## 题目描述

设计一个 `FirstUnique` 类：

- `FirstUnique(int[] nums)`：初始化对象，将 `nums` 中的数字依次加入队列。
- `int showFirstUnique()`：返回队列最左边的唯一整数（即只出现过一次的最早入队元素）。若不存在则返回 `-1`。
- `void add(int value)`：在队列尾部添加一个整数。

**示例：**

```
输入：
["FirstUnique","showFirstUnique","add","add","add","add","add","showFirstUnique"]
[[[2,3,5]],[],[5],[2],[3],[3],[2],[]]
输出：
[null,2,null,null,null,null,null,3]

解释：
FirstUnique firstUnique = new FirstUnique([2,3,5]);
firstUnique.showFirstUnique(); // 返回 2
firstUnique.add(5);            // 队列变为 [2,3,5,5]
firstUnique.add(2);            // 队列变为 [2,3,5,5,2]
firstUnique.add(3);            // 队列变为 [2,3,5,5,2,3]
firstUnique.add(3);            // 队列变为 [2,3,5,5,2,3,3]
firstUnique.add(2);            // 队列变为 [2,3,5,5,2,3,3,2]
firstUnique.showFirstUnique(); // 返回 3（2、5 已出现多次）
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^8`
- `1 <= value <= 10^8`
- 最多调用 `showFirstUnique` 和 `add` 各 `10^5` 次

## 解题思路

核心问题：高效找到队列中第一个只出现过一次的元素。

**思路：双端队列 + 哈希集合**

- 维护一个有序队列（`collections.deque`）记录元素入队顺序。
- 维护一个哈希集合 `seen` 记录所有已入队元素，以及一个哈希集合 `duplicate` 记录出现超过一次的元素。
- `showFirstUnique()`：从队列头部弹出所有已在 `duplicate` 中的元素，返回队头（若存在）。
- `add(value)`：若 `value` 已经在 `seen` 中则加入 `duplicate`；否则加入 `seen` 并入队。

这样每次 `showFirstUnique` 时，队头一定是唯一元素（已重复的已被弹出）。

**关键点：**  
队列中的元素不删除，但在 `showFirstUnique` 时懒删除队头的重复元素，保证均摊 O(1)。

## Python 代码实现

### 方法一：双端队列 + 双哈希集合（推荐）

```python
from collections import deque

class FirstUnique:
    def __init__(self, nums: list):
        self.queue = deque()       # 记录元素顺序（懒删除）
        self.seen = set()          # 见过的元素集合
        self.duplicate = set()     # 重复出现的元素集合

        for num in nums:
            self.add(num)

    def showFirstUnique(self) -> int:
        # 从队头弹出所有重复元素（懒删除）
        while self.queue and self.queue[0] in self.duplicate:
            self.queue.popleft()
        # 返回队头（唯一元素），不存在返回 -1
        return self.queue[0] if self.queue else -1

    def add(self, value: int) -> None:
        if value in self.seen:
            # 已见过，标记为重复
            self.duplicate.add(value)
        else:
            # 第一次见，加入队列和 seen
            self.seen.add(value)
            self.queue.append(value)
```

### 方法二：有序字典（OrderedDict）

```python
from collections import OrderedDict

class FirstUnique:
    def __init__(self, nums: list):
        # OrderedDict 维护插入顺序，value 为出现次数
        self.count = OrderedDict()
        for num in nums:
            self.add(num)

    def showFirstUnique(self) -> int:
        # 找到第一个出现次数为 1 的元素
        for key, cnt in self.count.items():
            if cnt == 1:
                return key
        return -1

    def add(self, value: int) -> None:
        if value in self.count:
            self.count[value] += 1
        else:
            self.count[value] = 1
```

**注意：** 方法二的 `showFirstUnique` 最坏情况 O(n)，不如方法一高效。

### 方法三：链表 + 哈希表（手写双向链表，最优）

```python
class FirstUnique:
    def __init__(self, nums: list):
        # 用字典模拟有序集合，value: None 表示唯一，True 表示重复
        self.unique = {}   # 维护有序的唯一元素（Python 3.7+ dict 有序）
        self.all_seen = set()
        for num in nums:
            self.add(num)

    def showFirstUnique(self) -> int:
        # Python 3.7+ dict 保持插入顺序，取第一个键
        for key in self.unique:
            return key
        return -1

    def add(self, value: int) -> None:
        if value in self.all_seen:
            # 已见过，从唯一字典中删除（如果在的话）
            self.unique.pop(value, None)
        else:
            self.all_seen.add(value)
            self.unique[value] = True
```

## 复杂度分析

| 方法 | 初始化 | showFirstUnique | add |
|------|--------|-----------------|-----|
| 方法一（双端队列） | O(n) | 均摊 O(1) | O(1) |
| 方法二（OrderedDict） | O(n) | O(n) | O(1) |
| 方法三（有序字典） | O(n) | O(1) | O(1) |

- 空间复杂度：O(n)，存储所有入队元素。

## 关键点总结

1. 懒删除：队列中的重复元素不立即删除，在查询时才清理队头，保证均摊效率。
2. Python 3.7+ 的普通 `dict` 保持插入顺序，可直接利用。
3. 用两个集合（`seen` 和 `duplicate`）可以 O(1) 判断一个元素是否重复。
4. `deque` 的 `popleft()` 是 O(1)，比列表的 `pop(0)` 高效。

## 易错点

- 忘记在 `showFirstUnique` 中做懒删除，导致返回了已重复的元素。
- 初始化时忘记调用 `add` 方法处理 `nums`，导致逻辑不统一。
- Python 2 中 `dict` 无序，需要用 `OrderedDict`。
