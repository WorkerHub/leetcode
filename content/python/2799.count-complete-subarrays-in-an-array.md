## 题目描述

给你一个由 **正整数** 组成的数组 `nums`。

如果一个子数组中包含数组中存在的 **所有** 不同值，则该子数组为 **完整子数组**。

返回数组中 **完整子数组** 的数目。

**示例 1：**
```
输入：nums = [1,3,1,2,2]
输出：4
解释：完整子数组：[1,3,1,2],[1,3,1,2,2],[3,1,2],[3,1,2,2]
```

**示例 2：**
```
输入：nums = [5,5,5,5]
输出：10
```

**提示：**
- `1 <= nums.length <= 1000`

## 解题思路

**滑动窗口**：统计整个数组的不同值数量 `total_distinct`。

用双指针维护窗口 `[left, right]`，保证窗口内不同值数量 == `total_distinct`。对每个左端 `left`，找最小的右端 `right` 使窗口满足条件，则以 `left` 为左端的完整子数组数量 = `n - right`。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countCompleteSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        total = len(set(nums))  # 数组中不同值的总数

        ans = 0
        cnt = defaultdict(int)
        distinct = 0
        left = 0

        for right in range(n):
            if cnt[nums[right]] == 0:
                distinct += 1
            cnt[nums[right]] += 1

            # 收缩左端：保持最小满足条件的窗口
            while distinct == total:
                # 以 left 为左端、right 到 n-1 为右端的都是完整子数组
                ans += n - right
                cnt[nums[left]] -= 1
                if cnt[nums[left]] == 0:
                    distinct -= 1
                left += 1

        return ans
```

### 方法二：枚举左端

```python
from typing import List

class Solution:
    def countCompleteSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        total = len(set(nums))
        ans = 0

        for l in range(n):
            seen = set()
            for r in range(l, n):
                seen.add(nums[r])
                if len(seen) == total:
                    ans += n - r
                    break

        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n)，空间复杂度 O(k)（k 为不同值数量）
- 方法二：时间复杂度 O(n^2)

## 关键点总结

1. 完整子数组包含所有不同值
2. 滑动窗口找到最小右端后，该左端之后的所有右端都满足
3. `ans += n - right` 计数了所有以 left 为左端的完整子数组

## 易错点

1. 找到满足条件的窗口后，`n - right` 为该左端的贡献（不是 `n - right - 1`）
2. 收缩左端时计数要正确更新
