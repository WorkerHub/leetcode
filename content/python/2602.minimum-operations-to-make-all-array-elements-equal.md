## 题目描述

给你一个正整数数组 `nums`。

同时给你一个长度为 `m` 的查询数组 `queries`。第 `i` 个查询中，你需要将 `nums` 中所有元素变成 `queries[i]`。每次操作可以将一个元素加 1 或减 1，返回一个长度为 `m` 的数组 `answer`，其中 `answer[i]` 是第 `i` 次查询的最少操作数。

**示例 1：**
```
输入：nums = [3,1,6,8], queries = [1,5]
输出：[14,10]
解释：
- 查询1：把所有元素变成1，操作数 = (3-1)+(1-1)+(6-1)+(8-1) = 14
- 查询2：把所有元素变成5，操作数 = (5-3)+(5-1)+(6-5)+(8-5) = 10
```

**示例 2：**
```
输入：nums = [2,9,6,3], queries = [10]
输出：[20]
```

**数据范围：**
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^9
- 1 <= queries.length <= 10^5
- 1 <= queries[i] <= 10^9

## 解题思路

排序 + 前缀和 + 二分查找：

对于查询值 `q`，总操作数 = 小于 `q` 的元素与 `q` 的差之和 + 大于 `q` 的元素与 `q` 的差之和。

设排序后数组为 `sorted_nums`，前缀和为 `prefix`：
- 设二分查找得到 `q` 在排序数组中的位置 `k`（即前 `k` 个元素 <= q）
- 左侧贡献：`q * k - prefix[k]`
- 右侧贡献：`(prefix[n] - prefix[k]) - q * (n - k)`
- 总和相加即为答案

## Python 代码实现

### 方法一：排序 + 前缀和 + 二分查找（推荐）

```python
from typing import List
import bisect
from itertools import accumulate

class Solution:
    def minOperations(self, nums: List[int], queries: List[int]) -> List[int]:
        # 排序
        nums.sort()
        n = len(nums)
        # 构建前缀和（prefix[i] 表示前 i 个元素之和）
        prefix = [0] * (n + 1)
        for i, x in enumerate(nums):
            prefix[i + 1] = prefix[i] + x

        result = []
        for q in queries:
            # 二分查找：找到第一个 > q 的位置（即 nums 中 <= q 的元素个数）
            k = bisect.bisect_right(nums, q)
            # 左侧（nums[0..k-1] 都 <= q）的操作数
            left_cost = q * k - prefix[k]
            # 右侧（nums[k..n-1] 都 > q）的操作数
            right_cost = (prefix[n] - prefix[k]) - q * (n - k)
            result.append(left_cost + right_cost)

        return result
```

### 方法二：使用 itertools.accumulate

```python
from typing import List
import bisect
from itertools import accumulate

class Solution:
    def minOperations(self, nums: List[int], queries: List[int]) -> List[int]:
        nums.sort()
        n = len(nums)
        # accumulate 生成前缀和列表，插入 0 作为首项
        prefix = [0] + list(accumulate(nums))

        ans = []
        for q in queries:
            k = bisect.bisect_right(nums, q)
            # 小于等于 q 的元素：q*k - sum(nums[:k])
            left = q * k - prefix[k]
            # 大于 q 的元素：sum(nums[k:]) - q*(n-k)
            right = (prefix[n] - prefix[k]) - q * (n - k)
            ans.append(left + right)
        return ans
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，排序 O(n log n)，每次查询二分 O(log n)
- 空间复杂度：O(n)，存储前缀和数组

## 关键点总结

1. 排序后，利用前缀和将区间求和转化为 O(1) 操作
2. `bisect_right` 找到分界点，左侧元素需要增加，右侧元素需要减少
3. 绝对值之和最小的点是中位数，但这里查询固定了目标值

## 易错点

1. 注意前缀和数组下标，`prefix[k]` 表示前 `k` 个元素之和
2. `bisect_right` 而非 `bisect_left`，确保等于 q 的元素被归入左侧
3. 数组元素和查询值可能很大，注意整数溢出（Python 无此问题）
