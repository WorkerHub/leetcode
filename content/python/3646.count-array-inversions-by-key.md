## 题目描述

给你两个整数数组 `key` 和 `value`，长度均为 `n`。定义一对 `(i, j)` 为逆序对，当且仅当：

- `i < j`
- `key[i] > key[j]`，或 `key[i] == key[j]` 且 `value[i] > value[j]`

返回逆序对的数量，结果对 `10^9 + 7` 取模。

**示例 1：**

```
输入：key = [2,1,3], value = [1,2,3]
输出：1
解释：(0,1)：key[0]=2 > key[1]=1，是逆序对
```

**示例 2：**

```
输入：key = [1,1,1], value = [3,2,1]
输出：3
解释：key 相同时按 value 排序，所有对均为逆序对
```

**提示：**

- `1 <= n <= 10^5`
- `1 <= key[i], value[i] <= 10^9`

## 解题思路

将 `(key[i], value[i])` 视为二元组，统计逆序对数。

**归并排序**：合并时统计跨左右两半的逆序对数。

或者**树状数组**：离散化后，从右往左，对每个元素查询在其之前有多少个比它大的元素。

## Python 代码实现

### 方法一：归并排序统计（推荐）

```python
from typing import List

class Solution:
    def countInversions(self, key: List[int], value: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(key)
        pairs = sorted(set(zip(key, value)))
        rank = {p: i for i, p in enumerate(pairs)}
        arr = [rank[(k, v)] for k, v in zip(key, value)]

        self.count = 0

        def merge_sort(a):
            if len(a) <= 1:
                return a
            mid = len(a) // 2
            left = merge_sort(a[:mid])
            right = merge_sort(a[mid:])
            merged = []
            i = j = 0
            while i < len(left) and j < len(right):
                if left[i] <= right[j]:
                    merged.append(left[i])
                    i += 1
                else:
                    self.count = (self.count + len(left) - i) % MOD
                    merged.append(right[j])
                    j += 1
            merged.extend(left[i:])
            merged.extend(right[j:])
            return merged

        merge_sort(arr)
        return self.count
```

### 方法二：树状数组

```python
from typing import List

class Solution:
    def countInversions(self, key: List[int], value: List[int]) -> int:
        MOD = 10 ** 9 + 7
        # 按 (key, value) 排序后离散化
        pairs = [(k, v) for k, v in zip(key, value)]
        sorted_pairs = sorted(set(pairs))
        rank = {p: i + 1 for i, p in enumerate(sorted_pairs)}
        N = len(sorted_pairs)

        bit = [0] * (N + 1)

        def update(i):
            while i <= N:
                bit[i] += 1
                i += i & (-i)

        def query(i):
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        ans = 0
        for p in pairs:
            r = rank[p]
            # 比 r 大的已插入的元素数 = 已插入总数 - query(r)
            already = query(N) - query(r)
            ans = (ans + already) % MOD
            update(r)

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 二元组比较：先比较 key，相同再比较 value
2. 归并排序或树状数组均可统计逆序对
3. 离散化处理：将二元组映射到连续整数排名
4. 结果对 MOD 取模

## 易错点

1. 逆序对定义：`key[i] > key[j]` 或（`key[i] == key[j]` 且 `value[i] > value[j]`）
2. 离散化时要对 (key, value) 对排序，而非单独对 key 或 value
3. 树状数组从右往左统计会更直观
