## 题目描述

给你一棵树（即无向连通无环图），这棵树由编号从 `0` 到 `n - 1` 的 `n` 个节点组成，恰好有 `n - 1` 条边。树的根节点为 `0`。

给你一个长度为 `n` 的字符串 `labels`，其中 `labels[i]` 表示第 `i` 个节点的标签（均为小写字母）。

另给你一个二维整数数组 `edges`，其中 `edges[i] = [ai, bi]` 表示节点 `ai` 和节点 `bi` 之间存在一条边。

返回一个大小为 `n` 的整数数组 `ans`，其中 `ans[i]` 表示第 `i` 个节点的子树中（包括节点 `i` 本身）与 `labels[i]` 相同的节点数。

**示例 1：**
```
输入：n = 7, edges = [[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], labels = "abaedcd"
输出：[2,1,1,1,1,1,1]
```

## 解题思路

### DFS 后序遍历

每个节点的答案 = 自身标签出现次数（1）+ 所有子节点子树中相同标签的数量。

用 DFS 后序遍历，从叶子节点向上合并计数数组（26个字母的频次）。

**关键点：**
- 每次 DFS 返回该子树中各字母的频次数组
- `ans[node] = count[labels[node]]`（当前子树中与自身标签相同的节点数）

## 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubTrees(self, n: int, edges: List[List[int]], labels: str) -> List[int]:
        # 建图（邻接表）
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = [0] * n

        def dfs(node: int, parent: int) -> List[int]:
            # 初始化当前节点的字母频次（26个字母）
            count = [0] * 26
            count[ord(labels[node]) - ord('a')] = 1

            # 遍历所有子节点（排除父节点）
            for child in graph[node]:
                if child != parent:
                    child_count = dfs(child, node)
                    # 合并子节点的频次
                    for i in range(26):
                        count[i] += child_count[i]

            # 当前节点的答案 = 子树中与自身标签相同的数量
            ans[node] = count[ord(labels[node]) - ord('a')]
            return count

        dfs(0, -1)
        return ans
```

### 方法二：使用 Counter 简化

```python
from typing import List
from collections import defaultdict, Counter

class Solution:
    def countSubTrees(self, n: int, edges: List[List[int]], labels: str) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = [0] * n

        def dfs(node: int, parent: int) -> Counter:
            # 初始化：当前节点贡献 1 个自身标签
            count = Counter({labels[node]: 1})
            for child in graph[node]:
                if child != parent:
                    count += dfs(child, node)
            # 当前节点答案
            ans[node] = count[labels[node]]
            return count

        dfs(0, -1)
        return ans
```

### 方法三：迭代 DFS（避免递归栈溢出）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubTrees(self, n: int, edges: List[List[int]], labels: str) -> List[int]:
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        ans = [0] * n
        counts = [[0] * 26 for _ in range(n)]
        # 初始化每个节点自身
        for i in range(n):
            counts[i][ord(labels[i]) - ord('a')] = 1

        # 拓扑排序（从叶子往根处理）
        parent = [-1] * n
        visited = [False] * n
        order = []
        stack = [0]
        visited[0] = True
        while stack:
            node = stack.pop()
            order.append(node)
            for child in graph[node]:
                if not visited[child]:
                    visited[child] = True
                    parent[child] = node
                    stack.append(child)

        # 从叶子到根，合并计数
        for node in reversed(order):
            ans[node] = counts[node][ord(labels[node]) - ord('a')]
            if parent[node] != -1:
                for i in range(26):
                    counts[parent[node]][i] += counts[node][i]

        return ans
```

## 复杂度分析

- **时间复杂度**：O(26N) = O(N)，每个节点处理一次，每次合并 26 个字母的计数
- **空间复杂度**：O(26N) = O(N)

## 关键点总结

1. DFS 后序遍历，子节点先算，父节点再合并
2. 每个节点维护子树中 26 个字母的频次
3. 当前节点的答案 = 其字母在子树频次数组中的值
4. 用 `Counter` 的 `+=` 可以方便合并

## 易错点

- 建树时用无向图，DFS 时需要传入父节点以避免走回头路
- 节点编号从 0 开始，字母用 `ord(c) - ord('a')` 转下标
