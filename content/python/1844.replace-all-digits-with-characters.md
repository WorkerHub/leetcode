## 题目描述

给你一个下标从 0 开始的字符串 `s`，它的偶数下标处是小写英文字母，奇数下标处是数字。

对于每个奇数下标 `i`，将 `s[i]` 替换为 `shift(s[i-1], s[i])`，即将 `s[i-1]` 向后移动 `s[i]` 位后的字母。

返回替换后的字符串。

**示例：**
```
输入：s = "a1c1e1"
输出："abcdef"
解释：b = shift(a, 1), d = shift(c, 1), f = shift(e, 1)
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母和数字
- shift(s[i-1], s[i]) <= 'z'（保证不越界）

## 解题思路

遍历字符串，遇到奇数位置的数字，将前一个字母向后移动对应位数后替换该数字。

`shift(c, d)` = `chr(ord(c) + int(d))`

## 代码实现

### 方法一：列表替换（推荐）

```python
class Solution:
    def replaceDigits(self, s: str) -> str:
        result = list(s)
        for i in range(1, len(s), 2):
            # 将奇数位的数字替换为 shift(s[i-1], s[i])
            result[i] = chr(ord(s[i - 1]) + int(s[i]))
        return ''.join(result)
```

### 方法二：字符串拼接（每两个字符处理）

```python
class Solution:
    def replaceDigits(self, s: str) -> str:
        result = []
        for i in range(0, len(s), 2):
            result.append(s[i])  # 保留偶数位字母
            if i + 1 < len(s):
                # 替换奇数位数字
                result.append(chr(ord(s[i]) + int(s[i + 1])))
        return ''.join(result)
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，结果列表

## 关键点总结

1. `chr(ord(c) + d)` 实现字母后移 d 位
2. 奇数位一定是数字，偶数位一定是字母（题目保证）
3. 步长为 2 遍历所有奇数或偶数位

## 易错点

- `int(s[i])` 将字符 '1' 转为整数 1，不要忘记类型转换
- 步长为 2 时要注意字符串长度为奇数时最后一个偶数位没有对应的数字
