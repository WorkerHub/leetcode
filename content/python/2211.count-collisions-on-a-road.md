## 题目描述

在一条无限长的公路上，有 `n` 辆汽车正在行驶。给你一个长度为 `n` 的字符串 `directions`，代表每辆车的行驶方向：
- `'L'`：向左行驶
- `'R'`：向右行驶
- `'S'`：静止

**碰撞规则：**
- 当一辆向右行驶的车遇到一辆向左行驶的车（即 `R...L` 的组合）时，它们会碰撞。
- 碰撞后车辆变为静止 `'S'`。
- 向左行驶最左侧的车、向右行驶最右侧的车永远不会碰撞。

返回碰撞后**总碰撞次数**（每辆车最多参与一次碰撞，但一次碰撞使两辆车都停下，故计碰撞的汽车数量）。

**注意：** 这里返回的是碰撞中涉及的汽车总数（即使一次碰撞影响两辆车）。

**示例 1：**
```
输入：directions = "RLRSLL"
输出：5
```

**示例 2：**
```
输入：directions = "LLRR"
输出：0
```

## 解题思路

关键观察：
- 最左侧连续的 `L` 永远向左驶出，不会碰撞。
- 最右侧连续的 `R` 永远向右驶出，不会碰撞。
- 除此之外，所有 `R` 和 `S` 以及会与右侧某个车碰撞的 `L` 都会产生碰撞。

更简洁地：**去掉首部的 `L` 和尾部的 `R` 后，剩余非 `S` 的字符数就是答案。**

这是因为去掉首尾不碰撞的车后，中间的每辆 `R`（会被右边某个 `L` 或 `S` 撞停）、每辆 `L`（会被左边某个 `R` 或 `S` 撞停）以及参与碰撞的 `S` 都会被计入。

## 代码实现

### 方法一：去首尾后统计非 S（推荐）

```python
class Solution:
    def countCollisions(self, directions: str) -> int:
        # 去掉首部连续的 L（向左行驶，不会碰撞）
        # 去掉尾部连续的 R（向右行驶，不会碰撞）
        s = directions.lstrip('L').rstrip('R')
        # 剩余字符中非 'S' 的数量就是碰撞次数
        return sum(1 for c in s if c != 'S')
```

### 方法二：栈模拟

```python
class Solution:
    def countCollisions(self, directions: str) -> int:
        stack = []
        collisions = 0

        for d in directions:
            if d == 'R':
                stack.append(d)
            elif d == 'S':
                # 所有栈中的 R 都会与这个 S 碰撞
                collisions += len(stack)
                stack.clear()
                # S 本身不进栈（静止）
            else:  # d == 'L'
                if stack:
                    # 弹出所有 R（它们都与这个 L 碰撞）
                    # 最后 R 和 L 碰撞产生两辆停车
                    if 'R' in stack or True:
                        # 栈中 R 的数量 + 这辆 L
                        cnt = len(stack)
                        collisions += cnt + 1  # R 们 + 这辆 L
                        stack.clear()
                        stack.append('S')  # 碰后变 S
                    # else 若栈顶是 S，L 也会碰
                else:
                    pass  # 最左侧的 L，不碰撞

        return collisions
```

### 方法三：模拟（更规范）

```python
class Solution:
    def countCollisions(self, directions: str) -> int:
        # 等价于：去掉前缀 L 和后缀 R，剩余非 S 的字符数
        n = len(directions)
        left = 0
        while left < n and directions[left] == 'L':
            left += 1
        right = n - 1
        while right >= 0 and directions[right] == 'R':
            right -= 1
        return sum(1 for i in range(left, right + 1) if directions[i] != 'S')
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历。
- 空间复杂度：O(1)（方法三），O(n)（方法一，lstrip/rstrip 创建新字符串）。

## 关键点总结

1. 最左端的 `L` 和最右端的 `R` 永远不碰撞，直接去掉。
2. 去掉后剩余中间部分，所有非 `S` 的车辆都必然参与碰撞。
3. 贪心思路简洁：`lstrip('L').rstrip('R')` 后统计非 `S`。

## 易错点

- 不能简单统计所有 `R` 前面有 `L` 的对数，因为会有链式碰撞（一辆 R 可能碰上一辆停止的 S）。
- 但去首尾方法已完全处理了这些情况。
