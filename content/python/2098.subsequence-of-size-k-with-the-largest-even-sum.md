## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回长度为 `k` 的子序列的**最大偶数和**。如果不存在，返回 `-1`。

**示例 1：**
```
输入：nums = [4,1,5,3,1], k = 3
输出：12
解释：子序列 [4,5,3] 和为 12（偶数）
```

**示例 2：**
```
输入：nums = [4,6,2], k = 3
输出：12
解释：只有一个长度为3的子序列 [4,6,2]，和为12
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

## 解题思路

**贪心：**

1. 先取最大的 k 个数（排序后取末尾 k 个），这些数的和是最大的
2. 如果和已经是偶数，直接返回
3. 如果和是奇数，需要调整一次以使和变为偶数：
   - **替换方案A：** 将已选的最小奇数换成未选的最大偶数（减少奇数数量）
   - **替换方案B：** 将已选的最小偶数换成未选的最大奇数（增加偶数数量）
   - 取两种方案中差值最小的（即损失最小的）
4. 若都无法替换（不存在合法替换对），返回 -1

## 代码实现

### 方法一：排序 + 贪心调整（推荐）

```python
from typing import List

class Solution:
    def largestEvenSum(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)

        # 取最大的 k 个数
        selected = nums[n - k:]
        rest = nums[:n - k]
        total = sum(selected)

        if total % 2 == 0:
            return total

        # 需要调整：将和变为偶数
        # selected 中按升序，rest 中按升序
        # 方案A：换出 selected 中最小奇数，换入 rest 中最大偶数
        # 方案B：换出 selected 中最小偶数，换入 rest 中最大奇数

        best = -1

        # 方案A：找 selected 中最小奇数
        for i in range(len(selected)):
            if selected[i] % 2 == 1:
                # 找 rest 中最大偶数
                for j in range(len(rest) - 1, -1, -1):
                    if rest[j] % 2 == 0:
                        best = max(best, total - selected[i] + rest[j])
                        break
                break

        # 方案B：找 selected 中最小偶数
        for i in range(len(selected)):
            if selected[i] % 2 == 0:
                # 找 rest 中最大奇数
                for j in range(len(rest) - 1, -1, -1):
                    if rest[j] % 2 == 1:
                        best = max(best, total - selected[i] + rest[j])
                        break
                break

        return best
```

### 方法二：分离奇偶后贪心

```python
from typing import List

class Solution:
    def largestEvenSum(self, nums: List[int], k: int) -> int:
        nums.sort(reverse=True)
        total = sum(nums[:k])

        if total % 2 == 0:
            return total

        # 把 nums 分为已选（前k个）和未选（后n-k个）
        # 在已选中找最小奇数/偶数，在未选中找最大偶数/奇数
        selected = sorted(nums[:k])
        rest = sorted(nums[k:], reverse=True)

        best = -1

        # 换出已选中最小奇数，换入未选中最大偶数
        min_odd_sel = next((x for x in selected if x % 2 == 1), None)
        max_even_rest = next((x for x in rest if x % 2 == 0), None)
        if min_odd_sel is not None and max_even_rest is not None:
            best = max(best, total - min_odd_sel + max_even_rest)

        # 换出已选中最小偶数，换入未选中最大奇数
        min_even_sel = next((x for x in selected if x % 2 == 0), None)
        max_odd_rest = next((x for x in rest if x % 2 == 1), None)
        if min_even_sel is not None and max_odd_rest is not None:
            best = max(best, total - min_even_sel + max_odd_rest)

        return best
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(k)，存储已选元素

## 关键点总结

1. 先贪心选最大的 k 个数
2. 若和为偶数则直接返回
3. 若和为奇数，需要一次交换（换出最小损失的奇/偶数）
4. 两种调整方案取最大值

## 易错点

- 调整时要从已选中选**最小**的（损失最少），从未选中选**最大**的（收益最多）
- 调整后结果可能比原来更小，但只要是合法的偶数就返回最大值
- 若无法调整（无法凑成偶数），返回 -1
