## 题目描述

给你一个整数数组 `nums` 和整数 `k`，判断是否可以将数组分成两个非空连续子数组，使得两个子数组的元素之和之差的绝对值不超过 `k`。

**示例 1：**

```
输入：nums = [1,3,5,7], k = 4
输出：true
解释：[1,3] 和 [5,7]，和分别为4和12，差8>4；[1,3,5]和[7]，和9和7，差2<=4
```

**示例 2：**

```
输入：nums = [1,2,3], k = 0
输出：false
解释：所有划分差均>0
```

**提示：**

- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
- `0 <= k <= 10^9`

## 解题思路

枚举分割点：将数组分成 `nums[0..i]` 和 `nums[i+1..n-1]`，分别计算两部分之和之差，判断是否 <= k。

用前缀和预处理，O(1) 计算每个分割点的两部分之和。

## Python 代码实现

### 方法一：前缀和枚举（推荐）

```python
from typing import List

class Solution:
    def checkPartition(self, nums: List[int], k: int) -> bool:
        n = len(nums)
        total = sum(nums)
        prefix = 0

        for i in range(n - 1):
            prefix += nums[i]
            suffix = total - prefix
            if abs(prefix - suffix) <= k:
                return True

        return False
```

### 方法二：直接遍历

```python
from typing import List

class Solution:
    def checkPartition(self, nums: List[int], k: int) -> bool:
        total = sum(nums)
        left_sum = 0
        for i in range(len(nums) - 1):
            left_sum += nums[i]
            right_sum = total - left_sum
            if abs(left_sum - right_sum) <= k:
                return True
        return False
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只需枚举 n-1 个分割点
2. 前缀和 + 总和快速计算两部分之和
3. 有一个分割点满足条件即返回 true

## 易错点

1. 两部分都必须非空，分割点从 0 到 n-2
2. 差值是绝对值，用 `abs()`
3. 不需要 DP，直接枚举即可
