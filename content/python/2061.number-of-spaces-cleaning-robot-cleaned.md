## 题目描述

一个清洁机器人从 `(0, 0)` 出发，初始朝右。矩阵中 `0` 表示空地，`1` 表示障碍物。

机器人运动规则：
- 每次向前移动一步
- 如果下一步是障碍物或超出边界，向右转 90 度再移动
- 机器人会在清洁过的空地停止

返回机器人清洁的空地数目（经过的格子均被清洁，包括起始位置）。

**提示：**
- 矩阵大小 `m x n`，`1 <= m, n <= 300`
- `matrix[i][j]` 是 `0` 或 `1`
- `matrix[0][0] == 0`

## 解题思路

直接模拟机器人的运动过程。维护当前位置和方向，模拟直到机器人停止（进入曾经清洁过的格子且方向相同时陷入循环停止）。

**终止条件：** 当机器人到达一个已经以相同方向经过的格子时，说明进入了循环，停止。

## 代码实现

### 方法一：模拟（推荐）

```python
from typing import List

class Solution:
    def numberOfCleanRooms(self, room: List[List[int]]) -> int:
        m, n = len(room), len(room[0])
        # 方向：右、下、左、上
        dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]

        r, c, d = 0, 0, 0  # 当前行、列、方向
        cleaned = set()    # 已清洁的格子
        visited = set()    # (行, 列, 方向) 已访问状态

        while (r, c, d) not in visited:
            visited.add((r, c, d))
            cleaned.add((r, c))

            # 尝试向前移动
            nr, nc = r + dirs[d][0], c + dirs[d][1]
            if 0 <= nr < m and 0 <= nc < n and room[nr][nc] == 0:
                r, c = nr, nc
            else:
                # 转向
                d = (d + 1) % 4

        return len(cleaned)
```

### 方法二：标记数组优化

```python
from typing import List

class Solution:
    def numberOfCleanRooms(self, room: List[List[int]]) -> int:
        m, n = len(room), len(room[0])
        dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]

        r, c, d = 0, 0, 0
        cleaned = 0
        visited = [[False] * n for _ in range(m)]
        state_visited = set()  # (r, c, d)

        while True:
            state = (r, c, d)
            if state in state_visited:
                break
            state_visited.add(state)

            if not visited[r][c]:
                visited[r][c] = True
                cleaned += 1

            nr, nc = r + dirs[d][0], c + dirs[d][1]
            if 0 <= nr < m and 0 <= nc < n and room[nr][nc] == 0:
                r, c = nr, nc
            else:
                d = (d + 1) % 4

        return cleaned
```

## 复杂度分析

- 时间复杂度：O(m * n * 4)，每个状态（位置+方向）最多访问一次
- 空间复杂度：O(m * n)

## 关键点总结

1. 状态包含位置和方向：`(r, c, d)`，相同状态意味着进入循环
2. 转向规则：障碍物或边界时向右转 90 度
3. 机器人只清洁空地（`room[r][c] == 0`）

## 易错点

- 状态必须包含方向（只有位置不够，可能多次以不同方向经过同一格子）
- 起始位置 `(0, 0)` 也算清洁
- 方向循环：4 个方向，`d = (d + 1) % 4`
