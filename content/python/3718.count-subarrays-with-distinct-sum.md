## 题目描述

给定整数数组 `nums` 和整数 `k`，统计所有元素都不同且元素之和恰好等于 `k` 的子数组数量。

**示例 1：**
```
输入：nums = [1,2,3,1,3], k = 6
输出：1
解释：子数组 [1,2,3]（下标 0-2）的元素不同且和为 6，是唯一满足条件的子数组。
     [3,1] 和为 4，不满足。
     [2,3,1] 和为 6 但检查元素唯一性：2,3,1 均不同，满足！-> 答案应为 2。
```

**示例 2：**
```
输入：nums = [4,2,4], k = 8
输出：0
解释：和为 8 的子数组 [4,4] 有重复，[2,4] 和为 6，不满足。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= 10^9`

## 解题思路

滑动窗口 + 哈希表。

维护一个滑动窗口 `[left, right]`，使得窗口内元素各不相同。使用哈希表记录窗口内元素。

对于每个右端点 `right`：
- 若 `nums[right]` 已在窗口内，移动左指针直到移除重复元素。
- 当前窗口内元素各不相同，但窗口内和可能不等于 k。
- 由于需要和恰好等于 k，需要维护窗口内的和，同时还要确保元素不重复。

这里需要枚举以每个下标为右端点的、元素各不相同的所有子数组，检查其和是否等于 k。

但直接枚举复杂度较高，可以用前缀和 + 哈希优化：
- 先找不重复的子数组，再统计其中和等于 k 的。

更直接的方法：双指针维护不重复窗口，对每个右端点枚举左端点并累计和。

## Python 代码实现

### 方法一：滑动窗口（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        count = defaultdict(int)
        left = 0
        window_sum = 0
        result = 0

        for right in range(n):
            # 加入右端点
            count[nums[right]] += 1
            window_sum += nums[right]

            # 若有重复，收缩左边界
            while count[nums[right]] > 1:
                count[nums[left]] -= 1
                window_sum -= nums[left]
                left += 1

            # 当前 [left, right] 内元素不重复
            # 统计所有以 right 结尾、元素不重复且和等于 k 的子数组
            # 在 [left, right] 范围内枚举左端点
            # 注意：和随左端点右移而减小，不单调，难以直接用窗口
            # 改为枚举：对每个右端点，向左遍历寻找满足条件的子数组
            cur_sum = 0
            for l in range(right, left - 1, -1):
                cur_sum += nums[l]
                if cur_sum == k:
                    result += 1
                elif cur_sum > k:
                    break  # 由于 nums[i] >= 1，和只会越来越大，可以提前终止

        return result
```

### 方法二：前缀和 + 哈希集合

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0

        # 枚举左端点，右指针扩展直到出现重复
        for left in range(n):
            seen = set()
            cur_sum = 0
            for right in range(left, n):
                if nums[right] in seen:
                    break  # 出现重复，停止
                seen.add(nums[right])
                cur_sum += nums[right]
                if cur_sum == k:
                    result += 1
                # cur_sum > k 不能提前退出，因为后面可能和 == k... 
                # 但由于 nums[i] >= 1，cur_sum 只增不减，可以提前退出
                elif cur_sum > k:
                    break

        return result
```

## 复杂度分析

- 时间复杂度：O(n^2) 最坏情况，但由于元素不重复和和单调增的约束，实际很快
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 元素不重复的约束使得滑动窗口内的子数组数量有限
2. 由于元素均为正整数，窗口内和随左端点右移单调减少，可以提前终止内层循环
3. 双层循环在元素值较大时实际运行很快

## 易错点

1. 和等于 k 不能用单一窗口解决，需要枚举左端点
2. 正整数保证和单调递增，出现重复时才停止
