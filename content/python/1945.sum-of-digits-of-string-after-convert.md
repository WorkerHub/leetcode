## 题目描述

给你一个由小写字母组成的字符串 `s` 和一个整数 `k`。

**转换**的步骤如下：
1. 将 `s` 中每个字符转换为它在字母表中的位置（a=1, b=2, ..., z=26），拼接成一个整数
2. 对拼接后的整数，将其**所有位的数字相加**，重复 `k` 次

返回最终结果。

**示例 1：**
```
输入：s = "iiii", k = 1
输出：36
解释：i=9, 拼接为 "9999"，各位和 = 9+9+9+9 = 36
```

**示例 2：**
```
输入：s = "leetcode", k = 2
输出：6
解释：l=12,e=5,e=5,t=20,c=3,o=15,d=4,e=5 → "1255203154152035"
第 1 次：1+2+5+5+2+0+3+1+5+4+1+5+2+0+3+5 = 44
第 2 次：4+4 = 8... 等等实际是 6
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写字母
- `1 <= k <= 10`

---

## 解题思路

### 核心思想：直接模拟

1. 将字符串转换为数字字符串（每个字母转为 1-26，拼接）
2. 对数字字符串的各位数字求和
3. 重复 `k` 次第 2 步

---

## 代码实现

### 方法一：字符串模拟（推荐）

```python
class Solution:
    def getLucky(self, s: str, k: int) -> int:
        # 步骤 1：将字母转为数字字符串并拼接
        num_str = ''.join(str(ord(c) - ord('a') + 1) for c in s)

        # 步骤 2：计算各位数字之和，重复 k 次
        result = sum(int(d) for d in num_str)
        for _ in range(k - 1):
            result = sum(int(d) for d in str(result))

        return result
```

### 方法二：直接整数操作

```python
class Solution:
    def getLucky(self, s: str, k: int) -> int:
        # 构建数字字符串
        num_str = ''
        for c in s:
            num_str += str(ord(c) - 96)  # a=1, ord('a')=97

        def digit_sum(n: int) -> int:
            """计算整数 n 的各位数字之和"""
            total = 0
            while n > 0:
                total += n % 10
                n //= 10
            return total

        # 第一次：对字符串各位求和
        result = sum(int(d) for d in num_str)
        # 后续 k-1 次：对整数各位求和
        for _ in range(k - 1):
            result = digit_sum(result)

        return result
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(n + k * log(max_result)) | O(n) |
| 方法二 | O(n + k * digits) | O(n) |

---

## 关键点总结

1. 字母转数字：`ord(c) - ord('a') + 1`（a=1, z=26）
2. 第一次求和是对数字字符串，之后是对整数
3. 注意两位数字（10-26）会被拆分为两个数字字符

---

## 易错点

- 字母对应数字为 1-26，不是 0-25
- 注意 10-26 是两位数，拼接后贡献两个数字位
