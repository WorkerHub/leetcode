## 题目描述

给你一个下标从 **0** 开始的整数数组 `nums`，判断是否存在两个长度为 `2` 的子数组且它们的和相等。

注意，这两个子数组起始位置的下标**必须不同**。

如果存在这样的子数组，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：nums = [4,2,4]
输出：true
解释：nums[0..1] = [4,2]，和为 6；nums[1..2] = [2,4]，和为 6。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5]
输出：false
```

**示例 3：**
```
输入：nums = [0,0,0]
输出：true
```

**提示：**
- `2 <= nums.length <= 1000`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

**哈希表：**

遍历所有相邻两数的和，用哈希集合记录已见过的和：
- 若当前和已在集合中，返回 `True`。
- 否则，将当前和加入集合。

## 代码实现

### 方法一：哈希集合（推荐）

```python
from typing import List

class Solution:
    def findSubarrays(self, nums: List[int]) -> bool:
        seen = set()
        
        for i in range(len(nums) - 1):
            s = nums[i] + nums[i + 1]
            if s in seen:
                return True
            seen.add(s)
        
        return False
```

### 方法二：暴力双重循环

```python
from typing import List

class Solution:
    def findSubarrays(self, nums: List[int]) -> bool:
        n = len(nums)
        
        for i in range(n - 1):
            for j in range(i + 1, n - 1):
                if nums[i] + nums[i + 1] == nums[j] + nums[j + 1]:
                    return True
        
        return False
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希集合 | O(n) | O(n) |
| 暴力双重循环 | O(n^2) | O(1) |

## 关键点总结

1. 只需要找两个不同起始下标的长度为 2 的子数组，其和相等。
2. 使用哈希集合一次遍历即可，时间复杂度 O(n)。
3. 每次计算相邻两数之和，若之前出现过，则返回 `True`。

## 易错点

- 题目要求子数组起始位置下标不同（不是值不同），所以不同位置的相同和即满足条件。
- 遍历到 `len(nums) - 1` 为止（最后一个长度为 2 的子数组从 `n-2` 开始）。
