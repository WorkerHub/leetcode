## 题目描述

我们构建了一个序列：

```
第 1 行: 0
第 2 行: 01
第 3 行: 0110
第 4 行: 01101001
...
```

每一行都通过将前一行中的每个 `0` 替换为 `01`，每个 `1` 替换为 `10` 来生成。

给定行数 `n` 和索引 `k`，返回第 `n` 行中第 `k` 个字符（索引从 1 开始）。

**示例 1:**
```
输入: n = 1, k = 1
输出: 0
```

**示例 2:**
```
输入: n = 2, k = 1
输出: 0
```

**示例 3:**
```
输入: n = 2, k = 2
输出: 1
```

## 解题思路

使用递归。第 n 行的第 k 个字符：
- 如果 k 在前半部分，结果与第 n-1 行的第 k 个字符相同
- 如果 k 在后半部分，结果与第 n-1 行的第 k - 2^(n-2) 个字符相反

## Python 代码实现

```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        if n == 1:
            return 0
        
        # 第 n 行长度的一半
        mid = 2 ** (n - 2)
        
        if k <= mid:
            return self.kthGrammar(n - 1, k)
        else:
            return 1 - self.kthGrammar(n - 1, k - mid)
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(n)

## 关键点总结

1. **递归规律**
2. **二分思想**
3. **翻转关系**
