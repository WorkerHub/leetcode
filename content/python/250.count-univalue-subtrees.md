## 题目描述

给定一棵二叉树，统计该二叉树中同值子树的个数。

同值子树是指该子树的所有节点都具有相同的值。

**示例 1：**
```
输入: root = [5,1,5,5,5,null,5]

              5
             / \
            1   5
           / \   \
          5   5   5

输出: 4
解释: 有 4 个同值子树：
- 两个叶子节点 5（左子树的两个 5）
- 一个叶子节点 5（右子树的 5）
- 根节点的右子树（全是 5）
```

**示例 2：**
```
输入: root = []
输出: 0
```

**示例 3：**
```
输入: root = [5,5,5,5,5,null,5]
输出: 6
```

**提示：**
- 树中节点数目在范围 [0, 1000] 内
- -1000 <= Node.val <= 1000

## 解题思路

这道题要求统计同值子树的个数，核心是**自底向上的递归**。

**核心思想：**
- 使用后序遍历（左-右-根），自底向上判断每个子树是否是同值子树
- 一个树是同值子树的条件：
  1. 左子树是同值子树（或为空）
  2. 右子树是同值子树（或为空）
  3. 左子树的值 == 根节点的值（如果左子树存在）
  4. 右子树的值 == 根节点的值（如果右子树存在）

**关键观察：**
1. **叶子节点**：一定是同值子树
2. **递归性质**：判断当前树是否是同值子树，需要先判断左右子树
3. **计数时机**：每发现一个同值子树就计数
4. **返回值**：递归函数返回当前子树是否是同值子树

**算法设计：**
- 使用深度优先搜索（DFS）
- 递归函数返回：当前子树是否是同值子树
- 使用全局变量或闭包记录计数

## Python 代码实现

### 方法一：递归 + 全局计数（推荐）⭐

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def countUnivalSubtrees(self, root: TreeNode) -> int:
        """
        后序遍历，自底向上判断
        时间复杂度：O(n)，每个节点访问一次
        空间复杂度：O(h)，h 是树的高度（递归栈）
        """
        self.count = 0
        self.isUnival(root)
        return self.count
    
    def isUnival(self, node: TreeNode) -> bool:
        """
        判断以 node 为根的子树是否是同值子树
        返回 True/False，同时更新计数
        """
        # 空节点认为是同值子树
        if not node:
            return True
        
        # 递归判断左右子树
        left_is_unival = self.isUnival(node.left)
        right_is_unival = self.isUnival(node.right)
        
        # 如果左右子树不是同值子树，当前树也不是
        if not left_is_unival or not right_is_unival:
            return False
        
        # 检查左子树的值是否等于当前节点
        if node.left and node.left.val != node.val:
            return False
        
        # 检查右子树的值是否等于当前节点
        if node.right and node.right.val != node.val:
            return False
        
        # 当前树是同值子树，计数加 1
        self.count += 1
        return True
```

### 方法二：简化的递归判断

```python
class Solution:
    def countUnivalSubtrees(self, root: TreeNode) -> int:
        """
        简化判断逻辑
        """
        self.count = 0
        
        def helper(node):
            """返回当前子树是否是同值子树"""
            if not node:
                return True
            
            # 递归左右子树
            left = helper(node.left)
            right = helper(node.right)
            
            # 检查是否满足同值条件
            if left and right:
                if node.left and node.left.val != node.val:
                    return False
                if node.right and node.right.val != node.val:
                    return False
                
                # 满足条件，计数
                self.count += 1
                return True
            
            return False
        
        helper(root)
        return self.count
```

### 方法三：返回元组（值 + 是否同值）

```python
from typing import Optional, Tuple

class Solution:
    def countUnivalSubtrees(self, root: Optional[TreeNode]) -> int:
        """
        递归返回 (是否同值, 节点值)
        """
        self.count = 0
        
        def helper(node) -> Tuple[bool, int]:
            """
            返回 (是否是同值子树, 该子树的值)
            """
            if not node:
                return (True, None)
            
            # 递归处理左右子树
            left_unival, left_val = helper(node.left)
            right_unival, right_val = helper(node.right)
            
            # 检查是否是同值子树
            is_unival = True
            
            # 左子树不是同值，或者值不匹配
            if not left_unival:
                is_unival = False
            elif node.left and left_val != node.val:
                is_unival = False
            
            # 右子树不是同值，或者值不匹配
            if not right_unival:
                is_unival = False
            elif node.right and right_val != node.val:
                is_unival = False
            
            if is_unival:
                self.count += 1
            
            return (is_unival, node.val)
        
        helper(root)
        return self.count
```

### 方法四：Pythonic 简洁版

```python
class Solution:
    def countUnivalSubtrees(self, root: TreeNode) -> int:
        """
        Python 简洁写法
        """
        self.count = 0
        
        def is_unival(node):
            if not node:
                return True
            
            left = is_unival(node.left)
            right = is_unival(node.right)
            
            # 检查左右子树是否都是同值且值匹配
            if (left and right and
                (not node.left or node.left.val == node.val) and
                (not node.right or node.right.val == node.val)):
                self.count += 1
                return True
            
            return False
        
        is_unival(root)
        return self.count
```

### 方法五：迭代法（使用后序遍历栈）

```python
class Solution:
    def countUnivalSubtrees(self, root: TreeNode) -> int:
        """
        迭代实现（较复杂，不推荐）
        使用后序遍历 + 哈希表记录
        """
        if not root:
            return 0
        
        count = 0
        stack = []
        last_visited = None
        current = root
        
        # 使用字典记录每个节点是否是同值子树
        is_unival_map = {}
        
        while stack or current:
            # 一直向左走
            while current:
                stack.append(current)
                current = current.left
            
            peek = stack[-1]
            
            # 如果右子树存在且未访问，访问右子树
            if peek.right and peek.right != last_visited:
                current = peek.right
            else:
                # 处理当前节点（后序遍历的"根"）
                node = stack.pop()
                
                # 判断是否是同值子树
                left_unival = not node.left or is_unival_map.get(node.left, False)
                right_unival = not node.right or is_unival_map.get(node.right, False)
                
                is_current_unival = (
                    left_unival and right_unival and
                    (not node.left or node.left.val == node.val) and
                    (not node.right or node.right.val == node.val)
                )
                
                is_unival_map[node] = is_current_unival
                if is_current_unival:
                    count += 1
                
                last_visited = node
        
        return count
```

## 复杂度分析

**递归方法（方法一~四）：**
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 是树的高度，递归栈空间

**迭代方法（方法五）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈和哈希表

## 图解示例

**示例 1：root = [5,1,5,5,5,null,5]**

```
              5
             / \
            1   5
           / \   \
          5   5   5

后序遍历处理过程：

1. 访问左下角的 5（叶子）
   - 是同值子树，count = 1

2. 访问右下角的 5（叶子）
   - 是同值子树，count = 2

3. 访问节点 1
   - 左子树是同值（5），右子树是同值（5）
   - 但 1 ≠ 5，所以节点 1 的子树不是同值
   - count 不变

4. 访问右边的 5（叶子）
   - 是同值子树，count = 3

5. 访问右边的 5（有右子节点）
   - 右子树是同值（5），值也是 5
   - 是同值子树，count = 4

6. 访问根节点 5
   - 左子树不是同值（节点 1 那棵树）
   - 不是同值子树
   - count = 4

最终结果：4
```

**判断逻辑流程图：**
```
判断节点 N 是否是同值子树：
  ├─ 左子树是同值？ ─ No ─> 返回 False
  │                  
  │                  Yes
  │                   ↓
  ├─ 右子树是同值？ ─ No ─> 返回 False
  │                  
  │                  Yes
  │                   ↓
  ├─ 左子节点值 == N.val？ ─ No ─> 返回 False
  │                  
  │                  Yes
  │                   ↓
  ├─ 右子节点值 == N.val？ ─ No ─> 返回 False
  │                  
  │                  Yes
  │                   ↓
  └─ count++，返回 True
```

## 关键点总结

1. **后序遍历**：必须先处理子树，再处理根节点
2. **递归返回值**：返回当前子树是否是同值子树
3. **空节点处理**：空节点认为是同值子树
4. **判断条件**：左右子树都是同值 + 值都等于根节点
5. **计数时机**：确认是同值子树时立即计数

## 易错点

1. **空节点处理**：空节点应该返回 True，不是 False
2. **判断顺序**：要先判断左右子树是否是同值，再判断值是否相等
3. **叶子节点**：叶子节点一定是同值子树，不要漏掉
4. **短路逻辑**：如果左右子树有一个不是同值，直接返回 False
5. **计数重复**：确保每个同值子树只计数一次
