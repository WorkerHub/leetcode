## 题目描述

给你一个二进制字符串数组 `strs` 和两个整数 `m` 和 `n`。

请你找出并返回 `strs` 的最大子集的长度，该子集中最多有 `m` 个 `0` 和 `n` 个 `1`。

如果 `x` 的所有元素也是 `y` 的元素，集合 `x` 是集合 `y` 的子集。

**示例 1：**
```
输入：strs = ["10","0001","111001","1","0"], m = 5, n = 3
输出：4
解释：最多有 5 个 0 和 3 个 1 的最大子集是 {"10","0001","1","0"}，因此答案是 4。
其他满足题意但较小的子集包括 {"0001","1"} 和 {"10","1","0"}。
{"111001"} 不满足题意，因为它含 4 个 1，大于 n 的值 3。
```

**示例 2：**
```
输入：strs = ["10","0","1"], m = 1, n = 1
输出：2
解释：最大的子集是 {"0", "1"}，所以答案是 2。
```

**提示：**
- `1 <= strs.length <= 600`
- `1 <= strs[i].length <= 100`
- `strs[i]` 仅由 `'0'` 和 `'1'` 组成
- `1 <= m, n <= 100`

## 解题思路

这是一道**二维背包问题**，是 0-1 背包的扩展。

**核心思想：**
- 传统背包：一个容量限制
- 本题：两个容量限制（0 的个数和 1 的个数）

**DP 定义：**
- `dp[i][j]` 表示最多有 i 个 0 和 j 个 1 时，最大子集的大小

**状态转移：**
- 对于每个字符串，统计其中 0 和 1 的个数
- 选择该字符串：`dp[i][j] = dp[i-zeros][j-ones] + 1`
- 不选择：`dp[i][j]` 保持不变

## Python 代码实现

### 方法一：二维 DP（推荐）⭐

```python
from typing import List

class Solution:
    def findMaxForm(self, strs: List[str], m: int, n: int) -> int:
        # dp[i][j] 表示最多 i 个 0 和 j 个 1 的最大子集大小
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for s in strs:
            # 统计当前字符串的 0 和 1 个数
            zeros = s.count('0')
            ones = s.count('1')
            
            # 倒序遍历，避免重复使用
            for i in range(m, zeros - 1, -1):
                for j in range(n, ones - 1, -1):
                    dp[i][j] = max(dp[i][j], dp[i-zeros][j-ones] + 1)
        
        return dp[m][n]
```

**关键：** 倒序遍历避免同一物品被多次使用

### 方法二：详细注释版

```python
from typing import List

class Solution:
    def findMaxForm(self, strs: List[str], m: int, n: int) -> int:
        # 初始化 DP 表
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 遍历每个字符串（物品）
        for s in strs:
            # 计算该字符串的"重量"（0 和 1 的个数）
            zeros = s.count('0')
            ones = s.count('1')
            
            # 背包遍历（倒序避免重复）
            for i in range(m, zeros - 1, -1):
                for j in range(n, ones - 1, -1):
                    # 选择 s：需要 zeros 个 0 和 ones 个 1
                    # 价值为 1（增加一个字符串）
                    dp[i][j] = max(dp[i][j], dp[i-zeros][j-ones] + 1)
        
        return dp[m][n]
```

## 复杂度分析

- 时间复杂度：O(len(strs) × m × n)
- 空间复杂度：O(m × n)

## 关键点总结

1. **二维背包：** 两个容量限制
2. **倒序遍历：** 保证每个物品只用一次
3. **状态转移：** `dp[i][j] = max(不选, 选)`
4. **计数：** 使用 `count()` 统计 0 和 1

## 易错点

1. **顺序遍历：** 会导致重复使用
   ```python
   # 错误
   for i in range(zeros, m + 1):
   
   # 正确
   for i in range(m, zeros - 1, -1):
   ```

2. **边界条件：** 从 m 到 zeros（不是 0）
