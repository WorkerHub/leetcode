## 题目描述

给你一个 `m x n` 的二维整数数组 `grid`。

按照以下规则遍历 `grid`：
- 从 `grid[0][0]` 出发
- 先向右遍历第一行，再向左遍历第二行（Z 字形）
- 每隔一个元素跳过（即只取下标为偶数的元素——0, 2, 4, ...）

返回遍历顺序下取到的元素列表。

**示例 1：**

```
输入：grid = [[1,2],[3,4]]
输出：[1,4]
解释：
遍历顺序：1->2->4->3（Z字形）
取下标 0,2：1,4
```

**示例 2：**

```
输入：grid = [[2,1],[2,1],[2,1]]
输出：[2,1,2]
解释：
Z字形遍历：2,1,1,2,2,1
取下标 0,2,4：2,1,2
```

**提示：**
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^5`
- `1 <= grid[i][j] <= 10^5`

## 解题思路

按 Z 字形遍历网格：
- 偶数行（0-indexed）从左到右
- 奇数行从右到左

将所有元素放入一个列表，再取下标为 0, 2, 4, ... 的元素。

## Python 代码实现

### 方法一：先 Z 字形生成序列，再取偶数下标（推荐）

```python
from typing import List

class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        sequence = []

        for row_idx, row in enumerate(grid):
            if row_idx % 2 == 0:
                # 偶数行：从左到右
                sequence.extend(row)
            else:
                # 奇数行：从右到左
                sequence.extend(reversed(row))

        # 取下标为偶数（0, 2, 4, ...）的元素
        return sequence[::2]
```

### 方法二：直接计算，不生成完整序列

```python
from typing import List

class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        result = []
        m, n = len(grid), len(grid[0])
        # 全局下标
        global_idx = 0

        for row_idx in range(m):
            if row_idx % 2 == 0:
                # 从左到右
                for col in range(n):
                    if global_idx % 2 == 0:
                        result.append(grid[row_idx][col])
                    global_idx += 1
            else:
                # 从右到左
                for col in range(n - 1, -1, -1):
                    if global_idx % 2 == 0:
                        result.append(grid[row_idx][col])
                    global_idx += 1

        return result
```

### 方法三：利用列切片

```python
from typing import List

class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        result = []
        # 追踪当前取偶数还是奇数列
        # 由于每行 n 列，行 0 取 0,2,4,...；行 1 反向后也取 0,2,4,...（全局）
        # 全局偶数下标取决于 n 的奇偶性

        take = True  # 当前是否取该元素
        for row_idx, row in enumerate(grid):
            if row_idx % 2 == 0:
                cols = row
            else:
                cols = row[::-1]

            for val in cols:
                if take:
                    result.append(val)
                take = not take

        return result
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)（存储序列），若不算输出则 O(1)

## 关键点总结

1. Z 字形：偶数行从左到右，奇数行从右到左
2. 取全局遍历序列中下标为偶数（0, 2, 4, ...）的元素
3. 方法三用 `take` 变量追踪当前是否应取，避免生成完整序列

## 易错点

1. 行下标的奇偶决定方向（0-indexed：0 为偶数行从左到右）
2. "每隔一个跳过"是全局下标的偶数，不是每行内的偶数
3. 当 n 为奇数时，一行结束后，下一行的起始元素的全局奇偶性会改变
