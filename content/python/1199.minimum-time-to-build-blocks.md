## 题目描述

给定一个长度为 n 的数组 `blocks`，其中 `blocks[i]` 表示建造第 i 个街区需要的时间。

你最开始只有一个工人。工人可以执行以下两种操作之一：

1. **分裂成两个工人**：耗时 `split` 个单位时间，工人数量增加 1
2. **建造一个街区**：耗时 `blocks[i]` 个单位时间，然后该工人完成任务离开

注意：如果两个工人同时分裂，它们是并行分裂的，因此总耗时是 `split`（而不是 2×split）。

返回建造所有街区所需的最少时间。

**示例 1：**
```
输入：blocks = [1], split = 1
输出：1
解释：我们用 1 个工人建造 1 个街区，耗时 1 个单位。
```

**示例 2：**
```
输入：blocks = [1,2], split = 5
输出：7
解释：
我们先将工人分裂成 2 个工人，耗时 5 个单位。
然后让两个工人分别建造两个街区，耗时 max(1, 2) = 2。
总耗时 5 + 2 = 7。
```

**示例 3：**
```
输入：blocks = [1,2,3], split = 1
输出：4
解释：
第一次分裂：1 个工人 → 2 个工人，耗时 1
第二次分裂：其中 1 个工人再分裂，耗时 1（并行进行）
最终 3 个工人分别建造 3 个街区，耗时 max(1,2,3) = 3
总耗时 1 + 1 + 3 = 4
```

**提示：**
- 1 <= blocks.length <= 1000
- 1 <= blocks[i] <= 10^5
- 1 <= split <= 100

## 解题思路

这道题的核心是**哈夫曼编码（Huffman Coding）**的思想。

### 关键观察

1. **建造时间并行**：多个工人同时建造，总时间取决于最慢的那个
2. **分裂时间累加**：每次分裂都会增加总时间
3. **最优策略**：让建造时间长的街区尽早分配工人（减少等待时间）

### 哈夫曼树的思想

把问题建模为构建一棵二叉树：
- **叶子节点**：代表建造某个街区（耗时 blocks[i]）
- **内部节点**：代表分裂操作（耗时 split）
- **从根到叶子的路径长度**：代表该街区需要经历的分裂次数

目标：最小化总时间 = 分裂总耗时 + 最大建造时间

**核心思路**：
- 每次合并两个**最小的**时间（街区或已分裂的子树）
- 合并耗时 = split + max(left, right)
- 最终得到的根节点值就是最小总时间

### 为什么是哈夫曼树？

哈夫曼树保证了：
- 建造时间长的街区在树中深度浅（分裂次数少）
- 建造时间短的街区在树中深度深（可以承受更多分裂）
- 这样能使总时间最小化

## Python 代码实现

### 方法一：最小堆（哈夫曼树，推荐）

```python
from typing import List
import heapq

class Solution:
    def minBuildTime(self, blocks: List[int], split: int) -> int:
        """
        使用哈夫曼树思想：
        1. 将所有建造时间放入最小堆
        2. 每次取出两个最小的时间
        3. 合并：split + max(time1, time2)
        4. 将合并结果放回堆
        5. 最后堆中剩余的元素就是答案
        """
        # 将所有街区建造时间放入最小堆
        heap = blocks[:]
        heapq.heapify(heap)
        
        # 不断合并，直到只剩一个元素
        while len(heap) > 1:
            # 取出两个最小的时间
            time1 = heapq.heappop(heap)
            time2 = heapq.heappop(heap)
            
            # 合并：需要先分裂（耗时split），然后并行建造（耗时max）
            merged_time = split + max(time1, time2)
            
            # 将合并后的时间放回堆
            heapq.heappush(heap, merged_time)
        
        return heap[0]
```

### 方法二：排序 + 贪心

```python
from typing import List

class Solution:
    def minBuildTime(self, blocks: List[int], split: int) -> int:
        """
        先排序，从小到大合并
        """
        blocks.sort()
        
        while len(blocks) > 1:
            # 取出两个最小的
            time1 = blocks.pop(0)
            time2 = blocks.pop(0)
            
            # 合并并插入到正确位置（保持有序）
            merged = split + max(time1, time2)
            
            # 二分插入保持有序
            import bisect
            bisect.insort(blocks, merged)
        
        return blocks[0]
```

### 方法三：递归 + 记忆化（理解用）

```python
from typing import List
from functools import lru_cache

class Solution:
    def minBuildTime(self, blocks: List[int], split: int) -> int:
        """
        递归思路：
        对于 n 个街区，选择一个分割点 k
        - 前 k 个街区分配给左子树
        - 后 n-k 个街区分配给右子树
        - 总时间 = split + max(左子树时间, 右子树时间)
        """
        blocks.sort()
        n = len(blocks)
        
        @lru_cache(None)
        def dfs(start: int, end: int) -> int:
            """计算 blocks[start:end+1] 的最小建造时间"""
            if start == end:
                return blocks[start]
            
            min_time = float('inf')
            # 尝试所有可能的分割点
            for k in range(start, end):
                left_time = dfs(start, k)
                right_time = dfs(k + 1, end)
                # 需要先分裂，然后两边并行建造
                total_time = split + max(left_time, right_time)
                min_time = min(min_time, total_time)
            
            return min_time
        
        return dfs(0, n - 1)
```

### 方法四：优先队列（详细注释版）

```python
from typing import List
import heapq

class Solution:
    def minBuildTime(self, blocks: List[int], split: int) -> int:
        """
        哈夫曼树完整实现
        """
        # Step 1: 构建最小堆
        heap = blocks[:]
        heapq.heapify(heap)
        
        # Step 2: 自底向上构建哈夫曼树
        while len(heap) > 1:
            # 取出两个权重最小的节点
            left = heapq.heappop(heap)   # 最小的
            right = heapq.heappop(heap)  # 次小的
            
            # 创建父节点：
            # - 需要先花费 split 时间分裂出两个工人
            # - 两个工人并行工作，总时间取决于较慢的那个
            # - 父节点的权重 = split + max(left, right)
            parent = split + max(left, right)
            
            # 将父节点放回堆中
            heapq.heappush(heap, parent)
        
        # Step 3: 最后剩下的就是根节点，即最小总时间
        return heap[0]
```

## 复杂度分析

**最小堆方法：**
- **时间复杂度：** O(n log n)
  - 建堆：O(n)
  - n-1 次合并，每次 2 个 pop + 1 个 push：O(log n)
  - 总共 O(n log n)
- **空间复杂度：** O(n)，堆的空间

**排序方法：**
- **时间复杂度：** O(n² log n)
  - 初始排序：O(n log n)
  - n-1 次合并，每次插入：O(n)
  - 总共 O(n²)
- **空间复杂度：** O(1)

**递归方法：**
- **时间复杂度：** O(n³) 或更差（取决于剪枝）
- **空间复杂度：** O(n²)，记忆化缓存

## 关键点总结

1. **哈夫曼树思想**：这是经典的哈夫曼编码问题，最小化带权路径长度
2. **贪心策略**：总是合并最小的两个时间，保证最优
3. **并行理解**：多个工人同时工作，时间取 max 而不是 sum
4. **分裂成本**：每次合并都要加上 split 成本
5. **堆的应用**：用最小堆高效维护当前最小值

## 易错点

1. **理解并行**：工人是并行建造，不是串行，所以是 max 不是 sum
2. **合并公式**：合并后的时间是 `split + max(t1, t2)`，不要忘记加 split
3. **循环终止条件**：堆中剩余 1 个元素时停止，而不是 0 个
4. **初始化堆**：要复制数组 `blocks[:]`，不要直接修改原数组
5. **排序方法效率**：排序 + 插入的方法效率较低，不推荐

## 图解示例

以 `blocks = [1,2,3], split = 1` 为例：

```
初始堆: [1, 2, 3]

第一次合并:
  取出 1, 2
  合并: 1 + max(1,2) = 3
  堆: [3, 3]

第二次合并:
  取出 3, 3
  合并: 1 + max(3,3) = 4
  堆: [4]

结果: 4

对应的二叉树结构:
        4 (split=1)
       / \
      /   \
    3(3)  3(split=1)
           / \
         1(1) 2(2)

解释：
- 从根到叶子的路径代表分裂次数
- 叶子 1 和 2 需要 1 次分裂
- 叶子 3 不需要分裂（直接建造）
- 总时间 = 1(分裂) + 1(分裂) + max(1,2,3) = 4
```
