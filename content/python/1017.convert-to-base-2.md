## 题目描述

给定一个整数 `n`，返回它在 **base -2** 下的字符串表示。

注意：返回的字符串不能有前导零，除非字符串就是 `"0"`。

**示例 1：**
```
输入：n = 2
输出："110"
解释：(-2)² + (-2)¹ = 4 + (-2) = 2
```

**示例 2：**
```
输入：n = 3
输出："111"
解释：(-2)² + (-2)¹ + (-2)⁰ = 4 + (-2) + 1 = 3
```

**示例 3：**
```
输入：n = 4
输出："100"
解释：(-2)² = 4
```

**约束条件：**
- `0 <= n <= 10⁹`

## 解题思路

这道题要求将十进制数转换为 -2 进制数。与普通的进制转换不同，这里的基数是负数 -2。

### 核心思想

1. **普通进制转换回顾**：对于正数基数 `k`，我们不断除以 `k`，取余数作为当前位，商作为下一轮的被除数。

2. **负数基数的特殊性**：当基数为负数时，标准的除法和取余规则会产生负数余数，这不符合我们的需求（每一位应该是 0 或 1）。

3. **关键观察**：
   - 在 -2 进制中，每一位的系数只能是 0 或 1
   - 位置 `i` 的值是 `(-2)^i`
   - 偶数位（0, 2, 4...）的权重是正数：1, 4, 16...
   - 奇数位（1, 3, 5...）的权重是负数：-2, -8, -32...

4. **算法流程**：
   - 当 `n = 0` 时，直接返回 `"0"`
   - 重复以下步骤直到 `n = 0`：
     - 计算余数 `r = n % (-2)`
     - 计算商 `q = n // (-2)`
     - 如果余数为负（-1），需要调整：余数变为 1，商加 1
     - 将余数添加到结果中
     - 更新 `n = q`
   - 最后将结果反转

### 为什么需要调整？

在 Python 中，`n % (-2)` 可能得到 `-1` 或 `0`。但在 -2 进制表示中，每一位只能是 0 或 1。

当余数为 -1 时：
- `n = q * (-2) + (-1)`
- 转换为：`n = (q + 1) * (-2) + 1`
- 所以当前位应该是 1，商应该是 `q + 1`

## Python 代码实现

### 方法一：数学除法调整法（推荐）

```python
class Solution:
    def baseNeg2(self, n: int) -> str:
        """
        使用除法和取余，处理负数基数的特殊情况
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        # 特殊情况：0 的表示
        if n == 0:
            return "0"
        
        result = []
        
        # 不断除以 -2，直到 n 为 0
        while n:
            # 计算余数和商
            remainder = n % (-2)
            quotient = n // (-2)
            
            # 如果余数是 -1，需要调整为 1
            # 此时商需要加 1
            if remainder == -1:
                remainder = 1
                quotient += 1
            
            # 将当前位添加到结果
            result.append(str(remainder))
            
            # 更新 n 为商
            n = quotient
        
        # 反转结果（因为我们是从低位到高位计算的）
        return ''.join(reversed(result))
```

### 方法二：位运算优化法

```python
class Solution:
    def baseNeg2(self, n: int) -> str:
        """
        使用位运算技巧，利用负数基数的性质
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        if n == 0:
            return "0"
        
        result = []
        
        while n:
            # 取最低位
            result.append(str(n & 1))
            
            # 右移一位，但因为是 -2 进制，需要特殊处理
            # n = (n - (n & 1)) / (-2)
            # 简化为：n = -(n >> 1)
            n = -(n >> 1)
        
        return ''.join(reversed(result))
```

### 方法三：通用进制转换法

```python
class Solution:
    def baseNeg2(self, n: int) -> str:
        """
        通用的负数基数转换算法
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        if n == 0:
            return "0"
        
        base = -2
        result = []
        
        while n:
            # 使用 divmod 同时获取商和余数
            quotient, remainder = divmod(n, base)
            
            # 确保余数非负
            if remainder < 0:
                remainder -= base  # remainder += 2
                quotient += 1
            
            result.append(str(remainder))
            n = quotient
        
        return ''.join(reversed(result))
```

## 复杂度分析

### 方法一、二、三：

- **时间复杂度**：O(log n)
  - 每次迭代将 n 减少约一半
  - 迭代次数为 O(log₂ n)

- **空间复杂度**：O(log n)
  - 需要存储结果字符串，长度为 O(log n)

## 图解示例

以 `n = 6` 为例，展示转换过程：

```
初始：n = 6

第一步：
  6 ÷ (-2) = -3 余 0
  当前位：0
  n = -3

第二步：
  -3 ÷ (-2) = 1 余 -1
  调整：余数 -1 → 1，商 1 → 2
  当前位：1
  n = 2

第三步：
  2 ÷ (-2) = -1 余 0
  当前位：0
  n = -1

第四步：
  -1 ÷ (-2) = 0 余 -1
  调整：余数 -1 → 1，商 0 → 1
  当前位：1
  n = 1

第五步：
  1 ÷ (-2) = 0 余 1
  当前位：1
  n = 0

结果（反转）：11010

验证：(-2)⁴ + (-2)³ + (-2)¹ = 16 + (-8) + (-2) = 6 ✓
```

## 关键点总结

1. **负数基数的余数调整**：当余数为负时，需要调整为非负值（0 或 1），同时商加 1

2. **位权理解**：-2 进制中，偶数位是正权重，奇数位是负权重

3. **结果反转**：从低位到高位计算，最后需要反转字符串

4. **特殊值处理**：n = 0 时直接返回 "0"

5. **位运算技巧**：方法二利用了 `n = -(n >> 1)` 的等价关系，更加简洁

## 易错点

1. **忘记调整负余数**
   ```python
   # 错误写法
   remainder = n % (-2)
   result.append(str(remainder))  # 可能添加 -1
   
   # 正确写法
   if remainder == -1:
       remainder = 1
       quotient += 1
   ```

2. **忘记反转结果**
   - 计算是从低位到高位，但表示是从高位到低位

3. **特殊情况处理**
   - 忘记处理 n = 0 的情况

4. **商的更新错误**
   - 调整余数时，必须同时调整商

5. **Python 的除法规则**
   - Python 的 `//` 和 `%` 对负数的处理与其他语言不同，需要注意
