## 题目描述

给你一个正整数 `n`，描述一个三角形：第 `i` 行有 `2i - 1` 个三角形单元格（从 1 到 2i-1 编号）。

你需要找出一个将最小数量的单元格涂成红色的方案，使得三角形没有一个全为红色的向上朝向的三角形（由 3 个相邻单元格组成）。

返回涂红单元格的列表 `[row, col]`。

**数据范围：**
- 1 <= n <= 1000

## 解题思路

观察规律：每 4 行为一个循环，对每组 4 行有固定的染色模式。

行的三角形格子分为奇数格（向上朝向）和偶数格（向下朝向）。需要保证没有三个相邻向上朝向的格子都是红色。

**规律**（0-indexed 行，从第 1 行开始）：
- 每 4 行一个周期：
  - 第 1 行：奇数格全涂（1, 3, 5...）
  - 第 2 行：最后 2 个格涂（即 2i-2, 2i-1）
  - 第 3 行：1 个格涂（1）
  - 第 4 行：什么都不涂

实际模式（从行 1 开始）：
- 每 4 行：行 r 的图案

## Python 代码实现

### 方法一：规律枚举

```python
from typing import List

class Solution:
    def colorRed(self, n: int) -> List[List[int]]:
        ans = []

        # 最后一行处理
        # 对每行从下往上分析
        # 规律（1-indexed 行）：
        # r % 4 == 1：涂奇数列（1, 3, 5, ..., 2r-1）
        # r % 4 == 2：涂最后两列（2r-2, 2r-1）
        # r % 4 == 3：涂第 1 列
        # r % 4 == 0：不涂

        # 从最后一行到第一行处理
        for r in range(n, 0, -1):
            remainder = (n - r) % 4  # 从底部算起的偏移
            if remainder == 0:
                # 涂奇数列
                for c in range(1, 2 * r, 2):
                    ans.append([r, c])
            elif remainder == 1:
                # 涂最后两列
                cols = 2 * r - 1
                ans.append([r, cols - 1])
                ans.append([r, cols])
            elif remainder == 2:
                # 涂第 1 列
                ans.append([r, 1])
            # remainder == 3：不涂

        return ans
```

### 方法二：直接按行计算

```python
from typing import List

class Solution:
    def colorRed(self, n: int) -> List[List[int]]:
        ans = []

        # 根据每行的 (n - r) % 4 决定染色方案
        for r in range(1, n + 1):
            mod = (n - r) % 4
            if mod == 0:
                # 涂所有奇数列
                for c in range(1, 2 * r, 2):
                    ans.append([r, c])
            elif mod == 1:
                # 涂最后两列
                total_cols = 2 * r - 1
                if total_cols >= 2:
                    ans.append([r, total_cols - 1])
                ans.append([r, total_cols])
            elif mod == 2:
                # 只涂第一列
                ans.append([r, 1])
            # mod == 3: 不涂

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2)，最多每格涂一次，总格数 O(n^2)
- 空间复杂度：O(n^2)，输出结果

## 关键点总结

1. 以 4 行为周期，根据距底部的偏移确定染色模式
2. 需要验证该方案确实满足：没有全红色的向上三角形
3. 从底行向上确定偏移量更直观

## 易错点

1. 行和列都是 1-indexed
2. 第 r 行有 2r-1 个格子（1 到 2r-1）
3. 奇数格为向上三角，偶数格为向下三角
