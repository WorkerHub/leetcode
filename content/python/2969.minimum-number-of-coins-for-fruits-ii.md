## 题目描述

给你一个整数数组 `prices`（1-indexed），其中 `prices[i]` 是第 `i` 种水果的价格。

若你购买第 `i` 种水果，可以免费获得之后的 `i` 种水果（即第 i+1 到 i+i 种免费）。

返回购买所有 n 种水果所需的最少花费。

**提示：**
- `1 <= prices.length <= 10^6`
- `1 <= prices[i] <= 10^15`

## 解题思路

与第 2944 题相同，但 n 达到 10^6，需要 O(n) 或 O(n log n) 解法（方法二单调队列 O(n)）。

定义 `dp[i]` 为获得前 i 种水果的最小花费。

对于 dp[i]，需要找 j in [ceil(i/2), i] 使 dp[j-1] + prices[j-1] 最小。

使用单调队列（deque）维护这个滑动窗口最小值，窗口范围随 i 的增大同步移动。

## Python 代码实现

### 方法一：单调队列（推荐，O(n)）

```python
from typing import List
from collections import deque

class Solution:
    def minimumCoins(self, prices: List[int]) -> int:
        n = len(prices)
        # dp[i] = 获得前 i 种水果的最小花费（1-indexed，dp[0]=0）
        # dp[i] = min(dp[j-1] + prices[j-1]) for j in [ceil(i/2), i]
        # = min(dp[j-1] + prices[j-1]) for j-1 in [(i+1)//2 - 1, i-1]
        # = min(dp[j] + prices[j]) for j in [(i-1)//2, i-1]  # 0-indexed dp, prices

        # 单调队列：deque 存 (dp[j] + prices[j], j)
        # 窗口为 j in [ceil(i/2)-1, i-1]，即 j in [(i-1)//2, i-1]

        dp = [0] * (n + 1)
        dq = deque()  # (cost, j) where j is 0-indexed

        # 初始化：j=0 对应 dp[0] + prices[0]
        # 但 dp 是 1-indexed，重新定义：
        # dp[i]（1-indexed）= min over j in [ceil(i/2), i]: dp[j-1] + prices[j-1]
        # 等价：dp[i] = min over j in [(i+1)//2, i]: dp[j-1] + prices[j-1]

        # 使用 0-indexed：令 f[i] = dp[i] (i=0: 0, i=1..n: cost of first i fruits)
        # f[i] = min over j in [(i+1)//2, i]: f[j-1] + prices[j-1]
        # j 从 (i+1)//2 到 i，对应 j-1 从 (i-1)//2 到 i-1

        f = [0] * (n + 1)
        dq = deque()  # (f[j-1] + prices[j-1], j-1) = (f[k] + prices[k], k) where k = j-1

        # 当 i 从 1 到 n 时，窗口 k 从 (i-1)//2 到 i-1
        # 先加入 k = i-1，再移除 k < (i-1)//2 的

        for i in range(1, n + 1):
            # 加入 k = i-1（新的右端点）
            k = i - 1
            val = f[k] + prices[k]
            while dq and dq[-1][0] >= val:
                dq.pop()
            dq.append((val, k))

            # 移除左端不在窗口的元素：k < (i-1)//2
            lo = (i - 1) // 2
            while dq and dq[0][1] < lo:
                dq.popleft()

            f[i] = dq[0][0]

        return f[n]
```

### 方法二：使用 heapq（O(n log n)）

```python
from typing import List
import heapq

class Solution:
    def minimumCoins(self, prices: List[int]) -> int:
        n = len(prices)
        f = [0] * (n + 1)
        heap = []  # (cost, k)

        for i in range(1, n + 1):
            k = i - 1
            heapq.heappush(heap, (f[k] + prices[k], k))
            # 移除过期元素
            lo = (i - 1) // 2
            while heap[0][1] < lo:
                heapq.heappop(heap)
            f[i] = heap[0][0]

        return f[n]
```

## 复杂度分析

- 时间复杂度：O(n)（单调队列）；O(n log n)（堆）
- 空间复杂度：O(n)

## 关键点总结

1. 单调队列维护滑动窗口最小值，窗口范围 [(i-1)//2, i-1]
2. 先加右端，再移除左端过期元素
3. 单调递增队列（从前到后递增），队头是最小值

## 易错点

1. 窗口下界 `(i-1)//2`（Python 整数向下取整）
2. 1-indexed 与 0-indexed 的转换
3. 单调队列维护时先移右端（保持单调），再移左端（移除过期）
