## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

n 皇后问题研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n，返回所有不同的 n 皇后问题的解决方案。

**示例 1：**
```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
```

**示例 2：**
```
输入：n = 1
输出：[["Q"]]
```

**提示：**
- `1 <= n <= 9`

## 解题思路

核心思想：回溯 + 剪枝

**约束条件：**
1. 同一行只能有一个皇后
2. 同一列只能有一个皇后
3. 同一对角线只能有一个皇后

**对角线判断：**
- 主对角线：row - col 相同
- 副对角线：row + col 相同

## Python 代码实现

```python
from typing import List

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        result = []
        board = [['.'] * n for _ in range(n)]
        cols = set()
        diag1 = set()  # row - col
        diag2 = set()  # row + col
        
        def backtrack(row: int):
            if row == n:
                # 找到一个解
                result.append([''.join(r) for r in board])
                return
            
            for col in range(n):
                # 检查是否可以放置
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                
                # 放置皇后
                board[row][col] = 'Q'
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                
                # 递归下一行
                backtrack(row + 1)
                
                # 撤销选择
                board[row][col] = '.'
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)
        
        backtrack(0)
        return result
```

## 复杂度分析

- 时间复杂度：O(n!)
- 空间复杂度：O(n)

## 关键点总结

1. **回溯框架**：逐行放置皇后
2. **剪枝条件**：检查列和对角线
3. **对角线公式**：row±col

## 易错点

1. **对角线判断**：主对角线和副对角线的公式
2. **状态恢复**：回溯时要撤销所有状态
