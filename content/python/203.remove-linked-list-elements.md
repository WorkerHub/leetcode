## 题目描述

给你一个链表的头节点 `head` 和一个整数 `val`，请你删除链表中所有满足 `Node.val == val` 的节点，并返回 **新的头节点**。

**示例 1：**
```
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]
```

**示例 2：**
```
输入：head = [], val = 1
输出：[]
```

**示例 3：**
```
输入：head = [7,7,7,7], val = 7
输出：[]
```

**提示：**
- 列表中的节点数目在范围 `[0, 10^4]` 内
- `1 <= Node.val <= 50`
- `0 <= val <= 50`

## 解题思路

这道题是链表删除操作的经典题目。关键在于处理以下情况：

1. **头节点需要删除**：可能有多个连续的头节点需要删除
2. **中间节点删除**：需要修改前驱节点的 next 指针
3. **所有节点都删除**：返回 None

### 核心思路

**删除链表节点的标准操作**：
```
prev.next = prev.next.next
```

**难点**：头节点没有前驱节点，需要特殊处理。

### 解决方案

1. **虚拟头节点（哨兵节点）**：创建一个虚拟节点指向 head，统一处理
2. **递归**：递归处理子链表，简洁优雅
3. **迭代**：直接遍历处理

## Python 代码实现

### 方法一：虚拟头节点（推荐）⭐

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeElements(self, head: ListNode, val: int) -> ListNode:
        # 创建虚拟头节点，简化边界处理
        dummy = ListNode(0)
        dummy.next = head
        
        # 当前节点从虚拟头节点开始
        curr = dummy
        
        # 遍历链表
        while curr.next:
            if curr.next.val == val:
                # 删除下一个节点
                curr.next = curr.next.next
            else:
                # 移动到下一个节点
                curr = curr.next
        
        # 返回新的头节点
        return dummy.next
```

**代码说明**：
- **虚拟头节点**：dummy 节点的作用是统一处理头节点和其他节点
- **curr.next**：始终检查下一个节点，而不是当前节点
- **删除操作**：`curr.next = curr.next.next` 跳过要删除的节点
- **不移动指针**：删除后不移动 curr，因为新的 curr.next 还需要检查

### 方法二：递归实现⭐

```python
class Solution:
    def removeElements(self, head: ListNode, val: int) -> ListNode:
        # 递归终止条件
        if not head:
            return None
        
        # 递归处理后续链表
        head.next = self.removeElements(head.next, val)
        
        # 判断当前节点是否需要删除
        return head.next if head.val == val else head
```

**代码说明**：
- **递归思路**：先处理后面的链表，再处理当前节点
- **返回值**：如果当前节点需要删除，返回 head.next；否则返回 head
- **优势**：代码简洁，逻辑清晰
- **劣势**：递归深度受链表长度限制，可能栈溢出

### 方法三：不使用虚拟头节点

```python
class Solution:
    def removeElements(self, head: ListNode, val: int) -> ListNode:
        # 处理头节点
        while head and head.val == val:
            head = head.next
        
        # 如果链表为空，直接返回
        if not head:
            return None
        
        # 处理后续节点
        curr = head
        while curr.next:
            if curr.next.val == val:
                curr.next = curr.next.next
            else:
                curr = curr.next
        
        return head
```

**代码说明**：
- **分两步**：先处理头节点，再处理其他节点
- **头节点处理**：用 while 循环删除所有值为 val 的头节点
- **代码较长**：需要单独处理头节点的边界情况

### 方法四：Python 函数式风格（仅用于理解）

```python
class Solution:
    def removeElements(self, head: ListNode, val: int) -> ListNode:
        # 转为列表
        values = []
        curr = head
        while curr:
            if curr.val != val:
                values.append(curr.val)
            curr = curr.next
        
        # 重建链表
        dummy = ListNode(0)
        curr = dummy
        for value in values:
            curr.next = ListNode(value)
            curr = curr.next
        
        return dummy.next
```

**注意**：这种方法创建了新的链表，不是原地修改，仅用于理解思路。

## 复杂度分析

### 方法一：虚拟头节点
- **时间复杂度**：O(n)，遍历一次链表
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法二：递归
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(n)，递归调用栈的深度

### 方法三：不使用虚拟头节点
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **虚拟头节点技巧**：统一处理头节点和其他节点，避免特殊判断
2. **指针操作**：删除节点时，修改前驱节点的 next 指针
3. **循环条件**：使用 `while curr.next` 而不是 `while curr`
4. **递归思路**：先处理子问题，再处理当前问题
5. **边界情况**：空链表、所有节点都删除、头节点删除

## 易错点

1. **忘记处理头节点**：头节点也可能需要删除，不使用虚拟头节点时容易出错
2. **指针移动时机**：删除节点后不应该移动指针（因为新的 next 还需要检查）
3. **空指针异常**：访问 `curr.next.val` 前要确保 `curr.next` 不为空
4. **返回值错误**：应该返回 `dummy.next` 而不是 `head`（head 可能被删除）
5. **递归栈溢出**：链表很长时，递归可能导致栈溢出
