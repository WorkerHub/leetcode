## 题目描述

给你一个以字符串表示的非负整数 num 和一个整数 k，移除这个数中的 k 位数字，使得剩下的数字最小。请你返回这个最小的数字。

**示例 1：**
```
输入：num = "1432219", k = 3
输出："1219"
解释：移除掉三个数字 4, 3, 和 2 形成一个新的最小的数字 1219。
```

**示例 2：**
```
输入：num = "10200", k = 1
输出："200"
解释：移掉首位的 1 剩下的数字为 200，注意输出不能有任何前导零。
```

**示例 3：**
```
输入：num = "10", k = 2
输出："0"
解释：从原数字移除所有的数字，剩余为空就是 0。
```

**提示：**
- 1 <= k <= num.length <= 10^5
- num 仅由若干位数字（0 - 9）组成
- 除了 0 本身之外，num 不含任何前导零

## 解题思路

这是一道经典的贪心 + 单调栈问题。

核心思想：
1. 从左到右遍历数字，要使结果最小，应该让高位尽可能小
2. 如果当前数字比前一个数字小，就应该移除前一个数字
3. 使用单调栈维护一个递增序列

算法流程：
1. 使用栈存储结果数字
2. 遍历每个数字：
   - 如果栈顶元素大于当前数字且还能删除（k > 0），就删除栈顶
   - 将当前数字入栈
3. 如果还有剩余删除次数，从末尾删除
4. 处理前导零
5. 处理空字符串的情况

## Python 代码实现

### 方法一：单调栈（推荐）

```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        """
        使用单调栈维护递增序列
        贪心策略：从左到右，遇到递减的位置就删除较大的数字
        """
        stack = []
        remain = k  # 剩余需要删除的数字个数
        
        for digit in num:
            # 当栈不为空，还有删除次数，且栈顶元素大于当前数字时
            # 删除栈顶元素（贪心：让高位尽可能小）
            while stack and remain > 0 and stack[-1] > digit:
                stack.pop()
                remain -= 1
            
            stack.append(digit)
        
        # 如果还有剩余删除次数，从末尾删除
        # 例如 "123456", k=3 -> "123"
        if remain > 0:
            stack = stack[:-remain]
        
        # 去除前导零，转换为字符串
        result = ''.join(stack).lstrip('0')
        
        # 如果结果为空，返回 "0"
        return result if result else '0'
```

### 方法二：单调栈（详细注释版）

```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        """
        单调栈详细实现
        """
        if k >= len(num):
            return '0'
        
        stack = []
        
        for i, digit in enumerate(num):
            # 贪心策略：
            # 1. 栈不为空
            # 2. 还有删除机会（k > 0）
            # 3. 栈顶元素大于当前元素（删除栈顶可以让结果更小）
            while stack and k > 0 and stack[-1] > digit:
                stack.pop()
                k -= 1
            
            # 避免前导零：只有栈不为空或当前数字不为 '0' 时才入栈
            # 但这样会漏掉 "0" 的情况，所以不推荐
            stack.append(digit)
        
        # 如果 k 还大于 0，说明剩余数字是递增的
        # 例如 "123", k=1，应该删除最后一位得到 "12"
        while k > 0:
            stack.pop()
            k -= 1
        
        # 转换为字符串并去除前导零
        result = ''.join(stack).lstrip('0')
        
        return result if result else '0'
```

### 方法三：字符串操作

```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        """
        直接使用字符串列表操作
        """
        result = []
        
        for digit in num:
            # 当满足条件时，不断删除结果中的最后一个字符
            while result and k and result[-1] > digit:
                result.pop()
                k -= 1
            result.append(digit)
        
        # 处理剩余的 k
        result = result[:len(result) - k] if k else result
        
        # 去掉前导零
        ans = ''.join(result).lstrip('0')
        
        return ans or '0'
```

### 方法四：使用 deque

```python
from collections import deque

class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        """
        使用双端队列实现
        """
        queue = deque()
        
        for digit in num:
            while queue and k > 0 and queue[-1] > digit:
                queue.pop()
                k -= 1
            queue.append(digit)
        
        # 删除剩余的 k 个数字
        for _ in range(k):
            if queue:
                queue.pop()
        
        # 去除前导零
        while queue and queue[0] == '0':
            queue.popleft()
        
        return ''.join(queue) if queue else '0'
```

## 复杂度分析

- **时间复杂度**：O(n)
  - 每个数字最多入栈一次，出栈一次
  - 去除前导零的时间复杂度为 O(n)
  
- **空间复杂度**：O(n)
  - 栈的空间复杂度为 O(n)

## 图解示例

以 `num = "1432219", k = 3` 为例：

```
初始：stack = [], k = 3

遍历 '1': stack = ['1']

遍历 '4': stack = ['1', '4']

遍历 '3': 
  - '4' > '3'，删除 '4'，k = 2
  - stack = ['1', '3']

遍历 '2':
  - '3' > '2'，删除 '3'，k = 1
  - stack = ['1', '2']

遍历 '2':
  - '2' == '2'，不删除
  - stack = ['1', '2', '2']

遍历 '1':
  - '2' > '1'，删除 '2'，k = 0
  - stack = ['1', '2', '1']

遍历 '9':
  - k = 0，不能再删除
  - stack = ['1', '2', '1', '9']

结果：1219
```

## 关键点总结

1. **贪心策略**：从高位到低位，尽可能让每一位都最小
2. **单调栈思想**：维护一个递增的栈，遇到更小的数字就删除前面较大的
3. **边界处理**：
   - 删除次数用完后的处理
   - 前导零的处理
   - 结果为空的处理
4. **时间优化**：每个元素最多入栈、出栈各一次

## 易错点

1. **前导零处理**：
   - 正确：使用 `lstrip('0')` 去除前导零
   - 错误：在入栈时就过滤 '0'（会导致 "10", k=1 输出空而不是 "0"）

2. **剩余删除次数**：
   - 遍历完后如果 k > 0，需要从末尾继续删除
   - 例如 "12345", k=3，遍历完栈为 ['1','2','3','4','5']，需删除后 3 位

3. **空结果处理**：
   - 当所有数字都被删除时，应返回 "0" 而不是空字符串
   - 例如 "10", k=2 应返回 "0"

4. **字符比较**：
   - 字符串的比较是字典序比较，'9' > '1' 是正确的
   - 不需要转换为整数

## 学习建议

1. **理解贪心策略**：
   - 为什么从高位开始删除？因为高位对数值的影响更大
   - 为什么要删除较大的数字？因为要让结果最小

2. **掌握单调栈**：
   - 单调栈是解决这类问题的标准工具
   - 练习识别何时使用单调栈（通常涉及"下一个更大/更小"元素）

3. **边界情况**：
   - 总是考虑极端情况：全删除、不删除、全是相同数字

4. **Python 技巧**：
   - `lstrip('0')` 去除左侧字符
   - `''.join(list)` 列表转字符串
   - `list[:-k]` 删除后 k 个元素
