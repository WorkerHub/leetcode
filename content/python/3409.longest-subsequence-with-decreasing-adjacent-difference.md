## 题目描述

给你一个整数数组 `nums`。

你的任务是找到 `nums` 的最长**子序列**，满足该子序列中相邻元素的差的**绝对值**是非递增的。

即，若子序列为 `a[0], a[1], ..., a[k]`，则对所有 `i`，`|a[i+1] - a[i+2]| <= |a[i] - a[i+1]|`。

返回该子序列的最大长度。

**示例 1：**

```
输入：nums = [16,6,3]
输出：3
解释：子序列 [16,6,3]，差为 |16-6|=10, |6-3|=3，递减，合法
```

**示例 2：**

```
输入：nums = [6,5,3,4,2,1]
输出：4
解释：子序列 [6,3,2,1]，差为 3,1,1，非递增，合法
```

**提示：**
- `1 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`

## 解题思路

动态规划定义：
- `dp[i][d]` = 以 `nums[i]` 结尾，最后一个相邻差为 `d` 的最长子序列长度

转移：对于每个 `j < i`，令 `diff = |nums[i] - nums[j]|`，则：
`dp[i][diff] = max(dp[i][diff], dp[j][d'] + 1)`，其中 `d' >= diff`（上一个差大于等于当前差）

但这需要对每个 j 枚举所有 d' >= diff，复杂度过高。

**优化**：将 `dp[j]` 理解为：以 j 结尾，最后差为 d 的最长长度。我们想要的是 `max(dp[j][d'] for d' >= diff)`，即 j 结尾、最后差大于等于 diff 的最大长度。

改用后缀最大值：`best[j][d]` = 以 j 结尾且最后差 >= d 的最大长度。

实际上，对于每个 j，维护 `f[j]` 数组，其中 `f[j][d]` = 以 nums[j] 结尾、最后差恰为 d 的最大子序列长度。然后用后缀最大：`suf[j][d] = max(f[j][d], f[j][d+1], ...)`。

对于每个 i，枚举 j < i，令 `d = |nums[i] - nums[j]|`，更新 `f[i][d] = max(f[i][d], suf[j][d] + 1)`。

## Python 代码实现

### 方法一：DP + 后缀最大值优化（推荐）

```python
from typing import List

class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        n = len(nums)
        MAX_VAL = max(nums)

        # dp[i] 是一个数组，dp[i][d] 表示以 nums[i] 结尾且最后差为 d 的最长子序列
        # 为节省空间，使用字典
        # 但为了后缀最大值，用数组更方便

        # f[i] = 数组，f[i][d] = 以 nums[i] 结尾、最后差为 d 的最长子序列长度
        # 初始化：单独的元素，长度为 1，差可以是任意值（设为最大差范围内都是 1）
        # suf[i][d] = max(f[i][d], f[i][d+1], ..., f[i][MAX])

        # 简化：对每个 i，suf[i] 是 f[i] 的后缀最大值数组
        suf = []  # suf[i] 是长度为 MAX_VAL+2 的数组

        ans = 1

        for i in range(n):
            # 初始化 f_i：长度 MAX_VAL+2 的数组
            f_i = [0] * (MAX_VAL + 2)

            for j in range(i):
                d = abs(nums[i] - nums[j])
                # 以 nums[i] 结尾，最后差为 d，转移自 suf[j][d]
                val = suf[j][d] + 1
                if val > f_i[d]:
                    f_i[d] = val

            # 如果没有前驱，长度至少为 1
            for d in range(MAX_VAL + 2):
                if f_i[d] == 0:
                    f_i[d] = 1
                ans = max(ans, f_i[d])

            # 计算后缀最大值
            suf_i = f_i[:]
            for d in range(MAX_VAL - 1, -1, -1):
                suf_i[d] = max(suf_i[d], suf_i[d + 1])

            suf.append(suf_i)

        return ans
```

### 方法二：简化 DP（利用差值范围较小）

```python
from typing import List

class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return 1

        MAX_DIFF = max(nums)  # 最大差值不超过 max(nums)

        # dp[i][d]: 以 nums[i] 结尾，最后差恰好为 d 的最长子序列
        dp = [[1] * (MAX_DIFF + 2) for _ in range(n)]

        # 后缀最大值 suf[i][d] = max(dp[i][d..MAX_DIFF])
        suf = [None] * n
        suf[0] = dp[0][:]

        ans = 1

        for i in range(1, n):
            for j in range(i):
                d = abs(nums[i] - nums[j])
                # 从 j 转移：需要 j 处的最后差 >= d
                new_len = suf[j][d] + 1
                if new_len > dp[i][d]:
                    dp[i][d] = new_len
                    ans = max(ans, new_len)

            # 计算 suf[i]
            suf[i] = dp[i][:]
            for d in range(MAX_DIFF - 1, -1, -1):
                suf[i][d] = max(suf[i][d], suf[i][d + 1])

        return ans
```

## 复杂度分析

- 时间复杂度：O(n^2 + n * MAX_VAL)，其中 MAX_VAL 为数组最大值
- 空间复杂度：O(n * MAX_VAL)

## 关键点总结

1. 状态定义：`dp[i][d]` 表示以 nums[i] 结尾且最后差为 d 的最长子序列
2. 转移时需要前驱的"最后差 >= 当前差"，用后缀最大值优化
3. 后缀最大值 `suf[i][d] = max(dp[i][d], dp[i][d+1], ...)`

## 易错点

1. 初始情况下每个单独元素长度为 1，差值未定义（可认为差值为任意非负数）
2. 后缀最大值的方向要从大到小计算
3. MAX_DIFF 的范围要根据数据确定
