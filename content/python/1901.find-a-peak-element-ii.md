## 题目描述

给你一个下标从 **0** 开始的 `m x n` 矩阵 `mat`，其中任意两个相邻元素均不相等。从以下位置任选其一返回 `[i, j]`：

- `mat[i][j]` 严格大于其上下左右相邻元素（即是一个**峰值元素**）

**示例 1：**
```
输入：mat = [[1,4],[3,2]]
输出：[0,1]
解释：mat[0][1] = 4 是峰值，因为 4 > 1 且 4 > 2
```

**示例 2：**
```
输入：mat = [[10,20,15],[21,30,14],[7,16,32]]
输出：[1,1] 或 [2,2]
解释：mat[1][1] = 30 满足峰值条件
```

**提示：**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 500`
- `1 <= mat[i][j] <= 10^5`
- 相邻元素均不相等

---

## 解题思路

### 核心思想：对行进行二分查找

将问题转化为一维峰值查找：

1. 对行索引进行二分查找，取中间行 `mid`
2. 在 `mid` 行中找到最大值所在列 `max_col`
3. 比较 `mat[mid][max_col]` 与上下相邻元素：
   - 若 `mat[mid][max_col] > mat[mid+1][max_col]`，则峰值在 `[lo, mid]` 范围内
   - 否则峰值在 `[mid+1, hi]` 范围内

**为什么这样做？** 因为在 `mid` 行找到的列最大值，其左右已经满足条件（是该行最大值），只需要判断上下方向。通过二分可保证收敛到峰值所在行。

时间复杂度可从暴力 O(mn) 优化到 O(m log n) 或 O(n log m)。

## 代码实现

### 方法一：对行二分查找（推荐）

```python
from typing import List

class Solution:
    def findPeakGrid(self, mat: List[List[int]]) -> List[int]:
        m, n = len(mat), len(mat[0])
        lo, hi = 0, m - 1

        while lo < hi:
            mid = (lo + hi) // 2
            # 找当前行的最大值所在列
            max_col = mat[mid].index(max(mat[mid]))

            # 比较当前行最大值与下一行同列的值
            if mat[mid][max_col] > mat[mid + 1][max_col]:
                # 峰值在上半部分（包括 mid）
                hi = mid
            else:
                # 峰值在下半部分
                lo = mid + 1

        # lo 行就是峰值所在行，找该行最大值列
        max_col = mat[lo].index(max(mat[lo]))
        return [lo, max_col]
```

### 方法二：对列二分查找

```python
from typing import List

class Solution:
    def findPeakGrid(self, mat: List[List[int]]) -> List[int]:
        m, n = len(mat), len(mat[0])
        lo, hi = 0, n - 1

        while lo < hi:
            mid = (lo + hi) // 2
            # 找当前列的最大值所在行
            max_row = 0
            for i in range(m):
                if mat[i][mid] > mat[max_row][mid]:
                    max_row = i

            # 比较当前列最大值与右侧同行的值
            if mat[max_row][mid] > mat[max_row][mid + 1]:
                # 峰值在左半部分（包括 mid）
                hi = mid
            else:
                # 峰值在右半部分
                lo = mid + 1

        # 找 lo 列的最大值所在行
        max_row = 0
        for i in range(m):
            if mat[i][lo] > mat[max_row][lo]:
                max_row = i
        return [max_row, lo]
```

### 方法三：暴力枚举（对比学习）

```python
from typing import List

class Solution:
    def findPeakGrid(self, mat: List[List[int]]) -> List[int]:
        m, n = len(mat), len(mat[0])
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

        for i in range(m):
            for j in range(n):
                is_peak = True
                # 检查四个方向的邻居
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n:
                        if mat[ni][nj] >= mat[i][j]:
                            is_peak = False
                            break
                if is_peak:
                    return [i, j]
        return [-1, -1]
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（对行二分） | O(n log m) | O(1) |
| 方法二（对列二分） | O(m log n) | O(1) |
| 方法三（暴力） | O(mn) | O(1) |

---

## 关键点总结

1. 将二维峰值查找转化为对行/列的二分查找
2. 先在中间行找列最大值，再通过上下比较确定二分方向
3. 每次二分后，目标范围内一定存在峰值（单调性保证）
4. 最终收敛到一行后，该行的列最大值即为峰值

---

## 易错点

- 不要忘记最终返回时还需要再次查找列最大值
- 二分边界：`hi = mid` 而非 `hi = mid - 1`，因为 mid 行本身可能是峰值所在行
- 矩阵边界处理：二分时只比较到 `m-1` 行，不越界
