## 题目描述

给定一个正整数 `n`，返回最小的正整数，使得该整数的二进制表示中至少有 `n` 个置位（即二进制中值为 1 的位）。

**示例 1：**
```
输入：n = 1
输出：1
解释：1 的二进制为 "1"，有 1 个置位。
```

**示例 2：**
```
输入：n = 2
输出：3
解释：3 的二进制为 "11"，有 2 个置位。
```

**示例 3：**
```
输入：n = 4
输出：15
解释：15 的二进制为 "1111"，有 4 个置位，且 15 是满足条件的最小整数。
```

**提示：**
- `1 <= n <= 30`

## 解题思路

最小的含 n 个置位的正整数，就是将最低 n 位全部置为 1，其余位为 0。

数学公式：`2^n - 1`

例如：
- n=1：`2^1 - 1 = 1`（二进制：`1`）
- n=2：`2^2 - 1 = 3`（二进制：`11`）
- n=3：`2^3 - 1 = 7`（二进制：`111`）
- n=4：`2^4 - 1 = 15`（二进制：`1111`）

位运算实现：`(1 << n) - 1`，将 1 左移 n 位再减一，即低 n 位全部为 1。

## Python 代码实现

### 方法一：位运算（推荐）

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        # (1 << n) 将 1 左移 n 位，得到 2^n
        # 再减 1 使得低 n 位全部为 1
        return (1 << n) - 1
```

### 方法二：数学幂运算

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        # 2 的 n 次方减 1
        return 2 ** n - 1
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 最小的含 n 个置位的数，其二进制最低 n 位全为 1
2. `(1 << n) - 1` 是生成低 n 位全为 1 掩码的标准写法
3. Python 中整数没有溢出问题，n 最大为 30 时结果为 `2^30 - 1 = 1073741823`

## 易错点

1. 不要直接返回 `n`，这是置位数量，不是结果值
2. 注意 `1 << n` 而不是 `n << 1`（后者是将 n 左移一位）
