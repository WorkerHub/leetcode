## 题目描述

给定一个二维网格 grid ，其中：
- '.' 是一个空房间
- '#' 是一堵墙
- '@' 是起点
- 小写字母表示钥匙
- 大写字母表示锁

我们从起点开始，一步步走到网格中的所有钥匙。可以通过空房间和已有钥匙对应的锁。

返回获取 所有钥匙 的最短路径的步数。如果无法获取所有钥匙，返回 -1 。

**示例 1：**
```
输入：grid = ["@.a..", "###.#", "b.A.B"]
输出：8
解释：目标是获取所有钥匙，而不是打开所有锁。
```

**示例 2：**
```
输入：grid = ["@..aA", "..B#.", "....b"]
输出：6
```

**提示：**
- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 30
- grid[i][j] 只含有 '.', '#', '@', 'a'-'f' 以及 'A'-'F'
- 钥匙的数目范围是 [1, 6]

## 解题思路

这是一道**状态压缩 BFS** 的经典题目。

**核心难点：**
- 不能简单地用 (x, y) 表示状态
- 相同位置但持有不同钥匙是不同状态

**状态定义：**
- 状态 = (x, y, keys)
- keys 用二进制表示持有的钥匙集合
- 例如：keys = 0b101 表示持有钥匙 'a' 和 'c'

**算法流程：**
1. BFS 从起点 '@' 开始
2. 状态：(x, y, keys)，keys 是位掩码
3. 遇到钥匙：更新 keys
4. 遇到锁：检查是否有对应钥匙
5. 收集到所有钥匙时返回步数

## Python 代码实现

### 方法一：状态压缩 BFS（推荐）⭐

```python
class Solution:
    def shortestPathAllKeys(self, grid: List[str]) -> int:
        from collections import deque
        
        m, n = len(grid), len(grid[0])
        
        # 找到起点和钥匙总数
        start_x, start_y = 0, 0
        key_count = 0
        
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '@':
                    start_x, start_y = i, j
                elif grid[i][j].islower():
                    key_count += 1
        
        # 所有钥匙的状态
        all_keys = (1 << key_count) - 1
        
        # BFS: (x, y, keys)
        queue = deque([(start_x, start_y, 0, 0)])  # (x, y, keys, steps)
        visited = {(start_x, start_y, 0)}
        
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        
        while queue:
            x, y, keys, steps = queue.popleft()
            
            # 收集到所有钥匙
            if keys == all_keys:
                return steps
            
            # 四个方向
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                
                if not (0 <= nx < m and 0 <= ny < n):
                    continue
                
                cell = grid[nx][ny]
                
                # 墙
                if cell == '#':
                    continue
                
                new_keys = keys
                
                # 钥匙
                if cell.islower():
                    new_keys |= (1 << (ord(cell) - ord('a')))
                
                # 锁
                if cell.isupper():
                    # 检查是否有对应钥匙
                    if not (keys & (1 << (ord(cell) - ord('A')))):
                        continue
                
                # 新状态
                if (nx, ny, new_keys) not in visited:
                    visited.add((nx, ny, new_keys))
                    queue.append((nx, ny, new_keys, steps + 1))
        
        return -1
```

**代码说明：**
- 状态：(x, y, keys)，keys 是位掩码
- `keys |= (1 << i)` 添加钥匙
- `keys & (1 << i)` 检查是否有钥匙

### 方法二：简化版

```python
class Solution:
    def shortestPathAllKeys(self, grid: List[str]) -> int:
        from collections import deque
        
        m, n = len(grid), len(grid[0])
        start, keys_total = None, 0
        
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '@':
                    start = (i, j)
                if 'a' <= grid[i][j] <= 'f':
                    keys_total += 1
        
        target = (1 << keys_total) - 1
        queue = deque([(*start, 0)])
        visited = {(*start, 0)}
        steps = 0
        
        while queue:
            for _ in range(len(queue)):
                x, y, keys = queue.popleft()
                
                if keys == target:
                    return steps
                
                for dx, dy in [(0,1), (1,0), (0,-1), (-1,0)]:
                    nx, ny = x + dx, y + dy
                    
                    if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] != '#':
                        c = grid[nx][ny]
                        new_keys = keys
                        
                        if 'a' <= c <= 'f':
                            new_keys |= 1 << (ord(c) - ord('a'))
                        
                        if 'A' <= c <= 'F' and not (keys >> (ord(c) - ord('A')) & 1):
                            continue
                        
                        if (nx, ny, new_keys) not in visited:
                            visited.add((nx, ny, new_keys))
                            queue.append((nx, ny, new_keys))
            
            steps += 1
        
        return -1
```

## 复杂度分析

- **时间复杂度**：O(m × n × 2^k)，k 是钥匙数量。
- **空间复杂度**：O(m × n × 2^k)，visited 集合。

## 关键点总结

1. **状态压缩**：用位掩码表示钥匙集合
2. **三维状态**：(x, y, keys)
3. **BFS 最短路**：保证找到最短路径
4. **位运算**：添加、检查钥匙
5. **状态剪枝**：visited 去重

## 易错点

1. **状态定义不完整**：只用 (x, y) 会出错
2. **钥匙数量**：只有 1-6 个，适合位运算
3. **锁的处理**：检查是否有对应钥匙
