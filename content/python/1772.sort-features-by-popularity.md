## 题目描述

给你一个字符串数组 `features`，其中 `features[i]` 是第 `i` 个产品的单个产品特性的名字。

还有一个字符串数组 `responses`，其中 `responses[i]` 是第 `i` 个应答的用户的满意反馈。

注意，同一个用户可能在多次反馈中提到同一产品特性，但每次反馈中每个特性只计一次。

请你按照**产品特性被提及的频率**（从高到低）对 `features` 进行排序，如果频率相同，则按原顺序排列。

返回排序后的 `features`。

**示例：**
```
输入：features = ["cooler","lock","touch"], responses = ["i like cooler cooler","lock touch cool","you like touch"]
输出：["touch","cooler","lock"]
```

**提示：**
- `1 <= features.length <= 10^4`
- `1 <= responses.length <= 10^2`

## 解题思路

1. 统计每个 feature 被多少个用户提及（同一用户多次提及只算一次）
2. 按频率降序、原始顺序稳定排序

## 代码实现

### 方法一：哈希表统计 + 排序（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def sortFeatures(self, features: List[str], responses: List[str]) -> List[str]:
        # 统计每个 feature 被多少用户提及
        feature_set = set(features)
        count = defaultdict(int)
        
        for response in responses:
            # 同一 response 中每个 feature 只计一次
            mentioned = set(response.split()) & feature_set
            for f in mentioned:
                count[f] += 1
        
        # 按频率降序、原始位置升序排序
        # 原始位置用 index 表示
        feature_idx = {f: i for i, f in enumerate(features)}
        
        return sorted(features, key=lambda f: (-count[f], feature_idx[f]))
```

### 方法二：带原始索引排序

```python
from typing import List
from collections import defaultdict

class Solution:
    def sortFeatures(self, features: List[str], responses: List[str]) -> List[str]:
        count = defaultdict(int)
        feature_set = set(features)
        
        for resp in responses:
            words = set(resp.split())
            for w in words:
                if w in feature_set:
                    count[w] += 1
        
        # Python 排序稳定，先保证原顺序，再按频率排序
        indexed = list(enumerate(features))
        indexed.sort(key=lambda x: -count[x[1]])
        
        return [f for _, f in indexed]
```

## 复杂度分析

- **时间复杂度**：O(n * m + n log n)，n 是 features 长度，m 是 responses 平均长度
- **空间复杂度**：O(n)，哈希表

## 关键点总结

1. 同一用户同一次反馈中，每个特性只计一次（用集合去重）
2. 排序时频率高的排前面，频率相同时保持原顺序

## 易错点

- 同一 response 中重复出现的 feature 只算一次（用 `set(response.split())` 去重）
- 排序稳定性保证同频率时保持原顺序
