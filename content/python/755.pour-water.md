## 题目描述

给定一个由非负整数组成的数组 `heights`，表示直方图。假设每个柱子的宽度为 `1`。

在 `V` 单位的水落下后，返回直方图的高度。

水最初是从索引 `K` 处滴下。每次滴一单位的水时：

1. 首先，它尝试向左移动，如果能找到一个比当前位置低的位置，它会移动到最左边的最低位置。
2. 如果找不到这样的位置（即左边都更高或相同），它会尝试向右移动，如果能找到一个比当前位置低的位置，它会移动到最右边的最低位置。
3. 如果左右都找不到比当前位置低的地方，水滴会停留在当前位置。

**示例 1:**
```
输入: heights = [2,1,1,2,1,2,2], V = 4, K = 3
输出: [2,2,2,2,2,2,2]
解释:
#       #
#       #
##  # ###
#########
 0123456

第一次水滴从索引 K = 3 开始：
- 向左看，索引 2 比索引 3 低，继续向左
- 索引 1 和索引 2 一样低，不能再向左
- 所以水滴落在索引 1

第二次水滴从索引 K = 3 开始：
- 向左看，索引 1,2,3 现在一样高
- 向右看，索引 4 比索引 3 低
- 所以水滴落在索引 4

第三次和第四次类似...
```

**提示：**
- `1 <= heights.length <= 100`
- `0 <= heights[i] <= 99`
- `0 <= V <= 2000`
- `0 <= K < heights.length`

## 解题思路

这道题需要模拟水滴的流动过程。关键是理解水滴的移动规则：
1. 先尝试向左找最低点
2. 找不到再尝试向右找最低点
3. 都找不到就停在当前位置

**算法流程：**
1. 对于每一滴水（重复 V 次）：
   - 从位置 K 开始
   - 向左寻找最低点
   - 如果没找到，向右寻找最低点
   - 在找到的位置增加高度
2. 返回最终的高度数组

## Python 代码实现

### 方法一：模拟（推荐）⭐

```python
from typing import List

class Solution:
    def pourWater(self, heights: List[int], V: int, K: int) -> List[int]:
        def drop_water(k):
            # 尝试向左移动
            left = k
            while left > 0 and heights[left - 1] <= heights[left]:
                if heights[left - 1] < heights[left]:
                    left -= 1
                else:
                    break
            
            # 如果向左找到了更低的位置
            if heights[left] < heights[k]:
                heights[left] += 1
                return
            
            # 尝试向右移动
            right = k
            while right < len(heights) - 1 and heights[right + 1] <= heights[right]:
                if heights[right + 1] < heights[right]:
                    right += 1
                else:
                    break
            
            # 如果向右找到了更低的位置
            if heights[right] < heights[k]:
                heights[right] += 1
                return
            
            # 左右都没找到更低的位置，停在当前位置
            heights[k] += 1
        
        # 滴 V 次水
        for _ in range(V):
            drop_water(K)
        
        return heights
```

class Solution:
    def pourWater(self, heights: List[int], V: int, K: int) -> List[int]:
        def find_position(k):
            """找到水滴应该停留的位置"""
            # 向左找最低点
            best = k
            for i in range(k - 1, -1, -1):
                if heights[i] > heights[best]:
                    # 遇到更高的，停止
                    break
                elif heights[i] < heights[best]:
                    # 找到更低的
                    best = i
            
            # 如果向左找到了更低的位置，返回
            if best != k:
                return best
            
            # 向右找最低点
            for i in range(k + 1, len(heights)):
                if heights[i] > heights[best]:
                    # 遇到更高的，停止
                    break
                elif heights[i] < heights[best]:
                    # 找到更低的
                    best = i
            
            return best
        
        # 滴 V 次水
        for _ in range(V):
            pos = find_position(K)
            heights[pos] += 1
        
        return heights

### 方法三：详细注释版（易理解）

```python
class Solution:
    def pourWater(self, heights: List[int], V: int, K: int) -> List[int]:
        def pour_one_drop(start_pos):
            """
            模拟一滴水从 start_pos 开始流动的过程
            返回水滴最终停留的位置
            """
            n = len(heights)
            current = start_pos
            
            # 阶段 1: 尝试向左流动
            # 找到左边最低且最左的位置
            left_lowest = start_pos
            i = start_pos - 1
            
            while i >= 0:
                if heights[i] > heights[left_lowest]:
                    # 遇到更高的墙，无法继续向左
                    break
                elif heights[i] < heights[left_lowest]:
                    # 找到更低的位置
                    left_lowest = i
                # 如果相等，继续向左看（为了找到最左边的最低点）
                i -= 1
            
            # 如果向左找到了更低的位置，水滴停在那里
            if heights[left_lowest] < heights[start_pos]:
                return left_lowest
            
            # 阶段 2: 如果向左找不到，尝试向右流动
            # 找到右边最低且最右的位置
            right_lowest = start_pos
            i = start_pos + 1
            
            while i < n:
                if heights[i] > heights[right_lowest]:
                    # 遇到更高的墙，无法继续向右
                    break
                elif heights[i] < heights[right_lowest]:
                    # 找到更低的位置
                    right_lowest = i
                # 如果相等，继续向右看（为了找到最右边的最低点）
                i += 1
            
            # 如果向右找到了更低的位置，水滴停在那里
            if heights[right_lowest] < heights[start_pos]:
                return right_lowest
            
            # 阶段 3: 左右都找不到更低的位置，水滴停在起始位置
            return start_pos
        
        # 滴 V 次水
        for _ in range(V):
            position = pour_one_drop(K)
            heights[position] += 1
        
        return heights
```

### 方法四：简洁版本

```python
class Solution:
    def pourWater(self, heights: List[int], V: int, K: int) -> List[int]:
        for _ in range(V):
            # 尝试向左
            pos = K
            for i in range(K - 1, -1, -1):
                if heights[i] > heights[pos]:
                    break
                if heights[i] < heights[pos]:
                    pos = i
            
            # 如果向左找到了，就停在那
            if pos != K:
                heights[pos] += 1
                continue
            
            # 尝试向右
            for i in range(K + 1, len(heights)):
                if heights[i] > heights[pos]:
                    break
                if heights[i] < heights[pos]:
                    pos = i
            
            # 增加高度
            heights[pos] += 1
        
        return heights
```

## 复杂度分析

- **时间复杂度：** O(V * n)，其中 V 是水滴数量，n 是数组长度。每滴水最多遍历整个数组。
- **空间复杂度：** O(1)，只使用常数额外空间（不计入输出数组）。

## 关键点总结

1. **流动规则：** 水总是先尝试向左流，找不到才向右流
2. **最低点选择：** 如果有多个相同高度的最低点，选择最左边的（向左流）或最右边的（向右流）
3. **停止条件：** 遇到更高的位置或到达边界时停止
4. **模拟过程：** 逐滴模拟，每滴水独立计算
5. **原地修改：** 直接修改原数组

## 易错点

1. **方向优先级：** 一定要先向左再向右，不能反过来
2. **相等高度处理：** 高度相等时要继续前进（为了找到最边缘的位置）
3. **比较对象：** 比较的是当前遍历位置和已找到的最低点，不是和起始位置
4. **边界条件：** 注意数组边界的处理
5. **修改时机：** 找到最终位置后再增加高度，不要在寻找过程中修改
