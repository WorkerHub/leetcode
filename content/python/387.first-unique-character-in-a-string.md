## 题目描述

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

**示例 1:**

```
输入: s = "leetcode"
输出: 0
```

**示例 2:**

```
输入: s = "loveleetcode"
输出: 2
```

**示例 3:**

```
输入: s = "aabb"
输出: -1
```

**提示:**

- `1 <= s.length <= 10^5`
- `s` 只包含小写字母

## 解题思路

本题是经典的**字符计数**问题，有多种解法。

### 核心思想

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 两次遍历 | O(n) | O(1) | 简单直观 |
| 一次遍历 | O(n) | O(1) | 稍微复杂 |
| 数组计数 | O(n) | O(1) | 空间固定 |

### 思路一：两次遍历（推荐新手）

1. 第一次遍历：统计每个字符的出现次数
2. 第二次遍历：找到第一个出现次数为 1 的字符

### 思路二：一次遍历

使用哈希表记录每个字符的第一次出现位置和是否重复。

### 思路三：数组计数

因为只有小写字母，可以用长度 26 的数组代替哈希表。

## Python 代码实现

### 方法一：两次遍历 + Counter（推荐）⭐

```python
from collections import Counter

class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        使用 Counter 统计频次，两次遍历
        时间复杂度: O(n)
        空间复杂度: O(1) - 最多 26 个小写字母
        """
        # 统计每个字符的出现次数
        counter = Counter(s)
        
        # 找到第一个出现次数为 1 的字符
        for i, char in enumerate(s):
            if counter[char] == 1:
                return i
        
        return -1
```

### 方法二：数组计数

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        使用数组计数
        时间复杂度: O(n)
        空间复杂度: O(1) - 固定 26 个字母
        """
        # 统计每个字母的出现次数
        counts = [0] * 26
        
        for char in s:
            counts[ord(char) - ord('a')] += 1
        
        # 找到第一个出现一次的字符
        for i, char in enumerate(s):
            if counts[ord(char) - ord('a')] == 1:
                return i
        
        return -1
```

### 方法三：字典计数

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        手动使用字典计数
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        char_count = {}
        
        # 第一次遍历：统计频次
        for char in s:
            char_count[char] = char_count.get(char, 0) + 1
        
        # 第二次遍历：找第一个不重复的
        for i, char in enumerate(s):
            if char_count[char] == 1:
                return i
        
        return -1
```

### 方法四：记录索引（一次遍历思路）

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        记录每个字符的索引
        时间复杂度: O(n)
        空间复杂度: O(1)
        """
        # 用字典记录字符的索引，-1 表示重复，-2 表示未出现
        index_map = {}
        
        for i, char in enumerate(s):
            if char not in index_map:
                index_map[char] = i
            else:
                index_map[char] = -1  # 标记为重复
        
        # 找到最小的非 -1 索引
        result = float('inf')
        for idx in index_map.values():
            if idx != -1 and idx < result:
                result = idx
        
        return result if result != float('inf') else -1
```

### 方法五：使用 index 和 rindex（创意解法）

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        利用 index 和 rindex
        如果字符只出现一次，index == rindex
        时间复杂度: O(n * 26) = O(n)
        空间复杂度: O(1)
        """
        # 找到所有唯一字符的索引
        indices = [s.index(c) for c in set(s) if s.index(c) == s.rindex(c)]
        
        return min(indices) if indices else -1
```

### 方法六：一行代码（Pythonic）

```python
from collections import Counter

class Solution:
    def firstUniqChar(self, s: str) -> int:
        """
        使用列表推导和 min
        """
        counter = Counter(s)
        indices = [i for i, c in enumerate(s) if counter[c] == 1]
        return indices[0] if indices else -1
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历字符串最多两次
- Counter 统计需要 O(n)
- 查找第一个唯一字符需要 O(n)

**空间复杂度：** O(1)
- 虽然使用了哈希表或数组，但最多存储 26 个小写字母
- 常数空间，不随输入规模增长

## 关键点总结

1. **两次遍历模式**：先统计，再查找，逻辑清晰
2. **Counter 的使用**：Python 内置工具，简化代码
3. **数组优化**：26 个字母可以用数组代替哈希表
4. **索引技巧**：`index()` 返回第一次出现，`rindex()` 返回最后一次
5. **空间常数性**：虽然用了额外结构，但大小固定

## 易错点

1. **返回值错误**：要返回索引，不是字符本身
2. **找不到的情况**：返回 `-1`，不是 `None`
3. **空字符串**：题目保证长度至少为 1
4. **重复的定义**：出现次数大于 1 就是重复
5. **第一个的含义**：是原字符串中第一次出现的位置，不是字母表顺序
