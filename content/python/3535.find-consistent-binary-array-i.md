## 题目描述

给定整数 `zero`、`one` 和 `limit`。构造一个长度为 `zero + one` 的二进制数组，其中恰好有 `zero` 个 `0` 和 `one` 个 `1`，且不存在长度超过 `limit` 的连续相同元素的子数组。求满足条件的数组数量，对 `10^9 + 7` 取模。

**示例 1：**

```
输入：zero = 1, one = 1, limit = 2
输出：2
解释：长度2的二进制数组：[0,1] 和 [1,0]，均满足条件。
```

**示例 2：**

```
输入：zero = 2, one = 1, limit = 1
输出：1
解释：满足条件的只有 [0,1,0]。
```

**提示：**
- `1 <= zero, one <= 200`
- `1 <= limit <= 200`

## 解题思路

动态规划。

状态定义：`dp[i][j][last][cnt]` = 已填 i 个 0 和 j 个 1，最后一个数字为 `last`，连续相同数字数量为 `cnt` 时的方案数。

简化：`dp[i][j][last][cnt]`，其中 `last` 为 0 或 1，`cnt` 为 1 到 `limit`。

状态转移：
- 继续填 `last`（若 `cnt < limit`）：`cnt + 1`
- 改变填另一个数字：`cnt` 重置为 1

## Python 代码实现

### 方法一：记忆化 DFS（推荐）

```python
from functools import lru_cache

class Solution:
    def numberOfConsistentArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7

        @lru_cache(maxsize=None)
        def dp(z, o, last, cnt):
            # z: 剩余 0 的个数，o: 剩余 1 的个数
            # last: 最后一个数字，cnt: 连续相同数字数量
            if z == 0 and o == 0:
                return 1
            result = 0
            # 放 0
            if z > 0:
                if last == 0 and cnt < limit:
                    result += dp(z-1, o, 0, cnt+1)
                elif last == 1:
                    result += dp(z-1, o, 0, 1)
            # 放 1
            if o > 0:
                if last == 1 and cnt < limit:
                    result += dp(z, o-1, 1, cnt+1)
                elif last == 0:
                    result += dp(z, o-1, 1, 1)
            return result % MOD

        # 第一个数字可以是 0 或 1
        ans = 0
        if zero > 0:
            ans += dp(zero-1, one, 0, 1)
        if one > 0:
            ans += dp(zero, one-1, 1, 1)
        return ans % MOD
```

### 方法二：迭代 DP

```python
class Solution:
    def numberOfConsistentArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[z][o][last][cnt] = 方案数
        # last: 0 or 1, cnt: 1..limit
        dp = [[[[0] * (limit + 1) for _ in range(2)] for _ in range(one + 1)] for _ in range(zero + 1)]

        # 初始化：第一个数字
        if zero > 0:
            dp[zero-1][one][0][1] = 1
        if one > 0:
            dp[zero][one-1][1][1] = 1

        # 按填入总数从少到多遍历
        ans = 0
        # 用 BFS/递推 方式
        # 实际上记忆化 DFS 更简洁，这里给出迭代版本
        # 重新用前向推导

        # 从 (zero, one) 开始，每步减少一个
        from collections import defaultdict
        curr = defaultdict(int)
        if zero > 0:
            curr[(zero-1, one, 0, 1)] = 1
        if one > 0:
            curr[(zero, one-1, 1, 1)] = 1

        while curr:
            next_state = defaultdict(int)
            for (z, o, last, cnt), ways in curr.items():
                if z == 0 and o == 0:
                    ans = (ans + ways) % MOD
                    continue
                if z > 0:
                    if last == 0 and cnt < limit:
                        next_state[(z-1, o, 0, cnt+1)] = (next_state[(z-1, o, 0, cnt+1)] + ways) % MOD
                    elif last == 1:
                        next_state[(z-1, o, 0, 1)] = (next_state[(z-1, o, 0, 1)] + ways) % MOD
                if o > 0:
                    if last == 1 and cnt < limit:
                        next_state[(z, o-1, 1, cnt+1)] = (next_state[(z, o-1, 1, cnt+1)] + ways) % MOD
                    elif last == 0:
                        next_state[(z, o-1, 1, 1)] = (next_state[(z, o-1, 1, 1)] + ways) % MOD
            curr = next_state

        return ans
```

## 复杂度分析

- 时间复杂度：O(zero * one * limit)，DP 状态数
- 空间复杂度：O(zero * one * limit)

## 关键点总结

1. DP 状态需要记录剩余 0/1 的数量、最后一个数字、连续数量
2. 连续数量不能超过 `limit`，否则该方案无效
3. 初始化时需要分别从第一个数字为 0 或 1 开始

## 易错点

1. 连续数量从 1 开始（不是从 0 开始）
2. 改变数字时连续计数重置为 1（不是 0）
3. 需要对 `10^9 + 7` 取模
