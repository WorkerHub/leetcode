## 题目描述

给你一个二进制数组 `nums`。

每次操作可以翻转从某个下标开始到末尾的所有元素（后缀翻转）。

返回使所有元素都变为 1 所需的 **最少** 操作次数。

**示例 1：**
```
输入：nums = [0,1,1,0,1]
输出：4
```

**示例 2：**
```
输入：nums = [1,0,0,0]
输出：1
```

**提示：**
- `1 <= nums.length <= 10^5`

## 解题思路

后缀翻转等价于：每次翻转后，之后所有元素都取反。

贪心：从左到右扫描，遇到当前值为 0（考虑累积翻转后），需要在此处进行一次翻转（操作数 +1），将此后所有元素取反。记录翻转次数的奇偶性（用 flipped 变量）。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        ops = 0
        flipped = 0  # 当前累积翻转次数（奇偶）

        for x in nums:
            cur = x ^ flipped  # 当前实际值
            if cur == 0:
                ops += 1
                flipped ^= 1  # 从此处开始再次翻转

        return ops
```

### 方法二：DP

```python
from typing import List

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        # dp[0] = 当前元素实际为 0 时的最少操作
        # dp[1] = 当前元素实际为 1 时的最少操作
        # 状态转移类似统计翻转次数
        ops = 0
        flip = 0
        for x in nums:
            if (x ^ flip) == 0:
                ops += 1
                flip ^= 1
        return ops
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 后缀翻转操作等价于改变此后所有元素的极性
2. 用 flipped 变量记录当前累积翻转奇偶性
3. 遇到"实际为 0"的元素，立即执行后缀翻转

## 易错点

1. 每次翻转改变的是 flipped 的奇偶性，不是翻转整个数组
2. 实际值 = `x XOR flipped`
