## 题目描述

有一棵苹果树，每天 `i`（从第 `0` 天开始），树上会长出 `apples[i]` 个苹果，这些苹果将在第 `days[i]` 天后腐烂，即这些苹果在第 `i + days[i] - 1` 天之后就不能吃了。

每天你最多可以吃一个苹果，注意只有在苹果未腐烂时你才可以吃苹果。

请你返回最多能吃多少个苹果。

**示例 1：**
```
输入：apples = [1,2,3,5,2], days = [3,2,1,4,2]
输出：7
```

**示例 2：**
```
输入：apples = [3,0,0,0,0,2], days = [3,1,1,1,1,2]
输出：5
```

**提示：**
- `1 <= apples.length == days.length <= 2 * 10^4`
- `0 <= apples[i], days[i] <= 2 * 10^4`

## 解题思路

**贪心策略**：每天优先吃过期时间最早的苹果（避免浪费）。

使用最小堆（优先队列），堆中存 `(过期日期, 数量)`：
1. 第 `i` 天：将当天产生的苹果加入堆
2. 弹出已过期的苹果（过期日期 <= 当前天）
3. 从堆顶取过期最早的苹果吃一个
4. 苹果数量递减 1，若不为 0 则重新入堆
5. 苹果全部产完后（超过 `n` 天），继续消耗堆中的苹果

## 代码实现

### 方法一：贪心 + 最小堆（推荐）

```python
import heapq
from typing import List

class Solution:
    def eatenApples(self, apples: List[int], days: List[int]) -> int:
        n = len(apples)
        # 最小堆，存 (过期日期, 苹果数量)
        heap = []
        eaten = 0
        i = 0
        
        # 先处理生产阶段（第0到n-1天），再处理剩余苹果
        while i < n or heap:
            # 如果还在生产阶段，加入今天的苹果
            if i < n and apples[i] > 0:
                # 过期日期 = i + days[i]（第 i + days[i] 天不能吃了）
                heapq.heappush(heap, (i + days[i], apples[i]))
            
            # 清除已过期的苹果（过期日期 <= 当前天i）
            while heap and heap[0][0] <= i:
                heapq.heappop(heap)
            
            # 吃最快过期的苹果
            if heap:
                expire, cnt = heapq.heappop(heap)
                eaten += 1
                # 如果还剩苹果，重新加回堆
                if cnt > 1:
                    heapq.heappush(heap, (expire, cnt - 1))
            
            i += 1
        
        return eaten
```

### 方法二：显式分两阶段处理

```python
import heapq
from typing import List

class Solution:
    def eatenApples(self, apples: List[int], days: List[int]) -> int:
        n = len(apples)
        heap = []
        eaten = 0
        
        # 阶段一：苹果生产中（第0到n-1天）
        for i in range(n):
            # 加入今天产生的苹果
            if apples[i] > 0:
                heapq.heappush(heap, (i + days[i], apples[i]))
            # 清除过期苹果
            while heap and heap[0][0] <= i:
                heapq.heappop(heap)
            # 吃一个
            if heap:
                expire, cnt = heapq.heappop(heap)
                eaten += 1
                if cnt > 1:
                    heapq.heappush(heap, (expire, cnt - 1))
        
        # 阶段二：生产结束，消耗剩余苹果
        i = n
        while heap:
            # 清除过期苹果
            while heap and heap[0][0] <= i:
                heapq.heappop(heap)
            if not heap:
                break
            expire, cnt = heapq.heappop(heap)
            # 可以吃多少天：min(剩余苹果数, 过期前剩余天数)
            can_eat = min(cnt, expire - i)
            eaten += can_eat
            i += can_eat
        
        return eaten
```

## 复杂度分析

- **时间复杂度**：O(n log n)，堆操作每次 O(log n)
- **空间复杂度**：O(n)，堆最多存 n 个元素

## 关键点总结

1. 贪心：每天优先吃最快过期的苹果
2. 最小堆按过期日期排序，方便取过期最早的苹果
3. 阶段二要注意批量处理：可以一次性吃完某批苹果（不需要一天天模拟）

## 易错点

- 过期日期是 `i + days[i]`（第 `i + days[i]` 天，从第0天开始，所以该天不能吃）
- 阶段二中 `i` 要正确递增
