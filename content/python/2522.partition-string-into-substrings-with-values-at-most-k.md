## 题目描述

给你一个字符串 `s`，它由数字 `1` 到 `9` 组成，同时给你一个整数 `k`。

如果一个字符串代表的数字值 <= `k`，则称该字符串是 **合法** 的。

将 `s` 分割成若干合法的子字符串，并返回需要的 **最少** 分割数。如果无法分割，返回 `-1`。

**示例 1：**

```
输入：s = "165462", k = 60
输出：4
解释：分割为 "16" | "54" | "6" | "2"，但最优为 "1" | "6" | "54" | "62" 不合法... 最优为 4 段。
```

**示例 2：**

```
输入：s = "238182", k = 5
输出：-1
解释：单个字符 "2" 值为 2 <= 5，但 "8" 值为 8 > 5，无法分割。
```

**提示：**

- `1 <= s.length <= 10^5`
- `1 <= k <= 10^9`
- `s` 只包含 '1' 到 '9' 的字符

## 解题思路

**贪心**：从左到右，尽量延伸当前段，直到再加一位就超过 k，才切割。

贪心正确性：延伸当前段不会增加后续的分割难度（因为当前段越长，后续可处理的字符越少）。

若单个字符的值 > k（即某个字符 > k），则无法分割，返回 -1。

## Python 代码实现

### 方法一：贪心（推荐）

```python
class Solution:
    def minimumPartition(self, s: str, k: int) -> int:
        parts = 1
        cur = 0  # 当前段的数值

        for ch in s:
            d = int(ch)
            # 若单个字符就超过 k，无法分割
            if d > k:
                return -1
            # 尝试将当前字符加入当前段
            new_val = cur * 10 + d
            if new_val > k:
                # 当前段已满，需要新开一段
                parts += 1
                cur = d
            else:
                cur = new_val

        return parts
```

### 方法二：动态规划

```python
class Solution:
    def minimumPartition(self, s: str, k: int) -> int:
        n = len(s)
        # dp[i] = s[0..i-1] 最少分割数
        INF = float('inf')
        dp = [INF] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            val = 0
            for j in range(i, 0, -1):
                # 子串 s[j-1..i-1]
                val = int(s[j-1]) * (10 ** (i - j)) + val
                if val > k:
                    break
                if dp[j-1] != INF:
                    dp[i] = min(dp[i], dp[j-1] + 1)

        return dp[n] if dp[n] != INF else -1
```

## 复杂度分析

- 方法一时间复杂度：O(n)，线性贪心
- 方法二时间复杂度：O(n * log k)，每个位置最多向前 log10(k) 步
- 空间复杂度：O(1)（方法一），O(n)（方法二）

## 关键点总结

1. 贪心：每段尽可能长，值不超过 k
2. 若某单字符 > k，直接返回 -1
3. 整数拼接：`cur * 10 + digit`，超过 k 时切割新段

## 易错点

1. 超过 k 时，要先切割，再将当前字符作为新段的开始
2. 当前字符本身可能 > k，需单独判断
3. DP 方法中字符串转数字的过程要防止中途超出 k
