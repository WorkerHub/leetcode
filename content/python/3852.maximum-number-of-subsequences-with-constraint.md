## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，统计满足以下条件的非空子序列数目（模 `10^9 + 7`）：子序列中任意相邻两个元素之差的绝对值不超过 `k`。

**示例 1：**

```
输入：nums = [1, 2, 3], k = 1
输出：7
解释：满足条件的子序列有 7 个（所有非空子序列均满足）。
```

**示例 2：**

```
输入：nums = [1, 5, 3], k = 2
输出：5
解释：[1], [5], [3], [1,3], [3,5]（注意 [1,5] 差为 4 > 2 不满足）。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

## 解题思路

**哈希表 DP** + 区间查询：
- `dp[v]` = 以值 v 结尾的满足条件子序列数。
- 对每个 `nums[i] = v`，`dp[v] += sum(dp[v-k..v+k]) + 1`（加入所有差 <= k 的已有子序列末尾，+1 表示单独成为子序列）。
- 需要快速查询 `sum(dp[v-k..v+k])`，可以用线段树或 SortedDict 维护。

## Python 代码实现

### 方法一：哈希表 + 暴力查询（小数据）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countSubsequences(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        # dp[v] = 以值 v 结尾的合法子序列数
        dp = defaultdict(int)
        total = 0

        for v in nums:
            # 以 v 结尾的新子序列数 = sum(dp[u] for |u-v| <= k) + 1
            new_count = 1
            for u in range(max(1, v - k), v + k + 1):
                new_count = (new_count + dp[u]) % MOD
            dp[v] = (dp[v] + new_count) % MOD
            total = (total + new_count) % MOD

        return total
```

### 方法二：线段树优化区间求和

```python
from typing import List

class BIT:
    """树状数组（Binary Indexed Tree）用于区间求和"""
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        while i <= self.n:
            self.tree[i] = (self.tree[i] + delta) % (10 ** 9 + 7)
            i += i & (-i)

    def query(self, i):
        s = 0
        while i > 0:
            s = (s + self.tree[i]) % (10 ** 9 + 7)
            i -= i & (-i)
        return s

    def range_query(self, l, r):
        if l > r:
            return 0
        return (self.query(r) - self.query(l - 1)) % (10 ** 9 + 7)


class Solution:
    def countSubsequences(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        max_val = max(nums)
        bit = BIT(max_val)
        total = 0

        for v in nums:
            # 查询 [v-k, v+k] 范围的 dp 值之和
            lo = max(1, v - k)
            hi = min(max_val, v + k)
            range_sum = bit.range_query(lo, hi)
            new_count = (range_sum + 1) % MOD
            bit.update(v, new_count)
            total = (total + new_count) % MOD

        return total
```

## 复杂度分析

- 时间复杂度：O(n * k)（方法一）；O(n log max_val)（方法二）
- 空间复杂度：O(max_val)，BIT 数组

## 关键点总结

1. DP 状态以值为键，而不是下标，避免 O(n^2) 空间。
2. 每个元素可以接在所有差 <= k 的已有子序列后面，或单独成子序列（+1）。
3. 树状数组将区间求和从 O(k) 优化到 O(log n)。

## 易错点

1. 不要混淆"下标"和"值"的 DP 定义，这里以"值"为键。
2. 树状数组下标从 1 开始，注意边界处理。
3. 取模运算在加法和查询时都需要保持。
