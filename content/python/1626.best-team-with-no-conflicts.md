## 题目描述

假设你是一支篮球队的教练，你想从一些球员中组建一支没有冲突的最强球队。

球员可能存在**年龄冲突**：如果两个球员中的**较年长者的得分少于较年轻者**，则两个球员之间就会存在冲突。同龄球员之间不存在年龄冲突。

给你两个列表 `scores` 和 `ages`，分别表示每个球员的得分和年龄，请你返回**所有可能的无冲突球队中得分最高**的那支球队的总分。

**示例：**
```
输入：scores = [1,3,5,10,15], ages = [1,2,3,4,5]
输出：34
解释：可以选择所有球员（无冲突），总分 1+3+5+10+15=34
```

**提示：**
- `1 <= scores.length, ages.length <= 1000`
- `scores.length == ages.length`
- `1 <= scores[i] <= 10^6`
- `1 <= ages[i] <= 1000`

## 解题思路

将球员按**年龄升序**排序（同年龄按得分升序），然后转化为**最长不递减子序列**问题（得分不递减）。

**原理：** 无冲突要求：年龄较大的球员得分 >= 年龄较小的。排序后，只要后面球员的得分 >= 前面球员，就不会产生冲突。

**DP 定义：** `dp[i]` = 以第 i 个球员结尾的无冲突球队最大总分。

## 代码实现

### 方法一：动态规划（推荐）

```python
from typing import List

class Solution:
    def bestTeamScore(self, scores: List[int], ages: List[int]) -> int:
        # 按年龄升序排序，年龄相同按得分升序
        players = sorted(zip(ages, scores))
        n = len(players)
        
        # dp[i]：以第 i 个球员结尾的无冲突球队最大总分
        dp = [s for _, s in players]  # 初始：每人单独组队
        
        for i in range(1, n):
            for j in range(i):
                age_j, score_j = players[j]
                age_i, score_i = players[i]
                # 无冲突条件：得分不递减（年龄已排序保证不降序）
                if score_j <= score_i:
                    dp[i] = max(dp[i], dp[j] + score_i)
        
        return max(dp)
```

### 方法二：树状数组优化

```python
from typing import List

class Solution:
    def bestTeamScore(self, scores: List[int], ages: List[int]) -> int:
        MAX_SCORE = 10 ** 6 + 1
        
        # 树状数组（用于 O(log n) 区间最大值查询）
        tree = [0] * (MAX_SCORE + 1)
        
        def update(i: int, val: int):
            while i <= MAX_SCORE:
                tree[i] = max(tree[i], val)
                i += i & (-i)
        
        def query(i: int) -> int:
            res = 0
            while i > 0:
                res = max(res, tree[i])
                i -= i & (-i)
            return res
        
        # 按年龄升序，年龄相同按得分升序
        players = sorted(zip(ages, scores))
        ans = 0
        
        for age, score in players:
            # 查询得分 <= score 的最大 dp 值
            best = query(score) + score
            ans = max(ans, best)
            update(score, best)
        
        return ans
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n^2) | O(n) |
| 树状数组 | O(n log M) | O(M) |

M 为最大得分（10^6）。

## 关键点总结

1. 按年龄+得分排序后，问题转化为"得分不递减子序列的最大总分"
2. 同年龄球员按得分升序排，可以避免同年龄的错误排除
3. DP 状态转移：若 `score[j] <= score[i]`，则 `dp[i] = max(dp[i], dp[j] + score[i])`
4. 树状数组优化到 O(n log M)

## 易错点

- 同年龄的球员不存在冲突，排序时同年龄按得分升序处理
- DP 初始值为每个球员单独的得分（不是 0）
- 最终答案是 `max(dp)`，不是 `dp[-1]`
