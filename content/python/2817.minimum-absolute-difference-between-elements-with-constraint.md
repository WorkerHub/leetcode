## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 和一个整数 `x`。

找到差的绝对值最小的两个元素的下标对 `(i, j)`，满足 `|i - j| >= x`（下标距离至少为 x）。

返回 `nums[i]` 和 `nums[j]` 的绝对差最小值。

**示例 1：**
```
输入：nums = [4,3,2,4], x = 2
输出：0
解释：下标对 (0, 3)：|0-3|=3>=2，|nums[0]-nums[3]|=|4-4|=0
```

**示例 2：**
```
输入：nums = [5,3,2,10,15], x = 1
输出：1
解释：下标对 (1, 2)：|1-2|=1>=1，|3-2|=1
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= x <= nums.length`

## 解题思路

对每个下标 `j >= x`，需要在 `nums[0..j-x]` 中找与 `nums[j]` 最接近的元素。

**有序集合 + 二分查找：**
- 维护一个有序集合（保存前 `j-x+1` 个元素）
- 对每个新的 `j`，将 `nums[j-x]` 加入有序集合
- 在有序集合中二分查找与 `nums[j]` 最接近的值

Python 中可用 `SortedList`（from sortedcontainers）实现有序集合，支持 O(log n) 的插入和 bisect 查找。

## Python 代码实现

### 方法一：SortedList（推荐）

```python
from typing import List
from sortedcontainers import SortedList

class Solution:
    def minAbsoluteDifference(self, nums: List[int], x: int) -> int:
        n = len(nums)
        sl = SortedList()
        ans = float('inf')

        for j in range(n):
            # 将满足距离 >= x 条件的元素加入有序集合
            if j >= x:
                sl.add(nums[j - x])

            if sl:
                target = nums[j]
                # 二分查找最接近 target 的元素
                idx = sl.bisect_left(target)
                # 检查 idx 处和 idx-1 处
                if idx < len(sl):
                    ans = min(ans, abs(sl[idx] - target))
                if idx > 0:
                    ans = min(ans, abs(sl[idx - 1] - target))

        return ans
```

### 方法二：手动二分（不依赖第三方库）

```python
import bisect
from typing import List

class Solution:
    def minAbsoluteDifference(self, nums: List[int], x: int) -> int:
        n = len(nums)
        sorted_arr = []  # 手动维护有序数组
        ans = float('inf')

        for j in range(n):
            if j >= x:
                # 插入 nums[j-x] 到有序数组
                bisect.insort(sorted_arr, nums[j - x])

            if sorted_arr:
                target = nums[j]
                idx = bisect.bisect_left(sorted_arr, target)
                if idx < len(sorted_arr):
                    ans = min(ans, abs(sorted_arr[idx] - target))
                if idx > 0:
                    ans = min(ans, abs(sorted_arr[idx - 1] - target))

        return ans
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次插入和查找都是 O(log n)
- 空间复杂度：O(n)，有序集合最多存 n 个元素

## 图解示例

```
nums = [4,3,2,4], x = 2

j=0: 有序集合={}，j<x 跳过
j=1: 有序集合={}，j<x 跳过
j=2: 加入 nums[0]=4，有序集合=[4]，target=2，最近=4，差=2
j=3: 加入 nums[1]=3，有序集合=[3,4]，target=4，最近=4（idx=1），差=0

答案 = 0
```

## 关键点总结

1. 滑动窗口思想：对每个 j，维护 `[0, j-x]` 的有序集合
2. 二分查找找最近的值：检查 bisect_left 返回位置及其前一位
3. SortedList 是 Python 有序集合的最佳实践，支持 O(log n) 操作

## 易错点

1. 当 `idx == len(sl)` 时，只检查 `idx-1`（不能越界）
2. 当 `idx == 0` 时，只检查 `idx`（不能访问负索引）
3. 手动维护有序数组用 `bisect.insort`，时间复杂度是 O(n) 插入，整体 O(n^2)

## 学习建议

若环境不支持 `sortedcontainers`，可手动实现，但效率较低。建议学习时了解 `SortedList` 的使用，这是 Python 竞赛编程中常用的数据结构。
