## 题目描述

给你 `n` 个项目，`milestones[i]` 是第 `i` 个项目的里程碑数量。你每周可以做一个项目的一个里程碑，相邻两周不能做同一个项目。

返回你能工作的**最多周数**。

**示例 1：**
```
输入：milestones = [1, 2, 3]
输出：6
解释：工作顺序：项目 2、0、1（或其他），可以工作 6 周（完成所有里程碑）
```

**示例 2：**
```
输入：milestones = [5, 2, 1]
输出：7
解释：项目 0 里程碑最多 5，其余共 3，能安排：5对3，最多穿插工作 2*3+1 = 7 周
```

**提示：**
- `n == milestones.length`，`1 <= n <= 10^5`
- `1 <= milestones[i] <= 10^9`

---

## 解题思路

### 核心思想：贪心 - 最大值与其余的关系

设 `max_m` = 最大里程碑数，`rest` = 其余里程碑数之和（total - max_m）。

**两种情况：**
1. 若 `max_m <= rest + 1`：所有里程碑可全部完成，答案为 `total`
2. 若 `max_m > rest + 1`：最大项目太多，只能穿插完成 `rest * 2 + 1` 周

---

## 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def numberOfWeeks(self, milestones: List[int]) -> int:
        total = sum(milestones)
        max_m = max(milestones)
        rest = total - max_m

        if max_m <= rest + 1:
            # 最大项目数不超过其余总数+1，可以全部完成
            return total
        else:
            # 最大项目太多，穿插完成：rest * 2 + 1 周
            return rest * 2 + 1
```

### 方法二：显式推导验证

```python
from typing import List

class Solution:
    def numberOfWeeks(self, milestones: List[int]) -> int:
        total = sum(milestones)
        max_m = max(milestones)
        rest = total - max_m

        # 如果可以完全穿插（最大 <= 其余 + 1），则全部完成
        # 否则，只能穿插安排 rest 个到最大项目的间隙中
        # 最优排列：max_m 个大项目，之间插 rest 个其他项目
        # 能完成：rest * 2 + 1（如 A B A B A ... A）
        return total if max_m <= rest + 1 else rest * 2 + 1
```

## 关键点总结

1. 关键约束：相邻两周不能做同一项目
2. 瓶颈在于最大里程碑数的项目能否被均匀穿插
3. 公式：`max_m <= rest + 1` 时全部完成，否则 `2 * rest + 1`

---

## 易错点

- `rest = total - max_m`，不要计算成总数减去其他某个值
- `rest * 2 + 1` 是最优穿插时的最大值（不是 `(rest+1) * 2 - 1`）
