## 题目描述

给你两个字符串 `s` 和 `t`，返回需要在 `s` 末尾追加的最少字符数，使得 `t` 成为 `s` 的 **子序列**。

**示例：**
```
输入：s = "coaching", t = "coding"
输出：4
解释：s 包含 t 中的 "co" 前缀，剩余 "ding" 需追加
```

**提示：**
- `1 <= s.length, t.length <= 10^5`
- `s` 和 `t` 都只包含小写英文字母

## 解题思路

**双指针贪心：**

用双指针检查 `t` 中有多少个前缀字符可以作为 `s` 的子序列被匹配：
- 指针 `i` 遍历 `s`，指针 `j` 遍历 `t`
- 每次 `s[i] == t[j]` 时，`j` 向右移动
- 最终 `j` 是 t 中第一个不能被匹配的位置
- 答案 = `len(t) - j`

## 代码实现

### 方法一：双指针（推荐）

```python
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        j = 0  # t 的指针
        for c in s:
            if j < len(t) and c == t[j]:
                j += 1  # t[j] 被匹配，移动到下一个
        # j 是 t 中第一个未被匹配的位置
        return len(t) - j
```

### 方法二：显式双指针写法

```python
class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        i, j = 0, 0
        n, m = len(s), len(t)

        while i < n and j < m:
            if s[i] == t[j]:
                j += 1  # 匹配成功，移动 t 的指针
            i += 1

        # t[j:] 是尚未被匹配的部分，需要追加
        return m - j
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n) | O(1) |

## 关键点总结

1. 贪心地从左到右匹配 t 的前缀
2. 匹配到 j 时，t[0..j-1] 已经是 s 的子序列
3. 未匹配部分 t[j..m-1] 必须追加，长度 = m - j

## 易错点

- 不需要真的追加字符，只需统计剩余未匹配的 t 的字符数
