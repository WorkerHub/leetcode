## 题目描述

给你一个 `n x n` 的矩阵 `grid`，你可以旋转矩阵（每次 90 度，共 4 种旋转），请返回旋转后左上角 `k x k` 子矩阵（取所有可能旋转后的最大和）。

等价于：在 4 种旋转中，找到使左上角 `k x k` 子矩阵元素和最大的那种旋转。

**示例 1：**

```
输入：grid = [[1,2],[3,4]], k = 1
输出：4
解释：旋转后左上角最大元素是4
```

**提示：**

- `1 <= k <= n <= 10^3`
- `1 <= grid[i][j] <= 10^4`

## 解题思路

枚举 4 种旋转，对每种旋转计算左上角 `k x k` 子矩阵之和，取最大值。

矩阵旋转：
- 0度：原矩阵
- 90度：`new[j][n-1-i] = grid[i][j]`
- 180度：`new[n-1-i][n-1-j] = grid[i][j]`
- 270度：`new[n-1-j][i] = grid[i][j]`

用前缀和快速计算子矩阵之和。

## Python 代码实现

### 方法一：枚举旋转 + 前缀和（推荐）

```python
from typing import List

class Solution:
    def rotateGrid(self, grid: List[List[int]], k: int) -> int:
        n = len(grid)

        def submatrix_sum(mat: List[List[int]], k: int) -> int:
            return sum(mat[i][j] for i in range(k) for j in range(k))

        def rotate90(mat):
            n = len(mat)
            return [[mat[n - 1 - j][i] for j in range(n)] for i in range(n)]

        ans = 0
        curr = grid
        for _ in range(4):
            ans = max(ans, submatrix_sum(curr, k))
            curr = rotate90(curr)

        return ans
```

### 方法二：直接坐标映射

```python
from typing import List

class Solution:
    def rotateGrid(self, grid: List[List[int]], k: int) -> int:
        n = len(grid)
        ans = 0

        for rot in range(4):
            total = 0
            for i in range(k):
                for j in range(k):
                    # 根据旋转角度映射原坐标
                    if rot == 0:
                        total += grid[i][j]
                    elif rot == 1:
                        total += grid[n - 1 - j][i]
                    elif rot == 2:
                        total += grid[n - 1 - i][n - 1 - j]
                    else:
                        total += grid[j][n - 1 - i]
            ans = max(ans, total)

        return ans
```

## 复杂度分析

- 时间复杂度：O(k^2)，枚举 4 次，每次 O(k^2)
- 空间复杂度：O(n^2)（方法一旋转矩阵），O(1)（方法二）

## 关键点总结

1. 矩阵只有 4 种旋转，直接枚举
2. 每种旋转后，左上角 `k x k` 子矩阵的原始坐标有固定映射
3. 用坐标映射避免实际旋转矩阵

## 易错点

1. 旋转方向（顺时针/逆时针）影响坐标映射公式
2. k 可能等于 n
3. 方法一中旋转 4 次后回到原始矩阵
