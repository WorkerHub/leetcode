## 题目描述

给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例 1：**
```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807
```

**示例 2：**
```
输入：l1 = [0], l2 = [0]
输出：[0]
```

**示例 3：**
```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```

**提示：**
- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 解题思路

这道题模拟了手工加法的过程：

1. **逐位相加**：从最低位（链表头）开始，逐位相加
2. **处理进位**：两个数字相加可能产生进位，需要传递到下一位
3. **长度不同**：两个链表长度可能不同，短的按 0 处理
4. **最后的进位**：如果最高位还有进位，需要新建节点

关键观察：
- 链表已经是逆序存储，正好符合从低位到高位的加法顺序
- 需要一个变量 `carry` 记录进位
- 可以使用哑节点（dummy node）简化代码

## Python 代码实现

### 方法一：迭代法（推荐）

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        # 创建哑节点，简化边界处理
        dummy = ListNode(0)
        current = dummy
        carry = 0  # 进位
        
        # 遍历两个链表
        while l1 or l2 or carry:
            # 获取当前位的值
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            
            # 计算和与进位
            total = val1 + val2 + carry
            carry = total // 10  # 新的进位
            digit = total % 10   # 当前位的数字
            
            # 创建新节点
            current.next = ListNode(digit)
            current = current.next
            
            # 移动指针
            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next
        
        return dummy.next
```

### 方法二：递归法

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        def add(l1: ListNode, l2: ListNode, carry: int) -> ListNode:
            # 递归终止条件
            if not l1 and not l2 and carry == 0:
                return None
            
            # 获取当前值
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            
            # 计算和与进位
            total = val1 + val2 + carry
            digit = total % 10
            new_carry = total // 10
            
            # 创建当前节点
            node = ListNode(digit)
            
            # 递归处理下一位
            next1 = l1.next if l1 else None
            next2 = l2.next if l2 else None
            node.next = add(next1, next2, new_carry)
            
            return node
        
        return add(l1, l2, 0)
```

### 方法三：简化版（使用 Python 特性）

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        current = dummy
        carry = 0
        
        while l1 or l2 or carry:
            # 使用条件表达式简化代码
            total = (l1.val if l1 else 0) + (l2.val if l2 else 0) + carry
            
            # 创建新节点
            current.next = ListNode(total % 10)
            current = current.next
            
            # 更新进位和指针
            carry = total // 10
            l1 = l1.next if l1 else None
            l2 = l2.next if l2 else None
        
        return dummy.next
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(max(m, n))，m 和 n 分别是两个链表的长度
- 空间复杂度：O(max(m, n))，新链表的长度最多为 max(m, n) + 1

**递归方法额外说明：**
- 递归调用栈深度为 O(max(m, n))

## 图解示例

以示例 1 为例：`342 + 465 = 807`

```
链表表示：
l1:  2 -> 4 -> 3
l2:  5 -> 6 -> 4
     ↓    ↓    ↓
步骤：
第1位: 2 + 5 = 7, carry = 0
第2位: 4 + 6 = 10, digit = 0, carry = 1
第3位: 3 + 4 + 1(进位) = 8, carry = 0

结果: 7 -> 0 -> 8
```

## 关键点总结

1. **哑节点技巧**：使用 `dummy` 节点简化链表头的处理
2. **进位处理**：`carry = total // 10`, `digit = total % 10`
3. **循环条件**：`while l1 or l2 or carry`，确保处理完所有位和最后的进位
4. **空节点处理**：当链表为空时，将其值视为 0

## 易错点

1. **忘记最后的进位**：循环条件必须包含 `carry`，例如 `[5] + [5] = [0, 1]`
2. **链表长度不同**：需要正确处理 `None` 节点
3. **边界条件**：
   - 两个链表都为空但有进位
   - 单节点链表
4. **修改原链表**：不要修改输入的链表，应创建新链表
