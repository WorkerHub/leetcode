## 题目描述

给定一个二进制数组 nums，计算其中最大连续 1 的个数。

**示例 1：**
```
输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头的两个数字和最后的三个数字都是连续 1，所以最大连续 1 的个数是 3。
```

**示例 2：**
```
输入：nums = [1,0,1,1,0,1]
输出：2
```

**提示：**
- 1 <= nums.length <= 10^5
- nums[i] 不是 0 就是 1

## 解题思路

这是一道简单的数组遍历题目，核心思想是：

1. **一次遍历**：
   - 遍历数组，统计连续 1 的个数
   - 遇到 0 时重置计数器
   - 记录过程中的最大值

2. **双指针**（可选）：
   - 左指针标记连续 1 的起始位置
   - 右指针向前扫描
   - 遇到 0 时计算长度并更新最大值

3. **状态维护**：
   - 当前连续 1 的个数
   - 历史最大连续 1 的个数

## Python 代码实现

### 方法一：一次遍历（推荐）

```python
from typing import List

class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        """
        一次遍历统计最大连续 1 的个数
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        max_count = 0  # 最大连续 1 的个数
        current_count = 0  # 当前连续 1 的个数
        
        for num in nums:
            if num == 1:
                # 遇到 1，增加当前计数
                current_count += 1
                # 更新最大值
                max_count = max(max_count, current_count)
            else:
                # 遇到 0，重置当前计数
                current_count = 0
        
        return max_count
```

### 方法二：使用 split（Python 特色）

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        """
        将数组转为字符串，按 '0' 分割
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # 将数组转为字符串
        s = ''.join(map(str, nums))
        
        # 按 '0' 分割，得到所有连续 1 的段
        segments = s.split('0')
        
        # 返回最长段的长度
        return max(len(seg) for seg in segments) if segments else 0
```

### 方法三：双指针

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        """
        使用双指针找连续 1 的区间
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        max_len = 0
        i = 0
        n = len(nums)
        
        while i < n:
            if nums[i] == 1:
                # 找到 1 的起始位置
                j = i
                # 向右扩展
                while j < n and nums[j] == 1:
                    j += 1
                # 更新最大长度
                max_len = max(max_len, j - i)
                # 移动到下一个可能的起始位置
                i = j
            else:
                i += 1
        
        return max_len
```

### 方法四：函数式编程风格

```python
from itertools import groupby

class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        """
        使用 itertools.groupby 分组
        
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        # groupby 将连续相同的元素分组
        # 只关心值为 1 的组
        return max((sum(1 for _ in group) for key, group in groupby(nums) if key == 1), default=0)
```

### 方法五：简洁版

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        """
        最简洁的实现
        
        时间复杂度：O(n)
        空间复杂度：O(1)
        """
        max_count = count = 0
        
        for num in nums:
            count = count + 1 if num == 1 else 0
            max_count = max(max_count, count)
        
        return max_count
```

## 复杂度分析

**方法一、三、五：**
- **时间复杂度**：O(n)
  - 遍历数组一次
  
- **空间复杂度**：O(1)
  - 只使用常数额外空间

**方法二、四：**
- **时间复杂度**：O(n)
  - 需要遍历数组
  
- **空间复杂度**：O(n)
  - 需要创建字符串或分组结构

## 关键点总结

1. **状态维护**：维护当前连续计数和最大计数
2. **重置时机**：遇到 0 时重置当前计数
3. **更新时机**：遇到 1 时更新最大值
4. **边界处理**：空数组、全 0、全 1 的情况
5. **简洁代码**：使用三元表达式简化逻辑

## 易错点

1. **忘记更新最大值**
   - 每次遇到 1 都要检查是否需要更新最大值
   - 不能只在遇到 0 时更新

2. **边界情况**
   - 数组以连续 1 结尾时，要确保最后的计数被考虑
   - 方法一在循环中实时更新最大值，避免了这个问题

3. **空数组**
   - nums = [] 时应返回 0
   - 使用 max(..., default=0) 或提前判断

4. **全 1 数组**
   - nums = [1,1,1,1] 应返回 4
   - 确保最大值在循环中正确更新

5. **全 0 数组**
   - nums = [0,0,0] 应返回 0
   - 初始化 max_count = 0 可以处理
