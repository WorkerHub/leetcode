## 题目描述

一顿**好餐**是指两个食物的美味程度之和为 2 的幂。

给你一个整数数组 `deliciousness`，其中 `deliciousness[i]` 表示第 `i` 道食物的美味程度。

返回可以用数组中的食物做出的**好餐**的数量。由于结果可能很大，返回结果对 `10^9 + 7` 取余后的结果。

注意：食物的每一对下标应不同（即 `i != j`）。

**示例 1：**
```
输入：deliciousness = [1,3,5,7,9]
输出：4
解释：(1,7), (3,5), (1,9), (3,9) 分别对应和 8, 8, 10... 等2的幂
```

**提示：**
- `1 <= deliciousness.length <= 10^5`
- `0 <= deliciousness[i] <= 2^20`

## 解题思路

用哈希表记录已遍历过的数字及其出现次数。

对每个数 `x`，枚举所有 2 的幂（从 `2^0` 到 `2^21`），查找 `power - x` 是否在哈希表中，若存在则累加计数。

因为 `deliciousness[i] <= 2^20`，两数之和最大为 `2^21`，所以只需枚举 `2^0` 到 `2^21`。

## 代码实现

### 方法一：哈希表 + 枚举 2 的幂（推荐）

```python
from typing import List
from collections import defaultdict

class Solution:
    def countPairs(self, deliciousness: List[int]) -> int:
        MOD = 10 ** 9 + 7
        # 记录已遍历数字的出现次数
        count = defaultdict(int)
        ans = 0
        
        for x in deliciousness:
            # 枚举所有可能的 2 的幂（2^0 到 2^21）
            power = 1
            for _ in range(22):
                # 查找是否存在 power - x 使两者之和为 2 的幂
                complement = power - x
                if complement in count:
                    ans = (ans + count[complement]) % MOD
                power <<= 1  # 乘以 2
            
            # 将当前数加入哈希表
            count[x] += 1
        
        return ans
```

### 方法二：先统计后枚举

```python
from typing import List
from collections import Counter

class Solution:
    def countPairs(self, deliciousness: List[int]) -> int:
        MOD = 10 ** 9 + 7
        count = Counter(deliciousness)
        ans = 0
        
        # 获取所有不同的值
        keys = list(count.keys())
        
        for i, x in enumerate(keys):
            for bit in range(22):
                power = 1 << bit
                complement = power - x
                if complement in count:
                    if complement == x:
                        # 两个数相同，从 count[x] 个中选 2 个
                        ans += count[x] * (count[x] - 1) // 2
                    elif complement > x:
                        # 只统计 complement > x 的情况避免重复计数
                        ans += count[x] * count[complement]
        
        return ans % MOD
```

## 复杂度分析

- **时间复杂度**：O(n * 22) = O(n log max_val)，每个数枚举 22 个 2 的幂
- **空间复杂度**：O(n)，哈希表存储

## 关键点总结

1. 两数之和最大为 `2^21`，只需枚举 22 个 2 的幂
2. 方法一的顺序遍历天然避免重复计数（只看前面已有的数）
3. 方法二需要额外处理两数相同的情况

## 易错点

- 结果要对 `10^9 + 7` 取余
- 方法一中先查哈希表再插入，避免将自身与自身配对
- `deliciousness[i]` 可以为 0，所以 `2^0 = 1` 也要枚举
