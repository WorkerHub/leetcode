## 题目描述

**反转** 一个整数意味着倒置它的所有位（包含前导零，前导零会在反转后被删除）。

例如，反转 1000 得到 1，反转 1000021 得到 1200001。

给你一个整数 `num`，**反转** `num` 得到 `reversedNum`，**再次反转** `reversedNum` 得到 `finalNum`。

如果 `finalNum == num`，返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：num = 526
输出：true
解释：526 -> 625 -> 526，相等。
```

**示例 2：**
```
输入：num = 1800
输出：false
解释：1800 -> 0081 = 81 -> 18，不等于 1800。
```

**提示：**
- `0 <= num <= 10^6`

## 解题思路

**数学规律：**

- 若 `num == 0`：0 反转后还是 0，`finalNum == 0 == num`，返回 true。
- 若 `num % 10 != 0`（末位不为 0）：反转后末位变为首位，首位不为 0，再反转回来还是原数，返回 true。
- 若 `num % 10 == 0` 且 `num != 0`：末位有 0，第一次反转后变为首位（被删除），导致信息丢失，第二次反转无法还原，返回 false。

## 代码实现

### 方法一：数学规律（推荐）

```python
class Solution:
    def isSameAfterReversals(self, num: int) -> bool:
        # num=0 特例，或末位不为 0 时可以还原
        return num == 0 or num % 10 != 0
```

### 方法二：模拟两次反转

```python
class Solution:
    def isSameAfterReversals(self, num: int) -> bool:
        def reverse_num(n: int) -> int:
            # 整数反转（自动去除前导零）
            return int(str(n)[::-1])

        return reverse_num(reverse_num(num)) == num
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 数学规律 | O(1) | O(1) |
| 模拟反转 | O(log num) | O(log num) |

## 关键点总结

1. 关键在于末位是否为 0：末位为 0 且 num != 0 时，反转后前导零被删除，无法还原。
2. `num == 0` 是特殊情况，需单独处理。
3. 方法一是 O(1) 的最优解。

## 易错点

- `num == 0` 时 `0 % 10 == 0`，但答案是 true，需要先特判。
- 直接写 `return num == 0 or num % 10 != 0` 即已包含了对 0 的处理。
