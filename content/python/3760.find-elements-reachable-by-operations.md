## 题目描述

给定整数数组 `nums` 和整数 `k`，对数组中的元素执行操作：选择任意元素 `x`，将 `x` 替换为 `x | k`（按位或）或 `x & k`（按位与）。

统计数组中可以通过若干次操作变成任意目标值 `target` 的元素数量。（也可理解为：对每个元素独立操作，统计能生成不同结果的元素总数）。

**示例 1：**
```
输入：nums = [1,2,3], k = 5
输出：6
解释：对每个元素可以生成：
     1: 1, 1|5=5, 1&5=1 -> {1,5}
     2: 2, 2|5=7, 2&5=0 -> {0,2,7}
     3: 3, 3|5=7, 3&5=1 -> {1,3,7}
     总共不重复的可达值：{0,1,2,3,5,7} 共 6 个。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## 解题思路

对每个元素，可以生成的值集合是有限的。通过 BFS 从每个元素出发，枚举所有可通过 `x|k` 和 `x&k` 操作到达的值，加入集合。

由于每次操作后结果的位数不会增加，集合大小有限。

## Python 代码实现

### 方法一：BFS 枚举可达值（推荐）

```python
from typing import List
from collections import deque

class Solution:
    def countReachable(self, nums: List[int], k: int) -> int:
        reachable = set()

        for x in nums:
            # BFS 从 x 出发，枚举所有可达值
            visited = set()
            queue = deque([x])
            visited.add(x)

            while queue:
                val = queue.popleft()
                reachable.add(val)

                for next_val in [val | k, val & k]:
                    if next_val not in visited:
                        visited.add(next_val)
                        queue.append(next_val)

        return len(reachable)
```

### 方法二：直接枚举两步操作

```python
from typing import List

class Solution:
    def countReachable(self, nums: List[int], k: int) -> int:
        reachable = set()

        for x in nums:
            # 两次操作最多生成 4 个值（实际上迭代后会收敛）
            current = {x}
            prev_size = -1
            while len(current) != prev_size:
                prev_size = len(current)
                new_vals = set()
                for v in current:
                    new_vals.add(v | k)
                    new_vals.add(v & k)
                current |= new_vals
            reachable |= current

        return len(reachable)
```

## 复杂度分析

- 时间复杂度：O(n * S)，S 为每个元素的可达值集合大小（有限，通常很小）
- 空间复杂度：O(n * S)

## 关键点总结

1. 位运算操作的可达值集合收敛快：OR 使位增加，AND 使位减少，两者交替不会无限增长
2. BFS 从每个起始值出发，枚举所有可达值
3. 全局 set 统计不重复的可达值总数

## 易错点

1. 迭代需要一直进行直到集合不再增长（不仅仅是 1-2 步）
2. 不同起始值可能到达相同的目标值
