## 题目描述

给你一个下标从 0 开始的二进制字符串 `s` 和两个整数 `minJump` 和 `maxJump`。

初始位置为 0（`s[0] == '0'`），每次可以从位置 `i` 跳到满足以下条件的位置 `j`：
- `i + minJump <= j <= i + maxJump`
- `s[j] == '0'`

若能到达最后一个位置（`s[n-1] == '0'`），返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "011010", minJump = 2, maxJump = 3
输出：true
```

**示例 2：**
```
输入：s = "01101110", minJump = 2, maxJump = 3
输出：false
```

## 解题思路

**DP + 前缀和**：

`dp[i]` = 是否能到达位置 i。

`dp[i] = s[i] == '0' AND (存在 j 使得 i - maxJump <= j <= i - minJump 且 dp[j] == True)`

用前缀和 `pre[i]` = `sum(dp[0..i])`，则区间内可达点数 = `pre[i-minJump] - pre[max(0, i-maxJump-1)]`，若大于 0 则 `dp[i] = True`。

## 代码实现

### 方法一：DP + 前缀和（推荐）

```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        if s[-1] != '0':
            return False

        dp = [False] * n
        dp[0] = True

        # pre[i] = dp[0..i] 中 True 的个数
        pre = [0] * (n + 1)
        pre[1] = 1  # dp[0] = True

        for i in range(1, n):
            if s[i] == '0':
                # 检查区间 [i-maxJump, i-minJump] 内是否有可达点
                lo = max(0, i - maxJump)
                hi = i - minJump
                if hi >= 0:
                    count = pre[hi + 1] - pre[lo]
                    if count > 0:
                        dp[i] = True
            pre[i + 1] = pre[i] + (1 if dp[i] else 0)

        return dp[-1]
```

### 方法二：滑动窗口计数

```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        if s[-1] != '0':
            return False

        dp = [False] * n
        dp[0] = True
        window = 0  # 窗口 [i-maxJump, i-minJump] 内的可达点数

        for i in range(1, n):
            # 扩展窗口右边界（加入 i-minJump）
            if i >= minJump and dp[i - minJump]:
                window += 1
            # 收缩窗口左边界（移除 i-maxJump-1）
            if i > maxJump and dp[i - maxJump - 1]:
                window -= 1
            if s[i] == '0' and window > 0:
                dp[i] = True

        return dp[-1]
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，dp 数组和前缀和数组

## 关键点总结

1. 朴素 DP 是 O(n * (maxJump - minJump)) 的，用前缀和优化到 O(n)
2. 滑动窗口方法：窗口内的可达点数动态维护，无需每次重新计算
3. 首先判断 s[-1] == '0'，否则直接返回 false

## 易错点

- 前缀和下标：`pre[i+1]` 对应 `dp[i]`，注意偏移
- 滑动窗口边界：扩展在 `i >= minJump` 时，收缩在 `i > maxJump` 时
