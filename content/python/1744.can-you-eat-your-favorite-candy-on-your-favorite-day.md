## 题目描述

给你一个下标从 **0** 开始的正整数数组 `candiesCount`，其中 `candiesCount[i]` 表示第 `i` 类糖果的数目。同时给你一个二维数组 `queries`，其中 `queries[i] = [favoriteType_i, favoriteDay_i, dailyCap_i]`。

每天你会吃**至少 1 颗**且最多 `dailyCap_i` 颗糖果（但保证至少吃 1 颗）。你必须按照**类型编号顺序**吃糖果，即先把第 0 类全吃完，再吃第 1 类...

对于第 `i` 个查询，判断在第 `favoriteDay_i` 天（从第 0 天开始）是否可以吃到第 `favoriteType_i` 类糖果（即在那天吃了至少一颗第 `favoriteType_i` 类糖果）。

**示例：**
```
输入：candiesCount = [7,4,5,3,8], queries = [[0,2,2],[4,2,4],[2,13,1000000000]]
输出：[true,false,true]
```

**提示：**
- `1 <= candiesCount.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `0 <= favoriteType_i < candiesCount.length`

## 解题思路

对于查询 `(t, d, cap)`，能在第 `d` 天吃到第 `t` 类糖果的条件：

1. **第 d 天最多能吃** `d * cap` 颗糖果（每天 cap 颗，共 d+1 天，即 0..d）
   - 注意：d 从 0 开始，第 d 天之前（含第 d 天）共吃了 `(d+1) * cap` 颗
2. **第 d 天最少已吃** `d + 1` 颗糖果（每天至少 1 颗）

第 `t` 类糖果的范围（前缀和）：
- 最晚开始吃第 `t` 类的颗数：`prefix[t]`（前 t 类全吃完）
- 最早开始吃第 `t` 类的颗数：`prefix[t] + 1`（第 t 类第一颗）
- 最晚吃完第 `t` 类的颗数：`prefix[t+1]`

能在第 `d` 天吃到第 `t` 类，当且仅当：
- `(d+1) * 1 <= prefix[t+1]`（至少吃 d+1 颗不超过前 t+1 类的总数）
- `(d+1) * cap >= prefix[t] + 1`（最多吃 d+1 天能吃到第 t 类的第一颗）

## 代码实现

### 方法一：前缀和 + 双不等式（推荐）

```python
from typing import List

class Solution:
    def canEat(self, candiesCount: List[int], queries: List[List[int]]) -> List[bool]:
        n = len(candiesCount)
        
        # 计算前缀和
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + candiesCount[i]
        
        ans = []
        for t, d, cap in queries:
            # 第 d 天（从0起）结束时，最少吃 d+1 颗，最多吃 (d+1)*cap 颗
            min_eaten = d + 1       # 最少吃的颗数
            max_eaten = (d + 1) * cap  # 最多吃的颗数
            
            # 第 t 类糖果的范围：前缀和 prefix[t]+1 到 prefix[t+1]
            # 第 t 类的第一颗是第 prefix[t]+1 颗，最后一颗是第 prefix[t+1] 颗
            candy_start = prefix[t] + 1    # 第 t 类第一颗的编号（1-indexed）
            candy_end = prefix[t + 1]       # 第 t 类最后一颗的编号
            
            # 能吃到第 t 类：吃的范围 [min_eaten, max_eaten] 与 [candy_start, candy_end] 有交集
            can = max_eaten >= candy_start and min_eaten <= candy_end
            ans.append(can)
        
        return ans
```

### 方法二：更直观的条件判断

```python
from typing import List

class Solution:
    def canEat(self, candiesCount: List[int], queries: List[List[int]]) -> List[bool]:
        n = len(candiesCount)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + candiesCount[i]
        
        ans = []
        for fav_type, fav_day, daily_cap in queries:
            # 条件1：到第 fav_day 天结束时（共 fav_day+1 天），
            #        即使每天最多吃 daily_cap 颗，也必须还没吃完 fav_type 之前的所有糖
            # 即 (fav_day+1)*daily_cap >= prefix[fav_type]+1
            cond1 = (fav_day + 1) * daily_cap >= prefix[fav_type] + 1
            
            # 条件2：到第 fav_day 天结束时，即使每天只吃1颗，也不超过前 fav_type+1 类的总数
            # 即 fav_day+1 <= prefix[fav_type+1]
            cond2 = fav_day + 1 <= prefix[fav_type + 1]
            
            ans.append(cond1 and cond2)
        
        return ans
```

## 复杂度分析

- **时间复杂度**：O(n + q)，预处理前缀和 O(n)，每次查询 O(1)
- **空间复杂度**：O(n)，前缀和数组

## 关键点总结

1. 问题转化为：第 `d` 天可以吃的颗数范围与第 `t` 类糖果的颗数范围有交集
2. 两个区间是否有交集：`max_eaten >= candy_start and min_eaten <= candy_end`
3. 注意日期从 0 开始，第 d 天共吃了 d+1 天

## 易错点

- 前缀和是累计糖果总数（1-indexed 处理更清晰）
- 注意乘法溢出：`(d+1) * cap` 可能很大，Python 整数无溢出
