## 题目描述

给你一个仅由小写英文字母组成的字符串 `s`，返回**以相同字母开头和结尾**的子字符串的数目。

**示例：**
```
输入：s = "abcba"
输出：7
解释：
长度 1 的子串：a, b, c, b, a（5 个）
跨越的：a...a（s[0..4]），b...b（s[1..3]），共 2 个
总计 7 个
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

**计数法（推荐）：**

对于每个字符 `c`，如果它在字符串中出现了 `cnt` 次，那么以 `c` 开头且以 `c` 结尾的子串数为：
- 长度为 1 的：`cnt` 个
- 长度 >= 2 的：每两个位置的组合 C(cnt, 2)

合并：以 `c` 开头和结尾的子串数 = `cnt * (cnt + 1) / 2`

具体来说，枚举字符 `c` 出现的次数 `k`，每次遇到 `c`，答案加上当前已经遇到的 `c` 的个数（包括自身）= 前缀计数。

## 代码实现

### 方法一：前缀计数（推荐）

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        count = {}  # 记录每个字符已出现的次数
        ans = 0

        for c in s:
            # 当前字符 c 与之前所有 c 配对，加上自身（长度1子串）
            count[c] = count.get(c, 0) + 1
            ans += count[c]

        return ans
```

### 方法二：统计各字符频次

```python
from collections import Counter

class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        freq = Counter(s)
        ans = 0

        # 每个字符出现 cnt 次，贡献 cnt*(cnt+1)//2 个子串
        for cnt in freq.values():
            ans += cnt * (cnt + 1) // 2

        return ans
```

## 复杂度分析

- 时间复杂度：O(n)，线性遍历
- 空间复杂度：O(1)，最多 26 个字母的计数

## 关键点总结

1. 对每个字母 `c`，出现 `cnt` 次时，以 `c` 开头和结尾的子串共 `C(cnt,2) + cnt = cnt*(cnt+1)/2` 个
2. 方法一利用前缀计数，每遇到 `c` 时直接加上当前计数（包含自身），等价于公式
3. 分析：遍历到第 `k` 个 `c` 时，它与之前 `k-1` 个 `c` 分别形成 1 个子串，加上自身长度1子串，共 `k` 个，总和为 `1+2+...+cnt = cnt*(cnt+1)/2`

## 易错点

- 不要忘记长度为 1 的子串（单个字符本身也满足开头结尾相同）
- 公式是 `cnt*(cnt+1)//2`，不是 `cnt*(cnt-1)//2`
