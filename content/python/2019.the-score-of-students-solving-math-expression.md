## 题目描述

给你一个字符串 `s`，仅含 `0-9` 的数字和 `+`、`*` 运算符，代表一个合法的数学表达式（操作数是一位数）。

学生解答了这道题，可能答对（正确计算），也可能犯错（错误地改变了运算顺序）。

给你一个整数数组 `answers`，`answers[i]` 是第 `i` 个学生的答案。

计分规则：
- 正确答案得 5 分
- 虽然不是正确答案，但可能通过重新加括号得到的结果得 2 分
- 其他情况 0 分

返回所有学生的总分。

**示例 1：**
```
输入：s = "7+3*1*2", answers = [20,13,42]
输出：7
解释：正确答案为 13（5分），20 可通过加括号得到（(7+3)*1*2=20，2分），42 不合法（0分）
```

**提示：**
- `3 <= s.length <= 31`
- `s` 由单位数字和 `+`、`*` 组成
- 表达式合法（不含括号）
- `1 <= answers.length <= 10^4`
- `0 <= answers[i] <= 1000`

## 解题思路

**核心：** 用区间 DP 计算表达式的所有**可能结果集合**（通过不同括号加法得到的所有可能值）。

**dp 定义：** `dp[i][j]` = 子表达式 `s[i..j]` 通过所有可能的括号方式能得到的结果集合。

**状态转移：** 对于 `s[i..j]`，枚举最后一个运算符位置 `k`：
- 对 `dp[i][k-1]` 中每个值 `a` 和 `dp[k+1][j]` 中每个值 `b`
- 如果 `s[k] == '+'`：`dp[i][j].add(a + b)`
- 如果 `s[k] == '*'`：`dp[i][j].add(a * b)`

由于数字最大为 1000（`9*9*...*9 <= 1000`），可以限制集合大小。

## 代码实现

### 方法一：区间 DP（推荐）

```python
from typing import List

class Solution:
    def scoreOfStudents(self, s: str, answers: List[int]) -> int:
        # 解析表达式为数字和运算符交替的列表
        nums = []
        ops = []
        for i, c in enumerate(s):
            if i % 2 == 0:
                nums.append(int(c))
            else:
                ops.append(c)

        n = len(nums)  # 数字个数
        MAX_VAL = 1000  # 结果不可能超过 1000

        # dp[i][j] 表示第 i 到第 j 个数字（含）通过各种括号得到的所有可能值的集合
        dp = [[set() for _ in range(n)] for _ in range(n)]
        for i in range(n):
            dp[i][i].add(nums[i])

        # 区间 DP，按长度枚举
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                # 枚举分割点 k（运算符 ops[k] 连接 nums[k] 和 nums[k+1]）
                for k in range(i, j):
                    for a in dp[i][k]:
                        for b in dp[k + 1][j]:
                            val = a + b if ops[k] == '+' else a * b
                            if val <= MAX_VAL:
                                dp[i][j].add(val)

        # 计算正确答案
        correct = eval(s)
        possible = dp[0][n - 1]

        total = 0
        for ans in answers:
            if ans == correct:
                total += 5
            elif ans in possible:
                total += 2

        return total
```

### 方法二：用栈计算正确答案 + 区间 DP

```python
from typing import List

class Solution:
    def scoreOfStudents(self, s: str, answers: List[int]) -> int:
        # 用栈计算正确答案（先乘后加）
        def calc_correct(expr: str) -> int:
            stack = []
            i = 0
            while i < len(expr):
                if expr[i].isdigit():
                    num = int(expr[i])
                    if stack and stack[-1] == '*':
                        stack.pop()   # 弹出 '*'
                        stack[-1] *= num  # 合并乘法
                    else:
                        stack.append(num)
                elif expr[i] in '+-*':
                    stack.append(expr[i])
                i += 1
            return sum(x for x in stack if isinstance(x, int))

        correct = calc_correct(s)

        # 区间 DP 计算所有可能值
        nums = [int(s[i]) for i in range(0, len(s), 2)]
        ops = [s[i] for i in range(1, len(s), 2)]
        n = len(nums)
        LIMIT = 1000

        dp = [[set() for _ in range(n)] for _ in range(n)]
        for i in range(n):
            dp[i][i] = {nums[i]}

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                for k in range(i, j):
                    op = ops[k]
                    for a in dp[i][k]:
                        for b in dp[k + 1][j]:
                            v = a + b if op == '+' else a * b
                            if v <= LIMIT:
                                dp[i][j].add(v)

        possible = dp[0][n - 1]
        total = 0
        for ans in answers:
            if ans == correct:
                total += 5
            elif ans != correct and ans in possible:
                total += 2

        return total
```

## 复杂度分析

- 时间复杂度：O(n^3 * V^2)，n 为操作数个数，V 为值域大小（≤1000）
- 空间复杂度：O(n^2 * V)

## 关键点总结

1. 区间 DP 计算所有可能的括号方案结果
2. 限制结果值 <= 1000，防止集合过大（实际上两个单位数乘积最大 81，经多次加不超过 1000）
3. 答案集合 `possible` 包含的是"加了括号但不一定正确"的值，不含正确答案

## 易错点

- 注意 5 分和 2 分互斥：正确答案得 5 分，不能再得 2 分
- 检查 2 分时要排除正确答案（`ans != correct and ans in possible`）
- 值域裁剪 `val <= 1000` 是正确的，防止集合爆炸
