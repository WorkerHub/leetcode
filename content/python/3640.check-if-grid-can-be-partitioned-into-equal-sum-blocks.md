## 题目描述

给你一个 `m x n` 的矩阵 `grid`，判断是否可以通过若干次水平或垂直切割，将矩阵分成若干块，使得每块的元素之和相等。

**示例 1：**

```
输入：grid = [[1,1],[1,1]]
输出：true
解释：每块和均为1（切成4个1x1块）
```

**示例 2：**

```
输入：grid = [[1,2],[3,4]]
输出：false
解释：无论如何切割，都无法使各块和相等
```

**提示：**

- `1 <= m, n <= 10^3`
- `1 <= grid[i][j] <= 10^4`

## 解题思路

考虑行前缀和和列前缀和：

若可以切割，则每列之和相等（水平切割方向）或每行之和相等（垂直切割方向）。

枚举水平切割：每行之和的前缀是否存在均匀分割点。
枚举垂直切割：每列之和的前缀是否存在均匀分割点。

判断一维数组是否可以分成若干段使每段和相等。

## Python 代码实现

### 方法一：行列前缀和检验（推荐）

```python
from typing import List

class Solution:
    def canPartition(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        def can_split(arr: List[int]) -> bool:
            total = sum(arr)
            if total == 0:
                return True
            # 检查是否存在任意均等分割
            prefix = 0
            for x in arr[:-1]:
                prefix += x
                if total % prefix == 0 or prefix % total == 0:
                    pass
            # 简化：检查前缀和是否能整除总和
            prefix = 0
            for x in arr[:-1]:
                prefix += x
                if total % prefix == 0:
                    # 检查每段是否都等于 prefix
                    target = prefix
                    curr = 0
                    valid = True
                    for y in arr:
                        curr += y
                        if curr == target:
                            curr = 0
                        elif curr > target:
                            valid = False
                            break
                    if valid and curr == 0:
                        return True
            return False

        # 检查按行切割（每行之和组成的数组）
        row_sums = [sum(grid[i]) for i in range(m)]
        if can_split(row_sums):
            return True

        # 检查按列切割
        col_sums = [sum(grid[i][j] for i in range(m)) for j in range(n)]
        if can_split(col_sums):
            return True

        return False
```

### 方法二：暴力枚举切割

```python
from typing import List

class Solution:
    def canPartition(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)

        # 尝试按行切割
        prefix = 0
        for i in range(m - 1):
            prefix += sum(grid[i])
            if total % prefix == 0:
                target = prefix
                curr = 0
                valid = True
                for k in range(m):
                    curr += sum(grid[k])
                    if curr == target:
                        curr = 0
                    elif curr > target:
                        valid = False
                        break
                if valid:
                    return True

        # 尝试按列切割
        prefix = 0
        for j in range(n - 1):
            prefix += sum(grid[i][j] for i in range(m))
            if total % prefix == 0:
                target = prefix
                curr = 0
                valid = True
                for k in range(n):
                    curr += sum(grid[i][k] for i in range(m))
                    if curr == target:
                        curr = 0
                    elif curr > target:
                        valid = False
                        break
                if valid:
                    return True

        return False
```

## 复杂度分析

- 时间复杂度：O(m * n + (m + n)^2)
- 空间复杂度：O(m + n)

## 关键点总结

1. 只需考虑水平或垂直切割（单向）
2. 将行和/列和转化为一维数组，判断能否等分
3. 一维等分判断：前缀和为总和的因子，且实际每段都等于目标值

## 易错点

1. 切割需要完整贯穿整个矩阵（水平或垂直直线切割）
2. 多次切割时每次的目标值需一致
3. 不考虑混合方向切割
