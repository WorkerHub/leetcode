## 题目描述

给你一棵二叉树的根节点 `root`，请你按以下方式收集树的叶子节点：

1. 收集所有叶子节点
2. 删除所有叶子节点
3. 重复步骤 1 和 2，直到树为空

返回一个二维数组 `answer`，其中 `answer[i]` 是第 `i` 次收集的所有叶子节点的值（从左到右）。

**示例 1：**

```
输入：root = [1,2,3,4,5]
输出：[[4,5,3],[2],[1]]
解释：
[[3,5,4],[2],[1]] 和 [[3,4,5],[2],[1]] 也是正确答案
```

示例图：
```
        1
       / \
      2   3
     / \
    4   5

第一次：叶子节点 [4, 5, 3]
第二次：叶子节点 [2]
第三次：叶子节点 [1]
```

**示例 2：**

```
输入：root = [1]
输出：[[1]]
```

**提示：**
- 树中节点数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

这道题的关键是理解"按层收集叶子节点"的本质。

### 核心观察

观察示例 1：
- 第一次收集：节点 4、5、3（它们的高度都是 0）
- 第二次收集：节点 2（删除 4、5 后，它的高度变为 0）
- 第三次收集：节点 1（删除 2、3 后，它的高度变为 0）

**结论**：第 `i` 次被收集的节点，其高度都是 `i-1`。

### 定义高度

- 叶子节点的高度为 0
- 非叶子节点的高度 = max(左子树高度, 右子树高度) + 1

### 算法思路

使用 DFS 后序遍历：
1. 递归计算每个节点的高度
2. 将节点按高度分组
3. 高度相同的节点在同一轮被收集

## Python 代码实现

### 方法一：DFS 后序遍历（推荐）

```python
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def findLeaves(self, root: Optional[TreeNode]) -> List[List[int]]:
        """
        DFS 后序遍历，按高度分组
        时间复杂度：O(n)
        空间复杂度：O(n)
        """
        result = []
        
        def dfs(node: Optional[TreeNode]) -> int:
            """
            返回节点的高度，并将节点加入对应高度的分组
            """
            if not node:
                return -1  # 空节点高度定义为 -1
            
            # 后序遍历：先处理左右子树
            left_height = dfs(node.left)
            right_height = dfs(node.right)
            
            # 当前节点的高度
            height = max(left_height, right_height) + 1
            
            # 确保 result 有足够的空间
            if height >= len(result):
                result.append([])
            
            # 将当前节点加入对应高度的分组
            result[height].append(node.val)
            
            return height
        
        dfs(root)
        return result
```

### 方法二：使用字典存储（更直观）

```python
from typing import List, Optional
from collections import defaultdict

class Solution:
    def findLeaves(self, root: Optional[TreeNode]) -> List[List[int]]:
        """
        使用字典按高度分组
        """
        height_map = defaultdict(list)
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return -1
            
            left_height = dfs(node.left)
            right_height = dfs(node.right)
            height = max(left_height, right_height) + 1
            
            # 将节点值加入对应高度的列表
            height_map[height].append(node.val)
            
            return height
        
        max_height = dfs(root)
        
        # 按高度顺序组织结果
        result = []
        for h in range(max_height + 1):
            result.append(height_map[h])
        
        return result
```

### 方法三：显式模拟删除过程（不推荐，低效）

```python
from typing import List, Optional

class Solution:
    def findLeaves(self, root: Optional[TreeNode]) -> List[List[int]]:
        """
        模拟实际的删除过程
        时间复杂度：O(n^2)，每次都要遍历整棵树
        """
        result = []
        
        while root:
            leaves = []
            root = self.removeLeaves(root, leaves)
            result.append(leaves)
        
        return result
    
    def removeLeaves(self, node: Optional[TreeNode], 
                     leaves: List[int]) -> Optional[TreeNode]:
        """
        删除叶子节点，并收集它们的值
        """
        if not node:
            return None
        
        # 如果是叶子节点
        if not node.left and not node.right:
            leaves.append(node.val)
            return None  # 删除该节点
        
        # 递归处理左右子树
        node.left = self.removeLeaves(node.left, leaves)
        node.right = self.removeLeaves(node.right, leaves)
        
        return node
```

## 复杂度分析

### 方法一/二：DFS 后序遍历
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈 + 结果数组

### 方法三：模拟删除
- 时间复杂度：O(n × h)，h 为树高，每次都要遍历树
- 空间复杂度：O(n)

## 关键点总结

1. **高度定义**：叶子节点高度为 0，向上递增
2. **后序遍历**：必须先知道子树高度，才能计算当前节点高度
3. **按高度分组**：高度相同的节点在同一轮被收集
4. **空节点高度**：定义为 -1，使得叶子节点高度为 0
5. **优化思想**：避免实际删除节点，直接按高度分组

## 易错点

1. **高度定义**：注意空节点高度为 -1，叶子节点为 0
2. **遍历顺序**：必须用后序遍历，先处理子节点
3. **数组初始化**：要确保 result 有足够的空间
4. **边界情况**：单节点树、空树的处理
5. **顺序问题**：题目允许同一高度的节点以任意顺序出现
