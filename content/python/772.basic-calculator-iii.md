## 题目描述

实现一个基本的计算器来计算简单的表达式字符串。

表达式字符串可以包含：
- 非负整数
- `+`, `-`, `*`, `/` 运算符
- 左括号 `(` 和右括号 `)`

## 解题思路

使用栈处理优先级和括号。

## Python 代码实现

```python
class Solution:
    def calculate(self, s: str) -> int:
        def helper(s):
            stack = []
            num = 0
            sign = '+'
            
            for i, char in enumerate(s):
                if char.isdigit():
                    num = num * 10 + int(char)
                elif char == '(':
                    # 递归处理括号内容
                    num, i = helper(s[i+1:])
                
                if char in '+-*/' or i == len(s) - 1:
                    if sign == '+':
                        stack.append(num)
                    elif sign == '-':
                        stack.append(-num)
                    elif sign == '*':
                        stack.append(stack.pop() * num)
                    elif sign == '/':
                        stack.append(int(stack.pop() / num))
                    
                    sign = char
                    num = 0
                
                if char == ')':
                    break
            
            return sum(stack)
        
        return helper(s)
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(n)
