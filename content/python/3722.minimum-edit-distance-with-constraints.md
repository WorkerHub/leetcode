## 题目描述

给定两个字符串 `word1` 和 `word2`，以及一组禁止操作约束 `constraints`。每个约束 `constraints[i] = [t, i1, i2]` 表示：不允许对 `word1[i1]` 和 `word2[i2]` 使用操作类型 `t`（0=插入，1=删除，2=替换）。

在满足约束的条件下，求将 `word1` 转换为 `word2` 所需的最小操作数。若无法完成转换，返回 `-1`。

**示例 1：**
```
输入：word1 = "abc", word2 = "adc", constraints = []
输出：1
解释：将 'b' 替换为 'd'，一次操作。
```

**示例 2：**
```
输入：word1 = "ab", word2 = "b", constraints = [[1, 0, 0]]
输出：-1
解释：需要删除 word1[0]='a'，但该操作被禁止。
```

**提示：**
- `0 <= word1.length, word2.length <= 100`
- `0 <= constraints.length <= 50`

## 解题思路

带约束的编辑距离，在经典编辑距离 DP 的基础上加入约束检查。

**经典编辑距离 DP：**
- `dp[i][j]`：将 `word1[0..i-1]` 转换为 `word2[0..j-1]` 的最小操作数
- 转移：
  - 若 `word1[i-1] == word2[j-1]`：`dp[i][j] = dp[i-1][j-1]`
  - 删除 `word1[i-1]`：`dp[i][j] = dp[i-1][j] + 1`（若未被约束）
  - 插入 `word2[j-1]`：`dp[i][j] = dp[i][j-1] + 1`（若未被约束）
  - 替换：`dp[i][j] = dp[i-1][j-1] + 1`（若未被约束）

约束需预处理为集合，方便 O(1) 查询。

## Python 代码实现

### 方法一：带约束的编辑距离 DP（推荐）

```python
from typing import List

class Solution:
    def minEditDistance(self, word1: str, word2: str, constraints: List[List[int]]) -> int:
        m, n = len(word1), len(word2)
        INF = float('inf')

        # 预处理约束
        forbidden = set()
        for t, i1, i2 in constraints:
            forbidden.add((t, i1, i2))

        # dp[i][j]: word1[0..i-1] -> word2[0..j-1] 的最小操作数
        dp = [[INF] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = 0

        # 初始化第一行（从 word1 前缀转换为空串：全部删除）
        for i in range(1, m + 1):
            if (1, i - 1, 0) not in forbidden:  # 删除 word1[i-1]
                if dp[i-1][0] != INF:
                    dp[i][0] = dp[i-1][0] + 1

        # 初始化第一列（空串转换为 word2 前缀：全部插入）
        for j in range(1, n + 1):
            if (0, 0, j - 1) not in forbidden:  # 插入 word2[j-1]
                if dp[0][j-1] != INF:
                    dp[0][j] = dp[0][j-1] + 1

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 字符相同，不需要操作
                if word1[i-1] == word2[j-1]:
                    if dp[i-1][j-1] != INF:
                        dp[i][j] = min(dp[i][j], dp[i-1][j-1])

                # 删除 word1[i-1]
                if (1, i-1, j-1) not in forbidden and dp[i-1][j] != INF:
                    dp[i][j] = min(dp[i][j], dp[i-1][j] + 1)

                # 插入 word2[j-1]
                if (0, i-1, j-1) not in forbidden and dp[i][j-1] != INF:
                    dp[i][j] = min(dp[i][j], dp[i][j-1] + 1)

                # 替换 word1[i-1] 为 word2[j-1]
                if word1[i-1] != word2[j-1]:
                    if (2, i-1, j-1) not in forbidden and dp[i-1][j-1] != INF:
                        dp[i][j] = min(dp[i][j], dp[i-1][j-1] + 1)

        return dp[m][n] if dp[m][n] != INF else -1
```

### 方法二：无约束基础版（对比参考）

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = list(range(n + 1))

        for i in range(1, m + 1):
            prev = dp[0]
            dp[0] = i
            for j in range(1, n + 1):
                temp = dp[j]
                if word1[i-1] == word2[j-1]:
                    dp[j] = prev
                else:
                    dp[j] = 1 + min(prev, dp[j], dp[j-1])
                prev = temp

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 带约束的编辑距离在每次转移前检查该操作是否被禁止
2. 约束预处理为 set，查询 O(1)
3. 无法到达的状态用 INF 标记，最终若 `dp[m][n] == INF` 则返回 -1

## 易错点

1. 初始化第一行/列时也需要检查约束（删除/插入操作是否被禁止）
2. 约束中的下标 i1, i2 从 0 开始，与 DP 下标有偏移
