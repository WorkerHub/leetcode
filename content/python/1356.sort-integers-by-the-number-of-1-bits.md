## 题目描述

给你一个整数数组 `arr`，请你将数组中的元素按照其二进制表示中数字 `1` 的数目升序排序。

如果存在多个数字的 `1` 的数目相同，则必须将它们按照**数值大小升序**排列。

请你返回排序后的数组。

**示例 1：**
```
输入：arr = [0,1,2,3,4,5,6,7,8]
输出：[0,1,2,4,8,3,5,6,7]
解释：[0] 是唯一一个有 0 个 1 的数。
     [1,2,4,8] 都有 1 个 1。
     [3,5,6] 有 2 个 1。
     [7] 有 3 个 1。
```

**示例 2：**
```
输入：arr = [1024,512,256,128,64,32,16,8,4,2,1]
输出：[1,2,4,8,16,32,64,128,256,512,1024]
解释：所有整数有且仅有 1 个 1 ，所以按数值大小升序排列。
```

**示例 3：**
```
输入：arr = [10000,10000]
输出：[10000,10000]
```

**提示：**
- `1 <= arr.length <= 500`
- `0 <= arr[i] <= 10^4`

## 解题思路

题目要求自定义排序：**主键**为二进制中 1 的个数（升序），**次键**为数值本身（升序）。

统计一个整数二进制中 1 的个数有多种方法：
1. Python 内置 `bin(x).count('1')`
2. Python 3.10+ 的 `int.bit_count()`
3. 手动位运算：`x & (x-1)` 消去最低位的 1，计数循环次数
4. `bin(x)` 转二进制字符串后计数

## Python 代码实现

### 方法一：Python 内置排序（最简洁，推荐）

```python
from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        # 使用自定义排序键：(1的个数, 数值本身)
        return sorted(arr, key=lambda x: (bin(x).count('1'), x))
```

**解释：**
- `bin(x)` 将整数转为二进制字符串，如 `bin(6)` 返回 `'0b110'`。
- `.count('1')` 统计其中 '1' 的个数。
- 排序键是二元组 `(1的个数, 数值)`，Python 对元组按字典序比较，先比第一个元素，相同再比第二个，恰好满足题目要求。

### 方法二：bit_count() 方法（Python 3.10+）

```python
from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        # Python 3.10+ 整数内置 bit_count() 方法
        return sorted(arr, key=lambda x: (x.bit_count(), x))
```

### 方法三：手动位运算统计 1 的个数

```python
from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        
        def count_ones(x: int) -> int:
            """统计 x 二进制中 1 的个数（Brian Kernighan 算法）"""
            count = 0
            while x:
                x &= (x - 1)  # 消去最低位的 1
                count += 1
            return count
        
        return sorted(arr, key=lambda x: (count_ones(x), x))
```

**Brian Kernighan 算法说明：** `x & (x-1)` 会将 x 最低位的 1 变为 0（其余不变），循环直到 x 为 0，循环次数即为 1 的个数。

**示例：** x=6（二进制 110）
```
x=6（110）: 6 & 5 = 4（100），count=1
x=4（100）: 4 & 3 = 0（000），count=2
x=0，结束，返回 2
```

### 方法四：预处理 + 排序（大数据量时更高效）

```python
from typing import List

class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        # 预先计算所有值的 1 的个数，避免重复计算
        # 对于值域 [0, 10^4]，可用打表
        bit_count = [bin(i).count('1') for i in range(10001)]
        return sorted(arr, key=lambda x: (bit_count[x], x))
```

## 复杂度分析

- 时间复杂度：O(N log N * K)，其中 N 是数组长度，K 是统计 1 个数的时间（对于 `bin().count('1')` 约 O(log(max_val))，对于 Brian Kernighan 算法约 O(popcount)）。整体约 O(N log N * log(max_val))。
- 空间复杂度：O(N)，排序的额外空间。

## 二进制 1 的个数统计方法对比

| 方法 | 时间复杂度 | 代码简洁度 | 说明 |
|------|------------|------------|------|
| `bin(x).count('1')` | O(bits) | 最简洁 | Python 内置，推荐 |
| `x.bit_count()` | O(1) | 简洁 | Python 3.10+ |
| Brian Kernighan | O(popcount) | 较复杂 | 理解位运算的好方法 |
| 预处理打表 | O(1) | 较复杂 | 值域固定时高效 |

## 关键点总结

1. Python `sorted()` 支持自定义 `key` 函数，用元组 `(主键, 次键)` 实现多级排序。
2. `bin(x).count('1')` 是 Python 统计二进制中 1 个数的最简写法。
3. Brian Kernighan 算法 `x & (x-1)` 是位运算中的经典技巧，每次消去最低位的 1。
4. Python 的 `sorted()` 是稳定排序（Tim Sort），时间复杂度 O(N log N)。
5. 元组比较时按字典序：先比第一个元素，相同时再比第二个，完美匹配题目的双重排序要求。

## 易错点

- `bin(x)` 返回的字符串以 `'0b'` 开头（如 `bin(5) = '0b101'`），但 `.count('1')` 只计数 '1' 字符，不受 '0b' 前缀影响，可以放心使用。
- 对 x=0 的处理：`bin(0) = '0b0'`，`bin(0).count('1') = 0`，结果正确，不需要特判。
- 排序键必须是 `(bit_count, value)`，而不能只用 `bit_count`（忽略次键会导致相同 1 个数的元素顺序不确定）。
