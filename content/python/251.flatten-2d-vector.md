## 题目描述

设计并实现一个迭代器来展开一个二维向量。迭代器需要支持 `next` 和 `hasNext` 两个操作。

**示例：**

```python
Vector2D iterator = new Vector2D([[1,2],[3],[4]]);

iterator.next();    // 返回 1
iterator.next();    // 返回 2
iterator.next();    // 返回 3
iterator.hasNext(); // 返回 true
iterator.hasNext(); // 返回 true
iterator.next();    // 返回 4
iterator.hasNext(); // 返回 false
```

**提示：**
- `next()` 和 `hasNext()` 的调用次数最多为 100 次
- 你可以假定 `next()` 的调用总是有效的

## 解题思路

这道题目要求我们设计一个迭代器，将二维数组展开成一维进行遍历。核心思想是使用两个指针来追踪当前位置：
1. 外层指针：指向当前所在的子数组
2. 内层指针：指向当前子数组中的元素位置

关键点：
- 需要处理空数组的情况
- `hasNext()` 需要跳过空的子数组
- 保持指针的正确移动

## Python 代码实现

### 方法一：双指针（推荐）⭐

```python
from typing import List

class Vector2D:
    def __init__(self, vec: List[List[int]]):
        """
        初始化迭代器
        时间复杂度：O(1)
        """
        self.vec = vec
        self.outer = 0  # 外层指针，指向当前子数组
        self.inner = 0  # 内层指针，指向子数组中的元素
    
    def next(self) -> int:
        """
        返回下一个元素
        时间复杂度：O(1)
        """
        # hasNext() 已经确保了当前位置有效
        self.hasNext()
        result = self.vec[self.outer][self.inner]
        self.inner += 1
        return result
    
    def hasNext(self) -> bool:
        """
        判断是否还有下一个元素
        时间复杂度：O(1) 均摊
        """
        # 跳过空数组
        while self.outer < len(self.vec):
            # 当前子数组还有元素
            if self.inner < len(self.vec[self.outer]):
                return True
            # 移动到下一个子数组
            self.outer += 1
            self.inner = 0
        return False
```

### 方法二：预处理展开（空间换时间）

```python
from typing import List

class Vector2D:
    def __init__(self, vec: List[List[int]]):
        """
        在初始化时就展开所有元素
        时间复杂度：O(n)，n 为总元素数
        空间复杂度：O(n)
        """
        self.nums = []
        # 展开所有元素
        for row in vec:
            for num in row:
                self.nums.append(num)
        self.index = 0
    
    def next(self) -> int:
        """
        返回下一个元素
        时间复杂度：O(1)
        """
        result = self.nums[self.index]
        self.index += 1
        return result
    
    def hasNext(self) -> bool:
        """
        判断是否还有下一个元素
        时间复杂度：O(1)
        """
        return self.index < len(self.nums)
```

### 方法三：使用生成器（Python 特色）

```python
from typing import List

class Vector2D:
    def __init__(self, vec: List[List[int]]):
        """
        使用生成器实现
        """
        def flatten():
            for row in vec:
                for num in row:
                    yield num
        
        self.generator = flatten()
        self.next_val = None
        self.has_next = True
        self._advance()
    
    def _advance(self):
        """预取下一个值"""
        try:
            self.next_val = next(self.generator)
            self.has_next = True
        except StopIteration:
            self.has_next = False
    
    def next(self) -> int:
        """返回下一个元素"""
        result = self.next_val
        self._advance()
        return result
    
    def hasNext(self) -> bool:
        """判断是否还有下一个元素"""
        return self.has_next
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：
  - `__init__()`: O(1)
  - `next()`: O(1)
  - `hasNext()`: O(1) 均摊，最坏情况 O(k)，k 为连续空数组数量
- 空间复杂度：O(1)，只使用常数额外空间

**方法二（预处理）：**
- 时间复杂度：
  - `__init__()`: O(n)
  - `next()`: O(1)
  - `hasNext()`: O(1)
- 空间复杂度：O(n)

**方法三（生成器）：**
- 时间复杂度：O(1) 每次操作
- 空间复杂度：O(1)

## 关键点总结

1. **双指针技巧**：使用外层和内层两个指针追踪当前位置
2. **边界处理**：正确处理空数组和数组末尾的情况
3. **懒加载 vs 预处理**：双指针是懒加载，预处理是空间换时间
4. **hasNext() 的责任**：应该负责跳过空数组，定位到下一个有效位置
5. **Python 生成器**：利用 Python 的生成器特性可以简化实现

## 易错点

1. **忘记跳过空数组**：在 `hasNext()` 中必须处理空子数组
   ```python
   # 错误：没有跳过空数组
   if self.inner < len(self.vec[self.outer]):
       return True
   
   # 正确：使用 while 循环跳过所有空数组
   while self.outer < len(self.vec):
       if self.inner < len(self.vec[self.outer]):
           return True
       self.outer += 1
       self.inner = 0
   ```

2. **next() 中重复检查**：`next()` 应该依赖 `hasNext()` 的检查结果
   ```python
   # 推荐：先调用 hasNext() 确保位置有效
   def next(self):
       self.hasNext()
       result = self.vec[self.outer][self.inner]
       self.inner += 1
       return result
   ```

3. **指针更新时机**：移动到下一个子数组时，要重置内层指针为 0

4. **边界条件**：测试空数组、只有一个元素、全是空数组等极端情况
