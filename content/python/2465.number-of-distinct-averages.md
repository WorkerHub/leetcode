## 题目描述

给你一个 **下标从 0 开始** 长度为 **偶数** 的整数数组 `nums`。

只要 `nums` **不是** 空数组，你就可以执行以下步骤：

- 找到 `nums` 中的最小值，并删除它。
- 找到 `nums` 中的最大值，并删除它。
- 计算删除两个元素的 **平均值**。

返回上述过程中生成的 **不同** 平均值的数目。

**示例 1：**
```
输入：nums = [4,1,4,0,3,5]
输出：2
解释：
1. 删除 0 和 5，平均值 (0+5)/2 = 2.5
2. 删除 1 和 4，平均值 (1+4)/2 = 2.5
3. 删除 3 和 4，平均值 (3+4)/2 = 3.5
不同的平均值有 {2.5, 3.5}，共 2 个。
```

**示例 2：**
```
输入：nums = [1,100]
输出：1
```

**提示：**
- `2 <= nums.length <= 100`
- `nums.length` 是偶数
- `0 <= nums[i] <= 100`

## 解题思路

排序后用双指针，每次取最小值和最大值的和（不需要真正除以 2，用和来区分是否相同），存入集合，返回集合大小。

**注意：** 由于只需判断不同的平均值数目，可以用（最小 + 最大）的和代替（避免浮点数），两个和相同当且仅当平均值相同。

## 代码实现

### 方法一：排序 + 双指针 + 集合（推荐）

```python
from typing import List

class Solution:
    def distinctAverages(self, nums: List[int]) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1
        seen = set()

        while left < right:
            seen.add(nums[left] + nums[right])  # 用和代替平均值
            left += 1
            right -= 1

        return len(seen)
```

### 方法二：排序后逐对比较

```python
from typing import List

class Solution:
    def distinctAverages(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        averages = set()

        for i in range(n // 2):
            # 第 i 小和第 i 大（从右数第 i 个）
            avg = nums[i] + nums[n - 1 - i]
            averages.add(avg)

        return len(averages)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序 + 双指针 | O(n log n) | O(n) |

## 关键点总结

1. 排序后，最小值和最大值分别在两端，双指针向中间逼近
2. 用两数之和代替平均值，避免浮点运算（集合中存整数）
3. 集合自动去重，大小即为不同平均值数目

## 易错点

- 无需真正计算平均值（除以 2），只需用和来去重
- 排序后对称位置的元素配对
