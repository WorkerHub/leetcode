## 题目描述

给你两个字符串 `word1` 和 `word2`，请你按下述方法构造一个字符串：
- 从 `word1` 中选出某个**非空**子序列 `subsequence1`。
- 从 `word2` 中选出某个**非空**子序列 `subsequence2`。
- 连接两个子序列 `subsequence1 + subsequence2`，得到字符串。

返回可构造的最长**回文串**的长度。如果无法构造回文串，返回 `0`。

**示例：**
```
输入：word1 = "cacb", word2 = "cbba"
输出：5
解释：选 word1 中的 "c"，word2 中的 "bbc"，连接得 "cbbc" 长度4... 最优是 "abcba" 长度5
```

**提示：**
- `1 <= word1.length, word2.length <= 1000`

## 解题思路

将两个字符串拼接为 `s = word1 + word2`，求 `s` 的最长回文子序列（LPS）。

但要确保最终回文串至少包含一个来自 `word1` 的字符和一个来自 `word2` 的字符。

**关键**：区间 DP 求 LPS，`dp[i][j]` = `s[i..j]` 的最长回文子序列长度。对于跨越 `word1` 和 `word2` 分界的回文串（即 `s[i]` 来自 `word1`，`s[j]` 来自 `word2`，且 `s[i] == s[j]` 时），记录最大值。

## 代码实现

### 方法一：区间 DP（推荐）

```python
class Solution:
    def longestPalindrome(self, word1: str, word2: str) -> int:
        s = word1 + word2
        n = len(s)
        n1 = len(word1)
        
        # dp[i][j] = s[i..j] 的最长回文子序列
        dp = [[0] * n for _ in range(n)]
        
        # 长度 1 的子串
        for i in range(n):
            dp[i][i] = 1
        
        ans = 0
        
        # 按长度由小到大
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                    # 如果 s[i] 来自 word1，s[j] 来自 word2，则这是一个有效答案
                    if i < n1 <= j:
                        ans = max(ans, dp[i][j])
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        
        return ans
```

### 方法二：记忆化递归

```python
from functools import lru_cache

class Solution:
    def longestPalindrome(self, word1: str, word2: str) -> int:
        s = word1 + word2
        n = len(s)
        n1 = len(word1)
        ans = [0]
        
        @lru_cache(maxsize=None)
        def dp(i, j):
            if i > j:
                return 0
            if i == j:
                return 1
            if s[i] == s[j]:
                res = dp(i + 1, j - 1) + 2
                if i < n1 <= j:
                    ans[0] = max(ans[0], res)
                return res
            return max(dp(i + 1, j), dp(i, j - 1))
        
        dp(0, n - 1)
        return ans[0]
```

## 复杂度分析

- **时间复杂度**：O((n1 + n2)^2)
- **空间复杂度**：O((n1 + n2)^2)

## 关键点总结

1. 拼接两个字符串，求 LPS
2. 在 LPS 计算中，记录跨越两个字符串分界的回文（确保两个字符串各有贡献）
3. 只在 `s[i]` 来自 `word1` 且 `s[j]` 来自 `word2` 时更新答案

## 易错点

- 必须要求结果回文串包含 `word1` 和 `word2` 各至少一个字符
- 跨界条件：`i < n1 <= j`（即 `i` 在 `word1` 中，`j` 在 `word2` 中）
