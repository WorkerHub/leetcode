## 题目描述

给定一棵二叉树的根节点 `root`，返回所有子树的平均值中的最大值。

子树是树中的任意节点和它的所有后代。树的平均值是树中所有节点值的总和除以节点数。

**示例 1:**

```
输入: root = [5,6,1]
输出: 6.00000
解释: 
对于值为5的节点，平均值为 (5 + 6 + 1) / 3 = 4。
对于值为6的节点，平均值为 6 / 1 = 6。
对于值为1的节点，平均值为 1 / 1 = 1。
所以答案是6。
```

**示例 2:**

```
输入: root = [0,null,1]
输出: 1.00000
```

**提示:**

- 树中节点数在 `[1, 10^4]` 范围内
- `0 <= Node.val <= 10^5`

## 解题思路

这道题需要计算每个子树的平均值，找出最大的那个。

关键观察：
1. 需要遍历每个节点作为子树的根
2. 对于每个节点，需要知道其子树的节点总和与节点数量
3. 使用后序遍历（先处理子节点，再处理父节点）

解题步骤：
1. 定义一个辅助函数，返回子树的（节点和，节点数）
2. 在遍历过程中计算每个子树的平均值
3. 维护全局最大平均值
4. 使用后序遍历确保先计算子树信息

## Python 代码实现

### 方法一：后序遍历 + 全局变量（推荐）

```python
from typing import Optional, Tuple

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maximumAverageSubtree(self, root: Optional[TreeNode]) -> float:
        self.max_avg = 0.0  # 全局最大平均值
        
        def dfs(node: Optional[TreeNode]) -> Tuple[int, int]:
            """
            返回当前子树的 (节点值之和, 节点数量)
            """
            if not node:
                return (0, 0)
            
            # 后序遍历：先处理左右子树
            left_sum, left_count = dfs(node.left)
            right_sum, right_count = dfs(node.right)
            
            # 计算当前子树的和与节点数
            curr_sum = node.val + left_sum + right_sum
            curr_count = 1 + left_count + right_count
            
            # 计算当前子树的平均值
            curr_avg = curr_sum / curr_count
            
            # 更新全局最大平均值
            self.max_avg = max(self.max_avg, curr_avg)
            
            # 返回当前子树信息供父节点使用
            return (curr_sum, curr_count)
        
        dfs(root)
        return self.max_avg
```

### 方法二：不使用全局变量

```python
class Solution:
    def maximumAverageSubtree(self, root: Optional[TreeNode]) -> float:
        def dfs(node: Optional[TreeNode]) -> Tuple[int, int, float]:
            """
            返回 (子树节点和, 节点数, 该子树及其所有子树的最大平均值)
            """
            if not node:
                return (0, 0, 0.0)
            
            # 递归处理左右子树
            left_sum, left_count, left_max = dfs(node.left)
            right_sum, right_count, right_max = dfs(node.right)
            
            # 计算当前子树信息
            curr_sum = node.val + left_sum + right_sum
            curr_count = 1 + left_count + right_count
            curr_avg = curr_sum / curr_count
            
            # 当前子树的最大平均值是：当前平均值、左子树最大、右子树最大 三者最大值
            max_avg = max(curr_avg, left_max, right_max)
            
            return (curr_sum, curr_count, max_avg)
        
        _, _, result = dfs(root)
        return result
```

### 方法三：使用类封装返回值

```python
class SubtreeInfo:
    def __init__(self, sum_val: int, count: int):
        self.sum_val = sum_val
        self.count = count
        self.avg = sum_val / count if count > 0 else 0

class Solution:
    def maximumAverageSubtree(self, root: Optional[TreeNode]) -> float:
        self.max_avg = 0.0
        
        def dfs(node: Optional[TreeNode]) -> SubtreeInfo:
            if not node:
                return SubtreeInfo(0, 0)
            
            left_info = dfs(node.left)
            right_info = dfs(node.right)
            
            curr_sum = node.val + left_info.sum_val + right_info.sum_val
            curr_count = 1 + left_info.count + right_info.count
            curr_info = SubtreeInfo(curr_sum, curr_count)
            
            self.max_avg = max(self.max_avg, curr_info.avg)
            
            return curr_info
        
        dfs(root)
        return self.max_avg
```

## 复杂度分析

- 时间复杂度：O(n)，其中 n 是节点数，每个节点访问一次
- 空间复杂度：O(h)，其中 h 是树的高度，递归栈的深度

## 关键点总结

1. **后序遍历**：必须先计算子树信息，才能计算父节点信息
2. **信息传递**：每个节点需要向上传递（和，数量）两个信息
3. **平均值计算**：在每个节点都要计算当前子树的平均值并更新最大值
4. **返回值设计**：返回元组 (sum, count) 简洁高效

## 易错点

1. **忘记计算叶子节点**：叶子节点本身也是一棵子树，平均值就是其值
   
2. **平均值计算时机错误**：必须在获取左右子树信息后才能计算当前平均值

3. **返回值混淆**：
   ```python
   # 错误：返回平均值而不是(和, 数量)
   def dfs(node):
       return curr_avg  # 这样父节点无法计算自己的平均值
   
   # 正确：返回和与数量
   def dfs(node):
       return (curr_sum, curr_count)
   ```

4. **除零错误**：空节点的处理要返回 (0, 0)，不要计算平均值
