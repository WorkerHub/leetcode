## 题目描述

给你二叉树的根结点 `root`，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`。
- 展开后的单链表应该与二叉树前序遍历顺序相同。

**示例 1：**

```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [0]
输出：[0]
```

**提示：**

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

**进阶**：你可以使用原地算法（O(1) 额外空间）展开这棵树吗？

## 解题思路

这道题要求将二叉树展开成链表，展开顺序是**前序遍历**（根-左-右）。

### 核心观察

展开后的链表结构：
```
1 -> 2 -> 3 -> 4 -> 5 -> 6
```
这正是前序遍历的顺序：1, 2, 3, 4, 5, 6

### 解题方法

**方法一：前序遍历 + 重建链表**
- 先进行前序遍历，将节点存入列表
- 然后遍历列表，将所有节点连接成链表
- 时间 O(n)，空间 O(n)

**方法二：递归（后序遍历思想）**
- 先递归处理右子树和左子树
- 然后将左子树插入到根节点和右子树之间
- 时间 O(n)，空间 O(h)

**方法三：迭代（找前驱节点）**
- 对于每个节点，找到其左子树的最右节点（前驱）
- 将右子树接到前驱的右侧
- 将左子树移到右侧
- 时间 O(n)，空间 O(1) - 最优解

**方法四：前序遍历 + 栈**
- 使用栈模拟前序遍历
- 同时构建链表
- 时间 O(n)，空间 O(h)

## Python 代码实现

### 方法一：前序遍历 + 重建链表（易理解）

```python
from typing import Optional, List

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        """
        Do not return anything, modify root in-place instead.
        """
        if not root:
            return
        
        # 步骤 1：前序遍历，收集所有节点
        nodes = []
        
        def preorder(node: Optional[TreeNode]) -> None:
            if not node:
                return
            nodes.append(node)
            preorder(node.left)
            preorder(node.right)
        
        preorder(root)
        
        # 步骤 2：将节点连接成链表
        for i in range(len(nodes) - 1):
            nodes[i].left = None
            nodes[i].right = nodes[i + 1]
        
        # 最后一个节点
        nodes[-1].left = None
        nodes[-1].right = None
```

### 方法二：递归（后序遍历）⭐

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        def dfs(node: Optional[TreeNode]) -> Optional[TreeNode]:
            """
            展开以 node 为根的子树，返回展开后的链表尾节点
            """
            if not node:
                return None
            
            # 叶子节点，返回自己
            if not node.left and not node.right:
                return node
            
            # 递归展开左右子树
            left_tail = dfs(node.left)
            right_tail = dfs(node.right)
            
            # 如果左子树存在，进行拼接
            if left_tail:
                # 左子树的尾节点连接到右子树
                left_tail.right = node.right
                # 将左子树移到右边
                node.right = node.left
                # 左子树置空
                node.left = None
            
            # 返回链表的尾节点
            # 如果右子树存在，返回右子树的尾节点；否则返回左子树的尾节点
            return right_tail if right_tail else left_tail
        
        dfs(root)
```

### 方法三：迭代 - 找前驱节点（最优）⭐⭐

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        current = root
        
        while current:
            # 如果左子树存在
            if current.left:
                # 找到左子树的最右节点（前驱节点）
                predecessor = current.left
                while predecessor.right:
                    predecessor = predecessor.right
                
                # 将右子树接到前驱节点的右侧
                predecessor.right = current.right
                
                # 将左子树移到右侧
                current.right = current.left
                current.left = None
            
            # 移动到下一个节点
            current = current.right
```

### 方法四：前序遍历 + 栈

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        if not root:
            return
        
        stack = [root]
        prev = None
        
        while stack:
            current = stack.pop()
            
            # 连接前一个节点
            if prev:
                prev.left = None
                prev.right = current
            
            # 右子节点先入栈（后访问）
            if current.right:
                stack.append(current.right)
            # 左子节点后入栈（先访问）
            if current.left:
                stack.append(current.left)
            
            prev = current
```

### 方法五：逆向前序遍历

```python
class Solution:
    def __init__(self):
        self.prev = None
    
    def flatten(self, root: Optional[TreeNode]) -> None:
        """
        按照 根-右-左 的顺序遍历，每次将当前节点连接到 prev
        这样最终结果就是 根-左-右 的链表
        """
        if not root:
            return
        
        # 先处理右子树
        self.flatten(root.right)
        # 再处理左子树
        self.flatten(root.left)
        
        # 当前节点连接到之前处理的节点
        root.right = self.prev
        root.left = None
        self.prev = root
```

## 复杂度分析

### 方法一

- **时间复杂度**：O(n)，遍历所有节点两次
- **空间复杂度**：O(n)，需要存储所有节点

### 方法二

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，递归调用栈，h 为树高

### 方法三（最优）

- **时间复杂度**：O(n)，看似有嵌套循环，但每条边最多访问一次
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法四

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，栈的空间

### 方法五

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归调用栈

## 关键点总结

1. **前序遍历顺序**：展开后的链表顺序就是前序遍历（根-左-右）
2. **原地操作**：要求修改原树，不能创建新节点
3. **找前驱节点**：方法三的核心是找到左子树的最右节点
4. **逆向思维**：方法五按照 根-右-左 遍历，巧妙构建链表
5. **空间优化**：方法三是唯一的 O(1) 空间解法

## 易错点

1. **忘记置空左指针**：
   ```python
   # 错误：只设置右指针
   current.right = current.left
   
   # 正确：左指针要置空
   current.right = current.left
   current.left = None
   ```

2. **前驱节点查找错误**：
   ```python
   # 要找左子树的最右节点
   predecessor = current.left
   while predecessor.right:  # 不是 while predecessor
       predecessor = predecessor.right
   ```

3. **拼接顺序错误**：
   ```python
   # 正确顺序：
   # 1. 将右子树接到前驱的右侧
   predecessor.right = current.right
   # 2. 将左子树移到右侧
   current.right = current.left
   # 3. 左子树置空
   current.left = None
   ```

4. **空树处理**：要检查 `root` 是否为 `None`

5. **修改了原树结构后遍历错误**：在修改树结构时要注意遍历顺序
