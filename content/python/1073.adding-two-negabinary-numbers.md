## 题目描述

给定两个数字 `arr1` 和 `arr2`，它们表示两个以负二进制（base -2）表示的整数。

返回 `arr1` 和 `arr2` 之和的负二进制表示。

注意：每个数组都是以最高有效位在前的形式表示（即，最重要的位在索引 0 处）。

**示例 1：**
```
输入：arr1 = [1,1,1,1,1], arr2 = [1,0,1]
输出：[1,0,0,0,0]
解释：arr1 表示 11，arr2 表示 5，11 + 5 = 16，在负二进制中为 [1,0,0,0,0]
```

**示例 2：**
```
输入：arr1 = [0], arr2 = [0]
输出：[0]
```

**示例 3：**
```
输入：arr1 = [0], arr2 = [1]
输出：[1]
```

**提示：**
- `1 <= arr1.length, arr2.length <= 1000`
- `arr1[i]` 和 `arr2[i]` 为 0 或 1
- `arr1` 和 `arr2` 都没有前导零

## 解题思路

这道题需要理解**负二进制（Negabinary）**的表示方法：

1. **负二进制表示**：
   - 普通二进制：每一位的权重是 2⁰, 2¹, 2², 2³, ...（从右到左）
   - 负二进制：每一位的权重是 (-2)⁰, (-2)¹, (-2)², (-2)³, ... = 1, -2, 4, -8, 16, -32, ...
   - 例如：`[1,0,1]` = 1×4 + 0×(-2) + 1×1 = 5

2. **加法规则**：
   - 类似二进制加法，从低位到高位逐位相加
   - 关键在于处理进位：
     - 在普通二进制中，进位总是正数
     - 在负二进制中，进位可能是正数或负数

3. **进位处理**：
   - 当前位的和 = arr1[i] + arr2[i] + carry
   - 如果和 >= 2，需要进位
   - 进位规则：
     - 和为 2 或 3 时，向高位进位 -1（因为 2 = 0 - 2×(-1)）
     - 当前位的值 = 和 % 2
     - 进位 = -(和 // 2)

4. **算法流程**：
   - 从右到左（低位到高位）逐位相加
   - 处理进位（注意是负进位）
   - 去除前导零

## Python 代码实现

### 方法一：模拟加法（推荐）

```python
from typing import List

class Solution:
    def addNegabinary(self, arr1: List[int], arr2: List[int]) -> List[int]:
        result = []
        carry = 0
        i, j = len(arr1) - 1, len(arr2) - 1
        
        # 从低位到高位逐位相加
        while i >= 0 or j >= 0 or carry:
            # 获取当前位的值
            val1 = arr1[i] if i >= 0 else 0
            val2 = arr2[j] if j >= 0 else 0
            
            # 当前位的和（包括进位）
            total = val1 + val2 + carry
            
            # 计算当前位的结果和新的进位
            result.append(total % 2)
            carry = -(total // 2)  # 负二进制的进位是负的
            
            i -= 1
            j -= 1
        
        # 去除前导零
        while len(result) > 1 and result[-1] == 0:
            result.pop()
        
        # 结果是从低位到高位，需要反转
        return result[::-1]
```

### 方法二：统一处理所有情况

```python
from typing import List

class Solution:
    def addNegabinary(self, arr1: List[int], arr2: List[int]) -> List[int]:
        result = []
        carry = 0
        
        # 反转数组，方便从低位开始处理
        arr1, arr2 = arr1[::-1], arr2[::-1]
        max_len = max(len(arr1), len(arr2))
        
        for i in range(max_len):
            # 获取当前位的值
            a = arr1[i] if i < len(arr1) else 0
            b = arr2[i] if i < len(arr2) else 0
            
            # 当前位的和
            s = a + b + carry
            
            # 计算结果和进位
            result.append(s & 1)  # s % 2 的位运算写法
            carry = -(s >> 1)     # -(s // 2) 的位运算写法
        
        # 处理剩余的进位
        while carry:
            result.append(carry & 1)
            carry = -(carry >> 1)
        
        # 去除前导零
        while len(result) > 1 and result[-1] == 0:
            result.pop()
        
        return result[::-1]
```

### 方法三：先转十进制再转负二进制

```python
from typing import List

class Solution:
    def addNegabinary(self, arr1: List[int], arr2: List[int]) -> List[int]:
        # 负二进制转十进制
        def negabinary_to_decimal(arr: List[int]) -> int:
            result = 0
            for i, digit in enumerate(arr):
                result += digit * ((-2) ** (len(arr) - 1 - i))
            return result
        
        # 十进制转负二进制
        def decimal_to_negabinary(num: int) -> List[int]:
            if num == 0:
                return [0]
            
            result = []
            while num:
                if num % 2 == 0:
                    result.append(0)
                    num //= -2
                else:
                    result.append(1)
                    num = (num - 1) // -2
            
            return result[::-1]
        
        # 转换为十进制，相加，再转回负二进制
        num1 = negabinary_to_decimal(arr1)
        num2 = negabinary_to_decimal(arr2)
        total = num1 + num2
        
        return decimal_to_negabinary(total)
```

## 复杂度分析

**方法一、二（推荐）：**
- **时间复杂度**：O(max(m, n))，其中 m 和 n 是两个数组的长度
  - 需要遍历较长数组的所有位
- **空间复杂度**：O(max(m, n))，存储结果数组

**方法三：**
- **时间复杂度**：O(m + n)
  - 转换为十进制：O(m + n)
  - 转换回负二进制：O(log|num|)
- **空间复杂度**：O(max(m, n))

## 图解示例

以 `arr1 = [1,1,1,1,1]`（11），`arr2 = [1,0,1]`（5）为例：

```
负二进制表示：
arr1 = [1,1,1,1,1]
     = 1×16 + 1×(-8) + 1×4 + 1×(-2) + 1×1
     = 16 - 8 + 4 - 2 + 1 = 11

arr2 = [1,0,1]
     = 1×4 + 0×(-2) + 1×1
     = 4 + 0 + 1 = 5

加法过程（从右到左）：
     1 1 1 1 1
   +     1 0 1
   -----------
     位0: 1+1=2  → 写0，进位-1
     位1: 1+0-1=0 → 写0，进位0
     位2: 1+1+0=2 → 写0，进位-1
     位3: 1+0-1=0 → 写0，进位0
     位4: 1+0+0=1 → 写1，进位0
   
结果：[1,0,0,0,0]
验证：1×16 = 16 ✓
```

## 关键点总结

1. **负二进制理解**：每一位的权重是 (-2) 的幂次，正负交替
2. **进位规则**：进位是负数，`carry = -(sum // 2)`
3. **位运算优化**：`& 1` 代替 `% 2`，`>> 1` 代替 `// 2`
4. **去除前导零**：结果可能有多余的前导零，需要移除
5. **边界处理**：当两个数都是 0 时，结果是 [0]

## 易错点

1. **进位符号**：忘记进位是负数，导致计算错误
2. **数组方向**：混淆高位和低位的位置，索引 0 是最高位
3. **前导零**：忘记去除前导零，或者错误地将 [0] 也去除
4. **循环条件**：忘记处理进位可能超出原数组长度的情况
5. **负数表示**：负二进制可以表示负数，需要正确理解权重
