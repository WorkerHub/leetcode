## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，每次操作可以将数组中的任意一个元素替换为该元素的任意约数（因子）。

返回使数组所有元素的最大公约数（GCD）等于 `k` 所需的最少操作次数。如果无法达到则返回 -1。

**示例 1：**

```
输入：nums = [2, 4, 6], k = 2
输出：0
解释：gcd(2, 4, 6) = 2 = k，无需操作。
```

**示例 2：**

```
输入：nums = [3, 9, 15], k = 5
输出：-1
解释：k=5 不能是 gcd，因为 5 不是这些数的因子。
```

**示例 3：**

```
输入：nums = [4, 8, 16], k = 2
输出：0
解释：gcd = 4，但目标是 2...
将 4 替换为 2（操作 1 次），gcd(2,8,16)=2。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## 解题思路

首先判断 k 是否可以整除所有 nums[i]（即 k | nums[i]）：
1. 若 k 不整除某个 nums[i]，将其替换为 k 的倍数的因子，但实际上我们能替换为更小的因子。
2. 要使 GCD = k，必须 k | nums[i] 对所有 i 成立，且至少有一个 nums[i] = k（或操作后等于 k）。

简化：
- 若某个 nums[i] 不是 k 的倍数：无论如何操作，nums[i] 的任何约数也不会是 k 的倍数（约数 <= nums[i]，若 k 不整除 nums[i]，k 的因子必须满足特定条件）。
- 实际上，若 k 不整除 nums[i]，将 nums[i] 替换为 k（若 k <= nums[i]，但 k 不是 nums[i] 的因子，则不能直接替换为 k，只能替换为 nums[i] 的约数）。

更正确的分析：每次操作只能将元素替换为其约数（因子），不能随意替换为任意值。
- 若 nums[i] 不是 k 的倍数，不可能通过操作使 nums[i] 变为 k 的倍数（因子只会变小）。

## Python 代码实现

### 方法一：检查可行性 + 统计操作次数（推荐）

```python
from typing import List
from math import gcd

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        # 检查每个元素是否是 k 的倍数
        for v in nums:
            if v % k != 0:
                return -1  # 不可能使 GCD = k

        # 统计 GCD = k 所需操作
        # 当前 GCD
        current_gcd = 0
        for v in nums:
            current_gcd = gcd(current_gcd, v)

        if current_gcd == k:
            return 0

        # current_gcd > k（current_gcd 是 k 的倍数，因为所有 nums[i] 是 k 的倍数）
        # 需要将某些元素减小，使 GCD 降到 k
        # 将某元素 v 替换为 v / (v/k) = k（若 v/k 是整数）
        # 每次操作：将某个元素替换为 k（其因子）
        # 统计有多少元素不等于 k
        count_not_k = sum(1 for v in nums if v != k)
        # 只需要操作 1 个元素为 k，GCD 就能变为 k（若其他元素都是 k 的倍数）
        return 1 if count_not_k > 0 else 0
```

### 方法二：GCD 分析

```python
from typing import List
from math import gcd

class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        total_gcd = 0
        for v in nums:
            total_gcd = gcd(total_gcd, v)
            if total_gcd % k != 0:
                return -1  # 不可能使 GCD = k

        if total_gcd == k:
            return 0

        # 需要将某个元素操作为其因子使 GCD 等于 k
        # 若存在元素 v 使 gcd(v, total_gcd) = k 的因子，操作 1 次即可
        return 1
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))，GCD 计算
- 空间复杂度：O(1)

## 关键点总结

1. 要使 GCD = k，所有元素必须是 k 的倍数（否则返回 -1）。
2. 当前 GCD > k 时，只需将一个元素替换为 k（1 次操作）即可使 GCD 降为 k。
3. 若当前 GCD = k，无需操作。

## 易错点

1. 操作只能替换为约数，不能任意替换。
2. 返回 -1 的条件：k 不整除某个 nums[i]（无法通过约数操作使其变为 k 的倍数）。
