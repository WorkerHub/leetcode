## 题目描述

给你一个整数数组 `queries` 和一个正整数 `intLength`，找出每个查询对应的**第 k 个** `intLength` 位回文整数。

回文整数从最小到最大排列，`queries[i]` 表示要找第 `queries[i]` 个该长度的回文整数。

若不存在对应的回文整数，返回 -1。

**示例 1：**
```
输入：queries = [1,2,3,4,5,90], intLength = 3
输出：[101,111,121,131,141,999]
```

**示例 2：**
```
输入：queries = [2,4,6], intLength = 4
输出：[1111,1221,1331]
```

## 解题思路

`intLength` 位回文数由前半部分决定（后半部分是前半部分的镜像）。

- 若 `intLength` 为奇数，前半部分长度 = `(intLength + 1) // 2`，前半部分范围 `[10^(half-1), 10^half - 1]`。
- 若 `intLength` 为偶数，前半部分长度 = `intLength // 2`，相同范围。

第 k 个回文数的前半部分 = `10^(half-1) + k - 1`（1-indexed）。

将前半部分拼接其反转（奇数长度反转时去掉中间字符）即得回文数。

## 代码实现

### 方法一：数学构造（推荐）

```python
from typing import List

class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        # 前半部分的长度
        half = (intLength + 1) // 2

        # 前半部分的最小值（首位不为0）
        start = 10 ** (half - 1)
        # 前半部分最大值
        end = 10 ** half - 1

        result = []
        for q in queries:
            # 第 q 个回文数对应的前半部分
            prefix = start + q - 1
            if prefix > end:
                result.append(-1)
                continue

            # 构造回文数
            prefix_str = str(prefix)
            if intLength % 2 == 0:
                # 偶数长度：前缀 + 前缀反转
                palindrome = prefix_str + prefix_str[::-1]
            else:
                # 奇数长度：前缀 + 前缀去掉最后一位的反转
                palindrome = prefix_str + prefix_str[-2::-1]

            result.append(int(palindrome))

        return result
```

### 方法二：纯数字操作（不转字符串）

```python
from typing import List

class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        half = (intLength + 1) // 2
        start = 10 ** (half - 1)

        res = []
        for q in queries:
            prefix = start + q - 1
            if prefix >= 10 ** half:
                res.append(-1)
                continue

            # 从前缀构造回文数
            palindrome = prefix
            # 需要镜像的部分（偶数长度：整个前缀；奇数长度：前缀去掉最后一位）
            mirror = prefix // 10 if intLength % 2 == 1 else prefix
            # 将 mirror 的每一位依次追加
            while mirror > 0:
                palindrome = palindrome * 10 + mirror % 10
                mirror //= 10

            res.append(palindrome)

        return res
```

## 复杂度分析

- 时间复杂度：O(q * intLength)，q 为查询数量，每次构造 O(intLength)。
- 空间复杂度：O(1)（不计输出数组）。

## 关键点总结

1. `intLength` 位回文数由前 `(intLength+1)//2` 位决定。
2. 前半部分范围从 `10^(half-1)` 到 `10^half - 1`，共 `9 * 10^(half-1)` 个。
3. 奇数长度时中间字符不反转（只取前缀去掉末位的反转）。

## 易错点

- `intLength == 1` 时，`half = 1`，起始前缀为 1，回文数就是 1 到 9。
- 前缀超出范围时返回 -1，即 `prefix > end`。
- 奇偶长度处理时字符串切片 `[-2::-1]` 而非 `[-1::-1]`（去掉最后一位再反转）。
