## 题目描述

给你一个 `m x n` 的矩阵 `grid`，每次操作：
1. 删除每一行中最大的值，若有多个最大值删除其中任意一个
2. 将这一轮所有被删除的最大值中的最大值，加入分数

重复操作直到矩阵为空，返回最终得分。

**示例：**
```
输入：grid = [[1,2,4],[3,3,1]]
输出：8
解释：
第1轮：每行最大值为 4 和 3，删除后得分 +4
第2轮：每行最大值为 2 和 3，删除后得分 +3
第3轮：每行最大值为 1 和 1，删除后得分 +1
总分 = 4+3+1 = 8
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 50`
- `1 <= grid[i][j] <= 100`

## 解题思路

**排序模拟：**

对每行排序，每次删除每行最大列（同一轮，即同一列位置），取这一轮各行该列的最大值累加。

**直接方法：** 每行排序后，第 j 轮（从最大列开始）取各行第 `n-1-j` 列的最大值。

即：每行排序后，对每一列（从右到左），取该列所有行的最大值并累加。

## 代码实现

### 方法一：每行排序后按列取最大值（推荐）

```python
from typing import List

class Solution:
    def deleteGreatestValue(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        # 对每行排序
        for row in grid:
            row.sort()

        ans = 0
        # 从右到左，每轮删除各行当前最大列
        for j in range(n - 1, -1, -1):
            col_max = max(grid[i][j] for i in range(m))
            ans += col_max

        return ans
```

### 方法二：模拟（直接操作）

```python
from typing import List

class Solution:
    def deleteGreatestValue(self, grid: List[List[int]]) -> int:
        ans = 0
        m, n = len(grid), len(grid[0])

        for _ in range(n):  # 共 n 轮
            row_maxes = []
            for row in grid:
                max_val = max(row)
                row.remove(max_val)  # 删除该行最大值
                row_maxes.append(max_val)
            ans += max(row_maxes)

        return ans
```

### 方法三：numpy 风格的简洁写法

```python
from typing import List

class Solution:
    def deleteGreatestValue(self, grid: List[List[int]]) -> int:
        # 每行排序，然后对每列取最大值求和
        sorted_grid = [sorted(row) for row in grid]
        # 转置后，对每列（原排序后的每个位置）取最大值
        return sum(max(sorted_grid[i][j] for i in range(len(grid)))
                   for j in range(len(grid[0])))
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序+按列 | O(m*n*log n) | O(1) |
| 模拟删除 | O(m*n^2) | O(m) |

## 关键点总结

1. 每行排序后，每轮删除的是各行的同一"列位置"（排序后的第 k 大）
2. 每轮分数 = 该列各行的最大值
3. 等价于：对排序后矩阵的每一列求最大值，然后求和

## 易错点

- 每轮是删除每行的最大值（不是整个矩阵最大值），但计分是这轮所有删除值中的最大
