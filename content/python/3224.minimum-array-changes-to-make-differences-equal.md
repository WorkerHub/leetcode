## 题目描述

给你一个长度为 `n` 的整数数组 `nums`（`n` 为偶数），以及一个整数 `k`。

你可以执行以下操作**任意次**：从 `nums` 中选择一个下标 `i`，将 `nums[i]` 改为 `[0, k]` 之间的任意整数。

定义 `q(i) = |nums[i] - nums[n - 1 - i]|`（对称下标对的差的绝对值）。

返回使所有 `q(i)` 相等所需的**最少操作次数**。

**示例 1：**
```
输入：nums = [1,0,1,2,4,3], k = 4
输出：2
```

**示例 2：**
```
输入：nums = [0,1,2,3,3,6,5,4], k = 6
输出：2
```

**提示：**
- `2 <= n <= 10^5`
- `n` 为偶数
- `0 <= nums[i] <= k`
- `1 <= k <= 10^5`

## 解题思路

枚举目标差值 `d`（0 到 k），对每个 d 计算所需操作数：

对于每对 `(a, b) = (nums[i], nums[n-1-i])`：
- 若 `|a - b| == d`：0 次操作
- 若可以通过改变一个值使差为 d（即 `d` 在可达范围内）：1 次操作
  - 改变一个值可以达到差为 `d`：当 `d <= max(a, b, k - min(a,b))`（等价于改一个值能达到）
  - 更精确：`d <= max(a, k-a, b, k-b)`... 
- 否则：2 次操作

用差分数组优化枚举所有 d 的计算。

## Python 代码实现

### 方法一：差分数组优化（推荐）

```python
from typing import List

class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        n = len(nums)
        # 差分数组：diff[d] 表示目标差值为 d 时的最少操作数（相对值）
        # 对于每对 (a, b)：
        # - 当前差值 cur = |a - b|
        # - 一次操作能达到的最大差值：max(a, b, k-a, k-b)
        
        # 对每个 d (0..k)，操作数 = sum of (0 if d==cur else 1 if d<=max_one else 2)
        # = n//2 * 1 (基础1) - (d == cur 的对数) + (d > max_one 的对数)
        # 转化：ops(d) = n//2 - count(d==cur) + count(d>max_one)
        # 用差分来处理 "d<=max_one" 和 "d==cur"
        
        half = n // 2
        # diff[d]：在 d 处操作数相比"全部2次"的减少量
        # 全部 2 次：2 * half
        # 每对的贡献：
        #   d == cur: -2（不需要操作）
        #   d != cur but d <= max_one: -1（只需1次）
        #   d > max_one: -0（需要2次）
        
        # 差分优化：对范围 [0, max_one] 减1，对 cur 再减1
        delta = [0] * (k + 2)  # 差分数组
        
        for i in range(half):
            a, b = nums[i], nums[n - 1 - i]
            cur = abs(a - b)
            max_one = max(a, b, k - a, k - b)
            # 范围 [0, max_one] 所有 d 可以用 1 次操作覆盖（相比2次减1）
            delta[0] -= 1
            delta[max_one + 1] += 1
            # d == cur 时减1（总共-2）
            delta[cur] -= 1
            delta[cur + 1] += 1
        
        # 基础为每对都用2次操作
        base = 2 * half
        ans = base
        acc = 0
        for d in range(k + 1):
            acc += delta[d]
            ans = min(ans, base + acc)
        
        return ans
```

### 方法二：暴力枚举（小数据）

```python
from typing import List

class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        n = len(nums)
        half = n // 2
        pairs = [(nums[i], nums[n-1-i]) for i in range(half)]
        
        ans = float('inf')
        for d in range(k + 1):
            ops = 0
            for a, b in pairs:
                cur = abs(a - b)
                if cur == d:
                    ops += 0
                elif d <= max(a, b, k - a, k - b):
                    ops += 1
                else:
                    ops += 2
            ans = min(ans, ops)
        return ans
```

## 复杂度分析

- 方法一：时间复杂度 O(n + k)，空间复杂度 O(k)
- 方法二：时间复杂度 O(n * k)，仅适合小数据

## 关键点总结

1. 枚举目标差值 d，统计每对需要的操作数
2. 用差分数组将区间更新优化到 O(n + k)
3. "一次操作能达到差 d" 的条件是 d <= max(a, b, k-a, k-b)

## 易错点

1. max_one 的计算：改一个值到 [0,k] 中的任意值，最大差为 max(a, b, k-a, k-b)
2. 差分数组要处理边界 +1
