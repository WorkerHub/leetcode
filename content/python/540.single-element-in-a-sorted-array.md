## 题目描述

给你一个只包含整数的有序数组，其中每个元素都会出现两次，唯有一个数只会出现一次。

请找出并返回只出现一次的那个数。

你设计的解决方案必须满足 O(log n) 时间复杂度和 O(1) 空间复杂度。

**示例 1:**
```
输入: nums = [1,1,2,3,3,4,4,8,8]
输出: 2
```

**示例 2:**
```
输入: nums = [3,3,7,7,10,11,11]
输出: 10
```

**提示:**
- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^5

## 解题思路

这道题的关键是要在 O(log n) 的时间复杂度内解决，这提示我们需要使用二分查找。

**核心观察:**

1. 数组是有序的，且除了一个元素外，其他元素都出现两次
2. 在单独元素出现之前，成对元素的第一个元素索引是偶数，第二个元素索引是奇数
3. 在单独元素出现之后，成对元素的第一个元素索引是奇数，第二个元素索引是偶数

**算法流程:**

1. 使用二分查找，维护左右指针 left 和 right
2. 计算中间位置 mid
3. 将 mid 与相邻元素比较：
   - 如果 nums[mid] == nums[mid-1]，检查 mid 的奇偶性
   - 如果 nums[mid] == nums[mid+1]，检查 mid 的奇偶性
4. 根据奇偶性判断单独元素在左侧还是右侧，调整搜索范围

## Python 代码实现

### 方法一：二分查找（推荐）

```python
from typing import List

class Solution:
    def singleNonDuplicate(self, nums: List[int]) -> int:
        """
        使用二分查找，时间复杂度 O(log n)
        
        思路：利用数组的对称性，单独元素前后的配对规律不同
        """
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 确保 mid 是偶数索引，方便比较
            # 如果 mid 是奇数，减1变成偶数
            if mid % 2 == 1:
                mid -= 1
            
            # 检查 mid 和 mid+1 是否相等
            if nums[mid] == nums[mid + 1]:
                # 说明单独元素在右侧
                # 因为正常情况下，偶数索引应该和下一个元素相等
                left = mid + 2
            else:
                # 说明单独元素在左侧（包括 mid 本身）
                right = mid
        
        return nums[left]
```

### 方法二：异或运算（不满足时间复杂度要求）

```python
from typing import List

class Solution:
    def singleNonDuplicate(self, nums: List[int]) -> int:
        """
        使用异或运算，时间复杂度 O(n)
        
        原理：相同的数异或结果为 0，任何数与 0 异或等于其本身
        """
        result = 0
        for num in nums:
            result ^= num
        return result
```

### 方法三：二分查找优化版

```python
from typing import List

class Solution:
    def singleNonDuplicate(self, nums: List[int]) -> int:
        """
        二分查找的另一种写法
        
        通过判断 mid 的位置和相邻元素的关系来缩小范围
        """
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = left + (right - left) // 2
            
            # 判断 mid 与哪个相邻元素相等
            if nums[mid] == nums[mid - 1]:
                # mid 和前一个元素相等
                # 如果 mid 是奇数位置，说明单独元素在右侧
                if mid % 2 == 1:
                    left = mid + 1
                else:
                    right = mid - 2
            elif nums[mid] == nums[mid + 1]:
                # mid 和后一个元素相等
                # 如果 mid 是偶数位置，说明单独元素在右侧
                if mid % 2 == 0:
                    left = mid + 2
                else:
                    right = mid - 1
            else:
                # mid 就是单独元素
                return nums[mid]
        
        return nums[left]
```

## 复杂度分析

**方法一（二分查找）：**
- 时间复杂度：O(log n)，二分查找每次将搜索范围减半
- 空间复杂度：O(1)，只使用了常数个额外变量

**方法二（异或运算）：**
- 时间复杂度：O(n)，需要遍历整个数组
- 空间复杂度：O(1)

## 关键点总结

1. 题目要求 O(log n) 时间复杂度，提示使用二分查找
2. 利用数组有序且成对出现的特性，观察索引的奇偶规律
3. 在单独元素左侧：偶数索引与下一个元素相等
4. 在单独元素右侧：奇数索引与下一个元素相等
5. 将 mid 调整为偶数索引可以简化逻辑判断

## 易错点

1. 边界处理：要注意 mid-1 和 mid+1 不能越界
2. 奇偶判断：容易混淆单独元素左右两侧的配对规律
3. 循环条件：应该是 `left < right` 而不是 `left <= right`
4. 移动指针时的步长：确认是 mid+2 还是 mid-2
