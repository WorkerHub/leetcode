## 题目描述

给你一个有向图，共 `n` 个节点（编号 0 到 n-1）和一组边 `edges[i] = [u, v, w]`，表示从 u 到 v 有一条权重为 w 的有向边。

你从节点 0 出发，目标是到达节点 n-1。不同的是，每条边都有一个**开放时间窗口** `[open, close]`，只有在时间 `t` 满足 `open <= t <= close` 时才能通过。

返回从 0 到 n-1 的最短时间，如果无法到达则返回 -1。

**示例 1：**

```
输入：n = 4, edges = [[0,1,2,1,3],[1,2,1,2,4],[2,3,1,3,5]]
输出：3
解释：0->1（时间 2 通过，到达 1 的时刻为 3）->2->3，最短时间 3。
```

**提示：**
- `2 <= n <= 10^4`
- `1 <= edges.length <= 5 * 10^4`
- 每条边格式为 `[u, v, w, open, close]`

## 解题思路

本题是带时间窗口约束的最短路问题，使用改进的 Dijkstra：
1. 状态为 `(当前时间, 当前节点)`，初始状态为 `(0, 0)`。
2. 对于每条边 `(u, v, w, open, close)`，当前时间 t 满足：
   - 出发时刻 `t_depart >= open`（边开放时才出发）
   - 到达时刻 `t_depart + w <= close`（到达时边仍开放）
3. 若 `t < open`，需要等到 `open` 时刻再出发；若 `t > close`，此边本次不可用。
4. 使用优先队列（最小堆）保证最短时间优先处理。

## Python 代码实现

### 方法一：Dijkstra + 时间窗口（推荐）

```python
from typing import List
import heapq
from collections import defaultdict

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]]) -> int:
        # 构建邻接表：graph[u] = [(v, w, open, close), ...]
        graph = defaultdict(list)
        for u, v, w, open_t, close_t in edges:
            graph[u].append((v, w, open_t, close_t))

        # Dijkstra：(当前时间, 当前节点)
        dist = [float('inf')] * n
        dist[0] = 0
        heap = [(0, 0)]  # (时间, 节点)

        while heap:
            t, u = heapq.heappop(heap)
            if t > dist[u]:
                continue  # 已找到更短路径
            if u == n - 1:
                return t

            for v, w, open_t, close_t in graph[u]:
                # 计算可以出发的最早时刻
                if t <= close_t:  # 边未关闭
                    depart = max(t, open_t)  # 等待到开放时刻
                    arrive = depart + w
                    if arrive <= close_t and arrive < dist[v]:
                        dist[v] = arrive
                        heapq.heappush(heap, (arrive, v))

        return -1 if dist[n - 1] == float('inf') else dist[n - 1]
```

### 方法二：BFS 分层（适用于等权图）

```python
from typing import List
from collections import deque, defaultdict

class Solution:
    def minimumTime(self, n: int, edges: List[List[int]]) -> int:
        # 仅适用于所有边权重相同的情况
        graph = defaultdict(list)
        for u, v, w, open_t, close_t in edges:
            graph[u].append((v, w, open_t, close_t))

        visited = [False] * n
        visited[0] = True
        queue = deque([(0, 0)])  # (节点, 时间)

        while queue:
            u, t = queue.popleft()
            if u == n - 1:
                return t
            for v, w, open_t, close_t in graph[u]:
                depart = max(t, open_t)
                arrive = depart + w
                if arrive <= close_t and not visited[v]:
                    visited[v] = True
                    queue.append((v, arrive))

        return -1
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，Dijkstra 使用优先队列
- 空间复杂度：O(n + m)，邻接表和距离数组

## 关键点总结

1. 时间窗口约束需要在 Dijkstra 中额外判断"等待"和"截止时间"。
2. `depart = max(t, open_t)` 处理等待开放的情况。
3. `arrive <= close_t` 保证在窗口关闭前到达。

## 易错点

1. 到达时刻是 `depart + w`，不是 `t + w`（因为可能等待）。
2. 需要检查 `arrive <= close_t`，避免超出时间窗口。
3. Dijkstra 中用 dist 数组过滤已处理节点。
