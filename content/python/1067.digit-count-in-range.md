## 题目描述

给定一个在 `0` 和 `9` 之间的单个数字 `d`，以及两个整数 `low` 和 `high`，返回在 `[low, high]` 范围内（包括边界）数字 `d` 作为数位出现的次数。

**示例 1：**
```
输入：d = 1, low = 1, high = 13
输出：6
解释：数字 1 在 1, 10, 11, 12, 13 中出现了 6 次。
注意 11 中有两个 1。
```

**示例 2：**
```
输入：d = 3, low = 100, high = 250
输出：35
解释：数字 3 在 100-250 范围内出现了 35 次。
```

**提示：**
- `0 <= d <= 9`
- `1 <= low <= high <= 2 × 10^8`

## 解题思路

这是一道经典的**数位 DP**问题。直接枚举会超时，需要用数学方法或数位 DP 求解。

**核心思想：**
- 将问题转化为：`count(high) - count(low - 1)`
- `count(n)` 表示在 `[0, n]` 范围内数字 `d` 出现的次数

**数位 DP 方法：**
按位考虑，对于每一位：
- 如果当前位等于 `d`，计算有多少个数满足条件
- 考虑前导零的影响（对于 `d = 0` 的特殊情况）
- 使用记忆化避免重复计算

**数学方法：**
对于每一位，分别计算在该位上 `d` 出现的次数：
- 高位贡献
- 当前位贡献
- 低位贡献

## Python 代码实现

### 方法一：数位 DP（推荐）

```python
class Solution:
    def digitsCount(self, d: int, low: int, high: int) -> int:
        """
        时间复杂度：O(log n)
        空间复杂度：O(log n)
        """
        def count_digit(n: int) -> int:
            """计算 [0, n] 范围内 d 出现的次数"""
            if n < 0:
                return 0
            
            s = str(n)
            length = len(s)
            result = 0
            
            # 遍历每一位
            for i in range(length):
                # 当前位左边的数字
                higher = int(s[:i]) if i > 0 else 0
                # 当前位的数字
                cur = int(s[i])
                # 当前位右边的数字
                lower = int(s[i+1:]) if i < length - 1 else 0
                
                # 计算当前位为 d 的情况
                if d == 0:
                    # 特殊处理 0（避免前导零）
                    if i > 0:
                        result += (higher - 1) * (10 ** (length - i - 1))
                else:
                    result += higher * (10 ** (length - i - 1))
                
                # 当前位等于 d
                if cur > d:
                    if d > 0 or i > 0:  # 避免前导零
                        result += 10 ** (length - i - 1)
                elif cur == d:
                    if d > 0 or i > 0:
                        result += lower + 1
            
            return result
        
        return count_digit(high) - count_digit(low - 1)
```

### 方法二：简化的数学方法

```python
class Solution:
    def digitsCount(self, d: int, low: int, high: int) -> int:
        """
        数学方法计算数位出现次数
        """
        def count(n: int) -> int:
            if n < 0:
                return 0
            
            count = 0
            factor = 1  # 当前位的权重（1, 10, 100, ...）
            
            while factor <= n:
                # 分离高位、当前位、低位
                higher = n // (factor * 10)
                cur = (n // factor) % 10
                lower = n % factor
                
                if d == 0:
                    # 0 不能作为前导，所以高位至少为 1
                    if higher == 0:
                        break
                    count += (higher - 1) * factor
                else:
                    count += higher * factor
                
                # 根据当前位的值调整计数
                if cur > d:
                    count += factor
                elif cur == d:
                    count += lower + 1
                
                factor *= 10
            
            return count
        
        return count(high) - count(low - 1)
```

### 方法三：记忆化 DFS

```python
class Solution:
    def digitsCount(self, d: int, low: int, high: int) -> int:
        """
        使用记忆化 DFS 实现数位 DP
        """
        def count(n: int) -> int:
            if n < 0:
                return 0
            
            s = str(n)
            memo = {}
            
            def dfs(pos: int, count: int, is_limit: bool, is_num: bool) -> int:
                """
                pos: 当前处理的位置
                count: d 出现的次数
                is_limit: 是否受到上界限制
                is_num: 是否已经开始填数字（处理前导零）
                """
                if pos == len(s):
                    return count
                
                state = (pos, count, is_limit, is_num)
                if state in memo:
                    return memo[state]
                
                result = 0
                
                # 可以跳过当前位（前导零）
                if not is_num:
                    result = dfs(pos + 1, count, False, False)
                
                # 当前位可以填的数字范围
                start = 0 if is_num else 1
                end = int(s[pos]) if is_limit else 9
                
                for digit in range(start, end + 1):
                    new_count = count + (1 if digit == d else 0)
                    result += dfs(pos + 1, new_count, is_limit and digit == end, True)
                
                memo[state] = result
                return result
            
            return dfs(0, 0, True, False)
        
        return count(high) - count(low - 1)
```

## 复杂度分析

**方法一和方法二：数学方法**
- 时间复杂度：O(log n)，n 是数字的位数
- 空间复杂度：O(1)

**方法三：记忆化 DFS**
- 时间复杂度：O(log n × 状态数)
- 空间复杂度：O(log n × 状态数)

## 图解示例

**示例：d = 1, low = 1, high = 13**

```
逐位分析 count(13)：

十位（权重=10）：
  higher = 13 // 100 = 0
  cur = (13 // 10) % 10 = 1
  lower = 13 % 10 = 3
  
  贡献：higher × 10 = 0
       因为 cur = d = 1，加上 lower + 1 = 4
  小计：4（来自 10, 11, 12, 13）

个位（权重=1）：
  higher = 13 // 10 = 1
  cur = 13 % 10 = 3
  lower = 0
  
  贡献：higher × 1 = 1
       因为 cur > d，再加 1
  小计：2（来自 1, 11）

总计：4 + 2 = 6 ✓

详细列表：
1: 个位 1 次
10: 十位 1 次
11: 十位 1 次 + 个位 1 次 = 2 次
12: 十位 1 次
13: 十位 1 次
共 6 次
```

## 关键点总结

1. **数位 DP**：按位分析，分别计算每一位上 `d` 的贡献
2. **前导零处理**：当 `d = 0` 时需要特殊处理，避免计入前导零
3. **分段计算**：`count(high) - count(low - 1)` 的区间技巧
4. **高位、当前位、低位**：理解三者对计数的影响

## 易错点

1. **d = 0 的情况**：需要特殊处理前导零
2. **边界条件**：`low = 0` 或 `low = 1` 的特殊情况
3. **位数计算**：注意整除和取模的顺序
4. **重复计数**：11 中有两个 1，不要遗漏
