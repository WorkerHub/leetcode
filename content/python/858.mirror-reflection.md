## 题目描述

有一个特殊的正方形房间，每面墙上都有一面镜子。除西南角以外，每个角落都有一个接受器，编号为 0、1 和 2 。

正方形房间的墙壁长度为 p，一束激光从西南角射出，首先会与东墙相遇，入射点到接收器 0 的距离为 q 。

返回光线最先遇到的接收器的编号（保证光线最终会遇到一个接收器）。

**示例 1：**
```
输入：p = 2, q = 1
输出：2
解释：光线在第一次反射后到达接收器 2。
```

**示例 2：**
```
输入：p = 3, q = 1
输出：1
```

**提示：**
- 1 <= q <= p <= 1000

## 题目理解

房间布局：
```
接收器1 -------- 接收器2
  |                |
  |                |
  |                |
激光源 ---------- 接收器0
(西南角)
```

- 正方形边长为 p
- 激光从 (0, 0) 射出，首先与东墙相遇于 (p, q)
- 三个接收器位置：
  - 接收器 0：东南角 (p, 0)
  - 接收器 1：西北角 (0, p)
  - 接收器 2：东北角 (p, p)

## 解题思路

这道题看似复杂，实际上可以通过**数学方法**巧妙求解。

**核心思想：镜像展开**

与其模拟光线反射，不如将房间镜像展开：
- 水平方向：每次碰到墙就展开一个镜像房间
- 竖直方向：每次碰到墙就展开一个镜像房间

光线在展开后的平面中**直线前进**，直到碰到某个接收器。

**数学分析：**

1. 光线从 (0, 0) 出发，斜率为 q/p
2. 光线方程：y = (q/p) × x
3. 光线碰到接收器时：
   - x 是 p 的倍数（到达东墙或西墙）
   - y 是 p 的倍数（到达北墙或南墙）

4. 设光线到达点 (m×p, n×q)，其中 m, n 是最小的正整数使得 m×p = n×q
   - 即 m/n = q/p，化简得 m = q/gcd(p,q), n = p/gcd(p,q)

5. 根据 m, n 的奇偶性判断接收器：
   - m 偶，n 奇 → 接收器 0（东南角）
   - m 奇，n 奇 → 接收器 1（西北角）
   - m 奇，n 偶 → 接收器 2（东北角）
   - m 偶，n 偶 → 不可能（已化简）

## Python 代码实现

### 方法一：数学方法（推荐）⭐

```python
class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        from math import gcd
        
        # 求最大公约数
        g = gcd(p, q)
        
        # 化简后的倍数
        m = q // g  # 水平方向的房间数
        n = p // g  # 竖直方向的房间数
        
        # 根据奇偶性判断
        if m % 2 == 0:  # m 偶
            return 0  # 接收器 0
        elif n % 2 == 0:  # m 奇，n 偶
            return 2  # 接收器 2
        else:  # m 奇，n 奇
            return 1  # 接收器 1
```

**代码说明：**
- 使用 gcd 化简 p 和 q
- 根据化简后的奇偶性判断接收器

### 方法二：位运算优化

```python
class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        from math import gcd
        
        g = gcd(p, q)
        p //= g
        q //= g
        
        # p 是水平方向，q 是竖直方向
        # p 偶 → 0, p 奇 q 偶 → 2, p 奇 q 奇 → 1
        if p & 1 == 0:
            return 0
        elif q & 1 == 0:
            return 2
        else:
            return 1
```

**代码说明：**
- `& 1` 判断奇偶性，比 `% 2` 稍快
- 注意这里 p, q 的含义与方法一相反

### 方法三：不使用 gcd

```python
class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        # 扩展直到 p 和 q 都是整数倍
        m = q  # 水平方向走的距离
        n = p  # 竖直方向走的距离
        
        # 找到最小的 m, n 使得 m 是 p 的倍数，n 是 p 的倍数
        while m % p != 0 or n % q != 0:
            m += q
            n += p
        
        # 计算房间数
        horizontal = m // p
        vertical = n // p
        
        if horizontal % 2 == 0:
            return 0
        elif vertical % 2 == 0:
            return 2
        else:
            return 1
```

**代码说明：**
- 不使用 gcd，通过循环找最小公倍数
- 效率较低，但更直观

### 方法四：数学公式（简化版）

```python
class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        from math import gcd
        
        # 扩展倍数使得都能整除
        lcm = p * q // gcd(p, q)
        
        # 在竖直和水平方向的反射次数
        vertical = lcm // p
        horizontal = lcm // q
        
        # 判断接收器
        if vertical % 2 == 0:
            return 0
        return 1 if horizontal % 2 == 1 else 2
```

## 复杂度分析

### 方法一、二：
- **时间复杂度**：O(log(min(p, q)))，gcd 的时间复杂度。
- **空间复杂度**：O(1)。

### 方法三：
- **时间复杂度**：O(max(p, q))，循环次数取决于 p 和 q。
- **空间复杂度**：O(1)。

## 关键点总结

1. **镜像展开**：将反射问题转化为直线运动
2. **最大公约数**：化简 p 和 q 到最简形式
3. **奇偶判断**：根据化简后的奇偶性确定接收器
4. **数学规律**：
   - m 偶 → 接收器 0
   - m 奇，n 偶 → 接收器 2
   - m 奇，n 奇 → 接收器 1
5. **不会出现 m 偶 n 偶**：因为已经化简到最简形式

## 易错点

1. **m 和 n 的定义混淆**：
   - 注意是 m = q/gcd 还是 p/gcd
   - 不同定义导致不同的判断逻辑

2. **奇偶判断顺序**：
   - 先判断 m 偶（接收器 0）
   - 再判断 n 偶（接收器 2）
   - 否则接收器 1

3. **理解镜像展开**：
   - 不要尝试模拟每次反射
   - 用数学方法直接计算

4. **gcd 的导入**：记得 `from math import gcd`
