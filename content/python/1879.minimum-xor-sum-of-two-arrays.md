## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，两个数组长度均为 `n`。

将 `nums1` 中的元素与 `nums2` 中的元素一一配对，每个元素只能使用一次，使得所有配对的按位异或值之和**最小**。

返回最小异或值之和。

**示例：**
```
输入：nums1 = [1,2], nums2 = [2,3]
输出：2
解释：nums1[0] XOR nums2[1] + nums1[1] XOR nums2[0] = 0+3=3 或 3+2=5，最小为 0+2=2（nums1=[1,2] vs nums2=[2,3]，1^2=3，2^3=1，和为4；或 1^3=2，2^2=0，和为2）
```

**提示：**
- `n <= 14`

## 解题思路

**状态压缩 DP**：

n <= 14，可以用 bitmask 表示 nums2 中已使用的元素。

`dp[mask]` = 使用了 nums2 中 mask 对应的元素（与 nums1 的前 popcount(mask) 个元素配对）时的最小异或和。

转移：`dp[mask] = min(dp[mask ^ (1 << j)] + nums1[i] ^ nums2[j])`，其中 `i = popcount(mask) - 1`，j 为 mask 中为 1 的任意位。

## 代码实现

### 方法一：状态压缩 DP（推荐）

```python
from typing import List

class Solution:
    def minimumXORSum(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        # dp[mask] = nums2 中已配对元素为 mask 时的最小异或和
        dp = [float('inf')] * (1 << n)
        dp[0] = 0

        for mask in range(1, 1 << n):
            # 已配对了 i = bin(mask).count('1') 个元素
            i = bin(mask).count('1') - 1  # nums1 的第 i 个（0-indexed）
            # 枚举 mask 中为 1 的位 j，表示 nums2[j] 与 nums1[i] 配对
            for j in range(n):
                if mask & (1 << j):
                    prev_mask = mask ^ (1 << j)  # 去掉第 j 位
                    dp[mask] = min(dp[mask], dp[prev_mask] + (nums1[i] ^ nums2[j]))

        return dp[(1 << n) - 1]
```

### 方法二：记忆化 DFS

```python
from typing import List
from functools import lru_cache

class Solution:
    def minimumXORSum(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)

        @lru_cache(maxsize=None)
        def dp(i: int, mask: int) -> int:
            """nums1[i:] 与 nums2 中未使用（mask 中为 0）的元素配对的最小异或和"""
            if i == n:
                return 0
            result = float('inf')
            for j in range(n):
                if not (mask >> j & 1):
                    result = min(result, (nums1[i] ^ nums2[j]) + dp(i + 1, mask | (1 << j)))
            return result

        return dp(0, 0)
```

## 复杂度分析

- **时间复杂度**：O(n * 2^n)，2^n 个状态，每个状态枚举 n 位
- **空间复杂度**：O(2^n)

## 关键点总结

1. n <= 14，状态压缩 DP 可行（2^14 = 16384 个状态）
2. mask 表示 nums2 中已使用的元素，与 nums1 的配对顺序由 popcount(mask) 决定
3. 转移时枚举 mask 中为 1 的位，尝试将该位对应的 nums2 元素与 nums1[i] 配对

## 易错点

- i 等于当前已配对数量减 1（0-indexed），通过 `bin(mask).count('1') - 1` 计算
- `prev_mask = mask ^ (1 << j)` 去掉最后加入的 j
