## 题目描述

如果一棵二叉树满足下述几个条件，则可以称为**奇偶树**：
- 二叉树根节点所在层下标为 `0`，根的子节点所在层下标为 `1`，以此类推。
- **偶数下标**层上的所有节点的值都是**奇整数**，从左到右按**严格递增**顺序排列。
- **奇数下标**层上的所有节点的值都是**偶整数**，从左到右按**严格递减**顺序排列。

给你二叉树的根节点，如果二叉树为**奇偶树**，则返回 `true`，否则返回 `false`。

**示例：**
```
输入：root = [1,10,4,3,null,7,9,12,8,6,null,null,2]
输出：true
```

**提示：**
- 树中节点数在范围 `[1, 10^5]` 内
- `1 <= Node.val <= 10^6`

## 解题思路

使用**BFS 层序遍历**，逐层检查条件：
1. 偶数层：所有值必须是奇数，且严格递增
2. 奇数层：所有值必须是偶数，且严格递减

关键：用变量记录上一个节点的值，与当前值比较。

## 代码实现

### 方法一：BFS 层序遍历（推荐）

```python
from collections import deque
from typing import Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isEvenOddTree(self, root: Optional[TreeNode]) -> bool:
        queue = deque([root])
        level = 0  # 当前层的下标
        
        while queue:
            size = len(queue)
            # 记录上一个节点的值（用于比较递增/递减）
            prev = float('-inf') if level % 2 == 0 else float('inf')
            
            for _ in range(size):
                node = queue.popleft()
                val = node.val
                
                if level % 2 == 0:
                    # 偶数层：值必须是奇数，且严格递增
                    if val % 2 == 0:
                        return False  # 偶数层出现偶数值
                    if val <= prev:
                        return False  # 不是严格递增
                    prev = val
                else:
                    # 奇数层：值必须是偶数，且严格递减
                    if val % 2 == 1:
                        return False  # 奇数层出现奇数值
                    if val >= prev:
                        return False  # 不是严格递减
                    prev = val
                
                # 将子节点加入队列
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            level += 1
        
        return True
```

### 方法二：DFS 递归（记录每层最后一个值）

```python
from typing import Optional

class Solution:
    def isEvenOddTree(self, root: Optional[TreeNode]) -> bool:
        # level_last[level] 记录该层最后处理的节点值
        level_last = {}
        
        def dfs(node: TreeNode, level: int) -> bool:
            if not node:
                return True
            
            val = node.val
            
            # 检查奇偶性
            if level % 2 == 0 and val % 2 == 0:
                return False  # 偶数层不能有偶数值
            if level % 2 == 1 and val % 2 == 1:
                return False  # 奇数层不能有奇数值
            
            # 检查单调性
            if level in level_last:
                if level % 2 == 0 and val <= level_last[level]:
                    return False  # 偶数层不是严格递增
                if level % 2 == 1 and val >= level_last[level]:
                    return False  # 奇数层不是严格递减
            
            level_last[level] = val
            
            # 先序遍历（左右子树都需检查）
            return dfs(node.left, level + 1) and dfs(node.right, level + 1)
        
        return dfs(root, 0)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS  | O(n) | O(n)（队列宽度） |
| DFS  | O(n) | O(h)（递归栈深度） |

## 关键点总结

1. 偶数层要求：奇数值 + 严格递增
2. 奇数层要求：偶数值 + 严格递减
3. BFS 按层遍历天然适合这种逐层检查的题目
4. 使用 `prev` 变量跟踪同层的前一个节点值

## 易错点

- 严格递增/递减：`val <= prev` 不合法（需要 `val > prev`）
- 偶数层初始 `prev = -inf`（要递增），奇数层初始 `prev = +inf`（要递减）
- DFS 方法需要记录每层最后访问的节点，确保左右顺序
