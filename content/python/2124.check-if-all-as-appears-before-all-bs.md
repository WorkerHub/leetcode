## 题目描述

给你一个**仅**由字母 `'a'` 和 `'b'` 组成的字符串 `s`。如果字符串中**每个** `'a'` 都出现在**每个** `'b'` 之前，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s = "aaabbb"
输出：true
```

**示例 2：**
```
输入：s = "abab"
输出：false
```

**示例 3：**
```
输入：s = "bbb"
输出：true
```

**提示：**
- `1 <= s.length <= 100`
- `s[i]` 为 `'a'` 或 `'b'`

## 解题思路

如果字符串中出现了 `"ba"` 子序列（即某个 b 后面跟着一个 a），则不合法。

等价条件：字符串不包含子串 `"ba"`。

## 代码实现

### 方法一：检查是否含 "ba"（推荐）

```python
class Solution:
    def checkString(self, s: str) -> bool:
        # 若包含 "ba" 则不合法
        return "ba" not in s
```

### 方法二：遍历检查（更直观）

```python
class Solution:
    def checkString(self, s: str) -> bool:
        # 一旦出现 'b'，后面不能再出现 'a'
        seen_b = False
        for ch in s:
            if ch == 'b':
                seen_b = True
            elif seen_b:
                # 出现了 'a' 但之前已经有 'b'
                return False
        return True
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 检查子串 | O(n) | O(1) |
| 遍历检查 | O(n) | O(1) |

## 关键点总结

1. 等价于字符串中不含 `"ba"` 子串。
2. Python 的 `in` 运算符直接判断子串，一行解决。
3. 遍历法用 flag 标记是否见过 b，再检查之后是否有 a。

## 易错点

- 注意 `"bbb"` 是合法的（没有 a，所有 a（零个）都在所有 b 前面）。
- `"aaa"` 也是合法的（没有 b）。
