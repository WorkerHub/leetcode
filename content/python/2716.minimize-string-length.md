## 题目描述

给你一个字符串 `s`，你可以对其进行以下操作 **任意次**：

选择字符串中一个字符 `c`，删除该字符左边或右边的一个与 `c` **相同** 的字符（如果存在的话）。

返回执行 **最优** 操作序列后字符串的 **最小长度**。

**示例 1：**
```
输入：s = "aaabc"
输出：3
解释：操作："aaabc" -> "aabc" -> "abc"，结果长度 3
```

**示例 2：**
```
输入：s = "cbbd"
输出：3
解释：操作："cbbd" -> "cbd"，结果长度 3
```

**示例 3：**
```
输入：s = "dddaaa"
输出：2
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含小写英文字母

## 解题思路

关键观察：每次操作可以删除某个字符的一个重复。最终结果是让每个字符最多出现一次。所以最小长度就是字符串中**不同字符的数量**。

## Python 代码实现

### 方法一：集合（推荐）

```python
class Solution:
    def minimizedStringLength(self, s: str) -> int:
        # 不同字符的数量即为最小长度
        return len(set(s))
```

### 方法二：哈希表计数

```python
from collections import Counter

class Solution:
    def minimizedStringLength(self, s: str) -> int:
        # 统计不同字符种类数
        return len(Counter(s))
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集大小固定为 26）

## 关键点总结

1. 每种字符可以通过操作消除所有重复，只保留一个
2. 最小长度 = 字符串中不同字符的种类数

## 易错点

1. 不要想复杂了，关键是理解每种字符最终能压缩到只剩 1 个
2. 操作顺序不影响最终结果
