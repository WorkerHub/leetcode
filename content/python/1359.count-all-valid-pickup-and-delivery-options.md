## 题目描述

给你 `n` 笔订单，每笔订单都需要快递服务。

计算所有有效的取件/配送序列的数目，使得配送操作 `D_i` 总是在取件操作 `P_i` 之后进行。

答案由于很大，请返回对 `10^9 + 7` 取模后的结果。

**示例 1：**
```
输入：n = 1
输出：1
解释：只有一种序列：(P1, D1)
```

**示例 2：**
```
输入：n = 2
输出：6
解释：所有序列：
(P1,P2,D1,D2), (P1,P2,D2,D1), (P1,D1,P2,D2),
(P2,P1,D1,D2), (P2,P1,D2,D1), (P2,D2,P1,D1)
共 6 种。
注意不能是 (P1,D2,P2,D1)，因为 D2 在 P2 之前。
```

**示例 3：**
```
输入：n = 3
输出：90
```

**提示：**
- `1 <= n <= 500`

## 解题思路

**递推/数学推导：**

考虑逐步插入每一对 (P_i, D_i)：

当已经安排了 `i-1` 对订单（2(i-1) 个位置），现在要插入第 `i` 对。

**可用位置数：** 当前序列有 `2(i-1)` 个位置，插入两个新位置后变为 `2i` 个位置。

**先插入 P_i：** 可以放在 `2(i-1)+1 = 2i-1` 个间隙中（包括两端）。

**再插入 D_i：** D_i 必须在 P_i 后面。设 P_i 放在了第 k 个位置（1-indexed），那么 D_i 可以放在 P_i 后面的 `2i-k` 个位置中。

**关键公式：**

对于插入第 i 对，P_i 和 D_i 的总放置方案数等于：

```
sum_{k=1}^{2i-1} (2i - k) = (2i-1) + (2i-2) + ... + 1 = (2i-1) * 2i / 2 = i * (2i-1)
```

所以：`f(i) = f(i-1) * i * (2i-1)`

**总结公式：**

`ans = product_{i=1}^{n} i * (2i-1)`

即 `1*1 * 2*3 * 3*5 * ... * n*(2n-1)`。

**验证：**
- n=1: 1*1 = 1 ✓
- n=2: 1 * (2*3) = 6 ✓
- n=3: 1 * 6 * (3*5) = 1 * 6 * 15 = 90 ✓

## Python 代码实现

### 方法一：数学公式（推荐，最优）

```python
class Solution:
    def countOrders(self, n: int) -> int:
        MOD = 10**9 + 7
        ans = 1
        for i in range(1, n + 1):
            # 插入第 i 对时，可选的方案数为 i * (2i-1)
            # i：P_i 的位置数（2i-1 个间隙中选一个，但与 D_i 组合简化为 i）
            # (2i-1)：D_i 在 P_i 之后的位置数（平均值，通过求和得到）
            ans = ans * i * (2 * i - 1) % MOD
        return ans
```

### 方法二：动态规划（从 n=1 递推）

```python
class Solution:
    def countOrders(self, n: int) -> int:
        MOD = 10**9 + 7
        # dp[i] 表示 i 对订单的有效序列数
        dp = [0] * (n + 1)
        dp[1] = 1  # 只有 (P1, D1) 一种
        
        for i in range(2, n + 1):
            # 在 2(i-1) 个已排好的位置中插入第 i 对
            # 总方案数 = i * (2i-1) * dp[i-1]
            dp[i] = dp[i - 1] * i * (2 * i - 1) % MOD
        
        return dp[n]
```

### 方法三：组合数学推导（直接计算）

```python
class Solution:
    def countOrders(self, n: int) -> int:
        """
        另一种推导：
        2n 个元素全排列共 (2n)! 种。
        对于每对 (Pi, Di)，Pi 必须在 Di 之前，
        所以每对有一半的排列满足条件，共 n 对。
        答案 = (2n)! / 2^n
        """
        MOD = 10**9 + 7
        
        # 计算 (2n)!
        from math import factorial
        numerator = factorial(2 * n) % MOD
        
        # 计算 2^n
        denominator = pow(2, n, MOD)
        
        # 模逆元：a / b mod p = a * b^(p-2) mod p（费马小定理，p为质数）
        denominator_inv = pow(denominator, MOD - 2, MOD)
        
        return numerator * denominator_inv % MOD
```

**方法三推导说明：**

2n 个操作的全排列共 `(2n)!` 种。对于每一对 `(Pi, Di)`，恰好有一半的排列中 Pi 在 Di 之前，另一半 Di 在 Pi 之前。n 对互相独立，所以：

`ans = (2n)! / 2^n`

验证：
- n=1: 2!/2 = 1 ✓
- n=2: 4!/4 = 24/4 = 6 ✓
- n=3: 6!/8 = 720/8 = 90 ✓

### 方法四：递推（详细版，展示推导过程）

```python
class Solution:
    def countOrders(self, n: int) -> int:
        MOD = 10**9 + 7
        ans = 1
        
        for i in range(1, n + 1):
            # 目前序列已有 2*(i-1) 个位置
            # 插入 Pi 有 2*(i-1)+1 = 2i-1 个间隙可选
            # 插入 Di（必须在 Pi 后）的期望可选数为：
            #   Pi 在第 k 个间隙时，Di 有 2i-k 个位置
            #   k 从 1 到 2i-1，平均每种 Pi 位置对应的 Di 位置数之和：
            #   1+2+...+(2i-1) = (2i-1)*2i/2 = i*(2i-1)
            # 所以插入这对的总方案数 = i*(2i-1)
            ans = ans * (i * (2 * i - 1)) % MOD
        
        return ans
```

## 复杂度分析

- 时间复杂度：O(N)，循环 n 次。
- 空间复杂度：O(1)（方法一）或 O(N)（方法二 DP 数组）。

## 推导过程详解

用具体例子理解递推：

**n=2 时的插入过程：**

初始：(P1, D1) — 1 种排列，位置为：`_ P1 _ D1 _`（3 个间隙）

插入 P2：可以放在 3 个间隙的任意一个：
- `P2 P1 D1`（间隙 1）
- `P1 P2 D1`（间隙 2）
- `P1 D1 P2`（间隙 3）

对每种 P2 位置，插入 D2（必须在 P2 后）：
- P2 在间隙 1：D2 有 3 个位置（P2 后的所有间隙）
- P2 在间隙 2：D2 有 2 个位置
- P2 在间隙 3：D2 有 1 个位置

总方案数 = 3+2+1 = 6 = 2*(2*2-1) = 2*3 = 6 ✓

## 关键点总结

1. **递推公式**：`ans = product_{i=1}^{n} i*(2i-1)`，每步乘以第 i 对的插入方案数。
2. **组合意义**：`i*(2i-1)` 等于将 P_i 放入 2i-1 个位置后，D_i 在 P_i 之后所有可能位置数的总和。
3. **等价公式**：`ans = (2n)! / 2^n`，全排列除以每对 (Pi,Di) 的相对顺序选择数。
4. **取模运算**：每次乘法后立即取模，防止数值溢出。
5. **模逆元**：方法三中除以 `2^n` 需要用费马小定理计算模逆元（`pow(x, MOD-2, MOD)`）。

## 易错点

- 取模要在每次乘法后进行，不能等到最后（中间结果可能超出 Python 内存限制，虽然 Python 支持大整数，但运算效率会降低）。
- 方法三中直接用 `factorial(2n)` 不取模再相除是错误的，必须在模运算下进行（用模逆元代替直接除法）。
- 递推时注意 `i` 从 1 开始（不是 0），`i=1` 时 `i*(2i-1) = 1*1 = 1`，即只有 1 对时只有 1 种排列，正确。
