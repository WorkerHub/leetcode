## 题目描述

给你一个整数 `k` 和一个整数 `x`。

定义一个数 `n` 的价格：将 `n` 的二进制表示中，所有满足条件的位的数量，其中条件为"该位是从右往左第 `x`、`2x`、`3x`... 位（1-indexed）且该位为 1"。

定义 `nums` 为从 1 到 `n` 的所有整数，它们的价格总和不超过 `k` 的最大 `n`。

换句话说，返回最大的 `n` 使得 `price(1) + price(2) + ... + price(n) <= k`。

**示例 1：**
```
输入：k = 9, x = 1
输出：6
```

**示例 2：**
```
输入：k = 7, x = 2
输出：9
```

**提示：**
- `1 <= k <= 10^15`
- `1 <= x <= 8`

## 解题思路

**二分查找**：对答案 `n` 进行二分，判断 `1..n` 的价格总和是否 <= `k`。

**计算 `1..n` 中第 `x, 2x, 3x...` 位为 1 的总个数**：

对于第 `b` 位（1-indexed，从右到左），在 `1..n` 中，第 `b` 位为 1 的数的个数可以用数位 DP 公式计算：

设 `p = 2^(b-1)`（该位的值），则在 `0..n` 中第 `b` 位为 1 的个数为：
- `full_cycles = n // (2*p)` 
- `remainder = n % (2*p)`
- 个数 = `full_cycles * p + max(0, remainder - p + 1)`

## Python 代码实现

### 方法一：二分 + 数位统计（推荐）

```python
class Solution:
    def findMaximumNumber(self, k: int, x: int) -> int:
        def count_price(n: int) -> int:
            # 计算 1..n 中所有数字的价格总和
            total = 0
            # 枚举第 x, 2x, 3x, ... 位
            bit = x  # 1-indexed
            while (1 << (bit - 1)) <= n:
                p = 1 << (bit - 1)  # 该位的权重
                cycle = p << 1       # 一个周期 = 2 * p
                full = n // cycle    # 完整的周期数
                rem = n % cycle      # 剩余部分
                # 完整周期中该位为 1 的个数 = full * p
                # 剩余部分中该位为 1 的个数 = max(0, rem - p + 1)
                total += full * p + max(0, rem - p + 1)
                bit += x
            return total

        # 二分答案
        lo, hi = 1, (k + 1) * (1 << x)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if count_price(mid) <= k:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

### 方法二：手动验证版

```python
class Solution:
    def findMaximumNumber(self, k: int, x: int) -> int:
        def get_total_price(n: int) -> int:
            """计算 1 到 n 所有数价格之和"""
            result = 0
            pos = x  # 当前检查的位（1-indexed）
            while pos <= n.bit_length() + x:
                p = 1 << (pos - 1)
                if p > n:
                    break
                cycle = p * 2
                full_cycles = n // cycle
                remainder = n % cycle
                # 当前位为 1 的数的个数
                cnt = full_cycles * p + max(0, remainder - p + 1)
                result += cnt
                pos += x
            return result

        lo, hi = 0, 2 * 10 ** 15
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if get_total_price(mid) <= k:
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 复杂度分析

- 时间复杂度：O(log^2(n * 2^x))，外层二分 O(log n)，每次计算价格 O(log n / x)
- 空间复杂度：O(1)

## 关键点总结

1. 答案具有单调性（价格总和随 n 增大而增大），适合二分
2. 数位统计公式：利用周期性快速计算第 `b` 位在 `1..n` 中为 1 的总次数
3. 二分上界可以估算：最坏情况每个数贡献约 `log n / x` 的价格

## 易错点

1. 位编号从 1 开始（1-indexed），对应权重为 `2^(bit-1)`
2. 剩余部分中该位为 1 的个数需要用 `max(0, rem - p + 1)` 避免负数
3. 二分时注意 `lo = mid` 还是 `lo = mid + 1` 的边界
