## 题目描述

给你一个正整数 `n`，返回 `2` 和 `n` 的最小公倍数（正整数中最小的能被 `2` 和 `n` 整除的数）。

**示例 1：**
```
输入：n = 5
输出：10
解释：5 和 2 的最小公倍数为 10。
```

**示例 2：**
```
输入：n = 6
输出：6
解释：6 和 2 的最小公倍数为 6，因为 6 是 2 的倍数。
```

**提示：**
- `1 <= n <= 150`

## 解题思路

求 `2` 和 `n` 的最小公倍数（LCM）。

- 若 `n` 是偶数，`lcm(2, n) = n`（n 本身就是 2 的倍数）
- 若 `n` 是奇数，`lcm(2, n) = 2 * n`

也可以直接用公式：`lcm(a, b) = a * b / gcd(a, b)`，其中 `gcd(2, n)` 为 1（n 奇数）或 2（n 偶数）。

## 代码实现

### 方法一：直接判断奇偶（推荐）

```python
class Solution:
    def smallestEvenMultiple(self, n: int) -> int:
        # 若 n 为偶数，最小公倍数就是 n 本身
        # 若 n 为奇数，最小公倍数是 2*n
        return n if n % 2 == 0 else 2 * n
```

### 方法二：使用 math.lcm

```python
import math

class Solution:
    def smallestEvenMultiple(self, n: int) -> int:
        # 利用内置最小公倍数函数
        return math.lcm(2, n)
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 直接判断 | O(1) | O(1) |
| math.lcm | O(log n) | O(1) |

## 关键点总结

1. 与 2 求 LCM：偶数不变，奇数乘以 2
2. Python 3.9+ 的 `math.lcm` 可直接使用

## 易错点

- n=1 时结果为 2，n=2 时结果为 2，都满足偶数条件
