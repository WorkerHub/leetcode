## 题目描述

给你一个二维整数数组 `segments`，其中 `segments[i] = [start_i, end_i]` 表示一个线段。

返回从中选出的最大数量的不重叠线段数目（两条线段不重叠指它们没有公共点，即一条的终点严格小于另一条的起点）。

**示例 1：**

```
输入：segments = [[1, 3], [2, 4], [5, 7], [6, 8]]
输出：2
解释：选 [1,3] 和 [5,7]，或 [1,3] 和 [6,8]，两条不重叠。
```

**示例 2：**

```
输入：segments = [[1, 2], [3, 4], [5, 6]]
输出：3
解释：三条线段互不重叠，全选。
```

**提示：**
- `1 <= segments.length <= 10^5`
- `0 <= start_i <= end_i <= 10^9`

## 解题思路

经典**贪心**问题（活动选择问题）：
1. 按线段**右端点**升序排序。
2. 贪心：每次选择右端点最小且与上一条不重叠的线段。
3. 若当前线段的左端点 > 上一条已选线段的右端点，则选取当前线段。

动态规划也可解决，但贪心更简洁。

## Python 代码实现

### 方法一：贪心（推荐）

```python
from typing import List

class Solution:
    def maxNonOverlapping(self, segments: List[List[int]]) -> int:
        # 按右端点升序排序
        segments.sort(key=lambda x: x[1])

        count = 0
        last_end = -1  # 上一条已选线段的右端点

        for start, end in segments:
            # 当前线段的起点严格大于上一条线段的终点
            if start > last_end:
                count += 1
                last_end = end

        return count
```

### 方法二：动态规划

```python
from typing import List
import bisect

class Solution:
    def maxNonOverlapping(self, segments: List[List[int]]) -> int:
        # 按右端点排序
        segments.sort(key=lambda x: x[1])
        n = len(segments)

        # dp[i] = 考虑前 i 条线段时的最大不重叠数
        dp = [0] * (n + 1)
        ends = [seg[1] for seg in segments]

        for i in range(1, n + 1):
            start_i = segments[i - 1][0]
            # 找最后一条右端点 < start_i 的线段（严格不重叠）
            j = bisect.bisect_left(ends, start_i, 0, i - 1)
            # 选第 i 条线段
            dp[i] = max(dp[i - 1], dp[j] + 1)

        return dp[n]
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)（方法一贪心）；O(n)（方法二 DP）

## 关键点总结

1. 活动选择问题的贪心策略：按结束时间排序，优先选结束最早的。
2. 两线段不重叠的条件：`start > last_end`（严格大于）。
3. 动态规划通过二分查找优化状态转移。

## 易错点

1. 不重叠条件是严格大于，端点相等算重叠。
2. 排序按右端点，不是左端点。
3. DP 中二分查找的范围只在前 i-1 条线段中查找。
