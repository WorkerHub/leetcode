## 题目描述

给你一个字符串 `s`，表示 12 小时制的时间，格式为 `hh:mm`。其中某些数字被替换成了 `?`。

12 小时制的时间范围是 `01:00` 到 `12:59`。

返回将 `?` 替换后可以得到的 **最晚** 时间。

**示例 1：**
```
输入：s = "1?:?4"
输出："11:54"
```

**示例 2：**
```
输入：s = "0?:5?"
输出："09:59"
```

**提示：**
- `s.length == 5`
- `s` 的格式为 `hh:mm`
- 字符串中只有 `?` 和数字

## 解题思路

贪心：对每个 `?` 位置，尽量填入最大的合法数字。需要注意 12 小时制的约束：
- 小时 `h1h2`：范围 01-12
- 分钟 `m1m2`：范围 00-59

对每个 `?` 位置枚举 0-9，从大到小找第一个合法的数字。

## Python 代码实现

### 方法一：贪心逐位处理（推荐）

```python
class Solution:
    def findLatestTime(self, s: str) -> str:
        s = list(s)

        # 处理小时十位 s[0]
        if s[0] == '?':
            if s[1] == '?' or s[1] <= '2':
                s[0] = '1'  # 最大为 1x（12 为最大小时）
            else:
                s[0] = '0'

        # 处理小时个位 s[1]
        if s[1] == '?':
            if s[0] == '1':
                s[1] = '2'  # 最大为 12
            else:
                s[1] = '9'  # 但 12 小时制无 09，等等

        # 处理分钟十位 s[3]
        if s[3] == '?':
            s[3] = '5'  # 最大为 5x

        # 处理分钟个位 s[4]
        if s[4] == '?':
            s[4] = '9'  # 最大为 x9

        return ''.join(s)
```

### 方法二：枚举所有可能（更直观）

```python
class Solution:
    def findLatestTime(self, s: str) -> str:
        def valid(t: str) -> bool:
            h = int(t[:2])
            m = int(t[3:])
            return 1 <= h <= 12 and 0 <= m <= 59

        # 枚举所有替换，找最大合法时间
        candidates = []
        for h in range(1, 13):
            for m in range(0, 60):
                t = f"{h:02d}:{m:02d}"
                match = all(
                    s[i] == '?' or s[i] == t[i]
                    for i in range(5)
                )
                if match:
                    candidates.append(t)
        return max(candidates)
```

## 复杂度分析

- 时间复杂度：O(1)，字符串长度固定为 5
- 空间复杂度：O(1)

## 关键点总结

1. 12 小时制：小时范围 01-12，分钟范围 00-59
2. 贪心：从高位到低位，尽量填最大合法数字
3. 数字之间有约束（如小时十位为 1 时，个位最大为 2）

## 易错点

1. 12 小时制小时从 01 开始，不存在 00
2. 小时十位为 1 时个位最大是 2（即 12）
