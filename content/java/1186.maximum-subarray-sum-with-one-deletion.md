## 题目描述

给定整数数组，返回非空子数组的最大和，可以选择删除其中最多一个元素。

**示例：**
```
输入: arr = [1,-2,0,3]
输出: 4（删除-2，得到[1,0,3]）
```

## 解题思路

Kadane 算法变形，维护两个状态：`noDelete` 表示不删除的最大子数组和，`oneDelete` 表示删除一个元素的最大子数组和。

## Java 代码实现

```java
class Solution {
    public int maximumSum(int[] arr) {
        int n = arr.length;
        // noDelete: 以当前元素结尾，不删除的最大和
        // oneDelete: 以当前元素结尾，删除一个元素的最大和
        int noDelete = arr[0];
        int oneDelete = 0;
        int maxSum = arr[0];
        
        for (int i = 1; i < n; i++) {
            // 先更新 oneDelete（依赖旧的 noDelete）
            // 选项1：延续之前已删除一个的子数组
            // 选项2：删除当前元素（即跳过当前，使用之前不删除的结果）
            oneDelete = Math.max(oneDelete + arr[i], noDelete);
            // 再更新 noDelete
            noDelete = Math.max(noDelete + arr[i], arr[i]);
            
            maxSum = Math.max(maxSum, Math.max(noDelete, oneDelete));
        }
        
        return maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两个状态**：不删除 vs 已删除一个元素
2. **更新顺序**：oneDelete 先于 noDelete 更新（依赖旧值）
3. **oneDelete 转移**：延续已删除状态 或 删除当前元素
4. **子数组非空**：至少包含一个元素，全负数时选最大负数
