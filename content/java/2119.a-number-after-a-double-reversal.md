## 题目描述

给定整数num，反转两次后是否等于原数。反转时前导零被删除。

## 解题思路

数学规律：num==0或末位不为0时可还原，末位为0且num!=0时信息丢失无法还原。

## Java 代码实现

```java
class Solution {
    public boolean isSameAfterReversals(int num) {
        return num == 0 || num % 10 != 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **末位为0时信息丢失**：反转后前导零被删除
2. **num==0特殊情况**：0反转两次还是0
3. **一行判断**：num==0 || num%10!=0
