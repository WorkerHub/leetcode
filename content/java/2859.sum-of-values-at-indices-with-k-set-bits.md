## 题目描述

给你整数数组 nums 和整数 k，返回所有下标 i 的二进制表示中恰好有 k 个置位的 `nums[i]` 之和。

## 解题思路

遍历所有下标，用 `Integer.bitCount(i)` 计算置位数，等于 k 则累加。

## Java 代码实现

```java
class Solution {
    public int sumIndicesWithKSetBits(List<Integer> nums, int k) {
        int sum = 0;
        for (int i = 0; i < nums.size(); i++) {
            // Integer.bitCount 计算二进制中 1 的个数
            if (Integer.bitCount(i) == k) {
                sum += nums.get(i);
            }
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. Java 内置 `Integer.bitCount()` 统计置位数，O(1) 时间
2. 下标从 0 开始，下标 0 没有置位
3. 直接遍历累加即可，无需复杂算法
