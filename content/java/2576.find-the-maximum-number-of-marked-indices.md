## 题目描述

给你整数数组 `nums`，每次操作选两个未标记下标 i, j，若 `2*nums[i] <= nums[j]` 则将两者都标记，返回可以标记的最多下标数目。

## 解题思路

排序后双指针贪心：左指针从 0 开始，右指针从中点 `(n+1)/2` 开始，若 `2*nums[left] <= nums[right]` 则两者均可配对，左指针右移；无论是否配对，右指针都右移。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxNumOfMarkedIndices(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int left = 0, right = (n + 1) / 2, count = 0;
        while (right < n) {
            if (2 * nums[left] <= nums[right]) {
                count += 2;
                left++;
            }
            right++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后前半最小与后半最小配对，最优贪心
2. 右指针初始位置在中点，保证右边始终有足够大的值
3. 右指针每步必移，左指针仅在配对成功时移动
