## 题目描述

字符串 `start` 和 `target` 由 'L'、'R'、'_' 组成，'L' 可左移到相邻空格，'R' 可右移，棋子不能穿越，判断能否从 `start` 变换为 `target`。

## 解题思路

双指针同步跳过下划线，逐对比较非下划线字符：字符类型必须相同；L 只能左移（start 位置 >= target 位置）；R 只能右移（start 位置 <= target 位置）。

## Java 代码实现

```java
class Solution {
    public boolean canChange(String start, String target) {
        int n = start.length(), i = 0, j = 0;
        while (i < n || j < n) {
            while (i < n && start.charAt(i) == '_') i++;
            while (j < n && target.charAt(j) == '_') j++;
            if (i == n && j == n) return true;
            if (i == n || j == n) return false;
            if (start.charAt(i) != target.charAt(j)) return false;
            // L 只能左移：start 位置必须 >= target 位置
            if (start.charAt(i) == 'L' && i < j) return false;
            // R 只能右移：start 位置必须 <= target 位置
            if (start.charAt(i) == 'R' && i > j) return false;
            i++; j++;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 去掉下划线后 L/R 的相对顺序不变（棋子不能穿越）。
2. L 只能左移（start 位置 >= target 位置），R 只能右移（start 位置 <= target 位置）。
3. 两步验证：字符序列相同 + 位置约束满足。
