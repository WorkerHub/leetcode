## 题目描述

判断无向加权图中每条边是否在某条从0到n-1的最短路径上。

## 解题思路

双向Dijkstra：从0和n-1分别求最短距离，边(u,v,w)在最短路上当且仅当dist0[u]+w+distn[v]==dist0[n-1]（或反向）。

## Java 代码实现

```java
class Solution {
    public boolean[] findAnswer(int n, int[][] edges) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int i = 0; i < edges.length; i++) {
            int u = edges[i][0], v = edges[i][1], w = edges[i][2];
            graph[u].add(new int[]{v, w, i});
            graph[v].add(new int[]{u, w, i});
        }

        long[] dist0 = dijkstra(graph, 0, n);
        long[] distn = dijkstra(graph, n - 1, n);

        boolean[] ans = new boolean[edges.length];
        long shortest = dist0[n - 1];
        if (shortest == Long.MAX_VALUE) return ans;

        for (int i = 0; i < edges.length; i++) {
            int u = edges[i][0], v = edges[i][1], w = edges[i][2];
            if (dist0[u] + w + distn[v] == shortest || dist0[v] + w + distn[u] == shortest) {
                ans[i] = true;
            }
        }
        return ans;
    }

    private long[] dijkstra(List<int[]>[] graph, int src, int n) {
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[src] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[0], b[0]));
        pq.offer(new long[]{0, src});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0]; int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (int[] e : graph[u]) {
                int v = e[0]; long w = e[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new long[]{dist[v], v});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+M) logN)
- **空间复杂度**：O(N+M)

## 关键点总结

1. **双向Dijkstra**：从0和n-1各跑一次
2. **边在最短路条件**：dist0[u]+w+distn[v]==总最短距离
3. **无向边两个方向都要检查**
