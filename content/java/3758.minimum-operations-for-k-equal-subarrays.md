## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可以将任意元素增减 1，求使数组中存在 `k` 个相等元素所需的最少操作次数。

## 解题思路

排序后，滑动窗口枚举大小为 `k` 的连续子数组，最优目标值为中位数。用前缀和 O(1) 计算每个窗口的代价，取最小值。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minOperations(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i+1] = prefix[i] + nums[i];
        }

        long ans = Long.MAX_VALUE;

        for (int l = 0; l <= n - k; l++) {
            int r = l + k - 1;
            int mid = l + k / 2; // 中位数下标

            // 左半部分代价：[l, mid-1] 到 nums[mid] 的距离
            long leftSum = prefix[mid] - prefix[l];
            long costLeft = (long)nums[mid] * (mid - l) - leftSum;

            // 右半部分代价：[mid+1, r] 到 nums[mid] 的距离
            long rightSum = prefix[r+1] - prefix[mid+1];
            long costRight = rightSum - (long)nums[mid] * (r - mid);

            ans = Math.min(ans, costLeft + costRight);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后，相等的最优目标值是中位数
2. 滑动窗口枚举连续 k 个元素，前缀和 O(1) 计算代价
3. 使用 `long` 防止整数溢出
