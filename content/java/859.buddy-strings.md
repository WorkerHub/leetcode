## 题目描述

给你两个字符串 s 和 goal ，只要我们可以通过交换 s 中的两个字母得到与 goal 相等的结果，就返回 true；否则返回 false 。

交换字母的定义是：取两个下标 i 和 j （下标从 0 开始）且满足 i != j ，接着交换 s[i] 和 s[j] 处的字符。

**示例 1：**
```
输入：s = "ab", goal = "ba"
输出：true
```

**示例 2：**
```
输入：s = "ab", goal = "ab"
输出：false
```

**示例 3：**
```
输入：s = "aa", goal = "aa"
输出：true
解释：你可以交换 s[0] = 'a' 和 s[1] = 'a' 生成 "aa"，此时 s 和 goal 相等。
```

**提示：**
- 1 <= s.length, goal.length <= 2 × 10^4
- s 和 goal 由小写英文字母组成

## 解题思路

这道题需要考虑**两种情况**：

**情况1：s 和 goal 不相等**
- 必须通过交换一次使得相等
- 找到所有不同的位置，必须恰好有 2 个
- 这 2 个位置交换后能使字符串相等

**情况2：s 和 goal 相等**
- 需要交换两个相同的字符（交换后仍相等）
- 只要 s 中有重复字符即可

**算法流程：**
1. 如果长度不同，直接返回 false
2. 找出所有 s[i] != goal[i] 的位置
3. 如果有 0 个不同：检查是否有重复字符
4. 如果有 2 个不同：检查交换后是否相等
5. 其他情况：返回 false

## Java 代码实现

### 方法一：直接模拟（推荐）

```java
class Solution {
    public boolean buddyStrings(String s, String goal) {
        // 长度不同，无法通过交换得到
        if (s.length() != goal.length()) return false;

        // 记录不同的位置
        List<Integer> diffPositions = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != goal.charAt(i)) {
                diffPositions.add(i);
                if (diffPositions.size() > 2) return false; // 超过2个不同，直接返回
            }
        }

        // 如果两个字符串相等，需要有重复字符
        if (diffPositions.isEmpty()) {
            Set<Character> seen = new HashSet<>();
            for (char c : s.toCharArray()) {
                if (!seen.add(c)) return true; // 发现重复字符
            }
            return false;
        }

        // 必须恰好有 2 个不同的位置，且交换后能相等
        if (diffPositions.size() == 2) {
            int i = diffPositions.get(0), j = diffPositions.get(1);
            return s.charAt(i) == goal.charAt(j) && s.charAt(j) == goal.charAt(i);
        }

        return false;
    }
}
```

**代码说明：**
- 记录差异位置的索引
- 检查交换后是否匹配

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串。
- **空间复杂度**：O(1)，字符集大小固定。

## 图解示例

a b → b a ✓

```

```

## 关键点总结

1. **两种情况**：s == goal 和 s != goal 分别处理
2. **重复字符检查**：若相等，需要有重复字符才能交换
3. **差异位置**：必须恰好 2 个
4. **交换验证**：`s[i] == goal[j] && s[j] == goal[i]`
5. **长度检查**：首先检查长度是否相同

## 易错点

1. **忘记处理 s == goal 的情况**：需要检查是否有重复字符

2. **差异位置数量判断**：
   - 0 个：需要有重复字符
   - 2 个：需要交换后匹配
   - 其他：false

3. **交换验证错误**：两个方向都要验证 `s[i] == goal[j] && s[j] == goal[i]`
