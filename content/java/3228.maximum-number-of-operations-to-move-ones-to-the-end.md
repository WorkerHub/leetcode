## 题目描述

给你一个二进制字符串 `s`，每次可将任意 `'10'` 子串变为 `'01'`（把 `'1'` 向右移一位），返回最大操作次数。

## Java 代码实现

```java
class Solution {
    public long maxOperations(String s) {
        long ans = 0;
        int ones = 0; // 当前已见到的 '1' 数量
        for (char c : s.toCharArray()) {
            if (c == '1') {
                ones++;
            } else {
                // 遇到 '0'，前面所有 '1' 都可以向右移动一次
                ans += ones;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每遇到一个 `'0'`，前面所有 `'1'` 各向右移动一步，共贡献 `ones` 次操作
2. 等价于：每个 `'1'` 的操作次数 = 其后面（直到下一个 `'1'`）的 `'0'` 数量
3. 结果可能很大，使用 `long` 防止溢出
