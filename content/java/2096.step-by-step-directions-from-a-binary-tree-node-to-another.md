## 题目描述

给定二叉树root和两个节点值startValue、destValue，返回从start到dest的最短路径（L/R/U表示方向）。

## 解题思路

DFS分别找从根到start和dest的路径，去掉公共前缀（LCA之上部分），start侧剩余变U，dest侧保持原方向。

## Java 代码实现

```java
class Solution {
    public String getDirections(TreeNode root, int startValue, int destValue) {
        StringBuilder pathS = new StringBuilder();
        StringBuilder pathD = new StringBuilder();
        findPath(root, startValue, pathS);
        findPath(root, destValue, pathD);
        
        // 去掉公共前缀
        int i = 0;
        while (i < pathS.length() && i < pathD.length() && pathS.charAt(i) == pathD.charAt(i)) {
            i++;
        }
        
        // start到LCA全变U，LCA到dest保持原方向
        return "U".repeat(pathS.length() - i) + pathD.substring(i);
    }
    
    private boolean findPath(TreeNode node, int target, StringBuilder path) {
        if (node == null) return false;
        if (node.val == target) return true;
        path.append('L');
        if (findPath(node.left, target, path)) return true;
        path.deleteCharAt(path.length() - 1);
        path.append('R');
        if (findPath(node.right, target, path)) return true;
        path.deleteCharAt(path.length() - 1);
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **DFS找路径**：分别记录根到start和dest的方向序列
2. **公共前缀即LCA**：去掉相同前缀后拼接结果
3. **start侧变U**：向上走的步数等于剩余路径长度
