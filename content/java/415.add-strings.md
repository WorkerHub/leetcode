## 题目描述

给定两个字符串形式的非负整数 num1 和 num2，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 BigInteger），也不能直接将输入的字符串转换为整数形式。

**示例 1：**
```
输入：num1 = "11", num2 = "123"
输出："134"
```

**示例 2：**
```
输入：num1 = "456", num2 = "77"
输出："533"
```

**示例 3：**
```
输入：num1 = "0", num2 = "0"
输出："0"
```

## Java 代码实现

### 方法一：模拟加法（推荐）

```java
class Solution {
    public String addStrings(String num1, String num2) {
        // 从右到左逐位相加
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int carry = 0;
        StringBuilder result = new StringBuilder();

        while (i >= 0 || j >= 0 || carry > 0) {
            // 当前位的数字，超出范围则取 0
            int digit1 = (i >= 0) ? (num1.charAt(i) - '0') : 0;
            int digit2 = (j >= 0) ? (num2.charAt(j) - '0') : 0;

            int total = digit1 + digit2 + carry;
            carry = total / 10;           // 进位
            result.append(total % 10);    // 当前位结果

            i--;
            j--;
        }

        // 结果是逆序的，需要反转
        return result.reverse().toString();
    }
}
```

### 方法二：补齐长度

```java
class Solution {
    public String addStrings(String num1, String num2) {
        // 先补齐到相同长度
        int maxLen = Math.max(num1.length(), num2.length());
        // 用 '0' 在前面补齐
        while (num1.length() < maxLen) num1 = "0" + num1;
        while (num2.length() < maxLen) num2 = "0" + num2;

        int carry = 0;
        StringBuilder result = new StringBuilder();

        for (int i = maxLen - 1; i >= 0; i--) {
            int total = (num1.charAt(i) - '0') + (num2.charAt(i) - '0') + carry;
            carry = total / 10;
            result.append(total % 10);
        }

        // 处理最高位的进位
        if (carry > 0) {
            result.append(carry);
        }

        return result.reverse().toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(m, n))
- **空间复杂度**：O(max(m, n))

## 关键点总结

1. 从右到左逐位相加
2. 处理进位
3. 处理长度不同的情况
4. 最后可能还有进位

## 易错点

1. 忘记处理最后的进位
2. 索引越界
3. 忘记反转结果（StringBuilder 从低位到高位追加）
