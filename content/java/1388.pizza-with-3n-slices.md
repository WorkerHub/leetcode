## 题目描述

披萨有 3n 片排成环形，你选一片后相邻两片会被朋友取走，共选 n 次，求你能获得的最大总量。

## 解题思路

每次选一片后相邻两片被移除，等价于从长度 3n 的环形数组中选 n 个互不相邻的元素使总和最大。环形转线性：分两种情况（排除首元素/排除末元素）分别做线性 DP，取最大值。线性 DP：`dp[i][j]` = 前 i 个中选 j 个不相邻元素的最大和，转移：`dp[i][j] = max(dp[i-1][j], dp[i-2][j-1] + arr[i-1])`。

## Java 代码实现

```java
class Solution {
    public int maxSizeSlices(int[] slices) {
        int n = slices.length / 3;
        int m = slices.length;
        // 环形转线性：两种情况取最大
        return Math.max(
            solve(slices, 1, m - 1, n),    // 排除第一个元素
            solve(slices, 0, m - 2, n)     // 排除最后一个元素
        );
    }

    // 从 slices[left..right] 中选 k 个不相邻元素的最大和
    private int solve(int[] slices, int left, int right, int k) {
        int size = right - left + 1;
        // dp[i][j]：前 i 个元素中选 j 个不相邻元素的最大和
        // 用滚动数组优化空间
        int[] prev2 = new int[k + 1];
        int[] prev1 = new int[k + 1];

        for (int i = 1; i <= size; i++) {
            int[] curr = new int[k + 1];
            for (int j = 1; j <= k; j++) {
                // 不选第 i 个
                int notTake = prev1[j];
                // 选第 i 个（则 i-1 不能选）
                int take = prev2[j - 1] + slices[left + i - 1];
                curr[j] = Math.max(notTake, take);
            }
            prev2 = prev1;
            prev1 = curr;
        }

        return prev1[k];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²)，两次 solve 函数各 O(3n × n)。
- 空间复杂度：O(n)，滚动数组优化后只需 O(k) 空间。

## 关键点总结

1. 选 n 片使相邻两片被移除，等价于环形数组中选 n 个互不相邻元素使和最大。
2. 环形转线性：排除首元素和排除末元素两种情况，分别做线性 DP 取最大值。
3. 滚动数组优化：dp[i] 只依赖 dp[i-1] 和 dp[i-2]，空间从 O(n²) 优化到 O(n)。
