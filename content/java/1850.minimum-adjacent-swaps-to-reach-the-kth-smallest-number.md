## 题目描述

将数字字符串变为第k个更大排列所需的最少相邻交换次数。

## 解题思路

两步：1) k次Next Permutation得到目标排列；2) 贪心计算原串变为目标串的最少相邻交换次数（类似冒泡排序）。

## Java 代码实现

```java
class Solution {
    public int getMinSwaps(String num, int k) {
        char[] arr = num.toCharArray();
        // 执行k次Next Permutation
        for (int t = 0; t < k; t++) {
            nextPermutation(arr);
        }
        
        // 计算原串变为目标串的最少相邻交换次数
        char[] orig = num.toCharArray();
        int swaps = 0;
        for (int i = 0; i < orig.length; i++) {
            if (orig[i] != arr[i]) {
                // 找到arr[i]在orig中的位置
                int j = i + 1;
                while (orig[j] != arr[i]) j++;
                // 将orig[j]交换到位置i
                while (j > i) {
                    char tmp = orig[j];
                    orig[j] = orig[j - 1];
                    orig[j - 1] = tmp;
                    j--;
                    swaps++;
                }
            }
        }
        return swaps;
    }
    
    private void nextPermutation(char[] a) {
        int n = a.length;
        int i = n - 2;
        while (i >= 0 && a[i] >= a[i + 1]) i--;
        if (i < 0) return;
        int j = n - 1;
        while (a[j] <= a[i]) j--;
        char tmp = a[i]; a[i] = a[j]; a[j] = tmp;
        // 反转i+1之后
        int left = i + 1, right = n - 1;
        while (left < right) {
            tmp = a[left]; a[left] = a[right]; a[right] = tmp;
            left++; right--;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k*N + N^2)
- **空间复杂度**：O(N)

## 关键点总结

1. **k次Next Permutation**：找目标排列
2. **贪心交换计数**：从左到右对齐，每次找最近匹配移过来
3. **相邻交换**：等价于冒泡排序的交换次数
