## 题目描述

给定二叉树中的两个节点 `p` 和 `q`，每个节点有指向父节点的指针 `parent`，返回这两个节点的最近公共祖先（LCA）。

## 解题思路

**双指针（类似链表相交）：** `a` 和 `b` 分别从 `p` 和 `q` 出发向上走，到达 null 后分别跳到对方起点，两者相遇即 LCA。两条路径长度之和相同，保证会在 LCA 相遇。

## Java 代码实现

```java
class Solution {
    public Node lowestCommonAncestor(Node p, Node q) {
        Node a = p, b = q;

        // 类似找链表交点：两指针各走一次完整路径后在 LCA 相遇
        while (a != b) {
            a = (a == null) ? q : a.parent; // 到达 null 后跳到 q 的起点
            b = (b == null) ? p : b.parent; // 到达 null 后跳到 p 的起点
        }

        return a;
    }
}
```

### 方法二：哈希集合

```java
class Solution {
    public Node lowestCommonAncestor(Node p, Node q) {
        Set<Node> ancestors = new HashSet<>();
        // 将 p 的所有祖先加入集合
        Node node = p;
        while (node != null) {
            ancestors.add(node);
            node = node.parent;
        }
        // 从 q 向上找第一个在集合中的祖先
        node = q;
        while (node != null) {
            if (ancestors.contains(node)) return node;
            node = node.parent;
        }
        return null;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(h)，h 为树的高度
- **空间复杂度**：双指针 O(1)，哈希集合 O(h)

## 关键点总结

1. 双指针：路径 p→root 和 q→root 的长度之和固定，两指针会在 LCA 相遇
2. 到达 null 后跳到另一条路径的起点（p 跳 q，q 跳 p）
3. 双指针方法 O(1) 空间，推荐使用
