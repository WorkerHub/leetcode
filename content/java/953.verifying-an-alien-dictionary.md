## 题目描述

某种外星语也使用英文小写字母，但可能顺序不同。字母表的顺序（`order`）是该语言字母的排列顺序。

给定一组用外星语书写的单词 `words`，以及其字母表的顺序 `order`，只有当给定的单词在这种外星语中按字典序排列时，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
输出：true
解释：在该语言的字母表中，'h' 在 'l' 之前，所以单词序列是按字典序排列的。
```

**示例 2：**
```
输入：words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
输出：false
解释：在该语言的字母表中，'d' 在 'l' 之后，那么 words[0] > words[1]，因此单词序列不是按字典序排列的。
```

**示例 3：**
```
输入：words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
输出：false
解释："apple" > "app"，因为 'e' > '∅'（'∅' 代表不存在的字符）。
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 20`
- `order.length == 26`
- `words[i]` 和 `order` 中的所有字符都是英文小写字母

## 解题思路

这道题的本质是验证单词序列是否按照给定的字母表顺序排列。

**核心思想：**

1. **字典序比较**：按照外星字母表的顺序比较相邻两个单词
2. **建立映射**：将外星字母映射到其顺序位置（0-25）
3. **逐对比较**：只需要比较相邻的两个单词是否满足字典序

**算法流程：**
1. 创建字母到位置的哈希表映射
2. 遍历相邻的单词对
3. 比较每对单词的字典序
4. 如果发现逆序，返回 false
5. 全部通过，返回 true

**字典序比较规则：**
- 从左到右逐个字符比较
- 如果字符不同，比较它们的顺序
- 如果前缀相同，较短的单词应该在前面

## Java 代码实现

### 方法一：哈希表映射 + 双指针比较（推荐）⭐

```java
class Solution {
    /**
     * 验证单词是否按外星字母表顺序排列
     * 思路：
     * 1. 建立字母到位置的映射
     * 2. 比较相邻单词的字典序
     */
    public boolean isAlienSorted(String[] words, String order) {
        // 建立字母顺序映射
        int[] orderMap = new int[26];
        for (int i = 0; i < order.length(); i++) {
            orderMap[order.charAt(i) - 'a'] = i;
        }

        // 比较相邻的单词
        for (int i = 0; i < words.length - 1; i++) {
            if (!isSorted(words[i], words[i + 1], orderMap)) {
                return false;
            }
        }
        return true;
    }

    /**
     * 判断 word1 是否应该排在 word2 前面
     */
    private boolean isSorted(String word1, String word2, int[] orderMap) {
        int minLen = Math.min(word1.length(), word2.length());

        // 逐字符比较
        for (int i = 0; i < minLen; i++) {
            int c1 = orderMap[word1.charAt(i) - 'a'];
            int c2 = orderMap[word2.charAt(i) - 'a'];

            // 如果字符不同，比较它们的顺序
            if (c1 != c2) {
                return c1 < c2;
            }
        }

        // 如果前缀相同，检查长度
        // 如果 word1 更长，说明逆序（例如 "apple" 和 "app"）
        return word1.length() <= word2.length();
    }
}
```

### 方法二：一次遍历简化版

```java
class Solution {
    /**
     * 简化版实现，直接在主方法中完成比较
     */
    public boolean isAlienSorted(String[] words, String order) {
        // 建立顺序映射
        int[] orderMap = new int[26];
        for (int i = 0; i < 26; i++) {
            orderMap[order.charAt(i) - 'a'] = i;
        }

        // 比较相邻单词
        for (int i = 0; i < words.length - 1; i++) {
            String word1 = words[i];
            String word2 = words[i + 1];
            boolean found = false;

            // 逐字符比较
            for (int j = 0; j < Math.min(word1.length(), word2.length()); j++) {
                int c1 = orderMap[word1.charAt(j) - 'a'];
                int c2 = orderMap[word2.charAt(j) - 'a'];
                if (c1 < c2) {
                    // 顺序正确，跳出
                    found = true;
                    break;
                } else if (c1 > c2) {
                    // 顺序错误，返回 false
                    return false;
                }
            }

            // 所有字符都相同时，检查长度
            if (!found && word1.length() > word2.length()) {
                return false;
            }
        }

        return true;
    }
}
```

### 方法三：转换为标准字母表

```java
class Solution {
    /**
     * 将外星单词转换为标准字母表单词，然后比较
     * 思路：
     * 1. 建立外星字母到标准字母的映射
     * 2. 转换所有单词
     * 3. 检查转换后的单词是否已排序
     */
    public boolean isAlienSorted(String[] words, String order) {
        // 建立外星字母到标准字母的映射
        char[] map = new char[26];
        for (int i = 0; i < 26; i++) {
            map[order.charAt(i) - 'a'] = (char) ('a' + i);
        }

        // 转换并比较相邻单词
        for (int i = 0; i < words.length - 1; i++) {
            String t1 = translate(words[i], map);
            String t2 = translate(words[i + 1], map);
            if (t1.compareTo(t2) > 0) return false;
        }
        return true;
    }

    /** 将外星单词转换为标准字母表单词 */
    private String translate(String word, char[] map) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toCharArray()) {
            sb.append(map[c - 'a']);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度**：O(N × M)
  - N 是单词数量
  - M 是单词的平均长度
  - 需要比较 N-1 对单词，每次比较最多 M 个字符
- **空间复杂度**：O(1)，字母表固定为 26 个字母

**方法三：**
- **时间复杂度**：O(N × M)，转换和比较
- **空间复杂度**：O(N × M)，存储转换后的单词

## 关键点总结

1. **哈希表映射**：将字母映射到位置索引，O(1) 查询
2. **相邻比较**：只需比较相邻单词，不需要全局比较
3. **提前终止**：找到第一个不同字符即可判断顺序
4. **边界处理**：特别注意前缀相同时的长度比较
5. **数组代替 Map**：26 个字母可以用大小为 26 的数组替代 HashMap

## 易错点

1. **前缀问题**：忘记处理一个单词是另一个单词前缀的情况
   - 例如："apple" 和 "app"，"apple" 不应该排在 "app" 前面
2. **边界条件**：
   - 单词数组长度为 1：直接返回 true
3. **循环边界**：比较 N-1 对单词，而不是 N 对
4. **字符比较**：要比较映射后的值，不是字符本身
5. **Java 字符串比较**：不能用 `==` 比较字符串，要用 `equals()` 或 `compareTo()`
