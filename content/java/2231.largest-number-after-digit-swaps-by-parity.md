## 题目描述

多次交换同奇偶性的相邻数字，求能得到的最大整数。

## 解题思路

同奇偶性可任意排列（多次相邻交换等价全排列）。分别对奇数位和偶数位数字降序排列，按原位置奇偶性填回。

## Java 代码实现

```java
class Solution {
    public int largestInteger(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        // 分别收集奇偶数字并降序排列
        PriorityQueue<Integer> odds = new PriorityQueue<>(Collections.reverseOrder());
        PriorityQueue<Integer> evens = new PriorityQueue<>(Collections.reverseOrder());
        
        for (char d : digits) {
            int v = d - '0';
            if (v % 2 == 1) odds.offer(v);
            else evens.offer(v);
        }
        
        StringBuilder sb = new StringBuilder();
        for (char d : digits) {
            int v = d - '0';
            if (v % 2 == 1) sb.append(odds.poll());
            else sb.append(evens.poll());
        }
        return Integer.parseInt(sb.toString());
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)，N为位数
- **空间复杂度**：O(N)

## 关键点总结

1. **同奇偶可任意排列**：多次相邻交换等价冒泡排序
2. **分组降序**：奇数位数字降序、偶数位数字降序
3. **按原位置填回**：保持奇偶位置不变
