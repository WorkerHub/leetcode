## 题目描述

给你整数数组 nums 和两个整数 indexDifference、valueDifference，找出满足 `abs(i-j) >= indexDifference` 且 `abs(nums[i]-nums[j]) >= valueDifference` 的两个下标，不存在则返回 `[-1, -1]`。数据范围 n 达 10^5，需要 O(n) 解法。

## 解题思路

枚举 j，候选 i 在 `[0, j-indexDifference]` 中动态维护前缀最大/最小值索引。每步只需将新加入的 `i = j - indexDifference` 更新到最大/最小中，再检查两种配对（nums[j] 配最小值 i，或 nums[j] 配最大值 i）。

## Java 代码实现

```java
class Solution {
    public int[] findIndices(int[] nums, int indexDifference, int valueDifference) {
        int n = nums.length;
        int minIdx = 0; // [0, i] 中最小值下标
        int maxIdx = 0; // [0, i] 中最大值下标

        for (int j = indexDifference; j < n; j++) {
            // 新加入候选下标 i = j - indexDifference
            int i = j - indexDifference;
            if (nums[i] < nums[minIdx]) minIdx = i;
            if (nums[i] > nums[maxIdx]) maxIdx = i;

            // 检查 nums[j] 与最小值配对
            if (nums[j] - nums[minIdx] >= valueDifference) return new int[]{minIdx, j};
            // 检查 nums[j] 与最大值配对
            if (nums[maxIdx] - nums[j] >= valueDifference) return new int[]{maxIdx, j};
        }
        return new int[]{-1, -1};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，单次遍历，每步 O(1) 更新
- **空间复杂度**：O(1)

## 关键点总结

1. `abs(nums[i]-nums[j])` 最大化需要找区间内的最大值或最小值与 nums[j] 配对
2. 候选区间随 j 单调扩展，动态维护最大/最小值无需重扫
3. j 从 indexDifference 开始，i = j - indexDifference 恰好满足下标差条件
