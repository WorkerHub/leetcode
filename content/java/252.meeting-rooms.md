## 题目描述

给定一个会议时间安排的数组 `intervals`，每个会议时间都会包括开始和结束的时间 `intervals[i] = [starti, endi]`，请你判断一个人是否能够参加这里面的全部会议。

**示例 1：**

```
输入：intervals = [[0,30],[5,10],[15,20]]
输出：false
解释：存在重叠的会议时间
```

**示例 2：**

```
输入：intervals = [[7,10],[2,4]]
输出：true
解释：没有重叠的会议时间
```

**提示：**
- `0 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti < endi <= 10^6`

## 解题思路

这是一道经典的区间问题。要判断一个人能否参加所有会议，关键是检查是否存在时间冲突。

核心思想：
1. 将所有会议按照开始时间排序
2. 检查相邻的两个会议是否有重叠
3. 如果前一个会议的结束时间大于后一个会议的开始时间，说明有冲突

关键观察：
- 排序后，只需要检查相邻会议即可
- 如果相邻会议都不冲突，那么整体就不冲突

## Java 代码实现

### 方法一：排序 + 遍历（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        // 边界情况：空数组或只有一个会议
        if (intervals.length <= 1) return true;

        // 按照会议开始时间排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        // 检查相邻会议是否有重叠
        for (int i = 1; i < intervals.length; i++) {
            // 如果前一个会议的结束时间 > 当前会议的开始时间，说明冲突
            if (intervals[i - 1][1] > intervals[i][0]) {
                return false;
            }
        }

        return true;
    }
}
```

### 方法二：Lambda 表达式简化排序

```java
import java.util.Arrays;

class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return true;

        // 使用 Comparator 按开始时间升序排列
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        for (int i = 1; i < intervals.length; i++) {
            // 前一个会议结束时间 > 当前会议开始时间 → 冲突
            if (intervals[i - 1][1] > intervals[i][0]) {
                return false;
            }
        }

        return true;
    }
}
```

### 方法三：暴力解法（用于对比学习）

```java
class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        // 暴力检查所有会议对，时间复杂度 O(n^2)
        int n = intervals.length;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 判断两个区间是否重叠
                if (isOverlap(intervals[i], intervals[j])) {
                    return false;
                }
            }
        }

        return true;
    }

    // 判断两个区间是否重叠
    private boolean isOverlap(int[] a, int[] b) {
        // 两个区间重叠的条件：
        // a 的开始时间 < b 的结束时间 AND b 的开始时间 < a 的结束时间
        return a[0] < b[1] && b[0] < a[1];
    }
}
```

## 复杂度分析

**方法一（排序 + 遍历）：**
- 时间复杂度：O(n log n)，主要是排序的时间
- 空间复杂度：O(log n)，排序使用的栈空间

**方法三（暴力解法）：**
- 时间复杂度：O(n^2)，需要检查所有会议对
- 空间复杂度：O(1)

## 关键点总结

1. **排序是关键**：按开始时间排序后，问题简化为检查相邻区间
2. **区间重叠判断**：前一个结束时间 > 后一个开始时间表示重叠
3. **时间复杂度优化**：排序方法 O(n log n) 优于暴力 O(n^2)
4. **边界条件**：注意处理空数组和单个会议的情况
5. **Java 排序**：使用 `Arrays.sort` 配合 `Comparator` 进行二维数组排序

## 易错点

1. **重叠条件判断错误**
   ```java
   // 错误：使用 >= 会错误地认为刚好衔接的会议也冲突
   if (intervals[i - 1][1] >= intervals[i][0]) return false;

   // 正确：使用 > ，允许前一个会议结束时下一个会议开始
   if (intervals[i - 1][1] > intervals[i][0]) return false;
   ```

2. **忘记排序**
   ```java
   // 错误：没有排序就直接检查相邻会议
   for (int i = 1; i < intervals.length; i++) {
       if (intervals[i - 1][1] > intervals[i][0]) return false;
   }

   // 正确：先排序
   Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
   ```

3. **Comparator 溢出问题**：当数值差可能溢出时，用 `Integer.compare()` 而非直接相减

4. **空数组处理**：记得处理空数组的情况，应该返回 `true`
