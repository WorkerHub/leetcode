## 题目描述

每次操作将数组中某个数减半（可为小数），求使总和至少减半的最少操作次数。

## 解题思路

贪心：每次对当前最大值减半收益最大。用最大堆维护当前值，不断弹出最大值减半直到累计减少量>=总和/2。

## Java 代码实现

```java
class Solution {
    public int halveArray(int[] nums) {
        PriorityQueue<Double> pq = new PriorityQueue<>(Collections.reverseOrder());
        double total = 0;
        for (int x : nums) {
            pq.offer((double) x);
            total += x;
        }
        
        double target = total / 2;
        double reduced = 0;
        int ops = 0;
        
        while (reduced < target) {
            double max = pq.poll();
            double half = max / 2;
            reduced += half;
            pq.offer(half);
            ops++;
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k log N)，k为操作次数
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心最优**：每次减半最大值，减少量最大
2. **最大堆维护**：Java用Collections.reverseOrder()
3. **浮点数运算**：减半后可能是小数，用double
