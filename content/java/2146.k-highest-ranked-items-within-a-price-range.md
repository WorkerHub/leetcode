## 题目描述

从start出发BFS，找价格在[low,high]范围内的商品，按(距离,价格,行,列)排名返回前k个坐标。

## 解题思路

BFS遍历所有可达商品并记录距离，收集满足价格范围的商品后按排名规则排序取前k个。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> highestRankedKItems(int[][] grid, int[] pricing, int[] start, int k) {
        int m = grid.length, n = grid[0].length;
        int low = pricing[0], high = pricing[1];
        int sr = start[0], sc = start[1];
        
        boolean[][] visited = new boolean[m][n];
        visited[sr][sc] = true;
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{sr, sc, 0});
        // (距离, 价格, 行, 列)
        List<int[]> items = new ArrayList<>();
        
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], dist = cur[2];
            int price = grid[r][c];
            if (price >= low && price <= high) {
                items.add(new int[]{dist, price, r, c});
            }
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc] && grid[nr][nc] != 0) {
                    visited[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, dist + 1});
                }
            }
        }
        
        // 按(距离, 价格, 行, 列)排序
        items.sort((a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0];
            if (a[1] != b[1]) return a[1] - b[1];
            if (a[2] != b[2]) return a[2] - b[2];
            return a[3] - b[3];
        });
        
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < Math.min(k, items.size()); i++) {
            result.add(Arrays.asList(items.get(i)[2], items.get(i)[3]));
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N*log(M*N))
- **空间复杂度**：O(M*N)

## 关键点总结

1. **BFS保证最短距离**：天然得到每个商品的距离信息
2. **排序关键字**：(距离, 价格, 行, 列)四元组比较
3. **墙的处理**：grid值为0不可通过，入队前过滤
