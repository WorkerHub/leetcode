## 题目描述

给你 n×n 矩阵 `grid`，其中 1 到 n² 的整数中恰好一个出现两次、一个缺失，返回 `[重复值, 缺失值]`。

## 解题思路

用计数数组统计每个数字出现次数，出现 2 次的为重复值，出现 0 次的为缺失值。

## Java 代码实现

```java
class Solution {
    public int[] findMissingAndRepeatedValues(int[][] grid) {
        int n = grid.length;
        int[] cnt = new int[n * n + 1];
        for (int[] row : grid)
            for (int x : row) cnt[x]++;

        int repeated = -1, missing = -1;
        for (int num = 1; num <= n * n; num++) {
            if (cnt[num] == 2) repeated = num;
            else if (cnt[num] == 0) missing = num;
        }
        return new int[]{repeated, missing};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. 计数数组统计频次，频次为 2 的是重复值，为 0 的是缺失值
2. 数字范围 1 到 n²，数组大小 n²+1
3. 方法简单直接，空间换时间
