## 题目描述

给定非负整数数组 nums（一半奇数一半偶数），排序使得偶数索引放偶数、奇数索引放奇数。

**示例：**
```
输入：nums = [4,2,5,7]
输出：[4,5,2,7]
```

## 解题思路

双指针：一个指向偶数索引、一个指向奇数索引，找到错位的元素后交换。

## Java 代码实现

```java
class Solution {
    public int[] sortArrayByParityII(int[] nums) {
        int n = nums.length;
        int i = 0, j = 1; // i 偶数索引，j 奇数索引

        while (i < n && j < n) {
            // 偶数位置是偶数则跳过
            while (i < n && nums[i] % 2 == 0) i += 2;
            // 奇数位置是奇数则跳过
            while (j < n && nums[j] % 2 == 1) j += 2;
            // 交换错位元素
            if (i < n && j < n) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
            }
        }

        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针分别步进 2**：偶数索引 +2，奇数索引 +2
2. **交换错位**：偶数位上的奇数与奇数位上的偶数交换
3. **原地修改**：无需额外空间
