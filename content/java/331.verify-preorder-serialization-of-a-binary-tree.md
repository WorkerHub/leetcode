## 题目描述

序列化二叉树的一种方法是使用**前序遍历**。当我们遇到一个非空节点时，我们可以记录下这个节点的值。如果它是一个空节点，我们可以使用一个标记值记录，例如 `#`。

```
     _9_
    /   \
   3     2
  / \   / \
 4   1  #  6
/ \ / \   / \
# # # #   # #
```

例如，上面的二叉树可以被序列化为字符串 `"9,3,4,#,#,1,#,#,2,#,6,#,#"`，其中 `#` 代表一个空节点。

给定一串以逗号分隔的序列，验证它是否是正确的二叉树的前序序列化。编写一个在不重构树的条件下的可行算法。

保证每个以逗号分隔的字符或为一个整数或为一个表示 `null` 指针的 `#`。

你可以认为输入格式总是有效的。

**示例 1:**

```
输入: preorder = "9,3,4,#,#,1,#,#,2,#,6,#,#"
输出: true
```

**示例 2:**

```
输入: preorder = "1,#"
输出: false
```

**示例 3:**

```
输入: preorder = "9,#,#,1"
输出: false
```

**提示:**

- `1 <= preorder.length <= 10^4`
- `preorder` 由以逗号 `","` 分隔的 `[0,100]` 范围内的整数和 `"#"` 组成

## 解题思路

这道题有两种经典解法：**栈模拟** 和 **出入度法**。

### 思路一：栈模拟（推荐）

二叉树的性质：
- 非空节点提供 2 个出度（左右子节点）
- 每个节点（除根节点）消耗 1 个入度（父节点的出度）

使用栈模拟：
1. 用栈记录**可用的槽位数**（即未使用的出度）
2. 遍历每个节点：
   - 如果栈为空且不是第一个节点，返回 `false`（没有槽位可用）
   - 消耗一个槽位（栈顶 -1）
   - 如果是非空节点，提供 2 个新槽位
   - 如果栈顶为 0，弹出（该节点的槽位已用完）
3. 最后栈应该为空（所有槽位都被使用）

### 思路二：出入度法

- 初始化 `slots = 1`（根节点有 1 个槽位）
- 遍历每个节点：
  - 先消耗 1 个槽位（`slots -= 1`）
  - 如果 `slots < 0`，返回 `false`
  - 如果是非空节点，提供 2 个新槽位（`slots += 2`）
- 最后 `slots` 应该为 0

## Java 代码实现

### 方法一：栈模拟（推荐）⭐

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValidSerialization(String preorder) {
        // 栈模拟：维护可用槽位数
        String[] nodes = preorder.split(",");
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(1);  // 初始有 1 个槽位（根节点）

        for (String node : nodes) {
            // 没有可用槽位
            if (stack.isEmpty()) {
                return false;
            }

            // 消耗一个槽位
            int top = stack.pop() - 1;

            // 如果还有剩余槽位，重新压入
            if (top > 0) {
                stack.push(top);
            }

            // 非空节点提供 2 个新槽位
            if (!node.equals("#")) {
                stack.push(2);
            }
        }

        // 最后栈应该为空（所有槽位都被使用）
        return stack.isEmpty();
    }
}
```

### 方法二：出入度法（更简洁）⭐

```java
class Solution {
    public boolean isValidSerialization(String preorder) {
        // 出入度法：slots 表示可用槽位数
        String[] nodes = preorder.split(",");
        int slots = 1;  // 初始有 1 个槽位（根节点）

        for (String node : nodes) {
            // 每个节点消耗 1 个槽位
            slots -= 1;

            // 槽位不足，无效
            if (slots < 0) {
                return false;
            }

            // 非空节点提供 2 个新槽位
            if (!node.equals("#")) {
                slots += 2;
            }
        }

        // 所有槽位应该刚好用完
        return slots == 0;
    }
}
```

### 方法三：栈模拟（合并叶子节点）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValidSerialization(String preorder) {
        // 栈模拟：将 "数字 # #" 合并为 #
        String[] nodes = preorder.split(",");
        Deque<String> stack = new ArrayDeque<>();

        for (String node : nodes) {
            stack.push(node);

            // 当栈顶为 "... 数字 # #" 时，合并为 #
            while (stack.size() >= 3) {
                String top1 = stack.pop();
                String top2 = stack.pop();
                String top3 = stack.pop();

                if (top1.equals("#") && top2.equals("#") && !top3.equals("#")) {
                    // 弹出 # # 数字，压入一个 #（表示这个子树已完成）
                    stack.push("#");
                } else {
                    // 不满足条件，恢复栈
                    stack.push(top3);
                    stack.push(top2);
                    stack.push(top1);
                    break;
                }
            }
        }

        // 最后栈中应该只剩一个 #（完整的树）
        return stack.size() == 1 && stack.peek().equals("#");
    }
}
```

## 复杂度分析

**方法一/二：栈 / 出入度**

- **时间复杂度**：O(n)
  - 遍历所有节点一次
  
- **空间复杂度**：
  - 方法一：O(h)，栈的深度最多为树的高度
  - 方法二：O(1)，只用一个变量

**方法三：合并叶子节点**

- **时间复杂度**：O(n)
  - 每个节点最多入栈出栈一次
  
- **空间复杂度**：O(n)
  - 栈的空间

## 关键点总结

1. **槽位概念**：
   - 每个节点（除根）消耗 1 个槽位
   - 非空节点提供 2 个槽位
   - 空节点不提供槽位

2. **合法性判断**：
   - 遍历过程中槽位不能为负
   - 最后槽位应该为 0（刚好用完）

3. **栈的作用**：
   - 方法一：记录每个节点的剩余槽位
   - 方法三：合并完整的子树

4. **出入度思想**：
   - 出度：节点提供的子节点槽位
   - 入度：节点占用的父节点槽位

5. **前序遍历特性**：先访问根节点，再访问子树

## 易错点

1. **初始槽位数**：应该是 1（根节点的槽位），不是 0

2. **槽位检查时机**：
   - 方法一：在消耗槽位后检查栈是否为空
   - 方法二：在消耗槽位后立即检查是否为负

3. **最后的判断**：
   - 方法一：栈应该为空
   - 方法二：`slots == 0`（不是 `<= 0`）

4. **边界情况**：
   - 空字符串：题目保证不会出现
   - 单个节点：`"#"` 或 `"1,#,#"`

5. **字符串分割**：使用 `split(",")` 分割字符串，字符串比较用 `equals()` 而非 `==`

```
处理 #: slots = 2 - 1 = 1

处理 #: slots = 2 - 1 = 1

```
