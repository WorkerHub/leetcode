## 题目描述

给定 `m x n` 二维数组 `grid` 和整数 `k`，统计满足 `r1 < r2` 且 `|grid[r1][c1] - grid[r2][c2]| == k` 的元素对数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPairs(int[][] grid, int k) {
        int m = grid.length;
        int count = 0;

        for (int r1 = 0; r1 < m; r1++) {
            // 统计第 r1 行各值频率
            Map<Integer, Integer> cnt1 = new HashMap<>();
            for (int v : grid[r1]) cnt1.merge(v, 1, Integer::sum);

            for (int r2 = r1 + 1; r2 < m; r2++) {
                // 统计第 r2 行各值频率
                Map<Integer, Integer> cnt2 = new HashMap<>();
                for (int v : grid[r2]) cnt2.merge(v, 1, Integer::sum);

                for (Map.Entry<Integer, Integer> e : cnt1.entrySet()) {
                    int v = e.getKey(), c = e.getValue();
                    count += c * cnt2.getOrDefault(v + k, 0);
                    if (k > 0) count += c * cnt2.getOrDefault(v - k, 0);
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m^2 * n)
- 空间复杂度：O(n)

## 关键点总结

1. 跨行约束：r1 < r2，枚举所有行对
2. 哈希表加速：`|a - b| == k` 等价于 `b == a+k` 或 `b == a-k`
3. k == 0 时只计一次，避免重复（`v+k == v-k`）
