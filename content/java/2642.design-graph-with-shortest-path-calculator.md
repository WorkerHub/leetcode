## 题目描述

设计一个有向带权图，支持动态添加边和查询两点间最短路径（不可达返回 -1）。

## Java 代码实现

```java
import java.util.*;

class Graph {
    private final int n;
    private final List<int[]>[] adj; // adj[u] = {v, cost}

    public Graph(int n, int[][] edges) {
        this.n = n;
        adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) adj[e[0]].add(new int[]{e[1], e[2]});
    }

    public void addEdge(int[] edge) {
        adj[edge[0]].add(new int[]{edge[1], edge[2]});
    }

    public int shortestPath(int node1, int node2) {
        // Dijkstra 从 node1 出发
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[node1] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, node1});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue; // 过时条目
            if (u == node2) return (int) d;
            for (int[] next : adj[u]) {
                int v = next[0];
                long nd = dist[u] + next[1];
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{nd, v});
                }
            }
        }
        return dist[node2] == Long.MAX_VALUE ? -1 : (int) dist[node2];
    }
}
```

## 复杂度分析

- addEdge：O(1)
- shortestPath：O((n + m) log n)，m 为边数

## 关键点总结

1. 每次查询重新运行 Dijkstra，适应动态加边
2. 最小堆维护 (距离, 节点)，跳过过时条目
3. 用 `long` 防止边权累加溢出
