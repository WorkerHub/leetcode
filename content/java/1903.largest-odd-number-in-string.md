## 题目描述

给你表示大整数的字符串 `num`，在所有非空子字符串中找出值最大的奇数，以字符串形式返回，不存在则返回 `""`。

## 解题思路

奇偶性只由最后一位决定，字符串越长值越大（无前导零），因此从右往左找第一个奇数位，返回从开头到该位置的前缀字符串。

## Java 代码实现

```java
class Solution {
    public String largestOddNumber(String num) {
        // 从右往左找第一个奇数位
        for (int i = num.length() - 1; i >= 0; i--) {
            if ((num.charAt(i) - '0') % 2 == 1) {
                return num.substring(0, i + 1);
            }
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 奇偶性只由最后一位（个位）决定
2. 越长的前缀对应越大的数值（无前导零）
3. 贪心：找最右边的奇数位，取其前缀
