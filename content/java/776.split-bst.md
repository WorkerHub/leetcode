## 题目描述

给定 BST 的根节点和目标值 target，将 BST 分成两棵子树：一棵所有节点值 <= target，另一棵所有节点值 > target。

**示例：**
```
输入：root = [4,2,6,1,3,5,7], target = 2
输出：[[2,1],[4,3,6,null,null,5,7]]
```

## 解题思路

递归分割：根据当前节点值与 target 的关系，递归处理左子树或右子树并重新连接。

## Java 代码实现

```java
class Solution {
    public TreeNode[] splitBST(TreeNode root, int target) {
        if (root == null) return new TreeNode[]{null, null};

        if (root.val <= target) {
            // 左子树全属于左侧，递归处理右子树
            TreeNode[] result = splitBST(root.right, target);
            root.right = result[0];
            return new TreeNode[]{root, result[1]};
        } else {
            // 右子树全属于右侧，递归处理左子树
            TreeNode[] result = splitBST(root.left, target);
            root.left = result[1];
            return new TreeNode[]{result[0], root};
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(h)，h 为树高
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **BST 性质**：左子树 < 根 < 右子树
2. **递归分割**：根据值与 target 关系决定递归方向
3. **重新连接**：将递归结果接回当前节点
