## 题目描述

给你初始窗口列表 `windows` 和操作序列 `queries`，每次操作将对应窗口移到最前面，返回操作完成后的窗口列表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] simulationResult(int[] windows, int[] queries) {
        Set<Integer> windowSet = new HashSet<>();
        for (int w : windows) windowSet.add(w);

        // 逆序处理 queries，去重后得到最终前置顺序
        List<Integer> result = new ArrayList<>();
        Set<Integer> seen = new HashSet<>();
        for (int i = queries.length - 1; i >= 0; i--) {
            int q = queries[i];
            if (windowSet.contains(q) && seen.add(q)) {
                result.add(q);
            }
        }

        // 加入未被查询的窗口（保持原顺序）
        for (int w : windows) {
            if (!seen.contains(w)) result.add(w);
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为 windows 长度，m 为 queries 长度
- 空间复杂度：O(n)

## 关键点总结

1. 逆序处理 queries：后被查询的优先级最高（最终在前面）
2. 对每个 query 去重，只保留最后一次出现
3. 原始 windows 中未被查询的保持相对顺序
