## 题目描述

给你整数数组 `coins`，返回从 0 开始能凑出的最大连续整数个数（即能凑出 0, 1, ..., k 则返回 k+1）。

## 解题思路

排序后贪心：维护当前可凑出 `[0, reach]` 的所有值。对每个 `coin`，若 `coin <= reach+1`，则扩展到 `reach + coin`；否则有空缺，停止。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int getMaximumConsecutive(int[] coins) {
        Arrays.sort(coins);
        int reach = 0; // 当前可凑出 [0, reach] 的所有值

        for (int coin : coins) {
            if (coin > reach + 1) break; // 存在空缺，无法覆盖 reach+1
            reach += coin; // 扩展覆盖范围到 [0, reach+coin]
        }

        return reach + 1; // 0 到 reach 共 reach+1 个值
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后维护 reach：当前已能覆盖 [0, reach]
2. 若 coin <= reach+1，则覆盖范围扩展为 [0, reach+coin]
3. 初始 reach=0（只能凑出 0），最终返回 reach+1
