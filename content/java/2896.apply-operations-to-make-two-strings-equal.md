## 题目描述

给你两个等长二进制字符串 s1、s2 和正整数 x，可以以不同代价翻转位对，返回使 s1==s2 的最小代价，无法实现返回 -1。

## 解题思路

只关注 s1[i] != s2[i] 的差异位置，差异数为奇数时返回 -1；用 DP 处理差异位置数组，每对相邻差异的消除代价 = `min(位置差, x)`，通过记忆化递归从前往后配对。

## Java 代码实现

```java
class Solution {
    private int[] diff;
    private int x;
    private int[] memo;

    public int minOperations(String s1, String s2, int x) {
        List<Integer> diffList = new ArrayList<>();
        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) != s2.charAt(i)) diffList.add(i);
        }

        int n = diffList.size();
        if (n % 2 == 1) return -1;
        if (n == 0) return 0;

        this.diff = diffList.stream().mapToInt(Integer::intValue).toArray();
        this.x = x;
        this.memo = new int[n];
        Arrays.fill(memo, -1);

        return dp(0);
    }

    // 处理 diff[i..n-1] 的最小代价（i 到 n-1 为偶数个）
    private int dp(int i) {
        if (i >= diff.length) return 0;
        if (memo[i] != -1) return memo[i];

        // 将 diff[i] 与 diff[i+1] 配对
        int res = Math.min(diff[i + 1] - diff[i], x) + dp(i + 2);

        // 将 diff[i] 与 diff[i+1] 分别跨入不同的对（需要多看一步）
        if (i + 3 < diff.length) {
            res = Math.min(res,
                Math.min(diff[i + 1] - diff[i], x) +
                Math.min(diff[i + 3] - diff[i + 2], x) +
                dp(i + 4));
        }

        memo[i] = res;
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为差异位置数量
- **空间复杂度**：O(n)

## 关键点总结

1. 只处理 s1[i] != s2[i] 的差异位置，奇数个差异无解
2. 每对相邻差异消除代价 = `min(位置差, x)`（x 为跨串操作代价）
3. 记忆化递归简化配对决策
