## 题目描述

给定正整数，检查其二进制表示是否总是 0、1 交替出现。

**示例：**
```
输入：n = 5（二进制 101）
输出：true
```

## 解题思路

位运算：n ^ (n >> 1) 如果是交替的则所有位为1，再检查 xor & (xor + 1) == 0。

## Java 代码实现

```java
class Solution {
    public boolean hasAlternatingBits(int n) {
        int xor = n ^ (n >>> 1);
        return (xor & (xor + 1)) == 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **异或技巧**：交替位异或右移1位后全为1
2. **全1检查**：x & (x+1) == 0
3. **无符号右移**：Java 用 >>> 避免符号位问题
