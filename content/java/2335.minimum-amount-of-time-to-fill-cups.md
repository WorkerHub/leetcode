## 题目描述

给你长度为 3 的数组 `amount`，每秒可同时填充两种不同水各一杯，或单独填充一杯，返回填满所有杯子所需的最少秒数。

## 解题思路

贪心数学公式：设排序后 `a <= b <= c`。若最大值 `c >= a+b`，则需 c 秒；否则需 `ceil((a+b+c)/2)` 秒。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int fillCups(int[] amount) {
        Arrays.sort(amount);
        int a = amount[0], b = amount[1], c = amount[2];
        if (c >= a + b) return c; // 最大值超过另两者之和
        return (a + b + c + 1) / 2; // 向上取整
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（数组长度固定为 3）
- **空间复杂度**：O(1)

## 关键点总结

1. 每次同时减少两种数量最大的杯子是最优策略。
2. 最大值 >= 其余之和时，等最大值消耗完即可。
3. 整数向上取整：`(total + 1) / 2`。
