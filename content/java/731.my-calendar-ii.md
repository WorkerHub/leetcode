## 题目描述

实现一个 MyCalendarTwo 类来存放日程安排。如果添加的时间不会导致三重预订，则可以添加。

**示例：**
```
myCalendar.book(10, 20); // true
myCalendar.book(50, 60); // true
myCalendar.book(10, 40); // true
myCalendar.book(5, 15);  // false（会造成三重预订）
myCalendar.book(5, 10);  // true
myCalendar.book(25, 55); // true
```

## 解题思路

维护两个列表：所有预订 calendar 和双重预订 overlaps。新预订先检查是否与 overlaps 冲突，再更新 overlaps。

## Java 代码实现

```java
class MyCalendarTwo {
    private List<int[]> calendar;
    private List<int[]> overlaps;

    public MyCalendarTwo() {
        calendar = new ArrayList<>();
        overlaps = new ArrayList<>();
    }

    public boolean book(int start, int end) {
        // 检查是否会造成三重预订
        for (int[] interval : overlaps) {
            if (start < interval[1] && end > interval[0]) {
                return false;
            }
        }
        // 记录新的重叠区间
        for (int[] interval : calendar) {
            if (start < interval[1] && end > interval[0]) {
                overlaps.add(new int[]{
                    Math.max(start, interval[0]),
                    Math.min(end, interval[1])
                });
            }
        }
        calendar.add(new int[]{start, end});
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **双列表维护**：calendar 存所有预订，overlaps 存双重预订区间
2. **三重检测**：新预订与 overlaps 冲突则为三重
3. **重叠计算**：交集为 [max(s1,s2), min(e1,e2))
