## 题目描述

偶数下标是字母，奇数下标是数字。将每个奇数位数字替换为 shift(s[i-1], s[i])，即前一字母后移对应位数。

## 解题思路

遍历奇数位，用 (char)(s[i-1] + (s[i] - '0')) 计算替换后的字符。

## Java 代码实现

```java
class Solution {
    public String replaceDigits(String s) {
        char[] arr = s.toCharArray();
        for (int i = 1; i < arr.length; i += 2) {
            // 将奇数位数字替换为前一字母后移对应位数
            arr[i] = (char)(arr[i - 1] + (arr[i] - '0'));
        }
        return new String(arr);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **字符运算**：(char)(c + d) 实现字母后移
2. **步长为2**：只处理奇数位
3. **原地修改**：toCharArray后直接修改
