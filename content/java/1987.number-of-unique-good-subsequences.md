## 题目描述

给定由 `'0'` 和 `'1'` 组成的字符串 `binary`，求其中所有不同的"好子序列"数量（好子序列不含前导零，即以 `'1'` 开头或等于 `"0"`），对 `10^9 + 7` 取余。

## 解题思路

维护两个变量：`ends1`（以 `'1'` 结尾的不同好子序列数）和 `ends0`（以 `'0'` 结尾的不同好子序列数，不含单独 `"0"`）。遇到 `'1'` 时 `ends1 = ends1 + ends0 + 1`（在所有好子序列后加 `'1'`，再加单独 `"1"`）；遇到 `'0'` 时 `ends0 = ends1 + ends0`。最终答案加上单独的 `"0"`（若存在）。

## Java 代码实现

### 方法一：DP（推荐）

```java
class Solution {
    public int numberOfUniqueGoodSubsequences(String binary) {
        final int MOD = 1_000_000_007;
        // ends1: 以'1'结尾的不同好子序列数
        // ends0: 以'0'结尾的不同好子序列数（不含单独"0"）
        long ends1 = 0, ends0 = 0;
        boolean hasZero = false;

        for (char c : binary.toCharArray()) {
            if (c == '1') {
                // 在所有好子序列后面加'1'，再加单独的"1"
                ends1 = (ends1 + ends0 + 1) % MOD;
            } else {
                // 在所有好子序列后面加'0'
                ends0 = (ends1 + ends0) % MOD;
                hasZero = true;
            }
        }

        // 加上单独的"0"（如果存在）
        return (int) ((ends1 + ends0 + (hasZero ? 1 : 0)) % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只需维护以 `'1'` 和 `'0'` 结尾的不同好子序列数，每次更新自动去重
2. 单独的 `"0"` 单独处理，在最后加 1
3. 遇到 `'0'` 时不需要加 1，因为单独的 `"0"` 另行统计
