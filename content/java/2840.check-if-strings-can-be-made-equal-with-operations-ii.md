## 题目描述

任意长度字符串，可交换同奇偶下标的字符，判断s1能否变为s2。

## 解题思路

偶数位字符可任意排列，奇数位字符可任意排列。分别比较两组字符频次是否相同。

## Java 代码实现

```java
class Solution {
    public boolean checkStrings(String s1, String s2) {
        int[] even1 = new int[26], even2 = new int[26];
        int[] odd1 = new int[26], odd2 = new int[26];

        for (int i = 0; i < s1.length(); i++) {
            if (i % 2 == 0) {
                even1[s1.charAt(i) - 'a']++;
                even2[s2.charAt(i) - 'a']++;
            } else {
                odd1[s1.charAt(i) - 'a']++;
                odd2[s2.charAt(i) - 'a']++;
            }
        }
        return Arrays.equals(even1, even2) && Arrays.equals(odd1, odd2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **同奇偶位可任意重排**：充分自由度
2. **频次数组比较**：26个字母计数
3. **与2839同理**：只是长度不限
