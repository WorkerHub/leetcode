## 题目描述

给你整数数组 `nums` 和整数 `d`，返回满足 `(nums[i]+nums[j]+nums[k]) % d == 0` 的三元组 `(i,j,k)`（i<j<k）数目。

## 解题思路

枚举中间下标 j，左侧用哈希表存 `nums[i] % d` 的计数，右侧枚举 k，查询需要的余数 `(d - (nums[j]+nums[k])%d) % d`。

## Java 代码实现

```java
class Solution {
    public int divisibleTripletCount(int[] nums, int d) {
        int n = nums.length, ans = 0;

        for (int j = 1; j < n - 1; j++) {
            // 构建左侧余数哈希表
            Map<Integer, Integer> left = new HashMap<>();
            for (int i = 0; i < j; i++) {
                left.merge(nums[i] % d, 1, Integer::sum);
            }
            // 枚举右侧 k
            for (int k = j + 1; k < n; k++) {
                int need = (d - (nums[j] + nums[k]) % d) % d;
                ans += left.getOrDefault(need, 0);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举中间元素 j，左侧哈希表存余数计数
2. 需要的 i 余数 = `(d - (nums[j]+nums[k])%d) % d`
3. `(d - x) % d` 处理 x==0 时正确返回 0
