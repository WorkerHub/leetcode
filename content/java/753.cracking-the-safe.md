## 题目描述

有一个需要密码才能打开的保险箱。密码是 `n` 位数，密码的每一位都是范围 `[0, k-1]` 中的一个数字。

你可以输入任意长度的密码序列，保险箱会自动记住最后 `n` 位输入。

例如，假设密码是 `"345"`，我可以输入 `"012345"` 来打开它，因为保险箱只记得最后 `3` 位数字 `"345"`。

请返回一个能打开保险箱的最短字符串。

**示例 1:**
```
输入：n = 1, k = 2
输出："01" 或 "10"
解释：只有两种可能的密码：
"0" 和 "1"
"01" 和 "10" 都可以打开保险箱。
```

**示例 2:**
```
输入：n = 2, k = 2
输出："00110"
解释：
4 种可能的密码：
"00", "01", "10", "11"
"00110" 可以打开保险箱，因为它包含了所有可能的密码：
"00" (位置 0-1)
"01" (位置 1-2)
"11" (位置 2-3)
"10" (位置 3-4，循环到位置 0)
```

**提示：**
- `1 <= n <= 4`
- `1 <= k <= 10`
- `1 <= k^n <= 4096`

## 解题思路

这道题实际上是要找到一个包含所有可能的 n 位密码的最短字符串，这是一个经典的 **欧拉回路（Eulerian Circuit）** 问题。

**核心思想：**
1. 将问题转化为图论问题
2. 每个 (n-1) 位的数字序列是一个节点
3. 如果在节点 A 后面添加一个数字可以得到节点 B，则 A 到 B 有一条边
4. 遍历所有边恰好一次，就能得到包含所有 n 位密码的序列

**图的构建：**
- 节点：所有可能的 (n-1) 位数字序列，共 k^(n-1) 个
- 边：从节点 A 到节点 B，表示在 A 的末尾添加一个数字后，删除第一位，得到 B
- 每个节点有 k 条出边，k 条入边
- 这是一个欧拉图（所有节点的入度等于出度）

**算法流程（Hierholzer 算法）：**
1. 从起点（通常是全 0）开始
2. 使用 DFS 遍历所有边
3. 将访问的边（代表添加的数字）记录下来
4. 逆序输出结果

## Java 代码实现

### 方法一：欧拉回路（Hierholzer 算法）（推荐）

```java
import java.util.*;

class Solution {
    private Set<String> visited;
    private StringBuilder result;
    private int k;

    public String crackSafe(int n, int k) {
        this.k = k;
        this.visited = new HashSet<>();
        this.result = new StringBuilder();

        if (n == 1) {
            // 特殊情况：只有一位密码
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < k; i++) sb.append(i);
            return sb.toString();
        }

        // 起始节点（n-1 个 0）
        String start = "0".repeat(n - 1);
        dfs(start, n);

        // 添加起始节点
        result.append(start);
        return result.toString();
    }

    private void dfs(String node, int n) {
        // 尝试所有可能的下一个数字
        for (int digit = 0; digit < k; digit++) {
            // 构造边（节点 + 数字）
            String edge = node + digit;
            if (!visited.contains(edge)) {
                visited.add(edge);
                // 下一个节点是当前边的后 n-1 位
                String nextNode = edge.substring(1);
                dfs(nextNode, n);
                // 记录添加的数字
                result.append(digit);
            }
        }
    }
}
```

### 方法二：迭代版本（使用栈）

```java
import java.util.*;

class Solution {
    public String crackSafe(int n, int k) {
        if (n == 1) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < k; i++) sb.append(i);
            return sb.toString();
        }

        String start = "0".repeat(n - 1);
        Set<String> visited = new HashSet<>();
        Deque<String> stack = new ArrayDeque<>();
        List<Integer> resultDigits = new ArrayList<>();

        stack.push(start);
        // 记录每个节点已尝试到哪个数字
        Map<String, Integer> nextDigit = new HashMap<>();

        while (!stack.isEmpty()) {
            String node = stack.peek();
            int digit = nextDigit.getOrDefault(node, 0);

            if (digit < k) {
                nextDigit.put(node, digit + 1);
                String edge = node + digit;
                if (!visited.contains(edge)) {
                    visited.add(edge);
                    String nextNode = edge.substring(1);
                    stack.push(nextNode);
                }
            } else {
                // 所有边都已访问，回溯时记录最后一个字符
                stack.pop();
                if (!stack.isEmpty()) {
                    String prev = stack.peek();
                    // 找到从 prev 到 node 的数字
                    resultDigits.add(node.charAt(node.length() - 1) - '0');
                }
            }
        }

        StringBuilder sb = new StringBuilder(start);
        // 逆序拼接
        for (int i = resultDigits.size() - 1; i >= 0; i--) {
            sb.append(resultDigits.get(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度：** O(k^n)，需要访问所有 k^n 个密码
- **空间复杂度：** O(k^n)，需要存储所有访问过的边和递归栈

## 关键点总结

1. **问题转化：** 将问题转化为寻找欧拉回路
2. **图的性质：** 这是一个欧拉图，所有节点的入度等于出度
3. **Hierholzer 算法：** 用于寻找欧拉回路的经典算法
4. **DFS 顺序：** 后序遍历的逆序就是欧拉回路
5. **边的表示：** 边由节点加一个数字组成

## 易错点

1. **特殊情况：** n=1 时需要特殊处理
2. **节点定义：** 节点是 (n-1) 位序列，不是 n 位
3. **边的构造：** 边由当前节点加一个数字组成
4. **结果顺序：** DFS 的结果需要逆序
5. **起始节点：** 不要忘记在结果末尾添加起始节点
