## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出和为目标值 `target` 的那两个整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

**示例 1：**
```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9，返回 [0, 1]
```

**示例 2：**
```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

**示例 3：**
```
输入：nums = [3,3], target = 6
输出：[0,1]
```

## 解题思路

### 方法一：暴力法（不推荐）
使用双重循环遍历所有可能的组合，时间复杂度为 O(n²)。

### 方法二：哈希表（推荐）
使用哈希表可以将时间复杂度降低到 O(n)。

**核心思想：**
- 遍历数组时，对于每个元素 `nums[i]`，计算 `target - nums[i]`
- 在哈希表中查找是否存在这个差值
- 如果存在，说明找到了答案
- 如果不存在，将当前元素及其索引存入哈希表

**为什么使用哈希表？**
- 哈希表的查找时间复杂度为 O(1)
- 可以边遍历边查找，只需一次遍历

## Java 代码实现

### 方法一：哈希表（一次遍历）（推荐）

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // 创建哈希表，用于存储 {值: 索引}
        Map<Integer, Integer> map = new HashMap<>();
        
        // 遍历数组
        for (int i = 0; i < nums.length; i++) {
            // 计算需要找的另一个数
            int complement = target - nums[i];
            
            // 如果在哈希表中找到了complement
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            
            // 将当前数字和索引存入哈希表
            map.put(nums[i], i);
        }
        
        // 题目保证有解，所以不会执行到这里
        return new int[0];
    }
}
```

### 方法二：暴力法（仅供参考）

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[]{i, j};
                }
            }
        }
        return new int[0];
    }
}
```

## 复杂度分析

### 哈希表方法
- **时间复杂度**：O(n)，只需遍历一次数组
- **空间复杂度**：O(n)，最坏情况下需要存储 n 个元素

### 暴力法
- **时间复杂度**：O(n²)，双重循环
- **空间复杂度**：O(1)

## 关键点总结

1. **哈希表是关键**：将查找时间从 O(n) 降到 O(1)
2. **一次遍历**：边遍历边查找，不需要预先填充哈希表
3. **注意边界**：题目保证有唯一解，不需要处理无解情况
4. **索引不重复**：同一个元素不能使用两次（通过 `i` 和 `j` 的位置关系保证）
