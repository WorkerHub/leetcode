## 题目描述

设计位集Bitset支持fix/unfix/flip/all/one/count/toString操作。

## 解题思路

用数组存储位集+翻转标记（lazy flip），flip()时只切换标记和更新count，fix/unfix根据翻转状态决定实际存储值。

## Java 代码实现

```java
class Bitset {
    private int[] bits;
    private int size;
    private int cnt; // 逻辑上1的个数
    private boolean flipped;
    
    public Bitset(int size) {
        this.size = size;
        this.bits = new int[size];
        this.cnt = 0;
        this.flipped = false;
    }
    
    public void fix(int idx) {
        // 逻辑上设为1
        int target = flipped ? 0 : 1;
        if (bits[idx] != target) {
            bits[idx] = target;
            cnt++;
        }
    }
    
    public void unfix(int idx) {
        // 逻辑上设为0
        int target = flipped ? 1 : 0;
        if (bits[idx] != target) {
            bits[idx] = target;
            cnt--;
        }
    }
    
    public void flip() {
        flipped = !flipped;
        cnt = size - cnt;
    }
    
    public boolean all() {
        return cnt == size;
    }
    
    public boolean one() {
        return cnt > 0;
    }
    
    public int count() {
        return cnt;
    }
    
    public String toString() {
        StringBuilder sb = new StringBuilder(size);
        for (int b : bits) {
            sb.append(flipped ? (1 - b) : b);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：fix/unfix/flip/all/one/count均O(1)，toString O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **翻转标记lazy flip**：flip()从O(N)优化到O(1)
2. **fix/unfix考虑翻转状态**：实际存储值取决于flipped标志
3. **维护cnt**：使all/one/count都是O(1)
