## 题目描述

给定数组 nums 构造 BST，计算有多少种重排方式使 BST 相同。答案对 10^9+7 取模。

**示例：**
```
输入：nums = [2,1,3]
输出：1
```

## 解题思路

递归+组合数学：根固定，左右子树元素集合固定，交错方式数 = C(left+right, left)，递归计算子问题。

## Java 代码实现

```java
class Solution {
    private long MOD = 1_000_000_007;
    private long[][] C;
    
    public int numOfWays(int[] nums) {
        int n = nums.length;
        // 预计算组合数
        C = new long[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            C[i][0] = 1;
            for (int j = 1; j <= i; j++) {
                C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD;
            }
        }
        
        List<Integer> list = new ArrayList<>();
        for (int x : nums) list.add(x);
        
        return (int)((count(list) - 1 + MOD) % MOD);
    }
    
    private long count(List<Integer> arr) {
        if (arr.size() <= 1) return 1;
        int root = arr.get(0);
        List<Integer> left = new ArrayList<>();
        List<Integer> right = new ArrayList<>();
        for (int i = 1; i < arr.size(); i++) {
            if (arr.get(i) < root) left.add(arr.get(i));
            else right.add(arr.get(i));
        }
        long ways = C[left.size() + right.size()][left.size()];
        ways = ways % MOD * count(left) % MOD * count(right) % MOD;
        return ways;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **递归分解**：根固定，左右子树分别递归
2. **组合数**：C(left+right, left) 种交错方式
3. **减一**：最终答案减去原始排列本身
