## 题目描述

将学生分成若干组，要求后一组人数和成绩总和都严格大于前一组，返回最多组数。

## 解题思路

贪心：分成 k 组时组的人数至少为 1+2+...+k = k*(k+1)/2 <= n。只需找最大的 k 满足此条件，将排序后的成绩依次按 1,2,...,k 人分配，人数递增且每人成绩正整数保证总和也递增。

## Java 代码实现

```java
class Solution {
    public int maximumGroups(int[] grades) {
        int n = grades.length;
        // 找最大 k 使得 k*(k+1)/2 <= n
        int k = 1;
        while ((long)(k + 1) * (k + 2) / 2 <= n) k++;
        return k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sqrt(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 关键洞察：满足人数递增条件，成绩总和条件自然满足（排序后分配）。
2. 最大 k 满足三角数不等式 `k*(k+1)/2 <= n`。
3. 也可用数学公式 `k = floor((-1+sqrt(1+8n))/2)` 直接求解。
