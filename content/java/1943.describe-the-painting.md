## 题目描述

给你区间涂色数组 `segments[i] = [l, r, color]`（可重叠，颜色叠加），返回所有非空区间的描述列表 `[l, r, colorSum]`，相邻颜色和相同的区间合并。

## 解题思路

差分 + 离散化：在端点处用差分记录颜色值的加减，排序端点后从左到右扫描累加，收集颜色和 > 0 的区间，合并相邻颜色和相同的段。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<List<Long>> splitPainting(int[][] segments) {
        // 差分：端点处颜色值变化
        TreeMap<Integer, Long> diff = new TreeMap<>();
        for (int[] seg : segments) {
            diff.merge(seg[0], (long) seg[2], Long::sum);
            diff.merge(seg[1], -(long) seg[2], Long::sum);
        }

        List<List<Long>> result = new ArrayList<>();
        long curSum = 0;
        int prevX = -1;
        for (Map.Entry<Integer, Long> e : diff.entrySet()) {
            int x = e.getKey();
            if (curSum > 0 && prevX != -1) {
                // 合并相邻颜色和相同的区间
                if (!result.isEmpty() && result.get(result.size() - 1).get(2) == curSum
                        && result.get(result.size() - 1).get(1) == prevX) {
                    result.get(result.size() - 1).set(1, (long) x);
                } else {
                    result.add(Arrays.asList((long) prevX, (long) x, curSum));
                }
            }
            curSum += e.getValue();
            prevX = x;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 差分处理区间颜色叠加：起点 +color，终点 -color
2. TreeMap 自动排序端点，从左到右扫描累加
3. 合并相邻颜色和相同且连续的区间
