## 题目描述

给你 `m x n` 矩阵 `isWater`（1 为水域，0 为陆地），为每个单元格分配高度：水域为 0，相邻高度差不超过 1，使最大高度最大。返回高度矩阵。

## 解题思路

多源 BFS：将所有水域单元格作为初始源点（高度 0）同时加入队列，BFS 扩展时每层高度加 1，即每个陆地单元格高度等于到最近水域的距离。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[][] highestPeak(int[][] isWater) {
        int m = isWater.length, n = isWater[0].length;
        int[][] height = new int[m][n];
        Deque<int[]> queue = new ArrayDeque<>();

        // 初始化：水域高度为 0，陆地标记为 -1
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (isWater[i][j] == 1) {
                    height[i][j] = 0;
                    queue.offer(new int[]{i, j});
                } else {
                    height[i][j] = -1; // 未访问
                }
            }
        }

        int[] dr = {0, 0, 1, -1};
        int[] dc = {1, -1, 0, 0};

        // 多源 BFS 扩展
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1];
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && height[nr][nc] == -1) {
                    height[nr][nc] = height[r][c] + 1; // 高度 = 到最近水域的距离
                    queue.offer(new int[]{nr, nc});
                }
            }
        }

        return height;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. 多源 BFS：所有水域同时出发，确保每个陆地得到最近水域距离
2. `-1` 标记未访问，避免重复入队
