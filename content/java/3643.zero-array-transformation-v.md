## 题目描述

给定整数数组 `nums` 和查询数组 `queries`（每个查询 `[l, r]` 可将该区间内任意元素各减 1），返回使 `nums` 全部归零所需的最少查询次数，若无法实现返回 -1。

## Java 代码实现

```java
class Solution {
    public int minZeroArray(int[] nums, int[][] queries) {
        int n = nums.length, q = queries.length;

        if (check(nums, queries, 0)) return 0;
        if (!check(nums, queries, q)) return -1;

        // 二分查找最小查询数
        int lo = 1, hi = q;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (check(nums, queries, mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean check(int[] nums, int[][] queries, int k) {
        int n = nums.length;
        int[] diff = new int[n + 1];
        for (int i = 0; i < k; i++) {
            diff[queries[i][0]]++;
            diff[queries[i][1] + 1]--;
        }
        int cover = 0;
        for (int i = 0; i < n; i++) {
            cover += diff[i];
            if (cover < nums[i]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log q)，二分 O(log q) 次，每次验证 O(n + q)
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组快速计算区间覆盖次数，判断每个位置覆盖次数是否 >= nums[i]
2. 二分最小查询数，答案具有单调性（前 k 个可行则前 k+1 个也可行）
3. 先检查边界情况：k=0（已全零）和 k=q（全部查询不够）
