## 题目描述

给你偶数长度整数数组 `nums`，你和朋友轮流各取一个最小值，朋友先放入结果数组，你后放，返回最终数组。

## 解题思路

排序后每两个一组，先放较大的（朋友取），再放较小的（你取）。

## Java 代码实现

```java
class Solution {
    public int[] numberGame(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int[] arr = new int[n];
        for (int i = 0; i < n; i += 2) {
            arr[i] = nums[i + 1];     // 朋友取第二小，先放
            arr[i + 1] = nums[i];     // 你取最小，后放
        }
        return arr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序后每两个连续元素为一组
2. 朋友取较大的（nums[i+1]）先放，你取较小的（nums[i]）后放
3. 放入顺序与取出顺序相反
