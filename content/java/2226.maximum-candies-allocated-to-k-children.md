## 题目描述

将糖果堆分成子堆分配给k个小朋友（不能合并），求每人能得到的最大糖果数。

## 解题思路

二分查找答案：对每人分m颗进行二分，检查所有堆能提供的子堆总数sum(c/m)是否>=k。

## Java 代码实现

```java
class Solution {
    public int maximumCandies(int[] candies, long k) {
        int left = 0, right = 0;
        for (int c : candies) right = Math.max(right, c);
        
        while (left < right) {
            int mid = (left + right + 1) / 2;
            long count = 0;
            for (int c : candies) count += c / mid;
            if (count >= k) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log(max_candy))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：答案具有单调性，m越大越难满足
2. **检查函数**：每堆能提供c/m个子堆，总和>=k则可行
3. **向上取整防死循环**：(left+right+1)/2求最大可行值
