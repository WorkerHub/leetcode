## 题目描述

给定字符串数组 queries 和模式 pattern，判断每个 query 是否能通过在 pattern 中插入小写字母得到（不能有多余大写字母）。

**示例：**
```
输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FB"
输出：[true,false,true,true,false]
```

## 解题思路

双指针：遍历 query，若字符匹配 pattern 当前字符则两个指针前进；若不匹配但是小写字母则跳过；若是大写字母则失败。

## Java 代码实现

```java
class Solution {
    public List<Boolean> camelMatch(String[] queries, String pattern) {
        List<Boolean> result = new ArrayList<>();
        for (String query : queries) {
            result.add(isMatch(query, pattern));
        }
        return result;
    }

    private boolean isMatch(String query, String pattern) {
        int j = 0;
        for (int i = 0; i < query.length(); i++) {
            if (j < pattern.length() && query.charAt(i) == pattern.charAt(j)) {
                j++;
            } else if (Character.isUpperCase(query.charAt(i))) {
                // 多余的大写字母，不匹配
                return false;
            }
        }
        return j == pattern.length();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为 queries 长度，m 为平均 query 长度
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针匹配**：pattern 指针只在匹配时前进
2. **大写字母约束**：query 中多余大写字母直接失败
3. **小写字母可跳过**：不匹配的小写字母视为插入字符
