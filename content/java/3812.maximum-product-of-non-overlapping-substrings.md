## 题目描述

给定字符串 `s`，选择若干个不重叠的子串使所有子串长度之积最大，返回最大乘积（模 `10^9+7`）。

## Java 代码实现

```java
class Solution {
    public int maxProduct(String s) {
        final int MOD = 1_000_000_007;
        int n = s.length();
        // dp[i][j] = s[i..j] 范围内不重叠子串的最大长度乘积
        long[][] dp = new long[n][n];

        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp[i][j] = len; // 选整个 [i,j] 作为一个子串
                // 枚举分割点
                for (int k = i; k < j; k++) {
                    dp[i][j] = Math.max(dp[i][j], dp[i][k] * dp[k + 1][j]);
                }
            }
        }
        return (int) (dp[0][n - 1] % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)
- 空间复杂度：O(n^2)

## 关键点总结

1. 区间 DP：dp[i][j] 表示范围 [i,j] 内的最大长度乘积
2. 选整个区间时贡献为区间长度，分割时取两部分乘积的最大值
3. 比较时不取模（避免影响大小关系），最终返回时取模
