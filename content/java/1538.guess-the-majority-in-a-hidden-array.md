## 题目描述

交互题：隐藏数组只含 1 和 -1，有严格多数元素。可用 query(a,b,c,d) 查询四元素乘积。用最多 4n 次查询找出多数元素的任意下标。

## 解题思路

以 query(0,1,2,3) 为基准，对 i≥4 比较 query(0,1,2,i) 与基准判断 arr[i] 是否与 arr[3] 相同。前 3 个下标用额外查询推断。

## Java 代码实现

```java
class Solution {
    public int guessMajority(ArrayReader reader) {
        int n = reader.length();
        int base = reader.query(0, 1, 2, 3);
        
        // 统计与 arr[3] 相同/不同的数量
        int sameCount = 1; // arr[3] 本身
        int diffCount = 0;
        int diffIdx = -1; // 记录一个不同的下标
        
        // 处理 i >= 4
        for (int i = 4; i < n; i++) {
            if (reader.query(0, 1, 2, i) == base) {
                sameCount++;
            } else {
                diffCount++;
                diffIdx = i;
            }
        }
        
        // 处理 i=0: 比较 query(1,2,3,4) 与 query(0,2,3,4)
        // arr[0]==arr[1] iff query(0,2,3,4)==query(1,2,3,4)
        int q0 = reader.query(1, 2, 3, 4);
        // base * q0 = arr[0]*arr[4], 若==1则arr[0]==arr[4]
        if (base * q0 == 1) {
            // arr[0] 与 arr[4] 相同
            // arr[4] 与 arr[3] 的关系已知
            if (reader.query(0, 1, 2, 4) == base) sameCount++;
            else diffCount++;
        } else {
            if (reader.query(0, 1, 2, 4) == base) diffCount++;
            else sameCount++;
        }
        
        // 处理 i=1
        int q1 = reader.query(0, 2, 3, 4);
        if (base * q1 == 1) {
            if (reader.query(0, 1, 2, 4) == base) sameCount++;
            else diffCount++;
        } else {
            if (reader.query(0, 1, 2, 4) == base) diffCount++;
            else sameCount++;
        }
        
        // 处理 i=2
        int q2 = reader.query(0, 1, 3, 4);
        if (base * q2 == 1) {
            if (reader.query(0, 1, 2, 4) == base) sameCount++;
            else diffCount++;
        } else {
            if (reader.query(0, 1, 2, 4) == base) diffCount++;
            else sameCount++;
        }
        
        // 多数在 same 组则返回 3，否则返回 diff 组的任意下标
        if (sameCount >= diffCount) return 3;
        return diffIdx;
    }
}
```

## 复杂度分析

- **查询次数**：O(n)
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **基准比较**：query(0,1,2,i) 与 base 相等则 arr[i]==arr[3]
2. **乘积性质**：base × query(1,2,3,4) = arr[0]×arr[4]
3. **分组计数**：最终多数组的任意下标即为答案
