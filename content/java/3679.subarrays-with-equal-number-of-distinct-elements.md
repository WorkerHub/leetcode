## 题目描述

给你一个整数数组 `nums`，返回满足以下条件的子数组数量：子数组中不同元素的个数等于整个数组中不同元素的个数。

## 解题思路

含恰好 k 种不同元素的子数组数 = 至多 k 种 - 至多 k-1 种（滑动窗口标准技巧）。k 为整个数组的不同元素数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countSubarrays(int[] nums) {
        int target = (int) Arrays.stream(nums).distinct().count();
        return atMost(nums, target) - atMost(nums, target - 1);
    }

    private long atMost(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        long count = 0;
        int left = 0, distinct = 0;
        for (int right = 0; right < nums.length; right++) {
            freq.merge(nums[right], 1, Integer::sum);
            if (freq.get(nums[right]) == 1) distinct++;
            while (distinct > k) {
                freq.merge(nums[left], -1, Integer::sum);
                if (freq.get(nums[left]) == 0) { freq.remove(nums[left]); distinct--; }
                left++;
            }
            // 以right为右端点的合法子数组数
            count += right - left + 1;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 含恰好 k 种 = 至多 k 种 - 至多 k-1 种（固定套路）
2. 至多 k 种时，每次右端点右移，统计以 right 结尾的合法子数组数
3. k = 整个数组的不同元素数
