## 题目描述

给你二进制数组 `nums`，好子数组恰好包含一个 1，返回将 `nums` 分割成若干好子数组的方案数（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
class Solution {
    public int numberOfGoodSubarraySplits(int[] nums) {
        final int MOD = 1_000_000_007;
        // 若没有 1，无法分割
        int prevOne = -1;
        long ans = 1;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) {
                if (prevOne != -1) {
                    // 相邻两个 1 之间的间距即为切割点数
                    ans = ans * (i - prevOne) % MOD;
                }
                prevOne = i;
            }
        }
        return prevOne == -1 ? 0 : (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 好的分割必须保证每段恰好有一个 1
2. 相邻两个 1 之间的 0 串可以任意分割，有 `gap` 种方式（`gap = pos[i+1] - pos[i]`）
3. 各段独立，方案数相乘
