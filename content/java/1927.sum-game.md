## 题目描述

Alice 和 Bob 轮流替换字符串 `num` 中的 `'?'`，Alice 希望前后半部分和不等，Bob 希望相等，双方最优策略，Alice 赢则返回 `true`。

## 解题思路

数学分析：Bob 赢的充要条件为 `2*(sl - sr) == 9*(qr - ql)`（其中 sl/sr 为前后半数字和，ql/qr 为前后半问号数），Alice 赢当且仅当此等式不成立。

## Java 代码实现

```java
class Solution {
    public boolean sumGame(String num) {
        int n = num.length(), half = n / 2;
        int sumLeft = 0, qLeft = 0, sumRight = 0, qRight = 0;

        for (int i = 0; i < half; i++) {
            if (num.charAt(i) == '?') qLeft++;
            else sumLeft += num.charAt(i) - '0';
        }
        for (int i = half; i < n; i++) {
            if (num.charAt(i) == '?') qRight++;
            else sumRight += num.charAt(i) - '0';
        }

        // Bob 赢的条件：2*(sumLeft - sumRight) == 9*(qRight - qLeft)
        return 2 * (sumLeft - sumRight) != 9 * (qRight - qLeft);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. Bob 赢充要条件：每对 `(前?, 后?)` 可用 `(x, 9-x)` 填充，和差为 9
2. 用整数等式 `2*(sl-sr) == 9*(qr-ql)` 避免浮点误差
3. 问号数量差为奇数时 Alice 必赢
