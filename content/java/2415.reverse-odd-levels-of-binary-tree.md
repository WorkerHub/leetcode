## 题目描述

给你完美二叉树的根节点 `root`，反转奇数层（1, 3, 5, ...）的节点值，返回根节点。

## 解题思路

DFS：利用完美二叉树的对称性，同时传入镜像对称的两个节点。在奇数层交换两节点的值，偶数层直接递归子节点（注意子节点交叉传递以保持对称）。

## Java 代码实现

```java
class Solution {
    public TreeNode reverseOddLevels(TreeNode root) {
        dfs(root.left, root.right, true);
        return root;
    }

    private void dfs(TreeNode left, TreeNode right, boolean isOdd) {
        if (left == null) return;
        if (isOdd) {
            // 奇数层：交换对称节点的值
            int tmp = left.val;
            left.val = right.val;
            right.val = tmp;
        }
        // 递归：镜像对称地传递子节点
        dfs(left.left, right.right, !isOdd);
        dfs(left.right, right.left, !isOdd);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(log n)（递归栈深度）

## 关键点总结

1. 只需交换节点值，不改变树结构。
2. DFS 利用完美二叉树对称性，同时处理镜像对称的两个节点。
3. 递归子节点时交叉传递：`left.right` 对应 `right.left`（镜像对应关系）。
