## 题目描述

给你两个等长字符串 `s` 和 `t` 以及整数 `k`，每次可以将 `s` 中某字符替换为字母表中前一个或后一个字母（循环：'z'->'a', 'a'->'z'），每个字符最多操作 k 次，判断能否将 `s` 变为 `t`。

## Java 代码实现

```java
class Solution {
    public boolean checkFeasibility(String s, String t, int k) {
        // 逐字符检查循环最短距离是否在 k 步以内
        for (int i = 0; i < s.length(); i++) {
            int dist = Math.abs(s.charAt(i) - t.charAt(i));
            // 循环最短距离：顺时针或逆时针取较小值
            int minDist = Math.min(dist, 26 - dist);
            if (minDist > k) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个字符可以通过循环路径变成任意字符，最短路径为 `min(dist, 26 - dist)`。
2. 若无操作次数限制，答案总为 true（长度相同时）。
3. 有限制时，逐字符检查是否在 k 步内。
