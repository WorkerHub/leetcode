## 题目描述

给你整数数组 `nums`，返回使其成为**山形数组**（存在峰值，两侧严格递增/递减）所需删除的最少元素个数。

## 解题思路

问题转化：找最长山形子序列，最少删除 = n - 最长山形长度。

计算 `lis[i]`（以 i 结尾的最长严格递增子序列）和 `lds[i]`（以 i 开头的最长严格递减子序列），以 i 为峰值的山形长度 = `lis[i] + lds[i] - 1`（峰值不能在首尾）。

## Java 代码实现

```java
class Solution {
    public int minimumMountainRemovals(int[] nums) {
        int n = nums.length;
        int[] lis = lisLengths(nums, false);
        int[] lds = lisLengths(nums, true);

        int maxMountain = 0;
        for (int i = 1; i < n - 1; i++) {
            if (lis[i] > 1 && lds[i] > 1) {
                maxMountain = Math.max(maxMountain, lis[i] + lds[i] - 1);
            }
        }
        return n - maxMountain;
    }

    // 计算每个位置的严格递增子序列长度（reverse=true 时从右到左计算）
    private int[] lisLengths(int[] nums, boolean reverse) {
        int n = nums.length;
        int[] arr = reverse ? reverseArray(nums) : nums;
        int[] dp = new int[0];
        int[] result = new int[n];

        for (int i = 0; i < n; i++) {
            int pos = lowerBound(dp, arr[i]);
            result[i] = pos + 1;
            if (pos == dp.length) {
                dp = Arrays.copyOf(dp, dp.length + 1);
            }
            dp[pos] = arr[i];
        }

        if (reverse) {
            // 反转结果
            for (int i = 0, j = n - 1; i < j; i++, j--) {
                int tmp = result[i]; result[i] = result[j]; result[j] = tmp;
            }
        }
        return result;
    }

    private int[] reverseArray(int[] arr) {
        int n = arr.length;
        int[] rev = new int[n];
        for (int i = 0; i < n; i++) rev[i] = arr[n - 1 - i];
        return rev;
    }

    // 二分查找第一个 >= target 的位置（严格递增用 lower_bound）
    private int lowerBound(int[] dp, int target) {
        int lo = 0, hi = dp.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (dp[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. `lis[i] + lds[i] - 1` 为以 i 为峰值的最长山形长度
2. 峰值不能在首尾（`lis[i] > 1` 且 `lds[i] > 1`）
3. `lds` = 反转数组后的 LIS（再反转结果）
