## 题目描述

给定两个等长整数数组 `source` 和 `target`，每次可将 `source` 中某个元素加 1 或减 1（代价为 1），返回将 `source` 变为 `target` 的最少操作次数。

## 解题思路

每个位置相互独立，最优策略是将每个元素直接移动到目标值，总代价为各位置绝对差之和。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] source, int[] target) {
        // 每个位置独立，最优策略是直接移动到目标值
        int total = 0;
        for (int i = 0; i < source.length; i++) {
            total += Math.abs(source[i] - target[i]);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最基础版本：独立移动，答案为 `sum(|source[i] - target[i]|)`。
2. BFS 版本：在值域图上进行最短路搜索（加减 1 的代价为 1，跳转代价也为 1）。
3. 哈希表记录已访问值，避免重复访问。
