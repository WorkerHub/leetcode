## 题目描述

给定比赛结果matches[i]=[winner,loser]，返回从未输过和恰好输一场的玩家列表（升序）。

## 解题思路

哈希表统计每个玩家的败场数，胜者也需记录(败场为0)。最后按败场数分类并排序。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findWinners(int[][] matches) {
        Map<Integer, Integer> lossCount = new HashMap<>();
        
        for (int[] m : matches) {
            lossCount.putIfAbsent(m[0], 0); // 确保胜者被记录
            lossCount.merge(m[1], 1, Integer::sum);
        }
        
        List<Integer> noLoss = new ArrayList<>();
        List<Integer> oneLoss = new ArrayList<>();
        
        for (Map.Entry<Integer, Integer> e : lossCount.entrySet()) {
            if (e.getValue() == 0) noLoss.add(e.getKey());
            else if (e.getValue() == 1) oneLoss.add(e.getKey());
        }
        
        Collections.sort(noLoss);
        Collections.sort(oneLoss);
        return Arrays.asList(noLoss, oneLoss);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)，排序主导
- **空间复杂度**：O(N)

## 关键点总结

1. **胜者也要记录**：putIfAbsent确保只赢不输的也在map中
2. **merge方法**：简洁地对败者计数+1
3. **最后排序输出**：结果按升序
