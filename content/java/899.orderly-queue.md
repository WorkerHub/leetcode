## 题目描述

给定字符串 s 和整数 k，每次可以将前 k 个字符中的一个移到末尾。返回经过任意次操作后能得到的字典序最小字符串。

**示例：**
```
输入：s = "cba", k = 1
输出："acb"
```

## 解题思路

数学结论：k=1 只能旋转，找最小旋转；k≥2 可以实现任意排列（等价于冒泡排序），直接排序。

## Java 代码实现

```java
class Solution {
    public String orderlyQueue(String s, int k) {
        if (k == 1) {
            // 只能旋转，找最小旋转
            String min = s;
            for (int i = 1; i < s.length(); i++) {
                String rotated = s.substring(i) + s.substring(0, i);
                if (rotated.compareTo(min) < 0) {
                    min = rotated;
                }
            }
            return min;
        } else {
            // k >= 2 可以完全排序
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            return new String(chars);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²) for k=1，O(n log n) for k≥2
- **空间复杂度**：O(n)

## 关键点总结

1. **k=1 特殊**：只能做旋转操作
2. **k≥2 排序**：可以实现任意相邻交换
3. **数学证明**：k≥2 等价于冒泡排序能力
