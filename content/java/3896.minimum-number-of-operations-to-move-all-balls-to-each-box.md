## 题目描述

给定二进制字符串 `boxes`（'1' 表示有球），返回数组 `answer`，`answer[i]` 为将所有球移到第 i 个箱子所需的最少操作数（每次将一个球移动一步）。

## 解题思路

前缀和双扫描：从左到右维护左侧球数和累计代价，从右到左维护右侧球数和累计代价，两次扫描结果相加即为每个位置的答案。

## Java 代码实现

```java
class Solution {
    public int[] minOperations(String boxes) {
        int n = boxes.length();
        int[] ans = new int[n];

        // 从左到右：统计每个位置的左侧贡献
        int balls = 0, cost = 0;
        for (int i = 0; i < n; i++) {
            ans[i] += cost;
            if (boxes.charAt(i) == '1') balls++;
            cost += balls; // 每个左侧球向右多走 1 步
        }

        // 从右到左：统计每个位置的右侧贡献
        balls = 0;
        cost = 0;
        for (int i = n - 1; i >= 0; i--) {
            ans[i] += cost;
            if (boxes.charAt(i) == '1') balls++;
            cost += balls; // 每个右侧球向左多走 1 步
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. 前缀和扫描两遍：左扫贡献所有左侧球，右扫贡献所有右侧球。
2. 向右移动时，每多走 1 步，所有左侧球各多贡献 1（总贡献 += 球数）。
3. 这是 LeetCode 1769（相同思路）的变体。
