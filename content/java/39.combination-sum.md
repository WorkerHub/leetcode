## 题目描述

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的所有 **不同组合**，并返回这些组合的列表。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取**。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 150 个。

**示例 1：**
```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
```

**示例 2：**
```
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

**示例 3：**
```
输入：candidates = [2], target = 1
输出：[]
```

## 解题思路

### 核心思想：回溯算法

这是一道典型的回溯问题，需要找出所有满足条件的组合。

**关键点：**
1. 每个数字可以重复使用
2. 需要去重（例如 `[2,3]` 和 `[3,2]` 是同一个组合）
3. 要找出所有组合，不是排列

**去重方法：**
- 每次递归从当前索引开始，而不是从 0 开始
- 这样保证组合是有序的，避免重复

**算法流程：**
1. 定义回溯函数 `backtrack(start, path, remain)`
2. 如果 `remain == 0`，将当前组合加入结果
3. 如果 `remain < 0`，剪枝返回
4. 从 `start` 开始遍历候选数字，递归尝试

## Java 代码实现

### 方法一：回溯（标准解法）

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        backtrack(candidates, 0, new ArrayList<>(), target);
        return result;
    }
    
    private void backtrack(int[] candidates, int start, List<Integer> path, int remain) {
        // 找到一个解
        if (remain == 0) {
            result.add(new ArrayList<>(path));  // 注意要复制
            return;
        }
        
        // 从start开始，避免重复组合
        for (int i = start; i < candidates.length; i++) {
            // 剪枝：如果已经超过remain，不再继续
            if (candidates[i] > remain) continue;
            
            // 选择当前数字
            path.add(candidates[i]);
            // 递归，注意仍从i开始（可以重复使用）
            backtrack(candidates, i, path, remain - candidates[i]);
            // 回溯
            path.remove(path.size() - 1);
        }
    }
}
```

### 方法二：排序 + 剪枝优化

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        // 排序后可以提前剪枝
        Arrays.sort(candidates);
        backtrack(candidates, 0, new ArrayList<>(), target);
        return result;
    }
    
    private void backtrack(int[] candidates, int start, List<Integer> path, int remain) {
        if (remain == 0) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        for (int i = start; i < candidates.length; i++) {
            // 剪枝：排序后，如果当前数字已经大于剩余值，后面更大的数字也不用试了
            if (candidates[i] > remain) break;
            
            path.add(candidates[i]);
            backtrack(candidates, i, path, remain - candidates[i]);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(S)，S 是所有可行解的长度之和
  - 最坏情况下，候选数字都是 1，需要 target 个 1
  - 组合数为 2^target

- **空间复杂度**：O(target)，递归深度最多为 target

## 关键点总结

1. **避免重复组合**：
   - 递归时从 `start` 开始，不是从 0
   - 保证组合的顺序性

2. **允许重复使用**：
   - 递归时传入 `i`，不是 `i+1`
   - 同一个数字可以多次使用

3. **剪枝优化**：
   - `remain < 0` 时直接返回
   - 排序后，如果当前数字已超过剩余值，后面的更大数字都不用试

4. **路径复制**：
   - `result.add(new ArrayList<>(path))` 而不是 `result.add(path)`
   - 否则会被后续回溯修改

## 易错点

1. **重复组合**：
   - 错误：`backtrack(0, path, remain)`：会产生重复
   - 正确：`backtrack(i, path, remain)`：从当前位置开始

2. **路径复制**：
   - 错误：`result.add(path)`：引用，会被修改
   - 正确：`result.add(new ArrayList<>(path))`：复制，保持不变

3. **递归参数**：
   - 允许重复：`backtrack(i, ...)`
   - 不允许重复：`backtrack(i+1, ...)`

4. **Java 列表删除**：
   - `path.remove(path.size() - 1)` 删除最后一个元素（按索引删除）
   - 不要用 `path.remove(candidates[i])` 会按值删除
