## 题目描述

判断能否将整数数组分成 k 个非空子集，使每个子集的和相等。

**示例：**
```
输入：nums = [4,3,2,3,5,2,1], k = 4
输出：true（[5],[1,4],[2,3],[2,3]）
```

## 解题思路

回溯：先判断总和能否整除 k，降序排列后用 used 数组标记，逐个填充每个桶到 target。

## Java 代码实现

```java
class Solution {
    public boolean canPartitionKSubsets(int[] nums, int k) {
        int sum = 0;
        for (int num : nums) sum += num;
        if (sum % k != 0) return false;

        int target = sum / k;
        Arrays.sort(nums);
        if (nums[nums.length - 1] > target) return false;

        boolean[] used = new boolean[nums.length];
        return backtrack(nums, used, k, 0, target, nums.length - 1);
    }

    private boolean backtrack(int[] nums, boolean[] used, int k, int curSum, int target, int start) {
        if (k == 0) return true;
        if (curSum == target) {
            return backtrack(nums, used, k - 1, 0, target, nums.length - 1);
        }

        for (int i = start; i >= 0; i--) {
            if (used[i] || curSum + nums[i] > target) continue;

            used[i] = true;
            if (backtrack(nums, used, k, curSum + nums[i], target, i - 1)) {
                return true;
            }
            used[i] = false;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × 2^n)
- **空间复杂度**：O(n)

## 关键点总结

1. **前置判断**：总和不整除 k 直接返回 false
2. **降序排列**：大数优先尝试加快剪枝
3. **桶填充**：一个桶满后开始填下一个
