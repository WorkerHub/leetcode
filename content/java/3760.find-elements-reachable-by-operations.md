## 题目描述

给定整数数组 `nums` 和整数 `k`，对每个元素可以反复执行 `x | k` 或 `x & k` 操作，统计所有元素经过若干次操作后可达的不同值的总数量。

## 解题思路

对每个元素用 BFS 枚举所有可达值（通过 OR 和 AND 操作），将结果加入全局集合，最终返回集合大小。由于位运算操作集合收敛快，每个元素的可达值集合有限。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countReachable(int[] nums, int k) {
        Set<Integer> reachable = new HashSet<>();

        for (int x : nums) {
            Set<Integer> visited = new HashSet<>();
            Deque<Integer> queue = new ArrayDeque<>();
            queue.offer(x);
            visited.add(x);

            while (!queue.isEmpty()) {
                int val = queue.poll();
                reachable.add(val);
                // 枚举两种操作
                for (int next : new int[]{val | k, val & k}) {
                    if (visited.add(next)) {
                        queue.offer(next);
                    }
                }
            }
        }

        return reachable.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × S)，S 为每个元素的可达值集合大小（通常很小）
- 空间复杂度：O(n × S)

## 关键点总结

1. 位运算操作的可达值集合收敛快：OR 增位、AND 减位，交替后不会无限增长
2. BFS 从每个起始值出发枚举所有可达值
3. 全局 Set 统计不重复的可达值总数
