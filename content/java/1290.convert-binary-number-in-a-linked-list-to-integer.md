## 题目描述

单链表每个节点值为 0 或 1，表示二进制数。返回该链表表示的十进制值。

**示例：**
```
输入：head = [1,0,1]
输出：5
```

## 解题思路

遍历链表，逐位左移累加：result = result * 2 + node.val。

## Java 代码实现

```java
class Solution {
    public int getDecimalValue(ListNode head) {
        int result = 0;
        while (head != null) {
            result = result * 2 + head.val;
            head = head.next;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **位运算等价**：result * 2 等价于 result << 1
2. **从高位到低位**：链表头是最高位
3. **逐步累加**：每次左移一位再加当前值
