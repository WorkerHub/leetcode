## 题目描述

给定数组nums和初始值original，若original在nums中则翻倍，重复直到找不到为止，返回最终值。

## 解题思路

将nums存入HashSet，循环查找original并翻倍直到不存在。

## Java 代码实现

```java
class Solution {
    public int findFinalValue(int[] nums, int original) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);
        
        while (set.contains(original)) {
            original *= 2;
        }
        return original;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + log(max))
- **空间复杂度**：O(N)

## 关键点总结

1. **HashSet O(1)查找**：每次判断original是否存在
2. **循环次数有限**：最多log2(max)次翻倍
3. **简洁实现**：while循环直到找不到
