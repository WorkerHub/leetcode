## 题目描述

每次删除word前k个字符并在末尾添加k个任意字符，求恢复到初始状态的最少操作次数。（word.length<=50）

## 解题思路

操作t次后恢复条件：word[t*k:]是word的前缀。直接字符串比较即可。

## Java 代码实现

```java
class Solution {
    public int minimumTimeToInitialState(String word, int k) {
        int n = word.length();
        for (int t = 1; t <= (n + k - 1) / k; t++) {
            int start = t * k;
            if (start >= n) return t;
            // 检查word[start:]是否是word的前缀
            if (word.startsWith(word.substring(start))) {
                return t;
            }
        }
        return (n + k - 1) / k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2/K)
- **空间复杂度**：O(N)

## 关键点总结

1. **恢复条件**：word[t*k:]等于word的前缀
2. **start>=n时全部被替换**：可任意构造
3. **数据范围小可直接比较**
