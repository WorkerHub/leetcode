## 题目描述

Alice从左、Bob从右同时给植物浇水，水量不足时需装满（计数+1）。相遇时水量大的人浇，相同则Alice浇。求装满次数。

## 解题思路

双指针模拟：左右指针向中间靠拢，各自检查水量是否足够，不足则装满。相遇时特殊处理。

## Java 代码实现

```java
class Solution {
    public int minimumRefill(int[] plants, int capacityA, int capacityB) {
        int n = plants.length;
        int l = 0, r = n - 1;
        int wa = capacityA, wb = capacityB;
        int refills = 0;
        
        while (l < r) {
            // Alice浇plants[l]
            if (wa < plants[l]) {
                wa = capacityA;
                refills++;
            }
            wa -= plants[l];
            l++;
            
            // Bob浇plants[r]
            if (wb < plants[r]) {
                wb = capacityB;
                refills++;
            }
            wb -= plants[r];
            r--;
        }
        
        // 相遇时选水量大的人浇
        if (l == r) {
            if (wa >= wb) {
                if (wa < plants[l]) refills++;
            } else {
                if (wb < plants[l]) refills++;
            }
        }
        
        return refills;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针模拟**：左右分别模拟Alice和Bob
2. **相遇处理**：比较当前水量决定谁浇
3. **装满计数**：水量不足时先装满再浇
