## 题目描述

如果一个正整数每一位数字都不同，则称为特殊整数。给你正整数 `n`，返回 `[1, n]` 内特殊整数的数目。

## 解题思路

数位 DP：从高位到低位逐位填写，用位掩码 `mask` 记录已用数字集合，`tight` 标记是否受上界约束，`started` 标记是否已填写非零数字。对所有合法的（未重复数字）填法计数。

## Java 代码实现

```java
class Solution {
    private char[] digits;
    private int[][][] memo; // [pos][mask] 只在 tight=false、started=true 时缓存

    public int countSpecialNumbers(int n) {
        digits = Integer.toString(n).toCharArray();
        int len = digits.length;
        // memo[pos][mask]: pos 位、掩码为 mask 时 tight=false & started=true 的计数
        memo = new int[len][1 << 10];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dp(0, 0, true, false);
    }

    private int dp(int pos, int mask, boolean tight, boolean started) {
        if (pos == digits.length) return started ? 1 : 0;
        if (!tight && started && memo[pos][mask] != -1) return memo[pos][mask];

        int limit = tight ? (digits[pos] - '0') : 9;
        int result = 0;
        for (int d = 0; d <= limit; d++) {
            if (d == 0 && !started) {
                // 前导零，不标记为已开始
                result += dp(pos + 1, mask, tight && d == limit, false);
            } else if (((mask >> d) & 1) == 1) {
                continue; // 数字已使用
            } else {
                result += dp(pos + 1, mask | (1 << d), tight && d == limit, true);
            }
        }
        if (!tight && started) memo[pos][mask] = result;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10 * 2^10 * len)，len 最多 10
- **空间复杂度**：O(2^10 * len)

## 关键点总结

1. 位掩码 `mask` 记录已使用的 10 个数字，最多 2^10=1024 种状态。
2. 前导零处理：`started=false` 时填 0 不计入掩码，也不算已开始。
3. 只在 `tight=false && started=true` 时缓存，其余情况直接计算。
