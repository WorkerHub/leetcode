## 题目描述

有根树添加一条额外边，找到并返回该边。三种情况：节点有两个父节点、形成环、两者兼有。

**示例：**
```
输入：edges = [[1,2],[1,3],[2,3]]
输出：[2,3]
```

## 解题思路

先找是否有节点有两个父节点（入度为2），再用并查集检测环。分情况处理：无双父则找环边，有双父则尝试删除后一条候选边看是否还有环。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public int[] findRedundantDirectedConnection(int[][] edges) {
        int n = edges.length;
        int[] inDegree = new int[n + 1];
        int[] candidate1 = null, candidate2 = null;

        // 找入度为2的节点
        for (int[] edge : edges) {
            inDegree[edge[1]]++;
            if (inDegree[edge[1]] == 2) {
                // 找到两条边指向同一节点
                candidate2 = edge;
                for (int[] e : edges) {
                    if (e[1] == edge[1] && e != edge) {
                        candidate1 = e;
                        break;
                    }
                }
            }
        }

        parent = new int[n + 1];
        for (int i = 1; i <= n; i++) parent[i] = i;

        if (candidate2 == null) {
            // 没有入度为2的节点，找环
            for (int[] edge : edges) {
                if (!union(edge[0], edge[1])) return edge;
            }
        } else {
            // 尝试删除 candidate2
            for (int[] edge : edges) {
                if (edge == candidate2) continue;
                if (!union(edge[0], edge[1])) return candidate1;
            }
            return candidate2;
        }
        return new int[0];
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private boolean union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return false;
        parent[rootX] = rootY;
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × α(n))
- **空间复杂度**：O(n)

## 关键点总结

1. **三种情况**：双父无环、有环无双父、双父且有环
2. **候选边**：找到入度为2的节点的两条入边
3. **验证策略**：删除后一条候选边，若仍有环则返回前一条
