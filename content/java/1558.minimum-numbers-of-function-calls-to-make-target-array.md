## 题目描述

初始全 0 数组，每次可选一个元素+1 或所有元素×2，求将数组变为 nums 的最少操作次数。

**示例：**
```
输入：nums = [1,5]
输出：5
```

## 解题思路

位运算分析：+1 次数 = 所有数 popcount 之和，×2 次数 = 最大数的最高位位置。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int addOps = 0;
        int maxBits = 0;
        for (int x : nums) {
            addOps += Integer.bitCount(x);
            maxBits = Math.max(maxBits, 32 - Integer.numberOfLeadingZeros(x));
        }
        // ×2 次数 = 最大数的位长 - 1
        int mulOps = maxBits > 0 ? maxBits - 1 : 0;
        return addOps + mulOps;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **+1 操作**：每个数二进制中 1 的个数之和
2. **×2 操作**：全局操作，次数由最大数的最高位决定
3. **位运算**：Integer.bitCount() 和 numberOfLeadingZeros()
