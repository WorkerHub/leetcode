## 题目描述

字符串被按行存入 rows×cols 矩阵后按对角线读出得到 encodedText，给定 encodedText 和 rows，还原原始字符串（去掉末尾空格）。

## 解题思路

计算 `cols = len / rows`，枚举每条对角线的起始列，按 `(r, c)` → `(r+1, c+1)` 方向读字符，索引为 `r*cols + c`，最后去掉末尾空格。

## Java 代码实现

### 方法一：索引计算（推荐）

```java
class Solution {
    public String decodeCiphertext(String encodedText, int rows) {
        if (rows == 1) return encodedText.stripTrailing();
        int cols = encodedText.length() / rows;
        StringBuilder sb = new StringBuilder();

        for (int startCol = 0; startCol < cols; startCol++) {
            int r = 0, c = startCol;
            while (r < rows && c < cols) {
                sb.append(encodedText.charAt(r * cols + c));
                r++; c++;
            }
        }
        // 去掉末尾空格
        int end = sb.length();
        while (end > 0 && sb.charAt(end - 1) == ' ') end--;
        return sb.substring(0, end);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 矩阵位置 `(r, c)` 对应 encodedText 索引 `r*cols + c`
2. 枚举每条对角线起始列，沿 (r+1, c+1) 方向读取
3. 末尾空格须去掉
