## 题目描述

给定括号字符串s和locked字符串，locked[i]='0'时可改变s[i]。判断能否使s变成有效括号字符串。

## 解题思路

贪心区间法：维护未匹配左括号数量的范围[lo,hi]。可变位置同时扩展两端。hi<0时不合法，最终lo==0合法。

## Java 代码实现

```java
class Solution {
    public boolean canBeValid(String s, String locked) {
        int n = s.length();
        if (n % 2 == 1) return false;
        
        int lo = 0, hi = 0;
        for (int i = 0; i < n; i++) {
            if (locked.charAt(i) == '0') {
                lo--;
                hi++;
            } else if (s.charAt(i) == '(') {
                lo++;
                hi++;
            } else {
                lo--;
                hi--;
            }
            if (hi < 0) return false;
            lo = Math.max(lo, 0);
        }
        return lo == 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **奇数长度直接返回false**：有效括号串长度必为偶数
2. **lo/hi区间维护**：跟踪未匹配左括号的最小和最大可能数量
3. **lo取max(lo,0)**：可变位置可以补充左括号
