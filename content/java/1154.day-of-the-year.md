## 题目描述

给定格式为 "DD-Mon-YYYY" 的日期字符串，返回该日期是当年的第几天。

**示例：**
```
输入：date = "05-May-1977"
输出：125
```

## 解题思路

解析日期字符串，根据月份累加天数，注意闰年 2 月为 29 天。

## Java 代码实现

```java
class Solution {
    public int dayOfYear(String date) {
        String[] parts = date.split("-");
        int day = Integer.parseInt(parts[0]);
        String monthStr = parts[1];
        int year = Integer.parseInt(parts[2]);

        // 月份映射
        String[] months = {"Jan","Feb","Mar","Apr","May","Jun",
                           "Jul","Aug","Sep","Oct","Nov","Dec"};
        int month = 0;
        for (int i = 0; i < 12; i++) {
            if (months[i].equals(monthStr)) {
                month = i + 1;
                break;
            }
        }

        // 每月天数（平年）
        int[] daysInMonth = {31,28,31,30,31,30,31,31,30,31,30,31};

        // 闰年判断
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
            daysInMonth[1] = 29;
        }

        // 累加前面月份天数
        int result = day;
        for (int i = 0; i < month - 1; i++) {
            result += daysInMonth[i];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **闰年判断**：能被 400 整除，或能被 4 整除且不能被 100 整除
2. **月份天数表**：[31,28,31,30,31,30,31,31,30,31,30,31]
3. **累加计算**：前面所有月份天数 + 当前天数
4. **字符串解析**：split("-") 分割
