## 题目描述

请你编写一个程序来计算两个日期之间隔了多少天。

日期以字符串形式给出，格式为 `YYYY-MM-DD`，如下面的例子所示。

**示例 1：**
```
输入：date1 = "2019-06-29", date2 = "2019-06-30"
输出：1
```

**示例 2：**
```
输入：date1 = "2020-01-15", date2 = "2019-12-31"
输出：15
```

**提示：**
- 给定的日期是 `1971` 年到 `2100` 年之间的有效日期。

## 解题思路

计算两个日期之间的天数差，有两种主要思路：

1. **手动计算**：将每个日期转换为从某个基准日（如 1971-01-01）起的天数，两者之差的绝对值即为答案。需要自己处理：
   - 每月的天数（28/29/30/31）
   - 闰年判断（能被 4 整除且不能被 100 整除，或能被 400 整除）
   - 累计到某年某月某日的总天数

2. **使用 LocalDate（Java 8+）**：直接解析日期字符串，利用 `ChronoUnit.DAYS.between()` 计算天数差。

## Java 代码实现

### 方法一：手动计算（推荐，不依赖日期库）

```java
class Solution {
    public int daysBetweenDates(String date1, String date2) {
        return Math.abs(dateToDay(date1) - dateToDay(date2));
    }
    
    // 将日期字符串转换为从 1971-01-01 起的天数
    private int dateToDay(String date) {
        int year  = Integer.parseInt(date.substring(0, 4));
        int month = Integer.parseInt(date.substring(5, 7));
        int day   = Integer.parseInt(date.substring(8, 10));
        
        int total = 0;
        
        // 累加 1971 年到 year-1 年的天数
        for (int y = 1971; y < year; y++) {
            total += isLeap(y) ? 366 : 365;
        }
        
        // 累加 year 年 1 月到 month-1 月的天数
        int[] daysInMonth = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        for (int m = 1; m < month; m++) {
            total += daysInMonth[m];
            if (m == 2 && isLeap(year)) total++; // 闰年 2 月加 1 天
        }
        
        // 加上当月天数（第 day 天，从第 1 天起）
        total += day - 1;
        
        return total;
    }
    
    // 判断是否为闰年
    private boolean isLeap(int year) {
        return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
    }
}
```

### 方法二：使用 Java 8 LocalDate（最简洁）

```java
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;

class Solution {
    public int daysBetweenDates(String date1, String date2) {
        // 解析日期字符串（格式 YYYY-MM-DD 符合 ISO 8601 标准）
        LocalDate d1 = LocalDate.parse(date1);
        LocalDate d2 = LocalDate.parse(date2);
        
        // 计算天数差的绝对值
        return (int) Math.abs(ChronoUnit.DAYS.between(d1, d2));
    }
}
```

### 方法三：手动计算（优化版，用公式避免循环）

```java
class Solution {
    public int daysBetweenDates(String date1, String date2) {
        return Math.abs(dateToDay(date1) - dateToDay(date2));
    }
    
    private int dateToDay(String date) {
        int y = Integer.parseInt(date.substring(0, 4));
        int m = Integer.parseInt(date.substring(5, 7));
        int d = Integer.parseInt(date.substring(8, 10));
        
        // 完整年的天数公式（格里高利历）
        int prevY = y - 1;
        int total = 365 * prevY + prevY / 4 - prevY / 100 + prevY / 400;
        
        // 当年前 m-1 个月的天数
        int[] daysInMonth = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        for (int i = 1; i < m; i++) {
            total += daysInMonth[i];
            if (i == 2 && isLeap(y)) total++;
        }
        
        total += d;
        return total;
    }
    
    private boolean isLeap(int year) {
        return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 手动循环年份 | O(Y)（Y 为年份范围，最多 129） | O(1) |
| 优化版（公式） | O(1) | O(1) |
| LocalDate 库 | O(1) | O(1) |

## 闰年规则详解

```
闰年判断规则：
1. 能被 400 整除 -> 闰年（如 2000, 1600）
2. 能被 100 整除但不能被 400 整除 -> 平年（如 1900, 2100）
3. 能被 4 整除但不能被 100 整除 -> 闰年（如 2004, 2024）
4. 其他 -> 平年（如 2019, 2021）

代码：year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)
```

## 关键点总结

1. Java 8+ 可以使用 `LocalDate.parse()` 直接解析 ISO 格式日期，`ChronoUnit.DAYS.between()` 计算天数差。
2. 手动计算时，先写 `isLeap()` 辅助函数，再统计年、月、日各部分的天数。
3. 基准日可以任意选（如 1971-01-01 或公元 1 年 1 月 1 日），两个日期用同一基准相减即可。
4. `Math.abs()` 取绝对值，处理两个日期大小关系不确定的情况。
5. 月份天数记忆口诀："一三五七八十腊，三十一天永不差，四六九冬三十天，只有二月二十八（闰年二十九）"。

## 易错点

- 闰年判断不能只用 `year % 4 == 0`，还要排除能被 100 整除但不能被 400 整除的年份。
- 两个日期大小不确定，必须用 `Math.abs()` 取绝对值。
- `date.substring(0, 4)` 提取年份，`substring(5, 7)` 提取月份，`substring(8, 10)` 提取日，注意索引范围。
- 手动计算月份天数时，2 月需要根据当年是否为闰年来决定是 28 还是 29 天。
