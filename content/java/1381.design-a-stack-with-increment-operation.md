## 题目描述

设计一个支持 push、pop 和 increment 操作的栈。increment(k, val) 将栈底 k 个元素的值都增加 val（不足 k 个则全部增加）。要求所有操作均 O(1)。

## 解题思路

使用惰性增量（Lazy Increment）：用额外数组 `inc[]` 延迟记录增量，`increment(k, val)` 只在下标 `min(k, size)-1` 处累加 val；pop 时弹出 `stack[top] + inc[top]`，并将 `inc[top]` 向下传播给 `inc[top-1]`。所有操作均 O(1)。

## Java 代码实现

```java
class CustomStack {
    private int[] stack;
    private int[] inc;   // 惰性增量数组，inc[i] 表示栈第 i 层的待累加增量
    private int top;     // 栈顶指针（-1 表示空栈）

    public CustomStack(int maxSize) {
        stack = new int[maxSize];
        inc = new int[maxSize];
        top = -1;
    }

    public void push(int x) {
        if (top < stack.length - 1) {
            stack[++top] = x;
            // 新元素的初始增量为 0（inc[top] 保留旧值，需清零）
            inc[top] = 0;
        }
    }

    public int pop() {
        if (top < 0) return -1;
        // 弹出值 = 原始值 + 累积增量
        int val = stack[top] + inc[top];
        // 将当前层增量向下传播
        if (top > 0) {
            inc[top - 1] += inc[top];
        }
        inc[top] = 0;
        top--;
        return val;
    }

    public void increment(int k, int val) {
        if (top < 0) return;
        // 增量记录在影响范围最顶部元素处
        int idx = Math.min(k - 1, top);
        inc[idx] += val;
    }
}
```

## 复杂度分析

- 时间复杂度：push O(1)，pop O(1)，increment O(1)。
- 空间复杂度：O(maxSize)，栈数组和增量数组。

## 关键点总结

1. 惰性增量将批量修改的代价分摊到每次 pop，`inc[idx]` 记录影响范围最顶部的累积增量。
2. pop 时将当前层 inc 传播给下一层，保证底部元素在未来 pop 时也能正确累加。
3. `inc[top]` 在 push 时需清零（避免复用旧数组位置的残留值）。
