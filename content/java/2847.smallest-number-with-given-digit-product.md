## 题目描述

给你一个正整数 n，找到最小的正整数 x 使得 x 的各位数字之积等于 n，返回字符串形式，不存在则返回 "-1"。

## 解题思路

贪心分解：从 9 到 2 依次整除 n（优先大因子以减少位数），将所有因子从小到大排序后拼接即为最小数值。

## Java 代码实现

```java
class Solution {
    public String smallestNumber(long n) {
        if (n == 1) return "1";

        List<Integer> digits = new ArrayList<>();
        // 从 9 到 2 贪心分解（优先大因子以减少位数）
        for (int d = 9; d >= 2; d--) {
            while (n % d == 0) {
                digits.add(d);
                n /= d;
            }
        }

        // 若 n > 1，说明存在大于 9 的质因子，无法分解
        if (n > 1) return "-1";

        // 从小到大排序，使组合的数值最小
        Collections.sort(digits);
        StringBuilder sb = new StringBuilder();
        for (int d : digits) sb.append(d);
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n × 8)
- **空间复杂度**：O(log n)

## 关键点总结

1. 只用 2-9 的因子分解 n，从 9 到 2 贪心（大因子减少位数）
2. 分解后若 n > 1，说明有大于 9 的质因子，返回 "-1"
3. 因子从小到大排序后拼接得到最小整数
