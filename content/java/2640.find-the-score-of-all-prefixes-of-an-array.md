## 题目描述

给你长度为 `n` 的整数数组 `nums`，前缀 `nums[0..i]` 的分数定义为 `nums[i] + max(nums[0..i])`，返回所有前缀分数组成的数组。

## Java 代码实现

```java
class Solution {
    public long[] findPrefixScore(int[] nums) {
        int n = nums.length;
        long[] ans = new long[n];
        long maxSoFar = 0;
        for (int i = 0; i < n; i++) {
            maxSoFar = Math.max(maxSoFar, nums[i]); // 更新前缀最大值
            ans[i] = nums[i] + maxSoFar;             // 分数 = 当前值 + 前缀最大值
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 用单变量维护前缀最大值，先更新再计算分数
2. 结果用 `long` 防止溢出
