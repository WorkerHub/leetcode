## 题目描述

树是一个无向图，其中任何两个顶点只通过一条路径连接。换句话说，一个任何没有简单环路的连通图都是一棵树。

给你一棵包含 `n` 个节点的树，标记为 `0` 到 `n - 1` 。给定数字 `n` 和一个有 `n - 1` 条无向边的 `edges` 列表（每一个边都是一对标签），其中 `edges[i] = [ai, bi]` 表示树中节点 `ai` 和 `bi` 之间存在一条无向边。

可选择树中任何一个节点作为根。当选择节点 `x` 作为根节点时，设结果树的高度为 `h` 。在所有可能的树中，具有最小高度的树（即，`min(h)`）被称为**最小高度树**。

请你找到所有的**最小高度树**并按**任意顺序**返回它们的根节点标签列表。

树的**高度**是指根节点和叶子节点之间最长向下路径上边的数量。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/09/01/e1.jpg)

```
输入：n = 4, edges = [[1,0],[1,2],[1,3]]
输出：[1]
解释：如图所示，当根是标签为 1 的节点时，树的高度是 1 ，这是唯一的最小高度树。
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/09/01/e2.jpg)

```
输入：n = 6, edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]
输出：[3,4]
```

**提示：**
- `1 <= n <= 2 * 10^4`
- `edges.length == n - 1`
- `0 <= ai, bi < n`
- `ai != bi`
- 所有 `(ai, bi)` 互不相同
- 给定的输入**保证**是一棵树，并且**不会有重复的边**

## 解题思路

### 核心观察

**最小高度树的根节点一定在树的"中心"**。

对于一棵树：
- 如果直径（最长路径）的长度是偶数，有 1 个中心节点
- 如果直径的长度是奇数，有 2 个中心节点

**关键结论**：最小高度树的根节点最多有 2 个！

### 方法：拓扑排序（剥洋葱）⭐

类似于拓扑排序的思想，从外向内逐层剥离叶子节点：

1. **找到所有叶子节点**（度为 1 的节点）
2. **移除叶子节点**，更新相邻节点的度
3. **重复步骤 1-2**，直到剩余节点数 ≤ 2
4. **剩余的节点**就是最小高度树的根节点

### 为什么这样做是对的？

- 叶子节点肯定不是最优的根（高度最大）
- 逐层剥离叶子节点，最后剩下的是树的中心
- 树的中心到所有叶子的距离最平衡

## Java 代码实现

### 方法一：拓扑排序（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        // 特殊情况
        if (n == 1) return Collections.singletonList(0);
        if (n == 2) return Arrays.asList(0, 1);

        // 构建邻接表和度数组
        List<Set<Integer>> graph = new ArrayList<>();
        int[] degree = new int[n];

        for (int i = 0; i < n; i++) {
            graph.add(new HashSet<>());
        }

        for (int[] edge : edges) {
            int a = edge[0], b = edge[1];
            graph.get(a).add(b);
            graph.get(b).add(a);
            degree[a]++;
            degree[b]++;
        }

        // 找到所有叶子节点（度为 1）
        Queue<Integer> leaves = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (degree[i] == 1) {
                leaves.offer(i);
            }
        }

        // 逐层剥离叶子节点
        int remaining = n;
        while (remaining > 2) {
            // 当前层的叶子节点数量
            int leafCount = leaves.size();
            remaining -= leafCount;

            // 移除当前层的所有叶子
            for (int k = 0; k < leafCount; k++) {
                int leaf = leaves.poll();

                // 更新相邻节点的度
                for (int neighbor : graph.get(leaf)) {
                    degree[neighbor]--;

                    // 如果邻居变成叶子，加入队列
                    if (degree[neighbor] == 1) {
                        leaves.offer(neighbor);
                    }
                }
            }
        }

        // 剩余的节点就是答案
        return new ArrayList<>(leaves);
    }
}
```

### 方法二：简化版本

```java
import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        if (n <= 2) {
            List<Integer> result = new ArrayList<>();
            for (int i = 0; i < n; i++) result.add(i);
            return result;
        }

        // 构建邻接表
        List<Set<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new HashSet<>());

        for (int[] edge : edges) {
            int a = edge[0], b = edge[1];
            graph.get(a).add(b);
            graph.get(b).add(a);
        }

        // 初始化叶子节点
        List<Integer> leaves = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (graph.get(i).size() == 1) leaves.add(i);
        }

        // 逐层剥离
        int remaining = n;
        while (remaining > 2) {
            remaining -= leaves.size();
            List<Integer> newLeaves = new ArrayList<>();

            for (int leaf : leaves) {
                // 叶子节点只有一个邻居
                int neighbor = graph.get(leaf).iterator().next();
                graph.get(neighbor).remove(leaf);

                // 如果邻居变成叶子
                if (graph.get(neighbor).size() == 1) {
                    newLeaves.add(neighbor);
                }
            }

            leaves = newLeaves;
        }

        return leaves;
    }
}
```

### 方法三：带详细注释的版本

```java
import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        /**
         * 寻找最小高度树的根节点
         *
         * 核心思想：树的中心节点
         * - 从外向内逐层剥离叶子节点
         * - 最后剩下的 1-2 个节点就是中心
         *
         * 类比：剥洋葱，一层一层剥，最后剩下的是核心
         */
        // 边界情况
        if (n == 1) return Collections.singletonList(0);
        if (n == 2) return Arrays.asList(0, 1);

        // 1. 构建图（邻接表 + 度数组）
        // 使用 Set 方便删除
        List<Set<Integer>> graph = new ArrayList<>();
        int[] degree = new int[n];

        for (int i = 0; i < n; i++) graph.add(new HashSet<>());

        for (int[] edge : edges) {
            int a = edge[0], b = edge[1];
            graph.get(a).add(b);
            graph.get(b).add(a);
            degree[a]++;
            degree[b]++;
        }

        // 2. 找到所有叶子节点（度为 1）
        Queue<Integer> leaves = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (degree[i] == 1) leaves.offer(i);
        }

        // 3. 逐层剥离叶子节点
        int remaining = n; // 剩余节点数

        while (remaining > 2) {
            // 当前层的叶子数量
            int leafCount = leaves.size();
            remaining -= leafCount;

            // 处理当前层的所有叶子
            for (int k = 0; k < leafCount; k++) {
                int leaf = leaves.poll();

                // 遍历叶子的邻居
                for (int neighbor : graph.get(leaf)) {
                    // 移除边（度减 1）
                    degree[neighbor]--;

                    // 如果邻居变成叶子，加入下一层
                    if (degree[neighbor] == 1) {
                        leaves.offer(neighbor);
                    }
                }
            }
        }

        // 4. 剩余的 1-2 个节点就是答案
        return new ArrayList<>(leaves);
    }
}
```

### 方法四：不使用度数组

```java
import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        if (n <= 2) {
            List<Integer> result = new ArrayList<>();
            for (int i = 0; i < n; i++) result.add(i);
            return result;
        }

        // 构建邻接表（使用 Set 方便删除）
        List<Set<Integer>> neighbors = new ArrayList<>();
        for (int i = 0; i < n; i++) neighbors.add(new HashSet<>());

        for (int[] edge : edges) {
            neighbors.get(edge[0]).add(edge[1]);
            neighbors.get(edge[1]).add(edge[0]);
        }

        // 找叶子节点
        List<Integer> leaves = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (neighbors.get(i).size() == 1) leaves.add(i);
        }

        // 剥离叶子
        int remainingNodes = n;
        while (remainingNodes > 2) {
            remainingNodes -= leaves.size();
            List<Integer> newLeaves = new ArrayList<>();

            for (int leaf : leaves) {
                // 获取叶子的唯一邻居
                int neighbor = neighbors.get(leaf).iterator().next();
                neighbors.get(neighbor).remove(leaf);

                // 检查邻居是否变成叶子
                if (neighbors.get(neighbor).size() == 1) {
                    newLeaves.add(neighbor);
                }
            }

            leaves = newLeaves;
        }

        return leaves;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
  - 构建图：O(n)
  - 每个节点最多被访问一次：O(n)
- 空间复杂度：O(n)，图的存储空间

## 关键点总结

1. **树的中心**：最小高度树的根节点一定是树的中心
2. **最多 2 个根**：答案最多有 2 个节点
3. **拓扑排序思想**：从外向内逐层剥离
4. **度的更新**：移除叶子时要更新邻居的度
5. **终止条件**：剩余节点 ≤ 2

## 易错点

1. **边界情况**：`n=1` 和 `n=2` 需要特殊处理
2. **双向边**：无向图，构建邻接表时要加两次
3. **度的定义**：叶子节点的度是 1，不是 0
4. **队列操作**：要记录当前层的大小，不能边遍历边添加
5. **集合操作**：使用 Set 方便删除，注意 `iterator().next()` 获取唯一邻居

## 学习建议

这道题结合了图论和拓扑排序：

1. **图的表示**：
   - 邻接表：`List<Set<Integer>>`
   - 度数组：记录每个节点的度

2. **拓扑排序变体**：
   - 经典拓扑排序：有向图，入度为 0
   - 本题：无向树，度为 1（叶子节点）

3. **BFS 思想**：
   - 层序遍历：一层一层处理
   - 队列操作：记录每层的大小

4. **树的性质**：
   - 树的直径：最长路径
   - 树的中心：直径的中点
   - 最小高度树的根 = 树的中心

5. **优化技巧**：
   - 使用 Set 而不是 List（O(1) 删除）
   - 度数组而不是每次计算（空间换时间）

6. **举一反三**：
   - 如果要求树的直径？（两次 BFS/DFS）
   - 如果是有向图？（经典拓扑排序）
   - 如果有多个连通分量？（每个分量单独处理）
