## 题目描述

给整数数组 nums，返回所有频率等于最高频率的元素的总出现次数之和。

## 解题思路

统计每个元素频率，找到最大频率，累加所有等于最大频率的元素个数。

## Java 代码实现

```java
class Solution {
    public int maxFrequencyElements(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.merge(x, 1, Integer::sum);
        int maxFreq = 0;
        for (int f : freq.values()) maxFreq = Math.max(maxFreq, f);
        int ans = 0;
        for (int f : freq.values()) {
            if (f == maxFreq) ans += f;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 统计频率后找最大频率
2. 满足最大频率的元素每个贡献 maxFreq 次
3. 返回总出现次数（不是元素种数）
