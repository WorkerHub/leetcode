## 题目描述

给定一个字符串 `s`，你需要反转字符串中每个单词的字符顺序，同时仍保留空格和单词的初始顺序。

**示例 1：**
```
输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"
```

**示例 2：**
```
输入：s = "Mr Ding"
输出："rM gniD"
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `s` 包含可打印的 ASCII 字符
- `s` 不包含任何开头或结尾空格
- `s` 里至少有一个词
- `s` 中的所有单词都用一个空格隔开

## 解题思路

这是一道简单的字符串处理题，需要反转每个单词内部的字符，但保持单词的顺序。

核心思想：
1. 按空格分割字符串，得到单词列表
2. 反转每个单词
3. 用空格重新连接

## Java 代码实现

### 方法一：split + 反转（推荐）⭐

```java
class Solution {
    public String reverseWords(String s) {
        // 按空格分割，反转每个单词，再用空格连接
        String[] words = s.split(" ");
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < words.length; i++) {
            if (i > 0) sb.append(" ");
            sb.append(new StringBuilder(words[i]).reverse());
        }
        return sb.toString();
    }
}
```

### 方法二：双指针

```java
class Solution {
    public String reverseWords(String s) {
        // 使用双指针找到每个单词的边界，然后反转
        char[] chars = s.toCharArray();
        int n = chars.length;

        int start = 0;
        for (int i = 0; i <= n; i++) {
            // 遇到空格或到达末尾，反转单词
            if (i == n || chars[i] == ' ') {
                reverse(chars, start, i - 1);
                start = i + 1;
            }
        }

        return new String(chars);
    }

    // 反转 chars[left..right]
    private void reverse(char[] chars, int left, int right) {
        while (left < right) {
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 方法三：使用 Stream（简洁版本）

```java
import java.util.Arrays;
import java.util.stream.Collectors;

class Solution {
    public String reverseWords(String s) {
        // 使用 Java Stream 简洁处理
        return Arrays.stream(s.split(" "))
                .map(word -> new StringBuilder(word).reverse().toString())
                .collect(Collectors.joining(" "));
    }
}
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，需要遍历整个字符串
- **空间复杂度**：O(n)，存储结果字符串

## 关键点总结

1. **split 方法**：按空格分割字符串
2. **StringBuilder.reverse()**：Java 内置反转方法
3. **双指针原地反转**：方法二效率更高，不需要额外分割
4. **join 方法**：用空格连接单词列表
5. **边界处理**：最后一个单词需要单独处理

## 易错点

1. **理解题意**：反转每个单词内部，不是反转整个字符串
2. **空格处理**：保持单词之间的空格
3. **边界情况**：最后一个单词需要单独处理
4. **字符串不可变**：Java 中字符串不可变，原地操作需要转成 char 数组
