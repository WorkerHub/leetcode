## 题目描述

序列化是将数据结构或对象转换为一系列位的过程，以便它可以存储在文件或内存缓冲区中，或通过网络连接链路传输，以便稍后在同一个或另一个计算机环境中重建。

设计一个算法来序列化和反序列化二叉搜索树。对序列化/反序列化算法的工作方式没有限制。你只需确保二叉搜索树可以序列化为字符串，并且可以将该字符串反序列化为最初的二叉搜索树。

编码的字符串应尽可能紧凑。

**示例 1:**

```
输入: root = [2,1,3]
输出: [2,1,3]
```

**示例 2:**

```
输入: root = []
输出: []
```

**提示:**

- 树中节点数范围是 [0, 10^4]
- 0 <= Node.val <= 10^4
- 题目数据保证输入的树是一棵二叉搜索树

## 解题思路

这道题是 [297. Serialize and Deserialize Binary Tree](https://leetcode.com/problems/serialize-and-deserialize-binary-tree/) 的特化版本，但由于是**二叉搜索树（BST）**，可以利用其特性进行优化。

**BST 的特性：**
1. 左子树所有节点 < 根节点 < 右子树所有节点
2. 中序遍历是有序的
3. 前序/后序遍历可以唯一确定 BST

**优化方案：**

与普通二叉树不同，BST 只需要**前序遍历**就能唯一重建，不需要使用空值标记（null）。

**方法对比：**
1. **方法一（利用 BST 特性）**：只存储前序遍历，反序列化时利用 BST 性质重建
2. **方法二（通用方法）**：与 297 题相同，使用空值标记
3. **方法三（后序遍历）**：利用后序遍历重建 BST

## Java 代码实现

### 方法一：前序遍历 + BST 性质（推荐）

```java
import java.util.Arrays;
import java.util.LinkedList;
import java.util.Queue;

class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

public class Codec {
    /**
     * 使用前序遍历序列化，利用 BST 性质反序列化
     * 不需要存储 null 标记，空间最优
     */

    // 序列化：前序遍历
    public String serialize(TreeNode root) {
        /**
         * 前序遍历序列化
         * 时间复杂度: O(n)
         * 空间复杂度: O(n)
         */
        StringBuilder sb = new StringBuilder();
        preorder(root, sb);
        // 去掉末尾多余的逗号
        if (sb.length() > 0) sb.deleteCharAt(sb.length() - 1);
        return sb.toString();
    }

    private void preorder(TreeNode node, StringBuilder sb) {
        if (node == null) return;
        sb.append(node.val).append(',');
        preorder(node.left, sb);
        preorder(node.right, sb);
    }

    // 反序列化：利用 BST 性质重建树
    public TreeNode deserialize(String data) {
        /**
         * 利用 BST 性质重建树
         * 时间复杂度: O(n)
         * 空间复杂度: O(n)
         */
        if (data == null || data.isEmpty()) return null;

        String[] parts = data.split(",");
        int[] vals = Arrays.stream(parts).mapToInt(Integer::parseInt).toArray();
        int[] index = {0};  // 用数组传递索引引用

        return build(vals, index, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode build(int[] vals, int[] index, int minVal, int maxVal) {
        /**
         * 在 [minVal, maxVal] 范围内构建子树
         */
        if (index[0] >= vals.length) return null;

        int val = vals[index[0]];

        // 如果当前值不在范围内，说明不属于当前子树
        if (val < minVal || val > maxVal) return null;

        // 创建节点，推进索引
        index[0]++;
        TreeNode node = new TreeNode(val);

        // 左子树：值在 [minVal, val) 范围内
        node.left = build(vals, index, minVal, val);
        // 右子树：值在 (val, maxVal] 范围内
        node.right = build(vals, index, val, maxVal);

        return node;
    }
}
```

### 方法二：后序遍历（逆序构建）

```java
public class Codec {
    /**
     * 使用后序遍历，从右到左构建
     */

    public String serialize(TreeNode root) {
        /**后序遍历序列化*/
        StringBuilder sb = new StringBuilder();
        postorder(root, sb);
        if (sb.length() > 0) sb.deleteCharAt(sb.length() - 1);
        return sb.toString();
    }

    private void postorder(TreeNode node, StringBuilder sb) {
        if (node == null) return;
        postorder(node.left, sb);
        postorder(node.right, sb);
        sb.append(node.val).append(',');
    }

    public TreeNode deserialize(String data) {
        /**从后向前构建 BST*/
        if (data == null || data.isEmpty()) return null;

        String[] parts = data.split(",");
        int[] vals = Arrays.stream(parts).mapToInt(Integer::parseInt).toArray();
        int[] index = {vals.length - 1};  // 从末尾开始

        return buildPostorder(vals, index, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode buildPostorder(int[] vals, int[] index, int minVal, int maxVal) {
        if (index[0] < 0) return null;

        int val = vals[index[0]];

        if (val < minVal || val > maxVal) return null;

        // 从后向前，所以先处理右子树
        index[0]--;
        TreeNode node = new TreeNode(val);

        // 注意顺序：后序是左右根，所以反向是根右左
        node.right = buildPostorder(vals, index, val, maxVal);
        node.left = buildPostorder(vals, index, minVal, val);

        return node;
    }
}
```

### 方法三：通用方法（与 297 题相同）

```java
import java.util.LinkedList;
import java.util.Queue;

public class Codec {
    /**
     * 使用 null 标记的通用方法
     * 适用于任何二叉树，但不是最优
     */

    public String serialize(TreeNode root) {
        /**前序遍历，使用 "#" 表示 null*/
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        if (sb.length() > 0) sb.deleteCharAt(sb.length() - 1);
        return sb.toString();
    }

    private void serializeHelper(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append('#').append(',');
            return;
        }
        sb.append(node.val).append(',');
        serializeHelper(node.left, sb);
        serializeHelper(node.right, sb);
    }

    public TreeNode deserialize(String data) {
        /**根据序列化字符串重建树*/
        if (data == null || data.isEmpty()) return null;

        Queue<String> queue = new LinkedList<>(Arrays.asList(data.split(",")));
        return deserializeHelper(queue);
    }

    private TreeNode deserializeHelper(Queue<String> queue) {
        String val = queue.poll();
        if ("#".equals(val)) return null;

        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = deserializeHelper(queue);
        node.right = deserializeHelper(queue);
        return node;
    }
}
```

### 方法四：迭代版本

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class Codec {
    /**
     * 迭代实现序列化和反序列化
     */

    public String serialize(TreeNode root) {
        /**迭代前序遍历*/
        if (root == null) return "";

        StringBuilder sb = new StringBuilder();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            sb.append(node.val).append(',');
            // 先右后左，保证前序遍历
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }

        sb.deleteCharAt(sb.length() - 1);
        return sb.toString();
    }

    public TreeNode deserialize(String data) {
        /**迭代构建 BST*/
        if (data == null || data.isEmpty()) return null;

        String[] parts = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(parts[0]));
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        for (int i = 1; i < parts.length; i++) {
            int val = Integer.parseInt(parts[i]);
            TreeNode node = new TreeNode(val);

            // 找到合适的父节点
            if (val < stack.peek().val) {
                // 作为左子节点
                stack.peek().left = node;
            } else {
                // 找到第一个比当前值小的节点
                TreeNode parent = null;
                while (!stack.isEmpty() && stack.peek().val < val) {
                    parent = stack.pop();
                }
                parent.right = node;
            }

            stack.push(node);
        }

        return root;
    }
}
```

## 复杂度分析

**方法一（前序遍历 + BST 性质）：**
- 序列化时间复杂度：O(n)
- 反序列化时间复杂度：O(n)
- 空间复杂度：O(n)
- **优点**：不需要存储 null，空间最优

**方法二（后序遍历）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- **优点**：思路独特，利用后序遍历的逆序

**方法三（通用方法）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)
- **缺点**：需要存储 null 标记，空间不够优

## 关键点总结

1. **BST 特性利用**：前序遍历可以唯一确定 BST
2. **范围限制**：利用 [minVal, maxVal] 判断节点归属
3. **无需 null 标记**：比通用方法更省空间
4. **递归构建**：通过范围限制自然划分左右子树
5. **索引管理**：Java 中用 `int[]` 数组传递索引引用，模拟"引用传递"

## 易错点

1. **范围判断错误**：
   ```java
   // 错误：严格不等号用错
   if (val <= minVal || val >= maxVal) return null;

   // 正确：
   if (val < minVal || val > maxVal) return null;
   ```

2. **Java 中无法直接传递 int 引用**：
   ```java
   // 错误：int 是值类型，无法在递归中更新
   private TreeNode build(int[] vals, int index, ...) { ... }

   // 正确：用 int[] 数组传递索引
   private TreeNode build(int[] vals, int[] index, ...) {
       index[0]++;  // 可以修改并在调用者处生效
   }
   ```

3. **递归顺序**：
   - 前序：先左后右
   - 后序反向：先右后左
   - 顺序错误会导致树结构错误

4. **边界条件**：
   - 空树的处理
   - 只有一个节点的处理
   - 链状树的处理
