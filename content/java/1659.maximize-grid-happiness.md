## 题目描述

`m x n` 网格（m,n <= 5），放置内向人（基础+120，每相邻-30）和外向人（基础+40，每相邻+20）。给定内/外向人数量，最大化总幸福感。

## 解题思路

**状态压缩 DP：** 每行状态用三进制（0=空/1=内/2=外）表示，共 3^n 种。DP 状态为 `(行, 已用内向人数, 已用外向人数, 上一行状态)`，逐行转移。

## Java 代码实现

```java
class Solution {
    private int m, n, intCount, extCount;
    private Integer[][][][][] memo;

    public int getMaxGridHappiness(int m, int n, int introvertsCount, int extrovertsCount) {
        this.m = m; this.n = n;
        this.intCount = introvertsCount; this.extCount = extrovertsCount;
        int maxState = (int) Math.pow(3, n);
        memo = new Integer[m][introvertsCount + 1][extrovertsCount + 1][maxState][2];
        return dp(0, 0, 0, 0);
    }

    private int dp(int row, int ni, int ei, int prevState) {
        if (row == m || (ni == intCount && ei == extCount)) return 0;
        if (memo[row][ni][ei][prevState] != null) return memo[row][ni][ei][prevState];

        int maxState = (int) Math.pow(3, n);
        int best = dp(row + 1, ni, ei, 0); // 当前行全空

        // 解码上一行状态
        int[] prev = decode(prevState);

        for (int state = 1; state < maxState; state++) {
            int[] curr = decode(state);
            int sNi = 0, sEi = 0;
            for (int k = 0; k < n; k++) {
                if (curr[k] == 1) sNi++;
                else if (curr[k] == 2) sEi++;
            }
            if (ni + sNi > intCount || ei + sEi > extCount) continue;

            int h = rowHappiness(curr, prev);
            h += dp(row + 1, ni + sNi, ei + sEi, state);
            best = Math.max(best, h);
        }

        return memo[row][ni][ei][prevState] = best;
    }

    private int[] decode(int state) {
        int[] row = new int[n];
        for (int k = 0; k < n; k++) {
            row[k] = state % 3;
            state /= 3;
        }
        return row;
    }

    private int rowHappiness(int[] curr, int[] prev) {
        int h = 0;
        for (int k = 0; k < n; k++) {
            if (curr[k] == 0) continue;
            h += curr[k] == 1 ? 120 : 40; // 基础幸福感
            // 与左邻居的影响（双向）
            if (k > 0 && curr[k - 1] != 0) {
                h += curr[k] == 1 ? -30 : 20;
                h += curr[k - 1] == 1 ? -30 : 20;
            }
            // 与上方邻居的影响（双向）
            if (prev[k] != 0) {
                h += curr[k] == 1 ? -30 : 20;
                h += prev[k] == 1 ? -30 : 20;
            }
        }
        return h;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * I * E * 3^(2n))，I,E <= 6，3^5=243
- **空间复杂度**：O(m * I * E * 3^n)

## 关键点总结

1. 三进制状态压缩（0/1/2 = 空/内/外）
2. 相邻幸福感是双向的（两人都受影响）
3. 记忆化搜索避免重复计算
