## 题目描述

给你一个 32 位的有符号整数 `x`，返回将 `x` 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 `[-2^31, 2^31 - 1]`，就返回 0。

假设环境不允许存储 64 位整数（有符号或无符号）。

**示例 1：**
```
输入：x = 123
输出：321
```

**示例 2：**
```
输入：x = -123
输出：-321
```

**示例 3：**
```
输入：x = 120
输出：21
```

**提示：**
- `-2^31 <= x <= 2^31 - 1`

## 解题思路

这道题的核心是：
1. 将整数的数字部分反转
2. 检查反转后是否溢出

关键观察：
- 需要在反转过程中提前检查溢出（Java 的 int 有范围限制）
- 负数需要单独处理符号
- 反转可以通过数学方法（每次取余数）

## Java 代码实现

### 方法一：数学方法 + 提前检查溢出（推荐）

```java
class Solution {
    public int reverse(int x) {
        int result = 0;
        
        while (x != 0) {
            // 取最后一位数字
            int digit = x % 10;
            // 去掉最后一位
            x /= 10;
            
            // 提前检查正数溢出
            // 如果 result > Integer.MAX_VALUE / 10，则 result * 10 会溢出
            // 如果 result == Integer.MAX_VALUE / 10 且 digit > 7，也会溢出
            if (result > Integer.MAX_VALUE / 10 ||
                (result == Integer.MAX_VALUE / 10 && digit > 7)) {
                return 0;
            }
            
            // 提前检查负数溢出
            if (result < Integer.MIN_VALUE / 10 ||
                (result == Integer.MIN_VALUE / 10 && digit < -8)) {
                return 0;
            }
            
            // 将数字添加到结果中
            result = result * 10 + digit;
        }
        
        return result;
    }
}
```

### 方法二：使用 long 暂存（简化版）

```java
class Solution {
    public int reverse(int x) {
        long result = 0;
        
        while (x != 0) {
            result = result * 10 + x % 10;
            x /= 10;
        }
        
        // 检查是否溢出
        if (result > Integer.MAX_VALUE || result < Integer.MIN_VALUE) {
            return 0;
        }
        
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log x)，x 有多少位就需要循环多少次
- 空间复杂度：O(1)

## 关键点总结

1. **溢出检查**：必须在反转前或反转后检查是否超出 32 位整数范围
2. **符号处理**：Java 中 `%` 运算符对负数返回负值，不需要单独处理符号
3. **数学反转**：通过 `% 10` 取最后一位，`/ 10` 去掉最后一位
4. **边界情况**：`Integer.MIN_VALUE` 和 `Integer.MAX_VALUE` 的边界

## 易错点

1. **忘记检查溢出**：题目明确要求超出范围返回 0
2. **Java 的负数取余**：`-123 % 10 = -3`，与 Python 不同，但正好可以直接用
3. **溢出检查时机**：
   - 方法一在反转过程中检查（严格）
   - 方法二使用 long 暂存后检查（简单但不满足严格要求）
4. **Integer.MIN_VALUE**：其绝对值比 Integer.MAX_VALUE 大 1
