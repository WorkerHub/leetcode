## 题目描述

给你顾客访问记录字符串 `customers`（Y/N），在第 `j` 小时关门的代价 = 前缀 N 数 + 后缀 Y 数，返回代价最小的最早关门时刻。

## 解题思路

从全部关门时的代价（总 Y 数）出发，逐步向右扩展：遇到 Y 代价减 1，遇到 N 代价加 1，维护最小代价及对应时刻。

## Java 代码实现

```java
class Solution {
    public int bestClosingTime(String customers) {
        int penalty = 0;
        // 初始代价 j=0：所有 Y 都在关门后，代价 = Y 总数
        for (char c : customers.toCharArray())
            if (c == 'Y') penalty++;

        int minPenalty = penalty, ans = 0;
        for (int j = 0; j < customers.length(); j++) {
            // 向右扩展一小时
            if (customers.charAt(j) == 'Y') penalty--; // 减少后缀 Y
            else penalty++;                              // 增加前缀 N
            if (penalty < minPenalty) {
                minPenalty = penalty;
                ans = j + 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. j=0 时代价为总 Y 数，每向右扩展一个位置：Y 使代价减 1，N 使代价加 1
2. 使用严格小于更新，保证返回最早出现的最小代价时刻
3. j 范围为 0 到 n（包含两端）
