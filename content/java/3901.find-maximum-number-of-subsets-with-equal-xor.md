## 题目描述

给定整数数组 `nums`（n <= 16），将 `nums` 划分为若干非空子集使每个子集的异或值相等，返回满足条件的最大子集数量。

## 解题思路

XOR 线性基方法：计算 `nums` 的线性基的秩 r。若总异或值不为 0，最多能分 `2^(r-1)` 个子集；若总异或值为 0，最多能分 `2^r` 个子集。

## Java 代码实现

```java
class Solution {
    public int maximumSubsets(int[] nums) {
        // 计算总异或值
        int totalXor = 0;
        for (int v : nums) totalXor ^= v;

        // 构建 XOR 线性基（nums[i] <= 1000 < 2^10）
        int[] basis = new int[10];
        int rank = 0;

        for (int v : nums) {
            // 用线性基化简 v
            for (int i = 0; i < rank; i++) {
                v = Math.min(v, v ^ basis[i]);
            }
            if (v > 0) {
                // v 线性无关，加入基底
                basis[rank++] = v;
            }
        }

        if (totalXor != 0) {
            // 每个子集 XOR = totalXor，最多分 2^(rank-1) 个子集
            return 1 << (rank - 1);
        } else {
            // totalXor == 0，最多分 2^rank 个子集
            return 1 << rank;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * max_bit)，max_bit = 10
- 空间复杂度：O(max_bit)

## 关键点总结

1. 总 XOR = 0 时，子集可以分成 XOR 均为 0 的若干组；否则每组 XOR = 总 XOR。
2. XOR 线性基的秩 r 决定了可表示的 XOR 值个数（2^r 种）。
3. 状态压缩 DP 暴力枚举子集划分，适合 n <= 16 的小规模数据。
