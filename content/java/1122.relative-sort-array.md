## 题目描述

对 arr1 排序，使得在 arr2 中出现的元素按 arr2 顺序排列，不在 arr2 中的元素按升序排在末尾。

**示例：**
```
输入：arr1 = [2,3,1,3,2,4,6,7,9,2,19], arr2 = [2,1,4,3,9,6]
输出：[2,2,2,1,4,3,3,9,6,7,19]
```

## 解题思路

计数排序：统计 arr1 频率，先按 arr2 顺序输出对应次数的元素，再遍历 0-1000 输出剩余。

## Java 代码实现

```java
class Solution {
    public int[] relativeSortArray(int[] arr1, int[] arr2) {
        int[] count = new int[1001];
        for (int num : arr1) count[num]++;

        int[] result = new int[arr1.length];
        int idx = 0;

        // 按 arr2 顺序输出
        for (int num : arr2) {
            while (count[num]-- > 0) {
                result[idx++] = num;
            }
        }

        // 剩余元素按升序输出
        for (int i = 0; i <= 1000; i++) {
            while (count[i]-- > 0) {
                result[idx++] = i;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m + 1001)，即 O(n + m)
- **空间复杂度**：O(1001) = O(1)

## 关键点总结

1. **计数排序**：值域 0-1000，适合计数排序
2. **两阶段输出**：先按 arr2 顺序，再扫描计数数组输出剩余
3. **清零计数**：arr2 处理后 count 归零，避免后续重复
