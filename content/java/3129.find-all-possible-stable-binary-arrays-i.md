## 题目描述

给定zero、one和limit，求含zero个0和one个1且任意连续相同段长度不超过limit的数组数量，结果取模。

## 解题思路

DP：dp[i][j][v]表示已放i个0、j个1、末位为v的方案数。转移时枚举最后一段长度1~limit，用前缀和优化。

## Java 代码实现

```java
class Solution {
    public int numberOfStableArrays(int zero, int one, int limit) {
        int MOD = 1_000_000_007;
        // dp[i][j][0/1]: 已放i个0、j个1，末位为0/1的方案数
        long[][][] dp = new long[zero + 1][one + 1][2];

        // 初始化：前缀全为0或全为1
        for (int i = 1; i <= Math.min(zero, limit); i++) dp[i][0][0] = 1;
        for (int j = 1; j <= Math.min(one, limit); j++) dp[0][j][1] = 1;

        for (int i = 0; i <= zero; i++) {
            for (int j = 0; j <= one; j++) {
                if (i == 0 && j == 0) continue;
                // 末位为0：从末位为1的状态转移，最后一段0长度k(1~limit)
                if (i > 0) {
                    for (int k = 1; k <= Math.min(i, limit); k++) {
                        if (j > 0 || i - k == 0) {
                            // i-k个0,j个1,末位为1 -> 再追加k个0
                            dp[i][j][0] = (dp[i][j][0] + dp[i - k][j][1]) % MOD;
                        }
                    }
                }
                // 末位为1：从末位为0的状态转移，最后一段1长度k(1~limit)
                if (j > 0) {
                    for (int k = 1; k <= Math.min(j, limit); k++) {
                        if (i > 0 || j - k == 0) {
                            dp[i][j][1] = (dp[i][j][1] + dp[i][j - k][0]) % MOD;
                        }
                    }
                }
            }
        }
        return (int)((dp[zero][one][0] + dp[zero][one][1]) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(zero * one * limit)
- **空间复杂度**：O(zero * one)

## 关键点总结

1. **约束：连续相同段<=limit**：枚举末段长度转移
2. **三维DP**：(已用0数, 已用1数, 末位值)
3. **初始化**：纯0或纯1的前缀（长度<=limit）
