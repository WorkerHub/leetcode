## 题目描述

给定字符串 `s`，每次操作将三个连续字符全部转换为 `'O'`，返回将所有 `'X'` 转换为 `'O'` 所需的最少操作次数。

## 解题思路

贪心：从左到右遍历，遇到 `'X'` 立刻执行一次操作覆盖当前及后续两个字符，跳过 3 位继续。

## Java 代码实现

### 方法一：贪心跳跃（推荐）

```java
class Solution {
    public int minimumMoves(String s) {
        int count = 0, i = 0;
        while (i < s.length()) {
            if (s.charAt(i) == 'X') {
                count++; // 覆盖i, i+1, i+2三个位置
                i += 3;
            } else {
                i++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 遇到 X 立刻从当前位置开始覆盖 3 个字符（最大化利用操作）
2. 每次操作后跳过 3 个位置
