## 题目描述

返回字符串数组中所有包含字符x的单词的下标。

## 解题思路

遍历每个单词，检查是否包含字符x，包含则加入结果。

## Java 代码实现

```java
class Solution {
    public List<Integer> findWordsContaining(String[] words, char x) {
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < words.length; i++) {
            if (words[i].indexOf(x) >= 0) {
                result.add(i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * M)，N为单词数，M为最长单词长度
- **空间复杂度**：O(1)（不计输出）

## 关键点总结

1. **indexOf检查字符是否存在**
2. **返回下标而非单词本身**
3. **顺序遍历即可**
