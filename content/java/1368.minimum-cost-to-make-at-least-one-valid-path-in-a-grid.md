## 题目描述

给你一个 m×n 的网格，每个单元格有方向标记（1右/2左/3下/4上）。按当前方向移动代价为 0，修改方向代价为 1。从 (0,0) 出发求到达 (m-1,n-1) 的最小代价。

## 解题思路

边权只有 0 或 1，使用 **0-1 BFS（双端队列）**：代价 0 的移动（同方向）将新节点加入队头，代价 1 的移动（改方向）加入队尾，队头始终是当前最小代价节点，时间复杂度 O(m×n)。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minCost(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 四个方向：右(1)、左(2)、下(3)、上(4)
        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        // 双端队列，存储 [row, col]
        Deque<int[]> dq = new ArrayDeque<>();
        dq.addFirst(new int[]{0, 0});

        while (!dq.isEmpty()) {
            int[] cur = dq.pollFirst();
            int r = cur[0], c = cur[1];
            int cost = dist[r][c];

            // 遍历四个方向（方向编号从 1 开始）
            for (int d = 0; d < 4; d++) {
                int nr = r + dirs[d][0];
                int nc = c + dirs[d][1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;

                // grid[r][c] 为 1~4，对应 dirs[0~3]，d+1 即方向编号
                int moveCost = (grid[r][c] == d + 1) ? 0 : 1;
                int newCost = cost + moveCost;
                if (newCost < dist[nr][nc]) {
                    dist[nr][nc] = newCost;
                    if (moveCost == 0) {
                        dq.addFirst(new int[]{nr, nc});  // 免费移动加队头
                    } else {
                        dq.addLast(new int[]{nr, nc});   // 付费移动加队尾
                    }
                }
            }
        }

        return dist[m - 1][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m×n)，每个节点最多入队两次。
- 空间复杂度：O(m×n)，dist 数组和双端队列。

## 关键点总结

1. 0-1 BFS 适用于边权只有 0 或 1 的最短路，双端队列替代优先队列，避免 O(log N) 堆操作。
2. 代价 0 加队头、代价 1 加队尾，保证队头始终是当前最小代价节点。
3. 方向编号 1~4 对应 `dirs[0~3]`，用 `grid[r][c] == d+1` 判断是否需要改方向。
