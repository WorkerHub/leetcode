## 题目描述

给出集合 `[1,2,3,...,n]`，其所有元素共有 `n!` 种排列。

按大小顺序列出所有排列情况，并一一标记，当 `n = 3` 时, 所有排列如下：

1. "123"
2. "132"
3. "213"
4. "231"
5. "312"
6. "321"

给定 `n` 和 `k`，返回第 `k` 个排列。

**示例 1：**
```
输入：n = 3, k = 3
输出："213"
```

**示例 2：**
```
输入：n = 4, k = 9
输出："2314"
```

**示例 3：**
```
输入：n = 3, k = 1
输出："123"
```

**提示：**
- `1 <= n <= 9`
- `1 <= k <= n!`

## 解题思路

核心思想：数学规律（康托展开）

关键观察：
- 第一位确定后，后面有 (n-1)! 种排列
- 可以直接计算第 k 个排列，不需要生成所有排列

## Java 代码实现

```java
class Solution {
    public String getPermutation(int n, int k) {
        // 计算阶乘
        int[] factorial = new int[n];
        factorial[0] = 1;
        for (int i = 1; i < n; i++) {
            factorial[i] = factorial[i - 1] * i;
        }

        // 候选数字
        List<Integer> nums = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            nums.add(i);
        }

        StringBuilder result = new StringBuilder();
        k--;  // 转为0索引

        for (int i = n; i >= 1; i--) {
            // 确定当前位的数字索引
            int idx = k / factorial[i - 1];
            result.append(nums.get(idx));
            nums.remove(idx);
            k %= factorial[i - 1];
        }

        return result.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. **康托展开**：直接计算第k个排列
2. **阶乘**：每一位的选择数
3. **索引转换**：k转为0索引
