## 题目描述

给定spells和potions数组及success阈值，对每个spell求有多少potion使乘积>=success。

## 解题思路

排序potions后二分查找：对每个spell，找第一个使spell*potion>=success的位置，右侧全部满足。

## Java 代码实现

```java
class Solution {
    public int[] successfulPairs(int[] spells, int[] potions, long success) {
        Arrays.sort(potions);
        int n = spells.length, m = potions.length;
        int[] result = new int[n];

        for (int i = 0; i < n; i++) {
            // 找第一个 potions[j] >= ceil(success / spells[i])
            long need = (success + spells[i] - 1) / spells[i];
            int lo = 0, hi = m;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (potions[mid] >= need) hi = mid;
                else lo = mid + 1;
            }
            result[i] = m - lo;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + M) log M)
- **空间复杂度**：O(1)（不计输出）

## 关键点总结

1. **排序+二分**：经典配对计数模式
2. **向上取整计算阈值**：(success + spell - 1) / spell
3. **long防溢出**：乘积可能超int范围
