## 题目描述

判断能否用字符串s的所有字符恰好构造k个非空回文字符串。

## 解题思路

贪心：回文最多有1个奇数频率字符在中间。需满足两个条件：k<=len(s)且出现奇数次的字符数<=k。

## Java 代码实现

```java
class Solution {
    public boolean canConstruct(String s, int k) {
        if (k > s.length()) return false;

        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }
        // 统计出现奇数次的字符个数
        int oddCount = 0;
        for (int f : freq) {
            if (f % 2 != 0) oddCount++;
        }
        return oddCount <= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **回文性质**：最多1个奇数频率字符
2. **oddCount <= k**：每个奇数字符至少占一个回文中心
3. **k <= len(s)**：每个回文至少1个字符
