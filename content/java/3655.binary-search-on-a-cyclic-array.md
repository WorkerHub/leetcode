## 题目描述

给你一个由升序数组旋转后得到的整数数组 `nums`（无重复元素）和目标值 `target`，返回目标值在数组中的下标，若不存在返回 -1。

## 解题思路

二分查找：通过比较 `nums[mid]` 与端点判断哪半部分有序，再判断 target 是否在有序部分内，缩小搜索范围。

## Java 代码实现

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;

        while (left <= right) {
            int mid = (left + right) / 2;
            if (nums[mid] == target) return mid;

            // 左半部分有序
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 右半部分有序
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 旋转数组每次二分后，至少一半是有序的
2. 通过比较端点值判断哪半部分有序
3. 在有序半部分用常规二分逻辑缩小范围
