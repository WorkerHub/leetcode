## 题目描述

有 n 种题型，第 i 种有 `count_i` 道题每题 `mark_i` 分，返回恰好得 `target` 分的方案数（模 10^9+7）。

## 解题思路

分组背包 DP：`dp[j]` 表示恰好得 j 分的方案数；对每种题型用新数组更新，枚举做 0 到 count 道的方案数累加。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int waysToReachTarget(int target, int[][] types) {
        int[] dp = new int[target + 1];
        dp[0] = 1; // 0 分有 1 种方案

        for (int[] type : types) {
            int count = type[0], mark = type[1];
            int[] newDp = new int[target + 1];
            for (int j = 0; j <= target; j++) {
                // 枚举做 t 道该题型（t = 0 到 min(count, j/mark)）
                for (int t = 0; t <= count && t * mark <= j; t++) {
                    newDp[j] = (int) ((newDp[j] + dp[j - t * mark]) % MOD);
                }
            }
            dp = newDp;
        }
        return dp[target];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * target * count_max)
- **空间复杂度**：O(target)

## 关键点总结

1. 每种题型独立，用新数组 newDp 更新避免重复计算
2. 内层枚举做 0 到 count 道，累加 `dp[j - t*mark]`
3. dp[0] = 1 代表恰好 0 分有 1 种方案（不做任何题）
