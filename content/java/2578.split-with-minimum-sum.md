## 题目描述

给你正整数 `num`，将其各位数字分配给两个非负整数 `num1` 和 `num2`，使两者之和最小，返回最小和。

## 解题思路

将各位数字排序后交替分配给 num1 和 num2：排序后较小的数字优先占据高位，交替保证两数位数均衡，从而最小化总和。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int splitNum(int num) {
        char[] digits = Integer.toString(num).toCharArray();
        Arrays.sort(digits);
        int n1 = 0, n2 = 0;
        for (int i = 0; i < digits.length; i++) {
            int d = digits[i] - '0';
            if (i % 2 == 0) n1 = n1 * 10 + d;
            else n2 = n2 * 10 + d;
        }
        return n1 + n2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(d log d)，d 为位数（最多 10）
- **空间复杂度**：O(d)

## 关键点总结

1. 排序后交替分配，让两数高位都尽可能小
2. 奇偶交替保证两数位数均衡
3. 较小的数字放高位可最小化贡献
