## 题目描述

编码字符串中字母表示自身，数字 d 表示前面的字符串重复 d 次。求解码后第 k 个字符。

**示例：**
```
输入：s = "leet2code3", k = 10
输出："o"
```

## 解题思路

逆向推导：先计算解码后总长度，再从后往前缩减长度，利用取模确定字符位置。

## Java 代码实现

```java
class Solution {
    public String decodeAtIndex(String s, int k) {
        long size = 0;

        // 计算解码后的总长度
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                size *= c - '0';
            } else {
                size++;
            }
        }

        // 从后往前逆推
        for (int i = s.length() - 1; i >= 0; i--) {
            k %= size;
            char c = s.charAt(i);

            if (k == 0 && Character.isLetter(c)) {
                return String.valueOf(c);
            }

            if (Character.isDigit(c)) {
                size /= (c - '0');
            } else {
                size--;
            }
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向推导**：避免展开整个字符串
2. **取模运算**：k %= size 处理重复
3. **长度缩减**：从后往前逐步缩小
