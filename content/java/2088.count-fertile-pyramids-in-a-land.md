## 题目描述

统计二进制矩阵中的肥沃金字塔和倒置金字塔总数。金字塔以(r,c)为顶向下扩展，每层左右各多一格。

## 解题思路

DP：dp[r][c]=以(r,c)为顶的最大金字塔高度=min(dp[r+1][c-1], dp[r+1][c], dp[r+1][c+1])+1。倒置金字塔翻转矩阵后同样处理。

## Java 代码实现

```java
class Solution {
    public int countPyramids(int[][] grid) {
        return count(grid) + count(reverse(grid));
    }
    
    private int[][] reverse(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] rev = new int[m][n];
        for (int i = 0; i < m; i++) {
            rev[i] = grid[m - 1 - i].clone();
        }
        return rev;
    }
    
    private int count(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        int total = 0;
        
        // 最后一行初始化
        for (int c = 0; c < n; c++) dp[m-1][c] = grid[m-1][c];
        
        // 从倒数第二行往上
        for (int r = m - 2; r >= 0; r--) {
            dp[r][0] = grid[r][0];
            dp[r][n-1] = grid[r][n-1];
            for (int c = 1; c < n - 1; c++) {
                if (grid[r][c] == 1) {
                    dp[r][c] = Math.min(dp[r+1][c-1], Math.min(dp[r+1][c], dp[r+1][c+1])) + 1;
                }
            }
        }
        
        // 统计：每个dp[r][c]贡献dp[r][c]-1个金字塔（高度2到dp[r][c]）
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (dp[r][c] > 1) total += dp[r][c] - 1;
            }
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N)
- **空间复杂度**：O(M × N)

## 关键点总结

1. **DP递推**：取下一行左中右最小值+1
2. **贡献计算**：dp[r][c]值贡献dp[r][c]-1个金字塔（高度≥2才算）
3. **倒置金字塔**：翻转矩阵后重复计算
