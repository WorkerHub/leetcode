## 题目描述

给你一个整数数组 nums，找到其中最长严格递增子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

**示例 1：**
```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4。
```

**示例 2：**
```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**
```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示：**
- 1 <= nums.length <= 2500
- -10^4 <= nums[i] <= 10^4

**进阶：**
- 你能将算法的时间复杂度降低到 O(n log n) 吗？

## 解题思路

这是一道经典的动态规划题目，也是面试高频题。

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 难度 |
|------|-----------|-----------|------|
| 动态规划 | O(n²) | O(n) | 中等 |
| 二分查找 + 贪心 | O(n log n) | O(n) | 较难 |

### 方法一：动态规划（容易理解）

**定义状态：**
- `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列的长度

**状态转移：**
```
dp[i] = max(dp[j] + 1)  其中 0 <= j < i 且 nums[j] < nums[i]
```

**初始化：**
- 每个元素自身可以构成长度为 1 的子序列：`dp[i] = 1`

### 方法二：二分查找 + 贪心（最优解）

**核心思想：**
维护一个数组 `tails`，其中 `tails[i]` 表示长度为 `i+1` 的递增子序列的最小末尾元素。

**关键观察：**
- 如果我们要让子序列尽可能长，应该让序列上升得尽可能慢
- 对于相同长度的递增子序列，末尾元素越小越好

**算法流程：**
1. 遍历数组中的每个数字 `num`
2. 在 `tails` 中二分查找第一个 >= `num` 的位置
3. 更新该位置的值为 `num`
4. 如果没找到（num 比所有元素都大），追加到末尾

## Java 代码实现

### 方法一：动态规划 O(n²)

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        // dp[i] 表示以 nums[i] 结尾的最长递增子序列长度
        int[] dp = new int[n];
        // 初始化：每个元素单独构成长度为 1 的子序列
        java.util.Arrays.fill(dp, 1);

        int maxLen = 1;

        for (int i = 1; i < n; i++) {
            // 检查 i 之前的所有元素
            for (int j = 0; j < i; j++) {
                // 如果 nums[j] < nums[i]，可以接在 j 后面
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }

        return maxLen;
    }
}
```

### 方法二：二分查找 + 贪心 O(n log n)（推荐）

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        // tails[i] 表示长度为 i+1 的递增子序列的最小末尾元素
        int[] tails = new int[nums.length];
        int size = 0; // tails 的有效长度

        for (int num : nums) {
            // 二分查找第一个 >= num 的位置
            int left = 0, right = size;
            while (left < right) {
                int mid = (left + right) / 2;
                if (tails[mid] < num) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            // left 就是第一个 >= num 的位置
            tails[left] = num;

            // 如果插入到末尾，说明子序列长度增加
            if (left == size) {
                size++;
            }
        }

        // tails 的有效长度就是最长递增子序列的长度
        return size;
    }
}
```

### 方法三：使用 ArrayList 的二分查找

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public int lengthOfLIS(int[] nums) {
        // 使用 ArrayList 存储 tails
        List<Integer> tails = new ArrayList<>();

        for (int num : nums) {
            // 二分查找第一个 >= num 的位置
            int pos = lowerBound(tails, num);

            if (pos == tails.size()) {
                // num 比所有元素都大，追加到末尾
                tails.add(num);
            } else {
                // 更新对应位置，用更小的值替换
                tails.set(pos, num);
            }
        }

        return tails.size();
    }

    // 查找第一个 >= target 的位置（等价于 Python 的 bisect_left）
    private int lowerBound(List<Integer> list, int target) {
        int left = 0, right = list.size();
        while (left < right) {
            int mid = (left + right) / 2;
            if (list.get(mid) < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```

### 方法四：带路径记录的 DP

```java
import java.util.Arrays;

class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        int[] parent = new int[n]; // 记录每个位置的前驱

        Arrays.fill(dp, 1);
        Arrays.fill(parent, -1);

        int maxLen = 1;
        int maxIdx = 0;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    parent[i] = j;
                }
            }
            if (dp[i] > maxLen) {
                maxLen = dp[i];
                maxIdx = i;
            }
        }

        // 重建路径
        int[] path = new int[maxLen];
        int idx = maxIdx;
        for (int i = maxLen - 1; i >= 0; i--) {
            path[i] = nums[idx];
            idx = parent[idx];
        }

        // 输出路径（调试用）
        System.out.println("最长递增子序列：" + Arrays.toString(path));
        return maxLen;
    }
}
```

## 复杂度分析

### 方法一（动态规划）：

**时间复杂度：** O(n²)
- 两层循环，外层 n 次，内层最多 n 次

**空间复杂度：** O(n)
- dp 数组

### 方法二（二分查找）：

**时间复杂度：** O(n log n)
- 遍历数组：O(n)
- 每次二分查找：O(log n)
- 总计：O(n log n)

**空间复杂度：** O(n)
- tails 数组最坏情况长度为 n

## 图解示例

示例：`nums = [10,9,2,5,3,7,101,18]`

### 动态规划过程：

```
初始化：dp = [1, 1, 1, 1, 1, 1, 1, 1]

i=0: nums[0]=10, dp[0]=1

i=1: nums[1]=9
  j=0: nums[0]=10 >= 9, 跳过
  dp[1]=1

i=2: nums[2]=2
  j=0,j=1: 都 >= 2, 跳过
  dp[2]=1

i=3: nums[3]=5
  j=2: nums[2]=2 < 5, dp[3] = max(1, dp[2]+1) = 2
  dp[3]=2, 序列：[2,5]

i=4: nums[4]=3
  j=2: nums[2]=2 < 3, dp[4] = max(1, dp[2]+1) = 2
  dp[4]=2, 序列：[2,3]

i=5: nums[5]=7
  j=3: nums[3]=5 < 7, dp[5] = max(1, 2+1) = 3
  dp[5]=3, 序列：[2,5,7] 或 [2,3,7]

i=6: nums[6]=101
  j=5: nums[5]=7 < 101, dp[6] = max(1, 3+1) = 4
  dp[6]=4, 序列：[2,5,7,101]

i=7: nums[7]=18
  j=5: nums[5]=7 < 18, dp[7] = max(1, 3+1) = 4
  dp[7]=4, 序列：[2,5,7,18]

最大值：max(dp) = 4
```

### 二分查找过程：

```
初始化：tails = [], size = 0

num=10: tails=[10], size=1
num=9:  查找 >= 9 的位置是 0，替换 tails=[9], size=1
num=2:  查找 >= 2 的位置是 0，替换 tails=[2], size=1
num=5:  查找 >= 5 的位置是 1（末尾），追加 tails=[2,5], size=2
num=3:  查找 >= 3 的位置是 1，替换 tails=[2,3], size=2
num=7:  查找 >= 7 的位置是 2（末尾），追加 tails=[2,3,7], size=3
num=101:查找 >= 101 的位置是 3（末尾），追加 tails=[2,3,7,101], size=4
num=18: 查找 >= 18 的位置是 3，替换 tails=[2,3,7,18], size=4

最终 size=4

注意：tails 不一定是实际的最长递增子序列，只是长度正确
```

## 关键点总结

1. **DP 定义**：`dp[i]` 是以 `nums[i]` 结尾的最长长度
2. **状态转移**：遍历所有 `j < i` 且 `nums[j] < nums[i]`，取最大值
3. **贪心思想**：对于相同长度的子序列，末尾元素越小越好
4. **二分优化**：维护的 tails 数组是单调递增的，可以二分查找
5. **lower_bound**：查找第一个 >= num 的位置（Java 中需手写）

## 易错点

1. **返回值错误**
   ```java
   // 错误：返回 dp[n-1]
   return dp[n - 1];
   // 最长子序列不一定以最后一个元素结尾
   
   // 正确：返回 max(dp)
   return maxLen; // 遍历时记录最大值
   ```

2. **严格递增理解**
   ```java
   // 错误：允许相等（非严格递增）
   if (nums[j] <= nums[i]) {
       dp[i] = Math.max(dp[i], dp[j] + 1);
   }
   
   // 正确：严格递增
   if (nums[j] < nums[i]) {
       dp[i] = Math.max(dp[i], dp[j] + 1);
   }
   ```

3. **二分查找边界（使用 bisect_left 等价）**
   ```java
   // 错误：使用 upper_bound（查找 > num 的位置）
   // 会跳过相等的元素，导致错误
   
   // 正确：使用 lower_bound（查找 >= num 的位置）
   // 保证严格递增（不允许相等）
   while (left < right) {
       int mid = (left + right) / 2;
       if (tails[mid] < num) { // 注意是严格小于
           left = mid + 1;
       } else {
           right = mid;
       }
   }
   ```

4. **tails 数组的理解**
   ```java
   // 错误理解：tails 就是最长递增子序列
   // tails 只保证长度正确，不保证就是实际的子序列
   
   // 正确理解：tails[i] 是长度为 i+1 的子序列的最小末尾元素
   // 例如 tails=[2,3,7,18] 并不代表 [2,3,7,18] 是一个合法子序列
   ```
