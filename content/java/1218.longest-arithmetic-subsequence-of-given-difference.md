## 题目描述

给定整数数组 arr 和整数 difference，返回 arr 中最长等差子序列的长度，该子序列相邻元素之差等于 difference。

**示例：**
```
输入：arr = [1,5,7,8,5,3,4,2,1], difference = -2
输出：4（子序列 [7,5,3,1]）
```

## 解题思路

用 HashMap 记录以每个数字结尾的最长等差子序列长度。对于当前元素 num，其前驱为 num - difference，状态转移：dp[num] = dp[num - difference] + 1。

## Java 代码实现

```java
class Solution {
    public int longestSubsequence(int[] arr, int difference) {
        // dp[num] = 以 num 结尾的最长等差子序列长度
        Map<Integer, Integer> dp = new HashMap<>();
        int maxLen = 1;
        
        for (int num : arr) {
            // 查找前驱元素
            int prev = num - difference;
            int len = dp.getOrDefault(prev, 0) + 1;
            dp.put(num, len);
            maxLen = Math.max(maxLen, len);
        }
        
        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **哈希表 DP**：dp[num] 存储以 num 结尾的最长序列长度
2. **O(1) 查找前驱**：num - difference 即为前一个元素
3. **单次遍历**：从左到右遍历，保证子序列顺序
4. **getOrDefault**：前驱不存在时默认为 0，当前元素自身长度为 1
