## 题目描述

给你整数数组 `nums`，可删除任意数量元素，使剩余元素各不相同，返回满足条件的剩余元素之和的最大值。

## 解题思路

贪心：若有正数，选所有不同正数（负数只会降低总和，不选）；若全为非正数，选最大值（即最接近 0 的那个）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxSum(int[] nums) {
        Set<Integer> positives = new HashSet<>();
        int maxVal = Integer.MIN_VALUE;

        for (int x : nums) {
            maxVal = Math.max(maxVal, x);
            if (x > 0) positives.add(x);
        }

        if (!positives.isEmpty()) {
            int sum = 0;
            for (int x : positives) sum += x;
            return sum;
        }

        // 全为非正数，选最大值（最多选 1 个）
        return maxVal;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 有正数时：所有不同正数均选，负数一个不选（负数只会拖累总和）
2. 全为非正数时：选最大的那个（最少损失）
3. 元素唯一性由 HashSet 天然保证（自动去重）
