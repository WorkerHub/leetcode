## 题目描述

删除链表中间节点（下标⌊n/2⌋），返回修改后的头节点。

## 解题思路

快慢指针：slow从dummy出发（得到前驱），fast从head出发每次两步。fast到底时slow.next即中间节点。

## Java 代码实现

```java
class Solution {
    public ListNode deleteMiddle(ListNode head) {
        if (head == null || head.next == null) return null;
        
        ListNode dummy = new ListNode(0, head);
        ListNode slow = dummy, fast = head;
        
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // slow.next 是中间节点
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **dummy节点**：slow从dummy出发得到中间节点前驱
2. **快慢指针**：fast走两步slow走一步
3. **边界**：单节点链表删除后返回null
