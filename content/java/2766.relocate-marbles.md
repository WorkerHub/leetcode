## 题目描述

给你弹珠位置数组 `nums` 和移动操作数组 `moveFrom`、`moveTo`，将 `moveFrom[i]` 位置的所有弹珠移到 `moveTo[i]`，返回操作后所有弹珠位置（升序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> relocateMarbles(int[] nums, int[] moveFrom, int[] moveTo) {
        Set<Integer> positions = new HashSet<>();
        for (int x : nums) positions.add(x);
        for (int i = 0; i < moveFrom.length; i++) {
            if (moveFrom[i] != moveTo[i]) {
                positions.remove(moveFrom[i]);
                positions.add(moveTo[i]);
            }
        }
        List<Integer> ans = new ArrayList<>(positions);
        Collections.sort(ans);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，排序 O(n log n)，操作 O(q)
- 空间复杂度：O(n)

## 关键点总结

1. 集合自动处理重复位置
2. `src == dst` 时不需要操作
3. 最终排序返回
