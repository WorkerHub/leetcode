## 题目描述

将数字字符串按k分组求各组数字之和拼接，重复直到长度<=k。

## 解题思路

模拟：每轮将字符串按k分组，每组各字符数字求和转字符串拼接，直到结果长度不超过k。

## Java 代码实现

```java
class Solution {
    public String digitSum(String s, int k) {
        while (s.length() > k) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < s.length(); i += k) {
                int sum = 0;
                for (int j = i; j < Math.min(i + k, s.length()); j++) {
                    sum += s.charAt(j) - '0';
                }
                sb.append(sum);
            }
            s = sb.toString();
        }
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * log_k(N))
- **空间复杂度**：O(N)

## 关键点总结

1. **逐组求和**：每个字符是0-9的数字，组和可能是多位数
2. **重复直到长度<=k**：可能需要多轮
3. **最后一组可能不足k个**：自然截断
