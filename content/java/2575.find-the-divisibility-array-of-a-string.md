## 题目描述

给你数字字符串 `word` 和正整数 `m`，返回可整除性数组：若前缀 `word[0..i]` 所表示的数能被 `m` 整除则为 1，否则为 0。

## 解题思路

逐位维护余数：`remainder = (remainder * 10 + digit) % m`，避免大数运算，余数为 0 则对应位置为 1。

## Java 代码实现

```java
class Solution {
    public int[] divisibilityArray(String word, int m) {
        int n = word.length();
        int[] div = new int[n];
        long remainder = 0;
        for (int i = 0; i < n; i++) {
            remainder = (remainder * 10 + (word.charAt(i) - '0')) % m;
            div[i] = remainder == 0 ? 1 : 0;
        }
        return div;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 逐位取模：`(r * 10 + d) % m` 等价于前缀数字模 m
2. 使用 `long` 避免 `r * 10` 溢出（m 最大 10^9）
3. 余数为 0 时前缀数可被 m 整除
