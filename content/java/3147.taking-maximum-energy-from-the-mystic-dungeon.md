## 题目描述

`n` 个法师站成一排，能量值为 `energy[i]`，从某个下标出发每次向后跳 `k` 步收集能量，返回可收集的**最大**能量值。

## 解题思路

从后往前计算后缀和：`suffix[i] = energy[i] + suffix[i+k]`（若 `i+k` 越界则只取 `energy[i]`）。答案为最后 `k` 个位置后缀和的最大值（每个起点对应一种路径）。

## Java 代码实现

```java
class Solution {
    public int maximumEnergy(int[] energy, int k) {
        int n = energy.length;
        int[] suffix = energy.clone();
        // 从后往前累加后缀和
        for (int i = n - k - 1; i >= 0; i--) {
            suffix[i] += suffix[i + k];
        }
        // 起点只有 k 种（下标 n-k 到 n-1）
        int ans = Integer.MIN_VALUE;
        for (int i = n - k; i < n; i++) {
            ans = Math.max(ans, suffix[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举 k 个可能的起始位置（下标 n-k 到 n-1）
2. 用后缀和避免重复计算，从后往前递推
3. 能量值可能为负，初始化答案为 `Integer.MIN_VALUE`
