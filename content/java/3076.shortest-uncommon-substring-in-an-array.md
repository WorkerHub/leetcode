## 题目描述

对数组中每个字符串，找出最短的不是其他任何字符串子串的子字符串（多个最短则取字典序最小），不存在则返回空串。

## 解题思路

预处理每个子字符串出现在哪些字符串中，对每个字符串枚举长度从短到长的子串（按字典序），找第一个只属于当前字符串的子串。

## Java 代码实现

```java
class Solution {
    public String[] shortestSubstrings(String[] arr) {
        int n = arr.length;
        // 统计每个子字符串出现在哪些字符串中
        Map<String, Set<Integer>> subMap = new HashMap<>();
        for (int i = 0; i < n; i++) {
            String s = arr[i];
            int len = s.length();
            for (int l = 1; l <= len; l++) {
                for (int start = 0; start + l <= len; start++) {
                    String sub = s.substring(start, start + l);
                    subMap.computeIfAbsent(sub, k -> new HashSet<>()).add(i);
                }
            }
        }

        String[] result = new String[n];
        for (int i = 0; i < n; i++) {
            String s = arr[i];
            String best = "";
            outer:
            for (int l = 1; l <= s.length(); l++) {
                // 收集当前长度的所有候选子串（字典序排序）
                TreeSet<String> candidates = new TreeSet<>();
                for (int start = 0; start + l <= s.length(); start++) {
                    candidates.add(s.substring(start, start + l));
                }
                for (String sub : candidates) {
                    // 只出现在第 i 个字符串中
                    if (subMap.get(sub).size() == 1) {
                        best = sub;
                        break outer;
                    }
                }
            }
            result[i] = best;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L^3)，n 个字符串，L 为最大长度
- **空间复杂度**：O(n * L^2)，存储子串集合

## 关键点总结

1. 枚举所有子字符串，按长度优先、字典序其次排序
2. 找第一个只属于当前字符串的子字符串（出现的字符串集合大小为 1）
3. TreeSet 自动保证字典序排序
