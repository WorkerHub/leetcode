## 题目描述

给定 n 和 start，返回 [0, 2^n - 1] 的一个排列 p，满足：p[0] = start，相邻元素（含首尾）的二进制只有一位不同。

**示例：**
```
输入：n = 2, start = 3
输出：[3,2,0,1]（二进制 11→10→00→01）
```

## 解题思路

本质是格雷码的变形。标准格雷码 gray(i) = i ^ (i >> 1)。将整个序列与 start 异或即可使起始值变为 start，且保持相邻元素仅一位不同的性质。

## Java 代码实现

```java
class Solution {
    public List<Integer> circularPermutation(int n, int start) {
        List<Integer> result = new ArrayList<>();
        int total = 1 << n;
        for (int i = 0; i < total; i++) {
            // 格雷码与 start 异或
            result.add(start ^ i ^ (i >> 1));
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n)
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **格雷码公式**：gray(i) = i ^ (i >> 1)
2. **异或平移**：与 start 异或使序列从 start 开始
3. **异或保持性质**：a^c 和 b^c 的汉明距离等于 a 和 b 的汉明距离
4. **循环性**：格雷码首尾也只差一位
