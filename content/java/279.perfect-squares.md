## 题目描述

给你一个整数 n，返回和为 n 的完全平方数的最少数量。

完全平方数是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

**示例 1：**
```
输入: n = 12
输出: 3 
解释: 12 = 4 + 4 + 4
```

**示例 2：**
```
输入: n = 13
输出: 2
解释: 13 = 4 + 9
```

**提示：**
- 1 <= n <= 10^4

## 解题思路

这道题有多种解法，从动态规划到 BFS，再到数学定理。

### 思路一：动态规划

定义 `dp[i]` 为和为 i 的完全平方数的最少数量。

**状态转移：**
- 对于每个 i，尝试所有可能的完全平方数 j^2（j^2 <= i）
- `dp[i] = min(dp[i - j^2] + 1)` for all j where j^2 <= i

**初始状态：**
- `dp[0] = 0`
- `dp[i] = i`（最坏情况，i 个 1）

### 思路二：BFS（广度优先搜索）

将问题看作图的最短路径：
- 从 0 开始，每次可以加上一个完全平方数
- 目标是到达 n，求最少步数

### 思路三：数学定理（四平方和定理）

**拉格朗日四平方和定理：** 任何正整数都可以表示为至多 4 个完全平方数的和。

进一步优化：
- 如果 n 本身是完全平方数，答案是 1
- 如果 n = 4^k * (8m + 7)，答案是 4
- 否则，检查能否用 2 个完全平方数表示，不能则答案是 3

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int numSquares(int n) {
        // 初始化 dp 数组，dp[i] 表示和为 i 的完全平方数的最少数量
        int[] dp = new int[n + 1];
        // 初始化为最坏情况（i 个 1 相加）
        for (int i = 1; i <= n; i++) {
            dp[i] = i;
        }
        // dp[0] = 0

        // 状态转移
        for (int i = 1; i <= n; i++) {
            // 尝试所有完全平方数 j*j <= i
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}
```

### 方法二：优化的动态规划（预计算完全平方数）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int numSquares(int n) {
        // 预计算所有可能的完全平方数
        List<Integer> squares = new ArrayList<>();
        for (int i = 1; i * i <= n; i++) {
            squares.add(i * i);
        }

        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = Integer.MAX_VALUE;
            for (int sq : squares) {
                if (sq > i) break;
                if (dp[i - sq] + 1 < dp[i]) {
                    dp[i] = dp[i - sq] + 1;
                }
            }
        }

        return dp[n];
    }
}
```

### 方法三：BFS（广度优先搜索）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public int numSquares(int n) {
        // 预计算完全平方数
        List<Integer> squares = new ArrayList<>();
        for (int i = 1; i * i <= n; i++) {
            squares.add(i * i);
        }

        // BFS，visited 标记已访问的和
        boolean[] visited = new boolean[n + 1];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        visited[0] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();

            // 逐层遍历
            for (int i = 0; i < size; i++) {
                int cur = queue.poll();

                // 尝试加上每个完全平方数
                for (int sq : squares) {
                    int next = cur + sq;
                    if (next == n) return steps;
                    if (next < n && !visited[next]) {
                        visited[next] = true;
                        queue.offer(next);
                    }
                }
            }
        }

        return steps;
    }
}
```

### 方法四：数学方法（四平方和定理）

```java
class Solution {
    public int numSquares(int n) {
        // 情况 1: n 本身是完全平方数
        if (isPerfectSquare(n)) return 1;

        // 情况 2: n = 4^k * (8m + 7)，答案是 4
        int temp = n;
        while (temp % 4 == 0) {
            temp /= 4;
        }
        if (temp % 8 == 7) return 4;

        // 情况 3: 检查是否可以用 2 个完全平方数表示
        for (int i = 1; (long) i * i <= n; i++) {
            if (isPerfectSquare(n - i * i)) return 2;
        }

        // 情况 4: 需要 3 个完全平方数
        return 3;
    }

    private boolean isPerfectSquare(int x) {
        int sqrt = (int) Math.sqrt(x);
        return sqrt * sqrt == x;
    }
}
```

### 方法五：记忆化递归

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<Integer, Integer> memo = new HashMap<>();

    public int numSquares(int n) {
        return dfs(n);
    }

    private int dfs(int remain) {
        if (remain == 0) return 0;
        if (memo.containsKey(remain)) return memo.get(remain);

        int minCount = Integer.MAX_VALUE;
        // 尝试所有完全平方数
        for (int j = 1; j * j <= remain; j++) {
            minCount = Math.min(minCount, dfs(remain - j * j) + 1);
        }

        memo.put(remain, minCount);
        return minCount;
    }
}
```

## 复杂度分析

### 方法一、二：动态规划

**时间复杂度：** O(n * √n)
- 外层循环 n 次
- 内层循环 √n 次（所有完全平方数）

**空间复杂度：** O(n)
- dp 数组

### 方法三：BFS

**时间复杂度：** O(n * √n)
- 最坏情况访问所有节点
- 每个节点尝试 √n 个完全平方数

**空间复杂度：** O(n)
- 队列和 visited 数组

### 方法四：数学方法

**时间复杂度：** O(√n)
- 检查是否可以用 2 个平方数表示

**空间复杂度：** O(1)

## 关键点总结

1. **动态规划思路**：和为 i 的方案 = min(和为 i-j^2 的方案 + 1)
2. **BFS 思路**：将问题转化为图的最短路径
3. **数学优化**：利用四平方和定理，答案只可能是 1、2、3 或 4
4. **完全平方数的范围**：只需考虑 <= n 的完全平方数（最多 √n 个）
5. **Java 注意**：
   - `isPerfectSquare` 使用 `(int) Math.sqrt(x)` 再验证，避免浮点误差
   - 数学方法中检查 `(long) i * i <= n` 防止溢出

## 易错点

1. **dp 初始化**
   ```java
   // 错误：初始化为 0
   int[] dp = new int[n + 1];
   
   // 正确：初始化为最坏情况（i 个 1）
   for (int i = 1; i <= n; i++) dp[i] = i;
   ```

2. **完全平方数的遍历**
   ```java
   // 优化：j*j <= i 时退出
   for (int j = 1; j * j <= i; j++) {
       dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
   }
   ```

3. **BFS 中的访问标记**
   ```java
   // 必须标记访问过的节点，避免重复
   if (next < n && !visited[next]) {
       visited[next] = true;
       queue.offer(next);
   }
   ```

4. **数学方法的浮点误差**
   ```java
   // 正确的完全平方数判断
   private boolean isPerfectSquare(int x) {
       int sqrt = (int) Math.sqrt(x);
       return sqrt * sqrt == x;  // 精确比较，避免浮点误差
   }
   ```
