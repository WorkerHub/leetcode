## 题目描述

给定数组 `nums` 和 `target`（长度 <= 4），每次可将 `nums` 任意元素加 1，返回使 `target` 中每个元素都有 `nums` 中某个元素是其倍数所需的最少操作数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumIncrements(int[] nums, int[] target) {
        int m = target.length;
        int full = (1 << m) - 1;

        // 预计算每个子集的 LCM
        long[] lcmMask = new long[1 << m];
        lcmMask[0] = 1;
        for (int mask = 1; mask <= full; mask++) {
            int idx = Integer.numberOfTrailingZeros(mask);
            lcmMask[mask] = lcm(lcmMask[mask & (mask - 1)], target[idx]);
        }

        long INF = Long.MAX_VALUE / 2;
        long[] dp = new long[1 << m];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int v : nums) {
            // 计算 v 覆盖每个非空子集的最小代价（增加到 LCM 的倍数）
            long[] cost = new long[1 << m];
            for (int mask = 1; mask <= full; mask++) {
                long L = lcmMask[mask];
                long rem = v % L;
                cost[mask] = (rem == 0) ? 0 : L - rem;
            }

            // 枚举每个已覆盖集合，加上 v 覆盖新子集
            long[] newDp = dp.clone();
            for (int state = 0; state <= full; state++) {
                if (dp[state] >= INF) continue;
                // 枚举 v 额外覆盖的补集子集
                int complement = full ^ state;
                for (int sub = complement; sub > 0; sub = (sub - 1) & complement) {
                    int newState = state | sub;
                    long val = dp[state] + cost[sub];
                    if (val < newDp[newState]) newDp[newState] = val;
                }
            }
            dp = newDp;
        }

        return dp[full];
    }

    private long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }
    private long lcm(long a, long b) { return a / gcd(a, b) * b; }
}
```

## 复杂度分析

- 时间复杂度：O(n * 3^m)，m = target.length <= 4
- 空间复杂度：O(2^m)

## 关键点总结

1. 覆盖多个 target 元素时需增加到这些元素 LCM 的倍数
2. 位掩码 DP：`dp[mask]` = 覆盖 mask 对应 target 元素的最少代价
3. 枚举补集子集：`for (int sub = complement; sub > 0; sub = (sub-1) & complement)`
