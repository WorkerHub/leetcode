## 题目描述

给你整数数组 `nums`，返回按位 AND 结果最大的子数组中最长子数组的长度。

## 解题思路

子数组按位 AND 的最大值等于数组最大值本身（单元素子数组）。包含非最大值元素的子数组 AND 结果必然更小，因此问题转化为：找由最大值构成的最长连续子数组。

## Java 代码实现

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int maxVal = 0;
        // 找数组最大值
        for (int x : nums) maxVal = Math.max(maxVal, x);

        int ans = 0, cur = 0;
        for (int x : nums) {
            if (x == maxVal) {
                cur++;             // 连续最大值长度加一
                ans = Math.max(ans, cur);
            } else {
                cur = 0;           // 连续中断，重置
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. AND 操作的最大值就是数组的最大值（单元素子数组即可达到）
2. 任何包含非最大值的子数组，AND 值必然小于最大值
3. 问题简化为找由最大值组成的最长连续子数组
