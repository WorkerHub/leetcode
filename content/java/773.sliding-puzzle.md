## 题目描述

在一个 `2 x 3` 的板上有 5 块砖瓦，用数字 `1~5` 来表示, 以及一块空缺用 `0` 来表示。一次移动定义为选择 `0` 与一个相邻的数字（上下左右）进行交换。

最终当板 `board` 的结果是 `[[1,2,3],[4,5,0]]` 时，谜板被解开。

给出一个谜板的初始状态，返回最少可以通过多少次移动解开谜板，如果不能解开谜板，则返回 `-1`。

**示例 1:**
```
输入：board = [[1,2,3],[4,0,5]]
输出：1
解释：交换 0 和 5，一次移动完成
```

**示例 2:**
```
输入：board = [[1,2,3],[5,4,0]]
输出：-1
解释：没有办法完成谜板
```

## 解题思路

使用 BFS 搜索所有可能的状态，直到找到目标状态。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int slidingPuzzle(int[][] board) {
        // 将二维数组转为字符串表示状态
        StringBuilder sb = new StringBuilder();
        for (int[] row : board) {
            for (int num : row) sb.append(num);
        }
        String start = sb.toString();
        String target = "123450";

        // 每个位置可以交换的相邻位置（线性索引）
        int[][] neighbors = {
            {1, 3},       // 位置 0
            {0, 2, 4},    // 位置 1
            {1, 5},       // 位置 2
            {0, 4},       // 位置 3
            {1, 3, 5},    // 位置 4
            {2, 4}        // 位置 5
        };

        // BFS
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        queue.offer(start);
        visited.add(start);
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int s = 0; s < size; s++) {
                String state = queue.poll();

                if (state.equals(target)) return steps;

                // 找到 '0' 的位置
                int zeroPos = state.indexOf('0');

                // 尝试所有可能的移动
                for (int nextPos : neighbors[zeroPos]) {
                    char[] stateArr = state.toCharArray();
                    // 交换
                    char temp = stateArr[zeroPos];
                    stateArr[zeroPos] = stateArr[nextPos];
                    stateArr[nextPos] = temp;
                    String newState = new String(stateArr);

                    if (!visited.contains(newState)) {
                        visited.add(newState);
                        queue.offer(newState);
                    }
                }
            }
            steps++;
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度：** O((m*n)! * m*n)
- **空间复杂度：** O((m*n)!)

## 关键点总结

1. **状态表示：** 用字符串表示状态
2. **BFS 搜索：** 寻找最短路径
3. **邻居关系：** 预先定义每个位置的邻居
