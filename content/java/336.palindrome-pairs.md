## 题目描述

给定一组**互不相同**的单词，找出所有**不同**的索引对 `(i, j)`，使得列表中的两个单词，`words[i] + words[j]`，可拼接成回文串。

**示例 1:**

```
输入：words = ["abcd","dcba","lls","s","sssll"]
输出：[[0,1],[1,0],[3,2],[2,4]]
解释：可拼接成的回文串为 ["dcbaabcd","abcddcba","slls","llssssll"]
```

**示例 2:**

```
输入：words = ["bat","tab","cat"]
输出：[[0,1],[1,0]]
解释：可拼接成的回文串为 ["battab","tabbat"]
```

**示例 3:**

```
输入：words = ["a",""]
输出：[[0,1],[1,0]]
```

**提示:**

- `1 <= words.length <= 5000`
- `0 <= words[i].length <= 300`
- `words[i]` 由小写英文字母组成

## 解题思路

暴力解法是 O(n² * k)，其中 n 是单词数，k 是单词长度。我们需要优化。

### 核心思想

对于单词 `s`，如果 `s + t` 是回文串，则：
1. **情况 1**：`s` 的某个前缀是回文，`t` 是 `s` 剩余部分的翻转
2. **情况 2**：`s` 的某个后缀是回文，`t` 是 `s` 剩余部分的翻转
3. **情况 3**：`s` 本身是回文，`t` 是空串或者空串是回文

### 算法思路

1. **构建哈希表**：将所有单词及其索引存入哈希表
2. **遍历每个单词**：
   - 将单词分成前缀和后缀
   - **情况 1**：如果前缀是回文，查找后缀的翻转是否存在
   - **情况 2**：如果后缀是回文，查找前缀的翻转是否存在
3. **去重**：避免重复的配对

## Java 代码实现

### 方法一：哈希表 + 枚举分割点（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<List<Integer>> palindromePairs(String[] words) {
        // 构建单词到索引的映射
        Map<String, Integer> wordMap = new HashMap<>();
        for (int i = 0; i < words.length; i++) {
            wordMap.put(words[i], i);
        }

        List<List<Integer>> result = new ArrayList<>();

        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            int len = word.length();

            // 枚举所有分割点
            for (int j = 0; j <= len; j++) {
                String prefix = word.substring(0, j);
                String suffix = word.substring(j);

                // 情况 1: 前缀是回文，查找后缀的翻转
                if (isPalindrome(prefix)) {
                    String reversedSuffix = new StringBuilder(suffix).reverse().toString();
                    if (wordMap.containsKey(reversedSuffix) && wordMap.get(reversedSuffix) != i) {
                        result.add(Arrays.asList(wordMap.get(reversedSuffix), i));
                    }
                }

                // 情况 2: 后缀是回文，查找前缀的翻转
                // 注意：j != len 避免重复（当 j == len 时，suffix 为空，会和情况 1 重复）
                if (j != len && isPalindrome(suffix)) {
                    String reversedPrefix = new StringBuilder(prefix).reverse().toString();
                    if (wordMap.containsKey(reversedPrefix) && wordMap.get(reversedPrefix) != i) {
                        result.add(Arrays.asList(i, wordMap.get(reversedPrefix)));
                    }
                }
            }
        }

        return result;
    }

    private boolean isPalindrome(String s) {
        // 双指针判断回文
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

### 方法二：字典树（Trie）解法

```java
import java.util.*;

class Solution {
    // 字典树节点
    static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int wordIndex = -1;  // 单词索引，-1 表示不是单词结尾
        List<Integer> palindromeSuffixes = new ArrayList<>();  // 以当前节点为前缀的回文后缀索引
    }

    public List<List<Integer>> palindromePairs(String[] words) {
        TrieNode root = new TrieNode();

        // 构建字典树（插入翻转的单词）
        for (int i = 0; i < words.length; i++) {
            insert(root, new StringBuilder(words[i]).reverse().toString(), i, words[i]);
        }

        List<List<Integer>> result = new ArrayList<>();

        // 查找配对
        for (int i = 0; i < words.length; i++) {
            search(root, words[i], i, result);
        }

        return result;
    }

    private void insert(TrieNode root, String reversedWord, int index, String originalWord) {
        TrieNode node = root;
        for (int j = 0; j < reversedWord.length(); j++) {
            // 如果原单词剩余部分（从 j 开始）是回文，记录当前单词索引
            if (isPalindrome(originalWord, 0, originalWord.length() - 1 - j)) {
                node.palindromeSuffixes.add(index);
            }

            int c = reversedWord.charAt(j) - 'a';
            if (node.children[c] == null) {
                node.children[c] = new TrieNode();
            }
            node = node.children[c];
        }
        node.wordIndex = index;
        node.palindromeSuffixes.add(index);
    }

    private void search(TrieNode root, String word, int index, List<List<Integer>> result) {
        TrieNode node = root;
        for (int j = 0; j < word.length(); j++) {
            // 情况 1: 匹配到一个完整单词，且剩余部分是回文
            if (node.wordIndex != -1 && node.wordIndex != index) {
                if (isPalindrome(word, j, word.length() - 1)) {
                    result.add(Arrays.asList(index, node.wordIndex));
                }
            }

            int c = word.charAt(j) - 'a';
            if (node.children[c] == null) return;
            node = node.children[c];
        }

        // 情况 2: word 全部匹配完
        // 找到所有以当前节点为前缀的回文后缀
        for (int suffixIndex : node.palindromeSuffixes) {
            if (suffixIndex != index) {
                result.add(Arrays.asList(index, suffixIndex));
            }
        }
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

### 方法三：暴力解法（会超时）

```java
import java.util.*;

class Solution {
    public List<List<Integer>> palindromePairs(String[] words) {
        // 暴力解法：O(n² * k)
        List<List<Integer>> result = new ArrayList<>();
        int n = words.length;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i != j) {
                    String combined = words[i] + words[j];
                    String reversed = new StringBuilder(combined).reverse().toString();
                    if (combined.equals(reversed)) {
                        result.add(Arrays.asList(i, j));
                    }
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

**方法一：哈希表**

- **时间复杂度**：O(n * k²)
  - n：单词数
  - k：单词平均长度
  - 每个单词枚举 k 个分割点，每次判断回文 O(k)
  
- **空间复杂度**：O(n * k)
  - 哈希表存储所有单词

**方法二：字典树**

- **时间复杂度**：O(n * k²)
  - 构建字典树：O(n * k²)
  - 查找：O(n * k²)
  
- **空间复杂度**：O(n * k)
  - 字典树的空间

**方法三：暴力解法**

- **时间复杂度**：O(n² * k)
  - 双层循环 O(n²)，每次判断回文 O(k)
  
- **空间复杂度**：O(1)

## 关键点总结

1. **核心思想**：将单词分成前缀和后缀，分别判断回文
2. **两种情况**：
   - 前缀是回文，找后缀的翻转
   - 后缀是回文，找前缀的翻转
3. **去重技巧**：`j != len` 避免重复
4. **哈希表优化**：O(1) 查找翻转的单词
5. **字典树优化**：适合大量单词的场景

## 易错点

1. **重复配对**：
   - 情况 2 需要 `j != len` 避免重复
   - 当 `j == len` 时，suffix 为空，会和情况 1 重复

2. **自身配对**：
   - 要检查 `wordMap.get(reversedSuffix) != i`
   - 避免一个单词和自己配对

3. **空字符串处理**：
   - 空字符串是回文
   - 空字符串可以和任何回文单词配对

4. **索引顺序**：
   - `[wordMap.get(reversedSuffix), i]`：reversed 在前
   - `[i, wordMap.get(reversedPrefix)]`：i 在前

5. **字符串比较**：Java 中字符串比较必须用 `equals()`，不能用 `==`

```
对于 "lls" (索引 2)：
  
分割点 j=0: prefix="", suffix="lls"
  - prefix 是回文 ✓
  - suffix 翻转 = "sll"，不在字典中

分割点 j=1: prefix="l", suffix="ls"
  - prefix 是回文 ✓
  - suffix 翻转 = "sl"，不在字典中

分割点 j=2: prefix="ll", suffix="s"
  - prefix 是回文 ✓

  - 添加配对 [3, 2] → "s" + "lls" = "slls" ✓

分割点 j=3: prefix="lls", suffix=""
  - suffix 是回文 ✓
  - prefix 翻转 = "sll"，不在字典中
```
