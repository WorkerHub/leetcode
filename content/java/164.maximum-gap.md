## 题目描述

给定一个无序的数组 `nums`，返回数组在排序之后，相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 0。

你必须编写一个在「线性时间」内运行并使用「线性额外空间」的算法。

**示例 1：**
```
输入：nums = [3,6,9,1]
输出：3
解释：排序后的数组是 [1,3,6,9]，其中相邻元素 (3,6) 和 (6,9) 之间都存在最大差值 3。
```

**示例 2：**
```
输入：nums = [10]
输出：0
解释：数组元素个数小于 2，因此返回 0。
```

**提示：**
- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^9

## 解题思路

题目要求线性时间 O(n) 和线性空间 O(n)，这排除了比较排序（O(n log n)）。

### 思路一：桶排序（推荐）⭐

**核心思想：**

1. **鸽巢原理**：n 个数分布在 [min, max] 范围内，如果均匀分布，相邻元素的平均间距是 `(max - min) / (n - 1)`

2. **关键观察**：
   - 最大间距至少是平均间距
   - 如果使用桶大小等于平均间距，最大间距不会出现在桶内，只会出现在桶与桶之间
   - 只需比较相邻非空桶之间的间距

**算法流程：**

1. 找到数组的最小值 minVal 和最大值 maxVal
2. 如果 minVal == maxVal，返回 0（所有元素相同）
3. 计算桶的大小：bucketSize = max(1, (maxVal - minVal) / (n - 1))
4. 计算桶的数量：bucketCount = (maxVal - minVal) / bucketSize + 1
5. 为每个桶记录其中的最小值和最大值
6. 遍历所有数字，放入对应的桶
7. 遍历桶，计算相邻非空桶之间的间距（当前桶的最小值 - 前一个桶的最大值）

### 思路二：基数排序

使用基数排序在 O(n) 时间内排序，然后遍历找最大间距。

### 思路三：直接排序（不满足时间要求）

使用内置排序 O(n log n)，然后遍历找最大间距。虽然不满足题目要求，但可以作为对比。

## Java 代码实现

### 方法一：桶排序（推荐）⭐

```java
class Solution {
    public int maximumGap(int[] nums) {
        int n = nums.length;
        if (n < 2) return 0;

        // 找到最小值和最大值
        int minVal = nums[0], maxVal = nums[0];
        for (int num : nums) {
            minVal = Math.min(minVal, num);
            maxVal = Math.max(maxVal, num);
        }

        // 所有元素相同
        if (minVal == maxVal) return 0;

        // 计算桶的大小和数量
        // 桶大小至少为 1，最大为平均间距
        int bucketSize = Math.max(1, (maxVal - minVal) / (n - 1));
        int bucketCount = (maxVal - minVal) / bucketSize + 1;

        // 初始化桶，每个桶记录其中的最小值和最大值
        int[] bucketMin = new int[bucketCount];
        int[] bucketMax = new int[bucketCount];
        boolean[] bucketUsed = new boolean[bucketCount];
        Arrays.fill(bucketMin, Integer.MAX_VALUE);
        Arrays.fill(bucketMax, Integer.MIN_VALUE);

        // 将每个数字放入对应的桶
        for (int num : nums) {
            // 计算桶索引
            int idx = (num - minVal) / bucketSize;
            bucketUsed[idx] = true;
            bucketMin[idx] = Math.min(bucketMin[idx], num);
            bucketMax[idx] = Math.max(bucketMax[idx], num);
        }

        // 计算最大间距
        int maxGap = 0;
        int prevMax = minVal; // 前一个非空桶的最大值

        for (int i = 0; i < bucketCount; i++) {
            // 跳过空桶
            if (!bucketUsed[i]) continue;

            // 当前桶的最小值 - 前一个桶的最大值
            maxGap = Math.max(maxGap, bucketMin[i] - prevMax);

            // 更新前一个桶的最大值
            prevMax = bucketMax[i];
        }

        return maxGap;
    }
}
```

### 方法二：基数排序

```java
class Solution {
    public int maximumGap(int[] nums) {
        int n = nums.length;
        if (n < 2) return 0;

        // 基数排序
        radixSort(nums);

        // 找最大间距
        int maxGap = 0;
        for (int i = 1; i < n; i++) {
            maxGap = Math.max(maxGap, nums[i] - nums[i - 1]);
        }

        return maxGap;
    }

    private void radixSort(int[] nums) {
        int n = nums.length;
        int[] output = new int[n];

        // 找到最大值，确定位数
        int maxVal = nums[0];
        for (int num : nums) {
            maxVal = Math.max(maxVal, num);
        }

        // 从个位开始，逐位排序
        for (int exp = 1; maxVal / exp > 0; exp *= 10) {
            countingSort(nums, output, exp);
        }
    }

    private void countingSort(int[] nums, int[] output, int exp) {
        int n = nums.length;
        int[] count = new int[10]; // 0-9 十个桶

        // 统计每个数字在当前位上的出现次数
        for (int num : nums) {
            int digit = (num / exp) % 10;
            count[digit]++;
        }

        // 计算累计次数
        for (int i = 1; i < 10; i++) {
            count[i] += count[i - 1];
        }

        // 从后向前遍历，保证稳定性
        for (int i = n - 1; i >= 0; i--) {
            int digit = (nums[i] / exp) % 10;
            output[count[digit] - 1] = nums[i];
            count[digit]--;
        }

        // 复制回原数组
        System.arraycopy(output, 0, nums, 0, n);
    }
}
```

### 方法三：直接排序（不满足要求）

```java
class Solution {
    public int maximumGap(int[] nums) {
        int n = nums.length;
        if (n < 2) return 0;

        // 排序（不满足线性时间要求）
        Arrays.sort(nums);

        // 找最大间距
        int maxGap = 0;
        for (int i = 1; i < n; i++) {
            maxGap = Math.max(maxGap, nums[i] - nums[i - 1]);
        }

        return maxGap;
    }
}
```

## 复杂度分析

**方法一（桶排序）：**
- 时间复杂度：O(n)，遍历数组常数次
- 空间复杂度：O(n)，桶的数量最多为 n

**方法二（基数排序）：**
- 时间复杂度：O(d * n)，其中 d 是最大数字的位数，对于 32 位整数 d 是常数，所以是 O(n)
- 空间复杂度：O(n)

**方法三（直接排序）：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(1) 或 O(n)

## 图解示例

示例：nums = [3, 6, 9, 1]

```
原数组：[3, 6, 9, 1]
minVal = 1, maxVal = 9, n = 4

桶大小：(9 - 1) / (4 - 1) = 8 / 3 = 2（向下取整）
桶数量：(9 - 1) / 2 + 1 = 5

数字分配：
1: 桶0 (1-1)/2 = 0  → buckets[0] = [1, 1]
3: 桶1 (3-1)/2 = 1  → buckets[1] = [3, 3]
6: 桶2 (6-1)/2 = 2  → buckets[2] = [6, 6]
9: 桶4 (9-1)/2 = 4  → buckets[4] = [9, 9]

桶状态：
桶0: [1, 1]
桶1: [3, 3]
桶2: [6, 6]
桶3: 空
桶4: [9, 9]

计算间距：
桶0 → 桶1: 3 - 1 = 2
桶1 → 桶2: 6 - 3 = 3
桶2 → 桶4: 9 - 6 = 3

最大间距：3
```

## 关键点总结

1. **鸽巢原理**：n 个数分成 n-1 个桶，必有空桶，最大间距在桶之间
2. **桶大小选择**：使用平均间距，确保最大间距不在桶内
3. **只记录最值**：每个桶只需记录最小值和最大值
4. **跳过空桶**：空桶不影响结果
5. **线性时间**：桶排序和基数排序都能达到 O(n)

## 易错点

1. **边界情况**：n < 2 或所有元素相同时返回 0
2. **桶大小为 0**：当 maxVal == minVal 时需要特殊处理
3. **桶索引计算**：`(num - minVal) / bucketSize`
4. **空桶处理**：遍历桶时需要跳过空桶（使用 bucketUsed 数组标记）
5. **初始化 prevMax**：应该初始化为 minVal，而不是第一个桶的最大值
