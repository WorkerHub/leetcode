## 题目描述

Alice 和 Bob 轮流取石子（Alice 先手），每次可从任意非空堆取至少 1 颗，取走最后一颗者获胜，给你石子堆数组 `piles`，双方最优策略下 Alice 能赢则返回 `true`。

## 解题思路

Nim 游戏定理：所有堆异或和不为 0 则先手必胜，异或和为 0 则先手必败。

## Java 代码实现

```java
class Solution {
    public boolean nimGame(int[] piles) {
        // 计算所有堆的异或和
        int xorSum = 0;
        for (int p : piles) xorSum ^= p;
        // 异或和不为 0 则先手必胜
        return xorSum != 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. Nim 游戏：异或和 ≠ 0 先手必胜，异或和 = 0 先手必败
2. 这是 Sprague-Grundy 定理的基础应用
