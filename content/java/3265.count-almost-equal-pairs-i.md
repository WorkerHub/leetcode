## 题目描述

给你整数数组 `nums`，若将整数 `a` 的恰好一对数字互换后能等于 `b`（无前导零），或 `a == b`，则称 `(a, b)` 为近似相等对。返回下标 `i < j` 且构成近似相等对的对数。

## 解题思路

对每个数字生成所有一次交换后的变体集合（含自身），遍历时查前面已见过的数字中有多少在变体集合中。用哈希表计数避免重复遍历。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPairs(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        int ans = 0;

        for (int x : nums) {
            // 生成 x 的所有一次交换变体
            Set<Integer> variants = getVariants(x);
            // 统计前面已见数字中属于变体集合的个数
            for (int v : variants) {
                ans += cnt.getOrDefault(v, 0);
            }
            cnt.merge(x, 1, Integer::sum);
        }
        return ans;
    }

    private Set<Integer> getVariants(int x) {
        char[] s = Integer.toString(x).toCharArray();
        int n = s.length;
        Set<Integer> variants = new HashSet<>();
        variants.add(x); // 自身（不交换也算）
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 交换位 i 和位 j
                char tmp = s[i]; s[i] = s[j]; s[j] = tmp;
                // 不能有前导零
                if (s[0] != '0') {
                    variants.add(Integer.parseInt(new String(s)));
                }
                // 还原
                tmp = s[i]; s[i] = s[j]; s[j] = tmp;
            }
        }
        return variants;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * D^2)，D 为数字最大位数（约 7）
- 空间复杂度：O(n * D^2)

## 关键点总结

1. 生成每个数所有一次交换的变体（含自身）
2. 用哈希表统计已见数字，遍历变体集合累加答案
3. 注意交换后不能有前导零
