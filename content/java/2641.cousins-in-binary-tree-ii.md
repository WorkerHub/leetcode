## 题目描述

给你一棵二叉树，用每个节点的**堂兄弟节点之和**（同层但父节点不同的节点的值之和）替换该节点的值，返回修改后的树根节点。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public TreeNode replaceValueInTree(TreeNode root) {
        if (root == null) return null;
        root.val = 0; // 根节点无堂兄弟
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            // 收集当前层所有父节点及其子节点之和
            List<int[]> levelInfo = new ArrayList<>(); // [子节点之和]
            List<TreeNode[]> children = new ArrayList<>();
            int levelSum = 0;

            for (int k = 0; k < size; k++) {
                TreeNode node = queue.poll();
                int childSum = 0;
                if (node.left != null) childSum += node.left.val;
                if (node.right != null) childSum += node.right.val;
                levelSum += childSum;
                children.add(new TreeNode[]{node.left, node.right});
                levelInfo.add(new int[]{childSum});
            }

            // 更新子节点的值 = 层总和 - 该父节点的两个子节点之和
            for (int k = 0; k < children.size(); k++) {
                int childSum = levelInfo.get(k)[0];
                for (TreeNode child : children.get(k)) {
                    if (child != null) {
                        child.val = levelSum - childSum;
                        queue.offer(child);
                    }
                }
            }
        }
        return root;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问常数次
- 空间复杂度：O(n)，BFS 队列

## 关键点总结

1. 每个节点新值 = 同层总和 - 兄弟节点总和（兄弟 = 同父子节点）
2. BFS 按层处理：先累积层内各父节点的子节点和，再更新
3. 根节点直接设为 0
