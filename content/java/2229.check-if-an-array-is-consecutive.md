## 题目描述

判断数组是否是连续数组（包含min到max的所有整数且每个恰好出现一次）。

## 解题思路

两个条件：无重复（集合大小==数组大小）且max-min==n-1。

## Java 代码实现

```java
class Solution {
    public boolean isConsecutive(int[] nums) {
        int n = nums.length;
        Set<Integer> set = new HashSet<>();
        int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
        
        for (int x : nums) {
            set.add(x);
            min = Math.min(min, x);
            max = Math.max(max, x);
        }
        
        return set.size() == n && max - min == n - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **两个条件缺一不可**：无重复+范围恰好覆盖n个数
2. **集合判重**：set.size()==n表示无重复
3. **一遍遍历**：同时求min/max和建set
