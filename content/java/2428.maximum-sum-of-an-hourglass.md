## 题目描述

给你 `m x n` 整数矩阵 `grid`，返回矩阵中所有沙漏（上中下三行，上下行各 3 个元素，中间 1 个）的最大总和。

## 解题思路

枚举所有沙漏的左上角 `(r, c)`（范围：`0 <= r <= m-3`，`0 <= c <= n-3`），计算 7 个元素之和，取最大值。

## Java 代码实现

```java
class Solution {
    public int maxSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;

        // 枚举沙漏左上角 (r, c)
        for (int r = 0; r <= m - 3; r++) {
            for (int c = 0; c <= n - 3; c++) {
                // 计算沙漏 7 个元素之和
                int total = grid[r][c] + grid[r][c + 1] + grid[r][c + 2]
                          + grid[r + 1][c + 1]
                          + grid[r + 2][c] + grid[r + 2][c + 1] + grid[r + 2][c + 2];
                ans = Math.max(ans, total);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)

## 关键点总结

1. 沙漏共 7 个元素，固定形状不能旋转
2. 枚举左上角范围：行 `0 ~ m-3`，列 `0 ~ n-3`
3. 所有元素非负，初始答案设为 0 即可
