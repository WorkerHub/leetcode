## 题目描述

冬季已经来临。你的任务是设计一个有固定加热半径的供暖器向所有房屋供暖。

在加热器的加热半径范围内的每个房屋都可以获得供暖。

现在，给出位于一条水平线上的房屋 `houses` 和供暖器 `heaters` 的位置，请你找出并返回可以覆盖所有房屋的最小加热半径。

**说明：** 所有供暖器都遵循你的半径标准，加热的半径也一样。

**示例 1：**
```
输入：houses = [1,2,3], heaters = [2]
输出：1
解释：仅在位置 2 有一个供暖器。如果我们将加热半径设为 1，那么所有房屋就都能得到供暖。
```

**示例 2：**
```
输入：houses = [1,2,3,4], heaters = [1,4]
输出：1
解释：在位置 1, 4 上有两个供暖器。我们需要将加热半径设为 1，这样所有房屋就都能得到供暖。
```

**示例 3：**
```
输入：houses = [1,5], heaters = [2]
输出：3
```

**提示：**
- `1 <= houses.length, heaters.length <= 3 * 10^4`
- `1 <= houses[i], heaters[i] <= 10^9`

## 解题思路

**核心思想：** 对于每个房屋，找到离它最近的供暖器，所需的最小半径就是所有房屋到其最近供暖器距离的最大值。

**算法流程：**
1. 对房屋和供暖器位置排序
2. 对每个房屋，使用二分查找找到最近的供暖器
3. 计算该房屋到最近供暖器的距离
4. 取所有距离的最大值

## Java 代码实现

### 方法一：二分查找（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    public int findRadius(int[] houses, int[] heaters) {
        // 排序供暖器位置
        Arrays.sort(heaters);
        int radius = 0;

        for (int house : houses) {
            // 使用二分查找找到第一个大于 house 的供暖器位置
            int pos = upperBound(heaters, house);

            // 计算到左右两个供暖器的距离
            int leftDist = (pos == 0) ? Integer.MAX_VALUE : house - heaters[pos - 1];
            int rightDist = (pos == heaters.length) ? Integer.MAX_VALUE : heaters[pos] - house;

            // 取较小距离
            int minDist = Math.min(leftDist, rightDist);

            // 更新最大半径
            radius = Math.max(radius, minDist);
        }

        return radius;
    }

    // 找到第一个大于 target 的位置（对应 Python 的 bisect_right）
    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

### 方法二：双指针

```java
import java.util.Arrays;

class Solution {
    public int findRadius(int[] houses, int[] heaters) {
        Arrays.sort(houses);
        Arrays.sort(heaters);

        int radius = 0;
        int j = 0; // 供暖器指针

        for (int house : houses) {
            // 找到最近的供暖器
            while (j < heaters.length - 1 &&
                   Math.abs(heaters[j + 1] - house) <= Math.abs(heaters[j] - house)) {
                j++;
            }

            // 更新半径
            radius = Math.max(radius, Math.abs(heaters[j] - house));
        }

        return radius;
    }
}
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n log m)，n 是房屋数，m 是供暖器数
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(n log n + m log m)
- 空间复杂度：O(1)

## 关键点总结

1. **排序：** 必须先排序才能使用二分或双指针
2. **二分查找：** 找到最近的供暖器
3. **左右比较：** 比较左右两个供暖器的距离
4. **最大值：** 半径取所有房屋的最大距离

## 易错点

1. **忘记排序**
2. **边界处理：** 最左和最右的房屋（用 `Integer.MAX_VALUE` 处理越界）
3. **二分位置：** 使用 upperBound（找第一个大于目标值的位置）
