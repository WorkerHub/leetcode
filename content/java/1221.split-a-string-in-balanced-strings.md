## 题目描述

平衡字符串是 'L' 和 'R' 数量相等的字符串。给定平衡字符串 s，将其分割为尽可能多的平衡子串，返回最大数量。

**示例：**
```
输入：s = "RLRRLLRLRL"
输出：4（"RL", "RRLL", "RL", "RL"）
```

## 解题思路

贪心：用计数器记录 L 和 R 的差值，每当差值为 0 时说明找到一个平衡子串，计数加一。

## Java 代码实现

```java
class Solution {
    public int balancedStringSplit(String s) {
        int count = 0, balance = 0;
        for (char c : s.toCharArray()) {
            // R 加 1，L 减 1
            balance += (c == 'R') ? 1 : -1;
            // 平衡时分割
            if (balance == 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心**：一旦平衡立即分割，能获得最多子串
2. **计数器**：R 为 +1，L 为 -1，归零即平衡
3. **不需要存储子串**：只需记录分割次数
