## 题目描述

给定整数数组 `nums` 和整数 `k`，找出所有不重复子集，使得子集中所有元素之和等于 `k`。子集内元素按非递减顺序排列，结果不包含重复子集。

## 解题思路

回溯 + 去重（类似 Combination Sum II）。先排序，然后回溯枚举所有子集，同一层跳过重复元素，当前和超过 k 时剪枝。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> findSubsets(int[] nums, int k) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        backtrack(nums, k, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] nums, int remaining, int start,
                           List<Integer> current, List<List<Integer>> result) {
        if (remaining == 0) {
            result.add(new ArrayList<>(current));
            return;
        }
        for (int i = start; i < nums.length; i++) {
            if (nums[i] > remaining) break; // 排序后可提前剪枝
            if (i > start && nums[i] == nums[i-1]) continue; // 跳过同层重复元素
            current.add(nums[i]);
            backtrack(nums, remaining - nums[i], i + 1, current, result);
            current.remove(current.size() - 1);
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序 + 回溯是解决组合求和问题的标准模式
2. 同层跳过重复元素：`i > start && nums[i] == nums[i-1]`
3. 排序后可以提前剪枝
