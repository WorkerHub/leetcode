## 题目描述

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。

构造这个链表的**深拷贝**。深拷贝应该正好由 `n` 个**全新**节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点**。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y`。那么在复制链表中对应的两个节点 `x` 和 `y`，同样有 `x.random --> y`。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：
- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null`。

你的代码**只**接受原链表的头节点 `head` 作为传入参数。

**示例 1：**
```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**示例 2：**
```
输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]
```

**示例 3：**
```
输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]
```

**提示：**
- `0 <= n <= 1000`
- `-10^4 <= Node.val <= 10^4`
- `Node.random` 为 `null` 或指向链表中的节点

## 解题思路

这道题的难点在于 `random` 指针的处理，因为在复制节点时，`random` 指向的节点可能还未创建。

**核心思想：建立原节点与新节点的映射关系**

### 方法一：哈希表映射
1. **第一次遍历**：创建所有新节点，建立 `原节点 → 新节点` 的映射
2. **第二次遍历**：设置新节点的 `next` 和 `random` 指针，通过哈希表查找对应关系

### 方法二：节点拆分（不使用额外空间）
1. **第一步**：在每个原节点后面插入复制节点
   - 原链表：`1 → 2 → 3`
   - 变成：`1 → 1' → 2 → 2' → 3 → 3'`
2. **第二步**：设置复制节点的 `random` 指针
   - `node.next.random = node.random.next`
3. **第三步**：拆分链表，恢复原链表并得到新链表

## Java 代码实现

### 方法一：哈希表（推荐，易理解）

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }
        
        // 哈希表：原节点 -> 新节点
        Map<Node, Node> nodeMap = new HashMap<>();
        
        // 第一次遍历：创建所有新节点
        Node curr = head;
        while (curr != null) {
            nodeMap.put(curr, new Node(curr.val));
            curr = curr.next;
        }
        
        // 第二次遍历：设置新节点的 next 和 random 指针
        curr = head;
        while (curr != null) {
            // 设置 next 指针
            if (curr.next != null) {
                nodeMap.get(curr).next = nodeMap.get(curr.next);
            }
            // 设置 random 指针
            if (curr.random != null) {
                nodeMap.get(curr).random = nodeMap.get(curr.random);
            }
            curr = curr.next;
        }
        
        return nodeMap.get(head);
    }
}
```

### 方法二：哈希表（一次遍历优化版）

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }
        
        // 哈希表：原节点 -> 新节点
        Map<Node, Node> nodeMap = new HashMap<>();
        
        // 获取或创建克隆节点
        // 遍历原链表
        Node curr = head;
        while (curr != null) {
            // 获取或创建当前节点的克隆
            nodeMap.putIfAbsent(curr, new Node(curr.val));
            Node cloned = nodeMap.get(curr);
            
            // 设置 next
            if (curr.next != null) {
                nodeMap.putIfAbsent(curr.next, new Node(curr.next.val));
                cloned.next = nodeMap.get(curr.next);
            }
            // 设置 random
            if (curr.random != null) {
                nodeMap.putIfAbsent(curr.random, new Node(curr.random.val));
                cloned.random = nodeMap.get(curr.random);
            }
            curr = curr.next;
        }
        
        return nodeMap.get(head);
    }
}
```

### 方法三：节点拆分（O(1) 空间）

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }
        
        // 第一步：在每个节点后面插入复制节点
        // 1 -> 2 -> 3  变成  1 -> 1' -> 2 -> 2' -> 3 -> 3'
        Node curr = head;
        while (curr != null) {
            Node cloned = new Node(curr.val);
            cloned.next = curr.next;
            curr.next = cloned;
            curr = cloned.next;
        }
        
        // 第二步：设置复制节点的 random 指针
        curr = head;
        while (curr != null) {
            if (curr.random != null) {
                curr.next.random = curr.random.next;
            }
            curr = curr.next.next;
        }
        
        // 第三步：拆分链表
        curr = head;
        Node clonedHead = head.next;
        while (curr != null) {
            Node cloned = curr.next;
            curr.next = cloned.next;
            if (cloned.next != null) {
                cloned.next = cloned.next.next;
            }
            curr = curr.next;
        }
        
        return clonedHead;
    }
}
```

### 方法四：递归 + 哈希表

```java
class Solution {
    private Map<Node, Node> visited = new HashMap<>();
    
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }
        
        // 如果已经访问过，直接返回克隆节点
        if (visited.containsKey(head)) {
            return visited.get(head);
        }
        
        // 创建新节点
        Node node = new Node(head.val);
        visited.put(head, node);
        
        // 递归复制 next 和 random
        node.next = copyRandomList(head.next);
        node.random = copyRandomList(head.random);
        
        return node;
    }
}
```

## 复杂度分析

### 方法一、二、四：哈希表
- **时间复杂度**：O(n)，需要遍历链表 1-2 次
- **空间复杂度**：O(n)，哈希表存储 n 个节点的映射

### 方法三：节点拆分
- **时间复杂度**：O(n)，需要遍历链表 3 次
- **空间复杂度**：O(1)，不使用额外空间（不考虑返回值）

## 图解示例

以 `head = [[7,null],[13,0],[11,4],[10,2],[1,0]]` 为例：

**原链表：**
```
节点:  7  →  13  →  11  →  10  →  1
random: ↓    ↓     ↓      ↓     ↓
       null  7     1      11    7
```

**方法三（节点拆分）过程：**

**步骤1：插入复制节点**
```
7 → 7' → 13 → 13' → 11 → 11' → 10 → 10' → 1 → 1'
```

**步骤2：设置 random（以节点 13 为例）**
```
原节点 13.random 指向 7
复制节点 13'.random = 13.random.next = 7'
```

**步骤3：拆分链表**
```
原链表: 7 → 13 → 11 → 10 → 1
新链表: 7' → 13' → 11' → 10' → 1'
```

## 关键点总结

1. **深拷贝的理解**：新链表的所有节点和指针都是新创建的，不能指向原链表
2. **映射关系的建立**：哈希表是最直观的方式，建立原节点到新节点的映射
3. **节点拆分技巧**：巧妙地将新节点插入原节点后面，利用位置关系代替哈希表
4. **指针操作的顺序**：拆分链表时要注意先保存指针再修改，避免丢失引用
5. **边界情况**：空链表、只有一个节点、random 指向 null 等情况

## 易错点

1. **忘记处理 random 为 null**
   ```java
   // 设置 random 指针前要判断是否为 null
   if (curr.random != null) {
       nodeMap.get(curr).random = nodeMap.get(curr.random);
   }
   ```

2. **拆分链表时丢失节点**
   ```java
   // 要先保存 cloned，再修改指针
   Node cloned = curr.next;
   curr.next = cloned.next;
   ```

3. **死循环**
   ```java
   // 节点拆分时，步进要用 curr.next.next 而不是 curr.next
   curr = curr.next.next;
   ```

4. **空节点处理**
   ```java
   if (head == null) {
       return null;
   }
   ```

5. **Java 中使用 equals 比较节点**
   ```java
   // 哈希表中用节点对象作为 key，Java 默认按引用比较，是正确的
   nodeMap.containsKey(curr)  // 正确
   ```
