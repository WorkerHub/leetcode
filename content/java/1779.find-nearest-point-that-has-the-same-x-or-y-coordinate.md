## 题目描述

给你位置 `(x, y)` 和点数组 `points`，返回与你共享 x 或 y 坐标（有效点）且曼哈顿距离最近的点的下标（多个取最小下标，无有效点返回 -1）。

## 解题思路

线性扫描，对每个有效点（`a==x` 或 `b==y`）计算曼哈顿距离，维护最小距离及其下标。

## Java 代码实现

```java
class Solution {
    public int nearestValidPoint(int x, int y, int[][] points) {
        int minDist = Integer.MAX_VALUE;
        int bestIdx = -1;

        for (int i = 0; i < points.length; i++) {
            int a = points[i][0], b = points[i][1];
            // 有效点：共享 x 坐标或 y 坐标
            if (a == x || b == y) {
                int dist = Math.abs(a - x) + Math.abs(b - y);
                if (dist < minDist) {
                    minDist = dist;
                    bestIdx = i;
                }
            }
        }

        return bestIdx;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 有效点：`a == x` 或 `b == y`
2. 严格小于 `<` 更新确保相同距离时取下标最小
