## 题目描述

给定 m×n 二进制矩阵，可翻转任意列。返回翻转后所有值相等的行的最大数量。

**示例：**
```
输入：matrix = [[0,0,0],[0,0,1],[1,1,0]]
输出：2
```

## 解题思路

两行能通过同组列翻转变相等，当且仅当它们相同或完全互补。标准化每行（以首元素为基准异或），用哈希表统计模式出现次数。

## Java 代码实现

```java
class Solution {
    public int maxEqualRowsAfterFlips(int[][] matrix) {
        Map<String, Integer> patternCount = new HashMap<>();
        int maxCount = 0;

        for (int[] row : matrix) {
            StringBuilder sb = new StringBuilder();
            // 以第一个元素为基准标准化
            for (int val : row) {
                sb.append(val ^ row[0]);
            }
            String pattern = sb.toString();
            int count = patternCount.merge(pattern, 1, Integer::sum);
            maxCount = Math.max(maxCount, count);
        }

        return maxCount;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **模式识别**：相同或互补的行通过同组翻转可变相等
2. **标准化**：异或首元素将相同/互补的行映射到同一模式
3. **哈希计数**：统计最多的模式数即为答案
