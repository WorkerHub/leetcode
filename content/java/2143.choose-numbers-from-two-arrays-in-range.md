## 题目描述

对每个下标从nums1和nums2中选一个值，求使两组选出值之和相等的方案数（模10^9+7）。

## 解题思路

转化为差值DP：选nums1[i]贡献diff=nums1[i]-nums2[i]，选nums2[i]贡献0。最终差值为0的方案数即答案。

## Java 代码实现

```java
class Solution {
    public int countWays(int[] nums1, int[] nums2) {
        int MOD = 1_000_000_007;
        int n = nums1.length;
        // 用HashMap存储差值->方案数
        Map<Integer, Long> dp = new HashMap<>();
        dp.put(0, 1L);
        
        for (int i = 0; i < n; i++) {
            int d = nums1[i] - nums2[i];
            Map<Integer, Long> newDp = new HashMap<>();
            for (Map.Entry<Integer, Long> entry : dp.entrySet()) {
                int diff = entry.getKey();
                long ways = entry.getValue();
                // 选nums1[i]
                newDp.merge(diff + d, ways, (a, b) -> (a + b) % MOD);
                // 选nums2[i]
                newDp.merge(diff, ways, (a, b) -> (a + b) % MOD);
            }
            dp = newDp;
        }
        return (int)(dp.getOrDefault(0, 0L) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * maxDiff)
- **空间复杂度**：O(maxDiff)

## 关键点总结

1. **差值转化**：选nums1贡献nums1[i]-nums2[i]，选nums2贡献0
2. **目标差值为0**：即两组和相等
3. **HashMap DP**：处理负数差值比数组更灵活
