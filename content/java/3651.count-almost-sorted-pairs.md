## 题目描述

给你一个字符串数组 `words`，定义一对 `(i, j)` 为"几乎有序对"当且仅当 `i < j` 且 `words[i]` 最多交换一对字符后能变成 `words[j]`（长度相同）。返回这样的对的数量。

## 解题思路

枚举所有对 `(i, j)`，统计两字符串不同位置数：为 0（已相同）或 2（差异位置可交换复原）时满足条件。

## Java 代码实现

```java
class Solution {
    public int countPairs(String[] words) {
        int count = 0;
        int n = words.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isAlmostSorted(words[i], words[j])) count++;
            }
        }
        return count;
    }

    private boolean isAlmostSorted(String w1, String w2) {
        if (w1.length() != w2.length()) return false;
        int len = w1.length();
        // 收集差异位置
        int diffA1 = -1, diffB1 = -1, diffA2 = -1, diffB2 = -1;
        int diffCount = 0;
        for (int k = 0; k < len; k++) {
            if (w1.charAt(k) != w2.charAt(k)) {
                diffCount++;
                if (diffCount == 1) {
                    diffA1 = w1.charAt(k);
                    diffB1 = w2.charAt(k);
                } else if (diffCount == 2) {
                    diffA2 = w1.charAt(k);
                    diffB2 = w2.charAt(k);
                } else {
                    return false; // 超过2处不同
                }
            }
        }
        if (diffCount == 0) return true;
        if (diffCount == 2) {
            // 交换后 w1[pos1] 和 w1[pos2] 互换，应变成 w2
            return diffA1 == diffB2 && diffA2 == diffB1;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，L 为字符串长度
- 空间复杂度：O(1)

## 关键点总结

1. 不同位置数为 0 或 2 才满足条件
2. 差异为 2 时，需满足 `(a,b)` 和 `(b,a)` 互为镜像
3. 枚举所有对，O(n^2)
