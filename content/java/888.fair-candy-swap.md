## 题目描述

Alice 和 Bob 各有若干盒糖果，互换一盒使得两人糖果总量相等。返回各自交换的糖果数。

**示例：**
```
输入：aliceSizes = [1,1], bobSizes = [2,2]
输出：[1,2]
```

## 解题思路

数学推导：设 Alice 给出 x，Bob 给出 y，则 y = x + (sumB - sumA) / 2。用 HashSet 查找。

## Java 代码实现

```java
class Solution {
    public int[] fairCandySwap(int[] aliceSizes, int[] bobSizes) {
        int sumA = 0, sumB = 0;
        for (int a : aliceSizes) sumA += a;
        for (int b : bobSizes) sumB += b;
        int diff = (sumB - sumA) / 2;

        Set<Integer> bobSet = new HashSet<>();
        for (int b : bobSizes) bobSet.add(b);

        for (int x : aliceSizes) {
            int y = x + diff;
            if (bobSet.contains(y)) {
                return new int[]{x, y};
            }
        }
        return new int[]{};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(n)

## 关键点总结

1. **数学公式**：y = x + (sumB - sumA) / 2
2. **HashSet 查找**：O(1) 时间查询
3. **保证有解**：差值一定为偶数
