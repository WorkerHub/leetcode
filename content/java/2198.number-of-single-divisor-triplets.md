## 题目描述

给定正整数a、b、c，返回满足恰好有一个变量整除i+j+k的三元组(i,j,k)数目。

## 解题思路

数据范围小(<=100)，直接三重循环枚举，统计s%a==0、s%b==0、s%c==0中恰好为1的情况。

## Java 代码实现

```java
class Solution {
    public long singleDivisorTriplet(int a, int b, int c) {
        long count = 0;
        for (int i = 1; i <= a; i++) {
            for (int j = 1; j <= b; j++) {
                for (int k = 1; k <= c; k++) {
                    int s = i + j + k;
                    int divides = 0;
                    if (s % a == 0) divides++;
                    if (s % b == 0) divides++;
                    if (s % c == 0) divides++;
                    if (divides == 1) count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(a * b * c)
- **空间复杂度**：O(1)

## 关键点总结

1. **恰好一个整除**：三个布尔条件之和等于1
2. **暴力可行**：数据范围<=100，最多10^6次循环
3. **范围注意**：i从1到a，j从1到b，k从1到c
