## 题目描述

给你两棵二叉树：`root1` 和 `root2`。

想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。合并的规则是：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，**不为** null 的节点将直接作为新二叉树的节点。

返回合并后的二叉树。

**注意：**合并过程必须从两个树的根节点开始。

**示例 1：**

```
输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]
输出：[3,4,5,5,4,null,7]
```

**示例 2：**

```
输入：root1 = [1], root2 = [1,2]
输出：[2,2]
```

**提示：**

- 两棵树中的节点数目在范围 `[0, 2000]` 内
- `-10^4 <= Node.val <= 10^4`

## 解题思路

**核心思想：同步递归遍历两棵树**

- 两个节点都存在：值相加
- 只有一个存在：直接使用
- 都不存在：返回 None

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        // 基本情况
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        // 两个节点都存在，创建新节点
        TreeNode merged = new TreeNode(root1.val + root2.val);

        // 递归合并左右子树
        merged.left = mergeTrees(root1.left, root2.left);
        merged.right = mergeTrees(root1.right, root2.right);

        return merged;
    }
}
```

### 方法二：原地修改（空间优化）

```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        // 在 root1 上原地修改
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        // 修改 root1
        root1.val += root2.val;
        root1.left = mergeTrees(root1.left, root2.left);
        root1.right = mergeTrees(root1.right, root2.right);

        return root1;
    }
}
```

### 方法三：迭代（BFS）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        // 层序遍历迭代合并
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        // 使用队列同步遍历
        Deque<TreeNode[]> queue = new ArrayDeque<>();
        queue.offer(new TreeNode[]{root1, root2});

        while (!queue.isEmpty()) {
            TreeNode[] pair = queue.poll();
            TreeNode node1 = pair[0], node2 = pair[1];

            // 合并值
            node1.val += node2.val;

            // 处理左子树
            if (node1.left != null && node2.left != null) {
                queue.offer(new TreeNode[]{node1.left, node2.left});
            } else if (node1.left == null) {
                node1.left = node2.left;
            }

            // 处理右子树
            if (node1.right != null && node2.right != null) {
                queue.offer(new TreeNode[]{node1.right, node2.right});
            } else if (node1.right == null) {
                node1.right = node2.right;
            }
        }

        return root1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(m, n))，m 和 n 为两棵树的节点数
- **空间复杂度**：O(min(m, n))

## 关键点总结

1. **递归边界**：任一树为空时返回另一棵树
2. **同步遍历**：同时递归左右子树
3. **原地修改 vs 新建**：根据需求选择
4. **null 处理**：自动处理不对称的树结构
