## 题目描述

给你整数数组 nums，将其分割为尽可能多的子数组，使每个子数组中所有元素的按位与等于零，返回最多能分割的子数组数。

## 解题思路

贪心：从左到右维护当前子数组的 AND 值，一旦 AND 变为 0 立即分割并重置，利用 AND 单调递减的性质保证贪心正确。

## Java 代码实现

```java
class Solution {
    public int maxSubarrays(int[] nums) {
        int curAnd = ~0; // 全 1（初始值）
        int count = 0;

        for (int x : nums) {
            curAnd &= x;
            if (curAnd == 0) {
                count++;
                curAnd = ~0; // 重置为全 1
            }
        }

        return Math.max(count, 1); // 至少返回 1
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. AND 具有单调性：随着元素增加只会减小（位只被清零）
2. 贪心：AND 变为 0 立即分割，使后续子数组数量最大化
3. `~0` 是全 1 的整数，作为初始值不影响第一次 AND 运算
