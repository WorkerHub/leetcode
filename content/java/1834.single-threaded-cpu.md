## 题目描述

单线程CPU按规则处理任务：空闲时选处理时间最短（相同选下标最小）的已入队任务。返回执行顺序。

## 解题思路

排序+最小堆模拟：任务按入队时间排序，用指针依次加入堆，堆以(处理时间,下标)为键。CPU空闲且堆空时跳跃到下一个任务入队时间。

## Java 代码实现

```java
class Solution {
    public int[] getOrder(int[][] tasks) {
        int n = tasks.length;
        // 按入队时间排序，保留原始下标
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> tasks[a][0] - tasks[b][0]);
        
        // 最小堆：(处理时间, 原始下标)
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> 
            a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        
        int[] result = new int[n];
        int ptr = 0, ri = 0;
        long time = 0;
        
        while (ri < n) {
            // 将所有已入队的任务加入堆
            while (ptr < n && tasks[indices[ptr]][0] <= time) {
                heap.offer(new int[]{tasks[indices[ptr]][1], indices[ptr]});
                ptr++;
            }
            
            if (heap.isEmpty()) {
                // 跳跃到下一个任务的入队时间
                time = tasks[indices[ptr]][0];
                continue;
            }
            
            int[] task = heap.poll();
            result[ri++] = task[1];
            time += task[0]; // 处理时间
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **按入队时间排序**：用指针依次加入堆
2. **堆键(处理时间,下标)**：保证选取最优任务
3. **时间跳跃**：堆空时跳到下一个入队时间
