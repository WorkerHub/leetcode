## 题目描述

设计 MRU 队列，初始含 1 到 n 的元素，支持 `fetch(k)`：将第 k 个（1-indexed）元素移到末尾并返回。

## 解题思路

数据量不大（n, 操作数 <= 2000），用 `ArrayList` 模拟：删除第 k-1 个元素并追加到末尾，O(n) 每次操作。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class MRUQueue {
    private List<Integer> queue;

    public MRUQueue(int n) {
        queue = new ArrayList<>();
        for (int i = 1; i <= n; i++) queue.add(i); // 初始化队列
    }

    public int fetch(int k) {
        int val = queue.remove(k - 1); // 取出第 k 个元素（0-indexed 为 k-1）
        queue.add(val); // 移到末尾
        return val;
    }
}
```

## 复杂度分析

- **时间复杂度**：`fetch` O(n)（ArrayList 删除）
- **空间复杂度**：O(n)

## 关键点总结

1. ArrayList 支持按索引删除和末尾追加
2. 本题数据量小，暴力模拟即可
