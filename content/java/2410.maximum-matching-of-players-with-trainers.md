## 题目描述

给你运动员能力数组 `players` 和训练师能力数组 `trainers`，若 `players[i] <= trainers[j]` 则可匹配（每人最多匹配一次），返回最大匹配数。

## 解题思路

排序双指针：两个数组升序排序，i 指向运动员，j 指向训练师。若当前运动员能力 <= 当前训练师能力则匹配成功（i、j 都右移），否则训练师指针右移找更强的。

## Java 代码实现

```java
class Solution {
    public int matchPlayersAndTrainers(int[] players, int[] trainers) {
        Arrays.sort(players);
        Arrays.sort(trainers);
        int ans = 0, j = 0;
        for (int p : players) {
            while (j < trainers.length && trainers[j] < p) j++;
            if (j < trainers.length) {
                ans++;
                j++; // 该训练师已使用
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m log m)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后对最弱运动员用最弱满足条件的训练师，贪心保证最优。
2. 训练师指针只向右走，每个训练师最多使用一次。
3. 经典二部图最大匹配的贪心解法。
