## 题目描述

n×n 矩阵，从每行选一个数（相邻行不能选同一列），求最小路径和。

**示例：**
```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：13
解释：选 1(列0) + 5(列1) + 7(列0) = 13
```

## 解题思路

DP + 维护最小和次小：dp[i][j] = grid[i][j] + min(dp[i-1][k], k≠j)。优化：只需记录上一行的最小值和次小值。

## Java 代码实现

```java
class Solution {
    public int minFallingPathSum(int[][] grid) {
        int n = grid.length;
        if (n == 1) return grid[0][0];
        
        // 记录上一行的最小值、次小值及最小值的列
        int min1 = 0, min2 = 0, minCol = -1;
        
        for (int i = 0; i < n; i++) {
            int curMin1 = Integer.MAX_VALUE, curMin2 = Integer.MAX_VALUE, curMinCol = -1;
            
            for (int j = 0; j < n; j++) {
                int val = grid[i][j] + (j != minCol ? min1 : min2);
                
                if (val < curMin1) {
                    curMin2 = curMin1;
                    curMin1 = val;
                    curMinCol = j;
                } else if (val < curMin2) {
                    curMin2 = val;
                }
            }
            min1 = curMin1;
            min2 = curMin2;
            minCol = curMinCol;
        }
        return min1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **最小/次小优化**：避免 O(n³) 暴力
2. **不同列约束**：若当前列 = 上一行最小值列，则用次小值
3. **滚动更新**：只需上一行的最小、次小信息
