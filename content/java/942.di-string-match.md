## 题目描述

给定字符串 s（只含 'I' 和 'D'），构造 [0,n] 的一个排列使得 'I' 位置递增、'D' 位置递减。

## 解题思路

贪心：遇 'I' 取当前最小值，遇 'D' 取当前最大值。最后追加剩余值（此时 low==high）。

## Java 代码实现

```java
class Solution {
    public int[] diStringMatch(String s) {
        int n = s.length();
        int low = 0, high = n;
        int[] result = new int[n + 1];

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == 'I') {
                result[i] = low++;
            } else {
                result[i] = high--;
            }
        }
        result[n] = low; // low == high

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，不计输出

## 关键点总结

1. **贪心选择**：'I' 取最小保证后面还有更大值
2. **'D' 取最大**：保证后面还有更小值
3. **最后一个值**：low == high 时放最后
