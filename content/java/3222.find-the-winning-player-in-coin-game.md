## 题目描述

Alice 和 Bob 轮流取硬币（Alice 先），每次可取 1 枚 75 值硬币 + 1 枚 115 值硬币，或仅取 1 枚 75 值硬币，无法操作者输。给定 x（75 值硬币数）和 y（115 值硬币数），返回获胜者。

## Java 代码实现

```java
class Solution {
    public String losingPlayer(int x, int y) {
        // 每次操作恰好消耗 1 枚 75 值硬币（x 决定总操作次数）
        // x 为奇数时 Alice 取最后一次操作，Alice 胜
        // x 为偶数时 Bob 取最后一次操作，Bob 胜
        return x % 2 == 1 ? "Alice" : "Bob";
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 无论选大操作还是小操作，每次都恰好消耗 1 枚 75 值硬币
2. 总操作次数固定为 x，因此只需判断 x 的奇偶性
3. x 为奇数时 Alice 获胜，x 为偶数时 Bob 获胜
