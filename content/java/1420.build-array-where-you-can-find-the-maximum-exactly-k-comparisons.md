## 题目描述

给你三个整数 `n`、`m` 和 `k`。下述算法用于找某个数组中的最大元素：

```
maximum_value = -1
maximum_index = -1
search_cost = 0
for i from 0 to n-1:
    if nums[i] > maximum_value:
        maximum_value = nums[i]
        maximum_index = i
        search_cost = search_cost + 1
return maximum_index
```

构造一个长度为 `n`、元素在 `[1, m]` 范围内的数组，使得上述算法的 `search_cost` 恰好等于 `k`。

返回满足条件的数组数目，答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 2, m = 3, k = 1
输出：6
解释：有 6 种数组满足条件：[1,1],[2,1],[2,2],[3,1],[3,2],[3,3]
```

**示例 2：**

```
输入：n = 5, m = 2, k = 3
输出：0
解释：没有满足条件的数组。
```

**示例 3：**

```
输入：n = 9, m = 1, k = 1
输出：1
```

**提示：**

- `1 <= n <= 50`
- `1 <= m <= 100`
- `0 <= k <= n`

## 解题思路

### 动态规划

**理解 search_cost：**

`search_cost` 等于数组的"前缀最大值改变的次数"，也就是从左到右遇到新的最大值的次数。

**DP 状态定义：**

`dp[j][cost]` = 已选 `i` 个元素，当前最大值为 `j`，搜索代价为 `cost` 的方案数。

**转移：**

对第 `i+1` 个元素，设其值为 `v`（`1 <= v <= m`）：

- 若 `v <= j`（不更新最大值）：`dp[j][cost]` 有 `j` 个选择（1 到 j）
- 若 `v > j`（更新最大值，cost+1）：从 `dp[j][cost]` 转移到 `dp[v][cost+1]`

**初始状态：** `dp[0][0] = 1`（空数组，最大值为0，代价为0）

**答案：** `sum(dp[j][k] for j in [1, m])`

## Java 代码实现

### 方法一：二维 DP（滚动数组，推荐）

```java
class Solution {
    public int numOfArrays(int n, int m, int k) {
        int MOD = 1_000_000_007;

        // dp[j][c] = 当前最大值为 j，搜索代价为 c 的方案数
        long[][] dp = new long[m + 1][k + 1];
        dp[0][0] = 1;  // 空数组，最大值为0，代价为0

        for (int i = 0; i < n; i++) {
            long[][] newDp = new long[m + 1][k + 1];
            for (int j = 0; j <= m; j++) {
                for (int cost = 0; cost <= k; cost++) {
                    if (dp[j][cost] == 0) continue;

                    // 情况1：选一个不超过 j 的值（不更新最大值），j 种选择
                    newDp[j][cost] = (newDp[j][cost] + dp[j][cost] * j) % MOD;

                    // 情况2：选一个比 j 大的值 v（更新最大值，cost+1）
                    if (cost + 1 <= k) {
                        for (int v = j + 1; v <= m; v++) {
                            newDp[v][cost + 1] = (newDp[v][cost + 1] + dp[j][cost]) % MOD;
                        }
                    }
                }
            }
            dp = newDp;
        }

        long ans = 0;
        for (int j = 1; j <= m; j++) {
            ans = (ans + dp[j][k]) % MOD;
        }
        return (int) ans;
    }
}
```

### 方法二：前缀和优化（减少内层循环）

```java
class Solution {
    public int numOfArrays(int n, int m, int k) {
        int MOD = 1_000_000_007;
        long[][] dp = new long[m + 1][k + 1];
        dp[0][0] = 1;

        for (int i = 0; i < n; i++) {
            long[][] newDp = new long[m + 1][k + 1];

            // 维护前缀和：prefix[j][c] = sum(dp[1..j][c])
            long[][] prefix = new long[m + 2][k + 1];
            for (int j = 1; j <= m; j++) {
                for (int c = 0; c <= k; c++) {
                    prefix[j][c] = (prefix[j - 1][c] + dp[j][c]) % MOD;
                }
            }

            for (int j = 1; j <= m; j++) {
                for (int c = 0; c <= k; c++) {
                    // 情况1：选一个 <= j 的值（不更新最大值），j 种选择
                    newDp[j][c] = (newDp[j][c] + dp[j][c] * j) % MOD;

                    // 情况2：从最大值 < j 的状态，选 j 作为新最大值（cost+1）
                    // sum(dp[0..j-1][c-1]) = prefix[j-1][c-1]
                    if (c >= 1) {
                        newDp[j][c] = (newDp[j][c] + prefix[j - 1][c - 1]) % MOD;
                    }
                }
            }
            dp = newDp;
        }

        long ans = 0;
        for (int j = 1; j <= m; j++) {
            ans = (ans + dp[j][k]) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三维 DP | O(n * m^2 * k) | O(m * k) |
| 前缀和优化 | O(n * m * k) | O(m * k) |

方法二用前缀和将内层循环优化掉，时间复杂度最优。

## 关键点总结

1. `search_cost` 等于"从左到右，前缀最大值更新的次数"
2. DP 状态：（当前最大值，当前代价）
3. 转移：选小于等于最大值的数（不增加代价）或选更大的数（代价+1）
4. 前缀和优化：避免对"所有比当前最大值大的 v"内层枚举

## 易错点

1. 初始最大值设为 0（表示还没有选任何元素），代价为 0
2. 选不超过 j 的值时，有 `j` 种选择（1 到 j，不是 0 到 j）
3. 最终答案只统计 `dp[j][k]`（j >= 1），不包含 j = 0
4. Java 中使用 `long` 存储中间结果，防止乘法溢出
