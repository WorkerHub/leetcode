## 题目描述

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是 **快乐数** 就返回 `true`；不是，则返回 `false`。

**示例 1：**
```
输入：n = 19
输出：true
解释：
1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1
```

**示例 2：**
```
输入：n = 2
输出：false
```

**提示：**
- `1 <= n <= 2^31 - 1`

## 解题思路

这道题的关键在于**检测循环**。有三种可能的结果：

1. 最终得到 1（快乐数）
2. 进入无限循环（不是快乐数）
3. 数字越来越大，趋向无穷（实际上不会发生）

### 核心观察

**为什么不会无限增大？**

以 3 位数为例：
- 最大的 3 位数是 999，平方和为 9² + 9² + 9² = 243
- 任何 3 位数的平方和都不会超过 243

因此，数字不会无限增大，只会：
- 最终到达 1
- 进入循环

### 解决方案

需要**检测循环**，有三种方法：

1. **哈希表记录**：用集合记录出现过的数字
2. **快慢指针**：类似检测链表环
3. **数学规律**：利用已知的循环数字

## Java 代码实现

### 方法一：哈希表检测循环（推荐）⭐

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    // 计算各位数字的平方和
    private int getNext(int num) {
        int total = 0;
        while (num > 0) {
            int digit = num % 10;  // 获取个位数
            total += digit * digit;  // 累加平方
            num /= 10;  // 去掉个位数
        }
        return total;
    }
    
    public boolean isHappy(int n) {
        // 用集合记录出现过的数字
        Set<Integer> seen = new HashSet<>();
        
        while (n != 1 && !seen.contains(n)) {
            seen.add(n);
            n = getNext(n);
        }
        
        // 如果是 1，说明是快乐数；否则进入了循环
        return n == 1;
    }
}
```

**代码说明**：
- `getNext()` 计算各位数字的平方和
- 用 `HashSet` 记录所有出现过的数字
- 如果遇到重复数字，说明进入循环，不是快乐数
- 如果得到 1，说明是快乐数

### 方法二：快慢指针（空间优化）⭐

```java
class Solution {
    private int getNext(int num) {
        int total = 0;
        while (num > 0) {
            int digit = num % 10;
            total += digit * digit;
            num /= 10;
        }
        return total;
    }
    
    public boolean isHappy(int n) {
        // 快慢指针
        int slow = n;
        int fast = getNext(n);
        
        // 快指针每次走两步，慢指针走一步
        while (fast != 1 && slow != fast) {
            slow = getNext(slow);              // 慢指针走一步
            fast = getNext(getNext(fast));     // 快指针走两步
        }
        
        // 如果 fast 是 1，说明是快乐数
        return fast == 1;
    }
}
```

**代码说明**：
- 类似于「链表环检测」问题
- 快指针每次走两步，慢指针走一步
- 如果有循环，快慢指针一定会相遇
- 如果到达 1，说明是快乐数

### 方法三：简化版（HashSet）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isHappy(int n) {
        Set<Integer> seen = new HashSet<>();
        
        while (n != 1) {
            // 如果出现重复，说明进入循环
            if (seen.contains(n)) {
                return false;
            }
            seen.add(n);
            
            // 计算下一个数
            int total = 0;
            while (n > 0) {
                int digit = n % 10;
                total += digit * digit;
                n /= 10;
            }
            n = total;
        }
        
        return true;
    }
}
```

## 复杂度分析

### 方法一：哈希表
- **时间复杂度**：O(log n)，主要取决于数字的位数和循环次数
- **空间复杂度**：O(log n)，集合存储中间结果

### 方法二：快慢指针
- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)，不需要额外的集合存储

## 图解示例

以 n = 19 为例：

```
19 → 1² + 9² = 1 + 81 = 82
82 → 8² + 2² = 64 + 4 = 68
68 → 6² + 8² = 36 + 64 = 100
100 → 1² + 0² + 0² = 1 ✓

结论：19 是快乐数
```

以 n = 2 为例：

```
2 → 4
4 → 16
16 → 37
37 → 58
58 → 89
89 → 145
145 → 42
42 → 20
20 → 4  ← 出现循环！

结论：2 不是快乐数（进入 4 → 16 → 37 → ... → 4 的循环）
```

## 关键点总结

1. **问题本质**：检测是否进入循环，类似于链表环检测
2. **两种思路**：哈希表记录历史值 vs 快慢指针
3. **优化技巧**：快慢指针可以节省空间
4. **数学性质**：数字不会无限增大，只会收敛或循环

## 易错点

1. **忘记检测循环**：只计算平方和，忘记判断是否重复
2. **死循环**：没有正确的退出条件
3. **边界情况**：n = 1 时应该直接返回 true
4. **整数溢出**：Java 中 int 最大值为 2^31-1，各位平方和不会溢出 int，但要注意 long 类型场景
