## 题目描述

给你二进制字符串 `s` 和整数 `num1`、`num2`，返回 0 与 1 数量之比等于 `num1:num2` 的子字符串数目。

## 解题思路

设 `f(i) = num2 * cnt0[i] - num1 * cnt1[i]`，子串 `[l, r]` 满足条件当且仅当 `f(r+1) == f(l)`。用哈希表统计 f 值出现次数，枚举右端点累加答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long fixedRatio(String s, int num1, int num2) {
        Map<Long, Long> freq = new HashMap<>();
        freq.put(0L, 1L); // 空前缀

        long cnt0 = 0, cnt1 = 0, ans = 0;
        for (char c : s.toCharArray()) {
            if (c == '0') cnt0++;
            else cnt1++;
            long key = (long) num2 * cnt0 - (long) num1 * cnt1;
            ans += freq.getOrDefault(key, 0L);
            freq.merge(key, 1L, Long::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 比例条件 `cnt0:cnt1 = num1:num2` 等价于 `num2*cnt0 - num1*cnt1 = 0`
2. 前缀差恒等 ↔ 子串满足条件，用哈希表统计等价前缀
3. 初始化 `freq[0] = 1` 对应空前缀，返回值用 `long` 防溢出
