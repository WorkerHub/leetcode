## 题目描述

给你绳子长度数组 `ribbons` 和整数 `k`，通过切割获得至少 k 段等长绳子，返回这些绳子的最大长度，无法满足返回 0。

## 解题思路

对答案（绳子长度）二分查找。给定长度 mid，能切出的段数为 `sum(ribbon / mid)`，若段数 >= k 则可行，找最大可行长度。

## Java 代码实现

```java
class Solution {
    public int maxLength(int[] ribbons, int k) {
        int lo = 1, hi = 0;
        for (int r : ribbons) hi = Math.max(hi, r);

        int result = 0;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canCut(ribbons, mid, k)) {
                result = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return result;
    }

    // 判断能否切出至少 k 段长度为 length 的绳子
    private boolean canCut(int[] ribbons, int length, int k) {
        long count = 0;
        for (int r : ribbons) count += r / length;
        return count >= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * log(max_ribbon))
- **空间复杂度**：O(1)

## 关键点总结

1. 对答案（长度）二分，而非对下标二分
2. 验证函数：段数 = `sum(r / length)`，与 k 比较
3. 初始 result = 0 处理无法满足的情况
