## 题目描述

给定 C++ 源代码，移除行注释 `//` 和块注释 `/* ... */`，返回移除注释后的代码（空行不输出）。

**示例：**
```
输入：["a/*comment", "line", "more_comment*/b"]
输出：["ab"]
```

## 解题思路

状态机模拟：用布尔变量标记是否在块注释中，逐字符扫描处理。行注释直接跳过本行剩余，块注释持续到遇到 `*/`。

## Java 代码实现

```java
class Solution {
    public List<String> removeComments(String[] source) {
        List<String> result = new ArrayList<>();
        boolean inBlock = false;
        StringBuilder newLine = new StringBuilder();

        for (String line : source) {
            int i = 0;
            while (i < line.length()) {
                if (inBlock) {
                    if (i + 1 < line.length() && line.charAt(i) == '*' && line.charAt(i + 1) == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        i++;
                    }
                } else {
                    if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '/') {
                        break; // 行注释，跳过剩余
                    } else if (i + 1 < line.length() && line.charAt(i) == '/' && line.charAt(i + 1) == '*') {
                        inBlock = true;
                        i += 2;
                    } else {
                        newLine.append(line.charAt(i));
                        i++;
                    }
                }
            }

            if (!inBlock && newLine.length() > 0) {
                result.add(newLine.toString());
                newLine = new StringBuilder();
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 为行数，m 为行长度
- **空间复杂度**：O(n × m)

## 关键点总结

1. **状态机**：用 inBlock 标记是否在块注释中
2. **块注释跨行**：块注释可能将多行拼接
3. **行注释**：遇到 `//` 直接 break 跳过本行
