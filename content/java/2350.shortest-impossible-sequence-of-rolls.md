## 题目描述

给你骰子结果数组 `rolls`（每个值在 [1,k]），返回最短的无法作为 `rolls` 子序列的骰子序列长度。

## 解题思路

贪心段划分：将 rolls 按段划分，每段包含所有 k 种点数至少一次。经过 t 段后，所有长度为 t 的序列都能找到子序列，长度 t+1 则不能，答案为段数 + 1。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int shortestSequence(int[] rolls, int k) {
        Set<Integer> seen = new HashSet<>();
        int segments = 0; // 完整覆盖 k 种点数的段数

        for (int x : rolls) {
            seen.add(x);
            if (seen.size() == k) {
                segments++;
                seen.clear(); // 当前段覆盖了所有 k 种，开始新段
            }
        }
        return segments + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. t 段每段包含全部 k 种点数，保证长度 t 的所有序列都是子序列。
2. 答案为段数 + 1（剩余不完整的段不足以覆盖更长序列）。
3. 贪心地用 HashSet 判断当前段是否覆盖所有点数，然后清空重新开始。
