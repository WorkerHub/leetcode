## 题目描述

给你一个整数数组 `nums` 和若干查询 `queries[i] = [l, r]`，每次查询对 `nums[l..r]` 内的重复元素执行删除操作（保留每个值的第一次出现）。返回执行完所有查询后删除操作次数的总和。

## 解题思路

预处理 `prev[i]`：记录位置 i 的值上一次出现的位置。对于查询 `[l, r]`，统计 `[l, r]` 内满足 `prev[i] >= l` 的元素个数（即在窗口内重复出现的元素）。

## Java 代码实现

```java
class Solution {
    public long minimumOperations(int[] nums, int[][] queries) {
        int n = nums.length;
        int[] prev = new int[n];
        // 记录每个值上一次出现的位置
        Map<Integer, Integer> lastSeen = new HashMap<>();

        for (int i = 0; i < n; i++) {
            prev[i] = lastSeen.getOrDefault(nums[i], -1);
            lastSeen.put(nums[i], i);
        }

        long total = 0;
        for (int[] q : queries) {
            int l = q[0], r = q[1];
            // 统计 [l, r] 内重复元素数量
            for (int i = l; i <= r; i++) {
                if (prev[i] >= l) {
                    total++;
                }
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * q)，n 为数组长度，q 为查询数
- 空间复杂度：O(n)，prev 数组和哈希表

## 关键点总结

1. 每次查询的操作数 = 区间内重复的元素个数（`prev[i] >= l` 判断是否重复）。
2. `prev[i]` 预处理使判断变为 O(1)，避免每次查询重建集合。
3. 可用线段树或莫队算法优化到 O((n+q) log n)。
