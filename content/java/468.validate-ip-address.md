## 题目描述

给定一个字符串 `queryIP`。如果是有效的 IPv4 地址，返回 `"IPv4"`；如果是有效的 IPv6 地址，返回 `"IPv6"`；如果不是上述类型的 IP 地址，返回 `"Neither"`。

**有效的 IPv4 地址** 是 `"x1.x2.x3.x4"` 形式的 IP 地址。其中 `0 <= xi <= 255` 且 `xi` 不能包含前导零。

- 例如: `"192.168.1.1"` 、`"192.168.1.0"` 为有效 IPv4 地址，`"192.168.01.1"` 为无效 IPv4 地址；`"192.168.1.00"` 、`"192.168@1.1"` 为无效 IPv4 地址。

**有效的 IPv6 地址** 是 `"x1:x2:x3:x4:x5:x6:x7:x8"` 形式的 IP 地址。其中：

- `1 <= xi.length <= 4`
- `xi` 是一个十六进制字符串，可以包含数字、小写英文字母 `'a'` 到 `'f'` 和大写英文字母 `'A'` 到 `'F'`。
- 在 `xi` 中允许前导零。

例如 `"2001:0db8:85a3:0000:0000:8a2e:0370:7334"` 和 `"2001:db8:85a3:0:0:8A2E:0370:7334"` 是有效的 IPv6 地址，而 `"2001:0db8:85a3::8A2E:037j:7334"` 和 `"02001:0db8:85a3:0000:0000:8a2e:0370:7334"` 是无效的 IPv6 地址。

**示例 1：**
```
输入：queryIP = "172.16.254.1"
输出："IPv4"
解释：有效的 IPv4 地址，返回 "IPv4"
```

**示例 2：**
```
输入：queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
输出："IPv6"
解释：有效的 IPv6 地址，返回 "IPv6"
```

**示例 3：**
```
输入：queryIP = "256.256.256.256"
输出："Neither"
解释：既不是 IPv4 地址，也不是 IPv6 地址
```

**提示：**
- `queryIP` 仅由英文字母，数字，字符 `'.'` 和 `':'` 组成。

## 解题思路

这是一道字符串验证题，需要仔细处理各种边界情况。

**解题步骤：**
1. 根据分隔符判断是 IPv4（`.`）还是 IPv6（`:`）
2. 分别验证 IPv4 和 IPv6 的规则

**IPv4 验证规则：**
- 恰好 4 个部分
- 每个部分是 0-255 的数字
- 不能有前导零（除了 "0" 本身）
- 不能有非数字字符

**IPv6 验证规则：**
- 恰好 8 个部分
- 每个部分是 1-4 位十六进制数
- 只能包含 0-9, a-f, A-F
- 允许前导零

## Java 代码实现

### 方法一：分情况验证（推荐）⭐

```java
class Solution {
    public String validIPAddress(String queryIP) {
        // 判断是 IPv4 还是 IPv6
        if (queryIP.contains(".")) {
            return validateIPv4(queryIP);
        } else if (queryIP.contains(":")) {
            return validateIPv6(queryIP);
        } else {
            return "Neither";
        }
    }

    private String validateIPv4(String ip) {
        // 使用 -1 保留尾部空字符串（处理末尾多余的点）
        String[] parts = ip.split("\\.", -1);

        // 必须恰好 4 个部分
        if (parts.length != 4) return "Neither";

        for (String part : parts) {
            // 不能为空
            if (part.isEmpty()) return "Neither";

            // 不能有前导零（除了 "0" 本身）
            if (part.length() > 1 && part.charAt(0) == '0') return "Neither";

            // 必须全是数字
            for (char c : part.toCharArray()) {
                if (!Character.isDigit(c)) return "Neither";
            }

            // 范围检查 0-255
            if (Integer.parseInt(part) > 255) return "Neither";
        }

        return "IPv4";
    }

    private String validateIPv6(String ip) {
        // 使用 -1 保留尾部空字符串（处理末尾多余的冒号）
        String[] parts = ip.split(":", -1);

        // 必须恰好 8 个部分
        if (parts.length != 8) return "Neither";

        String hexChars = "0123456789abcdefABCDEF";

        for (String part : parts) {
            // 长度必须是 1-4
            if (part.isEmpty() || part.length() > 4) return "Neither";

            // 必须全是十六进制字符
            for (char c : part.toCharArray()) {
                if (hexChars.indexOf(c) == -1) return "Neither";
            }
        }

        return "IPv6";
    }
}
```

### 方法二：使用正则表达式

```java
import java.util.regex.Pattern;

class Solution {
    public String validIPAddress(String queryIP) {
        // IPv4 正则：4 个 0-255 的数字，用 . 分隔
        String ipv4Pattern = "^(([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\\.){3}"
                           + "([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])$";

        // IPv6 正则：8 个 1-4 位十六进制数，用 : 分隔
        String ipv6Pattern = "^(([0-9a-fA-F]{1,4}):){7}([0-9a-fA-F]{1,4})$";

        if (Pattern.matches(ipv4Pattern, queryIP)) {
            return "IPv4";
        } else if (Pattern.matches(ipv6Pattern, queryIP)) {
            return "IPv6";
        } else {
            return "Neither";
        }
    }
}
```

**优点：** 代码简洁，但正则难以理解和调试

### 方法三：详细验证版

```java
class Solution {
    public String validIPAddress(String queryIP) {
        if (queryIP.contains(".") && !queryIP.contains(":")) {
            String[] parts = queryIP.split("\\.", -1);
            if (parts.length == 4) {
                boolean valid = true;
                for (String p : parts) {
                    if (!isValidIPv4Part(p)) {
                        valid = false;
                        break;
                    }
                }
                if (valid) return "IPv4";
            }
        } else if (queryIP.contains(":") && !queryIP.contains(".")) {
            String[] parts = queryIP.split(":", -1);
            if (parts.length == 8) {
                boolean valid = true;
                for (String p : parts) {
                    if (!isValidIPv6Part(p)) {
                        valid = false;
                        break;
                    }
                }
                if (valid) return "IPv6";
            }
        }

        return "Neither";
    }

    private boolean isValidIPv4Part(String s) {
        // 空字符串无效
        if (s.isEmpty()) return false;

        // 长度不能超过 3
        if (s.length() > 3) return false;

        // 前导零检查
        if (s.charAt(0) == '0' && s.length() > 1) return false;

        // 必须全是数字
        for (char c : s.toCharArray()) {
            if (!Character.isDigit(c)) return false;
        }

        // 范围检查
        return Integer.parseInt(s) <= 255;
    }

    private boolean isValidIPv6Part(String s) {
        // 空字符串或长度超过 4
        if (s.isEmpty() || s.length() > 4) return false;

        // 必须是十六进制字符
        for (char c : s.toCharArray()) {
            if (!Character.isDigit(c)
                    && !(c >= 'a' && c <= 'f')
                    && !(c >= 'A' && c <= 'F')) {
                return false;
            }
        }

        return true;
    }
}
```

## 复杂度分析

**方法一（分情况验证）：**
- 时间复杂度：O(n)，n 是字符串长度
- 空间复杂度：O(1)

**方法二（正则表达式）：**
- 时间复杂度：O(n)，正则引擎的匹配
- 空间复杂度：O(1)

## 关键点总结

1. **分隔符判断：** 先根据 `.` 或 `:` 区分类型
2. **IPv4 前导零：** `"01"` 无效，但 `"0"` 有效
3. **IPv6 允许前导零：** `"0001"` 有效
4. **部分数量：** IPv4 恰好 4 个，IPv6 恰好 8 个
5. **边界情况：** 空部分、多余分隔符、混合分隔符

## 易错点

1. **前导零判断：** IPv4 不允许，IPv6 允许
   ```java
   // IPv4："01" 无效，"0" 有效
   if (s.charAt(0) == '0' && s.length() > 1) return false;

   // IPv6："0001" 有效，无需前导零检查
   ```

2. **混合分隔符：** 同时包含 `.` 和 `:`
   ```java
   // 错误：只检查是否包含
   if (queryIP.contains(".")) return validateIPv4(queryIP);

   // 正确：确保不包含另一种分隔符
   if (queryIP.contains(".") && !queryIP.contains(":")) { ... }
   ```

3. **空部分：** `"192.168..1"` 或 `"2001::85a3"`
   ```java
   // split 会产生空字符串
   // "192.168..1".split("\\.", -1) -> ["192", "168", "", "1"]
   // 必须检查空字符串
   if (part.isEmpty()) return "Neither";
   ```

4. **边界值：** IPv4 的 255 和 256
   ```java
   // "255" 有效，"256" 无效
   if (Integer.parseInt(part) > 255) return "Neither";
   ```

5. **字符验证：** IPv6 只能是十六进制
   ```java
   // 错误：允许所有字母
   if (Character.isLetterOrDigit(c)) { ... }

   // 正确：只允许 0-9, a-f, A-F
   if (hexChars.indexOf(c) == -1) return "Neither";
   ```
