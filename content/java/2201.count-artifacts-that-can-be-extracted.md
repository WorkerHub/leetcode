## 题目描述

神器覆盖矩形区域，当其所有格子都被挖掘后可提取，返回可提取的神器数量。

## 解题思路

将挖掘位置存入HashSet，遍历每个神器检查其矩形内所有格子是否全部已挖掘。

## Java 代码实现

```java
class Solution {
    public int digArtifacts(int n, int[][] artifacts, int[][] dig) {
        Set<Integer> dug = new HashSet<>();
        for (int[] d : dig) {
            dug.add(d[0] * n + d[1]);
        }
        
        int ans = 0;
        for (int[] a : artifacts) {
            boolean extracted = true;
            for (int r = a[0]; r <= a[2] && extracted; r++) {
                for (int c = a[1]; c <= a[3] && extracted; c++) {
                    if (!dug.contains(r * n + c)) {
                        extracted = false;
                    }
                }
            }
            if (extracted) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k + A)，k为挖掘点数，A为神器总面积
- **空间复杂度**：O(k)

## 关键点总结

1. **哈希集合O(1)查询**：将(r,c)编码为r*n+c存入Set
2. **枚举神器格子**：闭区间[r1,r2]×[c1,c2]全部检查
3. **早终止优化**：发现未挖掘格子立即break
