## 题目描述

用给定宽度的砖块构造宽为width高为height的墙，相邻行接缝不能重叠，求方案数（模10^9+7）。

## 解题思路

DFS预处理所有合法行的接缝mask，预计算相容行对（mask按位与为0），然后DP逐行转移。

## Java 代码实现

```java
class Solution {
    public int buildWall(int height, int width, int[] bricks) {
        int MOD = 1_000_000_007;
        
        // 生成所有合法行的接缝mask
        Set<Integer> maskSet = new HashSet<>();
        dfs(width, 0, 0, bricks, maskSet);
        List<Integer> masks = new ArrayList<>(maskSet);
        int m = masks.size();
        
        // 预计算相容矩阵
        List<List<Integer>> compatible = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            compatible.add(new ArrayList<>());
            for (int j = 0; j < m; j++) {
                if ((masks.get(i) & masks.get(j)) == 0) {
                    compatible.get(i).add(j);
                }
            }
        }
        
        // DP
        long[] dp = new long[m];
        Arrays.fill(dp, 1L);
        
        for (int row = 1; row < height; row++) {
            long[] newDp = new long[m];
            for (int i = 0; i < m; i++) {
                for (int j : compatible.get(i)) {
                    newDp[j] = (newDp[j] + dp[i]) % MOD;
                }
            }
            dp = newDp;
        }
        
        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
    
    private void dfs(int remaining, int pos, int mask, int[] bricks, Set<Integer> result) {
        if (remaining == 0) {
            result.add(mask);
            return;
        }
        for (int b : bricks) {
            if (b <= remaining) {
                int newMask = mask;
                if (pos > 0) newMask |= (1 << (pos - 1));
                dfs(remaining - b, pos + b, newMask, bricks, result);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(height * M^2)，M为合法行数
- **空间复杂度**：O(M^2)

## 关键点总结

1. **bitmask编码接缝**：width<=10，最多9个接缝位
2. **相容条件**：两行mask按位与为0（无公共接缝）
3. **逐行DP转移**：dp[j] += dp[i] 当i和j相容
