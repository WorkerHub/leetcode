## 题目描述

序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。

请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。

**提示：** 输入输出格式与 LeetCode 目前使用的方式一致，详情请参阅 LeetCode 序列化二叉树的格式。你并非必须采取这种方式，你也可以采用其他的方法解决这个问题。

**示例 1：**
```
输入：root = [1,2,3,null,null,4,5]
输出：[1,2,3,null,null,4,5]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**提示：**
- 树中节点数在范围 [0, 10^4] 内
- -1000 <= Node.val <= 1000

## 解题思路

序列化和反序列化是一对互逆操作，关键是设计合理的编码格式。

**常见方法对比：**

| 方法 | 优点 | 缺点 |
|------|------|------|
| 前序遍历 + null 标记 | 简单直观，递归实现 | 需要标记空节点 |
| 层序遍历 + null 标记 | 符合 LeetCode 格式 | 需要队列 |
| 括号表示法 | 结构清晰 | 字符串较长 |

**核心要点：**
1. 必须能够唯一确定树的结构
2. 序列化和反序列化必须匹配
3. 需要标记空节点（null）的位置

## Java 代码实现

### 方法一：前序遍历（DFS）推荐

```java
import java.util.Arrays;
import java.util.LinkedList;
import java.util.Queue;

public class Codec {
    // 序列化：将树转换为字符串（前序遍历，用 "null" 标记空节点，","分隔）
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        serializeHelper(root, sb);
        return sb.toString();
    }

    private void serializeHelper(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("null,");
            return;
        }
        // 前序：先根节点
        sb.append(node.val).append(',');
        // 再递归处理左右子树
        serializeHelper(node.left, sb);
        serializeHelper(node.right, sb);
    }

    // 反序列化：将字符串还原为树
    public TreeNode deserialize(String data) {
        // 用队列按顺序消费节点值
        Queue<String> queue = new LinkedList<>(Arrays.asList(data.split(",")));
        return deserializeHelper(queue);
    }

    private TreeNode deserializeHelper(Queue<String> queue) {
        String val = queue.poll();
        if ("null".equals(val)) {
            return null;
        }
        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = deserializeHelper(queue);
        node.right = deserializeHelper(queue);
        return node;
    }
}
```

### 方法二：层序遍历（BFS）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

public class Codec {
    // 层序遍历序列化（与 LeetCode 格式一致）
    public String serialize(TreeNode root) {
        if (root == null) return "";

        StringBuilder sb = new StringBuilder();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node == null) {
                sb.append("null,");
            } else {
                sb.append(node.val).append(',');
                // 将子节点加入队列（包括 null）
                queue.offer(node.left);
                queue.offer(node.right);
            }
        }

        // 去除末尾多余的 "null,"
        String result = sb.toString();
        // 去除末尾逗号
        return result.endsWith(",") ? result.substring(0, result.length() - 1) : result;
    }

    // 层序遍历反序列化
    public TreeNode deserialize(String data) {
        if (data == null || data.isEmpty()) return null;

        String[] vals = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(vals[0]));
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int i = 1;

        while (!queue.isEmpty() && i < vals.length) {
            TreeNode node = queue.poll();

            // 处理左子节点
            if (i < vals.length && !"null".equals(vals[i])) {
                node.left = new TreeNode(Integer.parseInt(vals[i]));
                queue.offer(node.left);
            }
            i++;

            // 处理右子节点
            if (i < vals.length && !"null".equals(vals[i])) {
                node.right = new TreeNode(Integer.parseInt(vals[i]));
                queue.offer(node.right);
            }
            i++;
        }

        return root;
    }
}
```

### 方法三：后序遍历

```java
import java.util.Arrays;
import java.util.Deque;
import java.util.ArrayDeque;

public class Codec {
    // 后序遍历序列化（左-右-根）
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        postorderSerialize(root, sb);
        return sb.toString();
    }

    private void postorderSerialize(TreeNode node, StringBuilder sb) {
        if (node == null) {
            sb.append("null,");
            return;
        }
        postorderSerialize(node.left, sb);
        postorderSerialize(node.right, sb);
        sb.append(node.val).append(',');
    }

    // 后序遍历反序列化（从后向前）
    public TreeNode deserialize(String data) {
        String[] vals = data.split(",");
        // 使用双端队列，从末尾开始消费
        Deque<String> deque = new ArrayDeque<>(Arrays.asList(vals));
        return postorderDeserialize(deque);
    }

    private TreeNode postorderDeserialize(Deque<String> deque) {
        String val = deque.pollLast();
        if ("null".equals(val)) {
            return null;
        }
        TreeNode node = new TreeNode(Integer.parseInt(val));
        // 注意：后序遍历从后往前，先构建右子树
        node.right = postorderDeserialize(deque);
        node.left = postorderDeserialize(deque);
        return node;
    }
}
```

## 复杂度分析

### 所有方法：

**时间复杂度：**
- serialize: O(n) - 遍历所有节点
- deserialize: O(n) - 构建所有节点

**空间复杂度：**
- serialize: O(n) - 存储序列化字符串
- deserialize: O(n) - 递归栈或队列

## 图解示例

示例树：
```
    1
   / \
  2   3
     / \
    4   5
```

### 前序遍历序列化：
```
访问顺序：1 → 2 → null → null → 3 → 4 → null → null → 5 → null → null

序列化结果：
"1,2,null,null,3,4,null,null,5,null,null,"

反序列化过程：
1. 读取 "1"，创建节点 1
2. 递归处理左子树：
   - 读取 "2"，创建节点 2
   - 递归处理左子树：读取 "null"，返回 null
   - 递归处理右子树：读取 "null"，返回 null
3. 递归处理右子树：
   - 读取 "3"，创建节点 3
   - 递归处理左子树：
     - 读取 "4"，创建节点 4
     - ...
```

### 层序遍历序列化：
```
层次访问：
第1层：1
第2层：2, 3
第3层：null, null, 4, 5

序列化结果：
"1,2,3,null,null,4,5"

反序列化过程：
1. 创建根节点 1，加入队列
2. 从队列取出 1：
   - 左子节点是 2，创建并加入队列
   - 右子节点是 3，创建并加入队列
3. 从队列取出 2：
   - 左子节点是 null，跳过
   - 右子节点是 null，跳过
4. 从队列取出 3：
   - 左子节点是 4，创建并加入队列
   - 右子节点是 5，创建并加入队列
```

## 关键点总结

1. **遍历顺序**：前序、后序、层序都可以，但必须标记 null
2. **null 标记**：必须标记空节点位置，否则无法唯一确定树
3. **Java 字符串比较**：使用 `equals` 而不是 `==` 比较字符串
4. **分隔符选择**：常用逗号，也可以用其他字符
5. **递归匹配**：序列化和反序列化的递归顺序必须一致

## 易错点

1. **字符串比较用 == 而不是 equals**
   ```java
   // 错误：Java 中 == 比较的是对象引用
   if (val == "null") { ... }
   
   // 正确：使用 equals 比较字符串内容
   if ("null".equals(val)) { ... }
   ```

2. **忘记标记 null**
   ```java
   // 错误：不标记 null，无法确定结构
   private void serialize(TreeNode node, StringBuilder sb) {
       if (node == null) return; // 空节点直接返回，无标记
       sb.append(node.val).append(',');
       ...
   }
   
   // 正确：必须标记 null
   if (node == null) {
       sb.append("null,");
       return;
   }
   ```

3. **后序遍历的顺序**
   ```java
   // 错误：反序列化时顺序错误
   private TreeNode build(Deque<String> deque) {
       TreeNode node = new TreeNode(Integer.parseInt(deque.pollLast()));
       node.left = build(deque);  // 错误！后序从后往前应先右后左
       node.right = build(deque);
   }
   
   // 正确：先右后左
   private TreeNode build(Deque<String> deque) {
       String val = deque.pollLast();
       if ("null".equals(val)) return null;
       TreeNode node = new TreeNode(Integer.parseInt(val));
       node.right = build(deque);
       node.left = build(deque);
       return node;
   }
   ```

4. **空树处理**
   ```java
   // 错误：没有处理空树
   public TreeNode deserialize(String data) {
       String[] vals = data.split(",");
       // 如果 data 为空字符串，split 可能产生 [""] 而非 []
   }
   
   // 正确：先检查
   public TreeNode deserialize(String data) {
       if (data == null || data.isEmpty()) return null;
       ...
   }
   ```
