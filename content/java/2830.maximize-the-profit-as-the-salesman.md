## 题目描述

选择不重叠区间的offers卖房，最大化总利润。

## 解题思路

DP：dp[i]表示处理前i个位置的最大利润。按end分组，对以i-1结尾的offer，dp[i]=max(dp[i-1], dp[start]+gold)。

## Java 代码实现

```java
class Solution {
    public int maximizeTheProfit(int n, List<List<Integer>> offers) {
        // 按end分组
        List<int[]>[] endOffers = new ArrayList[n];
        for (int i = 0; i < n; i++) endOffers[i] = new ArrayList<>();
        for (List<Integer> o : offers) {
            endOffers[o.get(1)].add(new int[]{o.get(0), o.get(2)});
        }

        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1];
            for (int[] offer : endOffers[i - 1]) {
                dp[i] = Math.max(dp[i], dp[offer[0]] + offer[1]);
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(N + M)

## 关键点总结

1. **按end位置分组offers**：避免排序和二分
2. **dp[start]+gold**：start之前的最优+当前offer收益
3. **dp[i]=max(dp[i-1], ...)**：不选或选某个以i-1结尾的offer
