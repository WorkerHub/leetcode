## 题目描述

二叉树中的路径被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。

路径和是路径中各节点值的总和。

给你一个二叉树的根节点 `root`，返回其最大路径和。

**示例 1：**

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

**示例 2：**

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42
```

**提示：**

- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

## 解题思路

这是一道经典的树形 DP 问题，难点在于理解路径的定义和如何处理负数节点。

**核心思想：**

1. **路径的定义**：
   - 路径可以从任意节点开始，到任意节点结束
   - 路径不一定经过根节点
   - 路径至少包含一个节点

2. **递归思路**：
   - 对于每个节点，计算以该节点为"最高点"的路径最大和
   - 以节点为最高点的路径 = 左子树贡献 + 节点值 + 右子树贡献
   - 向上传递时，只能选择左或右其中一条路径（不能分叉）

3. **负数处理**：
   - 如果子树的贡献为负数，可以选择不要该子树（贡献为 0）
   - 这样可以避免负数降低路径和

**关键观察：**

- 对于每个节点，有两种情况：
  1. 该节点作为路径的"最高点"（左子树 + 节点 + 右子树）
  2. 该节点作为路径的一部分，向上传递（节点 + max(左子树, 右子树)）

## Java 代码实现

### 方法一：后序遍历 + 实例变量（推荐）

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    // 使用实例变量记录全局最大路径和
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxGain(root);
        return maxSum;
    }

    private int maxGain(TreeNode node) {
        // 递归返回以 node 为起点的单边路径最大和
        if (node == null) return 0;

        // 递归计算左右子树的最大贡献
        // 如果贡献为负，则不选择该子树（贡献为 0）
        int leftGain = Math.max(maxGain(node.left), 0);
        int rightGain = Math.max(maxGain(node.right), 0);

        // 以当前节点为"最高点"的路径和
        int pathSum = node.val + leftGain + rightGain;

        // 更新全局最大路径和
        maxSum = Math.max(maxSum, pathSum);

        // 向上传递时，只能选择左或右其中一条路径
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

### 方法二：使用数组存储结果（避免实例变量）

```java
class Solution {
    public int maxPathSum(TreeNode root) {
        int[] maxSum = {Integer.MIN_VALUE};
        maxGain(root, maxSum);
        return maxSum[0];
    }

    private int maxGain(TreeNode node, int[] maxSum) {
        if (node == null) return 0;

        // 计算左右子树的贡献
        int leftGain = Math.max(maxGain(node.left, maxSum), 0);
        int rightGain = Math.max(maxGain(node.right, maxSum), 0);

        // 更新最大路径和
        int pathSum = node.val + leftGain + rightGain;
        maxSum[0] = Math.max(maxSum[0], pathSum);

        // 返回单边最大路径
        return node.val + Math.max(leftGain, rightGain);
    }
}
```

### 方法三：返回数组（路径和与单边最大值）

```java
class Solution {
    public int maxPathSum(TreeNode root) {
        // 返回 [以root为最高点的路径最大和, 以root为起点的单边最大和]
        return dfs(root)[0];
    }

    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{Integer.MIN_VALUE, 0};

        // 递归左右子树
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        // 计算左右的正贡献
        int leftGain = Math.max(left[1], 0);
        int rightGain = Math.max(right[1], 0);

        // 以当前节点为最高点的路径和
        int currPath = node.val + leftGain + rightGain;

        // 单边最大和
        int currGain = node.val + Math.max(leftGain, rightGain);

        // 最大路径和（考虑左右子树的情况）
        int maxPath = Math.max(currPath, Math.max(left[0], right[0]));

        return new int[]{maxPath, currGain};
    }
}
```

### 方法四：迭代实现（后序遍历，较复杂）

```java
class Solution {
    public int maxPathSum(TreeNode root) {
        int maxSum = Integer.MIN_VALUE;
        // 存储每个节点的单边最大贡献
        java.util.Map<TreeNode, Integer> nodeGain = new java.util.HashMap<>();

        // 后序遍历（迭代）
        java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();
        TreeNode prev = null;
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            // 遍历到最左
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }

            curr = stack.peek();

            // 如果右子树不存在或已访问，处理当前节点
            if (curr.right == null || curr.right == prev) {
                stack.pop();

                // 计算左右贡献
                int leftGain = Math.max(nodeGain.getOrDefault(curr.left, 0), 0);
                int rightGain = Math.max(nodeGain.getOrDefault(curr.right, 0), 0);

                // 更新最大路径和
                int pathSum = curr.val + leftGain + rightGain;
                maxSum = Math.max(maxSum, pathSum);

                // 存储单边贡献
                nodeGain.put(curr, curr.val + Math.max(leftGain, rightGain));

                prev = curr;
                curr = null;
            } else {
                // 访问右子树
                curr = curr.right;
            }
        }

        return maxSum;
    }
}
```

## 复杂度分析

**方法一、二、三：递归**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈的深度，h 为树的高度

**方法四：迭代**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要栈和哈希表

## 关键点总结

1. **路径理解**：路径可以从任意节点到任意节点，不一定经过根
2. **分叉问题**：节点作为"最高点"时可以包含左右子树，向上传递时只能选一边
3. **负数处理**：贡献为负时不选择该子树（`Math.max(gain, 0)`）
4. **后序遍历**：需要先计算子树的结果，再处理当前节点
5. **全局最大值**：在递归过程中不断更新全局最大路径和

## 易错点

1. **忘记处理负数**：没有用 `Math.max(gain, 0)` 处理负贡献
2. **返回值错误**：向上返回时应该是单边最大值，不是路径和
3. **初始化错误**：`maxSum` 应初始化为 `Integer.MIN_VALUE`，不是 0（因为可能全是负数）
4. **理解路径**：路径是连续的，不能跳跃节点
5. **遍历顺序**：必须用后序遍历，因为需要先知道子树的结果

## 图解示例

```
示例：[-10, 9, 20, null, null, 15, 7]

        -10
        /  \
       9   20
          /  \
         15   7

递归过程（后序遍历）：

1. 节点 15：
   - leftGain = 0, rightGain = 0
   - pathSum = 15
   - 返回 15

2. 节点 7：
   - leftGain = 0, rightGain = 0
   - pathSum = 7
   - 返回 7

3. 节点 20：
   - leftGain = max(15, 0) = 15
   - rightGain = max(7, 0) = 7
   - pathSum = 20 + 15 + 7 = 42（最大！）
   - 返回 20 + max(15, 7) = 35

4. 节点 9：
   - leftGain = 0, rightGain = 0
   - pathSum = 9
   - 返回 9

5. 节点 -10：
   - leftGain = max(9, 0) = 9
   - rightGain = max(35, 0) = 35
   - pathSum = -10 + 9 + 35 = 34
   - 返回 -10 + max(9, 35) = 25

最大路径和 = 42（路径：15 -> 20 -> 7）
```

## 为什么要取 max(gain, 0)？

```
如果不处理负数：

        5
       / \
     -3  -2

不取 max：
leftGain = -3, rightGain = -2
pathSum = 5 + (-3) + (-2) = 0

取 max：
leftGain = Math.max(-3, 0) = 0
rightGain = Math.max(-2, 0) = 0
pathSum = 5 + 0 + 0 = 5

显然，不选择负贡献的子树更优。
```
