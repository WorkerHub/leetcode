## 题目描述

给定一棵二叉搜索树和其中的一个节点 `p`，找到该节点在树中的中序后继。如果节点没有中序后继，请返回 `null`。

节点 `p` 的中序后继是在中序遍历顺序中，节点 `p` 之后出现的第一个节点。

**示例 1:**

```
输入: root = [2,1,3], p = 1
输出: 2
解释: 1 的中序后继节点是 2。注意 p 和返回值都是 TreeNode 类型的。
```

**示例 2:**

```
输入: root = [5,3,6,2,4,null,null,1], p = 6
输出: null
解释: 因为给定节点没有中序后继，所以答案返回 null。
```

**提示:**

- 树中节点的数目在范围 `[1, 10^4]` 内。
- `-10^5 <= Node.val <= 10^5`
- 树中所有节点的值都是唯一的。

## 解题思路

这道题要求找二叉搜索树（BST）中某个节点的中序后继。利用 BST 的性质，可以高效地找到后继节点。

**核心知识：**

中序遍历 BST 得到的是递增序列，中序后继就是比当前节点大的最小节点。

**关键观察：**

1. 如果节点 p 有右子树，后继是右子树中最左（最小）的节点
2. 如果节点 p 没有右子树，后继是"某个祖先节点"，该祖先的左子树包含 p

**两种情况分析：**

情况一：p 有右子树
```
    5
   / \
  3   6    p = 5
 / \
2   4

后继 = 右子树的最左节点 = 6
```

情况二：p 没有右子树
```
    5
   / \
  3   6    p = 4
 / \
2   4

后继 = 向上找的第一个"左转"的祖先 = 5
```

**算法流程：**

方法一（利用 BST 性质）：
1. 从根节点开始搜索
2. 如果当前节点值 > p.val，可能是后继，记录并往左走
3. 如果当前节点值 <= p.val，往右走
4. 返回记录的后继节点

方法二（中序遍历）：
1. 中序遍历整棵树
2. 找到 p 后，下一个访问的节点就是后继

## Java 代码实现

### 方法一：利用 BST 性质（推荐，最优解）

```java
class Solution {
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        // 利用 BST 性质找后继
        // 时间复杂度 O(h)，h 为树高
        TreeNode successor = null;

        while (root != null) {
            if (root.val > p.val) {
                // 当前节点可能是后继，记录并继续往左找更小的
                successor = root;
                root = root.left;
            } else {
                // 当前节点值 <= p.val，后继一定在右边
                root = root.right;
            }
        }

        return successor;
    }
}
```

### 方法二：分两种情况处理

```java
class Solution {
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        // 情况 1: p 有右子树，后继是右子树的最左节点
        if (p.right != null) {
            TreeNode node = p.right;
            while (node.left != null) {
                node = node.left;
            }
            return node;
        }

        // 情况 2: p 无右子树，需要向上找祖先
        // 从根开始搜索 p，记录路径中可能的后继
        TreeNode successor = null;
        TreeNode node = root;

        while (node != null) {
            if (node.val > p.val) {
                successor = node; // 可能的后继
                node = node.left;
            } else if (node.val < p.val) {
                node = node.right;
            } else { // 找到 p
                break;
            }
        }

        return successor;
    }
}
```

### 方法三：递归法（优雅实现）

```java
class Solution {
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        if (root == null) return null;

        // 如果 p 的值 >= 当前节点，后继一定在右子树
        if (p.val >= root.val) {
            return inorderSuccessor(root.right, p);
        } else {
            // p 的值 < 当前节点，当前节点可能是后继
            // 先去左子树找，如果找不到，当前节点就是后继
            TreeNode left = inorderSuccessor(root.left, p);
            return left != null ? left : root;
        }
    }
}
```

### 方法四：详细注释版（新手友好）

```java
class Solution {
    /**
     * 查找 BST 中节点 p 的中序后继
     *
     * 思路：
     * 1. 中序后继 = 比 p.val 大的最小节点
     * 2. 从根开始搜索，维护一个候选后继
     * 3. 如果当前节点 > p.val，它可能是后继，往左找更小的
     * 4. 如果当前节点 <= p.val，后继在右边
     *
     * 示例：[5,3,6,2,4], p=3
     * root=5: 5>3, successor=5, 往左
     * root=3: 3=3, 往右
     * root=4: 4>3, successor=4, 往左
     * root=None: 返回 successor=4
     */
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        TreeNode successor = null; // 候选后继
        TreeNode current = root;

        while (current != null) {
            if (current.val > p.val) {
                // 当前节点值大于 p，它可能是后继
                // 但可能存在更小的后继在左子树，继续搜索
                successor = current;
                current = current.left;
            } else {
                // current.val <= p.val
                // 后继一定在右子树（如果存在的话）
                current = current.right;
            }
        }

        return successor;
    }
}
```

## 复杂度分析

**方法一：利用 BST 性质**
- 时间复杂度：`O(h)` 其中 h 是树的高度，最坏 O(n)
- 空间复杂度：`O(1)` 只使用常数空间

**方法三：递归**
- 时间复杂度：`O(h)`
- 空间复杂度：`O(h)` 递归栈

## 关键点总结

1. **BST 性质**：中序遍历是递增的，后继就是比当前节点大的最小值
2. **两种情况**：有右子树和无右子树的处理方式不同
3. **迭代 vs 递归**：迭代法空间复杂度更优
4. **候选后继**：遍历时维护一个可能的后继节点
5. **通用性**：中序遍历法适用于普通二叉树，但效率较低

## 易错点

1. **等于的情况**：`root.val == p.val` 时应该往右走
2. **最大节点**：树中最大节点没有后继，应返回 null
3. **右子树处理**：有右子树时，忘记找右子树的最左节点
4. **迭代终止条件**：while 循环条件应该是 `root != null`
5. **空树处理**：需要考虑根节点为空的情况
