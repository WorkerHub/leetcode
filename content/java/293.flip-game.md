## 题目描述

你和朋友玩一个叫做「翻转游戏」的游戏。游戏规则如下：

给你一个字符串 currentState，其中只包含 '+' 和 '-'。你和朋友轮流将连续的两个 "++" 反转成 "--"。当一方无法进行有效的翻转时便意味着游戏结束，另一方获胜。

请你写出一个函数来计算出第一次翻转后，字符串所有的可能状态。

**示例 1：**
```
输入：currentState = "++++"
输出：["--++","+--+","++--"]
```

**示例 2：**
```
输入：currentState = "+"
输出：[]
```

**提示：**
- 1 <= currentState.length <= 500
- currentState[i] 不是 '+' 就是 '-'

## 解题思路

这是一道简单的字符串模拟题，思路很直接：

1. 遍历字符串，找到所有连续的 "++"
2. 将每个 "++" 翻转成 "--"，生成新状态
3. 收集所有可能的新状态

**实现要点：**
- 需要检查位置 i 和 i+1 是否都是 '+'
- Java 中字符串不可变，需要使用 StringBuilder 或字符数组
- 注意边界条件：字符串长度小于 2 时无法翻转

## Java 代码实现

### 方法一：StringBuilder（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generatePossibleNextMoves(String currentState) {
        List<String> result = new ArrayList<>();
        char[] chars = currentState.toCharArray();

        // 遍历每个可能的翻转位置
        for (int i = 0; i < chars.length - 1; i++) {
            // 检查当前位置和下一位置是否都是 '+'
            if (chars[i] == '+' && chars[i + 1] == '+') {
                // 翻转：将 ++ 变成 --
                chars[i] = '-';
                chars[i + 1] = '-';
                result.add(new String(chars));
                // 恢复状态
                chars[i] = '+';
                chars[i + 1] = '+';
            }
        }

        return result;
    }
}
```

### 方法二：使用 String 切片拼接

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generatePossibleNextMoves(String currentState) {
        List<String> result = new ArrayList<>();

        for (int i = 0; i < currentState.length() - 1; i++) {
            // 检查是否为连续的 "++"
            if (currentState.charAt(i) == '+' && currentState.charAt(i + 1) == '+') {
                // 拼接：前缀 + "--" + 后缀
                String newState = currentState.substring(0, i) + "--"
                        + currentState.substring(i + 2);
                result.add(newState);
            }
        }

        return result;
    }
}
```

### 方法三：使用 StringBuilder 优化

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generatePossibleNextMoves(String currentState) {
        List<String> result = new ArrayList<>();
        StringBuilder sb = new StringBuilder(currentState);

        for (int i = 0; i < sb.length() - 1; i++) {
            if (sb.charAt(i) == '+' && sb.charAt(i + 1) == '+') {
                // 翻转
                sb.setCharAt(i, '-');
                sb.setCharAt(i + 1, '-');
                result.add(sb.toString());
                // 恢复状态
                sb.setCharAt(i, '+');
                sb.setCharAt(i + 1, '+');
            }
        }

        return result;
    }
}
```

## 复杂度分析

### 所有方法：

**时间复杂度：** O(n^2)
- 外层循环遍历 n-1 个位置：O(n)
- 每次生成新字符串需要 O(n)
- 总时间复杂度：O(n^2)

**空间复杂度：** O(n)
- 结果列表最多包含 n-1 个字符串
- 每个字符串长度为 n
- 总空间：O(n^2)，但不计入输出空间的话是 O(n)

## 图解示例

以 `currentState = "++++"` 为例：

```
初始状态：++++

位置 0: ++++ → --++
        ^^       ^^
        翻转这两个

位置 1: ++++ → +--+
         ^^      ^^
         翻转这两个

位置 2: ++++ → ++--
          ^^     ^^
          翻转这两个

结果：["--++", "+--+", "++--"]
```

再看一个例子 `currentState = "+-++"`：

```
初始状态：+-++

位置 0: +-++
        ^^
        不是 ++，跳过

位置 1: +-++
         ^^
         不是 ++，跳过

位置 2: +-++ → +---
          ^^     ^^
          翻转这两个

结果：["+---"]
```

## 关键点总结

1. **遍历范围**：注意是 `i < length - 1`，因为需要检查两个字符
2. **字符串不可变**：Java 字符串不可变，需要用字符数组或 StringBuilder
3. **精确匹配**：只翻转连续的 "++"，不能只有一个 '+'
4. **所有可能性**：要找出所有位置的翻转结果，不是只找一个
5. **边界条件**：长度小于 2 的字符串无法翻转，返回空列表

## 易错点

1. **遍历范围错误**
   ```java

   for (int i = 0; i < currentState.length(); i++) {
       if (chars[i] == '+' && chars[i + 1] == '+') { // i+1 会越界
   
   // 正确：只遍历到倒数第二个
   for (int i = 0; i < currentState.length() - 1; i++) {
   ```

2. **只找一个结果**
   ```java
   // 错误：找到第一个就返回
   if (currentState.charAt(i) == '+' && currentState.charAt(i+1) == '+') {
       return Arrays.asList(currentState.substring(0,i) + "--" + currentState.substring(i+2));
   
   // 正确：要找所有可能
   result.add(currentState.substring(0, i) + "--" + currentState.substring(i + 2));
   ```

3. **字符串拼接索引错误**
   ```java
   // 错误：索引范围错误
   String newState = currentState.substring(0, i) + "--" + currentState.substring(i + 1);
   
   // 正确：应该从 i+2 开始（替换两个字符）
   String newState = currentState.substring(0, i) + "--" + currentState.substring(i + 2);
   ```

4. **忘记恢复字符数组状态**
   ```java
   // 错误：翻转后没有恢复
   chars[i] = '-';
   chars[i + 1] = '-';
   result.add(new String(chars));
   // 忘记恢复，影响后续判断
   
   // 正确：要恢复
   chars[i] = '-';
   chars[i + 1] = '-';
   result.add(new String(chars));
   chars[i] = '+';
   chars[i + 1] = '+';
   ```
