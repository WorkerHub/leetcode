## 题目描述

给你一个 n×n 矩阵，-1 为障碍物，正整数为格子值，返回所有非障碍物格子的远端距离之和（远端距离 = 无法到达的非障碍物格子值之和）。

## 解题思路

BFS 求连通分量：同一连通分量内格子互相可达，每格远端距离 = 总非障碍物值之和 - 本分量值之和，整个分量贡献 = `comp_size × (total - comp_sum)`。

## Java 代码实现

```java
class Solution {
    public long sumRemoteness(int[][] grid) {
        int n = grid.length;
        // 计算所有非障碍物格子的值之和
        long total = 0;
        for (int[] row : grid)
            for (int v : row)
                if (v != -1) total += v;

        boolean[][] visited = new boolean[n][n];
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        long ans = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != -1 && !visited[i][j]) {
                    // BFS 计算连通分量
                    Queue<int[]> queue = new LinkedList<>();
                    queue.offer(new int[]{i, j});
                    visited[i][j] = true;
                    long compSum = 0;
                    int compSize = 0;
                    while (!queue.isEmpty()) {
                        int[] cur = queue.poll();
                        compSum += grid[cur[0]][cur[1]];
                        compSize++;
                        for (int[] d : dirs) {
                            int nr = cur[0] + d[0], nc = cur[1] + d[1];
                            if (nr >= 0 && nr < n && nc >= 0 && nc < n
                                    && !visited[nr][nc] && grid[nr][nc] != -1) {
                                visited[nr][nc] = true;
                                queue.offer(new int[]{nr, nc});
                            }
                        }
                    }
                    // 该分量每格的远端距离 = total - compSum
                    ans += (long) compSize * (total - compSum);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 同一连通分量内格子的远端距离相同，等于 `total - comp_sum`
2. 整个分量的贡献 = `comp_size × (total - comp_sum)`
3. 使用 long 防止溢出（值最大 10^6，格子最多 90000 个）
