## 题目描述

给你一个整数数组 `houses` 表示一条街上房屋的位置，以及整数 `k`，请你用 `k` 个邮筒覆盖所有房屋，使所有房屋到最近邮筒的**总距离最小**。

邮筒可以放在**任意**位置，不必和房屋位置一样，但必须放在某个整数坐标上。

返回最小的总距离之和。测试数据保证答案在 32 位有符号整数范围内。

**示例 1：**

```
输入：houses = [1,4,8,10,20], k = 3
输出：5
解释：将邮筒分别放在位置 3，9 和 20（或 10）。
- 位置 3: 距离 [1,4] 各自最近，总距离 |1-3|+|4-3|=2+1=3
- 位置 9: 距离 [8,10] 最近，总距离 |8-9|+|10-9|=1+1=2
- 位置 20: 距离 [20] 最近，总距离 0
总计: 5
```

**示例 2：**

```
输入：houses = [2,3,5,12,18], k = 2
输出：9
```

**提示：**
- `1 <= k <= houses.length <= 100`
- `1 <= houses[i] <= 10^4`

## 解题思路

**核心思想：动态规划 + 中位数定理**

**中位数定理：** 对于一组点，将一个邮筒放在它们的**中位数**位置时，总距离最小。

**预处理：** 先计算 `cost[i][j]`——将一个邮筒覆盖 `houses[i..j]` 时的最小总距离（邮筒放在中位数位置）。

**DP 定义：** `dp[i][j]` = 用 `i` 个邮筒覆盖前 `j` 个房子的最小总距离。

**状态转移：** 枚举最后一个邮筒覆盖的范围 `[p, j-1]`：
```
dp[i][j] = min(dp[i-1][p] + cost[p][j-1]) for all p in [i-1, j-1]
```

**计算 cost[i][j]：**
排序后，`houses[i..j]` 的中位数是 `houses[(i+j)/2]`，总距离用前缀和 O(1) 计算。

## Java 代码实现

### 方法一：区间预处理 + DP（推荐）

```java
import java.util.Arrays;

class Solution {
    public int minDistance(int[] houses, int k) {
        Arrays.sort(houses);  // 排序是使用中位数定理的前提
        int n = houses.length;

        // 预处理 cost[i][j]：用一个邮筒覆盖 houses[i..j] 的最小距离
        int[][] cost = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 邮筒放在中位数位置，总距离 = 对称求和
                int mid = (i + j) / 2;
                for (int t = i; t <= j; t++) {
                    cost[i][j] += Math.abs(houses[t] - houses[mid]);
                }
            }
        }

        final int INF = Integer.MAX_VALUE / 2;
        // dp[i][j]：用 i 个邮筒覆盖前 j 个房子（下标 0..j-1）的最小距离
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;  // 0 个邮筒覆盖 0 个房子，距离为 0

        for (int i = 1; i <= k; i++) {
            for (int j = i; j <= n; j++) {
                // 枚举最后一个邮筒覆盖 houses[p..j-1]
                for (int p = i - 1; p < j; p++) {
                    if (dp[i - 1][p] < INF) {
                        dp[i][j] = Math.min(dp[i][j], dp[i - 1][p] + cost[p][j - 1]);
                    }
                }
            }
        }

        return dp[k][n];
    }
}
```

### 方法二：前缀和优化 cost 计算

```java
import java.util.Arrays;

class Solution {
    public int minDistance(int[] houses, int k) {
        Arrays.sort(houses);
        int n = houses.length;

        // 前缀和用于快速计算区间和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + houses[i];
        }

        final int INF = Integer.MAX_VALUE / 2;
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;

        for (int i = 1; i <= k; i++) {
            for (int j = i; j <= n; j++) {
                for (int p = i - 1; p < j; p++) {
                    if (dp[i - 1][p] < INF) {
                        int c = intervalCost(houses, prefix, p, j - 1);
                        dp[i][j] = Math.min(dp[i][j], dp[i - 1][p] + c);
                    }
                }
            }
        }

        return dp[k][n];
    }

    // 用前缀和计算将一个邮筒放在 houses[i..j] 中位数位置的最小总距离
    private int intervalCost(int[] houses, long[] prefix, int i, int j) {
        int mid = (i + j) / 2;
        long m = houses[mid];
        // 左半部分：[i, mid-1]，到 m 的距离 = mid*m - sum(houses[i..mid-1])
        long left = mid * m - (prefix[mid] - prefix[i]);
        // 右半部分：[mid+1, j]，到 m 的距离 = sum(houses[mid+1..j]) - (j-mid)*m
        long right = (prefix[j + 1] - prefix[mid + 1]) - (j - mid) * m;
        return (int) (left + right);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 区间预处理 + DP | O(k * n^2) | O(k * n + n^2) |
| 前缀和优化 | O(k * n^2) | O(k * n) |

- n=100, k=100 时：100 * 100^2 = 1,000,000，完全可行。

## 关键点总结

1. **中位数定理**：一维空间中，将邮筒放在一组点的中位数位置时，总距离最小。
2. 先排序，再用 DP 枚举每个邮筒的覆盖范围。
3. `cost[i][j]` 的计算：排序后中位数是 `houses[(i+j)/2]`，用前缀和 O(1) 计算区间总距离。
4. DP 状态转移：枚举最后一个邮筒的覆盖起点 `p`，`dp[i][j] = min(dp[i-1][p] + cost[p][j-1])`。

## 易错点

- **必须先排序**：中位数定理在无序数组中不适用，排序是前提。
- **DP 下标对齐**：`dp[i][j]` 表示 `i` 个邮筒覆盖**前 j 个**（下标 0 到 j-1）房子，`cost[p][j-1]` 表示第 p 到 j-1 个（0 起）房子。
- **中位数位置**：`(i+j)/2` 是正确的中位数下标（向下取整），奇偶长度均适用。
- 计算时使用 `long` 防止溢出（`mid * m` 可能很大）。
