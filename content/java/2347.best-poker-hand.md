## 题目描述

给你 5 张牌的点数 `ranks` 和花色 `suits`，按优先级返回最佳手牌：同花 > 三条 > 对子 > 高牌。

## 解题思路

按优先级依次检查：花色全相同则同花；点数最大频率 >= 3 则三条；>= 2 则对子；否则高牌。

## Java 代码实现

```java
class Solution {
    public String bestHand(int[] ranks, char[] suits) {
        // 检查同花：5 张花色相同
        boolean flush = true;
        for (char s : suits) if (s != suits[0]) { flush = false; break; }
        if (flush) return "Flush";

        // 统计点数频率
        int[] cnt = new int[14];
        for (int r : ranks) cnt[r]++;
        int maxCnt = 0;
        for (int c : cnt) maxCnt = Math.max(maxCnt, c);

        if (maxCnt >= 3) return "Three of a Kind";
        if (maxCnt >= 2) return "Pair";
        return "High Card";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（固定 5 张牌）
- **空间复杂度**：O(1)

## 关键点总结

1. 按同花 > 三条 > 对子 > 高牌的优先级顺序判断。
2. 三条条件为 `>= 3`，四张相同时也满足（题目只有这 4 种分类）。
3. 用数组（大小 14）替代哈希表统计频率，更高效。
