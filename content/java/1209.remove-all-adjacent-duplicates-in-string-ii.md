## 题目描述

给定字符串 s 和整数 k，反复删除由 k 个相邻且相同的字符组成的子串，直到无法继续删除，返回最终结果。

**示例：**
```
输入：s = "deeedbbcccbdaa", k = 3
输出："aa"
解释：先删 "eee" 和 "ccc"，得到 "ddbbbdaa"，再删 "bbb"，得到 "dddaa"，再删 "ddd"，得到 "aa"
```

## 解题思路

使用栈记录每个字符及其连续出现次数。遍历字符串，如果当前字符与栈顶相同则计数加一，否则入栈新元素。当计数达到 k 时弹出栈顶。

## Java 代码实现

```java
class Solution {
    public String removeDuplicates(String s, int k) {
        // 栈存储 [字符, 计数]
        Deque<int[]> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            if (!stack.isEmpty() && stack.peek()[0] == c) {
                stack.peek()[1]++;
                // 计数达到 k，弹出
                if (stack.peek()[1] == k) {
                    stack.pop();
                }
            } else {
                stack.push(new int[]{c, 1});
            }
        }
        
        // 从栈中重建字符串
        StringBuilder sb = new StringBuilder();
        for (int[] pair : stack) {
            for (int i = 0; i < pair[1]; i++) {
                sb.append((char) pair[0]);
            }
        }
        return sb.reverse().toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈 + 计数**：栈中存储 (字符, 连续次数) 对
2. **即时消除**：计数达到 k 立即弹出，自动处理链式消除
3. **逆序重建**：栈底到栈顶是逆序，最后需 reverse
4. **int[] 代替 Pair**：`int[]{char, count}` 避免创建额外类
