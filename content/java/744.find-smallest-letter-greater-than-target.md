## 题目描述

给定一个按非递减顺序排列的字符数组 letters 和一个字符 target，返回 letters 中大于 target 的最小字符。如果不存在，返回第一个字符。

**示例：**
```
输入：letters = ["c","f","j"], target = "c"
输出："f"
```

## 解题思路

二分查找第一个大于 target 的位置，越界时取模返回第一个字符。

## Java 代码实现

```java
class Solution {
    public char nextGreatestLetter(char[] letters, char target) {
        int left = 0, right = letters.length;

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (letters[mid] <= target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        // 越界则返回第一个字符
        return letters[left % letters.length];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **二分查找**：找第一个大于 target 的位置
2. **取模处理**：越界时循环回到第一个字符
3. **严格大于**：条件是 `<=` 时右移
