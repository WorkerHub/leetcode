## 题目描述

给你所有元素不同的整数数组 `nums`，若对某元素作为二分查找目标时，无论中间点如何选取都能被找到，则称该元素可二分搜索。返回可二分搜索的元素数量。

## 解题思路

元素 `nums[i]` 可二分搜索当且仅当：大于左侧所有元素且小于右侧所有元素。用前缀最大值和后缀最小值判断。

## Java 代码实现

```java
class Solution {
    public int binarySearchableNumbers(int[] nums) {
        int n = nums.length;
        int[] suffMin = new int[n + 1];
        suffMin[n] = Integer.MAX_VALUE;
        for (int i = n - 1; i >= 0; i--)
            suffMin[i] = Math.min(nums[i], suffMin[i + 1]);

        int count = 0, curMax = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            if (nums[i] > curMax && nums[i] < suffMin[i + 1]) count++;
            curMax = Math.max(curMax, nums[i]);
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 可二分搜索 = 前缀最大值 < x < 后缀最小值
2. 后缀最小值预计算，前缀最大值在线更新
3. `suffMin[i+1]` 是 i 右侧（不含 i）的最小值
