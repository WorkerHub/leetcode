## 题目描述

n 个石子，轮流取完全平方数个石子（1,4,9,16...），不能取者输。Alice 先手，判断 Alice 是否必胜。

**示例：**
```
输入：n = 4
输出：true（Alice 直接取 4 个）
```

## 解题思路

DP 博弈：dp[i] = 面对 i 个石子时当前玩家是否必胜。若存在某个完全平方数 k² 使得 dp[i-k²]=false，则 dp[i]=true。

## Java 代码实现

```java
class Solution {
    public boolean winnerSquareGame(int n) {
        boolean[] dp = new boolean[n + 1];
        
        for (int i = 1; i <= n; i++) {
            for (int k = 1; k * k <= i; k++) {
                if (!dp[i - k * k]) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × √n)
- **空间复杂度**：O(n)

## 关键点总结

1. **博弈 DP**：dp[i]=true 当且仅当存在走法让对手面临必败态
2. **完全平方数枚举**：1, 4, 9, 16...
3. **必败态传递**：能转移到对手的 false 状态就是 true
