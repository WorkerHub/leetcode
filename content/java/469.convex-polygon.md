## 题目描述

给定一个按顺序连接的多边形的顶点，判断该多边形是否为凸多边形。

**注意：**
1. 顶点个数至少为 3 个且不超过 10000。
2. 坐标范围为 -10000 到 10000。
3. 你可以假定给定的点形成的多边形均为简单多边形（简单多边形的定义）。换句话说，保证每个顶点处恰好是两条边的连接点，并且这些边互不相交。

**示例 1：**
```
输入：points = [[0,0],[0,5],[5,5],[5,0]]
输出：true
```

**示例 2：**
```
输入：points = [[0,0],[0,10],[10,10],[10,0],[5,5]]
输出：false
```

## 解题思路

判断凸多边形的核心是**叉积（Cross Product）**。

**凸多边形性质：**
- 所有内角都小于 180 度
- 或者说：沿边界行走时，始终向同一方向转（全部左转或全部右转）

**数学原理：**
- 使用向量叉积判断转向
- 对于三个连续点 A, B, C：
  - 向量 AB = (B.x - A.x, B.y - A.y)
  - 向量 BC = (C.x - B.x, C.y - B.y)
  - 叉积 = AB.x × BC.y - AB.y × BC.x
  - 叉积 > 0：左转（逆时针）
  - 叉积 < 0：右转（顺时针）
  - 叉积 = 0：共线

**判断凸多边形：**
- 遍历所有连续三个点
- 计算叉积
- 如果所有叉积符号相同（全正或全负），则为凸多边形
- 允许叉积为 0（共线的情况）

## Java 代码实现

### 方法一：叉积法（推荐）⭐

```java
class Solution {
    public boolean isConvex(List<List<Integer>> points) {
        int n = points.size();

        // 记录叉积的符号（正、负或零）
        long sign = 0;

        for (int i = 0; i < n; i++) {
            // 三个连续的点（循环）
            List<Integer> p1 = points.get(i);
            List<Integer> p2 = points.get((i + 1) % n);
            List<Integer> p3 = points.get((i + 2) % n);

            // 计算向量 p1->p2 和 p2->p3 的叉积
            long cross = crossProduct(p1, p2, p3);

            if (cross != 0) {  // 忽略共线的情况
                // 检查符号是否一致
                if (sign == 0) {
                    sign = cross;  // 记录第一个非零叉积的符号
                } else if (sign * cross < 0) {  // 符号不一致
                    return false;
                }
            }
        }

        return true;
    }

    private long crossProduct(List<Integer> p1, List<Integer> p2, List<Integer> p3) {
        // 向量 p1->p2
        long v1x = p2.get(0) - p1.get(0);
        long v1y = p2.get(1) - p1.get(1);

        // 向量 p2->p3
        long v2x = p3.get(0) - p2.get(0);
        long v2y = p3.get(1) - p2.get(1);

        // 叉积（使用 long 避免整数溢出）
        return v1x * v2y - v1y * v2x;
    }
}
```

### 方法二：简化版

```java
class Solution {
    public boolean isConvex(List<List<Integer>> points) {
        int n = points.size();
        long prev = 0;  // 记录前一个叉积的符号

        for (int i = 0; i < n; i++) {
            // 计算叉积
            long dx1 = points.get((i + 1) % n).get(0) - points.get(i).get(0);
            long dy1 = points.get((i + 1) % n).get(1) - points.get(i).get(1);
            long dx2 = points.get((i + 2) % n).get(0) - points.get((i + 1) % n).get(0);
            long dy2 = points.get((i + 2) % n).get(1) - points.get((i + 1) % n).get(1);

            long cross = dx1 * dy2 - dy1 * dx2;

            if (cross != 0) {
                // 检查符号一致性
                if (cross * prev < 0) {
                    return false;
                }
                prev = cross;
            }
        }

        return true;
    }
}
```

## 关键点总结

1. **叉积判断转向：** 正负表示左转/右转
2. **符号一致性：** 所有叉积符号相同
3. **处理共线：** 叉积为 0 时忽略
4. **循环处理：** 使用模运算处理边界
5. **简单多边形假设：** 边不相交

## 易错点

1. **忘记循环：** 最后几个点也要检查
   ```java
   // 正确：使用模运算
   points.get((i + 2) % n)
   ```

2. **叉积为零的处理：** 共线点不影响凸性
   ```java
   if (cross != 0) {
       // 只检查非零叉积
   }
   ```

3. **符号判断：** 使用乘积判断符号是否相反
   ```java
   if (sign * cross < 0) {  // 符号相反
       return false;
   }
   ```

4. **整数溢出：** 坐标范围 -10000 到 10000，叉积可达 4×10^8，需要用 long
   ```java
   // 正确：使用 long 类型
   long cross = v1x * v2y - v1y * v2x;
   ```
