## 题目描述

给你一个三位数 `n`，若将 `n`、`2*n`、`3*n` 拼接后恰好包含 1 到 9 每个数字各一次，则称其为迷人数字，返回是否满足条件。

## Java 代码实现

```java
class Solution {
    public boolean isFascinating(int n) {
        // 拼接 n、2n、3n 的字符串
        String s = "" + n + (2 * n) + (3 * n);
        if (s.length() != 9) return false;
        // 检查包含 '1'-'9' 各一次，无 '0'
        boolean[] seen = new boolean[10];
        for (char c : s.toCharArray()) {
            int d = c - '0';
            if (d == 0 || seen[d]) return false;
            seen[d] = true;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)（数字位数固定最多 9 位）
- 空间复杂度：O(1)

## 关键点总结

1. 拼接后长度必须为 9（三个三位数的拼接，但 2n/3n 可能是 4 位数时要注意）
2. 不能含 `'0'`
3. `'1'` 到 `'9'` 各出现恰好一次
