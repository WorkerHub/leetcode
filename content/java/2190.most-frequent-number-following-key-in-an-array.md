## 题目描述

统计数组中紧跟在key后面出现次数最多的数。

## 解题思路

遍历数组，当nums[i]==key时统计nums[i+1]的频次，返回频次最高的值。

## Java 代码实现

```java
class Solution {
    public int mostFrequent(int[] nums, int key) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] == key) {
                cnt.merge(nums[i + 1], 1, Integer::sum);
            }
        }
        
        int maxFreq = 0, result = 0;
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            if (e.getValue() > maxFreq) {
                maxFreq = e.getValue();
                result = e.getKey();
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **遍历到倒数第二个**：避免i+1越界
2. **只统计key后面的元素**：nums[i]==key时计数nums[i+1]
3. **取频次最大的值**
