## 题目描述

给定表达式（含花括号表示并集、相邻表示笛卡尔积），返回所有可能的单词（字典序，去重）。

**示例：**
```
输入：expression = "{a,b}{c,{d,e}}"
输出：["ac","ad","ae","bc","bd","be"]
```

## 解题思路

递归解析：按逗号分割为多个项（并集），每个项内部的因子做笛卡尔积。遇到花括号递归处理子表达式。

## Java 代码实现

```java
class Solution {
    private int i;

    public List<String> braceExpansionII(String expression) {
        i = 0;
        Set<String> result = parse(expression);
        List<String> ans = new ArrayList<>(result);
        Collections.sort(ans);
        return ans;
    }

    private Set<String> parse(String s) {
        Set<String> result = new HashSet<>();
        // 当前项的笛卡尔积
        List<Set<String>> product = new ArrayList<>();
        product.add(new HashSet<>(Arrays.asList("")));

        while (i < s.length()) {
            char c = s.charAt(i);
            if (c == '{') {
                i++; // 跳过 '{'
                Set<String> sub = parse(s);
                i++; // 跳过 '}'
                product.add(sub);
            } else if (c == '}') {
                break;
            } else if (c == ',') {
                // 并集：先计算当前项的笛卡尔积，加入结果
                result.addAll(cartesian(product));
                product.clear();
                product.add(new HashSet<>(Arrays.asList("")));
                i++;
            } else {
                // 字母
                Set<String> single = new HashSet<>();
                single.add(String.valueOf(c));
                product.add(single);
                i++;
            }
        }
        result.addAll(cartesian(product));
        return result;
    }

    private Set<String> cartesian(List<Set<String>> sets) {
        Set<String> result = sets.get(0);
        for (int j = 1; j < sets.size(); j++) {
            Set<String> next = new HashSet<>();
            for (String s1 : result) {
                for (String s2 : sets.get(j)) {
                    next.add(s1 + s2);
                }
            }
            result = next;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × M × log M)，M 为结果集大小
- **空间复杂度**：O(M)

## 关键点总结

1. **运算符优先级**：花括号 > 连接（笛卡尔积） > 并集（逗号）
2. **递归处理嵌套**：遇到 { 递归，遇到 } 返回
3. **Set 自动去重**：结果用 HashSet 存储
