## 题目描述

公路上n辆车分别向左(L)、向右(R)或静止(S)，返回碰撞涉及的汽车总数。

## 解题思路

去掉首部连续L和尾部连续R（它们不会碰撞），剩余中间部分所有非S字符都会参与碰撞。

## Java 代码实现

```java
class Solution {
    public int countCollisions(String directions) {
        int n = directions.length();
        int left = 0, right = n - 1;
        
        // 去掉首部连续L
        while (left < n && directions.charAt(left) == 'L') left++;
        // 去掉尾部连续R
        while (right >= 0 && directions.charAt(right) == 'R') right--;
        
        // 中间部分非S的数量即为答案
        int ans = 0;
        for (int i = left; i <= right; i++) {
            if (directions.charAt(i) != 'S') ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **首部L不碰撞**：向左驶出永不碰撞
2. **尾部R不碰撞**：向右驶出永不碰撞
3. **中间非S全碰撞**：去掉首尾后，所有R和L都必然参与碰撞
