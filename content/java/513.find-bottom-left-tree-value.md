## 题目描述

给定一个二叉树的根节点 `root`，请找出该二叉树**最底层最左边**节点的值。

假设二叉树中至少有一个节点。

**示例 1：**
```
输入：root = [2,1,3]
输出：1
```

**示例 2：**
```
输入：root = [1,2,3,4,null,5,6,null,null,7]
输出：7
```

**提示：**
- 树中节点数目在范围 `[1, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 解题思路

### 核心思想：
找**最底层**的**最左边**节点，有两个关键点：
1. 最底层：深度最大
2. 最左边：同一层中最左侧

### 解法对比：
- **BFS（层序遍历）**：从右到左遍历，最后一个就是答案
- **DFS**：记录最大深度及对应的最左节点

## Java 代码实现

### 方法一：BFS 层序遍历（从右到左）⭐

```java
import java.util.*;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public int findBottomLeftValue(TreeNode root) {
        // BFS 从右到左遍历，最后访问的就是最底层最左边
        // 时间复杂度：O(n)，空间复杂度：O(w)，w 是最大宽度
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int result = root.val;

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            result = node.val;

            // 先右后左，这样最后访问的是最左边
            if (node.right != null) queue.offer(node.right);
            if (node.left != null) queue.offer(node.left);
        }

        return result;
    }
}
```

### 方法二：BFS 正常层序（记录每层第一个）

```java
class Solution {
    public int findBottomLeftValue(TreeNode root) {
        // 正常的层序遍历，记录每层的第一个节点
        // 时间复杂度：O(n)，空间复杂度：O(w)
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int leftmost = root.val;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();

                // 每层的第一个节点
                if (i == 0) leftmost = node.val;

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }

        return leftmost;
    }
}
```

### 方法三：DFS（记录最大深度）

```java
class Solution {
    private int maxDepth = -1;
    private int result;

    public int findBottomLeftValue(TreeNode root) {
        // DFS，记录最大深度及对应的最左节点
        // 时间复杂度：O(n)，空间复杂度：O(h)
        result = root.val;
        dfs(root, 0);
        return result;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) return;

        // 叶子节点，检查是否更新
        if (node.left == null && node.right == null) {
            if (depth > maxDepth) {
                maxDepth = depth;
                result = node.val;
            }
        }

        // 先左后右，保证同一深度最左优先
        dfs(node.left, depth + 1);
        dfs(node.right, depth + 1);
    }
}
```

### 方法四：DFS 优化版（所有节点都检查）

```java
class Solution {
    private int maxDepth = -1;
    private int result;

    public int findBottomLeftValue(TreeNode root) {
        // DFS，检查所有节点（不只是叶子）
        // 时间复杂度：O(n)，空间复杂度：O(h)
        result = root.val;
        dfs(root, 0);
        return result;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) return;

        // 更深的层级，或同一层第一次访问
        if (depth > maxDepth) {
            maxDepth = depth;
            result = node.val;
        }

        // 先左后右
        dfs(node.left, depth + 1);
        dfs(node.right, depth + 1);
    }
}
```

## 复杂度分析

### BFS：
- **时间复杂度**：O(n)，访问所有节点
- **空间复杂度**：O(w)，w 是树的最大宽度

### DFS：
- **时间复杂度**：O(n)，访问所有节点
- **空间复杂度**：O(h)，h 是树的高度（递归栈）

## 关键点总结

1. **BFS 技巧**：从右到左遍历，最后一个就是答案
2. **DFS 技巧**：记录最大深度，先左后右保证最左优先
3. **深度定义**：根节点深度为 0（或 1，只要一致即可）
4. **更新条件**：深度严格大于时更新，保证最左
5. **边界情况**：单节点树，返回根节点值

## 易错点

1. **BFS 方向错误**：从左到右会得到最右边的值
2. **DFS 顺序错误**：先右后左会得到最右边的值
3. **深度判断**：应该用 `>` 而不是 `>=`，保证最左
4. **只检查叶子节点**：非叶子节点也可能是最左的（方法四更健壮）
5. **初始深度**：从 0 或 1 开始都可以，但要一致


## 学习建议

**对于新手：**
1. 先掌握 BFS 层序遍历的基本模板
2. 理解方法一的巧妙之处（从右到左）
3. 学习 DFS 深度记录的技巧

**进阶学习：**
1. 对比 BFS 和 DFS 的空间复杂度差异
2. 理解为什么先左后右很重要
3. 尝试不同的深度定义方式

**实战技巧：**
- "最底层" + "最左边" → BFS 或 DFS + 深度记录
- BFS 适合层级相关问题
- DFS 递归栈空间通常小于 BFS 队列
