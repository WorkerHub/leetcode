## 题目描述

苹果树每天 `i` 产出 `apples[i]` 个苹果，在第 `i + days[i]` 天后腐烂。每天最多吃一个苹果，返回最多能吃多少个。

## 解题思路

**贪心 + 最小堆：** 每天优先吃过期时间最早的苹果（避免浪费）。最小堆存 `(过期日期, 数量)`，每天加入新苹果，清除过期苹果，吃堆顶苹果。

## Java 代码实现

```java
class Solution {
    public int eatenApples(int[] apples, int[] days) {
        int n = apples.length;
        // 最小堆，按过期日期排序
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        int eaten = 0, i = 0;

        while (i < n || !pq.isEmpty()) {
            // 加入今天产生的苹果
            if (i < n && apples[i] > 0) {
                pq.offer(new int[]{i + days[i], apples[i]});
            }
            // 清除已过期的苹果（过期日 <= 今天）
            while (!pq.isEmpty() && pq.peek()[0] <= i) pq.poll();
            // 吃过期最早的苹果
            if (!pq.isEmpty()) {
                int[] top = pq.poll();
                eaten++;
                if (top[1] > 1) pq.offer(new int[]{top[0], top[1] - 1});
            }
            i++;
        }
        return eaten;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：优先吃最快过期的苹果
2. 过期日期 = `i + days[i]`（该天起不能吃）
3. 苹果生产结束后继续处理堆中剩余苹果
