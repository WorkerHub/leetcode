## 题目描述

计算数组中所有奇数长度子数组的和。

**示例：**
```
输入：arr = [1,4,2,5,3]
输出：58
```

## 解题思路

数学方法：每个元素被包含在 ((i+1)*(n-i)+1)/2 个奇数长度子数组中。

## Java 代码实现

```java
class Solution {
    public int sumOddLengthSubarrays(int[] arr) {
        int n = arr.length, sum = 0;
        for (int i = 0; i < n; i++) {
            // arr[i] 被包含在奇数长度子数组中的次数
            int count = ((i + 1) * (n - i) + 1) / 2;
            sum += arr[i] * count;
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贡献法**：每个元素乘以其出现在奇数长度子数组的次数
2. **公式**：((i+1)*(n-i)+1)/2
