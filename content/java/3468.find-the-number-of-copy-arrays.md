## 题目描述

给你整数数组 `original` 和二维数组 `bounds`，其中 `bounds[i] = [li, ri]`。复制数组 `copy` 满足相邻差与 `original` 相同且 `li <= copy[i] <= ri`，返回满足条件的不同复制数组数量。

## 解题思路

`copy[i] = original[i] + k`（常数偏移 k），每个约束给出 `li - original[i] <= k <= ri - original[i]`，取所有约束的交集，答案为交集内整数个数。

## Java 代码实现

```java
class Solution {
    public int countArrays(int[] original, int[][] bounds) {
        long maxLower = Long.MIN_VALUE;
        long minUpper = Long.MAX_VALUE;

        for (int i = 0; i < original.length; i++) {
            // copy[i] = original[i] + k，约束 k 的范围
            long lower = (long) bounds[i][0] - original[i];
            long upper = (long) bounds[i][1] - original[i];
            maxLower = Math.max(maxLower, lower);
            minUpper = Math.min(minUpper, upper);
        }

        return (int) Math.max(0, minUpper - maxLower + 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 复制数组是原数组加上一个常数偏移 k
2. 每个位置约束给出 k 的范围，取所有范围的交集
3. 答案为交集内整数个数，使用 `long` 防止溢出
