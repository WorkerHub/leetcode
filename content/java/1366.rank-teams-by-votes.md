## 题目描述

按投票规则对参赛团队排名：优先比较各位置得票数（降序），所有位置票数相同时按队名字典序升序，返回排名结果字符串。

## 解题思路

用二维数组 `count[team][pos]` 记录每个队伍在各位置的票数，然后自定义比较器：依次比较各位置票数（降序），最终决胜用队名字典序（升序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String rankTeams(String[] votes) {
        int n = votes[0].length(); // 队伍数量
        // count[i][j]：第 i 个队伍（'A'+i）在第 j 位置的票数
        int[][] count = new int[26][n];

        for (String vote : votes) {
            for (int pos = 0; pos < n; pos++) {
                count[vote.charAt(pos) - 'A'][pos]++;
            }
        }

        // 获取所有参赛队伍字母
        Character[] teams = new Character[n];
        for (int i = 0; i < n; i++) {
            teams[i] = votes[0].charAt(i);
        }

        // 自定义排序：各位置票数降序，最后按字母升序决胜
        Arrays.sort(teams, (a, b) -> {
            int ia = a - 'A', ib = b - 'A';
            for (int pos = 0; pos < n; pos++) {
                if (count[ia][pos] != count[ib][pos]) {
                    return count[ib][pos] - count[ia][pos]; // 票数多的排前
                }
            }
            return a - b; // 字典序升序决胜
        });

        // 构造结果字符串
        StringBuilder sb = new StringBuilder();
        for (char t : teams) {
            sb.append(t);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(V×N + N²×log N)，V 为投票数，N 为队伍数（最多 26）。统计 O(V×N)，排序 O(N log N)，每次比较 O(N)。
- 空间复杂度：O(N²)，存储各队伍各位置票数。

## 关键点总结

1. 用 26×N 的二维数组存储各队在各位置的票数，N 最大为 26。
2. 自定义比较器依次比较各位置票数（降序），所有位置相同才按字母升序。
3. 使用 `Character[]` 而非 `char[]`，以便 `Arrays.sort` 接受自定义 Comparator。
