## 题目描述

给你一个字符串 `s`，它由数字（`'0'` - `'9'`）和 `'#'` 组成。我们希望按下述规则将 `s` 映射为一些小写英文字符：

- 字符（`'a'` - `'i'`）分别用（`'1'` - `'9'`）表示
- 字符（`'j'` - `'z'`）分别用（`'10#'` - `'26#'`）表示

返回映射之后形成的新字符串。

题目数据保证映射始终唯一。

示例 1：
```
输入：s = "10#11#12"
输出："jkab"
解释："j" -> "10#" , "k" -> "11#" , "a" -> "1" , "b" -> "2"
```

示例 2：
```
输入：s = "1326#"
输出："acz"
```

示例 3：
```
输入：s = "25#"
输出："y"
```

提示：
- `1 <= s.length <= 1000`
- `s` 只包含数字和 `'#'` 字符
- `s` 是映射始终存在的有效字符串

## 解题思路

这道题的关键是识别两种模式：
1. 单个数字 `'1'-'9'` 映射到 `'a'-'i'`
2. 两位数字 + `'#'`（如 `'10#'`）映射到 `'j'-'z'`

### 思路一：从右向左遍历
从右向左遍历字符串，遇到 `'#'` 就取前面两位数字，否则取一位数字。

### 思路二：从左向右遍历
从左向右遍历，检查当前位置后面第二个字符是否为 `'#'`。

## Java 代码实现

### 方法一：从右向左（推荐）

```java
class Solution {
    public String freqAlphabets(String s) {
        StringBuilder result = new StringBuilder();
        int i = s.length() - 1;
        
        while (i >= 0) {
            // 如果当前是 '#'，取前面两位数字
            if (s.charAt(i) == '#') {
                int num = Integer.parseInt(s.substring(i - 2, i));
                result.append((char)('a' + num - 1));
                i -= 3;
            } else {
                // 单个数字
                int num = s.charAt(i) - '0';
                result.append((char)('a' + num - 1));
                i -= 1;
            }
        }
        
        // 反转结果（因为是从右向左处理的）
        return result.reverse().toString();
    }
}
```

### 方法二：从左向右

```java
class Solution {
    public String freqAlphabets(String s) {
        StringBuilder result = new StringBuilder();
        int i = 0;
        int n = s.length();
        
        while (i < n) {
            // 检查后面第二个位置是否有 '#'
            if (i + 2 < n && s.charAt(i + 2) == '#') {
                // 取两位数字
                int num = Integer.parseInt(s.substring(i, i + 2));
                result.append((char)('a' + num - 1));
                i += 3;
            } else {
                // 单个数字
                int num = s.charAt(i) - '0';
                result.append((char)('a' + num - 1));
                i += 1;
            }
        }
        
        return result.toString();
    }
}
```

### 方法三：使用栈

```java
import java.util.*;

class Solution {
    public String freqAlphabets(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            stack.push(c);
            
            // 检查栈顶是否形成 数字数字# 模式
            if (stack.peek() == '#' && stack.size() >= 3) {
                stack.pop(); // 移除 '#'
                char digit2 = stack.pop();
                char digit1 = stack.pop();
                int num = Integer.parseInt("" + digit1 + digit2);
                stack.push((char)('a' + num - 1));
            }
        }
        
        // 收集结果（栈是逆序的）
        StringBuilder result = new StringBuilder();
        while (!stack.isEmpty()) {
            char c = stack.pop();
            if (Character.isDigit(c)) {
                result.append((char)('a' + (c - '0') - 1));
            } else {
                result.append(c);
            }
        }
        
        return result.reverse().toString();
    }
}
```

## 复杂度分析

### 方法一、二
- 时间复杂度：O(n)，遍历一次字符串
- 空间复杂度：O(n)，存储结果

## 关键点总结

1. 识别两种模式：单数字和双数字+#
2. 从右向左处理可以直接判断是否为 '#'
3. 从左向右需要向前看两位
4. 使用 `'a' + num - 1` 转换数字到字母
5. Java 中字符类型可以直接加减整数

## 易错点

1. 数字到字母的转换公式错误（应该是 `num - 1`）
2. 从右向左遍历后忘记反转结果
3. 边界检查不完整（检查 `i + 2 < n`）
4. Integer.parseInt 参数要正确截取子字符串

## 图解示例

以 s = "10#11#12" 为例（从左向右）：

```
位置 0: s[0..1] = "10", s[2] = '#'
  → 匹配 "10#"，转换为 'j'，i 移动到 3

位置 3: s[3..4] = "11", s[5] = '#'
  → 匹配 "11#"，转换为 'k'，i 移动到 6

位置 6: s[6] = "1", i+2 >= len(s)
  → 单个数字，转换为 'a'，i 移动到 7

位置 7: s[7] = "2"
  → 单个数字，转换为 'b'，i 移动到 8

结果："jkab"
```
