## 题目描述

给你数组 `maximumHeight`，为每座塔设置不超过限制且互不相同的正整数高度，返回高度总和的最大值，无法满足返回 -1。

## 解题思路

贪心：降序排序后，第一座塔取最大高度，后续每座塔取 `min(当前限制, 前一座高度-1)`。若高度降至 0 则无解。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maximumTotalSum(int[] maximumHeight) {
        int[] heights = maximumHeight.clone();
        Arrays.sort(heights);
        int n = heights.length;
        long total = heights[n - 1]; // 最大限制的塔取最大高度
        int prev = heights[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            prev = Math.min(heights[i], prev - 1); // 不超过限制且比前一座矮
            if (prev <= 0) return -1;
            total += prev;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 降序排序：限制最大的塔优先分配高值
2. 每座塔高度 = min(自身限制, 前一座高度 - 1)，保证互不相同
3. 若高度降至 0 则说明塔太多，无法满足互不相同，返回 -1
