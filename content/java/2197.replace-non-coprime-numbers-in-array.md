## 题目描述

不断将相邻非互质数对替换为其LCM，直到无相邻非互质对，返回最终数组。

## 解题思路

栈模拟：每次入栈后与栈顶不断合并直到互质。合并公式lcm(a,b)=a/gcd(a,b)*b。

## Java 代码实现

```java
class Solution {
    public List<Integer> replaceNonCoprimes(int[] nums) {
        LinkedList<Long> stack = new LinkedList<>();
        
        for (int x : nums) {
            long cur = x;
            // 与栈顶不断合并直到互质
            while (!stack.isEmpty()) {
                long top = stack.peekLast();
                long g = gcd(top, cur);
                if (g == 1) break;
                stack.pollLast();
                cur = top / g * cur; // LCM
            }
            stack.addLast(cur);
        }
        
        List<Integer> result = new ArrayList<>();
        for (long v : stack) {
            result.add((int) v);
        }
        return result;
    }
    
    private long gcd(long a, long b) {
        while (b != 0) {
            long t = b;
            b = a % b;
            a = t;
        }
        return a;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log(max_val))
- **空间复杂度**：O(N)

## 关键点总结

1. **栈模拟合并**：新元素入栈后与栈顶不断合并直到互质
2. **LCM公式**：lcm(a,b) = a / gcd(a,b) * b，先除后乘防溢出
3. **while循环**：合并后新值可能与更早元素不互质，需继续检查
