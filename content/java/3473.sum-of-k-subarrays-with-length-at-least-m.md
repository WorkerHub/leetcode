## 题目描述

给你整数数组 `nums` 和正整数 `k`、`m`，从 `nums` 中选取 k 个不重叠且每个长度至少为 m 的子数组，使元素之和最大，返回该最大和。

## 解题思路

DP + 前缀和：`dp[i][j]` 表示从 `nums[0..i-1]` 中选 j 个合法子数组的最大和。转移时利用前缀和将"以 i 结尾的子数组和"表示为 `prefix[i] - prefix[l]`，维护 `max(dp[l][j-1] - prefix[l])` 随 i 增大逐步更新，使内层转移 O(1)。

## Java 代码实现

```java
class Solution {
    public long maxSumOfKSubarrays(int[] nums, int k, int m) {
        int n = nums.length;
        long NEG_INF = Long.MIN_VALUE / 2;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // 滚动数组：prev[i] = dp[i][j-1]
        long[] prev = new long[n + 1];
        for (int i = 1; i <= n; i++) prev[i] = NEG_INF;
        prev[0] = 0;

        for (int j = 1; j <= k; j++) {
            long[] curr = new long[n + 1];
            for (int i = 1; i <= n; i++) curr[i] = NEG_INF;
            long maxPrev = NEG_INF;

            for (int i = 1; i <= n; i++) {
                // 不选以 i 结尾的子数组
                if (curr[i - 1] != NEG_INF)
                    curr[i] = Math.max(curr[i], curr[i - 1]);

                // 更新 maxPrev：在 i >= m 时，l = i-m 可作为起点
                if (i >= m) {
                    int l = i - m;
                    if (prev[l] != NEG_INF)
                        maxPrev = Math.max(maxPrev, prev[l] - prefix[l]);
                }

                // 选以位置 i-1 结尾、长度 >= m 的子数组
                if (maxPrev != NEG_INF)
                    curr[i] = Math.max(curr[i], maxPrev + prefix[i]);
            }

            prev = curr;
        }

        return prev[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(n)（滚动数组）

## 关键点总结

1. 转移分解：子数组和 = `prefix[i] - prefix[l]`，维护 `max(prev[l] - prefix[l])` 做到 O(1) 转移
2. `curr[i] = curr[i-1]` 表示不选以 i 结尾的子数组（继承前面最优解）
3. maxPrev 在 `i >= m` 时才开始更新，保证子数组长度至少为 m
