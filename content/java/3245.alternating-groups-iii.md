## 题目描述

给你圆形颜色数组 `colors` 和查询数组，查询类型 1 统计长度为 `size` 的交替组数量，类型 2 修改某位置颜色，返回所有类型 1 查询的结果。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> numberOfAlternatingGroups(int[] colors, int[][] queries) {
        int n = colors.length;
        // alt[i]: 从位置 i 开始向右的最长交替序列长度
        int[] alt = new int[n];

        // 预计算 alt 数组（逆序，圆形处理）
        computeAlt(colors, alt, n);

        List<Integer> result = new ArrayList<>();
        for (int[] q : queries) {
            if (q[0] == 1) {
                // 统计 alt[i] >= size 的位置数
                int size = q[1];
                int count = 0;
                for (int i = 0; i < n; i++) {
                    if (alt[i] >= size) count++;
                }
                result.add(count);
            } else {
                // 修改颜色并重新计算
                int idx = q[1], col = q[2];
                if (colors[idx] != col) {
                    colors[idx] = col;
                    computeAlt(colors, alt, n);
                }
            }
        }
        return result;
    }

    private void computeAlt(int[] colors, int[] alt, int n) {
        // 逆序计算圆形的交替延伸长度
        // 先做两圈展开处理圆形
        for (int i = 2 * n - 1; i >= 0; i--) {
            int cur = i % n;
            int next = (i + 1) % n;
            if (colors[cur] != colors[next]) {
                alt[cur] = (i < n ? Math.min(alt[next] + 1, n) : 1);
            } else {
                alt[cur] = 1;
            }
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) * n)，每次操作 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 圆形交替组通过"交替延伸长度"描述，alt[i] >= size 则位置 i 是有效起点
2. 修改一个位置后重新计算整个 alt 数组
3. 完整优化版（树状数组维护段长分布）可达 O((n+q) log n)
