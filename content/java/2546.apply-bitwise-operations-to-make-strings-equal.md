## 题目描述

给你两个二进制字符串 `s` 和 `target`，每次操作可选两个不同下标 i、j 执行 `s[i] = s[i] OR s[j]`，`s[j] = s[i] XOR s[j]`，判断能否通过若干次操作使 `s == target`。

## 解题思路

分析操作效果：操作只能在"有 1 时传播 1 或消除 1"，但无法凭空创造 1，也无法消灭最后一个 1。结论：s 和 target 是否包含 1 必须一致。

## Java 代码实现

```java
class Solution {
    public boolean makeStringsEqual(String s, String target) {
        // 可达条件：s 和 target 对"是否含 1"必须一致
        boolean sHasOne = s.contains("1");
        boolean tHasOne = target.contains("1");
        return sHasOne == tHasOne;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 操作不能凭空创造 1，只能在有 1 时传播或消除
2. 若 s 全为 0，永远无法产生 1；若 s 有 1，无法消灭所有 1
3. 结论只需判断两串是否均含/均不含 1
