## 题目描述

给你整数 `n`，返回满足 `1 <= a <= b <= n` 且 `a^2 + b^2` 是完全平方数的整数对数目。

## 解题思路

n <= 250，直接暴力枚举所有对 (a, b)，检查 a^2 + b^2 是否为完全平方数（用整数开方判断）。

## Java 代码实现

```java
class Solution {
    public int countPairs(int n) {
        int count = 0;
        for (int a = 1; a <= n; a++) {
            for (int b = a; b <= n; b++) {
                int s = a * a + b * b;
                int root = (int) Math.sqrt(s);
                // 判断 s 是否是完全平方数
                if (root * root == s) count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(1)

## 关键点总结

1. n 很小（≤ 250），O(n^2) 暴力枚举完全可行
2. 判断完全平方数：`(int)sqrt(s) * (int)sqrt(s) == s`
3. 注意 `a <= b`（允许 a = b）
