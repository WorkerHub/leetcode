## 题目描述

给你一个整数数组 `nums`，和一个整数 `k`。

在一个操作中，您可以选择 `0 <= i < nums.length` 的任何索引 `i`。将 `nums[i]` 改为 `nums[i] + x`，其中 `x` 是一个范围为 `[-k, k]` 的任意整数。对于每个索引 `i`，最多 **只能** 应用 **一次** 此操作。

`nums` 的 **分数** 是 `nums` 中最大和最小元素的差值。

在对 `nums` 中的每个索引最多应用一次上述操作后，返回 `nums` 的最低 **分数**。

**示例 1：**
```
输入：nums = [1], k = 0
输出：0
解释：分数是 max(nums) - min(nums) = 1 - 1 = 0。
```

**示例 2：**
```
输入：nums = [0,10], k = 2
输出：6
解释：将 nums 改为 [2,8]。分数是 max(nums) - min(nums) = 8 - 2 = 6。
```

**示例 3：**
```
输入：nums = [1,3,6], k = 3
输出：0
解释：将 nums 改为 [4,4,4] 或 [3,3,3] 或 [2,2,2]。分数是 max(nums) - min(nums) = 0。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^4`
- `0 <= k <= 10^4`

## 解题思路

这道题的目标是通过调整数组中每个元素（最多加减 k），使得调整后数组的最大值和最小值的差值最小。

**核心思想：**
1. 原数组的最大值是 `max_val`，最小值是 `min_val`
2. 为了缩小差值，我们应该：
   - 让最大值尽可能变小：`max_val - k`
   - 让最小值尽可能变大：`min_val + k`
3. 如果 `min_val + k >= max_val - k`，说明可以让所有数相等，差值为 0
4. 否则，最小差值为 `(max_val - k) - (min_val + k) = max_val - min_val - 2k`

**数学推导：**
- 原始差值：`max_val - min_val`
- 最多可以缩小：`2k`（最大值减 k，最小值加 k）
- 最小差值：`max(0, max_val - min_val - 2k)`

## Java 代码实现

### 方法一：直接计算（推荐）

```java
class Solution {
    public int smallestRangeI(int[] nums, int k) {
        int maxVal = nums[0];
        int minVal = nums[0];

        // 找到数组的最大值和最小值
        for (int num : nums) {
            maxVal = Math.max(maxVal, num);
            minVal = Math.min(minVal, num);
        }

        // 计算调整后的最小差值
        // 最大值最多减 k，最小值最多加 k
        // 如果能让它们重叠或相等，差值为 0
        // 否则差值为原差值减去 2k
        return Math.max(0, maxVal - minVal - 2 * k);
    }
}
```

### 方法二：使用 Java 流

```java
import java.util.Arrays;

class Solution {
    public int smallestRangeI(int[] nums, int k) {
        int maxVal = Arrays.stream(nums).max().getAsInt();
        int minVal = Arrays.stream(nums).min().getAsInt();
        return Math.max(0, maxVal - minVal - 2 * k);
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历数组找到最大值和最小值

**空间复杂度：** O(1)
- 只使用常数额外空间

## 关键点总结

1. **贪心策略**：让最大值变小，最小值变大，缩小差值
2. **数学计算**：最小差值 = `max(0, 原差值 - 2k)`
3. **边界情况**：差值可能为负，要用 `Math.max(0, ...)` 处理
4. **简单问题**：不需要真的去调整数组，直接数学计算即可
5. **单次操作**：每个元素只能调整一次，所以最多调整 k

## 易错点

1. **忘记乘以 2**：最大值和最小值同时调整，总共可以缩小 2k
2. **负数情况**：差值可能小于 0，要用 `Math.max(0, ...)` 保证非负
3. **单元素数组**：只有一个元素时差值为 0（代码自动处理）
4. **理解题意**：每个元素只能操作一次，不是可以任意调整
