## 题目描述

给定一棵二叉搜索树和其中的一个节点 `node`，找到该节点在树中的中序后继。如果节点没有中序后继，请返回 `null`。

一个节点 `node` 的中序后继是键值大于 `node.val` 且键值最小的节点。

你可以直接访问节点，但无法直接访问树的根节点。每个节点都有其父节点的引用。节点定义如下：

```java
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node parent;
}
```

**示例 1：**
```
输入：tree = [2,1,3], node = 1
输出：2
解释：1 的中序后继是 2。注意节点和返回值都是 Node 类型的。
```

**示例 2：**
```
输入：tree = [5,3,6,2,4,null,null,1], node = 6
输出：null
解释：该节点没有中序后继，因此返回 null。
```

**示例 3：**
```
输入：tree = [15,6,18,3,7,17,20,2,4,null,13,...], node = 15
输出：17
```

**提示：**
- 树中节点的数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`
- 树中所有节点的值都是唯一的

**进阶：** 你能否在不访问任何节点的值的情况下解决问题？

## 解题思路

这道题与 [285. Inorder Successor in BST](https://leetcode.com/problems/inorder-successor-in-bst/) 不同之处在于：
1. **没有给出根节点**，但每个节点有父节点引用
2. 需要直接从给定节点找中序后继

### 核心思想：
BST 的中序后继有两种情况：
1. **如果节点有右子树**：后继是右子树的最左节点
2. **如果节点无右子树**：向上找父节点，直到找到一个节点是其父节点的左孩子

### 算法流程：

**情况 1：有右子树**
```
node → 右子树的最左节点
```

**情况 2：无右子树**
```
向上找父节点，直到：
- 当前节点是父节点的左孩子（父节点就是后继）
- 或到达根节点（无后继）
```

## Java 代码实现

### 方法一：分类讨论（推荐）⭐

```java
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node parent;
}

class Solution {
    public Node inorderSuccessor(Node node) {
        // BST 中序后继
        // 时间复杂度：O(h)，h 是树的高度
        // 空间复杂度：O(1)

        // 情况 1：如果有右子树
        if (node.right != null) {
            // 后继是右子树的最左节点
            Node successor = node.right;
            while (successor.left != null) {
                successor = successor.left;
            }
            return successor;
        }

        // 情况 2：没有右子树
        // 向上找，直到找到一个节点是其父节点的左孩子
        while (node.parent != null) {
            // 如果当前节点是父节点的左孩子
            if (node.parent.left == node) {
                return node.parent;
            }
            // 否则继续向上
            node = node.parent;
        }

        // 到达根节点还没找到，说明没有后继
        return null;
    }
}
```

### 方法二：统一处理（更简洁）

```java
class Solution {
    public Node inorderSuccessor(Node node) {
        // 更简洁的实现
        // 时间复杂度：O(h)，空间复杂度：O(1)

        // 有右子树：找右子树最小值
        if (node.right != null) {
            node = node.right;
            while (node.left != null) {
                node = node.left;
            }
            return node;
        }

        // 无右子树：向上找第一个左转的祖先
        while (node.parent != null && node == node.parent.right) {
            node = node.parent;
        }

        return node.parent;
    }
}
```

### 方法三：递归实现

```java
class Solution {
    public Node inorderSuccessor(Node node) {
        // 递归实现
        // 时间复杂度：O(h)，空间复杂度：O(h)

        // 情况 1：有右子树
        if (node.right != null) {
            return findMin(node.right);
        }

        // 情况 2：无右子树，递归向上找
        return findSuccessorUp(node);
    }

    private Node findMin(Node node) {
        // 找子树的最小节点
        while (node.left != null) {
            node = node.left;
        }
        return node;
    }

    private Node findSuccessorUp(Node node) {
        // 向上找后继
        if (node.parent == null) return null;

        // 如果是父节点的左孩子，父节点就是后继
        if (node.parent.left == node) {
            return node.parent;
        }

        // 否则继续向上找
        return findSuccessorUp(node.parent);
    }
}
```

### 方法四：进阶解法（不访问节点值）

```java
class Solution {
    public Node inorderSuccessor(Node node) {
        // 进阶：不访问节点值
        // 仅通过指针关系判断
        // 时间复杂度：O(h)，空间复杂度：O(1)

        // 有右子树
        if (node.right != null) {
            // 找右子树最左节点
            Node result = node.right;
            while (result.left != null) {
                result = result.left;
            }
            return result;
        }

        // 无右子树
        // 向上找到第一个"从左边上来"的祖先
        Node child = node;
        Node parent = node.parent;

        while (parent != null) {
            // 如果从左边上来，parent 就是后继
            if (parent.left == child) {
                return parent;
            }
            // 从右边上来，继续向上
            child = parent;
            parent = parent.parent;
        }

        return null;
    }
}
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(h)，h 是树的高度
  - 最坏情况：从叶子节点到根节点
  - 平衡树：O(log n)
  - 链状树：O(n)
- **空间复杂度**：
  - 迭代：O(1)
  - 递归：O(h)

## 关键点总结

1. **两种情况**：有右子树 vs 无右子树
2. **有右子树**：后继是右子树的最小值（最左节点）
3. **无右子树**：向上找第一个"左转"的祖先
4. **终止条件**：到达根节点仍未找到 → 无后继
5. **不需要根节点**：利用 parent 指针即可

## 易错点

1. **忘记右子树情况**：有右子树时不需要向上找
2. **左右孩子判断**：要用 `==` 判断引用，不是比较值
3. **空指针检查**：访问 `.parent` 前要检查是否为 null
4. **返回值**：找不到后继时返回 null
5. **循环条件**：while 条件要正确，避免死循环
