## 题目描述

第 1 天有 1 人知道秘密，知道后第 `delay` 天起每天可传播给一个新人，第 `forget` 天会忘记（忘记前仍可传播）。返回第 n 天末知道秘密的人数（模 10^9+7）。

## 解题思路

DP + 滑动窗口：`dp[i]` 为第 i 天新增知道秘密的人数。维护可传播的人数 `spread`，第 `i-delay` 天新增的人开始加入可传播集合，第 `i-forget` 天新增的人移出。最终答案为第 `[n-forget+1, n]` 天的 dp 之和。

## Java 代码实现

```java
class Solution {
    public int peopleAwareOfSecret(int n, int delay, int forget) {
        final int MOD = 1_000_000_007;
        long[] dp = new long[n + 1];
        dp[1] = 1;
        long spread = 0; // 当前可传播的人数

        for (int i = 2; i <= n; i++) {
            if (i - delay >= 1) spread = (spread + dp[i - delay]) % MOD;   // 新加入传播
            if (i - forget >= 1) spread = (spread - dp[i - forget] + MOD) % MOD; // 忘记退出
            dp[i] = spread;
        }

        // 统计第 n 天末仍知道秘密的人（第 n-forget+1 到 n 天新增的）
        long ans = 0;
        for (int i = Math.max(1, n - forget + 1); i <= n; i++) {
            ans = (ans + dp[i]) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `dp[i]` 记录第 i 天新增人数，用滑动窗口 O(1) 维护可传播总数。
2. 减法取模需加 MOD 防止负数：`(spread - dp[i-forget] + MOD) % MOD`。
3. 最终答案只统计尚未忘记的人（第 `[n-forget+1, n]` 天新增）。
