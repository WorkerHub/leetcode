## 题目描述

给你下标从 1 开始的整数数组 nums，若下标集合中任意两下标 i、j 的乘积为完全平方数，则为完全子集，返回完全子集元素之和的最大值。

## 解题思路

两下标乘积为完全平方数当且仅当它们的无平方因子部分（square-free part）相同；对所有下标计算 square-free part 后分组累加，取最大组的和。

## Java 代码实现

```java
class Solution {
    public long maximumSum(List<Integer> nums) {
        int n = nums.size();
        Map<Integer, Long> groups = new HashMap<>();

        for (int i = 1; i <= n; i++) {
            int key = squareFreePart(i);
            groups.merge(key, (long) nums.get(i - 1), Long::sum);
        }

        long ans = 0;
        for (long v : groups.values()) ans = Math.max(ans, v);
        return ans;
    }

    // 计算 x 的无平方因子部分（去掉所有偶数次幂质因子）
    private int squareFreePart(int x) {
        int result = 1;
        for (int d = 2; (long) d * d <= x; d++) {
            int cnt = 0;
            while (x % d == 0) { cnt++; x /= d; }
            if ((cnt & 1) == 1) result *= d; // 奇数次幂保留
        }
        return result * x; // 剩余质因子（必然奇数次）
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × sqrt(n))
- **空间复杂度**：O(n)

## 关键点总结

1. 乘积为完全平方数 ⟺ square-free part 相同
2. Square-free part：对每个质因子，只保留奇数次幂的部分
3. 同组所有下标都选取，同组之和即为候选答案
