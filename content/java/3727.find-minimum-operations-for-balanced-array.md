## 题目描述

给定整数数组 `nums`，每次操作将任意元素加 1 或减 1（代价为 1），求使所有元素相等（变为中位数）所需的最小总操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minOperations(int[] nums) {
        Arrays.sort(nums);
        int median = nums[nums.length / 2];
        long total = 0;
        for (int x : nums) total += Math.abs(x - median);
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(1)

## 关键点总结

1. 将所有数改为中位数时绝对差之和最小（中位数最优性定理）
2. 偶数个元素时取中间两个值之任一，结果相同
3. 答案可能较大，返回类型用 `long`
