## 题目描述

在预算内购买股票（每支最多一次），最大化利润（future-present之和）。

## 解题思路

0/1背包：物品为利润>0的股票，重量为present[i]，价值为future[i]-present[i]，容量为budget。

## Java 代码实现

```java
class Solution {
    public int maximumProfit(int[] present, int[] future, int budget) {
        int[] dp = new int[budget + 1];
        for (int i = 0; i < present.length; i++) {
            int profit = future[i] - present[i];
            if (profit <= 0) continue;
            // 0/1背包倒序
            for (int j = budget; j >= present[i]; j--) {
                dp[j] = Math.max(dp[j], dp[j - present[i]] + profit);
            }
        }
        return dp[budget];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * budget)
- **空间复杂度**：O(budget)

## 关键点总结

1. **0/1背包**：每支股票最多买一次
2. **跳过亏损股票**：profit<=0不考虑
3. **倒序遍历容量**：保证每支只用一次
