## 题目描述

有 n 个房间（0~n-1），初始只有 0 号房间解锁。每个房间有一些钥匙可以开其他房间。判断能否进入所有房间。

**示例：**
```
输入：rooms = [[1],[2],[3],[]]
输出：true
```

## 解题思路

图的遍历：从 0 号房间出发 DFS/BFS，判断能否访问所有节点。

## Java 代码实现

```java
class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] visited = new boolean[n];
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        visited[0] = true;
        int count = 1;

        while (!stack.isEmpty()) {
            int room = stack.pop();
            for (int key : rooms.get(room)) {
                if (!visited[key]) {
                    visited[key] = true;
                    count++;
                    stack.push(key);
                }
            }
        }

        return count == n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 为房间数，m 为钥匙总数
- **空间复杂度**：O(n)

## 关键点总结

1. **图遍历**：本质是有向图可达性问题
2. **DFS/BFS 均可**：从 0 出发遍历
3. **计数判断**：访问过的房间数 == 总房间数
