## 题目描述

巧克力条由若干小块组成，甜度为 sweetness[i]。需分成 k+1 段（和 k 个朋友分享），你吃甜度最小的那段。最大化你能得到的最小甜度。

**示例：**
```
输入：sweetness = [1,2,3,4,5,6,7,8,9], k = 5
输出：6（分法 [1,2,3],[4,5],[6],[7],[8],[9]）
```

## 解题思路

二分答案：二分"你能得到的最小甜度"。对于每个 mid，贪心验证能否切出至少 k+1 段且每段甜度 ≥ mid。

## Java 代码实现

```java
class Solution {
    public int maximizeSweetness(int[] sweetness, int k) {
        int left = 1;
        int right = 0;
        for (int s : sweetness) right += s;
        right /= (k + 1);
        
        while (left < right) {
            int mid = left + (right - left + 1) / 2;
            if (canDivide(sweetness, k + 1, mid)) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }
    
    // 贪心验证：能否切出至少 pieces 段，每段甜度 >= minSweet
    private boolean canDivide(int[] sweetness, int pieces, int minSweet) {
        int count = 0, sum = 0;
        for (int s : sweetness) {
            sum += s;
            if (sum >= minSweet) {
                count++;
                sum = 0;
            }
        }
        return count >= pieces;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(sum/k))
- **空间复杂度**：O(1)

## 关键点总结

1. **最大化最小值**：二分答案的经典模式
2. **贪心验证**：累积和 ≥ mid 就切一刀
3. **二分上界**：总和/(k+1) 为理论最大值
4. **左闭右闭**：求最大可行值，mid 取右中位数
