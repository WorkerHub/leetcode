## 题目描述

给定有向图，判断从 source 出发的所有路径是否都以 destination 结束（无环、无死胡同、路径有限）。

**示例：**
```
输入：n = 4, edges = [[0,1],[0,2],[1,3],[2,3]], source = 0, destination = 3
输出：true
```

## 解题思路

DFS + 三色标记：白色(未访问)、灰色(访问中,用于环检测)、黑色(已完成)。检查：目标无出边、无环、非目标叶子无效。

## Java 代码实现

```java
class Solution {
    private List<List<Integer>> graph;
    private int[] state; // 0:白, 1:灰, 2:黑
    private int destination;

    public boolean leadsToDestination(int n, int[][] edges, int source, int destination) {
        this.destination = destination;
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) graph.get(e[0]).add(e[1]);

        // 目标节点不能有出边
        if (!graph.get(destination).isEmpty()) return false;

        state = new int[n];
        return dfs(source);
    }

    private boolean dfs(int node) {
        if (node == destination) return true;

        // 灰色节点 → 有环
        if (state[node] == 1) return false;
        // 黑色节点 → 已验证通过
        if (state[node] == 2) return true;

        // 非目标节点无出边 → 死胡同
        if (graph.get(node).isEmpty()) return false;

        state[node] = 1; // 标记为灰色

        for (int neighbor : graph.get(node)) {
            if (!dfs(neighbor)) return false;
        }

        state[node] = 2; // 标记为黑色
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **三色标记**：区分"正在访问"和"已完成"来检测环
2. **目标无出边**：destination 不能有出边
3. **非目标叶子**：无出边的非目标节点意味着路径无效
