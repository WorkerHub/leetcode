## 题目描述

给定指令数组 `instructions`（"add" 或 "jump"）和 `values`。从索引 0 开始："add" 则分数加 `values[i]` 并移到 i+1；"jump" 则移到 `i + values[i]`。越界时停止。返回最终分数。

## 解题思路

模拟 + 循环检测：使用 boolean 数组记录已访问的索引，再次访问则说明进入循环，停止执行。

## Java 代码实现

```java
class Solution {
    public long calculateScore(String[] instructions, int[] values) {
        int n = instructions.length;
        boolean[] visited = new boolean[n];
        long score = 0;
        int i = 0;
        while (i >= 0 && i < n) {
            if (visited[i]) break; // 循环检测
            visited[i] = true;
            if (instructions[i].equals("add")) {
                score += values[i];
                i++;
            } else {
                i += values[i];
            }
        }
        return score;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个索引最多访问一次
- 空间复杂度：O(n)

## 关键点总结

1. visited 数组检测循环，防止无限执行
2. "jump" 是相对跳转 `i + values[i]`，可以向左
3. 分数用 long 防止溢出
