## 题目描述

给你整数数组 nums，将下标分成若干组，要求同组内所有值不同，且任意两组大小之差不超过 1，返回最少组数。

## 解题思路

统计每个值的频率，设最小频率为 `minFreq`。从大到小枚举每组大小 k（从 minFreq 到 1），对于每个频率 cnt，用 k 或 k+1 分组的可行条件是 `cnt % k <= cnt / k`。第一个对所有频率均可行的 k 即为答案，对应总组数为各频率 `ceil(cnt/(k+1)) * ... ` 的求和。

## Java 代码实现

```java
class Solution {
    public int minGroupsForValidAssignment(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.merge(x, 1, Integer::sum);

        int minFreq = Integer.MAX_VALUE;
        for (int cnt : freq.values()) minFreq = Math.min(minFreq, cnt);

        // 从大到小枚举每组大小 k
        for (int k = minFreq; k >= 1; k--) {
            int totalGroups = 0;
            boolean valid = true;
            for (int cnt : freq.values()) {
                int q = cnt / k, r = cnt % k;
                if (r == 0) {
                    totalGroups += q;       // 全部用 k 大小
                } else if (r <= q) {
                    totalGroups += q + 1;   // r 组扩为 k+1，其余保持 k
                } else {
                    valid = false;
                    break;
                }
            }
            if (valid) return totalGroups;
        }
        return nums.length; // 每组 1 个（极端情况）
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + D×minFreq)，D 为不同值数量
- **空间复杂度**：O(D)

## 关键点总结

1. 每组大小必须为某固定值 k 或 k+1（差不超过 1 的约束）
2. 对于频率 cnt 和组大小 k：`r <= q` 时可行（r 个组需要额外 1 个位置，从 q 个 k 大小的组各贡献 1 个）
3. 从大 k 到小 k 枚举，第一个可行解即为最少组数（k 越大，组越少）
