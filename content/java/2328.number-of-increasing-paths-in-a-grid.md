## 题目描述

给你一个 m×n 整数矩阵，每次可移动到四个方向中值严格更大的格子，返回所有严格递增路径的总数（模 10^9+7）。

## 解题思路

记忆化 DFS：`dp[i][j]` 为以 `(i,j)` 为起点的严格递增路径数。每个格子向四个方向延伸，只走值更大的邻格。严格递增保证无环，无需标记访问状态。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;
    private int[][] grid, memo;
    private int m, n;
    private final int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

    public int countPaths(int[][] grid) {
        this.grid = grid;
        m = grid.length; n = grid[0].length;
        memo = new int[m][n]; // 0 表示未计算
        long ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = (ans + dfs(i, j)) % MOD;
        return (int) ans;
    }

    private int dfs(int i, int j) {
        if (memo[i][j] != 0) return memo[i][j]; // 已缓存
        long count = 1; // 单格路径
        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] > grid[i][j]) {
                count = (count + dfs(ni, nj)) % MOD;
            }
        }
        return memo[i][j] = (int) count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)，每个格子只计算一次
- **空间复杂度**：O(m × n)

## 关键点总结

1. 严格递增保证图是 DAG，记忆化 DFS 无需考虑环。
2. 每个格子的路径数 = 1（自身）+ 所有可延伸邻格的路径数之和。
3. 答案是所有格子作为起点的路径数之和。
