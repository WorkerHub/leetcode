## 题目描述

给你两个等长字符串 s、t 和整数 k，每次操作可将 s 的某个后缀移到开头（字符串旋转），恰好 k 次操作后能变为 t 的方案数对 10^9+7 取模。

## 解题思路

KMP + 矩阵快速幂：用 KMP 在 t+t 中统计 s 和 t 出现次数得到转移系数，构建 2×2 转移矩阵（状态：等于 s 或等于 t），矩阵快速幂处理 k 最大 10^15 的情况。

## Java 代码实现

```java
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int numberOfWays(String s, String t, long k) {
        int n = s.length();
        // KMP 统计 pattern 在 text 中出现次数
        long a = kmpCount(t + t, s);           // t+t 中 s 的出现次数
        long b = kmpCount(t + t, t) - 1;       // t+t 中 t 的出现次数（减去自身）

        // 2x2 转移矩阵：行=当前状态(s,t)，列=下一状态(s,t)
        long[][] M = {
            {n - a, a},
            {n - b - 1, b}
        };

        long[][] Mk = matPow(M, k);
        // 初始从 s 出发（状态[1,0]），k 步后到 t 的数量
        return (int) Mk[0][1];
    }

    private long kmpCount(String text, String pattern) {
        String combined = pattern + "#" + text;
        int m = combined.length(), pLen = pattern.length();
        int[] fail = new int[m];
        long count = 0;
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && combined.charAt(i) != combined.charAt(j)) j = fail[j - 1];
            if (combined.charAt(i) == combined.charAt(j)) j++;
            fail[i] = j;
            if (j == pLen) {
                count++;
                j = fail[j - 1];
            }
        }
        return count;
    }

    private long[][] matMul(long[][] A, long[][] B) {
        int n = A.length;
        long[][] C = new long[n][n];
        for (int i = 0; i < n; i++)
            for (int k = 0; k < n; k++)
                for (int j = 0; j < n; j++)
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
        return C;
    }

    private long[][] matPow(long[][] M, long p) {
        int n = M.length;
        long[][] result = new long[n][n];
        // 单位矩阵
        for (int i = 0; i < n; i++) result[i][i] = 1;
        while (p > 0) {
            if ((p & 1) == 1) result = matMul(result, M);
            M = matMul(M, M);
            p >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + log k × 8)
- **空间复杂度**：O(n)

## 关键点总结

1. KMP 在 t+t 中统计匹配次数，得到旋转转移系数
2. 矩阵快速幂处理超大 k（最大 10^15）
3. 2×2 矩阵只有两个状态：当前等于 s 或等于 t
