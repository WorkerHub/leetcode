## 题目描述

请你实现一个能够支持以下两种方法的推文计数类 `TweetCounts`：

**1. `recordTweet(tweetName, time)`**

记录推文发布情况：用户 `tweetName` 在 `time`（以**秒**为单位）时刻发布了一条推文。

**2. `getTweetCountsPerFrequency(freq, tweetName, startTime, endTime)`**

返回从开始时间 `startTime`（以秒为单位）到结束时间 `endTime`（以秒为单位）内，每隔 `freq` 时间段中指定用户 `tweetName` 发布推文的次数。

- `freq` 的值为 `"minute"`、`"hour"` 或 `"day"`，分别表示每**分钟**、每**小时**和每**天**的时间间隔。
- 第一个时间段始终从 `startTime` 开始，按照 `freq` 划分，最后一个时间段的结束时间可能大于 `endTime`。

**示例：**
```
输入：
["TweetCounts","recordTweet","recordTweet","recordTweet","getTweetCountsPerFrequency","getTweetCountsPerFrequency","recordTweet","getTweetCountsPerFrequency"]
[[],["tweet3",0],["tweet3",60],["tweet3",10],["minute","tweet3",0,59],["minute","tweet3",0,60],["tweet3",120],["hour","tweet3",0,210]]

输出：
[null,null,null,null,[2],[2,1],[null],[4]]
```

**提示：**
- `0 <= time, startTime, endTime <= 10^9`
- `0 <= endTime - startTime <= 10^4`
- 每个测试用例最多有 `10^4` 次 `recordTweet` 调用。
- 每个测试用例最多有 `10^4` 次 `getTweetCountsPerFrequency` 调用。

## 解题思路

**数据结构设计：**

使用哈希表 `tweets` 存储每个用户的推文时间列表：
```
tweets = {tweetName: [time1, time2, ...]}
```

**`getTweetCountsPerFrequency` 算法：**

1. 将 `freq` 转换为秒数：minute=60，hour=3600，day=86400
2. 计算时间段数量：`(endTime - startTime) / delta + 1`
3. 对该用户的所有推文时间，判断属于哪个时间段：`(time - startTime) / delta`
4. 累加对应时间段的计数

## Java 代码实现

### 方法一：HashMap + ArrayList（推荐）

```java
import java.util.*;

class TweetCounts {
    // 存储每个用户的推文时间列表
    private Map<String, List<Integer>> tweets;
    
    public TweetCounts() {
        tweets = new HashMap<>();
    }
    
    public void recordTweet(String tweetName, int time) {
        // 记录推文时间
        tweets.computeIfAbsent(tweetName, k -> new ArrayList<>()).add(time);
    }
    
    public List<Integer> getTweetCountsPerFrequency(String freq, String tweetName,
                                                     int startTime, int endTime) {
        // 将 freq 转换为秒数
        int delta;
        if (freq.equals("minute")) delta = 60;
        else if (freq.equals("hour")) delta = 3600;
        else delta = 86400; // "day"
        
        // 时间段数量
        int n = (endTime - startTime) / delta + 1;
        int[] result = new int[n];
        
        // 统计每个时间段的推文数
        List<Integer> times = tweets.getOrDefault(tweetName, Collections.emptyList());
        for (int t : times) {
            if (t >= startTime && t <= endTime) {
                // 属于第几个时间段
                int idx = (t - startTime) / delta;
                result[idx]++;
            }
        }
        
        // 转换为 List<Integer>
        List<Integer> ans = new ArrayList<>();
        for (int v : result) ans.add(v);
        return ans;
    }
}
```

### 方法二：记录时排序，查询时二分（优化版）

```java
import java.util.*;

class TweetCounts {
    private Map<String, List<Integer>> tweets;
    
    public TweetCounts() {
        tweets = new HashMap<>();
    }
    
    public void recordTweet(String tweetName, int time) {
        // 保持时间列表有序（使用插入位置保持有序）
        List<Integer> list = tweets.computeIfAbsent(tweetName, k -> new ArrayList<>());
        // 二分找插入位置
        int pos = Collections.binarySearch(list, time);
        if (pos < 0) pos = -(pos + 1);
        list.add(pos, time);
    }
    
    public List<Integer> getTweetCountsPerFrequency(String freq, String tweetName,
                                                     int startTime, int endTime) {
        int delta;
        if (freq.equals("minute")) delta = 60;
        else if (freq.equals("hour")) delta = 3600;
        else delta = 86400;
        
        int n = (endTime - startTime) / delta + 1;
        int[] result = new int[n];
        
        List<Integer> times = tweets.getOrDefault(tweetName, Collections.emptyList());
        
        // 二分查找 startTime 和 endTime 的范围
        int lo = lowerBound(times, startTime);
        int hi = upperBound(times, endTime);
        
        // 只遍历在 [startTime, endTime] 范围内的推文
        for (int i = lo; i < hi; i++) {
            int idx = (times.get(i) - startTime) / delta;
            result[idx]++;
        }
        
        List<Integer> ans = new ArrayList<>();
        for (int v : result) ans.add(v);
        return ans;
    }
    
    // 找第一个 >= target 的位置
    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
    
    // 找第一个 > target 的位置
    private int upperBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

| 方法 | recordTweet | getTweetCountsPerFrequency | 空间 |
|------|-------------|---------------------------|------|
| 方法一 | O(1) | O(k)（k为该用户推文数） | O(总推文数) |
| 方法二 | O(log k + k) | O(m + n)（m为范围内推文数） | O(总推文数) |

其中：
- k：某用户总推文数
- m：[startTime, endTime] 范围内该用户的推文数
- n：时间段数量

## 关键点总结

1. 核心：用哈希表存储每个用户的推文时间列表
2. 时间段计算：`(t - startTime) / delta` 得到推文属于哪个时间段（从 0 开始索引）
3. 时间段总数：`(endTime - startTime) / delta + 1`
4. 方法二利用有序列表和二分查找，在推文数量很大时更高效

## 易错点

1. 时间段数量计算：`(endTime - startTime) / delta + 1`（+1 是因为包含两端）
2. 时间段索引：`(t - startTime) / delta`，是相对于 `startTime` 的偏移，不是绝对时间
3. 过滤范围：只处理 `startTime <= t <= endTime` 的推文（包含两端）
4. `freq` 到秒数的映射别写错：minute=60, hour=3600, day=86400
