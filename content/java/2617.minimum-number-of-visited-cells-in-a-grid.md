## 题目描述

给你一个 `m x n` 整数矩阵 `grid`，从左上角 `(0,0)` 出发，每步向右或向下移动，从 `(i,j)` 最多移动 `grid[i][j]` 步，返回到达右下角所需访问的最少单元格数，不可达返回 -1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumVisitedCells(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        if (m == 1 && n == 1) return 1;

        int[][] dp = new int[m][n];
        for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE);
        dp[0][0] = 1;

        // row_heaps[i] 存 (dp值, 该行可达的最远列)
        PriorityQueue<int[]>[] rowHeaps = new PriorityQueue[m];
        PriorityQueue<int[]>[] colHeaps = new PriorityQueue[n];
        for (int i = 0; i < m; i++) rowHeaps[i] = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        for (int j = 0; j < n; j++) colHeaps[j] = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 从行堆中取最优前驱（到期的堆顶弹出）
                while (!rowHeaps[i].isEmpty() && rowHeaps[i].peek()[1] < j) {
                    rowHeaps[i].poll();
                }
                if (!rowHeaps[i].isEmpty()) {
                    dp[i][j] = Math.min(dp[i][j], rowHeaps[i].peek()[0] + 1);
                }
                // 从列堆中取最优前驱
                while (!colHeaps[j].isEmpty() && colHeaps[j].peek()[1] < i) {
                    colHeaps[j].poll();
                }
                if (!colHeaps[j].isEmpty()) {
                    dp[i][j] = Math.min(dp[i][j], colHeaps[j].peek()[0] + 1);
                }
                // 当前格可达，加入行堆和列堆
                if (dp[i][j] < Integer.MAX_VALUE) {
                    rowHeaps[i].offer(new int[]{dp[i][j], j + grid[i][j]});
                    colHeaps[j].offer(new int[]{dp[i][j], i + grid[i][j]});
                }
            }
        }

        return dp[m - 1][n - 1] == Integer.MAX_VALUE ? -1 : dp[m - 1][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. DP + 堆优化：每格从行堆/列堆的最优前驱转移
2. 堆顶记录可达最远下标，过期时弹出
3. 初始格 (0,0) 计为 1 步
