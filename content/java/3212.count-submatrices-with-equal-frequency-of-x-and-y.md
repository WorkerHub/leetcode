## 题目描述

给你一个字符矩阵 `grid`（字符为 `'X'`、`'Y'` 或 `'.'`），返回左上角在 `(0,0)` 的子矩阵中，`'X'` 和 `'Y'` 出现频率相等且至少有一个 `'X'` 的子矩阵数量。

## Java 代码实现

```java
class Solution {
    public int numberOfSubmatrices(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;
        // 用一维数组累计每列中 X 和 Y 的数量
        int[] colX = new int[n];
        int[] colY = new int[n];

        for (int i = 0; i < m; i++) {
            int sumX = 0, sumY = 0;
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 'X') colX[j]++;
                else if (grid[i][j] == 'Y') colY[j]++;
                sumX += colX[j];
                sumY += colY[j];
                // 子矩阵 (0,0) 到 (i,j) 满足条件
                if (sumX == sumY && sumX > 0) {
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(n)

## 关键点总结

1. 利用列累计数组模拟二维前缀和，空间复杂度优化到 O(n)
2. 条件是 X 和 Y 数量相等且 X 数量大于 0
3. 行方向上累加列的和即得到从 (0,0) 到当前位置的总计数
