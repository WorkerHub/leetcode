## 题目描述

给定以 0 为根的带权树和节点值数组 `nums`，特殊路径为从根到某节点的路径上所有节点值各不相同，返回 [最长路径边权和, 对应最少节点数]。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] nums;
    private List<int[]>[] graph; // [neighbor, weight]
    private int[] lastSeenDepth; // value -> 最近出现的深度
    private long[] distPrefix;   // 路径各深度的累积距离
    private long ansLen = 0;
    private int ansNodes = 1;

    @SuppressWarnings("unchecked")
    public int[] longestSpecialPath(int[][] edges, int[] nums) {
        int n = nums.length;
        this.nums = nums;
        this.graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        this.lastSeenDepth = new int[100001];
        Arrays.fill(lastSeenDepth, -1);
        this.distPrefix = new long[n + 1];

        dfs(0, -1, 0, 0, 0);
        return new int[]{(int) ansLen, ansNodes};
    }

    private void dfs(int node, int parent, long curDist, int depth, int pathStartDepth) {
        distPrefix[depth] = curDist;
        int v = nums[node];

        // 若值 v 已在路径中出现，路径起点需推进
        int newStart = pathStartDepth;
        if (lastSeenDepth[v] >= pathStartDepth) {
            newStart = lastSeenDepth[v] + 1;
        }

        long pathLen = curDist - distPrefix[newStart];
        int numNodes = depth - newStart + 1;

        if (pathLen > ansLen || (pathLen == ansLen && numNodes < ansNodes)) {
            ansLen = pathLen;
            ansNodes = numNodes;
        }

        int oldDepth = lastSeenDepth[v];
        lastSeenDepth[v] = depth;

        for (int[] child : graph[node]) {
            if (child[0] != parent) {
                dfs(child[0], node, curDist + child[1], depth + 1, newStart);
            }
        }

        // 恢复状态
        lastSeenDepth[v] = oldDepth;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n + V)，V 为值域大小

## 关键点总结

1. DFS 时用数组记录每个值最近出现的路径深度。
2. 遇到重复值时，路径起始深度推进到重复位置之后。
3. 用前缀距离数组 O(1) 计算路径长度。
