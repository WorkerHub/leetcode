## 题目描述

每轮完成2或3个相同难度任务，求完成所有任务的最少轮数，不可能则返回-1。

## 解题思路

统计每种难度数量cnt：cnt==1返回-1，否则最少轮数=ceil(cnt/3)。尽量每轮3个最优。

## Java 代码实现

```java
class Solution {
    public int minimumRounds(int[] tasks) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int t : tasks) {
            count.merge(t, 1, Integer::sum);
        }
        
        int ans = 0;
        for (int cnt : count.values()) {
            if (cnt == 1) return -1;
            ans += (cnt + 2) / 3; // ceil(cnt/3)
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(D)，D为不同难度数

## 关键点总结

1. **cnt==1无法完成**：不能凑成2或3个
2. **最少轮数=ceil(cnt/3)**：尽量3个一轮
3. **整数向上取整**：(cnt+2)/3
