## 题目描述

给你一棵有 `n` 个节点的树，每个节点有权值 `vals[i]`，以及若干查询 `queries[j] = [u, v]`，返回从 u 到 v 路径上的最小节点权值。

## 解题思路

LCA 倍增法：BFS 建树，用 sparse table 预处理每个节点向上 `2^k` 步的祖先及路径最小值。每次查询先对齐深度，再同步上移到 LCA，全程维护路径最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final int LOG = 17;
    int[][] parent;
    int[][] minVal;
    int[] depth;

    public int[] minimumPathValue(int n, int[][] edges, int[] vals, int[][] queries) {
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) { graph[e[0]].add(e[1]); graph[e[1]].add(e[0]); }

        parent = new int[LOG][n];
        minVal = new int[LOG][n];
        depth = new int[n];
        for (int[] row : parent) Arrays.fill(row, -1);
        for (int[] row : minVal) Arrays.fill(row, Integer.MAX_VALUE);

        // BFS建树
        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0); visited[0] = true;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (!visited[v]) {
                    visited[v] = true;
                    parent[0][v] = u;
                    minVal[0][v] = Math.min(vals[u], vals[v]);
                    depth[v] = depth[u] + 1;
                    queue.offer(v);
                }
            }
        }
        // 倍增预处理
        for (int k = 1; k < LOG; k++) {
            for (int v = 0; v < n; v++) {
                int p = parent[k-1][v];
                if (p == -1) continue;
                parent[k][v] = parent[k-1][p];
                minVal[k][v] = Math.min(minVal[k-1][v], minVal[k-1][p]);
            }
        }

        int[] res = new int[queries.length];
        for (int i = 0; i < queries.length; i++) res[i] = lcaMin(queries[i][0], queries[i][1], vals);
        return res;
    }

    private int lcaMin(int u, int v, int[] vals) {
        int res = Math.min(vals[u], vals[v]);
        if (depth[u] < depth[v]) { int t = u; u = v; v = t; }
        int diff = depth[u] - depth[v];
        for (int k = 0; k < LOG; k++) {
            if (((diff >> k) & 1) == 1) { res = Math.min(res, minVal[k][u]); u = parent[k][u]; }
        }
        if (u == v) return res;
        for (int k = LOG - 1; k >= 0; k--) {
            if (parent[k][u] != parent[k][v]) {
                res = Math.min(res, Math.min(minVal[k][u], minVal[k][v]));
                u = parent[k][u]; v = parent[k][v];
            }
        }
        return Math.min(res, Math.min(minVal[0][u], minVal[0][v]));
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n log n)

## 关键点总结

1. LCA 倍增同时维护路径最小值
2. 对齐深度时累积路径最小值
3. `minVal[k][v]` 表示 v 向上走 `2^k` 步路径上的最小值
