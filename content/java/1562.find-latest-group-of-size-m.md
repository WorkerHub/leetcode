## 题目描述

按 arr[i] 顺序依次将位置设为 1，返回最后一步使得存在恰好长度为 m 的全 1 连续子串的步骤编号。

**示例：**
```
输入：arr = [3,5,1,2,4], m = 1
输出：4
```

## 解题思路

维护每个区间端点的长度，每次合并时更新长度为 m 的区间计数。

## Java 代码实现

```java
class Solution {
    public int findLatestStep(int[] arr, int m) {
        int n = arr.length;
        int[] length = new int[n + 2]; // 端点记录区间长度
        int[] count = new int[n + 1];  // count[l]: 长度为 l 的区间数
        int ans = -1;
        
        for (int step = 0; step < n; step++) {
            int pos = arr[step];
            int leftLen = length[pos - 1];
            int rightLen = length[pos + 1];
            int newLen = leftLen + rightLen + 1;
            
            // 更新新区间的两端
            length[pos - leftLen] = newLen;
            length[pos + rightLen] = newLen;
            
            // 更新 count
            if (leftLen > 0) count[leftLen]--;
            if (rightLen > 0) count[rightLen]--;
            count[newLen]++;
            
            if (count[m] > 0) ans = step + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **端点记录长度**：只更新区间两端的 length 值
2. **count 数组**：维护各长度区间数量
3. **合并区间**：新长度 = 左区间长度 + 右区间长度 + 1
