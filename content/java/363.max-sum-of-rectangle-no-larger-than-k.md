## 题目描述

给你一个 `m x n` 的矩阵 `matrix` 和一个整数 `k`，找出并返回矩阵内部矩形区域的不超过 `k` 的最大数值和。

题目数据保证总会存在一个数值和不超过 `k` 的矩形区域。

**示例 1：**

```
输入：matrix = [[1,0,1],[0,-2,3]], k = 2
输出：2
解释：蓝色矩形区域 [[0,1],[-2,3]] 的数值和是 2，且 2 是不超过 k 的最大数字（k = 2）
```

**示例 2：**

```
输入：matrix = [[2,2,-1]], k = 3
输出：3
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-100 <= matrix[i][j] <= 100`
- `-10^5 <= k <= 10^5`

**进阶：**
如果行数远大于列数，该如何设计解决方案？

## 解题思路

这是一道综合性很强的题目，涉及前缀和、降维、有序集合等多个技巧。

### 核心思想

1. **降维处理**：将二维矩形和问题转化为一维数组的子数组和问题
2. **枚举行边界**：固定上下边界，将问题降维到一维
3. **有序集合优化**：使用有序集合（如 TreeSet）快速查找满足条件的前缀和

### 算法流程

1. 枚举矩形的上边界 `i`
2. 枚举矩形的下边界 `j`（从 `i` 到 `m-1`）
3. 计算从第 `i` 行到第 `j` 行每列的和，得到一维数组
4. 在一维数组中找不超过 `k` 的最大子数组和

### 一维子数组和问题

对于一维数组，要找不超过 `k` 的最大子数组和：
- 使用前缀和 `preSum`
- 要找 `preSum[j] - preSum[i] <= k`，即 `preSum[i] >= preSum[j] - k`
- 使用有序集合快速找到 `>= preSum[j] - k` 的最小值

## Java 代码实现

### 方法一：前缀和 + 有序集合（推荐）

```java
import java.util.TreeSet;

class Solution {
    public int maxSumSubmatrix(int[][] matrix, int k) {
        int m = matrix.length, n = matrix[0].length;
        int maxSum = Integer.MIN_VALUE;

        // 枚举上边界
        for (int top = 0; top < m; top++) {
            int[] colSum = new int[n];  // 记录从 top 行到当前行每列的累计和

            // 枚举下边界
            for (int bottom = top; bottom < m; bottom++) {
                // 更新列和
                for (int col = 0; col < n; col++) {
                    colSum[col] += matrix[bottom][col];
                }

                // 在一维数组 colSum 中找不超过 k 的最大子数组和
                maxSum = Math.max(maxSum, maxSumSubarray(colSum, k));

                // 提前退出优化
                if (maxSum == k) return k;
            }
        }

        return maxSum;
    }

    /**
     * 在一维数组中找不超过 k 的最大子数组和
     * 使用 TreeSet 优化查找
     */
    private int maxSumSubarray(int[] nums, int k) {
        int maxSum = Integer.MIN_VALUE;
        int prefixSum = 0;
        TreeSet<Integer> sortedSums = new TreeSet<>();
        sortedSums.add(0);  // 存储前缀和，初始化为 0（空前缀）

        for (int num : nums) {
            prefixSum += num;

            // 找 prefixSum - x <= k，即 x >= prefixSum - k
            // 在有序集合中查找 >= prefixSum - k 的最小值
            Integer target = sortedSums.ceiling(prefixSum - k);

            if (target != null) {
                maxSum = Math.max(maxSum, prefixSum - target);
            }

            sortedSums.add(prefixSum);
        }

        return maxSum;
    }
}
```

### 方法二：优化——选择较小维度作为外层循环

```java
import java.util.TreeSet;

class Solution {
    public int maxSumSubmatrix(int[][] matrix, int k) {
        int m = matrix.length, n = matrix[0].length;
        int maxSum = Integer.MIN_VALUE;

        // 优化：选择较小的维度作为外层循环
        // 如果 m > n，转置矩阵，让行数 <= 列数
        if (m > n) {
            matrix = transpose(matrix, m, n);
            int tmp = m; m = n; n = tmp;
        }

        for (int top = 0; top < m; top++) {
            int[] colSum = new int[n];

            for (int bottom = top; bottom < m; bottom++) {
                for (int col = 0; col < n; col++) {
                    colSum[col] += matrix[bottom][col];
                }

                maxSum = Math.max(maxSum, maxSumSubarray(colSum, k));

                if (maxSum == k) return k;
            }
        }

        return maxSum;
    }

    /** 转置矩阵 */
    private int[][] transpose(int[][] matrix, int m, int n) {
        int[][] result = new int[n][m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[j][i] = matrix[i][j];
            }
        }
        return result;
    }

    private int maxSumSubarray(int[] nums, int k) {
        int maxSum = Integer.MIN_VALUE;
        int prefixSum = 0;
        TreeSet<Integer> sortedSums = new TreeSet<>();
        sortedSums.add(0);

        for (int num : nums) {
            prefixSum += num;
            // 二分查找 >= prefixSum - k 的最小值
            Integer target = sortedSums.ceiling(prefixSum - k);
            if (target != null) {
                maxSum = Math.max(maxSum, prefixSum - target);
            }
            sortedSums.add(prefixSum);
        }

        return maxSum;
    }
}
```

### 方法三：暴力法（用于理解）

```java
class Solution {
    public int maxSumSubmatrix(int[][] matrix, int k) {
        int m = matrix.length, n = matrix[0].length;
        int maxSum = Integer.MIN_VALUE;

        // 预计算二维前缀和
        int[][] prefix = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = matrix[i - 1][j - 1]
                        + prefix[i - 1][j]
                        + prefix[i][j - 1]
                        - prefix[i - 1][j - 1];
            }
        }

        // 枚举所有矩形
        for (int i1 = 1; i1 <= m; i1++) {
            for (int j1 = 1; j1 <= n; j1++) {
                for (int i2 = i1; i2 <= m; i2++) {
                    for (int j2 = j1; j2 <= n; j2++) {
                        // 计算矩形和
                        int rectSum = prefix[i2][j2]
                                - prefix[i1 - 1][j2]
                                - prefix[i2][j1 - 1]
                                + prefix[i1 - 1][j1 - 1];

                        if (rectSum <= k) {
                            maxSum = Math.max(maxSum, rectSum);
                        }
                    }
                }
            }
        }

        return maxSum;
    }
}
```

## 复杂度分析

### 方法一：前缀和 + 有序集合
- 时间复杂度：O(m^2 × n × log n)
  - 枚举上下边界：O(m^2)
  - 每次查找一维最大和：O(n × log n)
- 空间复杂度：O(n)

### 方法二：优化后
- 时间复杂度：O(min(m, n)^2 × max(m, n) × log(max(m, n)))
- 空间复杂度：O(max(m, n))

### 方法三：暴力法
- 时间复杂度：O(m^2 × n^2)
- 空间复杂度：O(m × n)

## 关键点总结

1. **降维思想**：二维问题转化为一维问题是关键
2. **有序集合**：Java 中使用 `TreeSet.ceiling()` 快速查找满足条件的前缀和
3. **前缀和技巧**：快速计算子数组和
4. **优化策略**：选择较小的维度作为外层循环
5. **提前退出**：找到等于 k 的结果可立即返回

## 易错点

1. **边界条件**：前缀和数组的索引容易出错
2. **初始化**：有序集合要初始化加入 0，表示空前缀
3. **查找方向**：要找 `>= target` 的最小值，使用 `TreeSet.ceiling()`
4. **矩阵转置**：优化时注意正确转置矩阵
5. **负数处理**：数组中有负数，不能用滑动窗口
