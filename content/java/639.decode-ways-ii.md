## 题目描述

包含数字和 '*' 的字符串（'*' 表示 1-9 任一数字），返回解码方法数，mod 10^9+7。

**示例：**
```
输入：s = "1*"
输出：18
```

## 解题思路

DP：分情况讨论单独解码和组合解码中 '*' 的可能取值。

## Java 代码实现

```java
class Solution {
    public int numDecodings(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();
        long[] dp = new long[n + 1];
        dp[0] = 1;

        // 第一个字符
        if (s.charAt(0) == '*') dp[1] = 9;
        else if (s.charAt(0) != '0') dp[1] = 1;
        else return 0;

        for (int i = 2; i <= n; i++) {
            char c = s.charAt(i - 1);
            char prev = s.charAt(i - 2);

            // 单独解码 s[i-1]
            if (c == '*') {
                dp[i] = 9 * dp[i - 1] % MOD;
            } else if (c != '0') {
                dp[i] = dp[i - 1];
            }

            // 与前一个字符组合解码
            if (prev == '*') {
                if (c == '*') {
                    dp[i] = (dp[i] + 15 * dp[i - 2]) % MOD; // 11-19,21-26
                } else if (c <= '6') {
                    dp[i] = (dp[i] + 2 * dp[i - 2]) % MOD; // 1c, 2c
                } else {
                    dp[i] = (dp[i] + dp[i - 2]) % MOD; // 只有 1c
                }
            } else if (prev == '1') {
                if (c == '*') {
                    dp[i] = (dp[i] + 9 * dp[i - 2]) % MOD; // 11-19
                } else {
                    dp[i] = (dp[i] + dp[i - 2]) % MOD;
                }
            } else if (prev == '2') {
                if (c == '*') {
                    dp[i] = (dp[i] + 6 * dp[i - 2]) % MOD; // 21-26
                } else if (c <= '6') {
                    dp[i] = (dp[i] + dp[i - 2]) % MOD;
                }
            }
        }

        return (int) dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **分情况讨论**：'*' 前一位、'*' 当前位、数字的各种组合
2. **15种双星组合**：11-19 (9种) + 21-26 (6种)
3. **用 long**：避免中间计算溢出
