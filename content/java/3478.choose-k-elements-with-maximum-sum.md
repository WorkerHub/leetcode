## 题目描述

给你等长数组 `nums1`、`nums2` 和整数 `k`，对每个下标 i 选最多 k 个满足 `nums1[j] < nums1[i]` 的下标 j 使 `nums2[j]` 之和最大，返回结果数组。

## 解题思路

排序 + 最小堆：按 nums1 值排序后分组处理相同值的元素——先用当前堆的和作为该组的答案，再将该组的 nums2 值加入大小为 k 的最小堆（保留 top-k）。先记录答案再更新堆，确保严格小于条件。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long[] findMaxSum(int[] nums1, int[] nums2, int k) {
        int n = nums1.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> nums1[a] - nums1[b]);

        long[] answer = new long[n];
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(); // 最小堆，维护 top-k
        long heapSum = 0;
        int i = 0;

        while (i < n) {
            // 收集相同 nums1 值的组
            int j = i;
            while (j < n && nums1[idx[j]] == nums1[idx[i]]) j++;

            // 先记录答案（用当前堆）
            for (int p = i; p < j; p++) {
                answer[idx[p]] = heapSum;
            }

            // 再将这组的 nums2 值加入堆
            for (int p = i; p < j; p++) {
                int v = nums2[idx[p]];
                minHeap.offer(v);
                heapSum += v;
                if (minHeap.size() > k) {
                    heapSum -= minHeap.poll();
                }
            }

            i = j;
        }

        return answer;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和堆操作
- 空间复杂度：O(n)

## 关键点总结

1. 相同 nums1 值的元素分为一组，先记录答案再更新堆（保证严格小于）
2. 最小堆维护大小为 k 的 top-k 集合，堆和即为最大 k 个 nums2 之和
3. heapSum 实时维护堆内元素之和，O(1) 获取结果
