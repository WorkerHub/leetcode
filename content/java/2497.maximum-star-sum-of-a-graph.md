## 题目描述

给你 `n` 节点图（每节点有值）和边数组，选一个中心节点及至多 `k` 个相邻节点形成星形图，返回最大星形图节点值之和。

## 解题思路

贪心：对每个节点，收集所有正值邻居并降序排列，取前 k 个加上中心节点值作为该节点的最优星形图和，取所有节点的最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxStarSum(int[] vals, int[][] edges, int k) {
        int n = vals.length;
        List<Integer>[] adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();

        // 只收集正值邻居
        for (int[] e : edges) {
            if (vals[e[1]] > 0) adj[e[0]].add(vals[e[1]]);
            if (vals[e[0]] > 0) adj[e[1]].add(vals[e[0]]);
        }

        int ans = Integer.MIN_VALUE;
        for (int v = 0; v < n; v++) {
            // 降序排序邻居值，取前 k 个
            adj[v].sort(Collections.reverseOrder());
            int sum = vals[v];
            for (int i = 0; i < Math.min(k, adj[v].size()); i++) {
                sum += adj[v].get(i);
            }
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m + n)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 只选正值邻居（加负值只会减少总和）
2. 贪心选最大的 k 个正邻居，邻居值降序排序后取前 k 个
3. `ans` 初始化为 `Integer.MIN_VALUE`，因为节点值可能为负
