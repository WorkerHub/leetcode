## 题目描述

给你字符串列表 `words`（所有字符串等长）和目标字符串 `target`，从每列中选一个字符（列下标严格递增）构成 `target`，返回方案数（对 `10^9+7` 取余）。

## 解题思路

**一维 DP：** `dp[i]` = 构成 `target[0..i-1]` 的方案数。

预处理 `freq[k][c]` = 第 k 列字符 c 的出现次数。对每列 j（逆序遍历 i），`dp[i] += dp[i-1] * freq[j][target[i-1]]`。

## Java 代码实现

```java
class Solution {
    public int numWays(String[] words, String target) {
        final int MOD = 1_000_000_007;
        int m = words[0].length(); // 单词长度
        int n = target.length();

        // 预处理：freq[k][c] = 第 k 列中字符 c 的出现次数
        int[][] freq = new int[m][26];
        for (String word : words) {
            for (int k = 0; k < m; k++) {
                freq[k][word.charAt(k) - 'a']++;
            }
        }

        // dp[i] = 构成 target[0..i-1] 的方案数
        long[] dp = new long[n + 1];
        dp[0] = 1; // 空目标串只有一种方式

        for (int j = 0; j < m; j++) { // 枚举列
            // 逆序遍历，避免同一列被多次使用
            for (int i = Math.min(j + 1, n); i >= 1; i--) {
                int cIdx = target.charAt(i - 1) - 'a';
                dp[i] = (dp[i] + dp[i - 1] * freq[j][cIdx]) % MOD;
            }
        }

        return (int) dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(L*W + m*n)，L 为 words 总字符数，m 为单词长度，n 为 target 长度
- **空间复杂度**：O(m*26 + n)

## 关键点总结

1. 预处理频率数组，避免重复统计
2. 逆序遍历 i 确保同一列只用一次（类似 0/1 背包）
3. `dp[0] = 1` 是边界条件（空目标串一种构成方式）
