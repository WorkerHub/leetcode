## 题目描述

给你二叉树的根节点 `root`，返回其节点值的**层序遍历**。（即逐层地，从左到右访问所有节点）。

**示例 1：**
```
    3
   / \
  9  20
    /  \
   15   7
```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

**示例 2：**
输入：root = [1]
输出：[[1]]

**示例 3：**
输入：root = []
输出：[]

**提示：**
- 树中节点数目在范围 [0, 2000] 内
- -1000 <= Node.val <= 1000

## 解题思路

层序遍历就是**广度优先搜索（BFS）**，使用队列实现。

**核心思想：**
1. 使用队列存储每一层的节点
2. 每次处理一层：记录当前层节点个数，依次出队并访问
3. 将下一层的节点（左右孩子）加入队列
4. 重复直到队列为空

**也可以使用递归（DFS）+ 层级标记实现**。

## Java 代码实现

### 方法一：BFS（队列迭代）⭐

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();  // 当前层的节点数
            List<Integer> levelVals = new ArrayList<>();

            // 处理当前层的所有节点
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelVals.add(node.val);

                // 将下一层节点加入队列
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            result.add(levelVals);
        }

        return result;
    }
}
```

### 方法二：DFS（递归 + 层级标记）

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int level, List<List<Integer>> result) {
        if (node == null) return;

        // 如果当前层还没有列表，创建一个
        if (result.size() == level) {
            result.add(new ArrayList<>());
        }

        // 将当前节点值加入对应层
        result.get(level).add(node.val);

        // 递归处理左右子树
        dfs(node.left, level + 1, result);
        dfs(node.right, level + 1, result);
    }
}
```

### 方法三：BFS（逐层处理）

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        List<TreeNode> currentLevel = new ArrayList<>();
        currentLevel.add(root);

        while (!currentLevel.isEmpty()) {
            List<Integer> levelVals = new ArrayList<>();
            List<TreeNode> nextLevel = new ArrayList<>();

            for (TreeNode node : currentLevel) {
                levelVals.add(node.val);
                if (node.left != null) nextLevel.add(node.left);
                if (node.right != null) nextLevel.add(node.right);
            }

            result.add(levelVals);
            currentLevel = nextLevel;
        }

        return result;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是树中节点总数，每个节点访问一次
- 空间复杂度：O(n)
  - BFS：队列最多存储一层的节点，最坏情况下（完全二叉树最后一层）为 O(n/2) = O(n)
  - DFS：递归调用栈深度为树的高度 O(h)，加上结果数组 O(n)，总体 O(n)

## 关键点总结

1. **BFS 核心**：队列 + 按层处理（记录当前层节点数）
2. **层分隔技巧**：通过 `queue.size()` 确定当前层的节点数
3. **DFS 实现**：用 level 参数标记深度，按深度分组
4. **Java 注意**：使用 `LinkedList` 或 `ArrayDeque` 实现队列，用 `offer/poll` 操作

## 易错点

1. **忘记判空**：root 为空时直接返回空列表
2. **层分隔错误**：没有正确记录每层节点数，导致层混乱
3. **队列使用**：使用 `poll()` 从队头取元素，不能用栈的 `pop()`
4. **DFS 时机**：DFS 方法中要先检查 `result.size() == level` 再添加列表
