## 题目描述

给你字符串 `s`，可以进行一次操作：选择任意非空子串，将其中每个字符替换为字母表中的前一个字符（`'a'` 替换为 `'z'`），返回操作后字典序最小的字符串。

## Java 代码实现

```java
class Solution {
    public String smallestString(String s) {
        char[] chars = s.toCharArray();
        int n = chars.length;
        int i = 0;
        // 跳过前缀的 'a'
        while (i < n && chars[i] == 'a') i++;
        // 全是 'a'，将最后一个变为 'z'（影响最小）
        if (i == n) {
            chars[n - 1] = 'z';
            return new String(chars);
        }
        // 从第一个非 'a' 开始，连续将非 'a' 的字符减一
        while (i < n && chars[i] != 'a') {
            chars[i] = (char) (chars[i] - 1);
            i++;
        }
        return new String(chars);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：尽可能早地开始减少字符，且连续减少非 `'a'` 的字符
2. 遇到 `'a'` 停止（`'a'` 变为 `'z'` 反而增大）
3. 全为 `'a'` 时，强制将最后一个字符变为 `'z'`（影响最小）
