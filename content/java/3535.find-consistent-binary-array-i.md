## 题目描述

给定整数 `zero`、`one` 和 `limit`，构造长度为 `zero + one` 的二进制数组，恰好含 `zero` 个 0 和 `one` 个 1，且不存在长度超过 `limit` 的连续相同元素。求满足条件的方案数，对 10^9+7 取模。

## 解题思路

四维 DP：`dp[z][o][last][cnt]` 表示剩余 z 个 0 和 o 个 1 待填，最后填的是 `last`（0 或 1），已连续 `cnt` 个时的方案数。每步可继续填同样数字（若 cnt < limit）或切换数字（cnt 重置为 1）。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int numberOfConsistentArrays(int zero, int one, int limit) {
        // dp[z][o][last][cnt]: z 剩余 0 数，o 剩余 1 数，last=0/1，cnt=1..limit
        int[][][][] dp = new int[zero + 1][one + 1][2][limit + 1];

        // 初始化第一个数字
        if (zero > 0) dp[zero - 1][one][0][1] = 1;
        if (one > 0) dp[zero][one - 1][1][1] = 1;

        int ans = 0;
        // 按剩余总数递推
        for (int total = zero + one - 1; total >= 0; total--) {
            for (int z = 0; z <= zero; z++) {
                int o = total - z;
                if (o < 0 || o > one) continue;
                for (int last = 0; last < 2; last++) {
                    for (int cnt = 1; cnt <= limit; cnt++) {
                        int ways = dp[z][o][last][cnt];
                        if (ways == 0) continue;
                        if (z == 0 && o == 0) { ans = (ans + ways) % MOD; continue; }
                        // 放 0
                        if (z > 0) {
                            if (last == 0 && cnt < limit)
                                dp[z-1][o][0][cnt+1] = (dp[z-1][o][0][cnt+1] + ways) % MOD;
                            else if (last == 1)
                                dp[z-1][o][0][1] = (dp[z-1][o][0][1] + ways) % MOD;
                        }
                        // 放 1
                        if (o > 0) {
                            if (last == 1 && cnt < limit)
                                dp[z][o-1][1][cnt+1] = (dp[z][o-1][1][cnt+1] + ways) % MOD;
                            else if (last == 0)
                                dp[z][o-1][1][1] = (dp[z][o-1][1][1] + ways) % MOD;
                        }
                    }
                }
            }
        }
        // 收集终态
        for (int last = 0; last < 2; last++)
            for (int cnt = 1; cnt <= limit; cnt++)
                ans = (ans + dp[0][0][last][cnt]) % MOD;
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(zero * one * limit)
- 空间复杂度：O(zero * one * limit)

## 关键点总结

1. 连续计数不能超过 limit，切换数字时重置为 1
2. 初始状态：第一个数字为 0 或 1，连续计数为 1
3. 结果对 10^9+7 取模
