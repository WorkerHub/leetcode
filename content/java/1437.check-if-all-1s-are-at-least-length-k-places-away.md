## 题目描述

给你一个由若干 `0` 和 `1` 组成的数组 `nums` 以及整数 `k`。

如果所有 `1` 都至少相距 `k` 个位置，则返回 `true`；否则，返回 `false`。

"至少相距 k 个位置"指：对任意两个 `1` 的下标 `i` 和 `j`（`i < j`），都满足 `j - i >= k`。

**示例 1：**
```
输入：nums = [1,0,0,0,1,0,0,1], k = 2
输出：true
解释：每对 1 之间都至少间隔了 2 个位置。
1 在下标 0, 4, 7，间距为 4 和 3，均 >= 2，返回 true。
```

**示例 2：**
```
输入：nums = [1,0,0,1,0,1], k = 2
输出：false
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= k <= nums.length`
- `nums[i]` 为 `0` 或 `1`

## 解题思路

**思路：记录上一个 1 的位置**

由于只需要检查相邻两个 `1` 之间的距离（非相邻的距离一定更大），因此：
1. 遍历数组，记录上一个 `1` 的下标 `last`（初始化为 `-k-1`）。
2. 遇到 `1` 时，检查 `当前下标 - last >= k`。
   - 若满足，更新 `last`。
   - 若不满足，直接返回 `false`。
3. 遍历完成后返回 `true`。

**为什么只检查相邻 1 之间的距离？**  
若相邻两个 1 的距离都 >= k，则所有 1 的距离自然 >= k（间距是单调不减的关系，相邻最小）。

## Java 代码实现

### 方法一：记录上一个 1 的位置（推荐）

```java
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        int last = -k - 1;  // 初始值确保第一个 1 一定满足条件

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) {
                if (i - last < k) {
                    return false;  // 距离不足 k
                }
                last = i;  // 更新上一个 1 的位置
            }
        }

        return true;
    }
}
```

### 方法二：提取所有 1 的下标，逐一比较

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        // 找出所有 1 的下标
        List<Integer> ones = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) ones.add(i);
        }

        // 检查相邻两个 1 的间距
        for (int i = 1; i < ones.size(); i++) {
            if (ones.get(i) - ones.get(i - 1) < k) {
                return false;
            }
        }

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历数组一次。
- **空间复杂度：**
  - 方法一：O(1)，仅用常数空间。
  - 方法二：O(m)，m 为 1 的数量。

## 图解示例

```
nums = [1,0,0,0,1,0,0,1], k = 2

遍历：
  下标 0：nums[0]=1，last=-3（初始），0-(-3)=3 >= 2，更新 last=0
  下标 4：nums[4]=1，4-0=4 >= 2，更新 last=4
  下标 7：nums[7]=1，7-4=3 >= 2，更新 last=7

遍历完毕，返回 true
```

## 关键点总结

1. 只需检查相邻两个 `1` 的距离，因为相邻距离是所有 `1` 对距离中最小的。
2. 初始化 `last = -k - 1` 确保遇到第一个 `1` 时不会误判（`0 - (-k-1) = k+1 >= k`）。
3. 如果数组中没有 `1` 或只有一个 `1`，方法自然返回 `true`。

## 易错点

- 初始 `last` 设置不当（如设为 0），导致第一个 1 在下标 0 时误判。
- 检查条件写成 `i - last <= k`（方向反了），或用 `>` 而非 `>=`（边界错误）。
- 忘记在找到不满足条件的情况时立即返回，继续遍历浪费时间。
