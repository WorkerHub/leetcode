## 题目描述

给你整数数组 `nums`，若子数组中相邻元素差的绝对值恰好为 1，则称其为**连续子数组**。返回所有连续子数组的元素之和的总和，对 `10^9+7` 取模。

## 解题思路

分别处理递增（差为 +1）和递减（差为 -1）的连续子数组。`dpInc[i]` = 以 i 结尾的所有递增连续子数组的和之和，`dpDec[i]` 同理。单个元素被两者各计算一次，最终减去重复。

## Java 代码实现

```java
class Solution {
    public int getSum(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        long[] dpInc = new long[n]; // 以 i 结尾的递增连续子数组和之和
        long[] dpDec = new long[n]; // 以 i 结尾的递减连续子数组和之和
        long[] inc = new long[n];   // 以 i 结尾的递增连续子数组数量
        long[] dec = new long[n];   // 以 i 结尾的递减连续子数组数量

        for (int i = 0; i < n; i++) {
            inc[i] = dec[i] = 1; // 自身算 1 个
            dpInc[i] = dpDec[i] = nums[i];
        }

        for (int i = 1; i < n; i++) {
            int diff = nums[i] - nums[i - 1];
            if (diff == 1) {
                inc[i] = inc[i - 1] + 1;
                // 新增的连续子数组 = 前面所有递增子数组后追加 nums[i]
                dpInc[i] = (dpInc[i - 1] + (long) nums[i] * inc[i]) % MOD;
            } else if (diff == -1) {
                dec[i] = dec[i - 1] + 1;
                dpDec[i] = (dpDec[i - 1] + (long) nums[i] * dec[i]) % MOD;
            }
        }

        long ans = 0;
        for (int i = 0; i < n; i++) {
            // 加上递增和递减，减去 nums[i]（单个元素重复计算了一次）
            ans = (ans + dpInc[i] + dpDec[i] - nums[i] % MOD + MOD) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 分递增（+1）和递减（-1）两类分别 DP
2. `dpInc[i] = dpInc[i-1] + nums[i] * inc[i]`：前面的子数组各追加 nums[i]，加上自身
3. 单个元素被递增和递减各算一次，最终减去一次重复
