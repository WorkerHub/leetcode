## 题目描述

给你二叉树的根节点 `root`，请你采用前序遍历的方式，将二叉树转化为一个由括号和整数组成的字符串，返回构造出的字符串。

空节点使用一对空括号对 `"()"` 表示，转化后需要省略所有不影响字符串与原始二叉树之间的一对一映射关系的空括号对。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/05/03/cons1-tree.jpg)

```
输入：root = [1,2,3,4]
输出："1(2(4))(3)"
解释：初步转化后得到 "1(2(4)())(3())"，
但省略所有不必要的空括号对后，得到 "1(2(4))(3)"
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/05/03/cons2-tree.jpg)

```
输入：root = [1,2,3,null,4]
输出："1(2()(4))(3)"
解释：和示例 1 类似，但不能省略第一个空括号对，否则会破坏输入与输出一一映射的关系
```

**提示：**

- 树中节点数目范围是 `[1, 10^4]`
- `-1000 <= Node.val <= 1000`

## 解题思路

这道题要求将二叉树转换为字符串，核心是**前序遍历 + 括号表示法**。

**规则总结：**

1. **根节点**：直接添加值
2. **左子树**：
   - 存在：添加 `(左子树字符串)`
   - 不存在但右子树存在：添加 `()`
   - 不存在且右子树也不存在：省略
3. **右子树**：
   - 存在：添加 `(右子树字符串)`
   - 不存在：省略

**省略规则：**
- 左右子树都为空：完全省略括号
- 只有右子树为空：省略右括号
- 只有左子树为空：**不能省略**左括号，必须用 `()` 占位

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
class Solution {
    public String tree2str(TreeNode root) {
        // 递归前序遍历构建字符串
        if (root == null) {
            return "";
        }

        // 根节点值
        StringBuilder result = new StringBuilder(String.valueOf(root.val));

        // 处理左子树
        if (root.left != null || root.right != null) {
            // 左子树存在或右子树存在时，都需要添加左括号
            result.append("(").append(tree2str(root.left)).append(")");
        }

        // 处理右子树
        if (root.right != null) {
            result.append("(").append(tree2str(root.right)).append(")");
        }

        return result.toString();
    }
}
```

### 方法二：递归（详细版）

```java
class Solution {
    public String tree2str(TreeNode root) {
        // 详细版本，清晰展示各种情况
        if (root == null) {
            return "";
        }

        String result = String.valueOf(root.val);

        // 情况1：左右子树都不存在
        if (root.left == null && root.right == null) {
            return result;
        }

        // 情况2：只有左子树存在
        if (root.left != null && root.right == null) {
            return result + "(" + tree2str(root.left) + ")";
        }

        // 情况3：只有右子树存在（左子树用空括号占位）
        if (root.left == null) {
            return result + "()" + "(" + tree2str(root.right) + ")";
        }

        // 情况4：左右子树都存在
        return result + "(" + tree2str(root.left) + ")"
                + "(" + tree2str(root.right) + ")";
    }
}
```

### 方法三：迭代（栈模拟递归）

```java
import java.util.*;

class Solution {
    public String tree2str(TreeNode root) {
        // 使用栈实现迭代版本
        if (root == null) return "";

        StringBuilder result = new StringBuilder();
        Deque<TreeNode> stack = new ArrayDeque<>();
        Set<TreeNode> visited = new HashSet<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.peek();

            if (visited.contains(node)) {
                // 节点已访问，添加右括号
                stack.pop();
                result.append(")");
            } else {
                // 第一次访问节点
                visited.add(node);
                result.append("(").append(node.val);

                // 特殊处理：只有右子树时，需要为左子树添加空括号
                if (node.left == null && node.right != null) {
                    result.append("()");
                }

                // 先右后左（因为栈是后进先出）
                if (node.right != null) {
                    stack.push(node.right);
                }
                if (node.left != null) {
                    stack.push(node.left);
                }
            }
        }

        // 去掉最外层的括号
        return result.substring(1, result.length() - 1);
    }
}
```

## 复杂度分析

### 递归方法
- **时间复杂度**：O(n)，n 为节点数，每个节点访问一次
- **空间复杂度**：O(h)，h 为树高，递归栈深度
  - 最坏情况（链式树）：O(n)
  - 最好情况（平衡树）：O(log n)

### 迭代方法
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈和 visited 集合

## 图解示例

示例 1：`root = [1,2,3,4]`

```
      1
     / \
    2   3
   /
  4

前序遍历：1 -> 2 -> 4 -> 3

构建过程：
1: "1"
├─ 左子树 2: "2"
│  ├─ 左子树 4: "4"
│  │  └─ 无子树，返回 "4"
│  └─ 无右子树，省略
│  返回 "2(4)"
└─ 右子树 3: "3"
   └─ 无子树，返回 "3"

最终：1 + (2(4)) + (3) = "1(2(4))(3)"
```

## 关键点总结

1. **前序遍历**：根 -> 左 -> 右
2. **括号规则**：
   - 左子树空但右子树非空：必须用 `()` 占位
   - 左右都空：完全省略括号
   - 右子树空：省略右括号
3. **递归边界**：空节点返回空字符串
4. **使用 StringBuilder**：Java 中字符串拼接用 StringBuilder 效率更高
5. **省略优化**：根据子树情况决定是否添加括号

## 易错点

1. **忘记左子树占位**：只有右子树时忘记为左子树添加 `()`
2. **过度省略括号**：左右都空时也添加括号
3. **条件判断顺序**：应该是 `if (root.left != null || root.right != null)`
4. **负数处理**：`String.valueOf(root.val)` 会自动处理负数

2. **掌握括号规则**：
   - 画出几个示例树，手动构建字符串
   - 总结什么情况需要括号，什么情况可以省略
   - 理解为什么左子树空时需要 `()` 占位

   - 使用 StringBuilder 而不是字符串直接拼接
   - 注意 TreeNode 的定义

   - 初学者：方法二（详细版），逻辑清晰
