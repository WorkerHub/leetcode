## 题目描述

给定特殊二叉树（每个节点有0或2个子节点，root.val = min(left.val, right.val)），返回第二小的值，不存在返回 -1。

**示例：**
```
输入：root = [2,2,5,null,null,5,7]
输出：5
```

## 解题思路

根节点值是最小值，DFS 搜索大于根节点值的最小值。节点值 > min_val 时无需继续搜索子树（剪枝）。

## Java 代码实现

```java
class Solution {
    private long secondMin = Long.MAX_VALUE;

    public int findSecondMinimumValue(TreeNode root) {
        int minVal = root.val;
        dfs(root, minVal);
        return secondMin == Long.MAX_VALUE ? -1 : (int) secondMin;
    }

    private void dfs(TreeNode node, int minVal) {
        if (node == null) return;

        // 当前值大于最小值，更新第二小值
        if (node.val > minVal && node.val < secondMin) {
            secondMin = node.val;
        }

        // 只有值等于最小值时才继续搜索子树
        if (node.val == minVal) {
            dfs(node.left, minVal);
            dfs(node.right, minVal);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **根节点性质**：根节点值一定是最小值
2. **剪枝优化**：节点值 > min_val 时不需要搜索子树
3. **用 long 避免溢出**：节点值可达 2^31 - 1
