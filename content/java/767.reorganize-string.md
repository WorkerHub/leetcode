## 题目描述

给定一个字符串 `s`，重新排列字符串，使得任意两个相邻的字符都不相同。

返回 `s` 的任意可能的重新排列。若不可能，返回空字符串 `""`。

**示例 1:**
```
输入: s = "aab"
输出: "aba"
```

**示例 2:**
```
输入: s = "aaab"
输出: ""
```

## 解题思路

使用贪心 + 堆的策略，每次选择出现次数最多的字符（且不同于上一个字符）。

## Java 代码实现

### 方法一：最大堆（推荐）

```java
import java.util.*;

class Solution {
    public String reorganizeString(String s) {
        // 统计字符频率
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        // 如果最高频率超过 (n+1)/2，无法重排
        int maxFreq = 0;
        for (int f : count) maxFreq = Math.max(maxFreq, f);
        if (maxFreq > (s.length() + 1) / 2) return "";

        // 最大堆（频率, 字符）
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        for (int i = 0; i < 26; i++) {
            if (count[i] > 0) heap.offer(new int[]{count[i], i});
        }

        StringBuilder result = new StringBuilder();
        int[] prev = {0, -1}; // 上一个字符的 {频率, 索引}

        while (!heap.isEmpty()) {
            int[] curr = heap.poll();
            result.append((char) ('a' + curr[1]));

            // 将上一个字符放回堆
            if (prev[0] > 0) heap.offer(prev);

            // 更新当前字符（频率 -1）
            prev = new int[]{curr[0] - 1, curr[1]};
        }

        return result.toString();
    }
}
```

### 方法二：排序 + 填充

```java
class Solution {
    public String reorganizeString(String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        int maxFreq = 0, maxChar = 0;
        for (int i = 0; i < 26; i++) {
            if (count[i] > maxFreq) {
                maxFreq = count[i];
                maxChar = i;
            }
        }

        // 如果最高频率超过 (n+1)/2，无法重排
        if (maxFreq > (s.length() + 1) / 2) return "";

        char[] result = new char[s.length()];
        int index = 0;

        // 先填充频率最高的字符（偶数位置）
        while (count[maxChar] > 0) {
            result[index] = (char) ('a' + maxChar);
            index += 2;
            count[maxChar]--;
        }

        // 再填充其余字符
        for (int i = 0; i < 26; i++) {
            while (count[i] > 0) {
                if (index >= s.length()) index = 1; // 切换到奇数位置
                result[index] = (char) ('a' + i);
                index += 2;
                count[i]--;
            }
        }

        return new String(result);
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n log k)，k 是不同字符数
- **空间复杂度：** O(k)

## 关键点总结

1. **判断可行性：** 最高频率不能超过 (n+1)/2
2. **贪心策略：** 每次选择频率最高的字符
3. **堆的应用：** 高效地获取最大元素
