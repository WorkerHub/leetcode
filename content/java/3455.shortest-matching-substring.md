## 题目描述

给你字符串 `s` 和模式字符串 `p`（恰好包含两个 `'*'`，可匹配任意字符序列）。找到 `s` 中能被 `p` 匹配的最短子串，返回其长度。不存在则返回 -1。

## 解题思路

将 p 按 `'*'` 分为三段 `pre`、`mid`、`suf`。用 KMP 找三段各自在 s 中的所有出现位置。对每个 pre 的起始位置，用二分查找在 mid 和 suf 的位置列表中找满足顺序约束的最短组合。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int shortestMatchingSubstring(String s, String p) {
        // 将 p 按 '*' 分为三段
        int star1 = p.indexOf('*');
        int star2 = p.indexOf('*', star1 + 1);
        String pre = p.substring(0, star1);
        String mid = p.substring(star1 + 1, star2);
        String suf = p.substring(star2 + 1);

        // KMP 找各段在 s 中的所有出现位置
        List<Integer> prePos = kmpSearch(s, pre);
        List<Integer> midPos = kmpSearch(s, mid);
        List<Integer> sufPos = kmpSearch(s, suf);

        int lp = pre.length(), lm = mid.length(), ls = suf.length();
        int ans = -1;

        for (int pi : prePos) {
            // mid 必须在 pi + lp 之后开始
            int minMidStart = pi + lp;
            int mi;
            int midStart;
            if (lm == 0) {
                midStart = minMidStart;
            } else {
                mi = lowerBound(midPos, minMidStart);
                if (mi >= midPos.size()) continue;
                midStart = midPos.get(mi);
            }

            // suf 必须在 midStart + lm 之后开始
            int minSufStart = midStart + lm;
            int sufStart;
            if (ls == 0) {
                sufStart = minSufStart;
            } else {
                int si = lowerBound(sufPos, minSufStart);
                if (si >= sufPos.size()) continue;
                sufStart = sufPos.get(si);
            }

            int length = sufStart + ls - pi;
            if (ans == -1 || length < ans) {
                ans = length;
            }
        }
        return ans;
    }

    // KMP 搜索，返回 pattern 在 text 中所有出现的起始位置
    private List<Integer> kmpSearch(String text, String pattern) {
        List<Integer> positions = new ArrayList<>();
        int n = text.length(), m = pattern.length();
        if (m == 0) {
            // 空串在所有位置都出现
            for (int i = 0; i <= n; i++) positions.add(i);
            return positions;
        }
        // 构建失败函数
        int[] fail = new int[m];
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && pattern.charAt(i) != pattern.charAt(j)) j = fail[j - 1];
            if (pattern.charAt(i) == pattern.charAt(j)) j++;
            fail[i] = j;
        }
        for (int i = 0, j = 0; i < n; i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) j = fail[j - 1];
            if (text.charAt(i) == pattern.charAt(j)) j++;
            if (j == m) {
                positions.add(i - m + 1);
                j = fail[j - 1];
            }
        }
        return positions;
    }

    // 二分查找：第一个 >= target 的位置下标
    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) * log n)，KMP 建表加二分查找
- 空间复杂度：O(n + m)

## 关键点总结

1. 将 p 分为三段（两个 * 分割的前中后）
2. KMP 找三段各自在 s 中的所有出现位置
3. 二分查找满足顺序约束的最短组合
