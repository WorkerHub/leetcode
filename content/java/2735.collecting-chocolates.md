## 题目描述

给你代价数组 `nums` 和整数 `x`，每次操作（代价 `x`）可以循环偏移所有类型的代价，返回收集所有类型巧克力的最小总代价。

## Java 代码实现

```java
class Solution {
    public long minCostToAcquireAllTypesOfFruits(int[] nums, long x) {
        int n = nums.length;
        // min_cost[i] 记录类型 i 在当前操作次数下的最小代价
        long[] minCost = new long[n];
        for (int i = 0; i < n; i++) minCost[i] = nums[i];
        long ans = 0;
        for (long v : minCost) ans += v;  // 0 次操作
        for (int k = 1; k < n; k++) {
            // 操作 k 次后，类型 i 可以选 nums[(i-k+n)%n]
            for (int i = 0; i < n; i++) {
                minCost[i] = Math.min(minCost[i], nums[(i - k + n) % n]);
            }
            // 总代价 = k*x + 各类型最小代价之和
            long total = (long) k * x;
            for (long v : minCost) total += v;
            ans = Math.min(ans, total);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 操作 k 次可以让类型 i 访问 k+1 个候选值（循环偏移）
2. 枚举操作次数，逐步更新每个类型的最小代价
3. 操作次数从 0 到 n-1（超过 n 次无意义）
