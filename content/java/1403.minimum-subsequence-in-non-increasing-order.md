## 题目描述

给你一个数组 `nums`，请你找到一个长度最小的子序列，满足该子序列的元素之和**严格大于**未包含在该子序列中的元素之和。

如果存在多个满足条件的子序列，请返回**元素之和最大**的子序列（也就是说，子序列按**非递增顺序**排序）。

题目数据保证满足所有条件的子序列存在。

**注意：** 子序列的元素不一定要连续。返回子序列需按**非递增顺序**排序。

**示例 1：**

```
输入：nums = [4,3,10,9,8]
输出：[10,9]
解释：子序列 [10,9] 和 [10,8] 是最小的、满足元素之和大于其他元素之和的子序列。
但是 [10,9] 的元素之和最大，所以返回 [10,9]。
```

**示例 2：**

```
输入：nums = [4,4,7,6,7]
输出：[7,7,6]
解释：子序列 [7,7] 和 [7,6] 都是最小的满足条件的子序列。但是 [7,7] 有两个 7，而 [7,6] 的元素和为 13 < 14，所以应返回 [7,7,6]。
实际上 7+7=14 > 4+4+6=14 不成立（要严格大于），所以需要取 [7,7,6]。
```

**示例 3：**

```
输入：nums = [6]
输出：[6]
```

**提示：**

- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`

## 解题思路

**贪心策略：**

要找"元素和最大的最短子序列"，自然想到**排序后从大到小取元素**：

1. 将 `nums` 降序排序
2. 从最大值开始逐个加入子序列，同时维护"子序列之和"和"剩余元素之和"
3. 一旦子序列之和 > 剩余元素之和，立即返回结果

**正确性证明：**
- 降序贪心保证了每次加入的都是当前最大值，使得子序列以最快速度超过剩余元素之和
- 这样得到的子序列长度最短，且在同等长度下元素之和最大

## Java 代码实现

### 方法一：降序排序 + 贪心（推荐）

```java
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] minSubsequence(int[] nums) {
        // 降序排序（通过转换为 Integer 数组实现）
        Integer[] arr = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) arr[i] = nums[i];
        Arrays.sort(arr, (a, b) -> b - a);

        int total = 0;
        for (int num : arr) total += num;  // 所有元素之和

        int subSum = 0;  // 子序列当前之和
        List<Integer> result = new ArrayList<>();

        for (int num : arr) {
            subSum += num;
            result.add(num);
            int remaining = total - subSum;  // 剩余元素之和
            // 子序列之和严格大于剩余之和时停止
            if (subSum > remaining) {
                break;
            }
        }

        // 转换为 int 数组返回
        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

### 方法二：用前缀和判断（等价写法）

```java
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] minSubsequence(int[] nums) {
        Integer[] arr = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) arr[i] = nums[i];
        Arrays.sort(arr, (a, b) -> b - a);

        int total = 0;
        for (int num : arr) total += num;

        List<Integer> result = new ArrayList<>();
        int currentSum = 0;

        for (int num : arr) {
            currentSum += num;
            result.add(num);
            // 当前子序列之和超过总和的一半时，就满足严格大于剩余之和
            if (currentSum * 2 > total) {
                break;
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度 O(n log n)**：排序主导。
- **空间复杂度 O(n)**：存储结果（最坏全部元素）。

## 图解示例

以 `nums = [4,3,10,9,8]` 为例：

```
排序后：[10, 9, 8, 4, 3]
total = 34, half = 17

i=0: 取 10, subSum=10, remaining=24, 10 <= 24，继续
i=1: 取 9,  subSum=19, remaining=15, 19 > 15，停止

返回 [10, 9]
```

以 `nums = [4,4,7,6,7]` 为例：

```
排序后：[7, 7, 6, 4, 4]
total = 28, half = 14

i=0: 取 7, subSum=7,  remaining=21, 7 <= 21，继续
i=1: 取 7, subSum=14, remaining=14, 14 <= 14（注意是严格大于），继续
i=2: 取 6, subSum=20, remaining=8,  20 > 8，停止

返回 [7, 7, 6]
```

## 关键点总结

1. 降序排序后从大到小贪心取元素，保证最短且和最大
2. 停止条件：子序列之和**严格大于**剩余之和（`subSum > total - subSum`）
3. 等价条件：`subSum * 2 > total`（避免浮点数）
4. 结果直接按降序排列，满足题目"非递增顺序"的要求

## 易错点

- 条件是**严格大于**（`>`），不是 `>=`，示例 2 中 `14 > 14` 不成立
- Java 中用 `subSum * 2 > total` 替代 `subSum > total / 2.0` 避免浮点运算
- 不需要从原数组中找子序列的下标，只需返回值即可（降序排序后直接取前若干个）
