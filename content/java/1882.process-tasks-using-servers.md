## 题目描述

给你服务器权重数组 `servers` 和任务处理时间数组 `tasks`，每个任务到达时分配给权重最小（相同则编号最小）的空闲服务器，无空闲则等待最早释放的服务器，返回每个任务分配的服务器编号数组。

## 解题思路

使用两个最小堆：空闲堆按 (weight, index) 排序，繁忙堆按 (finishTime, weight, index) 排序。每个任务到来时先释放已完成的服务器，再分配最优空闲服务器；若无空闲则取最早完成的服务器。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int[] assignTasks(int[] servers, int[] tasks) {
        int n = servers.length, m = tasks.length;
        // 空闲堆：(weight, index)
        PriorityQueue<int[]> freeHeap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        // 繁忙堆：(finishTime, weight, index)
        PriorityQueue<long[]> busyHeap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? Long.compare(a[0], b[0]) : (a[1] != b[1] ? Long.compare(a[1], b[1]) : Long.compare(a[2], b[2])));

        for (int i = 0; i < n; i++) {
            freeHeap.offer(new int[]{servers[i], i});
        }

        int[] result = new int[m];
        for (int j = 0; j < m; j++) {
            long time = j;
            // 释放已完成的服务器
            while (!busyHeap.isEmpty() && busyHeap.peek()[0] <= time) {
                long[] top = busyHeap.poll();
                freeHeap.offer(new int[]{(int) top[1], (int) top[2]});
            }

            if (!freeHeap.isEmpty()) {
                // 有空闲服务器，取最优的
                int[] srv = freeHeap.poll();
                result[j] = srv[1];
                busyHeap.offer(new long[]{time + tasks[j], srv[0], srv[1]});
            } else {
                // 无空闲服务器，等待最早完成的
                long[] srv = busyHeap.poll();
                result[j] = (int) srv[2];
                busyHeap.offer(new long[]{srv[0] + tasks[j], srv[1], srv[2]});
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) log n)，n 为服务器数，m 为任务数
- **空间复杂度**：O(n + m)

## 关键点总结

1. 两个堆：空闲堆按优先级（权重、编号），繁忙堆按完成时间
2. 每个任务到来时，先释放已完成的服务器，再分配
3. 若无空闲服务器，直接取繁忙堆堆顶，在其完成时间后开始任务
