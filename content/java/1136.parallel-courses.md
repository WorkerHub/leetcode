## 题目描述

n 门课程编号 1~n，relations[i] = [prev, next] 表示先修关系。每学期可学任意数量无前置依赖的课程。返回学完所有课程的最少学期数，有环则返回 -1。

**示例：**
```
输入：n = 3, relations = [[1,3],[2,3]]
输出：2（第一学期学 1,2；第二学期学 3）
```

## 解题思路

BFS 拓扑排序按层遍历，层数即为最少学期数。若遍历结束仍有未访问节点则存在环。

## Java 代码实现

```java
class Solution {
    public int minimumSemesters(int n, int[][] relations) {
        // 构建邻接表和入度数组
        List<Integer>[] graph = new List[n + 1];
        int[] inDegree = new int[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();

        for (int[] r : relations) {
            graph[r[0]].add(r[1]);
            inDegree[r[1]]++;
        }

        // 初始化队列：入度为 0 的课程
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 1; i <= n; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }

        int semesters = 0;
        int studied = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            semesters++;
            for (int k = 0; k < size; k++) {
                int course = queue.poll();
                studied++;
                for (int next : graph[course]) {
                    if (--inDegree[next] == 0) {
                        queue.offer(next);
                    }
                }
            }
        }

        return studied == n ? semesters : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + E)
- **空间复杂度**：O(n + E)

## 关键点总结

1. **BFS 拓扑排序**：按层遍历，每层为一个学期
2. **入度数组**：入度为 0 表示可以立即学习
3. **环检测**：遍历完成后 studied < n 则有环
4. **课程编号从 1 开始**：数组大小 n+1
