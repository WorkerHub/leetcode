## 题目描述

给你只含 `[` 和 `]` 的偶数长度字符串 `s`（各占一半），每次可交换任意两个字符，返回使 `s` 平衡所需的最少交换次数。

## 解题思路

统计扫描过程中最大的"未匹配 ]"数量 k（即最大负的括号余量），每次交换修复 2 个不匹配，答案为 `ceil(k/2)`。

## Java 代码实现

```java
class Solution {
    public int minSwaps(String s) {
        int bal = 0, unmatched = 0;
        for (char c : s.toCharArray()) {
            bal += (c == '[') ? 1 : -1;
            unmatched = Math.max(unmatched, -bal); // 记录最大未匹配 ] 数
        }
        return (unmatched + 1) / 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 扫描时记录最大未匹配 `]` 数量 k
2. 每次交换修复 2 个不匹配，答案为 `(k+1)/2`
3. 字符各占一半保证有解
