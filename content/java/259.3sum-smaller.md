## 题目描述

给定一个长度为 n 的整数数组 `nums` 和一个目标值 `target`，找出 `nums` 中满足以下条件的三元组 `(i, j, k)` 的数量：

- `0 <= i < j < k < n`
- `nums[i] + nums[j] + nums[k] < target`

**示例 1：**

```
输入：nums = [-2,0,1,3], target = 2
输出：2
解释：满足条件的三元组为：
[-2,0,1] 因为 (-2) + 0 + 1 = -1 < 2
[-2,0,3] 因为 (-2) + 0 + 3 = 1 < 2
```

**示例 2：**

```
输入：nums = [], target = 0
输出：0
```

**示例 3：**

```
输入：nums = [0], target = 0
输出：0
```

**提示：**
- `n == nums.length`
- `0 <= n <= 3500`
- `-100 <= nums[i] <= 100`
- `-100 <= target <= 100`

## 解题思路

这道题是经典的"三数之和"问题的变种，不需要找具体的三元组，只需要统计数量。

核心思想：
1. 先对数组排序
2. 固定第一个数，用双指针寻找另外两个数
3. 由于数组有序，可以快速统计满足条件的组合数

关键观察：
- 排序后，如果 `nums[i] + nums[left] + nums[right] < target`
- 那么 `left` 和 `left+1, left+2, ..., right-1` 之间的所有数都满足条件
- 可以一次性统计 `right - left` 个三元组

## Java 代码实现

### 方法一：排序 + 双指针（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        // 时间复杂度：O(n^2)，空间复杂度：O(log n)（排序）
        int n = nums.length;
        if (n < 3) return 0;

        // 排序，使双指针可以利用有序性
        Arrays.sort(nums);
        int count = 0;

        // 固定第一个数
        for (int i = 0; i < n - 2; i++) {
            int left = i + 1, right = n - 1;

            while (left < right) {
                int total = nums[i] + nums[left] + nums[right];

                if (total < target) {
                    // 关键：如果 nums[i] + nums[left] + nums[right] < target
                    // 由于数组有序，nums[left] 右边到 right 的所有数都满足
                    // 共 right - left 个三元组
                    count += right - left;
                    left++; // 移动左指针，继续寻找更多组合
                } else {
                    right--; // 和太大，缩小右边界
                }
            }
        }

        return count;
    }
}
```

### 方法二：详细注释版本

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        int n = nums.length;
        if (n < 3) return 0;

        Arrays.sort(nums);
        int count = 0;

        for (int i = 0; i < n - 2; i++) {
            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                int currentSum = nums[i] + nums[left] + nums[right];

                if (currentSum < target) {
                    // nums[i] + nums[left] + nums[right] < target
                    // 因为数组已排序，nums[left] < nums[left+1] < ... < nums[right]
                    // 所以 nums[i] + nums[left] + j 对于所有 j ∈ [left+1, right] 都 < target
                    // 这些三元组为：(i, left, left+1), (i, left, left+2), ..., (i, left, right)
                    // 共 right - left 个
                    count += right - left;
                    left++; // 移动左指针，继续查找以 left 为中间值的三元组
                } else {
                    right--; // 和太大，需要减小
                }
            }
        }

        return count;
    }
}
```

### 方法三：暴力解法（用于对比）

```java
class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        // 暴力枚举所有三元组，时间复杂度 O(n^3)
        int n = nums.length;
        int count = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    if (nums[i] + nums[j] + nums[k] < target) {
                        count++;
                    }
                }
            }
        }

        return count;
    }
}
```

### 方法四：排序 + 二分查找

```java
import java.util.Arrays;

class Solution {
    public int threeSumSmaller(int[] nums, int target) {
        // 时间复杂度：O(n^2 log n)
        int n = nums.length;
        if (n < 3) return 0;

        Arrays.sort(nums);
        int count = 0;

        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                // 寻找满足 nums[i] + nums[j] + nums[k] < target 的最大 k
                // 即 nums[k] < target - nums[i] - nums[j]
                int targetVal = target - nums[i] - nums[j];

                // 二分查找第一个 >= targetVal 的位置
                int lo = j + 1, hi = n;
                while (lo < hi) {
                    int mid = lo + (hi - lo) / 2;
                    if (nums[mid] < targetVal) lo = mid + 1;
                    else hi = mid;
                }

                // [j+1, lo-1] 范围内的数都满足条件
                count += lo - j - 1;
            }
        }

        return count;
    }
}
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：O(n^2)，排序 O(n log n) + 双重循环 O(n^2)
- 空间复杂度：O(log n)，排序所需的栈空间

**方法三（暴力）：**
- 时间复杂度：O(n^3)
- 空间复杂度：O(1)

**方法四（二分查找）：**
- 时间复杂度：O(n^2 log n)
- 空间复杂度：O(1)

## 图解示例

以 `nums = [-2,0,1,3], target = 2` 为例：

```
排序后：nums = [-2, 0, 1, 3]
索引：         0   1  2  3

i=0, nums[i]=-2:
  left=1(0), right=3(3)
  sum = -2 + 0 + 3 = 1 < 2 ✓
  → 有 (3-1) = 2 个三元组：
    [-2, 0, 1]: -2 + 0 + 1 = -1 < 2 ✓
    [-2, 0, 3]: -2 + 0 + 3 = 1 < 2 ✓
  → count = 2, left = 2

  left=2(1), right=3(3)
  sum = -2 + 1 + 3 = 2 >= 2 ✗
  → right = 2

  left=2, right=2, 循环结束

i=1, nums[i]=0:
  left=2(1), right=3(3)
  sum = 0 + 1 + 3 = 4 >= 2 ✗
  → right = 2

  left=2, right=2, 循环结束

最终结果：count = 2
```

为什么 `count += right - left`：

```
当 i=0, left=1, right=3 时：
nums[0] + nums[1] + nums[3] = -2 + 0 + 3 = 1 < 2

因为数组有序，nums[2] = 1 < nums[3] = 3：
- nums[0] + nums[1] + nums[2] = -2 + 0 + 1 = -1 < 2 ✓

共有 right - left = 3 - 1 = 2 个满足条件的三元组
```

## 关键点总结

1. **排序是关键**：排序后可以使用双指针优化
2. **双指针技巧**：左右指针根据和的大小调整
3. **计数优化**：利用有序性质，一次性统计多个三元组
4. **不需要去重**：题目只要求统计数量，不需要返回具体三元组
5. **公式理解**：`count += right - left` 是核心

## 易错点

1. **理解计数公式**
   ```java
   // 错误：只统计当前一个
   if (total < target) count += 1;

   // 正确：统计所有满足条件的
   if (total < target) count += right - left;
   ```

2. **循环边界**
   ```java
   // 错误：i 可以到 n-1
   for (int i = 0; i < n; i++)

   // 正确：至少要留两个位置给 left 和 right
   for (int i = 0; i < n - 2; i++)
   ```

3. **指针移动方向**
   ```java
   // 当 sum < target 时，要增大和，移动 left
   if (total < target) {
       count += right - left;
       left++;  // 向右移动
   } else {
       right--; // 向左移动
   }
   ```

4. **边界条件**
   ```java
   // 数组长度小于 3 时，无法组成三元组
   if (n < 3) return 0;
   ```
