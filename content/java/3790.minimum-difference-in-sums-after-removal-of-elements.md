## 题目描述

给定长度为 `3n` 的整数数组 `nums`，移除恰好 `n` 个元素，使剩余 `2n` 个元素中前 `n` 个的和与后 `n` 个的和的差最小化，返回该最小差值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumDifference(int[] nums) {
        int total = nums.length, n = total / 3;

        // left[i]: nums[0..i-1] 中最小 n 个元素之和（i 从 n 到 2n）
        long[] left = new long[total + 1];
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        long curSum = 0;
        for (int i = 0; i < n; i++) { maxHeap.offer(nums[i]); curSum += nums[i]; }
        left[n] = curSum;
        for (int i = n; i < 2 * n; i++) {
            maxHeap.offer(nums[i]);
            curSum += nums[i];
            curSum -= maxHeap.poll(); // 弹出最大值，保持最小 n 个
            left[i + 1] = curSum;
        }

        // right[i]: nums[i..3n-1] 中最大 n 个元素之和（i 从 2n 到 n）
        long[] right = new long[total + 1];
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        curSum = 0;
        for (int i = total - 1; i >= total - n; i--) { minHeap.offer(nums[i]); curSum += nums[i]; }
        right[total - n] = curSum;
        for (int i = total - n - 1; i >= n; i--) {
            minHeap.offer(nums[i]);
            curSum += nums[i];
            curSum -= minHeap.poll(); // 弹出最小值，保持最大 n 个
            right[i] = curSum;
        }

        long ans = Long.MAX_VALUE;
        for (int k = n; k <= 2 * n; k++) ans = Math.min(ans, left[k] - right[k]);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作
- 空间复杂度：O(n)

## 关键点总结

1. 分割点 `k` 从 `n` 到 `2n` 枚举，前半部分取最小 n 个，后半部分取最大 n 个
2. 用最大堆维护前缀最小 n 个元素之和，用最小堆维护后缀最大 n 个元素之和
3. 答案需用 `long` 防止溢出
