## 题目描述

给定整数数组 `nums`，若存在 `i < j` 且 `nums[j] > nums[i]`，返回所有满足条件的 `nums[j] - nums[i]` 的最大值；否则返回 -1。

## 解题思路

维护前缀最小值，遍历时对每个 `nums[j]` 计算与当前最小值的差，更新最大差值。与股票买卖（LeetCode 121）思路相同。

## Java 代码实现

### 方法一：前缀最小值（推荐）

```java
class Solution {
    public int maximumDifference(int[] nums) {
        int minVal = nums[0];
        int maxDiff = -1;

        for (int j = 1; j < nums.length; j++) {
            if (nums[j] > minVal) {
                maxDiff = Math.max(maxDiff, nums[j] - minVal);
            } else {
                minVal = Math.min(minVal, nums[j]);
            }
        }

        return maxDiff;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 维护前缀最小值，对每个新元素计算差值
2. 差值严格大于 0 才更新答案（等于 0 不算）
3. 不能用全局 max-min，因为要求 i < j（需要前缀最小值）
