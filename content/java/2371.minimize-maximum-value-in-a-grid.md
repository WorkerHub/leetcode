## 题目描述

给你 m×n 整数矩阵 `grid`（所有值各不相同），将每个格子替换为正整数，使同行同列均非递减，返回替换后矩阵最大值的最小可能值。

## 解题思路

将所有格子按原始值从小到大排序，依次处理每个格子，替换值取"当前行已分配最大值"和"当前列已分配最大值"中的较大值加 1，保证行列非递减且尽可能小。

## Java 代码实现

```java
class Solution {
    public int[][] minScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 收集所有格子并按原始值排序
        int[][] cells = new int[m * n][3];
        int idx = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                cells[idx++] = new int[]{grid[i][j], i, j};
        Arrays.sort(cells, (a, b) -> a[0] - b[0]);

        int[] rowMax = new int[m]; // 每行已分配最大值
        int[] colMax = new int[n]; // 每列已分配最大值
        int[][] result = new int[m][n];
        for (int[] cell : cells) {
            int i = cell[1], j = cell[2];
            // 替换值至少比行最大值和列最大值各大 1
            int val = Math.max(rowMax[i], colMax[j]) + 1;
            result[i][j] = val;
            rowMax[i] = val;
            colMax[j] = val;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m*n * log(m*n))
- **空间复杂度**：O(m*n)

## 关键点总结

1. 按原始值升序处理，保证处理当前格子时同行列中原始值更小的格子已处理完毕。
2. 替换值取行列已分配最大值的较大者加 1，贪心使局部值尽量小。
3. 最终返回结果矩阵（最大值即为最后处理格子的替换值）。
