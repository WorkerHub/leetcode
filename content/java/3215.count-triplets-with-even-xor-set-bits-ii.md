## 题目描述

给你三个整数数组 `a`、`b`、`c`，返回三元组 `(a[i], b[j], c[k])` 的数量，使得 `a[i] XOR b[j] XOR c[k]` 中设置位（1 的个数）的数量为偶数。

## Java 代码实现

```java
class Solution {
    public long numberOfTriplets(int[] a, int[] b, int[] c) {
        // 统计各数组中 popcount 为偶数/奇数的元素数量
        long[] ca = countParity(a);
        long[] cb = countParity(b);
        long[] cc = countParity(c);

        // 三个 popcount 之和为偶数：全偶 或 两奇一偶（三种排列）
        return ca[0] * cb[0] * cc[0]
             + ca[1] * cb[1] * cc[0]
             + ca[1] * cb[0] * cc[1]
             + ca[0] * cb[1] * cc[1];
    }

    private long[] countParity(int[] arr) {
        long even = 0, odd = 0;
        for (int x : arr) {
            if (Integer.bitCount(x) % 2 == 0) even++;
            else odd++;
        }
        return new long[]{even, odd};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m + p)，分别遍历三个数组
- 空间复杂度：O(1)

## 关键点总结

1. XOR 的 popcount 奇偶性等于各个数 popcount 奇偶性的异或（加法模 2）
2. 三个数 popcount 之和为偶数：全偶 或 两奇一偶（三种排列）
3. 分别统计三个数组奇偶 popcount 数量后直接乘法组合
