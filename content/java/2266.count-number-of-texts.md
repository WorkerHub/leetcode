## 题目描述

旧手机按键输入，给定按键序列，求可能发送的不同信息数量（mod 1e9+7）。

## 解题思路

按相同字符分段，每段独立DP。键7和9可连按1-4次，其余1-3次。f(n)=f(n-1)+f(n-2)+f(n-3)[+f(n-4)]，各段结果相乘。

## Java 代码实现

```java
class Solution {
    public int countTexts(String pressedKeys) {
        int MOD = 1_000_000_007;
        int n = pressedKeys.length();

        // 预计算dp3和dp4
        long[] dp3 = new long[n + 1];
        long[] dp4 = new long[n + 1];
        dp3[0] = dp4[0] = 1;
        for (int i = 1; i <= n; i++) {
            dp3[i] = dp3[i - 1];
            if (i >= 2) dp3[i] = (dp3[i] + dp3[i - 2]) % MOD;
            if (i >= 3) dp3[i] = (dp3[i] + dp3[i - 3]) % MOD;
            dp4[i] = dp4[i - 1];
            if (i >= 2) dp4[i] = (dp4[i] + dp4[i - 2]) % MOD;
            if (i >= 3) dp4[i] = (dp4[i] + dp4[i - 3]) % MOD;
            if (i >= 4) dp4[i] = (dp4[i] + dp4[i - 4]) % MOD;
        }

        long ans = 1;
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && pressedKeys.charAt(j) == pressedKeys.charAt(i)) j++;
            int len = j - i;
            char ch = pressedKeys.charAt(i);
            if (ch == '7' || ch == '9') {
                ans = ans * dp4[len] % MOD;
            } else {
                ans = ans * dp3[len] % MOD;
            }
            i = j;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分段独立**：连续相同字符各段方案数相乘
2. **7/9键最多4次，其余最多3次**
3. **DP递推类似爬楼梯**：f(n)=f(n-1)+...+f(n-k)
