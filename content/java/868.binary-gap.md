## 题目描述

给定一个正整数 n，找到并返回 n 的二进制表示中两个 相邻 1 之间的 最长距离 。如果不存在两个相邻的 1，返回 0 。

如果只有 0 将两个 1 分隔开（可能不存在 0 ），则认为这两个 1 彼此 相邻 。两个 1 之间的距离是它们的 位置 之间的绝对差。例如，"1001" 中的两个 1 的距离为 3 。

**示例 1：**
```
输入：n = 22
输出：2
解释：22 的二进制是 "10110" 。
第一个相邻的两个 1 的距离为 2 。
第二个相邻的两个 1 的距离为 1 。
答案取两者中最大的，也就是 2 。
```

**示例 2：**
```
输入：n = 8
输出：0
解释：8 的二进制是 "1000" 。
在 8 的二进制表示中没有相邻的两个 1，所以返回 0 。
```

**提示：**
- 1 <= n <= 10^9

## 解题思路

找到所有 1 的位置，计算相邻 1 之间的最大距离。

## Java 代码实现

### 方法一：一次遍历（推荐）

```java
class Solution {
    public int binaryGap(int n) {
        int last = -1; // 上一个 1 的位置
        int result = 0;
        int pos = 0;

        while (n != 0) {
            if ((n & 1) == 1) {
                if (last != -1) {
                    result = Math.max(result, pos - last);
                }
                last = pos;
            }
            n >>= 1;
            pos++;
        }

        return result;
    }
}
```

**代码说明：**
- `n & 1` 检查最低位是否为 1
- `n >>= 1` 右移一位，检查下一位
- `last` 记录上一个 1 的位置，-1 表示还未遇到 1

### 方法二：字符串方法

```java
class Solution {
    public int binaryGap(int n) {
        String binary = Integer.toBinaryString(n);
        int result = 0;
        int last = -1;

        for (int i = 0; i < binary.length(); i++) {
            if (binary.charAt(i) == '1') {
                if (last != -1) {
                    result = Math.max(result, i - last);
                }
                last = i;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，二进制位数。
- **空间复杂度**：O(1) 或 O(log n)（字符串方法）。

## 关键点总结

1. **位运算**：`n & 1` 检查最低位，`n >>= 1` 右移
2. **记录位置**：跟踪上一个 1 的位置
3. **计算间距**：相邻位置的差值取最大
