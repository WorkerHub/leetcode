## 题目描述

设计王位继承系统，支持birth/death/getInheritanceOrder。继承顺序基于家族树前序遍历，死亡者不出现但其后代仍继承。

## 解题思路

哈希表存孩子列表，死亡集合标记。getInheritanceOrder做前序DFS，跳过死者但继续遍历其子树。

## Java 代码实现

```java
class ThroneInheritance {
    private String king;
    private Map<String, List<String>> children;
    private Set<String> dead;
    
    public ThroneInheritance(String kingName) {
        this.king = kingName;
        this.children = new HashMap<>();
        this.dead = new HashSet<>();
    }
    
    public void birth(String parentName, String childName) {
        children.computeIfAbsent(parentName, k -> new ArrayList<>()).add(childName);
    }
    
    public void death(String name) {
        dead.add(name);
    }
    
    public List<String> getInheritanceOrder() {
        List<String> order = new ArrayList<>();
        dfs(king, order);
        return order;
    }
    
    private void dfs(String name, List<String> order) {
        if (!dead.contains(name)) {
            order.add(name);
        }
        // 死者的后代仍需遍历
        List<String> kids = children.get(name);
        if (kids != null) {
            for (String child : kids) {
                dfs(child, order);
            }
        }
    }
}
```

## 复杂度分析

- **birth/death**：O(1)
- **getInheritanceOrder**：O(N)，N为家族总人数

## 关键点总结

1. **有序孩子列表**：按出生顺序存储
2. **死亡只标记不删除**：DFS跳过死者但遍历其子树
3. **前序DFS**：恰好给出正确继承顺序
