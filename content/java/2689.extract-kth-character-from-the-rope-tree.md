## 题目描述

给你一棵绳索树，叶节点有字符串值，内部节点代表子树字符串的拼接，返回整个字符串中第 `k` 个字符（1-indexed）。

## Java 代码实现

```java
class Solution {
    public char getKthCharacter(RopeTreeNode root, int k) {
        return dfs(root, k);
    }

    private char dfs(RopeTreeNode node, int k) {
        // 叶节点直接返回对应字符
        if (node.left == null && node.right == null) {
            return node.val.charAt(k - 1);
        }
        // 获取左子树长度，决定在哪棵子树中查找
        int leftLen = getLength(node.left);
        if (k <= leftLen) {
            return dfs(node.left, k);
        } else {
            return dfs(node.right, k - leftLen);
        }
    }

    private int getLength(RopeTreeNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return node.val.length();
        return node.len;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)（平衡树时）
- 空间复杂度：O(depth)

## 关键点总结

1. 利用左子树长度剪枝，直接定位到目标子树
2. k 是 1-indexed，叶节点访问 `charAt(k-1)`
