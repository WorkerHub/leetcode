## 题目描述

给你整数 `n`，返回 `[1..n]` 的排列数，满足每个位置 i（1-indexed）处的元素能被 i 整除。

## 解题思路

状态压缩 DP：`dp[mask]` 表示已使用数字集合为 mask 时的方案数，当前填的位置 = popcount(mask)+1。枚举未使用的数字 num，若 num 能被当前位置整除则转移。

## Java 代码实现

```java
class Solution {
    public int selfDivisiblePermutationCount(int n) {
        int[] dp = new int[1 << n];
        dp[0] = 1;

        for (int mask = 0; mask < (1 << n); mask++) {
            int pos = Integer.bitCount(mask) + 1; // 当前要填的位置（1-indexed）
            if (pos > n) continue;
            for (int num = 1; num <= n; num++) {
                if ((mask >> (num - 1) & 1) == 1) continue; // 已使用
                if (num % pos == 0) { // num 能被位置整除
                    dp[mask | (1 << (num - 1))] += dp[mask];
                }
            }
        }
        return dp[(1 << n) - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 2ⁿ)
- **空间复杂度**：O(2ⁿ)

## 关键点总结

1. mask 第 i 位为 1 表示数字 i+1 已使用
2. 当前位置 = 已使用数字个数 + 1
3. 条件 num % pos == 0（num 能被位置 pos 整除）
