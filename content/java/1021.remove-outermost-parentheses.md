## 题目描述

给定有效括号字符串 s，删除每个原语（primitive）的最外层括号后返回结果。

**示例：**
```
输入：s = "(()())(())"
输出："()()()"
```

## 解题思路

计数器：用 level 追踪当前括号深度，level > 0 时才添加字符（跳过最外层）。

## Java 代码实现

```java
class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder sb = new StringBuilder();
        int level = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                if (level > 0) sb.append(c);
                level++;
            } else {
                level--;
                if (level > 0) sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **层数追踪**：level 为 0 时是原语边界
2. **跳过最外层**：level == 0 的左括号和 level == 1 变 0 的右括号不加
3. **处理顺序**：左括号先判断后加，右括号先减后判断
