## 题目描述

给你字符串 `s`（由空格分隔的单词组成），返回 `s` 的不同字母异位词数目（每个单词独立计算排列数之积），结果对 `10^9+7` 取模。

## 解题思路

每个单词的不同排列数 = `len! / (c1! × c2! × ... × ck!)`，预计算阶乘和阶乘逆元（费马小定理），对所有单词的排列数取乘积。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public long countAnagrams(String s) {
        int n = s.length();
        long[] fact = new long[n + 1];
        long[] invFact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = modPow(fact[n], MOD - 2, MOD);
        for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

        long result = 1;
        for (String word : s.split(" ")) {
            int len = word.length();
            long perm = fact[len];
            // 除以各字符频次的阶乘
            int[] cnt = new int[26];
            for (char c : word.toCharArray()) cnt[c - 'a']++;
            for (int c : cnt) perm = perm * invFact[c] % MOD;
            result = result * perm % MOD;
        }
        return result;
    }

    private long modPow(long base, long exp, long mod) {
        long res = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) res = res * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|s|)
- **空间复杂度**：O(|s|)

## 关键点总结

1. 每个单词的不同排列数 = `n! / (各字符频次的阶乘之积)`
2. 预计算阶乘逆元数组（线性递推）比每次调用快速幂高效
3. 费马小定理：`a^{-1} ≡ a^{p-2} (mod p)`
