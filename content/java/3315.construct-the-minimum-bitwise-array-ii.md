## 题目描述

与 3314 相同，但数据范围更大：`nums[i] <= 10^9`，需要 O(log n) 的解法。构造数组 `ans` 满足 `ans[i] | (ans[i] + 1) == nums[i]`，无解时为 -1。

## 解题思路

对奇质数 p，设 p 二进制末尾有 t 个连续的 1，最小解为 `x = p ^ (1 << (t-1))`（清除末尾连续 1 中最高的那个 1）。`t` 可由 `p ^ (p+1)` 的位长度减 1 得到（`p ^ (p+1)` 恰好有 t+1 个连续的 1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] minBitwiseArray(List<Integer> nums) {
        int[] result = new int[nums.size()];
        for (int i = 0; i < nums.size(); i++) {
            int p = nums.get(i);
            if (p == 2) { result[i] = -1; continue; }
            // p^(p+1) 有 t+1 个末尾连续1，位长度 = t+1
            int mask = p ^ (p + 1);
            int t = 32 - Integer.numberOfLeadingZeros(mask) - 1; // t = bit_length - 1
            result[i] = p ^ (1 << (t - 1)); // 清除末尾连续1中最高的那位
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个数 O(1) 处理
- 空间复杂度：O(1)，不计输出

## 关键点总结

1. `p ^ (p+1)` 的位长度 - 1 快速计算末尾连续 1 的个数 t
2. 答案是 `p ^ (1 << (t-1))`，即清除末尾 t 个连续 1 中最高位
3. 唯一偶质数 2 无解
