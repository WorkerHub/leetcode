## 题目描述

给定一个二维整数数组 `intervals`，其中 `intervals[i] = [starti, endi]` 表示从 `starti` 到 `endi` 的所有整数，包括 `starti` 和 `endi`。

返回集合 `S` 的最小大小，使得对于 `intervals` 中的每个区间，`S` 与该区间的交集大小至少为 2。

**示例 1:**
```
输入: intervals = [[1,3],[1,4],[2,5],[3,5]]
输出: 3
解释: 考虑集合 S = {2, 3, 4}。对于每个区间，S 与该区间至少有 2 个元素的交集。
```

**示例 2:**
```
输入: intervals = [[1,2],[2,3],[2,4],[4,5]]
输出: 5
解释: 一个最小的集合是 {1, 2, 3, 4, 5}。
```

**提示:**
- `1 <= intervals.length <= 3000`
- `intervals[i].length == 2`
- `0 <= starti < endi <= 10^8`

## 解题思路

这是一个贪心算法问题。关键是找到合适的排序策略和选择策略。

**核心思想：**
1. 按照区间的结束位置排序，如果结束位置相同，按开始位置降序排序
2. 对于每个区间，尽量选择靠右的元素（因为这样更可能覆盖后面的区间）
3. 维护已选择的最后两个元素，检查当前区间是否被覆盖

**算法流程：**
1. 按 (end, -start) 排序区间
2. 初始化两个指针 p1, p2 为 -1（表示还没选择）
3. 对于每个区间：
   - 如果 p1 和 p2 都在区间内，已覆盖，跳过
   - 如果只有 p2 在区间内，选择区间的最后一个元素
   - 如果都不在，选择区间的最后两个元素

## Java 代码实现

### 方法一：贪心算法（推荐）

```java
import java.util.Arrays;

class Solution {
    public int intersectionSizeTwo(int[][] intervals) {
        // 按结束位置排序，结束位置相同则按开始位置降序
        Arrays.sort(intervals, (a, b) -> a[1] != b[1] ? a[1] - b[1] : b[0] - a[0]);

        // 最后选择的两个元素
        int p1 = -1, p2 = -1;
        int result = 0;

        for (int[] interval : intervals) {
            int start = interval[0], end = interval[1];

            // 情况 1: 两个元素都不在区间内
            if (start > p2) {
                // 选择区间最右边的两个元素
                p1 = end - 1;
                p2 = end;
                result += 2;
            }
            // 情况 2: 只有 p2 在区间内（p1 不在）
            else if (start > p1) {
                // 选择当前区间的最后一个元素
                p1 = p2;
                p2 = end;
                result += 1;
            }
            // 情况 3: p1 和 p2 都在区间内，不需要添加新元素
        }

        return result;
    }
}
```

### 方法二：详细注释版（易理解）

```java
import java.util.Arrays;

class Solution {
    public int intersectionSizeTwo(int[][] intervals) {
        // 排序策略：
        // 1. 按区间结束位置升序排序
        // 2. 如果结束位置相同，按开始位置降序排序
        Arrays.sort(intervals, (a, b) -> {
            if (a[1] != b[1]) return a[1] - b[1];
            return b[0] - a[0]; // 结束相同时，开始位置大的排前面
        });

        // last1: 倒数第二个选择的元素
        // last2: 最后一个选择的元素
        // 初始化为 -1 表示还没有选择任何元素
        int last1 = -1, last2 = -1;
        int count = 0;

        for (int[] interval : intervals) {
            int start = interval[0], end = interval[1];

            // 情况 1: 两个元素都不在当前区间内，需要选择 2 个新元素
            if (start > last2) {
                // 贪心策略：选择区间最右边的两个元素
                last1 = end - 1;
                last2 = end;
                count += 2;
            }
            // 情况 2: last2 在区间内，但 last1 不在，只需再选 1 个元素
            else if (start > last1) {
                last1 = last2;
                last2 = end;
                count += 1;
            }
            // 情况 3: last1 和 last2 都在区间内，不需要添加新元素
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n log n)，主要是排序的时间
- **空间复杂度：** O(1)，只使用常数额外空间（不计排序的空间）

## 关键点总结

1. **排序策略：** 按结束位置排序，相同时按开始位置降序
2. **贪心选择：** 总是选择区间最右边的元素
3. **状态维护：** 只需要记录最后选择的两个元素
4. **分类讨论：** 根据已选元素与当前区间的关系分三种情况
5. **正确性证明：** 选择最右边的元素能覆盖更多后续区间

## 易错点

1. **排序条件：** 结束位置相同时要按开始位置降序，不是升序
2. **边界判断：** 要正确判断元素是否在区间内
3. **更新顺序：** 选择一个新元素时，p1 和 p2 的更新顺序要正确
4. **初始值：** p1 和 p2 的初始值要设为不可能出现在区间内的值
5. **选择策略：** 要选择区间最右边的元素，不是最左边
