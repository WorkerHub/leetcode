## 题目描述

给定一个 N 叉树的根节点 `root`，返回其节点值的后序遍历。

## Java 代码实现

### 方法一：递归

```java
class Solution {
    public List<Integer> postorder(Node root) {
        List<Integer> result = new ArrayList<>();
        dfs(root, result);
        return result;
    }

    private void dfs(Node node, List<Integer> result) {
        if (node == null) return;
        for (Node child : node.children) {
            dfs(child, result);
        }
        result.add(node.val);
    }
}
```

### 方法二：迭代（前序逆序）

```java
class Solution {
    public List<Integer> postorder(Node root) {
        LinkedList<Integer> result = new LinkedList<>();
        if (root == null) return result;
        Deque<Node> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            Node node = stack.pop();
            result.addFirst(node.val);
            for (Node child : node.children) {
                stack.push(child);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)
