## 题目描述

给你二进制数组 nums、整数 k 和 maxChanges，每次可将相邻位变为 1（最多 maxChanges 次）或移动并拾起 1，返回 Alice 拾起 k 个 1 的最少操作次数。

## 解题思路

贪心：枚举 Alice 起始位置，先拾起相邻最多 3 个 1，再用 maxChanges 次变更（每次 2 步），剩余的用滑动窗口在 1 的位置数组上找最近的 remaining 个 1（以中位数为集合中心最小化移动距离），利用前缀和快速计算代价。

## Java 代码实现

```java
class Solution {
    public long minimumMoves(int[] nums, int k, int maxChanges) {
        int n = nums.length;
        // 收集所有 1 的位置
        List<Integer> ones = new ArrayList<>();
        for (int i = 0; i < n; i++) if (nums[i] == 1) ones.add(i);
        int m = ones.size();

        // 前缀和用于快速计算区间元素到中位数的距离和
        long[] prefix = new long[m + 1];
        for (int i = 0; i < m; i++) prefix[i + 1] = prefix[i] + ones.get(i);

        long ans = Long.MAX_VALUE;
        for (int si = 0; si < n; si++) {
            // 计算附近（距离 <= 1）可直接拾起的 1 的数量
            int free = 0;
            for (int d = -1; d <= 1; d++) {
                int pos = si + d;
                if (pos >= 0 && pos < n && nums[pos] == 1) free++;
            }
            free = Math.min(free, k);
            int needChange = Math.min(maxChanges, k - free);
            int needWindow = k - free - needChange;
            long base = (long) needChange * 2;

            if (needWindow <= 0) { ans = Math.min(ans, base); continue; }
            if (needWindow > m) continue;

            // 滑动窗口大小 needWindow，中心取中位数
            for (int l = 0; l + needWindow - 1 < m; l++) {
                int r = l + needWindow - 1, mid = (l + r) / 2;
                long midPos = ones.get(mid);
                // 计算窗口内元素到中位数的总距离
                long costL = midPos * (mid - l + 1) - (prefix[mid + 1] - prefix[l]);
                long costR = (prefix[r + 1] - prefix[mid]) - midPos * (r - mid + 1);
                long cost = base + Math.abs(si - midPos) + costL + costR;
                ans = Math.min(ans, cost);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m)，枚举起始位置和窗口
- **空间复杂度**：O(m)

## 关键点总结

1. 贪心：先用相邻 1，再用变更，最后移动到更远的 1
2. 滑动窗口在 1 的位置数组上移动，以中位数为集合中心最优
3. 前缀和快速计算区间元素到中位数的距离和
