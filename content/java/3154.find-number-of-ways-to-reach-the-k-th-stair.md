## 题目描述

从第 1 阶出发，可执行操作 1（向下一阶，不能连续且不能在第 0 阶以下）或操作 2（向上 2^jump 阶，jump 从 0 开始自增），每次到达第 k 阶计一次，返回总次数。

## 解题思路

设执行 m 次操作 2，插入 d 次操作 1（向下），最终位置为 `1 + (2^m - 1) - d = k`，即 `d = 2^m - k`。操作 1 只能插在操作 2 之间（共 m+1 个间隔），每间隔最多一次，方案数为 `C(m+1, d)`。枚举 m 从 0 到 30 累加即可。

## Java 代码实现

```java
class Solution {
    public int waysToReachStair(int k) {
        int ans = 0;
        // 枚举操作 2 的次数 m（最多约 30 次，因为 2^30 > 10^9）
        for (int m = 0; m <= 30; m++) {
            long d = (1L << m) - k; // 需要向下操作的次数
            if (d < 0 || d > m + 1) continue;
            ans += comb(m + 1, (int) d);
        }
        return ans;
    }

    // 计算组合数 C(n, r)
    private long comb(int n, int r) {
        if (r > n || r < 0) return 0;
        if (r == 0 || r == n) return 1;
        r = Math.min(r, n - r); // 利用对称性减少计算量
        long result = 1;
        for (int i = 0; i < r; i++) {
            result = result * (n - i) / (i + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(30 × 30) = O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 操作 2 最多执行约 30 次（2^30 > 10^9）
2. 执行 m 次操作 2 后位置固定为 `2^m`，再插入 d 次下降调整到 k
3. 组合数 `C(m+1, d)` 对应选择在哪些间隔执行操作 1
