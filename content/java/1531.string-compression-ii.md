## 题目描述

删除至多 k 个字符，使剩余字符串的行程编码长度最小。返回最小编码长度。

**示例：**
```
输入：s = "aaabcccd", k = 2
输出：4
```

## 解题思路

DP：dp[i][j] = 前 i 个字符删去 j 个后的最小编码长度。对每个位置枚举最后一组保留的字符。

## Java 代码实现

```java
class Solution {
    public int getLengthOfOptimalCompression(String s, int k) {
        int n = s.length();
        // dp[i][j] = 前 i 个字符删除 j 个后的最小编码长度
        int[][] dp = new int[n + 1][k + 1];
        for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
        dp[0][0] = 0;
        
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= Math.min(i, k); j++) {
                // 删除第 i 个字符
                if (j > 0) dp[i][j] = dp[i-1][j-1];
                
                // 保留第 i 个字符，向前枚举相同字符
                int same = 0, diff = 0;
                for (int t = i; t >= 1; t--) {
                    if (s.charAt(t-1) == s.charAt(i-1)) same++;
                    else diff++;
                    if (diff > j) break;
                    dp[i][j] = Math.min(dp[i][j], 
                        dp[t-1][j-diff] + encodeLen(same));
                }
            }
        }
        return dp[n][k];
    }
    
    private int encodeLen(int count) {
        if (count == 1) return 1;
        if (count < 10) return 2;
        if (count < 100) return 3;
        return 4;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n × k)

## 关键点总结

1. **DP 定义**：前 i 个字符删 j 个的最小编码长度
2. **向前枚举**：统计与 s[i] 相同的字符数，不同的删除
3. **编码长度**：1→1, 2-9→2, 10-99→3, 100→4
4. **删除策略**：删除中间不同的字符使相同字符连续
