## 题目描述

给你已排序无重叠的区间数组 `intervals` 和整数 `size`，插入一个长度为 `size` 的新区间后，返回连通组（相邻/重叠区间的合并）的最小数量。

## 解题思路

先计算原始连通组数 `base`（相邻区间首尾相差 > 1 则新组）。用前缀和预处理每个前缀内的组数，再用滑动窗口枚举新区间能覆盖的原区间范围（窗口跨度 `end_r - start_l + 1 <= size`），取最大可节省的组数。答案 = `base - maxSave + 1`。

## Java 代码实现

```java
class Solution {
    public int minConnectedGroups(int[][] intervals, int size) {
        int n = intervals.length;
        // 原始连通组数
        int base = 1;
        for (int i = 1; i < n; i++)
            if (intervals[i][0] > intervals[i-1][1] + 1) base++;

        // 前缀组数：prefix[i] = intervals[0..i-1] 包含的连通组数
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++)
            prefix[i+1] = prefix[i] + (i == 0 || intervals[i][0] > intervals[i-1][1] + 1 ? 1 : 0);

        int maxSave = 0, l = 0;
        for (int r = 0; r < n; r++) {
            // 保持窗口跨度不超过 size
            while ((long)(intervals[r][1] - intervals[l][0] + 1) > size) l++;
            // 窗口 [l, r] 内的组数，节省 windowGroups - 1 组（合并为 1 组后再加新区间）
            int windowGroups = prefix[r+1] - prefix[l];
            maxSave = Math.max(maxSave, windowGroups - 1);
        }
        return base - maxSave + 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，滑动窗口一次遍历
- 空间复杂度：O(n)，前缀组数数组

## 关键点总结

1. 滑动窗口条件：`end_r - start_l + 1 <= size`（区间端点跨度不超过新区间长度）
2. 前缀和 O(1) 查询窗口内的连通组数
3. 答案 = 原组数 - 最大节省 + 1（新区间本身贡献 1 组）
