## 题目描述

给你一个整数数组 `nums`，每次操作可以将一个元素加 1 或减 1。返回使数组成为回文数组所需的最少操作次数。

## 解题思路

双指针贪心：对对称位置 `(left, right)` 使两者相等，代价为 `|nums[left] - nums[right]|`。各对对称位置独立处理，总代价为所有差值之和。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int left = 0, right = nums.length - 1;
        long ops = 0;
        while (left < right) {
            ops += Math.abs(nums[left] - nums[right]);
            left++;
            right--;
        }
        return (int) ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 回文数组要求 `nums[i] == nums[n-1-i]`
2. 每对对称位置独立处理，代价为差值绝对值
3. 中间元素（n 为奇数时）不需要调整
