## 题目描述

n个硬币堆只能从顶部取，取k次求最大总价值。

## 解题思路

分组背包DP：dp[j]表示取j枚的最大价值。对每堆用前缀和预计算取t枚的总价值，枚举从该堆取0到min(j,pile_size)枚。

## Java 代码实现

```java
class Solution {
    public int maxValueOfCoins(List<List<Integer>> piles, int k) {
        int[] dp = new int[k + 1];
        
        for (List<Integer> pile : piles) {
            int size = pile.size();
            // 计算前缀和
            int[] prefix = new int[size + 1];
            for (int i = 0; i < size; i++) {
                prefix[i + 1] = prefix[i] + pile.get(i);
            }
            
            // 逆序更新（用新数组避免覆盖）
            int[] newDp = new int[k + 1];
            for (int j = 0; j <= k; j++) {
                for (int t = 0; t <= Math.min(j, size); t++) {
                    newDp[j] = Math.max(newDp[j], dp[j - t] + prefix[t]);
                }
            }
            dp = newDp;
        }
        return dp[k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * 所有堆总大小)
- **空间复杂度**：O(k)

## 关键点总结

1. **分组背包**：每堆是一组，从每组选0到pile_size件
2. **前缀和**：预计算取前t枚的总价值
3. **新数组更新**：避免同一层互相影响
