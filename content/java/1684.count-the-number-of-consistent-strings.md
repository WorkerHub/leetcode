## 题目描述

字符串 `allowed`（字符各不同）和字符串数组 `words`。若某字符串的每个字符都在 `allowed` 中，称其为**一致字符串**。返回一致字符串的数目。

## 解题思路

**位运算：** 将 `allowed` 编码为 26 位掩码，对每个单词同样编码，若 `wordMask & allowedMask == wordMask`（即 word 是 allowed 的子集），则计数加一。

## Java 代码实现

```java
class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        int allowedMask = 0;
        for (char c : allowed.toCharArray()) {
            allowedMask |= (1 << (c - 'a'));
        }

        int count = 0;
        for (String word : words) {
            int wordMask = 0;
            for (char c : word.toCharArray()) {
                wordMask |= (1 << (c - 'a'));
            }
            // wordMask 是 allowedMask 的子集则一致
            if ((wordMask & allowedMask) == wordMask) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为 words 数量，m 为单词平均长度
- **空间复杂度**：O(1)

## 关键点总结

1. 子集关系：`(A & B) == A` 表示 A 的所有位都在 B 中
2. 字符到位下标：`c - 'a'`，得到 0-25 的索引
