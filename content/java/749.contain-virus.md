## 题目描述

m×n 矩阵中，1 为已感染区域，0 为未感染。每天病毒向相邻未感染区域扩散。每天选择威胁最大的区域建防火墙隔离。返回需要的防火墙总数。

## 解题思路

模拟：每轮 DFS 找所有感染区域，计算各区域的威胁（相邻未感染格数）和所需墙数，隔离威胁最大的区域，其他区域扩散。

## Java 代码实现

```java
class Solution {
    private int[][] grid;
    private int m, n;
    private int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

    public int containVirus(int[][] isInfected) {
        this.grid = isInfected;
        this.m = grid.length;
        this.n = grid[0].length;
        int totalWalls = 0;

        while (true) {
            List<Set<int[]>> regions = new ArrayList<>();
            List<Set<String>> frontiers = new ArrayList<>();
            List<Integer> perimeters = new ArrayList<>();
            boolean[][] visited = new boolean[m][n];

            // 找所有感染区域
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (grid[i][j] == 1 && !visited[i][j]) {
                        Set<int[]> region = new HashSet<>();
                        Set<String> frontier = new HashSet<>();
                        int[] perimeter = {0};
                        dfs(i, j, visited, region, frontier, perimeter);
                        regions.add(region);
                        frontiers.add(frontier);
                        perimeters.add(perimeter[0]);
                    }
                }
            }

            if (regions.isEmpty()) break;

            // 找威胁最大的区域
            int maxIdx = 0;
            for (int i = 1; i < frontiers.size(); i++) {
                if (frontiers.get(i).size() > frontiers.get(maxIdx).size()) {
                    maxIdx = i;
                }
            }

            // 隔离威胁最大的区域
            totalWalls += perimeters.get(maxIdx);
            for (int[] cell : regions.get(maxIdx)) {
                grid[cell[0]][cell[1]] = 2;
            }

            // 其他区域扩散
            for (int k = 0; k < regions.size(); k++) {
                if (k == maxIdx) continue;
                for (String key : frontiers.get(k)) {
                    String[] parts = key.split(",");
                    int r = Integer.parseInt(parts[0]);
                    int c = Integer.parseInt(parts[1]);
                    grid[r][c] = 1;
                }
            }
        }
        return totalWalls;
    }

    private void dfs(int i, int j, boolean[][] visited, Set<int[]> region, Set<String> frontier, int[] perimeter) {
        if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j]) return;
        if (grid[i][j] == 0) {
            frontier.add(i + "," + j);
            perimeter[0]++;
            return;
        }
        if (grid[i][j] != 1) return;

        visited[i][j] = true;
        region.add(new int[]{i, j});
        for (int[] d : dirs) {
            dfs(i + d[0], j + d[1], visited, region, frontier, perimeter);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O((m×n)²)
- **空间复杂度**：O(m×n)

## 关键点总结

1. **DFS 分区**：识别所有独立的感染区域
2. **威胁评估**：frontier 大小代表威胁程度
3. **墙数计算**：perimeter 为所需防火墙数（含重复边）
4. **模拟扩散**：未隔离区域感染相邻格
