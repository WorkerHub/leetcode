## 题目描述

从nums1移除2个元素后加x使其与nums2相同，求最小的x。

## 解题思路

排序后，nums2[0]对应nums1排序后前3个之一（最多移除2个更小元素）。枚举3种候选x，双指针验证。

## Java 代码实现

```java
class Solution {
    public int minimumAddedInteger(int[] nums1, int[] nums2) {
        Arrays.sort(nums1);
        Arrays.sort(nums2);
        // nums2[0]对应nums1[0],nums1[1],nums1[2]之一
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < 3; i++) {
            int x = nums2[0] - nums1[i];
            if (check(nums1, nums2, x)) {
                ans = Math.min(ans, x);
            }
        }
        return ans;
    }

    private boolean check(int[] nums1, int[] nums2, int x) {
        int j = 0, removed = 0;
        for (int i = 0; i < nums1.length && j < nums2.length; i++) {
            if (nums1[i] + x == nums2[j]) {
                j++;
            } else {
                removed++;
                if (removed > 2) return false;
            }
        }
        return j == nums2.length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后枚举3种候选x**
2. **双指针验证**：不匹配时计入removed
3. **取最小满足条件的x**
