## 题目描述

正整数 `n` 写在板上，每天对板上每个数字 x 将其所有 <= n 的因数也写上，经过 10^9 天后板上有多少不同的数字？

## 解题思路

数学规律：n=1 时答案为 1；n>1 时经过足够多天，板上最终为 `{2, 3, ..., n}`，答案为 `n-1`。

## Java 代码实现

```java
class Solution {
    public int distinctIntegers(int n) {
        // n == 1 时只有 {1}；n > 1 时最终为 {2, 3, ..., n}，共 n-1 个
        return Math.max(1, n - 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 经过足够多天集合趋于稳定，不需要真正模拟 10^9 天
2. n > 1 时最终集合为 {2, ..., n}，大小为 n-1
3. n == 1 时特判返回 1（防止 n-1=0）
