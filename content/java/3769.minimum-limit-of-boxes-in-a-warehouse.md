## 题目描述

给定整数数组 `boxes`（每个盒子的重量）和整数数组 `warehouse`（每个仓库格子的承重上限），只能从左向右放入，每格最多一个盒子，求将所有盒子放完后最少需要多少格子。

## 解题思路

计算每格有效承重（从左到该格的前缀最小值），贪心匹配：将最重的盒子放入承重最大的格子，统计用了多少格。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumBoxes(int[] boxes, int[] warehouse) {
        int n = warehouse.length;
        // 计算每格有效承重（前缀最小值）
        int[] effective = new int[n];
        effective[0] = warehouse[0];
        for (int i = 1; i < n; i++) {
            effective[i] = Math.min(effective[i - 1], warehouse[i]);
        }

        Arrays.sort(boxes);
        Arrays.sort(effective);

        // 贪心：最大有效承重匹配最重盒子
        int j = boxes.length - 1;
        int count = 0;
        for (int i = n - 1; i >= 0 && j >= 0; i--) {
            if (effective[i] >= boxes[j]) {
                j--;
                count++;
            }
        }

        return j < 0 ? count : -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 每格有效承重 = 从左到该格的前缀最小值（盒子需穿越所有左侧格子）
2. 贪心：最重盒子放入承重最大格子
3. 有效承重排序后从大到小逐一匹配
