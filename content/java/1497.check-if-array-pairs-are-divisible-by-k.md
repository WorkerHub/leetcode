## 题目描述

给你一个整数数组 `arr` 和一个整数 `k`，其中 `arr` 的长度是**偶数**。

请你判断能否将数组中的所有元素配对，且**每对元素的和**都能被 `k` 整除。

若可以，请返回 `True`；否则，返回 `False`。

**示例 1：**

```
输入：arr = [1,2,3,4,5,10,6,7,8,9], k = 5
输出：true
解释：配对 (1,9),(2,8),(3,7),(4,6),(5,10)，每对和分别是 10,10,10,10,15，均可被 5 整除。
```

**示例 2：**

```
输入：arr = [1,2,3,4,5,6], k = 7
输出：true
解释：配对 (1,6),(2,5),(3,4)，和为 7,7,7，均可被 7 整除。
```

**示例 3：**

```
输入：arr = [1,2,3,4,5,6], k = 10
输出：false
解释：没有任何一种配对方式使所有对的和能被 10 整除。
```

**提示：**

- `arr.length == 2 * n`，`1 <= n <= 10^5`
- `1 <= k <= 10^5`
- `-10^9 <= arr[i] <= 10^9`

## 解题思路

**核心思想：余数互补配对**

若两个数 `a + b` 能被 `k` 整除，则 `(a % k + b % k) % k == 0`。

设 `r = a % k`（取非负余数），则 `b` 的余数必须为 `(k - r) % k`（注意 `r=0` 时，互补余数也是 0）。

**算法：**

1. 统计每个余数的出现次数（注意处理负数取模）。
2. 检查：
   - 余数为 0 的数必须是偶数个（自己和自己配对）。
   - 对于余数 `r`（1 <= r < k/2），余数 `r` 的数量必须等于余数 `k-r` 的数量。
   - 若 k 为偶数，余数为 `k/2` 的数也必须是偶数个（自己和自己配对）。

**负数取模的处理：**

Java 中，`-1 % 5 == -1`（符号与被除数相同），需要加 k 再取模：`((num % k) + k) % k` 确保结果非负。

## Java 代码实现

### 方法一：余数统计 + 互补验证（推荐）

```java
class Solution {
    public boolean canArrange(int[] arr, int k) {
        // 统计每个余数的频率
        // Java 的 % 对负数返回负余数，需要加 k 再取模
        int[] remainderCount = new int[k];
        for (int num : arr) {
            int r = ((num % k) + k) % k;  // 保证非负余数
            remainderCount[r]++;
        }

        // 检查余数为 0 的数量是否为偶数（必须两两配对）
        if (remainderCount[0] % 2 != 0) return false;

        // 检查余数 r 和余数 k-r 的数量是否相等
        for (int r = 1; r < k; r++) {
            if (remainderCount[r] != remainderCount[k - r]) {
                return false;
            }
        }

        // 注意：上面循环已经检查了所有对，包括 r 和 k-r 两次比较，是等价的
        // 但若 k 为偶数，余数 k/2 需要额外验证数量为偶数
        if (k % 2 == 0 && remainderCount[k / 2] % 2 != 0) {
            return false;
        }

        return true;
    }
}
```

### 方法二：更简洁的循环（分情况讨论）

```java
class Solution {
    public boolean canArrange(int[] arr, int k) {
        // 统计余数频率
        int[] count = new int[k];
        for (int num : arr) {
            count[((num % k) + k) % k]++;
        }

        for (int r = 0; r < k; r++) {
            if (r == 0) {
                // 余数为 0 的数量必须为偶数
                if (count[0] % 2 != 0) return false;
            } else if (r * 2 == k) {
                // k 为偶数，余数恰好为 k/2 的数量必须为偶数
                if (count[r] % 2 != 0) return false;
            } else if (r < k - r) {
                // 互补余数数量必须相等，只遍历 r < k-r 的部分，避免重复
                if (count[r] != count[k - r]) return false;
            }
        }

        return true;
    }
}
```

### 方法三：排序 + 双指针

```java
import java.util.Arrays;

class Solution {
    public boolean canArrange(int[] arr, int k) {
        // 按余数排序
        int n = arr.length;
        int[] sorted = Arrays.copyOf(arr, n);
        // 用非负余数进行排序
        Integer[] boxed = new Integer[n];
        for (int i = 0; i < n; i++) boxed[i] = arr[i];
        Arrays.sort(boxed, (a, b) -> ((a % k) + k) % k - ((b % k) + k) % k);

        // 双指针：左右指针向中间靠拢
        int left = 0, right = n - 1;
        while (left < right) {
            int sumRem = (((boxed[left] % k) + k) % k + ((boxed[right] % k) + k) % k) % k;
            if (sumRem != 0) return false;
            left++;
            right--;
        }

        return true;
    }
}
```

### 方法四：哈希表 + 原地消除

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean canArrange(int[] arr, int k) {
        Map<Integer, Integer> freq = new HashMap<>();

        // 统计每个余数的需求
        for (int num : arr) {
            int r = ((num % k) + k) % k;
            // 检查是否存在配对
            int complement = (k - r) % k;
            if (freq.getOrDefault(complement, 0) > 0) {
                // 找到配对，消除
                freq.put(complement, freq.get(complement) - 1);
            } else {
                // 记录当前余数等待配对
                freq.put(r, freq.getOrDefault(r, 0) + 1);
            }
        }

        // 若所有余数都被消除，返回 true
        for (int v : freq.values()) {
            if (v != 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（推荐） | O(n + k) | O(k) |
| 方法二 | O(n + k) | O(k) |
| 方法三（排序） | O(n log n) | O(n) |
| 方法四（哈希） | O(n) | O(k) |

- 方法一/二/四 均为 O(n)，推荐
- 方法三排序略慢，但思路清晰

## 关键点总结

1. **余数互补**：`a + b` 能被 `k` 整除，当且仅当 `(a%k + b%k) % k == 0`，即余数互补。
2. **特殊情况**：
   - 余数 0：只能与余数 0 配对，数量必须为偶数。
   - 余数 k/2（k 为偶数）：只能与余数 k/2 配对，数量必须为偶数。
3. **Java 负数取模**：`(-1) % 5 == -1`，Java 中需要 `((num % k) + k) % k` 保证非负余数。
4. **只检查 r < k-r 的部分**：避免重复验证（r 和 k-r 是同一对，只需检查一次）。

## 图解示例

以 `arr=[1,2,3,4,5,10,6,7,8,9], k=5` 为例：

```
余数统计：
0 → [5, 10]  → 2个，偶数 ✓
1 → [1, 6]   → 2个，与余数4(2个)匹配 ✓
2 → [2, 7]   → 2个，与余数3(2个)匹配 ✓
3 → [3, 8]   → 2个，与余数2(2个)匹配 ✓
4 → [4, 9]   → 2个，与余数1(2个)匹配 ✓
结果：True
```

## 易错点

- **负数余数**：Java 中 `-7 % 5 == -2`，需要加 k 再取模：`((-7 % k) + k) % k = 3`。
- **k 为偶数时的 k/2 特判**：方法一循环遍历了所有 r，但 `r == k-r` 时比较自身永远相等，需要额外判断数量是否为偶数。
- **k=1 的情况**：所有数余数都是 0，数量为偶数（题目保证数组长度为偶数），可以配对。
