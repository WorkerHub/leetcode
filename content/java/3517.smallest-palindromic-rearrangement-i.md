## 题目描述

给定回文字符串 `s`，重排其字符使其仍为回文且字典序最小，返回结果。

## 解题思路

统计字符频次，前半部分按字典序（a 到 z）各取 `cnt/2` 个组成前缀，至多一个奇数频次字符放中间，后半是前半的逆序。

## Java 代码实现

```java
class Solution {
    public String smallestPalindrome(String s) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        StringBuilder half = new StringBuilder();
        char mid = 0;
        for (int i = 0; i < 26; i++) {
            // 每对放一个到前半
            for (int j = 0; j < cnt[i] / 2; j++) half.append((char)('a' + i));
            if (cnt[i] % 2 == 1) mid = (char)('a' + i);
        }

        StringBuilder res = new StringBuilder(half);
        if (mid != 0) res.append(mid);
        res.append(half.reverse());
        return res.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 前半按字典序排列，保证整体字典序最小
2. 至多一个奇数频次字符放中间
3. 后半是前半的镜像
