## 题目描述

给你字符串数组 `words`，依次将相邻字符串拼接（若末尾与下一个开头字符相同则重叠一位），返回最终字符串的最小可能长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimizeConcatenatedLength(String[] words) {
        // dp[(first, last)] = 以 first 开头、last 结尾的最短拼接长度
        // 用 first*26+last 作为 key
        Map<Integer, Integer> dp = new HashMap<>();
        String w0 = words[0];
        dp.put((w0.charAt(0) - 'a') * 26 + (w0.charAt(w0.length() - 1) - 'a'), w0.length());

        for (int i = 1; i < words.length; i++) {
            String w = words[i];
            char wf = w.charAt(0), wl = w.charAt(w.length() - 1);
            int wlen = w.length();
            Map<Integer, Integer> newDp = new HashMap<>();

            for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                int key = entry.getKey(), length = entry.getValue();
                char f = (char) ('a' + key / 26), l = (char) ('a' + key % 26);
                // 拼接 w，若末尾等于 w 开头则重叠一位
                int overlap = (l == wf) ? 1 : 0;
                int newLen = length + wlen - overlap;
                int newKey = (f - 'a') * 26 + (wl - 'a');
                newDp.merge(newKey, newLen, Math::min);
            }
            dp = newDp;
        }
        return Collections.min(dp.values());
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26^2)，每步最多 676 个状态
- 空间复杂度：O(26^2)

## 关键点总结

1. 状态仅需记录（开头字符，末尾字符），不需要保存完整字符串
2. 拼接时若末尾 == 下个单词开头，长度减 1
