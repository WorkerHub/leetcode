## 题目描述

无向树中 Alice 从根节点 0 出发到某叶子，Bob 从节点 `bob` 出发到根节点 0，同时到达某节点时收益各半，先到则独享。返回 Alice 能获得的最大净收益。

## 解题思路

两次 DFS：第一次从 `bob` 出发找到到根节点的路径，记录 Bob 每个节点的到达时间；第二次从根节点 DFS 模拟 Alice 的所有路径，根据 Alice/Bob 到达时间关系计算收益，在叶子处更新最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<List<Integer>> adj;
    private int[] amount;
    private int[] bobTime;
    private int ans = Integer.MIN_VALUE;

    public int mostProfitablePath(int[][] edges, int bob, int[] amount) {
        int n = amount.length;
        this.amount = amount;
        this.bobTime = new int[n];
        Arrays.fill(bobTime, Integer.MAX_VALUE);

        adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        // 第一步：找 Bob 到根节点的路径，记录到达时间
        findBobPath(bob, -1, 0);
        // 第二步：DFS 计算 Alice 的最大收益
        aliceDfs(0, -1, 0, 0);
        return ans;
    }

    private boolean findBobPath(int node, int parent, int time) {
        if (node == 0) { bobTime[node] = time; return true; }
        for (int nb : adj.get(node)) {
            if (nb != parent && findBobPath(nb, node, time + 1)) {
                bobTime[node] = time;
                return true;
            }
        }
        return false;
    }

    private void aliceDfs(int node, int parent, int aliceTime, int profit) {
        // 根据 Alice 和 Bob 到达时间计算收益
        if (aliceTime < bobTime[node])       profit += amount[node];
        else if (aliceTime == bobTime[node]) profit += amount[node] / 2;

        boolean isLeaf = true;
        for (int nb : adj.get(node)) {
            if (nb != parent) {
                isLeaf = false;
                aliceDfs(nb, node, aliceTime + 1, profit);
            }
        }
        if (isLeaf) ans = Math.max(ans, profit);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 先确定 Bob 到达每个路径节点的时间，再模拟 Alice 的 DFS
2. 同时到达时收益各半（整数除法）
3. 叶子节点判断：除父节点外没有其他邻居
