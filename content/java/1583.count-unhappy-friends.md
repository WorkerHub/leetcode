## 题目描述

n 人配对，若存在 x 更偏好 y 且 y 也更偏好 x（两人都比当前配对更偏好对方），则 x 不开心。返回不开心人数。

## 解题思路

预处理排名矩阵，对每人遍历其偏好中比配对对象更高的人，检查对方是否也更偏好自己。

## Java 代码实现

```java
class Solution {
    public int unhappyFriends(int n, int[][] preferences, int[][] pairs) {
        // 预处理排名：rank[x][y] = y 在 x 的偏好列表中的排名
        int[][] rank = new int[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n - 1; j++)
                rank[i][preferences[i][j]] = j;
        
        // 建立配对关系
        int[] partner = new int[n];
        for (int[] p : pairs) {
            partner[p[0]] = p[1];
            partner[p[1]] = p[0];
        }
        
        int ans = 0;
        for (int x = 0; x < n; x++) {
            int v = partner[x];
            boolean unhappy = false;
            for (int y : preferences[x]) {
                if (y == v) break; // 后面的排名都不如 v
                int u = partner[y];
                if (rank[y][x] < rank[y][u]) {
                    unhappy = true;
                    break;
                }
            }
            if (unhappy) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **排名矩阵**：O(1) 比较偏好关系
2. **提前终止**：找到一个满足条件的 y 即确定 x 不开心
3. **只需遍历到配对对象**：之后的人排名更低
