## 题目描述

数字可以被视为其因子的乘积。例如：

```
8 = 2 × 2 × 2
  = 2 × 4
```

编写一个函数，返回整数 n 的所有可能的因子组合。

**注意：**
1. 每个组合的因子必须按升序排列
2. 答案中不应包含单独的 n
3. 你可以以任何顺序返回答案

**示例 1：**

```
输入：n = 1
输出：[]
```

**示例 2：**

```
输入：n = 12
输出：[[2,6],[3,4],[2,2,3]]
解释：
12 = 2 × 6
   = 3 × 4
   = 2 × 2 × 3
```

**示例 3：**

```
输入：n = 37
输出：[]
解释：37 是质数
```

**提示：**
- `1 <= n <= 10^7`

## 解题思路

这是一道经典的回溯问题，需要找出所有因子的组合。

核心思想：
1. 从最小因子 2 开始尝试
2. 如果 i 是 n 的因子，有两个选择：
   - 选择 i，继续对 n/i 进行分解
   - 不选择 i，尝试下一个更大的因子
3. 递归终止条件：n 变为 1 或找不到因子

关键点：
- 避免重复：通过传递起始因子确保因子升序
- 剪枝：只需要搜索到 sqrt(n)，因为更大的因子会在递归中自然出现
- 边界：不包含 n 本身作为单独的因子组合

## Java 代码实现

### 方法一：回溯（推荐）⭐

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> getFactors(int n) {
        List<List<Integer>> result = new ArrayList<>();
        backtrack(result, new ArrayList<>(), n, 2);
        return result;
    }

    /**
     * 回溯法找出所有因子组合
     * @param result  结果集合
     * @param path    当前因子路径
     * @param num     当前需要分解的数
     * @param start   起始因子，确保因子升序
     */
    private void backtrack(List<List<Integer>> result, List<Integer> path, int num, int start) {
        // 如果 path 不为空，说明已经有因子了
        // 此时 num 可以作为最后一个因子加入组合
        if (!path.isEmpty()) {
            List<Integer> combo = new ArrayList<>(path);
            combo.add(num);
            result.add(combo);
        }

        // 只搜索到 sqrt(num)，避免重复（更大的因子会作为 num/i 出现）
        for (int i = start; (long) i * i <= num; i++) {
            if (num % i == 0) {
                // 选择 i 作为因子，递归分解 num/i
                path.add(i);
                backtrack(result, path, num / i, i);
                // 回溯：撤销选择
                path.remove(path.size() - 1);
            }
        }
    }
}
```

### 方法二：回溯优化版（逻辑更清晰）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> getFactors(int n) {
        if (n <= 1) return new ArrayList<>();
        List<List<Integer>> result = new ArrayList<>();
        backtrack(result, new ArrayList<>(), n, 2);
        return result;
    }

    private void backtrack(List<List<Integer>> result, List<Integer> path, int num, int start) {
        // 尝试所有可能的因子（只到 sqrt(num)）
        for (int i = start; (long) i * i <= num; i++) {
            if (num % i == 0) {
                // 选择 i 作为因子
                path.add(i);
                // 递归分解 num/i，从 i 开始确保升序
                backtrack(result, path, num / i, i);
                path.remove(path.size() - 1);
            }
        }

        // 将 num 本身作为最后一个因子
        // 只有当 path 不为空时才添加（确保不是只有 n 本身）
        if (!path.isEmpty()) {
            List<Integer> combo = new ArrayList<>(path);
            combo.add(num);
            result.add(combo);
        }
    }
}
```

### 方法三：记忆化递归

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    private Map<Long, List<List<Integer>>> memo = new HashMap<>();

    public List<List<Integer>> getFactors(int n) {
        return helper(n, 2);
    }

    private List<List<Integer>> helper(int num, int start) {
        // 检查缓存（用 (num, start) 作为键）
        long key = (long) num * 10001 + start;
        if (memo.containsKey(key)) return memo.get(key);

        List<List<Integer>> result = new ArrayList<>();

        // 尝试所有因子
        for (int i = start; (long) i * i <= num; i++) {
            if (num % i == 0) {
                int quotient = num / i;
                // 直接添加 [i, quotient] 这个组合
                List<Integer> pair = new ArrayList<>();
                pair.add(i);
                pair.add(quotient);
                result.add(pair);

                // 递归分解 quotient，并在前面加上 i
                for (List<Integer> sub : helper(quotient, i)) {
                    List<Integer> combo = new ArrayList<>();
                    combo.add(i);
                    combo.addAll(sub);
                    result.add(combo);
                }
            }
        }

        memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

**方法一（回溯）：**
- 时间复杂度：O(2^log n)，最坏情况下有指数级的组合
- 空间复杂度：O(log n)，递归栈的深度

**方法三（记忆化）：**
- 时间复杂度：带记忆化后避免重复计算，实际更快
- 空间复杂度：O(n log n)，存储中间结果

## 图解示例

以 `n = 12` 为例：

```
搜索树：
start=2, num=12
├─ i=2: 12%2==0 → 分解 6
│  └─ start=2, num=6
│     ├─ i=2: 6%2==0 → 分解 3
│     │  └─ start=2, num=3 → [2,2,3] ✓
│     └─ 超过sqrt(6) → [2,6] ✓
│
└─ i=3: 12%3==0 → 分解 4
   └─ start=3, num=4
      └─ 没有>=3的因子(3*3>4) → [3,4] ✓

结果：[[2,6], [2,2,3], [3,4]]
```

## 关键点总结

1. **回溯模板**：选择因子 → 递归分解 → 撤销选择
2. **剪枝优化**：只搜索到 sqrt(n)，避免重复
3. **升序保证**：通过 start 参数确保因子升序排列
4. **终止条件**：num 为 1 或找不到因子时终止
5. **边界处理**：排除 n 本身作为单独的因子组合

## 易错点

1. **忘记排除 n 本身**
   ```java
   // 错误：会包含 [12] 这样的结果
   combo.add(num);
   result.add(combo);

   // 正确：只有当 path 不为空时才添加
   if (!path.isEmpty()) {
       combo.add(num);
       result.add(combo);
   }
   ```

2. **搜索范围错误**
   ```java
   // 低效：搜索到 num-1
   for (int i = start; i < num; i++)

   // 高效：只搜索到 sqrt(num)
   for (int i = start; (long) i * i <= num; i++)
   ```

3. **整数溢出**：当 n 很大时，`i * i` 可能溢出，需要用 `(long) i * i`

4. **重复组合**
   ```java
   // 错误：可能产生 [2,3] 和 [3,2] 这样的重复
   backtrack(result, path, num / i, 2);

   // 正确：从 i 开始，确保升序
   backtrack(result, path, num / i, i);
   ```
