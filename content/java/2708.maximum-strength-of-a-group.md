## 题目描述

给你整数数组 `nums`，选取一个或多个元素组成一组，组的强度为所有元素的乘积，返回最大强度。

## Java 代码实现

```java
class Solution {
    public long maxStrength(int[] nums) {
        // DP：同时维护当前子集的最大和最小乘积
        long dpMax = nums[0], dpMin = nums[0];
        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long newMax = Math.max(Math.max(dpMax * x, dpMin * x), x);
            long newMin = Math.min(Math.min(dpMax * x, dpMin * x), x);
            dpMax = newMax;
            dpMin = newMin;
        }
        return dpMax;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 同时维护最大乘积和最小乘积（负数乘以最小可能变最大）
2. 每步从三种候选中取最大/最小：`dpMax*x, dpMin*x, x`（单独选当前元素）
