## 题目描述

车有 capacity 个座位，给定行程 trips[i] = [numPassengers, from, to]，判断能否完成所有行程。

**示例：**
```
输入：trips = [[2,1,5],[3,3,7]], capacity = 4
输出：false
```

## 解题思路

差分数组：在 from 位置 +passengers，在 to 位置 -passengers，前缀和表示每个位置的实际乘客数，检查是否超过 capacity。

## Java 代码实现

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        // 差分数组（位置范围 0~1000）
        int[] diff = new int[1001];

        for (int[] trip : trips) {
            diff[trip[1]] += trip[0];  // 上车
            diff[trip[2]] -= trip[0];  // 下车
        }

        // 前缀和检查容量
        int current = 0;
        for (int d : diff) {
            current += d;
            if (current > capacity) return false;
        }

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 1001)，n 为行程数
- **空间复杂度**：O(1001) = O(1)

## 关键点总结

1. **差分数组**：区间更新的经典技巧
2. **上车/下车**：from 位置加，to 位置减
3. **前缀和**：差分数组的前缀和 = 每个位置的实际值
