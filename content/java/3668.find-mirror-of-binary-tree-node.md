## 题目描述

给你一棵二叉树的根节点 `root` 和树中的一个节点 `u`，返回 `u` 的镜像节点（镜像翻转整棵树后，`u` 所在位置的节点）。

## 解题思路

递归同步遍历：同时在原树和镜像树中搜索。原树走左子树时，镜像树走右子树（反之亦然）。若原树当前节点就是 `u`，则返回镜像树的当前节点。

## Java 代码实现

```java
class Solution {
    private TreeNode target;

    public TreeNode mirrorNode(TreeNode root, TreeNode u) {
        target = u;
        return find(root, root);
    }

    private TreeNode find(TreeNode original, TreeNode mirror) {
        if (original == null) return null;
        // 找到目标节点，返回镜像树对应节点
        if (original == target) return mirror;
        TreeNode left = find(original.left, mirror.right);
        if (left != null) return left;
        return find(original.right, mirror.left);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树高

## 关键点总结

1. 镜像操作：每次走左时镜像走右，走右时镜像走左
2. 同步遍历原树和镜像树
3. 根节点的镜像是根节点本身
