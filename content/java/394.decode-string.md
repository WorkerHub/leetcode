## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

**示例 1:**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2:**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3:**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4:**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

**提示:**

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]`

## 解题思路

本题是经典的**栈应用**问题，也可以用递归解决。

### 核心思想

**使用栈处理嵌套结构：**

1. 遇到数字：累积数字（可能是多位数）
2. 遇到 `[`：将当前的数字和字符串压栈，重置状态
3. 遇到 `]`：弹栈，将当前字符串重复 k 次，拼接到栈顶字符串
4. 遇到字母：累积到当前字符串

**栈中存储的内容：**
- 数字：表示重复次数
- 字符串：表示当前层级的字符串

### 思路对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 栈 | 直观，易理解 | 需要两个栈 |
| 递归 | 代码简洁 | 理解稍难 |

## Java 代码实现

### 方法一：双栈（推荐）⭐

```java
import java.util.*;

class Solution {
    public String decodeString(String s) {
        // 使用两个栈：一个存数字，一个存字符串
        // 时间复杂度: O(n)
        // 空间复杂度: O(n)
        Deque<Integer> stackNum = new ArrayDeque<>();  // 存储重复次数
        Deque<String> stackStr = new ArrayDeque<>();   // 存储字符串
        int num = 0;                                   // 当前数字
        StringBuilder result = new StringBuilder();    // 当前字符串

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 累积数字（可能是多位数）
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 将当前状态压栈
                stackNum.push(num);
                stackStr.push(result.toString());
                // 重置状态
                num = 0;
                result = new StringBuilder();
            } else if (c == ']') {
                // 弹出栈顶
                int repeatTimes = stackNum.pop();
                String prevStr = stackStr.pop();
                // 重复当前字符串并拼接
                StringBuilder sb = new StringBuilder(prevStr);
                for (int i = 0; i < repeatTimes; i++) {
                    sb.append(result);
                }
                result = sb;
            } else {
                // 累积字母
                result.append(c);
            }
        }

        return result.toString();
    }
}
```

### 方法二：单栈（优化）

```java
import java.util.*;

class Solution {
    public String decodeString(String s) {
        // 使用单个栈存储 [重复次数, 当前字符串] 对
        Deque<Object[]> stack = new ArrayDeque<>();
        int num = 0;
        StringBuilder result = new StringBuilder();

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 压栈
                stack.push(new Object[]{num, result.toString()});
                num = 0;
                result = new StringBuilder();
            } else if (c == ']') {
                // 弹栈并处理
                Object[] top = stack.pop();
                int repeatTimes = (int) top[0];
                String prevStr = (String) top[1];
                StringBuilder sb = new StringBuilder(prevStr);
                for (int i = 0; i < repeatTimes; i++) {
                    sb.append(result);
                }
                result = sb;
            } else {
                result.append(c);
            }
        }

        return result.toString();
    }
}
```

### 方法三：递归

```java
class Solution {
    private int index = 0;

    public String decodeString(String s) {
        // 递归解码
        // 时间复杂度: O(n)
        // 空间复杂度: O(n)
        index = 0;
        return decode(s);
    }

    private String decode(String s) {
        StringBuilder result = new StringBuilder();
        int num = 0;

        while (index < s.length()) {
            char c = s.charAt(index);

            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
                index++;
            } else if (c == '[') {
                index++;  // 跳过 '['
                // 递归解码括号内的内容
                String subStr = decode(s);
                for (int i = 0; i < num; i++) {
                    result.append(subStr);
                }
                num = 0;
            } else if (c == ']') {
                index++;  // 跳过 ']'
                return result.toString();
            } else {
                result.append(c);
                index++;
            }
        }

        return result.toString();
    }
}
```

### 方法四：正则表达式（仅供学习）

```java
import java.util.regex.*;

class Solution {
    public String decodeString(String s) {
        // 使用正则表达式递归替换（不推荐，仅供学习）
        // 匹配 数字[字母]
        Pattern pattern = Pattern.compile("(\\d+)\\[([a-z]+)\\]");
        Matcher matcher = pattern.matcher(s);
        while (matcher.find()) {
            int times = Integer.parseInt(matcher.group(1));
            String repeat = matcher.group(2).repeat(times);
            s = s.substring(0, matcher.start()) + repeat + s.substring(matcher.end());
            matcher = pattern.matcher(s);
        }
        return s;
    }
}
```

### 方法五：使用队列的迭代实现

```java
import java.util.*;

class Solution {
    public String decodeString(String s) {
        // 使用队列模拟迭代器
        Deque<Character> queue = new ArrayDeque<>();
        for (char c : s.toCharArray()) queue.offer(c);
        return decode(queue);
    }

    private String decode(Deque<Character> queue) {
        StringBuilder result = new StringBuilder();
        int num = 0;

        while (!queue.isEmpty()) {
            char c = queue.poll();
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 递归解码
                String sub = decode(queue);
                result.append(sub.repeat(num));
                num = 0;
            } else if (c == ']') {
                return result.toString();
            } else {
                result.append(c);
            }
        }

        return result.toString();
    }
}
```

## 复杂度分析

**时间复杂度：** O(n * k)
- n 是字符串长度
- k 是最大重复次数
- 最坏情况下每个字符可能被重复 k 次

**空间复杂度：** O(n)
- 栈的深度取决于嵌套层数
- 最坏情况下所有字符都在栈中

## 关键点总结

1. **栈的应用**：处理嵌套结构的标准方法
2. **多位数处理**：数字可能是多位的，需要累积
3. **状态管理**：需要保存当前的数字和字符串
4. **StringBuilder**：Java 中大量字符串拼接应使用 StringBuilder
5. **递归思维**：嵌套结构天然适合递归

## 易错点

1. **多位数字**：`10[a]` 不是 `1` 和 `0[a]`
2. **嵌套处理**：`3[a2[c]]` 需要正确处理内层
3. **字母在数字前**：`abc3[cd]` 中 `abc` 不重复
4. **栈的内容**：要保存之前的字符串，不是只保存括号内的
5. **返回时机**：遇到 `]` 时返回当前结果

## 图解示例

```

处理过程:

字符 '3': num=3
字符 '[': 压栈 (3, ""), num=0, result=""
字符 'a': result="a"
字符 '2': num=2
字符 '[': 压栈 (2, "a"), num=0, result=""
字符 'c': result="c"
字符 ']': 弹栈 (2, "a"), result="a" + "c"*2 = "acc"
字符 ']': 弹栈 (3, ""), result="" + "acc"*3 = "accaccacc"

栈的变化:
[] → [(3,"")] → [(3,""), (2,"a")] → [(3,"")] → []

结果: "accaccacc"
```
