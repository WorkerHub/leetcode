## 题目描述

设计数据结构 MajorityChecker，查询子数组 [left, right] 中出现次数 >= threshold 的元素，不存在返回 -1。

**示例：**
```
arr = [1,1,2,2,1,1]
query(0,5,4) → 1（1出现4次）
query(0,3,3) → -1
query(2,3,2) → 2
```

## 解题思路

随机化 + 二分查找：预处理每个元素的位置列表。查询时随机采样子数组中的元素作为候选，用二分查找验证其在区间内的出现次数。

## Java 代码实现

```java
class MajorityChecker {
    private int[] arr;
    private Map<Integer, List<Integer>> positions;
    private Random rand;

    public MajorityChecker(int[] arr) {
        this.arr = arr;
        this.positions = new HashMap<>();
        this.rand = new Random();
        // 预处理每个元素的位置列表
        for (int i = 0; i < arr.length; i++) {
            positions.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }
    }

    public int query(int left, int right, int threshold) {
        // 随机采样 20 次
        for (int t = 0; t < 20; t++) {
            int idx = left + rand.nextInt(right - left + 1);
            int candidate = arr[idx];
            List<Integer> pos = positions.get(candidate);
            // 二分查找区间内出现次数
            int lo = Collections.binarySearch(pos, left);
            if (lo < 0) lo = -lo - 1;
            int hi = Collections.binarySearch(pos, right);
            if (hi < 0) hi = -hi - 2;
            else hi = hi; // right 本身在列表中
            int count = hi - lo + 1;
            if (count >= threshold) return candidate;
        }
        return -1;
    }
}
```

## 复杂度分析

- **初始化**：O(n)
- **单次查询**：O(k * log n)，k = 采样次数（20）
- **空间复杂度**：O(n)

## 关键点总结

1. **随机化正确性**：如果多数元素存在，每次采样命中概率 >= threshold/(right-left+1)
2. **二分查找验证**：O(log n) 计算区间出现次数
3. **预处理位置列表**：每个值的索引有序存储
4. **采样次数**：20 次几乎确保正确
