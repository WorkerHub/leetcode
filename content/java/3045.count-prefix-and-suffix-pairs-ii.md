## 题目描述

同3042但数据范围大（n<=10^5，总字符数<=5*10^5），需要高效算法统计前后缀对。

## 解题思路

将每个字符串转为字符对序列(s[i], s[n-1-i])，用Trie统计前缀匹配数：遍历时先查询已有匹配数再插入。

## Java 代码实现

```java
class Solution {
    public long countPrefixSuffixPairs(String[] words) {
        Map<Long, long[]> trie = new HashMap<>(); // 节点ID -> {count, nextId}
        long nextId = 1;
        long ans = 0;

        // 简化：用HashMap模拟Trie
        // 每个节点用map存children，key为字符对编码
        Map<Long, Map<Integer, Long>> children = new HashMap<>();
        Map<Long, Integer> count = new HashMap<>();
        children.put(0L, new HashMap<>());
        count.put(0L, 0);

        for (String word : words) {
            int n = word.length();
            long node = 0;
            for (int i = 0; i < n; i++) {
                int pair = (word.charAt(i) - 'a') * 26 + (word.charAt(n - 1 - i) - 'a');
                Map<Integer, Long> ch = children.get(node);
                if (!ch.containsKey(pair)) {
                    ch.put(pair, nextId);
                    children.put(nextId, new HashMap<>());
                    count.put(nextId, 0);
                    nextId++;
                }
                node = ch.get(pair);
                ans += count.get(node);
            }
            count.merge(node, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(总字符数)
- **空间复杂度**：O(总字符数)

## 关键点总结

1. **字符对序列(s[i], s[n-1-i])**：前缀后缀条件转为序列前缀关系
2. **Trie统计**：查询已有匹配数再插入自身
3. **遍历顺序保证i<j**
