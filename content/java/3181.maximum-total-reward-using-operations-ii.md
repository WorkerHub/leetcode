## 题目描述

与 3180 相同（选奖励使总奖励最大，每次选的值必须严格大于当前总），但数据范围更大（最大 5×10^4），需要 bitset 优化。

## 解题思路

用 Java 的 `BigInteger` 或 `long[]` 数组模拟 bitset。第 v 位为 1 表示总奖励 v 可达，初始第 0 位为 1。对每个奖励 r，取 dp 中 v < r 的低 r 位，左移 r 位后并入 dp：`dp |= (dp & mask) << r`，其中 mask = (1<<r)-1。

## Java 代码实现

```java
import java.math.BigInteger;
class Solution {
    public int maxTotalReward(int[] rewardValues) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int r : rewardValues) set.add(r);
        int maxVal = set.last();

        // 用 BigInteger 模拟 bitset
        BigInteger dp = BigInteger.ONE; // 第 0 位为 1（v=0 可达）
        for (int r : set) {
            // mask = (1 << r) - 1，只保留低 r 位
            BigInteger mask = BigInteger.ONE.shiftLeft(r).subtract(BigInteger.ONE);
            dp = dp.or(dp.and(mask).shiftLeft(r));
        }
        return dp.bitLength() - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × maxVal / 64)
- **空间复杂度**：O(maxVal / 64)

## 关键点总结

1. bitset 将布尔 DP 数组压缩为位图，位操作并行处理 64 个状态
2. `(dp & mask) << r` 同时将所有 v < r 的可达状态转移到 v+r
3. 去重保证每个奖励值只使用一次
