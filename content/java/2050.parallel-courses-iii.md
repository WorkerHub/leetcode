## 题目描述

n 门课程有前置依赖关系，每门课程有完成时间 time[i]，可并行修读，但必须先完成所有前置。返回完成所有课程的最少月数。

## 解题思路

拓扑排序 + DP：`dp[i]` = 完成课程 i 的最早时间。转移：`dp[nxt] = max(dp[nxt], dp[node] + time[nxt-1])`，答案为 `max(dp)`。

## Java 代码实现

### 方法一：拓扑排序 + DP（推荐）

```java
import java.util.*;

class Solution {
    public int minimumTime(int n, int[][] relations, int[] time) {
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[n + 1];
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());

        for (int[] rel : relations) {
            graph.get(rel[0]).add(rel[1]);
            inDegree[rel[1]]++;
        }

        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) dp[i] = time[i - 1];

        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }

        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int nxt : graph.get(node)) {
                // 等所有前置完成后再修 nxt
                dp[nxt] = Math.max(dp[nxt], dp[node] + time[nxt - 1]);
                if (--inDegree[nxt] == 0) queue.offer(nxt);
            }
        }

        int ans = 0;
        for (int i = 1; i <= n; i++) ans = Math.max(ans, dp[i]);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(V + E)
- 空间复杂度：O(V + E)

## 关键点总结

1. 拓扑排序确保处理节点时所有前驱已处理
2. 多个前驱取最晚完成时间（max），而非求和（并行执行）
3. 答案为所有节点完成时间的最大值
