## 题目描述

给定座位位置数组 `seats` 和学生位置数组 `students`（各 n 个），每次可将一名学生移动一步，返回将所有学生安排到座位上的最少移动次数。

## 解题思路

贪心：将两数组分别排序后，第 i 个学生去第 i 个座位时总移动距离最小。

## Java 代码实现

### 方法一：排序后配对（推荐）

```java
import java.util.Arrays;

class Solution {
    public int minMovesToSeat(int[] seats, int[] students) {
        Arrays.sort(seats);
        Arrays.sort(students);
        int total = 0;
        for (int i = 0; i < seats.length; i++) {
            total += Math.abs(seats[i] - students[i]);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后按顺序配对满足"不交叉"原则，总移动距离最小
2. 移动距离为绝对值之和
