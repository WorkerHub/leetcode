## 题目描述

给定一个整数 `n`，返回 `n!` 结果中尾随零的数量。

提示：`n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1`

**示例 1：**
```
输入：n = 3
输出：0
解释：3! = 6，没有尾随零。
```

**示例 2：**
```
输入：n = 5
输出：1
解释：5! = 120，有 1 个尾随零。
```

**示例 3：**
```
输入：n = 0
输出：0
```

**提示：**
- 0 <= n <= 10^4

**进阶：** 你可以设计并实现对数时间复杂度的算法来解决此问题吗？

## 解题思路

**核心观察：** 尾随零是由因子 10 产生的，而 10 = 2 × 5。

**关键发现：**
1. 尾随零的数量 = min(因子 2 的个数, 因子 5 的个数)
2. 在阶乘中，**因子 2 的个数远多于因子 5**
3. 因此，**尾随零的数量 = 因子 5 的个数**

**如何计算因子 5 的个数？**

在 1 到 n 中：
- 5 的倍数贡献 1 个因子 5：5, 10, 15, 20, ...
- 25 的倍数贡献 2 个因子 5：25, 50, 75, ...（25 = 5²）
- 125 的倍数贡献 3 个因子 5：125, 250, ...（125 = 5³）

**计算公式：**
```
因子 5 的总数 = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ⌊n/625⌋ + ...
```

**算法流程：**
1. 初始化计数器 `count = 0`
2. 循环：`n /= 5`，并累加 `n`
3. 当 `n < 5` 时结束
4. 返回 `count`

**为什么不直接计算阶乘？**
- n! 会非常大，容易溢出
- 不需要实际计算，只需数因子

## Java 代码实现

### 方法一：迭代计算（推荐）

```java
class Solution {
    public int trailingZeroes(int n) {
        int count = 0;
        
        // 统计因子 5 的个数
        while (n >= 5) {
            n /= 5;
            count += n;
        }
        
        return count;
    }
}
```

### 方法二：递归实现

```java
class Solution {
    public int trailingZeroes(int n) {
        if (n < 5) {
            return 0;
        }
        
        // 当前层贡献 + 递归计算更高次幂
        return n / 5 + trailingZeroes(n / 5);
    }
}
```

### 方法三：显式累加各次幂

```java
class Solution {
    public int trailingZeroes(int n) {
        int count = 0;
        long powerOf5 = 5;
        
        // 累加 5, 25, 125, 625, ... 的贡献
        while (powerOf5 <= n) {
            count += n / powerOf5;
            powerOf5 *= 5;
        }
        
        return count;
    }
}
```

## 复杂度分析

**时间复杂度：** O(log₅n)
- 每次循环 n 缩小为原来的 1/5
- 循环次数约为 log₅n

**空间复杂度：**
- 方法一、三：O(1)
- 方法二：O(log₅n)，递归调用栈

## 图解示例

以 `n = 25` 为例：

```
25! 中因子 5 的计算：

第一轮：⌊25/5⌋ = 5
  贡献 1 个因子 5 的数：5, 10, 15, 20, 25

第二轮：⌊25/25⌋ = 1
  贡献 2 个因子 5 的数：25 (额外贡献)

总计：5 + 1 = 6 个因子 5
所以 25! 有 6 个尾随零
```

**验证：**
```
25! = 15511210043330985984000000
           6 个尾随零 ↑
```

**为什么 25 要计算两次？**
```
25 = 5 × 5，包含 2 个因子 5
第一轮：⌊25/5⌋ 包含了 25，贡献 1 个
第二轮：⌊25/25⌋ 再贡献 1 个
总共：2 个因子 5
```

## 关键点总结

1. **不要计算阶乘**：直接数学分析，避免溢出
2. **因子 5 决定**：因子 2 足够多，只需统计因子 5
3. **重复计数**：25, 125 等会被多次计算，这是正确的
4. **对数复杂度**：每次除以 5，满足进阶要求
5. **整数除法**：Java 中 `/` 对整数执行整除

## 易错点

1. **尝试计算阶乘**
   - 错误：先算 `n!`，再数尾随零
   - 问题：大数溢出，时间复杂度高

2. **只计算一次 n/5**
   - 错误：`return n / 5`
   - 问题：遗漏 25, 125 等的额外贡献

3. **循环条件错误**
   - 错误：`while (n > 0)` 配合 `n /= 5` 后累加（会将 n=0 时继续累加）
   - 正确：`while (n >= 5)`

4. **方法三中 powerOf5 溢出**
   - 注意：5^14 已超过 int 范围，需要使用 long

5. **忘记 n = 0 的情况**
   - 0! = 1，没有尾随零

## 学习建议

**新手建议：**
1. **理解因式分解**：10 = 2 × 5，尾随零来自 10 的因子
2. **手动验证**：计算 5!, 10!, 15!, 20!, 25! 验证规律
3. **从简单开始**：先理解只计算 n/5 的情况，再理解递归累加

**进阶学习：**
1. 为什么因子 2 总是够用？
   - 偶数比 5 的倍数更多
   - 每个偶数贡献至少 1 个因子 2
2. 理解 25, 125 为什么贡献多个因子 5
3. 学习第 793 题（逆问题：给定尾随零数量，求可能的 n）

**数学原理：**

| n | n/5 | n/25 | n/125 | 总和 | 验证 |
|---|-----|------|-------|------|------|
| 5 | 1 | 0 | 0 | 1 | 5! = 120 |
| 10 | 2 | 0 | 0 | 2 | 10! = 3628800 |
| 25 | 5 | 1 | 0 | 6 | 25! 有 6 个零 |
| 100 | 20 | 4 | 0 | 24 | 100! 有 24 个零 |
| 125 | 25 | 5 | 1 | 31 | 125! 有 31 个零 |

**Java 技巧：**
- Java 中 int 除法自动向下取整，与 Python 的 `//` 等价
- 当幂次可能超过 int 范围时，使用 `long` 类型
- 递归实现简洁，但迭代更高效
