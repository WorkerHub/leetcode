## 题目描述

对str1中的字符最多各加一次（循环，z->a），判断str2能否成为str1的子序列。

## 解题思路

双指针贪心：遍历str1，若当前字符等于str2[j]或加一后等于str2[j]则匹配，j前进。

## Java 代码实现

```java
class Solution {
    public boolean canMakeSubsequence(String str1, String str2) {
        int j = 0;
        int n2 = str2.length();

        for (int i = 0; i < str1.length() && j < n2; i++) {
            char c1 = str1.charAt(i);
            char c2 = str2.charAt(j);
            // c1本身匹配或循环加一后匹配
            if (c1 == c2 || (c1 - 'a' + 1) % 26 == c2 - 'a') {
                j++;
            }
        }
        return j == n2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针贪心匹配子序列**：尽早匹配
2. **匹配条件两种**：相等或加一后相等
3. **循环加一**：(c-'a'+1)%26处理z->a
