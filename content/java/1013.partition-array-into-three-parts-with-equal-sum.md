## 题目描述

给你一个整数数组 `arr`，只有可以将其划分为三个和相等的非空部分时才返回 `true`，否则返回 `false`。

形式上，如果可以找到索引 `i + 1 < j` 且满足 `(arr[0] + arr[1] + ... + arr[i] == arr[i + 1] + arr[i + 2] + ... + arr[j - 1] == arr[j] + arr[j + 1] + ... + arr[arr.length - 1])` 就可以将数组三等分。

**示例 1：**
```
输入：arr = [0,2,1,-6,6,-7,9,1,2,0,1]
输出：true
解释：0 + 2 + 1 = -6 + 6 - 7 + 9 + 1 = 2 + 0 + 1
```

**示例 2：**
```
输入：arr = [0,2,1,-6,6,7,9,-1,2,0,1]
输出：false
```

**示例 3：**
```
输入：arr = [3,3,6,5,-2,2,5,1,-9,4]
输出：true
解释：3 + 3 = 6 = 5 - 2 + 2 + 5 + 1 - 9 + 4
```

**提示：**
- `3 <= arr.length <= 5 * 10^4`
- `-10^4 <= arr[i] <= 10^4`

## 解题思路

**核心观察**：
1. 如果能三等分，每部分的和必须等于总和的1/3
2. 总和必须能被3整除
3. 贪心策略：找到第一个和为sum/3的部分，再找第二个

**算法步骤**：
1. 计算总和，如果不能被3整除，返回false
2. 贪心地从左往右找第一个和为target的部分
3. 继续找第二个和为target的部分
4. 如果找到两个，剩余部分自动满足

## Java 代码实现

### 方法一：贪心查找（推荐）

```java
class Solution {
    public boolean canThreePartsEqualSum(int[] arr) {
        int total = 0;
        for (int num : arr) total += num;

        // 总和必须能被3整除
        if (total % 3 != 0) return false;

        int target = total / 3;
        int currentSum = 0;
        int count = 0; // 找到的部分数量

        // 注意：不遍历最后一个元素，保证第三部分非空
        for (int i = 0; i < arr.length - 1; i++) {
            currentSum += arr[i];

            // 找到一个和为target的部分
            if (currentSum == target) {
                count++;
                currentSum = 0;

                // 找到两个部分即可，剩余自动是第三部分
                if (count == 2) return true;
            }
        }

        return false;
    }
}
```

### 方法二：双指针

```java
class Solution {
    public boolean canThreePartsEqualSum(int[] arr) {
        int total = 0;
        for (int num : arr) total += num;

        if (total % 3 != 0) return false;

        int target = total / 3;
        int n = arr.length;

        // 从左边找第一个部分
        int leftSum = 0;
        int left = 0;
        while (left < n - 2) {
            leftSum += arr[left];
            if (leftSum == target) break;
            left++;
        }

        // 从右边找第三个部分
        int rightSum = 0;
        int right = n - 1;
        while (right > left + 1) {
            rightSum += arr[right];
            if (rightSum == target) break;
            right--;
        }

        // 检查是否找到有效的划分
        return leftSum == target && rightSum == target && left + 1 < right;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)，只使用常数额外空间

## 图解示例

以 `arr = [0,2,1,-6,6,-7,9,1,2,0,1]` 为例：

```
总和 = 0+2+1-6+6-7+9+1+2+0+1 = 9
目标 = 9 / 3 = 3

遍历过程：
i=0: sum=0
i=1: sum=2
i=2: sum=3 → 找到第1部分！count=1, sum=0
i=3: sum=-6
i=4: sum=0
i=5: sum=-7
i=6: sum=2
i=7: sum=3 → 找到第2部分！count=2, sum=0
返回 true

划分结果：
第1部分：[0,2,1] = 3
第2部分：[-6,6,-7,9,1] = 3
第3部分：[2,0,1] = 3
```

## 关键点总结

1. **必要条件**：总和能被3整除
2. **贪心策略**：找到两个部分即可，第三部分自动满足
3. **边界保证**：循环不包括最后一个元素，保证第三部分非空
4. **特殊情况**：target为0时可能有多个有效划分
5. **提前返回**：找到两个部分立即返回true

## 易错点

1. **忘记检查总和**：必须先判断总和是否能被3整除
2. **最后一个元素**：循环范围要保证第三部分非空
3. **重置累加和**：找到一个部分后要重置currentSum
4. **target为0**：此方法天然正确处理，不需要特殊逻辑
5. **部分数量**：只需找到2个部分，不是3个
