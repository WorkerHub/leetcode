## 题目描述

长度为偶数的数组 `nums`，每次操作可将任一元素替换为 `[1, limit]` 中的整数。使所有对称对之和相同（**互补**），返回最少操作数。

## 解题思路

**差分数组：** 对每对 `(a, b)`（a <= b），分析不同目标和 T 需要的操作次数：
- `T = a+b`：0 次
- `T ∈ [a+1, b+limit] 且 T != a+b`：1 次
- 其他：2 次

用差分数组 O(1) 更新区间，最后前缀和求最小值。

## Java 代码实现

```java
class Solution {
    public int minMoves(int[] nums, int limit) {
        int n = nums.length;
        int[] diff = new int[2 * limit + 2];

        for (int i = 0; i < n / 2; i++) {
            int a = nums[i], b = nums[n - 1 - i];
            if (a > b) { int tmp = a; a = b; b = tmp; } // 确保 a <= b

            int lo = a + 1;       // 1 次操作区间左边界
            int hi = b + limit;   // 1 次操作区间右边界
            int mid = a + b;      // 0 次操作的目标和

            // 整个 [2, 2*limit] 范围需要 2 次操作
            diff[2] += 2;
            // [lo, 2*limit] 需要 1 次操作（减 1）
            diff[lo] -= 1;
            // [mid, mid] 需要 0 次操作（再减 1）
            diff[mid] -= 1;
            diff[mid + 1] += 1;
            // [hi+1, 2*limit] 恢复 2 次（加 1）
            diff[hi + 1] += 1;
        }

        int ans = Integer.MAX_VALUE, curr = 0;
        for (int t = 2; t <= 2 * limit; t++) {
            curr += diff[t];
            ans = Math.min(ans, curr);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + limit)
- **空间复杂度**：O(limit)

## 关键点总结

1. 差分数组 O(1) 时间对区间统一加/减
2. 区间分析：0次/1次/2次操作对应不同 T 范围
3. 前缀和恢复差分数组，取最小值
