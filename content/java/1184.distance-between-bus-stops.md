## 题目描述

环形公交线路有 n 个站点，`distance[i]` 表示站 i 到站 `(i+1)%n` 的距离。返回从 start 到 destination 的最短距离。

**示例：**
```
输入: distance = [1,2,3,4], start = 0, destination = 1
输出: 1
```

## 解题思路

顺时针距离 + 逆时针距离 = 总距离。计算顺时针距离后，用总距离减去即得逆时针距离，取较小值。

## Java 代码实现

```java
class Solution {
    public int distanceBetweenBusStops(int[] distance, int start, int destination) {
        // 确保 start < destination
        if (start > destination) {
            int temp = start;
            start = destination;
            destination = temp;
        }
        
        int clockwise = 0, total = 0;
        for (int i = 0; i < distance.length; i++) {
            total += distance[i];
            if (i >= start && i < destination) {
                clockwise += distance[i];
            }
        }
        
        return Math.min(clockwise, total - clockwise);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **环形路线**：两条路径距离之和等于总距离
2. **交换简化**：确保 start < destination 避免环形处理
3. **一次遍历**：同时计算总距离和顺时针距离
