## 题目描述

给定 `m × n` 整数矩阵 `grid`，从左上角 `(0,0)` 出发，移动到单元格 `(i,j)` 的代价为 `grid[i][j]`，起点不计代价。求访问矩阵中所有单元格的最小总代价。

## 解题思路

Dijkstra：以每格为节点，从 `(0,0)` 出发求到所有格子的最短路径，累加所有格子的最短路径代价即为答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minCost(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        long[][] dist = new long[m][n];
        for (long[] row : dist) Arrays.fill(row, Long.MAX_VALUE);
        dist[0][0] = 0;

        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0, 0});
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long cost = cur[0]; int i = (int) cur[1], j = (int) cur[2];
            if (cost > dist[i][j]) continue;
            for (int[] d : dirs) {
                int ni = i + d[0], nj = j + d[1];
                if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                    long nc = cost + grid[ni][nj];
                    if (nc < dist[ni][nj]) {
                        dist[ni][nj] = nc;
                        pq.offer(new long[]{nc, ni, nj});
                    }
                }
            }
        }
        long ans = 0;
        for (long[] row : dist) for (long d : row) ans += d;
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. 格子带权移动的经典解法是 Dijkstra
2. 起点 `(0,0)` 代价为 0，移动到某格代价为该格值
3. 累加所有格子的最短路径代价
