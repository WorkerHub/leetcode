## 题目描述

找出数组中出现频次等于其数值的最大整数（幸运数），不存在返回-1。

## 解题思路

哈希表统计频率，遍历找出所有满足num==freq的数，取最大值。

## Java 代码实现

```java
class Solution {
    public int findLucky(int[] arr) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : arr) {
            count.merge(num, 1, Integer::sum);
        }
        int result = -1;
        for (Map.Entry<Integer, Integer> e : count.entrySet()) {
            if (e.getKey().equals(e.getValue())) {
                result = Math.max(result, e.getKey());
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **幸运数定义**：数值 == 出现频率
2. **HashMap统计频率**后遍历取最大
3. **不存在时返回-1**
