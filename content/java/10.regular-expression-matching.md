## 题目描述

给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配。

- `'.'` 匹配任意单个字符
- `'*'` 匹配零个或多个前面的那一个元素

所谓匹配，是要涵盖整个字符串 `s` 的，而不是部分字符串。

**示例 1：**
```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串
```

**示例 2：**
```
输入：s = "aa", p = "a*"
输出：true
解释：'*' 代表可以匹配零个或多个前面的那一个元素，即可以匹配 'a'。因此，重复 'a' 一次，字符串变为 "aa"
```

**示例 3：**
```
输入：s = "ab", p = ".*"
输出：true
解释：".*" 表示可匹配零个或多个任意字符
```

**提示：**
- `1 <= s.length <= 20`
- `1 <= p.length <= 20`
- `s` 只包含小写英文字母
- `p` 只包含小写英文字母，以及字符 `.` 和 `*`
- 保证每次出现字符 `*` 时，前面都匹配到有效的字符

## 解题思路

这是经典的动态规划问题。

**状态定义：**
- `dp[i][j]` 表示 `s[0:i]` 与 `p[0:j]` 是否匹配

**状态转移：**
1. 如果 `p[j-1]` 不是 `*`：
   - 匹配当前字符：`dp[i][j] = dp[i-1][j-1] && (s[i-1] == p[j-1] || p[j-1] == '.')`
2. 如果 `p[j-1]` 是 `*`：
   - 匹配 0 次：`dp[i][j] = dp[i][j-2]`
   - 匹配 1 次或多次：`dp[i][j] = dp[i-1][j] && (s[i-1] == p[j-2] || p[j-2] == '.')`

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        
        // dp[i][j] 表示 s[0:i] 与 p[0:j] 是否匹配
        boolean[][] dp = new boolean[m + 1][n + 1];
        
        // 空字符串匹配空模式
        dp[0][0] = true;
        
        // 处理 a*, a*b*, a*b*c* 这种模式
        for (int j = 2; j <= n; j += 2) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];
            }
        }
        
        // 填表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (p.charAt(j - 1) == '*') {
                    // * 匹配 0 次
                    dp[i][j] = dp[i][j - 2];
                    // * 匹配 1 次或多次
                    if (s.charAt(i - 1) == p.charAt(j - 2) || p.charAt(j - 2) == '.') {
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                } else {
                    // 普通字符或 '.'
                    if (s.charAt(i - 1) == p.charAt(j - 1) || p.charAt(j - 1) == '.') {
                        dp[i][j] = dp[i - 1][j - 1];
                    }
                }
            }
        }
        
        return dp[m][n];
    }
}
```

### 方法二：递归（带记忆化）

```java
class Solution {
    private Boolean[][] memo;
    
    public boolean isMatch(String s, String p) {
        memo = new Boolean[s.length() + 1][p.length() + 1];
        return dp(s, p, 0, 0);
    }
    
    private boolean dp(String s, String p, int i, int j) {
        if (memo[i][j] != null) return memo[i][j];
        
        boolean result;
        
        // 模式已用完
        if (j == p.length()) {
            result = i == s.length();
        } else {
            // 当前字符是否匹配
            boolean firstMatch = i < s.length() &&
                (s.charAt(i) == p.charAt(j) || p.charAt(j) == '.');
            
            // 下一个字符是 *
            if (j + 1 < p.length() && p.charAt(j + 1) == '*') {
                // 匹配 0 次 或 匹配 1 次及以上
                result = dp(s, p, i, j + 2) || (firstMatch && dp(s, p, i + 1, j));
            } else {
                // 普通匹配
                result = firstMatch && dp(s, p, i + 1, j + 1);
            }
        }
        
        memo[i][j] = result;
        return result;
    }
}
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. **`*` 的含义**：匹配零个或多个前面的元素
2. **状态转移**：分 `*` 和非 `*` 两种情况
3. **初始化**：空串与 `a*`、`a*b*` 等可能匹配

## 易错点

1. **`*` 的处理**：`*` 匹配的是前一个字符，而非自己
2. **索引对应**：dp 数组的索引与字符串索引差 1
3. **初始化**：`dp[0][j]` 需要特殊处理
