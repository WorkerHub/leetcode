## 题目描述

与 3439 相同背景，但只能移动恰好 1 个会议，且可插入任意其他空闲时间段，返回移动后最大连续空闲时间。

## Java 代码实现

```java
class Solution {
    public int maxFreeTime(int eventTime, int k, int[] startTime, int[] endTime) {
        int n = startTime.length;

        // 构建空隙数组（n+1 个）
        int[] gaps = new int[n + 1];
        gaps[0] = startTime[0];
        for (int i = 1; i < n; i++) gaps[i] = startTime[i] - endTime[i - 1];
        gaps[n] = eventTime - endTime[n - 1];

        int[] dur = new int[n];
        for (int i = 0; i < n; i++) dur[i] = endTime[i] - startTime[i];

        // 前缀最大值：prefMax[i] = max(gaps[0..i-1])
        int[] prefMax = new int[n + 2];
        for (int i = 0; i <= n; i++) prefMax[i + 1] = Math.max(prefMax[i], gaps[i]);

        // 后缀最大值：sufMax[i] = max(gaps[i..n])
        int[] sufMax = new int[n + 2];
        for (int i = n; i >= 0; i--) sufMax[i] = Math.max(sufMax[i + 1], gaps[i]);

        int ans = 0;
        for (int g : gaps) ans = Math.max(ans, g); // 不移动时的基准

        for (int i = 0; i < n; i++) {
            int d = dur[i];
            int merged = gaps[i] + d + gaps[i + 1];
            // 检查 gaps[i] 和 gaps[i+1] 以外是否存在 >= d 的空隙
            boolean canPlace = prefMax[i] >= d || sufMax[i + 2] >= d;
            if (canPlace) ans = Math.max(ans, merged);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 移动会议 i 后，原位置三段（gaps[i] + d[i] + gaps[i+1]）合并
2. 需验证能否将该会议插入其他地方（某空隙 >= d[i]）
3. 前后缀最大值快速检查可用空隙，排除 gaps[i] 和 gaps[i+1]
