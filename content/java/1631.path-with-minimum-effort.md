## 题目描述

给你 `rows x columns` 的地图 `heights`，路径的**费力程度**为路径上相邻格子高度差绝对值的最大值。返回从左上角到右下角的路径中**费力程度最小**的值。

**提示：**
- `1 <= rows, columns <= 100`
- `1 <= heights[i][j] <= 10^6`

## 解题思路

**Dijkstra 最短路：** 将"最小最大高度差"作为距离，用最小堆维护，松弛时取 `max(当前费力, 相邻高度差)` 而非相加。

## Java 代码实现

```java
class Solution {
    public int minimumEffortPath(int[][] heights) {
        int rows = heights.length, cols = heights[0].length;
        // dist[r][c] = 从左上角到 (r,c) 的最小费力程度
        int[][] dist = new int[rows][cols];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        // 最小堆：(当前费力程度, row, col)
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        heap.offer(new int[]{0, 0, 0});

        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!heap.isEmpty()) {
            int[] curr = heap.poll();
            int effort = curr[0], r = curr[1], c = curr[2];

            if (r == rows - 1 && c == cols - 1) return effort;
            if (effort > dist[r][c]) continue; // 过时状态跳过

            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) {
                    int diff = Math.abs(heights[nr][nc] - heights[r][c]);
                    int newEffort = Math.max(effort, diff);
                    if (newEffort < dist[nr][nc]) {
                        dist[nr][nc] = newEffort;
                        heap.offer(new int[]{newEffort, nr, nc});
                    }
                }
            }
        }
        return dist[rows - 1][cols - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m*n * log(m*n))，Dijkstra + 最小堆
- **空间复杂度**：O(m*n)

## 关键点总结

1. Dijkstra 中用最大高度差（而非累加）定义"距离"
2. 松弛条件：`max(effort, diff) < dist[nr][nc]`
3. 到达终点时立即返回（最小堆保证第一次到达最优）
