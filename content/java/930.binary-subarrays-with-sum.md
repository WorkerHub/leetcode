## 题目描述

给定二元数组 nums 和整数 goal，返回和为 goal 的非空子数组数量。

**示例：**
```
输入：nums = [1,0,1,0,1], goal = 2
输出：4
```

## 解题思路

前缀和 + 哈希表：维护前缀和计数，对于每个位置，查找 prefixSum - goal 出现过多少次。

## Java 代码实现

```java
class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);

        int prefixSum = 0, result = 0;
        for (int num : nums) {
            prefixSum += num;
            result += prefixCount.getOrDefault(prefixSum - goal, 0);
            prefixCount.merge(prefixSum, 1, Integer::sum);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀和技巧**：子数组和 = 两个前缀和之差
2. **哈希表计数**：记录每个前缀和出现次数
3. **初始化**：prefixCount[0] = 1 处理从头开始的子数组
