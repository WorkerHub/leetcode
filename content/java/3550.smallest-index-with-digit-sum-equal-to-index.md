## 题目描述

给定一个整数数组 `nums`。对于每个下标 `i`，若 `nums[i]` 的各位数字之和等于 `i`，则称下标 `i` 为"特殊下标"。返回最小的特殊下标，若不存在则返回 `-1`。

## 解题思路

遍历数组，对每个下标 `i` 用取模运算计算 `nums[i]` 的各位数字之和，若等于 `i` 则直接返回。

## Java 代码实现

```java
class Solution {
    public int smallestIndex(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            // 计算各位数字之和
            int x = nums[i], s = 0;
            while (x > 0) {
                s += x % 10;
                x /= 10;
            }
            if (s == i) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log10(max_val))，遍历数组并计算各位和
- 空间复杂度：O(1)

## 关键点总结

1. 各位数字之和：用取模运算逐位累加
2. 找最小满足条件的索引：从左到右遍历，第一个满足的即为答案
3. 没有满足条件的索引则返回 -1
