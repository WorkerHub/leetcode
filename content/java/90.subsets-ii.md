## 题目描述

给你一个整数数组 `nums`，其中可能包含重复元素，请你返回该数组所有可能的子集（幂集）。

解集不能包含重复的子集。返回的解集中，子集可以按任意顺序排列。

**示例 1：**
```
输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]
```

**示例 2：**
```
输入：nums = [0]
输出：[[],[0]]
```

**提示：**
- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`

## 解题思路

这道题是第 78 题「子集」的进阶版，区别在于数组中可能包含重复元素。核心问题是：如何避免生成重复的子集？

**关键观察：**
1. 如果数组中有重复元素，直接用第 78 题的方法会产生重复子集
2. 例如 `[1,2,2]`，如果不去重，会生成两个 `[1,2]`

**解决方案：**
1. **先排序**：将相同元素放在一起，便于跳过重复
2. **剪枝策略**：在同一层递归中，如果当前元素与前一个元素相同且前一个元素未被使用，则跳过

**为什么要排序？**
- 排序后，相同的元素会相邻
- 可以通过比较 `nums[i] == nums[i-1]` 来判断是否重复

**剪枝的核心逻辑：**
```
如果 nums[i] == nums[i-1] 且 i > start，说明：
- 当前元素与前一个元素相同
- 前一个元素在本层递归中已经被处理过
- 跳过当前元素，避免重复
```

**图解示例（以 [1,2,2] 为例）：**
```
                    []
           /         |         \
         [1]        [2]        [2] ← 跳过（与前面的2重复）
        /   \        |
    [1,2]  [1,2]    [2,2]
      |      ← 跳过
   [1,2,2]
```

## Java 代码实现

### 方法一：回溯 + 排序去重（推荐）

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private int[] nums;

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums); // 排序是去重的关键
        this.nums = nums;
        backtrack(0, new ArrayList<>());
        return result;
    }

    private void backtrack(int start, List<Integer> path) {
        // 每个路径都是一个有效子集
        result.add(new ArrayList<>(path));

        for (int i = start; i < nums.length; i++) {
            // 剪枝：跳过同一层的重复元素
            // i > start 保证不是当前层的第一个元素
            if (i > start && nums[i] == nums[i - 1]) {
                continue;
            }

            path.add(nums[i]);
            backtrack(i + 1, path); // 递归下一层
            path.remove(path.size() - 1); // 回溯
        }
    }
}
```

### 方法二：迭代 + 去重

```java
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums); // 排序
        List<List<Integer>> result = new ArrayList<>();
        result.add(new ArrayList<>());

        // 记录上一轮添加的子集数量
        int prevSize = 0;

        for (int i = 0; i < nums.length; i++) {
            // 当前要处理的起始位置
            int start = 0;

            // 如果当前元素与前一个相同，只对上一轮新增的子集添加当前元素
            if (i > 0 && nums[i] == nums[i - 1]) {
                start = prevSize;
            }

            prevSize = result.size(); // 记录本轮开始前的大小

            // 遍历现有子集，添加当前元素
            for (int j = start; j < prevSize; j++) {
                List<Integer> newSubset = new ArrayList<>(result.get(j));
                newSubset.add(nums[i]);
                result.add(newSubset);
            }
        }

        return result;
    }
}
```

### 方法三：使用集合去重（不推荐，仅供理解）

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private int[] nums;

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        this.nums = nums;
        backtrack(0, new ArrayList<>());

        // 使用集合去重（将列表转为字符串）
        Set<String> seen = new HashSet<>();
        List<List<Integer>> unique = new ArrayList<>();
        for (List<Integer> subset : result) {
            String key = subset.toString();
            if (seen.add(key)) {
                unique.add(subset);
            }
        }
        return unique;
    }

    private void backtrack(int start, List<Integer> path) {
        result.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            backtrack(i + 1, path);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

**方法一（回溯 + 剪枝）：**
- 时间复杂度：O(n × 2^n)，其中 n 是数组长度。最坏情况下仍需生成所有子集，每个子集需要 O(n) 时间复制
- 空间复杂度：O(n)，递归栈的深度

**方法二（迭代）：**
- 时间复杂度：O(n × 2^n)
- 空间复杂度：O(1)，不计结果空间

**方法三（集合去重）：**
- 时间复杂度：O(n × 2^n)，额外的去重操作
- 空间复杂度：O(2^n)，需要额外的集合空间

## 图解示例

以 `nums = [1,2,2]` 为例，展示回溯过程：

```
排序后：[1,2,2]

递归树：
                        []
           /             |            \
        [1]            [2]           [2] ← 跳过
       /   \            |
   [1,2]  [1,2]       [2,2]
     |      ↑ 跳过
  [1,2,2]

最终结果：[[], [1], [1,2], [1,2,2], [2], [2,2]]
```

**关键点：**
1. 在同一层中，第二个 `[2]` 被跳过（因为 `nums[2] == nums[1]` 且 `i > start`）
2. 在 `[1]` 分支下，第二个 `[1,2]` 被跳过（因为 `nums[2] == nums[1]` 且 `i > start`）

## 关键点总结

1. **排序是前提**：必须先排序才能有效去重
2. **剪枝条件**：`i > start && nums[i] == nums[i-1]` 跳过同层重复元素
3. **与第 78 题的区别**：增加了排序和去重逻辑
4. **去重原理**：同层相同元素只处理第一个，后续跳过
5. **回溯模板**：每次都添加当前路径，然后递归选择后续元素

## 易错点

1. **忘记排序**：不排序无法正确去重

2. **去重条件错误**：应该是 `i > start` 而不是 `i > 0`
   ```java
   // 错误：会跳过合法的子集
   if (i > 0 && nums[i] == nums[i - 1]) // 应该是 i > start
   ```

3. **使用 `i - 1` 时未判断边界**：确保 `i > start` 才能访问 `nums[i-1]`

4. **误用集合去重**：虽然可行，但效率低，不是最优解

5. **Java 中 List 复制**：添加到结果时要用 `new ArrayList<>(path)` 深拷贝，否则会受后续修改影响
