## 题目描述

通过交换nums1[i]和nums2[i]，使nums1[n-1]和nums2[n-1]分别为各自数组最大值，求最少操作次数。

## 解题思路

末尾只有交换/不交换两种状态，分别计算每种情况下前n-1个位置需要的最少交换次数，取最小值。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int res1 = calc(nums1, nums2, nums1[n - 1], nums2[n - 1]);
        int res2 = calc(nums1, nums2, nums2[n - 1], nums1[n - 1]);
        if (res2 != Integer.MAX_VALUE) res2++;
        int ans = Math.min(res1, res2);
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }

    private int calc(int[] nums1, int[] nums2, int max1, int max2) {
        int ops = 0;
        for (int i = 0; i < nums1.length - 1; i++) {
            if (nums1[i] <= max1 && nums2[i] <= max2) {
                continue;
            } else if (nums2[i] <= max1 && nums1[i] <= max2) {
                ops++;
            } else {
                return Integer.MAX_VALUE;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举末尾两种状态**：交换或不交换
2. **贪心判断每个位置**：不换/换/不可行
3. **末尾交换本身+1**
