## 题目描述

给定含 '('、')' 和小写字母的字符串 s，删除最少数目的括号使其有效，返回任意合法字符串。

**示例：**
```
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
```

## 解题思路

用栈记录无法匹配的括号索引。遍历时：遇到 '(' 入栈索引，遇到 ')' 若栈非空弹出配对，否则记录该 ')' 索引。最后删除所有标记的索引。

## Java 代码实现

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        Set<Integer> toRemove = new HashSet<>();
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);
            } else if (c == ')') {
                if (!stack.isEmpty()) {
                    stack.pop(); // 匹配成功
                } else {
                    toRemove.add(i); // 多余的 ')'
                }
            }
        }
        // 栈中剩余的是多余的 '('
        while (!stack.isEmpty()) toRemove.add(stack.pop());
        
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            if (!toRemove.contains(i)) sb.append(s.charAt(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈记录索引**：而非字符，方便后续定位删除
2. **两类无效括号**：无配对的 ')' 和无配对的 '('
3. **HashSet 标记删除**：O(1) 判断某位置是否需要删除
4. **重建字符串**：跳过标记位置
