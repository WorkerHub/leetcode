## 题目描述

给你数组 `start` 和整数 `d`，对每个下标 `i` 从区间 `[start[i], start[i]+d]` 选一个整数，返回所有选出整数中相邻最小差的最大值。

## 解题思路

二分答案：二分最小差值 `minGap`，贪心检验可行性。排序后从左到右，每次选满足距离约束的最小值（`max(start[i], prev + minGap)`），若超出右端则不可行。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxPossibleScore(int[] start, int d) {
        Arrays.sort(start);
        int n = start.length;
        long lo = 0, hi = ((long) start[n - 1] + d - start[0]) / (n - 1);

        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (canAchieve(start, d, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return (int) lo;
    }

    private boolean canAchieve(int[] start, int d, long minGap) {
        long prev = start[0];
        for (int i = 1; i < start.length; i++) {
            long nxt = Math.max((long) start[i], prev + minGap);
            if (nxt > (long) start[i] + d) return false; // 超出区间右端
            prev = nxt;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))
- 空间复杂度：O(1)

## 关键点总结

1. 二分最小差值，排序后贪心检验
2. 贪心：对每个区间取满足距离约束的最小值
3. 二分上界为 `(max+d-min)/(n-1)`，注意用 `long` 防溢出
