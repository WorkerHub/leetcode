## 题目描述

从每袋中去除一些豆子使剩余非空袋豆数相等，求最少去除的豆数。

## 解题思路

排序后枚举目标值beans[i]：左侧全清空，右侧减到beans[i]。保留=beans[i]*(n-i)，去除=总和-保留，取最小。

## Java 代码实现

```java
class Solution {
    public long minimumRemoval(int[] beans) {
        Arrays.sort(beans);
        int n = beans.length;
        long total = 0;
        for (int b : beans) total += b;
        
        long ans = total;
        for (int i = 0; i < n; i++) {
            // 以beans[i]为目标值，保留beans[i]*(n-i)
            long keep = (long) beans[i] * (n - i);
            ans = Math.min(ans, total - keep);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后枚举目标值**：以beans[i]为目标，左侧清空右侧削减
2. **保留=beans[i]*(n-i)**：从i到末尾每袋保留beans[i]个
3. **用long防溢出**：beans[i]*(n-i)可能超int
