## 题目描述

给定最大二叉树的根节点 root 和整数 val（原数组末尾追加 val 后重建最大树），返回新树的根节点。

**示例：**
```
输入：root = [4,1,3,null,null,2], val = 5
输出：[5,4,null,1,3,null,null,2]
```

## 解题思路

递归：val 追加在末尾，只会出现在右子树路径上。若 val > root.val 则 val 成为新根，原树为左子树；否则递归插入右子树。

## Java 代码实现

```java
class Solution {
    public TreeNode insertIntoMaxTree(TreeNode root, int val) {
        if (root == null || val > root.val) {
            TreeNode newRoot = new TreeNode(val);
            newRoot.left = root;
            return newRoot;
        }

        root.right = insertIntoMaxTree(root.right, val);
        return root;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(h)
- **空间复杂度**：O(h)

## 关键点总结

1. **末尾追加**：val 只可能在右子树路径上
2. **递归结构**：大于当前节点就替换，否则递归右子树
3. **新根情况**：val 最大时成为整棵树的根
