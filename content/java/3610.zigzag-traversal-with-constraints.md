## 题目描述

给定 `m x n` 矩阵 `grid` 和整数 `k`，偶数行从左到右、奇数行从右到左进行锯齿遍历，且只收集列下标满足 `j % k == 0` 的元素，返回收集结果。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> zigzagTraversal(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        List<Integer> result = new ArrayList<>();

        // 预计算满足 j % k == 0 的所有列下标
        List<Integer> validCols = new ArrayList<>();
        for (int j = 0; j < n; j += k) validCols.add(j);

        for (int i = 0; i < m; i++) {
            if (i % 2 == 0) {
                // 偶数行：从左到右
                for (int j : validCols) result.add(grid[i][j]);
            } else {
                // 奇数行：从右到左（逆序遍历 validCols）
                for (int p = validCols.size() - 1; p >= 0; p--) {
                    result.add(grid[i][validCols.get(p)]);
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n / k)，遍历所有满足条件的元素
- 空间复杂度：O(m * n / k)，结果列表

## 关键点总结

1. 合法列下标集合只计算一次，偶奇行共用
2. 奇数行逆序遍历合法列下标即可
3. `range(0, n, k)` 或步长循环简洁生成列下标
