## 题目描述

给定一个数组 `coins`，表示在从位置 1 到位置 n 的路径上每个位置的花费。你需要从位置 1 开始，到达位置 n。

你每次可以向前跳 1 到 `maxJump` 步。你的目标是找到**花费最小**的路径。如果有多条花费相同的路径，返回**字典序最小**的那一条。

如果无法到达位置 n，返回空数组。

**示例 1:**

```
输入: coins = [1,2,4,-1,2], maxJump = 2
输出: [1,3,5]
解释:
路径 1 -> 3 -> 5 的花费是 1 + 4 + 2 = 7
```

**示例 2:**

```
输入: coins = [1,2,4,-1,2], maxJump = 1
输出: []
解释:
无法跳过位置 4（花费为 -1 表示不可达）
```

**提示:**
- `coins.length == n`
- `1 <= n <= 1000`
- `-1 <= coins[i] <= 100`
- `1 <= maxJump <= 100`
- `coins[0]` 不会是 -1

## 解题思路

这是一道**动态规划 + 路径记录**的问题。

### 核心思路

1. **动态规划求最小花费**：
   - `dp[i]` 表示到达位置 i 的最小花费
   - 状态转移：`dp[i] = min(dp[j] + coins[i])` for j in range(max(0, i-maxJump), i)

2. **路径记录**：
   - 记录每个位置的前驱节点
   - 为了字典序最小，从最远的前驱开始考虑

3. **字典序最小**：
   - 在花费相同的情况下，选择编号最小的前驱
   - 这样构造的路径字典序最小

### 关键观察

- 花费为 -1 的位置不可达
- 需要同时记录最小花费和路径
- 字典序最小意味着路径中的数字尽可能小

## Java 代码实现

### 方法一：动态规划 + 路径记录（推荐）

```java
import java.util.*;

class Solution {
    public List<Integer> cheapestJump(int[] coins, int maxJump) {
        int n = coins.length;

        // 特殊情况
        if (coins[n - 1] == -1) return new ArrayList<>();

        // dp[i] 表示到达位置 i 的最小花费
        int[] dp = new int[n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        // parent[i] 表示到达位置 i 的前驱位置
        int[] parent = new int[n];
        Arrays.fill(parent, -1);

        dp[0] = coins[0];

        // 正向 DP
        for (int i = 0; i < n; i++) {
            if (coins[i] == -1 || dp[i] == Integer.MAX_VALUE) continue;

            // 从位置 i 跳到后面的位置
            for (int j = i + 1; j < Math.min(i + maxJump + 1, n); j++) {
                if (coins[j] == -1) continue;

                int cost = dp[i] + coins[j];

                // 更新条件：
                // 1. 花费更小
                // 2. 花费相同但前驱编号更小（字典序）
                if (cost < dp[j]) {
                    dp[j] = cost;
                    parent[j] = i;
                } else if (cost == dp[j] && i < parent[j]) {
                    parent[j] = i;
                }
            }
        }

        // 无法到达终点
        if (dp[n - 1] == Integer.MAX_VALUE) return new ArrayList<>();

        // 回溯构造路径
        List<Integer> path = new ArrayList<>();
        int pos = n - 1;
        while (pos != -1) {
            path.add(pos + 1); // 位置从 1 开始
            pos = parent[pos];
        }

        Collections.reverse(path);
        return path;
    }
}
```

### 方法二：反向 DP + 路径记录

```java
import java.util.*;

class Solution {
    public List<Integer> cheapestJump(int[] coins, int maxJump) {
        int n = coins.length;

        if (coins[n - 1] == -1) return new ArrayList<>();

        // dp[i] 表示到达位置 i 的最小花费
        int[] dp = new int[n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        // next_pos[i] 表示从位置 i 到达终点的下一步位置
        int[] nextPos = new int[n];
        Arrays.fill(nextPos, -1);

        // 起点
        dp[0] = coins[0];

        // 从后往前填表（为了方便记录路径）
        for (int i = n - 1; i >= 0; i--) {
            if (coins[i] == -1) continue;

            // 尝试从当前位置跳到后面的位置
            for (int j = i + 1; j < Math.min(i + maxJump + 1, n); j++) {
                if (coins[j] == -1) continue;

                if (dp[i] == Integer.MAX_VALUE) continue;
                int cost = dp[i] + coins[j];

                // 更新条件：花费更小，或花费相同但路径字典序更小
                if (cost < dp[j] || (cost == dp[j] && nextPos[i] < nextPos[j])) {
                    dp[j] = cost;
                    nextPos[i] = j;
                }
            }
        }

        // 无法到达终点
        if (dp[n - 1] == Integer.MAX_VALUE) return new ArrayList<>();

        // 构造路径
        List<Integer> path = new ArrayList<>();
        int pos = 0;
        while (pos != -1) {
            path.add(pos + 1); // 位置从 1 开始
            if (pos == n - 1) break;
            pos = nextPos[pos];
        }

        return path;
    }
}
```

### 方法三：优化版本（带路径长度）

```java
import java.util.*;

class Solution {
    public List<Integer> cheapestJump(int[] coins, int maxJump) {
        int n = coins.length;

        if (coins[n - 1] == -1) return new ArrayList<>();

        // dp[i] = 最小花费
        int[] dp = new int[n];
        // length[i] = 路径长度
        int[] length = new int[n];
        // parent[i] = 前驱位置
        int[] parent = new int[n];

        Arrays.fill(dp, Integer.MAX_VALUE);
        Arrays.fill(parent, -1);

        dp[0] = coins[0];
        length[0] = 1;

        for (int i = 0; i < n; i++) {
            if (coins[i] == -1 || dp[i] == Integer.MAX_VALUE) continue;

            for (int j = i + 1; j < Math.min(i + maxJump + 1, n); j++) {
                if (coins[j] == -1) continue;

                int cost = dp[i] + coins[j];
                int len = length[i] + 1;

                // 更新条件：
                // 1. 花费更小
                // 2. 花费相同但路径更长（字典序更小）
                // 3. 花费相同且路径长度相同但前驱更小
                if (cost < dp[j]
                    || (cost == dp[j] && len > length[j])
                    || (cost == dp[j] && len == length[j] && i < parent[j])) {
                    dp[j] = cost;
                    length[j] = len;
                    parent[j] = i;
                }
            }
        }

        if (dp[n - 1] == Integer.MAX_VALUE) return new ArrayList<>();

        // 回溯路径
        List<Integer> path = new ArrayList<>();
        int pos = n - 1;
        while (pos != -1) {
            path.add(pos + 1);
            pos = parent[pos];
        }

        Collections.reverse(path);
        return path;
    }
}
```

## 复杂度分析

### 方法一/二：动态规划
- **时间复杂度**：O(n × maxJump)
  - 外层循环 n 次
  - 内层循环最多 maxJump 次
- **空间复杂度**：O(n)，dp 数组和 parent 数组

### 方法三：优化版本
- **时间复杂度**：O(n × maxJump)
- **空间复杂度**：O(n)

```
位置：  0   1   2   3   4
花费：  1   2   4  -1   2
索引：  1   2   3   4   5

DP 过程（正向）：

从位置0出发：

  到位置2：cost = 1+4=5, dp[2]=5, parent[2]=0

从位置1出发：
  到位置2：cost = 3+4=7 > 5，不更新
  到位置3：-1，跳过

从位置2出发：
  到位置3：-1，跳过
  到位置4：cost = 5+2=7, dp[4]=7, parent[4]=2

dp = [1, 3, 5, MAX, 7]

回溯路径：
4 -> 2 -> 0
反转：[0, 2, 4]
转换为1-based：[1, 3, 5]
```

## 关键点总结

1. **动态规划**：`dp[i]` 表示到达位置 i 的最小花费
2. **路径记录**：使用 parent 数组记录前驱节点
3. **字典序最小**：花费相同时选择编号最小的前驱
4. **不可达位置**：花费为 -1 的位置需要跳过
5. **边界处理**：终点不可达时返回空数组

## 易错点

1. **位置索引**：
   ```java
   // 题目位置从1开始，数组索引从0开始
   path.add(pos + 1); // 转换为1-based
   ```

2. **字典序条件**：
   ```java
   // 花费相同时，选择编号更小的前驱
   if (cost < dp[j]) {
       update();
   } else if (cost == dp[j] && i < parent[j]) { // 注意这个条件
       update();
   }
   ```

3. **不可达判断**：
   ```java
   // 终点不可达
   if (coins[n - 1] == -1) return new ArrayList<>();
   
   // 某个位置不可达
   if (coins[i] == -1) continue;
   ```

4. **跳跃范围**：
   ```java
   // 注意边界：Math.min(i + maxJump + 1, n)
   for (int j = i + 1; j < Math.min(i + maxJump + 1, n); j++)
   ```

5. **路径构造**：
   ```java
   // 回溯时需要反转
   Collections.reverse(path);
   ```

## 学习建议

**适合新手的学习路径：**

1. **理解问题**：
   - 明确什么是字典序最小
   - 理解为什么花费相同时选择最小前驱

2. **动态规划基础**：
   - 定义状态：到达每个位置的最小花费
   - 状态转移：从前面的位置转移过来
   - 初始化和边界条件

3. **路径记录技巧**：
   - 使用 parent 数组记录前驱
   - 回溯构造完整路径
   - 注意路径需要反转

4. **字典序处理**：
   - 理解字典序的定义
   - 在 DP 更新时加入字典序判断

**常见问题：**

Q: 为什么花费相同时选择最小的前驱？
A: 因为路径中较早的位置编号越小，字典序越小。

Q: 正向 DP 和反向 DP 有什么区别？
A: 正向更直观，反向可以更方便地记录路径（不需要反转）。

Q: 如何确保字典序最小？
A: 在更新 DP 时，花费相同的情况下选择编号最小的前驱。
