## 题目描述

给你 n 个长度均为 n 的二进制字符串数组 `nums`，返回一个长度为 n 且不在 `nums` 中的二进制字符串。

## 解题思路

对角线构造法（康托对角化）：令 `res[i]` 与 `nums[i][i]` 不同，则 `res` 与每个 `nums[i]` 至少在第 i 位不同，保证不在数组中，O(n) 时间。

## Java 代码实现

```java
class Solution {
    public String findDifferentBinaryString(String[] nums) {
        int n = nums.length;
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++)
            sb.append(nums[i].charAt(i) == '0' ? '1' : '0');
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 对角线构造保证 O(n) 且结果唯一确定
2. `res[i]` 与 `nums[i][i]` 不同，确保 `res != nums[i]` 对所有 i 成立
