## 题目描述

m×n 金矿网格，每个格子有一定数量的黄金（0 表示空）。从任意非零格子出发，每步向四方向移动，不能重复访问，不能进入 0 格子。求能收集的最大黄金数量。

**示例：**
```
输入：grid = [[0,6,0],[5,8,7],[0,9,0]]
输出：24（路径 9→8→7）
```

## 解题思路

回溯法：从每个非零格子出发 DFS，标记已访问格子，回溯时恢复。记录所有路径中的最大值。

## Java 代码实现

```java
class Solution {
    private int[][] grid;
    private int m, n;
    private int maxGold = 0;
    private int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    
    public int getMaximumGold(int[][] grid) {
        this.grid = grid;
        this.m = grid.length;
        this.n = grid[0].length;
        
        // 从每个非零格子出发
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 0) {
                    dfs(i, j, 0);
                }
            }
        }
        return maxGold;
    }
    
    private void dfs(int r, int c, int gold) {
        // 收集当前格子的黄金
        gold += grid[r][c];
        maxGold = Math.max(maxGold, gold);
        
        // 标记已访问
        int temp = grid[r][c];
        grid[r][c] = 0;
        
        // 探索四个方向
        for (int[] dir : dirs) {
            int nr = r + dir[0], nc = c + dir[1];
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] != 0) {
                dfs(nr, nc, gold);
            }
        }
        
        // 回溯恢复
        grid[r][c] = temp;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n × 4^k)，k 为非零格子数（最多 25）
- **空间复杂度**：O(k)，递归栈深度

## 关键点总结

1. **回溯**：修改原数组标记访问，回溯时恢复
2. **多起点**：每个非零格子都可能是最优起点
3. **剪枝**：grid[nr][nc] == 0 时不进入（包含已访问的）
4. **原地修改**：设为 0 标记已访问，避免额外 visited 数组
