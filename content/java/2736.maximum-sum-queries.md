## 题目描述

给你数组 `nums1`、`nums2` 和查询数组 `queries`，每个查询 `[xi, yi]` 要求在所有满足 `nums1[j] >= xi` 且 `nums2[j] >= yi` 的下标中，找 `nums1[j] + nums2[j]` 的最大值（不存在返回 -1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maximumSumQueries(int[] nums1, int[] nums2, int[][] queries) {
        int n = nums1.length, q = queries.length;
        // 将 (nums1[i], nums2[i]) 按 nums1 降序排列
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) { pairs[i][0] = nums1[i]; pairs[i][1] = nums2[i]; }
        Arrays.sort(pairs, (a, b) -> b[0] - a[0]);
        // 查询按 xi 降序排列，保留原始下标
        Integer[] qi = new Integer[q];
        for (int i = 0; i < q; i++) qi[i] = i;
        Arrays.sort(qi, (a, b) -> queries[b][0] - queries[a][0]);

        int[] ans = new int[q];
        Arrays.fill(ans, -1);
        // 单调栈：按 nums2 升序，sum 降序
        int[][] stack = new int[n][2]; // [nums2, sum]
        int top = 0, ptr = 0;

        for (int idx : qi) {
            int x = queries[idx][0], y = queries[idx][1];
            // 将所有 nums1[j] >= x 的元素加入栈
            while (ptr < n && pairs[ptr][0] >= x) {
                int a = pairs[ptr][0], b = pairs[ptr][1], s = a + b;
                // 维护单调性：sum 递减（弹出 sum 更小的）
                while (top > 0 && stack[top - 1][1] <= s) top--;
                // nums2 单调递增（只加入 nums2 更大的）
                if (top == 0 || stack[top - 1][0] < b) {
                    stack[top][0] = b; stack[top][1] = s; top++;
                }
                ptr++;
            }
            // 二分找满足 nums2 >= y 的最小索引（sum 最大）
            int lo = 0, hi = top;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (stack[mid][0] >= y) hi = mid;
                else lo = mid + 1;
            }
            if (lo < top) ans[idx] = stack[lo][1];
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n + q)

## 关键点总结

1. 离线按 x 降序处理，保证处理查询时已有所有满足 `nums1 >= x` 的元素
2. 单调栈按 nums2 升序、sum 降序，支持二分查询
3. 二分找满足 `nums2 >= y` 中最小索引，对应最大 sum
