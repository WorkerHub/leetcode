## 题目描述

给定 `m × n` 矩阵 `grid`，从任意单元格出发，每次可以移动到相邻单元格（上下左右）并收集点数。无代价移动要求目标格点数 >= 当前格，否则花费 1 次代价。在 `k` 次代价操作内，求可收集的最大点数之和。

## 解题思路

使用优先队列（最大堆）的 Dijkstra 变体。状态为 `(当前总点数, 已用代价, 行, 列)`，从每个格子作为起点初始化，始终扩展当前点数最大的状态。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long maxPoints(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        // best[i][j][c]: 到达 (i,j) 使用 c 次代价的最大点数
        long[][][] best = new long[m][n][k + 1];
        for (long[][] a : best)
            for (long[] b : a)
                java.util.Arrays.fill(b, Long.MIN_VALUE);

        // 优先队列：(-点数, 代价, 行, 列)
        PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(b[0], a[0]));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                best[i][j][0] = grid[i][j];
                pq.offer(new long[]{grid[i][j], 0, i, j});
            }
        }

        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        long ans = 0;

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long pts = cur[0];
            int cost = (int)cur[1], r = (int)cur[2], c = (int)cur[3];
            if (pts < best[r][c][cost]) continue;
            ans = Math.max(ans, pts);
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int newCost = cost + (grid[nr][nc] >= grid[r][c] ? 0 : 1);
                long newPts = pts + grid[nr][nc];
                if (newCost <= k && newPts > best[nr][nc][newCost]) {
                    best[nr][nc][newCost] = newPts;
                    pq.offer(new long[]{newPts, newCost, nr, nc});
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn * k * log(mn))
- 空间复杂度：O(mn * k)

## 关键点总结

1. 状态包含已使用代价次数，增加一维进行 Dijkstra
2. 无代价移动要求目标格值 >= 当前格值
3. 每个格子都可以作为起点
