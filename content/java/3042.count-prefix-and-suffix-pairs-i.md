## 题目描述

统计(i,j)对数使得words[i]同时是words[j]的前缀和后缀（i<j）。

## 解题思路

数据范围小，暴力枚举所有对，用startsWith和endsWith检查。

## Java 代码实现

```java
class Solution {
    public int countPrefixSuffixPairs(String[] words) {
        int count = 0, n = words.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (words[i].length() <= words[j].length()
                    && words[j].startsWith(words[i])
                    && words[j].endsWith(words[i])) {
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2 * L)
- **空间复杂度**：O(1)

## 关键点总结

1. **同时是前缀和后缀**：两个条件都要满足
2. **前提len(s1)<=len(s2)**
3. **暴力枚举所有对**：数据范围小
