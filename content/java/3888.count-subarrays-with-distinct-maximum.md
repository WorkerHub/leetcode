## 题目描述

给你一个整数数组 `nums`，统计最大元素恰好只出现一次的子数组数目。

## 解题思路

找全局最大值的所有出现位置，对每个位置 `pos[i]`，以它为唯一最大值的子数组数量 = 左侧可选范围 * 右侧可选范围（乘法原理，范围由相邻最大值位置限定）。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public long countSubarrays(int[] nums) {
        int n = nums.length;

        // 找全局最大值
        int maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);

        // 收集所有最大值出现的位置
        List<Integer> positions = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (nums[i] == maxVal) positions.add(i);
        }

        long count = 0;
        int k = positions.size();

        for (int idx = 0; idx < k; idx++) {
            int pos = positions.get(idx);

            // 左边界：上一个最大值位置之后（或数组起始）
            int leftBound = (idx > 0) ? positions.get(idx - 1) + 1 : 0;
            // 右边界：下一个最大值位置之前（或数组末尾）
            int rightBound = (idx < k - 1) ? positions.get(idx + 1) - 1 : n - 1;

            // 子数组左端可选：[leftBound, pos]，右端可选：[pos, rightBound]
            long leftChoices = pos - leftBound + 1;
            long rightChoices = rightBound - pos + 1;
            count += leftChoices * rightChoices;
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历一次找位置，再遍历一次统计
- 空间复杂度：O(k)，k 为最大值出现次数

## 关键点总结

1. 找全局最大值的所有出现位置。
2. 对每个位置，计算以该位置为唯一最大值的子数组数量（乘法原理）。
3. 左右范围由相邻的最大值位置决定。
