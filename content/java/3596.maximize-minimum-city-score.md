## 题目描述

给定图中 `n` 个城市和若干道路，每个城市有分数，选一个非空连通子集使子集中最小城市分数最大化，返回该最大最小分数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximizeMinScore(int n, int[][] edges, int[] scores) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 按分数降序加入节点，用并查集维护连通性
        Integer[] nodes = new Integer[n];
        for (int i = 0; i < n; i++) nodes[i] = i;
        Arrays.sort(nodes, (a, b) -> scores[b] - scores[a]);

        int[] parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        boolean[] inSet = new boolean[n];
        int componentCount = 0;
        int ans = 0;

        for (int node : nodes) {
            inSet[node] = true;
            componentCount++;
            for (int nb : graph.get(node)) {
                if (inSet[nb] && find(parent, node) != find(parent, nb)) {
                    union(parent, node, nb);
                    componentCount--;
                }
            }
            // 当所有已加入的节点恰好构成一个连通分量时，当前最小分数有效
            if (componentCount == 1) {
                ans = scores[node];  // 按降序加入，当前 node 是最小分数
            }
        }
        return ans;
    }

    private int find(int[] parent, int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int[] parent, int x, int y) {
        int px = find(parent, x), py = find(parent, y);
        if (px != py) parent[px] = py;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n + E * α(n))，排序 + 并查集
- 空间复杂度：O(n + E)

## 关键点总结

1. 将节点按分数降序加入，用并查集维护连通性
2. 首次所有节点连通（`componentCount == 1`）时，当前最小分数为答案
3. 按降序加入，当前节点分数是已加入节点中最小的
