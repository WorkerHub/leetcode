## 题目描述

给你整数数组 `nums` 和整数 `k`，若子集中不存在差恰好为 `k` 的两个元素，则称该子集为 **k-free** 子集，返回所有 k-free 子集的数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countTheNumOfKFreeSubsets(int[] nums, int k) {
        Arrays.sort(nums);
        // 按 num % k 分组
        Map<Integer, List<Integer>> groups = new LinkedHashMap<>();
        for (int x : nums) {
            groups.computeIfAbsent(x % k, key -> new ArrayList<>()).add(x);
        }

        long ans = 1;
        for (List<Integer> group : groups.values()) {
            int n = group.size();
            // 类打家劫舍 DP：f 不选当前，g 选当前
            long f = 1, g = 1;
            Integer prev = null;
            for (int x : group) {
                if (prev != null && x - prev == k) {
                    // 相邻差为 k，选当前则前一个不能选
                    long newF = f + g;
                    long newG = f;
                    f = newF;
                    g = newG;
                } else {
                    // 与前一个不冲突，独立
                    long total = f + g;
                    f = total;
                    g = total;
                }
                prev = x;
            }
            ans *= (f + g);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，分组存储

## 关键点总结

1. 差为 `k` 的元素模 `k` 余数相同，按此分组
2. 组内问题类似打家劫舍（不能选差为 `k` 的相邻元素）
3. 不同组独立，将各组答案相乘
