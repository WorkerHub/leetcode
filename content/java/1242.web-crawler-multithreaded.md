## 题目描述

实现多线程网页爬虫，从 startUrl 开始爬取所有同主机名的链接。单线程方案会超时，必须并发爬取。

**约束：** getUrls(url) 15ms 内返回，需要并发加速。

## 解题思路

使用线程池并发爬取。ConcurrentHashMap 记录已访问 URL，每获取一个 URL 提交到线程池异步爬取。

## Java 代码实现

```java
class Solution {
    public List<String> crawl(String startUrl, HtmlParser htmlParser) {
        String hostname = getHostname(startUrl);
        Set<String> visited = ConcurrentHashMap.newKeySet();
        visited.add(startUrl);
        
        // 使用线程池并发爬取
        ExecutorService executor = Executors.newFixedThreadPool(8);
        List<Future<List<String>>> futures = new ArrayList<>();
        
        // BFS
        Queue<String> queue = new ConcurrentLinkedQueue<>();
        queue.offer(startUrl);
        
        while (!queue.isEmpty()) {
            List<Future<List<String>>> batch = new ArrayList<>();
            while (!queue.isEmpty()) {
                String url = queue.poll();
                batch.add(executor.submit(() -> htmlParser.getUrls(url)));
            }
            
            for (Future<List<String>> future : batch) {
                try {
                    for (String next : future.get()) {
                        if (getHostname(next).equals(hostname) && visited.add(next)) {
                            queue.offer(next);
                        }
                    }
                } catch (Exception e) {}
            }
        }
        
        executor.shutdown();
        return new ArrayList<>(visited);
    }
    
    private String getHostname(String url) {
        String withoutProtocol = url.substring(7);
        int idx = withoutProtocol.indexOf('/');
        return idx == -1 ? withoutProtocol : withoutProtocol.substring(0, idx);
    }
}
```

## 关键点总结

1. **线程池**：ExecutorService 管理并发线程
2. **ConcurrentHashMap**：线程安全的 visited 集合
3. **批量提交**：每轮将当前层 URL 同时提交，等待全部完成
4. **visited.add() 原子性**：ConcurrentHashMap.newKeySet() 的 add 是原子操作
