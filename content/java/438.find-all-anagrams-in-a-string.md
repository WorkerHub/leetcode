## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的字母异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

**示例 1：**
```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的字母异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的字母异位词。
```

**示例 2：**
```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的字母异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的字母异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的字母异位词。
```

**提示：**
- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

## 解题思路

这道题要求找到所有字母异位词的位置。核心思想是使用滑动窗口 + 哈希表。

**关键观察：**
1. 字母异位词意味着字符频率相同
2. 窗口大小固定为 `len(p)`
3. 使用滑动窗口维护当前窗口的字符频率

**算法流程：**
1. 统计 `p` 的字符频率
2. 使用固定大小的滑动窗口遍历 `s`
3. 维护窗口内的字符频率
4. 当窗口频率与 `p` 的频率相同时，记录起始位置

## Java 代码实现

### 方法一：滑动窗口 + 数组计数 ⭐ 推荐

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int sLen = s.length();
        int pLen = p.length();
        
        if (sLen < pLen) return result;
        
        // 使用数组代替哈希表（只有 26 个字母）
        int[] pCount = new int[26];
        int[] windowCount = new int[26];
        
        // 统计 p 的字符频率
        for (char c : p.toCharArray()) {
            pCount[c - 'a']++;
        }
        
        // 初始化第一个窗口
        for (int i = 0; i < pLen; i++) {
            windowCount[s.charAt(i) - 'a']++;
        }
        
        // 检查第一个窗口
        if (Arrays.equals(windowCount, pCount)) {
            result.add(0);
        }
        
        // 滑动窗口
        for (int i = pLen; i < sLen; i++) {
            // 加入右边的字符
            windowCount[s.charAt(i) - 'a']++;
            // 移除左边的字符
            windowCount[s.charAt(i - pLen) - 'a']--;
            
            // 检查是否匹配
            if (Arrays.equals(windowCount, pCount)) {
                result.add(i - pLen + 1);
            }
        }
        
        return result;
    }
}
```

### 方法二：滑动窗口 + HashMap

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int sLen = s.length();
        int pLen = p.length();
        
        if (sLen < pLen) return result;
        
        // 统计 p 的字符频率
        Map<Character, Integer> pCount = new HashMap<>();
        for (char c : p.toCharArray()) {
            pCount.merge(c, 1, Integer::sum);
        }
        
        // 窗口字符频率
        Map<Character, Integer> windowCount = new HashMap<>();
        
        // 初始化第一个窗口
        for (int i = 0; i < pLen; i++) {
            windowCount.merge(s.charAt(i), 1, Integer::sum);
        }
        
        // 检查第一个窗口
        if (windowCount.equals(pCount)) {
            result.add(0);
        }
        
        // 滑动窗口
        for (int i = pLen; i < sLen; i++) {
            // 加入右边的字符
            windowCount.merge(s.charAt(i), 1, Integer::sum);
            
            // 移除左边的字符
            char leftChar = s.charAt(i - pLen);
            int leftCount = windowCount.get(leftChar) - 1;
            if (leftCount == 0) {
                windowCount.remove(leftChar);
            } else {
                windowCount.put(leftChar, leftCount);
            }
            
            // 检查是否匹配
            if (windowCount.equals(pCount)) {
                result.add(i - pLen + 1);
            }
        }
        
        return result;
    }
}
```

### 方法三：优化版（减少比较次数）

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int sLen = s.length();
        int pLen = p.length();
        
        if (sLen < pLen) return result;
        
        int[] pCount = new int[26];
        int[] windowCount = new int[26];
        
        for (char c : p.toCharArray()) {
            pCount[c - 'a']++;
        }
        
        // 记录有多少个字符频率匹配
        int matchCount = 0;
        
        for (int i = 0; i < sLen; i++) {
            // 加入右边的字符
            int rightIdx = s.charAt(i) - 'a';
            windowCount[rightIdx]++;
            
            if (windowCount[rightIdx] == pCount[rightIdx]) {
                matchCount++;
            } else if (windowCount[rightIdx] == pCount[rightIdx] + 1) {
                matchCount--;
            }
            
            // 如果窗口大小超过 pLen，移除左边的字符
            if (i >= pLen) {
                int leftIdx = s.charAt(i - pLen) - 'a';
                windowCount[leftIdx]--;
                
                if (windowCount[leftIdx] == pCount[leftIdx]) {
                    matchCount++;
                } else if (windowCount[leftIdx] == pCount[leftIdx] - 1) {
                    matchCount--;
                }
            }
            
            // 如果所有 26 个字符频率都匹配
            if (matchCount == 26) {
                result.add(i - pLen + 1);
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

**方法一：数组计数**
- 时间复杂度：O(n)，n 是字符串 s 的长度
  - 滑动窗口遍历一次
  - 数组比较是 O(26) = O(1)
- 空间复杂度：O(1)，固定 26 个字母

**方法二：HashMap**
- 时间复杂度：O(n)
- 空间复杂度：O(1)，最多 26 个不同字母

**方法三：优化版**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 `s = "cbaebabacd", p = "abc"` 为例：

```
p = "abc" 的字符频率：
a: 1, b: 1, c: 1

滑动窗口过程：
窗口1: "cba" -> {c:1, b:1, a:1} ✓ 匹配，索引0
窗口2: "bae" -> {b:1, a:1, e:1} ✗
窗口3: "aeb" -> {a:1, e:1, b:1} ✗
窗口4: "eba" -> {e:1, b:1, a:1} ✗
窗口5: "bab" -> {b:2, a:1} ✗
窗口6: "aba" -> {a:2, b:1} ✗
窗口7: "bac" -> {b:1, a:1, c:1} ✓ 匹配，索引6
窗口8: "acd" -> {a:1, c:1, d:1} ✗

结果：[0, 6]
```

## 关键点总结

1. **滑动窗口**：固定大小的窗口，O(1) 时间移动
2. **字符频率**：使用数组或 HashMap 记录频率
3. **窗口更新**：加入右边字符，移除左边字符
4. **快速比较**：int[26] 数组比较比 HashMap 更快
5. **优化技巧**：用 matchCount 减少比较次数

## 易错点

1. **窗口大小**：窗口大小固定为 `pLen`
2. **索引计算**：起始索引是 `i - pLen + 1`
3. **初始窗口**：要先处理第一个窗口
4. **HashMap 删除**：频率为 0 的键要删除，否则 equals() 比较会失败
5. **边界情况**：s 比 p 短时直接返回空列表
