## 题目描述

给定数组 `colors`（值为 1、2 或 3）和查询 `queries`，每个查询包含索引 `i` 和颜色 `c`，返回从索引 `i` 到目标颜色 `c` 的最短距离，找不到返回 -1。

**示例：**
```
输入: colors = [1,1,2,1,3,2,2,3,3], queries = [[1,3],[2,2],[6,1]]
输出: [3,0,3]
```

## 解题思路

DP 预处理：双向扫描数组，`dist[i][c]` 存储位置 i 到颜色 c 的最短距离。从左到右和从右到左各扫描一次，每个查询 O(1) 回答。

## Java 代码实现

```java
class Solution {
    public List<Integer> shortestDistanceColor(int[] colors, int[][] queries) {
        int n = colors.length;
        int INF = n + 1;
        
        // dist[i][c] = 位置i到颜色c的最短距离
        int[][] dist = new int[n][4];
        for (int[] row : dist) Arrays.fill(row, INF);
        
        // 从左向右扫描
        for (int i = 0; i < n; i++) {
            dist[i][colors[i]] = 0;
            if (i > 0) {
                for (int c = 1; c <= 3; c++) {
                    dist[i][c] = Math.min(dist[i][c], dist[i - 1][c] + 1);
                }
            }
        }
        
        // 从右向左扫描
        for (int i = n - 2; i >= 0; i--) {
            for (int c = 1; c <= 3; c++) {
                dist[i][c] = Math.min(dist[i][c], dist[i + 1][c] + 1);
            }
        }
        
        // 处理查询
        List<Integer> result = new ArrayList<>();
        for (int[] q : queries) {
            int d = dist[q[0]][q[1]];
            result.add(d >= INF ? -1 : d);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)，预处理 O(n)，每次查询 O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **双向扫描**：从左到右和从右到左各扫描一次
2. **INF 初始化**：用 n+1 代替 Integer.MAX_VALUE 避免溢出
3. **颜色只有3种**：数组比哈希表高效
4. **当前颜色距离为0**：`dist[i][colors[i]] = 0`
