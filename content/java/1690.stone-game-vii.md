## 题目描述

Alice 和 Bob 轮流移除最左或最右的石头并获得**剩余**石头得分之和。双方最优策略下，返回 Alice 和 Bob 得分的最大差值。

## 解题思路

**区间 DP：** `dp[i][j]` 为在 `stones[i..j]` 中当前玩家比对手多得的最大分数。移除左端得 `sum(i+1,j) - dp[i+1][j]`，移除右端得 `sum(i,j-1) - dp[i][j-1]`，取最大值。用前缀和 O(1) 计算区间和。

## Java 代码实现

```java
class Solution {
    public int stoneGameVII(int[] stones) {
        int n = stones.length;
        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];

        int[][] dp = new int[n][n];
        // 从短区间到长区间递推
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                // 移除左端 stones[i]，获得 sum(i+1, j)
                int removeLeft = (prefix[j + 1] - prefix[i + 1]) - dp[i + 1][j];
                // 移除右端 stones[j]，获得 sum(i, j-1)
                int removeRight = (prefix[j] - prefix[i]) - dp[i][j - 1];
                dp[i][j] = Math.max(removeLeft, removeRight);
            }
        }
        return dp[0][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 状态设计：当前玩家与对手的得分差（而非各自绝对得分）
2. `dp[i][j] = max(rangeSum(i+1,j) - dp[i+1][j], rangeSum(i,j-1) - dp[i][j-1])`
3. 区间 DP 先枚举长度，再枚举左端点
