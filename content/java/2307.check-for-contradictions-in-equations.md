## 题目描述

给定一组除法方程A/B=value，判断是否存在矛盾。

## 解题思路

带权并查集：每个节点记录与根的比值。合并时若已在同一集合则检查比值是否一致，不一致则矛盾。

## Java 代码实现

```java
class Solution {
    private Map<String, String> parent = new HashMap<>();
    private Map<String, Double> weight = new HashMap<>();

    public boolean checkContradictions(List<List<String>> equations, double[] values) {
        for (int i = 0; i < equations.size(); i++) {
            String a = equations.get(i).get(0);
            String b = equations.get(i).get(1);
            double val = values[i];
            if (union(a, b, val)) return true;
        }
        return false;
    }

    private String find(String x) {
        if (!parent.containsKey(x)) {
            parent.put(x, x);
            weight.put(x, 1.0);
        }
        if (!parent.get(x).equals(x)) {
            String root = find(parent.get(x));
            weight.put(x, weight.get(x) * weight.get(parent.get(x)));
            parent.put(x, root);
        }
        return parent.get(x);
    }

    // 返回true表示矛盾
    private boolean union(String x, String y, double val) {
        String rx = find(x);
        String ry = find(y);
        if (rx.equals(ry)) {
            // x/rx = weight[x], y/ry = weight[y]
            // x/y = weight[x] / weight[y]
            return Math.abs(weight.get(x) / weight.get(y) - val) > 1e-5;
        }
        // 将ry挂到rx
        parent.put(ry, rx);
        weight.put(ry, weight.get(x) / (weight.get(y) * val));
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * alpha(N))
- **空间复杂度**：O(N)

## 关键点总结

1. **带权并查集**：权值表示节点与根的比值
2. **路径压缩时累乘权值**
3. **浮点比较容差1e-5**
