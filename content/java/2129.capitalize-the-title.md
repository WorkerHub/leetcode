## 题目描述

给定标题字符串title，长度<=2的单词全小写，其余单词首字母大写其余小写。

## 解题思路

按空格分割单词，根据长度决定大小写形式再拼接。

## Java 代码实现

```java
class Solution {
    public String capitalizeTitle(String title) {
        String[] words = title.split(" ");
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < words.length; i++) {
            if (i > 0) sb.append(' ');
            String word = words[i].toLowerCase();
            if (word.length() <= 2) {
                sb.append(word);
            } else {
                sb.append(Character.toUpperCase(word.charAt(0)));
                sb.append(word.substring(1));
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分割处理**：按空格split后逐词处理
2. **长度判断**：<=2全小写，>2首字母大写
3. **先toLowerCase**：统一转小写再处理首字母
