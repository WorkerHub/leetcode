## 题目描述

统计num的所有长度为k的子字符串中能整除num的个数。

## 解题思路

将num转字符串，滑动窗口枚举所有长度k的子串，转整数后检查是否整除num（0不能整除）。

## Java 代码实现

```java
class Solution {
    public int divisorSubstrings(int num, int k) {
        String s = String.valueOf(num);
        int count = 0;
        for (int i = 0; i <= s.length() - k; i++) {
            int sub = Integer.parseInt(s.substring(i, i + k));
            if (sub != 0 && num % sub == 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * k)，N为位数
- **空间复杂度**：O(N)

## 关键点总结

1. **子串转整数**：注意前导零转为0
2. **0不能作除数**：需要特判
3. **检查整除**：num % sub == 0
