## 题目描述

给定由数字字符组成的字符串 `num`，统计其排列中奇数下标数字之和等于偶数下标数字之和的排列数量，结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final int MOD = 1_000_000_007;

    public int countBalancedPermutations(String num) {
        int n = num.length();
        int total = 0;
        int[] cnt = new int[10];
        for (char c : num.toCharArray()) {
            cnt[c - '0']++;
            total += c - '0';
        }
        if (total % 2 != 0) return 0;

        int target = total / 2;
        int oddLen = (n + 1) / 2; // 奇数位个数（1-indexed 奇数位）

        // dp[j][s]: 已选 j 个数字放奇数位，这 j 个数字之和为 s 的方案数
        long[][] dp = new long[oddLen + 1][target + 1];
        dp[0][0] = 1;

        for (int d = 0; d <= 9; d++) {
            if (cnt[d] == 0) continue;
            // 逆序枚举防止重复选取
            for (int take = cnt[d]; take >= 1; take--) {
                long comb = combination(cnt[d], take);
                for (int j = oddLen; j >= take; j--) {
                    for (int s = target; s >= d * take; s--) {
                        dp[j][s] = (dp[j][s] + dp[j - take][s - d * take] * comb) % MOD;
                    }
                }
            }
        }

        long result = dp[oddLen][target];
        result = result * factorial(oddLen) % MOD;
        result = result * factorial(n - oddLen) % MOD;
        for (int d = 0; d <= 9; d++) {
            result = result * modInverse(factorial(cnt[d]), MOD) % MOD;
        }

        return (int) result;
    }

    private long factorial(int n) {
        long res = 1;
        for (int i = 2; i <= n; i++) res = res * i % MOD;
        return res;
    }

    private long modInverse(long a, long mod) {
        return modPow(a, mod - 2, mod);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }

    private long combination(int n, int k) {
        if (k > n) return 0;
        long res = 1;
        for (int i = 0; i < k; i++) {
            res = res * (n - i) % MOD;
            res = res * modInverse(i + 1, MOD) % MOD;
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * target * 10)，DP 状态数 × 数字种类
- 空间复杂度：O(n * target)

## 关键点总结

1. 总和为奇数时直接返回 0
2. 多重背包 DP 统计奇数位选取方案，再乘以排列数
3. 重复数字用组合数 C(c, take) 处理，最终除以各数字阶乘
