## 题目描述

Alice 和 Bob 在阶为 n 的斐波那契树上轮流操作（Alice 先手），每次可移除任意一棵子树，无法操作者输，问 Alice 是否必赢。

## 解题思路

通过博弈论分析（Sprague-Grundy 定理）打表验证规律：n=0 时先手必赢，n 为奇数时先手必赢，n 为正偶数时先手必输。

## Java 代码实现

### 方法一：数学规律（推荐）

```java
class Solution {
    public boolean findGameWinner(int n) {
        // 规律：n=0 或 n为奇数时Alice赢，n为正偶数时Alice输
        if (n == 0) return true;
        return n % 2 == 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 斐波那契树博弈本质是 Nim 类博弈，用 Sprague-Grundy 定理分析
2. 打表规律：n=0 先手赢，n 为奇数先手赢，n 为正偶数先手输
3. n=0 特殊处理：只有一个节点，先手取走必赢
