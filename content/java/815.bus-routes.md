## 题目描述

给你一个数组 `routes`，表示一系列公交线路，其中每个 `routes[i]` 表示一条公交线路，第 `i` 辆公交车将会在上面循环行驶。

现在从 `source` 车站出发（初始时不在公交车上），要前往 `target` 车站。期间仅可乘坐公交车。

求出 **最少乘坐的公交车数量**。如果不可能到达终点车站，返回 `-1`。

**示例 1:**
```
输入: routes = [[1,2,7],[3,6,7]], source = 1, target = 6
输出: 2
解释: 最优策略是先乘坐第一辆公交车到达车站 7, 然后乘坐第二辆公交车到车站 6。
```

**示例 2:**
```
输入: routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]], source = 15, target = 12
输出: -1
```

**提示:**
- `1 <= routes.length <= 500`
- `1 <= routes[i].length <= 10^5`
- `routes[i]` 中的所有值 **互不相同**
- `sum(routes[i].length) <= 10^5`
- `0 <= routes[i][j] < 10^6`
- `0 <= source, target < 10^6`

## 解题思路

这是一道图的BFS问题。关键是将问题转化为**公交车之间的转换**，而不是站点之间的转换。

**核心思想：**
1. 建立站点到公交车的映射
2. BFS 搜索公交车，而不是站点
3. 每次换乘公交车，步数加 1

## Java 代码实现

### 方法一：BFS（推荐）

```java
import java.util.*;

class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) return 0;

        // 建立站点到公交车的映射
        Map<Integer, List<Integer>> stopToBuses = new HashMap<>();
        for (int bus = 0; bus < routes.length; bus++) {
            for (int stop : routes[bus]) {
                stopToBuses.computeIfAbsent(stop, k -> new ArrayList<>()).add(bus);
            }
        }

        // BFS：搜索公交车
        Set<Integer> visitedBuses = new HashSet<>();
        Set<Integer> visitedStops = new HashSet<>();
        Queue<int[]> queue = new ArrayDeque<>();  // [当前站点, 乘坐公交车数]

        queue.offer(new int[]{source, 0});
        visitedStops.add(source);

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int stop = cur[0], busesTaken = cur[1];

            // 遍历当前站点的所有公交车
            for (int bus : stopToBuses.getOrDefault(stop, Collections.emptyList())) {
                if (visitedBuses.contains(bus)) continue;
                visitedBuses.add(bus);

                // 遍历这辆公交车的所有站点
                for (int nextStop : routes[bus]) {
                    if (nextStop == target) return busesTaken + 1;

                    if (!visitedStops.contains(nextStop)) {
                        visitedStops.add(nextStop);
                        queue.offer(new int[]{nextStop, busesTaken + 1});
                    }
                }
            }
        }

        return -1;
    }
}
```

### 方法二：按层 BFS（优化版本）

```java
import java.util.*;

class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) return 0;

        // 建立映射
        Map<Integer, List<Integer>> stopToBuses = new HashMap<>();
        for (int i = 0; i < routes.length; i++) {
            for (int stop : routes[i]) {
                stopToBuses.computeIfAbsent(stop, k -> new ArrayList<>()).add(i);
            }
        }

        // BFS
        Queue<Integer> queue = new ArrayDeque<>();
        Set<Integer> visitedStops = new HashSet<>();
        Set<Integer> visitedBuses = new HashSet<>();
        queue.offer(source);
        visitedStops.add(source);
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int stop = queue.poll();

                for (int bus : stopToBuses.getOrDefault(stop, Collections.emptyList())) {
                    if (visitedBuses.contains(bus)) continue;
                    visitedBuses.add(bus);

                    for (int nextStop : routes[bus]) {
                        if (nextStop == target) return steps;
                        if (!visitedStops.contains(nextStop)) {
                            visitedStops.add(nextStop);
                            queue.offer(nextStop);
                        }
                    }
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × S)，N 是公交车数量，S 是站点总数
- **空间复杂度**：O(N × S)

## 关键点总结

1. **问题转化**：搜索公交车而非站点
2. **双向映射**：站点到公交车的映射很关键
3. **避免重复**：同时标记访问过的站点和公交车
4. **BFS层次**：每一层代表一次换乘

## 易错点

1. **起点终点相同**：需要特判
2. **重复访问**：必须标记访问过的公交车和站点
3. **步数计算**：每换一辆公交车才加 1
