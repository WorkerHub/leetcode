## 题目描述

有 `n` 节点的满二叉树（根为 1，节点 v 的子节点为 2v 和 2v+1），初始所有节点值为 0。给你 `queries` 数组，每次查询将以指定节点为根的子树所有节点取反，返回所有操作后值为 1 的节点数目。

## 解题思路

节点 `u` 的最终值取决于祖先路径上被查询的总次数奇偶性。用哈希表统计每个查询节点的查询次数，然后 DFS 从根向叶子传递累计翻转次数，奇数次即为值 1 的节点。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int n;
    private Map<Integer, Integer> queryCount;
    private int ans;

    public int numberOfNodes(int n, int[] queries) {
        this.n = n;
        this.ans = 0;
        queryCount = new HashMap<>();
        for (int q : queries) {
            queryCount.merge(q, 1, Integer::sum);
        }
        dfs(1, 0);
        return ans;
    }

    // DFS 传递累计翻转次数
    private void dfs(int node, int flips) {
        if (node > n) return;
        flips += queryCount.getOrDefault(node, 0);
        if (flips % 2 == 1) ans++;
        dfs(2 * node, flips);     // 左子节点
        dfs(2 * node + 1, flips); // 右子节点
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)
- **空间复杂度**：O(n + q)

## 关键点总结

1. 节点最终值 = 祖先路径上所有 query 次数之和的奇偶性
2. DFS 从上到下传递翻转次数，O(n) 完成所有节点判断
3. 满二叉树中，节点 v 的子节点为 2v 和 2v+1
