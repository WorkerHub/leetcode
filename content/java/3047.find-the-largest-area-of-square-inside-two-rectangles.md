## 题目描述

给你两个二维整数数组 `bottomLeft` 和 `topRight` 分别表示 n 个矩形的左下角和右上角坐标，返回任意两个矩形交集内可放置的最大正方形面积，若无交集返回 0。

## 解题思路

枚举所有矩形对，计算交集区域（左下角取 max，右上角取 min），若交集合法则最大正方形边长为 `min(宽, 高)`。

## Java 代码实现

```java
class Solution {
    public long largestSquareInsideTwoRectangles(int[][] bottomLeft, int[][] topRight) {
        int n = bottomLeft.length;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 计算两矩形的交集区域
                int ix1 = Math.max(bottomLeft[i][0], bottomLeft[j][0]);
                int iy1 = Math.max(bottomLeft[i][1], bottomLeft[j][1]);
                int ix2 = Math.min(topRight[i][0], topRight[j][0]);
                int iy2 = Math.min(topRight[i][1], topRight[j][1]);
                // 交集有效则计算最大正方形面积
                if (ix1 < ix2 && iy1 < iy2) {
                    long side = Math.min(ix2 - ix1, iy2 - iy1);
                    ans = Math.max(ans, side * side);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，枚举所有矩形对
- **空间复杂度**：O(1)

## 关键点总结

1. 两矩形交集 = 坐标分量取 max（左下）和 min（右上）
2. 交集有效条件：`ix1 < ix2` 且 `iy1 < iy2`（严格小于）
3. 交集内最大正方形边长 = `min(宽, 高)`，返回面积（边长的平方）
