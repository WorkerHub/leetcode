## 题目描述

二维字符网格中判断是否存在相同值形成的环（长度至少 4，不能直接回头）。

**示例：**
```
输入：grid = [["a","a","a","a"],["a","b","b","a"],["a","b","b","a"],["a","a","a","a"]]
输出：true
```

## 解题思路

并查集：遍历每个格子，对右边和下面的相同值格子做 union，若已在同一集合则有环。

## Java 代码实现

```java
class Solution {
    private int[] parent, rank;
    
    public boolean containsCycle(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        parent = new int[m * n];
        rank = new int[m * n];
        for (int i = 0; i < m * n; i++) parent[i] = i;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 只看右边和下面
                if (j + 1 < n && grid[i][j] == grid[i][j + 1]) {
                    if (!union(i * n + j, i * n + j + 1)) return true;
                }
                if (i + 1 < m && grid[i][j] == grid[i + 1][j]) {
                    if (!union(i * n + j, (i + 1) * n + j)) return true;
                }
            }
        }
        return false;
    }
    
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    
    private boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // 已联通，有环
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N × α(M×N))
- **空间复杂度**：O(M × N)

## 关键点总结

1. **并查集检测环**：union 时若已在同一集合则有环
2. **只看右和下**：避免重复处理边
3. **相同值约束**：只对相同字符的相邻格子做 union
