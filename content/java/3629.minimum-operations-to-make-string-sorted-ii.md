## 题目描述

给定字符串 `s`，每次操作将最长严格递减后缀反转并追加到末尾，返回使字符串变为字典序最大排列所需的最小操作次数（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int makeStringSorted(String s) {
        int n = s.length();
        long[] fact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;

        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        // 初始分母的逆元：prod(freq[c]!)
        long invDenom = 1;
        for (int cnt : freq) invDenom = invDenom * modpow(fact[cnt], MOD - 2) % MOD;

        long ans = 0;
        int remaining = n;
        for (char c : s.toCharArray()) {
            int ci = c - 'a';
            // 统计比当前字符小的字符总数
            long smaller = 0;
            for (int j = 0; j < ci; j++) smaller += freq[j];
            // 当前位置选更小字符的排列数
            long perms = fact[remaining - 1] * invDenom % MOD;
            ans = (ans + smaller % MOD * perms) % MOD;

            // 更新：去掉一个字符 c，分母缩小 freq[c]!/(freq[c]-1)! = freq[c]，逆元乘以 freq[c]
            invDenom = invDenom * freq[ci] % MOD;
            freq[ci]--;
            remaining--;
        }
        return (int) ans;
    }

    private long modpow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，遍历每个字符时统计更小字符数
- 空间复杂度：O(26)

## 关键点总结

1. 操作次数等于当前排列在所有排列中的字典序位置（从0起）
2. 逐位统计比当前字符小的个数乘以剩余全排列数，累加即可
3. 有重复字符时全排列数需除以各字符频率的阶乘，用模逆元处理
