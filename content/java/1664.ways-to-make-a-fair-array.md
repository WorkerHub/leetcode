## 题目描述

从整数数组 `nums` 中删除恰好一个元素，若剩余数组奇数下标和等于偶数下标和（**公平数组**），统计满足条件的删除方案数。

## 解题思路

删除第 i 个元素后，右侧所有元素奇偶性翻转。

新偶数位和 = 左边偶数和 + 右边原奇数和；新奇数位和 = 左边奇数和 + 右边原偶数和。

维护前缀偶数和/奇数和，实时更新总和即可。

## Java 代码实现

```java
class Solution {
    public int waysToMakeFair(int[] nums) {
        int totalEven = 0, totalOdd = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i % 2 == 0) totalEven += nums[i];
            else totalOdd += nums[i];
        }

        int result = 0;
        int prefixEven = 0, prefixOdd = 0;

        for (int i = 0; i < nums.length; i++) {
            // 从总和中去掉当前元素的贡献（后缀和）
            if (i % 2 == 0) totalEven -= nums[i];
            else totalOdd -= nums[i];

            // 删除 i 后：新偶数位和 = 左偶 + 右原奇；新奇数位和 = 左奇 + 右原偶
            int newEven = prefixEven + totalOdd;
            int newOdd = prefixOdd + totalEven;

            if (newEven == newOdd) result++;

            // 更新前缀和
            if (i % 2 == 0) prefixEven += nums[i];
            else prefixOdd += nums[i];
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 删除第 i 个元素后，右侧元素奇偶性完全翻转
2. 新偶数位和 = 左边偶数 + 右边原奇数
3. 用差值法在遍历时维护后缀和（先减去当前元素）
