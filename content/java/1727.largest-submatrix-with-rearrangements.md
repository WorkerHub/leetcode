## 题目描述

给你一个 0/1 矩阵 `matrix`，可以任意移动列的位置，返回包含全 1 的最大子矩阵面积。

## 解题思路

先计算每个位置向上连续 1 的个数（柱高），然后对每行的高度数组降序排序，枚举子矩阵宽度：宽度为 `j+1` 时，最小高度为排序后第 `j` 个元素，面积 = `(j+1) * heights[j]`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int largestSubmatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;

        // 计算每列的向上连续 1 的个数
        for (int i = 1; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 1) {
                    matrix[i][j] += matrix[i - 1][j];
                }
            }
        }

        int ans = 0;
        for (int i = 0; i < m; i++) {
            // 复制当前行并降序排序
            int[] heights = matrix[i].clone();
            Arrays.sort(heights);
            // 枚举宽度（排序后从大到小遍历）
            for (int j = n - 1; j >= 0; j--) {
                int h = heights[j];
                if (h == 0) break; // 高度为 0 后面都是 0，提前退出
                int width = n - j; // 当前宽度
                ans = Math.max(ans, width * h);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 向上连续 1 的个数转化为柱状图问题
2. 列可以任意排列，因此对每行高度降序排序后贪心取最优面积
