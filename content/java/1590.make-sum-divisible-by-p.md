## 题目描述

移除最短子数组使剩余元素和能被 p 整除。不能移除全部，无解返回 -1。

**示例：**
```
输入：nums = [3,1,4,2], p = 6
输出：1
```

## 解题思路

前缀和+哈希表：需找最短子数组使其和 ≡ total%p (mod p)。哈希表存前缀余数的最新位置。

## Java 代码实现

```java
class Solution {
    public int minSubarray(int[] nums, int p) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;
        int r = (int)(total % p);
        if (r == 0) return 0;
        
        // 哈希表：前缀和余数 -> 最后出现位置
        Map<Integer, Integer> lastSeen = new HashMap<>();
        lastSeen.put(0, -1);
        int prefix = 0, ans = n;
        
        for (int i = 0; i < n; i++) {
            prefix = (int)((prefix + (long)nums[i]) % p);
            int target = (prefix - r + p) % p;
            if (lastSeen.containsKey(target)) {
                ans = Math.min(ans, i - lastSeen.get(target));
            }
            lastSeen.put(prefix, i);
        }
        return ans < n ? ans : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **目标**：找子数组和 ≡ total%p (mod p)
2. **哈希表存最新位置**：因为要最短子数组
3. **负数取模**：(prefix - r + p) % p
