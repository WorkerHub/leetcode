## 题目描述

**超级丑数**是一个正整数，其所有质因数都在给定的质数数组 `primes` 中。

给你一个整数 `n` 和一个整数数组 `primes`，返回第 `n` 个**超级丑数**。

题目数据保证第 `n` 个超级丑数在**32-bit**带符号整数范围内。

**示例 1：**
```
输入：n = 12, primes = [2,7,13,19]
输出：32 
解释：给定长度为 4 的质数数组 primes = [2,7,13,19]，前 12 个超级丑数序列为：[1,2,4,7,8,13,14,16,19,26,28,32] 。
```

**示例 2：**
```
输入：n = 1, primes = [2,3,5]
输出：1
解释：1 不含质因数，因此它的所有质因数都在质数数组 primes = [2,3,5] 中。
```

**提示：**
- `1 <= n <= 10^5`
- `1 <= primes.length <= 100`
- `2 <= primes[i] <= 1000`
- 题目数据保证 `primes[i]` 是一个质数
- `primes` 中的所有值互不相同，且按**升序**排列

## 解题思路

这是 264 题（Ugly Number II）的扩展版，质因数从 [2,3,5] 扩展到任意质数数组。

### 核心思想：多路归并

类似于合并 K 个有序链表，我们需要从 K 个"生成序列"中选择最小值。

**K 个生成序列**：
- 第 1 个序列：1×primes[0], 2×primes[0], 4×primes[0], ...
- 第 2 个序列：1×primes[1], 2×primes[1], 4×primes[1], ...
- ...
- 第 K 个序列：1×primes[K-1], 2×primes[K-1], ...

**方法**：
1. **动态规划 + 多指针**：维护 K 个指针，每次选最小值
2. **最小堆**：用堆维护候选值

## Java 代码实现

### 方法一：动态规划 + 多指针（推荐）⭐

```java
class Solution {
    public int nthSuperUglyNumber(int n, int[] primes) {
        // dp[i] 表示第 i+1 个超级丑数
        int[] dp = new int[n];
        dp[0] = 1;

        int k = primes.length;
        // 为每个质数维护一个指针
        int[] pointers = new int[k];

        for (int i = 1; i < n; i++) {
            // 计算每个质数对应的候选值
            int minVal = Integer.MAX_VALUE;
            for (int j = 0; j < k; j++) {
                minVal = Math.min(minVal, dp[pointers[j]] * primes[j]);
            }

            // 选择最小值作为下一个丑数
            dp[i] = minVal;

            // 更新指针（可能有多个指针需要前进，避免重复）
            for (int j = 0; j < k; j++) {
                if (dp[pointers[j]] * primes[j] == minVal) {
                    pointers[j]++;
                }
            }
        }

        return dp[n - 1];
    }
}
```

### 方法二：最小堆

```java
import java.util.*;

class Solution {
    public int nthSuperUglyNumber(int n, int[] primes) {
        // 使用最小堆维护候选值
        PriorityQueue<Long> heap = new PriorityQueue<>();
        Set<Long> seen = new HashSet<>();

        heap.offer(1L);
        seen.add(1L);

        long ugly = 1;

        for (int i = 0; i < n; i++) {
            // 取出最小值
            ugly = heap.poll();

            // 生成新的候选值
            for (int prime : primes) {
                long newUgly = ugly * prime;
                if (!seen.contains(newUgly)) {
                    seen.add(newUgly);
                    heap.offer(newUgly);
                }
            }
        }

        return (int) ugly;
    }
}
```

### 方法三：优化的多指针

```java
class Solution {
    public int nthSuperUglyNumber(int n, int[] primes) {
        int[] dp = new int[n];
        dp[0] = 1;
        int[] pointers = new int[primes.length];

        for (int i = 1; i < n; i++) {
            // 计算候选值并找最小值
            int minVal = Integer.MAX_VALUE;
            for (int j = 0; j < primes.length; j++) {
                minVal = Math.min(minVal, dp[pointers[j]] * primes[j]);
            }
            dp[i] = minVal;

            // 更新所有等于最小值的指针
            for (int j = 0; j < primes.length; j++) {
                if (dp[pointers[j]] * primes[j] == minVal) {
                    pointers[j]++;
                }
            }
        }

        return dp[n - 1];
    }
}
```

### 方法四：带详细注释的版本

```java
class Solution {
    /**
     * 动态规划 + 多指针
     *
     * 思路：
     * 1. dp[i] 表示第 i+1 个超级丑数
     * 2. 每个质数 primes[j] 都有一个指针 pointers[j]
     * 3. 候选值：dp[pointers[j]] * primes[j]
     * 4. 选择最小的候选值作为下一个丑数
     * 5. 更新对应的指针
     */
    public int nthSuperUglyNumber(int n, int[] primes) {
        // 初始化
        int[] dp = new int[n];
        dp[0] = 1; // 第 1 个丑数是 1

        int k = primes.length;
        int[] pointers = new int[k]; // 每个质数的指针，初始都指向 dp[0]

        // 生成第 2 到第 n 个丑数
        for (int i = 1; i < n; i++) {
            // 计算每个质数的候选值，找到最小值
            int minVal = Integer.MAX_VALUE;
            for (int j = 0; j < k; j++) {
                // candidates[j] = dp[pointers[j]] * primes[j]
                minVal = Math.min(minVal, dp[pointers[j]] * primes[j]);
            }

            // 选择最小值
            dp[i] = minVal;

            // 更新指针
            // 注意：可能有多个候选值等于最小值，都要更新，避免重复
            for (int j = 0; j < k; j++) {
                if (dp[pointers[j]] * primes[j] == minVal) {
                    pointers[j]++;
                }
            }
        }

        return dp[n - 1];
    }
}
```

## 复杂度分析

**方法一（多指针）：**
- 时间复杂度：O(n × k)，其中 k 是 primes 的长度
- 空间复杂度：O(n + k)

**方法二（最小堆）：**
- 时间复杂度：O(n × k × log(n×k))
- 空间复杂度：O(n × k)

## 关键点总结

1. **多路归并**：类似合并 K 个有序链表
2. **多指针**：为每个质数维护一个指针
3. **去重**：可能有多个质数生成相同的丑数，都要更新指针
4. **初始值**：第 1 个丑数是 1
5. **选择最小值**：每次从 K 个候选值中选最小的

## 易错点

1. **指针更新**：所有等于最小值的指针都要更新，不是只更新一个
2. **初始化**：`dp[0] = 1`，`pointers` 全为 0
3. **边界情况**：`n = 1` 时直接返回 1
4. **溢出**：使用堆方法时候选值可能超过 int 范围，用 long 存储
