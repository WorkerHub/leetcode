## 题目描述

无向图有 n 个节点，所有边通行时间为 `time`，信号灯每 `change` 分钟切换，红灯期间须等待。从 1 出发求到达 n 的第二最短时间（严格大于最短时间）。

## 解题思路

BFS 允许每个节点被访问最多 2 次（记录最短和次短到达时间）。每次出发前检查是否在红灯期（`t/change` 为奇数），若是则等待到下一个绿灯时刻后再行进。

## Java 代码实现

### 方法一：BFS 记录前两次到达时间（推荐）

```java
import java.util.*;

class Solution {
    public int secondMinimum(int n, int[][] edges, int time, int change) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        int[] dist1 = new int[n + 1], dist2 = new int[n + 1];
        Arrays.fill(dist1, Integer.MAX_VALUE);
        Arrays.fill(dist2, Integer.MAX_VALUE);
        dist1[1] = 0;

        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{1, 0}); // {节点, 当前时间}

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int node = cur[0], curTime = cur[1];

            // 计算出发时间（等待红灯）
            int t = curTime;
            if ((t / change) % 2 == 1) {
                t = (t / change + 1) * change; // 等到下一个绿灯
            }
            int nextTime = t + time;

            for (int nei : graph.get(node)) {
                if (dist1[nei] == Integer.MAX_VALUE) {
                    dist1[nei] = nextTime;
                    queue.offer(new int[]{nei, nextTime});
                } else if (dist2[nei] == Integer.MAX_VALUE && nextTime > dist1[nei]) {
                    dist2[nei] = nextTime;
                    if (nei == n) return dist2[n];
                    queue.offer(new int[]{nei, nextTime});
                }
            }
        }
        return dist2[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(V + E)，每个节点最多处理 2 次
- 空间复杂度：O(V + E)

## 关键点总结

1. 每个节点最多到达 2 次，BFS 自然按时间层序处理
2. 红灯判断：`(t / change) % 2 == 1` 时等待到 `(t/change + 1) * change`
3. 次短时间必须严格大于最短时间
