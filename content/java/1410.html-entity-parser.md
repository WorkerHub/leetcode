## 题目描述

HTML 实体解析器 是一种特殊的解析器，它将 HTML 代码作为输入，并用字符本身替换掉所有这些特殊的字符实体。

HTML 里这些特殊字符和它们对应的字符实体包括：

| 字符 | 实体 |
|------|------|
| `"` | `&quot;` |
| `'` | `&apos;` |
| `&` | `&amp;` |
| `>` | `&gt;` |
| `<` | `&lt;` |
| `/` | `&frasl;` |

给你输入字符串 `text` ，实现一个 HTML 实体解析器，返回解析器解析后的结果。

**示例 1：**

```
输入：text = "&amp; is an HTML entity but &ambassador; is not."
输出："& is an HTML entity but &ambassador; is not."
```

**示例 2：**

```
输入：text = "and I quote: &quot;...&quot;"
输出："and I quote: \"...\""
```

**示例 3：**

```
输入：text = "Stay home! Practice on Leetcode :)"
输出："Stay home! Practice on Leetcode :)"
```

**提示：**

- `1 <= text.length <= 10^5`
- 字符串可能包含 256 个 ASCII 字符中的任意字符

## 解题思路

### 方法一：哈希表 + String.replace()（推荐）

建立一个从实体到字符的映射，然后依次替换。

**注意顺序：** `&amp;` 必须最后替换（或者先替换），否则会把其他实体中的 `&` 提前替换掉，导致实体识别失败。

正确顺序：先处理其他5个实体，最后处理 `&amp;`。

### 方法二：手动字符扫描

遍历字符串，遇到 `&` 时向后寻找 `;`，提取实体名称并查表替换。这是最"手工"的方法，但最清晰。

## Java 代码实现

### 方法一：哈希表 + String.replace()（推荐）

```java
class Solution {
    public String entityParser(String text) {
        // 定义实体到字符的映射
        // 注意：&amp; 必须放在最后替换，避免影响其他实体中的 &
        String[][] entities = {
            {"&quot;", "\""},
            {"&apos;", "'"},
            {"&gt;",   ">"},
            {"&lt;",   "<"},
            {"&frasl;", "/"},
            {"&amp;",  "&"},   // 必须最后替换
        };

        for (String[] pair : entities) {
            text = text.replace(pair[0], pair[1]);
        }

        return text;
    }
}
```

### 方法二：手动字符扫描（逐字符处理）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String entityParser(String text) {
        // 建立映射字典
        Map<String, String> mapping = new HashMap<>();
        mapping.put("&quot;",  "\"");
        mapping.put("&apos;",  "'");
        mapping.put("&amp;",   "&");
        mapping.put("&gt;",    ">");
        mapping.put("&lt;",    "<");
        mapping.put("&frasl;", "/");

        StringBuilder result = new StringBuilder();
        int i = 0;
        int n = text.length();

        while (i < n) {
            if (text.charAt(i) == '&') {
                // 向后找分号，最多看 7 个字符（最长实体 &frasl; 长7）
                int end = text.indexOf(';', i + 1);
                if (end != -1 && end - i <= 7) {
                    String entity = text.substring(i, end + 1);
                    if (mapping.containsKey(entity)) {
                        // 识别到合法实体，替换后跳过
                        result.append(mapping.get(entity));
                        i = end + 1;
                        continue;
                    }
                }
            }
            // 不是实体，直接添加当前字符
            result.append(text.charAt(i));
            i++;
        }

        return result.toString();
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| String.replace() | O(6 * n) = O(n) | O(n) |
| 手动扫描 | O(n) | O(n) |

其中 `n` 为字符串长度。

## 关键点总结

1. `&amp;` 必须最后替换（方法一），否则会引起连锁替换错误
2. 手动扫描用 `indexOf(';', i+1)` 找分号，并限制范围不超过 7 个字符
3. 最长实体 `&frasl;` 有 7 个字符，所以 `end - i <= 7`
4. Java 的 `String.replace()` 方法简洁有效，适合固定替换场景

## 易错点

1. 方法一中 `&amp;` 顺序错误：如果先替换 `&amp;`，会破坏字符串中其他位置的 `&` 开头的实体
2. 方法二中 `end - i <= 7` 的范围检查：防止匹配过长的非实体字符串
3. 实体 `&apos;` 是单引号 `'`，不是反引号
