## 题目描述

给你一个整数数组 `nums`，每步操作将最大值替换为第二大的值，返回使所有元素相等所需的操作次数。

## 解题思路

排序后，每遇到比前一个大的新值层数加一，每个元素需要「当前层数」步操作到达最小值。累加所有元素的层数即为答案。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int reductionOperations(int[] nums) {
        Arrays.sort(nums);
        int result = 0;
        int levels = 0; // 当前需要的层数

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) {
                levels++; // 遇到新值，层数加一
            }
            result += levels; // 当前元素需要 levels 步操作
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后，每遇到一个比前一个大的值，层数加一
2. 每个元素到达最小值需要「当前层数」步操作
3. 最小值层数为 0，不需要操作
