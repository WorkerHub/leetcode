## 题目描述

给你整数数组 `nums`，如果某元素出现次数超过子数组长度的一半则称为支配元素，找到最小有效分割下标（两个子数组都有支配元素）。

## Java 代码实现

```java
class Solution {
    public int minimumIndex(java.util.List<Integer> nums) {
        int n = nums.size();
        // Boyer-Moore 投票法找支配元素
        int dom = 0, cnt = 0;
        for (int x : nums) {
            if (cnt == 0) { dom = x; cnt = 1; }
            else if (x == dom) cnt++;
            else cnt--;
        }
        // 统计支配元素总频次
        int total = 0;
        for (int x : nums) if (x == dom) total++;

        // 枚举分割点
        int leftCnt = 0;
        for (int i = 0; i < n - 1; i++) {
            if (nums.get(i) == dom) leftCnt++;
            int rightCnt = total - leftCnt;
            int leftLen = i + 1, rightLen = n - i - 1;
            if (leftCnt * 2 > leftLen && rightCnt * 2 > rightLen) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. Boyer-Moore 投票法 O(n) 找到候选支配元素，再统计其真实频次
2. 枚举分割点，维护左侧支配元素计数，右侧 = total - leftCnt
3. 两侧都满足 `count * 2 > length` 时即为有效分割
