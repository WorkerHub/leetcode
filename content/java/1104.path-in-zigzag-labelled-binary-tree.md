## 题目描述

无限完全二叉树中，奇数行从左到右编号，偶数行从右到左编号。给定节点标号 label，返回从根到该节点的路径。

**示例：**
```
输入：label = 14
输出：[1,3,4,14]
```

## 解题思路

逐层向上追溯：对于偶数层的节点先镜像映射到正常位置，再除 2 得父节点，若父节点在偶数层再反向映射回去。

## Java 代码实现

```java
class Solution {
    public List<Integer> pathInZigZagTree(int label) {
        // 计算层数
        int level = 0;
        int temp = label;
        while (temp > 0) {
            level++;
            temp >>= 1;
        }

        List<Integer> path = new ArrayList<>();
        while (label >= 1) {
            path.add(label);
            // 当前层的范围
            int levelMin = 1 << (level - 1);
            int levelMax = (1 << level) - 1;

            // 偶数层需要镜像映射到正常位置
            if (level % 2 == 0) {
                label = levelMin + levelMax - label;
            }

            // 父节点（正常二叉树）
            label >>= 1;
            level--;

            // 如果父节点在偶数层，需要反向映射
            if (label > 0 && level % 2 == 0) {
                int parentMin = 1 << (level - 1);
                int parentMax = (1 << level) - 1;
                label = parentMin + parentMax - label;
            }
        }

        Collections.reverse(path);
        return path;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log label)
- **空间复杂度**：O(log label)

## 关键点总结

1. **镜像映射**：`mirror = levelMin + levelMax - label`
2. **双向映射**：先映射当前节点，找父节点后再映射父节点
3. **位运算求层数**：等同于 bit_length
