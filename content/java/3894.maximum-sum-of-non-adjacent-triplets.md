## 题目描述

从整数数组中选出三个互不相邻的元素（任意两个选出元素的下标之差绝对值 >= 2），返回最大总和；无法选出则返回 -1。

## 解题思路

滚动 DP：用 `prev2[k]` 和 `prev1[k]` 分别表示两步前和上一步中选了 k 个不相邻元素的最大和。对每个新元素 v，选 v 时从 `prev2[k-1]` 转移，不选则继承 `prev1[k]`。

## Java 代码实现

```java
class Solution {
    public long maximumSum(int[] nums) {
        long NEG_INF = Long.MIN_VALUE / 2;
        // prev2[k] = 两步之前选了 k 个不相邻元素的最大和
        // prev1[k] = 上一步选了 k 个不相邻元素的最大和
        long[] prev2 = {0, NEG_INF, NEG_INF, NEG_INF};
        long[] prev1 = {0, NEG_INF, NEG_INF, NEG_INF};

        for (int v : nums) {
            long[] curr = {0, NEG_INF, NEG_INF, NEG_INF};
            for (int k = 0; k < 4; k++) {
                // 不选当前元素：继承上一步状态
                curr[k] = prev1[k];
                // 选当前元素：从两步前的 k-1 个转移（保证不相邻）
                if (k >= 1 && prev2[k - 1] != NEG_INF) {
                    curr[k] = Math.max(curr[k], prev2[k - 1] + v);
                }
            }
            prev2 = prev1;
            prev1 = curr;
        }

        return prev1[3] != NEG_INF ? prev1[3] : -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，滚动数组

## 关键点总结

1. 选 k 个不相邻元素的 DP：`dp[k] = max(dp[k], dp_prev2[k-1] + v)`。
2. "不相邻"要求：选 nums[i] 时，前一个选的最晚在 nums[i-2]。
3. 用两个滚动变量 prev2 和 prev1 代替二维 DP，降低空间。
