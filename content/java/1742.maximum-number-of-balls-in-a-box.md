## 题目描述

球的编号范围为 `lowLimit` 到 `highLimit`，盒子编号为球各位数字之和。返回装球最多的盒子的球数。

## 解题思路

枚举每个球，计算各位数字之和作为盒子编号，用数组计数，最后返回最大值（最大盒子编号不超过 45）。

## Java 代码实现

```java
class Solution {
    public int countBalls(int lowLimit, int highLimit) {
        int[] boxes = new int[46]; // 最大各位数字之和为 45（99999）
        int maxCount = 0;

        for (int num = lowLimit; num <= highLimit; num++) {
            int s = 0, n = num;
            while (n > 0) {
                s += n % 10; // 逐位累加
                n /= 10;
            }
            boxes[s]++;
            maxCount = Math.max(maxCount, boxes[s]);
        }

        return maxCount;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((highLimit - lowLimit) * log(highLimit))
- **空间复杂度**：O(1)，盒子数固定

## 关键点总结

1. 各位数字之和作为盒子编号，最大为 45
2. 遍历时维护最大值，无需最后再扫描
