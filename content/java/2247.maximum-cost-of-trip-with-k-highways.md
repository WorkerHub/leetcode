## 题目描述

n个城市间有高速公路，找恰好经过k条边的最大过路费路径（可重复经过城市）。

## 解题思路

dp[step][city]表示走了step条边到达city的最大代价。从任意城市出发(cost=0)，每步枚举所有边转移。k<=50, n<=15，复杂度O(k*n*m)。

## Java 代码实现

```java
class Solution {
    public int maximumCost(int n, int[][] highways, int k) {
        // 建邻接表
        List<List<int[]>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] h : highways) {
            adj.get(h[0]).add(new int[]{h[1], h[2]});
            adj.get(h[1]).add(new int[]{h[0], h[2]});
        }

        // dp[city] = 当前步数到达city的最大代价
        long[] dp = new long[n];
        long INF = Long.MIN_VALUE / 2;
        Arrays.fill(dp, 0); // 从任意城市出发

        for (int step = 0; step < k; step++) {
            long[] ndp = new long[n];
            Arrays.fill(ndp, INF);
            for (int u = 0; u < n; u++) {
                if (dp[u] == INF) continue;
                for (int[] edge : adj.get(u)) {
                    ndp[edge[0]] = Math.max(ndp[edge[0]], dp[u] + edge[1]);
                }
            }
            dp = ndp;
        }

        long ans = INF;
        for (long v : dp) ans = Math.max(ans, v);
        return ans == INF ? -1 : (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * (n + m))
- **空间复杂度**：O(n)

## 关键点总结

1. **步数DP**：dp[step][city]，允许重复经过城市
2. **从任意起点出发**：初始所有城市代价为0
3. **不可达返回-1**：k步后所有城市都不可达时
