## 题目描述

给你包含 0 到 n-1 所有整数的数组 `nums`，每次操作可将任意元素移到空格（0 的位置）。返回将数组升序排列的最少操作次数。

## 解题思路

置换环分析：目标状态有两种——0 在位置 0（`[0,1,...,n-1]`）和 0 在末尾（`[1,2,...,n-1,0]`）。对每种目标，分析置换环：长度为 k 的环中若 0 在环内需 k-1 次操作，否则需 k+1 次操作（需额外移入 0）。取两种方案的最小值。

## Java 代码实现

```java
class Solution {
    public int sortArray(int[] nums) {
        int n = nums.length;
        // 方案 A: 目标 [0,1,...,n-1]
        int[] targetA = new int[n];
        for (int i = 0; i < n; i++) targetA[i] = i;
        // 方案 B: 目标 [1,2,...,n-1,0]
        int[] targetB = new int[n];
        for (int i = 0; i < n - 1; i++) targetB[i] = i + 1;
        targetB[n - 1] = 0;

        return Math.min(solve(nums, targetA), solve(nums, targetB));
    }

    private int solve(int[] nums, int[] target) {
        int n = nums.length;
        // want[v] = 值 v 的目标位置
        int[] want = new int[n];
        for (int i = 0; i < n; i++) want[target[i]] = i;

        // pos[v] = 值 v 的当前位置
        int[] pos = new int[n];
        for (int i = 0; i < n; i++) pos[nums[i]] = i;

        boolean[] visited = new boolean[n];
        int ops = 0;

        for (int v = 0; v < n; v++) {
            if (visited[v] || pos[v] == want[v]) {
                visited[v] = true;
                continue;
            }
            // 追踪置换环
            int cycleLen = 0;
            boolean hasZero = false;
            int cur = v;
            while (!visited[cur]) {
                visited[cur] = true;
                if (cur == 0) hasZero = true;
                cur = target[pos[cur]]; // 当前位置的目标值
                cycleLen++;
            }
            // 0 在环中：k-1 次；不在环中：k+1 次
            ops += hasZero ? cycleLen - 1 : cycleLen + 1;
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 置换环中 0 是操作的媒介：在环内则 k-1 次，不在则需 k+1 次（先移入 0）
2. 需要考虑两种目标状态（0 在头部或尾部），取最小值
3. 每个元素最多访问一次，O(n) 完成分析
