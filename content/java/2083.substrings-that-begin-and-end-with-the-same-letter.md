## 题目描述

统计以相同字母开头和结尾的子字符串数目。

## 解题思路

前缀计数：遍历时每遇到字符c，答案加上当前c已出现的次数（包含自身）。等价于每个字符出现cnt次贡献cnt*(cnt+1)/2。

## Java 代码实现

```java
class Solution {
    public long numberOfSubstrings(String s) {
        int[] count = new int[26];
        long ans = 0;
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
            ans += count[c - 'a']; // 与之前所有相同字符配对+自身
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀计数**：每遇到c加上当前计数
2. **公式等价**：cnt*(cnt+1)/2
3. **包含长度1子串**：单字符也满足
