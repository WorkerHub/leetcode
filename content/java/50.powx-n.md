## 题目描述

实现 pow(x, n)，即计算 `x` 的整数 `n` 次幂函数。

**示例 1：**
```
输入：x = 2.00000, n = 10
输出：1024.00000
```

**示例 2：**
```
输入：x = 2.10000, n = 3
输出：9.26100
```

**示例 3：**
```
输入：x = 2.00000, n = -2
输出：0.25000
解释：2^-2 = 1/2^2 = 1/4 = 0.25
```

**提示：**
- `-100.0 < x < 100.0`
- `-2^31 <= n <= 2^31-1`
- `n` 是一个整数
- 要么 `x` 不为零，要么 `n > 0`
- `-10^4 <= x^n <= 10^4`

## 解题思路

核心思想：快速幂（分治）

关键观察：
- x^n = (x^2)^(n/2) 当n为偶数
- x^n = x × (x^2)^((n-1)/2) 当n为奇数
- 负指数：x^(-n) = 1 / x^n

## Java 代码实现

### 方法一：快速幂（递归）

```java
class Solution {
    public double myPow(double x, int n) {
        // 使用 long 防止 n = -2^31 时取反溢出
        long N = n;
        if (N < 0) {
            x = 1 / x;
            N = -N;
        }
        return quickPow(x, N);
    }

    private double quickPow(double base, long exp) {
        if (exp == 0) {
            return 1.0;
        }

        double half = quickPow(base, exp / 2);

        if (exp % 2 == 0) {
            return half * half;
        } else {
            return half * half * base;
        }
    }
}
```

### 方法二：快速幂（迭代）

```java
class Solution {
    public double myPow(double x, int n) {
        // 使用 long 防止 n = -2^31 时取反溢出
        long N = n;
        if (N < 0) {
            x = 1 / x;
            N = -N;
        }

        double result = 1.0;
        double current = x;

        while (N > 0) {
            // 如果当前位是1，乘上当前的base
            if (N % 2 == 1) {
                result *= current;
            }

            // base 平方
            current *= current;
            // N 右移一位
            N /= 2;
        }

        return result;
    }
}
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(log n)
- 空间复杂度：
  - 递归 O(log n)
  - 迭代 O(1)

## 关键点总结

1. **快速幂**：将 O(n) 优化到 O(log n)
2. **负指数**：转换为倒数
3. **二进制思想**：n 的二进制表示决定如何组合

## 易错点

1. **整数溢出**：n = -2^31 时，取反会溢出 int，需用 long 存储
2. **奇偶判断**：奇数时要多乘一个 x
