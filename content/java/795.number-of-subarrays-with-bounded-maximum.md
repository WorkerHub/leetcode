## 题目描述

给定整数数组 nums 和两个整数 left、right，返回连续非空子数组的个数，使得子数组中最大元素在 [left, right] 范围内。

**示例：**
```
输入：nums = [2,1,4,3], left = 2, right = 3
输出：3（子数组 [2], [2,1], [3]）
```

## 解题思路

使用计数技巧：最大值 ≤ right 的子数组数 - 最大值 ≤ left-1 的子数组数 = 最大值在 [left, right] 的子数组数。

## Java 代码实现

```java
class Solution {
    public int numSubarrayBoundedMax(int[] nums, int left, int right) {
        return countAtMost(nums, right) - countAtMost(nums, left - 1);
    }

    // 统计最大值 <= bound 的子数组个数
    private int countAtMost(int[] nums, int bound) {
        int count = 0, cur = 0;
        for (int num : nums) {
            if (num <= bound) {
                cur++;
            } else {
                cur = 0;
            }
            count += cur;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **容斥原理**：atMost(right) - atMost(left-1)
2. **连续计数**：每个合法元素可以延续之前的子数组
3. **断裂重置**：遇到超界元素时计数归零
