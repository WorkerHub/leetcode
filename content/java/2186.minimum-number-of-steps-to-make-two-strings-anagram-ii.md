## 题目描述

两个字符串s和t，每步可在任一字符串追加一个字符，求使两者互为字母异位词的最少步数。

## 解题思路

统计两字符串每个字母的频次差，答案=所有|cnt_s[c]-cnt_t[c]|之和。

## Java 代码实现

```java
class Solution {
    public int minSteps(String s, String t) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;
        for (char c : t.toCharArray()) freq[c - 'a']--;
        
        int ans = 0;
        for (int f : freq) ans += Math.abs(f);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|s| + |t|)
- **空间复杂度**：O(1)

## 关键点总结

1. **频次差的绝对值之和**：s多的需往t追加，t多的需往s追加
2. **freq数组**：s中字符+1，t中字符-1
3. **O(1)额外空间**：只需26个字母的频率数组
