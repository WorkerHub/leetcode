## 题目描述

给定一个长度为 `n` 的字符串 `s`，其中 `s[i]` 是：
- `"D"` 意味着递减
- `"I"` 意味着递增

有效排列是对有 `n + 1` 个在 `[0, n]` 范围内的整数的一个排列 `perm`，使得对所有的 `i`：
- 如果 `s[i] == 'D'`，那么 `perm[i] > perm[i+1]`
- 如果 `s[i] == 'I'`，那么 `perm[i] < perm[i+1]`

返回有效排列 `perm` 的数量。答案可能很大，请返回对 `10^9 + 7` 取余后的结果。

**示例 1：**
```
输入：s = "DID"
输出：5
解释：
(0, 1, 2, 3) 的五个有效排列是：
(1, 0, 3, 2)
(2, 0, 3, 1)
(2, 1, 3, 0)
(3, 0, 2, 1)
(3, 1, 2, 0)
```

**示例 2：**
```
输入：s = "D"
输出：1
```

**提示：**
- n == s.length
- 1 <= n <= 200
- s[i] 为 'I' 或 'D'

## 解题思路

这是一道经典的动态规划问题。核心思想是：
1. 不需要关心具体的数字，只需要关心相对大小关系
2. 使用 DP 记录：前 i 个位置，第 i 个位置排名为 j 的方案数

**状态定义：**
- `dp[i][j]` 表示前 i+1 个数的排列中，第 i 个数在这 i+1 个数中排名第 j（从 0 开始）的方案数

**状态转移：**
- 如果 `s[i-1] == 'D'`（第 i-1 个位置需要递减）：
  - 说明 `perm[i-1] > perm[i]`
  - 新加入一个数后，原来排名 >= j 的数都要 +1
  - `dp[i][j] = sum(dp[i-1][k])` for k in [j, i-1]
- 如果 `s[i-1] == 'I'`（第 i-1 个位置需要递增）：
  - 说明 `perm[i-1] < perm[i]`
  - `dp[i][j] = sum(dp[i-1][k])` for k in [0, j-1]

**关键观察：**
- 每次加入新数时，可以调整所有数的排名，只要保持相对顺序
- 使用前缀和优化状态转移，避免重复计算

## Java 代码实现

### 方法一：动态规划 + 前缀和优化（推荐）

```java
class Solution {
    public int numPermsDISequence(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();

        // dp[j] 表示当前数排名第 j 的方案数
        int[] dp = new int[n + 1];
        dp[0] = 1; // 初始状态：一个数，排名第 0

        for (int idx = 0; idx < n; idx++) {
            int[] newDp = new int[n + 1];
            char c = s.charAt(idx);

            if (c == 'D') {
                // 从右往左累加前缀和
                int cumsum = 0;
                for (int j = idx; j >= 0; j--) {
                    cumsum = (cumsum + dp[j]) % MOD;
                    newDp[j] = cumsum;
                }
            } else { // c == 'I'
                // 从左往右累加前缀和
                int cumsum = 0;
                for (int j = 0; j <= idx; j++) {
                    newDp[j + 1] = cumsum;
                    cumsum = (cumsum + dp[j]) % MOD;
                }
            }

            dp = newDp;
        }

        // 求所有排名的总和
        int result = 0;
        for (int val : dp) {
            result = (result + val) % MOD;
        }
        return result;
    }
}
```

### 方法二：基础动态规划（O(n^3)，易理解）

```java
class Solution {
    public int numPermsDISequence(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();

        // dp[i][j] 表示前 i+1 个数中，第 i 个数排名第 j 的方案数
        int[][] dp = new int[n + 1][n + 1];
        dp[0][0] = 1; // 初始状态：一个数，排名第 0

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= i; j++) {
                if (s.charAt(i - 1) == 'D') {
                    // 递减：第 i-1 个数的排名要 >= j
                    for (int k = j; k < i; k++) {
                        dp[i][j] = (dp[i][j] + dp[i - 1][k]) % MOD;
                    }
                } else { // 'I'
                    // 递增：第 i-1 个数的排名要 < j
                    for (int k = 0; k < j; k++) {
                        dp[i][j] = (dp[i][j] + dp[i - 1][k]) % MOD;
                    }
                }
            }
        }

        // 最终答案是所有排名的总和
        int result = 0;
        for (int j = 0; j <= n; j++) {
            result = (result + dp[n][j]) % MOD;
        }
        return result;
    }
}
```

### 方法三：简化的前缀和版本

```java
class Solution {
    public int numPermsDISequence(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();

        int[] dp = new int[]{1}; // 初始状态

        for (int i = 0; i < n; i++) {
            int len = dp.length;
            int[] newDp = new int[len + 1];

            if (s.charAt(i) == 'I') {
                // dp[i][j] = sum(dp[i-1][:j])，从左到右累加
                for (int j = 0; j < len; j++) {
                    newDp[j + 1] = (newDp[j] + dp[j]) % MOD;
                }
            } else {
                // dp[i][j] = sum(dp[i-1][j:])，从右到左累加
                for (int j = len - 1; j >= 0; j--) {
                    newDp[j] = (newDp[j + 1] + dp[j]) % MOD;
                }
            }

            dp = newDp;
        }

        int result = 0;
        for (int val : dp) {
            result = (result + val) % MOD;
        }
        return result;
    }
}
```

## 复杂度分析

**方法一（优化 DP）：**
- 时间复杂度：O(n^2)，使用前缀和优化
- 空间复杂度：O(n)，滚动数组优化

**方法二（基础 DP）：**
- 时间复杂度：O(n^3)，三层循环
- 空间复杂度：O(n^2)，DP 数组

## 关键点总结

1. **抽象思维**：不关心具体数值，只关心相对排名
2. **状态设计**：用排名而不是具体值定义状态
3. **转移方程**：根据 D/I 的约束，确定排名的转移范围
4. **前缀和优化**：将 O(n) 的求和优化为 O(1)
5. **滚动数组**：每次只需要前一层的状态，可以空间优化

## 易错点

1. **排名范围**：第 i 个位置的排名范围是 [0, i]，有 i+1 种可能
2. **转移方向**：D 是从右往左累加，I 是从左往右累加
3. **数组长度**：每次加入新元素，长度会 +1
4. **取模操作**：每次加法后都要取模
5. **初始状态**：dp[0][0] = 1 或 dp = [1]
