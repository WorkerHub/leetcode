## 题目描述

统计数组中同时存在比它更小和比它更大元素的数量。

## 解题思路

等价于既不是最大值也不是最小值的元素数量。找出最大值和最小值后遍历统计。

## Java 代码实现

```java
class Solution {
    public int countElements(int[] nums) {
        int minVal = nums[0], maxVal = nums[0];
        for (int x : nums) {
            minVal = Math.min(minVal, x);
            maxVal = Math.max(maxVal, x);
        }
        if (minVal == maxVal) return 0;
        
        int count = 0;
        for (int x : nums) {
            if (x != minVal && x != maxVal) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **满足条件等价于非极值**：既不是最大也不是最小
2. **边界处理**：所有元素相等时min==max，答案为0
3. **O(N)时间O(1)空间**：两次遍历即可
