## 题目描述

给你一个字符串 `s`，请你按照单词在 `s` 中的出现顺序将它们全部竖向排列。

单词是仅由非空格字符组成的字符串。此外，请你消除每一行中的空尾随空格。

**示例 1：**

```
输入：s = "HOW ARE YOU"
输出：["HAY","OR","WEU"]
解释：每个单词都竖向排列。
 "HAY"
 "OR"
 "WEU"
```

**示例 2：**

```
输入：s = "TO BE OR NOT TO BE"
输出：["TBONTB","OEROOE","   T"]
解释：题目允许有多个空格，但必须消除末尾空格。
```

**示例 3：**

```
输入：s = "CONTEST IS COMING"
输出：["CIC","OSO","N M","T I","E N","S G","T"]
```

**提示：**

- `1 <= s.length <= 200`
- `s` 仅含大写英文字母和空格
- 题目数据保证两个单词之间只有一个空格

## 解题思路

**模拟过程：**

1. 将字符串按空格分割得到单词列表
2. 找到最长单词的长度 `max_len`，这决定了结果列表的长度
3. 对第 `i` 行（第 `i` 列）：取每个单词的第 `i` 个字符（不足长度的用空格补齐），拼接成字符串
4. 去掉每行末尾的空格

**直觉图解（s = "HOW ARE YOU"）：**

```
单词：HOW  ARE  YOU
      H    A    Y    -> "HAY"（第0行）
      O    R    O    -> "ORO"
      W    E    U    -> "WEU"（第2行）
```

## Java 代码实现

### 方法一：模拟（推荐）

```java
import java.util.*;

class Solution {
    public List<String> printVertically(String s) {
        String[] words = s.split(" ");
        int maxLen = 0;
        for (String word : words) {
            maxLen = Math.max(maxLen, word.length());
        }
        
        List<String> result = new ArrayList<>();
        for (int i = 0; i < maxLen; i++) {
            StringBuilder row = new StringBuilder();
            for (String word : words) {
                // 如果单词长度超过 i，取第 i 个字符，否则用空格填充
                if (i < word.length()) {
                    row.append(word.charAt(i));
                } else {
                    row.append(' ');
                }
            }
            // 去除末尾空格
            int end = row.length() - 1;
            while (end >= 0 && row.charAt(end) == ' ') end--;
            result.add(row.substring(0, end + 1));
        }
        
        return result;
    }
}
```

### 方法二：使用 StringBuilder.trimRight（简洁版）

```java
import java.util.*;

class Solution {
    public List<String> printVertically(String s) {
        String[] words = s.split(" ");
        int maxLen = 0;
        for (String word : words) {
            maxLen = Math.max(maxLen, word.length());
        }
        
        List<String> result = new ArrayList<>();
        for (int i = 0; i < maxLen; i++) {
            StringBuilder row = new StringBuilder();
            for (String word : words) {
                row.append(i < word.length() ? word.charAt(i) : ' ');
            }
            // 使用 stripTrailing() 去除末尾空格（Java 11+）
            result.add(row.toString().stripTrailing());
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为单词数，m 为最长单词长度
- **空间复杂度**：O(n * m)，结果列表的大小

## 关键点总结

1. 问题本质是矩阵转置：将"行=单词，列=字符位置"转换为"行=字符位置，列=单词"
2. 短单词的对应位置用空格补齐，再去掉末尾空格
3. 结果列表的行数等于最长单词的长度
4. Java 11+ 可以用 `String.stripTrailing()` 去除末尾空格

## 易错点

1. **只去末尾空格**：不能用 `trim()`（会去掉两端），应该只去末尾空格
2. **行数等于最长单词长度**：结果列表的行数由最长单词决定
3. **Java 字符串不可变**：修改字符串时要使用 `StringBuilder`
