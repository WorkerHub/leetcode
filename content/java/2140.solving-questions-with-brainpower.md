## 题目描述

考试按顺序做题，解决第i题得points分但跳过后brainpower道题，也可跳过。求最高分数。

## 解题思路

从右到左DP：dp[i]=max(dp[i+1], points[i]+dp[i+brainpower+1])。跳过或解决取最大值。

## Java 代码实现

```java
class Solution {
    public long mostPoints(int[][] questions) {
        int n = questions.length;
        long[] dp = new long[n + 1];
        
        for (int i = n - 1; i >= 0; i--) {
            int points = questions[i][0];
            int brainpower = questions[i][1];
            int next = Math.min(i + brainpower + 1, n);
            dp[i] = Math.max(dp[i + 1], points + dp[next]);
        }
        return dp[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **从右到左DP**：避免向前依赖
2. **两个选择**：跳过(dp[i+1])或解决(points+dp[next])
3. **边界处理**：next超出n时dp值为0
