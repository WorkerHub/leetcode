## 题目描述

k 个鸡蛋、n 层楼，求最坏情况下找到临界楼层 f 的最少操作次数。

**示例：**
```
输入：k = 2, n = 6
输出：3
```

## 解题思路

逆向 DP：dp[m][k] 表示 m 次操作、k 个鸡蛋最多能测多少层。递推式：dp[m][k] = dp[m-1][k-1] + dp[m-1][k] + 1。

## Java 代码实现

```java
class Solution {
    public int superEggDrop(int k, int n) {
        // dp[i] 表示 i 个鸡蛋在 m 次操作内能测多少层
        int[] dp = new int[k + 1];
        int m = 0;

        while (dp[k] < n) {
            m++;
            // 倒序更新避免覆盖
            for (int i = k; i >= 1; i--) {
                dp[i] = dp[i - 1] + dp[i] + 1;
            }
        }

        return m;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × log n)
- **空间复杂度**：O(k)

## 关键点总结

1. **逆向思维**：求次数能测多少层而非楼层需多少次
2. **递推公式**：碎了测下面 + 没碎测上面 + 当前层
3. **空间优化**：倒序更新一维数组
