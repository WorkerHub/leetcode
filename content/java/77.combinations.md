## 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按任何顺序返回答案。

**示例 1：**
```
输入：n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

**示例 2：**
```
输入：n = 1, k = 1
输出：[[1]]
```

**提示：**
- `1 <= n <= 20`
- `1 <= k <= n`

## 解题思路

核心思想：回溯

关键步骤：
1. 从start开始选择数字
2. 选择后递归处理剩余数字
3. 达到k个数时加入结果

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> result = new ArrayList<>();
        backtrack(n, k, 1, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int n, int k, int start, List<Integer> path, List<List<Integer>> result) {
        // 剪枝：剩余数字不够凑满k个
        if (path.size() + (n - start + 1) < k) {
            return;
        }

        if (path.size() == k) {
            // 找到一个合法组合，加入结果
            result.add(new ArrayList<>(path));
            return;
        }

        for (int i = start; i <= n; i++) {
            path.add(i);
            backtrack(n, k, i + 1, path, result);
            // 回溯，撤销选择
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(C(n,k) × k)
- 空间复杂度：O(k)

## 关键点总结

1. **回溯模板**：选择→递归→撤销
2. **剪枝优化**：剩余数字不够时提前返回
3. **去重**：start从i+1开始，避免重复

## 易错点

1. **复制列表**：加入结果时用 `new ArrayList<>(path)` 复制，不能直接加引用
2. **回溯撤销**：每次递归后要移除最后一个元素
