## 题目描述

找三元组(i,j,k)使prices[i]<prices[j]<prices[k]，最大化profits[i]+profits[j]+profits[k]。

## 解题思路

枚举中间元素j，用两个树状数组分别维护：左侧price<prices[j]的最大profit，右侧price>prices[j]的最大profit。

## Java 代码实现

```java
class Solution {
    private int[] tree;

    public int maxProfit(int[] prices, int[] profits) {
        int n = prices.length;
        int maxPrice = 0;
        for (int p : prices) maxPrice = Math.max(maxPrice, p);

        // 从左到右扫描，计算左侧最大profit
        int[] leftMax = new int[n];
        tree = new int[maxPrice + 2];
        Arrays.fill(tree, -1);
        Arrays.fill(leftMax, -1);
        for (int i = 0; i < n; i++) {
            // 查询price < prices[i]的最大profit
            leftMax[i] = query(prices[i] - 1);
            update(prices[i], profits[i]);
        }

        // 从右到左扫描，计算右侧最大profit
        int[] rightMax = new int[n];
        tree = new int[maxPrice + 2];
        Arrays.fill(tree, -1);
        Arrays.fill(rightMax, -1);
        for (int i = n - 1; i >= 0; i--) {
            // 查询price > prices[i]的最大profit（反向树状数组）
            rightMax[i] = querySuffix(prices[i] + 1, maxPrice);
            update(prices[i], profits[i]);
        }

        // 枚举中间元素
        int ans = -1;
        for (int j = 0; j < n; j++) {
            if (leftMax[j] >= 0 && rightMax[j] >= 0) {
                ans = Math.max(ans, leftMax[j] + profits[j] + rightMax[j]);
            }
        }
        return ans;
    }

    private void update(int i, int val) {
        for (; i < tree.length; i += i & (-i)) {
            tree[i] = Math.max(tree[i], val);
        }
    }

    private int query(int i) {
        int res = -1;
        for (; i > 0; i -= i & (-i)) {
            res = Math.max(res, tree[i]);
        }
        return res;
    }

    private int querySuffix(int l, int maxVal) {
        // 后缀最大值：查询[l, maxVal]范围用前缀技巧
        // 转化为反向BIT：用maxVal+1-price作为下标
        // 这里简化处理，直接用query(maxVal) 对比 query(l-1)不适用max
        // 改用从右到左建BIT，下标取反
        int res = -1;
        for (int i = tree.length - 1 - l + 1; i > 0; i -= i & (-i)) {
            res = Math.max(res, tree[i]);
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logM)，M为最大price
- **空间复杂度**：O(M)

## 关键点总结

1. **枚举中间元素**：左右分别求前缀/后缀最大值
2. **树状数组维护前缀max**：update取max而非加法
3. **右侧用反向BIT**：将下标翻转处理后缀查询
