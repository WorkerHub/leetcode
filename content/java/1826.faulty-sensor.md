## 题目描述

两个传感器其中一个跳过了一个数据点，判断哪个有故障（1或2），无法确定返回-1。

## 解题思路

找到第一个不同位置i，检查sensor1[i+1:]是否等于sensor2[i:n-1]（sensor1故障），反之亦然。

## Java 代码实现

```java
class Solution {
    public int badSensor(int[] sensor1, int[] sensor2) {
        int n = sensor1.length;
        int i = 0;
        while (i < n && sensor1[i] == sensor2[i]) i++;
        if (i >= n - 1) return -1;
        
        boolean s1Fault = true, s2Fault = true;
        for (int j = i; j < n - 1; j++) {
            if (sensor1[j + 1] != sensor2[j]) s1Fault = false;
            if (sensor2[j + 1] != sensor1[j]) s2Fault = false;
        }
        
        if (s1Fault && !s2Fault) return 1;
        if (s2Fault && !s1Fault) return 2;
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **找第一个差异点**：之后偏移一位比较
2. **两种情况都满足则返回-1**
3. **i到末尾才不同则无法确定**
