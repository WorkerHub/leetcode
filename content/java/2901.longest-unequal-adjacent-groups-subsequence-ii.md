## 题目描述

给你字符串数组 words 和整数数组 groups，选出最长子序列使相邻元素满足：groups 值不同、长度相同、汉明距离恰好为 1，返回对应的 words 列表。

## 解题思路

DP + 路径回溯：`dp[i]` 为以第 i 个单词结尾的最长合法子序列长度，`prev[i]` 记录前驱下标，最终从最大 dp 值回溯还原路径。

## Java 代码实现

```java
class Solution {
    public List<String> getWordsInLongestSubsequence(String[] words, int[] groups) {
        int n = words.length;
        int[] dp = new int[n];
        int[] prev = new int[n];
        Arrays.fill(dp, 1);
        Arrays.fill(prev, -1);

        for (int i = 1; i < n; i++) {
            for (int j = i - 1; j >= 0; j--) {
                if (groups[j] != groups[i]
                        && words[j].length() == words[i].length()
                        && hammingDistance(words[j], words[i]) == 1
                        && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    prev[i] = j;
                }
            }
        }

        // 找最大 dp 值对应的末尾下标
        int best = 0;
        for (int i = 1; i < n; i++) if (dp[i] > dp[best]) best = i;

        // 回溯路径
        List<String> result = new ArrayList<>();
        for (int idx = best; idx != -1; idx = prev[idx]) result.add(words[idx]);
        Collections.reverse(result);
        return result;
    }

    private int hammingDistance(String a, String b) {
        int diff = 0;
        for (int i = 0; i < a.length(); i++) {
            if (a.charAt(i) != b.charAt(i)) diff++;
            if (diff > 1) return diff; // 提前终止
        }
        return diff;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2 × L)，n 为单词数，L 为单词长度
- **空间复杂度**：O(n)

## 关键点总结

1. 三个约束同时检查：groups 不同、等长、汉明距离恰好为 1
2. prev 数组记录路径，最终 reverse 得到正序结果
3. 汉明距离计算提前终止（diff > 1 直接返回）
