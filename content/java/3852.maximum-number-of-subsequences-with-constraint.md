## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，统计满足以下条件的非空子序列数目（模 `10^9 + 7`）：子序列中任意相邻两个元素之差的绝对值不超过 `k`。

## 解题思路

使用树状数组（BIT）优化 DP：`dp[v]` 表示以值 v 结尾的合法子序列数。对每个 `nums[i] = v`，`dp[v] += sum(dp[v-k..v+k]) + 1`。树状数组将区间求和从 O(k) 优化到 O(log n)。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;
    private long[] tree;
    private int size;

    private void update(int i, long delta) {
        // 树状数组单点更新（下标从 1 开始）
        for (; i <= size; i += i & (-i)) {
            tree[i] = (tree[i] + delta) % MOD;
        }
    }

    private long query(int i) {
        // 树状数组前缀和查询
        long s = 0;
        for (; i > 0; i -= i & (-i)) {
            s = (s + tree[i]) % MOD;
        }
        return s;
    }

    private long rangeQuery(int l, int r) {
        if (l > r) return 0;
        return (query(r) - query(l - 1) + MOD) % MOD;
    }

    public long countSubsequences(int[] nums, int k) {
        int maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);

        size = maxVal;
        tree = new long[size + 1];
        long total = 0;

        for (int v : nums) {
            int lo = Math.max(1, v - k);
            int hi = Math.min(maxVal, v + k);
            // 以 v 结尾的新子序列数 = [v-k, v+k] 范围内 dp 之和 + 1
            long newCount = (rangeQuery(lo, hi) + 1) % MOD;
            update(v, newCount);
            total = (total + newCount) % MOD;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log max_val)
- 空间复杂度：O(max_val)，树状数组

## 关键点总结

1. DP 状态以值为键，每个元素可接在差 <= k 的已有子序列后面或单独成子序列（+1）。
2. 树状数组将区间求和从 O(k) 优化到 O(log n)。
3. 取模运算在每步加法和查询时都需要维护。
