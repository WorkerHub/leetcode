## 题目描述

给定整数数组 `nums`，每次操作可将任意元素改为任意整数，返回使数组变为连续（所有元素不同且最大最小差等于 n-1）所需的最少操作次数。

## 解题思路

目标数组为 `[x, x+1, ..., x+n-1]`，操作次数 = n - 保留的原始元素数。去重排序后，枚举每个元素作为起始值 x，用滑动窗口找 `[x, x+n-1]` 范围内的最多去重元素数。

## Java 代码实现

### 方法一：排序去重 + 滑动窗口（推荐）

```java
import java.util.*;

class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        // 去重并排序
        int[] unique = Arrays.stream(nums).distinct().sorted().toArray();
        int m = unique.length;

        int maxKeep = 0;
        int right = 0;

        for (int left = 0; left < m; left++) {
            long windowEnd = (long) unique[left] + n - 1;
            // 移动右指针找到窗口右边界
            while (right < m && unique[right] <= windowEnd) right++;
            maxKeep = Math.max(maxKeep, right - left);
        }

        return n - maxKeep;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 目标数组是 n 个连续不同整数，最优起始值是原数组某元素
2. 必须先**去重**再排序，重复元素最终只能保留一个
3. 窗口大小是 n（原数组长度），不是去重后的长度；注意 int 溢出用 long
