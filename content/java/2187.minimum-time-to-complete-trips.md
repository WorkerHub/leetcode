## 题目描述

多辆公交车并行运行，第i辆每趟耗时time[i]，求完成至少totalTrips趟行程的最少时间。

## 解题思路

二分答案：时间t内每辆车完成t/time[i]趟，总趟数单调递增。二分找最小满足条件的t。

## Java 代码实现

```java
class Solution {
    public long minimumTime(int[] time, int totalTrips) {
        long lo = 1;
        long hi = (long) Arrays.stream(time).min().getAsInt() * totalTrips;
        
        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (canFinish(time, mid, totalTrips)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
    
    private boolean canFinish(int[] time, long t, int totalTrips) {
        long trips = 0;
        for (int ti : time) {
            trips += t / ti;
            if (trips >= totalTrips) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * log(minTime * totalTrips))
- **空间复杂度**：O(1)

## 关键点总结

1. **答案单调性**：时间越长完成趟数越多
2. **可行性判断**：sum(t/time[i]) >= totalTrips
3. **提前返回优化**：trips达标后无需继续累加
