## 题目描述

给你正整数数组 `nums`，统计满足 `i < j < k` 且三个元素两两不同的三元组数目。

## 解题思路

枚举中间元素的值 v，利用乘法原理：左侧已遍历的元素中选不等于 v 的一个（prefix），从 v 的出现次数 c 中选一个，右侧剩余元素中选不等于 v 的一个（suffix），贡献为 `prefix * c * suffix`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int unequalTriplets(int[] nums) {
        // 统计各值出现次数
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : nums) count.merge(x, 1, Integer::sum);

        int ans = 0, prefix = 0, n = nums.length;
        for (int c : count.values()) {
            int suffix = n - prefix - c; // 不属于当前值的右侧元素数
            ans += prefix * c * suffix;
            prefix += c;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举中间值 v，贡献 = 左侧非 v 元素数 × v 的出现次数 × 右侧非 v 元素数
2. prefix 累积已处理的元素数，suffix 为剩余元素数减去当前值出现次数
3. 利用乘法原理，O(n) 完成统计
