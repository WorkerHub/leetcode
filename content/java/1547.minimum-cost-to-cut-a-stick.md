## 题目描述

长度为 n 的木棍，给定切割点数组 cuts。每次切割费用 = 被切木棍长度，求完成所有切割的最小总费用。

**示例：**
```
输入：n = 7, cuts = [1,3,4,5]
输出：16
```

## 解题思路

区间 DP：加入端点 0 和 n，dp[i][j] = 在 (cuts[i], cuts[j]) 内切割的最小费用。枚举第一刀位置 k。

## Java 代码实现

```java
class Solution {
    public int minCost(int n, int[] cuts) {
        // 加入端点并排序
        int[] c = new int[cuts.length + 2];
        c[0] = 0;
        c[c.length - 1] = n;
        for (int i = 0; i < cuts.length; i++) {
            c[i + 1] = cuts[i];
        }
        Arrays.sort(c);
        
        int m = c.length;
        int[][] dp = new int[m][m];
        
        // 枚举区间长度
        for (int len = 2; len < m; len++) {
            for (int i = 0; i + len < m; i++) {
                int j = i + len;
                dp[i][j] = Integer.MAX_VALUE;
                // 枚举切割点
                for (int k = i + 1; k < j; k++) {
                    dp[i][j] = Math.min(dp[i][j],
                        dp[i][k] + dp[k][j] + c[j] - c[i]);
                }
            }
        }
        return dp[0][m - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m³)，m = cuts.length + 2
- **空间复杂度**：O(m²)

## 关键点总结

1. **加端点**：加入 0 和 n 使区间表示统一
2. **区间 DP**：枚举第一刀位置 k
3. **费用公式**：当前区间长度 + 两子区间费用
