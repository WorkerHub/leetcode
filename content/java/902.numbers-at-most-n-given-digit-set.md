## 题目描述

给定一个按非递减顺序排列的数字数组 `digits`。你可以用任意次数 `digits[i]` 来写数字。例如，如果 `digits = ['1','3','5']`，我们可以写数字，如 `'13'`, `'551'`, 和 `'1351315'`。

返回可以生成的小于或等于给定整数 `n` 的正整数的个数。

**示例 1：**
```
输入：digits = ["1","3","5","7"], n = 100
输出：20
解释：
可写出的数字有：
1, 3, 5, 7, 11, 13, 15, 17, 31, 33, 35, 37, 51, 53, 55, 57, 71, 73, 75, 77
```

**示例 2：**
```
输入：digits = ["1","4","9"], n = 1000000000
输出：29523
解释：
我们可以写 3 位数字，4 位数字，5 位数字，6 位数字，7 位数字，8 位数字，或 9 位数字。
总共，可以使用 digits 写出 29523 个整数。
```

**提示：**
- 1 <= digits.length <= 9
- digits[i].length == 1
- digits[i] 是从 '1' 到 '9' 的数字
- digits 中的所有值都不同
- digits 按非递减顺序排列
- 1 <= n <= 10^9

## 解题思路

这是一道数位 DP 问题。核心思想是分类讨论：
1. **位数少于 n 的数字**：可以自由组合
2. **位数等于 n 的数字**：需要逐位判断

**算法流程：**

假设 n 有 k 位：
1. 计算位数小于 k 的所有合法数字：对于 i 位数，有 `len(digits)^i` 种组合
2. 计算位数等于 k 的合法数字：
   - 从高位到低位逐位判断
   - 如果当前位可以填比 n 对应位小的数字，后面位可以随意填
   - 如果只能填等于 n 对应位的数字，继续检查下一位
   - 如果没有合适的数字可填，结束

**关键观察：**
- 位数少的数字一定小于 n（因为 digits 不包含 '0'）
- 对于位数相同的，需要逐位比较
- 使用组合数学计算，避免枚举所有数字

## Java 代码实现

### 方法一：数位 DP（推荐）

```java
class Solution {
    public int atMostNGivenDigitSet(String[] digits, int n) {
        // 将 n 转换为字符串
        String s = String.valueOf(n);
        int k = s.length(); // n 的位数
        int d = digits.length; // 可用数字的个数

        int result = 0;

        // 1. 计算位数小于 k 的所有数字
        int power = d;
        for (int i = 1; i < k; i++) {
            result += power;
            power *= d;
        }

        // 2. 计算位数等于 k 的数字
        for (int i = 0; i < k; i++) {
            // 统计有多少个 digit 小于 s.charAt(i)
            int count = 0;
            boolean hasSame = false; // 是否存在等于 s[i] 的数字

            for (String digit : digits) {
                if (digit.charAt(0) < s.charAt(i)) {
                    count++;
                } else if (digit.charAt(0) == s.charAt(i)) {
                    hasSame = true;
                }
            }

            // 计算后面 k-i-1 位可以任意填的方案数
            int suffix = 1;
            for (int j = 0; j < k - i - 1; j++) {
                suffix *= d;
            }
            result += count * suffix;

            // 如果当前位没有等于 s[i] 的数字，无法继续构造
            if (!hasSame) {
                return result;
            }
        }

        // 所有位都能找到相等的数字，n 本身也是合法的
        result += 1;
        return result;
    }
}
```

### 方法二：优化的迭代版本

```java
class Solution {
    public int atMostNGivenDigitSet(String[] digits, int n) {
        String s = String.valueOf(n);
        int k = s.length();
        int d = digits.length;

        // 位数少于 k 的数字个数
        int ans = 0;
        int power = d;
        for (int i = 1; i < k; i++) {
            ans += power;
            power *= d;
        }

        // 位数等于 k 的数字
        for (int i = 0; i < k; i++) {
            char c = s.charAt(i);

            // 计算有多少个 digit < c
            int cnt = 0;
            boolean found = false;
            for (String digit : digits) {
                if (digit.charAt(0) < c) {
                    cnt++;
                } else if (digit.charAt(0) == c) {
                    found = true;
                }
            }

            // 计算后缀方案数
            int suffix = 1;
            for (int j = 0; j < k - i - 1; j++) {
                suffix *= d;
            }
            ans += cnt * suffix;

            // 如果没有 digit 等于 c，无法继续
            if (!found) {
                return ans;
            }
        }

        // n 本身也是合法的
        ans += 1;
        return ans;
    }
}
```

## 复杂度分析

**方法一（迭代数位 DP）：**
- 时间复杂度：O(k × d)，其中 k 是 n 的位数，d 是 digits 的长度
  - 外层循环 k 次，内层循环 d 次
- 空间复杂度：O(k)，存储 n 的字符串表示

## 关键点总结

1. **分类讨论**：将问题分为位数小于 n 和位数等于 n 两种情况
2. **组合计数**：位数为 i 的合法数字有 `d^i` 个
3. **逐位判断**：对于位数相同的，从高位到低位逐个比较
4. **提前终止**：如果某一位无法匹配，后续位不需要再检查
5. **边界处理**：最后要判断 n 本身是否合法

## 易错点

1. **位数计算**：位数为 i 的数字有 `d^i` 个，不是 `d^(i-1)`
2. **n 本身**：别忘了判断 n 本身是否可以由 digits 构成
3. **数字范围**：digits 不包含 '0'，所以位数少的数字一定大于 0
4. **幂运算**：`d^0 = 1`，表示没有后续位时只有一种选择
5. **整数溢出**：Java 中注意幂运算可能溢出，此题范围内 int 足够
