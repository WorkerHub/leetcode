## 题目描述

n块奶酪分给两只老鼠，第一只恰好吃k块，求最大总得分。

## 解题思路

贪心：先全给老鼠二号(base=sum(reward2))，选差值reward1[i]-reward2[i]最大的k块换给老鼠一号。

## Java 代码实现

```java
class Solution {
    public int miceAndCheese(int[] reward1, int[] reward2, int k) {
        int n = reward1.length;
        int base = 0;
        int[] diff = new int[n];
        for (int i = 0; i < n; i++) {
            base += reward2[i];
            diff[i] = reward1[i] - reward2[i];
        }
        Arrays.sort(diff);
        // 选最大的k个差值
        int extra = 0;
        for (int i = n - 1; i >= n - k; i--) {
            extra += diff[i];
        }
        return base + extra;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **转化为选k个差值最大的**：全给二号后换k个给一号
2. **差值排序取top-k**
3. **差值可为负但仍需选满k个**
