## 题目描述

给你一个整数数组 `nums` 以及两个整数 `lower` 和 `upper`。求数组中，值位于范围 `[lower, upper]`（包含 `lower` 和 `upper`）之内的**区间和的个数**。

区间和 `S(i, j)` 表示在 `nums` 中，位置从 `i` 到 `j` 的元素之和，包含 `i` 和 `j`（`i ≤ j`）。

**示例 1:**

```
输入：nums = [-2, 5, -1], lower = -2, upper = 2
输出：3
解释：存在三个区间：[0,0]、[2,2]、[0,2]，对应的区间和分别是：-2、-1、2。
```

**示例 2:**

```
输入：nums = [0], lower = 0, upper = 0
输出：1
```

**提示:**

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `-10^5 <= lower <= upper <= 10^5`
- 题目数据保证答案是一个 32 位的整数

## 解题思路

这道题是**前缀和 + 归并排序**的经典应用。

### 核心思想

1. **前缀和转化**：
   - 区间和 `S(i, j) = prefix_sum[j] - prefix_sum[i-1]`
   - 题目要求 `lower <= S(i, j) <= upper`
   - 即：`lower <= prefix_sum[j] - prefix_sum[i-1] <= upper`
   - 变形：`prefix_sum[j] - upper <= prefix_sum[i-1] <= prefix_sum[j] - lower`

2. **问题转化**：
   - 对于每个 `j`，统计有多少个 `i < j` 满足条件
   - 即：统计在 `prefix_sum[0...j-1]` 中，有多少个值在 `[prefix_sum[j] - upper, prefix_sum[j] - lower]` 范围内

3. **归并排序优化**：
   - 暴力枚举 O(n²)，会超时
   - 使用归并排序的过程中统计，时间复杂度降为 O(n log n)

### 归并排序统计原理

在归并排序的合并过程中：
- 左半部分和右半部分都已排序
- 对于右半部分的每个元素 `prefix_sum[j]`，可以在左半部分用双指针快速找到满足条件的范围

## Java 代码实现

### 方法一：归并排序（推荐）⭐

```java
class Solution {
    private long lower, upper;

    public int countRangeSum(int[] nums, int lower, int upper) {
        // 前缀和 + 归并排序
        this.lower = lower;
        this.upper = upper;
        int n = nums.length;

        // 计算前缀和数组（使用 long 避免整数溢出）
        long[] prefixSum = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefixSum[i + 1] = prefixSum[i] + nums[i];
        }

        // 归并排序并统计
        return mergeSort(prefixSum, 0, n);
    }

    private int mergeSort(long[] arr, int left, int right) {
        // 归并排序：返回区间 [left, right] 中满足条件的区间和个数
        if (right - left <= 1) return 0;

        int mid = (left + right) / 2;

        // 递归统计左右两部分
        int count = mergeSort(arr, left, mid);
        count += mergeSort(arr, mid, right);

        // 统计跨越 mid 的区间和
        // 对于右半部分的每个 k，统计左半部分有多少个 i 满足条件
        int i = left, j = left;
        for (int k = mid; k < right; k++) {
            // 找到左半部分中满足条件的范围 [i, j)
            // arr[i] >= arr[k] - upper
            while (i < mid && arr[i] < arr[k] - upper) i++;
            // arr[j] <= arr[k] - lower
            while (j < mid && arr[j] <= arr[k] - lower) j++;
            count += j - i;
        }

        // 归并排序的合并过程
        merge(arr, left, mid, right);

        return count;
    }

    private void merge(long[] arr, int left, int mid, int right) {
        // 合并两个有序数组
        long[] temp = new long[right - left];
        int i = left, j = mid, idx = 0;

        while (i < mid && j < right) {
            if (arr[i] <= arr[j]) {
                temp[idx++] = arr[i++];
            } else {
                temp[idx++] = arr[j++];
            }
        }

        while (i < mid) temp[idx++] = arr[i++];
        while (j < right) temp[idx++] = arr[j++];

        // 将排序结果复制回原数组
        System.arraycopy(temp, 0, arr, left, right - left);
    }
}
```

### 方法二：暴力解法（超时，仅用于理解）

```java
class Solution {
    public int countRangeSum(int[] nums, int lower, int upper) {
        // 暴力解法：枚举所有区间
        // 时间复杂度 O(n^2)，会超时
        int n = nums.length;
        int count = 0;

        // 枚举所有区间 [i, j]
        for (int i = 0; i < n; i++) {
            long currentSum = 0;
            for (int j = i; j < n; j++) {
                currentSum += nums[j];
                if (lower <= currentSum && currentSum <= upper) {
                    count++;
                }
            }
        }

        return count;
    }
}
```

### 方法三：前缀和 + 有序容器（TreeMap）

```java
import java.util.TreeMap;

class Solution {
    public int countRangeSum(int[] nums, int lower, int upper) {
        // 前缀和 + 有序容器（TreeMap 替代 Python 的 SortedList）
        long prefixSum = 0;
        int count = 0;
        TreeMap<Long, Integer> sortedSums = new TreeMap<>();
        sortedSums.put(0L, 1);  // 有序映射：前缀和 -> 出现次数

        for (int num : nums) {
            prefixSum += num;

            // 在有序映射中查找满足条件的前缀和个数
            // prefixSum - upper <= prevSum <= prefixSum - lower
            long lo = prefixSum - upper;
            long hi = prefixSum - lower;

            // 统计 [lo, hi] 范围内的前缀和个数
            for (int cnt : sortedSums.subMap(lo, true, hi, true).values()) {
                count += cnt;
            }

            // 将当前前缀和加入有序映射
            sortedSums.merge(prefixSum, 1, Integer::sum);
        }

        return count;
    }
}
```

## 复杂度分析

**方法一：归并排序**

- **时间复杂度**：O(n log n)
  - 归并排序的时间复杂度
  - 每层统计 O(n)，共 log n 层
  
- **空间复杂度**：O(n)
  - 前缀和数组 + 归并排序的临时数组

**方法二：暴力解法**

- **时间复杂度**：O(n²)
  - 双层循环枚举所有区间
  
- **空间复杂度**：O(1)

**方法三：有序容器**

- **时间复杂度**：O(n log n)
  - 每次插入和查找都是 O(log n)
  
- **空间复杂度**：O(n)
  - 有序映射存储所有前缀和

## 关键点总结

1. **前缀和转化**：区间和问题转化为前缀和差值问题
2. **归并排序统计**：
   - 左右两部分分别排序后，可以用双指针快速统计
   - 关键在于理解归并过程中如何统计跨越 mid 的区间
3. **双指针技巧**：
   - `i` 指针找下界：`arr[i] >= arr[k] - upper`
   - `j` 指针找上界：`arr[j] <= arr[k] - lower`
   - 满足条件的个数 = `j - i`
4. **long 类型避免溢出**：Java 中前缀和可能溢出 int，必须使用 long
5. **分治思想**：将问题分解为左半部分、右半部分、跨越部分三种情况

## 易错点

1. **前缀和数组长度**：应该是 `n + 1`，`prefix_sum[0] = 0`
2. **区间范围理解**：
   - `lower <= prefix_sum[j] - prefix_sum[i-1] <= upper`
   - 变形为：`prefix_sum[j] - upper <= prefix_sum[i-1] <= prefix_sum[j] - lower`
3. **双指针边界**：
   - `i` 和 `j` 的初始值都是 `left`
   - `i` 找第一个 `>= arr[k] - upper` 的位置
   - `j` 找第一个 `> arr[k] - lower` 的位置
4. **归并排序的合并**：不要忘记在统计完后执行合并操作
5. **整数溢出**：Java 中必须使用 long 类型存储前缀和

```
前缀和数组：
prefixSum = [0, -2, 3, 2]
索引:        0   1  2  3

需要找的区间和：
[0, 0]: -2  ✓ (在 [-2, 2] 范围内)
[0, 1]: 3   ✗
[0, 2]: 2   ✓
[1, 1]: 5   ✗
[1, 2]: 4   ✗
[2, 2]: -1  ✓

归并排序过程（简化）：
对于 prefixSum[2] = 3：
  需要找左半部分中满足 3 - 2 <= x <= 3 - (-2) 的 x
  即：1 <= x <= 5
  在 [0, -2] 中，3 满足（但 3 在右半部分，这里统计的是跨越的）
  
最终统计到 3 个满足条件的区间和
```
