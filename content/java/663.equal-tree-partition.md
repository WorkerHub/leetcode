## 题目描述

给定一棵二叉树的根节点 `root`，请判断是否可以通过删除**恰好一条**边将树分成两棵子树，使得两棵子树的节点值之和相等。

如果可以，返回 `true`，否则返回 `false`。

**示例 1:**

```
输入：root = [5,10,10,null,null,2,3]
输出：true
解释：
    5
   / \
  10  10
     /  \
    2    3
删除边 5-10（右），得到两棵树：[5,10] 和 [10,2,3]
和分别为 15 和 15
```

**示例 2:**

```
输入：root = [1,2,10,null,null,2,20]
输出：false
解释：无法找到这样的边
```

**提示:**
- 树中节点数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

### 核心观察

如果删除一条边后两棵树的和相等，那么：
- 原树的总和 = `totalSum`
- 删除某条边后，一棵子树的和 = `totalSum / 2`

所以问题转化为：**是否存在某棵子树，其和等于 totalSum / 2**

### 算法流程

1. 计算整棵树的总和 `totalSum`
2. 如果 `totalSum` 为奇数，直接返回 false
3. DFS 遍历，计算每棵子树的和
4. 如果某棵子树的和等于 `totalSum / 2`，返回 true
5. **注意**：不能删除根节点的边（会导致只有一棵树）

## Java 代码实现

### 方法一：DFS + 记录所有子树和（推荐）

```java
import java.util.*;

class Solution {
    public boolean checkEqualTree(TreeNode root) {
        // 存储所有子树的和
        List<Integer> subtreeSums = new ArrayList<>();

        int totalSum = getSum(root, subtreeSums);

        // 如果总和为奇数，无法平分
        if (totalSum % 2 != 0) return false;

        int target = totalSum / 2;

        // 检查是否存在子树和等于 target（排除根节点，即不用最后一个元素）
        // subtreeSums 最后一个元素是根节点的和（等于 totalSum），要排除
        for (int i = 0; i < subtreeSums.size() - 1; i++) {
            if (subtreeSums.get(i) == target) return true;
        }

        return false;
    }

    private int getSum(TreeNode node, List<Integer> subtreeSums) {
        if (node == null) return 0;

        int leftSum = getSum(node.left, subtreeSums);
        int rightSum = getSum(node.right, subtreeSums);
        int currentSum = node.val + leftSum + rightSum;

        // 记录所有节点的子树和
        subtreeSums.add(currentSum);

        return currentSum;
    }
}
```

### 方法二：两次 DFS

```java
import java.util.*;

class Solution {
    private boolean found = false;

    public boolean checkEqualTree(TreeNode root) {
        // 计算总和
        int totalSum = getTotal(root);

        if (totalSum % 2 != 0) return false;

        int target = totalSum / 2;

        // 检查是否存在非根节点的子树和等于 target
        checkSubtree(root, target, true);

        return found;
    }

    private int getTotal(TreeNode node) {
        if (node == null) return 0;
        return node.val + getTotal(node.left) + getTotal(node.right);
    }

    private int checkSubtree(TreeNode node, int target, boolean isRoot) {
        if (node == null || found) return 0;

        int currentSum = node.val
                + checkSubtree(node.left, target, false)
                + checkSubtree(node.right, target, false);

        // 不是根节点且和等于 target
        if (!isRoot && currentSum == target) {
            found = true;
        }

        return currentSum;
    }
}
```

### 方法三：单次遍历（使用 HashSet）

```java
import java.util.*;

class Solution {
    public boolean checkEqualTree(TreeNode root) {
        List<Integer> seen = new ArrayList<>();

        int total = dfs(root, seen);

        if (total % 2 != 0) return false;

        seen.remove(seen.size() - 1); // 移除根节点的和
        return seen.contains(total / 2);
    }

    private int dfs(TreeNode node, List<Integer> seen) {
        if (node == null) return 0;
        int total = node.val + dfs(node.left, seen) + dfs(node.right, seen);
        seen.add(total);
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，存储子树和

## 关键点总结

1. **总和判断**：总和必须是偶数
2. **排除根节点**：不能删除根节点的边
3. **特殊情况**：总和为 0 时，需要至少两棵子树和为 0
4. **子树和**：记录所有子树的和

## 易错点

1. **忘记排除根节点**：
   ```java
   // 错误：包含了根节点（最后一个元素）
   if (subtreeSums.contains(target)) return true;
   
   // 正确：排除根节点
   for (int i = 0; i < subtreeSums.size() - 1; i++) {
       if (subtreeSums.get(i) == target) return true;
   }
   ```

2. **总和为 0 的特殊情况**：
   ```java
   // 如果 totalSum = 0, target = 0
   // 需要找到一个非根的子树和为 0
   ```

3. **奇数总和没有提前返回**：
   ```java
   if (totalSum % 2 != 0) return false;
   ```
