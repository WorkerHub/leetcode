## 题目描述

给定数组 `nums` 和整数 `k`，可以最多将一个元素改为 k，返回能得到的最多等分方式数（将数组分成两个非空子数组使左右和相等）。

## 解题思路

枚举修改位置 j（将 nums[j] 改为 k，delta = k - nums[j]）：左侧分割点的前缀和不变，查找 `prefix[i] == target`；右侧分割点前缀和偏移 delta，查找 `prefix[i] == target - delta`。用左右两个哈希计数器动态维护，移动分界点。

## Java 代码实现

### 方法一：哈希表 + 枚举修改位置（推荐）

```java
import java.util.*;

class Solution {
    public int waysToPartition(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i+1] = prefix[i] + nums[i];
        long total = prefix[n];

        // 不修改时的答案
        int ans = 0;
        if (total % 2 == 0) {
            long half = total / 2;
            for (int i = 1; i < n; i++) {
                if (prefix[i] == half) ans++;
            }
        }

        // 枚举修改位置j
        Map<Long, Integer> leftCnt = new HashMap<>();
        Map<Long, Integer> rightCnt = new HashMap<>();
        for (int i = 1; i < n; i++) rightCnt.merge(prefix[i], 1, Integer::sum);

        for (int j = 0; j < n; j++) {
            long delta = (long) k - nums[j];
            long newTotal = total + delta;
            if (newTotal % 2 == 0) {
                long target = newTotal / 2;
                // 左侧分割点：前缀和不变，查target
                int cur = leftCnt.getOrDefault(target, 0);
                // 右侧分割点：前缀和偏移delta，查target-delta
                cur += rightCnt.getOrDefault(target - delta, 0);
                ans = Math.max(ans, cur);
            }
            // 移动分界点：将prefix[j+1]从rightCnt移到leftCnt
            rightCnt.merge(prefix[j+1], -1, Integer::sum);
            leftCnt.merge(prefix[j+1], 1, Integer::sum);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 修改位置 j 后，左侧分割点前缀和不变，右侧分割点前缀和偏移 delta
2. 用左右两个哈希计数器动态维护，右移分界点
3. 使用 long 防止前缀和溢出
