## 题目描述

给你整数数组 `nums` 和查询 `queries[i] = [l, r]`。每个查询可以对区间 `[l, r]` 中的某一个元素减 1。返回使 `nums` 变为全 0 所需的最少查询数，若无法实现返回 -1。

## 解题思路

贪心 + 最大堆：按左端点排序查询，对每个位置 `i` 需要 `nums[i]` 次减操作。每次从所有覆盖当前位置（`l <= i`）的查询中，优先选择右端点最大的（贪心：能覆盖更多未来位置）。用最大堆维护可用查询，差分数组追踪已用查询的覆盖效果。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxRemoval(int[] nums, int[][] queries) {
        int n = nums.length;

        // 按左端点排序查询
        Arrays.sort(queries, (a, b) -> a[0] - b[0]);

        // 最大堆：存右端点（优先使用右端点最大的查询）
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());

        // 差分数组：记录已使用查询的覆盖情况
        int[] diff = new int[n + 1];

        int qIdx = 0;
        int opsUsed = 0;
        int cover = 0;

        for (int i = 0; i < n; i++) {
            // 将所有 l <= i 的查询加入堆
            while (qIdx < queries.length && queries[qIdx][0] <= i) {
                heap.offer(queries[qIdx][1]);
                qIdx++;
            }

            // 更新当前位置的覆盖次数
            cover += diff[i];

            // 需要 nums[i] 次覆盖，当前覆盖 cover 次
            while (cover < nums[i]) {
                // 移除右端点 < i 的过期查询
                while (!heap.isEmpty() && heap.peek() < i) {
                    heap.poll();
                }
                if (heap.isEmpty()) {
                    return -1; // 无可用查询
                }
                int r = heap.poll();
                // 使用该查询：在 r+1 处撤销覆盖
                diff[r + 1]--;
                cover++;
                opsUsed++;
            }
        }

        return opsUsed;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) * log q)，堆操作
- 空间复杂度：O(n + q)

## 关键点总结

1. 贪心策略：对每个位置优先使用右端点最大的查询，能覆盖更多未来位置。
2. 最大堆维护可用查询（按右端点排序），差分数组追踪查询使用情况。
3. 取出过期查询（右端点 < i）时直接丢弃，不计入使用数。
