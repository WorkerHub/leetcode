## 题目描述

给定整数 `k`，找到最少数量的斐波那契数（可重复使用）使其和等于 `k`，返回该最少数量。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int findMinFibonacciNumbers(int k) {
        // 生成所有不超过 k 的斐波那契数
        List<Integer> fibs = new ArrayList<>();
        int a = 1, b = 1;
        while (a <= k) {
            fibs.add(a);
            int c = a + b;
            a = b;
            b = c;
        }

        // 贪心：每次取不超过 k 的最大斐波那契数
        int count = 0;
        int idx = fibs.size() - 1;
        while (k > 0) {
            while (fibs.get(idx) > k) idx--;
            k -= fibs.get(idx);
            count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log^2 k)，斐波那契数约 O(log k) 个，每次回退指针均摊 O(log k)
- 空间复杂度：O(log k)

## 关键点总结

1. Zeckendorf 定理：贪心每次取最大斐波那契数可得最优解
2. 1 到 10^9 内斐波那契数约 43 个，列表很小
3. 指针单调递减，无需每次从头查找
