## 题目描述

给定等长字符串数组 strs，删除最少的列使得每行剩余字符组成的字符串是非递减的。返回最少删除列数。

**示例：**
```
输入：strs = ["babca","bbazb"]
输出：3
```

## 解题思路

转化为 LIS 问题：保留最多的列使每行非递减。dp[i] 表示以第 i 列结尾的最长有效列序列。转移条件：所有行 strs[row][j] <= strs[row][i]。

## Java 代码实现

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int n = strs.length, m = strs[0].length();
        int[] dp = new int[m];
        Arrays.fill(dp, 1);

        for (int i = 1; i < m; i++) {
            for (int j = 0; j < i; j++) {
                // 检查所有行是否满足 strs[row][j] <= strs[row][i]
                boolean valid = true;
                for (int row = 0; row < n; row++) {
                    if (strs[row].charAt(j) > strs[row].charAt(i)) {
                        valid = false;
                        break;
                    }
                }
                if (valid) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
        }

        int maxKeep = 0;
        for (int x : dp) maxKeep = Math.max(maxKeep, x);
        return m - maxKeep;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × n)
- **空间复杂度**：O(m)

## 关键点总结

1. **LIS 变体**：保留最多有效列 = 最长递增子序列
2. **多行约束**：所有行都必须满足非递减
3. **答案转化**：删除数 = 总列数 - 最多保留列数
