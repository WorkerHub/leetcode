## 题目描述

将2n个整数的数组分成n对，使每对中两个数相等，判断是否可行。

## 解题思路

每种数字必须出现偶数次。统计每个数字出现次数，若全部为偶数则返回true。

## Java 代码实现

```java
class Solution {
    public boolean divideArray(int[] nums) {
        int[] count = new int[501];
        for (int x : nums) {
            count[x]++;
        }
        for (int c : count) {
            if (c % 2 != 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)，计数数组固定大小

## 关键点总结

1. **核心条件**：每种数字出现次数为偶数
2. **计数数组**：值范围1-500，用固定数组即可
3. **一遍遍历统计**：无需排序
