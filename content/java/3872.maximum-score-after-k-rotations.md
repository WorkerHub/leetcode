## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，对数组执行恰好 `k` 次向右旋转，每次旋转后选择一个前缀，得分为该前缀之和，返回 `k` 次旋转中可获得的最大总分数。

## 解题思路

用 doubled 数组（nums 复制两遍）模拟所有旋转状态。旋转 r 次后，数组起点在 doubled 中位于 n-r 处，预计算该起点下的最大前缀和。将所有旋转状态的最大前缀和降序排列，取前 k 个之和（贪心最优）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maximumScore(int[] nums, int k) {
        int n = nums.length;
        // 构建前缀和，doubled 数组模拟所有旋转
        long[] prefix = new long[2 * n + 1];
        for (int i = 0; i < 2 * n; i++) {
            prefix[i + 1] = prefix[i] + nums[i % n];
        }

        // 计算每种旋转状态的最大前缀和
        long[] maxPrefixes = new long[n];
        for (int r = 0; r < n; r++) {
            int s = n - r; // 旋转 r 次后在 doubled 中的起点
            long best = 0;
            for (int j = 0; j < n; j++) {
                // 计算从起点 s 开始长度为 j+1 的前缀和
                best = Math.max(best, prefix[s + j + 1] - prefix[s]);
            }
            maxPrefixes[r] = best;
        }

        // 贪心：取最大的 k 个前缀和求和
        Arrays.sort(maxPrefixes);
        long ans = 0;
        for (int i = n - 1; i >= n - k; i--) {
            ans += maxPrefixes[i];
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，暴力枚举每种旋转的最大前缀和
- 空间复杂度：O(n)

## 关键点总结

1. 旋转后数组可以用 doubled 数组模拟，起点随旋转次数变化。
2. 每次旋转的最优前缀和可以预计算，然后贪心选 k 个最大值。
3. 旋转次数从 0 到 n-1，共 n 种状态，选其中最大的 k 个。
