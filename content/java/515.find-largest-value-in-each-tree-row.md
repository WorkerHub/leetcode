## 题目描述

给定一棵二叉树的根节点 `root`，请找出每一层的最大值。

**示例 1：**
```
输入：root = [1,3,2,5,3,null,9]
输出：[1,3,9]
解释：
          1
         / \
        3   2
       / \   \
      5   3   9
```

**示例 2：**
```
输入：root = [1,2,3]
输出：[1,3]
```

**提示：**
- 树中节点数目在范围 `[0, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 解题思路

这道题要求找每层的最大值，典型的层序遍历问题。

### 解法对比：
- **BFS**：层序遍历，每层记录最大值
- **DFS**：深度优先，记录每层的最大值

## Java 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```java
import java.util.*;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public List<Integer> largestValues(TreeNode root) {
        // BFS 层序遍历
        // 时间复杂度：O(n)，空间复杂度：O(w)，w 是最大宽度
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            int maxVal = Integer.MIN_VALUE;  // 每层的最大值

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                maxVal = Math.max(maxVal, node.val);

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            result.add(maxVal);
        }

        return result;
    }
}
```

### 方法二：DFS（递归）

```java
class Solution {
    public List<Integer> largestValues(TreeNode root) {
        // DFS 深度优先搜索
        // 时间复杂度：O(n)，空间复杂度：O(h)
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int depth, List<Integer> result) {
        if (node == null) return;

        // 如果是新的一层，添加当前值
        if (depth == result.size()) {
            result.add(node.val);
        } else {
            // 更新当前层的最大值
            result.set(depth, Math.max(result.get(depth), node.val));
        }

        // 递归左右子树
        dfs(node.left, depth + 1, result);
        dfs(node.right, depth + 1, result);
    }
}
```

## 复杂度分析

### BFS：
- **时间复杂度**：O(n)
- **空间复杂度**：O(w)，w 是树的最大宽度

### DFS：
- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 是树的高度

## 关键点总结

1. **BFS 模板**：使用队列，按层遍历
2. **DFS 技巧**：用深度索引直接访问结果数组
3. **初始值**：每层最大值初始化为 `Integer.MIN_VALUE`
4. **空树处理**：返回空列表
5. **Java 注意**：使用 `Integer.MIN_VALUE` 而非 0，因为节点值可能为负

## 易错点

1. **空树**：要特判 root 是否为 null
2. **负数**：初始化为 `Integer.MIN_VALUE` 而非 0
3. **深度索引**：DFS 中深度从 0 开始
4. **队列大小**：BFS 中要先记录 `queue.size()`
