## 题目描述

给定 n 节点家族树（根为 0），每个节点有唯一遗传值（1~n），返回每个节点子树中最小缺失的正整数。

## 解题思路

只有包含值 1 的节点的祖先链上，答案才可能大于 1，其余节点答案均为 1。从值为 1 的节点开始向上遍历，每次用迭代 DFS 收集子树所有遗传值，更新最小缺失值 `miss`（miss 单调递增，不需要每次从头扫描）。

## Java 代码实现

### 方法一：迭代 DFS + 向上遍历（推荐）

```java
import java.util.*;

class Solution {
    public int[] smallestMissingValueSubtree(int[] parents, int[] nums) {
        int n = parents.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parents[i]).add(i);

        int[] ans = new int[n];
        Arrays.fill(ans, 1); // 默认答案为1

        // 找值为1的节点
        int nodeWith1 = -1;
        for (int i = 0; i < n; i++) {
            if (nums[i] == 1) { nodeWith1 = i; break; }
        }
        if (nodeWith1 == -1) return ans;

        boolean[] nodeVisited = new boolean[n];
        Set<Integer> geneticSet = new HashSet<>();

        int miss = 1;
        int cur = nodeWith1;

        while (cur != -1) {
            // 迭代DFS收集cur子树中未收集的遗传值
            Deque<Integer> stack = new ArrayDeque<>();
            stack.push(cur);
            while (!stack.isEmpty()) {
                int node = stack.pop();
                if (nodeVisited[node]) continue;
                nodeVisited[node] = true;
                geneticSet.add(nums[node]);
                for (int child : children.get(node)) {
                    if (!nodeVisited[child]) stack.push(child);
                }
            }
            // 更新miss（单调递增）
            while (geneticSet.contains(miss)) miss++;
            ans[cur] = miss;
            cur = parents[cur]; // 移动到父节点
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点最多被访问一次
- 空间复杂度：O(n)

## 关键点总结

1. 只有值为 1 的节点的祖先链上，答案才可能大于 1
2. `miss` 单调递增，不需要每次从头扫描
3. 用 `nodeVisited` 避免重复处理子树节点，保证总复杂度 O(n)
