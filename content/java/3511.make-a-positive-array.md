## 题目描述

给定整数数组 `nums`。每次操作可以选择一个子数组将所有元素取反。求使数组所有元素之和为正数所需的最少操作次数，不可能时返回 `-1`。

## 解题思路

贪心：每次用 Kadane 变体找最小（最负）子数组和并取反，使总和增益最大。若当前所有子数组和均 >= 0 但总和仍 <= 0，则返回 -1。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int makePositive(int[] nums) {
        int n = nums.length;
        long[] arr = new long[n];
        for (int i = 0; i < n; i++) arr[i] = nums[i];

        int ops = 0;
        for (int iter = 0; iter <= 2 * n; iter++) {
            // 检查总和
            long total = 0;
            for (long x : arr) total += x;
            if (total > 0) return ops;

            // 找最小子数组和（Kadane 变体）
            long minSum = 0, curSum = 0;
            int minStart = -1, minEnd = -1, curStart = 0;
            int bestStart = 0;
            for (int i = 0; i < n; i++) {
                curSum += arr[i];
                if (curSum < minSum) {
                    minSum = curSum;
                    minEnd = i;
                    bestStart = curStart;
                }
                if (curSum > 0) { curSum = 0; curStart = i + 1; }
            }
            if (minEnd == -1) return -1; // 无负子数组

            for (int i = bestStart; i <= minEnd; i++) arr[i] = -arr[i];
            ops++;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，最多 O(n) 次操作，每次 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每次取反最大负和子数组，总和增益最大
2. 若无负子数组但总和 <= 0，返回 -1
3. 使用 long 防止累加溢出
