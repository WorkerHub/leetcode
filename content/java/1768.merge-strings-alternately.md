## 题目描述

给你字符串 `word1` 和 `word2`，从 `word1` 开始交替取字符合并，较长字符串的剩余部分追加到末尾。返回合并后字符串。

## 解题思路

双指针交替取字符，较短字符串用完后拼接剩余部分。

## Java 代码实现

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        StringBuilder sb = new StringBuilder();
        int i = 0, j = 0;

        while (i < word1.length() && j < word2.length()) {
            sb.append(word1.charAt(i++)); // 先取 word1
            sb.append(word2.charAt(j++)); // 再取 word2
        }

        // 拼接剩余部分
        sb.append(word1.substring(i));
        sb.append(word2.substring(j));

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)

## 关键点总结

1. 交替取字符，从 word1 开始
2. 较短字符串用完后拼接剩余
