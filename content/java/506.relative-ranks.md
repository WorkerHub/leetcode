## 题目描述

给你一个长度为 `n` 的整数数组 `score`，其中 `score[i]` 是第 `i` 位运动员在比赛中的得分。所有得分都互不相同。

运动员将根据得分决定名次，其中名次第 `1` 的运动员得分最高，名次第 `2` 的运动员得分第二高，依此类推。运动员的名次决定了他们的获奖情况：

- 名次第 `1` 的运动员获金牌 `"Gold Medal"`
- 名次第 `2` 的运动员获银牌 `"Silver Medal"`
- 名次第 `3` 的运动员获铜牌 `"Bronze Medal"`
- 从名次第 `4` 到第 `n` 的运动员，只能获得他们的名次编号（即，名次第 `x` 的运动员获得编号 `"x"`）

使用长度为 `n` 的数组 `answer` 返回获奖情况，其中 `answer[i]` 是第 `i` 位运动员的获奖情况。

**示例 1：**
```
输入：score = [5,4,3,2,1]
输出：["Gold Medal","Silver Medal","Bronze Medal","4","5"]
解释：名次为 [1st, 2nd, 3rd, 4th, 5th]。
```

**示例 2：**
```
输入：score = [10,3,8,9,4]
输出：["Gold Medal","5","Bronze Medal","Silver Medal","4"]
解释：名次为 [1st, 5th, 3rd, 2nd, 4th]。
```

**提示：**
- `n == score.length`
- `1 <= n <= 10^4`
- `0 <= score[i] <= 10^6`
- `score` 中的所有值互不相同

## 解题思路

这道题的核心是**排序 + 映射**。需要根据分数排名，然后将排名映射回原始索引位置。

### 核心思想：
1. 对分数排序，得到排名
2. 建立分数到排名的映射
3. 遍历原数组，根据分数查找对应的奖牌/排名

### 算法流程：
1. 对分数降序排序，得到排名顺序
2. 创建分数到名次的哈希表
3. 前三名映射为奖牌，其余为数字排名
4. 遍历原数组，根据分数查表得到结果

## Java 代码实现

### 方法一：排序 + 哈希表（推荐）⭐

```java
import java.util.*;

class Solution {
    public String[] findRelativeRanks(int[] score) {
        // 排序 + 哈希表映射
        // 时间复杂度：O(n log n)，空间复杂度：O(n)
        int n = score.length;

        // 对分数降序排序（创建副本）
        int[] sorted = score.clone();
        // 利用流的方式降序排列
        // 这里用手动方式降序
        Arrays.sort(sorted);
        // 反转为降序
        for (int i = 0, j = sorted.length - 1; i < j; i++, j--) {
            int tmp = sorted[i]; sorted[i] = sorted[j]; sorted[j] = tmp;
        }

        // 建立分数到名次的映射
        Map<Integer, String> rankMap = new HashMap<>();
        String[] medals = {"Gold Medal", "Silver Medal", "Bronze Medal"};

        for (int i = 0; i < sorted.length; i++) {
            if (i < 3) {
                rankMap.put(sorted[i], medals[i]);
            } else {
                rankMap.put(sorted[i], String.valueOf(i + 1));
            }
        }

        // 根据原数组的分数查找对应的名次
        String[] result = new String[n];
        for (int i = 0; i < n; i++) {
            result[i] = rankMap.get(score[i]);
        }
        return result;
    }
}
```

### 方法二：索引排序（更优雅）

```java
class Solution {
    public String[] findRelativeRanks(int[] score) {
        // 对索引进行排序，避免建立哈希表
        // 时间复杂度：O(n log n)，空间复杂度：O(n)
        int n = score.length;

        // 创建索引数组，按分数降序排序
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> score[b] - score[a]);

        // 准备结果数组
        String[] result = new String[n];
        String[] medals = {"Gold Medal", "Silver Medal", "Bronze Medal"};

        // 根据排序后的索引顺序分配名次
        for (int rank = 0; rank < n; rank++) {
            int idx = indices[rank];
            if (rank < 3) {
                result[idx] = medals[rank];
            } else {
                result[idx] = String.valueOf(rank + 1);
            }
        }

        return result;
    }
}
```

### 方法三：使用数组排序（避免装箱）

```java
class Solution {
    public String[] findRelativeRanks(int[] score) {
        // 使用二维数组存储 (分数, 原始索引)
        // 时间复杂度：O(n log n)，空间复杂度：O(n)
        int n = score.length;

        // 创建 (分数, 原始索引) 数组
        int[][] scoreWithIndex = new int[n][2];
        for (int i = 0; i < n; i++) {
            scoreWithIndex[i][0] = score[i];
            scoreWithIndex[i][1] = i;
        }

        // 按分数降序排序
        Arrays.sort(scoreWithIndex, (a, b) -> b[0] - a[0]);

        // 准备结果
        String[] result = new String[n];
        String[] medals = {"Gold Medal", "Silver Medal", "Bronze Medal"};

        for (int rank = 0; rank < n; rank++) {
            int idx = scoreWithIndex[rank][1];
            if (rank < 3) {
                result[idx] = medals[rank];
            } else {
                result[idx] = String.valueOf(rank + 1);
            }
        }

        return result;
    }
}
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(n log n)
  - 排序：O(n log n)
  - 建立映射和查询：O(n)
- **空间复杂度**：O(n)
  - 排序后的数组或索引数组：O(n)
  - 哈希表或结果数组：O(n)

## 关键点总结

1. **排序策略**：降序排序，分数最高的排第一
2. **映射关系**：分数 → 排名，或索引 → 排名
3. **前三名特殊处理**：使用奖牌名称而非数字
4. **保持原顺序**：结果数组要与输入数组索引对应
5. **索引排序技巧**：排序索引而非值，直接得到结果位置

## 易错点

1. **排序方向**：应该是降序，不是升序
2. **排名从 1 开始**：第 4 名是 "4"，不是 "3"
3. **字符串类型**：数字排名要用 `String.valueOf()` 转为字符串
4. **索引对应**：result[i] 对应 score[i] 的名次，不要搞混
5. **边界情况**：n < 3 时，可能没有铜牌
