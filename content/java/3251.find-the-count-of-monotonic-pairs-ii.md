## 题目描述

与 3250 相同的问题，但数据范围更大：`1 <= n <= 2000`，`1 <= nums[i] <= 1000`。返回单调对数量，对 `10^9 + 7` 取模。

## 解题思路

与 3250 完全相同的 DP + 前缀和方法。`dp[y]` 表示 `arr1[i] = y` 的方案数，通过前缀和 O(1) 完成区间求和。总复杂度 O(n * maxVal) = O(2 * 10^6)，可接受。

## Java 代码实现

```java
class Solution {
    public int countOfPairs(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // dp[y] = arr1[i] = y 时的方案数
        long[] dp = new long[maxVal + 1];
        for (int y = 0; y <= nums[0]; y++) dp[y] = 1;

        for (int i = 1; i < n; i++) {
            long[] newDp = new long[maxVal + 1];
            // 构建前缀和加速区间查询
            long[] prefix = new long[maxVal + 2];
            for (int x = 0; x <= maxVal; x++) {
                prefix[x + 1] = (prefix[x] + dp[x]) % MOD;
            }
            int diff = nums[i] - nums[i - 1];
            for (int y = 0; y <= nums[i]; y++) {
                // 前一个 arr1 值 x 的合法范围
                int lo = Math.max(0, y - diff);
                int hi = Math.min(y, nums[i - 1]);
                if (lo > hi) continue;
                newDp[y] = (prefix[hi + 1] - prefix[lo] + MOD) % MOD;
            }
            dp = newDp;
        }

        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * maxVal)，其中 maxVal = 1000
- 空间复杂度：O(maxVal)

## 关键点总结

1. 与 3250 完全相同的 DP 思路，只是数据范围更大
2. 前缀和优化内层区间求和，每步转移 O(1)
3. 取模相减时需加 MOD 防止负数
