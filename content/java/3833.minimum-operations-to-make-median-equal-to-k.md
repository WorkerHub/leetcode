## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可将任意元素加 1 或减 1，返回使中位数等于 `k` 的最少操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minOperationsToMakeMedianK(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        int mid = n / 2;
        long ops = 0;

        if (nums[mid] > k) {
            // 中位数大于 k，从 mid 向左将大于 k 的元素降到 k
            for (int i = mid; i >= 0 && nums[i] > k; i--) {
                ops += nums[i] - k;
            }
        } else if (nums[mid] < k) {
            // 中位数小于 k，从 mid 向右将小于 k 的元素升到 k
            for (int i = mid; i < n && nums[i] < k; i++) {
                ops += k - nums[i];
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后中位数在位置 n/2（0-indexed）
2. 将中位数降低：从 mid 向左将大于 k 的元素改为 k
3. 将中位数升高：从 mid 向右将小于 k 的元素改为 k
