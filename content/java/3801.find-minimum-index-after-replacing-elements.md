## 题目描述

给定整数数组 `nums`，每个元素可以替换为自身的任意因子，找到替换后数组最小值第一次出现的下标。

## Java 代码实现

```java
class Solution {
    public int minimumIndex(int[] nums) {
        // 任何元素都可以替换为 1，问题等价于找数组最小值的第一个下标
        int minVal = nums[0];
        int minIdx = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < minVal) {
                minVal = nums[i];
                minIdx = i;
            }
        }
        return minIdx;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 任何正整数都可以替换为其因子 1，问题化简为找最小值首次出现位置
2. 线性扫描维护当前最小值及其下标即可
3. 遇到更小值时更新，保证找到第一个最小值
