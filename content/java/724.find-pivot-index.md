## 题目描述

找出数组的中心下标，即左侧所有元素之和等于右侧所有元素之和。返回最左边的，不存在返回 -1。

**示例：**
```
输入：nums = [1,7,3,6,5,6]
输出：3（左侧和 = 右侧和 = 11）
```

## 解题思路

前缀和：维护 leftSum，右侧和 = total - leftSum - nums[i]，相等则找到。

## Java 代码实现

```java
class Solution {
    public int pivotIndex(int[] nums) {
        int total = 0;
        for (int num : nums) total += num;

        int leftSum = 0;
        for (int i = 0; i < nums.length; i++) {
            if (leftSum == total - leftSum - nums[i]) {
                return i;
            }
            leftSum += nums[i];
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和思想**：右侧和 = total - leftSum - nums[i]
2. **先判断再更新**：判断后才将 nums[i] 加入 leftSum
3. **返回最左**：从左到右遍历，第一个满足条件的即是答案
