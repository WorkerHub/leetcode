## 题目描述

给你整数数组 `nums`，如果子数组中任意两个元素之差的绝对值 <= 2，则称为连续子数组，返回连续子数组的总数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long continuousSubarrays(int[] nums) {
        int n = nums.length;
        long ans = 0;
        int left = 0;
        // 单调递减队列（维护最大值下标）
        Deque<Integer> maxDq = new ArrayDeque<>();
        // 单调递增队列（维护最小值下标）
        Deque<Integer> minDq = new ArrayDeque<>();

        for (int right = 0; right < n; right++) {
            // 维护最大值队列（单调递减）
            while (!maxDq.isEmpty() && nums[maxDq.peekLast()] <= nums[right]) maxDq.pollLast();
            maxDq.offerLast(right);
            // 维护最小值队列（单调递增）
            while (!minDq.isEmpty() && nums[minDq.peekLast()] >= nums[right]) minDq.pollLast();
            minDq.offerLast(right);
            // 若窗口不满足条件，移动 left
            while (nums[maxDq.peekFirst()] - nums[minDq.peekFirst()] > 2) {
                left++;
                if (maxDq.peekFirst() < left) maxDq.pollFirst();
                if (minDq.peekFirst() < left) minDq.pollFirst();
            }
            ans += right - left + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素入队/出队各一次
- 空间复杂度：O(n)

## 关键点总结

1. 单调队列同时维护窗口最大值和最小值
2. 当最大值 - 最小值 > 2 时，缩小窗口
3. 以 right 结尾的合法子数组数等于 `right - left + 1`
