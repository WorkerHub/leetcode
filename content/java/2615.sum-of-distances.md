## 题目描述

对每个下标i，求所有与nums[i]相同值的其他下标j的|i-j|之和。

## 解题思路

分组+前缀和：按值分组收集下标，每组内用前缀和公式O(1)计算每个位置的绝对差之和。

## Java 代码实现

```java
class Solution {
    public long[] distance(int[] nums) {
        int n = nums.length;
        long[] ans = new long[n];
        Map<Integer, List<Integer>> groups = new HashMap<>();

        for (int i = 0; i < n; i++) {
            groups.computeIfAbsent(nums[i], k -> new ArrayList<>()).add(i);
        }

        for (List<Integer> indices : groups.values()) {
            int m = indices.size();
            // 前缀和
            long[] prefix = new long[m + 1];
            for (int k = 0; k < m; k++) {
                prefix[k + 1] = prefix[k] + indices.get(k);
            }
            for (int k = 0; k < m; k++) {
                long idx = indices.get(k);
                // 左侧贡献
                long left = idx * k - prefix[k];
                // 右侧贡献
                long right = (prefix[m] - prefix[k + 1]) - idx * (m - 1 - k);
                ans[(int) idx] = left + right;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **按值分组**：相同值的下标放一起
2. **前缀和优化绝对差之和**：左侧idx*k-prefix[k]
3. **用long防溢出**
