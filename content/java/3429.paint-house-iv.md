## 题目描述

给定 `n` 栋房子和 `k` 种颜色，相邻房子不能同色，且第一栋和最后一栋必须同色，返回满足条件的最小涂色总代价，不可能则返回 -1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minCost(int n, int[][] cost) {
        int k = cost[0].length;
        long INF = Long.MAX_VALUE / 2;
        long ans = INF;

        // 枚举第 0 栋和第 n-1 栋的颜色 c
        for (int c = 0; c < k; c++) {
            long[] dp = new long[k];
            Arrays.fill(dp, INF);
            dp[c] = cost[0][c];

            for (int i = 1; i < n; i++) {
                // 最小/次小值优化：O(k) 转移
                long min1 = INF, min2 = INF;
                int minIdx = -1;
                for (int j = 0; j < k; j++) {
                    if (dp[j] < min1) { min2 = min1; min1 = dp[j]; minIdx = j; }
                    else if (dp[j] < min2) { min2 = dp[j]; }
                }
                long[] ndp = new long[k];
                for (int j = 0; j < k; j++) {
                    long prev = (j == minIdx) ? min2 : min1;
                    ndp[j] = (prev >= INF) ? INF : prev + cost[i][j];
                }
                dp = ndp;
            }

            // 第 n-1 栋颜色必须为 c
            if (dp[c] < ans) ans = dp[c];
        }

        return (ans >= INF) ? -1 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k^2)，枚举 k 种颜色，每次 DP 为 O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 枚举首尾颜色 c，固定初始状态后做标准涂色 DP
2. 最小/次小值优化将每步转移从 O(k^2) 降至 O(k)
3. 最终取 `dp[c]`（第 n-1 栋必须与第 0 栋同色）
