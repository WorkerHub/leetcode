## 题目描述

给定两个二叉搜索树 root1 和 root2，以及一个整数 target。如果第一棵树中存在 v1，第二棵树中存在 v2，使得 v1 + v2 = target，返回 true。

**示例：**
```
输入：root1 = [2,1,4], root2 = [1,0,3], target = 5
输出：true（2 + 3 = 5）
```

## 解题思路

方法一：遍历第一棵树将值存入 HashSet，遍历第二棵树检查 target - val 是否在集合中。方法二：中序遍历两棵树得到有序数组，双指针查找。

## Java 代码实现

### 方法一：哈希集合（推荐）

```java
class Solution {
    public boolean twoSumBSTs(TreeNode root1, TreeNode root2, int target) {
        // 收集第一棵树的所有值
        Set<Integer> set = new HashSet<>();
        inorder(root1, set);
        // 在第二棵树中查找配对
        return search(root2, set, target);
    }
    
    private void inorder(TreeNode node, Set<Integer> set) {
        if (node == null) return;
        set.add(node.val);
        inorder(node.left, set);
        inorder(node.right, set);
    }
    
    private boolean search(TreeNode node, Set<Integer> set, int target) {
        if (node == null) return false;
        if (set.contains(target - node.val)) return true;
        return search(node.left, set, target) || search(node.right, set, target);
    }
}
```

### 方法二：中序遍历 + 双指针

```java
class Solution {
    public boolean twoSumBSTs(TreeNode root1, TreeNode root2, int target) {
        // 中序遍历得到两个有序数组
        List<Integer> arr1 = new ArrayList<>();
        List<Integer> arr2 = new ArrayList<>();
        inorder(root1, arr1);
        inorder(root2, arr2);
        
        // 双指针：arr1 从左往右，arr2 从右往左
        int i = 0, j = arr2.size() - 1;
        while (i < arr1.size() && j >= 0) {
            int sum = arr1.get(i) + arr2.get(j);
            if (sum == target) return true;
            else if (sum < target) i++;
            else j--;
        }
        return false;
    }
    
    private void inorder(TreeNode node, List<Integer> list) {
        if (node == null) return;
        inorder(node.left, list);
        list.add(node.val);
        inorder(node.right, list);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n)（哈希集合）或 O(n + m)（双指针法）

## 关键点总结

1. **HashSet 查找**：O(1) 时间判断 target - val 是否存在
2. **BST 中序遍历**：得到有序数组，可用双指针
3. **双指针方向**：一个从最小值开始，一个从最大值开始
4. **BST 搜索剪枝**：也可利用 BST 性质在第二棵树中搜索
