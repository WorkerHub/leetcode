## 题目描述

给定一个三角形 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。相邻的结点在这里指的是下标与上一层结点下标相同或者等于上一层结点下标 + 1 的两个结点。也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i` 或 `i + 1`。

**示例 1：**

```
输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
解释：如下面简图所示：
   2
  3 4
 6 5 7
4 1 8 3
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。
```

**示例 2：**

```
输入：triangle = [[-10]]
输出：-10
```

**提示：**

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

**进阶：**

你可以只使用 O(n) 的额外空间（n 为三角形的总行数）来解决这个问题吗？

## 解题思路

这是一道经典的动态规划问题，类似于杨辉三角，但要求的是找最小路径和。

**核心思想：**

1. **自顶向下 DP**：`dp[i][j]` 表示从顶点到位置 `(i, j)` 的最小路径和
   - 状态转移：`dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])`
   - 注意边界：第一列和最后一列的处理

2. **自底向上 DP（推荐）**：从最后一行开始向上计算
   - 状态转移：`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`
   - 优点：不需要处理边界，最终结果就是 `dp[0][0]`

3. **空间优化**：只需要保存一行的状态，空间复杂度 O(n)

## Java 代码实现

### 方法一：自底向上 DP + 原地修改（推荐）

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        // 从倒数第二行开始，自底向上更新
        for (int i = triangle.size() - 2; i >= 0; i--) {
            for (int j = 0; j < triangle.get(i).size(); j++) {
                // 当前位置的最小路径和 = 当前值 + 下一行相邻两个位置的最小值
                int minPath = Math.min(triangle.get(i+1).get(j), triangle.get(i+1).get(j+1));
                triangle.get(i).set(j, triangle.get(i).get(j) + minPath);
            }
        }

        return triangle.get(0).get(0);
    }
}
```

### 方法二：自底向上 DP + 额外数组

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();

        // dp[j] 表示到达当前行第 j 个位置的最小路径和
        int[] dp = new int[triangle.get(n-1).size()];
        for (int j = 0; j < dp.length; j++) {
            dp[j] = triangle.get(n-1).get(j);
        }

        // 从倒数第二行开始向上计算
        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j < triangle.get(i).size(); j++) {
                dp[j] = triangle.get(i).get(j) + Math.min(dp[j], dp[j+1]);
            }
        }

        return dp[0];
    }
}
```

### 方法三：自顶向下 DP

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();

        // dp[i][j] 表示从顶点到 (i, j) 的最小路径和
        int[][] dp = new int[n][];
        for (int i = 0; i < n; i++) dp[i] = new int[triangle.get(i).size()];
        dp[0][0] = triangle.get(0).get(0);

        // 从第二行开始计算
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < triangle.get(i).size(); j++) {
                if (j == 0) {
                    // 第一列：只能从上一行的第一个位置下来
                    dp[i][j] = dp[i-1][j] + triangle.get(i).get(j);
                } else if (j == triangle.get(i).size() - 1) {
                    // 最后一列：只能从上一行的最后一个位置下来
                    dp[i][j] = dp[i-1][j-1] + triangle.get(i).get(j);
                } else {
                    // 中间位置：可以从上一行的 j-1 或 j 位置下来
                    dp[i][j] = Math.min(dp[i-1][j-1], dp[i-1][j]) + triangle.get(i).get(j);
                }
            }
        }

        // 返回最后一行的最小值
        int minVal = Integer.MAX_VALUE;
        for (int val : dp[n-1]) minVal = Math.min(minVal, val);
        return minVal;
    }
}
```

### 方法四：自顶向下 DP + 空间优化

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        int[] dp = {triangle.get(0).get(0)};

        for (int i = 1; i < n; i++) {
            int[] newDp = new int[triangle.get(i).size()];

            for (int j = 0; j < triangle.get(i).size(); j++) {
                if (j == 0) {
                    newDp[j] = dp[0] + triangle.get(i).get(j);
                } else if (j == triangle.get(i).size() - 1) {
                    newDp[j] = dp[dp.length - 1] + triangle.get(i).get(j);
                } else {
                    newDp[j] = Math.min(dp[j-1], dp[j]) + triangle.get(i).get(j);
                }
            }

            dp = newDp;
        }

        int minVal = Integer.MAX_VALUE;
        for (int val : dp) minVal = Math.min(minVal, val);
        return minVal;
    }
}
```

### 方法五：记忆化递归

```java
class Solution {
    private int[][] memo;
    private List<List<Integer>> triangle;

    public int minimumTotal(List<List<Integer>> triangle) {
        this.triangle = triangle;
        int n = triangle.size();
        // 用 Integer.MAX_VALUE 表示未计算
        memo = new int[n][n];
        for (int[] row : memo) Arrays.fill(row, Integer.MAX_VALUE);
        return dfs(0, 0);
    }

    private int dfs(int i, int j) {
        if (i == triangle.size() - 1) {
            return triangle.get(i).get(j);
        }

        if (memo[i][j] != Integer.MAX_VALUE) return memo[i][j];

        // 选择下一行的 j 或 j+1
        memo[i][j] = triangle.get(i).get(j) + Math.min(dfs(i+1, j), dfs(i+1, j+1));
        return memo[i][j];
    }
}
```

## 复杂度分析

**方法一：原地修改**
- 时间复杂度：O(n²)，n 为三角形的行数
- 空间复杂度：O(1)，直接修改输入数组

**方法二：自底向上 + 额外数组**
- 时间复杂度：O(n²)
- 空间复杂度：O(n)，只需要一行的空间

**方法三、四：自顶向下**
- 时间复杂度：O(n²)
- 空间复杂度：O(n²) 或 O(n)

**方法五：记忆化递归**
- 时间复杂度：O(n²)
- 空间复杂度：O(n²)，缓存和递归栈

## 关键点总结

1. **自底向上优势**：不需要处理边界情况，代码更简洁
2. **原地修改技巧**：如果允许修改输入，可以达到 O(1) 空间
3. **状态转移方程**：
   - 自底向上：`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`
   - 自顶向下：`dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])`
4. **空间优化**：只需要保存相邻两行的状态
5. **相邻定义**：从 `(i, j)` 可以到 `(i+1, j)` 或 `(i+1, j+1)`

## 易错点

1. **边界处理**：自顶向下时要特殊处理第一列和最后一列
2. **相邻定义理解**：注意是下标 `j` 和 `j+1`，不是 `j-1` 和 `j+1`
3. **最终结果**：自顶向下需要取最后一行的最小值，自底向上直接是 `dp[0][0]`
4. **空间优化方向**：更新顺序很重要，避免覆盖还需要的值
5. **原地修改**：要确认题目是否允许修改输入数组
