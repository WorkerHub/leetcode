## 题目描述

给你 `m×n` 二进制矩阵 `grid` 和整数 `health`，从 (0,0) 走到 (m-1,n-1)，经过值为 1 的格子消耗 1 点 health，health 降为 0 则失败。判断是否存在安全路径（health 始终 > 0）。

## 解题思路

0-1 BFS：将问题转化为最小化 health 消耗的最短路。代价为 0（空格）的邻居加入队首，代价为 1（障碍）的邻居加入队尾。最终判断最小消耗是否严格小于 health。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean findSafeWalk(List<List<Integer>> grid, int health) {
        int m = grid.size(), n = grid.get(0).size();
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = grid.get(0).get(0);

        Deque<int[]> dq = new ArrayDeque<>();
        dq.offerFirst(new int[]{0, 0});

        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        while (!dq.isEmpty()) {
            int[] cur = dq.pollFirst();
            int r = cur[0], c = cur[1];
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                    int cost = dist[r][c] + grid.get(nr).get(nc);
                    if (cost < dist[nr][nc]) {
                        dist[nr][nc] = cost;
                        if (grid.get(nr).get(nc) == 0) {
                            dq.offerFirst(new int[]{nr, nc}); // 代价 0，加队首
                        } else {
                            dq.offerLast(new int[]{nr, nc});  // 代价 1，加队尾
                        }
                    }
                }
            }
        }
        return dist[m - 1][n - 1] < health; // 最小消耗严格小于 health
    }
}
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 关键点总结

1. 0-1 BFS：代价为 0 的邻居加队首，代价为 1 的加队尾，效率优于 Dijkstra
2. 判断条件是严格小于 health（health 必须 > 0 才能存活）
3. 起点本身也可能消耗 health（grid[0][0] == 1 时 dist[0][0] = 1）
