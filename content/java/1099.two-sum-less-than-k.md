## 题目描述

给定整数数组和整数 k，返回两数之和的最大值且小于 k。不存在返回 -1。

**示例：**
```
输入：nums = [34,23,1,24,75,33,54,8], k = 60
输出：58
```

## 解题思路

排序 + 双指针：排序后左右指针向中间移动，和 < k 时更新最大值并右移左指针，否则左移右指针。

## Java 代码实现

```java
class Solution {
    public int twoSumLessThanK(int[] nums, int k) {
        Arrays.sort(nums);
        int left = 0, right = nums.length - 1;
        int maxSum = -1;

        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum < k) {
                maxSum = Math.max(maxSum, sum);
                left++;
            } else {
                right--;
            }
        }

        return maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后双指针**：经典的两数之和变体
2. **移动策略**：和小则左移（尝试更大），和大则右移（减小）
3. **不需要索引**：只要值，所以可以排序
