## 题目描述

给定一个非负整数数组 nums 和一个整数 k，你需要将这个数组分成 k 个非空的连续子数组。

设计一个算法使得这 k 个子数组各自和的最大值最小。

**示例 1：**
```
输入：nums = [7,2,5,10,8], k = 2
输出：18
解释：一共有四种方法将 nums 分割为 2 个子数组。
其中最好的方式是将其分为 [7,2,5] 和 [10,8]，因为此时这两个子数组各自的和的最大值为18，在所有情况中最小。
```

**示例 2：**
```
输入：nums = [1,2,3,4,5], k = 2
输出：9
```

**示例 3：**
```
输入：nums = [1,4,4], k = 3
输出：4
```

**提示：**
- 1 <= nums.length <= 1000
- 0 <= nums[i] <= 10^6
- 1 <= k <= min(50, nums.length)

## 解题思路

这道题可以用二分查找或动态规划解决。

### 二分查找思路（推荐）

核心观察：
1. 答案的范围：[max(nums), sum(nums)]
   - 最小值：至少要包含最大的单个元素
   - 最大值：所有元素在一个子数组中
2. 如果能在限制为 mid 的情况下分成 <= k 个子数组，说明答案 <= mid
3. 二分查找答案，验证可行性

验证函数：
- 给定一个限制 limit，判断能否将数组分成 <= k 个子数组，每个子数组和 <= limit

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public int splitArray(int[] nums, int k) {
        // 确定二分查找的范围
        long left = 0, right = 0;
        for (int num : nums) {
            left = Math.max(left, num);  // 最小可能：包含最大元素
            right += num;                // 最大可能：所有元素在一个子数组
        }

        while (left < right) {
            long mid = (left + right) / 2;

            if (canSplit(nums, k, mid)) {
                // 可以分成 <= k 个，尝试更小的 max_sum
                right = mid;
            } else {
                // 不能分成 <= k 个，需要更大的 max_sum
                left = mid + 1;
            }
        }

        return (int) left;
    }

    /**
     * 判断是否能将数组分成 <= k 个子数组，每个和 <= maxSum
     */
    private boolean canSplit(int[] nums, int k, long maxSum) {
        int count = 1;       // 至少需要一个子数组
        long currentSum = 0;

        for (int num : nums) {
            if (currentSum + num <= maxSum) {
                currentSum += num;
            } else {
                // 需要新的子数组
                count++;
                currentSum = num;
            }
        }

        return count <= k;
    }
}
```

### 方法二：动态规划

```java
import java.util.Arrays;

class Solution {
    public int splitArray(int[] nums, int k) {
        int n = nums.length;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        // dp[i][j] = 将前 i 个数分成 j 个子数组的最小的最大子数组和
        long[][] dp = new long[n + 1][k + 1];
        for (long[] row : dp) Arrays.fill(row, Long.MAX_VALUE / 2);
        dp[0][0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= Math.min(i, k); j++) {
                // 枚举第 j 个子数组的起始位置 p+1
                for (int p = j - 1; p < i; p++) {
                    // 第 j 个子数组是 nums[p..i-1]，和为 prefix[i] - prefix[p]
                    long subSum = prefix[i] - prefix[p];
                    dp[i][j] = Math.min(dp[i][j], Math.max(dp[p][j - 1], subSum));
                }
            }
        }

        return (int) dp[n][k];
    }
}
```

### 方法三：记忆化搜索

```java
import java.util.Arrays;

class Solution {
    private int[] nums;
    private long[] prefix;
    private long[][] memo;
    private int n;

    public int splitArray(int[] nums, int k) {
        this.nums = nums;
        this.n = nums.length;

        // 前缀和
        prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        // 记忆化表，初始化为 -1
        memo = new long[n][k + 1];
        for (long[] row : memo) Arrays.fill(row, -1);

        return (int) dfs(0, k);
    }

    /**
     * 从 index 开始，分成 remaining 个子数组，返回最小的最大子数组和
     */
    private long dfs(int index, int remaining) {
        // 剩余只有一个子数组
        if (remaining == 1) {
            return prefix[n] - prefix[index];
        }

        if (memo[index][remaining] != -1) {
            return memo[index][remaining];
        }

        long result = Long.MAX_VALUE / 2;

        // 枚举当前子数组的结束位置
        for (int i = index; i <= n - remaining; i++) {
            // 当前子数组 nums[index..i]
            long currentSum = prefix[i + 1] - prefix[index];

            // 剩余部分的最优解（提前剪枝：currentSum 已经大于 result 则跳过）
            if (currentSum >= result) break;

            long rest = dfs(i + 1, remaining - 1);
            result = Math.min(result, Math.max(currentSum, rest));
        }

        memo[index][remaining] = result;
        return result;
    }
}
```

## 复杂度分析

### 方法一：二分查找

- **时间复杂度**：O(n * log(sum - max))
  - 二分查找次数：O(log(sum - max))
  - 每次验证：O(n)

- **空间复杂度**：O(1)

### 方法二：动态规划

- **时间复杂度**：O(n^2 * k)

- **空间复杂度**：O(n * k)

### 方法三：记忆化搜索

- **时间复杂度**：O(n^2 * k)
  - 状态数 O(n * k)，每个状态 O(n) 时间

- **空间复杂度**：O(n * k)

## 关键点总结

1. 二分查找答案的技巧
2. 验证函数的设计（贪心）
3. 答案范围的确定：[max(nums), sum(nums)]
4. DP 状态定义：前 i 个元素分成 j 组的最优解
5. 使用 `long` 处理整数溢出（sum 最大为 1000 * 10^6 = 10^9，超过 int 范围）

## 易错点

1. **整数溢出**：
   - 数组元素之和最大为 1000 * 10^6 = 10^9，接近 int 上限
   - 使用 `long` 类型存储 left、right 和 prefix

2. **二分边界条件**：
   - `left = max(nums)`（不能用 0，因为每个子数组至少包含一个元素）
   - `right = sum(nums)`（最大情况，所有元素在一组）
   - 使用 `left < right` 而非 `left <= right`

3. **验证函数的正确性**：
   - 贪心地尽量将元素放入当前子数组
   - 当加入新元素会超过限制时，开启新子数组

4. **DP 状态转移**：
   - 需要三层循环：枚举元素数、子数组数、分割点
   - 注意初始化为足够大的值
