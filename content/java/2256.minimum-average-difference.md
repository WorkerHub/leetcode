## 题目描述

求平均差最小的下标：|前i+1个元素均值 - 后n-i-1个元素均值|最小。

## 解题思路

维护前缀和，遍历每个下标计算左右均值之差（整数除法），取最小差的最小下标。

## Java 代码实现

```java
class Solution {
    public int minimumAverageDifference(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        long prefix = 0;
        int ans = 0;
        long minDiff = Long.MAX_VALUE;

        for (int i = 0; i < n; i++) {
            prefix += nums[i];
            long suffix = total - prefix;
            long leftAvg = prefix / (i + 1);
            long rightAvg = (i < n - 1) ? suffix / (n - i - 1) : 0;
            long diff = Math.abs(leftAvg - rightAvg);
            if (diff < minDiff) {
                minDiff = diff;
                ans = i;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和递推**：避免重复计算
2. **整数除法向下取整**：Java的/对正数天然向下取整
3. **用long防溢出**：元素和可能超int范围
