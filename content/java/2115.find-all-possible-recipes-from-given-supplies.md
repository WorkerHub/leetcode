## 题目描述

给定菜品数组recipes、对应原料ingredients和初始供应supplies，菜品可作为其他菜品的原料。返回所有能做出的菜。

## 解题思路

拓扑排序BFS：每道菜的入度为未满足原料数。supplies中的原料作为起点，满足原料后入度减一，入度为0时可制作。

## Java 代码实现

```java
class Solution {
    public List<String> findAllRecipes(String[] recipes, List<List<String>> ingredients, String[] supplies) {
        // 建图：原料 -> 依赖它的菜
        Map<String, List<String>> graph = new HashMap<>();
        Map<String, Integer> inDegree = new HashMap<>();
        Set<String> recipeSet = new HashSet<>(Arrays.asList(recipes));
        
        for (int i = 0; i < recipes.length; i++) {
            inDegree.put(recipes[i], ingredients.get(i).size());
            for (String ing : ingredients.get(i)) {
                graph.computeIfAbsent(ing, k -> new ArrayList<>()).add(recipes[i]);
            }
        }
        
        // BFS从supplies开始
        Queue<String> queue = new LinkedList<>();
        for (String s : supplies) queue.offer(s);
        
        List<String> result = new ArrayList<>();
        while (!queue.isEmpty()) {
            String item = queue.poll();
            if (recipeSet.contains(item)) {
                result.add(item);
            }
            if (graph.containsKey(item)) {
                for (String dep : graph.get(item)) {
                    inDegree.put(dep, inDegree.get(dep) - 1);
                    if (inDegree.get(dep) == 0) {
                        queue.offer(dep);
                    }
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **拓扑排序BFS**：天然处理依赖链和循环依赖
2. **入度为未满足原料数**：满足一个减一，为0时可制作
3. **循环依赖**：入度永远不为0，不会进入队列
