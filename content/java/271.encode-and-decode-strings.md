## 题目描述

设计一个算法来编码一个字符串列表。编码后的字符串会通过网络发送，并且会在接收端被解码回原来的字符串列表。

请实现 `encode` 和 `decode` 方法。

**示例 1：**
```
输入: ["Hello","World"]
输出: ["Hello","World"]
解释:
encode: "Hello" 和 "World" 被编码成一个字符串
decode: 将编码后的字符串解码回原始列表
```

**示例 2：**
```
输入: [""]
输出: [""]
```

**示例 3：**
```
输入: []
输出: []
```

**提示：**
- 0 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- strs[i] 包含任何可能的字符，包括所有 256 个合法的 ASCII 字符

**注意：**
- 不要使用 Java 的内置序列化方法
- 字符串可能包含任何字符，包括分隔符

## 解题思路

这道题的核心挑战是：**如何选择一个分隔符，使得它不会与字符串内容冲突？**

### 关键观察

1. 不能简单使用单个字符作为分隔符（如逗号、分号），因为字符串本身可能包含这些字符
2. 需要一种方法来标记每个字符串的边界
3. 常见方案：
   - 使用长度前缀：`长度 + 分隔符 + 内容`
   - 使用转义字符：将特殊字符转义
   - 使用非 ASCII 字符

### 最优方案：长度前缀编码

采用 `长度 + '#' + 内容` 的格式：
- 每个字符串前面加上它的长度和一个分隔符（如 `#`）
- 解码时先读取长度，然后根据长度精确读取字符串内容
- 这样即使字符串包含 `#`，也不会影响解码

## Java 代码实现

### 方法一：长度前缀编码（推荐）

```java
import java.util.ArrayList;
import java.util.List;

public class Codec {

    /**
     * 编码字符串列表为单个字符串
     * 格式: 长度#字符串内容长度#字符串内容...
     */
    public String encode(List<String> strs) {
        if (strs == null || strs.isEmpty()) {
            return "";
        }

        StringBuilder sb = new StringBuilder();
        for (String s : strs) {
            // 格式: "长度#内容"
            sb.append(s.length()).append('#').append(s);
        }
        return sb.toString();
    }

    /**
     * 解码字符串为字符串列表
     */
    public List<String> decode(String s) {
        List<String> result = new ArrayList<>();
        if (s == null || s.isEmpty()) {
            return result;
        }

        int i = 0;
        while (i < s.length()) {
            // 找到 '#' 的位置
            int j = i;
            while (s.charAt(j) != '#') {
                j++;
            }

            // 提取长度
            int length = Integer.parseInt(s.substring(i, j));

            // 提取字符串内容，跳过 '#'
            i = j + 1;
            result.add(s.substring(i, i + length));

            // 移动到下一个字符串
            i += length;
        }

        return result;
    }
}
```

### 方法二：使用特殊分隔符（转义方案）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Codec {

    /**
     * 使用转义字符方案
     * 将分隔符 ":;" 用于分隔，字符串中的 ":" 转义为 "::"
     */
    public String encode(List<String> strs) {
        if (strs == null || strs.isEmpty()) {
            return "";
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < strs.size(); i++) {
            // 将 ':' 替换为 '::'
            String escaped = strs.get(i).replace(":", "::");
            if (i > 0) {
                sb.append(":;");
            }
            sb.append(escaped);
        }
        return sb.toString();
    }

    /**
     * 解码转义后的字符串
     */
    public List<String> decode(String s) {
        List<String> result = new ArrayList<>();
        if (s == null || s.isEmpty()) {
            return result;
        }

        // 按 ":;" 分割
        String[] parts = s.split(":;", -1);
        for (String part : parts) {
            // 还原转义的 ':'
            result.add(part.replace("::", ":"));
        }
        return result;
    }
}
```

### 方法三：使用非 ASCII 字符分隔

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Codec {

    // 使用超出 ASCII 范围的字符作为分隔符
    private static final String DELIMITER = String.valueOf((char) 257);

    /**
     * 使用非 ASCII 字符作为分隔符
     */
    public String encode(List<String> strs) {
        if (strs == null || strs.isEmpty()) {
            return "";
        }
        return String.join(DELIMITER, strs);
    }

    /**
     * 按非 ASCII 字符分割字符串
     */
    public List<String> decode(String s) {
        if (s == null || s.isEmpty()) {
            return new ArrayList<>();
        }
        return Arrays.asList(s.split(DELIMITER, -1));
    }
}
```

## 复杂度分析

### 方法一：长度前缀编码

**时间复杂度：**
- 编码：O(n)，n 是所有字符串的总长度
- 解码：O(n)，需要遍历整个编码字符串

**空间复杂度：**
- O(n)，存储编码/解码结果

### 方法二：转义方案

**时间复杂度：**
- 编码：O(n)，需要替换每个字符串中的 `:`
- 解码：O(n)，需要分割和还原

**空间复杂度：**
- O(n)

### 方法三：非 ASCII 字符

**时间复杂度：**
- 编码：O(n)
- 解码：O(n)

**空间复杂度：**
- O(n)

## 关键点总结

1. **长度前缀是最可靠的方案**：不依赖于字符串内容，适用于任意字符
2. **转义方案的问题**：需要仔细处理转义字符，容易出错
3. **非 ASCII 方案的问题**：题目说明字符串可能包含 256 个 ASCII 字符，需确认约束
4. **边界情况**：空字符串列表、包含空字符串的列表
5. **Java 注意**：使用 `StringBuilder` 拼接字符串，避免 `+` 操作产生大量临时对象

## 易错点

1. **分隔符冲突**：使用单字符分隔符时，字符串内容可能包含该字符
   ```java
   // 错误示例
   public String encode(List<String> strs) {
       return String.join(",", strs);  // 如果字符串包含 ','，解码会出错
   }
   ```

2. **空字符串处理**：要正确处理空字符串
   ```java
   // 正确处理
   encode(Arrays.asList("")) -> "0#"
   decode("0#") -> [""]
   ```

3. **整数解析错误**：在长度前缀方案中，要正确解析长度
   ```java
   // 错误：假设长度只有一位数字
   int length = s.charAt(i) - '0';  // 当长度 >= 10 时会出错
   
   // 正确：找到 '#' 再解析
   int j = i;
   while (s.charAt(j) != '#') j++;
   int length = Integer.parseInt(s.substring(i, j));
   ```

4. **字符串拼接性能**：使用 `StringBuilder`，而不是直接用 `+` 拼接
