## 题目描述

可以用字符串表示一个学生的出勤记录，其中每个字符用来标记当天的出勤情况（缺勤、迟到、到场）。记录中只包含以下三个字符：

- `'A'`：Absent，缺勤
- `'L'`：Late，迟到
- `'P'`：Present，到场

如果学生能够**同时**满足下面两个条件，则可以获得出勤奖励：

- 按总出勤计，学生缺勤（`'A'`）严格少于两天
- 学生不会存在连续 3 天或连续 3 天以上的迟到（`'L'`）记录

给定一个整数 `n`，返回记录长度为 `n` 时，可能获得出勤奖励的记录情况数量。答案可能很大，所以返回对 `10^9 + 7` **取余**的结果。

**示例 1：**
```
输入：n = 2
输出：8
解释：有 8 种长度为 2 的记录会被奖励：
"PP", "AP", "PA", "LP", "PL", "AL", "LA", "LL"
只有 "AA" 不会被奖励，因为缺勤次数为 2。
```

**示例 2：**
```
输入：n = 1
输出：3
```

**示例 3：**
```
输入：n = 10101
输出：183236316
```

**提示：**
- `1 <= n <= 10^5`

## 解题思路

这是一道困难的动态规划题目，需要在满足约束条件下统计方案数。

核心思想：
1. 使用**状态机 DP**，定义状态表示不同的出勤情况
2. 状态转移需要考虑缺勤次数和连续迟到次数的限制
3. 使用取模避免整数溢出

状态定义：
- `dp[i][j][k]` 表示前 i 天，有 j 次缺勤，以连续 k 次迟到结尾的方案数
- `j ∈ {0, 1}`（缺勤次数最多 1 次）
- `k ∈ {0, 1, 2}`（连续迟到次数最多 2 次）

状态转移：
1. **添加 P（到场）**：`dp[i][j][0] += dp[i-1][j][0] + dp[i-1][j][1] + dp[i-1][j][2]`
2. **添加 A（缺勤）**：`dp[i][1][0] += dp[i-1][0][0] + dp[i-1][0][1] + dp[i-1][0][2]`
3. **添加 L（迟到）**：
   - `dp[i][j][1] += dp[i-1][j][0]`
   - `dp[i][j][2] += dp[i-1][j][1]`

## Java 代码实现

### 方法一：三维 DP（标准解法）⭐

```java
class Solution {
    public int checkRecord(int n) {
        // 三维动态规划
        // dp[i][j][k] = 前 i 天，j 次缺勤，结尾连续 k 个 L 的方案数
        final int MOD = 1_000_000_007;

        // dp[j][k]: j 次缺勤（0 或 1），结尾连续 k 次 L（0,1,2）
        long[][][] dp = new long[n + 1][2][3];
        // 初始状态：第 0 天，没有缺勤，没有连续迟到
        dp[0][0][0] = 1;

        for (int i = 1; i <= n; i++) {
            // 添加 P（到场）：不增加缺勤，连续迟到重置为 0
            for (int j = 0; j < 2; j++) {
                for (int k = 0; k < 3; k++) {
                    dp[i][j][0] = (dp[i][j][0] + dp[i - 1][j][k]) % MOD;
                }
            }

            // 添加 A（缺勤）：缺勤次数 +1，连续迟到重置为 0
            for (int k = 0; k < 3; k++) {
                dp[i][1][0] = (dp[i][1][0] + dp[i - 1][0][k]) % MOD;
            }

            // 添加 L（迟到）：不增加缺勤，连续迟到 +1
            for (int j = 0; j < 2; j++) {
                for (int k = 1; k < 3; k++) {
                    dp[i][j][k] = (dp[i][j][k] + dp[i - 1][j][k - 1]) % MOD;
                }
            }
        }

        // 统计所有合法状态
        long result = 0;
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 3; k++) {
                result = (result + dp[n][j][k]) % MOD;
            }
        }

        return (int) result;
    }
}
```

### 方法二：空间优化（滚动数组）⭐

```java
class Solution {
    public int checkRecord(int n) {
        // 空间优化：只需要前一天的状态
        final int MOD = 1_000_000_007;

        // prev[j][k]: 上一天缺勤 j 次，结尾连续 k 个 L 的方案数
        long[][] prev = new long[2][3];
        prev[0][0] = 1;

        for (int i = 0; i < n; i++) {
            long[][] curr = new long[2][3];

            // 添加 P
            for (int j = 0; j < 2; j++) {
                for (int k = 0; k < 3; k++) {
                    curr[j][0] = (curr[j][0] + prev[j][k]) % MOD;
                }
            }

            // 添加 A
            for (int k = 0; k < 3; k++) {
                curr[1][0] = (curr[1][0] + prev[0][k]) % MOD;
            }

            // 添加 L
            for (int j = 0; j < 2; j++) {
                for (int k = 1; k < 3; k++) {
                    curr[j][k] = (curr[j][k] + prev[j][k - 1]) % MOD;
                }
            }

            prev = curr;
        }

        // 统计结果
        long result = 0;
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 3; k++) {
                result = (result + prev[j][k]) % MOD;
            }
        }

        return (int) result;
    }
}
```

## 复杂度分析

**方法一（标准 DP）：**
- **时间复杂度**：O(n)，遍历 n 天，每天处理常数个状态
- **空间复杂度**：O(n)，存储 n+1 天的状态

**方法二（空间优化）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，只使用两个 2×3 的数组

## 关键点总结

1. **状态设计**：使用三维状态 `[天数][缺勤次数][连续迟到次数]` 表示方案数
2. **状态转移**：根据添加 P/A/L 进行不同的转移
3. **取模运算**：每次累加都要取模，防止整数溢出
4. **空间优化**：使用滚动数组优化空间到 O(1)
5. **long 类型**：Java 中使用 long 防止中间计算溢出

## 易错点

1. **取模时机**：每次加法都要取模，不能只在最后取模
2. **状态初始化**：`dp[0][0][0] = 1` 表示第 0 天的初始状态
3. **循环边界**：
   - 缺勤次数 j 只有 0 和 1
   - 连续迟到次数 k 只有 0、1、2
4. **状态转移顺序**：
   - 添加 L 时，k 要从 1 开始（因为需要 k-1）
   - 添加 A 时，只能从 j=0 转移到 j=1
5. **结果统计**：需要累加所有合法状态（j=0,1; k=0,1,2）
