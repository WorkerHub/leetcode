## 题目描述

删除与前一个保留词互为变位词的字符串，返回最终结果数组。

## 解题思路

维护结果列表，当前词排序后与结果末尾词排序不同时才加入。

## Java 代码实现

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> result = new ArrayList<>();
        result.add(words[0]);

        for (int i = 1; i < words.length; i++) {
            char[] curr = words[i].toCharArray();
            char[] prev = result.get(result.size() - 1).toCharArray();
            Arrays.sort(curr);
            Arrays.sort(prev);
            if (!Arrays.equals(curr, prev)) {
                result.add(words[i]);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * L log L)，L为最长单词长度
- **空间复杂度**：O(N * L)

## 关键点总结

1. **与结果末尾比较**：不是与原数组前一个比较
2. **排序判断变位词**：排序后相等即为变位词
3. **第一个词必定保留**
