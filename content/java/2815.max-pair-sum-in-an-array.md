## 题目描述

给你整数数组 `nums`，找出"最大数字"（各位数字中最大值）相同的两个数，返回这样的数对中最大的和，若不存在返回 -1。

## Java 代码实现

```java
class Solution {
    public int maxSum(int[] nums) {
        int[] maxByKey = new int[10]; // maxByKey[d] = 最大数字为 d 的已见最大值
        int ans = -1;
        for (int num : nums) {
            int key = maxDigit(num);
            if (maxByKey[key] > 0) {
                ans = Math.max(ans, maxByKey[key] + num);
            }
            maxByKey[key] = Math.max(maxByKey[key], num);
        }
        return ans;
    }

    int maxDigit(int x) {
        int d = 0;
        while (x > 0) {
            d = Math.max(d, x % 10);
            x /= 10;
        }
        return d;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log V)，V 为 nums 中最大值
- 空间复杂度：O(1)，哈希表最多 10 个键

## 关键点总结

1. 最大数字 = 整数各位中的最大值
2. 用大小为 10 的数组记录每个最大数字对应的已见最大值
3. 一次遍历：先更新答案，再更新最大值
