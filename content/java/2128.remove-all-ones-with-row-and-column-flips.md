## 题目描述

给定二进制矩阵，每次可翻转一行或一列（0变1,1变0），判断能否变成全零矩阵。

## 解题思路

等价条件：每行要么与第一行相同，要么是第一行的位取反。满足则可通过行列翻转变全零。

## Java 代码实现

```java
class Solution {
    public boolean removeOnes(int[][] grid) {
        int[] first = grid[0];
        int n = first.length;
        
        for (int i = 1; i < grid.length; i++) {
            boolean same = true, complement = true;
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != first[j]) same = false;
                if (grid[i][j] != 1 - first[j]) complement = false;
            }
            if (!same && !complement) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(1)

## 关键点总结

1. **等价条件**：所有行必须与第一行相同或互补
2. **证明**：相同行翻转后一致，互补行通过行翻转统一，再列翻转变零
3. **只需与第一行比较**：无需两两比较
