## 题目描述

实现 `AuthenticationManager` 类：构造函数接受 `timeToLive`；`generate` 生成令牌；`renew` 续期未过期的令牌；`countUnexpiredTokens` 统计未过期令牌数。过期时刻 `<= currentTime` 时视为已过期。

## 解题思路

用 HashMap 存储 `tokenId -> 过期时间`。generate 直接覆盖，renew 检查是否未过期，count 遍历统计。

## Java 代码实现

```java
import java.util.*;

class AuthenticationManager {
    private int ttl;
    private Map<String, Integer> tokens; // tokenId -> 过期时间

    public AuthenticationManager(int timeToLive) {
        this.ttl = timeToLive;
        this.tokens = new HashMap<>();
    }

    public void generate(String tokenId, int currentTime) {
        // 生成新令牌，设置过期时间
        tokens.put(tokenId, currentTime + ttl);
    }

    public void renew(String tokenId, int currentTime) {
        // 只有令牌存在且未过期（expire > currentTime）才续期
        Integer expire = tokens.get(tokenId);
        if (expire != null && expire > currentTime) {
            tokens.put(tokenId, currentTime + ttl);
        }
    }

    public int countUnexpiredTokens(int currentTime) {
        int count = 0;
        for (int expire : tokens.values()) {
            if (expire > currentTime) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- `generate`：O(1)
- `renew`：O(1)
- `countUnexpiredTokens`：O(n)

## 关键点总结

1. 过期判断：`expire > currentTime`（等于时已过期）
2. generate 时令牌一定不存在或已过期，可直接覆盖
