## 题目描述

给定字符串 `s` 和包含恰好一个 `'*'` 的模式 `p`，`'*'` 可匹配任意字符序列（含空），判断 `p` 是否能匹配 `s` 的某个子串。

## Java 代码实现

```java
class Solution {
    public boolean hasMatch(String s, String p) {
        int starIdx = p.indexOf('*');
        String prefix = p.substring(0, starIdx);
        String suffix = p.substring(starIdx + 1);

        // 在 s 中找 prefix 最靠前的位置
        int start = s.indexOf(prefix);
        if (start == -1) return false;

        // 在 prefix 之后的部分检查是否以 suffix 结尾
        String afterPrefix = s.substring(start + prefix.length());
        return afterPrefix.endsWith(suffix);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，字符串查找
- 空间复杂度：O(n)，子串切片

## 关键点总结

1. 将 `p` 按 `'*'` 分为 prefix 和 suffix。
2. 找 prefix 最靠前的位置，之后检查剩余部分是否以 suffix 结尾。
3. prefix 越靠前，后缀有更多匹配空间（贪心正确）。
