## 题目描述

统计不在竖线对|...|之间的星号*数目。

## 解题思路

遍历字符串，用布尔标志跟踪是否在竖线对内。遇|翻转状态，不在对内遇*则计数。

## Java 代码实现

```java
class Solution {
    public int countAsterisks(String s) {
        int count = 0;
        boolean inPair = false;

        for (char c : s.toCharArray()) {
            if (c == '|') {
                inPair = !inPair;
            } else if (c == '*' && !inPair) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **布尔标志跟踪状态**：是否在|对内
2. **遇|翻转**：成对出现保证正确性
3. **只统计对外的***
