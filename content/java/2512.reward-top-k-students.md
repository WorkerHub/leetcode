## 题目描述

给你正面/负面反馈词列表和学生报告，每出现正面词得 3 分，负面词扣 1 分，返回得分最高的前 k 名学生 id（分数降序，相同则 id 升序）。

## 解题思路

将正负词存入 HashSet，对每个报告分词统计得分，最后按（分数降序，id 升序）排序取前 k 个。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> topStudents(String[] positive_feedback, String[] negative_feedback,
                                     String[] report, int[] student_id, int k) {
        Set<String> pos = new HashSet<>(Arrays.asList(positive_feedback));
        Set<String> neg = new HashSet<>(Arrays.asList(negative_feedback));

        int n = report.length;
        int[][] scores = new int[n][2]; // [score, id]
        for (int i = 0; i < n; i++) {
            int score = 0;
            for (String word : report[i].split(" ")) {
                if (pos.contains(word)) score += 3;
                else if (neg.contains(word)) score -= 1;
            }
            scores[i][0] = score;
            scores[i][1] = student_id[i];
        }

        // 按分数降序，id 升序排列
        Arrays.sort(scores, (a, b) -> a[0] != b[0] ? b[0] - a[0] : a[1] - b[1]);

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < k; i++) ans.add(scores[i][1]);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L + n log n)，L 为报告平均词数
- **空间复杂度**：O(n + P + N)

## 关键点总结

1. HashSet 存储词汇，单词查找 O(1)
2. 排序键：先按分数降序，再按 id 升序
3. `Arrays.sort` 的比较器用 `b[0]-a[0]` 实现分数降序
