## 题目描述

给你一个长度为 `n` 的非空字符串数组 `words`，返回长度为 `n` 的数组 `ans`，其中 `ans[i]` 等于第 `i` 个字符串所有前缀的分数之和（某前缀的分数等于 `words` 中以该前缀开头的字符串数目）。

## 解题思路

构建字典树，插入时路径上每个节点的 `count` 加 1，表示经过该节点的字符串数量。查询时沿路径累加所有节点的 `count` 即为该单词的前缀分数之和。

## Java 代码实现

```java
class Solution {
    // 字典树节点
    static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int count = 0; // 经过此节点的字符串数量
    }

    private TrieNode root = new TrieNode();

    // 插入单词，路径上每个节点 count+1
    private void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            node = node.children[idx];
            node.count++;
        }
    }

    // 查询单词所有前缀的分数之和
    private int score(String word) {
        TrieNode node = root;
        int total = 0;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) break;
            node = node.children[idx];
            total += node.count;
        }
        return total;
    }

    public int[] sumPrefixScores(String[] words) {
        // 将所有单词插入字典树
        for (String word : words) {
            insert(word);
        }
        // 查询每个单词的前缀分数之和
        int[] ans = new int[words.length];
        for (int i = 0; i < words.length; i++) {
            ans[i] = score(words[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L)，n 为单词数，L 为平均单词长度
- **空间复杂度**：O(n * L)，字典树节点总数

## 关键点总结

1. 字典树每个节点的 `count` 统计经过该节点的单词数
2. 对每个单词，沿字典树遍历，将路径上所有节点的 `count` 累加
3. 使用数组 `children[26]` 代替哈希表，效率更高
