## 题目描述

二进制矩阵中，统计三个1组成的直角三角形数目（两个在同行，一个在同列，直角在交点处）。

## 解题思路

预计算每行每列1的数量。对每个值为1的格子(i,j)，它作为直角顶点的贡献为(row[i]-1)*(col[j]-1)。

## Java 代码实现

```java
class Solution {
    public long numberOfRightTriangles(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] row = new int[m];
        int[] col = new int[n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    row[i]++;
                    col[j]++;
                }
            }
        }
        long ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    ans += (long)(row[i] - 1) * (col[j] - 1);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N)
- **空间复杂度**：O(M+N)

## 关键点总结

1. **直角顶点贡献**：(row[i]-1)*(col[j]-1)
2. **预计算行列1的个数**避免重复计算
3. **注意用long防溢出**
