## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

**示例 1：**
```
输入：nums = [1,3,5,6], target = 5
输出：2
```

**示例 2：**
```
输入：nums = [1,3,5,6], target = 2
输出：1
```

**示例 3：**
```
输入：nums = [1,3,5,6], target = 7
输出：4
```

## 解题思路

### 核心思想：二分查找

要求 O(log n) 时间复杂度，使用二分查找。

**问题本质：**
- 找第一个 `>= target` 的位置
- 如果找到 `target`，返回其位置
- 如果没找到，返回插入位置（第一个大于 `target` 的位置）

**算法流程：**
1. 使用标准二分查找
2. 当 `nums[mid] < target` 时，`left = mid + 1`
3. 当 `nums[mid] >= target` 时，`right = mid - 1`
4. 最后返回 `left`

## Java 代码实现

### 方法一：标准二分查找

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        // 如果没找到，left就是插入位置
        return left;
    }
}
```

### 方法二：找第一个 >= target 的位置

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                // nums[mid] >= target，继续向左找
                right = mid - 1;
            }
        }
        
        return left;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，标准二分查找
- **空间复杂度**：O(1)，只使用常量额外空间

## 图解示例

### 示例 1：`nums = [1,3,5,6], target = 5`

```
[1,3,5,6]
 ↑   ↑ ↑
left mid right

nums[mid]=3 < 5, left = mid + 1

[1,3,5,6]
     ↑ ↑
   left/mid right

nums[mid]=5 == 5, 返回 2
```

### 示例 2：`nums = [1,3,5,6], target = 2`

```
[1,3,5,6]
 ↑   ↑ ↑
left mid right

nums[mid]=3 >= 2, right = mid - 1

[1,3,5,6]
 ↑↑
right left

返回 left = 1（插入位置）
```

### 示例 3：`nums = [1,3,5,6], target = 7`

```
[1,3,5,6]
 ↑   ↑ ↑
left mid right

nums[mid]=3 < 7, left = mid + 1

[1,3,5,6]
     ↑ ↑
   left mid/right

nums[mid]=5 < 7, left = mid + 1

[1,3,5,6]
       ↑
    right left

返回 left = 4（插入位置）
```

## 关键点总结

1. **返回值**：
   - 找到：返回 `target` 的位置
   - 没找到：返回 `left`（插入位置）

2. **为什么返回 left**：
   - 当 `left > right` 时，循环结束
   - `left` 指向第一个 `>= target` 的位置
   - 恰好是插入位置

3. **简化思路**：
   - 本题就是找"第一个 >= target 的位置"
   - 可以用统一的模板处理

## 易错点

1. **返回值**：
   - 不是返回 `mid`，而是返回 `left`
   - `left` 在循环结束后就是答案

2. **循环条件**：
   - `while (left <= right)`（有等号）

3. **边界情况**：
   - `target` 比所有元素都大：返回 `nums.length`
   - `target` 比所有元素都小：返回 `0`
   - 数组为空：返回 `0`

## 二分查找模板对比

| 问题 | 条件 | 返回 |
|------|------|------|
| 找 target | `nums[mid] == target` | `mid` |
| 找第一个 >= target | `nums[mid] >= target` 时 `right=mid-1` | `left` |
| 找第一个 > target | `nums[mid] > target` 时 `right=mid-1` | `left` |
| 插入位置 | 找第一个 >= target | `left` |
