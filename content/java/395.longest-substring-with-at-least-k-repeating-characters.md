## 题目描述

给你一个字符串 `s` 和一个整数 `k`，请你找出 `s` 中的最长子串，要求该子串中的每一字符出现次数都不少于 `k`。返回这一子串的长度。

如果不存在这样的子字符串，则返回 0。

**示例 1:**

```
输入：s = "aaabb", k = 3
输出：3
解释：最长子串为 "aaa"，其中 'a' 重复了 3 次。
```

**示例 2:**

```
输入：s = "ababbc", k = 2
输出：5
解释：最长子串为 "ababb"，其中 'a' 重复了 2 次，'b' 重复了 3 次。
```

**提示:**

- `1 <= s.length <= 10^4`
- `s` 仅由小写英文字母组成
- `1 <= k <= 10^5`

## 解题思路

本题是一道有趣的字符串问题，可以用**分治**或**滑动窗口**解决。

### 核心思想

**关键观察：**

如果某个字符在整个字符串中出现次数小于 k，那么它不可能出现在任何合法子串中。我们可以用这个字符作为分隔符，将字符串分割成多个部分，递归求解每个部分的最长子串。

### 思路一：分治（推荐）⭐

**算法流程：**

1. 统计字符串中每个字符的出现次数
2. 找到第一个出现次数小于 k 的字符
3. 如果没有这样的字符，整个字符串都满足条件
4. 如果有，以该字符为分隔符，递归求解左右两部分
5. 返回左右两部分的最大值

**时间复杂度：** O(n * 26) = O(n)

### 思路二：滑动窗口

枚举子串中不同字符的数量（1-26），对于每个数量，使用滑动窗口找到最长的满足条件的子串。

## Java 代码实现

### 方法一：分治递归（推荐）⭐

```java
class Solution {
    public int longestSubstring(String s, int k) {
        // 分治递归
        // 时间复杂度: O(n * 26) = O(n)
        // 空间复杂度: O(n) - 递归栈

        // 递归终止条件
        if (s.length() < k) return 0;

        // 统计字符频次
        int[] counter = new int[26];
        for (char c : s.toCharArray()) {
            counter[c - 'a']++;
        }

        // 找到第一个出现次数小于 k 的字符
        for (int i = 0; i < 26; i++) {
            if (counter[i] > 0 && counter[i] < k) {
                // 以该字符为分隔符，递归求解每个部分
                char splitChar = (char)('a' + i);
                int max = 0;
                for (String sub : s.split(String.valueOf(splitChar))) {
                    max = Math.max(max, longestSubstring(sub, k));
                }
                return max;
            }
        }

        // 所有字符出现次数都 >= k
        return s.length();
    }
}
```

### 方法二：优化的分治

```java
class Solution {
    public int longestSubstring(String s, int k) {
        // 优化的分治，避免重复统计
        return helper(s, 0, s.length(), k);
    }

    private int helper(String s, int start, int end, int k) {
        // 递归辅助函数
        if (end - start < k) return 0;

        // 统计频次
        int[] counter = new int[26];
        for (int i = start; i < end; i++) {
            counter[s.charAt(i) - 'a']++;
        }

        // 找分隔符
        for (int mid = start; mid < end; mid++) {
            int charIdx = s.charAt(mid) - 'a';
            if (counter[charIdx] < k) {
                // 递归左右两部分
                int left = helper(s, start, mid, k);
                int right = helper(s, mid + 1, end, k);
                return Math.max(left, right);
            }
        }

        // 没有找到分隔符，整个区间都满足
        return end - start;
    }
}
```

### 方法三：滑动窗口

```java
class Solution {
    public int longestSubstring(String s, int k) {
        // 滑动窗口：枚举子串中不同字符的数量
        // 时间复杂度: O(26 * n) = O(n)
        // 空间复杂度: O(1)
        int maxLen = 0;

        // 枚举子串中不同字符的数量（1-26）
        for (int targetUnique = 1; targetUnique <= 26; targetUnique++) {
            maxLen = Math.max(maxLen, slidingWindow(s, k, targetUnique));
        }

        return maxLen;
    }

    private int slidingWindow(String s, int k, int targetUnique) {
        // 找到恰好包含 targetUnique 种字符的最长子串，
        // 且每个字符出现次数 >= k
        int[] charCount = new int[26];
        int left = 0;
        int maxLen = 0;
        int unique = 0;     // 当前窗口中不同字符数
        int atLeastK = 0;   // 出现次数 >= k 的字符数

        for (int right = 0; right < s.length(); right++) {
            int charIdx = s.charAt(right) - 'a';

            if (charCount[charIdx] == 0) unique++;
            charCount[charIdx]++;

            if (charCount[charIdx] == k) atLeastK++;

            // 收缩窗口
            while (unique > targetUnique) {
                int leftCharIdx = s.charAt(left) - 'a';
                if (charCount[leftCharIdx] == k) atLeastK--;
                charCount[leftCharIdx]--;
                if (charCount[leftCharIdx] == 0) unique--;
                left++;
            }

            // 更新结果
            if (unique == targetUnique && atLeastK == targetUnique) {
                maxLen = Math.max(maxLen, right - left + 1);
            }
        }

        return maxLen;
    }
}
```

### 方法四：简洁的分治

```java
class Solution {
    public int longestSubstring(String s, int k) {
        // 最简洁的分治实现
        if (s.length() < k) return 0;

        // 找出现次数小于 k 的字符
        int[] counter = new int[26];
        for (char c : s.toCharArray()) counter[c - 'a']++;

        for (int i = 0; i < 26; i++) {
            if (counter[i] > 0 && counter[i] < k) {
                // 以该字符分割，递归求解
                char splitChar = (char)('a' + i);
                int max = 0;
                for (String sub : s.split(String.valueOf(splitChar))) {
                    max = Math.max(max, longestSubstring(sub, k));
                }
                return max;
            }
        }

        return s.length();
    }
}
```

## 复杂度分析

### 方法一：分治

**时间复杂度：** O(n)
- 最坏情况下递归深度为 26（字母表大小）
- 每层遍历字符串一次：O(26 * n) = O(n)

**空间复杂度：** O(n)
- 递归调用栈的深度最坏为 O(26)
- split 可能产生 O(n) 个子串

### 方法三：滑动窗口

**时间复杂度：** O(26 * n) = O(n)
- 需要枚举 26 种不同字符数量
- 每次滑动窗口遍历字符串 O(n)

**空间复杂度：** O(1)
- 只使用固定大小的数组

## 关键点总结

1. **分治思想**：不满足条件的字符作为分隔符
2. **递归终止**：字符串长度小于 k 或所有字符都满足
3. **滑动窗口**：枚举字符种类数，限制窗口条件
4. **字符统计**：使用长度为 26 的数组统计频次
5. **优化技巧**：使用 split 简化代码

## 易错点

1. **边界条件**：字符串长度小于 k 时返回 0
2. **分隔符选择**：要选择出现次数小于 k 的字符
3. **递归返回值**：要返回所有子问题的最大值
4. **滑动窗口条件**：需要同时满足字符数和频次两个条件
5. **空子串处理**：split 可能产生空字符串
