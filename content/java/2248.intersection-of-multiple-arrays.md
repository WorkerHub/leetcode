## 题目描述

返回在所有子数组中都出现的整数，按升序排列。

## 解题思路

统计每个元素出现在多少个子数组中，等于子数组总数则为公共元素，结果排序。

## Java 代码实现

```java
class Solution {
    public List<Integer> intersection(int[][] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int[] arr : nums) {
            for (int x : arr) {
                count.merge(x, 1, Integer::sum);
            }
        }

        List<Integer> ans = new ArrayList<>();
        int n = nums.length;
        for (var entry : count.entrySet()) {
            if (entry.getValue() == n) {
                ans.add(entry.getKey());
            }
        }
        Collections.sort(ans);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(总元素数 + k·log k)，k为不同元素数
- **空间复杂度**：O(k)

## 关键点总结

1. **计数法**：统计每个元素出现的子数组数
2. **等于总数组数即为公共元素**
3. **结果需升序排列**
