## 题目描述

给定 `m x n` 整数矩阵 `grid`，选三个单元格构成三角形（至少两点在同一行或列），返回所有可能三角形面积乘以 2 的最大值（即底 * 高的最大值）。

## Java 代码实现

```java
class Solution {
    public long maxArea(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 每行的最小列和最大列
        int[] rowMinCol = new int[m], rowMaxCol = new int[m];
        // 每列的最小行和最大行
        int[] colMinRow = new int[n], colMaxRow = new int[n];

        java.util.Arrays.fill(rowMinCol, n);
        java.util.Arrays.fill(rowMaxCol, -1);
        java.util.Arrays.fill(colMinRow, m);
        java.util.Arrays.fill(colMaxRow, -1);

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                rowMinCol[r] = Math.min(rowMinCol[r], c);
                rowMaxCol[r] = Math.max(rowMaxCol[r], c);
                colMinRow[c] = Math.min(colMinRow[c], r);
                colMaxRow[c] = Math.max(colMaxRow[c], r);
            }
        }

        long ans = 0;

        // 同行两点为底，第三点在不同行
        for (int r = 0; r < m; r++) {
            long base = rowMaxCol[r] - rowMinCol[r];
            if (base == 0) continue;
            long height = Math.max(r, m - 1 - r);
            ans = Math.max(ans, base * height);
        }

        // 同列两点为底，第三点在不同列
        for (int c = 0; c < n; c++) {
            long base = colMaxRow[c] - colMinRow[c];
            if (base == 0) continue;
            long height = Math.max(c, n - 1 - c);
            ans = Math.max(ans, base * height);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m*n) 预处理，O(m+n) 枚举
- 空间复杂度：O(m+n)

## 关键点总结

1. 同行两点最大底 = 该行最右列 - 最左列；最大高 = 第三点到该行的行距（取行 0 或行 m-1）
2. 同理对列方向枚举，两种方向取最大
3. 面积 * 2 = 底 * 高，用 `long` 防止溢出
