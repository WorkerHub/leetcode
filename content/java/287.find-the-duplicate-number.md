## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有一个重复的整数，返回这个重复的数。

你设计的解决方案必须不修改数组 `nums` 且只用常量级 `O(1)` 的额外空间。

**示例 1:**

```
输入: nums = [1,3,4,2,2]
输出: 2
```

**示例 2:**

```
输入: nums = [3,1,3,4,2]
输出: 3
```

**示例 3:**

```
输入: nums = [3,3,3,3,3]
输出: 3
```

**提示:**

- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个整数出现两次或多次，其余整数均只出现一次

**进阶:**

- 如何证明 `nums` 中至少存在一个重复的数字?
- 你可以设计一个线性级时间复杂度 `O(n)` 的解决方案吗？

## 解题思路

这是一道非常经典的问题，有多种巧妙的解法。关键限制是不能修改数组且只能使用 O(1) 空间。

**核心观察：**

1. n+1 个数字，范围是 [1, n]，根据抽屉原理必有重复
2. 可以将数组看作链表，`nums[i]` 指向索引 `nums[i]` 的节点
3. 重复数字会导致链表出现环

**解法概览：**

1. **快慢指针（环形链表）**：最优解，O(n) 时间 O(1) 空间
2. **二分查找**：利用抽屉原理，O(n log n) 时间 O(1) 空间
3. **哈希表/排序**：简单但不满足空间限制

**快慢指针原理：**

将数组看作链表，索引 `i` 指向 `nums[i]`：
```
nums = [1, 3, 4, 2, 2]
索引:   0  1  2  3  4

链表: 0 -> 1 -> 3 -> 2 -> 4 -> 2 (环)
```

重复数字是环的入口！使用 Floyd 判圈算法找环入口。

## Java 代码实现

### 方法一：快慢指针（Floyd 判圈算法，推荐）

```java
class Solution {
    public int findDuplicate(int[] nums) {
        // 快慢指针找环
        // 时间复杂度 O(n)，空间复杂度 O(1)

        // 第一步：找到环中的相遇点
        int slow = nums[0];
        int fast = nums[0];

        // 快慢指针移动，直到相遇
        do {
            slow = nums[slow];          // 慢指针走一步
            fast = nums[nums[fast]];    // 快指针走两步
        } while (slow != fast);

        // 第二步：找到环的入口（即重复数字）
        // 一个指针从起点开始，一个从相遇点开始
        // 两者以相同速度移动，相遇点就是环入口
        slow = nums[0];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }

        return slow;
    }
}
```

### 方法二：二分查找（抽屉原理）

```java
class Solution {
    public int findDuplicate(int[] nums) {
        // 二分查找 + 抽屉原理
        // 时间复杂度 O(n log n)，空间复杂度 O(1)
        //
        // 思路：
        // 对于中间值 mid，统计 <= mid 的数字个数
        // 如果个数 > mid，重复数字在 [1, mid]
        // 否则在 [mid+1, n]
        int left = 1, right = nums.length - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            // 统计 <= mid 的数字个数
            int count = 0;
            for (int num : nums) {
                if (num <= mid) count++;
            }

            if (count > mid) {
                // 重复数字在 [left, mid]
                right = mid;
            } else {
                // 重复数字在 [mid+1, right]
                left = mid + 1;
            }
        }

        return left;
    }
}
```

### 方法三：详细注释版快慢指针（新手友好）

```java
class Solution {
    /**
     * Floyd 判圈算法（龟兔赛跑）
     *
     * 核心思想：
     * 1. 将数组视为链表，nums[i] 指向 nums[nums[i]]
     * 2. 重复数字会导致链表有环
     * 3. 使用快慢指针找到环的入口
     *
     * 示例：[1, 3, 4, 2, 2]
     * 索引:  0  1  2  3  4
     *
     * 链表结构：
     * 0 -> nums[0]=1 -> nums[1]=3 -> nums[3]=2 -> nums[2]=4 -> nums[4]=2
     * 形成环：2 -> 4 -> 2
     *
     * 算法步骤：
     * 阶段 1：快慢指针找相遇点
     * - slow 每次走 1 步
     * - fast 每次走 2 步
     * - 在环内必定相遇
     *
     * 阶段 2：找环入口
     * - slow 回到起点
     * - fast 留在相遇点
     * - 两者同速前进，相遇点即为环入口（重复数字）
     */
    public int findDuplicate(int[] nums) {
        // 阶段 1：寻找相遇点
        int slow = nums[0];
        int fast = nums[0];

        // 第一次相遇
        do {
            slow = nums[slow];          // 走一步
            fast = nums[nums[fast]];    // 走两步
        } while (slow != fast);        // 在环内相遇

        // 阶段 2：寻找环的入口
        // 数学证明：从起点和相遇点同时出发，相遇点就是环入口
        slow = nums[0]; // 回到起点

        while (slow != fast) {
            slow = nums[slow]; // 同速前进
            fast = nums[fast];
        }

        // 此时 slow 和 fast 都指向环入口，即重复数字
        return slow;
    }
}
```

### 方法四：哈希表（不满足空间要求，仅供参考）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findDuplicate(int[] nums) {
        // 哈希表解法
        // 时间 O(n)，空间 O(n) - 不满足题目要求
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (!seen.add(num)) {
                return num; // add 返回 false 说明已存在
            }
        }
        return -1;
    }
}
```

## 复杂度分析

**方法一：快慢指针**
- 时间复杂度：`O(n)` 最多遍历两次数组
- 空间复杂度：`O(1)` 只用常数变量

**方法二：二分查找**
- 时间复杂度：`O(n log n)` 二分 O(log n) 次，每次统计 O(n)
- 空间复杂度：`O(1)`

**方法四：哈希表**
- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)` 不满足题目要求

## 关键点总结

1. **抽屉原理**：n+1 个数字放入 n 个抽屉，必有重复
2. **链表抽象**：将数组看作链表是解题关键
3. **Floyd 算法**：快慢指针找环是经典算法，需深入理解
4. **环入口性质**：从起点和相遇点同速前进，相遇点是环入口
5. **二分思想**：利用计数判断重复数字在哪个区间

## 易错点

1. **快慢指针初始化**：应该从 `nums[0]` 开始，不是索引 0
2. **第二阶段起点**：slow 要回到 `nums[0]`，不是索引 0
3. **do-while 写法**：Java 中需用 do-while 确保至少执行一次
4. **计数条件**：是 `num <= mid` 不是 `num < mid`
5. **环的理解**：链表的环不是数组的环，是值的指向关系
