## 题目描述

给你一个字符串数组 words，只返回可以使用在美式键盘同一行的字母打印出来的单词。键盘如下图所示。

美式键盘中：
- 第一行由字符 "qwertyuiop" 组成
- 第二行由字符 "asdfghjkl" 组成
- 第三行由字符 "zxcvbnm" 组成

**示例 1：**
```
输入：words = ["Hello","Alaska","Dad","Peace"]
输出：["Alaska","Dad"]
```

**示例 2：**
```
输入：words = ["omk"]
输出：[]
```

**示例 3：**
```
输入：words = ["adsdf","sfd"]
输出：["adsdf","sfd"]
```

**提示：**
- 1 <= words.length <= 20
- 1 <= words[i].length <= 100
- words[i] 由英文字母（小写和大写字母）组成

## 解题思路

这是一道简单的字符串处理题，核心是判断单词的所有字母是否都在同一行。

### 核心思想

1. **字符分组**：
   - 将键盘字符分成三组
   - 建立字符到行号的映射

2. **判断方法**：
   - 获取单词第一个字符的行号
   - 检查其他字符是否都在同一行

3. **优化思路**：
   - 使用集合快速判断字符属于哪一行
   - 使用哈希表存储字符到行的映射

## Java 代码实现

### 方法一：哈希表映射（推荐）

```java
import java.util.*;

class Solution {
    public String[] findWords(String[] words) {
        // 建立字符到行号的映射
        Map<Character, Integer> rowMap = new HashMap<>();
        String[] rows = {"qwertyuiop", "asdfghjkl", "zxcvbnm"};

        for (int i = 0; i < rows.length; i++) {
            for (char c : rows[i].toCharArray()) {
                rowMap.put(c, i);
                rowMap.put(Character.toUpperCase(c), i); // 大写字母
            }
        }

        List<String> result = new ArrayList<>();

        for (String word : words) {
            // 获取第一个字符的行号
            int firstRow = rowMap.get(word.charAt(0));
            boolean allSameRow = true;

            // 检查所有字符是否在同一行
            for (char c : word.toCharArray()) {
                if (rowMap.get(c) != firstRow) {
                    allSameRow = false;
                    break;
                }
            }

            if (allSameRow) {
                result.add(word);
            }
        }

        return result.toArray(new String[0]);
    }
}
```

### 方法二：使用集合判断

```java
import java.util.*;

class Solution {
    public String[] findWords(String[] words) {
        Set<Character> row1 = new HashSet<>(Arrays.asList(
            'q','w','e','r','t','y','u','i','o','p',
            'Q','W','E','R','T','Y','U','I','O','P'
        ));
        Set<Character> row2 = new HashSet<>(Arrays.asList(
            'a','s','d','f','g','h','j','k','l',
            'A','S','D','F','G','H','J','K','L'
        ));
        Set<Character> row3 = new HashSet<>(Arrays.asList(
            'z','x','c','v','b','n','m',
            'Z','X','C','V','B','N','M'
        ));

        List<String> result = new ArrayList<>();

        for (String word : words) {
            Set<Character> wordSet = new HashSet<>();
            for (char c : word.toCharArray()) {
                wordSet.add(c);
            }

            // 检查单词的所有字符是否是某一行的子集
            if (row1.containsAll(wordSet) ||
                row2.containsAll(wordSet) ||
                row3.containsAll(wordSet)) {
                result.add(word);
            }
        }

        return result.toArray(new String[0]);
    }
}
```

### 方法三：转小写统一处理

```java
import java.util.*;

class Solution {
    public String[] findWords(String[] words) {
        String[] rows = {"qwertyuiop", "asdfghjkl", "zxcvbnm"};
        List<String> result = new ArrayList<>();

        for (String word : words) {
            String lowerWord = word.toLowerCase();

            for (String row : rows) {
                boolean allInRow = true;
                for (char c : lowerWord.toCharArray()) {
                    if (row.indexOf(c) == -1) {
                        allInRow = false;
                        break;
                    }
                }
                if (allInRow) {
                    result.add(word);
                    break;
                }
            }
        }

        return result.toArray(new String[0]);
    }
}
```

### 方法四：使用行号数组（最优）

```java
import java.util.*;

class Solution {
    public String[] findWords(String[] words) {
        // 预先建立 26 个字母的行号映射（只需小写）
        int[] rowOf = new int[26];
        for (char c : "qwertyuiop".toCharArray()) rowOf[c - 'a'] = 1;
        for (char c : "asdfghjkl".toCharArray()) rowOf[c - 'a'] = 2;
        for (char c : "zxcvbnm".toCharArray()) rowOf[c - 'a'] = 3;

        List<String> result = new ArrayList<>();

        for (String word : words) {
            // 获取第一个字符所在行
            int targetRow = rowOf[Character.toLowerCase(word.charAt(0)) - 'a'];
            boolean valid = true;

            for (char c : word.toCharArray()) {
                if (rowOf[Character.toLowerCase(c) - 'a'] != targetRow) {
                    valid = false;
                    break;
                }
            }

            if (valid) {
                result.add(word);
            }
        }

        return result.toArray(new String[0]);
    }
}
```

### 方法五：正则表达式

```java
import java.util.*;
import java.util.regex.*;

class Solution {
    public String[] findWords(String[] words) {
        Pattern pattern = Pattern.compile(
            "(?i)([qwertyuiop]+|[asdfghjkl]+|[zxcvbnm]+)"
        );

        List<String> result = new ArrayList<>();
        for (String word : words) {
            Matcher matcher = pattern.matcher(word);
            if (matcher.matches()) {
                result.add(word);
            }
        }

        return result.toArray(new String[0]);
    }
}
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(n × m)
  - n 是单词数量
  - m 是单词的平均长度
  - 需要检查每个单词的每个字符

- **空间复杂度**：O(1)
  - 键盘行数固定
  - 字符集固定
  - 不随输入规模增长

## 关键点总结

1. **字符映射**：建立字符到行的映射关系
2. **集合操作**：使用 containsAll 判断子集
3. **大小写处理**：统一转小写或建立双向映射
4. **短路求值**：找到不匹配的字符立即退出循环
5. **多种实现**：哈希表、集合、数组等

## 易错点

1. **大小写处理**
   - 单词包含大小写字母
   - 需要统一处理（如转小写）或建立双向映射
   - Java 中使用 Character.toLowerCase(c)

2. **字符比较**
   - Java 中比较字符不能直接用 ==
   - 使用 rowMap.get(c).equals(firstRow) 或拆箱比较

3. **集合操作**
   - containsAll 判断是否是子集
   - 要确保行集合包含大小写字母或先转小写

4. **返回类型**
   - Java 返回 String[] 而不是 List<String>
   - 使用 result.toArray(new String[0]) 转换

5. **break 的使用**
   - 找到匹配的行后要 break
   - 避免重复添加单词
