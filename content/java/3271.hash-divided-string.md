## 题目描述

给你字符串 `s` 和正整数 `k`，将 `s` 按长度 `k` 分段，每段各字符值（a=0,...,z=25）之和对 26 取模得到新字符，拼接返回哈希值。

## 解题思路

按步长 `k` 遍历字符串，每段累加字符值，对 26 取模后转换为对应字母。

## Java 代码实现

```java
class Solution {
    public String stringHash(String s, int k) {
        StringBuilder result = new StringBuilder();
        int n = s.length();
        for (int i = 0; i < n; i += k) {
            int total = 0;
            // 当前段求和
            for (int j = i; j < i + k; j++) {
                total += s.charAt(j) - 'a';
            }
            result.append((char) (total % 26 + 'a'));
        }
        return result.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n/k)

## 关键点总结

1. 按 k 分组，每组独立处理
2. 字符值：'a'=0, ..., 'z'=25，使用 `charAt(j) - 'a'` 获取
3. 求和 mod 26 后加 'a' 得到新字符
