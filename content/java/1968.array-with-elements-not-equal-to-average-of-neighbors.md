## 题目描述

给你长度为奇数且元素各不相同的数组 `nums`，重新排列使得每个元素不等于相邻两元素的平均值，返回任一满足条件的数组。

## 解题思路

排序后交换相邻奇偶位：排序后位置 1, 3, 5... 的元素与下一位交换，产生"峰谷"交替模式，确保无元素等于相邻平均值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] rearrangeArray(int[] nums) {
        Arrays.sort(nums);
        for (int i = 1; i < nums.length - 1; i += 2) {
            int tmp = nums[i]; nums[i] = nums[i + 1]; nums[i + 1] = tmp;
        }
        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后交换奇数位与下一位，产生峰谷模式
2. 峰谷模式保证相邻三元素不可能满足平均值关系
