## 题目描述

给定一个单链表 `L` 的头节点 `head`，单链表 `L` 表示为：

```
L0 → L1 → … → Ln-1 → Ln
```

请将其重新排列后变为：

```
L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …
```

不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

**示例 1：**
```
输入：head = [1,2,3,4]
输出：[1,4,2,3]
```

**示例 2：**
```
输入：head = [1,2,3,4,5]
输出：[1,5,2,4,3]
```

**提示：**
- 链表的长度范围为 `[1, 5 * 10^4]`
- `1 <= node.val <= 1000`

## 解题思路

这道题需要将链表按照"头尾交替"的方式重新排列，可以分解为三个子问题：

**核心思想：找中点 + 反转 + 合并**

### 算法步骤：

1. **找到链表中点**：使用快慢指针找到链表的中间节点
2. **反转后半部分**：将中点之后的链表反转
3. **合并两部分**：交替合并前半部分和反转后的后半部分

### 详细说明：

**步骤1：找中点**
- 使用快慢指针，快指针每次走 2 步，慢指针每次走 1 步
- 当快指针到达末尾时，慢指针在中点

**步骤2：反转后半部分**
- 从中点开始反转链表
- 使用标准的链表反转算法

**步骤3：合并**
- 交替从前半部分和后半部分取节点
- 重新连接指针

## Java 代码实现

### 方法一：找中点 + 反转 + 合并（推荐）

```java
// Definition for singly-linked list.
// class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) {
            return;
        }

        // 步骤1: 找到链表中点
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // slow 现在指向中点（或中点偏左）
        // 将链表分为两部分
        ListNode secondHalf = slow.next;
        slow.next = null;  // 断开前后两部分

        // 步骤2: 反转后半部分
        secondHalf = reverseList(secondHalf);

        // 步骤3: 合并两部分
        ListNode first = head;
        ListNode second = secondHalf;
        while (second != null) {
            // 保存下一个节点
            ListNode temp1 = first.next;
            ListNode temp2 = second.next;

            // 交替连接
            first.next = second;
            second.next = temp1;

            // 移动指针
            first = temp1;
            second = temp2;
        }
    }

    private ListNode reverseList(ListNode head) {
        // 反转链表
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextNode = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextNode;
        }
        return prev;
    }
}
```

### 方法二：一体化版本（所有逻辑在一个函数中）

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) {
            return;
        }

        // 步骤1: 找中点
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 步骤2: 反转后半部分
        ListNode prev = null;
        ListNode curr = slow.next;
        slow.next = null;  // 断开

        while (curr != null) {
            ListNode nextNode = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextNode;
        }

        // 步骤3: 合并
        ListNode first = head;
        ListNode second = prev;

        while (second != null) {
            ListNode temp1 = first.next;
            ListNode temp2 = second.next;
            first.next = second;
            second.next = temp1;
            first = temp1;
            second = temp2;
        }
    }
}
```

### 方法三：使用 ArrayList 存储（不满足空间要求，但直观）

```java
class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) {
            return;
        }

        // 将链表节点存入列表
        List<ListNode> nodes = new ArrayList<>();
        ListNode curr = head;
        while (curr != null) {
            nodes.add(curr);
            curr = curr.next;
        }

        // 使用双指针重新连接
        int left = 0, right = nodes.size() - 1;

        while (left < right) {
            nodes.get(left).next = nodes.get(right);
            left++;
            if (left == right) {
                break;
            }
            nodes.get(right).next = nodes.get(left);
            right--;
        }

        // 最后一个节点的 next 置为 null
        nodes.get(left).next = null;
    }
}
```

## 复杂度分析

### 方法一、二：找中点 + 反转 + 合并
- **时间复杂度**：O(n)
  - 找中点：O(n)
  - 反转：O(n/2)
  - 合并：O(n/2)
- **空间复杂度**：O(1)，只使用常数个指针

### 方法三：ArrayList 存储
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，需要存储所有节点

## 图解示例

以 `head = [1,2,3,4,5]` 为例：

```
原始链表：
1 → 2 → 3 → 4 → 5

步骤1：找中点（slow 指针）
        slow
         ↓
1 → 2 → 3 → 4 → 5
            ↑
           fast

分割为两部分：
前半部分: 1 → 2 → 3
后半部分: 4 → 5

步骤2：反转后半部分
后半部分: 5 → 4

步骤3：交替合并
first:  1 → 2 → 3
second: 5 → 4

合并过程：
第1次: 1 → 5 → 2 → 3
              4
第2次: 1 → 5 → 2 → 4 → 3

最终结果：
1 → 5 → 2 → 4 → 3
```

**偶数节点的例子 `[1,2,3,4]`：**

```
原始: 1 → 2 → 3 → 4

找中点: slow 在 2
前半部分: 1 → 2
后半部分: 3 → 4

反转后半部分: 4 → 3

合并:
1 → 4 → 2 → 3
```

## 关键点总结

1. **三步法**：找中点、反转、合并，每一步都是经典的链表操作
2. **快慢指针找中点**：快指针每次走 2 步，慢指针每次走 1 步
3. **断开链表**：找到中点后要将前后两部分断开（`slow.next = null`）
4. **交替合并**：保存下一个节点再修改指针，避免丢失引用
5. **原地修改**：方法没有返回值，直接修改原链表

## 易错点

1. **忘记断开链表**：找到中点后要将 `slow.next` 置为 null，否则形成环
2. **指针保存顺序**：合并时要先保存 next 指针再修改，否则丢失引用
3. **边界条件**：空链表、单节点、双节点要特殊处理
4. **快慢指针的终止条件**：`fast.next != null && fast.next.next != null` 还是 `fast != null && fast.next != null`
5. **合并的终止条件**：当 second 为 null 时终止（因为后半部分可能比前半部分少 1 个）
