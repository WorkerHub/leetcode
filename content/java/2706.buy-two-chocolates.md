## 题目描述

给你巧克力价格数组 `prices` 和金额 `money`，必须购买恰好两块且总价不超过 `money`，返回最大剩余金额（无法购买则返回 `money`）。

## Java 代码实现

```java
class Solution {
    public int buyChoco(int[] prices, int money) {
        // 找最小的两个价格
        int first = Integer.MAX_VALUE, second = Integer.MAX_VALUE;
        for (int p : prices) {
            if (p <= first) { second = first; first = p; }
            else if (p < second) { second = p; }
        }
        int cost = first + second;
        return cost <= money ? money - cost : money;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最大化剩余 = 最小化花费，取最便宜的两块
2. 负担不起时返回原始金额
