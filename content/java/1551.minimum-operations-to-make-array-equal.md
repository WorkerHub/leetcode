## 题目描述

数组 arr[i] = 2*i+1（即 [1,3,5,...,2n-1]），每次操作选两个下标使一个+1另一个-1，求使所有元素相等的最少操作次数。

**示例：**
```
输入：n = 3
输出：2
```

## 解题思路

数学公式：目标值为 n，操作次数 = 左半部分与 n 的差之和 = n²/4。

## Java 代码实现

```java
class Solution {
    public int minOperations(int n) {
        return n * n / 4;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **目标值**：所有元素变为平均值 n
2. **公式**：n²/4（整数除法）
3. **等差数列**：差值序列 (n-1, n-3, ..., 1) 求和
