## 题目描述

满足以下条件的密码被认为是强密码：
1. 长度至少为 6 个字符，最多为 20 个字符
2. 至少包含一个小写字母、一个大写字母和一个数字
3. 不能包含三个连续相同的字符（例如 "...aaa..." 是不允许的，但 "...aa...a..." 是可以的）

给你一个字符串 password，返回将 password 修改到满足强密码条件所需的最少修改步数。

插入、删除、替换任一字符都算作一次修改。

**示例 1：**
```
输入：password = "a"
输出：5
```

**示例 2：**
```
输入：password = "aA1"
输出：3
```

**示例 3：**
```
输入：password = "1337C0d3"
输出：0
```

## 解题思路

这是一道复杂的贪心题，需要分情况讨论。

核心思路：
1. 统计缺少的字符类型（小写、大写、数字）
2. 统计连续字符需要的替换次数
3. 根据长度分三种情况处理：
   - 长度 < 6：需要添加字符
   - 6 <= 长度 <= 20：只需替换
   - 长度 > 20：需要删除字符

## Java 代码实现

### 方法一：分类讨论

```java
class Solution {
    public int strongPasswordChecker(String password) {
        // 分情况讨论
        int n = password.length();

        // 统计缺少的字符类型
        boolean hasLower = false, hasUpper = false, hasDigit = false;
        for (char c : password.toCharArray()) {
            if (Character.isLowerCase(c)) hasLower = true;
            else if (Character.isUpperCase(c)) hasUpper = true;
            else if (Character.isDigit(c)) hasDigit = true;
        }
        int missingTypes = (hasLower ? 0 : 1) + (hasUpper ? 0 : 1) + (hasDigit ? 0 : 1);

        // 统计连续字符需要的替换次数
        int replace = 0;
        int one = 0, two = 0;  // 连续段长度模 3 余 0 和余 1 的个数
        int i = 2;

        while (i < n) {
            if (password.charAt(i) == password.charAt(i - 1) &&
                password.charAt(i - 1) == password.charAt(i - 2)) {
                // 找到连续段，统计其完整长度
                int length = 2;
                while (i < n && password.charAt(i) == password.charAt(i - 1)) {
                    length++;
                    i++;
                }

                // 每 3 个连续字符需要一次替换
                replace += length / 3;

                if (length % 3 == 0) {
                    one++;       // 删 1 个可节省 1 次替换
                } else if (length % 3 == 1) {
                    two++;       // 删 2 个可节省 1 次替换
                }
            } else {
                i++;
            }
        }

        // 分三种情况处理
        if (n < 6) {
            // 长度不足，添加字符可同时解决缺少类型和连续字符问题
            return Math.max(missingTypes, 6 - n);
        } else if (n <= 20) {
            // 长度合适，替换可同时解决缺少类型和连续字符问题
            return Math.max(missingTypes, replace);
        } else {
            // 长度过长，需要先删除多余字符
            int delete = n - 20;

            // 优化：删除可以减少替换次数
            // 删除 1 个字符可以减少 1 个长度为 3k+1 的连续段的替换
            replace -= Math.min(delete, one);
            // 删除 2 个字符可以减少 1 个长度为 3k+2 的连续段的替换
            replace -= Math.min(Math.max(delete - one, 0), two * 2) / 2;
            // 删除 3 个字符可以减少 1 次替换
            replace -= Math.max(delete - one - two * 2, 0) / 3;

            return delete + Math.max(missingTypes, replace);
        }
    }
}
```

### 方法二：简化版（不考虑最优删除）

```java
class Solution {
    public int strongPasswordChecker(String password) {
        // 简化版实现
        int n = password.length();

        // 统计缺少的类型
        int missing = 3;
        boolean hasLower = false, hasUpper = false, hasDigit = false;
        for (char c : password.toCharArray()) {
            if (Character.isLowerCase(c)) hasLower = true;
            else if (Character.isUpperCase(c)) hasUpper = true;
            else if (Character.isDigit(c)) hasDigit = true;
        }
        if (hasLower) missing--;
        if (hasUpper) missing--;
        if (hasDigit) missing--;

        // 统计替换次数
        int replace = 0;
        int idx = 0;
        while (idx < n) {
            int length = 1;
            while (idx + length < n && password.charAt(idx) == password.charAt(idx + length)) {
                length++;
            }
            replace += length / 3;
            idx += length;
        }

        if (n < 6) {
            return Math.max(6 - n, missing);
        } else if (n <= 20) {
            return Math.max(missing, replace);
        } else {
            int delete = n - 20;
            return delete + Math.max(missing, replace - delete / 3);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 分三种长度情况讨论
2. 统计缺少的字符类型
3. 统计连续字符需要的替换
4. 优化删除策略

## 易错点

1. 没有考虑删除可以优化替换次数
2. 边界情况处理错误
3. 连续字符统计错误
