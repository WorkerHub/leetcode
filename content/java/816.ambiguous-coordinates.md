## 题目描述

我们有一些二维坐标，如 `"(1, 3)"` 或 `"(2, 0.5)"`，然后我们移除所有逗号，小数点和空格，得到一个字符串 `s`。

返回所有可能的原始坐标字符串的列表。我们的答案可以按 **任意顺序** 返回。

**示例 1:**
```
输入: s = "(123)"
输出: ["(1, 2.3)","(1, 23)","(1.2, 3)","(12, 3)"]
```

**示例 2:**
```
输入: s = "(0123)"
输出: ["(0, 1.23)","(0, 12.3)","(0, 123)","(0.1, 2.3)","(0.1, 23)","(0.12, 3)"]
```

**示例 3:**
```
输入: s = "(00011)"
输出: ["(0, 0.011)","(0.001, 1)"]
```

**提示:**
- `4 <= s.length <= 12`
- `s[0]` == `"("` 且 `s[s.length - 1]` == `")"`
- `s` 的其他字符都是数字

## 解题思路

1. 去掉括号，分割成两部分
2. 对每部分枚举所有合法的小数表示
3. 组合所有可能的坐标

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<String> ambiguousCoordinates(String s) {
        // 去掉括号
        String inner = s.substring(1, s.length() - 1);
        int n = inner.length();

        List<String> result = new ArrayList<>();

        // 分割成两部分
        for (int i = 1; i < n; i++) {
            String left = inner.substring(0, i);
            String right = inner.substring(i);

            List<String> leftNums = makeNumbers(left);
            List<String> rightNums = makeNumbers(right);

            for (String l : leftNums) {
                for (String r : rightNums) {
                    result.add("(" + l + ", " + r + ")");
                }
            }
        }

        return result;
    }

    /**
     * 生成字符串 s 的所有合法数字表示
     */
    private List<String> makeNumbers(String s) {
        int n = s.length();
        List<String> result = new ArrayList<>();

        // 特殊情况：多位数且以0结尾，不能作为整数也不能作为小数整数部分
        if (n > 1 && s.charAt(0) == '0' && s.charAt(n - 1) == '0') {
            return result;
        }

        // 整数（无小数点）
        if (n == 1 || s.charAt(0) != '0') {
            result.add(s);
        }

        // 带小数点
        for (int i = 1; i < n; i++) {
            String integerPart = s.substring(0, i);
            String decimalPart = s.substring(i);

            // 整数部分不能有前导0（除非是 "0"）
            // 小数部分不能有后导0
            if ((integerPart.equals("0") || integerPart.charAt(0) != '0')
                    && decimalPart.charAt(decimalPart.length() - 1) != '0') {
                result.add(integerPart + "." + decimalPart);
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n³)

## 关键点总结

1. **前导零**：整数部分只有 "0" 可以有前导零
2. **后导零**：小数部分不能有后导零
3. **枚举分割点**：尝试所有可能的分割位置

## 易错点

1. **特殊情况**："00" 不合法
2. **小数点位置**：不能在开头或结尾
3. **单独的0**："0" 是合法的
