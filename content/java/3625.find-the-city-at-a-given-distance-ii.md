## 题目描述

给定 `n` 个城市和双向加权边，对每个城市找出距离不超过 `distanceThreshold` 的城市数最少的城市，若相同取编号最大的。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int findTheCity(int n, int[][] edges, int distanceThreshold) {
        int INF = Integer.MAX_VALUE / 2;
        int[][] dist = new int[n][n];
        for (int[] row : dist) Arrays.fill(row, INF);
        for (int i = 0; i < n; i++) dist[i][i] = 0;
        for (int[] e : edges) {
            dist[e[0]][e[1]] = Math.min(dist[e[0]][e[1]], e[2]);
            dist[e[1]][e[0]] = Math.min(dist[e[1]][e[0]], e[2]);
        }

        // Floyd-Warshall 全源最短路
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dist[i][k] + dist[k][j] < dist[i][j]) {
                        dist[i][j] = dist[i][k] + dist[k][j];
                    }
                }
            }
        }

        int ans = -1, minCount = n + 1;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (i != j && dist[i][j] <= distanceThreshold) count++;
            }
            if (count <= minCount) {
                minCount = count;
                ans = i;  // 相同时取编号更大的
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)，Floyd-Warshall
- 空间复杂度：O(n^2)，距离矩阵

## 关键点总结

1. n <= 100 时 Floyd-Warshall 最简洁
2. 遍历时用 `<=` 覆盖，保证相同计数时取编号最大
3. 初始化 `INF = Integer.MAX_VALUE / 2` 防止加法溢出
