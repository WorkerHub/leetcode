## 题目描述

按分级税率计算总税款，每个税级区间按对应税率征税。

## 解题思路

模拟：逐区间计算应税金额（min(income, upper) - prevUpper），乘税率累加。

## Java 代码实现

```java
class Solution {
    public double calculateTax(int[][] brackets, int income) {
        double tax = 0.0;
        int prev = 0;

        for (int[] b : brackets) {
            if (income <= prev) break;
            int taxable = Math.min(income, b[0]) - prev;
            tax += taxable * b[1] / 100.0;
            prev = b[0];
        }
        return tax;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **逐区间计算应税金额**：min(income, upper) - prev
2. **收入低于当前区间下限时提前退出**
3. **税率是百分比**：除以100
