## 题目描述

如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个回文串。

字母和数字都属于字母数字字符。

给你一个字符串 `s`，如果它是回文串，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入: s = "A man, a plan, a canal: Panama"
输出: true
解释: "amanaplanacanalpanama" 是回文串。
```

**示例 2：**
```
输入: s = "race a car"
输出: false
解释: "raceacar" 不是回文串。
```

**示例 3：**
```
输入: s = " "
输出: true
解释: 在移除非字母数字字符之后，s 是一个空字符串 ""。
由于空字符串正着反着读都一样，所以是回文串。
```

**提示：**
- `1 <= s.length <= 2 * 10^5`
- `s` 仅由可打印的 ASCII 字符组成

## 解题思路

验证回文串的核心思想是**双指针对撞**：
1. 使用左右两个指针，分别从字符串两端向中间移动
2. 跳过所有非字母数字字符
3. 比较左右指针指向的字符（忽略大小写）
4. 如果不相等则返回 false，全部相等则返回 true

这道题是典型的双指针问题，关键在于：
- 正确判断字母数字字符（Java 使用 `Character.isLetterOrDigit()`）
- 统一大小写进行比较（Java 使用 `Character.toLowerCase()`）
- 处理边界情况（空字符串、只有特殊字符等）

## Java 代码实现

### 方法一：双指针（推荐）

```java
class Solution {
    public boolean isPalindrome(String s) {
        // 使用双指针从两端向中间移动
        int left = 0, right = s.length() - 1;

        while (left < right) {
            // 跳过左边的非字母数字字符
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }

            // 跳过右边的非字母数字字符
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }

            // 比较字符（统一转为小写）
            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
                return false;
            }

            // 移动指针
            left++;
            right--;
        }

        return true;
    }
}
```

### 方法二：预处理 + 双指针

```java
class Solution {
    public boolean isPalindrome(String s) {
        // 先过滤掉非字母数字字符，并转为小写
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                sb.append(Character.toLowerCase(c));
            }
        }
        String filtered = sb.toString();

        // 使用双指针验证
        int left = 0, right = filtered.length() - 1;
        while (left < right) {
            if (filtered.charAt(left) != filtered.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }
}
```

### 方法三：预处理 + 反转比较

```java
class Solution {
    public boolean isPalindrome(String s) {
        // 过滤并转小写
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                sb.append(Character.toLowerCase(c));
            }
        }
        String filtered = sb.toString();

        // 直接比较字符串和其反转
        String reversed = sb.reverse().toString();
        return filtered.equals(reversed);
    }
}
```

### 方法四：使用正则表达式

```java
class Solution {
    public boolean isPalindrome(String s) {
        // 使用正则去除非字母数字字符
        String filtered = s.replaceAll("[^a-zA-Z0-9]", "").toLowerCase();

        // 比较字符串和其反转
        String reversed = new StringBuilder(filtered).reverse().toString();
        return filtered.equals(reversed);
    }
}
```

## 复杂度分析

### 方法一：双指针（推荐）
- **时间复杂度**：O(n)，其中 n 是字符串长度。最多遍历整个字符串一次
- **空间复杂度**：O(1)，只使用了常数个变量

### 方法二：预处理 + 双指针
- **时间复杂度**：O(n)，需要遍历一次过滤，再遍历一次验证
- **空间复杂度**：O(n)，需要额外空间存储过滤后的字符串

### 方法三/四：预处理 + 反转比较
- **时间复杂度**：O(n)，过滤一次，反转和比较各一次
- **空间复杂度**：O(n)，存储过滤后的字符串和反转字符串

## 关键点总结

1. **双指针是最优解法**：原地操作，空间复杂度 O(1)
2. **字符判断技巧**：使用 `Character.isLetterOrDigit()` 判断字母数字字符
3. **大小写处理**：使用 `Character.toLowerCase()` 统一转为小写
4. **边界处理**：注意空字符串、只有特殊字符等情况
5. **Java 字符串比较**：使用 `equals()` 比较字符串，不能用 `==`

## 易错点

1. **忘记跳过非字母数字字符**
   ```java
   // 错误：直接比较所有字符
   if (s.charAt(left) != s.charAt(right))  // 会将空格、标点也纳入比较

   // 正确：先跳过非字母数字字符
   while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
       left++;
   }
   ```

2. **忘记统一大小写**
   ```java
   // 错误：大小写不一致
   if (s.charAt(left) != s.charAt(right))

   // 正确：统一转为小写
   if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right)))
   ```

3. **边界条件处理**
   ```java
   // 需要同时满足 left < right，防止指针越界
   while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
       left++;
   }
   ```

4. **Java 字符串比较**：比较 `String` 对象时必须用 `equals()`，不能用 `==`
