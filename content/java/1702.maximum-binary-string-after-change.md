## 题目描述

二进制字符串，可无限次将 `"00"` 替换为 `"10"` 或 `"10"` 替换为 `"01"`。返回可得到的最大二进制字符串。

## 解题思路

**贪心：** 前导 `1` 无法移动。从第一个 `0` 起，所有的 `0`（含夹在其中的 `1`）最终可合并为连续 `1` 加最后一个 `0`，唯一 `0` 的位置为 `firstZero + zeroCount - 1`。

## Java 代码实现

```java
class Solution {
    public String maximumBinaryString(String binary) {
        int n = binary.length();
        int firstZero = binary.indexOf('0');
        if (firstZero == -1) return binary; // 全为1

        // 统计从第一个0起的0的数量
        int zeroCount = 0;
        for (int i = firstZero; i < n; i++) {
            if (binary.charAt(i) == '0') zeroCount++;
        }

        // 构造结果：全1，仅在 firstZero + zeroCount - 1 处放0
        char[] res = new char[n];
        Arrays.fill(res, '1');
        res[firstZero + zeroCount - 1] = '0';
        return new String(res);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 前导 `1` 的数量不变
2. 从第一个 `0` 开始，所有 `0` 可以被合并，最终只留一个 `0`
3. 唯一 `0` 的位置 = `firstZero + zeroCount - 1`
