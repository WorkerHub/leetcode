## 题目描述

给你一个字符串数组 `words`，数组中的每个字符串都可以看作是一个单词。请你按**任意** 顺序返回 `words` 中是其他单词的子字符串的所有单词。

如果你可以删除 `words[j]` 最左侧和/或最右侧的若干字符得到 `word[i]`，那么字符串 `words[i]` 就是 `words[j]` 的一个子字符串。

**示例 1：**

```
输入：words = ["mass","as","hero","superhero"]
输出：["as","mass"]
解释："as" 是 "mass" 的子字符串，"hero" 是 "superhero" 的子字符串。
["hero","as"] 也是有效的答案。
```

**示例 2：**

```
输入：words = ["leetcode","et","code"]
输出：["et","code"]
解释："et", "code" 都是 "leetcode" 的子字符串。
```

**示例 3：**

```
输入：words = ["blue","green","bu"]
输出：[]
```

**提示：**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 30`
- `words[i]` 仅包含小写英文字母
- `words` 中的所有字符串**互不相同**

## 解题思路

**暴力双重循环：** 对每个单词 `words[i]`，遍历其他所有单词 `words[j]`（`j != i`），检查 `words[i]` 是否是 `words[j]` 的子字符串。

Java 中用 `String.contains()` 方法可以直接判断子字符串关系。

由于数据规模小（words.length ≤ 100，每个单词长度 ≤ 30），O(n^2 * L) 完全够用。

## Java 代码实现

### 方法一：双重循环 + contains 方法（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> stringMatching(String[] words) {
        List<String> result = new ArrayList<>();
        int n = words.length;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                // i != j 排除自身，contains 判断子字符串关系
                if (i != j && words[j].contains(words[i])) {
                    result.add(words[i]);
                    break;  // 找到一个即可，不重复添加
                }
            }
        }
        return result;
    }
}
```

### 方法二：排序后只在更长的单词中查找（优化版）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> stringMatching(String[] words) {
        // 先按长度排序，短的在前
        String[] sorted = words.clone();
        Arrays.sort(sorted, (a, b) -> a.length() - b.length());
        List<String> result = new ArrayList<>();
        int n = sorted.length;

        for (int i = 0; i < n; i++) {
            // 只需在比 sorted[i] 长的单词中查找（更长的才可能包含它）
            for (int j = i + 1; j < n; j++) {
                if (sorted[j].contains(sorted[i])) {
                    result.add(sorted[i]);
                    break;
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（双重循环） | O(n^2 * L) | O(n) |
| 方法二（排序+剪枝） | O(n^2 * L) 最坏，实际更快 | O(n) |

- n = 100，L = 30，O(n^2 * L) = 300,000 次操作，完全够用。
- Java 的 `contains()` 方法底层使用字符串搜索算法，单次匹配 O(L)。

## 关键点总结

1. Java 的 `String.contains(CharSequence s)` 直接判断子字符串关系
2. 双重循环时，`i != j` 排除自身（一个字符串是自身的子字符串，但不满足题意）
3. `break` 避免同一个单词被重复添加到结果中
4. 方法二通过排序和剪枝（只在更长的单词中查找）略微优化

## 易错点

- 忘记排除 `i == j` 的情况：每个单词都是自身的子字符串，不应被计入
- 没有使用 `break`：如果 `words[0]` 既是 `words[1]` 又是 `words[2]` 的子串，没有 `break` 会重复添加
- 注意题目说"互不相同"，所以不会有完全相同的两个单词导致误判
