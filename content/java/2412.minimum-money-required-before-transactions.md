## 题目描述

给你交易数组 `transactions`（`[cost, cashback]`），每次需先支付 `cost` 再获得 `cashback`，无论顺序如何，返回能完成所有交易的最少起始金额。

## 解题思路

设总亏损 `totalLoss = sum(max(cost-cashback, 0))`。对每笔交易考虑把它放在最后执行的情形：若该笔有净亏损，则所需资金 = `totalLoss - loss + cost`；否则所需资金 = `totalLoss + cost`。取所有情况的最大值即为答案。所有值需用 `long`。

## Java 代码实现

```java
class Solution {
    public long minimumMoney(int[][] transactions) {
        long totalLoss = 0;
        for (int[] t : transactions) {
            totalLoss += Math.max(t[0] - t[1], 0); // 累计净亏损
        }
        long ans = 0;
        for (int[] t : transactions) {
            int cost = t[0], cashback = t[1];
            long loss = Math.max(cost - cashback, 0);
            long needed;
            if (loss > 0) {
                // 有净亏损的交易放最后：前面扣除其他亏损后还需 cost
                needed = totalLoss - loss + cost;
            } else {
                // 无净亏损的交易放最后：前面已扣 totalLoss，还需 cost
                needed = totalLoss + cost;
            }
            ans = Math.max(ans, needed);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 总亏损 = 所有净亏损之和（只算 `cost > cashback` 的交易）。
2. 枚举每笔交易放最后执行时所需起始资金，取最大值。
3. 数据规模：n 最大 10^5，cost 最大 10^9，总亏损可达 10^14，必须用 `long`。
