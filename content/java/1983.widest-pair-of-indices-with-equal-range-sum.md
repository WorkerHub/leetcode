## 题目描述

给定等长数组 `nums1` 和 `nums2`，找满足 `nums1[i..j]` 之和等于 `nums2[i..j]` 之和的最大子数组宽度 `j - i + 1`，不存在返回 0。

## 解题思路

设 `diff[i] = nums1[i] - nums2[i]`，条件等价于 `diff[i..j]` 之和为 0，即前缀差值 `prefix[j+1] == prefix[i]`。用哈希表记录每个前缀差值第一次出现的位置，求最大区间长度。

## Java 代码实现

### 方法一：前缀和差 + 哈希表（推荐）

```java
import java.util.*;

class Solution {
    public int widestPairOfIndices(int[] nums1, int[] nums2) {
        int n = nums1.length;
        // 记录每个前缀差值第一次出现的位置
        Map<Integer, Integer> firstSeen = new HashMap<>();
        firstSeen.put(0, -1); // 前缀差为0对应位置-1（数组起始前）
        int prefix = 0;
        int ans = 0;

        for (int j = 0; j < n; j++) {
            prefix += nums1[j] - nums2[j];
            if (firstSeen.containsKey(prefix)) {
                // 子数组宽度：j - firstSeen[prefix]
                ans = Math.max(ans, j - firstSeen.get(prefix));
            } else {
                // 只记录第一次出现（保证区间最宽）
                firstSeen.put(prefix, j);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 两数组区间和相等等价于差数组区间和为 0，即前缀差值相等
2. 哈希表只记录每个前缀差值第一次出现的位置，保证找到最宽区间
3. 初始化 `firstSeen.put(0, -1)` 处理从头开始的子数组
