## 题目描述

给你奖励值数组 `rewardValues`，初始总奖励为 0，每次选取的值必须严格大于当前总奖励，返回可获得的最大总奖励。

## 解题思路

排序去重后，用 DP 标记所有可达总奖励值：`dp[v] = true` 表示总奖励 v 可达。对每个奖励 r，对所有 v < r 的可达状态，将 v+r 标记为可达（倒序遍历避免重复使用）。

## Java 代码实现

```java
class Solution {
    public int maxTotalReward(int[] rewardValues) {
        // 排序去重
        TreeSet<Integer> set = new TreeSet<>();
        for (int r : rewardValues) set.add(r);
        int maxVal = set.last();

        boolean[] dp = new boolean[maxVal * 2];
        dp[0] = true;

        for (int r : set) {
            // 倒序遍历 [r-1, 0]，避免重复使用同一奖励
            for (int v = r - 1; v >= 0; v--) {
                if (dp[v]) dp[v + r] = true;
            }
        }
        // 找最大可达值
        for (int v = dp.length - 1; v >= 0; v--) {
            if (dp[v]) return v;
        }
        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × maxVal)
- **空间复杂度**：O(maxVal)

## 关键点总结

1. 排序后每个奖励只在当前总奖励小于它时才能使用
2. DP 标记所有可达总奖励值，倒序遍历保证每个奖励只用一次
3. 去重避免重复使用相同奖励值
