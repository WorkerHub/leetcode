## 题目描述

给你整数数组 `nums` 和查询数组 `queries`，其中 `queries[i] = [l, r, val]`，每次查询对 `nums[l..r]` 中每个元素最多减 `val`（不低于 0）。返回使数组变为全 0 所需的最少查询数 `k`，若不能则返回 -1。

## 解题思路

答案具有单调性：前 k 个查询足够则前 k+1 个也足够。二分查找最小的 k，用差分数组验证前 k 个查询是否能使每个位置的可减总量 >= `nums[i]`。

## Java 代码实现

```java
class Solution {
    public int minZeroArray(int[] nums, int[][] queries) {
        int n = nums.length;
        int q = queries.length;

        // 先检查是否有解（使用全部查询）
        if (!check(nums, queries, n, q)) {
            return -1;
        }

        // 二分查找最小的 k
        int lo = 0, hi = q;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (check(nums, queries, n, mid)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }

        return lo;
    }

    private boolean check(int[] nums, int[][] queries, int n, int k) {
        // 差分数组：统计每个位置被前 k 个查询覆盖的最大可减量
        long[] diff = new long[n + 1];
        for (int i = 0; i < k; i++) {
            int l = queries[i][0], r = queries[i][1];
            long val = queries[i][2];
            diff[l] += val;
            diff[r + 1] -= val;
        }

        // 还原前缀和，验证每个位置覆盖量 >= nums[i]
        long cover = 0;
        for (int i = 0; i < n; i++) {
            cover += diff[i];
            if (nums[i] > cover) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) * log q)，二分 * check 函数
- 空间复杂度：O(n)，差分数组

## 关键点总结

1. 二分答案的单调性：前 k 个查询足够，则前 k+1 个也足够。
2. 验证函数用差分数组 O(n + k) 计算每个位置的最大可减量。
3. 每个查询贡献 `val`，差分数组中 `diff[l] += val, diff[r+1] -= val`。
