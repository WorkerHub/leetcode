## 题目描述

二进制字符串分成三个非空子串，每段 1 的数量相同。返回方案数，对 10^9+7 取模。

**示例：**
```
输入：s = "10101"
输出：4
```

## 解题思路

每段需 total/3 个 1。找第一段末尾和第二段末尾的 1 与下一个 1 之间的间隔，答案 = 两间隔之积。

## Java 代码实现

```java
class Solution {
    public int numWays(String s) {
        long MOD = 1_000_000_007;
        int n = s.length();
        int ones = 0;
        for (char c : s.toCharArray()) if (c == '1') ones++;
        
        if (ones % 3 != 0) return 0;
        if (ones == 0) {
            // 任意分割合法：C(n-1, 2)
            return (int)((long)(n - 1) * (n - 2) / 2 % MOD);
        }
        
        int target = ones / 3;
        // 找所有 1 的位置
        int[] pos = new int[ones];
        int idx = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') pos[idx++] = i;
        }
        
        // 第一刀间隔：pos[target] - pos[target-1]
        long gap1 = pos[target] - pos[target - 1];
        // 第二刀间隔：pos[2*target] - pos[2*target-1]
        long gap2 = pos[2 * target] - pos[2 * target - 1];
        
        return (int)(gap1 * gap2 % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **三等分**：每段 total/3 个 1
2. **间隔乘积**：两刀可选位置独立相乘
3. **全零特例**：C(n-1,2) 种分法
