## 题目描述

有 n 个怪物，力量值为 `power[i]`。每天获得 gain 点魔法（初始 gain=1），消耗 `power[i]` 点魔法可杀死怪物 i，每杀一只 gain 加 1。返回杀死所有怪物所需的最少天数。

## 解题思路

状态压缩 DP：用整数 mask 的二进制位表示已杀死的怪物集合，`dp[mask]` 为杀死这些怪物所需最少天数。转移时枚举下一个要杀的怪物 i，`gain = popcount(mask) + 1`，天数需向上取整。

## Java 代码实现

```java
class Solution {
    public long minimumTime(int[] power) {
        int n = power.length, total = 1 << n;
        long[] dp = new long[total];
        Arrays.fill(dp, Long.MAX_VALUE / 2);
        dp[0] = 0;

        for (int mask = 0; mask < total; mask++) {
            if (dp[mask] == Long.MAX_VALUE / 2) continue;
            int k = Integer.bitCount(mask);
            int gain = k + 1; // 当前增益
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) continue; // 已杀死
                int newMask = mask | (1 << i);
                // 向上取整：(power[i] + gain - 1) / gain
                long days = ((long) power[i] + gain - 1) / gain;
                dp[newMask] = Math.min(dp[newMask], dp[mask] + days);
            }
        }
        return dp[total - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n * n)，n <= 17 约 200 万次
- **空间复杂度**：O(2^n)

## 关键点总结

1. 状态掩码 mask 中 1 的个数即已杀死怪物数，`gain = popcount(mask) + 1`。
2. 天数向上取整：`(power[i] + gain - 1) / gain`。
3. dp 值可能很大（power[i] 最大 10^9，n 最多 17），需用 `long`。
