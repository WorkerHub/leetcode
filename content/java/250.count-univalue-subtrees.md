## 题目描述

给定一棵二叉树，统计该二叉树中同值子树的个数。

同值子树是指该子树的所有节点都具有相同的值。

**示例 1：**
```
输入: root = [5,1,5,5,5,null,5]

              5
             / \
            1   5
           / \   \
          5   5   5

输出: 4
解释: 有 4 个同值子树：
- 两个叶子节点 5（左子树的两个 5）
- 一个叶子节点 5（右子树的 5）
- 根节点的右子树（全是 5）
```

**示例 2：**
```
输入: root = []
输出: 0
```

**示例 3：**
```
输入: root = [5,5,5,5,5,null,5]
输出: 6
```

**提示：**
- 树中节点数目在范围 [0, 1000] 内
- -1000 <= Node.val <= 1000

## 解题思路

这道题要求统计同值子树的个数，核心是**自底向上的递归**。

**核心思想：**
- 使用后序遍历（左-右-根），自底向上判断每个子树是否是同值子树
- 一个树是同值子树的条件：
  1. 左子树是同值子树（或为空）
  2. 右子树是同值子树（或为空）
  3. 左子树的值 == 根节点的值（如果左子树存在）
  4. 右子树的值 == 根节点的值（如果右子树存在）

**关键观察：**
1. **叶子节点**：一定是同值子树
2. **递归性质**：判断当前树是否是同值子树，需要先判断左右子树
3. **计数时机**：每发现一个同值子树就计数
4. **返回值**：递归函数返回当前子树是否是同值子树

**算法设计：**
- 使用深度优先搜索（DFS）
- 递归函数返回：当前子树是否是同值子树
- 使用成员变量记录计数

## Java 代码实现

### 方法一：递归 + 成员变量计数（推荐）⭐

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    private int count = 0;
    
    public int countUnivalSubtrees(TreeNode root) {
        count = 0;
        isUnival(root);
        return count;
    }
    
    /**
     * 判断以 node 为根的子树是否是同值子树
     * 返回 true/false，同时更新计数
     * 后序遍历：先处理左右子树，再判断根节点
     */
    private boolean isUnival(TreeNode node) {
        // 空节点认为是同值子树
        if (node == null) {
            return true;
        }
        
        // 递归判断左右子树（后序遍历，必须先处理子树）
        boolean leftIsUnival = isUnival(node.left);
        boolean rightIsUnival = isUnival(node.right);
        
        // 如果左右子树不是同值子树，当前树也不是
        if (!leftIsUnival || !rightIsUnival) {
            return false;
        }
        
        // 检查左子树的值是否等于当前节点
        if (node.left != null && node.left.val != node.val) {
            return false;
        }
        
        // 检查右子树的值是否等于当前节点
        if (node.right != null && node.right.val != node.val) {
            return false;
        }
        
        // 当前树是同值子树，计数加 1
        count++;
        return true;
    }
}
```

### 方法二：简化的递归判断

```java
class Solution {
    private int count = 0;
    
    public int countUnivalSubtrees(TreeNode root) {
        count = 0;
        helper(root);
        return count;
    }
    
    private boolean helper(TreeNode node) {
        if (node == null) {
            return true;
        }
        
        // 递归左右子树
        boolean left = helper(node.left);
        boolean right = helper(node.right);
        
        // 检查是否满足同值条件
        if (left && right) {
            if (node.left != null && node.left.val != node.val) {
                return false;
            }
            if (node.right != null && node.right.val != node.val) {
                return false;
            }
            
            // 满足条件，计数
            count++;
            return true;
        }
        
        return false;
    }
}
```

### 方法三：一行条件判断（简洁版）⭐

```java
class Solution {
    private int count = 0;
    
    public int countUnivalSubtrees(TreeNode root) {
        count = 0;
        isUnival(root);
        return count;
    }
    
    private boolean isUnival(TreeNode node) {
        if (node == null) return true;
        
        boolean left = isUnival(node.left);
        boolean right = isUnival(node.right);
        
        // 检查左右子树都是同值，且值与根节点相同
        if (left && right
                && (node.left == null || node.left.val == node.val)
                && (node.right == null || node.right.val == node.val)) {
            count++;
            return true;
        }
        
        return false;
    }
}
```

### 方法四：使用数组传递计数（避免成员变量）

```java
class Solution {
    public int countUnivalSubtrees(TreeNode root) {
        int[] count = {0};
        isUnival(root, count);
        return count[0];
    }
    
    private boolean isUnival(TreeNode node, int[] count) {
        if (node == null) return true;
        
        boolean left = isUnival(node.left, count);
        boolean right = isUnival(node.right, count);
        
        if (!left || !right) return false;
        
        if (node.left != null && node.left.val != node.val) return false;
        if (node.right != null && node.right.val != node.val) return false;
        
        count[0]++;
        return true;
    }
}
```

### 方法五：迭代法（使用后序遍历栈）

```java
import java.util.*;

class Solution {
    public int countUnivalSubtrees(TreeNode root) {
        if (root == null) return 0;
        
        int count = 0;
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode lastVisited = null;
        TreeNode current = root;
        
        // 使用哈希表记录每个节点是否是同值子树
        Map<TreeNode, Boolean> isUnivalMap = new HashMap<>();
        
        while (!stack.isEmpty() || current != null) {
            // 一直向左走
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            
            TreeNode peek = stack.peek();
            
            // 如果右子树存在且未访问，访问右子树
            if (peek.right != null && peek.right != lastVisited) {
                current = peek.right;
            } else {
                // 处理当前节点（后序遍历的"根"）
                TreeNode node = stack.pop();
                
                // 判断是否是同值子树
                boolean leftUnival = node.left == null || isUnivalMap.getOrDefault(node.left, false);
                boolean rightUnival = node.right == null || isUnivalMap.getOrDefault(node.right, false);
                
                boolean isCurrentUnival = leftUnival && rightUnival
                        && (node.left == null || node.left.val == node.val)
                        && (node.right == null || node.right.val == node.val);
                
                isUnivalMap.put(node, isCurrentUnival);
                if (isCurrentUnival) {
                    count++;
                }
                
                lastVisited = node;
            }
        }
        
        return count;
    }
}
```

## 复杂度分析

**递归方法（方法一~四）：**
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 是树的高度，递归栈空间

**迭代方法（方法五）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈和哈希表

## 图解示例

**示例 1：root = [5,1,5,5,5,null,5]**

```
              5
             / \
            1   5
           / \   \
          5   5   5

后序遍历处理过程：

1. 访问左下角的 5（叶子）
   - 是同值子树，count = 1

2. 访问右下角的 5（叶子）
   - 是同值子树，count = 2

3. 访问节点 1
   - 左子树是同值（5），右子树是同值（5）
   - 但 1 ≠ 5，所以节点 1 的子树不是同值
   - count 不变

4. 访问右边的 5（叶子）
   - 是同值子树，count = 3

5. 访问右边的 5（有右子节点）
   - 右子树是同值（5），值也是 5
   - 是同值子树，count = 4

6. 访问根节点 5
   - 左子树不是同值（节点 1 那棵树）
   - 不是同值子树
   - count = 4

最终结果：4
```

**判断逻辑流程图：**
```
判断节点 N 是否是同值子树：
  ├─ 左子树是同值？ ─ No ─> 返回 false
  │                  
  │                  Yes
  │                   ↓
  ├─ 右子树是同值？ ─ No ─> 返回 false
  │                  
  │                  Yes
  │                   ↓
  ├─ 左子节点值 == N.val？ ─ No ─> 返回 false
  │                  
  │                  Yes
  │                   ↓
  ├─ 右子节点值 == N.val？ ─ No ─> 返回 false
  │                  
  │                  Yes
  │                   ↓
  └─ count++，返回 true
```

## 关键点总结

1. **后序遍历**：必须先处理子树，再处理根节点
2. **递归返回值**：返回当前子树是否是同值子树
3. **空节点处理**：空节点返回 true，不影响父节点判断
4. **判断条件**：左右子树都是同值 + 值都等于根节点
5. **计数时机**：确认是同值子树时立即计数

## 易错点

1. **空节点处理**：空节点应该返回 true，不是 false
2. **判断顺序**：要先判断左右子树是否是同值，再判断值是否相等（防止短路导致计数错误）
3. **叶子节点**：叶子节点一定是同值子树，不要漏掉
4. **短路逻辑**：即使某个子树不是同值，也要继续递归另一侧（计数用）
5. **Java 成员变量**：多次调用时记得重置 `count = 0`
