## 题目描述

给你一个 `m x n` 正整数矩阵，每次可向右或向下移动若干步，得分为终点值减起点值，返回所有移动中可获得的**最大**总得分（可为负）。

## 解题思路

路径得分等于终点值减起点值（中间节点相消）。对每个终点 `(i,j)`，用 DP 维护其左上方（不含自身）的最小值 `minVal[i][j]`，答案为 `grid[i][j] - minVal[i][j]` 的最大值。

## Java 代码实现

```java
class Solution {
    public int maxScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // minVal[i][j] 表示 (i,j) 左上方所有格子中的最小值
        int[][] minVal = new int[m][n];
        final int INF = Integer.MAX_VALUE;
        for (int[] row : minVal) java.util.Arrays.fill(row, INF);

        int ans = Integer.MIN_VALUE;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 从上方和左方继承最小值（包含上/左格子本身）
                if (i > 0) minVal[i][j] = Math.min(minVal[i][j], Math.min(minVal[i-1][j], grid[i-1][j]));
                if (j > 0) minVal[i][j] = Math.min(minVal[i][j], Math.min(minVal[i][j-1], grid[i][j-1]));
                // 当前格作为终点，计算最大得分
                if (minVal[i][j] < INF) {
                    ans = Math.max(ans, grid[i][j] - minVal[i][j]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. 路径得分 = 终点值 - 起点值（中间节点抵消）
2. 只需找终点左上方（不含自身）的最小起点值
3. DP 从上方和左方同时继承最小值，覆盖所有可达起点
