## 题目描述

给定数字字符串 num，将其分成斐波那契式序列（f[i]+f[i+1]=f[i+2]，长度≥3，每个数<2^31）。返回任意一组合法分割。

**示例：**
```
输入：num = "1101111"
输出：[11,0,11,11]
```

## 解题思路

回溯搜索：枚举每个数字的切分位置，利用斐波那契性质剪枝。

## Java 代码实现

```java
class Solution {
    public List<Integer> splitIntoFibonacci(String num) {
        List<Integer> result = new ArrayList<>();
        backtrack(num, 0, result);
        return result;
    }

    private boolean backtrack(String num, int index, List<Integer> path) {
        if (index == num.length() && path.size() >= 3) {
            return true;
        }

        for (int i = index; i < num.length(); i++) {
            // 前导零检查
            if (num.charAt(index) == '0' && i > index) break;

            long curr = Long.parseLong(num.substring(index, i + 1));
            // 溢出检查
            if (curr > Integer.MAX_VALUE) break;

            int size = path.size();
            // 斐波那契检查
            if (size >= 2) {
                long sum = (long) path.get(size - 1) + path.get(size - 2);
                if (curr > sum) break;
                if (curr < sum) continue;
            }

            path.add((int) curr);
            if (backtrack(num, i + 1, path)) return true;
            path.remove(path.size() - 1);
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 2^n)，实际因剪枝远小于此
- **空间复杂度**：O(n)

## 关键点总结

1. **回溯搜索**：枚举分割位置
2. **多重剪枝**：前导零、溢出、大于目标和
3. **斐波那契约束**：确定前两个数后后续唯一
