## 题目描述

将数组分成多行，每行元素互不相同，使行数尽可能少。

## 解题思路

计数贪心：每个数字第k次出现放到第k行(0-indexed)，行数等于最大频率。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findMatrix(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Map<Integer, Integer> cnt = new HashMap<>();

        for (int x : nums) {
            int row = cnt.getOrDefault(x, 0);
            if (row == result.size()) {
                result.add(new ArrayList<>());
            }
            result.get(row).add(x);
            cnt.put(x, row + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **行数=最大频率**：每次出现需要新的一行
2. **cnt记录下次应放的行号**
3. **按需新建行**：row==result.size()时
