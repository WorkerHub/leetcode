## 题目描述

给定整数数组 `nums`（长度 <= 10^5）。每次操作选相邻两元素替换为它们的和，求使数组变为非递减有序所需的最少操作次数。

## 解题思路

大规模高效解法：用数组模拟双向链表（O(1) 合并）+ 最小堆（按相邻对之和排序，优先合并和最小的逆序对）+ 实时维护逆序对计数。每次从堆中取"和最小"的相邻对，若是逆序对则合并，同时更新前后相邻关系及逆序对数，直至逆序对数为 0。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int minimumPairRemoval(int[] nums) {
        int n = nums.length;
        if (n <= 1) return 0;

        long[] val = new long[n];
        int[] prv = new int[n];
        int[] nxt = new int[n];
        for (int i = 0; i < n; i++) {
            val[i] = nums[i];
            prv[i] = i - 1;
            nxt[i] = i + 1;
        }

        // 统计初始逆序对数
        int inv = 0;
        for (int i = 0; i < n - 1; i++) if (val[i] > val[i + 1]) inv++;

        // 最小堆：[相邻对之和, 左节点下标]
        PriorityQueue<long[]> heap = new PriorityQueue<>((a, b) -> Long.compare(a[0], b[0]));
        for (int i = 0; i < n - 1; i++) heap.offer(new long[]{val[i] + val[i + 1], i});

        boolean[] deleted = new boolean[n];
        int ops = 0;

        while (inv > 0) {
            long[] top = heap.poll();
            long pairSum = top[0];
            int i = (int) top[1];
            int j = nxt[i];

            // 跳过过期条目（节点已删除或值已变）
            if (deleted[i] || j >= n || deleted[j]) continue;
            if (val[i] + val[j] != pairSum) continue;
            if (val[i] <= val[j]) continue; // 非逆序对，跳过

            long merged = val[i] + val[j];
            inv--; // i 和 j 之间的逆序对消失

            // 更新前驱 pi 与 i 之间的逆序关系
            int pi = prv[i];
            if (pi >= 0) {
                if (val[pi] > val[i] && val[pi] <= merged) inv--;
                else if (val[pi] <= val[i] && val[pi] > merged) inv++;
            }

            // 更新 j 与后继 nj 之间的逆序关系
            int nj = nxt[j];
            if (nj < n) {
                if (val[j] > val[nj] && merged <= val[nj]) inv--;
                else if (val[j] <= val[nj] && merged > val[nj]) inv++;
            }

            // 执行合并
            val[i] = merged;
            deleted[j] = true;
            nxt[i] = nj;
            if (nj < n) prv[nj] = i;

            // 将新的相邻对加入堆
            if (pi >= 0) heap.offer(new long[]{val[pi] + merged, pi});
            if (nj < n) heap.offer(new long[]{merged + val[nj], i});

            ops++;
        }

        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次合并 O(log n)，最多 O(n) 次合并
- 空间复杂度：O(n)

## 关键点总结

1. 双向链表模拟数组，合并操作 O(1) 更新前后指针
2. 最小堆惰性删除：取堆顶时验证值是否一致，不一致则跳过
3. 每次合并后实时更新前后相邻关系的逆序对计数
