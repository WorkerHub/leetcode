## 题目描述

给你一个无重复元素的整数数组，每次右移将最后一个元素移到开头，返回使数组有序所需的最少右移次数，不可能则返回 -1。

## 解题思路

找下降点：旋转数组能排序当且仅当恰好有 1 个下降点，且 `nums[n-1] <= nums[0]`，右移次数 = `n - drop_idx`。

## Java 代码实现

```java
class Solution {
    public int minimumRightShifts(List<Integer> nums) {
        int n = nums.size();
        int dropIdx = -1, dropCount = 0;

        for (int i = 0; i < n - 1; i++) {
            if (nums.get(i) > nums.get(i + 1)) {
                dropCount++;
                dropIdx = i + 1; // 下降点后的位置即右移起点
            }
        }

        if (dropCount == 0) return 0; // 已经有序
        if (dropCount > 1) return -1; // 多个下降点无法通过旋转排序

        // 检查旋转后首尾是否满足有序
        if (nums.get(n - 1) <= nums.get(0)) {
            return n - dropIdx;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 旋转数组能排序当且仅当至多有 1 个下降点
2. 下降点位置 `drop_idx` 决定右移次数：`n - drop_idx`
3. 还需验证 `nums[n-1] <= nums[0]`（旋转点两端相接有序）
