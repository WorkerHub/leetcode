## 题目描述

给定整数数组 `nums` 和正整数 `k`，每次操作可将任意元素加 1 或减 1（代价 1），返回使某个长度为 k 的子数组所有元素相等所需最少操作数的最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minOperations(int[] nums, int k) {
        int n = nums.length;
        long ans = Long.MAX_VALUE;

        // 滑动窗口 + 两个堆维护中位数
        // 大根堆（左半，存负值）
        PriorityQueue<Long> left = new PriorityQueue<>(Collections.reverseOrder());
        long leftSum = 0;
        // 小根堆（右半）
        PriorityQueue<Long> right = new PriorityQueue<>();
        long rightSum = 0;
        // 懒删除
        Map<Long, Integer> toRemove = new HashMap<>();

        for (int r = 0; r < n; r++) {
            // 添加 nums[r]
            long v = nums[r];
            if (left.isEmpty() || v <= left.peek()) {
                left.offer(v);
                leftSum += v;
            } else {
                right.offer(v);
                rightSum += v;
            }

            // 平衡两堆
            while (left.size() > (k + 1) / 2) {
                long top = left.poll();
                leftSum -= top;
                right.offer(top);
                rightSum += top;
            }
            while (!right.isEmpty() && right.size() > k / 2) {
                long top = right.poll();
                rightSum -= top;
                left.offer(top);
                leftSum += top;
            }

            if (r >= k) {
                // 移除 nums[r - k]
                long rem = nums[r - k];
                toRemove.merge(rem, 1, Integer::sum);
                if (!left.isEmpty() && rem <= left.peek()) leftSum -= rem;
                else rightSum -= rem;

                // 懒清理
                while (!left.isEmpty() && toRemove.getOrDefault(left.peek(), 0) > 0) {
                    long top = left.poll();
                    toRemove.merge(top, -1, Integer::sum);
                    if (toRemove.get(top) == 0) toRemove.remove(top);
                }
                while (!right.isEmpty() && toRemove.getOrDefault(right.peek(), 0) > 0) {
                    long top = right.poll();
                    toRemove.merge(top, -1, Integer::sum);
                    if (toRemove.get(top) == 0) toRemove.remove(top);
                }

                // 再平衡
                while (left.size() > (k + 1) / 2) {
                    long top = left.poll(); leftSum -= top;
                    right.offer(top); rightSum += top;
                }
                while (!right.isEmpty() && right.size() > k / 2) {
                    long top = right.poll(); rightSum -= top;
                    left.offer(top); leftSum += top;
                }
            }

            if (r >= k - 1) {
                long median = left.peek();
                // 代价 = median * left.size() - leftSum + rightSum - median * right.size()
                long cost = median * left.size() - leftSum + rightSum - median * right.size();
                ans = Math.min(ans, cost);
            }
        }
        return ans == Long.MAX_VALUE ? 0 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log k)，滑动窗口 + 堆操作
- 空间复杂度：O(k)

## 关键点总结

1. 使子数组所有元素相等的最优目标值是中位数。
2. 两个堆（大根堆 + 小根堆）维护中位数，并用懒删除处理滑动窗口。
3. 代价 = 各元素与中位数绝对差之和，可用两堆的和快速计算。
