## 题目描述

给定固定长度整数数组，将每个零复制一份，其余元素右移。原地修改，不返回。

**示例：**
```
输入：arr = [1,0,2,3,0,4,5,0]
输出：[1,0,0,2,3,0,0,4]
```

## 解题思路

两遍扫描：第一遍计算零的数量确定实际写入范围；第二遍从后往前填充，避免覆盖未处理元素。

## Java 代码实现

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        int n = arr.length;
        int zeros = 0;

        // 第一遍：计算需要处理的范围
        for (int num : arr) {
            if (num == 0) zeros++;
        }

        // 从后往前填充
        int i = n - 1;
        int write = n + zeros - 1;

        while (i >= 0) {
            if (write < n) {
                arr[write] = arr[i];
            }
            // 如果是零，再写一次
            if (arr[i] == 0) {
                write--;
                if (write < n) {
                    arr[write] = 0;
                }
            }
            i--;
            write--;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **从后往前**：避免覆盖未处理元素
2. **虚拟写指针**：write 可能超出数组范围，只在 < n 时实际写入
3. **零的复制**：遇到零时 write 多移动一步
