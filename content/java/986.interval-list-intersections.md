## 题目描述

给定两个排序好的区间列表 firstList 和 secondList，返回两个列表的交集。

**示例：**
```
输入：firstList = [[0,2],[5,10]], secondList = [[1,5],[8,12]]
输出：[[1,2],[5,5],[8,10]]
```

## 解题思路

双指针：计算当前两个区间的交集 [max(start), min(end)]，若有效则加入结果。移动结束较早的指针。

## Java 代码实现

```java
class Solution {
    public int[][] intervalIntersection(int[][] firstList, int[][] secondList) {
        List<int[]> result = new ArrayList<>();
        int i = 0, j = 0;

        while (i < firstList.length && j < secondList.length) {
            int start = Math.max(firstList[i][0], secondList[j][0]);
            int end = Math.min(firstList[i][1], secondList[j][1]);

            if (start <= end) {
                result.add(new int[]{start, end});
            }

            // 移动结束较早的指针
            if (firstList[i][1] < secondList[j][1]) {
                i++;
            } else {
                j++;
            }
        }

        return result.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(1)

## 关键点总结

1. **交集计算**：start = max(两起点)，end = min(两终点)
2. **有效性判断**：start <= end 时有交集
3. **指针推进**：结束早的区间不会再与后续区间相交
