## 题目描述

给定整数数组 `nums`、范围 `[lower, upper]` 和整数 `limit`，每次可将某元素加减 1（结果必须在 [lower, upper] 内），返回使所有元素相等的最少操作数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minOperations(int[] nums, int lower, int upper, int limit) {
        int n = nums.length;

        // 将所有元素截断到 [lower, upper]
        int[] clipped = new int[n];
        for (int i = 0; i < n; i++) {
            clipped[i] = Math.max(lower, Math.min(upper, nums[i]));
        }
        Arrays.sort(clipped);

        // 最优目标值为中位数（最小化绝对差之和）
        int median = clipped[n / 2];
        int target = Math.max(lower, Math.min(upper, median));

        // 用前缀和计算总代价
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + clipped[i];

        // 二分找 target 的位置
        int pos = Arrays.binarySearch(clipped, target);
        if (pos < 0) pos = -pos - 1;
        else {
            // 找最左位置
            while (pos > 0 && clipped[pos - 1] == target) pos--;
        }

        // 左侧代价：target * pos - prefix[pos]
        long leftCost = (long) target * pos - prefix[pos];
        // 右侧代价：(prefix[n] - prefix[pos]) - target * (n - pos)
        long rightCost = (prefix[n] - prefix[pos]) - (long) target * (n - pos);

        return leftCost + rightCost;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 超出 `[lower, upper]` 的元素截断到边界（必须满足的约束）
2. 截断后，使所有元素相等的最优目标值是中位数
3. 前缀和 O(1) 计算总绝对差代价
