## 题目描述

模拟消消乐：标记连续3个及以上相同的糖果（行/列），消除后上方糖果下落，重复直到稳定。

**示例：**
```
输入：board（10×5矩阵）
输出：稳定后的矩阵
```

## 解题思路

循环模拟：1) 标记所有可消除的（用负数标记），2) 让糖果下落（双指针从下往上收集），3) 重复直到无可消除。

## Java 代码实现

```java
class Solution {
    public int[][] candyCrush(int[][] board) {
        int rows = board.length, cols = board[0].length;

        while (true) {
            boolean found = false;

            // 标记行中连续3个及以上相同的
            for (int r = 0; r < rows; r++) {
                for (int c = 0; c < cols - 2; c++) {
                    int val = Math.abs(board[r][c]);
                    if (val != 0 && val == Math.abs(board[r][c + 1]) && val == Math.abs(board[r][c + 2])) {
                        board[r][c] = board[r][c + 1] = board[r][c + 2] = -val;
                        found = true;
                    }
                }
            }

            // 标记列中连续3个及以上相同的
            for (int r = 0; r < rows - 2; r++) {
                for (int c = 0; c < cols; c++) {
                    int val = Math.abs(board[r][c]);
                    if (val != 0 && val == Math.abs(board[r + 1][c]) && val == Math.abs(board[r + 2][c])) {
                        board[r][c] = board[r + 1][c] = board[r + 2][c] = -val;
                        found = true;
                    }
                }
            }

            if (!found) break;

            // 让糖果下落
            for (int c = 0; c < cols; c++) {
                int writeRow = rows - 1;
                for (int r = rows - 1; r >= 0; r--) {
                    if (board[r][c] > 0) {
                        board[writeRow][c] = board[r][c];
                        writeRow--;
                    }
                }
                while (writeRow >= 0) {
                    board[writeRow][c] = 0;
                    writeRow--;
                }
            }
        }
        return board;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(rows × cols × k)，k 为消除轮数
- **空间复杂度**：O(1)，原地修改

## 关键点总结

1. **负数标记**：避免影响同轮其他检查
2. **取绝对值比较**：已标记的负数仍参与比较
3. **下落算法**：双指针从下往上收集正数
