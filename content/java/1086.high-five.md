## 题目描述

给定成绩列表 items[i] = [ID, score]，计算每个学生前五名平均成绩（整数除法）。按 ID 升序返回。

**示例：**
```
输入：items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
输出：[[1,87],[2,88]]
```

## 解题思路

按学生 ID 分组，对每组成绩降序排序取前 5，求和整除 5。

## Java 代码实现

```java
class Solution {
    public int[][] highFive(int[][] items) {
        // 按 ID 分组
        TreeMap<Integer, PriorityQueue<Integer>> map = new TreeMap<>();

        for (int[] item : items) {
            map.computeIfAbsent(item[0], k -> new PriorityQueue<>()).offer(item[1]);
            // 只保留最大的 5 个（最小堆，超过 5 个就弹出最小的）
            if (map.get(item[0]).size() > 5) {
                map.get(item[0]).poll();
            }
        }

        int[][] result = new int[map.size()][2];
        int idx = 0;
        for (Map.Entry<Integer, PriorityQueue<Integer>> entry : map.entrySet()) {
            int sum = 0;
            for (int score : entry.getValue()) {
                sum += score;
            }
            result[idx++] = new int[]{entry.getKey(), sum / 5};
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log 5) = O(n)
- **空间复杂度**：O(k)，k 为学生数

## 关键点总结

1. **最小堆维护 Top 5**：堆大小超 5 时弹出最小值
2. **TreeMap 自动排序**：按 ID 有序遍历
3. **整数除法**：sum / 5 在 Java 中自动截断
