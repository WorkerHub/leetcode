## 题目描述

给你正整数 `n`，返回 `[even, odd]`，分别表示其二进制表示中偶数下标和奇数下标处值为 1 的位数（下标从 0 开始，最低位为下标 0）。

## 解题思路

逐位右移枚举 `n` 的每一位，判断当前下标的奇偶性，分别统计值为 1 的位数。

## Java 代码实现

```java
class Solution {
    public int[] evenOddBit(int n) {
        int even = 0, odd = 0;
        int idx = 0; // 当前位的下标
        while (n > 0) {
            if ((n & 1) == 1) {
                if (idx % 2 == 0) even++;
                else odd++;
            }
            n >>= 1;
            idx++;
        }
        return new int[]{even, odd};
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 下标从低位（最右边）开始计数，最低位是下标 0（偶数）
2. 逐位右移，同时递增下标计数器
3. 只有值为 1 的位才计数
