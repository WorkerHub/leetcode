## 题目描述

给定有向带权图，每条边 `[u, v, w, open, close]` 只在时间窗口 `[open, close]` 内可通过，从节点 0 出发，返回到达节点 n-1 的最短时间，不可达返回 -1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int n, int[][] edges) {
        // 构建邻接表：[v, w, open, close]
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) graph[e[0]].add(new int[]{e[1], e[2], e[3], e[4]});

        // Dijkstra：(时间, 节点)
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long t = cur[0];
            int u = (int) cur[1];
            if (t > dist[u]) continue;
            if (u == n - 1) return (int) t;
            for (int[] e : graph[u]) {
                int v = e[0], w = e[1], open = e[2], close = e[3];
                if (t > close) continue; // 边已关闭
                long depart = Math.max(t, open); // 等待到开放时刻
                long arrive = depart + w;
                if (arrive <= close && arrive < dist[v]) {
                    dist[v] = arrive;
                    pq.offer(new long[]{arrive, v});
                }
            }
        }
        return dist[n - 1] == Long.MAX_VALUE ? -1 : (int) dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)
- 空间复杂度：O(n + m)

## 关键点总结

1. `depart = max(t, open)` 处理等待开放的情况
2. `arrive <= close` 保证在时间窗口关闭前到达
3. 使用 long 避免时间计算溢出
