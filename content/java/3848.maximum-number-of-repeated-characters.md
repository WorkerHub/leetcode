## 题目描述

给你一个字符串 `s`，返回出现次数最多的字符及其出现次数。如果有多个字符出现次数相同，返回字典序最小的字符。

## 解题思路

用数组统计每个小写字母的频率，找到最大频率，再从 'a' 到 'z' 顺序找第一个频率等于最大值的字符（自然保证字典序最小）。

## Java 代码实现

```java
class Solution {
    public Object[] maxRepeated(String s) {
        int[] cnt = new int[26];
        // 统计每个字符出现次数
        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;
        }
        // 找最大频率
        int maxCount = 0;
        for (int v : cnt) {
            maxCount = Math.max(maxCount, v);
        }
        // 从字典序最小的字符开始找
        char bestChar = 'a';
        for (int i = 0; i < 26; i++) {
            if (cnt[i] == maxCount) {
                bestChar = (char) ('a' + i);
                break;
            }
        }
        return new Object[]{String.valueOf(bestChar), maxCount};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串
- 空间复杂度：O(1)，固定大小的 26 个字母数组

## 关键点总结

1. 用长度为 26 的数组代替哈希表，效率更高且自然有序。
2. 从 'a' 到 'z' 顺序遍历保证找到的是字典序最小的字符。
3. 次数相同时取字典序最小，不是任意一个。
