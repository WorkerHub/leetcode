## 题目描述

给定数组 nums 和两个长度 firstLen、secondLen，找两个不重叠子数组使其和最大。

**示例：**
```
输入：nums = [0,6,5,2,2,5,1,9,4], firstLen = 1, secondLen = 2
输出：20（[9] + [6,5]）
```

## 解题思路

前缀和 + 滑动窗口：分两种情况（firstLen 在左或右），遍历时动态维护左侧最大子数组和。

## Java 代码实现

```java
class Solution {
    public int maxSumTwoNoOverlap(int[] nums, int firstLen, int secondLen) {
        int n = nums.length;
        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        return Math.max(helper(prefix, firstLen, secondLen, n),
                       helper(prefix, secondLen, firstLen, n));
    }

    // L 在左，M 在右
    private int helper(int[] prefix, int L, int M, int n) {
        int maxL = 0, result = 0;
        for (int i = L + M; i <= n; i++) {
            // 更新左侧长度 L 子数组的最大和
            maxL = Math.max(maxL, prefix[i - M] - prefix[i - M - L]);
            // 当前长度 M 子数组和
            int curM = prefix[i] - prefix[i - M];
            result = Math.max(result, maxL + curM);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **两种情况**：firstLen 在左或 secondLen 在左
2. **动态维护最大值**：遍历时记录左侧已遍历的最大子数组和
3. **前缀和**：O(1) 计算子数组和
