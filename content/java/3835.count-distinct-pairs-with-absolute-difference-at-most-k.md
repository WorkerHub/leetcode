## 题目描述

给定整数数组 `nums` 和非负整数 `k`，返回满足 `a != b` 且 `|a - b| <= k` 的不同元素对数目（不考虑顺序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countDistinctPairs(int[] nums, int k) {
        // 去重并排序
        int[] vals = Arrays.stream(nums).distinct().sorted().toArray();
        int count = 0, left = 0;
        for (int right = 0; right < vals.length; right++) {
            while (vals[right] - vals[left] > k) left++;
            count += right - left; // 以 right 为右端的合法对数
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先去重，转化为有序不重复数组的配对问题
2. 双指针维护满足差值约束的窗口
3. 以 right 为右端的合法对数为 `right - left`（不含 right 自身）
