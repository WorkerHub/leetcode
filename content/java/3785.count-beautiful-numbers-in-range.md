## 题目描述

给定整数 `lo` 和 `hi`，统计 `[lo, hi]` 范围内每一位数字（不为 0）各不相同且整数能被每一位数字整除的"美丽数字"数量，结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;
    // 状态：位置、掩码（1-9用9位）、当前LCM、当前数mod2520、是否紧贴上界
    private int[] digits;
    private long[][][][][] memo;

    public int countBeautifulNumbers(int lo, int hi) {
        return (int) ((countUpTo(hi) - countUpTo(lo - 1) + MOD) % MOD);
    }

    private long countUpTo(int n) {
        if (n <= 0) return 0;
        digits = String.valueOf(n).chars().map(c -> c - '0').toArray();
        int L = digits.length;
        // memo[pos][mask][lcm_idx][mod][tight]
        // LCM of 1..9 = 2520, 最多9种lcm值（实际是2520的因数）
        // 简化：直接递归+记忆化
        memo = new long[L][512][2521][2521][2];
        for (long[][][][] a : memo) for (long[][][] b : a) for (long[][] c : b) for (long[] d : c) java.util.Arrays.fill(d, -1);
        return dfs(0, 0, 1, 0, 1, L);
    }

    private long dfs(int pos, int mask, int lcm, int mod, int tight, int L) {
        if (pos == L) {
            if (mask == 0) return 0;
            return mod % lcm == 0 ? 1 : 0;
        }
        if (memo[pos][mask][lcm][mod][tight] != -1) return memo[pos][mask][lcm][mod][tight];

        int limit = tight == 1 ? digits[pos] : 9;
        long res = 0;

        for (int d = 0; d <= limit; d++) {
            int newTight = (tight == 1 && d == limit) ? 1 : 0;
            if (d == 0) {
                if (mask == 0) { // 前导零
                    res += dfs(pos + 1, 0, 1, 0, newTight, L);
                }
                // 0 在数字中不允许（不加入）
            } else {
                int bit = 1 << (d - 1);
                if ((mask & bit) != 0) continue; // 数字已用过
                int newLcm = lcm(lcm, d);
                int newMod = (mod * 10 + d) % 2520;
                res += dfs(pos + 1, mask | bit, newLcm, newMod, newTight, L);
            }
        }

        return memo[pos][mask][lcm][mod][tight] = res % MOD;
    }

    private int lcm(int a, int b) {
        return a / gcd(a, b) * b;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(L * 2^9 * 2520 * 2)，L 为位数（最多 10）
- 空间复杂度：O(L * 2^9 * 2520)

## 关键点总结

1. 同时满足"不重复"和"能被每位整除"：不重复用 9 位掩码，整除用 LCM 和余数
2. LCM(1..9) = 2520，mod 状态上界为 2520
3. 区间统计用差分：`count(hi) - count(lo-1)`
