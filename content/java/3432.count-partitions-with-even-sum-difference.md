## 题目描述

给定整数数组 `nums`，对每个分割点 i（1 <= i <= n-1）计算左部分之和减右部分之和的差值，返回差值为偶数的分割方案数。

## Java 代码实现

```java
class Solution {
    public int countPartitions(int[] nums) {
        // 差值 = left_sum - right_sum = 2 * left_sum - total
        // 差值为偶数 <=> total 为偶数
        int total = 0;
        for (int v : nums) total += v;
        return (total % 2 == 0) ? nums.length - 1 : 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 差值 = 2 * left_sum - total，偶数性仅取决于 total 的奇偶性
2. total 为偶数时所有 n-1 个分割点均满足，否则无满足的分割
3. 无需枚举分割点，直接判断总和奇偶
