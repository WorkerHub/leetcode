## 题目描述

给定整数数组 `nums`，执行 `k` 次操作：每次将数组最大元素除以 2（向下取整）。返回操作后所有偶数元素的总和。

## 解题思路

用最大堆模拟。由于任何正整数最多经过 30 次除 2 后变为 0，实际操作次数上限为 `min(k, 30 * n)`，超过后结果不变。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long sumDivisibleByTwo(int[] nums, int k) {
        // 最大堆
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int x : nums) maxHeap.offer(x);

        // 最多操作 min(k, 30*n) 次
        int maxOps = Math.min(k, 30 * nums.length);

        for (int i = 0; i < maxOps; i++) {
            int top = maxHeap.poll();
            if (top == 0) {
                maxHeap.offer(0);
                break; // 最大值为 0，后续无变化
            }
            maxHeap.offer(top / 2);
        }

        // 统计偶数元素之和
        long sum = 0;
        for (int x : maxHeap) {
            if (x % 2 == 0) sum += x;
        }
        return sum;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + min(k, 30n)) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 任何正整数最多 30 次除 2 后变为 0（`log2(10^9) ≈ 30`）
2. 操作次数上限 `30 * n` 防止超时
3. 最大堆高效获取最大值，O(log n) 每次操作
