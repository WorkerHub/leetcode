## 题目描述

司机从位置 1 出发，给定 `rides[i] = [start, end, tip]`，接一单收入为 `end - start + tip`，同时只能接一位乘客，返回最大总收入。

## 解题思路

经典加权区间调度 DP：`dp[i]` 为到达位置 i 的最大收入，转移为 `dp[i] = dp[i-1]`（不接单）或对所有在 i 下车的乘客取 `dp[start] + (i-start+tip)` 的最大值。用哈希表按下车位置分组加速转移。

## Java 代码实现

### 方法一：动态规划 + 哈希表（推荐）

```java
import java.util.*;

class Solution {
    public long maxTaxiEarnings(int n, int[][] rides) {
        // 按下车位置分组
        Map<Integer, List<int[]>> endMap = new HashMap<>();
        for (int[] ride : rides) {
            endMap.computeIfAbsent(ride[1], k -> new ArrayList<>()).add(ride);
        }

        long[] dp = new long[n + 1]; // dp[i]表示到达位置i的最大收入

        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1]; // 不在位置i接单
            if (endMap.containsKey(i)) {
                for (int[] ride : endMap.get(i)) {
                    int start = ride[0], tip = ride[2];
                    long earn = i - start + tip;
                    dp[i] = Math.max(dp[i], dp[start] + earn);
                }
            }
        }

        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为 rides 数量
- 空间复杂度：O(n + m)

## 关键点总结

1. `dp[i] = dp[i-1]` 不能漏掉（司机可以不接单直接到位置 i）
2. 收入公式是 `end - start + tip`，从 `dp[start]` 转移
3. 用 long 防止溢出（tip 最大 10^5，n 最大 10^5）
