## 题目描述

给你 n 个方法（编号 0 到 n-1）和调用关系 `invocations`，方法 k 存在 bug。若某方法只能从有 bug 的方法到达，它也被视为有 bug。返回所有无 bug 方法的列表。

## 解题思路

两步：1) BFS 从 k 找出所有可达节点（疑似有 bug）；2) 检查是否有"干净方法"调用了疑似方法。若有则无法移除任何方法，否则移除疑似方法集合。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> remainingMethods(int n, int k, int[][] invocations) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : invocations) graph.get(e[0]).add(e[1]);

        // BFS 找出从 k 可达的所有节点（疑似有 bug）
        boolean[] suspicious = new boolean[n];
        Queue<Integer> q = new LinkedList<>();
        q.offer(k);
        suspicious[k] = true;
        while (!q.isEmpty()) {
            int node = q.poll();
            for (int nb : graph.get(node)) {
                if (!suspicious[nb]) {
                    suspicious[nb] = true;
                    q.offer(nb);
                }
            }
        }

        // 检查是否有干净方法调用了疑似方法
        for (int[] e : invocations) {
            if (!suspicious[e[0]] && suspicious[e[1]]) {
                // 无法移除，返回全部方法
                List<Integer> all = new ArrayList<>();
                for (int i = 0; i < n; i++) all.add(i);
                return all;
            }
        }

        // 安全移除疑似方法，返回其余方法
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (!suspicious[i]) result.add(i);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 图是有向图，只能从调用方向被调用方传播
2. 检查外部调用：若存在边 `(a→b)` 使 a 干净而 b 疑似，则不能移除任何方法
3. 若整个图都从 k 可达（无干净方法调用疑似方法），则移除 suspicious 集合
