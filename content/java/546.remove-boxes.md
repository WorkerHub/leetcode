## 题目描述

给出不同颜色的盒子 `boxes`，每轮移除连续 k 个相同颜色的盒子得 k*k 分。返回最大积分。

**示例：**
```
输入：boxes = [1,3,2,2,2,3,4,3,1]
输出：23
```

## 解题思路

`dp[l][r][k]` 表示移除 `boxes[l..r]` 且 `boxes[r]` 右侧有 k 个同色盒子时的最大积分。

## Java 代码实现

```java
class Solution {
    private int[][][] memo;

    public int removeBoxes(int[] boxes) {
        int n = boxes.length;
        memo = new int[n][n][n];
        return dp(boxes, 0, n - 1, 0);
    }

    private int dp(int[] boxes, int l, int r, int k) {
        if (l > r) return 0;
        if (memo[l][r][k] > 0) return memo[l][r][k];

        // 合并右侧连续相同颜色
        while (r > l && boxes[r] == boxes[r - 1]) {
            r--;
            k++;
        }

        // 情况1：直接移除 boxes[r] 及右侧 k 个同色盒子
        int res = dp(boxes, l, r - 1, 0) + (k + 1) * (k + 1);

        // 情况2：在区间中找同色盒子合并
        for (int i = l; i < r; i++) {
            if (boxes[i] == boxes[r]) {
                res = Math.max(res, dp(boxes, l, i, k + 1) + dp(boxes, i + 1, r - 1, 0));
            }
        }

        memo[l][r][k] = res;
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n⁴)
- **空间复杂度**：O(n³)

## 关键点总结

1. **三维状态**：`dp[l][r][k]`，k 表示右侧同色盒子数
2. **两种决策**：直接移除 or 找同色合并
3. **优化**：合并连续相同颜色减少递归
