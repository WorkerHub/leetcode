## 题目描述

给你正整数数组 `nums` 和 `cost`，将 `nums[i]` 增减 1 的开销为 `cost[i]`，返回使所有元素相等的最小总开销。

## 解题思路

目标函数 `f(t) = Σ|nums[i] - t| * cost[i]` 是凸函数，最优点是加权中位数。排序后找第一个累计权重超过总权重一半的值即为加权中位数，然后计算总开销。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minCost(int[] nums, int[] cost) {
        int n = nums.length;
        // 按 nums 值排序（记录原始索引对应关系）
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> nums[a] - nums[b]);

        // 计算总权重，找加权中位数
        long totalCost = 0;
        for (int c : cost) totalCost += c;
        long half = (totalCost + 1) / 2; // 向上取整的一半

        long prefix = 0;
        int median = nums[idx[n - 1]]; // 默认最大值
        for (int i = 0; i < n; i++) {
            prefix += cost[idx[i]];
            if (prefix >= half) {
                median = nums[idx[i]];
                break;
            }
        }

        // 计算将所有元素变为加权中位数的总开销
        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += (long) Math.abs(nums[i] - median) * cost[i];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 目标函数是加权绝对差之和，是凸函数，最优解为加权中位数
2. 排序后找累计权重首次超过总权重一半的位置
3. 注意乘法可能溢出，使用 `long`
