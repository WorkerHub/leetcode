## 题目描述

给定 `startTime`、`endTime` 和 `queryTime`，返回在时间点 `queryTime` 正在做作业的学生数量（区间 `[startTime[i], endTime[i]]` 含端点）。

## Java 代码实现

```java
class Solution {
    public int busyStudent(int[] startTime, int[] endTime, int queryTime) {
        int count = 0;
        for (int i = 0; i < startTime.length; i++) {
            // 检查 queryTime 是否在闭区间内
            if (startTime[i] <= queryTime && queryTime <= endTime[i]) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历一次
- 空间复杂度：O(1)

## 关键点总结

1. 区间判断使用闭区间 `<=`，不要漏掉端点
2. 单次遍历即可，无需排序
