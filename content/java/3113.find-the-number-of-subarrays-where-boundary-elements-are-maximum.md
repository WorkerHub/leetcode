## 题目描述

给你整数数组 `nums`，统计第一个和最后一个元素都等于子数组最大值的子数组数量。

## 解题思路

单调不增栈，用 `(值, 计数)` 对存储。处理每个元素 x 时，弹出栈中小于 x 的元素，若栈顶值等于 x，则以 x 为边界的合法子数组数 = 栈中该值的计数，然后计数 +1；否则入栈新元素。每个元素本身（长度 1）也算一个合法子数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long numberOfSubarrays(int[] nums) {
        long ans = 0;
        Deque<long[]> stack = new ArrayDeque<>(); // [值, 计数]

        for (int x : nums) {
            // 弹出所有严格小于 x 的元素
            while (!stack.isEmpty() && stack.peek()[0] < x) stack.pop();

            if (!stack.isEmpty() && stack.peek()[0] == x) {
                long cnt = stack.peek()[1];
                ans += cnt; // cnt 个以前面相同值开头的合法子数组
                stack.peek()[1]++;
            } else {
                stack.push(new long[]{x, 1});
            }
            ans++; // 长度为 1 的子数组 [x]
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 单调不增栈，`(值, 计数)` 压缩相同值
2. 弹出条件是严格小于，等于时更新计数
