## 题目描述

Alice 展示长度为 n 的字符串 s（F/W/E），Bob 每轮选择不同于上一轮的字符，胜负规则：Water 胜 Fire，Fire 胜 Earth，Earth 胜 Water，各得 +1/0/-1 分。返回 Bob 总分 > 0 的策略数（模 10^9+7）。

## 解题思路

DP：`dp[score_offset][last]` 表示当前积分偏移为 offset 且上一步选 last 的方案数。用偏移量 n 将积分范围 [-n,n] 映射到 [0,2n]。每轮枚举 cur != last，按胜负关系更新分数。统计最终分数 > n（即实际分 > 0）的所有方案。

## Java 代码实现

```java
class Solution {
    public int countWinningSequences(String s) {
        final int MOD = 1_000_000_007;
        int n = s.length();
        // delta[alice][bob]: bob 得分变化，Water(1)>Fire(0), Fire(0)>Earth(2), Earth(2)>Water(1)
        int[][] delta = new int[3][3];
        int[][] wins = {{1, 0}, {0, 2}, {2, 1}}; // (bob, alice) bob 胜的组合
        for (int[] w : wins) delta[w[1]][w[0]] = 1;
        for (int a = 0; a < 3; a++) for (int b = 0; b < 3; b++)
            if (a != b && delta[a][b] == 0) delta[a][b] = -1;

        int offset = n;
        // dp[score + offset][last_choice]
        long[][] dp = new long[2 * n + 1][3];
        int first = charIdx(s.charAt(0));
        for (int bob = 0; bob < 3; bob++)
            dp[delta[first][bob] + offset][bob] = 1;

        for (int i = 1; i < n; i++) {
            int alice = charIdx(s.charAt(i));
            long[][] ndp = new long[2 * n + 1][3];
            for (int score = 0; score <= 2 * n; score++) {
                for (int last = 0; last < 3; last++) {
                    if (dp[score][last] == 0) continue;
                    for (int cur = 0; cur < 3; cur++) {
                        if (cur == last) continue; // 不能连续相同
                        int ns = score + delta[alice][cur];
                        if (ns >= 0 && ns <= 2 * n)
                            ndp[ns][cur] = (ndp[ns][cur] + dp[score][last]) % MOD;
                    }
                }
            }
            dp = ndp;
        }

        long ans = 0;
        for (int score = offset + 1; score <= 2 * n; score++)
            for (int last = 0; last < 3; last++)
                ans = (ans + dp[score][last]) % MOD;
        return (int) ans;
    }

    private int charIdx(char c) {
        return c == 'F' ? 0 : c == 'W' ? 1 : 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，n 轮，每轮遍历 O(n) 个分数状态 * 9
- 空间复杂度：O(n)

## 关键点总结

1. 偏移量处理负分：将 [-n, n] 映射到 [0, 2n]
2. 状态禁止连续相同选择（cur != last）
3. 胜负关系：Water > Fire > Earth > Water（循环克制）
