## 题目描述

给你一个网格矩阵，0 表示陆地，正整数表示水域中的鱼数，从任意水域出发按四方向移动只能进入水域，返回能收集到的最大鱼数。

## Java 代码实现

```java
class Solution {
    private int[][] grid;
    private int m, n;

    public int findMaxFish(int[][] grid) {
        this.grid = grid;
        m = grid.length;
        n = grid[0].length;
        int ans = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] > 0) {
                    ans = Math.max(ans, dfs(r, c));
                }
            }
        }
        return ans;
    }

    private int dfs(int r, int c) {
        if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] == 0) return 0;
        int fish = grid[r][c];
        grid[r][c] = 0; // 标记已访问
        return fish + dfs(r + 1, c) + dfs(r - 1, c) + dfs(r, c + 1) + dfs(r, c - 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)，递归栈

## 关键点总结

1. DFS 求连通水域的鱼数总和，直接将格子置 0 标记已访问
2. 枚举所有水域格作为起点，取最大值
