## 题目描述

设计一个跳表（Skiplist），支持 search、add、erase 操作。跳表是一种可以在 O(log n) 期望时间内完成搜索、插入和删除的数据结构。

**示例：**
```
Skiplist skiplist = new Skiplist();
skiplist.add(1);
skiplist.add(2);
skiplist.add(3);
skiplist.search(0); // false
skiplist.add(4);
skiplist.search(1); // true
skiplist.erase(0);  // false
skiplist.erase(1);  // true
skiplist.search(1); // false
```

## 解题思路

跳表是多层链表结构，底层包含所有元素，每层是下层的子集。通过随机化决定元素提升到哪一层，实现期望 O(log n) 的操作。

## Java 代码实现

```java
class Skiplist {
    private static final int MAX_LEVEL = 16;
    private static final double P = 0.5;
    private Node head;
    private Random random;
    
    // 跳表节点
    private static class Node {
        int val;
        Node[] next; // 每层的下一个节点
        
        Node(int val, int level) {
            this.val = val;
            this.next = new Node[level + 1];
        }
    }
    
    public Skiplist() {
        head = new Node(-1, MAX_LEVEL);
        random = new Random();
    }
    
    // 随机生成层数
    private int randomLevel() {
        int level = 0;
        while (level < MAX_LEVEL && random.nextDouble() < P) {
            level++;
        }
        return level;
    }
    
    public boolean search(int target) {
        Node curr = head;
        // 从最高层开始向下搜索
        for (int i = MAX_LEVEL; i >= 0; i--) {
            while (curr.next[i] != null && curr.next[i].val < target) {
                curr = curr.next[i];
            }
            if (curr.next[i] != null && curr.next[i].val == target) {
                return true;
            }
        }
        return false;
    }
    
    public void add(int num) {
        Node[] update = new Node[MAX_LEVEL + 1];
        Node curr = head;
        // 找到每层的插入位置
        for (int i = MAX_LEVEL; i >= 0; i--) {
            while (curr.next[i] != null && curr.next[i].val < num) {
                curr = curr.next[i];
            }
            update[i] = curr;
        }
        int level = randomLevel();
        Node newNode = new Node(num, level);
        // 在每层插入新节点
        for (int i = 0; i <= level; i++) {
            newNode.next[i] = update[i].next[i];
            update[i].next[i] = newNode;
        }
    }
    
    public boolean erase(int num) {
        Node[] update = new Node[MAX_LEVEL + 1];
        Node curr = head;
        boolean found = false;
        // 找到每层中目标节点的前驱
        for (int i = MAX_LEVEL; i >= 0; i--) {
            while (curr.next[i] != null && curr.next[i].val < num) {
                curr = curr.next[i];
            }
            if (curr.next[i] != null && curr.next[i].val == num) {
                found = true;
            }
            update[i] = curr;
        }
        if (!found) return false;
        // 删除目标节点（只删除一个）
        Node target = update[0].next[0];
        for (int i = 0; i < target.next.length; i++) {
            update[i].next[i] = target.next[i];
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：期望 O(log n)（搜索、插入、删除）
- **空间复杂度**：期望 O(n)

## 关键点总结

1. **多层链表**：高层是低层的快速通道，加速搜索
2. **随机化层数**：每次插入以概率 p 决定是否提升，期望高度 O(log n)
3. **update 数组**：记录每层待修改的前驱节点
4. **从高层到低层**：搜索时从最高层开始逐层下降
