## 题目描述

给你整数数组 `nums` 和整数 `k`、`x`，对每个长度为 `k` 的子数组，返回出现次数最多的 `x` 种数字的 `出现次数 * 数字值` 之和（同频取数值大的）。

## 解题思路

数据范围小（n <= 50），暴力枚举每个长度为 k 的子数组，用 HashMap 统计频率，按 (频率降序, 数值降序) 排序取前 x 个计算 x-sum。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] findXSum(int[] nums, int k, int x) {
        int n = nums.length;
        int[] result = new int[n - k + 1];
        for (int i = 0; i <= n - k; i++) {
            Map<Integer, Integer> freq = new HashMap<>();
            // 统计窗口内每个数的频率
            for (int j = i; j < i + k; j++) freq.merge(nums[j], 1, Integer::sum);
            // 按 (频率降序, 数值降序) 排序，取前 x 个
            List<int[]> list = new ArrayList<>();
            for (var e : freq.entrySet()) list.add(new int[]{e.getKey(), e.getValue()});
            list.sort((a, b) -> a[1] != b[1] ? b[1] - a[1] : b[0] - a[0]);
            int sum = 0;
            for (int j = 0; j < Math.min(x, list.size()); j++)
                sum += list.get(j)[0] * list.get(j)[1];
            result[i] = sum;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k log k)，每个子数组统计并排序
- 空间复杂度：O(k)

## 关键点总结

1. x-sum 是出现次数 top-x 的数字的 `出现次数 * 数值` 之和
2. 排序键：先按频率降序，频率相同时按数值降序
3. 数据范围小（n <= 50），暴力枚举简单可靠
