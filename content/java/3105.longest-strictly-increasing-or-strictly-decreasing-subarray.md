## 题目描述

给你整数数组 `nums`，返回最长严格递增或严格递减子数组的长度。

## 解题思路

一次扫描同时维护以当前位置结尾的最长递增长度 `inc` 和最长递减长度 `dec`，根据相邻元素关系更新，实时记录最大值。

## Java 代码实现

```java
class Solution {
    public int longestMonotonicSubarray(int[] nums) {
        int ans = 1, inc = 1, dec = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) { inc++; dec = 1; }
            else if (nums[i] < nums[i - 1]) { dec++; inc = 1; }
            else { inc = 1; dec = 1; }
            ans = Math.max(ans, Math.max(inc, dec));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 同时维护递增和递减两个连续长度
2. 相邻相等时两者都重置为 1
