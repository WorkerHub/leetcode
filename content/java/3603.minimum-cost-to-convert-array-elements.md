## 题目描述

给定整数数组 `nums` 和整数 `x`、`y`，每次操作可将某元素 +1/-1（费用 1），或全局所有元素 +1（费用 x）/ -1（费用 y），求使所有元素相等的最小总费用。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minCost(int[] nums, int x, int y) {
        Arrays.sort(nums);
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        long ans = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            long t = nums[i];
            // 小于 t 的元素需增加，逐个操作费用为 t * i - prefix[i]
            long costUp = t * i - prefix[i];
            // 大于 t 的元素需减少，逐个操作费用为 (prefix[n] - prefix[i+1]) - t * (n-i-1)
            long costDown = (prefix[n] - prefix[i + 1]) - t * (n - i - 1);
            ans = Math.min(ans, costUp + costDown);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主要开销
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 最优目标值一定在数组元素中（排序后中间值附近最优）
2. 前缀和快速计算左侧增加费用和右侧减少费用
3. 用 `long` 防止费用累加溢出
