## 题目描述

给定整数数组 `nums`，子数组的交替和定义为从下标 i 起按正负交替加减各元素，返回所有非空子数组交替和的最大值。

## 解题思路

DP 维护两个状态：`odd`（当前元素符号为正的最大交替和）和 `even`（当前元素符号为负的最大交替和），逐步滚动更新取最大值。

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public long maximumAlternatingSubarraySum(int[] nums) {
        long odd = nums[0];   // 当前元素符号为正时的最大交替和
        long even = -nums[0]; // 当前元素符号为负时的最大交替和
        long ans = nums[0];

        for (int i = 1; i < nums.length; i++) {
            long newOdd = Math.max(nums[i], even + nums[i]); // 新开始或接在负号之后
            long newEven = odd - nums[i];                     // 必须接在正号之后
            ans = Math.max(ans, newOdd);
            odd = newOdd;
            even = newEven;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 子数组交替和总以正号开始，答案取所有 odd 状态的最大值
2. `odd` 转移：单独开始 `nums[i]` 或接在负号位置之后 `even + nums[i]`
3. `even` 转移：必须接在正号位置之后 `odd - nums[i]`
