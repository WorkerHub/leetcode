## 题目描述

给你长度为 n 的非负整数数组 `nums`，对每个 i 返回从 `nums[i]` 开始、能达到最大按位 OR 值的最短子数组的长度。

## 解题思路

从右往左处理：对每一位（共 30 位），记录该位在当前位置右侧最后一次出现 1 的位置。位置 i 的答案 = 所有有效位中最远出现位置 - i + 1。

## Java 代码实现

```java
class Solution {
    public int[] smallestSubarrays(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        int[] last = new int[30]; // last[bit] = 该位最后出现 1 的位置

        for (int i = n - 1; i >= 0; i--) {
            // 更新每一位最后出现的位置
            for (int bit = 0; bit < 30; bit++) {
                if ((nums[i] >> bit & 1) == 1) last[bit] = i;
            }
            // 子数组至少延伸到所有必要位的最远位置
            int farthest = i;
            for (int bit = 0; bit < 30; bit++) {
                farthest = Math.max(farthest, last[bit]);
            }
            ans[i] = farthest - i + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 30) = O(n)
- **空间复杂度**：O(30) = O(1)

## 关键点总结

1. OR 操作只增不减，最大 OR 值就是包含全部后缀的 OR。
2. 对每一位独立追踪其最后出现位置，子数组需延伸到所有必要位的最远处。
3. `last` 数组初始化为 0，若某位在 i 之后从未出现则无需延伸（last[bit]=0 不影响 max）。
