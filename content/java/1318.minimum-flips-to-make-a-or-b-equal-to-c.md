## 题目描述

给你三个正整数 `a`、`b` 和 `c`。

你可以对 `a` 和 `b` 的二进制表示进行位翻转操作，返回能够使按位或运算 `a OR b == c` 成立的**最小翻转次数**。

「位翻转操作」是指将一个数的二进制位中的 `0` 变成 `1` 或者将 `1` 变成 `0`。

**示例 1：**

```
输入：a = 2, b = 6, c = 5
输出：3
```

**示例 2：**

```
输入：a = 4, b = 2, c = 7
输出：1
```

**示例 3：**

```
输入：a = 1, b = 2, c = 3
输出：0
```

**提示：**

- `1 <= a <= 10^9`
- `1 <= b <= 10^9`
- `1 <= c <= 10^9`

## 解题思路

**逐位分析**

对于每一位，独立分析 `a`、`b`、`c` 对应的比特位，分三种情况：

**情况 1：c 的该位为 1**
- 需要 `a OR b = 1`，即 a 或 b 中至少有一个为 1
- 若 `a=0, b=0`：需要翻转 1 次（将 a 或 b 任意一个翻成 1）
- 若 `a=1, b=0` 或 `a=0, b=1` 或 `a=1, b=1`：不需要翻转

**情况 2：c 的该位为 0**
- 需要 `a OR b = 0`，即 a 和 b 都必须为 0
- 若 `a=0, b=0`：不需要翻转
- 若 `a=1, b=0` 或 `a=0, b=1`：需要翻转 1 次
- 若 `a=1, b=1`：需要翻转 2 次

## Java 代码实现

### 方法一：逐位枚举（推荐）

```java
class Solution {
    public int minFlips(int a, int b, int c) {
        int flips = 0;
        
        // 枚举每一位（最多30位，因为 a,b,c <= 10^9 < 2^30）
        for (int i = 0; i < 30; i++) {
            int bitA = (a >> i) & 1; // a 的第 i 位
            int bitB = (b >> i) & 1; // b 的第 i 位
            int bitC = (c >> i) & 1; // c 的第 i 位
            
            if (bitC == 1) {
                // c 该位为 1，a OR b 需为 1
                // 只有当 a=0 且 b=0 时才需要翻转 1 次
                if (bitA == 0 && bitB == 0) {
                    flips += 1;
                }
            } else {
                // c 该位为 0，a OR b 需为 0，即 a 和 b 都需为 0
                // a 有几个 1，b 有几个 1，就需要翻转几次
                flips += bitA + bitB;
            }
        }
        
        return flips;
    }
}
```

### 方法二：位运算一次性计算（高效）

```java
class Solution {
    public int minFlips(int a, int b, int c) {
        // c=1, a=0, b=0 的位：需要翻1次
        // ~(a|b) & c 表示 a OR b 为 0 但 c 为 1 的位
        int needOne = ~(a | b) & c;
        
        // c=0 时需要将 a 和 b 的 1 全部翻成 0
        int flipA = ~c & a; // c=0 但 a=1，需翻 a
        int flipB = ~c & b; // c=0 但 b=1，需翻 b
        
        // 统计各自的 1 的个数
        return Integer.bitCount(needOne) + Integer.bitCount(flipA) + Integer.bitCount(flipB);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log max(a, b, c))，即最多处理 30 位
- **空间复杂度**：O(1)

## 图解示例

以 `a=2, b=6, c=5` 为例：

```
位编号: 2  1  0
a    : 0  1  0
b    : 1  1  0
c    : 1  0  1

位0: c=1, a=0, b=0 -> 需翻1次（a或b翻成1）
位1: c=0, a=1, b=1 -> 需翻2次（a翻成0，b翻成0）
位2: c=1, a=0, b=1 -> 不需翻（b=1已满足OR=1）

总计: 1 + 2 + 0 = 3
```

## 关键点总结

1. 对每一位独立分析，各位互不影响
2. `c=1` 时：a 和 b 同时为 0 才需要翻 1 次
3. `c=0` 时：a 有多少个 1 翻多少次，b 有多少个 1 翻多少次
4. Java 中 `Integer.bitCount(x)` 可以统计二进制中 1 的个数

## 易错点

1. **c=0 时 a=1, b=1 需要翻 2 次**：两个都要翻，不能只翻一个
2. **Java 中 `~x` 是有符号取反**：与 Python 不同，Java 中整数是 32 位有符号数，不需要额外的掩码
3. **枚举位数要足够**：a, b, c 最大 10^9 < 2^30，枚举 30 位即可

## 学习建议

1. 先掌握基本位运算：`&`（与）、`|`（或）、`^`（异或）、`~`（取反）、`>>`（右移）
2. 理解"逐位分析"的思路：对于与位相关的问题，按位独立处理通常是正确方向
3. 方法一（逐位枚举）是最容易理解的，建议先掌握；方法二是优化版本
4. Java 中使用 `Integer.bitCount()` 统计 1 的个数比手动计数更简洁
