## 题目描述

对数组每个元素最多执行一次操作：减去一个严格小于该元素的质数，判断是否能使数组变为严格递增序列。

## 解题思路

**贪心 + 二分查找**：从左到右遍历，对每个元素 `nums[i]` 找最大质数 `p < nums[i] - prev`，使处理后的值尽量小（给后续元素留余地）。预先用埃拉托斯特尼筛法筛出所有 1000 以内的质数，用二分查找找最大合法质数。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public boolean primeSubOperation(int[] nums) {
        // 筛法预处理质数
        boolean[] sieve = new boolean[1001];
        Arrays.fill(sieve, true);
        sieve[0] = sieve[1] = false;
        for (int i = 2; i * i <= 1000; i++) {
            if (sieve[i]) {
                for (int j = i * i; j <= 1000; j += i) sieve[j] = false;
            }
        }
        List<Integer> primes = new ArrayList<>();
        for (int i = 2; i <= 1000; i++) {
            if (sieve[i]) primes.add(i);
        }

        int prev = 0; // 上一个处理后的值
        for (int num : nums) {
            int diff = num - prev;
            if (diff <= 0) return false; // 即使不减也无法大于 prev
            // 二分查找：严格小于 diff 的最大质数
            int lo = 0, hi = primes.size() - 1, idx = -1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (primes.get(mid) < diff) {
                    idx = mid;
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            prev = (idx >= 0) ? num - primes.get(idx) : num;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log P)，P 为质数个数（约 168 个）
- 空间复杂度：O(P)

## 关键点总结

1. 贪心：每次减去尽可能大的质数，使当前值尽量小
2. 关键约束：p < nums[i] 且 nums[i] - p > prev
3. 若 diff <= 0，直接返回 false
