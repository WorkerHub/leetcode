## 题目描述

给定正整数数组 nums，找出满足条件的最长前缀长度：从前缀中恰好删除一个元素后，剩下每个数字的出现次数都相同。

**示例：**
```
输入：nums = [2,2,1,1,5,3,3,5]
输出：7（删除 nums[4]=5 后得到 [2,2,1,1,3,3]，每个数出现 2 次）
```

## 解题思路

维护三个信息：freq[num] 数字出现次数、freqCount[f] 某频率对应的数字个数、maxFreq 最大频率。遍历时判断是否满足删除一个元素后所有频率相等。

## Java 代码实现

```java
class Solution {
    public int maxEqualFreq(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();       // 数字 → 出现次数
        Map<Integer, Integer> freqCount = new HashMap<>();  // 频率 → 对应数字个数
        int maxFreq = 0, result = 0;
        
        for (int i = 0; i < nums.length; i++) {
            int num = nums[i];
            // 更新频率
            int oldF = freq.getOrDefault(num, 0);
            int newF = oldF + 1;
            freq.put(num, newF);
            
            // 更新 freqCount
            if (oldF > 0) {
                freqCount.put(oldF, freqCount.get(oldF) - 1);
                if (freqCount.get(oldF) == 0) freqCount.remove(oldF);
            }
            freqCount.merge(newF, 1, Integer::sum);
            maxFreq = Math.max(maxFreq, newF);
            
            int len = i + 1;
            int uniqueCount = freq.size(); // 不同数字个数
            
            // 判断是否满足条件
            // 情况1：所有数字频率为1（删任意一个）
            if (maxFreq == 1) { result = len; continue; }
            // 情况2：只有一种数字（删一个）
            if (uniqueCount == 1) { result = len; continue; }
            // 情况3：所有数字频率相同且 频率*个数 == len-1（删一个频率为1的数字）
            if (freqCount.containsKey(maxFreq) && freqCount.get(maxFreq) * maxFreq == len - 1
                && freqCount.getOrDefault(1, 0) == 1) { result = len; continue; }
            // 情况4：所有数字频率为 maxFreq-1，只有一个为 maxFreq（删那个多出的一次）
            if (freqCount.containsKey(maxFreq) && freqCount.get(maxFreq) == 1
                && freqCount.getOrDefault(maxFreq - 1, 0) == uniqueCount - 1
                && (maxFreq - 1) * (uniqueCount - 1) + maxFreq == len) { result = len; continue; }
            // 情况5：所有数字频率都是 maxFreq，总数 == len-1（有一个多余的频率为1）
            if (freqCount.containsKey(maxFreq) && freqCount.get(maxFreq) == uniqueCount
                && maxFreq * uniqueCount == len - 1) { result = len; continue; }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **三种哈希表**：数字频率、频率计数、最大频率
2. **多种合法情况**：需要逐一分析删除一个元素后的状态
3. **边界情况**：全是相同数字、全频率为 1、只有一个多出来的
4. **在线处理**：遍历一次即可确定每个前缀是否合法
