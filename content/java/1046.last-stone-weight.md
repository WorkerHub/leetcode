## 题目描述

每回合选两块最重石头粉碎，x==y 则都碎，否则剩 y-x。返回最后剩余石头重量，无则返回 0。

**示例：**
```
输入：stones = [2,7,4,1,8,1]
输出：1
```

## 解题思路

最大堆：每次取出两个最大值粉碎。Java 的 PriorityQueue 默认最小堆，用 Collections.reverseOrder() 改为最大堆。

## Java 代码实现

```java
class Solution {
    public int lastStoneWeight(int[] stones) {
        // 最大堆
        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
        for (int s : stones) {
            pq.offer(s);
        }

        while (pq.size() > 1) {
            int first = pq.poll();  // 最重
            int second = pq.poll(); // 第二重
            if (first != second) {
                pq.offer(first - second);
            }
        }

        return pq.isEmpty() ? 0 : pq.poll();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **最大堆**：快速获取最大的两个元素
2. **Java PriorityQueue**：默认最小堆，需 reverseOrder 变最大堆
3. **终止条件**：堆中元素 ≤ 1 时停止
