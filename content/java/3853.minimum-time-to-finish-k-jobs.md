## 题目描述

给你一个整数数组 `jobs`（长度 n <= 12）和一个整数 `k`（工人数），返回分配所有任务给 k 名工人后，最大工作时间的最小值。

## 解题思路

状态压缩 DP：预计算每个子集的和，`dp[mask]` 表示用最少工人完成 mask 中任务时的最小最大时间。枚举 k 次工人，每次枚举 mask 的子集分配给当前工人。

## Java 代码实现

```java
class Solution {
    public int minimumTimeRequired(int[] jobs, int k) {
        int n = jobs.length;
        int full = (1 << n) - 1;

        // 预计算每个子集的任务总时间
        int[] subsetSum = new int[full + 1];
        for (int mask = 1; mask <= full; mask++) {
            int lsb = mask & (-mask);
            int bit = Integer.numberOfTrailingZeros(lsb);
            subsetSum[mask] = subsetSum[mask ^ lsb] + jobs[bit];
        }

        // dp[mask] = 完成 mask 中任务所需最小最大工作时间（初始1个工人）
        int[] dp = subsetSum.clone();

        for (int worker = 1; worker < k; worker++) {
            int[] newDp = new int[full + 1];
            for (int mask = 0; mask <= full; mask++) {
                newDp[mask] = dp[mask]; // 当前工人不分配任何任务
                // 枚举分配给当前工人的子集
                for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
                    newDp[mask] = Math.min(newDp[mask],
                        Math.max(dp[mask ^ sub], subsetSum[sub]));
                }
            }
            dp = newDp;
        }

        return dp[full];
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * 3^n)，枚举子集的子集
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 12 是状态压缩 DP 的标志，`3^12` 约 53 万次操作可接受。
2. 子集枚举 `sub = (sub - 1) & mask` 是经典技巧，遍历 mask 的所有非空子集。
3. 初始化：1 名工人时 `dp[mask] = subsetSum[mask]`。
