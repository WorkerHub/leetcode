## 题目描述

给你整数 `n` 和长度为 `2^n` 的数组 `sums`（某未知数组所有子集和，含空集 0），还原并返回原数组（可含负数）。

## 解题思路

分治：排序后取 `d = sums[1] - sums[0]` 为候选元素。将 sums 分为两组：group0（不含 d 贡献）和 group1 = group0 + d（含 d 贡献）。最小值 `sums[0]` 必在 group0，递归处理 group0，每层追加一个元素 d。

## Java 代码实现

### 方法一：分治递归（推荐）

```java
import java.util.*;

class Solution {
    public int[] recoverArray(int n, int[] sums) {
        Arrays.sort(sums);
        List<Integer> sumList = new ArrayList<>();
        for (int s : sums) sumList.add(s);
        List<Integer> result = solve(sumList);
        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private List<Integer> solve(List<Integer> arr) {
        if (arr.size() == 1) {
            // 仅剩空集对应的0，返回空
            return new ArrayList<>();
        }

        // arr已排序，候选差值
        int d = arr.get(1) - arr.get(0);

        // 将arr分为两组：group0不含d贡献，group1 = group0 + d
        Map<Integer, Integer> used = new HashMap<>();
        List<Integer> group0 = new ArrayList<>();

        for (int v : arr) {
            int useCount = used.getOrDefault(v, 0);
            if (useCount > 0) {
                // 该元素已被配对到group1，跳过
                used.put(v, useCount - 1);
                continue;
            }
            group0.add(v);
            // 将 v+d 标记为已被group1占用
            used.merge(v + d, 1, Integer::sum);
        }

        // 递归处理group0，追加当前候选元素d
        List<Integer> res = solve(group0);
        res.add(d);
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 每次取最小的差值 `d` 作为候选元素，将 sums 分为含 d 和不含 d 两半
2. 最小值 `sums[0]` 一定在不含 d 的组
3. 递归处理一半直到剩余 1 个元素（空集对应的 0）
