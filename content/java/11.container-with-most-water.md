## 题目描述

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂直线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**示例 1：**
```
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
```

**示例 2：**
```
输入：height = [1,1]
输出：1
```

## 解题思路

### 双指针（推荐）

**核心思想：**
- 容器的面积 = 两条线之间的距离 * 较短线的高度
- 公式：`area = (right - left) * min(height[left], height[right])`

**双指针策略：**
1. 初始化：左指针在最左边，右指针在最右边（宽度最大）
2. 每次移动较矮的那一边的指针
3. 因为移动较高的边，面积一定减小；移动较矮的边，面积有可能增大

## Java 代码实现

### 方法一：双指针（推荐）

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int maxArea = 0;
        
        while (left < right) {
            // 计算当前面积
            int width = right - left;
            int currentHeight = Math.min(height[left], height[right]);
            int currentArea = width * currentHeight;
            
            // 更新最大面积
            maxArea = Math.max(maxArea, currentArea);
            
            // 移动较矮的那一边
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        
        return maxArea;
    }
}
```

### 方法二：暴力法（仅供理解）

```java
class Solution {
    public int maxArea(int[] height) {
        int maxArea = 0;
        int n = height.length;
        
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int area = (j - i) * Math.min(height[i], height[j]);
                maxArea = Math.max(maxArea, area);
            }
        }
        
        return maxArea;
    }
}
```

## 复杂度分析

### 双指针方法
- **时间复杂度**：O(n)，只需遍历一次数组
- **空间复杂度**：O(1)

### 暴力法
- **时间复杂度**：O(n^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **面积公式**：`面积 = 宽度 * min(左高度, 右高度)`
2. **双指针策略**：始终移动较矮的那一边
3. **贪心思想**：从最大宽度开始，寻找可能更高的高度
4. **正确性证明**：移动较高的边不可能得到更大面积

## 易错点

1. **移动哪个指针**：应该移动较矮的指针
2. **高度计算**：要取两边高度的最小值（木桶效应）
3. **边界条件**：`left < right` 而不是 `left <= right`
