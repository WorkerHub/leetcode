## 题目描述

给你二叉树根节点 `root` 和整数 `k`，若某节点的值大于子树中至少 k 个其他节点的值，则该节点"足够大"，返回足够大的节点数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    int k, ans;

    public int countGreatEnoughNodes(TreeNode root, int k) {
        this.k = k;
        this.ans = 0;
        dfs(root);
        return ans;
    }

    // 返回子树中最大的 k 个值（小根堆）
    PriorityQueue<Integer> dfs(TreeNode node) {
        if (node == null) return new PriorityQueue<>();
        PriorityQueue<Integer> left = dfs(node.left);
        PriorityQueue<Integer> right = dfs(node.right);

        // 启发式合并：小堆并入大堆
        if (left.size() < right.size()) {
            PriorityQueue<Integer> tmp = left; left = right; right = tmp;
        }
        for (int v : right) {
            left.offer(v);
            if (left.size() > k) left.poll(); // 保留最大的 k 个
        }

        // 加入当前节点
        left.offer(node.val);
        if (left.size() > k) left.poll();

        // 若堆满 k 个且当前节点值 > 堆中最小值，则足够大
        if (left.size() == k && node.val > left.peek()) ans++;
        return left;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log k)
- 空间复杂度：O(n + k)

## 关键点总结

1. 小根堆保留子树中最大的 k 个值
2. 若堆已满且 node.val > 堆顶（第 k 大），则该节点值大于至少 k 个其他节点
3. 启发式合并（小堆并入大堆）降低常数
