## 题目描述

n 个石子在数轴上，每次移动端点石子到非端点空位。求使石子连续的最小和最大移动次数。

**示例：**
```
输入：stones = [7,4,9]
输出：[1,2]
```

## 解题思路

排序后：最大移动 = max(stones[n-1]-stones[1], stones[n-2]-stones[0]) - (n-2)；最小移动用滑动窗口找长度≤n的区间内石子最多的情况，特殊处理 n-1 个连续石子的情况。

## Java 代码实现

```java
class Solution {
    public int[] numMovesStonesII(int[] stones) {
        Arrays.sort(stones);
        int n = stones.length;

        // 最大移动次数
        int maxMoves = Math.max(stones[n - 1] - stones[1] - n + 2,
                                stones[n - 2] - stones[0] - n + 2);

        // 最小移动次数 - 滑动窗口
        int minMoves = n;
        int left = 0;

        for (int right = 0; right < n; right++) {
            // 保持窗口范围 <= n
            while (stones[right] - stones[left] + 1 > n) {
                left++;
            }

            int count = right - left + 1;

            // 特殊情况：n-1 个石子占据连续 n-1 个位置
            if (count == n - 1 && stones[right] - stones[left] + 1 == n - 1) {
                minMoves = Math.min(minMoves, 2);
            } else {
                minMoves = Math.min(minMoves, n - count);
            }
        }

        return new int[]{minMoves, maxMoves};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序主导
- **空间复杂度**：O(1)

## 关键点总结

1. **最大移动贪心**：固定一端 n-1 个石子，移动另一端
2. **最小移动滑动窗口**：找长度≤n的区间内石子最多
3. **特殊情况**：n-1 个连续位置需要 2 次移动
