## 题目描述

给你一个元素为 1 或 -1 的整数数组 `coins` 和目标和 `target`，每次可以翻转任意一枚硬币（1 变 -1 或反之），返回使所有硬币之和等于 `target` 的最少翻转次数，无法达到则返回 -1。

## 解题思路

设正数个数为 p，负数个数为 q，当前和为 p-q。差值 `d = target - (p-q)` 必须为偶数（每次翻转改变 2）；d>0 时翻转 d/2 个 -1 为 1，d<0 时翻转 |d|/2 个 1 为 -1，检查可用数量是否足够。

## Java 代码实现

```java
class Solution {
    public int minFlips(int[] coins, int target) {
        int p = 0;
        // 统计正数个数
        for (int c : coins) {
            if (c == 1) p++;
        }
        int q = coins.length - p;
        int currentSum = p - q;

        int diff = target - currentSum;
        // 差值为奇数时无解
        if (diff % 2 != 0) return -1;

        int flips = diff / 2;
        if (flips > 0) {
            // 需要将 flips 个 -1 翻转为 1
            return flips <= q ? flips : -1;
        } else {
            // 需要将 |flips| 个 1 翻转为 -1
            return -flips <= p ? -flips : -1;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，统计正负数个数
- 空间复杂度：O(1)

## 关键点总结

1. 每次翻转使总和改变 2，因此差值必须为偶数。
2. 增大总和：翻转 -1 为 1；减小总和：翻转 1 为 -1。
3. 最少翻转次数 = `|diff| / 2`，其中 diff 为目标与当前总和之差。
