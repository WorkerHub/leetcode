## 题目描述

Alice 和 Bob 轮流取石头（Alice 先），每块石头对 Alice 和 Bob 各有价值 `aliceValues[i]` 和 `bobValues[i]`。双方都足够聪明，各自最优策略下，返回结果（Alice赢返回1，平局返回0，Bob赢返回-1）。

## 解题思路

**贪心：** 选一块石头的"综合价值"= 自己获得 + 阻止对方获得 = `aliceValues[i] + bobValues[i]`。按此降序排序，Alice 取偶数下标、Bob 取奇数下标。

## Java 代码实现

```java
class Solution {
    public int stoneGameVI(int[] aliceValues, int[] bobValues) {
        int n = aliceValues.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        // 按综合价值降序排序
        Arrays.sort(idx, (a, b) -> (bobValues[b] + aliceValues[b]) - (bobValues[a] + aliceValues[a]));

        int aliceScore = 0, bobScore = 0;
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) aliceScore += aliceValues[idx[i]]; // Alice 先手
            else bobScore += bobValues[idx[i]];
        }

        return Integer.compare(aliceScore, bobScore);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序依据是 `aliceValues[i] + bobValues[i]`（综合价值）
2. Alice 取偶数轮（0, 2, 4...），Bob 取奇数轮
3. `Integer.compare()` 直接返回 -1/0/1
