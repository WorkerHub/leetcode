## 题目描述

将字符串 s 分成 k 个非空子串，可修改字符使每个子串都是回文串。求最少修改字符数。

**示例：**
```
输入：s = "abc", k = 2
输出：1
解释：分为 "ab" 和 "c"，改 "ab" 为 "aa"，修改 1 次
```

## 解题思路

1. 预处理 cost[i][j] = 将 s[i..j] 变为回文的最少修改次数
2. DP：dp[i][j] = 前 i 个字符分成 j 段的最少修改次数

## Java 代码实现

```java
class Solution {
    public int palindromePartition(String s, int k) {
        int n = s.length();
        
        // 预处理：cost[i][j] = s[i..j] 变回文的最少修改次数
        int[][] cost = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                cost[i][j] = cost[i+1][j-1] + (s.charAt(i) != s.charAt(j) ? 1 : 0);
            }
        }
        
        // dp[i][j] = 前 i 个字符分成 j 段的最少修改次数
        int[][] dp = new int[n + 1][k + 1];
        for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE);
        dp[0][0] = 0;
        
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= Math.min(i, k); j++) {
                // 最后一段是 s[l..i-1]
                for (int l = j - 1; l < i; l++) {
                    if (dp[l][j-1] != Integer.MAX_VALUE) {
                        dp[i][j] = Math.min(dp[i][j], dp[l][j-1] + cost[l][i-1]);
                    }
                }
            }
        }
        return dp[n][k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n² + n × k)

## 关键点总结

1. **预处理回文代价**：区间 DP 计算 cost[i][j]
2. **分段 DP**：经典的"分成 k 段"模式
3. **转移**：枚举最后一段的起点
4. **双端配对**：回文代价从两端向中间配对计算
