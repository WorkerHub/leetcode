## 题目描述

给定整数数组 `nums` 和整数 `k`，在所有长度恰好为 `k` 的子数组中，返回最大值与最小值之差的最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumDifference(int[] nums, int k) {
        if (k == 1) return 0;
        int n = nums.length;
        Deque<Integer> maxDq = new ArrayDeque<>(); // 单调递减，维护最大值
        Deque<Integer> minDq = new ArrayDeque<>(); // 单调递增，维护最小值
        int ans = Integer.MAX_VALUE;

        for (int i = 0; i < n; i++) {
            while (!maxDq.isEmpty() && nums[maxDq.peekLast()] <= nums[i]) maxDq.pollLast();
            maxDq.addLast(i);
            while (!minDq.isEmpty() && nums[minDq.peekLast()] >= nums[i]) minDq.pollLast();
            minDq.addLast(i);

            if (i >= k - 1) {
                // 移除过期元素（左端为 i-k+1）
                while (maxDq.peekFirst() < i - k + 1) maxDq.pollFirst();
                while (minDq.peekFirst() < i - k + 1) minDq.pollFirst();
                ans = Math.min(ans, nums[maxDq.peekFirst()] - nums[minDq.peekFirst()]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)

## 关键点总结

1. 双单调队列：递减队列维护窗口最大值，递增队列维护最小值
2. 过期元素下标 < i-k+1 时从队首移除
3. k=1 时差值恒为 0，直接返回
