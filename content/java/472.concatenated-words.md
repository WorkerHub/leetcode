## 题目描述

给你一个不含重复单词的字符串数组 `words`，请你找出并返回 `words` 中的所有 **连接词**。

**连接词** 定义为：一个完全由给定数组中的至少两个较短单词组成的字符串。

**示例 1：**
```
输入：words = ["cat","cats","catsdogcats","dog","dogcatsdog","hippopotamuses","rat","ratcatdogcat"]
输出：["catsdogcats","dogcatsdog","ratcatdogcat"]
解释："catsdogcats" 由 "cats", "dog" 和 "cats" 组成; 
     "dogcatsdog" 由 "dog", "cats" 和 "dog" 组成; 
     "ratcatdogcat" 由 "rat", "cat", "dog" 和 "cat" 组成。
```

**示例 2：**
```
输入：words = ["cat","dog","catdog"]
输出：["catdog"]
```

**提示：**
- `1 <= words.length <= 10^4`
- `1 <= words[i].length <= 30`
- `words[i]` 仅由小写英文字母组成
- `words` 中所有字符串都是唯一的
- `1 <= sum(words[i].length) <= 10^5`

## 解题思路

这是一道**动态规划 + 字典查找**的组合题。

**核心思想：**
1. 对每个单词，检查它是否可以由其他单词拼接而成
2. 使用 DP 判断单词是否可拆分
3. 需要至少两个单词组成（不能是自己）

**算法流程：**
1. 将所有单词加入集合（快速查找）
2. 按长度排序（短的先处理）
3. 对每个单词使用 DP 检查是否可拆分
4. DP：`dp[i]` 表示 `word[:i]` 是否可由其他单词组成

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<String> findAllConcatenatedWordsInADict(String[] words) {
        Set<String> wordSet = new HashSet<>(Arrays.asList(words));
        List<String> result = new ArrayList<>();

        for (String word : words) {
            if (canForm(word, wordSet)) {
                result.add(word);
            }
        }

        return result;
    }

    // 判断 word 是否可以由字典中的其他单词组成
    private boolean canForm(String word, Set<String> wordSet) {
        if (word.isEmpty()) return false;

        int n = word.length();
        // dp[i] 表示 word 前 i 个字符是否可以由字典中的单词组成
        boolean[] dp = new boolean[n + 1];
        dp[0] = true; // 空字符串

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j]) {
                    String substr = word.substring(j, i);
                    // 不能是单词本身
                    if (wordSet.contains(substr) && !substr.equals(word)) {
                        dp[i] = true;
                        break;
                    }
                }
            }
        }

        return dp[n];
    }
}
```

### 方法二：DFS + 记忆化

```java
import java.util.*;

class Solution {
    public List<String> findAllConcatenatedWordsInADict(String[] words) {
        Set<String> wordSet = new HashSet<>(Arrays.asList(words));
        List<String> result = new ArrayList<>();

        for (String word : words) {
            Map<Integer, Boolean> memo = new HashMap<>();
            if (dfs(word, wordSet, memo, 0, 0)) {
                result.add(word);
            }
        }

        return result;
    }

    // start: 当前搜索起点；count: 已使用的单词数
    private boolean dfs(String word, Set<String> wordSet,
                        Map<Integer, Boolean> memo, int start, int count) {
        if (start == word.length()) {
            return count >= 2; // 至少两个单词
        }

        if (memo.containsKey(start)) return memo.get(start);

        for (int end = start + 1; end <= word.length(); end++) {
            String substr = word.substring(start, end);
            if (wordSet.contains(substr) && !substr.equals(word)) {
                if (dfs(word, wordSet, memo, end, count + 1)) {
                    memo.put(start, true);
                    return true;
                }
            }
        }

        memo.put(start, false);
        return false;
    }
}
```

### 方法三：优化版（按长度排序）

```java
import java.util.*;

class Solution {
    public List<String> findAllConcatenatedWordsInADict(String[] words) {
        // 按长度排序，短的先处理
        Arrays.sort(words, Comparator.comparingInt(String::length));
        Set<String> wordSet = new HashSet<>();
        List<String> result = new ArrayList<>();

        for (String word : words) {
            if (canForm(word, wordSet)) {
                result.add(word);
            }
            wordSet.add(word);
        }

        return result;
    }

    private boolean canForm(String word, Set<String> wordSet) {
        if (wordSet.isEmpty()) return false;

        int n = word.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && wordSet.contains(word.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }

        return dp[n];
    }
}
```

**优点：** 动态构建字典，避免自身匹配问题

## 复杂度分析

**方法一：**
- 时间复杂度：O(n × m^3)，n 是单词数，m 是平均长度
- 空间复杂度：O(n × m)

**方法三（优化）：**
- 时间复杂度：O(n log n + n × m^2)
- 空间复杂度：O(n × m)

## 关键点总结

1. **DP 状态：** `dp[i]` 表示前 i 个字符是否可拆分
2. **避免自身：** 不能用单词本身拼接
3. **至少两个：** 必须由至少两个单词组成
4. **集合查找：** 使用 HashSet 加速查找
5. **排序优化：** 按长度排序避免问题

## 易错点

1. **自身匹配：** 必须排除单词本身
   ```java
   if (!substr.equals(word) && wordSet.contains(substr))
   ```

2. **空字符串：** 初始化 `dp[0] = true`

3. **至少两个单词：** 检查计数
