## 题目描述

你有一个只支持单个标签页的**浏览器**，最开始你浏览的网页是 `homepage`，可以访问其他的网站 `url`，也可以在浏览历史中后退 `steps` 步或前进 `steps` 步。

请你实现 `BrowserHistory` 类：

- `BrowserHistory(string homepage)`：用 `homepage` 初始化浏览器类。
- `void visit(string url)`：从当前页跳转访问 `url` 对应的页面。执行此操作会把浏览历史前进部分全部删除。
- `string back(int steps)`：在浏览历史中后退 `steps` 步。如果你只能在历史中后退至多 `x` 步且 `steps > x`，那么你只后退 `x` 步。返回后退至多 `steps` 步以后的 `url`。
- `string forward(int steps)`：在浏览历史中前进 `steps` 步。如果你只能在历史中前进至多 `x` 步且 `steps > x`，那么你只前进 `x` 步。返回前进至多 `steps` 步以后的 `url`。

**示例：**

```
输入：
["BrowserHistory","visit","visit","visit","back","back","forward","visit","forward","back","back"]
[["leetcode.com"],["google.com"],["facebook.com"],["youtube.com"],[1],[1],[1],["linkedin.com"],[2],[2],[7]]
输出：
[null,null,null,null,"facebook.com","google.com","facebook.com",null,"linkedin.com","google.com","leetcode.com"]
```

**提示：**
- `1 <= homepage.length <= 20`
- `1 <= url.length <= 20`
- `1 <= steps <= 100`
- `homepage` 和 `url` 都只包含小写英文字母和 `.`
- 最多调用 `5000` 次 `visit`、`back` 和 `forward` 函数

## 解题思路

**核心思想：** 用一个列表（数组）存储历史记录，用一个指针 `cur` 记录当前位置，用 `end` 记录有效历史的末尾。

- `visit(url)`：将 `url` 插入 `cur+1` 位置，清除之后的历史，更新 `cur = cur + 1`。
- `back(steps)`：`cur = max(0, cur - steps)`，返回 `history[cur]`。
- `forward(steps)`：`cur = min(end, cur + steps)`，返回 `history[cur]`。

## Java 代码实现

### 方法一：列表 + 双指针（推荐，所有操作 O(1)）

```java
import java.util.ArrayList;
import java.util.List;

class BrowserHistory {
    private List<String> history;
    private int cur;  // 当前页面的指针
    private int end;  // 有效历史的末尾

    public BrowserHistory(String homepage) {
        history = new ArrayList<>();
        history.add(homepage);
        cur = 0;
        end = 0;
    }

    public void visit(String url) {
        cur++;
        // 如果当前位置超出列表范围，追加；否则覆盖
        if (cur < history.size()) {
            history.set(cur, url);
        } else {
            history.add(url);
        }
        end = cur;  // 更新有效末尾，截断后续历史
    }

    public String back(int steps) {
        // 后退 steps 步，但不能超过头部
        cur = Math.max(0, cur - steps);
        return history.get(cur);
    }

    public String forward(int steps) {
        // 前进 steps 步，但不能超过有效末尾
        cur = Math.min(end, cur + steps);
        return history.get(cur);
    }
}
```

### 方法二：双栈模拟（后退栈 + 前进栈）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class BrowserHistory {
    private Deque<String> backStack;    // 后退历史（当前页也在栈顶）
    private Deque<String> forwardStack; // 前进历史

    public BrowserHistory(String homepage) {
        backStack = new ArrayDeque<>();
        forwardStack = new ArrayDeque<>();
        backStack.push(homepage);
    }

    public void visit(String url) {
        backStack.push(url);    // 访问新页面，压入后退栈
        forwardStack.clear();   // 清空前进历史
    }

    public String back(int steps) {
        // 将当前页移到前进栈，直到后退了 steps 步或只剩一页
        while (steps > 0 && backStack.size() > 1) {
            forwardStack.push(backStack.pop());
            steps--;
        }
        return backStack.peek();    // 返回后退后的当前页
    }

    public String forward(int steps) {
        // 将前进栈顶移到后退栈，直到前进了 steps 步或前进栈为空
        while (steps > 0 && !forwardStack.isEmpty()) {
            backStack.push(forwardStack.pop());
            steps--;
        }
        return backStack.peek();    // 返回前进后的当前页
    }
}
```

## 复杂度分析

| 方法 | visit | back | forward | 空间 |
|------|-------|------|---------|------|
| 列表+双指针 | O(1) | O(1) | O(1) | O(n) |
| 双栈 | O(1) | O(steps) | O(steps) | O(n) |

- 方法一（列表+双指针）是最优方案，所有操作均为 O(1)。
- 方法二双栈在步数较大时性能略差，但逻辑更直观。

## 关键点总结

1. 浏览器历史本质上是一个**带指针的线性结构**，`visit` 时截断后续历史。
2. 双栈模拟：后退栈保存历史，前进栈保存前进历史，`visit` 清空前进栈。
3. 最优方案（方法一）：用 `end` 指针标记有效历史末尾，`visit` 时原地覆盖，避免截断操作。
4. `back` 和 `forward` 要用 `Math.max`/`Math.min` 防止越界。

## 易错点

- **`visit` 时忘记清空前进历史**：访问新页面后，前进历史应该失效。
- **`back` 和 `forward` 越界**：要用 `Math.max(0, ...)` 和 `Math.min(end, ...)` 限制范围。
- **方法一中 `end` 的作用**：`end` 标记有效末尾，`forward` 不能超过 `end`。
