## 题目描述

给定一个无向图（n 个节点，m 条边），需要为每个节点分配一个 `1` 到 `n` 的唯一整数值（排列）。边的价值等于其两端节点值的乘积，图的总价值是所有边的价值之和。求最大化图的总价值所能得到的最大值。

## 解题思路

贪心策略：度数越大的节点应该分配越大的值，因为它参与更多的边乘积。按节点度数降序排列，分配从 n 到 1 的值，孤立节点分配小值不影响结果。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maximumValueSum(int n, int[][] edges) {
        // 计算每个节点的度数
        int[] degree = new int[n];
        for (int[] e : edges) {
            degree[e[0]]++;
            degree[e[1]]++;
        }

        // 按度数降序排列节点索引
        Integer[] nodes = new Integer[n];
        for (int i = 0; i < n; i++) nodes[i] = i;
        Arrays.sort(nodes, (a, b) -> degree[b] - degree[a]);

        // 分配值：度数最大的节点分配最大值 n
        int[] nodeVal = new int[n];
        for (int rank = 0; rank < n; rank++) {
            nodeVal[nodes[rank]] = n - rank;
        }

        // 计算总价值
        long total = 0;
        for (int[] e : edges) {
            total += (long) nodeVal[e[0]] * nodeVal[e[1]];
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n + m)，排序 + 计算
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：度数大的节点分配大的值，最大化参与多边的节点贡献
2. 孤立节点（无边）分配小值不影响结果
3. 乘积用 `long` 防止整数溢出
