## 题目描述

给你一棵以 `root` 为根的二叉树和一个整数 `target`，请你删除**所有值为 `target` 的叶子节点**。

注意，一旦删除值为 `target` 的叶子节点，它的父节点就可能变成叶子节点；如果新的叶子节点的值恰好也是 `target`，那么这个节点也需要被删除。

也就是说，你需要重复此过程直到不能继续删除。

**示例 1：**

```
输入：root = [1,2,3,2,null,2,4], target = 2
输出：[1,null,3,null,4]
```

**示例 2：**

```
输入：root = [1,3,3,3,2], target = 3
输出：[1,3,null,null,2]
```

**示例 3：**

```
输入：root = [1,2,null,2,null,2], target = 2
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[1, 3000]` 内
- `1 <= Node.val, target <= 1000`

## 解题思路

**后序 DFS（推荐）**

关键观察：删除操作是自底向上的——只有先处理完子树，才能知道父节点是否变成了叶子节点。

因此使用**后序遍历（左右根）**：先递归处理左右子树，再判断当前节点。

**后序 DFS 的逻辑：**

```
dfs(node):
    1. 递归处理左子树：node.left = dfs(node.left)
    2. 递归处理右子树：node.right = dfs(node.right)
    3. 判断当前节点：
       - 如果 node 是叶子（无子节点）且 node.val == target：返回 null（删除）
       - 否则：返回 node（保留）
```

## Java 代码实现

### 方法一：后序 DFS（推荐）

```java
class Solution {
    public TreeNode removeLeafNodes(TreeNode root, int target) {
        return dfs(root, target);
    }
    
    private TreeNode dfs(TreeNode node, int target) {
        if (node == null) return null;
        
        // 后序：先处理左右子树
        node.left = dfs(node.left, target);
        node.right = dfs(node.right, target);
        
        // 判断当前节点是否为叶子且值等于 target
        if (node.left == null && node.right == null && node.val == target) {
            return null; // 删除该节点
        }
        
        return node; // 保留该节点
    }
}
```

### 方法二：递归简化版（内联）

```java
class Solution {
    public TreeNode removeLeafNodes(TreeNode root, int target) {
        if (root == null) return null;
        root.left = removeLeafNodes(root.left, target);
        root.right = removeLeafNodes(root.right, target);
        // 如果当前节点变成了值为 target 的叶子，返回 null
        return (root.left == null && root.right == null && root.val == target) ? null : root;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 为树高，递归栈深度；最坏 O(n)，平均 O(log n)

## 图解示例

以 `root = [1,2,3,2,null,2,4], target = 2` 为例：

```
初始树：
        1
       / \
      2   3
     /   / \
    2   2   4

后序处理：
1. 处理节点 2（最左叶子）：是叶子且值=2，删除 -> 返回 null
2. 处理节点 2（左子根）：左子变 null，无子节点，值=2，删除 -> 返回 null
3. 处理节点 2（3的左子）：是叶子且值=2，删除 -> 返回 null
4. 处理节点 4：是叶子且值=4，保留
5. 处理节点 3：左子变 null，保留
6. 处理节点 1：左子变 null，保留

最终：
    1
     \
      3
       \
        4
```

## 关键点总结

1. **后序遍历**是关键：先处理子树，再处理当前节点
2. 删除叶子的操作：让父节点的对应指针指向 `null`，在递归中即返回 `null`
3. 一次后序遍历即可完成所有删除，不需要多次遍历

## 易错点

1. **前序遍历不行**：如果先处理当前节点再处理子树，子节点变化不能反映到当前节点
2. **返回值的处理**：`node.left = dfs(node.left, target)` 这一行至关重要，它接收子树处理后的返回值（可能是 null）
3. **叶子判断时机**：在递归处理完左右子树之后才判断，此时子树中的叶子已经被删除
