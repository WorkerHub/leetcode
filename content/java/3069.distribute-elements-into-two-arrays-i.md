## 题目描述

按规则将数组元素分配到 arr1 和 arr2：arr1[0]=nums[0]，arr2[0]=nums[1]，之后若 arr1 末尾 > arr2 末尾则追加到 arr1，否则追加到 arr2，返回 arr1+arr2。

## 解题思路

按题意直接模拟，维护两个列表，依次比较末尾元素决定追加位置。

## Java 代码实现

```java
class Solution {
    public int[] resultArray(int[] nums) {
        List<Integer> arr1 = new ArrayList<>();
        List<Integer> arr2 = new ArrayList<>();
        arr1.add(nums[0]);
        arr2.add(nums[1]);

        for (int i = 2; i < nums.length; i++) {
            // 比较两数组末尾元素，决定追加位置
            if (arr1.get(arr1.size() - 1) > arr2.get(arr2.size() - 1)) {
                arr1.add(nums[i]);
            } else {
                arr2.add(nums[i]);
            }
        }

        // 合并两个数组
        int[] result = new int[nums.length];
        int idx = 0;
        for (int x : arr1) result[idx++] = x;
        for (int x : arr2) result[idx++] = x;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 初始化时 arr1=[nums[0]]，arr2=[nums[1]]，从 nums[2] 开始处理
2. 比较两数组的最后一个元素决定分配方向
3. 题目保证所有元素互不相同，不会出现相等情况
