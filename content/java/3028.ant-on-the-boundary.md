## 题目描述

蚂蚁从原点出发，每次移动nums[i]步，统计回到原点的次数。

## 解题思路

计算前缀和，统计前缀和等于0的次数。

## Java 代码实现

```java
class Solution {
    public int returnToBoundaryCount(int[] nums) {
        int pos = 0, count = 0;
        for (int x : nums) {
            pos += x;
            if (pos == 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **蚂蚁位置=前缀和**
2. **统计前缀和为0的次数**
3. **初始位置不算一次回到边界**
