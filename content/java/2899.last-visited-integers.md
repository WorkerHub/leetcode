## 题目描述

给你整数数组 nums，遇到正整数加入列表，遇到 -1 则查找当前连续 -1 数量 k 对应的倒数第 k 个整数（不存在则为 -1），返回所有查询结果。

## 解题思路

模拟：维护已访问整数列表和连续 -1 计数器，遇到非负数时重置计数，遇到 -1 时计数加 1 并从列表末尾索引。

## Java 代码实现

```java
class Solution {
    public List<Integer> lastVisitedIntegers(List<Integer> nums) {
        List<Integer> seen = new ArrayList<>();
        List<Integer> ans = new ArrayList<>();
        int k = 0; // 连续 -1 计数

        for (int x : nums) {
            if (x != -1) {
                seen.add(x);
                k = 0; // 重置连续 -1 计数
            } else {
                k++;
                int idx = seen.size() - k;
                ans.add(idx >= 0 ? seen.get(idx) : -1);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 遇到非 -1 数字时，重置连续 -1 计数器
2. 第 k 个连续 -1 对应列表倒数第 k 个，即索引 `size - k`
3. 若 `size < k` 则返回 -1
