## 题目描述

给你字符串 `s`，可以任意次选择一个字符 `c`，删除其左侧和右侧各最近的相同字符（若存在），返回操作后字符串的最小长度。

## Java 代码实现

```java
class Solution {
    public int minimumLength(String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }
        int ans = 0;
        for (int cnt : count) {
            if (cnt == 0) continue;
            // 奇数次出现保留 1 个，偶数次出现保留 2 个
            ans += (cnt % 2 == 1) ? 1 : 2;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，统计字符频率
- 空间复杂度：O(1)，最多 26 个字母

## 关键点总结

1. 每次操作删除相同字符左右各最近一个（共 2 个），保留中间
2. 每个字母奇数次出现最终保留 1 个，偶数次出现保留 2 个
3. 不同字母之间互不影响
