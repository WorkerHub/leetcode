## 题目描述

给你正整数数组 `nums`，判断是否存在两个或以上元素的按位 OR 结果有尾随零（即结果为偶数）。

## 解题思路

OR 结果有尾随零等价于所有参与元素的最低位均为 0（即均为偶数），因此只需判断数组中是否有至少两个偶数。

## Java 代码实现

```java
class Solution {
    public boolean hasTrailingZeros(int[] nums) {
        int evenCount = 0;
        for (int x : nums) {
            if ((x & 1) == 0) evenCount++; // 偶数最低位为 0
            if (evenCount >= 2) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. OR 有尾随零 ⟺ 所有参与元素均为偶数
2. 只需找到至少 2 个偶数
3. 用位运算 `(x & 1) == 0` 判断偶数更高效
