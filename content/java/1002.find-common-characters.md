## 题目描述

给你一个字符串数组 `words`，请你找出所有在 `words` 的每个字符串中都出现的共用字符（包括重复字符），并以数组形式返回。你可以按任意顺序返回答案。

**示例 1：**
```
输入：words = ["bella","label","roller"]
输出：["e","l","l"]
```

**示例 2：**
```
输入：words = ["cool","lock","cook"]
输出：["c","o"]
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 由小写英文字母组成

## 解题思路

这道题的核心是找出所有字符串中的**共同字符**，包括重复的字符。

**关键观察：**
1. 一个字符在结果中出现的次数 = 它在所有字符串中出现次数的**最小值**
2. 例如：如果字符 'l' 在三个字符串中分别出现 2次、3次、2次，那么结果中 'l' 应该出现 2 次

**算法流程：**
1. 统计第一个字符串中每个字符的出现次数（作为初始计数）
2. 遍历后续每个字符串，更新每个字符的最小出现次数
3. 根据最终的计数结果，构造返回数组

## Java 代码实现

### 方法一：数组计数（推荐）

```java
import java.util.*;

class Solution {
    public List<String> commonChars(String[] words) {
        // 用数组记录每个字母的最小出现次数（26个小写字母）
        int[] minFreq = new int[26];
        Arrays.fill(minFreq, Integer.MAX_VALUE);

        for (String word : words) {
            // 统计当前单词中每个字母的出现次数
            int[] freq = new int[26];
            for (char c : word.toCharArray()) {
                freq[c - 'a']++;
            }
            // 更新最小出现次数
            for (int i = 0; i < 26; i++) {
                minFreq[i] = Math.min(minFreq[i], freq[i]);
            }
        }

        // 构造结果
        List<String> result = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < minFreq[i]; j++) {
                result.add(String.valueOf((char) ('a' + i)));
            }
        }

        return result;
    }
}
```

### 方法二：从第一个单词初始化

```java
import java.util.*;

class Solution {
    public List<String> commonChars(String[] words) {
        // 统计第一个单词中每个字符的出现次数作为基准
        int[] commonCount = new int[26];
        for (char c : words[0].toCharArray()) {
            commonCount[c - 'a']++;
        }

        // 遍历剩余单词，更新最小计数
        for (int i = 1; i < words.length; i++) {
            int[] wordCount = new int[26];
            for (char c : words[i].toCharArray()) {
                wordCount[c - 'a']++;
            }
            // 对每个字符，取最小出现次数
            for (int j = 0; j < 26; j++) {
                commonCount[j] = Math.min(commonCount[j], wordCount[j]);
            }
        }

        // 根据计数构造结果
        List<String> result = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < commonCount[i]; j++) {
                result.add(String.valueOf((char) ('a' + i)));
            }
        }

        return result;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n * m)
- n 是字符串数组的长度，m 是字符串的平均长度
- 需要遍历所有字符串的所有字符

**空间复杂度：** O(1)
- 只需要存储 26 个字母的计数，与输入规模无关
- 如果考虑返回结果，空间复杂度为 O(k)，k 为结果长度

## 关键点总结

1. **最小值思想**：共同字符的数量由最少出现次数决定
2. **数组计数**：对于小写字母，可以用长度为 26 的数组代替哈希表
3. **字符转整数**：`c - 'a'` 将字符映射到 0-25 的索引
4. **逐步取最小**：遍历每个单词后，用 Math.min 更新最小计数

## 易错点

1. **初始值设置**：方法一中初始化为 Integer.MAX_VALUE，方法二中初始化为第一个单词的计数
2. **重复字符**：如果字符出现多次，结果中也要包含多次
3. **空集合处理**：如果某个字符在某个单词中不存在，其计数为 0，最终结果中不应包含
4. **返回格式**：要返回字符列表，不是计数数组
