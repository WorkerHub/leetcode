## 题目描述

给定 BST 根节点，将其转换为累加树（Greater Sum Tree），每个节点新值等于原树中大于或等于该节点值的所有节点值之和。

**示例：**
```
输入：[4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]
```

## 解题思路

反向中序遍历（右→根→左）按降序访问节点，遍历过程中维护累加和并更新节点值。

## Java 代码实现

```java
class Solution {
    private int sum = 0;

    public TreeNode bstToGst(TreeNode root) {
        reverseInorder(root);
        return root;
    }

    private void reverseInorder(TreeNode node) {
        if (node == null) return;

        // 先遍历右子树（更大的节点）
        reverseInorder(node.right);

        // 累加当前节点值并更新
        sum += node.val;
        node.val = sum;

        // 再遍历左子树
        reverseInorder(node.left);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **反向中序遍历**：右→根→左，按降序访问 BST 节点
2. **累加和维护**：全局变量记录已访问节点的和
3. **与 538 题相同**：Convert BST to Greater Tree
