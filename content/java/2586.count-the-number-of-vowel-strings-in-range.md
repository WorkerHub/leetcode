## 题目描述

给你字符串数组 `words` 和整数 `left`、`right`，返回下标在 [left, right] 范围内首尾字符都是元音的字符串数目。

## 解题思路

遍历 `words[left..right]`，判断每个字符串的首尾字符是否都在元音集合 `{a,e,i,o,u}` 中，统计满足条件的数目。

## Java 代码实现

```java
class Solution {
    public int vowelStrings(String[] words, int left, int right) {
        String vowels = "aeiou";
        int count = 0;
        for (int i = left; i <= right; i++) {
            String w = words[i];
            char first = w.charAt(0), last = w.charAt(w.length() - 1);
            if (vowels.indexOf(first) >= 0 && vowels.indexOf(last) >= 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(right - left + 1)
- **空间复杂度**：O(1)

## 关键点总结

1. 元音集合为 `"aeiou"`，用 `indexOf` 检查字符是否是元音
2. 首字符 `charAt(0)` 和尾字符 `charAt(len-1)` 都需满足
3. 单字符字符串的首尾是同一个字符，仍然合法
