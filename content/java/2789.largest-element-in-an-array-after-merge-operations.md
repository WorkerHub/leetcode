## 题目描述

给你整数数组 `nums`，可以将满足 `nums[i] <= nums[i+1]` 的相邻对合并为 `nums[i] + nums[i+1]`，返回最终数组中可能存在的最大元素。

## Java 代码实现

```java
class Solution {
    public long maxArrayValue(int[] nums) {
        long cur = nums[nums.length - 1];
        long ans = cur;
        // 从右向左：只要左侧 <= 当前累积值就合并
        for (int i = nums.length - 2; i >= 0; i--) {
            if (nums[i] <= cur) {
                cur += nums[i];
            } else {
                cur = nums[i];
            }
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 从右向左贪心：右侧大值为左侧合并提供条件
2. 只要 `nums[i] <= cur` 即可合并，累积值递增
3. 用 `long` 防止累积和溢出
