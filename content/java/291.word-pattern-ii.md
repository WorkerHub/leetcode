## 题目描述

给定一个模式 pattern 和一个字符串 s，请你判断 s 是否遵循相同的模式。

这里的遵循指完全匹配，例如，pattern 中的每个字母和字符串 s 中的每个非空单词之间存在双向连接的对应模式。

**示例 1：**
```
输入：pattern = "abab", s = "redblueredblue"
输出：true
解释：一种可能的映射如下：
'a' -> "red"
'b' -> "blue"
```

**示例 2：**
```
输入：pattern = "aaaa", s = "asdasdasdasd"
输出：true
解释：一种可能的映射如下：
'a' -> "asd"
```

**示例 3：**
```
输入：pattern = "abab", s = "asdasdasdasd"
输出：true
解释：一种可能的映射如下：
'a' -> "a"
'b' -> "sd"
```

**提示：**
- 1 <= pattern.length, s.length <= 20
- pattern 只包含小写英文字母
- s 只包含小写英文字母

## 解题思路

这道题是 290. 单词规律的进阶版，区别在于：
- 290 题中字符串已经被空格分割好了
- 本题需要自己决定如何分割字符串 s

**核心思想：回溯 + 哈希表**

1. 使用两个哈希表维护双向映射关系
   - `patternToWord`：模式字符到单词的映射
   - `wordToPattern`：单词到模式字符的映射

2. 递归回溯过程：
   - 如果 pattern 和 s 都遍历完，返回 true
   - 如果只有一个遍历完，返回 false
   - 获取当前模式字符，尝试所有可能的单词分割
   - 检查映射关系是否一致
   - 递归处理剩余部分
   - 回溯恢复状态

3. 剪枝优化：
   - 如果当前字符已有映射，直接验证
   - 提前判断剩余长度是否足够

## Java 代码实现

### 方法一：回溯 + 双向哈希表（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    // 双向映射表
    private Map<Character, String> patternToWord = new HashMap<>();
    private Map<String, Character> wordToPattern = new HashMap<>();

    public boolean wordPatternMatch(String pattern, String s) {
        return backtrack(pattern, 0, s, 0);
    }

    private boolean backtrack(String pattern, int pIdx, String s, int sIdx) {
        // 基础情况：都遍历完了
        if (pIdx == pattern.length() && sIdx == s.length()) {
            return true;
        }
        // 只有一个遍历完，说明不匹配
        if (pIdx == pattern.length() || sIdx == s.length()) {
            return false;
        }

        char c = pattern.charAt(pIdx);

        // 如果该字符已经有映射
        if (patternToWord.containsKey(c)) {
            String word = patternToWord.get(c);
            // 检查 s 中是否有对应的单词
            if (!s.startsWith(word, sIdx)) {
                return false;
            }
            // 递归检查剩余部分
            return backtrack(pattern, pIdx + 1, s, sIdx + word.length());
        }

        // 如果该字符还没有映射，尝试所有可能的单词
        for (int end = sIdx + 1; end <= s.length(); end++) {
            String word = s.substring(sIdx, end);

            // 如果这个单词已经被其他字符映射了，跳过
            if (wordToPattern.containsKey(word)) {
                continue;
            }

            // 建立映射关系
            patternToWord.put(c, word);
            wordToPattern.put(word, c);

            // 递归检查
            if (backtrack(pattern, pIdx + 1, s, end)) {
                return true;
            }

            // 回溯，撤销映射
            patternToWord.remove(c);
            wordToPattern.remove(word);
        }

        return false;
    }
}
```

### 方法二：回溯 + 剪枝优化

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public boolean wordPatternMatch(String pattern, String s) {
        return backtrack(pattern, 0, s, 0, new HashMap<>(), new HashSet<>());
    }

    private boolean backtrack(String pattern, int pIdx, String s, int sIdx,
                               Map<Character, String> mapping, Set<String> used) {
        // 基础情况
        if (pIdx == pattern.length() && sIdx == s.length()) {
            return true;
        }
        if (pIdx == pattern.length() || sIdx == s.length()) {
            return false;
        }

        char c = pattern.charAt(pIdx);

        // 如果已有映射，直接验证
        if (mapping.containsKey(c)) {
            String word = mapping.get(c);
            if (!s.startsWith(word, sIdx)) {
                return false;
            }
            return backtrack(pattern, pIdx + 1, s, sIdx + word.length(), mapping, used);
        }

        // 剪枝：至少为剩余 pattern 每个字符留一个字符
        int remainingChars = pattern.length() - pIdx - 1;
        int maxLen = s.length() - sIdx - remainingChars;

        for (int length = 1; length <= maxLen; length++) {
            String word = s.substring(sIdx, sIdx + length);

            // 检查是否已被映射
            if (used.contains(word)) {
                continue;
            }

            // 建立映射
            mapping.put(c, word);
            used.add(word);

            // 递归
            if (backtrack(pattern, pIdx + 1, s, sIdx + length, mapping, used)) {
                return true;
            }

            // 回溯
            mapping.remove(c);
            used.remove(word);
        }

        return false;
    }
}
```

## 复杂度分析

### 方法一和方法二：

**时间复杂度：** O(n^m)
- n 是字符串 s 的长度
- m 是 pattern 的长度
- 最坏情况下需要尝试所有可能的分割方式
- 实际运行中由于剪枝，性能会好很多

**空间复杂度：** O(m)
- 递归调用栈深度为 m
- 哈希表存储最多 m 个映射关系

## 关键点总结

1. **双向映射**：需要同时维护 pattern→word 和 word→pattern 的映射，确保一对一关系
2. **回溯框架**：建立映射 → 递归 → 撤销映射，这是标准的回溯模板
3. **边界条件**：pattern 和 s 必须同时遍历完才算匹配成功
4. **剪枝优化**：计算最大可能的单词长度，避免无效尝试
5. **状态恢复**：回溯时必须完全恢复状态，包括删除映射关系

## 易错点

1. **忘记双向检查**
   ```java
   // 错误：只检查 pattern -> word
   if (mapping.containsKey(c)) { ... }
   
   // 正确：还要检查 word -> pattern（used 集合）
   if (used.contains(word)) { continue; }
   ```

2. **边界条件处理不当**
   ```java
   // 错误：只检查一个是否结束
   if (pIdx == pattern.length()) return true;
   
   // 正确：两个都要检查
   if (pIdx == pattern.length() && sIdx == s.length()) return true;
   if (pIdx == pattern.length() || sIdx == s.length()) return false;
   ```

3. **回溯时忘记恢复状态**
   ```java
   // 错误：没有删除映射
   mapping.put(c, word);
   if (backtrack(...)) return true;
   // 忘记 mapping.remove(c)
   
   // 正确：必须恢复
   mapping.put(c, word);
   if (backtrack(...)) return true;
   mapping.remove(c);
   ```
