## 题目描述

给你糖果数组 `candiesCount`（按类型顺序吃）和查询 `[favoriteType, favoriteDay, dailyCap]`，每天至少吃 1 颗最多 `dailyCap` 颗，按顺序吃。判断第 `favoriteDay` 天能否吃到第 `favoriteType` 类糖果。

## 解题思路

前缀和预处理。对查询 `(t, d, cap)`，第 `d` 天结束时吃的颗数范围为 `[d+1, (d+1)*cap]`，第 `t` 类糖果的颗数范围为 `[prefix[t]+1, prefix[t+1]]`，两区间有交集则可行。注意用 `long` 防止溢出。

## Java 代码实现

```java
class Solution {
    public boolean[] canEat(int[] candiesCount, int[][] queries) {
        int n = candiesCount.length;

        // 前缀和（用 long 防止溢出）
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + candiesCount[i];
        }

        boolean[] ans = new boolean[queries.length];
        for (int i = 0; i < queries.length; i++) {
            long t = queries[i][0], d = queries[i][1], cap = queries[i][2];

            // 第 d 天结束时的吃糖范围
            long minEaten = d + 1;         // 每天最少 1 颗
            long maxEaten = (d + 1) * cap; // 每天最多 cap 颗

            // 第 t 类糖果的颗数范围（1-indexed）
            long candyStart = prefix[(int) t] + 1;       // 第 t 类第一颗
            long candyEnd = prefix[(int) t + 1];          // 第 t 类最后一颗

            // 两区间有交集则可行
            ans[i] = maxEaten >= candyStart && minEaten <= candyEnd;
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)
- **空间复杂度**：O(n)

## 关键点总结

1. 区间交集判断：`[min, max]` 与 `[start, end]` 有交集等价于 `max >= start && min <= end`
2. 用 `long` 防止 `(d+1)*cap` 溢出
