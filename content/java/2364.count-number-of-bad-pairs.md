## 题目描述

给你整数数组 `nums`，若 `i < j` 且 `j-i != nums[j]-nums[i]`，则 `(i,j)` 是坏数对，返回坏数对总数。

## 解题思路

变形条件：`j-i == nums[j]-nums[i]` 等价于 `nums[i]-i == nums[j]-j`。坏数对 = 总数对 - 好数对。遍历时维护哈希表记录 `nums[i]-i` 的出现次数，遇到新元素时，当前与之前已出现的元素中差值不同的就是坏数对数（即 `i - count[key]`）。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countBadPairs(int[] nums) {
        Map<Integer, Integer> seen = new HashMap<>();
        long ans = 0;
        for (int i = 0; i < nums.length; i++) {
            int key = nums[i] - i;
            int good = seen.getOrDefault(key, 0); // 前面与当前构成好数对的数量
            ans += i - good; // 坏数对 = 前面总元素数 - 好数对数
            seen.merge(key, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 条件变形：`nums[i]-i == nums[j]-j` 为好数对的充要条件。
2. 逐步累计：处理第 i 个元素时，与前面 i 个中好数对数为 `seen[key]`，坏数对为 `i - seen[key]`。
3. `nums[i]-i` 可能为负数，哈希表可正常处理。
