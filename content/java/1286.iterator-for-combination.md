## 题目描述

设计迭代器类，给定升序字符串和组合长度，按字典序依次返回所有组合。

**示例：**
```
CombinationIterator("abc", 2)
next() → "ab", next() → "ac", next() → "bc"
```

## 解题思路

预生成所有组合存入队列，或用位掩码迭代。预生成最简单直接。

## Java 代码实现

```java
class CombinationIterator {
    private Queue<String> queue;
    
    public CombinationIterator(String characters, int combinationLength) {
        queue = new LinkedList<>();
        generate(characters, combinationLength, 0, new StringBuilder());
    }
    
    private void generate(String chars, int len, int start, StringBuilder sb) {
        if (sb.length() == len) {
            queue.offer(sb.toString());
            return;
        }
        for (int i = start; i < chars.length(); i++) {
            sb.append(chars.charAt(i));
            generate(chars, len, i + 1, sb);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
    
    public String next() {
        return queue.poll();
    }
    
    public boolean hasNext() {
        return !queue.isEmpty();
    }
}
```

## 复杂度分析

- **时间复杂度**：初始化 O(C(n,k) × k)，next/hasNext O(1)
- **空间复杂度**：O(C(n,k) × k)

## 关键点总结

1. **预生成**：初始化时生成所有组合
2. **回溯**：标准组合生成模板
3. **队列**：按字典序存储，依次取出
