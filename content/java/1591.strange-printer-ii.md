## 题目描述

判断能否通过若干次矩形打印操作（后打印覆盖先打印）得到目标矩阵。

## 解题思路

拓扑排序：若颜色A的矩形内有颜色B，则A必须先打印。建有向图检测是否有环。

## Java 代码实现

```java
class Solution {
    public boolean isPrintable(int[][] targetGrid) {
        int m = targetGrid.length, n = targetGrid[0].length;
        // 找每种颜色的最小覆盖矩形
        int[][] bounds = new int[61][4]; // [minR, maxR, minC, maxC]
        boolean[] exists = new boolean[61];
        for (int[] b : bounds) Arrays.fill(b, -1);
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int c = targetGrid[i][j];
                if (!exists[c]) {
                    exists[c] = true;
                    bounds[c] = new int[]{i, i, j, j};
                } else {
                    bounds[c][0] = Math.min(bounds[c][0], i);
                    bounds[c][1] = Math.max(bounds[c][1], i);
                    bounds[c][2] = Math.min(bounds[c][2], j);
                    bounds[c][3] = Math.max(bounds[c][3], j);
                }
            }
        }
        
        // 建有向图：颜色c的矩形内出现颜色other，则 c -> other
        Set<Integer>[] graph = new HashSet[61];
        int[] inDegree = new int[61];
        for (int i = 0; i <= 60; i++) graph[i] = new HashSet<>();
        
        for (int c = 1; c <= 60; c++) {
            if (!exists[c]) continue;
            int r1 = bounds[c][0], r2 = bounds[c][1];
            int c1 = bounds[c][2], c2 = bounds[c][3];
            for (int i = r1; i <= r2; i++) {
                for (int j = c1; j <= c2; j++) {
                    int other = targetGrid[i][j];
                    if (other != c && !graph[c].contains(other)) {
                        graph[c].add(other);
                        inDegree[other]++;
                    }
                }
            }
        }
        
        // 拓扑排序
        Queue<Integer> queue = new LinkedList<>();
        int colorCount = 0;
        for (int c = 1; c <= 60; c++) {
            if (exists[c]) {
                colorCount++;
                if (inDegree[c] == 0) queue.offer(c);
            }
        }
        
        int processed = 0;
        while (!queue.isEmpty()) {
            int c = queue.poll();
            processed++;
            for (int nxt : graph[c]) {
                if (--inDegree[nxt] == 0) queue.offer(nxt);
            }
        }
        return processed == colorCount;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N × C)，C为颜色数
- **空间复杂度**：O(C²)

## 关键点总结

1. **最小覆盖矩形**：每种颜色的外接矩形
2. **建图**：矩形内有其他颜色则建边
3. **拓扑排序**：无环则可打印
