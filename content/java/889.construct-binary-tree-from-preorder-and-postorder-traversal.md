## 题目描述

给定前序遍历和后序遍历结果，重构二叉树。如果有多个答案，返回任一个。

**示例：**
```
输入：preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1]
输出：[1,2,3,4,5,6,7]
```

## 解题思路

分治递归：前序第一个为根，第二个为左子树根。在后序中找到左子树根的位置确定左子树大小。

## Java 代码实现

```java
class Solution {
    private Map<Integer, Integer> postIndex = new HashMap<>();

    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        for (int i = 0; i < postorder.length; i++) {
            postIndex.put(postorder[i], i);
        }
        return build(preorder, 0, preorder.length - 1, 0, postorder.length - 1);
    }

    private TreeNode build(int[] pre, int preL, int preR, int postL, int postR) {
        if (preL > preR) return null;

        TreeNode root = new TreeNode(pre[preL]);
        if (preL == preR) return root;

        // 左子树根在前序中的下一个位置
        int leftRootVal = pre[preL + 1];
        int leftIdx = postIndex.get(leftRootVal);
        int leftSize = leftIdx - postL + 1;

        root.left = build(pre, preL + 1, preL + leftSize, postL, leftIdx);
        root.right = build(pre, preL + leftSize + 1, preR, leftIdx + 1, postR - 1);
        return root;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **分治**：确定根节点并划分左右子树
2. **前序第二个**：是左子树的根
3. **后序定位**：确定左子树大小
