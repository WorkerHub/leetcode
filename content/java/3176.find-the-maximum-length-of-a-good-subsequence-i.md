## 题目描述

给你整数数组 `nums` 和非负整数 `k`，若子序列中相邻元素不同的个数不超过 k，则称其为好子序列，返回最长好子序列的长度。

## 解题思路

DP + 哈希表优化：`best[v][j]` 为以值 v 结尾、恰好有 j 处相邻不同时的最长子序列长度；`globalBest[j]` 为不同数恰好为 j 时的全局最优。对每个新元素 x，接在相同值后不增加不同数，接在不同值后 j+1。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums, int k) {
        Map<Integer, int[]> best = new HashMap<>(); // 值 -> dp 数组
        int[] globalBest = new int[k + 1];
        int ans = 0;

        for (int x : nums) {
            int[] oldBest = best.getOrDefault(x, new int[k + 1]);
            int[] newBest = new int[k + 1];
            for (int j = 0; j <= k; j++) {
                // 接在相同值后（不增加不同数）
                newBest[j] = oldBest[j] + 1;
                // 接在不同值后（不同数 +1）
                if (j > 0) {
                    newBest[j] = Math.max(newBest[j], globalBest[j - 1] + 1);
                }
            }
            // 更新 best[x]
            int[] cur = best.computeIfAbsent(x, v -> new int[k + 1]);
            for (int j = 0; j <= k; j++) {
                cur[j] = Math.max(cur[j], newBest[j]);
                globalBest[j] = Math.max(globalBest[j], newBest[j]);
                ans = Math.max(ans, newBest[j]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)
- **空间复杂度**：O(V × k)，V 为不同值数量

## 关键点总结

1. 接在相同值后不增加不同数，接在不同值后 j+1
2. 用哈希表记录每个值结尾的 DP 状态，将 O(n^2 k) 优化为 O(nk)
3. 先用旧值计算新值，再更新全局最优
