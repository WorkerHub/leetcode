## 题目描述

每天对数组进行变换：局部最小值 +1，局部最大值 -1，首尾不变。重复直到数组不再变化。

**示例：**
```
输入：arr = [6,2,3,4]
输出：[6,3,3,4]
```

## 解题思路

模拟：每轮创建新数组，对中间元素判断局部极值并修改。当新旧数组相同时停止。

## Java 代码实现

```java
class Solution {
    public List<Integer> transformArray(int[] arr) {
        int n = arr.length;
        boolean changed = true;
        
        while (changed) {
            changed = false;
            int[] next = arr.clone();
            for (int i = 1; i < n - 1; i++) {
                if (arr[i] < arr[i - 1] && arr[i] < arr[i + 1]) {
                    next[i]++;
                    changed = true;
                } else if (arr[i] > arr[i - 1] && arr[i] > arr[i + 1]) {
                    next[i]--;
                    changed = true;
                }
            }
            arr = next;
        }
        
        List<Integer> result = new ArrayList<>();
        for (int num : arr) result.add(num);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × max(arr))，最多变换 max(arr) 轮
- **空间复杂度**：O(n)

## 关键点总结

1. **基于前一天的状态**：必须用新数组记录本轮变化，不能原地修改
2. **首尾不变**：只处理 i ∈ [1, n-2]
3. **终止条件**：一轮中没有任何元素变化
