## 题目描述

返回数组中距离0最近的数字，相同距离取较大值。

## 解题思路

遍历维护最优答案：绝对值更小则更新，绝对值相同取正数。

## Java 代码实现

```java
class Solution {
    public int findClosestNumber(int[] nums) {
        int ans = nums[0];
        for (int x : nums) {
            if (Math.abs(x) < Math.abs(ans) || 
                (Math.abs(x) == Math.abs(ans) && x > ans)) {
                ans = x;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **绝对值最小即距0最近**
2. **绝对值相同取正数**：正数优先于负数
3. **一遍遍历**：维护当前最优
