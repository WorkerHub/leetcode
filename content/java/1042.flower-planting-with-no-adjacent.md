## 题目描述

n 个花园，每个最多 3 条路径，用 4 种花着色使相邻花园花色不同。保证有解。

**示例：**
```
输入：n = 3, paths = [[1,2],[2,3],[3,1]]
输出：[1,2,3]
```

## 解题思路

贪心图着色：每个节点最多 3 个邻居，4 种颜色一定够用。顺序遍历，选第一个邻居没用过的颜色。

## Java 代码实现

```java
class Solution {
    public int[] gardenNoAdj(int n, int[][] paths) {
        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] path : paths) {
            graph.get(path[0] - 1).add(path[1] - 1);
            graph.get(path[1] - 1).add(path[0] - 1);
        }

        int[] answer = new int[n];

        // 贪心着色
        for (int i = 0; i < n; i++) {
            // 收集邻居已使用的颜色
            boolean[] used = new boolean[5]; // 颜色 1-4
            for (int neighbor : graph.get(i)) {
                if (answer[neighbor] != 0) {
                    used[answer[neighbor]] = true;
                }
            }

            // 选第一个可用颜色
            for (int color = 1; color <= 4; color++) {
                if (!used[color]) {
                    answer[i] = color;
                    break;
                }
            }
        }

        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，m 为边数
- **空间复杂度**：O(n + m)

## 关键点总结

1. **保证有解**：4 种颜色，每个节点最多 3 个邻居
2. **贪心策略**：顺序遍历，选第一个未被邻居使用的颜色
3. **邻接表**：用 List 存储图结构
