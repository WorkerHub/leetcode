## 题目描述

基因序列可以表示为一条由 8 个字符组成的字符串，其中每个字符都是 `'A'`、`'C'`、`'G'` 和 `'T'` 之一。

假设我们需要调查从基因序列 `start` 变为 `end` 所发生的基因变化。一次基因变化就意味着这个基因序列中的一个字符发生了变化。

- 例如，`"AACCGGTT" --> "AACCGGTA"` 就是一次基因变化。

另有一个基因库 `bank` 记录了所有有效的基因变化，只有基因库中的基因才是有效的基因序列。（变化后的基因必须位于基因库 `bank` 中）

给你两个基因序列 `start` 和 `end`，以及一个基因库 `bank`，请你找出并返回能够使 `start` 变化为 `end` 所需的最少变化次数。如果无法完成此基因变化，返回 `-1`。

注意：起始基因序列 `start` 默认是有效的，但是它并不一定会出现在基因库中。

**示例 1：**
```
输入：start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]
输出：1
```

**示例 2：**
```
输入：start = "AACCGGTT", end = "AAACGGTA", bank = ["AACCGGTA","AACCGCTA","AAACGGTA"]
输出：2
```

**提示：**
- `0 <= bank.length <= 10`
- `start.length == end.length == bank[i].length == 8`
- `start`、`end` 以及 `bank[i]` 仅由字符 `['A', 'C', 'G', 'T']` 组成

## 解题思路

这道题本质是一个最短路径问题，可以使用广度优先搜索（BFS）解决。

**关键观察：**
1. 每次只能改变一个字符
2. 变化后的基因必须在 bank 中
3. 要找最少的变化次数 -> BFS

**算法流程：**
1. 将 bank 转为集合，方便快速查找
2. 使用 BFS 从 start 开始搜索
3. 每次尝试改变一个位置的字符（4种可能）
4. 如果新基因在 bank 中且未访问过，加入队列
5. 直到找到 end 或队列为空

## Java 代码实现

### 方法一：BFS ⭐ 推荐

```java
import java.util.*;

class Solution {
    public int minMutation(String start, String end, String[] bank) {
        // 如果 end 不在基因库中，无法到达
        Set<String> bankSet = new HashSet<>(Arrays.asList(bank));
        if (!bankSet.contains(end)) return -1;
        
        // BFS
        Queue<String> queue = new ArrayDeque<>();
        queue.offer(start);
        Set<String> visited = new HashSet<>();
        visited.add(start);
        char[] genes = {'A', 'C', 'G', 'T'};
        int steps = 0;
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            steps++;
            
            for (int s = 0; s < size; s++) {
                String current = queue.poll();
                char[] arr = current.toCharArray();
                
                // 尝试改变每个位置
                for (int i = 0; i < 8; i++) {
                    char orig = arr[i];
                    // 尝试每种字符
                    for (char gene : genes) {
                        if (gene == orig) continue;
                        
                        // 生成新基因
                        arr[i] = gene;
                        String newGene = new String(arr);
                        
                        // 找到目标
                        if (newGene.equals(end)) return steps;
                        
                        // 如果在基因库中且未访问过
                        if (bankSet.contains(newGene) && !visited.contains(newGene)) {
                            queue.offer(newGene);
                            visited.add(newGene);
                        }
                        
                        arr[i] = orig;  // 还原字符
                    }
                }
            }
        }
        
        return -1;
    }
}
```

### 方法二：优化版（预先计算差异）

```java
import java.util.*;

class Solution {
    public int minMutation(String start, String end, String[] bank) {
        if (!Arrays.asList(bank).contains(end)) return -1;
        
        // BFS
        Queue<String> queue = new ArrayDeque<>();
        queue.offer(start);
        Set<String> visited = new HashSet<>();
        visited.add(start);
        int steps = 0;
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            steps++;
            
            for (int s = 0; s < size; s++) {
                String current = queue.poll();
                
                // 遍历基因库，找到所有相差一个字符的基因
                for (String gene : bank) {
                    if (!visited.contains(gene) && oneDiff(current, gene)) {
                        if (gene.equals(end)) return steps;
                        queue.offer(gene);
                        visited.add(gene);
                    }
                }
            }
        }
        
        return -1;
    }
    
    // 判断两个基因是否只差一个字符
    private boolean oneDiff(String gene1, String gene2) {
        int diff = 0;
        for (int i = 0; i < gene1.length(); i++) {
            if (gene1.charAt(i) != gene2.charAt(i)) {
                diff++;
                if (diff > 1) return false;
            }
        }
        return diff == 1;
    }
}
```

### 方法三：双向 BFS

```java
import java.util.*;

class Solution {
    public int minMutation(String start, String end, String[] bank) {
        Set<String> bankSet = new HashSet<>(Arrays.asList(bank));
        if (!bankSet.contains(end)) return -1;
        
        char[] genes = {'A', 'C', 'G', 'T'};
        
        // 双向 BFS
        Set<String> beginSet = new HashSet<>();
        Set<String> endSet = new HashSet<>();
        beginSet.add(start);
        endSet.add(end);
        Set<String> visited = new HashSet<>();
        int steps = 0;
        
        while (!beginSet.isEmpty() && !endSet.isEmpty()) {
            // 始终从小的集合开始搜索
            if (beginSet.size() > endSet.size()) {
                Set<String> temp = beginSet;
                beginSet = endSet;
                endSet = temp;
            }
            
            Set<String> nextSet = new HashSet<>();
            steps++;
            
            for (String current : beginSet) {
                char[] arr = current.toCharArray();
                // 尝试所有可能的变化
                for (int i = 0; i < 8; i++) {
                    char orig = arr[i];
                    for (char gene : genes) {
                        if (gene == orig) continue;
                        
                        arr[i] = gene;
                        String newGene = new String(arr);
                        
                        // 如果在另一端找到，返回结果
                        if (endSet.contains(newGene)) return steps;
                        
                        if (bankSet.contains(newGene) && !visited.contains(newGene)) {
                            nextSet.add(newGene);
                            visited.add(newGene);
                        }
                        
                        arr[i] = orig;
                    }
                }
            }
            
            beginSet = nextSet;
        }
        
        return -1;
    }
}
```

## 复杂度分析

**方法一：BFS**
- 时间复杂度：O(N × L × C)
  - N = bank 的长度
  - L = 基因长度（8）
  - C = 字符集大小（4）
- 空间复杂度：O(N)，visited 集合

**方法二：优化版**
- 时间复杂度：O(N² × L)
- 空间复杂度：O(N)

**方法三：双向 BFS**
- 时间复杂度：O(N × L × C)，但实际更快
- 空间复杂度：O(N)

## 关键点总结

1. **BFS 应用**：最短路径问题用 BFS
2. **状态表示**：基因序列就是状态
3. **转移条件**：只改变一个字符，且在 bank 中
4. **visited 集合**：避免重复访问
5. **双向 BFS**：从两端同时搜索，提高效率

## 易错点

1. **end 不在 bank**：要先检查 end 是否在 bank 中
2. **字符串比较**：Java 中要用 equals() 比较字符串，不能用 ==
3. **visited 初始化**：start 要加入 visited
4. **返回值**：找不到路径返回 -1
5. **步数计数**：每层结束后才加 1
