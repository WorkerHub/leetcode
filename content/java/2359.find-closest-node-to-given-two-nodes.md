## 题目描述

给你每个节点至多一条出边的有向图（`edges` 数组），从 `node1` 和 `node2` 都能到达的节点中，找使 `max(dist1[x], dist2[x])` 最小的节点下标（并列取最小下标）。

## 解题思路

分别从 `node1` 和 `node2` 出发线性遍历（每节点最多一条出边，无需BFS），记录各节点距离。再枚举所有节点取最小 `max` 值的节点。

## Java 代码实现

```java
class Solution {
    public int closestMeetingNode(int[] edges, int node1, int node2) {
        int n = edges.length;
        int[] dist1 = getDist(edges, node1, n);
        int[] dist2 = getDist(edges, node2, n);

        int ans = -1, minMax = Integer.MAX_VALUE;
        for (int x = 0; x < n; x++) {
            if (dist1[x] == Integer.MAX_VALUE || dist2[x] == Integer.MAX_VALUE) continue;
            int curMax = Math.max(dist1[x], dist2[x]);
            if (curMax < minMax) { // 严格更小才更新，保证下标最小
                minMax = curMax;
                ans = x;
            }
        }
        return ans;
    }

    private int[] getDist(int[] edges, int start, int n) {
        int[] dist = new int[n];
        java.util.Arrays.fill(dist, Integer.MAX_VALUE);
        int cur = start, d = 0;
        while (cur != -1 && dist[cur] == Integer.MAX_VALUE) {
            dist[cur] = d++;
            cur = edges[cur];
        }
        return dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每个节点至多一条出边，路径是一条链（可能有环），线性遍历即可。
2. 用 `dist[cur] == MAX_VALUE` 判断未访问，遇到已访问节点停止（处理环）。
3. 枚举时严格小于才更新，保证多个答案时返回最小下标。
