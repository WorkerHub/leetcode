## 题目描述

给你偶数长度字符串 `s` 和查询数组，每个查询允许对前半段和对应后半段各自内部重排，判断能否使整串成为回文。

## 解题思路

将后半段翻转为 t（t[i] = s[n-1-i]）。查询范围外的位置不能有 first[i]!=t[i] 的不匹配；查询范围内，first[l..r] 和 t[tl..tr] 的字符多重集相同则可重排成回文。用前缀计数数组 O(1) 查询字符频次，前缀不匹配数组 O(1) 查询外部不匹配数。

## Java 代码实现

```java
class Solution {
    public boolean[] canMakePalindromeQueries(String s, int[][] queries) {
        int n = s.length(), half = n / 2;
        String first = s.substring(0, half);
        // t[i] = s[n-1-i]，后半段翻转
        char[] t = new char[half];
        for (int i = 0; i < half; i++) t[i] = s.charAt(n - 1 - i);

        // 前缀计数
        int[][] pf = buildPrefix(first.toCharArray(), half);
        int[][] pt = buildPrefix(t, half);
        // 前缀不匹配数
        int[] mismatch = new int[half + 1];
        for (int i = 0; i < half; i++)
            mismatch[i + 1] = mismatch[i] + (first.charAt(i) != t[i] ? 1 : 0);

        boolean[] res = new boolean[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1];
            int tl = half - 1 - r, tr = half - 1 - l;

            // 查询范围外必须无不匹配
            int outer = mismatch[l] + (mismatch[half] - mismatch[r + 1]);
            int outerT = mismatch[tl] + (mismatch[half] - mismatch[tr + 1]);
            if (outer != 0 || outerT != 0) { res[q] = false; continue; }

            // 查询范围内字符多重集必须相同
            res[q] = sameFreq(pf, l, r, pt, tl, tr);
        }
        return res;
    }

    private int[][] buildPrefix(char[] str, int n) {
        int[][] prefix = new int[n + 1][26];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i].clone();
            prefix[i + 1][str[i] - 'a']++;
        }
        return prefix;
    }

    private boolean sameFreq(int[][] pf, int l1, int r1, int[][] pt, int l2, int r2) {
        for (int c = 0; c < 26; c++) {
            if (pf[r1 + 1][c] - pf[l1][c] != pt[r2 + 1][c] - pt[l2][c]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(26(n + q))
- **空间复杂度**：O(26n)

## 关键点总结

1. 将后半段翻转为 t，问题变为 first 与 t 的对应位置匹配问题
2. 查询范围外不匹配必须为 0，范围内字符多重集相同即可重排
3. 前缀计数和前缀不匹配数组实现 O(1) 查询
