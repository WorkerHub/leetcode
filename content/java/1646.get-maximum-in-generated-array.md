## 题目描述

按规则生成长度为 `n+1` 的数组：`nums[0]=0`，`nums[1]=1`，`nums[2i]=nums[i]`，`nums[2i+1]=nums[i]+nums[i+1]`。返回数组最大值。

## 解题思路

按规则直接模拟生成数组，然后返回最大值。

## Java 代码实现

```java
class Solution {
    public int getMaximumGenerated(int n) {
        if (n == 0) return 0;

        int[] nums = new int[n + 1];
        nums[0] = 0;
        nums[1] = 1;

        for (int i = 1; 2 * i <= n; i++) {
            nums[2 * i] = nums[i]; // 偶数下标
            if (2 * i + 1 <= n) {
                nums[2 * i + 1] = nums[i] + nums[i + 1]; // 奇数下标
            }
        }

        int max = 0;
        for (int x : nums) max = Math.max(max, x);
        return max;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 直接按定义模拟，无需额外技巧
2. 特殊处理 n=0 的边界情况
3. 循环 i 从 1 到 n/2，分别填充偶数和奇数下标
