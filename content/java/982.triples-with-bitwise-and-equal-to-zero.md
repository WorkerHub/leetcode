## 题目描述

给定整数数组 nums，返回满足 nums[i] & nums[j] & nums[k] == 0 的三元组 (i, j, k) 的数目。

**示例：**
```
输入：nums = [2,1,3]
输出：12
```

## 解题思路

预处理两两 AND：先统计所有 nums[i] & nums[j] 的结果及出现次数，再遍历第三个数检查与 pair AND 是否为 0。

## Java 代码实现

```java
class Solution {
    public int countTriplets(int[] nums) {
        int n = nums.length;
        // 统计所有两两AND结果
        Map<Integer, Integer> pairCount = new HashMap<>();
        for (int a : nums) {
            for (int b : nums) {
                pairCount.merge(a & b, 1, Integer::sum);
            }
        }

        // 统计三元组
        int result = 0;
        for (int c : nums) {
            for (Map.Entry<Integer, Integer> entry : pairCount.entrySet()) {
                if ((entry.getKey() & c) == 0) {
                    result += entry.getValue();
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² + n * m)，m 为不同 pair AND 结果数
- **空间复杂度**：O(m)

## 关键点总结

1. **分步计算**：先两两 AND，再与第三个数 AND
2. **HashMap 优化**：相同结果合并计数
3. **位运算性质**：AND 结果范围有限（<= max(nums)）
