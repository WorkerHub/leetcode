## 题目描述

将字符串中所有'1'（黑球）移到'0'（白球）右边，每次交换相邻两个，求最少操作次数。

## 解题思路

从左到右遍历，维护已见'1'的个数ones，每遇到'0'需越过ones个黑球。

## Java 代码实现

```java
class Solution {
    public long minimumSteps(String s) {
        long ans = 0;
        int ones = 0;
        for (char c : s.toCharArray()) {
            if (c == '1') {
                ones++;
            } else {
                ans += ones;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **每个'0'需越过其左侧所有'1'**
2. **维护ones计数器累加即可**
3. **用long防溢出**：最坏情况O(N^2)次操作
