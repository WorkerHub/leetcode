## 题目描述

给定整数数组，找出所有最小绝对差的数对 [a, b]（a < b），按升序返回。

**示例：**
```
输入: arr = [4,2,1,3]
输出: [[1,2],[2,3],[3,4]]
```

## 解题思路

排序后最小差值一定在相邻元素间。一次遍历同时找最小差值和收集结果。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> minimumAbsDifference(int[] arr) {
        Arrays.sort(arr);
        List<List<Integer>> result = new ArrayList<>();
        int minDiff = Integer.MAX_VALUE;
        
        // 第一遍：找最小差值
        for (int i = 1; i < arr.length; i++) {
            minDiff = Math.min(minDiff, arr[i] - arr[i - 1]);
        }
        
        // 第二遍：收集所有最小差值的数对
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] - arr[i - 1] == minDiff) {
                result.add(Arrays.asList(arr[i - 1], arr[i]));
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **排序**：最小差值一定在排序后相邻元素间
2. **两遍遍历**：第一遍找最小差，第二遍收集结果
3. **无需绝对值**：排序后 arr[i] - arr[i-1] >= 0
