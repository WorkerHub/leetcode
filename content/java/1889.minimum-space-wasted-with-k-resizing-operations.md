## 题目描述

给你内存使用数组 `nums` 和整数 k，可进行 k 次调整大小操作将数组分成最多 k+1 段，每段分配容量为段内最大值，返回最少浪费的内存（浪费量 = 分配量 - 使用量之和）。

## 解题思路

DP：将数组分成 k+1 段，每段浪费量为 `max * len - sum`。用前缀和和区间最大值预计算加速，`dp[j][i]` 表示前 i 个元素调整 j 次的最小浪费。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minSpaceWastedKResizing(int[] nums, int k) {
        int n = nums.length;
        int INF = Integer.MAX_VALUE / 2;

        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // dp[j][i] = 前 i 个元素调整 j 次的最小浪费
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;

        // 0 次调整，整体为一段
        for (int i = 1; i <= n; i++) {
            int mx = 0;
            for (int p = i; p >= 1; p--) mx = Math.max(mx, nums[p - 1]);
            dp[0][i] = mx * i - prefix[i];
        }

        // j 次调整
        for (int j = 1; j <= k; j++) {
            for (int i = 1; i <= n; i++) {
                int mx = 0;
                for (int p = i; p >= 1; p--) {
                    mx = Math.max(mx, nums[p - 1]); // 最后一段 [p-1, i-1] 的最大值
                    int segSum = prefix[i] - prefix[p - 1];
                    int waste = mx * (i - p + 1) - segSum;
                    if (dp[j - 1][p - 1] != INF) {
                        dp[j][i] = Math.min(dp[j][i], dp[j - 1][p - 1] + waste);
                    }
                }
            }
        }
        return dp[k][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * n^2)
- **空间复杂度**：O(k * n)

## 关键点总结

1. 将问题转化为将数组分成 k+1 段，每段浪费量为 `max * len - sum`
2. 用前缀和快速计算区间和，从右向左枚举时维护区间最大值
3. k 次调整意味着分成 k+1 段
