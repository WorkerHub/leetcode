## 题目描述

给你 `m×n` 二进制矩阵 `grid`，返回 `diff` 矩阵，其中 `diff[i][j] = onesRow_i + onesCol_j - zerosRow_i - zerosCol_j`。

## 解题思路

预先统计每行和每列中 1 的个数，利用公式 `diff[i][j] = 2*rowOnes[i] + 2*colOnes[j] - n - m` 直接计算。

## Java 代码实现

```java
class Solution {
    public int[][] onesMinusZeros(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] rowOnes = new int[m], colOnes = new int[n];

        // 统计每行和每列中 1 的个数
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1) {
                    rowOnes[i]++;
                    colOnes[j]++;
                }

        // diff[i][j] = 2*rowOnes[i] + 2*colOnes[j] - m - n
        int[][] diff = new int[m][n];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                diff[i][j] = 2 * rowOnes[i] + 2 * colOnes[j] - m - n;

        return diff;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m + n)

## 关键点总结

1. `onesRow - zerosRow = 2*onesRow - n`（因为 onesRow + zerosRow = n）
2. 最终公式：`2*rowOnes[i] + 2*colOnes[j] - m - n`
3. 提前统计行列的 1 数，避免暴力重复计算
