## 题目描述

n×n 二元矩阵中恰好有两座岛（1 表示陆地），翻转最少的 0 使两座岛连通。返回最小翻转数。

## 解题思路

DFS 标记第一座岛并将其边界加入队列，然后 BFS 层序扩展直到碰到第二座岛。

## Java 代码实现

```java
class Solution {
    private int n;
    private int[][] grid;
    private Queue<int[]> queue = new LinkedList<>();

    public int shortestBridge(int[][] grid) {
        this.grid = grid;
        this.n = grid.length;

        // 找到第一个 1，DFS 标记第一座岛
        boolean found = false;
        for (int i = 0; i < n && !found; i++) {
            for (int j = 0; j < n && !found; j++) {
                if (grid[i][j] == 1) {
                    dfs(i, j);
                    found = true;
                }
            }
        }

        // BFS 扩展到第二座岛
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        int steps = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                int[] cell = queue.poll();
                for (int[] d : dirs) {
                    int ni = cell[0] + d[0], nj = cell[1] + d[1];
                    if (ni >= 0 && ni < n && nj >= 0 && nj < n) {
                        if (grid[ni][nj] == 1) return steps;
                        if (grid[ni][nj] == 0) {
                            grid[ni][nj] = 2;
                            queue.offer(new int[]{ni, nj});
                        }
                    }
                }
            }
            steps++;
        }

        return -1;
    }

    private void dfs(int i, int j) {
        if (i < 0 || i >= n || j < 0 || j >= n || grid[i][j] != 1) return;
        grid[i][j] = 2;
        queue.offer(new int[]{i, j});
        dfs(i + 1, j);
        dfs(i - 1, j);
        dfs(i, j + 1);
        dfs(i, j - 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **DFS + BFS 组合**：DFS 标记岛屿，BFS 求最短距离
2. **标记访问**：用 2 标记已访问的格子
3. **层序 BFS**：每层代表一步扩展
