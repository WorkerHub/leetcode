## 题目描述

给你正整数数组 `nums` 和正整数 `k`，若子集中任意两个整数的绝对差不等于 `k`，则称该子集为**漂亮**子集。返回所有非空漂亮子集的数目。

## 解题思路

**回溯 + 哈希计数**：数组长度最多 20，枚举所有非空子集。排序后用哈希计数维护当前子集，加入 `x` 时检查 `x-k` 是否已存在，若存在则跳过。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int ans = 0;
    private int[] nums;
    private int k;
    private Map<Integer, Integer> cnt = new HashMap<>();

    public int beautifulSubsets(int[] nums, int k) {
        Arrays.sort(nums);
        this.nums = nums;
        this.k = k;
        backtrack(0);
        return ans;
    }

    private void backtrack(int start) {
        for (int i = start; i < nums.length; i++) {
            int x = nums[i];
            // 若 x - k 在当前子集中，不能加入 x
            if (cnt.getOrDefault(x - k, 0) > 0) continue;
            cnt.merge(x, 1, Integer::sum);
            ans++; // 每加入一个元素，子集数 +1
            backtrack(i + 1);
            cnt.merge(x, -1, Integer::sum);
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n)，回溯枚举
- 空间复杂度：O(n)

## 关键点总结

1. 排序后只需检查 `x - k` 是否在集合中（升序添加，`x+k` 还未加入）
2. 哈希计数维护当前子集中元素出现次数
3. 每次合法加入一个元素就将答案 +1
