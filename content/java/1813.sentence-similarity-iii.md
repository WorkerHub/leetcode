## 题目描述

两个句子相似当且仅当较短句子的单词序列可以由较长句子删除中间某段单词后得到（即较短句子是较长句子的前缀+后缀）。

## 解题思路

分割为单词列表，令 s 为较短者，l 为较长者。从左端匹配前缀（指针 i），从右端匹配后缀（指针 j），若 `i + j >= len(s)` 则 s 被完全覆盖。

## Java 代码实现

```java
class Solution {
    public boolean areSentencesSimilar(String sentence1, String sentence2) {
        String[] w1 = sentence1.split(" ");
        String[] w2 = sentence2.split(" ");

        // 令 s 为较短句子，l 为较长句子
        if (w1.length > w2.length) {
            String[] tmp = w1; w1 = w2; w2 = tmp;
        }
        String[] s = w1, l = w2;
        int n = s.length, m = l.length;

        int i = 0; // 从左匹配的长度
        while (i < n && s[i].equals(l[i])) i++;

        int j = 0; // 从右匹配的长度
        while (j < n - i && s[n - 1 - j].equals(l[m - 1 - j])) j++;

        return i + j >= n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 前后缀匹配不重叠：右端匹配时 `j < n - i`
2. s 完全被覆盖的条件：`i + j >= len(s)`
