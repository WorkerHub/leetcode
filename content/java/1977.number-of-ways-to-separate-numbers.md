## 题目描述

给你数字字符串 `num`，分割成若干非空子字符串使其数字形成非递减序列（无前导零），返回合法方案数 mod 10^9+7。

## 解题思路

区间 DP + LCP 加速：`dp[i][j]` 为最后一段 `num[i..j-1]` 的方案数，用 LCP（最长公共前缀）数组 O(1) 比较两段大小，前缀和优化转移。

## Java 代码实现

```java
class Solution {
    public int numberOfCombinations(String num) {
        final int MOD = 1_000_000_007;
        int n = num.length();
        // lcp[i][j] = num[i:] 和 num[j:] 的最长公共前缀
        int[][] lcp = new int[n + 1][n + 1];
        for (int i = n - 1; i >= 0; i--)
            for (int j = n - 1; j >= 0; j--)
                lcp[i][j] = num.charAt(i) == num.charAt(j) ? lcp[i + 1][j + 1] + 1 : 0;

        // dp[i][j]: 最后一段起点 i，终点 j（不含）的方案数
        int[][] dp = new int[n][n + 1];
        // prefix[i][r] = dp[0][i] + dp[1][i] + ... + dp[r-1][i]
        int[][] prefix = new int[n][n + 1];

        for (int j = 1; j <= n; j++) {
            for (int i = j - 1; i >= 0; i--) {
                if (num.charAt(i) == '0') { dp[i][j] = 0; continue; }
                int L = j - i;
                if (i == 0) { dp[i][j] = 1; continue; }
                // 同长段：k = i - L
                int k = i - L;
                long sameLen = 0;
                if (k >= 0 && num.charAt(k) != '0') {
                    int common = lcp[k][i];
                    if (common >= L || num.charAt(k + common) <= num.charAt(i + common))
                        sameLen = dp[k][i];
                }
                // 较短段：前缀和 prefix[i][i] - prefix[i][max(0,i-L)]
                int lo = Math.max(0, i - L);
                long shorter = (prefix[i][i] - prefix[i][lo] + MOD) % MOD;
                dp[i][j] = (int) ((sameLen + shorter) % MOD);
            }
            // 更新 prefix[?][j]
            for (int i = 0; i < n; i++)
                prefix[i][j] = (int) ((prefix[i][j - 1] + dp[j - 1][i]) % MOD);
        }

        long ans = 0;
        for (int i = 0; i < n; i++) ans = (ans + dp[i][n]) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. LCP 数组使两段长度相同时比较大小为 O(1)
2. 前缀和优化较短段的转移
3. 前导零检查：`num.charAt(i) == '0'` 时方案数为 0
