## 题目描述

给你字符串 `s`，删除最少字符使其不含三个连续相同字符（花式字符串），返回结果。

## 解题思路

贪心：遍历字符串，若当前字符与结果末尾两个字符相同则跳过，否则加入结果。

## Java 代码实现

```java
class Solution {
    public String makeFancyString(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            int len = sb.length();
            // 若末尾两个字符与当前相同，跳过
            if (len >= 2 && sb.charAt(len - 1) == c && sb.charAt(len - 2) == c)
                continue;
            sb.append(c);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 检查末尾两个字符（允许两个连续相同）
2. 第三个连续相同字符时跳过
