## 题目描述

给你一个由非负整数 `a1, a2, ..., an` 组成的数据流输入，请你将到目前为止看到的数字总结为不相交的区间列表。

实现 `SummaryRanges` 类：

- `SummaryRanges()` 初始化对象。
- `void addNum(int value)` 向数据流中添加整数 `value`。
- `int[][] getIntervals()` 以不相交区间 `[starti, endi]` 的列表形式返回对数据流中的整数的总结。答案应该按 `starti` 升序排列。

**示例：**
```
输入：
["SummaryRanges", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals", "addNum", "getIntervals"]
[[], [1], [], [3], [], [7], [], [2], [], [6], []]
输出：
[null, null, [[1, 1]], null, [[1, 1], [3, 3]], null, [[1, 1], [3, 3], [7, 7]], null, [[1, 3], [7, 7]], null, [[1, 3], [6, 7]]]

解释：
SummaryRanges summaryRanges = new SummaryRanges();
summaryRanges.addNum(1);      // 数据流: [1]
summaryRanges.getIntervals(); // 返回 [[1, 1]]
summaryRanges.addNum(3);      // 数据流: [1, 3]
summaryRanges.getIntervals(); // 返回 [[1, 1], [3, 3]]
summaryRanges.addNum(7);      // 数据流: [1, 3, 7]
summaryRanges.getIntervals(); // 返回 [[1, 1], [3, 3], [7, 7]]
summaryRanges.addNum(2);      // 数据流: [1, 2, 3, 7]
summaryRanges.getIntervals(); // 返回 [[1, 3], [7, 7]]
summaryRanges.addNum(6);      // 数据流: [1, 2, 3, 6, 7]
summaryRanges.getIntervals(); // 返回 [[1, 3], [6, 7]]
```

**提示：**
- `0 <= value <= 10^4`
- 最多调用 `addNum` 和 `getIntervals` 方法 `3 * 10^4` 次

**进阶：** 如果存在大量合并，并且与数据流的大小相比，不相交区间的数量很小，该怎么办？

## 解题思路

这道题的核心是维护一个有序的、不相交的区间列表。

**关键操作：**
1. **添加数字**：可能需要合并相邻区间
2. **获取区间**：直接返回当前区间列表

**实现方案：**
- 使用有序列表存储区间
- 二分查找定位插入位置
- 合并可能的左右区间

## Java 代码实现

### 方法一：二分查找 + 合并⭐

```java
import java.util.ArrayList;
import java.util.List;

class SummaryRanges {
    // 存储不相交的区间，按起点排序
    private List<int[]> intervals;

    public SummaryRanges() {
        intervals = new ArrayList<>();
    }

    public void addNum(int value) {
        int[] newInterval = {value, value};

        if (intervals.isEmpty()) {
            intervals.add(newInterval);
            return;
        }

        // 二分查找第一个起点 > value 的位置
        int left = 0, right = intervals.size();
        while (left < right) {
            int mid = (left + right) / 2;
            if (intervals.get(mid)[0] <= value) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        int pos = left; // 第一个起点 > value 的位置

        int leftIdx = pos - 1; // 左边区间的索引
        int rightIdx = pos;    // 右边区间的索引

        // 检查是否已在某个区间内
        if (leftIdx >= 0 && intervals.get(leftIdx)[0] <= value && value <= intervals.get(leftIdx)[1]) {
            return;
        }

        // 判断能否与左边区间合并
        boolean mergeLeft = leftIdx >= 0 && intervals.get(leftIdx)[1] + 1 >= value;
        // 判断能否与右边区间合并
        boolean mergeRight = rightIdx < intervals.size() && intervals.get(rightIdx)[0] - 1 <= value;

        if (mergeLeft && mergeRight) {
            // 合并左右两个区间
            intervals.get(leftIdx)[1] = intervals.get(rightIdx)[1];
            intervals.remove(rightIdx);
        } else if (mergeLeft) {
            // 只合并左边
            intervals.get(leftIdx)[1] = Math.max(intervals.get(leftIdx)[1], value);
        } else if (mergeRight) {
            // 只合并右边
            intervals.get(rightIdx)[0] = Math.min(intervals.get(rightIdx)[0], value);
        } else {
            // 插入新区间
            intervals.add(pos, new int[]{value, value});
        }
    }

    public int[][] getIntervals() {
        return intervals.toArray(new int[0][]);
    }
}
```

**时间复杂度：**
- addNum: O(n)，最坏情况需要移动元素
- getIntervals: O(1)

**空间复杂度：** O(n)

### 方法二：使用 TreeSet + 排序

```java
import java.util.ArrayList;
import java.util.List;
import java.util.TreeSet;

class SummaryRanges {
    private TreeSet<Integer> nums;

    public SummaryRanges() {
        nums = new TreeSet<>();
    }

    public void addNum(int value) {
        nums.add(value);
    }

    public int[][] getIntervals() {
        if (nums.isEmpty()) {
            return new int[0][];
        }

        List<int[]> result = new ArrayList<>();
        int start = -1, end = -1;

        for (int num : nums) {
            if (start == -1) {
                // 初始化第一个区间
                start = end = num;
            } else if (num == end + 1) {
                // 扩展当前区间
                end = num;
            } else {
                // 保存当前区间，开始新区间
                result.add(new int[]{start, end});
                start = end = num;
            }
        }

        // 添加最后一个区间
        result.add(new int[]{start, end});

        return result.toArray(new int[0][]);
    }
}
```

**时间复杂度：**
- addNum: O(log n)
- getIntervals: O(n)

## 关键点总结

1. **二分查找**：快速定位插入位置
2. **区间合并**：判断相邻或重叠
3. **边界处理**：左右区间的合并条件
4. **去重**：避免重复添加

## 易错点

1. **合并条件**
   ```java
   // 错误：只考虑紧邻
   boolean mergeLeft = intervals.get(leftIdx)[1] + 1 == value;

   // 正确：考虑重叠
   boolean mergeLeft = intervals.get(leftIdx)[1] + 1 >= value;
   ```

2. **重复添加**
   ```java
   // 需要检查是否已在区间内
   if (leftIdx >= 0 && intervals.get(leftIdx)[0] <= value && value <= intervals.get(leftIdx)[1]) {
       return;
   }
   ```
