## 题目描述

给你一个数字字符串 `s`，至多可以交换一对奇偶性相同的相邻数字，返回字典序最小的结果。

## Java 代码实现

```java
class Solution {
    public String getSmallestString(String s) {
        char[] arr = s.toCharArray();
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            int a = arr[i] - '0', b = arr[i + 1] - '0';
            // 奇偶性相同且前者大于后者时交换，字典序更小
            if (a % 2 == b % 2 && a > b) {
                arr[i] = (char) ('0' + b);
                arr[i + 1] = (char) ('0' + a);
                break; // 只操作一次
            }
        }
        return new String(arr);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，转换为字符数组

## 关键点总结

1. 贪心：找到最左边能让字典序变小的交换
2. 条件：相邻两位奇偶性相同，且前者 > 后者
3. 只需执行一次操作，找到就立即交换并退出
