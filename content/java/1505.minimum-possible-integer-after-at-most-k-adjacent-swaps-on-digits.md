## 题目描述

给定数字字符串 num 和整数 k，最多 k 次相邻交换，求能得到的最小整数。

**示例：**
```
输入：num = "4321", k = 4
输出："1342"
```

## 解题思路

贪心 + 树状数组：从高位到低位，每次找能在剩余步数内移到当前位的最小数字。树状数组维护已移走元素的偏移量。

## Java 代码实现

```java
class Solution {
    private int[] bit;
    
    public String minInteger(String num, int k) {
        int n = num.length();
        bit = new int[n + 1];
        
        // 每个数字的出现位置队列
        Queue<Integer>[] pos = new Queue[10];
        for (int i = 0; i < 10; i++) pos[i] = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            pos[num.charAt(i) - '0'].offer(i);
        }
        
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            // 从 0 到 9 尝试最小数字
            for (int d = 0; d <= 9; d++) {
                if (pos[d].isEmpty()) continue;
                int idx = pos[d].peek();
                // 实际需要的交换次数 = idx - 前面已被移走的数量
                int cost = idx - query(idx);
                if (cost <= k) {
                    k -= cost;
                    pos[d].poll();
                    update(idx + 1, 1, n);
                    sb.append((char)('0' + d));
                    break;
                }
            }
        }
        return sb.toString();
    }
    
    private void update(int i, int val, int n) {
        for (; i <= n; i += i & (-i)) bit[i] += val;
    }
    
    private int query(int i) {
        int sum = 0;
        for (; i > 0; i -= i & (-i)) sum += bit[i];
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10 × n × log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心**：每位尽量放最小的数字
2. **树状数组**：维护已移走元素数，快速计算实际距离
3. **位置队列**：每个数字的出现位置按顺序存储
4. **实际代价**：原始位置 - 已移走的在前面的数量
