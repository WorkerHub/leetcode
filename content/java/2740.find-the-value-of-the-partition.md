## 题目描述

给你正整数数组 `nums`，将其分成两个非空子集，分区值定义为 `|max(subset1) - min(subset2)|`，返回所有可能分区的最小分区值。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int findValueOfPartition(int[] nums) {
        Arrays.sort(nums);
        // 最小分区值就是排序后相邻元素之差的最小值
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < nums.length - 1; i++) {
            ans = Math.min(ans, nums[i + 1] - nums[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后，最优分区一定是某个前缀和后缀
2. 分区值 = 前缀最大值（nums[k-1]）与后缀最小值（nums[k]）之差
