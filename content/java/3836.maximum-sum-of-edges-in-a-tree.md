## 题目描述

给定 `n` 节点树和边权，可删除若干边使每个连通子树节点数不超过 `k`，返回保留边的最大权重之和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumEdgeSum(int n, int[][] edges, int k) {
        // 贪心：将树分成若干块，每块大小 <= k，最少需要 ceil(n/k)-1 次切割
        // 删除权重最小的 ceil(n/k)-1 条边，保留其余边
        long total = 0;
        int[] weights = new int[edges.length];
        for (int i = 0; i < edges.length; i++) {
            weights[i] = edges[i][2];
            total += weights[i];
        }
        int numCuts = (n + k - 1) / k - 1;
        if (numCuts == 0) return total;

        Arrays.sort(weights);
        long removed = 0;
        for (int i = 0; i < numCuts; i++) removed += weights[i];
        return total - removed;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m)，排序边权
- 空间复杂度：O(m)

## 关键点总结

1. 将树切割为 `ceil(n/k)` 个子树，需要 `ceil(n/k)-1` 次切割
2. 贪心删除权重最小的 `ceil(n/k)-1` 条边，最大化保留边权和
3. 树连通，保证有 n-1 条边可供选择
