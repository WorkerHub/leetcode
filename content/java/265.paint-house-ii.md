## 题目描述

假如有一排房子共有 `n` 幢，每个房子可以被粉刷成 `k` 种颜色中的一种。房子粉刷成不同颜色的成本也是不同的。

你需要粉刷所有的房子并且使其相邻的两个房子颜色不能相同。

成本用一个 `n × k` 的矩阵 `costs` 表示：
- `costs[i][j]` 表示粉刷第 `i` 幢房子颜色 `j` 的成本

返回粉刷完所有房子的最小成本。

**示例 1：**
```
输入: costs = [[1,5,3],[2,9,4]]
输出: 5
解释: 
房子 0 刷成颜色 0 的成本为 1
房子 1 刷成颜色 2 的成本为 4
总成本: 1 + 4 = 5
```

**示例 2：**
```
输入: costs = [[1,3],[2,4]]
输出: 5
```

**提示：**
- `costs.length == n`
- `costs[i].length == k`
- `1 <= n <= 100`
- `2 <= k <= 20`
- `1 <= costs[i][j] <= 20`

## 解题思路

这是"粉刷房子 I"的进阶版，从 3 种颜色扩展到 k 种颜色。

**动态规划思路：**

**状态定义：**
- `dp[i][j]` 表示粉刷前 i+1 个房子，且第 i 个房子颜色为 j 的最小成本

**状态转移：**
- `dp[i][j] = costs[i][j] + min(dp[i-1][p])` (p ≠ j)
- 即：第 i 个房子颜色 j 的最小成本 = 当前成本 + 前一个房子非 j 颜色的最小成本

**优化关键：**
- 朴素做法：对于每个 (i, j)，遍历 k 种颜色找最小值，时间复杂度 O(n × k²)
- 优化方法：记录前一行的最小值和次小值，时间复杂度降为 O(n × k)

## Java 代码实现

### 方法一：动态规划 + 最小值优化（推荐）⭐

```java
class Solution {
    public int minCostII(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        int n = costs.length;
        int k = costs[0].length;

        // 初始化：第一个房子的成本
        int[] dp = costs[0].clone();

        for (int i = 1; i < n; i++) {
            // 找到前一行的最小值和次小值
            int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;
            int min1Idx = -1;

            for (int j = 0; j < k; j++) {
                if (dp[j] < min1) {
                    min2 = min1;
                    min1 = dp[j];
                    min1Idx = j;
                } else if (dp[j] < min2) {
                    min2 = dp[j];
                }
            }

            // 计算当前行
            int[] newDp = new int[k];
            for (int j = 0; j < k; j++) {
                // 如果当前颜色不是前一行最小值的颜色，使用最小值
                // 否则使用次小值
                if (j != min1Idx) {
                    newDp[j] = costs[i][j] + min1;
                } else {
                    newDp[j] = costs[i][j] + min2;
                }
            }

            dp = newDp;
        }

        // 返回最小成本
        int result = Integer.MAX_VALUE;
        for (int val : dp) {
            result = Math.min(result, val);
        }
        return result;
    }
}
```

### 方法二：原地修改（节省空间）

```java
class Solution {
    public int minCostII(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        int n = costs.length;
        int k = costs[0].length;

        for (int i = 1; i < n; i++) {
            // 找上一行的最小值和次小值
            int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;
            int min1Idx = -1;

            for (int j = 0; j < k; j++) {
                if (costs[i - 1][j] < min1) {
                    min2 = min1;
                    min1 = costs[i - 1][j];
                    min1Idx = j;
                } else if (costs[i - 1][j] < min2) {
                    min2 = costs[i - 1][j];
                }
            }

            // 更新当前行
            for (int j = 0; j < k; j++) {
                if (j != min1Idx) {
                    costs[i][j] += min1;
                } else {
                    costs[i][j] += min2;
                }
            }
        }

        // 找最后一行的最小值
        int result = Integer.MAX_VALUE;
        for (int val : costs[n - 1]) {
            result = Math.min(result, val);
        }
        return result;
    }
}
```

### 方法三：暴力 DP（不推荐，超时）

```java
class Solution {
    public int minCostII(int[][] costs) {
        // 时间复杂度 O(n * k^2)，会超时
        // 仅供理解思路
        if (costs == null || costs.length == 0) return 0;

        int n = costs.length;
        int k = costs[0].length;
        int[] dp = costs[0].clone();

        for (int i = 1; i < n; i++) {
            int[] newDp = new int[k];
            for (int j = 0; j < k; j++) {
                // 遍历前一个房子的所有颜色
                int minPrev = Integer.MAX_VALUE;
                for (int p = 0; p < k; p++) {
                    if (p != j) {
                        minPrev = Math.min(minPrev, dp[p]);
                    }
                }
                newDp[j] = costs[i][j] + minPrev;
            }
            dp = newDp;
        }

        int result = Integer.MAX_VALUE;
        for (int val : dp) {
            result = Math.min(result, val);
        }
        return result;
    }
}
```

## 复杂度分析

### 方法一、二（最小值优化）
- **时间复杂度**：O(n × k)
  - 遍历 n 个房子
  - 每个房子遍历 k 种颜色
  - 找最小值和次小值是 O(k)
  - 总计：O(n × k)

- **空间复杂度**：
  - 方法一：O(k)，只用一维数组
  - 方法二：O(1)，原地修改

### 方法三（暴力）
- **时间复杂度**：O(n × k²)，会超时
- **空间复杂度**：O(k)

## 图解示例

以 `costs = [[1,5,3],[2,9,4]]` 为例（k=3, n=2）：

```
第 0 个房子：
  颜色 0: 成本 1
  颜色 1: 成本 5
  颜色 2: 成本 3
  dp = [1, 5, 3]

第 1 个房子：
  前一行: dp = [1, 5, 3]
  最小值: min1 = 1 (索引 0)
  次小值: min2 = 3
  
  颜色 0: 2 + min2 = 2 + 3 = 5 (不能用 min1，因为索引相同)
  颜色 1: 9 + min1 = 9 + 1 = 10
  颜色 2: 4 + min1 = 4 + 1 = 5
  
  dp = [5, 10, 5]

答案: min(dp) = 5
```

## 关键点总结

1. **最小值优化**：记录前一行的最小值和次小值，避免 O(k) 遍历
2. **次小值的作用**：当前颜色等于前一行最小值颜色时，使用次小值
3. **空间优化**：只需要一维数组，滚动更新即可
4. **状态转移核心**：
   ```java
   newDp[j] = costs[i][j] + (j != min1Idx ? min1 : min2);
   ```
5. **边界条件**：第一行直接使用原始成本

## 易错点

1. **忘记找次小值**：只记录最小值会导致无法处理相同颜色的情况
2. **索引混淆**：要区分颜色索引和最小值索引
3. **空数组处理**：需要检查 `costs` 是否为空
4. **初始化错误**：第一行应该直接用 `costs[0]`，不需要计算
5. **Java 中使用 Integer.MAX_VALUE**：代替 Python 的 float('inf')
