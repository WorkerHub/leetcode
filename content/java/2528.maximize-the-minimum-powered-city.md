## 题目描述

给你 `stations` 数组（`stations[i]` 表示城市 i 的电力站数），每个城市电力值为距离不超过 `r` 的所有城市电力站之和，可额外增加 `k` 个电力站，使所有城市电力最小值最大化，返回该最大值。

## 解题思路

二分最小电力值 `m`，贪心验证：从左到右若城市 i 电力不足 `m`，将新站尽量放在 `i+r` 处（覆盖范围最靠右），用差分数组维护影响范围，统计总需站数是否 <= k。

## Java 代码实现

```java
class Solution {
    public long maxPower(int[] stations, int r, long k) {
        int n = stations.length;
        // 前缀和计算初始电力
        long[] ps = new long[n + 1];
        for (int i = 0; i < n; i++) ps[i + 1] = ps[i] + stations[i];

        // 初始电力值
        long[] power = new long[n];
        for (int i = 0; i < n; i++) {
            power[i] = ps[Math.min(n, i + r + 1)] - ps[Math.max(0, i - r)];
        }

        long lo = 0, hi = 0;
        for (long p : power) lo = Math.min(lo == 0 ? p : lo, p);
        hi = lo + k;

        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (feasible(power, n, r, k, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean feasible(long[] power, int n, int r, long k, long minVal) {
        long[] diff = new long[n + 2];
        long total = 0, cur = 0;
        long[] pw = power.clone();

        for (int i = 0; i < n; i++) {
            cur += diff[i];
            if (pw[i] + cur < minVal) {
                long need = minVal - pw[i] - cur;
                total += need;
                if (total > k) return false;
                // 尽量将新站放在 i+r 处（覆盖范围最靠右）
                int place = Math.min(i + r, n - 1);
                diff[place] += need;
                int end = place + 2 * r + 1;
                if (end <= n) diff[end] -= need;
                cur += need; // 当前位置立即受益
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log(sum + k))
- **空间复杂度**：O(n)

## 关键点总结

1. 二分最小电力值，配合贪心验证是否可行
2. 贪心：电力不足时将新站放在 `i+r` 处，使覆盖范围尽量向右延伸
3. 差分数组高效维护新增电力站对范围 `[place-r, place+r]` 的影响
