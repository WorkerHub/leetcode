## 题目描述

给你花园中所有树的坐标 `trees`，用最小半径的圆形围栏将所有树圈住，返回圆心 `[x, y]` 和半径 `r`。

## 解题思路

最小包围圆（Welzl 随机增量算法）：随机打乱点后逐点加入，若点不在当前圆内则它必须在最小圆的边界上，递归求解。最小圆由至多 3 个边界点确定，期望 O(n) 时间。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public double[] outerTrees(int[][] trees) {
        List<int[]> pts = new ArrayList<>(Arrays.asList(trees));
        Collections.shuffle(pts);
        double[] circle = {0, 0, 0};

        for (int i = 0; i < pts.size(); i++) {
            if (!inCircle(circle, pts.get(i))) {
                circle = makeCircle(pts.get(i));
                for (int j = 0; j < i; j++) {
                    if (!inCircle(circle, pts.get(j))) {
                        circle = makeCircle(pts.get(i), pts.get(j));
                        for (int k = 0; k < j; k++) {
                            if (!inCircle(circle, pts.get(k))) {
                                circle = makeCircle(pts.get(i), pts.get(j), pts.get(k));
                            }
                        }
                    }
                }
            }
        }
        return circle;
    }

    private boolean inCircle(double[] c, int[] p) {
        double dx = c[0] - p[0], dy = c[1] - p[1];
        return dx * dx + dy * dy <= (c[2] + 1e-7) * (c[2] + 1e-7);
    }

    private double[] makeCircle(int[] p) {
        return new double[]{p[0], p[1], 0};
    }

    private double[] makeCircle(int[] p1, int[] p2) {
        double cx = (p1[0] + p2[0]) / 2.0, cy = (p1[1] + p2[1]) / 2.0;
        double dx = p1[0] - p2[0], dy = p1[1] - p2[1];
        return new double[]{cx, cy, Math.sqrt(dx * dx + dy * dy) / 2};
    }

    private double[] makeCircle(int[] p1, int[] p2, int[] p3) {
        double ax = p1[0], ay = p1[1], bx = p2[0], by = p2[1], cx = p3[0], cy = p3[1];
        double d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by));
        if (Math.abs(d) < 1e-10) {
            // 三点共线，取最远两点为直径
            double[] c = makeCircle(p1, p2);
            if (!inCircle(c, p3)) c = makeCircle(p1, p3);
            if (!inCircle(c, p2)) c = makeCircle(p2, p3);
            return c;
        }
        double ux = ((ax*ax+ay*ay)*(by-cy)+(bx*bx+by*by)*(cy-ay)+(cx*cx+cy*cy)*(ay-by))/d;
        double uy = ((ax*ax+ay*ay)*(cx-bx)+(bx*bx+by*by)*(ax-cx)+(cx*cx+cy*cy)*(bx-ax))/d;
        double dx = ux - ax, dy = uy - ay;
        return new double[]{ux, uy, Math.sqrt(dx*dx + dy*dy)};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n) 期望
- **空间复杂度**：O(n)

## 关键点总结

1. 最小包围圆由至多 3 个点确定
2. 随机打乱保证期望 O(n) 时间复杂度
3. 三点共线时外接圆公式分母为 0，需特判
