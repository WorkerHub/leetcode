## 题目描述

最多 3 次操作（将任一元素改为任意值），使数组最大值与最小值差最小。

**示例：**
```
输入：nums = [1,5,0,10,14]
输出：1
```

## 解题思路

排序后，相当于从两端删掉共 3 个元素。4 种方案取最小差值。

## Java 代码实现

```java
class Solution {
    public int minDifference(int[] nums) {
        int n = nums.length;
        if (n <= 4) return 0;
        
        Arrays.sort(nums);
        
        int result = Integer.MAX_VALUE;
        // 4 种方案：删左 i 个 + 删右 (3-i) 个
        for (int i = 0; i <= 3; i++) {
            result = Math.min(result, nums[n - 1 - (3 - i)] - nums[i]);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序**：极值在两端
2. **4 种方案**：删左 0-3 个 + 删右 3-0 个
3. **n ≤ 4**：直接返回 0（全部可以改成相同）
4. **等价于删除**：改为任意值 ≈ 删除极值
