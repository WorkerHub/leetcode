## 题目描述

将十进制数转为十六进制，将 0 替换为 O，1 替换为 I。若结果只含 A-F、I、O 则返回，否则返回 "ERROR"。

**示例：**
```
输入：num = "257"
输出："IOI"
解释：257 的十六进制是 101，替换后得 "IOI"
```

## 解题思路

转十六进制后大写，替换 0→O、1→I，检查是否只含合法字符。

## Java 代码实现

```java
class Solution {
    public String toHexspeak(String num) {
        long n = Long.parseLong(num);
        String hex = Long.toHexString(n).toUpperCase();
        
        StringBuilder sb = new StringBuilder();
        for (char c : hex.toCharArray()) {
            if (c == '0') sb.append('O');
            else if (c == '1') sb.append('I');
            else if (c >= 'A' && c <= 'F') sb.append(c);
            else return "ERROR"; // 含有 2-9 的数字
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **Long 解析**：数字可能超出 int 范围
2. **十六进制转换**：Long.toHexString()
3. **字符替换**：0→O, 1→I
4. **合法性检查**：只允许 A-F, I, O
