## 题目描述

给你非负整数 `num`，若存在某个非负整数 `k` 满足 `k + reverse(k) = num`，返回 `true`，否则返回 `false`。

## 解题思路

枚举 `k` 从 0 到 `num`，检查 `k + reverse(k) == num`。由于 `k + reverse(k) >= k`，`k` 不超过 `num`，枚举范围有界。`num <= 10^5`，枚举可接受。

## Java 代码实现

```java
class Solution {
    public boolean sumIsAddedOrReversed(int num) {
        for (int k = 0; k <= num; k++) {
            if (k + reverse(k) == num) return true;
        }
        return false;
    }

    private int reverse(int x) {
        int rev = 0;
        while (x > 0) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return rev;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(num × log(num))
- **空间复杂度**：O(1)

## 关键点总结

1. 枚举 k 从 0 到 num，检查是否满足条件
2. k = 0 时 reverse(0) = 0，`0 + 0 = 0`，需包含此情况
3. `num <= 10^5`，枚举量可接受
