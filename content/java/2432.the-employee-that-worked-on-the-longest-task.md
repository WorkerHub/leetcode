## 题目描述

给你员工任务日志 `logs`（每条记录包含员工 ID 和离开时间），返回耗时最长的任务对应的员工 ID，耗时相同时取 ID 最小的员工。

## 解题思路

顺序遍历 logs，每个任务耗时 = 当前离开时间 - 上一个离开时间（第一个任务从时间 0 开始），维护最大耗时及对应员工 ID，相同耗时取较小 ID。

## Java 代码实现

```java
class Solution {
    public int hardestWorker(int n, int[][] logs) {
        int ansId = logs[0][0];
        int maxTime = logs[0][1]; // 第一个任务从时间 0 开始
        int prev = logs[0][1];

        for (int i = 1; i < logs.length; i++) {
            int empId = logs[i][0];
            int leaveTime = logs[i][1];
            int duration = leaveTime - prev;
            // 耗时更长，或耗时相同但 ID 更小，则更新
            if (duration > maxTime || (duration == maxTime && empId < ansId)) {
                maxTime = duration;
                ansId = empId;
            }
            prev = leaveTime;
        }
        return ansId;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m)，m 为日志条数
- **空间复杂度**：O(1)

## 关键点总结

1. 第一个任务耗时 = `logs[0][1] - 0`（从时间 0 开始）
2. 后续任务耗时 = 当前离开时间 - 上一个离开时间
3. 相同耗时取更小的员工 ID
