## 题目描述

给定平面上的点集，找出由这些点构成的矩形（边不一定平行坐标轴）的最小面积。无法构成返回 0。

## 解题思路

枚举三个点 (p1, p2, p3)，p1 为直角顶点。检查向量 p1p2 和 p1p3 是否垂直（点积为 0），第四个点 p4 = p2+p3-p1 是否存在。

## Java 代码实现

```java
class Solution {
    public double minAreaFreeRect(int[][] points) {
        int n = points.length;
        Set<Long> pointSet = new HashSet<>();
        for (int[] p : points) {
            pointSet.add((long) p[0] * 40001 + p[1]);
        }

        double minArea = Double.MAX_VALUE;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    // 尝试三种直角顶点
                    double area = tryRect(points, i, j, k, pointSet);
                    if (area > 0) minArea = Math.min(minArea, area);
                    area = tryRect(points, j, i, k, pointSet);
                    if (area > 0) minArea = Math.min(minArea, area);
                    area = tryRect(points, k, i, j, pointSet);
                    if (area > 0) minArea = Math.min(minArea, area);
                }
            }
        }

        return minArea == Double.MAX_VALUE ? 0 : minArea;
    }

    private double tryRect(int[][] points, int a, int b, int c, Set<Long> pointSet) {
        // a 为直角顶点，检查向量 ab 和 ac 是否垂直
        int[] pa = points[a], pb = points[b], pc = points[c];
        int vx1 = pb[0] - pa[0], vy1 = pb[1] - pa[1];
        int vx2 = pc[0] - pa[0], vy2 = pc[1] - pa[1];

        // 点积为 0 表示垂直
        if (vx1 * vx2 + vy1 * vy2 != 0) return -1;

        // 第四个点
        int x4 = pb[0] + pc[0] - pa[0];
        int y4 = pb[1] + pc[1] - pa[1];

        if (!pointSet.contains((long) x4 * 40001 + y4)) return -1;

        // 计算面积 = |叉积|
        double side1 = Math.sqrt(vx1 * vx1 + vy1 * vy1);
        double side2 = Math.sqrt(vx2 * vx2 + vy2 * vy2);
        return side1 * side2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n)

## 关键点总结

1. **向量点积判垂直**：点积为 0 则垂直
2. **第四个点推导**：p4 = p2 + p3 - p1
3. **三种直角顶点**：枚举哪个点是直角
