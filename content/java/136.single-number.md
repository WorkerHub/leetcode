## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1：**
```
输入：nums = [2,2,1]
输出：1
```

**示例 2：**
```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**
```
输入：nums = [1]
输出：1
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次

## 解题思路

这道题的关键在于**位运算**，特别是**异或运算（XOR）**的性质。

**核心思想：异或运算的性质**
1. `a ^ a = 0`（任何数和自己异或等于 0）
2. `a ^ 0 = a`（任何数和 0 异或等于自己）
3. 异或运算满足交换律和结合律：`a ^ b ^ c = a ^ (b ^ c) = (a ^ b) ^ c`

**算法流程：**
- 将数组中所有数字进行异或运算
- 由于相同的数字异或为 0，最终剩下的就是只出现一次的数字
- 例如：`[4,1,2,1,2]`
  - `4 ^ 1 ^ 2 ^ 1 ^ 2`
  - `= 4 ^ (1 ^ 1) ^ (2 ^ 2)`
  - `= 4 ^ 0 ^ 0`
  - `= 4`

**为什么这样做是最优的？**
- 时间复杂度：O(n)，只需遍历一次
- 空间复杂度：O(1)，不需要额外空间
- 满足题目的所有要求

## Java 代码实现

### 方法一：位运算异或（推荐）

```java
class Solution {
    public int singleNumber(int[] nums) {
        // 所有数字异或，相同的数字会抵消为 0
        int result = 0;
        for (int num : nums) {
            result ^= num;
        }
        return result;
    }
}
```

### 方法二：哈希表（不满足空间要求，但便于理解）

```java
class Solution {
    public int singleNumber(int[] nums) {
        // 使用集合存储，出现两次的删除
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (seen.contains(num)) {
                seen.remove(num);
            } else {
                seen.add(num);
            }
        }
        // 最后剩下的就是只出现一次的
        return seen.iterator().next();
    }
}
```

### 方法三：数学方法（集合）

```java
class Solution {
    public int singleNumber(int[] nums) {
        // 2 * (所有不重复数字的和) - 所有数字的和 = 只出现一次的数字
        Set<Integer> numSet = new HashSet<>();
        long sumAll = 0;
        long sumSet = 0;
        for (int num : nums) {
            sumAll += num;
            numSet.add(num);
        }
        for (int num : numSet) {
            sumSet += num;
        }
        return (int)(2 * sumSet - sumAll);
    }
}
```

## 复杂度分析

### 方法一：位运算
- **时间复杂度**：O(n)，需要遍历数组一次
- **空间复杂度**：O(1)，只使用一个变量

### 方法二：哈希表
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(n)，最坏情况下需要存储 n/2 个元素

### 方法三：数学方法
- **时间复杂度**：O(n)，需要遍历数组计算和
- **空间复杂度**：O(n)，需要创建集合

## 图解示例

以 `nums = [4,1,2,1,2]` 为例：

```
二进制表示和异或过程：
4:  0100
1:  0001
2:  0010
1:  0001
2:  0010

异或过程：
0000 (初始)
^ 0100 = 0100  (4)
^ 0001 = 0101  (4^1)
^ 0010 = 0111  (4^1^2)
^ 0001 = 0110  (4^1^2^1)
^ 0010 = 0100  (4^1^2^1^2 = 4)

结果：0100 = 4
```

## 关键点总结

1. **异或运算的性质**：`a ^ a = 0`，`a ^ 0 = a`，这是解题的核心
2. **交换律和结合律**：异或运算顺序无关，可以任意调整
3. **位运算优势**：常数级空间复杂度，且运算速度快
4. **问题转化**：将"找唯一元素"转化为"消除成对元素"
5. **Java 整数溢出**：方法三中求和时注意使用 `long` 防止溢出

## 易错点

1. **忘记初始化**：异或的初始值必须是 0
2. **误用其他运算**：不能用加减法或其他位运算代替异或
3. **空间复杂度要求**：题目要求 O(1) 空间，哈希表方法不满足
4. **数据范围**：虽然有负数，但异或运算对负数同样适用（补码表示）
5. **Java 整数溢出**：数学方法中求和可能溢出，需要用 `long` 计算
