## 题目描述

给定字符矩阵 `grid` 和字符串 `pattern`。统计同时满足"在某行水平出现的 pattern 中"且"在某列垂直出现的 pattern 中"的单元格数量。

## 解题思路

分别标记水平方向和垂直方向被 pattern 覆盖的单元格（用 boolean 矩阵），最后统计两者交集数量。

## Java 代码实现

```java
class Solution {
    public int countCells(char[][] grid, String pattern) {
        int rows = grid.length, cols = grid[0].length, pLen = pattern.length();
        boolean[][] hMark = new boolean[rows][cols];
        boolean[][] vMark = new boolean[rows][cols];

        // 水平标记
        for (int r = 0; r < rows; r++) {
            String rowStr = new String(grid[r]);
            int pos = 0;
            while ((pos = rowStr.indexOf(pattern, pos)) != -1) {
                for (int c = pos; c < pos + pLen; c++) hMark[r][c] = true;
                pos++;
            }
        }

        // 垂直标记
        for (int c = 0; c < cols; c++) {
            StringBuilder sb = new StringBuilder();
            for (int r = 0; r < rows; r++) sb.append(grid[r][c]);
            String colStr = sb.toString();
            int pos = 0;
            while ((pos = colStr.indexOf(pattern, pos)) != -1) {
                for (int r = pos; r < pos + pLen; r++) vMark[r][c] = true;
                pos++;
            }
        }

        int count = 0;
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++)
                if (hMark[r][c] && vMark[r][c]) count++;
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(rows * cols * pLen)
- 空间复杂度：O(rows * cols)

## 关键点总结

1. 水平和垂直分别独立标记，最后取交集
2. `indexOf(pattern, pos++)` 允许重叠匹配
3. 标记 pattern 覆盖的所有单元格，不只是起始位置
