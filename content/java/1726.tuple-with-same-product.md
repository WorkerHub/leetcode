## 题目描述

给你由不同正整数组成的数组 `nums`，返回满足 `a * b = c * d` 的元组 `(a, b, c, d)` 的数量，其中四个元素两两不同且均来自 `nums`。

## 解题思路

枚举所有数对 `(i, j)`（i < j）并记录乘积，用哈希表统计各乘积出现次数。若某乘积有 `k` 个数对，则 `C(k,2) * 8` 即为该乘积贡献的元组数（两对各自可互换，两对间也可互换，共 8 种排列）。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int tupleSameProduct(int[] nums) {
        int n = nums.length;
        Map<Integer, Integer> productCount = new HashMap<>();
        int ans = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int p = nums[i] * nums[j];
                // 当前数对与已有的同乘积数对各自组成元组，每对贡献 8 种排列
                ans += productCount.getOrDefault(p, 0) * 8;
                productCount.merge(p, 1, Integer::sum);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 枚举所有数对的乘积并统计频率
2. 每两个相同乘积的数对可组合成 8 种有效元组
