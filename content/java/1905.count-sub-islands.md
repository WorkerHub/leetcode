## 题目描述

给你两个 `m x n` 的二进制矩阵 `grid1` 和 `grid2`，若 `grid2` 中某岛屿的所有陆地格在 `grid1` 中也是陆地，则为子岛屿，返回子岛屿数目。

## 解题思路

DFS 遍历 grid2 的每个岛屿，同时检查对应 grid1 位置是否都是陆地。必须遍历完整个岛屿再判断（不能短路），用标志位记录是否满足子岛屿条件。

## Java 代码实现

```java
class Solution {
    private int[][] grid1, grid2;
    private int m, n;

    public int countSubIslands(int[][] grid1, int[][] grid2) {
        this.grid1 = grid1;
        this.grid2 = grid2;
        m = grid2.length;
        n = grid2[0].length;

        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid2[i][j] == 1 && dfs(i, j)) {
                    count++;
                }
            }
        }
        return count;
    }

    private boolean dfs(int i, int j) {
        if (i < 0 || i >= m || j < 0 || j >= n || grid2[i][j] == 0) return true;
        grid2[i][j] = 0; // 标记已访问
        boolean isSub = (grid1[i][j] == 1);
        // 必须全部递归完，不能短路
        boolean r1 = dfs(i, j + 1);
        boolean r2 = dfs(i, j - 1);
        boolean r3 = dfs(i + 1, j);
        boolean r4 = dfs(i - 1, j);
        return isSub && r1 && r2 && r3 && r4;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn)
- **空间复杂度**：O(mn)，递归栈

## 关键点总结

1. 子岛屿要求 grid2 中岛屿的所有格子在 grid1 中也是陆地
2. DFS 时不能短路，需标记所有格子后再综合判断
3. 将 grid2 对应位置置 0 标记已访问，避免重复
