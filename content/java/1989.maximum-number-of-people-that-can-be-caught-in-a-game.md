## 题目描述

整数数组 `team`（0 表示"鬼"，1 表示"人"），每个鬼可抓距离不超过 `dist` 的一个人，每个人只能被抓一次，返回鬼最多能抓住几个人。

## 解题思路

提取鬼和人的位置数组，用贪心双指针：若当前鬼与当前人距离 <= dist，则配对成功，两指针都前进；否则位置较小的一方前进（跳过无法配对者）。

## Java 代码实现

### 方法一：贪心双指针（推荐）

```java
import java.util.*;

class Solution {
    public int catchMaximumAmountofPeople(int[] team, int dist) {
        // 分别提取鬼和人的位置
        List<Integer> ghosts = new ArrayList<>();
        List<Integer> persons = new ArrayList<>();
        for (int i = 0; i < team.length; i++) {
            if (team[i] == 0) ghosts.add(i);
            else persons.add(i);
        }

        int count = 0;
        int g = 0, p = 0;
        while (g < ghosts.size() && p < persons.size()) {
            if (Math.abs(ghosts.get(g) - persons.get(p)) <= dist) {
                // 配对成功
                count++;
                g++;
                p++;
            } else if (ghosts.get(g) < persons.get(p)) {
                // 鬼的位置更靠左，当前鬼无法抓后面的人
                g++;
            } else {
                // 人的位置更靠左，当前人无法被后面的鬼抓
                p++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 提取位置后用双指针贪心，就近配对不会错过更优方案
2. 当前鬼（或人）位置更小且差距超 dist，则该鬼（或人）只能跳过
3. 条件 `Math.abs(g - p) <= dist`，注意是 `<=`
