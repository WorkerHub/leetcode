## 题目描述

称整数为"美丽数"当且仅当每一位非零数字 d 都整除该整数本身，返回 `[lo, hi]` 范围内美丽数的数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] digits;
    private Map<Long, Integer> memo;

    public int countBeautifulNumbers(int lo, int hi) {
        return count(hi) - count(lo - 1);
    }

    private int count(int n) {
        String s = String.valueOf(n);
        digits = new int[s.length()];
        for (int i = 0; i < digits.length; i++) digits[i] = s.charAt(i) - '0';
        memo = new HashMap<>();
        return dfs(0, 0, 1, true, false);
    }

    // numMod: current number mod 2520; lcm: lcm of placed digits (1=nothing yet, 0=invalid)
    private int dfs(int pos, int numMod, int lcm, boolean tight, boolean started) {
        if (lcm == 0) return 0; // contains digit 0
        if (pos == digits.length) return (started && numMod % lcm == 0) ? 1 : 0;

        if (!tight) {
            long key = (long) pos * 2521 * 2520 + (long) lcm * 2520 + numMod;
            if (started) key += 1_000_000_000L;
            Integer cached = memo.get(key);
            if (cached != null) return cached;
        }

        int lim = tight ? digits[pos] : 9, res = 0;
        for (int d = 0; d <= lim; d++) {
            int newMod = (numMod * 10 + d) % 2520;
            int newLcm;
            boolean newStarted = started || d > 0;
            if (!started && d == 0) newLcm = 1;      // 前导零
            else if (d == 0) newLcm = 0;              // 数字 0 → 非法
            else newLcm = lcm(lcm, d);
            res += dfs(pos + 1, newMod, newLcm, tight && d == lim, newStarted);
        }

        if (!tight) {
            long key = (long) pos * 2521 * 2520 + (long) lcm * 2520 + numMod;
            if (started) key += 1_000_000_000L;
            memo.put(key, res);
        }
        return res;
    }

    private int lcm(int a, int b) { return a / gcd(a, b) * b; }
    private int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
}
```

## 复杂度分析

- 时间复杂度：O(10 * L * max_lcm)，L 为位数，max_lcm <= 2520
- 空间复杂度：O(L * max_lcm)

## 关键点总结

1. 数位 DP：状态为 (pos, numMod2520, lcm, started)，tight 不计入记忆
2. 美丽数条件：不含数字 0，且数字 mod lcm == 0
3. 1-9 的 LCM 最大为 2520，numMod 对 2520 取模即可
