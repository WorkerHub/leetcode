## 题目描述

一群朋友在度假期间会相互借钱。比如，小爱同学支付了小新同学的午餐共计 10 美元。如果小明同学支付了小爱同学的出租车钱共计 5 美元。我们可以用一个三元组 `(x, y, z)` 表示一次交易，表示 `x` 借给 `y` 共计 `z` 美元。用 `0, 1, 2` 表示小爱同学、小新同学和小明同学（`0, 1, 2` 为朋友的 ID），交易记录为 `[[0, 1, 10], [2, 0, 5]]`。

给定一群人之间的交易记录列表，计算能够还清所有债务的最小次数。

**注意：**
1. 一次交易会以三元组 `(x, y, z)` 表示，并有 `x ≠ y` 且 `z > 0`。
2. 人的标识从 0 开始，可能不连续。

**示例 1：**
```
输入：transactions = [[0,1,10],[2,0,5]]
输出：2
解释：
人物 0 给人物 1 共计 10 美元。
人物 2 给人物 0 共计 5 美元。

需要两次交易。一种方式是人物 1 分别给人物 0 和人物 2 各 5 美元。
```

**示例 2：**
```
输入：transactions = [[0,1,10],[1,0,1],[1,2,5],[2,0,5]]
输出：1
解释：
人物 0 给人物 1 共计 10 美元。
人物 1 给人物 0 共计 1 美元。
人物 1 给人物 2 共计 5 美元。
人物 2 给人物 0 共计 5 美元。

因此，人物 1 只需要给人物 0 共计 4 美元，所有的债务即可还清。
```

**提示：**
- `1 <= transactions.length <= 8`
- `transactions[i].length == 3`
- `0 <= fromi, toi < 12`
- `fromi != toi`
- `1 <= amounti <= 100`

## 解题思路

这是一道经典的**账务平衡问题**，本质是图论中的**多商品流问题**，但规模较小可用回溯求解。

**核心观察：**
1. 先计算每个人的净债务（收入 - 支出）
2. 净债务为正表示别人欠他钱，为负表示他欠别人钱
3. 问题转化为：用最少的交易次数使所有净债务归零

**关键性质：**
- 如果有 n 个人有非零债务，最多需要 n-1 次交易就能平衡
- 目标是找到更少的交易次数

**算法思路：**
1. 计算每个人的净债务
2. 过滤掉净债务为 0 的人（已平衡）
3. 使用回溯法尝试不同的配对方式
4. 每次配对使一个或两个人的债务归零

**优化策略：**
- 如果两个人的净债务相反（一正一负且绝对值相等），一次交易即可抵消
- 优先处理能完全抵消的配对

## Java 代码实现

### 方法一：回溯法（推荐）⭐

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int minTransfers(int[][] transactions) {
        // 步骤 1：计算每个人的净债务
        Map<Integer, Integer> balance = new HashMap<>();
        for (int[] t : transactions) {
            balance.merge(t[0], -t[2], Integer::sum);  // from_p 支出
            balance.merge(t[1], t[2], Integer::sum);   // to_p 收入
        }

        // 步骤 2：过滤掉净债务为 0 的人
        List<Integer> debtsList = new ArrayList<>();
        for (int b : balance.values()) {
            if (b != 0) debtsList.add(b);
        }

        int[] debts = new int[debtsList.size()];
        for (int i = 0; i < debtsList.size(); i++) {
            debts[i] = debtsList.get(i);
        }

        // 步骤 3：回溯求解最少交易次数
        return backtrack(debts, 0);
    }

    private int backtrack(int[] debts, int idx) {
        // 跳过已平衡的人
        while (idx < debts.length && debts[idx] == 0) {
            idx++;
        }

        // 所有人都已平衡
        if (idx == debts.length) {
            return 0;
        }

        int minTransfers = Integer.MAX_VALUE / 2;

        // 尝试与后面的人配对
        for (int i = idx + 1; i < debts.length; i++) {
            // 只配对相反符号的债务（一个欠钱，一个要钱）
            if ((long) debts[idx] * debts[i] < 0) {
                // 配对：将 idx 的债务转移给 i
                debts[i] += debts[idx];

                // 递归处理下一个人
                minTransfers = Math.min(minTransfers, 1 + backtrack(debts, idx + 1));

                // 回溯
                debts[i] -= debts[idx];
            }
        }

        return minTransfers;
    }
}
```

**核心技巧：**
- `debts[i] += debts[idx]`：将 idx 的债务转移给 i
- `debts[idx] * debts[i] < 0`：确保一正一负才配对

### 方法二：优化回溯（优先完全抵消）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int minTransfers(int[][] transactions) {
        // 计算净债务
        Map<Integer, Integer> balance = new HashMap<>();
        for (int[] t : transactions) {
            balance.merge(t[0], -t[2], Integer::sum);
            balance.merge(t[1], t[2], Integer::sum);
        }

        List<Integer> debtsList = new ArrayList<>();
        for (int b : balance.values()) {
            if (b != 0) debtsList.add(b);
        }

        int n = debtsList.size();
        int[] debts = new int[n];
        for (int i = 0; i < n; i++) {
            debts[i] = debtsList.get(i);
        }

        // 优化：优先处理能完全抵消的配对
        return backtrack(debts, 0, n);
    }

    private int backtrack(int[] debts, int idx, int n) {
        while (idx < n && debts[idx] == 0) {
            idx++;
        }

        if (idx == n) return 0;

        int minCount = Integer.MAX_VALUE / 2;

        for (int i = idx + 1; i < n; i++) {
            if ((long) debts[idx] * debts[i] < 0) {
                // 保存原值
                int original = debts[i];
                debts[i] += debts[idx];

                // 无论是否完全抵消，递归求解
                minCount = Math.min(minCount, 1 + backtrack(debts, idx + 1, n));

                // 回溯
                debts[i] = original;

                // 剪枝：如果完全抵消，这通常是最优选择
                if (debts[i] + debts[idx] == 0) break;
            }
        }

        return minCount;
    }
}
```

### 方法三：状态压缩 DP（理论最优）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int minTransfers(int[][] transactions) {
        // 计算净债务
        Map<Integer, Integer> balance = new HashMap<>();
        for (int[] t : transactions) {
            balance.merge(t[0], -t[2], Integer::sum);
            balance.merge(t[1], t[2], Integer::sum);
        }

        List<Integer> debtsList = new ArrayList<>();
        for (int b : balance.values()) {
            if (b != 0) debtsList.add(b);
        }

        int n = debtsList.size();
        int[] debts = new int[n];
        for (int i = 0; i < n; i++) {
            debts[i] = debtsList.get(i);
        }

        // 预处理：哪些子集可以内部平衡（总和为 0）
        boolean[] canBalance = new boolean[1 << n];
        for (int mask = 0; mask < (1 << n); mask++) {
            int total = 0;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    total += debts[i];
                }
            }
            canBalance[mask] = (total == 0);
        }

        // DP
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE / 2) continue;

            // 找到第一个未处理的人
            int first = -1;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0) {
                    first = i;
                    break;
                }
            }

            if (first == -1) continue;

            // 枚举包含 first 的未处理人的子集
            int remaining = ((1 << n) - 1) & ~mask;
            for (int sub = remaining; sub != 0; sub = (sub - 1) & remaining) {
                if ((sub & (1 << first)) != 0 && canBalance[sub]) {
                    // sub 是可以内部平衡的子集，需要 bitCount - 1 次交易
                    int peopleCount = Integer.bitCount(sub);
                    dp[mask | sub] = Math.min(dp[mask | sub], dp[mask] + peopleCount - 1);
                }
            }
        }

        return dp[(1 << n) - 1];
    }
}
```

**注意：** 状态压缩 DP 实现复杂，实际面试中回溯法更实用

## 复杂度分析

**方法一（回溯）：**
- 时间复杂度：O(n!)，最坏情况下尝试所有配对
- 空间复杂度：O(n)，递归栈

**方法二（优化回溯）：**
- 时间复杂度：O(n!)，但剪枝后实际更快
- 空间复杂度：O(n)

**方法三（状态压缩 DP）：**
- 时间复杂度：O(3^n)，枚举子集
- 空间复杂度：O(2^n)

**实际应用：** 由于 `n <= 12`（净债务人数），回溯法完全可行

## 图解示例

以 `transactions = [[0,1,10],[2,0,5]]` 为例：

```
步骤 1：计算净债务
人 0: -10 + 5 = -5 （欠 5 美元）
人 1: +10 = +10 （要收 10 美元）
人 2: -5 （欠 5 美元）

步骤 2：债务列表
debts = [-5, 10, -5]

步骤 3：回溯配对
方案 1：
  - 人 0（-5）给人 1，人 1 变为 +5
  - 人 2（-5）给人 1，人 1 变为 0
  - 共 2 次交易

方案 2：
  - 人 0（-5）给人 1（+10），人 1 变为 +5，人 0 归零
  - 人 2（-5）给人 1（+5），两人都归零
  - 共 2 次交易

最少交易数 = 2
```

## 关键点总结

1. **净债务计算：** 收入 - 支出，简化问题
2. **只关心非零债务：** 过滤掉已平衡的人
3. **回溯配对：** 尝试不同的债务合并方式
4. **符号相反才配对：** 一正一负才能抵消
5. **优化剪枝：** 优先处理能完全抵消的配对

## 易错点

1. **忘记过滤零债务：** 包含已平衡的人会影响结果
   ```java
   // 错误
   for (int b : balance.values()) debtsList.add(b);

   // 正确
   for (int b : balance.values()) {
       if (b != 0) debtsList.add(b);
   }
   ```

2. **配对条件错误：** 允许同号债务配对
   ```java
   // 错误：同号也配对，无法抵消
   for (int i = idx + 1; i < n; i++) {
       debts[i] += debts[idx];
   }

   // 正确：只配对异号
   if ((long) debts[idx] * debts[i] < 0) {
       debts[i] += debts[idx];
   }
   ```

3. **回溯忘记恢复：** 修改 debts 后必须回溯
   ```java
   // 错误
   debts[i] += debts[idx];
   backtrack(debts, idx + 1, n);
   // 缺少恢复

   // 正确
   debts[i] += debts[idx];
   backtrack(debts, idx + 1, n);
   debts[i] -= debts[idx];  // 回溯
   ```

4. **理解题意：** 最少交易次数 ≠ 最少金额，是次数
