## 题目描述

给你一个加权有向图，边集 `edges[i] = [u, v, w]`，经过中间节点 v（非起终点）时需额外支付 `cost[v]`。返回从节点 0 到节点 n-1 的最小总代价。

## 解题思路

Dijkstra：将节点代价等价为增加入边权重——到达非终点节点 v 时代价加 `cost[v]`。标准 Dijkstra 即可解决。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumCost(int n, int[][] edges, int[] cost) {
        List<long[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            // 将节点代价分摊到入边（终点不加）
            long nodeCost = (e[1] == n - 1) ? 0 : cost[e[1]];
            graph[e[0]].add(new long[]{e[1], e[2] + nodeCost});
        }

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0]; int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (long[] e : graph[u]) {
                int v = (int) e[0];
                long nd = d + e[1];
                if (nd < dist[v]) { dist[v] = nd; pq.offer(new long[]{nd, v}); }
            }
        }
        return dist[n - 1] == Long.MAX_VALUE ? -1 : dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)
- 空间复杂度：O(V + E)

## 关键点总结

1. 节点代价等价于增加入边权重
2. 终点 n-1 不需要加额外代价
3. 使用 long 防止溢出
