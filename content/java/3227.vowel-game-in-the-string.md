## 题目描述

Alice 和 Bob 交替从字符串取子串（Alice 取两端都是元音的子串，Bob 取两端都是辅音的子串），不能操作者输，Alice 先手，返回 Alice 是否能赢。

## Java 代码实现

```java
class Solution {
    public boolean doesAliceWin(String s) {
        // 博弈结果只取决于元音数量的奇偶性
        // Alice 可以每次取单个元音字母，元音为奇数时 Alice 必胜
        int vowelCount = 0;
        for (char c : s.toCharArray()) {
            if ("aeiou".indexOf(c) >= 0) vowelCount++;
        }
        return vowelCount % 2 == 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 博弈结果只取决于元音数量的奇偶性
2. Alice 总能取单个元音字母（满足两端都是元音的条件）
3. 元音奇数时 Alice 必胜，偶数（含 0）时 Bob 必胜
