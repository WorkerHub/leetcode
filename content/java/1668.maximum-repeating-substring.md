## 题目描述

给你字符串 `sequence` 和 `word`，返回 `word` 重复 `k` 次（`word*k`）是 `sequence` 子串的最大 `k`。

## 解题思路

**暴力枚举：** 从 k=0 开始，检查 `word*(k+1)` 是否是 `sequence` 的子串，找最大 k。

**DP：** `dp[i]` = 以 `sequence[i]` 结尾，`word` 连续重复的最大次数。

## Java 代码实现

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int k = 0;
        int maxK = sequence.length() / word.length();
        String repeated = "";
        for (int i = 1; i <= maxK; i++) {
            repeated += word;
            if (sequence.contains(repeated)) k = i;
            else break; // 更长的重复更难出现
        }
        return k;
    }
}
```

### 方法二：DP

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int n = sequence.length(), m = word.length();
        if (n < m) return 0;

        int[] dp = new int[n];
        int ans = 0;

        for (int i = m - 1; i < n; i++) {
            // 检查 sequence[i-m+1..i] 是否等于 word
            if (sequence.substring(i - m + 1, i + 1).equals(word)) {
                dp[i] = (i >= m ? dp[i - m] : 0) + 1;
                ans = Math.max(ans, dp[i]);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：暴力 O(n^2/m)，DP O(n*m)
- **空间复杂度**：暴力 O(n)，DP O(n)

## 关键点总结

1. 暴力法简洁，遇到不包含时可提前 break
2. DP：`dp[i] = dp[i-m] + 1`（若当前位置结束的 m 长度子串等于 word）
3. Java 中字符串包含用 `contains`，比较用 `equals`
