## 题目描述

给你整数数组 `nums`，可以任意重排，令前 i+1 个元素前缀和 > 0 的个数为得分，返回最大得分。

## 解题思路

降序排序后计算前缀和，统计前缀和 > 0 的个数；一旦前缀和 <= 0 可提前终止，后续更小的元素不会改变结果。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxScore(int[] nums) {
        Arrays.sort(nums);
        // 逆序（降序）
        int n = nums.length;
        int score = 0;
        long prefix = 0;
        for (int i = n - 1; i >= 0; i--) {
            prefix += nums[i];
            if (prefix > 0) score++;
            else break; // 后续更小，前缀和只会更小
        }
        return score;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 降序排列是最优贪心：大数在前使前缀和保持正数最长
2. 前缀和用 `long` 防止溢出
3. 前缀和 <= 0 时提前终止，后续不可能再有正值
