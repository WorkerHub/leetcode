## 题目描述

给你整数数组 `nums` 和整数 `k`，将数组分割为子数组，子数组代价为 `k + trim(子数组)` 的长度（trim 指删去恰好出现一次的元素），返回最小总代价。

## 解题思路

DP：`dp[i]` = 分割 `nums[0..i-1]` 的最小代价。枚举子数组起点 j，从右到左维护哈希表统计 `importance`（某元素第 2 次出现 +2，第 3+ 次 +1），转移取最小值。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int minCost(int[] nums, int k) {
        int n = nums.length;
        int[] dp = new int[n + 1];
        final int INF = Integer.MAX_VALUE / 2;
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            dp[i] = INF;
            Map<Integer, Integer> freq = new HashMap<>();
            int importance = 0;
            // 枚举子数组 nums[j..i-1]，从右到左扩展
            for (int j = i - 1; j >= 0; j--) {
                int f = freq.getOrDefault(nums[j], 0) + 1;
                freq.put(nums[j], f);
                if (f == 2) importance += 2;       // 第二次出现，+2
                else if (f > 2) importance += 1;   // 第三次及以后，+1
                if (dp[j] < INF) {
                    dp[i] = Math.min(dp[i], dp[j] + k + importance);
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. `importance` = 出现 >= 2 次的元素在子数组中的位置总数
2. 维护 importance 的增量：元素第 2 次出现 +2，之后每次 +1
3. DP 转移枚举子数组起点，动态维护 importance 避免重复计算
