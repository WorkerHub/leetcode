## 题目描述

给你 `m×n` 矩阵 `grid` 和查询数组 `queries`，对每个查询从 `(0,0)` 出发，只能进入值严格小于查询值的单元格，返回各查询可访问的单元格数。

## 解题思路

离线处理：将查询按值从小到大排序，用最小堆维护待扩展单元格。随着查询值增大，逐步弹出堆中值 < 当前查询的格子并扩展邻居，前一查询的结果可直接复用。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maxPoints(int[][] grid, int[] queries) {
        int m = grid.length, n = grid[0].length;
        int k = queries.length;

        // 将查询附上原始下标后排序
        Integer[] qIdx = new Integer[k];
        for (int i = 0; i < k; i++) qIdx[i] = i;
        Arrays.sort(qIdx, (a, b) -> queries[a] - queries[b]);

        // 最小堆：[格子值, 行, 列]
        PriorityQueue<int[]> heap = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        boolean[][] visited = new boolean[m][n];
        heap.offer(new int[]{grid[0][0], 0, 0});
        visited[0][0] = true;

        int[] ans = new int[k];
        int count = 0;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        for (int i : qIdx) {
            int q = queries[i];
            // 弹出所有值 < q 的格子，扩展邻居
            while (!heap.isEmpty() && heap.peek()[0] < q) {
                int[] cur = heap.poll();
                count++;
                for (int[] d : dirs) {
                    int nr = cur[1] + d[0], nc = cur[2] + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                        visited[nr][nc] = true;
                        heap.offer(new int[]{grid[nr][nc], nr, nc});
                    }
                }
            }
            ans[i] = count;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((mn + k) log(mn))
- **空间复杂度**：O(mn + k)

## 关键点总结

1. 离线排序后，查询结果单调不减，可以复用前一查询的计数
2. 最小堆保证每次弹出的格子值最小，自然满足 < q 的扩展条件
3. 邻居入堆时即标记已访问，防止重复入堆
