## 题目描述

给你一个链表的头节点 `head` 和一个特定值 `x`，请你对链表进行分隔，使得所有小于 `x` 的节点都出现在大于或等于 `x` 的节点之前。

你应当保留两个分区中每个节点的初始相对位置。

**示例 1：**
```
输入：head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]
```

**示例 2：**
```
输入：head = [2,1], x = 2
输出：[1,2]
```

**提示：**
- 链表中节点的数目在范围 `[0, 200]` 内
- `-100 <= Node.val <= 100`
- `-200 <= x <= 200`

## 解题思路

核心思想：使用两个虚拟头节点，分别构建小于 x 和大于等于 x 的两个链表，最后将它们连接起来。

**算法流程：**
1. 创建两个虚拟头节点 `smallDummy` 和 `largeDummy`
2. 使用两个指针 `small` 和 `large` 分别指向两个链表的尾部
3. 遍历原链表，根据节点值与 x 的大小关系，将节点分别接到对应链表后
4. 将小链表的尾部连接到大链表的头部
5. 注意将大链表的尾部指向 null，避免环

**关键观察：**
- 不需要改变节点的相对顺序，只需要按条件分组
- 使用虚拟头节点可以简化边界处理
- 最后需要断开大链表的尾部，防止成环

## Java 代码实现

### 方法一：双指针（推荐）

```java
// Definition for singly-linked list.
// public class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public ListNode partition(ListNode head, int x) {
        // 创建两个虚拟头节点
        ListNode smallDummy = new ListNode(0);
        ListNode largeDummy = new ListNode(0);

        // small 和 large 分别指向两个链表的尾部
        ListNode small = smallDummy;
        ListNode large = largeDummy;

        // 遍历原链表
        ListNode current = head;
        while (current != null) {
            if (current.val < x) {
                // 将节点接到小链表后
                small.next = current;
                small = small.next;
            } else {
                // 将节点接到大链表后
                large.next = current;
                large = large.next;
            }
            current = current.next;
        }

        // 关键：断开大链表的尾部，防止成环
        large.next = null;

        // 将小链表的尾部连接到大链表的头部
        small.next = largeDummy.next;

        return smallDummy.next;
    }
}
```

### 方法二：原地修改（空间优化）

```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        // 边界情况
        if (head == null || head.next == null) {
            return head;
        }

        // 虚拟头节点
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // prev 指向小于 x 的最后一个节点
        ListNode prev = dummy;
        while (prev.next != null && prev.next.val < x) {
            prev = prev.next;
        }

        // current 从 prev 的下一个节点开始
        ListNode current = prev.next;

        // 遍历链表，将小于 x 的节点移到前面
        while (current != null && current.next != null) {
            if (current.next.val < x) {
                // 将 current.next 节点移到 prev 后面
                ListNode temp = current.next;
                current.next = temp.next;
                temp.next = prev.next;
                prev.next = temp;
                prev = prev.next;
            } else {
                current = current.next;
            }
        }

        return dummy.next;
    }
}
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：O(n)，遍历链表一次
- 空间复杂度：O(1)，只使用了常数个额外节点

**方法二（原地修改）：**
- 时间复杂度：O(n)，遍历链表一次
- 空间复杂度：O(1)，原地修改

## 关键点总结

1. **虚拟头节点**：简化边界处理，避免空指针判断
2. **双链表构建**：分别维护小于和大于等于 x 的两个链表
3. **断尾操作**：必须将大链表的尾部指向 null，防止成环
4. **保持顺序**：按原顺序依次添加到对应链表，自然保持相对位置

## 易错点

1. **忘记断尾**：如果不将 `large.next = null`，可能会形成环
2. **连接顺序**：应该是 `small.next = largeDummy.next`，而不是 `largeDummy`
3. **空链表处理**：使用虚拟头节点可以自动处理空链表情况
4. **节点复用**：直接移动原节点，不需要创建新节点
5. **Java 中 null 检查**：遍历时必须检查 `current != null`
