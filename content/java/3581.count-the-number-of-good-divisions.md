## 题目描述

给定字符串数组 `words`，将其分成若干连续组，每组的第一个字符串的首字母等于最后一个字符串的末字母，求满足条件的分组方式数量，对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countGoodDivisions(String[] words) {
        int MOD = 1_000_000_007;
        int n = words.length;
        long[] dp = new long[n + 1];
        dp[0] = 1;

        // firstCharSum[c] = sum of dp[j] where words[j][0] == c
        long[] firstCharSum = new long[26];
        firstCharSum[words[0].charAt(0) - 'a'] = dp[0];

        for (int i = 1; i <= n; i++) {
            char lastChar = words[i - 1].charAt(words[i - 1].length() - 1);
            dp[i] = firstCharSum[lastChar - 'a'] % MOD;

            if (i < n) {
                int fc = words[i].charAt(0) - 'a';
                firstCharSum[fc] = (firstCharSum[fc] + dp[i]) % MOD;
            }
        }
        return (int) dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(n)，DP 数组

## 关键点总结

1. 合法组条件：起始单词首字母 = 末尾单词末字母
2. 用哈希表（26 个字母）按首字母维护 dp 前缀和，O(1) 查询
3. 状态转移：`dp[i] = sum(dp[j] where words[j][0] == words[i-1][-1])`
