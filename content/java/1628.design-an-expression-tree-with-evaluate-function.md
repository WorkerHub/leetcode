## 题目描述

给你算术表达式的**后缀表示法**（逆波兰表达式），设计将其转化为表达式树的算法，并实现 `evaluate()` 函数计算树的值。叶节点是操作数，非叶节点是运算符（`+`、`-`、`*`、`/`）。

**示例：**
- 输入：`["3","4","+","2","*","7","/"]` 输出：`2`（即 `((3+4)*2)/7`）

## 解题思路

**构建：** 用栈处理后缀表达式，遇到数字创建叶节点压栈，遇到运算符弹出两个节点作为左右子树。

**求值：** 叶节点返回数字，非叶节点递归计算左右子树后应用运算符。

## Java 代码实现

```java
/**
 * 抽象节点接口（题目已定义）
 */
abstract class Node {
    public abstract int evaluate();
}

// 数字叶节点
class NumNode extends Node {
    private int val;
    public NumNode(int val) { this.val = val; }

    @Override
    public int evaluate() { return val; }
}

// 运算符节点
class OpNode extends Node {
    private char op;
    private Node left, right;

    public OpNode(char op, Node left, Node right) {
        this.op = op;
        this.left = left;
        this.right = right;
    }

    @Override
    public int evaluate() {
        int l = left.evaluate();
        int r = right.evaluate();
        switch (op) {
            case '+': return l + r;
            case '-': return l - r;
            case '*': return l * r;
            case '/': return l / r; // 向零截断
            default: return 0;
        }
    }
}

class TreeBuilder {
    public Node buildTree(String[] postfix) {
        Deque<Node> stack = new ArrayDeque<>();
        Set<Character> ops = new HashSet<>(Arrays.asList('+', '-', '*', '/'));

        for (String token : postfix) {
            char c = token.charAt(0);
            if (ops.contains(c) && token.length() == 1) {
                // 运算符：弹出右、左操作数
                Node right = stack.pop();
                Node left = stack.pop();
                stack.push(new OpNode(c, left, right));
            } else {
                // 数字：创建叶节点
                stack.push(new NumNode(Integer.parseInt(token)));
            }
        }
        return stack.peek();
    }
}
```

## 复杂度分析

- **时间复杂度**：buildTree O(n)，evaluate O(n)
- **空间复杂度**：O(n)，n 为 token 数

## 关键点总结

1. 后缀表达式用栈构建表达式树
2. 注意右操作数先弹出（后缀中右操作数更后进栈）
3. 除法向零截断，Java 的 `/` 对整数直接截断，无需额外处理
4. 递归求值，叶节点返回数字值
