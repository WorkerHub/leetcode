## 题目描述

子序列的宽度定义为最大值与最小值之差。返回数组所有非空子序列宽度之和（对 10^9+7 取模）。

**示例：**
```
输入：nums = [2,1,3]
输出：6
```

## 解题思路

排序后，nums[i] 作为最大值出现 2^i 次，作为最小值出现 2^(n-1-i) 次。每个元素的贡献为 nums[i] × (2^i - 2^(n-1-i))。

## Java 代码实现

```java
class Solution {
    public int sumSubseqWidths(int[] nums) {
        int MOD = 1_000_000_007;
        int n = nums.length;
        Arrays.sort(nums);

        // 预计算 2 的幂
        long[] pow2 = new long[n];
        pow2[0] = 1;
        for (int i = 1; i < n; i++) {
            pow2[i] = (pow2[i - 1] * 2) % MOD;
        }

        long result = 0;
        for (int i = 0; i < n; i++) {
            // 作为最大值 - 作为最小值
            result = (result + nums[i] * (pow2[i] - pow2[n - 1 - i])) % MOD;
        }

        return (int) ((result + MOD) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **排序**：确定每个元素作为最大/最小值的次数
2. **组合数学**：含 nums[i] 的子序列中它是最大值的有 2^i 个
3. **取模**：注意负数取模要加 MOD
