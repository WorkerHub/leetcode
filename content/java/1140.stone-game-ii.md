## 题目描述

石子游戏 II：piles[i] 表示第 i 堆石子数。Alice 先手，M 初始为 1。每回合可拿前 X 堆（1<=X<=2M），然后 M=max(M,X)。双方最优策略，返回 Alice 最大得分。

**示例：**
```
输入：piles = [2,7,9,4,4]
输出：10
```

## 解题思路

博弈 DP：`dp[i][m]` 表示从位置 i 开始、M=m 时先手最大收益。利用后缀和：先手收益 = suffixSum[i] - 对手最优收益。`dp[i][m] = max(suffix[i] - dp[i+x][max(m,x)])` 对所有 1<=x<=2m。

## Java 代码实现

```java
class Solution {
    public int stoneGameII(int[] piles) {
        int n = piles.length;

        // 后缀和
        int[] suffix = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suffix[i] = suffix[i + 1] + piles[i];
        }

        // dp[i][m]：从位置 i、M=m 时先手最大收益
        int[][] dp = new int[n + 1][n + 1];

        // 从后往前填表
        for (int i = n - 1; i >= 0; i--) {
            for (int m = 1; m <= n; m++) {
                if (i + 2 * m >= n) {
                    // 可以全拿
                    dp[i][m] = suffix[i];
                } else {
                    // 枚举拿 x 堆
                    for (int x = 1; x <= 2 * m; x++) {
                        int newM = Math.max(m, x);
                        dp[i][m] = Math.max(dp[i][m], suffix[i] - dp[i + x][newM]);
                    }
                }
            }
        }

        return dp[0][1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **博弈转化**：先手收益 = 剩余总和 - 对手最优收益
2. **后缀和**：`suffix[i]` 快速得到从 i 到末尾的总和
3. **边界条件**：`i + 2*m >= n` 时可以全拿
4. **M 单调不减**：`newM = max(m, x)`，状态空间有限
5. **自底向上**：从末尾往前填表，保证子问题已解决
