## 题目描述

从数组 `nums` 中选两个下标不同的数，使其数位和相等且两数之和最大，返回最大和，不存在则返回 -1。

## 解题思路

哈希表按数位和分组，对每组只需维护当前遇到的最大值。遍历时若当前数与已有最大值同组，则更新答案并更新组内最大值。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maximumSum(int[] nums) {
        Map<Integer, Integer> best = new HashMap<>(); // 数位和 -> 该组最大数
        int ans = -1;
        for (int x : nums) {
            int ds = digitSum(x);
            if (best.containsKey(ds)) {
                ans = Math.max(ans, best.get(ds) + x); // 更新答案
                best.put(ds, Math.max(best.get(ds), x)); // 更新组内最大值
            } else {
                best.put(ds, x);
            }
        }
        return ans;
    }

    private int digitSum(int x) {
        int s = 0;
        while (x > 0) { s += x % 10; x /= 10; }
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(max_num))
- **空间复杂度**：O(n)

## 关键点总结

1. 按数位和分组，每组内找最大两数之和。
2. 遍历时先用 `best[ds] + x` 更新答案，再更新 `best[ds]`，顺序不能反。
3. 数位和最大为 9×10=90（最大 10^9），哈希表空间有限。
