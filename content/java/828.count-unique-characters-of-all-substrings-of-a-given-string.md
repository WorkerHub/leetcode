## 题目描述

我们定义了一个函数 `countUniqueChars(s)` 来统计字符串 `s` 中的唯一字符，并返回唯一字符的个数。

例如：`s = "LEETCODE"`，则其中 `"L"`, `"T"`, `"C"`, `"O"`, `"D"` 都是唯一字符，因为它们只出现一次，所以 `countUniqueChars(s) = 5`。

本题将会给你一个字符串 `s`，我们需要返回 `countUniqueChars(t)` 的总和，其中 `t` 是 `s` 的子字符串。

**示例 1:**
```
输入: s = "ABC"
输出: 10
```

**示例 2:**
```
输入: s = "ABA"
输出: 8
```

**示例 3:**
```
输入: s = "LEETCODE"
输出: 92
```

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int uniqueLetterString(String s) {
        int n = s.length();

        // 记录每个字符出现的位置
        Map<Character, List<Integer>> pos = new HashMap<>();
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            pos.computeIfAbsent(c, k -> new ArrayList<>()).add(i);
        }

        int result = 0;

        for (List<Integer> indices : pos.values()) {
            // 在首尾添加虚拟位置
            int size = indices.size();

            for (int i = 0; i < size; i++) {
                // 左边界：前一个相同字符的位置（或 -1）
                int left = (i > 0) ? indices.get(i - 1) : -1;
                // 右边界：后一个相同字符的位置（或 n）
                int right = (i < size - 1) ? indices.get(i + 1) : n;

                int curr = indices.get(i);
                // 贡献 = 左边可选范围 × 右边可选范围
                result += (curr - left) * (right - curr);
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贡献法**：计算每个字符在多少子串中唯一
2. **位置记录**：记录每个字符的所有位置
3. **乘法原理**：左右区间长度相乘
