## 题目描述

将数组分为三个非空部分 `nums1, nums2, nums3`，若 `nums1` 是 `nums2` 的前缀或 `nums2` 是 `nums3` 的前缀，则为"美丽分割"，返回美丽分割的数量。

## Java 代码实现

```java
class Solution {
    public int beautifulSplits(int[] nums) {
        int n = nums.length;

        // lcp[i][j] = nums[i:] 和 nums[j:] 的最长公共前缀
        int[][] lcp = new int[n + 1][n + 1];
        // 从右往左、从下往上填充
        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (nums[i] == nums[j]) {
                    lcp[i][j] = lcp[i + 1][j + 1] + 1;
                } else {
                    lcp[i][j] = 0;
                }
            }
        }

        int ans = 0;
        // nums1=nums[0:i], nums2=nums[i:j], nums3=nums[j:n]
        for (int i = 1; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                int len1 = i, len2 = j - i, len3 = n - j;
                // 条件1：nums1 是 nums2 的前缀
                boolean cond1 = (len1 <= len2) && (lcp[0][i] >= len1);
                // 条件2：nums2 是 nums3 的前缀
                boolean cond2 = (len2 <= len3) && (lcp[i][j] >= len2);
                if (cond1 || cond2) ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，LCP 预计算与枚举均为 O(n^2)
- 空间复杂度：O(n^2)，LCP 数组

## 关键点总结

1. `lcp[i][j]` 表示 `nums[i:]` 和 `nums[j:]` 的最长公共前缀，用 DP 预计算。
2. 判断 A 是 B 的前缀：`len(A) <= len(B)` 且 `lcp[startA][startB] >= len(A)`。
3. LCP 从右下角往左上角填充（依赖 `lcp[i+1][j+1]`）。
