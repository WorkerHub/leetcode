## 题目描述

给定只含 `1` 和 `-1` 的数组 `nums` 和整数 `k`，每次操作可选长度为 `k` 的子数组将所有元素取反，判断是否可使所有元素相等。

## Java 代码实现

```java
class Solution {
    public boolean canBeEqual(int[] nums, int k) {
        return canAll(nums, k, 1) || canAll(nums, k, -1);
    }

    private boolean canAll(int[] nums, int k, int target) {
        int n = nums.length;
        // diff[i] 记录 i 位置的取反次数奇偶变化
        int[] diff = new int[n + 1];
        int flip = 0;

        for (int i = 0; i < n; i++) {
            flip ^= diff[i];
            int actual = (flip == 0) ? nums[i] : -nums[i];
            if (actual != target) {
                // 需要取反以 i 开始的长度 k 子数组
                if (i + k > n) return false;
                diff[i] ^= 1;
                diff[i + k] ^= 1;
                flip ^= 1;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，差分数组单次遍历
- 空间复杂度：O(n)，差分数组

## 关键点总结

1. 贪心：从左到右，遇到不符合目标的元素立即取反包含该位置的子数组
2. 差分数组避免重复修改每个元素，O(1) 维护区间翻转状态
3. 分别尝试目标为全 1 和全 -1 两种情况
