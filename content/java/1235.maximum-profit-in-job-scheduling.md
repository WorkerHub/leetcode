## 题目描述

n 份兼职工作，每份有开始时间、结束时间和报酬。时间重叠的工作不能同时做。求最大报酬。

**示例：**
```
输入：startTime = [1,2,3,3], endTime = [3,4,5,6], profit = [50,10,40,70]
输出：120（选第 1 和第 4 份：[1-3]+[3-6] = 50+70）
```

## 解题思路

按结束时间排序。dp[i] = 考虑前 i 个工作的最大报酬。对于第 i 个工作：不做则 dp[i-1]；做则 profit[i] + dp[j]（j 为最后一个不冲突的工作，用二分查找）。

## Java 代码实现

```java
class Solution {
    public int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
        int n = startTime.length;
        int[][] jobs = new int[n][3];
        for (int i = 0; i < n; i++) {
            jobs[i] = new int[]{endTime[i], startTime[i], profit[i]};
        }
        // 按结束时间排序
        Arrays.sort(jobs, (a, b) -> a[0] - b[0]);
        
        // dp[i] = 前 i 个工作的最大报酬
        int[] dp = new int[n + 1];
        
        for (int i = 1; i <= n; i++) {
            int end = jobs[i - 1][0];
            int start = jobs[i - 1][1];
            int p = jobs[i - 1][2];
            
            // 二分查找最后一个结束时间 <= start 的工作
            int j = binarySearch(jobs, i - 1, start);
            
            // 做或不做取最大值
            dp[i] = Math.max(dp[i - 1], dp[j] + p);
        }
        
        return dp[n];
    }
    
    // 查找 jobs[0..right-1] 中最后一个 endTime <= target 的索引+1
    private int binarySearch(int[][] jobs, int right, int target) {
        int lo = 0, hi = right;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (jobs[mid][0] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo; // lo 个工作的结束时间 <= target
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **按结束时间排序**：方便用二分查找不冲突的工作
2. **DP + 二分**：dp[i] = max(不做 dp[i-1], 做 profit[i]+dp[j])
3. **二分找前驱**：结束时间 ≤ 当前开始时间的最后一个工作
4. **加权区间调度**：经典 DP 问题
