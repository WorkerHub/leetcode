## 题目描述

给你整数数组 nums 和整数 k，每次操作可将任意元素加 1，要求每个长度 ≥ 3 的子数组中最大值 ≥ k，返回最少操作次数。

## 解题思路

条件等价于不存在连续 3 个元素都 < k。设 `dp[i]` = 将 nums[i] 提升至 >= k 时的最少总操作数，转移为 `dp[i] = cost(i) + min(dp[i-1], dp[i-2], dp[i-3])`，答案取最后三个 dp 的最小值。滚动数组优化空间至 O(1)。

## Java 代码实现

```java
class Solution {
    public long minIncrementOperations(int[] nums, int k) {
        int n = nums.length;
        // a, b, c 分别对应 dp[i-2], dp[i-1], dp[i]
        long a = Math.max(0, k - nums[0]);
        long b = Math.max(0, k - nums[1]);
        long c = Math.max(0, k - nums[2]);

        for (int i = 3; i < n; i++) {
            long cost = Math.max(0, k - nums[i]);
            long next = cost + Math.min(a, Math.min(b, c));
            a = b;
            b = c;
            c = next;
        }
        return Math.min(a, Math.min(b, c));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 问题等价：任意连续 3 个元素中至少有一个 >= k
2. dp[i] = cost(i) + min(dp[i-1], dp[i-2], dp[i-3])，保证最近三个中至少有一个达到 k
3. 答案取最后三个 dp 的最小值（最后一段窗口也要满足条件）
