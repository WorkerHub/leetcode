## 题目描述

给定一个由非负整数组成的数组 `heights`，表示直方图。假设每个柱子的宽度为 `1`。

在 `V` 单位的水落下后，返回直方图的高度。

水最初是从索引 `K` 处滴下。每次滴一单位的水时：

1. 首先，它尝试向左移动，如果能找到一个比当前位置低的位置，它会移动到最左边的最低位置。
2. 如果找不到这样的位置（即左边都更高或相同），它会尝试向右移动，如果能找到一个比当前位置低的位置，它会移动到最右边的最低位置。
3. 如果左右都找不到比当前位置低的地方，水滴会停留在当前位置。

**示例 1:**
```
输入: heights = [2,1,1,2,1,2,2], V = 4, K = 3
输出: [2,2,2,2,2,2,2]
```

**提示：**
- `1 <= heights.length <= 100`
- `0 <= heights[i] <= 99`
- `0 <= V <= 2000`
- `0 <= K < heights.length`

## 解题思路

这道题需要模拟水滴的流动过程。关键是理解水滴的移动规则：
1. 先尝试向左找最低点
2. 找不到再尝试向右找最低点
3. 都找不到就停在当前位置

**算法流程：**
1. 对于每一滴水（重复 V 次）：
   - 从位置 K 开始
   - 向左寻找最低点
   - 如果没找到，向右寻找最低点
   - 在找到的位置增加高度
2. 返回最终的高度数组

## Java 代码实现

### 方法一：模拟（推荐）

```java
class Solution {
    public int[] pourWater(int[] heights, int V, int K) {
        // 滴 V 次水
        for (int v = 0; v < V; v++) {
            int pos = K;
            // 尝试向左
            for (int i = K - 1; i >= 0; i--) {
                if (heights[i] > heights[pos]) break;
                if (heights[i] < heights[pos]) pos = i;
            }
            // 如果向左找到了更低的位置，停在那
            if (pos != K) {
                heights[pos]++;
                continue;
            }
            // 尝试向右
            for (int i = K + 1; i < heights.length; i++) {
                if (heights[i] > heights[pos]) break;
                if (heights[i] < heights[pos]) pos = i;
            }
            // 增加高度（无论向右是否找到，都在 pos 处增加）
            heights[pos]++;
        }
        return heights;
    }
}
```

### 方法二：详细注释版（易理解）

```java
class Solution {
    public int[] pourWater(int[] heights, int V, int K) {
        int n = heights.length;

        for (int v = 0; v < V; v++) {
            // 阶段 1: 尝试向左流动，找左边最低且最左的位置
            int leftLowest = K;
            for (int i = K - 1; i >= 0; i--) {
                if (heights[i] > heights[leftLowest]) {
                    // 遇到更高的墙，无法继续向左
                    break;
                } else if (heights[i] < heights[leftLowest]) {
                    // 找到更低的位置
                    leftLowest = i;
                }
                // 如果相等，继续向左看（为了找到最左边的最低点）
            }

            // 如果向左找到了更低的位置，水滴停在那里
            if (heights[leftLowest] < heights[K]) {
                heights[leftLowest]++;
                continue;
            }

            // 阶段 2: 如果向左找不到，尝试向右流动
            int rightLowest = K;
            for (int i = K + 1; i < n; i++) {
                if (heights[i] > heights[rightLowest]) {
                    // 遇到更高的墙，无法继续向右
                    break;
                } else if (heights[i] < heights[rightLowest]) {
                    // 找到更低的位置
                    rightLowest = i;
                }
            }

            // 向右找到了更低的位置或停在原地
            heights[rightLowest]++;
        }

        return heights;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(V * n)，其中 V 是水滴数量，n 是数组长度。每滴水最多遍历整个数组。
- **空间复杂度：** O(1)，只使用常数额外空间（不计入输出数组）。

## 关键点总结

1. **流动规则：** 水总是先尝试向左流，找不到才向右流
2. **最低点选择：** 如果有多个相同高度的最低点，选择最左边的（向左流）或最右边的（向右流）
3. **停止条件：** 遇到更高的位置或到达边界时停止
4. **模拟过程：** 逐滴模拟，每滴水独立计算
5. **原地修改：** 直接修改原数组

## 易错点

1. **方向优先级：** 一定要先向左再向右，不能反过来
2. **相等高度处理：** 高度相等时要继续前进（为了找到最边缘的位置）
3. **比较对象：** 比较的是当前遍历位置和已找到的最低点，不是和起始位置
4. **边界条件：** 注意数组边界的处理
5. **修改时机：** 找到最终位置后再增加高度，不要在寻找过程中修改
