## 题目描述

给你长度为 n 的整数数组 `nums`，构建长度为 2n 的数组，前后各为 `nums` 本身，返回该数组。

## 解题思路

直接将 nums 拼接自身，构建 ans[i] = nums[i] 且 ans[i+n] = nums[i]。

## Java 代码实现

```java
class Solution {
    public int[] getConcatenation(int[] nums) {
        int n = nums.length;
        int[] ans = new int[2 * n];
        for (int i = 0; i < n; i++) {
            ans[i] = nums[i];       // 前半部分
            ans[i + n] = nums[i];   // 后半部分
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 直接按定义构建，ans[i] = ans[i+n] = nums[i]
