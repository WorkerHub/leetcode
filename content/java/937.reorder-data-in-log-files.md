## 题目描述

给定日志数组，字母日志排在数字日志前面。字母日志按内容排序（相同按标识符排序），数字日志保持原序。

## 解题思路

自定义排序：字母日志优先级高，按 (内容, 标识符) 排序；数字日志保持原序。

## Java 代码实现

```java
class Solution {
    public String[] reorderLogFiles(String[] logs) {
        Arrays.sort(logs, (a, b) -> {
            String[] splitA = a.split(" ", 2);
            String[] splitB = b.split(" ", 2);
            boolean isDigitA = Character.isDigit(splitA[1].charAt(0));
            boolean isDigitB = Character.isDigit(splitB[1].charAt(0));

            if (!isDigitA && !isDigitB) {
                // 都是字母日志：先按内容排序，再按标识符
                int cmp = splitA[1].compareTo(splitB[1]);
                return cmp != 0 ? cmp : splitA[0].compareTo(splitB[0]);
            }
            if (!isDigitA) return -1; // 字母日志排前面
            if (!isDigitB) return 1;
            return 0; // 数字日志保持原序
        });
        return logs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n × m)，m 为日志平均长度
- **空间复杂度**：O(n)

## 关键点总结

1. **自定义排序**：字母日志 < 数字日志
2. **稳定排序**：数字日志保持原序
3. **split 限制**：只分割第一个空格
