## 题目描述

给你两个正整数 `n` 和 `m`，每次操作可以将 `n` 加 1。返回使 `n` 被 `m` 整除所需的最少操作次数。

## 解题思路

若 `n % m == 0` 返回 0；否则返回 `m - n % m`（差多少步到下一个 m 的倍数）。可用 `(m - n % m) % m` 统一两种情况。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int n, int m) {
        return (m - n % m) % m;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 下一个 m 的倍数距 n 的距离 = `(m - n%m) % m`
2. 当 n 已整除 m 时，`n%m = 0`，结果为 0
3. 一行代码统一处理两种情况
