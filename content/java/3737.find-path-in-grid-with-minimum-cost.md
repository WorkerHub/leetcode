## 题目描述

给定 `m × n` 矩阵 `grid`，从左上角 `(0,0)` 出发只能向右或向下移动，到达右下角 `(m-1,n-1)`，求路径上所有格子代价之和的最小值。

## Java 代码实现

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 空间优化：用一行 dp 数组
        int[] dp = new int[n];
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + grid[0][j];

        for (int i = 1; i < m; i++) {
            dp[0] += grid[i][0];
            for (int j = 1; j < n; j++) {
                dp[j] = Math.min(dp[j], dp[j - 1]) + grid[i][j];
            }
        }

        return dp[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(n)，滚动数组优化

## 关键点总结

1. 只能向右或向下移动，问题具有无后效性，适合 DP
2. 滚动数组将空间从 O(mn) 优化到 O(n)
3. 正确初始化第一行和第一列
