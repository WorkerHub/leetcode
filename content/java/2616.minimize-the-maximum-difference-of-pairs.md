## 题目描述

给你一个整数数组 `nums` 和整数 `p`，从中选 `p` 个不重叠下标对，使所有对中差值绝对值的最大值最小，返回该最小值。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimizeMax(int[] nums, int p) {
        if (p == 0) return 0;
        Arrays.sort(nums);
        int n = nums.length;
        int lo = 0, hi = nums[n - 1] - nums[0];
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (canFindPPairs(nums, p, mid)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    // 贪心验证：排序后从左到右，相邻差 <= maxDiff 则配对
    private boolean canFindPPairs(int[] nums, int p, int maxDiff) {
        int count = 0;
        int i = 0;
        while (i < nums.length - 1) {
            if (nums[i + 1] - nums[i] <= maxDiff) {
                count++;
                i += 2; // 跳过已配对的两个元素
                if (count >= p) return true;
            } else {
                i++;
            }
        }
        return count >= p;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n + n log M)，n 为数组长度，M 为最大差值
- 空间复杂度：O(log n)（排序递归栈）

## 关键点总结

1. 二分最大差值，转化为可行性验证
2. 排序后相邻元素差最小，贪心配对从左到右
3. 配对后跳过两个元素，不能重叠使用
