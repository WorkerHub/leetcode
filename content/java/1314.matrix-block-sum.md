## 题目描述

给你一个 `m x n` 的矩阵 `mat` 和一个整数 `k`，请你返回一个矩阵 `answer`，其中每个 `answer[i][j]` 是所有满足下述条件的元素 `mat[r][c]` 的和：

- `i - k <= r <= i + k`
- `j - k <= c <= j + k`
- `(r, c)` 在矩阵内

**示例 1：**

```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出：[[12,21,16],[27,45,33],[24,39,28]]
解释：以 (1,1) 为中心的 3x3 子矩阵为整个矩阵，和为 45
```

**示例 2：**

```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出：[[45,45,45],[45,45,45],[45,45,45]]
解释：k=2 时所有中心点的范围都覆盖整个矩阵
```

**提示：**

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n, k <= 100`
- `1 <= mat[i][j] <= 100`

## 解题思路

**核心思想：二维前缀和**

如果暴力计算每个 `answer[i][j]`，需要遍历以 `(i,j)` 为中心的矩形区域，时间复杂度为 O(m*n*k^2)。

利用**二维前缀和**，可以将每次矩形区域求和的复杂度降至 O(1)。

**二维前缀和定义：**

`prefix[i][j]` = 左上角 `(0,0)` 到右下角 `(i-1, j-1)` 的矩形区域所有元素之和。

**构建前缀和：**

```
prefix[i][j] = mat[i-1][j-1]
             + prefix[i-1][j]    (上方矩形)
             + prefix[i][j-1]    (左方矩形)
             - prefix[i-1][j-1]  (重复计算的左上角)
```

**查询矩形 (r1,c1) 到 (r2,c2) 的区域和：**

```
sum = prefix[r2+1][c2+1]
    - prefix[r1][c2+1]
    - prefix[r2+1][c1]
    + prefix[r1][c1]
```

## Java 代码实现

### 方法一：二维前缀和（推荐）

```java
class Solution {
    public int[][] matrixBlockSum(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;
        
        // 构建二维前缀和，多一行一列便于处理边界
        int[][] prefix = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = mat[i - 1][j - 1]
                        + prefix[i - 1][j]
                        + prefix[i][j - 1]
                        - prefix[i - 1][j - 1];
            }
        }
        
        // 计算答案矩阵
        int[][] answer = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 确定查询范围，截断到矩阵边界内
                int r1 = Math.max(0, i - k);
                int c1 = Math.max(0, j - k);
                int r2 = Math.min(m - 1, i + k);
                int c2 = Math.min(n - 1, j + k);
                // 使用前缀和查询矩形区域和
                answer[i][j] = prefix[r2 + 1][c2 + 1]
                        - prefix[r1][c2 + 1]
                        - prefix[r2 + 1][c1]
                        + prefix[r1][c1];
            }
        }
        
        return answer;
    }
}
```

### 方法二：暴力解法（理解对照用）

```java
class Solution {
    public int[][] matrixBlockSum(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;
        int[][] answer = new int[m][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 枚举以 (i,j) 为中心的矩形内所有元素
                for (int r = Math.max(0, i - k); r <= Math.min(m - 1, i + k); r++) {
                    for (int c = Math.max(0, j - k); c <= Math.min(n - 1, j + k); c++) {
                        answer[i][j] += mat[r][c];
                    }
                }
            }
        }
        
        return answer;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维前缀和 | O(m*n) | O(m*n) |
| 暴力 | O(m*n*k^2) | O(1) |

- **二维前缀和**：构建 O(m*n)，每次查询 O(1)，总共 O(m*n)
- 当 k 较大时，前缀和的优势非常明显

## 关键点总结

1. 二维前缀和的构建公式：`prefix[i][j] = mat[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]`
2. 查询公式使用容斥原理，需要减去重叠部分
3. `prefix` 数组比 `mat` 多一行一列（在行列各加 1），处理边界更方便
4. 查询范围需要用 `Math.max/min` 截断到矩阵边界内

## 易错点

1. **下标偏移**：`prefix[i][j]` 对应 `mat[i-1][j-1]`，查询时注意转换
2. **容斥原理方向**：查询 `(r1,c1)~(r2,c2)` 用 `prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]`
3. **边界截断**：`i-k` 可能为负，`i+k` 可能超出 m-1，需要 `Math.max/min` 处理
