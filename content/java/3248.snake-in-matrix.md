## 题目描述

给你一个 `n x n` 矩阵，蛇初始位于 `(0,0)`，给定命令数组（UP/DOWN/LEFT/RIGHT），返回执行所有命令后蛇所在格子的编号（编号 = 行号 * n + 列号）。

## 解题思路

直接维护格子编号：DOWN 加 n，UP 减 n，RIGHT 加 1，LEFT 减 1，无需拆分行列坐标。

## Java 代码实现

```java
import java.util.List;

class Solution {
    public int finalPositionOfSnake(int n, List<String> commands) {
        int pos = 0;
        // 直接维护格子编号，避免行列坐标转换
        for (String cmd : commands) {
            if (cmd.equals("RIGHT")) pos += 1;
            else if (cmd.equals("LEFT")) pos -= 1;
            else if (cmd.equals("DOWN")) pos += n;
            else if (cmd.equals("UP")) pos -= n;
        }
        return pos;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m)，m 为命令数量
- 空间复杂度：O(1)

## 关键点总结

1. 格子编号 = 行 * n + 列，DOWN 等价于 pos += n
2. 题目保证不越界，不需要边界检查
3. 直接维护编号比维护行列坐标更简洁
