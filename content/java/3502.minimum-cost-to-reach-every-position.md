## 题目描述

给你整数数组 `cost`，`cost[i]` 是从位置 i 到 i+1 的费用，可从 0 到 i 中任意位置免费出发，返回到达每个位置的最小费用数组。

## 解题思路

到达位置 i 的最小费用 = `cost[0..i-1]` 的最小值（选代价最小的位置出发一步到达）。维护前缀最小值，O(n) 计算。

## Java 代码实现

```java
class Solution {
    public int[] minCostToReachEveryPosition(int[] cost) {
        int n = cost.length;
        int[] result = new int[n];
        // result[0] = 0（已在位置 0）
        int minCost = Integer.MAX_VALUE;
        for (int i = 1; i < n; i++) {
            minCost = Math.min(minCost, cost[i - 1]);
            result[i] = minCost;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 位置 0 代价固定为 0
2. 到达位置 i 的最小代价 = `min(cost[0..i-1])`（选最优出发点）
3. 用一个变量维护前缀最小值，避免重复扫描
