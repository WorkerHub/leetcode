## 题目描述

摩天轮每轮最多搭4人，每人付boardingCost，每轮成本runningCost。customers[i]为第i轮前到达人数。求最大利润时的旋转次数，无法盈利返回-1。

## 解题思路

模拟：累积等待人数，每轮上最多4人，计算累计利润，记录最大利润对应轮次。customers处理完后继续清空等待区。

## Java 代码实现

```java
class Solution {
    public int minOperationsMaxProfit(int[] customers, int boardingCost, int runningCost) {
        int waiting = 0, profit = 0, maxProfit = 0, bestRot = -1, rot = 0;
        int i = 0;
        
        while (i < customers.length || waiting > 0) {
            if (i < customers.length) {
                waiting += customers[i];
                i++;
            }
            // 本轮上车人数
            int board = Math.min(4, waiting);
            waiting -= board;
            profit += board * boardingCost - runningCost;
            rot++;
            
            if (profit > maxProfit) {
                maxProfit = profit;
                bestRot = rot;
            }
        }
        return bestRot;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + waiting/4)
- **空间复杂度**：O(1)

## 关键点总结

1. **等待人数滚动累加**：每轮最多消耗4人
2. **处理完customers后继续**：清空等待区
3. **严格大于**：记录最早达到最大利润的轮次
