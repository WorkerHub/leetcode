## 题目描述

给定整数数组 `nums`，每次操作可将任意元素替换为另一整数，返回使数组变为交替数组（偶数位置值 != 奇数位置值）的最少操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumOperations(int[] nums) {
        int n = nums.length;
        // 统计偶数位和奇数位各值的频率
        Map<Integer, Integer> evenCnt = new HashMap<>(), oddCnt = new HashMap<>();
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) evenCnt.merge(nums[i], 1, Integer::sum);
            else oddCnt.merge(nums[i], 1, Integer::sum);
        }

        // 取频率最高的前2个
        int[][] even = top2(evenCnt), odd = top2(oddCnt);
        // 若各自最高频值不冲突，直接保留两者最多元素
        int keep;
        if (even[0][0] != odd[0][0]) {
            keep = even[0][1] + odd[0][1];
        } else {
            // 冲突时，一方选次高频
            keep = Math.max(even[0][1] + odd[1][1], even[1][1] + odd[0][1]);
        }
        return n - keep;
    }

    private int[][] top2(Map<Integer, Integer> cnt) {
        int v1 = -1, c1 = 0, v2 = -1, c2 = 0;
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            if (e.getValue() > c1) { v2 = v1; c2 = c1; v1 = e.getKey(); c1 = e.getValue(); }
            else if (e.getValue() > c2) { v2 = e.getKey(); c2 = e.getValue(); }
        }
        return new int[][]{{v1, c1}, {v2, c2}};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：保留尽可能多的元素不变，操作数 = n - 保留数
2. 偶数位和奇数位分别选频率最高的值，不冲突时直接叠加
3. 冲突时一方退而选次高频，取两种方案较优者
