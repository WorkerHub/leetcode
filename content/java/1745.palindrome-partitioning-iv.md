## 题目描述

给你字符串 `s`，判断是否能将其分割成三个非空回文子字符串。

## 解题思路

区间 DP 预处理所有子串是否为回文（O(n^2)），然后枚举两个分割点，检查三段是否均为回文。

## Java 代码实现

```java
class Solution {
    public boolean checkPartitioning(String s) {
        int n = s.length();

        // 预处理：isPal[i][j] 表示 s[i..j] 是否为回文
        boolean[][] isPal = new boolean[n][n];

        // 长度为 1
        for (int i = 0; i < n; i++) isPal[i][i] = true;

        // 长度为 2
        for (int i = 0; i < n - 1; i++) {
            isPal[i][i + 1] = (s.charAt(i) == s.charAt(i + 1));
        }

        // 长度 >= 3
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                isPal[i][j] = (s.charAt(i) == s.charAt(j)) && isPal[i + 1][j - 1];
            }
        }

        // 枚举两个分割点（三段各非空）
        for (int i = 1; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                // s[0..i-1], s[i..j-1], s[j..n-1]
                if (isPal[0][i - 1] && isPal[i][j - 1] && isPal[j][n - 1]) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 区间 DP 预处理避免重复判断回文
2. 枚举分割点时确保三段非空
