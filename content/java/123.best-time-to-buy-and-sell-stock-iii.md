## 题目描述

给定一个数组，它的第 `i` 个元素是一支给定的股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成两笔交易。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**

```
输入：prices = [3,3,5,0,0,3,1,4]
输出：6
解释：在第 4 天（股票价格 = 0）的时候买入，在第 6 天（股票价格 = 3）的时候卖出，这笔交易所能获得利润 = 3-0 = 3 。
     随后，在第 7 天（股票价格 = 1）的时候买入，在第 8 天 （股票价格 = 4）的时候卖出，这笔交易所能获得利润 = 4-1 = 3 。
     总利润为 3 + 3 = 6 。
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：4
解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5-1 = 4 。
     注意你不能在第 1 天和第 2 天接连购买股票，之后再将它们卖出。
     因为这样属于同时参与了多笔交易，你必须在再次购买前出售掉之前的股票。
```

**示例 3：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这个情况下, 没有交易完成, 所以最大利润为 0。
```

**提示：**

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^5`

## 解题思路

这是股票买卖系列中的困难题，限制最多完成两笔交易。

**核心思想：**

1. **动态规划**：定义不同状态下的最大利润
2. **状态划分**：将问题分为完成 0、1、2 次交易的情况
3. **状态转移**：每次交易包括买入和卖出两个操作

**状态定义：**

- `buy1`：第一次买入后的最大利润（负数）
- `sell1`：第一次卖出后的最大利润
- `buy2`：第二次买入后的最大利润
- `sell2`：第二次卖出后的最大利润

**状态转移方程：**

```
buy1 = max(buy1, -prices[i])           // 第一次买入
sell1 = max(sell1, buy1 + prices[i])   // 第一次卖出
buy2 = max(buy2, sell1 - prices[i])    // 第二次买入
sell2 = max(sell2, buy2 + prices[i])   // 第二次卖出
```

## Java 代码实现

### 方法一：动态规划（四个状态）（推荐）

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) return 0;

        // 初始化四个状态
        int buy1 = -prices[0];  // 第一次买入后利润为负
        int sell1 = 0;           // 初始未卖出，利润为 0
        int buy2 = -prices[0];  // 第二次买入
        int sell2 = 0;           // 第二次卖出

        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            // 第一次买入：要么保持，要么今天买入
            buy1 = Math.max(buy1, -price);
            // 第一次卖出：要么保持，要么今天卖出
            sell1 = Math.max(sell1, buy1 + price);
            // 第二次买入：要么保持，要么今天买入（基于第一次卖出的利润）
            buy2 = Math.max(buy2, sell1 - price);
            // 第二次卖出：要么保持，要么今天卖出
            sell2 = Math.max(sell2, buy2 + price);
        }

        // 最多两笔交易的最大利润
        return sell2;
    }
}
```

### 方法二：通用 DP（适用于 k 次交易）

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) return 0;

        int n = prices.length;
        int k = 2;  // 最多 2 次交易

        // dp[i][j][0] 表示第 i 天，完成了 j 笔交易，不持有股票的最大利润
        // dp[i][j][1] 表示第 i 天，完成了 j 笔交易，持有股票的最大利润
        int[][][] dp = new int[n][k + 1][2];

        // 初始化
        for (int j = 0; j <= k; j++) {
            dp[0][j][0] = 0;
            dp[0][j][1] = -prices[0];
        }

        for (int i = 1; i < n; i++) {
            for (int j = 1; j <= k; j++) {
                // 不持有：昨天不持有 或 今天卖出（完成一笔交易）
                dp[i][j][0] = Math.max(dp[i-1][j][0], dp[i-1][j-1][1] + prices[i]);
                // 持有：昨天持有 或 今天买入
                dp[i][j][1] = Math.max(dp[i-1][j][1], dp[i-1][j][0] - prices[i]);
            }
            // j=0 时无法卖出，dp[i][0][1] 更新买入状态
            dp[i][0][1] = Math.max(dp[i-1][0][1], -prices[i]);
        }

        // 返回最后一天，最多完成 k 笔交易，不持有股票的最大利润
        int result = 0;
        for (int j = 0; j <= k; j++) {
            result = Math.max(result, dp[n-1][j][0]);
        }
        return result;
    }
}
```

### 方法三：空间优化的通用 DP

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) return 0;

        int k = 2;
        // buy[j] 表示完成第 j 次买入后（未卖出）的最大利润
        // sell[j] 表示完成第 j 次卖出后的最大利润
        int[] buy = new int[k + 1];
        int[] sell = new int[k + 1];

        // 初始化：买入时利润为负
        for (int j = 0; j <= k; j++) {
            buy[j] = -prices[0];
        }

        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            for (int j = 1; j <= k; j++) {
                // 更新买入和卖出状态
                buy[j] = Math.max(buy[j], sell[j] - price);
                sell[j] = Math.max(sell[j], buy[j-1] + price);
            }
        }

        return sell[k];
    }
}
```

### 方法四：分割数组（两次遍历）

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) return 0;

        int n = prices.length;

        // left[i] 表示 [0, i] 区间内一次交易的最大利润
        int[] left = new int[n];
        int minPrice = prices[0];
        for (int i = 1; i < n; i++) {
            minPrice = Math.min(minPrice, prices[i]);
            left[i] = Math.max(left[i-1], prices[i] - minPrice);
        }

        // right[i] 表示 [i, n-1] 区间内一次交易的最大利润
        int[] right = new int[n];
        int maxPrice = prices[n-1];
        for (int i = n - 2; i >= 0; i--) {
            maxPrice = Math.max(maxPrice, prices[i]);
            right[i] = Math.max(right[i+1], maxPrice - prices[i]);
        }

        // 枚举分割点，找最大值
        int maxProfit = 0;
        for (int i = 0; i < n; i++) {
            maxProfit = Math.max(maxProfit, left[i] + right[i]);
        }

        return maxProfit;
    }
}
```

### 方法五：记忆化递归

```java
class Solution {
    private int[] prices;
    private int[][][] memo;

    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) return 0;
        this.prices = prices;
        int n = prices.length;
        // memo[i][k][hold]，-1 表示未计算
        this.memo = new int[n][3][2];
        for (int[][] a : memo) {
            for (int[] b : a) {
                java.util.Arrays.fill(b, -1);
            }
        }
        return dfs(0, 2, 0);
    }

    private int dfs(int i, int k, int hold) {
        // 到达末尾或没有剩余可交易次数
        if (i == prices.length || k == 0) return 0;

        if (memo[i][k][hold] != -1) return memo[i][k][hold];

        // 不操作
        int res = dfs(i + 1, k, hold);

        if (hold == 1) {
            // 持有股票，可以卖出（k-1 表示消耗一次交易机会）
            res = Math.max(res, dfs(i + 1, k - 1, 0) + prices[i]);
        } else {
            // 不持有股票，可以买入（卖出才消耗交易机会）
            res = Math.max(res, dfs(i + 1, k, 1) - prices[i]);
        }

        memo[i][k][hold] = res;
        return res;
    }
}
```

## 复杂度分析

**方法一：四个状态**
- 时间复杂度：O(n)，只需要遍历一次数组
- 空间复杂度：O(1)，只使用常量额外空间

**方法二：通用 DP**
- 时间复杂度：O(n × k) = O(n)，k = 2 是常数
- 空间复杂度：O(n × k) = O(n)

**方法三：空间优化**
- 时间复杂度：O(n × k) = O(n)
- 空间复杂度：O(k) = O(1)

**方法四：分割数组**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法五：记忆化递归**
- 时间复杂度：O(n × k) = O(n)
- 空间复杂度：O(n × k) = O(n)

## 关键点总结

1. **状态定义**：买入和卖出分别对应不同的状态
2. **状态转移**：每个状态都有"保持"和"操作"两种选择
3. **初始化**：买入状态初始化为负数，卖出状态初始化为 0
4. **交易次数**：卖出时才算完成一笔交易
5. **最优子结构**：第二次买入基于第一次卖出的利润

## 易错点

1. **交易次数定义**：买入+卖出算一笔交易，不是两笔
2. **状态更新顺序**：要注意 buy2 依赖 sell1 的当前值
3. **初始化**：buy1 和 buy2 初始化为 `-prices[0]`，不是 `Integer.MIN_VALUE`
4. **边界条件**：数组为空或只有一个元素时返回 0
5. **状态含义**：sell2 表示最多完成两笔交易，也可能只完成一笔或零笔
