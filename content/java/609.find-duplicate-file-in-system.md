## 题目描述

给你一个目录信息列表 `paths`，包括目录路径，以及该目录中的所有文件及其内容，请你找到文件系统中的所有重复文件组的路径。答案可按**任意顺序**返回。

一组重复的文件至少包括**两个**具有完全相同内容的文件。

**单个**目录信息字符串的格式如下：

- `"root/d1/d2/.../dm f1.txt(f1_content) f2.txt(f2_content) ... fn.txt(fn_content)"`

**示例 1：**

```
输入：paths = ["root/a 1.txt(abcd) 2.txt(efgh)","root/c 3.txt(abcd)","root/c/d 4.txt(efgh)","root 4.txt(efgh)"]
输出：[["root/a/2.txt","root/c/d/4.txt","root/4.txt"],["root/a/1.txt","root/c/3.txt"]]
```

**提示：**

- `1 <= paths.length <= 2 * 10^4`
- `1 <= paths[i].length <= 3000`
- `paths[i]` 由英文字母、数字、字符 `'/'`、`'.'`、`'('`、`')'` 和 `' '` 组成

## 解题思路

这道题的核心是**根据文件内容分组**，找出内容相同的文件。

**解题步骤：**

1. **解析字符串**：提取目录路径、文件名和内容
2. **哈希映射**：用文件内容作为 key，文件路径列表作为 value
3. **筛选结果**：只返回至少有 2 个文件的组

## Java 代码实现

### 方法一：哈希表（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<List<String>> findDuplicate(String[] paths) {
        // 文件内容 -> 文件路径列表
        Map<String, List<String>> contentMap = new HashMap<>();

        for (String path : paths) {
            // 分割目录和文件信息
            String[] parts = path.split(" ");
            String directory = parts[0];

            // 处理每个文件
            for (int i = 1; i < parts.length; i++) {
                String fileInfo = parts[i];
                // 解析文件名和内容
                // 格式：filename.txt(content)
                int nameEnd = fileInfo.indexOf('(');
                String filename = fileInfo.substring(0, nameEnd);
                String content = fileInfo.substring(nameEnd + 1, fileInfo.length() - 1); // 去掉括号

                // 构建完整路径
                String fullPath = directory + "/" + filename;

                // 按内容分组
                contentMap.computeIfAbsent(content, k -> new ArrayList<>()).add(fullPath);
            }
        }

        // 筛选出至少有2个文件的组
        List<List<String>> result = new ArrayList<>();
        for (List<String> fileList : contentMap.values()) {
            if (fileList.size() >= 2) {
                result.add(fileList);
            }
        }

        return result;
    }
}
```

### 方法二：手动解析（最快）⭐⭐

```java
class Solution {
    public List<List<String>> findDuplicate(String[] paths) {
        Map<String, List<String>> contentMap = new HashMap<>();

        for (String path : paths) {
            String[] parts = path.split(" ");
            String directory = parts[0];

            for (int i = 1; i < parts.length; i++) {
                String fileInfo = parts[i];
                // 找到括号位置
                int idx = fileInfo.indexOf('(');
                String filename = fileInfo.substring(0, idx);
                String content = fileInfo.substring(idx + 1, fileInfo.length() - 1);

                // 构建完整路径
                String fullPath = directory + "/" + filename;

                // 分组
                if (!contentMap.containsKey(content)) {
                    contentMap.put(content, new ArrayList<>());
                }
                contentMap.get(content).add(fullPath);
            }
        }

        // 返回结果
        List<List<String>> result = new ArrayList<>();
        for (List<String> fileList : contentMap.values()) {
            if (fileList.size() >= 2) {
                result.add(fileList);
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m × k)，n 为路径数，m 为平均文件数，k 为平均字符串长度
- **空间复杂度**：O(n × m)，存储所有文件路径

## 关键点总结

1. **字符串解析**：正确提取目录、文件名、内容三部分
2. **哈希分组**：使用内容作为 key 进行分组
3. **路径拼接**：注意目录和文件名之间的 `/`
4. **结果筛选**：只返回至少 2 个文件的组
5. **Java 技巧**：使用 `computeIfAbsent` 简化代码

## 易错点

1. **路径拼接错误**：缺少斜杠 `directory + "/" + filename`
2. **括号处理不当**：`fileInfo.length() - 1` 去掉右括号
3. **忘记筛选**：只返回 size >= 2 的组
