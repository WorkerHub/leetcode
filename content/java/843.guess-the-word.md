## 题目描述

交互式问题：从长度为 6 的单词列表中猜出秘密单词。每次猜测返回与秘密单词的精确匹配数。最多猜 10 次。

**示例：**
```
输入：words = ["acckzz","ccbazz","eiowzz","abcczz"], secret = "acckzz"
输出：调用 master.guess("acckzz") 返回 6
```

## 解题思路

每次猜测后根据匹配数过滤候选列表，缩小搜索范围。

## Java 代码实现

```java
class Solution {
    public void findSecretWord(String[] words, Master master) {
        List<String> candidates = new ArrayList<>(Arrays.asList(words));

        for (int i = 0; i < 10; i++) {
            // 随机选择一个候选词
            String guess = candidates.get(0);
            int matches = master.guess(guess);

            if (matches == 6) return;

            // 过滤：保留与 guess 匹配数相同的候选词
            List<String> next = new ArrayList<>();
            for (String w : candidates) {
                if (match(w, guess) == matches) {
                    next.add(w);
                }
            }
            candidates = next;
        }
    }

    private int match(String a, String b) {
        int count = 0;
        for (int i = 0; i < 6; i++) {
            if (a.charAt(i) == b.charAt(i)) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **交互式**：根据反馈调整策略
2. **过滤缩减**：每次猜测后只保留匹配数一致的候选
3. **Minimax 优化**：选择最能缩小候选范围的单词
