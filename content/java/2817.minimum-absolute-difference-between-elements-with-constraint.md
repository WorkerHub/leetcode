## 题目描述

找下标距离>=x的两元素的最小绝对差。

## 解题思路

TreeSet维护有序集合：遍历j时将nums[j-x]加入TreeSet，用floor/ceiling找最接近nums[j]的值。

## Java 代码实现

```java
class Solution {
    public int minAbsoluteDifference(List<Integer> nums, int x) {
        int n = nums.size();
        TreeSet<Integer> set = new TreeSet<>();
        int ans = Integer.MAX_VALUE;

        for (int j = 0; j < n; j++) {
            if (j >= x) {
                set.add(nums.get(j - x));
            }
            if (!set.isEmpty()) {
                int target = nums.get(j);
                // 找>=target的最小值
                Integer ceil = set.ceiling(target);
                if (ceil != null) ans = Math.min(ans, ceil - target);
                // 找<=target的最大值
                Integer floor = set.floor(target);
                if (floor != null) ans = Math.min(ans, target - floor);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **TreeSet维护有序集合**：O(log N)插入和查找
2. **ceiling/floor找最近值**：两侧都检查
3. **滑动加入**：j>=x时才将nums[j-x]加入
