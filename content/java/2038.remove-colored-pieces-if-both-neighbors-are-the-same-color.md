## 题目描述

字符串 `colors` 由 'A' 和 'B' 组成，Alice 只能移除两侧邻居均为 'A' 的 'A'，Bob 只能移除两侧邻居均为 'B' 的 'B'，Alice 先手，无法操作者输，返回 Alice 是否必赢。

## 解题思路

两人操作完全独立互不影响。统计 `colors[i-1]==colors[i]==colors[i+1]=='A'` 的位置数为 Alice 的可操作次数，同理统计 Bob 的，Alice 赢当且仅当 alice > bob。

## Java 代码实现

### 方法一：统计可操作次数（推荐）

```java
class Solution {
    public boolean winnerOfGame(String colors) {
        int alice = 0, bob = 0;
        for (int i = 1; i < colors.length() - 1; i++) {
            char c = colors.charAt(i);
            if (c == colors.charAt(i - 1) && c == colors.charAt(i + 1)) {
                if (c == 'A') alice++;
                else bob++;
            }
        }
        return alice > bob;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. Alice 和 Bob 的操作完全独立，不互相影响
2. 三连同色段长度 l 有 max(0, l-2) 个可移除位置，等价于统计中间位置两侧同色的计数
3. Alice 赢需要严格大于 Bob（等于时先手不利）
