## 题目描述

给你两个物品数组（每项 `[价值, 重量]`），合并两数组中价值相同的物品（重量相加），返回按价值升序排列的结果。

## 解题思路

用 TreeMap（有序哈希表）按价值统计总重量，遍历两个数组累加权重，最后按键排序输出。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<List<Integer>> mergeSimilarItems(int[][] items1, int[][] items2) {
        TreeMap<Integer, Integer> map = new TreeMap<>(); // 按价值自动排序
        for (int[] item : items1) map.merge(item[0], item[1], Integer::sum);
        for (int[] item : items2) map.merge(item[0], item[1], Integer::sum);
        List<List<Integer>> ans = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : map.entrySet()) {
            ans.add(Arrays.asList(e.getKey(), e.getValue()));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n+m) log(n+m))
- **空间复杂度**：O(n+m)

## 关键点总结

1. `TreeMap` 自动按键（价值）升序排列，遍历时无需额外排序。
2. `merge(key, val, Integer::sum)` 等价于若存在则加，否则插入。
3. 两个数组可以顺序合并到同一个 TreeMap。
