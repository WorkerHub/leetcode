## 题目描述

有 `n` 个人，每个人的编号为 `0` 到 `n-1`。

给定两个列表：
- `watchedVideos`：`watchedVideos[i]` 是第 `i` 个人观看的视频列表
- `friends`：`friends[i]` 是第 `i` 个人的好友列表

给定整数 `id` 和 `level`，找出 `id` 的第 `level` 级好友（不是第 1 级，也不是第 2 级，而是恰好第 `level` 级）看过的所有视频。

返回这些视频的列表，按观看频率**升序**排列（频率相同时按字母序排列）。

**示例 1：**

```
输入：watchedVideos = [["A","B"],["C"],["B","C"],["D"]], 
     friends = [[1,2],[0,3],[0,3],[1,2]], id = 0, level = 1
输出：["B","C"]
解释：
id = 0 的好友是 1 和 2（第 1 级）
他们看过的视频：C（1次）、B（2次）、C（2次）
整理：B -> 1次，C -> 2次，按频率升序：["B","C"]
```

**示例 2：**

```
输入：watchedVideos = [["A","B"],["C"],["B","C"],["D"]], 
     friends = [[1,2],[0,3],[0,3],[1,2]], id = 0, level = 2
输出：["D"]
解释：id = 0 的第2级好友是 3，他只看了 "D"
```

**提示：**

- `n == watchedVideos.length == friends.length`
- `2 <= n <= 100`
- `1 <= watchedVideos[i].length <= 100`
- `1 <= watchedVideos[i][j].length <= 8`
- `0 <= friends[i].length < n`
- `0 <= friends[i][j] < n`
- `1 <= level < n`
- 如果 `friends[i]` 包含 `j`，那么 `friends[j]` 包含 `i`

## 解题思路

**整体思路：BFS 找第 level 级好友 + 哈希表统计视频频率**

**第一步：BFS 找第 level 级好友**

从 `id` 出发做 BFS，每扩展一层代表好友级别 +1，到达 `level` 层时收集所有节点即为第 `level` 级好友。

**第二步：统计视频频率**

遍历所有第 `level` 级好友，统计他们观看视频的总次数。

**第三步：排序输出**

按频率升序，频率相同按字母序排列。

## Java 代码实现

### 方法一：BFS + 哈希表（推荐）

```java
import java.util.*;

class Solution {
    public List<String> watchedVideosByFriends(
            List<List<String>> watchedVideos,
            int[][] friends,
            int id,
            int level) {
        
        // BFS 找第 level 级好友
        Set<Integer> visited = new HashSet<>();
        visited.add(id);
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(id);
        
        for (int i = 0; i < level; i++) {
            // 每次循环扩展一层
            Queue<Integer> nextLevel = new LinkedList<>();
            while (!queue.isEmpty()) {
                int person = queue.poll();
                for (int friend : friends[person]) {
                    if (!visited.contains(friend)) {
                        visited.add(friend);
                        nextLevel.offer(friend);
                    }
                }
            }
            queue = nextLevel;
        }
        
        // 此时 queue 中存放的是第 level 级好友
        // 统计他们观看视频的频率
        Map<String, Integer> videoCount = new HashMap<>();
        for (int person : queue) {
            for (String video : watchedVideos.get(person)) {
                videoCount.merge(video, 1, Integer::sum);
            }
        }
        
        // 按频率升序，频率相同按字母序排列
        List<String> result = new ArrayList<>(videoCount.keySet());
        result.sort((a, b) -> {
            int cntA = videoCount.get(a);
            int cntB = videoCount.get(b);
            if (cntA != cntB) return cntA - cntB;
            return a.compareTo(b);
        });
        
        return result;
    }
}
```

### 方法二：BFS（使用集合，代码更清晰）

```java
import java.util.*;

class Solution {
    public List<String> watchedVideosByFriends(
            List<List<String>> watchedVideos,
            int[][] friends,
            int id,
            int level) {
        
        // 初始化：已访问集合，当前层节点集合
        Set<Integer> visited = new HashSet<>();
        visited.add(id);
        Set<Integer> currentLevel = new HashSet<>();
        currentLevel.add(id);
        
        for (int i = 0; i < level; i++) {
            Set<Integer> nextLevel = new HashSet<>();
            for (int person : currentLevel) {
                for (int friend : friends[person]) {
                    if (!visited.contains(friend)) {
                        visited.add(friend);
                        nextLevel.add(friend);
                    }
                }
            }
            currentLevel = nextLevel;
        }
        
        // 统计第 level 级好友看过的视频频率
        Map<String, Integer> videoCount = new HashMap<>();
        for (int person : currentLevel) {
            for (String video : watchedVideos.get(person)) {
                videoCount.merge(video, 1, Integer::sum);
            }
        }
        
        // 排序：先按频率，再按字母序
        List<String> result = new ArrayList<>(videoCount.keySet());
        result.sort(Comparator.comparingInt(videoCount::get).thenComparing(Comparator.naturalOrder()));
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + E + V * log V)
  - BFS：O(n + E)，n 为节点数，E 为边数（好友关系数）
  - 统计视频：O(V)，V 为第 level 级好友看过的视频总数
  - 排序：O(V * log V)
- **空间复杂度**：O(n + V)，visited 集合 O(n)，视频计数哈希表 O(V)

## 关键点总结

1. BFS 天然适合"按层级遍历"的问题，每轮循环扩展一层好友
2. 使用 `visited` 集合避免重复访问（同一个人可能是多个人的好友）
3. Java 中 `Map.merge()` 方法可以方便地统计频率
4. 排序时用 `Comparator.comparingInt().thenComparing()` 实现多关键字排序

## 易错点

1. **忘记标记 `id` 本人为已访问**：如果不把 `id` 加入 `visited`，可能在 BFS 时绕回自己
2. **BFS 层次混乱**：每次扩展要用新的队列收集下一层，不能在遍历当前层时直接添加到同一队列
3. **排序方向**：题目要求频率**升序**，别写成降序
