## 题目描述

给字符串 s、a、b 和整数 k，返回所有"美丽下标" i（s 从 i 开始匹配 a，且存在 j 使 s 从 j 开始匹配 b 且 |i-j|<=k）。

## 解题思路

KMP 分别找到 a、b 在 s 中所有出现位置，再用二分查找判断每个 posA[i] 在 posB 中是否存在满足距离 ≤ k 的位置。

## Java 代码实现

```java
class Solution {
    public List<Integer> beautifulIndices(String s, String a, String b, int k) {
        List<Integer> posA = kmpSearch(s, a);
        List<Integer> posB = kmpSearch(s, b);
        List<Integer> result = new ArrayList<>();
        for (int i : posA) {
            // 二分查找 posB 中第一个 >= i-k 的位置
            int lo = lowerBound(posB, i - k);
            if (lo < posB.size() && posB.get(lo) <= i + k) {
                result.add(i);
            }
        }
        return result;
    }

    private List<Integer> kmpSearch(String text, String pattern) {
        int n = text.length(), m = pattern.length();
        int[] fail = new int[m];
        // 构建失配表
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && pattern.charAt(i) != pattern.charAt(j)) j = fail[j - 1];
            if (pattern.charAt(i) == pattern.charAt(j)) j++;
            fail[i] = j;
        }
        List<Integer> positions = new ArrayList<>();
        for (int i = 0, j = 0; i < n; i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) j = fail[j - 1];
            if (text.charAt(i) == pattern.charAt(j)) j++;
            if (j == m) {
                positions.add(i - m + 1);
                j = fail[j - 1];
            }
        }
        return positions;
    }

    // 返回第一个 >= target 的下标
    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m1 + m2 + p·log q)
- **空间复杂度**：O(n)

## 关键点总结

1. KMP 线性时间找所有匹配位置
2. 条件 |i-j|≤k 等价于 i-k ≤ j ≤ i+k
3. 二分在有序列表中快速定位
