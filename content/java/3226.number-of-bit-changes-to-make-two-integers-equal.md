## 题目描述

给你两个正整数 `n` 和 `k`，每次操作可将 `n` 中某个值为 `1` 的位改为 `0`，返回使 `n` 等于 `k` 所需的最少操作次数，若无法实现返回 `-1`。

## Java 代码实现

```java
class Solution {
    public int minChanges(int n, int k) {
        // k 中某位是 1 但 n 对应位是 0，无法通过 1->0 操作实现
        if ((k & n) != k) return -1;
        // 操作次数 = n 中有、k 中没有的 1 的数量
        return Integer.bitCount(n ^ k);
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 操作只能 1 -> 0，所以 k 需要是 n 的按位子集
2. `(k & n) != k` 说明 k 中存在 n 没有的 1 位，返回 -1
3. 操作次数 = `Integer.bitCount(n ^ k)`（n 中多余的 1 的数量）
