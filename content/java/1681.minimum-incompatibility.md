## 题目描述

整数数组 `nums` 和整数 `k`，将数组划分为 `k` 个相同大小的子集，要求同一子集无重复元素。子集的**不兼容性** = 最大值 - 最小值。返回各子集不兼容性之和的最小值，无法分配则返回 `-1`。

## 解题思路

**状态压缩 DP：** 预计算每个大小恰好为 `n/k` 且无重复元素的子集的不兼容性（max - min）。`dp[mask]` 为已选集合为 `mask` 时的最小不兼容性总和。枚举时固定最低未选位所在的合法子集进行转移。

## Java 代码实现

```java
class Solution {
    public int minimumIncompatibility(int[] nums, int k) {
        int n = nums.length;
        int size = n / k; // 每个子集的大小

        // 检查某个元素出现次数是否超过 k
        int[] freq = new int[n + 1];
        for (int x : nums) {
            if (++freq[x] > k) return -1;
        }

        // 预计算每个合法子集的不兼容性
        int[] cost = new int[1 << n];
        Arrays.fill(cost, -1);
        for (int mask = 1; mask < (1 << n); mask++) {
            if (Integer.bitCount(mask) != size) continue;
            // 提取子集元素，检查重复
            int mn = Integer.MAX_VALUE, mx = Integer.MIN_VALUE;
            boolean valid = true;
            boolean[] seen = new boolean[n + 1];
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 0) continue;
                if (seen[nums[i]]) { valid = false; break; }
                seen[nums[i]] = true;
                mn = Math.min(mn, nums[i]);
                mx = Math.max(mx, nums[i]);
            }
            if (valid) cost[mask] = mx - mn;
        }

        int full = (1 << n) - 1;
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE / 2) continue;
            int rest = full ^ mask;
            if (rest == 0) continue;
            // 固定最低位，避免重复枚举
            int lowBit = rest & (-rest);
            // 枚举 rest 的所有包含最低位的子集
            for (int sub = rest; sub > 0; sub = (sub - 1) & rest) {
                if ((sub & lowBit) != 0 && cost[sub] != -1) {
                    dp[mask | sub] = Math.min(dp[mask | sub], dp[mask] + cost[sub]);
                }
            }
        }

        int ans = dp[full];
        return ans == Integer.MAX_VALUE / 2 ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(3^n)，枚举所有子集的子集
- **空间复杂度**：O(2^n)

## 关键点总结

1. 固定最低未选位：每次枚举包含该位的子集，避免重复分组
2. 预计算合法子集代价：大小等于 size 且无重复元素
3. 元素出现次数超过 k 直接返回 -1
