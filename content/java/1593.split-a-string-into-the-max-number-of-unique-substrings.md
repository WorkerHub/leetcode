## 题目描述

将字符串分割成尽可能多的唯一非空子字符串，返回最大分割数。

**示例：**
```
输入：s = "ababccc"
输出：5
解释：["a", "b", "ab", "c", "cc"]
```

## 解题思路

回溯：字符串长度≤16，枚举所有分割方式。用HashSet维护已使用子串，剪枝优化。

## Java 代码实现

```java
class Solution {
    private int ans = 1;
    
    public int maxUniqueSplit(String s) {
        backtrack(s, 0, new HashSet<>());
        return ans;
    }
    
    private void backtrack(String s, int start, Set<String> used) {
        int n = s.length();
        // 剪枝：即使剩余每个字符独立也不超当前最优
        if (used.size() + (n - start) <= ans) return;
        if (start == n) {
            ans = Math.max(ans, used.size());
            return;
        }
        for (int end = start + 1; end <= n; end++) {
            String sub = s.substring(start, end);
            if (!used.contains(sub)) {
                used.add(sub);
                backtrack(s, end, used);
                used.remove(sub);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × 2^N)
- **空间复杂度**：O(N)

## 关键点总结

1. **回溯枚举**：长度≤16，回溯可行
2. **HashSet维护**：已使用子串去重
3. **剪枝**：剩余长度+已有数≤当前最优时提前退出
