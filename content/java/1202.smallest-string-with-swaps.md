## 题目描述

给定字符串 s 和索引对数组 pairs，可任意多次交换 pairs 中的索引对字符，返回字典序最小的字符串。

**示例：**
```
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
```

## 解题思路

连通分量内的字符可以任意排列。用并查集找出所有连通分量，对每个连通分量内的字符排序后按位置放回。

## Java 代码实现

```java
class Solution {
    private int[] parent;
    
    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        
        // 合并可交换的索引
        for (List<Integer> pair : pairs) {
            union(pair.get(0), pair.get(1));
        }
        
        // 按连通分量分组
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            groups.computeIfAbsent(find(i), k -> new ArrayList<>()).add(i);
        }
        
        // 对每个连通分量内的字符排序后放回
        char[] result = new char[n];
        for (List<Integer> indices : groups.values()) {
            List<Character> chars = new ArrayList<>();
            for (int idx : indices) chars.add(s.charAt(idx));
            Collections.sort(chars);
            Collections.sort(indices);
            for (int i = 0; i < indices.size(); i++) {
                result[indices.get(i)] = chars.get(i);
            }
        }
        
        return new String(result);
    }
    
    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    
    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m * α(n))
- **空间复杂度**：O(n)

## 关键点总结

1. **传递性**：a↔b 且 b↔c 则 a、b、c 可任意排列
2. **并查集**：高效处理动态连通性
3. **路径压缩**：`parent[x] = find(parent[x])` 优化查找
4. **组内排序**：连通分量内字符排序放到对应位置
