## 题目描述

字符串只含 '('、')' 和 '*'，其中 * 可视为 '(' 或 ')' 或空。判断字符串是否有效。

**示例：**
```
输入：s = "(*)"
输出：true
```

## 解题思路

贪心：维护可能的左括号数量范围 [low, high]。遇到 '(' 两者加1，')' 两者减1，'*' low减1 high加1。high<0 返回 false，low<0 重置为0，最终 low==0。

## Java 代码实现

```java
class Solution {
    public boolean checkValidString(String s) {
        int low = 0, high = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                low++;
                high++;
            } else if (c == ')') {
                low--;
                high--;
            } else {
                low--;  // * 当作 )
                high++; // * 当作 (
            }

            // 右括号太多
            if (high < 0) return false;
            // low 不能小于 0
            low = Math.max(low, 0);
        }

        return low == 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **范围思想**：维护左括号数量的可能范围
2. **high<0**：右括号太多，无法匹配
3. **low 重置**：low<0 时重置为0（可用 * 抵消）
4. **最终判断**：low==0 表示所有左括号可被匹配
