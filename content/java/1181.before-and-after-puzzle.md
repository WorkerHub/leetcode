## 题目描述

给定短语列表 `phrases`，返回所有能通过连接两个短语形成的不同字符串列表，要求第一个短语的最后一个单词等于第二个短语的第一个单词。结果按字典序排列并去重。

**示例：**
```
输入: phrases = ["writing code","code rocks"]
输出: ["writing code rocks"]
```

## 解题思路

用哈希表将首单词相同的短语分组。遍历每个短语，用其尾单词查找可拼接的后续短语，拼接时去掉重复单词。用 TreeSet 自动排序去重。

## Java 代码实现

```java
class Solution {
    public List<String> beforeAndAfterPuzzles(String[] phrases) {
        int n = phrases.length;
        // 预处理：提取首尾单词
        String[][] words = new String[n][];
        Map<String, List<Integer>> firstMap = new HashMap<>();
        
        for (int i = 0; i < n; i++) {
            words[i] = phrases[i].split(" ");
            firstMap.computeIfAbsent(words[i][0], k -> new ArrayList<>()).add(i);
        }
        
        // TreeSet 自动排序去重
        TreeSet<String> resultSet = new TreeSet<>();
        
        for (int i = 0; i < n; i++) {
            String lastWord = words[i][words[i].length - 1];
            List<Integer> candidates = firstMap.get(lastWord);
            if (candidates == null) continue;
            
            for (int j : candidates) {
                if (i == j) continue;
                // 拼接：前半部分 + 后半部分去掉首单词
                StringBuilder sb = new StringBuilder(phrases[i]);
                for (int k = 1; k < words[j].length; k++) {
                    sb.append(' ').append(words[j][k]);
                }
                resultSet.add(sb.toString());
            }
        }
        
        return new ArrayList<>(resultSet);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² * m + k * log k)，n 为短语数，m 为平均长度
- **空间复杂度**：O(n * m + k)

## 关键点总结

1. **哈希表分组**：按首单词分组，快速查找可拼接的短语
2. **TreeSet**：自动排序去重，无需手动处理
3. **拼接技巧**：前半部分完整 + 后半部分从第二个单词开始
4. **索引判断**：`i != j` 避免自己和自己拼接
