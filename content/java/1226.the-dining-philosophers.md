## 题目描述

5 个哲学家围坐圆桌，每两人之间一把叉子。哲学家需要同时拿起左右两把叉子才能吃饭。实现 wantsToEat 方法，确保不会死锁。

**关键约束：** 避免死锁（所有人都拿着左叉子等右叉子的情况）。

## 解题思路

打破循环等待：偶数编号哲学家先拿左叉子，奇数编号先拿右叉子。这样不会形成环形等待。

## Java 代码实现

```java
class DiningPhilosophers {
    private ReentrantLock[] forks = new ReentrantLock[5];
    
    public DiningPhilosophers() {
        for (int i = 0; i < 5; i++) {
            forks[i] = new ReentrantLock();
        }
    }
    
    public void wantsToEat(int philosopher,
                           Runnable pickLeftFork,
                           Runnable pickRightFork,
                           Runnable eat,
                           Runnable putLeftFork,
                           Runnable putRightFork) throws InterruptedException {
        int left = philosopher;
        int right = (philosopher + 1) % 5;
        
        // 偶数先拿左，奇数先拿右（打破循环等待）
        int first = (philosopher % 2 == 0) ? left : right;
        int second = (philosopher % 2 == 0) ? right : left;
        
        forks[first].lock();
        forks[second].lock();
        try {
            pickLeftFork.run();
            pickRightFork.run();
            eat.run();
            putLeftFork.run();
            putRightFork.run();
        } finally {
            forks[second].unlock();
            forks[first].unlock();
        }
    }
}
```

## 关键点总结

1. **打破循环等待**：奇偶编号拿叉子顺序不同，避免死锁
2. **ReentrantLock**：每把叉子对应一个锁
3. **try-finally**：确保锁一定被释放
4. **也可用 Semaphore**：限制最多 4 人同时尝试吃饭
