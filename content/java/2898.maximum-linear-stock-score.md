## 题目描述

给你整数数组 scores，选出下标子序列使得相邻选中下标 i、j 满足 `scores[j] - scores[i] == j - i`，返回这样的线性子序列的最大分数和。

## 解题思路

条件等价于 `scores[i] - i == 常数`，因此用哈希表按 `scores[i] - i` 分组累加 scores[i]，取最大组和。

## Java 代码实现

```java
class Solution {
    public long maxScore(int[] scores) {
        Map<Long, Long> groupSum = new HashMap<>();

        for (int i = 0; i < scores.length; i++) {
            long key = (long) scores[i] - i; // 键可能为负数，使用 long
            groupSum.merge(key, (long) scores[i], Long::sum);
        }

        long ans = 0;
        for (long v : groupSum.values()) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 线性条件 `scores[j] - scores[i] == j - i` 等价于 `scores[i] - i == 常数`
2. 哈希表按变换后的键分组，累加原始 scores 值
3. 键可能为负数，使用 long 避免溢出
