## 题目描述

给定 n 个节点的二叉树，每个节点有 node.val 枚硬币，总共 n 枚。每次可在相邻节点间移动一枚硬币，返回使每个节点恰好有一枚硬币的最少移动次数。

**示例：**
```
输入：root = [3,0,0]
输出：2
```

## 解题思路

DFS 后序遍历：每个节点返回其子树的"过剩"硬币数（可为负表示缺少）。每条边的移动次数等于通过该边的硬币绝对值。

## Java 代码实现

```java
class Solution {
    private int moves = 0;

    public int distributeCoins(TreeNode root) {
        dfs(root);
        return moves;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        int leftExcess = dfs(node.left);
        int rightExcess = dfs(node.right);

        // 经过左右子树边的移动次数
        moves += Math.abs(leftExcess) + Math.abs(rightExcess);

        // 返回当前子树的过剩硬币数
        return node.val + leftExcess + rightExcess - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **后序遍历**：先处理子树再处理当前节点
2. **过剩概念**：excess = val + left + right - 1
3. **绝对值累加**：无论硬币流向如何，经过边就计数
