## 题目描述

给定日期的 day、month、year，返回这一天是星期几（英文全称）。

**示例：**
```
输入: day = 31, month = 8, year = 2019
输出: "Saturday"
```

## 解题思路

从基准日期 1971-01-01（星期五）开始累加天数，总天数模 7 得到星期几。也可使用蔡勒公式直接计算。

## Java 代码实现

### 方法一：从基准日期累加

```java
class Solution {
    public String dayOfTheWeek(int day, int month, int year) {
        String[] weeks = {"Sunday", "Monday", "Tuesday", "Wednesday",
                          "Thursday", "Friday", "Saturday"};
        int[] monthDays = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        
        int days = 0;
        // 累加完整年份的天数
        for (int y = 1971; y < year; y++) {
            days += isLeap(y) ? 366 : 365;
        }
        // 累加当年已过月份的天数
        for (int m = 1; m < month; m++) {
            days += monthDays[m - 1];
            if (m == 2 && isLeap(year)) days++;
        }
        // 加当月天数
        days += day;
        
        // 1971-01-01 是星期五，索引5；1月1日本身算第1天
        return weeks[(4 + days) % 7];
    }
    
    private boolean isLeap(int year) {
        return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    }
}
```

### 方法二：蔡勒公式

```java
class Solution {
    public String dayOfTheWeek(int day, int month, int year) {
        String[] weeks = {"Sunday", "Monday", "Tuesday", "Wednesday",
                          "Thursday", "Friday", "Saturday"};
        // 蔡勒公式：1月2月视为上一年的13月14月
        if (month < 3) {
            month += 12;
            year--;
        }
        int c = year / 100;
        int y = year % 100;
        int w = (day + 2 * month + 3 * (month + 1) / 5 + y + y / 4 - c / 4 + c / 2 + 1) % 7;
        return weeks[w];
    }
}
```

## 复杂度分析

- **时间复杂度**：方法一 O(year-1971)，方法二 O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **闰年判断**：能被4整除但不能被100整除，或能被400整除
2. **基准日期**：1971-01-01 是星期五
3. **蔡勒公式**：1月2月视为上一年的13月14月
4. **模7映射**：总天数模7对应星期数组索引
