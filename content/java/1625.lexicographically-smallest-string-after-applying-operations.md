## 题目描述

给你一个偶数长度的字符串 `s` 和两个整数 `a` 和 `b`。可以任意次执行：
1. 将 `s` 中**所有奇数下标**的字符都加 `a`（0-9 循环）
2. 将字符串 `s` 向右**旋转** `b` 位

请返回可以得到的**字典序最小**的字符串。

## 解题思路

状态空间有限，用 **BFS** 枚举所有可达状态，找字典序最小的字符串。

## Java 代码实现

```java
class Solution {
    public String findLexSmallestString(String s, int a, int b) {
        Set<String> visited = new HashSet<>();
        Queue<String> queue = new ArrayDeque<>();
        queue.offer(s);
        visited.add(s);
        String ans = s;

        while (!queue.isEmpty()) {
            String curr = queue.poll();

            // 更新答案
            if (curr.compareTo(ans) < 0) {
                ans = curr;
            }

            // 操作 1：对奇数下标字符加 a
            char[] arr = curr.toCharArray();
            for (int i = 1; i < arr.length; i += 2) {
                arr[i] = (char) ('0' + (arr[i] - '0' + a) % 10);
            }
            String next1 = new String(arr);

            // 操作 2：旋转 b 位
            int n = curr.length();
            String next2 = curr.substring(n - b) + curr.substring(0, n - b);

            // 加入未访问的状态
            for (String nxt : new String[]{next1, next2}) {
                if (!visited.contains(nxt)) {
                    visited.add(nxt);
                    queue.offer(nxt);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2 * 10)，状态数为 O(10 * n/gcd(b,n))
- **空间复杂度**：O(n^2)，存储所有可达状态

## 关键点总结

1. 状态空间有限，BFS 枚举所有可达状态
2. 加法操作周期为 10，旋转操作周期为 n/gcd(b,n)
3. BFS 天然避免重复访问已见状态
4. Java 中字符串比较用 `compareTo`
