## 题目描述

给定 `m x n` 矩阵 `grid`（元素 0~15）和整数 `k`，从左上角只能向右或向下移动到右下角，返回路径上所有元素异或值等于 `k` 的路径数量（对 10^9+7 取模）。

## Java 代码实现

```java
class Solution {
    public int countPathsWithXorValue(int[][] grid, int k) {
        final int MOD = 1_000_000_007;
        final int MAX_XOR = 16; // 元素值 <= 15，异或范围 [0,15]
        int m = grid.length, n = grid[0].length;

        // dp[j][v] = 当前行 j 列，路径异或值为 v 的路径数
        int[][] dp = new int[n][MAX_XOR];
        dp[0][grid[0][0]] = 1;

        // 初始化第一行
        for (int j = 1; j < n; j++) {
            for (int v = 0; v < MAX_XOR; v++) {
                int prevV = v ^ grid[0][j];
                dp[j][v] = dp[j - 1][prevV];
            }
        }

        for (int i = 1; i < m; i++) {
            int[][] newDp = new int[n][MAX_XOR];
            for (int j = 0; j < n; j++) {
                for (int v = 0; v < MAX_XOR; v++) {
                    int prevV = v ^ grid[i][j];
                    // 从上方来
                    newDp[j][v] = dp[j][prevV];
                    // 从左方来
                    if (j > 0) {
                        newDp[j][v] = (newDp[j][v] + newDp[j - 1][prevV]) % MOD;
                    }
                }
            }
            dp = newDp;
        }

        return dp[n - 1][k];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 16)
- 空间复杂度：O(n * 16)，滚动数组优化

## 关键点总结

1. 异或的逆运算是其自身：到达 (i,j) 异或值为 v，则前驱的异或值为 `v ^ grid[i][j]`。
2. 值域小（0-15），第三维只需 16，状态空间可控。
3. 滚动数组将空间从 O(m*n*16) 降至 O(n*16)。
