## 题目描述

给你一棵完全二叉树的根节点 `root`，求出该树的节点个数。

完全二叉树的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 `h` 层，则该层包含 `1~ 2^h` 个节点。

**示例 1：**

```
输入：root = [1,2,3,4,5,6]
输出：6
```

**示例 2：**

```
输入：root = []
输出：0
```

**示例 3：**

```
输入：root = [1]
输出：1
```

**提示：**

- 树中节点的数目范围是 `[0, 5 * 10^4]`
- `0 <= Node.val <= 5 * 10^4`
- 题目数据保证输入的树是完全二叉树

**进阶：** 遍历树来统计节点是一种时间复杂度为 O(n) 的简单解决方案。你可以设计一个更快的算法吗？

## 解题思路

这道题的关键是利用**完全二叉树的特性**来优化算法。

### 核心观察

1. **满二叉树**：如果一棵完全二叉树是满二叉树，节点数 = 2^h - 1（h 为树高）
2. **完全二叉树的子树**：完全二叉树的左右子树，至少有一个是满二叉树
3. **判断是否满二叉树**：一直往左走和一直往右走的深度相同

### 算法流程

1. 计算树的最左深度和最右深度
2. 如果左右深度相同，说明是满二叉树，直接返回 2^h - 1
3. 否则，递归计算左右子树的节点数，再加上根节点

## Java 代码实现

### 方法一：利用完全二叉树性质（推荐）

```java
class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) {
            return 0;
        }

        // 计算最左侧的深度
        int leftDepth = getDepth(root.left);
        // 计算最右侧的深度
        int rightDepth = getDepth(root.right);

        if (leftDepth == rightDepth) {
            // 左子树是满二叉树，左子树节点数 = 2^leftDepth - 1
            // 加上根节点和右子树
            return (1 << leftDepth) + countNodes(root.right);
        } else {
            // 右子树是满二叉树，右子树节点数 = 2^rightDepth - 1
            // 加上根节点和左子树
            return (1 << rightDepth) + countNodes(root.left);
        }
    }

    /** 计算树的深度（一直往左走） */
    private int getDepth(TreeNode node) {
        int depth = 0;
        while (node != null) {
            depth++;
            node = node.left;
        }
        return depth;
    }
}
```

### 方法二：二分查找 + 位运算

```java
class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) {
            return 0;
        }

        // 计算树的高度
        int level = 0;
        TreeNode node = root;
        while (node.left != null) {
            level++;
            node = node.left;
        }

        // 如果高度为 0，只有根节点
        if (level == 0) {
            return 1;
        }

        // 二分查找最后一层的节点数
        // 最后一层的节点编号范围：[0, 2^level - 1]
        int left = 0;
        int right = (1 << level) - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (exists(mid, level, root)) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        // 前 level 层的节点数 + 最后一层的节点数
        return (1 << level) - 1 + left;
    }

    /** 判断最后一层的第 idx 个节点是否存在 */
    private boolean exists(int idx, int level, TreeNode node) {
        int left = 0;
        int right = (1 << level) - 1;
        for (int i = 0; i < level; i++) {
            int mid = left + (right - left) / 2;
            if (idx <= mid) {
                node = node.left;
                right = mid;
            } else {
                node = node.right;
                left = mid + 1;
            }
        }
        return node != null;
    }
}
```

### 方法三：普通递归（暴力解法）

```java
class Solution {
    public int countNodes(TreeNode root) {
        // 简单递归，不利用完全二叉树的性质
        if (root == null) {
            return 0;
        }
        return 1 + countNodes(root.left) + countNodes(root.right);
    }
}
```

### 方法四：迭代法（层序遍历）

```java
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) {
            return 0;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int count = 0;

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            count++;
            if (node.left != null) {
                queue.offer(node.left);
            }
            if (node.right != null) {
                queue.offer(node.right);
            }
        }

        return count;
    }
}
```

## 复杂度分析

**方法一：利用完全二叉树性质**
- 时间复杂度：O(log²n)，每次递归计算深度需要 O(log n)，递归深度为 O(log n)
- 空间复杂度：O(log n)，递归调用栈的深度

**方法二：二分查找**
- 时间复杂度：O(log²n)，二分查找 O(log n) 次，每次检查需要 O(log n)
- 空间复杂度：O(1)

**方法三：普通递归**
- 时间复杂度：O(n)，需要访问每个节点
- 空间复杂度：O(log n)，递归栈深度

**方法四：迭代法**
- 时间复杂度：O(n)，访问每个节点
- 空间复杂度：O(n)，队列最多存储一层的节点

- 右深度 = 1（2->5）
- left_depth == right_depth
- 左子树是满二叉树，节点数 = 2^1 = 2
- 递归计算右子树 + 2 + 1

## 关键点总结

1. **完全二叉树性质**：左右子树至少有一个是满二叉树
2. **满二叉树判断**：最左深度 == 最右深度
3. **位运算优化**：`1 << h` 等价于 `2^h`，效率更高
4. **递归优化**：每次递归只处理一半的子树
5. **时间复杂度优化**：从 O(n) 优化到 O(log²n)

## 易错点

1. **深度计算错误**：深度从 0 开始还是从 1 开始要统一
2. **边界条件**：空树的处理
3. **位运算理解**：`1 << h` 表示 2^h，不是 2^h - 1
4. **递归方向**：判断哪个子树是满二叉树，递归计算另一个
5. **完全二叉树定义**：最后一层节点都在最左侧
