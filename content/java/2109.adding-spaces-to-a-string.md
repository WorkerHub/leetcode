## 题目描述

给定字符串s和严格递增数组spaces，在每个spaces[i]位置的字符之前插入空格，返回结果字符串。

## 解题思路

双指针遍历字符串，当下标等于spaces[j]时插入空格。用StringBuilder收集结果。

## Java 代码实现

```java
class Solution {
    public String addSpaces(String s, int[] spaces) {
        StringBuilder sb = new StringBuilder();
        int j = 0;
        for (int i = 0; i < s.length(); i++) {
            if (j < spaces.length && i == spaces[j]) {
                sb.append(' ');
                j++;
            }
            sb.append(s.charAt(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **双指针**：i遍历字符串，j遍历spaces数组
2. **StringBuilder**：避免字符串拼接O(N^2)
3. **spaces严格递增**：可顺序遍历无需二分
