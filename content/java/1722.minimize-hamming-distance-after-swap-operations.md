## 题目描述

给你两个整数数组 `source` 和 `target`，长度都是 `n`，以及 `allowedSwaps[i] = [ai, bi]` 表示可以交换 `source` 中下标 `ai` 和 `bi` 的元素（可多次任意顺序交换）。返回 `source` 与 `target` 之间的**最小汉明距离**。

## 解题思路

用并查集将 `allowedSwaps` 连通的下标合并。同一连通分量内的 `source` 元素可任意排列，用计数贪心匹配 `target` 中对应元素以最小化汉明距离。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent;

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }

    public int minimumHammingDistance(int[] source, int[] target, int[][] allowedSwaps) {
        int n = source.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 合并可交换的下标
        for (int[] swap : allowedSwaps) {
            union(swap[0], swap[1]);
        }

        // 按连通分量分组
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = find(i);
            groups.computeIfAbsent(root, k -> new ArrayList<>()).add(i);
        }

        int hamming = 0;
        for (List<Integer> indices : groups.values()) {
            // 统计该分量中 source 的元素频率
            Map<Integer, Integer> srcCount = new HashMap<>();
            for (int i : indices) {
                srcCount.merge(source[i], 1, Integer::sum);
            }
            // 对 target 中对应位置尝试匹配
            for (int i : indices) {
                int t = target[i];
                if (srcCount.getOrDefault(t, 0) > 0) {
                    srcCount.merge(t, -1, Integer::sum); // 消耗一个匹配
                } else {
                    hamming++; // 无法匹配，汉明距离 +1
                }
            }
        }

        return hamming;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * α(n))，并查集近似线性
- **空间复杂度**：O(n)

## 关键点总结

1. 并查集找出所有连通分量
2. 同一分量内用计数 Map 贪心匹配，最小化未匹配数量
