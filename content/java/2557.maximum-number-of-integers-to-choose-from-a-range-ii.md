## 题目描述

给你已排序无重复数组 `banned`、整数 `n` 和 `maxSum`（n 最大 10^9），从 `[1,n]` 中选不在 banned 中的整数，总和 <= maxSum，返回最多能选的数目。

## 解题思路

二分答案：二分选取数目 cnt，计算"前 cnt 个合法整数之和"是否 <= maxSum。找第 cnt 个合法整数用二分（在 [1,n] 中有 `x - bisect(banned,x)` 个合法整数），再用等差数列前缀和减去 banned 前缀和得到结果。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    int[] banned;
    long[] bannedPrefix;

    public int maxCount(int[] banned, int n, long maxSum) {
        // 过滤掉 > n 的 banned 元素（已排序）
        int m = upperBound(banned, n);
        this.banned = Arrays.copyOf(banned, m);
        this.bannedPrefix = new long[m + 1];
        for (int i = 0; i < m; i++) bannedPrefix[i + 1] = bannedPrefix[i] + banned[i];

        // 合法整数总数
        int total = n - m;
        int lo = 0, hi = total;
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (sumOfFirstK(mid) <= maxSum) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    // 前 k 个合法整数之和
    private long sumOfFirstK(int k) {
        if (k <= 0) return 0;
        // 二分找第 k 个合法整数（1..x 中合法数量 = x - bisect_right(banned, x)）
        int lo = 1, hi = (int) 2e9;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            int valid = mid - upperBound(banned, mid);
            if (valid >= k) hi = mid;
            else lo = mid + 1;
        }
        long kth = lo;
        // 1+2+...+kth 减去 banned 中 <= kth 的数之和
        long total = kth * (kth + 1) / 2;
        int cnt = upperBound(banned, (int) kth);
        return total - bannedPrefix[cnt];
    }

    // 返回 arr 中 <= target 的元素数（upper_bound for <= target）
    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|banned| log n)
- **空间复杂度**：O(|banned|)

## 关键点总结

1. n 可达 10^9，不能逐个枚举，用二分答案
2. 计算"前 k 个合法整数之和"：二分找第 k 个合法整数，用等差数列前缀和减 banned 前缀和
3. banned 前缀和提前计算，避免每次 O(n) 求和
