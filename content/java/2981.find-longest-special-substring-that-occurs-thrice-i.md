## 题目描述

给你字符串 `s`（长度最大 50），找到至少出现三次的最长特殊子字符串（只由单一字母重复组成），不存在则返回 -1。

## 解题思路

将字符串拆分为连续相同字符的段，记录各段长度。对每个字符，长度为 L 的段对长度 k 的特殊子串贡献 L-k+1 次，累加并找出现 >= 3 次的最大 k。

## Java 代码实现

```java
class Solution {
    public int maximumLength(String s) {
        int n = s.length();
        // 统计每个字符、每个长度的出现次数
        int[][] cnt = new int[26][n + 1]; // cnt[c][k] = 字符c长度k的特殊子串出现次数

        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            int c = s.charAt(i) - 'a';
            int L = j - i; // 连续段长度
            for (int k = 1; k <= L; k++) cnt[c][k] += L - k + 1; // 长度 k 出现 L-k+1 次
            i = j;
        }

        int ans = -1;
        for (int c = 0; c < 26; c++)
            for (int k = n; k >= 1; k--)
                if (cnt[c][k] >= 3) { ans = Math.max(ans, k); break; }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)（段内枚举所有长度）
- **空间复杂度**：O(26n)

## 关键点总结

1. 连续相同字符段长度 L 对长度 k 的贡献 = L-k+1
2. 统计出现次数后找满足 >= 3 次的最大长度
3. n <= 50 时 O(n²) 完全够用
