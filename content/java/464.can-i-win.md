## 题目描述

在 "100 game" 这个游戏中，两名玩家轮流选择从 1 到 10 的任意整数，累计整数和，先使得累计整数和达到或超过 100 的玩家，即为胜者。

如果我们将游戏规则改为 "玩家不能重复使用整数" 呢？

例如，两个玩家可以轮流从公共整数池中抽取从 1 到 15 的整数（不放回），直到累计整数和 >= 100。

给定两个整数 `maxChoosableInteger` （整数池中可选择的最大数）和 `desiredTotal`（累计和），若先出手的玩家能稳赢则返回 `true`，否则返回 `false`。假设两位玩家游戏时都表现最佳。

**示例 1：**
```
输入：maxChoosableInteger = 10, desiredTotal = 11
输出：false
解释：
无论第一个玩家选择哪个整数，他都会失败。
第一个玩家可以选择从 1 到 10 的整数。
如果第一个玩家选择 1，那么第二个玩家只能选择从 2 到 10 的整数。
第二个玩家可以通过选择整数 10（那么累积和为 11 >= desiredTotal），从而取得胜利。
同样地，第一个玩家选择任意其他整数，第二个玩家都会赢。
```

**示例 2：**
```
输入：maxChoosableInteger = 10, desiredTotal = 0
输出：true
```

**示例 3：**
```
输入：maxChoosableInteger = 10, desiredTotal = 1
输出：true
```

**提示：**
- `1 <= maxChoosableInteger <= 20`
- `0 <= desiredTotal <= 300`

## 解题思路

这是一道经典的**博弈论 + 记忆化搜索**问题。

**核心观察：**
1. 两个玩家都采用最优策略
2. 当前玩家胜利的条件：
   - 直接选一个数使累计和达到目标
   - 或者无论对手如何选择，自己都能赢

**状态表示：**
- 使用**位掩码（bitmask）**表示哪些数字已被使用
- 例如：`state = 0b1010` 表示数字 2 和 4 已被使用

**递归思路：**
```
canWin(state, remaining):
    如果当前玩家能选一个数使 remaining <= 0，返回 true

    遍历所有未使用的数字 i：
        如果选择 i 后，对手无法获胜（canWin 返回 false）
        那么当前玩家选 i 就能获胜，返回 true

    如果所有选择都让对手获胜，返回 false
```

**边界情况：**
1. 如果所有数字之和 < desiredTotal，先手必输
2. 如果 desiredTotal <= 0，先手直接赢（不需要选数）
3. 如果 maxChoosableInteger >= desiredTotal，先手直接选最大数即赢

## Java 代码实现

### 方法一：记忆化搜索 + 位运算（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int maxChoosableInteger;
    private int desiredTotal;
    private Map<Integer, Boolean> memo = new HashMap<>();

    public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
        this.maxChoosableInteger = maxChoosableInteger;
        this.desiredTotal = desiredTotal;

        // 边界情况 1：所有数字之和都不够
        if ((1 + maxChoosableInteger) * maxChoosableInteger / 2 < desiredTotal) {
            return false;
        }

        // 边界情况 2：目标已达成或为 0
        if (desiredTotal <= 0) {
            return true;
        }

        return canWin(0, desiredTotal);
    }

    private boolean canWin(int state, int remaining) {
        // state: 位掩码，表示哪些数字已被使用
        // remaining: 还需要多少才能达到 desiredTotal
        if (memo.containsKey(state)) {
            return memo.get(state);
        }

        // 尝试选择每个未使用的数字
        for (int i = 1; i <= maxChoosableInteger; i++) {
            int mask = 1 << (i - 1);  // 第 i 个数字的掩码

            // 如果数字 i 未被使用
            if ((state & mask) == 0) {
                // 选择数字 i
                // 如果选 i 后直接赢，或者对手在新状态下输
                if (i >= remaining || !canWin(state | mask, remaining - i)) {
                    memo.put(state, true);
                    return true;
                }
            }
        }

        // 所有选择都让对手赢
        memo.put(state, false);
        return false;
    }
}
```

**核心技巧：**
- `(state & mask) == 0`：检查数字 i 是否未使用
- `state | mask`：标记数字 i 已使用
- `i >= remaining`：选 i 后直接达到目标

### 方法二：使用数组模拟状态（更直观）

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<String, Boolean> memo = new HashMap<>();

    public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
        // 边界情况
        if ((1 + maxChoosableInteger) * maxChoosableInteger / 2 < desiredTotal) {
            return false;
        }
        if (desiredTotal <= 0) {
            return true;
        }

        boolean[] available = new boolean[maxChoosableInteger + 1];
        Arrays.fill(available, 1, maxChoosableInteger + 1, true);

        return canWin(available, desiredTotal, maxChoosableInteger);
    }

    private boolean canWin(boolean[] available, int remaining, int maxNum) {
        // 最大数能直接达成目标
        if (available[maxNum] && maxNum >= remaining) {
            return true;
        }

        // 以可用数字状态作为键（避免重复计算）
        String key = Arrays.toString(available);
        if (memo.containsKey(key)) {
            return memo.get(key);
        }

        // 尝试每个可选数字
        for (int i = 1; i <= maxNum; i++) {
            if (available[i]) {
                available[i] = false;
                // 如果对手在新状态下输，当前玩家赢
                if (!canWin(available, remaining - i, maxNum)) {
                    available[i] = true;
                    memo.put(key, true);
                    return true;
                }
                available[i] = true;
            }
        }

        memo.put(key, false);
        return false;
    }
}
```

**优点：** 代码更易读，但性能略逊于位运算

### 方法三：自底向上 DP

```java
class Solution {
    public boolean canIWin(int maxChoosableInteger, int desiredTotal) {
        // 边界情况
        if ((1 + maxChoosableInteger) * maxChoosableInteger / 2 < desiredTotal) {
            return false;
        }
        if (desiredTotal <= 0) {
            return true;
        }

        int n = maxChoosableInteger;

        // dp[state] 表示在 state 状态下，当前玩家是否能赢
        boolean[] dp = new boolean[1 << n];

        // 从所有数字都被使用的状态开始，倒推
        for (int state = (1 << n) - 1; state >= 0; state--) {
            // 计算当前累计和
            int currentSum = 0;
            for (int i = 0; i < n; i++) {
                if ((state & (1 << i)) != 0) {
                    currentSum += i + 1;
                }
            }

            if (currentSum >= desiredTotal) {
                continue;  // 游戏已结束
            }

            // 尝试每个未使用的数字
            for (int i = 0; i < n; i++) {
                if ((state & (1 << i)) == 0) {  // 数字 i+1 未使用
                    if (i + 1 >= desiredTotal - currentSum || !dp[state | (1 << i)]) {
                        dp[state] = true;
                        break;
                    }
                }
            }
        }

        return dp[0];
    }
}
```

**注意：** 需要额外计算累计和，较复杂

## 复杂度分析

**方法一（位运算 + 记忆化）：**
- 时间复杂度：O(2^n × n)，n = maxChoosableInteger
  - 状态数：2^n（每个数字用或不用）
  - 每个状态遍历 n 个数字
- 空间复杂度：O(2^n)，记忆化字典

**方法二（数组表示）：**
- 时间复杂度：O(2^n × n)
- 空间复杂度：O(2^n)，加上字符串存储开销

**实际优化：**
- 由于 `maxChoosableInteger <= 20`，2^20 ≈ 100 万，可接受
- 记忆化大幅减少重复计算

## 关键点总结

1. **博弈论思想：** 当前玩家赢 = 存在一种选择使对手输
2. **位运算优化：** 用整数表示状态，节省空间和时间
3. **记忆化搜索：** 避免重复计算相同状态
4. **边界处理：**
   - 总和不足：先手必输
   - 目标 <= 0：先手直接赢
5. **状态设计：** 只需记录已使用的数字，不需要记录累计和

## 易错点

1. **忘记边界情况：** 总和不足时直接返回 false
   ```java
   // 必须检查
   if ((1 + maxChoosableInteger) * maxChoosableInteger / 2 < desiredTotal) {
       return false;
   }
   ```

2. **位运算索引错误：** 数字 i 对应的位是 i-1
   ```java
   // 错误
   int mask = 1 << i;  // 数字 i 的掩码（从第 i 位开始）

   // 正确
   int mask = 1 << (i - 1);  // 数字从 1 开始，位从 0 开始
   ```

3. **记忆化键的选择：** 需要同时记录状态和剩余目标
   ```java
   // 错误：只记录 state
   if (memo.containsKey(state)) { ... }

   // 正确：state 已经隐含了累计和信息（或者显式记录）
   // 本题中，state 唯一确定游戏状态，不需要额外记录 remaining
   ```

4. **胜负判断：** 理解"对手输 = 我赢"的逻辑
   ```java
   // 如果对手在新状态下输，我就赢
   if (!canWin(newState, newRemaining)) {
       return true;
   }
   ```
