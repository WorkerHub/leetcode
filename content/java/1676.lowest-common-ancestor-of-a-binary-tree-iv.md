## 题目描述

给定二叉树根节点和一组节点 `nodes`，返回这些节点的最近公共祖先（LCA）。

## 解题思路

**DFS：** 将目标节点的值存入 HashSet。递归时，若当前节点在目标集合中，直接返回（其子孙无需单独处理）。左右子树分别递归，合并结果。

## Java 代码实现

```java
class Solution {
    private Set<Integer> targets;

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode[] nodes) {
        targets = new HashSet<>();
        for (TreeNode node : nodes) targets.add(node.val);
        return dfs(root);
    }

    private TreeNode dfs(TreeNode node) {
        if (node == null) return null;
        // 当前节点在目标集合中，直接返回
        if (targets.contains(node.val)) return node;
        TreeNode left = dfs(node.left);
        TreeNode right = dfs(node.right);
        if (left != null && right != null) return node; // 左右各有目标节点
        return left != null ? left : right;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 目标节点集合用 HashSet 加速查找
2. 若当前节点在集合中，其子孙一定也被覆盖，直接返回
