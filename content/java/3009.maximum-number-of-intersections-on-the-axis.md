## 题目描述

给圆数组 circles[i]=[x,y,r]，返回 x 轴上被最多圆覆盖的点被覆盖的圆的数量。

## 解题思路

对每个与 x 轴相交的圆（y≤r），用整数平方根计算覆盖的整数区间 [x-d, x+d]，用差分数组统计各点覆盖次数，排序后扫描取最大值。

## Java 代码实现

```java
class Solution {
    public int maximumIntersectionCount(int[][] circles) {
        TreeMap<Long, Integer> diff = new TreeMap<>();
        for (int[] c : circles) {
            long x = c[0], y = c[1], r = c[2];
            if (y > r) continue;
            long d = (long) Math.sqrt((double)(r * r - y * y));
            // 修正整数平方根（防止浮点误差）
            while (d * d + y * y > r * r) d--;
            while ((d + 1) * (d + 1) + y * y <= r * r) d++;
            long left = x - d, right = x + d;
            diff.merge(left, 1, Integer::sum);
            diff.merge(right + 1, -1, Integer::sum);
        }
        int ans = 0, cur = 0;
        for (int delta : diff.values()) {
            cur += delta;
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 圆与 x 轴相交条件：y ≤ r
2. 用整数平方根并手动修正避免浮点误差
3. 差分数组 + 排序扫描统计最大覆盖数
