## 题目描述

给你整数数组 `nums`，返回数组 `answer`，其中 `answer[i] = |leftSum[i] - rightSum[i]|`，leftSum[i] 和 rightSum[i] 分别为下标 i 左侧和右侧元素之和。

## 解题思路

用变量维护左侧累加和与右侧累加和：初始 `leftSum=0`，`rightSum=totalSum`；每步先从 rightSum 减去当前元素，计算差的绝对值，再将当前元素加到 leftSum。

## Java 代码实现

```java
class Solution {
    public int[] leftRightDifference(int[] nums) {
        int n = nums.length;
        int leftSum = 0, rightSum = 0;
        for (int v : nums) rightSum += v;

        int[] answer = new int[n];
        for (int i = 0; i < n; i++) {
            rightSum -= nums[i]; // 右侧不含 i
            answer[i] = Math.abs(leftSum - rightSum);
            leftSum += nums[i]; // 左侧更新供下次使用
        }
        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 用两个变量代替前缀数组，节省空间
2. 每步先更新 rightSum（去除当前元素），再计算，再更新 leftSum
3. 结果取绝对值
