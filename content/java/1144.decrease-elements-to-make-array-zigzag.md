## 题目描述

给定整数数组 nums，每次操作将某元素减 1。使数组成为锯齿数组（交替大小）的最少操作次数。两种锯齿模式选操作少的。

**示例：**
```
输入：nums = [9,6,1,6,2]
输出：4
```

## 解题思路

分别计算两种模式的代价取最小。对于需要成为"谷底"的位置 i，操作数 = max(0, nums[i] - min(左邻, 右邻) + 1)。一次遍历同时计算两种模式。

## Java 代码实现

```java
class Solution {
    public int movesToMakeZigzag(int[] nums) {
        int n = nums.length;
        int[] moves = new int[2]; // moves[0]: 偶数位小, moves[1]: 奇数位小

        for (int i = 0; i < n; i++) {
            int left = (i > 0) ? nums[i - 1] : Integer.MAX_VALUE;
            int right = (i < n - 1) ? nums[i + 1] : Integer.MAX_VALUE;
            int minNeighbor = Math.min(left, right);

            // 位置 i 需要成为谷底时的操作数
            if (nums[i] >= minNeighbor) {
                moves[i % 2] += nums[i] - minNeighbor + 1;
            }
        }

        return Math.min(moves[0], moves[1]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两种模式**：偶数位做谷 vs 奇数位做谷，选代价小的
2. **贪心**：每个谷底位置减到 min(邻居)-1
3. **边界处理**：首尾元素只有一个邻居，另一侧设 MAX_VALUE
4. **一次遍历**：`moves[i%2]` 同时累积两种模式
