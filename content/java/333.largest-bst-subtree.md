## 题目描述

给定一个二叉树，找到其中最大的二叉搜索树（BST）子树，并返回该子树的节点数。

**注意:**

- 子树必须包含其所有后代。
- BST 的定义：左子树的所有节点值小于根节点值，右子树的所有节点值大于根节点值，且左右子树也必须是 BST。

**示例 1:**

```
输入: 
    10
    / \
   5  15
  / \   \ 
 1   8   7

输出: 3
解释: 高亮部分为最大的 BST 子树。
     返回值 3 是这个子树的节点数。
      5
     / \
    1   8
```

**示例 2:**

```
输入:
    10
    / \
   5  15
  /     
 1   

输出: 3
```

**提示:**

- 树中节点数目在范围 `[0, 10^4]` 内
- `-10^4 <= Node.val <= 10^4`

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题的核心是**自底向上**传递信息，判断每个子树是否为 BST。

### 核心思想

1. **后序遍历**：先处理左右子树，再处理当前节点
2. **返回信息**：每个节点需要返回：
   - `isBST`：是否为 BST
   - `size`：子树节点数
   - `minVal`：子树最小值
   - `maxVal`：子树最大值
3. **BST 判断条件**：
   - 左子树是 BST 且左子树最大值 < 当前节点值
   - 右子树是 BST 且右子树最小值 > 当前节点值
4. **更新最大值**：遍历过程中更新全局最大 BST 节点数

## Java 代码实现

### 方法一：后序遍历（推荐）⭐

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    // 全局最大 BST 节点数
    private int maxSize = 0;

    public int largestBSTSubtree(TreeNode root) {
        dfs(root);
        return maxSize;
    }

    /**
     * 返回 int[4]: {isBST(1=true/0=false), size, minVal, maxVal}
     */
    private int[] dfs(TreeNode node) {
        // 空节点：minVal = MAX_VALUE, maxVal = MIN_VALUE
        if (node == null) {
            return new int[]{1, 0, Integer.MAX_VALUE, Integer.MIN_VALUE};
        }

        // 递归处理左右子树
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        // 判断当前树是否为 BST
        // left[0]=isBST, left[3]=maxVal; right[0]=isBST, right[2]=minVal
        if (left[0] == 1 && right[0] == 1 && left[3] < node.val && node.val < right[2]) {
            // 是 BST
            int size = left[1] + right[1] + 1;
            maxSize = Math.max(maxSize, size);

            // 最小值：左子树最小值或当前值
            int minVal = Math.min(left[2], node.val);
            // 最大值：右子树最大值或当前值
            int maxVal = Math.max(right[3], node.val);

            return new int[]{1, size, minVal, maxVal};
        } else {
            // 不是 BST
            return new int[]{0, 0, 0, 0};
        }
    }
}
```

### 方法二：使用内部类封装状态（更清晰）

```java
class Solution {
    // BST 信息封装类
    static class BSTInfo {
        boolean isBST;
        int size;
        int minVal;
        int maxVal;

        BSTInfo(boolean isBST, int size, int minVal, int maxVal) {
            this.isBST = isBST;
            this.size = size;
            this.minVal = minVal;
            this.maxVal = maxVal;
        }
    }

    private int maxSize = 0;

    public int largestBSTSubtree(TreeNode root) {
        dfs(root);
        return maxSize;
    }

    private BSTInfo dfs(TreeNode node) {
        // 空节点
        if (node == null) {
            return new BSTInfo(true, 0, Integer.MAX_VALUE, Integer.MIN_VALUE);
        }

        // 递归处理左右子树
        BSTInfo left = dfs(node.left);
        BSTInfo right = dfs(node.right);

        // 判断当前树是否为 BST
        if (left.isBST && right.isBST && left.maxVal < node.val && node.val < right.minVal) {
            // 是 BST
            int size = left.size + right.size + 1;
            maxSize = Math.max(maxSize, size);

            return new BSTInfo(
                true,
                size,
                Math.min(left.minVal, node.val),
                Math.max(right.maxVal, node.val)
            );
        } else {
            // 不是 BST
            return new BSTInfo(false, 0, 0, 0);
        }
    }
}
```

### 方法三：暴力解法（不推荐）

```java
class Solution {
    public int largestBSTSubtree(TreeNode root) {
        // 暴力解法：对每个节点判断以它为根的树是否为 BST，时间复杂度 O(n^2)
        if (root == null) return 0;

        // 如果当前子树是 BST，计算节点数
        if (isBST(root, Long.MIN_VALUE, Long.MAX_VALUE)) {
            return countNodes(root);
        }

        // 否则，递归检查左右子树
        return Math.max(largestBSTSubtree(root.left), largestBSTSubtree(root.right));
    }

    private boolean isBST(TreeNode node, long minVal, long maxVal) {
        if (node == null) return true;
        if (node.val <= minVal || node.val >= maxVal) return false;
        return isBST(node.left, minVal, node.val) && isBST(node.right, node.val, maxVal);
    }

    private int countNodes(TreeNode node) {
        if (node == null) return 0;
        return 1 + countNodes(node.left) + countNodes(node.right);
    }
}
```

## 复杂度分析

**方法一/二：后序遍历**

- **时间复杂度**：O(n)
  - 每个节点访问一次
  
- **空间复杂度**：O(h)
  - h：树的高度，递归栈的空间

**方法三：暴力解法**

- **时间复杂度**：O(n^2)
  - 对每个节点都判断一次是否为 BST（O(n)），共 n 个节点
  
- **空间复杂度**：O(h)
  - 递归栈的空间

## 关键点总结

1. **后序遍历**：先处理子树，再处理当前节点
2. **信息传递**：每个节点返回 `(isBST, size, minVal, maxVal)`
3. **BST 判断**：
   - 左右子树都是 BST
   - `left.maxVal < node.val < right.minVal`
4. **边界值处理**：
   - 空节点：`minVal = Integer.MAX_VALUE`，`maxVal = Integer.MIN_VALUE`
   - 叶子节点：`minVal = maxVal = node.val`
5. **全局变量**：使用成员变量记录最大值

## 易错点

1. **空节点的最小最大值**：
   - 正确：`minVal = Integer.MAX_VALUE`，`maxVal = Integer.MIN_VALUE`
   - 错误：`minVal = Integer.MIN_VALUE`，`maxVal = Integer.MAX_VALUE`（会导致判断错误）

2. **BST 判断条件**：
   - 正确：`left.maxVal < node.val && node.val < right.minVal`（严格小于）
   - 错误：使用 `<=`（BST 不允许相等）

3. **最小最大值的更新**：
   - 最小值：`Math.min(left.minVal, node.val)`
   - 最大值：`Math.max(right.maxVal, node.val)`

4. **非 BST 的返回值**：返回 `(false, 0, 0, 0)` 即可，后面的值不重要

5. **暴力解法溢出**：用 `long` 类型传递边界值，避免 `Integer.MIN_VALUE - 1` 溢出
