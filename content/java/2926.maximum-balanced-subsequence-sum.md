## 题目描述

选取平衡子序列（相邻下标满足nums[j]-nums[i]>=j-i），使元素和最大。

## 解题思路

令a[i]=nums[i]-i，条件变为a[j]>=a[i]。用树状数组维护离散化后a值的前缀最大dp值。

## Java 代码实现

```java
class Solution {
    private long[] bit;
    private int m;

    public long maxBalancedSubsequenceSum(int[] nums) {
        int n = nums.length;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = nums[i] - i;

        // 离散化
        int[] sorted = Arrays.stream(a).distinct().sorted().toArray();
        m = sorted.length;
        Map<Integer, Integer> rank = new HashMap<>();
        for (int i = 0; i < m; i++) rank.put(sorted[i], i + 1);

        bit = new long[m + 1];
        Arrays.fill(bit, Long.MIN_VALUE);

        long ans = Long.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            int r = rank.get(a[i]);
            long prevMax = query(r);
            long dpI = nums[i] + Math.max(0, prevMax);
            ans = Math.max(ans, dpI);
            update(r, dpI);
        }
        return ans;
    }

    private void update(int i, long val) {
        for (; i <= m; i += i & (-i)) {
            bit[i] = Math.max(bit[i], val);
        }
    }

    private long query(int i) {
        long res = Long.MIN_VALUE;
        for (; i > 0; i -= i & (-i)) {
            res = Math.max(res, bit[i]);
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **关键变换**：nums[j]-j >= nums[i]-i，转为一维非递减条件
2. **树状数组维护前缀max**：update取max而非加法
3. **prevMax<=0时不选前驱**：dp_i = nums[i]
