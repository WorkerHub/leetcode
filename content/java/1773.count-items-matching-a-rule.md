## 题目描述

给你物品数组 `items[i] = [type, color, name]` 和规则 `(ruleKey, ruleValue)`，返回匹配规则的物品数目。

## 解题思路

将 ruleKey 映射到索引（type→0, color→1, name→2），统计对应字段等于 ruleValue 的物品数。

## Java 代码实现

```java
import java.util.List;

class Solution {
    public int countMatches(List<List<String>> items, String ruleKey, String ruleValue) {
        // 确定对应的字段索引
        int idx;
        if (ruleKey.equals("type")) idx = 0;
        else if (ruleKey.equals("color")) idx = 1;
        else idx = 2; // "name"

        int count = 0;
        for (List<String> item : items) {
            if (item.get(idx).equals(ruleValue)) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

1. ruleKey 映射到列表索引，简化判断逻辑
