## 题目描述

给定字符串数组 `words`，统计对 `(i, j)`（`i < j`）中 `words[i]` 是 `words[j]` 的前缀或 `words[j]` 是 `words[i]` 的前缀的数量。

## Java 代码实现

```java
class Solution {
    public int countPrefixSuffixPairs(String[] words) {
        int n = words.length;
        int count = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                String a = words[i], b = words[j];
                // a 是 b 的前缀，或 b 是 a 的前缀
                if (b.startsWith(a) || a.startsWith(b)) count++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n² * L)，n 为词数，L 为最大词长
- 空间复杂度：O(1)

## 关键点总结

1. `String.startsWith()` 简洁高效，n ≤ 50 时 O(n²) 完全可行
2. 前缀关系是双向的，需同时检查两个方向
3. 相等的两个词互为前缀
