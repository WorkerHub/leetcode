## 题目描述

给定整数数组 `nums`，找最长子序列，使得相邻元素差的绝对值非递增，返回该子序列的最大长度。

## Java 代码实现

```java
class Solution {
    public int longestSubsequence(int[] nums) {
        int n = nums.length;
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // dp[i][d] = 以 nums[i] 结尾、最后差恰为 d 的最长子序列长度
        // suf[i][d] = max(dp[i][d], dp[i][d+1], ...) 后缀最大值
        int[][] suf = new int[n][maxVal + 2];

        int ans = 1;

        for (int i = 0; i < n; i++) {
            int[] fi = new int[maxVal + 2];
            // 初始：单独元素，差未定义，长度 1
            for (int d = 0; d <= maxVal + 1; d++) fi[d] = 1;

            for (int j = 0; j < i; j++) {
                int d = Math.abs(nums[i] - nums[j]);
                // 从 j 转移，需要 j 处最后差 >= d
                int newLen = suf[j][d] + 1;
                if (newLen > fi[d]) fi[d] = newLen;
            }

            // 计算后缀最大值
            suf[i][maxVal + 1] = fi[maxVal + 1];
            for (int d = maxVal; d >= 0; d--) {
                suf[i][d] = Math.max(fi[d], suf[i][d + 1]);
            }
            ans = Math.max(ans, suf[i][0]);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 + n * MAX_VAL)
- 空间复杂度：O(n * MAX_VAL)

## 关键点总结

1. 状态 `dp[i][d]` 表示以 nums[i] 结尾且最后差为 d 的最长子序列。
2. 转移时需要前驱的最后差 >= 当前差，用后缀最大值优化。
3. 后缀最大值从大到小计算：`suf[i][d] = max(dp[i][d], suf[i][d+1])`。
