## 题目描述

给你整数数组 `nums` 和整数 `k`，每次操作选一个元素加入得分并将其替换为 `ceil(值/3)`，执行 `k` 次，返回最大得分。

## 解题思路

贪心 + 最大堆：每次选当前最大元素加入得分，然后将其替换为 `ceil(val/3) = (val+2)/3` 后重新入堆。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long maxKelements(int[] nums, int k) {
        // 最大堆
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int x : nums) maxHeap.offer(x);

        long score = 0;
        for (int i = 0; i < k; i++) {
            int val = maxHeap.poll();
            score += val;
            // ceil(val / 3) = (val + 2) / 3
            maxHeap.offer((val + 2) / 3);
        }
        return score;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：每次选最大元素保证得分最大化
2. `ceil(val/3)` 的整数实现：`(val + 2) / 3`，避免浮点误差
3. 用 `long` 累加得分，防止溢出
