## 题目描述

给你 `n` 节点带权无向图，可以最多将 `k` 条边的权重置为 0，返回从 `src` 到 `dst` 的最短路径长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int shortestPathWithHops(int n, int[][] edges, int src, int dst, int k) {
        // 建邻接表
        List<int[]>[] adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            adj[e[0]].add(new int[]{e[1], e[2]});
            adj[e[1]].add(new int[]{e[0], e[2]});
        }

        // dist[node][hops] = 使用 hops 次免费跳跃到达 node 的最短距离
        long[][] dist = new long[n][k + 1];
        for (long[] row : dist) Arrays.fill(row, Long.MAX_VALUE);
        dist[src][0] = 0;

        // 堆：(距离, 节点, 已用跳跃次数)
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, src, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1], hops = (int) cur[2];
            if (d > dist[u][hops]) continue;

            for (int[] next : adj[u]) {
                int v = next[0], w = next[1];
                // 正常走
                if (d + w < dist[v][hops]) {
                    dist[v][hops] = d + w;
                    pq.offer(new long[]{dist[v][hops], v, hops});
                }
                // 免费跳跃（将该边权置为 0）
                if (hops < k && d < dist[v][hops + 1]) {
                    dist[v][hops + 1] = d;
                    pq.offer(new long[]{d, v, hops + 1});
                }
            }
        }

        long ans = Long.MAX_VALUE;
        for (int h = 0; h <= k; h++) ans = Math.min(ans, dist[dst][h]);
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) * k * log(nk))，m 为边数
- 空间复杂度：O(nk + m)

## 关键点总结

1. 扩展 Dijkstra 状态为 `(节点, 已用免费跳跃次数)`，共 `n * (k+1)` 个状态
2. 每条边有两种转移：正常走（累加权重）或免费跳跃（不累加权重，跳跃数+1）
3. 取 `dist[dst][0..k]` 的最小值即为答案
