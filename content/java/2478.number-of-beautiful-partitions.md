## 题目描述

给你字符串 `s`（只含数字字符）和整数 `k`、`minLength`，将 `s` 分成 `k` 段，每段长度至少为 `minLength` 且首字符为素数（2/3/5/7）、末字符为非素数，返回方案数对 `10^9+7` 取余。

## 解题思路

DP + 前缀和优化：`f[i][j]` 表示 `s[0..i-1]` 分成 `j` 段的方案数。枚举每个合法终点 `i`（`s[i-1]` 非素数），用滑动指针维护合法起点的 `f[ptr][j-1]` 之和（起点字符为素数且距终点 `>= minLength`）。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;
    private static final String PRIMES = "2357";

    public int beautifulPartitions(String s, int k, int minLength) {
        int n = s.length();
        // 初始条件检查
        if (PRIMES.indexOf(s.charAt(0)) < 0 || PRIMES.indexOf(s.charAt(n - 1)) >= 0) return 0;

        int[][] f = new int[n + 1][k + 1];
        f[0][0] = 1;

        for (int j = 1; j <= k; j++) {
            int prefix = 0, ptr = 0;
            for (int i = minLength; i <= n; i++) {
                // 以 s[i-1] 为终点，终点必须为非素数
                if (PRIMES.indexOf(s.charAt(i - 1)) >= 0) continue;

                // 更新前缀和：加入所有满足条件的起点 ptr
                while (ptr <= i - minLength) {
                    if (PRIMES.indexOf(s.charAt(ptr)) >= 0) {
                        // 起点 ptr 对应 f[ptr][j-1]
                        prefix = (prefix + f[ptr][j - 1]) % MOD;
                    }
                    ptr++;
                }
                f[i][j] = prefix;
            }
        }
        return f[n][k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)
- **空间复杂度**：O(n × k)

## 关键点总结

1. 每段首字符为素数、末字符为非素数，用字符串 "2357" 快速判断
2. 前缀和 + 滑动指针将内层循环从 O(n) 优化到 O(1)
3. 初始条件：`s[0]` 必须是素数，`s[n-1]` 必须是非素数，否则直接返回 0
