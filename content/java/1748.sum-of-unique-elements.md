## 题目描述

给你整数数组 `nums`，返回只出现恰好一次的元素之和。

## 解题思路

用数组（或哈希表）统计每个元素出现次数，将出现次数为 1 的元素求和。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int sumOfUnique(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : nums) {
            count.merge(x, 1, Integer::sum);
        }
        int sum = 0;
        for (Map.Entry<Integer, Integer> e : count.entrySet()) {
            if (e.getValue() == 1) sum += e.getKey(); // 只出现一次的元素
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 统计频率后过滤出现次数恰好为 1 的元素求和
