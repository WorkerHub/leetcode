## 题目描述

给你一个整数数组 `nums`，按要求返回一个新数组 `counts`。数组 `counts` 有该性质： `counts[i]` 的值是  `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

**示例 1：**
```
输入：nums = [5,2,6,1]
输出：[2,1,1,0] 
解释：
5 的右侧有 2 个更小的元素 (2 和 1)
2 的右侧仅有 1 个更小的元素 (1)
6 的右侧有 1 个更小的元素 (1)
1 的右侧有 0 个更小的元素
```

**示例 2：**
```
输入：nums = [-1]
输出：[0]
```

**示例 3：**
```
输入：nums = [-1,-1]
输出：[0,0]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

这是一道经典的**逆序对**问题的变体。

### 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 |
|------|-----------|-----------|------|
| 暴力 | O(n²) | O(1) | 简单 |
| 归并排序 | O(n log n) | O(n) | 中等 |
| 树状数组 | O(n log n) | O(n) | 中等 |
| 线段树 | O(n log n) | O(n) | 较难 |

### 核心思想

**从右往左遍历**，维护一个有序结构，统计当前元素在结构中的位置。

## Java 代码实现

### 方法一：归并排序（推荐）⭐

```java
import java.util.*;

class Solution {
    private int[] indices; // 索引数组，归并排序时保持原始索引
    private int[] counts;  // 结果数组
    private int[] nums;    // 原数组

    public List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        this.nums = nums;
        this.indices = new int[n];
        this.counts = new int[n];

        // 初始化索引数组
        for (int i = 0; i < n; i++) indices[i] = i;

        mergeSort(0, n - 1);

        // 将结果转为 List
        List<Integer> result = new ArrayList<>();
        for (int c : counts) result.add(c);
        return result;
    }

    private void mergeSort(int left, int right) {
        if (left >= right) return;

        int mid = (left + right) / 2;
        mergeSort(left, mid);
        mergeSort(mid + 1, right);
        merge(left, mid, right);
    }

    private void merge(int left, int mid, int right) {
        int[] temp = new int[right - left + 1];
        int i = left, j = mid + 1, k = 0;

        while (i <= mid && j <= right) {
            if (nums[indices[i]] <= nums[indices[j]]) {
                // 统计右侧小于当前元素的数量
                counts[indices[i]] += j - (mid + 1);
                temp[k++] = indices[i++];
            } else {
                temp[k++] = indices[j++];
            }
        }

        // 处理剩余的左侧元素
        while (i <= mid) {
            counts[indices[i]] += j - (mid + 1);
            temp[k++] = indices[i++];
        }

        // 处理剩余的右侧元素
        while (j <= right) {
            temp[k++] = indices[j++];
        }

        // 更新索引数组
        for (int t = 0; t < temp.length; t++) {
            indices[left + t] = temp[t];
        }
    }
}
```

### 方法二：树状数组

```java
import java.util.*;

class Solution {
    private int[] tree;
    private int size;

    public List<Integer> countSmaller(int[] nums) {
        // 离散化：将数值映射到 [1, n] 范围
        int[] sortedNums = nums.clone();
        Arrays.sort(sortedNums);
        // 去重
        int uniqueCount = 0;
        int[] unique = new int[sortedNums.length];
        for (int i = 0; i < sortedNums.length; i++) {
            if (i == 0 || sortedNums[i] != sortedNums[i - 1]) {
                unique[uniqueCount++] = sortedNums[i];
            }
        }

        // 建立值到排名的映射
        Map<Integer, Integer> rank = new HashMap<>();
        for (int i = 0; i < uniqueCount; i++) {
            rank.put(unique[i], i + 1);
        }

        size = uniqueCount;
        tree = new int[size + 1];

        List<Integer> result = new ArrayList<>();
        // 从右往左遍历
        for (int i = nums.length - 1; i >= 0; i--) {
            int r = rank.get(nums[i]);
            // 查询比当前元素小的数量
            result.add(query(r - 1));
            // 将当前元素加入树状数组
            update(r, 1);
        }

        // 结果需要反转
        Collections.reverse(result);
        return result;
    }

    // 低位运算
    private int lowbit(int x) {
        return x & (-x);
    }

    // 单点更新
    private void update(int i, int delta) {
        while (i <= size) {
            tree[i] += delta;
            i += lowbit(i);
        }
    }

    // 前缀查询
    private int query(int i) {
        int result = 0;
        while (i > 0) {
            result += tree[i];
            i -= lowbit(i);
        }
        return result;
    }
}
```

### 方法三：暴力方法（会超时）

```java
import java.util.*;

class Solution {
    public List<Integer> countSmaller(int[] nums) {
        List<Integer> result = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = i + 1; j < n; j++) {
                if (nums[j] < nums[i]) count++;
            }
            result.add(count);
        }

        return result;
    }
}
```

### 方法四：二分查找 + 有序列表

```java
import java.util.*;

class Solution {
    public List<Integer> countSmaller(int[] nums) {
        List<Integer> result = new ArrayList<>();
        List<Integer> sortedList = new ArrayList<>();

        // 从右往左遍历
        for (int i = nums.length - 1; i >= 0; i--) {
            // 二分查找插入位置（第一个 >= nums[i] 的位置）
            int pos = lowerBound(sortedList, nums[i]);
            result.add(pos);
            // 插入元素
            sortedList.add(pos, nums[i]);
        }

        // 结果需要反转
        Collections.reverse(result);
        return result;
    }

    // 二分查找：返回第一个 >= target 的位置
    private int lowerBound(List<Integer> list, int target) {
        int left = 0, right = list.size();
        while (left < right) {
            int mid = (left + right) / 2;
            if (list.get(mid) < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
```

## 复杂度分析

**归并排序：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

**树状数组：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

**二分查找 + 插入：**
- 时间复杂度：O(n²)，插入操作是 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **归并排序**：在合并时统计逆序对
2. **树状数组**：离散化 + 从右往左插入
3. **索引数组**：归并排序时需要保持原始索引
4. **从右往左**：维护已遍历元素的有序结构
5. **离散化**：树状数组需要将值映射到 [1, n] 范围

## 易错点

1. **归并排序的统计时机**：在左边元素归并时统计
2. **离散化**：树状数组的索引从 1 开始
3. **结果反转**：从右往左遍历，最后要反转结果
4. **等于的情况**：`<=` 时才统计右侧元素
5. **索引数组**：归并排序时要维护原始索引
