## 题目描述

给定一个由数字组成的字符串 `s`，找出其所有子字符串（转换为数字后）中的质数，返回最大的 3 个不同质数之和。若不足 3 个不同质数，返回所有不同质数子串的和。

## 解题思路

字符串长度 <= 10，最多 55 个子串。枚举所有子串，转换为整数，判断是否为质数，用集合去重，排序后取最大 3 个求和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private boolean isPrime(long n) {
        if (n < 2) return false;
        if (n == 2) return true;
        if (n % 2 == 0) return false;
        for (long i = 3; i * i <= n; i += 2)
            if (n % i == 0) return false;
        return true;
    }

    public long sumOfLargestPrimes(String s) {
        int n = s.length();
        Set<Long> primes = new HashSet<>();

        // 枚举所有子串
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j <= n; j++) {
                long num = Long.parseLong(s.substring(i, j));
                if (isPrime(num)) primes.add(num);
            }
        }

        // 取最大的 3 个不同质数求和
        List<Long> sorted = new ArrayList<>(primes);
        sorted.sort(Collections.reverseOrder());
        long ans = 0;
        for (int i = 0; i < Math.min(3, sorted.size()); i++)
            ans += sorted.get(i);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * sqrt(10^n))，n 为字符串长度，最多 10
- 空间复杂度：O(n^2)，存储所有质数子串

## 关键点总结

1. 字符串长度 <= 10，枚举所有 O(n^2) 个子串
2. 子串转整数后用集合去重（前导零子串值相同）
3. 取不同质数中最大的 3 个求和
