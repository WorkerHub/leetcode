## 题目描述

在一排多米诺骨牌中，`tops[i]` 和 `bottoms[i]` 分别代表第 `i` 个多米诺骨牌的上半部分和下半部分。（一个多米诺是两个从 1 到 6 的数字同列平铺形成的，该列的每一半上都有一个数字。）

我们可以旋转第 `i` 个多米诺，使得 `tops[i]` 和 `bottoms[i]` 的值交换。

返回能使 `tops` 中所有值或者 `bottoms` 中所有值都相同的最小旋转次数。

如果无法做到，返回 `-1`。

**示例 1：**
```
输入：tops = [2,1,2,4,2,2], bottoms = [5,2,6,2,3,2]
输出：2
解释：
图一表示：在我们旋转之前，tops 和 bottoms
图二表示：旋转位置 2 和 4 之后，使得 bottoms 中所有元素都是 2
```

**示例 2：**
```
输入：tops = [3,5,1,2,3], bottoms = [3,6,3,3,4]
输出：-1
解释：
在这种情况下，无论怎样旋转都不能使所有值都相同。
```

**提示：**
- `2 <= tops.length <= 2 * 10^4`
- `bottoms.length == tops.length`
- `1 <= tops[i], bottoms[i] <= 6`

## 解题思路

这道题的关键观察是：

**核心思想：**
1. 如果能让所有值相同，这个值**必定是** `tops[0]` 或 `bottoms[0]`
2. 因为每一列都必须包含这个目标值（否则无法旋转得到）
3. 所以我们只需要检查 `tops[0]` 和 `bottoms[0]` 这两个候选值

**算法流程：**
1. 尝试将所有位置的 top 或 bottom 变成 `tops[0]`
2. 尝试将所有位置的 top 或 bottom 变成 `bottoms[0]`
3. 计算每种情况所需的最小旋转次数
4. 返回最小值，如果都无法实现则返回 -1

**旋转次数计算：**
- 如果第 i 列的 top 已经是目标值，不需要旋转
- 如果第 i 列的 bottom 是目标值，需要旋转一次
- 如果两者都不是目标值，说明无法实现

## Java 代码实现

### 方法一：贪心（推荐）

```java
class Solution {
    public int minDominoRotations(int[] tops, int[] bottoms) {
        // 只需要检查 tops[0] 和 bottoms[0] 两个候选值
        int result = check(tops[0], tops, bottoms);

        // 如果 tops[0] 和 bottoms[0] 不同，还需要检查 bottoms[0]
        if (tops[0] != bottoms[0]) {
            int result2 = check(bottoms[0], tops, bottoms);
            if (result == -1) return result2;
            if (result2 != -1) result = Math.min(result, result2);
        }

        return result;
    }

    /**
     * 检查能否让所有位置的 top 或 bottom 都变成 target
     * 返回最小旋转次数，如果无法实现返回 -1
     */
    private int check(int target, int[] tops, int[] bottoms) {
        int rotationsToTop = 0;    // 将 target 都旋转到 top 的次数
        int rotationsToBottom = 0; // 将 target 都旋转到 bottom 的次数

        for (int i = 0; i < tops.length; i++) {
            if (tops[i] != target && bottoms[i] != target) {
                // 该列既没有 target 在 top，也没有在 bottom
                return -1;
            }

            // 如果 top 不是 target，需要旋转到 top
            if (tops[i] != target) rotationsToTop++;
            // 如果 bottom 不是 target，需要旋转到 bottom
            if (bottoms[i] != target) rotationsToBottom++;
        }

        // 返回两种方案的最小值
        return Math.min(rotationsToTop, rotationsToBottom);
    }
}
```

### 方法二：简化版

```java
class Solution {
    public int minDominoRotations(int[] tops, int[] bottoms) {
        int n = tops.length;

        // 尝试 tops[0] 和 bottoms[0] 两个候选值
        int[] candidates = tops[0] == bottoms[0] ?
            new int[]{tops[0]} :
            new int[]{tops[0], bottoms[0]};

        for (int target : candidates) {
            int topRotations = 0;
            int bottomRotations = 0;
            boolean valid = true;

            for (int i = 0; i < n; i++) {
                if (tops[i] != target && bottoms[i] != target) {
                    valid = false;
                    break;
                }
                if (tops[i] != target) topRotations++;
                if (bottoms[i] != target) bottomRotations++;
            }

            if (valid) return Math.min(topRotations, bottomRotations);
        }

        return -1;
    }
}
```

### 方法三：计数优化

```java
class Solution {
    public int minDominoRotations(int[] tops, int[] bottoms) {
        int n = tops.length;
        // 统计每个数字在 top 和 bottom 中出现的次数
        int[] topCount = new int[7];
        int[] bottomCount = new int[7];
        int[] sameCount = new int[7]; // 同一位置 top==bottom 的次数

        for (int i = 0; i < n; i++) {
            topCount[tops[i]]++;
            bottomCount[bottoms[i]]++;
            if (tops[i] == bottoms[i]) sameCount[tops[i]]++;
        }

        // 检查每个可能的目标值（1-6）
        for (int target = 1; target <= 6; target++) {
            // 如果 target 出现的总次数（去重）等于 n，说明可行
            if (topCount[target] + bottomCount[target] - sameCount[target] == n) {
                return n - Math.max(topCount[target], bottomCount[target]);
            }
        }

        return -1;
    }
}
```

## 复杂度分析

**方法一、二、三：**
- **时间复杂度：** O(n)，最多遍历数组两次
- **空间复杂度：** O(1)

## 关键点总结

1. **候选值限定**：目标值只能是 `tops[0]` 或 `bottoms[0]`
2. **必要条件**：每一列都必须包含目标值（在 top 或 bottom 中）
3. **两种方案**：将目标值都移到 top，或都移到 bottom
4. **贪心选择**：选择旋转次数较少的方案
5. **优化技巧**：只需要检查最多 2 个候选值，而不是 6 个

## 易错点

1. **候选值遗漏**：忘记检查 `bottoms[0]`（当它与 `tops[0]` 不同时）
2. **返回值错误**：应该返回最小旋转次数，不是最大次数
3. **边界情况**：
   - 所有 top 和 bottom 都相同
   - 无法实现的情况
4. **计数错误**：同一位置 top 和 bottom 相同时，不要重复计数
