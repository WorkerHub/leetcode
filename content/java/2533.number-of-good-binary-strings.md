## 题目描述

给你四个整数，好二进制字符串长度在 `[minLength, maxLength]` 之间，每个 1 的连续组长度是 `oneGroup` 的倍数，每个 0 的连续组长度是 `zeroGroup` 的倍数，返回好字符串的数目（对 `10^9+7` 取模）。

## 解题思路

DP：`dp[i]` = 长度恰好为 i 的好字符串数。在末尾追加 `zeroGroup` 个 0（从 `dp[i-zeroGroup]`）或 `oneGroup` 个 1（从 `dp[i-oneGroup]`），汇总 `[minLength, maxLength]` 范围内的结果。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public int goodBinaryStrings(int minLength, int maxLength, int oneGroup, int zeroGroup) {
        int[] dp = new int[maxLength + 1];
        dp[0] = 1; // 空字符串是有效起点

        for (int i = 1; i <= maxLength; i++) {
            // 在长度为 i-zeroGroup 的好字符串后追加 zeroGroup 个 0
            if (i >= zeroGroup) dp[i] = (dp[i] + dp[i - zeroGroup]) % MOD;
            // 在长度为 i-oneGroup 的好字符串后追加 oneGroup 个 1
            if (i >= oneGroup)  dp[i] = (dp[i] + dp[i - oneGroup]) % MOD;
        }

        long ans = 0;
        for (int i = minLength; i <= maxLength; i++) ans += dp[i];
        return (int) (ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(maxLength)
- **空间复杂度**：O(maxLength)

## 关键点总结

1. `dp[0] = 1` 作为基础状态（空字符串），通过不断追加整组构建
2. 每次追加完整的 0 组或 1 组，而非单个字符
3. 最终对 `[minLength, maxLength]` 范围内的 dp 值求和
