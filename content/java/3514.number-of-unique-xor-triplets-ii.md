## 题目描述

给定整数数组 `nums`（元素不一定是排列，n <= 1500，值 <= 10^9）。求有多少个不同的值可以表示为 `nums[i] XOR nums[j] XOR nums[k]`（i < j < k）。

## 解题思路

先计算所有两元素 XOR 构建线性基，再将所有 `nums[k]` 也插入线性基，线性基张成大小即为答案（`2^基底数`）。

## Java 代码实现

```java
class Solution {
    public int uniqueXorTriplets(int[] nums) {
        int n = nums.length;
        int[] basis = new int[30];
        int bSize = 0;

        // 所有两元素 XOR 插入线性基
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int x = nums[i] ^ nums[j];
                for (int b = 0; b < bSize; b++) x = Math.min(x, x ^ basis[b]);
                if (x > 0) basis[bSize++] = x;
            }
        }
        // 所有 nums[k] 也插入
        for (int x : nums) {
            for (int b = 0; b < bSize; b++) x = Math.min(x, x ^ basis[b]);
            if (x > 0) basis[bSize++] = x;
        }

        return 1 << bSize;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max_val))
- 空间复杂度：O(log(max_val))

## 关键点总结

1. 三元组 XOR = (两元素 XOR) XOR (第三元素)
2. 线性基大小 b 对应张成空间 `2^b` 个不同值
3. 将两元素 XOR 和所有 nums[k] 合入同一线性基
