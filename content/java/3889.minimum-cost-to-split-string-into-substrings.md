## 题目描述

给你一个字符串 `s`，将其分割为若干子串，每个子串的代价为其中重复字符的数目，返回最小总代价。

## 解题思路

动态规划：`dp[i]` = 将 `s[0..i-1]` 分割的最小代价。对每个位置枚举分割点，从右向左扩展子串时用频率表 O(1) 更新代价，代价 = 已出现次数之和。

## Java 代码实现

```java
class Solution {
    public int minimumCost(String s) {
        int n = s.length();
        // dp[i] = s[0..i-1] 的最小分割代价
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            int[] freq = new int[26];
            int cost = 0;

            // 从右向左枚举分割点 j，子串为 s[j..i-1]
            for (int j = i - 1; j >= 0; j--) {
                int c = s.charAt(j) - 'a';
                // 加入字符 c，代价增加 freq[c]（已出现次数）
                cost += freq[c];
                freq[c]++;

                if (dp[j] != Integer.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[j] + cost);
                }
            }
        }

        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有分割点
- 空间复杂度：O(n)，DP 数组

## 关键点总结

1. 子串代价 = 子串中重复字符出现的额外次数之和。
2. DP 枚举所有分割点，取最小代价。
3. 从右向左扩展子串时，维护频率表可以 O(1) 更新代价。
