## 题目描述

word 是 puzzle 的谜底需满足：1) word 包含 puzzle 首字母；2) word 每个字母都在 puzzle 中。对每个 puzzle 统计谜底数。

**示例：**
```
输入: words=["aaaa","asas","able"], puzzles=["abslute"]
输出: [3]
```

## 解题思路

将每个 word 转为字符集位掩码，哈希表统计。对每个 puzzle（长度7，最多 2^6=64 个子集），枚举包含首字母的子集，在哈希表中查找。

## Java 代码实现

```java
class Solution {
    public List<Integer> findNumOfValidWords(String[] words, String[] puzzles) {
        // 预处理：word 字符集 → 出现次数
        Map<Integer, Integer> wordCount = new HashMap<>();
        for (String word : words) {
            int mask = 0;
            for (char c : word.toCharArray()) mask |= (1 << (c - 'a'));
            wordCount.merge(mask, 1, Integer::sum);
        }

        List<Integer> result = new ArrayList<>();
        for (String puzzle : puzzles) {
            int firstBit = 1 << (puzzle.charAt(0) - 'a');
            // 其余字符的掩码
            int restMask = 0;
            for (int i = 1; i < 7; i++) {
                restMask |= (1 << (puzzle.charAt(i) - 'a'));
            }

            int count = 0;
            // 枚举其余字符的所有子集，加上首字母
            int subset = restMask;
            while (true) {
                count += wordCount.getOrDefault(subset | firstBit, 0);
                if (subset == 0) break;
                subset = (subset - 1) & restMask;
            }
            result.add(count);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(W*L + P*2^6)，W 为 words 数，P 为 puzzles 数
- **空间复杂度**：O(W)

## 关键点总结

1. **位掩码表示字符集**：26 位二进制表示包含哪些字母
2. **子集枚举**：`subset = (subset-1) & mask` 标准技巧
3. **puzzle 长度固定 7**：子集最多 2^6=64 个（去掉首字母后 6 位）
4. **哈希表预处理**：避免对每个 puzzle 遍历所有 words
