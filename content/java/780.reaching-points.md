## 题目描述

给定 sx, sy, tx, ty，从 (x,y) 可转换到 (x,x+y) 或 (x+y,y)。判断能否从 (sx,sy) 到达 (tx,ty)。

**示例：**
```
输入：sx = 1, sy = 1, tx = 3, ty = 5
输出：true（(1,1)->(1,2)->(3,2)->(3,5)）
```

## 解题思路

从终点反向推导：较大的坐标是由较小坐标加出来的，用取模加速回退。

## Java 代码实现

```java
class Solution {
    public boolean reachingPoints(int sx, int sy, int tx, int ty) {
        while (tx >= sx && ty >= sy) {
            if (tx == sx && ty == sy) return true;

            if (tx > ty) {
                if (ty == sy) return (tx - sx) % sy == 0;
                tx %= ty;
            } else {
                if (tx == sx) return (ty - sy) % sx == 0;
                ty %= tx;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(max(tx, ty)))
- **空间复杂度**：O(1)

## 关键点总结

1. **反向推导**：从终点往起点推
2. **取模加速**：避免逐步减法超时
3. **终止条件**：当一个坐标等于起点对应值时，直接判断
