## 题目描述

有 `n` 个工人和 `m` 件物品，每件物品需要分配给某个工人。物品 `i` 需要时间 `time[i]` 完成，工人 `j` 处理物品 `i` 的实际时间为 `ceil(time[i] / capacity[j])`。所有工人并行工作，求分配所有物品的最短完成时间。

## 解题思路

状态压缩 DP。`n_workers <= 8`，物品用位掩码表示。`dp[mask]` 为已处理 `mask` 集合中物品时的最短完成时间。枚举每个工人处理的子集，转移更新。

## Java 代码实现

```java
class Solution {
    public int minTime(int[] time, int[] capacity) {
        int m = time.length;
        int n = capacity.length;
        int full = 1 << m;

        // 预处理：workerTime[j][mask] = 工人 j 处理 mask 中物品所需时间
        int[][] workerTime = new int[n][full];
        for (int j = 0; j < n; j++) {
            for (int mask = 0; mask < full; mask++) {
                int total = 0;
                for (int i = 0; i < m; i++) {
                    if ((mask >> i & 1) == 1) {
                        total += (time[i] + capacity[j] - 1) / capacity[j]; // 向上取整
                    }
                }
                workerTime[j][mask] = total;
            }
        }

        int INF = Integer.MAX_VALUE / 2;
        int[] dp = new int[full];
        java.util.Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int j = 0; j < n; j++) {
            int[] newDp = dp.clone();
            for (int prev = 0; prev < full; prev++) {
                if (dp[prev] == INF) continue;
                int remaining = (full - 1) ^ prev;
                // 枚举 remaining 的所有非空子集
                for (int sub = remaining; sub > 0; sub = (sub - 1) & remaining) {
                    int newMask = prev | sub;
                    int cost = Math.max(dp[prev], workerTime[j][sub]);
                    if (cost < newDp[newMask]) newDp[newMask] = cost;
                }
            }
            dp = newDp;
        }

        return dp[full - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × 3^m)
- 空间复杂度：O(2^m)

## 关键点总结

1. 状态压缩 DP：枚举每个工人处理的物品子集
2. 完成时间 = 各工人各自工作时间的最大值
3. 枚举补集的子集：`for sub = remaining; sub > 0; sub = (sub-1) & remaining`
