## 题目描述

无向图中，若三个节点 a、b、c 两两相连则构成三角形，返回图中三角形（环形三元组）的数目。

## 解题思路

用邻接集合存图，枚举每条边 (u, v)，统计同时与 u 和 v 相邻的节点数（共同邻居）。每个三角形被三条边各计一次，最后除以 3。

## Java 代码实现

### 方法一：邻接集合求交集（推荐）

```java
import java.util.*;

class Solution {
    public int numberOfPaths(int n, int[][] corridors) {
        Set<Integer>[] adj = new Set[n + 1];
        for (int i = 1; i <= n; i++) adj[i] = new HashSet<>();
        for (int[] c : corridors) {
            adj[c[0]].add(c[1]);
            adj[c[1]].add(c[0]);
        }
        int count = 0;
        for (int[] c : corridors) {
            int u = c[0], v = c[1];
            // 统计共同邻居数
            for (int w : adj[u]) {
                if (adj[v].contains(w)) count++;
            }
        }
        return count / 3; // 每个三角形被计数3次
    }
}
```

## 复杂度分析

- 时间复杂度：O(E * d)，d 为平均度数
- 空间复杂度：O(n + E)

## 关键点总结

1. 枚举每条边统计共同邻居，每个三角形被计 3 次，除以 3
2. 用 HashSet 存邻接关系，contains 查询 O(1)
