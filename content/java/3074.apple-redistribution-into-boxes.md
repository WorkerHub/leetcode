## 题目描述

给你 n 个包裹的苹果数和 m 个箱子的容量，将所有苹果转移到最少数量的箱子中，返回最少箱子数量。

## 解题思路

贪心：将箱子按容量降序排序，从最大容量开始使用，累计容量达到总苹果数时返回已用箱子数。

## Java 代码实现

```java
class Solution {
    public int minimumBoxes(int[] apple, int[] capacity) {
        int total = 0;
        for (int a : apple) total += a;

        // 按容量降序排序，优先使用最大容量的箱子
        Arrays.sort(capacity);
        int used = 0;
        for (int i = capacity.length - 1; i >= 0; i--) {
            used += capacity[i];
            if (used >= total) return capacity.length - i;
        }
        return capacity.length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：优先使用最大容量的箱子
2. 累计容量直到 >= 总苹果数，返回已用箱子数
3. 题目保证总容量足够，一定能找到答案
