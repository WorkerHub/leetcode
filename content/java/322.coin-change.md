## 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的**最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

**示例 1:**

```
输入：coins = [1, 2, 5], amount = 11
输出：3
解释：11 = 5 + 5 + 1
```

**示例 2:**

```
输入：coins = [2], amount = 3
输出：-1
```

**示例 3:**

```
输入：coins = [1], amount = 0
输出：0
```

**提示:**

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

## 解题思路

这是一道经典的**完全背包问题**，求最少硬币数。

### 核心思想

1. **状态定义**：`dp[i]` 表示凑成金额 `i` 所需的最少硬币数
2. **状态转移**：对于每个金额 `i`，尝试使用每种硬币 `coin`
   - 如果 `i >= coin`，则 `dp[i] = min(dp[i], dp[i - coin] + 1)`
3. **初始化**：`dp[0] = 0`（凑成 0 元需要 0 个硬币），其他位置初始化为无穷大
4. **结果**：`dp[amount]`，如果仍为无穷大则返回 -1

### 为什么是动态规划？

- **最优子结构**：凑成金额 `i` 的最优解包含凑成 `i - coin` 的最优解
- **重叠子问题**：计算不同金额时会重复计算相同的子问题

## Java 代码实现

### 方法一：动态规划（一维数组）⭐

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // dp[i] 表示凑成金额 i 所需的最少硬币数
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);  // 用 amount+1 代替无穷大
        dp[0] = 0;  // 凑成 0 元需要 0 个硬币

        // 遍历每个金额
        for (int i = 1; i <= amount; i++) {
            // 尝试使用每种硬币
            for (int coin : coins) {
                if (i >= coin) {
                    // 使用当前硬币，硬币数 +1
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }

        // 如果无法凑成，返回 -1
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

### 方法二：优化的动态规划（先遍历硬币）

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // 先遍历硬币，再遍历金额（完全背包的另一种写法）
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);
        dp[0] = 0;

        // 先遍历硬币
        for (int coin : coins) {
            // 再遍历金额（从小到大）
            for (int i = coin; i <= amount; i++) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }

        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

### 方法三：广度优先搜索（BFS）

```java
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // BFS 思路：从 0 开始，每次加一个硬币，找到最短路径
        if (amount == 0) return 0;

        Queue<Integer> queue = new LinkedList<>();
        boolean[] visited = new boolean[amount + 1];
        queue.offer(0);
        visited[0] = true;
        int step = 0;

        while (!queue.isEmpty()) {
            step++;
            int size = queue.size();

            // 处理当前层的所有节点
            for (int s = 0; s < size; s++) {
                int current = queue.poll();

                // 尝试加上每种硬币
                for (int coin : coins) {
                    int next = current + coin;

                    // 找到目标
                    if (next == amount) return step;

                    // 未访问且未超过目标
                    if (next < amount && !visited[next]) {
                        visited[next] = true;
                        queue.offer(next);
                    }
                }
            }
        }

        return -1;  // 无法凑成
    }
}
```

### 方法四：记忆化递归（自顶向下）

```java
import java.util.Arrays;

class Solution {
    private int[] memo;
    private int[] coins;

    public int coinChange(int[] coins, int amount) {
        // 记忆化递归：自顶向下求解
        this.coins = coins;
        this.memo = new int[amount + 1];
        Arrays.fill(memo, -2);  // -2 表示未计算
        return dp(amount);
    }

    private int dp(int n) {
        // 基础情况
        if (n == 0) return 0;
        if (n < 0) return -1;

        // 已计算过
        if (memo[n] != -2) return memo[n];

        // 尝试所有硬币
        int res = Integer.MAX_VALUE;
        for (int coin : coins) {
            int sub = dp(n - coin);
            if (sub != -1) {
                res = Math.min(res, sub + 1);
            }
        }

        // 记录结果
        memo[n] = (res == Integer.MAX_VALUE) ? -1 : res;
        return memo[n];
    }
}
```

## 复杂度分析

**方法一/二：动态规划**

- **时间复杂度**：O(amount * n)
  - amount：金额范围
  - n：硬币种类数
  
- **空间复杂度**：O(amount)
  - dp 数组的空间

**方法三：BFS**

- **时间复杂度**：O(amount * n)
  - 最坏情况访问所有金额
  
- **空间复杂度**：O(amount)
  - 队列和 visited 数组

**方法四：记忆化递归**

- **时间复杂度**：O(amount * n)
- **空间复杂度**：O(amount)
  - 递归栈 + memo 数组

## 关键点总结

1. **完全背包问题**：每种物品可以使用无限次
2. **状态转移方程**：`dp[i] = min(dp[i], dp[i - coin] + 1)`
3. **初始化技巧**：使用 `amount + 1` 表示不可达状态（Java 中避免使用 Integer.MAX_VALUE 防止加法溢出）
4. **遍历顺序**：可以先遍历金额或先遍历硬币（完全背包两种写法都可以）
5. **BFS 思想**：将问题转化为求最短路径问题

## 易错点

1. **初始化错误**：忘记设置 `dp[0] = 0`
2. **边界检查**：要确保 `i >= coin` 才能使用该硬币
3. **返回值判断**：最后要检查 `dp[amount]` 是否为无穷大
4. **整数溢出**：Java 中若用 `Integer.MAX_VALUE` 初始化，加 1 会溢出，建议用 `amount + 1`
5. **完全背包 vs 0-1 背包**：
   - 完全背包：内层循环正序（从小到大）
   - 0-1 背包：内层循环倒序（从大到小）
