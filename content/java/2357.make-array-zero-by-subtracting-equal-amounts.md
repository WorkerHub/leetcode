## 题目描述

给你非负整数数组 `nums`，每次操作选一个正整数 x（不超过最小非零值）从所有非零元素减去，返回使所有元素为 0 的最少操作次数。

## 解题思路

每次操作消灭当前最小非零值（选 x = 最小非零值），操作次数等于不同正整数值的个数。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumOperations(int[] nums) {
        Set<Integer> unique = new HashSet<>();
        for (int x : nums) if (x > 0) unique.add(x); // 只统计正数
        return unique.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每次操作消灭一个"层级"（最小非零值），操作次数 = 不同正整数值的个数。
2. 用 HashSet 去重统计正整数种数，O(n) 完成。
3. 0 不参与计数。
