## 题目描述

给你整数数组 nums，对每个整数将所有数字替换为该数中最大的数字，返回所有加密整数的总和。

## 解题思路

对每个整数找到最大数字 d，构造同等位数的全 d 组成的数（如 316 → 666），求和。

## Java 代码实现

```java
class Solution {
    public int sumOfEncryptedInt(int[] nums) {
        int total = 0;
        for (int x : nums) total += encrypt(x);
        return total;
    }

    private int encrypt(int n) {
        int maxDigit = 0, digits = 0, result = 0;
        // 找最大数字和位数
        int temp = n;
        while (temp > 0) {
            maxDigit = Math.max(maxDigit, temp % 10);
            digits++;
            temp /= 10;
        }
        // 构造同位数的全 maxDigit 数
        for (int i = 0; i < digits; i++) {
            result = result * 10 + maxDigit;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L)，L 为数字位数（最多 4 位）
- **空间复杂度**：O(1)

## 关键点总结

1. 找最大数字后，构造同位数的全最大数字的数
2. 同位数全 d 数 = d 重复 digits 次
3. 位数与原数相同（不能改变长度）
