## 题目描述

给你严格递增数组 `rungs`（梯子踏板高度）和整数 `dist`（每次最多爬升高度），从高度 0 出发，返回到达最高踏板所需添加的最少踏板数。

## 解题思路

贪心：对相邻两位置间距 `gap`，需要添加 `(gap-1)/dist` 个踏板（整数除法），各段独立计算求和。

## Java 代码实现

```java
class Solution {
    public int addRungs(int[] rungs, int dist) {
        int result = 0;
        int prev = 0; // 从高度 0 开始
        for (int rung : rungs) {
            int gap = rung - prev;
            if (gap > dist)
                result += (gap - 1) / dist; // 需要添加的踏板数
            prev = rung;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 各段间距独立处理，贪心均匀分配踏板
2. `(gap-1)/dist` 等价于 `ceil(gap/dist) - 1`，整数运算避免浮点
3. 从高度 0 出发，第一个踏板也需检查
