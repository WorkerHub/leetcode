## 题目描述

给你字符串 `source`、`target` 以及子字符串转换规则，每次操作将 source 中的子字符串 `original[i]` 替换为 `changed[i]`，代价为 `cost[i]`，返回将 source 转换为 target 的最少总代价，不可能则返回 -1。

## 解题思路

将所有字符串映射为节点 ID，用 Floyd-Warshall 预计算字符串间最短转换代价。DP 枚举分割：`dp[i]` 为处理前 i 字符的最小代价，枚举子串 source[j..i-1] 是否能转换为 target[j..i-1]。

## Java 代码实现

```java
class Solution {
    public long minimumCost(String source, String target, String[] original, String[] changed, int[] cost) {
        final long INF = Long.MAX_VALUE / 2;
        Map<String, Integer> sid = new HashMap<>();

        // 为所有字符串分配 ID
        for (String s : original) sid.putIfAbsent(s, sid.size());
        for (String s : changed) sid.putIfAbsent(s, sid.size());
        int m = sid.size();

        long[][] dist = new long[m][m];
        for (long[] row : dist) Arrays.fill(row, INF);
        for (int i = 0; i < m; i++) dist[i][i] = 0;
        for (int i = 0; i < cost.length; i++) {
            int u = sid.get(original[i]), v = sid.get(changed[i]);
            dist[u][v] = Math.min(dist[u][v], cost[i]);
        }

        // Floyd-Warshall
        for (int k = 0; k < m; k++)
            for (int i = 0; i < m; i++)
                for (int j = 0; j < m; j++)
                    if (dist[i][k] != INF && dist[k][j] != INF)
                        dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);

        int n = source.length();
        long[] dp = new long[n + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            // 单字符不转换
            if (source.charAt(i - 1) == target.charAt(i - 1) && dp[i - 1] != INF)
                dp[i] = dp[i - 1];
            // 枚举子串 source[j..i-1] -> target[j..i-1]
            for (int j = 0; j < i; j++) {
                if (dp[j] == INF) continue;
                String sSub = source.substring(j, i);
                String tSub = target.substring(j, i);
                Integer su = sid.get(sSub), tv = sid.get(tSub);
                if (su != null && tv != null && dist[su][tv] != INF)
                    dp[i] = Math.min(dp[i], dp[j] + dist[su][tv]);
            }
        }
        return dp[n] == INF ? -1 : dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(K³ + n² × K)，K 为不同字符串数
- **空间复杂度**：O(K² + n)

## 关键点总结

1. 子字符串转换转化为图节点间最短路
2. DP 枚举所有子串分割点，利用预计算的最短路
3. source[i-1]==target[i-1] 时可选择不操作（代价 0）
