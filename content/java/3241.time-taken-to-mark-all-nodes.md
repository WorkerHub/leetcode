## 题目描述

给你一棵 `n` 节点的无向树，奇数节点被标记后 1 秒传播到邻居，偶数节点 2 秒传播，返回数组 `ans`，`ans[i]` 为从节点 `i` 出发标记所有节点所需的时间。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] graph;
    private int[] dpDown;   // 向下的最大时间
    private int[] dpDown2;  // 向下第二大时间（用于换根）
    private int[] dpDownId; // dpDown 来自哪个子节点
    private int[] dpUp;     // 向上的最大时间
    private int[] parent;
    private int[] order;
    private int orderSize;

    public int[] timeTaken(int[][] edges) {
        int n = edges.length + 1;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        dpDown = new int[n]; dpDown2 = new int[n];
        dpDownId = new int[n]; dpUp = new int[n];
        parent = new int[n]; order = new int[n];
        Arrays.fill(parent, -1); orderSize = 0;

        // BFS 得到拓扑序
        boolean[] visited = new boolean[n];
        Queue<Integer> q = new LinkedList<>();
        q.offer(0); visited[0] = true;
        while (!q.isEmpty()) {
            int u = q.poll();
            order[orderSize++] = u;
            for (int v : graph[u]) {
                if (!visited[v]) { visited[v] = true; parent[v] = u; q.offer(v); }
            }
        }

        // 逆序计算 dpDown（向下最大时间）
        for (int k = orderSize - 1; k >= 0; k--) {
            int u = order[k];
            int best = 0, secondBest = 0, bestId = -1;
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                int val = dpDown[v] + (u % 2 == 0 ? 2 : 1);
                if (val >= best) { secondBest = best; best = val; bestId = v; }
                else if (val > secondBest) secondBest = val;
            }
            dpDown[u] = best; dpDown2[u] = secondBest; dpDownId[u] = bestId;
        }

        // 正序计算 dpUp（换根向上最大时间）
        int[] ans = new int[n];
        ans[0] = dpDown[0];
        for (int k = 0; k < orderSize; k++) {
            int u = order[k];
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                // v 的 dpUp：经过 u 的最大时间
                int edgeTime = v % 2 == 0 ? 2 : 1;
                int upFromU = dpUp[u];
                int downFromU = (dpDownId[u] == v) ? dpDown2[u] : dpDown[u];
                dpUp[v] = Math.max(upFromU, downFromU) + edgeTime;
                ans[v] = Math.max(dpDown[v], dpUp[v]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 换根 DP：先以 0 为根计算向下最大时间，再传递"向上"信息
2. 边的权重取决于出发节点的奇偶性（偶数 2 秒，奇数 1 秒）
3. 换根时用第一、第二大子树值，排除当前子节点的贡献
