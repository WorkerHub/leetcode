## 题目描述

实现稀疏向量类 SparseVector，支持高效的点积运算。

**示例：**
```
输入：nums1 = [1,0,0,2,3], nums2 = [0,3,0,4,0]
输出：8
```

## 解题思路

只存储非零元素的 (index, value) 对，用双指针计算点积。

## Java 代码实现

```java
class SparseVector {
    private Map<Integer, Integer> map;
    
    SparseVector(int[] nums) {
        map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) map.put(i, nums[i]);
        }
    }
    
    public int dotProduct(SparseVector vec) {
        // 遍历较小的 map
        Map<Integer, Integer> a = this.map, b = vec.map;
        if (a.size() > b.size()) { Map<Integer, Integer> t = a; a = b; b = t; }
        int result = 0;
        for (Map.Entry<Integer, Integer> entry : a.entrySet()) {
            if (b.containsKey(entry.getKey())) {
                result += entry.getValue() * b.get(entry.getKey());
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **初始化**：O(n)
- **点积**：O(min(nnz1, nnz2))
- **空间**：O(nnz)

## 关键点总结

1. **稀疏存储**：只存非零元素
2. **遍历小表**：在大表中查找，O(min(nnz1,nnz2))
3. **HashMap**：支持 O(1) 查找
