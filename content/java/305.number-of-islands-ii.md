## 题目描述

给你一个 `m x n` 的空二维网格，网格中的每个单元格初始时都是水域。我们可以通过执行 `addLand` 操作，将某个位置的水域变成陆地。

给你一个数组 `positions`，其中 `positions[i] = [ri, ci]` 表示第 `i` 次操作中将位置 `(ri, ci)` 变成陆地。

返回一个整数数组 `answer`，其中 `answer[i]` 是将单元格 `(ri, ci)` 转变成陆地后，网格中岛屿的数量。

**岛屿**的定义是被水包围，并且通过水平或垂直方向上相邻的陆地连接而成的。你可以假设网格的四个边均被水包围。

**示例 1：**
```
输入：m = 3, n = 3, positions = [[0,0],[0,1],[1,2],[2,1]]
输出：[1,1,2,3]
解释：
初始时，网格全是水域：
. . .
. . .
. . .

操作 #1：addLand(0, 0) 将 (0,0) 变成陆地，有 1 个岛屿
X . .
. . .
. . .

操作 #2：addLand(0, 1) 将 (0,1) 变成陆地，仍然是 1 个岛屿（与 (0,0) 相连）
X X .
. . .
. . .

操作 #3：addLand(1, 2) 将 (1,2) 变成陆地，现在有 2 个岛屿
X X .
. . X
. . .

操作 #4：addLand(2, 1) 将 (2,1) 变成陆地，现在有 3 个岛屿
X X .
. . X
. X .
```

**示例 2：**
```
输入：m = 1, n = 1, positions = [[0,0]]
输出：[1]
```

**提示：**
- `1 <= m, n, positions.length <= 10^4`
- `1 <= m * n <= 10^4`
- `positions[i].length == 2`
- `0 <= ri < m`
- `0 <= ci < n`

## 解题思路

这是一道典型的**动态连通性问题**，最适合用**并查集（Union-Find）**来解决。

### 核心思路

1. **初始状态**：所有格子都是水域，岛屿数量为 0
2. **添加陆地**：
   - 将该位置标记为陆地，岛屿数量 +1
   - 检查四个方向（上、下、左、右）是否有相邻的陆地
   - 如果有，使用并查集合并，每合并一次，岛屿数量 -1

### 并查集操作

- **初始化**：每个位置的父节点是自己
- **查找**：找到某个位置所属的岛屿的根节点（路径压缩优化）
- **合并**：将两个岛屿合并成一个（按秩合并优化）

### 坐标转换

二维坐标 `(i, j)` 转换为一维索引：`index = i * n + j`

## Java 代码实现

### 方法一：并查集（推荐）⭐

```java
import java.util.*;

class Solution {
    private int[] parent;
    private int[] rank;
    private int count; // 岛屿数量

    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        parent = new int[m * n];
        rank = new int[m * n];
        // -1 表示水域，未初始化
        Arrays.fill(parent, -1);
        count = 0;

        List<Integer> result = new ArrayList<>();
        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}}; // 四个方向

        for (int[] pos : positions) {
            int r = pos[0], c = pos[1];
            // 将二维坐标转换为一维索引
            int idx = r * n + c;

            // 如果已经是陆地，跳过（题目可能有重复位置）
            if (parent[idx] != -1) {
                result.add(count);
                continue;
            }

            // 添加新陆地，岛屿数量 +1
            parent[idx] = idx;
            count++;

            // 检查四个方向的相邻陆地
            for (int[] dir : directions) {
                int nr = r + dir[0], nc = c + dir[1];
                int neighborIdx = nr * n + nc;

                // 如果相邻位置在范围内且是陆地
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && parent[neighborIdx] != -1) {
                    union(idx, neighborIdx);
                }
            }

            result.add(count);
        }

        return result;
    }

    private int find(int x) {
        // 查找 x 的根节点（带路径压缩）
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    private void union(int x, int y) {
        // 合并 x 和 y 所在的集合
        int rootX = find(x), rootY = find(y);

        if (rootX == rootY) return; // 已经在同一个集合

        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }

        count--; // 合并后岛屿数量减 1
    }
}
```

### 方法二：并查集优化版（HashMap）

```java
import java.util.*;

class Solution {
    private Map<Integer, Integer> parent; // 只存储陆地的父节点
    private Map<Integer, Integer> rankMap;

    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        parent = new HashMap<>();
        rankMap = new HashMap<>();

        List<Integer> result = new ArrayList<>();
        int count = 0;
        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        for (int[] pos : positions) {
            int r = pos[0], c = pos[1];
            int idx = r * n + c;

            // 如果已经是陆地
            if (parent.containsKey(idx)) {
                result.add(count);
                continue;
            }

            // 初始化新陆地
            parent.put(idx, idx);
            rankMap.put(idx, 0);
            count++;

            // 尝试与四个方向的陆地合并
            for (int[] dir : directions) {
                int nr = r + dir[0], nc = c + dir[1];
                int neighborIdx = nr * n + nc;

                if (nr >= 0 && nr < m && nc >= 0 && nc < n && parent.containsKey(neighborIdx)) {
                    if (union(idx, neighborIdx)) {
                        count--;
                    }
                }
            }

            result.add(count);
        }

        return result;
    }

    private int find(int x) {
        // 查找根节点（路径压缩）
        if (!parent.get(x).equals(x)) {
            parent.put(x, find(parent.get(x)));
        }
        return parent.get(x);
    }

    private boolean union(int x, int y) {
        // 合并两个集合
        int rootX = find(x), rootY = find(y);

        if (rootX == rootY) return false;

        // 按秩合并
        int rankX = rankMap.get(rootX), rankY = rankMap.get(rootY);
        if (rankX < rankY) {
            parent.put(rootX, rootY);
        } else if (rankX > rankY) {
            parent.put(rootY, rootX);
        } else {
            parent.put(rootY, rootX);
            rankMap.put(rootX, rankX + 1);
        }

        return true;
    }
}
```

### 方法三：带详细注释的版本

```java
import java.util.*;

class Solution {
    /**
     * 使用并查集解决动态岛屿问题
     *
     * 核心思想：
     * 1. 添加陆地时，岛屿数量 +1
     * 2. 与相邻陆地合并时，岛屿数量 -1
     */
    private Map<Integer, Integer> parent; // 字典存储父节点（只存陆地）

    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        parent = new HashMap<>();

        List<Integer> result = new ArrayList<>();
        int count = 0; // 当前岛屿数量

        // 四个方向：右、左、下、上
        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        for (int[] pos : positions) {
            int r = pos[0], c = pos[1];
            // 二维转一维
            int idx = r * n + c;

            // 重复添加同一个位置
            if (parent.containsKey(idx)) {
                result.add(count);
                continue;
            }

            // 添加新陆地
            parent.put(idx, idx); // 初始时父节点是自己
            count++;

            // 检查四个方向
            for (int[] dir : directions) {
                int nr = r + dir[0], nc = c + dir[1];
                int neighborIdx = nr * n + nc;

                // 边界检查 + 是否是陆地
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && parent.containsKey(neighborIdx)) {
                    // 尝试合并
                    if (union(idx, neighborIdx)) {
                        count--; // 合并成功，岛屿数量减 1
                    }
                }
            }

            result.add(count);
        }

        return result;
    }

    private int find(int x) {
        // 查找根节点并路径压缩
        if (!parent.get(x).equals(x)) {
            parent.put(x, find(parent.get(x))); // 路径压缩
        }
        return parent.get(x);
    }

    private boolean union(int x, int y) {
        // 合并两个集合
        // 返回：true 表示成功合并，false 表示已在同一集合
        int rootX = find(x), rootY = find(y);

        if (rootX != rootY) {
            parent.put(rootX, rootY); // 简化版，不使用按秩合并
            return true;
        }

        return false;
    }
}
```

## 复杂度分析

**并查集方法：**
- 时间复杂度：O(k × α(m×n))，其中 k 是 positions 的长度，α 是反阿克曼函数，几乎是常数
- 空间复杂度：O(m × n)，并查集的空间

## 关键点总结

1. **并查集的应用**：动态连通性问题的标准解法
2. **岛屿数量的变化规律**：
   - 添加陆地：+1
   - 合并两个岛屿：-1
3. **路径压缩**：`parent[x] = find(parent[x])` 优化查询
4. **按秩合并**：将较小的树合并到较大的树，优化树的高度
5. **坐标转换**：二维 `(i, j)` → 一维 `i * n + j`

## 易错点

1. **重复添加**：positions 可能包含重复的位置，需要判断
2. **合并条件**：只有当两个根节点不同时才需要合并
3. **计数错误**：合并时忘记 `count -= 1`
4. **边界检查**：检查相邻位置是否在网格范围内
5. **初始化**：新陆地的父节点初始化为自己
