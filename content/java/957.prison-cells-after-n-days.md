## 题目描述

监狱中有 8 间牢房，每间牢房不是有人住就是空着。每天，无论牢房是被占用或空置，都会根据以下规则进行变更：

- 如果一间牢房的两个相邻的房间都被占用或都是空的，那么该牢房就会被占用。
- 否则，它就会被空置。

注意：由于监狱中的牢房排成一行，所以行中的第一个和最后一个房间无法有两个相邻的房间。

给你一个整数数组 `cells`，用于表示牢房的初始状态：如果第 `i` 间牢房被占用，则 `cells[i] == 1`，否则 `cells[i] == 0`。另给你一个整数 `n`。

请你返回 `n` 天后监狱的状况（即，按上述规则运行 `n` 次后的状态）。

**示例 1：**
```
输入：cells = [0,1,0,1,1,0,0,1], n = 7
输出：[0,0,1,1,0,0,0,0]
```

**示例 2：**
```
输入：cells = [1,0,0,1,0,0,1,0], n = 1000000000
输出：[0,0,1,1,1,1,1,0]
```

**提示：**
- `cells.length == 8`
- `cells[i]` 为 `0` 或 `1`
- `1 <= n <= 10^9`

## 解题思路

关键观察：由于只有8个牢房，状态数量有限（最多2^8=256种），所以一定会出现循环。

**核心思想：**
1. 找到循环周期
2. 利用取模跳过重复计算

## Java 代码实现

### 方法一：找循环周期（推荐）⭐

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    /**
     * 找循环周期优化
     */
    public int[] prisonAfterNDays(int[] cells, int n) {
        Map<String, Integer> seen = new HashMap<>();

        while (n > 0) {
            String state = Arrays.toString(cells);
            if (seen.containsKey(state)) {
                // 找到循环
                int cycleLen = seen.get(state) - n;
                n %= cycleLen;
                if (n == 0) return cells;
            }

            seen.put(state, n);
            cells = nextDay(cells);
            n--;
        }

        return cells;
    }

    /** 计算下一天的状态 */
    private int[] nextDay(int[] cells) {
        int[] newCells = new int[8];
        for (int i = 1; i < 7; i++) {
            // 两侧相同则为1，不同则为0
            newCells[i] = (cells[i - 1] == cells[i + 1]) ? 1 : 0;
        }
        return newCells;
    }
}
```

### 方法二：简化版

```java
class Solution {
    /**
     * 简化版：使用 List 记录历史状态
     */
    public int[] prisonAfterNDays(int[] cells, int n) {
        Map<String, Integer> seen = new HashMap<>();
        java.util.List<int[]> history = new java.util.ArrayList<>();

        for (int day = 0; day < n; day++) {
            String state = Arrays.toString(cells);
            if (seen.containsKey(state)) {
                int cycleStart = seen.get(state);
                int cycleLen = day - cycleStart;
                int remaining = (n - cycleStart) % cycleLen;
                return history.get(cycleStart + remaining);
            }
            seen.put(state, day);
            history.add(cells.clone());
            cells = nextDay(cells);
        }

        return cells;
    }

    private int[] nextDay(int[] cells) {
        int[] newCells = new int[8];
        for (int i = 1; i < 7; i++) {
            // 利用异或：a == b 等价于 (a ^ b) == 0，即 (a ^ b ^ 1) == 1
            newCells[i] = (cells[i - 1] ^ cells[i + 1] ^ 1);
        }
        return newCells;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(N, 2^8)) = O(min(N, 256))
- **空间复杂度**：O(2^8) = O(256)

## 关键点总结

1. **循环检测**：有限状态必有循环
2. **取模优化**：利用周期性跳过计算
3. **异或技巧**：`a == b` 等价于 `a ^ b ^ 1 == 1`

## 易错点

1. 边界牢房始终为0
2. 循环可能不从第0天开始
3. n很大时必须优化
4. Java 中数组不能直接比较，需转为字符串
