## 题目描述

给你两个篮子 `basket1` 和 `basket2`，每次可交换两篮子间的一个水果（代价为两者中的较小值），返回使两篮子水果数量相同的最小总代价，若无法实现返回 `-1`。

## 解题思路

统计每种水果的数量差；若某水果总数为奇数则返回 -1。将各篮子"多出的"水果收集后排序，两两配对（最小对最大），每次取直接交换代价与"中转"（全局最小值 * 2）的较小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minCost(int[] basket1, int[] basket2) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : basket1) cnt.merge(x, 1, Integer::sum);
        for (int x : basket2) cnt.merge(x, -1, Integer::sum);

        List<Integer> toMove = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int diff = e.getValue();
            if (diff % 2 != 0) return -1; // 总数为奇数，无法平衡
            // basket1 多出 diff/2 个（diff > 0）或 basket2 多出 (-diff)/2 个
            for (int i = 0; i < Math.abs(diff) / 2; i++) toMove.add(e.getKey());
        }

        Collections.sort(toMove);
        int minAll = Integer.MAX_VALUE;
        for (int x : basket1) minAll = Math.min(minAll, x);
        for (int x : basket2) minAll = Math.min(minAll, x);

        long cost = 0;
        int m = toMove.size() / 2;
        for (int i = 0; i < m; i++) {
            // 直接交换（配对最小与最大），代价取较小者；或用全局最小中转
            cost += Math.min(toMove.get(i), 2L * minAll);
        }
        return cost;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 某水果总数为奇数时无法平衡，返回 -1
2. 收集需要移动的水果，排序后配对：最小的与最大的配对，代价取两者的较小值
3. 中转策略：用全局最小值做中间人，代价 `2 * minAll`，可能比直接交换更便宜
