## 题目描述

给你整数数组 `nums`，可以修改任意两个元素，使得低分（最小绝对差）等于 0，求高分（最大绝对差）的最小值。

## 解题思路

低分可以变为 0（修改两端使相邻值相等），因此只需最小化高分。排序后，高分 = `max - min`，修改两个元素意味着可以去掉最多两端元素，取三种情况的最小值：去掉最大两个、去掉最小两个、各去掉一个。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimizeSum(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        // 三种删除两端元素的方案，取最小高分
        return Math.min(
            nums[n - 1] - nums[2],  // 删除最小两个
            Math.min(
                nums[n - 3] - nums[0],  // 删除最大两个
                nums[n - 2] - nums[1]   // 各删除一个
            )
        );
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 低分可以通过修改使之为 0，问题转化为最小化高分
2. 排序后，修改两个元素等价于去掉两端的某两个极值
3. 枚举三种去法取最小值即可
