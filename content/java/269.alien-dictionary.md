## 题目描述

现有一种使用英语字母的外星文语言，这门语言的字母顺序与英语顺序不同。

给定一个字符串列表 `words`，作为这门语言的词典，`words` 中的字符串已经按这门新语言的字母顺序进行了排序。

请你根据该词典还原出此语言中已知的字母顺序，并以字符串形式返回。

若不存在合法字母顺序，返回 `""`。若存在多种可能的合法字母顺序，返回其中任意一种即可。

当且仅当对于词典中的任意两个相邻单词 `a` 和 `b`，在新语言的字母顺序中，`a` 在 `b` 之前，则称该字母顺序合法。

**示例 1：**
```
输入: words = ["wrt","wrf","er","ett","rftt"]
输出: "wertf"
解释: 
从 "wrt" < "wrf" 可知 t < f
从 "wrf" < "er" 可知 w < e
从 "er" < "ett" 可知 r < t
从 "ett" < "rftt" 可知 e < r
综合起来：w < e < r < t < f
```

**示例 2：**
```
输入: words = ["z","x"]
输出: "zx"
```

**示例 3：**
```
输入: words = ["z","x","z"]
输出: ""
解释: 不存在合法顺序，因为 z < x 且 x < z 形成环
```

**提示：**
- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` 仅由小写英文字母组成

## 解题思路

这是一道经典的**拓扑排序**问题。

**核心思路：**

1. **构建有向图**：
   - 比较相邻的两个单词，找到第一个不同的字符
   - 建立字符的先后关系（有向边）

2. **拓扑排序**：
   - 使用 BFS（Kahn算法）或 DFS 进行拓扑排序
   - 检测是否有环（环意味着不存在合法顺序）

3. **边界情况**：
   - 如果前缀相同但前面的单词更长，则无效（如 ["abc", "ab"]）
   - 检测环的存在
   - 确保所有字符都被包含

## Java 代码实现

### 方法一：BFS 拓扑排序（Kahn 算法）（推荐）⭐

```java
import java.util.*;

class Solution {
    public String alienOrder(String[] words) {
        // 初始化图和入度
        Map<Character, Set<Character>> graph = new HashMap<>();
        Map<Character, Integer> inDegree = new HashMap<>();

        // 将所有字符加入入度表
        for (String word : words) {
            for (char c : word.toCharArray()) {
                inDegree.putIfAbsent(c, 0);
                graph.putIfAbsent(c, new HashSet<>());
            }
        }

        // 构建图：比较相邻单词
        for (int i = 0; i < words.length - 1; i++) {
            String word1 = words[i];
            String word2 = words[i + 1];
            int minLen = Math.min(word1.length(), word2.length());

            // 检查前缀情况：如果 word1 是 word2 的前缀且更长，无效
            if (word1.length() > word2.length() && word1.startsWith(word2)) {
                return "";
            }

            // 找到第一个不同的字符
            for (int j = 0; j < minLen; j++) {
                char c1 = word1.charAt(j);
                char c2 = word2.charAt(j);
                if (c1 != c2) {
                    // c1 < c2，添加边 c1 -> c2
                    if (!graph.get(c1).contains(c2)) {
                        graph.get(c1).add(c2);
                        inDegree.put(c2, inDegree.get(c2) + 1);
                    }
                    break; // 只需要第一个不同的字符
                }
            }
        }

        // BFS 拓扑排序
        Queue<Character> queue = new LinkedList<>();
        for (Map.Entry<Character, Integer> entry : inDegree.entrySet()) {
            if (entry.getValue() == 0) {
                queue.offer(entry.getKey());
            }
        }

        StringBuilder result = new StringBuilder();
        while (!queue.isEmpty()) {
            char c = queue.poll();
            result.append(c);

            // 更新邻居的入度
            for (char neighbor : graph.get(c)) {
                inDegree.put(neighbor, inDegree.get(neighbor) - 1);
                if (inDegree.get(neighbor) == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        // 检查是否所有字符都被访问（是否有环）
        if (result.length() != inDegree.size()) {
            return "";
        }

        return result.toString();
    }
}
```

### 方法二：DFS 拓扑排序

```java
import java.util.*;

class Solution {
    // 0: 未访问, 1: 访问中, 2: 已完成
    private Map<Character, Integer> state;
    private Map<Character, Set<Character>> graph;
    private StringBuilder result;
    private boolean hasCycle;

    public String alienOrder(String[] words) {
        // 初始化图
        graph = new HashMap<>();
        state = new HashMap<>();

        for (String word : words) {
            for (char c : word.toCharArray()) {
                graph.putIfAbsent(c, new HashSet<>());
                state.putIfAbsent(c, 0);
            }
        }

        // 构建图
        for (int i = 0; i < words.length - 1; i++) {
            String word1 = words[i];
            String word2 = words[i + 1];
            int minLen = Math.min(word1.length(), word2.length());

            if (word1.length() > word2.length() && word1.startsWith(word2)) {
                return "";
            }

            for (int j = 0; j < minLen; j++) {
                char c1 = word1.charAt(j);
                char c2 = word2.charAt(j);
                if (c1 != c2) {
                    graph.get(c1).add(c2);
                    break;
                }
            }
        }

        // DFS 拓扑排序
        result = new StringBuilder();
        hasCycle = false;

        for (char c : graph.keySet()) {
            if (state.get(c) == 0) {
                dfs(c);
                if (hasCycle) return "";
            }
        }

        // 反转结果（后序遍历是反向的拓扑排序）
        return result.reverse().toString();
    }

    private void dfs(char c) {
        if (hasCycle) return;

        state.put(c, 1); // 标记为访问中

        for (char neighbor : graph.get(c)) {
            if (state.get(neighbor) == 1) {
                hasCycle = true; // 发现环
                return;
            }
            if (state.get(neighbor) == 0) {
                dfs(neighbor);
            }
        }

        state.put(c, 2); // 标记为已完成
        result.append(c); // 后序遍历
    }
}
```

## 复杂度分析

### 方法一、二
- **时间复杂度**：O(C)
  - C 是所有单词的字符总数
  - 构建图：O(C)，需要遍历所有字符
  - 拓扑排序：O(V + E)，V 是字符种类数（最多26），E 是边数
  - 总体：O(C)

- **空间复杂度**：O(1) 或 O(26) = O(1)
  - 字符集固定为小写字母（最多26个）

## 图解示例

以 `words = ["wrt","wrf","er","ett","rftt"]` 为例：

```
1. 比较相邻单词，建立关系:
   "wrt" vs "wrf": t < f  (添加边 t → f)
   "wrf" vs "er":  w < e  (添加边 w → e)
   "er"  vs "ett": r < t  (添加边 r → t)
   "ett" vs "rftt": e < r (添加边 e → r)

2. 构建的图:
   w → e
   e → r
   r → t
   t → f

3. 计算入度:
   w: 0, e: 1, r: 1, t: 1, f: 1

4. BFS 拓扑排序:
   队列初始: [w]
   取出 w → 结果: "w", e 入度→0 加入队列
   取出 e → 结果: "we", r 入度→0 加入队列
   取出 r → 结果: "wer", t 入度→0 加入队列
   取出 t → 结果: "wert", f 入度→0 加入队列
   取出 f → 结果: "wertf"

5. 最终结果: "wertf"
```

## 关键点总结

1. **拓扑排序应用**：字典序问题本质是拓扑排序
2. **图的构建**：
   - 只比较相邻单词
   - 只需要第一个不同的字符
   - 注意去重（同一条边不要重复添加）
3. **特殊情况处理**：
   - 前缀但前面单词更长：`["abc", "ab"]` 无效
   - 环的检测：拓扑排序结果数量 < 字符总数
4. **BFS vs DFS**：
   - BFS（Kahn算法）更直观
   - DFS 需要记录访问状态（0/1/2）
5. **Java 中使用 `String.startsWith`** 检查前缀

## 易错点

1. **前缀陷阱**：
   ```java
   // ["abc", "ab"] 是无效的
   if (word1.length() > word2.length() && word1.startsWith(word2)) {
       return "";
   }
   ```

2. **重复边问题**：
   ```java
   // 需要检查边是否已存在
   if (!graph.get(c1).contains(c2)) {
       graph.get(c1).add(c2);
       inDegree.put(c2, inDegree.get(c2) + 1);
   }
   ```

3. **只取第一个不同字符**：找到第一个不同字符后要 `break`

4. **环检测**：拓扑排序后，检查结果长度是否等于节点数

5. **字符集初始化**：要包含所有出现过的字符，不仅仅是有边的字符

   - 只比较相邻元素
   - 只需第一个差异
   - 注意重复边和入度更新

4. **环检测方法**：
   - BFS：检查结果数量是否等于节点数
