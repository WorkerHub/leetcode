## 题目描述

给定整数数组 `nums`，求满足 `i < j < k`，`nums[j] == nums[i] * 2`，`nums[k] == nums[j] * 2` 的三元组数量，对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countSpecialTriplets(int[] nums) {
        int MOD = 1_000_000_007;
        int n = nums.length;

        // 预计算右侧频次
        Map<Integer, Integer> right = new HashMap<>();
        for (int x : nums) right.merge(x, 1, Integer::sum);

        Map<Integer, Integer> left = new HashMap<>();
        long result = 0;

        for (int x : nums) {
            // 以 x 为中间元素（x 必须是偶数）
            right.merge(x, -1, Integer::sum);

            if (x % 2 == 0) {
                int half = x / 2;
                long doubleVal = (long) x * 2;
                if (doubleVal <= Integer.MAX_VALUE) {
                    long l = left.getOrDefault(half, 0);
                    long r = right.getOrDefault((int) doubleVal, 0);
                    result = (result + l * r) % MOD;
                }
            }

            left.merge(x, 1, Integer::sum);
        }
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表操作均摊 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 枚举中间元素，统计左侧 `x/2` 的个数和右侧 `2x` 的个数
2. 先将右侧频次减去当前元素，再计算贡献，最后更新左侧频次
3. 中间元素必须是偶数（`x/2` 需为整数）
