## 题目描述

给你 `m x n` 整数矩阵 `board`，放置三个车使任意两车不在同一行或列，返回三车所在格子的最大值之和。（`3 <= m, n <= 100`）

## 解题思路

对每行只保留前 3 大的 (value, col) 对（三行选三个不同列，每行最多用到前 3 名）。预计算前缀和后缀的 top3，枚举中间行，在前缀和后缀中查找列不冲突的最大组合。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumValueSum(int[][] board) {
        int m = board.length, n = board[0].length;

        // 对每行取最大的 3 个 (value, col) 对
        long[][][] rows = new long[m][3][2]; // rows[r][k] = {value, col}
        for (int r = 0; r < m; r++) {
            // 找每行前 3 大
            long[][] top3 = {{Long.MIN_VALUE, -1}, {Long.MIN_VALUE, -1}, {Long.MIN_VALUE, -1}};
            for (int c = 0; c < n; c++) {
                long v = board[r][c];
                if (v > top3[0][0]) {
                    top3[2] = top3[1]; top3[1] = top3[0];
                    top3[0] = new long[]{v, c};
                } else if (v > top3[1][0]) {
                    top3[2] = top3[1];
                    top3[1] = new long[]{v, c};
                } else if (v > top3[2][0]) {
                    top3[2] = new long[]{v, c};
                }
            }
            rows[r] = top3;
        }

        // 前缀 top3（行 0..i 合并）
        long[][][] prefix = new long[m][3][2];
        prefix[0] = rows[0];
        for (int i = 1; i < m; i++) {
            prefix[i] = mergeTop3(prefix[i - 1], rows[i]);
        }

        // 后缀 top3（行 i..m-1 合并）
        long[][][] suffix = new long[m][3][2];
        suffix[m - 1] = rows[m - 1];
        for (int i = m - 2; i >= 0; i--) {
            suffix[i] = mergeTop3(suffix[i + 1], rows[i]);
        }

        long ans = Long.MIN_VALUE;
        // 枚举中间行 r2
        for (int r2 = 1; r2 < m - 1; r2++) {
            for (long[] t2 : rows[r2]) {
                long v2 = t2[0]; long c2 = t2[1];
                // 在前缀中找不与 c2 冲突的最大 v1
                for (long[] t1 : prefix[r2 - 1]) {
                    long v1 = t1[0]; long c1 = t1[1];
                    if (c1 == c2) continue;
                    // 在后缀中找不与 c1, c2 冲突的最大 v3
                    for (long[] t3 : suffix[r2 + 1]) {
                        long v3 = t3[0]; long c3 = t3[1];
                        if (c3 != c1 && c3 != c2) {
                            ans = Math.max(ans, v1 + v2 + v3);
                            break;
                        }
                    }
                    break; // 前缀已按降序，找到第一个合法的即可
                }
            }
        }
        return ans;
    }

    private long[][] mergeTop3(long[][] a, long[][] b) {
        // 合并两个 top3，取最大的 3 个
        long[][] combined = new long[6][2];
        System.arraycopy(a, 0, combined, 0, 3);
        System.arraycopy(b, 0, combined, 3, 3);
        Arrays.sort(combined, (x, y) -> Long.compare(y[0], x[0]));
        return Arrays.copyOf(combined, 3);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n + m * 27)
- 空间复杂度：O(m * 3)

## 关键点总结

1. 每行只需 top3，三行选三不同列最多 27 种候选组合
2. 前后缀合并 top3 保证跨行选最优
3. 枚举中间行，查找前后缀中列不冲突的最大值
