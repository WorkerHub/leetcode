## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是回文。

返回符合要求的**最少分割次数**。

**示例 1：**
```
输入: s = "aab"
输出: 1
解释: 只需一次分割就可将 s 分割成 ["aa","b"] 这样两个回文子串。
```

**示例 2：**
```
输入: s = "a"
输出: 0
```

**示例 3：**
```
输入: s = "ab"
输出: 1
```

**提示：**
- `1 <= s.length <= 2000`
- `s` 仅由小写英文字母组成

## 解题思路

这道题是 [131. 分割回文串](https://leetcode.com/problems/palindrome-partitioning/) 的进阶版，要求的是**最少分割次数**而不是所有方案。

### 核心思想：动态规划

定义 `dp[i]` 表示字符串前 `i+1` 个字符的最少分割次数（即 `s[0..i]` 的最少分割次数）。

### 状态转移：

对于位置 `i`，如果 `s[j+1..i]` 是回文串，那么：
```
dp[i] = min(dp[i], dp[j] + 1)
```

特殊情况：如果 `s[0..i]` 整体是回文串，则 `dp[i] = 0`（不需要分割）。

### 优化策略：

1. **预处理回文判断**：使用 DP 预先计算所有子串是否为回文
2. **中心扩展优化**：在计算 dp 的同时判断回文，减少空间

### 算法步骤：

1. 预处理：计算 `isPalindrome[i][j]` 表示 `s[i..j]` 是否为回文
2. 初始化：`dp[i] = i`（最坏情况，每个字符都分割）
3. 状态转移：枚举所有可能的分割点
4. 返回 `dp[n-1]`

## Java 代码实现

### 方法一：DP + 预处理回文（推荐）⭐

```java
class Solution {
    public int minCut(String s) {
        int n = s.length();
        
        // 预处理：判断所有子串是否为回文
        boolean[][] isPalindrome = new boolean[n][n];
        
        // 单字符是回文
        for (int i = 0; i < n; i++) {
            isPalindrome[i][i] = true;
        }
        
        // 长度为 2 的子串
        for (int i = 0; i < n - 1; i++) {
            isPalindrome[i][i + 1] = (s.charAt(i) == s.charAt(i + 1));
        }
        
        // 长度 >= 3 的子串
        for (int length = 3; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                isPalindrome[i][j] = (s.charAt(i) == s.charAt(j) && isPalindrome[i + 1][j - 1]);
            }
        }
        
        // dp[i] 表示 s[0..i] 的最少分割次数
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            dp[i] = i;  // 最坏情况
        }
        
        for (int i = 0; i < n; i++) {
            // 整体是回文
            if (isPalindrome[0][i]) {
                dp[i] = 0;
                continue;
            }
            // 枚举分割点
            for (int j = 0; j < i; j++) {
                if (isPalindrome[j + 1][i]) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }
        
        return dp[n - 1];
    }
}
```

### 方法二：中心扩展 + DP（空间优化）

```java
class Solution {
    public int minCut(String s) {
        int n = s.length();
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            dp[i] = i;  // 最坏情况初始化
        }
        
        for (int i = 0; i < n; i++) {
            // 以 i 为中心的奇数长度回文
            expand(s, dp, i, i);
            // 以 i, i+1 为中心的偶数长度回文
            expand(s, dp, i, i + 1);
        }
        
        return dp[n - 1];
    }
    
    private void expand(String s, int[] dp, int left, int right) {
        int n = s.length();
        while (left >= 0 && right < n && s.charAt(left) == s.charAt(right)) {
            if (left == 0) {
                dp[right] = 0;
            } else {
                dp[right] = Math.min(dp[right], dp[left - 1] + 1);
            }
            left--;
            right++;
        }
    }
}
```

### 方法三：一维 DP 优化版

```java
class Solution {
    public int minCut(String s) {
        int n = s.length();
        
        // 预处理回文
        boolean[][] isPalindrome = new boolean[n][n];
        for (int i = 0; i < n; i++) {
            isPalindrome[i][i] = true;
        }
        for (int i = 0; i < n - 1; i++) {
            isPalindrome[i][i + 1] = (s.charAt(i) == s.charAt(i + 1));
        }
        for (int length = 3; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                isPalindrome[i][j] = (s.charAt(i) == s.charAt(j) && isPalindrome[i + 1][j - 1]);
            }
        }
        
        // dp[i] 表示 s[0..i] 的最少分割次数
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            if (isPalindrome[0][i]) {
                dp[i] = 0;
            } else {
                dp[i] = i;
                for (int j = 0; j < i; j++) {
                    if (isPalindrome[j + 1][i]) {
                        dp[i] = Math.min(dp[i], dp[j] + 1);
                    }
                }
            }
        }
        
        return dp[n - 1];
    }
}
```

## 复杂度分析

设字符串长度为 n。

### 方法一：DP + 预处理
- **时间复杂度**：O(n^2)
  - 预处理回文：O(n^2)
  - DP 计算：O(n^2)
- **空间复杂度**：O(n^2)，回文数组 + DP 数组

### 方法二：中心扩展 + DP
- **时间复杂度**：O(n^2)，每个中心最多扩展 n 次
- **空间复杂度**：O(n)，只需 DP 数组

## 关键点总结

1. **DP 定义**：`dp[i]` 表示前 `i+1` 个字符的最少分割次数
2. **状态转移**：枚举所有分割点，选择最小值
3. **回文预处理**：避免重复判断，提高效率
4. **初始化技巧**：`dp[i] = i`（最坏情况）
5. **优化空间**：中心扩展法可以省略回文数组

## 易错点

1. **DP 初始值错误**
   ```java
   // 错误：初始化为 0
   int[] dp = new int[n];
   
   // 正确：初始化为最坏情况
   for (int i = 0; i < n; i++) dp[i] = i;
   ```

2. **索引错误**
   ```java
   // 注意 dp[i] 对应 s[0..i]
   // isPalindrome[i][j] 对应 s[i..j]
   ```

3. **边界条件**
   ```java
   // 整体是回文时，分割次数为 0
   if (isPalindrome[0][i]) {
       dp[i] = 0;
   }
   ```

4. **回文判断范围**
   ```java
   // 错误：范围错误
   if (isPalindrome[j][i])
   
   // 正确：注意索引对应
   if (isPalindrome[j + 1][i])
   ```

5. **整数比较用 Math.min**
   ```java
   dp[i] = Math.min(dp[i], dp[j] + 1);
   ```
