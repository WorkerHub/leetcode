## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回长度至少为 `k` 且元素互不相同的子数组中元素之和的最大值，不存在则返回 0。

## 解题思路

在 3870 的滑动窗口基础上增加长度约束：只有当窗口长度 `right - left + 1 >= k` 时才更新最大和，其余逻辑与 3870 完全相同。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long maximumSubarraySum(int[] nums, int k) {
        int left = 0;
        long currSum = 0, maxSum = 0;
        Map<Integer, Integer> freq = new HashMap<>();

        for (int right = 0; right < nums.length; right++) {
            int v = nums[right];
            freq.merge(v, 1, Integer::sum);
            currSum += v;

            // 出现重复，收缩左端直到无重复
            while (freq.get(v) > 1) {
                int lv = nums[left];
                freq.merge(lv, -1, Integer::sum);
                currSum -= lv;
                left++;
            }
            // 窗口长度满足 >= k 才记录
            if (right - left + 1 >= k) {
                maxSum = Math.max(maxSum, currSum);
            }
        }
        return maxSum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 在 3870 基础上增加长度 >= k 的判断，其余逻辑相同。
2. 窗口长度 = `right - left + 1`。
3. 若没有满足长度 >= k 且无重复的子数组，返回默认值 0。
