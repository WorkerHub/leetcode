## 题目描述

初始分数为 1，每次可将分数加 1，或将分数乘以 2（最多 `maxDoubles` 次），返回从 1 到 `target` 的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minMoves(int target, int maxDoubles) {
        int moves = 0;
        // 逆向贪心：从 target 反推到 1
        while (target > 1 && maxDoubles > 0) {
            if (target % 2 == 1) {
                // 奇数，先 -1 变偶数
                target--;
                moves++;
            } else {
                // 偶数，使用一次双倍（÷2）
                target /= 2;
                moves++;
                maxDoubles--;
            }
        }
        // 剩余全靠 +1
        moves += (target - 1);
        return moves;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log target + maxDoubles)，每次双倍将 target 减半
- 空间复杂度：O(1)

## 关键点总结

1. 逆向贪心：从 target 反推到 1，双倍操作变为除以 2
2. 奇数必须先 -1 变偶数才能使用双倍
3. 双倍用完后，剩余步数直接为 `target - 1`
