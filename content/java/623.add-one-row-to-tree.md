## 题目描述

给定二叉树根节点 `root`，以及两个整数 `val` 和 `depth`，在给定深度处添加一行值为 `val` 的节点。

**示例：**
```
输入：root = [4,2,6,3,1,5], val = 1, depth = 2
输出：[4,1,1,2,6,3,1,5]
```

## 解题思路

DFS 递归到 depth-1 层，为每个节点创建新的左右子节点，将原来的子树挂到新节点下。

## Java 代码实现

```java
class Solution {
    public TreeNode addOneRow(TreeNode root, int val, int depth) {
        // 特殊情况：在根节点上方插入
        if (depth == 1) {
            TreeNode newRoot = new TreeNode(val);
            newRoot.left = root;
            return newRoot;
        }
        dfs(root, val, depth, 1);
        return root;
    }

    private void dfs(TreeNode node, int val, int depth, int current) {
        if (node == null) return;

        if (current == depth - 1) {
            // 保存原左右子树
            TreeNode oldLeft = node.left;
            TreeNode oldRight = node.right;
            // 创建新节点并重新连接
            node.left = new TreeNode(val);
            node.right = new TreeNode(val);
            node.left.left = oldLeft;
            node.right.right = oldRight;
            return;
        }

        dfs(node.left, val, depth, current + 1);
        dfs(node.right, val, depth, current + 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归栈深度

## 关键点总结

1. **特殊处理 depth=1**：创建新根节点
2. **在 depth-1 层操作**：找到父节点进行插入
3. **保存原子树**：先保存再重新连接
