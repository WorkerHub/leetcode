## 题目描述

给定整数数组 `nums` 和整数 `k`，将 `nums` 分割成尽可能少的子数组，使每个子数组恰好包含 `k` 个不同整数，返回最少子数组数，无法完成则返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int splitArray(int[] nums, int k) {
        int n = nums.length;
        int count = 0;
        int i = 0;

        while (i < n) {
            Map<Integer, Integer> freq = new HashMap<>();
            int j = i;
            // 贪心：尽量延伸当前子数组
            while (j < n) {
                int x = nums[j];
                if (!freq.containsKey(x) && freq.size() == k) {
                    break;  // 再加就超过 k 种，切割
                }
                freq.merge(x, 1, Integer::sum);
                j++;
            }
            if (freq.size() < k) return -1;  // 剩余元素不足 k 种
            count++;
            i = j;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个元素访问一次
- 空间复杂度：O(k)，哈希表最多存 k 个键

## 关键点总结

1. 贪心：每段尽量延伸，当不同数为 k 且下一个是新数时才切割
2. 切割后若当前段不足 k 种则返回 -1
3. 切割点 `j` 直接作为下一段起点
