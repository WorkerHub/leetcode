## 题目描述

给你一棵有 `n` 个节点的无向树，节点编号从 `0` 到 `n-1`，以及一个整数数组 `hasApple`（大小为 `n`），其中 `hasApple[i] = true` 代表节点 `i` 有一个苹果。

你将以节点 `0` 为根节点，求得从节点 `0` 出发，收集所有苹果，并回到节点 `0` 所需要的**最少时间**（秒）。

无向边用 `edges` 数组给出，`edges[i] = [fromi, toi]` 表示节点 `fromi` 和 `toi` 之间有一条双向边。

每走一条边（不论方向），需要花费 **1 秒**。

**示例 1：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,true,false,true,true,false]
输出：8
```

**示例 2：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,true,false,false,true,false]
输出：6
```

**示例 3：**
```
输入：n=7, edges=[[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], hasApple=[false,false,false,false,false,false,false]
输出：0
```

**提示：**
- `1 <= n <= 10^5`
- `edges.length == n - 1`
- `0 <= fromi, toi <= n - 1`
- `fromi != toi`
- `hasApple.length == n`

## 解题思路

**DFS 后序遍历：**

从根节点（0）做 DFS，对每个子树计算：从子树根节点出发收集该子树内所有苹果并返回所需时间。

**关键观察：**
- 若某子树内没有苹果，不需要走这棵子树，时间贡献为 0。
- 若某子树内有苹果，必须走到该子树并回来，时间贡献为 `子树内部时间 + 2`（来回各 1 秒）。

**递推公式（对节点 u，从父节点 parent 调用）：**
```
dfs(u) = sum(dfs(v) + 2 for v in children(u) if dfs(v) > 0 or hasApple[v])
```

即：若子节点 v 的子树需要访问（子树有苹果或 v 本身有苹果），则加上 `dfs(v) + 2`。

## Java 代码实现

### 方法一：DFS 递归（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private List<List<Integer>> graph;
    private List<Boolean> hasApple;

    public int minTime(int n, int[][] edges, List<Boolean> hasApple) {
        // 建邻接表（无向图）
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }
        this.hasApple = hasApple;
        return dfs(0, -1);
    }

    private int dfs(int node, int parent) {
        // 返回从 node 收集其子树所有苹果并回到 node 所需时间
        int totalTime = 0;

        for (int child : graph.get(node)) {
            if (child == parent) continue;  // 不回到父节点

            int childTime = dfs(child, node);

            // 如果子树需要访问（子树内部需要时间，或子节点本身有苹果）
            if (childTime > 0 || hasApple.get(child)) {
                totalTime += childTime + 2;  // +2 是去该子节点再回来的时间
            }
        }

        return totalTime;
    }
}
```

### 方法二：DFS 迭代（显式栈）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public int minTime(int n, int[][] edges, List<Boolean> hasApple) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }

        // 用显式栈模拟 DFS，记录后序遍历顺序
        int[] time = new int[n];
        int[] parentMap = new int[n];
        boolean[] visited = new boolean[n];
        parentMap[0] = -1;
        visited[0] = true;

        // 记录后序遍历序列
        List<int[]> order = new ArrayList<>();  // [节点, 父节点]
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0, -1});

        while (!stack.isEmpty()) {
            int[] pair = stack.pop();
            int node = pair[0], par = pair[1];
            order.add(pair);
            for (int child : graph.get(node)) {
                if (!visited[child]) {
                    visited[child] = true;
                    stack.push(new int[]{child, node});
                }
            }
        }

        // 从后往前（后序）计算时间
        for (int i = order.size() - 1; i >= 0; i--) {
            int node = order.get(i)[0], par = order.get(i)[1];
            if (par == -1) continue;
            if (hasApple.get(node) || time[node] > 0) {
                time[par] += time[node] + 2;
            }
        }

        return time[0];
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，每个节点和边各访问一次。
- **空间复杂度：** O(n)，邻接表和递归栈深度。

## 图解示例

```
n=7, hasApple=[F,F,T,F,T,T,F]

树结构：
        0
       / \
      1   2
     / \ / \
    4  5 3  6

DFS 从 0 出发：

dfs(4, 1): 无子节点，hasApple[4]=T，返回 0
dfs(5, 1): 无子节点，hasApple[5]=T，返回 0
dfs(1, 0):
  child=4: dfs(4)=0，hasApple[4]=T -> total += 0+2 = 2
  child=5: dfs(5)=0，hasApple[5]=T -> total += 0+2 = 2
  total = 4，返回 4

dfs(3, 2): 无子节点，hasApple[3]=F，返回 0
dfs(6, 2): 无子节点，hasApple[6]=F，返回 0
dfs(2, 0):
  hasApple[2]=T，child=3,6 都没苹果，total=0，返回 0

dfs(0, -1):
  child=1: dfs(1)=4 > 0 -> total += 4+2 = 6
  child=2: dfs(2)=0，hasApple[2]=T -> total += 0+2 = 2
  total = 8

返回 8，正确！
```

## 关键点总结

1. 后序 DFS：先处理子节点，再汇总到父节点，典型的树形 DP 思路。
2. 判断是否需要访问子树：`childTime > 0`（子树内有苹果）或 `hasApple.get(child)`（子节点本身有苹果）。
3. 来回时间 `+2`：每条边来回各走一次，固定贡献 2 秒。
4. 根节点不需要额外加 2（已包含在每个子树的贡献中）。

## 易错点

- 将根节点的时间也加 2（根节点不需要来回，起点和终点）。
- 只判断 `hasApple.get(child)` 而忘记 `childTime > 0`（子树深处有苹果但中间节点没苹果）。
- 建图时使用有向图而非无向图，导致遍历不完整。
