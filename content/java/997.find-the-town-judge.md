## 题目描述

小镇有 n 个人，法官不信任任何人，其他人都信任法官。给定 trust 数组，返回法官编号，不存在返回 -1。

**示例：**
```
输入：n = 3, trust = [[1,3],[2,3]]
输出：3
```

## 解题思路

入度-出度：法官的信任净值（被信任次数 - 信任别人次数）应为 n-1。

## Java 代码实现

```java
class Solution {
    public int findJudge(int n, int[][] trust) {
        int[] trustCount = new int[n + 1];

        for (int[] t : trust) {
            trustCount[t[0]]--; // 信任别人，出度+1
            trustCount[t[1]]++; // 被信任，入度+1
        }

        for (int i = 1; i <= n; i++) {
            if (trustCount[i] == n - 1) return i;
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n)

## 关键点总结

1. **入度-出度**：法官入度 n-1，出度 0，净值 n-1
2. **单数组**：用一个数组记录净信任值
3. **图论思想**：信任关系是有向图
