## 题目描述

有 n 个网络节点，给定有向边列表 times[i] = (u, v, w)。从节点 k 发出信号，返回所有节点都收到信号的最短时间。不能全部收到返回 -1。

**示例：**
```
输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2
```

## 解题思路

Dijkstra 算法：从 k 出发计算到所有节点的最短距离，答案为最大距离值。

## Java 代码实现

```java
class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        // 构建邻接表
        List<int[]>[] graph = new List[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] t : times) graph[t[0]].add(new int[]{t[1], t[2]});

        // 距离数组
        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;

        // 最小堆：(距离, 节点)
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, k});

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int d = curr[0], u = curr[1];

            if (d > dist[u]) continue;

            for (int[] edge : graph[u]) {
                int v = edge[0], w = edge[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }

        int maxDist = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == Integer.MAX_VALUE) return -1;
            maxDist = Math.max(maxDist, dist[i]);
        }
        return maxDist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(E log V)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **Dijkstra 算法**：适用于非负权边的单源最短路径
2. **最小堆优化**：高效获取当前距离最小的节点
3. **结果判断**：最大距离为答案，有无穷大则返回 -1
