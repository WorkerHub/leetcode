## 题目描述

给你一个整数数组 `nums`，返回最长的非递减子序列的长度。

## 解题思路

经典 LIS（最长非递减子序列）问题，使用 patience sorting 二分查找优化。维护 `tails` 数组，`tails[i]` 表示长度为 `i+1` 的非递减子序列的最小末尾元素。对每个元素用二分查找找第一个严格大于它的位置替换，或追加到末尾。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int lengthOfLIS(int[] nums) {
        List<Integer> tails = new ArrayList<>();
        for (int x : nums) {
            // 非递减：找第一个严格大于 x 的位置（upper_bound）
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails.get(mid) <= x) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) {
                tails.add(x);
            } else {
                tails.set(lo, x);
            }
        }
        return tails.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 非递减用 upper_bound（找第一个严格大于 x 的位置），严格递增用 lower_bound
2. `tails` 数组始终有序，其长度就是答案
3. 替换操作不改变长度，追加才增加答案
