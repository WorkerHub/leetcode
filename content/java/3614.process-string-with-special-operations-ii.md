## 题目描述

给定字符串 `s`，按与 3612 相同规则处理（普通字符追加、`'*'` 删除末尾、`'#'` 翻转），处理完后回答若干查询：每个查询返回结果字符串第 `k` 个字符。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public char[] processStrII(String s, int[] queries) {
        Deque<Character> dq = new ArrayDeque<>();
        boolean isReversed = false;

        for (char c : s.toCharArray()) {
            if (c == '*') {
                if (!dq.isEmpty()) {
                    if (!isReversed) dq.pollLast();
                    else dq.pollFirst();
                }
            } else if (c == '#') {
                isReversed = !isReversed;
            } else {
                if (!isReversed) dq.offerLast(c);
                else dq.offerFirst(c);
            }
        }

        // 转为列表，根据方向决定是否翻转
        char[] arr = new char[dq.size()];
        int idx = 0;
        for (char ch : dq) arr[idx++] = ch;
        if (isReversed) {
            int l = 0, r = arr.length - 1;
            while (l < r) { char tmp = arr[l]; arr[l++] = arr[r]; arr[r--] = tmp; }
        }

        char[] result = new char[queries.length];
        for (int i = 0; i < queries.length; i++) result[i] = arr[queries[i]];
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q)，模拟 O(n)，查询 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 双端队列 + 方向标志，O(1) 处理翻转操作（`'#'` 只切换标志）
2. 最终转换为数组时根据方向标志决定是否翻转，批量回答查询
3. 与 3612 的区别在于有多个查询，需一次模拟后批量处理
