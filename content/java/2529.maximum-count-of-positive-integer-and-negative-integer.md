## 题目描述

给你非递减有序数组 `nums`，返回正整数数目和负整数数目中的较大值（0 既不算正也不算负）。

## 解题思路

二分查找确定边界：负整数数目 = 第一个 >= 0 的位置；正整数数目 = n - 第一个 > 0 的位置。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximumCount(int[] nums) {
        // 负整数：< 0，个数 = 第一个 >= 0 的位置
        int neg = lowerBound(nums, 0);
        // 正整数：> 0，个数 = n - 第一个 > 0 的位置（即第一个 >= 1 的位置）
        int pos = nums.length - lowerBound(nums, 1);
        return Math.max(neg, pos);
    }

    // 返回第一个 >= target 的位置
    private int lowerBound(int[] nums, int target) {
        int lo = 0, hi = nums.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (nums[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 数组有序，用二分查找 O(log n) 找到两个边界
2. 负数个数 = 第一个 >= 0 的下标；正数个数 = n - 第一个 >= 1 的下标
3. 0 通过两次查找自然被排除，无需特判
