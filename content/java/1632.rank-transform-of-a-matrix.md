## 题目描述

给你 `m x n` 的矩阵，返回矩阵的**秩变换**：秩从 1 开始，同行/列较小元素秩更小，相同元素同行/列秩相等，每个元素秩尽量小。

**提示：**
- `1 <= m, n <= 500`，`-10^9 <= matrix[i][j] <= 10^9`

## 解题思路

1. 将所有元素按值从小到大排序
2. 对相同值的元素，用**并查集**将同行或同列的分为一组
3. 每组的秩 = 组内所有元素所在行/列的已用最大秩 + 1
4. 更新每行每列的最大秩

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public int[][] matrixRankTransform(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] answer = new int[m][n];
        int[] rowMax = new int[m]; // 每行已分配的最大秩
        int[] colMax = new int[n]; // 每列已分配的最大秩

        // 按值分组：值 -> 位置列表
        TreeMap<Integer, List<int[]>> valPos = new TreeMap<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                valPos.computeIfAbsent(matrix[r][c], k -> new ArrayList<>()).add(new int[]{r, c});
            }
        }

        for (Map.Entry<Integer, List<int[]>> entry : valPos.entrySet()) {
            List<int[]> positions = entry.getValue();

            // 并查集：前 m 个节点是行，后 n 个是列
            parent = new int[m + n];
            for (int i = 0; i < m + n; i++) parent[i] = i;

            for (int[] pos : positions) {
                union(pos[0], m + pos[1]); // 行 r 和列 c 合并
            }

            // 对每个连通组，找最大约束秩
            Map<Integer, Integer> groupMax = new HashMap<>();
            for (int[] pos : positions) {
                int root = find(pos[0]);
                int maxRank = Math.max(rowMax[pos[0]], colMax[pos[1]]);
                groupMax.merge(root, maxRank, Math::max);
            }

            // 给每个元素分配秩并更新行/列最大秩
            for (int[] pos : positions) {
                int root = find(pos[0]);
                int rank = groupMax.get(root) + 1;
                answer[pos[0]][pos[1]] = rank;
                rowMax[pos[0]] = Math.max(rowMax[pos[0]], rank);
                colMax[pos[1]] = Math.max(colMax[pos[1]], rank);
            }
        }
        return answer;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m*n * log(m*n) * α(m+n))
- **空间复杂度**：O(m*n + m + n)

## 关键点总结

1. 按值从小到大处理，确保较小值先确定秩
2. 并查集用 m+n 个节点表示行和列
3. 每组秩 = 组内所有行/列已用最大秩 + 1
4. 处理完后更新对应行/列的最大秩
