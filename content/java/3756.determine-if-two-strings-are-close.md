## 题目描述

给定两个字符串 `word1` 和 `word2`，判断它们是否"接近"：字符集合相同，且各字母频率的多重集相同（频率列表排序后一致）。

## 解题思路

统计两个字符串的字母频率，比较字符集是否相同，再排序频率数组进行比较。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public boolean closeStrings(String word1, String word2) {
        int[] cnt1 = new int[26];
        int[] cnt2 = new int[26];
        for (char c : word1.toCharArray()) cnt1[c - 'a']++;
        for (char c : word2.toCharArray()) cnt2[c - 'a']++;

        // 条件 1：字符集相同（出现的字母种类一致）
        for (int i = 0; i < 26; i++) {
            if ((cnt1[i] == 0) != (cnt2[i] == 0)) return false;
        }

        // 条件 2：频率多重集相同
        Arrays.sort(cnt1);
        Arrays.sort(cnt2);
        return Arrays.equals(cnt1, cnt2);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(1)，字母表大小固定为 26

## 关键点总结

1. 两个条件缺一不可：字符集和频率多重集均需相同
2. 频率多重集比较：排序后对比，不需要知道具体对应关系
3. 字符集检查：某字母在一个字符串中出现而在另一个中没有则返回 false
