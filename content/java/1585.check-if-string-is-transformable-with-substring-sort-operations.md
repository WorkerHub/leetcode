## 题目描述

每次可选 s 的任意子串排序。判断能否通过若干次操作将 s 变为 t。

**示例：**
```
输入：s = "84532", t = "34852"
输出：true
```

## 解题思路

贪心：子串排序等价于小字符可以向左移，但不能越过更小的字符。用队列记录每个数字的位置，逐字符匹配 t。

## Java 代码实现

```java
class Solution {
    public boolean isTransformable(String s, String t) {
        if (s.length() != t.length()) return false;
        
        // 记录 s 中每个数字的位置队列
        @SuppressWarnings("unchecked")
        Deque<Integer>[] pos = new Deque[10];
        for (int i = 0; i < 10; i++) pos[i] = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            pos[s.charAt(i) - '0'].offer(i);
        }
        
        for (char c : t.toCharArray()) {
            int d = c - '0';
            if (pos[d].isEmpty()) return false;
            int idx = pos[d].peek();
            // 检查 idx 前面是否有比 d 小的数字
            for (int smaller = 0; smaller < d; smaller++) {
                if (!pos[smaller].isEmpty() && pos[smaller].peek() < idx) {
                    return false;
                }
            }
            pos[d].poll();
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(9n) = O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **排序=小字符左移**：不能越过更小的字符
2. **队列维护位置**：每个数字的出现位置按序存储
3. **检查前方阻塞**：匹配 d 时其左边不能有更小的数字
