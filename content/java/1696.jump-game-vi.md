## 题目描述

下标 0 开始的整数数组 `nums` 和整数 `k`，从下标 0 出发，每步最多向前跳 `k` 步，返回能得到的**最大得分**（经过所有下标的数字之和）。

## 解题思路

**DP + 单调队列：** `dp[i] = max(dp[i-k..i-1]) + nums[i]`。用单调递减队列在滑动窗口内 O(1) 查询最大值。

## Java 代码实现

```java
class Solution {
    public int maxResult(int[] nums, int k) {
        int n = nums.length;
        int[] dp = new int[n];
        dp[0] = nums[0];
        // 单调递减队列，存下标，队首是窗口内 dp 最大值的下标
        ArrayDeque<Integer> dq = new ArrayDeque<>();
        dq.addLast(0);

        for (int i = 1; i < n; i++) {
            // 移除超出窗口的队首元素
            while (!dq.isEmpty() && dq.peekFirst() < i - k) dq.pollFirst();
            dp[i] = dp[dq.peekFirst()] + nums[i];
            // 维护单调递减：移除队尾比 dp[i] 小的元素
            while (!dq.isEmpty() && dp[dq.peekLast()] <= dp[i]) dq.pollLast();
            dq.addLast(i);
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 状态转移：`dp[i] = windowMax(dp[i-k..i-1]) + nums[i]`
2. 单调递减队列：队首为窗口最大值，新元素入队前弹出队尾较小元素
3. 队首出队条件：`index < i - k`（超出窗口）
