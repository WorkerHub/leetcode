## 题目描述

给你两个长度为 n 的整数数组 `nums1` 和 `nums2` 以及整数 `k`，每次操作选一个下标将 `nums1[i]` 加减 k 同时 `nums2[i]` 减加 k，返回使两数组元素和相等的最少操作次数，无法实现返回 `-1`。

## 解题思路

设 `diff[i] = nums1[i] - nums2[i]`，每次操作将某位置的 diff 加减 `2k`。若 k=0 则 diff 全为 0 才合法；否则每个 diff 必须是 k 的倍数，且正 diff 总和与负 diff 总和（以 k 为单位）相等，答案为正 diff 总和除以 k。

## Java 代码实现

```java
class Solution {
    public long minOperations(int[] nums1, int[] nums2, int k) {
        if (k == 0) {
            for (int i = 0; i < nums1.length; i++)
                if (nums1[i] != nums2[i]) return -1;
            return 0;
        }

        long pos = 0, neg = 0;
        for (int i = 0; i < nums1.length; i++) {
            long d = nums1[i] - nums2[i];
            if (d % k != 0) return -1; // 差值不是 k 的倍数，无解
            if (d > 0) pos += d / k;
            else if (d < 0) neg += (-d) / k;
        }
        // 增操作和减操作次数必须相等（平衡）
        return pos == neg ? pos : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每次操作对 diff[i] 加减 `2k`，等效为对某位置加 k 另一位置减 k
2. 各位置 diff 必须是 k 的倍数，否则无解
3. 增量操作次数和减量操作次数必须相等（一次操作同时影响两个方向）
