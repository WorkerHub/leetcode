## 题目描述

给定整数数组 `nums`（长度 <= 16），找出所有非空子集按位或的最大值，返回按位或等于该最大值的子集数目。

## 解题思路

最大按位或 = 所有元素的 OR。枚举所有 2^n-1 个非空子集，统计按位或等于最大值的个数。

## Java 代码实现

### 方法一：位掩码枚举（推荐）

```java
class Solution {
    public int countMaxOrSubsets(int[] nums) {
        int n = nums.length;
        int maxOr = 0;
        for (int x : nums) maxOr |= x;

        int count = 0;
        for (int mask = 1; mask < (1 << n); mask++) {
            int curOr = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) curOr |= nums[i];
            }
            if (curOr == maxOr) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(1)

## 关键点总结

1. 最大按位或 = 所有元素 OR，无法超过这个值
2. n <= 16，枚举 2^16 = 65536 个子集完全可行
3. 跳过 mask=0（空集）
