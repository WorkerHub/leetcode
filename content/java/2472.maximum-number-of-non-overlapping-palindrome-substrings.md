## 题目描述

给你字符串 `s` 和正整数 `k`，从中选出若干不重叠子字符串，每个子串长度至少为 `k` 且是回文串，返回最多能选出的子串数目。

## 解题思路

DP 预处理 `isPal[i][j]` 表示 `s[i..j]` 是否为回文，再用贪心 DP：`f[i]` 为 `s[0..i-1]` 中的最大回文子串数。转移时只枚举长度为 `k` 和 `k+1` 的回文子串（奇偶各一种），贪心选最短（最早结束）以留出更多空间。

## Java 代码实现

```java
class Solution {
    public int maxPalindromes(String s, int k) {
        int n = s.length();
        boolean[][] isPal = new boolean[n][n];
        // 预处理所有子串是否为回文
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    isPal[i][j] = (j - i < 2) || isPal[i + 1][j - 1];
                }
            }
        }

        int[] f = new int[n + 1];
        for (int i = k; i <= n; i++) {
            f[i] = f[i - 1]; // 不以 i-1 结尾
            // 只需枚举长度 k 和 k+1（涵盖奇偶回文）
            for (int len : new int[]{k, k + 1}) {
                int left = i - len;
                if (left >= 0 && isPal[left][i - 1]) {
                    f[i] = Math.max(f[i], f[left] + 1);
                }
            }
        }
        return f[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. 贪心：选最短满足条件的回文（最早结束），为后续留出更多空间
2. 只需枚举长度 k 和 k+1：任何更长的回文内部必然包含一个长度为 k 或 k+1 的回文核心
3. DP 预处理回文判断，避免重复计算
