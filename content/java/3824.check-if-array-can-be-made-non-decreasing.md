## 题目描述

给定整数数组 `nums`，最多删除一个元素，判断能否使数组变为非递减序列。

## Java 代码实现

```java
class Solution {
    public boolean checkPossibility(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] > nums[i + 1]) {
                // 尝试删除 i 或 i+1，检查剩余是否非递减
                return check(nums, i) || check(nums, i + 1);
            }
        }
        return true;
    }

    private boolean check(int[] nums, int skip) {
        int prev = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (i == skip) continue;
            if (nums[i] < prev) return false;
            prev = nums[i];
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 找到第一个违规点 i（`nums[i] > nums[i+1]`），只需尝试删除这两个位置之一
2. 无需枚举所有删除方案，贪心地处理第一个违规点即可
3. 若无违规点直接返回 true
