## 题目描述

f(s) = 字符串中字典序最小字符的出现频率。对每个 query，统计 words 中满足 f(query) < f(word) 的单词数。

**示例：**
```
输入：queries = ["bbb","cc"], words = ["a","aa","aaa","aaaa"]
输出：[1,2]
```

## 解题思路

预处理 words 的 f 值并排序，对每个 query 用二分查找统计比它大的数量。

## Java 代码实现

```java
class Solution {
    public int[] numSmallerByFrequency(String[] queries, String[] words) {
        // 计算 words 的 f 值并排序
        int[] wordF = new int[words.length];
        for (int i = 0; i < words.length; i++) {
            wordF[i] = f(words[i]);
        }
        Arrays.sort(wordF);

        // 对每个 query 二分查找
        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int qf = f(queries[i]);
            // 找第一个大于 qf 的位置
            int idx = upperBound(wordF, qf);
            result[i] = wordF.length - idx;
        }
        return result;
    }

    private int f(String s) {
        // 找最小字符的频率
        char minChar = s.charAt(0);
        int count = 1;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) < minChar) {
                minChar = s.charAt(i);
                count = 1;
            } else if (s.charAt(i) == minChar) {
                count++;
            }
        }
        return count;
    }

    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n+m)*k + n log n + m log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **f 函数**：一次遍历找最小字符并计数
2. **排序 + 二分**：预处理后每次查询 O(log n)
3. **upperBound**：找第一个严格大于 target 的位置
4. **结果计算**：总长 - upperBound 位置 = 满足条件的数量
