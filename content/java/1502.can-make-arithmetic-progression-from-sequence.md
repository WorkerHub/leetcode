## 题目描述

判断数组重新排列后能否构成等差数列。

**示例：**
```
输入：arr = [3,5,1]
输出：true
解释：排序后 [1,3,5]，公差为 2
```

## 解题思路

排序后检查相邻元素差是否都相同。

## Java 代码实现

```java
class Solution {
    public boolean canMakeArithmeticProgression(int[] arr) {
        Arrays.sort(arr);
        int d = arr[1] - arr[0];
        for (int i = 2; i < arr.length; i++) {
            if (arr[i] - arr[i-1] != d) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序**：等差数列排序后公差恒定
2. **逐对检查**：差值是否一致
3. **O(n) 方法**：也可用 HashSet + 公差公式
