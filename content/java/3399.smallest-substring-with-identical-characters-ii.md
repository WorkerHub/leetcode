## 题目描述

与 3398 完全相同的问题，但数据范围更大（n 最大 10^5），需要 O(n log n) 的高效解法。

## Java 代码实现

```java
class Solution {
    public int minLength(String s, int numOps) {
        int n = s.length();

        // 预计算连续段长度
        int[] runs = computeRuns(s, n);

        // 特判 mid=1
        int c0 = 0, c1 = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) != "01".charAt(i % 2)) c0++;
            if (s.charAt(i) != "10".charAt(i % 2)) c1++;
        }
        if (Math.min(c0, c1) <= numOps) return 1;

        // 二分 [2, n]
        int lo = 2, hi = n;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            long ops = 0;
            for (int L : runs) ops += L / (mid + 1);
            if (ops <= numOps) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private int[] computeRuns(String s, int n) {
        java.util.List<Integer> runList = new java.util.ArrayList<>();
        int i = 0;
        while (i < n) {
            int j = i + 1;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            runList.add(j - i);
            i = j;
        }
        return runList.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，预计算连续段 O(n)，二分 O(log n) 次，每次验证 O(段数)
- 空间复杂度：O(n)，存储连续段长度

## 关键点总结

1. 预计算连续段长度，加速每次二分验证。
2. `mid=1` 特殊处理：变为交替字符串，枚举两种模式取最小。
3. `mid>=2`：每段长度 L 的代价为 `L/(mid+1)`（每 mid+1 个插入一个翻转）。
