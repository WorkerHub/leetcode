## 题目描述

给你正整数数组 `nums` 和正整数 `k`，将数组分为两个非空子集，若两个子集的和均 >= `k` 则称为好分区，返回好分区的数目（结果对 `10^9 + 7` 取模）。

## 解题思路

容斥：好分区数 = 总分区数（`2^(n-1)`）- 坏分区数（子集1的和 < k 的方案数）。用 0-1 背包计算和严格小于 k 的子集数，减去空集后即为坏分区数。总和 < 2k 时提前返回 0。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public long countPartitions(int[] nums, int k) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;
        // 总和不足 2k，不可能有好分区
        if (total < 2L * k) return 0;

        // 0-1 背包：dp[j] = 和恰好为 j 的子集数
        long[] dp = new long[k];
        dp[0] = 1;
        for (int num : nums) {
            // 逆序遍历避免重复选取
            for (int j = k - 1; j >= 0; j--) {
                if (j + num < k) {
                    dp[j + num] = (dp[j + num] + dp[j]) % MOD;
                }
            }
        }

        // 坏分区数 = 和 < k 的子集数 - 1（减去空集）
        long bad = 0;
        for (long v : dp) bad = (bad + v) % MOD;
        bad = (bad - 1 + MOD) % MOD;

        // 总分区数 = 2^(n-1)
        long totalPartitions = pow(2, n - 1);
        return (totalPartitions - bad + MOD) % MOD;
    }

    private long pow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)
- **空间复杂度**：O(k)

## 关键点总结

1. 好分区数 = 总分区数 - 坏分区数（利用容斥简化问题）
2. 总和 < 2k 时提前返回 0，避免无效计算
3. 0-1 背包逆序遍历统计和严格小于 k 的子集数，减去空集
