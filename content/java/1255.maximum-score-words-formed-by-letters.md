## 题目描述

给定词汇表 words、字母表 letters 和每个字母的分数 score。用 letters 中的字母拼写 words 中的单词（每个字母只能用一次），求能获得的最大分数和。

**示例：**
```
输入：words = ["dog","cat","dad","good"], letters = ["a","a","c","d","d","d","g","o","o"], score = [1,0,9,5,0,0,3,0,0,...]
输出：23（选 "dad"=11 + "good"=12）
```

## 解题思路

回溯：每个单词选或不选。选时检查字母是否够用，够则累加分数继续搜索。words.length ≤ 14 所以 2^14 可行。

## Java 代码实现

```java
class Solution {
    private int maxScore = 0;
    
    public int maxScoreWords(String[] words, char[] letters, int[] score) {
        // 统计可用字母
        int[] available = new int[26];
        for (char c : letters) available[c - 'a']++;
        
        backtrack(words, score, available, 0, 0);
        return maxScore;
    }
    
    private void backtrack(String[] words, int[] score, int[] available, int idx, int curScore) {
        maxScore = Math.max(maxScore, curScore);
        
        for (int i = idx; i < words.length; i++) {
            // 检查能否拼写该单词
            int[] cost = new int[26];
            int wordScore = 0;
            boolean canUse = true;
            
            for (char c : words[i].toCharArray()) {
                cost[c - 'a']++;
                wordScore += score[c - 'a'];
                if (cost[c - 'a'] > available[c - 'a']) {
                    canUse = false;
                    break;
                }
            }
            
            if (canUse) {
                // 使用该单词
                for (int j = 0; j < 26; j++) available[j] -= cost[j];
                backtrack(words, score, available, i + 1, curScore + wordScore);
                // 回溯
                for (int j = 0; j < 26; j++) available[j] += cost[j];
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × L)，n 为单词数，L 为单词平均长度
- **空间复杂度**：O(n)，递归深度

## 关键点总结

1. **回溯**：每个单词选或不选，标准子集枚举
2. **字母计数**：用数组统计可用字母和单词消耗
3. **提前剪枝**：字母不够时跳过该单词
4. **回溯恢复**：使用后归还字母
