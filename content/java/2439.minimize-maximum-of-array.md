## 题目描述

给你非负整数数组 `nums`，每次操作可将 `nums[i]` 减 1 同时 `nums[i-1]` 加 1（1 <= i < n），进行任意次操作后返回数组中可能的最小最大值。

## 解题思路

数学贪心：超出部分只能向左传递，前 k 个元素的总和不变，要使最大值最小，需要让前 k 个元素均摊，所以答案 >= ceil(prefix_sum[k] / k)。对所有前缀取最大的 ceil(sum/count) 即为答案。

## Java 代码实现

```java
class Solution {
    public int minimizeArrayValue(int[] nums) {
        // 答案 = max over all i of ceil(prefix_sum[i+1] / (i+1))
        long ans = 0;
        long prefixSum = 0;
        for (int i = 0; i < nums.length; i++) {
            prefixSum += nums[i];
            // 向上取整：(prefixSum + i) / (i + 1)
            long avg = (prefixSum + i) / (i + 1);
            ans = Math.max(ans, avg);
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 超出部分只能向左传（操作是 `nums[i]` 减，`nums[i-1]` 加）
2. 前 k 个元素总和不变，最大值 >= ceil(前缀和 / k)
3. 整数向上取整：`(a + b - 1) / b`，即 `(prefixSum + i) / (i+1)`
