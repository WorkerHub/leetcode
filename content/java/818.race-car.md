## 题目描述

你的赛车起始停留在位置 `0`，速度为 `+1`，行驶在一根无限长的数轴上。（车也可以向负数方向行驶。）

你的车会根据一系列由 `A`（加速）和 `R`（倒车）组成的指令进行自动驾驶。

当车得到指令 `"A"` 时，将会做以下操作：
- `position += speed`
- `speed *= 2`

当车得到指令 `"R"` 时，将会做以下操作：
- 如果当前速度是正数，则将速度变为 `-1`
- 否则将速度变为 `1`
- 速度会改变但位置不变

给定目标位置 `target`，返回能到达目标位置的最短指令列表的长度。

**示例 1:**
```
输入: target = 3
输出: 2
解释: 最短指令列表为 "AA"
```

**示例 2:**
```
输入: target = 6
输出: 5
解释: 最短指令列表为 "AAARA"
```

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int racecar(int target) {
        // BFS：(位置, 速度) -> 步数
        Queue<long[]> queue = new ArrayDeque<>();  // [position, speed]
        Set<Long> visited = new HashSet<>();

        queue.offer(new long[]{0, 1});
        visited.add(encode(0, 1));
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                long[] cur = queue.poll();
                long pos = cur[0], speed = cur[1];

                if (pos == target) return steps;

                // 指令 A：加速
                long newPos = pos + speed;
                long newSpeed = speed * 2;
                long key1 = encode(newPos, newSpeed);
                if (!visited.contains(key1) && Math.abs(newPos) < 2 * target) {
                    visited.add(key1);
                    queue.offer(new long[]{newPos, newSpeed});
                }

                // 指令 R：倒车
                long revSpeed = speed > 0 ? -1 : 1;
                long key2 = encode(pos, revSpeed);
                if (!visited.contains(key2)) {
                    visited.add(key2);
                    queue.offer(new long[]{pos, revSpeed});
                }
            }
            steps++;
        }

        return -1;
    }

    private long encode(long pos, long speed) {
        // 编码 (pos, speed) 为唯一 long 值，speed 范围有限
        return pos * 100000L + (speed + 50000);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(T log T)
- **空间复杂度**：O(T log T)

## 关键点总结

1. **BFS搜索**：找最短路径
2. **状态剪枝**：限制位置范围在 2 * target 内
3. **状态定义**：(位置, 速度) 的二元组
4. **编码状态**：将二元组编码为唯一键值
