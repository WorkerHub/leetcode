## 题目描述

微波炉面板有数字键0-9，手指从startAt开始，移动和按下各有代价。求设置targetSeconds的最小总代价。

## 解题思路

枚举所有合法的(分钟,秒)组合（分钟0-99，秒=targetSeconds-m*60在[0,99]内），计算每种组合的按键代价取最小。

## Java 代码实现

```java
class Solution {
    public int minCostSetTime(int startAt, int moveCost, int pushCost, int targetSeconds) {
        int ans = Integer.MAX_VALUE;
        
        for (int m = 0; m < 100; m++) {
            int s = targetSeconds - m * 60;
            if (s < 0 || s > 99) continue;
            
            // 构造按键序列：m*100+s的各位数字（去掉前导零）
            int num = m * 100 + s;
            if (num == 0) continue; // targetSeconds不会为0
            
            // 提取数字序列
            String seq = String.valueOf(num);
            int cost = 0;
            int cur = startAt;
            for (char c : seq.toCharArray()) {
                int digit = c - '0';
                if (digit != cur) {
                    cost += moveCost;
                    cur = digit;
                }
                cost += pushCost;
            }
            ans = Math.min(ans, cost);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，最多100种组合，每种最多4位
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举所有合法表示**：分钟0-99，对应秒数0-99
2. **按键序列**：m*100+s转字符串去掉前导零
3. **代价计算**：移动到不同数字加moveCost，每次按键加pushCost
