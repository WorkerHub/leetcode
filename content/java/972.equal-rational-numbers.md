## 题目描述

判断两个有理数字符串（可含循环小数如 "0.1(6)"）是否表示相同的数。

**示例：**
```
输入：s = "0.9(9)", t = "1."
输出：true
```

## 解题思路

将有理数字符串转换为分数比较。循环小数 0.a(b) = a/10^len(a) + b/(10^len(a) * (10^len(b) - 1))。

## Java 代码实现

```java
class Solution {
    public boolean isRationalEqual(String s, String t) {
        return Math.abs(toDouble(s) - toDouble(t)) < 1e-9;
    }

    private double toDouble(String s) {
        int parenIdx = s.indexOf('(');
        if (parenIdx == -1) return Double.parseDouble(s);

        String base = s.substring(0, parenIdx);
        String repeat = s.substring(parenIdx + 1, s.length() - 1);

        // 展开足够多的循环位
        StringBuilder sb = new StringBuilder(base);
        for (int i = 0; i < 20; i++) sb.append(repeat);
        return Double.parseDouble(sb.toString());
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，字符串长度有限
- **空间复杂度**：O(1)

## 关键点总结

1. **高精度展开**：循环部分重复足够多次
2. **浮点比较**：用 epsilon 判断相等
3. **字符串解析**：找括号分割各部分
