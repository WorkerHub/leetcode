## 题目描述

给定 DataFrame employees，将 salary 列的所有值翻倍。

## 解题思路

本题为 Python Pandas 专项练习，使用就地向量化运算 `df['salary'] *= 2`。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df['salary'] *= 2 等价于就地修改每个 salary 值

import java.util.*;

class Solution {
    // Java 中就地修改 salary 列
    public int[][] modifySalaryColumn(int[][] employees) {
        // employees[i] = [emp_id, salary]
        for (int[] row : employees) {
            row[1] *= 2; // 将 salary 翻倍
        }
        return employees;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. `df['col'] *= 2` 就地翻倍，最简洁高效
2. 向量化操作性能优于 apply 逐行处理
3. Pandas 列运算会自动对整列应用，无需显式循环
