## 题目描述

给定整数 `n` 和 `m`，构造长度为 `n` 的数组（元素在 `[1, m]`），满足：对所有 `i < j`，`(j - i) % nums[i] != 0`。无法构造返回空数组。

## 解题思路

回溯：值为 1 时必然违反（1 整除任何正整数），故 `m < 2` 无解。逐位填充，对每个位置从 2 到 m 枚举，检查前面所有位置 `j < i` 的约束 `(i - j) % nums[j] != 0`。

## Java 代码实现

```java
class Solution {
    private int[] result;
    private int n, m;

    public int[] findArray(int n, int m) {
        if (m < 2) return new int[0];
        this.n = n; this.m = m;
        this.result = new int[n];
        return backtrack(0) ? result : new int[0];
    }

    private boolean backtrack(int pos) {
        if (pos == n) return true;
        for (int v = 2; v <= m; v++) {
            if (isValid(pos, v)) {
                result[pos] = v;
                if (backtrack(pos + 1)) return true;
                result[pos] = 0;
            }
        }
        return false;
    }

    private boolean isValid(int pos, int v) {
        for (int j = 0; j < pos; j++) {
            if ((pos - j) % result[j] == 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m^n * n)，最坏情况，回溯剪枝后实际很快
- 空间复杂度：O(n)

## 关键点总结

1. `nums[i] = 1` 时 `(j-i) % 1 = 0` 永远违反，故 m < 2 无解
2. 前面位置约束后面：只需检查 `j < i` 是否 `(i-j) % nums[j] == 0`
3. 优先选较大值，整除概率更低
