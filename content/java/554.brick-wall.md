## 题目描述

你的面前有一堵矩形的、由 n 行砖块组成的砖墙。这些砖块高度相同（也就是一个单位高）但是宽度不同。每一行砖块的宽度之和相等。

你现在要画一条**自顶向下**的、穿过**最少**砖块的垂线。如果你画的线只是从砖块的边缘经过，就不算穿过这块砖。**你不能沿着墙的两个垂直边缘之一画线，这样显然是没有穿过一块砖的。**

给你一个二维数组 `wall`，该数组包含这堵墙的信息。其中，`wall[i]` 是一个代表从左至右每块砖的宽度的数组。你需要找出怎样画才能使这条线**穿过的砖块数量最少**，并且返回**穿过的砖块数量**。

**示例 1：**

![brick wall](https://assets.leetcode.com/uploads/2021/04/24/cutwall-grid.jpg)

```
输入：wall = [[1,2,2,1],[3,1,2],[1,3,2],[2,4],[3,1,2],[1,3,1,1]]
输出：2
```

**示例 2：**
```
输入：wall = [[1],[1],[1]]
输出：3
```

**提示：**
- `n == wall.length`
- `1 <= n <= 10^4`
- `1 <= wall[i].length <= 10^4`
- `1 <= sum(wall[i].length) <= 2 * 10^4`
- 对于每一行 i，`sum(wall[i])` 应当是相同的
- `1 <= wall[i][j] <= 2^31 - 1`

## 解题思路

这道题的核心思想是：**找到穿过最少砖块的垂线 = 找到经过最多砖块边缘的垂线**。

关键观察：
1. 垂线穿过的砖块数 = 总行数 - 经过的砖块边缘数
2. 要使穿过的砖块数最少，需要让经过的边缘数最多
3. 不能在墙的最左边和最右边画线

算法思路：
1. 统计每个位置（从左边开始的距离）有多少条砖块边缘
2. 找到边缘数最多的位置
3. 返回 `总行数 - 最多边缘数`

实现方法：
- 使用哈希表记录每个位置的边缘数量
- 遍历每一行，累加砖块宽度，记录每个边缘位置
- 注意不要统计最右边的边缘（墙的右边界）

## Java 代码实现

### 方法一：哈希表统计边缘（推荐）⭐

```java
import java.util.*;

class Solution {
    public int leastBricks(List<List<Integer>> wall) {
        // 使用哈希表统计每个位置的砖块边缘数量
        Map<Integer, Integer> edgeCount = new HashMap<>();

        for (List<Integer> row : wall) {
            int position = 0;
            // 遍历每一块砖（不包括最后一块，因为不能在墙的右边界画线）
            for (int i = 0; i < row.size() - 1; i++) {
                position += row.get(i);
                edgeCount.put(position, edgeCount.getOrDefault(position, 0) + 1);
            }
        }

        // 如果没有任何边缘（所有行都只有一块砖），返回总行数
        if (edgeCount.isEmpty()) return wall.size();

        // 最多边缘数
        int maxEdges = Collections.max(edgeCount.values());

        // 穿过的砖块数 = 总行数 - 最多边缘数
        return wall.size() - maxEdges;
    }
}
```

### 方法二：简化版本

```java
import java.util.*;

class Solution {
    public int leastBricks(List<List<Integer>> wall) {
        // 更简洁的实现
        Map<Integer, Integer> edgeCount = new HashMap<>();

        for (List<Integer> row : wall) {
            int position = 0;
            // 累加宽度，统计边缘位置（不包括最后一块砖）
            for (int i = 0; i < row.size() - 1; i++) {
                position += row.get(i);
                edgeCount.merge(position, 1, Integer::sum);
            }
        }

        // maxEdges = 0 表示没有边缘（所有行都只有一块砖）
        int maxEdges = 0;
        for (int cnt : edgeCount.values()) {
            maxEdges = Math.max(maxEdges, cnt);
        }

        return wall.size() - maxEdges;
    }
}
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n × m)，其中 n 是墙的行数，m 是每行平均的砖块数量。需要遍历所有砖块。
- **空间复杂度**：O(w)，其中 w 是墙的总宽度。哈希表最多存储 w 个不同的边缘位置。

## 图解示例

以示例 1 为例：
```
wall = [[1,2,2,1],
        [3,1,2],
        [1,3,2],
        [2,4],
        [3,1,2],
        [1,3,1,1]]
```

统计边缘位置：
```
行1: [1,2,2,1] -> 边缘位置: 1, 3, 5
行2: [3,1,2]   -> 边缘位置: 3, 4
行3: [1,3,2]   -> 边缘位置: 1, 4
行4: [2,4]     -> 边缘位置: 2
行5: [3,1,2]   -> 边缘位置: 3, 4
行6: [1,3,1,1] -> 边缘位置: 1, 4, 5
```

边缘统计：
```
位置 1: 3 条边缘
位置 2: 1 条边缘
位置 3: 3 条边缘
位置 4: 4 条边缘 ⭐（最多）
位置 5: 2 条边缘
```

在位置 4 画线，经过 4 条边缘，穿过 6 - 4 = 2 块砖。

## 关键点总结

1. **问题转化**：穿过最少砖块 = 经过最多边缘
2. **哈希表应用**：统计每个位置的边缘数量
3. **边界处理**：不统计墙的右边界（每行最后一块砖的右边）
4. **累加计算**：通过累加宽度得到每个边缘的位置
5. **结果计算**：`总行数 - 最多边缘数`

## 易错点

1. **右边界问题**：
   - 不能在墙的右边界画线
   - 遍历时不包括每行的最后一块砖：`i < row.size() - 1`
2. **空边缘情况**：
   - 当所有行都只有一块砖时，`edgeCount` 为空
   - 需要特判返回 `wall.size()`
3. **位置计算**：
   - 使用累加和计算位置，不是砖块的索引
4. **理解题意**：
   - "经过边缘"不算穿过砖块
   - 要求的是穿过的砖块数，不是边缘数
5. **数据范围**：
   - 砖块宽度可能很大（2^31-1），位置累加时注意使用 int 是否溢出
