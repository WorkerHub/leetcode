## 题目描述

给你一个整数数组 `nums`，从中选出若干个不相邻元素（任意两个选出的元素在原数组中不相邻），使其总和最小，返回该最小不相邻元素和。

## Java 代码实现

```java
class Solution {
    public long minNonAdjacentSum(int[] nums) {
        int n = nums.length;
        // dpSkip = 不选当前元素时的最小和
        // dpPick = 选当前元素时的最小和
        long dpSkip = 0;
        long dpPick = nums[0];

        for (int i = 1; i < n; i++) {
            long newSkip = Math.min(dpSkip, dpPick); // 不选 i，前一个随意
            long newPick = dpSkip + nums[i];          // 选 i，前一个必须不选
            dpSkip = newSkip;
            dpPick = newPick;
        }

        // 最终取选或不选当前元素的最小值
        return Math.min(dpSkip, dpPick);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)，滚动数组

## 关键点总结

1. 打家劫舍的最小化版本：最大值改为最小值，取 min 代替 max。
2. 空间优化：只需保留前一个状态，O(1) 空间。
3. 最终答案取 `min(skip, pick)` 而不是强制选某个。
