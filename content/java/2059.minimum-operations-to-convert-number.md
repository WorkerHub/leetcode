## 题目描述

给定整数数组 `nums`、起始值 `start` 和目标值 `goal`，每次可从 nums 中选数 x 对当前值做 +x/-x/^x 操作（中间值须在 [0,1000]），返回从 start 到 goal 的最少操作次数。

## 解题思路

BFS 最短路：从 start 出发，枚举所有操作，若结果等于 goal 返回步数，若在 [0,1000] 内且未访问则入队。

## Java 代码实现

### 方法一：BFS（推荐）

```java
import java.util.*;

class Solution {
    public int minimumOperations(int[] nums, int start, int goal) {
        if (start == goal) return 0;
        boolean[] visited = new boolean[1001];
        visited[start] = true;
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            while (size-- > 0) {
                int val = queue.poll();
                for (int x : nums) {
                    int[] nexts = {val + x, val - x, val ^ x};
                    for (int nv : nexts) {
                        if (nv == goal) return steps;
                        if (nv >= 0 && nv <= 1000 && !visited[nv]) {
                            visited[nv] = true;
                            queue.offer(nv);
                        }
                    }
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1001 * |nums|)
- 空间复杂度：O(1001)

## 关键点总结

1. BFS 保证最少操作次数
2. 检查 `nv == goal` 须在范围检查之前（goal 可能超出 [0,1000]）
3. 中间值超出范围则跳过
