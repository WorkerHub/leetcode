## 题目描述

给你一个无向星型图（n 个节点，n-1 条边），返回中心节点。

## 解题思路

中心节点连接所有其他节点，必然同时出现在任意两条边中。只需检查前两条边的公共节点即可。

## Java 代码实现

```java
class Solution {
    public int findCenter(int[][] edges) {
        // 中心节点必然出现在前两条边中
        int a = edges[0][0], b = edges[0][1];
        int c = edges[1][0];
        // 若 a 出现在第二条边则为中心，否则 b 是中心
        return (a == c || a == edges[1][1]) ? a : b;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 中心节点出现在所有边中，必然是前两条边的公共节点
