## 题目描述

火车车厢s[i]='1'含违禁品，可从左/右端删（代价1）或单独删违禁车厢（代价2），求移除所有违禁品的最小时间。

## 解题思路

DP：left[i]=处理s[0..i]的最小代价，right[i]=处理s[i..n-1]的最小代价。对违禁车厢：left[i]=min(i+1, left[i-1]+2)。枚举分割点取最小。

## Java 代码实现

```java
class Solution {
    public int minimumTime(String s) {
        int n = s.length();
        
        // left[i]: 处理s[0..i]的最小代价
        int[] left = new int[n];
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') {
                left[i] = i > 0 ? left[i - 1] : 0;
            } else {
                int prev = i > 0 ? left[i - 1] : 0;
                left[i] = Math.min(i + 1, prev + 2);
            }
        }
        
        // right[i]: 处理s[i..n-1]的最小代价
        int[] right = new int[n];
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '0') {
                right[i] = i < n - 1 ? right[i + 1] : 0;
            } else {
                int nxt = i < n - 1 ? right[i + 1] : 0;
                right[i] = Math.min(n - i, nxt + 2);
            }
        }
        
        // 枚举分割点
        int ans = Math.min(left[n - 1], right[0]);
        for (int i = 0; i < n - 1; i++) {
            ans = Math.min(ans, left[i] + right[i + 1]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **三种策略**：从左端删到i（代价i+1）、从右端删到i（代价n-i）、单独删（代价2）
2. **递推关系**：left[i]=min(i+1, left[i-1]+2)
3. **枚举分割点**：左边用left处理，右边用right处理
