## 题目描述

给定 `n` 个节点的无向图，将节点分成尽可能多的组使得每条边连接的两节点属于相邻组（编号差 1），返回最多分组数，若存在奇数环返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int magnificentSets(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        int[] color = new int[n + 1];
        Arrays.fill(color, -1);
        int ans = 0;

        for (int i = 1; i <= n; i++) {
            if (color[i] != -1) continue;
            // BFS 二着色，同时收集连通分量
            List<Integer> comp = new ArrayList<>();
            Queue<Integer> q = new LinkedList<>();
            q.offer(i);
            color[i] = 0;
            while (!q.isEmpty()) {
                int u = q.poll();
                comp.add(u);
                for (int v : graph.get(u)) {
                    if (color[v] == -1) {
                        color[v] = 1 - color[u];
                        q.offer(v);
                    } else if (color[v] == color[u]) {
                        return -1;  // 奇数环
                    }
                }
            }
            // 对分量内每个节点做 BFS，取最大深度
            int maxGroups = 0;
            for (int src : comp) {
                maxGroups = Math.max(maxGroups, bfsDepth(src, n, graph));
            }
            ans += maxGroups;
        }
        return ans;
    }

    private int bfsDepth(int src, int n, List<List<Integer>> graph) {
        int[] dist = new int[n + 1];
        Arrays.fill(dist, -1);
        dist[src] = 0;
        Queue<Integer> q = new LinkedList<>();
        q.offer(src);
        int maxD = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : graph.get(u)) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    maxD = Math.max(maxD, dist[v]);
                    q.offer(v);
                }
            }
        }
        return maxD + 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * (n + E))，每个节点做一次 BFS
- 空间复杂度：O(n + E)

## 关键点总结

1. 奇数环（非二部图）直接返回 -1，用 BFS 二着色检测
2. 每个连通分量独立计算，答案为分量最大 BFS 深度
3. 各分量的最大深度（分组数）累加得到总答案
