## 题目描述

给你二进制字符串 s 和正整数 k，返回 s 中含恰好 k 个 1 的最短子字符串；若有多个等长的，返回字典序最小的；不存在则返回空字符串。

## 解题思路

枚举所有起点 i，向右扩展统计 1 的个数，一旦恰好等于 k 则记录当前子串，超过 k 则提前退出内层循环。最终从所有候选中取最短且字典序最小的。

## Java 代码实现

```java
class Solution {
    public String shortestBeautifulSubstring(String s, int k) {
        int n = s.length();
        String best = "";
        int minLen = n + 1;

        for (int i = 0; i < n; i++) {
            int ones = 0;
            for (int j = i; j < n; j++) {
                if (s.charAt(j) == '1') ones++;
                if (ones == k) {
                    // 当前子串 s[i..j] 恰好含 k 个 1
                    int len = j - i + 1;
                    String sub = s.substring(i, j + 1);
                    if (len < minLen || (len == minLen && sub.compareTo(best) < 0)) {
                        minLen = len;
                        best = sub;
                    }
                } else if (ones > k) {
                    break; // 超过 k 个 1，无需继续扩展
                }
            }
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，枚举所有子字符串
- **空间复杂度**：O(n)，存储当前最优子串

## 关键点总结

1. 最短美丽子字符串两端必须都是 1，否则可以去掉端部的 0 使其更短
2. 相同长度时用 `compareTo` 比较字典序
3. 1 的个数超过 k 时可提前退出内层循环
