## 题目描述

给定 0/1 数组 `nums`，对相邻元素反复执行 AND 或 OR 操作直到只剩一个元素，返回可能得到的最大值和最小值 `[max, min]`。

## Java 代码实现

```java
class Solution {
    public int[] minMaxAfterOperations(int[] nums) {
        int ones = 0;
        for (int x : nums) ones += x;
        // OR 具有扩散性：有1则最终可得1
        int maxVal = ones > 0 ? 1 : 0;
        // AND 具有收敛性：有0则最终可得0
        int minVal = ones == nums.length ? 1 : 0;
        return new int[]{maxVal, minVal};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. OR 操作具有扩散性：只要有一个 1，最终可得 1
2. AND 操作具有收敛性：只要有一个 0，最终可得 0
3. 无需模拟具体操作过程，直接统计 1 的个数判断
