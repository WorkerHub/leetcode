## 题目描述

重新设计9键手机键盘分配字母，使输入字符串s的总按键次数最少。

## 解题思路

贪心：按字母频次降序排列，最高频的9个字母各占一键第1位（按1次），次9个占第2位（按2次），以此类推。

## Java 代码实现

```java
class Solution {
    public int minimumKeypresses(String s) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        // 降序排列
        Integer[] freqs = new Integer[26];
        for (int i = 0; i < 26; i++) freqs[i] = freq[i];
        Arrays.sort(freqs, Collections.reverseOrder());

        int ans = 0;
        for (int i = 0; i < 26; i++) {
            if (freqs[i] == 0) break;
            ans += freqs[i] * (i / 9 + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + 26 log 26) = O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心**：高频字母放在按键次数少的位置
2. **9个键**：第i个字母(0-indexed)按键次数为i/9+1
3. **频次降序**：保证总按键最少
