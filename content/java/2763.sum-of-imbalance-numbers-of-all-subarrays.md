## 题目描述

一个数组的不平衡数字是排序后相邻元素差 > 1 的对数，给你整数数组 `nums`，返回所有子数组不平衡数字的总和。

## Java 代码实现

```java
import java.util.TreeMap;

class Solution {
    public int sumImbalanceNumbers(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int l = 0; l < n; l++) {
            // TreeMap 维护有序集合（值 -> 计数）
            TreeMap<Integer, Integer> tm = new TreeMap<>();
            int imbalance = 0;
            for (int r = l; r < n; r++) {
                int x = nums[r];
                if (!tm.containsKey(x)) {
                    // 仅在新值插入时更新不平衡数
                    Integer prev = tm.floorKey(x - 1);
                    Integer next = tm.ceilingKey(x + 1);
                    if (prev != null && x - prev > 1) imbalance++;
                    if (next != null && next - x > 1) imbalance++;
                    // 若 x 填补了 prev 和 next 之间的间隙
                    if (prev != null && next != null && next - prev > 1) imbalance--;
                }
                tm.merge(x, 1, Integer::sum);
                total += imbalance;
            }
        }
        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 log n)
- 空间复杂度：O(n)

## 关键点总结

1. 对每个左端固定，动态维护有序集合
2. 每次插入新元素时增量更新不平衡数
3. 插入元素可能填补间隙（减少不平衡），也可能产生新间隙（增加不平衡）
