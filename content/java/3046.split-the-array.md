## 题目描述

给你一个长度为偶数的整数数组 `nums`，判断是否可以将其分成两个长度相等且各自无重复元素的数组。

## 解题思路

若所有元素出现次数均不超过 2，则可以成功分割（各出现一次分到两个数组）；否则不可能。

## Java 代码实现

```java
class Solution {
    public boolean isPossibleToSplit(int[] nums) {
        // 统计每个元素出现次数
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }
        // 若任意元素出现超过 2 次，则无法分割
        for (int v : freq.values()) {
            if (v > 2) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每个元素最多出现 2 次，各放一个到两个数组，两个数组内均无重复
2. 若某元素出现 >= 3 次，不可能实现（鸽巢原理）
3. 不需要实际构造两个数组，只需判断频率是否 <= 2
