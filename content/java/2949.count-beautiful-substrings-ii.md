## 题目描述

给你字符串 `s`（长度最大 5×10⁴）和正整数 `k`，统计元音数等于辅音数且乘积能被 `k` 整除的子字符串数目。

## 解题思路

设子串长度为 2m，条件等价于 m² % k == 0。找最小正整数 p 满足 p² % k == 0，所有合法 m 均为 p 的倍数，子串长度为 2p 的倍数。用前缀差（元音+1，辅音-1）+ 哈希表，key = (前缀值, 下标 % 2p)，key 相同的两位置之间的子串满足条件。

## Java 代码实现

```java
class Solution {
    public long beautifulSubstrings(String s, int k) {
        Set<Character> vowels = Set.of('a', 'e', 'i', 'o', 'u');
        int n = s.length();

        // 求最小 p 使得 p^2 % k == 0
        int p = 1;
        while ((long) p * p % k != 0) p++;
        int period = 2 * p;

        // key 编码：prefix 范围 [-n, n]，mod 范围 [0, period)
        Map<Long, Integer> cnt = new HashMap<>();
        long prefix = 0;
        long ans = 0;
        cnt.put(encode(0, 0, period), 1); // 空前缀初始化

        for (int i = 1; i <= n; i++) {
            prefix += vowels.contains(s.charAt(i - 1)) ? 1 : -1;
            long key = encode(prefix, i % period, period);
            ans += cnt.getOrDefault(key, 0);
            cnt.merge(key, 1, Integer::sum);
        }
        return ans;
    }

    private long encode(long prefix, int mod, int period) {
        // prefix 偏移保证非负，乘以足够大的数避免冲突
        return (prefix + 100000L) * (period + 1) + mod;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + √k)
- **空间复杂度**：O(n)

## 关键点总结

1. 最小有效周期 p：满足 p² % k == 0 的最小正整数，p <= k
2. 子串长度必须是 2p 的倍数，通过下标模 2p 限制
3. 哈希表 key 同时包含前缀值和下标模值，key 相同则两位置间子串满足条件
