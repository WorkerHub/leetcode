## 题目描述

现在你总共有 `numCourses` 门课需要选，记为 `0` 到 `numCourses - 1`。给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]`，表示在选修课程 `ai` 前必须先选修 `bi`。

- 例如，想要学习课程 `0`，你需要先完成课程 `1`，我们用一个匹配来表示：`[0,1]`。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回**任意一种**就可以了。如果不可能完成所有课程，返回一个**空数组**。

**示例 1：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]
解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1]。
```

**示例 2：**
```
输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,2,1,3]
解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。
因此，一个正确的课程顺序是 [0,1,2,3]。另一个正确的排序是 [0,2,1,3]。
```

**示例 3：**
```
输入：numCourses = 1, prerequisites = []
输出：[0]
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `ai != bi`
- 所有`[ai, bi]` **互不相同**

## 解题思路

这道题是 [207. 课程表](https://leetcode.com/problems/course-schedule/) 的进阶版，不仅要判断能否完成，还要**返回一个合法的学习顺序**。

### 问题建模

1. **有向图**：课程是节点，`[a, b]` 表示边 `b → a`
2. **拓扑排序**：找到有向无环图（DAG）的拓扑序列
3. **有环检测**：如果有环，无法完成所有课程

### 拓扑排序的定义

对于有向无环图（DAG），**拓扑排序**是所有节点的一个线性排序，满足：
- 如果存在边 `u → v`，那么 `u` 在排序中出现在 `v` 之前

### 解决方案

1. **BFS（Kahn 算法）**：基于入度的广度优先搜索 ⭐
2. **DFS**：深度优先搜索，后序遍历

## Java 代码实现

### 方法一：BFS 拓扑排序（Kahn 算法）推荐⭐

```java
import java.util.*;

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        // 1. 构建图和入度数组
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[numCourses];  // 入度数组
        
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        
        for (int[] pre : prerequisites) {
            int course = pre[0];
            int prereq = pre[1];
            graph.get(prereq).add(course);  // prereq -> course
            inDegree[course]++;
        }
        
        // 2. 将所有入度为 0 的节点加入队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        // 3. BFS 拓扑排序
        int[] order = new int[numCourses];  // 存储拓扑排序结果
        int index = 0;
        
        while (!queue.isEmpty()) {
            int course = queue.poll();
            order[index++] = course;  // 加入结果
            
            // 处理所有依赖当前课程的课程
            for (int nextCourse : graph.get(course)) {
                inDegree[nextCourse]--;
                // 入度变为 0，加入队列
                if (inDegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }
        
        // 4. 检查是否所有课程都被访问
        // 如果有环，部分节点的入度永远不会为 0
        if (index == numCourses) {
            return order;
        } else {
            return new int[0];  // 有环，无法完成，返回空数组
        }
    }
}
```

**算法思路**：
1. **构建图**：邻接表 + 入度数组
2. **初始化队列**：所有入度为 0 的节点（无前置依赖）
3. **BFS 过程**：
   - 取出节点，加入结果
   - 将后继节点的入度减 1
   - 入度变为 0 的节点加入队列
4. **检查结果**：如果结果长度等于课程数，说明无环

**为什么是拓扑序？**
- 入度为 0 的节点没有前置依赖，可以直接学习
- 处理完一个节点，它的后继节点的依赖减少
- 当后继节点的所有前置依赖都处理完，入度变为 0，可以学习

### 方法二：DFS 拓扑排序⭐

```java
import java.util.*;

class Solution {
    private int[] visited;
    private List<List<Integer>> graph;
    private int[] order;
    private int index;
    private boolean hasCycle;
    
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        // 1. 构建图
        graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] pre : prerequisites) {
            graph.get(pre[1]).add(pre[0]);
        }
        
        // 2. 初始化
        visited = new int[numCourses];  // 0=未访问, 1=访问中, 2=已完成
        order = new int[numCourses];
        index = numCourses - 1;  // 从末尾开始填充（后序遍历逆序）
        hasCycle = false;
        
        // 3. 对每个未访问的节点进行 DFS
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0) {
                dfs(i);
            }
        }
        
        return hasCycle ? new int[0] : order;
    }
    
    private void dfs(int course) {
        if (hasCycle) return;  // 已发现环，提前退出
        
        // 标记为「访问中」
        visited[course] = 1;
        
        // 递归访问所有后继节点
        for (int nextCourse : graph.get(course)) {
            if (visited[nextCourse] == 0) {
                dfs(nextCourse);
            } else if (visited[nextCourse] == 1) {
                // 访问到「访问中」的节点，有环
                hasCycle = true;
                return;
            }
        }
        
        // 标记为「已完成」
        visited[course] = 2;
        // 后序位置加入结果（从末尾向前填充，相当于逆序）
        order[index--] = course;
    }
}
```

**算法思路**：
- **DFS 后序遍历**：在递归返回前加入结果
- **为什么从末尾填充？**
  - DFS 后序遍历得到的是**逆拓扑序**
  - 通过从末尾向前填充，直接得到正确的拓扑序
  - 等价于先收集后序结果再反转

**关键理解**：
```
如果有边 A → B，DFS(A) 会先递归 DFS(B)
B 先加入 order（填到末尾位置），A 后加入
从前往后：[A, B, ...]，正确的拓扑序
```

### 方法三：BFS 优化版

```java
import java.util.*;

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        int[][] graph = new int[numCourses][];
        int[] inDegree = new int[numCourses];
        
        // 先统计出度，用于构建邻接表
        int[] outDegree = new int[numCourses];
        for (int[] pre : prerequisites) {
            outDegree[pre[1]]++;
            inDegree[pre[0]]++;
        }
        for (int i = 0; i < numCourses; i++) {
            graph[i] = new int[outDegree[i]];
            outDegree[i] = 0;  // 重置，用作填充指针
        }
        for (int[] pre : prerequisites) {
            graph[pre[1]][outDegree[pre[1]]++] = pre[0];
        }
        
        // BFS
        int[] queue = new int[numCourses];
        int head = 0, tail = 0;
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue[tail++] = i;
            }
        }
        
        int[] order = new int[numCourses];
        int index = 0;
        while (head < tail) {
            int course = queue[head++];
            order[index++] = course;
            for (int nextCourse : graph[course]) {
                if (--inDegree[nextCourse] == 0) {
                    queue[tail++] = nextCourse;
                }
            }
        }
        
        return index == numCourses ? order : new int[0];
    }
}
```

**优化说明**：
- 使用数组模拟队列，避免 LinkedList 的额外开销
- 性能更优，适合追求极致性能的场景

## 复杂度分析

### 方法一、三：BFS
- **时间复杂度**：O(V + E)
  - V 是课程数（节点数）
  - E 是依赖关系数（边数）
- **空间复杂度**：O(V + E)
  - 邻接表：O(E)
  - 入度数组：O(V)
  - 队列：O(V)

### 方法二：DFS
- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V + E)
  - 递归栈：O(V)

## 关键点总结

1. **拓扑排序应用**：有向无环图的线性排序
2. **两种实现**：
   - BFS（Kahn 算法）：基于入度，更直观
   - DFS：后序遍历，需要反转结果
3. **环检测**：
   - BFS：结果长度 < 节点数
   - DFS：访问到「访问中」的节点
4. **多个答案**：拓扑排序可能有多个合法结果
5. **与 207 题对比**：207 只判断能否完成，210 要返回顺序

## 易错点

1. **边的方向**：`[a, b]` 表示 `b → a`，容易搞反

2. **DFS 结果需要反转或逆序填充**：
   - 后序遍历是逆拓扑序
   - 忘记处理顺序会导致结果错误

3. **环检测遗漏**：
   ```java
   // 错误：直接返回 order，没检查是否有环
   return order;
   
   // 正确：检查长度
   return index == numCourses ? order : new int[0];
   ```

4. **返回类型**：Java 返回空数组用 `new int[0]`，不是 `null`

5. **DFS 状态错误**：
   - 忘记标记「访问中」
   - 忘记标记「已完成」
