## 题目描述

设计一个敲击计数器，用来统计过去 5 分钟内被敲击次数。

你的系统应该接受一个时间戳参数（以秒为单位），并且你可以假定对系统的调用是按时间顺序进行的（即时间戳是单调递增的）。几次敲击可能同时发生。

实现 `HitCounter` 类：

- `HitCounter()` 初始化敲击计数器对象
- `void hit(int timestamp)` 记录在时间戳 `timestamp` 发生的一次敲击（以秒为单位）
- `int getHits(int timestamp)` 返回在过去 5 分钟内（即从 `timestamp - 300` 到 `timestamp`，包括两端）的敲击次数

**示例 1：**

```
输入：
["HitCounter", "hit", "hit", "hit", "getHits", "hit", "getHits", "getHits"]
[[], [1], [2], [3], [4], [300], [300], [301]]

输出：
[null, null, null, null, 3, null, 4, 3]

解释：
HitCounter hitCounter = new HitCounter();
hitCounter.hit(1);       // 在时间戳 1 敲击
hitCounter.hit(2);       // 在时间戳 2 敲击
hitCounter.hit(3);       // 在时间戳 3 敲击
hitCounter.getHits(4);   // 在时间戳 4 统计，应返回 3
hitCounter.hit(300);     // 在时间戳 300 敲击
hitCounter.getHits(300); // 在时间戳 300 统计，应返回 4
hitCounter.getHits(301); // 在时间戳 301 统计，应返回 3（时间戳 1 已过期）
```

**提示：**
- `1 <= timestamp <= 2 * 10^9`
- 所有对系统的调用都是按时间顺序进行的（时间戳严格递增）
- `hit` 和 `getHits` 的调用次数总计不超过 `300`

**进阶：**
如果每秒的敲击次数是一个很大的数字，你的设计能应对吗？

## 解题思路

这是一个滑动窗口问题，窗口大小固定为 300 秒。关键点：
1. 需要记录每次敲击的时间戳
2. 查询时只统计最近 300 秒内的敲击
3. 时间戳是单调递增的

### 核心思想

**方法一：队列**
- 使用队列存储每次敲击的时间戳
- `getHits` 时移除超过 300 秒的旧记录
- 返回队列长度

**方法二：循环数组（针对进阶问题）**
- 将 300 秒映射到固定大小的数组（300 个位置）
- 每个位置记录该秒的敲击次数和时间戳
- 节省空间，适合高频敲击

## Java 代码实现

### 方法一：队列（推荐，简单直观）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class HitCounter {
    private Deque<Integer> hits;  // 存储所有敲击的时间戳

    /** 初始化计数器，使用队列存储时间戳 */
    public HitCounter() {
        hits = new ArrayDeque<>();
    }

    /**
     * 记录一次敲击
     * 时间复杂度：O(1)
     */
    public void hit(int timestamp) {
        hits.offerLast(timestamp);
    }

    /**
     * 获取过去 300 秒内的敲击次数
     * 时间复杂度：O(n)，n 为过期的敲击数
     */
    public int getHits(int timestamp) {
        // 移除超过 300 秒的旧记录
        while (!hits.isEmpty() && hits.peekFirst() <= timestamp - 300) {
            hits.pollFirst();
        }
        return hits.size();
    }
}
```

### 方法二：循环数组（进阶，空间优化）

```java
class HitCounter {
    private int[] times;    // 记录每个位置最后更新的时间戳
    private int[] hitCount; // 记录每个位置的敲击次数

    /** 使用固定大小的数组，每个位置对应一秒 */
    public HitCounter() {
        times    = new int[300];
        hitCount = new int[300];
    }

    /**
     * 记录一次敲击
     * 时间复杂度：O(1)
     */
    public void hit(int timestamp) {
        int idx = timestamp % 300;  // 使用取模映射到数组索引

        // 如果这个位置的时间戳已过期，重置计数
        if (times[idx] != timestamp) {
            times[idx]    = timestamp;
            hitCount[idx] = 1;
        } else {
            // 同一秒内的多次敲击，累加
            hitCount[idx]++;
        }
    }

    /**
     * 获取过去 300 秒内的敲击次数
     * 时间复杂度：O(300) = O(1)
     */
    public int getHits(int timestamp) {
        int total = 0;
        for (int i = 0; i < 300; i++) {
            // 只统计未过期的敲击
            if (timestamp - times[i] < 300) {
                total += hitCount[i];
            }
        }
        return total;
    }
}
```

### 方法三：哈希表（另一种实现）

```java
import java.util.HashMap;
import java.util.Iterator;
import java.util.Map;

class HitCounter {
    private Map<Integer, Integer> counter;  // 记录每个时间戳的敲击次数

    /** 使用哈希表记录每个时间戳的敲击次数 */
    public HitCounter() {
        counter = new HashMap<>();
    }

    /**
     * 记录一次敲击
     * 时间复杂度：O(1)
     */
    public void hit(int timestamp) {
        counter.put(timestamp, counter.getOrDefault(timestamp, 0) + 1);
    }

    /**
     * 获取过去 300 秒内的敲击次数
     * 时间复杂度：O(k)，k 为不同时间戳的数量
     */
    public int getHits(int timestamp) {
        int total = 0;
        // 遍历哈希表，统计有效时间戳的敲击数
        Iterator<Map.Entry<Integer, Integer>> it = counter.entrySet().iterator();
        while (it.hasNext()) {
            Map.Entry<Integer, Integer> entry = it.next();
            if (timestamp - entry.getKey() < 300) {
                total += entry.getValue();
            } else {
                // 删除过期的时间戳以节省空间
                it.remove();
            }
        }
        return total;
    }
}
```

## 复杂度分析

### 方法一：队列
- `hit`：时间 O(1)，空间 O(1)
- `getHits`：时间 O(n)，n 为需要移除的过期敲击数
- 空间复杂度：O(H)，H 为 300 秒内的总敲击数

### 方法二：循环数组
- `hit`：时间 O(1)，空间 O(1)
- `getHits`：时间 O(300) = O(1)
- 空间复杂度：O(300) = O(1)，固定空间

### 方法三：哈希表
- `hit`：时间 O(1)，空间 O(1)
- `getHits`：时间 O(k)，k 为不同时间戳的数量
- 空间复杂度：O(k)

## 关键点总结

1. **滑动窗口**：维护一个 300 秒的滑动时间窗口
2. **单调性**：利用时间戳单调递增的特性优化
3. **空间权衡**：方法一空间随敲击数增长，方法二固定空间
4. **进阶优化**：高频敲击时，方法二的循环数组更优
5. **及时清理**：定期清理过期数据可以节省空间

## 易错点

1. **时间范围**：是 `[timestamp - 300, timestamp]`，注意边界
2. **索引计算**：循环数组使用 `timestamp % 300` 映射
3. **重置条件**：循环数组中，时间戳不同时要重置计数
4. **空队列判断**：使用队列时要检查是否为空
5. **同一秒多次敲击**：要累加而不是覆盖
