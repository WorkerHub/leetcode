## 题目描述

给你整数数组 `hours`，返回满足 `(hours[i] + hours[j]) % 24 == 0`（i < j）的数对数量。

## 解题思路

对每个 h，只关心 `h % 24` 的余数 r，需要找之前余数为 `(24 - r) % 24` 的元素。用大小为 24 的数组统计余数出现次数。

## Java 代码实现

```java
class Solution {
    public int countCompleteDayPairs(int[] hours) {
        int[] cnt = new int[24]; // 统计各余数出现次数
        int ans = 0;
        for (int h : hours) {
            int r = h % 24;
            int need = (24 - r) % 24; // 需要的互补余数
            ans += cnt[need];
            cnt[r]++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（固定 24 个桶）

## 关键点总结

1. 只需对 24 取模，用固定大小数组而非哈希表
2. 每次先查再更新，避免自身配对
3. `(24 - r) % 24` 处理 r=0 时互补余数为 0 的情况
