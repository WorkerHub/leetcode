## 题目描述

给定字符串 `s`，每次操作可替换任意字符，返回使字符串变为回文串的最少替换次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(String s) {
        int ops = 0;
        int n = s.length();
        // 双指针：统计不匹配的对称字符对数
        for (int i = 0; i < n / 2; i++) {
            if (s.charAt(i) != s.charAt(n - 1 - i)) ops++;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 回文要求 `s[i] == s[n-1-i]`，每对不匹配恰好需要 1 次替换
2. 奇数长度中间字符不需要操作
3. 每对只需替换一个字符（改左或改右均可）
