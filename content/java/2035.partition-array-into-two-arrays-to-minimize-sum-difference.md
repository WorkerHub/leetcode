## 题目描述

给定长度为 2n 的整数数组，将其分为两组各 n 个元素，使两组元素之和的差的绝对值最小，返回该最小值。

## 解题思路

折半枚举（Meet in the Middle）：将数组分为左右两半各 n 个，枚举左半所有子集按选取数量 k 分组存储可能的和；右半同理，对每个 k 将 right_sums[n-k] 排序后二分查找最接近 `total/2 - ls` 的值，取差绝对值最小。

## Java 代码实现

### 方法一：折半枚举 + 二分查找（推荐）

```java
import java.util.*;

class Solution {
    public int minimumDifference(int[] nums) {
        int n = nums.length / 2;
        long total = 0;
        for (int x : nums) total += x;

        // left_sums[k] = 从左半选k个元素的所有可能和
        List<List<Long>> leftSums = new ArrayList<>();
        List<List<Long>> rightSums = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            leftSums.add(new ArrayList<>());
            rightSums.add(new ArrayList<>());
        }

        for (int mask = 0; mask < (1 << n); mask++) {
            int k = Integer.bitCount(mask);
            long s = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) s += nums[i];
            }
            leftSums.get(k).add(s);
        }
        for (int mask = 0; mask < (1 << n); mask++) {
            int k = Integer.bitCount(mask);
            long s = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) s += nums[n + i];
            }
            rightSums.get(k).add(s);
        }

        for (int k = 0; k <= n; k++) {
            Collections.sort(rightSums.get(k));
        }

        long ans = Long.MAX_VALUE;
        for (int k = 0; k <= n; k++) {
            List<Long> rs = rightSums.get(n - k);
            for (long ls : leftSums.get(k)) {
                // 二分查找最接近 total/2 - ls 的值
                long need = total - 2 * ls; // 等价于找 ls+rs 最接近 total/2
                // 找 rs 中最接近 need/2 的值
                int lo = 0, hi = rs.size() - 1;
                int pos = Collections.binarySearch(rs, total / 2 - ls);
                if (pos < 0) pos = -pos - 1;
                for (int p = pos - 1; p <= pos; p++) {
                    if (p >= 0 && p < rs.size()) {
                        long diff = Math.abs(2 * (ls + rs.get(p)) - total);
                        ans = Math.min(ans, diff);
                    }
                }
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 2^n)
- 空间复杂度：O(n * 2^n)

## 关键点总结

1. 折半枚举将时间从 O(2^(2n)) 降为 O(n * 2^n)，n <= 15 可接受
2. 左半选 k 个，右半必须选 n-k 个
3. 目标差 `|2*(ls+rs) - total|`，二分查找相邻两个候选值取最小
