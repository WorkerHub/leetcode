## 题目描述

给你字符串数组 `words` 和字符 `separator`，对每个字符串按 `separator` 分割，将所有非空分割结果收集到新数组中返回。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<String> splitWordsBySeparator(List<String> words, char separator) {
        List<String> ans = new ArrayList<>();
        String sep = String.valueOf(separator);
        for (String word : words) {
            // split 后过滤空字符串
            for (String part : word.split(java.util.regex.Pattern.quote(sep), -1)) {
                if (!part.isEmpty()) ans.add(part);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为字符串数，L 为平均长度
- 空间复杂度：O(n * L)

## 关键点总结

1. `split` 产生的空字符串需要过滤
2. 传入 `-1` 作为第二参数保留末尾空串（再过滤掉）
3. 使用 `Pattern.quote` 转义特殊字符（如 `.`、`$`）
