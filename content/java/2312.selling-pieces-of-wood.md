## 题目描述

将m*n木块切割出售获得最大收益，可水平或垂直切割。

## 解题思路

区间DP：dp[h][w]为h*w木块最大价值。枚举水平切割位置和垂直切割位置取最大。

## Java 代码实现

```java
class Solution {
    public long sellingWood(int m, int n, int[][] prices) {
        long[][] dp = new long[m + 1][n + 1];
        // 初始化可直接出售的价格
        for (int[] p : prices) {
            dp[p[0]][p[1]] = Math.max(dp[p[0]][p[1]], p[2]);
        }

        for (int h = 1; h <= m; h++) {
            for (int w = 1; w <= n; w++) {
                // 水平切割
                for (int i = 1; i < h; i++) {
                    dp[h][w] = Math.max(dp[h][w], dp[i][w] + dp[h - i][w]);
                }
                // 垂直切割
                for (int j = 1; j < w; j++) {
                    dp[h][w] = Math.max(dp[h][w], dp[h][j] + dp[h][w - j]);
                }
            }
        }
        return dp[m][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N * (M + N))
- **空间复杂度**：O(M * N)

## 关键点总结

1. **dp[h][w]包含三种选择**：直接出售、水平切、垂直切
2. **自底向上递推**：从小尺寸到大尺寸
3. **初始化出售价格**：同尺寸取最大价格
