## 题目描述

有一个 `m x n` 的二元网格 `grid`，其中 `1` 表示砖块，`0` 表示空白。砖块 **稳定**（不会掉落）的前提是：
- 砖块直接连接到网格的顶部，或者
- 至少有一块相邻（4 个方向之一）砖块 **稳定** 不会掉落时

给你一个数组 `hits`，这是需要依次消除砖块的位置。每当消除 `hits[i] = (rowi, coli)` 位置上的砖块时，对应位置的砖块（若存在）会消失，然后其他的砖块可能因为这一消除操作而 **掉落**。

返回一个数组 `result`，其中 `result[i]` 表示第 `i` 次消除操作对应掉落的砖块数目。

**注意**：消除可能指向是没有砖块的空白位置，如果发生这种情况，则没有砖块掉落。

**示例 1:**
```
输入: grid = [[1,0,0,0],[1,1,1,0]], hits = [[1,0]]
输出: [2]
解释: 网格开始为:
[[1,0,0,0],
 [1,1,1,0]]
消除 (1,0) 处的砖块，得到网格:
[[1,0,0,0],
 [0,1,1,0]]
两个砖块不再稳定，因为它们不再与顶部相连，也不再与另一个稳定的砖块相连，因此它们将掉落。
得到的网格为:
[[1,0,0,0],
 [0,0,0,0]]
因此，结果为 [2]。
```

**示例 2:**
```
输入: grid = [[1,0,0,0],[1,1,0,0]], hits = [[1,1],[1,0]]
输出: [0,0]
```

**提示:**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `grid[i][j]` 为 `0` 或 `1`
- `1 <= hits.length <= 4 * 10^4`
- `hits[i].length == 2`
- `0 <= xi <= m - 1`
- `0 <= yi <= n - 1`
- 所有 `(xi, yi)` 互不相同

## 解题思路

这是一道经典的**逆向思维 + 并查集**问题。

**核心思想**：
- 正向模拟每次敲击很困难，因为需要检查大量砖块是否掉落
- **逆向思考**：从最终状态开始，倒序添加砖块，计算每次添加砖块导致多少砖块重新稳定

**算法流程**：

1. **预处理**：先把所有要敲击的砖块标记为消除（设为 2）
2. **构建最终状态的并查集**：
   - 创建一个虚拟节点代表"顶部"
   - 将所有稳定的砖块连接到并查集中
   - 第一行的砖块连接到虚拟顶部节点
3. **逆序恢复砖块**：
   - 从后往前遍历 hits 数组
   - 每次恢复一个砖块，检查与顶部连接的砖块数量变化
   - 变化量 - 1 就是因为这次敲击掉落的砖块数

**关键点**：
- 使用并查集维护连通性和大小
- 虚拟节点技巧：添加一个额外节点代表顶部
- 逆向思维：从结果倒推原因

## Java 代码实现

### 方法一：并查集 + 逆向思维（推荐）

```java
import java.util.*;

class Solution {
    int[] parent;
    int[] size;

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }

    private void union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return;
        // 将 y 合并到 x
        parent[rootY] = rootX;
        size[rootX] += size[rootY];
    }

    private int getSize(int x) {
        return size[find(x)];
    }

    public int[] hitBricks(int[][] grid, int[][] hits) {
        int m = grid.length, n = grid[0].length;

        // 复制网格，标记要敲击的位置
        int[][] status = new int[m][n];
        for (int i = 0; i < m; i++) {
            status[i] = grid[i].clone();
        }
        for (int[] hit : hits) {
            status[hit[0]][hit[1]] = 0;
        }

        // 创建并查集，额外增加一个虚拟顶部节点
        int roof = m * n;
        parent = new int[m * n + 1];
        size = new int[m * n + 1];
        for (int i = 0; i <= m * n; i++) {
            parent[i] = i;
            size[i] = 1;
        }

        // 将所有剩余的砖块加入并查集
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (status[i][j] == 1) {
                    // 第一行连接到虚拟顶部
                    if (i == 0) {
                        union(i * n + j, roof);
                    }
                    // 连接上方砖块
                    if (i > 0 && status[i-1][j] == 1) {
                        union(i * n + j, (i-1) * n + j);
                    }
                    // 连接左方砖块
                    if (j > 0 && status[i][j-1] == 1) {
                        union(i * n + j, i * n + (j-1));
                    }
                }
            }
        }

        // 四个方向
        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        int[] result = new int[hits.length];

        // 逆序恢复砖块
        for (int k = hits.length - 1; k >= 0; k--) {
            int r = hits[k][0], c = hits[k][1];

            // 如果原来就没有砖块，掉落数为 0
            if (grid[r][c] == 0) {
                result[k] = 0;
                continue;
            }

            // 记录恢复前与顶部连接的砖块数
            int prevSize = getSize(roof);

            // 恢复砖块
            status[r][c] = 1;

            // 第一行连接到虚拟顶部
            if (r == 0) {
                union(r * n + c, roof);
            }

            // 连接四个方向的砖块
            for (int[] dir : directions) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && status[nr][nc] == 1) {
                    union(r * n + c, nr * n + nc);
                }
            }

            // 记录恢复后与顶部连接的砖块数
            int currSize = getSize(roof);

            // 掉落的砖块数 = 增加的砖块数 - 1（减去当前恢复的砖块）
            result[k] = Math.max(0, currSize - prevSize - 1);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n + k × α(m × n))，其中 k 是 hits 的长度，α 是阿克曼函数的反函数
- **空间复杂度**：O(m × n)，并查集和复制的网格

## 关键点总结

1. **逆向思维**：从结果倒推，添加砖块比移除砖块更容易计算
2. **虚拟节点技巧**：用一个额外节点代表顶部，简化判断
3. **并查集维护连通性**：高效地查询和合并连通块
4. **大小追踪**：并查集需要维护每个集合的大小
5. **边界处理**：原本就没有砖块的位置，掉落数为 0

## 易错点

1. **忘记检查原网格**：hits 位置原本可能没有砖块
2. **结果顺序**：逆序处理后需要按原始顺序输出
3. **掉落数计算**：要减去当前恢复的砖块本身（-1）
4. **虚拟节点大小**：初始大小应该为 1
5. **并查集实现**：需要同时维护 parent 和 size
