## 题目描述

给你严格递增的石头位置数组 `stones`，青蛙从首石到末石再返回首石，每块中间石最多踩一次，返回最小化最大跳跃距离。

## 解题思路

最优策略是两条路径交替使用石头（一条用奇数位置，一条用偶数位置），因此答案为所有「隔一跳」的最大距离，即 `max(stones[i] - stones[i-2])`，同时考虑首步 `stones[1] - stones[0]`。

## Java 代码实现

```java
class Solution {
    public int maxJump(int[] stones) {
        int ans = stones[1] - stones[0]; // 首步两条路径均需经过
        for (int i = 2; i < stones.length; i++) {
            ans = Math.max(ans, stones[i] - stones[i - 2]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 两条路径交替使用石头是最优策略
2. 每条路径实际上是隔一个石头跳一次，最大跳跃 = `max(stones[i] - stones[i-2])`
3. 首尾石头两条路径共享，首步距离单独处理
