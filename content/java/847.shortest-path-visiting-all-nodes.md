## 题目描述

给定无向连通图（n 个节点），返回能够访问所有节点的最短路径长度。可以从任意节点出发，可以重复访问节点和边。

**示例：**
```
输入：graph = [[1,2,3],[0],[0],[0]]
输出：4
```

## 解题思路

BFS + 状态压缩：用位掩码表示已访问节点集合，状态为 (当前节点, 访问掩码)，BFS 求最短路径。

## Java 代码实现

```java
class Solution {
    public int shortestPathLength(int[][] graph) {
        int n = graph.length;
        int target = (1 << n) - 1;

        // BFS：(节点, 状态)
        Queue<int[]> queue = new LinkedList<>();
        boolean[][] visited = new boolean[n][1 << n];

        for (int i = 0; i < n; i++) {
            queue.offer(new int[]{i, 1 << i, 0});
            visited[i][1 << i] = true;
        }

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int node = curr[0], state = curr[1], dist = curr[2];

            if (state == target) return dist;

            for (int neighbor : graph[node]) {
                int nextState = state | (1 << neighbor);
                if (!visited[neighbor][nextState]) {
                    visited[neighbor][nextState] = true;
                    queue.offer(new int[]{neighbor, nextState, dist + 1});
                }
            }
        }
        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × 2^n)
- **空间复杂度**：O(n × 2^n)

## 关键点总结

1. **状态压缩**：位掩码表示已访问节点
2. **多源 BFS**：每个节点都可作为起点
3. **去重**：(节点, 掩码) 对唯一性
