## 题目描述

给定一个非空的字符串 s，检查是否可以通过由它的一个子串重复多次构成。

**示例 1:**

```
输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成。
```

**示例 2:**

```
输入: s = "aba"
输出: false
```

**示例 3:**

```
输入: s = "abcabcabcabc"
输出: true
解释: 可由子串 "abc" 重复四次构成 (或子串 "abcabc" 重复两次构成)。
```

**提示:**

- 1 <= s.length <= 10^4
- s 由小写英文字母组成

## 解题思路

**方法一：枚举所有可能的周期长度**
- 周期长度必须是字符串长度的因数
- 检查每个可能的周期

**方法二：拼接字符串技巧**
- 如果 s 由重复子串构成，则 s+s 中必然包含 s（除了首尾）
- 检查 (s+s) 去掉首尾字符后是否包含 s

## Java 代码实现

### 方法一：枚举周期（推荐）

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        // 枚举所有可能的周期长度
        // 时间复杂度: O(n * sqrt(n))
        // 空间复杂度: O(n)
        int n = s.length();

        // 周期长度最多是 n/2
        for (int i = 1; i <= n / 2; i++) {
            // 周期长度必须是 n 的因数
            if (n % i == 0) {
                String pattern = s.substring(0, i);
                // 检查是否由该模式重复构成
                StringBuilder sb = new StringBuilder();
                int repeat = n / i;
                for (int j = 0; j < repeat; j++) {
                    sb.append(pattern);
                }
                if (sb.toString().equals(s)) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

### 方法二：拼接字符串技巧

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        // 字符串拼接技巧
        // 时间复杂度: O(n)
        // 空间复杂度: O(n)

        // s+s 中间部分（去掉首尾各一个字符）是否包含 s
        String doubled = s + s;
        String middle = doubled.substring(1, doubled.length() - 1);
        return middle.contains(s);
    }
}
```

### 方法三：KMP 算法

```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        // KMP 算法
        // 时间复杂度: O(n)
        // 空间复杂度: O(n)
        int n = s.length();
        if (n == 0) {
            return false;
        }

        // 构建 next（部分匹配表）数组
        int[] next = new int[n];
        int j = 0;

        for (int i = 1; i < n; i++) {
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = next[j - 1];
            }
            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }
            next[i] = j;
        }

        // 如果 next[n-1] != 0 且长度是周期的整数倍
        return next[n - 1] != 0 && n % (n - next[n - 1]) == 0;
    }
}
```
