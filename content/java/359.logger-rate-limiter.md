## 题目描述

请你设计一个日志系统，可以流式接收消息以及它的时间戳。每条不重复的消息最多只能每 10 秒打印一次。也就是说，如果在时间戳 `t` 打印某条消息，那么相同的消息直到时间戳变为 `t + 10` 之前都不会被打印。

所有消息都按时间顺序发送。多条消息可能到达同一时间戳。

实现 `Logger` 类：

- `Logger()` 初始化 `logger` 对象
- `bool shouldPrintMessage(int timestamp, string message)` 如果这条消息 `message` 在给定的时间戳 `timestamp` 应该被打印出来，则返回 `true`，否则请返回 `false`。

**示例：**
```
输入：
["Logger", "shouldPrintMessage", "shouldPrintMessage", "shouldPrintMessage", "shouldPrintMessage", "shouldPrintMessage", "shouldPrintMessage"]
[[], [1, "foo"], [2, "bar"], [3, "foo"], [8, "bar"], [10, "foo"], [11, "foo"]]
输出：
[null, true, true, false, false, false, true]

解释：
Logger logger = new Logger();
logger.shouldPrintMessage(1, "foo");  // 返回 true，打印 "foo"
logger.shouldPrintMessage(2, "bar");  // 返回 true，打印 "bar"
logger.shouldPrintMessage(3, "foo");  // 返回 false，"foo" 在时间戳 1 打印过，下次可打印时间戳是 1 + 10 = 11
logger.shouldPrintMessage(8, "bar");  // 返回 false，"bar" 在时间戳 2 打印过，下次可打印时间戳是 2 + 10 = 12
logger.shouldPrintMessage(10, "foo"); // 返回 false，"foo" 下次可打印时间戳是 11
logger.shouldPrintMessage(11, "foo"); // 返回 true，时间戳 11 >= 11，可以打印
```

**提示：**
- `0 <= timestamp <= 10^9`
- 每个 `timestamp` 都将按非递减顺序（时间顺序）传递
- `1 <= message.length <= 30`
- 最多调用 `10^4` 次 `shouldPrintMessage` 方法

## 解题思路

这是一个简单的设计题，核心是记录每条消息最后打印的时间。

**核心思想：**
- 使用哈希表记录 {消息: 最后打印时间}
- 新消息到来时，检查是否过了 10 秒

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Logger {
    // 记录每条消息最后打印的时间
    private Map<String, Integer> messageTime;

    public Logger() {
        messageTime = new HashMap<>();
    }

    public boolean shouldPrintMessage(int timestamp, String message) {
        // 如果消息未打印过，或者距离上次打印已达 10 秒
        if (!messageTime.containsKey(message) || timestamp >= messageTime.get(message) + 10) {
            messageTime.put(message, timestamp);
            return true;
        }

        return false;
    }
}
```

**时间复杂度：** O(1)
**空间复杂度：** O(M)，M 为不同消息的数量

## 关键点总结

1. **哈希表**：记录消息和时间的映射
2. **时间判断**：timestamp >= last_time + 10
3. **更新时间**：只在返回 true 时更新

## 易错点

1. **边界条件**：timestamp == last_time + 10 应该返回 true（使用 `>=` 而非 `>`）
2. **更新时机**：只在允许打印时更新时间
3. **字符串比较**：Java 中用 `equals()` 比较字符串，HashMap 的 `containsKey` 已正确处理
