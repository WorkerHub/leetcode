## 题目描述

给你整数数组 nums，找满足 `i<j<k`、`nums[i]<nums[j]`、`nums[j]>nums[k]` 的山形三元组，返回 `nums[i]+nums[j]+nums[k]` 的最小值，不存在则返回 -1。数组长度 ≤ 10^5，需要 O(n) 解法。

## 解题思路

预处理后缀最小值数组 `suffMin[j]`（j 右侧不含 j 的最小值），再一次正向遍历维护前缀最小值 `prefMin`（j 左侧不含 j 的最小值）。若 `prefMin < nums[j]` 且 `suffMin[j] < nums[j]`，则 `prefMin + nums[j] + suffMin[j]` 是一个候选答案。

## Java 代码实现

```java
class Solution {
    public int minimumSum(int[] nums) {
        int n = nums.length;
        int[] suffMin = new int[n];
        suffMin[n - 1] = Integer.MAX_VALUE;
        // 预处理后缀最小值（不含 j 本身）
        for (int j = n - 2; j >= 0; j--) {
            suffMin[j] = Math.min(suffMin[j + 1], nums[j + 1]);
        }

        int ans = Integer.MAX_VALUE;
        int prefMin = Integer.MAX_VALUE; // 当前 j 左侧的最小值
        for (int j = 0; j < n; j++) {
            // 检查 j 能否作为山峰
            if (prefMin < nums[j] && suffMin[j] < nums[j]) {
                ans = Math.min(ans, prefMin + nums[j] + suffMin[j]);
            }
            // 更新前缀最小值
            prefMin = Math.min(prefMin, nums[j]);
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，两次线性扫描
- **空间复杂度**：O(n)，后缀最小值数组

## 关键点总结

1. 最小化总和：贪心地取左侧最小值和右侧最小值
2. 前缀最小值可在线维护（单变量），节省一次遍历
3. 山形条件：左最小 < nums[j] 且 右最小 < nums[j]，缺一不可
