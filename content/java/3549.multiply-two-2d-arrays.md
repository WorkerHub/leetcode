## 题目描述

给定两个稀疏矩阵 `mat1`（`m x k`）和 `mat2`（`k x n`），计算它们的矩阵乘积 `mat1 x mat2`，返回 `m x n` 的结果矩阵，利用稀疏性跳过零元素。

## 解题思路

标准矩阵乘法，利用稀疏性优化：遍历 mat1 时跳过零元素，只对非零的 `mat1[i][p]` 遍历 mat2 的第 p 行，累加乘积到结果矩阵。

## Java 代码实现

```java
class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int m = mat1.length, k = mat1[0].length, n = mat2[0].length;
        int[][] result = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int p = 0; p < k; p++) {
                if (mat1[i][p] == 0) continue; // 跳过零元素
                for (int j = 0; j < n; j++) {
                    if (mat2[p][j] != 0) {
                        result[i][j] += mat1[i][p] * mat2[p][j];
                    }
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * k * n)（最坏），O(非零元素数量）（稀疏情况）
- 空间复杂度：O(m * n)，结果矩阵

## 关键点总结

1. 稀疏矩阵优化：跳过零元素的乘法
2. 枚举中间维度 k，对非零的 mat1[i][p] 才遍历 mat2 第 p 行
3. 结果矩阵初始化为全零，累加非零乘积
