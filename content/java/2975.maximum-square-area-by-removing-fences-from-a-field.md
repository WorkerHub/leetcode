## 题目描述

给你 m×n 田地，有横向和纵向栅栏，可移除任意栅栏，返回能形成的最大正方形面积（对 10^9+7 取模），无法形成则返回 -1。

## 解题思路

枚举水平方向所有线对（含边界 0 和 m）的距离存入集合，再枚举垂直方向所有线对的距离，找两集合的最大公共距离 d，面积为 d²。

## Java 代码实现

```java
class Solution {
    public long maximizeSquareArea(int m, int n, int[] hFences, int[] vFences) {
        final long MOD = 1_000_000_007;
        Set<Long> hGaps = getGaps(hFences, m);
        Set<Long> vGaps = getGaps(vFences, n);

        long best = -1;
        for (long d : hGaps) {
            if (vGaps.contains(d)) best = Math.max(best, d);
        }
        return best == -1 ? -1 : best % MOD * (best % MOD) % MOD;
    }

    private Set<Long> getGaps(int[] fences, int boundary) {
        int[] lines = new int[fences.length + 2];
        lines[0] = 0;
        for (int i = 0; i < fences.length; i++) lines[i + 1] = fences[i];
        lines[lines.length - 1] = boundary;
        Arrays.sort(lines);

        Set<Long> gaps = new HashSet<>();
        for (int i = 0; i < lines.length; i++)
            for (int j = i + 1; j < lines.length; j++)
                gaps.add((long) lines[j] - lines[i]);
        return gaps;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(H² + V²)，H、V 最大约 600
- **空间复杂度**：O(H² + V²)

## 关键点总结

1. 边界 0 和 m（或 n）必须加入线集合
2. 枚举所有线对距离，用集合求最大公共距离
3. 面积 d² 可能溢出，计算时需对 MOD 取模
