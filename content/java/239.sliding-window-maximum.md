## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

**示例 1：**
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2：**
```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

这道题要求在滑动窗口中快速找到最大值，关键是如何高效维护窗口最大值。

**朴素方法：**
- 每次窗口移动，遍历窗口内所有元素找最大值
- 时间复杂度：O(n * k)，会超时

**优化思路：单调队列**

使用双端队列（Deque）维护一个单调递减的序列：
- 队首始终是当前窗口的最大值
- 队列中存储的是元素的**索引**（不是值）

**单调队列的维护规则：**

1. **入队**：新元素从队尾入队前，移除所有比它小的元素
2. **出队**：如果队首元素已经不在窗口内，移除队首
3. **查询**：队首元素就是当前窗口的最大值

**为什么存储索引？**
- 需要判断元素是否还在窗口内
- 通过索引可以快速判断

**为什么单调递减？**
- 如果新元素大于队尾元素，队尾元素永远不可能是最大值
- 可以直接移除，保持队列单调性

## Java 代码实现

### 方法一：单调队列（推荐）⭐

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 使用单调递减队列
        // 时间复杂度：O(n)
        // 空间复杂度：O(k)
        if (nums == null || nums.length == 0 || k == 0) {
            return new int[0];
        }

        int n = nums.length;
        // 双端队列，存储元素索引，保持对应值单调递减
        Deque<Integer> dq = new ArrayDeque<>();
        int[] result = new int[n - k + 1];
        int idx = 0;

        for (int i = 0; i < n; i++) {
            // 1. 移除队首过期的元素（不在窗口内）
            if (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
                dq.pollFirst();
            }

            // 2. 移除队尾所有小于当前元素的元素
            // 保持队列单调递减
            while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
                dq.pollLast();
            }

            // 3. 当前元素索引入队
            dq.offerLast(i);

            // 4. 如果窗口已经形成（i >= k-1），记录最大值
            if (i >= k - 1) {
                result[idx++] = nums[dq.peekFirst()];
            }
        }

        return result;
    }
}
```

### 方法二：单调队列（详细注释版）

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 单调队列详解版本
        int n = nums.length;
        Deque<Integer> dq = new ArrayDeque<>(); // 存储索引
        int[] result = new int[n - k + 1];
        int idx = 0;

        for (int i = 0; i < n; i++) {
            // 维护窗口大小：移除队首不在窗口内的元素
            // 窗口范围：[i - k + 1, i]
            while (!dq.isEmpty() && dq.peekFirst() < i - k + 1) {
                dq.pollFirst();
            }

            // 维护单调性：移除队尾小于当前值的元素
            // 因为它们不可能成为最大值
            while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
                dq.pollLast();
            }

            // 当前元素入队
            dq.offerLast(i);

            // 窗口形成后，记录结果
            // 队首元素就是当前窗口最大值的索引
            if (i >= k - 1) {
                result[idx++] = nums[dq.peekFirst()];
            }
        }

        return result;
    }
}
```

### 方法三：大顶堆（优先队列）

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 使用大顶堆（优先队列）
        // 时间复杂度：O(n log n)
        // 空间复杂度：O(n)
        int n = nums.length;
        int[] result = new int[n - k + 1];

        // 大顶堆：存储 (值, 索引) 对，按值降序
        PriorityQueue<int[]> heap = new PriorityQueue<>(
            (a, b) -> b[0] - a[0]
        );

        for (int i = 0; i < n; i++) {
            // 元素入堆
            heap.offer(new int[]{nums[i], i});

            // 如果窗口已经形成
            if (i >= k - 1) {
                // 移除不在窗口内的元素（懒删除）
                while (heap.peek()[1] < i - k + 1) {
                    heap.poll();
                }
                // 堆顶元素就是最大值
                result[i - k + 1] = heap.peek()[0];
            }
        }

        return result;
    }
}
```

### 方法四：暴力法（仅用于理解，会超时）

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 暴力方法：每次遍历窗口找最大值
        // 时间复杂度：O(n * k)
        int n = nums.length;
        int[] result = new int[n - k + 1];

        for (int i = 0; i <= n - k; i++) {
            // 找到窗口 [i, i+k) 的最大值
            int windowMax = nums[i];
            for (int j = i + 1; j < i + k; j++) {
                windowMax = Math.max(windowMax, nums[j]);
            }
            result[i] = windowMax;
        }

        return result;
    }
}
```

## 复杂度分析

**方法一（单调队列）：**
- 时间复杂度：O(n)，每个元素最多入队、出队一次
- 空间复杂度：O(k)，队列最多存储 k 个元素

**方法三（大顶堆）：**
- 时间复杂度：O(n log n)，每次入堆、出堆操作是 O(log n)
- 空间复杂度：O(n)，堆可能存储所有元素

**方法四（暴力法）：**
- 时间复杂度：O(n * k)
- 空间复杂度：O(1)

## 关键点总结

1. **单调队列**：维护单调递减序列，队首是最大值
2. **存储索引**：通过索引判断元素是否在窗口内
3. **双端操作**：队首出队（过期元素），队尾出队（维护单调性）
4. **O(n) 时间**：每个元素最多入队、出队一次
5. **Deque 使用**：Java 的 `ArrayDeque` 提供 O(1) 的两端操作

## 易错点

1. **窗口边界判断**：
   ```java
   // 窗口范围是 [i - k + 1, i]
   if (!dq.isEmpty() && dq.peekFirst() < i - k + 1)  // 正确
   if (!dq.isEmpty() && dq.peekFirst() <= i - k)      // 也正确
   if (!dq.isEmpty() && dq.peekFirst() < i - k)       // 错误
   ```

2. **结果记录时机**：
   ```java
   // 只有窗口形成后才记录
   if (i >= k - 1)  // 正确
   if (i >= k)      // 错误，会少记录一个
   ```

3. **队列存储的是索引**：
   ```java
   dq.offerLast(i);               // 正确
   dq.offerLast(nums[i]);         // 错误
   result[idx++] = nums[dq.peekFirst()]; // 正确
   result[idx++] = dq.peekFirst();       // 错误
   ```

4. **比较时用值，判断时用索引**：
   ```java
   // 比较值
   while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i])
   // 判断索引
   if (!dq.isEmpty() && dq.peekFirst() < i - k + 1)
   ```

5. **单调递减 vs 递增**：
   - 求最大值用单调递减队列
   - 求最小值用单调递增队列

6. **Java Deque API**：
   - `offerFirst/offerLast`：两端入队
   - `pollFirst/pollLast`：两端出队
   - `peekFirst/peekLast`：两端查看
