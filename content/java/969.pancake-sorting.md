## 题目描述

通过煎饼翻转（翻转前 k 个元素）对数组排序，返回操作序列中的 k 值。

**示例：**
```
输入：[3,2,4,1]
输出：[4,2,4,3]
```

## 解题思路

贪心：从大到小排序。每次找最大值位置，先翻到首位，再翻到目标位置。

## Java 代码实现

```java
class Solution {
    public List<Integer> pancakeSort(int[] arr) {
        List<Integer> result = new ArrayList<>();
        int n = arr.length;

        for (int target = n; target > 0; target--) {
            // 找到目标值位置
            int idx = 0;
            for (int i = 0; i < target; i++) {
                if (arr[i] == target) { idx = i; break; }
            }

            if (idx == target - 1) continue; // 已在正确位置

            // 翻到首位
            if (idx != 0) {
                flip(arr, idx + 1);
                result.add(idx + 1);
            }
            // 翻到目标位置
            flip(arr, target);
            result.add(target);
        }

        return result;
    }

    private void flip(int[] arr, int k) {
        int left = 0, right = k - 1;
        while (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **两次翻转**：先翻到首位，再翻到目标位置
2. **从大到小**：每次处理当前最大值
3. **跳过优化**：已在正确位置时不操作
