## 题目描述

有效 IP 地址正好由四个整数（每个整数位于 `0` 到 `255` 之间组成，且不能含有前导 `0`），整数之间用 `'.'` 分隔。

例如：`"0.1.2.201"` 和 `"192.168.1.1"` 是有效 IP 地址，但是 `"0.011.255.245"`、`"192.168.1.312"` 和 `"192.168@1.1"` 是无效 IP 地址。

给定一个只包含数字的字符串 `s`，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在 `s` 中插入 `'.'` 来形成。你不能重新排序或删除 `s` 中的任何数字。你可以按任何顺序返回答案。

**示例 1：**
```
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]
```

**示例 2：**
```
输入：s = "0000"
输出：["0.0.0.0"]
```

**示例 3：**
```
输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
```

**提示：**
- `1 <= s.length <= 20`
- `s` 仅由数字组成

## 解题思路

**核心思想：回溯 + 剪枝**

IP 地址的约束条件：
1. 必须恰好有 4 段
2. 每段的值在 `[0, 255]` 之间
3. 每段不能有前导零（除了单独的 "0"）
4. 必须用完所有字符

**回溯框架：**
1. 选择：在当前位置后插入 `'.'`，分割出一段
2. 约束：每段长度 1-3，值在 0-255，无前导零
3. 目标：分成 4 段且用完所有字符

**剪枝优化：**
- 如果剩余字符太多或太少，无法组成剩余的段，提前返回
- 每段长度最多 3 位，最少 1 位

## Java 代码实现

### 方法一：回溯法（推荐）

```java
class Solution {
    private List<String> result = new ArrayList<>();

    public List<String> restoreIpAddresses(String s) {
        int n = s.length();
        // 长度检查：IP 地址最少 4 位（如 0.0.0.0），最多 12 位（如 255.255.255.255）
        if (n < 4 || n > 12) {
            return result;
        }
        backtrack(s, 0, new ArrayList<>());
        return result;
    }

    private void backtrack(String s, int start, List<String> path) {
        int n = s.length();

        // 递归终止条件
        if (path.size() == 4) {
            // 必须恰好用完所有字符
            if (start == n) {
                result.add(String.join(".", path));
            }
            return;
        }

        // 剪枝：剩余字符数量检查
        int remainSegments = 4 - path.size(); // 还需要几段
        int remainChars = n - start;          // 还剩几个字符

        // 剩余字符太少或太多都不行
        if (remainChars < remainSegments || remainChars > remainSegments * 3) {
            return;
        }

        // 尝试分割 1-3 位
        for (int length = 1; length <= 3; length++) {
            // 不能超出边界
            if (start + length > n) {
                break;
            }

            // 获取当前段
            String segment = s.substring(start, start + length);

            // 检查是否合法
            if (isValid(segment)) {
                // 选择当前段
                path.add(segment);
                // 递归处理剩余部分
                backtrack(s, start + length, path);
                // 撤销选择
                path.remove(path.size() - 1);
            }
        }
    }

    // 检查一段是否合法
    private boolean isValid(String segment) {
        // 检查前导零
        if (segment.length() > 1 && segment.charAt(0) == '0') {
            return false;
        }
        // 检查范围
        int val = Integer.parseInt(segment);
        return val >= 0 && val <= 255;
    }
}
```

### 方法二：迭代法（三层循环）

```java
class Solution {
    public List<String> restoreIpAddresses(String s) {
        List<String> result = new ArrayList<>();
        int n = s.length();

        if (n < 4 || n > 12) {
            return result;
        }

        // 尝试所有可能的分割点
        // i, j, k 分别是第一、二、三个点的位置
        for (int i = 1; i < Math.min(4, n - 2); i++) {          // 第一段：[0, i)
            for (int j = i + 1; j < Math.min(i + 4, n - 1); j++) { // 第二段：[i, j)
                for (int k = j + 1; k < Math.min(j + 4, n); k++) {  // 第三段：[j, k)
                    // 第四段：[k, n)
                    String seg1 = s.substring(0, i);
                    String seg2 = s.substring(i, j);
                    String seg3 = s.substring(j, k);
                    String seg4 = s.substring(k, n);

                    // 检查每段是否合法
                    if (isValid(seg1) && isValid(seg2) && isValid(seg3) && isValid(seg4)) {
                        result.add(seg1 + "." + seg2 + "." + seg3 + "." + seg4);
                    }
                }
            }
        }

        return result;
    }

    private boolean isValid(String segment) {
        if (segment == null || segment.length() == 0 || segment.length() > 3) {
            return false;
        }
        if (segment.length() > 1 && segment.charAt(0) == '0') {
            return false;
        }
        int val = Integer.parseInt(segment);
        return val >= 0 && val <= 255;
    }
}
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(3^4 × n) = O(n)，最多尝试 3^4 = 81 种分割方式，每次验证 O(1)
- 空间复杂度：O(n)，递归栈深度为 4，存储结果需要 O(n)

**方法二：**
- 时间复杂度：O(1)，三层循环固定次数（最多 3 × 3 × 3 = 27）
- 空间复杂度：O(1)，不考虑结果存储

## 关键点总结

1. **IP 地址规则**：4 段、每段 0-255、无前导零（除了 "0"）
2. **回溯三要素**：选择（分割 1-3 位）、约束（合法性检查）、目标（4 段且用完）
3. **剪枝优化**：检查剩余字符是否能组成剩余段数
4. **边界处理**：字符串长度必须在 [4, 12] 之间
5. **前导零判断**：长度 > 1 且首字符为 '0' 时非法

## 易错点

1. **前导零处理**：
   - "01" 是非法的（有前导零）
   - "0" 是合法的（单独的零）
   - "10" 是合法的（零不在开头）

2. **边界情况**：
   - 字符串长度不足 4 或超过 12，直接返回空
   - 每段最多 3 位数字

3. **剪枝条件**：
   - 剩余字符太少：`remainChars < remainSegments`
   - 剩余字符太多：`remainChars > remainSegments * 3`

4. **Java 字符串操作**：使用 `String.join(".", path)` 拼接结果

5. **结果格式**：用 `'.'` 连接四段，注意不要多余的点

   ```java
   void backtrack(int start, List<String> path) {
       if (满足条件) {
           记录结果;
           return;
       }
       if (剪枝条件) {
           return;
       }
       for (选择 : 选择列表) {
           if (合法) {
               做选择;
               backtrack(...);
               撤销选择;
           }
       }
   }
   ```
