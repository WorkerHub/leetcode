## 题目描述

给定两个字符串 `s` 和 `t`，它们只包含小写字母。

字符串 `t` 由字符串 `s` 随机重排，然后在随机位置添加一个字母。

请找出在 `t` 中被添加的字母。

**示例 1:**

```
输入：s = "abcd", t = "abcde"
输出："e"
解释：'e' 是那个被添加的字母。
```

**示例 2:**

```
输入：s = "", t = "y"
输出："y"
```

**提示:**

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` 和 `t` 只包含小写字母

## 解题思路

本题有多种巧妙的解法，从暴力到优雅。

### 核心思想

字符串 `t` 比 `s` 多一个字符，找出这个字符的方法：

1. **统计字符频次**：比较两个字符串中每个字符的出现次数
2. **排序比较**：排序后逐位比较
3. **求和相减**：ASCII 码求和后相减
4. **异或运算**：利用异或的性质（最优雅）⭐

### 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 哈希表 | O(n) | O(1) | 直观 |
| 排序 | O(n log n) | O(1) | 简单但慢 |
| 求和 | O(n) | O(1) | 巧妙 |
| 异或 | O(n) | O(1) | 最优雅 |

## Java 代码实现

### 方法一：异或运算（最优雅）⭐⭐⭐

```java
class Solution {
    public char findTheDifference(String s, String t) {
        /**
         * 利用异或运算的性质：
         * - a ^ a = 0
         * - a ^ 0 = a
         * - 异或满足交换律和结合律
         *
         * 将 s 和 t 的所有字符异或，相同的字符会抵消，剩下的就是多出的字符
         * 时间复杂度: O(n)
         * 空间复杂度: O(1)
         */
        int result = 0;

        // 对 s 中的所有字符进行异或
        for (char c : s.toCharArray()) {
            result ^= c;
        }

        // 对 t 中的所有字符进行异或
        for (char c : t.toCharArray()) {
            result ^= c;
        }

        return (char) result;
    }
}
```

### 方法二：求和相减（巧妙）⭐

```java
class Solution {
    public char findTheDifference(String s, String t) {
        /**
         * 利用 ASCII 码求和相减
         * t 的所有字符 ASCII 码之和 - s 的所有字符 ASCII 码之和 = 多出字符的 ASCII 码
         * 时间复杂度: O(n)
         * 空间复杂度: O(1)
         */
        int sumS = 0, sumT = 0;

        for (char c : s.toCharArray()) {
            sumS += c;
        }
        for (char c : t.toCharArray()) {
            sumT += c;
        }

        return (char) (sumT - sumS);
    }
}
```

### 方法三：数组计数

```java
class Solution {
    public char findTheDifference(String s, String t) {
        /**
         * 使用数组统计字符频次
         * 时间复杂度: O(n)
         * 空间复杂度: O(1) - 固定 26 个字母
         */
        int[] counts = new int[26];

        // 统计 t 中的字符
        for (char c : t.toCharArray()) {
            counts[c - 'a']++;
        }

        // 减去 s 中的字符
        for (char c : s.toCharArray()) {
            counts[c - 'a']--;
        }

        // 找到计数为 1 的字符
        for (int i = 0; i < 26; i++) {
            if (counts[i] == 1) {
                return (char) (i + 'a');
            }
        }

        return ' '; // 题目保证有答案，不会到这里
    }
}
```

### 方法四：排序比较

```java
import java.util.Arrays;

class Solution {
    public char findTheDifference(String s, String t) {
        /**
         * 排序后逐位比较
         * 时间复杂度: O(n log n)
         * 空间复杂度: O(n) - 需要额外空间存储字符数组
         */
        char[] sArr = s.toCharArray();
        char[] tArr = t.toCharArray();
        Arrays.sort(sArr);
        Arrays.sort(tArr);

        // 逐位比较
        for (int i = 0; i < sArr.length; i++) {
            if (sArr[i] != tArr[i]) {
                return tArr[i];
            }
        }

        // 如果前面都相同，说明多出的字符在最后
        return tArr[tArr.length - 1];
    }
}
```

## 复杂度分析

### 最优解（异或）

**时间复杂度：** O(n)
- 需要遍历两个字符串各一次
- 每个字符的异或操作是 O(1)

**空间复杂度：** O(1)
- 只使用一个整数变量存储异或结果

## 关键点总结

1. **异或的性质**：`a ^ a = 0`，`a ^ 0 = a`，相同的元素会抵消
2. **求和相减**：ASCII 码之差等于多出字符的 ASCII 码
3. **数组计数**：O(1) 空间，适合只有小写字母的场景
4. **位运算应用**：异或在查找唯一元素问题中非常有效
5. **类型转换**：Java 中 `(char) intValue` 将 int 转为 char

## 易错点

1. **空字符串情况**：s 可能为空，t 只有一个字符，需要处理
2. **返回类型**：返回 `char`，不是字符的 ASCII 整数值
3. **排序方法的边界**：多出的字符可能在任何位置（包括最后）
4. **异或的理解**：需要理解为什么异或可以找到唯一元素
5. **Java char 和 int**：`char ^= char` 的结果是 int，需要强制转换为 char

## 图解示例

### 异或运算过程

```
s = "abcd"
t = "abcde"

步骤 1: 对 s 中所有字符异或
result = 0
result ^= 'a'(97)  -> 97
result ^= 'b'(98)  -> 97 ^ 98 = 3
result ^= 'c'(99)  -> 3 ^ 99 = 96
result ^= 'd'(100) -> 96 ^ 100 = 4

步骤 2: 对 t 中所有字符异或
result ^= 'a'(97)  -> 4 ^ 97 = 101
result ^= 'b'(98)  -> 101 ^ 98 = 7
result ^= 'c'(99)  -> 7 ^ 99 = 100
result ^= 'd'(100) -> 100 ^ 100 = 0
result ^= 'e'(101) -> 0 ^ 101 = 101

步骤 3: 转换回字符
(char) 101 = 'e'

原理：s 和 t 的公共字符在异或中抵消，剩下的就是多出的 'e'
```

### 求和相减过程

```
s = "abcd"
sumS = 97 + 98 + 99 + 100 = 394

t = "abcde"
sumT = 97 + 98 + 99 + 100 + 101 = 495

diff = 495 - 394 = 101
(char) 101 = 'e'
```
