## 题目描述

给你整数数组 `nums` 和 `threshold`，找出满足以下条件的最长子数组的长度：第一个元素为偶数、相邻元素奇偶性交替、所有元素 <= threshold。

## Java 代码实现

```java
class Solution {
    public int longestAlternatingSubarray(int[] nums, int threshold) {
        int n = nums.length, ans = 0;
        int i = 0;
        while (i < n) {
            // 起点必须是偶数且 <= threshold
            if (nums[i] % 2 != 0 || nums[i] > threshold) { i++; continue; }
            int j = i + 1;
            // 向后延伸：奇偶交替且 <= threshold
            while (j < n && nums[j] <= threshold && nums[j] % 2 != nums[j - 1] % 2) j++;
            ans = Math.max(ans, j - i);
            i = j;  // 从 j 重新找新起点
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 起点必须是偶数
2. 相邻元素奇偶性不同（交替）
3. 所有元素 <= threshold
