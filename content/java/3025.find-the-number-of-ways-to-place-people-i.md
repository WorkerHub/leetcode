## 题目描述

给点集，Alice 选左上角点，Bob 选右下角点构成矩形（x1≤x2, y1≥y2），矩形内不含其他点，返回满足条件的 (Alice, Bob) 对数。

## 解题思路

排序后枚举所有对：按 x 升序、x 相同则 y 降序排列，固定 Alice(i)，遍历 Bob(j)，用最大 y2 记录检查矩形内是否有其他点插入。

## Java 代码实现

```java
class Solution {
    public int numberOfPairs(int[][] points) {
        // 按 x 升序，x 相同则 y 降序
        Arrays.sort(points, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);
        int n = points.length, ans = 0;
        for (int i = 0; i < n; i++) {
            int x1 = points[i][0], y1 = points[i][1];
            int maxY2 = Integer.MIN_VALUE;
            for (int j = i + 1; j < n; j++) {
                int x2 = points[j][0], y2 = points[j][1];
                if (y2 > y1) continue; // Bob 必须在 Alice 下方
                // 若 y2 > maxY2，说明矩形内没有其他点插入（y2 最高的 Bob）
                if (y2 > maxY2) {
                    maxY2 = y2;
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² )
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后枚举：固定 Alice，遍历 Bob 时维护最大 y2
2. y2 > maxY2 才合法：保证矩形内无其他点在 [y2,y1] 范围内
3. Alice 在左上（x1≤x2, y1≥y2）
