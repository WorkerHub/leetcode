## 题目描述

设计一个接收整数流的数据结构，该数据结构支持检查是否存在两数之和等于特定值。

实现 `TwoSum` 类：

- `TwoSum()` 初始化 `TwoSum` 对象
- `void add(int number)` 向数据结构中添加一个数 `number`
- `boolean find(int value)` 寻找数据结构中是否存在一对整数，使得两数之和等于给定的值 `value`。如果存在，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：
["TwoSum", "add", "add", "add", "find", "find"]
[[], [1], [3], [5], [4], [7]]
输出：
[null, null, null, null, true, false]

解释：
TwoSum twoSum = new TwoSum();
twoSum.add(1);   // [] --> [1]
twoSum.add(3);   // [1] --> [1,3]
twoSum.add(5);   // [1,3] --> [1,3,5]
twoSum.find(4);  // 1 + 3 = 4，返回 true
twoSum.find(7);  // 没有两个整数加和等于 7，返回 false
```

**提示：**
- -10^5 <= number <= 10^5
- -2^31 <= value <= 2^31 - 1
- 最多调用 10^4 次 `add` 和 `find`

## 解题思路

这是一个**数据结构设计**问题，需要在 `add` 和 `find` 操作之间做权衡。

**核心问题：** 优化 `add` 还是优化 `find`？

### 策略一：优化 add（哈希表计数）
- `add`：O(1)，直接存入哈希表
- `find`：O(n)，遍历哈希表查找配对

### 策略二：优化 find（预计算所有和）
- `add`：O(n)，更新所有可能的两数之和
- `find`：O(1)，直接查哈希表

**选择依据：**
- 如果 `add` 频繁，选策略一
- 如果 `find` 频繁，选策略二
- **通常选策略一**，因为实际场景中添加数据更频繁

## Java 代码实现

### 方法一：哈希表计数（推荐，优化 add）⭐

```java
class TwoSum {
    // 使用哈希表存储数字及其出现次数
    private Map<Integer, Integer> numCounts;

    public TwoSum() {
        numCounts = new HashMap<>();
    }

    public void add(int number) {
        // O(1) 时间添加
        numCounts.put(number, numCounts.getOrDefault(number, 0) + 1);
    }

    public boolean find(int value) {
        // O(n) 时间查找
        for (int num : numCounts.keySet()) {
            // 使用 long 避免溢出（value 可达 2^31-1，num 可达 10^5）
            long complement = (long) value - num;

            if (complement != num) {
                // 情况1：两个不同的数
                if (complement >= Integer.MIN_VALUE && complement <= Integer.MAX_VALUE
                        && numCounts.containsKey((int) complement)) {
                    return true;
                }
            } else {
                // 情况2：两个相同的数（需要至少出现2次）
                if (numCounts.get(num) > 1) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

### 方法二：列表存储 + 哈希集合查找

```java
class TwoSum {
    private List<Integer> nums;

    public TwoSum() {
        nums = new ArrayList<>();
    }

    public void add(int number) {
        // 直接添加到列表
        nums.add(number);
    }

    public boolean find(int value) {
        // 使用集合加速查找
        Set<Integer> numSet = new HashSet<>(nums);

        for (int num : nums) {
            long complement = (long) value - num;
            if (complement != num) {
                if (complement >= Integer.MIN_VALUE && complement <= Integer.MAX_VALUE
                        && numSet.contains((int) complement)) {
                    return true;
                }
            } else {
                // 相同数需要至少2个
                int count = 0;
                for (int n : nums) {
                    if (n == num) count++;
                    if (count >= 2) return true;
                }
            }
        }

        return false;
    }
}
```

### 方法三：预计算所有和（优化 find，不推荐）

```java
class TwoSum {
    private List<Integer> nums;
    private Set<Long> sums; // 存储所有可能的两数之和（用 long 避免溢出）

    public TwoSum() {
        nums = new ArrayList<>();
        sums = new HashSet<>();
    }

    public void add(int number) {
        // O(n) 时间，计算新数与已有数的所有和
        for (int num : nums) {
            sums.add((long) num + number);
        }
        nums.add(number);
    }

    public boolean find(int value) {
        // O(1) 时间查找
        return sums.contains((long) value);
    }
}
```

### 方法四：排序 + 双指针

```java
class TwoSum {
    private List<Integer> nums;

    public TwoSum() {
        nums = new ArrayList<>();
    }

    public void add(int number) {
        nums.add(number);
    }

    public boolean find(int value) {
        // 排序后使用双指针
        int[] arr = nums.stream().mapToInt(Integer::intValue).toArray();
        Arrays.sort(arr);

        int left = 0, right = arr.length - 1;

        while (left < right) {
            long currentSum = (long) arr[left] + arr[right];
            if (currentSum == value) {
                return true;
            } else if (currentSum < value) {
                left++;
            } else {
                right--;
            }
        }

        return false;
    }
}
```

## 复杂度分析

| 方法 | add 时间 | find 时间 | 空间复杂度 |
|------|---------|----------|-----------|
| 方法一（哈希表计数） | O(1) | O(n) | O(n) |
| 方法二（列表+集合） | O(1) | O(n) | O(n) |
| 方法三（预计算） | O(n) | O(1) | O(n²) |
| 方法四（排序双指针） | O(1) | O(n log n) | O(n) |

**推荐方法一**，因为：
- `add` 操作更频繁，O(1) 添加很重要
- `find` 的 O(n) 复杂度可接受
- 空间复杂度 O(n) 合理

## 关键点总结

1. **重复元素处理**：相同数字需要出现至少 2 次
2. **哈希表计数**：使用 `getOrDefault` 简化代码
3. **权衡选择**：根据操作频率选择优化策略
4. **边界情况**：空数据结构、单个元素
5. **避免自身配对**：`complement != num` 或检查计数 > 1

## 易错点

1. **重复数字判断错误**
   - 错误：直接 `numCounts.containsKey(complement)`（相同数时会误判）
   - 正确：分情况讨论，相同数需要 `count > 1`

2. **整数溢出**
   - `value` 可以到 `2^31 - 1`，`num` 可以到 `10^5`
   - `value - num` 可能溢出 int，需用 `long complement = (long) value - num`

3. **使用列表的陷阱**
   ```java
   // 错误：同一个元素会自己和自己配对
   for (int num : nums) {
       if (nums.contains(value - num)) return true;
   }
   // 需要额外处理相同元素的情况
   ```

4. **预计算方法的空间问题**
   - n 个数有 O(n²) 个两数之和，空间消耗大

5. **初始化遗漏**
   - 必须在构造函数中初始化数据结构
