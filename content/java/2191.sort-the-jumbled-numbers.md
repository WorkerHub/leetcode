## 题目描述

给定映射规则mapping[i]=j，将nums中每个数逐位映射后按映射值稳定排序。

## 解题思路

对每个数逐位提取并用mapping替换得到映射值，以映射值为key进行稳定排序。

## Java 代码实现

```java
class Solution {
    public int[] sortJumbled(int[] mapping, int[] nums) {
        int n = nums.length;
        int[][] arr = new int[n][2]; // [映射值, 原始下标]
        
        for (int i = 0; i < n; i++) {
            arr[i][0] = getMapped(nums[i], mapping);
            arr[i][1] = i;
        }
        
        // 稳定排序：映射值相同时按原始下标
        Arrays.sort(arr, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            result[i] = nums[arr[i][1]];
        }
        return result;
    }
    
    private int getMapped(int x, int[] mapping) {
        if (x == 0) return mapping[0];
        int result = 0, factor = 1;
        while (x > 0) {
            result += mapping[x % 10] * factor;
            factor *= 10;
            x /= 10;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * D * log N)，D为最大位数
- **空间复杂度**：O(N)

## 关键点总结

1. **逐位映射**：取每位数字用mapping替换再组合
2. **稳定排序**：映射值相同时保持原始顺序（用原始下标作第二排序键）
3. **x=0特殊处理**：不进入while循环，直接返回mapping[0]
