## 题目描述

将香槟倒入金字塔形杯塔顶部，满了溢出到下一行两个杯子。给定倒入量 poured、查询行 query_row 和列 query_glass，返回该杯中液面高度（0~1）。

**示例：**
```
输入：poured = 2, query_row = 1, query_glass = 1
输出：0.5
```

## 解题思路

模拟溢出过程：每个杯子超过 1 的部分平均分给下一行的左右两个杯子。

## Java 代码实现

```java
class Solution {
    public double champagneTower(int poured, int query_row, int query_glass) {
        double[][] tower = new double[query_row + 1][query_row + 2];
        tower[0][0] = poured;

        for (int i = 0; i < query_row; i++) {
            for (int j = 0; j <= i; j++) {
                if (tower[i][j] > 1) {
                    double overflow = tower[i][j] - 1;
                    tower[i][j] = 1;
                    tower[i + 1][j] += overflow / 2;
                    tower[i + 1][j + 1] += overflow / 2;
                }
            }
        }

        return Math.min(1.0, tower[query_row][query_glass]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(query_row²)
- **空间复杂度**：O(query_row²)

## 关键点总结

1. **模拟溢出**：超过 1 的部分均分给下方两个杯子
2. **逐行处理**：只需模拟到目标行
3. **结果截断**：最终结果不超过 1
