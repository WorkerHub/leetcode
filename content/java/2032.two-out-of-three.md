## 题目描述

给定三个整数数组 `nums1`、`nums2`、`nums3`，返回至少在其中两个数组中出现的所有不同整数（顺序任意）。

## 解题思路

对每个数组去重后统计每个值出现的数组次数，返回次数 >= 2 的值。

## Java 代码实现

### 方法一：哈希表计数（推荐）

```java
import java.util.*;

class Solution {
    public List<Integer> twoOutOfThree(int[] nums1, int[] nums2, int[] nums3) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int[] arr : new int[][]{nums1, nums2, nums3}) {
            Set<Integer> seen = new HashSet<>();
            for (int x : arr) {
                if (seen.add(x)) {  // 每个数组内去重
                    cnt.merge(x, 1, Integer::sum);
                }
            }
        }
        List<Integer> res = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            if (e.getValue() >= 2) res.add(e.getKey());
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n1 + n2 + n3)
- 空间复杂度：O(n1 + n2 + n3)

## 关键点总结

1. 每个数组先去重再计数，避免同一数组中同一值被多次统计
2. `seen.add(x)` 返回 false 表示已存在，用于去重判断
