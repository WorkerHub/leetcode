## 题目描述

n 个任务和 m 个工人，有 pills 颗药丸可使工人强度 +strength，每个工人最多一颗，返回能完成的最多任务数。

## 解题思路

二分答案 k，验证能否完成最简单的 k 个任务：取最强 k 个工人，从最难任务开始分配——最强工人能直接完成则分配之；否则找最弱的能吃药完成的工人分配（节省强工人），用 TreeMap 维护有序工人集合。

## Java 代码实现

### 方法一：二分 + 贪心 + TreeMap（推荐）

```java
import java.util.*;

class Solution {
    public int maxTaskAssign(int[] tasks, int[] workers, int pills, int strength) {
        Arrays.sort(tasks);
        Arrays.sort(workers);
        int lo = 0, hi = Math.min(tasks.length, workers.length);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (canDo(tasks, workers, pills, strength, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean canDo(int[] tasks, int[] workers, int pills, int strength, int k) {
        // 使用最强的k个工人
        TreeMap<Integer, Integer> avail = new TreeMap<>();
        for (int i = workers.length - k; i < workers.length; i++) {
            avail.merge(workers[i], 1, Integer::sum);
        }
        int p = pills;
        // 从最难任务开始分配
        for (int i = k - 1; i >= 0; i--) {
            int task = tasks[i];
            Integer strongest = avail.lastKey();
            if (strongest >= task) {
                // 最强工人直接完成
                if (avail.merge(strongest, -1, Integer::sum) == 0) avail.remove(strongest);
            } else {
                // 需要药丸：找最弱的能吃药完成的工人
                if (p == 0) return false;
                Integer w = avail.ceilingKey(task - strength);
                if (w == null) return false;
                if (avail.merge(w, -1, Integer::sum) == 0) avail.remove(w);
                p--;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log^2 n)
- 空间复杂度：O(n)

## 关键点总结

1. 二分最多完成任务数，取最简单的 k 个任务和最强 k 个工人
2. 从最难任务开始贪心：吃药时找最弱的能完成的工人（保留强工人）
3. TreeMap 提供 ceilingKey、lastKey 以 O(log n) 维护有序工人集合
