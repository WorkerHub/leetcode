## 题目描述

给你大小为 n 的数组 `prevRoom`（`prevRoom[i]` 是建造房间 i 前必须建造的房间），返回建造所有房间的不同顺序数，结果对 10^9+7 取余。

## 解题思路

树形 DP：`dp[v] = (size[v]-1)! * prod(dp[c] * inv_fact[size[c]])`，其中 size[v] 为子树大小。用费马小定理预计算阶乘逆元，用迭代后序遍历避免递归栈溢出。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final int MOD = 1_000_000_007;

    public int waysToBuildRooms(int[] prevRoom) {
        int n = prevRoom.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(prevRoom[i]).add(i);

        // 预计算阶乘和逆元
        long[] fact = new long[n + 1], invFact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = pow(fact[n], MOD - 2, MOD);
        for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

        // 迭代后序遍历
        int[] order = new int[n];
        int[] size = new int[n];
        long[] dp = new long[n];
        Arrays.fill(size, 1);
        Arrays.fill(dp, 1L);

        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        int idx = 0;
        while (!stack.isEmpty()) order[idx++] = stack.pop();
        // 重新BFS记录顺序
        idx = 0;
        stack.push(0);
        while (!stack.isEmpty()) {
            int v = stack.pop();
            order[idx++] = v;
            for (int c : children.get(v)) stack.push(c);
        }

        // 从叶到根计算
        for (int i = n - 1; i >= 0; i--) {
            int v = order[i];
            for (int c : children.get(v)) {
                size[v] += size[c];
                dp[v] = dp[v] * dp[c] % MOD * invFact[size[c]] % MOD;
            }
            dp[v] = dp[v] * fact[size[v] - 1] % MOD;
        }
        return (int) dp[0];
    }

    private long pow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 核心公式：`dp[v] = (size[v]-1)! * prod(dp[c] / size[c]!)`
2. 用费马小定理预计算阶乘逆元避免模除
3. 迭代后序遍历避免 Java 递归栈溢出
