## 题目描述

Alice 从 0 分开始，每次随机抽取 1~maxPts 加到分数上，分数 < k 时继续抽取。求最终分数不超过 n 的概率。

**示例：**
```
输入：n = 6, k = 1, maxPts = 10
输出：0.60000
```

## 解题思路

概率 DP + 滑动窗口：dp[i] 表示得分为 i 的概率，用滑动窗口维护前 maxPts 个状态的概率和。

## Java 代码实现

```java
class Solution {
    public double new21Game(int n, int k, int maxPts) {
        if (k == 0 || n >= k + maxPts - 1) return 1.0;

        double[] dp = new double[n + 1];
        dp[0] = 1.0;
        double windowSum = 1.0;

        for (int i = 1; i <= n; i++) {
            dp[i] = windowSum / maxPts;
            if (i < k) {
                windowSum += dp[i];
            }
            if (i >= maxPts) {
                windowSum -= dp[i - maxPts];
            }
        }

        double result = 0;
        for (int i = k; i <= n; i++) {
            result += dp[i];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **概率 DP**：dp[i] = 前 maxPts 个可达状态的概率之和 / maxPts
2. **滑动窗口**：维护窗口内概率和避免重复计算
3. **边界条件**：k=0 或 n 足够大时必胜
