## 题目描述

`0/1` 数组 `nums`，每次可交换相邻两个不同元素。返回使数组中恰好有 `k` 个连续 `1` 的最少相邻交换次数。

## 解题思路

**贪心 + 前缀和：** 提取所有 `1` 的下标数组 `pos`，令 `p[j] = pos[j] - j` 消除自然间距。对每个大小为 `k` 的窗口，以中位数为集合点，用前缀和 O(1) 计算窗口代价，取最小值。

## Java 代码实现

```java
class Solution {
    public int minMoves(int[] nums, int k) {
        List<Integer> pos = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) pos.add(i);
        }
        int m = pos.size();
        // 消除偏移：p[j] = pos[j] - j
        long[] p = new long[m];
        for (int j = 0; j < m; j++) p[j] = pos.get(j) - j;
        // 前缀和
        long[] prefix = new long[m + 1];
        for (int i = 0; i < m; i++) prefix[i + 1] = prefix[i] + p[i];

        long ans = Long.MAX_VALUE;
        for (int i = 0; i <= m - k; i++) {
            int mid = i + k / 2;
            long center = p[mid];
            // 右半部分（含mid）代价
            long rightSum = prefix[i + k] - prefix[mid];
            long rightCost = rightSum - center * (i + k - mid);
            // 左半部分代价
            long leftSum = prefix[mid] - prefix[i];
            long leftCost = center * (mid - i) - leftSum;
            ans = Math.min(ans, leftCost + rightCost);
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(m)，m 为 1 的数量

## 关键点总结

1. `p[j] = pos[j] - j` 消除偏移，使问题变为"移动到中位数"的经典问题
2. 前缀和加速每个窗口代价计算
3. 以中位数为集合点时代价最小
