## 题目描述

给你一个由若干 `0` 和 `1` 组成的字符串 `s`，请你计算并返回将该字符串分割成两个 **非空** 子字符串（即 **左** 子字符串和 **右** 子字符串）所能获得的最大得分。

「分割字符串的得分」为 **左** 子字符串中 `0` 的数量加上 **右** 子字符串中 `1` 的数量。

**示例 1：**

```
输入：s = "011101"
输出：5
解释：
将字符串分割成两个子字符串：
左 = "0"  得分 = 1（0的个数）
右 = "11101"  得分 = 4（1的个数）
总得分 = 1 + 4 = 5（最优分割）
```

**示例 2：**

```
输入：s = "00111"
输出：5
解释：
左 = "00"  得分 = 2
右 = "111"  得分 = 3
总得分 = 5
```

**示例 3：**

```
输入：s = "1111"
输出：3
```

**提示：**

- `2 <= s.length <= 500`
- 字符串 `s` 仅由字符 `'0'` 和 `'1'` 组成

## 解题思路

### 方法一：枚举分割点（推荐）

枚举所有可能的分割点（左子串至少1个字符，右子串至少1个字符），对每种分割计算得分，取最大值。

分割点 `i` 表示左子串为 `s[0..i]`，右子串为 `s[i+1..]`，`i` 从 0 到 `n-2`。

### 方法二：一次遍历（最优）

核心公式：`score = left_zeros + (total_ones - left_ones)`

设 `total_ones` 为字符串中 '1' 的总数，从左到右维护：
- `leftZeros`：当前左子串中 '0' 的个数
- `leftOnes`：当前左子串中 '1' 的个数

## Java 代码实现

### 方法一：枚举分割点（直观）

```java
class Solution {
    public int maxScore(String s) {
        int n = s.length();
        int maxScore = 0;

        // 枚举分割点 i（左子串 s[0..i]，右子串 s[i+1..]）
        for (int i = 0; i < n - 1; i++) {
            int leftZeros = 0, rightOnes = 0;
            // 计算左边 0 的个数
            for (int l = 0; l <= i; l++) {
                if (s.charAt(l) == '0') leftZeros++;
            }
            // 计算右边 1 的个数
            for (int r = i + 1; r < n; r++) {
                if (s.charAt(r) == '1') rightOnes++;
            }
            maxScore = Math.max(maxScore, leftZeros + rightOnes);
        }
        return maxScore;
    }
}
```

### 方法二：一次遍历（最优，O(n) 时间 O(1) 空间）

```java
class Solution {
    public int maxScore(String s) {
        // 总 1 的个数
        int totalOnes = 0;
        for (char c : s.toCharArray()) {
            if (c == '1') totalOnes++;
        }

        int leftZeros = 0;  // 当前左子串中 0 的个数
        int leftOnes = 0;   // 当前左子串中 1 的个数
        int maxScore = 0;

        // 遍历到 n-2（留一个字符给右子串）
        for (int i = 0; i < s.length() - 1; i++) {
            if (s.charAt(i) == '0') {
                leftZeros++;
            } else {
                leftOnes++;
            }
            // 当前分割的得分
            int score = leftZeros + (totalOnes - leftOnes);
            maxScore = Math.max(maxScore, score);
        }

        return maxScore;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 枚举分割点 | O(n^2) | O(1) |
| 一次遍历 | O(n) | O(1) |

最优解为一次遍历方法。

## 图解示例

以 `s = "011101"` 为例（方法二）：

```
totalOnes = 4

i=0, s[0]='0': leftZeros=1, leftOnes=0, score=1+(4-0)=5, max=5
i=1, s[1]='1': leftZeros=1, leftOnes=1, score=1+(4-1)=4, max=5
i=2, s[2]='1': leftZeros=1, leftOnes=2, score=1+(4-2)=3, max=5
i=3, s[3]='1': leftZeros=1, leftOnes=3, score=1+(4-3)=2, max=5
i=4, s[4]='0': leftZeros=2, leftOnes=3, score=2+(4-3)=3, max=5

答案：5 ✓
```

## 关键点总结

1. 核心公式：`score = leftZeros + rightOnes = leftZeros + (totalOnes - leftOnes)`
2. 分割点范围：`i` 从 0 到 `n-2`（左右子串均非空）
3. 一次遍历只需维护左子串的 0 和 1 计数，加上总 1 数即可

## 易错点

1. 分割点的范围：左子串至少 1 个字符，右子串至少 1 个字符，所以循环到 `n-2`
2. 注意先统计 `totalOnes`，再做一次遍历
3. `right_ones = total_ones - left_ones`，这种"用总数减去左边数量得到右边数量"的技巧非常常用
