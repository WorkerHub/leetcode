## 题目描述

设计停车系统，三种车位（大/中/小），addCar检查对应类型是否有空位。

## 解题思路

数组存储三种车位剩余数量，carType直接作为索引。

## Java 代码实现

```java
class ParkingSystem {
    private int[] spaces;
    
    public ParkingSystem(int big, int medium, int small) {
        spaces = new int[]{0, big, medium, small};
    }
    
    public boolean addCar(int carType) {
        if (spaces[carType] > 0) {
            spaces[carType]--;
            return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **数组索引对应类型**：1=大，2=中，3=小
2. **O(1)操作**：检查并减少车位数
