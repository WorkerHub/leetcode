## 题目描述

给定字符串 `s` 和整数 `k`，通过删除字符使字符串中不同字符种数不超过 `k`，求最少删除字符数。

## 解题思路

贪心：统计各字符频率，按频率升序排列，优先全部删除频率最低的字符（直到剩余字符种数 <= k），累加删除数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minDeletion(String s, int k) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        int distinct = 0;
        for (int v : cnt) if (v > 0) distinct++;
        if (distinct <= k) return 0;

        // 按频率升序排序
        Arrays.sort(cnt);
        int del = 0, idx = 0;
        while (distinct > k) {
            del += cnt[idx++];
            distinct--;
        }
        return del;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + 26 log 26) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 删除整个字符种类（全部出现次数），不是只删一个
2. 优先删除频率最低的字符种类，代价最小
3. 需要删除 `distinct - k` 个字符种类
