## 题目描述

给定正整数数组 arr，构造满足中序遍历叶子顺序与 arr 一致的二叉树，每个非叶节点值等于左右子树叶子最大值的乘积。求所有非叶节点值的最小可能总和。

**示例：**
```
输入：arr = [6,2,4]
输出：32
```

## 解题思路

单调栈（递减）：遇到比栈顶大的元素时弹出栈顶，弹出的元素与左右邻居中较小者相乘。贪心本质：让小数尽早被消除，与尽可能小的邻居合并。

## Java 代码实现

### 方法一：单调栈（推荐）

```java
class Solution {
    public int mctFromLeafValues(int[] arr) {
        int result = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(Integer.MAX_VALUE); // 哨兵

        for (int num : arr) {
            // 栈顶 <= 当前值时弹出
            while (stack.peek() <= num) {
                int mid = stack.pop();
                // mid 与左右邻居中较小者合并
                result += mid * Math.min(stack.peek(), num);
            }
            stack.push(num);
        }

        // 处理栈中剩余元素
        while (stack.size() > 2) {
            result += stack.pop() * stack.peek();
        }

        return result;
    }
}
```

### 方法二：区间 DP

```java
class Solution {
    public int mctFromLeafValues(int[] arr) {
        int n = arr.length;
        int[][] dp = new int[n][n];
        int[][] maxVal = new int[n][n];

        // 预处理区间最大值
        for (int i = 0; i < n; i++) {
            maxVal[i][i] = arr[i];
            for (int j = i + 1; j < n; j++) {
                maxVal[i][j] = Math.max(maxVal[i][j - 1], arr[j]);
            }
        }

        // 枚举区间长度
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;
                // 枚举分割点
                for (int k = i; k < j; k++) {
                    int cost = dp[i][k] + dp[k + 1][j] + maxVal[i][k] * maxVal[k + 1][j];
                    dp[i][j] = Math.min(dp[i][j], cost);
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

## 复杂度分析

- **方法一（单调栈）**：时间 O(n)，空间 O(n)
- **方法二（区间 DP）**：时间 O(n³)，空间 O(n²)

## 关键点总结

1. **单调递减栈**：栈底到栈顶递减，遇到更大元素时弹出合并
2. **贪心本质**：小数与其较小邻居合并，代价最小
3. **哨兵技巧**：栈底放 MAX_VALUE 避免空栈判断
4. **剩余处理**：栈中剩余元素依次与栈顶合并
5. **区间 DP 对比**：`dp[i][j] = min(dp[i][k] + dp[k+1][j] + max[i][k]*max[k+1][j])`
