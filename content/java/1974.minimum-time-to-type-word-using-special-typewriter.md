## 题目描述

26 个字母排成圆圈，指针初始在 `'a'`，每次顺/逆时针移动 1 秒，打印当前字母 1 秒，返回打印 `word` 的最短时间。

## 解题思路

对每对相邻字母，计算顺时针和逆时针的最短距离 `min(diff, 26-diff)`，加 1 秒打印时间求和。

## Java 代码实现

```java
class Solution {
    public int minTimeToType(String word) {
        int total = 0, prev = 0; // 'a' 对应 0
        for (char c : word.toCharArray()) {
            int cur = c - 'a';
            int diff = Math.abs(cur - prev);
            total += Math.min(diff, 26 - diff) + 1; // 移动 + 打印
            prev = cur;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 圆形距离 = `min(diff, 26-diff)`
2. 每个字母打印额外 +1 秒
3. 初始位置 'a'，从第一个字母计算移动距离
