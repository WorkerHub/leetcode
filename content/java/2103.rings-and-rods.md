## 题目描述

给定字符串rings表示环的颜色和所在杆编号，返回集齐红绿蓝三种颜色环的杆数量。

## 解题思路

用位掩码记录每根杆的颜色状态（R=1,G=2,B=4），三色齐全时mask=7。

## Java 代码实现

```java
class Solution {
    public int countPoints(String rings) {
        int[] rodMask = new int[10];
        for (int i = 0; i < rings.length(); i += 2) {
            char color = rings.charAt(i);
            int rod = rings.charAt(i + 1) - '0';
            int bit = color == 'R' ? 1 : color == 'G' ? 2 : 4;
            rodMask[rod] |= bit;
        }
        int count = 0;
        for (int mask : rodMask) {
            if (mask == 7) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **位掩码**：R=1,G=2,B=4，三色齐全mask=7
2. **步长为2**：每两个字符为一组（颜色+杆号）
3. **固定10根杆**：空间恒定
