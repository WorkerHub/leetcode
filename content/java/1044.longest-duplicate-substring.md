## 题目描述

给定字符串 s，返回任意一个最长的重复子串（出现2次或更多）。无则返回空串。

**示例：**
```
输入：s = "banana"
输出："ana"
```

## 解题思路

二分查找 + Rabin-Karp 滚动哈希。二分查找重复子串最大长度（单调性：存在长度 L 的重复子串则必存在 L-1 的），对每个长度用滚动哈希 O(n) 检测重复。

## Java 代码实现

```java
class Solution {
    public String longestDupSubstring(String s) {
        int n = s.length();
        int left = 0, right = n - 1;
        String result = "";

        while (left <= right) {
            int mid = (left + right) / 2;
            int start = search(s, mid);
            if (start != -1) {
                result = s.substring(start, start + mid);
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return result;
    }

    // 滚动哈希检测是否存在长度为 L 的重复子串
    private int search(String s, int L) {
        if (L == 0) return -1;

        long base = 26;
        long mod = (1L << 61) - 1; // 大素数
        long baseL = 1;
        for (int i = 0; i < L - 1; i++) {
            baseL = baseL * base % mod;
        }

        // 计算第一个窗口的哈希值
        long hash = 0;
        for (int i = 0; i < L; i++) {
            hash = (hash * base + (s.charAt(i) - 'a')) % mod;
        }

        HashMap<Long, Integer> seen = new HashMap<>();
        seen.put(hash, 0);

        // 滑动窗口
        for (int i = 1; i <= s.length() - L; i++) {
            hash = ((hash - (s.charAt(i - 1) - 'a') * baseL % mod + mod) * base
                    + (s.charAt(i + L - 1) - 'a')) % mod;
            if (seen.containsKey(hash)) {
                return i;
            }
            seen.put(hash, i);
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **二分查找长度**：利用单调性二分重复子串的最大长度
2. **Rabin-Karp 滚动哈希**：O(1) 更新窗口哈希值
3. **大素数取模**：使用 2^61-1 减少哈希冲突
