## 题目描述

求[low,high]中奇数位数=偶数位数且能被k整除的数的个数。

## 解题思路

数位DP：状态为(位置, 余数mod k, 奇偶位数差, tight, started)。f(high)-f(low-1)求区间答案。

## Java 代码实现

```java
class Solution {
    private char[] digits;
    private int k;
    private int n;
    private int[][][][][] memo;

    public int numberOfBeautifulIntegers(int low, int high, int k) {
        this.k = k;
        return count(high) - count(low - 1);
    }

    private int count(int num) {
        if (num <= 0) return 0;
        digits = String.valueOf(num).toCharArray();
        n = digits.length;
        // memo[pos][rem][balance+n][tight][started]
        memo = new int[n][k][2 * n + 1][2][2];
        for (int[][][][] a : memo)
            for (int[][][] b : a)
                for (int[][] c : b)
                    for (int[] d : c)
                        Arrays.fill(d, -1);
        return dp(0, 0, n, 1, 0); // balance偏移n避免负数
    }

    private int dp(int pos, int rem, int balance, int tight, int started) {
        if (pos == n) {
            if (started == 0) return 0;
            return (rem == 0 && balance == n) ? 1 : 0;
        }
        if (memo[pos][rem][balance][tight][started] != -1) {
            return memo[pos][rem][balance][tight][started];
        }

        int hi = tight == 1 ? (digits[pos] - '0') : 9;
        int result = 0;

        for (int d = 0; d <= hi; d++) {
            if (d == 0 && started == 0) {
                result += dp(pos + 1, 0, n, (tight == 1 && d == hi) ? 1 : 0, 0);
            } else {
                int newBal = balance + (d % 2 == 1 ? 1 : -1);
                int newRem = (rem * 10 + d) % k;
                result += dp(pos + 1, newRem, newBal, (tight == 1 && d == hi) ? 1 : 0, 1);
            }
        }

        memo[pos][rem][balance][tight][started] = result;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10 * N * K * 2N)，N<=10，K<=20
- **空间复杂度**：O(N * K * N)

## 关键点总结

1. **数位DP经典模板**：f(high)-f(low-1)
2. **balance偏移存储**：避免负索引
3. **前导零不计入奇偶统计**
