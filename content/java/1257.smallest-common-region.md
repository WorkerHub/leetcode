## 题目描述

给定区域列表 regions（每个列表第一个区域包含该列表其他区域）和两个区域 region1、region2，返回包含它们的最小公共区域。

**示例：**
```
regions = [["Earth","North America","South America"],["North America","United States","Canada"],...]
region1 = "Quebec", region2 = "New York"
输出："North America"
```

## 解题思路

类似 LCA（最近公共祖先）：构建父节点映射，找到两个区域的祖先链，返回第一个公共祖先。

## Java 代码实现

```java
class Solution {
    public String findSmallestRegion(List<List<String>> regions, String region1, String region2) {
        // 构建父节点映射
        Map<String, String> parent = new HashMap<>();
        for (List<String> region : regions) {
            String par = region.get(0);
            for (int i = 1; i < region.size(); i++) {
                parent.put(region.get(i), par);
            }
        }
        
        // 找 region1 的所有祖先
        Set<String> ancestors = new HashSet<>();
        String curr = region1;
        while (curr != null) {
            ancestors.add(curr);
            curr = parent.get(curr);
        }
        
        // 沿 region2 的祖先链找第一个公共祖先
        curr = region2;
        while (!ancestors.contains(curr)) {
            curr = parent.get(curr);
        }
        return curr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为总区域数
- **空间复杂度**：O(n)

## 关键点总结

1. **树结构**：每个列表的第一个元素是其他元素的父节点
2. **LCA 模式**：先收集一个节点的祖先集合，再沿另一个节点向上找
3. **HashMap 存父关系**：子→父映射
