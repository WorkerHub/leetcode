## 题目描述

给定若干圆，统计至少在一个圆内的格点（整数坐标点）数量。

## 解题思路

枚举所有可能的格点(x,y)，检查是否在某个圆内：(x-cx)²+(y-cy)²<=r²。坐标范围[0,200]，枚举量约40000。

## Java 代码实现

```java
class Solution {
    public int countLatticePoints(int[][] circles) {
        int count = 0;
        // 确定枚举范围
        int minX = 200, maxX = 0, minY = 200, maxY = 0;
        for (int[] c : circles) {
            minX = Math.min(minX, c[0] - c[2]);
            maxX = Math.max(maxX, c[0] + c[2]);
            minY = Math.min(minY, c[1] - c[2]);
            maxY = Math.max(maxY, c[1] + c[2]);
        }

        for (int x = minX; x <= maxX; x++) {
            for (int y = minY; y <= maxY; y++) {
                for (int[] c : circles) {
                    int dx = x - c[0], dy = y - c[1];
                    if (dx * dx + dy * dy <= c[2] * c[2]) {
                        count++;
                        break;
                    }
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * m)，N为格点数，m为圆数
- **空间复杂度**：O(1)

## 关键点总结

1. **距离平方判断**：避免浮点运算
2. **找到一个圆即break**：只需在至少一个圆内
3. **坐标范围有限**：枚举可行
