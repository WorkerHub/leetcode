## 题目描述

给定整数数组 `nums`，每次操作可将任意两个元素替换为它们的平均值（向下取整）。求使所有元素相等的最少操作次数，若无法实现则返回 `-1`。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        // 若总和不能整除 n，无法使所有元素相等
        if (total % n != 0) return -1;

        long target = total / n;
        // 统计不等于 target 的元素数量
        int notEqual = 0;
        for (int x : nums) {
            if (x != target) notEqual++;
        }

        // 每次操作可修正 2 个元素，最少操作 = ceil(notEqual / 2)
        return (notEqual + 1) / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 平均值操作不改变总和，因此目标值唯一：`sum/n`
2. 若总和不能整除 n，永远无法达成，返回 -1
3. 每次配对一个偏大和一个偏小的元素，最少操作 = `ceil(异常元素数 / 2)`
