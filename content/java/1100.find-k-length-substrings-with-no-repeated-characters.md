## 题目描述

给定字符串 s 和整数 k，统计长度为 k 且无重复字符的子串个数。

**示例：**
```
输入：s = "havefunonleetcode", k = 5
输出：6
```

## 解题思路

固定大小滑动窗口：维护窗口内字符频率，若不同字符数 == k 则计数+1。

## Java 代码实现

```java
class Solution {
    public int numKLenSubstrNoRepeats(String s, int k) {
        if (k > s.length() || k > 26) return 0;

        int[] freq = new int[26];
        int unique = 0, count = 0;

        // 初始化第一个窗口
        for (int i = 0; i < k; i++) {
            if (freq[s.charAt(i) - 'a']++ == 0) unique++;
        }
        if (unique == k) count++;

        // 滑动窗口
        for (int i = k; i < s.length(); i++) {
            // 加入右边
            if (freq[s.charAt(i) - 'a']++ == 0) unique++;
            // 移除左边
            if (--freq[s.charAt(i - k) - 'a'] == 0) unique--;
            // 检查
            if (unique == k) count++;
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（26 个字母）

## 关键点总结

1. **固定窗口**：窗口大小恒为 k
2. **unique 计数**：维护窗口内不同字符数
3. **判断条件**：unique == k 等价于无重复
