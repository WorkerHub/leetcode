## 题目描述

给定字符串 `s` 和模式串 `part`，重复找到 s 中最靠左的 `part` 出现位置并删除，直到 s 中不再包含 `part`。返回最终字符串。

## 解题思路

栈 + KMP：维护字符栈和 KMP 状态栈，字符依次入栈时同步推进 KMP 状态。一旦状态达到 `len(part)`，说明栈顶恰好组成了 `part`，弹出对应 m 个字符。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String removeOccurrences(String s, String part) {
        int m = part.length();
        // 构建KMP失配函数
        int[] fail = new int[m];
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && part.charAt(i) != part.charAt(j)) j = fail[j - 1];
            if (part.charAt(i) == part.charAt(j)) j++;
            fail[i] = j;
        }

        // 字符栈和KMP状态栈
        char[] chars = new char[s.length()];
        int[] states = new int[s.length() + 1];
        int top = 0;
        states[0] = 0;

        for (char c : s.toCharArray()) {
            int cur = states[top];
            while (cur > 0 && c != part.charAt(cur)) cur = fail[cur - 1];
            if (c == part.charAt(cur)) cur++;
            chars[top] = c;
            states[++top] = cur;
            // 匹配完成，弹出m个字符
            if (cur == m) top -= m;
        }
        return new String(chars, 0, top);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. KMP + 栈：每个字符入栈时同步维护 KMP 匹配状态
2. 匹配完成时弹出 m 个字符，KMP 状态自动回滚到之前的状态
3. 状态栈比字符栈多一个初始状态（0），保持同步
