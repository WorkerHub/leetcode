## 题目描述

给你一个循环链表的头节点，将其平均分为两个循环链表（奇数节点时第一个多一个），返回两个链表的头节点。

## Java 代码实现

```java
class Solution {
    public ListNode[] splitCircularLinkedList(ListNode list) {
        ListNode slow = list, fast = list;

        // 快慢指针找中点
        while (fast.next != list && fast.next.next != list) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // 偶数节点时 fast 需要再走一步
        if (fast.next.next == list) fast = fast.next;

        // slow 是第一个链表的最后一个节点
        // fast 是整个链表的最后一个节点
        ListNode head2 = slow.next;
        slow.next = list;   // 第一个链表成环
        fast.next = head2;  // 第二个链表成环

        return new ListNode[]{list, head2};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 快慢指针：快指针每次走 2 步，慢指针走 1 步，找到中点
2. 奇偶节点数的循环终止条件不同，偶数时需 fast 额外走一步
3. 断开后分别设置各自的环形连接
