## 题目描述

只含数字 4 和 7 的整数称为幸运数（按大小排列：4, 7, 44, 47, 74, 77, ...），给你整数 `k`，返回第 `k` 个幸运数（字符串形式）。

## Java 代码实现

```java
class Solution {
    public String kthLuckyNumber(int k) {
        // k+1 转二进制，去掉最高位，0 -> '4'，1 -> '7'
        String binary = Integer.toBinaryString(k + 1).substring(1);
        StringBuilder sb = new StringBuilder();
        for (char c : binary.toCharArray()) {
            sb.append(c == '0' ? '4' : '7');
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(log k)
- 空间复杂度：O(log k)

## 关键点总结

1. 幸运数形如二叉树按层排列，第 k 个对应 k+1 的二进制表示（去掉最高位的 1）
2. 二进制中 0 对应 '4'，1 对应 '7'
3. `Integer.toBinaryString(k+1).substring(1)` 去掉最高位
