## 题目描述

n个人互相评价好/坏人，好人说真话坏人不可靠。枚举所有分配方案，求满足一致性的最多好人数。

## 解题思路

n<=15，枚举2^n种方案（bitmask），对每种方案验证所有好人的声明是否一致，取最多好人数。

## Java 代码实现

```java
class Solution {
    public int maximumGood(int[][] statements) {
        int n = statements.length;
        int ans = 0;
        
        for (int mask = 0; mask < (1 << n); mask++) {
            if (isValid(statements, mask, n)) {
                ans = Math.max(ans, Integer.bitCount(mask));
            }
        }
        return ans;
    }
    
    private boolean isValid(int[][] statements, int mask, int n) {
        for (int i = 0; i < n; i++) {
            if ((mask >> i & 1) == 0) continue; // i是坏人，跳过
            // i是好人，验证其所有声明
            for (int j = 0; j < n; j++) {
                if (statements[i][j] == 1 && (mask >> j & 1) == 0) return false;
                if (statements[i][j] == 0 && (mask >> j & 1) == 1) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^N * N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **n<=15可枚举**：2^15 * 15^2 ≈ 7.4*10^6
2. **只验证好人的声明**：坏人声明不可靠，无需验证
3. **Integer.bitCount**：快速统计好人数
