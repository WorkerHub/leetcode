## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回元素之和等于 k 的子数组数量。

## 解题思路

前缀和 + 哈希表：`sum[l..r] = prefix[r+1] - prefix[l] = k`，即 `prefix[l] = prefix[r+1] - k`。遍历时维护前缀和出现次数，对每个新前缀和查询 `prefix - k` 的出现次数。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1); // 空子数组前缀和0出现1次
        int prefix = 0, ans = 0;
        for (int x : nums) {
            prefix += x;
            ans += count.getOrDefault(prefix - k, 0);
            count.merge(prefix, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 初始化 `count[0] = 1`（处理从头开始的子数组）
2. 先查询再更新，避免同一位置自匹配
3. 数组含负数不能用滑动窗口，必须用前缀和
