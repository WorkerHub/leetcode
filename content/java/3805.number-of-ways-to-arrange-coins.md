## 题目描述

给定 `n` 枚硬币和正整数 `k`，将硬币排成阶梯形（第 `i` 行恰好 `i` 枚，且不超过 `k` 行），返回恰好用完所有硬币的方案数（模 `10^9+7`）。

## Java 代码实现

```java
class Solution {
    public int arrangeCoins(long n, int k) {
        final int MOD = 1_000_000_007;
        int count = 0;
        // 枚举行数 r，前 r 行共 r*(r+1)/2 枚，不超过 n 且 r <= k
        for (long r = 1; r <= k && r * (r + 1) / 2 <= n; r++) {
            if (r * (r + 1) / 2 == n) count++;
        }
        return count % MOD;
    }
}
```

## 复杂度分析

- 时间复杂度：O(min(k, sqrt(n)))
- 空间复杂度：O(1)

## 关键点总结

1. 前 r 行的硬币总数为三角数 `r*(r+1)/2`
2. 枚举行数不超过 min(k, sqrt(2n))，范围有限
3. 使用 long 类型避免 r*(r+1)/2 溢出
