## 题目描述

将偶数finalSum拆分为尽可能多个不同正偶数之和，返回这些正偶数。

## 解题思路

贪心：从2开始依次选取2,4,6,...直到剩余值不够下一个时将剩余值全部作为最后一个数（保证不重复）。

## Java 代码实现

```java
class Solution {
    public List<Long> maximumEvenSplit(long finalSum) {
        List<Long> result = new ArrayList<>();
        if (finalSum % 2 != 0) return result;
        
        long cur = 2;
        long remaining = finalSum;
        
        while (remaining > cur) {
            result.add(cur);
            remaining -= cur;
            cur += 2;
        }
        // 剩余值作为最后一个数（比cur大，不重复）
        result.add(remaining);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sqrt(finalSum))
- **空间复杂度**：O(sqrt(finalSum))

## 关键点总结

1. **奇数无法拆分**：偶数之和必为偶数
2. **贪心从小到大**：每次选最小可用偶数，最大化个数
3. **最后一步合并**：剩余值并入最后一个数保证不重复
