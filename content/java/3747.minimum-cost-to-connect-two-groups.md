## 题目描述

给定两个整数组 `group1`（大小 `m`）和 `group2`（大小 `n`），以及代价矩阵 `cost`，其中 `cost[i][j]` 表示连接 `group1[i]` 和 `group2[j]` 的代价。每个 `group1[i]` 必须连接到至少一个 `group2[j]`，每个 `group2[j]` 必须连接到至少一个 `group1[i]`，求最小总代价。

## 解题思路

状态压缩 DP。用 `n` 位掩码表示 `group2` 中已被覆盖的节点集合。`dp[mask]` 表示处理完当前 `group1` 节点后，`group2` 已覆盖集合为 `mask` 的最小代价。最终对未覆盖的 `group2` 节点用各自最小代价补充。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int connectTwoGroups(List<List<Integer>> cost) {
        int m = cost.size(), n = cost.get(0).size();
        int full = 1 << n;
        int INF = Integer.MAX_VALUE / 2;

        // 每个 group2[j] 被连接的最小代价
        int[] minCost = new int[n];
        Arrays.fill(minCost, INF);
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                minCost[j] = Math.min(minCost[j], cost.get(i).get(j));
            }
        }

        int[] dp = new int[full];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int i = 0; i < m; i++) {
            int[] newDp = new int[full];
            Arrays.fill(newDp, INF);
            for (int mask = 0; mask < full; mask++) {
                if (dp[mask] == INF) continue;
                // 枚举第 i 个 group1 节点连接 group2 的节点 j
                for (int j = 0; j < n; j++) {
                    int newMask = mask | (1 << j);
                    newDp[newMask] = Math.min(newDp[newMask], dp[mask] + cost.get(i).get(j));
                }
            }
            dp = newDp;
        }

        // 补充未覆盖的 group2 节点
        int ans = INF;
        for (int mask = 0; mask < full; mask++) {
            if (dp[mask] == INF) continue;
            int extra = 0;
            for (int j = 0; j < n; j++) {
                if ((mask >> j & 1) == 0) {
                    extra += minCost[j];
                }
            }
            ans = Math.min(ans, dp[mask] + extra);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 2^n)
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 12 使得状态压缩 DP 可行（2^12 = 4096 个状态）
2. 未被覆盖的 group2 节点用其最便宜的连接方式补充
3. 每次 group1 节点处理时选一个 group2 节点更新掩码
