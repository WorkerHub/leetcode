## 题目描述

两个字符串相似指交换两个位置的字母可使其相等（或本身相等）。给定字符串列表（互为字母异位词），求相似字符串组的个数。

**示例：**
```
输入：strs = ["tars","rats","arts","star"]
输出：2（{"tars","rats","arts"} 和 {"star"}）
```

## 解题思路

并查集：枚举所有字符串对，相似的合并到同一组，最后统计连通分量数。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public int numSimilarGroups(String[] strs) {
        int n = strs.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isSimilar(strs[i], strs[j])) {
                    union(i, j);
                }
            }
        }

        int groups = 0;
        for (int i = 0; i < n; i++) {
            if (find(i) == i) groups++;
        }
        return groups;
    }

    private boolean isSimilar(String s1, String s2) {
        int diff = 0;
        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) != s2.charAt(i)) {
                diff++;
                if (diff > 2) return false;
            }
        }
        return true;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × m)，n 为字符串数，m 为字符串长度
- **空间复杂度**：O(n)

## 关键点总结

1. **并查集**：合并相似字符串到同一组
2. **相似判断**：最多 2 个位置不同
3. **连通分量计数**：find(i) == i 的个数
