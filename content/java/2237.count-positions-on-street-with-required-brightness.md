## 题目描述

街上有灯覆盖区间，统计实际亮度>=需求亮度的位置数量。

## 解题思路

差分数组：每盏灯对[pos-range, pos+range]区间+1，求前缀和还原亮度，逐位比较requirement。

## Java 代码实现

```java
class Solution {
    public int meetRequirement(int n, int[][] lights, int[] requirement) {
        int[] diff = new int[n + 1];
        for (int[] light : lights) {
            int left = Math.max(0, light[0] - light[1]);
            int right = Math.min(n - 1, light[0] + light[1]);
            diff[left]++;
            diff[right + 1]--;
        }
        
        int brightness = 0, ans = 0;
        for (int i = 0; i < n; i++) {
            brightness += diff[i];
            if (brightness >= requirement[i]) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)，M为灯数量
- **空间复杂度**：O(N)

## 关键点总结

1. **差分数组处理区间更新**：O(1)完成一次区间+1
2. **前缀和还原**：差分数组求前缀和得每位置亮度
3. **边界裁剪**：灯覆盖范围限制在[0, n-1]内
