## 题目描述

给你 `n` 节点有向图和目标节点 `destination`，判断是否可以添加有向边使所有路径最终指向 `destination`。

## 解题思路

DFS 三色标记：`destination` 不能有出边；其他节点用 0（未访问）、1（访问中）、2（已完成）三色标记，遇到访问中节点说明有环返回 false；叶子节点（出度为 0）必须是 `destination`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] adj;
    private int[] color; // 0=未访问, 1=访问中, 2=已完成

    public boolean leadsToDestination(int n, int[][] edges, int destination) {
        adj = new List[n];
        color = new int[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) adj[e[0]].add(e[1]);

        // destination 不能有出边
        if (!adj[destination].isEmpty()) return false;

        // 检查所有节点
        for (int i = 0; i < n; i++) {
            if (color[i] == 0 && !dfs(i, destination)) return false;
        }
        return true;
    }

    private boolean dfs(int node, int dest) {
        if (color[node] == 1) return false; // 有环
        if (color[node] == 2) return true;  // 已验证

        color[node] = 1; // 标记访问中
        if (adj[node].isEmpty()) {
            // 叶子节点必须是 destination
            color[node] = 2;
            return node == dest;
        }
        for (int nb : adj[node]) {
            if (!dfs(nb, dest)) return false;
        }
        color[node] = 2;
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. destination 有出边时直接返回 false
2. 三色 DFS 同时检测环和路径有效性
3. 叶子节点（出度为 0）若不是 destination 则无法添加有效路径
