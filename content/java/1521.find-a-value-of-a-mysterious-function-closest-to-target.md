## 题目描述

func(arr, l, r) = AND(arr[l..r])。找使 |func(arr,l,r) - target| 最小的值。

**示例：**
```
输入：arr = [9,12,3,7,15], target = 5
输出：2
```

## 解题思路

位运算特性：固定右端点，AND 值单调不增且不同值最多 log(max_val) 个。维护当前右端点所有可能的 AND 值集合。

## Java 代码实现

```java
class Solution {
    public int closestToTarget(int[] arr, int target) {
        int result = Integer.MAX_VALUE;
        Set<Integer> curSet = new HashSet<>();
        
        for (int num : arr) {
            Set<Integer> newSet = new HashSet<>();
            newSet.add(num);
            for (int val : curSet) {
                newSet.add(val & num);
            }
            for (int val : newSet) {
                result = Math.min(result, Math.abs(val - target));
            }
            curSet = newSet;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(max_val))
- **空间复杂度**：O(log(max_val))

## 关键点总结

1. **AND 单调不增**：位只会从 1 变 0
2. **集合大小有限**：最多 20 个不同值（log2(10^6)）
3. **滚动更新**：每步将所有旧值 AND 新元素
4. **逐步逼近**：对集合中每个值更新最小差
