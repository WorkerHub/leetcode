## 题目描述

将句子分成多行，每行最多 k 个字符，除最后一行外每行剩余空格产生代价 `(k - 行长)^2`，返回最小总代价。

## 解题思路

DP：`dp[i]` = 放置前 i 个单词的最小代价。从后往前枚举最后一行起始位置 j，用前缀和计算行宽，若行宽 <= k 则更新 `dp[i] = min(dp[i], dp[j-1] + (k-rowLen)^2)`，最后一行代价为 0。

## Java 代码实现

### 方法一：动态规划 + 前缀和（推荐）

```java
class Solution {
    public int minimumCost(String sentence, int k) {
        String[] words = sentence.split(" ");
        int n = words.length;
        int[] psum = new int[n + 1]; // 前缀字符数之和（不含空格）
        for (int i = 0; i < n; i++) psum[i + 1] = psum[i] + words[i].length();

        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = i; j >= 1; j--) {
                // 第 j..i 个单词放一行（1-indexed）
                int spaces = i - j;
                int rowLen = psum[i] - psum[j - 1] + spaces;
                if (rowLen > k) break; // 超出，更少单词也不行
                int extra = k - rowLen;
                if (i == n) {
                    dp[i] = Math.min(dp[i], dp[j - 1]); // 最后一行无代价
                } else {
                    dp[i] = Math.min(dp[i], dp[j - 1] + extra * extra);
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 行长 = 单词字符总数 + 行内单词间空格数（单词数 - 1）
2. 最后一行代价为 0
3. 从后往前枚举起始位置，超出 k 时 break
