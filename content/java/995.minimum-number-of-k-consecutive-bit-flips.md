## 题目描述

给定二进制数组 nums 和整数 k，每次可以翻转长度为 k 的子数组，返回使数组全部为 1 的最少翻转次数，不可能返回 -1。

**示例：**
```
输入：nums = [0,1,0], k = 1
输出：2
```

## 解题思路

贪心 + 差分：从左到右遍历，遇到当前为 0（考虑之前翻转影响后）就翻转。用差分数组记录翻转影响范围。

## Java 代码实现

```java
class Solution {
    public int minKBitFlips(int[] nums, int k) {
        int n = nums.length;
        int[] isFlipped = new int[n];
        int flipped = 0, result = 0;

        for (int i = 0; i < n; i++) {
            if (i >= k) {
                flipped ^= isFlipped[i - k];
            }

            if ((nums[i] ^ flipped) == 0) {
                // 当前位为0，需要翻转
                if (i + k > n) return -1;
                result++;
                isFlipped[i] = 1;
                flipped ^= 1;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心**：从左到右遇到 0 就翻转
2. **差分数组**：记录翻转的起止位置
3. **XOR 累计**：用异或跟踪当前翻转奇偶性
