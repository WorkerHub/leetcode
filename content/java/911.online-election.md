## 题目描述

给你两个整数数组 `persons` 和 `times`。在选举中，第 `i` 张票是在时刻 `times[i]` 投给候选人 `persons[i]` 的。

对于发生在时刻 `t` 的每个查询，需要找出在 `t` 时刻在选举中领先的候选人的编号。

在 `t` 时刻投出的选票也将被计入我们的查询之中。在平局的情况下，最近获得投票的候选人将会获胜。

实现 `TopVotedCandidate` 类：

- `TopVotedCandidate(int[] persons, int[] times)` 使用 `persons` 和 `times` 数组初始化对象。
- `int q(int t)` 根据前面描述的规则，返回在时刻 `t` 在选举中领先的候选人的编号。

**示例：**
```
输入：
["TopVotedCandidate", "q", "q", "q", "q", "q", "q"]
[[[0, 1, 1, 0, 0, 1, 0], [0, 5, 10, 15, 20, 25, 30]], [3], [12], [25], [15], [24], [8]]
输出：
[null, 0, 1, 1, 0, 0, 1]
```

**提示：**
- `1 <= persons.length <= 5000`
- `times.length == persons.length`
- `0 <= persons[i] < persons.length`
- `0 <= times[i] <= 10^9`
- `times` 是严格递增的数组
- `times[0] <= t <= 10^9`
- 每个测试用例最多调用 `10^4` 次 `q`

## 解题思路

这道题是一道设计题，需要高效地查询某个时刻的领先候选人。

**核心思路：**
1. **预处理**：在初始化时，计算每个时刻的领先候选人
2. **查询优化**：使用二分查找快速定位时刻 t

**初始化阶段：**
1. 遍历所有投票记录，维护每个候选人的票数
2. 对于每个时刻，记录当时的领先候选人
3. 如果平局，选择最近获得投票的候选人

**查询阶段：**
1. 给定时刻 t，找到小于等于 t 的最大投票时刻
2. 使用二分查找在 times 数组中定位
3. 返回该时刻的领先候选人

## Java 代码实现

### 方法一：预处理 + 二分查找（推荐）

```java
class TopVotedCandidate {
    private int[] times;
    private int[] leaders; // leaders[i] 表示 times[i] 时刻的领先者

    public TopVotedCandidate(int[] persons, int[] times) {
        this.times = times;
        int n = persons.length;
        this.leaders = new int[n];

        int[] voteCounts = new int[persons.length + 1]; // 记录每个候选人的票数
        int leader = -1;       // 当前领先者
        int maxVotes = 0;      // 最高票数

        // 遍历每个投票时刻
        for (int i = 0; i < n; i++) {
            int person = persons[i];
            voteCounts[person]++;

            // 更新领先者
            // 如果票数更多，或者票数相同但是更新的投票（平局规则）
            if (voteCounts[person] >= maxVotes) {
                leader = person;
                maxVotes = voteCounts[person];
            }

            // 记录当前时刻的领先者
            leaders[i] = leader;
        }
    }

    public int q(int t) {
        // 二分查找：找到 <= t 的最大时刻
        int left = 0, right = times.length - 1;
        while (left < right) {
            int mid = (left + right + 1) / 2; // 使用右中位数
            if (times[mid] <= t) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        return leaders[left];
    }
}
```

### 方法二：使用 Arrays.binarySearch

```java
import java.util.Arrays;

class TopVotedCandidate {
    private int[] times;
    private int[] leaders;

    public TopVotedCandidate(int[] persons, int[] times) {
        this.times = times;
        int n = persons.length;
        this.leaders = new int[n];

        int[] voteCounts = new int[n + 1];
        int leader = -1;
        int maxVotes = 0;

        for (int i = 0; i < n; i++) {
            voteCounts[persons[i]]++;
            if (voteCounts[persons[i]] >= maxVotes) {
                leader = persons[i];
                maxVotes = voteCounts[persons[i]];
            }
            leaders[i] = leader;
        }
    }

    public int q(int t) {
        // Arrays.binarySearch 返回负数时，插入点为 -result - 1
        int pos = Arrays.binarySearch(times, t);
        if (pos < 0) {
            // 找到插入位置，减1得到小于t的最大索引
            pos = -pos - 2;
        }
        return leaders[pos];
    }
}
```

## 复杂度分析

**初始化：**
- 时间复杂度：O(n)，需要遍历所有投票记录
- 空间复杂度：O(n)，存储领先者数组和票数统计

**查询 `q`：**
- 时间复杂度：O(log n)，二分查找
- 空间复杂度：O(1)

## 关键点总结

1. **预处理思想**：将计算前置到初始化阶段，加速查询
2. **二分查找**：在有序数组中快速定位时刻
3. **平局处理**：使用 `>=` 而不是 `>`，确保平局时选择最新的候选人
4. **边界处理**：找 `<= t` 的最大值，使用右中位数二分
5. **空间换时间**：存储所有时刻的领先者，避免重复计算

## 易错点

1. **平局规则**：要使用 `>=` 而不是 `>`，确保平局时更新为最新的候选人
2. **二分查找方向**：需要找 `<= t` 的最大值，不是 `>= t` 的最小值
3. **右中位数**：二分查找找最大满足条件的值时，需要使用右中位数
4. **索引越界**：确保 t >= times[0]，题目保证了这一点
5. **票数数组初始化**：需要足够大
