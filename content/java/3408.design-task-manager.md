## 题目描述

设计任务管理器，支持添加、编辑优先级、删除任务，以及执行优先级最高（相同时 taskId 更大的优先）的任务并返回其 userId。

## Java 代码实现

```java
import java.util.*;

class TaskManager {
    // taskId -> {userId, priority}
    private Map<Integer, int[]> taskInfo = new HashMap<>();
    // 有序集合存 (priority, taskId)，取最大
    private TreeMap<long[], Integer> sortedTasks = new TreeMap<>((a, b) -> {
        if (a[0] != b[0]) return Long.compare(a[0], b[0]);
        return Long.compare(a[1], b[1]);
    });

    // 用 TreeSet 更简洁
    private TreeSet<long[]> taskSet = new TreeSet<>((a, b) -> {
        if (a[0] != b[0]) return Long.compare(a[0], b[0]);
        return Long.compare(a[1], b[1]);
    });

    public TaskManager(List<List<Integer>> tasks) {
        for (List<Integer> t : tasks) {
            int userId = t.get(0), taskId = t.get(1), priority = t.get(2);
            taskInfo.put(taskId, new int[]{userId, priority});
            taskSet.add(new long[]{priority, taskId});
        }
    }

    public void add(int userId, int taskId, int priority) {
        taskInfo.put(taskId, new int[]{userId, priority});
        taskSet.add(new long[]{priority, taskId});
    }

    public void edit(int taskId, int newPriority) {
        int[] info = taskInfo.get(taskId);
        taskSet.remove(new long[]{info[1], taskId}); // 删除旧记录
        info[1] = newPriority;
        taskSet.add(new long[]{newPriority, taskId}); // 插入新记录
    }

    public void remove(int taskId) {
        int[] info = taskInfo.remove(taskId);
        taskSet.remove(new long[]{info[1], taskId});
    }

    public int execTop() {
        if (taskSet.isEmpty()) return -1;
        long[] top = taskSet.last(); // 取最大（优先级最高，taskId 最大）
        taskSet.remove(top);
        int taskId = (int) top[1];
        return taskInfo.remove(taskId)[0];
    }
}
```

## 复杂度分析

- add/edit/remove/execTop：O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 结合哈希表（O(1) 按 taskId 查找）和有序集合（O(log n) 取最大值）。
2. 优先级相同时 taskId 大的优先，(priority, taskId) 的字典序即比较准则。
3. `edit` 操作先删除旧记录，再插入新记录。
