## 题目描述

如果一个正整数自身是回文数，且它也是一个回文数的平方，那么我们称这个数为超级回文数。

现在，给定两个正整数 `left` 和 `right`（以字符串形式表示），返回包含在范围 `[left, right]` 中的超级回文数的数量。

**示例 1：**
```
输入：left = "4", right = "1000"
输出：4
解释：
4, 9, 121, 484 是超级回文数。
注意 676 不是一个超级回文数：26 * 26 = 676，但是 26 不是回文数。
```

**示例 2：**
```
输入：left = "1", right = "2"
输出：1
```

**提示：**
- `1 <= len(left) <= 18`
- `1 <= len(right) <= 18`
- `left` 和 `right` 只包含数字
- `left` 和 `right` 不会以 0 开头
- `left` 和 `right` 代表 `[1, 10^18]` 范围内的整数
- `left` 小于或等于 `right`

## 解题思路

这道题的关键在于理解两个条件：
1. 数字本身是回文数
2. 数字的平方根也是回文数

**核心观察：**
- 如果 `n` 是超级回文数，那么 `n = k^2`，且 `k` 和 `n` 都是回文数
- 由于范围是 `[1, 10^18]`，所以 `k` 的范围是 `[1, 10^9]`
- 我们可以枚举所有回文数 `k`，检查 `k^2` 是否也是回文数且在范围内

**优化策略：**
- 不需要枚举所有 `10^9` 个数，只需要构造回文数
- 回文数可以通过前半部分构造（奇数长度和偶数长度）
- 对于长度为 `d` 的回文数，只需要枚举 `10^(d/2)` 个数

## Java 代码实现

### 方法一：枚举回文数（推荐）

```java
class Solution {
    public int superpalindromesInRange(String left, String right) {
        long L = Long.parseLong(left);
        long R = Long.parseLong(right);

        int count = 0;

        // 枚举回文数的前半部分，范围是 [1, 100000)
        for (int i = 1; i < 100000; i++) {
            String s = String.valueOf(i);

            // 构造偶数长度的回文数
            String palindromeEven = s + new StringBuilder(s).reverse().toString();
            long palin = Long.parseLong(palindromeEven);
            long square = palin * palin;
            if (square > R) break;
            if (square >= L && isPalindrome(square)) {
                count++;
            }

            // 构造奇数长度的回文数（添加中间数字）
            for (int d = 0; d <= 9; d++) {
                String palindromeOdd = s + d + new StringBuilder(s).reverse().toString();
                palin = Long.parseLong(palindromeOdd);
                square = palin * palin;
                if (square > R) break;
                if (square >= L && isPalindrome(square)) {
                    count++;
                }
            }
        }

        return count;
    }

    // 判断数字是否为回文数
    private boolean isPalindrome(long n) {
        String s = String.valueOf(n);
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

### 方法二：优化的枚举（更清晰）

```java
class Solution {
    public int superpalindromesInRange(String left, String right) {
        long L = Long.parseLong(left);
        long R = Long.parseLong(right);

        int count = 0;

        // 枚举 1-9 位的回文数平方根
        // 由于最大值是 10^18，平方根最大是 10^9（9位数）
        // 前半部分最多5位
        for (int length = 1; length <= 5; length++) {
            int lo = (int) Math.pow(10, length - 1);
            int hi = (int) Math.pow(10, length);

            // 偶数长度回文数
            for (int i = lo; i < hi; i++) {
                String s = String.valueOf(i);
                long palin = Long.parseLong(s + new StringBuilder(s).reverse().toString());
                long square = palin * palin;
                if (square >= L && square <= R && isPalindrome(square)) {
                    count++;
                }
            }

            // 奇数长度回文数
            for (int i = lo; i < hi; i++) {
                for (int mid = 0; mid <= 9; mid++) {
                    String s = String.valueOf(i);
                    long palin = Long.parseLong(s + mid + new StringBuilder(s).reverse().toString());
                    long square = palin * palin;
                    if (square >= L && square <= R && isPalindrome(square)) {
                        count++;
                    }
                }
            }
        }

        return count;
    }

    private boolean isPalindrome(long n) {
        String s = String.valueOf(n);
        int l = 0, r = s.length() - 1;
        while (l < r) {
            if (s.charAt(l++) != s.charAt(r--)) return false;
        }
        return true;
    }
}
```

## 复杂度分析

**时间复杂度：** O(W^(1/4) * log W)
- 其中 W = 10^18 是范围上限
- 我们需要枚举约 10^5 个回文数平方根
- 每个回文数需要 O(log W) 时间判断其平方是否为回文

**空间复杂度：** O(log W)
- 字符串转换需要的空间

## 关键点总结

1. **范围分析**：由于范围是 `[1, 10^18]`，平方根范围是 `[1, 10^9]`
2. **回文数构造**：通过前半部分构造，避免枚举所有数字
3. **奇偶长度**：需要分别处理奇数长度和偶数长度的回文数
4. **剪枝优化**：当平方超过右边界时可以提前结束
5. **使用 long**：Java 中注意使用 long 避免整数溢出

## 易错点

1. **整数溢出**：Java 中必须使用 long，因为 10^18 超过 int 范围
2. **范围控制**：注意平方根的枚举范围，不要超过 10^9
3. **奇偶长度**：要同时考虑奇数长度和偶数长度的回文数
4. **边界情况**：注意 left 和 right 的边界值
5. **Long.parseLong**：使用字符串构造长整数
