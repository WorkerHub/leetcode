## 题目描述

给定一个字符串 s，返回 s 中不同的非空回文子序列个数。答案对 10^9 + 7 取模。

**示例：**
```
输入：s = "bccb"
输出：6
解释：6个不同的非空回文子序列为："b", "c", "bb", "cc", "bcb", "bccb"
```

## 解题思路

区间 DP：dp[i][j] 表示 s[i..j] 中不同回文子序列个数。根据首尾字符是否相同分情况讨论，注意去重。

## Java 代码实现

```java
class Solution {
    public int countPalindromicSubsequences(String s) {
        int MOD = 1_000_000_007;
        int n = s.length();
        long[][] dp = new long[n][n];

        // 单个字符是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;

                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] * 2;

                    // 在内部找相同字符的位置
                    int left = i + 1, right = j - 1;
                    while (left <= right && s.charAt(left) != s.charAt(i)) left++;
                    while (left <= right && s.charAt(right) != s.charAt(i)) right--;

                    if (left > right) {
                        // 内部没有相同字符
                        dp[i][j] += 2;
                    } else if (left == right) {
                        // 内部有一个相同字符
                        dp[i][j] += 1;
                    } else {
                        // 内部有多个相同字符，减去重复
                        dp[i][j] -= dp[left + 1][right - 1];
                    }
                } else {
                    dp[i][j] = dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1];
                }

                dp[i][j] = (dp[i][j] % MOD + MOD) % MOD;
            }
        }

        return (int) dp[0][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：枚举所有子串长度
2. **去重处理**：根据内部相同字符数量分三种情况
3. **取模**：注意减法可能产生负数，需加 MOD
