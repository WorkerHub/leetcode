## 题目描述

与 3372 相同，但数据规模更大（n, m 达 10^5），需要更高效的算法来计算树中每个节点在距离 k 内的节点数。

## 解题思路

数据规模 10^5，暴力 BFS O(n^2) 会超时。使用**换根 DP**：先从根节点做一次 DFS 计算每个节点子树内的距离统计，再做一次 DFS 将父节点贡献"换根"到子节点，一次性完成所有节点的覆盖数计算。树 2 取所有节点中最大的 `c2[j]`（k-1 半径）加到树 1 每个节点上。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maxTargetNodes(int[][] edges1, int[][] edges2, int k) {
        int n1 = edges1.length + 1;
        int n2 = edges2.length + 1;

        List<List<Integer>> g1 = buildGraph(edges1, n1);
        List<List<Integer>> g2 = buildGraph(edges2, n2);

        int[] c1 = countReachable(g1, n1, k);
        int[] c2 = countReachable(g2, n2, k - 1);

        int bestC2 = 0;
        for (int v : c2) bestC2 = Math.max(bestC2, v);

        int[] ans = new int[n1];
        for (int i = 0; i < n1; i++) {
            ans[i] = c1[i] + bestC2;
        }
        return ans;
    }

    private List<List<Integer>> buildGraph(int[][] edges, int n) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        return g;
    }

    /**
     * 换根 DP：计算每个节点在 distLimit 距离内的节点数
     * down[v] = v 子树内距离 v 为 d 的节点数（按深度分层存储）
     */
    private int[] countReachable(List<List<Integer>> g, int n, int distLimit) {
        if (distLimit < 0) return new int[n];

        // DFS 顺序 + 父节点记录
        int[] parent = new int[n];
        int[] order = new int[n];
        Arrays.fill(parent, -1);
        boolean[] visited = new boolean[n];
        int idx = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        visited[0] = true;
        while (!stack.isEmpty()) {
            int v = stack.pop();
            order[idx++] = v;
            for (int nb : g.get(v)) {
                if (!visited[nb]) {
                    visited[nb] = true;
                    parent[nb] = v;
                    stack.push(nb);
                }
            }
        }

        // down[v][d] = v 子树内距离 v 恰好为 d 的节点数
        // 用列表存储（每个节点最多 distLimit+1 层）
        int[][] down = new int[n][distLimit + 1];
        for (int i = 0; i < n; i++) down[i][0] = 1;

        // 从叶到根合并子树
        for (int i = n - 1; i >= 1; i--) {
            int v = order[i];
            int p = parent[v];
            for (int d = 0; d < distLimit; d++) {
                down[p][d + 1] += down[v][d];
            }
        }

        // up[v] 存储从父节点方向来、距离 v 为 d 的节点数
        int[][] up = new int[n][distLimit + 1];

        // 从根到叶换根
        int[] reach = new int[n];
        // 根节点的 reach 直接是 down[0] 的前缀和
        for (int d = 0; d <= distLimit; d++) reach[0] += down[0][d];

        for (int i = 1; i < n; i++) {
            int v = order[i];
            int p = parent[v];
            // up[v][1] 来自父节点本身，up[v][d+1] 来自 up[p][d] 和 down[p][d] 减去 v 贡献
            up[v][1] = 1; // 父节点本身距离 v 为 1
            for (int d = 1; d < distLimit; d++) {
                // 父节点方向距离 d 的节点：up[p][d-1] + down[p][d-1] - down[v][d-2]
                // 更准确：父节点距 v 为 1，父节点子树（排除 v 方向）距 v 为 d 的 = down[p][d-1] - (d>=2 ? down[v][d-2] : (d==1?1:0))
                // 以及 up[p] 方向距 v 为 d 的 = up[p][d-1]
                int fromParentDown = down[p][d] - (d >= 1 ? down[v][d - 1] : 0);
                int fromParentUp = up[p][d];
                up[v][d + 1] = fromParentDown + fromParentUp;
            }
            // 计算 v 的总 reach
            int total = 0;
            for (int d = 0; d <= distLimit; d++) {
                total += down[v][d] + up[v][d];
            }
            // up[v][0] 不存在（距离为 0 只有自身，已在 down[v][0] 中）
            // 注意 up[v][0] 初始化为 0，避免重复计数
            reach[v] = total;
        }

        return reach;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，换根 DP 每个节点处理 k 层
- 空间复杂度：O(n * k)

## 关键点总结

1. 换根 DP 将 O(n^2) 的暴力 BFS 优化为 O(n*k)。
2. 分两次 DFS：第一次从叶到根计算子树内各深度节点数，第二次从根到叶换根计算父节点方向贡献。
3. 树 2 的最优连接点是 `max(c2[j])` for all j。
