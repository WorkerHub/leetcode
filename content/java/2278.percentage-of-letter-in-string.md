## 题目描述

返回字符letter在字符串s中所占的百分比（向下取整）。

## 解题思路

统计letter出现次数，计算count*100/len(s)整数除法。

## Java 代码实现

```java
class Solution {
    public int percentageLetter(String s, char letter) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == letter) count++;
        }
        return count * 100 / s.length();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **先乘100再除**：避免浮点精度问题
2. **整数除法向下取整**：Java的/天然满足
