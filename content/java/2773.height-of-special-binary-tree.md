## 题目描述

给你二叉树根节点 `root`（每个节点要么是叶子要么有两个子节点），特殊节点是恰好有一个子节点为叶子的节点，返回从根到最深叶子经过的特殊节点数量的最大值。

## Java 代码实现

```java
class Solution {
    public int heightOfTree(TreeNode root) {
        return dfs(root);
    }

    private boolean isLeaf(TreeNode node) {
        return node != null && node.left == null && node.right == null;
    }

    private int dfs(TreeNode node) {
        if (node == null || isLeaf(node)) return 0;
        int leftH = dfs(node.left);
        int rightH = dfs(node.right);
        // 特殊节点：两个子节点中恰好一个是叶子
        boolean isSpecial = (isLeaf(node.left) && !isLeaf(node.right))
                         || (isLeaf(node.right) && !isLeaf(node.left));
        return (isSpecial ? 1 : 0) + Math.max(leftH, rightH);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树高

## 关键点总结

1. 特殊节点：两个子节点中恰好一个是叶子
2. 特殊高度是路径上特殊节点的计数
