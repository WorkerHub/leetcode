## 题目描述

给你一个字符串 `s` 和整数 `k`，将每个字符替换为字母表中向后第 `k` 位（循环处理），返回加密后的字符串。

## Java 代码实现

```java
class Solution {
    public String getEncryptedString(String s, int k) {
        k = k % 26; // 先对 26 取模简化计算
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            // 计算新字符位置并循环处理
            int newPos = (c - 'a' + k) % 26;
            sb.append((char) ('a' + newPos));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度
- 空间复杂度：O(n)，存储结果字符串

## 关键点总结

1. 用 `(pos + k) % 26` 实现循环移位
2. 先将 `k` 对 26 取模可以简化计算
