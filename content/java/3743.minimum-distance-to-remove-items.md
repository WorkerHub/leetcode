## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作移除一段连续子数组（代价为子数组长度），求移除所有大于 `k` 的元素所需的最小总代价。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumDistance(int[] nums, int k) {
        // 找出所有"坏"元素（值 > k）的位置
        List<Integer> bad = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > k) bad.add(i);
        }
        if (bad.isEmpty()) return 0;

        // 贪心：若两个相邻坏位置的间隙 gap < 2，合并代价更优
        // 每段单独代价 1；合并间隙代价 gap（只需额外覆盖间隙元素）
        int total = 1; // 第一个坏位置代价 1
        for (int i = 1; i < bad.size(); i++) {
            int gap = bad.get(i) - bad.get(i - 1) - 1;
            if (gap < 1) {
                total += gap; // 合并：只增加间隙代价（gap=0时免费合并）
            } else {
                total += 1;  // 分开：新开一个区间代价 1
            }
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，存储坏位置

## 关键点总结

1. 关注相邻坏元素之间的间隙：间隙为 0 时合并必然更优
2. 合并代价 = 间隙长度；分开代价 = 2；间隙 < 2 时合并更优
3. 贪心逐步决策，每次只需考虑当前相邻的两个坏位置
