## 题目描述

给定一个 `m × n` 的整数矩阵 `grid`，从左上角到右下角只能向右或向下移动，路径必须经过中间单元格 `(m/2, n/2)`，求满足条件的最小路径代价。

## Java 代码实现

```java
class Solution {
    public int minCostPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int midR = m / 2, midC = n / 2;
        final int INF = Integer.MAX_VALUE / 2;

        // 第一段 DP：从 (0,0) 到各点的最小代价
        int[][] dp1 = new int[m][n];
        for (int[] row : dp1) java.util.Arrays.fill(row, INF);
        dp1[0][0] = grid[0][0];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int top = i > 0 ? dp1[i - 1][j] : INF;
                int left = j > 0 ? dp1[i][j - 1] : INF;
                dp1[i][j] = Math.min(top, left) + grid[i][j];
            }
        }

        // 第二段 DP：从各点到 (m-1,n-1) 的最小代价（逆向）
        int[][] dp2 = new int[m][n];
        for (int[] row : dp2) java.util.Arrays.fill(row, INF);
        dp2[m - 1][n - 1] = grid[m - 1][n - 1];
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (i == m - 1 && j == n - 1) continue;
                int bot = i < m - 1 ? dp2[i + 1][j] : INF;
                int right = j < n - 1 ? dp2[i][j + 1] : INF;
                dp2[i][j] = Math.min(bot, right) + grid[i][j];
            }
        }

        // 两段之和减去中间格（被计算了两次）
        return dp1[midR][midC] + dp2[midR][midC] - grid[midR][midC];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)，两次 DP 各遍历全矩阵
- 空间复杂度：O(mn)，DP 数组

## 关键点总结

1. 强制经过某中间点时，将路径分为两段分别求最短路
2. 中间点被两段都计算了一次，最终需要减去一次
3. 第二段 DP 逆向（从终点往回）求解
