## 题目描述

给定整数数组 `nums`，返回非递减子序列的数量（包含空子序列），结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public long countGoodSubsequences(int[] nums) {
        // 离散化
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        Map<Integer, Integer> rank = new HashMap<>();
        int idx = 0;
        for (int v : sorted) if (!rank.containsKey(v)) rank.put(v, idx++);
        int N = rank.size();

        // 树状数组维护以各值结尾的子序列数前缀和
        long[] bit = new long[N + 1];
        long[] dp = new long[N];  // dp[r] = 以 rank r 结尾的子序列数

        long ans = 1;  // 空子序列
        for (int v : nums) {
            int r = rank.get(v);
            long cnt = (query(bit, r) + 1) % MOD;  // 前缀和 + 新开一个
            long delta = (cnt - dp[r] + MOD) % MOD;
            dp[r] = cnt;
            update(bit, r, delta, N);
            ans = (ans + delta) % MOD;
        }
        return ans;
    }

    private void update(long[] bit, int i, long delta, int N) {
        i++;
        while (i <= N) {
            bit[i] = (bit[i] + delta) % MOD;
            i += i & (-i);
        }
    }

    private long query(long[] bit, int i) {
        i++;
        long s = 0;
        while (i > 0) {
            s = (s + bit[i]) % MOD;
            i -= i & (-i);
        }
        return s;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，树状数组每次更新/查询 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. `dp[v]` = 以值 `v` 结尾的非递减子序列数，等于以 `<= v` 结尾的子序列数 + 1
2. 树状数组维护前缀和，快速查询所有 `<= v` 的贡献
3. 同一值被更新时计算增量 `delta` 更新树状数组，避免重复计数
