## 题目描述

给定 DataFrame students，将列名 id、first、last、age 分别重命名为 student_id、first_name、last_name、age_in_years。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.rename(columns={'old': 'new', ...})` 通过字典映射重命名列。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.rename(columns={'id':'student_id', ...}) 通过字典映射重命名列

import java.util.*;

class Solution {
    // Java 中重命名 Map 的键（模拟列重命名）
    public List<Map<String, Object>> renameColumns(List<Map<String, Object>> students) {
        Map<String, String> renameMap = Map.of(
            "id", "student_id",
            "first", "first_name",
            "last", "last_name",
            "age", "age_in_years"
        );
        List<Map<String, Object>> result = new ArrayList<>();
        for (Map<String, Object> row : students) {
            Map<String, Object> newRow = new LinkedHashMap<>();
            for (Map.Entry<String, Object> entry : row.entrySet()) {
                String newKey = renameMap.getOrDefault(entry.getKey(), entry.getKey());
                newRow.put(newKey, entry.getValue());
            }
            result.add(newRow);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)，n 行 k 列
- **空间复杂度**：O(n × k)

## 关键点总结

1. `df.rename(columns=dict)` 通过字典映射重命名，未指定的列名不变
2. 直接赋值 `df.columns = [...]` 需要提供全部列名且顺序正确
3. Java 中 Map 没有直接的列重命名操作，需要手动遍历重建
