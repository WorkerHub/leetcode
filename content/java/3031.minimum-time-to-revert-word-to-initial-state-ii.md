## 题目描述

同3029但word长度扩大到10^6，需要Z函数O(N)预处理。

## 解题思路

Z函数预处理后，对每个t检查z[t*k]>=n-t*k是否成立。

## Java 代码实现

```java
class Solution {
    public int minimumTimeToInitialState(String word, int k) {
        int n = word.length();
        int[] z = zFunction(word);

        for (int t = 1; t <= (n + k - 1) / k; t++) {
            int start = t * k;
            if (start >= n) return t;
            if (z[start] >= n - start) return t;
        }
        return (n + k - 1) / k;
    }

    private int[] zFunction(String s) {
        int n = s.length();
        int[] z = new int[n];
        z[0] = n;
        int l = 0, r = 0;
        for (int i = 1; i < n; i++) {
            if (i < r) z[i] = Math.min(r - i, z[i - l]);
            while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) {
                z[i]++;
            }
            if (i + z[i] > r) { l = i; r = i + z[i]; }
        }
        return z;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **Z函数**：z[i]表示word[i:]与word的最长公共前缀长度
2. **恢复条件**：z[start]>=n-start
3. **start>=n全部替换**：直接返回t
