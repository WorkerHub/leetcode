## 题目描述

给定数组arr，对每个元素计算与所有相同值元素下标差的绝对值之和。

## 解题思路

分组处理：同值下标放一组，用前缀和O(k)计算每个位置的间距之和。左侧贡献=j*p-prefix[j]，右侧贡献=suffix-(k-1-j)*p。

## Java 代码实现

```java
class Solution {
    public long[] getDistances(int[] arr) {
        int n = arr.length;
        long[] result = new long[n];
        
        // 收集每个值的出现下标
        Map<Integer, List<Integer>> posMap = new HashMap<>();
        for (int i = 0; i < n; i++) {
            posMap.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }
        
        for (List<Integer> positions : posMap.values()) {
            int k = positions.size();
            // 前缀和
            long[] prefix = new long[k + 1];
            for (int j = 0; j < k; j++) {
                prefix[j + 1] = prefix[j] + positions.get(j);
            }
            
            for (int j = 0; j < k; j++) {
                long p = positions.get(j);
                // 左侧j个位置的贡献
                long left = j * p - prefix[j];
                // 右侧(k-1-j)个位置的贡献
                long right = (prefix[k] - prefix[j + 1]) - (long)(k - 1 - j) * p;
                result[(int)p] = left + right;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分组+前缀和**：将O(k^2)暴力变O(k)
2. **左右分开计算**：左侧 j*p - prefix[j]，右侧 suffix - (k-1-j)*p
3. **用long**：间距之和可能很大
