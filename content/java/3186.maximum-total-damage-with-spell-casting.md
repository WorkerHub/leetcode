## 题目描述

法师有 n 个法术，使用伤害值为 x 的法术后，伤害值为 x-2、x-1、x+1、x+2 的法术均不能使用，返回最大总伤害。

## 解题思路

统计每个唯一伤害值的总伤害，排序后做 DP。对每个唯一值 v，可以不选（继承前一个状态），也可以选（找最近一个 <= v-3 的前缀最优，用二分查找）。

## Java 代码实现

```java
class Solution {
    public long maximumTotalDamage(int[] power) {
        // 统计每个值的总伤害
        Map<Integer, Long> cntMap = new HashMap<>();
        for (int p : power) cntMap.merge(p, (long) p, Long::sum);

        int[] vals = cntMap.keySet().stream().mapToInt(x -> x).sorted().toArray();
        int n = vals.length;
        long[] sums = new long[n];
        for (int i = 0; i < n; i++) sums[i] = cntMap.get(vals[i]);

        // dp[i+1] = 考虑前 i+1 个唯一值时的最大总伤害
        long[] dp = new long[n + 1];
        for (int i = 0; i < n; i++) {
            // 不选 vals[i]
            dp[i + 1] = dp[i];
            // 选 vals[i]，找第一个 >= vals[i]-2 的位置 j，则 dp[j] 是可用的前缀
            int lo = 0, hi = i;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (vals[mid] >= vals[i] - 2) hi = mid;
                else lo = mid + 1;
            }
            // lo 是第一个 >= vals[i]-2 的下标，dp[lo] 是合法的前缀状态
            dp[i + 1] = Math.max(dp[i + 1], dp[lo] + sums[i]);
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 统计每个唯一值的总伤害（值 × 出现次数）
2. 类似打家劫舍，限制范围变为 ±2（选 v 则 v-2 到 v+2 都不可用）
3. 二分查找合法前驱：找第一个 >= v-2 的下标作为分割点
