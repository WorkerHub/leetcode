## 题目描述

若整数 `x` 能被其各位数字之和整除，则称其为 Harshad 数。若 `x` 是 Harshad 数，返回各位数字之和；否则返回 -1。

## 解题思路

计算各位数字之和，判断 x 是否能被整除。

## Java 代码实现

```java
class Solution {
    public int sumOfTheDigitsOfHarshadNumber(int x) {
        int s = 0, tmp = x;
        while (tmp > 0) {
            s += tmp % 10;
            tmp /= 10;
        }
        return x % s == 0 ? s : -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log x)
- 空间复杂度：O(1)

## 关键点总结

1. 计算各位数字之和后判断整除
2. 返回数字和而非布尔值
