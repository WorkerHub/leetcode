## 题目描述

将字符串 s 转换为 t，每次移动选一个位置循环右移 1 位，每个位置最多操作一次但可在不同轮次操作。最多 k 次移动内能否完成转换。

**示例：**
```
输入：s = "input", t = "ouput", k = 9
输出：true
```

## 解题思路

每个位置需要步数 d = (t[i]-s[i])%26。步数为 d 的第 c 次使用实际消耗 d+26*(c-1)，只要所有实际消耗 ≤ k。

## Java 代码实现

```java
class Solution {
    public boolean canConvertString(String s, String t, int k) {
        if (s.length() != t.length()) return false;
        
        // cnt[d] 记录步数 d 已使用的次数
        int[] cnt = new int[26];
        
        for (int i = 0; i < s.length(); i++) {
            int d = (t.charAt(i) - s.charAt(i) + 26) % 26;
            if (d == 0) continue;
            // 实际需要的移动步数
            int actual = d + 26 * cnt[d];
            if (actual > k) return false;
            cnt[d]++;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **循环右移**：步数 d = (t[i]-s[i]+26)%26
2. **轮次累加**：相同步数第 c 次需要 d+26*(c-1) 步
3. **d=0 跳过**：不需要操作的位置
