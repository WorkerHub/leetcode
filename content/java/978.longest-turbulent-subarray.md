## 题目描述

给定整数数组 arr，返回最大湍流子数组的长度。湍流子数组要求相邻元素的比较符号交替翻转。

**示例：**
```
输入：arr = [9,4,2,10,7,8,8,1,9]
输出：5
解释：arr[1] > arr[2] < arr[3] > arr[4] < arr[5]
```

## 解题思路

动态规划：维护以当前位置结尾的递增长度 inc 和递减长度 dec。若当前大于前一个，则 inc = dec + 1；若小于，则 dec = inc + 1。

## Java 代码实现

```java
class Solution {
    public int maxTurbulenceSize(int[] arr) {
        int n = arr.length;
        if (n <= 1) return n;

        int inc = 1, dec = 1;
        int maxLen = 1;

        for (int i = 1; i < n; i++) {
            if (arr[i] > arr[i - 1]) {
                inc = dec + 1;
                dec = 1;
            } else if (arr[i] < arr[i - 1]) {
                dec = inc + 1;
                inc = 1;
            } else {
                inc = 1;
                dec = 1;
            }
            maxLen = Math.max(maxLen, Math.max(inc, dec));
        }

        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **交替状态**：inc 和 dec 交替转换
2. **相等归零**：相邻相等时重置为 1
3. **O(1) 空间**：只需两个变量跟踪状态
