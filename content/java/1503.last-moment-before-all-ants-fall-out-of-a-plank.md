## 题目描述

长度 n 的木板，蚂蚁以 1/秒移动，相遇时掉头。给定向左和向右的蚂蚁位置，求最后一只掉落的时刻。

**示例：**
```
输入：n = 4, left = [4,3], right = [0,1]
输出：4
```

## 解题思路

脑筋急转弯：相遇掉头等效于穿过彼此。向左的掉落时间 = 位置，向右的 = n - 位置。取最大值。

## Java 代码实现

```java
class Solution {
    public int getLastMoment(int n, int[] left, int[] right) {
        int maxTime = 0;
        for (int pos : left) {
            maxTime = Math.max(maxTime, pos);
        }
        for (int pos : right) {
            maxTime = Math.max(maxTime, n - pos);
        }
        return maxTime;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **等价转换**：相遇掉头 = 穿过（蚂蚁不可区分）
2. **向左**：掉落时间 = 当前位置
3. **向右**：掉落时间 = n - 当前位置
4. **答案**：所有时间的最大值
