## 题目描述

给定奖励值数组 `rewardValues`，每个奖励最多获取 `k` 次（k <= 3）；获取规则：当前总奖励 `x` 严格小于 `v` 时才能获取 `v`，总奖励增加 `v`，返回最大总奖励。

## Java 代码实现

```java
import java.math.BigInteger;
import java.util.*;

class Solution {
    public int maxReward(int[] rewardValues, int k) {
        // 每个值最多保留 min(count, k) 个
        Map<Integer, Integer> cnt = new TreeMap<>();
        for (int v : rewardValues) cnt.merge(v, 1, Integer::sum);
        List<Integer> vals = new ArrayList<>();
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int times = Math.min(e.getValue(), k);
            for (int i = 0; i < times; i++) vals.add(e.getKey());
        }

        // 位集 DP：dp 的第 i 位为 1 表示总奖励 i 可达
        // dp |= (dp & ((1<<v)-1)) << v
        BigInteger dp = BigInteger.ONE; // 第 0 位为 1，初始总奖励 0 可达
        for (int v : vals) {
            BigInteger mask = BigInteger.ONE.shiftLeft(v).subtract(BigInteger.ONE);
            dp = dp.or(dp.and(mask).shiftLeft(v));
        }
        return dp.bitLength() - 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k * maxVal / 64)
- 空间复杂度：O(maxVal / 64)

## 关键点总结

1. 位集 DP：dp 的第 i 位为 1 表示总奖励 i 可达，初始 dp=1（第 0 位）
2. 对每个奖励值 v，掩码 `(1<<v)-1` 提取小于 v 的所有可达状态，左移 v 位并入 dp
3. 每个值最多使用 min(count, k) 次，通过重复添加到列表实现
