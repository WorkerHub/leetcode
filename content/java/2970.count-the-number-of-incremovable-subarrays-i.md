## 题目描述

给你整数数组 `nums`，若删除某子数组后剩余元素严格递增，则称该子数组为递增可删除子数组，返回其总数。

## 解题思路

枚举所有 (l, r)，检查删除 nums[l..r] 后的三个条件：左段递增、右段递增、连接处 nums[l-1] < nums[r+1]。n <= 50 时 O(n²) 足够。

## Java 代码实现

```java
class Solution {
    public int incremovableSubarrayCount(int[] nums) {
        int n = nums.length, ans = 0;

        for (int l = 0; l < n; l++) {
            // 检查左段 nums[0..l-1] 是否严格递增
            boolean leftOk = true;
            for (int i = 1; i < l; i++) {
                if (nums[i - 1] >= nums[i]) { leftOk = false; break; }
            }
            if (!leftOk) break; // 左段不递增则之后的 l 也不行

            for (int r = l; r < n; r++) {
                // 检查右段 nums[r+1..n-1] 是否严格递增
                boolean rightOk = true;
                for (int i = r + 2; i < n; i++) {
                    if (nums[i - 1] >= nums[i]) { rightOk = false; break; }
                }
                if (!rightOk) continue;
                // 检查连接处
                if (l > 0 && r < n - 1 && nums[l - 1] >= nums[r + 1]) continue;
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. 三个条件：左段递增、右段递增、连接处严格递增
2. 左段不递增时右侧的 l 也不满足，可直接 break
3. 删除整个数组也合法（剩余为空视为递增）
