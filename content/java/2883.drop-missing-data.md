## 题目描述

给定 DataFrame students，删除 name 列中含有缺失值（NaN）的行。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.dropna(subset='name')` 删除指定列含空值的行。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.dropna(subset='name') 等价于过滤 name 不为 null 的行

import java.util.*;

class Solution {
    // Java 中过滤 name 不为 null 或空的行
    public List<String[]> dropMissingData(List<String[]> students) {
        // students[i] = [id, name, age]，name 可能为 null
        List<String[]> result = new ArrayList<>();
        for (String[] row : students) {
            if (row[1] != null && !row[1].isEmpty()) {
                result.add(row);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `df.dropna(subset=col)` 删除指定列有 NaN 的行
2. `df['col'].notna()` 返回非空值的布尔序列，可用于布尔索引
3. Java 中 null 或空字符串对应 Pandas 的 NaN
