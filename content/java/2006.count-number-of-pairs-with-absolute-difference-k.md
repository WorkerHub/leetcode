## 题目描述

给定整数数组 `nums` 和整数 `k`，返回满足 `i < j` 且 `|nums[i] - nums[j]| == k` 的数对数目。

## 解题思路

遍历每个元素 x，在哈希表中查找已出现过的 `x-k` 和 `x+k` 的频次累加，然后将 x 加入哈希表（先查后插保证 i < j）。

## Java 代码实现

### 方法一：哈希表计数（推荐）

```java
import java.util.*;

class Solution {
    public int countKDifference(int[] nums, int k) {
        int count = 0;
        Map<Integer, Integer> freq = new HashMap<>();

        for (int x : nums) {
            // 查找已遍历元素中与x差值为k的
            count += freq.getOrDefault(x - k, 0);
            count += freq.getOrDefault(x + k, 0);
            freq.merge(x, 1, Integer::sum);
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `|a - b| == k` 等价于 `b == a-k` 或 `b == a+k`
2. 先查询再插入当前元素，天然保证 i < j
3. n <= 200 时暴力 O(n²) 也可行
