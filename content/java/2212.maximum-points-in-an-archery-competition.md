## 题目描述

Bob有numArrows支箭，分配到12个区域以赢得分数（严格多于Alice即得该区域分），求最大得分的分配方案。

## 解题思路

2^12=4096种方案暴力枚举。对每种位掩码计算所需箭数和得分，选得分最大且箭数不超标的方案，剩余箭给区域0。

## Java 代码实现

```java
class Solution {
    public int[] maximumBobPoints(int numArrows, int[] aliceArrows) {
        int bestScore = 0, bestMask = 0;
        
        for (int mask = 1; mask < (1 << 12); mask++) {
            int arrowsUsed = 0, score = 0;
            for (int i = 0; i < 12; i++) {
                if ((mask >> i & 1) == 1) {
                    arrowsUsed += aliceArrows[i] + 1;
                    score += i;
                }
            }
            if (arrowsUsed <= numArrows && score > bestScore) {
                bestScore = score;
                bestMask = mask;
            }
        }
        
        // 构建答案
        int[] ans = new int[12];
        int remaining = numArrows;
        for (int i = 0; i < 12; i++) {
            if ((bestMask >> i & 1) == 1) {
                ans[i] = aliceArrows[i] + 1;
                remaining -= ans[i];
            }
        }
        ans[0] += remaining; // 剩余箭给区域0
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^12 * 12)，常数级
- **空间复杂度**：O(1)

## 关键点总结

1. **12区域暴力可行**：4096种方案全枚举
2. **赢区域i需花费**：aliceArrows[i]+1支箭
3. **剩余箭归区域0**：满足用完所有箭的要求
