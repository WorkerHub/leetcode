## 题目描述

汽车从起点出发驶向目的地，该目的地位于出发位置东面 target 英里处。

沿途有加油站，用数组 stations 表示。其中 stations[i] = [positioni, fueli] 表示第 i 个加油站位于出发位置东面 positioni 英里处，并且有 fueli 升汽油。

假设汽车油箱的容量是无限的，其中最初有 startFuel 升燃料。它每行驶 1 英里就会用掉 1 升汽油。当汽车到达加油站时，它可能停下来加油，将所有汽油从加油站转移到汽车中。

为了到达目的地，汽车所必要的最低加油次数是多少？如果无法到达目的地，则返回 -1 。

**示例 1：**
```
输入：target = 1, startFuel = 1, stations = []
输出：0
```

**示例 2：**
```
输入：target = 100, startFuel = 1, stations = [[10,100]]
输出：-1
```

**示例 3：**
```
输入：target = 100, startFuel = 10, stations = [[10,60],[20,30],[30,30],[60,40]]
输出：2
```

**提示：**
- 1 <= target, startFuel <= 10^9
- 0 <= stations.length <= 500
- 1 <= positioni < positioni+1 < target
- 1 <= fueli < 10^9

## 解题思路

### 方法一思路：贪心 + 最大堆

**核心思想：**
- 尽可能少加油，每次加油选择之前经过的油量最大的加油站

**算法流程：**
1. 用最大堆存储经过但未加油的加油站
2. 模拟行驶过程
3. 当油不够时，选择堆中油量最大的站加油
4. 记录加油次数

## Java 代码实现

### 方法一：贪心 + 最大堆（推荐）

```java
class Solution {
    public int minRefuelStops(int target, int startFuel, int[][] stations) {
        // 最大堆，存储燃料量
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        int fuel = startFuel;
        int count = 0;
        int i = 0;

        while (fuel < target) {
            // 将所有能到达的加油站加入堆
            while (i < stations.length && stations[i][0] <= fuel) {
                maxHeap.offer(stations[i][1]);
                i++;
            }

            // 如果没有可用的加油站，无法到达
            if (maxHeap.isEmpty()) {
                return -1;
            }

            // 选择油量最大的加油站
            fuel += maxHeap.poll();
            count++;
        }

        return count;
    }
}
```

**代码说明：**
- 用最大堆动态维护可以选择的加油站
- 只有在"油不够"时才加油，每次选最多的
- 这样保证加油次数最少

### 方法二：动态规划

```java
class Solution {
    public int minRefuelStops(int target, int startFuel, int[][] stations) {
        int n = stations.length;
        // dp[i] 表示加 i 次油能到达的最远距离
        long[] dp = new long[n + 1];
        dp[0] = startFuel;

        for (int i = 0; i < n; i++) {
            // 从后往前更新，避免重复使用
            for (int j = i; j >= 0; j--) {
                if (dp[j] >= stations[i][0]) {
                    dp[j + 1] = Math.max(dp[j + 1], dp[j] + stations[i][1]);
                }
            }
        }

        // 找到最少加油次数
        for (int i = 0; i <= n; i++) {
            if (dp[i] >= target) {
                return i;
            }
        }

        return -1;
    }
}
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n log n)，堆操作
- **空间复杂度**：O(n)

### 方法二：
- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：需要加油时，选择之前经过的油量最大的站
2. **最大堆**：动态维护可用的加油站（Java 中用 reverseOrder）
3. **DP 状态**：`dp[i]` 表示加 i 次油的最远距离
4. **模拟过程**：按顺序处理每个加油站

## 易错点

1. **Java 最大堆**：`new PriorityQueue<>(Collections.reverseOrder())`
2. **DP 更新顺序**：必须从后往前，避免重复使用同一个站
3. **边界条件**：startFuel 就能到达目标
