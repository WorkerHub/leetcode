## 题目描述

给你整数数组 `nums`，通过重新排列元素后拼接成字符串，返回能形成的最大整数（字符串形式）。

## 解题思路

自定义排序：对于两个数字字符串 `a` 和 `b`，若 `a+b > b+a` 则 `a` 应排在前面。全为 0 时返回 "0"。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String largestNumber(int[] nums) {
        String[] strs = new String[nums.length];
        for (int i = 0; i < nums.length; i++) strs[i] = String.valueOf(nums[i]);

        // 自定义比较：拼接后字符串较大的排前面
        Arrays.sort(strs, (a, b) -> (b + a).compareTo(a + b));

        // 处理全 0 的情况
        if (strs[0].equals("0")) return "0";
        return String.join("", strs);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n × L)，L 为数字平均位数
- **空间复杂度**：O(n)

## 关键点总结

1. 核心：用拼接后字符串大小定义排序顺序，而非直接比较数值
2. `(b + a).compareTo(a + b)` 实现降序排列
3. 全 0 输入需特殊处理，避免输出 "000..."
