## 题目描述

给你一棵根为 0 的树，边上有小写字母标签，统计路径上字符可以重排为回文串的节点对数 `(u, v)`（u < v）的总数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    List<List<Integer>> children;
    String s;
    Map<Integer, Integer> maskCount;
    long ans;

    public long countPalindromePaths(int[] parent, String s) {
        int n = parent.length;
        this.s = s;
        children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parent[i]).add(i);

        maskCount = new HashMap<>();
        maskCount.put(0, 1); // 根节点掩码为 0
        ans = 0;
        dfs(0, 0);
        return ans;
    }

    void dfs(int node, int mask) {
        // 统计与当前节点可配对的节点数（XOR=0 或 XOR=2^i）
        ans += maskCount.getOrDefault(mask, 0);
        for (int i = 0; i < 26; i++) {
            ans += maskCount.getOrDefault(mask ^ (1 << i), 0);
        }
        maskCount.merge(mask, 1, Integer::sum);
        for (int child : children.get(node)) {
            int bit = s.charAt(child) - 'a';
            dfs(child, mask ^ (1 << bit));
        }
        // 回溯
        maskCount.merge(mask, -1, Integer::sum);
    }
}
```

## 复杂度分析

- 时间复杂度：O(26n)
- 空间复杂度：O(n)

## 关键点总结

1. 根到节点的路径用 26 位掩码记录每个字母出现的奇偶性
2. 两节点路径掩码 = 两掩码 XOR（公共前缀抵消）
3. XOR 结果至多一位为 1 时路径字符可组成回文
