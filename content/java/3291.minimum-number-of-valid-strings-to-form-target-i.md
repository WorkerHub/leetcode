## 题目描述

给你字符串数组 `words` 和字符串 `target`，从 words 中任意选取前缀拼接成 target，返回所需最少前缀数量，无法形成返回 -1。

## 解题思路

字典树 + DP：建字典树存储所有 words，`dp[i]` 为构成 `target[0..i-1]` 的最少前缀数。对每个位置 i 从字典树出发匹配，将所有可达位置 j+1 的 dp 值更新。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minValidStrings(String[] words, String target) {
        int n = target.length();
        // 构建字典树，-1 表示无子节点
        List<int[]> trie = new ArrayList<>();
        int[] root = new int[26];
        Arrays.fill(root, -1);
        trie.add(root);

        for (String word : words) {
            int node = 0;
            for (char c : word.toCharArray()) {
                int ci = c - 'a';
                if (trie.get(node)[ci] == -1) {
                    int[] newNode = new int[26];
                    Arrays.fill(newNode, -1);
                    trie.add(newNode);
                    trie.get(node)[ci] = trie.size() - 1;
                }
                node = trie.get(node)[ci];
            }
        }

        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            if (dp[i] == Integer.MAX_VALUE) continue;
            int node = 0;
            for (int j = i; j < n; j++) {
                int ci = target.charAt(j) - 'a';
                if (trie.get(node)[ci] == -1) break;
                node = trie.get(node)[ci];
                dp[j + 1] = Math.min(dp[j + 1], dp[i] + 1);
            }
        }
        return dp[n] == Integer.MAX_VALUE ? -1 : dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n² + Σ|words|)
- 空间复杂度：O(Σ|words| × 26 + n)

## 关键点总结

1. 字典树从每个位置匹配所有 words 的前缀，找出所有可达位置
2. dp[i] = 构成 target 前 i 个字符的最少前缀数
3. 匹配的是 words 的前缀，不是完整单词
