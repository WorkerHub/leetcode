## 题目描述

给你整数数组 `nums`，将数组按每个值的频率**升序**排序。如果多个值频率相同，按数值本身**降序**排序。

## 解题思路

用 HashMap 统计频率，自定义排序键：频率升序，频率相同时值降序。

## Java 代码实现

```java
class Solution {
    public int[] frequencySort(int[] nums) {
        // 统计每个元素的频率
        Map<Integer, Integer> freq = new HashMap<>();
        for (int num : nums) {
            freq.merge(num, 1, Integer::sum);
        }

        // 将 int[] 转为 Integer[] 以使用自定义比较器
        Integer[] arr = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) arr[i] = nums[i];

        // 排序：频率升序，频率相同时值降序
        Arrays.sort(arr, (a, b) -> {
            int fa = freq.get(a), fb = freq.get(b);
            if (fa != fb) return fa - fb; // 频率升序
            return b - a; // 值降序
        });

        // 转回 int[]
        for (int i = 0; i < nums.length; i++) nums[i] = arr[i];
        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. HashMap 统计频率
2. 自定义 Comparator：频率升序，同频率时值降序
3. Java 对基本类型数组无法直接用 Comparator，需先转为 Integer[]
