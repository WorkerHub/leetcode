## 题目描述

给定整数数组，返回位数为偶数的数字个数。

**示例：**
```
输入：nums = [12,345,2,6,7896]
输出：2
解释：12(2位) 和 7896(4位) 是偶数位数
```

## 解题思路

对每个数计算位数（转字符串或循环除 10），判断位数是否为偶数。

## Java 代码实现

```java
class Solution {
    public int findNumbers(int[] nums) {
        int count = 0;
        for (int num : nums) {
            if (String.valueOf(num).length() % 2 == 0) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **位数判断**：转字符串取长度最简洁
2. **数学方法**：也可用 log10 或循环除 10
3. **偶数判断**：长度 % 2 == 0
