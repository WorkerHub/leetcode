## 题目描述

给定整数数组 `nums`、起始值 `start` 和目标值 `target`，每步可对当前值加或减 `nums` 中任意元素，返回从 `start` 到达 `target` 的最少步数。

## 解题思路

BFS 从 `start` 出发，每步可以加或减 `nums` 中任意元素，找到 `target` 的最短路径。值域有限（约 [-2000, 2000]），用哈希集合记录访问过的值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minSteps(int[] nums, int start, int target) {
        if (start == target) return 0;

        Set<Integer> visited = new HashSet<>();
        Queue<Integer> queue = new LinkedList<>();
        visited.add(start);
        queue.offer(start);
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                for (int v : nums) {
                    // 加或减 nums[v]，得到两个新值
                    int[] nexts = {curr + v, curr - v};
                    for (int next : nexts) {
                        if (next == target) return steps;
                        if (!visited.contains(next)) {
                            visited.add(next);
                            queue.offer(next);
                        }
                    }
                }
            }
        }

        return -1; // 不可达
    }
}
```

## 复杂度分析

- 时间复杂度：O(R * n)，R 为值域大小，n 为 nums 长度
- 空间复杂度：O(R)，已访问集合

## 关键点总结

1. BFS 保证最少步数，每步可以选任意 nums[i] 加或减。
2. 值域有限，可以用哈希集合记录已访问避免重复。
3. 双向 BFS 可以将搜索空间从 O(b^d) 降到 O(b^(d/2))。
