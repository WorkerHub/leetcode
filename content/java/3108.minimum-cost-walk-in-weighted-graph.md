## 题目描述

给你 n 个顶点的无向加权图，路径开销为路径上所有边权重的按位与。对每个查询 [s, t] 返回最小开销路径，不存在路径返回 -1。

## 解题思路

按位与越多边只会越小，因此同一连通分量内最优开销 = 该分量所有边权的 AND。用并查集维护连通性，同时记录每个分量的边权 AND 值。

## Java 代码实现

```java
class Solution {
    int[] parent;

    public int[] minimumCost(int n, int[][] edges, int[][] query) {
        parent = new int[n];
        int[] compAnd = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; compAnd[i] = (1 << 17) - 1; }

        for (int[] e : edges) {
            int pu = find(e[0]), pv = find(e[1]);
            compAnd[pu] &= e[2];
            compAnd[pv] &= e[2];
            if (pu != pv) {
                parent[pu] = pv;
                compAnd[pv] &= compAnd[pu];
            }
        }

        int[] ans = new int[query.length];
        for (int i = 0; i < query.length; i++) {
            int s = query[i][0], t = query[i][1];
            if (find(s) != find(t)) ans[i] = -1;
            else if (s == t) ans[i] = 0;
            else ans[i] = compAnd[find(s)];
        }
        return ans;
    }

    private int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m + q) * alpha(n))
- 空间复杂度：O(n)

## 关键点总结

1. AND 单调不增，走更多边开销不会变大
2. 并查集合并时同步维护 AND 值，初始为全 1
3. s == t 时开销为 0
