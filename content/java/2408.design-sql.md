## 题目描述

设计 SQL 类，支持创建表、插入行（行 ID 自增）、删除行、查询指定行列的值。

## 解题思路

用 HashMap 存储每张表的数据：`tables` 映射表名到 `{行ID -> 行数据}`，`nextId` 记录每张表的下一个行 ID（删除后不回滚）。

## Java 代码实现

```java
class SQL {
    private Map<String, Map<Integer, List<String>>> tables;
    private Map<String, Integer> nextId;

    public SQL(List<String> names, List<Integer> columns) {
        tables = new HashMap<>();
        nextId = new HashMap<>();
        for (String name : names) {
            tables.put(name, new HashMap<>());
            nextId.put(name, 1);
        }
    }

    public void insertRow(String name, List<String> row) {
        int id = nextId.get(name);
        tables.get(name).put(id, row);
        nextId.put(name, id + 1); // 自增，不因删除回退
    }

    public void deleteRow(String name, int rowId) {
        tables.get(name).remove(rowId);
    }

    public String selectCell(String name, int rowId, int columnId) {
        return tables.get(name).get(rowId).get(columnId - 1); // 列 ID 从 1 开始
    }
}
```

## 复杂度分析

- **时间复杂度**：insertRow/deleteRow/selectCell 均 O(1)
- **空间复杂度**：O(总行数 * 最大列数)

## 关键点总结

1. 行 ID 自增且不因删除回退，需单独维护计数器。
2. HashMap 支持 O(1) 的插入、删除、查找。
3. 列 ID 从 1 开始，访问列表时需减 1。
