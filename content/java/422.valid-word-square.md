## 题目描述

给你一个单词序列，判断其是否形成了一个有效的单词方块。

有效的单词方块是指此由单词序列组成的文字方块的第 k 行和第 k 列（0 ≤ k < max(行数, 列数)）所显示的字符串完全相同。

**注意：**
1. 给定的单词数至少为 1 且不超过 500
2. 单词长度至少为 1 且不超过 500
3. 每个单词只包含小写英文字母

**示例 1：**
```
输入：
[
  "abcd",
  "bnrt",
  "crmy",
  "dtye"
]
输出：true
解释：
第 1 行和第 1 列都是 "abcd"
第 2 行和第 2 列都是 "bnrt"
第 3 行和第 3 列都是 "crmy"
第 4 行和第 4 列都是 "dtye"

因此，这是一个有效的单词方块。
```

**示例 2：**
```
输入：
[
  "abcd",
  "bnrt",
  "crm",
  "dt"
]
输出：true
解释：
第 1 行和第 1 列都是 "abcd"
第 2 行和第 2 列都是 "bnrt"
第 3 行和第 3 列都是 "crm"
第 4 行和第 4 列都是 "dt"

因此，这是一个有效的单词方块。
```

**示例 3：**
```
输入：
[
  "ball",
  "area",
  "read",
  "lady"
]
输出：false
解释：
第 3 列是 "read"，而第 3 行是 "read" 的不同排列 "lead"。
因此，这不是一个有效的单词方块。
```

## 解题思路

这道题要求判断单词序列是否构成有效的单词方块。核心是验证矩阵的对称性。

**关键观察：**
1. 有效的单词方块满足：`words[i][j] == words[j][i]`（当索引有效时）
2. 矩阵不一定是正方形，可能是矩形
3. 需要处理不同长度的单词（参差不齐的情况）

**算法流程：**
1. 遍历每个单词的每个字符
2. 检查对应位置的字符是否相等
3. 注意边界检查：索引不能越界

## Java 代码实现

### 方法一：直接模拟 ⭐ 推荐

```java
import java.util.List;

class Solution {
    public boolean validWordSquare(List<String> words) {
        // 遍历每一行
        for (int i = 0; i < words.size(); i++) {
            // 遍历当前行的每个字符
            for (int j = 0; j < words.get(i).length(); j++) {
                // 检查边界：第j行是否存在
                if (j >= words.size()) {
                    return false;
                }
                // 检查边界：第j行的第i个字符是否存在
                if (i >= words.get(j).length()) {
                    return false;
                }
                // 检查对称性
                if (words.get(i).charAt(j) != words.get(j).charAt(i)) {
                    return false;
                }
            }
        }

        return true;
    }
}
```

### 方法二：构造列字符串

```java
import java.util.List;

class Solution {
    public boolean validWordSquare(List<String> words) {
        int n = words.size();

        // 构造每一列的字符串
        for (int i = 0; i < n; i++) {
            StringBuilder col = new StringBuilder();
            for (int j = 0; j < n; j++) {
                if (i < words.get(j).length()) {
                    col.append(words.get(j).charAt(i));
                }
            }

            // 第i行应该等于第i列
            if (!words.get(i).equals(col.toString())) {
                return false;
            }
        }

        return true;
    }
}
```

### 方法三：简化版


## 复杂度分析

**方法一：直接模拟**
- 时间复杂度：O(n × m)，其中 n 是单词数量，m 是平均单词长度
  - 需要遍历所有字符进行比较
- 空间复杂度：O(1)

**方法二：构造列字符串**
- 时间复杂度：O(n × m)
- 空间复杂度：O(m)，需要存储列字符串

**方法三：简化版**
- 时间复杂度：O(n² × m)
- 空间复杂度：O(m)

## 关键点总结

1. **矩阵对称性**：本质是检查矩阵是否关于主对角线对称
2. **边界检查**：必须检查行列索引是否越界
3. **参差不齐**：单词长度可能不同，需要特别处理
4. **双向验证**：`words[i][j]` 和 `words[j][i]` 都要存在且相等
5. **提前返回**：发现不匹配立即返回 false，提高效率

## 易错点

1. **索引越界**：访问 `words[j][i]` 前必须检查 `j < words.size()` 和 `i < words.get(j).length()`
2. **不对称的矩形**：矩阵可能是 3×5 这样的矩形，不一定是正方形
3. **空字符串**：需要处理单词为空字符串的情况
4. **单向检查不够**：只检查行到列不够，还需要隐式验证列到行
5. **多余的列**：如果某行很长，需要确保对应的列也存在
