## 题目描述

给定两个等长整数数组 arr1 和 arr2，返回 `|arr1[i]-arr1[j]| + |arr2[i]-arr2[j]| + |i-j|` 的最大值。

**示例：**
```
输入：arr1 = [1,2,3,4], arr2 = [-1,4,5,6]
输出：13
```

## 解题思路

绝对值展开：三个绝对值有 8 种符号组合，由对称性简化为 4 种。每种情况形如 `f(i) - f(j)`，其最大值 = `max(f) - min(f)`。对 4 种情况取最大即可。

四种函数：`±arr1[i] ± arr2[i] + i`（符号组合 ++, +-, -+, --）

## Java 代码实现

```java
class Solution {
    public int maxAbsValExpr(int[] arr1, int[] arr2) {
        int n = arr1.length;
        int result = 0;

        // 四种符号组合：(s1*arr1[i] + s2*arr2[i] + i)
        int[][] signs = {{1, 1}, {1, -1}, {-1, 1}, {-1, -1}};

        for (int[] sign : signs) {
            int s1 = sign[0], s2 = sign[1];
            int maxVal = Integer.MIN_VALUE;
            int minVal = Integer.MAX_VALUE;

            for (int i = 0; i < n; i++) {
                int val = s1 * arr1[i] + s2 * arr2[i] + i;
                maxVal = Math.max(maxVal, val);
                minVal = Math.min(minVal, val);
            }

            result = Math.max(result, maxVal - minVal);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历 4 次数组
- **空间复杂度**：O(1)

## 关键点总结

1. **绝对值展开**：`|a-b| = max(a-b, b-a)`，多个绝对值枚举所有符号组合
2. **对称性简化**：8 种组合因 i,j 互换对称性简化为 4 种
3. **差值最大化**：`f(i)-f(j)` 的最大值 = `max(f) - min(f)`
4. **本质是三维曼哈顿距离最大值**
