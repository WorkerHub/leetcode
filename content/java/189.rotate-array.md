## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**
```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

**示例 2：**
```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释: 
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

**进阶：**
- 尽可能想出更多的解决方案，至少有三种不同的方法可以解决这个问题。
- 你能使用空间复杂度为 `O(1)` 的原地算法解决这个问题吗？

## 解题思路

这道题有多种解法，我们从简单到优化逐步讲解。

### 方法一：使用额外数组

最直观的方法：创建新数组，计算每个元素旋转后的位置。

### 方法二：三次反转（最优解）

核心思想：通过三次反转实现旋转，不需要额外空间。

观察规律：`[1,2,3,4,5,6,7]` 向右旋转 3 步得到 `[5,6,7,1,2,3,4]`

分解为三步：
1. 反转整个数组：`[7,6,5,4,3,2,1]`
2. 反转前 k 个元素：`[5,6,7,4,3,2,1]`
3. 反转后 n-k 个元素：`[5,6,7,1,2,3,4]`

**为什么有效？**
- 第一次反转：所有元素位置颠倒
- 第二次反转：将应该在前面的元素恢复正序
- 第三次反转：将应该在后面的元素恢复正序

### 方法三：环状替换

把数组看作环形，每个元素按照旋转规律放到目标位置。

## Java 代码实现

### 方法一：使用额外数组（最易理解）

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n; // 处理 k > n 的情况

        // 创建新数组
        int[] newNums = new int[n];

        // 计算每个元素旋转后的位置
        for (int i = 0; i < n; i++) {
            newNums[(i + k) % n] = nums[i];
        }

        // 复制回原数组
        System.arraycopy(newNums, 0, nums, 0, n);
    }
}
```

### 方法二：三次反转（推荐）

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n; // 优化：k 可能大于 n

        // 三次反转
        reverse(nums, 0, n - 1);  // 反转整个数组
        reverse(nums, 0, k - 1);  // 反转前 k 个
        reverse(nums, k, n - 1);  // 反转后 n-k 个
    }

    // 辅助方法：反转数组的指定区间
    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 方法三：环状替换（进阶）

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;

        int count = 0; // 已移动的元素个数

        for (int start = 0; count < n; start++) {
            int current = start;
            int prev = nums[start];

            // 处理一个环
            do {
                int next = (current + k) % n;
                int temp = nums[next];
                nums[next] = prev;
                prev = temp;
                current = next;
                count++;
            } while (start != current);
        }
    }
}
```

### 方法四：逐步旋转（暴力解法，不推荐）

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;

        // 每次将最后一个元素移到最前面，重复 k 次
        for (int i = 0; i < k; i++) {
            int last = nums[n - 1];
            for (int j = n - 1; j > 0; j--) {
                nums[j] = nums[j - 1];
            }
            nums[0] = last;
        }
    }
}
```

## 复杂度分析

**方法二（三次反转）：**
- **时间复杂度**：O(n)，每个元素被访问常数次
- **空间复杂度**：O(1)，只使用了常数个额外变量

**方法一（额外数组）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

**方法三（环状替换）：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

**方法四（暴力）：**
- **时间复杂度**：O(n × k)
- **空间复杂度**：O(1)

## 关键点总结

1. **取模优化**：`k = k % n`，避免不必要的旋转
2. **三次反转技巧**：这是数组旋转的经典算法
3. **原地修改**：Java 中直接修改数组元素，或使用 `System.arraycopy`
4. **边界情况**：k = 0 或 k = n 时，数组不变
5. **通用技巧**：反转在数组操作中应用广泛

## 易错点

1. **k 大于 n 的处理**：必须先取模
   ```java
   k = k % n; // 必须的优化
   ```

2. **Java 数组复制的正确方式**：
   ```java
   System.arraycopy(src, 0, dest, 0, n); // 正确
   // 或者用循环：for (int i = 0; i < n; i++) nums[i] = newNums[i];
   ```

3. **反转边界错误**：
   ```java
   reverse(nums, 0, k - 1);  // 正确：反转前 k 个（索引 0 到 k-1）
   reverse(nums, 0, k);      // 错误：会多反转一个
   ```

4. **k=0 时的特殊处理**：三次反转方法当 k=0 时，`reverse(0, -1)` 不会执行（left > right），所以自动处理了这种情况

5. **环状替换的终止条件**：需要用 count 记录已移动的元素数
   ```java
   int count = 0;
   // ...
   while (count < n); // 确保所有元素都被移动
   ```
