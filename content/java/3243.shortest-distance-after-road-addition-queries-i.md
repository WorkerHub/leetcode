## 题目描述

初始有一条从 0 到 n-1 的单向链路，每次查询添加一条有向边 `(ui, vi)`，返回每次添加后从节点 0 到节点 n-1 的最短路径长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] shortestDistanceAfterQueries(int n, int[][] queries) {
        // 初始图：0 -> 1 -> ... -> n-1
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int i = 0; i < n - 1; i++) graph[i].add(i + 1);

        int[] ans = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            graph[queries[q][0]].add(queries[q][1]);
            ans[q] = bfs(n, graph);
        }
        return ans;
    }

    private int bfs(int n, List<Integer>[] graph) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        dist[0] = 0;
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    queue.offer(v);
                }
            }
        }
        return dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(q * (n + q))，每次查询后做 BFS
- 空间复杂度：O(n + q)

## 关键点总结

1. 每次添加边后重新 BFS 求最短路
2. 图是有向图（所有边从小编号到大编号），BFS 保证无环
3. 数据范围小（n, q <= 500），直接重新 BFS 即可
