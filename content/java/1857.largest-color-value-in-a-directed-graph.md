## 题目描述

有向图中每个节点有一个颜色，求任意路径中某种颜色出现的最大次数。有环返回-1。

## 解题思路

拓扑排序+DP：dp[u][c]表示以u结尾的路径中颜色c的最大出现次数。拓扑排序逐节点更新，未处理完则有环。

## Java 代码实现

```java
class Solution {
    public int largestPathValue(String colors, int[][] edges) {
        int n = colors.length();
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[n];
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            inDegree[e[1]]++;
        }
        
        // dp[u][c] = 以u结尾的路径中颜色c的最大次数
        int[][] dp = new int[n][26];
        for (int u = 0; u < n; u++) {
            dp[u][colors.charAt(u) - 'a'] = 1;
        }
        
        // 拓扑排序BFS
        Queue<Integer> queue = new LinkedList<>();
        for (int u = 0; u < n; u++) {
            if (inDegree[u] == 0) queue.offer(u);
        }
        
        int processed = 0, ans = 0;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            processed++;
            for (int c = 0; c < 26; c++) ans = Math.max(ans, dp[u][c]);
            
            for (int v : graph.get(u)) {
                int vc = colors.charAt(v) - 'a';
                for (int c = 0; c < 26; c++) {
                    dp[v][c] = Math.max(dp[v][c], dp[u][c] + (c == vc ? 1 : 0));
                }
                if (--inDegree[v] == 0) queue.offer(v);
            }
        }
        return processed == n ? ans : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + M) × 26)
- **空间复杂度**：O(N × 26)

## 关键点总结

1. **拓扑排序+DP**：确保前驱已处理再更新
2. **26种颜色独立维护**：每个节点存26维数组
3. **环检测**：处理节点数<n则有环
