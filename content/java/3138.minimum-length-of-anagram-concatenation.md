## 题目描述

字符串s由某个字符串t的异位词重复拼接而成，求t的最小长度。

## 解题思路

t的长度必须是len(s)的因子。从小到大枚举因子d，将s切分为长度d的块，验证所有块的字符频率相同，找到第一个满足的即为答案。

## Java 代码实现

```java
class Solution {
    public int minAnagramLength(String s) {
        int n = s.length();
        for (int d = 1; d <= n; d++) {
            if (n % d != 0) continue;
            if (check(s, d)) return d;
        }
        return n;
    }

    private boolean check(String s, int d) {
        int[] base = new int[26];
        for (int i = 0; i < d; i++) base[s.charAt(i) - 'a']++;
        for (int i = d; i < s.length(); i += d) {
            int[] cur = new int[26];
            for (int j = i; j < i + d; j++) cur[s.charAt(j) - 'a']++;
            if (!Arrays.equals(base, cur)) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * d(N))，d(N)为因子数
- **空间复杂度**：O(1)

## 关键点总结

1. **t长度必为len(s)的因子**
2. **验证所有块字符频率相同**
3. **从小到大枚举，首个满足即最优**
