## 题目描述

字符串 word 可含重复字母，重新分配 26 个字母到 8 个按键，输入代价等于按键位置（1-indexed），返回输入 word 的最小总代价。

## 解题思路

贪心：频率越高的字母应分配到代价越低的位置。统计每字母频率，按频率降序排列，第 i 个（0-indexed）字母代价 = i/8+1。

## Java 代码实现

```java
class Solution {
    public int minimumPushes(String word) {
        int[] freq = new int[26];
        for (char c : word.toCharArray()) freq[c - 'a']++;
        // 按频率降序排列
        Arrays.sort(freq);
        int total = 0;
        // freq 升序，倒序遍历等价于降序
        for (int i = 25, rank = 0; i >= 0 && freq[i] > 0; i--, rank++) {
            total += freq[i] * (rank / 8 + 1);
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 26 log 26) = O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 频率最高的字母排前面，代价最小
2. 第 rank 个（0-indexed）字母代价 = rank/8+1
3. 与 3014 的区别：本题有重复字母，需按频率贪心
