## 题目描述

给你整数数组 `pizzas`，共 n 块。奇数天吃的披萨完整计入体重，偶数天只计入一半。可以任意安排顺序，求最大总体重增加量。

## 解题思路

贪心：奇数天有 `ceil(n/2)` 天，偶数天有 `floor(n/2)` 天。将 pizzas 降序排列，奇数天吃最重的前 `ceil(n/2)` 块，偶数天吃剩余中最重的 `floor(n/2)` 块（各取一半）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maxWeight(int[] pizzas) {
        int n = pizzas.length;
        Arrays.sort(pizzas);

        // 奇数天 ceil(n/2) 天，偶数天 floor(n/2) 天
        int oddDays = (n + 1) / 2;
        int evenDays = n / 2;

        long total = 0;
        // 奇数天：选最大的 oddDays 块（完整计入）
        for (int i = n - 1; i >= n - oddDays; i--) {
            total += pizzas[i];
        }
        // 偶数天：选接下来最大的 evenDays 块（各取一半）
        for (int i = n - oddDays - 1; i >= n - oddDays - evenDays; i--) {
            total += pizzas[i] / 2;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 奇数天完整计入，偶数天只计一半——奇数天应吃最重的
2. n 天中奇数天 ceil(n/2)，偶数天 floor(n/2)
3. 贪心：先分配最重的给奇数天，剩余给偶数天
