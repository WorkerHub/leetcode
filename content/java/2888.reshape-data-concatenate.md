## 题目描述

给定两个具有相同列结构的 DataFrame df1 和 df2，将它们垂直拼接（按行堆叠）。

## 解题思路

本题为 Python Pandas 专项练习，使用 `pd.concat([df1, df2], ignore_index=True)` 垂直拼接。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// pd.concat([df1, df2], ignore_index=True) 等价于列表合并

import java.util.*;

class Solution {
    // Java 中合并两个列表（垂直拼接）
    public <T> List<T> concatenateTables(List<T> df1, List<T> df2) {
        List<T> result = new ArrayList<>(df1);
        result.addAll(df2);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. `pd.concat([df1, df2], ignore_index=True)` 垂直拼接，重置行索引
2. `axis=1` 参数改为水平拼接（按列）
3. Java 中用 `addAll()` 合并两个列表
