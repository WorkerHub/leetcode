## 题目描述

将 `n` 个不同的学生分配到 `k` 个有区别的非空组中，求分配方式的总数，结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
class Solution {
    public int countWays(int n, int k) {
        final int MOD = 1_000_000_007;
        if (k > n) return 0;

        // dp[i][j]: 将 i 个学生分到 j 个有区别非空组的方案数
        // 转移：第 i 个学生加入已有 j 组之一，或单独开新组
        long[][] dp = new long[n + 1][k + 1];
        dp[0][0] = 1; // 0 个学生放入 0 个组，1 种方式

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= Math.min(i, k); j++) {
                // 加入已有组之一：j 种选择
                dp[i][j] = (j * dp[i - 1][j]) % MOD;
                // 单独开新组
                dp[i][j] = (dp[i][j] + dp[i - 1][j - 1]) % MOD;
            }
        }

        return (int) dp[n][k];
    }
}
```

## 复杂度分析

- 时间复杂度：O(nk)
- 空间复杂度：O(nk)，DP 数组

## 关键点总结

1. DP 转移式体现"每个新元素要么进已有组，要么单独开新组"
2. 等价于第二类 Stirling 数乘以 k!（有序划分）
3. k > n 时无法每组至少一人，直接返回 0
