## 题目描述

给定整数数组 `nums`，返回满足 `nums[a] + nums[b] + nums[c] == nums[d]` 且 `a < b < c < d` 的四元组数目。

## 解题思路

枚举 c，对每个 c 将 `b = c-1` 的所有 `(a, b)` 对之和加入哈希表，再枚举 d，查找 `nums[d] - nums[c]` 是否在哈希表中。

## Java 代码实现

### 方法一：哈希表优化（推荐）

```java
import java.util.*;

class Solution {
    public int countQuadruplets(int[] nums) {
        int n = nums.length;
        int ans = 0;
        // cnt[v] = nums[a]+nums[b]=v 的对数，a<b<当前c
        Map<Integer, Integer> cnt = new HashMap<>();

        for (int c = 2; c < n - 1; c++) {
            // 新加入 b = c-1 与所有 a < b 形成的对
            for (int a = 0; a < c - 1; a++) {
                int sum = nums[a] + nums[c - 1];
                cnt.merge(sum, 1, Integer::sum);
            }
            // 枚举 d（d > c）
            for (int d = c + 1; d < n; d++) {
                int target = nums[d] - nums[c];
                if (target >= 0) {
                    ans += cnt.getOrDefault(target, 0);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²)
- 空间复杂度：O(n²)

## 关键点总结

1. `n <= 50`，暴力 O(n^4) 也可行，哈希表优化至 O(n²)
2. 固定 c，维护所有 `(a, b)` 对之和，枚举 d 查目标值
3. `target = nums[d] - nums[c]` 需保证 >= 0
