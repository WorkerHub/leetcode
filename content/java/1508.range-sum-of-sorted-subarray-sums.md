## 题目描述

求所有非空连续子数组的和，升序排列后，返回下标 left 到 right 的元素和（mod 10^9+7）。

**示例：**
```
输入：nums = [1,2,3,4], n = 4, left = 1, right = 5
输出：13
```

## 解题思路

暴力枚举所有子数组和，排序后求区间和。n≤1000，子数组数最多 500500，可接受。

## Java 代码实现

```java
class Solution {
    public int rangeSum(int[] nums, int n, int left, int right) {
        int MOD = 1_000_000_007;
        int total = n * (n + 1) / 2;
        int[] sums = new int[total];
        int idx = 0;
        
        for (int i = 0; i < n; i++) {
            int sum = 0;
            for (int j = i; j < n; j++) {
                sum += nums[j];
                sums[idx++] = sum;
            }
        }
        
        Arrays.sort(sums);
        
        long result = 0;
        for (int i = left - 1; i < right; i++) {
            result = (result + sums[i]) % MOD;
        }
        return (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² log n)
- **空间复杂度**：O(n²)

## 关键点总结

1. **枚举子数组和**：双重循环，前缀累加
2. **排序**：得到有序的子数组和
3. **区间求和**：取 [left-1, right-1] 的和
4. **取模**：防止溢出
