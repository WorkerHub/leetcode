## 题目描述

每位只能为 0 或 1 的十进制数称为**十进制二进制数**。给字符串 `n`，返回和为 `n` 的十进制二进制数的最少数量。

## 解题思路

**贪心：** 每个十进制二进制数每位只能贡献 0 或 1，凑出某位数字 `d` 至少需要 `d` 个数。答案为 `n` 中各位数字的最大值。

## Java 代码实现

```java
class Solution {
    public int minPartitions(String n) {
        int maxDigit = 0;
        for (char c : n.toCharArray()) {
            maxDigit = Math.max(maxDigit, c - '0');
            if (maxDigit == 9) break; // 提前退出
        }
        return maxDigit;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|n|)
- **空间复杂度**：O(1)

## 关键点总结

1. 各位最多需要该位数字个数的十进制二进制数
2. 答案 = `n` 中最大的数字
