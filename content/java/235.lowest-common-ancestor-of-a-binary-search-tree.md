## 题目描述

给定一个二叉搜索树（BST），找到该树中两个指定节点的最近公共祖先（LCA）。

最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。"

**示例 1：**
```
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6
解释：节点 2 和节点 8 的最近公共祖先是 6。
```

**示例 2：**
```
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4
输出：2
解释：节点 2 和节点 4 的最近公共祖先是 2，因为根据定义最近公共祖先节点可以为节点本身。
```

**示例 3：**
```
输入：root = [2,1], p = 2, q = 1
输出：2
```

**提示：**
- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 均存在于给定的二叉搜索树中

## 解题思路

这道题的关键是利用二叉搜索树（BST）的性质。

**BST 的性质：**
- 左子树的所有节点值 < 根节点值
- 右子树的所有节点值 > 根节点值

**核心思想：**

由于 BST 的有序性，我们可以通过比较节点值来判断：

1. **如果 p 和 q 都小于当前节点**：LCA 在左子树
2. **如果 p 和 q 都大于当前节点**：LCA 在右子树
3. **如果 p 和 q 分别在当前节点两侧**（或其中一个就是当前节点）：当前节点就是 LCA

**为什么第 3 种情况是 LCA？**
- 这是第一个满足 p、q 在不同子树的节点
- 再往下走，p 和 q 会在同一侧，不可能是 LCA

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode(int x) { val = x; }
// }

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 递归方法：利用 BST 的性质
        // 如果 p 和 q 都小于 root，LCA 在左子树
        if (p.val < root.val && q.val < root.val) {
            return lowestCommonAncestor(root.left, p, q);
        }

        // 如果 p 和 q 都大于 root，LCA 在右子树
        if (p.val > root.val && q.val > root.val) {
            return lowestCommonAncestor(root.right, p, q);
        }

        // 否则，root 就是 LCA
        // 这包括三种情况：
        // 1. p 和 q 分别在 root 两侧
        // 2. p 或 q 就是 root
        // 3. p 和 q 相等（虽然题目说 p != q）
        return root;
    }
}
```

### 方法二：迭代（推荐）⭐

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 迭代方法：不使用递归栈
        TreeNode node = root;

        while (node != null) {
            // p 和 q 都在左子树
            if (p.val < node.val && q.val < node.val) {
                node = node.left;
            }
            // p 和 q 都在右子树
            else if (p.val > node.val && q.val > node.val) {
                node = node.right;
            }
            // 找到 LCA
            else {
                return node;
            }
        }

        return null;
    }
}
```

### 方法三：递归简化版

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 更简洁的递归写法
        // 确保 p.val <= q.val，简化判断
        int minVal = Math.min(p.val, q.val);
        int maxVal = Math.max(p.val, q.val);

        // 如果 root 在 [minVal, maxVal] 范围内，root 就是 LCA
        if (root.val >= minVal && root.val <= maxVal) {
            return root;
        }

        // 如果 root 大于 maxVal，LCA 在左子树
        if (root.val > maxVal) {
            return lowestCommonAncestor(root.left, p, q);
        }

        // 如果 root 小于 minVal，LCA 在右子树
        return lowestCommonAncestor(root.right, p, q);
    }
}
```

### 方法四：一次遍历（记录路径）

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 记录从 root 到 p 和 q 的路径，找到最后一个公共节点
        List<TreeNode> pathP = getPath(root, p);
        List<TreeNode> pathQ = getPath(root, q);

        // 找到最后一个公共节点
        TreeNode lca = null;
        int len = Math.min(pathP.size(), pathQ.size());
        for (int i = 0; i < len; i++) {
            if (pathP.get(i) == pathQ.get(i)) {
                lca = pathP.get(i);
            } else {
                break;
            }
        }

        return lca;
    }

    // 获取从 root 到目标节点的路径
    private List<TreeNode> getPath(TreeNode root, TreeNode target) {
        List<TreeNode> path = new ArrayList<>();
        TreeNode node = root;
        while (node != target) {
            path.add(node);
            if (target.val < node.val) {
                node = node.left;
            } else {
                node = node.right;
            }
        }
        path.add(node);
        return path;
    }
}
```

## 复杂度分析

**方法一、二（递归/迭代）：**
- 时间复杂度：O(h)，h 为树的高度
  - 最好情况（平衡树）：O(log n)
  - 最坏情况（链状树）：O(n)
- 空间复杂度：
  - 递归：O(h)，递归栈
  - 迭代：O(1)

**方法四（记录路径）：**
- 时间复杂度：O(h)
- 空间复杂度：O(h)，存储路径

## 图解示例

```
示例树：
        6
       / \
      2   8
     / \ / \
    0  4 7  9
      / \
     3   5

查找 p = 2, q = 8 的 LCA：

步骤 1：从 root = 6 开始
  p(2) < 6 < q(8)
  p 和 q 分别在 6 的两侧
  返回 6

查找 p = 2, q = 4 的 LCA：

步骤 1：从 root = 6 开始
  p(2) < 6, q(4) < 6
  都在左子树，向左走

步骤 2：到达 node = 2
  p(2) == 2, q(4) > 2
  p 就是当前节点，q 在右侧
  返回 2
```

## 关键点总结

1. **利用 BST 性质**：通过值的大小关系判断方向
2. **分三种情况**：都在左、都在右、分居两侧
3. **节点可以是自己的祖先**：p 或 q 可能就是 LCA
4. **迭代优于递归**：空间复杂度 O(1)
5. **路径思想**：也可以通过记录路径来解决

## 易错点

1. **忘记节点可以是自己的祖先**：
   ```java
   // 错误：只考虑分居两侧的情况
   if (p.val < root.val && root.val < q.val) return root;
   
   // 正确：使用 else 处理所有其他情况
   if (p.val < root.val && q.val < root.val)
       return lowestCommonAncestor(root.left, p, q);
   else if (p.val > root.val && q.val > root.val)
       return lowestCommonAncestor(root.right, p, q);
   else
       return root;
   ```

2. **混淆 BST 和普通二叉树**：
   - 这道题只适用于 BST
   - 普通二叉树需要用不同的方法（见 236 题）

3. **判断条件不完整**：
   ```java
   // 需要同时判断 p 和 q
   if (p.val < root.val && q.val < root.val)  // 正确
   if (p.val < root.val || q.val < root.val)  // 错误
   ```

4. **返回值错误**：应该返回节点本身，不是节点的值
