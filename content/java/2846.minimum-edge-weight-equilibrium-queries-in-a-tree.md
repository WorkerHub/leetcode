## 题目描述

给你一棵 n 个节点的树和 q 个查询 `queries[i] = [a, b]`，边权为 1~26，返回每个查询中将路径上所有边权变为相同值所需的最少操作数。

## 解题思路

LCA + 前缀计数：预处理每个节点从根到该节点的各权重出现次数，查询时利用 LCA 计算路径上各权重频次，最少操作数 = 路径长度 - 最高频权重次数。

## Java 代码实现

```java
class Solution {
    private static final int LOG = 14;
    private int[] depth;
    private int[][] parent;
    private int[][] cnt; // cnt[i][w] = 根到节点 i 路径上权重 w 的次数

    public int[] minOperationsQueries(int n, int[][] edges, int[][] queries) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        depth = new int[n];
        parent = new int[LOG][n];
        cnt = new int[n][27];

        // 迭代 DFS 预处理深度、父节点、前缀计数
        boolean[] visited = new boolean[n];
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0, -1, 0});
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            int node = cur[0], par = cur[1], d = cur[2];
            if (visited[node]) continue;
            visited[node] = true;
            depth[node] = d;
            parent[0][node] = par == -1 ? node : par;
            for (int[] nei : graph[node]) {
                if (!visited[nei[0]]) {
                    // 复制父节点前缀计数并更新权重
                    cnt[nei[0]] = cnt[node].clone();
                    cnt[nei[0]][nei[1]]++;
                    stack.push(new int[]{nei[0], node, d + 1});
                }
            }
        }

        // 二进制提升预处理 LCA
        for (int j = 1; j < LOG; j++) {
            for (int i = 0; i < n; i++) {
                parent[j][i] = parent[j - 1][parent[j - 1][i]];
            }
        }

        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int a = queries[i][0], b = queries[i][1];
            int l = lca(a, b);
            int pathLen = depth[a] + depth[b] - 2 * depth[l];
            int maxFreq = 0;
            for (int w = 1; w <= 26; w++) {
                maxFreq = Math.max(maxFreq, cnt[a][w] + cnt[b][w] - 2 * cnt[l][w]);
            }
            ans[i] = pathLen - maxFreq;
        }
        return ans;
    }

    private int lca(int u, int v) {
        if (depth[u] < depth[v]) { int t = u; u = v; v = t; }
        int diff = depth[u] - depth[v];
        for (int j = 0; j < LOG; j++) {
            if (((diff >> j) & 1) == 1) u = parent[j][u];
        }
        if (u == v) return u;
        for (int j = LOG - 1; j >= 0; j--) {
            if (parent[j][u] != parent[j][v]) {
                u = parent[j][u];
                v = parent[j][v];
            }
        }
        return parent[0][u];
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) × log n × 26)
- **空间复杂度**：O(n × (log n + 26))

## 关键点总结

1. 路径权重统计用从根到节点的前缀计数，LCA 去掉公共部分
2. 最少操作 = 路径长度 - 最频繁权重次数
3. 二进制提升预处理 LCA，查询 O(log n)
