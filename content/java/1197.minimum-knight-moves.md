## 题目描述

无限棋盘上，马从 (0,0) 移动到 (x,y)，返回最少步数。

**示例：**
```
输入：x = 5, y = 5
输出：4
```

## 解题思路

BFS 搜索最短路径。利用对称性只考虑第一象限，加剪枝限制搜索范围。

## Java 代码实现

```java
class Solution {
    public int minKnightMoves(int x, int y) {
        // 利用对称性
        x = Math.abs(x);
        y = Math.abs(y);
        
        int[][] dirs = {{2,1},{1,2},{-1,2},{-2,1},{-2,-1},{-1,-2},{1,-2},{2,-1}};
        
        Queue<int[]> queue = new LinkedList<>();
        Set<Long> visited = new HashSet<>();
        queue.offer(new int[]{0, 0});
        visited.add(0L);
        
        int steps = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] cur = queue.poll();
                if (cur[0] == x && cur[1] == y) return steps;
                
                for (int[] d : dirs) {
                    int nx = cur[0] + d[0], ny = cur[1] + d[1];
                    long key = (long)(nx + 310) * 1000 + (ny + 310);
                    // 剪枝：限制搜索范围
                    if (!visited.contains(key) && nx >= -2 && ny >= -2 && nx <= x + 2 && ny <= y + 2) {
                        visited.add(key);
                        queue.offer(new int[]{nx, ny});
                    }
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(|x|,|y|)²)
- **空间复杂度**：O(max(|x|,|y|)²)

## 关键点总结

1. **对称性**：转到第一象限减少搜索空间
2. **BFS 求最短路**：逐层扩展保证第一次到达即最短
3. **剪枝**：限制搜索范围 [-2, target+2]
4. **visited 编码**：用 long 编码坐标对避免冲突
