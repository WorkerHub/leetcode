## 题目描述

给你长度为 `n` 的整数数组 `nums`，返回长度为 `n-1` 的数组，其中第 i 个元素为 `nums[i] | nums[i+1]`。

## 解题思路

直接遍历相邻元素，逐一计算按位或。

## Java 代码实现

```java
class Solution {
    public int[] orArray(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n - 1];
        for (int i = 0; i < n - 1; i++) {
            ans[i] = nums[i] | nums[i + 1];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 相邻元素按位或，结果长度为 n-1
2. 直接遍历，无需额外技巧
