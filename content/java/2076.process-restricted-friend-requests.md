## 题目描述

n 个人有若干限制（某两人不能直接或间接成为朋友），对每个好友请求判断是否可接受（接受后不违反限制），已接受的永久生效。

## 解题思路

并查集：对每个请求，先检查合并后是否违反限制（找两人的根，若某限制的两端分别属于这两个集合则违反）。不违反则合并并返回 true，否则返回 false。

## Java 代码实现

### 方法一：并查集 + 合并前验证（推荐）

```java
class Solution {
    private int[] parent, rank;

    public boolean[] friendRequests(int n, int[][] restrictions, int[][] requests) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        boolean[] res = new boolean[requests.length];
        for (int i = 0; i < requests.length; i++) {
            int pu = find(requests[i][0]), pv = find(requests[i][1]);
            if (pu == pv) { res[i] = true; continue; } // 已在同一集合

            // 检查合并后是否违反限制
            boolean violated = false;
            for (int[] r : restrictions) {
                int rx = find(r[0]), ry = find(r[1]);
                if ((rx == pu && ry == pv) || (rx == pv && ry == pu)) {
                    violated = true; break;
                }
            }
            if (!violated) {
                union(pu, pv);
                res[i] = true;
            }
        }
        return res;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        if (rank[x] < rank[y]) { int t = x; x = y; y = t; }
        parent[y] = x;
        if (rank[x] == rank[y]) rank[x]++;
    }
}
```

## 复杂度分析

- 时间复杂度：O(Q * R * alpha(n))
- 空间复杂度：O(n)

## 关键点总结

1. 对每个请求，取两端的根节点，检查限制中是否有两端分属这两个根
2. 先验证再合并，避免需要回滚
3. 已在同一集合时直接接受
