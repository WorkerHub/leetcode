## 题目描述

给你一个大小为 m x n 的矩阵 mat，请以对角线遍历的顺序，用一个数组返回这个矩阵中的所有元素。

**示例 1：**
```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,2,4,7,5,3,6,8,9]
```

**示例 2：**
```
输入：mat = [[1,2],[3,4]]
输出：[1,2,3,4]
```

**提示：**
- m == mat.length
- n == mat[i].length
- 1 <= m, n <= 10^4
- 1 <= m * n <= 10^4
- -10^5 <= mat[i][j] <= 10^5

## 解题思路

这是一道模拟题，核心是理解对角线遍历的规律。

### 核心思想

1. **对角线特征**：
   - 同一对角线上的元素，行列索引之和相同
   - 例如：(0,0), (0,1)和(1,0), (0,2)和(1,1)和(2,0)

2. **遍历方向**：
   - 奇数对角线：从下往上（右上方向）
   - 偶数对角线：从上往下（左下方向）

3. **边界处理**：
   - 对角线索引从 0 到 m + n - 2
   - 每条对角线的起点和终点需要计算

4. **方向变化规律**：
   - 对角线索引为偶数：向右上
   - 对角线索引为奇数：向左下

## Java 代码实现

### 方法一：按对角线分组（推荐）

```java
import java.util.*;

class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        if (mat == null || mat.length == 0) return new int[0];

        int m = mat.length, n = mat[0].length;
        int[] result = new int[m * n];
        int idx = 0;

        // 对角线总数是 m + n - 1
        for (int d = 0; d < m + n - 1; d++) {
            List<Integer> diagonal = new ArrayList<>();

            // 计算当前对角线的起点
            // 如果 d < n，起点在第一行
            // 否则起点在最后一列
            int row = d < n ? 0 : d - n + 1;
            int col = d < n ? d : n - 1;

            // 沿对角线收集元素
            while (row < m && col >= 0) {
                diagonal.add(mat[row][col]);
                row++;
                col--;
            }

            // 偶数对角线需要反转（向右上）
            if (d % 2 == 0) {
                Collections.reverse(diagonal);
            }

            for (int val : diagonal) {
                result[idx++] = val;
            }
        }

        return result;
    }
}
```

### 方法二：直接模拟

```java
class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        if (mat == null || mat.length == 0) return new int[0];

        int m = mat.length, n = mat[0].length;
        int[] result = new int[m * n];
        int row = 0, col = 0;
        int direction = 1; // 1 表示向右上，-1 表示向左下

        for (int i = 0; i < m * n; i++) {
            result[i] = mat[row][col];

            // 向右上移动
            if (direction == 1) {
                // 到达右边界，向下移动
                if (col == n - 1) {
                    row++;
                    direction = -1;
                // 到达上边界，向右移动
                } else if (row == 0) {
                    col++;
                    direction = -1;
                // 正常向右上移动
                } else {
                    row--;
                    col++;
                }
            // 向左下移动
            } else {
                // 到达下边界，向右移动
                if (row == m - 1) {
                    col++;
                    direction = 1;
                // 到达左边界，向下移动
                } else if (col == 0) {
                    row++;
                    direction = 1;
                // 正常向左下移动
                } else {
                    row++;
                    col--;
                }
            }
        }

        return result;
    }
}
```

### 方法三：使用 HashMap 分组

```java
import java.util.*;

class Solution {
    public int[] findDiagonalOrder(int[][] mat) {
        if (mat == null || mat.length == 0) return new int[0];

        int m = mat.length, n = mat[0].length;
        Map<Integer, List<Integer>> diagonals = new HashMap<>();

        // 按 i + j 分组
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                diagonals.computeIfAbsent(i + j, k -> new ArrayList<>()).add(mat[i][j]);
            }
        }

        int[] result = new int[m * n];
        int idx = 0;

        for (int key = 0; key < m + n - 1; key++) {
            List<Integer> diagonal = diagonals.get(key);
            // 偶数对角线反转
            if (key % 2 == 0) {
                Collections.reverse(diagonal);
            }
            for (int val : diagonal) {
                result[idx++] = val;
            }
        }

        return result;
    }
}
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(m × n)
  - 遍历矩阵中的每个元素一次

- **空间复杂度**：
  - 方法一、三：O(m × n)，需要额外存储
  - 方法二：O(1)，不包括输出数组

## 关键点总结

1. **对角线特征**：行列索引和相同
2. **方向规律**：奇偶对角线方向不同
3. **边界判断**：到达边界时改变方向
4. **起点计算**：每条对角线的起始位置
5. **反转操作**：偶数对角线需要反转

## 易错点

1. **方向判断**
   - 哪些对角线需要反转
   - 偶数对角线还是奇数对角线

2. **边界条件**
   - 到达右边界和上边界的处理
   - 到达下边界和左边界的处理
   - 优先级：先判断列边界再判断行边界

3. **起点计算**
   - 对角线 d < n 时，起点在第一行
   - 对角线 d >= n 时，起点在最后一列

4. **循环次数**
   - 总共 m * n 个元素
   - 不要多遍历或少遍历

5. **索引越界**
   - 移动时检查边界
   - 使用 while row < m && col >= 0
