## 题目描述

给定 `arr1` 和 `arr2`，每次操作可将 `arr1[i]` 替换为 `arr2[j]`。返回使 `arr1` 严格递增的最小操作数，无法实现返回 -1。

**示例：**
```
输入：arr1 = [1,5,3,6,7], arr2 = [1,3,2,4]
输出：1（用2替换5）
```

## 解题思路

DP + 二分查找。用哈希表 `dp` 存储状态：键为当前位置的值，值为达到该值的最小操作次数。对每个位置有两种选择：保留原值或从 arr2 中替换。arr2 排序去重后用二分查找定位。

## Java 代码实现

```java
class Solution {
    public int makeArrayIncreasing(int[] arr1, int[] arr2) {
        // arr2 排序去重
        TreeSet<Integer> set = new TreeSet<>();
        for (int x : arr2) set.add(x);
        int[] sorted2 = new int[set.size()];
        int idx = 0;
        for (int x : set) sorted2[idx++] = x;
        
        // dp: 值 -> 最小操作次数
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(-1, 0);
        
        for (int num : arr1) {
            Map<Integer, Integer> newDp = new HashMap<>();
            
            for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                int prevVal = entry.getKey();
                int ops = entry.getValue();
                
                // 选项1：不替换当前元素
                if (num > prevVal) {
                    newDp.merge(num, ops, Math::min);
                }
                
                // 选项2：替换当前元素（找arr2中大于prevVal的最小值）
                int pos = upperBound(sorted2, prevVal);
                if (pos < sorted2.length) {
                    newDp.merge(sorted2[pos], ops + 1, Math::min);
                }
            }
            
            dp = newDp;
        }
        
        if (dp.isEmpty()) return -1;
        int result = Integer.MAX_VALUE;
        for (int v : dp.values()) result = Math.min(result, v);
        return result;
    }
    
    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m * log m)，n 为 arr1 长度，m 为 arr2 去重后长度
- **空间复杂度**：O(m)

## 关键点总结

1. **哈希表 DP**：状态为「当前值 → 最小操作次数」
2. **二分查找**：在排序后的 arr2 中找严格大于 prevVal 的最小值
3. **去重**：arr2 中重复值无意义
4. **贪心**：替换时选最小可行值，保留更多后续空间
