## 题目描述

在一条水平线上有 `n` 个加油站。给定一个数组 `stations` 表示每个加油站的位置。

你有 `k` 个额外的加油站要添加。返回可以达到的最大距离的最小可能值。

## 解题思路

使用二分查找答案，检查是否可以用 k 个加油站使最大距离不超过 mid。

## Java 代码实现

```java
class Solution {
    public double minmaxGasDist(int[] stations, int k) {
        double left = 0, right = stations[stations.length - 1] - stations[0];

        // 二分查找：找到最小的最大距离
        while (right - left > 1e-6) {
            double mid = (left + right) / 2;
            // 检查是否可以用 k 个额外加油站使最大距离不超过 mid
            if (possible(stations, k, mid)) {
                right = mid;
            } else {
                left = mid;
            }
        }

        return left;
    }

    // 判断能否用至多 k 个加油站使得相邻距离都不超过 distance
    private boolean possible(int[] stations, int k, double distance) {
        int count = 0;
        for (int i = 0; i < stations.length - 1; i++) {
            // 每个区间需要插入的加油站数量
            count += (int) ((stations[i + 1] - stations[i]) / distance);
        }
        return count <= k;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n log(max_distance / precision))
- **空间复杂度：** O(1)

## 关键点总结

1. 二分查找答案
2. 浮点数精度
3. 贪心验证
