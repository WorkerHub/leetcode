## 题目描述

给你 `m×n` 二进制矩阵，判断是否存在从左上到右下（只能向右或向下）的路径，使得路径上 0 和 1 的数量相等。

## 解题思路

路径长度固定为 `m+n-1`，若为偶数则不可能等量。用 `dp[i][j]` 存储到达 `(i, j)` 时所有可能差值（1的数-0的数）的范围 `[lo, hi]`，由于差值连续且同奇偶，用区间代替集合。最终判断 0 是否在 `dp[m-1][n-1]` 的范围内。

## Java 代码实现

```java
class Solution {
    public boolean isThereAPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        if ((m + n - 1) % 2 == 0) return false; // 路径长度为奇数才可能等量

        // lo[i][j], hi[i][j]: 到达 (i,j) 时差值（1数-0数）的最小值和最大值
        int[][] lo = new int[m][n], hi = new int[m][n];
        final int INF = Integer.MAX_VALUE / 2;
        for (int[] row : lo) java.util.Arrays.fill(row, INF);
        for (int[] row : hi) java.util.Arrays.fill(row, -INF);

        lo[0][0] = hi[0][0] = (grid[0][0] == 1) ? 1 : -1;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int d = (grid[i][j] == 1) ? 1 : -1;
                int curLo = INF, curHi = -INF;
                if (i > 0 && lo[i-1][j] != INF) {
                    curLo = Math.min(curLo, lo[i-1][j] + d);
                    curHi = Math.max(curHi, hi[i-1][j] + d);
                }
                if (j > 0 && lo[i][j-1] != INF) {
                    curLo = Math.min(curLo, lo[i][j-1] + d);
                    curHi = Math.max(curHi, hi[i][j-1] + d);
                }
                lo[i][j] = curLo;
                hi[i][j] = curHi;
            }
        }
        return lo[m-1][n-1] <= 0 && 0 <= hi[m-1][n-1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. 路径长度 `m+n-1` 为偶数则不可能等量，直接返回 false
2. 可达差值构成连续区间，用 `[lo, hi]` 代替集合存储
3. 最终判断 0 是否在目标格的差值范围内
