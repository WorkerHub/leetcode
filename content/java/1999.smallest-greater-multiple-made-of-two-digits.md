## 题目描述

给定整数 `k`、`digit1` 和 `digit2`，找最小的大于 `k` 的正整数，使其是 `k` 的倍数且只包含数字 `digit1` 和 `digit2`，不存在返回 -1。

## 解题思路

BFS 按位数从小到大枚举只含 digit1 和 digit2 的正整数（首位非 0），对每个数检查是否大于 k 且是 k 的倍数，首次满足即为答案。

## Java 代码实现

### 方法一：BFS 枚举（推荐）

```java
import java.util.*;

class Solution {
    public int findInteger(int k, int digit1, int digit2) {
        // 去重并排序两种数字
        Set<Integer> digitSet = new TreeSet<>();
        digitSet.add(digit1);
        digitSet.add(digit2);

        // 两种数字都是0，无法构造正整数
        if (digitSet.size() == 1 && digitSet.contains(0)) return -1;

        Queue<Long> queue = new LinkedList<>();
        // 初始化：非零开头的数字入队
        for (int d : digitSet) {
            if (d != 0) queue.offer((long) d);
        }

        long limit = 2_000_000_000L; // 防止无限循环的上限

        while (!queue.isEmpty()) {
            long num = queue.poll();
            if (num > limit) return -1;
            if (num > k && num % k == 0) return (int) num;
            // 末尾追加digit1或digit2扩展数字
            for (int d : digitSet) {
                long next = num * 10 + d;
                if (next <= limit) queue.offer(next);
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^L)，L 为答案位数
- 空间复杂度：O(2^L)

## 关键点总结

1. BFS 按位数（数值大小）枚举，保证找到最小值
2. 首位不能为 0，使用 TreeSet 去重且排序
3. 设置上限 2 * 10^9 防止无限循环，使用 long 防止溢出
