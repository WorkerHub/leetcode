## 题目描述

给你一个数组 `nums`，对于其中每个元素 `nums[i]`，统计数组中比它小的所有数字的数目，以数组形式返回答案。

## 解题思路

利用值域 0~100 做计数排序：统计每个值出现次数，计算前缀和，`prefix[v]` 即小于 v 的数字总数，最后直接映射原数组。时间复杂度 O(N+M)，空间复杂度 O(M)，M=101。

## Java 代码实现

```java
class Solution {
    public int[] smallerNumbersThanCurrent(int[] nums) {
        // 计数数组，值域 0~100
        int[] count = new int[102];
        for (int v : nums) {
            count[v]++;
        }
        // 计算前缀和：count[v] 变为小于等于 v 的数字数量
        for (int v = 1; v < 102; v++) {
            count[v] += count[v - 1];
        }
        // 构造结果：比 v 小的数量 = count[v-1]（v>0），0（v==0）
        int[] result = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            result[i] = nums[i] > 0 ? count[nums[i] - 1] : 0;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(N + M)，N 为数组长度，M = 101（值域大小）。
- 空间复杂度：O(M)，计数数组固定大小。

## 关键点总结

1. 值域有界（0~100）时，计数排序比比较排序更高效。
2. 前缀和后 `count[v]` 表示 <= v 的数字数量，比 v 小的数量为 `count[v-1]`（v>0 时）。
3. v == 0 时特判返回 0，避免数组越界。
