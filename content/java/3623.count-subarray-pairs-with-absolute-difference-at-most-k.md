## 题目描述

给定整数数组 `nums` 和整数 `k`，返回满足 `0 <= i < j < n` 且 `|nums[i] - nums[j]| <= k` 的下标对数量。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long countPairs(int[] nums, int k) {
        Arrays.sort(nums);
        long count = 0;
        int left = 0;

        for (int right = 0; right < nums.length; right++) {
            // 移动左指针直到 nums[right] - nums[left] <= k
            while (nums[right] - nums[left] > k) {
                left++;
            }
            // [left, right-1] 中的元素都满足条件
            count += right - left;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主要开销
- 空间复杂度：O(1)

## 关键点总结

1. 排序后绝对值差等价于 `nums[right] - nums[left]`（单调性）
2. 双指针：对每个右端点统计有效左端点数为 `right - left`
3. 排序破坏下标顺序但不影响计数结果
