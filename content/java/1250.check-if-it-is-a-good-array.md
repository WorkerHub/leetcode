## 题目描述

给定正整数数组 nums，判断是否能从中选取若干数字，各乘以任意整数后使总和为 1（即是否为"好数组"）。

**示例：**
```
输入：nums = [12,5,7,23]
输出：true（5×3 + 7×(-2) = 1）
```

## 解题思路

贝祖定理：整数线性组合能得到 1 当且仅当这些数的 GCD 为 1。所以只需判断数组所有元素的 GCD 是否为 1。

## Java 代码实现

```java
class Solution {
    public boolean isGoodArray(int[] nums) {
        int g = nums[0];
        for (int i = 1; i < nums.length; i++) {
            g = gcd(g, nums[i]);
            if (g == 1) return true; // 提前终止
        }
        return g == 1;
    }
    
    private int gcd(int a, int b) {
        while (b != 0) {
            int t = b;
            b = a % b;
            a = t;
        }
        return a;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(max))
- **空间复杂度**：O(1)

## 关键点总结

1. **贝祖定理**：线性组合 = 1 ⇔ GCD = 1
2. **提前终止**：GCD 一旦变为 1 就可以立即返回
3. **GCD 链式计算**：gcd(a, b, c) = gcd(gcd(a, b), c)
4. **数论本质**：看似复杂的问题有简洁的数学解
