## 题目描述

给你链表的头节点 `head` 和一个整数 `k`，交换链表正数第 `k` 个节点和倒数第 `k` 个节点的**值**后，返回链表的头节点。

## 解题思路

用双指针找正数第 `k` 个节点（`first`），然后快慢指针继续前进，慢指针到达的位置即为倒数第 `k` 个节点（`second`），交换两者的值。

## Java 代码实现

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

class Solution {
    public ListNode swapNodes(ListNode head, int k) {
        // fast 先走 k-1 步，找到正数第 k 个节点
        ListNode fast = head;
        for (int i = 0; i < k - 1; i++) {
            fast = fast.next;
        }
        ListNode first = fast; // 正数第 k 个节点

        // slow 和 fast 同步前进，找倒数第 k 个节点
        ListNode slow = head;
        while (fast.next != null) {
            fast = fast.next;
            slow = slow.next;
        }
        ListNode second = slow; // 倒数第 k 个节点

        // 交换两节点的值
        int tmp = first.val;
        first.val = second.val;
        second.val = tmp;

        return head;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只交换值，不修改链表结构
2. 双指针技巧：fast 先走 k 步后，fast 与 slow 同步前进
