## 题目描述

给你两个 4 位整数 `n` 和 `m`，每次操作将 `n` 某一位 +1 或 -1（最高位不能为 0，各位不能超出 0-9 范围），代价为操作后的数值。若操作后的数是质数（且不是目标 m）则禁止该操作。返回将 n 变成 m 的最小总代价，不可能则返回 -1。

## 解题思路

将每个 4 位整数看作图节点，相邻节点是一次合法操作可达的整数，边权为目标整数的值。若 n 本身是质数则无法操作直接返回 -1。用 Dijkstra 从 n 出发求到 m 的最短路。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minOperations(int n, int m) {
        if (n == m) return 0;
        boolean[] isPrime = sieve(9999);
        if (isPrime[n]) return -1; // n 是质数，无法操作

        int[] dist = new int[10000];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[n] = 0;
        // 优先队列：{代价, 当前值}
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, n});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int cost = cur[0], val = cur[1];
            if (val == m) return cost;
            if (cost > dist[val]) continue;

            // 枚举每一位的 +1 和 -1
            int[] digits = toDigits(val);
            for (int i = 0; i < 4; i++) {
                int d = digits[i];
                for (int delta : new int[]{-1, 1}) {
                    int nd = d + delta;
                    if (nd < 0 || nd > 9) continue;
                    if (i == 0 && nd == 0) continue; // 最高位不能为 0
                    digits[i] = nd;
                    int newVal = fromDigits(digits);
                    digits[i] = d; // 恢复
                    // 质数（非目标）不能作为中间节点
                    if (isPrime[newVal] && newVal != m) continue;
                    int newCost = cost + newVal;
                    if (newCost < dist[newVal]) {
                        dist[newVal] = newCost;
                        pq.offer(new int[]{newCost, newVal});
                    }
                }
            }
        }
        return -1;
    }

    private boolean[] sieve(int maxN) {
        boolean[] isPrime = new boolean[maxN + 1];
        Arrays.fill(isPrime, true);
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; (long) i * i <= maxN; i++) {
            if (isPrime[i]) {
                for (int j = i * i; j <= maxN; j += i) isPrime[j] = false;
            }
        }
        return isPrime;
    }

    private int[] toDigits(int val) {
        int[] d = new int[4];
        for (int i = 3; i >= 0; i--) {
            d[i] = val % 10;
            val /= 10;
        }
        return d;
    }

    private int fromDigits(int[] d) {
        return d[0] * 1000 + d[1] * 100 + d[2] * 10 + d[3];
    }
}
```

## 复杂度分析

- 时间复杂度：O(V log V)，V = 9000（4 位数数量）
- 空间复杂度：O(V)

## 关键点总结

1. 将整数变换建模为最短路，边权为目标整数的值。
2. 质数（除目标 m）不能作为中间状态。
3. Dijkstra 求从 n 到 m 的最小代价路径。
