## 题目描述

给你整数数组 nums（n 最大 10^5），返回所有 i < j < k 的三元组中 `(nums[i] - nums[j]) * nums[k]` 的最大值，若全为负则返回 0。

## 解题思路

一次遍历：维护 `maxI`（当前最大 nums[i]）和 `maxIJ`（当前最大 nums[i] - nums[j]），对每个位置先用 maxIJ 更新答案，再依次更新 maxIJ 和 maxI，严格保证更新顺序。

## Java 代码实现

```java
class Solution {
    public long maximumTripletValue(int[] nums) {
        long ans = 0, maxI = 0, maxIJ = 0;

        for (int x : nums) {
            // 先将当前 x 作为 k 更新答案
            ans = Math.max(ans, maxIJ * x);
            // 再将当前 x 作为 j 更新 maxIJ
            maxIJ = Math.max(maxIJ, maxI - x);
            // 最后将当前 x 作为 i 更新 maxI
            maxI = Math.max(maxI, x);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 更新顺序关键：先更新 ans（用 k），再更新 maxIJ（用 j），最后更新 maxI（用 i）
2. maxI 和 maxIJ 保证了 i < j < k 的下标约束
3. 使用 long 防止乘法溢出
