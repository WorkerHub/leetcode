## 题目描述

判断数组中是否存在连续三个奇数。

**示例：**
```
输入：arr = [1,2,34,3,4,5,7,23,12]
输出：true
解释：[5,7,23] 是连续三个奇数
```

## 解题思路

计数器法：遇奇加 1，遇偶重置为 0，达到 3 返回 true。

## Java 代码实现

```java
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        int count = 0;
        for (int num : arr) {
            if (num % 2 == 1) {
                count++;
                if (count == 3) return true;
            } else {
                count = 0;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **计数器**：遇奇加 1，遇偶清零
2. **提前返回**：达到 3 立即返回
