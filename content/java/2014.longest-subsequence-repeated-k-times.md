## 题目描述

给定字符串 `s` 和整数 `k`，找最长子序列 `seq` 使得 `seq` 重复 k 次是 `s` 的子序列，若有多个等长答案返回字典序最大的。

## 解题思路

只有出现次数 >= k 的字符才能出现在答案中，答案长度不超过 `n/k`。用 BFS 按层枚举所有候选子序列（每层追加一个字符），验证 `seq*k` 是否是 `s` 的子序列，维护最长且字典序最大的答案。

## Java 代码实现

### 方法一：BFS 枚举（推荐）

```java
import java.util.*;

class Solution {
    private String s;
    private int k;

    public String longestSubsequenceRepeatedK(String s, int k) {
        this.s = s;
        this.k = k;

        // 过滤出现次数>=k的字符，按字典序降序
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;
        List<Character> validChars = new ArrayList<>();
        for (int i = 25; i >= 0; i--) {
            if (freq[i] >= k) validChars.add((char)('a' + i));
        }

        Queue<String> queue = new LinkedList<>();
        queue.offer("");
        String ans = "";

        while (!queue.isEmpty()) {
            String cur = queue.poll();
            for (char c : validChars) {
                String candidate = cur + c;
                if (isSubseqK(candidate)) {
                    if (candidate.length() > ans.length() ||
                        (candidate.length() == ans.length() && candidate.compareTo(ans) > 0)) {
                        ans = candidate;
                    }
                    queue.offer(candidate);
                }
            }
        }
        return ans;
    }

    // 判断seq重复k次是否是s的子序列
    private boolean isSubseqK(String seq) {
        int i = 0;
        for (int rep = 0; rep < k; rep++) {
            for (char c : seq.toCharArray()) {
                while (i < s.length() && s.charAt(i) != c) i++;
                if (i >= s.length()) return false;
                i++;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * |valid|^(n/k))，实际剪枝效果好
- 空间复杂度：O(n/k)

## 关键点总结

1. 只有出现次数 >= k 的字符才有可能出现在答案中（剪枝）
2. BFS 层序枚举保证先处理较短的候选，找到最长有效子序列
3. 字符按字典序降序枚举，先找到的同长度候选字典序更大
