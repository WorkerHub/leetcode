## 题目描述

给定账户列表（名字+邮箱），有共同邮箱的账户属于同一人，合并后返回（邮箱按字典序排列）。

**示例：**
```
输入：[["John","johnsmith@mail.com","john_newyork@mail.com"],["John","johnsmith@mail.com","john00@mail.com"],...]
输出：[["John","john00@mail.com","john_newyork@mail.com","johnsmith@mail.com"],...]
```

## 解题思路

并查集：将邮箱映射到账户索引，有共同邮箱的账户合并。最后按根节点分组收集邮箱。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public List<List<String>> accountsMerge(List<List<String>> accounts) {
        int n = accounts.size();
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 邮箱到账户索引的映射
        Map<String, Integer> emailToId = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int j = 1; j < accounts.get(i).size(); j++) {
                String email = accounts.get(i).get(j);
                if (emailToId.containsKey(email)) {
                    union(i, emailToId.get(email));
                } else {
                    emailToId.put(email, i);
                }
            }
        }

        // 按根节点分组
        Map<Integer, Set<String>> groups = new HashMap<>();
        for (Map.Entry<String, Integer> entry : emailToId.entrySet()) {
            int root = find(entry.getValue());
            groups.computeIfAbsent(root, k -> new TreeSet<>()).add(entry.getKey());
        }

        // 构建结果
        List<List<String>> result = new ArrayList<>();
        for (Map.Entry<Integer, Set<String>> entry : groups.entrySet()) {
            List<String> list = new ArrayList<>();
            list.add(accounts.get(entry.getKey()).get(0));
            list.addAll(entry.getValue());
            result.add(list);
        }
        return result;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × K × α(N))
- **空间复杂度**：O(N × K)

## 关键点总结

1. **并查集合并**：有共同邮箱的账户合并
2. **TreeSet 排序**：自动按字典序排列邮箱
3. **邮箱映射**：第一次出现的邮箱记录账户索引
