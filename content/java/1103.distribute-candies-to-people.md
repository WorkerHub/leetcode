## 题目描述

将 candies 颗糖果分给 num_people 个人，第一人 1 颗，第二人 2 颗...循环分发直到分完。最后一次可能不够，全部给当前人。

**示例：**
```
输入：candies = 7, num_people = 4
输出：[1,2,3,1]
```

## 解题思路

直接模拟：依次分发递增数量的糖果，用取模循环索引，最后一次取 min(剩余, 应发)。

## Java 代码实现

```java
class Solution {
    public int[] distributeCandies(int candies, int num_people) {
        int[] result = new int[num_people];
        int give = 1;

        while (candies > 0) {
            // 当前分发给第 (give-1) % num_people 个人
            result[(give - 1) % num_people] += Math.min(candies, give);
            candies -= give;
            give++;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(√C)，总分发次数约 √(2C)
- **空间复杂度**：O(1)（不计结果数组）

## 关键点总结

1. **取模循环**：`(give-1) % num_people` 实现循环分配
2. **Math.min 处理尾部**：最后一次分发可能不足
3. **分发次数**：约 √(2 × candies) 次
