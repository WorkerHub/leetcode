## 题目描述

判断在最多改变 1 个元素的情况下，数组能否变成非递减数列。

**示例：**
```
输入：nums = [4,2,3]
输出：true（将 4 改为 2）
```

## 解题思路

贪心：遇到逆序对时选择最优修改方式——优先降低前一个元素。

## Java 代码实现

```java
class Solution {
    public boolean checkPossibility(int[] nums) {
        int count = 0;

        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] > nums[i + 1]) {
                count++;
                if (count > 1) return false;

                // 决定修改哪个
                if (i == 0 || nums[i - 1] <= nums[i + 1]) {
                    nums[i] = nums[i + 1]; // 降低前一个
                } else {
                    nums[i + 1] = nums[i]; // 提高后一个
                }
            }
        }

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **最多一次修改**：逆序对不超过 1
2. **贪心选择**：优先降低 nums[i]，不影响后续
3. **边界判断**：需要看 nums[i-1] 与 nums[i+1] 的关系
