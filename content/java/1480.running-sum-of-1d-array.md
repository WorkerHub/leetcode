## 题目描述

给定数组nums，返回其前缀和数组，即runningSum[i] = sum(nums[0]…nums[i])。

## 解题思路

原地修改：从第2个元素开始，每个元素加上前一个元素的值即可。

## Java 代码实现

```java
class Solution {
    public int[] runningSum(int[] nums) {
        // 从第2个元素开始累加
        for (int i = 1; i < nums.length; i++) {
            nums[i] += nums[i - 1];
        }
        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和递推**：prefix[i] = prefix[i-1] + nums[i]
2. **原地修改**：无需额外数组
3. **从i=1开始**：第一个元素不需要修改
