## 题目描述

求解给定方程，返回 "x=#value"、"Infinite solutions" 或 "No solution"。

**示例：**
```
输入：equation = "x+5-3+x=6+x-2"
输出："x=2"
```

## 解题思路

解析等号两边，分别统计 x 的系数和常数项，移项后求解。

## Java 代码实现

```java
class Solution {
    public String solveEquation(String equation) {
        String[] parts = equation.split("=");
        int[] left = parse(parts[0]);
        int[] right = parse(parts[1]);

        // 移项：x系数移到左边，常数移到右边
        int coef = left[0] - right[0];
        int constant = right[1] - left[1];

        if (coef == 0) {
            return constant == 0 ? "Infinite solutions" : "No solution";
        }
        return "x=" + (constant / coef);
    }

    // 返回 [x的系数, 常数项]
    private int[] parse(String expr) {
        int coef = 0, constant = 0;
        int sign = 1, num = 0;
        boolean hasNum = false;

        for (int i = 0; i < expr.length(); i++) {
            char c = expr.charAt(i);
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
                hasNum = true;
            } else if (c == 'x') {
                coef += hasNum ? sign * num : sign;
                num = 0;
                hasNum = false;
            } else { // '+' 或 '-'
                if (hasNum) {
                    constant += sign * num;
                }
                num = 0;
                hasNum = false;
                sign = c == '+' ? 1 : -1;
            }
        }
        // 处理末尾数字
        if (hasNum) {
            constant += sign * num;
        }

        return new int[]{coef, constant};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **分别解析两边**：统计 x 系数和常数
2. **移项求解**：coef * x = constant
3. **特殊情况**：coef=0 时判断 Infinite 或 No solution
4. **单独 x**：系数为 1，不是 0
