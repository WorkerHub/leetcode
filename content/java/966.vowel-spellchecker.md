## 题目描述

实现拼写检查器：按优先级匹配——完全匹配 > 大小写不敏感匹配 > 元音替换匹配。返回第一个匹配的单词或空串。

## 解题思路

三个哈希表：精确匹配集合、小写映射、元音模式映射（元音替换为通配符）。查询时按优先级依次查找。

## Java 代码实现

```java
class Solution {
    public String[] spellchecker(String[] wordlist, String[] queries) {
        Set<String> exact = new HashSet<>(Arrays.asList(wordlist));
        Map<String, String> caseMap = new HashMap<>();
        Map<String, String> vowelMap = new HashMap<>();

        for (String word : wordlist) {
            String lower = word.toLowerCase();
            caseMap.putIfAbsent(lower, word);
            vowelMap.putIfAbsent(toPattern(lower), word);
        }

        String[] result = new String[queries.length];
        for (int i = 0; i < queries.length; i++) {
            String q = queries[i];
            if (exact.contains(q)) {
                result[i] = q;
            } else if (caseMap.containsKey(q.toLowerCase())) {
                result[i] = caseMap.get(q.toLowerCase());
            } else if (vowelMap.containsKey(toPattern(q.toLowerCase()))) {
                result[i] = vowelMap.get(toPattern(q.toLowerCase()));
            } else {
                result[i] = "";
            }
        }
        return result;
    }

    private String toPattern(String word) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toCharArray()) {
            sb.append("aeiou".indexOf(c) >= 0 ? '*' : c);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O((W + Q) × L)
- **空间复杂度**：O(W × L)

## 关键点总结

1. **三级优先级**：精确 > 大小写 > 元音
2. **putIfAbsent**：只记录第一次出现的匹配
3. **元音模式**：统一替换为通配符
