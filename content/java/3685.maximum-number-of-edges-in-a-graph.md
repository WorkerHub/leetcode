## 题目描述

给你一个无向图，有 `n` 个节点和整数 `threshold`，要求图中任意两个连通分量之间的边数不超过 `threshold`。在满足约束的前提下，图中最多可以有多少条边？

## 解题思路

贪心：每个连通分量最多有 `threshold + 1` 个节点，分量内可构成完全图。最优策略是将 n 个节点均分为若干大小为 `threshold + 1` 的组，每组内构成完全图，余数组单独处理。

## Java 代码实现

```java
class Solution {
    public long maximumEdges(int n, int threshold) {
        if (threshold == 0) return 0; // 每个节点独立
        if (threshold >= n - 1) return (long) n * (n - 1) / 2; // 完全图

        long k = threshold + 1;
        long q = n / k, r = n % k;
        // 完整组的边数 + 余数组的边数
        return q * k * (k - 1) / 2 + r * (r - 1) / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 每个连通分量最多 `threshold + 1` 个节点
2. 最优：尽量用最大组，每组内构成完全图
3. 完全图边数公式：`k*(k-1)/2`
