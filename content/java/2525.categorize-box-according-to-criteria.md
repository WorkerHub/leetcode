## 题目描述

给你箱子的长、宽、高和质量，若任一维度 >= 10^4 或体积 >= 10^9 则为大型（Bulky），质量 >= 100 则为重型（Heavy），根据两者组合返回 "Both"、"Bulky"、"Heavy" 或 "Neither"。

## 解题思路

直接按条件判断，注意体积计算时用 `long` 防止整数溢出。

## Java 代码实现

```java
class Solution {
    public String categorizeBox(int length, int width, int height, int mass) {
        // 用 long 防止体积溢出
        boolean isBulky = length >= 10000 || width >= 10000 || height >= 10000
                || (long) length * width * height >= 1_000_000_000L;
        boolean isHeavy = mass >= 100;

        if (isBulky && isHeavy) return "Both";
        if (isBulky) return "Bulky";
        if (isHeavy) return "Heavy";
        return "Neither";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 大型条件为"任一"满足，即 `||` 而非 `&&`
2. 体积为三维相乘（非最大维度），Java 中需转 `long` 防溢出
3. 四种分类用两个布尔值组合判断
