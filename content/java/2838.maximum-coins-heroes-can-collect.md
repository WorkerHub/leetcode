## 题目描述

英雄力量>=硬币难度可收集该硬币，对每个英雄求可收集的硬币总值。

## 解题思路

按难度排序+前缀和：对每个英雄二分找力量能覆盖的硬币范围，前缀和直接得答案。

## Java 代码实现

```java
class Solution {
    public long[] maximumCoins(int[] heroes, int[] coins, int[] powers) {
        int m = coins.length;
        // 按难度排序
        int[][] items = new int[m][2];
        for (int i = 0; i < m; i++) {
            items[i][0] = powers[i];
            items[i][1] = coins[i];
        }
        Arrays.sort(items, (a, b) -> a[0] - b[0]);

        // 前缀和
        long[] prefix = new long[m + 1];
        for (int i = 0; i < m; i++) {
            prefix[i + 1] = prefix[i] + items[i][1];
        }

        // 对每个英雄二分查找
        long[] ans = new long[heroes.length];
        for (int i = 0; i < heroes.length; i++) {
            int power = heroes[i];
            // 找第一个difficulty > power的位置
            int lo = 0, hi = m;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (items[mid][0] > power) hi = mid;
                else lo = mid + 1;
            }
            ans[i] = prefix[lo];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+M) log M)
- **空间复杂度**：O(M)

## 关键点总结

1. **按难度排序+前缀和**：O(1)求区间硬币总值
2. **二分找边界**：difficulty<=power的最大范围
3. **每个英雄独立查询**
