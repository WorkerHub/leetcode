## 题目描述

给你 n 座城市的路径数组 `paths`，返回出现在所有路径中的最长公共子路径的长度。

## 解题思路

二分答案长度 mid，用双滚动哈希验证是否存在长度为 mid 的公共子路径：对每条路径计算所有长度 mid 的子路径哈希集合，求所有路径的交集是否非空。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final long MOD1 = 1_000_000_007L, BASE1 = 100003L;
    static final long MOD2 = 1_000_000_009L, BASE2 = 200003L;

    public int longestCommonSubpath(int n, int[][] paths) {
        int lo = 0, hi = Integer.MAX_VALUE;
        for (int[] p : paths) hi = Math.min(hi, p.length);

        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (canFind(paths, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean canFind(int[][] paths, int len) {
        Set<Long> common = null;
        for (int[] path : paths) {
            Set<Long> hashes = getHashes(path, len);
            if (common == null) common = hashes;
            else common.retainAll(hashes);
            if (common.isEmpty()) return false;
        }
        return common != null && !common.isEmpty();
    }

    private Set<Long> getHashes(int[] path, int len) {
        if (path.length < len) return new HashSet<>();
        long h1 = 0, h2 = 0, pw1 = 1, pw2 = 1;
        for (int i = 0; i < len; i++) {
            h1 = (h1 * BASE1 + path[i] + 1) % MOD1;
            h2 = (h2 * BASE2 + path[i] + 1) % MOD2;
            if (i < len - 1) { pw1 = pw1 * BASE1 % MOD1; pw2 = pw2 * BASE2 % MOD2; }
        }
        Set<Long> res = new HashSet<>();
        res.add(h1 * MOD2 + h2); // 双哈希编码为单值
        for (int i = len; i < path.length; i++) {
            h1 = (h1 - (path[i - len] + 1) * pw1 % MOD1 + MOD1) % MOD1;
            h1 = (h1 * BASE1 + path[i] + 1) % MOD1;
            h2 = (h2 - (path[i - len] + 1) * pw2 % MOD2 + MOD2) % MOD2;
            h2 = (h2 * BASE2 + path[i] + 1) % MOD2;
            res.add(h1 * MOD2 + h2);
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(S log S)，S 为所有路径长度之和
- **空间复杂度**：O(S)

## 关键点总结

1. 二分长度 + 哈希验证是解决此类问题的通用框架
2. 双哈希大幅降低碰撞概率
3. 滚动哈希避免重复计算每个窗口的哈希值
