## 题目描述

给定字符串 `word` 和字符 `ch`，找 `ch` 在 `word` 中第一次出现的下标 `i`，反转 `word[0..i]` 后返回结果；若不存在则返回原字符串。

## 解题思路

找到字符 ch 第一次出现的下标 i，用双指针反转字符数组 `[0, i]` 区间，拼接后缀返回。

## Java 代码实现

### 方法一：双指针反转（推荐）

```java
class Solution {
    public String reversePrefix(String word, char ch) {
        int i = word.indexOf(ch);
        if (i == -1) return word;

        // 转为字符数组，双指针反转[0, i]
        char[] chars = word.toCharArray();
        int lo = 0, hi = i;
        while (lo < hi) {
            char tmp = chars[lo];
            chars[lo] = chars[hi];
            chars[hi] = tmp;
            lo++;
            hi--;
        }
        return new String(chars);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `indexOf(ch)` 返回第一次出现的下标，不存在返回 -1
2. 反转范围是 `[0, i]`（含 i），后缀 `[i+1:]` 不变
