## 题目描述

用邮票 stamp 多次盖在全 '?' 序列上得到目标字符串 target。返回盖章位置序列（逆向思考：从 target 逐步还原为 '?'）。

## 解题思路

逆向贪心：从 target 出发，每次找到能匹配的位置（允许已变 '?' 的位置），将匹配位置标记为 '?'。重复直到全为 '?'。结果逆序。

## Java 代码实现

```java
class Solution {
    public int[] movesToStamp(String stamp, String target) {
        int m = stamp.length(), n = target.length();
        char[] t = target.toCharArray();
        List<Integer> result = new ArrayList<>();
        int stamped = 0;

        while (stamped < n) {
            boolean found = false;
            for (int i = 0; i <= n - m; i++) {
                boolean changed = false, match = true;
                for (int j = 0; j < m; j++) {
                    if (t[i + j] == '?') continue;
                    if (t[i + j] != stamp.charAt(j)) { match = false; break; }
                    changed = true;
                }
                if (match && changed) {
                    for (int j = 0; j < m; j++) {
                        if (t[i + j] != '?') { stamped++; t[i + j] = '?'; }
                    }
                    result.add(i);
                    found = true;
                }
            }
            if (!found) return new int[0];
        }

        // 逆序输出
        int[] ans = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            ans[i] = result.get(result.size() - 1 - i);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × m)
- **空间复杂度**：O(n)

## 关键点总结

1. **逆向思维**：从 target 还原为全 '?'
2. **贪心匹配**：每轮尽可能多地盖章
3. **结果逆序**：逆向操作需要翻转结果
