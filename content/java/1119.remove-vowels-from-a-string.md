## 题目描述

给定字符串 s，移除所有元音字母（a, e, i, o, u）并返回新字符串。

**示例：**
```
输入：s = "leetcodeisacommunityforcoders"
输出："ltcdscmmntyfrcdrs"
```

## 解题思路

遍历过滤：逐字符检查是否为元音，非元音加入 StringBuilder。

## Java 代码实现

```java
class Solution {
    public String removeVowels(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if ("aeiou".indexOf(c) == -1) {
                sb.append(c);
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **StringBuilder**：高效拼接字符串
2. **indexOf 判断**：检查字符是否在元音集中
3. **也可用 replaceAll**：`s.replaceAll("[aeiou]", "")`
