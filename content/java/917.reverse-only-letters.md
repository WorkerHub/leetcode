## 题目描述

给你一个字符串 `s`，所有非英文字母保留在原有位置，所有英文字母位置反转。返回反转后的字符串。

**示例：**
```
输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"
```

## 解题思路

双指针：左右指针从两端向中间移动，遇到字母就交换，遇到非字母就跳过。

## Java 代码实现

```java
class Solution {
    public String reverseOnlyLetters(String s) {
        char[] chars = s.toCharArray();
        int left = 0, right = chars.length - 1;

        while (left < right) {
            // 左指针找到字母
            while (left < right && !Character.isLetter(chars[left])) left++;
            // 右指针找到字母
            while (left < right && !Character.isLetter(chars[right])) right--;
            // 交换
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
            left++;
            right--;
        }

        return new String(chars);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，字符数组

## 关键点总结

1. **双指针**：从两端向中间扫描
2. **跳过非字母**：`Character.isLetter()` 判断
3. **原地交换**：只交换字母位置
