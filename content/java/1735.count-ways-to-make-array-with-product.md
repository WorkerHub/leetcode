## 题目描述

给你查询数组 `queries[i] = [n, k]`，对每个查询，返回长度为 `n`、元素均为正整数且乘积等于 `k` 的数组方案数（对 `10^9+7` 取余）。

## 解题思路

将 `k` 做质因数分解 `k = p1^a1 * p2^a2 * ...`，每个质因数独立分配：把 `a` 个相同质因数分配到 `n` 个位置（允许为 0）的方案数 = 隔板法 `C(a+n-1, n-1)`。所有质因数方案数之积即为答案。预处理阶乘和逆元加速组合数计算。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;
    private static final int MAX = 14014;
    private static final long[] fact = new long[MAX + 1];
    private static final long[] invFact = new long[MAX + 1];

    static {
        // 预处理阶乘和逆元
        fact[0] = 1;
        for (int i = 1; i <= MAX; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[MAX] = modPow(fact[MAX], MOD - 2, MOD);
        for (int i = MAX - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;
    }

    private static long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }

    private static long comb(int n, int r) {
        // 计算 C(n, r)
        if (r < 0 || r > n) return 0;
        return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
    }

    public int[] waysToFillArray(int[][] queries) {
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int n = queries[i][0], k = queries[i][1];
            long result = 1;
            // 质因数分解 k
            for (int d = 2; d * d <= k; d++) {
                if (k % d == 0) {
                    int exp = 0;
                    while (k % d == 0) { exp++; k /= d; }
                    // 将 exp 个 d 分配到 n 个位置：C(exp + n - 1, n - 1)
                    result = result * comb(exp + n - 1, n - 1) % MOD;
                }
            }
            if (k > 1) {
                // k 本身是质数，指数为 1
                result = result * comb(n, n - 1) % MOD;
            }
            ans[i] = (int) result;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(Q * sqrt(k))
- **空间复杂度**：O(MAX) 预处理组合数

## 关键点总结

1. 质因数各自独立，方案数相乘
2. 隔板法：`a` 个相同元素分配到 `n` 个位置（可为 0）= `C(a+n-1, n-1)`
3. 预处理阶乘和费马逆元加速组合数
