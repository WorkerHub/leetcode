## 题目描述

4 张 1-9 的牌，判断能否通过 +、-、*、/ 运算得到 24。

**示例：**
```
输入：cards = [4, 1, 8, 7]
输出：true（(8-4) * (7-1) = 24）
```

## 解题思路

回溯：每次选两个数进行四则运算，将结果放回，递归处理剩余数。只剩一个数时判断是否为 24。

## Java 代码实现

```java
class Solution {
    private static final double EPSILON = 1e-6;

    public boolean judgePoint24(int[] cards) {
        List<Double> nums = new ArrayList<>();
        for (int card : cards) {
            nums.add((double) card);
        }
        return backtrack(nums);
    }

    private boolean backtrack(List<Double> nums) {
        int n = nums.size();
        if (n == 1) {
            return Math.abs(nums.get(0) - 24) < EPSILON;
        }

        // 选两个数进行运算
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j) continue;

                List<Double> remaining = new ArrayList<>();
                for (int k = 0; k < n; k++) {
                    if (k != i && k != j) remaining.add(nums.get(k));
                }

                double a = nums.get(i), b = nums.get(j);

                // 尝试四种运算
                double[] results = {a + b, a - b, a * b};
                for (double res : results) {
                    remaining.add(res);
                    if (backtrack(remaining)) return true;
                    remaining.remove(remaining.size() - 1);
                }

                // 除法需要检查除数不为0
                if (Math.abs(b) > EPSILON) {
                    remaining.add(a / b);
                    if (backtrack(remaining)) return true;
                    remaining.remove(remaining.size() - 1);
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，输入固定为4个数，搜索空间有限
- **空间复杂度**：O(1)，递归深度固定为3

## 关键点总结

1. **回溯思想**：选两个数运算，递归处理剩余
2. **浮点精度**：用 epsilon 判断是否等于 24
3. **除法处理**：检查除数不为 0
4. **顺序问题**：减法和除法不满足交换律，需要两个方向
