## 题目描述

从ideas中选两个名字交换首字母，若两个新名字都不在ideas中则可行，求可行对数。

## 解题思路

按首字母分组存后缀集合。对每对首字母(a,b)，交集中的后缀不可用，可行对数=(|A|-交集)*(|B|-交集)*2。

## Java 代码实现

```java
class Solution {
    public long distinctNames(String[] ideas) {
        // 按首字母分组存后缀
        Set<String>[] groups = new HashSet[26];
        for (int i = 0; i < 26; i++) groups[i] = new HashSet<>();
        for (String idea : ideas) {
            groups[idea.charAt(0) - 'a'].add(idea.substring(1));
        }

        long ans = 0;
        for (int i = 0; i < 26; i++) {
            for (int j = i + 1; j < 26; j++) {
                // 计算交集大小
                int mutual = 0;
                for (String s : groups[i]) {
                    if (groups[j].contains(s)) mutual++;
                }
                long cntA = groups[i].size() - mutual;
                long cntB = groups[j].size() - mutual;
                ans += cntA * cntB * 2;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * L + 26^2 * N)
- **空间复杂度**：O(N * L)

## 关键点总结

1. **按首字母分组**：将问题转化为集合运算
2. **交集后缀不可交换**：去掉交集后两组独立配对
3. **乘2**：(a,b)和(b,a)都算可行对
