## 题目描述

单线程 CPU 上执行 n 个函数，日志格式为 `"{function_id}:{"start"|"end"}:{timestamp}"`，返回每个函数的独占时间。

**示例：**
```
输入：n = 2, logs = ["0:start:0","1:start:2","1:end:5","0:end:6"]
输出：[3,4]
```

## 解题思路

用栈模拟函数调用：start 入栈，end 出栈，用 prevTime 追踪时间段。

## Java 代码实现

```java
class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        int prevTime = 0;

        for (String log : logs) {
            String[] parts = log.split(":");
            int funcId = Integer.parseInt(parts[0]);
            String action = parts[1];
            int timestamp = Integer.parseInt(parts[2]);

            if (action.equals("start")) {
                if (!stack.isEmpty()) {
                    // 累加栈顶函数的时间
                    result[stack.peek()] += timestamp - prevTime;
                }
                stack.push(funcId);
                prevTime = timestamp;
            } else {
                // end: 累加当前函数时间（包含当前时间点）
                result[stack.pop()] += timestamp - prevTime + 1;
                prevTime = timestamp + 1;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m)，m 为日志数量
- **空间复杂度**：O(n)

## 关键点总结

1. **栈跟踪当前函数**：start 入栈，end 出栈
2. **end 时间包含当前点**：+1 处理
3. **prevTime 更新**：start 设为 timestamp，end 设为 timestamp+1
