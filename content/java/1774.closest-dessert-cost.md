## 题目描述

有 n 种基料（必选一种）和 m 种配料（每种 0/1/2 份），返回总费用最接近 `target` 的值（多种答案取较小）。

## 解题思路

枚举每种基料，回溯枚举所有配料组合（3^m 种），找最接近 target 的费用。超过 target 时剪枝。

## Java 代码实现

```java
class Solution {
    private int ans;
    private int target;
    private int[] toppingCosts;

    public int closestCost(int[] baseCosts, int[] toppingCosts, int target) {
        this.target = target;
        this.toppingCosts = toppingCosts;
        this.ans = Integer.MAX_VALUE;

        for (int base : baseCosts) {
            backtrack(0, base);
        }
        return ans;
    }

    private void backtrack(int idx, int cur) {
        // 更新答案：绝对差更小，或相等时取较小值
        int diff = Math.abs(cur - target);
        int ansDiff = Math.abs(ans - target);
        if (diff < ansDiff || (diff == ansDiff && cur < ans)) {
            ans = cur;
        }

        // 剪枝：当前费用已超过 target 且不可能更优
        if (cur >= target || idx == toppingCosts.length) return;

        // 配料 idx 可以加 0、1 或 2 份
        for (int cnt = 0; cnt <= 2; cnt++) {
            backtrack(idx + 1, cur + toppingCosts[idx] * cnt);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 3^m)，n 为基料数，m 为配料数
- **空间复杂度**：O(m)，递归栈

## 关键点总结

1. 枚举所有配料组合（每种 0/1/2 份），3^10 约 6 万种
2. 多种等距答案取较小值
