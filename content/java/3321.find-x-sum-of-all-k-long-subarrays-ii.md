## 题目描述

与 3318 相同，但数据范围更大（n <= 10^5），需要高效解法。对每个长度为 k 的子数组计算 x-sum（选频率最高的 x 种数字，同频选数值大的，结果乘频率）。

## 解题思路

双 TreeSet 维护 top-x：`top` 保存当前出现频率最高的 x 个不同数字（按 (freq,val) 排序），`bot` 保存其余；维护 `topSum` 增量更新。滑动窗口每次移入/移出一个元素时，更新对应的 (freq, val) 对并重新平衡两个集合。

## Java 代码实现

```java
import java.util.*;

class Solution {
    // 比较器：按 (freq asc, val asc)，末尾元素最大
    private static final Comparator<long[]> CMP =
        (a, b) -> a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]);

    private TreeSet<long[]> top, bot;
    private long topSum;
    private int x;

    public long[] findXSum(int[] nums, int k, int x) {
        this.x = x;
        top = new TreeSet<>(CMP);
        bot = new TreeSet<>(CMP);
        topSum = 0;
        Map<Integer, Integer> freq = new HashMap<>();
        int n = nums.length;
        long[] result = new long[n - k + 1];

        for (int i = 0; i < n; i++) {
            addNum(nums[i], freq);
            if (i >= k) removeNum(nums[i - k], freq);
            if (i >= k - 1) result[i - k + 1] = topSum;
        }
        return result;
    }

    private void addNum(int val, Map<Integer, Integer> freq) {
        int oldF = freq.getOrDefault(val, 0);
        if (oldF > 0) erase(oldF, val);
        freq.merge(val, 1, Integer::sum);
        // 先加入 bot，由 balance 决定是否移入 top
        bot.add(new long[]{freq.get(val), val});
        balance();
    }

    private void removeNum(int val, Map<Integer, Integer> freq) {
        int oldF = freq.get(val);
        erase(oldF, val);
        freq.merge(val, -1, Integer::sum);
        int newF = freq.get(val);
        if (newF > 0) bot.add(new long[]{newF, val});
        else freq.remove(val);
        balance();
    }

    // 从 top 或 bot 中删除 (f, val)
    private void erase(int f, int val) {
        long[] entry = {f, val};
        if (top.remove(entry)) topSum -= (long) f * val;
        else bot.remove(entry);
    }

    private void balance() {
        // top 过多，移出最小元素到 bot
        while (top.size() > x) {
            long[] e = top.first();
            top.remove(e); topSum -= e[0] * e[1]; bot.add(e);
        }
        // top 不足，从 bot 移入最大元素
        while (top.size() < x && !bot.isEmpty()) {
            long[] e = bot.last();
            bot.remove(e); top.add(e); topSum += e[0] * e[1];
        }
        // 确保 top 中最小 >= bot 中最大（保持 top 为最大的 x 个）
        while (!bot.isEmpty() && !top.isEmpty()) {
            long[] bMax = bot.last(), tMin = top.first();
            if (CMP.compare(bMax, tMin) > 0) {
                bot.remove(bMax); top.remove(tMin);
                topSum += bMax[0] * bMax[1] - tMin[0] * tMin[1];
                top.add(bMax); bot.add(tMin);
            } else break;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次滑动窗口操作均为 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 双 TreeSet 按 (freq, val) 维护 top-x，topSum 增量更新避免每次重算
2. 频率变化时先 erase 旧 (freq, val)，再插入新 (freq, val) 到 bot，然后 balance
3. balance 三步：缩减 top → 填充 top → 交换确保 top 中全为最大 x 个
