## 题目描述

根据前序遍历输出字符串恢复二叉树。深度用短划线数量表示（根节点深度 0 无短划线），节点值紧跟其后。

**示例：**
```
输入：S = "1-2--3--4-5--6--7"
输出：[1,2,5,3,4,6,7]
```

## 解题思路

栈模拟：解析字符串得到 (深度, 值) 对，用栈维护当前路径。栈大小 > 当前深度时弹出，栈顶即为父节点。

## Java 代码实现

```java
class Solution {
    public TreeNode recoverFromPreorder(String traversal) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        int i = 0;

        while (i < traversal.length()) {
            // 统计深度
            int depth = 0;
            while (i < traversal.length() && traversal.charAt(i) == '-') {
                depth++;
                i++;
            }

            // 解析节点值
            int val = 0;
            while (i < traversal.length() && Character.isDigit(traversal.charAt(i))) {
                val = val * 10 + (traversal.charAt(i) - '0');
                i++;
            }

            TreeNode node = new TreeNode(val);

            // 调整栈深度
            while (stack.size() > depth) {
                stack.pop();
            }

            // 建立父子关系
            if (!stack.isEmpty()) {
                TreeNode parent = stack.peek();
                if (parent.left == null) {
                    parent.left = node;
                } else {
                    parent.right = node;
                }
            }

            stack.push(node);
        }

        // 栈底为根节点
        while (stack.size() > 1) stack.pop();
        return stack.peek();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为字符串长度
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **栈维护路径**：栈大小等于当前深度时栈顶为父节点
2. **解析规则**：短划线数 = 深度，紧跟数字 = 值
3. **左右判断**：父节点左空设左子，否则设右子
