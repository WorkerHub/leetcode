## 题目描述

找出长度大于等于 k 的连续子数组的最大平均值。

**示例：**
```
输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75000
```

## 解题思路

二分答案：二分平均值 mid，将数组每个元素减去 mid 后，检查是否存在长度≥k 且和≥0 的子数组。

## Java 代码实现

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        double left = Integer.MAX_VALUE, right = Integer.MIN_VALUE;
        for (int num : nums) {
            left = Math.min(left, num);
            right = Math.max(right, num);
        }

        while (right - left > 1e-5) {
            double mid = (left + right) / 2;
            if (check(nums, k, mid)) {
                left = mid;
            } else {
                right = mid;
            }
        }
        return left;
    }

    private boolean check(int[] nums, int k, double mid) {
        // 检查是否存在长度>=k的子数组，平均值>=mid
        int n = nums.length;
        double curSum = 0;
        for (int i = 0; i < k; i++) {
            curSum += nums[i] - mid;
        }
        if (curSum >= 0) return true;

        double preSum = 0, minPreSum = 0;
        for (int i = k; i < n; i++) {
            curSum += nums[i] - mid;
            preSum += nums[i - k] - mid;
            minPreSum = Math.min(minPreSum, preSum);
            if (curSum - minPreSum >= 0) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log((max-min)/ε))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：利用平均值的单调性
2. **问题转化**：减去 mid 后判断是否存在和≥0 的子数组
3. **维护最小前缀和**：保证子数组长度≥k
