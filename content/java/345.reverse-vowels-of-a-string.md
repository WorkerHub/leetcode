## 题目描述

给你一个字符串 `s`，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，且可能以大小写两种形式出现不止一次。

**示例 1：**
```
输入：s = "hello"
输出："holle"
```

**示例 2：**
```
输入：s = "leetcode"
输出："leotcede"
```

**提示：**
- `1 <= s.length <= 3 * 10^5`
- `s` 由可打印的 ASCII 字符组成

## 解题思路

这道题是第 344 题（反转字符串）的变形，区别在于只反转元音字母。

**核心思想：**
使用双指针，从两端向中间移动，只有当两个指针都指向元音字母时才进行交换。

**算法流程：**
1. 定义元音字母集合（包含大小写）
2. 左指针从左往右找元音，右指针从右往左找元音
3. 当两个指针都找到元音时，交换它们
4. 继续移动指针，直到两指针相遇

**时间复杂度：** O(n)
**空间复杂度：** O(n)，因为 Java String 不可变，需要转换为 char 数组

## Java 代码实现

### 方法一：双指针（标准解法）⭐

```java
class Solution {
    public String reverseVowels(String s) {
        // 定义元音字母集合（包含大小写）
        Set<Character> vowels = new HashSet<>(
            Arrays.asList('a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U')
        );

        // 将字符串转为 char 数组（Java String 不可变）
        char[] chars = s.toCharArray();

        // 双指针
        int left = 0, right = chars.length - 1;

        while (left < right) {
            // 左指针向右移动，直到找到元音
            while (left < right && !vowels.contains(chars[left])) {
                left++;
            }

            // 右指针向左移动，直到找到元音
            while (left < right && !vowels.contains(chars[right])) {
                right--;
            }

            // 交换两个元音字母
            if (left < right) {
                char temp = chars[left];
                chars[left] = chars[right];
                chars[right] = temp;

                // 移动指针
                left++;
                right--;
            }
        }

        // 转回字符串
        return new String(chars);
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

### 方法二：简化版（合并判断）

```java
class Solution {
    public String reverseVowels(String s) {
        Set<Character> vowels = new HashSet<>(
            Arrays.asList('a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U')
        );
        char[] chars = s.toCharArray();
        int left = 0, right = chars.length - 1;

        while (left < right) {
            // 如果左边不是元音，左指针右移
            if (!vowels.contains(chars[left])) {
                left++;
            }
            // 如果右边不是元音，右指针左移
            else if (!vowels.contains(chars[right])) {
                right--;
            }
            // 两边都是元音，交换并移动
            else {
                char temp = chars[left];
                chars[left] = chars[right];
                chars[right] = temp;
                left++;
                right--;
            }
        }

        return new String(chars);
    }
}
```

### 方法三：使用字符串索引标记

```java
class Solution {
    public String reverseVowels(String s) {
        String vowelStr = "aeiouAEIOU";
        char[] chars = s.toCharArray();

        // 收集所有元音字母及其位置
        List<Character> vowelChars = new ArrayList<>();
        List<Integer> vowelPositions = new ArrayList<>();

        for (int i = 0; i < chars.length; i++) {
            if (vowelStr.indexOf(chars[i]) != -1) {
                vowelChars.add(chars[i]);
                vowelPositions.add(i);
            }
        }

        // 反转元音字母列表
        int n = vowelChars.size();
        for (int i = 0, j = n - 1; i < j; i++, j--) {
            char temp = vowelChars.get(i);
            vowelChars.set(i, vowelChars.get(j));
            vowelChars.set(j, temp);
        }

        // 放回原位置
        for (int i = 0; i < vowelPositions.size(); i++) {
            chars[vowelPositions.get(i)] = vowelChars.get(i);
        }

        return new String(chars);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 双指针 while | O(n) | O(n) | 高效，一次遍历 | 需要转 char 数组 |
| if-elif-else | O(n) | O(n) | 代码简洁 | 同上 |
| 索引标记 | O(n) | O(n) | 思路清晰 | 两次遍历 |

```
  e e     o   e

反转元音：e o e e

放回原位：
l e o t c e d e
  ↑ ↑     ↑   ↑

双指针过程：
初始：
left          right
 ↓              ↓
[l, e, e, t, c, o, d, e]

left 找到 e(index=1)，right 找到 e(index=7)
交换后：
[l, e, e, t, c, o, d, e]

继续移动：
left 找到 e(index=2)，right 找到 o(index=5)
交换后：
[l, e, o, t, c, e, d, e]

left >= right，结束
```

## 关键点总结

1. **元音集合**：使用 HashSet 存储元音字母，O(1) 查找
2. **大小写**：要同时考虑大小写元音
3. **双指针**：两个指针都找到元音才交换
4. **字符串不可变**：Java 需要先转为 char 数组
5. **边界条件**：left < right 防止越界

## 易错点

1. **忘记大小写**
   ```java
   // 错误：只包含小写
   Set<Character> vowels = new HashSet<>(Arrays.asList('a', 'e', 'i', 'o', 'u'));

   // 正确：包含大小写
   Set<Character> vowels = new HashSet<>(
       Arrays.asList('a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', 'U')
   );
   ```

2. **没有检查 left < right**
   ```java
   // 错误：可能导致指针越界
   while (left < right && !vowels.contains(chars[left])) {
       left++;
   }
   // 此时 left 可能 >= right，直接访问 chars[right] 可能交换了不该交换的

   // 正确：每次都检查
   while (left < right && !vowels.contains(chars[left])) {
       left++;
   }
   while (left < right && !vowels.contains(chars[right])) {
       right--;
   }
   ```

3. **直接修改 String**
   ```java
   // 错误：String 不可变，无法直接修改
   // s.charAt(0) = 'a';  // 编译错误

   // 正确：转为 char 数组
   char[] chars = s.toCharArray();
   chars[0] = 'a';
   return new String(chars);
   ```

4. **集合查询效率**
   ```java
   // 不推荐：String.indexOf 需要逐字符比较
   String vowelStr = "aeiou";
   if (vowelStr.indexOf(chars[left]) >= 0) { ... }  // O(n) 查询

   // 推荐：HashSet 查询 O(1)
   Set<Character> vowels = new HashSet<>(...);
   if (vowels.contains(chars[left])) { ... }  // O(1) 查询
   ```

5. **交换后忘记移动指针**
   ```java
   // 错误：可能导致死循环
   if (vowels.contains(chars[left]) && vowels.contains(chars[right])) {
       char temp = chars[left];
       chars[left] = chars[right];
       chars[right] = temp;
       // 忘记移动指针
   }

   // 正确：
   else {
       char temp = chars[left];
       chars[left] = chars[right];
       chars[right] = temp;
       left++;
       right--;
   }
   ```
