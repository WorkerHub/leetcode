## 题目描述

给定小写字母字符串 `s`，每次操作可删除任意一个字符，返回使所有字母出现频率相等所需的最少操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumOperations(String s) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        // 收集非零频率并排序
        List<Integer> freq = new ArrayList<>();
        for (int f : cnt) if (f > 0) freq.add(f);
        Collections.sort(freq);
        int n = freq.size();

        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + freq.get(i);

        int best = prefix[n]; // 全删代价（target=0）

        for (int i = 0; i < n; i++) {
            // 目标频率 = freq[i]：前 i 个字母全删，后面削减到 freq[i]
            int target = freq.get(i);
            int cost = prefix[i] + (prefix[n] - prefix[i]) - target * (n - i);
            best = Math.min(best, cost);

            // 目标频率 = freq[i] - 1：前 i+1 个字母全删，后面削减到 freq[i]-1
            if (target - 1 >= 0) {
                int t2 = target - 1;
                int cost2 = prefix[i + 1];
                if (n - i - 1 > 0) {
                    cost2 += (prefix[n] - prefix[i + 1]) - t2 * (n - i - 1);
                }
                best = Math.min(best, cost2);
            }
        }

        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26 log 26)，字母数量固定为 26
- 空间复杂度：O(26)

## 关键点总结

1. 只能删除字符，目标频率只能是现有频率中某个值或 0。
2. 对于低于目标频率的字母，只能全删（无法增加）。
3. 枚举每个 `freq[i]` 和 `freq[i]-1` 作为目标，用前缀和 O(1) 计算代价。
