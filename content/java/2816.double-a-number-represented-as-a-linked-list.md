## 题目描述

将链表表示的非负整数乘以2，返回结果链表。

## 解题思路

递归到链表末尾，返回进位。每个节点值*2加上子节点的进位，更新当前值和向上传递进位。

## Java 代码实现

```java
class Solution {
    public ListNode doubleIt(ListNode head) {
        int carry = doubleNode(head);
        if (carry > 0) {
            ListNode newHead = new ListNode(carry);
            newHead.next = head;
            return newHead;
        }
        return head;
    }

    private int doubleNode(ListNode node) {
        if (node == null) return 0;
        int doubled = node.val * 2 + doubleNode(node.next);
        node.val = doubled % 10;
        return doubled / 10;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)，递归栈

## 关键点总结

1. **递归到末尾返回进位**：自底向上处理
2. **最高位进位需新建头节点**
3. **每位计算：val*2+carry**
