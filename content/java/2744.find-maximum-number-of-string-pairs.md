## 题目描述

给你长度均为 2 的字符串数组 `words`，如果 `words[i]` 等于 `words[j]` 的反转则为一对（每个字符串最多属于一对），返回最多能形成的字符串对数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximumNumberOfStringPairs(String[] words) {
        Set<String> seen = new HashSet<>();
        int ans = 0;
        for (String word : words) {
            // 生成反转字符串
            String rev = "" + word.charAt(1) + word.charAt(0);
            if (seen.contains(rev)) {
                ans++;
                seen.remove(rev);  // 已配对，移除防止重复配对
            } else {
                seen.add(word);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每个字符串最多参与一对
2. 字符串长度固定为 2，反转操作很快
