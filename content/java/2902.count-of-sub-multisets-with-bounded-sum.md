## 题目描述

给你非负整数数组 nums 和整数 l、r，返回元素和在 [l, r] 范围内的子多重集数目，答案对 10^9+7 取模。

## 解题思路

多重背包 + 前缀和优化：统计每种值的出现次数，单独处理 0（贡献 cnt0+1 倍），对剩余每种值 v（出现 c 次）用前缀和滑动窗口将转移从 O(S×c) 优化为 O(S)，最终对 [l,r] 区间求和。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int countSubMultisets(List<Integer> nums, int l, int r) {
        int total = nums.stream().mapToInt(Integer::intValue).sum();
        if (l > total) return 0;
        r = Math.min(r, total);

        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) cnt.merge(x, 1, Integer::sum);

        // 单独处理 0：有 cnt(0)+1 种选法
        int zeroFactor = cnt.getOrDefault(0, 0) + 1;
        cnt.remove(0);

        int[] dp = new int[r + 1];
        dp[0] = 1;

        for (Map.Entry<Integer, Integer> entry : cnt.entrySet()) {
            int v = entry.getKey(), c = entry.getValue();
            if (v > r) continue;

            // 前缀和优化多重背包（对每个余数类）
            int[] newDp = dp.clone();
            for (int rem = 0; rem < v; rem++) {
                // 收集同余类的前缀和
                List<Integer> indices = new ArrayList<>();
                for (int idx = rem; idx <= r; idx += v) indices.add(idx);

                long[] prefix = new long[indices.size() + 1];
                for (int i = 0; i < indices.size(); i++) {
                    prefix[i + 1] = (prefix[i] + dp[indices.get(i)]) % MOD;
                }

                for (int i = 0; i < indices.size(); i++) {
                    int lo = Math.max(0, i - c);
                    newDp[indices.get(i)] = (int) ((prefix[i + 1] - prefix[lo] + MOD) % MOD);
                }
            }
            dp = newDp;
        }

        long ans = 0;
        for (int s = l; s <= r; s++) ans = (ans + dp[s]) % MOD;
        return (int) (ans * zeroFactor % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(S × K)，S = sum(nums)，K 为不同数字种类数，整体趋近 O(S)
- **空间复杂度**：O(S)

## 关键点总结

1. 0 单独处理（不影响和但有 cnt0+1 种选法），最后乘以倍数
2. 前缀和滑动窗口优化有界多重背包，按余数类分组处理
3. r 需要 clamp 到 total，防止数组越界
