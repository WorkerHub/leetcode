## 题目描述

给定一个数字 `n`，如果这个数字在旋转 `180°` 以后，得到的数字和原数字不同，则称这个数字为**易混淆数字**。

我们可以顺时针或逆时针旋转数字 `180°`。

当数字旋转 `180°` 后，数字中的每一位会发生如下变化：
- `0` 旋转后变为 `0`
- `1` 旋转后变为 `1`
- `6` 旋转后变为 `9`
- `8` 旋转后变为 `8`
- `9` 旋转后变为 `6`

数字 `2`、`3`、`4`、`5` 和 `7` 旋转后无法得到有效数字。

如果旋转后得到的数字与原数字不同，则该数字为易混淆数字，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：n = 6
输出：true
解释：6 旋转 180° 后变为 9，9 ≠ 6。
```

**示例 2：**
```
输入：n = 89
输出：true
解释：89 旋转 180° 后变为 68，68 ≠ 89。
```

**示例 3：**
```
输入：n = 11
输出：false
解释：11 旋转 180° 后仍为 11，11 = 11。
```

**提示：**
- `0 <= n <= 10^9`

## 解题思路

这道题的关键是理解旋转规则和判断条件：

1. **有效性检查**：数字中不能包含 `2, 3, 4, 5, 7`，否则旋转后无效
2. **旋转映射**：`0→0, 1→1, 6→9, 8→8, 9→6`
3. **比较判断**：旋转后的数字必须与原数字不同

**算法流程：**
1. 将数字逐位处理
2. 如果遇到无效数字（`2, 3, 4, 5, 7`），直接返回 `false`
3. 根据映射规则构建旋转后的数字
4. 比较旋转后的数字与原数字是否相同

## Java 代码实现

### 方法一：数学方法（推荐）

```java
class Solution {
    public boolean confusingNumber(int n) {
        // 时间复杂度：O(log n)
        // 空间复杂度：O(1)

        // 旋转映射（-1 表示无效）
        int[] rotateMap = {0, 1, -1, -1, -1, -1, 9, -1, 8, 6};

        int original = n;
        int rotated = 0;

        while (n > 0) {
            int digit = n % 10;

            // 如果数字不能旋转
            if (rotateMap[digit] == -1) {
                return false;
            }

            // 构建旋转后的数字
            rotated = rotated * 10 + rotateMap[digit];
            n /= 10;
        }

        // 比较旋转后的数字和原数字
        return rotated != original;
    }
}
```

### 方法二：字符串处理

```java
class Solution {
    public boolean confusingNumber(int n) {
        // 使用字符串处理
        // 时间复杂度：O(log n)
        // 空间复杂度：O(log n)

        // 旋转映射表
        java.util.Map<Character, Character> rotateMap = new java.util.HashMap<>();
        rotateMap.put('0', '0');
        rotateMap.put('1', '1');
        rotateMap.put('6', '9');
        rotateMap.put('8', '8');
        rotateMap.put('9', '6');

        String s = String.valueOf(n);

        // 构建旋转后的字符串
        StringBuilder rotated = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (!rotateMap.containsKey(c)) {
                return false;
            }
            rotated.append(rotateMap.get(c));
        }

        // 旋转后需要反转字符串（因为是 180° 旋转）
        String rotatedStr = rotated.reverse().toString();

        // 比较旋转后的数字和原数字
        return !rotatedStr.equals(s);
    }
}
```

## 复杂度分析

**时间复杂度：** O(log n)
- log n 是数字的位数
- 需要遍历每一位进行检查和转换

**空间复杂度：**
- 方法一：O(1)，只用常量空间
- 方法二：O(log n)，需要存储字符串

## 图解示例

**示例 1：n = 89**

```
原数字：8 9

旋转映射：
8 → 8
9 → 6

旋转后反转：6 8

68 ≠ 89，所以是易混淆数字 ✓
```

**示例 2：n = 11**

```
原数字：1 1

旋转映射：
1 → 1
1 → 1

旋转后反转：1 1

11 = 11，所以不是易混淆数字 ✗
```

## 关键点总结

1. **旋转规则**：只有 `0, 1, 6, 8, 9` 可以旋转，其他数字无效
2. **映射关系**：`0→0, 1→1, 6→9, 8→8, 9→6`
3. **反转操作**：旋转 180° 后，数字的顺序也会反转
4. **判断条件**：旋转后与原数字不同才是易混淆数字

## 易错点

1. **忘记反转**：旋转 180° 不仅要映射数字，还要反转顺序
2. **对称数字**：`0, 1, 8` 旋转后不变，但如果整个数字是回文且只包含这些，则不是易混淆数字
3. **无效数字**：包含 `2, 3, 4, 5, 7` 的数字直接返回 `false`
4. **边界情况**：`n = 0`：旋转后仍为 0，返回 `false`
