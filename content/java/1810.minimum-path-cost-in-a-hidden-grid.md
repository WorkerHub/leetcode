## 题目描述

交互题：隐藏带权网格，从 (0,0) 出发，通过 `canMove`/`move` 探索，`move` 返回目标格代价（-1 表示终点）。返回到终点的最小代价，不可达返回 -1。

## 解题思路

两阶段：先 DFS（带回溯）探索所有可达格子构建带权图，再在图上用 Dijkstra 求最短路。

## Java 代码实现

```java
import java.util.*;

interface GridMaster {
    boolean canMove(char direction);
    int move(char direction);
    boolean isTarget();
}

class Solution {
    private static final char[] DIRS = {'U', 'D', 'L', 'R'};
    private static final int[][] DELTAS = {{-1,0},{1,0},{0,-1},{0,1}};
    private static final char[] OPP = {'D','U','R','L'};

    private Map<Long, List<long[]>> graph = new HashMap<>(); // key -> [(cost, nkey)]
    private long targetKey = Long.MIN_VALUE;

    public int findShortestPath(GridMaster master) {
        dfs(master, 0, 0);
        if (targetKey == Long.MIN_VALUE) return -1;

        // Dijkstra 求最短路
        long startKey = encode(0, 0);
        Map<Long, Integer> dist = new HashMap<>();
        dist.put(startKey, 0);
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, startKey});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int d = (int) cur[0];
            long key = cur[1];
            if (key == targetKey) return d;
            if (d > dist.getOrDefault(key, Integer.MAX_VALUE)) continue;
            for (long[] nb : graph.getOrDefault(key, Collections.emptyList())) {
                int nd = d + (int) nb[0];
                long nk = nb[1];
                if (nd < dist.getOrDefault(nk, Integer.MAX_VALUE)) {
                    dist.put(nk, nd);
                    pq.offer(new long[]{nd, nk});
                }
            }
        }
        return -1;
    }

    private void dfs(GridMaster master, int r, int c) {
        long key = encode(r, c);
        if (!graph.containsKey(key)) graph.put(key, new ArrayList<>());
        if (master.isTarget()) targetKey = key;

        for (int i = 0; i < 4; i++) {
            int nr = r + DELTAS[i][0], nc = c + DELTAS[i][1];
            long nkey = encode(nr, nc);
            if (!graph.containsKey(nkey) && master.canMove(DIRS[i])) {
                int cost = master.move(DIRS[i]);
                if (cost == -1) cost = 0; // 终点代价视为 0
                graph.get(key).add(new long[]{cost, nkey});
                graph.put(nkey, new ArrayList<>());
                dfs(master, nr, nc);
                master.move(OPP[i]); // 回溯
            }
        }
    }

    private long encode(int r, int c) {
        return ((long)(r + 1000)) * 10000 + (c + 1000);
    }
}
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)
- **空间复杂度**：O(V + E)

## 关键点总结

1. DFS 探图时每次移动后必须沿反方向回溯
2. 起点 (0,0) 进入某格时的代价是到达该格的代价（move 返回值）
3. Dijkstra 用于有权图最短路
