## 题目描述

给你一组任务 `tasks[i] = [start_i, end_i, duration_i]`，任务 i 必须在 `[start_i, end_i]` 内完成，需要 `duration_i` 个连续时间单位，且任务不能同时进行。返回完成所有任务的最短时间，不可能则返回 -1。

## 解题思路

按截止时间排序后贪心验证可行性：每个任务在 `[max(start, current_time), end]` 内安排，若可用时间不足则返回 -1。总时间即为所有 duration 之和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int[][] tasks) {
        Arrays.sort(tasks, (a, b) -> Integer.compare(a[1], b[1])); // 按截止时间排序
        int currentTime = 0;
        int total = 0;

        for (int[] task : tasks) {
            int start = task[0], end = task[1], duration = task[2];
            int available = end - Math.max(start, currentTime) + 1;
            if (available < duration) return -1;
            total += duration;
            currentTime = Math.max(currentTime, start) + duration;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 按截止时间排序，确保最早截止的任务先安排
2. 检验每个任务是否有足够的时间窗口（可用时间 >= duration）
3. 总时间固定为各任务 duration 之和，关键是验证可行性
