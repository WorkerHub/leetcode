## 题目描述

给定有 `n` 个节点的树，节点值为 0-9 的数字，若连通子树中每个数字最多出现一次则称为"好子树"，其分数为所有节点值之和，求最大好子树分数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] vals;
    private List<List<Integer>> graph;
    private long ans = 0;

    public long maxGoodSubtreeScore(int[] vals, int[][] edges) {
        int n = vals.length;
        this.vals = vals;
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        dfs(0, -1);
        return ans;
    }

    // 返回以 v 为根的 dp 数组：dp[mask] = 使用该数字集合的最大分数
    private long[] dfs(int v, int parent) {
        int d = vals[v];
        int bit = 1 << d;
        // 初始：只含节点 v
        long[] dp = new long[1 << 10];
        Arrays.fill(dp, -1);
        dp[bit] = d;
        ans = Math.max(ans, d);

        for (int u : graph.get(v)) {
            if (u == parent) continue;
            long[] childDp = dfs(u, v);
            long[] newDp = Arrays.copyOf(dp, dp.length);

            // 合并 dp 和 childDp（两者数字集合无交集）
            for (int mask1 = 0; mask1 < (1 << 10); mask1++) {
                if (dp[mask1] < 0) continue;
                // 枚举 mask2 为 mask1 的补集的子集
                int comp = (~mask1) & ((1 << 10) - 1);
                for (int mask2 = comp; mask2 > 0; mask2 = (mask2 - 1) & comp) {
                    if (childDp[mask2] < 0) continue;
                    int newMask = mask1 | mask2;
                    long newScore = dp[mask1] + childDp[mask2];
                    if (newDp[newMask] < newScore) {
                        newDp[newMask] = newScore;
                        ans = Math.max(ans, newScore);
                    }
                }
            }
            dp = newDp;
        }
        return dp;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 4^5) = O(n * 2^10 * 子集枚举)，最坏情况
- 空间复杂度：O(n * 2^10)

## 关键点总结

1. 数字范围 0-9，用 10 位掩码表示数字集合（共 1024 种状态）
2. 树形 DP 合并子树时，确保两子树的数字集合没有交集（`mask1 & mask2 == 0`）
3. 枚举补集的子集以高效合并
