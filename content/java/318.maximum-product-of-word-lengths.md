## 题目描述

给你一个字符串数组 `words`，找出并返回 `length(words[i]) * length(words[j])` 的最大值，并且这两个单词不含有公共字母。如果不存在这样的两个单词，返回 `0`。

**示例 1：**
```
输入：words = ["abcw","baz","foo","bar","xtfn","abcdef"]
输出：16 
解释：这两个单词为 "abcw", "xtfn"。
```

**示例 2：**
```
输入：words = ["a","ab","abc","d","cd","bcd","abcd"]
输出：4 
解释：这两个单词为 "ab", "cd"。
```

**示例 3：**
```
输入：words = ["a","aa","aaa","aaaa"]
输出：0 
解释：不存在这样的两个单词。
```

**提示：**
- `2 <= words.length <= 1000`
- `1 <= words[i].length <= 1000`
- `words[i]` 仅包含小写字母

## 解题思路

### 核心问题

如何快速判断两个单词是否有公共字母？

### 方法对比

| 方法 | 判断公共字母 | 时间复杂度 |
|------|-------------|-----------|
| 暴力 | 双重循环比较字符 | O(n² × L²) |
| 集合 | set交集 | O(n² × L) |
| 位运算 | 位掩码 | O(n² + nL) |

### 位运算优化⭐

使用一个整数的26位表示26个字母：
- 第i位为1表示该单词包含字母i
- 两个单词无公共字母 ⟺ mask1 & mask2 == 0

## Java 代码实现

### 方法一：位运算（推荐）⭐

```java
class Solution {
    public int maxProduct(String[] words) {
        int n = words.length;

        // 为每个单词计算位掩码
        int[] masks = new int[n];
        for (int i = 0; i < n; i++) {
            for (char c : words[i].toCharArray()) {
                masks[i] |= 1 << (c - 'a');
            }
        }

        int maxProd = 0;

        // 枚举所有单词对
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 无公共字母
                if ((masks[i] & masks[j]) == 0) {
                    maxProd = Math.max(maxProd, words[i].length() * words[j].length());
                }
            }
        }

        return maxProd;
    }
}
```

### 方法二：位运算 + 哈希优化

```java
import java.util.*;

class Solution {
    public int maxProduct(String[] words) {
        // 使用哈希表存储：{位掩码: 最大长度}
        // 相同位掩码的单词只保留最长的
        Map<Integer, Integer> maskToLen = new HashMap<>();

        for (String word : words) {
            int mask = 0;
            for (char c : word.toCharArray()) {
                mask |= 1 << (c - 'a');
            }
            // 更新该掩码对应的最大长度
            maskToLen.put(mask, Math.max(maskToLen.getOrDefault(mask, 0), word.length()));
        }

        int maxProd = 0;

        // 枚举所有掩码对
        List<Integer> maskList = new ArrayList<>(maskToLen.keySet());
        for (int i = 0; i < maskList.size(); i++) {
            for (int j = i + 1; j < maskList.size(); j++) {
                if ((maskList.get(i) & maskList.get(j)) == 0) {
                    maxProd = Math.max(maxProd,
                            maskToLen.get(maskList.get(i)) * maskToLen.get(maskList.get(j)));
                }
            }
        }

        return maxProd;
    }
}
```

### 方法三：使用集合

```java
import java.util.*;

class Solution {
    public int maxProduct(String[] words) {
        int n = words.length;
        // 为每个单词构建字符集合
        Set<Character>[] wordSets = new HashSet[n];
        for (int i = 0; i < n; i++) {
            wordSets[i] = new HashSet<>();
            for (char c : words[i].toCharArray()) {
                wordSets[i].add(c);
            }
        }

        int maxProd = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 检查两个集合是否无交集
                boolean hasCommon = false;
                for (char c : wordSets[i]) {
                    if (wordSets[j].contains(c)) {
                        hasCommon = true;
                        break;
                    }
                }
                if (!hasCommon) {
                    maxProd = Math.max(maxProd, words[i].length() * words[j].length());
                }
            }
        }

        return maxProd;
    }
}
```

### 方法四：带详细注释

```java
class Solution {
    /**
     * 位运算优化
     *
     * 核心思想：
     * 1. 用26位整数表示单词包含的字母
     * 2. 位掩码为0表示无公共字母
     * 3. 枚举所有单词对找最大乘积
     *
     * 位掩码示例：
     * "abc" -> ...000000111 (第0,1,2位为1)
     * "def" -> ...000111000 (第3,4,5位为1)
     * 两者与运算 = 0，无公共字母
     */
    public int maxProduct(String[] words) {
        int n = words.length;

        // 步骤1：计算每个单词的位掩码
        int[] masks = new int[n];
        for (int i = 0; i < n; i++) {
            for (char c : words[i].toCharArray()) {
                // 将对应位设置为1
                int bitPos = c - 'a';
                masks[i] |= (1 << bitPos);
            }
        }

        // 步骤2：枚举所有单词对
        int maxProduct = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 检查是否有公共字母
                if ((masks[i] & masks[j]) == 0) {
                    int product = words[i].length() * words[j].length();
                    maxProduct = Math.max(maxProduct, product);
                }
            }
        }

        return maxProduct;
    }
}
```

## 复杂度分析

**位运算方法：**
- 时间复杂度：O(n² + n×L)，L是平均单词长度
- 空间复杂度：O(n)

**集合方法：**
- 时间复杂度：O(n² × L)
- 空间复杂度：O(n × L)

## 关键点总结

1. **位掩码**：用整数的26位表示26个字母
2. **位运算**：
   - 设置位：`mask |= 1 << i`
   - 检查交集：`(mask1 & mask2) == 0`
3. **优化**：相同掩码只保留最长单词
4. **位运算优势**：O(1)判断是否有公共字母

## 易错点

1. **位运算错误**：`1 << i` 注意运算符优先级，加括号更安全
2. **字符转位置**：`c - 'a'`
3. **枚举范围**：j从i+1开始，避免重复
4. **初始值**：maxProd初始化为0
5. **Java中与运算**：注意 `(masks[i] & masks[j]) == 0` 需要加括号，因为 `==` 优先级高于 `&`
