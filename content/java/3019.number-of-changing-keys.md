## 题目描述

给字符串 s（含大小写字母），不区分大小写，返回输入过程中换键的次数（相邻字符忽略大小写后不同即换键一次）。

## 解题思路

将字符串统一转小写，统计相邻字符不同的次数。

## Java 代码实现

```java
class Solution {
    public int countKeyChanges(String s) {
        int count = 0;
        for (int i = 1; i < s.length(); i++) {
            if (Character.toLowerCase(s.charAt(i)) != Character.toLowerCase(s.charAt(i - 1))) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 大小写视为同一键，比较前先统一大小写
2. 换键次数 = 相邻字符（不区分大小写）不同的个数
3. Character.toLowerCase() 处理大小写转换
