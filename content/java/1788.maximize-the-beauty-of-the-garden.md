## 题目描述

有 n 朵花，`flowers[i]` 为美丽值（可能为负）。从中选一个**有效子序列**（首尾元素值相同），返回其最大美丽值之和。

## 解题思路

有效子序列首尾值相同设为 v，取值 v 在原数组第一次（first）和最后一次（last）出现的位置，中间所有**正数**元素都加入（贪心：负数只会减小总和）。

用前缀正数和快速计算区间 `(first, last)` 内正数之和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximumBeauty(int[] flowers) {
        int n = flowers.length;
        Map<Integer, Integer> first = new HashMap<>();
        Map<Integer, Integer> last = new HashMap<>();

        for (int i = 0; i < n; i++) {
            int f = flowers[i];
            first.putIfAbsent(f, i);
            last.put(f, i);
        }

        // 前缀正数和：posSum[i] = flowers[0..i-1] 中正数之和
        int[] posSum = new int[n + 1];
        for (int i = 0; i < n; i++) {
            posSum[i + 1] = posSum[i] + Math.max(0, flowers[i]);
        }

        int ans = Integer.MIN_VALUE;
        for (Map.Entry<Integer, Integer> entry : first.entrySet()) {
            int v = entry.getKey();
            int l = entry.getValue();
            int r = last.get(v);
            if (l == r) {
                // 只出现一次，子序列只有该元素
                ans = Math.max(ans, flowers[l]);
            } else {
                // 首尾各一个 v + 中间区间 (l, r) 的正数和
                int middle = posSum[r] - posSum[l + 1];
                ans = Math.max(ans, flowers[l] + middle + flowers[r]);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 首尾相同值，中间贪心取所有正数
2. 前缀正数和快速计算区间内正数总和
3. 中间区间是开区间 `(l, r)`，即 `posSum[r] - posSum[l+1]`
