## 题目描述

设计电影租赁系统，支持 search（查未租借电影最便宜的 5 个商店）、rent（租借）、drop（归还）、report（查已租借中最便宜的 5 个）四种操作，按价格升序、相同按编号升序排列。

## 解题思路

维护三种数据结构：价格映射 `price[(shop,movie)]`，每部电影的未租借有序集合 `unrented[movie]`（按 price, shop 排序），以及全局已租借有序集合 `rented`（按 price, shop, movie 排序）。Java 用 TreeSet 实现有序集合。

## Java 代码实现

```java
import java.util.*;

class MovieRentingSystem {
    private Map<Long, Integer> price;
    private Map<Integer, TreeSet<long[]>> unrented;
    private TreeSet<long[]> rented;

    // 用 long 编码 (price, shop, movie) 以便比较
    private static final Comparator<long[]> CMP = (a, b) -> {
        for (int i = 0; i < a.length; i++) {
            if (a[i] != b[i]) return Long.compare(a[i], b[i]);
        }
        return 0;
    };

    public MovieRentingSystem(int n, int[][] entries) {
        price = new HashMap<>();
        unrented = new HashMap<>();
        rented = new TreeSet<>(CMP);

        for (int[] e : entries) {
            int shop = e[0], movie = e[1], p = e[2];
            price.put(encode(shop, movie), p);
            unrented.computeIfAbsent(movie, x -> new TreeSet<>(CMP))
                    .add(new long[]{p, shop});
        }
    }

    public List<Integer> search(int movie) {
        List<Integer> res = new ArrayList<>();
        TreeSet<long[]> ts = unrented.get(movie);
        if (ts == null) return res;
        int cnt = 0;
        for (long[] e : ts) {
            if (cnt++ >= 5) break;
            res.add((int) e[1]); // 商店编号
        }
        return res;
    }

    public void rent(int shop, int movie) {
        int p = price.get(encode(shop, movie));
        unrented.get(movie).remove(new long[]{p, shop});
        rented.add(new long[]{p, shop, movie});
    }

    public void drop(int shop, int movie) {
        int p = price.get(encode(shop, movie));
        rented.remove(new long[]{p, shop, movie});
        unrented.get(movie).add(new long[]{p, shop});
    }

    public List<List<Integer>> report() {
        List<List<Integer>> res = new ArrayList<>();
        int cnt = 0;
        for (long[] e : rented) {
            if (cnt++ >= 5) break;
            res.add(Arrays.asList((int) e[1], (int) e[2]));
        }
        return res;
    }

    private long encode(int shop, int movie) {
        return (long) shop * 100001 + movie;
    }
}
```

## 复杂度分析

- **search/rent/drop/report**：O(log n)
- **空间复杂度**：O(entries.length)

## 关键点总结

1. 三种视图：每部电影的未租状态、全局已租状态、价格映射
2. TreeSet 天然有序，支持 O(log n) 插入删除，迭代前 5 个
3. 排序键为 (price, shop) 或 (price, shop, movie)，自然满足多条件排序
