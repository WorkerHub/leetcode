## 题目描述

有 numBottles 满水瓶，每 numExchange 个空瓶换一瓶满水。求最多能喝多少瓶。

**示例：**
```
输入：numBottles = 9, numExchange = 3
输出：13
```

## 解题思路

模拟：喝掉所有满瓶变空瓶，用空瓶换新满瓶，循环直到空瓶不够换。

## Java 代码实现

```java
class Solution {
    public int numWaterBottles(int numBottles, int numExchange) {
        int total = numBottles;
        int empty = numBottles;
        
        while (empty >= numExchange) {
            int newBottles = empty / numExchange;
            total += newBottles;
            empty = empty % numExchange + newBottles;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **模拟过程**：喝 → 换 → 喝
2. **空瓶更新**：余下的 + 新换的
3. **数学公式**：total = numBottles + (numBottles - 1) / (numExchange - 1)
