## 题目描述

给你字符串数组 `strs`，每个字符串要么全是数字（值为整数值），要么全是字母（值为长度），返回最大值。

## 解题思路

遍历每个字符串，判断首字符是否为数字来区分类型，取所有值的最大值。

## Java 代码实现

```java
class Solution {
    public int maximumValue(String[] strs) {
        int ans = 0;
        for (String s : strs) {
            int val = Character.isDigit(s.charAt(0)) ? Integer.parseInt(s) : s.length();
            ans = Math.max(ans, val);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L)，L 为最长字符串长度
- **空间复杂度**：O(1)

## 关键点总结

1. 全数字字符串的值 = 整数值，全字母字符串的值 = 长度
2. `Character.isDigit()` 判断首字符确定类型
