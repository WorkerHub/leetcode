## 题目描述

给定长度 256 的频次数组 count（count[k] 表示数字 k 出现次数），计算最小值、最大值、均值、中位数、众数。

**示例：**
```
输入：count = [0,1,3,4,0,...,0]
输出：[1.00000,3.00000,2.37500,2.50000,3.00000]
```

## 解题思路

一次遍历求 min/max/sum/total/mode，再通过累计频次定位中位数（区分奇偶）。

## Java 代码实现

```java
class Solution {
    public double[] sampleStats(int[] count) {
        int min = -1, max = -1, mode = 0;
        long total = 0, sum = 0;
        int maxCount = 0;

        for (int i = 0; i < 256; i++) {
            if (count[i] > 0) {
                if (min == -1) min = i;
                max = i;
                total += count[i];
                sum += (long) i * count[i];
                if (count[i] > maxCount) {
                    maxCount = count[i];
                    mode = i;
                }
            }
        }

        double mean = (double) sum / total;

        // 计算中位数
        double median;
        long mid1 = (total + 1) / 2;
        long mid2 = total / 2 + 1;
        long cumulative = 0;
        int first = -1, second = -1;

        for (int i = 0; i < 256; i++) {
            cumulative += count[i];
            if (first == -1 && cumulative >= mid1) first = i;
            if (cumulative >= mid2) {
                second = i;
                break;
            }
        }
        median = (first + second) / 2.0;

        return new double[]{min, max, mean, median, mode};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(256) = O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **频次数组**：不需要展开原始数据
2. **中位数定位**：通过累计频次找到中间位置
3. **奇偶统一**：mid1=(total+1)/2, mid2=total/2+1 可统一处理
