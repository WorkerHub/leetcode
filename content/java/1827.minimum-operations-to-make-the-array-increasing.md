## 题目描述

每次操作可将一个元素+1，求使数组严格递增的最少操作次数。

## 解题思路

贪心：从左到右，若nums[i]<=prev，则增加到prev+1。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int ops = 0, prev = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] <= prev) {
                int target = prev + 1;
                ops += target - nums[i];
                prev = target;
            } else {
                prev = nums[i];
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心最少增加**：每个元素只增加到prev+1
2. **只能增加不能减少**
3. **及时更新prev**
