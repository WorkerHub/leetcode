## 题目描述

给定只包含 `'a'` 和 `'b'` 的字符串 `s`，统计其中交替子序列（相邻字符不相同）的数量。返回结果对 `10^9 + 7` 取模。

## 解题思路

DP：`dpA` 为以 `'a'` 结尾的交替子序列数，`dpB` 为以 `'b'` 结尾的交替子序列数。遇到 `'a'` 时 `dpA += dpB + 1`，遇到 `'b'` 时 `dpB += dpA + 1`。答案为 `dpA + dpB`。

## Java 代码实现

```java
class Solution {
    public long countAlternatingSubsequences(String s) {
        final int MOD = 1_000_000_007;
        long dpA = 0, dpB = 0;
        for (char c : s.toCharArray()) {
            if (c == 'a') {
                dpA = (dpA + dpB + 1) % MOD;
            } else {
                dpB = (dpB + dpA + 1) % MOD;
            }
        }
        return (dpA + dpB) % MOD;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 以某字符结尾的交替子序列数 = 以另一字符结尾的数 + 1（加上自身单字符）
2. 只需维护两个变量，无需完整 DP 数组
3. 单个字符也算交替子序列
