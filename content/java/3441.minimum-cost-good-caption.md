## 题目描述

给定字符串 `caption`，每次操作可将任意字符替换为另一字符（代价 1）。"好标题"要求每段连续相同字符的长度 >= 3，返回 [最小代价时字典序最小的好标题, 最小代价]。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String[] minCostGoodCaption(String caption) {
        int n = caption.length();
        int INF = Integer.MAX_VALUE / 2;

        // fwd[i][c][l]: 前 i+1 个字符，末尾字符为 c，末尾段长度 l（1,2,3表示>=3）的最小代价
        int[][][] fwd = new int[n][26][4];
        for (int[][] a : fwd) for (int[] row : a) Arrays.fill(row, INF);

        for (int c = 0; c < 26; c++)
            fwd[0][c][1] = (caption.charAt(0) - 'a' == c) ? 0 : 1;

        for (int i = 1; i < n; i++) {
            int orig = caption.charAt(i) - 'a';
            for (int c = 0; c < 26; c++) {
                int chg = (c == orig) ? 0 : 1;
                // 延续同一段
                for (int l = 1; l <= 3; l++) {
                    if (fwd[i-1][c][l] >= INF) continue;
                    int nl = Math.min(l + 1, 3);
                    fwd[i][c][nl] = Math.min(fwd[i][c][nl], fwd[i-1][c][l] + chg);
                }
                // 开始新段（前一段长度 >= 3）
                for (int pc = 0; pc < 26; pc++) {
                    if (pc == c || fwd[i-1][pc][3] >= INF) continue;
                    fwd[i][c][1] = Math.min(fwd[i][c][1], fwd[i-1][pc][3] + chg);
                }
            }
        }

        int minCost = INF;
        for (int c = 0; c < 26; c++) minCost = Math.min(minCost, fwd[n-1][c][3]);
        if (minCost >= INF) return new String[]{"", "-1"};

        // bwd[i][c][l]: 从状态(c,l)@i出发，位置i+1..n-1的最小代价
        int[][][] bwd = new int[n][26][4];
        for (int[][] a : bwd) for (int[] row : a) Arrays.fill(row, INF);
        for (int c = 0; c < 26; c++) bwd[n-1][c][3] = 0; // 合法终态

        for (int i = n-2; i >= 0; i--) {
            int nextOrig = caption.charAt(i+1) - 'a';
            for (int c = 0; c < 26; c++) {
                for (int l = 1; l <= 3; l++) {
                    // 位置 i+1 延续字符 c
                    int chg = (c == nextOrig) ? 0 : 1;
                    int nl = Math.min(l + 1, 3);
                    if (bwd[i+1][c][nl] < INF)
                        bwd[i][c][l] = Math.min(bwd[i][c][l], chg + bwd[i+1][c][nl]);
                    // 位置 i+1 开始新段（需 l=3）
                    if (l == 3) {
                        for (int nc = 0; nc < 26; nc++) {
                            if (nc == c) continue;
                            int chg2 = (nc == nextOrig) ? 0 : 1;
                            if (bwd[i+1][nc][1] < INF)
                                bwd[i][c][3] = Math.min(bwd[i][c][3], chg2 + bwd[i+1][nc][1]);
                        }
                    }
                }
            }
        }

        // 贪心重建字典序最小字符串
        char[] result = new char[n];
        int curC = -1, curL = -1;

        // 位置 0：选最小字符使总代价 = minCost
        for (int c = 0; c < 26; c++) {
            if (fwd[0][c][1] < INF && bwd[0][c][1] < INF &&
                    fwd[0][c][1] + bwd[0][c][1] == minCost) {
                result[0] = (char)('a' + c);
                curC = c; curL = 1;
                break;
            }
        }

        for (int i = 1; i < n; i++) {
            int orig = caption.charAt(i) - 'a';
            int prevFwd = fwd[i-1][curC][curL];
            for (int c = 0; c < 26; c++) {
                int newL;
                if (c == curC) {
                    newL = Math.min(curL + 1, 3);
                } else if (curL == 3) {
                    newL = 1;
                } else {
                    continue;
                }
                int chg = (c == orig) ? 0 : 1;
                if (prevFwd + chg != fwd[i][c][newL]) continue;
                if (bwd[i][c][newL] >= INF || fwd[i][c][newL] + bwd[i][c][newL] != minCost) continue;
                result[i] = (char)('a' + c);
                curC = c; curL = newL;
                break;
            }
        }

        return new String[]{new String(result), String.valueOf(minCost)};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26^2)，前后向 DP 各 O(n * 26^2)
- 空间复杂度：O(n * 26 * 3)

## 关键点总结

1. 状态 (字符 c, 末尾段长度 l∈{1,2,3}) 共 78 种，用前后向 DP 确定最优路径
2. 切换到新字符的前提：当前段长度 >= 3（l=3）
3. 前后向 DP 结合贪心重建：每步选满足总代价 = minCost 的最小字符
