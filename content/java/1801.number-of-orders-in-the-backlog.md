## 题目描述

给你订单数组 `orders[i] = [price, amount, orderType]`（0 买单，1 卖单），模拟撮合交易，返回积压订单总数量（对 10^9+7 取余）。

## 解题思路

用两个堆维护积压订单：买单用最大堆（堆顶为最高价），卖单用最小堆（堆顶为最低价）。每来一笔新单，尝试与对方堆顶匹配直到无法成交，剩余量加入对应堆。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int getNumberOfBacklogOrders(int[][] orders) {
        final int MOD = 1_000_000_007;
        // 买单最大堆：[price, amount]，按 price 降序
        PriorityQueue<int[]> buyHeap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        // 卖单最小堆：[price, amount]，按 price 升序
        PriorityQueue<int[]> sellHeap = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));

        for (int[] order : orders) {
            int price = order[0], amount = order[1], type = order[2];

            if (type == 0) {
                // 买单：与价格最低的卖单匹配
                while (amount > 0 && !sellHeap.isEmpty() && sellHeap.peek()[0] <= price) {
                    int[] top = sellHeap.poll();
                    if (top[1] <= amount) {
                        amount -= top[1]; // 卖单全部成交
                    } else {
                        top[1] -= amount; // 卖单部分成交，推回
                        sellHeap.offer(top);
                        amount = 0;
                    }
                }
                if (amount > 0) buyHeap.offer(new int[]{price, amount});
            } else {
                // 卖单：与价格最高的买单匹配
                while (amount > 0 && !buyHeap.isEmpty() && buyHeap.peek()[0] >= price) {
                    int[] top = buyHeap.poll();
                    if (top[1] <= amount) {
                        amount -= top[1]; // 买单全部成交
                    } else {
                        top[1] -= amount; // 买单部分成交，推回
                        buyHeap.offer(top);
                        amount = 0;
                    }
                }
                if (amount > 0) sellHeap.offer(new int[]{price, amount});
            }
        }

        long total = 0;
        for (int[] o : buyHeap) total += o[1];
        for (int[] o : sellHeap) total += o[1];
        return (int)(total % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 买单最大堆（最高价优先），卖单最小堆（最低价优先）
2. 部分成交时剩余量推回堆
3. 最终结果对 10^9+7 取模（amount 可能很大）
