## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**
```
输入：s = "()"
输出：true
```

**示例 2：**
```
输入：s = "()[]{}"
输出：true
```

**示例 3：**
```
输入：s = "(]"
输出：false
```

**提示：**
- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 解题思路

栈的经典应用：
- 遇到左括号，压入栈
- 遇到右括号，检查栈顶是否为匹配的左括号
- 最后栈应该为空

## Java 代码实现

### 方法一：栈 + 哈希表（推荐）

```java
class Solution {
    public boolean isValid(String s) {
        // 奇数长度直接返回 false
        if (s.length() % 2 == 1) return false;
        
        // 建立右括号到左括号的映射
        Map<Character, Character> pairs = Map.of(
            ')', '(',
            ']', '[',
            '}', '{'
        );
        
        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            if (pairs.containsKey(c)) {
                // 遇到右括号：检查栈顶是否匹配
                if (stack.isEmpty() || stack.peek() != pairs.get(c)) {
                    return false;
                }
                stack.pop();
            } else {
                // 遇到左括号：压栈
                stack.push(c);
            }
        }
        
        // 栈为空说明所有括号都匹配
        return stack.isEmpty();
    }
}
```

### 方法二：简化版

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            else if (stack.isEmpty() || stack.pop() != c) return false;
        }
        
        return stack.isEmpty();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(n)，最坏情况下栈存储所有左括号

## 图解示例

以 `s = "([{}])"` 为例：

```
步骤    字符    栈状态         操作
1       (      [(]           压栈
2       [      [(, []         压栈
3       {      [(, [, {]      压栈
4       }      [(, []         匹配 {，弹栈
5       ]      [(]           匹配 [，弹栈
6       )      []            匹配 (，弹栈

最终栈为空 -> 返回 true
```

## 关键点总结

1. **栈的应用**：括号匹配是栈的典型应用场景
2. **哈希表优化**：用 Map 存储配对关系
3. **提前剪枝**：奇数长度直接返回 false
4. **边界检查**：弹栈前检查栈是否为空

## 易错点

1. **忘记检查栈是否为空**：遇到右括号时，栈可能已经空了
2. **最后忘记检查栈**：栈中可能还有未匹配的左括号
3. **Java Stack vs Deque**：推荐使用 `ArrayDeque` 代替 `Stack`
