## 题目描述

给你字符串 `s` 和 `part`，反复删除 `s` 中最左边的 `part` 子字符串直到不再出现，返回最终字符串。

## 解题思路

栈模拟：逐字符压入栈，每次压入后检查栈顶 k 个字符是否等于 part，若是则弹出 k 个字符。这样天然处理删除后拼接形成新 part 的情况。

## Java 代码实现

```java
class Solution {
    public String removeOccurrences(String s, String part) {
        StringBuilder stack = new StringBuilder();
        int k = part.length();

        for (char ch : s.toCharArray()) {
            stack.append(ch);
            // 检查栈顶 k 个字符是否等于 part
            int len = stack.length();
            if (len >= k && stack.substring(len - k).equals(part)) {
                stack.delete(len - k, len); // 删除栈顶 k 个字符
            }
        }
        return stack.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)，n 为 s 长度，k 为 part 长度
- **空间复杂度**：O(n)

## 关键点总结

1. 每次删除后，原本不相邻的部分可能拼成新的 part，栈方法天然处理此情况
2. 用 StringBuilder 模拟栈，每次检查尾部 k 个字符
3. 数据规模小时也可直接用字符串 replace 循环
