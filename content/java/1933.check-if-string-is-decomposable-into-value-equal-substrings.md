## 题目描述

给你数字字符串 `s`，若能分解为若干等值子字符串，其中恰好一个长度对 3 取余为 1（其余均为 3 的倍数），则返回 `true`，否则返回 `false`。

## 解题思路

按连续相同字符分组，统计各组长度模 3 的余数：余数为 2 直接返回 false，余数为 1 只允许恰好出现 1 次。

## Java 代码实现

```java
class Solution {
    public boolean isDecomposable(String s) {
        int countMod1 = 0;
        int n = s.length();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            int rem = (j - i) % 3;
            if (rem == 2) return false;
            if (rem == 1) {
                countMod1++;
                if (countMod1 > 1) return false;
            }
            i = j;
        }
        return countMod1 == 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 按连续相同字符分组，检查各组长度模 3 的余数
2. 余数为 2 不合法；余数为 1 恰好允许 1 次
3. 最终需确认恰好有一个余数为 1 的分组
