## 题目描述

给你两个非负整数数组 `nums1` 和 `nums2`，返回由所有数对 `nums1[i] XOR nums2[j]` 组成的数组中所有元素的异或值。

## 解题思路

`nums1[i]` 在结果中出现 `len(nums2)` 次，`nums2[j]` 出现 `len(nums1)` 次。利用 XOR 性质：偶数次出现抵消为 0，奇数次有效。若 `len(nums2)` 为奇数则对答案异或 `XOR(nums1)`；若 `len(nums1)` 为奇数则异或 `XOR(nums2)`。

## Java 代码实现

```java
class Solution {
    public int xorAllNums(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int ans = 0;

        // nums1 中每个元素出现 n 次，n 为奇数时参与异或
        if (n % 2 == 1) {
            for (int x : nums1) ans ^= x;
        }
        // nums2 中每个元素出现 m 次，m 为奇数时参与异或
        if (m % 2 == 1) {
            for (int x : nums2) ans ^= x;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(1)

## 关键点总结

1. 利用 XOR 性质：`a ^ a = 0`，偶数次出现的元素抵消
2. `nums1[i]` 出现 `n` 次，`nums2[j]` 出现 `m` 次
3. 判断的是**对方**数组的长度奇偶，不是自身
