## 题目描述

给你整数数组 `nums`（长度最大 10^5），返回删除后剩余元素严格递增的子数组总数目。

## 解题思路

预处理最长严格递增前缀末尾 preEnd 和后缀起始 sufStart。枚举左端点 l（0 到 preEnd+1），对每个 l 用二分查找后缀中第一个 > nums[l-1] 的位置，确定最小右端点 r，累加 n-r 个合法右端点。

## Java 代码实现

```java
class Solution {
    public long incremovableSubarrayCount(int[] nums) {
        int n = nums.length;
        // 找最长严格递增前缀末尾
        int preEnd = 0;
        while (preEnd + 1 < n && nums[preEnd] < nums[preEnd + 1]) preEnd++;

        if (preEnd == n - 1) return (long) n * (n + 1) / 2; // 整体递增

        // 找最长严格递增后缀起始
        int sufStart = n - 1;
        while (sufStart > 0 && nums[sufStart - 1] < nums[sufStart]) sufStart--;

        long ans = 0;
        for (int l = 0; l <= preEnd + 1; l++) {
            int minR;
            if (l == 0) {
                minR = sufStart - 1; // r+1 = sufStart
            } else {
                // 在后缀 [sufStart, n-1] 中找第一个 > nums[l-1] 的位置
                int lo = sufStart, hi = n;
                while (lo < hi) {
                    int mid = (lo + hi) / 2;
                    if (nums[mid] > nums[l - 1]) hi = mid;
                    else lo = mid + 1;
                }
                minR = lo - 1; // r+1 = lo，r = lo-1
            }
            int rLo = Math.max(l - 1, minR);
            if (rLo < n) ans += n - rLo;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 预处理前缀和后缀递增的分界点
2. 枚举左端点只需到 preEnd+1，超过后左段不再递增
3. 整体递增时所有子数组都合法，共 n*(n+1)/2 个
