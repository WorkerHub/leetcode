## 题目描述

给你整数数组 prices 和 profits，找满足 `prices[i] < prices[j] < prices[k]`（i<j<k）的三元组，最大化 `profits[i]+profits[j]+profits[k]`，不存在则返回 -1。

## 解题思路

枚举中间元素 j，预处理 `leftMax[j]`（j 左侧价格严格小于 prices[j] 的最大利润）和 `rightMax[j]`（j 右侧价格严格大于 prices[j] 的最大利润），再枚举 j 取三者之和的最大值。n ≤ 2000，O(n²) 可行。

## Java 代码实现

```java
class Solution {
    public int maxProfit(int[] prices, int[] profits) {
        int n = prices.length;
        int[] leftMax = new int[n];
        int[] rightMax = new int[n];

        // 预处理左侧最大利润
        for (int j = 0; j < n; j++) {
            leftMax[j] = -1;
            for (int i = 0; i < j; i++) {
                if (prices[i] < prices[j]) {
                    leftMax[j] = Math.max(leftMax[j], profits[i]);
                }
            }
        }

        // 预处理右侧最大利润
        for (int j = 0; j < n; j++) {
            rightMax[j] = -1;
            for (int k = j + 1; k < n; k++) {
                if (prices[k] > prices[j]) {
                    rightMax[j] = Math.max(rightMax[j], profits[k]);
                }
            }
        }

        // 枚举中间元素
        int ans = -1;
        for (int j = 1; j < n - 1; j++) {
            if (leftMax[j] != -1 && rightMax[j] != -1) {
                ans = Math.max(ans, leftMax[j] + profits[j] + rightMax[j]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，预处理左右最大值各需 O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举中间元素是三元组问题的常用技巧
2. 预处理左右最大/最小值，将三重循环降为两重
3. 不存在合法三元组时返回 -1（而非 0）
