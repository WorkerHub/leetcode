## 题目描述

给定一个正整数 `n`，你可以做如下操作：

1. 如果 `n` 是偶数，则用 `n / 2` 替换 `n`。
2. 如果 `n` 是奇数，则可以用 `n + 1` 或 `n - 1` 替换 `n`。

返回 `n` 变为 `1` 所需的**最小替换次数**。

**示例 1:**

```
输入：n = 8
输出：3
解释：8 -> 4 -> 2 -> 1
```

**示例 2:**

```
输入：n = 7
输出：4
解释：7 -> 8 -> 4 -> 2 -> 1
或 7 -> 6 -> 3 -> 2 -> 1
```

**示例 3:**

```
输入：n = 4
输出：2
```

**提示:**

- `1 <= n <= 2^31 - 1`

## 解题思路

本题可以用多种方法解决：贪心、记忆化搜索、位运算。

### 核心思想

**贪心策略（位运算优化）：**

对于奇数 n，我们需要决定是 +1 还是 -1：
- **观察**：我们希望尽快减少二进制中 1 的个数
- **规则**：
  - 如果 `n % 4 == 1`：选择 `-1`（如 5 = 101b → 4 = 100b）
  - 如果 `n % 4 == 3`：选择 `+1`（如 7 = 111b → 8 = 1000b）
  - 特例：`n == 3` 时选择 `-1`

**为什么这样贪心？**

- `n % 4 == 1` 时，n 的二进制末尾是 `01`，减 1 后末尾变 `00`，消除两个 1
- `n % 4 == 3` 时，n 的二进制末尾是 `11`，加 1 后可能产生进位，消除多个 1

## Java 代码实现

### 方法一：贪心 + 位运算（推荐）⭐

```java
class Solution {
    public int integerReplacement(int n) {
        // 贪心策略 + 位运算
        // 时间复杂度: O(log n)
        // 空间复杂度: O(1)
        int count = 0;
        long num = n;  // 使用 long 避免 n+1 溢出（n 最大为 2^31-1）

        while (num != 1) {
            if (num % 2 == 0) {
                // 偶数：直接除以 2
                num /= 2;
            } else if (num == 3 || num % 4 == 1) {
                // 特例或 n % 4 == 1：选择 -1
                num -= 1;
            } else {
                // n % 4 == 3：选择 +1
                num += 1;
            }

            count++;
        }

        return count;
    }
}
```

### 方法二：记忆化搜索

```java
import java.util.*;

class Solution {
    private Map<Long, Integer> memo = new HashMap<>();

    public int integerReplacement(int n) {
        // 记忆化递归
        // 时间复杂度: O(log n)
        // 空间复杂度: O(log n)
        return helper((long) n);
    }

    private int helper(long num) {
        if (num == 1) return 0;
        if (memo.containsKey(num)) return memo.get(num);

        int result;
        if (num % 2 == 0) {
            result = 1 + helper(num / 2);
        } else {
            result = 1 + Math.min(helper(num + 1), helper(num - 1));
        }

        memo.put(num, result);
        return result;
    }
}
```

### 方法三：位运算优化

```java
class Solution {
    public int integerReplacement(int n) {
        // 使用位运算判断
        int count = 0;
        long num = n;  // 使用 long 避免溢出

        while (num > 1) {
            if ((num & 1) == 0) {
                // 偶数：右移一位
                num >>= 1;
            } else if (num == 3 || (num & 3) == 1) {
                // n==3 或末两位是 01：减 1
                num -= 1;
            } else {
                // 末两位是 11：加 1
                num += 1;
            }

            count++;
        }

        return count;
    }
}
```

### 方法四：BFS（理解用）

```java
import java.util.*;

class Solution {
    public int integerReplacement(int n) {
        // BFS 广度优先搜索
        // 时间复杂度: O(log n)
        // 空间复杂度: O(log n)
        if (n == 1) return 0;

        Queue<long[]> queue = new LinkedList<>();
        Set<Long> visited = new HashSet<>();

        queue.offer(new long[]{n, 0});
        visited.add((long) n);

        while (!queue.isEmpty()) {
            long[] curr = queue.poll();
            long num = curr[0];
            int steps = (int) curr[1];

            if (num == 1) return steps;

            // 偶数：除以 2
            if (num % 2 == 0) {
                long nextNum = num / 2;
                if (!visited.contains(nextNum)) {
                    visited.add(nextNum);
                    queue.offer(new long[]{nextNum, steps + 1});
                }
            } else {
                // 奇数：+1 或 -1
                for (long nextNum : new long[]{num + 1, num - 1}) {
                    if (!visited.contains(nextNum)) {
                        visited.add(nextNum);
                        queue.offer(new long[]{nextNum, steps + 1});
                    }
                }
            }
        }

        return -1;
    }
}
```

### 方法五：简洁的贪心

```java
class Solution {
    public int integerReplacement(int n) {
        // 更简洁的贪心实现
        int count = 0;
        long num = n;  // 使用 long 避免溢出

        while (num > 3) {
            if (num % 2 == 0) {
                num /= 2;
            } else if (num % 4 == 1) {
                num -= 1;
            } else {
                num += 1;
            }
            count++;
        }

        // num <= 3 时的处理
        return count + (int)(num - 1);
    }
}
```

## 复杂度分析

### 方法一：贪心

**时间复杂度：** O(log n)
- 每次操作至少将 n 减半（或接近减半）
- 最多需要 O(log n) 次操作

**空间复杂度：** O(1)
- 只使用常数额外空间

### 方法二：记忆化

**时间复杂度：** O(log n)
- 每个状态最多计算一次
- 状态数约为 O(log n)

**空间复杂度：** O(log n)
- 递归调用栈 + 缓存

## 关键点总结

1. **贪心策略**：根据 `n % 4` 的值决定 +1 还是 -1
2. **位运算优化**：`n & 1` 判断奇偶，`n >> 1` 除以 2
3. **特殊情况**：`n == 3` 时选择 -1 更优
4. **二进制视角**：减少二进制中 1 的个数
5. **long 类型**：Java 中 n+1 可能溢出 int，需要用 long

## 易错点

1. **忘记 n=3 的特例**：虽然 3 % 4 == 3，但 -1 更优
2. **溢出问题**：n 最大为 2^31-1，n+1 超出 int 范围，必须用 long
3. **位运算理解**：`n & 3` 等价于 `n % 4`
4. **递归终止条件**：n == 1 时返回 0
5. **贪心证明**：需要理解为什么这样贪心是最优的
