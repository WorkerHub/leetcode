## 题目描述

给定只含 `'('` 和 `')'` 的字符串 `s`，统计其中有效括号子串的数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countBalancedSubstrings(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 哨兵：记录最近一个无效括号的位置
        int count = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    // 栈变空，压入当前下标作为新边界
                    stack.push(i);
                } else {
                    // 当前有效段长度，以 i 结尾的有效子串数 = 有效长度 / 2
                    int validLen = i - stack.peek();
                    count += validLen / 2;
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，栈空间

## 关键点总结

1. 栈中初始压入 -1 作为哨兵，标记有效段的起始边界
2. 遇到 ')' 时若匹配成功，有效子串数 += `(i - 栈顶) / 2`
3. 有效括号子串长度一定是偶数
