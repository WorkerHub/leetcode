## 题目描述

给你小写字母字符串 `s`，若子序列中每个字母出现次数相同则为好子序列，返回非空好子序列的数目（对 `10^9+7` 取模）。

## 解题思路

统计各字母频次，枚举每种字母各取 k 个（k 从 1 到最大频次），方案数 = 所有出现字母的 `C(freq, k)` 之积；若某字母频次 < k 则跳出。预计算阶乘和逆元加速组合数计算。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public int countGoodSubsequences(String s) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        int maxFreq = 0;
        for (int f : cnt) maxFreq = Math.max(maxFreq, f);

        // 预计算阶乘和阶乘逆元
        int n = s.length() + 1;
        long[] fact = new long[n + 1];
        long[] invFact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = pow(fact[n], MOD - 2);
        for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

        long ans = 0;
        for (int k = 1; k <= maxFreq; k++) {
            long product = 1;
            boolean valid = true;
            for (int f : cnt) {
                if (f == 0) continue;
                if (f < k) { valid = false; break; }
                product = product * comb(fact, invFact, f, k) % MOD;
            }
            if (valid) ans = (ans + product) % MOD;
        }
        return (int) ans;
    }

    private long comb(long[] fact, long[] invFact, int n, int r) {
        if (r > n) return 0;
        return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
    }

    private long pow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|s| + maxFreq * 26)
- **空间复杂度**：O(|s|)

## 关键点总结

1. 固定每种字母各取 k 个，方案数 = 各字母 C(freq, k) 之积
2. 某字母频次 < k 时整个 k 无贡献，直接跳出内层循环
3. 预计算阶乘逆元使 C(n,r) 为 O(1) 查询
