## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，请你以数组形式返回两数组的交集。返回结果中每个元素出现的次数，应与元素在两个数组中都出现的次数一致（如果出现次数不一致，则考虑取较小值）。可以不考虑输出结果的顺序。

**示例 1：**
```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2,2]
```

**示例 2：**
```
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[4,9]
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

**进阶：**
- 如果给定的数组已经排好序呢？你将如何优化你的算法？
- 如果 `nums1` 的大小比 `nums2` 小，哪种方法更优？
- 如果 `nums2` 的元素存储在磁盘上，内存是有限的，并且你不能一次加载所有的元素到内存中，你该怎么办？

## 解题思路

这道题与第 349 题的区别是：需要保留重复元素。

**核心思想：**
- 统计每个元素的出现次数
- 取两个数组中较小的出现次数

**多种解法：**
1. 哈希表计数
2. 排序 + 双指针
3. 利用 Stream（Java 特色）

## Java 代码实现

### 方法一：哈希表计数（推荐）⭐

```java
import java.util.*;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 统计 nums1 中每个元素的出现次数
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums1) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        List<Integer> result = new ArrayList<>();

        // 遍历 nums2
        for (int num : nums2) {
            int cnt = count.getOrDefault(num, 0);
            if (cnt > 0) {
                result.add(num);
                count.put(num, cnt - 1);  // 减少计数
            }
        }

        // 转换为数组
        int[] arr = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            arr[i] = result.get(i);
        }
        return arr;
    }
}
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(min(m, n))

### 方法二：优化版（用较小数组建哈希表）

```java
import java.util.*;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 始终用较小的数组建哈希表，节省空间
        if (nums1.length > nums2.length) {
            return intersect(nums2, nums1);
        }

        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums1) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        List<Integer> result = new ArrayList<>();
        for (int num : nums2) {
            int cnt = count.getOrDefault(num, 0);
            if (cnt > 0) {
                result.add(num);
                count.put(num, cnt - 1);
            }
        }

        int[] arr = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            arr[i] = result.get(i);
        }
        return arr;
    }
}
```

### 方法三：排序 + 双指针

```java
import java.util.*;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 排序
        Arrays.sort(nums1);
        Arrays.sort(nums2);

        List<Integer> result = new ArrayList<>();
        int i = 0, j = 0;

        while (i < nums1.length && j < nums2.length) {
            if (nums1[i] < nums2[j]) {
                i++;
            } else if (nums1[i] > nums2[j]) {
                j++;
            } else {
                // 找到交集元素（保留重复）
                result.add(nums1[i]);
                i++;
                j++;
            }
        }

        int[] arr = new int[result.size()];
        for (int k = 0; k < result.size(); k++) {
            arr[k] = result.get(k);
        }
        return arr;
    }
}
```

**时间复杂度：** O(m log m + n log n)
**空间复杂度：** O(1)，不计结果数组

**适用场景：** 数组已排序，或空间受限

### 方法四：使用数组计数（数值范围有限时）

```java
class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        // 由于值在 [0, 1000] 范围内，可以用固定大小数组
        int[] count = new int[1001];

        for (int num : nums1) {
            count[num]++;
        }

        List<Integer> result = new ArrayList<>();
        for (int num : nums2) {
            if (count[num] > 0) {
                result.add(num);
                count[num]--;
            }
        }

        int[] arr = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            arr[i] = result.get(i);
        }
        return arr;
    }
}
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(1)，固定大小数组

## 图解示例

```
方法一：哈希表
count = {1: 2, 2: 2}

num = 2, count[2] = 2 > 0 → result = [2], count[2] = 1

方法三：双指针
排序后：
nums1 = [1,1,2,2]

i=0, j=0: 1 < 2, i++
i=1, j=0: 1 < 2, i++
i=2, j=0: 2 == 2, result=[2], i++, j++
i=3, j=1: 2 == 2, result=[2,2], i++, j++
```

## 关键点总结

1. **计数**：使用 HashMap 统计出现次数
2. **取最小值**：每匹配一次就减少计数
3. **双指针**：需要排序，但空间 O(1)
4. **空间优化**：用较小数组建哈希表

## 易错点

1. **没有考虑重复次数**
   ```java
   // 错误：只记录是否存在
   Set<Integer> set1 = new HashSet<>();
   for (int num : nums1) set1.add(num);

   // 正确：记录次数
   Map<Integer, Integer> count = new HashMap<>();
   for (int num : nums1) count.put(num, count.getOrDefault(num, 0) + 1);
   ```

2. **忘记减少计数**
   ```java
   // 错误：不减少计数会导致重复输出过多
   if (count.getOrDefault(num, 0) > 0) {
       result.add(num);
       // 忘记减少计数
   }

   // 正确：
   if (count.getOrDefault(num, 0) > 0) {
       result.add(num);
       count.put(num, count.get(num) - 1);  // 必须减少
   }
   ```

3. **int[] 不能直接用 List 的 toArray()**
   ```java
   // 错误：toArray() 返回 Object[]，不能直接转 int[]
   return result.toArray(new int[0]);  // 编译错误

   // 正确方式一：Stream
   return result.stream().mapToInt(Integer::intValue).toArray();

   // 正确方式二：手动复制
   int[] arr = new int[result.size()];
   for (int i = 0; i < result.size(); i++) arr[i] = result.get(i);
   return arr;
   ```

## 进阶问题解答

**1. 数组已排序？**
使用双指针，O(m + n) 时间，O(1) 空间

**2. nums1 比 nums2 小？**
用 nums1 建哈希表（O(m) 空间，m < n），遍历 nums2

```java
// 始终用较小数组建哈希表
if (nums1.length > nums2.length) {
    return intersect(nums2, nums1);
}
```

**3. nums2 在磁盘上？**
- 用 nums1 建哈希表（前提是 nums1 能放入内存）
- 分块读取 nums2
- 每块与哈希表比对
