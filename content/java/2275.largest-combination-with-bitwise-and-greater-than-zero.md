## 题目描述

求candidates中按位与结果大于0的最大子集长度。

## 解题思路

AND>0等价于存在某位k使所有数在第k位都为1。对每个二进制位统计为1的数的个数，取最大值。

## Java 代码实现

```java
class Solution {
    public int largestCombination(int[] candidates) {
        int ans = 0;
        for (int bit = 0; bit < 24; bit++) {
            int count = 0;
            for (int x : candidates) {
                if ((x >> bit & 1) == 1) count++;
            }
            ans = Math.max(ans, count);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(24 * N) = O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **关键洞察**：AND>0等价于存在某位全为1
2. **逐位统计**：24位覆盖10^7范围
3. **取最大计数**：即为最大子集长度
