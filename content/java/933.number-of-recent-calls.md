## 题目描述

实现 RecentCounter 类，ping(t) 在时间 t 添加请求并返回过去 3000 毫秒内的请求数。

## 解题思路

队列：每次 ping 入队，然后弹出所有超出 t-3000 时间范围的旧请求，返回队列大小。

## Java 代码实现

```java
class RecentCounter {
    private Queue<Integer> queue;

    public RecentCounter() {
        queue = new LinkedList<>();
    }

    public int ping(int t) {
        queue.offer(t);
        while (queue.peek() < t - 3000) {
            queue.poll();
        }
        return queue.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1) 均摊
- **空间复杂度**：O(n)

## 关键点总结

1. **队列维护**：保持队列内元素在时间窗口内
2. **滑动窗口**：弹出过期元素
3. **递增序列**：t 严格递增，所以队首最旧
