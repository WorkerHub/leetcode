## 题目描述

给你一个以字符串表示的非负整数 num 和一个整数 k，移除这个数中的 k 位数字，使得剩下的数字最小。请你返回这个最小的数字。

**示例 1：**
```
输入：num = "1432219", k = 3
输出："1219"
解释：移除掉三个数字 4, 3, 和 2 形成一个新的最小的数字 1219。
```

**示例 2：**
```
输入：num = "10200", k = 1
输出："200"
解释：移掉首位的 1 剩下的数字为 200，注意输出不能有任何前导零。
```

**示例 3：**
```
输入：num = "10", k = 2
输出："0"
解释：从原数字移除所有的数字，剩余为空就是 0。
```

**提示：**
- 1 <= k <= num.length <= 10^5
- num 仅由若干位数字（0 - 9）组成
- 除了 0 本身之外，num 不含任何前导零

## 解题思路

这是一道经典的贪心 + 单调栈问题。

核心思想：
1. 从左到右遍历数字，要使结果最小，应该让高位尽可能小
2. 如果当前数字比前一个数字小，就应该移除前一个数字
3. 使用单调栈维护一个递增序列

算法流程：
1. 使用栈存储结果数字
2. 遍历每个数字：
   - 如果栈顶元素大于当前数字且还能删除（k > 0），就删除栈顶
   - 将当前数字入栈
3. 如果还有剩余删除次数，从末尾删除
4. 处理前导零
5. 处理空字符串的情况

## Java 代码实现

### 方法一：单调栈（推荐）

```java
class Solution {
    public String removeKdigits(String num, int k) {
        // 使用 StringBuilder 模拟单调栈，维护递增序列
        // 贪心策略：从左到右，遇到递减的位置就删除较大的数字
        StringBuilder stack = new StringBuilder();
        int remain = k;  // 剩余需要删除的数字个数

        for (char digit : num.toCharArray()) {
            // 当栈不为空，还有删除次数，且栈顶元素大于当前数字时
            // 删除栈顶元素（贪心：让高位尽可能小）
            while (stack.length() > 0 && remain > 0
                    && stack.charAt(stack.length() - 1) > digit) {
                stack.deleteCharAt(stack.length() - 1);
                remain--;
            }
            stack.append(digit);
        }

        // 如果还有剩余删除次数，从末尾删除
        // 例如 "123456", k=3 -> "123"
        if (remain > 0) {
            stack.delete(stack.length() - remain, stack.length());
        }

        // 去除前导零
        int start = 0;
        while (start < stack.length() - 1 && stack.charAt(start) == '0') {
            start++;
        }

        return stack.substring(start);
    }
}
```

### 方法二：单调栈（详细注释版）

```java
class Solution {
    public String removeKdigits(String num, int k) {
        // 特殊情况：删除所有数字
        if (k >= num.length()) return "0";

        StringBuilder stack = new StringBuilder();

        for (char digit : num.toCharArray()) {
            // 贪心策略：
            // 1. 栈不为空
            // 2. 还有删除机会（k > 0）
            // 3. 栈顶元素大于当前元素（删除栈顶可以让结果更小）
            while (stack.length() > 0 && k > 0
                    && stack.charAt(stack.length() - 1) > digit) {
                stack.deleteCharAt(stack.length() - 1);
                k--;
            }

            // 避免多余前导零（可选优化：仅当栈非空或当前字符非'0'时追加）
            stack.append(digit);
        }

        // 如果 k 还大于 0，说明剩余数字是递增的，从末尾删除
        while (k > 0 && stack.length() > 0) {
            stack.deleteCharAt(stack.length() - 1);
            k--;
        }

        // 去除前导零
        int start = 0;
        while (start < stack.length() - 1 && stack.charAt(start) == '0') {
            start++;
        }

        String result = stack.substring(start);
        return result.isEmpty() ? "0" : result;
    }
}
```

### 方法三：使用 ArrayDeque

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String removeKdigits(String num, int k) {
        // 使用 ArrayDeque 模拟双端队列
        Deque<Character> deque = new ArrayDeque<>();

        for (char digit : num.toCharArray()) {
            // 维护单调递增队列
            while (!deque.isEmpty() && k > 0 && deque.peekLast() > digit) {
                deque.pollLast();
                k--;
            }
            deque.addLast(digit);
        }

        // 删除剩余的 k 个数字（从末尾）
        for (int i = 0; i < k; i++) {
            if (!deque.isEmpty()) deque.pollLast();
        }

        // 去除前导零并构建结果
        StringBuilder sb = new StringBuilder();
        boolean leadingZero = true;
        for (char c : deque) {
            if (leadingZero && c == '0') continue;  // 跳过前导零
            leadingZero = false;
            sb.append(c);
        }

        return sb.length() == 0 ? "0" : sb.toString();
    }
}
```

### 方法四：字符数组操作

```java
class Solution {
    public String removeKdigits(String num, int k) {
        // 使用 char 数组直接操作
        char[] arr = num.toCharArray();
        int top = 0;  // 栈顶指针

        for (char digit : arr) {
            // 不断弹出比当前数字大的栈顶元素
            while (top > 0 && k > 0 && arr[top - 1] > digit) {
                top--;
                k--;
            }
            arr[top++] = digit;
        }

        // 处理剩余 k
        top -= k;

        // 去除前导零
        int start = 0;
        while (start < top - 1 && arr[start] == '0') {
            start++;
        }

        return new String(arr, start, top - start);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
  - 每个数字最多入栈一次，出栈一次
  - 去除前导零的时间复杂度为 O(n)

- **空间复杂度**：O(n)
  - 栈的空间复杂度为 O(n)

## 图解示例

以 `num = "1432219", k = 3` 为例：

```
初始：stack = [], k = 3

遍历 '1': stack = ['1']

遍历 '4': stack = ['1', '4']

遍历 '3': 
  - '4' > '3'，删除 '4'，k = 2
  - stack = ['1', '3']

遍历 '2':
  - '3' > '2'，删除 '3'，k = 1
  - stack = ['1', '2']

遍历 '2':
  - '2' == '2'，不删除
  - stack = ['1', '2', '2']

遍历 '1':
  - '2' > '1'，删除 '2'，k = 0
  - stack = ['1', '2', '1']

遍历 '9':
  - k = 0，不能再删除
  - stack = ['1', '2', '1', '9']

结果：1219
```

## 关键点总结

1. **贪心策略**：从高位到低位，尽可能让每一位都最小
2. **单调栈思想**：维护一个递增的栈，遇到更小的数字就删除前面较大的
3. **边界处理**：
   - 删除次数用完后的处理
   - 前导零的处理
   - 结果为空的处理
4. **时间优化**：每个元素最多入栈、出栈各一次

## 易错点

1. **前导零处理**：
   - 正确：遍历结果跳过前导零
   - 错误：在入栈时就过滤 '0'（会导致 "10", k=1 输出空而不是 "0"）

2. **剩余删除次数**：
   - 遍历完后如果 k > 0，需要从末尾继续删除
   - 例如 "12345", k=3，遍历完后需删除后 3 位

3. **空结果处理**：
   - 当所有数字都被删除时，应返回 "0" 而不是空字符串

4. **Java 字符串不可变**：
   - Java 中 `String` 是不可变的，频繁修改应使用 `StringBuilder`
   - `StringBuilder.deleteCharAt()` 对应栈的弹出操作

## 学习建议

1. **理解贪心策略**：
   - 为什么从高位开始删除？因为高位对数值的影响更大
   - 为什么要删除较大的数字？因为要让结果最小

2. **掌握单调栈**：
   - 单调栈是解决这类问题的标准工具
   - 练习识别何时使用单调栈（通常涉及"下一个更大/更小"元素）

3. **边界情况**：
   - 总是考虑极端情况：全删除、不删除、全是相同数字

4. **Java 技巧**：
   - 用 `StringBuilder` 模拟栈：`append()` 入栈，`deleteCharAt(length-1)` 出栈，`charAt(length-1)` 查看栈顶
   - 用 `ArrayDeque` 可以更语义化地表达双端操作（`addLast`/`pollLast`）
   - `new String(charArray, offset, count)` 可以从 char 数组的指定范围构建字符串
