## 题目描述

将 nums 分割为 k 个不相交子数组，第 i 个子数组的强度为 `(-1)^(i+1) * i * sum`，返回所有分割方式中最大强度总和。

## 解题思路

DP + 前缀和：`dp[i][j]` 为前 j 个元素划分为 i 个子数组的最大强度。利用 `sum = prefix[j] - prefix[j']`，维护最优前驱 `max(dp[i-1][j'] - w_i * prefix[j'])` 实现 O(1) 转移。

## Java 代码实现

```java
class Solution {
    public long maximumStrength(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        long NEG_INF = Long.MIN_VALUE / 2;
        long[] prev = new long[n + 1];
        Arrays.fill(prev, NEG_INF);
        prev[0] = 0;

        for (int i = 1; i <= k; i++) {
            long w = (i % 2 == 1) ? i : -i; // 奇数正权重，偶数负权重
            long[] curr = new long[n + 1];
            Arrays.fill(curr, NEG_INF);
            long best = NEG_INF;

            for (int j = i; j <= n; j++) {
                // 更新最优前驱
                if (prev[j - 1] != NEG_INF) {
                    best = Math.max(best, prev[j - 1] - w * prefix[j - 1]);
                }
                // 更新 curr[j]
                if (best != NEG_INF) {
                    curr[j] = w * prefix[j] + best;
                }
            }
            prev = curr;
        }

        long ans = NEG_INF;
        for (int j = k; j <= n; j++) ans = Math.max(ans, prev[j]);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)
- **空间复杂度**：O(n)，滚动数组

## 关键点总结

1. 奇数子数组权重为正（希望和最大），偶数子数组权重为负（希望和最小）
2. DP 利用前缀和转化，用维护最优前驱实现 O(1) 转移
3. 用 long 防止溢出，初始化用 Long.MIN_VALUE/2 避免加法溢出
