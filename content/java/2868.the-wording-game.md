## 题目描述

Alice 和 Bob 轮流出牌，每张新牌首字母必须严格大于上一张末字母，Alice 先出，无法出牌者输，返回 Alice 是否能赢。

## 解题思路

贪心排序后模拟：两人各自的卡片排序后，每次出满足条件的首字母最小的牌（让对方难以接续），用双指针模拟直到一方无牌可出。

## Java 代码实现

```java
class Solution {
    public boolean canAliceWin(String[] a, String[] b) {
        Arrays.sort(a);
        Arrays.sort(b);

        int ia = 0, ib = 0;
        char prevLast = (char) ('a' - 1); // 初始无限制
        boolean aliceTurn = true;

        while (true) {
            if (aliceTurn) {
                // Alice 找首字母严格大于 prevLast 的最小牌
                while (ia < a.length && a[ia].charAt(0) <= prevLast) ia++;
                if (ia >= a.length) return false; // Alice 无牌可出
                prevLast = a[ia].charAt(a[ia].length() - 1);
                ia++;
            } else {
                // Bob 找首字母严格大于 prevLast 的最小牌
                while (ib < b.length && b[ib].charAt(0) <= prevLast) ib++;
                if (ib >= b.length) return true; // Bob 无牌可出，Alice 赢
                prevLast = b[ib].charAt(b[ib].length() - 1);
                ib++;
            }
            aliceTurn = !aliceTurn;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O((|a| + |b|) log(|a| + |b|))
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后贪心：每次选满足条件的首字母最小的牌
2. 初始 Alice 无限制，用比 'a' 小的字符初始化
3. 条件是严格大于（首字母 > 上一张末字母）
