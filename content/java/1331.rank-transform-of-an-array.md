## 题目描述

给你一个整数数组 `arr`，请你将数组中的每个元素替换为它们排序后的序号。

序号代表了一个元素有多大。序号编号规则如下：

- 序号从 1 开始编号。
- 一个元素越大，那么序号越大。如果两个元素相等，那么它们的序号相同。
- 每个数字的序号都应该尽可能地小。

**示例 1：**
```
输入：arr = [40,10,20,30]
输出：[4,1,2,3]
解释：40 是最大的元素，所以序号为 4；10 是最小的元素，序号为 1；以此类推。
```

**示例 2：**
```
输入：arr = [100,100,100]
输出：[1,1,1]
解释：所有元素相等，所以序号都为 1。
```

**示例 3：**
```
输入：arr = [37,12,28,9,100,56,80,5,12]
输出：[5,3,4,2,8,6,7,1,3]
```

**提示：**
- `0 <= arr.length <= 10^5`
- `-10^9 <= arr[i] <= 10^9`

## 解题思路

**算法步骤：**
1. 对数组元素去重并排序，得到从小到大的唯一值列表
2. 建立哈希映射：每个唯一值 -> 其排名（从 1 开始）
3. 遍历原数组，用哈希映射替换每个元素

**关键点：** 相同元素对应相同排名，排名连续（不跳号）。

## Java 代码实现

### 方法一：排序 + 哈希映射（推荐）

```java
import java.util.*;

class Solution {
    public int[] arrayRankTransform(int[] arr) {
        int n = arr.length;
        
        // 复制并排序，建立去重后的排名映射
        int[] sorted = arr.clone();
        Arrays.sort(sorted);
        
        // 建立值到排名的映射（去重：相同值只记录最小序号）
        Map<Integer, Integer> rankMap = new HashMap<>();
        int rank = 1;
        for (int val : sorted) {
            if (!rankMap.containsKey(val)) {
                rankMap.put(val, rank++);
            }
        }
        
        // 替换原数组
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            result[i] = rankMap.get(arr[i]);
        }
        return result;
    }
}
```

### 方法二：按排序索引直接填结果

```java
import java.util.*;

class Solution {
    public int[] arrayRankTransform(int[] arr) {
        int n = arr.length;
        if (n == 0) return new int[0];
        
        // 按值排序，保留原始索引
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> arr[a] - arr[b]);
        
        int[] result = new int[n];
        int rank = 1;
        for (int k = 0; k < n; k++) {
            // 如果与前一个值相同，使用相同排名
            if (k > 0 && arr[indices[k]] == arr[indices[k - 1]]) {
                result[indices[k]] = result[indices[k - 1]];
            } else {
                result[indices[k]] = rank;
                rank++;
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一 | O(n log n) | O(n) |
| 方法二 | O(n log n) | O(n) |

- **时间复杂度**：排序 `O(n log n)` 是瓶颈
- **空间复杂度**：哈希映射和结果数组各 `O(n)`

## 图解示例

以 `arr = [37, 12, 28, 9, 100, 56, 80, 5, 12]` 为例：

```
原数组：  [37, 12, 28,  9, 100, 56, 80,  5, 12]

去重排序：[5, 9, 12, 28, 37, 56, 80, 100]

排名映射：
  5  -> 1
  9  -> 2
  12 -> 3
  28 -> 4
  37 -> 5
  56 -> 6
  80 -> 7
  100-> 8

替换结果：[5, 3, 4, 2, 8, 6, 7, 1, 3]
```

## 关键点总结

1. 核心思路：排序去重 + 建立哈希映射，一次遍历替换
2. 对排序后的数组遍历，遇到新值才递增排名，保证相同元素同排名
3. 排名连续不跳号
4. 方法一用 `HashMap` 建立值到排名的映射，方法二直接操作索引数组

## 易错点

1. 忘记去重：直接对 `arr` 排序建映射时，相同元素会被赋予不同排名
2. 排名从 0 还是从 1 开始：题目要求从 1 开始
3. 排名是否连续：去重后再映射可以保证排名连续

## 学习建议

1. 掌握"排序 + 哈希映射"这个组合拳，很多映射类问题都可以用这个思路
2. 注意去重的必要性：如果不去重，相同元素无法映射到同一排名
3. 方法二通过索引数组排序是一种通用的"间接排序"技巧，适用于需要保留原始位置的情况
4. 试着思考：如果不允许使用排序，还有什么方法？（计数排序？）
