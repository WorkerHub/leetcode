## 题目描述

给你两个按 id 升序排列的二维数组 `nums1` 和 `nums2`（每行为 [id, val]），合并相同 id 的值，返回合并后的有序结果。

## 解题思路

双指针合并：类似归并排序的合并步骤，比较两指针指向的 id，相等则合并求和，否则取较小 id 加入结果。

## Java 代码实现

```java
class Solution {
    public int[][] mergeArrays(int[][] nums1, int[][] nums2) {
        java.util.List<int[]> res = new java.util.ArrayList<>();
        int i = 0, j = 0;
        while (i < nums1.length && j < nums2.length) {
            int id1 = nums1[i][0], id2 = nums2[j][0];
            if (id1 == id2) {
                res.add(new int[]{id1, nums1[i][1] + nums2[j][1]});
                i++; j++;
            } else if (id1 < id2) {
                res.add(nums1[i++]);
            } else {
                res.add(nums2[j++]);
            }
        }
        while (i < nums1.length) res.add(nums1[i++]);
        while (j < nums2.length) res.add(nums2[j++]);
        return res.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)

## 关键点总结

1. 双指针归并：id 相等时合并求和，否则取较小的加入结果
2. 归并结束后处理剩余元素
3. `res.toArray(new int[0][])` 将 List 转为二维数组
