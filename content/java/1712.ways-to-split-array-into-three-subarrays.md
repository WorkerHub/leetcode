## 题目描述

非负整数数组 `nums`，将其分为三个连续非空子数组，满足第一段和 <= 第二段和 <= 第三段和。返回好方案数对 `10^9 + 7` 取余。

## 解题思路

**前缀和 + 二分查找：** 枚举第一段结尾 `i`，对每个 `i` 用二分找第二段结尾 `j` 的合法范围 `[jMin, jMax]`，累加 `jMax - jMin + 1`。

- `jMin`：第二段和 >= 第一段和（`prefix[j+1] >= 2 * s1`）
- `jMax`：第三段和 >= 第二段和（`2 * prefix[j+1] <= total + s1`）

## Java 代码实现

```java
class Solution {
    public int waysToSplit(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];
        int total = prefix[n];

        long ans = 0;
        for (int i = 0; i < n - 2; i++) {
            int s1 = prefix[i + 1];
            if (s1 * 3 > total) break; // 剪枝

            // 二分找 jMin：prefix[j+1] >= 2*s1，且 j >= i+1, j <= n-2
            int lo = i + 1, hi = n - 2, jMin = n - 1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (prefix[mid + 1] - s1 >= s1) { jMin = mid; hi = mid - 1; }
                else lo = mid + 1;
            }

            // 二分找 jMax：2*(prefix[j+1]-s1) <= total-s1，且 j <= n-2
            lo = jMin; hi = n - 2;
            int jMax = jMin - 1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (2 * (prefix[mid + 1] - s1) <= total - s1) { jMax = mid; lo = mid + 1; }
                else hi = mid - 1;
            }

            if (jMin <= jMax) ans = (ans + jMax - jMin + 1) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 前缀和 O(1) 查区间和
2. 枚举第一段后，用两次二分确定第二段的合法范围
3. `s1 * 3 > total` 时剪枝提前退出
