## 题目描述

给你一棵带权树，多次行程各经过若干节点，可选择若干不相邻节点价格减半，返回所有行程总价格的最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] graph;
    private int[] price;
    private int[] cnt;

    public int minimumTotalPrice(int n, int[][] edges, int[] price, int[][] trips) {
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }
        this.price = price;
        cnt = new int[n];

        // 统计每个节点被行程经过的次数
        for (int[] trip : trips) {
            dfsPath(trip[0], -1, trip[1]);
        }

        // 树上 DP：返回 [不减半最小费用, 减半最小费用]
        int[] res = dp(0, -1);
        return Math.min(res[0], res[1]);
    }

    // DFS 找路径并统计经过次数，找到目标返回 true
    private boolean dfsPath(int node, int parent, int target) {
        if (node == target) {
            cnt[node]++;
            return true;
        }
        for (int nb : graph[node]) {
            if (nb != parent && dfsPath(nb, node, target)) {
                cnt[node]++;
                return true;
            }
        }
        return false;
    }

    // 返回 [不减半, 减半] 的最小总费用
    private int[] dp(int node, int parent) {
        int full = price[node] * cnt[node];
        int half = (price[node] / 2) * cnt[node];
        int notHalved = full;
        int halved = half;

        for (int nb : graph[node]) {
            if (nb != parent) {
                int[] child = dp(nb, node);
                notHalved += Math.min(child[0], child[1]); // 当前不减半，子节点随意
                halved += child[0];                         // 当前减半，子节点不能减半
            }
        }
        return new int[]{notHalved, halved};
    }
}
```

## 复杂度分析

- 时间复杂度：O(trips × n + n)，路径统计 O(trips × n)，树 DP O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 先用 DFS 统计每个节点被行程经过的次数
2. 树上 DP 类似打家劫舍：减半节点不能相邻
3. 节点实际代价 = `price[node] * cnt[node]`
