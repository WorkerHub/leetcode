## 题目描述

给你 `m x n` 整数矩阵 `grid` 和整数 `k`，从 `(0,0)` 只能向右或向下到 `(m-1,n-1)`，返回路径和能被 `k` 整除的路径数目（结果对 10^9+7 取余）。

## 解题思路

DP：`dp[i][j][r]` 表示到达 `(i,j)` 时路径和模 k 等于 r 的路径数。转移时逆推前驱余数 `prevR = (r - grid[i][j] % k + k) % k`，从上方和左方累加。

## Java 代码实现

```java
class Solution {
    public int numberOfPaths(int[][] grid, int k) {
        final int MOD = 1_000_000_007;
        int m = grid.length, n = grid[0].length;

        // dp[j][r] = 到达当前行第 j 列路径和 mod k = r 的路径数（滚动数组）
        int[][] prev = new int[n][k];
        prev[0][grid[0][0] % k] = 1;
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            for (int r = 0; r < k; r++) {
                int prevR = (r - grid[0][j] % k + k) % k;
                prev[j][r] = prev[j - 1][prevR];
            }
        }

        for (int i = 1; i < m; i++) {
            int[][] cur = new int[n][k];
            // 初始化第一列
            for (int r = 0; r < k; r++) {
                int prevR = (r - grid[i][0] % k + k) % k;
                cur[0][r] = prev[0][prevR];
            }
            for (int j = 1; j < n; j++) {
                for (int r = 0; r < k; r++) {
                    int prevR = (r - grid[i][j] % k + k) % k;
                    cur[j][r] = (prev[j][prevR] + cur[j - 1][prevR]) % MOD;
                }
            }
            prev = cur;
        }
        return prev[n - 1][0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n × k)
- **空间复杂度**：O(n × k)（滚动数组）

## 关键点总结

1. 状态包含路径和模 k 的余数，将问题转化为余数 DP
2. 逆推前驱余数：`prevR = (r - grid[i][j] % k + k) % k`，`+k` 防止负数
3. 答案为 `dp[m-1][n-1][0]`
