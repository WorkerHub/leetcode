## 题目描述

n 个盒子，每个有状态（开/关）、糖果数、钥匙列表、内含盒子列表。给定初始盒子，按规则打开能打开的盒子，求最多可获得的糖果数。

**示例：**
```
输入：status = [1,0,1,0], candies = [7,5,4,100], keys = [[],[],[1],[]], 
     containedBoxes = [[1,2],[3],[],[]], initialBoxes = [0]
输出：16
```

## 解题思路

BFS 模拟：维护"拥有的盒子"和"拥有的钥匙"，不断尝试打开可打开的盒子，直到无法再打开。

## Java 代码实现

```java
class Solution {
    public int maxCandies(int[] status, int[] candies, int[][] keys,
                         int[][] containedBoxes, int[] initialBoxes) {
        int n = status.length;
        boolean[] hasBox = new boolean[n];
        boolean[] hasKey = new boolean[n];
        boolean[] opened = new boolean[n];
        
        Queue<Integer> queue = new LinkedList<>();
        int totalCandies = 0;
        
        // 初始化
        for (int box : initialBoxes) {
            hasBox[box] = true;
            if (status[box] == 1) {
                queue.offer(box);
                opened[box] = true;
                totalCandies += candies[box];
            }
        }
        
        while (!queue.isEmpty()) {
            int box = queue.poll();
            
            // 获取钥匙
            for (int key : keys[box]) {
                hasKey[key] = true;
                // 如果有该盒子且未打开，现在可以打开
                if (hasBox[key] && !opened[key]) {
                    queue.offer(key);
                    opened[key] = true;
                    totalCandies += candies[key];
                }
            }
            
            // 获取内含盒子
            for (int contained : containedBoxes[box]) {
                hasBox[contained] = true;
                // 如果盒子本身是开的或有钥匙，可以打开
                if (!opened[contained] && (status[contained] == 1 || hasKey[contained])) {
                    queue.offer(contained);
                    opened[contained] = true;
                    totalCandies += candies[contained];
                }
            }
        }
        return totalCandies;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 总钥匙数 + 总内含盒子数)
- **空间复杂度**：O(n)

## 关键点总结

1. **BFS 模拟**：打开盒子 → 获取钥匙和新盒子 → 尝试打开更多
2. **两个条件**：拥有盒子 + (状态打开 或 有钥匙)
3. **即时检查**：获得钥匙时检查是否有对应盒子，获得盒子时检查是否有钥匙
