## 题目描述

给你偶数长度的整数数组 `nums`，每次取出最小和最大元素计算平均值，重复直到数组为空，返回所有平均值中的最小值。

## 解题思路

排序后，最小和最大元素分别在两端，用双指针 `nums[i]` 和 `nums[n-1-i]` 逐对计算平均值，返回最小值。

## Java 代码实现

```java
class Solution {
    public double minimumAverage(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        double ans = Double.MAX_VALUE;
        for (int i = 0; i < n / 2; i++) {
            double avg = (nums[i] + nums[n - 1 - i]) / 2.0;
            ans = Math.min(ans, avg);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后双指针从两端向中间，逐对取最小最大元素
2. 返回所有配对平均值中的最小值（不一定是第一对）
