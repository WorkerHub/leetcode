## 题目描述

给你 `n x m` 的整数矩阵 `grid` 和整数 `k`，返回满足以下条件的子矩阵数目：1. 子矩阵每列从上到下严格递减；2. 子矩阵最大元素 <= `k`。

## 解题思路

预处理 `h[i][j]`（从 `(i, j)` 向上连续严格递减的高度）。对每行 `i` 枚举列区间 `[c1, c2]`，子矩阵高度为 `min(h[i][c1..c2])`，再检查该范围内所有元素 <= k。

## Java 代码实现

```java
class Solution {
    public long countSubmatrices(int[][] grid, int k) {
        int n = grid.length, m = grid[0].length;

        // h[i][j] = 从 (i, j) 向上连续严格递减的高度（含自身）
        int[][] h = new int[n][m];
        for (int j = 0; j < m; j++) h[0][j] = 1;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < m; j++) {
                h[i][j] = (grid[i - 1][j] > grid[i][j]) ? h[i - 1][j] + 1 : 1;
            }
        }

        long count = 0;

        // 对每行 i，枚举列区间 [c1, c2]
        for (int i = 0; i < n; i++) {
            for (int c1 = 0; c1 < m; c1++) {
                int minH = h[i][c1];
                for (int c2 = c1; c2 < m; c2++) {
                    minH = Math.min(minH, h[i][c2]);
                    // 子矩阵行范围 [i - minH + 1, i]，列范围 [c1, c2]
                    // 检查所有元素 <= k
                    boolean valid = true;
                    outer:
                    for (int r = i - minH + 1; r <= i; r++) {
                        for (int c = c1; c <= c2; c++) {
                            if (grid[r][c] > k) {
                                valid = false;
                                break outer;
                            }
                        }
                    }
                    if (valid) count++;
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * m^2)，枚举子矩阵
- 空间复杂度：O(n * m)，高度数组

## 关键点总结

1. 每列严格递减的子矩阵高度用 `h[i][j]` 预处理，高度取列区间的最小值。
2. 对每行枚举列区间，动态维护最小高度。
3. 额外检查子矩阵内最大元素 <= k 约束。
