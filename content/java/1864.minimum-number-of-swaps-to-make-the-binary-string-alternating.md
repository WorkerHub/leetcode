## 题目描述

将二进制字符串变为交替串(010...或101...)的最少交换次数。无法实现返回-1。

## 解题思路

交替串只有两种形式，分别计算错位数/2取最小。可行性：0和1数量差≤1。

## Java 代码实现

```java
class Solution {
    public int minSwaps(String s) {
        int ones = 0, zeros = 0;
        for (char c : s.toCharArray()) {
            if (c == '1') ones++;
            else zeros++;
        }
        if (Math.abs(ones - zeros) > 1) return -1;
        
        if (ones > zeros) return countSwaps(s, '1');
        if (zeros > ones) return countSwaps(s, '0');
        return Math.min(countSwaps(s, '0'), countSwaps(s, '1'));
    }
    
    private int countSwaps(String s, char startChar) {
        // 统计偶数位与期望不符的个数
        int wrong = 0;
        for (int i = 0; i < s.length(); i += 2) {
            if (s.charAt(i) != startChar) wrong++;
        }
        return wrong;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **两种目标**：以0开头或以1开头
2. **交换次数=偶数位错位数**：错位的0和1数量相等，互相交换
3. **可行性判断**：abs(cnt0-cnt1)>1则不可能
