## 题目描述

有多种面额硬币，每次只能用单一面额，求能凑出的第k小金额。

## 解题思路

二分答案x，用容斥原理计算<=x的合法金额数：枚举coins子集，奇加偶减，每个子集贡献x/lcm(子集)。

## Java 代码实现

```java
class Solution {
    public long findKthSmallest(int[] coins, int k) {
        int n = coins.length;
        long lo = 1, hi = (long) k * coins[0];
        for (int c : coins) hi = Math.min(hi, (long) k * c);

        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (count(coins, mid, n) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private long count(int[] coins, long x, int n) {
        long res = 0;
        for (int mask = 1; mask < (1 << n); mask++) {
            long lc = 1;
            int bits = Integer.bitCount(mask);
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) {
                    lc = lc / gcd(lc, coins[i]) * coins[i];
                    if (lc > x) break;
                }
            }
            if (lc <= x) {
                if (bits % 2 == 1) res += x / lc;
                else res -= x / lc;
            }
        }
        return res;
    }

    private long gcd(long a, long b) {
        while (b != 0) { long t = b; b = a % b; a = t; }
        return a;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^N * log(K*min))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：找最小x使count(x)>=k
2. **容斥原理**：奇数子集加，偶数子集减
3. **LCM计算**：lcm(a,b)=a/gcd(a,b)*b防溢出
