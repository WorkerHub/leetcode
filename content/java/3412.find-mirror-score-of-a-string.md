## 题目描述

给定字符串 `s`，`'a'` 与 `'z'` 互为镜像，`'b'` 与 `'y'` 互为镜像，依此类推。遍历每个位置，若前面有未使用的镜像字符则配对得 `i-j` 分，返回总得分。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long calculateScore(String s) {
        // 每个字母维护一个栈，存未匹配的下标
        Deque<Integer>[] stacks = new ArrayDeque[26];
        for (int i = 0; i < 26; i++) stacks[i] = new ArrayDeque<>();

        long score = 0;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            int mirror = 25 - c; // 镜像字符索引

            if (!stacks[mirror].isEmpty()) {
                // 取最近的镜像字符（栈顶）
                int j = stacks[mirror].pop();
                score += i - j;
            } else {
                // 未找到镜像，入栈等待匹配
                stacks[c].push(i);
            }
        }
        return score;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符最多入栈出栈各一次
- 空间复杂度：O(n)，栈的总大小

## 关键点总结

1. 镜像字符关系：第 k 个字母（0-indexed）的镜像是第 25-k 个字母。
2. 用栈匹配"最近的"未使用镜像字符。
3. 每次匹配时，栈顶是最近的镜像字符下标。
