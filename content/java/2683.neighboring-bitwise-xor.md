## 题目描述

给你由 `original` 数组生成的 `derived` 数组（`derived[i] = original[i] XOR original[(i+1)%n]`），判断是否存在合法的 `original` 数组。

## Java 代码实现

```java
class Solution {
    public boolean doesValidArrayExist(int[] derived) {
        // 当且仅当 derived 所有元素的 XOR 为 0 时存在合法 original
        int xor = 0;
        for (int x : derived) xor ^= x;
        return xor == 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 循环 XOR 中每个 `original[i]` 出现两次，总 XOR 为 0
2. 因此 `derived` 所有元素 XOR = 0 是充要条件
