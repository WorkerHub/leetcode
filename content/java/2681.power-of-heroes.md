## 题目描述

给你整数数组 `nums`，英雄组的力量 = 最大值的平方 × 最小值，返回所有非空子集的力量之和（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int sumOfPower(int[] nums) {
        long MOD = 1_000_000_007L;
        Arrays.sort(nums);
        long ans = 0, dp = 0;
        // 枚举 nums[i] 作为最大值
        for (int x : nums) {
            // dp 是前面所有元素作为最小值的加权和
            // nums[i]^2 * (dp + nums[i])：dp 中每个最小值贡献 nums[i]^2，加上自身作为最小值
            ans = (ans + (long) x % MOD * (x % MOD) % MOD * ((dp + x) % MOD)) % MOD;
            // 更新 dp：旧最小值的子集多了一种选择（乘以2），加入 nums[i]
            dp = (2 * dp + x) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后枚举最大值 `nums[i]`，dp 维护前缀最小值加权和
2. 更新公式：`dp = 2 * dp + nums[i]`（旧子集增加一种选择而翻倍，加上 nums[i] 自身）
3. 全程注意取模
