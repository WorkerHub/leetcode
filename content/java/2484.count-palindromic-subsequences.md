## 题目描述

给你数字字符串 `s`，返回长度为 5 的回文子序列数目，结果对 `10^9+7` 取模。

## 解题思路

长度 5 的回文形如 `abcba`：枚举内层字符对位置 `(i, j)`（`s[i] == s[j]`），外层从 `s[0..i-1]` 和 `s[j+1..n-1]` 中各取一个相同字符 `a`，中间字符任意有 `j-i-1` 种。预处理 `left[i][d]` 和 `right[j][d]` 后三重枚举即可。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public long countPalindromes(String s) {
        int n = s.length();
        // left[i][d] = s[0..i-1] 中数字 d 的出现次数
        int[][] left = new int[n][10];
        // right[i][d] = s[i+1..n-1] 中数字 d 的出现次数
        int[][] right = new int[n][10];

        for (int i = 1; i < n; i++) {
            left[i] = left[i - 1].clone();
            left[i][s.charAt(i - 1) - '0']++;
        }
        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1].clone();
            right[i][s.charAt(i + 1) - '0']++;
        }

        long ans = 0;
        // 枚举内层字符对 (i, j)：s[i] == s[j]，中间至少有 1 个字符
        for (int i = 1; i < n - 3; i++) {
            for (int j = i + 2; j < n - 1; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    long mid = j - i - 1; // 中间字符数量
                    // 枚举外层字符 d
                    for (int d = 0; d < 10; d++) {
                        ans = (ans + (long) left[i][d] * right[j][d] % MOD * mid) % MOD;
                    }
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × 10)
- **空间复杂度**：O(n × 10)

## 关键点总结

1. 枚举内层对 `(i, j)` 满足 `s[i] == s[j]`，保证 `i >= 1, j <= n-2` 以留外层位置
2. 外层字符 `a` 须从两侧各取一个相同数字，贡献 `left[i][d] * right[j][d]`
3. 中间字符任意，个数为 `j - i - 1`
