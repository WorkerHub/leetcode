## 题目描述

Alice 打字时每个字符键至多多按一次，给你最终显示的字符串 `word`，返回 Alice 原本可能打出的不同字符串数量。

## 解题思路

对 `word` 中每段连续相同字符（长度 k），若 k >= 2 则该段可能是 k 个或 k-1 个（多按或不多按），贡献因子 2；k = 1 时只有 1 种。答案 = 各段因子之积 = 2^(长度 >= 2 的段数)。

## Java 代码实现

```java
class Solution {
    public int possibleStringCount(String word) {
        int result = 1, n = word.length(), i = 0;
        while (i < n) {
            int j = i + 1;
            while (j < n && word.charAt(j) == word.charAt(i)) j++;
            if (j - i >= 2) result *= 2; // 该段有多按或未多按两种可能
            i = j;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每段连续字符长度 >= 2 时贡献因子 2（多按或不多按）
2. 不同段独立，总答案是各段因子之积
3. 答案 = 2^(长度 >= 2 的段数)
