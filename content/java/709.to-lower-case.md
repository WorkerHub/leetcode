## 题目描述

给你一个字符串 `s`，将该字符串中的大写字母转换成相同的小写字母，返回新的字符串。

**示例 1：**

```
输入：s = "Hello"
输出："hello"
```

**示例 2：**

```
输入：s = "here"
输出："here"
```

**示例 3：**

```
输入：s = "LOVELY"
输出："lovely"
```

**提示：**
- `1 <= s.length <= 100`
- `s` 由 ASCII 字符集中的可打印字符组成

## 解题思路

这是一道字符串基础题，主要考察字符串处理和字符转换。

**核心思想：**
- 大写字母 A-Z 的 ASCII 码范围是 65-90
- 小写字母 a-z 的 ASCII 码范围是 97-122
- 大写字母转小写：ASCII 码值 + 32

**多种实现方式：**
1. 使用 Java 内置方法 `toLowerCase()`
2. 使用 ASCII 码转换
3. 使用位运算

## Java 代码实现

### 方法一：内置方法（推荐）⭐

```java
class Solution {
    public String toLowerCase(String s) {
        // 使用 Java 内置的 toLowerCase() 方法
        return s.toLowerCase();
    }
}
```

### 方法二：ASCII 码转换

```java
class Solution {
    public String toLowerCase(String s) {
        // 通过 ASCII 码转换实现
        // 大写字母 A-Z: 65-90
        // 小写字母 a-z: 97-122
        // 差值为 32
        StringBuilder sb = new StringBuilder();
        
        for (char c : s.toCharArray()) {
            // 判断是否为大写字母
            if (c >= 'A' && c <= 'Z') {
                // 转换为小写：ASCII 码 + 32
                sb.append((char)(c + 32));
            } else {
                // 保持原样
                sb.append(c);
            }
        }
        
        return sb.toString();
    }
}
```

### 方法三：使用 ASCII 码值判断

```java
class Solution {
    public String toLowerCase(String s) {
        // 直接使用 ASCII 码值判断
        char[] chars = s.toCharArray();
        
        for (int i = 0; i < chars.length; i++) {
            int ascii = chars[i];
            // 65-90 是大写字母 A-Z
            if (ascii >= 65 && ascii <= 90) {
                chars[i] = (char)(ascii + 32);
            }
        }
        
        return new String(chars);
    }
}
```

### 方法四：位运算优化

```java
class Solution {
    public String toLowerCase(String s) {
        // 大写字母和小写字母的 ASCII 码差异在第 6 位（从右往左数）
        // 通过 | 32 可以将大写转小写
        char[] chars = s.toCharArray();
        
        for (int i = 0; i < chars.length; i++) {
            if (chars[i] >= 'A' && chars[i] <= 'Z') {
                // 位运算：或上 0b100000 (32)
                chars[i] |= 32;
            }
        }
        
        return new String(chars);
    }
}
```

## 复杂度分析

### 所有方法：
- **时间复杂度：** O(n)，需要遍历字符串的每个字符
- **空间复杂度：** O(n)，需要创建新的字符串存储结果

## 图解示例

以 "Hello" 为例：

```
原字符串: H    e    l    l    o
ASCII码:  72   101  108  108  111
         (大写)(小写)(小写)(小写)(小写)

处理逻辑:
H (72) -> 是大写 -> 72 + 32 = 104 -> h
e (101) -> 是小写 -> 保持不变 -> e
l (108) -> 是小写 -> 保持不变 -> l
l (108) -> 是小写 -> 保持不变 -> l
o (111) -> 是小写 -> 保持不变 -> o

结果字符串: h    e    l    l    o
```

## 关键点总结

1. **ASCII 码规律**：大写字母和对应小写字母的 ASCII 码差值为 32
2. **字符判断**：可以用 `'A' <= c && c <= 'Z'` 或 `65 <= c && c <= 90` 判断大写字母
3. **字符转换**：Java 中可以直接强制类型转换 `(char)(c + 32)`
4. **位运算技巧**：`c |= 32` 可以将大写字母转为小写
5. **Java 特性**：实际应用中直接使用 `toLowerCase()` 最简洁高效

## 易错点

1. **忘记处理非字母字符**：数字、符号等应保持不变
2. **字符串不可变**：Java 中字符串不可变，需要使用 StringBuilder 或 char 数组
3. **ASCII 码范围**：只有 A-Z 需要转换，不要误转其他字符
4. **位运算的适用范围**：位运算 `| 32` 只对大写字母有效
5. **类型转换**：`(char)(c + 32)` 需要显式类型转换
