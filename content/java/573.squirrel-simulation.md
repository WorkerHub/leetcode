## 题目描述

现在有一棵树，一只松鼠和一些坚果。位置由二维网格的单元格表示。你的目标是找到松鼠收集所有坚果并把它们放到树下的最小路程。松鼠一次最多只能携带一颗坚果。

松鼠可以直接从当前位置跳到树或坚果的位置。所有的距离都是曼哈顿距离。

给定五个参数：
- `height` 和 `width` 表示网格的高度和宽度
- `tree` 表示树的位置
- `squirrel` 表示松鼠的位置
- `nuts` 表示坚果的位置数组

**示例：**
```
输入：
height = 5, width = 7
tree = [2,2]
squirrel = [4,4]
nuts = [[3,0], [2,5]]
输出：12
```

## 解题思路

核心观察：
- 除了第一颗坚果，其他所有坚果都需要往返（nut -> tree -> nut -> tree）
- 第一颗坚果：squirrel -> nut -> tree
- 最优策略：选择能节省最多距离的坚果作为第一颗

## Java 代码实现

### 方法一：贪心（推荐）⭐

```java
class Solution {
    public int minDistance(int height, int width, int[] tree, int[] squirrel, int[][] nuts) {
        // 贪心选择第一颗坚果
        // 计算所有坚果往返树的总距离
        int totalDistance = 0;
        for (int[] nut : nuts) {
            totalDistance += 2 * manhattanDistance(nut, tree);
        }

        // 找到最优的第一颗坚果（能节省最多距离的）
        // 节省的距离 = nut -> tree - squirrel -> nut
        int maxSaving = Integer.MIN_VALUE;
        for (int[] nut : nuts) {
            int distNutTree = manhattanDistance(nut, tree);
            int distSquirrelNut = manhattanDistance(squirrel, nut);
            int saving = distNutTree - distSquirrelNut;
            maxSaving = Math.max(maxSaving, saving);
        }

        return totalDistance - maxSaving;
    }

    // 计算曼哈顿距离
    private int manhattanDistance(int[] p1, int[] p2) {
        return Math.abs(p1[0] - p2[0]) + Math.abs(p1[1] - p2[1]);
    }
}
```

### 方法二：直接计算

```java
class Solution {
    public int minDistance(int height, int width, int[] tree, int[] squirrel, int[][] nuts) {
        // 直接计算最小距离
        int total = 0;
        int minDiff = Integer.MAX_VALUE;

        for (int[] nut : nuts) {
            int d = dist(nut, tree);
            total += 2 * d;
            // 计算作为第一颗坚果的额外距离（正数为多走，负数为少走）
            int diff = dist(squirrel, nut) - d;
            minDiff = Math.min(minDiff, diff);
        }

        return total + minDiff;
    }

    private int dist(int[] p1, int[] p2) {
        return Math.abs(p1[0] - p2[0]) + Math.abs(p1[1] - p2[1]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 是坚果数量
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心策略**：选择能节省最多距离的坚果作为第一颗
2. **曼哈顿距离**：|x1 - x2| + |y1 - y2|
3. **数学转化**：total - max_saving
