## 题目描述

给你美丽字符串 `s`（不含长度 2 或 3 的回文子串，只用前 `k` 个字母），返回字典序最小且大于 `s` 的美丽字符串，不存在则返回空字符串。

## Java 代码实现

```java
class Solution {
    public String smallestBeautifulString(String s, int k) {
        char[] arr = s.toCharArray();
        int n = arr.length;

        // 从最后一位开始，尝试递增该位
        int i = n - 1;
        while (i >= 0) {
            arr[i]++;
            // 找当前位第一个不形成回文的字符
            while (arr[i] < 'a' + k) {
                if ((i < 1 || arr[i] != arr[i - 1]) &&
                    (i < 2 || arr[i] != arr[i - 2])) {
                    break;
                }
                arr[i]++;
            }
            if (arr[i] < 'a' + k) {
                // 递增成功，将后续位填最小合法字符
                for (int j = i + 1; j < n; j++) {
                    arr[j] = 'a';
                    // 找第一个不形成回文的字符
                    while ((j >= 1 && arr[j] == arr[j - 1]) ||
                           (j >= 2 && arr[j] == arr[j - 2])) {
                        arr[j]++;
                    }
                }
                return new String(arr);
            }
            i--; // 当前位无法递增，退到前一位
        }
        return "";
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，最坏情况每位尝试 k 个字符
- 空间复杂度：O(n)

## 关键点总结

1. 不含长度 2 或 3 的回文等价于：`s[i] != s[i-1]` 且 `s[i] != s[i-2]`
2. 从末位往前找第一个可递增位，后续位从 'a' 开始填最小合法字符
3. k 限制了可用字符范围
