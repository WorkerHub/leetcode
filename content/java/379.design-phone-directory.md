## 题目描述

设计一个电话目录管理系统，让它支持以下功能：

- `PhoneDirectory(int maxNumbers)` 初始化电话目录，最多可以存储 `maxNumbers` 个号码
- `int get()` 获取一个未分配的号码，如果有可用号码则返回该号码，否则返回 -1
- `bool check(int number)` 检查指定的号码是否可用
- `void release(int number)` 释放（回收）一个号码

**示例：**

```
输入：
["PhoneDirectory", "get", "get", "check", "get", "check", "release", "check"]
[[3], [], [], [2], [], [2], [2], [2]]

输出：
[null, 0, 1, true, 2, false, null, true]

解释：
PhoneDirectory phoneDirectory = new PhoneDirectory(3);
phoneDirectory.get();      // 返回 0，可以返回任意可用的号码，这里我们假定第一次调用返回 0
phoneDirectory.get();      // 返回 1
phoneDirectory.check(2);   // 返回 true，号码 2 尚未分配
phoneDirectory.get();      // 返回 2
phoneDirectory.check(2);   // 返回 false，号码 2 已经被分配了
phoneDirectory.release(2); // 释放号码 2
phoneDirectory.check(2);   // 返回 true，号码 2 已经被释放
```

**提示：**
- `1 <= maxNumbers <= 10^4`
- `0 <= number < maxNumbers`
- 调用方法的总次数在 `[0, 10^4]` 范围内

## 解题思路

这道题是一个设计题，需要高效地管理号码的分配和释放。

### 核心需求

1. **get()**：O(1) 获取可用号码
2. **check(number)**：O(1) 检查号码是否可用
3. **release(number)**：O(1) 释放号码

### 设计思路

**方法一：布尔数组 + 队列（推荐）**
- 使用布尔数组标记号码是否可用（快速检查）
- 使用队列维护可用号码（快速获取）

**方法二：HashSet + 队列**
- 使用 HashSet 存储所有可用号码（快速检查）
- 使用队列维护可用号码（快速获取）

**方法三：位图（进阶）**
- 使用位图压缩存储状态

## Java 代码实现

### 方法一：布尔数组 + 队列（推荐）

```java
import java.util.*;

class PhoneDirectory {
    private boolean[] isAvailable; // 标记每个号码是否可用
    private Queue<Integer> queue;  // 维护可用号码队列

    public PhoneDirectory(int maxNumbers) {
        // 初始化：所有号码都可用
        isAvailable = new boolean[maxNumbers];
        Arrays.fill(isAvailable, true);
        queue = new LinkedList<>();
        for (int i = 0; i < maxNumbers; i++) {
            queue.offer(i);
        }
    }

    public int get() {
        // 队列为空，没有可用号码
        if (queue.isEmpty()) return -1;
        int number = queue.poll();
        isAvailable[number] = false; // 标记为已分配
        return number;
    }

    public boolean check(int number) {
        // 直接查布尔数组
        return isAvailable[number];
    }

    public void release(int number) {
        // 仅在号码已被分配时释放，避免重复加入队列
        if (!isAvailable[number]) {
            isAvailable[number] = true;
            queue.offer(number);
        }
    }
}
```

### 方法二：HashSet + 队列

```java
import java.util.*;

class PhoneDirectory {
    private Set<Integer> available; // 可用号码集合
    private Queue<Integer> queue;   // 可用号码队列

    public PhoneDirectory(int maxNumbers) {
        available = new HashSet<>();
        queue = new LinkedList<>();
        for (int i = 0; i < maxNumbers; i++) {
            available.add(i);
            queue.offer(i);
        }
    }

    public int get() {
        if (queue.isEmpty()) return -1;
        int number = queue.poll();
        available.remove(number); // 从集合中移除
        return number;
    }

    public boolean check(int number) {
        return available.contains(number);
    }

    public void release(int number) {
        if (!available.contains(number)) {
            available.add(number);
            queue.offer(number);
        }
    }
}
```

### 方法三：只用 HashSet（简化版）

```java
import java.util.*;

class PhoneDirectory {
    private Set<Integer> available;

    public PhoneDirectory(int maxNumbers) {
        available = new HashSet<>();
        for (int i = 0; i < maxNumbers; i++) {
            available.add(i);
        }
    }

    public int get() {
        if (available.isEmpty()) return -1;
        // Iterator 获取第一个可用号码（HashSet 迭代顺序不确定，但 O(1)）
        int number = available.iterator().next();
        available.remove(number);
        return number;
    }

    public boolean check(int number) {
        return available.contains(number);
    }

    public void release(int number) {
        available.add(number);
    }
}
```

### 方法四：位图（进阶，节省空间）

```java
class PhoneDirectory {
    private int maxNumbers;
    private int[] bitmap;    // 位图，每个 int 存储 32 个号码的状态
    private int nextCheck;   // 下一个可能可用的位置

    public PhoneDirectory(int maxNumbers) {
        this.maxNumbers = maxNumbers;
        // 向上取整：(maxNumbers + 31) / 32 个 int
        bitmap = new int[(maxNumbers + 31) / 32];
        // 初始全为 -1（即 0xFFFFFFFF，全位为 1 表示可用）
        java.util.Arrays.fill(bitmap, -1);
        nextCheck = 0;
    }

    public int get() {
        // 从 nextCheck 开始查找可用号码
        for (int i = nextCheck; i < maxNumbers; i++) {
            if (isAvailable(i)) {
                setUnavailable(i);
                nextCheck = i + 1;
                return i;
            }
        }
        // 从头再找一遍（处理 release 导致前面有空位）
        for (int i = 0; i < nextCheck; i++) {
            if (isAvailable(i)) {
                setUnavailable(i);
                return i;
            }
        }
        return -1;
    }

    public boolean check(int number) {
        return isAvailable(number);
    }

    public void release(int number) {
        if (!isAvailable(number)) {
            setAvailable(number);
            if (number < nextCheck) nextCheck = number;
        }
    }

    private boolean isAvailable(int number) {
        // 检查位图中对应位是否为 1
        int idx = number / 32;
        int bit = number % 32;
        return (bitmap[idx] & (1 << bit)) != 0;
    }

    private void setUnavailable(int number) {
        // 将对应位设为 0
        int idx = number / 32;
        int bit = number % 32;
        bitmap[idx] &= ~(1 << bit);
    }

    private void setAvailable(int number) {
        // 将对应位设为 1
        int idx = number / 32;
        int bit = number % 32;
        bitmap[idx] |= (1 << bit);
    }
}
```

## 复杂度分析

### 方法一/二：布尔数组/HashSet + 队列
- 构造函数：O(n) 时间，O(n) 空间
- `get`：O(1) 时间
- `check`：O(1) 时间
- `release`：O(1) 时间
- 空间复杂度：O(n)

### 方法三：只用 HashSet
- 时间复杂度：所有操作 O(1)（均摊）
- 空间复杂度：O(n)

### 方法四：位图
- 时间复杂度：
  - `get`：最坏 O(n)，平均 O(1)
  - `check`：O(1)
  - `release`：O(1)
- 空间复杂度：O(n/32)，节省约 32 倍空间

## 关键点总结

1. **数据结构选择**：
   - 布尔数组：快速检查，O(1)
   - 队列：快速获取下一个可用号码，O(1)
   - 位图：节省空间
2. **操作效率**：所有操作都应该是 O(1)
3. **释放检查**：释放前要检查号码是否已被分配，避免重复加入队列
4. **空间优化**：位图可以大幅减少空间占用
5. **边界处理**：没有可用号码时返回 -1

## 易错点

1. **重复释放**：释放已经可用的号码，要避免重复加入队列（方法一通过 `!isAvailable[number]` 判断）
2. **越界检查**：虽然题目保证输入合法，但实际应用中要检查
3. **初始化**：确保所有号码初始都是可用的
4. **HashSet 迭代**：`iterator().next()` 顺序不确定，不保证返回最小号码
5. **位图边界**：位图大小要正确计算，`(maxNumbers + 31) / 32`
