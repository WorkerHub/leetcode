## 题目描述

给你一棵 n 个节点的有根树（根节点为 0），每条边有权重。每个节点最多选一条连向子节点的边，且若选了某条子边，该子节点不能再选其子边。返回选中边权重之和的最大值。

## 解题思路

树形 DP：对每个节点 v，定义 `dp[v][0]` 为不被父边选中时 v 子树的最大分数，`dp[v][1]` 为被父边选中时的最大分数（此时 v 不能选任何子边）。转移时枚举选哪条子边，取使收益最大的一条。

## Java 代码实现

```java
class Solution {
    private List<int[]>[] children; // children[v] = list of {child, weight}
    private long[][] dp;

    @SuppressWarnings("unchecked")
    public long maxScore(int[][] edges) {
        int n = edges.length + 1;
        children = new List[n];
        for (int i = 0; i < n; i++) children[i] = new ArrayList<>();
        for (int[] e : edges) {
            children[e[0]].add(new int[]{e[1], e[2]});
        }
        dp = new long[n][2];
        dfs(0);
        return dp[0][0];
    }

    private void dfs(int v) {
        long base = 0;      // 不选任何子边时子树总分
        long bestGain = 0;  // 选一条子边的最大额外收益
        for (int[] uw : children[v]) {
            int u = uw[0], w = uw[1];
            dfs(u);
            base += dp[u][0];
            // 选 (v,u) 边比不选多出的收益
            long gain = w + dp[u][1] - dp[u][0];
            if (gain > bestGain) bestGain = gain;
        }
        dp[v][0] = base + bestGain; // 不被父边选：可选一条子边
        dp[v][1] = base;            // 被父边选：不能选任何子边
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `dp[v][0]`：v 不被父边选中时可从子边中选一条，取额外收益最大的。
2. `dp[v][1]`：v 被父边选中时不能选子边，贡献为各子树的 `dp[u][0]` 之和。
3. 额外收益 `gain = w + dp[u][1] - dp[u][0]`，只有 gain > 0 才值得选。
