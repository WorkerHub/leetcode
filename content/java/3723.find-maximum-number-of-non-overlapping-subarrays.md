## 题目描述

给定整数数组 `nums` 和整数 `k`，找出最多有多少个不重叠的子数组，使得每个子数组的元素之和恰好等于 `k`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxNonOverlapping(int[] nums, int k) {
        // 贪心 + 前缀和哈希：pre_map[前缀和] = 对应位置的最优 dp 值
        Map<Long, Integer> preMap = new HashMap<>();
        preMap.put(0L, 0);
        long preSum = 0;
        int dp = 0; // 当前最多不重叠子数组数

        for (int num : nums) {
            preSum += num;
            long target = preSum - k;
            if (preMap.containsKey(target)) {
                // 找到以当前位置结尾的和为 k 的子数组
                dp = Math.max(dp, preMap.get(target) + 1);
            }
            // 更新哈希表：记录当前前缀和对应的最优 dp 值
            preMap.merge(preSum, dp, Math::max);
        }

        return dp;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心策略：尽量早结束每个子数组，为后续留下更多空间
2. 前缀和将子数组和问题转化为两个前缀和之差
3. 哈希表记录"某前缀和对应的最优 DP 值"，一次遍历完成
