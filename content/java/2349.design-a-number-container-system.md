## 题目描述

设计数字容器系统，支持 `change(index, number)`（在指定索引填入数字，若已有则替换）和 `find(number)`（返回该数字的最小索引，不存在返回 -1）。

## 解题思路

维护两个映射：`idxToNum`（索引到数字）和 `numToHeap`（数字到最小堆，懒删除）。`change` 时直接将新索引加入堆；`find` 时弹出堆顶中已失效（索引对应数字已变更）的元素，返回有效堆顶。

## Java 代码实现

```java
import java.util.*;

class NumberContainers {
    private Map<Integer, Integer> idxToNum = new HashMap<>();
    private Map<Integer, PriorityQueue<Integer>> numToHeap = new HashMap<>();

    public void change(int index, int number) {
        idxToNum.put(index, number); // 更新索引到数字的映射
        numToHeap.computeIfAbsent(number, k -> new PriorityQueue<>()).offer(index);
        // 旧数字对应的堆不立即删除（懒删除）
    }

    public int find(int number) {
        PriorityQueue<Integer> heap = numToHeap.get(number);
        if (heap == null) return -1;
        // 弹出所有失效的堆顶（索引已被覆盖为其他数字）
        while (!heap.isEmpty() && idxToNum.getOrDefault(heap.peek(), -1) != number) {
            heap.poll();
        }
        return heap.isEmpty() ? -1 : heap.peek();
    }
}
```

## 复杂度分析

- **时间复杂度**：`change` O(log n)；`find` 均摊 O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 懒删除堆：`change` 不从旧堆中删除，`find` 时弹出已失效的堆顶。
2. 判断堆顶有效性：`idxToNum[heapTop] == number`。
3. 每个索引最多被加入堆的次数等于其被修改次数，总摊销 O(n log n)。
