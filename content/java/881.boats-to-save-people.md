## 题目描述

每艘船最多载两人，承重上限 limit。给定每人体重 people[i]，返回承载所有人所需的最小船数。

**示例：**
```
输入：people = [3,2,2,1], limit = 3
输出：3
```

## 解题思路

贪心 + 双指针：排序后最重和最轻尝试配对，能配就一起走，不能就最重的单独走。

## Java 代码实现

```java
class Solution {
    public int numRescueBoats(int[] people, int limit) {
        Arrays.sort(people);
        int left = 0, right = people.length - 1;
        int boats = 0;

        while (left <= right) {
            if (people[left] + people[right] <= limit) {
                left++;
            }
            right--;
            boats++;
        }
        return boats;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心策略**：最重配最轻
2. **双指针**：排序后两端向中间收缩
3. **每次必走一人**：right 总是递减
