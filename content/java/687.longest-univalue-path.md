## 题目描述

给定二叉树根节点，返回最长路径的长度（边数），路径中每个节点值相同。路径可以经过也可以不经过根节点。

**示例：**
```
输入：root = [5,4,5,1,1,5]
输出：2
```

## 解题思路

DFS：对每个节点计算向左和向右延伸的最长同值路径长度，全局答案为 左+右 的最大值，返回值为单侧最大值。

## Java 代码实现

```java
class Solution {
    private int maxLen = 0;

    public int longestUnivaluePath(TreeNode root) {
        dfs(root);
        return maxLen;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        int left = dfs(node.left);
        int right = dfs(node.right);

        int leftPath = 0, rightPath = 0;

        // 左孩子值相同，可以向左延伸
        if (node.left != null && node.left.val == node.val) {
            leftPath = left + 1;
        }
        // 右孩子值相同，可以向右延伸
        if (node.right != null && node.right.val == node.val) {
            rightPath = right + 1;
        }

        // 更新全局最大值（经过当前节点的路径）
        maxLen = Math.max(maxLen, leftPath + rightPath);

        // 返回单侧最长路径
        return Math.max(leftPath, rightPath);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **路径可转弯**：全局答案是左+右
2. **返回单侧**：向上返回只能选一侧
3. **值相同才延伸**：检查子节点值是否等于当前节点值
