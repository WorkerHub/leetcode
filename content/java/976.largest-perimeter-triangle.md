## 题目描述

给定正整数数组 nums，返回由其中三条边组成的面积不为零的三角形的最大周长。不能组成则返回 0。

**示例：**
```
输入：nums = [2,1,2]
输出：5
```

## 解题思路

排序 + 贪心：排序后从大到小检查相邻三个数，若满足 a + b > c 则构成三角形，返回周长。

## Java 代码实现

```java
class Solution {
    public int largestPerimeter(int[] nums) {
        Arrays.sort(nums);
        // 从后往前找第一组满足三角形条件的
        for (int i = nums.length - 3; i >= 0; i--) {
            if (nums[i] + nums[i + 1] > nums[i + 2]) {
                return nums[i] + nums[i + 1] + nums[i + 2];
            }
        }
        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **三角形条件**：排序后只需检查两小边之和 > 最大边
2. **贪心**：从大到小找到的第一组即为最大周长
3. **严格大于**：a + b > c，等号不构成三角形
