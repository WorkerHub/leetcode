## 题目描述

给你二叉树的根节点 `root`，返回其节点值自底向上的层序遍历。（即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：[[15,7],[9,20],[3]]
```

**示例 2：**

```
输入：root = [1]
输出：[[1]]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`

## 解题思路

这道题是二叉树层序遍历的变体，要求自底向上输出结果。核心思路有两种：

**方法一：正常层序遍历 + 反转结果**
1. 使用 BFS（广度优先搜索）进行正常的层序遍历
2. 将每一层的节点值收集到结果列表中
3. 最后将整个结果列表反转

**方法二：正常层序遍历 + 头部插入**
1. 使用 BFS 进行正常的层序遍历
2. 每遍历完一层，将该层结果插入到结果列表的开头
3. 这样就不需要最后反转

**BFS 层序遍历的标准模板**：
1. 使用队列存储节点
2. 每次处理当前队列中的所有节点（一层）
3. 将下一层的节点加入队列
4. 重复直到队列为空

## Java 代码实现

### 方法一：BFS + 反转结果（推荐）⭐

```java
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        // 边界情况：空树
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        // BFS 层序遍历
        while (!queue.isEmpty()) {
            int levelSize = queue.size();  // 当前层的节点数量
            List<Integer> levelValues = new ArrayList<>();  // 存储当前层的节点值

            // 遍历当前层的所有节点
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelValues.add(node.val);

                // 将下一层的节点加入队列
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            // 将当前层的结果加入到结果列表
            result.add(levelValues);
        }

        // 反转结果，实现自底向上
        Collections.reverse(result);
        return result;
    }
}
```

### 方法二：BFS + 头部插入

```java
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        LinkedList<List<Integer>> result = new LinkedList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> levelValues = new ArrayList<>();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelValues.add(node.val);

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            // 将当前层插入到结果列表的开头，实现自底向上
            result.addFirst(levelValues);
        }

        return result;
    }
}
```

### 方法三：DFS + 深度记录

```java
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, 0, result);
        // 反转结果，实现自底向上
        Collections.reverse(result);
        return result;
    }

    private void dfs(TreeNode node, int level, List<List<Integer>> result) {
        if (node == null) return;

        // 如果当前层级还没有对应的列表，就创建一个
        if (level >= result.size()) {
            result.add(new ArrayList<>());
        }

        // 将当前节点的值加入到对应层级的列表中
        result.get(level).add(node.val);

        // 递归遍历左右子树
        dfs(node.left, level + 1, result);
        dfs(node.right, level + 1, result);
    }
}
```

### 方法四：使用 ArrayDeque（双端队列优化）

```java
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        Deque<List<Integer>> resultDeque = new ArrayDeque<>();
        if (root == null) return new ArrayList<>();

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> levelValues = new ArrayList<>();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelValues.add(node.val);

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            // 使用 addFirst 在头部插入，避免反转
            resultDeque.addFirst(levelValues);
        }

        return new ArrayList<>(resultDeque);
    }
}
```

## 复杂度分析

### 方法一、二、四（BFS）

- **时间复杂度**：O(n)，其中 n 是树中的节点数。每个节点都会被访问一次。
- **空间复杂度**：O(n)，队列中最多会存储一层的节点，最坏情况下（完全二叉树）最后一层有 n/2 个节点。

### 方法三（DFS）

- **时间复杂度**：O(n)，每个节点都会被访问一次。
- **空间复杂度**：O(h)，其中 h 是树的高度，递归调用栈的深度。最坏情况下 h = n（退化成链表）。

## 关键点总结

1. **BFS 模板掌握**：层序遍历是 BFS 的经典应用，要掌握标准模板
2. **层级分离**：使用 `queue.size()` 来分离每一层
3. **反转技巧**：
   - 方法一：最后统一 `Collections.reverse(result)`
   - 方法二：使用 `LinkedList.addFirst()` 头插
   - 方法四：使用 `ArrayDeque.addFirst()` 头插
4. **DFS 也可行**：虽然层序遍历通常用 BFS，但 DFS 记录层级也能实现
5. **Java 数据结构**：`LinkedList` 支持 `addFirst`，`Collections.reverse` 可以反转列表

## 易错点

1. **层级分离错误**：忘记记录 `levelSize`，导致无法正确分离每一层
2. **空树处理**：要检查 `root` 是否为 `null`
3. **反转时机**：要在所有层遍历完成后再反转，不能边遍历边反转
4. **头插方式**：方法二使用 `LinkedList` 的 `addFirst()`，注意返回类型要声明为 `List`
5. **队列操作**：要使用 `poll()` 而不是 `pop()`，保证先进先出
