## 题目描述

`m x n` 网格，每格有挡板（`1` 左上到右下，`-1` 右上到左下）。`n` 颗球从顶部各列放入，返回每颗球落到底部哪一列，卡住则返回 -1。

## 解题思路

**逐球模拟：** 对每球逐行追踪：挡板为 `1` 时向右偏，若越界或右侧挡板为 `-1`（V形）则返回 -1；挡板为 `-1` 时向左偏，若越界或左侧挡板为 `1` 则返回 -1。

## Java 代码实现

```java
class Solution {
    public int[] findBall(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] result = new int[n];

        for (int startCol = 0; startCol < n; startCol++) {
            int col = startCol;
            for (int row = 0; row < m; row++) {
                if (grid[row][col] == 1) {
                    int next = col + 1;
                    // 越界或右侧挡板为 -1，形成 V 形
                    if (next >= n || grid[row][next] == -1) { col = -1; break; }
                    col = next;
                } else {
                    int next = col - 1;
                    // 越界或左侧挡板为 1，形成 V 形
                    if (next < 0 || grid[row][next] == 1) { col = -1; break; }
                    col = next;
                }
            }
            result[startCol] = col;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(n)

## 关键点总结

1. V 形陷阱：`1` 后跟 `-1`，或 `-1` 前是 `1`
2. 边界越界也算卡住
