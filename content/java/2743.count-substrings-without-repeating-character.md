## 题目描述

给你字符串 `s`，统计其中没有重复字符的非空子字符串的数目。

## Java 代码实现

```java
class Solution {
    public int numberOfSpecialSubstrings(String s) {
        int[] lastPos = new int[26];
        java.util.Arrays.fill(lastPos, -1);
        int left = 0, ans = 0;
        for (int right = 0; right < s.length(); right++) {
            int c = s.charAt(right) - 'a';
            // 若当前字符在窗口内出现过，移动左端到其上次位置+1
            if (lastPos[c] >= left) {
                left = lastPos[c] + 1;
            }
            lastPos[c] = right;
            // 以 right 结尾的无重复子串数量等于窗口长度
            ans += right - left + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集大小固定 26）

## 关键点总结

1. 每个 right 位置，以 right 结尾的合法子串数等于窗口长度
2. 记录上次位置，O(1) 移动左端
