## 题目描述

返回 `text` 中**不同非空**回声子字符串的数量。

字符串 `str` 是 `text` 的一个**子字符串**，需满足：

1. `str.length` 是**偶数**
2. 将 `str` 分成长度相同的两半，即 `str = str1 + str2`，且 `str1 == str2`

**示例 1：**

```
输入：text = "abcabcabc"
输出：3
解释：3 个回声子字符串为 "abcabc"、"bcabca"、"cabcab"
```

**示例 2：**

```
输入：text = "leetcodeleet"
输出：2
解释：2 个回声子字符串为 "leet" 和 "leetcodeleet"
```

**提示：**

- `1 <= text.length <= 2000`

## 解题思路

**什么是回声子字符串？**

形如 `str1 + str1` 的字符串，即由两个相同的子串拼接而成（长度至少为 2）。

字符串 `s` 的一个子串 `s[i..j]`，其长度为 `2L`，如果 `s[i..i+L-1] == s[i+L..j]`，则它是回声子字符串。

**方法一：暴力枚举 + 集合去重**

枚举所有偶数长度的子串，判断前后两半是否相等，用集合存储所有符合条件的不同子串。

**方法二：滚动哈希（Rabin-Karp）**

对于每个可能的"半长度" L，同时维护两个长度为 L 的滚动哈希窗口。

## Java 代码实现

### 方法一：暴力枚举（直观理解）

```java
import java.util.*;

class Solution {
    public int distinctEchoSubstrings(String text) {
        int n = text.length();
        Set<String> seen = new HashSet<>();
        
        // 枚举起始位置 i 和半长度 L
        for (int i = 0; i < n; i++) {
            for (int L = 1; i + 2 * L <= n; L++) {
                // 子串为 text[i : i + 2*L]，判断前后两半是否相等
                if (text.substring(i, i + L).equals(text.substring(i + L, i + 2 * L))) {
                    seen.add(text.substring(i, i + 2 * L));
                }
            }
        }
        
        return seen.size();
    }
}
```

### 方法二：滚动哈希（推荐，高效）

```java
import java.util.*;

class Solution {
    public int distinctEchoSubstrings(String text) {
        int n = text.length();
        long MOD = 1_000_000_007L;
        long BASE = 31L;
        
        Set<String> seen = new HashSet<>();
        
        // 对每个半长度 L 使用滚动哈希
        for (int L = 1; L <= n / 2; L++) {
            long power = 1L;
            for (int i = 0; i < L - 1; i++) power = power * BASE % MOD;
            
            // 计算初始窗口哈希
            long h1 = 0, h2 = 0;
            for (int i = 0; i < L; i++) {
                h1 = (h1 * BASE + (text.charAt(i) - 'a' + 1)) % MOD;
            }
            for (int i = L; i < 2 * L; i++) {
                h2 = (h2 * BASE + (text.charAt(i) - 'a' + 1)) % MOD;
            }
            
            // 滑动两个窗口
            for (int start = 0; start + 2 * L <= n; start++) {
                if (h1 == h2) {
                    // 哈希相等，再验证字符串（避免哈希碰撞）
                    if (text.substring(start, start + L).equals(
                            text.substring(start + L, start + 2 * L))) {
                        seen.add(text.substring(start, start + 2 * L));
                    }
                }
                
                if (start + 2 * L < n) {
                    // 更新第一个窗口：移除 text[start]，加入 text[start+L]
                    h1 = (h1 - (text.charAt(start) - 'a' + 1) * power % MOD + MOD) % MOD;
                    h1 = (h1 * BASE + (text.charAt(start + L) - 'a' + 1)) % MOD;
                    // 更新第二个窗口：移除 text[start+L]，加入 text[start+2L]
                    h2 = (h2 - (text.charAt(start + L) - 'a' + 1) * power % MOD + MOD) % MOD;
                    h2 = (h2 * BASE + (text.charAt(start + 2 * L) - 'a' + 1)) % MOD;
                }
            }
        }
        
        return seen.size();
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 暴力枚举 | O(n^3)（含字符串比较）| O(n^2) |
| 滚动哈希 | O(n^2) | O(n^2) |

空间复杂度 O(n^2) 来自 `seen` 集合中最多存储 O(n^2) 个子串。

## 关键点总结

1. 回声子串 = 两个相同子串拼接，长度必须为偶数
2. 使用集合自动去重，避免重复计数
3. 滚动哈希可将字符串比较降至 O(1)（近似），提高效率
4. Java 中字符串比较用 `equals()`，不能用 `==`

## 易错点

1. **字符串比较用集合存储**：即使不同位置的子串内容相同，也只计一次
2. **哈希碰撞**：滚动哈希时需要在哈希相等时再做字符串验证，避免误判
3. **滑动窗口的更新**：两个窗口要同时向右滑动，步进为 1
4. **取模运算中的负数**：Java 中 `%` 对负数结果可能为负，需加 MOD 后再取模
