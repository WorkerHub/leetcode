## 题目描述

给你 `m x n` 矩阵 `grid`，返回同大小答案矩阵：`answer[r][c]` = 左上对角线不同值数 - 右下对角线不同值数（均不含 `(r,c)` 本身）的绝对值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[][] differenceOfDistinctValues(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] answer = new int[m][n];

        // 按对角线处理（同一对角线 r - c 相同）
        for (int diag = -(m - 1); diag < n; diag++) {
            List<int[]> cells = new ArrayList<>();
            for (int r = 0; r < m; r++) {
                int c = r - diag;
                if (c >= 0 && c < n) cells.add(new int[]{r, c});
            }

            int sz = cells.size();
            // 前缀不同值数
            int[] prefixSize = new int[sz];
            Set<Integer> prefix = new HashSet<>();
            for (int k = 0; k < sz; k++) {
                prefixSize[k] = prefix.size();
                prefix.add(grid[cells.get(k)[0]][cells.get(k)[1]]);
            }
            // 后缀不同值数
            int[] suffixSize = new int[sz];
            Set<Integer> suffix = new HashSet<>();
            for (int k = sz - 1; k >= 0; k--) {
                suffixSize[k] = suffix.size();
                suffix.add(grid[cells.get(k)[0]][cells.get(k)[1]]);
            }

            for (int k = 0; k < sz; k++) {
                int r = cells.get(k)[0], c = cells.get(k)[1];
                answer[r][c] = Math.abs(prefixSize[k] - suffixSize[k]);
            }
        }
        return answer;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(min(m, n))

## 关键点总结

1. 同一对角线上所有格子的 `r - c` 值相同
2. 利用前缀和后缀集合，每条对角线只需两次遍历
