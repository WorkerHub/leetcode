## 题目描述

每次只能删首尾元素，求删除最小值和最大值的最少操作次数。

## 解题思路

三种策略取最小：1)都从左删；2)都从右删；3)一左一右。设两目标位置lo≤hi。

## Java 代码实现

```java
class Solution {
    public int minimumDeletions(int[] nums) {
        int n = nums.length;
        int minIdx = 0, maxIdx = 0;
        for (int i = 1; i < n; i++) {
            if (nums[i] < nums[minIdx]) minIdx = i;
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }
        int lo = Math.min(minIdx, maxIdx);
        int hi = Math.max(minIdx, maxIdx);
        
        // 三种策略
        int opt1 = hi + 1;              // 都从左删
        int opt2 = n - lo;              // 都从右删
        int opt3 = (lo + 1) + (n - hi); // 一左一右
        
        return Math.min(opt1, Math.min(opt2, opt3));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **三种策略**：全左、全右、一左一右
2. **归一化位置**：lo = min(两目标), hi = max(两目标)
3. **公式**：opt3 = (lo+1) + (n-hi)
