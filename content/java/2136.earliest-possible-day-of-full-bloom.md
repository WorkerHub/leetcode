## 题目描述

n朵花各需plantTime天种植和growTime天生长，每天只能种一朵。求所有花都开放的最早日期。

## 解题思路

贪心：按growTime降序排列，优先种生长时间最长的花。开花时间=种植结束天数+生长时间，取所有花的最大开花时间。

## Java 代码实现

```java
class Solution {
    public int earliestFullBloom(int[] plantTime, int[] growTime) {
        int n = plantTime.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        // 按growTime降序排列
        Arrays.sort(idx, (a, b) -> growTime[b] - growTime[a]);
        
        int ans = 0, currentDay = 0;
        for (int i : idx) {
            currentDay += plantTime[i];
            ans = Math.max(ans, currentDay + growTime[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **按growTime降序**：优先种生长时间长的花
2. **开花时间**：种植结束天数 + 生长时间
3. **答案取最大值**：所有花开花时间的最大值
