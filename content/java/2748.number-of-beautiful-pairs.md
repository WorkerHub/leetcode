## 题目描述

给你整数数组 `nums`，如果 `nums[i]` 的首位数字与 `nums[j]` 的末位数字互质（`i < j`），则 `(i, j)` 为美丽数对，返回美丽数对总数目。

## Java 代码实现

```java
class Solution {
    public int countBeautifulPairs(int[] nums) {
        int n = nums.length, ans = 0;
        for (int i = 0; i < n; i++) {
            // 获取 nums[i] 的首位数字
            int firstI = nums[i];
            while (firstI >= 10) firstI /= 10;
            for (int j = i + 1; j < n; j++) {
                // 获取 nums[j] 的末位数字
                int lastJ = nums[j] % 10;
                if (gcd(firstI, lastJ) == 1) ans++;
            }
        }
        return ans;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，gcd 为常数时间
- 空间复杂度：O(1)

## 关键点总结

1. 首位数字：反复整除 10 直到小于 10
2. 末位数字：`num % 10`
3. 互质：`gcd(a, b) == 1`
