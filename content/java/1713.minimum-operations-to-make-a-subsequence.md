## 题目描述

数组 `target`（元素互不相同）和 `arr`，每次可在 `arr` 任意位置插入整数，返回使 `target` 成为 `arr` 子序列的最少操作数。

## 解题思路

最少插入数 = `target.length - LCS(target, arr)`。由于 target 元素唯一，将 arr 中属于 target 的元素替换为其在 target 中的下标，求该序列的 LIS 即等价于 LCS。用贪心 + 二分 O(n log n) 求 LIS。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] target, int[] arr) {
        // target 元素映射到下标
        Map<Integer, Integer> pos = new HashMap<>();
        for (int i = 0; i < target.length; i++) pos.put(target[i], i);

        // arr 中属于 target 的元素转为对应下标
        List<Integer> nums = new ArrayList<>();
        for (int x : arr) {
            if (pos.containsKey(x)) nums.add(pos.get(x));
        }

        // 贪心 + 二分求 LIS
        List<Integer> tails = new ArrayList<>();
        for (int x : nums) {
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails.get(mid) < x) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) tails.add(x);
            else tails.set(lo, x);
        }
        return target.length - tails.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O((m + n) log m)
- **空间复杂度**：O(m + n)

## 关键点总结

1. 最少插入 = target 长度 - LCS 长度
2. target 元素唯一，LCS 等价于映射后的 LIS
3. 贪心 + 二分求 LIS，时间 O(n log n)
