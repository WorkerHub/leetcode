## 题目描述

给定字符串 `s` 和 `p`，返回 `s` 中所有 `p` 的字母异位词的起始下标列表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        int n = s.length(), m = p.length();
        if (m > n) return result;

        int[] pCount = new int[26];
        int[] window = new int[26];
        for (char c : p.toCharArray()) pCount[c - 'a']++;
        for (int i = 0; i < m; i++) window[s.charAt(i) - 'a']++;

        if (Arrays.equals(window, pCount)) result.add(0);

        for (int i = m; i < n; i++) {
            window[s.charAt(i) - 'a']++;           // 加入新字符
            window[s.charAt(i - m) - 'a']--;        // 移除旧字符
            if (Arrays.equals(window, pCount)) result.add(i - m + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，滑动窗口每步比较 26 个字符频率
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 固定窗口大小为 `p.length()`，滑动时加入新字符并移除旧字符
2. 用长度 26 的数组代替哈希表，`Arrays.equals` 比较是否为异位词
3. 初始化第一个窗口，再从位置 `m` 开始滑动
