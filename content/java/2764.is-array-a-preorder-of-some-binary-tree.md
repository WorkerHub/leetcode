## 题目描述

给你树节点数组 `nodes`（`nodes[i] = [id, parentId]`）和整数数组 `order`，判断 `order` 是否是该树的某种前序遍历结果。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] order;
    private int idx;
    private Map<Integer, List<Integer>> children;
    private boolean valid;

    public boolean isPreorder(int[][] nodes, int[] order) {
        this.order = order;
        this.idx = 0;
        this.valid = true;
        children = new HashMap<>();
        int root = -1;
        for (int[] node : nodes) {
            children.putIfAbsent(node[0], new ArrayList<>());
            if (node[1] == -1) root = node[0];
            else children.computeIfAbsent(node[1], k -> new ArrayList<>()).add(node[0]);
        }
        dfs(root);
        return valid && idx == order.length;
    }

    private void dfs(int node) {
        if (!valid) return;
        if (idx >= order.length || order[idx] != node) { valid = false; return; }
        idx++;
        // 贪心地按 order 顺序访问子节点
        Set<Integer> childSet = new HashSet<>(children.getOrDefault(node, new ArrayList<>()));
        while (!childSet.isEmpty()) {
            if (idx >= order.length || !childSet.contains(order[idx])) break;
            int nextChild = order[idx];
            childSet.remove(nextChild);
            dfs(nextChild);
        }
        if (!childSet.isEmpty()) valid = false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 构建树的邻接表，找到根节点
2. 递归 DFS 前序遍历，逐一比对 order 数组
3. 贪心按 order 顺序决定子节点访问次序
