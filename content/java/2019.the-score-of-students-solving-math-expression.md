## 题目描述

给定含一位数字和 +/* 运算符的数学表达式字符串 `s`，以及学生答案数组 `answers`。正确答案得 5 分，可通过加括号得到的结果得 2 分，其他 0 分，返回总分。

## 解题思路

用区间 DP 计算表达式所有可能的括号方案结果集合：`dp[i][j]` 为第 i 到第 j 个数字通过各种括号得到的所有可能值（限制 <= 1000）。正确答案用栈计算（先乘后加），查询每个学生答案对应分数。

## Java 代码实现

### 方法一：区间 DP（推荐）

```java
import java.util.*;

class Solution {
    public int scoreOfStudents(String s, int[] answers) {
        // 解析数字和运算符
        List<Integer> nums = new ArrayList<>();
        List<Character> ops = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            if (i % 2 == 0) nums.add(s.charAt(i) - '0');
            else ops.add(s.charAt(i));
        }

        int n = nums.size();
        final int LIMIT = 1000;

        // dp[i][j] = 第i到j个数字通过各种括号得到的所有可能值
        @SuppressWarnings("unchecked")
        Set<Integer>[][] dp = new HashSet[n][n];
        for (int i = 0; i < n; i++) {
            dp[i][i] = new HashSet<>();
            dp[i][i].add(nums.get(i));
        }

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = new HashSet<>();
                for (int k = i; k < j; k++) {
                    char op = ops.get(k);
                    for (int a : dp[i][k]) {
                        for (int b : dp[k+1][j]) {
                            int val = (op == '+') ? a + b : a * b;
                            if (val <= LIMIT) dp[i][j].add(val);
                        }
                    }
                }
            }
        }

        // 计算正确答案（用栈先乘后加）
        int correct = evalExpression(s);
        Set<Integer> possible = dp[0][n-1];

        int total = 0;
        for (int ans : answers) {
            if (ans == correct) total += 5;
            else if (possible.contains(ans)) total += 2;
        }
        return total;
    }

    private int evalExpression(String s) {
        // 用栈计算正确答案（先乘后加）
        Deque<Integer> stack = new ArrayDeque<>();
        int i = 0;
        while (i < s.length()) {
            char c = s.charAt(i);
            if (Character.isDigit(c)) {
                int num = c - '0';
                if (!stack.isEmpty() && stack.peek() == -1) {
                    stack.pop(); // 弹出乘号标记
                    stack.push(stack.pop() * num);
                } else {
                    stack.push(num);
                }
            } else if (c == '*') {
                stack.push(-1); // 用-1标记乘号
            }
            // +号不做处理，数字入栈后自然求和
            i++;
        }
        int result = 0;
        for (int v : stack) if (v != -1) result += v;
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3 * V^2)，n 为操作数个数，V = 1000
- 空间复杂度：O(n^2 * V)

## 关键点总结

1. 区间 DP 计算所有可能的括号方案结果，限制 <= 1000 防止集合爆炸
2. 正确答案和加括号得到的答案互斥：正确答案得 5 分不再得 2 分
3. `dp[i][j]` 包含正确答案值，查询时需先判断是否为正确答案
