## 题目描述

给定整数数组 `nums`，统计满足 `a < b < c < d` 且 `nums[a] * nums[d] == nums[b] * nums[c]` 的四元组数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countSpecialSubsequences(int[] nums) {
        int n = nums.length;
        long count = 0;

        // 枚举中间对 (b, c)
        for (int b = 1; b < n - 2; b++) {
            // 统计左边 [0, b-1] 各值出现次数
            Map<Integer, Integer> left = new HashMap<>();
            for (int a = 0; a < b; a++) {
                left.merge(nums[a], 1, Integer::sum);
            }

            for (int c = b + 1; c < n - 1; c++) {
                long product = (long) nums[b] * nums[c];

                // 统计右边 [c+1, n-1] 各值出现次数
                Map<Integer, Integer> right = new HashMap<>();
                for (int d = c + 1; d < n; d++) {
                    right.merge(nums[d], 1, Integer::sum);
                }

                // 枚举 nums[a] 的可能值
                for (Map.Entry<Integer, Integer> e : left.entrySet()) {
                    int va = e.getKey();
                    if (product % va == 0) {
                        long vd = product / va;
                        if (vd <= Integer.MAX_VALUE) {
                            count += (long) e.getValue() * right.getOrDefault((int) vd, 0);
                        }
                    }
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)，枚举 (b,c) 对后再遍历哈希表
- 空间复杂度：O(n)

## 关键点总结

1. `nums[a] * nums[d] == nums[b] * nums[c]` 是等比关系。
2. 固定中间对 (b,c) 后，利用哈希表统计左右两侧计数。
3. 整除检查 `product % va == 0` 保证 vd 为整数，注意使用 `long` 防溢出。
