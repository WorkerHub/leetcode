## 题目描述

给你字符串 s，返回每个字符最多出现 2 次的最长子字符串的长度。

## 解题思路

滑动窗口：维护窗口内每个字符的频率，当某字符超过 2 次时收缩左边界，记录最大窗口长度。

## Java 代码实现

```java
class Solution {
    public int maximumLengthSubstring(String s) {
        int[] freq = new int[26];
        int left = 0, ans = 0;
        for (int right = 0; right < s.length(); right++) {
            freq[s.charAt(right) - 'a']++;
            // 若当前字符超过 2 次，收缩左边界
            while (freq[s.charAt(right) - 'a'] > 2) {
                freq[s.charAt(left) - 'a']--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个字符最多进出窗口一次
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 滑动窗口维护"每字符最多 2 次"的约束
2. 当某字符超过 2 次时移动左边界直到满足约束
3. 窗口大小的最大值即为答案
