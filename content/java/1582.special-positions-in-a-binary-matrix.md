## 题目描述

二进制矩阵中 mat[i][j]==1 且所在行列只有一个 1 的位置称为特殊位置。返回特殊位置数目。

**示例：**
```
输入：mat = [[1,0,0],[0,0,1],[1,0,0]]
输出：1
```

## 解题思路

预计算每行每列的 1 的数量，遍历所有 1 的位置检查行列和是否都为 1。

## Java 代码实现

```java
class Solution {
    public int numSpecial(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[] rowSum = new int[m];
        int[] colSum = new int[n];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (mat[i][j] == 1) { rowSum[i]++; colSum[j]++; }
        
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (mat[i][j] == 1 && rowSum[i] == 1 && colSum[j] == 1)
                    ans++;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N)
- **空间复杂度**：O(M + N)

## 关键点总结

1. **行列和**：预计算后 O(1) 判断
2. **特殊条件**：mat[i][j]==1 且 rowSum[i]==1 且 colSum[j]==1
