## 题目描述

将字符串 `s` 的每个字母转换为 1-26 的数字拼接成整数，然后对各位数字求和，重复 `k` 次，返回最终结果。

## 解题思路

直接模拟：先构建数字字符串，对每一位求和（第一次），后续 k-1 次对整数各位求和。

## Java 代码实现

```java
class Solution {
    public int getLucky(String s, int k) {
        // 构建数字字符串并第一次求和
        int result = 0;
        for (char c : s.toCharArray()) {
            int num = c - 'a' + 1; // 转为 1-26
            result += num / 10 + num % 10; // 注意 10-26 是两位数
        }
        // 后续 k-1 次各位数字求和
        for (int i = 1; i < k; i++) {
            int tmp = 0;
            while (result > 0) {
                tmp += result % 10;
                result /= 10;
            }
            result = tmp;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + k)
- **空间复杂度**：O(1)

## 关键点总结

1. 字母转数字 `c - 'a' + 1`（a=1, z=26）
2. 10-26 为两位数，需拆分为十位和个位分别加
3. 第一次处理字符串，后续处理整数各位
