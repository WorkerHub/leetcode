## 题目描述

按饮食计划评估得分：每连续 k 天的卡路里总和 T，T < lower 得 -1 分，T > upper 得 +1 分，否则 0 分。返回总得分。

**示例：**
```
输入: calories = [1,2,3,4,5], k = 1, lower = 3, upper = 3
输出: 0（-1-1+0+1+1=0）
```

## 解题思路

固定大小 k 的滑动窗口，维护窗口和并逐个评分。

## Java 代码实现

```java
class Solution {
    public int dietPlanPerformance(int[] calories, int k, int lower, int upper) {
        int n = calories.length;
        int points = 0;

        // 第一个窗口
        int windowSum = 0;
        for (int i = 0; i < k; i++) windowSum += calories[i];
        if (windowSum < lower) points--;
        else if (windowSum > upper) points++;

        // 滑动窗口
        for (int i = k; i < n; i++) {
            windowSum += calories[i] - calories[i - k];
            if (windowSum < lower) points--;
            else if (windowSum > upper) points++;
        }
        return points;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **固定窗口大小 k**：每次滑动减旧加新
2. **三种评分**：< lower 扣分，> upper 加分，否则不变
3. **窗口数量**：共 n-k+1 个窗口
