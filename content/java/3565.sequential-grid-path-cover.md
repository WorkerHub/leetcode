## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`（是 1 到 m*n 的排列），按顺序访问值为 1, 2, 3, ..., m*n 的格子，每次移动只能走到四连通相邻格子。判断是否存在这样一条路径。

## 解题思路

只需检查相邻值（v 和 v+1）对应的格子是否四连通相邻（曼哈顿距离为 1）。找到每个值对应的位置，依次验证即可。

## Java 代码实现

```java
class Solution {
    public boolean isPathCover(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int k = m * n;
        // 找每个值对应的位置
        int[] row = new int[k + 1], col = new int[k + 1];
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++) {
                row[grid[r][c]] = r;
                col[grid[r][c]] = c;
            }

        // 检查相邻值是否在相邻格子（曼哈顿距离为 1）
        for (int v = 1; v < k; v++) {
            if (Math.abs(row[v] - row[v+1]) + Math.abs(col[v] - col[v+1]) != 1)
                return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历所有格子
- 空间复杂度：O(m * n)，位置数组

## 关键点总结

1. 只需检查相邻值（v 和 v+1）的格子是否四连通相邻
2. 曼哈顿距离为 1 表示相邻
3. 路径唯一确定，只需验证相邻性
