## 题目描述

给你小写英文字母字符串 `s`，"反向度"定义为每个字符的反向值（a->26, b->25, ..., z->1）与其 1-indexed 位置的乘积之和，返回该值。

## 解题思路

直接模拟：对每个字符计算反向值 `26 - (c - 'a')`，乘以位置 `(i+1)`，累加求和。

## Java 代码实现

```java
class Solution {
    public int reverseDegree(String s) {
        int total = 0;
        for (int i = 0; i < s.length(); i++) {
            int reverseVal = 26 - (s.charAt(i) - 'a'); // a->26, z->1
            total += reverseVal * (i + 1);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 反向值公式：`26 - (c - 'a')`，a 对应 26，z 对应 1
2. 位置从 1 开始（1-indexed），即 `(i + 1)`
3. 求所有（反向值 * 位置）的累加和
