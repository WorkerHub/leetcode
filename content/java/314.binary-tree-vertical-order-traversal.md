## 题目描述

给你一个二叉树的根结点 `root`，请你设计算法计算二叉树的**垂序遍历**序列。

对位于 `(row, col)` 的每个结点而言，其左右子结点分别位于 `(row + 1, col - 1)` 和 `(row + 1, col + 1)` 。树的根结点位于 `(0, 0)` 。

二叉树的**垂序遍历**从最左边的列开始直到最右边的列结束，按列索引每一列上的所有结点，形成一个按出现位置从上到下排序的有序列表。如果同行同列上有多个结点，则按结点的值从小到大进行排序。

返回二叉树的**垂序遍历**序列。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/01/28/vtree1.jpg)

```
输入：root = [3,9,20,null,null,15,7]
输出：[[9],[3,15],[20],[7]]
解释：
列 -1：只有结点 9
列 0：只有结点 3 和 15，按从上到下顺序
列 1：只有结点 20
列 2：只有结点 7
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/28/vtree2.jpg)

```
输入：root = [1,2,3,4,5,6,7]
输出：[[4],[2],[1,5,6],[3],[7]]
解释：
列 -2：只有结点 4
列 -1：只有结点 2
列 0：结点 1、5 和 6，按从上到下顺序
列 1：只有结点 3
列 2：只有结点 7
```

**提示：**
- 树中结点数目总数在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

### 核心概念

- **列号（column）**：根节点列号为 0，左子树列号 -1，右子树列号 +1
- **行号（row）**：根节点行号为 0，子节点行号 +1

### 方法对比

| 方法 | 特点 | 是否需要排序 |
|------|------|-------------|
| BFS | 自然保证从上到下 | 不需要按行排序 |
| DFS | 需要记录行号 | 需要按行排序 |

## Java 代码实现

### 方法一：BFS（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // 哈希表存储每一列的节点值
        Map<Integer, List<Integer>> columnTable = new HashMap<>();

        // BFS 队列：[节点, 列号]
        Queue<int[]> nodeQueue = new ArrayDeque<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        nodeQueue.offer(new int[]{0});

        // 用另一种方式：将节点和列号一起存储
        // 使用自定义封装
        Deque<Object[]> bfsQueue = new ArrayDeque<>();
        bfsQueue.offer(new Object[]{root, 0});

        int minCol = 0, maxCol = 0;

        while (!bfsQueue.isEmpty()) {
            Object[] pair = bfsQueue.poll();
            TreeNode node = (TreeNode) pair[0];
            int col = (int) pair[1];

            // 记录当前列的节点值
            columnTable.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);
            minCol = Math.min(minCol, col);
            maxCol = Math.max(maxCol, col);

            // 左子树：列号 -1
            if (node.left != null) {
                bfsQueue.offer(new Object[]{node.left, col - 1});
            }
            // 右子树：列号 +1
            if (node.right != null) {
                bfsQueue.offer(new Object[]{node.right, col + 1});
            }
        }

        // 按列号从小到大返回结果
        for (int col = minCol; col <= maxCol; col++) {
            result.add(columnTable.get(col));
        }

        return result;
    }
}
```

### 方法二：DFS + 排序

```java
import java.util.*;

class Solution {
    // 哈希表：{列号: [(行号, 节点值)]}
    private Map<Integer, List<int[]>> columnTable = new HashMap<>();

    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        dfs(root, 0, 0);

        // 按列号排序
        List<Integer> sortedCols = new ArrayList<>(columnTable.keySet());
        Collections.sort(sortedCols);

        for (int col : sortedCols) {
            List<int[]> colNodes = columnTable.get(col);
            // 按行号排序
            colNodes.sort((a, b) -> a[0] - b[0]);

            List<Integer> colVals = new ArrayList<>();
            for (int[] node : colNodes) {
                colVals.add(node[1]);
            }
            result.add(colVals);
        }

        return result;
    }

    private void dfs(TreeNode node, int row, int col) {
        if (node == null) return;

        // 记录节点的行号和值
        columnTable.computeIfAbsent(col, k -> new ArrayList<>()).add(new int[]{row, node.val});

        // 递归左右子树
        dfs(node.left, row + 1, col - 1);
        dfs(node.right, row + 1, col + 1);
    }
}
```

### 方法三：BFS + 记录范围

```java
import java.util.*;

class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // 使用哈希表存储每一列
        Map<Integer, List<Integer>> columnDict = new HashMap<>();
        int minCol = 0, maxCol = 0;

        // BFS 队列，存储 [节点, 列号]
        Deque<Object[]> queue = new ArrayDeque<>();
        queue.offer(new Object[]{root, 0});

        while (!queue.isEmpty()) {
            Object[] pair = queue.poll();
            TreeNode node = (TreeNode) pair[0];
            int col = (int) pair[1];

            // 更新列范围
            minCol = Math.min(minCol, col);
            maxCol = Math.max(maxCol, col);

            // 记录节点
            columnDict.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);

            if (node.left != null) queue.offer(new Object[]{node.left, col - 1});
            if (node.right != null) queue.offer(new Object[]{node.right, col + 1});
        }

        // 按列号顺序返回
        for (int col = minCol; col <= maxCol; col++) {
            result.add(columnDict.get(col));
        }

        return result;
    }
}
```

### 方法四：带详细注释的版本

```java
import java.util.*;

class Solution {
    /**
     * 二叉树垂序遍历（BFS 方法）
     *
     * 核心思想：
     * 1. 使用 BFS 遍历二叉树
     * 2. 为每个节点分配列号
     * 3. 按列号分组，BFS 自动保证同列内从上到下
     *
     * 为什么用 BFS？
     * - BFS 天然按层遍历，保证从上到下的顺序
     * - 不需要额外记录行号和排序
     */
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();

        // 空树直接返回
        if (root == null) return result;

        // 使用哈希表存储每一列的节点值
        // key: 列号, value: 节点值列表
        Map<Integer, List<Integer>> columnTable = new HashMap<>();

        // BFS 队列，每个元素是 [节点, 列号]
        Deque<Object[]> queue = new ArrayDeque<>();
        queue.offer(new Object[]{root, 0});

        int minCol = 0, maxCol = 0;

        // BFS 遍历
        while (!queue.isEmpty()) {
            Object[] pair = queue.poll();
            TreeNode node = (TreeNode) pair[0];
            int col = (int) pair[1];

            // 将节点值加入对应的列
            columnTable.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);

            // 更新列的范围
            minCol = Math.min(minCol, col);
            maxCol = Math.max(maxCol, col);

            // 左子节点：列号 -1
            if (node.left != null) {
                queue.offer(new Object[]{node.left, col - 1});
            }

            // 右子节点：列号 +1
            if (node.right != null) {
                queue.offer(new Object[]{node.right, col + 1});
            }
        }

        // 按列号从小到大排序，返回结果
        for (int col = minCol; col <= maxCol; col++) {
            result.add(columnTable.get(col));
        }

        return result;
    }
}
```

## 复杂度分析

**BFS 方法：**
- 时间复杂度：O(n log n)，n 是节点数，排序列号需要 O(k log k)，k 是列数
- 空间复杂度：O(n)，队列和哈希表的空间

**DFS 方法：**
- 时间复杂度：O(n log n)，需要对每一列排序
- 空间复杂度：O(n)，递归栈和哈希表的空间

## 关键点总结

1. **列号计算**：左子树 -1，右子树 +1
2. **BFS vs DFS**：
   - BFS：自然保证从上到下
   - DFS：需要记录行号并排序
3. **使用 HashMap**：简化代码，不需要检查键是否存在
4. **排序**：最后按列号排序
5. **空树处理**：返回空列表

## 易错点

1. **忘记排序**：列号可能是负数，要按从小到大排序
2. **BFS vs DFS**：DFS 需要额外排序，容易遗漏
3. **列号范围**：可能是负数，不能用数组索引
4. **空树**：要特殊处理
5. **同列节点顺序**：BFS 自动保证，DFS 需要按行号排序
