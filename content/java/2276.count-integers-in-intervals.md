## 题目描述

设计数据结构支持添加区间和查询所有区间合并后覆盖的整数总数。

## 解题思路

用TreeMap维护不重叠区间（按左端点排序）。每次add时找到所有重叠区间并合并，实时维护总覆盖数。

## Java 代码实现

```java
class CountIntervals {
    private TreeMap<Integer, Integer> map; // left -> right
    private int total;

    public CountIntervals() {
        map = new TreeMap<>();
        total = 0;
    }

    public void add(int left, int right) {
        // 找所有与[left, right]重叠的区间
        Integer lo = map.floorKey(right);
        while (lo != null && map.get(lo) >= left) {
            int r = map.get(lo);
            left = Math.min(left, lo);
            right = Math.max(right, r);
            total -= r - lo + 1;
            map.remove(lo);
            lo = map.floorKey(right);
        }
        // 检查左边可能重叠的
        lo = map.floorKey(left);
        if (lo != null && map.get(lo) >= left) {
            right = Math.max(right, map.get(lo));
            total -= map.get(lo) - lo + 1;
            left = lo;
            map.remove(lo);
        }
        map.put(left, right);
        total += right - left + 1;
    }

    public int count() {
        return total;
    }
}
```

## 复杂度分析

- **add**：均摊O(log N)
- **count**：O(1)

## 关键点总结

1. **TreeMap维护不重叠区间**：按左端点排序
2. **合并重叠区间**：floorKey找可能重叠的区间
3. **实时维护total**：add时增减覆盖数
