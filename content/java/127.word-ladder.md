## 题目描述

字典 `wordList` 中从单词 `beginWord` 到 `endWord` 的转换序列是一个按下述规格形成的序列 `beginWord -> s1 -> s2 -> ... -> sk`：

- 每一对相邻的单词只差一个字母
- 对于 `1 <= i <= k` 时，每个 `si` 都在 `wordList` 中。注意，`beginWord` 不需要在 `wordList` 中
- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord` 和一个字典 `wordList`，返回从 `beginWord` 到 `endWord` 的**最短转换序列**中的**单词数目**。如果不存在这样的转换序列，返回 `0`。

**示例 1：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出: 5
解释: 一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog", 返回它的长度 5。
```

**示例 2：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出: 0
解释: endWord "cog" 不在字典中，所以无法进行转换。
```

**提示：**
- `1 <= beginWord.length <= 10`
- `endWord.length == beginWord.length`
- `1 <= wordList.length <= 5000`
- `wordList[i].length == beginWord.length`
- `beginWord`、`endWord` 和 `wordList[i]` 由小写英文字母组成
- `beginWord != endWord`
- `wordList` 中的所有字符串互不相同

## 解题思路

这是一道典型的**无权图最短路径问题**，适合用 **BFS（广度优先搜索）** 解决。

### 核心思想：

1. **建图**：每个单词是一个节点，只差一个字母的两个单词之间有一条边
2. **BFS 搜索**：从 `beginWord` 开始，层层扩展，直到找到 `endWord`
3. **返回层数**：第一次遇到 `endWord` 时的层数就是最短路径长度

### 算法步骤：

1. 先检查 `endWord` 是否在字典中，不在则直接返回 0
2. 将 `beginWord` 加入队列，开始 BFS
3. 对于当前单词，尝试改变每个位置的字符（a-z），查看是否在字典中
4. 如果在字典中且未访问过，加入队列并标记为已访问
5. 如果遇到 `endWord`，返回当前步数
6. 如果队列为空还没找到，返回 0

### 优化技巧：

- **使用集合存储字典**：O(1) 时间查找
- **双向 BFS**：从两端同时搜索，减少搜索空间
- **预处理通配符模式**：建立中间状态映射，加速邻居查找

## Java 代码实现

### 方法一：BFS + 逐字符替换（推荐）

```java
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);

        // endWord 必须在字典中
        if (!wordSet.contains(endWord)) return 0;

        // BFS 队列
        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        Set<String> visited = new HashSet<>();
        visited.add(beginWord);
        int steps = 1;  // beginWord 算第 1 个单词

        while (!queue.isEmpty()) {
            int levelSize = queue.size();

            for (int i = 0; i < levelSize; i++) {
                String word = queue.poll();
                char[] wordChars = word.toCharArray();

                // 尝试改变每个位置的字符
                for (int j = 0; j < wordChars.length; j++) {
                    char original = wordChars[j];

                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;
                        wordChars[j] = c;
                        String nextWord = new String(wordChars);

                        // 找到目标单词
                        if (nextWord.equals(endWord)) return steps + 1;

                        // 新单词在字典中且未访问过
                        if (wordSet.contains(nextWord) && !visited.contains(nextWord)) {
                            visited.add(nextWord);
                            queue.offer(nextWord);
                        }

                        wordChars[j] = original;
                    }
                }
            }

            steps++;
        }

        return 0;
    }
}
```

### 方法二：双向 BFS（优化版）

```java
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        if (!wordSet.contains(endWord)) return 0;

        // 双向 BFS 的两个集合
        Set<String> beginSet = new HashSet<>();
        Set<String> endSet = new HashSet<>();
        beginSet.add(beginWord);
        endSet.add(endWord);

        Set<String> visited = new HashSet<>();
        int steps = 1;
        int wordLen = beginWord.length();

        while (!beginSet.isEmpty() && !endSet.isEmpty()) {
            // 优化：总是从小的一端开始搜索
            if (beginSet.size() > endSet.size()) {
                Set<String> tmp = beginSet;
                beginSet = endSet;
                endSet = tmp;
            }

            // 下一层的单词集合
            Set<String> nextSet = new HashSet<>();

            for (String word : beginSet) {
                char[] wordChars = word.toCharArray();

                for (int i = 0; i < wordLen; i++) {
                    char original = wordChars[i];

                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;
                        wordChars[i] = c;
                        String nextWord = new String(wordChars);

                        // 两端相遇
                        if (endSet.contains(nextWord)) return steps + 1;

                        // 有效的未访问单词
                        if (wordSet.contains(nextWord) && !visited.contains(nextWord)) {
                            visited.add(nextWord);
                            nextSet.add(nextWord);
                        }

                        wordChars[i] = original;
                    }
                }
            }

            // 移动到下一层
            beginSet = nextSet;
            steps++;
        }

        return 0;
    }
}
```

### 方法三：预处理通配符模式

```java
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        if (!wordList.contains(endWord)) return 0;

        // 预处理：建立通配符模式到单词的映射
        // 例如: "hot" -> "*ot", "h*t", "ho*"
        Map<String, List<String>> patternDict = new HashMap<>();
        int wordLen = beginWord.length();

        for (String word : wordList) {
            for (int i = 0; i < wordLen; i++) {
                String pattern = word.substring(0, i) + '*' + word.substring(i + 1);
                patternDict.computeIfAbsent(pattern, k -> new ArrayList<>()).add(word);
            }
        }

        // BFS
        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        Set<String> visited = new HashSet<>();
        visited.add(beginWord);
        int steps = 1;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();

            for (int i = 0; i < levelSize; i++) {
                String word = queue.poll();

                // 通过通配符模式找到所有邻居
                for (int j = 0; j < wordLen; j++) {
                    String pattern = word.substring(0, j) + '*' + word.substring(j + 1);
                    List<String> neighbors = patternDict.getOrDefault(pattern, new ArrayList<>());

                    for (String nextWord : neighbors) {
                        if (nextWord.equals(endWord)) return steps + 1;

                        if (!visited.contains(nextWord)) {
                            visited.add(nextWord);
                            queue.offer(nextWord);
                        }
                    }

                    // 清空已遍历的模式，避免重复访问
                    patternDict.put(pattern, new ArrayList<>());
                }
            }

            steps++;
        }

        return 0;
    }
}
```

### 方法四：简化版（容易理解）

```java
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        if (!wordSet.contains(endWord)) return 0;

        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        Set<String> visited = new HashSet<>();
        visited.add(beginWord);
        int level = 1;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();

            for (int k = 0; k < levelSize; k++) {
                String current = queue.poll();

                // 遍历字典中所有单词，找只差一个字母的邻居
                for (String word : new ArrayList<>(wordSet)) {
                    if (isAdjacent(current, word)) {
                        if (word.equals(endWord)) return level + 1;

                        queue.offer(word);
                        visited.add(word);
                        wordSet.remove(word);  // 从字典中移除已访问的词
                    }
                }
            }

            level++;
        }

        return 0;
    }

    // 判断两个单词是否只差一个字母
    private boolean isAdjacent(String word1, String word2) {
        int diffCount = 0;
        for (int i = 0; i < word1.length(); i++) {
            if (word1.charAt(i) != word2.charAt(i)) {
                diffCount++;
                if (diffCount > 1) return false;
            }
        }
        return diffCount == 1;
    }
}
```

## 复杂度分析

设单词长度为 L，字典大小为 N。

### 方法一：BFS + 逐字符替换
- **时间复杂度**：O(N * L * 26) = O(N * L)
  - 每个单词访问一次，每次尝试 L 个位置 * 26 个字母
- **空间复杂度**：O(N)，队列和访问集合

### 方法二：双向 BFS
- **时间复杂度**：O(N * L)，但实际运行更快
- **空间复杂度**：O(N)

### 方法三：预处理通配符
- **时间复杂度**：O(N * L)，预处理 O(N * L)，查询 O(L)
- **空间复杂度**：O(N * L)，存储模式映射

### 方法四：简化版
- **时间复杂度**：O(N^2 * L)，每个单词与所有其他单词比较
- **空间复杂度**：O(N)

## 关键点总结

1. **BFS 适合无权图最短路径**：每条边权重相同，BFS 第一次到达即最短
2. **使用集合优化查找**：`HashSet` 提供 O(1) 的查找时间
3. **标记已访问避免重复**：防止循环和重复搜索
4. **双向 BFS 优化**：从两端搜索可显著减少搜索空间
5. **字符数组替换技巧**：先转 `char[]`，修改后再 `new String(chars)` 构造新单词

## 易错点

1. **忘记检查 endWord 是否在字典中**
   ```java
   // 必须先检查
   if (!wordSet.contains(endWord)) return 0;
   ```

2. **返回值错误**
   ```java
   // 错误：返回步数而不是单词数
   return steps;

   // 正确：返回单词数（步数 + 1 包含 beginWord）
   return steps + 1;
   ```

3. **重复访问问题**
   ```java
   // 必须标记已访问，防止重复
   visited.add(nextWord);
   ```

4. **Java 字符串不可变性**
   ```java
   // 错误：字符串不可直接修改字符
   // s.charAt(i) = 'c';  // 编译错误

   // 正确：先转 char 数组，修改后再构造字符串
   char[] chars = word.toCharArray();
   chars[i] = c;
   String nextWord = new String(chars);
   ```

5. **beginWord 不在字典中**：题目说明 beginWord 可以不在字典中，不需要检查
