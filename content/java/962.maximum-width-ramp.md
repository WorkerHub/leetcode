## 题目描述

给定数组 nums，找到满足 i < j 且 nums[i] <= nums[j] 的最大宽度 j - i。

**示例：**
```
输入：nums = [6,0,8,2,1,5]
输出：4（i=1, j=5, nums[1]=0 <= nums[5]=5）
```

## 解题思路

单调栈：第一遍从左到右构建单调递减栈（可能的左端点），第二遍从右到左遍历弹出栈并更新最大宽度。

## Java 代码实现

```java
class Solution {
    public int maxWidthRamp(int[] nums) {
        int n = nums.length;
        Deque<Integer> stack = new ArrayDeque<>();

        // 构建单调递减栈（存索引）
        for (int i = 0; i < n; i++) {
            if (stack.isEmpty() || nums[i] < nums[stack.peek()]) {
                stack.push(i);
            }
        }

        int maxWidth = 0;
        // 从右向左遍历，弹出满足条件的左端点
        for (int j = n - 1; j >= 0; j--) {
            while (!stack.isEmpty() && nums[stack.peek()] <= nums[j]) {
                maxWidth = Math.max(maxWidth, j - stack.pop());
            }
        }

        return maxWidth;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **单调递减栈**：只保留可能成为最优左端点的索引
2. **逆序遍历**：从右到左找最大宽度
3. **弹出更新**：弹出时计算宽度
