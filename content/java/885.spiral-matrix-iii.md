## 题目描述

从 (rStart, cStart) 开始顺时针螺旋行走，按访问顺序返回 rows×cols 网格中所有位置的坐标。

**示例：**
```
输入：rows = 1, cols = 4, rStart = 0, cStart = 0
输出：[[0,0],[0,1],[0,2],[0,3]]
```

## 解题思路

模拟螺旋路径：方向按东→南→西→北循环，步数规律为 1,1,2,2,3,3,...

## Java 代码实现

```java
class Solution {
    public int[][] spiralMatrixIII(int rows, int cols, int rStart, int cStart) {
        int[][] result = new int[rows * cols][2];
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}; // 东南西北
        int idx = 0, r = rStart, c = cStart;
        result[idx++] = new int[]{r, c};

        int steps = 1, di = 0;
        while (idx < rows * cols) {
            for (int t = 0; t < 2; t++) { // 每个步长走两个方向
                for (int i = 0; i < steps; i++) {
                    r += dirs[di][0];
                    c += dirs[di][1];
                    if (r >= 0 && r < rows && c >= 0 && c < cols) {
                        result[idx++] = new int[]{r, c};
                    }
                }
                di = (di + 1) % 4;
            }
            steps++;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(rows, cols)²)
- **空间复杂度**：O(rows × cols)

## 关键点总结

1. **步数规律**：每两次转弯步数加 1
2. **方向循环**：东南西北四方向
3. **边界检查**：只记录网格内的位置
