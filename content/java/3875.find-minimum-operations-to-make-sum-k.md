## 题目描述

给你一个整数数组 `nums` 和目标值 `k`，每次操作可以对任意元素加 1 或减 1。返回使数组总和等于 `k` 所需的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        long sum = 0;
        // 求数组总和
        for (int x : nums) {
            sum += x;
        }
        // 最少操作次数等于当前总和与目标之差的绝对值
        return (int) Math.abs(sum - k);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，求和
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作改变总和 1（加 1 或减 1），最少操作次数 = 差的绝对值。
2. `Math.abs(sum - k)` 是最简洁的表达。
3. 可以对任意元素操作，不限制特定元素。
