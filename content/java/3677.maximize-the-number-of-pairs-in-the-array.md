## 题目描述

给你一个整数数组 `nums`，每次操作可以选择两个相等的元素配对并移除。返回最多可以配对的对数。

## 解题思路

统计每个元素的出现次数，每个元素可以配 `freq[v] / 2` 对，累加所有元素的配对数即为答案。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maximumPairs(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) freq.merge(x, 1, Integer::sum);
        int ans = 0;
        for (int v : freq.values()) ans += v / 2;
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每种元素独立配对，频率除以 2 取整即为配对数
2. 不同元素不能配对
