## 题目描述

给你粉笔消耗数组 `chalk` 和粉笔总量 `k`，学生从 0 开始轮流消耗粉笔，返回第一个粉笔不足时的学生编号。

## 解题思路

先用 `k %= total` 去掉完整轮次，再在前缀和数组中二分查找第一个前缀和超过 k 的位置即为答案。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int chalkReplacer(int[] chalk, int k) {
        int n = chalk.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + chalk[i];
        }
        // 去掉完整轮次（注意 total 可能超 int）
        long rem = k % prefix[n];

        // 二分查找第一个前缀和 > rem 的位置
        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (prefix[mid + 1] > rem) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + log n)
- **空间复杂度**：O(n)，前缀和数组

## 关键点总结

1. 先用 `k %= total` 去掉完整轮次，避免超时
2. 用前缀和 + 二分查找定位第一个不够粉笔的学生
3. total 可能超过 int 范围，使用 long
