## 题目描述

给你 n 个路口和道路数组，从 0 出发以最短时间到达 n-1，返回所有最短时间路径的数量 mod 10^9+7。

## 解题思路

Dijkstra + 路径计数：松弛时更新 `ways[v] = ways[u]`（发现更短路），或 `ways[v] += ways[u]`（发现等长路）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPaths(int n, int[][] roads) {
        final long MOD = 1_000_000_007;
        List<long[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] r : roads) {
            graph[r[0]].add(new long[]{r[1], r[2]});
            graph[r[1]].add(new long[]{r[0], r[2]});
        }

        long[] dist = new long[n];
        long[] ways = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE / 2);
        dist[0] = 0; ways[0] = 1;

        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0]; int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (long[] e : graph[u]) {
                int v = (int) e[0]; long newDist = d + e[1];
                if (newDist < dist[v]) {
                    dist[v] = newDist; ways[v] = ways[u];
                    pq.offer(new long[]{newDist, v});
                } else if (newDist == dist[v]) {
                    ways[v] = (ways[v] + ways[u]) % MOD;
                }
            }
        }
        return (int) ways[n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + e) log n)
- **空间复杂度**：O(n + e)

## 关键点总结

1. Dijkstra 同时维护到达每个节点的最短路径数
2. 发现更短路：`ways[v] = ways[u]`；等长路：`ways[v] += ways[u]`
3. 跳过过时状态（`d > dist[u]`）
