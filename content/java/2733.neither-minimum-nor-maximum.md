## 题目描述

给你包含不同正整数的数组 `nums`，返回既不是最小值也不是最大值的任意一个数，不存在则返回 `-1`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int findNonMinOrMax(int[] nums) {
        if (nums.length < 3) return -1;
        // 排序后第二个既非最小也非最大
        Arrays.sort(nums);
        return nums[1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 长度小于 3 时不可能存在满足条件的数
2. 只需找一个介于最小值和最大值之间的数
