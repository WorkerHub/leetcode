## 题目描述

从城市 start 出发，每次可去任意城市（消耗燃油=距离），求到达 finish 的所有路径数（可多次经过 finish）。对 10^9+7 取模。

**提示：** locations.length ≤ 100, fuel ≤ 200

## 解题思路

记忆化搜索：dp[cur][fuel] = 在城市 cur、剩余 fuel 时到达 finish 的路径数。每到 finish 贡献 1。

## Java 代码实现

```java
class Solution {
    private int MOD = 1_000_000_007;
    private int[][] memo;
    private int[] locations;
    private int finish;
    
    public int countRoutes(int[] locations, int start, int finish, int fuel) {
        this.locations = locations;
        this.finish = finish;
        int n = locations.length;
        memo = new int[n][fuel + 1];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dp(start, fuel);
    }
    
    private int dp(int cur, int fuel) {
        if (memo[cur][fuel] != -1) return memo[cur][fuel];
        long result = cur == finish ? 1 : 0;
        for (int nxt = 0; nxt < locations.length; nxt++) {
            if (nxt == cur) continue;
            int cost = Math.abs(locations[cur] - locations[nxt]);
            if (fuel >= cost) {
                result = (result + dp(nxt, fuel - cost)) % MOD;
            }
        }
        memo[cur][fuel] = (int)result;
        return (int)result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N² × Fuel)
- **空间复杂度**：O(N × Fuel)

## 关键点总结

1. **状态**：(当前城市, 剩余燃油)
2. **到 finish 就贡献 1**：不停止，可继续走
3. **记忆化**：避免重复计算
