## 题目描述

找二进制字符串中最长的平衡子串（所有0在1前面，且0和1数量相等）。

## 解题思路

分段统计：扫描连续的0段和紧接的1段，取min(zeros,ones)*2。

## Java 代码实现

```java
class Solution {
    public int findTheLongestBalancedSubstring(String s) {
        int n = s.length(), ans = 0, i = 0;
        while (i < n) {
            int zeros = 0, ones = 0;
            while (i < n && s.charAt(i) == '0') { zeros++; i++; }
            while (i < n && s.charAt(i) == '1') { ones++; i++; }
            ans = Math.max(ans, Math.min(zeros, ones) * 2);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **平衡子串形如000...111...**：0全在1前面
2. **取min(zeros,ones)*2**：有效平衡部分
3. **线性扫描**：统计连续段
