## 题目描述

在二维网格中每步代价为曼哈顿距离，另有特殊道路可以固定代价从一点到另一点，返回从起点到终点的最小代价。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumCost(int[] start, int[] target, int[][] specialRoads) {
        int sx = start[0], sy = start[1];
        int tx = target[0], ty = target[1];

        // Dijkstra：节点为坐标，边为曼哈顿距离或特殊路代价
        // 用 (dist, x, y) 的最小堆
        Map<Long, Integer> dist = new HashMap<>();
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        long startKey = encode(sx, sy);
        dist.put(startKey, 0);
        pq.offer(new long[]{0, sx, sy});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int d = (int) cur[0], x = (int) cur[1], y = (int) cur[2];
            long key = encode(x, y);
            if (d > dist.getOrDefault(key, Integer.MAX_VALUE)) continue;

            // 直接走到终点
            int toTarget = d + Math.abs(x - tx) + Math.abs(y - ty);
            long targetKey = encode(tx, ty);
            if (toTarget < dist.getOrDefault(targetKey, Integer.MAX_VALUE)) {
                dist.put(targetKey, toTarget);
                pq.offer(new long[]{toTarget, tx, ty});
            }

            // 使用特殊路
            for (int[] road : specialRoads) {
                int x1 = road[0], y1 = road[1], x2 = road[2], y2 = road[3], cost = road[4];
                int nd = d + Math.abs(x - x1) + Math.abs(y - y1) + cost;
                long nk = encode(x2, y2);
                if (nd < dist.getOrDefault(nk, Integer.MAX_VALUE)) {
                    dist.put(nk, nd);
                    pq.offer(new long[]{nd, x2, y2});
                }
            }
        }
        return dist.getOrDefault(encode(tx, ty),
               Math.abs(sx - tx) + Math.abs(sy - ty));
    }

    private long encode(int x, int y) {
        return (long) x * 100001 + y;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 log n)，n 为特殊路数量
- 空间复杂度：O(n)

## 关键点总结

1. Dijkstra：从每个已到达的点尝试使用各条特殊路
2. 终点可以从任意点走曼哈顿距离直达
3. 坐标编码为 long 类型作为哈希键
