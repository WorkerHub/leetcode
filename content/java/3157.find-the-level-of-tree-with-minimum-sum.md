## 题目描述

给你一棵二叉树，找出节点值之和最小的层，返回该层的层编号（根节点为第 1 层，若多层和相同取层号最小的）。

## 解题思路

BFS 层序遍历，逐层累加节点值，用严格小于更新最小和及对应层号。

## Java 代码实现

```java
class Solution {
    public int minimumLevel(TreeNode root) {
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int level = 1, minLevel = 1;
        long minSum = Long.MAX_VALUE;

        while (!queue.isEmpty()) {
            int size = queue.size();
            long layerSum = 0;
            // 处理当前层所有节点
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                layerSum += node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            // 严格小于才更新，保证层号最小
            if (layerSum < minSum) {
                minSum = layerSum;
                minLevel = level;
            }
            level++;
        }
        return minLevel;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，BFS 队列

## 关键点总结

1. BFS 天然按层处理，逐层求和
2. 用严格小于（`<`）更新，保证返回层号最小的层
3. 节点值可能为负，层和用 `long` 防溢出
