## 题目描述

整数数组 `nums`（至多 50 种不同值），`m` 个顾客（`m <= 10`）每人需要 `quantity[i]` 个**相同**整数。判断能否同时满足所有顾客。

## 解题思路

**状态压缩 DP：** m <= 10，用 `dp[mask]` 表示能否满足 mask 中顾客的子集。

预计算每个子集的总需求，枚举每种整数数量，更新可达的子集。

## Java 代码实现

```java
class Solution {
    public boolean canDistribute(int[] nums, int[] quantity) {
        int m = quantity.length;

        // 统计每种整数的数量
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int x : nums) freqMap.merge(x, 1, Integer::sum);
        int[] counts = freqMap.values().stream().mapToInt(Integer::intValue).toArray();
        Arrays.sort(counts); // 升序，倒序遍历

        // 预计算每个子集的总需求
        int[] subsetSum = new int[1 << m];
        for (int mask = 1; mask < (1 << m); mask++) {
            int lsb = Integer.numberOfTrailingZeros(mask);
            subsetSum[mask] = subsetSum[mask ^ (1 << lsb)] + quantity[lsb];
        }

        // dp[mask] = 能否满足 mask 中所有顾客
        boolean[] dp = new boolean[1 << m];
        dp[0] = true;

        for (int cnt : counts) {
            // 从大到小遍历，避免同一种整数被多次使用
            for (int mask = (1 << m) - 2; mask >= 0; mask--) {
                if (!dp[mask]) continue;
                int complement = ((1 << m) - 1) ^ mask;
                // 枚举补集的所有子集 sub
                for (int sub = complement; sub > 0; sub = (sub - 1) & complement) {
                    if (subsetSum[sub] <= cnt) {
                        dp[mask | sub] = true;
                    }
                }
            }
        }

        return dp[(1 << m) - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * 3^m)，k 为不同值数量（最多 50），m <= 10
- **空间复杂度**：O(2^m)

## 关键点总结

1. m <= 10，适合状态压缩 DP（2^10 = 1024）
2. 预处理子集总需求，避免重复计算
3. 枚举补集的子集：`sub = (sub-1) & complement`
4. 从大到小遍历 mask，避免同一整数被多次使用
