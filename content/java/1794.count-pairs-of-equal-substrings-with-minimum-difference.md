## 题目描述

给你两个不含重复字母的字符串 `firstString` 和 `secondString`，找出满足等值条件（两子串相等）且 `i - a` 最小的四元组 (i, j, a, b) 的数量。

## 解题思路

由于两字符串不含重复字母，每个字母最多出现一次。最优子串必为单字符。

对每个在两字符串中都出现的字母 c，计算 `pos1[c] - pos2[c]`，找最小差值并统计个数。

## Java 代码实现

```java
class Solution {
    public int countQuadruples(String firstString, String secondString) {
        int[] pos1 = new int[26];
        int[] pos2 = new int[26];
        Arrays.fill(pos1, -1);
        Arrays.fill(pos2, -1);

        for (int i = 0; i < firstString.length(); i++)
            pos1[firstString.charAt(i) - 'a'] = i;
        for (int i = 0; i < secondString.length(); i++)
            pos2[secondString.charAt(i) - 'a'] = i;

        int minDiff = Integer.MAX_VALUE;
        int count = 0;

        for (int c = 0; c < 26; c++) {
            if (pos1[c] == -1 || pos2[c] == -1) continue; // 不是公共字母
            int diff = pos1[c] - pos2[c];
            if (diff < minDiff) {
                minDiff = diff;
                count = 1;
            } else if (diff == minDiff) {
                count++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n、m 为两字符串长度
- **空间复杂度**：O(1)，字母表大小固定 26

## 关键点总结

1. 不含重复字母，每个字母在各字符串中最多出现一次
2. 最优子串为单字符，枚举 26 个公共字母求最小 `pos1-pos2`
