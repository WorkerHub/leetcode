## 题目描述

给定字符串 s，最多删除一个字符，判断是否能成为回文串。

**示例：**
```
输入：s = "abca"
输出：true（删除 'c' 得到 "aba"）
```

## 解题思路

双指针从两端向中间扫描，遇到不匹配时尝试跳过左边或右边，检查剩余部分是否回文。

## Java 代码实现

```java
class Solution {
    public boolean validPalindrome(String s) {
        int left = 0, right = s.length() - 1;

        while (left < right) {
            if (s.charAt(left) == s.charAt(right)) {
                left++;
                right--;
            } else {
                // 尝试删除左边或右边
                return isPalindrome(s, left + 1, right) || isPalindrome(s, left, right - 1);
            }
        }
        return true;
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针**：从两端向中间扫描
2. **贪心选择**：遇到不匹配时尝试两种删除方式
3. **最多一次**：只有一次删除机会，两种之一成功即可
