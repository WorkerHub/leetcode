## 题目描述

两种线程：氢和氧。设计同步机制使每次恰好 2 个氢线程和 1 个氧线程组合产生水分子 H2O。

**示例：**
```
输入：water = "HOH"
输出："HHO"
```

## 解题思路

信号量控制：h_sem 初始为 2 允许两个氢进入，氢完成后释放 o_sem 通知氧。氧等待两次 o_sem 后输出并重置。

## Java 代码实现

```java
class H2O {
    private Semaphore hSem = new Semaphore(2);
    private Semaphore oSem = new Semaphore(0);

    public H2O() {}

    public void hydrogen(Runnable releaseHydrogen) throws InterruptedException {
        hSem.acquire();
        releaseHydrogen.run();
        oSem.release(); // 通知氧：一个氢已就绪
    }

    public void oxygen(Runnable releaseOxygen) throws InterruptedException {
        oSem.acquire(); // 等待第一个氢
        oSem.acquire(); // 等待第二个氢
        releaseOxygen.run();
        hSem.release(2); // 允许下一组两个氢进入
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **h_sem=2**：最多允许 2 个氢同时进入
2. **o_sem acquire 两次**：确保 2 个氢就绪后氧才输出
3. **release(2)**：一次释放 2 个许可，重启下一轮
