## 题目描述

将中缀表达式字符串转换为二叉表达式树（非叶节点是运算符，叶节点是操作数）。

## 解题思路

双栈法：节点栈+运算符栈，遇到低优先级运算符时合并高优先级。括号内递归处理。

## Java 代码实现

```java
class Solution {
    public Node expTree(String s) {
        Deque<Node> nodes = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        
        for (char ch : s.toCharArray()) {
            if (ch == '(') {
                ops.push(ch);
            } else if (ch == ')') {
                // 合并到左括号
                while (ops.peek() != '(') {
                    combine(nodes, ops);
                }
                ops.pop(); // 弹出 '('
            } else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
                // 弹出优先级>=当前的运算符
                while (!ops.isEmpty() && ops.peek() != '(' && priority(ops.peek()) >= priority(ch)) {
                    combine(nodes, ops);
                }
                ops.push(ch);
            } else {
                // 操作数
                nodes.push(new Node(ch));
            }
        }
        
        // 处理剩余运算符
        while (!ops.isEmpty()) {
            combine(nodes, ops);
        }
        return nodes.pop();
    }
    
    private int priority(char op) {
        if (op == '*' || op == '/') return 2;
        return 1;
    }
    
    private void combine(Deque<Node> nodes, Deque<Character> ops) {
        char op = ops.pop();
        Node right = nodes.pop();
        Node left = nodes.pop();
        Node node = new Node(op, left, right);
        nodes.push(node);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **双栈法**：节点栈+运算符栈
2. **优先级规则**：`*/`高于`+-`，遇低弹高
3. **合并顺序**：先弹出的是右子树
