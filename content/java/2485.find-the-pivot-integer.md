## 题目描述

给你正整数 `n`，找出支点整数 `x`，使得 `1` 到 `x` 的总和等于 `x` 到 `n` 的总和，不存在则返回 `-1`。

## 解题思路

两端和相等意味着 `x² = n*(n+1)/2`，判断总和是否为完全平方数，是则返回其整数平方根，否则返回 -1。

## Java 代码实现

```java
class Solution {
    public int pivotInteger(int n) {
        int total = n * (n + 1) / 2;
        int x = (int) Math.sqrt(total);
        return x * x == total ? x : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 支点整数满足 `x² = n*(n+1)/2`
2. 用 `(int) Math.sqrt(total)` 取整数平方根，再验证是否完全平方
3. n <= 1000，总和最大约 500500，不会溢出 int
