## 题目描述

森林中若干兔子回答"还有多少只兔子与你颜色相同"，答案收集在数组 answers 中。返回森林中兔子的最少数量。

**示例：**
```
输入：answers = [1,1,2]
输出：5
```

## 解题思路

贪心分组：回答 x 的兔子一组最多 x+1 只。统计每个答案频率，向上取整计算组数。

## Java 代码实现

```java
class Solution {
    public int numRabbits(int[] answers) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int ans : answers) {
            count.merge(ans, 1, Integer::sum);
        }

        int result = 0;
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            int answer = entry.getKey();
            int freq = entry.getValue();
            int groupSize = answer + 1;
            // 向上取整计算组数
            int groups = (freq + groupSize - 1) / groupSize;
            result += groups * groupSize;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **分组策略**：回答 x 的兔子一组最多 x+1 只
2. **向上取整**：(freq + groupSize - 1) / groupSize
3. **贪心思想**：尽可能将同答案的兔子归为一组
