## 题目描述

给定一个正整数 `m`，你需要维护一个大小为 `m` 的排列 `perm`，初始值为 `[1, 2, 3, ..., m]`。

给出一个查询数组 `queries`，对每个查询 `queries[i]`：

1. 找到 `queries[i]` 在排列 `perm` 中的当前位置（0-indexed）
2. 把 `queries[i]` 移到排列的头部（位置 0）
3. 记录找到的位置

返回所有查询的结果数组。

**示例 1：**

```
输入：m = 3, queries = [3,1,2,1]
输出：[2,1,2,1]
解释：
初始排列：[1, 2, 3]
查询 3 → 位置 2，移到头部 → [3, 1, 2]
查询 1 → 位置 1，移到头部 → [1, 3, 2]
查询 2 → 位置 2，移到头部 → [2, 1, 3]
查询 1 → 位置 1，移到头部 → [1, 2, 3]
```

**示例 2：**

```
输入：m = 5, queries = [4,1,2,2]
输出：[3,1,2,0]
```

**提示：**

- `1 <= m <= 10^3`
- `1 <= queries.length <= m`
- `1 <= queries[i] <= m`

## 解题思路

### 方法一：直接模拟（推荐，m 较小时）

由于 `m <= 1000`，直接用列表模拟整个过程：

1. 初始化排列 `perm = [1, 2, ..., m]`
2. 对每个查询 `k`，找到其在 `perm` 中的位置
3. 删除该元素，插入到头部

Java 的 `ArrayList` 的 `indexOf()` 是 O(m)，`remove()` + `add(0, ...)` 也是 O(m)，整体 O(q * m)，对本题约束完全够用。

### 方法二：树状数组（BIT，适合大规模数据）

对于 `m` 很大的情况，可以用树状数组优化：

- 用树状数组维护一个大小为 `m + q` 的序列（前 `q` 位置为预留头部位置，后 `m` 位置为初始排列）
- 每次查询 `k`：用哈希表找到 `k` 当前所在的"绝对位置"，通过树状数组求前缀和得到相对位置（即排名）
- 把 `k` 从原位置删除，放到当前可用的最左预留位置

## Java 代码实现

### 方法一：直接模拟（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] processQueries(int[] queries, int m) {
        // 初始化排列 [1, 2, 3, ..., m]
        List<Integer> perm = new ArrayList<>();
        for (int i = 1; i <= m; i++) {
            perm.add(i);
        }

        int[] result = new int[queries.length];

        for (int idx = 0; idx < queries.length; idx++) {
            int k = queries[idx];
            // 找到 k 在当前排列中的位置
            int pos = perm.indexOf(k);
            result[idx] = pos;

            // 将 k 移到排列头部
            perm.remove(pos);
            perm.add(0, k);
        }

        return result;
    }
}
```

### 方法二：树状数组优化（适合大数据量）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    // 树状数组（Binary Indexed Tree），支持单点修改和前缀和查询
    private int[] tree;
    private int n;

    private void update(int i, int delta) {
        // 在位置 i 加上 delta（1-indexed）
        for (; i <= n; i += i & (-i)) {
            tree[i] += delta;
        }
    }

    private int query(int i) {
        // 求前缀和 [1, i]
        int s = 0;
        for (; i > 0; i -= i & (-i)) {
            s += tree[i];
        }
        return s;
    }

    public int[] processQueries(int[] queries, int m) {
        int q = queries.length;
        // 总长度：前 q 个位置预留给"移到头部"操作，后 m 个位置是初始排列
        n = q + m;
        tree = new int[n + 1];

        // 记录每个元素的当前绝对位置（1-indexed）
        Map<Integer, Integer> pos = new HashMap<>();
        for (int i = 1; i <= m; i++) {
            // 初始时元素 i 在绝对位置 q + i
            pos.put(i, q + i);
            update(q + i, 1);
        }

        // 下一个可用的头部位置（从 q 开始向左填充）
        int head = q;
        int[] result = new int[q];

        for (int idx = 0; idx < q; idx++) {
            int k = queries[idx];
            // k 的当前绝对位置（1-indexed）
            int curPos = pos.get(k);
            // 前缀和即为排列中的相对位置（0-indexed）
            int rank = query(curPos) - 1;
            result[idx] = rank;

            // 从原位置移除
            update(curPos, -1);

            // 放到新的头部位置
            pos.put(k, head);
            update(head, 1);
            head--;  // 下次再往左移一位
        }

        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 模拟 | O(q * m) | O(m) |
| 树状数组 | O((m + q) log(m + q)) | O(m + q) |

本题 `m <= 1000`，模拟完全够用。

## 关键点总结

1. 模拟思路直接，Java 的 `ArrayList.indexOf()` + `remove()` + `add(0, ...)` 即可解决
2. 树状数组方法的核心：用"绝对位置"到"相对排名"的映射，通过前缀和求排名
3. 树状数组预留头部位置的技巧：用前 `q` 个位置作为缓冲区
4. `i & (-i)` 是树状数组的核心操作，取最低位的 1

## 易错点

1. 位置是 0-indexed，而树状数组通常使用 1-indexed，注意转换
2. 模拟时 `remove` 和 `add` 的顺序：先找到位置并 `remove`，再 `add(0, k)`
3. 树状数组中，`head` 指针需要从 `q` 开始递减，不能重复使用
