## 题目描述

给你整数数组 `nums`，通过相邻交换使最小值（最左边）移到首位、最大值（最右边）移到末位，返回最少交换次数。

## 解题思路

贪心：最小值移到首位需 `minIdx` 次交换，最大值移到末位需 `n-1-maxIdx` 次交换。若最小值在最大值左边两者独立相加；若最小值在最大值右边，操作有一步重叠需减 1。

## Java 代码实现

```java
class Solution {
    public int minimumSwaps(int[] nums) {
        int n = nums.length;
        int minVal = Integer.MAX_VALUE, maxVal = Integer.MIN_VALUE;
        for (int x : nums) {
            minVal = Math.min(minVal, x);
            maxVal = Math.max(maxVal, x);
        }

        int minIdx = -1, maxIdx = -1;
        // 最小值取最左位置，最大值取最右位置
        for (int i = 0; i < n; i++) {
            if (nums[i] == minVal && minIdx == -1) minIdx = i;
            if (nums[i] == maxVal) maxIdx = i;
        }

        int cost = minIdx + (n - 1 - maxIdx);
        // 最小值在最大值右边：移动有一步重叠
        if (minIdx > maxIdx) cost--;
        return cost;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 最小值取最左位置，最大值取最右位置（题目要求）。
2. 两操作通常独立，当最小值在最大值右边时有一步重叠需减 1。
3. 移最大值到末尾会将最小值"带向左一步"（当最小值在其右边时）。
