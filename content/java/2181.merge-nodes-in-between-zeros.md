## 题目描述

链表由0分隔，将每两个相邻0之间的节点值求和合并为一个节点，返回不含0的新链表。

## 解题思路

遍历链表跳过开头的0，累加非零节点值，遇到0时将累加和作为新节点加入结果链表。

## Java 代码实现

```java
class Solution {
    public ListNode mergeNodes(ListNode head) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        ListNode cur = head.next; // 跳过开头的0
        int sum = 0;
        
        while (cur != null) {
            if (cur.val == 0) {
                // 遇到0，提交当前段和
                tail.next = new ListNode(sum);
                tail = tail.next;
                sum = 0;
            } else {
                sum += cur.val;
            }
            cur = cur.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)（不计输出）

## 关键点总结

1. **跳过头部的0**：从head.next开始遍历
2. **遇0提交累加和**：每个0标记一段的结束
3. **尾部0触发最后一段提交**
