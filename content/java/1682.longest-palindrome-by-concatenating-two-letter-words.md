## 题目描述

字符串数组 `words`，每个元素均为两字母单词。选择若干单词拼接，返回能构成的**最长回文串**的长度。

## 解题思路

**贪心 + 哈希表：** 将单词分两类：
- 自身是回文（如 "gg"）：两两放在两侧各贡献 4，若有奇数个可放一个在中心贡献 2
- 非回文（如 "lc"/"cl"）：与其翻转配对，每对贡献 4

## Java 代码实现

```java
class Solution {
    public int longestPalindrome(String[] words) {
        Map<String, Integer> count = new HashMap<>();
        for (String w : words) count.merge(w, 1, Integer::sum);

        int result = 0;
        boolean centerUsed = false;

        for (Map.Entry<String, Integer> e : count.entrySet()) {
            String w = e.getKey();
            int cnt = e.getValue();
            String rev = "" + w.charAt(1) + w.charAt(0);

            if (w.equals(rev)) {
                // 自身是回文词（如 "gg"）
                result += (cnt / 2) * 4;
                if (cnt % 2 == 1 && !centerUsed) {
                    result += 2;
                    centerUsed = true;
                }
            } else if (w.compareTo(rev) < 0) {
                // 非回文词，只处理 w < rev 的情况，避免重复统计
                int pairs = Math.min(cnt, count.getOrDefault(rev, 0));
                result += pairs * 4;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 自身回文词两两配对后，最多一个放在中心
2. 非回文词必须与翻转词配对，用 `w < rev` 避免重复统计
3. 每对贡献 4 个字符，中心贡献 2 个字符
