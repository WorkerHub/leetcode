## 题目描述

给你字符串 `s` 和整数 `k`。特殊子字符串指只包含一种字符的子串。从 `s` 中选取 k 个不相交的特殊子字符串，返回能选取的最大字符总数。不能选取 k 个则返回 -1。

## 解题思路

提取所有连续相同字符段，每段天然不相交。贪心：选最长的 k 段，总长度最大。若段数不足 k 则返回 -1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxSubstringLength(String s, int k) {
        int n = s.length();
        List<Integer> segments = new ArrayList<>();

        // 提取所有连续相同字符段的长度
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            segments.add(j - i);
            i = j;
        }

        if (segments.size() < k) return -1;

        // 贪心：选最长的 k 段
        segments.sort(Collections.reverseOrder());
        int total = 0;
        for (int idx = 0; idx < k; idx++) {
            total += segments.get(idx);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m log m)，m 为段数
- 空间复杂度：O(m)

## 关键点总结

1. 特殊子字符串 = 连续相同字符的段，天然不相交
2. 若段数 < k 则无法选取 k 个，返回 -1
3. 贪心选最长的 k 段，最大化字符总数
