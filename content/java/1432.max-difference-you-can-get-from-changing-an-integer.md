## 题目描述

给你一个整数 `num`。你可以对它进行如下操作：

- 选择 `num` 中某一位数字 `x`（`0 <= x <= 9`）。
- 选择另一个数字 `y`（`0 <= y <= 9`），将 `num` 中**所有** `x` 替换为 `y`。

注意替换后的数字不能有前导零（除非结果就是 0 本身），且不能是零（即不能让整数变为 0）。

你可以对 `num` 执行上述操作**两次**，第一次操作让 `num` 尽可能大（得到 `a`），第二次让 `num` 尽可能小（得到 `b`）。

返回 `a - b`。

**示例 1：**
```
输入：num = 555
输出：888
解释：
a = 999（将 5 替换为 9）
b = 111（将 5 替换为 1）
a - b = 888
```

**示例 2：**
```
输入：num = 9
输出：8
解释：
a = 9（已是最大）
b = 1（将 9 替换为 1）
a - b = 8
```

**示例 3：**
```
输入：num = 123456
输出：820000+...
解释：
a = 923456（将 1 替换为 9）
b = 103456（将 2 替换为 0）
```

**提示：**
- `1 <= num <= 10^8`

## 解题思路

**贪心策略：**

**求最大值 a（将某位替换为 9）：**
- 从左到右找第一个不是 `9` 的数字，将其全部替换为 `9`。
- 若所有位都是 `9`，则 `a = num`。

**求最小值 b（将某位替换为 0 或 1）：**
- 如果**首位不是 `1`**：将首位替换为 `1`，可以最小化（首位不能为 0，否则有前导零）。
- 如果**首位是 `1`**：从左到右找第一个不是 `0` 也不是 `1` 的数字，将其替换为 `0`。
- 若所有位都是 `0` 或 `1`，则无法减小，`b = num`。

## Java 代码实现

### 方法一：字符串替换（推荐）

```java
class Solution {
    public int maxDiff(int num) {
        String s = String.valueOf(num);

        // --- 求最大值 a ---
        // 找第一个非 9 的数字，替换为 9
        String a = s;
        for (char ch : s.toCharArray()) {
            if (ch != '9') {
                a = s.replace(ch, '9');
                break;
            }
        }

        // --- 求最小值 b ---
        String b = s;
        if (s.charAt(0) != '1') {
            // 首位不是 1：将首位替换为 1（不产生前导零）
            b = s.replace(s.charAt(0), '1');
        } else {
            // 首位是 1：找第一个非 0 非 1 的数字（从第二位开始），替换为 0
            for (int i = 1; i < s.length(); i++) {
                char ch = s.charAt(i);
                if (ch != '0' && ch != '1') {
                    b = s.replace(ch, '0');
                    break;
                }
            }
        }

        return Integer.parseInt(a) - Integer.parseInt(b);
    }
}
```

### 方法二：显式遍历（更清晰的逻辑）

```java
class Solution {
    public int maxDiff(int num) {
        char[] digits = String.valueOf(num).toCharArray();

        // --- 求最大值 a ---
        // 找第一个非 9 的位，全部替换为 9
        char replaceForMax = 0;
        for (char d : digits) {
            if (d != '9') {
                replaceForMax = d;
                break;
            }
        }

        char[] aDigits = digits.clone();
        if (replaceForMax != 0) {
            for (int i = 0; i < aDigits.length; i++) {
                if (aDigits[i] == replaceForMax) aDigits[i] = '9';
            }
        }

        // --- 求最小值 b ---
        char replaceForMin = 0;
        char replaceWith = 0;

        if (digits[0] != '1') {
            // 首位不是 1，将首位替换为 1
            replaceForMin = digits[0];
            replaceWith = '1';
        } else {
            // 首位是 1，找第一个非 0 非 1 的位（从第二位开始）
            for (int i = 1; i < digits.length; i++) {
                char d = digits[i];
                if (d != '0' && d != '1') {
                    replaceForMin = d;
                    replaceWith = '0';
                    break;
                }
            }
        }

        char[] bDigits = digits.clone();
        if (replaceForMin != 0) {
            for (int i = 0; i < bDigits.length; i++) {
                if (bDigits[i] == replaceForMin) bDigits[i] = replaceWith;
            }
        }

        int a = Integer.parseInt(new String(aDigits));
        int b = Integer.parseInt(new String(bDigits));
        return a - b;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(d)，d 为 `num` 的位数（最多 9 位），字符串替换操作 O(d)。
- **空间复杂度：** O(d)，存储字符串。

## 图解示例

```
num = 123456，s = "123456"

求最大值 a：
  第一个非 9 的字符是 '1'
  将所有 '1' 替换为 '9' -> "923456"
  a = 923456

求最小值 b：
  首位 '1' == '1'，进入第二个分支
  从第二位开始，找第一个非 0 非 1 的字符 -> '2'
  将所有 '2' 替换为 '0' -> "103456"
  b = 103456

a - b = 923456 - 103456 = 820000
```

## 关键点总结

1. 求最大值：找第一个不是 `9` 的位，全部改为 `9`（贪心，越高位越大）。
2. 求最小值：首位只能改为 `1`（不能有前导零）；非首位可以改为 `0`。
3. Java 的 `String.replace(char, char)` 会替换所有出现，刚好符合题意。
4. 如果首位已经是 `1`，则从第二位开始找替换目标。

## 易错点

- 首位替换为 `0` 会产生前导零，这是非法的，必须替换为 `1`。
- 求最小值时，首位是 `1` 的情况需要单独处理，不能简单地将 `1` 替换为 `0`。
- `String.replace(char, char)` 是全局替换，符合题意（题目要求将所有同一位数字都替换）。
