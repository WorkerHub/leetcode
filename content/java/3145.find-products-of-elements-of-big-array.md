## 题目描述

big_nums是将1,2,3,...各数的2的幂次分解依次拼接形成的无限数组，求区间乘积对mod取模。

## 解题思路

区间乘积=2^(各位指数之和)。二分定位区间边界对应的数，统计[1,n]中各位出现次数（即第bit位为1的数的个数），用快速幂计算2^指数和 mod m。

## Java 代码实现

```java
class Solution {
    public int[] findProductsOfElements(long[][] queries) {
        int[] ans = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            long from = queries[q][0], to = queries[q][1];
            long mod = queries[q][2];
            // 统计big_nums[from..to]中各2^bit的指数之和
            long exp = sumBits(to + 1) - sumBits(from);
            ans[q] = (int) power(2, exp, mod);
        }
        return ans;
    }

    // big_nums前k个元素中所有位指数之和
    private long sumBits(long k) {
        if (k <= 0) return 0;
        // 二分找第k个元素落在哪个数
        long lo = 1, hi = (long) 1e15;
        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (countElements(mid) >= k) hi = mid;
            else lo = mid + 1;
        }
        long val = lo;
        long prev = countElements(val - 1);
        // [1, val-1]贡献的指数和
        long result = sumBitsUpTo(val - 1);
        // val的前(k-prev)个位的指数
        long remain = k - prev;
        int cnt = 0;
        for (int bit = 0; bit < 60; bit++) {
            if (((val >> bit) & 1) == 1) {
                cnt++;
                if (cnt <= remain) result += bit;
                else break;
            }
        }
        return result;
    }

    // [1, n]中所有数的powerful数组总长度（各数二进制1的个数之和）
    private long countElements(long n) {
        if (n <= 0) return 0;
        long res = 0;
        for (int bit = 0; bit < 60; bit++) {
            long cycle = 1L << (bit + 1);
            long full = (n + 1) / cycle;
            long rem = (n + 1) % cycle;
            res += full * (1L << bit) + Math.max(0, rem - (1L << bit));
        }
        return res;
    }

    // [1, n]中所有数各位为1时的位号之和
    private long sumBitsUpTo(long n) {
        if (n <= 0) return 0;
        long res = 0;
        for (int bit = 0; bit < 60; bit++) {
            long cycle = 1L << (bit + 1);
            long full = (n + 1) / cycle;
            long rem = (n + 1) % cycle;
            long cnt = full * (1L << bit) + Math.max(0, rem - (1L << bit));
            res += cnt * bit;
        }
        return res;
    }

    private long power(long base, long exp, long mod) {
        if (mod == 1) return 0;
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(Q * log^2(maxval))
- **空间复杂度**：O(1)

## 关键点总结

1. **乘积=2^(各位指数之和)**：将乘法转化为指数求和
2. **二分定位**第k个元素对应的数
3. **统计[1,n]各位为1的数的个数**用数位计数公式
