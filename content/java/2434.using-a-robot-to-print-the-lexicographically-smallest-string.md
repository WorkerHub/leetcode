## 题目描述

给你字符串 `s` 和一个栈 `t`，每次可将 `s[0]` 压入 `t` 或将 `t` 的栈顶弹出到结果中，返回可得到的字典序最小字符串。

## 解题思路

贪心 + 栈：预计算后缀最小值 `suffMin[i]`（`s[i:]` 中的最小字符）。每次压栈后循环检查：若栈顶 <= 后续字符的最小值，立即弹出（越早输出小字符越好）。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String robotWithString(String s) {
        int n = s.length();
        char[] ch = s.toCharArray();

        // 预计算后缀最小值
        char[] suffMin = new char[n + 1];
        suffMin[n] = 'z'; // 哨兵，比所有字母大
        for (int i = n - 1; i >= 0; i--) {
            suffMin[i] = (char) Math.min(ch[i], suffMin[i + 1]);
        }

        Deque<Character> stack = new ArrayDeque<>();
        StringBuilder result = new StringBuilder();

        for (int i = 0; i < n; i++) {
            stack.push(ch[i]); // 将字符压入栈
            // 当栈顶字符 <= 后续最小字符时，弹出
            while (!stack.isEmpty() && stack.peek() <= suffMin[i + 1]) {
                result.append(stack.pop());
            }
        }
        // 清空栈中剩余字符
        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }
        return result.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：栈顶不大于后面所有字符的最小值时立即弹出
2. 后缀最小值预计算，O(1) 比较
3. 每次压栈后需循环弹出（不只检查一次）
