## 题目描述

给你四个整数数组 nums1、nums2、nums3 和 nums4，数组长度都是 n，请你计算有多少个元组 (i, j, k, l) 能满足：

- 0 <= i, j, k, l < n
- nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

**示例 1:**

```
输入: nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出: 2
解释:
两个元组如下:
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0
```

**示例 2:**

```
输入: nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
输出: 1
```

**提示:**

- n == nums1.length == nums2.length == nums3.length == nums4.length
- 1 <= n <= 200
- -2^28 <= nums1[i], nums2[i], nums3[i], nums4[i] <= 2^28

## 解题思路

这道题如果暴力枚举四层循环，时间复杂度是 O(n^4)，会超时。使用**哈希表**可以优化到 O(n^2)。

**核心思想：分组 + 哈希**
1. 将四个数组分成两组：(nums1, nums2) 和 (nums3, nums4)
2. 用哈希表记录前两个数组所有可能的和
3. 遍历后两个数组，查找是否存在对应的相反数

## Java 代码实现

### 方法一：哈希表（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        // 统计 nums1 + nums2 所有可能的和
        // 时间复杂度: O(n^2)
        // 空间复杂度: O(n^2)
        Map<Integer, Integer> sumMap = new HashMap<>();
        for (int a : nums1) {
            for (int b : nums2) {
                sumMap.put(a + b, sumMap.getOrDefault(a + b, 0) + 1);
            }
        }

        // 查找 nums3 + nums4 的相反数
        int count = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                int target = -(c + d);
                count += sumMap.getOrDefault(target, 0);
            }
        }

        return count;
    }
}
```

### 方法二：更简洁的写法

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        // 第一步：统计前两个数组的所有两数之和
        Map<Integer, Integer> map = new HashMap<>();
        for (int a : nums1) {
            for (int b : nums2) {
                map.merge(a + b, 1, Integer::sum);
            }
        }

        // 第二步：查找后两个数组的相反数
        int count = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                count += map.getOrDefault(-(c + d), 0);
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. **分组策略**：四个数组分成两组处理
2. **哈希优化**：用空间换时间，O(n^2) 代替 O(n^4)
3. **相反数查找**：a+b+c+d=0 等价于 a+b=-(c+d)
