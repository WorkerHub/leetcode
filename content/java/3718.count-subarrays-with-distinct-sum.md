## 题目描述

给定整数数组 `nums` 和整数 `k`，统计所有元素各不相同且元素之和恰好等于 `k` 的子数组数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countSubarrays(int[] nums, int k) {
        int n = nums.length;
        int result = 0;

        // 枚举左端点，右指针扩展直到出现重复或和超过 k
        for (int left = 0; left < n; left++) {
            Set<Integer> seen = new HashSet<>();
            long curSum = 0;
            for (int right = left; right < n; right++) {
                if (seen.contains(nums[right])) break; // 出现重复，停止
                seen.add(nums[right]);
                curSum += nums[right];
                if (curSum == k) result++;
                else if (curSum > k) break; // 元素为正整数，和只增不减
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²) 最坏情况，但正整数约束使实际运行较快
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 元素不重复约束限制了每个左端点能扩展的右端点数量
2. 由于元素均为正整数，窗口和单调递增，可以在和超过 k 时提前终止
3. 先枚举左端点再向右扩展，自然处理不重复约束
