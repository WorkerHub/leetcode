## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，找到最大的子数组和，使得该子数组包含 `k` 个值域上连续的整数（如值 3,4,5 连续）。

## 解题思路

枚举所有 k 个连续值的起始值 v（`v` 到 `v+k-1`）：若 nums 中包含这 k 个值，找覆盖这些值的子数组（包含所有出现位置的最小区间到最大区间），结合前缀和计算最大子数组和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxSubarraySum(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // 记录每个值在 nums 中出现的所有下标
        Map<Integer, List<Integer>> pos = new HashMap<>();
        for (int i = 0; i < n; i++) {
            pos.computeIfAbsent(nums[i], x -> new ArrayList<>()).add(i);
        }

        long ans = Long.MIN_VALUE;
        Set<Integer> vals = pos.keySet();

        for (int v : vals) {
            // 检查 v 到 v+k-1 是否都在 nums 中
            boolean valid = true;
            for (int u = v; u < v + k; u++) {
                if (!pos.containsKey(u)) { valid = false; break; }
            }
            if (!valid) continue;

            // 合并所有 k 个值的下标，找最左和最右
            int minIdx = Integer.MAX_VALUE, maxIdx = Integer.MIN_VALUE;
            for (int u = v; u < v + k; u++) {
                List<Integer> ps = pos.get(u);
                minIdx = Math.min(minIdx, ps.get(0));
                maxIdx = Math.max(maxIdx, ps.get(ps.size() - 1));
            }
            // 子数组 [minIdx, maxIdx] 的和
            ans = Math.max(ans, prefix[maxIdx + 1] - prefix[minIdx]);
        }

        return ans == Long.MIN_VALUE ? 0 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，枚举连续值区间
- 空间复杂度：O(n)，位置映射表

## 关键点总结

1. 连续值是指值域上连续（如 3,4,5），不是位置上连续。
2. 枚举所有可能的 k 个连续值集合，找覆盖这些值所有位置的子数组。
3. 前缀和快速计算子数组和，避免重复求和。
