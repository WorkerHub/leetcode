## 题目描述

给你一个有向无环图（DAG），共 n 个节点，边 `edges[i] = [u, v, w]`，每次可以花费 1 的代价将某条边权重改为任意非负整数，使从源点到汇点的所有路径长度相等，返回最小修改边数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumCost(int n, int[][] edges) {
        // 构建邻接表和入度数组
        List<int[]>[] graph = new List[n];
        int[] inDegree = new int[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();

        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            inDegree[e[1]]++;
        }

        // 拓扑排序 + DP 求从源点到各节点的最长路径
        long[] dist = new long[n];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0); // 节点 0 为源点

        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int[] next : graph[u]) {
                int v = next[0], w = next[1];
                // 松弛：更新到 v 的最长路径
                dist[v] = Math.max(dist[v], dist[u] + w);
                inDegree[v]--;
                if (inDegree[v] == 0) {
                    queue.offer(v);
                }
            }
        }

        // 统计不需要修改的边：边权恰好等于 dist[v] - dist[u]
        int canKeep = 0;
        for (int[] e : edges) {
            if (dist[e[0]] + e[2] == dist[e[1]]) {
                canKeep++;
            }
        }

        // 总边数减去可保留的边数即为需要修改的边数
        return edges.length - canKeep;
    }
}
```

## 复杂度分析

- 时间复杂度：O(V + E)，DAG 拓扑排序
- 空间复杂度：O(V + E)

## 关键点总结

1. DAG 上的 DP 通过拓扑排序求从源点到各节点的最长路径。
2. 所有路径等长 => 将所有路径对齐到最长路径，需修改边使较短路径变长。
3. 不需要修改的边：边权 w = `dist[v] - dist[u]`（恰好在最长路上）。
