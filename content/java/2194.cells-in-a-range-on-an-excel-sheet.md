## 题目描述

给定Excel单元格范围"col1row1:col2row2"，返回范围内所有单元格（列优先、行递增）。

## 解题思路

解析列范围和行范围，外层循环列（字母），内层循环行（数字），按序生成。

## Java 代码实现

```java
class Solution {
    public List<String> cellsInRange(String s) {
        char col1 = s.charAt(0), col2 = s.charAt(3);
        int row1 = s.charAt(1) - '0', row2 = s.charAt(4) - '0';
        
        List<String> result = new ArrayList<>();
        for (char c = col1; c <= col2; c++) {
            for (int r = row1; r <= row2; r++) {
                result.add("" + c + r);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((col2-col1+1) * (row2-row1+1))
- **空间复杂度**：O(1)（不计输出）

## 关键点总结

1. **列优先**：外层循环列字母，内层循环行数字
2. **解析格式**：s[0]和s[3]是列，s[1]和s[4]是行
3. **字符遍历**：char可直接++递增
