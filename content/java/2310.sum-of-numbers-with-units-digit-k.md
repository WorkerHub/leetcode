## 题目描述

求最少多少个个位为k的正整数之和等于num。

## 解题思路

个位循环性：t个个位为k的数之和的个位为(t*k)%10。枚举t从1到10，找满足(t*k)%10==num%10且t*k<=num的最小t。

## Java 代码实现

```java
class Solution {
    public int minimumNumbers(int num, int k) {
        if (num == 0) return 0;

        for (int t = 1; t <= 10; t++) {
            if ((t * k) % 10 == num % 10 && t * k <= num) {
                return t;
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **个位以10为周期循环**：只需枚举1到10
2. **双重条件**：个位匹配且数值可行(t*k<=num)
3. **num=0特判**：空集合和为0
