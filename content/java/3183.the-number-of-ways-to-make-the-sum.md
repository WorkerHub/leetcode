## 题目描述

用面值为 1、2、6 的无限硬币凑成整数 `n`，返回方案数对 10^6+3 取模。

## 解题思路

经典完全背包：外层遍历硬币面值，内层正序遍历金额，`dp[i] += dp[i - coin]`。

## Java 代码实现

```java
class Solution {
    public int numberOfWays(int n) {
        final int MOD = 1_000_003; // 10^6 + 3
        int[] coins = {1, 2, 6};
        int[] dp = new int[n + 1];
        dp[0] = 1; // 凑成 0 有 1 种方法（不选任何硬币）

        for (int c : coins) {
            // 完全背包：正序遍历
            for (int i = c; i <= n; i++) {
                dp[i] = (dp[i] + dp[i - c]) % MOD;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 3) = O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 完全背包：每种硬币可用无限次，内层正序遍历
2. `dp[0] = 1` 表示凑成 0 有唯一方案（空方案）
3. 模数为 10^6 + 3（注意不是 10^9 + 7）
