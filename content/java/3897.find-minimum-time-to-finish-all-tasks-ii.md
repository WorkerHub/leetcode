## 题目描述

给定任务列表 `tasks[i]=[start,end,duration]`，每个任务需在 `[start,end]` 内完成 `duration` 个单位时间（不必连续），每次只能执行一个任务，返回完成所有任务所需的最少总时间，无法完成则返回 -1。

## 解题思路

贪心：按截止时间升序排序，对每个任务从截止时间往前贪心选空闲时间段（尽量晚执行，为截止时间更早的任务留出空间），用位数组记录已占用时间段。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findMinimumTime(int[][] tasks) {
        // 按截止时间升序排序
        Arrays.sort(tasks, (a, b) -> a[1] - b[1]);
        int maxTime = 0;
        for (int[] t : tasks) maxTime = Math.max(maxTime, t[1]);

        // run[t] = 1 表示时间 t 已被占用
        int[] run = new int[maxTime + 1];

        for (int[] task : tasks) {
            int start = task[0], end = task[1], duration = task[2];
            // 统计 [start, end] 内已占用的时间
            int already = 0;
            for (int t = start; t <= end; t++) already += run[t];
            int need = duration - already;

            // 从截止时间往前贪心选空闲时间段
            for (int t = end; t >= start && need > 0; t--) {
                if (run[t] == 0) {
                    run[t] = 1;
                    need--;
                }
            }

            if (need > 0) return -1; // 任务无法完成
        }

        int total = 0;
        for (int t : run) total += t;
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * max_time)，每个任务最多扫描 max_time 个时间点
- 空间复杂度：O(max_time)

## 关键点总结

1. 按截止时间升序排序，优先处理最紧急的任务（贪心）。
2. 从截止时间往前贪心选空闲时间段（尽量晚执行，为早截止任务留出空间）。
3. 位集记录已占用时间，支持 O(1) 查询。
