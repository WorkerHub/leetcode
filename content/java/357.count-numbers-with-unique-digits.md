## 题目描述

给你一个整数 `n`，统计并返回各位数字都不同的数字 `x` 的个数，其中 `0 <= x < 10^n`。

**示例 1：**
```
输入：n = 2
输出：91
解释：答案应为除去 11、22、33、44、55、66、77、88、99 外，在 0 到 100 范围内的所有数字。
```

**示例 2：**
```
输入：n = 0
输出：1
```

**提示：**
- `0 <= n <= 8`

## 解题思路

这是一个排列组合问题。

**核心观察：**
- n=0: 1 个（0）
- n=1: 10 个（0-9）
- n=2: 第一位 9 种选择（1-9），第二位 9 种（0-9 除去第一位）= 9 × 9 = 81，加上一位数的 10 个，共 91
- n=3: 9 × 9 × 8，加上 n<=2 的结果

**递推公式：**
```
f(1) = 10
f(n) = f(n-1) + 9 × 9 × 8 × ... × (11-n)
```

## Java 代码实现

```java
class Solution {
    public int countNumbersWithUniqueDigits(int n) {
        if (n == 0) return 1;
        if (n == 1) return 10;

        int result = 10;      // n=1 的结果
        int uniqueDigits = 9; // 当前位数的独特数字个数（第一位有 9 种选择：1-9）
        int available = 9;    // 当前位可用的数字个数（除去已用数字）

        for (int i = 2; i <= n; i++) {
            // 每增加一位，可选数字减少一个
            uniqueDigits *= available;
            result += uniqueDigits;
            available--;
        }

        return result;
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 图解示例

```
n=2 的计算：
一位数：10 个（0-9）
二位数：
  第一位：1-9（9种）
  第二位：0-9 除去第一位（9种）
  共 9×9 = 81 个
总计：10 + 81 = 91

n=3 的计算：
一位数：10
二位数：81
三位数：9×9×8 = 648
总计：10 + 81 + 648 = 739
```

## 关键点总结

1. **排列组合**：第一位特殊（不能为0）
2. **递推**：基于前一个结果累加
3. **上限**：n>10 无意义（只有10个数字）
