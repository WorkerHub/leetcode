## 题目描述

有 n 台电脑，电脑 0 默认解锁。解锁电脑 i 需要某台已解锁电脑的密码严格小于 `complexity[i]`。求合法解锁排列数量，对 10^9+7 取模。

## 解题思路

电脑 0 必须是密码最小的（否则无解）。将其余电脑按 complexity 排序后，第 i 个（0-indexed）的排列选择数 = i+1（前 i 台已处理的电脑加上电脑 0 共 i+1 台均可作为前驱）。所有电脑的选择数之积即为答案。若任意电脑的 complexity <= complexity[0]，返回 0。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long countPermutations(int[] complexity) {
        final int MOD = 1_000_000_007;
        int n = complexity.length;

        // 电脑 0 必须是密码最小的
        int minC = complexity[0];
        for (int c : complexity) minC = Math.min(minC, c);
        if (complexity[0] != minC) return 0;

        // 对其余电脑按 complexity 排序
        int[] rest = Arrays.copyOfRange(complexity, 1, n);
        Arrays.sort(rest);

        long result = 1;
        for (int i = 0; i < rest.length; i++) {
            if (rest[i] <= complexity[0]) return 0; // 无法被解锁
            result = result * (i + 1) % MOD;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 电脑 0 必须是密码最小的，否则无法启动
2. 按密码排序后，第 i 个电脑有 (i+1) 种插入位置（前 i 台 + 电脑 0）
3. 答案 = 所有选择数的乘积
