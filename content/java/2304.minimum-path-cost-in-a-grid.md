## 题目描述

网格中从第一行到最后一行，路径代价=经过格子值之和+移动代价之和，求最小路径代价。

## 解题思路

DP：dp[j]表示到达当前行第j列的最小代价。从上一行每列转移，代价=dp[k]+moveCost[grid[i-1][k]][j]+grid[i][j]。

## Java 代码实现

```java
class Solution {
    public int minPathCost(int[][] grid, int[][] moveCost) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        // 初始化第一行
        for (int j = 0; j < n; j++) dp[j] = grid[0][j];

        for (int i = 1; i < m; i++) {
            int[] newDp = new int[n];
            Arrays.fill(newDp, Integer.MAX_VALUE);
            for (int k = 0; k < n; k++) {
                int v = grid[i - 1][k];
                for (int j = 0; j < n; j++) {
                    newDp[j] = Math.min(newDp[j], dp[k] + moveCost[v][j] + grid[i][j]);
                }
            }
            dp = newDp;
        }

        int ans = Integer.MAX_VALUE;
        for (int val : dp) ans = Math.min(ans, val);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N^2)
- **空间复杂度**：O(N)

## 关键点总结

1. **moveCost索引是格子的值**：不是位置
2. **路径代价包含格子值和移动代价**
3. **空间优化**：滚动数组只保留一行
