## 题目描述

给你闭区间数组 `intervals`，将其划分为若干组使每组内任意两区间不相交，返回最少组数。

## 解题思路

最少分组数 = 最大同时重叠区间数。用最小堆按左端点排序处理：堆中存各组最后一个区间的右端点，若堆顶 < 当前区间左端点则弹出复用，否则新开一组。堆大小即为答案。

## Java 代码实现

```java
class Solution {
    public int minGroups(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        PriorityQueue<Integer> heap = new PriorityQueue<>(); // 各组最后一个区间的右端点
        for (int[] interval : intervals) {
            if (!heap.isEmpty() && heap.peek() < interval[0]) {
                heap.poll(); // 复用最早结束的组
            }
            heap.offer(interval[1]);
        }
        return heap.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 最少分组数 = 最大同时重叠区间数（扫描线经典结论）。
2. 堆顶 < 当前左端点才可合并（严格小于，闭区间端点相等也算相交）。
3. 堆中元素数量即为当前所需组数。
