## 题目描述

给你下标从 0 开始的整数数组 `mountain`，返回所有峰值的下标（非边界且严格大于两侧相邻元素）。

## 解题思路

遍历下标 1 到 n-2，检查每个元素是否严格大于左右相邻元素。

## Java 代码实现

```java
class Solution {
    public List<Integer> findPeaks(int[] mountain) {
        List<Integer> peaks = new ArrayList<>();
        int n = mountain.length;
        for (int i = 1; i < n - 1; i++) {
            // 严格大于左右两侧
            if (mountain[i] > mountain[i - 1] && mountain[i] > mountain[i + 1]) {
                peaks.add(i);
            }
        }
        return peaks;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)，k 为峰值个数

## 关键点总结

1. 峰值必须是非边界位置（下标 1 到 n-2）
2. 必须严格大于两侧，不能等于
3. 返回下标而非值
