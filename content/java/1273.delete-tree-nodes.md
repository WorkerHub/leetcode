## 题目描述

给定以节点 0 为根的树（parent 数组表示）和每个节点的值。删除所有子树和为 0 的子树，返回剩余节点数。

**示例：**
```
输入：nodes = 7, parent = [-1,0,0,1,2,2,2], value = [1,-2,4,0,-2,-1,-1]
输出：2
```

## 解题思路

DFS 后序遍历：先计算子树的和与节点数，若子树和为 0 则整棵子树删除（节点数设 0）。

## Java 代码实现

```java
class Solution {
    public int deleteTreeNodes(int nodes, int[] parent, int[] value) {
        // 建立子节点列表
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < nodes; i++) children.add(new ArrayList<>());
        for (int i = 1; i < nodes; i++) {
            children.get(parent[i]).add(i);
        }
        
        int[] result = dfs(0, children, value);
        return result[1]; // 返回剩余节点数
    }
    
    // 返回 [子树和, 子树节点数]
    private int[] dfs(int node, List<List<Integer>> children, int[] value) {
        int sum = value[node];
        int count = 1;
        
        for (int child : children.get(node)) {
            int[] childResult = dfs(child, children, value);
            sum += childResult[0];
            count += childResult[1];
        }
        
        // 子树和为 0，删除整棵子树
        if (sum == 0) return new int[]{0, 0};
        return new int[]{sum, count};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **后序遍历**：先处理子节点，再汇总到父节点
2. **返回二元组**：(子树和, 节点数)
3. **删除条件**：子树和为 0 时节点数归零
4. **建树**：parent 数组转邻接表
