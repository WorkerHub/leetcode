## 题目描述

给定 `n` 个节点的无向加权图，删除若干边使连通分量数至少为 `k`，返回需删除边的最小总权重。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent;

    public int minimumTime(int n, int[][] edges, int k) {
        Arrays.sort(edges, Comparator.comparingInt(e -> e[2]));
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 构建最小生成树，收集树边权重
        List<Integer> mstWeights = new ArrayList<>();
        for (int[] e : edges) {
            if (union(e[0], e[1])) mstWeights.add(e[2]);
        }

        // 需要 k 个连通分量，删除最小的 k-1 条树边
        int need = k - 1;
        if (need <= 0) return 0;

        // 树边已按权重升序排列（edges 已排序，union 保留了顺序）
        int result = 0;
        for (int i = 0; i < Math.min(need, mstWeights.size()); i++) {
            result += mstWeights.get(i);
        }
        return result;
    }

    private boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        parent[px] = py;
        return true;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
}
```

## 复杂度分析

- 时间复杂度：O(E log E)，排序为主要开销
- 空间复杂度：O(n + E)

## 关键点总结

1. 逆向思维：删边增加分量，等价于删除最小生成树中权重最小的 `k-1` 条边
2. 非树边不影响连通性分裂，不需要删除
3. 并查集路径压缩保证合并效率
