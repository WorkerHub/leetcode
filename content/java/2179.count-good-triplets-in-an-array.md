## 题目描述

两个[0,n-1]的排列nums1和nums2，求好三元组数（在两个数组中相对顺序都递增的三元组）。

## 解题思路

构造a[i]=pos2[nums1[i]]，转化为统计a中递增三元组数。对每个中间值a[j]，贡献=左侧小于a[j]的数量*右侧大于a[j]的数量，用树状数组维护。

## Java 代码实现

```java
class Solution {
    public long goodTriplets(int[] nums1, int[] nums2) {
        int n = nums1.length;
        // pos2[v] = v在nums2中的位置
        int[] pos2 = new int[n];
        for (int i = 0; i < n; i++) {
            pos2[nums2[i]] = i;
        }
        // a[i] = nums1[i]在nums2中的位置
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = pos2[nums1[i]];
        }
        
        // 树状数组：从左到右计算left_less
        int[] bit = new int[n + 1];
        long[] leftLess = new long[n];
        for (int i = 0; i < n; i++) {
            leftLess[i] = query(bit, a[i] - 1);
            update(bit, a[i], n);
        }
        
        // 树状数组：从右到左计算right_greater
        int[] bit2 = new int[n + 1];
        long[] rightGreater = new long[n];
        for (int i = n - 1; i >= 0; i--) {
            int totalRight = n - 1 - i;
            long le = query(bit2, a[i]);
            rightGreater[i] = totalRight - le;
            update(bit2, a[i], n);
        }
        
        long ans = 0;
        for (int j = 0; j < n; j++) {
            ans += leftLess[j] * rightGreater[j];
        }
        return ans;
    }
    
    private void update(int[] bit, int i, int n) {
        i += 1; // 1-indexed
        while (i <= n) {
            bit[i]++;
            i += i & (-i);
        }
    }
    
    private long query(int[] bit, int i) {
        i += 1; // 1-indexed
        long s = 0;
        while (i > 0) {
            s += bit[i];
            i -= i & (-i);
        }
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **转化为单数组问题**：a[i]=pos2[nums1[i]]，统计递增三元组
2. **中间值贡献**：左侧更小数 × 右侧更大数
3. **两次树状数组**：正向求leftLess，反向求rightGreater
