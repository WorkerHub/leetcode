## 题目描述

给定整数数组 `nums` 和正整数 `k`，返回长度至少为 `k` 的连续子数组的最小和，不存在则返回 0。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumSumSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // 单调递减队列，维护前缀和最大值的索引
        // 子数组和 = prefix[r] - prefix[l]（r-l >= k），最小化 => 最大化 prefix[l]
        Deque<Integer> dq = new ArrayDeque<>();
        long ans = Long.MAX_VALUE;

        for (int r = k; r <= n; r++) {
            int l = r - k; // l 的合法范围 [0, r-k]
            // 维护单调递减队列（存索引，对应 prefix 值单调递减）
            while (!dq.isEmpty() && prefix[dq.peekLast()] <= prefix[l]) dq.pollLast();
            dq.addLast(l);
            ans = Math.min(ans, prefix[r] - prefix[dq.peekFirst()]);
        }
        return ans == Long.MAX_VALUE ? 0 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 前缀和将子数组和转化为两个前缀和之差
2. 最小子数组和等价于最大化左端前缀和，用单调递减队列维护
3. 合法左端点 l 随 r 单调增加，队列整体 O(n)
