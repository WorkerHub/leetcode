## 题目描述

统计字符串中的单词个数，这里的单词指的是连续的不是空格的字符。

请注意，你可以假定字符串里不包括任何不可打印的字符。

**示例：**
```
输入："Hello, my name is John"
输出：5
解释：这里的单词是 "Hello,", "my", "name", "is", "John"
```

**示例 2：**
```
输入："Hello"
输出：1
```

**示例 3：**
```
输入："    "
输出：0
```

**示例 4：**
```
输入：""
输出：0
```

**提示：**
- `0 <= s.length <= 300`
- `s` 由小写英文字母、大写英文字母、数字或空格 `' '` 组成

## 解题思路

这道题要求统计字符串中的单词数量。核心是识别连续的非空格字符序列。

**关键观察：**
1. 单词由连续的非空格字符组成
2. 单词之间由一个或多个空格分隔
3. 字符串开头和结尾可能有空格

**算法流程：**
1. 遍历字符串
2. 统计非空格字符序列的个数
3. 可以统计空格到非空格的转换次数

## Java 代码实现

### 方法一：使用内置方法 ⭐ 推荐

```java
class Solution {
    public int countSegments(String s) {
        // trim() 去除首尾空格，split("\\s+") 按一个或多个空格分割
        String trimmed = s.trim();
        if (trimmed.isEmpty()) return 0;
        return trimmed.split("\\s+").length;
    }
}
```

### 方法二：手动遍历

```java
class Solution {
    public int countSegments(String s) {
        int count = 0;
        
        for (int i = 0; i < s.length(); i++) {
            // 如果当前字符不是空格，且是第一个字符或前一个字符是空格
            // 说明这是一个新单词的开始
            if (s.charAt(i) != ' ' && (i == 0 || s.charAt(i - 1) == ' ')) {
                count++;
            }
        }
        
        return count;
    }
}
```

### 方法三：状态机

```java
class Solution {
    public int countSegments(String s) {
        int count = 0;
        boolean inWord = false;  // 是否在单词内
        
        for (char c : s.toCharArray()) {
            if (c != ' ') {
                if (!inWord) {
                    // 进入新单词
                    count++;
                    inWord = true;
                }
            } else {
                // 离开单词
                inWord = false;
            }
        }
        
        return count;
    }
}
```

### 方法四：统计单词边界

```java
class Solution {
    public int countSegments(String s) {
        int count = 0;
        int n = s.length();
        
        for (int i = 0; i < n; i++) {
            // 当前字符不是空格，且要么是第一个字符，要么前一个字符是空格
            if (s.charAt(i) != ' ' && (i == 0 || s.charAt(i - 1) == ' ')) {
                count++;
            }
        }
        
        return count;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，n 是字符串长度
- 空间复杂度：
  - 方法一：O(n)，split() 创建数组
  - 方法二、三、四：O(1)

## 关键点总结

1. **split() 方法**：Java 的 `split("\\s+")` 配合 `trim()` 可以处理连续空格和首尾空格
2. **边界检查**：判断是否是单词开始要检查前一个字符
3. **状态机思想**：维护是否在单词内的状态
4. **空字符串**：空字符串和纯空格字符串都返回 0

## 易错点

1. **连续空格**：多个连续空格不能算多个单词
2. **首尾空格**：要正确处理字符串开头和结尾的空格
3. **空字符串**：空字符串返回 0，不是 1
4. **split 陷阱**：Java 中 `"".split("\\s+")` 返回长度为 1 的数组，要先 trim() 再判断
5. **charAt 用法**：Java 字符串用 `charAt(i)` 获取字符，不能用下标运算符
