## 题目描述

给你整数 `target` 和 `maxValue`，从 0 开始，每次操作可以将当前值加 1，或将当前值乘以 2（结果不超过 `maxValue`）。返回到达 target 的最少操作次数。

## 解题思路

逆向贪心：从 target 反推到 0。若 target > maxValue 先减到 maxValue；之后偶数优先除以 2（逆向乘 2），奇数先减 1；最后从 1 到 0 需 1 步（+1 的逆操作）。

## Java 代码实现

```java
class Solution {
    public int minOperations(int target, int maxValue) {
        int ops = 0;
        // 先处理超过maxValue的部分（只能逐步减1）
        if (target > maxValue) {
            ops += target - maxValue;
            target = maxValue;
        }
        // 反向从target到1
        while (target > 1) {
            if (target % 2 == 1) { target--; ops++; }
            else { target /= 2; ops++; }
        }
        // 从0到1需1步
        ops += 1;
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log target)
- 空间复杂度：O(1)

## 关键点总结

1. 逆向思路：从 target 推到 0
2. 超过 maxValue 的部分只能逐步减 1
3. 在 maxValue 内偶数尽量除 2
