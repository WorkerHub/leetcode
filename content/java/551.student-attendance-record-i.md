## 题目描述

给定一个字符串 `s` 表示一个学生的出勤记录，其中每个字符表示一天的出勤情况。记录中只包含以下三个字符：

- `'A'`：Absent，缺勤
- `'L'`：Late，迟到
- `'P'`：Present，到场

如果学生的出勤记录不包含**超过一个 'A'（缺勤）**且**不包含连续的三个或更多 'L'（迟到）**，则该学生会被奖励。

如果学生会被奖励，返回 `true`；否则返回 `false`。

**示例 1：**
```
输入：s = "PPALLP"
输出：true
解释：学生有 1 个缺勤和连续 2 个迟到，满足奖励条件。
```

**示例 2：**
```
输入：s = "PPALLL"
输出：false
解释：学生有连续 3 个迟到，不满足奖励条件。
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 为 `'A'`、`'L'` 或 `'P'`

## 解题思路

这是一道简单的字符串判断题，需要检查两个条件：

1. **缺勤次数**：'A' 的数量不超过 1 次
2. **连续迟到**：不存在连续 3 个或更多的 'L'

核心思想：
- 遍历字符串，统计 'A' 的数量
- 检查是否存在 "LLL" 子串
- 两个条件都满足则返回 true

算法流程：
1. 统计字符串中 'A' 的数量，如果超过 1 个则返回 false
2. 检查字符串中是否包含 "LLL"，如果包含则返回 false
3. 都不满足上述条件则返回 true

## Java 代码实现

### 方法一：直接使用字符串方法（推荐）⭐

```java
class Solution {
    public boolean checkRecord(String s) {
        // 统计 'A' 的数量，并检查是否包含 "LLL"
        int absentCount = 0;
        for (char c : s.toCharArray()) {
            if (c == 'A') absentCount++;
        }
        // 缺勤不超过 1 次，且不包含连续 3 个迟到
        return absentCount <= 1 && !s.contains("LLL");
    }
}
```

### 方法二：一次遍历

```java
class Solution {
    public boolean checkRecord(String s) {
        // 一次遍历同时检查两个条件
        int absentCount = 0;       // 缺勤次数
        int continuousLate = 0;    // 连续迟到次数

        for (char c : s.toCharArray()) {
            if (c == 'A') {
                absentCount++;
                // 如果缺勤超过 1 次，直接返回 false
                if (absentCount > 1) return false;
                // 遇到 A，重置连续迟到计数
                continuousLate = 0;
            } else if (c == 'L') {
                continuousLate++;
                // 如果连续迟到达到 3 次，直接返回 false
                if (continuousLate >= 3) return false;
            } else {
                // 遇到 P，重置连续迟到计数
                continuousLate = 0;
            }
        }

        return true;
    }
}
```

### 方法三：正则表达式

```java
class Solution {
    public boolean checkRecord(String s) {
        // 检查是否不包含超过 1 个 A，且不包含连续 3 个或更多 L
        // 如果包含 "A.*A"（两个 A）或 "LLL"（连续 3 个 L），返回 false
        return !s.matches(".*A.*A.*") && !s.contains("LLL");
    }
}
```

## 复杂度分析

**方法一（推荐）：**
- **时间复杂度**：O(n)，其中 n 是字符串长度。遍历字符串统计 A 的数量，contains 操作也需要遍历字符串。
- **空间复杂度**：O(1)，只使用常量额外空间。

**方法二：**
- **时间复杂度**：O(n)，只需遍历一次字符串，最坏情况下遍历完整个字符串。
- **空间复杂度**：O(1)，只使用两个计数变量。

**方法三：**
- **时间复杂度**：O(n)，正则表达式匹配需要遍历字符串。
- **空间复杂度**：O(1)，不考虑正则引擎内部开销。

## 关键点总结

1. **两个独立条件**：缺勤次数和连续迟到是两个独立的判断条件，都需要满足
2. **字符串方法**：Java 的 `contains()` 方法可以快速检查子串
3. **一次遍历优化**：可以在遍历过程中同时检查两个条件，提前终止
4. **连续性判断**：注意是连续的 L，需要重置计数器
5. **代码简洁性**：方法一最简洁，推荐在面试中使用

## 易错点

1. **理解题意**：是"不超过 1 个 A"（允许 0 或 1 个），不是"恰好 1 个"
2. **连续性**：必须是连续的 3 个 L，不是总共 3 个 L
3. **边界情况**：
   - 字符串长度为 1 时
   - 全是 P 的情况
   - 恰好 2 个连续 L 的情况（应返回 true）
4. **重置计数器**：在方法二中，遇到非 L 字符时要重置连续迟到计数
