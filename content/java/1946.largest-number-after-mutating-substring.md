## 题目描述

给你数字字符串 `num` 和映射数组 `change`（`change[i]` 为数字 i 替换后的值），最多选一段连续子串进行替换，返回能得到的最大整数字符串。

## 解题思路

贪心：从左找第一个替换后变大的位置开始替换，向右延续直到替换后会变小（遇到 `change[d] < d` 停止），替换后相等时继续。

## Java 代码实现

```java
class Solution {
    public String maximumNumber(String num, int[] change) {
        char[] digits = num.toCharArray();
        boolean started = false;
        for (int i = 0; i < digits.length; i++) {
            int d = digits[i] - '0';
            int c = change[d];
            if (!started) {
                if (c > d) { digits[i] = (char) ('0' + c); started = true; }
                // c == d：无收益，不开始；c < d：不替换
            } else {
                if (c >= d) digits[i] = (char) ('0' + c);
                else break; // c < d，停止
            }
        }
        return new String(digits);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：从左找第一个 `change[d] > d` 的位置开始替换
2. 替换后相等（`change[d] == d`）继续，不影响当前但不中断后续机会
3. 遇到 `change[d] < d` 立即停止
