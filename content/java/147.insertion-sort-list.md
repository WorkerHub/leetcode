## 题目描述

给定单个链表的头 `head`，使用插入排序对链表进行排序，并返回排序后链表的头。

**插入排序**的算法步骤：

1. 插入排序是迭代的，每次只移动一个元素，直到所有元素可以形成一个有序的输出列表
2. 每次迭代中，插入排序只从输入数据中移除一个待排序的元素，找到它在序列中适当的位置，并将其插入
3. 重复直到所有输入数据插入完为止

**示例 1：**

```
输入: head = [4,2,1,3]
输出: [1,2,3,4]
```

**示例 2：**

```
输入: head = [-1,5,3,4,0]
输出: [-1,0,3,4,5]
```

**提示：**

- 列表中的节点数在范围 `[1, 5000]` 内
- `-5000 <= Node.val <= 5000`

## 解题思路

插入排序的核心思想：维护一个已排序的链表，依次从原链表中取出节点，插入到已排序链表的正确位置。

**算法流程：**

1. 创建一个虚拟头节点 `dummy`，用于简化插入操作
2. 从原链表中逐个取出节点 `curr`
3. 在已排序链表中从头开始查找插入位置
4. 找到第一个值大于 `curr.val` 的节点，将 `curr` 插入到它前面
5. 重复步骤 2-4，直到原链表为空

**关键观察：**

- 链表的插入排序比数组更高效，因为不需要移动大量元素
- 使用虚拟头节点可以避免对头节点的特殊处理
- 每次都从已排序链表的头部开始查找（可优化但会增加复杂度）

## Java 代码实现

### 方法一：标准插入排序（推荐）

```java
// Definition for singly-linked list.
// class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public ListNode insertionSortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        // 虚拟头节点，简化插入操作
        ListNode dummy = new ListNode(0);
        ListNode curr = head;  // 当前要插入的节点

        while (curr != null) {
            // 保存下一个要处理的节点
            ListNode nextNode = curr.next;

            // 在已排序链表中查找插入位置
            ListNode prev = dummy;
            while (prev.next != null && prev.next.val < curr.val) {
                prev = prev.next;
            }

            // 插入 curr 到 prev 后面
            curr.next = prev.next;
            prev.next = curr;

            // 处理下一个节点
            curr = nextNode;
        }

        return dummy.next;
    }
}
```

### 方法二：优化查找（减少重复比较）

```java
class Solution {
    public ListNode insertionSortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // lastSorted: 已排序部分的最后一个节点
        ListNode lastSorted = head;
        ListNode curr = head.next;

        while (curr != null) {
            if (lastSorted.val <= curr.val) {
                // 当前节点已经在正确位置
                lastSorted = lastSorted.next;
            } else {
                // 需要插入到前面的某个位置
                ListNode prev = dummy;
                while (prev.next.val < curr.val) {
                    prev = prev.next;
                }

                // 从原位置移除 curr
                lastSorted.next = curr.next;
                // 插入到新位置
                curr.next = prev.next;
                prev.next = curr;
            }

            curr = lastSorted.next;
        }

        return dummy.next;
    }
}
```

### 方法三：带注释的详细版本

```java
class Solution {
    public ListNode insertionSortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        // 虚拟头节点，避免处理头节点的特殊情况
        ListNode dummy = new ListNode(Integer.MIN_VALUE);

        // 当前要插入的节点
        ListNode current = head;

        while (current != null) {
            // 1. 保存下一个待处理节点
            ListNode nextTemp = current.next;

            // 2. 在已排序链表中找插入位置
            // prev 是插入位置的前一个节点
            ListNode prev = dummy;

            // 找到第一个大于等于 current.val 的节点的前驱
            while (prev.next != null && prev.next.val < current.val) {
                prev = prev.next;
            }

            // 3. 执行插入操作，current 插入到 prev 和 prev.next 之间
            current.next = prev.next;
            prev.next = current;

            // 4. 移动到下一个节点
            current = nextTemp;
        }

        return dummy.next;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n²)
- 外层循环：遍历 n 个节点
- 内层循环：平均情况下需要遍历 n/2 个节点查找插入位置
- 总体：O(n²)

**空间复杂度：** O(1)
- 只使用了常数个额外指针变量
- 原地排序，不需要额外的链表空间

## 关键点总结

1. **虚拟头节点**：使用 dummy 节点避免头节点的特殊处理
2. **三个指针**：
   - `curr`：当前要插入的节点
   - `prev`：已排序链表中的查找指针
   - `nextNode`：保存下一个待处理节点
3. **断链与重连**：正确处理节点的移除和插入
4. **每次从头查找**：虽然不是最优，但保证了代码简洁性
5. **稳定排序**：相同元素的相对顺序不变

## 易错点

1. **丢失节点引用**：在移动 `curr` 前，必须先保存 `curr.next`
2. **虚拟节点初始化**：dummy 节点的值可以是 `Integer.MIN_VALUE` 或任意足够小的值
3. **插入位置判断**：
   - 条件是 `prev.next.val < curr.val`，找到第一个不满足的位置
   - 需要同时判断 `prev.next` 是否为 null
4. **最后一个节点**：插入后要确保 `curr.next` 正确指向（可能是 null）
5. **空链表和单节点**：记得处理边界情况
