## 题目描述

以原点为中心的无限二维网格，格点 `(i,j)` 有 `|i|+|j|` 个苹果。找最小的偶数边长正方形（边长 2n，-n 到 n），使区域内苹果数 ≥ `neededApples`，返回其周长。

## 解题思路

数学公式：边长 2n 的正方形内苹果总数为 `2n(n+1)(2n+1)`。二分查找最小 n 使苹果数满足要求，答案为 `8n`。

## Java 代码实现

```java
class Solution {
    public long minimumPerimeter(long neededApples) {
        long lo = 1, hi = 100000;
        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (2 * mid * (mid + 1) * (2 * mid + 1) >= neededApples)
                hi = mid;
            else
                lo = mid + 1;
        }
        return 8 * lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 公式推导：半径 n 内苹果数 = `2n(n+1)(2n+1)`
2. 二分最小 n，满足苹果数 ≥ neededApples
3. 周长 = `8n`；`neededApples` 最大 10^15，n 最大约 50000
