## 题目描述

给你两个正整数字符串 `low` 和 `high`（最多 100 位），统计 `[low, high]` 范围内相邻数字之差恰好为 1 的步进数个数（对 10^9+7 取模）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    static final int MOD = 1_000_000_007;
    int[][] memo;
    String num;

    // last=10 表示尚未填入任何数字（前导零状态）
    int dfs(int pos, int last, boolean tight, boolean empty) {
        if (pos == num.length()) return empty ? 0 : 1;
        int memoKey = empty ? 10 : last;
        if (!tight && memo[pos][memoKey] >= 0) return memo[pos][memoKey];

        int limit = tight ? (num.charAt(pos) - '0') : 9;
        int res = 0;
        for (int d = 0; d <= limit; d++) {
            if (empty) {
                if (d == 0) res = (res + dfs(pos + 1, 0, tight && d == limit, true)) % MOD;
                else         res = (res + dfs(pos + 1, d, tight && d == limit, false)) % MOD;
            } else {
                if (Math.abs(d - last) == 1) {
                    res = (res + dfs(pos + 1, d, tight && d == limit, false)) % MOD;
                }
            }
        }
        if (!tight) memo[pos][memoKey] = res;
        return res;
    }

    int count(String s) {
        num = s;
        memo = new int[s.length()][11];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dfs(0, 0, true, true);
    }

    String subtractOne(String s) {
        char[] arr = s.toCharArray();
        int i = arr.length - 1;
        while (i >= 0 && arr[i] == '0') { arr[i] = '9'; i--; }
        arr[i]--;
        // 去掉前导零
        int start = 0;
        while (start < arr.length - 1 && arr[start] == '0') start++;
        return new String(arr, start, arr.length - start);
    }

    public int countSteppingNumbers(String low, String high) {
        return (count(high) - count(subtractOne(low)) + MOD) % MOD;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × 10 × 10)，n 为数字字符串长度（最大 100）
- 空间复杂度：O(n × 10)

## 关键点总结

1. 数位 DP：状态为（位置、前一位数字、是否紧贴上界、是否有前导零）
2. tight=false 时缓存结果；tight=true 路径唯一无需缓存
3. 答案 = f(high) - f(low-1)，需实现大数字符串减 1
