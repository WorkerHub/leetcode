## 题目描述

给你一个整数 `n` 和无向图的边列表 `edges`，返回无法互相到达的不同点对数目。

## 解题思路

使用并查集求各连通分量的大小，枚举每个分量时用"之前已遍历的节点总数"乘以当前分量大小累加，得到跨分量点对数。答案需要用 `long` 防止溢出。

## Java 代码实现

```java
class Solution {
    private int[] parent, size;

    // 路径压缩查找
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    // 按秩合并
    private void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (size[rx] < size[ry]) {
            int tmp = rx; rx = ry; ry = tmp;
        }
        parent[ry] = rx;
        size[rx] += size[ry];
    }

    public long countPairs(int n, int[][] edges) {
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
        for (int[] e : edges) {
            union(e[0], e[1]);
        }

        long ans = 0, prev = 0;
        boolean[] visited = new boolean[n];
        for (int i = 0; i < n; i++) {
            int root = find(i);
            if (!visited[root]) {
                visited[root] = true;
                // 当前分量与之前所有节点形成的点对
                ans += prev * size[root];
                prev += size[root];
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) * α(n))，m 为边数，α 为反阿克曼函数
- **空间复杂度**：O(n)

## 关键点总结

1. 不可达点对 = 不同连通分量之间的节点对数。
2. 枚举分量时用 `prev * size` 累加，等价于 `sum(si * sj, i != j)`。
3. n 最大 10^5，答案最大约 5×10^9，需用 `long`。
