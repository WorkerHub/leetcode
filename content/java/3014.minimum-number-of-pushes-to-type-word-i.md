## 题目描述

将互不相同的字母分配到 8 个按键（2-9），输入某字母的代价等于它在对应按键上的位置（1-indexed），返回输入 word 的最小总代价。

## 解题思路

8 个按键，第 i 个字母（0-indexed）代价为 i/8+1，直接累加即可。

## Java 代码实现

```java
class Solution {
    public int minimumPushes(String word) {
        int total = 0;
        for (int i = 0; i < word.length(); i++) {
            total += i / 8 + 1;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)（n ≤ 26，实际 O(1)）
- **空间复杂度**：O(1)

## 关键点总结

1. 所有字母各不相同，只需考虑字母数量
2. 8 个按键，前 8 个字母代价 1，后 8 个代价 2，以此类推
3. 第 i 个（0-indexed）字母代价 = i/8 + 1
