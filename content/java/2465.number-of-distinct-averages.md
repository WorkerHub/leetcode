## 题目描述

给你偶数长度整数数组 `nums`，每次删除最小值和最大值并计算其平均值，返回所有生成的不同平均值数目。

## 解题思路

排序后双指针，每次取首尾元素之和存入集合（用和代替平均值避免浮点数），返回集合大小。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int distinctAverages(int[] nums) {
        Arrays.sort(nums);
        Set<Integer> seen = new HashSet<>();
        int left = 0, right = nums.length - 1;

        while (left < right) {
            // 用两数之和代替平均值（避免浮点数），相同和对应相同平均值
            seen.add(nums[left] + nums[right]);
            left++;
            right--;
        }
        return seen.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序后对称位置配对，双指针向中间逼近
2. 用两数之和代替平均值，避免浮点数比较
3. 集合自动去重，大小即为不同平均值数目
