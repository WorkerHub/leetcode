## 题目描述

给你整数数组 `nums` 和整数 `lower`、`upper`，返回满足 `lower <= nums[i] + nums[j] <= upper`（i < j）的下标对数量。

## 解题思路

排序后用双指针：计算"和 <= limit 的对数"，答案 = f(upper) - f(lower-1)。双指针：左指针右移时右指针左移，`nums[left] + nums[right] <= limit` 则 `ans += right - left`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long countFairPairs(int[] nums, int lower, int upper) {
        Arrays.sort(nums);
        return countPairsAtMost(nums, upper) - countPairsAtMost(nums, lower - 1);
    }

    // 统计满足 nums[i] + nums[j] <= limit（i < j）的对数
    private long countPairsAtMost(int[] nums, long limit) {
        long count = 0;
        int left = 0, right = nums.length - 1;
        while (left < right) {
            if ((long) nums[left] + nums[right] <= limit) {
                count += right - left; // left 固定时，right 左侧的所有 j 都满足
                left++;
            } else {
                right--;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后利用单调性，双指针高效统计
2. 转化为"计算和 <= limit 的对数"，两次调用相减
3. `(long) nums[left] + nums[right]` 防止整数溢出
