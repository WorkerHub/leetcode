## 题目描述

给你一个 `n x n` 的矩阵，每次操作可以将任意一个元素加 1，返回使所有行和与列和相等所需的最少操作次数。

## 解题思路

目标和 `T` 必须 >= 当前所有行和与列和，取其最大值。总操作数 = `n * T - 当前所有元素之和`。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[][] grid) {
        int n = grid.length;

        // 计算每行的和
        int[] rowSums = new int[n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                rowSums[i] += grid[i][j];
            }
        }

        // 计算每列的和
        int[] colSums = new int[n];
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < n; i++) {
                colSums[j] += grid[i][j];
            }
        }

        // 目标和 = 所有行和与列和的最大值
        int target = 0;
        for (int s : rowSums) target = Math.max(target, s);
        for (int s : colSums) target = Math.max(target, s);

        // 总和
        int total = 0;
        for (int s : rowSums) total += s;

        // 操作数 = n * target - total
        return n * target - total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，遍历矩阵
- 空间复杂度：O(n)，行和列和数组

## 关键点总结

1. 只能加 1，目标和 T 必须 >= 当前所有行和与列和。
2. T = max(所有行和, 所有列和)，这是最小可行的目标。
3. 总操作数 = n*T - 当前总和（每行补足到 T，共 n 行）。
