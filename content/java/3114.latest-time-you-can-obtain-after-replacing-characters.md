## 题目描述

给你格式为 `hh:mm` 的 12 小时制时间字符串，部分数字被替换为 `?`，返回替换后可得到的最晚时间（时间范围 01:00 到 12:59）。

## 解题思路

贪心逐位处理：小时十位尽量取 1（若个位为 3-9 则取 0），小时个位在十位为 1 时最大取 2 否则取 9，分钟十位最大取 5，分钟个位最大取 9。

## Java 代码实现

```java
class Solution {
    public String findLatestTime(String s) {
        char[] c = s.toCharArray();
        if (c[0] == '?') c[0] = (c[1] == '?' || c[1] <= '2') ? '1' : '0';
        if (c[1] == '?') c[1] = (c[0] == '1') ? '2' : '9';
        if (c[3] == '?') c[3] = '5';
        if (c[4] == '?') c[4] = '9';
        return new String(c);
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 小时十位为 1 时，个位最大为 2（即 12）
2. 12 小时制小时从 01 开始，不存在 00
