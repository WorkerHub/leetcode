## 题目描述

给你一个二进制字符串 `s`，可以旋转（将首字符移到末尾）或翻转字符，返回使字符串变为交替字符串所需的最少翻转次数。

## 解题思路

旋转操作等价于在 `s+s` 中选长度为 n 的窗口。对两种目标字符串（0开头、1开头）分别用滑动窗口统计不匹配数，取最小值。

## Java 代码实现

```java
class Solution {
    public int minFlips(String s) {
        int n = s.length();
        String ss = s + s; // 循环展开

        int diff1 = 0, diff2 = 0; // 与两种目标的不匹配数
        // 初始化窗口
        for (int i = 0; i < n; i++) {
            int c = ss.charAt(i) - '0';
            if (c != i % 2) diff1++;       // 目标1：偶数位0，奇数位1
            if (c != 1 - i % 2) diff2++;   // 目标2：偶数位1，奇数位0
        }

        int result = Math.min(diff1, diff2);
        // 滑动窗口
        for (int i = n; i < 2 * n; i++) {
            int newC = ss.charAt(i) - '0';
            int oldC = ss.charAt(i - n) - '0';
            // 加入新位
            if (newC != i % 2) diff1++;
            if (newC != 1 - i % 2) diff2++;
            // 移出旧位
            if (oldC != (i - n) % 2) diff1--;
            if (oldC != 1 - (i - n) % 2) diff2--;
            result = Math.min(result, Math.min(diff1, diff2));
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，扩展字符串

## 关键点总结

1. 循环移位等价于在 `s+s` 中选长度为 n 的窗口
2. 对两种目标字符串（0开头和1开头）分别统计不匹配数
3. 新位的目标值基于全局位置 `i % 2`，不是窗口内相对位置
