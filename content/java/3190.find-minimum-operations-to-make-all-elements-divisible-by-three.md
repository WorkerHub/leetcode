## 题目描述

给你整数数组 `nums`，每次操作可将任意元素加 1 或减 1，返回使所有元素均能被 3 整除的最少操作次数。

## 解题思路

对每个元素取模 3：余数为 0 不需要操作，余数为 1（减 1）或余数为 2（加 1）均只需 1 次操作。统计余数非 0 的元素数即为答案。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[] nums) {
        int ans = 0;
        for (int x : nums) {
            if (x % 3 != 0) ans++; // 余数 1 或 2，各需 1 次操作
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 余数为 1 减 1，余数为 2 加 1，均只需 1 次操作
2. 统计余数不为 0 的元素个数即为答案
