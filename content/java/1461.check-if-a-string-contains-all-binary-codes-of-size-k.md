## 题目描述

给你一个二进制字符串 `s` 和一个整数 `k`。

如果所有长度为 `k` 的二进制字符串都是 `s` 的子串，请返回 `True`，否则请返回 `False`。

**示例 1：**
```
输入：s = "00110110", k = 2
输出：true
解释：长度为 2 的二进制串共有 4 种："00", "01", "10", "11"，它们全部是 s 的子串。
```

**示例 2：**
```
输入：s = "0110", k = 1
输出：true
解释：长度为 1 的二进制串共有 2 种："0", "1"，它们全部是 s 的子串。
```

**示例 3：**
```
输入：s = "0110", k = 2
输出：false
解释：长度为 2 的二进制串共有 4 种，而 s 只有 "01"、"11"、"10"，缺少 "00"。
```

**提示：**
- `1 <= s.length <= 5 * 10^5`
- `s[i]` 不是 `'0'` 就是 `'1'`
- `1 <= k <= 20`

## 解题思路

长度为 k 的二进制字符串共有 `2^k` 种，我们需要检查 s 中是否包含全部这些子串。

**方法一：滑动窗口 + 哈希集合**

用滑动窗口遍历 s 中所有长度为 k 的子串，存入集合中。最后检查集合大小是否等于 `2^k`。

**方法二：位运算优化（滚动哈希）**

将每个二进制子串转为整数（利用位运算滚动更新），减少重复计算：
- 新窗口 = `((旧窗口 << 1) | 新字符) & ((1 << k) - 1)`

将所有整数存入布尔数组，最后检查是否全部出现。

## Java 代码实现

### 方法一：滑动窗口 + 集合（推荐，直观）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean hasAllCodes(String s, int k) {
        int n = s.length();
        int need = 1 << k;  // 需要 2^k 种子串

        // 字符串长度不够包含所有子串，直接返回 false
        if (n - k + 1 < need) return false;

        Set<String> seen = new HashSet<>();
        for (int i = 0; i <= n - k; i++) {
            // 截取长度为 k 的子串并加入集合
            String sub = s.substring(i, i + k);
            seen.add(sub);
            // 提前终止：已经找到所有子串
            if (seen.size() == need) return true;
        }

        return seen.size() == need;
    }
}
```

### 方法二：位运算滚动哈希（优化版）

```java
class Solution {
    public boolean hasAllCodes(String s, int k) {
        int n = s.length();
        int need = 1 << k;  // 2^k

        if (n - k + 1 < need) return false;

        // 用布尔数组代替集合，节省空间
        boolean[] got = new boolean[need];
        // 掩码：保留低 k 位
        int mask = need - 1;
        // 计算第一个窗口的值
        int cur = Integer.parseInt(s.substring(0, k), 2);
        got[cur] = true;
        int count = 1;  // 已找到的不同子串数

        for (int i = k; i < n; i++) {
            // 滚动更新：移出最高位，加入新字符
            cur = ((cur << 1) | (s.charAt(i) - '0')) & mask;

            if (!got[cur]) {
                got[cur] = true;
                count++;
                if (count == need) return true;
            }
        }

        return count == need;
    }
}
```

### 方法三：位运算初始化窗口（避免 parseInt）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean hasAllCodes(String s, int k) {
        int n = s.length();
        int need = 1 << k;
        if (n - k + 1 < need) return false;

        boolean[] got = new boolean[need];
        int mask = need - 1;
        int cur = 0;

        // 初始化第一个窗口（逐位累加）
        for (int i = 0; i < k; i++) {
            cur = (cur << 1) | (s.charAt(i) - '0');
        }
        got[cur] = true;
        int count = 1;

        for (int i = k; i < n; i++) {
            cur = ((cur << 1) | (s.charAt(i) - '0')) & mask;
            if (!got[cur]) {
                got[cur] = true;
                count++;
                if (count == need) return true;
            }
        }

        return count == need;
    }
}
```

## 复杂度分析

**方法一（集合）：**
- 时间复杂度：O(n × k)，每次截取子串 O(k)，共 O(n) 次
- 空间复杂度：O(2^k × k)，集合中存储字符串

**方法二（位运算）：**
- 时间复杂度：O(n)，每次滚动更新 O(1)
- 空间复杂度：O(2^k)，布尔数组

## 关键点总结

1. 长度为 k 的二进制串共 `2^k` 种，这是目标数量
2. 字符串长度不足 `2^k + k - 1` 时，直接返回 false（不够放所有子串）
3. 位运算滚动哈希：`cur = ((cur << 1) | new_bit) & mask`，每次 O(1) 更新
4. 布尔数组代替集合可以减少哈希开销

## 易错点

- 注意 k 最大为 20，`2^20 = 1,048,576`，布尔数组的大小是可接受的
- Java 中 `s.charAt(i) - '0'` 将字符 '0'/'1' 转换为整数 0/1
- 提前终止优化很重要：找到所有子串后立即返回
