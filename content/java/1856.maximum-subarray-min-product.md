## 题目描述

数组的最小乘积=最小值×总和。求所有子数组中最大的最小乘积，结果对10^9+7取模。

## 解题思路

单调栈+前缀和：对每个元素找以其为最小值的最大子数组（左右第一个更小元素位置），用前缀和算子数组总和。

## Java 代码实现

```java
class Solution {
    public int maxSumMinProduct(int[] nums) {
        int MOD = 1_000_000_007;
        int n = nums.length;
        
        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        
        // 单调递增栈求左边界
        int[] left = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] >= nums[i]) stack.pop();
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }
        
        // 求右边界
        int[] right = new int[n];
        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && nums[stack.peek()] >= nums[i]) stack.pop();
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }
        
        // 计算最大最小乘积
        long ans = 0;
        for (int i = 0; i < n; i++) {
            long sum = prefix[right[i]] - prefix[left[i] + 1];
            ans = Math.max(ans, (long) nums[i] * sum);
        }
        return (int)(ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **单调递增栈**：找左右第一个严格小的元素位置
2. **前缀和**：O(1)计算子数组总和
3. **long防溢出**：乘积可能很大，最后取模
