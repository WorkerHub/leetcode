## 题目描述

给你一个字符串 `s` 和一组配对下标 `pairs`，`pairs[i] = [a, b]` 表示可以交换 `s[a]` 和 `s[b]`（可重复任意次）。返回交换后字典序最小的字符串。

## 解题思路

并查集找连通分量，同一连通分量内的字符可以任意排列。对每个分量的字符排序后按原下标顺序填入。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent;

    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 合并所有配对
        for (List<Integer> p : pairs) {
            union(p.get(0), p.get(1));
        }

        // 按连通分量分组
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = find(i);
            groups.computeIfAbsent(root, k -> new ArrayList<>()).add(i);
        }

        char[] result = s.toCharArray();
        for (List<Integer> group : groups.values()) {
            // 提取字符并排序
            char[] chars = new char[group.size()];
            for (int i = 0; i < group.size(); i++) chars[i] = s.charAt(group.get(i));
            Arrays.sort(chars);
            Collections.sort(group);
            // 按原下标顺序填入排序后的字符
            for (int i = 0; i < group.size(); i++) result[group.get(i)] = chars[i];
        }

        return new String(result);
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + E) * alpha(n) + n log n)
- 空间复杂度：O(n + E)

## 关键点总结

1. 交换是可传递的，用并查集找连通分量
2. 每个分量内字符可任意排列，排序后按原下标顺序填入
3. 分量内下标需排序保证字典序最小
