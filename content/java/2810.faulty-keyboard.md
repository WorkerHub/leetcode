## 题目描述

输入字符 `'i'` 时翻转屏幕上的当前内容，其他字符追加到末尾，给你字符串 `s`，返回最终屏幕内容。

## Java 代码实现

```java
class Solution {
    public String finalString(String s) {
        StringBuilder sb = new StringBuilder();
        for (char ch : s.toCharArray()) {
            if (ch == 'i') {
                sb.reverse(); // 翻转当前内容
            } else {
                sb.append(ch);
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，每次 reverse 为 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `StringBuilder.reverse()` 原地翻转，直接使用
2. 遍历每个字符，`'i'` 触发翻转，其余追加
