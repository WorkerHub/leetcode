## 题目描述

定义 `rev(x)` 为 x 各位数字反转后的值。给你数组 `nums`，返回满足 `nums[i] + rev(nums[j]) == nums[j] + rev(nums[i])` 的下标对 (i < j) 数目，对 10^9+7 取余。

## 解题思路

等式等价于 `nums[i] - rev(nums[i]) == nums[j] - rev(nums[j])`。令 `diff[i] = nums[i] - rev(nums[i])`，用 HashMap 统计每个 diff 值出现次数 k，贡献 `k*(k-1)/2` 对。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countNicePairs(int[] nums) {
        final int MOD = 1_000_000_007;
        Map<Integer, Long> cnt = new HashMap<>();

        for (int x : nums) {
            int d = x - rev(x);
            cnt.merge(d, 1L, Long::sum);
        }

        long result = 0;
        for (long k : cnt.values()) {
            result = (result + k * (k - 1) / 2) % MOD;
        }

        return (int) result;
    }

    private int rev(int x) {
        int r = 0;
        while (x > 0) {
            r = r * 10 + x % 10;
            x /= 10;
        }
        return r;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * d)，d 为数字位数
- **空间复杂度**：O(n)

## 关键点总结

1. 变形等式为 `diff[i] == diff[j]`，转化为统计问题
2. 相同 diff 值 k 个元素，配对数 `C(k,2) = k*(k-1)/2`
