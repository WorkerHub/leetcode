## 题目描述

用numCarpets块长度为carpetLen的地毯覆盖地板，求最少剩余可见白色瓷砖数。

## 解题思路

DP：dp[i][j]表示前i格用j块地毯的最少白色数。转移：不覆盖第i格(dp[i-1][j]+white[i])，或用一块地毯覆盖到第i格(dp[max(0,i-len)][j-1])。

## Java 代码实现

```java
class Solution {
    public int minimumWhiteTiles(String floor, int numCarpets, int carpetLen) {
        int n = floor.length();
        // 截断无效地毯数
        numCarpets = Math.min(numCarpets, (n + carpetLen - 1) / carpetLen);
        
        // dp[j] = 前i格用j块地毯最少白色数（滚动数组）
        int[][] dp = new int[n + 1][numCarpets + 1];
        
        for (int i = 1; i <= n; i++) {
            int white = floor.charAt(i - 1) - '0';
            for (int j = 0; j <= numCarpets; j++) {
                // 不覆盖第i格
                dp[i][j] = dp[i - 1][j] + white;
                // 用一块地毯覆盖到第i格结尾
                if (j > 0) {
                    int prev = Math.max(0, i - carpetLen);
                    dp[i][j] = Math.min(dp[i][j], dp[prev][j - 1]);
                }
            }
        }
        return dp[n][numCarpets];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * min(numCarpets, N/carpetLen))
- **空间复杂度**：O(N * numCarpets)

## 关键点总结

1. **截断地毯数**：超过ceil(n/len)块无意义
2. **DP转移两种选择**：露出当前格或用地毯覆盖到当前格
3. **覆盖范围**：从i-carpetLen+1到i，转移到dp[max(0,i-carpetLen)][j-1]
