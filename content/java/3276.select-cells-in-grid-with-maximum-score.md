## 题目描述

给你 `m×n` 矩阵 `grid`（`m,n≤10`，值≤100），选若干格子使每行最多选 1 个且所有选中值互不相同，返回最大总和。

## 解题思路

状态压缩 DP：`dp[mask]` 表示已使用 mask 中的行（位 i 为 1 表示第 i 行已选）时能获得的最大总和。按值从大到小枚举，对每个值选择用哪行（该行含此值且尚未使用）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxScore(int[][] grid) {
        int m = grid.length;
        // 对每个值，记录含该值的行集合（bitmask）
        Map<Integer, Integer> valRows = new HashMap<>();
        for (int i = 0; i < m; i++) {
            for (int val : grid[i]) {
                valRows.merge(val, 1 << i, (a, b) -> a | b);
            }
        }

        // dp[mask] = 已使用 mask 中各行，选了若干互不相同值的最大总和
        int[] dp = new int[1 << m];

        // 按值从大到小处理
        List<Integer> vals = new ArrayList<>(valRows.keySet());
        vals.sort(Collections.reverseOrder());

        for (int val : vals) {
            int rowMask = valRows.get(val);
            int[] newDp = dp.clone();
            for (int mask = 0; mask < (1 << m); mask++) {
                if (dp[mask] == 0 && mask != 0) continue; // 剪枝
                int available = rowMask & ~mask; // 含该值且未使用的行
                for (int avail = available; avail != 0; avail &= avail - 1) {
                    int lsb = avail & (-avail); // 取最低位代表的行
                    int newMask = mask | lsb;
                    newDp[newMask] = Math.max(newDp[newMask], dp[mask] + val);
                }
            }
            dp = newDp;
        }

        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(V × 2^m)，V 为不同值数量（≤100），2^m ≤ 1024
- 空间复杂度：O(2^m)

## 关键点总结

1. 对每个值记录其出现的行集合（bitmask），避免重复行
2. 按值从大到小处理，保证每个值最多被选一次
3. 枚举 `available` 的子集时用 `avail &= avail - 1` 逐一取位
