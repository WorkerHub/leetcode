## 题目描述

给你长度为 `n` 的数组 `pref`，其中 `pref[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]`，求原始数组 `arr`。

## 解题思路

利用 XOR 的性质：`arr[0] = pref[0]`，`arr[i] = pref[i] ^ pref[i-1]`（i >= 1）。对前缀异或数组做差分即可还原原数组。

## Java 代码实现

```java
class Solution {
    public int[] findArray(int[] pref) {
        int n = pref.length;
        int[] arr = new int[n];
        arr[0] = pref[0]; // 第一个元素直接取
        for (int i = 1; i < n; i++) {
            // arr[i] = pref[i] XOR pref[i-1]
            arr[i] = pref[i] ^ pref[i - 1];
        }
        return arr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)（输出数组）

## 关键点总结

1. XOR 的逆运算还是 XOR：`a ^ b = c` 则 `a = b ^ c`
2. `arr[i] = pref[i] ^ pref[i-1]` 是前缀异或的差分公式
3. 第一个元素直接等于 `pref[0]`
