## 题目描述

给你一个整数数组 `nums`，每次可以选一个非空连续子数组移除，得分为子数组所有元素的乘积，返回多次操作可获得的最大总得分。

## 解题思路

状态压缩 DP：`dp[mask]` 表示已移除 mask 对应元素后的最大得分。枚举当前剩余元素中的连续子数组（在原数组中连续）进行移除，取最大值。

## Java 代码实现

```java
class Solution {
    public int maximumPoints(int[] nums) {
        int n = nums.length;

        // 预计算每个连续区间的乘积
        int[][] prod = new int[n][n];
        for (int i = 0; i < n; i++) {
            prod[i][i] = nums[i];
            for (int j = i + 1; j < n; j++) {
                prod[i][j] = prod[i][j - 1] * nums[j];
            }
        }

        // dp[mask] = 已移除 mask 中元素后的最大得分
        int[] dp = new int[1 << n];

        for (int mask = 0; mask < (1 << n); mask++) {
            // 找出 mask 中剩余（未移除）的元素
            // 枚举剩余元素中的连续子数组（在原数组中下标连续）
            int i = 0;
            while (i < n) {
                // 跳过已移除的元素
                if ((mask >> i & 1) == 1) {
                    i++;
                    continue;
                }
                // 找以 i 开头的连续段
                int j = i;
                while (j < n && (mask >> j & 1) == 0) {
                    // 移除 [i, j] 这段
                    int newMask = mask;
                    for (int k = i; k <= j; k++) {
                        newMask |= (1 << k);
                    }
                    dp[newMask] = Math.max(dp[newMask], dp[mask] + prod[i][j]);
                    j++;
                }
                i++;
            }
        }

        // 找所有状态的最大值
        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n^2)，状态数 2^n，每个状态枚举 O(n^2) 个连续子数组
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 20，状态压缩 DP 可行（2^20 约 100 万）。
2. 每次操作移除的必须是当前剩余数组中在原数组下标连续的子数组。
3. 预计算区间乘积避免重复计算。
