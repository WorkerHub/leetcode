## 题目描述

n×n 二进制网格，每次可交换相邻行。要求第 i 行末尾至少有 n-1-i 个 0（上三角矩阵）。返回最少交换次数，无法完成返回 -1。

**示例：**
```
输入：grid = [[0,0,1],[1,1,0],[1,0,0]]
输出：3
```

## 解题思路

贪心：统计每行末尾连续 0 的数量，对每行 i 从下方找第一个满足条件的行冒泡到当前位置。

## Java 代码实现

```java
class Solution {
    public int minSwaps(int[][] grid) {
        int n = grid.length;
        // 计算每行末尾连续 0 的数量
        int[] tailZeros = new int[n];
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = n - 1; j >= 0; j--) {
                if (grid[i][j] == 0) count++;
                else break;
            }
            tailZeros[i] = count;
        }
        
        int swaps = 0;
        for (int i = 0; i < n; i++) {
            int need = n - 1 - i;
            if (need == 0) continue;
            // 找满足条件的最近行
            int pos = -1;
            for (int j = i; j < n; j++) {
                if (tailZeros[j] >= need) {
                    pos = j;
                    break;
                }
            }
            if (pos == -1) return -1;
            // 冒泡到位
            swaps += pos - i;
            for (int j = pos; j > i; j--) {
                tailZeros[j] = tailZeros[j - 1];
            }
            tailZeros[i] = need;
        }
        return swaps;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：每行找最近的满足条件的行冒泡到位
2. **末尾 0 计数**：第 i 行需要末尾至少 n-1-i 个 0
3. **相邻交换**：只能交换相邻行，次数 = 距离
