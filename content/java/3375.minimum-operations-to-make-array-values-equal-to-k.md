## 题目描述

给你一个整数数组 `nums` 和整数 `k`，每次操作可将所有严格大于某值 `h` 的元素设为 `h`。返回使所有元素等于 `k` 的最少操作次数，若有元素 < k 则返回 -1。

## 解题思路

若有任意 `nums[i] < k`，操作只能减小元素，无法增大，返回 -1。每次操作消灭一个"层级"，操作次数等于数组中严格大于 `k` 的不同值的个数。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minOperations(int[] nums, int k) {
        Set<Integer> greater = new HashSet<>();
        for (int x : nums) {
            if (x < k) return -1; // 无法增大，无解
            if (x > k) greater.add(x); // 统计大于 k 的不同值
        }
        return greater.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 若有 `nums[i] < k`，立即返回 -1。
2. 每次操作消灭一个大于 k 的层级，操作次数 = 大于 k 的不同值个数。
3. 等于 k 的元素无需操作。
