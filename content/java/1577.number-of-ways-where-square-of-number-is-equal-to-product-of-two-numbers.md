## 题目描述

统计满足 nums1[i]²==nums2[j]*nums2[k] (j<k) 的三元组数（类型1），加上满足 nums2[i]²==nums1[j]*nums1[k] (j<k) 的三元组数（类型2）。

**提示：** 数组长度 ≤ 1000

## 解题思路

哈希表：对每个 x²，在另一数组中枚举因子对。两因子相等用组合数，不等用乘积。

## Java 代码实现

```java
class Solution {
    public int numTriplets(int[] nums1, int[] nums2) {
        return countType(nums1, nums2) + countType(nums2, nums1);
    }
    
    private int countType(int[] a, int[] b) {
        // 统计 a[i]² == b[j]*b[k] (j<k) 的三元组数
        int count = 0;
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : b) freq.merge(x, 1, Integer::sum);
        
        for (int x : a) {
            long target = (long)x * x;
            Set<Integer> seen = new HashSet<>();
            for (int val : freq.keySet()) {
                if (target % val == 0 && !seen.contains(val)) {
                    long other = target / val;
                    if (other > Integer.MAX_VALUE) continue;
                    int otherInt = (int)other;
                    if (!freq.containsKey(otherInt)) continue;
                    seen.add(val);
                    seen.add(otherInt);
                    if (val == otherInt) {
                        int c = freq.get(val);
                        count += c * (c - 1) / 2;
                    } else {
                        count += freq.get(val) * freq.get(otherInt);
                    }
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × M)（最坏情况）
- **空间复杂度**：O(M)

## 关键点总结

1. **对称结构**：两种类型复用同一函数
2. **用 long**：x² 可能溢出 int
3. **去重**：seen 集合避免重复计算因子对
