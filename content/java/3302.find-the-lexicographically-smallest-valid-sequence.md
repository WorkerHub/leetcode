## 题目描述

给你字符串 `word1` 和 `word2`，找字典序最小的下标序列（严格递增），使得对应字符相等，至多一处例外（例外处 `word1[i]+1 == word2[i]`，即字母表下一个字母）。不存在返回空数组。

## 解题思路

后缀预处理 + 贪心：`suffix[i]` = 从 `word1[i]` 起向后能从 `word2` 末尾向前匹配的字符数。从左遍历 `word1`，贪心选最小下标：完全匹配时直接选；否则检查能否在此处使用一次特例（`word1[i]+1 == word2[j]` 且 `suffix[i+1] >= m-j-1`）。

## Java 代码实现

```java
class Solution {
    public int[] validSequence(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        // suffix[i]: 从 word1[i] 往后，从 word2 末尾往前能匹配的字符数
        int[] suffix = new int[n + 1];
        int j = m - 1;
        for (int i = n - 1; i >= 0; i--) {
            if (j >= 0 && word1.charAt(i) == word2.charAt(j)) {
                suffix[i] = suffix[i + 1] + 1;
                j--;
            } else {
                suffix[i] = suffix[i + 1];
            }
        }

        int[] result = new int[m];
        j = 0;
        boolean usedException = false;
        int idx = 0;

        for (int i = 0; i < n && j < m; i++) {
            if (word1.charAt(i) == word2.charAt(j)) {
                // 完全匹配，选取该下标
                result[idx++] = i;
                j++;
            } else if (!usedException) {
                // 检查能否在此使用一次特例
                if (word2.charAt(j) - word1.charAt(i) == 1
                        && suffix[i + 1] >= m - j - 1) {
                    result[idx++] = i;
                    j++;
                    usedException = true;
                }
            }
        }

        return j == m ? result : new int[0];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n)

## 关键点总结

1. 后缀数组预处理：`suffix[i]` 表示从 `word1[i]` 起能从 `word2` 末尾反向匹配的长度
2. 贪心：尽量选最小下标以保证字典序最小
3. 特例条件：差一个字母 + 后缀能覆盖剩余字符（`suffix[i+1] >= m-j-1`）
