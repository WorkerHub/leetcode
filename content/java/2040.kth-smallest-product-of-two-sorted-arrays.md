## 题目描述

给定两个升序排列的整数数组 `nums1` 和 `nums2`，从各取一个元素组成乘积，返回第 k 小的乘积。

## 解题思路

二分乘积值 x，统计 `nums1[i]*nums2[j] <= x` 的对数 count(x)，找使 count(x) >= k 的最小 x。对每个 nums1[i] 分正/负/零三种情况在 nums2 中二分统计。

## Java 代码实现

### 方法一：二分答案 + 分类讨论（推荐）

```java
import java.util.Arrays;

class Solution {
    public long kthSmallestProduct(int[] nums1, int[] nums2, long k) {
        int n2 = nums2.length;

        long lo = (long) -1e10, hi = (long) 1e10;
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (countLE(nums1, nums2, mid) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private long countLE(int[] nums1, int[] nums2, long x) {
        long cnt = 0;
        int n2 = nums2.length;
        for (int a : nums1) {
            if (a == 0) {
                if (x >= 0) cnt += n2; // 乘积全为0
            } else if (a > 0) {
                // a * b <= x => b <= x / a
                // 在nums2中找最右边 <= floor(x/a) 的位置
                cnt += upperBound(nums2, floorDiv(x, a));
            } else {
                // a < 0: a * b <= x => b >= ceil(x / a)
                cnt += n2 - lowerBound(nums2, ceilDiv(x, a));
            }
        }
        return cnt;
    }

    // 向下取整除法（向负无穷）
    private long floorDiv(long x, long a) {
        return Math.floorDiv(x, a);
    }

    // 向上取整除法（向正无穷）
    private long ceilDiv(long x, long a) {
        // a < 0 时：ceil(x/a) = floor(x/a) 如果整除，否则 floor(x/a) + 1 ... 
        // 用 Math.floorDiv(-x, -a) 因为 a < 0
        return -Math.floorDiv(-x, a); // ceil(x/a) = -floor(-x/a)
    }

    // nums2 中 <= val 的个数（upper_bound 位置）
    private int upperBound(int[] arr, long val) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] <= val) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    // nums2 中 >= val 的第一个位置（lower_bound）
    private int lowerBound(int[] arr, long val) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] < val) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O((m + n) * log V)，V 约为 10^10
- 空间复杂度：O(1)

## 关键点总结

1. 二分乘积值，统计 <= x 的乘积对数
2. 正数、负数、零三种情况分别处理（乘以负数不等号反向）
3. 使用 `Math.floorDiv` 保证向下取整语义（Java 整数除法向零取整）
