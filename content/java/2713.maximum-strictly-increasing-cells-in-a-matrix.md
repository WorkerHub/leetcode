## 题目描述

给你 `m x n` 整数矩阵 `mat`，从任意格子出发，每步可移动到同行或同列中值严格更大的格子，返回最长路径的格子数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxIncreasingCells(int[][] mat) {
        int m = mat.length, n = mat[1].length;
        // 按值分组收集坐标
        TreeMap<Integer, List<int[]>> groups = new TreeMap<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                groups.computeIfAbsent(mat[i][j], k -> new ArrayList<>()).add(new int[]{i, j});
            }
        }

        int[][] dp = new int[m][n];
        int[] rowBest = new int[m]; // 每行当前最优 dp 值
        int[] colBest = new int[n]; // 每列当前最优 dp 值

        for (List<int[]> cells : groups.values()) {
            // 先计算同组所有格子的新 dp 值（避免同值格子互相影响）
            int[] newVals = new int[cells.size()];
            for (int idx = 0; idx < cells.size(); idx++) {
                int r = cells.get(idx)[0], c = cells.get(idx)[1];
                newVals[idx] = 1 + Math.max(rowBest[r], colBest[c]);
            }
            // 再统一更新 dp 和 rowBest/colBest
            for (int idx = 0; idx < cells.size(); idx++) {
                int r = cells.get(idx)[0], c = cells.get(idx)[1];
                dp[r][c] = newVals[idx];
                rowBest[r] = Math.max(rowBest[r], dp[r][c]);
                colBest[c] = Math.max(colBest[c], dp[r][c]);
            }
        }

        int ans = 0;
        for (int[] row : dp) for (int v : row) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. 按值从小到大处理，用 `rowBest[]` 和 `colBest[]` 记录各行列最优 dp 值
2. 同值格子必须先全部计算新值，再统一更新，避免同值格子相互转移
3. `dp[r][c] = 1 + max(rowBest[r], colBest[c])`
