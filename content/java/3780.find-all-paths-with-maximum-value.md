## 题目描述

给定有向无环图（DAG），节点 `0` 到 `n-1`，每个节点有权值 `vals[i]`，求从节点 `0` 到节点 `n-1` 的所有路径中节点权值之和的最大值。

## 解题思路

DAG 上的最长路径：记忆化 DFS，`dp[u]` 表示从节点 `u` 到终点 `n-1` 的最大权值和（含 `u`）。转移为 `dp[u] = vals[u] + max(dp[v])` 对所有出边 `(u, v)`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<List<Integer>> graph;
    private int[] dp;
    private int n;

    public int maxPathValue(int n, int[][] edges, int[] vals) {
        this.n = n;
        graph = new ArrayList<>();
        dp = new int[n];
        Arrays.fill(dp, -1);

        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) graph.get(e[0]).add(e[1]);

        dp[n - 1] = vals[n - 1];
        int result = dfs(0, vals);
        return result == Integer.MIN_VALUE ? -1 : result;
    }

    private int dfs(int u, int[] vals) {
        if (dp[u] != -1) return dp[u];
        if (graph.get(u).isEmpty()) {
            dp[u] = Integer.MIN_VALUE; // 无法到达终点
            return dp[u];
        }
        int best = Integer.MIN_VALUE;
        for (int v : graph.get(u)) {
            int sub = dfs(v, vals);
            if (sub != Integer.MIN_VALUE) best = Math.max(best, sub);
        }
        dp[u] = best == Integer.MIN_VALUE ? Integer.MIN_VALUE : vals[u] + best;
        return dp[u];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. DAG 最大权值路径用记忆化 DFS，每个节点只计算一次
2. 无法到达终点的节点标记为 `MIN_VALUE` 防止误计
3. 终点的 dp 值直接初始化为 `vals[n-1]`
