## 题目描述

给你一棵二叉树的根节点 `root`，返回树的**最大宽度**。

树的**最大宽度**是所有层中最大的**宽度**。

每一层的**宽度**被定义为该层最左和最右的非空节点（即，两个端点）之间的长度。将这个二叉树视作与满二叉树结构相同，两端点间会出现一些延伸到这一层的 `null` 节点，这些 `null` 节点也计入长度。

题目数据保证答案将会在 **32 位有符号整数**范围内。

**示例 1:**

```
输入：root = [1,3,2,5,3,null,9]
输出：4
解释：最大宽度出现在树的第 3 层，宽度为 4 (5,3,null,9)。
```

**示例 2:**

```
输入：root = [1,3,2,5,null,null,9,6,null,7]
输出：7
解释：最大宽度出现在树的第 4 层，宽度为 7 (6,null,null,null,null,null,7)。
```

**示例 3:**

```
输入：root = [1,3,2,5]
输出：2
解释：最大宽度出现在树的第 2 层，宽度为 2 (5,3)。
```

**提示:**
- 树中节点的数目范围是 `[1, 3000]`
- `-100 <= Node.val <= 100`

## 解题思路

这道题的关键是给每个节点**编号**，就像完全二叉树的编号规则：

### 核心思想

**完全二叉树的编号规则：**
- 根节点编号为 0（或 1）
- 对于编号为 `i` 的节点：
  - 左子节点编号为 `2 * i`
  - 右子节点编号为 `2 * i + 1`

**计算宽度：**
- 每一层的宽度 = 最右节点编号 - 最左节点编号 + 1

### 解法选择

1. **BFS（层序遍历）**：逐层计算宽度
2. **DFS（深度优先）**：记录每层的最左和最右节点编号

## Java 代码实现

### 方法一：BFS 层序遍历（推荐）

```java
import java.util.*;

class Solution {
    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;

        int maxWidth = 0;
        // 队列存储 [节点, 编号]，使用两个队列分别存储
        Queue<TreeNode> nodeQueue = new LinkedList<>();
        Queue<Integer> indexQueue = new LinkedList<>();

        nodeQueue.offer(root);
        indexQueue.offer(0);

        while (!nodeQueue.isEmpty()) {
            int levelSize = nodeQueue.size();
            int leftIndex = indexQueue.peek(); // 当前层最左编号
            int rightIndex = 0;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = nodeQueue.poll();
                int index = indexQueue.poll();
                rightIndex = index; // 更新最右编号

                // 添加子节点，注意归一化防止溢出
                if (node.left != null) {
                    nodeQueue.offer(node.left);
                    indexQueue.offer(2 * (index - leftIndex));
                }
                if (node.right != null) {
                    nodeQueue.offer(node.right);
                    indexQueue.offer(2 * (index - leftIndex) + 1);
                }
            }

            // 计算当前层宽度
            maxWidth = Math.max(maxWidth, rightIndex - leftIndex + 1);
        }

        return maxWidth;
    }
}
```

### 方法二：DFS 深度优先

```java
import java.util.*;

class Solution {
    private int maxWidth = 0;
    private Map<Integer, Integer> leftMost = new HashMap<>(); // depth -> 最左编号

    public int widthOfBinaryTree(TreeNode root) {
        dfs(root, 0, 0);
        return maxWidth;
    }

    private void dfs(TreeNode node, int depth, int index) {
        if (node == null) return;

        // 如果是这一层第一个访问的节点，记录为最左
        if (!leftMost.containsKey(depth)) {
            leftMost.put(depth, index);
        }

        // 计算当前层的宽度
        int width = index - leftMost.get(depth) + 1;
        maxWidth = Math.max(maxWidth, width);

        // 递归处理左右子树
        dfs(node.left, depth + 1, 2 * index);
        dfs(node.right, depth + 1, 2 * index + 1);
    }
}
```

### 方法三：BFS 简洁版（使用 long 防止溢出）

```java
import java.util.*;

class Solution {
    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;

        long maxWidth = 0;
        // 使用 Deque 存储 (节点, 编号) 对
        Deque<long[]> queue = new ArrayDeque<>(); // [节点指针, 编号] 不能直接存节点
        // 用两个队列分别存
        Deque<TreeNode> nodeDeque = new ArrayDeque<>();
        Deque<Long> indexDeque = new ArrayDeque<>();

        nodeDeque.offer(root);
        indexDeque.offer(0L);

        while (!nodeDeque.isEmpty()) {
            int size = nodeDeque.size();
            long left = indexDeque.peekFirst();
            long right = 0;

            for (int i = 0; i < size; i++) {
                TreeNode node = nodeDeque.poll();
                long idx = indexDeque.poll();
                right = idx;

                if (node.left != null) {
                    nodeDeque.offer(node.left);
                    indexDeque.offer(2 * idx);
                }
                if (node.right != null) {
                    nodeDeque.offer(node.right);
                    indexDeque.offer(2 * idx + 1);
                }
            }

            maxWidth = Math.max(maxWidth, right - left + 1);
        }

        return (int) maxWidth;
    }
}
```

## 复杂度分析

### 方法一/二/三
- **时间复杂度**：O(n)，访问每个节点一次
- **空间复杂度**：O(h)，h 为树高
  - BFS：队列最多存储一层的节点，最坏 O(n)
  - DFS：递归栈深度 O(h)

## 关键点总结

1. **节点编号**：使用完全二叉树的编号规则
2. **宽度计算**：最右编号 - 最左编号 + 1
3. **BFS vs DFS**：都可以，BFS 更直观
4. **防止溢出**：可以每层重新归一化编号，或使用 long
5. **初始编号**：可以从 0 或 1 开始，保持一致即可

## 易错点

1. **编号规则**：
   ```java
   // 从 0 开始：左子节点 2*i，右子节点 2*i+1
   nodeQueue.offer(node.left);
   indexQueue.offer(2 * index);
   nodeQueue.offer(node.right);
   indexQueue.offer(2 * index + 1);
   ```

2. **宽度公式**：
   ```java
   // 包含两端
   width = rightIndex - leftIndex + 1; // 不要忘记 +1
   ```

3. **层的识别**：
   ```java
   // BFS 要记录每层的大小
   int levelSize = nodeQueue.size();
   ```

4. **溢出问题**：
   ```java
   // 深树可能导致编号溢出
   // 解决：每层归一化（减去最左编号）或使用 long
   int normalizedIndex = 2 * (index - leftIndex); // 归一化
   ```

**常见问题：**

Q: 为什么要用编号而不是实际位置？
A: 编号可以准确反映节点在满二叉树中的位置，包括 null 节点。

Q: 编号会溢出吗？
A: 在深树情况下可能，可以每层归一化（减去最左编号）或使用 long 类型。

Q: BFS 和 DFS 哪个更好？
A: BFS 更符合"层"的概念，代码也更直观。
