## 题目描述

给你一个 `m x n` 的矩阵 `grid`，其中部分格子有值（正整数），其余为 0。每次操作可以选择一行或一列，将其中所有 0 替换为该行/列的最大值。返回填满所有 0 所需的最少操作次数。

## 解题思路

贪心：统计有 0 的行数和有 0 的列数，取两者的最小值。只用行操作（每有 0 的行操作一次）或只用列操作（每有 0 的列操作一次），选代价较小的方案。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 统计有 0 的行数
        int rowOps = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 0) { rowOps++; break; }
            }
        }

        // 统计有 0 的列数
        int colOps = 0;
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                if (grid[i][j] == 0) { colOps++; break; }
            }
        }

        // 取操作次数较少的方向
        return Math.min(rowOps, colOps);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 行操作可以填满整行的 0（1 次操作），列操作可以填满整列的 0（1 次操作）。
2. 最优策略：选操作次数（有 0 的行数 vs 有 0 的列数）较少的方向。
3. 混合策略在一般情况下不优于单纯行或列操作。
