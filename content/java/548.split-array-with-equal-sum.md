## 题目描述

找到三个索引 i, j, k，将数组分成四段和相等的部分（分割点本身不计入任何段）。

**示例：**
```
输入：nums = [1,2,1,2,1,2,1]
输出：true
```

## 解题思路

前缀和 + 固定中间分割点 j，用 HashSet 存储左侧等和，右侧查找匹配。

## Java 代码实现

```java
class Solution {
    public boolean splitArray(int[] nums) {
        int n = nums.length;
        if (n < 7) return false;

        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        // 枚举中间分割点 j
        for (int j = 3; j < n - 3; j++) {
            Set<Integer> leftSums = new HashSet<>();

            // 左侧找 i
            for (int i = 1; i < j - 1; i++) {
                int sum1 = prefix[i];
                int sum2 = prefix[j] - prefix[i + 1];
                if (sum1 == sum2) {
                    leftSums.add(sum1);
                }
            }

            // 右侧找 k
            for (int k = j + 2; k < n - 1; k++) {
                int sum3 = prefix[k] - prefix[j + 1];
                int sum4 = prefix[n] - prefix[k + 1];
                if (sum3 == sum4 && leftSums.contains(sum3)) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀和**：快速计算区间和
2. **固定 j**：将三维搜索降为二维
3. **HashSet 加速**：左侧等和集合匹配右侧
4. **边界**：至少需要 7 个元素
