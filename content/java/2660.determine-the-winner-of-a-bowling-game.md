## 题目描述

给你两位玩家的保龄球得分数组，若前 1 或前 2 轮曾打满 10 分则本轮翻倍，计算各自总分，返回 1（玩家 1 胜）、2（玩家 2 胜）或 0（平局）。

## Java 代码实现

```java
class Solution {
    public int isWinner(int[] player1, int[] player2) {
        int s1 = calcScore(player1);
        int s2 = calcScore(player2);
        return s1 > s2 ? 1 : s2 > s1 ? 2 : 0;
    }

    private int calcScore(int[] scores) {
        int total = 0;
        for (int i = 0; i < scores.length; i++) {
            // 前 1 轮或前 2 轮有满分则翻倍
            boolean doubled = (i >= 1 && scores[i - 1] == 10)
                           || (i >= 2 && scores[i - 2] == 10);
            total += doubled ? scores[i] * 2 : scores[i];
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 翻倍条件：前 1 轮 OR 前 2 轮中任一为 10 分
2. 两者分开计算后比较大小
