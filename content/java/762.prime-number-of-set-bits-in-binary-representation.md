## 题目描述

给定两个整数 `left` 和 `right`，返回在闭区间 `[left, right]` 内有多少个数字的二进制表示中 `1` 的个数是质数。

**示例 1:**
```
输入: left = 6, right = 10
输出: 4
解释:
6  -> 110 (2 个 1，2 是质数)
7  -> 111 (3 个 1，3 是质数)
8  -> 1000 (1 个 1，1 不是质数)
9  -> 1001 (2 个 1，2 是质数)
10 -> 1010 (2 个 1，2 是质数)
共 4 个数字满足条件。
```

**示例 2:**
```
输入: left = 10, right = 15
输出: 5
```

**提示:**
- `1 <= left <= right <= 10^6`
- `0 <= right - left <= 10^4`

## 解题思路

这道题分为两个子问题：
1. 计算一个数字二进制表示中 1 的个数
2. 判断一个数是否为质数

**关键观察：**
- 由于 `right <= 10^6 < 2^20`，所以二进制位数最多 20 位
- 1 的个数最多为 20
- 只需要预先计算 20 以内的质数：2, 3, 5, 7, 11, 13, 17, 19

## Java 代码实现

### 方法一：位运算 + 质数集合（推荐）

```java
import java.util.*;

class Solution {
    public int countPrimeSetBits(int left, int right) {
        // 20 以内的质数（用位掩码表示）
        // 2,3,5,7,11,13,17,19 -> 0b10101000101000100100 = 665772
        Set<Integer> primes = new HashSet<>(Arrays.asList(2, 3, 5, 7, 11, 13, 17, 19));

        int count = 0;
        for (int num = left; num <= right; num++) {
            // 计算二进制中 1 的个数
            int bits = Integer.bitCount(num);
            // 判断是否为质数
            if (primes.contains(bits)) {
                count++;
            }
        }

        return count;
    }
}
```

### 方法二：使用位掩码

```java
class Solution {
    public int countPrimeSetBits(int left, int right) {
        // 使用位掩码表示质数
        // 第 i 位为 1 表示 i 是质数
        // 2, 3, 5, 7, 11, 13, 17, 19
        int primeMask = 0b10101000101000100100; // = 665772

        int count = 0;
        for (int num = left; num <= right; num++) {
            int bits = Integer.bitCount(num);
            // 检查第 bits 位是否为 1
            if (((primeMask >> bits) & 1) == 1) {
                count++;
            }
        }

        return count;
    }
}
```

### 方法三：详细注释版（易理解）

```java
class Solution {
    public int countPrimeSetBits(int left, int right) {
        // 预先列出可能的质数
        // 由于 right <= 10^6 < 2^20，所以最多 20 个 1
        // 20 以内的质数有: 2, 3, 5, 7, 11, 13, 17, 19
        boolean[] isPrime = new boolean[21];
        int[] primeList = {2, 3, 5, 7, 11, 13, 17, 19};
        for (int p : primeList) isPrime[p] = true;

        int result = 0;

        // 遍历区间内的每个数字
        for (int number = left; number <= right; number++) {
            // Integer.bitCount() 统计二进制中 1 的个数
            int onesCount = Integer.bitCount(number);

            // 判断 1 的个数是否为质数
            if (onesCount <= 20 && isPrime[onesCount]) {
                result++;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度：** O((right - left) * log(right))，遍历区间，每个数字计算位数需要 O(log n) 时间
- **空间复杂度：** O(1)，只使用常数空间

## 关键点总结

1. **范围限制：** right <= 10^6，所以最多 20 位
2. **质数预计算：** 20 以内的质数只有 8 个
3. **位运算技巧：** `Integer.bitCount(n)` 快速计算 1 的个数
4. **集合查找：** 使用集合判断质数，O(1) 时间
5. **优化空间：** 可以用位掩码代替集合

## 易错点

1. **质数定义：** 1 不是质数
2. **边界情况：** left 和 right 都要包含在内
3. **效率问题：** 每次都判断质数会很慢，应该预先存储
4. **范围理解：** 理解为什么只需要考虑 20 以内的质数
