## 题目描述

给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

**示例 1：**
```
输入：s = "egg", t = "add"
输出：true
解释：'e' -> 'a', 'g' -> 'd'
```

**示例 2：**
```
输入：s = "foo", t = "bar"
输出：false
解释：'o' 不能同时映射到 'a' 和 'r'
```

**示例 3：**
```
输入：s = "paper", t = "title"
输出：true
解释：'p' -> 't', 'a' -> 'i', 'e' -> 'l', 'r' -> 'e'
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `t.length == s.length`
- `s` 和 `t` 由任意有效的 ASCII 字符组成

## 解题思路

这道题的核心是理解**同构**的含义：

### 同构的定义

两个字符串同构，必须满足：
1. **一对一映射**：s 中的每个字符映射到 t 中的唯一字符
2. **双向映射**：不仅 s → t 要唯一，t → s 也要唯一
3. **位置对应**：相同位置的字符要满足映射关系

### 核心思想

需要建立**双向映射**：
- s → t 的映射
- t → s 的映射（防止多个字符映射到同一个字符）

### 解决方案

1. **双哈希表**：分别记录 s → t 和 t → s 的映射
2. **单哈希表 + 集合**：哈希表记录 s → t，集合记录 t 中已映射的字符
3. **模式编码**：将两个字符串编码成相同的模式

## Java 代码实现

### 方法一：双哈希表（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        // 建立双向映射
        Map<Character, Character> sToT = new HashMap<>();  // s 到 t 的映射
        Map<Character, Character> tToS = new HashMap<>();  // t 到 s 的映射
        
        for (int i = 0; i < s.length(); i++) {
            char charS = s.charAt(i);
            char charT = t.charAt(i);
            
            // 检查 s -> t 的映射
            if (sToT.containsKey(charS)) {
                if (sToT.get(charS) != charT) {
                    return false;
                }
            } else {
                sToT.put(charS, charT);
            }
            
            // 检查 t -> s 的映射
            if (tToS.containsKey(charT)) {
                if (tToS.get(charT) != charS) {
                    return false;
                }
            } else {
                tToS.put(charT, charS);
            }
        }
        
        return true;
    }
}
```

**代码说明**：
- 使用两个 HashMap 分别记录双向映射
- 遍历时同时检查两个方向的映射是否一致
- 如果发现冲突（一个字符映射到多个不同字符），返回 false

### 方法二：单哈希表 + 集合

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        Map<Character, Character> sToT = new HashMap<>();  // s 到 t 的映射
        Set<Character> usedT = new HashSet<>();  // t 中已经被映射的字符
        
        for (int i = 0; i < s.length(); i++) {
            char charS = s.charAt(i);
            char charT = t.charAt(i);
            
            if (sToT.containsKey(charS)) {
                // 如果已有映射，检查是否一致
                if (sToT.get(charS) != charT) {
                    return false;
                }
            } else {
                // 如果 charT 已经被其他字符映射，返回 false
                if (usedT.contains(charT)) {
                    return false;
                }
                sToT.put(charS, charT);
                usedT.add(charT);
            }
        }
        
        return true;
    }
}
```

**代码说明**：
- 用 `HashSet` 记录 t 中已被映射的字符
- 确保 t 中的每个字符只被映射一次

### 方法三：数组优化（利用 ASCII）⭐

```java
class Solution {
    public boolean isIsomorphic(String s, String t) {
        // 利用 ASCII 字符集大小为 256，用数组代替哈希表，速度更快
        int[] sToT = new int[256];
        int[] tToS = new int[256];
        
        for (int i = 0; i < s.length(); i++) {
            char charS = s.charAt(i);
            char charT = t.charAt(i);
            
            // 检查 s -> t 的映射（用 i+1 区分未映射状态0）
            if (sToT[charS] != 0 && sToT[charS] != charT + 1) {
                return false;
            }
            if (tToS[charT] != 0 && tToS[charT] != charS + 1) {
                return false;
            }
            
            sToT[charS] = charT + 1;
            tToS[charT] = charS + 1;
        }
        
        return true;
    }
}
```

**优化说明**：
- 用数组代替 HashMap，利用 ASCII 字符作为下标，速度更快
- `charT + 1` 是为了区分「未映射（值为 0）」和「映射到 ASCII 0 的字符」

### 方法四：模式编码

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[] encode(String str) {
        Map<Character, Integer> charToIndex = new HashMap<>();
        int[] pattern = new int[str.length()];
        for (int i = 0; i < str.length(); i++) {
            char c = str.charAt(i);
            if (!charToIndex.containsKey(c)) {
                charToIndex.put(c, i);
            }
            pattern[i] = charToIndex.get(c);
        }
        return pattern;
    }
    
    public boolean isIsomorphic(String s, String t) {
        // 两个字符串同构，当且仅当它们的编码模式相同
        int[] ps = encode(s);
        int[] pt = encode(t);
        return java.util.Arrays.equals(ps, pt);
    }
}
```

**代码说明**：
- 将每个字符映射为它第一次出现的位置
- 例如："egg" → [0, 1, 1]，"add" → [0, 1, 1]
- 两个字符串同构，当且仅当它们的编码模式相同

## 复杂度分析

### 方法一：双哈希表
- **时间复杂度**：O(n)，遍历一次字符串
- **空间复杂度**：O(n)，最坏情况下存储所有字符的映射

### 方法二：单哈希表 + 集合
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

### 方法三：数组优化
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（数组大小固定为 256）

### 方法四：模式编码
- **时间复杂度**：O(n)，需要遍历两次
- **空间复杂度**：O(n)，存储编码结果

## 图解示例

### 示例 1：s = "egg", t = "add"

```
位置：  0   1   2
s:     e   g   g
t:     a   d   d

映射关系：
e -> a
g -> d

双向检查：
s -> t: {e: a, g: d}
t -> s: {a: e, d: g}

没有冲突，返回 True
```

### 示例 2：s = "foo", t = "bar"

```
位置：  0   1   2
s:     f   o   o
t:     b   a   r

映射关系：
f -> b
o -> a (第一次)
o -> r (第二次) ← 冲突！

o 不能同时映射到 a 和 r
返回 False
```

## 关键点总结

1. **双向映射**：必须同时检查 s → t 和 t → s 的映射
2. **一对一关系**：每个字符只能映射到唯一的字符
3. **位置对应**：相同位置的字符要满足映射关系
4. **Java 优化**：用数组替代 HashMap 可以提升性能
5. **字符比较**：Java 中 Character 比较用 `!=` 即可（自动拆箱比较值）

## 易错点

1. **忘记双向检查**：只检查 s → t，忘记检查 t → s
   - 错误案例：s = "ab", t = "aa"，如果只检查 s → t 会误判为 True

2. **边界情况**：
   - 单字符字符串
   - 所有字符相同的字符串

3. **映射冲突**：没有检查一个字符是否映射到多个不同字符

4. **Java 自动装箱陷阱**：比较 Character 对象时，大值可能不走缓存，需用 `equals` 或比较基本类型
