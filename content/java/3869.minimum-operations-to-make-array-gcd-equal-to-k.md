## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，每次可以将任意元素替换为它的某个因子，返回使所有元素的最大公约数（GCD）等于 `k` 所需的最少操作次数，无法达到则返回 -1。

## 解题思路

要使 GCD = k，所有元素必须是 k 的倍数（否则返回 -1）。若满足此条件，当前 GCD 必为 k 的倍数；若等于 k 则无需操作，否则只需一次操作将某个元素替换为 k 即可使 GCD 降至 k。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        // 检查每个元素是否是 k 的倍数
        for (int v : nums) {
            if (v % k != 0) return -1;
        }
        // 计算当前数组的 GCD
        int g = 0;
        for (int v : nums) {
            g = gcd(g, v);
        }
        // 若当前 GCD 已等于 k，无需操作
        if (g == k) return 0;
        // 否则只需 1 次操作（将某元素替换为因子 k）
        return 1;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log(max_val))，GCD 计算
- 空间复杂度：O(1)

## 关键点总结

1. 要使 GCD = k，所有元素必须是 k 的倍数（否则返回 -1）。
2. 当前 GCD > k 时，只需将一个元素替换为 k（1 次操作）即可使 GCD 降为 k。
3. 若当前 GCD = k，无需操作。
