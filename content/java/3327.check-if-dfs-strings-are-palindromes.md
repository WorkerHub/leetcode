## 题目描述

给你 n 个节点的树（根节点 0）和字符数组 `s`，对每个节点 `i`，以 `i` 为根的子树按 DFS 序（先访问编号小的子节点）形成字符串，判断该字符串是否为回文串。

## 解题思路

DFS 构建欧拉序：每个节点 `i` 的子树对应 DFS 序字符串的连续区间 `[in[i], out[i]]`。对 DFS 序字符串预处理正向和反向多项式哈希，O(1) 查询区间哈希判断回文。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean[] findAnswer(int[] parent, String s) {
        int n = s.length();
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parent[i]).add(i);
        for (int i = 0; i < n; i++) Collections.sort(children.get(i));

        // 迭代 DFS 构建欧拉序
        int[] inTime = new int[n], outTime = new int[n];
        char[] dfsStr = new char[n];
        int[] timer = {0};
        Deque<int[]> stack = new ArrayDeque<>(); // [node, childIdx]
        stack.push(new int[]{0, 0});
        inTime[0] = timer[0];
        dfsStr[timer[0]++] = s.charAt(0);
        while (!stack.isEmpty()) {
            int[] top = stack.peek();
            int node = top[0], ci = top[1];
            if (ci < children.get(node).size()) {
                top[1]++;
                int child = children.get(node).get(ci);
                inTime[child] = timer[0];
                dfsStr[timer[0]++] = s.charAt(child);
                stack.push(new int[]{child, 0});
            } else {
                outTime[node] = timer[0] - 1;
                stack.pop();
            }
        }

        // 字符串哈希（双哈希防碰撞）
        long MOD1 = 1_000_000_007L, BASE1 = 131;
        long MOD2 = 1_000_000_009L, BASE2 = 137;
        long[] h1 = new long[n+1], h2 = new long[n+1];
        long[] rh1 = new long[n+1], rh2 = new long[n+1];
        long[] pw1 = new long[n+1], pw2 = new long[n+1];
        pw1[0] = pw2[0] = 1;
        for (int i = 0; i < n; i++) {
            int c = dfsStr[i] - 'a' + 1;
            h1[i+1] = (h1[i] * BASE1 + c) % MOD1;
            h2[i+1] = (h2[i] * BASE2 + c) % MOD2;
            pw1[i+1] = pw1[i] * BASE1 % MOD1;
            pw2[i+1] = pw2[i] * BASE2 % MOD2;
            int rc = dfsStr[n-1-i] - 'a' + 1;
            rh1[i+1] = (rh1[i] * BASE1 + rc) % MOD1;
            rh2[i+1] = (rh2[i] * BASE2 + rc) % MOD2;
        }

        boolean[] answer = new boolean[n];
        for (int i = 0; i < n; i++) {
            int l = inTime[i], r = outTime[i], len = r - l + 1;
            // 正向哈希 [l, r]
            long fwd1 = (h1[r+1] - h1[l] * pw1[len] % MOD1 + MOD1 * 2) % MOD1;
            long fwd2 = (h2[r+1] - h2[l] * pw2[len] % MOD2 + MOD2 * 2) % MOD2;
            // 反向哈希对应 [n-1-r, n-1-l] 在 rh 中
            int rl = n - 1 - r, rr = n - 1 - l;
            long bwd1 = (rh1[rr+1] - rh1[rl] * pw1[len] % MOD1 + MOD1 * 2) % MOD1;
            long bwd2 = (rh2[rr+1] - rh2[rl] * pw2[len] % MOD2 + MOD2 * 2) % MOD2;
            answer[i] = fwd1 == bwd1 && fwd2 == bwd2;
        }
        return answer;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，迭代 DFS + 哈希预处理 + n 次 O(1) 查询
- 空间复杂度：O(n)

## 关键点总结

1. DFS 欧拉序：每个节点子树对应 DFS 序的连续区间 `[in[i], out[i]]`
2. 双哈希判断回文：正向区间哈希 == 反向对应区间哈希
3. 迭代 DFS 避免 Java 递归栈溢出
