## 题目描述

给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2`，返回满足 `nums1[i] + nums1[j] > nums2[i] + nums2[j]`（0 <= i < j < n）的数对数目。

## 解题思路

令 `diff[k] = nums1[k] - nums2[k]`，问题转化为统计 `diff[i] + diff[j] > 0` 的数对数。对 diff 排序后用双指针：若 diff[left] + diff[right] > 0，则 [left, right-1] 中所有元素与 right 构成合法对，累加 right-left。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long countPairs(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[] diff = new int[n];
        for (int i = 0; i < n; i++) {
            diff[i] = nums1[i] - nums2[i];
        }
        Arrays.sort(diff);

        long count = 0;
        int left = 0, right = n - 1;
        while (left < right) {
            if (diff[left] + diff[right] > 0) {
                // diff[left..right-1] 与 diff[right] 均构成合法对
                count += right - left;
                right--;
            } else {
                left++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)，diff 数组

## 关键点总结

1. 差值变换：问题转化为 diff 数组中正数对的计数
2. 排序后双指针 O(n) 统计
3. 每次 right 减小时累加 right-left（不含 right 本身）
