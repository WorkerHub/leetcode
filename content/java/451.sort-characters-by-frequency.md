## 题目描述

给定一个字符串 s，根据字符出现的频率对其进行降序排序。一个字符出现的频率是它出现在字符串中的次数。

返回已排序的字符串。如果有多个答案，返回其中任何一个。

**示例 1:**

```
输入: s = "tree"
输出: "eert"
解释: 'e' 出现两次，'r' 和 't' 都只出现一次。
因此 'e' 必须出现在 'r' 和 't' 之前。此外，"eetr" 也是一个有效的答案。
```

**示例 2:**

```
输入: s = "cccaaa"
输出: "aaaccc"
解释: 'c' 和 'a' 都出现三次。此外，"aaaccc" 也是有效的答案。
注意 "cacaca" 是不正确的，因为相同的字母必须放在一起。
```

**示例 3:**

```
输入: s = "Aabb"
输出: "bbAa"
解释: 此外，"bbaA" 也是一个有效的答案，但 "Aabb" 是不正确的。
注意 'A' 和 'a' 被认为是两种不同的字符。
```

**提示:**

- 1 <= s.length <= 5 * 10^5
- s 由大小写英文字母和数字组成

## 解题思路

这道题的核心是**统计频率**和**按频率排序**。

**解决方案：**

1. **哈希表 + 排序**：统计频率，然后排序
2. **桶排序**：按频率分桶，从高频到低频收集
3. **堆排序**：使用最大堆按频率排序
4. **Java 标准解法**：使用 HashMap 和 PriorityQueue

## Java 代码实现

### 方法一：HashMap + 排序（推荐，最简洁）

```java
import java.util.*;

class Solution {
    public String frequencySort(String s) {
        // 统计每个字符的频率
        Map<Character, Integer> freqMap = new HashMap<>();
        for (char c : s.toCharArray()) {
            freqMap.put(c, freqMap.getOrDefault(c, 0) + 1);
        }

        // 按频率降序排序
        List<Map.Entry<Character, Integer>> entries = new ArrayList<>(freqMap.entrySet());
        entries.sort((a, b) -> b.getValue() - a.getValue());

        // 构建结果
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<Character, Integer> entry : entries) {
            char c = entry.getKey();
            int freq = entry.getValue();
            for (int i = 0; i < freq; i++) {
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

### 方法二：桶排序（时间复杂度最优）

```java
import java.util.*;

class Solution {
    public String frequencySort(String s) {
        // 统计频率
        Map<Character, Integer> freqMap = new HashMap<>();
        for (char c : s.toCharArray()) {
            freqMap.put(c, freqMap.getOrDefault(c, 0) + 1);
        }

        // 找最大频率
        int maxFreq = 0;
        for (int freq : freqMap.values()) {
            maxFreq = Math.max(maxFreq, freq);
        }

        // 创建桶：索引表示频率，值是该频率的字符列表
        List<List<Character>> buckets = new ArrayList<>();
        for (int i = 0; i <= maxFreq; i++) {
            buckets.add(new ArrayList<>());
        }
        for (Map.Entry<Character, Integer> entry : freqMap.entrySet()) {
            buckets.get(entry.getValue()).add(entry.getKey());
        }

        // 从高频到低频收集结果
        StringBuilder sb = new StringBuilder();
        for (int freq = maxFreq; freq >= 1; freq--) {
            for (char c : buckets.get(freq)) {
                for (int i = 0; i < freq; i++) {
                    sb.append(c);
                }
            }
        }

        return sb.toString();
    }
}
```

### 方法三：最大堆排序

```java
import java.util.*;

class Solution {
    public String frequencySort(String s) {
        // 统计频率
        Map<Character, Integer> freqMap = new HashMap<>();
        for (char c : s.toCharArray()) {
            freqMap.put(c, freqMap.getOrDefault(c, 0) + 1);
        }

        // 最大堆，按频率降序排列
        PriorityQueue<Map.Entry<Character, Integer>> maxHeap =
            new PriorityQueue<>((a, b) -> b.getValue() - a.getValue());
        maxHeap.addAll(freqMap.entrySet());

        // 从堆中取出并构建结果
        StringBuilder sb = new StringBuilder();
        while (!maxHeap.isEmpty()) {
            Map.Entry<Character, Integer> entry = maxHeap.poll();
            char c = entry.getKey();
            int freq = entry.getValue();
            for (int i = 0; i < freq; i++) {
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

### 方法四：手动排序

```java
import java.util.*;

class Solution {
    public String frequencySort(String s) {
        // 统计频率
        Map<Character, Integer> freqMap = new HashMap<>();
        for (char c : s.toCharArray()) {
            freqMap.put(c, freqMap.getOrDefault(c, 0) + 1);
        }

        // 转换为列表并按频率降序排序
        List<Character> chars = new ArrayList<>(freqMap.keySet());
        chars.sort((a, b) -> freqMap.get(b) - freqMap.get(a));

        // 构建结果
        StringBuilder sb = new StringBuilder();
        for (char c : chars) {
            int freq = freqMap.get(c);
            for (int i = 0; i < freq; i++) {
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

**方法一（HashMap + 排序）：**
- 时间复杂度：O(n + k log k)，n 是字符串长度，k 是不同字符数
- 空间复杂度：O(n)

**方法二（桶排序）：**
- 时间复杂度：O(n)，线性时间
- 空间复杂度：O(n)

**方法三（堆排序）：**
- 时间复杂度：O(n + k log k)
- 空间复杂度：O(n)

## 关键点总结

1. **频率统计**：使用 HashMap 统计频率
2. **排序策略**：按频率降序排序
3. **字符重复**：用循环生成重复字符
4. **桶排序优化**：利用频率范围有限的特点
5. **稳定性不要求**：相同频率的字符顺序任意

## 易错点

1. **忘记重复字符**：
   ```java
   // 错误：只添加字符一次
   sb.append(c);

   // 正确：重复添加
   for (int i = 0; i < freq; i++) {
       sb.append(c);
   }
   ```

2. **排序方向错误**：
   ```java
   // 错误：升序排序
   entries.sort((a, b) -> a.getValue() - b.getValue());

   // 正确：降序排序
   entries.sort((a, b) -> b.getValue() - a.getValue());
   ```

3. **字符串拼接效率**：
   ```java
   // 低效：反复创建新字符串
   String result = "";
   for (char c : chars) {
       result += c;
   }

   // 高效：使用 StringBuilder
   StringBuilder sb = new StringBuilder();
   for (char c : chars) {
       sb.append(c);
   }
   return sb.toString();
   ```

## 学习建议

1. **HashMap 的使用**：
   - `getOrDefault(key, defaultValue)` 简化代码
   - `entrySet()` 遍历键值对
   - 这是 Java 处理频率问题的标准工具

2. **桶排序思想**：
   - 当数据范围有限时，桶排序可以达到 O(n)
   - 理解桶排序的适用场景

3. **堆的应用**：
   - PriorityQueue 实现最大堆时传入逆序 Comparator
   - 适合 Top K 问题

4. **字符串处理**：
   - 优先使用 `StringBuilder` 而不是字符串拼接
   - `sb.toString()` 最终转换为字符串

5. **性能对比**：
   - 桶排序：O(n)，最快
   - HashMap + sort：O(n log k)，代码简洁
   - 堆排序：O(n log k)，适合流式数据
