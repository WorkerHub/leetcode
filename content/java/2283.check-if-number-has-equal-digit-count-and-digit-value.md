## 题目描述

检查字符串num是否自描述：num[i]等于数字i在num中出现的次数。

## 解题思路

统计每个数字出现频次，逐位验证num[i]是否等于数字i的实际出现次数。

## Java 代码实现

```java
class Solution {
    public boolean digitCount(String num) {
        int[] freq = new int[10];
        for (char c : num.toCharArray()) freq[c - '0']++;

        for (int i = 0; i < num.length(); i++) {
            if (num.charAt(i) - '0' != freq[i]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **频次数组统计**：freq[d]为数字d出现次数
2. **逐位验证**：num[i]的值应等于freq[i]
3. **字符串长度<=10**：i最大为9
