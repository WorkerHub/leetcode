## 题目描述

给你一个整数数组 `nums`，请你选择数组的两个不同下标 `i` 和 `j`，使得 `(nums[i]-1) * (nums[j]-1)` 取得最大值。

请你计算并返回该式的最大值。

**示例 1：**
```
输入：nums = [3,4,5,2]
输出：12
解释：如果选择下标 i=1 和 j=2（下标从 0 开始），则可以获得最大值 (nums[1]-1)*(nums[2]-1) = (4-1)*(5-1) = 3*4 = 12。
```

**示例 2：**
```
输入：nums = [1,5,4,5]
输出：16
解释：选择下标 i=1 和 j=3（下标从 0 开始），可以获得最大值 (5-1)*(5-1) = 4*4 = 16。
```

**示例 3：**
```
输入：nums = [3,7]
输出：12
```

**提示：**
- `2 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`

## 解题思路

**数学分析：** `(a-1) * (b-1)` 在 a、b 都尽量大时取得最大值。

因此，我们只需找到数组中**最大的两个数**，然后计算 `(max1 - 1) * (max2 - 1)` 即可。

**证明：** 假设 `max1 >= max2 >= x`（x 为其他任意元素），则：
- `(max1-1) * (max2-1) >= (max1-1) * (x-1)`（因为 max2 >= x）

所以最优解一定是最大值和次大值的组合。

## Java 代码实现

### 方法一：排序（推荐，最简洁）

```java
import java.util.Arrays;

class Solution {
    public int maxProduct(int[] nums) {
        // 排序后，最大的两个数在末尾
        Arrays.sort(nums);
        int n = nums.length;
        // 取最大值和次大值
        return (nums[n - 1] - 1) * (nums[n - 2] - 1);
    }
}
```

### 方法二：一次遍历维护最大值和次大值

```java
class Solution {
    public int maxProduct(int[] nums) {
        int max1 = 0, max2 = 0;  // max1 >= max2

        for (int num : nums) {
            if (num > max1) {
                max2 = max1;  // 原来的最大变次大
                max1 = num;   // 更新最大
            } else if (num > max2) {
                max2 = num;   // 只更新次大
            }
        }

        return (max1 - 1) * (max2 - 1);
    }
}
```

### 方法三：使用 PriorityQueue（了解堆的用法）

```java
import java.util.PriorityQueue;

class Solution {
    public int maxProduct(int[] nums) {
        // 最大堆：取前两个最大值
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int num : nums) maxHeap.offer(num);
        int top1 = maxHeap.poll();
        int top2 = maxHeap.poll();
        return (top1 - 1) * (top2 - 1);
    }
}
```

## 复杂度分析

**方法一（排序）：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

**方法二（一次遍历）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)，最优解法

**方法三（PriorityQueue）：**
- 时间复杂度：O(n log n)，入堆 n 次
- 空间复杂度：O(n)

## 关键点总结

1. `(a-1) * (b-1)` 最大化 => 选最大的两个数
2. 一次遍历维护最大值和次大值是最优做法（O(n) 时间，O(1) 空间）
3. 注意 `max1` 和 `max2` 的更新顺序：先更新 `max2 = max1`，再更新 `max1 = num`

## 易错点

- 更新次大值时，顺序很重要：先把 max1 赋给 max2，再更新 max1
- 如果写成 `max1 = num; max2 = max1`，会导致 max2 等于新的 max1
