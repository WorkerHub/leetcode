## 题目描述

给定一个长度为 `n` 的整数数组 `nums`。

假设 `arrk` 是数组 `nums` 顺时针旋转 `k` 个位置后的数组，我们定义 `nums` 的**旋转函数** `F` 为：

- `F(k) = 0 * arrk[0] + 1 * arrk[1] + ... + (n - 1) * arrk[n - 1]`

返回 `F(0), F(1), ..., F(n-1)` 中的最大值。

生成的测试用例让答案符合 **32 位** 整数。

**示例 1:**

```
输入: nums = [4,3,2,6]
输出: 26
解释:
F(0) = (0 * 4) + (1 * 3) + (2 * 2) + (3 * 6) = 0 + 3 + 4 + 18 = 25
F(1) = (0 * 6) + (1 * 4) + (2 * 3) + (3 * 2) = 0 + 4 + 6 + 6 = 16
F(2) = (0 * 2) + (1 * 6) + (2 * 4) + (3 * 3) = 0 + 6 + 8 + 9 = 23
F(3) = (0 * 3) + (1 * 2) + (2 * 6) + (3 * 4) = 0 + 2 + 12 + 12 = 26
所以 F(0), F(1), F(2), F(3) 中的最大值是 F(3) = 26 。
```

**示例 2:**

```
输入: nums = [100]
输出: 0
```

**提示:**

- `n == nums.length`
- `1 <= n <= 10^5`
- `-100 <= nums[i] <= 100`

## 解题思路

暴力解法是对每个旋转位置计算 F(k)，时间复杂度 O(n²)。我们需要找到 **F(k) 和 F(k-1) 的递推关系**。

### 核心思想：数学递推

**观察规律：**

```
原数组: [a, b, c, d]
F(0) = 0*a + 1*b + 2*c + 3*d

旋转1次: [d, a, b, c]
F(1) = 0*d + 1*a + 2*b + 3*c
     = (0*a + 1*b + 2*c + 3*d) - (a + b + c + d) + 4*d
     = F(0) - sum + n*nums[n-1]
```

**递推公式：**

```
F(k) = F(k-1) + sum - n * nums[n-k]
```

其中：
- `sum` 是数组元素之和
- `n` 是数组长度
- `nums[n-k]` 是旋转后移到最前面的元素

**推导过程：**

从 F(k-1) 到 F(k)：
- 每个元素的系数都增加 1（除了移到前面的元素）
- 移到前面的元素系数变为 0
- 总变化：sum - n * (移到前面的元素)

## Java 代码实现

### 方法一：数学递推（推荐）⭐

```java
class Solution {
    public int maxRotateFunction(int[] nums) {
        // 数学递推公式
        // 时间复杂度: O(n)
        // 空间复杂度: O(1)
        int n = nums.length;
        long totalSum = 0;
        for (int num : nums) totalSum += num;

        // 计算 F(0)
        long f = 0;
        for (int i = 0; i < n; i++) {
            f += (long) i * nums[i];
        }

        long maxF = f;

        // 递推计算 F(1), F(2), ..., F(n-1)
        for (int k = 1; k < n; k++) {
            // F(k) = F(k-1) + sum - n * nums[n-k]
            f = f + totalSum - (long) n * nums[n - k];
            maxF = Math.max(maxF, f);
        }

        return (int) maxF;
    }
}
```

### 方法二：更直观的递推

```java
class Solution {
    public int maxRotateFunction(int[] nums) {
        // 更清晰的递推实现
        int n = nums.length;
        if (n == 0) return 0;

        long totalSum = 0;
        for (int num : nums) totalSum += num;

        long currentF = 0;
        for (int i = 0; i < n; i++) {
            currentF += (long) i * nums[i];
        }
        long maxF = currentF;

        // 从后向前遍历
        for (int i = n - 1; i > 0; i--) {
            // 将 nums[i] 从末尾移到开头，其他元素的索引都增加 1
            currentF = currentF + totalSum - (long) n * nums[i];
            maxF = Math.max(maxF, currentF);
        }

        return (int) maxF;
    }
}
```

### 方法三：暴力解法（TLE）

```java
class Solution {
    public int maxRotateFunction(int[] nums) {
        // 暴力解法：枚举所有旋转
        // 时间复杂度: O(n^2)
        // 空间复杂度: O(1)
        int n = nums.length;
        long maxF = Long.MIN_VALUE;

        for (int k = 0; k < n; k++) {
            long f = 0;
            for (int i = 0; i < n; i++) {
                // 旋转 k 次后，索引 i 的元素是原数组的 nums[(i-k+n) % n]
                f += (long) i * nums[((i - k) % n + n) % n];
            }
            maxF = Math.max(maxF, f);
        }

        return (int) maxF;
    }
}
```

### 方法四：优化的暴力

```java
class Solution {
    public int maxRotateFunction(int[] nums) {
        // 使用旋转索引
        int n = nums.length;
        long maxF = Long.MIN_VALUE;

        for (int k = 0; k < n; k++) {
            // 旋转 k 次：rotated[i] = nums[(n - k + i) % n]
            long f = 0;
            for (int i = 0; i < n; i++) {
                f += (long) i * nums[(n - k + i) % n];
            }
            maxF = Math.max(maxF, f);
        }

        return (int) maxF;
    }
}
```

## 复杂度分析

### 方法一：递推

**时间复杂度：** O(n)
- 初始化 F(0) 需要 O(n)
- 递推计算 F(1) 到 F(n-1) 需要 O(n)

**空间复杂度：** O(1)
- 只使用常数额外空间

### 方法三：暴力

**时间复杂度：** O(n²)
- 外层循环 n 次
- 内层循环 n 次

**空间复杂度：** O(1)

## 关键点总结

1. **找递推关系**：F(k) 和 F(k-1) 的关系是关键
2. **数学推导**：从旋转的物理意义推导公式
3. **避免重复计算**：利用递推而不是每次重新计算
4. **边界处理**：n=1 时特殊处理
5. **整数溢出**：使用 long 类型避免乘法溢出

## 易错点

1. **递推方向**：从 F(k-1) 到 F(k) 还是反过来
2. **索引计算**：旋转后的索引对应关系
3. **公式理解**：要理解为什么是 `sum - n * nums[n-k]`
4. **初始值**：正确计算 F(0)
5. **整数溢出**：Java 中 int 乘法可能溢出，用 long 中间计算

## 图解示例

```
nums = [4, 3, 2, 6]
n = 4
sum = 15

F(0) = 0*4 + 1*3 + 2*2 + 3*6 = 25

从 F(0) 到 F(1):
旋转前: [4, 3, 2, 6]
旋转后: [6, 4, 3, 2]

F(1) = 0*6 + 1*4 + 2*3 + 3*2 = 16

递推:
F(1) = F(0) + sum - n * nums[3]
     = 25 + 15 - 4 * 6
     = 25 + 15 - 24
     = 16 ✓

从 F(1) 到 F(2):
F(2) = F(1) + sum - n * nums[2]
     = 16 + 15 - 4 * 2
     = 16 + 15 - 8
     = 23

从 F(2) 到 F(3):
F(3) = F(2) + sum - n * nums[1]
     = 23 + 15 - 4 * 3
     = 23 + 15 - 12
     = 26

最大值: 26
```

**递推公式推导：**

```
F(k-1) = 0*nums[n-k+1] + 1*nums[n-k+2] + ... + (n-1)*nums[n-k]
F(k)   = 0*nums[n-k]   + 1*nums[n-k+1] + ... + (n-1)*nums[n-k-1]

F(k) - F(k-1) = nums[n-k+1] + nums[n-k+2] + ... + nums[n-k-1] - (n-1)*nums[n-k]
              + nums[n-k+1] + ... + nums[n-k] - nums[n-k]
              = sum - n*nums[n-k]
```
