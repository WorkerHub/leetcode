## 题目描述

给定字符串 s，返回字典序最大的子字符串。

**示例：**
```
输入：s = "abab"
输出："bab"
```

## 解题思路

字典序最大的子字符串一定是某个后缀。用双指针比较后缀，跳过不可能的位置，O(n) 找到答案。

## Java 代码实现

```java
class Solution {
    public String lastSubstring(String s) {
        int n = s.length();
        int i = 0, j = 1, k = 0; // i=候选位置, j=比较位置, k=偏移

        while (j + k < n) {
            char ci = s.charAt(i + k), cj = s.charAt(j + k);
            if (ci == cj) {
                k++;
            } else if (ci > cj) {
                // i 更大，j 跳过已比较部分
                j = j + k + 1;
                k = 0;
            } else {
                // j 更大，更新候选位置
                i = Math.max(i + k + 1, j);
                j = i + 1;
                k = 0;
            }
        }
        return s.substring(i);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，i 和 j 单调递增
- **空间复杂度**：O(1)，不算返回值

## 关键点总结

1. **后缀性质**：字典序最大子串必为后缀
2. **双指针跳跃**：发现较小时跳 k+1 步，避免逐一比较
3. **i 不回退**：`i = max(i+k+1, j)` 保证单调性
4. **k 重置**：每次更新 i 或 j 后重置偏移量
