## 题目描述

给你多个已升序排列的整数数组列表 `arrays`，返回出现在所有数组中的最长公共子序列（升序）。

## 解题思路

由于值域为 1~100 且每个数组中元素唯一，用计数数组统计每个值出现的数组数，等于总数组数的即为公共元素，按序收集即为答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> longestCommomSubsequence(int[][] arrays) {
        int m = arrays.length;
        int[] count = new int[101];
        for (int[] arr : arrays)
            for (int x : arr) count[x]++;

        List<Integer> result = new ArrayList<>();
        for (int v = 1; v <= 100; v++)
            if (count[v] == m) result.add(v);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)，n 为数组数，k 为平均长度
- **空间复杂度**：O(1)（值域固定为 100）

## 关键点总结

1. 值域小（1~100）且每数组元素唯一，计数等于 m 即为公共元素
2. 按值从小到大遍历，结果天然升序
3. 无需额外排序
