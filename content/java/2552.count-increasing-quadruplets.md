## 题目描述

给你 1 到 n 的排列数组 `nums`，返回满足 `i < j < k < l` 且 `nums[i] < nums[k] < nums[j] < nums[l]` 的四元组数目。

## 解题思路

O(n²) DP：枚举 k（第三位），用 `dp[j]` 表示"j 左边小于 `nums[k]` 的元素数"。当 k 增加 1 时，对所有 j 中 `nums[j] > nums[k-1]` 的位置，`dp[j]++`。枚举 (j,k) 对（需 `nums[j] > nums[k]`），同时维护 k 右边大于 `nums[j]` 的 l 数量。

## Java 代码实现

```java
class Solution {
    public long countQuadruplets(int[] nums) {
        int n = nums.length;
        long ans = 0;
        // dp[j] = j 左边（已处理的位置中）小于 nums[k] 的元素数，随 k 更新
        int[] dp = new int[n];

        for (int k = 1; k < n - 1; k++) {
            // 维护 k 右边大于 nums[j] 的 l 数量（从右到左累计）
            // 每次对固定 k，枚举所有 j < k 且 nums[j] > nums[k]
            // 先更新 dp：对 j < k，若 nums[j] > nums[k-1]（新加入左边的元素），dp[j]++
            for (int j = 0; j < k; j++) {
                if (nums[j] > nums[k - 1]) dp[j]++;
                // 注意：dp[j] 记录的是 j 左边 < nums[k] 的元素数
                // 当加入 nums[k-1] 时，若 nums[k-1] < nums[j]，则 dp[j]++
            }
            // 统计 k 右边大于 nums[j] 的 l 数量（对每个满足条件的 j）
            int rightGreater = 0; // k 右边比某值大的数量，随 j 从小到大变化
            // 从右到左枚举 j，维护右侧计数
            // 先算 k 右边的前缀统计
            // 对固定 k，枚举 j，累加 dp[j] * (右边 > nums[j] 的 l 数)
            // 右边 > nums[j] 的 l 数：用后缀维护
            int[] sufGreater = new int[n]; // sufGreater[j] = k+1..n-1 中 > nums[j] 的数量
            for (int l = n - 1; l > k; l--) {
                for (int j = 0; j < k; j++) {
                    if (nums[l] > nums[j]) sufGreater[j]++;
                }
            }
            for (int j = 0; j < k; j++) {
                if (nums[j] > nums[k]) {
                    ans += (long) dp[j] * sufGreater[j];
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举中间对 (j, k)，需满足 j < k 且 nums[j] > nums[k]
2. 左侧贡献：j 左边小于 nums[k] 的元素数（dp[j] 随 k 增量维护）
3. 右侧贡献：k 右边大于 nums[j] 的元素数（后缀统计）
