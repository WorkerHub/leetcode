## 题目描述

构造长度为 `n`、每个元素在 `[1, m]` 之间的数组，相邻元素之积为偶数的对数恰好为 `k`，返回满足条件的数组数量（模 10^9+7）。

## 解题思路

DP：`dp[j][parity]` 表示已确定若干元素，有 `j` 个偶数乘积对，最后一个元素奇偶性（0=偶，1=奇）。加入偶数（even 种）时偶数对必 +1；加入奇数（odd 种）时：前偶后奇 → +1，前奇后奇 → 不变。

## Java 代码实现

```java
class Solution {
    public int countOfArrays(int n, int m, int k) {
        final int MOD = 1_000_000_007;
        long odd = (m + 1) / 2, even = m / 2;
        // dp[j][p]: j 个偶数对，最后元素奇偶 p
        long[][] dp = new long[k + 1][2];
        dp[0][0] = even; // 第一个元素为偶数
        dp[0][1] = odd;  // 第一个元素为奇数

        for (int i = 1; i < n; i++) {
            long[][] ndp = new long[k + 1][2];
            for (int j = 0; j <= k; j++) {
                // 加入偶数：与前一个元素构成偶数对，j 从 j-1 转来
                if (j >= 1) {
                    ndp[j][0] = (ndp[j][0] + (dp[j-1][0] + dp[j-1][1]) % MOD * even) % MOD;
                }
                // 加入奇数：前偶后奇 → j-1 转来（偶数对+1）
                if (j >= 1) {
                    ndp[j][1] = (ndp[j][1] + dp[j-1][0] * odd) % MOD;
                }
                // 加入奇数：前奇后奇 → 不增加偶数对
                ndp[j][1] = (ndp[j][1] + dp[j][1] * odd) % MOD;
            }
            dp = ndp;
        }
        return (int) ((dp[k][0] + dp[k][1]) % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 积为偶数当且仅当至少一个为偶数；前奇后奇时积为奇数
2. 加入偶数必然 +1 偶数对；加入奇数只在前一个为偶数时 +1
3. DP 状态记录最后元素奇偶性，避免枚举所有奇数段分布
