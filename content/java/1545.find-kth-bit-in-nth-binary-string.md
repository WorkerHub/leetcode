## 题目描述

S_1="0"，S_i = S_{i-1} + "1" + reverse(invert(S_{i-1}))。返回 S_n 中第 k 位（1-indexed）。

**示例：**
```
输入：n = 3, k = 1
输出："0"
S_3 = "0111001"
```

## 解题思路

递归/迭代：S_n 长度为 2^n-1，中间位为 '1'。k 在前半段递归前一层，在后半段映射到前半段并取反。

## Java 代码实现

```java
class Solution {
    public char findKthBit(int n, int k) {
        // 迭代：记录翻转次数
        int invert = 0;
        while (n > 1) {
            int mid = 1 << (n - 1); // 2^(n-1)
            if (k == mid) {
                // 中间位恒为 '1'，应用翻转
                return invert == 0 ? '1' : '0';
            } else if (k > mid) {
                // 后半段，映射到前半段并翻转
                k = (1 << n) - k; // 2^n - k
                invert ^= 1;
            }
            n--;
        }
        // n == 1, k == 1, S_1 = "0"
        return invert == 0 ? '0' : '1';
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **中间位**：第 2^(n-1) 位恒为 '1'
2. **后半段映射**：k → 2^n - k，翻转一次
3. **迭代优化**：用 invert 标记累积翻转次数
