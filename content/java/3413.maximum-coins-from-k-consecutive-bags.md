## 题目描述

数轴上有若干袋子，第 i 个袋子位于 `position[i]`，含 `coins[i]` 枚硬币，选长度为 k 的区间，收集区间内所有硬币，返回最多能收集的硬币数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumCoins(int[][] coins, int k) {
        // 按位置排序
        Arrays.sort(coins, (a, b) -> a[0] - b[0]);
        int n = coins.length;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + coins[i][1];

        long ans = 0;

        for (int i = 0; i < n; i++) {
            long pos = coins[i][0];
            // 左对齐：区间 [pos, pos + k - 1]
            ans = Math.max(ans, coinsInRange(coins, prefix, pos, pos + k - 1));
            // 右对齐：区间 [pos - k + 1, pos]
            ans = Math.max(ans, coinsInRange(coins, prefix, pos - k + 1, pos));
        }
        return ans;
    }

    private long coinsInRange(int[][] coins, long[] prefix, long left, long right) {
        // 二分找第一个 position >= left
        int lo = lowerBound(coins, left);
        // 二分找第一个 position > right
        int hi = upperBound(coins, right);
        return prefix[hi] - prefix[lo];
    }

    private int lowerBound(int[][] coins, long target) {
        int lo = 0, hi = coins.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (coins[mid][0] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    private int upperBound(int[][] coins, long target) {
        int lo = 0, hi = coins.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (coins[mid][0] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序和二分
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 最优区间一定以某个袋子位置为左端点或右端点。
2. 排序后用前缀和 + 二分可以 O(log n) 查询任意区间内的硬币总量。
3. 枚举 2n 个候选区间，取最大值。
