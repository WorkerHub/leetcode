## 题目描述

给数组 nums 和整数 k，每次可选相邻两元素将左元素替换为二者 AND 并删除右元素，最多操作 k 次，返回数组按位 OR 的最小值。

## 解题思路

贪心从高位到低位逐位尝试清零：对于每一位，检查能否通过 ≤k 次操作使该位在 OR 中为 0。做法是贪心合并，统计 AND 在当前掩码下能独立存在的段数，所需操作数 = n - 段数。

## Java 代码实现

```java
class Solution {
    public int minOrAfterOperations(int[] nums, int k) {
        int n = nums.length;
        int ans = 0;
        for (int bit = 29; bit >= 0; bit--) {
            int mask = ans | (1 << bit);
            // 统计按 mask 过滤后能独立成段的段数
            int groups = 0;
            int cur = ~0; // 全 1
            for (int x : nums) {
                cur &= x;
                if ((cur & mask) == 0) {
                    // 当前段 AND 在 mask 位上全为 0，可以独立成段
                    groups++;
                    cur = ~0;
                }
            }
            // 需要 n - groups 次操作
            if (n - groups <= k) {
                // 可以清零第 bit 位，不加入 ans
            } else {
                ans |= (1 << bit); // 无法清零，保留
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(30n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心从高位到低位逐位确定答案
2. 段数 groups 是能独立存在的连续 AND 段，操作数 = n - groups
3. 每位检验需要包含已确定的高位掩码 ans
