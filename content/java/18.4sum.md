## 题目描述

给你一个由 `n` 个整数组成的数组 `nums`，和一个目标值 `target`。请你找出并返回满足下述全部条件且不重复的四元组。

**示例 1：**
```
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

**示例 2：**
```
输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]
```

## 解题思路

「三数之和」的进阶版：排序 + 两层循环 + 双指针。

## Java 代码实现

### 方法：排序 + 双指针（推荐）

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;
        
        for (int i = 0; i < n - 3; i++) {
            // 去重
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            // 剪枝
            if ((long) nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target) break;
            if ((long) nums[i] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target) continue;
            
            for (int j = i + 1; j < n - 2; j++) {
                // 去重
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                
                // 剪枝
                if ((long) nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target) break;
                if ((long) nums[i] + nums[j] + nums[n - 2] + nums[n - 1] < target) continue;
                
                int left = j + 1, right = n - 1;
                
                while (left < right) {
                    long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
                    
                    if (sum == target) {
                        result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                        
                        // 去重
                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (left < right && nums[right] == nums[right - 1]) right--;
                        
                        left++;
                        right--;
                    } else if (sum < target) {
                        left++;
                    } else {
                        right--;
                    }
                }
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^3)
- **空间复杂度**：O(log n)，排序所需的栈空间

## 关键点总结

1. **使用 long 避免溢出**：Java 中四个 int 相加可能溢出
2. **去重四个位置**：i、j、left、right 都要去重
3. **剪枝优化**：最小四数和 > target 则 break，最大四数和 < target 则 continue

## 易错点

1. **整数溢出**：Java 中 `nums[i] + nums[j] + nums[left] + nums[right]` 可能溢出，需要用 `long`
2. **去重条件**：`j > i + 1 && nums[j] == nums[j-1]`，不能是 `j > 0`
