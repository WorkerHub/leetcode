## 题目描述

存在一个不含 0 的环形数组 nums，每个 nums[i] 都表示位于下标 i 的角色应该向前或向后移动的下标个数：

- 如果 nums[i] 是正数，向前（下标递增方向）移动 |nums[i]| 步
- 如果 nums[i] 是负数，向后（下标递减方向）移动 |nums[i]| 步

因为数组是环形的，所以可以假设从最后一个元素向前移动一步会到达第一个元素，从第一个元素向后移动一步会到达最后一个元素。

数组中的循环由长度为 k 的下标序列 seq 标识：

- 遵循上述移动规则将导致一组重复下标序列 seq[0] -> seq[1] -> ... -> seq[k - 1] -> seq[0] -> ...
- 所有 nums[seq[j]] 应当不是全正就是全负
- k > 1

如果 nums 中存在循环，返回 true；否则，返回 false。

**示例 1:**

```
输入: nums = [2,-1,1,2,2]
输出: true
解释: 存在循环，按下标 0 -> 2 -> 3 -> 0。循环长度为 3。
```

**示例 2:**

```
输入: nums = [-1,2]
输出: false
```

**示例 3:**

```
输入: nums = [-2,1,-1,-2,-2]
输出: false
```

**提示:**

- 1 <= nums.length <= 5000
- -1000 <= nums[i] <= 1000
- nums[i] != 0

**进阶:** 你能设计一个时间复杂度为 O(n) 且额外空间复杂度为 O(1) 的算法吗？

## 解题思路

使用**快慢指针**检测环，类似 [142. Linked List Cycle II](https://leetcode.com/problems/linked-list-cycle-ii/)。

**关键点：**
1. 循环必须是同方向的（全正或全负）
2. 循环长度必须 > 1
3. 使用快慢指针检测环

## Java 代码实现

### 方法一：快慢指针（推荐）

```java
class Solution {
    public boolean circularArrayLoop(int[] nums) {
        // 快慢指针检测环
        // 时间复杂度: O(n)
        // 空间复杂度: O(1)
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            // 如果已经访问过（被标记为 0），跳过
            if (nums[i] == 0) {
                continue;
            }

            // 快慢指针
            int slow = i;
            int fast = i;
            // 记录起始方向（正数为前向，负数为后向）
            boolean forward = nums[i] > 0;

            while (true) {
                // 移动慢指针
                slow = nextIndex(nums, slow, forward);
                if (slow == -1) break;

                // 移动快指针两次
                fast = nextIndex(nums, fast, forward);
                if (fast == -1) break;
                fast = nextIndex(nums, fast, forward);
                if (fast == -1) break;

                // 找到环
                if (slow == fast) {
                    // 检查环长度是否 > 1
                    if (slow == nextIndex(nums, slow, forward)) {
                        break; // 自环，不满足 k > 1
                    }
                    return true;
                }
            }

            // 标记已访问（将路径上的元素置为 0）
            int cur = i;
            while (nums[cur] != 0 && (nums[cur] > 0) == forward) {
                int next = ((cur + nums[cur]) % n + n) % n;
                nums[cur] = 0;
                cur = next;
            }
        }

        return false;
    }

    /**
     * 计算下一个索引，若方向不一致或形成自环则返回 -1
     */
    private int nextIndex(int[] nums, int i, boolean forward) {
        int n = nums.length;
        // 方向不一致，终止
        if ((nums[i] > 0) != forward) {
            return -1;
        }
        // 计算下一个位置（处理负数取模）
        int next = ((i + nums[i]) % n + n) % n;
        // 自环，终止
        if (next == i) {
            return -1;
        }
        return next;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **环检测**：快慢指针经典应用
2. **方向一致性**：循环必须同方向
3. **长度限制**：环长度必须 > 1
4. **负数取模**：Java 中负数取模可能为负，需要 `((i + nums[i]) % n + n) % n` 确保非负
