## 题目描述

给你字符串 `s` 和整数 `k`，每次操作可将任意字符替换为字母表中的前一个或后一个（循环），最多 k 次操作，返回可获得的最长回文子序列长度。

## 解题思路

区间 DP：`dp[i][j][ops]` 表示使用 ops 次操作后子串 `s[i..j]` 的最长回文子序列长度。两端字符变为相同的代价为 `min(|c1-c2|, 26-|c1-c2|)`（环形距离）。若剩余操作数 >= 代价，则可以配对两端并向内收缩。

## Java 代码实现

```java
class Solution {
    public int longestPalindromicSubsequence(String s, int k) {
        int n = s.length();
        // dp[i][j][ops]: s[i..j] 使用至多 ops 次操作的最长回文子序列
        int[][][] dp = new int[n][n][k + 1];

        // 初始化单字符
        for (int i = 0; i < n; i++)
            for (int ops = 0; ops <= k; ops++)
                dp[i][i][ops] = 1;

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                int diff = Math.abs(s.charAt(i) - s.charAt(j));
                int cost = Math.min(diff, 26 - diff); // 环形距离

                for (int ops = 0; ops <= k; ops++) {
                    // 不配对两端
                    int best = Math.max(
                        (i + 1 <= j ? dp[i + 1][j][ops] : 0),
                        (i <= j - 1 ? dp[i][j - 1][ops] : 0)
                    );

                    // 配对两端
                    if (ops >= cost) {
                        int inner = (len == 2) ? 0 : dp[i + 1][j - 1][ops - cost];
                        best = Math.max(best, inner + 2);
                    }

                    dp[i][j][ops] = best;
                }
            }
        }

        return dp[0][n - 1][k];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)
- 空间复杂度：O(n^2 * k)

## 关键点总结

1. 区间 DP：以子串长度为阶段，两端配对向内收缩
2. 两端字符变相同的代价：环形距离 `min(diff, 26-diff)`
3. ops 维度表示已用操作数，len == 2 时内部为空，直接 +2
