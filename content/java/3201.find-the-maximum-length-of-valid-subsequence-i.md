## 题目描述

给你整数数组 `nums`，若子序列中所有相邻元素之和的奇偶性相同，则称为有效子序列，返回最长有效子序列的长度。

## 解题思路

有效子序列只有三类：全偶、全奇、奇偶交替（包括以奇或以偶开头两种）。用 DP：`dp[p][q]` 表示末尾元素奇偶性为 p、与前一元素之和奇偶性为 q 时的最长子序列长度，对每个元素更新两种目标余数 q=0,1。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums) {
        // dp[p][q]: 末尾元素奇偶为 p，相邻和奇偶为 q 的最长子序列
        int[][] dp = new int[2][2];
        int ans = 0;
        for (int x : nums) {
            int p = x % 2;
            for (int q = 0; q < 2; q++) {
                // 前一元素奇偶 prevP 满足 (prevP + p) % 2 == q
                int prevP = (q - p + 2) % 2;
                dp[p][q] = dp[prevP][q] + 1;
                ans = Math.max(ans, dp[p][q]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 有效子序列按相邻和的奇偶性分类，只有 2 种目标余数（0 或 1）
2. DP 状态为（末尾元素奇偶性，目标相邻和奇偶性），大小 2×2
3. 同时处理全奇、全偶、奇偶交替三种情况
