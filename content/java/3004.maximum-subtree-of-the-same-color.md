## 题目描述

给一棵有颜色的树（n 个节点），返回最大的"同色子树"的节点数，子树内所有节点颜色相同。

## 解题思路

后序 DFS：记录每个节点的子树大小和是否为同色子树。若所有子节点的子树都是同色且颜色与当前节点相同，则当前子树也是同色的。

## Java 代码实现

```java
class Solution {
    private int[] color, parent;
    private List<Integer>[] children;
    private int[] subtreeSize;
    private boolean[] isSame;
    private int ans = 1;

    public int maximumSubtreeSize(int[][] edges, int[] color) {
        int n = color.length;
        this.color = color;
        children = new List[n];
        for (int i = 0; i < n; i++) children[i] = new ArrayList<>();
        int[] par = new int[n];
        par[0] = -1;
        // 建树（edges[i] = [parent, child]）
        for (int[] e : edges) {
            children[e[0]].add(e[1]);
        }
        subtreeSize = new int[n];
        isSame = new boolean[n];
        dfs(0, color);
        return ans;
    }

    private void dfs(int u, int[] color) {
        subtreeSize[u] = 1;
        isSame[u] = true;
        for (int v : children[u]) {
            dfs(v, color);
            subtreeSize[u] += subtreeSize[v];
            // 子节点颜色不同或子树非同色，则当前子树非同色
            if (color[v] != color[u] || !isSame[v]) {
                isSame[u] = false;
            }
        }
        if (isSame[u]) {
            ans = Math.max(ans, subtreeSize[u]);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 后序 DFS 先处理所有子节点再判断当前节点
2. 同色子树条件：所有子节点同色且与当前节点颜色相同
3. 累计子树大小，取最大值
