## 题目描述

给定布尔表达式字符串（含 `t`/`f`、`!`/`&`/`|` 和括号），返回运算结果。

**示例：**
```
输入：expression = "!(&(f,t))"
输出：true
```

## 解题思路

栈：遍历字符，除逗号外入栈。遇 `)` 时弹出至 `(`，收集值后弹出运算符，计算结果压回栈。

## Java 代码实现

```java
class Solution {
    public boolean parseBoolExpr(String expression) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : expression.toCharArray()) {
            if (c == ',') continue;

            if (c == ')') {
                // 收集括号内的值
                List<Character> values = new ArrayList<>();
                while (stack.peek() != '(') {
                    values.add(stack.pop());
                }
                stack.pop(); // 弹出 '('
                char op = stack.pop(); // 弹出运算符

                // 根据运算符计算结果
                char result;
                if (op == '&') {
                    result = values.contains('f') ? 'f' : 't';
                } else if (op == '|') {
                    result = values.contains('t') ? 't' : 'f';
                } else { // '!'
                    result = values.get(0) == 't' ? 'f' : 't';
                }
                stack.push(result);
            } else {
                stack.push(c);
            }
        }

        return stack.peek() == 't';
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈处理嵌套**：后进先出匹配括号结构
2. **遇 `)` 计算**：一个子表达式结束时触发求值
3. **& 短路**：含 'f' 即为 false；| 含 't' 即为 true
