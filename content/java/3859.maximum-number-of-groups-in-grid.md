## 题目描述

给你一个 `m x n` 的矩阵，将所有单元格分成若干组（第 1 组 1 个，第 2 组 2 个，第 3 组 3 个...，严格递增）。返回最多可以分成的组数。

## 解题思路

设最多分 k 组，需要的格子总数为 `1+2+...+k = k*(k+1)/2`。用二分查找找满足 `k*(k+1)/2 <= m*n` 的最大 k。注意 m*n 可能超 int 范围，使用 long。

## Java 代码实现

```java
class Solution {
    public int maximumGroups(int m, int n) {
        long total = (long) m * n;

        // 二分查找最大 k，使得 k*(k+1)/2 <= total
        long lo = 1, hi = (long) Math.sqrt(2.0 * total) + 2;

        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (mid * (mid + 1) / 2 <= total) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }

        return (int) lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log(sqrt(mn)))
- 空间复杂度：O(1)

## 关键点总结

1. 最多 k 组的充要条件：`k*(k+1)/2 <= m*n`。
2. m*n 最大为 10^12，需要使用 long 类型。
3. 二分上界设为 `sqrt(2*mn)`，因为最大 k 约为这个量级。
