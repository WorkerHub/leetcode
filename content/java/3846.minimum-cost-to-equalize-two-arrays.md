## 题目描述

给你两个整数数组 `nums1` 和 `nums2`（长度相同），以及两个整数 `cost1` 和 `cost2`。每次操作可以选择将 `nums1` 中某元素加 1（花费 `cost1`），或将 `nums1` 和 `nums2` 各一个元素同时加 1（花费 `cost2`）。使得 `nums1[i] >= nums2[i]` 对所有 i 成立，返回最小总花费。

## 解题思路

计算所有位置的差值之和 `total`。若 `2*cost2 < cost1`，则用操作二（成对操作）更划算；否则每个单位用操作一。奇数个单位时最后一个必须用操作一。

## Java 代码实现

```java
class Solution {
    public long minCost(int[] nums1, int[] nums2, int cost1, int cost2) {
        long total = 0;
        // 计算所有需要补足的差值之和
        for (int i = 0; i < nums1.length; i++) {
            if (nums1[i] < nums2[i]) {
                total += nums2[i] - nums1[i];
            }
        }
        // 判断操作二是否更划算
        if (2L * cost2 < cost1) {
            // 每两个单位用操作二，奇数剩余一个用操作一
            return (total / 2) * (2L * cost2) + (total % 2) * cost1;
        } else {
            // 操作一更划算
            return total * cost1;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个需要补足的差值单位可用操作一（cost1）或配合操作二（2*cost2）。
2. 若 `2*cost2 < cost1`，则操作二更经济。
3. 奇数个单位时，最后一个必须用操作一（操作二需要两个单位配对）。
