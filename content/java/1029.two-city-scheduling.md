## 题目描述

2n 人飞往 a 市或 b 市，costs[i] = [aCost, bCost]，每个城市恰好 n 人，返回最低总费用。

**示例：**
```
输入：costs = [[10,20],[30,200],[400,50],[30,20]]
输出：110
```

## 解题思路

贪心：按 aCost - bCost 排序（即去 A 的相对优势），前 n 人去 A 市，后 n 人去 B 市。

## Java 代码实现

```java
class Solution {
    public int twoCitySchedCost(int[][] costs) {
        // 按去A相对去B的优势排序
        Arrays.sort(costs, (a, b) -> (a[0] - a[1]) - (b[0] - b[1]));

        int n = costs.length / 2;
        int total = 0;

        // 前n人去A市（去A更划算）
        for (int i = 0; i < n; i++) {
            total += costs[i][0];
        }
        // 后n人去B市
        for (int i = n; i < 2 * n; i++) {
            total += costs[i][1];
        }

        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **相对优势排序**：按 aCost - bCost 升序
2. **贪心分配**：前半去 A，后半去 B
3. **问题转化**：选择问题变排序问题
