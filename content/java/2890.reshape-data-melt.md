## 题目描述

给定宽格式 DataFrame report（每列是一个季度），将其转换为长格式（每行一个季度记录）。

## 解题思路

本题为 Python Pandas 专项练习，使用 `pd.melt(df, id_vars='product', var_name='quarter', value_name='sales')` 宽格式转长格式。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// pd.melt() 宽格式转长格式，与 pivot 相反

import java.util.*;

class Solution {
    // Java 中模拟 melt：将列名转换为行数据
    public List<String[]> meltTable(Map<String, Map<String, Integer>> report) {
        // report: product -> {quarter -> sales}
        List<String[]> result = new ArrayList<>();
        for (Map.Entry<String, Map<String, Integer>> entry : report.entrySet()) {
            String product = entry.getKey();
            for (Map.Entry<String, Integer> qEntry : entry.getValue().entrySet()) {
                result.add(new String[]{product, qEntry.getKey(), String.valueOf(qEntry.getValue())});
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 行 m 列
- **空间复杂度**：O(n × m)

## 关键点总结

1. `pd.melt()` 将宽格式转为长格式（与 pivot 相反）
2. `id_vars`：不参与转换的列，`var_name`：列名的新列名，`value_name`：值的新列名
3. Java 中需要手动遍历所有列来生成行记录
