## 题目描述

给你一棵有 n 个节点的有根树（根为 0）和查询数组，每个查询 `[node, val]` 要求找从 `node` 到根路径上与 `val` 异或值最大的节点值，返回所有查询的答案。

## 解题思路

DFS + 动态 Trie：进入节点时将节点值插入 Trie，离开时删除。对每个查询，DFS 到达对应节点时 Trie 中恰好包含路径上所有节点值，此时查询最大异或值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final int BITS = 18;
    int[] trieCount = new int[1 << 20]; // Trie 节点计数

    public int[] maxGeneticDifference(int[] parents, int[][] queries) {
        int n = parents.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        int root = -1;
        for (int i = 0; i < n; i++) {
            if (parents[i] == -1) root = i;
            else children.get(parents[i]).add(i);
        }

        // 按节点分组查询
        List<List<int[]>> qMap = new ArrayList<>();
        for (int i = 0; i < n; i++) qMap.add(new ArrayList<>());
        for (int i = 0; i < queries.length; i++)
            qMap.get(queries[i][0]).add(new int[]{queries[i][1], i});

        int[] ans = new int[queries.length];
        // 迭代 DFS
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{root, 0}); // {node, leaving}
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            int node = cur[0];
            if (cur[1] == 1) {
                insert(node, -1); // 离开节点，删除
            } else {
                insert(node, 1);  // 进入节点，插入
                stack.push(new int[]{node, 1}); // 标记离开
                for (int[] q : qMap.get(node))
                    ans[q[1]] = query(q[0]);
                for (int child : children.get(node))
                    stack.push(new int[]{child, 0});
            }
        }
        return ans;
    }

    private void insert(int x, int delta) {
        int cur = 0;
        for (int bit = BITS; bit >= 0; bit--) {
            int b = (x >> bit) & 1;
            cur = cur * 2 + b + 1;
            trieCount[cur] += delta;
        }
    }

    private int query(int x) {
        int cur = 0, res = 0;
        for (int bit = BITS; bit >= 0; bit--) {
            int b = (x >> bit) & 1;
            int want = 1 - b; // 希望走异路方向
            int nxt = cur * 2 + want + 1;
            if (trieCount[nxt] > 0) {
                res |= (1 << bit);
                cur = nxt;
            } else {
                cur = cur * 2 + b + 1;
            }
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) * BITS)
- **空间复杂度**：O(n * BITS)

## 关键点总结

1. 动态 Trie 在进入/离开节点时插入/删除，保证查询时 Trie 恰好是当前路径
2. 节点值最大约 10^5，用 18 位二进制
3. 迭代 DFS 避免递归栈溢出
