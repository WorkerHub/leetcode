## 题目描述

给定递增质数数组 `arr`，对所有 `i < j` 的下标对可得分数 `arr[i]/arr[j]`，返回第 `k` 个最小分数对应的 `[arr[i], arr[j]]`。

## Java 代码实现

```java
class Solution {
    public int[] kthSmallestPrimeFraction(int[] arr, int k) {
        int n = arr.length;
        double left = 0, right = 1;

        while (true) {
            double mid = (left + right) / 2;
            int count = 0;
            int[] maxFrac = {0, 1};  // 记录不超过 mid 的最大分数

            // 双指针统计 arr[i]/arr[j] <= mid 的对数
            int j = 0;
            for (int i = 0; i < n; i++) {
                while (j < n && arr[i] > mid * arr[j]) j++;
                count += (n - j);
                if (j < n && (long) arr[i] * maxFrac[1] > (long) maxFrac[0] * arr[j]) {
                    maxFrac[0] = arr[i];
                    maxFrac[1] = arr[j];
                }
            }

            if (count == k) return maxFrac;
            else if (count < k) left = mid;
            else right = mid;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(1/eps))，二分约 50 次，每次 O(n) 双指针统计
- 空间复杂度：O(1)

## 关键点总结

1. 对分数值进行二分，双指针统计不超过 mid 的分数对数
2. 同时记录不超过 mid 的最大分数作为答案候选
3. 用乘法比较分数大小，避免浮点误差（`arr[i] * maxFrac[1] > maxFrac[0] * arr[j]`）
