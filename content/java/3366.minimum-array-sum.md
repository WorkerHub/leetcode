## 题目描述

给你整数数组 `nums` 和整数 `k`、`op1`、`op2`。操作 1：对某个元素除以 2 向上取整，最多 `op1` 次（每个元素最多用一次）。操作 2：对某个 >= k 的元素减去 k，最多 `op2` 次（每个元素最多用一次）。返回操作后数组元素之和的最小值。

## 解题思路

DP：`dp[j1][j2]` 为使用了 j1 次操作 1 和 j2 次操作 2 时的最小总和。对每个元素枚举不操作/只用操作1/只用操作2/先1后2/先2后1五种情况，取最小值。

## Java 代码实现

```java
class Solution {
    public int minArraySum(int[] nums, int k, int op1, int op2) {
        // dp[j1][j2] = 已用 j1 次操作1、j2 次操作2 时的最小总和
        int[][] dp = new int[op1 + 1][op2 + 1];
        final int INF = Integer.MAX_VALUE / 2;
        for (int[] row : dp) java.util.Arrays.fill(row, INF);
        dp[0][0] = 0;

        for (int x : nums) {
            int[][] newDp = new int[op1 + 1][op2 + 1];
            for (int[] row : newDp) java.util.Arrays.fill(row, INF);

            for (int j1 = 0; j1 <= op1; j1++) {
                for (int j2 = 0; j2 <= op2; j2++) {
                    if (dp[j1][j2] == INF) continue;
                    int base = dp[j1][j2];

                    // 不操作
                    newDp[j1][j2] = Math.min(newDp[j1][j2], base + x);

                    // 只用操作 1（向上取整除以 2）
                    if (j1 < op1) {
                        newDp[j1 + 1][j2] = Math.min(newDp[j1 + 1][j2], base + (x + 1) / 2);
                    }

                    // 只用操作 2（x >= k）
                    if (j2 < op2 && x >= k) {
                        newDp[j1][j2 + 1] = Math.min(newDp[j1][j2 + 1], base + x - k);
                    }

                    // 操作 1 + 操作 2
                    if (j1 < op1 && j2 < op2) {
                        // 先操作 1 后操作 2
                        int afterOp1 = (x + 1) / 2;
                        if (afterOp1 >= k) {
                            newDp[j1 + 1][j2 + 1] = Math.min(newDp[j1 + 1][j2 + 1], base + afterOp1 - k);
                        }
                        // 先操作 2 后操作 1
                        if (x >= k) {
                            int afterOp2 = x - k;
                            newDp[j1 + 1][j2 + 1] = Math.min(newDp[j1 + 1][j2 + 1], base + (afterOp2 + 1) / 2);
                        }
                    }
                }
            }
            dp = newDp;
        }

        int ans = INF;
        for (int[] row : dp) {
            for (int v : row) {
                ans = Math.min(ans, v);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * op1 * op2)，DP
- 空间复杂度：O(op1 * op2)

## 关键点总结

1. 每个元素每种操作最多用一次，枚举 5 种组合取最小。
2. 两种操作顺序（先 1 后 2 vs 先 2 后 1）结果可能不同，需要都考虑。
3. 操作 2 要求元素 >= k，操作 1 向上取整 = `(x + 1) / 2`。
