## 题目描述

给定正整数数组 `nums`，子数组的"GCD 分数"定义为子数组所有元素的最大公因数乘以子数组长度，求所有子数组中的最大 GCD 分数。

## Java 代码实现

```java
class Solution {
    public long maxGCDScore(int[] nums) {
        int n = nums.length;
        long ans = 0;

        // gcdGroups[i][0] = gcd 值，gcdGroups[i][1] = 该 gcd 对应的子数组长度
        // 每个右端点维护所有不同 gcd 值及其最长子数组长度
        int[][] gcdGroups = new int[0][2];

        for (int j = 0; j < n; j++) {
            int x = nums[j];
            int[][] newGroups = new int[gcdGroups.length + 1][2];
            int size = 0;

            for (int[] g : gcdGroups) {
                int ng = gcd(g[0], x);
                // 合并相同 gcd 的组
                if (size > 0 && newGroups[size - 1][0] == ng) {
                    newGroups[size - 1][1] += g[1];
                } else {
                    newGroups[size][0] = ng;
                    newGroups[size][1] = g[1] + 1;
                    size++;
                }
            }
            // 加入只含 nums[j] 的子数组
            if (size > 0 && newGroups[size - 1][0] == x) {
                // 已合并，不重复添加
            } else {
                newGroups[size][0] = x;
                newGroups[size][1] = 1;
                size++;
            }

            for (int i = 0; i < size; i++) {
                ans = Math.max(ans, (long) newGroups[i][0] * newGroups[i][1]);
            }

            gcdGroups = java.util.Arrays.copyOf(newGroups, size);
        }
        return ans;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))，每个右端点最多 O(log max_val) 个不同 gcd 组
- 空间复杂度：O(log(max_val))

## 关键点总结

1. 固定右端点时，向左扩展 GCD 单调不增
2. 不同 GCD 值的数量是 O(log max_val) 级别，合并相同 GCD 的组
3. 分数用 `long` 防止 GCD * 长度溢出
