## 题目描述

给定一棵 `n` 节点的树和每个节点的金币数 `coins[i]`，从节点 0 出发收集所有金币后返回节点 0，返回最小时间（每移动一步耗时 1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int collectTheCoins(int[] coins, int[][] edges) {
        int n = coins.length;
        List<Set<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new HashSet<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 拓扑排序剪枝：删除不含金币的叶子
        int[] degree = new int[n];
        for (int i = 0; i < n; i++) degree[i] = graph.get(i).size();
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < n; i++) if (degree[i] == 1 && coins[i] == 0) q.offer(i);
        while (!q.isEmpty()) {
            int u = q.poll();
            degree[u] = 0;
            for (int v : graph.get(u)) {
                graph.get(v).remove(u);
                degree[v]--;
                if (degree[v] == 1 && coins[v] == 0) q.offer(v);
            }
        }

        // 再剪两轮叶子（对应来回两步）
        for (int round = 0; round < 2; round++) {
            q.clear();
            for (int i = 0; i < n; i++) if (degree[i] == 1) q.offer(i);
            while (!q.isEmpty()) {
                int u = q.poll();
                degree[u] = 0;
                for (int v : graph.get(u)) {
                    graph.get(v).remove(u);
                    degree[v]--;
                }
            }
        }

        // 剩余边数 * 2 即为答案
        int edgeCount = 0;
        for (int[] e : edges) {
            if (degree[e[0]] > 0 && degree[e[1]] > 0) edgeCount++;
        }
        return edgeCount * 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，拓扑排序
- 空间复杂度：O(n)

## 关键点总结

1. 无金币的叶子节点无需访问，拓扑排序迭代剪枝
2. 每条必经边来回走需 2 步，答案为剩余边数 * 2
3. 有金币区域的叶子需额外剪两轮（对应最后两步来回）
