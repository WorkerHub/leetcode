## 题目描述

实现类 `LUPrefix`：支持上传视频（编号 1 到 n）和查询当前最长已上传前缀的长度（编号 1 到 i 的视频全部已上传）。

## 解题思路

维护变量 `prefix` 表示当前最长已上传前缀长度，用布尔数组记录上传状态。每次上传后，尝试从 `prefix+1` 开始向右延伸，直到找到未上传的视频。`prefix` 单调递增，while 循环总次数不超过 n，均摊 O(1)。

## Java 代码实现

```java
class LUPrefix {
    private boolean[] done;
    private int prefix;

    public LUPrefix(int n) {
        done = new boolean[n + 2]; // 下标 1 到 n
        prefix = 0;
    }

    public void upload(int video) {
        done[video] = true;
        // 尝试向右延伸已上传前缀
        while (done[prefix + 1]) {
            prefix++;
        }
    }

    public int longest() {
        return prefix;
    }
}
```

## 复杂度分析

- **时间复杂度**：upload 均摊 O(1)，longest O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. 维护「最长已上传前缀」变量，只需在 upload 时尝试延伸
2. `prefix` 单调递增，while 循环总执行次数最多 n 次
3. 布尔数组查询 O(1) 且常数小
