## 题目描述

Alice 从 `word="a"` 开始，每轮将每个字符替换为字母表下一个字符后追加到末尾。给你整数 `k`（1 索引），返回最终 `word` 的第 `k` 个字符。

## 解题思路

规律：位置 `i`（0 索引）处的字符由 `i` 的二进制中 1 的个数决定，即偏移量 = `popcount(k-1)`。

## Java 代码实现

```java
class Solution {
    public char kthCharacter(int k) {
        // 第 k 个字符（0 索引 k-1）的偏移量 = k-1 的二进制中 1 的个数
        return (char) ('a' + Integer.bitCount(k - 1));
    }
}
```

## 复杂度分析

- 时间复杂度：O(log k)
- 空间复杂度：O(1)

## 关键点总结

1. 位置 i（0 索引）的字符偏移量 = `popcount(i)`（i 的二进制中 1 的个数）
2. `Integer.bitCount(n)` 直接计算 popcount
3. k <= 500 < 2^9，偏移量最大为 9，不超过 26 个字母
