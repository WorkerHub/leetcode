## 题目描述

给定整数数组 `nums`，可执行一次操作：选择任意子数组，将子数组中的最小值替换为最大值。返回操作后整个数组的最大子数组和。

## 解题思路

DP 维护两个状态：`dpNo`（以当前位置结尾、未操作的最大子数组和）和 `dpOp`（已执行一次操作的最大子数组和）。操作可选可不选，取全局最大值。

## Java 代码实现

```java
class Solution {
    public long maxSubarraySum(int[] nums) {
        int n = nums.length;
        long dpNo = nums[0];   // 不操作，以 i 结尾的最大子数组和
        long dpOp = nums[0];   // 操作一次，以 i 结尾的最大子数组和
        long ans = Math.max(dpNo, dpOp);

        for (int i = 1; i < n; i++) {
            long x = nums[i];
            long newNo = Math.max(x, dpNo + x);
            // 已操作：要么延伸已操作子数组，要么在不操作基础上延伸
            long newOp = Math.max(newNo, dpOp + x);
            dpNo = newNo;
            dpOp = newOp;
            ans = Math.max(ans, Math.max(dpNo, dpOp));
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 操作是可选的，需要对比操作前后的结果
2. DP 两个状态：未操作 vs 已操作一次
3. 已操作状态从未操作状态转移，确保操作恰好发生一次
