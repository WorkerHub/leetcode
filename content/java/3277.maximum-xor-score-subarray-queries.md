## 题目描述

给你整数数组 `nums` 和查询数组 `queries[i]=[li,ri]`。子数组的 XOR 分数定义为反复将相邻两元素 XOR 合并后能得到的最大值。返回每个查询对应的 XOR 分数。

## 解题思路

预计算两个 DP 表：`dp[i][j]` 为子数组 `[i,j]` 的规约 XOR（`dp[i][j] = dp[i][j-1] ^ dp[i+1][j]`），`maxXor[i][j]` 为区间内所有子数组规约 XOR 的最大值。查询直接 O(1) 回答。

## Java 代码实现

```java
class Solution {
    public int[] maximumSubarrayXor(int[] nums, int[][] queries) {
        int n = nums.length;
        int[][] dp = new int[n][n];
        int[][] maxXor = new int[n][n];

        // 初始化单元素
        for (int i = 0; i < n; i++) {
            dp[i][i] = nums[i];
            maxXor[i][i] = nums[i];
        }

        // 按长度递推
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = dp[i][j - 1] ^ dp[i + 1][j];
                maxXor[i][j] = Math.max(dp[i][j],
                               Math.max(maxXor[i][j - 1], maxXor[i + 1][j]));
            }
        }

        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            ans[i] = maxXor[queries[i][0]][queries[i][1]];
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n² + q)，预计算 O(n²)，每次查询 O(1)
- 空间复杂度：O(n²)

## 关键点总结

1. 规约 XOR：`dp[i][j] = dp[i][j-1] ^ dp[i+1][j]`，初始值 `dp[i][i] = nums[i]`
2. 区间最大：`maxXor[i][j] = max(dp[i][j], maxXor[i][j-1], maxXor[i+1][j])`
3. 两表均可 O(n²) 预计算，之后 O(1) 回答每个查询
