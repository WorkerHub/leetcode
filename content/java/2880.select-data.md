## 题目描述

给定 DataFrame students，选取 student_id = 101 的学生的 name 和 age。

## 解题思路

本题为 Python Pandas 专项练习，使用布尔索引过滤行并选择列：`df[df['student_id'] == 101][['name', 'age']]`。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// 等价于：过滤满足条件的行，然后只保留特定列

import java.util.*;

class Solution {
    // 模拟：从学生列表中筛选 id=101 的 name 和 age
    public List<String> selectData(List<int[]> students, String[] names) {
        for (int i = 0; i < students.size(); i++) {
            if (students.get(i)[0] == 101) {
                // 返回 name 和 age
                return Arrays.asList(names[i], String.valueOf(students.get(i)[1]));
            }
        }
        return Collections.emptyList();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 行过滤：`df[df['col'] == val]`
2. 列选择：`df[['col1', 'col2']]`
3. 组合使用：先过滤行，再选列
