## 题目描述

给你字符串数组 `words` 和整数 `k`，对每个下标 i，删除 `words[i]` 后返回在剩余字符串中出现至少 k 次的最长公共前缀的长度，结果存入数组返回。

## 解题思路

字典树（Trie）：插入所有单词，每个节点维护经过该节点的单词计数。对每个 i，临时将 words[i] 路径上所有节点计数减 1，从根出发找唯一的 count>=k 路径的深度作为答案，再恢复计数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] count;
    private int[][] children;
    private int nodeCount = 1;

    public int[] longestCommonPrefix(String[] words, int k) {
        int n = words.length;
        int maxNodes = 0;
        for (String w : words) maxNodes += w.length();
        maxNodes++;

        count = new int[maxNodes];
        children = new int[maxNodes][26];

        // 插入所有单词，返回每个单词的节点路径
        int[][] paths = new int[n][];
        for (int i = 0; i < n; i++) {
            paths[i] = insert(words[i]);
        }

        int[] answer = new int[n];
        for (int i = 0; i < n; i++) {
            // 临时减少 words[i] 路径上的计数
            for (int node : paths[i]) count[node]--;
            answer[i] = query(k);
            // 恢复
            for (int node : paths[i]) count[node]++;
        }

        return answer;
    }

    private int[] insert(String word) {
        int node = 0;
        int[] path = new int[word.length()];
        for (int i = 0; i < word.length(); i++) {
            int c = word.charAt(i) - 'a';
            if (children[node][c] == 0) {
                children[node][c] = nodeCount++;
            }
            node = children[node][c];
            count[node]++;
            path[i] = node;
        }
        return path;
    }

    private int query(int k) {
        int node = 0;
        int depth = 0;
        while (true) {
            // 找恰好一个 count >= k 的子节点
            int next = -1;
            int validCount = 0;
            for (int c = 0; c < 26; c++) {
                int child = children[node][c];
                if (child != 0 && count[child] >= k) {
                    next = child;
                    validCount++;
                }
            }
            if (validCount != 1) break; // 无子节点或多个分叉
            node = next;
            depth++;
        }
        return depth;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为单词数，L 为最长单词长度
- 空间复杂度：O(n * L)

## 关键点总结

1. Trie 节点维护经过该节点的单词数，删除操作 O(L) 减计数再恢复
2. 查询时从根出发，唯一 count>=k 的子节点方向继续，否则停止
3. 多个子节点满足条件时公共前缀分叉，停止
