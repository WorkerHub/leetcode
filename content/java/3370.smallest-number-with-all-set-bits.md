## 题目描述

给你整数 `n`，返回大于等于 `n` 且二进制表示中所有位都是 1 的最小整数（即最小的 `2^k - 1 >= n`）。

## 解题思路

若 `n & (n+1) == 0`，说明 `n` 本身已是全 1，直接返回 n。否则，取 `n` 的二进制位长度 `k = 32 - Integer.numberOfLeadingZeros(n)`，返回 `(1 << k) - 1`。

## Java 代码实现

```java
class Solution {
    public int smallestNumber(int n) {
        // 若 n 已经是全 1（n & (n+1) == 0），直接返回 n
        if ((n & (n + 1)) == 0) {
            return n;
        }
        // 取 n 的二进制位长度 k，返回 2^k - 1
        int k = 32 - Integer.numberOfLeadingZeros(n);
        return (1 << k) - 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)，位运算
- 空间复杂度：O(1)

## 关键点总结

1. 全 1 二进制数形如 `1, 3, 7, 15, 31, ...`（即 `2^k - 1`）。
2. `n & (n+1) == 0` 当且仅当 n 是全 1 数。
3. `Integer.numberOfLeadingZeros(n)` 可快速获取位长度。
