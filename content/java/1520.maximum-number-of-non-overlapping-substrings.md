## 题目描述

给定字符串 s，找最多个数的不重叠子串集合，要求：若包含字符 c，则 c 的所有出现位置都在该子串中。

**示例：**
```
输入：s = "adefaddaccc"
输出：["e","f","ccc"]
```

## 解题思路

1. 预处理每个字符的左右边界
2. 扩展区间使其包含所有内部字符的完整出现
3. 按右端点排序，贪心选取不重叠区间

## Java 代码实现

```java
class Solution {
    public List<String> maxNumOfSubstrings(String s) {
        int n = s.length();
        int[] left = new int[26], right = new int[26];
        Arrays.fill(left, n);
        Arrays.fill(right, -1);
        
        // 记录每个字符的左右边界
        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            left[c] = Math.min(left[c], i);
            right[c] = Math.max(right[c], i);
        }
        
        // 对每个字符扩展区间
        List<int[]> intervals = new ArrayList<>();
        for (int c = 0; c < 26; c++) {
            if (right[c] == -1) continue;
            int l = left[c], r = right[c];
            boolean valid = true;
            for (int i = l; i <= r; i++) {
                int ch = s.charAt(i) - 'a';
                if (left[ch] < l) { valid = false; break; }
                r = Math.max(r, right[ch]);
            }
            if (valid) intervals.add(new int[]{l, r});
        }
        
        // 按右端点排序，贪心选取
        intervals.sort((a, b) -> a[1] - b[1]);
        List<String> result = new ArrayList<>();
        int prevEnd = -1;
        for (int[] interval : intervals) {
            if (interval[0] > prevEnd) {
                result.add(s.substring(interval[0], interval[1] + 1));
                prevEnd = interval[1];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 26)
- **空间复杂度**：O(26)

## 关键点总结

1. **字符边界**：每个字符的最左和最右位置
2. **区间扩展**：包含所有内部字符的完整出现
3. **贪心调度**：按右端点排序选不重叠
4. **有效性检查**：扩展时若左边界缩小则无效
