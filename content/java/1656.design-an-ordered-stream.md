## 题目描述

设计有序流：`insert(idKey, value)` 插入元素，返回从当前最小未返回 ID 开始连续已插入的 value 序列。

## 解题思路

维护数组存储 value，用指针 `ptr` 指向当前最小未返回 ID。每次插入后从 `ptr` 开始连续收集已插入的值。

## Java 代码实现

```java
class OrderedStream {
    private String[] data; // 1-indexed
    private int ptr;       // 当前最小未返回 ID

    public OrderedStream(int n) {
        data = new String[n + 1];
        ptr = 1;
    }

    public List<String> insert(int idKey, String value) {
        data[idKey] = value;
        List<String> result = new ArrayList<>();
        // 从 ptr 开始，连续返回已插入的值
        while (ptr < data.length && data[ptr] != null) {
            result.add(data[ptr]);
            ptr++;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：每次 insert O(k)，k 为当次返回元素数；总体 O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 维护指针 `ptr` 跟踪最小未返回 ID
2. 每个元素最多被访问两次（插入时 + 返回时），总 O(n)
3. 数组使用 1-indexed，空出 0 号位
