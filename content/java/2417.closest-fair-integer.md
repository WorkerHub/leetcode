## 题目描述

给你一个正整数 `n`，返回大于等于 `n` 的最小**公平整数**（各位中奇数数字个数等于偶数数字个数的整数）。

## 解题思路

公平整数的位数必须为偶数。若 `n` 的位数是奇数，直接跳到下一个偶数位数的最小公平整数（形如 `1...10...0`）；若位数是偶数，则从 `n` 开始枚举直到找到奇偶位数相等的数，若位数增加则跳到新位数的最小公平整数。

## Java 代码实现

```java
class Solution {
    // 判断 x 是否为公平整数
    private boolean isFair(int x) {
        int odd = 0, even = 0;
        while (x > 0) {
            int d = x % 10;
            if (d % 2 == 0) even++;
            else odd++;
            x /= 10;
        }
        return odd == even;
    }

    // 获取 n 的位数
    private int numDigits(int x) {
        return String.valueOf(x).length();
    }

    // 构造 digits 位的最小公平整数（前半奇数1，后半偶数0）
    private int minFair(int digits) {
        StringBuilder sb = new StringBuilder();
        int half = digits / 2;
        for (int i = 0; i < half; i++) sb.append('1');
        for (int i = 0; i < half; i++) sb.append('0');
        return Integer.parseInt(sb.toString());
    }

    public int closestFair(int n) {
        int digits = numDigits(n);
        // 若位数为奇数，直接跳到下一个偶数位数的最小公平整数
        if (digits % 2 == 1) {
            return minFair(digits + 1);
        }
        // 偶数位数，从 n 开始枚举
        while (true) {
            if (isFair(n)) return n;
            n++;
            // 若位数增加则跳到新偶数位数的最小公平整数
            if (numDigits(n) > digits) {
                digits += 2;
                n = minFair(digits);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(枚举次数 × log n)，实际枚举次数很少
- **空间复杂度**：O(log n)

## 关键点总结

1. 公平整数的总位数必须为偶数
2. 若 `n` 为奇数位数，直接跳到下一个偶数位数的最小公平整数
3. 偶数位数时从 `n` 开始枚举，遇到位数增加则再次跳转
