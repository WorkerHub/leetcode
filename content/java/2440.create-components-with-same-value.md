## 题目描述

给你 `n` 节点无向树（节点值数组 `nums`），可以删除一些边将树分成多个连通分量，返回能删除的最多边数，使所有分量的节点值之和相等。

## 解题思路

枚举分量个数 k（S 的因子，从大到小），每个分量值 = S/k。用 DFS 验证：子树和等于目标值时切断（返回 0），超过则不可行（返回 -1）。找到最大的可行 k，返回 k-1（删除的边数）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] nums;
    private List<List<Integer>> adj;
    private int target;

    public int componentValue(int[] nums, int[][] edges) {
        int n = nums.length;
        int S = 0;
        int maxVal = 0;
        for (int v : nums) { S += v; maxVal = Math.max(maxVal, v); }
        this.nums = nums;

        adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        // 枚举分量个数 k（S 的因子，从大到小）
        for (int k = n; k > 1; k--) {
            if (S % k == 0) {
                target = S / k;
                // 目标值必须 >= 最大节点值
                if (target >= maxVal && dfs(0, -1) == 0) {
                    return k - 1;
                }
            }
        }
        return 0;
    }

    // DFS 返回子树和 mod target（-1 表示不可行）
    private int dfs(int node, int parent) {
        int subSum = nums[node];
        for (int child : adj.get(node)) {
            if (child == parent) continue;
            int childSum = dfs(child, node);
            if (childSum == -1) return -1;
            subSum += childSum;
        }
        if (subSum > target) return -1;
        return subSum % target; // 等于 target 时返回 0（切断该子树）
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × d(S))，d(S) 为 S 的因子个数
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举分割为 k 个等值分量，每个分量值 = S/k（k 必须是 S 的因子）
2. DFS 中子树和等于目标值则切断（贡献一个分量），超过则不可行
3. 目标值必须 >= max(nums)，否则单个最大值节点无法满足条件
