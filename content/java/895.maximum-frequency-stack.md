## 题目描述

设计最大频率栈：push 压入元素，pop 弹出出现频率最高的元素（频率相同则弹出最近压入的）。

**示例：**
```
push 5,7,5,7,4,5 → pop 返回 5,7,5,4
```

## 解题思路

两个 HashMap：freq 记录每个值的频率，group 按频率分组存储栈。维护 maxFreq 追踪当前最高频率。

## Java 代码实现

```java
class FreqStack {
    private Map<Integer, Integer> freq;
    private Map<Integer, Deque<Integer>> group;
    private int maxFreq;

    public FreqStack() {
        freq = new HashMap<>();
        group = new HashMap<>();
        maxFreq = 0;
    }

    public void push(int val) {
        int f = freq.merge(val, 1, Integer::sum);
        group.computeIfAbsent(f, k -> new ArrayDeque<>()).push(val);
        maxFreq = Math.max(maxFreq, f);
    }

    public int pop() {
        int val = group.get(maxFreq).pop();
        freq.merge(val, -1, Integer::sum);
        if (group.get(maxFreq).isEmpty()) {
            maxFreq--;
        }
        return val;
    }
}
```

## 复杂度分析

- **时间复杂度**：push O(1)，pop O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **频率分组**：同频率元素在同一栈中
2. **maxFreq**：追踪当前最大频率
3. **栈特性**：保证相同频率中弹出最近的
