## 题目描述

给你一个非负整数 `x`，计算并返回 `x` 的算术平方根。

由于返回类型是整数，结果只保留整数部分，小数部分将被舍去。

**注意：** 不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

**示例 1：**
```
输入：x = 4
输出：2
```

**示例 2：**
```
输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842...，由于返回类型是整数，小数部分将被舍去
```

**提示：**
- `0 <= x <= 2^31 - 1`

## 解题思路

**方法对比：**
1. **二分查找**：在[0, x]范围内查找
2. **牛顿迭代法**：快速收敛

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public int mySqrt(int x) {
        if (x == 0) return 0;

        long left = 1, right = x;

        while (left <= right) {
            long mid = left + (right - left) / 2;

            if (mid * mid == x) {
                return (int) mid;
            } else if (mid * mid < x) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        // right 是最后一个满足 right*right <= x 的值
        return (int) right;
    }
}
```

### 方法二：牛顿迭代法

```java
class Solution {
    public int mySqrt(int x) {
        if (x == 0) return 0;

        long r = x;
        while (r * r > x) {
            r = (r + x / r) / 2;
        }

        return (int) r;
    }
}
```

## 复杂度分析

**二分查找：**
- 时间复杂度：O(log x)
- 空间复杂度：O(1)

**牛顿迭代：**
- 时间复杂度：O(log x)
- 空间复杂度：O(1)

## 关键点总结

1. **二分查找**：查找满足 mid^2 <= x 的最大值
2. **返回值**：返回 right（最后一个满足条件的值）
3. **整数溢出**：mid * mid 可能超出 int 范围，使用 long

## 易错点

1. **整数溢出**：Java 中 mid * mid 如果 mid 是 int 类型可能溢出，使用 long
