## 题目描述

给定长度为 n 的整数数组 `nums`，每个元素均在 `[1, n]` 范围内，但某些元素出现了两次，某些元素缺失。要求在 O(n) 时间和 O(1) 额外空间内，找出所有在 `[1, n]` 内但未出现在 `nums` 中的整数。

## 解题思路

原地标记法：遍历数组，对每个值 v = abs(nums[i])，将下标 v-1 处的元素取反（标记已出现）。重复出现时先检查是否已为负数。最后正数下标 i 对应的值 i+1 即为缺失数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        int n = nums.length;
        // 将出现过的数字对应下标位置的值取反
        for (int i = 0; i < n; i++) {
            int idx = Math.abs(nums[i]) - 1;
            if (nums[idx] > 0) nums[idx] = -nums[idx];
        }
        // 仍为正数的下标对应缺失的数字
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) result.add(i + 1);
        }
        // 恢复原数组
        for (int i = 0; i < n; i++) nums[i] = Math.abs(nums[i]);
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1) 额外空间

## 关键点总结

1. 原地标记：将出现过的数字映射到对应下标，用符号标记
2. 重复元素只需确保对应位置被标记一次（先判断是否已为负）
3. 取反不影响后续读取（用 abs() 获取原始值）
