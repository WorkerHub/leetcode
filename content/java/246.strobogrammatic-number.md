## 题目描述

中心对称数是指一个数字在旋转了 180 度之后看起来依旧相同的数字（或者上下颠倒地看）。

编写一个函数来判断该数字是否是中心对称数，其输入将会以一个字符串的形式来表达数字。

**示例 1：**
```
输入: num = "69"
输出: true
```

**示例 2：**
```
输入: num = "88"
输出: true
```

**示例 3：**
```
输入: num = "962"
输出: false
```

**示例 4：**
```
输入: num = "1"
输出: true
```

**提示：**
- 1 <= num.length <= 50
- num 只包含数字

## 解题思路

中心对称数的核心是：数字旋转 180 度后与原数字相同。

**关键观察：**
1. 只有 0、1、6、8、9 这 5 个数字旋转 180 度后还是数字
2. 旋转后的映射关系：
   - 0 → 0
   - 1 → 1
   - 6 → 9
   - 8 → 8
   - 9 → 6
3. 其他数字（2、3、4、5、7）旋转后不是有效数字

**算法思路：**
- 使用双指针从两端向中间检查
- 左指针的数字旋转后应该等于右指针的数字
- 如果某个位置的数字不能旋转（2、3、4、5、7），直接返回 false

## Java 代码实现

### 方法一：双指针 + 哈希表（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isStrobogrammatic(String num) {
        // 旋转映射关系
        Map<Character, Character> rotationMap = new HashMap<>();
        rotationMap.put('0', '0');
        rotationMap.put('1', '1');
        rotationMap.put('6', '9');
        rotationMap.put('8', '8');
        rotationMap.put('9', '6');
        
        int left = 0, right = num.length() - 1;
        
        while (left <= right) {
            char leftChar = num.charAt(left);
            char rightChar = num.charAt(right);
            
            // 检查左边字符是否能旋转
            if (!rotationMap.containsKey(leftChar)) {
                return false;
            }
            
            // 检查旋转后是否等于右边字符
            if (rotationMap.get(leftChar) != rightChar) {
                return false;
            }
            
            left++;
            right--;
        }
        
        return true;
    }
}
```

### 方法二：数组映射（更高效）⭐

```java
class Solution {
    public boolean isStrobogrammatic(String num) {
        // 使用数组存储映射，'-' 表示无效
        char[] rotation = {
            '0', '1', '\0', '\0', '\0', '\0', '9', '\0', '8', '6'
        };
        // rotation[0]='0', rotation[1]='1', rotation[6]='9', rotation[8]='8', rotation[9]='6'
        
        int left = 0, right = num.length() - 1;
        
        while (left <= right) {
            int leftDigit = num.charAt(left) - '0';
            int rightDigit = num.charAt(right) - '0';
            
            // 检查是否有效（rotation[i] == '\0' 表示无效）
            if (rotation[leftDigit] == '\0' || rotation[leftDigit] != num.charAt(right)) {
                return false;
            }
            
            left++;
            right--;
        }
        
        return true;
    }
}
```

### 方法三：构造旋转字符串比较

```java
class Solution {
    public boolean isStrobogrammatic(String num) {
        Map<Character, Character> rotationMap = new HashMap<>();
        rotationMap.put('0', '0');
        rotationMap.put('1', '1');
        rotationMap.put('6', '9');
        rotationMap.put('8', '8');
        rotationMap.put('9', '6');
        
        // 构造旋转后的字符串（逆序）
        StringBuilder rotated = new StringBuilder();
        for (int i = num.length() - 1; i >= 0; i--) {
            char c = num.charAt(i);
            if (!rotationMap.containsKey(c)) {
                return false;
            }
            rotated.append(rotationMap.get(c));
        }
        
        // 比较原字符串和旋转后的字符串
        return rotated.toString().equals(num);
    }
}
```

### 方法四：使用对称性检查

```java
class Solution {
    public boolean isStrobogrammatic(String num) {
        int n = num.length();
        
        for (int i = 0; i <= (n - 1) / 2; i++) {
            char left = num.charAt(i);
            char right = num.charAt(n - 1 - i);
            
            // 检查这对字符是否是有效的对称对
            if (!isValidPair(left, right)) {
                return false;
            }
        }
        
        return true;
    }
    
    private boolean isValidPair(char left, char right) {
        // 有效的对称对
        if (left == '0' && right == '0') return true;
        if (left == '1' && right == '1') return true;
        if (left == '6' && right == '9') return true;
        if (left == '8' && right == '8') return true;
        if (left == '9' && right == '6') return true;
        return false;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 双指针 + 哈希表 | O(n) | O(1) | 推荐，清晰易懂 |
| 数组映射 | O(n) | O(1) | 最高效 |
| 构造旋转字符串 | O(n) | O(n) | 需要额外空间 |
| 对称性检查 | O(n) | O(1) | 辅助函数清晰 |

## 关键点总结

1. **有效数字**：只有 0、1、6、8、9 这 5 个数字可以旋转
2. **映射关系**：6 ↔ 9 互换，0、1、8 保持不变
3. **双指针技巧**：从两端向中间检查，对称性问题的常用方法
4. **中间字符**：当长度为奇数时，中间字符必须是 0、1、8（自对称）
5. **Java 字符比较**：`char` 类型可以直接用 `==` 比较

## 易错点

1. **中间字符**：长度为奇数时，中间字符必须是 0、1、8，不能是 6 或 9
2. **映射方向**：6 旋转后是 9，9 旋转后是 6，不要弄反
3. **无效数字**：2、3、4、5、7 不能出现，出现即返回 false
4. **边界条件**：单个字符也要检查是否能自对称
5. **双指针边界**：`left <= right` 要包含等号（奇数长度需检查中间）
