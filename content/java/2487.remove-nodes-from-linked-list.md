## 题目描述

给你链表头节点 `head`，移除所有右侧存在更大节点的节点，返回修改后的链表头节点。

## 解题思路

从右到左维护最大值：保留从当前位置到末尾的最大值所在节点。反转链表后从左到右遍历，保留递减序列（大于等于当前最大值），再反转回来。

## Java 代码实现

```java
class Solution {
    public ListNode removeNodes(ListNode head) {
        // 反转链表
        ListNode rev = reverse(head);

        // 移除所有比当前最大值小的节点（从左到右维护单调不减）
        ListNode cur = rev;
        while (cur != null && cur.next != null) {
            if (cur.val > cur.next.val) {
                cur.next = cur.next.next; // 删除小节点
            } else {
                cur = cur.next;
            }
        }

        // 再次反转回来
        return reverse(rev);
    }

    private ListNode reverse(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode next = head.next;
            head.next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 保留条件：节点是从该位置到末尾的最大值（即右侧无更大节点）
2. 反转后从左到右，维护不递减序列（等价于原链表中无更大右邻）
3. 两次反转 + 一次遍历，空间 O(1)
