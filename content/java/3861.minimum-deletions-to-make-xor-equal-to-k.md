## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，每次操作可以删除数组中的一个元素。返回使数组所有元素异或值等于 `k` 所需的最少删除次数。

## 解题思路

计算全数组异或值 `total`。若 `total == k` 直接返回 0。否则需删除若干元素使其异或 = `target = total ^ k`：先检查能否一次删除（找等于 target 的元素），再检查两次删除（找两元素异或等于 target）。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minDeletions(int[] nums, int k) {
        int total = 0;
        for (int v : nums) total ^= v;

        if (total == k) return 0;

        int target = total ^ k;

        // 检查能否删除 1 个元素（某元素等于 target）
        for (int v : nums) {
            if (v == target) return 1;
        }

        // 检查能否删除 2 个元素（两元素异或 = target）
        Set<Integer> seen = new HashSet<>();
        for (int v : nums) {
            if (seen.contains(v ^ target)) return 2;
            seen.add(v);
        }

        // 最多 3 次删除
        return 3;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 删除元素 x 等价于从总异或中去掉 x，目标是找最少元素使其异或 = `total ^ k`。
2. 先检查 1 次删除，再检查 2 次删除，通常不超过 3 次。
3. 若 `total == k` 直接返回 0，不需要任何删除。
