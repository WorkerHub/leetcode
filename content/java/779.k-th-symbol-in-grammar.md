## 题目描述

构建序列：第 1 行为 0，每行将 0 替换为 01，1 替换为 10。给定行数 n 和位置 k（1-indexed），返回第 n 行第 k 个字符。

**示例：**
```
输入：n = 2, k = 2
输出：1（第2行为 "01"，第2个是 1）
```

## 解题思路

递归：第 n 行前半部分与第 n-1 行相同，后半部分为第 n-1 行取反。

## Java 代码实现

```java
class Solution {
    public int kthGrammar(int n, int k) {
        if (n == 1) return 0;

        int mid = 1 << (n - 2); // 2^(n-2)
        if (k <= mid) {
            return kthGrammar(n - 1, k);
        } else {
            return 1 - kthGrammar(n - 1, k - mid);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，递归栈

## 关键点总结

1. **递归规律**：前半部分不变，后半部分取反
2. **二分思想**：根据 k 与 mid 的关系递归
3. **取反操作**：1 - value 实现 0/1 翻转
