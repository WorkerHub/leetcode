## 题目描述

从正整数数组中选子集，排列成回文形式 [x, x², x⁴, ..., x^(2^k), ..., x⁴, x², x]，返回最长子集长度。

## 解题思路

哈希表统计每个数出现次数。对每个 x 构建序列 x, x², x⁴...，每级需要至少 2 次（两端各一），不足 2 次时可作为中心元素（+1）。特殊处理 x=1（全为 1，取最大奇数个）。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums) {
        Map<Long, Integer> count = new HashMap<>();
        for (int x : nums) count.merge((long) x, 1, Integer::sum);
        int ans = 1;
        for (long x : count.keySet()) {
            if (x == 1) {
                // 序列全为 1，取最大奇数
                int cnt = count.get(1L);
                ans = Math.max(ans, cnt % 2 == 1 ? cnt : cnt - 1);
                continue;
            }
            int length = 0;
            long cur = x;
            while (count.containsKey(cur)) {
                if (count.get(cur) >= 2) {
                    length += 2;
                    // 防止溢出
                    if (cur > 31622) { // sqrt(10^9) ≈ 31622，cur*cur > 10^9
                        length += 1; // cur 作为中心
                        break;
                    }
                    cur = cur * cur;
                } else {
                    length += 1; // 仅 1 次，作为中心
                    break;
                }
            }
            ans = Math.max(ans, length);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log log M)，M 为最大值
- **空间复杂度**：O(n)

## 关键点总结

1. 序列每级需要 ≥ 2 个（两端对称），不足时作为唯一中心
2. 翻方时检查溢出（cur > sqrt(10^9) 时下一步必超出范围）
3. x=1 特殊处理：回文长度必须为奇数
