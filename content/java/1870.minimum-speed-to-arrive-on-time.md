## 题目描述

每段行程距离为dist[i]，速度为整数speed。除最后一段外每段花费向上取整。求准时到达的最小速度，无解返回-1。

## 解题思路

二分查找速度：给定速度验证是否可行。前n-1段ceil(dist[i]/speed)，最后一段dist[n-1]/speed。

## Java 代码实现

```java
class Solution {
    public int minSpeedOnTime(int[] dist, double hour) {
        int n = dist.length;
        if (n - 1 >= hour) return -1;
        
        int lo = 1, hi = 10_000_000;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (canArrive(dist, mid, hour)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
    
    private boolean canArrive(int[] dist, int speed, double hour) {
        double total = 0;
        int n = dist.length;
        for (int i = 0; i < n - 1; i++) {
            // 向上取整：(dist[i] + speed - 1) / speed
            total += (dist[i] + speed - 1) / speed;
        }
        total += (double) dist[n - 1] / speed;
        return total <= hour;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × log(10^7))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分速度**：时间关于速度单调递减
2. **整数向上取整**：(a + b - 1) / b 避免浮点
3. **无解条件**：n-1 >= hour（等待时间已超时限）
