## 题目描述

根据给定正整数 n（2 的幂），输出 NBA 季后赛对阵结果。最强对最弱配对。

**示例：**
```
输入：n = 8
输出："(((1,8),(4,5)),((2,7),(3,6)))"
```

## 解题思路

模拟每轮比赛：列表中首尾配对，生成新列表，直到剩一个元素。

## Java 代码实现

```java
class Solution {
    public String findContestMatch(int n) {
        String[] teams = new String[n];
        for (int i = 0; i < n; i++) {
            teams[i] = String.valueOf(i + 1);
        }

        int size = n;
        while (size > 1) {
            for (int i = 0; i < size / 2; i++) {
                teams[i] = "(" + teams[i] + "," + teams[size - 1 - i] + ")";
            }
            size /= 2;
        }
        return teams[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **配对规则**：第 i 强对第 size-1-i 强
2. **原地修改**：每轮将结果存回数组前半部分
3. **log n 轮**：每轮 size 减半
