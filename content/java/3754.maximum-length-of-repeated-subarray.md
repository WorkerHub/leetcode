## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，找出它们的最长公共子数组（连续子序列）的长度。

## 解题思路

动态规划：`dp[i][j]` 表示以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的公共子数组长度。使用滚动数组将空间从 O(mn) 优化为 O(n)，需从右往左更新防止覆盖。

## Java 代码实现

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[] dp = new int[n + 1];
        int ans = 0;

        for (int i = 1; i <= m; i++) {
            // 从右往左更新，防止覆盖上一行的数据
            for (int j = n; j >= 1; j--) {
                if (nums1[i-1] == nums2[j-1]) {
                    dp[j] = dp[j-1] + 1;
                    ans = Math.max(ans, dp[j]);
                } else {
                    dp[j] = 0;
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(n)

## 关键点总结

1. DP 状态只依赖上一行，可用滚动数组优化空间
2. 从右往左更新 DP 数组，防止 `dp[j-1]` 被提前覆盖
3. 答案为所有 `dp[j]` 的最大值
