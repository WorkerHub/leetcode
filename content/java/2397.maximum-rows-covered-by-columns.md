## 题目描述

给你 m×n 二进制矩阵 `matrix` 和整数 `numSelect`，从中选 `numSelect` 列，若某行所有值为 1 的列都被选中则该行被覆盖，返回最多能覆盖的行数。

## 解题思路

位运算枚举：将每行压缩为二进制数（第 j 列对应第 j 位），枚举所有 n 位中恰好有 `numSelect` 个 1 的列掩码，对每种方案统计满足 `(rowMask & colMask) == rowMask` 的行数，取最大值。

## Java 代码实现

```java
class Solution {
    public int maximumRows(int[][] matrix, int numSelect) {
        int m = matrix.length, n = matrix[0].length;
        // 将每行压缩为二进制数
        int[] rowMasks = new int[m];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                rowMasks[i] |= (matrix[i][j] << j);

        int ans = 0;
        // 枚举所有 n 位中选 numSelect 位的方案
        for (int colMask = 0; colMask < (1 << n); colMask++) {
            if (Integer.bitCount(colMask) != numSelect) continue;
            int count = 0;
            for (int rm : rowMasks)
                if ((rm & colMask) == rm) count++; // 行中所有 1 都被覆盖
            ans = Math.max(ans, count);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n * m)，n <= 12 故最多 4096*m
- **空间复杂度**：O(m)

## 关键点总结

1. 行覆盖条件：`(rowMask & colMask) == rowMask`（行中所有 1 都在选择列中）。
2. n <= 12，枚举所有 2^n 种列掩码后按 bitCount 过滤，C(12,6)=924 种有效方案。
3. 第 j 列对应第 j 位，位方向需保持一致。
