## 题目描述

给定偶数长度的回文数字字符串，找用相同数字组成的最小且严格大于它的回文串。不存在返回空串。

## 解题思路

回文由前半部分决定，对前半部分执行 Next Permutation，再镜像构成完整回文。若前半部分已是最大排列则无解。

## Java 代码实现

```java
class Solution {
    public String nextPalindrome(String num) {
        int n = num.length();
        char[] half = num.substring(0, n / 2).toCharArray();
        
        // Next Permutation：从右向左找第一个下降位置
        int i = half.length - 2;
        while (i >= 0 && half[i] >= half[i + 1]) i--;
        
        if (i < 0) return ""; // 已是最大排列
        
        // 从右向左找第一个比 half[i] 大的位置
        int j = half.length - 1;
        while (half[j] <= half[i]) j--;
        
        // 交换
        char tmp = half[i];
        half[i] = half[j];
        half[j] = tmp;
        
        // 反转 i+1 之后的部分
        int left = i + 1, right = half.length - 1;
        while (left < right) {
            tmp = half[left];
            half[left] = half[right];
            half[right] = tmp;
            left++;
            right--;
        }
        
        // 构建回文串：前半 + 反转的前半
        String front = new String(half);
        String back = new StringBuilder(front).reverse().toString();
        return front + back;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **回文由前半决定**：只需对前半部分操作
2. **Next Permutation标准算法**：找下降点→找交换点→交换→反转后缀
3. **镜像拼接**：front + reverse(front)
