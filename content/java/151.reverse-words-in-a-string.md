## 题目描述

给你一个字符串 `s`，请你反转字符串中单词的顺序。

**单词**是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的单词分隔开。

返回单词顺序颠倒且单词之间用单个空格隔开的结果字符串。

**注意：** 输入字符串 `s` 中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**示例 1：**

```
输入: s = "the sky is blue"
输出: "blue is sky the"
```

**示例 2：**

```
输入: s = "  hello world  "
输出: "world hello"
解释: 反转后的字符串中不能存在前导空格和尾随空格。
```

**示例 3：**

```
输入: s = "a good   example"
输出: "example good a"
解释: 如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。
```

**提示：**

- `1 <= s.length <= 10^4`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中至少存在一个单词

**进阶：** 如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 O(1) 额外空间复杂度的原地解法。

## 解题思路

这道题的核心有两个任务：
1. 反转单词顺序
2. 处理多余的空格

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 实现难度 |
|------|-----------|-----------|---------|
| split + reverse | O(n) | O(n) | 简单 |
| 双指针 | O(n) | O(n) | 中等 |
| 原地反转 | O(n) | O(1) | 困难 |

**思路一：使用库函数（最简单）**

1. 使用 `trim()` 去除首尾空格，再用正则 `\\s+` 分割单词
2. 反转单词列表
3. 用 `String.join()` 连接

**思路二：双指针**

1. 从后往前遍历字符串
2. 用双指针找到每个单词
3. 依次添加到结果中

**思路三：原地反转（符合进阶要求）**

1. 反转整个字符数组
2. 反转每个单词
3. 清理多余空格

## Java 代码实现

### 方法一：使用 split 和 StringBuilder（推荐）

```java
class Solution {
    public String reverseWords(String s) {
        // trim() 去除首尾空格，split("\\s+") 按连续空格分割
        String[] words = s.trim().split("\\s+");
        StringBuilder sb = new StringBuilder();
        // 从后往前拼接单词
        for (int i = words.length - 1; i >= 0; i--) {
            sb.append(words[i]);
            if (i > 0) sb.append(' ');
        }
        return sb.toString();
    }
}
```

### 方法二：使用 String.join（一行代码）

```java
class Solution {
    public String reverseWords(String s) {
        // 分割、反转、连接
        String[] words = s.trim().split("\\s+");
        int left = 0, right = words.length - 1;
        // 双指针反转数组
        while (left < right) {
            String tmp = words[left];
            words[left] = words[right];
            words[right] = tmp;
            left++;
            right--;
        }
        return String.join(" ", words);
    }
}
```

### 方法三：双指针（自己实现分割）

```java
class Solution {
    public String reverseWords(String s) {
        s = s.trim(); // 去除首尾空格
        StringBuilder result = new StringBuilder();
        int right = s.length() - 1;

        while (right >= 0) {
            // 跳过空格
            while (right >= 0 && s.charAt(right) == ' ') {
                right--;
            }

            if (right < 0) break;

            // 找到单词的左边界
            int left = right;
            while (left >= 0 && s.charAt(left) != ' ') {
                left--;
            }

            // 提取单词
            if (result.length() > 0) result.append(' ');
            result.append(s, left + 1, right + 1);
            right = left;
        }

        return result.toString();
    }
}
```

### 方法四：原地反转（模拟 StringBuilder）

```java
class Solution {
    public String reverseWords(String s) {
        // 转换为字符数组
        char[] chars = s.toCharArray();

        // 1. 整体反转
        reverse(chars, 0, chars.length - 1);

        // 2. 单词反转，并去除多余空格
        int start = 0; // 当前单词的起始位置
        int writeIdx = 0; // 写入位置

        for (int i = 0; i <= chars.length; i++) {
            if (i == chars.length || chars[i] == ' ') {
                if (start < i) {
                    // 将单词写到 writeIdx 处（去除前置空格）
                    if (writeIdx > 0) chars[writeIdx++] = ' ';
                    int wordLen = i - start;
                    System.arraycopy(chars, start, chars, writeIdx, wordLen);
                    // 反转该单词
                    reverse(chars, writeIdx, writeIdx + wordLen - 1);
                    writeIdx += wordLen;
                }
                start = i + 1;
            }
        }

        return new String(chars, 0, writeIdx);
    }

    private void reverse(char[] chars, int left, int right) {
        // 反转 chars[left..right]
        while (left < right) {
            char tmp = chars[left];
            chars[left] = chars[right];
            chars[right] = tmp;
            left++;
            right--;
        }
    }
}
```

### 方法五：使用栈

```java
class Solution {
    public String reverseWords(String s) {
        Deque<String> stack = new ArrayDeque<>();
        StringBuilder word = new StringBuilder();

        for (char c : s.toCharArray()) {
            if (c != ' ') {
                word.append(c);
            } else if (word.length() > 0) {
                // 遇到空格且 word 不为空，说明一个单词结束
                stack.push(word.toString());
                word.setLength(0);
            }
        }

        // 处理最后一个单词
        if (word.length() > 0) {
            stack.push(word.toString());
        }

        // 栈是 LIFO，弹出时自然是反序
        StringBuilder result = new StringBuilder();
        while (!stack.isEmpty()) {
            if (result.length() > 0) result.append(' ');
            result.append(stack.pop());
        }

        return result.toString();
    }
}
```

## 复杂度分析

**方法一、二：split + join**

- 时间复杂度：O(n)
  - split: O(n)
  - reverse: O(m)，m 为单词数
  - join: O(n)
- 空间复杂度：O(n)
  - 存储分割后的单词数组

**方法三：双指针**

- 时间复杂度：O(n)
  - 遍历字符串一次
- 空间复杂度：O(n)
  - 存储 StringBuilder

**方法四：原地反转**

- 时间复杂度：O(n)
  - 反转整个字符串：O(n)
  - 反转每个单词：O(n)
  - 清理空格：O(n)
- 空间复杂度：O(n)
  - 转为字符数组操作

## 图解示例

以 `s = "  hello world  "` 为例：

**方法一（split + reverse）：**

```
原始: "  hello world  "

trim(): "hello world"

split("\\s+"): ["hello", "world"]

reverse(): ["world", "hello"]

join(): "world hello"
```

**方法四（原地反转）：**

```
1. 整体反转: "dlrow olleh"

2. 反转每个单词:
   "dlrow" -> "world"
   "olleh" -> "hello"
   结果: "world hello"
```

更复杂的例子：`s = "a good   example"`

```
1. split("\\s+"): ["a", "good", "example"]

2. reverse(): ["example", "good", "a"]

3. join(): "example good a"

多个空格被自动处理为一个
```

## 关键点总结

1. **Java 的 split 方法**：
   - `split("\\s+")` 按连续空格分割
   - 配合 `trim()` 去除首尾空格
   - 是最简单的解决方案

2. **双指针技巧**：
   - 从后往前遍历，避免反转列表
   - 一个指针找单词边界，一个指针提取单词

3. **原地反转的思想**：
   - 两次反转等价于单词顺序反转
   - `"abc def"` -> `"fed cba"` -> `"def abc"`

4. **空格处理**：
   - 前导空格、尾随空格
   - 单词间多个空格
   - 结果中只保留单个空格

5. **Java 字符串不可变**：
   - 使用 `char[]` 或 `StringBuilder` 进行原地操作
   - Java 的 `String` 不可直接修改

## 易错点

1. **split 的参数**：
   - `split(" ")` 和 `split("\\s+")` 不同
   - 前者按单个空格分割，后者按连续空格分割
   - 配合 `trim()` 才能正确处理首尾空格

2. **空字符串的处理**：
   - `"   ".trim().split("\\s+")` 返回 `[""]`，需要判断

3. **最后一个单词**：
   - 遍历时不要遗漏最后一个单词

4. **结果末尾的空格**：
   - join 后不会有尾随空格
   - 手动拼接时注意最后一个单词后不加空格

5. **边界情况**：
   - 只有一个单词
   - 全是空格
   - 没有空格
