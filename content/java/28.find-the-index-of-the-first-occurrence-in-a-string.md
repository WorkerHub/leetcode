## 题目描述

给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。

**示例 1：**
```
输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。第一个匹配项的下标是 0
```

**示例 2：**
```
输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现
```

**提示：**
- `1 <= haystack.length, needle.length <= 10^4`
- `haystack` 和 `needle` 仅由小写英文字符组成

## 解题思路

这是经典的字符串匹配问题。

**方法对比：**
1. **内置函数**：直接使用 `String.indexOf()`
2. **暴力法**：逐个位置尝试匹配
3. **KMP算法**：高效的字符串匹配算法

## Java 代码实现

### 方法一：内置函数（最简单）

```java
class Solution {
    public int strStr(String haystack, String needle) {
        // Java 内置的 indexOf 方法
        return haystack.indexOf(needle);
    }
}
```

### 方法二：暴力法

```java
class Solution {
    public int strStr(String haystack, String needle) {
        int n = haystack.length(), m = needle.length();

        // 遍历每个可能的起始位置
        for (int i = 0; i <= n - m; i++) {
            // 检查从 i 开始是否匹配（使用 equals 比较字符串）
            if (haystack.substring(i, i + m).equals(needle)) {
                return i;
            }
        }

        return -1;
    }
}
```

### 方法三：KMP 算法

```java
class Solution {
    public int strStr(String haystack, String needle) {
        int n = haystack.length(), m = needle.length();
        if (m == 0) return 0;

        // 构建 next 数组（部分匹配表）
        int[] next = new int[m];
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];
            }
            if (needle.charAt(i) == needle.charAt(j)) {
                j++;
            }
            next[i] = j;
        }

        // KMP 匹配
        j = 0;
        for (int i = 0; i < n; i++) {
            while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];
            }
            if (haystack.charAt(i) == needle.charAt(j)) {
                j++;
            }
            if (j == m) {
                return i - m + 1;
            }
        }

        return -1;
    }
}
```

## 复杂度分析

**方法一和方法二：**
- 时间复杂度：O(n×m)
- 空间复杂度：O(1)

**方法三（KMP）：**
- 时间复杂度：O(n + m)
- 空间复杂度：O(m)

## 关键点总结

1. **内置函数**：实际工作中推荐使用
2. **暴力法**：简单直观，适合小数据
3. **KMP**：面试常考，需要理解 next 数组的构建
4. **Java 字符串比较**：必须使用 `equals()` 而非 `==`

## 易错点

1. **边界情况**：needle 为空字符串时返回 0
2. **索引越界**：暴力法要注意范围是 `i <= n - m`
3. **字符串比较**：Java 中不能用 `==` 比较字符串内容，要用 `equals()`
