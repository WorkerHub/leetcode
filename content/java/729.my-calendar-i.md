## 题目描述

实现一个 `MyCalendar` 类来存放日程安排。如果要添加的日程安排不会造成重复预订，则可以存储。时间是半开区间 `[start, end)`。

**示例：**
```
输入：["MyCalendar", "book", "book", "book"]
[[], [10, 20], [15, 25], [20, 30]]
输出：[null, true, false, true]
```

## 解题思路

使用 TreeMap 存储已预订的区间，利用 floorKey 和 ceilingKey 快速检查新区间是否与相邻区间重叠。

## Java 代码实现

```java
class MyCalendar {
    private TreeMap<Integer, Integer> calendar;

    public MyCalendar() {
        calendar = new TreeMap<>();
    }

    public boolean book(int start, int end) {
        // 检查前一个区间是否重叠
        Integer prev = calendar.floorKey(start);
        if (prev != null && calendar.get(prev) > start) {
            return false;
        }
        // 检查后一个区间是否重叠
        Integer next = calendar.ceilingKey(start);
        if (next != null && next < end) {
            return false;
        }
        calendar.put(start, end);
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，每次 book 操作
- **空间复杂度**：O(n)

## 关键点总结

1. **TreeMap**：利用有序映射快速查找相邻区间
2. **重叠判断**：检查前后两个区间即可
3. **半开区间**：`[start, end)` 边界不重叠
