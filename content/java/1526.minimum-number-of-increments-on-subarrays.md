## 题目描述

全 0 数组，每次操作选一个子数组加 1，求变成 target 的最少操作次数。

**示例：**
```
输入：target = [1,2,3,2,1]
输出：3
```

## 解题思路

贪心：答案 = target[0] + 所有上升台阶的高度之和。每次上升意味着需要新增操作。

## Java 代码实现

```java
class Solution {
    public int minNumberOperations(int[] target) {
        int ops = target[0];
        for (int i = 1; i < target.length; i++) {
            if (target[i] > target[i-1]) {
                ops += target[i] - target[i-1];
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **上升台阶**：每次上升需要新增操作
2. **直觉**：看作山脉，数水平线段数
3. **差分理解**：正差分之和
