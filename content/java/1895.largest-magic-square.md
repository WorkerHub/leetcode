## 题目描述

给你一个 `m x n` 的整数矩阵 `grid`，返回其中最大幻方（每行、每列及两条对角线元素和相同）的尺寸 k。

## 解题思路

预计算行列前缀和，从大到小枚举 k，对每个左上角 (r, c) 验证是否构成幻方（所有行列和相等且等于对角线和）。

## Java 代码实现

```java
class Solution {
    public int largestMagicSquare(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 行前缀和
        int[][] rowPre = new int[m][n + 1];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                rowPre[i][j + 1] = rowPre[i][j] + grid[i][j];

        // 列前缀和
        int[][] colPre = new int[m + 1][n];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                colPre[i + 1][j] = colPre[i][j] + grid[i][j];

        // 从大到小枚举 k
        for (int k = Math.min(m, n); k >= 1; k--) {
            for (int r = 0; r <= m - k; r++) {
                for (int c = 0; c <= n - k; c++) {
                    if (isMagic(grid, rowPre, colPre, r, c, k)) return k;
                }
            }
        }
        return 1;
    }

    private boolean isMagic(int[][] grid, int[][] rowPre, int[][] colPre, int r, int c, int k) {
        // 目标和：第一行
        int target = rowPre[r][c + k] - rowPre[r][c];

        // 验证所有行
        for (int i = r; i < r + k; i++)
            if (rowPre[i][c + k] - rowPre[i][c] != target) return false;

        // 验证所有列
        for (int j = c; j < c + k; j++)
            if (colPre[r + k][j] - colPre[r][j] != target) return false;

        // 验证主对角线
        int diag1 = 0;
        for (int t = 0; t < k; t++) diag1 += grid[r + t][c + t];
        if (diag1 != target) return false;

        // 验证副对角线
        int diag2 = 0;
        for (int t = 0; t < k; t++) diag2 += grid[r + t][c + k - 1 - t];
        return diag2 == target;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(m,n) * m * n * k)
- **空间复杂度**：O(m * n)，前缀和数组

## 关键点总结

1. 行列前缀和 O(1) 计算区间和，避免重复计算
2. 幻方需验证：所有行列相等 + 两条对角线相等
3. 从大到小枚举 k，找到第一个即返回
