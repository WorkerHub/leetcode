## 题目描述

给你山峰坐标数组 `peaks`，每座山的底部区间为 `[x-y, x+y]`，若一座山的区间完全被另一座覆盖则不可见，返回可见山的数目。

## 解题思路

将山转化为区间 `[x-y, x+y]`，按左端点升序（相同则右端点降序）排序后扫描，维护最大右端点 `maxRight`：当前区间右端点 > maxRight 时可见（但完全相同的区间互相覆盖，都不可见）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int visibleMountains(int[][] peaks) {
        int n = peaks.length;
        int[][] segs = new int[n][2];
        for (int i = 0; i < n; i++) {
            segs[i][0] = peaks[i][0] - peaks[i][1]; // 左端点
            segs[i][1] = peaks[i][0] + peaks[i][1]; // 右端点
        }
        // 按左端点升序，左端点相同则右端点降序
        Arrays.sort(segs, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);

        int ans = 0, maxRight = Integer.MIN_VALUE;
        for (int i = 0; i < n; ) {
            int l = segs[i][0], r = segs[i][1];
            // 统计重复区间数量
            int j = i;
            while (j < n && segs[j][0] == l && segs[j][1] == r) j++;
            int count = j - i;

            if (r > maxRight) {
                maxRight = r;
                if (count == 1) ans++; // 唯一且未被覆盖，可见
            }
            i = j;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 区间覆盖问题：右端点 <= 当前最大右端点则被覆盖不可见。
2. 完全相同的区间互相覆盖，出现超过 1 次时都不可见。
3. 排序后单次扫描，O(n) 时间完成判断。
