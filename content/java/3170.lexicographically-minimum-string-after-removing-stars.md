## 题目描述

给你含小写字母和 `*` 的字符串 `s`，每遇到 `*` 需删除它及其左边字典序最小（相同时取最靠右）的字符，返回删除所有 `*` 后的字符串。

## 解题思路

维护 26 个字母各自的下标栈。遇到 `*` 时，找最小字母的栈顶下标标记删除；遇到字母则入栈。最后顺序输出未删除的字符。

## Java 代码实现

```java
class Solution {
    public String clearStars(String s) {
        int n = s.length();
        // 每个字母的下标栈
        Deque<Integer>[] buckets = new ArrayDeque[26];
        for (int i = 0; i < 26; i++) buckets[i] = new ArrayDeque<>();
        boolean[] deleted = new boolean[n];

        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            if (c == '*') {
                deleted[i] = true;
                // 找字典序最小且最靠右的字符删除
                for (int k = 0; k < 26; k++) {
                    if (!buckets[k].isEmpty()) {
                        deleted[buckets[k].pop()] = true; // 栈顶即最靠右
                        break;
                    }
                }
            } else {
                buckets[c - 'a'].push(i); // 压栈（栈顶为最靠右）
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (!deleted[i]) sb.append(s.charAt(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 26) = O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 用 26 个栈维护每个字母的下标，栈顶即最靠右的下标
2. 遇到 `*` 时找第一个非空栈弹出，实现「最小字母中最靠右」的贪心
3. `*` 本身也标记为删除
