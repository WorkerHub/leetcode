## 题目描述

将 `n` 颗**不同**的糖分配到 `k` 个**有标签**的袋子中，每个袋子至少一颗。返回方案数对 `10^9 + 7` 取余。

## 解题思路

**DP（第二类 Stirling 数）：** `dp[i][j]` = 将前 `i` 颗糖放入 `j` 个非空袋的方案数。第 `i` 颗糖要么自成一袋（`dp[i-1][j-1]`），要么放入已有 j 袋之一（`j * dp[i-1][j]`）。

## Java 代码实现

```java
class Solution {
    public int waysToDistribute(int n, int k) {
        final int MOD = 1_000_000_007;
        // 滚动数组优化空间
        long[] prev = new long[k + 1];
        prev[0] = 1; // dp[0][0] = 1

        for (int i = 1; i <= n; i++) {
            long[] curr = new long[k + 1];
            for (int j = 1; j <= Math.min(i, k); j++) {
                // 第 i 颗糖单独成一袋
                curr[j] = prev[j - 1];
                // 第 i 颗糖放入已有的 j 袋之一
                curr[j] = (curr[j] + (long) j * prev[j]) % MOD;
            }
            prev = curr;
        }
        return (int) prev[k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)
- **空间复杂度**：O(k)

## 关键点总结

1. 转移：`dp[i][j] = dp[i-1][j-1] + j * dp[i-1][j]`
2. 糖是不同的，放入已有袋子时系数为 `j`
3. 滚动数组将空间从 O(n*k) 优化为 O(k)
