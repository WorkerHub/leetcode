## 题目描述

给你二维点数组 `coordinates` 和整数 `k`，返回包含 `coordinates[k]` 的最长严格递增路径的长度（路径上 x 和 y 坐标均严格递增）。

## 解题思路

二维 LIS：按 x 升序排序（x 相同时 y 降序），再对 y 坐标用耐心排序求最长严格递增子序列（LIS）。x 相同时 y 降序可防止同 x 的两点被选入同一路径。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxPathLength(int[][] coordinates, int k) {
        // 按 x 升序，x 相同时 y 降序，避免同 x 的两点都被选
        Arrays.sort(coordinates, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);
        // 对 y 坐标求严格递增 LIS（耐心排序，二分查找）
        List<Integer> tails = new ArrayList<>();
        for (int[] p : coordinates) {
            int y = p[1];
            int pos = Collections.binarySearch(tails, y);
            if (pos < 0) pos = -pos - 1; // 第一个 >= y 的位置
            if (pos == tails.size()) tails.add(y);
            else tails.set(pos, y);
        }
        return tails.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + LIS
- 空间复杂度：O(n)

## 关键点总结

1. 二维 LIS：先按 x 升序排序，再对 y 求 LIS
2. x 相同时 y 降序，避免同 x 的两点互相构成路径
3. `Collections.binarySearch` 找插入位置，负返回值转换为 `-(pos+1)`
