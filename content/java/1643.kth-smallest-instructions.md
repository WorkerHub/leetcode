## 题目描述

Bob 从 `(0,0)` 出发到 `(row, column)`，只能向右（H）或向下（V）移动。给定 `destination = [row, column]` 和整数 `k`，找出字典序第 k 小的路径。

## 解题思路

路径由 `column` 个 H 和 `row` 个 V 组成。逐位贪心：H < V，每位先计算放 H 后的方案数 `C(h-1+v, v)`，若 `k <= 方案数` 则放 H，否则放 V 并 `k -= 方案数`。

## Java 代码实现

```java
class Solution {
    public String kthSmallestPath(int[] destination, int k) {
        int v = destination[0]; // 需要的 V 数量
        int h = destination[1]; // 需要的 H 数量
        StringBuilder sb = new StringBuilder();

        for (int step = 0; step < h + v; step++) {
            if (h == 0) {
                // H 用完，只能放 V
                sb.append('V');
                v--;
            } else if (v == 0) {
                // V 用完，只能放 H
                sb.append('H');
                h--;
            } else {
                // 计算放 H 后的方案数：C(h-1+v, v)
                long cnt = comb(h - 1 + v, v);
                if (k <= cnt) {
                    sb.append('H');
                    h--;
                } else {
                    sb.append('V');
                    v--;
                    k -= (int) cnt;
                }
            }
        }
        return sb.toString();
    }

    // 计算组合数 C(n, r)，使用帕斯卡三角形或直接计算
    private long comb(int n, int r) {
        if (r > n - r) r = n - r; // 取较小值优化
        long res = 1;
        for (int i = 0; i < r; i++) {
            res = res * (n - i) / (i + 1);
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((h+v) * min(h,v))
- **空间复杂度**：O(h+v)

## 关键点总结

1. `H < V`，每位优先尝试 H
2. 放 H 的方案数 = `C(h-1+v, v)`
3. `k <= cnt` 放 H；否则放 V，`k -= cnt`
4. H 或 V 为 0 时直接填另一种字符
