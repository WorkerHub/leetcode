## 题目描述

给你一棵二叉树的根节点 root，请你返回这棵树中最长连续序列的长度。

连续序列是指从父节点到子节点的路径，序列中的值依次递增 1。例如，1-2-3-4 是一个连续序列，但 1-2-4 不是。

注意：这个序列可以是递增的，且必须是父节点到子节点的方向。

**示例 1：**
```
输入：root = [1,null,3,2,4,null,null,null,5]
输出：3
解释：树中最长连续序列是 3-4-5，所以返回 3。
     1
      \
       3
      / \
     2   4
          \
           5
```

**示例 2：**
```
输入：root = [2,null,3,2,null,1]
输出：2
解释：树中最长连续序列是 2-3，所以返回 2。
     2
      \
       3
      /
     2
    /
   1
注意：虽然有 2-3-2 路径，但它不是连续递增的。
```

**提示：**
- 树中节点数在范围 [1, 3 * 10^4] 内
- -3 * 10^4 <= Node.val <= 3 * 10^4

## 解题思路

这道题要求找最长的连续递增序列，关键点：
1. 序列必须是从父节点到子节点
2. 每个节点的值要比父节点大 1
3. 路径可以在任意节点开始和结束

**方法对比：**

| 方法 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| DFS（自顶向下） | 传递当前长度 | 简单直观 | 需要全局变量 |
| DFS（自底向上） | 返回当前长度 | 逻辑清晰 | 稍复杂 |

**核心思路（自顶向下）：**
1. 从根节点开始遍历
2. 如果子节点值 = 父节点值 + 1，长度加 1
3. 否则，重新开始计数（长度为 1）
4. 记录遍历过程中的最大长度

## Java 代码实现

### 方法一：DFS 自顶向下（推荐）

```java
class Solution {
    private int maxLength = 0;

    public int longestConsecutive(TreeNode root) {
        dfs(root, null, 0);
        return maxLength;
    }

    private void dfs(TreeNode node, TreeNode parent, int currentLength) {
        if (node == null) return;

        // 如果当前节点值 = 父节点值 + 1，长度加 1；否则重新开始
        if (parent != null && node.val == parent.val + 1) {
            currentLength++;
        } else {
            currentLength = 1;
        }

        // 更新最大长度
        maxLength = Math.max(maxLength, currentLength);

        // 递归处理左右子树
        dfs(node.left, node, currentLength);
        dfs(node.right, node, currentLength);
    }
}
```

### 方法二：DFS 传递父节点值

```java
class Solution {
    private int maxLength = 0;

    public int longestConsecutive(TreeNode root) {
        dfs(root, Integer.MIN_VALUE, 0);
        return maxLength;
    }

    // 用整数传递父节点的值，避免传递节点引用
    private void dfs(TreeNode node, int parentVal, int currentLength) {
        if (node == null) return;

        // 判断是否连续
        if (node.val == parentVal + 1) {
            currentLength++;
        } else {
            currentLength = 1;
        }

        // 更新最大长度
        maxLength = Math.max(maxLength, currentLength);

        dfs(node.left, node.val, currentLength);
        dfs(node.right, node.val, currentLength);
    }
}
```

### 方法三：DFS 不使用全局变量

```java
class Solution {
    public int longestConsecutive(TreeNode root) {
        if (root == null) return 0;
        return dfs(root, Integer.MIN_VALUE, 0);
    }

    // 返回包含当前子树的最长连续序列长度
    private int dfs(TreeNode node, int parentVal, int currentLength) {
        if (node == null) return currentLength;

        // 计算当前长度
        if (node.val == parentVal + 1) {
            currentLength++;
        } else {
            currentLength = 1;
        }

        // 递归处理左右子树，取最大值
        int leftMax = dfs(node.left, node.val, currentLength);
        int rightMax = dfs(node.right, node.val, currentLength);

        return Math.max(currentLength, Math.max(leftMax, rightMax));
    }
}
```

### 方法四：迭代法（使用栈）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestConsecutive(TreeNode root) {
        if (root == null) return 0;

        int maxLength = 0;
        // 栈中存储：[节点, 父节点值, 当前长度]
        Deque<int[]> nodeStack = new ArrayDeque<>();
        Deque<TreeNode> treeStack = new ArrayDeque<>();
        // 使用两个栈分别存节点和 [父节点值, 当前长度]
        Deque<int[]> infoStack = new ArrayDeque<>();

        treeStack.push(root);
        infoStack.push(new int[]{Integer.MIN_VALUE, 0});

        while (!treeStack.isEmpty()) {
            TreeNode node = treeStack.pop();
            int[] info = infoStack.pop();
            int parentVal = info[0];
            int currentLength = info[1];

            // 计算当前长度
            if (node.val == parentVal + 1) {
                currentLength++;
            } else {
                currentLength = 1;
            }

            maxLength = Math.max(maxLength, currentLength);

            // 将子节点加入栈
            if (node.left != null) {
                treeStack.push(node.left);
                infoStack.push(new int[]{node.val, currentLength});
            }
            if (node.right != null) {
                treeStack.push(node.right);
                infoStack.push(new int[]{node.val, currentLength});
            }
        }

        return maxLength;
    }
}
```

### 方法五：BFS（层序遍历）

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int longestConsecutive(TreeNode root) {
        if (root == null) return 0;

        int maxLength = 0;
        // 队列存储节点
        Queue<TreeNode> nodeQueue = new ArrayDeque<>();
        // 队列存储 [父节点值, 当前长度]
        Queue<int[]> infoQueue = new ArrayDeque<>();

        nodeQueue.offer(root);
        infoQueue.offer(new int[]{Integer.MIN_VALUE, 0});

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            int[] info = infoQueue.poll();
            int parentVal = info[0];
            int currentLength = info[1];

            // 计算当前长度
            if (node.val == parentVal + 1) {
                currentLength++;
            } else {
                currentLength = 1;
            }

            maxLength = Math.max(maxLength, currentLength);

            if (node.left != null) {
                nodeQueue.offer(node.left);
                infoQueue.offer(new int[]{node.val, currentLength});
            }
            if (node.right != null) {
                nodeQueue.offer(node.right);
                infoQueue.offer(new int[]{node.val, currentLength});
            }
        }

        return maxLength;
    }
}
```

## 复杂度分析

### 所有方法：

**时间复杂度：** O(n)
- 每个节点访问一次

**空间复杂度：**
- DFS 递归：O(h)，h 是树的高度
  - 平衡树：O(log n)
  - 最坏情况（链式）：O(n)
- 迭代/BFS：O(w)，w 是树的最大宽度
  - 完全二叉树：O(n/2) = O(n)

## 图解示例

示例 1：`root = [1,null,3,2,4,null,null,null,5]`

```
树结构：
     1
      \
       3
      / \
     2   4
          \
           5

DFS 遍历过程：
1. 从 1 开始，长度 = 1
2. 访问 3：3 ≠ 1+1，重新开始，长度 = 1
3. 访问 2：2 ≠ 3+1，重新开始，长度 = 1
4. 回到 3，访问 4：4 = 3+1，长度 = 2
5. 访问 5：5 = 4+1，长度 = 3

最长连续序列：3 → 4 → 5，长度 = 3
```

示例 2：`root = [2,null,3,2,null,1]`

```
树结构：
     2
      \
       3
      /
     2
    /
   1

DFS 遍历过程：
1. 从 2 开始，长度 = 1
2. 访问 3：3 = 2+1，长度 = 2
3. 访问 2：2 ≠ 3+1，重新开始，长度 = 1
4. 访问 1：1 ≠ 2+1，重新开始，长度 = 1

最长连续序列：2 → 3，长度 = 2
注意：虽然路径是 2-3-2，但 2 ≠ 3+1，所以不连续
```

## 关键点总结

1. **连续定义**：子节点值必须等于父节点值 + 1
2. **方向限制**：只能从父到子，不能从子到父
3. **起点任意**：连续序列可以从任意节点开始
4. **重新计数**：不连续时长度重置为 1
5. **全局最大值**：需要记录整个遍历过程中的最大长度

## 易错点

1. **忘记重置长度**
   ```java
   // 错误：不连续时没有重置
   if (node.val == parentVal + 1) {
       currentLength++;
   }
   // 忘记 else 分支
   
   // 正确：不连续时重置为 1
   } else {
       currentLength = 1;
   }
   ```

2. **初始父节点值设置错误**
   ```java
   // 错误：初始父节点值为 0，如果根节点值为 1 会误算
   dfs(root, 0, 0);
   
   // 正确：使用 Integer.MIN_VALUE 作为初始父节点值
   dfs(root, Integer.MIN_VALUE, 0);
   ```

3. **比较条件错误**
   ```java
   // 错误：判断相等
   if (node.val == parentVal) {
       currentLength++;
   }
   
   // 正确：判断等于父节点 + 1
   if (node.val == parentVal + 1) {
       currentLength++;
   }
   ```

4. **忘记每个节点都要更新最大值**
   ```java
   // 错误：只在叶子节点更新
   if (node.left == null && node.right == null) {
       maxLength = Math.max(maxLength, currentLength);
   }
   
   // 正确：每个节点都要更新
   maxLength = Math.max(maxLength, currentLength);
   ```
