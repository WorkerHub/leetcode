## 题目描述

在 10^6 × 10^6 的网格中，给定封锁方格列表 blocked（最多200个），判断从 source 能否到达 target。

**示例：**
```
输入：blocked = [[0,1],[1,0]], source = [0,0], target = [0,2]
输出：false
```

## 解题思路

200 个障碍物最多围成面积约 n*(n-1)/2 ≈ 19900。从 source 和 target 分别 BFS，若访问节点数超过此阈值则说明未被包围。双向均未被包围则可达。

## Java 代码实现

```java
class Solution {
    private static final int LIMIT = 1000000;

    public boolean isEscapePossible(int[][] blocked, int[] source, int[] target) {
        if (blocked.length == 0) return true;

        Set<Long> blockedSet = new HashSet<>();
        for (int[] b : blocked) {
            blockedSet.add((long) b[0] * LIMIT + b[1]);
        }

        // 最大包围面积
        int maxArea = blocked.length * (blocked.length - 1) / 2;

        return bfs(source, target, blockedSet, maxArea) &&
               bfs(target, source, blockedSet, maxArea);
    }

    private boolean bfs(int[] start, int[] end, Set<Long> blockedSet, int maxArea) {
        Queue<int[]> queue = new LinkedList<>();
        Set<Long> visited = new HashSet<>();

        queue.offer(start);
        visited.add((long) start[0] * LIMIT + start[1]);

        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!queue.isEmpty() && visited.size() <= maxArea) {
            int[] cur = queue.poll();

            // 到达目标
            if (cur[0] == end[0] && cur[1] == end[1]) return true;

            for (int[] d : dirs) {
                int nx = cur[0] + d[0], ny = cur[1] + d[1];
                long key = (long) nx * LIMIT + ny;

                if (nx >= 0 && nx < LIMIT && ny >= 0 && ny < LIMIT &&
                    !visited.contains(key) && !blockedSet.contains(key)) {
                    visited.add(key);
                    queue.offer(new int[]{nx, ny});
                }
            }
        }

        // 超过最大包围面积，说明未被包围
        return visited.size() > maxArea;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，n 为 blocked 长度
- **空间复杂度**：O(n²)

## 关键点总结

1. **包围面积上限**：n 个障碍物最多围成 n*(n-1)/2 面积
2. **双向检查**：source 和 target 都需要验证未被包围
3. **坐标编码**：用 `x * 10^6 + y` 作为 long 类型 key
