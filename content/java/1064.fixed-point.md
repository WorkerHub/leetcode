## 题目描述

给定升序不同整数数组，返回最小的不动点（arr[i] == i）。不存在返回 -1。

**示例：**
```
输入：arr = [-10,-5,0,3,7]
输出：3
```

## 解题思路

二分查找：arr[i]-i 具有单调性。若 arr[mid] >= mid 则不动点可能在左侧（包括 mid），否则在右侧。

## Java 代码实现

```java
class Solution {
    public int fixedPoint(int[] arr) {
        int left = 0, right = arr.length - 1;
        int result = -1;

        while (left <= right) {
            int mid = (left + right) / 2;
            if (arr[mid] == mid) {
                result = mid;
                right = mid - 1; // 继续找更小的
            } else if (arr[mid] > mid) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **单调性**：arr[i]-i 递增，可二分
2. **找最小**：找到不动点后继续向左搜索
3. **剪枝**：arr[mid] > mid 时右侧不可能有更小不动点
