## 题目描述

给定两个字符串 str1 和 str2，返回同时以两者为子序列的最短字符串。

**示例：**
```
输入：str1 = "abac", str2 = "cab"
输出："cabac"
```

## 解题思路

先求 LCS（最长公共子序列）的 DP 表，再从 DP 表回溯构造结果：公共字符只保留一份，非公共字符都保留。

## Java 代码实现

```java
class Solution {
    public String shortestCommonSupersequence(String str1, String str2) {
        int m = str1.length(), n = str2.length();

        // 构建 LCS 的 DP 表
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (str1.charAt(i - 1) == str2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 从 DP 表回溯构造结果
        StringBuilder sb = new StringBuilder();
        int i = m, j = n;

        while (i > 0 && j > 0) {
            if (str1.charAt(i - 1) == str2.charAt(j - 1)) {
                sb.append(str1.charAt(i - 1));
                i--;
                j--;
            } else if (dp[i - 1][j] > dp[i][j - 1]) {
                sb.append(str1.charAt(i - 1));
                i--;
            } else {
                sb.append(str2.charAt(j - 1));
                j--;
            }
        }

        while (i > 0) sb.append(str1.charAt(--i));
        while (j > 0) sb.append(str2.charAt(--j));

        return sb.reverse().toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **基于 LCS**：超序列长度 = len1 + len2 - LCS长度
2. **回溯构造**：从 dp[m][n] 反向推导每个字符的来源
3. **反转结果**：从后往前构造需要最后反转
