## 题目描述

给你整数数组 `nums`，计算从 nums[0] 开始的最长连续递增前缀（每个元素比前一个大 1）的和 s，返回大于 s 且不在 nums 中的最小正整数。

## 解题思路

遍历计算最长连续递增前缀和，再从 s+1 开始找第一个不在 nums 集合中的整数。

## Java 代码实现

```java
class Solution {
    public int missingInteger(int[] nums) {
        // 计算连续递增前缀和（每步差值恰好为 1）
        int prefixSum = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1] + 1) prefixSum += nums[i];
            else break;
        }

        // 构建集合加速查找
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);

        // 从 prefixSum+1 开始找第一个不在集合中的整数
        int ans = prefixSum + 1;
        while (set.contains(ans)) ans++;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 连续递增要求差值恰好为 1，不是 >= 1
2. 从 prefixSum+1 开始查找（大于前缀和）
3. 用集合实现 O(1) 查找
