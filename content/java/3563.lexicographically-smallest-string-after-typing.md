## 题目描述

给定一个字符串 `word` 和整数 `k`。可以选择任意连续子串将其中所有字符向后移动一位（'a'->'b', ..., 'z'->'a'），共操作 `k` 次，使得最终字符串字典序最小。

## 解题思路

贪心：从左到右，对每个字符尝试将其变为 'a'（需 `(26 - c) % 26` 次操作）。若操作次数足够，变为 'a' 并扣除操作数；若不够（加 k 次后字符变大），停止操作。

## Java 代码实现

```java
class Solution {
    public String smallestString(String word, int k) {
        char[] chars = word.toCharArray();
        int remaining = k;

        for (int i = 0; i < chars.length && remaining > 0; i++) {
            int c = chars[i] - 'a';
            // 将 chars[i] 变为 'a' 需要的步数
            int stepsToA = (26 - c) % 26;
            if (stepsToA == 0) continue; // 已经是 'a'
            if (remaining >= stepsToA) {
                chars[i] = 'a';
                remaining -= stepsToA;
            } else {
                // 操作次数不足以绕圈变 'a'，+k 只会使字符变大，停止
                break;
            }
        }

        return new String(chars);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，字符数组

## 关键点总结

1. 字符 +1 操作是循环的（'z' -> 'a'）
2. 贪心：优先将字符变为 'a'，需要 `(26 - c) % 26` 步
3. 若操作次数不足以将当前字符变为 'a'，则不操作（+k 会使字符变大）
