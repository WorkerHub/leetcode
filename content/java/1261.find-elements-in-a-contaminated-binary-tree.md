## 题目描述

给定一棵被污染的二叉树（所有值为 -1），恢复规则：根为 0，左子 = 2*x+1，右子 = 2*x+2。实现 `FindElements` 类支持初始化恢复和查询。

**示例：**
```
输入：["FindElements","find","find"], [[[-1,null,-1]],[1],[2]]
输出：[null,false,true]
```

## 解题思路

DFS 恢复二叉树值，用 HashSet 存储所有恢复后的值，find 直接查表 O(1)。

## Java 代码实现

```java
class FindElements {
    private Set<Integer> values;
    
    public FindElements(TreeNode root) {
        values = new HashSet<>();
        dfs(root, 0);
    }
    
    private void dfs(TreeNode node, int val) {
        if (node == null) return;
        node.val = val;
        values.add(val);
        dfs(node.left, 2 * val + 1);
        dfs(node.right, 2 * val + 2);
    }
    
    public boolean find(int target) {
        return values.contains(target);
    }
}
```

## 复杂度分析

- **时间复杂度**：初始化 O(n)，查询 O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **堆索引规则**：左子 = 2*x+1，右子 = 2*x+2
2. **DFS 恢复**：前序遍历恢复所有节点值
3. **HashSet 查询**：O(1) 时间复杂度查询
