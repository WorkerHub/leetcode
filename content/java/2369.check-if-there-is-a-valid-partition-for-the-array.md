## 题目描述

给你整数数组 `nums`，将其分割成若干连续子数组，每个子数组须满足：恰好 2 个相等元素、恰好 3 个相等元素、或恰好 3 个连续递增元素之一。若能完成分割返回 `true`，否则返回 `false`。

## 解题思路

定义 `dp[i]` 表示前 i 个元素是否可有效分割（`dp[0]=true`）。三种转移：末尾取 2 个相等、3 个相等、3 个连续递增，满足其一即置 `dp[i]=true`。

## Java 代码实现

```java
class Solution {
    public boolean validPartition(int[] nums) {
        int n = nums.length;
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 2; i <= n; i++) {
            // 末尾 2 个相等
            if (dp[i - 2] && nums[i - 1] == nums[i - 2]) dp[i] = true;
            if (i >= 3) {
                // 末尾 3 个相等
                if (dp[i - 3] && nums[i - 1] == nums[i - 2] && nums[i - 2] == nums[i - 3]) dp[i] = true;
                // 末尾 3 个连续递增
                if (dp[i - 3] && nums[i - 1] - nums[i - 2] == 1 && nums[i - 2] - nums[i - 3] == 1) dp[i] = true;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `dp[i]` 表示 `nums[0..i-1]` 是否可有效分割，三种转移对应三种合法子数组。
2. `dp[i]` 只依赖 `dp[i-2]` 和 `dp[i-3]`，可进一步用滚动变量优化空间。
3. 连续递增条件：`nums[i-1]-nums[i-2]==1` 且 `nums[i-2]-nums[i-3]==1`。
