## 题目描述

有 `n` 个气球，编号为 `0` 到 `n - 1`，每个气球上都标有一个数字，这些数字存在数组 `nums` 中。

现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币。这里的 `i - 1` 和 `i + 1` 代表和 `i` 相邻的两个气球的序号。如果 `i - 1` 或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。

求所能获得硬币的最大数量。

**示例 1：**
```
输入：nums = [3,1,5,8]
输出：167
解释：
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167
```

**示例 2：**
```
输入：nums = [1,5]
输出：10
```

**提示：**
- `n == nums.length`
- `1 <= n <= 300`
- `0 <= nums[i] <= 100`

## 解题思路

这是一道非常经典的区间 DP 问题。

### 为什么不能贪心？

戳破气球的顺序会影响后续的收益，因为每次戳破气球后，相邻关系会改变。

### 核心思路：逆向思维

**正向思考**（困难）：先戳哪个气球？
- 戳破一个气球后，相邻关系改变，难以处理

**逆向思考**（巧妙）：最后戳哪个气球？⭐
- 假设最后戳破的是第 `k` 个气球
- 此时左右两边的气球都已被戳破
- 收益为：`nums[left-1] * nums[k] * nums[right+1]`
- 加上左右两边的最优收益

### 状态定义

`dp[i][j]` 表示戳破区间 `(i, j)` 开区间内所有气球能获得的最大硬币数。

**注意**：是开区间，不包括 `i` 和 `j`。

### 状态转移

对于区间 `(i, j)`，枚举最后戳破的气球 `k`（`i < k < j`）：

```
dp[i][j] = max(dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j])
           for k in range(i+1, j)
```

解释：
- `dp[i][k]`：左边区间的最优解
- `nums[i]*nums[k]*nums[j]`：戳破 k 的收益（此时 i 和 j 还在）
- `dp[k][j]`：右边区间的最优解

### 边界处理

在数组两端添加虚拟气球 `1`，方便处理边界。

## Java 代码实现

### 方法一：区间 DP（推荐）⭐

```java
class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;

        // 添加虚拟气球，构建新数组
        int[] arr = new int[n + 2];
        arr[0] = 1;
        arr[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            arr[i + 1] = nums[i];
        }
        int len = arr.length; // n + 2

        // dp[i][j] 表示戳破开区间 (i, j) 内所有气球的最大收益
        int[][] dp = new int[len][len];

        // 区间长度从小到大（至少为 3，包含两个边界和至少一个气球）
        for (int length = 3; length <= len; length++) {
            // 枚举区间起点
            for (int i = 0; i <= len - length; i++) {
                int j = i + length - 1;

                // 枚举最后戳破的气球 k
                for (int k = i + 1; k < j; k++) {
                    // 戳破 k 的收益 + 左右两边的最优收益
                    int coins = arr[i] * arr[k] * arr[j];
                    dp[i][j] = Math.max(dp[i][j], dp[i][k] + coins + dp[k][j]);
                }
            }
        }

        // 返回整个区间的最优解（不包括虚拟气球）
        return dp[0][len - 1];
    }
}
```

### 方法二：记忆化搜索

```java
import java.util.*;

class Solution {
    private int[] arr;
    private int[][] memo;

    public int maxCoins(int[] nums) {
        int n = nums.length;

        // 添加虚拟气球
        arr = new int[n + 2];
        arr[0] = 1;
        arr[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            arr[i + 1] = nums[i];
        }
        int len = arr.length;

        // 初始化备忘录，-1 表示未计算
        memo = new int[len][len];
        for (int[] row : memo) Arrays.fill(row, -1);

        return dp(0, len - 1);
    }

    /**
     * 返回戳破开区间 (i, j) 内所有气球的最大收益
     */
    private int dp(int i, int j) {
        // 区间内没有气球
        if (i + 1 == j) return 0;

        // 已经计算过
        if (memo[i][j] != -1) return memo[i][j];

        int maxCoins = 0;
        // 枚举最后戳破的气球 k
        for (int k = i + 1; k < j; k++) {
            int coins = arr[i] * arr[k] * arr[j];
            maxCoins = Math.max(maxCoins, dp(i, k) + coins + dp(k, j));
        }

        memo[i][j] = maxCoins;
        return maxCoins;
    }
}
```

### 方法三：带详细注释的版本

```java
class Solution {
    /**
     * 区间 DP 解决戳气球问题
     *
     * 核心思想：逆向思考，考虑最后戳破哪个气球
     *
     * 为什么要逆向？
     * - 正向：戳破一个气球后，相邻关系改变，难以处理
     * - 逆向：最后戳破时，左右气球已知（就是区间边界）
     *
     * 为什么添加虚拟气球？
     * - 方便处理边界情况
     * - 统一状态转移方程
     */
    public int maxCoins(int[] nums) {
        int n = nums.length;

        // 步骤1：添加虚拟气球（值为 1）
        int[] arr = new int[n + 2];
        arr[0] = 1;
        arr[n + 1] = 1;
        for (int i = 0; i < n; i++) arr[i + 1] = nums[i];
        int len = arr.length;

        // 步骤2：初始化 DP 数组
        // dp[i][j] = 戳破开区间 (i, j) 内所有气球的最大收益
        // 开区间：不包括 i 和 j
        int[][] dp = new int[len][len];

        // 步骤3：从小区间到大区间计算
        // length = 区间长度（包括两个边界）
        for (int length = 3; length <= len; length++) {
            // 枚举区间起点 i
            for (int i = 0; i <= len - length; i++) {
                // 计算区间终点 j
                int j = i + length - 1;

                // 枚举最后戳破的气球 k（在开区间 (i, j) 内）
                for (int k = i + 1; k < j; k++) {
                    // 1. 左边区间 (i, k) 的最优解
                    int left = dp[i][k];

                    // 2. 戳破 k 的收益（此时只剩下 i, k, j 三个气球）
                    int current = arr[i] * arr[k] * arr[j];

                    // 3. 右边区间 (k, j) 的最优解
                    int right = dp[k][j];

                    // 更新最大值
                    dp[i][j] = Math.max(dp[i][j], left + current + right);
                }
            }
        }

        // 返回整个区间的最优解
        return dp[0][len - 1];
    }
}
```

### 方法四：递归写法

```java
import java.util.*;

class Solution {
    private int[] arr;
    private Map<String, Integer> memo = new HashMap<>();

    public int maxCoins(int[] nums) {
        int n = nums.length;
        arr = new int[n + 2];
        arr[0] = 1;
        arr[n + 1] = 1;
        for (int i = 0; i < n; i++) arr[i + 1] = nums[i];
        return dfs(0, arr.length - 1);
    }

    /**
     * 计算区间 (i, j) 的最大收益
     */
    private int dfs(int i, int j) {
        if (i + 1 == j) return 0;

        String key = i + "," + j;
        if (memo.containsKey(key)) return memo.get(key);

        int maxCoins = 0;
        for (int k = i + 1; k < j; k++) {
            int coins = arr[i] * arr[k] * arr[j];
            maxCoins = Math.max(maxCoins, dfs(i, k) + coins + dfs(k, j));
        }

        memo.put(key, maxCoins);
        return maxCoins;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n³)
  - 外层循环：O(n)（区间长度）
  - 中层循环：O(n)（区间起点）
  - 内层循环：O(n)（枚举 k）
- 空间复杂度：O(n²)，DP 数组

## 关键点总结

1. **逆向思维**：考虑最后戳破哪个气球，而不是第一个
2. **虚拟气球**：在两端添加值为 1 的气球，简化边界处理
3. **开区间**：`dp[i][j]` 是开区间 `(i, j)`，不包括 `i` 和 `j`
4. **区间 DP**：从小区间到大区间计算
5. **状态转移**：枚举最后戳破的气球 `k`，分成左右两部分

## 易错点

1. **区间定义**：是开区间还是闭区间，要统一
2. **虚拟气球**：忘记添加或添加错误
3. **循环顺序**：区间长度要从小到大
4. **边界条件**：`i + 1 == j` 时没有气球可戳
5. **最后戳破**：收益是 `nums[i]*nums[k]*nums[j]`，不是 `nums[k-1]*nums[k]*nums[k+1]`
