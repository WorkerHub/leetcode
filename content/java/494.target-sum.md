## 题目描述

给你一个整数数组 nums 和一个整数 target。

向数组中的每个整数前添加 '+' 或 '-'，然后串联起所有整数，可以构造一个表达式：
- 例如，nums = [2, 1]，可以在 2 之前添加 '+'，在 1 之前添加 '-'，然后串联起来得到表达式 "+2-1"。

返回可以通过上述方法构造的、运算结果等于 target 的不同表达式的数目。

**示例 1：**
```
输入：nums = [1,1,1,1,1], target = 3
输出：5
解释：一共有 5 种方法让最终目标和为 3。
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

**示例 2：**
```
输入：nums = [1], target = 1
输出：1
```

**提示：**
- 1 <= nums.length <= 20
- 0 <= nums[i] <= 1000
- 0 <= sum(nums[i]) <= 1000
- -1000 <= target <= 1000

## 解题思路

这是一道经典的背包问题，可以用回溯或动态规划解决。

### 数学转换

设正数之和为 P，负数之和的绝对值为 N，则：
- P - N = target
- P + N = sum(nums)

两式相加：2P = target + sum(nums)
因此：P = (target + sum(nums)) / 2

**问题转换**：从数组中选取若干数，使其和为 P，有多少种选法？这是一个 0-1 背包问题。

### 核心思想

1. **回溯解法**：
   - 枚举每个数的符号（+ 或 -）
   - 递归计算所有可能的结果
   - 统计等于 target 的方案数

2. **动态规划**：
   - 转换为背包问题
   - dp[i] 表示和为 i 的方案数
   - 遍历每个数，更新 dp 数组

## Java 代码实现

### 方法一：动态规划（0-1背包）推荐

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int total = 0;
        for (int num : nums) total += num;

        // 边界情况
        if (Math.abs(target) > total || (target + total) % 2 != 0) {
            return 0;
        }

        // 目标和
        int P = (target + total) / 2;

        // dp[i] 表示和为 i 的方案数
        int[] dp = new int[P + 1];
        dp[0] = 1; // 和为 0 的方案数为 1

        // 遍历每个数
        for (int num : nums) {
            // 从后向前更新（避免重复使用）
            for (int j = P; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }

        return dp[P];
    }
}
```

### 方法二：回溯（DFS + 记忆化）

```java
import java.util.*;

class Solution {
    private Map<String, Integer> memo = new HashMap<>();

    public int findTargetSumWays(int[] nums, int target) {
        return dfs(nums, 0, 0, target);
    }

    private int dfs(int[] nums, int index, int currentSum, int target) {
        // 到达末尾
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }

        // 记忆化
        String key = index + "," + currentSum;
        if (memo.containsKey(key)) {
            return memo.get(key);
        }

        // 加号
        int count = dfs(nums, index + 1, currentSum + nums[index], target);
        // 减号
        count += dfs(nums, index + 1, currentSum - nums[index], target);

        memo.put(key, count);
        return count;
    }
}
```

### 方法三：二维 DP

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int n = nums.length;
        int total = 0;
        for (int num : nums) total += num;

        if (Math.abs(target) > total) {
            return 0;
        }

        // dp[i][j] 表示前 i 个数和为 j 的方案数
        // j 的范围是 [-total, total]，偏移 total 存储
        int[][] dp = new int[n + 1][2 * total + 1];
        dp[0][total] = 1; // 和为 0（偏移后索引为 total）

        for (int i = 1; i <= n; i++) {
            for (int j = -total; j <= total; j++) {
                // 加上当前数
                if (j - nums[i - 1] + total >= 0) {
                    dp[i][j + total] += dp[i - 1][j - nums[i - 1] + total];
                }
                // 减去当前数
                if (j + nums[i - 1] + total < 2 * total + 1) {
                    dp[i][j + total] += dp[i - 1][j + nums[i - 1] + total];
                }
            }
        }

        return dp[n][target + total];
    }
}
```

### 方法四：纯回溯（无记忆化，慢）

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        // 纯回溯，适合理解但会超时
        return backtrack(nums, 0, 0, target);
    }

    private int backtrack(int[] nums, int index, int currentSum, int target) {
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }

        // 尝试加号和减号
        return backtrack(nums, index + 1, currentSum + nums[index], target)
             + backtrack(nums, index + 1, currentSum - nums[index], target);
    }
}
```

## 复杂度分析

**方法一：DP**
- **时间复杂度**：O(n × sum)
  - n 个数，每个数更新 sum 个状态

- **空间复杂度**：O(sum)
  - 一维 DP 数组

**方法二：回溯 + 记忆化**
- **时间复杂度**：O(n × sum)
  - 状态数：n × sum

- **空间复杂度**：O(n × sum)
  - 记忆化字典

**方法四：纯回溯**
- **时间复杂度**：O(2^n)
- **空间复杂度**：O(n)

## 关键点总结

1. **问题转换**：从符号问题转换为背包问题
2. **数学推导**：P = (target + sum) / 2
3. **边界检查**：(target + sum) 必须是偶数且 <= 2 × sum
4. **0-1背包**：每个数只能用一次
5. **倒序更新**：避免重复使用同一个数

## 易错点

1. **边界条件**
   - (target + sum) 必须是偶数
   - abs(target) <= sum
   - 需要提前判断

2. **DP 更新顺序**
   - 必须从后向前更新
   - 避免使用更新后的值

3. **初始化**
   - dp[0] = 1，表示和为 0 有 1 种方案
   - 不要忘记初始化

4. **数学转换**
   - 容易忘记除以 2
   - 容易忘记检查能否整除

5. **记忆化的 key**
   - 使用 "index,currentSum" 字符串作为 key
   - 确保唯一性

## 学习建议

1. **掌握问题转换**：
   - 从原始问题到数学问题
   - 从数学问题到背包问题
   - 这是解题的关键

2. **0-1 背包模板**：
   - 状态定义
   - 状态转移
   - 更新顺序（倒序）

3. **回溯 vs DP**：
   - 回溯：自顶向下，易理解
   - DP：自底向上，效率高
   - 两种思路都要掌握

4. **记忆化技巧**：
   - 识别重复子问题
   - 使用 HashMap 缓存结果
   - 选择合适的 key

5. **优化空间**：
   - 二维 DP 转一维
   - 观察状态依赖关系
   - 倒序更新

6. **边界处理**：
   - 数学约束条件
   - 特殊情况（target = 0等）
   - 提前返回优化
