## 题目描述

n 个服务器构成无权无向图，主服务器为 0 号。每个数据服务器 i 有耐心值 patience[i]，每次往返最短路后若未收到回复则重发；求所有信息到达且无新信息传输的最早时刻。

## 解题思路

BFS 求从 0 到每个节点的最短距离 d，往返时间 rtt = 2d。最后一次重发时刻为 `((rtt-1)/patience)*patience`，该信息到达时刻再加 1 即为该服务器的贡献，取所有服务器的最大值。

## Java 代码实现

### 方法一：BFS + 数学计算（推荐）

```java
import java.util.*;

class Solution {
    public int networkBecomesIdle(int[][] edges, int[] patience) {
        int n = patience.length;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // BFS 求最短距离
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        dist[0] = 0;
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int nei : graph.get(node)) {
                if (dist[nei] == -1) {
                    dist[nei] = dist[node] + 1;
                    queue.offer(nei);
                }
            }
        }

        int ans = 0;
        for (int i = 1; i < n; i++) {
            int rtt = 2 * dist[i];
            int p = patience[i];
            int lastSend = ((rtt - 1) / p) * p; // 最后一次重发时刻
            ans = Math.max(ans, lastSend + rtt);
        }
        return ans + 1; // 最后信息到达后下一秒空闲
    }
}
```

## 复杂度分析

- 时间复杂度：O(V + E)
- 空间复杂度：O(V + E)

## 关键点总结

1. BFS 求无权图最短距离
2. 最后一次重发时刻：`((rtt-1) / patience) * patience`（发送时刻严格小于 rtt）
3. 答案为所有服务器最后回复到达时刻的最大值加 1
