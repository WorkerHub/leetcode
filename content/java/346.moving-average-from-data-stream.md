## 题目描述

给定一个整数数据流和一个窗口大小，根据该滑动窗口的大小，计算其所有整数的移动平均值。

实现 `MovingAverage` 类：

- `MovingAverage(int size)` 用窗口大小 `size` 初始化对象。
- `double next(int val)` 计算并返回数据流中最后 `size` 个值的移动平均值。

**示例：**
```
输入：
["MovingAverage", "next", "next", "next", "next"]
[[3], [1], [10], [3], [5]]
输出：
[null, 1.0, 5.5, 4.66667, 6.0]

解释：
MovingAverage movingAverage = new MovingAverage(3);
movingAverage.next(1);  // 返回 1.0 = 1 / 1
movingAverage.next(10); // 返回 5.5 = (1 + 10) / 2
movingAverage.next(3);  // 返回 4.66667 = (1 + 10 + 3) / 3
movingAverage.next(5);  // 返回 6.0 = (10 + 3 + 5) / 3
```

**提示：**
- `1 <= size <= 1000`
- `-10^5 <= val <= 10^5`
- 最多调用 `next` 方法 `10^4` 次

## 解题思路

这是一道设计题，核心是实现一个固定大小的滑动窗口。

**关键概念：**
- 滑动窗口：只保留最近的 `size` 个数据
- 移动平均：窗口内所有数的平均值

**实现方案：**

**方案1：队列实现**
- 使用队列（Queue/Deque）维护窗口
- 当队列满时，移除最旧的元素
- 维护窗口内元素的总和

**方案2：数组实现**
- 使用固定大小的数组和索引指针
- 循环使用数组空间
- 同样维护总和

## Java 代码实现

### 方法一：队列 + 总和（推荐）⭐

```java
import java.util.Queue;
import java.util.LinkedList;

class MovingAverage {
    private int size;
    private Queue<Integer> queue;
    private int windowSum;

    public MovingAverage(int size) {
        // 初始化固定大小的滑动窗口
        this.size = size;
        this.queue = new LinkedList<>();
        this.windowSum = 0;
    }

    public double next(int val) {
        // 添加新值
        queue.offer(val);
        windowSum += val;

        // 如果窗口满了，移除最旧的值
        if (queue.size() > size) {
            windowSum -= queue.poll();
        }

        // 返回平均值
        return (double) windowSum / queue.size();
    }
}
```

**时间复杂度：** O(1)，每次操作都是常数时间
**空间复杂度：** O(size)，存储窗口数据

### 方法二：循环数组（节省空间）

```java
class MovingAverage {
    private int size;
    private int[] window;   // 固定大小数组
    private int count;      // 当前窗口中的元素个数
    private int index;      // 当前插入位置
    private int windowSum;  // 窗口总和

    public MovingAverage(int size) {
        this.size = size;
        this.window = new int[size];
        this.count = 0;
        this.index = 0;
        this.windowSum = 0;
    }

    public double next(int val) {
        // 如果窗口已满，减去将被替换的值
        if (count == size) {
            windowSum -= window[index];
        }

        // 添加新值
        window[index] = val;
        windowSum += val;

        // 更新索引（循环）
        index = (index + 1) % size;

        // 更新计数（最多为 size）
        if (count < size) {
            count++;
        }

        // 返回平均值
        return (double) windowSum / count;
    }
}
```

**时间复杂度：** O(1)
**空间复杂度：** O(size)

### 方法三：使用 ArrayDeque（性能更好）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MovingAverage {
    private int size;
    private Deque<Integer> deque;
    private int windowSum;

    public MovingAverage(int size) {
        this.size = size;
        this.deque = new ArrayDeque<>();
        this.windowSum = 0;
    }

    public double next(int val) {
        deque.addLast(val);
        windowSum += val;

        // 超出窗口大小则移除队头
        if (deque.size() > size) {
            windowSum -= deque.pollFirst();
        }

        return (double) windowSum / deque.size();
    }
}
```

**注意：** `ArrayDeque` 比 `LinkedList` 性能更好，推荐使用 `ArrayDeque` 实现队列。

## 复杂度分析

| 方法 | next() 时间 | 空间复杂度 | 优点 | 缺点 |
|------|------------|-----------|------|------|
| LinkedList 队列 | O(1) | O(size) | 简洁 | LinkedList 有额外开销 |
| 循环数组 | O(1) | O(size) | 最节省空间 | 代码稍复杂 |
| ArrayDeque | O(1) | O(size) | 性能最佳 | 需要了解 Deque |

## 关键点总结

1. **数据结构选择**：ArrayDeque 比 LinkedList 更适合频繁的头部删除
2. **维护总和**：避免每次重新计算，O(1) 更新
3. **循环数组**：通过取模实现循环使用空间
4. **计数器**：区分窗口未满和已满的情况
5. **边界处理**：窗口未满时使用实际元素个数

## 易错点

1. **每次重新计算总和**
   ```java
   // 错误：需要遍历队列计算总和，O(n)
   public double next(int val) {
       queue.offer(val);
       if (queue.size() > size) queue.poll();
       int sum = 0;
       for (int x : queue) sum += x;  // O(n)!
       return (double) sum / queue.size();
   }

   // 正确：维护总和，O(1)
   public double next(int val) {
       windowSum += val;
       queue.offer(val);
       if (queue.size() > size) {
           windowSum -= queue.poll();
       }
       return (double) windowSum / queue.size();
   }
   ```

2. **循环数组索引错误**
   ```java
   // 错误：index 可能越界
   index++;

   // 正确：使用取模
   index = (index + 1) % size;
   ```

3. **count 计数错误**
   ```java
   // 错误：count 可能超过 size
   count++;

   // 正确：限制最大值
   if (count < size) {
       count++;
   }
   ```

4. **平均值计算用错分母**
   ```java
   // 错误：使用 size 而不是实际元素数（窗口未满时会出错）
   return (double) windowSum / size;

   // 正确：使用实际元素数
   return (double) windowSum / queue.size();
   // 或
   return (double) windowSum / count;
   ```

5. **整数除法导致精度丢失**
   ```java
   // 错误：整数除法
   return windowSum / queue.size();

   // 正确：强制转换为 double
   return (double) windowSum / queue.size();
   ```

**扩展思考：**
```java
// 问题1：如何支持获取窗口中位数？
// 需要维护有序结构，可以用两个堆（最大堆 + 最小堆）

// 问题2：如何支持加权移动平均？
// 每个元素乘以权重，维护加权总和

// 问题3：如何支持指数移动平均（EMA）？
// EMA = α * current + (1-α) * previousEMA
class ExponentialMovingAverage {
    private double alpha;
    private Double ema;

    public ExponentialMovingAverage(double alpha) {
        this.alpha = alpha;
        this.ema = null;
    }

    public double next(double val) {
        if (ema == null) {
            ema = val;
        } else {
            ema = alpha * val + (1 - alpha) * ema;
        }
        return ema;
    }
}
```
