## 题目描述

给定二维字符串数组 `responses`，每个调查对象的回答先去重，再统计所有对象中每个回答的出现频率。返回频率最高的回答，并列时返回字典序最小的。

## 解题思路

对每个调查对象用 HashSet 去重，再用 HashMap 统计全局频率，最后遍历找最高频且字典序最小的回答。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String findCommonResponse(String[][] responses) {
        Map<String, Integer> freq = new HashMap<>();
        for (String[] resp : responses) {
            Set<String> unique = new HashSet<>(Arrays.asList(resp));
            for (String w : unique) freq.merge(w, 1, Integer::sum);
        }
        String best = null;
        int maxFreq = 0;
        for (Map.Entry<String, Integer> e : freq.entrySet()) {
            int f = e.getValue();
            String w = e.getKey();
            if (f > maxFreq || (f == maxFreq && w.compareTo(best) < 0)) {
                maxFreq = f;
                best = w;
            }
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为调查对象数，m 为回答列表平均长度
- 空间复杂度：O(n * m)

## 关键点总结

1. 每个对象的回答先 HashSet 去重，再统计全局频率
2. 并列时选字典序最小（compareTo < 0）
3. merge 方法简洁地累加计数
