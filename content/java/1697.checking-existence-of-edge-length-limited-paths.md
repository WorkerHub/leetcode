## 题目描述

`n` 个节点的无向图，`edgeList[i] = [u, v, dis]`。查询 `queries[j] = [p, q, limit]`，判断是否存在从 `p` 到 `q` 且每条边权严格小于 `limit` 的路径。

## 解题思路

**离线排序 + 并查集：** 将查询和边均按权重升序排序，双指针推进：对每个查询，将所有权重 < limit 的边加入并查集，再用并查集判断 p、q 是否连通。

## Java 代码实现

```java
class Solution {
    private int[] parent, rank;

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }

    public boolean[] distanceLimitedPathsExist(int n, int[][] edgeList, int[][] queries) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 将查询附上原始下标并按 limit 排序
        int q = queries.length;
        Integer[] qi = new Integer[q];
        for (int i = 0; i < q; i++) qi[i] = i;
        Arrays.sort(qi, (a, b) -> queries[a][2] - queries[b][2]);

        // 边按权重排序
        Arrays.sort(edgeList, (a, b) -> a[2] - b[2]);

        boolean[] ans = new boolean[q];
        int ei = 0;
        for (int idx : qi) {
            int limit = queries[idx][2];
            // 将所有权重严格小于 limit 的边加入并查集
            while (ei < edgeList.length && edgeList[ei][2] < limit) {
                union(edgeList[ei][0], edgeList[ei][1]);
                ei++;
            }
            ans[idx] = (find(queries[idx][0]) == find(queries[idx][1]));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((E + Q) log(E + Q))
- **空间复杂度**：O(n + Q)

## 关键点总结

1. 离线处理：将查询按 limit 排序，边指针单调推进
2. 注意条件是严格小于 limit：`edgeList[ei][2] < limit`
3. 查询排序时保留原始下标，以便填写答案数组
