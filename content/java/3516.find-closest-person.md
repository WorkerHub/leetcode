## 题目描述

给定三个位置 `x1`、`x2`、`y`，返回 `y` 更靠近 `x1` 还是 `x2`：靠近 `x1` 返回 1，靠近 `x2` 返回 2，距离相等返回 0。

## 解题思路

分别计算 `|y - x1|` 和 `|y - x2|`，直接比较大小。

## Java 代码实现

```java
class Solution {
    public int findClosestPerson(int x1, int x2, int y) {
        int d1 = Math.abs(y - x1);
        int d2 = Math.abs(y - x2);
        if (d1 < d2) return 1;
        if (d2 < d1) return 2;
        return 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 绝对距离直接比较
2. 距离相等返回 0
