## 题目描述

给你链表的头结点 `head`，请将其按升序排列并返回排序后的链表。

**示例 1：**

```
输入: head = [4,2,1,3]
输出: [1,2,3,4]
```

**示例 2：**

```
输入: head = [-1,5,3,4,0]
输出: [-1,0,3,4,5]
```

**示例 3：**

```
输入: head = []
输出: []
```

**提示：**

- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

**进阶：** 你可以在 `O(n log n)` 时间复杂度和常数级空间复杂度下，对链表进行排序吗？

## 解题思路

这道题要求 O(n log n) 的时间复杂度，常见的排序算法中符合要求的有：
- 归并排序
- 堆排序
- 快速排序

对于链表，归并排序是最佳选择，因为：
1. 链表不支持随机访问，快速排序效率低
2. 链表的合并操作非常高效，适合归并排序
3. 可以实现 O(1) 的空间复杂度（自底向上）

**归并排序思路：**

采用分治策略：
1. **分割**：找到链表中点，将链表分成两半
2. **递归**：对两个子链表分别排序
3. **合并**：将两个有序链表合并成一个有序链表

## Java 代码实现

### 方法一：自顶向下归并排序（递归，推荐理解）

```java
// Definition for singly-linked list.
// class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public ListNode sortList(ListNode head) {
        // 基础情况：空链表或单节点
        if (head == null || head.next == null) {
            return head;
        }

        // 1. 找到链表中点，分割成两半
        ListNode mid = getMiddle(head);
        ListNode rightHead = mid.next;
        mid.next = null;  // 断开链表

        // 2. 递归排序两个子链表
        ListNode left = sortList(head);
        ListNode right = sortList(rightHead);

        // 3. 合并两个有序链表
        return merge(left, right);
    }

    private ListNode getMiddle(ListNode head) {
        // 快慢指针找中点
        ListNode slow = head;
        ListNode fast = head.next;  // fast 从 head.next 开始，确保左半部分较短

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        return slow;
    }

    private ListNode merge(ListNode l1, ListNode l2) {
        // 合并两个有序链表
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;

        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                curr.next = l1;
                l1 = l1.next;
            } else {
                curr.next = l2;
                l2 = l2.next;
            }
            curr = curr.next;
        }

        // 连接剩余部分
        curr.next = (l1 != null) ? l1 : l2;

        return dummy.next;
    }
}
```

### 方法二：自底向上归并排序（迭代，O(1) 空间）

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        // 1. 计算链表长度
        int length = 0;
        ListNode node = head;
        while (node != null) {
            length++;
            node = node.next;
        }

        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // 2. 自底向上归并，子链表长度从 1, 2, 4, 8... 递增
        for (int size = 1; size < length; size *= 2) {
            ListNode curr = dummy.next;
            ListNode tail = dummy;

            while (curr != null) {
                // 分割出第一个长度为 size 的子链表
                ListNode left = curr;
                ListNode right = split(left, size);
                // 分割出第二个长度为 size 的子链表
                curr = split(right, size);

                // 合并两个子链表，并连接到 tail 后面
                tail = mergeAndConnect(left, right, tail);
            }
        }

        return dummy.next;
    }

    private ListNode split(ListNode head, int size) {
        // 分割出长度为 size 的链表，返回剩余部分的头节点
        if (head == null) {
            return null;
        }

        for (int i = 1; i < size && head.next != null; i++) {
            head = head.next;
        }

        ListNode rest = head.next;
        head.next = null;
        return rest;
    }

    private ListNode mergeAndConnect(ListNode l1, ListNode l2, ListNode tail) {
        // 合并 l1 和 l2，连接到 tail 后面，返回合并后的尾节点
        ListNode curr = tail;

        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                curr.next = l1;
                l1 = l1.next;
            } else {
                curr.next = l2;
                l2 = l2.next;
            }
            curr = curr.next;
        }

        curr.next = (l1 != null) ? l1 : l2;

        // 移动到尾节点
        while (curr.next != null) {
            curr = curr.next;
        }

        return curr;
    }
}
```

### 方法三：简化版（将链表转为数组排序，不推荐但好理解）

```java
class Solution {
    public ListNode sortList(ListNode head) {
        // 1. 将链表转换为数组
        List<Integer> arr = new ArrayList<>();
        ListNode curr = head;
        while (curr != null) {
            arr.add(curr.val);
            curr = curr.next;
        }

        // 2. 排序数组
        Collections.sort(arr);

        // 3. 重建链表
        ListNode dummy = new ListNode(0);
        curr = dummy;
        for (int val : arr) {
            curr.next = new ListNode(val);
            curr = curr.next;
        }

        return dummy.next;
    }
    // 注意：方法三空间复杂度 O(n)，不符合进阶要求
}
```

## 复杂度分析

**方法一：自顶向下归并排序**

- 时间复杂度：O(n log n)
  - 递归深度：log n
  - 每层合并：O(n)
- 空间复杂度：O(log n)
  - 递归调用栈的深度

**方法二：自底向上归并排序**

- 时间复杂度：O(n log n)
  - 外层循环：log n 次（size: 1, 2, 4, ...）
  - 每次循环合并：O(n)
- 空间复杂度：O(1)
  - 只使用常数个指针变量

**方法三：转数组排序**

- 时间复杂度：O(n log n) - 取决于排序算法
- 空间复杂度：O(n) - 数组存储

## 图解示例

以 `head = [4,2,1,3]` 为例（自顶向下）：

```
原链表: 4 -> 2 -> 1 -> 3

第一次分割:
左: 4 -> 2
右: 1 -> 3

递归左半部分:
  分割: 4 | 2
  合并: 2 -> 4

递归右半部分:
  分割: 1 | 3
  合并: 1 -> 3

最终合并:
  2 -> 4  和  1 -> 3
  结果: 1 -> 2 -> 3 -> 4
```

自底向上过程：

```
原始: 4 -> 2 -> 1 -> 3

size = 1:
  合并 (4) 和 (2) -> 2 -> 4
  合并 (1) 和 (3) -> 1 -> 3
  结果: 2 -> 4 -> 1 -> 3

size = 2:
  合并 (2->4) 和 (1->3) -> 1 -> 2 -> 3 -> 4
  结果: 1 -> 2 -> 3 -> 4
```

## 关键点总结

1. **归并排序是链表排序的最佳选择**：
   - 不需要随机访问
   - 合并操作高效
   - 稳定排序

2. **找中点技巧**：
   - 快慢指针：slow 每次走一步，fast 走两步
   - fast 从 head.next 开始，保证左半部分不会比右半部分长

3. **两种实现方式**：
   - 自顶向下（递归）：代码简洁，空间 O(log n)
   - 自底向上（迭代）：空间 O(1)，满足进阶要求

4. **合并有序链表**：
   - 是归并排序的核心操作
   - 使用虚拟头节点简化代码

5. **断链操作**：
   - 分割时必须断开连接：`mid.next = null`
   - 避免形成环或访问错误区域

## 易错点

1. **找中点时的边界**：
   - `fast` 从 `head.next` 开始，而不是 `head`
   - 确保分割后左右两部分长度合理

2. **断链操作**：
   - 分割后必须 `mid.next = null`
   - 否则会导致无限递归或错误合并

3. **空链表处理**：
   - 递归基础情况：`if (head == null || head.next == null)`
   - 合并时处理 l1 或 l2 为 null 的情况

4. **自底向上的复杂度**：
   - split 函数要正确断开链表
   - mergeAndConnect 要返回正确的尾节点

5. **合并后的连接**：
   - 确保 tail 正确连接到合并后的链表
   - 更新 tail 到新的尾部
