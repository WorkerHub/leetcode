## 题目描述

给定非负整数 `lo` 和 `hi`，找最小非负整数 `x`，使得存在 `y` 满足 `lo <= y <= hi` 且 `y XOR x = y + x`（即 y 与 x 无公共 1 位）。

## Java 代码实现

```java
class Solution {
    public int findMinimumXor(int lo, int hi) {
        // y XOR x = y + x 等价于 y AND x = 0
        // x = 0 时任意 y 都满足（0 AND y = 0），直接返回 0
        return 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `y XOR x = y + x` 等价于 `y AND x = 0`（无进位加法等于异或）
2. x = 0 时 `0 AND y = 0` 恒成立，故最小 x = 0
3. 范围 [lo, hi] 非空（lo <= hi），必有合法 y
