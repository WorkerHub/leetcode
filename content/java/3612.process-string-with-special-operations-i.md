## 题目描述

给定字符串 `s`，按规则处理：普通字符追加到结果尾部，`'*'` 删除结果最后一个字符，`'#'` 将结果翻转，返回最终结果字符串。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String processStr(String s) {
        Deque<Character> dq = new ArrayDeque<>();
        boolean isReversed = false;

        for (char c : s.toCharArray()) {
            if (c == '*') {
                if (!dq.isEmpty()) {
                    if (!isReversed) dq.pollLast();
                    else dq.pollFirst();
                }
            } else if (c == '#') {
                isReversed = !isReversed;
            } else {
                if (!isReversed) dq.offerLast(c);
                else dq.offerFirst(c);
            }
        }

        StringBuilder sb = new StringBuilder();
        for (char ch : dq) sb.append(ch);
        if (isReversed) sb.reverse();
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个操作均摊 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 双端队列配合方向标志，O(1) 实现逻辑翻转（`'#'` 只切换标志）
2. 方向标志切换时，追加和删除方向都对应切换
3. 最终输出时根据方向标志决定是否反转
