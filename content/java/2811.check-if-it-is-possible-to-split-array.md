## 题目描述

给你整数数组 `nums` 和整数 `m`，每次操作可将某个子数组分成两个非空连续子数组（条件是至少一个子数组之和 >= m），判断能否分割到每个子数组长度为 1。

## Java 代码实现

```java
class Solution {
    public boolean canSplitArray(int[] nums, int m) {
        // n==1 时不需要分割
        if (nums.length == 1) return true;
        // 只需检查是否存在相邻两元素之和 >= m
        for (int i = 0; i + 1 < nums.length; i++) {
            if (nums[i] + nums[i + 1] >= m) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 核心结论：n==1 直接返回 true；否则只需检查是否存在相邻两元素之和 >= m
2. 长度 > 2 的子数组，只要包含一对相邻和 >= m 的元素，就可以一步步分割
