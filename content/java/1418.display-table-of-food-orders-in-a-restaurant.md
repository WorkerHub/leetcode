## 题目描述

给你一个数组 `orders`，表示客户在餐厅中完成的订单，其中 `orders[i] = [customerName, tableNumber, foodItem]`。

请你返回该餐厅的 **展示表**。在展示表中：

- 第一行包含所有不同的菜品名称，第一列为 `"Table"`，其余列按菜品名称的字典序排列
- 从第二行开始，每行展示每张桌子的订单情况：第一列是桌号（升序排列），其余列为对应菜品的订单数量（如果没点该菜则为 `"0"`）

**示例：**

```
输入：orders = [["David","3","Ceviche"],["Corina","10","Beef Burrito"],
                ["David","3","Fried Chicken"],["Carla","5","Water"],
                ["Carla","5","Ceviche"],["Rina","10","Beef Burrito"]]
输出：
[["Table","Beef Burrito","Ceviche","Fried Chicken","Water"],
 ["3","0","1","1","0"],
 ["5","0","1","0","1"],
 ["10","2","0","0","0"]]
```

**提示：**

- `1 <= orders.length <= 5 * 10^4`
- `orders[i].length == 3`
- `1 <= customerName.length, foodItem.length <= 20`
- `1 <= tableNumber <= 500`
- `customerName` 和 `foodItem` 由小写和大写英文字母及空格组成

## 解题思路

### 哈希表 + 排序

1. 用集合收集所有菜品名称，用集合收集所有桌号
2. 用嵌套字典记录每张桌子每种菜品的数量
3. 对菜品名称按字典序排序，对桌号按数字升序排序
4. 构建结果矩阵：第一行为表头，后续每行为桌子数据

**关键细节：**
- 桌号按**数字**升序（不是字符串字典序）
- 不存在的菜品数量填 "0"

## Java 代码实现

### 方法一：嵌套 HashMap（推荐）

```java
import java.util.*;

class Solution {
    public List<List<String>> displayTable(List<List<String>> orders) {
        // 收集所有菜品（用集合去重）
        Set<String> foodSet = new TreeSet<>();  // TreeSet 自动排序
        // 收集所有桌号（用集合去重）
        Set<Integer> tableSet = new TreeSet<>();  // TreeSet 自动排序
        // 记录每张桌子每种菜品的数量：tableOrders[桌号][菜品名] = 数量
        Map<Integer, Map<String, Integer>> tableOrders = new HashMap<>();

        for (List<String> order : orders) {
            String food = order.get(2);
            int table = Integer.parseInt(order.get(1));
            foodSet.add(food);
            tableSet.add(table);
            tableOrders.computeIfAbsent(table, k -> new HashMap<>())
                       .merge(food, 1, Integer::sum);
        }

        // 菜品名按字典序排序（TreeSet 已排序）
        List<String> foods = new ArrayList<>(foodSet);
        // 桌号按数字升序排序（TreeSet 已排序）
        List<Integer> tables = new ArrayList<>(tableSet);

        // 构建结果
        List<List<String>> result = new ArrayList<>();

        // 第一行：表头
        List<String> header = new ArrayList<>();
        header.add("Table");
        header.addAll(foods);
        result.add(header);

        // 后续每行：桌号 + 各菜品数量
        for (int table : tables) {
            List<String> row = new ArrayList<>();
            row.add(String.valueOf(table));
            Map<String, Integer> orders2 = tableOrders.getOrDefault(table, new HashMap<>());
            for (String food : foods) {
                row.add(String.valueOf(orders2.getOrDefault(food, 0)));
            }
            result.add(row);
        }

        return result;
    }
}
```

## 复杂度分析

设 `n = orders.size()`，`F` 为不同菜品数，`T` 为不同桌号数。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 嵌套 HashMap | O(n + F log F + T log T + T * F) | O(n + T * F) |

构建结果矩阵需要 O(T * F)。

## 关键点总结

1. 用嵌套 HashMap 记录 `table -> food -> count` 的映射
2. 菜品名按**字典序**排序，桌号按**数字大小**排序（不是字符串排序）
3. 表头第一列固定为 `"Table"`
4. 不存在的菜品数量填 `"0"`（字符串，不是整数）
5. Java 中用 `TreeSet` 自动维护有序集合

## 易错点

1. 桌号排序：必须按数字排序，而非字符串排序（"10" < "3" 是字符串顺序）
2. 结果矩阵中所有元素都是字符串（包括数字和桌号）
3. 用 `computeIfAbsent` 或 `getOrDefault` 处理 HashMap 中不存在的键
