## 题目描述

给你只含 `0` 和 `1` 的整数数组 `nums`。光标初始在位置 0，每步操作：若当前值为 0 则右移，若为 1 则清零并回退（位置 0 时前进）。判断能否在有限步内将所有元素变为 0。

## 解题思路

若数组中 1 的总数为偶数，可以将所有元素变为 0；若为奇数则最后会剩一个 1 无法消除。

## Java 代码实现

```java
class Solution {
    public boolean makeArrayZero(int[] nums) {
        // 统计 1 的总数，偶数则可以全部清零
        int ones = 0;
        for (int x : nums) {
            ones += x;
        }
        return ones % 2 == 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 若数组中 1 的总数为偶数，可以将所有元素变为 0。
2. 若 1 的总数为奇数，最后会剩一个 1 无法消除。
3. 这是一道基于奇偶性的判断题。
