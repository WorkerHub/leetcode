## 题目描述

给定字符串 `s` 和字符串 `t`，找出 `s` 中需要删除的最少字符数，使得 `t` 不再是 `s` 的子序列。

## 解题思路

若 `t` 不是 `s` 的子序列直接返回 0。否则贪心：从 `t` 末尾向前，每次在 `s` 中找 `t[j]` 最靠后的匹配并删除，逐一截断所有匹配路径。

## Java 代码实现

```java
class Solution {
    public int minDeletions(String s, String t) {
        int n = s.length(), m = t.length();

        // 检查 t 是否是 s 的子序列
        int j = 0;
        for (int i = 0; i < n && j < m; i++) {
            if (s.charAt(i) == t.charAt(j)) j++;
        }
        if (j < m) return 0; // t 不是子序列，无需删除

        // 贪心：从 t 末尾往前，删除 t[j] 在 s 中最靠后的匹配
        int result = 0;
        j = m - 1;
        int i = n - 1;
        while (j >= 0 && i >= 0) {
            // 找 t[j] 在 s 中最靠后的位置
            while (i >= 0 && s.charAt(i) != t.charAt(j)) i--;
            if (i >= 0) {
                result++;
                i--;
                j--;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)

## 关键点总结

1. 先判断 t 是否是 s 的子序列，不是则返回 0
2. 从后往前贪心，每次删除 t 当前字符在 s 中最靠后的匹配
3. 最少删除数等于 t 的长度（每个字符截断一次）
