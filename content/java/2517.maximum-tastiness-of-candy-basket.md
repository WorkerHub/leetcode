## 题目描述

给你正整数数组 `price` 和正整数 `k`，从中选 `k` 类糖果，篮子的甜蜜度等于任意两种糖果价格差绝对值的最小值，返回可获得的最大甜蜜度。

## 解题思路

二分答案：二分最小差值 `d`，对排序后的数组贪心验证——从最小价格开始，每次选满足差值 >= `d` 的下一个，统计最多能选多少个，判断是否 >= `k`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximumTastiness(int[] price, int k) {
        Arrays.sort(price);
        int lo = 0, hi = price[price.length - 1] - price[0];
        // 二分最大化最小差值
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (canSelect(price, k, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    // 贪心验证：能否在差值 >= minDiff 的约束下选出 k 个
    private boolean canSelect(int[] price, int k, int minDiff) {
        int count = 1, last = price[0];
        for (int i = 1; i < price.length; i++) {
            if (price[i] - last >= minDiff) {
                count++;
                last = price[i];
                if (count == k) return true;
            }
        }
        return count >= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + n log(maxDiff))
- **空间复杂度**：O(1)

## 关键点总结

1. 最小差值最大化是典型"二分答案"题型
2. 排序后贪心验证：从左到右依次选满足差值条件的最小元素
3. 二分"最大满足条件的值"时 mid 取上整 `(lo + hi + 1) / 2` 避免死循环
