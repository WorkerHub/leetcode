## 题目描述

电影院每行有 10 个座位（列 1-10），给你已预约座位列表，返回最多能安排多少个 4 人家庭（4 人坐同行相邻 4 座）。

## 解题思路

每行有效的 4 连座只有三块：块A（列3-6）、块B（列5-8）、块C（列7-10）。用位掩码表示每行已预约情况，只处理有预约的行；空行直接用公式 `2×(n-有预约行数)` 计算。对有预约的行，先尝试放两组（A+C，不重叠），否则尝试放一组（A、B 或 C 任意一块为空）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        // 每行已预约座位的位掩码（第 col-1 位为 1 表示被预约）
        Map<Integer, Integer> rowMask = new HashMap<>();
        for (int[] seat : reservedSeats) {
            int row = seat[0], col = seat[1];
            rowMask.merge(row, 1 << (col - 1), (a, b) -> a | b);
        }

        // 三块的位掩码
        int A = 0b0000111100; // 列 3,4,5,6（位 2-5）
        int B = 0b0111100000; // 列 5,6,7,8（位 4-7）
        int C = 0b1111000000; // 列 7,8,9,10（位 6-9）

        // 空行直接贡献 2 个家庭
        int ans = 2 * (n - rowMask.size());

        for (int mask : rowMask.values()) {
            if ((mask & A) == 0 && (mask & C) == 0) {
                ans += 2; // 块A + 块C 均空，放两组
            } else if ((mask & A) == 0 || (mask & B) == 0 || (mask & C) == 0) {
                ans += 1; // 任意一块为空，放一组
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(reservedSeats.length)，遍历预约列表并处理有预约的行。
- 空间复杂度：O(unique rows)，哈希表存储有预约行的位掩码。

## 关键点总结

1. n 最大 10^9 但有预约的行至多 10^4，空行用公式直接计算，避免遍历所有行。
2. 块A+C 不重叠可放两组，否则尝试 A/B/C 任一块（贪心：先尝试最多再退而求其次）。
3. 位掩码 `(mask & BLOCK) == 0` 表示该块内所有座位均未被预约。
