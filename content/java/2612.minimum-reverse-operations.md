## 题目描述

数组中1在位置p，每次翻转大小为k的子数组移动1，某些位置禁止，求到达各位置的最少操作次数。

## 解题思路

BFS+有序集合(TreeSet)：从x翻转可到达等差为2的位置范围[yMin,yMax]，用奇偶分开的TreeSet批量处理未访问节点。

## Java 代码实现

```java
class Solution {
    public int[] minReverseOperations(int n, int p, int[] banned, int k) {
        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        ans[p] = 0;
        Set<Integer> bannedSet = new HashSet<>();
        for (int b : banned) bannedSet.add(b);

        // 奇偶分开的TreeSet存储未访问节点
        TreeSet<Integer>[] unvisited = new TreeSet[2];
        unvisited[0] = new TreeSet<>();
        unvisited[1] = new TreeSet<>();
        for (int i = 0; i < n; i++) {
            if (i != p && !bannedSet.contains(i)) {
                unvisited[i % 2].add(i);
            }
        }

        Queue<Integer> queue = new LinkedList<>();
        queue.offer(p);
        while (!queue.isEmpty()) {
            int x = queue.poll();
            int lMin = Math.max(0, x - k + 1);
            int lMax = Math.min(n - k, x);
            int yMin = 2 * lMin + k - 1 - x;
            int yMax = 2 * lMax + k - 1 - x;

            TreeSet<Integer> ts = unvisited[yMin % 2];
            // 批量取出[yMin, yMax]范围内的未访问节点
            Integer y = ts.ceiling(yMin);
            while (y != null && y <= yMax) {
                ans[y] = ans[x] + 1;
                queue.offer(y);
                ts.remove(y);
                y = ts.ceiling(yMin);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **可达位置是等差为2的序列**：奇偶性固定
2. **TreeSet批量删除**：ceiling快速定位范围内节点
3. **奇偶分开存储**：减少查找范围
