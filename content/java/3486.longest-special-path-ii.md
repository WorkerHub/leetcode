## 题目描述

给你以 0 为根的带权树，节点 i 的值为 `nums[i]`，从根出发路径上各节点值均不同的路径为"特殊路径"。返回最长特殊路径的边权之和，及同等长度下最少节点数。

## 解题思路

DFS + 哈希表（双指针思想）：维护从根到当前节点的路径前缀距离数组。哈希表记录路径上每个值最近出现的深度。添加节点时若发现值重复，有效路径起点推进到重复位置之后（起点只增不减）。回溯时恢复哈希表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] nums;
    private List<int[]>[] graph;
    private long[] prefixDist;
    private Map<Integer, Integer> lastSeen = new HashMap<>();
    private long ansLen = 0;
    private int ansNodes = 1;

    @SuppressWarnings("unchecked")
    public int[] longestSpecialPath(int[][] edges, int[] nums) {
        int n = nums.length;
        this.nums = nums;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        prefixDist = new long[n + 1];

        dfs(0, -1, 0, 0);
        return new int[]{(int) ansLen, ansNodes};
    }

    private void dfs(int u, int parent, int depth, int startDepth) {
        int val = nums[u];
        int prevDepth = lastSeen.getOrDefault(val, -1);
        int newStart = Math.max(startDepth, prevDepth + 1);

        long curLen = prefixDist[depth] - prefixDist[newStart];
        int curNodes = depth - newStart + 1;

        if (curLen > ansLen || (curLen == ansLen && curNodes < ansNodes)) {
            ansLen = curLen;
            ansNodes = curNodes;
        }

        lastSeen.put(val, depth);
        for (int[] next : graph[u]) {
            int v = next[0], w = next[1];
            if (v != parent) {
                prefixDist[depth + 1] = prefixDist[depth] + w;
                dfs(v, u, depth + 1, newStart);
            }
        }
        // 回溯恢复
        if (prevDepth == -1) lastSeen.remove(val);
        else lastSeen.put(val, prevDepth);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. DFS 维护路径前缀距离，O(1) 计算任意路径段长度
2. 有效路径起点 = max(当前起点, 重复值位置 + 1)，只增不减
3. 回溯时恢复哈希表，保证状态正确
