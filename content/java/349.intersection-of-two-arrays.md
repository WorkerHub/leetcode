## 题目描述

给定两个数组 `nums1` 和 `nums2`，返回它们的交集。输出结果中的每个元素一定是唯一的。我们可以不考虑输出结果的顺序。

**示例 1：**
```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]
```

**示例 2：**
```
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
解释：[4,9] 也是可接受的。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

## 解题思路

这道题要找两个数组的交集，且结果唯一。

**核心观察：**
- 需要去重
- 不需要保持顺序
- 只需要判断元素是否同时出现在两个数组中

**多种解法：**
1. 集合求交集：最直接
2. 哈希表：遍历一个数组，查询另一个
3. 排序 + 双指针：适合有序或可排序的情况
4. 二分查找：一个排序，另一个二分查找

## Java 代码实现

### 方法一：哈希集合（推荐）⭐

```java
import java.util.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        // 将 nums1 转为集合
        Set<Integer> set1 = new HashSet<>();
        for (int num : nums1) {
            set1.add(num);
        }

        // 遍历 nums2，查找交集
        Set<Integer> resultSet = new HashSet<>();
        for (int num : nums2) {
            if (set1.contains(num)) {
                resultSet.add(num);  // 用集合自动去重
            }
        }

        // 转换为数组
        int[] result = new int[resultSet.size()];
        int i = 0;
        for (int num : resultSet) {
            result[i++] = num;
        }
        return result;
    }
}
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(m + n)

### 方法二：简化版（利用 Stream）

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        Set<Integer> set1 = Arrays.stream(nums1)
                                  .boxed()
                                  .collect(Collectors.toSet());
        Set<Integer> set2 = Arrays.stream(nums2)
                                  .boxed()
                                  .collect(Collectors.toSet());

        // 取两个集合的交集
        set1.retainAll(set2);

        return set1.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

**时间复杂度：** O(m + n)
**空间复杂度：** O(m + n)

### 方法三：排序 + 双指针

```java
import java.util.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        // 排序
        Arrays.sort(nums1);
        Arrays.sort(nums2);

        List<Integer> result = new ArrayList<>();
        int i = 0, j = 0;

        while (i < nums1.length && j < nums2.length) {
            if (nums1[i] < nums2[j]) {
                i++;
            } else if (nums1[i] > nums2[j]) {
                j++;
            } else {
                // 找到交集元素，去重
                if (result.isEmpty() || result.get(result.size() - 1) != nums1[i]) {
                    result.add(nums1[i]);
                }
                i++;
                j++;
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

**时间复杂度：** O(m log m + n log n)
**空间复杂度：** O(1)，不计结果数组

### 方法四：二分查找

```java
import java.util.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        // 对 nums1 排序，对 nums2 中每个元素二分查找
        Arrays.sort(nums1);
        Set<Integer> resultSet = new HashSet<>();

        for (int num : nums2) {
            if (binarySearch(nums1, num)) {
                resultSet.add(num);
            }
        }

        int[] result = new int[resultSet.size()];
        int i = 0;
        for (int num : resultSet) {
            result[i++] = num;
        }
        return result;
    }

    private boolean binarySearch(int[] arr, int target) {
        int left = 0, right = arr.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr[mid] == target) return true;
            else if (arr[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```

**时间复杂度：** O(m log m + n log m)
**空间复杂度：** O(1)，不计结果数组

## 关键点总结

1. **去重**：使用 HashSet 自动去重
2. **集合运算**：利用 `retainAll()` 求交集
3. **双指针**：需要先排序
4. **时间复杂度**：哈希表 O(n)，排序 O(n log n)

## 易错点

1. **忘记去重**
   ```java
   // 错误：可能有重复
   List<Integer> result = new ArrayList<>();
   for (int num : nums2) {
       // 如果 nums2 中有重复，result 也会有重复
       if (set1.contains(num)) result.add(num);
   }

   // 正确：用 Set 存结果
   Set<Integer> resultSet = new HashSet<>();
   for (int num : nums2) {
       if (set1.contains(num)) resultSet.add(num);
   }
   ```

2. **双指针忘记去重**
   ```java
   // 错误：未去重
   if (nums1[i] == nums2[j]) {
       result.add(nums1[i]);
       i++;
       j++;
   }

   // 正确：添加前检查是否重复
   if (nums1[i] == nums2[j]) {
       if (result.isEmpty() || result.get(result.size() - 1) != nums1[i]) {
           result.add(nums1[i]);
       }
       i++;
       j++;
   }
   ```

3. **使用 List 而不是 Set 存中间结果**
   ```java
   // 不推荐：List 需要手动去重
   List<Integer> seen = new ArrayList<>(Arrays.asList(nums1 转换));
   // 查找时用 contains，O(n) 效率低

   // 推荐：HashSet O(1) 查找
   Set<Integer> set1 = new HashSet<>();
   for (int num : nums1) set1.add(num);
   ```
