## 题目描述

从二维列表 student_data 创建一个包含 student_id 和 age 两列的 DataFrame，行顺序与列表相同。

## 解题思路

本题为 Python Pandas 专项练习，使用 `pd.DataFrame(data, columns=cols)` 直接从二维列表创建 DataFrame。Java 中无 Pandas 直接等价物，通常使用第三方库（如 Tablesaw）或手动封装数据结构。

## Java 代码实现

```java
// 本题为 Pandas 专项练习，Java 中无标准库直接等价物
// 以下为使用 Java 列表模拟二维表格的示例

import java.util.*;

class Solution {
    // 将二维列表封装为 Map 列表（模拟 DataFrame 行）
    public List<Map<String, Integer>> createDataframe(List<List<Integer>> studentData) {
        List<Map<String, Integer>> result = new ArrayList<>();
        for (List<Integer> row : studentData) {
            Map<String, Integer> record = new LinkedHashMap<>();
            record.put("student_id", row.get(0));
            record.put("age", row.get(1));
            result.add(record);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. Pandas `pd.DataFrame(data, columns=cols)` 是从列表创建 DataFrame 的标准方法
2. columns 参数按顺序指定列名
3. Java 中可用 Map 列表模拟行记录结构
