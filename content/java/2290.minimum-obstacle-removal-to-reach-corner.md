## 题目描述

网格中0为空地(代价0)，1为障碍(代价1)，求从左上到右下移除最少障碍数。

## 解题思路

0-1 BFS：边权只有0和1的最短路。代价0加队首，代价1加队尾，等效于Dijkstra但O(mn)更快。

## Java 代码实现

```java
class Solution {
    public int minimumObstacles(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        Deque<int[]> dq = new ArrayDeque<>();
        dq.offerFirst(new int[]{0, 0});
        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};

        while (!dq.isEmpty()) {
            int[] cur = dq.pollFirst();
            int r = cur[0], c = cur[1];
            if (dist[r][c] < cur.length > 2 ? 0 : 0) ; // 无需额外检查，直接继续

            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int newCost = dist[r][c] + grid[nr][nc];
                if (newCost < dist[nr][nc]) {
                    dist[nr][nc] = newCost;
                    if (grid[nr][nc] == 0) dq.offerFirst(new int[]{nr, nc});
                    else dq.offerLast(new int[]{nr, nc});
                }
            }
        }
        return dist[m - 1][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. **0-1 BFS**：边权0/1的最短路最优解法
2. **代价0加队首，代价1加队尾**：保证出队顺序正确
3. **比Dijkstra更快**：无需堆操作
