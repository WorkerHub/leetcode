## 题目描述

给你数组 `rectangles`，`rectangles[i] = [li, wi]`。设 `maxLen` 为所有矩形能切割出的最大正方形边长，返回能切割出边长为 `maxLen` 正方形的矩形数目。

## 解题思路

每个矩形能切出的最大正方形边长为 `min(li, wi)`。一遍遍历维护最大边长及其出现次数。

## Java 代码实现

```java
class Solution {
    public int countGoodRectangles(int[][] rectangles) {
        int maxLen = 0, count = 0;

        for (int[] rect : rectangles) {
            int side = Math.min(rect[0], rect[1]); // 能切出的最大正方形边长
            if (side > maxLen) {
                maxLen = side; // 更新最大边长，重置计数
                count = 1;
            } else if (side == maxLen) {
                count++; // 相同最大边长，计数加一
            }
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每个矩形能切出的最大正方形边长为 `min(长, 宽)`
2. 一遍遍历同时维护最大值和计数
