## 题目描述

给定字符串 licensePlate 和字符串数组 words，找到 words 中包含 licensePlate 所有字母（忽略数字和空格，不区分大小写）的最短单词。

**示例：**
```
输入：licensePlate = "1s3 PSt", words = ["step","steps","stripe","stepple"]
输出："steps"
```

## 解题思路

统计 licensePlate 中字母频率，对每个 word 检查是否包含所有字母，取最短的。

## Java 代码实现

```java
class Solution {
    public String shortestCompletingWord(String licensePlate, String[] words) {
        // 统计 licensePlate 中的字母频率
        int[] target = new int[26];
        for (char c : licensePlate.toCharArray()) {
            if (Character.isLetter(c)) {
                target[Character.toLowerCase(c) - 'a']++;
            }
        }

        String result = null;
        for (String word : words) {
            int[] count = new int[26];
            for (char c : word.toCharArray()) {
                count[c - 'a']++;
            }
            // 检查是否包含所有目标字母
            if (matches(count, target)) {
                if (result == null || word.length() < result.length()) {
                    result = word;
                }
            }
        }
        return result;
    }

    private boolean matches(int[] count, int[] target) {
        for (int i = 0; i < 26; i++) {
            if (count[i] < target[i]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 为 words 长度，m 为单词平均长度
- **空间复杂度**：O(1)

## 关键点总结

1. **过滤非字母**：只统计字母，忽略数字和空格
2. **大小写转换**：统一转小写比较
3. **频率匹配**：word 中每个字母频率 >= target 频率
