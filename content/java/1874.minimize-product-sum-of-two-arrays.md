## 题目描述

重排两个等长数组使配对乘积之和最小。

## 解题思路

排序不等式：一个升序一个降序配对，大配小乘积和最小。

## Java 代码实现

```java
class Solution {
    public int minProductSum(int[] nums1, int[] nums2) {
        Arrays.sort(nums1);
        Arrays.sort(nums2);
        int n = nums1.length;
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums1[i] * nums2[n - 1 - i];
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序不等式**：大配小乘积和最小
2. **一升一降**：nums1升序，nums2从尾到头配对
