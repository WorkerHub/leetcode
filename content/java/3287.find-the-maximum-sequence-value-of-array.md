## 题目描述

给你整数数组 `nums` 和正整数 `k`，从数组中选长度为 `2k` 的子序列，前 k 个元素 XOR 值与后 k 个元素 XOR 值的 OR 即为序列值。返回所有可能序列值的最大值。

## 解题思路

预计算前缀 XOR 集合和后缀 XOR 集合：`leftXors[i]` = 从 `nums[0..i]` 中选 k 个的所有可能 XOR 值集合，`rightXors[i]` = 从 `nums[i..n-1]` 选 k 个的集合。枚举分割点 i，对两侧集合中的值求 OR 最大值。由于 `nums[i] < 128`，XOR 值也 < 128，集合大小有限。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findMaximumXOR(int[] nums, int k) {
        int n = nums.length;
        final int MAX_XOR = 128;

        // leftXors[i] = nums[0..i] 中选 k 个元素的所有可能 XOR 值（用 boolean 数组表示集合）
        boolean[][] leftXors = new boolean[n][MAX_XOR];
        boolean[][] dp = new boolean[k + 1][MAX_XOR];
        dp[0][0] = true;
        for (int i = 0; i < n; i++) {
            boolean[][] newDp = new boolean[k + 1][MAX_XOR];
            for (int j = 0; j <= Math.min(i, k); j++) {
                for (int xor = 0; xor < MAX_XOR; xor++) {
                    if (!dp[j][xor]) continue;
                    newDp[j][xor] = true;          // 不选 nums[i]
                    if (j < k) newDp[j + 1][xor ^ nums[i]] = true; // 选 nums[i]
                }
            }
            dp = newDp;
            leftXors[i] = dp[k].clone();
        }

        // rightXors[i] = nums[i..n-1] 中选 k 个元素的所有可能 XOR 值
        boolean[][] rightXors = new boolean[n][MAX_XOR];
        dp = new boolean[k + 1][MAX_XOR];
        dp[0][0] = true;
        for (int i = n - 1; i >= 0; i--) {
            boolean[][] newDp = new boolean[k + 1][MAX_XOR];
            for (int j = 0; j <= Math.min(n - 1 - i, k); j++) {
                for (int xor = 0; xor < MAX_XOR; xor++) {
                    if (!dp[j][xor]) continue;
                    newDp[j][xor] = true;
                    if (j < k) newDp[j + 1][xor ^ nums[i]] = true;
                }
            }
            dp = newDp;
            rightXors[i] = dp[k].clone();
        }

        int ans = 0;
        // 枚举分割点：左边 [0..i] 选 k 个，右边 [i+1..n-1] 选 k 个
        for (int i = k - 1; i < n - k; i++) {
            for (int lx = 0; lx < MAX_XOR; lx++) {
                if (!leftXors[i][lx]) continue;
                for (int rx = 0; rx < MAX_XOR; rx++) {
                    if (rightXors[i + 1][rx]) {
                        ans = Math.max(ans, lx | rx);
                    }
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × k × MAX_XOR + n × MAX_XOR²)，MAX_XOR = 128
- 空间复杂度：O(n × MAX_XOR)

## 关键点总结

1. 分别正向和反向 DP，记录每个前缀/后缀中选 k 个的所有可能 XOR 值
2. 用 boolean 数组表示 XOR 值集合，利用 nums[i] < 128 限制范围
3. 枚举分割点，暴力枚举两侧 XOR 值组合求最大 OR
