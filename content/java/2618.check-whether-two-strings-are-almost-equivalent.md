## 题目描述

给你两个长度均为 `n` 的字符串 `word1` 和 `word2`，若每种字符在两字符串中出现频次之差的绝对值均不超过 3，则称它们**几乎等价**，返回是否几乎等价。

## Java 代码实现

```java
class Solution {
    public boolean checkAlmostEquivalent(String word1, String word2) {
        int[] diff = new int[26];
        // 统计 word1 中各字符频次
        for (char c : word1.toCharArray()) diff[c - 'a']++;
        // 减去 word2 中各字符频次
        for (char c : word2.toCharArray()) diff[c - 'a']--;
        // 检查每种字符的差值绝对值是否 <= 3
        for (int d : diff) {
            if (Math.abs(d) > 3) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串
- 空间复杂度：O(1)，固定 26 个字母

## 关键点总结

1. 只需统计 26 个小写字母的频次差
2. 差值数组正负两端均需检查绝对值
