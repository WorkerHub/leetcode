## 题目描述

你的任务是计算 `a^b` 对 `1337` 取模，其中 `a` 是一个正整数，`b` 是一个非常大的正整数且会以数组形式给出。

**示例 1：**

```
输入：a = 2, b = [3]
输出：8
```

**示例 2：**

```
输入：a = 2, b = [1,0]
输出：1024
```

**示例 3：**

```
输入：a = 1, b = [4,3,3,8,5,2]
输出：1
```

**提示：**
- `1 <= a <= 2^31 - 1`
- `1 <= b.length <= 2000`
- `0 <= b[i] <= 9`
- `b` 不含前导 0

## 解题思路

这道题涉及三个核心知识点：

### 1. 快速幂算法

计算 `a^n % mod` 的高效方法：
```
a^n = (a^2)^(n/2)           如果 n 是偶数
a^n = a * (a^2)^((n-1)/2)   如果 n 是奇数
```

### 2. 模运算性质

```
(a * b) % mod = ((a % mod) * (b % mod)) % mod
(a^b) % mod = ((a % mod)^b) % mod
```

### 3. 指数分解

对于 `b = [1,2,3]`（即 123）：
```
a^123 = a^(120 + 3) = a^120 * a^3 = (a^12)^10 * a^3
```

递归公式：
```
superPow(a, [1,2,3]) = superPow(a, [1,2])^10 * a^3
```

## Java 代码实现

### 方法一：迭代处理（从左到右，推荐）

```java
class Solution {
    private static final int MOD = 1337;

    public int superPow(int a, int[] b) {
        // 从左到右迭代处理每一位
        int result = 1;
        for (int digit : b) {
            // result = result^10 * a^digit
            result = myPow(result, 10) * myPow(a, digit) % MOD;
        }
        return result;
    }

    private int myPow(int a, int k) {
        // 快速幂：计算 a^k % MOD
        int result = 1;
        a %= MOD;
        while (k > 0) {
            if ((k & 1) == 1) {
                result = result * a % MOD;
            }
            a = a * a % MOD;
            k >>= 1;
        }
        return result;
    }
}
```

### 方法二：递归分解（从右到左）

```java
class Solution {
    private static final int MOD = 1337;

    public int superPow(int a, int[] b) {
        // 先对 a 取模，避免大数运算
        a %= MOD;
        return helper(a, b, b.length - 1);
    }

    private int helper(int a, int[] b, int idx) {
        // 递归终止条件
        if (idx < 0) {
            return 1;
        }
        // 递归计算前面的部分
        int part1 = myPow(helper(a, b, idx - 1), 10);
        // 计算最后一位
        int part2 = myPow(a, b[idx]);
        return part1 * part2 % MOD;
    }

    private int myPow(int a, int k) {
        // 快速幂
        int result = 1;
        a %= MOD;
        while (k > 0) {
            if ((k & 1) == 1) {
                result = result * a % MOD;
            }
            a = a * a % MOD;
            k >>= 1;
        }
        return result;
    }
}
```

### 方法三：将数组转换为大整数（BigInteger）

```java
import java.math.BigInteger;

class Solution {
    public int superPow(int a, int[] b) {
        // 将数组转换为 BigInteger
        StringBuilder sb = new StringBuilder();
        for (int digit : b) {
            sb.append(digit);
        }
        BigInteger exponent = new BigInteger(sb.toString());
        // 使用 BigInteger 的 modPow 方法
        return BigInteger.valueOf(a).modPow(exponent, BigInteger.valueOf(1337)).intValue();
    }
}
```

## 复杂度分析

### 方法一/二：递归/迭代
- 时间复杂度：O(n × log k)
  - n 为数组长度
  - 每次快速幂需要 O(log k)，k 最大为 10
- 空间复杂度：O(n)（递归）或 O(1)（迭代）

### 方法三：BigInteger
- 时间复杂度：O(n + log b)
- 空间复杂度：O(n)

## 关键点总结

1. **快速幂**：O(log n) 计算 a^n，避免直接循环
2. **模运算性质**：
   - `(a * b) % p = ((a % p) * (b % p)) % p`
   - 每步都取模，避免溢出
3. **指数分解**：将大指数分解为小指数的组合
4. **递归公式**：`a^[1,2,3] = (a^[1,2])^10 * a^3`
5. **及时取模**：每次运算后都要取模

## 易错点

1. **整数溢出**：Java 中 `int * int` 可能溢出，中间结果需要取模
2. **递归终止**：索引为负时返回 1
3. **快速幂实现**：注意取模的位置
4. **模数固定**：本题模数固定为 1337
5. **位运算判断奇偶**：`(k & 1) == 1` 判断奇数，注意括号优先级

## 图解示例

### 示例：a = 2, b = [1,0] (即 2^10)

**方法一（迭代）：**
```
初始 result = 1

处理 b[0] = 1：
  result = myPow(1, 10) * myPow(2, 1) % 1337
         = 1 * 2 % 1337 = 2

处理 b[1] = 0：
  result = myPow(2, 10) * myPow(2, 0) % 1337
         = 1024 * 1 % 1337 = 1024
```

**快速幂计算 2^10：**
```
k = 10 (1010 in binary)
result = 1

k = 10, 偶数, a = 2^2 = 4, k = 5
k = 5,  奇数, result = 1 * 4 = 4, a = 4^2 = 16, k = 2
k = 2,  偶数, a = 16^2 = 256, k = 1
k = 1,  奇数, result = 4 * 256 = 1024, k = 0

返回 1024
```
