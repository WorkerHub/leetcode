## 题目描述

给定一个包含非负整数的数组 `nums`，返回其中可以组成三角形三条边的三元组个数。

**示例 1：**

```
输入：nums = [2,2,3,4]
输出：3
解释：有效的组合是：
2,3,4 (使用第一个 2)
2,3,4 (使用第二个 2)
2,2,3
```

**示例 2：**

```
输入：nums = [4,2,3,4]
输出：4
```

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`

## 解题思路

三角形成立条件：三边 a、b、c（a ≤ b ≤ c）满足 `a + b > c`。

**核心思路：排序 + 双指针**

1. **排序**：将数组排序后，假设 `nums[i] ≤ nums[j] ≤ nums[k]`
2. **简化条件**：只需判断 `nums[i] + nums[j] > nums[k]`
3. **双指针**：固定最大边 k，用双指针找满足条件的 i, j

## Java 代码实现

### 方法一：排序 + 双指针（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    public int triangleNumber(int[] nums) {
        // 排序 + 双指针
        Arrays.sort(nums);
        int count = 0;
        int n = nums.length;

        // 固定最大边（从后往前）
        for (int k = n - 1; k >= 2; k--) {
            int left = 0, right = k - 1;

            // 双指针找两条较小的边
            while (left < right) {
                if (nums[left] + nums[right] > nums[k]) {
                    // [left, right-1] 都可以与 right, k 组成三角形
                    count += right - left;
                    right--;
                } else {
                    // 和太小，移动左指针
                    left++;
                }
            }
        }

        return count;
    }
}
```

### 方法二：暴力枚举

```java
import java.util.Arrays;

class Solution {
    public int triangleNumber(int[] nums) {
        // 三重循环暴力枚举
        Arrays.sort(nums);
        int count = 0;
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                for (int k = j + 1; k < n; k++) {
                    // 数组已排序，只需判断最小两边之和大于最大边
                    if (nums[i] + nums[j] > nums[k]) {
                        count++;
                    }
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

### 方法一（双指针）
- **时间复杂度**：O(n²)，外层循环 O(n)，双指针 O(n)
- **空间复杂度**：O(log n)，排序使用的栈空间

### 方法二（暴力）
- **时间复杂度**：O(n³)
- **空间复杂度**：O(log n)

## 关键点总结

1. **排序优化**：排序后只需判断最小两边之和
2. **双指针技巧**：固定最大边，双指针找两小边
3. **计数技巧**：当 `nums[left] + nums[right] > nums[k]` 时，`[left, right-1]` 都满足
4. **去除无效值**：数组中的 0 不影响结果（0 不能组成三角形）
