## 题目描述

一个程序最初打算将一个正整数数组保存到一个字符串中，每个整数之间用逗号分隔，但忘记添加逗号了。

给你一个数字字符串 `s` 和一个整数 `k`，请你返回**所有**可能的将字符串 `s` 恢复成一个数组的方案数，满足：

- 数组中每个元素的值在 `[1, k]` 范围内
- 数组中每个元素都不含前导零（即数字不能以 '0' 开头，除非数字本身就是 0，但本题要求值在 [1,k] 内，所以 0 不合法）

答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：s = "1000", k = 10000
输出：1
解释：唯一的方案是 [1000]
```

**示例 2：**

```
输入：s = "1000", k = 10
输出：0
解释：无法将 "1000" 恢复为元素 <= 10 的数组（1000 > 10，而 [1, 0, 0, 0] 和 [10, 00] 含有前导零或 0）
```

**示例 3：**

```
输入：s = "1317", k = 2000
输出：8
解释：可能的方案有 [1317],[131,7],[13,17],[13,1,7],[1,317],[1,31,7],[1,3,17],[1,3,1,7]
```

**提示：**

- `1 <= k <= 10^9`
- `1 <= s.length <= 10^5`

## 解题思路

### 动态规划

定义 `dp[i]` 表示将前 `i` 个字符（`s[0..i-1]`）完整分割为合法数组的方案数。

**初始状态：** `dp[0] = 1`（空字符串对应空数组，1 种方案）

**状态转移：** 对于位置 `i`（1-indexed），枚举最后一个数字是 `s[j..i-1]`（即从位置 `j` 到 `i-1`）：
- 若 `s[j] == '0'`，跳过（前导零不合法）
- 若 `int(s[j..i-1]) > k`，跳过（超出范围），且可以 break
- 若 `int(s[j..i-1]) >= 1`，则 `dp[i] += dp[j]`

**优化剪枝：**

1. `k` 最多 10 位，所以最后一个数字的长度最多为 `len(str(k))`，无需从 0 枚举到 i
2. 一旦 `int(s[j..i-1]) > k`，可以提前 break（因为继续往左扩展只会更大）

## Java 代码实现

### 方法一：DP（推荐）

```java
class Solution {
    public int numberOfArrays(String s, int k) {
        int MOD = 1_000_000_007;
        int n = s.length();
        // dp[i]：将 s[0..i-1] 分割为合法数组的方案数
        long[] dp = new long[n + 1];
        dp[0] = 1;  // 空字符串，1 种方案

        // k 的位数，决定最后一个数字的最大长度
        int maxDigits = String.valueOf(k).length();

        for (int i = 1; i <= n; i++) {
            // 从 i 向左枚举，最后一个数字的长度从 1 到 maxDigits
            for (int length = 1; length <= Math.min(maxDigits, i); length++) {
                int j = i - length;  // 最后一个数字的起始位置
                // 检查前导零（数字不能以 '0' 开头）
                if (s.charAt(j) == '0') {
                    continue;  // 这种长度对应的数字有前导零，不合法
                }

                // 将字符串转换为整数（长度不超过10，不会溢出long）
                long num = Long.parseLong(s.substring(j, i));

                // 如果超出 k，更长的数字更大，直接 break
                if (num > k) {
                    break;
                }

                // num 在 [1, k] 内，累加方案数
                dp[i] = (dp[i] + dp[j]) % MOD;
            }
        }

        return (int) dp[n];
    }
}
```

### 方法二：记忆化递归（自顶向下）

```java
import java.util.Arrays;

class Solution {
    private long[] memo;
    private String s;
    private int k;
    private int n;
    private int maxDigits;
    private static final int MOD = 1_000_000_007;

    public int numberOfArrays(String s, int k) {
        this.s = s;
        this.k = k;
        this.n = s.length();
        this.maxDigits = String.valueOf(k).length();
        this.memo = new long[n];
        Arrays.fill(memo, -1);
        return (int) dp(0);
    }

    // 返回将 s[i..n-1] 分割为合法数组的方案数
    private long dp(int i) {
        if (i == n) return 1;  // 已到达字符串末尾，找到一种方案
        if (memo[i] != -1) return memo[i];

        long result = 0;
        // 枚举从位置 i 开始的数字，长度为 1 到 maxDigits
        for (int length = 1; length <= Math.min(maxDigits, n - i); length++) {
            int j = i + length;
            // 前导零检查
            if (s.charAt(i) == '0') {
                continue;
            }

            long num = Long.parseLong(s.substring(i, j));
            if (num > k) break;  // 更长只会更大

            result = (result + dp(j)) % MOD;
        }

        memo[i] = result;
        return result;
    }
}
```

## 复杂度分析

设 `n = len(s)`，`D = len(str(k))`（k 的位数，最多 10）。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n * D) | O(n) |
| 记忆化递归 | O(n * D) | O(n) |

## 图解示例

以 `s = "1317", k = 2000` 为例：

```
dp[0] = 1（空字符串）
dp[1]：s[0:1]="1"，1 in [1,2000]，dp[1] += dp[0] = 1
dp[2]：s[1:2]="3"，dp[2]+=dp[1]=1；s[0:2]="13"，dp[2]+=dp[0]=1；dp[2]=2
dp[3]：s[2:3]="1"，+=dp[2]=2；s[1:3]="31"，+=dp[1]=1；s[0:3]="131"，+=dp[0]=1；dp[3]=4
dp[4]：s[3:4]="7"，+=dp[3]=4；s[2:4]="17"，+=dp[2]=2；s[1:4]="317"，+=dp[1]=1；s[0:4]="1317"，+=dp[0]=1；dp[4]=8
```

答案 `dp[4] = 8` ✓

## 关键点总结

1. `dp[i]` 定义为前 `i` 个字符的分割方案数，`dp[0] = 1`
2. 枚举最后一个数字时，最多往前看 `len(str(k))` 位
3. 遇到前导零直接 `continue`
4. 遇到数值超过 k 直接 `break`（更长的数字一定更大）
5. 每步取模防溢出，用 `long` 避免中间计算溢出

## 易错点

1. `break` 和 `continue` 的使用：超出 k 用 `break`，前导零用 `continue`
2. `dp[0] = 1` 的意义：空字符串对应 1 种方案（空数组）
3. Java 中解析子字符串为 long 时用 `Long.parseLong`，防止大数溢出 int
