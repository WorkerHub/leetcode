## 题目描述

与 3403 相同，但 `word` 长度可达 5×10^5，需要 O(n) 算法找字典序最大的分段字符串。

## Java 代码实现

```java
class Solution {
    public String answerString(String word, int numFriends) {
        int n = word.length();
        if (numFriends == 1) return word;

        int maxLen = n - numFriends + 1;

        // 双指针找字典序最大的起始位置
        int best = 0, j = 1;
        while (j < n) {
            int k = 0;
            while (j + k < n && word.charAt(best + k) == word.charAt(j + k)) k++;
            if (j + k < n && word.charAt(j + k) > word.charAt(best + k)) {
                int oldBest = best;
                best = j;
                j = Math.max(j + 1, oldBest + k + 1);
            } else {
                j += k + 1;
            }
            if (best >= j) j = best + 1;
        }

        return word.substring(best, Math.min(best + maxLen, n));
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，双指针线性扫描
- 空间复杂度：O(1)

## 关键点总结

1. 最大子串长度为 `n - numFriends + 1`。
2. 双指针在 O(n) 时间内找字典序最大的起始位置。
3. 只需考虑以最大字符开头的位置，可进一步剪枝。
