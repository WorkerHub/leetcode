## 题目描述

按以下规则压缩字符串 `word`：每次取当前字符及其最多 9 个连续重复，以「数字+字符」形式追加到结果，返回压缩后的字符串。

## 解题思路

贪心遍历：统计每段连续相同字符的长度，每次最多取 9 个，超过则分多组输出。

## Java 代码实现

```java
class Solution {
    public String compressedString(String word) {
        StringBuilder sb = new StringBuilder();
        int i = 0, n = word.length();
        while (i < n) {
            char c = word.charAt(i);
            int cnt = 0;
            // 最多连续取 9 个相同字符
            while (i < n && word.charAt(i) == c && cnt < 9) {
                cnt++;
                i++;
            }
            sb.append(cnt).append(c);
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每段相同字符最多取 9 个，超过则分多组（如 14 个 'a' 输出 "9a5a"）
2. 每组格式固定为「数字+字符」
