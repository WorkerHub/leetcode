## 题目描述

对字符串 s 进行多次查询 [left, right, k]：子串 s[left..right] 重新排列后最多替换 k 个字符，能否变成回文。

**示例：**
```
输入: s = "abcda", queries = [[0,3,1],[0,4,1]]
输出: [false, true]
```

## 解题思路

回文要求最多 1 个字符出现奇数次。统计子串中奇数次字符个数 odd，需替换 odd/2 次。用前缀异或数组 O(1) 查询区间奇偶性。

## Java 代码实现

```java
class Solution {
    public List<Boolean> canMakePaliQueries(String s, int[][] queries) {
        int n = s.length();
        // 前缀异或：第 i 位表示字符 'a'+i 出现奇数次
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] ^ (1 << (s.charAt(i) - 'a'));
        }

        List<Boolean> result = new ArrayList<>();
        for (int[] q : queries) {
            int left = q[0], right = q[1], k = q[2];
            // 区间内奇数次字符个数
            int oddCount = Integer.bitCount(prefix[right + 1] ^ prefix[left]);
            // 需替换 oddCount/2 对
            result.add(oddCount / 2 <= k);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)，预处理 O(n)，每次查询 O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀异或**：XOR 记录字符奇偶性
2. **区间查询**：prefix[right+1] ^ prefix[left] 得到区间状态
3. **bitCount**：统计 1 的个数即奇数次字符数
4. **替换公式**：需替换 oddCount / 2 次
