## 题目描述

给定活动数组 events[i] = [start, end, value]，最多参加 2 个不重叠活动（end1 < start2），返回可获得的最大价值之和。

## 解题思路

按结束时间排序，维护前缀最大价值数组 `best[i]`。对每个活动 i，用二分查找在结束时间 < start_i 的活动中找最大价值，与当前活动价值相加取最大值。

## Java 代码实现

### 方法一：排序 + 二分查找（推荐）

```java
import java.util.Arrays;

class Solution {
    public int maxTwoEvents(int[][] events) {
        Arrays.sort(events, (a, b) -> a[1] - b[1]); // 按结束时间排序
        int n = events.length;
        int[] ends = new int[n];
        int[] best = new int[n]; // best[i] = events[0..i] 中最大价值
        for (int i = 0; i < n; i++) {
            ends[i] = events[i][1];
            best[i] = Math.max(i > 0 ? best[i - 1] : 0, events[i][2]);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            int start = events[i][0], val = events[i][2];
            ans = Math.max(ans, val); // 只参加一个
            // 二分查找结束时间 < start 的最后一个活动
            int lo = 0, hi = i - 1, pos = -1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (ends[mid] < start) { pos = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            if (pos >= 0) ans = Math.max(ans, best[pos] + val);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 不重叠条件：end1 < start2（严格小于）
2. best 数组维护前缀最大价值，二分查找最近不冲突活动
3. 枚举每个活动作为第二个参加的活动
