## 题目描述

求字符串每个后缀与原串的最长公共前缀长度之和（即Z函数所有值的和）。

## 解题思路

Z函数：Z[i]表示s[i..]与s的最长公共前缀长度。维护Z-box区间[l,r]加速计算，Z[0]=n，答案为sum(Z)。

## Java 代码实现

```java
class Solution {
    public long sumScores(String s) {
        int n = s.length();
        int[] z = new int[n];
        z[0] = n;
        int l = 0, r = 0;
        
        for (int i = 1; i < n; i++) {
            if (i < r) {
                z[i] = Math.min(r - i, z[i - l]);
            }
            // 扩展匹配
            while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) {
                z[i]++;
            }
            // 更新Z-box
            if (i + z[i] > r) {
                l = i;
                r = i + z[i];
            }
        }
        
        long ans = 0;
        for (int v : z) ans += v;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **Z函数定义**：Z[i]=s[i..]与s的最长公共前缀长度
2. **Z-box加速**：维护[l,r]区间避免重复比较
3. **Z[0]=n**：整个字符串自身匹配
