## 题目描述

给定两个等长字符串 s 和 t，将 s[i] 变为 t[i] 的开销为 |s[i] - t[i]|。在总开销不超过 maxCost 的前提下，返回可以转换的最大长度子字符串。

**示例：**
```
输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3（"abc" → "bcd"，开销 1+1+1=3）
```

## 解题思路

先计算每个位置的转换开销数组，问题转化为：找到最长的子数组使得元素和不超过 maxCost。使用滑动窗口解决。

## Java 代码实现

```java
class Solution {
    public int equalSubstring(String s, String t, int maxCost) {
        int n = s.length();
        int[] cost = new int[n];
        for (int i = 0; i < n; i++) {
            cost[i] = Math.abs(s.charAt(i) - t.charAt(i));
        }
        
        // 滑动窗口
        int left = 0, sum = 0, maxLen = 0;
        for (int right = 0; right < n; right++) {
            sum += cost[right];
            // 窗口内开销超限，收缩左边界
            while (sum > maxCost) {
                sum -= cost[left++];
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)（开销数组）

## 关键点总结

1. **问题转化**：转换开销数组 → 最长子数组和 ≤ maxCost
2. **滑动窗口**：右指针扩展，左指针在超限时收缩
3. **Math.abs**：计算字符间的 ASCII 差值
