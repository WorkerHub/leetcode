## 题目描述

有 `n` 名表演者、`x` 个舞台，每名表演者分配到某个舞台，舞台得分为 `min(人数, y)`，返回总分恰好为每个可能值 `s`（`1 <= s <= min(n,x)*y`）的方案数数组（对 `10^9+7` 取模）。

## 解题思路

三维 DP：枚举使用 `k` 个有标号舞台，`dp[p][s]` 表示已分配 `p` 人到已处理舞台、总分 `s` 的方案数。每新增一个舞台，枚举放 `c` 人（c >= 1），乘以组合数 `C(剩余人数, c)`。最终 `dp[n][s]` 乘以 `C(x, k)` 累加到答案。预处理帕斯卡三角形组合数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] numberOfWays(int n, int x, int y) {
        final int MOD = 1_000_000_007;
        // 预处理组合数 C[i][j]
        int[][] C = new int[n + 1][n + 1];
        C[0][0] = 1;
        for (int i = 1; i <= n; i++) {
            C[i][0] = 1;
            for (int j = 1; j <= i; j++)
                C[i][j] = (int) ((C[i-1][j-1] + (long) C[i-1][j]) % MOD);
        }

        int maxK = Math.min(n, x);
        int maxScore = maxK * y;
        int[] result = new int[maxScore + 1];

        // dp[p][s] = 已用 p 人到当前舞台集合、总分 s 的方案数
        int[][] prev = new int[n + 1][maxScore + 1];
        prev[0][0] = 1;

        // C(x, k) 用于选 k 个舞台，C_x[k] 滚动计算
        long cxk = 1; // C(x, 0)
        for (int k = 1; k <= maxK; k++) {
            cxk = cxk % MOD * ((x - k + 1) % MOD) % MOD;
            // 求逆元... 改用直接预处理 C(x, k)
            // 重新用帕斯卡处理（x <= 300，可以直接算）
            break;
        }
        // 预处理 C(x, k)，x 可达 300
        long[] Cxk = new long[maxK + 1];
        Cxk[0] = 1;
        for (int k = 1; k <= maxK; k++)
            Cxk[k] = Cxk[k-1] % MOD * ((x - k + 1) % MOD) % MOD * modInv(k, MOD) % MOD;

        prev = new int[n + 1][maxScore + 1];
        prev[0][0] = 1;

        for (int k = 1; k <= maxK; k++) {
            int[][] cur = new int[n + 1][maxScore + 1];
            for (int p = k - 1; p <= n; p++) {
                for (int s = 0; s <= maxScore; s++) {
                    if (prev[p][s] == 0) continue;
                    // 第 k 个舞台放 c 名表演者（c >= 1）
                    for (int c = 1; p + c <= n; c++) {
                        int ns = s + Math.min(c, y);
                        if (ns > maxScore) break;
                        cur[p + c][ns] = (int) ((cur[p + c][ns] + (long) prev[p][s] * C[n - p][c]) % MOD);
                    }
                }
            }
            // 恰好用完 n 人的方案数贡献到结果
            for (int s = 1; s <= maxScore; s++)
                result[s] = (int) ((result[s] + Cxk[k] * cur[n][s]) % MOD);
            prev = cur;
        }

        // 返回 s=1 到 maxScore 的部分
        return Arrays.copyOfRange(result, 1, maxScore + 1);
    }

    private long modInv(long a, long mod) {
        return modPow(a, mod - 2, mod);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(min(n,x) * n^2 * min(n,x) * y)，三维 DP
- 空间复杂度：O(n * min(n,x) * y)

## 关键点总结

1. 三维 DP：枚举舞台数 k，滚动 dp[performers][score] 逐舞台转移
2. 每个舞台放 c 人乘以组合数 C(剩余人数, c)，最终乘 C(x, k) 选舞台
3. 得分贡献为 min(c, y)，超过 y 的人数不增加得分
