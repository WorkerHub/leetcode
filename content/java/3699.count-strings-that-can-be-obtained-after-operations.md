## 题目描述

给你一个二进制字符串 `s` 和整数 `k`，每次操作可以翻转 s 中的一位，最多操作 k 次。返回所有不同的可能结果字符串数量。

## 解题思路

与 s 的汉明距离 <= k 的字符串数 = `sum C(n, j) for j=0..min(k,n)`。每种距离 j 对应 `C(n, j)` 种字符串，不同翻转组合得到不同结果。

## Java 代码实现

```java
class Solution {
    public long countStrings(String s, int k) {
        int n = s.length();
        long total = 0;
        long comb = 1; // C(n, 0) = 1
        for (int j = 0; j <= Math.min(k, n); j++) {
            total += comb;
            // 更新组合数 C(n, j+1) = C(n, j) * (n-j) / (j+1)
            if (j < n) comb = comb * (n - j) / (j + 1);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k)
- 空间复杂度：O(1)

## 关键点总结

1. 距离 s 汉明距离 <= k 的字符串数 = sum C(n, j)，j=0..min(k,n)
2. 不同翻转位置组合得到不同字符串
3. k 超过 n 时只需取到 n
