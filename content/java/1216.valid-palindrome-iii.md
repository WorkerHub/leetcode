## 题目描述

给定字符串 s 和整数 k，判断是否可以通过删除最多 k 个字符将 s 变为回文串（即 s 是否为 k 回文串）。

**示例：**
```
输入：s = "abcdeca", k = 2
输出：true（删除 "b" 和 "e" 得到 "acdca"）
```

## 解题思路

最少需要删除的字符数 = 字符串长度 - 最长回文子序列长度。如果该值 ≤ k 则返回 true。用区间 DP 求最长回文子序列。

## Java 代码实现

```java
class Solution {
    public boolean isValidPalindrome(String s, int k) {
        int n = s.length();
        // dp[i][j] 表示 s[i..j] 的最长回文子序列长度
        int[][] dp = new int[n][n];
        
        // 单个字符回文长度为 1
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }
        
        // 按子串长度递增填表
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        
        // 最少删除数 = 总长度 - 最长回文子序列长度
        return n - dp[0][n - 1] <= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **转化问题**：k 回文 ⇔ 最少删除数 ≤ k ⇔ 最长回文子序列 ≥ n - k
2. **区间 DP**：dp[i][j] 表示子串 s[i..j] 的最长回文子序列
3. **转移方程**：两端相等则 +2，否则取去掉一端的最大值
4. **也可用 LCS**：s 与 reverse(s) 的 LCS 即为最长回文子序列
