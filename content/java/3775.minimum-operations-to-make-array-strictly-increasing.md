## 题目描述

给定整数数组 `nums`，每次操作可以将任意元素增加 1，求使数组变为严格递增的最少操作次数。

## 解题思路

贪心从左到右：维护上一元素调整后的目标值 `prev`，每个 `nums[i]` 的目标值至少为 `max(nums[i], prev + 1)`，累加差值即为操作次数。

## Java 代码实现

```java
class Solution {
    public long minOperations(int[] nums) {
        long ops = 0;
        long prev = nums[0]; // 上一元素调整后的值

        for (int i = 1; i < nums.length; i++) {
            long target = Math.max(nums[i], prev + 1);
            ops += target - nums[i];
            prev = target;
        }

        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只能增加元素，贪心地从左到右保持最小必要值
2. 每个元素目标值 = `max(原值, prev + 1)`
3. 操作次数 = 目标值 - 原始值（注意用 `long` 防溢出）
