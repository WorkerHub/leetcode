## 题目描述

两个整数之间的汉明距离指的是这两个数字对应二进制位不同的位置的数目。

给你两个整数 `x` 和 `y`，计算并返回它们之间的汉明距离。

**示例 1：**
```
输入：x = 1, y = 4
输出：2
解释：
1   (0 0 0 1)
4   (0 1 0 0)
       ↑   ↑
上面的箭头指出了对应二进制位不同的位置。
```

**示例 2：**
```
输入：x = 3, y = 1
输出：1
```

**提示：**
- `0 <= x, y <= 2^31 - 1`

## 解题思路

汉明距离的核心思想是统计两个数二进制表示中不同位的个数。

**核心观察：**
1. 两个数异或（XOR）运算后，结果中为 1 的位就是不同的位
2. 问题转化为统计异或结果中 1 的个数

**算法流程：**
1. 对 x 和 y 进行异或运算：`xor_result = x ^ y`
2. 统计 xor_result 中 1 的个数

**为什么异或可以找出不同的位？**
- `0 ^ 0 = 0`（相同）
- `1 ^ 1 = 0`（相同）
- `0 ^ 1 = 1`（不同）
- `1 ^ 0 = 1`（不同）

## Java 代码实现

### 方法一：Integer.bitCount() 内置方法（推荐）⭐

```java
class Solution {
    public int hammingDistance(int x, int y) {
        // 异或运算找出不同的位
        int xorResult = x ^ y;

        // 使用 Integer.bitCount 统计二进制中 1 的个数
        return Integer.bitCount(xorResult);
    }
}
```

**优点：** 代码简洁，底层使用硬件指令优化（popcount）

### 方法二：Brian Kernighan 算法

```java
class Solution {
    public int hammingDistance(int x, int y) {
        int xorResult = x ^ y;
        int count = 0;

        // Brian Kernighan 算法：每次消除最右边的 1
        while (xorResult != 0) {
            xorResult &= xorResult - 1;  // 清除最右边的 1
            count++;
        }

        return count;
    }
}
```

**核心技巧：** `n & (n - 1)` 可以消除 n 最右边的 1
- 例如：`n = 12 (1100)`，`n - 1 = 11 (1011)`，`n & (n - 1) = 8 (1000)`

### 方法三：逐位比较

```java
class Solution {
    public int hammingDistance(int x, int y) {
        int count = 0;

        // 逐位比较，直到两个数都为 0
        while (x != 0 || y != 0) {
            // 比较最低位
            if ((x & 1) != (y & 1)) {
                count++;
            }
            // 无符号右移一位，避免符号位问题
            x >>>= 1;
            y >>>= 1;
        }

        return count;
    }
}
```

### 方法四：直接对异或结果使用 Integer.bitCount()（最简洁）

```java
class Solution {
    public int hammingDistance(int x, int y) {
        // 一行搞定：异或后统计 1 的个数
        return Integer.bitCount(x ^ y);
    }
}
```

**最简洁：** Java 推荐使用 `Integer.bitCount()`，性能最佳

## 复杂度分析

**方法一、四（Integer.bitCount()）：**
- 时间复杂度：O(1)，底层硬件优化
- 空间复杂度：O(1)

**方法二（Brian Kernighan）：**
- 时间复杂度：O(k)，k 是二进制中 1 的个数（最优）
- 空间复杂度：O(1)

**方法三（逐位比较）：**
- 时间复杂度：O(log n)，n 是较大的数
- 空间复杂度：O(1)

## 关键点总结

1. **异或运算是核心：** `x ^ y` 直接标记出不同的位
2. **多种统计方法：**
   - Java 特色：`Integer.bitCount()`
   - 算法优化：Brian Kernighan 算法
3. **位运算技巧：** `n & (n - 1)` 消除最右边的 1
4. **时间优化：** Brian Kernighan 算法复杂度与 1 的个数相关，而非总位数
5. **无符号右移：** Java 中使用 `>>>` 避免符号位扩展问题

## 易错点

1. **忘记异或运算：** 直接统计两个数各自的 1 的个数
   ```java
   // 错误
   Integer.bitCount(x) + Integer.bitCount(y)

   // 正确
   Integer.bitCount(x ^ y)
   ```

2. **位运算优先级：** 比较运算符优先级高于位运算
   ```java
   // 错误（需要加括号）
   if (x & 1 != y & 1)  // Java 中 != 优先级高于 &，结果不符合预期

   // 正确
   if ((x & 1) != (y & 1))
   ```

3. **右移方向：** Java 中 `>>` 是有符号右移，`>>>` 是无符号右移
   ```java
   // 对于逐位比较，应使用无符号右移
   x >>>= 1;
   y >>>= 1;
   ```

4. **边界情况：** x 或 y 为 0 时也要正确处理
   ```java
   // x = 0, y = 0 时，汉明距离为 0
   // x = 0, y = 5 时，汉明距离等于 5 的二进制中 1 的个数
   ```
