## 题目描述

给你一个 `n x n` 的矩阵 `grid`，`grid[i][j]` 表示骑士访问该格子的顺序（0 到 n^2-1 各出现一次）。判断骑士是否可以按照顺序通过合法的马步依次访问所有格子。

## 解题思路

建立编号到位置的映射，然后逐步检查相邻编号之间是否满足马步条件：行差和列差的绝对值分别为 1 和 2（或 2 和 1）。骑士必须从位置 `(0,0)` 出发。

## Java 代码实现

```java
class Solution {
    public boolean checkValidGrid(int[][] grid) {
        int n = grid.length;
        if (grid[0][0] != 0) return false;

        // 建立编号到位置的映射
        int[][] pos = new int[n * n][2];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                pos[grid[i][j]][0] = i;
                pos[grid[i][j]][1] = j;
            }
        }

        // 检查相邻编号之间是否是合法马步
        for (int v = 0; v < n * n - 1; v++) {
            int dr = Math.abs(pos[v+1][0] - pos[v][0]);
            int dc = Math.abs(pos[v+1][1] - pos[v][1]);
            if (!((dr == 1 && dc == 2) || (dr == 2 && dc == 1))) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 先建立编号到位置的映射
2. 逐步检查相邻编号间是否是合法马步
3. 马步条件：`(|dr|, |dc|) ∈ {(1,2), (2,1)}`
