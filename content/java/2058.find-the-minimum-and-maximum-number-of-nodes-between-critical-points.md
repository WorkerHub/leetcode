## 题目描述

链表中临界点为局部极大值或极小值节点（比两侧邻居都大或都小）。返回 [最小相邻临界点距离, 第一到最后临界点距离]，临界点少于 2 个时返回 [-1, -1]。

## 解题思路

遍历链表记录所有临界点下标，最大距离 = 最后 - 第一，最小距离 = 相邻临界点差的最小值。

## Java 代码实现

### 方法一：单次遍历（推荐）

```java
class Solution {
    public int[] nodesBetweenCriticalPoints(ListNode head) {
        int first = -1, last = -1, prev = -1;
        int minDist = Integer.MAX_VALUE;
        int idx = 1;
        ListNode a = head, b = head.next;
        while (b != null && b.next != null) {
            ListNode c = b.next;
            if ((b.val > a.val && b.val > c.val) || (b.val < a.val && b.val < c.val)) {
                int pos = idx + 1;
                if (first == -1) first = pos;
                if (prev != -1) minDist = Math.min(minDist, pos - prev);
                prev = pos;
                last = pos;
            }
            a = b; b = c; idx++;
        }
        if (first == last) return new int[]{-1, -1};
        return new int[]{minDist, last - first};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 临界点：比两侧都大或都小（局部极值）
2. 最大距离 = 最后临界点 - 第一临界点
3. 少于 2 个临界点返回 [-1, -1]
