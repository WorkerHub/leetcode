## 题目描述

操作1花费cost1给一个元素+1，操作2花费cost2给两个不同元素各+1，求使所有元素相等的最小花费。

## 解题思路

枚举目标值(max到max+n)。对每个目标值，计算总差值和最大差值：若2*cost2>=cost1全用操作1；否则贪心配对——若max_diff<=total/2可全配对，否则剩余部分用操作1。

## Java 代码实现

```java
class Solution {
    public int minCostToEqualizeArray(int[] nums, int cost1, int cost2) {
        long MOD = 1_000_000_007;
        int n = nums.length;
        int maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);

        if (n <= 2 || cost2 >= 2 * cost1) {
            long total = 0;
            for (int v : nums) total += maxVal - v;
            return (int)(total % MOD * (cost1 % MOD) % MOD);
        }

        long ans = Long.MAX_VALUE;
        for (int target = maxVal; target <= maxVal + n; target++) {
            long total = 0, mx = 0;
            for (int v : nums) {
                long d = target - v;
                total += d;
                mx = Math.max(mx, d);
            }
            long rest = total - mx;
            long cost;
            if (mx <= rest) {
                // 可以全部配对
                cost = (total / 2) * cost2 + (total % 2) * cost1;
            } else {
                // 最大diff配对rest次，剩余单独用操作1
                cost = rest * cost2 + (mx - rest) * cost1;
            }
            ans = Math.min(ans, cost);
        }
        return (int)(ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **2*cost2>=cost1时全用操作1**
2. **贪心配对**：最大diff优先与其他配对
3. **枚举目标值max~max+n**：有时增大目标值总花费更少
