## 题目描述

初始余额 100，购买金额按照"5 向上"规则取整到最近的 10 的倍数后扣除，返回剩余余额。

## Java 代码实现

```java
class Solution {
    public int accountBalanceAfterPurchase(int purchaseAmount) {
        // (n + 5) / 10 * 10 实现"5 向上"的四舍五入到 10 的倍数
        int rounded = (purchaseAmount + 5) / 10 * 10;
        return 100 - rounded;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `(n + 5) / 10 * 10` 实现"5 向上舍入"到 10 的倍数
2. 个位在 0-4 向下取整，5-9 向上取整
