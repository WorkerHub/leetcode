## 题目描述

给你 `m×n` 矩阵 `grid`，每次删除每行的最大值，将本轮所有删除值中的最大值加入分数，重复直到矩阵为空，返回最终分数。

## 解题思路

每行排序后，每轮相当于取各行的第 `j` 列（从右到左），取该列所有行中的最大值累加即为答案。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int deleteGreatestValue(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 对每行排序
        for (int[] row : grid) Arrays.sort(row);

        int ans = 0;
        // 从右到左，每轮取各行当前最大列的最大值
        for (int j = n - 1; j >= 0; j--) {
            int colMax = 0;
            for (int i = 0; i < m; i++) {
                colMax = Math.max(colMax, grid[i][j]);
            }
            ans += colMax;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n × log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每行排序后，每轮删除等价于从右到左逐列处理
2. 每轮分数 = 该列各行的最大值
3. 等价于：对排序后矩阵每一列求最大值并累加
