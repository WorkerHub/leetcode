## 题目描述

按 Z 字形遍历 m×n 矩阵（偶数行从左到右，奇数行从右到左），每隔一个元素跳过，返回取到的元素列表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> zigzagTraversal(int[][] grid) {
        List<Integer> result = new ArrayList<>();
        boolean take = true; // 控制是否取当前元素

        for (int row = 0; row < grid.length; row++) {
            if (row % 2 == 0) {
                // 偶数行：从左到右
                for (int col = 0; col < grid[row].length; col++) {
                    if (take) result.add(grid[row][col]);
                    take = !take;
                }
            } else {
                // 奇数行：从右到左
                for (int col = grid[row].length - 1; col >= 0; col--) {
                    if (take) result.add(grid[row][col]);
                    take = !take;
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. Z 字形：偶数行从左到右，奇数行从右到左。
2. 取全局遍历序列中下标为偶数的元素（用 `take` 变量交替标记）。
3. 当 n 为奇数时，一行结束后 `take` 状态会自然延续到下一行。
