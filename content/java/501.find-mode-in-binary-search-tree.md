## 题目描述

给你一个含重复值的二叉搜索树（BST）的根节点 `root`，找出并返回 BST 中的所有众数（即，出现频率最高的元素）。

如果树中有不止一个众数，可以按任意顺序返回。

假定 BST 满足如下定义：
- 节点左子树中所含节点的值小于等于当前节点的值
- 节点右子树中所含节点的值大于等于当前节点的值
- 左子树和右子树都是二叉搜索树

**示例 1：**
```
输入：root = [1,null,2,2]
输出：[2]
```

**示例 2：**
```
输入：root = [0]
输出：[0]
```

**提示：**
- 树中节点的数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

**进阶：** 你可以不使用额外空间吗？（假设由递归产生的隐式调用栈的开销不被计算在内）

## 解题思路

这道题要求找出二叉搜索树中的众数。关键是利用 BST 的性质：中序遍历是有序的。

### 核心思想：
1. **利用 BST 性质**：中序遍历 BST 得到的是升序序列
2. **统计频率**：在有序序列中，相同的值必定连续出现
3. **找出众数**：记录最大频率，收集所有达到最大频率的值

### 算法流程：
1. 中序遍历树
2. 在遍历过程中统计每个值的出现次数
3. 维护当前最大频率和对应的众数列表
4. 当遇到更高频率时，更新众数列表；当频率相同时，添加到列表

## Java 代码实现

### 方法一：使用哈希表（最直观）

```java
import java.util.*;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public int[] findMode(TreeNode root) {
        // 使用哈希表统计每个值的频率
        Map<Integer, Integer> count = new HashMap<>();
        dfs(root, count);

        // 找出最大频率
        int maxCount = 0;
        for (int cnt : count.values()) {
            maxCount = Math.max(maxCount, cnt);
        }

        // 返回所有频率等于最大频率的值
        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == maxCount) {
                result.add(entry.getKey());
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private void dfs(TreeNode node, Map<Integer, Integer> count) {
        if (node == null) return;
        count.put(node.val, count.getOrDefault(node.val, 0) + 1);
        dfs(node.left, count);
        dfs(node.right, count);
    }
}
```

### 方法二：中序遍历 + O(1)空间（进阶解法）⭐

```java
class Solution {
    private Integer prev = null;  // 前一个节点的值
    private int count = 0;        // 当前值的出现次数
    private int maxCount = 0;     // 最大出现次数
    private List<Integer> result = new ArrayList<>();

    public int[] findMode(TreeNode root) {
        inorder(root);
        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private void inorder(TreeNode node) {
        if (node == null) return;

        // 遍历左子树
        inorder(node.left);

        // 处理当前节点
        // 如果当前值等于前一个值，计数加1
        if (prev != null && node.val == prev) {
            count++;
        } else {
            // 遇到新值，重置计数
            count = 1;
        }

        // 更新结果
        if (count > maxCount) {
            // 发现更高频率，清空结果，更新最大频率
            maxCount = count;
            result.clear();
            result.add(node.val);
        } else if (count == maxCount) {
            // 频率相同，添加到结果
            result.add(node.val);
        }

        // 更新前一个值
        prev = node.val;

        // 遍历右子树
        inorder(node.right);
    }
}
```

### 方法三：Morris 中序遍历（极致优化）

```java
class Solution {
    public int[] findMode(TreeNode root) {
        // Morris 遍历，真正的 O(1) 空间（连递归栈都不用）
        List<Integer> result = new ArrayList<>();
        int maxCount = 0;
        int count = 0;
        Integer prevVal = null;
        TreeNode current = root;

        while (current != null) {
            if (current.left == null) {
                // 没有左子树，处理当前节点
                if (prevVal != null && current.val == prevVal) {
                    count++;
                } else {
                    count = 1;
                }

                if (count > maxCount) {
                    maxCount = count;
                    result.clear();
                    result.add(current.val);
                } else if (count == maxCount) {
                    result.add(current.val);
                }

                prevVal = current.val;
                current = current.right;
            } else {
                // 有左子树，找到前驱节点
                TreeNode predecessor = current.left;
                while (predecessor.right != null && predecessor.right != current) {
                    predecessor = predecessor.right;
                }

                if (predecessor.right == null) {
                    // 建立线索
                    predecessor.right = current;
                    current = current.left;
                } else {
                    // 已有线索，说明左子树已访问完
                    predecessor.right = null;

                    // 处理当前节点
                    if (prevVal != null && current.val == prevVal) {
                        count++;
                    } else {
                        count = 1;
                    }

                    if (count > maxCount) {
                        maxCount = count;
                        result.clear();
                        result.add(current.val);
                    } else if (count == maxCount) {
                        result.add(current.val);
                    }

                    prevVal = current.val;
                    current = current.right;
                }
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

### 方法一（哈希表）：
- **时间复杂度**：O(n)，需要遍历所有节点
- **空间复杂度**：O(n)，哈希表存储所有不同的值

### 方法二（中序遍历）：
- **时间复杂度**：O(n)，遍历所有节点一次
- **空间复杂度**：O(h)，递归栈深度为树的高度 h

### 方法三（Morris 遍历）：
- **时间复杂度**：O(n)，每个节点最多访问两次
- **空间复杂度**：O(1)，真正的常数空间

## 关键点总结

1. **利用 BST 性质**：中序遍历得到有序序列，相同值连续出现
2. **一次遍历统计**：不需要先统计再查找，可以边遍历边更新结果
3. **空间优化**：从 O(n) 优化到 O(h) 再到 O(1)
4. **众数可能有多个**：需要收集所有达到最大频率的值
5. **边界处理**：注意处理单节点树和所有值都不同的情况

## 易错点

1. **忘记可能有多个众数**：结果应该是列表，不是单个值
2. **中序遍历顺序错误**：必须是左-根-右的顺序
3. **prev 初始化**：第一个节点时 prev 为 null，需要特殊处理
4. **频率相等时的处理**：应该添加到结果，而不是替换
5. **Morris 遍历的线索处理**：访问完左子树后要记得断开线索
