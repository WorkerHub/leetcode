## 题目描述

返回数组中不重叠子数组的最多数目，每个子数组元素总和等于 target。

**示例：**
```
输入：nums = [1,1,1,1,1], target = 2
输出：2
```

## 解题思路

贪心 + 前缀和：尽早找到和为 target 的子数组，找到后重置前缀和和哈希表从下一个位置重新开始。

## Java 代码实现

```java
class Solution {
    public int maxNonOverlapping(int[] nums, int target) {
        int ans = 0;
        int prefix = 0;
        Set<Integer> seen = new HashSet<>();
        seen.add(0);
        
        for (int num : nums) {
            prefix += num;
            if (seen.contains(prefix - target)) {
                ans++;
                // 重置，从下一个位置重新开始
                seen.clear();
                seen.add(0);
                prefix = 0;
            }
            seen.add(prefix);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心**：尽早结束当前子数组，留更多空间给后续
2. **重置策略**：找到后清空 seen 和 prefix
3. **前缀和**：prefix - target 在 seen 中则找到一个子数组
