## 题目描述

给定一个**无重复元素**的**有序**整数数组 `nums`。

返回**恰好覆盖数组中所有数字**的**最小有序**区间范围列表。也就是说，`nums` 的每个元素都恰好被某个区间范围所覆盖，并且不存在属于某个范围但不属于 `nums` 的数字 `x`。

列表中的每个区间范围 `[a,b]` 应该按如下格式输出：

- `"a->b"`，如果 `a != b`
- `"a"`，如果 `a == b`

**示例 1：**

```
输入：nums = [0,1,2,4,5,7]
输出：["0->2","4->5","7"]
解释：区间范围是：
[0,2] --> "0->2"
[4,5] --> "4->5"
[7,7] --> "7"
```

**示例 2：**

```
输入：nums = [0,2,3,4,6,8,9]
输出：["0","2->4","6","8->9"]
解释：区间范围是：
[0,0] --> "0"
[2,4] --> "2->4"
[6,6] --> "6"
[8,9] --> "8->9"
```

**提示：**

- `0 <= nums.length <= 20`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `nums` 中的所有值都**互不相同**
- `nums` 按**升序**排列

## 解题思路

这道题的核心是**找到连续的区间**。由于数组已经有序且无重复，只需要判断相邻元素是否连续即可。

### 核心思想

使用**双指针**：
1. 左指针 `start` 标记区间起点
2. 右指针 `i` 向右扫描，找到连续区间的终点
3. 当遇到不连续的数字时，将当前区间加入结果

### 判断连续的条件

两个数字连续：`nums[i+1] == nums[i] + 1`

## Java 代码实现

### 方法一：双指针（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> result = new ArrayList<>();
        if (nums == null || nums.length == 0) {
            return result;
        }

        int start = 0; // 区间起点

        for (int i = 0; i < nums.length; i++) {
            // 如果不是最后一个数字，且下一个数字连续，继续扩展区间
            if (i < nums.length - 1 && nums[i + 1] == nums[i] + 1) {
                continue;
            }

            // 否则，当前区间结束
            if (start == i) {
                // 单个数字
                result.add(String.valueOf(nums[start]));
            } else {
                // 区间
                result.add(nums[start] + "->" + nums[i]);
            }

            // 更新下一个区间的起点
            start = i + 1;
        }

        return result;
    }
}
```

### 方法二：while 循环

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> result = new ArrayList<>();
        int i = 0;
        int n = nums.length;

        while (i < n) {
            int start = i;
            // 找到连续区间的终点
            while (i + 1 < n && nums[i + 1] == nums[i] + 1) {
                i++;
            }

            // 添加区间
            if (start == i) {
                result.add(String.valueOf(nums[start]));
            } else {
                result.add(nums[start] + "->" + nums[i]);
            }

            i++;
        }

        return result;
    }
}
```

### 方法三：更简洁的写法

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> result = new ArrayList<>();
        int i = 0;

        while (i < nums.length) {
            int j = i;
            // 扩展区间
            while (j + 1 < nums.length && nums[j + 1] == nums[j] + 1) {
                j++;
            }

            // 构造区间字符串
            if (i == j) {
                result.add(String.valueOf(nums[i]));
            } else {
                result.add(nums[i] + "->" + nums[j]);
            }

            i = j + 1;
        }

        return result;
    }
}
```

### 方法四：详细注释版（便于理解）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        /**
         * 汇总区间：将有序数组中的连续数字合并为区间
         *
         * 思路：
         * 1. 遍历数组，找到每个连续区间
         * 2. 区间起点到终点相同时输出单个数字
         * 3. 区间起点到终点不同时输出 "起点->终点"
         */
        List<String> result = new ArrayList<>();
        if (nums == null || nums.length == 0) {
            return result;
        }

        int start = 0; // 当前区间的起点索引

        for (int i = 0; i < nums.length; i++) {
            // 检查是否还有下一个数字，且下一个数字是否连续
            // 连续的条件：nums[i+1] = nums[i] + 1
            if (i + 1 < nums.length && nums[i + 1] == nums[i] + 1) {
                // 继续扩展当前区间
                continue;
            }

            // 当前区间结束（遇到不连续的数字或到达末尾）
            if (start == i) {
                // 区间只有一个数字
                result.add(String.valueOf(nums[start]));
            } else {
                // 区间有多个数字
                result.add(nums[start] + "->" + nums[i]);
            }

            // 更新下一个区间的起点
            start = i + 1;
        }

        return result;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(1)，不计结果列表，只使用常数个变量

## 图解示例

以 `nums = [0,1,2,4,5,7]` 为例：

```
索引  0  1  2  3  4  5
数值  0  1  2  4  5  7

第一轮：
start = 0, i = 0
  nums[1] = 1 = nums[0] + 1，连续，继续
start = 0, i = 1
  nums[2] = 2 = nums[1] + 1，连续，继续
start = 0, i = 2
  nums[3] = 4 ≠ nums[2] + 1，不连续
  添加 "0->2"
  start = 3

第二轮：
start = 3, i = 3
  nums[4] = 5 = nums[3] + 1，连续，继续
start = 3, i = 4
  nums[5] = 7 ≠ nums[4] + 1，不连续
  添加 "4->5"
  start = 5

第三轮：
start = 5, i = 5
  到达末尾，start == i
  添加 "7"

结果：["0->2", "4->5", "7"]
```

## 关键点总结

1. **连续判断**：`nums[i+1] == nums[i] + 1`
2. **区间标记**：用 start 记录区间起点，i 扫描终点
3. **边界处理**：检查 `i + 1 < nums.length` 防止越界
4. **格式化输出**：单个数字 vs 区间的不同格式
5. **指针更新**：区间结束后更新 start

## 易错点

1. **越界检查**：访问 `nums[i+1]` 前要检查 `i+1 < nums.length`
2. **空数组**：需要特判空数组的情况
3. **单个数字**：`start == i` 时只输出一个数字，不是区间
4. **字符串格式**：注意是 `"a->b"` 不是 `"a-b"` 或其他格式
5. **起点更新**：每次区间结束后要更新 `start = i + 1`
