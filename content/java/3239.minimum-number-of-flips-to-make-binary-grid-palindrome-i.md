## 题目描述

给你一个 `m x n` 的二进制矩阵 `grid`，翻转任意格子的值，返回使每行每列都是回文序列的最少翻转次数。

## Java 代码实现

```java
class Solution {
    public int minFlips(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;

        // 处理四元对称格子组
        for (int i = 0; i < m / 2; i++) {
            for (int j = 0; j < n / 2; j++) {
                int c = grid[i][j] + grid[i][n-1-j]
                      + grid[m-1-i][j] + grid[m-1-i][n-1-j];
                ans += Math.min(c, 4 - c);
            }
        }

        // m 为奇数时处理中间行的对称对
        if (m % 2 == 1) {
            int midRow = m / 2;
            for (int j = 0; j < n / 2; j++) {
                if (grid[midRow][j] != grid[midRow][n-1-j]) ans++;
            }
        }

        // n 为奇数时处理中间列的对称对
        if (n % 2 == 1) {
            int midCol = n / 2;
            for (int i = 0; i < m / 2; i++) {
                if (grid[i][midCol] != grid[m-1-i][midCol]) ans++;
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 行列同时回文要求四个对称位置相同，翻转代价为 min(c, 4-c)
2. 奇数行/列需要单独处理中间行/列（只需两个位置相同）
3. m 和 n 都是奇数时，中心格子自动满足
