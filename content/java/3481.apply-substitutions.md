## 题目描述

给你替换规则列表 `replacements`（键值对）和字符串 `text`，其中 `%key%` 格式的占位符需替换为对应值（值中也可能含占位符，无循环依赖），返回完全展开后的字符串。

## 解题思路

记忆化 DFS：建立哈希表后，对每个键递归展开其值中的所有占位符。缓存已展开的结果避免重复计算，无循环依赖保证递归终止。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private Map<String, String> repMap;
    private Map<String, String> memo = new HashMap<>();

    public String applySubstitutions(List<List<String>> replacements, String text) {
        repMap = new HashMap<>();
        for (List<String> pair : replacements) {
            repMap.put(pair.get(0), pair.get(1));
        }
        return expand(text);
    }

    private String expand(String s) {
        if (memo.containsKey(s)) return memo.get(s);

        StringBuilder result = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            if (s.charAt(i) == '%') {
                int j = s.indexOf('%', i + 1);
                if (j != -1) {
                    String key = s.substring(i + 1, j);
                    if (repMap.containsKey(key)) {
                        result.append(expand(repMap.get(key)));
                        i = j + 1;
                        continue;
                    }
                }
            }
            result.append(s.charAt(i));
            i++;
        }

        String res = result.toString();
        memo.put(s, res);
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为规则数，L 为平均字符串长度
- 空间复杂度：O(n * L)，缓存展开结果

## 关键点总结

1. 记忆化避免重复展开同一字符串
2. 递归展开：对值中的 `%key%` 占位符继续展开
3. 无循环依赖保证递归必定终止
