## 题目描述

给你一个目标数组 `target` 和一个整数 `n`，每次迭代，需要从 `list = [1, 2, ..., n]` 中按顺序读取一个数字。

请使用下述操作来构建目标数组 `target`：
- **Push**：从 `list` 中读取一个新整数，将其推入数组。
- **Pop**：删除数组最顶端的元素。

注意，在做 Push 操作前，不能先做 Pop 操作，即每次必须先 Push 再可以 Pop。

如果目标数组构建完成，就停止读取更多数字。题目数据保证目标数组严格递增且每个元素都在 `[1, n]` 范围内。

请返回构建 `target` 数组所用的操作序列，操作序列中的元素为字符串 `"Push"` 和 `"Pop"`。

**示例 1：**
```
输入：target = [1,3], n = 3
输出：["Push","Push","Pop","Push"]
解释：
读取 1，Push，数组 [1]
读取 2，Push，数组 [1,2]，Pop，数组 [1]（2 不在 target 中）
读取 3，Push，数组 [1,3]
```

**示例 2：**
```
输入：target = [1,2,3], n = 3
输出：["Push","Push","Push"]
```

**示例 3：**
```
输入：target = [1,2], n = 4
输出：["Push","Push"]
解释：target 已构建完成，不需要读取剩余数字。
```

**提示：**
- `1 <= target.length <= 100`
- `1 <= target[i] <= n`
- `1 <= n <= 100`
- `target` 严格递增

## 解题思路

**模拟过程：**

从 1 到 n 顺序读取数字，对每个数字：
1. 先执行 Push（所有数字都会被 Push）。
2. 若该数字**在 target 中**，保留（不 Pop）。
3. 若该数字**不在 target 中**，执行 Pop（丢弃）。
4. 当 target 中所有元素都已加入，停止。

**优化：** 将 `target` 转为集合以 O(1) 查询；当读取到的数字超过 `target` 最后一个元素时，可以提前停止。

## Java 代码实现

### 方法一：模拟遍历（推荐）

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<String> buildArray(int[] target, int n) {
        Set<Integer> targetSet = new HashSet<>();  // 转换为集合，O(1) 查询
        for (int t : target) targetSet.add(t);

        List<String> result = new ArrayList<>();
        int targetIdx = 0;  // target 中下一个要匹配的元素下标

        for (int num = 1; num <= n; num++) {
            if (targetIdx >= target.length) break;  // target 已全部构建，提前退出

            result.add("Push");  // 每个数字都先 Push

            if (!targetSet.contains(num)) {
                result.add("Pop");  // 不在 target 中，立即 Pop
            } else {
                targetIdx++;  // 成功匹配 target 中的一个元素
            }
        }

        return result;
    }
}
```

### 方法二：直接按 target 构造（无需集合）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> buildArray(int[] target, int n) {
        List<String> result = new ArrayList<>();
        int current = 1;  // 当前读取的数字（从 1 开始）

        for (int t : target) {
            // 在到达 target[i] 之前，所有不在 target 的数字都 Push 再 Pop
            while (current < t) {
                result.add("Push");
                result.add("Pop");
                current++;
            }

            // current == t，Push 保留
            result.add("Push");
            current++;
        }

        return result;
    }
}
```

### 方法三：计算跳跃数量（简洁版）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> buildArray(int[] target, int n) {
        List<String> result = new ArrayList<>();
        int prev = 0;  // 上一个 target 元素

        for (int t : target) {
            // prev+1 到 t-1 的数字都是 Push+Pop，共 t-prev-1 个
            for (int i = 0; i < t - prev - 1; i++) {
                result.add("Push");
                result.add("Pop");
            }
            // t 本身只 Push
            result.add("Push");
            prev = t;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，最多遍历 1 到 n 的所有数字。
- **空间复杂度：** O(1)（不计输出列表），或 O(n) 计入输出。

## 图解示例

```
target = [1,3], n = 3

方法二过程：
  t=1: current=1, 1 == t，Push；current=2
  t=3: current=2 < 3，Push+Pop（处理2）；current=3
       current=3 == t，Push；current=4

结果：["Push", "Push", "Pop", "Push"]
```

## 关键点总结

1. 所有数字都会被 Push，不在 target 中的数字紧接着 Pop。
2. 方法三最简洁：通过计算相邻 target 元素之间的"跳过数量"来批量添加 Push+Pop。
3. 遇到 target 最后一个元素后可以立即停止，不需要处理剩余数字。
4. `target` 严格递增是关键条件，确保顺序一致。

## 易错点

- 忘记在非 target 数字 Push 后立刻 Pop（颠倒顺序）。
- 处理到 target 最后一个元素后继续读取多余数字（效率问题，但不影响正确性）。
- 方法三中 `(t - prev - 1)` 计算中间跳过的数字数量时，减去 1 是因为不包含 t 本身。
