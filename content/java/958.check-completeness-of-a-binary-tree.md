## 题目描述

给定一个二叉树的根节点 `root`，判断其是否是一个完全二叉树。

在一个完全二叉树中，除了最后一层外，所有层都是完全填充的，并且最后一层中的所有节点都尽可能地靠左。最后一层（第 h 层）包含 `1` 到 `2^h` 个节点。

**示例 1：**
```
输入：root = [1,2,3,4,5,6]
输出：true
```

**示例 2：**
```
输入：root = [1,2,3,4,5,null,7]
输出：false
```

**提示：**
- 树中节点数在范围 `[1, 100]` 内
- `1 <= Node.val <= 1000`

## 解题思路

完全二叉树的特点：层序遍历时，遇到第一个空节点后，不应该再有非空节点。

## Java 代码实现

### 方法一：层序遍历（推荐）⭐

```java
import java.util.ArrayDeque;
import java.util.Deque;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    /**
     * 层序遍历检查完全性
     */
    public boolean isCompleteTree(TreeNode root) {
        if (root == null) return true;

        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        boolean foundNull = false;

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();

            if (node == null) {
                foundNull = true;
            } else {
                // 遇到空节点后又有非空节点，不是完全二叉树
                if (foundNull) return false;
                queue.offer(node.left);
                queue.offer(node.right);
            }
        }

        return true;
    }
}
```

### 方法二：编号法

```java
class Solution {
    /**
     * 给节点编号，检查编号连续性
     * 完全二叉树的节点编号是连续的（1 到 N）
     */
    public boolean isCompleteTree(TreeNode root) {
        if (root == null) return true;

        Deque<int[]> queue = new ArrayDeque<>(); // [节点索引, 节点引用]
        // 使用 Object[] 存储节点和索引
        java.util.Queue<Object[]> q = new java.util.LinkedList<>();
        q.offer(new Object[]{root, 1});

        int maxIndex = 0, count = 0;

        while (!q.isEmpty()) {
            Object[] item = q.poll();
            TreeNode node = (TreeNode) item[0];
            int index = (int) item[1];

            maxIndex = Math.max(maxIndex, index);
            count++;

            if (node.left != null) q.offer(new Object[]{node.left, 2 * index});
            if (node.right != null) q.offer(new Object[]{node.right, 2 * index + 1});
        }

        // 完全二叉树：最大编号 == 节点数
        return maxIndex == count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. 完全二叉树：遇到空节点后不能再有节点
2. 编号法：最大编号等于节点数
3. BFS 是检查完全性的标准方法

## 易错点

1. 要将 null 也入队
2. 注意空树的处理
3. Java 中 ArrayDeque 不允许存 null，可用 LinkedList
