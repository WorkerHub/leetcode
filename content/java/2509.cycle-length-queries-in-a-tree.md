## 题目描述

给你完全二叉树（根为 1，左孩子 2v，右孩子 2v+1），对每个查询 `[a, b]`，添加 a-b 边后形成环，返回环的长度。

## 解题思路

环长 = dist(a, LCA) + dist(b, LCA) + 1（新边）。在完全二叉树中通过整数除法快速找 LCA：深度较大的节点先除以 2 向上移动，直到两节点相等。移动的总步数即为 dist(a, LCA) + dist(b, LCA)。

## Java 代码实现

```java
class Solution {
    public int[] cycleLengthQueries(int n, int[][] queries) {
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            long a = queries[i][0], b = queries[i][1];
            int steps = 1; // 新边计 1
            while (a != b) {
                if (a > b) a >>= 1; // 较深节点向上移动
                else b >>= 1;
                steps++;
            }
            ans[i] = steps;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q × log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 父节点 = 节点编号 >> 1，利用整数除法快速上移
2. 找 LCA：每次让编号较大（深度较深）的节点向上移动一层
3. 环长 = 上移总步数 + 1（新添加的边）
