## 题目描述

给你整数数组 `gifts`，每秒选礼物最多的那堆，将其减少为向下取整的平方根，经过 `k` 秒后返回所有堆礼物的总数量。

## 解题思路

最大堆：每次取出最大值，替换为其整数平方根，重复 k 次，最后求和。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long pickGifts(int[] gifts, int k) {
        // 最大堆
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int g : gifts) maxHeap.offer(g);

        for (int i = 0; i < k; i++) {
            int max = maxHeap.poll();
            maxHeap.offer((int) Math.sqrt(max)); // 向下取整平方根
        }

        long total = 0;
        for (int v : maxHeap) total += v;
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 最大堆每次 O(log n) 取最大并更新
2. `(int) Math.sqrt(max)` 向下取整（Java 中整数转换自动截断）
3. 返回 `long` 累加防止溢出
