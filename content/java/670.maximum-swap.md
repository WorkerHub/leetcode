## 题目描述

给定非负整数，最多交换一次任意两位数字，返回能得到的最大值。

**示例：**
```
输入：num = 2736
输出：7236（交换 2 和 7）
```

## 解题思路

贪心：记录每个数字最后出现位置，从高位开始找第一个可以被更大数字替换的位置。

## Java 代码实现

```java
class Solution {
    public int maximumSwap(int num) {
        char[] digits = String.valueOf(num).toCharArray();

        // 记录每个数字最后出现的位置
        int[] last = new int[10];
        for (int i = 0; i < digits.length; i++) {
            last[digits[i] - '0'] = i;
        }

        // 从高位开始，找第一个可以被更大数字替换的位置
        for (int i = 0; i < digits.length; i++) {
            for (int d = 9; d > digits[i] - '0'; d--) {
                if (last[d] > i) {
                    // 交换
                    char temp = digits[i];
                    digits[i] = digits[last[d]];
                    digits[last[d]] = temp;
                    return Integer.parseInt(new String(digits));
                }
            }
        }

        return num;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为位数
- **空间复杂度**：O(n)

## 关键点总结

1. **记录最后位置**：同样数字选最右边的（结果更大）
2. **从高位找**：优先交换高位
3. **从大到小尝试**：找最大的可交换数字
