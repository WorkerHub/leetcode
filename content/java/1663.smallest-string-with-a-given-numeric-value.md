## 题目描述

字母数值：a=1, b=2, ..., z=26。返回长度为 `n`、字母数值之和为 `k` 的**字典序最小**字符串。

## 解题思路

**贪心（从后往前）：** 前面字符尽量小（'a'=1），后面尽量大（'z'=26）。从右往左，每位取 `min(26, k - 剩余位数)`，保证前面每位至少 1。

## Java 代码实现

```java
class Solution {
    public String getSmallestString(int n, int k) {
        char[] result = new char[n];

        for (int i = n - 1; i >= 0; i--) {
            // 前 i 个位置各至少用 1，当前位置最大值 = min(26, k - i)
            int val = Math.min(26, k - i);
            result[i] = (char) ('a' + val - 1);
            k -= val;
        }

        return new String(result);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 字典序最小：前面尽量填 'a'，后面填大字符
2. 从后往前，每位取 `min(26, k - i)`，i 为剩余位数
3. 字符值从 1 开始（a=1）
