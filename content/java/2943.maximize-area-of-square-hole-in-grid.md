## 题目描述

网格中移除连续的行/列条纹形成正方形洞，求最大面积。

## 解题思路

分别对hBars和vBars排序，找最长连续段长度max_h和max_v，正方形边长=min(max_h,max_v)+1。

## Java 代码实现

```java
class Solution {
    public int maximizeSquareHoleArea(int n, int m, int[] hBars, int[] vBars) {
        int maxH = maxConsecutive(hBars);
        int maxV = maxConsecutive(vBars);
        int side = Math.min(maxH, maxV) + 1;
        return side * side;
    }

    private int maxConsecutive(int[] bars) {
        Arrays.sort(bars);
        int maxLen = 1, curLen = 1;
        for (int i = 1; i < bars.length; i++) {
            if (bars[i] == bars[i - 1] + 1) {
                curLen++;
                maxLen = Math.max(maxLen, curLen);
            } else {
                curLen = 1;
            }
        }
        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(H logH + V logV)
- **空间复杂度**：O(1)

## 关键点总结

1. **连续条纹合并扩大洞**：k条连续条纹使边长+k
2. **基础洞大小1x1**：初始边长为1
3. **正方形取两方向最小值**
