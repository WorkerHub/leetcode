## 题目描述

给你整数数组 nums 和整数 limit，每次可将相邻两个元素替换为其乘积（前提是乘积 ≤ limit），返回最多操作后数组的最短长度。

## 解题思路

贪心：从左到右扫描，维护当前段的乘积，能合并则合并，否则开始新段，最终段数即为最短长度。

## Java 代码实现

```java
class Solution {
    public int minArrayLength(int[] nums, int limit) {
        int segments = 1;
        long product = nums[0]; // 使用 long 防止溢出

        for (int i = 1; i < nums.length; i++) {
            if (product * nums[i] <= limit) {
                product *= nums[i]; // 合并相邻元素
            } else {
                segments++;         // 无法合并，开始新段
                product = nums[i];
            }
        }
        return segments;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：能合并就合并，尽量减少段数
2. 只能合并相邻元素，乘积不超过 limit
3. 使用 long 防止乘积中间计算溢出
