## 题目描述

给定按时间排序的事件数组 `events[i] = [index, time]`，每次按键的持续时间为相邻时间差（首次从 0 开始），返回按住时间最长的按钮编号，相同时取编号最小的。

## Java 代码实现

```java
class Solution {
    public int buttonWithLongestTime(int[][] events) {
        int bestTime = 0;
        int bestIndex = -1;
        int prevTime = 0;

        for (int[] e : events) {
            int index = e[0], time = e[1];
            int duration = time - prevTime;
            // 持续时间更长，或相同时取 index 更小的
            if (duration > bestTime || (duration == bestTime && index < bestIndex)) {
                bestTime = duration;
                bestIndex = index;
            }
            prevTime = time;
        }

        return bestIndex;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 每次按键的持续时间 = 当前时间 - 上次时间（第一次为 time - 0）。
2. 找持续时间最长的按键，相同时取 index 最小。
3. 只需维护前一次时间戳，无需额外空间。
