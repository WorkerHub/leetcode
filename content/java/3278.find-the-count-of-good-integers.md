## 题目描述

给你正整数 `n` 和 `k`，若一个 `n` 位整数能被 `k` 整除，且其数字重排（不含前导零）后可构成回文数，则称其为**好整数**。返回 `n` 位好整数的数量。

## 解题思路

枚举所有 n 位回文数，找能被 k 整除的，用排序后的数字字符串去重（同一多重集只统计一次），然后对每种多重集统计满足无前导零的 n 位排列数（全排列减去首位为 0 的情况）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countGoodIntegers(int n, int k) {
        int half = (n + 1) / 2;
        int start = (int) Math.pow(10, half - 1);
        int end = (int) Math.pow(10, half);
        Set<String> seen = new HashSet<>();
        long ans = 0;

        for (int firstHalf = start; firstHalf < end; firstHalf++) {
            String s = String.valueOf(firstHalf);
            StringBuilder sb = new StringBuilder(s);
            if (n % 2 == 0) {
                sb.append(new StringBuilder(s).reverse());
            } else {
                sb.append(new StringBuilder(s.substring(0, s.length() - 1)).reverse());
            }
            long num = Long.parseLong(sb.toString());
            if (num % k != 0) continue;

            // 数字排序作为多重集唯一标识
            char[] chars = sb.toString().toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            if (!seen.add(key)) continue;

            // 统计 n 位无前导零排列数
            int[] cnt = new int[10];
            for (char c : sb.toString().toCharArray()) cnt[c - '0']++;

            long total = factorial(n);
            for (int c : cnt) total /= factorial(c);

            // 减去首位为 0 的排列数
            if (cnt[0] > 0) {
                cnt[0]--;
                long zeroFirst = factorial(n - 1);
                for (int c : cnt) zeroFirst /= factorial(c);
                cnt[0]++;
                total -= zeroFirst;
            }
            ans += total;
        }
        return ans;
    }

    private long factorial(int n) {
        long res = 1;
        for (int i = 2; i <= n; i++) res *= i;
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10^(n/2))，枚举前半部分
- 空间复杂度：O(10^(n/2))（seen 集合）

## 关键点总结

1. 枚举所有 n 位回文数，找能被 k 整除的，用排序字符串去重
2. 全排列数 = n! / (各数字计数的阶乘之积)
3. 减去首位为 0 的排列数（固定首位为 0，剩余 n-1 位全排列）
