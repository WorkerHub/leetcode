## 题目描述

给定一个不重复的整数数组 `nums`。**最大二叉树**可以用下面的算法从 `nums` 递归地构建:

1. 创建一个根节点，其值为 `nums` 中的最大值。
2. 递归地在最大值**左边**的**子数组前缀**上构建左子树。
3. 递归地在最大值**右边**的**子数组后缀**上构建右子树。

返回 `nums` 构建的**最大二叉树**。

**示例 1:**

```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,null,0,null,null,2,null,1]
```

**示例 2:**

```
输入：nums = [3,2,1]
输出：[3,null,2,null,1]
```

**提示:**
- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- `nums` 中的所有整数**互不相同**

## 解题思路

这是一道典型的**分治**问题，也可以用**单调栈**优化。

### 思路一：递归分治（最直观）

按照题目描述直接递归构建：

1. 找到数组中的最大值及其索引
2. 最大值作为根节点
3. 最大值左边的子数组构建左子树
4. 最大值右边的子数组构建右子树

### 思路二：单调栈（优化到 O(n)）

使用**单调递减栈**：
- 栈中存储节点，保持从栈底到栈顶递减
- 遇到更大的数时，弹出栈中较小的数

## Java 代码实现

### 方法一：递归分治（推荐新手）

```java
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        return build(nums, 0, nums.length);
    }

    private TreeNode build(int[] nums, int left, int right) {
        // 构建 nums[left..right) 的最大二叉树
        if (left >= right) return null;

        // 找到最大值的索引
        int maxIdx = left;
        for (int i = left + 1; i < right; i++) {
            if (nums[i] > nums[maxIdx]) {
                maxIdx = i;
            }
        }

        // 创建根节点
        TreeNode root = new TreeNode(nums[maxIdx]);

        // 递归构建左右子树
        root.left = build(nums, left, maxIdx);
        root.right = build(nums, maxIdx + 1, right);

        return root;
    }
}
```

### 方法二：单调栈（最优解）

```java
import java.util.*;

class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        Deque<TreeNode> stack = new ArrayDeque<>(); // 单调递减栈

        for (int num : nums) {
            // 创建当前节点
            TreeNode node = new TreeNode(num);
            TreeNode last = null;

            // 弹出所有小于当前值的节点
            while (!stack.isEmpty() && stack.peek().val < num) {
                last = stack.pop();
            }

            // 最后弹出的节点作为当前节点的左子树
            if (last != null) {
                node.left = last;
            }

            // 如果栈不为空，当前节点作为栈顶的右子树
            if (!stack.isEmpty()) {
                stack.peek().right = node;
            }

            stack.push(node);
        }

        // 栈底元素是根节点（栈中最大值）
        TreeNode root = null;
        while (!stack.isEmpty()) {
            root = stack.pop();
        }
        return root;
    }
}
```

### 方法三：单调栈（另一种写法）

```java
import java.util.*;

class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        Deque<TreeNode> stack = new ArrayDeque<>();

        for (int num : nums) {
            TreeNode node = new TreeNode(num);

            // 弹出所有比当前值小的节点，它们成为当前节点的左子树
            while (!stack.isEmpty() && stack.peek().val < num) {
                node.left = stack.pop();
            }

            // 如果栈不为空，当前节点是栈顶的右子节点
            if (!stack.isEmpty()) {
                stack.peek().right = node;
            }

            stack.push(node);
        }

        // 返回栈底元素（最大值节点，即根节点）
        TreeNode root = null;
        while (!stack.isEmpty()) root = stack.pop();
        return root;
    }
}
```

## 复杂度分析

### 方法一：递归分治
- **时间复杂度**：O(n²) 最坏情况，O(n log n) 平均情况
- **空间复杂度**：O(h)，h 为树高

### 方法二/三：单调栈
- **时间复杂度**：O(n)，每个元素最多入栈出栈一次
- **空间复杂度**：O(n)，栈的大小

## 图解示例

示例 1：`nums = [3,2,1,6,0,5]`

**单调栈过程：**

```
处理 3: stack = [3]
处理 2: stack = [3, 2]  (2 < 3，作为3的右子节点)
处理 1: stack = [3, 2, 1]  (1 < 2，作为2的右子节点)
处理 6: stack = [6]  (弹出3,2,1，它们构成6的左子树)
        3 -> 2 -> 1 作为 6 的左子树
处理 0: stack = [6, 0]  (0 < 6，作为6的右子节点)
处理 5: stack = [6, 5]  (弹出0，0作为5的左子节点；5作为6的右子节点)
```

## 关键点总结

1. **分治思想**：递归地将问题分解为子问题
2. **最大值分割**：最大值作为根，分割左右子数组
3. **单调栈优化**：利用单调性质，O(n) 时间构建
4. **栈的性质**：单调递减栈维护可能的父节点
5. **左右子树规律**：弹出的节点作为左子树，新节点作为右子树

## 易错点

1. **数组范围**：注意 left 和 right 的边界（左闭右开）
2. **空数组处理**：`if (left >= right) return null;`
3. **单调栈的左右子树关系**：弹出的节点是左子树，当前节点是栈顶的右子节点
4. **单调栈返回值**：返回栈中最后剩下的最大值节点（根节点）
