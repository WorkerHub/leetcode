## 题目描述

给你 `m`、`n` 和一个链表头节点 `head`，生成 m×n 矩阵，从左上角按顺时针螺旋顺序填入链表值，剩余位置填 -1。

## 解题思路

模拟螺旋遍历：用方向数组表示右/下/左/上四个方向，每次移动后若下一格越界或已填充则转向。链表耗尽后退出即可，剩余位置已初始化为 -1。

## Java 代码实现

```java
class Solution {
    public int[][] spiralMatrix(int m, int n, ListNode head) {
        int[][] matrix = new int[m][n];
        // 初始化为 -1
        for (int[] row : matrix) java.util.Arrays.fill(row, -1);

        // 四个方向：右、下、左、上
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int d = 0, r = 0, c = 0;

        ListNode node = head;
        while (node != null) {
            matrix[r][c] = node.val;
            node = node.next;

            // 计算下一个位置
            int nr = r + dirs[d][0], nc = c + dirs[d][1];
            // 若越界或已填充则转向
            if (nr < 0 || nr >= m || nc < 0 || nc >= n || matrix[nr][nc] != -1) {
                d = (d + 1) % 4;
                nr = r + dirs[d][0];
                nc = c + dirs[d][1];
            }
            r = nr; c = nc;
        }
        return matrix;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. 初始化矩阵为 -1，用 `!= -1` 判断是否已访问，无需额外 visited 数组。
2. 转向条件：下一格越界或已被填充。
3. 链表耗尽后直接退出，未填充的格子保持 -1。
