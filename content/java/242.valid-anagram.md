## 题目描述

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

**注意：** 若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

**示例 1：**
```
输入: s = "anagram", t = "nagaram"
输出: true
```

**示例 2：**
```
输入: s = "rat", t = "car"
输出: false
```

**提示：**
- 1 <= s.length, t.length <= 5 * 10^4
- s 和 t 仅包含小写字母

**进阶：** 如果输入字符串包含 Unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 解题思路

判断两个字符串是否为字母异位词，核心是**判断两个字符串中每个字符出现的次数是否相同**。

**基本思路：**
1. **排序法**：将两个字符串排序后比较是否相等
2. **哈希表法**：统计每个字符出现的次数，然后比较
3. **数组计数法**：利用小写字母只有 26 个的特点，用数组统计

**关键观察：**
- 如果两个字符串长度不同，直接返回 false
- 字母异位词意味着字符种类和数量完全相同，只是顺序不同
- 可以用 Java 的数组统计字符频次

## Java 代码实现

### 方法一：排序法（最直观）

```java
import java.util.Arrays;

class Solution {
    public boolean isAnagram(String s, String t) {
        // 长度不同，直接返回 false
        if (s.length() != t.length()) {
            return false;
        }
        
        // 将字符串转为字符数组排序后比较
        char[] sArr = s.toCharArray();
        char[] tArr = t.toCharArray();
        Arrays.sort(sArr);
        Arrays.sort(tArr);
        
        return Arrays.equals(sArr, tArr);
    }
}
```

### 方法二：数组计数法（推荐）⭐

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        // 长度不同，直接返回 false
        if (s.length() != t.length()) {
            return false;
        }
        
        // 创建长度为 26 的计数数组
        int[] count = new int[26];
        
        // 统计字符频次：s 中的字符 +1，t 中的字符 -1
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
            count[t.charAt(i) - 'a']--;
        }
        
        // 如果是异位词，所有计数都应该为 0
        for (int c : count) {
            if (c != 0) {
                return false;
            }
        }
        
        return true;
    }
}
```

### 方法三：手动哈希表（进阶理解）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        
        // 统计 s 中每个字符的频次
        Map<Character, Integer> charCount = new HashMap<>();
        for (char c : s.toCharArray()) {
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);
        }
        
        // 在 t 中减去对应字符的频次
        for (char c : t.toCharArray()) {
            if (!charCount.containsKey(c)) {
                return false;
            }
            charCount.put(c, charCount.get(c) - 1);
            if (charCount.get(c) < 0) {
                return false;
            }
        }
        
        // 检查是否所有字符频次都为 0
        for (int cnt : charCount.values()) {
            if (cnt != 0) {
                return false;
            }
        }
        
        return true;
    }
}
```

### 方法四：两次遍历优化版

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        
        // 创建计数数组
        int[] count = new int[26];
        
        // 遍历 s，统计各字符出现次数
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }
        
        // 遍历 t，减去对应字符次数，若某字符次数减为负数则返回 false
        for (char c : t.toCharArray()) {
            count[c - 'a']--;
            if (count[c - 'a'] < 0) {
                return false; // 提前返回
            }
        }
        
        return true;
    }
}
```

### 进阶：支持 Unicode 字符

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        
        // 使用 HashMap 处理任意字符（包括 Unicode）
        Map<Character, Integer> map = new HashMap<>();
        
        for (char c : s.toCharArray()) {
            map.put(c, map.getOrDefault(c, 0) + 1);
        }
        
        for (char c : t.toCharArray()) {
            int cnt = map.getOrDefault(c, 0);
            if (cnt == 0) {
                return false;
            }
            map.put(c, cnt - 1);
        }
        
        return true;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 排序法 | O(n log n) | O(n) | 简单直观，但效率较低 |
| 数组计数 | O(n) | O(1) | 推荐，最优解 |
| 手动哈希表 | O(n) | O(1) | 帮助理解原理 |
| Unicode 版 | O(n) | O(n) | 字符种类可能很多 |

## 关键点总结

1. **长度检查**：两个字符串长度不同，直接返回 false，可以提前剪枝
2. **字符频次**：核心是统计每个字符出现的次数是否相同
3. **空间优化**：利用题目条件（仅小写字母），可以用固定大小的数组
4. **Java 技巧**：`charAt(i) - 'a'` 将字符转为 0-25 的索引
5. **Unicode 支持**：哈希表方法天然支持 Unicode，数组方法仅适用于有限字符集

## 易错点

1. **忘记长度检查**：虽然后续逻辑也能判断，但提前检查更高效
2. **字符范围假设**：题目明确说明只有小写字母，但进阶要求考虑 Unicode
3. **数组索引越界**：使用数组计数时，要确保 `charAt(i) - 'a'` 在 [0, 25] 范围内
4. **空字符串处理**：两个空字符串应该返回 true（它们互为异位词）
5. **Java 字符串比较**：不能用 `==` 比较字符串，要用 `equals()`
