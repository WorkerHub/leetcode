## 题目描述

有两种特殊字符：

- 第一种字符可以用一位二进制数 `0` 表示
- 第二种字符可以用两位二进制数 `10` 或 `11` 表示

给你一个以 `0` 结尾的二进制数组 `bits`，如果最后一个字符必须是一个一位字符，则返回 `true`。否则，返回 `false`。

**示例 1：**

```
输入：bits = [1,0,0]
输出：true
解释：唯一的解码方式是将其解析为一位字符 "0" 和一位字符 "0"。
所以最后一个字符是一位字符。
```

**示例 2：**

```
输入：bits = [1,1,1,0]
输出：false
解释：唯一的解码方式是将其解析为两位字符 "11" 和一位字符 "0"。
所以最后一个字符不是一位字符。
```

**提示：**
- `1 <= bits.length <= 1000`
- `bits[i]` 为 `0` 或 `1`

## 解题思路

**核心观察：**
- 遇到 `1` 时，必然是两位字符的开始，需要跳过下一位
- 遇到 `0` 时，是一位字符
- 检查倒数第二个位置之前的所有 `1` 的数量

**算法流程：**
1. 从头开始遍历，遇到 `1` 跳过下一位
2. 看最后是否正好停在倒数第一个位置

## Java 代码实现

### 方法一：模拟解码（推荐）⭐

```java
class Solution {
    public boolean isOneBitCharacter(int[] bits) {
        // 从头遍历，遇到 1 跳两步，遇到 0 跳一步
        // 看最后是否正好在最后一个位置
        int i = 0;
        int n = bits.length;
        
        while (i < n - 1) {
            if (bits[i] == 1) {
                i += 2; // 两位字符
            } else {
                i += 1; // 一位字符
            }
        }
        
        // 如果正好停在最后一位，说明最后是一位字符
        return i == n - 1;
    }
}
```

### 方法二：从后往前（巧妙）

```java
class Solution {
    public boolean isOneBitCharacter(int[] bits) {
        // 从倒数第二位往前数连续的 1 的个数
        // 如果是偶数个，最后是一位字符
        int count = 0;
        int i = bits.length - 2;
        
        // 统计倒数第二位之前连续 1 的个数
        while (i >= 0 && bits[i] == 1) {
            count++;
            i--;
        }
        
        // count 为偶数时，最后一个是一位字符
        return count % 2 == 0;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 关键点总结

1. **贪心思想**：遇到 1 必然跳两步
2. **倒数计数**：统计倒数第二位前的连续 1
3. **奇偶性**：1 的个数决定最后一位的解释
