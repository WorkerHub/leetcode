## 题目描述

给定一个包含大写字母和小写字母的字符串 s，返回通过这些字母构造成的最长的回文串的长度。

在构造过程中，请注意区分大小写。比如 "Aa" 不能当做一个回文字符串。

**示例 1：**
```
输入：s = "abccccdd"
输出：7
解释：我们可以构造的最长的回文串是 "dccaccd"，它的长度是 7。
```

**示例 2：**
```
输入：s = "a"
输出：1
```

**示例 3：**
```
输入：s = "aaaaaccc"
输出：7
```

**提示：**
- 1 <= s.length <= 2000
- s 只由小写和大写英文字母组成

## 解题思路

回文串的特点：
1. 偶数个相同字符可以全部使用（左右对称）
2. 奇数个相同字符可以使用偶数部分 + 1个放中间
3. 最多只能有一个字符出现奇数次并放在中间

贪心策略：
1. 统计每个字符的出现次数
2. 出现偶数次的字符全部使用
3. 出现奇数次的字符使用 count - 1（偶数部分）
4. 如果有奇数次的字符，可以选一个放中间，长度 +1

## Java 代码实现

### 方法一：哈希表计数（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int longestPalindrome(String s) {
        // 统计字符频次，贪心构造回文串
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        int length = 0;
        boolean hasOdd = false;

        for (int freq : count.values()) {
            if (freq % 2 == 0) {
                // 偶数次，全部使用
                length += freq;
            } else {
                // 奇数次，使用偶数部分
                length += freq - 1;
                hasOdd = true;
            }
        }

        // 如果有奇数频次的字符，可以放一个在中间
        if (hasOdd) length += 1;

        return length;
    }
}
```

### 方法二：简化版（直接计算）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int longestPalindrome(String s) {
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        // 每个字符取偶数部分：freq / 2 * 2
        int length = 0;
        for (int freq : count.values()) {
            length += (freq / 2) * 2;
        }

        // 如果还有剩余的奇数字符，可以加 1（放中间）
        return length < s.length() ? length + 1 : length;
    }
}
```

### 方法三：数组计数（利用 ASCII 码）

```java
class Solution {
    public int longestPalindrome(String s) {
        // 使用数组代替 HashMap（'A'-'Z' 65-90, 'a'-'z' 97-122）
        int[] count = new int[128];
        for (char c : s.toCharArray()) {
            count[c]++;
        }

        int length = 0;
        boolean hasOdd = false;

        for (int freq : count) {
            length += (freq / 2) * 2;  // 取偶数部分
            if (freq % 2 == 1) hasOdd = true;
        }

        return hasOdd ? length + 1 : length;
    }
}
```

### 方法四：集合配对法

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestPalindrome(String s) {
        // 使用集合记录出现奇数次的字符
        Set<Character> charSet = new HashSet<>();

        for (char c : s.toCharArray()) {
            if (charSet.contains(c)) {
                charSet.remove(c);  // 配对成功
            } else {
                charSet.add(c);     // 等待配对
            }
        }

        // charSet 中剩余的是出现奇数次的字符
        // 长度 = 总长度 - 奇数字符个数 + 1（可以选一个放中间）
        int oddCount = charSet.size();
        if (oddCount > 0) {
            return s.length() - oddCount + 1;
        }
        return s.length();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
  - 遍历字符串一次

- **空间复杂度**：O(1)
  - 最多 52 个字母（大小写），常数空间

## 关键点总结

1. 回文串的对称性
2. 偶数频次字符全用，奇数频次字符用偶数部分
3. 最多一个字符可以放中间

## 易错点

1. 忘记处理中间字符（+1）
2. 误认为只能有一个奇数频次字符
