## 题目描述

给你一个字符串 `s`，它只包含三种字符 `a`、`b` 和 `c`。

请你返回 `a`、`b` 和 `c` 都**至少出现过一次**的子字符串数目。

**示例 1：**
```
输入：s = "abcabc"
输出：10
解释：包含 a、b 和 c 各至少一次的子字符串为：
"abc"、"abca"、"abcab"、"abcabc"、"bca"、"bcab"、"bcabc"、"cab"、"cabc"、"abc"(最后一个)
共 10 个。
```

**示例 2：**
```
输入：s = "aaacb"
输出：3
解释：包含三种字符的子字符串为：
"aaacb"、"aacb"、"acb"，共 3 个。
```

**示例 3：**
```
输入：s = "abc"
输出：1
```

**提示：**
- `3 <= s.length <= 5 * 10^4`
- `s` 只包含字符 `a`、`b` 和 `c`。

## 解题思路

**关键观察：** 如果子字符串 `s[left..right]` 包含了 a、b、c 各至少一次，那么 `s[left..right]`、`s[left..right+1]`、……、`s[left..n-1]`（即扩展右边界的所有子串）也都满足条件。

这意味着对于每个左端点 `left`，找到最短的满足条件的子串 `s[left..minRight]`，那么以 `left` 为起点的合法子串共有 `n - minRight` 个。

**方法二（右端点枚举）：** 对每个右端点 `r`，设 `last[c]` 为字符 c 在 `s[0..r]` 中最后一次出现的位置。令 `minLast = min(last[a], last[b], last[c])`，则以 `r` 结尾的合法子串个数 = `minLast + 1`（左端点可以是 0, 1, ..., minLast）。

## Java 代码实现

### 方法一：滑动窗口（左端点枚举，推荐）

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int n = s.length();
        int[] count = new int[3]; // 当前窗口内 a/b/c 的计数（0=a, 1=b, 2=c）
        int ans = 0;
        int r = 0; // 右指针
        
        for (int l = 0; l < n; l++) {
            // 扩展右边界直到窗口包含 a, b, c 各至少一次
            while (r < n && !(count[0] > 0 && count[1] > 0 && count[2] > 0)) {
                count[s.charAt(r) - 'a']++;
                r++;
            }
            
            // 如果当前窗口 [l, r-1] 包含三种字符
            // 以 l 为左端点，右端点为 r-1 到 n-1 的子串都合法
            // 共 n - (r-1) = n - r + 1 个
            if (count[0] > 0 && count[1] > 0 && count[2] > 0) {
                ans += n - r + 1;
            }
            
            // 移动左指针：将 s[l] 移出窗口
            count[s.charAt(l) - 'a']--;
        }
        
        return ans;
    }
}
```

### 方法二：右端点枚举（最优雅）

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int n = s.length();
        // last[c] 表示字符 c 最后一次出现的位置（-1 表示未出现）
        int[] last = {-1, -1, -1}; // 0=a, 1=b, 2=c
        int ans = 0;
        
        for (int r = 0; r < n; r++) {
            // 更新当前字符的最后位置
            last[s.charAt(r) - 'a'] = r;
            
            // 以 r 结尾的合法子串的左端点范围：
            // 左端点必须 <= min(last[a], last[b], last[c])
            int minLast = Math.min(last[0], Math.min(last[1], last[2]));
            
            if (minLast >= 0) { // 三种字符都出现过
                ans += minLast + 1;
            }
        }
        
        return ans;
    }
}
```

**方法二解释：**

对于右端点 `r`，设 `last[a]`、`last[b]`、`last[c]` 分别是 a、b、c 在 `s[0..r]` 中最后一次出现的位置。

令 `minLast = min(last[a], last[b], last[c])`。

子串 `s[l..r]` 包含三种字符当且仅当 `l <= minLast`（因为 l 必须不超过最后一次出现的最小位置，才能确保三种字符都在 `[l, r]` 中）。

所以以 `r` 结尾的合法子串个数 = `minLast + 1`（左端点可以是 0, 1, ..., minLast）。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（滑动窗口，左端点枚举） | O(N) | O(1) |
| 方法二（右端点枚举） | O(N) | O(1) |

## 图解示例

以 `s = "abcabc"` 为例，方法二右端点枚举：

```
r=0: s[0]='a', last={0,−1,−1}, minLast=−1, ans+=0
r=1: s[1]='b', last={0,1,−1},  minLast=−1, ans+=0
r=2: s[2]='c', last={0,1,2},   minLast=0,  ans+=1  (子串: "abc")
r=3: s[3]='a', last={3,1,2},   minLast=1,  ans+=2  (子串: "bca","abca")
r=4: s[4]='b', last={3,4,2},   minLast=2,  ans+=3  (子串: "cab","bcab","abcab")
r=5: s[5]='c', last={3,4,5},   minLast=3,  ans+=4  (子串: "abc","cabc","bcabc","abcabc")

总 ans = 0+0+1+2+3+4 = 10
```

## 关键点总结

1. **右端点枚举法**（方法二）是本题最优雅的解法，利用"三种字符最后出现位置的最小值"直接计算合法子串数。
2. 对于右端点 `r`，合法左端点个数 = `min(last[a], last[b], last[c]) + 1`。
3. **滑动窗口左端点枚举法**（方法一）更通用，适合处理"至少包含某些元素"的子字符串问题。
4. 两种 O(N) 方法的核心思想相同：利用单调性计数而非逐个枚举。

## 易错点

- 方法一中合法子串数的计算：窗口 `[l, r-1]` 合法时，以 `l` 为左端点、右端点从 `r-1` 到 `n-1` 都合法，共 `n - r + 1` 个（注意 `r` 在循环中已经多加 1）。
- 方法二中 `minLast` 可能为 -1（某种字符尚未出现），此时不应加任何计数，用 `if minLast >= 0` 过滤。
- Java 中 `s.charAt(r) - 'a'` 将字符转为 0/1/2 下标，注意使用 `charAt()` 而不是直接用字符数组。
