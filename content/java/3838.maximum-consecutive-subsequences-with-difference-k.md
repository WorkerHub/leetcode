## 题目描述

给定整数数组 `nums` 和整数 `k`，找到最长子序列使相邻元素差恰好为 `k`（+k 或 -k），返回其长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximumConsecutive(int[] nums, int k) {
        // dp[v] = 以值 v 结尾的满足条件子序列的最大长度
        Map<Integer, Integer> dp = new HashMap<>();
        int ans = 1;

        for (int v : nums) {
            // 可以接在 v-k 或 v+k 之后
            int prev = Math.max(
                dp.getOrDefault(v - k, 0),
                dp.getOrDefault(v + k, 0)
            );
            dp.put(v, prev + 1);
            ans = Math.max(ans, prev + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 哈希表 DP 按值记录状态，从 v-k 或 v+k 双向转移
2. 按位置从左到右处理，保证子序列顺序性
3. 初始答案为 1（单个元素）
