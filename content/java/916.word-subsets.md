## 题目描述

words2 中每个单词都是 words1 中某单词的子集（字母频率满足），则该单词为"通用单词"。返回所有通用单词。

**示例：**
```
输入：words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["e","o"]
输出：["facebook","google","leetcode"]
```

## 解题思路

合并 words2 的要求：对每个字母取最大出现次数。然后逐一检查 words1 中的单词是否满足。

## Java 代码实现

```java
class Solution {
    public List<String> wordSubsets(String[] words1, String[] words2) {
        // 合并 words2 的最大频率要求
        int[] maxFreq = new int[26];
        for (String word : words2) {
            int[] freq = new int[26];
            for (char c : word.toCharArray()) freq[c - 'a']++;
            for (int i = 0; i < 26; i++) {
                maxFreq[i] = Math.max(maxFreq[i], freq[i]);
            }
        }

        // 检查 words1
        List<String> result = new ArrayList<>();
        for (String word : words1) {
            int[] freq = new int[26];
            for (char c : word.toCharArray()) freq[c - 'a']++;
            boolean valid = true;
            for (int i = 0; i < 26; i++) {
                if (freq[i] < maxFreq[i]) { valid = false; break; }
            }
            if (valid) result.add(word);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) × k)
- **空间复杂度**：O(1)，26 个字母常数空间

## 关键点总结

1. **合并要求**：对每个字母取 words2 中的最大频率
2. **一次预处理**：避免重复检查每个 words2 单词
3. **频率比较**：逐字母检查频率是否满足
