## 题目描述

给两个等长数组，找曼哈顿距离|nums1[i]-nums1[j]|+|nums2[i]-nums2[j]|最小的下标对(i,j)，相同距离时返回字典序最小的。

## 解题思路

分治法求最近点对：将点按x排序，分治合并时处理中间带，比较时维护字典序最小的答案。

## Java 代码实现

```java
class Solution {
    private int[] nums1, nums2;
    private int[] bestPair = {0, 1};
    private int bestDist = Integer.MAX_VALUE;

    public int[] beautifulPair(int[] nums1, int[] nums2) {
        this.nums1 = nums1;
        this.nums2 = nums2;
        int n = nums1.length;
        int[][] points = new int[n][2]; // {x, 原始下标}
        for (int i = 0; i < n; i++) points[i] = new int[]{nums1[i], i};
        Arrays.sort(points, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        closestPair(points, 0, n - 1);
        return bestPair;
    }

    private void closestPair(int[][] pts, int lo, int hi) {
        if (hi - lo < 3) {
            for (int i = lo; i <= hi; i++) {
                for (int j = i + 1; j <= hi; j++) {
                    update(pts[i][1], pts[j][1]);
                }
            }
            return;
        }
        int mid = (lo + hi) / 2;
        int midX = pts[mid][0];
        closestPair(pts, lo, mid);
        closestPair(pts, mid + 1, hi);

        // 中间带
        List<int[]> strip = new ArrayList<>();
        for (int i = lo; i <= hi; i++) {
            if (Math.abs(pts[i][0] - midX) < bestDist) {
                strip.add(pts[i]);
            }
        }
        strip.sort((a, b) -> nums2[a[1]] - nums2[b[1]]);

        for (int i = 0; i < strip.size(); i++) {
            for (int j = i + 1; j < strip.size(); j++) {
                if (nums2[strip.get(j)[1]] - nums2[strip.get(i)[1]] >= bestDist) break;
                update(strip.get(i)[1], strip.get(j)[1]);
            }
        }
    }

    private void update(int i, int j) {
        int a = Math.min(i, j), b = Math.max(i, j);
        int d = Math.abs(nums1[i] - nums1[j]) + Math.abs(nums2[i] - nums2[j]);
        if (d < bestDist || (d == bestDist && (a < bestPair[0] || (a == bestPair[0] && b < bestPair[1])))) {
            bestDist = d;
            bestPair = new int[]{a, b};
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log^2 N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分治求最近点对**：经典几何算法
2. **中间带处理**：按y排序后只比较距离<d的
3. **字典序最小**：同距离时比较下标对
