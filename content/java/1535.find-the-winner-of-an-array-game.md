## 题目描述

数组前两个比较，大的留前面小的去末尾。某个数连赢 k 轮即为赢家。

**示例：**
```
输入：arr = [2,1,3,5,4], k = 2
输出：5
```

## 解题思路

观察：若 k≥n-1，赢家必为最大值。否则模拟比较，维护当前冠军和连胜次数。

## Java 代码实现

```java
class Solution {
    public int getWinner(int[] arr, int k) {
        int winner = arr[0];
        int wins = 0;
        
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > winner) {
                winner = arr[i];
                wins = 1;
            } else {
                wins++;
            }
            if (wins == k) return winner;
        }
        return winner; // 遍历完说明 winner 是最大值
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **一次遍历**：不需要真正移动元素
2. **k≥n-1**：最大值一定会赢
3. **提前终止**：连胜达到 k 即返回
4. **遍历完未返回**：当前 winner 就是最大值
