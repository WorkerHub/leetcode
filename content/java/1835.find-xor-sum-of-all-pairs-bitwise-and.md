## 题目描述

两个数组所有数对(i,j)的arr1[i] AND arr2[j]的XOR总和。

## 解题思路

AND对XOR有分配律：⊕(arr1[i] AND arr2[j]) = (⊕arr1) AND (⊕arr2)。O(n+m)解决。

## Java 代码实现

```java
class Solution {
    public int getXORSum(int[] arr1, int[] arr2) {
        int xor1 = 0, xor2 = 0;
        for (int x : arr1) xor1 ^= x;
        for (int x : arr2) xor2 ^= x;
        return xor1 & xor2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(1)

## 关键点总结

1. **AND对XOR分配律**：(a⊕b)&c = (a&c)⊕(b&c)
2. **化简为两个全体XOR的AND**
3. **从O(NM)优化到O(N+M)**
