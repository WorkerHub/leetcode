## 题目描述

给定句子字符串 `sentence` 和模式字符串 `pattern`，重排 `sentence` 的单词使其满足 `pattern` 的同构模式（相同位置对应相同单词），返回任意合法结果，无法满足则返回空字符串。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String rearrangeSentence(String sentence, String pattern) {
        String[] sWords = sentence.split(" ");
        String[] pWords = pattern.split(" ");

        if (sWords.length != pWords.length) return "";

        // 双向映射：pattern单词 -> sentence单词，sentence单词 -> pattern单词
        Map<String, String> pToS = new HashMap<>();
        Map<String, String> sToP = new HashMap<>();

        for (int i = 0; i < sWords.length; i++) {
            String sw = sWords[i], pw = pWords[i];
            if (pToS.containsKey(pw) && !pToS.get(pw).equals(sw)) return "";
            if (sToP.containsKey(sw) && !sToP.get(sw).equals(pw)) return "";
            pToS.put(pw, sw);
            sToP.put(sw, pw);
        }

        // 按 pattern 顺序重构
        StringBuilder sb = new StringBuilder();
        for (String pw : pWords) {
            if (sb.length() > 0) sb.append(' ');
            sb.append(pToS.get(pw));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * L)，n 为单词数，L 为单词平均长度
- 空间复杂度：O(n)

## 关键点总结

1. 本质是同构字符串（isomorphic strings）的单词版，需要双向映射
2. 双向映射避免多对一（同一 sentence 单词对应不同 pattern 单词）
3. 按 pattern 顺序重构结果
