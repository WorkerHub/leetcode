## 题目描述

给定十六进制字符串 `s`，两位玩家轮流将某个字符替换为相邻的十六进制值，无法操作者输，先手玩家是否能赢？

## Java 代码实现

```java
class Solution {
    public boolean canWin(String s) {
        // Sprague-Grundy 定理：每个字符独立，Grundy 值为其十六进制整数值
        // 所有字符 Grundy 值异或不为 0 则先手赢
        int xorSum = 0;
        for (char c : s.toCharArray()) {
            int val = (c >= '0' && c <= '9') ? (c - '0') : (c - 'a' + 10);
            xorSum ^= val;
        }
        return xorSum != 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(1)

## 关键点总结

1. 每个字符的操作相互独立，可拆分为独立子游戏
2. Sprague-Grundy 定理：整体 Grundy 值 = 各字符 Grundy 值的异或
3. 每个字符的 Grundy 值等于其十六进制整数值（0-15），异或结果不为 0 则先手必赢
