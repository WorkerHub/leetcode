## 题目描述

Dota2 参议院由 Radiant 和 Dire 两个阵营组成，每个参议员可以禁止一名对方参议员的权利。预测哪一方获胜。

**示例：**
```
输入：senate = "RD"
输出："Radiant"
```

## 解题思路

贪心 + 双队列：索引小的先行动，禁掉对方后加入下一轮（索引+n）。

## Java 代码实现

```java
class Solution {
    public String predictPartyVictory(String senate) {
        int n = senate.length();
        Queue<Integer> radiant = new LinkedList<>();
        Queue<Integer> dire = new LinkedList<>();

        for (int i = 0; i < n; i++) {
            if (senate.charAt(i) == 'R') radiant.offer(i);
            else dire.offer(i);
        }

        while (!radiant.isEmpty() && !dire.isEmpty()) {
            int r = radiant.poll();
            int d = dire.poll();
            // 索引小的先行动，禁掉对方，自己进入下一轮
            if (r < d) {
                radiant.offer(r + n);
            } else {
                dire.offer(d + n);
            }
        }

        return radiant.isEmpty() ? "Dire" : "Radiant";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **双队列模拟**：分别存两个阵营的参议员索引
2. **索引小的先行动**：贪心策略
3. **+n 进入下一轮**：保证轮次顺序
