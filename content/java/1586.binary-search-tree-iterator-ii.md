## 题目描述

实现 BST 迭代器支持 next/prev/hasNext/hasPrev 双向遍历。

## 解题思路

中序遍历得到有序数组，用指针在数组上前后移动。

## Java 代码实现

```java
class BSTIterator {
    private List<Integer> nodes = new ArrayList<>();
    private int idx = -1;
    
    public BSTIterator(TreeNode root) {
        inorder(root);
    }
    
    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        nodes.add(node.val);
        inorder(node.right);
    }
    
    public boolean hasNext() {
        return idx + 1 < nodes.size();
    }
    
    public int next() {
        return nodes.get(++idx);
    }
    
    public boolean hasPrev() {
        return idx - 1 >= 0;
    }
    
    public int prev() {
        return nodes.get(--idx);
    }
}
```

## 复杂度分析

- **初始化**：O(n)
- **next/prev**：O(1)
- **空间**：O(n)

## 关键点总结

1. **中序遍历**：得到升序数组
2. **双向指针**：idx 前后移动
3. **初始 idx=-1**：表示还未开始
