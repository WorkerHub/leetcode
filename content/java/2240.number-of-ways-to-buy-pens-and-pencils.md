## 题目描述

用total金额购买cost1的钢笔和cost2的铅笔（各买任意数量含0），求总方案数。

## 解题思路

枚举钢笔数量i从0到total/cost1，每种情况铅笔可买0到(total-i*cost1)/cost2种，累加即可。

## Java 代码实现

```java
class Solution {
    public long waysToBuyPensPencils(int total, int cost1, int cost2) {
        long ans = 0;
        for (int i = 0; i * cost1 <= total; i++) {
            int remaining = total - i * cost1;
            ans += remaining / cost2 + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(total / cost1)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举一种，整除另一种**：避免二重循环
2. **+1不能遗漏**：包含买0支铅笔的情况
3. **将更贵的放外层**：减少循环次数
