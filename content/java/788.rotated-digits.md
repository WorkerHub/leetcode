## 题目描述

好数是旋转 180 度后能得到不同有效数字的数。0/1/8 不变，2↔5，6↔9，含 3/4/7 无效。返回 [1,n] 中好数的数量。

**示例：**
```
输入：n = 10
输出：4（好数为 2,5,6,9）
```

## 解题思路

逐位检查：包含 3/4/7 则无效，必须至少包含一个 2/5/6/9 才算好数。

## Java 代码实现

```java
class Solution {
    public int rotatedDigits(int n) {
        int count = 0;
        for (int i = 1; i <= n; i++) {
            if (isGood(i)) count++;
        }
        return count;
    }

    private boolean isGood(int num) {
        boolean hasDiff = false;
        while (num > 0) {
            int d = num % 10;
            if (d == 3 || d == 4 || d == 7) return false;
            if (d == 2 || d == 5 || d == 6 || d == 9) hasDiff = true;
            num /= 10;
        }
        return hasDiff;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **无效数字**：含 3/4/7 直接排除
2. **好数条件**：至少含一个 2/5/6/9
3. **逐位检查**：% 10 取末位，/ 10 去末位
