## 题目描述

设计食物评分系统，支持 `changeRating(food, newRating)` 更新评分，以及 `highestRated(cuisine)` 返回指定烹饪方式中评分最高（并列时字典序最小）的食物名称。

## 解题思路

维护两个映射：`foodInfo`（食物 -> (烹饪方式, 评分)）和 `cuisineHeap`（烹饪方式 -> 最小堆 `(-rating, food)`）。`changeRating` 向堆中加入新记录（懒删除旧记录）；`highestRated` 弹出失效的堆顶，返回有效堆顶的食物名。

## Java 代码实现

```java
import java.util.*;

class FoodRatings {
    private Map<String, int[]> foodInfo = new HashMap<>(); // food -> [rating, cuisineIdx]
    private Map<String, String> foodCuisine = new HashMap<>(); // food -> cuisine
    private Map<String, PriorityQueue<int[]>> cuisineHeap = new HashMap<>();
    // 堆元素：[-rating, foodHash] 但需要存 food 字符串，改用 Object[]
    private Map<String, PriorityQueue<Object[]>> heaps = new HashMap<>();

    public FoodRatings(String[] foods, String[] cuisines, int[] ratings) {
        for (int i = 0; i < foods.length; i++) {
            String food = foods[i], cuisine = cuisines[i];
            int rating = ratings[i];
            foodInfo.put(food, new int[]{rating});
            foodCuisine.put(food, cuisine);
            heaps.computeIfAbsent(cuisine, k -> new PriorityQueue<>((a, b) -> {
                int cmp = (int) b[0] - (int) a[0]; // 评分降序
                return cmp != 0 ? cmp : ((String) a[1]).compareTo((String) b[1]); // 字典序升序
            })).offer(new Object[]{rating, food});
        }
    }

    public void changeRating(String food, int newRating) {
        foodInfo.get(food)[0] = newRating; // 更新当前评分
        String cuisine = foodCuisine.get(food);
        heaps.get(cuisine).offer(new Object[]{newRating, food}); // 懒删除：加入新记录
    }

    public String highestRated(String cuisine) {
        PriorityQueue<Object[]> heap = heaps.get(cuisine);
        // 弹出失效的堆顶（评分已变更）
        while (true) {
            Object[] top = heap.peek();
            String food = (String) top[1];
            if ((int) top[0] == foodInfo.get(food)[0]) return food;
            heap.poll();
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：`changeRating` O(log n)；`highestRated` 均摊 O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 堆排序键为 `(-rating, food)`，评分降序、字典序升序，堆顶即最优食物。
2. 懒删除：`changeRating` 只加入新记录，`highestRated` 时弹出评分已变更的过期记录。
3. 用 `foodInfo` 维护每种食物的当前有效评分，判断堆顶是否过期。
