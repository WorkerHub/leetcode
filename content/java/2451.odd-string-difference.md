## 题目描述

给你等长字符串数组 `words`，每个字符串的**差值数组**定义为相邻字符的编码差。数组中恰好有一个字符串的差值数组与其他不同，返回该字符串。

## 解题思路

计算每个字符串的差值数组，用哈希表统计各差值数组出现次数，返回只出现一次的那个对应的字符串。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String oddString(String[] words) {
        Map<String, Integer> count = new HashMap<>();
        String[] diffs = new String[words.length];

        for (int i = 0; i < words.length; i++) {
            diffs[i] = getDiff(words[i]);
            count.merge(diffs[i], 1, Integer::sum);
        }

        // 找差值数组只出现一次的字符串
        for (int i = 0; i < words.length; i++) {
            if (count.get(diffs[i]) == 1) return words[i];
        }
        return "";
    }

    // 计算字符串的差值数组（转为字符串作为 key）
    private String getDiff(String word) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < word.length() - 1; i++) {
            if (sb.length() > 0) sb.append(',');
            sb.append(word.charAt(i + 1) - word.charAt(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)，m 为单词数，n 为单词长度
- **空间复杂度**：O(m × n)

## 关键点总结

1. 差值数组是相邻字符编码之差，序列化后作为哈希表的键
2. 只有一个字符串的差值不同，其余所有相同
3. 统计频次后找唯一的那个
