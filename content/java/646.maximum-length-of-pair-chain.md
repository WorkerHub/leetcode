## 题目描述

给你 n 个数对 `pairs[i] = [left_i, right_i]`，当 `b < c` 时 `[c,d]` 可以跟在 `[a,b]` 后面。返回最长数对链的长度。

**示例：**
```
输入：pairs = [[1,2],[2,3],[3,4]]
输出：2（[1,2] -> [3,4]）
```

## 解题思路

贪心：按第二个元素排序，类似区间调度问题，每次选结束时间最早的。

## Java 代码实现

```java
class Solution {
    public int findLongestChain(int[][] pairs) {
        // 按第二个元素排序
        Arrays.sort(pairs, (a, b) -> a[1] - b[1]);

        int count = 0;
        int currentEnd = Integer.MIN_VALUE;

        for (int[] pair : pairs) {
            if (pair[0] > currentEnd) {
                count++;
                currentEnd = pair[1];
            }
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **按结束时间排序**：贪心选择结束早的
2. **严格大于**：pair[0] > currentEnd（不是 >=）
3. **类似区间调度**：经典贪心问题
