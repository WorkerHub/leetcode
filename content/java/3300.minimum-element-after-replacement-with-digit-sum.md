## 题目描述

给你整数数组 `nums`，可对任意元素任意次替换为其数字和。返回可能得到的最小元素。

## 解题思路

对每个元素求一次数字和，与原值取最小，然后取所有结果的最小值即可（数字和 <= 原值，替换有益）。

## Java 代码实现

```java
class Solution {
    public int minElement(int[] nums) {
        int min = Integer.MAX_VALUE;
        for (int x : nums) {
            min = Math.min(min, Math.min(x, digitSum(x)));
        }
        return min;
    }

    private int digitSum(int n) {
        int s = 0;
        while (n > 0) {
            s += n % 10;
            n /= 10;
        }
        return s;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × log(max_val))
- 空间复杂度：O(1)

## 关键点总结

1. 数字和总是 <= 原值（对正整数），替换后值不增
2. 只需求一次数字和即可（题目数字和还可能 > 9，但只需一步即比原值小）
3. 结果为 min(原值, 数字和) 取全局最小
