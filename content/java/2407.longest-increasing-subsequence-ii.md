## 题目描述

给你整数数组 `nums` 和整数 `k`，返回严格递增且相邻元素差值不超过 k 的最长子序列长度。

## 解题思路

设 `dp[v]` 为以值 v 结尾的最长子序列长度，转移：`dp[v] = max(dp[v-k..v-1]) + 1`。用线段树在值域上维护区间最大值，每次 O(log M) 查询和更新，M 为最大值。

## Java 代码实现

```java
class Solution {
    private int[] tree;
    private int n;

    public int lengthOfLIS(int[] nums, int k) {
        n = 100001;
        tree = new int[4 * n];
        int ans = 0;
        for (int v : nums) {
            // 查询 [v-k, v-1] 的最大 dp 值
            int best = query(Math.max(1, v - k), v - 1, 1, 1, n);
            update(v, best + 1, 1, 1, n);
            ans = Math.max(ans, best + 1);
        }
        return ans;
    }

    private void update(int pos, int val, int node, int lo, int hi) {
        if (lo == hi) {
            tree[node] = Math.max(tree[node], val);
            return;
        }
        int mid = (lo + hi) / 2;
        if (pos <= mid) update(pos, val, 2 * node, lo, mid);
        else update(pos, val, 2 * node + 1, mid + 1, hi);
        tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
    }

    private int query(int l, int r, int node, int lo, int hi) {
        if (l > r) return 0;
        if (l <= lo && hi <= r) return tree[node];
        int mid = (lo + hi) / 2, res = 0;
        if (l <= mid) res = Math.max(res, query(l, r, 2 * node, lo, mid));
        if (r > mid) res = Math.max(res, query(l, r, 2 * node + 1, mid + 1, hi));
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)，M = 10^5
- **空间复杂度**：O(M)

## 关键点总结

1. 线段树在值域 [1, M] 上维护 dp 数组的区间最大值，而非下标。
2. 每次遇到值 v，查询 [v-k, v-1] 的最大 dp 值，更新 dp[v]。
3. 取 `max(1, v-k)` 防止左端点越界。
