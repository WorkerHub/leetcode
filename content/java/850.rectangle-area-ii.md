## 题目描述

给定矩形列表 rectangles[i] = [x1, y1, x2, y2]，计算所有矩形覆盖的总面积（对 10^9+7 取模）。

**示例：**
```
输入：rectangles = [[0,0,2,2],[1,0,2,3],[1,0,3,1]]
输出：6
```

## 解题思路

扫描线 + 坐标压缩：按 y 坐标扫描，维护每个 x 区间被覆盖的次数，逐层计算面积。

## Java 代码实现

```java
class Solution {
    public int rectangleArea(int[][] rectangles) {
        int MOD = 1_000_000_007;

        // 提取并排序所有 x 坐标
        TreeSet<Integer> xSet = new TreeSet<>();
        List<int[]> events = new ArrayList<>();

        for (int[] rect : rectangles) {
            xSet.add(rect[0]);
            xSet.add(rect[2]);
            events.add(new int[]{rect[1], rect[0], rect[2], 1});  // 开始
            events.add(new int[]{rect[3], rect[0], rect[2], -1}); // 结束
        }

        Integer[] xCoords = xSet.toArray(new Integer[0]);
        Map<Integer, Integer> xIndex = new HashMap<>();
        for (int i = 0; i < xCoords.length; i++) {
            xIndex.put(xCoords[i], i);
        }

        events.sort((a, b) -> a[0] - b[0]);
        int[] active = new int[xCoords.length];
        long area = 0;
        int prevY = 0;

        for (int[] event : events) {
            int y = event[0], x1 = event[1], x2 = event[2], delta = event[3];

            // 计算当前层的宽度
            long width = 0;
            for (int i = 0; i < xCoords.length - 1; i++) {
                if (active[i] > 0) {
                    width += xCoords[i + 1] - xCoords[i];
                }
            }
            area = (area + width * (y - prevY)) % MOD;

            // 更新活跃区间
            for (int i = xIndex.get(x1); i < xIndex.get(x2); i++) {
                active[i] += delta;
            }
            prevY = y;
        }

        return (int) area;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **扫描线**：按 y 坐标从下到上扫描
2. **坐标压缩**：离散化 x 坐标
3. **事件驱动**：矩形的进入和退出
