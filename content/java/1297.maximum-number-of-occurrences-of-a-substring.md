## 题目描述

返回满足条件的子串的最大出现次数：不同字母数 ≤ maxLetters，长度在 [minSize, maxSize] 之间。

**示例：**
```
输入：s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4
输出：2
解释：子串 "aab" 出现 2 次
```

## 解题思路

关键观察：只需检查长度 = minSize 的子串。长子串出现 k 次，其 minSize 前缀也至少出现 k 次。

## Java 代码实现

```java
class Solution {
    public int maxFreq(String s, int maxLetters, int minSize, int maxSize) {
        Map<String, Integer> count = new HashMap<>();
        int maxFreq = 0;
        
        for (int i = 0; i <= s.length() - minSize; i++) {
            String sub = s.substring(i, i + minSize);
            // 检查不同字母数
            Set<Character> chars = new HashSet<>();
            for (char c : sub.toCharArray()) chars.add(c);
            
            if (chars.size() <= maxLetters) {
                int freq = count.merge(sub, 1, Integer::sum);
                maxFreq = Math.max(maxFreq, freq);
            }
        }
        return maxFreq;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × minSize)
- **空间复杂度**：O(n × minSize)

## 关键点总结

1. **只检查 minSize**：长子串出现次数 ≤ 短子串出现次数
2. **滑动窗口**：固定长度遍历
3. **字母数限制**：用 Set 统计不同字母
