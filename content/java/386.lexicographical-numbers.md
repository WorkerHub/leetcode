## 题目描述

给你一个整数 `n`，按字典序返回范围 `[1, n]` 内所有整数。

你必须设计一个时间复杂度为 `O(n)` 且使用 `O(1)` 额外空间的算法。

**示例 1:**

```
输入：n = 13
输出：[1,10,11,12,13,2,3,4,5,6,7,8,9]
```

**示例 2:**

```
输入：n = 2
输出：[1,2]
```

**提示:**

- `1 <= n <= 5 * 10^4`

## 解题思路

**字典序（Lexicographical Order）** 是按照字符串的字典顺序排列，而不是数值大小。

例如：`1, 10, 11, ..., 19, 2, 20, 21, ...`

### 核心思想

**观察规律：**

字典序的遍历类似于**十叉树的深度优先搜索（DFS）**：

```
        1           2           3    ...    9
      /   \
    10    11  ...  19
   / \
 100 101 ... 109
```

**遍历规则：**

1. 从 1 开始
2. 尽可能向下（乘以 10）：`1 -> 10 -> 100 -> 1000 ...`
3. 如果不能向下，向右（加 1）：`1000 -> 1001`
4. 如果不能向右，回退到上一层再向右

### 迭代算法

```
current = 1
while result.length < n:
    add current to result
    
    if current * 10 <= n:
        current = current * 10  # 向下
    else:
        # 不能向下，需要向右或回退
        while current % 10 == 9 or current + 1 > n:
            current = current / 10  # 回退
        current += 1  # 向右
```

## Java 代码实现

### 方法一：迭代模拟（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> result = new ArrayList<>();
        int current = 1;

        for (int i = 0; i < n; i++) {
            result.add(current);

            // 尝试向下（乘以 10）
            if (current * 10 <= n) {
                current *= 10;
            } else {
                // 不能向下，需要向右或回退
                // 如果当前数以 9 结尾或者 +1 会超过 n，需要回退
                while (current % 10 == 9 || current + 1 > n) {
                    current /= 10;
                }
                current++;
            }
        }

        return result;
    }
}
```

### 方法二：递归 DFS（直观）

```java
import java.util.*;

class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> result = new ArrayList<>();

        // 从 1-9 开始
        for (int i = 1; i <= 9 && i <= n; i++) {
            dfs(i, n, result);
        }

        return result;
    }

    /** 递归深度优先搜索，时间复杂度: O(n)，空间复杂度: O(log n) */
    private void dfs(int current, int n, List<Integer> result) {
        if (current > n) {
            return;
        }

        result.add(current);

        // 尝试向下（添加 0-9）
        for (int i = 0; i <= 9; i++) {
            int next = current * 10 + i;
            if (next > n) {
                break;
            }
            dfs(next, n, result);
        }
    }
}
```

### 方法三：排序（不推荐，不满足 O(1) 空间要求）

```java
import java.util.*;

class Solution {
    public List<Integer> lexicalOrder(int n) {
        // 将数字转换为字符串后排序
        // 时间复杂度: O(n log n)
        // 空间复杂度: O(n) - 字符串转换
        List<Integer> nums = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            nums.add(i);
        }
        // 按字符串形式的字典序排序
        nums.sort((a, b) -> String.valueOf(a).compareTo(String.valueOf(b)));
        return nums;
    }
}
```

## 复杂度分析

### 方法一：迭代

**时间复杂度：** O(n)
- 恰好生成 n 个数字，每个数字处理 O(1) 时间

**空间复杂度：** O(1)
- 不算结果数组，只使用常数额外空间
- 满足题目要求

### 方法二：递归

**时间复杂度：** O(n)
- 每个数字访问一次

**空间复杂度：** O(log n)
- 递归调用栈的深度最多为数字的位数
- 不满足 O(1) 空间要求

## 关键点总结

1. **字典序规律**：按字符串排序，不是数值排序
2. **十叉树模型**：问题可以建模为十叉树的 DFS 遍历
3. **迭代实现**：通过规则模拟 DFS，避免递归栈空间
4. **向下优先**：优先 `current * 10`，尽可能深入
5. **回退条件**：当前数以 9 结尾或 +1 超过 n 时需要回退

## 易错点

1. **起始数字**：从 1 开始，不是 0
2. **回退逻辑**：需要同时检查 `current % 10 == 9` 和 `current + 1 > n`
3. **边界处理**：n = 1 的情况
4. **理解字典序**：10 在字典序中排在 2 前面
5. **空间复杂度**：递归方法不满足 O(1) 要求
