## 题目描述

给你一个 `m x n` 的矩阵 `mat`（相邻元素均不相等），返回任意一个峰值元素的位置 `[i, j]`（严格大于上下左右相邻元素）。

## 解题思路

对行二分：取中间行 mid，找该行最大值所在列 maxCol，比较与下一行同列的值——若大于则峰值在上半部分（含 mid），否则在下半部分。收敛到最终行后该行最大值即为峰值。

## Java 代码实现

```java
class Solution {
    public int[] findPeakGrid(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int lo = 0, hi = m - 1;

        while (lo < hi) {
            int mid = (lo + hi) / 2;
            // 找当前行的最大值所在列
            int maxCol = 0;
            for (int j = 0; j < n; j++) {
                if (mat[mid][j] > mat[mid][maxCol]) maxCol = j;
            }
            // 比较与下一行同列的值
            if (mat[mid][maxCol] > mat[mid + 1][maxCol]) {
                hi = mid; // 峰值在上半部分（含 mid）
            } else {
                lo = mid + 1; // 峰值在下半部分
            }
        }

        // 找最终行的最大值列
        int maxCol = 0;
        for (int j = 0; j < n; j++) {
            if (mat[lo][j] > mat[lo][maxCol]) maxCol = j;
        }
        return new int[]{lo, maxCol};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log m)
- **空间复杂度**：O(1)

## 关键点总结

1. 将二维峰值查找转化为对行的二分查找
2. 中间行找列最大值后，通过上下比较确定二分方向
3. 收敛到最终行后，该行列最大值即为峰值
