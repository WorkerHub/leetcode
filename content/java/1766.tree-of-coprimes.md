## 题目描述

给你 n 个节点的树（根为 0），每个节点有值（1-50）。对每个节点找离它最近的祖先（不含自身），使该祖先值与当前节点值互质，返回结果数组（不存在则返回 -1）。

## 解题思路

预计算 1-50 中所有互质对。DFS 遍历树，维护路径上每种值的节点栈（存节点编号和深度），对每个节点枚举互质值，在对应栈顶取深度最大的即为最近祖先。回溯时出栈。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] ans;
    private int[] nums;
    private List<Integer>[] graph;
    // coprimes[v] = 与 v 互质的所有值列表
    private List<Integer>[] coprimes;
    // path[v] = 当前路径上值为 v 的节点列表（存 [节点编号, 深度]）
    private Deque<int[]>[] path;

    @SuppressWarnings("unchecked")
    public int[] getCoprimes(int[] nums, int[][] edges) {
        int n = nums.length;
        this.nums = nums;
        this.ans = new int[n];
        Arrays.fill(ans, -1);

        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        // 预计算互质对
        coprimes = new List[51];
        for (int i = 1; i <= 50; i++) {
            coprimes[i] = new ArrayList<>();
            for (int j = 1; j <= 50; j++) {
                if (gcd(i, j) == 1) coprimes[i].add(j);
            }
        }

        path = new Deque[51];
        for (int i = 1; i <= 50; i++) path[i] = new ArrayDeque<>();

        dfs(0, -1, 0);
        return ans;
    }

    private void dfs(int node, int parent, int depth) {
        int val = nums[node];
        // 找最近互质祖先：枚举与 val 互质的值，取深度最大的
        int bestDepth = -1, bestNode = -1;
        for (int v : coprimes[val]) {
            if (!path[v].isEmpty()) {
                int[] top = path[v].peek();
                if (top[1] > bestDepth) {
                    bestDepth = top[1];
                    bestNode = top[0];
                }
            }
        }
        ans[node] = bestNode;

        // 将当前节点压入路径
        path[val].push(new int[]{node, depth});

        for (int neighbor : graph[node]) {
            if (neighbor != parent) dfs(neighbor, node, depth + 1);
        }

        // 回溯
        path[val].pop();
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 50)
- **空间复杂度**：O(n + 50^2)

## 关键点总结

1. 预计算互质对，每个节点只需枚举至多 50 个互质值
2. 路径栈记录每种值的祖先，取最深的即为最近互质祖先
3. DFS 回溯时出栈
