## 题目描述

有令牌数组和初始能量 power。花费 tokens[i] 能量得 1 分，或花 1 分获得 tokens[i] 能量。每个令牌最多用一次，求最大分数。

## 解题思路

排序 + 双指针贪心：花最少能量换分数（左端），花分数换最多能量（右端）。

## Java 代码实现

```java
class Solution {
    public int bagOfTokensScore(int[] tokens, int power) {
        Arrays.sort(tokens);
        int left = 0, right = tokens.length - 1;
        int score = 0, maxScore = 0;

        while (left <= right) {
            if (power >= tokens[left]) {
                // 花能量换分数（选最小的）
                power -= tokens[left++];
                score++;
                maxScore = Math.max(maxScore, score);
            } else if (score > 0) {
                // 花分数换能量（选最大的）
                power += tokens[right--];
                score--;
            } else {
                break;
            }
        }

        return maxScore;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序 + 双指针**：贪心选择最优交换
2. **花最小换分**：从左端消费
3. **花分换最大能量**：从右端获取
