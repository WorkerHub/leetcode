## 题目描述

给定 m×n 矩阵，每行递增排序，找出所有行的最小公共元素。无公共元素返回 -1。

**示例：**
```
输入：mat = [[1,2,3,4,5],[2,4,5,8,10],[3,5,7,9,11],[1,3,5,7,9]]
输出：5
```

## 解题思路

方法一：计数法，统计每个元素出现行数，找等于 m 的最小值。方法二：遍历第一行每个元素，在其他行二分查找。

## Java 代码实现

### 方法一：计数

```java
class Solution {
    public int smallestCommonElement(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[] count = new int[10001];
        
        for (int[] row : mat) {
            for (int num : row) {
                count[num]++;
            }
        }
        
        for (int i = 1; i <= 10000; i++) {
            if (count[i] == m) return i;
        }
        return -1;
    }
}
```

### 方法二：二分查找

```java
class Solution {
    public int smallestCommonElement(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        
        for (int num : mat[0]) {
            boolean found = true;
            for (int i = 1; i < m; i++) {
                int idx = Arrays.binarySearch(mat[i], num);
                if (idx < 0) {
                    found = false;
                    break;
                }
            }
            if (found) return num;
        }
        return -1;
    }
}
```

## 复杂度分析

- **方法一**：时间 O(m*n)，空间 O(max_val)
- **方法二**：时间 O(n * m * log n)，空间 O(1)

## 关键点总结

1. **计数法**：值域有限时直接用数组计数最高效
2. **二分查找**：利用行有序特性，第一行遍历+其他行二分
3. **从小到大遍历**：第一个满足条件的就是最小公共元素
