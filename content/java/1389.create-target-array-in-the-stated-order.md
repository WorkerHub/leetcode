## 题目描述

按给定顺序在目标数组的指定下标处插入元素，返回最终的目标数组。

## 解题思路

模拟：使用ArrayList的add(index, value)方法，在指定位置插入元素，后续元素自动后移。

## Java 代码实现

```java
class Solution {
    public int[] createTargetArray(int[] nums, int[] index) {
        List<Integer> target = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            // 在index[i]位置插入nums[i]
            target.add(index[i], nums[i]);
        }
        return target.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)，每次插入最坏移动O(N)个元素
- **空间复杂度**：O(N)

## 关键点总结

1. **ArrayList.add(index, value)**：在指定位置插入
2. **后续元素自动右移**：无需手动处理
3. **数据范围小(n<=100)**：O(N^2)可行
