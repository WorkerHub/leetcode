## 题目描述

给你一个整数数组 `nums`，其中包含 n-2 个普通数、一个特殊数和一个异常值。规则：n-2 个普通数的和等于特殊数，找出最大的异常值。

## 解题思路

设总和为 `total`，推导公式：`total - S - O = S`，即 `O = total - 2*S`。枚举每个数作为特殊数 S，计算对应异常值 O，检验 O 是否在数组中，取所有合法 O 中的最大值。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int getLargestOutlier(int[] nums) {
        // 统计每个值的出现次数
        Map<Integer, Integer> cnt = new HashMap<>();
        int total = 0;
        for (int x : nums) {
            total += x;
            cnt.merge(x, 1, Integer::sum);
        }

        int ans = Integer.MIN_VALUE;
        // 枚举每个不同的值作为特殊数 S
        for (int S : cnt.keySet()) {
            int O = total - 2 * S; // 计算异常值
            if (cnt.containsKey(O)) {
                // O != S 或数组中有至少两个 S
                if (O != S || cnt.get(O) >= 2) {
                    ans = Math.max(ans, O);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表构建 + 枚举
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 公式推导：`O = total - 2 * S`。
2. 枚举每个数作为特殊数 S，计算对应的异常值 O。
3. `O == S` 时，需要数组中有至少两个该值（一个作为 S，一个作为 O）。
