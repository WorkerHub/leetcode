## 题目描述

与 3069 相同的分配规则，但判断条件改为：arr1 中严格大于 nums[i] 的元素个数 > arr2 中的则追加到 arr1，否则追加到 arr2（n 最大 10^5）。

## 解题思路

用树状数组（Fenwick Tree）+ 坐标压缩，对每个新元素快速查询两个数组中大于它的元素个数，维护两个 BIT 分别记录 arr1 和 arr2 的元素分布。

## Java 代码实现

```java
class Solution {
    int[] tree1, tree2;
    int m;

    public int[] resultArray(int[] nums) {
        int n = nums.length;
        // 坐标压缩
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        sorted = Arrays.stream(sorted).distinct().toArray();
        m = sorted.length;
        tree1 = new int[m + 1];
        tree2 = new int[m + 1];

        List<Integer> arr1 = new ArrayList<>(), arr2 = new ArrayList<>();
        arr1.add(nums[0]); arr2.add(nums[1]);
        update(tree1, rank(sorted, nums[0]));
        update(tree2, rank(sorted, nums[1]));

        for (int i = 2; i < n; i++) {
            int r = rank(sorted, nums[i]);
            // 大于 nums[i] 的元素数 = 总数 - 小于等于 nums[i] 的元素数
            int cnt1 = arr1.size() - query(tree1, r);
            int cnt2 = arr2.size() - query(tree2, r);
            if (cnt1 > cnt2) { arr1.add(nums[i]); update(tree1, r); }
            else { arr2.add(nums[i]); update(tree2, r); }
        }

        int[] res = new int[n];
        int idx = 0;
        for (int x : arr1) res[idx++] = x;
        for (int x : arr2) res[idx++] = x;
        return res;
    }

    private int rank(int[] sorted, int val) {
        return Arrays.binarySearch(sorted, val) + 1; // 1-indexed
    }

    private void update(int[] tree, int i) {
        for (; i <= m; i += i & (-i)) tree[i]++;
    }

    private int query(int[] tree, int i) {
        int s = 0;
        for (; i > 0; i -= i & (-i)) s += tree[i];
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，树状数组每次操作 O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 需要动态维护有序集合，支持快速查询大于某值的元素个数
2. 树状数组 + 离散化是经典组合
3. 比较的是"严格大于"：大于数量 = 总数 - 小于等于数量（bisect_right 等价）
