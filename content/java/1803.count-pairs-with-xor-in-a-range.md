## 题目描述

给你整数数组 `nums` 和整数 `low`、`high`，返回满足 `low <= nums[i] XOR nums[j] <= high` 的漂亮数对 (i < j) 数目。

## 解题思路

转化为两次前缀查询：`countLess(high+1) - countLess(low)`。

字典树（Trie）从高位到低位构建，每个节点维护经过的数字个数。逐个插入 nums，每次插入前查询已有数中与当前数 XOR 严格小于 limit 的个数。

## Java 代码实现

```java
class Solution {
    // 字典树节点：children[0/1] 和经过计数
    private int[][] children = new int[300001][2];
    private int[] cnt = new int[300001];
    private int trieSize = 1;

    public int countPairs(int[] nums, int low, int high) {
        int result = 0;
        for (int num : nums) {
            result += countLess(num, high + 1) - countLess(num, low);
            insert(num);
        }
        return result;
    }

    private void insert(int num) {
        int node = 0;
        for (int i = 14; i >= 0; i--) { // 最多 15 位（2*10^4 < 2^15）
            int bit = (num >> i) & 1;
            if (children[node][bit] == 0) {
                children[node][bit] = trieSize++;
            }
            node = children[node][bit];
            cnt[node]++;
        }
    }

    // 统计已插入的数与 num XOR 后严格小于 limit 的数量
    private int countLess(int num, int limit) {
        int node = 0, result = 0;
        for (int i = 14; i >= 0; i--) {
            int numBit = (num >> i) & 1;
            int limBit = (limit >> i) & 1;
            if (limBit == 1) {
                // XOR 该位为 0 时结果一定更小，累加该方向计数
                int same = children[node][numBit]; // XOR=0 方向
                if (same != 0) result += cnt[same];
                // 继续走 XOR=1 方向
                int diff = children[node][1 - numBit];
                if (diff == 0) break;
                node = diff;
            } else {
                // 只能走 XOR=0 方向
                int same = children[node][numBit];
                if (same == 0) break;
                node = same;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 15) = O(n log max_val)
- **空间复杂度**：O(n * 15)

## 关键点总结

1. 区间查询转两次前缀查询：`[low, high]` = `countLess(high+1) - countLess(low)`
2. 字典树每个节点维护经过数字个数，查询时若 limit 当前位为 1 可直接累加同侧计数
3. 逐个插入保证每对数对只统计一次
