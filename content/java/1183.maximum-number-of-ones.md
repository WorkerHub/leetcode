## 题目描述

给定 `width x height` 的矩阵，约束任意 `sideLength x sideLength` 子矩阵中最多 `maxOnes` 个 1。求整个矩阵最多能有多少个 1。

**示例：**
```
输入: width = 3, height = 3, sideLength = 2, maxOnes = 1
输出: 4
```

## 解题思路

矩阵按 sideLength 分块，每个位置 `(i%s, j%s)` 在整个矩阵中重复出现。计算每个块内位置的覆盖次数，贪心选择覆盖次数最多的 maxOnes 个位置放 1。

## Java 代码实现

```java
class Solution {
    public int maximumNumberOfOnes(int width, int height, int sideLength, int maxOnes) {
        int s = sideLength;
        int[] counts = new int[s * s];
        int idx = 0;
        
        for (int r = 0; r < s; r++) {
            for (int c = 0; c < s; c++) {
                // 位置(r,c)在整个矩阵中出现的次数
                int rowCount = (height - r + s - 1) / s;
                int colCount = (width - c + s - 1) / s;
                counts[idx++] = rowCount * colCount;
            }
        }
        
        // 降序排序，选前 maxOnes 个
        Arrays.sort(counts);
        int result = 0;
        for (int i = counts.length - 1; i >= counts.length - maxOnes; i--) {
            result += counts[i];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(s² * log(s²))，s = sideLength
- **空间复杂度**：O(s²)

## 关键点总结

1. **分块思想**：矩阵按 sideLength 平铺，位置通过取模映射
2. **覆盖次数**：`ceil((height-r)/s) * ceil((width-c)/s)`
3. **贪心**：选覆盖次数最多的位置放 1，总数最大
4. **向上取整**：`(a + b - 1) / b`
