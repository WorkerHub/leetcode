## 题目描述

给你整数数组 `nums` 和整数 `k`，找某个连续子数组的按位 OR 值与 `k` 的绝对差最小，返回该最小绝对差。

## 解题思路

固定右端点 r，随左端点 l 右移，OR 值单调不增。对每个右端点，维护所有不同 OR 值的集合（至多 30 个，因 32 位整数每次至少多一个 1 位），并更新最小绝对差。

## Java 代码实现

```java
class Solution {
    public int minimumDifference(int[] nums, int k) {
        int ans = Integer.MAX_VALUE;
        // 维护以当前位置结尾的所有不同 OR 值
        Set<Integer> prev = new HashSet<>();

        for (int x : nums) {
            Set<Integer> curr = new HashSet<>();
            curr.add(x); // 长度为 1 的子数组
            for (int v : prev) {
                curr.add(v | x);
            }
            // 统计所有 OR 值与 k 的差
            for (int v : curr) {
                ans = Math.min(ans, Math.abs(v - k));
            }
            prev = curr;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 30) = O(n)
- **空间复杂度**：O(30) = O(1)

## 关键点总结

1. 固定右端点，不同 OR 值至多 30 个（32 位整数位数上限）
2. 每步将前一步所有 OR 值与当前元素做 OR，加上当前元素本身
3. 枚举所有 OR 值与 k 的差取最小
