## 题目描述

给你一个字符串 `s`，统计满足以下条件的子字符串数量：是回文串，或者恰好改变一个字符后可以变为回文串。

## 解题思路

中心扩展法：对每个中心扩展时统计首尾不匹配的对数。不匹配对数为 0（已是回文）或 1（改一个字符）时计入答案，超过 1 时停止扩展。

## Java 代码实现

```java
class Solution {
    public int countPalindromes(String s) {
        int n = s.length(), count = 0;
        // 奇数长度子串（每个字符本身单独计）
        count += n;
        for (int i = 0; i < n; i++) {
            count += expand(s, n, i - 1, i + 1);
        }
        // 偶数长度子串
        for (int i = 0; i < n - 1; i++) {
            count += expand(s, n, i, i + 1);
        }
        return count;
    }

    private int expand(String s, int n, int left, int right) {
        int cnt = 0, mismatches = 0;
        while (left >= 0 && right < n) {
            if (s.charAt(left) != s.charAt(right)) mismatches++;
            if (mismatches <= 1) cnt++;
            else break;
            left--; right++;
        }
        return cnt;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(1)

## 关键点总结

1. "至多改变一个字符成为回文"等价于首尾不匹配对数 <= 1
2. 中心扩展统计不匹配对数，超过 1 时停止
3. 单字符子串始终是回文，单独加入计数
