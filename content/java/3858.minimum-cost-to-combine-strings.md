## 题目描述

给你一个字符串数组 `strs`，每次操作可以将任意两个字符串拼接，代价为两个字符串长度之和。返回合并所有字符串的最小总代价。

## 解题思路

等价于哈夫曼编码问题：每次合并两个最短的字符串可使总代价最小。使用最小堆（优先队列），每次取出两个最小长度合并，将新长度重新入堆。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long minimumCost(String[] strs) {
        // 将所有字符串长度加入最小堆
        PriorityQueue<Long> heap = new PriorityQueue<>();
        for (String s : strs) {
            heap.offer((long) s.length());
        }

        long totalCost = 0;
        while (heap.size() > 1) {
            // 取最短的两个字符串合并
            long a = heap.poll();
            long b = heap.poll();
            long cost = a + b;
            totalCost += cost;
            heap.offer(cost);
        }
        return totalCost;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次堆操作 O(log n)，共 n-1 次合并
- 空间复杂度：O(n)，堆

## 关键点总结

1. 最小代价合并 = 哈夫曼编码贪心：每次合并两个最短的。
2. 只需记录长度，不需要实际拼接字符串。
3. 合并后的长度也要入堆等待后续合并。
