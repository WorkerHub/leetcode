## 题目描述

给定一个二叉树（具有根结点 root）， 一个目标结点 target ，和一个整数值 k 。

返回到目标结点 target 距离为 k 的所有结点的值的列表。 答案可以以 任何顺序 返回。

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2
输出：[7,4,1]
解释：所求结点为与目标结点（值为 5）距离为 2 的结点，值分别为 7，4，以及 1
```

**提示：**
- 节点数在 [1, 500] 范围内
- 0 <= Node.val <= 500
- Node.val 中所有值 不同
- 目标结点 target 是树上的结点
- 0 <= k <= 1000

## 解题思路

这道题的难点是二叉树中**没有父指针**，无法直接向上查找。

**解法思路：**
1. **建立父指针映射**：DFS 遍历树，记录每个节点的父节点
2. **BFS 从目标节点扩散**：把树看作无向图，从 target 开始 BFS
3. **距离为 k 的节点**：BFS 第 k 层的所有节点

**关键步骤：**
1. 先遍历树，建立 `parent` 字典
2. 从 target 开始 BFS，访问子节点和父节点
3. 使用 visited 避免重复访问
4. BFS 到第 k 层时返回结果

## Java 代码实现

### 方法一：父指针 + BFS（推荐）

```java
class Solution {
    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
        // 步骤1：建立父指针映射
        Map<Integer, TreeNode> parent = new HashMap<>();
        buildParent(root, null, parent);

        // 步骤2：从 target 开始 BFS
        Queue<TreeNode> queue = new ArrayDeque<>();
        Set<Integer> visited = new HashSet<>();
        queue.offer(target);
        visited.add(target.val);
        int distance = 0;

        while (!queue.isEmpty()) {
            if (distance == k) {
                List<Integer> result = new ArrayList<>();
                for (TreeNode node : queue) {
                    result.add(node.val);
                }
                return result;
            }

            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();

                // 访问左子节点
                if (node.left != null && !visited.contains(node.left.val)) {
                    visited.add(node.left.val);
                    queue.offer(node.left);
                }

                // 访问右子节点
                if (node.right != null && !visited.contains(node.right.val)) {
                    visited.add(node.right.val);
                    queue.offer(node.right);
                }

                // 访问父节点
                TreeNode par = parent.get(node.val);
                if (par != null && !visited.contains(par.val)) {
                    visited.add(par.val);
                    queue.offer(par);
                }
            }

            distance++;
        }

        return new ArrayList<>();
    }

    private void buildParent(TreeNode node, TreeNode par, Map<Integer, TreeNode> parent) {
        if (node == null) return;
        parent.put(node.val, par);
        buildParent(node.left, node, parent);
        buildParent(node.right, node, parent);
    }
}
```

**代码说明：**
- 先用 DFS 建立父指针映射
- 再用 BFS 从 target 向四周（左子、右子、父节点）扩散
- 使用 visited 避免重复访问

### 方法二：构建图 + BFS

```java
class Solution {
    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
        // 构建无向图（邻接表）
        Map<Integer, List<Integer>> graph = new HashMap<>();
        buildGraph(root, graph);

        // BFS
        Queue<Integer> queue = new ArrayDeque<>();
        Set<Integer> visited = new HashSet<>();
        queue.offer(target.val);
        visited.add(target.val);
        int distance = 0;

        while (!queue.isEmpty()) {
            if (distance == k) {
                return new ArrayList<>(queue);
            }
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int nodeVal = queue.poll();
                for (int neighbor : graph.getOrDefault(nodeVal, new ArrayList<>())) {
                    if (!visited.contains(neighbor)) {
                        visited.add(neighbor);
                        queue.offer(neighbor);
                    }
                }
            }
            distance++;
        }

        return new ArrayList<>();
    }

    private void buildGraph(TreeNode node, Map<Integer, List<Integer>> graph) {
        if (node == null) return;
        if (node.left != null) {
            graph.computeIfAbsent(node.val, x -> new ArrayList<>()).add(node.left.val);
            graph.computeIfAbsent(node.left.val, x -> new ArrayList<>()).add(node.val);
            buildGraph(node.left, graph);
        }
        if (node.right != null) {
            graph.computeIfAbsent(node.val, x -> new ArrayList<>()).add(node.right.val);
            graph.computeIfAbsent(node.right.val, x -> new ArrayList<>()).add(node.val);
            buildGraph(node.right, graph);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历所有节点。
- **空间复杂度**：O(n)，parent 映射或图。

## 关键点总结

1. **父指针映射**：DFS 建立父子关系
2. **转化为无向图**：可以向上也可以向下
3. **BFS 层次遍历**：距离等于层数
4. **visited 去重**：避免重复访问
5. **多种解法**：父指针、图都可以

## 易错点

1. **忘记检查 parent(node) 是否为 null**：根节点的父节点是 null
2. **visited 时机**：加入队列时就标记，不是出队列时
3. **距离计数**：是边的数量，不是节点数量
