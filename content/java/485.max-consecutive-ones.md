## 题目描述

给定一个二进制数组 nums，计算其中最大连续 1 的个数。

**示例 1：**
```
输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头的两个数字和最后的三个数字都是连续 1，所以最大连续 1 的个数是 3。
```

**示例 2：**
```
输入：nums = [1,0,1,1,0,1]
输出：2
```

**提示：**
- 1 <= nums.length <= 10^5
- nums[i] 不是 0 就是 1

## 解题思路

这是一道简单的数组遍历题目，核心思想是：

1. **一次遍历**：
   - 遍历数组，统计连续 1 的个数
   - 遇到 0 时重置计数器
   - 记录过程中的最大值

2. **双指针**（可选）：
   - 左指针标记连续 1 的起始位置
   - 右指针向前扫描
   - 遇到 0 时计算长度并更新最大值

3. **状态维护**：
   - 当前连续 1 的个数
   - 历史最大连续 1 的个数

## Java 代码实现

### 方法一：一次遍历（推荐）

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 一次遍历统计最大连续 1 的个数
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxCount = 0;     // 最大连续 1 的个数
        int currentCount = 0; // 当前连续 1 的个数

        for (int num : nums) {
            if (num == 1) {
                // 遇到 1，增加当前计数
                currentCount++;
                // 更新最大值
                maxCount = Math.max(maxCount, currentCount);
            } else {
                // 遇到 0，重置当前计数
                currentCount = 0;
            }
        }

        return maxCount;
    }
}
```

### 方法二：按段统计（Java 风格）

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 遇到 0 时统计当前段长度并更新最大值
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxLen = 0;
        int segStart = -1; // 当前连续 1 段的起始索引（-1 表示未开始）

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) {
                if (segStart == -1) segStart = i; // 记录段的起始位置
                maxLen = Math.max(maxLen, i - segStart + 1);
            } else {
                segStart = -1; // 重置段起始位置
            }
        }

        return maxLen;
    }
}
```

### 方法三：双指针

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 使用双指针找连续 1 的区间
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxLen = 0;
        int i = 0;
        int n = nums.length;

        while (i < n) {
            if (nums[i] == 1) {
                // 找到 1 的起始位置
                int j = i;
                // 向右扩展
                while (j < n && nums[j] == 1) {
                    j++;
                }
                // 更新最大长度
                maxLen = Math.max(maxLen, j - i);
                // 移动到下一个可能的起始位置
                i = j;
            } else {
                i++;
            }
        }

        return maxLen;
    }
}
```

### 方法四：分组统计

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 分组统计，找到每段连续 1 的长度
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxLen = 0;
        int i = 0;
        int n = nums.length;

        while (i < n) {
            int j = i;
            // 跳过连续相同的元素，统计长度
            while (j < n && nums[j] == nums[i]) {
                j++;
            }
            // 只关心值为 1 的组
            if (nums[i] == 1) {
                maxLen = Math.max(maxLen, j - i);
            }
            i = j;
        }

        return maxLen;
    }
}
```

### 方法五：简洁版

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 最简洁的实现
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxCount = 0, count = 0;

        for (int num : nums) {
            count = (num == 1) ? count + 1 : 0;
            maxCount = Math.max(maxCount, count);
        }

        return maxCount;
    }
}
```

## 复杂度分析

**方法一、三、四、五：**
- **时间复杂度**：O(n)
  - 遍历数组一次
  
- **空间复杂度**：O(1)
  - 只使用常数额外空间

**方法二：**
- **时间复杂度**：O(n)
  - 需要遍历数组
  
- **空间复杂度**：O(1)
  - 只使用常数额外空间

## 关键点总结

1. **状态维护**：维护当前连续计数和最大计数
2. **重置时机**：遇到 0 时重置当前计数
3. **更新时机**：遇到 1 时更新最大值
4. **边界处理**：空数组、全 0、全 1 的情况
5. **简洁代码**：使用三元表达式简化逻辑

## 易错点

1. **忘记更新最大值**
   - 每次遇到 1 都要检查是否需要更新最大值
   - 不能只在遇到 0 时更新

2. **边界情况**
   - 数组以连续 1 结尾时，要确保最后的计数被考虑
   - 方法一在循环中实时更新最大值，避免了这个问题

3. **空数组**
   - nums = [] 时应返回 0
   - 初始化 maxCount = 0 可以处理

4. **全 1 数组**
   - nums = [1,1,1,1] 应返回 4
   - 确保最大值在循环中正确更新

5. **全 0 数组**
   - nums = [0,0,0] 应返回 0
   - 初始化 maxCount = 0 可以处理
