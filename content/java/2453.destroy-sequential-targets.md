## 题目描述

给你正整数数组 `nums` 和整数 `space`，机器以 seed `s` 可摧毁所有位于 `s, s+space, s+2*space, ...` 的目标。返回能摧毁最多目标的最小整数 seed。

## 解题思路

seed `s` 能摧毁所有 `num % space == s % space` 的目标。用哈希表按余数分组，统计各组大小，找最大组中最小的 `num` 即为答案。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int destroyTargets(int[] nums, int space) {
        // count[r] = 余数为 r 的元素个数
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : nums) {
            int r = x % space;
            count.merge(r, 1, Integer::sum);
        }

        int maxCount = 0;
        for (int c : count.values()) maxCount = Math.max(maxCount, c);

        // 在所有 nums 中，找余数组大小等于 maxCount 且值最小的
        int ans = Integer.MAX_VALUE;
        for (int x : nums) {
            if (count.get(x % space) == maxCount) {
                ans = Math.min(ans, x);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. seed `s` 能摧毁所有 `num % space == s % space` 的目标
2. 按余数分组统计，找最大组
3. 最大组中取最小的 `num` 作为 seed（不是最小的余数）
