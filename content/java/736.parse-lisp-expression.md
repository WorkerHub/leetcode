## 题目描述

给定一个类似 Lisp 语句的字符串表达式，求出其计算结果。支持 let、add、mult 操作。

**示例：**
```
输入：expression = "(let x 2 (mult x (let x 3 y 4 (add x y))))"
输出：14
```

## 解题思路

递归解析：分词后根据操作符类型递归计算。let 表达式需要维护变量作用域。

## Java 代码实现

```java
class Solution {
    private int pos;

    public int evaluate(String expression) {
        pos = 0;
        return parse(expression, new HashMap<>());
    }

    private int parse(String expr, Map<String, Integer> scope) {
        if (expr.charAt(pos) == '(') {
            pos++; // 跳过 '('
            int result;

            if (expr.startsWith("let", pos)) {
                pos += 4; // 跳过 "let "
                Map<String, Integer> newScope = new HashMap<>(scope);

                while (true) {
                    // 判断是否为最后一个表达式
                    if (expr.charAt(pos) == '(' || isNumber(expr, pos)) {
                        result = parse(expr, newScope);
                        break;
                    }
                    String var = parseToken(expr);
                    if (pos >= expr.length() || expr.charAt(pos) == ')') {
                        // 这是最终表达式（变量名）
                        result = newScope.get(var);
                        break;
                    }
                    pos++; // 跳过空格
                    int val = parse(expr, newScope);
                    newScope.put(var, val);
                    pos++; // 跳过空格
                }
            } else if (expr.startsWith("add", pos)) {
                pos += 4; // 跳过 "add "
                int a = parse(expr, scope);
                pos++; // 跳过空格
                int b = parse(expr, scope);
                result = a + b;
            } else { // mult
                pos += 5; // 跳过 "mult "
                int a = parse(expr, scope);
                pos++; // 跳过空格
                int b = parse(expr, scope);
                result = a * b;
            }

            pos++; // 跳过 ')'
            return result;
        } else if (isNumber(expr, pos)) {
            return parseNumber(expr);
        } else {
            String var = parseToken(expr);
            return scope.get(var);
        }
    }

    private boolean isNumber(String expr, int i) {
        return Character.isDigit(expr.charAt(i)) || expr.charAt(i) == '-';
    }

    private int parseNumber(String expr) {
        int sign = 1;
        if (expr.charAt(pos) == '-') {
            sign = -1;
            pos++;
        }
        int num = 0;
        while (pos < expr.length() && Character.isDigit(expr.charAt(pos))) {
            num = num * 10 + (expr.charAt(pos) - '0');
            pos++;
        }
        return sign * num;
    }

    private String parseToken(String expr) {
        int start = pos;
        while (pos < expr.length() && expr.charAt(pos) != ' ' && expr.charAt(pos) != ')') {
            pos++;
        }
        return expr.substring(start, pos);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **递归解析**：根据首字符判断表达式类型
2. **作用域管理**：let 表达式创建新的变量作用域
3. **分词处理**：正确解析数字、变量名和嵌套括号
