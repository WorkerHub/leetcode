## 题目描述

给你一个质数数组 `nums`，构造数组 `ans` 满足 `ans[i] | (ans[i] + 1) == nums[i]`，无解时 `ans[i] = -1`。数据范围 `nums[i] <= 100`。

## 解题思路

数据范围小，直接暴力枚举 `x` 从 0 到 `p-1`，找第一个满足 `x | (x+1) == p` 的 `x`。特判质数 2（唯一偶质数）无解。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] minBitwiseArray(List<Integer> nums) {
        int[] result = new int[nums.size()];
        for (int i = 0; i < nums.size(); i++) {
            int p = nums.get(i);
            if (p == 2) { result[i] = -1; continue; }
            result[i] = -1;
            // 暴力枚举 x，找最小的满足 x|(x+1)==p 的值
            for (int x = 0; x < p; x++) {
                if ((x | (x + 1)) == p) { result[i] = x; break; }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * max_val)，暴力枚举
- 空间复杂度：O(1)，不计输出

## 关键点总结

1. 质数 2 是唯一偶质数，无解返回 -1
2. 对奇质数 p，最小 x 是将 p 末尾连续 1 中最高位清零的结果
3. 数据范围小（≤100），直接暴力枚举简单可靠
