## 题目描述

矩阵中选拐角路径（水平+垂直各一段），求路径元素乘积的最大尾随零数。

## 解题思路

尾随零=min(因子2总数,因子5总数)。预计算每格因子2/5个数，行列前缀和。枚举拐角点(i,j)的4种方向组合（水平左/右+垂直上/下），取最大min(sum2,sum5)。

## Java 代码实现

```java
class Solution {
    public int maxTrailingZeros(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] two = new int[m][n], five = new int[m][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int v = grid[i][j];
                while (v % 2 == 0) { two[i][j]++; v /= 2; }
                v = grid[i][j];
                while (v % 5 == 0) { five[i][j]++; v /= 5; }
            }
        }
        
        // 行前缀和
        int[][] preR2 = new int[m][n + 1], preR5 = new int[m][n + 1];
        // 列前缀和
        int[][] preC2 = new int[m + 1][n], preC5 = new int[m + 1][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                preR2[i][j + 1] = preR2[i][j] + two[i][j];
                preR5[i][j + 1] = preR5[i][j] + five[i][j];
                preC2[i + 1][j] = preC2[i][j] + two[i][j];
                preC5[i + 1][j] = preC5[i][j] + five[i][j];
            }
        }
        
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int v2 = two[i][j], v5 = five[i][j];
                // 水平左(含j) + 垂直上(不含i)
                int h2 = preR2[i][j + 1], h5 = preR5[i][j + 1];
                // 水平右(含j)
                int hr2 = preR2[i][n] - preR2[i][j], hr5 = preR5[i][n] - preR5[i][j];
                // 垂直上(不含i行)
                int vu2 = preC2[i][j], vu5 = preC5[i][j];
                // 垂直下(不含i行)
                int vd2 = preC2[m][j] - preC2[i + 1][j], vd5 = preC5[m][j] - preC5[i + 1][j];
                
                // 4种组合，减去重复的(i,j)
                ans = Math.max(ans, Math.min(h2 + vu2, h5 + vu5));
                ans = Math.max(ans, Math.min(h2 + vd2, h5 + vd5));
                ans = Math.max(ans, Math.min(hr2 + vu2, hr5 + vu5));
                ans = Math.max(ans, Math.min(hr2 + vd2, hr5 + vd5));
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N * log(max_val))
- **空间复杂度**：O(M * N)

## 关键点总结

1. **尾随零=min(因子2,因子5)**：分别统计
2. **行列前缀和**：O(1)查询任意子段因子总数
3. **4种拐角方向**：水平左/右 × 垂直上/下
4. **含(i,j)的段**：水平段已包含(i,j)，垂直段不含(i,j)避免重复
