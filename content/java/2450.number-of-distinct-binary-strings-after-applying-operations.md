## 题目描述

给你二进制字符串 `s` 和正整数 `k`，可以任意次翻转 `s` 中长度为 `k` 的子字符串的每个字符，返回 `s` 可以变成的不同字符串数目（结果对 10^9+7 取余）。

## 解题思路

共有 `n - k + 1` 个可操作位置（长度为 k 的子字符串起点），每个位置可独立地选择操作或不操作，不同操作序列产生不同结果，答案为 `2^(n - k + 1)`。

## Java 代码实现

```java
class Solution {
    public int countDistinctStrings(String s, int k) {
        final int MOD = 1_000_000_007;
        int n = s.length();
        // 答案 = 2^(n - k + 1)
        return (int) pow(2, n - k + 1, MOD);
    }

    private long pow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)（快速幂）
- **空间复杂度**：O(1)

## 关键点总结

1. 可操作位置数为 `n - k + 1`，每个位置独立选择翻转或不翻转
2. 答案与字符串具体内容无关，只与长度和 k 有关
3. 用快速幂计算 `2^(n-k+1) mod 10^9+7`
