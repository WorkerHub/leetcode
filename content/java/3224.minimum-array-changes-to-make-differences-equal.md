## 题目描述

给你长度为 `n`（偶数）的整数数组 `nums` 和整数 `k`，每次操作可将某元素改为 `[0, k]` 内任意值，返回使所有对称对绝对差相等的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minChanges(int[] nums, int k) {
        int n = nums.length;
        int half = n / 2;
        // 差分数组优化：对每对 (a, b) 分析其对不同目标差值 d 的贡献
        int[] delta = new int[k + 2];

        for (int i = 0; i < half; i++) {
            int a = nums[i], b = nums[n - 1 - i];
            int cur = Math.abs(a - b);
            // 改一个值可达到的最大差值
            int maxOne = Math.max(Math.max(a, b), Math.max(k - a, k - b));
            // 范围 [0, maxOne] 内只需 1 次操作（相比 2 次减 1）
            delta[0]--;
            if (maxOne + 1 <= k + 1) delta[maxOne + 1]++;
            // d == cur 时无需操作（再减 1，总共减 2）
            delta[cur]--;
            if (cur + 1 <= k + 1) delta[cur + 1]++;
        }

        // 基础为每对都用 2 次操作，找最小值
        int base = 2 * half;
        int ans = base, acc = 0;
        for (int d = 0; d <= k; d++) {
            acc += delta[d];
            ans = Math.min(ans, base + acc);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + k)
- 空间复杂度：O(k)

## 关键点总结

1. 枚举目标差值 d，统计每对需要的操作数（0、1 或 2 次）
2. 用差分数组将区间更新优化到 O(n + k)
3. "一次操作能达到差 d" 的条件是 d <= max(a, b, k-a, k-b)
