## 题目描述

给你一个 `m x n` 的矩阵 `grid`，每个格子有权值。在矩阵中放置若干棋子，任意两个棋子不在同一行也不在同一列，返回最大总权值。

## 解题思路

等价于最大权二分匹配（行为左节点，列为右节点）。使用状态压缩 DP：`dp[mask]` 表示已选了 `mask` 对应列、已处理了 `popcount(mask)` 行时的最大权值，逐行更新。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxPoints(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int size = 1 << n;
        int[] dp = new int[size];
        Arrays.fill(dp, Integer.MIN_VALUE);
        dp[0] = 0;

        for (int i = 0; i < m; i++) {
            int[] newDp = dp.clone();
            for (int mask = 0; mask < size; mask++) {
                int row = Integer.bitCount(mask); // 已选行数
                if (row != i) continue; // 只处理已选了 i 行的状态
                if (dp[mask] == Integer.MIN_VALUE) continue;
                // 为第 i 行选一列
                for (int j = 0; j < n; j++) {
                    if ((mask >> j & 1) == 0) {
                        int newMask = mask | (1 << j);
                        newDp[newMask] = Math.max(newDp[newMask], dp[mask] + grid[i][j]);
                    }
                }
            }
            dp = newDp;
        }

        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * 2^n * n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 问题等价于最大权二分匹配（行列各选一次）
2. 状态压缩 DP 用列的 bitmask 记录已使用的列
3. 每行可以选择不放棋子（保持 dp 状态不变）
