## 题目描述

与 3243 相同场景，但数据规模更大（`n, q <= 10^5`），需要高效维护最短路长度。

## Java 代码实现

```java
class Solution {
    public int[] shortestDistanceAfterQueries(int n, int[][] queries) {
        // 用"下一个节点"数组模拟有序集合，实现路径压缩
        // nxt[i] = 当前最短路上 i 之后的节点
        int[] nxt = new int[n];
        for (int i = 0; i < n - 1; i++) nxt[i] = i + 1;
        nxt[n - 1] = n; // 哨兵

        int length = n - 1; // 初始最短路长度
        int[] ans = new int[queries.length];

        for (int q = 0; q < queries.length; q++) {
            int u = queries[q][0], v = queries[q][1];
            // 删除 u+1 到 v-1 之间在路径上的节点
            int cur = nxt[u];
            while (cur < v) {
                length--;          // 节点被跳过，路径缩短
                int next = nxt[cur];
                nxt[cur] = v;      // 路径压缩：中间节点直接指向 v
                cur = next;
            }
            nxt[u] = v;            // u 直接连到 v
            ans[q] = length;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q) 均摊（类似路径压缩）
- 空间复杂度：O(n)

## 关键点总结

1. 最短路 = 路径上的节点数 - 1
2. 添加新边 (u, v) 时，删除路径上 u 和 v 之间的所有中间节点
3. 路径压缩（nxt[cur] = v）避免重复扫描，实现均摊 O(1)
