## 题目描述

给定 `n` 和 `k`，找出包含 1 到 n 的数字且恰好有 `k` 个逆序对的不同数组个数，结果 mod 10^9 + 7。

**示例：**
```
输入：n = 3, k = 1
输出：2
解释：[1,3,2] 和 [2,1,3] 各有 1 个逆序对
```

## 解题思路

DP + 前缀和优化：`dp[i][j]` 表示使用 1~i 恰好 j 个逆序对的排列数，插入第 i 个数到不同位置产生 0~i-1 个新逆序对。

## Java 代码实现

```java
class Solution {
    public int kInversePairs(int n, int k) {
        int MOD = 1_000_000_007;
        // dp[i][j]: 使用1~i，恰好j个逆序对的排列数
        int[][] dp = new int[n + 1][k + 1];
        dp[0][0] = 1;

        for (int i = 1; i <= n; i++) {
            dp[i][0] = 1;
            for (int j = 1; j <= k; j++) {
                // 前缀和优化
                dp[i][j] = (dp[i][j - 1] + dp[i - 1][j]) % MOD;
                if (j >= i) {
                    dp[i][j] = (dp[i][j] - dp[i - 1][j - i] + MOD) % MOD;
                }
            }
        }

        return dp[n][k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)
- **空间复杂度**：O(n × k)

## 关键点总结

1. **状态定义**：dp[i][j] = 前 i 个数有 j 个逆序对的排列数
2. **前缀和优化**：将求和 O(n) 降为 O(1)
3. **取模注意负数**：减法后加 MOD 再取模
