## 题目描述

给你正整数数组 `nums`，将每个整数的各位数字分离出来，按原数组顺序（且保持每个整数内各位顺序）排列成新数组，返回该数组。

## 解题思路

对每个数转为字符串，按位分拆并转为整数添加到结果列表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] separateDigits(int[] nums) {
        List<Integer> list = new ArrayList<>();
        for (int num : nums) {
            // 转为字符串逐位分离（高位在前）
            for (char ch : Integer.toString(num).toCharArray()) {
                list.add(ch - '0');
            }
        }
        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * d)，d 为最大位数（最多 5 位）
- **空间复杂度**：O(n * d)

## 关键点总结

1. `Integer.toString(num)` 从高位到低位，直接遍历保持顺序
2. 各位分离后按原数组顺序拼接，不去重
3. 单位数字不需要拆分（toCharArray 只有一个字符）
