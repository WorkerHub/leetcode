## 题目描述

设计并实现一个迭代器来展开一个二维向量。迭代器需要支持 `next` 和 `hasNext` 两个操作。

**示例：**

```
Vector2D iterator = new Vector2D([[1,2],[3],[4]]);

iterator.next();    // 返回 1
iterator.next();    // 返回 2
iterator.next();    // 返回 3
iterator.hasNext(); // 返回 true
iterator.hasNext(); // 返回 true
iterator.next();    // 返回 4
iterator.hasNext(); // 返回 false
```

**提示：**
- `next()` 和 `hasNext()` 的调用次数最多为 100 次
- 你可以假定 `next()` 的调用总是有效的

## 解题思路

这道题目要求我们设计一个迭代器，将二维数组展开成一维进行遍历。核心思想是使用两个指针来追踪当前位置：
1. 外层指针：指向当前所在的子数组
2. 内层指针：指向当前子数组中的元素位置

关键点：
- 需要处理空数组的情况
- `hasNext()` 需要跳过空的子数组
- 保持指针的正确移动

## Java 代码实现

### 方法一：双指针（推荐）⭐

```java
class Vector2D {
    private int[][] vec;
    private int outer; // 外层指针，指向当前子数组
    private int inner; // 内层指针，指向子数组中的元素

    public Vector2D(int[][] vec) {
        // 初始化迭代器
        this.vec = vec;
        this.outer = 0;
        this.inner = 0;
    }

    public int next() {
        // 先调用 hasNext() 确保位置有效
        hasNext();
        return vec[outer][inner++];
    }

    public boolean hasNext() {
        // 跳过空数组，定位到下一个有效元素
        while (outer < vec.length) {
            // 当前子数组还有元素
            if (inner < vec[outer].length) {
                return true;
            }
            // 移动到下一个子数组，重置内层指针
            outer++;
            inner = 0;
        }
        return false;
    }
}
```

### 方法二：预处理展开（空间换时间）

```java
import java.util.ArrayList;
import java.util.List;

class Vector2D {
    private List<Integer> nums; // 展开后的一维列表
    private int index;          // 当前索引

    public Vector2D(int[][] vec) {
        // 在初始化时就展开所有元素，时间复杂度 O(n)
        nums = new ArrayList<>();
        for (int[] row : vec) {
            for (int num : row) {
                nums.add(num);
            }
        }
        index = 0;
    }

    public int next() {
        // 返回当前元素并移动索引
        return nums.get(index++);
    }

    public boolean hasNext() {
        // 判断是否还有未访问的元素
        return index < nums.size();
    }
}
```

### 方法三：迭代器包装（Java 特色）

```java
import java.util.Iterator;
import java.util.NoSuchElementException;

class Vector2D implements Iterator<Integer> {
    private int[][] vec;
    private int outer;
    private int inner;

    public Vector2D(int[][] vec) {
        this.vec = vec;
        this.outer = 0;
        this.inner = 0;
        // 初始化时就定位到第一个有效元素
        advance();
    }

    // 跳过空子数组，定位到下一个有效位置
    private void advance() {
        while (outer < vec.length && inner >= vec[outer].length) {
            outer++;
            inner = 0;
        }
    }

    public Integer next() {
        if (!hasNext()) {
            throw new NoSuchElementException();
        }
        int result = vec[outer][inner++];
        advance(); // 预先定位到下一个有效位置
        return result;
    }

    public boolean hasNext() {
        return outer < vec.length;
    }
}
```

## 复杂度分析

**方法一（双指针）：**
- 时间复杂度：
  - 构造函数：O(1)
  - `next()`：O(1)
  - `hasNext()`：O(1) 均摊，最坏情况 O(k)，k 为连续空数组数量
- 空间复杂度：O(1)，只使用常数额外空间

**方法二（预处理）：**
- 时间复杂度：
  - 构造函数：O(n)，n 为总元素数
  - `next()`：O(1)
  - `hasNext()`：O(1)
- 空间复杂度：O(n)

## 关键点总结

1. **双指针技巧**：使用外层和内层两个指针追踪当前位置
2. **边界处理**：正确处理空数组和数组末尾的情况
3. **懒加载 vs 预处理**：双指针是懒加载，预处理是空间换时间
4. **hasNext() 的责任**：应该负责跳过空数组，定位到下一个有效位置
5. **Java 迭代器**：可以实现 `Iterator<Integer>` 接口，与 Java 集合框架集成

## 易错点

1. **忘记跳过空数组**：在 `hasNext()` 中必须处理空子数组
   ```java
   // 错误：没有跳过空数组
   if (inner < vec[outer].length) return true;

   // 正确：使用 while 循环跳过所有空数组
   while (outer < vec.length) {
       if (inner < vec[outer].length) return true;
       outer++;
       inner = 0;
   }
   ```

2. **next() 中重复检查**：`next()` 应该依赖 `hasNext()` 的检查结果
   ```java
   // 推荐：先调用 hasNext() 确保位置有效
   public int next() {
       hasNext();
       return vec[outer][inner++];
   }
   ```

3. **指针更新时机**：移动到下一个子数组时，要重置内层指针为 0

4. **Java 数组越界**：访问 `vec[outer]` 前需要确保 `outer < vec.length`
