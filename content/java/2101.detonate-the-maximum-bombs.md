## 题目描述

给定炸弹列表bombs[i]=[x,y,r]，引爆一个炸弹可链式触发范围内的其他炸弹，求最多能引爆多少个。

## 解题思路

建有向图（i能触发j则加边i→j），对每个起点BFS/DFS求可达节点数，取最大值。距离用平方比较避免浮点误差。

## Java 代码实现

```java
class Solution {
    public int maximumDetonation(int[][] bombs) {
        int n = bombs.length;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        
        for (int i = 0; i < n; i++) {
            long xi = bombs[i][0], yi = bombs[i][1], ri = bombs[i][2];
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                long dx = xi - bombs[j][0], dy = yi - bombs[j][1];
                // 用平方比较避免浮点误差
                if (dx * dx + dy * dy <= ri * ri) {
                    graph.get(i).add(j);
                }
            }
        }
        
        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, bfs(graph, i, n));
        }
        return ans;
    }
    
    private int bfs(List<List<Integer>> graph, int start, int n) {
        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(start);
        visited[start] = true;
        int count = 0;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            count++;
            for (int nb : graph.get(node)) {
                if (!visited[nb]) {
                    visited[nb] = true;
                    queue.offer(nb);
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^3)，建图O(N^2)，N次BFS各O(N^2)
- **空间复杂度**：O(N^2)

## 关键点总结

1. **有向图**：i能触发j不等于j能触发i
2. **平方比较**：避免sqrt浮点误差
3. **用long**：坐标平方可能溢出int
