## 题目描述

混淆数：旋转 180 度后得到不同的有效数字。返回 1 到 n 之间混淆数的个数。有效旋转数字：0→0, 1→1, 6→9, 8→8, 9→6。

**示例：**
```
输入：n = 20
输出：6
解释：混淆数为 [6,9,10,16,18,19]
```

## 解题思路

回溯生成所有由 {0,1,6,8,9} 组成的数字（≤n），检查旋转后是否不同。DFS 过程中同时维护旋转值避免重复计算。

## Java 代码实现

```java
class Solution {
    private static final int[] VALID = {0, 1, 6, 8, 9};
    private static final int[] ROTATE = {0, 1, -1, -1, -1, -1, 9, -1, 8, 6};
    private int n;
    private int count;

    public int confusingNumberII(int n) {
        this.n = n;
        this.count = 0;
        // 首位不能是 0
        for (int d : new int[]{1, 6, 8, 9}) {
            if (d <= n) {
                dfs(d, ROTATE[d], 10);
            }
        }
        return count;
    }

    private void dfs(long num, long rotated, long base) {
        // 旋转后不同则是混淆数
        if (num != rotated) {
            count++;
        }
        // 尝试在末尾追加有效数字
        for (int d : VALID) {
            long next = num * 10 + d;
            if (next > n) break;
            dfs(next, ROTATE[d] * base + rotated, base * 10);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(5^d)，d 为 n 的位数
- **空间复杂度**：O(d)，递归栈

## 关键点总结

1. **直接生成**：只枚举有效数字组合，不遍历 1~n
2. **在线计算旋转值**：DFS 中增量维护 rotated，避免每次从头计算
3. **首位非零**：第一位只能选 1,6,8,9
4. **混淆判定**：num != rotated
