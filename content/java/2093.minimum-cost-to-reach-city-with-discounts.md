## 题目描述

n个城市间有收费公路，有discounts次折扣机会(费用减半)。求从0到n-1的最小费用。

## 解题思路

Dijkstra状态扩展：状态=(城市, 已用折扣次数)，每条边可选用折扣(toll/2)或不用(toll)。

## Java 代码实现

```java
class Solution {
    public int minimumCost(int n, int[][] highways, int discounts) {
        List<int[]>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] h : highways) {
            graph[h[0]].add(new int[]{h[1], h[2]});
            graph[h[1]].add(new int[]{h[0], h[2]});
        }
        
        int[][] dist = new int[n][discounts + 1];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;
        
        // (cost, city, used)
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 0, 0});
        
        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int cost = curr[0], city = curr[1], used = curr[2];
            if (cost > dist[city][used]) continue;
            if (city == n - 1) return cost;
            
            for (int[] edge : graph[city]) {
                int nb = edge[0], toll = edge[1];
                // 不打折
                if (cost + toll < dist[nb][used]) {
                    dist[nb][used] = cost + toll;
                    pq.offer(new int[]{dist[nb][used], nb, used});
                }
                // 打折
                if (used < discounts && cost + toll / 2 < dist[nb][used + 1]) {
                    dist[nb][used + 1] = cost + toll / 2;
                    pq.offer(new int[]{dist[nb][used + 1], nb, used + 1});
                }
            }
        }
        
        int ans = Integer.MAX_VALUE;
        for (int k = 0; k <= discounts; k++) {
            ans = Math.min(ans, dist[n - 1][k]);
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((E + N) × D × log(N × D))
- **空间复杂度**：O(N × D)

## 关键点总结

1. **状态扩展Dijkstra**：(城市, 已用折扣)
2. **两种转移**：用折扣(toll/2)或不用
3. **目标**：min(dist[n-1][0..discounts])
