## 题目描述

给你一棵以节点 0 为首都的无向树，每辆车的座位数为 `seats`，所有非首都城市的人驾车沿树边向首都汇聚，途中可合并乘车，返回最少燃油总消耗。

## 解题思路

DFS 计算每棵子树的人数，每条非根边的燃油消耗 = `ceil(经过该边的人数 / seats)`，累加即为答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] adj;
    private int seats;
    private long fuel;

    public long minimumFuelCost(int[][] roads, int seats) {
        int n = roads.length + 1;
        this.seats = seats;
        this.fuel = 0;
        adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] road : roads) {
            adj[road[0]].add(road[1]);
            adj[road[1]].add(road[0]);
        }
        dfs(0, -1);
        return fuel;
    }

    // 返回以 node 为根的子树中的人数
    private int dfs(int node, int parent) {
        int people = 1; // 当前城市一个人
        for (int nb : adj[node]) {
            if (nb != parent) {
                int sub = dfs(nb, node);
                people += sub;
                // 通过此边需要的车辆数即为燃油消耗
                fuel += (sub + seats - 1) / seats;
            }
        }
        return people;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每条非根边的燃油 = `ceil(子树人数 / seats)`
2. DFS 后序返回子树人数，逐边累加燃油
3. `ceil(a / b)` 用整数表达为 `(a + b - 1) / b`，结果用 `long` 存储
