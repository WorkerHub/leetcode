## 题目描述

Range模块是跟踪数字范围的模块。设计一个数据结构来跟踪表示为 **半开区间** 的范围并查询它们。

**半开区间** `[left, right)` 表示所有 `left <= x < right` 的实数 `x`。

实现 `RangeModule` 类:

- `RangeModule()` 初始化数据结构的对象。
- `void addRange(int left, int right)` 添加 **半开区间** `[left, right)`，跟踪该区间中的每个实数。
- `boolean queryRange(int left, int right)` 只有在当前正在跟踪区间 `[left, right)` 中的每一个实数时，才返回 `true` ，否则返回 `false` 。
- `void removeRange(int left, int right)` 停止跟踪 **半开区间** `[left, right)` 中当前正在跟踪的每个实数。

**示例：**

```
输入
["RangeModule", "addRange", "removeRange", "queryRange", "queryRange", "queryRange"]
[[], [10, 20], [14, 16], [10, 14], [13, 15], [16, 17]]
输出
[null, null, null, true, false, true]
```

**提示：**
- `1 <= left < right <= 10^9`
- 在单个测试用例中，对 `addRange`、`queryRange` 和 `removeRange` 的调用总数不超过 `10^4` 次

## 解题思路

这道题需要高效地维护和查询区间集合。

**核心思想：**
- 使用有序的区间列表维护所有被跟踪的区间
- 区间需要合并，避免重叠
- 使用二分查找优化查询

**关键操作：**
1. **添加区间**：找到所有重叠的区间，合并成一个大区间
2. **查询区间**：检查该区间是否被某个跟踪区间完全覆盖
3. **删除区间**：将重叠的区间拆分，移除指定部分

## Java 代码实现

### 方法一：有序列表 + 遍历（推荐）⭐

```java
import java.util.ArrayList;
import java.util.List;

class RangeModule {
    // 存储不重叠的区间，按起点排序，使用 int[] 数组 [left, right]
    private List<int[]> intervals;
    
    public RangeModule() {
        intervals = new ArrayList<>();
    }
    
    public void addRange(int left, int right) {
        List<int[]> newIntervals = new ArrayList<>();
        int i = 0;
        int n = intervals.size();
        
        // 添加所有在 [left, right) 之前的区间
        while (i < n && intervals.get(i)[1] < left) {
            newIntervals.add(intervals.get(i));
            i++;
        }
        
        // 合并所有与 [left, right) 重叠的区间
        while (i < n && intervals.get(i)[0] <= right) {
            left = Math.min(left, intervals.get(i)[0]);
            right = Math.max(right, intervals.get(i)[1]);
            i++;
        }
        
        newIntervals.add(new int[]{left, right});
        
        // 添加所有在 [left, right) 之后的区间
        while (i < n) {
            newIntervals.add(intervals.get(i));
            i++;
        }
        
        intervals = newIntervals;
    }
    
    public boolean queryRange(int left, int right) {
        // 查找可能覆盖 [left, right) 的区间
        for (int[] interval : intervals) {
            if (interval[0] <= left && right <= interval[1]) {
                return true;
            }
            if (interval[0] >= right) {
                break; // 已经过了目标区间
            }
        }
        return false;
    }
    
    public void removeRange(int left, int right) {
        List<int[]> newIntervals = new ArrayList<>();
        
        for (int[] interval : intervals) {
            int iLeft = interval[0], iRight = interval[1];
            
            // 无重叠，保留
            if (iRight <= left || iLeft >= right) {
                newIntervals.add(interval);
            } else {
                // 有重叠，可能拆分成两个区间
                // 左半部分
                if (iLeft < left) {
                    newIntervals.add(new int[]{iLeft, left});
                }
                // 右半部分
                if (right < iRight) {
                    newIntervals.add(new int[]{right, iRight});
                }
            }
        }
        
        intervals = newIntervals;
    }
}
```

## 复杂度分析

### 方法一：
- **addRange:** O(n)，最坏情况需要遍历所有区间
- **queryRange:** O(n)，最坏情况需要遍历所有区间
- **removeRange:** O(n)，需要遍历所有区间
- **空间复杂度：** O(n)，n 为区间数量

## 关键点总结

1. **区间合并**：重叠或相邻的区间需要合并
2. **有序维护**：保持区间按起点排序，方便查询
3. **区间拆分**：删除时可能将一个区间拆成两个
4. **半开区间**：注意 `[left, right)` 不包含 right
5. **遍历效率**：可以提前退出遍历（已超过目标区间时）

## 易错点

1. **区间边界处理**：半开区间的边界判断容易出错
2. **合并条件**：`intervals.get(i)[0] <= right` 才能合并
3. **删除后的区间**：可能产生 0、1 或 2 个新区间
4. **空列表情况**：初始状态和删除完后的处理
5. **ArrayList 的引用问题**：修改时要创建新的 List
