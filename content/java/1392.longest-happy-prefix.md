## 题目描述

返回字符串中最长的既是非空前缀也是非空后缀的子串（不能等于原字符串本身）。

## 解题思路

KMP的next数组：next[n-1]就是整个字符串的最长公共真前后缀长度，即答案长度。

## Java 代码实现

```java
class Solution {
    public String longestPrefix(String s) {
        int n = s.length();
        int[] next = new int[n];
        int j = 0;

        for (int i = 1; i < n; i++) {
            // 不匹配时回退
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = next[j - 1];
            }
            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }
            next[i] = j;
        }
        return s.substring(0, next[n - 1]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **KMP的next数组**：next[i]表示s[0..i]的最长公共真前后缀长度
2. **答案就是next[n-1]**：与题目定义完全吻合
3. **回退操作**：while j>0 && s[i]!=s[j] 是核心
