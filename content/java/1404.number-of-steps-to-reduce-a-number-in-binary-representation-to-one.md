## 题目描述

给你一个以二进制形式表示的数字 `s`。请你返回按下述规则将其减少到 1 所需要的步骤数：

- 如果当前数字为**偶数**，则将其除以 2（即**右移**一位，去掉末位 0）。
- 如果当前数字为**奇数**，则将其加 1（注意可能产生**进位**）。

题目保证你总是可以按上述规则将测试用例变为 1。

**示例 1：**

```
输入：s = "1101"
输出：6
解释："1101" 表示 13。
步骤：13 变为 14，14 变为 7，7 变为 8，8 变为 4，4 变为 2，2 变为 1。
共 6 步。
```

**示例 2：**

```
输入：s = "10"
输出：1
解释："10" 表示 2。2 变为 1，共 1 步。
```

**示例 3：**

```
输入：s = "1"
输出：0
```

**提示：**

- `1 <= s.length <= 500`
- `s` 由字符 `'0'` 和 `'1'` 组成
- `s[0] == '1'`

## 解题思路

### 方法一：整数转换（直接模拟）

将二进制字符串转为整数，然后模拟操作，但当 `s.length <= 500` 时，整数可能非常大（2^500），Java 需要使用 BigInteger。

### 方法二：直接操作字符串（推荐）

从字符串末位开始模拟，避免大整数运算：

**规则转化为字符串操作：**
- 末位为 `'0'`（偶数）：右移 = 删掉末位 `'0'`，步骤数 +1
- 末位为 `'1'`（奇数）：加 1 需要处理进位

**更聪明的字符串模拟：** 维护一个进位 `carry`，从右向左扫描：

- 末位（或有进位时）为 `1`：加 1 产生进位，相当于这一位变成 0 并进位，步骤 +2（加1一步+右移一步）
- 末位为 `0`：直接右移，步骤 +1
- 直到只剩 `s[0]`（最高位），特殊处理进位

## Java 代码实现

### 方法一：BigInteger 模拟

```java
import java.math.BigInteger;

class Solution {
    public int numSteps(String s) {
        // 将二进制字符串转为大整数
        BigInteger num = new BigInteger(s, 2);
        BigInteger one = BigInteger.ONE;
        BigInteger two = BigInteger.TWO;
        int steps = 0;

        while (!num.equals(one)) {
            if (num.testBit(0)) {
                // 奇数：加 1
                num = num.add(one);
            } else {
                // 偶数：除以 2（右移）
                num = num.shiftRight(1);
            }
            steps++;
        }
        return steps;
    }
}
```

### 方法二：字符串模拟 + 进位处理（推荐，处理超大数）

```java
class Solution {
    public int numSteps(String s) {
        int steps = 0;
        int carry = 0;  // 进位标志
        int n = s.length();

        // 从最低位（s 末尾）向最高位（s[0]）扫描
        for (int i = n - 1; i > 0; i--) {
            int curBit = (s.charAt(i) - '0') + carry;  // 当前位的值（加上进位）

            if (curBit % 2 == 1) {
                // 当前位为奇数（即为1）：需要加1，会产生进位，然后右移
                // 加1后这一位变成 0（+进位），再右移 → 共 2 步（加1 + 除2）
                steps += 2;
                carry = 1;  // 向高位产生进位
            } else {
                // 当前位为偶数（即为0）：直接右移
                steps += 1;
                carry = 0;  // 不产生进位
            }
        }

        // 处理最高位（s[0]）
        // 如果有进位，最高位 1 加上进位 1 = 10（二进制），变为 2，还需要再右移一步
        steps += carry;
        return steps;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（BigInteger） | O(n^2)（大整数运算） | O(n) |
| 方法二（字符串） | O(n) | O(1) |

- 方法一中大整数加法和除法本身是 O(n) 的，共 O(n) 次操作，故总体 O(n^2)。
- 方法二只扫描一遍字符串，O(n)。

## 图解示例

以 `s = "1101"` 为例，方法二模拟：

```
初始：carry = 0

i=3, s[3]='1', curBit=1+0=1 (奇), steps+=2=2, carry=1
i=2, s[2]='0', curBit=0+1=1 (奇), steps+=2=4, carry=1
i=1, s[1]='1', curBit=1+1=2 (偶), steps+=1=5, carry=1

处理最高位：steps += carry=1, 最终 steps=6

返回 6 ✓
```

## 关键点总结

1. 字符串模拟的关键：维护进位 `carry`，从低位向高位扫描
2. 当前位（含进位）为 `1`（奇数）：需要两步（加1 + 右移），并向高位产生进位
3. 当前位（含进位）为 `0`（偶数）：只需一步（右移），不产生进位
4. 最后处理最高位的进位：如有进位则额外加 1 步

## 易错点

- 方法一对超大整数（500位二进制）是 O(n^2)，Java 需使用 BigInteger
- 方法二中每次奇数情况步骤为 2（不是 1），因为加 1 和右移是两个独立的步骤
- 处理完所有位后，还要判断最高位是否有进位（若有则多一步右移）
- 循环范围是 `i > 0`（不包含 `i=0`），最高位单独处理
