## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。"

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3。
```

**示例 2：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5。因为根据定义最近公共祖先节点可以为节点本身。
```

**示例 3：**
```
输入：root = [1,2], p = 1, q = 2
输出：1
```

**提示：**
- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中

## 解题思路

与 235 题不同，这是普通二叉树，不能利用 BST 的性质，需要遍历整个树。

**核心思想：递归 + 回溯**

**关键观察：**
1. 如果 p 和 q 分别在某个节点的左右子树中，该节点就是 LCA
2. 如果 p 或 q 就是当前节点，当前节点就是 LCA
3. 如果 p 和 q 都在左子树，LCA 在左子树中
4. 如果 p 和 q 都在右子树，LCA 在右子树中

**递归逻辑：**
- 递归函数返回：在当前子树中找到的 p、q 或它们的 LCA
- 如果左右子树都有返回值，当前节点是 LCA
- 如果只有一侧有返回值，返回那一侧的结果

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode(int x) { val = x; }
// }

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 递归终止条件
        // 1. 空节点：返回 null
        // 2. 找到 p 或 q：返回该节点
        if (root == null || root == p || root == q) {
            return root;
        }

        // 递归搜索左右子树
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 根据左右子树的返回值判断
        // 情况 1：左右子树都有返回值，说明 p 和 q 分居两侧
        if (left != null && right != null) {
            return root;
        }

        // 情况 2：只有左子树有返回值
        // 说明 p 和 q 都在左子树，或者只找到了一个
        if (left != null) {
            return left;
        }

        // 情况 3：只有右子树有返回值
        // 说明 p 和 q 都在右子树，或者只找到了一个
        return right;
    }
}
```

### 方法二：递归简化版

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 更简洁的写法
        // 终止条件
        if (root == null || root == p || root == q) {
            return root;
        }

        // 递归左右子树
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 如果左右都不为空，当前节点是 LCA
        if (left != null && right != null) {
            return root;
        }

        // 否则返回不为空的那个
        return left != null ? left : right;
    }
}
```

### 方法三：存储父节点（迭代）

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 使用哈希表存储每个节点的父节点
        // 然后找到从 p 到根的路径，再从 q 向上找第一个在路径中的节点
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        parent.put(root, null);

        // 使用栈进行 DFS，记录所有节点的父节点
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        // 当 p 和 q 的父节点都找到时停止
        while (!parent.containsKey(p) || !parent.containsKey(q)) {
            TreeNode node = stack.pop();

            if (node.left != null) {
                parent.put(node.left, node);
                stack.push(node.left);
            }

            if (node.right != null) {
                parent.put(node.right, node);
                stack.push(node.right);
            }
        }

        // 记录从 p 到根的所有祖先
        Set<TreeNode> ancestors = new HashSet<>();
        TreeNode curr = p;
        while (curr != null) {
            ancestors.add(curr);
            curr = parent.get(curr);
        }

        // 从 q 向上找，第一个在 ancestors 中的就是 LCA
        curr = q;
        while (!ancestors.contains(curr)) {
            curr = parent.get(curr);
        }

        return curr;
    }
}
```

### 方法四：存储路径

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 找到从 root 到 p 和 q 的路径，然后找到最后一个公共节点
        List<TreeNode> pathP = new ArrayList<>();
        List<TreeNode> pathQ = new ArrayList<>();

        findPath(root, p, pathP);
        findPath(root, q, pathQ);

        // 找到最后一个公共节点
        TreeNode lca = null;
        int len = Math.min(pathP.size(), pathQ.size());
        for (int i = 0; i < len; i++) {
            if (pathP.get(i) == pathQ.get(i)) {
                lca = pathP.get(i);
            } else {
                break;
            }
        }

        return lca;
    }

    // DFS 找到从 root 到 target 的路径
    private boolean findPath(TreeNode root, TreeNode target, List<TreeNode> path) {
        if (root == null) return false;

        // 将当前节点加入路径
        path.add(root);

        // 找到目标节点
        if (root == target) return true;

        // 在左右子树中查找
        if (findPath(root.left, target, path) || findPath(root.right, target, path)) {
            return true;
        }

        // 当前路径不通，回溯
        path.remove(path.size() - 1);
        return false;
    }
}
```

## 复杂度分析

**方法一、二（递归）：**
- 时间复杂度：O(n)，需要遍历所有节点
- 空间复杂度：O(h)，递归栈的深度，h 为树的高度
  - 最好情况：O(log n)
  - 最坏情况：O(n)

**方法三（存储父节点）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，存储所有节点的父节点

**方法四（存储路径）：**
- 时间复杂度：O(n)
- 空间复杂度：O(h)，存储路径

## 图解示例

```
示例树：
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

查找 p = 5, q = 1 的 LCA：

递归过程（后序遍历）：

1. 从 root = 3 开始
   递归左子树（5）
   
2. 到达 node = 5
   node == p，返回 5
   
3. 回到 node = 3
   left = 5
   递归右子树（1）
   
4. 到达 node = 1
   node == q，返回 1
   
5. 回到 node = 3
   left = 5, right = 1
   左右都不为空，返回 3

查找 p = 5, q = 4 的 LCA：

1. 从 root = 3 开始
   递归左子树
   
2. 到达 node = 5
   node == p，返回 5
   （虽然 q 在 5 的子树中，但已经返回了）
   
3. 回到 node = 3
   left = 5, right = null
   返回 left = 5
```

## 关键点总结

1. **后序遍历**：先处理子树，再处理当前节点
2. **递归返回值**：返回找到的 p、q 或它们的 LCA
3. **判断逻辑**：左右都有返回值时，当前节点是 LCA
4. **节点可以是自己的祖先**：找到 p 或 q 就返回
5. **完全遍历**：最坏情况需要遍历整棵树

## 易错点

1. **忘记节点可以是自己的祖先**：
   ```java
   // 错误：没有处理 root == p 或 root == q 的情况
   if (root == null) return null;
   
   // 正确
   if (root == null || root == p || root == q) return root;
   ```

2. **理解递归返回值**：
   - 返回的不一定是 LCA
   - 可能只找到了 p 或 q
   - 只有左右都有返回值时，当前节点才是 LCA

3. **判断顺序**：
   ```java
   // 必须先判断左右都不为空
   if (left != null && right != null) return root;
   // 再返回其中一个
   return left != null ? left : right;
   ```

4. **与 BST 版本混淆**：
   - BST 版本（235 题）：可以通过值大小判断方向，O(h)
   - 普通二叉树（本题）：需要遍历，O(n)

5. **Java 中对象比较**：使用 `==` 比较节点引用，不要用 `equals()`

   - 先处理左子树
   - 再处理右子树
   - 最后处理根节点
   - 这道题就是后序遍历的应用

2. **掌握递归思路**：
   - 明确递归函数的返回值含义
   - 理解如何利用子问题的结果
   - 递归 + 回溯是树题的核心

3. **对比不同方法**：
   - 递归：代码简洁，思路清晰
   - 存储父节点：更直观，但空间复杂度高
   - 存储路径：类似思路，但更复杂
