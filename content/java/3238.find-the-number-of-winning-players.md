## 题目描述

给你玩家数 `n` 和拾取记录 `pick[i] = [xi, yi]`，若玩家 `i` 某种颜色的球数量严格大于 `i`，则玩家获胜，返回获胜玩家数量。

## Java 代码实现

```java
class Solution {
    public int winningPlayerCount(int n, int[][] pick) {
        // cnt[player][color] = 数量（颜色范围 0-10）
        int[][] cnt = new int[n][11];
        for (int[] p : pick) {
            cnt[p[0]][p[1]]++;
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            // 检查是否有某种颜色数量严格大于 i
            for (int c = 0; c <= 10; c++) {
                if (cnt[i][c] > i) {
                    ans++;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为 pick 长度
- 空间复杂度：O(n)

## 关键点总结

1. 颜色范围 0-10，用二维数组快速统计
2. 获胜条件：某种颜色数量**严格大于**玩家编号 i
3. 玩家 0 只需某种颜色数量 > 0（即至少有 1 个）
