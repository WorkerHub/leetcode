## 题目描述

返回数组中恰好拥有四个因数的元素的各因数之和。

## 解题思路

枚举因数到sqrt(n)，利用因数对称性找所有因数，超过4个提前退出。

## Java 代码实现

```java
class Solution {
    public int sumFourDivisors(int[] nums) {
        int result = 0;
        for (int num : nums) {
            int sum = 0, count = 0;
            for (int i = 1; (long) i * i <= num; i++) {
                if (num % i == 0) {
                    sum += i;
                    count++;
                    if (i != num / i) {
                        sum += num / i;
                        count++;
                    }
                    if (count > 4) break;
                }
            }
            if (count == 4) result += sum;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * sqrt(M))，M为数组最大值
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举到sqrt(n)**：利用因数对称性
2. **i == num/i时只计一次**：避免完全平方数重复
3. **超过4个因数提前break**：剪枝优化
