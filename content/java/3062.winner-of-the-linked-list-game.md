## 题目描述

偶数个节点的链表，Even 玩家收集偶数位置节点值，Odd 玩家收集奇数位置节点值，比较两人总和返回胜者或 "Tie"。

## 解题思路

每次取两个节点，分别累加到偶数和奇数玩家的总和，最后比较大小。

## Java 代码实现

```java
class Solution {
    public String gameResult(ListNode head) {
        int evenSum = 0, oddSum = 0;
        ListNode node = head;
        // 每次取两个节点，分别累加偶数位和奇数位的值
        while (node != null && node.next != null) {
            evenSum += node.val;
            oddSum += node.next.val;
            node = node.next.next;
        }
        if (evenSum > oddSum) return "Even";
        if (oddSum > evenSum) return "Odd";
        return "Tie";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历链表一次
- **空间复杂度**：O(1)

## 关键点总结

1. 位置从 0 开始（0-indexed），偶数位为 0, 2, 4, ...
2. 链表节点数为偶数，每次取两个节点刚好配对
3. 比较两人总和，相等返回 "Tie"
