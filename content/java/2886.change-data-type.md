## 题目描述

给定 DataFrame students，将 grade 列的数据类型从 float 转换为 int。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df['grade'].astype(int)` 转换列数据类型。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df['col'].astype(int) 等价于将每个浮点数截断为整数

class Solution {
    // Java 中将 double 数组转换为 int 数组（截断小数）
    public int[] changeDataType(double[] grades) {
        int[] result = new int[grades.length];
        for (int i = 0; i < grades.length; i++) {
            result[i] = (int) grades[i]; // 截断小数部分
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `df['col'].astype(int)` 转换列数据类型，float 转 int 截断小数
2. `df.astype({'col': dtype})` 可批量转换多列
3. 含 NaN 的浮点列需先处理缺失值再转 int
