## 题目描述

给定字符串数组 words，找到包含所有字符串作为子串的最短字符串。

## 解题思路

状态压缩 DP + TSP：预计算任意两个字符串的重叠长度，用 dp[mask][i] 表示已访问 mask 集合且最后一个是 i 的最大重叠。最后回溯路径构建结果。

## Java 代码实现

```java
class Solution {
    public String shortestSuperstring(String[] words) {
        int n = words.length;

        // 预计算重叠长度
        int[][] overlap = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i != j) {
                    int maxOv = Math.min(words[i].length(), words[j].length());
                    for (int k = maxOv; k > 0; k--) {
                        if (words[i].endsWith(words[j].substring(0, k))) {
                            overlap[i][j] = k;
                            break;
                        }
                    }
                }
            }
        }

        // 状态压缩 DP
        int[][] dp = new int[1 << n][n];
        int[][] parent = new int[1 << n][n];
        for (int[] row : parent) Arrays.fill(row, -1);

        for (int mask = 1; mask < (1 << n); mask++) {
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0) continue;
                int prevMask = mask ^ (1 << i);
                if (prevMask == 0) continue;
                for (int j = 0; j < n; j++) {
                    if ((prevMask & (1 << j)) == 0) continue;
                    if (dp[prevMask][j] + overlap[j][i] > dp[mask][i]) {
                        dp[mask][i] = dp[prevMask][j] + overlap[j][i];
                        parent[mask][i] = j;
                    }
                }
            }
        }

        // 找最优终点
        int fullMask = (1 << n) - 1;
        int last = 0;
        for (int i = 1; i < n; i++) {
            if (dp[fullMask][i] > dp[fullMask][last]) last = i;
        }

        // 回溯路径
        int[] path = new int[n];
        int mask = fullMask;
        for (int i = n - 1; i >= 0; i--) {
            path[i] = last;
            int prev = parent[mask][last];
            mask ^= (1 << last);
            last = prev;
        }

        // 构建结果
        StringBuilder sb = new StringBuilder(words[path[0]]);
        for (int i = 1; i < n; i++) {
            sb.append(words[path[i]].substring(overlap[path[i - 1]][path[i]]));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × 2^n)
- **空间复杂度**：O(n × 2^n)

## 关键点总结

1. **TSP 问题变体**：旅行商问题的字符串版本
2. **状态压缩**：bitmask 表示已使用的字符串集合
3. **重叠预计算**：避免重复计算字符串重叠
