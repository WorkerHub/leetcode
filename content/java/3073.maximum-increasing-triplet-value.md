## 题目描述

找满足 i<j<k、nums[i]<nums[j]、nums[k]>nums[j] 的三元组，使 nums[i]+nums[j]+nums[k] 最大，不存在则返回 0。

## 解题思路

枚举中间元素 j，预处理每个位置左侧小于它的最大值和右侧大于它的最大值，取三者之和的最大值。

## Java 代码实现

```java
class Solution {
    public long maximumTripletValue(int[] nums) {
        int n = nums.length;
        // right_max[j] = j+1..n-1 中大于 nums[j] 的最大值（无则为 0）
        int[] rightMax = new int[n];
        int suffMax = 0;
        for (int j = n - 1; j >= 0; j--) {
            rightMax[j] = suffMax > nums[j] ? suffMax : 0;
            if (nums[j] > suffMax) suffMax = nums[j];
        }

        // 从左往右枚举 j，维护左侧小于 nums[j] 的最大值
        long ans = 0;
        int[] leftNums = new int[n]; // 前缀有序结构（暴力 O(n^2) 在此数据量下）
        for (int j = 1; j < n - 1; j++) {
            // 找 nums[0..j-1] 中小于 nums[j] 的最大值
            int leftBest = 0;
            for (int i = 0; i < j; i++) {
                if (nums[i] < nums[j] && nums[i] > leftBest) leftBest = nums[i];
            }
            if (leftBest > 0 && rightMax[j] > 0) {
                long val = (long) leftBest + nums[j] + rightMax[j];
                if (val > ans) ans = val;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，枚举中间元素并扫描左侧
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举中间元素 j，分别找左侧最大的小于 nums[j] 的值和右侧最大的大于 nums[j] 的值
2. 右侧最大值可以用后缀最大值 O(n) 预处理
3. 用 long 防止溢出（nums[i] 最大 10^9，三数之和最大 3×10^9）
