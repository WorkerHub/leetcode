## 题目描述

将四位正整数的4个数字拆成两个新整数，求new1+new2的最小值。

## 解题思路

贪心：4个数字排序后最小的两个作为十位（系数10），较大的两个作为个位（系数1），和=(a+b)*10+(c+d)最小。

## Java 代码实现

```java
class Solution {
    public int minimumSum(int num) {
        int[] digits = new int[4];
        for (int i = 0; i < 4; i++) {
            digits[i] = num % 10;
            num /= 10;
        }
        Arrays.sort(digits);
        // 最小两个作十位，较大两个作个位
        return (digits[0] * 10 + digits[2]) + (digits[1] * 10 + digits[3]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心分配**：最小两个放十位最小化总和
2. **交叉配对**：a*10+c和b*10+d而非a*10+b和c*10+d
3. **固定4个数字**：常数时间空间
