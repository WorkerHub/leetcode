## 题目描述

向 `arr1`（不被 `divisor1` 整除）和 `arr2`（不被 `divisor2` 整除）中各填入 `uniqueCnt1`、`uniqueCnt2` 个不同正整数（两数组元素也互不相同），返回两数组中最大元素的最小值。

## 解题思路

二分最大值 `m`：用容斥原理计算 `[1,m]` 中可放入 arr1 的数量（不被 d1 整除）、可放入 arr2 的数量（不被 d2 整除）和两者均可放的数量（不被 d1 也不被 d2 整除），判断是否能满足需求。

## Java 代码实现

```java
class Solution {
    public int minimizeSet(int divisor1, int divisor2, int uniqueCnt1, int uniqueCnt2) {
        long lcm = (long) divisor1 / gcd(divisor1, divisor2) * divisor2;
        long lo = 1, hi = 2_000_000_000L;

        while (lo < hi) {
            long m = (lo + hi) / 2;
            if (check(m, divisor1, divisor2, lcm, uniqueCnt1, uniqueCnt2)) hi = m;
            else lo = m + 1;
        }
        return (int) lo;
    }

    private boolean check(long m, long d1, long d2, long lcm, long cnt1, long cnt2) {
        long avail1 = m - m / d1;         // 可放 arr1 的数量（不被 d1 整除）
        long avail2 = m - m / d2;         // 可放 arr2 的数量（不被 d2 整除）
        long availBoth = m - m / d1 - m / d2 + m / lcm; // 两者均可放的数量
        // arr1 需要 cnt1 个，arr2 需要 cnt2 个，总共 cnt1+cnt2 个不同正整数
        return avail1 >= cnt1 && avail2 >= cnt2 && availBoth >= Math.max(0, cnt1 - (avail1 - availBoth)) + Math.max(0, cnt2 - (avail2 - availBoth));
    }

    private long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(maxVal))，约 31 次二分迭代
- **空间复杂度**：O(1)

## 关键点总结

1. 二分最大值，check 函数用容斥原理计算各可用数量
2. `availBoth` 为两个数组均可使用的数量（不被 d1 也不被 d2 整除，用 LCM 容斥）
3. 使用 `long` 防止 LCM 和乘法溢出
