## 题目描述

非递减数组中恰有一个元素出现频率超过 25%，找出该元素。

**示例：**
```
输入：arr = [1,2,2,6,6,6,6,7,10]
输出：6
```

## 解题思路

数组有序，出现超过 n/4 次的元素跨度超过 n/4。只需检查 arr[i] == arr[i + n/4] 即可。

## Java 代码实现

```java
class Solution {
    public int findSpecialInteger(int[] arr) {
        int n = arr.length;
        int quarter = n / 4;
        for (int i = 0; i < n; i++) {
            if (arr[i] == arr[i + quarter]) {
                return arr[i];
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **有序数组**：相同元素连续
2. **跨度判断**：超过 25% 则 arr[i] == arr[i + n/4]
3. **保证有解**：题目保证恰好有一个
