## 题目描述

给你长度为 n 的字符串 `pattern`（含 'I' 和 'D'），返回由 1 到 9 中 n+1 个不同数字组成的最小字符串 `num`，使 `num[i]<num[i+1]` 对应 'I'，`num[i]>num[i+1]` 对应 'D'。

## 解题思路

用栈贪心：将 1 到 n+1 依次压栈，遇到 'I' 或遍历结束时将栈中所有元素弹出追加到结果，连续 'D' 段会在遇到 'I' 时一次性逆序输出。

## Java 代码实现

```java
class Solution {
    public String smallestNumber(String pattern) {
        int n = pattern.length();
        Deque<Integer> stack = new ArrayDeque<>();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i <= n; i++) {
            stack.push(i + 1); // 压入数字 1 到 n+1
            // 遇到 'I' 或末尾，弹出栈中所有元素
            if (i == n || pattern.charAt(i) == 'I') {
                while (!stack.isEmpty()) {
                    sb.append(stack.pop());
                }
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 连续的 'D' 段需要将该段数字倒序排列，用栈实现倒序输出。
2. 遇到 'I' 或末尾时，弹出栈中全部积压数字。
3. 末尾相当于虚拟的 'I'，统一用 `i == n` 触发弹出。
