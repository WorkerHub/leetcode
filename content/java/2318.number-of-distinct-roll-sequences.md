## 题目描述

掷骰子 `n` 次，要求每次结果不能与上一次相同、不能与上上次相同，且与上一次结果互质，返回不同序列数（模 10^9+7）。

## 解题思路

滚动 DP：用 `dp[prev][pprev]` 表示上一次为 `prev`、上上次为 `pprev` 时的方案数（pprev=0 表示不存在）。每步枚举新值 `cur`，满足三个约束时更新。由于骰子值仅 1-6，状态空间为 7×7，每次转移是常数级别。

## Java 代码实现

```java
class Solution {
    public int distinctSequences(int n) {
        final int MOD = 1_000_000_007;
        // gcd[i][j] 预计算互质关系
        boolean[][] coprime = new boolean[7][7];
        for (int i = 1; i <= 6; i++) {
            for (int j = 1; j <= 6; j++) {
                coprime[i][j] = (gcd(i, j) == 1);
            }
        }

        // dp[prev][pprev]: 上次为 prev，上上次为 pprev 的方案数
        long[][] dp = new long[7][7];
        // 第一次：prev=骰子值，pprev=0
        for (int f = 1; f <= 6; f++) dp[f][0] = 1;

        for (int step = 1; step < n; step++) {
            long[][] ndp = new long[7][7];
            for (int prev = 1; prev <= 6; prev++) {
                for (int pprev = 0; pprev <= 6; pprev++) {
                    if (dp[prev][pprev] == 0) continue;
                    for (int cur = 1; cur <= 6; cur++) {
                        if (cur == prev || cur == pprev) continue; // 不能重复
                        if (!coprime[cur][prev]) continue;         // 必须互质
                        ndp[cur][prev] = (ndp[cur][prev] + dp[prev][pprev]) % MOD;
                    }
                }
            }
            dp = ndp;
        }

        long ans = 0;
        for (int prev = 1; prev <= 6; prev++) {
            for (int pprev = 0; pprev <= 6; pprev++) {
                ans = (ans + dp[prev][pprev]) % MOD;
            }
        }
        return (int) ans;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 6 × 7 × 6) = O(n)，常数较小
- **空间复杂度**：O(6 × 7) = O(1)

## 关键点总结

1. 三个约束：不等于上一个、不等于上上个、与上一个互质。
2. 状态只有 6×7=42 个，每步枚举 6 个新值，整体为 O(n)。
3. pprev=0 表示不存在上上次，约束 `cur != pprev` 在 pprev=0 时恒成立。
