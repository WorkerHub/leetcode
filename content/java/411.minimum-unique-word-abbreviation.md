## 题目描述

给定一个目标字符串 target 和一个字符串数组 dictionary，找出 target 的最短缩写，使得它不会与 dictionary 中的任何字符串的缩写冲突。

缩写规则同 408 题。

**示例：**
```
输入：target = "apple", dictionary = ["blade"]
输出："a4"
解释："apple" 可以缩写为 "5", "a4", "ap3", "app2", "appl1", "apple"
     "blade" 可以缩写为 "5", "b4", "bl3", "bla2", "blad1", "blade"
     "a4" 是最短的且不与 "blade" 冲突
```

## 解题思路

这是一道困难题，需要枚举所有可能的缩写并验证。

核心思路：
1. 生成所有可能的缩写
2. 验证每个缩写是否与 dictionary 中的单词冲突
3. 选择最短的有效缩写

## Java 代码实现

### 方法一：回溯 + 验证

```java
import java.util.*;

class Solution {
    private String target;
    private List<String> dict;
    private String minAbbr;

    public String minAbbreviation(String target, String[] dictionary) {
        this.target = target;
        // 过滤掉长度不同的单词
        this.dict = new ArrayList<>();
        for (String word : dictionary) {
            if (word.length() == target.length()) {
                this.dict.add(word);
            }
        }

        if (this.dict.isEmpty()) {
            return String.valueOf(target.length());
        }

        this.minAbbr = target;
        backtrack(0, new StringBuilder(), 0);
        return minAbbr;
    }

    private void backtrack(int index, StringBuilder abbr, int count) {
        if (index == target.length()) {
            // 构建当前缩写字符串
            StringBuilder temp = new StringBuilder(abbr);
            if (count > 0) {
                temp.append(count);
            }
            String abbrStr = temp.toString();
            if (abbrStr.length() < minAbbr.length() && isUnique(abbrStr)) {
                minAbbr = abbrStr;
            }
            return;
        }

        // 剪枝：当前长度已经不优
        int currentLen = abbr.length() + (count > 0 ? 1 : 0) + (target.length() - index);
        if (currentLen >= minAbbr.length()) {
            return;
        }

        // 选择1：缩写当前字符
        backtrack(index + 1, abbr, count + 1);

        // 选择2：保留当前字符
        int prevLen = abbr.length();
        if (count > 0) {
            abbr.append(count);
        }
        abbr.append(target.charAt(index));
        backtrack(index + 1, abbr, 0);
        // 回溯，恢复状态
        abbr.delete(prevLen, abbr.length());
    }

    private boolean isUnique(String abbr) {
        // 检查缩写是否与字典中的单词冲突
        for (String word : dict) {
            if (isValidAbbr(word, abbr)) {
                return false;
            }
        }
        return true;
    }

    private boolean isValidAbbr(String word, String abbr) {
        // 验证 abbr 是否是 word 的有效缩写
        int i = 0, j = 0;
        while (j < abbr.length()) {
            if (Character.isDigit(abbr.charAt(j))) {
                if (abbr.charAt(j) == '0') return false;
                int num = 0;
                while (j < abbr.length() && Character.isDigit(abbr.charAt(j))) {
                    num = num * 10 + (abbr.charAt(j) - '0');
                    j++;
                }
                i += num;
            } else {
                if (i >= word.length() || word.charAt(i) != abbr.charAt(j)) {
                    return false;
                }
                i++;
                j++;
            }
        }
        return i == word.length();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n * m * n)
  - 生成 2^n 种缩写
  - 验证每个缩写需要 O(m * n)
  
- **空间复杂度**：O(n)

## 关键点总结

1. 过滤长度不同的单词
2. 回溯生成所有缩写
3. 验证缩写的唯一性
4. 剪枝优化
