## 题目描述

返回所有长度为 n 且相邻位数字差的绝对值为 k 的非负整数（无前导零）。

**示例：**
```
输入：n = 3, k = 7
输出：[181,292,707,818,929]
```

## 解题思路

BFS/DFS 逐位构建：从 1-9 开始，每次根据最后一位加/减 k 得到下一位，直到长度为 n。注意 k=0 时避免重复。

## Java 代码实现

```java
class Solution {
    public int[] numsSameConsecDiff(int n, int k) {
        List<Integer> current = new ArrayList<>();
        for (int i = 1; i <= 9; i++) current.add(i);

        for (int step = 1; step < n; step++) {
            List<Integer> next = new ArrayList<>();
            for (int num : current) {
                int lastDigit = num % 10;
                if (lastDigit + k <= 9) {
                    next.add(num * 10 + lastDigit + k);
                }
                if (k != 0 && lastDigit - k >= 0) {
                    next.add(num * 10 + lastDigit - k);
                }
            }
            current = next;
        }

        // n == 1 时特殊处理
        if (n == 1) {
            current = new ArrayList<>();
            for (int i = 0; i <= 9; i++) current.add(i);
        }

        return current.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n)
- **空间复杂度**：O(2^n)

## 关键点总结

1. **逐层构建**：每层添加一位数字
2. **k=0 去重**：+k 和 -k 相同时只加一次
3. **无前导零**：起始从 1 开始
