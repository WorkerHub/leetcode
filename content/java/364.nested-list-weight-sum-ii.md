## 题目描述

给你一个嵌套的整数列表 `nestedList`。每个元素要么是一个整数，要么是一个列表（其元素也可能是整数或者是其他列表）。

整数的深度取决于它位于多少个列表内部。例如，嵌套列表 `[1,[2,2],[[3],2],1]` 中每个整数的值就是其深度。令 `maxDepth` 为最大深度。

返回该嵌套列表按深度加权求和的结果。规则如下：
- 深度为 `maxDepth` 的整数，其权重为 1
- 深度为 `maxDepth - 1` 的整数，其权重为 2
- 深度为 `maxDepth - d` 的整数，其权重为 `d + 1`

**示例 1：**

```
输入：nestedList = [[1,1],2,[1,1]]
输出：8
解释：
- 四个深度为 2 的 1，权重为 1，总和为 4
- 一个深度为 1 的 2，权重为 2，总和为 4
- 结果：4 + 4 = 8
```

**示例 2：**

```
输入：nestedList = [1,[4,[6]]]
输出：17
解释：
- 一个深度为 1 的 1，权重为 3，总和为 3
- 一个深度为 2 的 4，权重为 2，总和为 8
- 一个深度为 3 的 6，权重为 1，总和为 6
- 结果：3 + 8 + 6 = 17
```

**提示：**
- `1 <= nestedList.length <= 50`
- 嵌套列表中整数的值在 `[-100, 100]` 范围内
- 任何整数的最大深度小于或等于 50

## 解题思路

这道题是 [339. Nested List Weight Sum](https://leetcode.com/problems/nested-list-weight-sum/) 的变体。

关键区别：
- 339 题：深度越深，权重越大（深度为 d，权重为 d）
- 本题：深度越浅，权重越大（深度为 d，权重为 maxDepth - d + 1）

### 解法思路

**方法一：两次遍历**
1. 第一次遍历：找到最大深度 `maxDepth`
2. 第二次遍历：按照 `maxDepth - depth + 1` 计算加权和

**方法二：巧妙的一次遍历（推荐）**
核心观察：
- 如果直接计算，需要知道 `maxDepth`
- 反向思考：每层的数字被累加的次数不同
- 使用 BFS 层序遍历，每次将当前层的数字累加到结果中
- 下一层继承上一层的未加权和，实现反向加权效果

## Java 代码实现

### 方法一：两次遍历（直观）

```java
import java.util.List;

/**
 * // 这是 NestedInteger 的接口，不需要实现
 * public interface NestedInteger {
 *     boolean isInteger();
 *     Integer getInteger();
 *     List<NestedInteger> getList();
 * }
 */
class Solution {
    public int depthSumInverse(List<NestedInteger> nestedList) {
        // 第一次遍历：找最大深度
        int maxDepth = getMaxDepth(nestedList);

        // 第二次遍历：计算加权和
        return getWeightedSum(nestedList, maxDepth, 1);
    }

    /** DFS 计算最大深度 */
    private int getMaxDepth(List<NestedInteger> nestedList) {
        int maxDepth = 1;
        for (NestedInteger item : nestedList) {
            if (!item.isInteger()) {
                maxDepth = Math.max(maxDepth, 1 + getMaxDepth(item.getList()));
            }
        }
        return maxDepth;
    }

    /**
     * DFS 计算加权和
     * 权重 = maxDepth - currentDepth + 1
     */
    private int getWeightedSum(List<NestedInteger> nestedList,
                               int maxDepth, int currentDepth) {
        int total = 0;
        int weight = maxDepth - currentDepth + 1;

        for (NestedInteger item : nestedList) {
            if (item.isInteger()) {
                total += item.getInteger() * weight;
            } else {
                total += getWeightedSum(item.getList(), maxDepth, currentDepth + 1);
            }
        }

        return total;
    }
}
```

### 方法二：BFS 一次遍历（推荐，巧妙）

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public int depthSumInverse(List<NestedInteger> nestedList) {
        Deque<NestedInteger> queue = new ArrayDeque<>(nestedList);
        int totalSum = 0;  // 最终结果
        int levelSum  = 0; // 当前层及之前所有层的数字和

        while (!queue.isEmpty()) {
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                NestedInteger item = queue.pollFirst();

                if (item.isInteger()) {
                    // 将当前数字加到层和中
                    levelSum += item.getInteger();
                } else {
                    // 将嵌套列表的元素加入队列
                    queue.addAll(item.getList());
                }
            }

            // 每处理完一层，将当前的 levelSum 加到总和
            // 这样深度浅的数字会被累加更多次
            totalSum += levelSum;
        }

        return totalSum;
    }
}
```

### 方法三：DFS + 记录每层和

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int depthSumInverse(List<NestedInteger> nestedList) {
        List<Integer> levelSums = new ArrayList<>();  // levelSums.get(i) 表示深度为 i+1 的所有数字之和

        // DFS 收集每层的和
        dfs(nestedList, 0, levelSums);

        // 反向加权求和
        int total = 0;
        int maxDepth = levelSums.size();
        for (int depth = 0; depth < maxDepth; depth++) {
            int weight = maxDepth - depth;
            total += levelSums.get(depth) * weight;
        }

        return total;
    }

    /** DFS 遍历，记录每层的数字和 */
    private void dfs(List<NestedInteger> nestedList, int depth, List<Integer> levelSums) {
        // 确保 levelSums 有足够的空间
        if (depth >= levelSums.size()) {
            levelSums.add(0);
        }

        for (NestedInteger item : nestedList) {
            if (item.isInteger()) {
                levelSums.set(depth, levelSums.get(depth) + item.getInteger());
            } else {
                dfs(item.getList(), depth + 1, levelSums);
            }
        }
    }
}
```

## 复杂度分析

设 N 为所有整数的总数，D 为最大深度。

### 方法一：两次遍历
- 时间复杂度：O(N)，遍历两次
- 空间复杂度：O(D)，递归栈深度

### 方法二：BFS 一次遍历
- 时间复杂度：O(N)，每个元素访问一次
- 空间复杂度：O(N)，队列最多存储所有元素

### 方法三：DFS + 记录每层和
- 时间复杂度：O(N)
- 空间复杂度：O(D)

## 关键点总结

1. **反向加权**：深度越浅，权重越大，这是与 339 题的关键区别
2. **BFS 技巧**：通过累加层和，巧妙实现反向加权
3. **层序遍历**：BFS 天然按层处理，适合这类问题
4. **数学转换**：`weight = maxDepth - depth + 1`
5. **一次遍历优化**：方法二避免了两次遍历，更优雅

## 易错点

1. **权重计算**：注意是 `maxDepth - depth + 1`，不是简单的 `depth`
2. **深度定义**：第一层深度为 1，不是 0
3. **BFS 队列**：要用 `addAll` 而不是 `add`
4. **空嵌套列表**：要处理空列表的情况
5. **负数处理**：整数可以是负数，要正确累加
