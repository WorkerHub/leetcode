## 题目描述

给定一个字符串 `s`，重复执行以下操作直到无法继续：找到相邻的两个字符，它们在字母表中相邻（如 'a' 和 'b'，或 'z' 和 'a'），将它们删除。返回最终剩余的字符串。

## 解题思路

使用栈模拟：遍历字符串，将字符逐个压入栈。若栈顶字符与当前字符在字母表中相邻（差为 1，或 'a'/'z' 差为 25），则弹出栈顶完成消除；否则压入当前字符。

## Java 代码实现

```java
class Solution {
    public String resultingString(String s) {
        StringBuilder stack = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (stack.length() > 0) {
                char top = stack.charAt(stack.length() - 1);
                int diff = Math.abs(c - top);
                // 相邻字母：差为 1，或 'a' 和 'z'（差为 25）
                if (diff == 1 || diff == 25) {
                    stack.deleteCharAt(stack.length() - 1);
                    continue;
                }
            }
            stack.append(c);
        }
        return stack.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈的空间

## 关键点总结

1. 栈模拟：字符与栈顶字符相邻则消除
2. 字母表相邻包括 'a' 和 'z'（循环字母表，差为 25）
3. 栈操作正确处理连锁消除
