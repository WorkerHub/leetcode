## 题目描述

给你正整数数组 `nums`，返回其中一个**升序**子数组（严格递增的连续序列）的最大元素和。

## 解题思路

线性扫描：维护当前升序子数组的和 `curSum`。若当前元素比前一个大则累加，否则重置为当前元素。每步更新最大值。

## Java 代码实现

```java
class Solution {
    public int maxAscendingSum(int[] nums) {
        int maxSum = nums[0];
        int curSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                curSum += nums[i]; // 继续扩展升序子数组
            } else {
                curSum = nums[i]; // 重置为新子数组起点
            }
            maxSum = Math.max(maxSum, curSum);
        }

        return maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 升序条件严格（`>`，不含等号），遇到不升序则重置
2. 初始化 curSum 和 maxSum 均为 nums[0]
