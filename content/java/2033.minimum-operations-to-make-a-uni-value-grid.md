## 题目描述

给定 m×n 的整数网格 `grid` 和整数 `x`，每次操作可将任一元素加减 x，返回将所有元素变为同一值的最少操作次数，不可能则返回 -1。

## 解题思路

将所有元素展平排序，若各元素与 `grid[0][0]` 的差不能被 x 整除则返回 -1。以中位数为目标值时操作次数最少，累加 `|val - median| / x`。

## Java 代码实现

### 方法一：排序取中位数（推荐）

```java
import java.util.*;

class Solution {
    public int minOperations(int[][] grid, int x) {
        int m = grid.length, n = grid[0].length;
        int[] vals = new int[m * n];
        int k = 0;
        for (int[] row : grid) {
            for (int v : row) vals[k++] = v;
        }
        Arrays.sort(vals);
        int base = vals[0] % x;
        for (int v : vals) {
            if (v % x != base) return -1;  // 余数不同，无法统一
        }
        int median = vals[vals.length / 2];
        int ops = 0;
        for (int v : vals) ops += Math.abs(v - median) / x;
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))
- 空间复杂度：O(mn)

## 关键点总结

1. 所有元素模 x 的余数必须相同，否则不可能
2. 以中位数为目标值使总操作次数最小
3. 每次操作距离为 x，因此操作次数为 `|val - median| / x`
