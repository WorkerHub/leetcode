## 题目描述

构造长度为 n 的正整数数组，相邻元素差不超过 1，总和不超过 `maxSum`，使 `nums[index]` 最大。返回该最大值。

## 解题思路

二分查找：对 `nums[index]` 的值 v 做二分，判断以 v 为峰值时的最小数组总和是否 <= maxSum。

两侧各自最小和：长度 L，峰值 v，若 `v >= L` 则为等差数列和；否则前段填 1 剩余等差数列。用 `long` 防溢出。

## Java 代码实现

```java
class Solution {
    public int maxValue(int n, int index, int maxSum) {
        int lo = 1, hi = maxSum;
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (minSum(mid, index + 1) + minSum(mid, n - index) - mid <= maxSum) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }

    // 计算以 peak 为末尾（最大值），向左延伸 length 个元素的最小和（含 peak 本身）
    private long minSum(long peak, long length) {
        if (peak >= length) {
            // 等差数列：peak, peak-1, ..., peak-length+1
            return (peak - length + 1 + peak) * length / 2;
        } else {
            // 前 length-peak 个填 1，后 peak 个为 1,2,...,peak
            return (length - peak) + peak * (peak + 1) / 2;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(maxSum))
- **空间复杂度**：O(1)

## 关键点总结

1. 对答案二分，贪心验证：以 v 为峰值两侧尽可能小
2. 等差数列公式计算最小和，`long` 防溢出
3. 峰值本身被 minSum 计算了两次，需减去一次 mid
