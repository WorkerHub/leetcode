## 题目描述

在整型数组 `nums` 中找出由三个数组成的最大乘积。

**示例：**
```
输入：nums = [1,2,3,4]
输出：24
```

## 解题思路

最大乘积只可能来自：三个最大正数，或两个最小负数 × 最大正数。

## Java 代码实现

```java
class Solution {
    public int maximumProduct(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        // 情况1：三个最大数
        int prod1 = nums[n - 1] * nums[n - 2] * nums[n - 3];
        // 情况2：两个最小数 × 最大数
        int prod2 = nums[0] * nums[1] * nums[n - 1];
        return Math.max(prod1, prod2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **负数特性**：两个负数相乘变正数
2. **只需比较两种情况**：三个最大 vs 两小一大
3. **排序简化**：排序后直接取首尾
