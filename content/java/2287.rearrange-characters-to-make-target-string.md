## 题目描述

用s中的字符最多能组成多少个target副本。

## 解题思路

统计s和target各字符频次，对target中每个字符取freq_s/freq_t的最小值。

## Java 代码实现

```java
class Solution {
    public int rearrangeCharacters(String s, String target) {
        int[] freqS = new int[26], freqT = new int[26];
        for (char c : s.toCharArray()) freqS[c - 'a']++;
        for (char c : target.toCharArray()) freqT[c - 'a']++;

        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < 26; i++) {
            if (freqT[i] > 0) {
                ans = Math.min(ans, freqS[i] / freqT[i]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|s| + |target|)
- **空间复杂度**：O(1)

## 关键点总结

1. **短板效应**：取所有字符能组成副本数的最小值
2. **整除**：freqS[c]/freqT[c]向下取整
3. **只看target中出现的字符**
