## 题目描述

找特征值x：数组中恰好有x个元素>=x。不存在返回-1。

**示例：**
```
输入：nums = [3,5]
输出：2
```

## 解题思路

排序后枚举x从0到n，用二分查找统计>=x的元素数。

## Java 代码实现

```java
class Solution {
    public int specialArray(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        
        for (int x = 0; x <= n; x++) {
            // 二分查找第一个 >= x 的位置
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (nums[mid] >= x) hi = mid;
                else lo = mid + 1;
            }
            int count = n - lo;
            if (count == x) return x;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **x范围[0,n]**：不可能有超过n个元素
2. **排序+二分**：快速统计>=x的元素数
3. **答案唯一**：找到即返回
