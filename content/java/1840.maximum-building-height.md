## 题目描述

n座建筑，第一座高度0，相邻高度差≤1，部分建筑有高度上限约束。求最大可能高度。

## 解题思路

两遍贪心传播：从左到右和从右到左传播约束，然后相邻约束点间峰值 = (h1+h2+distance)/2。

## Java 代码实现

```java
class Solution {
    public int maxBuilding(int n, int[][] restrictions) {
        // 加入起点和终点
        int m = restrictions.length;
        int[][] restr = new int[m + 2][2];
        restr[0] = new int[]{1, 0};
        for (int i = 0; i < m; i++) restr[i + 1] = restrictions[i].clone();
        restr[m + 1] = new int[]{n, n - 1};
        Arrays.sort(restr, (a, b) -> a[0] - b[0]);
        
        int total = restr.length;
        // 从左到右传播
        for (int i = 1; i < total; i++) {
            int diff = restr[i][0] - restr[i - 1][0];
            restr[i][1] = Math.min(restr[i][1], restr[i - 1][1] + diff);
        }
        // 从右到左传播
        for (int i = total - 2; i >= 0; i--) {
            int diff = restr[i + 1][0] - restr[i][0];
            restr[i][1] = Math.min(restr[i][1], restr[i + 1][1] + diff);
        }
        
        // 计算每段区间最大高度
        int ans = 0;
        for (int i = 0; i < total - 1; i++) {
            int dist = restr[i + 1][0] - restr[i][0];
            int peak = (restr[i][1] + restr[i + 1][1] + dist) / 2;
            ans = Math.max(ans, peak);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M log M)
- **空间复杂度**：O(M)

## 关键点总结

1. **双向传播约束**：每个点受左右两侧限制
2. **区间峰值公式**：(h1+h2+dist)/2
3. **终点约束**：最大高度为n-1
