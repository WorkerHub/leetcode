## 题目描述

给你一个整数数组 nums。玩家 1 和玩家 2 基于这个数组设计了一个游戏。

玩家 1 和玩家 2 轮流进行自己的回合，玩家 1 先手。开始时，两个玩家的初始分值都是 0。每一回合，玩家从数组的任意一端取一个数字（即，nums[0] 或 nums[nums.length - 1]），取到的数字将会从数组中移除（数组长度减 1）。玩家选中的数字将会加到他的得分上。当数组中没有剩余数字可取时，游戏结束。

如果玩家 1 能成为赢家，返回 true。如果两个玩家得分相等，同样认为玩家 1 是游戏的赢家，也返回 true。你可以假设每个玩家的玩法都会使他的分数最大化。

**示例 1：**
```
输入：nums = [1,5,2]
输出：false
解释：一开始，玩家 1 可以从 1 和 2 中进行选择。
如果他选择 2（或者 1），那么玩家 2 可以从 1（或者 2）和 5 中进行选择。如果玩家 2 选择了 5，那么玩家 1 则只剩下 1（或者 2）可选。
所以，玩家 1 的最终分数为 1 + 2 = 3，而玩家 2 为 5。
因此，玩家 1 永远不会成为赢家，返回 false。
```

**示例 2：**
```
输入：nums = [1,5,233,7]
输出：true
解释：玩家 1 一开始选择 1。然后玩家 2 必须从 5 和 7 中选择。无论玩家 2 选择了哪个，玩家 1 都可以选择 233。
最终，玩家 1（234 分）比玩家 2（12 分）获得更多的分数，所以返回 true，表示玩家 1 可以成为赢家。
```

**提示：**
- 1 <= nums.length <= 20
- 0 <= nums[i] <= 10^7

## 解题思路

这是一道经典的博弈论 + 动态规划题目。

### 核心思想

1. **博弈论视角**：
   - 两个玩家都采取最优策略
   - 玩家 1 想要最大化自己的优势
   - 玩家 2 想要最小化玩家 1 的优势

2. **状态定义**：
   - `dp[i][j]` 表示当剩余数组为 nums[i...j] 时，当前玩家与另一个玩家的分数差的最大值
   - 当前玩家可以选择 nums[i] 或 nums[j]

3. **状态转移**：
   - 选择 nums[i]：当前玩家得分 + nums[i]，对手在 nums[i+1...j] 中选择
   - 选择 nums[j]：当前玩家得分 + nums[j]，对手在 nums[i...j-1] 中选择
   - `dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`

4. **递归思路**：
   - 定义函数 `maxDiff(i, j)` 表示在区间 [i, j] 中当前玩家能获得的最大分数差
   - 基础情况：只有一个元素时，当前玩家拿走它

## Java 代码实现

### 方法一：递归 + 记忆化（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<String, Integer> memo = new HashMap<>();

    public boolean predictTheWinner(int[] nums) {
        // 递归 + 记忆化搜索
        // 时间复杂度：O(n²)
        // 空间复杂度：O(n²)
        return maxDiff(nums, 0, nums.length - 1) >= 0;
    }

    private int maxDiff(int[] nums, int i, int j) {
        // 返回在区间 [i, j] 中，当前玩家与对手的最大分数差
        if (i == j) {
            // 只有一个元素，当前玩家拿走
            return nums[i];
        }

        String key = i + "," + j;
        if (memo.containsKey(key)) return memo.get(key);

        // 选择左边：得到 nums[i]，对手在 [i+1, j] 中选择
        int chooseLeft = nums[i] - maxDiff(nums, i + 1, j);

        // 选择右边：得到 nums[j]，对手在 [i, j-1] 中选择
        int chooseRight = nums[j] - maxDiff(nums, i, j - 1);

        // 选择分数差最大的
        int result = Math.max(chooseLeft, chooseRight);
        memo.put(key, result);

        return result;
    }
}
```

### 方法二：动态规划（自底向上）

```java
class Solution {
    public boolean predictTheWinner(int[] nums) {
        // 动态规划，自底向上
        // 时间复杂度：O(n²)
        // 空间复杂度：O(n²)
        int n = nums.length;
        // dp[i][j] 表示在区间 [i, j] 中当前玩家的最大分数差
        int[][] dp = new int[n][n];

        // 初始化：只有一个元素的情况
        for (int i = 0; i < n; i++) {
            dp[i][i] = nums[i];
        }

        // 按区间长度从小到大遍历
        for (int length = 2; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                // 选择左边或右边，取最大分数差
                dp[i][j] = Math.max(
                    nums[i] - dp[i + 1][j],
                    nums[j] - dp[i][j - 1]
                );
            }
        }

        // 判断玩家 1 是否能赢
        return dp[0][n - 1] >= 0;
    }
}
```

### 方法三：动态规划（空间优化）

```java
class Solution {
    public boolean predictTheWinner(int[] nums) {
        // 动态规划 + 空间优化
        // 时间复杂度：O(n²)
        // 空间复杂度：O(n)
        int n = nums.length;
        // 使用一维数组，dp[j] 表示区间 [i, j] 的最大分数差
        int[] dp = nums.clone();

        // 从后往前遍历起点
        for (int i = n - 2; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                // dp[j] 当前表示 [i+1, j]
                // 更新为 [i, j]
                dp[j] = Math.max(nums[i] - dp[j], nums[j] - dp[j - 1]);
            }
        }

        return dp[n - 1] >= 0;
    }
}
```

### 方法四：MinMax 算法（更清晰的博弈论）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<String, int[]> memo = new HashMap<>();

    public boolean predictTheWinner(int[] nums) {
        // MinMax 算法：直接计算两个玩家的分数
        // 时间复杂度：O(n²)
        // 空间复杂度：O(n²)
        int[] scores = helper(nums, 0, nums.length - 1);
        // scores[0] 是当前玩家（玩家1）的得分，scores[1] 是对手的得分
        return scores[0] >= scores[1];
    }

    private int[] helper(int[] nums, int i, int j) {
        // 返回 {当前玩家分数, 对手分数}
        if (i == j) {
            return new int[]{nums[i], 0};
        }

        String key = i + "," + j;
        if (memo.containsKey(key)) return memo.get(key);

        // 选择左边
        int[] resLeft = helper(nums, i + 1, j);
        int[] chooseLeft = new int[]{nums[i] + resLeft[1], resLeft[0]};

        // 选择右边
        int[] resRight = helper(nums, i, j - 1);
        int[] chooseRight = new int[]{nums[j] + resRight[1], resRight[0]};

        // 当前玩家选择分数更高的
        int[] result = (chooseLeft[0] >= chooseRight[0]) ? chooseLeft : chooseRight;
        memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(n²)
  - 状态总数：O(n²)
  - 每个状态计算：O(1)
  
- **空间复杂度**：
  - 方法一、二、四：O(n²) - 存储所有状态
  - 方法三：O(n) - 空间优化

## 关键点总结

1. **博弈论问题转换**：将双人博弈转换为动态规划
2. **分数差思想**：记录分数差而不是绝对分数
3. **状态定义**：`dp[i][j]` 表示当前玩家的最大优势
4. **状态转移**：选择左边或右边，减去对手的优势
5. **空间优化**：可以压缩到一维数组

## 易错点

1. **状态含义理解**
   - dp[i][j] 是当前玩家的优势，不是玩家 1 的优势
   - 每次递归都是站在当前玩家的角度

2. **符号错误**
   - 选择后要减去对手在剩余区间的优势
   - 不是加上对手的优势

3. **边界条件**
   - i == j 时，当前玩家得到 nums[i]
   - 不要忘记初始化

4. **数组长度为 1**
   - nums = [1] 时，玩家 1 直接赢
   - 确保代码能处理

5. **空间优化的遍历顺序**
   - 必须从后往前遍历 i
   - 从前往后遍历 j
   - 顺序错误会导致结果错误
