## 题目描述

给定链表 head，对每个节点找到下一个值更大的节点值，没有则为 0。返回结果数组。

**示例：**
```
输入：head = [2,7,4,3,5]
输出：[7,0,5,5,0]
```

## 解题思路

链表转数组 + 单调栈：单调递减栈存储索引，遇到更大值时弹出栈顶并记录答案。

## Java 代码实现

```java
class Solution {
    public int[] nextLargerNodes(ListNode head) {
        // 链表转数组
        List<Integer> values = new ArrayList<>();
        ListNode curr = head;
        while (curr != null) {
            values.add(curr.val);
            curr = curr.next;
        }

        int n = values.size();
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>(); // 单调递减栈，存索引

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && values.get(stack.peek()) < values.get(i)) {
                result[stack.pop()] = values.get(i);
            }
            stack.push(i);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **链表转数组**：方便随机访问和索引操作
2. **单调递减栈**：维护待匹配的元素索引
3. **每个元素最多入栈出栈一次**：保证 O(n)
