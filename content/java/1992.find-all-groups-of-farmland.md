## 题目描述

给定 `m x n` 矩阵 `land`，1 表示农田，0 表示荒地，农田区域为矩形且互不相邻，找出所有农田组并用 `[r1, c1, r2, c2]`（左上角、右下角坐标）表示。

## 解题思路

扫描矩阵，找左上角（当前为 1，且上方和左方均不是 1），然后从左上角向下、向右扩展找右下角坐标。

## Java 代码实现

### 方法一：直接推算右下角（推荐）

```java
import java.util.*;

class Solution {
    public int[][] findFarmland(int[][] land) {
        int m = land.length, n = land[0].length;
        List<int[]> result = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 找左上角：当前为1，且上方和左方不是1
                if (land[i][j] == 1 &&
                    (i == 0 || land[i-1][j] == 0) &&
                    (j == 0 || land[i][j-1] == 0)) {
                    int r2 = i, c2 = j;
                    // 向下扩展
                    while (r2 + 1 < m && land[r2 + 1][j] == 1) r2++;
                    // 向右扩展
                    while (c2 + 1 < n && land[i][c2 + 1] == 1) c2++;
                    result.add(new int[]{i, j, r2, c2});
                }
            }
        }

        return result.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. 农田为矩形且不相邻，可直接找左上角后向右向下推算右下角
2. 左上角条件：上方为 0（或边界）且左方为 0（或边界）
3. 无需 visited 数组，直接利用矩形性质
