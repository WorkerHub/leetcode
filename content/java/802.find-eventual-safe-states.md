## 题目描述

有一个有 `n` 个节点的有向图，节点按 `0` 到 `n - 1` 编号。图由一个 **索引从 0 开始** 的二维整数数组 `graph` 表示，`graph[i]` 是与节点 `i` 相邻的节点的整数数组，这意味着从节点 `i` 到 `graph[i]` 中的每个节点都有一条有向边。

如果一个节点没有连出的有向边，则它是 **终端节点**。如果从该节点开始的所有可能路径都通向 **终端节点**，则该节点为 **安全节点**。

返回一个由图中所有 **安全节点** 组成的数组作为答案。答案数组中的元素应当按 **升序** 排列。

**示例 1:**
```
输入: graph = [[1,2],[2,3],[5],[0],[5],[],[]]
输出: [2,4,5,6]
解释: 
节点 5 和节点 6 是终端节点，因为它们没有出边。
从节点 2、4、5、6 开始的所有路径都通向终端节点，所以它们是安全节点。
```

**示例 2:**
```
输入: graph = [[1,2,3,4],[1,2],[3,4],[0,4],[]]
输出: [4]
解释:
只有节点 4 是安全的。从其他节点出发都可能到达一个环。
```

**提示:**
- `n == graph.length`
- `1 <= n <= 10^4`
- `0 <= graph[i].length <= n`
- `0 <= graph[i][j] <= n - 1`
- `graph[i]` 按严格递增顺序排列
- 图中可能包含自环
- 图中边的数目在范围 `[1, 4 * 10^4]` 内

## 解题思路

**核心思想**：一个节点是安全的，当且仅当它不在环中，且所有能到达的节点也是安全的。

**问题转换**：
- 如果一个节点在环中，它就不安全
- 如果一个节点能到达环，它也不安全
- 终端节点（没有出边）一定是安全的

**解法思路**：

1. **DFS + 三色标记法**：
   - 白色（0）：未访问
   - 灰色（1）：正在访问（在当前 DFS 路径中）
   - 黑色（2）：已访问完成且安全
   
   如果 DFS 过程中遇到灰色节点，说明存在环。

2. **拓扑排序（反向图）**：
   - 构建反向图
   - 从终端节点开始反向拓扑排序
   - 能被访问到的节点都是安全节点

## Java 代码实现

### 方法一：DFS + 三色标记（推荐）

```java
import java.util.*;

class Solution {
    // 0: 未访问, 1: 正在访问, 2: 已完成且安全
    int[] color;
    int[][] graph;

    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        this.graph = graph;
        this.color = new int[n];

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (dfs(i)) {
                result.add(i);
            }
        }
        return result;
    }

    /**
     * 判断节点是否安全
     * 返回 true 表示安全，false 表示不安全（在环中或能到达环）
     */
    private boolean dfs(int node) {
        if (color[node] > 0) {
            // 如果是灰色（1），说明在当前路径中再次遇到，存在环
            // 如果是黑色（2），说明之前已确认安全
            return color[node] == 2;
        }

        // 标记为灰色，表示正在访问
        color[node] = 1;

        // 检查所有相邻节点
        for (int neighbor : graph[node]) {
            if (!dfs(neighbor)) {
                // 如果任何一个相邻节点不安全，当前节点也不安全
                return false;
            }
        }

        // 所有相邻节点都安全，标记为黑色
        color[node] = 2;
        return true;
    }
}
```

### 方法二：拓扑排序（反向图）

```java
import java.util.*;

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;

        // 构建反向图和出度数组
        List<List<Integer>> reverseGraph = new ArrayList<>();
        int[] outDegree = new int[n];

        for (int i = 0; i < n; i++) {
            reverseGraph.add(new ArrayList<>());
        }

        for (int i = 0; i < n; i++) {
            outDegree[i] = graph[i].length;
            for (int j : graph[i]) {
                reverseGraph.get(j).add(i);
            }
        }

        // 从终端节点（出度为0的节点）开始
        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (outDegree[i] == 0) {
                queue.offer(i);
            }
        }

        boolean[] safe = new boolean[n];

        // 反向拓扑排序
        while (!queue.isEmpty()) {
            int node = queue.poll();
            safe[node] = true;

            // 对于所有指向当前节点的节点
            for (int prev : reverseGraph.get(node)) {
                outDegree[prev]--;
                if (outDegree[prev] == 0) {
                    queue.offer(prev);
                }
            }
        }

        // 收集所有安全节点
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (safe[i]) {
                result.add(i);
            }
        }

        return result;
    }
}
```

### 方法三：记忆化 DFS

```java
import java.util.*;

class Solution {
    // 0: 未访问, 1: 不安全, 2: 安全
    int[] memo;
    int[][] graph;

    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        this.graph = graph;
        this.memo = new int[n];

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (isSafe(i)) {
                result.add(i);
            }
        }
        return result;
    }

    private boolean isSafe(int node) {
        if (memo[node] != 0) {
            return memo[node] == 2;
        }

        // 标记为不安全（防止环）
        memo[node] = 1;

        for (int neighbor : graph[node]) {
            if (!isSafe(neighbor)) {
                return false;
            }
        }

        // 所有相邻节点都安全
        memo[node] = 2;
        return true;
    }
}
```

## 复杂度分析

### 方法一和方法三：
- **时间复杂度**：O(V + E)，其中 V 是节点数，E 是边数，每个节点和边都访问一次
- **空间复杂度**：O(V)，递归栈和颜色数组

### 方法二：
- **时间复杂度**：O(V + E)，构建反向图和拓扑排序都是线性时间
- **空间复杂度**：O(V + E)，存储反向图

## 关键点总结

1. **问题本质**：检测图中的环，不在环中且不能到达环的节点是安全的
2. **三色标记法**：DFS 中用于检测环的经典方法
3. **反向思维**：从终端节点反向扩展，能到达的节点都安全
4. **记忆化优化**：避免重复计算同一个节点
5. **终端节点**：出度为 0 的节点一定安全

## 易错点

1. **环的检测**：必须在 DFS 过程中标记"正在访问"状态，而不是"已访问"
2. **返回值顺序**：结果需要升序排列，但由于我们按顺序遍历，自然就是升序的
3. **记忆化陷阱**：在 DFS 开始时就标记为不安全，防止环中的节点互相递归
4. **终端节点判断**：出度为 0，而不是入度为 0
