## 题目描述

找出 s1 中最短的连续子串 window，使得 s2 是 window 的子序列。不存在返回空串。

**示例：**
```
输入：s1 = "abcdebdde", s2 = "bde"
输出："bcde"
```

## 解题思路

双指针：先向右扩展找到完整子序列匹配，再向左收缩找到最短窗口。记录全局最小窗口。

## Java 代码实现

```java
class Solution {
    public String minWindow(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        int minLen = Integer.MAX_VALUE;
        int start = -1;

        int i = 0, j = 0;
        while (i < m) {
            if (s1.charAt(i) == s2.charAt(j)) {
                j++;
                if (j == n) {
                    // 找到匹配，向左收缩
                    int end = i + 1;
                    j--;
                    while (j >= 0) {
                        if (s1.charAt(i) == s2.charAt(j)) j--;
                        i--;
                    }
                    i++;
                    j++;

                    if (end - i < minLen) {
                        minLen = end - i;
                        start = i;
                    }
                    // 从 i+1 重新开始
                    j = 0;
                }
            }
            i++;
        }
        return start == -1 ? "" : s1.substring(start, start + minLen);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)

## 关键点总结

1. **先扩展后收缩**：先向右找完整匹配，再向左找最短窗口
2. **子序列匹配**：不要求连续，但窗口本身是连续子串
3. **全局最小**：记录所有窗口中的最短
