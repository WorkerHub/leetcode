## 题目描述

给你整数数组 `nums` 和查询数组 `queries`（`queries[i] = [from, to]`），对每个查询判断子数组 `nums[from..to]` 是否为特殊数组（相邻元素奇偶性不同）。

## 解题思路

预处理前缀和：若 `nums[i]` 与 `nums[i-1]` 奇偶性相同则记为违规，`prefix[i+1] = prefix[i] + bad[i]`。子数组 `[l, r]` 特殊当且仅当 `prefix[r+1] - prefix[l+1] == 0`（即区间 `[l+1, r]` 内无违规）。

## Java 代码实现

```java
class Solution {
    public boolean[] isArraySpecial(int[] nums, int[][] queries) {
        int n = nums.length;
        // prefix[i] 记录前 i 个位置的违规次数
        int[] prefix = new int[n + 1];
        for (int i = 1; i < n; i++) {
            // nums[i] 与 nums[i-1] 奇偶相同则违规
            prefix[i + 1] = prefix[i] + (nums[i] % 2 == nums[i - 1] % 2 ? 1 : 0);
        }
        boolean[] ans = new boolean[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            // 检查 [l+1, r] 范围内是否有违规
            ans[i] = (prefix[r + 1] - prefix[l + 1]) == 0;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)，预处理 O(n)，每次查询 O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. 预处理违规位置前缀和，每次查询 O(1) 响应
2. 子数组 `[l, r]` 对应检查范围为 `[l+1, r]`（相邻对的右端点）
3. 违规即相邻元素奇偶性相同
