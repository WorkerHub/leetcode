## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例 1：**
```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**
```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

**提示：**
- `1 <= n <= 45`

## 解题思路

核心思想：动态规划（斐波那契数列）

关键观察：
- 到达第n阶 = 从第n-1阶爬1阶 + 从第n-2阶爬2阶
- dp[n] = dp[n-1] + dp[n-2]

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;

        int prev2 = 1, prev1 = 2;

        for (int i = 3; i <= n; i++) {
            int current = prev1 + prev2;
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
```

### 方法二：递归（会超时，仅供理解）

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
}
```

## 复杂度分析

**动态规划：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**递归：**
- 时间复杂度：O(2^n)
- 空间复杂度：O(n)

## 关键点总结

1. **状态转移**：dp[n] = dp[n-1] + dp[n-2]
2. **空间优化**：只需要两个变量
3. **本质**：斐波那契数列

## 易错点

1. **初始值**：n=1时返回1，n=2时返回2
2. **递归超时**：必须用动态规划
