## 题目描述

给定两个 n×n 二进制矩阵，可以平移其中一个图像覆盖另一个。返回最大重叠（两个图像都为 1 的位置数）。

**示例：**
```
输入：img1 = [[1,1,0],[0,1,0],[0,1,0]], img2 = [[0,0,0],[0,1,1],[0,0,1]]
输出：3
```

## 解题思路

记录两个矩阵中 1 的位置，枚举所有可能的平移向量，统计每个向量下的重叠数。

## Java 代码实现

```java
class Solution {
    public int largestOverlap(int[][] img1, int[][] img2) {
        int n = img1.length;
        List<int[]> ones1 = new ArrayList<>();
        List<int[]> ones2 = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (img1[i][j] == 1) ones1.add(new int[]{i, j});
                if (img2[i][j] == 1) ones2.add(new int[]{i, j});
            }
        }

        // 统计每个平移向量的重叠次数
        Map<String, Integer> counter = new HashMap<>();
        int maxOverlap = 0;

        for (int[] p1 : ones1) {
            for (int[] p2 : ones2) {
                String key = (p1[0] - p2[0]) + "," + (p1[1] - p2[1]);
                int count = counter.merge(key, 1, Integer::sum);
                maxOverlap = Math.max(maxOverlap, count);
            }
        }

        return maxOverlap;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n⁴)，最坏情况所有位置都是 1
- **空间复杂度**：O(n²)

## 关键点总结

1. **平移向量**：两个 1 的位置差定义了平移
2. **HashMap 计数**：相同向量出现次数即重叠数
3. **只考虑 1**：跳过 0 的位置提高效率
