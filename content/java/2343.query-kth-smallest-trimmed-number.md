## 题目描述

字符串数组 `nums` 中每个字符串长度相同，对每个查询 `[k, trim]`，将所有数字裁剪为后 trim 位后排序，返回第 k 小的数在原数组中的下标（多个相同取最小下标）。

## 解题思路

数据规模小（n, q <= 100），直接暴力模拟：对每个查询截取所有字符串后 trim 位，组成 `(裁剪串, 原始下标)` 对进行排序，取第 k 个的原始下标。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] smallestTrimmedNumbers(String[] nums, int[][] queries) {
        int[] ans = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int k = queries[q][0], trim = queries[q][1];
            int n = nums.length;
            // 构建 [裁剪串, 原始下标] 对
            String[][] trimmed = new String[n][2];
            for (int i = 0; i < n; i++) {
                trimmed[i][0] = nums[i].substring(nums[i].length() - trim);
                trimmed[i][1] = String.valueOf(i);
            }
            // 按裁剪串升序，相同则按下标升序
            Arrays.sort(trimmed, (a, b) -> {
                int cmp = a[0].compareTo(b[0]);
                return cmp != 0 ? cmp : Integer.parseInt(a[1]) - Integer.parseInt(b[1]);
            });
            ans[q] = Integer.parseInt(trimmed[k - 1][1]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q × n × log(n) × L)，q 为查询数，L 为字符串长度
- **空间复杂度**：O(n)

## 关键点总结

1. 长度相同的数字字符串，字典序等价于数值大小。
2. 排序元组时先按裁剪串，相同则按原始下标升序，满足"取最小下标"要求。
3. 数据规模小（≤100），暴力模拟即可。
