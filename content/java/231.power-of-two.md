## 题目描述

给你一个整数 `n`，请你判断该整数是否是 2 的幂次方。如果是，返回 `true`；否则，返回 `false`。

如果存在一个整数 `x` 使得 `n == 2^x`，则认为 `n` 是 2 的幂次方。

**示例 1：**
```
输入：n = 1
输出：true
解释：2^0 = 1
```

**示例 2：**
```
输入：n = 16
输出：true
解释：2^4 = 16
```

**示例 3：**
```
输入：n = 3
输出：false
```

**提示：**
- `-2^31 <= n <= 2^31 - 1`

## 解题思路

判断一个数是否是 2 的幂次方，有多种巧妙的方法：

**核心观察：**
1. 2 的幂次方在二进制表示中只有一个 1（例如：1=0001, 2=0010, 4=0100, 8=1000）
2. 2 的幂次方减 1 后，所有位都变成 1（例如：8-1=7，1000-1=0111）
3. 2 的幂次方必须是正数

**关键技巧：**
- 如果 n 是 2 的幂，则 `n & (n-1) == 0`
- 这是因为 n 和 n-1 在二进制上没有重叠的 1

## Java 代码实现

### 方法一：位运算（推荐）⭐

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // 首先 n 必须大于 0
        // 然后 n & (n-1) 应该等于 0（消除最右边的 1 后为 0）
        return n > 0 && (n & (n - 1)) == 0;
    }
}
```

### 方法二：位运算变体

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // 另一种位运算技巧：n & (-n) 可以获取最右边的 1
        // 如果 n 是 2 的幂，则只有一个 1，应该等于 n 本身
        return n > 0 && (n & -n) == n;
    }
}
```

### 方法三：取模运算

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // 不断除以 2，如果是 2 的幂，最后应该等于 1
        if (n <= 0) {
            return false;
        }
        while (n % 2 == 0) {
            n /= 2;
        }
        return n == 1;
    }
}
```

### 方法四：利用最大 2 的幂

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // 在 32 位整数范围内，最大的 2 的幂是 2^30 = 1073741824
        // 如果 n 是 2 的幂，则它一定能整除这个最大值
        return n > 0 && 1073741824 % n == 0;
    }
}
```

### 方法五：使用数学方法

```java
class Solution {
    public boolean isPowerOfTwo(int n) {
        // 使用对数计算
        if (n <= 0) {
            return false;
        }
        // 计算 log2(n)，如果是整数则是 2 的幂
        double logVal = Math.log(n) / Math.log(2);
        return Math.abs(logVal - Math.round(logVal)) < 1e-10;
    }
}
```

## 复杂度分析

**方法一（位运算）：**
- 时间复杂度：O(1)，只需要一次位运算
- 空间复杂度：O(1)

**方法三（取模运算）：**
- 时间复杂度：O(log n)，需要循环 log n 次
- 空间复杂度：O(1)

## 关键点总结

1. **位运算技巧**：`n & (n-1)` 可以消除最低位的 1，是判断 2 的幂的最优方法
2. **边界条件**：必须先判断 n > 0，因为 2 的幂一定是正数
3. **二进制特征**：2 的幂在二进制中只有一个 1
4. **多种解法**：位运算、取模、数学方法都可以解决
5. **性能对比**：位运算是 O(1)，最优解

## 易错点

1. **忘记判断 n > 0**：负数和 0 不是 2 的幂
   ```java
   // 错误：没有判断正数
   return (n & (n - 1)) == 0;
   
   // 正确
   return n > 0 && (n & (n - 1)) == 0;
   ```

2. **混淆位运算优先级**：需要加括号
   ```java
   // 错误：位运算优先级低于比较运算
   return n > 0 && n & (n - 1) == 0;
   
   // 正确
   return n > 0 && (n & (n - 1)) == 0;
   ```

3. **使用浮点数计算时的精度问题**：Math.log 可能有精度误差，需要用容差比较

4. **对 1 的处理**：1 = 2^0，是 2 的幂，不要遗漏

## 学习建议

1. **掌握位运算基础**：
   - 理解 `n & (n-1)` 消除最低位 1 的原理
   - 理解 `n & -n` 获取最低位 1 的原理
   - 这两个技巧在很多位运算题目中都会用到

2. **理解二进制表示**：
   - 2 的幂：1, 10, 100, 1000...
   - 2 的幂减 1：0, 1, 11, 111...
   - 相与结果：0, 0, 0, 0...

3. **循序渐进**：
   - 先理解取模方法（直观）
   - 再学习位运算方法（高效）
   - 最后掌握数学方法（拓展）

4. **举一反三**：
   - 判断 3 的幂、4 的幂有何不同
   - 4 的幂除了是 2 的幂，还有什么特征
   - 如何判断一个数的二进制中有多少个 1
