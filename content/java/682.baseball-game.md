## 题目描述

棒球比赛记录员，处理操作列表：整数 x 记录得分，"+" 加前两次得分之和，"D" 加前一次得分两倍，"C" 移除前一次得分。返回总分。

**示例：**
```
输入：ops = ["5","2","C","D","+"]
输出：30
```

## 解题思路

用栈维护有效得分记录，遍历操作按规则处理，最后求和。

## Java 代码实现

```java
class Solution {
    public int calPoints(String[] operations) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String op : operations) {
            if (op.equals("+")) {
                int top = stack.pop();
                int newScore = top + stack.peek();
                stack.push(top);
                stack.push(newScore);
            } else if (op.equals("D")) {
                stack.push(2 * stack.peek());
            } else if (op.equals("C")) {
                stack.pop();
            } else {
                stack.push(Integer.parseInt(op));
            }
        }

        int sum = 0;
        for (int score : stack) {
            sum += score;
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈应用**：需要频繁访问/删除最近元素
2. **字符串判断**：区分操作符和数字（含负数）
3. **"+" 操作**：需要访问栈顶两个元素
