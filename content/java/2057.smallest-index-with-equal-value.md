## 题目描述

给定整数数组 `nums`，返回满足 `i % 10 == nums[i]` 的最小下标，不存在则返回 -1。

## 解题思路

直接遍历，找到第一个满足条件的下标返回。

## Java 代码实现

### 方法一：遍历（推荐）

```java
class Solution {
    public int smallestEqual(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (i % 10 == nums[i]) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 条件是 `i % 10`（取个位数），而非 `i`
