## 题目描述

实现一个二叉搜索树迭代器类 `BSTIterator`，表示一个按中序遍历二叉搜索树（BST）的迭代器：

- `BSTIterator(TreeNode root)` 初始化 BSTIterator 类的一个对象。BST 的根节点 `root` 会作为构造函数的一部分给出。指针应初始化为一个不存在于 BST 中的数字，且该数字小于 BST 中的任何元素。
- `boolean hasNext()` 如果向指针右侧遍历存在数字，则返回 `true`；否则返回 `false`。
- `int next()` 将指针向右移动，然后返回指针处的数字。

注意，指针初始化为一个不存在于 BST 中的数字，所以对 `next()` 的首次调用将返回 BST 中的最小元素。

你可以假设 `next()` 调用总是有效的，也就是说，当调用 `next()` 时，BST 的中序遍历中至少存在一个下一个数字。

**示例：**
```
输入
["BSTIterator", "next", "next", "hasNext", "next", "hasNext", "next", "hasNext", "next", "hasNext"]
[[[7, 3, 15, null, null, 9, 20]], [], [], [], [], [], [], [], [], []]
输出
[null, 3, 7, true, 9, true, 15, true, 20, false]

解释
BSTIterator bSTIterator = new BSTIterator([7, 3, 15, null, null, 9, 20]);
bSTIterator.next();    // 返回 3
bSTIterator.next();    // 返回 7
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 9
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 15
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 20
bSTIterator.hasNext(); // 返回 False
```

**提示：**
- 树中节点的数目在范围 [1, 10^5] 内
- 0 <= Node.val <= 10^6
- 最多调用 10^5 次 `hasNext` 和 `next` 操作

**进阶：**
- 你可以设计一个满足下述条件的解决方案吗？`next()` 和 `hasNext()` 操作均摊时间复杂度为 O(1)，并使用 O(h) 内存。其中 h 是树的高度。

## 解题思路

**核心思想：** 实现二叉搜索树的**受控中序遍历**。

BST 的中序遍历结果是**升序序列**，我们需要按需逐个返回元素。

### 方法对比

| 方法 | 初始化 | next() | hasNext() | 空间 |
|------|--------|--------|-----------|------|
| 数组存储 | O(n) | O(1) | O(1) | O(n) |
| 栈模拟 | O(h) | O(1)均摊 | O(1) | O(h) |

### 方法一：提前遍历（不推荐，但简单）
- 初始化时进行完整中序遍历，存入数组
- `next()` 和 `hasNext()` 基于数组索引

### 方法二：栈模拟中序遍历（最优）
- 使用栈模拟递归的中序遍历
- 栈中保存从根到当前节点的左链路径
- `next()` 时弹出栈顶，并压入其右子树的左链

**栈的作用：**
- 保存待访问的节点
- 栈顶始终是下一个要访问的节点
- 访问节点后，将其右子树的左链压栈

## Java 代码实现

### 方法一：栈模拟中序遍历（推荐，O(h) 空间）

```java
// 二叉树节点定义
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class BSTIterator {
    private Deque<TreeNode> stack;

    public BSTIterator(TreeNode root) {
        stack = new ArrayDeque<>();
        // 将根到最左节点的路径全部压栈
        pushLeft(root);
    }

    /** 将节点及其所有左子节点压栈 */
    private void pushLeft(TreeNode node) {
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
    }

    /** 返回中序遍历的下一个元素 */
    public int next() {
        // 弹出栈顶节点（当前最小节点）
        TreeNode node = stack.pop();

        // 如果有右子树，将右子树的左链压栈
        if (node.right != null) {
            pushLeft(node.right);
        }

        return node.val;
    }

    /** 判断是否还有下一个元素 */
    public boolean hasNext() {
        return !stack.isEmpty();
    }
}
```

### 方法二：数组存储（简单，但 O(n) 空间）

```java
class BSTIterator {
    private List<Integer> nodes;
    private int index;

    public BSTIterator(TreeNode root) {
        nodes = new ArrayList<>();
        index = 0;
        // 中序遍历存入列表
        inorder(root);
    }

    /** 中序遍历 */
    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        nodes.add(node.val);
        inorder(node.right);
    }

    /** 返回下一个元素 */
    public int next() {
        return nodes.get(index++);
    }

    /** 判断是否还有元素 */
    public boolean hasNext() {
        return index < nodes.size();
    }
}
```

### 方法三：优化的栈实现（显式状态）

```java
class BSTIterator {
    private Deque<TreeNode> stack;
    private TreeNode current;

    public BSTIterator(TreeNode root) {
        stack = new ArrayDeque<>();
        current = root;
    }

    /** 返回中序遍历的下一个元素 */
    public int next() {
        // 先找到最左节点
        while (current != null) {
            stack.push(current);
            current = current.left;
        }

        // 弹出栈顶（最小节点）
        current = stack.pop();
        int result = current.val;

        // 转向右子树
        current = current.right;

        return result;
    }

    /** 判断是否还有元素 */
    public boolean hasNext() {
        return current != null || !stack.isEmpty();
    }
}
```

## 复杂度分析

### 方法一（栈模拟）

**时间复杂度：**
- 初始化：O(h)，h 是树的高度
- `next()`：O(1) 均摊
  - 单次可能 O(h)（压入右子树左链）
  - 但每个节点最多入栈出栈各一次
  - n 次调用总共 O(n)，均摊 O(1)
- `hasNext()`：O(1)

**空间复杂度：** O(h)
- 栈最多存储树高度个节点

### 方法二（数组）

**时间复杂度：**
- 初始化：O(n)
- `next()`：O(1)
- `hasNext()`：O(1)

**空间复杂度：** O(n)

## 图解示例

以树 `[7, 3, 15, null, null, 9, 20]` 为例：

```
       7
      / \
     3   15
        /  \
       9    20

中序遍历顺序：3 -> 7 -> 9 -> 15 -> 20
```

**栈模拟过程：**

```
初始化：
  stack = [7, 3]  (压入左链)

next() - 返回 3：
  弹出 3，无右子树
  stack = [7]

next() - 返回 7：
  弹出 7，有右子树 15
  压入 15 的左链 [15, 9]
  stack = [15, 9]

next() - 返回 9：
  弹出 9，无右子树
  stack = [15]

next() - 返回 15：
  弹出 15，有右子树 20
  压入 20 的左链 [20]
  stack = [20]

next() - 返回 20：
  弹出 20，无右子树
  stack = []

hasNext() - 返回 False
```

## 关键点总结

1. **中序遍历性质**：BST 的中序遍历结果是升序
2. **栈模拟递归**：用栈保存待访问的节点
3. **左链压栈**：每次压入从当前节点到最左节点的路径
4. **均摊分析**：每个节点最多入栈出栈各一次
5. **空间优化**：O(h) 而非 O(n)

## 易错点

1. **初始化忘记压栈**
   - 必须在构造函数中调用 `pushLeft(root)`

2. **next() 忘记处理右子树**
   - 弹出节点后，需要将其右子树的左链压栈

3. **hasNext() 判断错误**
   - 错误：`stack != null`
   - 正确：`!stack.isEmpty()`

4. **边界情况**
   - 单节点树
   - 只有左子树或只有右子树的树

5. **混淆前序和中序**
   - 中序：左 -> 根 -> 右（升序）
   - 前序：根 -> 左 -> 右（不是升序）

**迭代器模式：**
- 封装集合的内部结构
- 提供统一的访问接口
- 支持惰性求值（按需计算）

**中序遍历的栈模拟模板（Java）：**
```java
public List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode current = root;

    while (current != null || !stack.isEmpty()) {
        // 一路向左
        while (current != null) {
            stack.push(current);
            current = current.left;
        }

        // 访问节点
        current = stack.pop();
        result.add(current.val);

        // 转向右子树
        current = current.right;
    }

    return result;
}
```

**Java 技巧：**
- 使用 `Deque<TreeNode>` 代替 `Stack<TreeNode>`（性能更好）
- `ArrayDeque` 是双端队列，用作栈时使用 `push/pop`
- `stack.isEmpty()` 判断栈是否为空

**测试要点：**
- 测试所有节点都访问到
- 测试顺序是否正确（升序）
- 测试 `hasNext()` 在遍历结束后返回 `false`
- 测试各种树形状（平衡、倾斜等）
