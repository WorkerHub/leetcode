## 题目描述

给你字符串 s 和字符 c，统计以 c 开头且以 c 结尾的子字符串数量（单字符子串也算）。

## 解题思路

统计字符 c 的出现次数 cnt，以 c 开头且以 c 结尾的子字符串总数 = C(cnt,1) + C(cnt,2) = cnt*(cnt+1)/2。

## Java 代码实现

```java
class Solution {
    public long countSubstrings(String s, char c) {
        long cnt = 0;
        for (char ch : s.toCharArray()) {
            if (ch == c) cnt++;
        }
        // 总数 = cnt 个单字符 + C(cnt,2) 个首尾均为 c 的子串
        return cnt * (cnt + 1) / 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，统计字符 c 的出现次数
- **空间复杂度**：O(1)

## 关键点总结

1. 只需统计字符 c 的出现次数 cnt
2. 总子字符串数 = C(cnt,1) + C(cnt,2) = cnt*(cnt+1)/2
3. 用 long 防止溢出（n 最大 10^5，cnt*(cnt+1)/2 最大约 5×10^9）
