## 题目描述

给你两个字符串 `word1` 和 `word2`，每次从两个字符串头部各取一个字符追加到结果，返回字典序最大的合并字符串。

## 解题思路

贪心：每次选字典序较大的那个字符串的头部字符。当头部字符相同时，比较两个字符串剩余部分的字典序，取较大的那个。Java 中用 `compareTo` 或 `substring` 比较剩余部分。

## Java 代码实现

```java
class Solution {
    public String largestMerge(String word1, String word2) {
        StringBuilder sb = new StringBuilder();
        int i = 0, j = 0;

        while (i < word1.length() && j < word2.length()) {
            // 比较从 i 和 j 开始的剩余字符串字典序
            // Java 中 String.compareTo 按字典序比较
            if (word1.substring(i).compareTo(word2.substring(j)) >= 0) {
                sb.append(word1.charAt(i++));
            } else {
                sb.append(word2.charAt(j++));
            }
        }

        // 追加剩余部分
        sb.append(word1.substring(i));
        sb.append(word2.substring(j));

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O((m+n) * max(m,n))，每次字符串比较最坏 O(min(m,n))
- **空间复杂度**：O(m+n)

## 关键点总结

1. 每次选剩余部分字典序更大的字符串的头部字符
2. Java 中 `String.compareTo` 直接支持字典序比较
