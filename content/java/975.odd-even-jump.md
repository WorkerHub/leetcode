## 题目描述

给定整数数组 arr，从某个索引开始交替进行奇数跳和偶数跳。奇数跳跳到右侧 >= 当前值的最小值位置，偶数跳跳到右侧 <= 当前值的最大值位置。返回能到达最后一个索引的起始索引数量。

**示例：**
```
输入：arr = [10,13,12,14,15]
输出：2
```

## 解题思路

动态规划 + TreeMap：从后往前遍历，维护有序映射快速查找下一跳位置。odd[i] 表示从 i 做奇数跳能否到达终点，even[i] 表示偶数跳能否到达终点。

## Java 代码实现

```java
class Solution {
    public int oddEvenJumps(int[] arr) {
        int n = arr.length;
        boolean[] odd = new boolean[n];
        boolean[] even = new boolean[n];
        odd[n - 1] = even[n - 1] = true;

        // TreeMap 维护值到索引的映射
        TreeMap<Integer, Integer> map = new TreeMap<>();
        map.put(arr[n - 1], n - 1);

        int count = 1;
        for (int i = n - 2; i >= 0; i--) {
            int val = arr[i];

            // 奇数跳：找 >= val 的最小值
            Map.Entry<Integer, Integer> ceiling = map.ceilingEntry(val);
            if (ceiling != null) {
                odd[i] = even[ceiling.getValue()];
            }

            // 偶数跳：找 <= val 的最大值
            Map.Entry<Integer, Integer> floor = map.floorEntry(val);
            if (floor != null) {
                even[i] = odd[floor.getValue()];
            }

            if (odd[i]) count++;
            map.put(val, i);
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **状态转移**：奇数跳后变偶数跳，odd[i] = even[j]
2. **TreeMap 查找**：ceilingEntry/floorEntry 快速定位下一跳
3. **从后向前**：最后位置是 base case，逆序推导
