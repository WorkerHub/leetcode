## 题目描述

给你 `chargeTimes`、`runningCosts` 和预算 `budget`，运行 k 个连续机器人的费用为 `max(chargeTimes) + k * sum(runningCosts)`，返回在预算内可连续运行的最多机器人数量。

## 解题思路

滑动窗口 + 单调递减双端队列：右指针依次入窗口，单调队列维护窗口最大 chargeTime，累加 runningCost 之和。若当前窗口费用超出预算则收缩左端，取最大窗口大小。注意 budget 最大 10^15，需用 `long`。

## Java 代码实现

```java
class Solution {
    public int maximumRobots(int[] chargeTimes, int[] runningCosts, long budget) {
        int n = chargeTimes.length;
        Deque<Integer> dq = new ArrayDeque<>(); // 单调递减队列，存下标
        long windowSum = 0;
        int ans = 0, left = 0;

        for (int right = 0; right < n; right++) {
            // 入窗口：维护单调递减队列
            windowSum += runningCosts[right];
            while (!dq.isEmpty() && chargeTimes[dq.peekLast()] <= chargeTimes[right])
                dq.pollLast();
            dq.addLast(right);

            // 收缩窗口直到满足预算
            while (left <= right) {
                int k = right - left + 1;
                long cost = chargeTimes[dq.peekFirst()] + (long) k * windowSum;
                if (cost <= budget) break;
                windowSum -= runningCosts[left];
                if (dq.peekFirst() == left) dq.pollFirst();
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 单调递减双端队列维护窗口最大 chargeTime，队首即为最大值。
2. `k * sum(runningCosts)` 中 k 和 sum 都可达 5×10^4 * 10^5 = 5×10^9，需用 `long`。
3. 每个元素最多入队、出队各一次，总体 O(n)。
