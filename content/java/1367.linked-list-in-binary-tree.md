## 题目描述

给你一棵以 `root` 为根的二叉树和以 `head` 为头节点的链表，判断是否存在一条从某树节点开始一直向下的路径，路径上各节点值与链表节点值一一对应，返回 `true` 或 `false`。

## 解题思路

双重 DFS：外层遍历二叉树每个节点作为候选起点，内层从该节点开始同步向下匹配链表。`match` 函数中链表为空则匹配成功，树为空或值不匹配则失败，否则递归尝试左/右子树。

## Java 代码实现

```java
class Solution {
    public boolean isSubPath(ListNode head, TreeNode root) {
        if (root == null) return false;
        // 以当前节点为起点尝试匹配，或在左/右子树中找起点
        return match(head, root)
            || isSubPath(head, root.left)
            || isSubPath(head, root.right);
    }

    // 从 treeNode 开始，尝试匹配以 listNode 为首的链表
    private boolean match(ListNode listNode, TreeNode treeNode) {
        if (listNode == null) return true;  // 链表全部匹配成功
        if (treeNode == null) return false; // 树节点不足
        if (listNode.val != treeNode.val) return false; // 当前值不匹配
        // 向左或向右继续匹配下一个链表节点
        return match(listNode.next, treeNode.left)
            || match(listNode.next, treeNode.right);
    }
}
```

## 复杂度分析

- 时间复杂度：O(N × M)，N 为树节点数（最多 2500），M 为链表长度（最多 100）。
- 空间复杂度：O(N + M)，递归调用栈深度。

## 关键点总结

1. 外层遍历每个树节点作为候选起点，内层从起点沿树向下同步匹配链表。
2. `match` 函数终止条件：链表为空返回 `true`，树为空或值不匹配返回 `false`。
3. 路径只能向下（左子或右子），由 `match` 的递归结构天然保证。
