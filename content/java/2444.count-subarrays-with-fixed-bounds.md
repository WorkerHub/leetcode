## 题目描述

给你整数数组 `nums` 和整数 `minK`、`maxK`，返回最小值恰好等于 `minK` 且最大值恰好等于 `maxK` 的定界子数组数目。

## 解题思路

一次遍历：维护三个位置变量——`bad`（最后一个值不在 `[minK, maxK]` 的位置）、`lastMin`（最后一个值为 `minK` 的位置）、`lastMax`（最后一个值为 `maxK` 的位置）。以 `r` 结尾的定界子数组数 = `max(0, min(lastMin, lastMax) - bad)`。

## Java 代码实现

```java
class Solution {
    public long countSubarrays(int[] nums, int minK, int maxK) {
        long ans = 0;
        int bad = -1;      // 最后一个越界元素的位置
        int lastMin = -1;  // 最后一个 minK 的位置
        int lastMax = -1;  // 最后一个 maxK 的位置

        for (int r = 0; r < nums.length; r++) {
            int x = nums[r];
            // 越界元素，更新 bad
            if (x < minK || x > maxK) bad = r;
            if (x == minK) lastMin = r;
            if (x == maxK) lastMax = r;

            // 合法左端点数 = max(0, min(lastMin, lastMax) - bad)
            int leftBound = Math.min(lastMin, lastMax);
            ans += Math.max(0, leftBound - bad);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 维护三个关键位置：越界位置、最后的 minK 位置、最后的 maxK 位置
2. 合法左端点范围：`(bad, min(lastMin, lastMax)]`
3. 返回值用 `long` 防止溢出
