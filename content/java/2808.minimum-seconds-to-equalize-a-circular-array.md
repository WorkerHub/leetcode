## 题目描述

给你长度为 n 的环形整数数组 `nums`，每秒每个位置可替换为相邻位置的值，返回使所有元素相等所需的最少秒数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumSeconds(List<Integer> nums) {
        int n = nums.size();
        // 记录每个值出现的所有下标
        Map<Integer, List<Integer>> positions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            positions.computeIfAbsent(nums.get(i), k -> new ArrayList<>()).add(i);
        }

        int ans = n;
        for (List<Integer> pos : positions.values()) {
            int maxGap = 0;
            int m = pos.size();
            for (int i = 0; i < m; i++) {
                int gap;
                if (i + 1 < m) {
                    gap = pos.get(i + 1) - pos.get(i);
                } else {
                    gap = n - pos.get(m - 1) + pos.get(0); // 环形
                }
                maxGap = Math.max(maxGap, gap);
            }
            ans = Math.min(ans, maxGap / 2);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 选某值 v 最终覆盖全数组，扩散时间由相邻两个 v 之间的最大间距决定
2. 所需时间 = maxGap / 2（整除）
3. 环形数组最后一个与第一个之间的间距 = n - pos[m-1] + pos[0]
