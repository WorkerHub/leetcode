## 题目描述

给定字符串 `s` 和整数 `k`，返回数组 `ans`，其中 `ans[i]` 是 `s[i..i+k-1]` 中不同字符的数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countDistinct(String s, int k) {
        int n = s.length();
        int[] cnt = new int[26];
        int distinct = 0;
        int[] ans = new int[n - k + 1];

        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            if (cnt[c]++ == 0) distinct++;

            if (i >= k) {
                // 移除最左字符
                int lc = s.charAt(i - k) - 'a';
                if (--cnt[lc] == 0) distinct--;
            }
            if (i >= k - 1) ans[i - k + 1] = distinct;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 滑动窗口维护固定大小 k 的窗口，数组计数字符频率
2. 字符计数降为 0 时减少不同字符计数
3. 返回数组长度为 n - k + 1
