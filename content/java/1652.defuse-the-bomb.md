## 题目描述

给你**环形**整数数组 `code` 和密钥 `k`，将每个位置替换为：
- `k>0`：后 k 个元素之和
- `k<0`：前 |k| 个元素之和
- `k=0`：0

返回替换后的数组。

## 解题思路

**滑动窗口：** 维护固定大小为 |k| 的窗口和，每次移动一位。用取模处理环形下标。

## Java 代码实现

```java
class Solution {
    public int[] decrypt(int[] code, int k) {
        int n = code.length;
        int[] result = new int[n];
        if (k == 0) return result; // k=0 直接返回全 0

        // 确定初始窗口的起点和终点（相对于 i=0）
        int start, end;
        if (k > 0) {
            start = 1;
            end = k;
        } else {
            start = n + k; // k 为负，n+k < n
            end = n - 1;
        }

        // 计算初始窗口和
        int windowSum = 0;
        for (int i = start; i <= end; i++) {
            windowSum += code[i % n];
        }

        for (int i = 0; i < n; i++) {
            result[i] = windowSum;
            // 滑动：移出 start，加入 end+1
            windowSum -= code[start % n];
            windowSum += code[(end + 1) % n];
            start++;
            end++;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不含结果数组）

## 关键点总结

1. 环形下标用 `% n` 处理
2. k>0 看后面 k 个，k<0 看前面 |k| 个
3. 滑动窗口每次移动减去最左边元素，加入最右边新元素
