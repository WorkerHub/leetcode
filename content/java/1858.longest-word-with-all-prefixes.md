## 题目描述

找数组中最长的单词，使其所有前缀也在数组中。多个答案取字典序最小。

## 解题思路

将单词放入HashSet，排序后验证每个单词的所有前缀是否都在集合中。或用字典树DFS只沿单词结尾节点前进。

## Java 代码实现

```java
class Solution {
    public String longestWord(String[] words) {
        Set<String> wordSet = new HashSet<>(Arrays.asList(words));
        // 按长度降序，长度相同字典序升序
        Arrays.sort(words, (a, b) -> a.length() != b.length() ? b.length() - a.length() : a.compareTo(b));
        
        for (String word : words) {
            boolean valid = true;
            for (int i = 1; i < word.length(); i++) {
                if (!wordSet.contains(word.substring(0, i))) {
                    valid = false;
                    break;
                }
            }
            if (valid) return word;
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × L^2)，N个单词，每个检查L个前缀
- **空间复杂度**：O(N × L)

## 关键点总结

1. **排序策略**：长度降序+字典序升序，第一个满足的即答案
2. **前缀验证**：所有前缀（不含自身）都必须在集合中
3. **字典树优化**：DFS只沿is_end节点深入
