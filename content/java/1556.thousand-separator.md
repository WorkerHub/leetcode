## 题目描述

给整数 n 每隔三位添加点（千分位分隔符），返回字符串。

**示例：**
```
输入：n = 1234567891
输出："1.234.567.891"
```

## 解题思路

从右到左每 3 位插入一个点。

## Java 代码实现

```java
class Solution {
    public String thousandSeparator(int n) {
        String s = String.valueOf(n);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            if (i > 0 && (s.length() - i) % 3 == 0) {
                sb.append('.');
            }
            sb.append(s.charAt(i));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **从左往右遍历**：当剩余字符数是 3 的倍数时插入点
2. **不在开头插入**：i > 0 条件避免开头多一个点
