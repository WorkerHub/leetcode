## 题目描述

构造n个不同正整数使任意两数之和!=target，求最小和(mod 10^9+7)。

## 解题思路

数学：可安全选1到(target-1)/2（互不配对），不够时从target开始继续选。等差数列求和取模。

## Java 代码实现

```java
class Solution {
    public int minimumPossibleSum(int n, int target) {
        long MOD = 1_000_000_007;
        long half = (target - 1) / 2;

        if (n <= half) {
            return (int) ((long) n * (n + 1) / 2 % MOD);
        }
        // 先选1..half，再从target开始选n-half个
        long sum1 = half * (half + 1) / 2 % MOD;
        long remaining = n - half;
        // target + (target+1) + ... + (target+remaining-1)
        long sum2 = (remaining % MOD * (target % MOD) % MOD
                + remaining % MOD * ((remaining - 1) % MOD) % MOD * 500000004 % MOD) % MOD;
        // 简化：remaining*target + remaining*(remaining-1)/2
        sum2 = (remaining % MOD * (target % MOD) % MOD
                + remaining % MOD * ((remaining - 1) % MOD) % MOD * 500000004 % MOD) % MOD;
        return (int) ((sum1 + sum2) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **half=(target-1)/2**：避免target/2自身配对
2. **超出后从target开始选**：与前面任何数之和>target
3. **大数取模**：注意中间结果溢出
