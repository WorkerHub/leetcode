## 题目描述

通过合并相邻元素（替换为和），求能得到的最长非递减数组长度。

## 解题思路

dp[i]为考虑前i个元素的最长非递减合并长度。转移：找最大j使prefix[i]-prefix[j]>=last[j]，即prefix[j]+last[j]<=prefix[i]。用单调栈+二分查找优化。

## Java 代码实现

```java
class Solution {
    public int findMaximumLength(int[] nums) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        int[] dp = new int[n + 1];
        long[] last = new long[n + 1];

        // 单调栈：存储(prefix[j]+last[j], j)，保持值递增
        List<long[]> mono = new ArrayList<>();
        mono.add(new long[]{0, 0});

        for (int i = 1; i <= n; i++) {
            // 二分找最大j使得mono[j].val <= prefix[i]
            int lo = 0, hi = mono.size() - 1, res = 0;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (mono.get(mid)[0] <= prefix[i]) {
                    res = (int) mono.get(mid)[1];
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }

            int j = res;
            dp[i] = dp[j] + 1;
            last[i] = prefix[i] - prefix[j];

            // 加入单调栈
            long val = prefix[i] + last[i];
            while (!mono.isEmpty() && mono.get(mono.size() - 1)[0] >= val) {
                mono.remove(mono.size() - 1);
            }
            mono.add(new long[]{val, i});
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **合并段和非递减**：每段和>=前一段和
2. **转移条件**：prefix[j]+last[j]<=prefix[i]
3. **单调栈+二分**：维护递增序列支持快速查询
