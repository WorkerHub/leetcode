## 题目描述

模拟栈操作：queries[i]>=0时将nums[v]插入末尾，<0时删除末尾元素。每步返回arr[0]或-1。

## 解题思路

用列表模拟栈，每步记录栈底元素（arr[0]），为空返回-1。

## Java 代码实现

```java
class Solution {
    public int[] elementInNums(int[] nums, int[] queries) {
        List<Integer> arr = new ArrayList<>();
        int[] result = new int[queries.length];
        
        for (int q = 0; q < queries.length; q++) {
            int v = queries[q];
            if (v >= 0) {
                arr.add(nums[v]);
            } else {
                if (!arr.isEmpty()) {
                    arr.remove(arr.size() - 1);
                }
            }
            result[q] = arr.isEmpty() ? -1 : arr.get(0);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(Q)，Q为查询数
- **空间复杂度**：O(N)

## 关键点总结

1. **模拟栈**：v>=0插入末尾，v<0弹出末尾
2. **记录栈底**：每步返回arr[0]不是栈顶
3. **空栈检查**：删除前判断是否为空
