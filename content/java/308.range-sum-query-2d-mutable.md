## 题目描述

给你一个 2D 矩阵 `matrix`，请计算出从左上角 `(row1, col1)` 到右下角 `(row2, col2)` 组成的矩形中所有元素的和。

你需要实现 `NumMatrix` 类：

- `NumMatrix(int[][] matrix)` 给定整数矩阵 `matrix` 进行初始化
- `void update(int row, int col, int val)` 更新 `matrix[row][col]` 的值到 `val`
- `int sumRegion(int row1, int col1, int row2, int col2)` 返回左上角 `(row1, col1)` 、右下角 `(row2, col2)` 所描述的子矩阵的元素**总和**

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/14/sum-grid.jpg)

```
输入
["NumMatrix", "sumRegion", "update", "sumRegion"]
[[[[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]], [2, 1, 4, 3], [3, 2, 2], [2, 1, 4, 3]]
输出
[null, 8, null, 10]

解释
NumMatrix numMatrix = new NumMatrix([[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]);
numMatrix.sumRegion(2, 1, 4, 3); // 返回 8（红色矩形框的元素总和）
numMatrix.update(3, 2, 2);       // 矩阵变为 [[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 2, 1, 7], [1, 0, 3, 0, 5]]
numMatrix.sumRegion(2, 1, 4, 3); // 返回 10（红色矩形框的元素总和）
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 200`
- `-10^5 <= matrix[i][j] <= 10^5`
- `0 <= row < m`
- `0 <= col < n`
- `-10^5 <= val <= 10^5`
- `0 <= row1 <= row2 < m`
- `0 <= col1 <= col2 < n`
- 最多调用 `10^4` 次 `sumRegion` 和 `update` 方法

## 解题思路

这是 304 题（二维不可变区间和）和 307 题（一维可变区间和）的结合版本。

### 方法对比

| 方法 | 更新时间 | 查询时间 | 空间 |
|------|---------|---------|------|
| 暴力 | O(1) | O(mn) | O(1) |
| 二维树状数组 | O(log m × log n) | O(log m × log n) | O(mn) |
| 线段树 | O(log m × log n) | O(log m × log n) | O(mn) |
| 逐行树状数组 | O(log n) | O(m × log n) | O(mn) |

### 二维树状数组（推荐）⭐

**核心思想**：将一维树状数组扩展到二维。

- `tree[i][j]` 维护的是一个二维区域的和
- 更新和查询都需要在两个维度上操作

## Java 代码实现

### 方法一：二维树状数组（推荐）⭐

```java
class NumMatrix {
    private int m, n;
    private int[][] matrix;  // 原始矩阵
    private int[][] tree;    // 二维树状数组（索引从 1 开始）

    public NumMatrix(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return;

        m = matrix.length;
        n = matrix[0].length;

        // 原始矩阵（全 0 初始化）
        this.matrix = new int[m][n];

        // 二维树状数组，大小 (m+1) x (n+1)
        this.tree = new int[m + 1][n + 1];

        // 初始化所有元素
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                update(i, j, matrix[i][j]);
            }
        }
    }

    public void update(int row, int col, int val) {
        // 更新 matrix[row][col] 的值为 val
        // 计算差值
        int delta = val - matrix[row][col];
        matrix[row][col] = val;

        // 更新树状数组（在两个维度上向上传播）
        int i = row + 1; // 树状数组索引从 1 开始
        while (i <= m) {
            int j = col + 1;
            while (j <= n) {
                tree[i][j] += delta;
                j += lowbit(j);
            }
            i += lowbit(i);
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        // 返回子矩阵 (row1, col1) 到 (row2, col2) 的和
        return prefixSum(row2, col2)
             - prefixSum(row1 - 1, col2)
             - prefixSum(row2, col1 - 1)
             + prefixSum(row1 - 1, col1 - 1);
    }

    private int prefixSum(int row, int col) {
        // 计算从 (0, 0) 到 (row, col) 的矩形和
        if (row < 0 || col < 0) return 0;

        int result = 0;
        int i = row + 1;
        while (i > 0) {
            int j = col + 1;
            while (j > 0) {
                result += tree[i][j];
                j -= lowbit(j);
            }
            i -= lowbit(i);
        }

        return result;
    }

    private int lowbit(int x) {
        // 计算 lowbit(x)
        return x & (-x);
    }
}
```

### 方法二：逐行树状数组

```java
class NumMatrix {
    private int m, n;
    private int[][] matrix;
    private int[][] rowTree; // 每一行的树状数组

    public NumMatrix(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return;

        m = matrix.length;
        n = matrix[0].length;

        // 保存原始矩阵（复制）
        this.matrix = new int[m][n];
        for (int i = 0; i < m; i++) {
            this.matrix[i] = matrix[i].clone();
        }

        // 每一行都有一个树状数组
        rowTree = new int[m][n + 1];

        // 初始化每一行的树状数组
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int idx = j + 1;
                while (idx <= n) {
                    rowTree[i][idx] += matrix[i][j];
                    idx += idx & (-idx);
                }
            }
        }
    }

    public void update(int row, int col, int val) {
        // 更新 matrix[row][col] 的值为 val
        int delta = val - matrix[row][col];
        matrix[row][col] = val;

        // 更新第 row 行的树状数组
        int j = col + 1;
        while (j <= n) {
            rowTree[row][j] += delta;
            j += j & (-j);
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        // 返回子矩阵的和（累加每一行的区间和）
        int result = 0;
        for (int i = row1; i <= row2; i++) {
            result += rowQuery(i, col2) - rowQuery(i, col1 - 1);
        }
        return result;
    }

    private int rowQuery(int row, int col) {
        // 查询第 row 行 [0, col] 的前缀和
        if (col < 0) return 0;
        int result = 0;
        int j = col + 1;
        while (j > 0) {
            result += rowTree[row][j];
            j -= j & (-j);
        }
        return result;
    }
}
```

### 方法四：带详细注释的二维树状数组

```java
class NumMatrix {
    private int m, n;
    private int[][] matrix;
    private int[][] tree;

    public NumMatrix(int[][] matrix) {
        /**
         * 初始化二维树状数组
         *
         * tree[i][j] 的含义：
         * 维护一个二维区域的和，具体范围由 lowbit 决定
         */
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            m = 0; n = 0;
            return;
        }

        m = matrix.length;
        n = matrix[0].length;

        // 保存原始矩阵（用于计算差值）
        this.matrix = new int[m][n];

        // 二维树状数组，大小 (m+1) x (n+1)
        this.tree = new int[m + 1][n + 1];

        // 初始化所有元素
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                update(i, j, matrix[i][j]);
            }
        }
    }

    public void update(int row, int col, int val) {
        /**
         * 更新 matrix[row][col] 的值为 val
         *
         * 思路：
         * 1. 计算差值 delta
         * 2. 在两个维度上都向上传播更新
         */
        int delta = val - matrix[row][col];
        matrix[row][col] = val;

        // 树状数组索引从 1 开始
        int i = row + 1;
        while (i <= m) {
            int j = col + 1;
            while (j <= n) {
                tree[i][j] += delta;
                j += j & (-j); // lowbit(j)
            }
            i += i & (-i); // lowbit(i)
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        /**
         * 返回子矩阵的和
         *
         * 公式（容斥原理）：
         * sum = prefix(r2, c2) - prefix(r1-1, c2)
         *     - prefix(r2, c1-1) + prefix(r1-1, c1-1)
         */
        return prefixSum(row2, col2)
             - prefixSum(row1 - 1, col2)
             - prefixSum(row2, col1 - 1)
             + prefixSum(row1 - 1, col1 - 1);
    }

    private int prefixSum(int row, int col) {
        /**
         * 计算从 (0, 0) 到 (row, col) 的矩形和
         *
         * 思路：在两个维度上都向下累加
         */
        if (row < 0 || col < 0) return 0;

        int result = 0;
        int i = row + 1;
        while (i > 0) {
            int j = col + 1;
            while (j > 0) {
                result += tree[i][j];
                j -= j & (-j); // lowbit(j)
            }
            i -= i & (-i); // lowbit(i)
        }

        return result;
    }
}
```

## 复杂度分析

**二维树状数组：**
- 时间复杂度：
  - 初始化：O(mn log m log n)
  - 更新：O(log m × log n)
  - 查询：O(log m × log n)
- 空间复杂度：O(mn)

**逐行树状数组：**
- 时间复杂度：
  - 初始化：O(mn log n)
  - 更新：O(log n)
  - 查询：O(m log n)
- 空间复杂度：O(mn)

## 关键点总结

1. **二维树状数组的更新**：
   ```java
   int i = row + 1;
   while (i <= m) {
       int j = col + 1;
       while (j <= n) {
           tree[i][j] += delta;
           j += lowbit(j);
       }
       i += lowbit(i);
   }
   ```

2. **二维树状数组的查询**：
   ```java
   int i = row + 1;
   while (i > 0) {
       int j = col + 1;
       while (j > 0) {
           result += tree[i][j];
           j -= lowbit(j);
       }
       i -= lowbit(i);
   }
   ```

3. **容斥原理**：查询时需要加加减减，与二维前缀和类似

4. **索引转换**：树状数组索引从 1 开始，需要 +1

5. **更新是差值**：`delta = val - matrix[row][col]`，而不是直接赋值

## 易错点

1. **双重循环顺序**：内外层循环不能颠倒
2. **索引偏移**：忘记 +1 转换
3. **容斥原理**：区间查询的四项公式容易记错
4. **lowbit 计算**：`x & (-x)` 不要写错
5. **边界处理**：`prefixSum(-1, x)` 应返回 0
