## 题目描述

反复删除字符串中相邻且相同的两个字符，直到无法继续删除，返回最终字符串。

**示例：**
```
输入："abbaca"
输出："ca"
```

## 解题思路

栈：遍历字符，若栈顶与当前字符相同则弹出（消除），否则压入。最终栈中字符即为结果。

## Java 代码实现

```java
class Solution {
    public String removeDuplicates(String s) {
        StringBuilder stack = new StringBuilder();

        for (char c : s.toCharArray()) {
            if (stack.length() > 0 && stack.charAt(stack.length() - 1) == c) {
                // 栈顶与当前字符相同，消除
                stack.deleteCharAt(stack.length() - 1);
            } else {
                stack.append(c);
            }
        }

        return stack.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈的应用**：比较当前字符与"前一个"，栈天然适合
2. **StringBuilder 当栈**：Java 中用 StringBuilder 模拟栈更高效
3. **一次遍历**：每个字符最多入栈出栈各一次
