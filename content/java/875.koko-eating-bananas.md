## 题目描述

n 堆香蕉，第 i 堆有 piles[i] 根。每小时吃一堆中的 k 根（不够 k 就吃完）。求在 h 小时内吃完所有香蕉的最小速度 k。

**示例：**
```
输入：piles = [3,6,7,11], h = 8
输出：4
```

## 解题思路

二分答案：二分速度 k，检查以该速度能否在 h 小时内吃完。

## Java 代码实现

```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int left = 1, right = 0;
        for (int pile : piles) right = Math.max(right, pile);

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canFinish(piles, mid, h)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean canFinish(int[] piles, int k, int h) {
        long hours = 0;
        for (int pile : piles) {
            hours += (pile + k - 1) / k; // 向上取整
        }
        return hours <= h;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log m)，m 为最大堆大小
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：搜索速度而非位置
2. **向上取整**：(pile + k - 1) / k
3. **单调性**：速度越大用时越少
