## 题目描述

在"num1+num2"表达式中添加一对括号使结果最小（括号外部分与括号内相乘）。

## 解题思路

暴力枚举括号位置：左括号在+号左侧各位置，右括号在+号右侧各位置。计算left*(mid1+mid2)*right取最小值。

## Java 代码实现

```java
class Solution {
    public String minimizeResult(String expression) {
        int plusIdx = expression.indexOf('+');
        String left = expression.substring(0, plusIdx);
        String right = expression.substring(plusIdx + 1);
        
        long minVal = Long.MAX_VALUE;
        String best = "";
        
        for (int i = 0; i < left.length(); i++) {
            for (int j = 1; j <= right.length(); j++) {
                long a = i > 0 ? Long.parseLong(left.substring(0, i)) : 1;
                long b = Long.parseLong(left.substring(i)) + Long.parseLong(right.substring(0, j));
                long c = j < right.length() ? Long.parseLong(right.substring(j)) : 1;
                
                long val = a * b * c;
                if (val < minVal) {
                    minVal = val;
                    best = left.substring(0, i) + "(" + left.substring(i) + "+" + right.substring(0, j) + ")" + right.substring(j);
                }
            }
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)，N为总位数
- **空间复杂度**：O(N)

## 关键点总结

1. **括号外空部分视为1**：不乘以0
2. **暴力枚举可行**：数字最多10位，枚举次数<=100
3. **括号内加法，外乘法**：left*(括号内)+right
