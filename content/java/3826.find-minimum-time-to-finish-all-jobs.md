## 题目描述

给定任务数组 `jobs` 和 `k` 名工人，返回所有工人完成所有任务所需的最小最大工作时间（`jobs.length <= 12`）。

## Java 代码实现

```java
class Solution {
    public int minimumTimeRequired(int[] jobs, int k) {
        int n = jobs.length;
        int total = 1 << n;
        // 预计算每个子集的总时间
        int[] subSum = new int[total];
        for (int mask = 1; mask < total; mask++) {
            int lsb = Integer.numberOfTrailingZeros(mask);
            subSum[mask] = subSum[mask ^ (1 << lsb)] + jobs[lsb];
        }

        // dp[mask] = 分配完 mask 中任务时 k 名工人的最小最大时间
        // 逐层更新（第 j 名工人）
        int[] prev = subSum.clone(); // 1 名工人时，最大时间 = 总时间
        for (int j = 1; j < k; j++) {
            int[] curr = new int[total];
            for (int mask = 0; mask < total; mask++) {
                curr[mask] = subSum[mask]; // 全由一个工人做
                // 枚举当前工人负责的子集 sub
                for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
                    curr[mask] = Math.min(curr[mask],
                        Math.max(prev[mask ^ sub], subSum[sub]));
                }
            }
            prev = curr;
        }
        return prev[total - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * 3^n)
- 空间复杂度：O(2^n)

## 关键点总结

1. n <= 12 是状态压缩 DP 的信号，子集枚举用 `sub = (sub-1) & mask`
2. 预计算子集和用低位提取：`Integer.numberOfTrailingZeros(mask)`
3. 初始状态：1 名工人时最大时间等于所有任务总和
