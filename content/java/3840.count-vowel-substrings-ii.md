## 题目描述

给定字符串 `word`，统计包含全部五种元音（a,e,i,o,u）且仅由元音组成的子串数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countVowelSubstrings(String word) {
        // 至少包含 5 种元音的全元音子串数（"恰好" = 至少5种，因为只有5种元音）
        return atLeast(word, 5);
    }

    private int atLeast(String word, int k) {
        Set<Character> vowelSet = new HashSet<>(Arrays.asList('a','e','i','o','u'));
        int n = word.length(), count = 0, left = 0, distinct = 0;
        int[] freq = new int[26];

        for (int right = 0; right < n; right++) {
            char rc = word.charAt(right);
            if (!vowelSet.contains(rc)) {
                // 遇到非元音，重置窗口
                Arrays.fill(freq, 0);
                distinct = 0;
                left = right + 1;
                continue;
            }
            if (freq[rc - 'a']++ == 0) distinct++;

            // 收缩左端，统计以 right 结尾满足 >= k 种元音的子串数
            while (distinct >= k) {
                count += n - right;
                char lc = word.charAt(left);
                if (--freq[lc - 'a'] == 0) distinct--;
                left++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 遇到非元音字符时重置窗口（子串必须全为元音）
2. 双指针统计以 right 结尾、包含至少 k 种元音的子串数为 `n - right`
3. "恰好5种" = "至少5种"（因为只有5种元音，不存在6种）
