## 题目描述

给你一个整数 `n`，对于 `0 <= i <= n` 中的每个 `i`，计算其二进制表示中 `1` 的个数，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。

**示例 1:**

```
输入：n = 2
输出：[0,1,1]
解释：
0 --> 0
1 --> 1
2 --> 10
```

**示例 2:**

```
输入：n = 5
输出：[0,1,1,2,1,2]
解释：
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

**提示:**

- `0 <= n <= 10^5`

**进阶:**

- 很容易就能实现时间复杂度为 `O(n log n)` 的解决方案，你可以在线性时间复杂度 `O(n)` 内用一趟扫描解决此问题吗？
- 你能不使用任何内置函数解决此问题吗？（如，C++ 中的 `__builtin_popcount`）

## 解题思路

这道题有多种解法，从暴力到优化，核心是找到**递推关系**。

### 思路一：动态规划（最低位）

**观察规律**：
- `i` 的二进制表示中 1 的个数 = `i / 2` 的二进制表示中 1 的个数 + `i % 2`
- 即：`dp[i] = dp[i >> 1] + (i & 1)`

**原理**：
- `i >> 1` 是 `i` 右移一位（去掉最低位）
- `i & 1` 是 `i` 的最低位（0 或 1）

### 思路二：动态规划（最低设置位）

**观察规律**：
- `i & (i - 1)` 可以去掉 `i` 最右边的 1
- `dp[i] = dp[i & (i - 1)] + 1`

**原理**：
- `i & (i - 1)` 去掉最右边的 1
- 再加上被去掉的那个 1

### 思路三：动态规划（最高有效位）

**观察规律**：
- 找到小于等于 `i` 的最大 2 的幂 `highBit`
- `dp[i] = dp[i - highBit] + 1`

## Java 代码实现

### 方法一：动态规划（最低位）⭐

```java
class Solution {
    public int[] countBits(int n) {
        // 动态规划：dp[i] = dp[i >> 1] + (i & 1)
        int[] dp = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            // i 右移一位 + 最低位
            dp[i] = dp[i >> 1] + (i & 1);
        }

        return dp;
    }
}
```

### 方法二：动态规划（最低设置位）

```java
class Solution {
    public int[] countBits(int n) {
        // 动态规划：dp[i] = dp[i & (i - 1)] + 1
        int[] dp = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            // 去掉最右边的 1，然后 +1
            dp[i] = dp[i & (i - 1)] + 1;
        }

        return dp;
    }
}
```

### 方法三：动态规划（最高有效位）

```java
class Solution {
    public int[] countBits(int n) {
        // 动态规划：按 2 的幂分段
        int[] dp = new int[n + 1];
        int highBit = 0;

        for (int i = 1; i <= n; i++) {
            // 如果 i 是 2 的幂，更新 highBit
            if ((i & (i - 1)) == 0) {
                highBit = i;
            }

            // dp[i] = dp[i - highBit] + 1
            dp[i] = dp[i - highBit] + 1;
        }

        return dp;
    }
}
```

### 方法四：Brian Kernighan 算法

```java
class Solution {
    public int[] countBits(int n) {
        // Brian Kernighan 算法：每次去掉最右边的 1
        // 时间复杂度 O(n * k)，k 是二进制位数
        int[] ans = new int[n + 1];

        for (int i = 0; i <= n; i++) {
            ans[i] = countOnes(i);
        }

        return ans;
    }

    private int countOnes(int x) {
        int count = 0;
        while (x != 0) {
            x &= x - 1;  // 去掉最右边的 1
            count++;
        }
        return count;
    }
}
```

### 方法五：使用 Java 内置函数

```java
class Solution {
    public int[] countBits(int n) {
        // 使用 Integer.bitCount() 统计 1 的个数
        // 不符合进阶要求，但代码简洁
        int[] ans = new int[n + 1];
        for (int i = 0; i <= n; i++) {
            ans[i] = Integer.bitCount(i);
        }
        return ans;
    }
}
```

### 方法六：逐位统计

```java
class Solution {
    public int[] countBits(int n) {
        // 逐位统计 1 的个数
        int[] ans = new int[n + 1];

        for (int i = 0; i <= n; i++) {
            int x = i;
            int count = 0;
            while (x != 0) {
                count += x & 1;  // 检查最低位
                x >>= 1;  // 右移一位
            }
            ans[i] = count;
        }

        return ans;
    }
}
```

## 复杂度分析

**方法一/二/三：动态规划**

- **时间复杂度**：O(n)
  - 遍历 0 到 n，每次 O(1)
  
- **空间复杂度**：O(1)
  - 不考虑返回值的空间

**方法四/六：逐位统计**

- **时间复杂度**：O(n * log n)
  - 每个数字需要 O(log n) 时间统计 1 的个数
  
- **空间复杂度**：O(1)

**方法五：内置函数**

- **时间复杂度**：O(n)
  - `Integer.bitCount()` 是 O(1) 操作
  
- **空间复杂度**：O(1)

## 关键点总结

1. **三种 DP 递推关系**：
   - 最低位：`dp[i] = dp[i >> 1] + (i & 1)`
   - 最低设置位：`dp[i] = dp[i & (i - 1)] + 1`
   - 最高有效位：`dp[i] = dp[i - highBit] + 1`

2. **位运算技巧**：
   - `i >> 1`：右移一位，相当于 `i / 2`
   - `i & 1`：获取最低位
   - `i & (i - 1)`：去掉最右边的 1

3. **2 的幂判断**：`(i & (i - 1)) == 0`

4. **Brian Kernighan 算法**：`x &= x - 1` 去掉最右边的 1

5. **O(n) 优化**：利用已计算的结果，避免重复计算

## 易错点

1. **数组长度**：应该是 `n + 1`，包括 0

2. **初始值**：`dp[0] = 0`（0 的二进制中没有 1），Java 数组默认初始化为 0，自动满足

3. **位运算优先级**：
   - `(i & 1)` 需要加括号
   - `(i & (i - 1)) == 0` 需要正确的括号

4. **方法三的 highBit 更新**：
   - 只在 `i` 是 2 的幂时更新
   - 判断条件：`(i & (i - 1)) == 0`

5. **Brian Kernighan 算法**：
   - 是 `x &= x - 1`，不是 `x &= x + 1`

示例 2：`n = 5`

```
方法一（最低位）：
i=0: dp[0] = 0
i=1: dp[1] = dp[0] + 1 = 0 + 1 = 1
i=2: dp[2] = dp[1] + 0 = 1 + 0 = 1
i=3: dp[3] = dp[1] + 1 = 1 + 1 = 2

i=5: dp[5] = dp[2] + 1 = 1 + 1 = 2

方法二（最低设置位）：
i=0: dp[0] = 0
i=1: dp[1] = dp[0] + 1 = 0 + 1 = 1
i=2: dp[2] = dp[0] + 1 = 0 + 1 = 1
i=3: dp[3] = dp[2] + 1 = 1 + 1 = 2
i=4: dp[4] = dp[0] + 1 = 0 + 1 = 1
i=5: dp[5] = dp[4] + 1 = 1 + 1 = 2

结果: [0, 1, 1, 2, 1, 2]

方法三（最高有效位）：
i=1: highBit=1, dp[1] = dp[0] + 1 = 1
i=2: highBit=2, dp[2] = dp[0] + 1 = 1
i=3: highBit=2, dp[3] = dp[1] + 1 = 2
i=4: highBit=4, dp[4] = dp[0] + 1 = 1
```
