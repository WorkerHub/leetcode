## 题目描述

给你整数数组 `nums` 和查询数组 `queries`（每个查询 `[l, r]` 可将区间内某一个元素减 1），返回使所有元素变为 0 所需的最少操作次数，不可行则返回 -1。

## 解题思路

二分 + 差分检验：二分答案 k（使用前 k 个查询），用差分数组计算每个位置被覆盖的总次数，若所有位置覆盖次数均 >= nums[i] 则可行。

## Java 代码实现

```java
class Solution {
    public int minZeroArray(int[] nums, int[][] queries) {
        int n = nums.length, m = queries.length;

        if (!feasible(nums, queries, m)) return -1;

        int lo = 0, hi = m;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (feasible(nums, queries, mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean feasible(int[] nums, int[][] queries, int k) {
        int n = nums.length;
        int[] diff = new int[n + 1];
        for (int i = 0; i < k; i++) {
            int l = queries[i][0], r = queries[i][1];
            diff[l]++;
            diff[r + 1]--;
        }
        int coverage = 0;
        for (int i = 0; i < n; i++) {
            coverage += diff[i];
            if (coverage < nums[i]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m * n)，二分 O(log m) * 差分检查 O(n + k)
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组：O(n) 计算每个位置被前 k 个查询覆盖的总次数
2. 可行性：每个位置覆盖次数 >= nums[i] 即可行
3. 二分最小 k，先检查全部 m 个查询是否可行，不可行直接返回 -1
