## 题目描述

返回字符串 s 中最长的 awesome 子字符串长度。awesome 子串可重排成回文（至多一个字符出现奇数次）。s 只含数字 0-9。

**示例：**
```
输入：s = "3242415"
输出：5
```

## 解题思路

前缀异或 + 哈希表：用 10 位掩码记录各数字奇偶性。子串能构成回文 iff 前缀 XOR 至多 1 位不同。

## Java 代码实现

```java
class Solution {
    public int longestAwesome(String s) {
        // firstSeen[mask] = 该 mask 第一次出现的位置
        int[] firstSeen = new int[1024]; // 2^10
        Arrays.fill(firstSeen, -2); // -2 表示未见过
        firstSeen[0] = -1; // 空前缀
        
        int mask = 0, ans = 0;
        for (int i = 0; i < s.length(); i++) {
            // 翻转第 c 位
            mask ^= 1 << (s.charAt(i) - '0');
            
            // 情况1：完全相同 mask（全为偶数次）
            if (firstSeen[mask] != -2) {
                ans = Math.max(ans, i - firstSeen[mask]);
            } else {
                firstSeen[mask] = i;
            }
            
            // 情况2：只有一位不同（一个字符奇数次）
            for (int j = 0; j < 10; j++) {
                int target = mask ^ (1 << j);
                if (firstSeen[target] != -2) {
                    ans = Math.max(ans, i - firstSeen[target]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10n) = O(n)
- **空间复杂度**：O(1024) = O(1)

## 关键点总结

1. **10位掩码**：记录 0-9 各数字出现奇偶性
2. **前缀XOR**：子串奇偶性 = 两端前缀 XOR
3. **记录最早位置**：保证子串最长
