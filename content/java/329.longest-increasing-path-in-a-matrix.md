## 题目描述

给定一个 `m x n` 整数矩阵 `matrix`，找出其中**最长递增路径**的长度。

对于每个单元格，你可以往上，下，左，右四个方向移动。你**不能**在对角线方向上移动或移动到边界外（即不允许环绕）。

**示例 1:**

```
输入：matrix = [[9,9,4],[6,6,8],[2,1,1]]
输出：4
解释：最长递增路径为 [1, 2, 6, 9]。
```

**示例 2:**

```
输入：matrix = [[3,4,5],[3,2,6],[2,2,1]]
输出：4
解释：最长递增路径是 [3, 4, 5, 6]。注意不允许在对角线方向上移动。
```

**示例 3:**

```
输入：matrix = [[1]]
输出：1
```

**提示:**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 200`
- `0 <= matrix[i][j] <= 2^31 - 1`

## 解题思路

这道题有两种经典解法：**记忆化 DFS** 和**拓扑排序**。

### 思路一：记忆化深度优先搜索（推荐）

1. **DFS 搜索**：从每个格子出发，向四个方向 DFS，找到最长递增路径
2. **记忆化优化**：用 `memo[i][j]` 记录从 `(i, j)` 出发的最长路径长度，避免重复计算
3. **递归关系**：`memo[i][j] = max(dfs(邻居)) + 1`（邻居值必须大于当前值）

**为什么不会形成环？**
- 因为路径必须严格递增，不可能从某个点出发再回到自己

### 思路二：拓扑排序

1. **构建有向图**：如果 `matrix[i][j] < matrix[x][y]`，则 `(i,j) -> (x,y)` 有一条边
2. **计算入度**：每个节点的入度 = 有多少个邻居比它小
3. **BFS 拓扑排序**：
   - 从入度为 0 的节点开始（最小值节点）
   - 每次移除一层，路径长度 +1
   - 层数即为最长路径长度

## Java 代码实现

### 方法一：记忆化 DFS（推荐）⭐

```java
class Solution {
    private int[][] memo;
    private int[][] matrix;
    private int m, n;
    private int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    public int longestIncreasingPath(int[][] matrix) {
        // 记忆化深度优先搜索
        if (matrix == null || matrix.length == 0) return 0;

        m = matrix.length;
        n = matrix[0].length;
        this.matrix = matrix;
        memo = new int[m][n];  // 记忆化数组，0 表示未计算

        int result = 0;
        // 从每个格子出发，找全局最大值
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result = Math.max(result, dfs(i, j));
            }
        }

        return result;
    }

    private int dfs(int i, int j) {
        // 从 (i, j) 出发的最长递增路径长度
        // 已经计算过，直接返回
        if (memo[i][j] != 0) return memo[i][j];

        // 初始长度为 1（只包含自己）
        int maxLength = 1;

        for (int[] dir : directions) {
            int x = i + dir[0];
            int y = j + dir[1];

            // 检查边界和递增条件
            if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] > matrix[i][j]) {
                // 递归搜索邻居，取最大值
                maxLength = Math.max(maxLength, dfs(x, y) + 1);
            }
        }

        // 记录结果
        memo[i][j] = maxLength;
        return maxLength;
    }
}
```

### 方法二：拓扑排序（BFS）

```java
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    public int longestIncreasingPath(int[][] matrix) {
        // 拓扑排序：从最小值开始，逐层剥离
        if (matrix == null || matrix.length == 0) return 0;

        int m = matrix.length, n = matrix[0].length;
        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        // 计算每个格子的入度（有多少个邻居比它小）
        int[][] inDegree = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                for (int[] dir : directions) {
                    int x = i + dir[0], y = j + dir[1];
                    if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] < matrix[i][j]) {
                        inDegree[i][j]++;
                    }
                }
            }
        }

        // 将入度为 0 的格子加入队列（最小值）
        Queue<int[]> queue = new LinkedList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (inDegree[i][j] == 0) {
                    queue.offer(new int[]{i, j});
                }
            }
        }

        // BFS 拓扑排序
        int pathLength = 0;

        while (!queue.isEmpty()) {
            pathLength++;
            int size = queue.size();

            // 处理当前层的所有节点
            for (int s = 0; s < size; s++) {
                int[] cell = queue.poll();
                int i = cell[0], j = cell[1];

                // 遍历邻居
                for (int[] dir : directions) {
                    int x = i + dir[0], y = j + dir[1];

                    // 如果邻居更大，减少其入度
                    if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] > matrix[i][j]) {
                        inDegree[x][y]--;

                        // 入度为 0，加入队列
                        if (inDegree[x][y] == 0) {
                            queue.offer(new int[]{x, y});
                        }
                    }
                }
            }
        }

        return pathLength;
    }
}
```

### 方法三：简化版记忆化 DFS

```java
class Solution {
    private int[][] memo;
    private int[][] matrix;
    private int m, n;

    public int longestIncreasingPath(int[][] matrix) {
        // 简化版记忆化 DFS（等价于 Python 的 @lru_cache 写法）
        if (matrix == null || matrix.length == 0) return 0;

        m = matrix.length;
        n = matrix[0].length;
        this.matrix = matrix;
        memo = new int[m][n];

        int result = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result = Math.max(result, dfs(i, j));
            }
        }

        return result;
    }

    private int dfs(int i, int j) {
        // 从 (i, j) 出发的最长递增路径
        if (memo[i][j] != 0) return memo[i][j];

        int maxLength = 1;
        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        for (int[] dir : directions) {
            int x = i + dir[0], y = j + dir[1];
            if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] > matrix[i][j]) {
                maxLength = Math.max(maxLength, dfs(x, y) + 1);
            }
        }

        return memo[i][j] = maxLength;
    }
}
```

## 复杂度分析

**方法一：记忆化 DFS**

- **时间复杂度**：O(m * n)
  - 每个格子最多计算一次（记忆化）
  - 每次计算遍历 4 个方向
  
- **空间复杂度**：O(m * n)
  - memo 数组 + 递归栈

**方法二：拓扑排序**

- **时间复杂度**：O(m * n)
  - 计算入度：O(m * n)
  - BFS 遍历：每个格子最多入队一次
  
- **空间复杂度**：O(m * n)
  - inDegree 数组 + 队列

## 关键点总结

1. **记忆化必不可少**：没有记忆化会导致大量重复计算，超时
2. **严格递增保证无环**：不需要 visited 数组标记访问状态
3. **拓扑排序思想**：从最小值开始，逐层剥离，层数即为最长路径
4. **四个方向遍历**：使用方向数组 `directions` 简化代码
5. **全局最大值**：需要从每个格子出发尝试，取最大值

## 易错点

1. **忘记记忆化**：纯 DFS 会超时
2. **边界检查**：`x >= 0 && x < m && y >= 0 && y < n`
3. **递增条件**：`matrix[x][y] > matrix[i][j]`（严格大于）
4. **初始值设置**：
   - 记忆化 DFS：`maxLength = 1`（至少包含自己）
   - memo 初始化为 0（表示未计算）
5. **拓扑排序的入度定义**：
   - 本题：有多少个邻居**比它小**（而不是常规的有多少条入边）
