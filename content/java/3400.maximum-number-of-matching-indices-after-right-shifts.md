## 题目描述

给定两个长度为 n 的整数数组 `nums1` 和 `nums2`，每次可对 `nums1` 进行右移（最后一个元素移到最前），返回经若干次右移后 `nums1[i] == nums2[i]` 的最大匹配下标数量。

## Java 代码实现

```java
class Solution {
    public int maximumMatchingIndices(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int best = 0;

        // 枚举右移次数 k（0 到 n-1）
        for (int k = 0; k < n; k++) {
            int count = 0;
            // 右移 k 次后：nums1[j] 对应 nums2[(j+k)%n]
            for (int j = 0; j < n; j++) {
                if (nums1[j] == nums2[(j + k) % n]) count++;
            }
            best = Math.max(best, count);
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举 n 种右移，每次比较 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 右移 k 次等价于将 nums1[j] 与 nums2[(j+k)%n] 比较。
2. 枚举 k 从 0 到 n-1，统计每种右移下的匹配数，取最大值。
3. n <= 1000 时 O(n^2) 完全可行。
