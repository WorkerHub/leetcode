## 题目描述

f(x) 是 x! 末尾零的个数。给定 k，返回满足 f(x)=k 的非负整数 x 的数量。

**示例：**
```
输入：k = 0
输出：5（0!,1!,2!,3!,4! 末尾零个数都是 0）
```

## 解题思路

答案只能是 0 或 5。用二分查找判断是否存在 n 使得 trailingZeroes(n)==k。

## Java 代码实现

```java
class Solution {
    public int preimageSizeFZF(int k) {
        // 二分查找 f(n) >= k 的最小 n
        long left = 0, right = 5L * (k + 1);
        while (left < right) {
            long mid = left + (right - left) / 2;
            if (trailingZeroes(mid) < k) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return trailingZeroes(left) == k ? 5 : 0;
    }

    private long trailingZeroes(long n) {
        long count = 0;
        while (n > 0) {
            n /= 5;
            count += n;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²k)
- **空间复杂度**：O(1)

## 关键点总结

1. **答案只有 0 或 5**：f(n) 每次增加都跳 5 个连续值
2. **二分查找**：f(n) 单调递增，可二分
3. **末尾零公式**：n/5 + n/25 + n/125 + ...
