## 题目描述

给你一个整数数组 `nums`，选择任意两个下标 `i < j`，求 `nums[i] + nums[j] + gcd(nums[i], nums[j])` 的最大值。

## Java 代码实现

```java
class Solution {
    public long maxGcdSum(int[] nums) {
        int n = nums.length;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 枚举每对 (i, j)，计算两数之和加最大公因数
                long val = (long) nums[i] + nums[j] + gcd(nums[i], nums[j]);
                ans = Math.max(ans, val);
            }
        }
        return ans;
    }

    // 辗转相除法求最大公因数
    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max))，枚举 n^2 对，每对 gcd 计算 O(log(max))
- 空间复杂度：O(1)

## 关键点总结

1. gcd(a, b) <= min(a, b)，当 a 是 b 的倍数时取到最大值
2. 暴力枚举在 n <= 1000 时完全够用
3. 最优对通常是两个较大且有较大公约数的数
