## 题目描述

从屏幕显示 `"a"` 开始，每次可将最后一个字符改为下一个字母，或在末尾追加 `'a'`，返回变成 `target` 过程中出现的所有字符串序列。

## 解题思路

对 `target` 的每个字符 `c`，先追加 `'a'`，再逐步将末尾字符从 `'a'` 递增到 `c`。每次追加或递增都记录当前字符串。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<String> stringSequence(String target) {
        List<String> result = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        for (char c : target.toCharArray()) {
            cur.append('a'); // 追加 'a'
            // 从 'a' 递增到目标字符 c
            for (char ch = 'a'; ch <= c; ch++) {
                cur.setCharAt(cur.length() - 1, ch);
                result.add(cur.toString());
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，每个字符最多 26 步，每步构建字符串 O(n)
- 空间复杂度：O(n * 26)，结果序列

## 关键点总结

1. 每个字符经历：先追加 'a'，再逐步递增到目标字符
2. 前缀部分已固定，只有末尾字符在变化
3. 包含初始 "a" 和最终 target 的路径
