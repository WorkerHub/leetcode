## 题目描述

给数组 nums 和正整数 k，若子数组 nums[i..j] 满足 |nums[i]-nums[j]| < k，则为"好子数组"。返回所有好子数组中元素和的最大值，若不存在返回 0。

## 解题思路

前缀和 + 哈希表：枚举右端点 j，在哈希表中查找满足 |nums[i]-nums[j]| < k 的左端点 i，维护各 nums[i] 值对应的最小前缀和，使子数组和最大。

## Java 代码实现

```java
class Solution {
    public long maximumSubarraySum(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];
        // 记录每个值对应的最小前缀和
        Map<Integer, Long> minPrefix = new HashMap<>();
        long ans = Long.MIN_VALUE;
        boolean found = false;
        for (int j = 0; j < n; j++) {
            int v = nums[j];
            // 查询 minPrefix 中 key 满足 |key - v| < k 的最小值
            for (Map.Entry<Integer, Long> e : minPrefix.entrySet()) {
                if (Math.abs((long) e.getKey() - v) < k) {
                    long sum = prefix[j + 1] - e.getValue();
                    if (!found || sum > ans) { ans = sum; found = true; }
                }
            }
            // 更新当前值的最小前缀和
            minPrefix.merge(v, prefix[j], Math::min);
        }
        return found ? ans : 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²) 最坏情况
- **空间复杂度**：O(n)

## 关键点总结

1. 子数组和 = 右前缀和 - 左前缀和，左前缀和越小越好
2. 哈希表记录每个值对应的最小前缀和
3. k 最大 2×10^9，比较差值时用 long 防溢出
