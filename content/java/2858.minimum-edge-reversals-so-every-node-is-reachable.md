## 题目描述

给你一棵 n 个节点的有向树，返回数组 `answer`，`answer[i]` 为以节点 i 为根时从根到达所有节点所需反转的最少边数。

## 解题思路

换根 DP：先以节点 0 为根计算 `dp[0]`（需反转的边数），再 BFS 换根，转移公式 `dp[child] = dp[parent] + 1 - 2*cost`（cost=0 表示 parent→child 顺方向，cost=1 表示逆方向）。

## Java 代码实现

```java
class Solution {
    public int[] minEdgeReversals(int n, int[][] edges) {
        // 邻接表：(邻居, cost)，cost=0 顺方向无需反转，cost=1 逆方向需反转
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], 0}); // e[0]->e[1] 顺方向
            graph[e[1]].add(new int[]{e[0], 1}); // e[1]->e[0] 逆方向
        }

        int[] dp = new int[n];

        // 第一次 BFS：以 0 为根计算 dp[0]
        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0);
        visited[0] = true;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int[] nei : graph[node]) {
                if (!visited[nei[0]]) {
                    visited[nei[0]] = true;
                    dp[0] += nei[1]; // 从 0 出发遇到逆方向边需反转
                    queue.offer(nei[0]);
                }
            }
        }

        // 第二次 BFS：换根，按 BFS 顺序递推
        Arrays.fill(visited, false);
        queue.offer(0);
        visited[0] = true;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int[] nei : graph[node]) {
                if (!visited[nei[0]]) {
                    visited[nei[0]] = true;
                    // cost 是从 node 到 nei[0] 的方向代价
                    // 换根后该边代价变为 1-cost，差值为 1-2*cost
                    dp[nei[0]] = dp[node] + 1 - 2 * nei[1];
                    queue.offer(nei[0]);
                }
            }
        }
        return dp;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 建图时记录边方向（顺方向 cost=0，逆方向 cost=1）
2. 换根转移：`dp[child] = dp[parent] + 1 - 2 * cost`
3. 两次 BFS：第一次计算根节点答案，第二次换根递推所有节点
