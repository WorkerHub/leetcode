## 题目描述

给你长度 n 的数组 `nums`，对每个长度 k（1≤k≤n），求所有长度为 k 的子数组的最小值中的最大值，返回长度为 n 的答案数组。

## 解题思路

单调栈：对每个元素用单调栈求其作为最小值的最长子数组长度，更新对应位置的答案，最后从右向左传播（更短子数组答案不小于更长的）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] findMaximums(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i <= n; i++) {
            while (!stack.isEmpty() && (i == n || nums[stack.peek()] >= nums[i])) {
                int idx = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int right = i;
                int length = right - left - 1; // 以 nums[idx] 为最小值的最长子数组长度
                ans[length - 1] = Math.max(ans[length - 1], nums[idx]);
            }
            stack.push(i);
        }

        // 从大到小传播：更短子数组的答案 >= 更长子数组的答案
        for (int k = n - 2; k >= 0; k--)
            ans[k] = Math.max(ans[k], ans[k + 1]);

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 单调栈求每个元素作为最小值的最长子数组长度
2. 用 `i == n` 作为哨兵触发栈中剩余元素的处理
3. 反向传播填充所有长度的答案
