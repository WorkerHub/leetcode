## 题目描述

奇妙字符串是至多有一个字母出现奇数次的字符串（仅含 'a' 到 'j'），给你字符串 `word`，返回其中奇妙子字符串的数目。

## 解题思路

用 10 位掩码表示各字母出现次数的奇偶性，维护前缀掩码的出现次数。对每个前缀掩码，统计与之异或为 0（全偶）或为 2 的幂（恰一个奇数）的之前前缀的数量。

## Java 代码实现

```java
class Solution {
    public long wonderfulSubstrings(String word) {
        int[] count = new int[1024]; // 2^10 种掩码
        count[0] = 1; // 空前缀

        int mask = 0;
        long result = 0;

        for (char ch : word.toCharArray()) {
            mask ^= 1 << (ch - 'a'); // 翻转对应位

            // 情况1：全偶数（与相同掩码的前缀配对）
            result += count[mask];

            // 情况2：恰好一个奇数（与只差一位的掩码配对）
            for (int i = 0; i < 10; i++) {
                result += count[mask ^ (1 << i)];
            }

            count[mask]++;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10n) = O(n)
- **空间复杂度**：O(2^10) = O(1)

## 关键点总结

1. 位掩码表示各字母奇偶性，XOR 翻转奇偶
2. 子串掩码 = 前缀 XOR 之差，奇妙条件：掩码为 0 或为 2 的幂
3. 初始化 count[0] = 1（空前缀），每步检查 11 种合法情况
