## 题目描述

设计数据结构支持范围频率查询：给定 (left, right, value)，返回 arr[left..right] 中 value 出现的次数。

## 解题思路

预处理：用 HashMap 存储每个值的所有下标列表（有序）。查询时对该列表二分查找 >= left 和 > right 的位置，差值即为频率。

## Java 代码实现

### 方法一：HashMap + 二分查找（推荐）

```java
import java.util.*;

class RangeFreqQuery {
    private Map<Integer, List<Integer>> pos;

    public RangeFreqQuery(int[] arr) {
        pos = new HashMap<>();
        for (int i = 0; i < arr.length; i++) {
            pos.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }
    }

    public int query(int left, int right, int value) {
        List<Integer> indices = pos.get(value);
        if (indices == null) return 0;
        // 找 >= left 的第一个位置
        int lo = lowerBound(indices, left);
        // 找 > right 的第一个位置
        int hi = upperBound(indices, right);
        return hi - lo;
    }

    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    private int upperBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 初始化：O(n)
- 每次查询：O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 预处理存下标列表，查询时二分
2. lowerBound 找 >= left 的位置，upperBound 找 > right 的位置
3. 值不存在时返回 0
