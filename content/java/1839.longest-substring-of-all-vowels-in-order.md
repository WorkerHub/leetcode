## 题目描述

找最长"美丽子字符串"：仅含元音、非递减排列、每种元音至少出现一次。

## 解题思路

线性扫描：维护当前子串长度和不同元音数。当前字符>=前一字符则扩展，否则重置。unique==5时更新答案。

## Java 代码实现

```java
class Solution {
    public int longestBeautifulSubstring(String word) {
        int n = word.length();
        if (n < 5) return 0;
        
        int maxLen = 0, curLen = 1, unique = 1;
        
        for (int i = 1; i < n; i++) {
            if (word.charAt(i) == word.charAt(i - 1)) {
                curLen++;
            } else if (word.charAt(i) > word.charAt(i - 1)) {
                curLen++;
                unique++;
            } else {
                curLen = 1;
                unique = 1;
            }
            if (unique == 5) maxLen = Math.max(maxLen, curLen);
        }
        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **非递减判断**：charAt(i) >= charAt(i-1)
2. **元音有序**：a<e<i<o<u，字符比较即可
3. **unique==5时才更新**：确保5种元音都出现
