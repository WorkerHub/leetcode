## 题目描述

将1到n的整数按数字之和分组，返回最大组的个数。

## 解题思路

枚举1到n计算数字之和，用HashMap统计每种数字之和的个数，找最大组大小后统计达到该大小的组数。

## Java 代码实现

```java
class Solution {
    public int countLargestGroup(int n) {
        Map<Integer, Integer> groups = new HashMap<>();
        for (int num = 1; num <= n; num++) {
            int digitSum = 0;
            int x = num;
            while (x > 0) {
                digitSum += x % 10;
                x /= 10;
            }
            groups.merge(digitSum, 1, Integer::sum);
        }
        int maxSize = Collections.max(groups.values());
        int count = 0;
        for (int size : groups.values()) {
            if (size == maxSize) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * logN)
- **空间复杂度**：O(logN)，数字之和种类有限

## 关键点总结

1. **数字之和计算**：逐位取余累加
2. **HashMap统计分组大小**
3. **先找最大值再统计个数**
