## 题目描述

给你 `n x n` 矩阵 `grid`，`grid[row][col]` 表示骑士在该位置的访问顺序（从 0 开始）。判断该访问序列是否是合法的骑士游览路径。

## 解题思路

**模拟验证**：记录每个序号对应的坐标，然后按顺序检查相邻两步之间是否满足骑士 L 形移动（行差和列差绝对值分别为 1 和 2 的组合）。

## Java 代码实现

```java
class Solution {
    public boolean checkValidGrid(int[][] grid) {
        int n = grid.length;
        // 起点必须是 (0, 0)
        if (grid[0][0] != 0) return false;

        // 记录每个序号对应的 (行, 列)
        int[][] pos = new int[n * n][2];
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                pos[grid[r][c]][0] = r;
                pos[grid[r][c]][1] = c;
            }
        }

        // 验证相邻步之间是否是合法骑士移动
        for (int i = 1; i < n * n; i++) {
            int dr = Math.abs(pos[i][0] - pos[i - 1][0]);
            int dc = Math.abs(pos[i][1] - pos[i - 1][1]);
            // 骑士 L 形：(1,2) 或 (2,1)
            if (!((dr == 1 && dc == 2) || (dr == 2 && dc == 1))) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 起点必须是 `grid[0][0] == 0`
2. 骑士移动：行差和列差的绝对值分别为 1 和 2（或 2 和 1）
3. 规模最大 7x7=49，模拟即可
