## 题目描述

给定有 `n` 个节点的加权树，找到加权中位节点（重心）：删除该节点后，每个连通分量的权重之和均不超过总权重的一半。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findWeightedMedian(int n, int[][] edges, int[] weight) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        long total = 0;
        for (int w : weight) total += w;

        long[] subtreeWeight = new long[n];
        for (int i = 0; i < n; i++) subtreeWeight[i] = weight[i];

        int[] parent = new int[n];
        Arrays.fill(parent, -1);
        int[] order = new int[n];
        int idx = 0;

        // 迭代 DFS 建立遍历顺序
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0, -1});
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            int u = cur[0], p = cur[1];
            order[idx++] = u;
            parent[u] = p;
            for (int v : graph.get(u)) {
                if (v != p) stack.push(new int[]{v, u});
            }
        }

        // 后序计算子树权重
        for (int i = n - 1; i >= 0; i--) {
            int u = order[i];
            if (parent[u] != -1) subtreeWeight[parent[u]] += subtreeWeight[u];
        }

        // 贪心：从根出发，向最重子树移动
        int curr = 0;
        while (true) {
            int bestChild = -1;
            long bestW = 0;
            for (int v : graph.get(curr)) {
                if (v != parent[curr] && subtreeWeight[v] > bestW) {
                    bestW = subtreeWeight[v];
                    bestChild = v;
                }
            }
            if (bestW * 2 <= total) break;
            parent[bestChild] = -1;
            curr = bestChild;
        }
        return curr;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，DFS + 贪心移动
- 空间复杂度：O(n)

## 关键点总结

1. 树的重心：每个连通分量权重 <= 总权重/2
2. 贪心：从任意节点出发，向最重的子树移动，保证终止于重心
3. 权重用 `long` 防止累加溢出
