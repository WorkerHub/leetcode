## 题目描述

给定 `m × n` 整数矩阵 `grid`，从任意单元格出发，每次移动到上下左右相邻单元格且值恰好等于当前值加一。返回最长连续路径的长度。

## 解题思路

DFS + 记忆化：`dp[i][j]` 为以 `(i,j)` 为起点的最长连续递增路径。由于路径值严格递增不存在环，记忆化后每格只计算一次。

## Java 代码实现

```java
class Solution {
    int[][] dp;
    int[][] grid;
    int m, n;
    int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

    public int longestPath(int[][] grid) {
        this.grid = grid;
        m = grid.length; n = grid[0].length;
        dp = new int[m][n];
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = Math.max(ans, dfs(i, j));
        return ans;
    }

    private int dfs(int i, int j) {
        if (dp[i][j] != 0) return dp[i][j];
        dp[i][j] = 1;
        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && grid[ni][nj] == grid[i][j] + 1) {
                dp[i][j] = Math.max(dp[i][j], dfs(ni, nj) + 1);
            }
        }
        return dp[i][j];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 路径值严格递增，DAG 无环，DFS 无需 visited
2. 记忆化每格只计算一次，整体 O(mn)
3. `dp[i][j] != 0` 作为已计算标志
