## 题目描述

给你整数数组 `usageLimits`，其中 `usageLimits[i]` 是值 `i` 的最大使用次数，将整数分组使得每组长度严格递增且组内元素各不相同，返回最大组数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxIncreasingGroups(int[] usageLimits) {
        Arrays.sort(usageLimits);
        int ans = 0;
        long surplus = 0; // 多余使用次数
        for (int u : usageLimits) {
            surplus += u;
            // 若结余 >= 下一组所需长度，创建新组
            if (surplus >= ans + 1) {
                surplus -= (ans + 1);
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)

## 关键点总结

1. 排序后贪心：使用限制多的值可灵活填充多个组
2. 维护结余次数：当结余 >= 下一组长度时创建新组
3. `surplus` 用 `long` 防止累积和溢出
