## 题目描述

给你一个含至少一个 '1' 的二进制字符串，重排字符使得结果是奇数中的最大值，返回结果字符串。

## 解题思路

贪心：末位必须保留一个 '1'（保证奇数），其余所有 '1' 放在最高位，'0' 放在中间，公式为 `(ones-1) 个 '1' + zeros 个 '0' + '1'`。

## Java 代码实现

```java
class Solution {
    public String maximumOddBinaryNumber(String s) {
        int ones = 0;
        for (char c : s.toCharArray()) if (c == '1') ones++;
        int zeros = s.length() - ones;

        // (ones-1) 个 '1' + zeros 个 '0' + 末尾 '1'
        return "1".repeat(ones - 1) + "0".repeat(zeros) + "1";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 奇数要求末位为 '1'，保留一个 '1' 在末位
2. 其余 `ones-1` 个 '1' 放在最高位使数值最大
3. '0' 填充在中间位置
