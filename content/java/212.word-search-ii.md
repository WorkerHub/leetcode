## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个单词（字符串）列表 `words`，返回所有二维网格上的单词。

单词必须按照字母顺序，通过 **相邻的单元格** 内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母在一个单词中 **不允许被重复使用**。

**示例 1：**

```
输入：board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]
输出：["eat","oath"]
```

**示例 2：**

```
输入：board = [["a","b"],["c","d"]], words = ["abcb"]
输出：[]
```

**提示：**

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 12`
- `board[i][j]` 是一个小写英文字母
- `1 <= words.length <= 3 * 10^4`
- `1 <= words[i].length <= 10`
- `words[i]` 由小写英文字母组成
- `words` 中的所有字符串互不相同

## 解题思路

这道题是 [79. 单词搜索](https://leetcode.com/problems/word-search/) 的进阶版，需要在网格中查找多个单词。

**核心思想：**

如果对每个单词都进行一次 DFS，会导致大量重复搜索。更优的方法是：
1. **构建字典树（Trie）**：将所有单词存入 Trie
2. **一次 DFS 遍历**：从每个格子出发，同时匹配 Trie 中的所有单词
3. **剪枝优化**：找到单词后立即从 Trie 中置空，避免重复

**算法流程：**

1. 构建 Trie：将 `words` 中所有单词插入字典树
2. 遍历网格：从每个格子 `(i, j)` 出发进行 DFS
3. DFS 搜索：
   - 检查当前字符是否在 Trie 的子节点中
   - 如果是单词结尾，加入结果集
   - 标记当前格子为已访问（修改为特殊字符）
   - 递归搜索四个方向
   - 回溯：恢复格子原值
4. 剪枝：找到单词后将节点的 word 置为 null，避免重复查找

## Java 代码实现

### 方法一：字典树 + DFS + 剪枝（推荐）⭐

```java
class Solution {
    // 字典树节点
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word = null; // 存储完整单词（仅终止节点有值）
    }

    // 四个方向：右、下、左、上
    private static final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    public List<String> findWords(char[][] board, String[] words) {
        // 构建字典树
        TrieNode root = new TrieNode();
        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                int idx = c - 'a';
                if (node.children[idx] == null) {
                    node.children[idx] = new TrieNode();
                }
                node = node.children[idx];
            }
            node.word = word; // 存储完整单词
        }

        List<String> result = new ArrayList<>();
        int m = board.length, n = board[0].length;

        // 从每个格子出发搜索
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dfs(board, i, j, root, result);
            }
        }

        return result;
    }

    private void dfs(char[][] board, int i, int j, TrieNode node, List<String> result) {
        // 边界检查
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) {
            return;
        }

        char c = board[i][j];
        // 已访问过，或字符不在 Trie 中
        if (c == '#') return;

        int idx = c - 'a';
        if (node.children[idx] == null) return;

        node = node.children[idx];

        // 找到一个单词
        if (node.word != null) {
            result.add(node.word);
            node.word = null; // 置空避免重复添加
        }

        // 标记为已访问
        board[i][j] = '#';

        // 四个方向递归搜索
        for (int[] dir : DIRS) {
            dfs(board, i + dir[0], j + dir[1], node, result);
        }

        // 回溯：恢复原值
        board[i][j] = c;
    }
}
```

### 方法二：字典树类封装版

```java
class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word = null;
    }

    private static class Trie {
        TrieNode root = new TrieNode();

        void insert(String word) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                int idx = c - 'a';
                if (node.children[idx] == null) {
                    node.children[idx] = new TrieNode();
                }
                node = node.children[idx];
            }
            node.word = word;
        }
    }

    private static final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    private List<String> result = new ArrayList<>();

    public List<String> findWords(char[][] board, String[] words) {
        // 构建字典树
        Trie trie = new Trie();
        for (String word : words) {
            trie.insert(word);
        }

        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dfs(board, i, j, trie.root);
            }
        }

        return result;
    }

    private void dfs(char[][] board, int i, int j, TrieNode node) {
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) return;

        char c = board[i][j];
        if (c == '#') return;

        int idx = c - 'a';
        if (node.children[idx] == null) return;

        node = node.children[idx];

        // 找到单词
        if (node.word != null) {
            result.add(node.word);
            node.word = null; // 避免重复
        }

        // 标记已访问
        board[i][j] = '#';

        // 四个方向搜索
        for (int[] dir : DIRS) {
            dfs(board, i + dir[0], j + dir[1], node);
        }

        // 回溯
        board[i][j] = c;
    }
}
```

### 方法三：暴力解法（供对比学习）

```java
class Solution {
    private static final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    public List<String> findWords(char[][] board, String[] words) {
        // 对每个单词单独进行 DFS
        List<String> result = new ArrayList<>();
        int m = board.length, n = board[0].length;

        for (String word : words) {
            boolean found = false;
            outer:
            for (int i = 0; i < m && !found; i++) {
                for (int j = 0; j < n && !found; j++) {
                    if (board[i][j] == word.charAt(0)) {
                        if (dfs(board, i, j, word, 0, new boolean[m][n])) {
                            result.add(word);
                            found = true;
                        }
                    }
                }
            }
        }

        return result;
    }

    private boolean dfs(char[][] board, int i, int j, String word, int index, boolean[][] visited) {
        if (index == word.length()) return true;
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) return false;
        if (visited[i][j] || board[i][j] != word.charAt(index)) return false;

        visited[i][j] = true;

        for (int[] dir : DIRS) {
            if (dfs(board, i + dir[0], j + dir[1], word, index + 1, visited)) {
                visited[i][j] = false;
                return true;
            }
        }

        visited[i][j] = false;
        return false;
    }
}
```

## 复杂度分析

**方法一（字典树 + DFS）：**

- **时间复杂度：** O(M × N × 4^L)
  - M × N 是网格大小
  - L 是单词最大长度
  - 每个格子最多有 4 个方向
  - Trie 剪枝可显著降低实际复杂度
- **空间复杂度：** O(K × L)
  - K 是单词数量
  - L 是单词平均长度
  - 递归栈深度：O(L)

**方法三（暴力）：**

- **时间复杂度：** O(K × M × N × 4^L)
  - K 个单词，每个都要遍历整个网格
- **空间复杂度：** O(M × N + L)

## 关键点总结

1. **字典树优化**：一次 DFS 同时匹配多个单词，避免重复搜索
2. **剪枝策略**：找到单词后置空 word 字段，防止重复结果
3. **回溯模板**：标记访问 → 递归搜索 → 恢复状态
4. **空间优化**：直接修改 `board` 标记访问，无需额外 `visited` 数组
5. **Java 特点**：用 `TrieNode[26]` 数组代替 HashMap，效率更高

## 易错点

1. **重复结果**：
   ```java
   // 错误：未置空已找到的单词
   if (node.word != null) {
       result.add(node.word);
   }
   // 正确：找到后置为 null 避免重复
   if (node.word != null) {
       result.add(node.word);
       node.word = null;
   }
   ```

2. **回溯遗漏**：
   ```java
   // 错误：忘记恢复原值
   board[i][j] = '#';
   dfs(...);
   // 正确：必须回溯
   board[i][j] = '#';
   dfs(...);
   board[i][j] = c;
   ```

3. **边界检查顺序**：先检查边界，再访问 `board[i][j]`，避免数组越界

4. **特殊字符冲突**：标记访问时选择的特殊字符（如 `#`）不能与题目字符冲突，小写字母只有 a-z，`#` 的 ASCII 值在字母之前，不会冲突

5. **字符索引转换**：
   ```java
   int idx = c - 'a'; // 正确：转换为 0-25 的下标
   ```
