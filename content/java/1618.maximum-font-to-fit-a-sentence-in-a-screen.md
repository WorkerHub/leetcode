## 题目描述

给定text、屏幕w×h、字体列表fonts（升序）和FontInfo接口，返回能完整显示text的最大字体大小。

## 解题思路

二分查找：字体越大宽高越大，找满足条件（宽≤w且高≤h）的最大字体。

## Java 代码实现

```java
class Solution {
    public int maxFont(String text, int w, int h, int[] fonts, FontInfo fontInfo) {
        int lo = 0, hi = fonts.length - 1, ans = -1;
        
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (canFit(text, w, h, fonts[mid], fontInfo)) {
                ans = fonts[mid];
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return ans;
    }
    
    private boolean canFit(String text, int w, int h, int fontSize, FontInfo fontInfo) {
        if (fontInfo.getHeight(fontSize) > h) return false;
        long totalWidth = 0;
        for (char c : text.toCharArray()) {
            totalWidth += fontInfo.getWidth(fontSize, c);
            if (totalWidth > w) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|text| × log|fonts|)
- **空间复杂度**：O(1)

## 关键点总结

1. **二分查找最大字体**：满足条件右移，不满足左移
2. **先检查高度**：高度不满足直接返回false
3. **提前终止宽度计算**：超过w就返回false
