## 题目描述

给你二叉树根节点 `root`，返回满足"节点值等于所有后代节点值之和"的节点数。

## 解题思路

后序遍历 DFS：先计算左右子树的节点值总和，后代和 = 左子树总和 + 右子树总和，判断是否等于当前节点值，返回包含自身的子树总和。

## Java 代码实现

```java
class Solution {
    int count = 0;

    public int equalToDescendants(TreeNode root) {
        dfs(root);
        return count;
    }

    private long dfs(TreeNode node) {
        if (node == null) return 0;
        long leftSum = dfs(node.left);
        long rightSum = dfs(node.right);
        long descSum = leftSum + rightSum;
        if (node.val == descSum) count++;
        return descSum + node.val;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. 后序遍历先处理子树再处理根
2. 返回子树总和供父节点使用
3. 使用 `long` 防止溢出（节点值可为负数）
