## 题目描述

构造长度为n的严格递增数组使所有元素AND等于x，求最后一个元素的最小值。

## 解题思路

所有元素的AND=x意味着x的1位在所有元素中都为1。将n-1的二进制位依次嵌入x的0位上，得到最小的nums[n-1]。

## Java 代码实现

```java
class Solution {
    public long minEnd(int n, int x) {
        long result = x;
        long val = n - 1; // 需要嵌入x的0位中
        int bit = 0;
        while (val > 0) {
            // 找x的下一个0位
            while (((result >> bit) & 1) == 1) {
                bit++;
            }
            // 将val的最低位嵌入result的第bit位
            if ((val & 1) == 1) {
                result |= (1L << bit);
            }
            val >>= 1;
            bit++;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log N + log X)
- **空间复杂度**：O(1)

## 关键点总结

1. **AND=x要求x的1位必须保留**
2. **将n-1嵌入x的0位**：等价于在0位上数第n-1个数
3. **用long防止溢出**
