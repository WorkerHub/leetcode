## 题目描述

找强对(x,y)满足|x-y|<=min(x,y)，求所有强对中x XOR y的最大值。（n<=50）

## 解题思路

数据范围小，暴力枚举所有对，检查强对条件，维护最大XOR。

## Java 代码实现

```java
class Solution {
    public int maximumStrongPairXor(int[] nums) {
        int ans = 0;
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                if (Math.abs(nums[i] - nums[j]) <= Math.min(nums[i], nums[j])) {
                    ans = Math.max(ans, nums[i] ^ nums[j]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **强对条件等价于max(x,y)<=2*min(x,y)**
2. **允许i==j**：XOR为0
3. **数据范围小直接暴力**
