## 题目描述

给定正整数 n ，我们按任何顺序（包括原始顺序）将数字重新排序，注意其前导数字不能为零。

如果我们可以通过上述方式得到 2 的幂，返回 true；否则，返回 false。

**示例 1：**
```
输入：n = 1
输出：true
```

**示例 2：**
```
输入：n = 10
输出：false
```

**提示：**
- 1 <= n <= 10^9

## 解题思路

**关键观察：**
- 2 的幂最多到 2^29（10^9 范围内）
- 检查 n 的数字计数是否与某个 2 的幂相同

## Java 代码实现

### 方法一：排序比较（推荐）

```java
class Solution {
    public boolean reorderedPowerOf2(int n) {
        char[] nChars = Integer.toString(n).toCharArray();
        Arrays.sort(nChars);
        String sortedN = new String(nChars);

        // 检查所有 2 的幂（10^9 范围内最多 2^29）
        for (int i = 0; i < 30; i++) {
            char[] powerChars = Integer.toString(1 << i).toCharArray();
            Arrays.sort(powerChars);
            if (new String(powerChars).equals(sortedN)) {
                return true;
            }
        }

        return false;
    }
}
```

**代码说明：**
- 将 n 和 2 的幂的各位数字排序后比较
- 排序后相同 → 可以重排得到

### 方法二：计数比较

```java
class Solution {
    public boolean reorderedPowerOf2(int n) {
        String countN = getCount(n);

        for (int i = 0; i < 30; i++) {
            if (getCount(1 << i).equals(countN)) {
                return true;
            }
        }

        return false;
    }

    // 统计各数字出现次数，返回 "d0d1d2...d9" 格式
    private String getCount(int n) {
        int[] count = new int[10];
        while (n > 0) {
            count[n % 10]++;
            n /= 10;
        }
        return Arrays.toString(count);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²n)，排序每个数字串。
- **空间复杂度**：O(log n)，字符串长度。

## 关键点总结

1. **计数/排序比较**：使用排序后的数字串判断
2. **范围确定**：2^30 > 10^9，最多检查 30 个
3. **注意溢出**：`1 << i` 在 i=30 时对 int 溢出，只需 0~29
