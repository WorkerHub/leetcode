## 题目描述

给你字符串 `s`，每次可以替换一个字符，用最少操作将 `s` 变为字典序最小的回文串，返回该回文串。

## Java 代码实现

```java
class Solution {
    public String makeSmallestPalindrome(String s) {
        char[] arr = s.toCharArray();
        int left = 0, right = arr.length - 1;
        while (left < right) {
            if (arr[left] != arr[right]) {
                // 取较小字符，保证字典序最小
                char smaller = (char) Math.min(arr[left], arr[right]);
                arr[left] = arr[right] = smaller;
            }
            left++;
            right--;
        }
        return new String(arr);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 双指针处理对称位置，将较大字符替换为较小字符
2. 只需一次操作即可使不同的对称字符相等，同时保证字典序最小
