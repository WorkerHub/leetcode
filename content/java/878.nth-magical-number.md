## 题目描述

正整数能被 a 或 b 整除则为"神奇数字"。给定 n、a、b，返回第 n 个神奇数字（对 10^9+7 取模）。

**示例：**
```
输入：n = 4, a = 2, b = 3
输出：6
```

## 解题思路

二分答案 + 容斥原理：二分 x，计算 [1,x] 中神奇数字个数 = x/a + x/b - x/lcm(a,b)。

## Java 代码实现

```java
class Solution {
    public int nthMagicalNumber(int n, int a, int b) {
        int MOD = 1_000_000_007;
        long lcm = (long) a / gcd(a, b) * b;

        long left = Math.min(a, b);
        long right = (long) n * Math.min(a, b);

        while (left < right) {
            long mid = left + (right - left) / 2;
            long count = mid / a + mid / b - mid / lcm;
            if (count < n) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return (int) (left % MOD);
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(n × min(a,b)))
- **空间复杂度**：O(1)

## 关键点总结

1. **容斥原理**：x/a + x/b - x/lcm 避免重复计数
2. **二分答案**：count(x) 关于 x 单调递增
3. **LCM 公式**：lcm(a,b) = a * b / gcd(a,b)
