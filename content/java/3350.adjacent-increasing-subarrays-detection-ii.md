## 题目描述

与 3349 类似，但返回最大的 `k` 值，使得存在两个相邻且不重叠的长度为 `k` 的严格递增子数组。

## 解题思路

将数组分解为若干连续递增段。对于每两个相邻递增段，各自贡献 `min(左段长, 右段长)`；对于同一递增段内，可将其对半分，贡献 `段长 / 2`。取所有情况的最大值。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int maxIncreasingSubarrays(int[] nums) {
        int n = nums.length;

        // 预处理 inc[i]：从 i 开始的最长严格递增子数组长度
        int[] inc = new int[n];
        inc[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            inc[i] = nums[i] < nums[i + 1] ? inc[i + 1] + 1 : 1;
        }

        // 提取所有连续递增段的长度
        List<Integer> segments = new ArrayList<>();
        int i = 0;
        while (i < n) {
            int len = inc[i];
            segments.add(len);
            i += len;
        }

        int ans = 0;

        // 同一段内对半分
        for (int seg : segments) {
            ans = Math.max(ans, seg / 2);
        }

        // 相邻两段各取最小长度
        for (int s = 0; s < segments.size() - 1; s++) {
            ans = Math.max(ans, Math.min(segments.get(s), segments.get(s + 1)));
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历找所有递增段
- 空间复杂度：O(n)，递增段列表

## 关键点总结

1. 两段可以在同一个递增段内（最大 k = 段长度 / 2）。
2. 两段也可以是相邻的两个递增段（最大 k = min(左段长, 右段长)）。
3. 以上两种情况覆盖了所有可能，取最大值即可。
