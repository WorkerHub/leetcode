## 题目描述

给定字符串数组 `words`，每次操作可以交换相邻两个字符串的位置，求将所有互为字母异位词的字符串分组放在一起所需的最少操作次数。

## 解题思路

将每个字符串规范化（字母排序），相同规范化形式视为同组。问题等价于求将类别序列排成同组相邻的最少相邻交换次数，即逆序对数目（类比冒泡排序）。用归并排序 O(n log n) 统计逆序对。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[] labels;

    public int minOperations(String[] words) {
        Map<String, Integer> labelMap = new HashMap<>();
        labels = new int[words.length];
        for (int i = 0; i < words.length; i++) {
            char[] chars = words[i].toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            labelMap.putIfAbsent(key, labelMap.size());
            labels[i] = labelMap.get(key);
        }
        // 计算目标排列（按类别稳定排序后的下标）
        Integer[] idx = new Integer[words.length];
        for (int i = 0; i < idx.length; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> labels[a] - labels[b]);

        // 统计逆序对
        int[] pos = new int[words.length];
        for (int i = 0; i < idx.length; i++) pos[idx[i]] = i;

        return mergeSort(pos, 0, pos.length);
    }

    private int mergeSort(int[] arr, int lo, int hi) {
        if (hi - lo <= 1) return 0;
        int mid = (lo + hi) / 2;
        int inv = mergeSort(arr, lo, mid) + mergeSort(arr, mid, hi);
        int[] merged = new int[hi - lo];
        int i = lo, j = mid, k = 0;
        while (i < mid && j < hi) {
            if (arr[i] <= arr[j]) {
                merged[k++] = arr[i++];
            } else {
                merged[k++] = arr[j++];
                inv += mid - i; // arr[i..mid-1] 都比 arr[j] 大
            }
        }
        while (i < mid) merged[k++] = arr[i++];
        while (j < hi) merged[k++] = arr[j++];
        System.arraycopy(merged, 0, arr, lo, hi - lo);
        return inv;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 字母异位词规范化：对字母排序，相同规范化形式为同组
2. 分组相邻等价于求类别序列排序的最少相邻交换次数（逆序对数）
3. 归并排序统计逆序对
