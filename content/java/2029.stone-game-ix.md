## 题目描述

Alice 先手，Alice 和 Bob 轮流取石子，若已取走石子价值之和是 3 的倍数则取走最后一块的玩家输，无法操作者也输，两者最优策略，问 Alice 是否必赢。

## 解题思路

统计石子值模 3 的三种类别数量 cnt[0]、cnt[1]、cnt[2]：若 cnt[0] 为偶数，Alice 赢当且仅当 cnt[1] > 0 且 cnt[2] > 0；若 cnt[0] 为奇数，Alice 赢当且仅当 `|cnt[1] - cnt[2]| > 2`。

## Java 代码实现

### 方法一：数学结论（推荐）

```java
class Solution {
    public boolean stoneGameIX(int[] stones) {
        int[] cnt = new int[3];
        for (int s : stones) cnt[s % 3]++;

        if (cnt[0] % 2 == 0) {
            // cnt[0]为偶数：Alice赢需要1类和2类都有
            return cnt[1] > 0 && cnt[2] > 0;
        } else {
            // cnt[0]为奇数：Alice赢需要1类和2类差值>2
            return Math.abs(cnt[1] - cnt[2]) > 2;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只需统计石子值模 3 的三种类别数量
2. cnt[0] 的奇偶性决定博弈走向（偶数时 0 类石子成对抵消）
3. 这是经过完整博弈推导得出的数学结论
