## 题目描述

与3129相同但数据范围更大(<=1000)，需要前缀和优化DP转移。

## 解题思路

dp[i][j][v]表示放了i个0、j个1、末位为v的方案数。用前缀和将转移从O(limit)优化为O(1)：dp[i][j][0] = prefix1[i-1][j] - prefix1[i-limit-1][j]。

## Java 代码实现

```java
class Solution {
    public int numberOfStableArrays(int zero, int one, int limit) {
        int MOD = 1_000_000_007;
        long[][][] dp = new long[zero + 1][one + 1][2];

        // 初始化：纯0段或纯1段
        for (int i = 1; i <= Math.min(zero, limit); i++) dp[i][0][0] = 1;
        for (int j = 1; j <= Math.min(one, limit); j++) dp[0][j][1] = 1;

        // 前缀和数组：pr[i][j] = sum(dp[0..i][j][1]), pc[i][j] = sum(dp[i][0..j][0])
        long[][] pr = new long[zero + 1][one + 1];
        long[][] pc = new long[zero + 1][one + 1];

        // 构建初始前缀和
        for (int i = 0; i <= zero; i++) {
            for (int j = 0; j <= one; j++) {
                pr[i][j] = dp[i][j][1] + (i > 0 ? pr[i - 1][j] : 0);
                pc[i][j] = dp[i][j][0] + (j > 0 ? pc[i][j - 1] : 0);
            }
        }

        // 填充DP
        for (int i = 1; i <= zero; i++) {
            for (int j = 1; j <= one; j++) {
                // dp[i][j][0] = sum(dp[i-k][j][1], k=1..limit)
                long r = pr[i - 1][j] - (i - limit - 1 >= 0 ? pr[i - limit - 1][j] : 0);
                dp[i][j][0] = ((r % MOD) + MOD) % MOD;

                // dp[i][j][1] = sum(dp[i][j-k][0], k=1..limit)
                long c = pc[i][j - 1] - (j - limit - 1 >= 0 ? pc[i][j - limit - 1] : 0);
                dp[i][j][1] = ((c % MOD) + MOD) % MOD;

                // 更新前缀和
                pr[i][j] = (dp[i][j][1] + pr[i - 1][j]) % MOD;
                pc[i][j] = (dp[i][j][0] + pc[i][j - 1]) % MOD;
            }
        }
        return (int)((dp[zero][one][0] + dp[zero][one][1]) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(zero * one)
- **空间复杂度**：O(zero * one)

## 关键点总结

1. **前缀和优化转移**：O(limit)→O(1)
2. **行方向前缀和**维护末位为1的累积
3. **列方向前缀和**维护末位为0的累积
