## 题目描述

重构 2 行 n 列的二进制矩阵，第一行和为 upper，第二行和为 lower，第 i 列和为 colsum[i]。返回任意合法矩阵，不存在则返回空。

**示例：**
```
输入：upper = 2, lower = 1, colsum = [1,1,1]
输出：[[1,1,0],[0,0,1]]
```

## 解题思路

贪心：先处理 colsum=2 的列（两行都为 1），再处理 colsum=1 的列（优先放到剩余配额多的行），colsum=0 则两行都为 0。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> reconstructMatrix(int upper, int lower, int[] colsum) {
        int n = colsum.length;
        int[][] matrix = new int[2][n];
        
        // 先处理 colsum = 2
        for (int i = 0; i < n; i++) {
            if (colsum[i] == 2) {
                matrix[0][i] = 1;
                matrix[1][i] = 1;
                upper--;
                lower--;
            }
        }
        
        // 再处理 colsum = 1
        for (int i = 0; i < n; i++) {
            if (colsum[i] == 1) {
                if (upper > lower) {
                    matrix[0][i] = 1;
                    upper--;
                } else {
                    matrix[1][i] = 1;
                    lower--;
                }
            }
        }
        
        // 验证
        if (upper != 0 || lower != 0) return new ArrayList<>();
        
        List<List<Integer>> result = new ArrayList<>();
        for (int[] row : matrix) {
            List<Integer> list = new ArrayList<>();
            for (int v : row) list.add(v);
            result.add(list);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **colsum=2 先处理**：必须两行都为 1，无选择余地
2. **colsum=1 贪心**：优先放到剩余配额多的行
3. **验证**：处理完后 upper 和 lower 必须恰好为 0
4. **无解条件**：upper 或 lower 变为负数，或最终不为 0
