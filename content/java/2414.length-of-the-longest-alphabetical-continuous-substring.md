## 题目描述

给你小写英文字母字符串 `s`，返回最长字母连续子字符串的长度（即由字母表中连续字母组成的子串）。

## 解题思路

一次遍历：维护当前连续子串长度 `cur`，若 `s[i] - s[i-1] == 1` 则 `cur++`，否则重置 `cur=1`，实时更新最大值。

## Java 代码实现

```java
class Solution {
    public int longestContinuousSubstring(String s) {
        int ans = 1, cur = 1;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) - s.charAt(i - 1) == 1) {
                cur++;
                ans = Math.max(ans, cur);
            } else {
                cur = 1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 连续字母条件：`s[i] - s[i-1] == 1`（严格递增相差 1）。
2. 维护当前连续长度，不连续时重置为 1。
3. 初始 ans=1，单个字符也是合法子串。
