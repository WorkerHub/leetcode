## 题目描述

给你一棵 `n` 个节点的带权树，每个节点最多保留 `k` 条相邻边。在满足每个节点度数 <= k 的前提下，最大化保留边的权重之和。

## 解题思路

树形 DP + 贪心 DFS：对每个节点维护两个状态（连接/不连接父节点）。对每条子边计算净收益（`dp[child][1] + w - dp[child][0]`），贪心选择净收益最大的前 k 条（或 k-1 条，留一条给父节点），只选净收益 > 0 的边。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<int[]>[] graph;
    private int k;

    @SuppressWarnings("unchecked")
    public long maximizeSumOfWeights(int[][] edges, int k) {
        int n = edges.length + 1;
        this.k = k;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        return dfs(0, -1)[0];
    }

    // 返回 [dp0, dp1]：dp0 = 不连接父节点时最大和，dp1 = 连接父节点时最大和
    private long[] dfs(int node, int parent) {
        List<Long> gains = new ArrayList<>();
        long base = 0;

        for (int[] next : graph[node]) {
            int child = next[0], w = next[1];
            if (child == parent) continue;
            long[] res = dfs(child, node);
            base += res[0];
            // 选择连接 node-child 边的净收益
            gains.add(res[1] + w - res[0]);
        }

        // 降序排序净收益
        gains.sort(Collections.reverseOrder());

        // dp0：最多选 k 条子边（正收益）
        long dp0 = base;
        for (int i = 0; i < Math.min(k, gains.size()); i++) {
            if (gains.get(i) > 0) dp0 += gains.get(i);
            else break;
        }

        // dp1：最多选 k-1 条子边（留一条给父节点）
        long dp1 = base;
        for (int i = 0; i < Math.min(k - 1, gains.size()); i++) {
            if (gains.get(i) > 0) dp1 += gains.get(i);
            else break;
        }

        return new long[]{dp0, dp1};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS + 每个节点的排序
- 空间复杂度：O(n)，递归栈和邻接表

## 关键点总结

1. 树形 DP 每个节点有两种状态：连接或不连接父节点，决定可选子边数（k 或 k-1）。
2. 贪心选择净收益（`dp1 + w - dp0`）最大的前 k 条或 k-1 条子边。
3. 只有净收益 > 0 的边才值得选择。
