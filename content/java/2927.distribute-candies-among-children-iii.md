## 题目描述

将n颗糖分给3个小朋友，每人至多limit颗，求方案数。（n,limit<=10^8）

## 解题思路

容斥原理：答案=C(n+2,2)-3*C(n-limit+1,2)+3*C(n-2*limit,2)-C(n-3*limit-1,2)。

## Java 代码实现

```java
class Solution {
    public long distributeCandies(int n, int limit) {
        return c2(n + 2)
             - 3 * c2(n - limit + 1)
             + 3 * c2(n - 2 * limit)
             - c2(n - 3 * limit - 1);
    }

    private long c2(long x) {
        if (x < 2) return 0;
        return x * (x - 1) / 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **容斥原理**：减单人超限、加两人超限、减三人超限
2. **C(x,2)对负数返回0**：无意义方案数
3. **用long防溢出**：n可达10^8
