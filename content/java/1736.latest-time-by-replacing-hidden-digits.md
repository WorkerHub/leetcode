## 题目描述

给你格式为 `hh:mm` 的字符串 `time`，其中部分数字被替换为 `?`，返回满足有效时间（`00:00`-`23:59`）的最晚时间。

## 解题思路

贪心地为每个 `?` 填入当前位合法范围内的最大数字：小时十位受个位约束，小时个位受十位约束，分钟十位最大 5，分钟个位最大 9。

## Java 代码实现

```java
class Solution {
    public String maximumTime(String time) {
        char[] t = time.toCharArray();

        // 第 0 位：小时十位
        if (t[0] == '?') {
            // 个位 >= 4 时，十位只能是 1；否则可以是 2
            t[0] = (t[1] == '?' || t[1] - '0' <= 3) ? '2' : '1';
        }

        // 第 1 位：小时个位
        if (t[1] == '?') {
            t[1] = (t[0] == '2') ? '3' : '9'; // 2x 最大 23，其他最大 x9
        }

        // 第 3 位：分钟十位（最大 5）
        if (t[3] == '?') t[3] = '5';

        // 第 4 位：分钟个位（最大 9）
        if (t[4] == '?') t[4] = '9';

        return new String(t);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 各位有各自的合法范围，贪心取最大
2. 小时两位之间有约束：十位为 2 时个位最大 3；个位 >= 4 时十位最大 1
