## 题目描述

给你一座由 `n x n` 个街区组成的城市，每个街区都包含一座立方体建筑。给你一个下标从 **0** 开始的 `n x n` 整数矩阵 `grid`，其中 `grid[r][c]` 表示坐落于 `r` 行 `c` 列的建筑物的 **高度**。

城市的 **天际线** 是从远处观看城市时，所有建筑物形成的外部轮廓。从东、南、西、北四个主要方向观看到的 **天际线** 可能不同。

我们被允许为 **任意数量的建筑物** 的高度增加 **任意增量**。然而，增加的建筑物高度 **不能影响** 从任何主要方向观察城市得到的 **天际线**。

在 **不改变** 从任何主要方向观看得到的城市 **天际线** 的前提下，返回建筑物可以增加的 **最大高度增量总和**。

**示例 1:**
```
输入: grid = [[3,0,8,4],[2,4,5,7],[9,2,6,3],[0,3,1,0]]
输出: 35
```

**示例 2:**
```
输入: grid = [[0,0,0],[0,0,0],[0,0,0]]
输出: 0
```

**提示:**
- `n == grid.length`
- `n == grid[r].length`
- `2 <= n <= 50`
- `0 <= grid[r][c] <= 100`

## 解题思路

这道题的核心是理解"天际线"的概念：
- 从东/西方向看，天际线是每一行的最大值
- 从南/北方向看，天际线是每一列的最大值

**关键观察：**
要保持天际线不变，每个位置的建筑高度最多可以增加到：
- **min(该行最大值, 该列最大值)**

**算法步骤：**
1. 计算每一行的最大值（东西方向天际线）
2. 计算每一列的最大值（南北方向天际线）
3. 对于每个位置 `(i, j)`，可以增加到 `min(row_max[i], col_max[j])`
4. 累加所有位置的增量

## Java 代码实现

### 方法一：两次遍历（推荐）

```java
class Solution {
    public int maxIncreaseKeepingSkyline(int[][] grid) {
        int n = grid.length;

        // 计算每行的最大值（东西方向天际线）
        int[] rowMax = new int[n];
        // 计算每列的最大值（南北方向天际线）
        int[] colMax = new int[n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                rowMax[i] = Math.max(rowMax[i], grid[i][j]);
                colMax[j] = Math.max(colMax[j], grid[i][j]);
            }
        }

        // 计算总增量
        int totalIncrease = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                // 当前位置最多可以增加到两个方向天际线的最小值
                int maxHeight = Math.min(rowMax[i], colMax[j]);
                totalIncrease += maxHeight - grid[i][j];
            }
        }

        return totalIncrease;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，需要遍历整个矩阵
- **空间复杂度**：O(n)，存储行和列的最大值数组

## 关键点总结

1. **理解天际线**：行最大值和列最大值分别代表不同方向的天际线
2. **贪心策略**：每个位置都增加到允许的最大高度
3. **取最小值**：受两个方向限制，取 min 确保不改变任一方向的天际线
4. **矩阵操作**：熟练使用行列遍历和聚合操作

## 易错点

1. **理解错误**：可能会误以为只考虑一个方向的天际线
2. **增量计算**：是 `目标高度 - 当前高度`，不是目标高度本身
3. **矩阵转置**：计算列最大值时需要正确遍历列
