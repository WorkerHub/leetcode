## 题目描述

给你整数数组 `nums` 和正整数 `k`，每次操作可翻转某元素的一个二进制位，返回使所有元素 XOR 等于 `k` 的最少操作次数。

## 解题思路

计算所有元素的 XOR 值 xorAll，差异位 = xorAll XOR k，每个 1 位需要一次翻转，答案为差异位中 1 的个数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int xorAll = 0;
        for (int x : nums) xorAll ^= x; // 计算所有元素的 XOR
        int diff = xorAll ^ k;           // 差异位：需要翻转这些位
        return Integer.bitCount(diff);   // 1 的个数即为所需操作次数
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每次翻转一位等价于修改 xorAll 的那一位
2. 差异位 = xorAll XOR k，统计其中 1 的个数
3. Integer.bitCount() 计算汉明重量
