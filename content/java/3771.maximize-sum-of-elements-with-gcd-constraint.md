## 题目描述

给定整数数组 `nums` 和整数 `k`，选出一个子集使得子集所有元素的 GCD 恰好等于 `k`，且子集元素之和最大。

## 解题思路

筛选 `k` 的所有倍数，若这些倍数的总 GCD 等于 `k`，则全部选取；否则从大到小贪心添加，保证累计 GCD >= k，最终判断 GCD 是否等于 `k`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maxSum(int[] nums, int k) {
        // 筛选 k 的倍数，从大到小排序
        int[] multiples = Arrays.stream(nums)
                .filter(x -> x % k == 0)
                .toArray();

        if (multiples.length == 0) return -1;

        Arrays.sort(multiples);

        long total = 0;
        int curGcd = 0;
        // 从大到小贪心添加，保持 GCD >= k
        for (int i = multiples.length - 1; i >= 0; i--) {
            int newGcd = gcd(curGcd, multiples[i]);
            if (newGcd >= k) {
                curGcd = newGcd;
                total += multiples[i];
            }
        }

        return curGcd == k ? total : -1;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n + n log(max_val))
- 空间复杂度：O(n)

## 关键点总结

1. 只有 k 的倍数才能参与 GCD = k 的子集
2. 从大到小贪心选取，优先保留大元素以最大化总和
3. GCD(空集) 定义为 0，以 0 作初始值
