## 题目描述

初始分数1，目标target，最多maxDoubles次加倍(*2)，其余加一(+1)。求最少操作次数。

## 解题思路

逆向贪心：从target逆推到1。偶数且有加倍次数则除2，奇数则减1。加倍次数用完后剩余target-1次全部加一。

## Java 代码实现

```java
class Solution {
    public int minMoves(int target, int maxDoubles) {
        int ops = 0;
        while (target > 1 && maxDoubles > 0) {
            if (target % 2 == 1) {
                target--;
                ops++;
            } else {
                target /= 2;
                ops++;
                maxDoubles--;
            }
        }
        return ops + target - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(log target, maxDoubles))
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向思考**：从target逆推更直观
2. **奇数先减1**：不能直接除2
3. **加倍用完**：剩余全部加一（target-1步）
