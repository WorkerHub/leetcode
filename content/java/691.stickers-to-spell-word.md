## 题目描述

有 n 种贴纸，每个贴纸上有小写英文单词。从贴纸中切割字母拼出 target，返回最少贴纸数，不可能则返回 -1。

**示例：**
```
输入：stickers = ["with","example","science"], target = "thehat"
输出：3
```

## 解题思路

记忆化搜索：对剩余需要的字符串状态进行 DFS，每次选一个包含首字母的贴纸使用，取最小值。用排序后的剩余字符串作为 key 记忆化。

## Java 代码实现

```java
class Solution {
    public int minStickers(String[] stickers, String target) {
        int n = stickers.length;
        int[][] stickerCounts = new int[n][26];
        for (int i = 0; i < n; i++) {
            for (char c : stickers[i].toCharArray()) {
                stickerCounts[i][c - 'a']++;
            }
        }

        Map<String, Integer> memo = new HashMap<>();
        memo.put("", 0);
        return dfs(memo, stickerCounts, target);
    }

    private int dfs(Map<String, Integer> memo, int[][] stickerCounts, String remain) {
        if (memo.containsKey(remain)) return memo.get(remain);

        int[] targetCount = new int[26];
        for (char c : remain.toCharArray()) {
            targetCount[c - 'a']++;
        }

        int result = Integer.MAX_VALUE;
        for (int[] sticker : stickerCounts) {
            // 剪枝：贴纸必须包含 remain 的第一个字符
            if (sticker[remain.charAt(0) - 'a'] == 0) continue;

            // 使用贴纸后的剩余
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < 26; i++) {
                int need = targetCount[i] - sticker[i];
                for (int j = 0; j < Math.max(0, need); j++) {
                    sb.append((char) ('a' + i));
                }
            }

            int sub = dfs(memo, stickerCounts, sb.toString());
            if (sub != -1) {
                result = Math.min(result, 1 + sub);
            }
        }

        memo.put(remain, result == Integer.MAX_VALUE ? -1 : result);
        return memo.get(remain);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × m)，n 为 target 长度，m 为贴纸数
- **空间复杂度**：O(2^n)

## 关键点总结

1. **记忆化搜索**：用剩余字符串作为状态
2. **剪枝**：跳过不包含首字母的贴纸
3. **字母频率**：用频率数组高效计算剩余
