## 题目描述

给定有根树（根为节点 0），每条边有权值，通过对边权递增操作，使所有叶子节点的路径总长度相等，求最少总递增量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private long ans = 0;
    private List<List<int[]>> graph;  // graph[u] = [(v, w), ...]

    public long minIncrements(int n, int[][] edges) {
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(new int[]{e[1], e[2]});
            graph.get(e[1]).add(new int[]{e[0], e[2]});
        }
        dfs(0, -1);
        return ans;
    }

    // 返回以 node 为根的子树中叶子的最大相对深度
    private long dfs(int node, int parent) {
        List<Long> childrenDepths = new ArrayList<>();
        for (int[] child : graph.get(node)) {
            if (child[0] == parent) continue;
            long childMax = dfs(child[0], node);
            childrenDepths.add(childMax + child[1]);
        }

        if (childrenDepths.isEmpty()) return 0;  // 叶子节点

        // 对齐到最大深度
        long maxDepth = 0;
        for (long d : childrenDepths) maxDepth = Math.max(maxDepth, d);
        for (long d : childrenDepths) ans += maxDepth - d;

        return maxDepth;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈

## 关键点总结

1. 只能增不能减，各子树叶子对齐到最大深度
2. DFS 后序：先得到子树最大叶子深度，在父节点处对齐所有子树
3. 增量 = sum(max_depth - child_depth)，用 `long` 防止累加溢出
