## 题目描述

给你整数数组 `nums` 和正整数 `x`，从 `nums[0]` 出发可跳到任意后续位置，初始得分为 `nums[0]`，每次跳跃加上目标元素值，若奇偶性不同需额外扣除 `x`，返回最大得分。

## Java 代码实现

```java
class Solution {
    public long maxScore(int[] nums, int x) {
        // dp_even: 停在偶数位置的最大得分，dp_odd: 停在奇数位置的最大得分
        long NEG_INF = Long.MIN_VALUE / 2;
        long dpEven = NEG_INF, dpOdd = NEG_INF;
        if (nums[0] % 2 == 0) dpEven = nums[0];
        else dpOdd = nums[0];

        for (int i = 1; i < nums.length; i++) {
            long val = nums[i];
            if (val % 2 == 0) {
                // 来自偶数（同奇偶不扣费）或奇数（扣费 x）
                dpEven = Math.max(dpEven, dpOdd - x) + val;
            } else {
                dpOdd = Math.max(dpOdd, dpEven - x) + val;
            }
        }
        return Math.max(dpEven, dpOdd);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 按奇偶性维护两个 DP 状态，避免枚举所有跳跃路径
2. 奇偶切换需支付代价 x
3. 初始时另一奇偶状态为负无穷（不可达）
