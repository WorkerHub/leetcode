## 题目描述

将 nums 分成 k 个非空连续子数组，代价为首元素之和，且第 2 到第 k 个子数组起始下标跨度 ≤ dist，返回最小总代价。

## 解题思路

第一段代价固定为 nums[0]，需在滑动窗口 [i, i+dist] 内找 k-1 个最小值。用两个 TreeMap 动态维护窗口内最小的 k-1 个值（small）和其余值（large），滑动时保持两组大小平衡。

## Java 代码实现

```java
class Solution {
    private TreeMap<Integer, Integer> small = new TreeMap<>(), large = new TreeMap<>();
    private long smallSum = 0;
    private int need; // k-1

    public long minimumCost(int[] nums, int k, int dist) {
        need = k - 1;
        int n = nums.length;
        // 初始化窗口 [1, 1+dist]
        for (int i = 1; i <= 1 + dist && i < n; i++) addLarge(nums[i]);
        balance();

        long ans = small.size() == need ? nums[0] + smallSum : Long.MAX_VALUE;

        for (int i = 1; i + dist + 1 < n; i++) {
            // 移入新元素
            addLarge(nums[i + dist + 1]);
            // 移出旧元素 nums[i]
            remove(nums[i]);
            balance();
            if (small.size() == need) {
                ans = Math.min(ans, nums[0] + smallSum);
            }
        }
        return ans;
    }

    private void addSmall(int val) {
        small.merge(val, 1, Integer::sum);
        smallSum += val;
    }

    private void addLarge(int val) {
        large.merge(val, 1, Integer::sum);
    }

    private void remove(int val) {
        // 优先从 small 移除，否则从 large 移除
        if (small.containsKey(val)) {
            smallSum -= val;
            if (small.merge(val, -1, Integer::sum) == 0) small.remove(val);
        } else {
            if (large.merge(val, -1, Integer::sum) == 0) large.remove(val);
        }
    }

    private void balance() {
        // small 过多：移出最大值到 large
        while (small.size() > need) {
            int val = small.lastKey();
            smallSum -= val;
            if (small.merge(val, -1, Integer::sum) == 0) small.remove(val);
            large.merge(val, 1, Integer::sum);
        }
        // small 不足：从 large 移入最小值
        while (small.size() < need && !large.isEmpty()) {
            int val = large.firstKey();
            if (large.merge(val, -1, Integer::sum) == 0) large.remove(val);
            addSmall(val);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 窗口大小为 dist+1，在窗口内选 k-1 个最小值
2. TreeMap 支持有序操作和重复元素（用频次计数）
3. balance() 保持 small 恰好含 k-1 个最小值
