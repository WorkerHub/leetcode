## 题目描述

给你整数数组 `nums` 和非负整数 `k`，每次操作可将任意元素加 1 或减 1。返回使中位数等于 k 的最少操作数（偶数长度时中位数为中间两个中较小的）。

## 解题思路

排序后中位数在下标 `m = n/2`。若中位数大于 k，对左半（含 m）中大于 k 的元素求超出之和；若小于 k，对右半（含 m）中小于 k 的元素求不足之和。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minOperationsToMakeMedianK(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length, m = n / 2;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            if (i <= m && nums[i] > k) ans += nums[i] - k; // 左半部分大于 k
            else if (i >= m && nums[i] < k) ans += k - nums[i]; // 右半部分小于 k
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 中位数下标为 n/2，只需操作影响中位数的那一侧
2. 结果可能超 int，使用 long
