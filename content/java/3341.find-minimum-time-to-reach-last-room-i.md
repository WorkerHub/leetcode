## 题目描述

给你 `n x m` 的网格和 `moveTime[i][j]`（进入时间限制），从 `(0,0)` 出发，每步移动相邻格耗时 1 秒，但进入格子时间不能早于 `moveTime[i][j]`，返回到达 `(n-1, m-1)` 的最短时间。

## 解题思路

Dijkstra 最短路：从 `(r, c)` 移到 `(nr, nc)` 的到达时间为 `max(dist[r][c], moveTime[nr][nc]) + 1`（等待开放后再移动 1 秒）。用最小堆维护最短到达时间。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minTimeToReach(int[][] moveTime) {
        int n = moveTime.length, m = moveTime[0].length;
        int[][] dist = new int[n][m];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        // 最小堆：[时间, 行, 列]
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0, 0});

        int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int t = cur[0], r = cur[1], c = cur[2];
            if (t > dist[r][c]) continue;
            if (r == n - 1 && c == m - 1) return t;
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
                int arrive = Math.max(t, moveTime[nr][nc]) + 1;
                if (arrive < dist[nr][nc]) {
                    dist[nr][nc] = arrive;
                    pq.offer(new int[]{arrive, nr, nc});
                }
            }
        }
        return dist[n - 1][m - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m * log(n * m))，Dijkstra
- 空间复杂度：O(n * m)

## 关键点总结

1. 到达时间 = `max(当前时间, moveTime[目标]) + 1`（等待开放再移动 1 秒）
2. Dijkstra 标准写法，跳过过时状态
3. 初始格子 `(0,0)` 无需等待
