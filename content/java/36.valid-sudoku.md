## 题目描述

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可。

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3 x 3` 宫内只能出现一次。

**注意：**
- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

**示例 1：**
```
输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

**示例 2：**
```
输入：board = 
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与示例1相同。但由于位于左上角的 3x3 宫内有两个 8 存在, 因此这个数独是无效的。
```

## 解题思路

### 核心思想：哈希表记录

需要检查三个条件：
1. 每行没有重复数字
2. 每列没有重复数字
3. 每个 3×3 宫格没有重复数字

**算法流程：**
1. 遍历数独的每个格子
2. 对于每个非空格子 `board[i][j]`：
   - 检查该数字是否在第 `i` 行出现过
   - 检查该数字是否在第 `j` 列出现过
   - 检查该数字是否在所在的 3×3 宫格出现过
3. 用哈希表记录已出现的数字

**关键：如何确定 3×3 宫格？**
- 宫格索引 = `(i / 3) * 3 + j / 3`
- 例如 `(4, 5)` 在第 `(1, 1)` 个宫格

## Java 代码实现

### 方法一：使用集合数组

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // 记录每行、每列、每个宫格出现的数字
        Set<Character>[] rows = new HashSet[9];
        Set<Character>[] cols = new HashSet[9];
        Set<Character>[] boxes = new HashSet[9];
        
        for (int i = 0; i < 9; i++) {
            rows[i] = new HashSet<>();
            cols[i] = new HashSet<>();
            boxes[i] = new HashSet<>();
        }
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char num = board[i][j];
                
                // 跳过空格
                if (num == '.') continue;
                
                // 计算宫格索引
                int boxIndex = (i / 3) * 3 + j / 3;
                
                // 检查是否重复
                if (rows[i].contains(num) || cols[j].contains(num) || boxes[boxIndex].contains(num)) {
                    return false;
                }
                
                // 记录该数字
                rows[i].add(num);
                cols[j].add(num);
                boxes[boxIndex].add(num);
            }
        }
        
        return true;
    }
}
```

### 方法二：位运算（空间优化）

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // 用位掩码记录，每一位表示数字1-9是否出现
        int[] rows = new int[9];
        int[] cols = new int[9];
        int[] boxes = new int[9];
        
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') continue;
                
                int num = board[i][j] - '0';
                int boxIndex = (i / 3) * 3 + j / 3;
                
                // 检查该数字对应的位是否已设置
                int bit = 1 << num;
                if ((rows[i] & bit) != 0 || (cols[j] & bit) != 0 || (boxes[boxIndex] & bit) != 0) {
                    return false;
                }
                
                // 设置该位
                rows[i] |= bit;
                cols[j] |= bit;
                boxes[boxIndex] |= bit;
            }
        }
        
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，固定遍历 81 个格子
- **空间复杂度**：O(1)，固定使用 9 个集合/数组

## 图解示例

### 宫格索引计算：

```
数独被分成 9 个 3×3 宫格，编号 0-8：

+-------+-------+-------+
| 0 0 0 | 1 1 1 | 2 2 2 |
| 0 0 0 | 1 1 1 | 2 2 2 |
| 0 0 0 | 1 1 1 | 2 2 2 |
+-------+-------+-------+
| 3 3 3 | 4 4 4 | 5 5 5 |
| 3 3 3 | 4 4 4 | 5 5 5 |
| 3 3 3 | 4 4 4 | 5 5 5 |
+-------+-------+-------+
| 6 6 6 | 7 7 7 | 8 8 8 |
| 6 6 6 | 7 7 7 | 8 8 8 |
| 6 6 6 | 7 7 7 | 8 8 8 |
+-------+-------+-------+

宫格索引公式：(i / 3) * 3 + j / 3

例如：
(0, 0) → (0/3)*3 + 0/3 = 0
(2, 4) → (2/3)*3 + 4/3 = 0*3 + 1 = 1
(5, 7) → (5/3)*3 + 7/3 = 1*3 + 2 = 5
```

## 关键点总结

1. **宫格索引计算**：
   - `boxIndex = (i / 3) * 3 + j / 3`
   - 这是本题的核心技巧

2. **三重检查**：
   - 行：`rows[i]`
   - 列：`cols[j]`
   - 宫格：`boxes[boxIndex]`

3. **数据结构选择**：
   - 集合（HashSet）：简单直观
   - 位运算：空间最优

4. **边界条件**：
   - 空格用 `'.'` 表示，需要跳过

## 易错点

1. **宫格索引计算**：
   - 容易写错公式
   - 记住：`(i / 3) * 3 + j / 3`

2. **字符和整数**：
   - `board[i][j]` 是 char 类型
   - 位运算版本需要 `board[i][j] - '0'` 转换为整数

3. **空格判断**：
   - 要先判断是否为 `'.'`，再处理

4. **Java 数组初始化**：
   - `Set<Character>[]` 需要手动初始化每个元素
