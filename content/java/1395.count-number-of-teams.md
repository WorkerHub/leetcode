## 题目描述

从数组中选3个下标i<j<k使得rating严格递增或严格递减，求有效团队总数。

## 解题思路

枚举中间元素j，统计左侧比它小/大的个数和右侧比它大/小的个数，乘法原理计算。

## Java 代码实现

```java
class Solution {
    public int numTeams(int[] rating) {
        int n = rating.length;
        int count = 0;

        for (int j = 1; j < n - 1; j++) {
            int leftLess = 0, leftGreater = 0;
            int rightLess = 0, rightGreater = 0;

            for (int i = 0; i < j; i++) {
                if (rating[i] < rating[j]) leftLess++;
                else if (rating[i] > rating[j]) leftGreater++;
            }
            for (int k = j + 1; k < n; k++) {
                if (rating[k] > rating[j]) rightGreater++;
                else if (rating[k] < rating[j]) rightLess++;
            }
            // 递增三元组 + 递减三元组
            count += leftLess * rightGreater + leftGreater * rightLess;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举中间元素**：将O(N^3)降为O(N^2)
2. **乘法原理**：左右两侧独立选择
3. **递增+递减分别计算**
