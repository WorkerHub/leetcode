## 题目描述

给你两个整数 `num1` 和 `num2`。如果整数 `x` 满足：`x` 能被 `num1` 整除，且 `num1` 的十进制表示是 `x` 的十进制表示的子序列，则称 `x` 是一个**好数**。返回 `[1, num2]` 范围内所有好数之和。

## 解题思路

枚举 `num1` 的所有倍数（在 `[num1, num2]` 范围内），对每个倍数 `x` 用双指针检验 `String(num1)` 是否是 `String(x)` 的子序列。

## Java 代码实现

```java
class Solution {
    public long sumOfGoodNumbers(int num1, int num2) {
        String s1 = String.valueOf(num1);
        long total = 0;

        // 枚举 num1 的倍数
        for (int x = num1; x <= num2; x += num1) {
            if (isSubsequence(s1, String.valueOf(x))) {
                total += x;
            }
        }

        return total;
    }

    // 判断 sub 是否是 main 的子序列
    private boolean isSubsequence(String sub, String main) {
        int i = 0;
        for (int j = 0; j < main.length() && i < sub.length(); j++) {
            if (main.charAt(j) == sub.charAt(i)) {
                i++;
            }
        }
        return i == sub.length();
    }
}
```

## 复杂度分析

- 时间复杂度：O(num2/num1 * log(num2))，枚举倍数 * 子序列检验（O(位数)）
- 空间复杂度：O(log(num2))，字符串转换

## 关键点总结

1. 好数必须是 num1 的倍数，直接枚举倍数即可。
2. 子序列检验用双指针实现，O(字符串长度)。
3. 枚举数量约为 num2/num1，每次验证 O(位数)，总时间可接受。
