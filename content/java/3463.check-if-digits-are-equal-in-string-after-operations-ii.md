## 题目描述

与 3461 题相同，但字符串长度最大为 10^5，需要高效计算最终结果。最终值 = sum(C(n-2, i) * d[i]) mod 10。

## 解题思路

由于 10 = 2 * 5，用卢卡斯定理分别对质数 2 和 5 计算 C(n-2, i) mod p，再用中国剩余定理合并得到 mod 10 的结果。

## Java 代码实现

```java
class Solution {
    public boolean hasSameDigits(String s) {
        int n = s.length();
        int[] d = new int[n];
        for (int i = 0; i < n; i++) d[i] = s.charAt(i) - '0';

        int val0 = compute(d, 0, n - 1);
        int val1 = compute(d, 1, n - 1);
        return val0 == val1;
    }

    // 计算 sum(C(len-1, i) * d[start+i]) mod 10
    private int compute(int[] d, int start, int len) {
        int r2 = sumMod(d, start, len, 2);
        int r5 = sumMod(d, start, len, 5);
        // 中国剩余定理：找 x in [0,9] 使得 x%2==r2 且 x%5==r5
        for (int x = 0; x < 10; x++) {
            if (x % 2 == r2 && x % 5 == r5) return x;
        }
        return 0;
    }

    // 计算 sum(C(len-1, i) * d[start+i]) mod p（质数 p）
    private int sumMod(int[] d, int start, int len, int p) {
        int result = 0;
        int N = len - 1;
        for (int i = 0; i < len; i++) {
            int c = lucas(N, i, p);
            result = (result + c * d[start + i]) % p;
        }
        return result;
    }

    // 卢卡斯定理：C(n, k) mod p（p 为质数）
    private int lucas(int n, int k, int p) {
        if (k == 0) return 1;
        if (k > n) return 0;
        return (int) ((long) smallC(n % p, k % p, p) * lucas(n / p, k / p, p) % p);
    }

    // C(n, k) mod p，其中 n < p
    private int smallC(int n, int k, int p) {
        if (k > n) return 0;
        long c = 1;
        for (int i = 0; i < k; i++) {
            c = c * (n - i) % p;
            c = c * modInverse(i + 1, p) % p;
        }
        return (int) c;
    }

    // 费马小定理求逆元（p 为质数）
    private long modInverse(long a, long p) {
        return modPow(a, p - 2, p);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log_p(n))，卢卡斯定理递归深度
- 空间复杂度：O(log_p(n))

## 关键点总结

1. 最终结果 = 二项式卷积对 10 取模
2. 分别对质数 2 和 5 用卢卡斯定理计算，再用中国剩余定理合并
3. 卢卡斯定理：C(n,k) mod p = C(n%p, k%p) * C(n/p, k/p) mod p
