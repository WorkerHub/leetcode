## 题目描述

设计支持 `setCell`、`resetCell`（重置为 0）、`getValue`（计算形如 `"=A1+B2+3"` 公式之和）的电子表格，行号 1-9，列 A-Z。

## 解题思路

用 HashMap 存储非零单元格的值。解析公式时按 `+` 分割：首字符为大写字母则为单元格引用，否则为整数。

## Java 代码实现

```java
import java.util.*;

class Spreadsheet {
    private Map<String, Integer> cells = new HashMap<>();

    public Spreadsheet(int rows) {
        // 初始化无需预分配，哈希表按需存储
    }

    public void setCell(String cell, int value) {
        cells.put(cell, value);
    }

    public void resetCell(String cell) {
        cells.remove(cell);
    }

    public int getValue(String formula) {
        // 去掉开头的 '='
        String expr = formula.substring(1);
        String[] tokens = expr.split("\\+");
        int total = 0;
        for (String token : tokens) {
            if (!token.isEmpty() && Character.isUpperCase(token.charAt(0))) {
                // 单元格引用
                total += cells.getOrDefault(token, 0);
            } else {
                // 整数
                total += Integer.parseInt(token);
            }
        }
        return total;
    }
}
```

## 复杂度分析

- setCell/resetCell：O(1)
- getValue：O(L)，L 为公式长度
- 空间复杂度：O(n)，n 为非零单元格数量

## 关键点总结

1. HashMap 存储非零单元格，节省空间，未设置的单元格默认为 0
2. 公式以 `=` 开头，按 `+` 分割各项
3. 单元格引用识别：首字符为大写字母
