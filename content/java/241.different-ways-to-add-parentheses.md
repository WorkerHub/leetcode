## 题目描述

给你一个由数字和运算符组成的字符串 `expression`，按不同优先级组合数字和运算符，计算并返回所有可能组合的结果。你可以按任意顺序返回答案。

生成的测试用例满足其对应输出值符合 32 位整数范围，不同结果的数量不超过 10^4。

**示例 1：**
```
输入：expression = "2-1-1"
输出：[0,2]
解释：
((2-1)-1) = 0 
(2-(1-1)) = 2
```

**示例 2：**
```
输入：expression = "2*3-4*5"
输出：[-34,-14,-10,-10,10]
解释：
(2*(3-(4*5))) = -34 
((2*3)-(4*5)) = -14 
((2*(3-4))*5) = -10 
(2*((3-4)*5)) = -10 
(((2*3)-4)*5) = 10
```

**提示：**
- 1 <= expression.length <= 20
- expression 由数字和算符 '+'、'-' 和 '*' 组成
- 输入表达式中的所有整数值在范围 [0, 99] 

## 解题思路

这是一道经典的**分治算法**题目，核心思想是：

1. **分治的本质**：遇到运算符就将表达式分成左右两部分，分别递归计算
2. **递归终止条件**：当表达式中没有运算符时，说明是纯数字，直接返回
3. **合并结果**：左右两部分的所有可能结果进行运算符操作，得到当前的所有可能结果

**关键观察：**
- 每个运算符都可以作为"最后一个计算的运算符"
- 以某个运算符为界，左边表达式的所有结果 × 右边表达式的所有结果 = 当前的所有结果
- 这是一个标准的分治问题，类似于表达式求值的所有可能

**优化思路：**
- 使用记忆化搜索避免重复计算相同的子表达式
- 用哈希表存储已计算过的表达式结果

## Java 代码实现

### 方法一：分治 + 递归（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<Integer> diffWaysToCompute(String expression) {
        // 如果表达式是纯数字，直接返回
        if (!expression.contains("+") && !expression.contains("-") && !expression.contains("*")) {
            return Arrays.asList(Integer.parseInt(expression));
        }
        
        List<Integer> result = new ArrayList<>();
        
        // 遍历表达式，遇到运算符就分治
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            if (c == '+' || c == '-' || c == '*') {
                // 分治：递归计算左边部分的所有可能结果
                List<Integer> left = diffWaysToCompute(expression.substring(0, i));
                // 分治：递归计算右边部分的所有可能结果
                List<Integer> right = diffWaysToCompute(expression.substring(i + 1));
                
                // 合并：左边的每个结果与右边的每个结果进行运算
                for (int l : left) {
                    for (int r : right) {
                        if (c == '+') {
                            result.add(l + r);
                        } else if (c == '-') {
                            result.add(l - r);
                        } else {
                            result.add(l * r);
                        }
                    }
                }
            }
        }
        
        return result;
    }
}
```

### 方法二：分治 + 记忆化搜索（优化版）⭐

```java
import java.util.*;

class Solution {
    // 记忆化哈希表：表达式 -> 所有可能结果
    private Map<String, List<Integer>> memo = new HashMap<>();
    
    public List<Integer> diffWaysToCompute(String expression) {
        return helper(expression);
    }
    
    private List<Integer> helper(String expression) {
        // 如果已经计算过，直接返回
        if (memo.containsKey(expression)) {
            return memo.get(expression);
        }
        
        // 递归终止条件：纯数字
        if (!expression.contains("+") && !expression.contains("-") && !expression.contains("*")) {
            return Arrays.asList(Integer.parseInt(expression));
        }
        
        List<Integer> result = new ArrayList<>();
        
        // 遍历表达式，以运算符为分界点
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            if (c == '+' || c == '-' || c == '*') {
                // 递归计算左右两部分
                List<Integer> left = helper(expression.substring(0, i));
                List<Integer> right = helper(expression.substring(i + 1));
                
                // 合并结果
                for (int l : left) {
                    for (int r : right) {
                        if (c == '+') {
                            result.add(l + r);
                        } else if (c == '-') {
                            result.add(l - r);
                        } else {
                            result.add(l * r);
                        }
                    }
                }
            }
        }
        
        // 记忆化存储
        memo.put(expression, result);
        return result;
    }
}
```

### 方法三：动态规划（自底向上）

```java
import java.util.*;

class Solution {
    public List<Integer> diffWaysToCompute(String expression) {
        // 分离数字和运算符
        List<Integer> nums = new ArrayList<>();
        List<Character> ops = new ArrayList<>();
        
        int num = 0;
        for (char c : expression.toCharArray()) {
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else {
                nums.add(num);
                ops.add(c);
                num = 0;
            }
        }
        nums.add(num);
        
        int n = nums.size();
        // dp[i][j] 表示从第 i 个数到第 j 个数的所有可能结果
        List<Integer>[][] dp = new ArrayList[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                dp[i][j] = new ArrayList<>();
            }
        }
        
        // 初始化：单个数字
        for (int i = 0; i < n; i++) {
            dp[i][i].add(nums.get(i));
        }
        
        // 区间 DP：从小到大枚举区间长度
        for (int length = 2; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                
                // 枚举分割点（运算符位置）
                for (int k = i; k < j; k++) {
                    char op = ops.get(k);
                    for (int leftVal : dp[i][k]) {
                        for (int rightVal : dp[k + 1][j]) {
                            if (op == '+') {
                                dp[i][j].add(leftVal + rightVal);
                            } else if (op == '-') {
                                dp[i][j].add(leftVal - rightVal);
                            } else {
                                dp[i][j].add(leftVal * rightVal);
                            }
                        }
                    }
                }
            }
        }
        
        return dp[0][n - 1];
    }
}
```

## 复杂度分析

**方法一（分治递归）：**
- 时间复杂度：O(2^n)，其中 n 是表达式长度。最坏情况下每个运算符都会产生分支
- 空间复杂度：O(2^n)，递归调用栈和结果存储

**方法二（记忆化搜索）：**
- 时间复杂度：O(n * 2^n)，记忆化避免了大量重复计算
- 空间复杂度：O(n * 2^n)，memo 字典存储中间结果

**方法三（动态规划）：**
- 时间复杂度：O(n^3 * 2^n)
- 空间复杂度：O(n^2 * 2^n)

## 关键点总结

1. **分治思想**：遇到运算符就分成左右两部分，这是解决该题的核心
2. **递归终止条件**：当字符串是纯数字时，直接返回该数字
3. **结果合并**：左边所有结果 × 右边所有结果，进行对应运算符的计算
4. **记忆化优化**：使用哈希表存储已计算的子表达式结果，避免重复计算
5. **Java 技巧**：使用 `String.contains()` 判断是否包含运算符，`Integer.parseInt()` 转换数字

## 易错点

1. **字符串切割边界**：`substring(0, i)` 和 `substring(i+1)` 要正确分割
2. **数字识别**：表达式中可能有多位数，要正确解析
3. **运算符处理**：注意减法和乘法不满足交换律
4. **Java 数组泛型**：`List<Integer>[][]` 在 Java 中需要使用 `@SuppressWarnings("unchecked")` 或改用其他方式
5. **整数溢出**：题目保证了范围，但在实际应用中要注意
