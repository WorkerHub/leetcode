## 题目描述

给你一个**下标从 0 开始**的正整数数组 `w`，其中 `w[i]` 代表第 `i` 个下标的权重。

请你实现一个函数 `pickIndex`，它可以**随机地**从范围 `[0, w.length - 1]` 内（含 0 和 w.length - 1）选出并返回一个下标。选取下标 `i` 的概率为 `w[i] / sum(w)`。

## 解题思路

前缀和 + 二分查找。构造前缀和数组后，随机生成 [1, total] 范围内的数，用二分查找定位。

## Java 代码实现

```java
class Solution {
    private int[] prefixSum;
    private Random random;

    public Solution(int[] w) {
        prefixSum = new int[w.length];
        prefixSum[0] = w[0];
        for (int i = 1; i < w.length; i++) {
            prefixSum[i] = prefixSum[i - 1] + w[i];
        }
        random = new Random();
    }

    public int pickIndex() {
        int target = random.nextInt(prefixSum[prefixSum.length - 1]) + 1;
        // 二分查找第一个 >= target 的位置
        int left = 0, right = prefixSum.length - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            if (prefixSum[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```

## 复杂度分析

- **初始化**：O(n)
- **pickIndex**：O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀和**：将权重转化为区间
2. **二分查找**：快速定位目标区间
3. **随机数范围**：[1, total]，不是 [0, total-1]
