## 题目描述

给你一个不含前导零的二进制字符串 `s`，如果 `s` 中最多只含有一段连续的 `'1'`，返回 `true`；否则返回 `false`。

## 解题思路

因为字符串不含前导零（以 `'1'` 开头），若后续再出现 `'1'`，必然是经过了 `'0'` 之后，即存在子串 `"01"`。直接检查是否包含 `"01"` 即可。

## Java 代码实现

```java
class Solution {
    public boolean checkOnesSegment(String s) {
        // 若存在 "01"，说明 1 在 0 之后又出现，有至少两段 1
        return !s.contains("01");
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 不含前导零意味着字符串以 `'1'` 开头
2. 后续若再出现 `'1'`（经过某个 `'0'`），必然包含 `"01"` 子串
3. 检查 `"01"` 而非 `"10"`
