## 题目描述

给定一个循环数组 `nums`（`nums[nums.length - 1]` 的下一个元素是 `nums[0]`），返回 `nums` 中每个元素的下一个更大元素。

数字 `x` 的下一个更大的元素是按数组遍历顺序，这个数字之后的第一个比它更大的数，这意味着你应该循环地搜索它的下一个更大的数。如果不存在，则输出 `-1`。

**示例 1：**
```
输入：nums = [1,2,1]
输出：[2,-1,2]
解释：
第一个 1 的下一个更大的数是 2；
数字 2 找不到下一个更大的数； 
第二个 1 的下一个最大的数需要循环搜索，结果也是 2。
```

**示例 2：**
```
输入：nums = [1,2,3,4,3]
输出：[2,3,4,-1,4]
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这道题是 [496. Next Greater Element I](https://leetcode.com/problems/next-greater-element-i/) 的进阶版，增加了**循环数组**的特性。

### 核心思想：
1. 使用**单调栈**来高效找到下一个更大元素
2. 为了处理循环数组，可以**遍历两次数组**（或等价地遍历 `2n` 次）
3. 单调栈维护一个递减序列，栈中存储的是元素的索引

### 算法流程：
1. 初始化结果数组，默认值为 -1
2. 使用单调递减栈
3. 遍历数组两次（通过 `i % n` 实现循环）：
   - 当前元素大于栈顶元素时，栈顶元素找到了下一个更大元素
   - 弹出栈顶并更新结果
   - 将当前索引入栈
4. 返回结果数组

### 为什么遍历两次？
- 第一次遍历：处理正常的下一个更大元素
- 第二次遍历：处理循环回来的情况
- 注意：第二次遍历时只弹出，不再入栈（避免重复）

## Java 代码实现

### 方法一：单调栈 + 两次遍历（推荐）⭐

```java
import java.util.*;

class Solution {
    public int[] nextGreaterElements(int[] nums) {
        // 单调栈解法，遍历两次数组处理循环
        // 时间复杂度：O(n)，空间复杂度：O(n)
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);  // 初始化结果数组为 -1
        Deque<Integer> stack = new ArrayDeque<>();  // 单调递减栈，存储索引

        // 遍历两次数组
        for (int i = 0; i < 2 * n; i++) {
            // 当前元素（循环数组）
            int num = nums[i % n];

            // 当前元素大于栈顶元素时，栈顶找到了下一个更大元素
            while (!stack.isEmpty() && nums[stack.peek()] < num) {
                int idx = stack.pop();
                result[idx] = num;
            }

            // 只在第一次遍历时入栈，避免重复
            if (i < n) {
                stack.push(i);
            }
        }

        return result;
    }
}
```

### 方法二：单调栈优化版（更清晰的逻辑）

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        // 单调栈，明确区分两次遍历的目的
        // 时间复杂度：O(n)，空间复杂度：O(n)
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>();

        // 第一次遍历：正常处理
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                result[stack.pop()] = nums[i];
            }
            stack.push(i);
        }

        // 第二次遍历：处理循环部分（注意：第二次不入栈）
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                result[stack.pop()] = nums[i];
            }
        }

        return result;
    }
}
```

### 方法三：暴力解法（会超时，仅供理解）

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        // 暴力解法：对每个元素向后循环查找
        // 时间复杂度：O(n^2)，空间复杂度：O(1)
        int n = nums.length;
        int[] result = new int[n];

        for (int i = 0; i < n; i++) {
            result[i] = -1;
            // 向后查找 n 个元素（循环一圈）
            for (int j = 1; j < n; j++) {
                int nextIdx = (i + j) % n;
                if (nums[nextIdx] > nums[i]) {
                    result[i] = nums[nextIdx];
                    break;
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

### 方法一、二（单调栈）：
- **时间复杂度**：O(n)
  - 每个元素最多入栈、出栈各一次
  - 虽然遍历了 2n 次，但总操作数仍是 O(n)
- **空间复杂度**：O(n)，栈的大小最多为 n

### 方法三（暴力）：
- **时间复杂度**：O(n²)，每个元素最多查找 n 次
- **空间复杂度**：O(1)，不计结果数组

## 关键点总结

1. **单调栈模式**：栈维护递减序列，用于找下一个更大元素
2. **循环数组处理**：遍历 2n 次，通过 `i % n` 实现循环
3. **入栈时机**：只在第一次遍历时入栈，第二次只弹出
4. **栈存索引**：存储索引而非值，方便更新结果数组
5. **初始化为 -1**：未找到更大元素时的默认值

## 易错点

1. **重复入栈**：第二次遍历时不应该再入栈，会导致错误
2. **边界处理**：单元素数组返回 `[-1]`
3. **栈为空判断**：弹栈前要检查栈是否为空
4. **循环条件**：遍历到 `2 * n`，不是 `2 * n - 1`
5. **结果数组大小**：是 n，不是 2n

## 图解示例

以 `nums = [1,2,1]` 为例：

```
遍历过程：

i=0, num=1:
  栈为空，入栈 [0]
  result = [-1,-1,-1]

i=1, num=2:
  2 > nums[0]=1，弹出 0，result[0]=2
  入栈 [1]
  result = [2,-1,-1]

i=2, num=1:
  栈顶是 1，1 不大于 nums[1]=2
  入栈 [1,2]
  result = [2,-1,-1]

i=3 (第二次遍历), num=nums[0]=1:
  1 不大于 nums[2]=1，栈不变
  不入栈
  result = [2,-1,-1]

i=4, num=nums[1]=2:
  2 > nums[2]=1，弹出 2，result[2]=2
  不入栈
  result = [2,-1,2]

最终结果：[2,-1,2]
```
