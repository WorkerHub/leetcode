## 题目描述

给你一个整数 `n`，求恰由 `n` 个节点组成且节点值从 `1` 到 `n` 互不相同的二叉搜索树有多少种？

**示例 1：**
```
输入：n = 3
输出：5
解释：共有 5 种不同结构的二叉搜索树，节点值为 1 到 3
```

**示例 2：**
```
输入：n = 1
输出：1
```

**提示：**
- `1 <= n <= 19`

## 解题思路

这是一道经典的动态规划问题，也可以用数学方法（卡特兰数）求解。

### 核心思想

**动态规划思路：**

1. **定义状态**：`dp[i]` 表示 i 个节点能组成的不同二叉搜索树的个数

2. **关键观察**：对于 n 个节点，我们可以选择任意一个节点作为根节点（假设选择 j）：
   - 左子树有 `j-1` 个节点（值为 1 到 j-1）
   - 右子树有 `n-j` 个节点（值为 j+1 到 n）
   - 左右子树的组合数相乘即为以 j 为根的不同二叉搜索树个数

3. **状态转移方程**：
   ```
   dp[n] = sum(dp[i-1] * dp[n-i])  (i 从 1 到 n)
   ```

4. **初始状态**：
   - `dp[0] = 1`（空树算一种情况）
   - `dp[1] = 1`（一个节点只有一种结构）

**数学方法（卡特兰数）：**

这个问题的答案实际上是第 n 个卡特兰数（Catalan Number）：
```
C(n) = C(0)*C(n-1) + C(1)*C(n-2) + ... + C(n-1)*C(0)
```

也可以用公式直接计算：
```
C(n) = (2n)! / ((n+1)! * n!)
```

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int numTrees(int n) {
        // dp[i] 表示 i 个节点能组成的不同 BST 个数
        int[] dp = new int[n + 1];

        // 初始状态：空树和单节点树都是 1 种
        dp[0] = 1;
        dp[1] = 1;

        // 计算 2 到 n 个节点的情况
        for (int i = 2; i <= n; i++) {
            // 尝试每个节点作为根节点
            for (int j = 1; j <= i; j++) {
                // 左子树有 j-1 个节点，右子树有 i-j 个节点
                // 左右子树的组合数相乘
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }

        return dp[n];
    }
}
```

### 方法二：数学公式（卡特兰数）

```java
class Solution {
    public int numTrees(int n) {
        // 使用 long 防止中间计算溢出
        // C(n) = C(2n, n) / (n + 1)
        long result = 1;
        for (int i = 1; i <= n; i++) {
            // 逐步计算组合数 C(2n, n)
            result = result * (n + i) / i;
        }
        // 除以 (n + 1) 得到卡特兰数
        return (int) (result / (n + 1));
    }
}
```

### 方法三：递归 + 记忆化（便于理解）

```java
class Solution {
    private int[] memo;

    public int numTrees(int n) {
        memo = new int[n + 1];
        return helper(n);
    }

    // 计算 num 个节点能组成的 BST 个数
    private int helper(int num) {
        // 基本情况
        if (num <= 1) {
            return 1;
        }

        // 查询缓存
        if (memo[num] != 0) {
            return memo[num];
        }

        // 递归计算
        int count = 0;
        for (int i = 1; i <= num; i++) {
            // 以 i 为根，左子树 i-1 个节点，右子树 num-i 个节点
            int left = helper(i - 1);
            int right = helper(num - i);
            count += left * right;
        }

        // 缓存结果
        memo[num] = count;
        return count;
    }
}
```

## 复杂度分析

### 方法一：动态规划
- **时间复杂度**：O(n^2)
  - 外层循环 n 次，内层循环最多 n 次
- **空间复杂度**：O(n)
  - 需要 dp 数组存储中间结果

### 方法二：数学公式
- **时间复杂度**：O(n)
  - 只需一次循环计算组合数
- **空间复杂度**：O(1)
  - 只使用常数个变量

### 方法三：递归 + 记忆化
- **时间复杂度**：O(n^2)
  - 每个子问题只计算一次，共 n 个子问题，每个需要 O(n) 时间
- **空间复杂度**：O(n)
  - 递归栈和数组都最多存储 n 个元素

## 图解示例

以 n = 3 为例，展示如何计算：

```
n = 3 时，尝试每个节点作为根：

1. 根节点为 1：
   左子树：0 个节点 -> dp[0] = 1
   右子树：2 个节点 -> dp[2] = 2
   组合数：1 * 2 = 2

2. 根节点为 2：
   左子树：1 个节点 -> dp[1] = 1
   右子树：1 个节点 -> dp[1] = 1
   组合数：1 * 1 = 1

3. 根节点为 3：
   左子树：2 个节点 -> dp[2] = 2
   右子树：0 个节点 -> dp[0] = 1
   组合数：2 * 1 = 2

总计：2 + 1 + 2 = 5
```

具体的 5 种结构：
```
   1         1           2         3       3
    \         \         / \       /       /
     3         2       1   3     2       1
    /           \               /         \
   2             3             1           2
```

## 关键点总结

1. **动态规划的关键**：将问题分解为左右子树的组合问题
2. **状态定义清晰**：dp[i] 表示 i 个节点的 BST 个数
3. **卡特兰数**：这是卡特兰数的经典应用场景之一
4. **初始状态**：dp[0] = 1 很重要，空树算一种情况
5. **组合思想**：左右子树的不同组合需要相乘

## 易错点

1. **忘记 dp[0] = 1**
   - 空树必须初始化为 1，否则所有计算结果都会是 0

2. **混淆加法和乘法**
   - 不同根节点的方案数是相加（sum）
   - 左右子树的组合是相乘（multiply）

3. **数学公式整数溢出**
   - 使用 `long` 类型防止中间计算溢出
   - Java 中 int 的最大值约 21 亿，卡特兰数增长很快

4. **理解状态转移**
   - `dp[i]` 依赖于所有 `dp[j] * dp[i-j-1]`（j 从 0 到 i-1）
   - 必须按顺序从小到大计算
