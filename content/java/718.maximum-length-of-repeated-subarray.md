## 题目描述

给两个整数数组 `nums1` 和 `nums2`，返回 两个数组中 **公共的**、长度最长的子数组的长度。

**示例 1：**

```
输入：nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出：3
解释：长度最长的公共子数组是 [3,2,1]。
```

**示例 2：**

```
输入：nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出：5
```

**提示：**
- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 100`

## 解题思路

这是一道经典的最长公共子数组问题，类似于最长公共子序列，但要求元素必须连续。

**核心思想：动态规划**

`dp[i][j]` 表示以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度。

**状态转移：**
- 如果 `nums1[i-1] == nums2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = 0`（不连续则重新开始）

## Java 代码实现

### 方法一：二维 DP（推荐）⭐

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[][] dp = new int[m + 1][n + 1];
        int maxLen = 0;
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    maxLen = Math.max(maxLen, dp[i][j]);
                }
                // 不相等时 dp[i][j] = 0（默认值）
            }
        }
        
        return maxLen;
    }
}
```

### 方法二：空间优化（一维 DP）

```java
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[] dp = new int[n + 1];
        int maxLen = 0;
        
        for (int i = 1; i <= m; i++) {
            // 从后往前更新，避免覆盖
            for (int j = n; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                    maxLen = Math.max(maxLen, dp[j]);
                } else {
                    dp[j] = 0;
                }
            }
        }
        
        return maxLen;
    }
}
```

## 复杂度分析

### 二维 DP：
- **时间复杂度：** O(m × n)
- **空间复杂度：** O(m × n)

### 一维 DP：
- **时间复杂度：** O(m × n)
- **空间复杂度：** O(n)

## 关键点总结

1. **连续性**：子数组必须连续，不匹配时归零
2. **DP 定义**：以当前位置结尾的最长长度
3. **空间优化**：可以优化到 O(n)
4. **记录最大值**：在转移过程中记录全局最大值

## 易错点

1. **子数组 vs 子序列**：子数组必须连续
2. **DP 初始化**：边界为 0
3. **索引对应**：`dp[i][j]` 对应 `nums1[i-1]` 和 `nums2[j-1]`
4. **空间优化时的遍历方向**：要从后往前
