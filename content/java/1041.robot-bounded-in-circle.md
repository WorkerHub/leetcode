## 题目描述

机器人在原点面朝北，执行指令序列（G前进/L左转/R右转）并无限重复。判断机器人是否被困在循环中。

**示例：**
```
输入：instructions = "GGLLGG"
输出：true
```

## 解题思路

执行一次指令后，若回到原点或方向不朝北，则必定循环。方向改变意味着最多 4 次后回到原点。

## Java 代码实现

```java
class Solution {
    public boolean isRobotBounded(String instructions) {
        // 方向：0=北, 1=东, 2=南, 3=西
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int x = 0, y = 0;
        int dir = 0;

        for (char c : instructions.toCharArray()) {
            if (c == 'G') {
                x += dirs[dir][0];
                y += dirs[dir][1];
            } else if (c == 'L') {
                dir = (dir + 3) % 4;  // 左转
            } else {
                dir = (dir + 1) % 4;  // 右转
            }
        }

        // 回到原点 或 方向改变
        return (x == 0 && y == 0) || dir != 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **充要条件**：回到原点 或 方向不朝北
2. **方向改变的含义**：最多 4 次重复后形成闭合轨迹
3. **左转处理**：`(dir + 3) % 4` 等价于 `(dir - 1 + 4) % 4`
