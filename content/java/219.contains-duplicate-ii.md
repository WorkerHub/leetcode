## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在两个 **不同的索引** `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。如果存在，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1], k = 3
输出：true
```

**示例 2：**

```
输入：nums = [1,0,1,1], k = 1
输出：true
```

**示例 3：**

```
输入：nums = [1,2,3,1,2,3], k = 2
输出：false
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 解题思路

这是 [217. 存在重复元素](https://leetcode.com/problems/contains-duplicate/) 的进阶版，增加了索引距离的限制。

**核心思想：**

1. **哈希表存储索引**：记录每个值最近出现的索引
2. **滑动窗口**：维护大小为 k 的窗口，检查窗口内是否有重复
3. **距离检查**：找到重复元素时，检查索引差是否 <= k

**多种解法：**

1. **哈希表 + 索引**：记录每个值的最新索引，检查距离
2. **滑动窗口 + 集合**：维护大小为 k+1 的窗口，检查重复
3. **暴力法**：双循环检查（会超时）

## Java 代码实现

### 方法一：哈希表存储索引（推荐）⭐

```java
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        // 记录每个值最近出现的索引
        Map<Integer, Integer> indexMap = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            if (indexMap.containsKey(nums[i])) {
                // 检查索引距离
                if (i - indexMap.get(nums[i]) <= k) {
                    return true;
                }
            }
            // 更新最新索引（不管是否重复，都要更新为最新位置）
            indexMap.put(nums[i], i);
        }

        return false;
    }
}
```

### 方法二：滑动窗口 + 集合（经典解法）

```java
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        // 维护大小为 k 的滑动窗口
        Set<Integer> window = new HashSet<>();

        for (int i = 0; i < nums.length; i++) {
            // 窗口太大，移除最左边的元素
            if (i > k) {
                window.remove(nums[i - k - 1]);
            }

            // 检查窗口内是否有重复
            if (window.contains(nums[i])) {
                return true;
            }

            window.add(nums[i]);
        }

        return false;
    }
}
```

### 方法三：哈希表存储所有索引（过度设计）

```java
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        // 存储每个值的所有索引
        Map<Integer, List<Integer>> indexMap = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            indexMap.putIfAbsent(nums[i], new ArrayList<>());
            // 检查之前出现的索引
            for (int prevIndex : indexMap.get(nums[i])) {
                if (i - prevIndex <= k) {
                    return true;
                }
            }
            indexMap.get(nums[i]).add(i);
        }

        return false;
    }
}
```

### 方法四：暴力法（会超时，仅供理解）

```java
class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        // 双循环检查
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < Math.min(i + k + 1, n); j++) {
                if (nums[i] == nums[j]) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希表索引（方法一） | O(N) | O(N) | 最优解 |
| 滑动窗口（方法二） | O(N) | O(min(N, K)) | 空间更优 |
| 暴力法（方法四） | O(N × K) | O(1) | 会超时 |

**推荐：** 方法一（哈希表存储索引），代码简洁且性能最优

## 关键点总结

1. **哈希表优化**：将查找从 O(N) 降到 O(1)
2. **索引距离检查**：`i - j <= k`（因为遍历时 `i > j`，无需绝对值）
3. **滑动窗口思想**：维护固定大小的窗口，检查窗口内的重复
4. **空间优化**：滑动窗口最多存储 k 个元素
5. **提前返回**：找到满足条件的立即返回，无需遍历全部

## 易错点

1. **索引距离计算**：
   ```java
   // 正确：i 总是大于之前记录的索引
   if (i - indexMap.get(nums[i]) <= k)
   ```

2. **滑动窗口边界错误**：
   ```java
   // 错误：窗口大小不对
   if (i >= k) window.remove(nums[i - k]);
   // 正确：保持窗口大小为 k，从索引 k+1 开始移除
   if (i > k) window.remove(nums[i - k - 1]);
   ```

3. **更新索引时机**：
   ```java
   // 错误：先更新再检查（会用新索引覆盖旧的，检查时距离为 0）
   indexMap.put(nums[i], i);
   if (indexMap.containsKey(nums[i])) { ... }
   // 正确：先检查，再更新
   if (indexMap.containsKey(nums[i])) {
       if (i - indexMap.get(nums[i]) <= k) return true;
   }
   indexMap.put(nums[i], i);
   ```

4. **边界情况遗漏**：
   ```java
   // k = 0 时，要求相同索引，不可能
   // 数组长度为 1 时，不可能有两个不同索引
   ```

5. **Integer 装箱比较**：
   ```java
   // 错误：使用 == 比较 Integer 对象（值超出缓存范围时不可靠）
   indexMap.get(nums[i]) == i
   // 正确：使用 int 变量或调用 intValue()
   int prevIndex = indexMap.get(nums[i]);
   if (i - prevIndex <= k)
   ```
