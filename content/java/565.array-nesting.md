## 题目描述

索引从 0 开始长度为 N 的数组 A，包含 0 到 N - 1 的所有整数。找到最大的集合 S 并返回其大小，其中 `S[i] = {A[i], A[A[i]], A[A[A[i]]], ... }` 且遵守以下的规则。

假设选择索引为 i 的元素 A[i] 为 S 的第一个元素，S 的下一个元素应该是 A[A[i]]，之后是 A[A[A[i]]]... 以此类推，不断添加直到 S 出现重复的元素。

**示例 1：**
```
输入：A = [5,4,0,3,1,6,2]
输出：4
解释：
A[0] = 5, A[1] = 4, A[2] = 0, A[3] = 3, A[4] = 1, A[5] = 6, A[6] = 2.

其中一种最长的 S[K]:
S[0] = {A[0], A[5], A[6], A[2]} = {5, 6, 2, 0}
```

**提示：**
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] < nums.length`
- `nums` 中的所有值都是唯一的

## 解题思路

这是一道图论+环检测的问题。数组构成了一个函数图，每个索引指向另一个索引，最终会形成环。

核心思想：
- 从每个未访问的点出发，沿着链走，记录环的长度
- 使用标记数组避免重复访问

## Java 代码实现

### 方法一：DFS + 标记（推荐）⭐

```java
class Solution {
    public int arrayNesting(int[] nums) {
        // DFS 找最长环
        int n = nums.length;
        boolean[] visited = new boolean[n];
        int maxLength = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                int length = 0;
                int current = i;
                // 沿着链走，直到回到已访问的节点
                while (!visited[current]) {
                    visited[current] = true;
                    current = nums[current];
                    length++;
                }
                maxLength = Math.max(maxLength, length);
            }
        }

        return maxLength;
    }
}
```

### 方法二：原地标记（空间优化）

```java
class Solution {
    public int arrayNesting(int[] nums) {
        // 原地标记，不使用额外空间
        int maxLength = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != -1) {
                int length = 0;
                int current = i;
                while (nums[current] != -1) {
                    int nextIndex = nums[current];
                    nums[current] = -1;  // 标记为已访问
                    current = nextIndex;
                    length++;
                }
                maxLength = Math.max(maxLength, length);
            }
        }

        return maxLength;
    }
}
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(n)，每个元素访问一次
- **空间复杂度**：O(n)，visited 数组

**方法二：**
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，原地标记

## 关键点总结

1. **环的性质**：每个索引最终都会形成环
2. **一次遍历**：每个元素只访问一次
3. **原地标记**：可以修改原数组节省空间
4. **图论思想**：数组构成函数图
