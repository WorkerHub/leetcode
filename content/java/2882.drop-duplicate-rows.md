## 题目描述

给定 DataFrame customers，删除 email 列中重复的行，保留第一次出现的行。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.drop_duplicates(subset='email', keep='first')`。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.drop_duplicates(subset='email', keep='first')

import java.util.*;

class Solution {
    // Java 中用 LinkedHashSet 保留首次出现、去除重复的 email
    public List<String[]> dropDuplicateEmails(List<String[]> customers) {
        // customers[i] = [id, name, email]
        Set<String> seen = new LinkedHashSet<>();
        List<String[]> result = new ArrayList<>();
        for (String[] row : customers) {
            if (seen.add(row[2])) { // email 是第 3 列
                result.add(row);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `drop_duplicates(subset=col, keep='first')` 按指定列去重，保留首次出现
2. `keep='last'` 保留最后一次，`keep=False` 删除所有重复行
3. Java 中可用 LinkedHashSet 保持插入顺序并去重
