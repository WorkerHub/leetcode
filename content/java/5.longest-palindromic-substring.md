## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**示例 1：**
```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案
```

**示例 2：**
```
输入：s = "cbbd"
输出："bb"
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 解题思路

**方法对比：**
1. **中心扩展**：从每个位置向两边扩展（推荐）
2. **动态规划**：dp[i][j] 表示 s[i:j+1] 是否为回文
3. **Manacher算法**：线性时间复杂度

## Java 代码实现

### 方法一：中心扩展（推荐）

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 1) return "";
        
        int start = 0, maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度回文
            int len1 = expandAroundCenter(s, i, i);
            // 偶数长度回文
            int len2 = expandAroundCenter(s, i, i + 1);
            
            int len = Math.max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }
        
        return s.substring(start, start + maxLen);
    }
    
    private int expandAroundCenter(String s, int left, int right) {
        // 从中心向两边扩展
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

### 方法二：动态规划

```java
class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) return s;
        
        // dp[i][j] 表示 s[i..j] 是否为回文
        boolean[][] dp = new boolean[n][n];
        int start = 0, maxLen = 1;
        
        // 单个字符都是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }
        
        // 从长度 2 开始
        for (int length = 2; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                
                if (s.charAt(i) == s.charAt(j)) {
                    if (length == 2) {
                        dp[i][j] = true;
                    } else {
                        dp[i][j] = dp[i + 1][j - 1];
                    }
                }
                
                if (dp[i][j] && length > maxLen) {
                    start = i;
                    maxLen = length;
                }
            }
        }
        
        return s.substring(start, start + maxLen);
    }
}
```

## 复杂度分析

**方法一（中心扩展）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(1)

**方法二（动态规划）：**
- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. **中心扩展**：考虑奇数和偶数两种情况
2. **动态规划**：状态转移 dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]
3. **边界处理**：单字符和双字符

## 易错点

1. **奇偶情况**：回文串有奇数和偶数长度两种
2. **索引计算**：扩展后的起始位置计算 `start = i - (len - 1) / 2`
