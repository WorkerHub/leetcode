## 题目描述

给定整数数组和阈值 threshold，选正整数除数，每个数除以它向上取整后求和 ≤ threshold。求最小除数。

**示例：**
```
输入：nums = [1,2,5,9], threshold = 6
输出：5
```

## 解题思路

二分查找答案：除数越大，和越小。二分搜索最小的满足条件的除数。

## Java 代码实现

```java
class Solution {
    public int smallestDivisor(int[] nums, int threshold) {
        int lo = 1, hi = 1_000_000;
        
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (computeSum(nums, mid) <= threshold) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
    
    private int computeSum(int[] nums, int divisor) {
        int sum = 0;
        for (int num : nums) {
            sum += (num + divisor - 1) / divisor; // 向上取整
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(max))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：搜索范围 [1, max(nums)]
2. **单调性**：除数越大，和越小
3. **向上取整**：(a + b - 1) / b
4. **左端点**：找第一个满足条件的
