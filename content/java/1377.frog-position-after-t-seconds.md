## 题目描述

给你一棵有 n 个顶点的无向树，青蛙从顶点 1 出发，每秒随机跳到一个未访问的相邻顶点，若无则停留原地。返回 t 秒后恰好在顶点 target 上的概率。

## 解题思路

无向树上 DFS，排除父节点后每个节点的邻居即为子节点。到达 target 时：若时间恰好用完或 target 为叶子节点（无处可跳），返回当前概率；否则青蛙会继续跳走，返回 0。每步概率均分给各子节点。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private double ans = 0.0;

    public double frogPosition(int n, int[][] edges, int t, int target) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        dfs(graph, 1, 0, t, target, 1.0);
        return ans;
    }

    private void dfs(List<List<Integer>> graph, int node, int parent, int time, int target, double prob) {
        // 找未访问邻居（子节点）
        List<Integer> children = new ArrayList<>();
        for (int nb : graph.get(node)) {
            if (nb != parent) children.add(nb);
        }

        if (node == target) {
            // 到达目标：时间用完 或 无子节点（停留）
            if (time == 0 || children.isEmpty()) {
                ans = prob;
            }
            return;
        }

        // 时间用完或叶子节点（非目标），停止搜索
        if (time == 0 || children.isEmpty()) return;

        // 等概率跳向每个子节点
        double nextProb = prob / children.size();
        for (int child : children) {
            dfs(graph, child, node, time - 1, target, nextProb);
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点最多访问一次（树上路径唯一）。
- 空间复杂度：O(n)，邻接表和递归栈。

## 关键点总结

1. 无向树 DFS 时排除父节点，剩余邻居即为子节点，无需额外 visited 集合。
2. 到达 target 时需判断两种停留情况：时间恰好用完，或 target 是叶子节点。
3. 树上路径唯一，找到 target 后可立即返回，无需搜索其他分支。
