## 题目描述

给你 BST 根节点 `root` 和查询数组 `queries`，对每个查询返回树中不超过该值的最大值和不小于该值的最小值（不存在时返回 -1）。

## 解题思路

中序遍历 BST 得到有序数组，对每个查询用二分查找分别找 `<= q` 的最大值和 `>= q` 的最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<List<Integer>> closestNodes(TreeNode root, List<Integer> queries) {
        // 中序遍历得到有序数组
        List<Integer> sorted = new ArrayList<>();
        inorder(root, sorted);
        int[] arr = sorted.stream().mapToInt(Integer::intValue).toArray();

        List<List<Integer>> ans = new ArrayList<>();
        for (int q : queries) {
            // 找 <= q 的最大值（upper_bound - 1）
            int lo = 0, hi = arr.length - 1, mini = -1;
            while (lo <= hi) {
                int mid = (lo + hi) >>> 1;
                if (arr[mid] <= q) { mini = arr[mid]; lo = mid + 1; }
                else hi = mid - 1;
            }
            // 找 >= q 的最小值（lower_bound）
            lo = 0; hi = arr.length - 1;
            int maxi = -1;
            while (lo <= hi) {
                int mid = (lo + hi) >>> 1;
                if (arr[mid] >= q) { maxi = arr[mid]; hi = mid - 1; }
                else lo = mid + 1;
            }
            ans.add(Arrays.asList(mini, maxi));
        }
        return ans;
    }

    private void inorder(TreeNode node, List<Integer> list) {
        if (node == null) return;
        inorder(node.left, list);
        list.add(node.val);
        inorder(node.right, list);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q log n)
- **空间复杂度**：O(n)

## 关键点总结

1. BST 中序遍历结果有序，适合二分查找
2. 二分找最大的 `<= q`：向右收缩直到不满足
3. 二分找最小的 `>= q`：向左收缩直到不满足
