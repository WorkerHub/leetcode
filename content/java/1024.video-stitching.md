## 题目描述

给定视频片段数组 clips（每个片段有起止时间），返回覆盖 [0, time] 所需的最少片段数，不可能则返回 -1。

**示例：**
```
输入：clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]], time = 10
输出：3
```

## 解题思路

贪心：排序后，在当前已覆盖范围内选择能延伸最远的片段。类似跳跃游戏。

## Java 代码实现

```java
class Solution {
    public int videoStitching(int[][] clips, int time) {
        Arrays.sort(clips, (a, b) -> a[0] - b[0]);

        int count = 0, curEnd = 0, nextEnd = 0;
        int i = 0;

        while (curEnd < time) {
            // 在 curEnd 范围内找延伸最远的片段
            while (i < clips.length && clips[i][0] <= curEnd) {
                nextEnd = Math.max(nextEnd, clips[i][1]);
                i++;
            }

            if (nextEnd == curEnd) return -1;

            curEnd = nextEnd;
            count++;
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **贪心选择**：每次选能延伸最远的片段
2. **排序预处理**：按起始位置排序
3. **无解判断**：nextEnd == curEnd 时无法继续
