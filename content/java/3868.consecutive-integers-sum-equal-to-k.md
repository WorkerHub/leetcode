## 题目描述

给你一个正整数 `k`，返回将 `k` 表示为若干连续正整数之和的方案数。

## 解题思路

设从 `a` 开始的 `n` 个连续正整数之和为 k，则 `n*a + n*(n-1)/2 = k`，推出 `a = (k - n*(n-1)/2) / n`。枚举 n，条件为 `n*(n-1)/2 < k` 且余数能被 n 整除（保证 a 为正整数）。

## Java 代码实现

```java
class Solution {
    public int consecutiveNumbersSum(int k) {
        int count = 0;
        int n = 1;
        // n*(n-1)/2 < k 保证起始值 a >= 1
        while (n * (n - 1) / 2 < k) {
            int remainder = k - n * (n - 1) / 2;
            // remainder 能被 n 整除，则起始值 a 为正整数
            if (remainder % n == 0) count++;
            n++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(sqrt(k))，n 最大约为 sqrt(2k)
- 空间复杂度：O(1)

## 关键点总结

1. 设连续段长度为 n，起始值为 a，由 `n*a + n*(n-1)/2 = k` 求 a。
2. n 的上界约为 sqrt(2k)，枚举 n 即可。
3. 条件：`k - n*(n-1)/2` 为正数且能被 n 整除。
