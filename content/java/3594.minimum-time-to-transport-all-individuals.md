## 题目描述

有 `n` 人（`n <= 20`）需要用船从一岸运到另一岸，每次最多运 `k` 人，去程花费组中最慢者的时间，若未全部运完需选一人返回，求最少总时间。

## Java 代码实现

```java
class Solution {
    public int minimumTime(int n, int k, int[][] time) {
        // time[i] = [forward, backward] 表示第 i 人的去程和返程时间
        int full = (1 << n) - 1;
        int[] dp = new int[full + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int mask = 0; mask < full; mask++) {
            if (dp[mask] == Integer.MAX_VALUE / 2) continue;
            int remaining = full ^ mask;

            // 枚举 remaining 的所有非空子集，大小 <= k
            for (int sub = remaining; sub > 0; sub = (sub - 1) & remaining) {
                if (Integer.bitCount(sub) > k) {
                    if (sub == 0) break;
                    continue;
                }
                // 去程花费：组中最慢者
                int fwd = 0;
                for (int i = 0; i < n; i++) {
                    if ((sub >> i & 1) == 1) fwd = Math.max(fwd, time[i][0]);
                }
                int newMask = mask | sub;
                if (newMask == full) {
                    dp[full] = Math.min(dp[full], dp[mask] + fwd);
                } else {
                    // 返程：从 newMask 中选最快的一人返回
                    int bwd = Integer.MAX_VALUE;
                    for (int i = 0; i < n; i++) {
                        if ((newMask >> i & 1) == 1) bwd = Math.min(bwd, time[i][1]);
                    }
                    dp[newMask] = Math.min(dp[newMask], dp[mask] + fwd + bwd);
                }
            }
        }
        return dp[full];
    }
}
```

## 复杂度分析

- 时间复杂度：O(3^n * n)，枚举所有子集的子集
- 空间复杂度：O(2^n)

## 关键点总结

1. 状态 `dp[mask]` = 将 mask 对应人运到对岸的最少时间
2. 去程选 <= k 人，花费最慢者时间；返程选已过河者中最快的
3. 最后一组无需返程（全部运完后 `newMask == full`）
