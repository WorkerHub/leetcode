## 题目描述

给你由空格分隔的单词组成的字符串 `sentence`，判断是否为循环句（相邻单词首尾字母相同，且首尾单词形成循环）。

## 解题思路

直接在原字符串中检查：首尾字符相同，且每个空格前后字符相同。

## Java 代码实现

```java
class Solution {
    public boolean isCircularSentence(String sentence) {
        int n = sentence.length();
        // 检查首尾字符
        if (sentence.charAt(0) != sentence.charAt(n - 1)) return false;
        // 检查每个空格前后字符
        for (int i = 1; i < n - 1; i++) {
            if (sentence.charAt(i) == ' ' && sentence.charAt(i - 1) != sentence.charAt(i + 1))
                return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 循环条件等价于：首尾字符相同，且每个空格前后字符相同
2. 无需分割单词，直接在原字符串上一次扫描即可
