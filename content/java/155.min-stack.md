## 题目描述

设计一个支持 `push`，`pop`，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象
- `void push(int val)` 将元素 `val` 推入堆栈
- `void pop()` 删除堆栈顶部的元素
- `int top()` 获取堆栈顶部的元素
- `int getMin()` 获取堆栈中的最小元素

**示例：**

```
输入:
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出:
[null,null,null,null,-3,null,0,-2]

解释:
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
```

**提示：**

- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top` 和 `getMin` 操作总是在非空栈上调用
- `push`、`pop`、`top` 和 `getMin` 最多被调用 `3 * 10^4` 次

## 解题思路

要实现 O(1) 时间获取最小值，关键是在每次 push 和 pop 时维护最小值信息。

**核心问题：**

- 普通栈可以 O(1) 完成 push、pop、top
- 但获取最小值需要遍历，O(n)
- 如何优化到 O(1)？

**解决方案：**

使用辅助栈，同步记录每个状态下的最小值。

**方法对比：**

| 方法 | 空间复杂度 | 实现难度 | 推荐度 |
|------|-----------|---------|--------|
| 双栈法 | O(n) | 简单 | ★★★★★ |
| 单栈法（存差值） | O(n) | 中等 | ★★★ |
| 链表法 | O(n) | 简单 | ★★★★ |

## Java 代码实现

### 方法一：双栈法（推荐）

```java
class MinStack {
    // stack: 存储所有元素
    // minStack: 存储每个状态下的最小值
    private Deque<Integer> stack;
    private Deque<Integer> minStack;

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);

        // 更新最小值栈
        if (minStack.isEmpty()) {
            minStack.push(val);
        } else {
            // 新的最小值是 val 和当前最小值的较小者
            minStack.push(Math.min(val, minStack.peek()));
        }
    }

    public void pop() {
        stack.pop();
        minStack.pop();
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

### 方法二：优化的双栈法（减少空间）

```java
class MinStack {
    // 优化：minStack 只在必要时压入
    private Deque<Integer> stack;
    private Deque<Integer> minStack;

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);

        // 只有当 val <= 当前最小值时，才压入 minStack
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        int val = stack.pop();

        // 如果弹出的是最小值，也要从 minStack 弹出
        if (val == minStack.peek()) {
            minStack.pop();
        }
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

### 方法三：单栈法（存储差值）

```java
class MinStack {
    // 只用一个栈，存储元素与最小值的差值
    // 注意：差值可能溢出，需要用 long
    private Deque<Long> stack;
    private long minVal;

    public MinStack() {
        stack = new ArrayDeque<>();
    }

    public void push(int val) {
        if (stack.isEmpty()) {
            stack.push(0L); // 第一个元素，差值为 0
            minVal = val;
        } else {
            // 存储差值（可能溢出，用 long）
            long diff = (long) val - minVal;
            stack.push(diff);

            // 如果新值更小，更新最小值
            if (val < minVal) {
                minVal = val;
            }
        }
    }

    public void pop() {
        long diff = stack.pop();

        // 如果差值 < 0，说明弹出的是最小值
        // 需要恢复之前的最小值
        if (diff < 0) {
            minVal = minVal - diff;
        }
    }

    public int top() {
        long diff = stack.peek();

        // 如果差值 < 0，栈顶是当前最小值
        if (diff < 0) {
            return (int) minVal;
        } else {
            return (int) (minVal + diff);
        }
    }

    public int getMin() {
        return (int) minVal;
    }
}
```

### 方法四：链表实现

```java
class MinStack {
    // 链表节点，每个节点存储值和当前最小值
    private static class Node {
        int val;
        int minVal;
        Node next;

        Node(int val, int minVal, Node next) {
            this.val = val;
            this.minVal = minVal;
            this.next = next;
        }
    }

    private Node head;

    public MinStack() {
        head = null;
    }

    public void push(int val) {
        if (head == null) {
            head = new Node(val, val, null);
        } else {
            // 新节点的最小值是 val 和之前最小值的较小者
            int minVal = Math.min(val, head.minVal);
            head = new Node(val, minVal, head);
        }
    }

    public void pop() {
        head = head.next;
    }

    public int top() {
        return head.val;
    }

    public int getMin() {
        return head.minVal;
    }
}
```

### 方法五：使用数组对（简化版双栈）

```java
class MinStack {
    // 栈中每个元素存储 [值, 当前最小值] 的数组
    private Deque<int[]> stack;

    public MinStack() {
        stack = new ArrayDeque<>();
    }

    public void push(int val) {
        if (stack.isEmpty()) {
            stack.push(new int[]{val, val});
        } else {
            int currentMin = Math.min(val, stack.peek()[1]);
            stack.push(new int[]{val, currentMin});
        }
    }

    public void pop() {
        stack.pop();
    }

    public int top() {
        return stack.peek()[0];
    }

    public int getMin() {
        return stack.peek()[1];
    }
}
```

## 复杂度分析

**所有方法的时间复杂度：**

- `push`: O(1)
- `pop`: O(1)
- `top`: O(1)
- `getMin`: O(1)

**空间复杂度：**

- 方法一：O(n) - 两个栈都存储 n 个元素
- 方法二：O(n) - minStack 最多存储 n 个元素，但平均会少一些
- 方法三：O(n) - 一个栈 + 一个变量
- 方法四：O(n) - 链表存储 n 个节点
- 方法五：O(n) - 栈存储 n 个数组对

## 图解示例

以方法一（双栈法）为例：

```
操作序列: push(-2), push(0), push(-3), getMin(), pop(), top(), getMin()

push(-2):
stack:     [-2]
minStack: [-2]

push(0):
stack:     [-2, 0]
minStack: [-2, -2]  # min(-2, 0) = -2

push(-3):
stack:     [-2, 0, -3]
minStack: [-2, -2, -3]  # min(-2, -3) = -3

getMin():
返回 minStack.peek() = -3

pop():
stack:     [-2, 0]
minStack: [-2, -2]

top():
返回 stack.peek() = 0

getMin():
返回 minStack.peek() = -2
```

方法二（优化双栈）的区别：

```
push(-2):
stack:     [-2]
minStack: [-2]  # -2 <= min (空), 压入

push(0):
stack:     [-2, 0]
minStack: [-2]  # 0 > -2, 不压入

push(-3):
stack:     [-2, 0, -3]
minStack: [-2, -3]  # -3 <= -2, 压入

pop():  # 弹出 -3
stack:     [-2, 0]
minStack: [-2]  # -3 == minStack.peek(), 也弹出
```

## 关键点总结

1. **双栈思想**：
   - 主栈存储所有元素
   - 辅助栈存储每个状态的最小值
   - 两个栈同步操作

2. **空间优化**：
   - 方法二：只在必要时压入 minStack
   - 减少空间，但逻辑稍复杂

3. **单栈技巧**：
   - 存储差值而不是原值
   - 注意 Java 中差值可能溢出，需要用 `long`

4. **链表实现**：
   - 每个节点存储当前状态的最小值
   - 不需要额外的辅助栈

5. **Java 中用 Deque 代替 Stack**：
   - Java 中推荐用 `ArrayDeque` 代替 `Stack`
   - `Stack` 是遗留类，性能较差

## 易错点

1. **方法二的 pop 操作**：
   - 必须判断弹出的元素是否是最小值
   - 如果是，minStack 也要弹出

2. **方法二的 push 条件**：
   - 是 `val <= minStack.peek()`，不是 `val < minStack.peek()`
   - 因为可能有重复的最小值

3. **方法三的溢出问题**：
   - 差值 `val - minVal` 可能溢出 `int`
   - 必须使用 `long` 存储差值

4. **空栈判断**：
   - `getMin()` 前要确保栈非空
   - 题目保证了这一点，但实际使用要注意

5. **Java 的 Deque 方向**：
   - `push` 和 `pop` 操作栈顶（头部）
   - `peek` 查看栈顶（头部）
