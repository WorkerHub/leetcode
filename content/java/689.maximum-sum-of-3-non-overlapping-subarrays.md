## 题目描述

找出三个长度为 k 且不重叠的子数组，使和最大。返回起始索引（字典序最小）。

**示例：**
```
输入：nums = [1,2,1,2,6,7,5,1], k = 2
输出：[0,3,5]
```

## 解题思路

预计算所有长度为 k 的子数组和，用辅助数组 left[i] 和 right[i] 分别记录 [0,i] 和 [i,end] 范围内最大和的起始索引，枚举中间子数组位置。

## Java 代码实现

```java
class Solution {
    public int[] maxSumOfThreeSubarrays(int[] nums, int k) {
        int n = nums.length;
        int count = n - k + 1;

        // 计算所有长度为 k 的子数组和
        int[] sums = new int[count];
        int windowSum = 0;
        for (int i = 0; i < k; i++) windowSum += nums[i];
        sums[0] = windowSum;
        for (int i = k; i < n; i++) {
            windowSum += nums[i] - nums[i - k];
            sums[i - k + 1] = windowSum;
        }

        // left[i]: [0, i] 范围内最大和的起始索引
        int[] left = new int[count];
        int best = 0;
        for (int i = 0; i < count; i++) {
            if (sums[i] > sums[best]) best = i;
            left[i] = best;
        }

        // right[i]: [i, count-1] 范围内最大和的起始索引
        int[] right = new int[count];
        best = count - 1;
        for (int i = count - 1; i >= 0; i--) {
            if (sums[i] >= sums[best]) best = i;
            right[i] = best;
        }

        // 枚举中间子数组位置
        int[] result = {-1, -1, -1};
        int maxSum = 0;
        for (int j = k; j < count - k; j++) {
            int i = left[j - k], l = right[j + k];
            int total = sums[i] + sums[j] + sums[l];
            if (total > maxSum) {
                maxSum = total;
                result = new int[]{i, j, l};
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **预计算子数组和**：滑动窗口求所有长度 k 的子数组和
2. **左右最优辅助数组**：快速查询区间内最优位置
3. **字典序最小**：left 用 >，right 用 >=
