## 题目描述

给你一个 rows x cols 的屏幕和一个用非空的单词列表组成的句子，请你计算出给定句子可以在屏幕上完整显示的次数。

注意：
1. 一个单词不能拆分成两行
2. 单词在句子中的顺序必须保持不变
3. 在一行中的两个连续单词必须用一个空格符分隔
4. 句子中的单词总量不会超过 100
5. 每个单词的长度大于 0 且不会超过 10
6. 1 ≤ rows, cols ≤ 20,000

**示例：**
```
输入：rows = 2, cols = 8, sentence = ["hello", "world"]
输出：1
解释：
hello---
world---
字符 '-' 表示空白
```

## 解题思路

核心思路：
1. 将句子拼接成一个长字符串（单词之间加空格）
2. 模拟填充过程，记录每行的起始位置
3. 使用记忆化避免重复计算

## Java 代码实现

### 方法一：模拟 + 记忆化

```java
import java.util.*;

class Solution {
    public int wordsTyping(String[] sentence, int rows, int cols) {
        // 拼接句子，末尾加空格方便处理
        String s = String.join(" ", sentence) + " ";
        int length = s.length();

        // 记录每个起始位置完成的句子次数及下一个起始位置
        Map<Integer, int[]> memo = new HashMap<>();
        int count = 0;
        int pos = 0;  // 当前在拼接句子中的位置

        for (int row = 0; row < rows; row++) {
            if (memo.containsKey(pos)) {
                // 使用缓存，直接跳过计算
                count += memo.get(pos)[0];
                pos = memo.get(pos)[1];
            } else {
                int start = pos;
                // 这一行能放 cols 个字符
                pos += cols;

                // 如果当前字符不是空格，向前回退找到上一个空格
                while (pos < length && s.charAt(pos) != ' ') {
                    pos--;
                }

                // 跳过空格，指向下一个单词起始
                pos++;

                // 计算完成了多少次完整的句子
                int times = pos / length;
                count += times;
                pos %= length;

                // 缓存本次结果
                memo.put(start, new int[]{times, pos});
            }
        }

        return count;
    }
}
```

### 方法二：优化版

```java
class Solution {
    public int wordsTyping(String[] sentence, int rows, int cols) {
        // 优化的模拟，用取模处理循环句子
        String s = String.join(" ", sentence) + " ";
        int length = s.length();
        int pos = 0;

        for (int i = 0; i < rows; i++) {
            pos += cols;

            // 如果落在空格上，前进一位（新行从下一个单词开始）
            if (s.charAt(pos % length) == ' ') {
                pos++;
            } else {
                // 当前落在单词中间，回退到上一个空格
                while (pos > 0 && s.charAt((pos - 1) % length) != ' ') {
                    pos--;
                }
            }
        }

        // pos / length 即完整循环的次数
        return pos / length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(rows)
- **空间复杂度**：O(length)

## 关键点总结

1. 拼接句子为字符串
2. 模拟填充过程
3. 使用取模处理循环
4. 记忆化优化

## 易错点

1. 忘记处理单词之间的空格
2. 边界条件处理错误
