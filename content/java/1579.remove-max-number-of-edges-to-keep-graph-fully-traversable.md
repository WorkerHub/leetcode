## 题目描述

三种边（Alice专用、Bob专用、共用），在保证两人都能遍历整图前提下，移除最多边数。

**提示：** n ≤ 10^5

## 解题思路

双并查集贪心：优先加类型3边（最高效），再分别加类型1/2。冗余边可移除。

## Java 代码实现

```java
class Solution {
    public int maxNumEdgesToRemove(int n, int[][] edges) {
        int[] parentA = new int[n + 1], rankA = new int[n + 1];
        int[] parentB = new int[n + 1], rankB = new int[n + 1];
        for (int i = 0; i <= n; i++) { parentA[i] = i; parentB[i] = i; }
        int compA = n, compB = n, removed = 0;
        
        // 优先处理类型 3
        for (int[] e : edges) {
            if (e[0] == 3) {
                boolean a = union(parentA, rankA, e[1], e[2]);
                boolean b = union(parentB, rankB, e[1], e[2]);
                if (a) compA--;
                if (b) compB--;
                if (!a && !b) removed++;
            }
        }
        // 处理类型 1 和 2
        for (int[] e : edges) {
            if (e[0] == 1) {
                if (union(parentA, rankA, e[1], e[2])) compA--;
                else removed++;
            } else if (e[0] == 2) {
                if (union(parentB, rankB, e[1], e[2])) compB--;
                else removed++;
            }
        }
        
        return (compA == 1 && compB == 1) ? removed : -1;
    }
    
    private int find(int[] parent, int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    
    private boolean union(int[] parent, int[] rank, int x, int y) {
        int px = find(parent, x), py = find(parent, y);
        if (px == py) return false;
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(E × α(N))
- **空间复杂度**：O(N)

## 关键点总结

1. **类型3优先**：一条边同时服务两人
2. **冗余判断**：对两个 DSU 都无贡献的边可移除
3. **连通性检查**：最终两个 DSU 都须只有 1 个连通分量
