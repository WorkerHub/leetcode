## 题目描述

给你一个整数数组 `nums`，找到其中两个元素使乘积最大或最小，返回 `[max_product, min_product]`。

## 解题思路

排序后只需考虑首尾两端：最大乘积来自两最大正数或两最小负数，最小乘积通常来自最小负数乘最大正数，枚举候选取极值即可。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maxAndMinProduct(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        // 候选：首首、尾尾、首尾
        long a = (long) nums[0] * nums[1];
        long b = (long) nums[n-1] * nums[n-2];
        long c = (long) nums[0] * nums[n-1];
        long maxP = Math.max(a, b);
        long minP = Math.min(Math.min(a, b), c);
        return new int[]{(int) maxP, (int) minP};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 最大乘积来自两最大正数或两最小负数（首首或尾尾）
2. 最小乘积通常来自最小负数乘最大正数（首尾）
3. 用 `long` 避免乘积溢出
