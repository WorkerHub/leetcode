## 题目描述

给定区间列表，删除被其他区间完全覆盖的区间，返回剩余区间数目。[a,b] 被 [c,d] 覆盖当且仅当 c<=a 且 b<=d。

**示例：**
```
输入：intervals = [[1,4],[3,6],[2,8]]
输出：2
解释：[3,6] 被 [2,8] 覆盖
```

## 解题思路

排序：按左端点升序，左端点相同按右端点降序。然后贪心扫描，维护当前最大右端点。

## Java 代码实现

```java
class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
        // 按左端点升序，左端点相同则右端点降序
        Arrays.sort(intervals, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);
        
        int count = 0;
        int maxRight = 0;
        
        for (int[] interval : intervals) {
            if (interval[1] > maxRight) {
                count++; // 未被覆盖
                maxRight = interval[1];
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序策略**：左升右降，保证同起点的大区间在前
2. **贪心扫描**：右端点 ≤ maxRight 则被覆盖
3. **计数未覆盖**：比计数被覆盖更简洁
