## 题目描述

给你一个整数 `num`，请你找出同时满足下面全部要求的两个整数：

- 两数乘积等于 `num + 1` 或 `num + 2`
- 以绝对差进行度量，两数大小最接近

请你以两个整数的形式返回这两个整数，如果存在多组满足题意的答案，任选其中一组均可。

**示例 1：**
```
输入：num = 8
输出：[3,3]
解释：
对于 num + 1 = 9，最近的因子对是 (3, 3)，绝对差为 0。
对于 num + 2 = 10，最近的因子对是 (2, 5)，绝对差为 3。
选 (3, 3)。
```

**示例 2：**
```
输入：num = 123
输出：[5,25]
解释：
num+1=124，最近因子对：4*31（差27），2*62（差60），...
num+2=125，最近因子对：5*25（差20），更接近。
```

**提示：**
- `1 <= num <= 10^9`

## 解题思路

对于一个正整数 `target`，找两个因子 `a` 和 `b` 使得 `a * b = target` 且 `|a - b|` 最小。

**关键观察：** 当 `a * b = target` 时，使 `|a - b|` 最小的 `a` 在 `sqrt(target)` 附近。

**算法：** 从 `a = floor(sqrt(target))` 开始向下枚举，找第一个能整除 `target` 的 `a`，对应 `b = target / a`，此时 `|a - b|` 最小。

对 `target = num+1` 和 `target = num+2` 分别找最优因子对，然后比较两组中哪组差更小。

**为什么从 sqrt 向下找？**

设 `a <= b`，则 `a <= sqrt(target) <= b`。当 `a` 越接近 `sqrt(target)` 时，`b = target/a` 也越接近 `sqrt(target)`，两者差越小。从 `floor(sqrt(target))` 开始向下，第一个整除 target 的 `a` 就是最优的 `a`。

## Java 代码实现

### 方法一：从 sqrt 向下枚举（推荐）

```java
class Solution {
    public int[] closestDivisors(int num) {
        int[] pair1 = bestPair(num + 1);
        int[] pair2 = bestPair(num + 2);
        
        // 选差的绝对值更小的那一对
        if (Math.abs(pair1[0] - pair1[1]) <= Math.abs(pair2[0] - pair2[1])) {
            return pair1;
        }
        return pair2;
    }
    
    // 找乘积为 target 的最接近因子对
    private int[] bestPair(int target) {
        // 从 sqrt(target) 开始向下找第一个因子
        int a = (int) Math.sqrt(target);
        while (a >= 1) {
            if (target % a == 0) {
                return new int[]{a, target / a};
            }
            a--;
        }
        return new int[]{1, target}; // 最坏情况（target 是质数）
    }
}
```

### 方法二：暴力枚举所有因子（思路更直接）

```java
class Solution {
    public int[] closestDivisors(int num) {
        int[] pair1 = bestPair(num + 1);
        int[] pair2 = bestPair(num + 2);
        
        if (Math.abs(pair1[0] - pair1[1]) <= Math.abs(pair2[0] - pair2[1])) {
            return pair1;
        }
        return pair2;
    }
    
    private int[] bestPair(int target) {
        int[] best = {1, target};
        int bestDiff = target - 1;
        
        // 枚举到 sqrt(target)
        for (int a = 1; (long) a * a <= target; a++) {
            if (target % a == 0) {
                int b = target / a;
                if (b - a < bestDiff) {
                    bestDiff = b - a;
                    best = new int[]{a, b};
                }
            }
        }
        
        return best;
    }
}
```

### 方法三：合并两个目标值统一处理

```java
class Solution {
    public int[] closestDivisors(int num) {
        int[] best = null;
        int bestDiff = Integer.MAX_VALUE;
        
        // 对 num+1 和 num+2 分别处理
        for (int target : new int[]{num + 1, num + 2}) {
            // 从 sqrt 向下找第一个因子
            int a = (int) Math.sqrt(target);
            while (target % a != 0) {
                a--;
            }
            int b = target / a;
            int diff = b - a; // 由于 a <= sqrt <= b，b >= a，差为 b-a
            if (diff < bestDiff) {
                bestDiff = diff;
                best = new int[]{a, b};
            }
        }
        
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(sqrt(num))。从 sqrt(num+2) 向下枚举，最坏情况（num+1 和 num+2 都是质数）需要遍历到 1，共 sqrt(num) 步。
- 空间复杂度：O(1)。

## 关键点总结

1. 使两个因子差最小的分割点在 `sqrt(target)` 处，从该处向下找第一个因子即可。
2. 需要对 `num+1` 和 `num+2` 分别找最优因子对，然后取差更小的那组。
3. Java 中用 `(int) Math.sqrt(target)` 求整数平方根，注意浮点精度问题，可以用 `(long) a * a <= target` 避免 `a*a` 溢出。
4. 由于 `a <= sqrt(target) <= b = target/a`，所以 `b >= a`，`|a-b| = b-a`，差始终非负。

## 易错点

- 不能只考虑 `num+1`，必须同时考虑 `num+2`，选差更小的那对。
- `Math.sqrt` 可能有浮点精度问题，得到的初始 `a` 可能偏大，循环向下查找可以修正。
- 当 num+1 或 num+2 是完全平方数时，最优答案就是 `[sqrt, sqrt]`，差为 0，算法能正确处理（如 num=8 时 num+1=9=3*3）。
- 暴力枚举时用 `(long) a * a <= target` 防止 `a * a` 整数溢出（target 最大约 10^9+2）。

## 示例手动推导

以 `num = 8` 为例：

```
target1 = 9:
  sqrt(9) = 3, 9 % 3 == 0 -> 因子对 (3, 3)，差 = 0

target2 = 10:
  sqrt(10) ≈ 3.16，取 3
  10 % 3 = 1，不整除，a=2
  10 % 2 == 0 -> 因子对 (2, 5)，差 = 3

比较：0 < 3，选 (3, 3)
```
