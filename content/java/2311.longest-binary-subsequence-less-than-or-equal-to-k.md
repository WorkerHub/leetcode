## 题目描述

返回二进制字符串s的最长子序列长度，使其对应的二进制数<=k。

## 解题思路

贪心：所有0都可选（不增大值）。从右向左贪心选1（低位优先权重小），选后不超k则选入。

## Java 代码实现

```java
class Solution {
    public int longestSubsequence(String s, int k) {
        int n = s.length();
        int zeros = 0;
        for (char c : s.toCharArray()) {
            if (c == '0') zeros++;
        }

        int ones = 0;
        long val = 0;
        // 从右向左贪心选1
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '1') {
                long bitVal = 1L << ones;
                if (val + bitVal <= k) {
                    val += bitVal;
                    ones++;
                }
            }
        }
        return zeros + ones;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **0全选不影响值**：前导0不增大二进制数
2. **从右向左选1**：低位权重小，优先选更划算
3. **每个1的权重为2^(已选1的个数)**
