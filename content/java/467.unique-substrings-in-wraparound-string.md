## 题目描述

把字符串 `s` 看作 "abcdefghijklmnopqrstuvwxyz" 的无限环绕字符串，所以 `s` 看起来是这样的：

- `"...zabcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyzabcd...."`.

现在给定另一个字符串 `p`。返回 `s` 中 **唯一** 的 `p` 的 **非空子串** 的数量。

**示例 1：**
```
输入：p = "a"
输出：1
解释：字符串 s 中只有一个"a"子字符。
```

**示例 2：**
```
输入：p = "cac"
输出：2
解释：字符串 s 中的字符串"cac"只有两个子串"a"、"c"。
```

**示例 3：**
```
输入：p = "zab"
输出：6
解释：在字符串 s 中有六个子串"z"、"a"、"b"、"za"、"ab"、"zab"。
```

**提示：**
- `1 <= p.length <= 10^5`
- `p` 由小写英文字母构成

## 解题思路

这道题的关键是理解"环绕字符串"的概念，以及如何避免重复计数。

**核心观察：**
1. 环绕字符串意味着字符按字母顺序排列，且 'z' 后面是 'a'
2. p 的子串要在 s 中存在，必须是连续递增的字母序列（允许 z->a）
3. 关键问题：如何去重？

**去重策略：**
- 对于以某个字符结尾的所有子串，只需记录最长的长度
- 例如：以 'c' 结尾的子串有 "c", "bc", "abc"，长度为 3
- 这样可以确保所有子串都被计数且不重复

**动态规划思路：**
- `dp[c]` 表示以字符 c 结尾的最长连续递增子串长度
- 遍历字符串 p，维护当前连续递增序列的长度
- 更新每个字符对应的最大长度

**算法流程：**
1. 初始化 dp 数组（26 个字母）
2. 遍历 p，计算每个位置的连续长度
3. 更新以当前字符结尾的最大长度
4. 最后统计所有 dp 值的和

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findSubstringInWraproundString(String p) {
        if (p == null || p.isEmpty()) return 0;

        // dp[c] 表示以字符 c 结尾的最长连续子串长度
        Map<Character, Integer> dp = new HashMap<>();

        // 当前连续递增序列的长度
        int length = 0;

        for (int i = 0; i < p.length(); i++) {
            char c = p.charAt(i);
            // 检查是否与前一个字符连续
            if (i > 0 && (c - p.charAt(i - 1) + 26) % 26 == 1) {
                length++;
            } else {
                length = 1;  // 重新开始
            }

            // 更新以 c 结尾的最大长度
            dp.put(c, Math.max(dp.getOrDefault(c, 0), length));
        }

        // 返回所有字符的最大长度之和
        int result = 0;
        for (int v : dp.values()) {
            result += v;
        }
        return result;
    }
}
```

**核心技巧：**
- `(c - p.charAt(i-1) + 26) % 26 == 1`：判断是否连续（包括 z->a）
- `dp.put(c, Math.max(...))`：只保留最长的长度

### 方法二：使用数组代替字典

```java
class Solution {
    public int findSubstringInWraproundString(String p) {
        if (p == null || p.isEmpty()) return 0;

        // dp[i] 表示以字符 'a' + i 结尾的最长长度
        int[] dp = new int[26];

        int length = 0;

        for (int i = 0; i < p.length(); i++) {
            char c = p.charAt(i);
            // 判断连续性
            if (i > 0 && (c - p.charAt(i - 1) + 26) % 26 == 1) {
                length++;
            } else {
                length = 1;
            }

            // 更新
            int idx = c - 'a';
            dp[idx] = Math.max(dp[idx], length);
        }

        // 统计所有字符的最大长度之和
        int result = 0;
        for (int v : dp) {
            result += v;
        }
        return result;
    }
}
```

**优点：** 数组访问比字典稍快

### 方法三：详细注释版（便于理解）

```java
class Solution {
    public int findSubstringInWraproundString(String p) {
        // 特殊情况
        if (p == null || p.isEmpty()) return 0;

        // 以每个字母结尾的最长连续子串长度
        int[] maxLen = new int[26];

        // 当前连续长度
        int curLen = 1;
        maxLen[p.charAt(0) - 'a'] = 1;

        for (int i = 1; i < p.length(); i++) {
            char cur = p.charAt(i);
            char prev = p.charAt(i - 1);

            // 判断 p[i] 是否紧跟在 p[i-1] 后面（字母表顺序）
            // 'a' 的 ASCII 是 97，'b' 是 98，...，'z' 是 122
            // 如果 prev = 'z', cur = 'a'，则 ('a' - 'z' + 26) % 26 = 1
            if ((cur - prev + 26) % 26 == 1) {
                curLen++;
            } else {
                curLen = 1;  // 断开，重新开始
            }

            // 更新以 cur 结尾的最大长度
            // 为什么取 max？因为可能有多段连续序列都以同一字符结尾
            // 例如："abcabc"，两段都以 'c' 结尾，取长度较大的
            int idx = cur - 'a';
            maxLen[idx] = Math.max(maxLen[idx], curLen);
        }

        // 以字符 'c' 结尾的最长长度为 3，表示有 "c", "bc", "abc" 三个子串
        // 所有字符的长度之和就是唯一子串的总数
        int result = 0;
        for (int v : maxLen) {
            result += v;
        }
        return result;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，n 是字符串 p 的长度
- 空间复杂度：O(1)，dp 数组或字典最多 26 个字母

## 图解示例

以 `p = "zab"` 为例：

```
环绕字符串 s = "...xyzabcdefg..."

p = "zab"

遍历过程：
i = 0, char = 'z':
  - length = 1
  - dp['z'] = 1

i = 1, char = 'a':
  - ('a' - 'z' + 26) % 26 = (97 - 122 + 26) % 26 = 1 ✓
  - length = 2
  - dp['a'] = 2

i = 2, char = 'b':
  - ('b' - 'a' + 26) % 26 = 1 ✓
  - length = 3
  - dp['b'] = 3

结果：
dp = {'z': 1, 'a': 2, 'b': 3}

唯一子串：
- 以 'z' 结尾：'z' (1个)
- 以 'a' 结尾：'a', 'za' (2个)
- 以 'b' 结尾：'b', 'ab', 'zab' (3个)

总计：1 + 2 + 3 = 6
```

## 关键点总结

1. **连续性判断：** `(c - prev + 26) % 26 == 1`
2. **去重策略：** 对每个结尾字符只保留最长长度
3. **子串计数：** 长度为 n 的串包含 n 个以该字符结尾的子串
4. **环绕处理：** 'z' 后面可以接 'a'，用模运算处理
5. **动态更新：** 遍历一遍即可，维护当前长度和最大长度

## 易错点

1. **连续性判断错误：** 忘记处理 'z' -> 'a' 的情况
   ```java
   // 错误：只判断差值为 1
   if (c - prev == 1) { ... }

   // 正确：使用模运算
   if ((c - prev + 26) % 26 == 1) { ... }
   ```

2. **忘记取最大值：** 多段连续序列以同一字符结尾时
   ```java
   // 错误：直接赋值
   dp[idx] = length;

   // 正确：取最大值
   dp[idx] = Math.max(dp[idx], length);
   ```

3. **重复计数：** 误以为需要记录所有子串
   ```java
   // 错误思路：维护一个 Set 存所有子串（会超时和内存溢出）

   // 正确：利用数学性质，长度为 n 就有 n 个子串
   ```

4. **边界情况：** 空字符串或单字符
   ```java
   if (p == null || p.isEmpty()) return 0;
   // 单字符时，length = 1，dp[idx] = 1，返回 1
   ```
