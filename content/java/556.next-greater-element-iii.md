## 题目描述

给你一个正整数 `n`，请你找出符合条件的最小整数，其由重新排列 `n` 中存在的每位数字组成，并且其值大于 `n`。如果不存在这样的正整数，则返回 `-1`。

注意，返回的整数应当是一个 **32 位整数**，如果存在满足题意的答案，但不是 32 位整数，同样返回 `-1`。

**示例 1：**
```
输入：n = 12
输出：21
```

**示例 2：**
```
输入：n = 21
输出：-1
```

**示例 3：**
```
输入：n = 12443322
输出：13222344
```

**提示：**
- `1 <= n <= 2^31 - 1`

## 解题思路

这道题本质上是求**下一个排列**（Next Permutation），与 LeetCode 31 题相同。

核心思想：
1. 将数字转换为数组（字符串）
2. 从右向左找到第一个递减的位置 i（即 `nums[i] < nums[i+1]`）
3. 从右向左找到第一个大于 `nums[i]` 的位置 j
4. 交换 `nums[i]` 和 `nums[j]`
5. 将 i 后面的部分反转（变为升序）
6. 检查结果是否溢出

算法步骤：
1. **找到交换位置**：从右向左找第一个 `nums[i] < nums[i+1]`
   - 如果找不到，说明整个数字是降序，不存在下一个更大的排列
2. **找到交换对象**：从右向左找第一个 `nums[j] > nums[i]`
3. **交换**：交换 `nums[i]` 和 `nums[j]`
4. **反转**：反转 i+1 到末尾的部分
5. **验证**：检查结果是否在 32 位整数范围内

## Java 代码实现

### 方法一：下一个排列算法（推荐）⭐

```java
class Solution {
    public int nextGreaterElement(int n) {
        // 将数字转换为字符数组
        char[] digits = String.valueOf(n).toCharArray();
        int length = digits.length;

        // 步骤1：从右向左找到第一个递减的位置 i
        int i = length - 2;
        while (i >= 0 && digits[i] >= digits[i + 1]) {
            i--;
        }

        // 如果找不到，说明是降序排列，返回 -1
        if (i == -1) return -1;

        // 步骤2：从右向左找到第一个大于 digits[i] 的位置 j
        int j = length - 1;
        while (j > i && digits[j] <= digits[i]) {
            j--;
        }

        // 步骤3：交换 digits[i] 和 digits[j]
        char temp = digits[i];
        digits[i] = digits[j];
        digits[j] = temp;

        // 步骤4：反转 i+1 到末尾的部分
        int left = i + 1, right = length - 1;
        while (left < right) {
            char t = digits[left];
            digits[left] = digits[right];
            digits[right] = t;
            left++;
            right--;
        }

        // 转换回整数，并检查是否在 32 位整数范围内
        long result = Long.parseLong(new String(digits));

        // 步骤5：检查是否在 32 位整数范围内
        return result > Integer.MAX_VALUE ? -1 : (int) result;
    }
}
```

### 方法二：使用 StringBuilder

```java
class Solution {
    public int nextGreaterElement(int n) {
        // 使用 StringBuilder 处理字符操作
        char[] digits = Integer.toString(n).toCharArray();
        int len = digits.length;

        // 找到第一个递减位置
        int i = len - 2;
        while (i >= 0 && digits[i] >= digits[i + 1]) i--;

        if (i < 0) return -1;

        // 找到要交换的位置
        int j = len - 1;
        while (digits[j] <= digits[i]) j--;

        // 交换
        char tmp = digits[i]; digits[i] = digits[j]; digits[j] = tmp;

        // 使用双指针反转 i+1 到末尾
        int l = i + 1, r = len - 1;
        while (l < r) {
            char t = digits[l]; digits[l] = digits[r]; digits[r] = t;
            l++; r--;
        }

        long res = Long.parseLong(new String(digits));
        return res <= Integer.MAX_VALUE ? (int) res : -1;
    }
}
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(d)，其中 d 是数字的位数（d = log₁₀n）
  - 找递减位置：O(d)
  - 找交换位置：O(d)
  - 反转：O(d)
- **空间复杂度**：O(d)，存储数字的字符数组

## 关键点总结

1. **下一个排列算法**：这是一个经典算法，需要熟练掌握
2. **从右向左**：找递减位置和交换位置都是从右向左
3. **反转操作**：交换后需要反转后半部分，使其变为最小
4. **边界情况**：降序排列时返回 -1
5. **溢出检查**：Java 中用 long 类型接收结果，再与 Integer.MAX_VALUE 比较

## 易错点

1. **比较符号**：
   - 找递减位置：`digits[i] >= digits[i+1]`（注意是 >=）
   - 找交换位置：`digits[j] <= digits[i]`（注意是 <=）
2. **循环条件**：
   - 第一个循环：`i >= 0`
   - 第二个循环：`j > i`
3. **降序判断**：
   - 当 i == -1 时，说明整个数字是降序
4. **反转范围**：
   - 只反转 `i+1` 到末尾，不包括 i
5. **溢出处理**：
   - 必须使用 long 接收结果，再检查是否超过 Integer.MAX_VALUE
