## 题目描述

给你整数数组 `nums` 和整数 `k`，如果某个值在 `nums` 的每个长度为 `k` 的连续子数组中最多出现一次，则称该值为"几乎缺失"的整数。返回所有几乎缺失整数中的最大值，不存在则返回 -1。

## 解题思路

对每个不同的值用滑动窗口检查：维护当前窗口内该值的出现次数，若某个窗口内出现 >= 2 次则不满足。取所有满足条件的值的最大值。

## Java 代码实现

```java
class Solution {
    public int largestInteger(int[] nums, int k) {
        int n = nums.length;
        int ans = -1;

        Set<Integer> distinct = new HashSet<>();
        for (int x : nums) distinct.add(x);

        for (int x : distinct) {
            // 滑动窗口统计 x 在每个长度 k 的子数组中的出现次数
            int count = 0;
            for (int i = 0; i < k; i++) {
                if (nums[i] == x) count++;
            }
            boolean valid = count <= 1;

            for (int i = 1; i <= n - k && valid; i++) {
                if (nums[i - 1] == x) count--;
                if (nums[i + k - 1] == x) count++;
                if (count >= 2) valid = false;
            }

            if (valid) ans = Math.max(ans, x);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * d)，d 为不同值个数（最坏 O(n^2)）
- 空间复杂度：O(d)

## 关键点总结

1. 几乎缺失：在每个长度 k 的子数组中最多出现 1 次
2. 用滑动窗口高效统计每个值在各窗口中的出现次数
3. k=1 时所有值均满足；k=n 时只有出现恰好 1 次的值满足
