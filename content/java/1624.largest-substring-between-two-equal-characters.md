## 题目描述

给你一个字符串 `s`，请你返回**两个相同字符之间的最长子字符串**的长度，计算长度时**不含**这两个字符。如果不存在这样的子字符串，返回 `-1`。

**提示：**
- `1 <= s.length <= 300`
- `s` 只包含小写英文字母

## 解题思路

用数组记录每个字符**第一次出现**的位置，遍历时若当前字符已出现，则更新答案为两位置之差减一。

## Java 代码实现

```java
class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        int[] firstPos = new int[26];
        // 初始化为 -1，表示未出现
        Arrays.fill(firstPos, -1);
        int ans = -1;

        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (firstPos[idx] != -1) {
                // 两次出现之间的子串长度（不含两端）
                ans = Math.max(ans, i - firstPos[idx] - 1);
            } else {
                // 记录首次出现位置
                firstPos[idx] = i;
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(26) = O(1)，固定大小数组

## 关键点总结

1. 只需记录每个字符**第一次**出现的位置
2. 遇到重复字符时，长度 = `当前位置 - 首次位置 - 1`
3. 遇到相同字符时**不更新**首次位置（保留最早位置）
4. 初始答案为 -1，若未找到重复字符则返回 -1
