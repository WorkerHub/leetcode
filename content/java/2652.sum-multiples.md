## 题目描述

给你正整数 `n`，计算 `[1, n]` 范围内所有能被 3、5 或 7 整除的整数之和。

## Java 代码实现

```java
class Solution {
    public int sumOfMultiples(int n) {
        int sum = 0;
        for (int x = 1; x <= n; x++) {
            if (x % 3 == 0 || x % 5 == 0 || x % 7 == 0) sum += x;
        }
        return sum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 三个条件取并集，同时满足多个条件的数只计一次
2. n 最大为 1000，线性枚举即可
