## 题目描述

给你整数 `x`、`y`、`z`，分别表示字符串 `"aa"`、`"bb"`、`"ab"` 的数量，拼接后不含 `"aaa"` 或 `"bbb"`，返回最长字符串的长度。

## Java 代码实现

```java
class Solution {
    public int longestString(int x, int y, int z) {
        // "aa" 和 "bb" 必须交替，最多用 min(x,y) 对
        int pairs = Math.min(x, y);
        // 若 x != y，数量多的可以再放一个
        int extra = (x != y) ? 1 : 0;
        // 总拼接块数 * 2（每块长度为 2）
        return (2 * pairs + extra + z) * 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `"aa"` 和 `"bb"` 必须交替，最多用 `min(x, y)` 对
2. 若 `x != y`，多的那种可以再放一个（放在开头或结尾）
3. `"ab"` 不引入新的 `aa` 或 `bb`，全部可用
