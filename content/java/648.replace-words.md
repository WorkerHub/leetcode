## 题目描述

给定词根字典和句子，将句子中的继承词用最短词根替换。

**示例：**
```
输入：dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"
输出："the cat was rat by the bat"
```

## 解题思路

字典树：将所有词根插入 Trie，对句子中每个单词查找最短匹配前缀。

## Java 代码实现

```java
class Solution {
    private int[][] trie;
    private boolean[] isEnd;
    private int idx;

    public String replaceWords(List<String> dictionary, String sentence) {
        trie = new int[100001][26];
        isEnd = new boolean[100001];
        idx = 0;

        // 插入所有词根
        for (String root : dictionary) {
            insert(root);
        }

        // 替换句子中的单词
        String[] words = sentence.split(" ");
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < words.length; i++) {
            if (i > 0) sb.append(" ");
            sb.append(findRoot(words[i]));
        }
        return sb.toString();
    }

    private void insert(String word) {
        int cur = 0;
        for (char c : word.toCharArray()) {
            int ch = c - 'a';
            if (trie[cur][ch] == 0) {
                trie[cur][ch] = ++idx;
            }
            cur = trie[cur][ch];
        }
        isEnd[cur] = true;
    }

    private String findRoot(String word) {
        int cur = 0;
        for (int i = 0; i < word.length(); i++) {
            int ch = word.charAt(i) - 'a';
            if (trie[cur][ch] == 0) break;
            cur = trie[cur][ch];
            if (isEnd[cur]) return word.substring(0, i + 1);
        }
        return word;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(d + n×k)，d 为词根总长，n 为单词数，k 为平均单词长度
- **空间复杂度**：O(d)

## 关键点总结

1. **Trie 前缀匹配**：找到最短词根立即返回
2. **数组实现 Trie**：比 HashMap 更快
3. **isEnd 标记**：区分是否为完整词根
