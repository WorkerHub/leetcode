## 题目描述

按规则揭牌（取顶牌显示，下一张放底部），要求揭示顺序为递增。返回初始牌组排列。

## 解题思路

模拟索引队列：排序牌组，用队列模拟揭牌过程的索引变化，将排序后的牌放到对应位置。

## Java 代码实现

```java
class Solution {
    public int[] deckRevealedIncreasing(int[] deck) {
        Arrays.sort(deck);
        int n = deck.length;
        int[] result = new int[n];

        // 索引队列模拟揭牌过程
        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) queue.offer(i);

        for (int card : deck) {
            // 取出队首索引放牌
            result[queue.poll()] = card;
            // 将下一个索引移到队尾
            if (!queue.isEmpty()) {
                queue.offer(queue.poll());
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **索引模拟**：用队列模拟揭牌顺序
2. **排序对应**：最小牌放第一个揭示位置
3. **取一放一**：取出一个索引后将下一个移到队尾
