## 题目描述

三个线程分别调用 first()、second()、third()，设计同步机制保证按顺序输出 "firstsecondthird"。

**示例：**
```
输入：nums = [1,3,2]
输出："firstsecondthird"
```

## 解题思路

使用 CountDownLatch 或 Semaphore：first 完成后释放信号允许 second 执行，second 完成后释放信号允许 third。

## Java 代码实现

```java
class Foo {
    private CountDownLatch latch1 = new CountDownLatch(1);
    private CountDownLatch latch2 = new CountDownLatch(1);

    public Foo() {}

    public void first(Runnable printFirst) throws InterruptedException {
        printFirst.run();
        latch1.countDown(); // 通知 second 可以执行
    }

    public void second(Runnable printSecond) throws InterruptedException {
        latch1.await(); // 等待 first 完成
        printSecond.run();
        latch2.countDown(); // 通知 third 可以执行
    }

    public void third(Runnable printThird) throws InterruptedException {
        latch2.await(); // 等待 second 完成
        printThird.run();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **CountDownLatch**：一次性信号，countDown 后 await 立即通过
2. **顺序保证**：latch1 保证 first→second，latch2 保证 second→third
3. **也可用 Semaphore(0)**：acquire 等待，release 释放
