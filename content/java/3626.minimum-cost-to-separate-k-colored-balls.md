## 题目描述

给定颜色数组 `colors` 和整数 `k`，将球分成 `k` 组连续子数组，每组代价为组内重复颜色数（即颜色出现次数超过 1 的总数），返回最小总代价。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumCost(int[] colors, int k) {
        int n = colors.length;
        int INF = Integer.MAX_VALUE / 2;
        // dp[t][j] = 前 j 个球分成 t 组的最小代价
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;

        for (int t = 1; t <= k; t++) {
            for (int j = t; j <= n; j++) {
                // 枚举上一个分割点 i，区间 [i, j-1] 为第 t 组
                Map<Integer, Integer> freq = new HashMap<>();
                int cost = 0;
                for (int i = j - 1; i >= t - 1; i--) {
                    int c = colors[i];
                    freq.merge(c, 1, Integer::sum);
                    if (freq.get(c) > 1) cost++;  // 新增一个重复
                    if (dp[t - 1][i] < INF) {
                        dp[t][j] = Math.min(dp[t][j], dp[t - 1][i] + cost);
                    }
                }
            }
        }
        return dp[k][n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * n^2)，两层枚举分割点
- 空间复杂度：O(k * n)

## 关键点总结

1. 每组代价 = 颜色出现次数超过 1 的总数（重复数）
2. 从右向左扫描时用哈希表增量更新代价，避免重复计算
3. DP 转移：枚举分割点，合并子问题
