## 题目描述

统计字符串中只含元音字母且包含所有五种元音(a,e,i,o,u)的子串数目。

## 解题思路

暴力枚举：数据范围小(n<=100)，枚举所有子串，遇到非元音break，用Set记录已见元音种类。

## Java 代码实现

```java
class Solution {
    public int countVowelSubstrings(String word) {
        Set<Character> vowels = Set.of('a', 'e', 'i', 'o', 'u');
        int count = 0;
        int n = word.length();

        for (int i = 0; i < n; i++) {
            if (!vowels.contains(word.charAt(i))) continue;
            Set<Character> seen = new HashSet<>();
            for (int j = i; j < n; j++) {
                char c = word.charAt(j);
                if (!vowels.contains(c)) break; // 遇到非元音停止
                seen.add(c);
                if (seen.size() == 5) count++; // 包含所有5种元音
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **只含元音且包含全部5种**：双重条件
2. **遇到非元音立即break**：提前终止
3. **数据范围小**：暴力O(N^2)可行
