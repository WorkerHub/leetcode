## 题目描述

从字符串选k个不同字符的子序列，使美丽度（各字符在s中频率之和）最大，求最大美丽度子序列数量。

## 解题思路

贪心选频率最高的k种字符。每种有freq[i]种选法(选哪个位置)。频率相同的用组合数C(cnt,need)计算。

## Java 代码实现

```java
class Solution {
    public int countKSubsequencesWithMaxBeauty(String s, int k) {
        long MOD = 1_000_000_007;
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        // 收集非零频率并降序排列
        List<Integer> freqs = new ArrayList<>();
        for (int f : freq) if (f > 0) freqs.add(f);
        if (freqs.size() < k) return 0;
        freqs.sort(Collections.reverseOrder());

        int threshold = freqs.get(k - 1);
        int higherCount = 0;
        int equalCount = 0;
        for (int f : freqs) {
            if (f > threshold) higherCount++;
            else if (f == threshold) equalCount++;
        }
        int need = k - higherCount;

        long ans = 1;
        // 频率>threshold的字符各有freq种选法
        for (int f : freqs) {
            if (f > threshold) ans = ans * f % MOD;
        }
        // 频率==threshold的选need个，各有threshold种选法
        ans = ans * power(threshold, need, MOD) % MOD;
        // 组合数C(equalCount, need)
        ans = ans * comb(equalCount, need, MOD) % MOD;
        return (int) ans;
    }

    private long power(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }

    private long comb(int n, int r, long mod) {
        if (r > n) return 0;
        long num = 1, den = 1;
        for (int i = 0; i < r; i++) {
            num = num * (n - i) % mod;
            den = den * (i + 1) % mod;
        }
        return num * power(den, mod - 2, mod) % mod;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + 26 log 26)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心选频率最高的k种字符**
2. **每种字符有freq种位置选择**
3. **频率相同时用组合数+费马小定理求逆元**
