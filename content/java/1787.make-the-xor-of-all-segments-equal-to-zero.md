## 题目描述

给你整数数组 `nums` 和整数 `k`，使所有长度为 k 的区间异或值均为 0，返回最少修改次数。

## 解题思路

由连续 k 个区间异或为 0 可推导出：位置模 k 相同的元素必须全部相等。

将 k 个同余组各选一个代表值，要求所有代表值异或之和为 0，最小化总修改次数。

**DP**：`dp[v]` = 前几组处理完且当前组异或前缀为 `v` 时的最小修改次数。
- 初始 `dp[0]=0`，其余 INF
- 每组：默认用 `prev_min + groupSize`（选组外值），再对组内值枚举精确代价

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minChanges(int[] nums, int k) {
        int n = nums.length;
        final int MAX_VAL = 1024; // nums[i] < 2^10
        final int INF = Integer.MAX_VALUE / 2;

        int[] dp = new int[MAX_VAL];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int g = 0; g < k; g++) {
            // 第 g 组：收集所有 i mod k == g 的元素
            int[] cnt = new int[MAX_VAL];
            int size = 0;
            for (int i = g; i < n; i += k) {
                cnt[nums[i]]++;
                size++;
            }

            // 上一轮 dp 的全局最小值
            int prevMin = INF;
            for (int v : dp) if (v < prevMin) prevMin = v;

            // 新 dp 默认：用组外值，代价 = prevMin + size
            int[] newDp = new int[MAX_VAL];
            Arrays.fill(newDp, prevMin + size);

            // 对组内出现的值精确计算
            for (int val = 0; val < MAX_VAL; val++) {
                if (cnt[val] == 0) continue;
                int saveCnt = cnt[val]; // 选 val 时可以少改 saveCnt 个
                for (int prevXor = 0; prevXor < MAX_VAL; prevXor++) {
                    if (dp[prevXor] == INF) continue;
                    int target = prevXor ^ val;
                    int cost = dp[prevXor] + size - saveCnt;
                    if (cost < newDp[target]) {
                        newDp[target] = cost;
                    }
                }
            }

            dp = newDp;
        }

        return dp[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * MAX_VAL^2 / k + n) = O(n + k * MAX_VAL) 实际上每组内出现的值数量有限
- **空间复杂度**：O(MAX_VAL)

## 关键点总结

1. 位置 mod k 相同的元素必须相等（由连续区间异或为 0 推导）
2. dp[v] = 前若干组处理完且异或前缀为 v 时的最小修改次数
3. 用全局最小值 prevMin 初始化新 dp 数组（选组外值时代价）
