## 题目描述

找出字符串中同时以大写和小写出现的最大字母，返回其大写形式。

## 解题思路

将所有字符加入集合，从Z到A倒序枚举，第一个大小写都存在的字母即为答案。

## Java 代码实现

```java
class Solution {
    public String greatestLetter(String s) {
        boolean[] seen = new boolean[128];
        for (char c : s.toCharArray()) {
            seen[c] = true;
        }

        for (char c = 'Z'; c >= 'A'; c--) {
            if (seen[c] && seen[Character.toLowerCase(c)]) {
                return String.valueOf(c);
            }
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **布尔数组记录出现的字符**：O(1)查找
2. **从Z倒序枚举**：第一个满足条件的即为最大
3. **同时检查大写和小写**
