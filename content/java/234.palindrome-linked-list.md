## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**
```
输入：head = [1,2]
输出：false
```

**提示：**
- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：** 你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

## 解题思路

判断链表是否为回文，有多种方法，从简单到优化：

**方法思路：**

1. **数组辅助**：将链表值复制到数组，用双指针判断（空间 O(n)）
2. **栈辅助**：利用栈的后进先出特性（空间 O(n)）
3. **快慢指针 + 反转**：找到中点，反转后半部分，比较（空间 O(1)）⭐
4. **递归**：利用递归的回溯特性（空间 O(n)，递归栈）

**最优解思路（快慢指针 + 反转）：**

1. 使用快慢指针找到链表中点
2. 反转后半部分链表
3. 比较前半部分和反转后的后半部分
4. 恢复链表（可选）

## Java 代码实现

### 方法一：数组辅助（最简单）

```java
// Definition for singly-linked list.
// public class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public boolean isPalindrome(ListNode head) {
        // 将链表值存入列表
        List<Integer> vals = new ArrayList<>();
        ListNode current = head;
        while (current != null) {
            vals.add(current.val);
            current = current.next;
        }

        // 双指针判断回文
        int left = 0, right = vals.size() - 1;
        while (left < right) {
            if (!vals.get(left).equals(vals.get(right))) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }
}
```

### 方法二：快慢指针 + 反转（推荐，O(1) 空间）⭐

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        // 快慢指针找中点 + 反转后半部分链表
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        if (head == null || head.next == null) {
            return true;
        }

        // 步骤 1：使用快慢指针找到中点
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // slow 现在指向中点（或中点的前一个节点）
        // 反转后半部分链表
        ListNode secondHalf = reverse(slow.next);
        ListNode secondHalfCopy = secondHalf; // 保存用于恢复

        // 步骤 2：比较前半部分和反转后的后半部分
        ListNode firstHalf = head;
        boolean result = true;
        while (result && secondHalf != null) {
            if (firstHalf.val != secondHalf.val) {
                result = false;
            }
            firstHalf = firstHalf.next;
            secondHalf = secondHalf.next;
        }

        // 步骤 3：恢复链表（可选）
        slow.next = reverse(secondHalfCopy);

        return result;
    }

    // 反转链表
    private ListNode reverse(ListNode head) {
        ListNode prev = null;
        ListNode current = head;
        while (current != null) {
            ListNode nextNode = current.next;
            current.next = prev;
            prev = current;
            current = nextNode;
        }
        return prev;
    }
}
```

### 方法三：快慢指针 + 反转（简化版，不恢复链表）

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        // 不恢复链表的简化版本
        if (head == null || head.next == null) {
            return true;
        }

        // 找到中点
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 反转后半部分
        ListNode second = slow.next;
        slow.next = null; // 断开链表

        // 反转
        ListNode prev = null;
        while (second != null) {
            ListNode nextNode = second.next;
            second.next = prev;
            prev = second;
            second = nextNode;
        }

        // 比较
        ListNode first = head;
        second = prev;
        while (second != null) { // 后半部分可能比前半部分短
            if (first.val != second.val) {
                return false;
            }
            first = first.next;
            second = second.next;
        }

        return true;
    }
}
```

### 方法四：栈辅助

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        // 使用栈存储前半部分，利用栈的后进先出特性
        if (head == null || head.next == null) {
            return true;
        }

        // 找到中点
        ListNode slow = head, fast = head;
        Deque<Integer> stack = new ArrayDeque<>();

        // 将前半部分入栈
        while (fast != null && fast.next != null) {
            stack.push(slow.val);
            slow = slow.next;
            fast = fast.next.next;
        }

        // 如果是奇数长度，跳过中间节点
        if (fast != null) {
            slow = slow.next;
        }

        // 比较后半部分和栈中元素
        while (slow != null) {
            if (slow.val != stack.pop()) {
                return false;
            }
            slow = slow.next;
        }

        return true;
    }
}
```

## 复杂度分析

**方法一（数组辅助）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要存储所有节点值

**方法二（快慢指针 + 反转）：**
- 时间复杂度：O(n)，需要遍历链表两次
- 空间复杂度：O(1)，只用了常数个指针

**方法四（栈辅助）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n/2)，栈存储前半部分

## 关键点总结

1. **快慢指针找中点**：fast 走两步，slow 走一步，slow 到达中点
2. **反转链表**：经典的三指针反转法
3. **比较技巧**：只需比较后半部分的长度（奇数长度时后半部分较短）
4. **空间优化**：O(1) 空间的关键是原地修改链表
5. **恢复链表**：面试时可以询问是否需要恢复原链表

## 易错点

1. **中点判断**：
   ```java
   // 对于奇数长度 [1,2,3,2,1]，slow 应该停在 3
   // 对于偶数长度 [1,2,2,1]，slow 应该停在第一个 2
   
   // 正确写法
   while (fast.next != null && fast.next.next != null) {
       slow = slow.next;
       fast = fast.next.next;
   }
   ```

2. **比较长度**：后半部分可能比前半部分短，用后半部分的长度控制循环
   ```java
   while (second != null) { // 用 second 控制，不是 first
       if (first.val != second.val) return false;
       first = first.next;
       second = second.next;
   }
   ```

3. **空链表和单节点**：需要特殊处理
   ```java
   if (head == null || head.next == null) return true;
   ```

4. **反转链表时保存头节点**：如果需要恢复，要保存反转后的头节点

5. **Java 中整数比较**：基本类型 `int` 用 `==` 比较，包装类 `Integer` 用 `equals()` 比较
