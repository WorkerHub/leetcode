## 题目描述

给定字符串 `word1` 和 `word2`，统计 `word1` 中有多少个子字符串，通过重排可以包含 `word2`（即该子串包含 `word2` 所有字符且频次不少于 `word2`）。

## Java 代码实现

```java
class Solution {
    public long countSubstrings(String word1, String word2) {
        int n = word1.length();
        int[] need = new int[26];
        int needCount = 0;

        // 统计 word2 各字符需求
        for (char c : word2.toCharArray()) {
            need[c - 'a']++;
            needCount++;
        }

        int[] window = new int[26];
        int have = 0;  // 窗口中已满足的字符总数
        int left = 0;
        long result = 0;

        for (int right = 0; right < n; right++) {
            int c = word1.charAt(right) - 'a';
            window[c]++;
            if (window[c] <= need[c]) have++;  // 新增的字符对满足条件有贡献

            // 当窗口满足条件，以 left 为左端的子串满足，向右移动左端
            while (have == needCount) {
                // 以 left 为左端，right..n-1 为右端的子串均满足
                result += (long)(n - right);
                int lc = word1.charAt(left) - 'a';
                if (window[lc] <= need[lc]) have--;
                window[lc]--;
                left++;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，滑动窗口
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 滑动窗口维护窗口内字符频次，`have` 记录已满足的字符总数
2. 窗口满足条件时，以当前左端为起点的所有更长子串也满足
3. 答案用 `long` 防止溢出（子串数量可达 O(n^2)）
