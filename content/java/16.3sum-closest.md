## 题目描述

给你一个长度为 `n` 的整数数组 `nums` 和一个目标值 `target`。请你从 `nums` 中选出三个整数，使它们的和与 `target` 最接近。

返回这三个数的和。假定每组输入只存在恰好一个解。

**示例 1：**
```
输入：nums = [-1,2,1,-4], target = 1
输出：2
解释：与 target 最接近的和是 2 (-1 + 2 + 1 = 2)
```

**示例 2：**
```
输入：nums = [0,0,0], target = 1
输出：0
```

## 解题思路

与「三数之和」类似，排序 + 双指针，但不是找和为 0，而是找最接近 target 的和。

## Java 代码实现

### 方法：排序 + 双指针（推荐）

```java
class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        int closestSum = nums[0] + nums[1] + nums[2];
        
        for (int i = 0; i < n - 2; i++) {
            // 跳过重复
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            int left = i + 1, right = n - 1;
            
            while (left < right) {
                int currentSum = nums[i] + nums[left] + nums[right];
                
                // 如果正好等于target，直接返回
                if (currentSum == target) return target;
                
                // 更新最接近的和
                if (Math.abs(currentSum - target) < Math.abs(closestSum - target)) {
                    closestSum = currentSum;
                }
                
                // 移动指针
                if (currentSum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        
        return closestSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(log n)，排序所需的栈空间

## 关键点总结

1. **提前返回**：如果 `currentSum == target`，直接返回
2. **更新条件**：比较 `abs(currentSum - target)` 的大小
3. **不需要去重**：只返回一个值，不需要像三数之和那样严格去重

## 易错点

1. **初始值设置**：用前三个数的和初始化 `closestSum`
2. **比较方式**：要用绝对值比较差距
