## 题目描述

给你 n 棵小 BST（每棵 2-3 个节点），通过将叶节点替换为与其值相同根节点的子树来合并，返回合并后的 BST 根节点，不合法返回 null。

## 解题思路

用 HashMap 记录所有根节点，找出唯一不被其他树叶节点引用的根作为候选根，DFS 合并同时验证 BST 合法性（lo < val < hi），最终检查所有树都被消耗。

## Java 代码实现

```java
import java.util.*;

class Solution {
    Map<Integer, TreeNode> rootMap = new HashMap<>();
    Map<Integer, Boolean> used = new HashMap<>();

    public TreeNode canMerge(List<TreeNode> trees) {
        Set<Integer> leafVals = new HashSet<>();
        for (TreeNode t : trees) {
            rootMap.put(t.val, t);
            if (t.left != null) leafVals.add(t.left.val);
            if (t.right != null) leafVals.add(t.right.val);
        }

        // 找候选根：根值不在叶节点集合中的唯一树
        TreeNode root = null;
        for (TreeNode t : trees)
            if (!leafVals.contains(t.val)) {
                if (root != null) return null; // 超过一个候选根
                root = t;
            }
        if (root == null) return null;

        // DFS 合并并验证 BST
        if (!dfs(root, Integer.MIN_VALUE, Integer.MAX_VALUE)) return null;
        // 验证所有树都被消耗
        return rootMap.size() == 1 ? root : null;
    }

    private boolean dfs(TreeNode node, int lo, int hi) {
        if (node == null) return true;
        if (node.val <= lo || node.val >= hi) return false;
        // 叶节点尝试替换
        if (node.left == null && node.right == null && rootMap.containsKey(node.val)) {
            TreeNode sub = rootMap.remove(node.val);
            node.left = sub.left;
            node.right = sub.right;
        }
        return dfs(node.left, lo, node.val) && dfs(node.right, node.val, hi);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(n)

## 关键点总结

1. 候选根唯一：所有其他树的根值均出现在某棵树的叶节点中
2. DFS 合并时同步验证 BST 区间约束
3. 最终 rootMap 中只剩候选根说明所有树都被完全合并
