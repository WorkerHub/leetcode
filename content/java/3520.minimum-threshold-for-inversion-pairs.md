## 题目描述

给定整数数组 `nums` 和整数 `k`。定义阈值为 `t` 的逆序对：`i < j` 且 `nums[i] - nums[j] >= t`。求最小阈值 `t` 使逆序对数量 >= `k`。

## 解题思路

二分答案 + 有序集合统计：阈值越小逆序对越多（单调性），二分 `t`。对固定 `t`，从右向左遍历，用 TreeMap 维护已见值的频次，对每个 `nums[i]` 统计 TreeMap 中 <= `nums[i] - t` 的元素个数。

## Java 代码实现

```java
import java.util.TreeMap;

class Solution {
    public int minimumThreshold(int[] nums, int k) {
        int n = nums.length;
        int lo = 1, hi = 0;
        for (int x : nums) hi = Math.max(hi, x);
        int minVal = Integer.MAX_VALUE;
        for (int x : nums) minVal = Math.min(minVal, x);
        hi -= minVal;
        if (hi == 0) return 0;

        int ans = hi;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (countPairs(nums, mid) >= k) { ans = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        return ans;
    }

    private long countPairs(int[] nums, int t) {
        TreeMap<Integer, Integer> tm = new TreeMap<>();
        long count = 0;
        for (int i = nums.length - 1; i >= 0; i--) {
            // 统计 tm 中 <= nums[i] - t 的元素个数
            int threshold = nums[i] - t;
            NavigableMap<Integer, Integer> sub = tm.headMap(threshold, true);
            for (int cnt : sub.values()) count += cnt;
            tm.merge(nums[i], 1, Integer::sum);
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * log(max_diff))，最坏情况 headMap 遍历 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 阈值与逆序对数量单调，满足二分条件
2. 从右向左维护有序集合，统计 <= nums[i]-t 的元素数
3. 二分寻找满足"对数 >= k"的最小阈值
