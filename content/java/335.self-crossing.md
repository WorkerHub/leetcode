## 题目描述

给你一个整数数组 `distance`。从 X-Y 平面上的点 `(0, 0)` 开始，先向北移动 `distance[0]` 米，然后向西移动 `distance[1]` 米，再向南移动 `distance[2]` 米，接着向东移动 `distance[3]` 米，持续移动。也就是说，每次移动后你的方位会发生逆时针变化。

判断你所经过的路径是否相交。如果相交，返回 `true`；否则，返回 `false`。

**示例 1:**

```
输入：distance = [2,1,1,2]
输出：true
```

**示例 2:**

```
输入：distance = [1,2,3,4]
输出：false
```

**示例 3:**

```
输入：distance = [1,1,1,1]
输出：true
```

**提示:**

- `1 <= distance.length <= 10^5`
- `1 <= distance[i] <= 10^5`

## 解题思路

这道题是一道**几何模拟题**，关键是找出所有可能相交的情况。

### 核心思想

线段只可能与它前面的**第 3、4、5 条线段**相交，不可能与更远的线段相交。

具体来说，第 `i` 条线段可能与以下线段相交：
1. **第 i-3 条线段**（3 条线之前）
2. **第 i-4 条线段**（4 条线之前）
3. **第 i-5 条线段**（5 条线之前）

### 三种相交情况

设当前线段为 `i`，以下用 `d[i]` 表示 `distance[i]`：

#### 情况 1：第 i 条线与第 i-3 条线相交

```
     i-2
    ┌──┐
    │  │i-1
    │  └─┐
 i-3│    │i
    │    │
    └────┘
```

**条件**：
- `d[i] >= d[i-2]`
- `d[i-1] <= d[i-3]`

#### 情况 2：第 i 条线与第 i-4 条线相交

```
   i-3
  ┌───┐
  │   │i-2
  │   └──┐
  │      │i-1
 i-4│      └─┐
  │        │i
  └────────┘
```

**条件**：
- `i >= 4`
- `d[i-1] == d[i-3]`
- `d[i] + d[i-4] >= d[i-2]`

#### 情况 3：第 i 条线与第 i-5 条线相交

```
    i-4
   ┌───┐
   │   │i-3
   │   └───┐
   │       │i-2
 i-5│       └──┐
   │          │i-1
   │          └─┐
   │            │i
   └────────────┘
```

**条件**：
- `i >= 5`
- `d[i-2] >= d[i-4]`
- `d[i-3] >= d[i-1]`
- `d[i-1] + d[i-5] >= d[i-3]`
- `d[i] + d[i-4] >= d[i-2]`

## Java 代码实现

### 方法一：分情况判断（推荐）⭐

```java
class Solution {
    public boolean isSelfCrossing(int[] distance) {
        // 检查三种可能的相交情况
        int n = distance.length;

        for (int i = 3; i < n; i++) {
            // 情况 1: 第 i 条线与第 i-3 条线相交
            if (distance[i] >= distance[i - 2] && distance[i - 1] <= distance[i - 3]) {
                return true;
            }

            // 情况 2: 第 i 条线与第 i-4 条线相交
            if (i >= 4 && distance[i - 1] == distance[i - 3]
                    && distance[i] + distance[i - 4] >= distance[i - 2]) {
                return true;
            }

            // 情况 3: 第 i 条线与第 i-5 条线相交
            if (i >= 5 && distance[i - 2] >= distance[i - 4]
                    && distance[i - 3] >= distance[i - 1]
                    && distance[i - 1] + distance[i - 5] >= distance[i - 3]
                    && distance[i] + distance[i - 4] >= distance[i - 2]) {
                return true;
            }
        }

        return false;
    }
}
```

### 方法三：详细注释版（便于理解）

```java
class Solution {
    public boolean isSelfCrossing(int[] distance) {
        // 检查路径是否相交
        int n = distance.length;

        // 至少需要 4 条线才可能相交
        if (n < 4) return false;

        for (int i = 3; i < n; i++) {
            // 情况 1: 当前线（第 i 条）与第 i-3 条线相交
            // 这是最常见的相交情况
            // 条件：
            // - 第 i 条线足够长，能碰到第 i-3 条线（d[i] >= d[i-2]）
            // - 第 i-1 条线足够短，不会阻挡（d[i-1] <= d[i-3]）
            if (distance[i] >= distance[i - 2] && distance[i - 1] <= distance[i - 3]) {
                return true;
            }

            // 情况 2: 当前线与第 i-4 条线相交
            // 这种情况发生在路径几乎形成闭合时
            // 条件：
            // - 第 i-1 和第 i-3 条线长度相等（平行）
            // - 第 i 和第 i-4 条线总长度足够长
            if (i >= 4 && distance[i - 1] == distance[i - 3]
                    && distance[i] + distance[i - 4] >= distance[i - 2]) {
                return true;
            }

            // 情况 3: 当前线与第 i-5 条线相交
            // 这是最复杂的情况，路径形成复杂的折叠
            if (i >= 5 && distance[i - 2] >= distance[i - 4]
                    && distance[i - 3] >= distance[i - 1]
                    && distance[i - 1] + distance[i - 5] >= distance[i - 3]
                    && distance[i] + distance[i - 4] >= distance[i - 2]) {
                return true;
            }
        }

        return false;
    }
}
```

## 复杂度分析

**所有方法**

- **时间复杂度**：O(n)
  - 遍历数组一次，每次检查常数个条件
  
- **空间复杂度**：O(1)
  - 只使用常数个变量

## 关键点总结

1. **相交范围限制**：线段只可能与前 3、4、5 条线段相交
2. **三种情况**：
   - 与 i-3 相交：最常见
   - 与 i-4 相交：路径接近闭合
   - 与 i-5 相交：复杂折叠
3. **几何条件**：每种情况都有特定的长度关系
4. **早停优化**：一旦发现相交立即返回 `true`
5. **索引边界**：检查 i-4、i-5 前要确保 `i >= 4` 或 `i >= 5`

## 易错点

1. **索引越界**：
   - 情况 2 需要 `i >= 4`
   - 情况 3 需要 `i >= 5`
   
2. **条件判断顺序**：
   - 先判断最常见的情况 1
   - 再判断情况 2 和 3

3. **等号的使用**：
   - 情况 1：`>=` 和 `<=`
   - 情况 2：第一个条件用 `==`，第二个用 `>=`
   - 情况 3：都用 `>=`

4. **忘记返回 false**：循环结束后要返回 `false`

5. **边界情况**：`n < 4` 时不可能相交
