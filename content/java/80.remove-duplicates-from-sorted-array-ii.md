## 题目描述

给你一个有序数组 `nums`，请你原地删除重复出现的元素，使得出现次数超过两次的元素只出现两次，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在原地修改输入数组并在使用 O(1) 额外空间的条件下完成。

**示例 1：**
```
输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3]
解释：函数应返回新长度 length = 5, 并且原数组的前五个元素被修改为 1, 1, 2, 2, 3
```

**示例 2：**
```
输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3]
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按升序排列

## 解题思路

核心思想：双指针

关键观察：
- 慢指针指向下一个要填入的位置
- 快指针遍历数组
- 如果当前元素与slow-2位置的元素不同，就可以保留

## Java 代码实现

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length <= 2) {
            return nums.length;
        }

        int slow = 2;  // 前两个元素一定保留

        for (int fast = 2; fast < nums.length; fast++) {
            // 如果当前元素与slow-2位置不同，可以保留
            if (nums[fast] != nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **双指针**：slow指向填入位置，fast遍历
2. **判断条件**：与slow-2位置比较
3. **通用性**：改为k次只需比较slow-k

## 易错点

1. **初始值**：slow从2开始，前两个元素保留
2. **比较对象**：与slow-2比较，不是slow-1
