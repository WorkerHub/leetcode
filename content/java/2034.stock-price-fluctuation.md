## 题目描述

设计 `StockPrice` 类，支持按时间戳更新股价、查询最新价格、查询最大和最小价格（时间戳可修正之前的记录）。

## 解题思路

用 HashMap 存储时间戳到价格的映射，TreeMap 维护价格到频次的有序映射，支持 O(log n) 的最大/最小查询和更新。

## Java 代码实现

### 方法一：HashMap + TreeMap（推荐）

```java
import java.util.*;

class StockPrice {
    private Map<Integer, Integer> timeToPrice;  // 时间戳 -> 价格
    private TreeMap<Integer, Integer> priceCnt; // 价格 -> 出现次数（有序）
    private int latestTime;

    public StockPrice() {
        timeToPrice = new HashMap<>();
        priceCnt = new TreeMap<>();
        latestTime = 0;
    }

    public void update(int timestamp, int price) {
        latestTime = Math.max(latestTime, timestamp);
        if (timeToPrice.containsKey(timestamp)) {
            int oldPrice = timeToPrice.get(timestamp);
            // 移除旧价格
            priceCnt.merge(oldPrice, -1, Integer::sum);
            if (priceCnt.get(oldPrice) == 0) priceCnt.remove(oldPrice);
        }
        timeToPrice.put(timestamp, price);
        priceCnt.merge(price, 1, Integer::sum);
    }

    public int current() {
        return timeToPrice.get(latestTime);
    }

    public int maximum() {
        return priceCnt.lastKey();
    }

    public int minimum() {
        return priceCnt.firstKey();
    }
}
```

## 复杂度分析

- 时间复杂度：update/maximum/minimum O(log n)，current O(1)
- 空间复杂度：O(n)

## 关键点总结

1. TreeMap 天然有序，`lastKey()` 和 `firstKey()` 直接获取最大最小值
2. 更新时需先移除旧价格的计数，再插入新价格
3. 计数归零时从 TreeMap 中删除该键，避免脏数据
