## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的**连续子数组**的个数。

**示例 1：**
```
输入：nums = [1,1,1], k = 2
输出：2
```

**示例 2：**
```
输入：nums = [1,2,3], k = 3
输出：2
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 解题思路

这是一道经典的**前缀和 + 哈希表**问题。

核心思想：
- 如果 `prefixSum[j] - prefixSum[i] = k`，说明 `nums[i+1:j+1]` 的和为 k
- 转化为：`prefixSum[i] = prefixSum[j] - k`
- 使用哈希表记录每个前缀和出现的次数

## Java 代码实现

### 方法一：前缀和 + 哈希表（推荐）⭐

```java
import java.util.*;

class Solution {
    public int subarraySum(int[] nums, int k) {
        // 哈希表记录前缀和出现的次数
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);  // 前缀和为 0 出现 1 次

        int prefixSum = 0;
        int count = 0;

        for (int num : nums) {
            prefixSum += num;
            // 查找是否存在 prefixSum - k
            count += prefixCount.getOrDefault(prefixSum - k, 0);
            // 更新当前前缀和的次数
            prefixCount.put(prefixSum, prefixCount.getOrDefault(prefixSum, 0) + 1);
        }

        return count;
    }
}
```

### 方法二：暴力解法（用于理解）

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        // 暴力枚举所有子数组
        int count = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            int currentSum = 0;
            for (int j = i; j < n; j++) {
                currentSum += nums[j];
                if (currentSum == k) count++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

**方法一（哈希表）：**
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(n)，哈希表最多存储 n 个不同的前缀和

**方法二（暴力）：**
- **时间复杂度**：O(n²)，双重循环
- **空间复杂度**：O(1)

## 图解示例

以 `nums = [1, 2, 3], k = 3` 为例：

```
索引：    0  1  2
nums:    [1, 2, 3]
前缀和：  1  3  6

哈希表变化：
初始：{0: 1}
i=0, sum=1: count += map[1-3=−2] = 0, map = {0:1, 1:1}
i=1, sum=3: count += map[3-3=0] = 1, map = {0:1, 1:1, 3:1}
i=2, sum=6: count += map[6-3=3] = 1, map = {0:1, 1:1, 3:1, 6:1}

结果：count = 2
子数组：[1,2] 和 [3]
```

## 关键点总结

1. **前缀和思想**：prefixSum[j] - prefixSum[i] = sum(nums[i+1:j+1])
2. **哈希表优化**：将 O(n²) 优化到 O(n)
3. **初始化**：`prefixCount.put(0, 1)` 表示空前缀
4. **边遍历边更新**：先查找再更新，避免重复计数
5. **负数处理**：算法支持负数和 0

## 易错点

1. **初始化**：必须设置 `prefixCount.put(0, 1)`
2. **更新顺序**：先查找 `prefixSum - k`，再更新 `prefixSum`
3. **累加计数**：`count += prefixCount.get(prefixSum - k)`，不是 `+= 1`
4. **负数情况**：数组包含负数时，前缀和可能相同
5. **理解前缀和**：`prefixSum - k` 对应的是起点位置
