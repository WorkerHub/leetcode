## 题目描述

给定整数数组 `nums`，将其分为两个非空连续子数组，返回两部分之和都是偶数的划分数目。

## Java 代码实现

```java
class Solution {
    public int countPartitions(int[] nums) {
        long total = 0;
        for (int x : nums) total += x;
        // 总和为奇数时不存在合法划分
        if (total % 2 != 0) return 0;

        // 统计前缀和为偶数的划分点数（不含最后一个元素，保证后缀非空）
        int count = 0;
        long prefix = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            prefix += nums[i];
            if (prefix % 2 == 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 两部分和都为偶数等价于总和为偶数
2. 总和奇数时直接返回 0
3. 只需统计前缀和为偶数的划分点数
