## 题目描述

给你 n×n 二进制矩阵 `grid`（1 为贼），从左上角走到右下角，路径安全系数为路径上各格子到最近贼的最小距离，返回所有路径中安全系数的最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximumSafenessFactor(List<List<Integer>> grid) {
        int n = grid.size();
        int[][] dist = new int[n][n];
        for (int[] row : dist) Arrays.fill(row, -1);
        Deque<int[]> dq = new ArrayDeque<>();

        // 多源 BFS：计算每个格子到最近贼的距离
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid.get(i).get(j) == 1) {
                    dist[i][j] = 0;
                    dq.offer(new int[]{i, j});
                }
            }
        }
        int[] dx = {0, 0, 1, -1}, dy = {1, -1, 0, 0};
        while (!dq.isEmpty()) {
            int[] cur = dq.poll();
            for (int d = 0; d < 4; d++) {
                int nx = cur[0] + dx[d], ny = cur[1] + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < n && dist[nx][ny] == -1) {
                    dist[nx][ny] = dist[cur[0]][cur[1]] + 1;
                    dq.offer(new int[]{nx, ny});
                }
            }
        }

        // 最大最小路径：优先队列（最大堆按安全系数）
        // heap: [-safe, x, y]
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        pq.offer(new int[]{dist[0][0], 0, 0});
        boolean[][] visited = new boolean[n][n];
        visited[0][0] = true;

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int safe = cur[0], x = cur[1], y = cur[2];
            if (x == n - 1 && y == n - 1) return safe;
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < n && !visited[nx][ny]) {
                    visited[nx][ny] = true;
                    pq.offer(new int[]{Math.min(safe, dist[nx][ny]), nx, ny});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 log n)，BFS O(n^2)，Dijkstra O(n^2 log n)
- 空间复杂度：O(n^2)

## 关键点总结

1. 多源 BFS 计算各格子到最近贼的距离
2. Dijkstra 最大最小路径：优先队列按安全系数降序，维护路径最小安全系数最大化
