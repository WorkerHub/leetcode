## 题目描述

给定 4 位数字组成的数组，找到能表示的最大 24 小时制时间 "HH:MM"。无法构成则返回空字符串。

## 解题思路

枚举所有排列（4! = 24 种），验证是否为合法时间，记录最大值。

## Java 代码实现

```java
class Solution {
    public String largestTimeFromDigits(int[] arr) {
        int maxTime = -1;

        // 枚举所有排列
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                if (j == i) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == i || k == j) continue;
                    int l = 6 - i - j - k; // 剩余索引
                    int hour = arr[i] * 10 + arr[j];
                    int minute = arr[k] * 10 + arr[l];
                    if (hour < 24 && minute < 60) {
                        maxTime = Math.max(maxTime, hour * 60 + minute);
                    }
                }
            }
        }

        if (maxTime == -1) return "";
        return String.format("%02d:%02d", maxTime / 60, maxTime % 60);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，固定 24 种排列
- **空间复杂度**：O(1)

## 关键点总结

1. **暴力枚举**：只有 24 种排列，直接穷举
2. **合法性检查**：小时 < 24，分钟 < 60
3. **格式化输出**：补零显示
