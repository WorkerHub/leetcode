## 题目描述

给你整数数组 `nums` 和整数 `k`，恰好选一个元素将其乘以 `2^k`（左移 k 位），返回操作后所有元素按位 OR 的最大值。

## Java 代码实现

```java
class Solution {
    public long maximumOr(int[] nums, int k) {
        int n = nums.length;
        // 前缀 OR：prefix[i] = nums[0] | ... | nums[i-1]
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] | nums[i];
        // 后缀 OR：suffix[i] = nums[i+1] | ... | nums[n-1]
        long[] suffix = new long[n + 1];
        for (int i = n - 1; i >= 0; i--) suffix[i] = suffix[i + 1] | nums[i];

        long ans = 0;
        for (int i = 0; i < n; i++) {
            // 选择将 nums[i] 左移 k 位
            long result = prefix[i] | ((long) nums[i] << k) | suffix[i + 1];
            ans = Math.max(ans, result);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 预计算前缀 OR 和后缀 OR，枚举每个元素作为被左移的选择
2. 用 `long` 防止左移后溢出
