## 题目描述

有一块 `m x n` 的蛋糕，沿水平或垂直线切割有对应成本，最终切成 `1x1` 小块，返回最小总成本。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumCost(int m, int n, int[] horizontalCut, int[] verticalCut) {
        // 降序排序，优先执行成本高的切割
        Arrays.sort(horizontalCut);
        Arrays.sort(verticalCut);

        int hSegs = 1, vSegs = 1; // 当前水平/垂直段数
        int cost = 0;
        int i = horizontalCut.length - 1, j = verticalCut.length - 1;

        while (i >= 0 || j >= 0) {
            int hVal = i >= 0 ? horizontalCut[i] : -1;
            int vVal = j >= 0 ? verticalCut[j] : -1;

            if (hVal >= vVal) {
                // 水平切割，成本乘以当前垂直段数
                cost += hVal * vSegs;
                hSegs++;
                i--;
            } else {
                // 垂直切割，成本乘以当前水平段数
                cost += vVal * hSegs;
                vSegs++;
                j--;
            }
        }
        return cost;
    }
}
```

## 复杂度分析

- 时间复杂度：O((m + n) log(m + n))，排序
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：优先做成本高的切割，此时乘数（已有的段数）还小
2. 每次水平切割的实际成本 = 切割值 × 当前垂直段数
3. 维护水平段数和垂直段数，每次切割后对应段数加 1
