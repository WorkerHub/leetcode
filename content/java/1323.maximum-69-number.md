## 题目描述

给你一个仅由数字 `6` 和 `9` 组成的正整数 `num`。

你最多只能翻转一位数字，将 `6` 变成 `9`，或者把 `9` 变成 `6`。

请返回你可以得到的最大数字。

**示例 1：**

```
输入：num = 9669
输出：9969
```

**示例 2：**

```
输入：num = 9996
输出：9999
解释：将最后一位从 6 变到 9，得到最大数
```

**示例 3：**

```
输入：num = 9999
输出：9999
解释：不需要改变，已经是最大值
```

**提示：**

- `1 <= num <= 10^4`
- `num` 每位上的数字仅为 `6` 或 `9`

## 解题思路

**贪心策略：将最高位的 6 改为 9**

要使数字最大，应该将**最高位**的 `6` 改为 `9`（因为高位数字权重更大）。

如果没有 `6`（全是 `9`），则不需要任何改变。

**为什么是最高位的 6？**

数字越高位，权重（位值）越大。例如 `6669` 中：
- 将第 1 位 6 改为 9：9669（增加 3000）
- 将第 2 位 6 改为 9：6969（增加 300）
- 将第 3 位 6 改为 9：6699（增加 30）

显然改最高位增益最大。

## Java 代码实现

### 方法一：字符串替换（推荐，最简洁）

```java
class Solution {
    public int maximum69Number(int num) {
        // 将数字转为字符串，把第一个 '6' 替换为 '9'，再转回整数
        return Integer.parseInt(String.valueOf(num).replaceFirst("6", "9"));
    }
}
```

### 方法二：字符串查找（明确逻辑）

```java
class Solution {
    public int maximum69Number(int num) {
        String s = String.valueOf(num);
        // 找第一个 '6' 的位置
        int idx = s.indexOf('6');
        if (idx == -1) {
            // 没有 '6'，直接返回原数
            return num;
        }
        // 将该位置的 '6' 替换为 '9'
        StringBuilder sb = new StringBuilder(s);
        sb.setCharAt(idx, '9');
        return Integer.parseInt(sb.toString());
    }
}
```

### 方法三：数学方法（不转字符串）

```java
class Solution {
    public int maximum69Number(int num) {
        // 找到最高位 6 的位值（10^k）
        int temp = num;
        int pos = -1; // 记录最高位 6 的位置（以 10 的幂次表示）
        int p = 1;    // 当前位的位值
        
        while (temp > 0) {
            int digit = temp % 10;
            if (digit == 6) {
                pos = p; // 更新为当前 6 所在的位值（越高位 p 越大）
            }
            temp /= 10;
            p *= 10;
        }
        
        // 将该位的 6 变为 9，差值为 3
        if (pos != -1) {
            return num + 3 * pos;
        }
        return num;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(d)，d 为数字的位数（最多 5 位）
- **空间复杂度**：O(d)，字符串方法需要 O(d) 空间；数学方法 O(1)

## 关键点总结

1. 贪心思想：改变最高位的 6 收益最大
2. Java 的 `String.replaceFirst("6", "9")` 只替换第一次出现的 '6'，对应最高位
3. 将 6 变为 9 相当于加上 `3 * 该位的位值`

## 易错点

1. **只能改一位**：题目最多改一位，不能把所有 6 都改成 9
2. **9 不需要改**：9 已经是最大数字，将 9 改为 6 只会变小
3. **replaceFirst vs replace**：Java 中 `replace` 会替换所有，要用 `replaceFirst` 只替换第一个
