## 题目描述

给你 `m x n` 矩阵 `grid`、整数数组 `limits`（长度 m）和整数 `k`。第 i 行最多选 `limits[i]` 个元素，总共最多选 k 个。返回选取元素的最大总和。

## 解题思路

贪心：对每行取前 `limits[i]` 个最大元素作为候选，然后从所有候选中取最大的 k 个求和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxSum(int[][] grid, int[] limits, int k) {
        List<Integer> candidates = new ArrayList<>();

        for (int i = 0; i < grid.length; i++) {
            int[] row = grid[i].clone();
            Arrays.sort(row);
            int lim = limits[i];
            // 取该行最大的 lim 个（从末尾取）
            for (int j = row.length - 1; j >= row.length - lim; j--) {
                candidates.add(row[j]);
            }
        }

        // 从所有候选中选最大的 k 个
        candidates.sort(Collections.reverseOrder());
        long total = 0;
        for (int i = 0; i < Math.min(k, candidates.size()); i++) {
            total += candidates.get(i);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n log n + C log C)，C = sum(limits[i])
- 空间复杂度：O(C)

## 关键点总结

1. 每行独立取最大的 limits[i] 个元素作为候选
2. 全局从所有候选中贪心选最大的 k 个
3. 两步贪心：先行内贪心，再全局贪心
