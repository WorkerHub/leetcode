## 题目描述

给你无向图（n 个节点、可能有重复边）和查询数组，对每次查询返回满足「与 a 或 b 相连的边数严格大于 queries[j]」的点对 (a < b) 数目。

## 解题思路

对点对 (a, b)，与 a 或 b 相连的边数 = `deg[a] + deg[b] - cnt(a,b)`（重复边被计两次需减去）。

**双指针 + 修正**：
1. 排序度数数组，双指针统计 `deg[a] + deg[b] > q` 的点对数
2. 遍历所有重复边：若原来满足（`> q`）但减去重边后不满足（`<= q`），则多算了，减 1

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countPairs(int n, int[][] edges, int[] queries) {
        int[] deg = new int[n + 1];
        // 统计重复边数量
        Map<Integer, Integer> edgeCnt = new HashMap<>();

        for (int[] e : edges) {
            int u = e[0], v = e[1];
            deg[u]++;
            deg[v]++;
            int key = Math.min(u, v) * 20001 + Math.max(u, v);
            edgeCnt.merge(key, 1, Integer::sum);
        }

        // 排序后的度数数组
        int[] sortedDeg = Arrays.copyOfRange(deg, 1, n + 1);
        Arrays.sort(sortedDeg);

        int[] ans = new int[queries.length];

        for (int qi = 0; qi < queries.length; qi++) {
            int q = queries[qi];
            // 双指针统计 sortedDeg[i] + sortedDeg[j] > q 的点对数
            int total = 0;
            int left = 0, right = n - 1;
            while (left < right) {
                if (sortedDeg[left] + sortedDeg[right] > q) {
                    total += right - left; // left 与 left+1..right 均满足
                    right--;
                } else {
                    left++;
                }
            }
            // 修正重复边的影响
            for (Map.Entry<Integer, Integer> entry : edgeCnt.entrySet()) {
                int key = entry.getKey();
                int cnt = entry.getValue();
                int u = key / 20001, v = key % 20001;
                // 原来满足但减去重边后不满足 → 多算了一对，减 1
                if (deg[u] + deg[v] > q && deg[u] + deg[v] - cnt <= q) {
                    total--;
                }
            }
            ans[qi] = total;
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + |edges|) * |queries|)
- **空间复杂度**：O(n + |edges|)

## 关键点总结

1. 与 a 或 b 相连的边数 = `deg[a] + deg[b] - cnt(a,b)`
2. 先双指针统计度数之和超阈值的点对，再修正重复边的误差
3. 用 `min*20001+max` 编码无向边的 key
