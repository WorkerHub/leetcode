## 题目描述

给你一个双向链表的头节点，将其转换为数组，按从头到尾的顺序返回。

## 解题思路

从头节点开始沿 `next` 指针顺序遍历，将每个节点的值加入列表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] toArray(Node root) {
        List<Integer> list = new ArrayList<>();
        // 沿 next 指针顺序遍历
        Node curr = root;
        while (curr != null) {
            list.add(curr.val);
            curr = curr.next;
        }
        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 双向链表从头到尾沿 next 指针遍历即可
2. 不需要使用 prev 指针
