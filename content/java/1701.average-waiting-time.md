## 题目描述

`customers[i] = [arrival, cookTime]`，厨师按顾客到达顺序服务（同时只服务一人）。等待时间 = 完成时间 - 到达时间，返回平均等待时间。

## 解题思路

**模拟：** 维护厨师空闲时间 `freeTime`，每位顾客开始服务时间 = `max(freeTime, arrival)`，完成时间 = 开始 + cookTime，累计等待时间。

## Java 代码实现

```java
class Solution {
    public double averageWaitingTime(int[][] customers) {
        long totalWait = 0;
        long freeTime = 0;
        for (int[] c : customers) {
            long start = Math.max(freeTime, c[0]);
            long finish = start + c[1];
            totalWait += finish - c[0]; // 等待时间 = 完成时间 - 到达时间
            freeTime = finish;
        }
        return (double) totalWait / customers.length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 等待时间 = 完成时间 - 到达时间（包含服务时间）
2. 开始服务时间 = `max(厨师空闲时间, 顾客到达时间)`
