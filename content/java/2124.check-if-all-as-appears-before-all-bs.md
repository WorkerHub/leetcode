## 题目描述

给定仅由'a'和'b'组成的字符串s，判断是否所有'a'都出现在所有'b'之前。

## 解题思路

等价于字符串中不包含子串"ba"。若出现b后面跟a则不合法。

## Java 代码实现

```java
class Solution {
    public boolean checkString(String s) {
        return !s.contains("ba");
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **等价条件**：不包含"ba"子串
2. **一行解决**：利用String.contains方法
3. **边界**：全a或全b都合法
