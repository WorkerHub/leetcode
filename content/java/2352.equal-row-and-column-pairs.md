## 题目描述

给你 n×n 矩阵 `grid`，返回满足行 i 与列 j 完全相同（顺序也相同）的行列对 (i, j) 的数目。

## 解题思路

哈希表计数：将每一行转为字符串作为键统计出现次数，再遍历每列转为相同格式的字符串查询计数，累加匹配次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int equalPairs(int[][] grid) {
        int n = grid.length;
        Map<String, Integer> rowCount = new HashMap<>();

        // 统计每行出现次数（用逗号分隔的字符串作为键）
        for (int[] row : grid) {
            String key = Arrays.toString(row);
            rowCount.merge(key, 1, Integer::sum);
        }

        int ans = 0;
        // 遍历每列，构建列字符串查询
        for (int j = 0; j < n; j++) {
            int[] col = new int[n];
            for (int i = 0; i < n; i++) col[i] = grid[i][j];
            ans += rowCount.getOrDefault(Arrays.toString(col), 0);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)（构建行/列字符串各 O(n)，共 2n 次）
- **空间复杂度**：O(n^2)

## 关键点总结

1. 行和列都转为字符串后用哈希表匹配，避免逐元素比较。
2. `Arrays.toString` 生成格式如 `[1, 2, 3]`，行列转换后格式一致可直接比较。
3. 列下标 j 固定，行下标 i 变化：`grid[i][j]`。
