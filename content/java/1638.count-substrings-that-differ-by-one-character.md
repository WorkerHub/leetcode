## 题目描述

给你两个字符串 `s` 和 `t`，找出 `s` 的非空子串和 `t` 的非空子串中，**恰好只有 1 个字符不同**的字符串对的数目。

**提示：** `1 <= s.length, t.length <= 100`

## 解题思路

**枚举不同字符位置：** 对每对 `(i, j)`，若 `s[i] != t[j]`，向两侧扩展相同字符。向左扩展 `left` 步，向右扩展 `right` 步，以 (i,j) 为唯一不同字符的子串数 = `(left+1) * (right+1)`。

## Java 代码实现

```java
class Solution {
    public int countSubstrings(String s, String t) {
        int m = s.length(), n = t.length();
        int ans = 0;

        // 枚举 s[i] 和 t[j] 作为唯一不同的字符位置
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (s.charAt(i) != t.charAt(j)) {
                    // 向左扩展：s[i-k..i-1] == t[j-k..j-1]
                    int left = 0;
                    while (i - left - 1 >= 0 && j - left - 1 >= 0
                            && s.charAt(i - left - 1) == t.charAt(j - left - 1)) {
                        left++;
                    }
                    // 向右扩展：s[i+1..i+k] == t[j+1..j+k]
                    int right = 0;
                    while (i + right + 1 < m && j + right + 1 < n
                            && s.charAt(i + right + 1) == t.charAt(j + right + 1)) {
                        right++;
                    }
                    // 以 (i,j) 为唯一不同字符的子串数
                    ans += (left + 1) * (right + 1);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n * min(m,n))
- **空间复杂度**：O(1)

## 关键点总结

1. 枚举唯一不同字符位置 (i, j)，向两侧扩展相同字符
2. 子串数 = (left+1) * (right+1)，+1 是因为包含只有该不同字符的子串
3. 只有 `s[i] != t[j]` 时才作为唯一不同位置
