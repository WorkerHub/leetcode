## 题目描述

记事本上只有一个 'A'，每次可以 Copy All 或 Paste，求输出恰好 n 个 'A' 的最少操作次数。

**示例：**
```
输入：n = 3
输出：3（Copy All, Paste, Paste）
```

## 解题思路

质因数分解：最小操作数 = n 的所有质因数之和。

## Java 代码实现

```java
class Solution {
    public int minSteps(int n) {
        int result = 0;
        int factor = 2;

        while (n > 1) {
            while (n % factor == 0) {
                result += factor;
                n /= factor;
            }
            factor++;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(√n)
- **空间复杂度**：O(1)

## 关键点总结

1. **质因数分解**：操作次数 = 质因数之和
2. **直觉**：n=p×q 时，先做出 p 个再复制 q 次
3. **从小因子开始**：保证每次都是质因子
