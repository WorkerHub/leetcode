## 题目描述

给定 `n` 个节点和双向带权边列表 `edges`，求从节点 `0` 到节点 `n-1` 的最短路径，若不可达返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minCostPath(int n, int[][] edges) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]}); // 双向边
        }

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            if (u == n - 1) return (int) d;
            for (int[] nei : graph[u]) {
                long nd = dist[u] + nei[1];
                if (nd < dist[nei[0]]) {
                    dist[nei[0]] = nd;
                    pq.offer(new long[]{nd, nei[0]});
                }
            }
        }

        return dist[n - 1] == Long.MAX_VALUE ? -1 : (int) dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，Dijkstra
- 空间复杂度：O(n + m)

## 关键点总结

1. 双向边在邻接表中需要添加两个方向
2. 使用 `long` 防止路径权重累加溢出
3. 不可达时返回 -1
