## 题目描述

给定整数数组 `nums` 和整数 `k`，若子序列满足相邻元素之比不小于 `k`（即 `a[i+1] >= a[i] * k`），则为美丽子序列。返回所有美丽子序列的数量，结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countBeautifulSubsequences(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        // TreeMap：值 -> 以该值结尾的美丽子序列数量
        TreeMap<Long, Long> map = new TreeMap<>();
        long total = 0;

        for (int num : nums) {
            long v = num;
            // 找所有 prev <= v / k 的 dp 值之和
            long threshold = v / k;
            long prefixSum = 0;
            // 遍历 map 中所有键 <= threshold 的条目
            for (Map.Entry<Long, Long> e : map.headMap(threshold, true).entrySet()) {
                prefixSum = (prefixSum + e.getValue()) % MOD;
            }
            long dpV = (prefixSum + 1) % MOD;
            total = (total + dpV) % MOD;
            map.merge(v, dpV, (a, b) -> (a + b) % MOD);
        }

        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n² log n) 最坏情况（k=1 时所有前缀都需遍历）
- 空间复杂度：O(n)，TreeMap 存储

## 关键点总结

1. 条件 `a[i+1] >= a[i] * k` 等价于前驱值 `<= v / k`
2. 排序后保证只向后扩展，避免顺序问题
3. TreeMap 的 `headMap` 方法便于查询小于等于阈值的所有键
