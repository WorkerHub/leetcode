## 题目描述

加权无向图共 n 个节点，定义 `distanceToLastNode(x)` 为节点 x 到节点 n 的最短路径长度。**受限路径**要求路径上相邻节点 (u, v) 满足 `dist[u] > dist[v]`。返回从节点 1 到节点 n 的受限路径数目，对 10^9+7 取余。

## 解题思路

1. 从节点 n 出发用 Dijkstra 计算所有节点到 n 的最短距离 `dist[]`
2. 受限路径等价于沿 dist 递减方向前进
3. 按 dist 升序排序所有节点，设 `dp[u]` 为从 u 到 n 的受限路径数，`dp[n]=1`，按序传播

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countRestrictedPaths(int n, int[][] edges) {
        final int MOD = 1_000_000_007;
        // 建邻接表
        List<int[]>[] graph = new List[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        // Dijkstra 从节点 n 出发
        long[] dist = new long[n + 1];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[n] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, n});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (int[] nb : graph[u]) {
                int v = nb[0], w = nb[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new long[]{dist[v], v});
                }
            }
        }

        // 按 dist 升序排序节点，从 n（dist=0）向外传播路径数
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i + 1;
        Arrays.sort(order, (a, b) -> Long.compare(dist[a], dist[b]));

        long[] dp = new long[n + 1];
        dp[n] = 1;

        for (int u : order) {
            for (int[] nb : graph[u]) {
                int v = nb[0];
                // dist[u] < dist[v]：从 v 可以经 u 到达 n
                if (dist[u] < dist[v]) {
                    dp[v] = (dp[v] + dp[u]) % MOD;
                }
            }
        }

        return (int) dp[1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)
- **空间复杂度**：O(V + E)

## 关键点总结

1. Dijkstra 的源点是节点 n，不是节点 1
2. 受限路径条件：`dist[u] > dist[v]`（严格大于）
3. 按 dist 升序排列节点，从 dist 最小的（n）开始向外传播
