## 题目描述

将正负数量相等的数组重排，使正数在偶数下标、负数在奇数下标，且各自保持相对顺序。

## 解题思路

双指针：pos指向下一个正数位置（0,2,4,...），neg指向下一个负数位置（1,3,5,...），遍历原数组填入。

## Java 代码实现

```java
class Solution {
    public int[] rearrangeArray(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        int pos = 0; // 正数放偶数下标
        int neg = 1; // 负数放奇数下标
        
        for (int x : nums) {
            if (x > 0) {
                result[pos] = x;
                pos += 2;
            } else {
                result[neg] = x;
                neg += 2;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **正数偶数位，负数奇数位**：各自保持相对顺序
2. **双指针法**：pos和neg分别步长为2递增
3. **题目保证正负数量相等**：无需额外判断
