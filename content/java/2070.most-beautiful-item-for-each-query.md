## 题目描述

给定物品数组 items[i] = [price, beauty]，对每个查询 queries[j] 找出价格不超过 queries[j] 的最大美丽值，不存在则为 0。

## 解题思路

按价格排序后构建前缀最大美丽值数组，对每个查询二分查找价格 <= query 的最后位置，取对应前缀最大美丽值。

## Java 代码实现

### 方法一：排序 + 前缀最大 + 二分（推荐）

```java
import java.util.Arrays;

class Solution {
    public int[] maximumBeauty(int[][] items, int[] queries) {
        Arrays.sort(items, (a, b) -> a[0] - b[0]);
        int n = items.length;
        int[] prices = new int[n], maxBeauty = new int[n];
        int curMax = 0;
        for (int i = 0; i < n; i++) {
            curMax = Math.max(curMax, items[i][1]);
            prices[i] = items[i][0];
            maxBeauty[i] = curMax;
        }

        int[] res = new int[queries.length];
        for (int j = 0; j < queries.length; j++) {
            // 二分查找 prices <= queries[j] 的最后位置
            int lo = 0, hi = n - 1, pos = -1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (prices[mid] <= queries[j]) { pos = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            res[j] = pos >= 0 ? maxBeauty[pos] : 0;
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后构建前缀最大美丽值，每个位置存储"到此价格的最大美丽值"
2. 二分查找找价格 <= query 的最右位置
3. 查询结果独立，不相互影响
