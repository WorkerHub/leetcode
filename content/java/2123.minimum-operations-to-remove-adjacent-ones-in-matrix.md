## 题目描述

给定二进制矩阵，每次操作将一个1变0，求使矩阵中不存在相邻1的最少操作次数。

## 解题思路

棋盘染色后相邻1构成二分图。由König定理，最少操作数=二分图最大匹配数。用匈牙利算法求解。

## Java 代码实现

```java
class Solution {
    private int m, n;
    private int[][] grid;
    private int[] matchBlack; // 黑色节点的匹配对象（编码为一维索引）
    private int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
    
    public int minimumOperations(int[][] grid) {
        this.m = grid.length;
        this.n = grid[0].length;
        this.grid = grid;
        matchBlack = new int[m * n];
        Arrays.fill(matchBlack, -1);
        
        int result = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 只对白色节点（(i+j)%2==0）且值为1的尝试增广
                if (grid[i][j] == 1 && (i + j) % 2 == 0) {
                    boolean[] visited = new boolean[m * n];
                    if (dfs(i, j, visited)) {
                        result++;
                    }
                }
            }
        }
        return result;
    }
    
    private boolean dfs(int i, int j, boolean[] visited) {
        for (int[] d : dirs) {
            int ni = i + d[0], nj = j + d[1];
            if (ni < 0 || ni >= m || nj < 0 || nj >= n) continue;
            if (grid[ni][nj] != 1) continue;
            int idx = ni * n + nj;
            if (visited[idx]) continue;
            visited[idx] = true;
            if (matchBlack[idx] == -1 || dfs(matchBlack[idx] / n, matchBlack[idx] % n, visited)) {
                matchBlack[idx] = i * n + j;
                return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(V * E)，V为1的个数，E为相邻1的对数
- **空间复杂度**：O(V)

## 关键点总结

1. **棋盘染色构成二分图**：相邻格子奇偶性不同
2. **König定理**：最少删除数=最大匹配数
3. **匈牙利算法**：对每个白色1节点尝试找增广路
