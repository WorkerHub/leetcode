## 题目描述

给你整数数组 `coins` 和整数 `target`，可向数组添加任意正整数面值的硬币，返回能凑出 1 到 `target` 所有整数所需添加的最少硬币数。

## 解题思路

贪心：维护当前可达范围 `[1, reach]`（初始 reach=0），排序后遍历 coins。若当前硬币 `c <= reach+1` 则扩展范围；否则存在空缺，贪心添加面值 `reach+1` 的硬币（最高效填补），reach 变为 `2*reach+1`，直到 reach >= target。

## Java 代码实现

```java
class Solution {
    public int minimumAddedCoins(int[] coins, int target) {
        Arrays.sort(coins);
        long reach = 0; // 当前可凑出 [1, reach] 的所有整数
        int ans = 0, i = 0;

        while (reach < target) {
            if (i < coins.length && coins[i] <= reach + 1) {
                // 当前硬币可扩展 reach
                reach += coins[i++];
            } else {
                // 存在空缺，添加面值 reach+1
                reach = reach * 2 + 1;
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + log target)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心维护可达范围 `[1, reach]`，遇到空缺就添加 `reach+1`
2. 添加 `reach+1` 后 reach 变为 `2*reach+1`，最高效地填补空缺
3. reach 可能溢出 int，需使用 long
