## 题目描述

将数组每个元素替换为其右侧最大元素，最后一个元素替换为 -1。

**示例：**
```
输入：arr = [17,18,5,4,6,1]
输出：[18,6,6,6,1,-1]
```

## 解题思路

从右往左遍历，维护右侧最大值，依次替换。

## Java 代码实现

```java
class Solution {
    public int[] replaceElements(int[] arr) {
        int maxRight = -1;
        for (int i = arr.length - 1; i >= 0; i--) {
            int temp = arr[i];
            arr[i] = maxRight;
            maxRight = Math.max(maxRight, temp);
        }
        return arr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆序遍历**：从右到左维护最大值
2. **先替换后更新**：保存当前值后替换，再更新最大值
3. **原地修改**：不需要额外空间
