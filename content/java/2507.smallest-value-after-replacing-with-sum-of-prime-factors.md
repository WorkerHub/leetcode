## 题目描述

给你正整数 `n`，反复将 `n` 替换为其质因数之和（含重复），直到无法再减小，返回最小值。

## 解题思路

模拟：每次对 `n` 进行质因数分解求和，若新值与旧值相同（即 `n` 为质数）则停止，否则继续替换。

## Java 代码实现

```java
class Solution {
    public int smallestValue(int n) {
        while (true) {
            int sum = primeFactorSum(n);
            if (sum == n) return n; // n 已是质数
            n = sum;
        }
    }

    private int primeFactorSum(int x) {
        int total = 0;
        for (int d = 2; (long) d * d <= x; d++) {
            while (x % d == 0) {
                total += d;
                x /= d;
            }
        }
        if (x > 1) total += x; // 剩余质因数
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(√n × log n)，每次质因数分解 O(√n)，迭代 O(log n) 次
- **空间复杂度**：O(1)

## 关键点总结

1. 质因数之和含重复因数（如 4 → 2+2=4，本身为质数停止）
2. 终止条件：新值等于旧值（n 已是质数）
3. 每次替换后 n 迅速减小，迭代次数极少
