## 题目描述

三辆垃圾车分别收集金属('M')、纸('P')、玻璃('G')，每辆车从房子 0 出发只向右行驶，收集每单位垃圾需 1 分钟，行驶时间由 `travel` 数组给出。返回收集所有垃圾的最少总时间。

## 解题思路

收集时间 = 所有垃圾字符总数。行驶时间 = 每辆车行驶到最后一个含该类垃圾的房子的累计 travel 之和。预计算 travel 前缀和，三辆车独立计算。

## Java 代码实现

```java
class Solution {
    public int garbageCollection(String[] garbage, int[] travel) {
        int n = garbage.length;
        // 计算 travel 前缀和
        int[] prefix = new int[n]; // prefix[i] = travel[0]+...+travel[i-1]
        for (int i = 1; i < n; i++) prefix[i] = prefix[i - 1] + travel[i - 1];

        int total = 0;
        // 分别处理三种垃圾
        for (char type : new char[]{'M', 'P', 'G'}) {
            int last = 0; // 最后含该类垃圾的房子下标
            int count = 0;
            for (int i = 0; i < n; i++) {
                for (char c : garbage[i].toCharArray()) {
                    if (c == type) {
                        count++;
                        last = i;
                    }
                }
            }
            total += count + prefix[last]; // 收集时间 + 行驶到 last 的时间
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L)，L 为 garbage 字符串平均长度
- **空间复杂度**：O(n)

## 关键点总结

1. 行驶时间 = `prefix[last]`（travel[0]+...+travel[last-1]），而非 `travel[last]`。
2. 三辆车独立计算，互不影响。
3. 若某类垃圾只在房子 0，行驶时间为 `prefix[0]=0`。
