## 题目描述

给你正整数数组 nums，每次可删除 2 个或 3 个相等元素，返回使数组变空的最少操作次数，若不可能返回 -1。

## 解题思路

统计每种元素出现次数 cnt：出现 1 次则无法删除返回 -1；否则最少操作数 = `ceil(cnt / 3)`（等价于 `(cnt + 2) / 3`）。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) cnt.merge(x, 1, Integer::sum);

        int ops = 0;
        for (int c : cnt.values()) {
            if (c == 1) return -1; // 无法删除单个元素
            ops += (c + 2) / 3;   // ceil(c / 3)
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)，k 为不同元素数

## 关键点总结

1. 每种元素独立处理，出现 1 次直接返回 -1
2. 最少操作数公式：`ceil(c / 3) = (c + 2) / 3`
3. 总操作数是各元素操作数之和
