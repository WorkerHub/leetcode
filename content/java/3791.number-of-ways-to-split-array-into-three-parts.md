## 题目描述

给定整数数组 `nums`，将其分为三个非空连续子数组，使第一部分的和 ≤ 第二部分的和 ≤ 第三部分的和，返回满足条件的分割方案数（结果对 `10^9+7` 取模）。

## Java 代码实现

```java
class Solution {
    public int waysToSplit(int[] nums) {
        int n = nums.length;
        final int MOD = 1_000_000_007;

        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];
        long total = prefix[n];

        long ans = 0;
        int jLo = 1, jHi = 1;

        for (int i = 1; i < n - 1; i++) {
            long sum1 = prefix[i];
            // j 的下界：sum2 >= sum1 => prefix[j] - prefix[i] >= sum1
            jLo = Math.max(jLo, i + 1);
            while (jLo < n - 1 && prefix[jLo] - prefix[i] < sum1) jLo++;

            // j 的上界：sum2 <= sum3 => 2*(prefix[j]-prefix[i]) <= total-prefix[i]
            jHi = Math.max(jHi, jLo);
            while (jHi < n - 1 && 2 * (prefix[jHi] - prefix[i]) <= total - prefix[i]) jHi++;
            // jHi 是第一个不满足的位置，有效上界是 jHi - 1

            if (jLo <= jHi - 1) ans = (ans + jHi - jLo) % MOD;
        }

        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，双指针单调递增
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 前缀和预处理，快速计算区间和
2. 双指针 `jLo` 和 `jHi` 均单调递增，总体 O(n)
3. `jHi` 指向第一个不满足的位置，有效方案数为 `jHi - jLo`
