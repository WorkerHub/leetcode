## 题目描述

若整数 x 中每个出现的数字 d 恰好出现 d 次，则称 x 为数值平衡数。给定 n（<= 10^6），返回严格大于 n 的最小数值平衡数。

## 解题思路

从 n+1 开始逐个检查：统计各数字出现次数，验证每个出现的数字 d 是否恰好出现 d 次。n <= 10^6 时答案范围较小，暴力可行。

## Java 代码实现

### 方法一：逐个检查（推荐）

```java
class Solution {
    public int nextBeautifulNumber(int n) {
        int x = n + 1;
        while (!isBalanced(x)) x++;
        return x;
    }

    private boolean isBalanced(int x) {
        int[] cnt = new int[10];
        int tmp = x;
        while (tmp > 0) {
            cnt[tmp % 10]++;
            tmp /= 10;
        }
        for (int d = 0; d <= 9; d++) {
            if (cnt[d] != 0 && cnt[d] != d) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(D * k)，D 为到答案的距离，k 为数字位数
- 空间复杂度：O(1)

## 关键点总结

1. 平衡数条件：每个出现的数字 d 恰好出现 d 次（0 不能出现）
2. n <= 10^6，答案不超过 1224444444，暴力可行
