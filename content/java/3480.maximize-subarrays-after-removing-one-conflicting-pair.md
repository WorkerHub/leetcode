## 题目描述

给你整数 `n` 和冲突对数组 `conflictingPairs`，"好子数组"不包含任意两个互相冲突的下标。可删除一对冲突，返回好子数组数量的最大值。

## 解题思路

对每个右端点 r，合法左端点的下界 `minLeft[r]` = 所有右端点 <= r 的冲突对中，最大的左端点值 +1。基础答案 = sum(r - minLeft[r] + 1)。枚举删除每对冲突 (a, b)：删除后从 b 开始重算 minLeft，累计增益，取最大增益加到基础答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximizeSubarrays(int n, int[][] conflictingPairs) {
        // rightMap[r] = 所有右端点为 r 的冲突对的左端点列表
        List<List<Integer>> rightMap = new ArrayList<>();
        for (int i = 0; i <= n + 1; i++) rightMap.add(new ArrayList<>());

        for (int[] p : conflictingPairs) {
            int a = Math.min(p[0], p[1]);
            int b = Math.max(p[0], p[1]);
            rightMap.get(b).add(a);
        }

        // 计算 minLeft 和基础答案
        int[] minLeft = new int[n + 1];
        int cur = 1;
        long base = 0;
        for (int r = 1; r <= n; r++) {
            for (int a : rightMap.get(r)) cur = Math.max(cur, a + 1);
            minLeft[r] = cur;
            base += r - cur + 1;
        }

        // 枚举删除每对冲突，计算增益
        long bestGain = 0;
        for (int[] p : conflictingPairs) {
            int a = Math.min(p[0], p[1]);
            int b = Math.max(p[0], p[1]);

            // 删除 (a, b) 后，从 r=b 开始重算 minLeft
            int cur2 = (b > 1) ? minLeft[b - 1] : 1;
            long gain = 0;
            for (int r = b; r <= n; r++) {
                int newBound = cur2;
                for (int aa : rightMap.get(r)) {
                    if (!(aa == a && r == b)) { // 跳过被删除的冲突对
                        newBound = Math.max(newBound, aa + 1);
                    }
                }
                cur2 = newBound;
                gain += minLeft[r] - cur2; // 增量：left bound 降低的量
            }
            bestGain = Math.max(bestGain, gain);
        }

        return base + bestGain;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m)，m 为冲突对数量
- 空间复杂度：O(n + m)

## 关键点总结

1. minLeft[r] 由所有右端点 <= r 的冲突对中最大的左端点决定
2. 删除某冲突对后，其右端点 b 之后的 minLeft 可能降低，产生增益
3. 需保证每对 (a, b) 中 a < b，统一规范化处理
