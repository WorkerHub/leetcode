## 题目描述

给你二叉树的根节点 `root` 和一个整数目标和 `targetSum`，找出所有从根节点到叶子节点路径总和等于给定目标和的路径。

**叶子节点**是指没有子节点的节点。

**示例 1：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]
```

**示例 2：**

```
输入：root = [1,2,3], targetSum = 5
输出：[]
```

**示例 3：**

```
输入：root = [1,2], targetSum = 0
输出：[]
```

**提示：**

- 树中节点总数在范围 `[0, 5000]` 内
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`

## 解题思路

这道题是第 112 题的进阶版，不仅要判断是否存在路径，还要找出所有满足条件的路径。

### 核心思路

这是一道典型的**回溯**问题：
1. 需要记录从根节点到当前节点的路径
2. 到达叶子节点时，判断路径和是否等于目标值
3. 如果满足条件，将路径加入结果集
4. 回溯时要恢复状态（移除当前节点）

### 关键要点

1. **路径记录**：使用列表记录当前路径上的所有节点值
2. **回溯操作**：递归返回前要移除当前节点（恢复状态）
3. **深拷贝**：加入结果集时要复制路径，不能直接引用
4. **叶子节点判断**：只在叶子节点处检查路径和

## Java 代码实现

### 方法一：DFS + 回溯（推荐）⭐

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        dfs(root, targetSum);
        return result;
    }

    private void dfs(TreeNode node, int remaining) {
        if (node == null) return;

        // 将当前节点加入路径
        path.add(node.val);
        remaining -= node.val;

        // 到达叶子节点，检查路径和
        if (node.left == null && node.right == null) {
            if (remaining == 0) {
                // 找到一条满足条件的路径，加入结果集
                // 注意：要复制路径，不能直接引用
                result.add(new ArrayList<>(path));
            }
        } else {
            // 继续递归左右子树
            dfs(node.left, remaining);
            dfs(node.right, remaining);
        }

        // 回溯：移除当前节点，恢复状态
        path.remove(path.size() - 1);
    }
}
```

### 方法二：DFS + 回溯（累加版本）

```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        dfs(root, 0, targetSum, path, result);
        return result;
    }

    private void dfs(TreeNode node, int currentSum, int targetSum,
                     List<Integer> path, List<List<Integer>> result) {
        if (node == null) return;

        // 添加当前节点到路径
        path.add(node.val);
        currentSum += node.val;

        // 叶子节点：检查路径和
        if (node.left == null && node.right == null) {
            if (currentSum == targetSum) {
                result.add(new ArrayList<>(path));
            }
        }

        // 递归遍历子树
        dfs(node.left, currentSum, targetSum, path, result);
        dfs(node.right, currentSum, targetSum, path, result);

        // 回溯
        path.remove(path.size() - 1);
    }
}
```

### 方法三：DFS（不显式回溯）

```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;
        dfs(root, targetSum, new ArrayList<>(), result);
        return result;
    }

    private void dfs(TreeNode node, int remaining,
                     List<Integer> path, List<List<Integer>> result) {
        // 叶子节点
        if (node.left == null && node.right == null) {
            if (remaining == node.val) {
                List<Integer> newPath = new ArrayList<>(path);
                newPath.add(node.val);
                result.add(newPath);
            }
            return;
        }

        // 递归左子树（每次传入新的列表，不需要显式回溯）
        if (node.left != null) {
            List<Integer> newPath = new ArrayList<>(path);
            newPath.add(node.val);
            dfs(node.left, remaining - node.val, newPath, result);
        }

        // 递归右子树
        if (node.right != null) {
            List<Integer> newPath = new ArrayList<>(path);
            newPath.add(node.val);
            dfs(node.right, remaining - node.val, newPath, result);
        }
    }
}
```

### 方法四：BFS（层序遍历）

```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // 三个队列分别存储节点、当前路径和、当前路径
        Queue<TreeNode> nodeQueue = new ArrayDeque<>();
        Queue<Integer> sumQueue = new ArrayDeque<>();
        Queue<List<Integer>> pathQueue = new ArrayDeque<>();

        List<Integer> rootPath = new ArrayList<>();
        rootPath.add(root.val);
        nodeQueue.offer(root);
        sumQueue.offer(root.val);
        pathQueue.offer(rootPath);

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            int currentSum = sumQueue.poll();
            List<Integer> path = pathQueue.poll();

            // 叶子节点：检查路径和
            if (node.left == null && node.right == null) {
                if (currentSum == targetSum) {
                    result.add(path);
                }
                continue;
            }

            // 左子树
            if (node.left != null) {
                List<Integer> leftPath = new ArrayList<>(path);
                leftPath.add(node.left.val);
                nodeQueue.offer(node.left);
                sumQueue.offer(currentSum + node.left.val);
                pathQueue.offer(leftPath);
            }

            // 右子树
            if (node.right != null) {
                List<Integer> rightPath = new ArrayList<>(path);
                rightPath.add(node.right.val);
                nodeQueue.offer(node.right);
                sumQueue.offer(currentSum + node.right.val);
                pathQueue.offer(rightPath);
            }
        }

        return result;
    }
}
```

### 方法五：迭代 + 栈

```java
class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // 三个栈分别存储节点、剩余目标和、当前路径
        Deque<TreeNode> nodeStack = new ArrayDeque<>();
        Deque<Integer> sumStack = new ArrayDeque<>();
        Deque<List<Integer>> pathStack = new ArrayDeque<>();

        List<Integer> rootPath = new ArrayList<>();
        rootPath.add(root.val);
        nodeStack.push(root);
        sumStack.push(targetSum - root.val);
        pathStack.push(rootPath);

        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            int remaining = sumStack.pop();
            List<Integer> path = pathStack.pop();

            // 叶子节点
            if (node.left == null && node.right == null) {
                if (remaining == 0) {
                    result.add(path);
                }
                continue;
            }

            // 右子树（先压栈，后访问）
            if (node.right != null) {
                List<Integer> rightPath = new ArrayList<>(path);
                rightPath.add(node.right.val);
                nodeStack.push(node.right);
                sumStack.push(remaining - node.right.val);
                pathStack.push(rightPath);
            }

            // 左子树（后压栈，先访问）
            if (node.left != null) {
                List<Integer> leftPath = new ArrayList<>(path);
                leftPath.add(node.left.val);
                nodeStack.push(node.left);
                sumStack.push(remaining - node.left.val);
                pathStack.push(leftPath);
            }
        }

        return result;
    }
}
```

## 复杂度分析

### 方法一、二（DFS + 回溯）

- **时间复杂度**：O(n²)
  - 遍历所有节点：O(n)
  - 每次找到路径时复制路径：O(h)，h 为树高
  - 最坏情况下所有路径都满足条件：O(n²)
- **空间复杂度**：O(h)，递归调用栈和路径列表

### 方法三、四、五

- **时间复杂度**：O(n²)，同上
- **空间复杂度**：O(n)，每个节点都会创建新的路径列表

```
dfs(5):
  path = [5]
  dfs(4):
    path = [5, 4]
    dfs(11):
      path = [5, 4, 11]
      dfs(7):
        path = [5, 4, 11, 7]  # 叶子节点，sum != 22
        path.remove() -> [5, 4, 11]  # 回溯
      dfs(2):
        path = [5, 4, 11, 2]  # 叶子节点，sum == 22，加入结果
        path.remove() -> [5, 4, 11]  # 回溯

    path.remove() -> [5]  # 回溯
  dfs(8):
    ... 类似过程
```

## 关键点总结

1. **回溯模板**：添加节点 -> 递归 -> 移除节点，这是回溯的标准模板
2. **深拷贝路径**：`new ArrayList<>(path)`，不能直接添加引用
3. **叶子节点判断**：只在叶子节点处检查和添加路径
4. **路径构建方式**：
   - 方法一、二：使用共享 path，需要回溯
   - 方法三：每次传入新列表，不需要回溯（但空间开销大）
5. **DFS vs BFS**：DFS 更自然，BFS 也可以但代码更复杂

## 易错点

1. **忘记深拷贝**：
   ```java
   // 错误：直接添加引用
   result.add(path);  // 所有路径都会变成最后一条

   // 正确：复制路径
   result.add(new ArrayList<>(path));
   ```

2. **忘记回溯**：
   ```java
   // 错误：没有移除操作
   path.add(node.val);
   dfs(node.left, remaining);
   dfs(node.right, remaining);
   // 缺少 path.remove(path.size() - 1)

   // 正确：
   path.add(node.val);
   dfs(node.left, remaining);
   dfs(node.right, remaining);
   path.remove(path.size() - 1);  // 回溯
   ```

3. **在非叶子节点处添加路径**：
   ```java
   // 错误：在任意节点处检查
   if (remaining == 0) result.add(new ArrayList<>(path));

   // 正确：只在叶子节点处检查
   if (node.left == null && node.right == null && remaining == 0) {
       result.add(new ArrayList<>(path));
   }
   ```

4. **路径为空的情况**：要检查 `node` 是否为 `null`

5. **空树处理**：空树应返回空列表 `[]` 而不是 `[[]]`
