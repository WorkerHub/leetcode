## 题目描述

给你正整数 `l` 和 `r`，若正整数 x 的各位数字之积能整除 x，则称 x 为美丽数，返回 [l, r] 内美丽数的数量。

## 解题思路

数位 DP：`f(n)` 统计 [1, n] 内美丽数数量，答案为 `f(r) - f(l-1)`。状态为（当前位、是否受上界约束、各位乘积、当前数字值）。乘积含 0 时特殊标记，末尾判断 `numVal % prod == 0`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private char[] digits;
    private Map<Long, Integer> memo = new HashMap<>();

    public int beautifulNumbers(int l, int r) {
        return countUpTo(r) - countUpTo(l - 1);
    }

    private int countUpTo(int n) {
        if (n <= 0) return 0;
        digits = String.valueOf(n).toCharArray();
        memo.clear();
        return dp(0, true, 1, 0);
    }

    // pos: 当前位; tight: 是否受上界约束; prod: 各位乘积（0表示含0位）; numVal: 当前数字值
    private int dp(int pos, boolean tight, long prod, long numVal) {
        if (pos == digits.length) {
            if (prod == 0) return 0; // 含 0 的位
            return (numVal % prod == 0) ? 1 : 0;
        }
        long key = ((long) pos << 40) | ((tight ? 1L : 0L) << 39) | (prod << 15) | numVal;
        if (!tight && memo.containsKey(key)) return memo.get(key);

        int limit = tight ? (digits[pos] - '0') : 9;
        int result = 0;
        for (int d = 0; d <= limit; d++) {
            boolean newTight = tight && (d == limit);
            long newProd = (prod == 0 || d == 0) ? 0 : prod * d;
            long newNum = numVal * 10 + d;
            result += dp(pos + 1, newTight, newProd, newNum);
        }

        if (!tight) memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * D * P * N)，D 为位数，P 为乘积状态数，N 为数字值状态数
- 空间复杂度：O(D * P * N)

## 关键点总结

1. 数位 DP：逐位填充，维护乘积和当前数字值作为状态
2. 含 0 的位导致乘积为 0，无法整除，特殊标记跳过
3. 答案 = f(r) - f(l-1)，注意 f(0) = 0
