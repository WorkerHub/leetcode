## 题目描述

给定整数数组 `nums` 和整数 `k`，判断是否可将数组分成两个非空连续子数组，使得两部分元素之和之差的绝对值不超过 `k`。

## Java 代码实现

```java
class Solution {
    public boolean checkPartition(int[] nums, int k) {
        long total = 0;
        for (int x : nums) total += x;

        long prefix = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            prefix += nums[i];
            long suffix = total - prefix;
            if (Math.abs(prefix - suffix) <= k) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 枚举 `n-1` 个分割点，利用前缀和 O(1) 计算两部分之和
2. 使用 `long` 防止大数组求和溢出
3. 有一个分割点满足条件即返回 true
