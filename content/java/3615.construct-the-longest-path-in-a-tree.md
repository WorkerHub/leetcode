## 题目描述

给定 `n` 个节点的树，每个节点有权值 `vals[i]`，路径合法当且仅当路径上节点权值严格递增，返回最长合法路径的节点数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] vals;
    private List<List<Integer>> graph;
    private int ans = 1;

    public int longestPath(int n, int[][] edges, int[] vals) {
        this.vals = vals;
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        dfs(0, -1);
        return ans;
    }

    // 返回以 node 为端点的最长严格递增路径长度
    private int dfs(int node, int parent) {
        int best1 = 0, best2 = 0;  // 最长和次长子路径
        for (int child : graph.get(node)) {
            if (child == parent) continue;
            int childLen = dfs(child, node);
            // 只有子节点权值更大才能接续
            if (vals[child] > vals[node]) {
                if (childLen > best1) { best2 = best1; best1 = childLen; }
                else if (childLen > best2) best2 = childLen;
            }
        }
        // 经过 node 的最长路径 = 最长 + 次长子路径 + 1
        ans = Math.max(ans, best1 + best2 + 1);
        return best1 + 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈

## 关键点总结

1. 经过某节点的最长路径 = 最长 + 次长子路径 + 1
2. 只有子节点权值严格大于当前节点才能拼接路径
3. DFS 返回单方向最长路径长度（为父节点服务）
