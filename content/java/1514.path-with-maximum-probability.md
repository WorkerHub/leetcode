## 题目描述

无向加权图，边权为成功概率（0-1之间）。求从 start 到 end 概率最大的路径，路径概率 = 边权乘积。

**示例：**
```
输入：n = 3, edges = [[0,1],[1,2],[0,2]], succProb = [0.5,0.5,0.2], start = 0, end = 2
输出：0.25000
```

## 解题思路

Dijkstra 变体：最大堆，初始 prob[start]=1，松弛条件为 prob[u]*w > prob[v]。

## Java 代码实现

```java
class Solution {
    public double maxProbability(int n, int[][] edges, double[] succProb, int start, int end) {
        // 建图
        List<List<double[]>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int i = 0; i < edges.length; i++) {
            int u = edges[i][0], v = edges[i][1];
            graph.get(u).add(new double[]{v, succProb[i]});
            graph.get(v).add(new double[]{u, succProb[i]});
        }
        
        double[] prob = new double[n];
        prob[start] = 1.0;
        // 最大堆
        PriorityQueue<double[]> pq = new PriorityQueue<>((a, b) -> Double.compare(b[1], a[1]));
        pq.offer(new double[]{start, 1.0});
        
        while (!pq.isEmpty()) {
            double[] curr = pq.poll();
            int u = (int) curr[0];
            double p = curr[1];
            
            if (u == end) return p;
            if (p < prob[u]) continue;
            
            for (double[] edge : graph.get(u)) {
                int v = (int) edge[0];
                double newProb = p * edge[1];
                if (newProb > prob[v]) {
                    prob[v] = newProb;
                    pq.offer(new double[]{v, newProb});
                }
            }
        }
        return 0.0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **Dijkstra 变体**：最大化乘积而非最小化和
2. **最大堆**：每次取概率最大的节点
3. **松弛条件**：prob[u]*w > prob[v]
4. **初始化**：prob[start]=1，其他为 0
