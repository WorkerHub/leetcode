## 题目描述

给定一个嵌套的整数列表 `nestedList`，每个元素要么是一个整数，要么是一个列表（其元素也可能是整数或列表）。

整数的深度是其在列表内部的嵌套层数。例如，嵌套列表 `[1,[2,2],[[3],2],1]` 中每个整数的值就是其深度。

请你计算并返回该嵌套列表表示的加权和，其中每个整数的权重为其深度。

**示例 1:**

```
输入：nestedList = [[1,1],2,[1,1]]
输出：10
解释：四个 1 的深度为 2，一个 2 的深度为 1。1*2 + 1*2 + 2*1 + 1*2 + 1*2 = 10
```

**示例 2:**

```
输入：nestedList = [1,[4,[6]]]
输出：27
解释：一个 1 的深度为 1，一个 4 的深度为 2，一个 6 的深度为 3。1*1 + 4*2 + 6*3 = 27
```

**示例 3:**

```
输入：nestedList = [0]
输出：0
```

**提示:**

- `1 <= nestedList.length <= 50`
- 嵌套列表中整数的值在范围 `[-100, 100]` 内
- 任何整数的最大深度小于或等于 50

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题可以使用 **DFS（深度优先搜索）** 或 **BFS（广度优先搜索）** 解决。

### 核心思想

1. **深度优先搜索（DFS）**：
   - 递归遍历嵌套列表
   - 每次进入下一层，深度 +1
   - 遇到整数时，累加 `值 * 深度`

2. **广度优先搜索（BFS）**：
   - 使用队列层次遍历
   - 每层深度 +1
   - 遇到整数时，累加 `值 * 当前深度`

## Java 代码实现

首先定义 `NestedInteger` 接口（题目提供）：

```java
// LeetCode 提供的接口，无需自己实现
public interface NestedInteger {
    // 如果是整数返回 true，否则返回 false
    public boolean isInteger();

    // 如果是整数，返回整数值
    public Integer getInteger();

    // 如果是列表，返回嵌套列表
    public List<NestedInteger> getList();
}
```

### 方法一：深度优先搜索（递归）⭐

```java
import java.util.List;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        // DFS 递归：计算加权和
        return dfs(nestedList, 1);
    }

    /**
     * 递归计算加权和
     * @param nestedList 当前层的嵌套列表
     * @param depth 当前深度
     */
    private int dfs(List<NestedInteger> nestedList, int depth) {
        int total = 0;

        for (NestedInteger item : nestedList) {
            if (item.isInteger()) {
                // 是整数，累加 值 * 深度
                total += item.getInteger() * depth;
            } else {
                // 是列表，递归处理下一层
                total += dfs(item.getList(), depth + 1);
            }
        }

        return total;
    }
}
```

### 方法二：广度优先搜索（BFS）

```java
import java.util.*;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        // BFS 层次遍历：计算加权和
        Queue<NestedInteger> queue = new LinkedList<>(nestedList);
        int depth = 1;
        int total = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();

            // 处理当前层的所有元素
            for (int i = 0; i < size; i++) {
                NestedInteger item = queue.poll();

                if (item.isInteger()) {
                    // 是整数，累加 值 * 深度
                    total += item.getInteger() * depth;
                } else {
                    // 是列表，将其元素加入队列
                    queue.addAll(item.getList());
                }
            }

            // 进入下一层
            depth++;
        }

        return total;
    }
}
```

### 方法三：迭代 DFS（使用栈）

```java
import java.util.*;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        // 迭代 DFS：使用栈，存储 (NestedInteger, depth) 对
        Deque<int[]> stackDepth = new ArrayDeque<>();
        Deque<NestedInteger> stackItems = new ArrayDeque<>();

        // 初始化：将所有顶层元素入栈，深度为 1
        for (NestedInteger item : nestedList) {
            stackItems.push(item);
            stackDepth.push(new int[]{1});
        }

        int total = 0;

        while (!stackItems.isEmpty()) {
            NestedInteger item = stackItems.pop();
            int depth = stackDepth.pop()[0];

            if (item.isInteger()) {
                total += item.getInteger() * depth;
            } else {
                // 将列表中的元素加入栈，深度 +1
                for (NestedInteger nested : item.getList()) {
                    stackItems.push(nested);
                    stackDepth.push(new int[]{depth + 1});
                }
            }
        }

        return total;
    }
}
```

### 方法四：迭代 DFS（使用 AbstractMap.SimpleEntry）

```java
import java.util.*;

class Solution {
    public int depthSum(List<NestedInteger> nestedList) {
        // 使用 Deque 存储 (item, depth) 对
        Deque<AbstractMap.SimpleEntry<NestedInteger, Integer>> stack = new ArrayDeque<>();

        // 初始化
        for (NestedInteger item : nestedList) {
            stack.push(new AbstractMap.SimpleEntry<>(item, 1));
        }

        int total = 0;

        while (!stack.isEmpty()) {
            AbstractMap.SimpleEntry<NestedInteger, Integer> entry = stack.pop();
            NestedInteger item = entry.getKey();
            int depth = entry.getValue();

            if (item.isInteger()) {
                total += item.getInteger() * depth;
            } else {
                for (NestedInteger nested : item.getList()) {
                    stack.push(new AbstractMap.SimpleEntry<>(nested, depth + 1));
                }
            }
        }

        return total;
    }
}
```

## 复杂度分析

**方法一：DFS 递归**

- **时间复杂度**：O(n)
  - n：所有整数的总数
  - 每个元素访问一次
  
- **空间复杂度**：O(d)
  - d：最大嵌套深度
  - 递归栈的深度

**方法二：BFS**

- **时间复杂度**：O(n)
  - 每个元素访问一次
  
- **空间复杂度**：O(w)
  - w：最宽一层的元素数
  - 队列的最大长度

**方法三/四：迭代 DFS**

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)
  - 栈的最大深度

## 关键点总结

1. **递归 DFS**：最直观，深度作为参数传递
2. **BFS 层次遍历**：按层处理，每层深度 +1
3. **深度计算**：
   - 初始深度为 1
   - 每进入下一层，深度 +1
4. **NestedInteger 接口**：
   - `isInteger()`：判断是否为整数
   - `getInteger()`：获取整数值
   - `getList()`：获取嵌套列表
5. **加权和公式**：`sum(值 * 深度)`

## 易错点

1. **初始深度**：应该从 1 开始，不是 0

2. **递归深度传递**：
   - 正确：`dfs(item.getList(), depth + 1)`
   - 错误：`dfs(item.getList(), depth)`

3. **BFS 的层次处理**：
   - 要记录每层的大小 `size = queue.size()`
   - 处理完一层后才 `depth++`

4. **空列表处理**：空列表的加权和为 0

5. **接口调用顺序**：
   - 先调用 `isInteger()` 判断
   - 再调用 `getInteger()` 或 `getList()`
