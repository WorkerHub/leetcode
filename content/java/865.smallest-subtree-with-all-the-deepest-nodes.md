## 题目描述

给定一个根为 root 的二叉树，每个节点的深度是 该节点到根的最短距离 。

返回包含原始树中所有 最深节点 的 最小子树 。

如果一个节点在 整个树 的任意节点之间具有最大的深度，则该节点是 最深的 。

一个节点的 子树 是该节点加上它的所有后代的集合。

**示例 1：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
```

**示例 2：**
```
输入：root = [1]
输出：[1]
```

**示例 3：**
```
输入：root = [0,1,3,null,2]
输出：[2]
```

**提示：**
- 树中节点的数量在 [1, 500] 范围内
- 0 <= Node.val <= 500
- 每个节点的值都是 独一无二 的

## 解题思路

**核心观察：**
- 最深节点的最小子树 = 最深节点的最近公共祖先（LCA）

**算法思路：**
1. DFS 计算每个节点的深度
2. 对于每个节点，返回其子树中最深节点的深度
3. 如果左右子树最深深度相同，当前节点就是 LCA
4. 否则返回更深的那个子树

## Java 代码实现

### 方法一：DFS（推荐）

```java
class Solution {
    public TreeNode subtreeWithAllDeepest(TreeNode root) {
        return dfs(root)[1];
    }

    // 返回 [最深深度, 包含所有最深节点的子树根]
    // 通过一个长度为 2 的数组模拟 Python 的元组返回
    private TreeNode[] dfs(TreeNode node) {
        if (node == null) return new TreeNode[]{null, null}; // [深度节点占位, null]

        // 这里用另一种方式：返回深度和节点的包装
        return dfsHelper(node);
    }

    private int maxDepth;
    private TreeNode result;

    public TreeNode subtreeWithAllDeepestV2(TreeNode root) {
        maxDepth = -1;
        result = null;
        helper(root, 0);
        return result;
    }

    private int helper(TreeNode node, int depth) {
        if (node == null) return depth - 1;

        int leftDepth = helper(node.left, depth + 1);
        int rightDepth = helper(node.right, depth + 1);

        int maxLeft = leftDepth;
        int maxRight = rightDepth;

        if (maxLeft == maxRight) {
            if (maxLeft > maxDepth) {
                maxDepth = maxLeft;
                result = node;
            }
        }
        return Math.max(maxLeft, maxRight);
    }

    // 推荐方法：返回 (深度, 节点) 对
    private TreeNode[] dfsHelper(TreeNode node) {
        if (node == null) return new TreeNode[0]; // placeholder
        return null;
    }
}
```

**更清晰的实现：**

```java
class Solution {
    // 使用内部类存储结果
    private int[] depthAndNode(TreeNode node, int[] result) {
        return result;
    }

    public TreeNode subtreeWithAllDeepest(TreeNode root) {
        return solve(root).node;
    }

    private Result solve(TreeNode node) {
        if (node == null) return new Result(0, null);

        Result left = solve(node.left);
        Result right = solve(node.right);

        // 左右深度相同，当前节点是答案
        if (left.depth == right.depth) {
            return new Result(left.depth + 1, node);
        } else if (left.depth > right.depth) {
            // 左子树更深
            return new Result(left.depth + 1, left.node);
        } else {
            // 右子树更深
            return new Result(right.depth + 1, right.node);
        }
    }

    static class Result {
        int depth;
        TreeNode node;
        Result(int depth, TreeNode node) {
            this.depth = depth;
            this.node = node;
        }
    }
}
```

**代码说明：**
- 使用内部类 Result 存储 (深度, 节点) 对
- `solve(node)` 返回子树中最深深度及对应的 LCA
- 若左右深度相同，当前节点就是答案

## 复杂度分析

- **时间复杂度**：O(n)，DFS 遍历所有节点。
- **空间复杂度**：O(h)，递归栈，h 为树的高度。

## 关键点总结

1. **LCA 问题**：最深节点的最近公共祖先
2. **一次 DFS**：同时计算深度和查找节点
3. **返回值设计**：返回 (深度, 节点) 对
4. **边界情况**：空节点返回深度 0
