## 题目描述

给定字符串 `s`（长度 <= 12），找两个不相交回文子序列使其长度乘积最大，返回最大乘积。

## 解题思路

用状态压缩枚举所有子集，预计算每个位掩码对应子序列的最长回文子序列长度（区间 DP）。枚举所有不相交子集对（按位与为 0），取乘积最大值。

## Java 代码实现

### 方法一：状态压缩枚举（推荐）

```java
class Solution {
    public int maxProduct(String s) {
        int n = s.length();
        int total = 1 << n;
        int[] pal = new int[total];

        // 预计算每个掩码对应子序列的最长回文子序列长度
        for (int mask = 1; mask < total; mask++) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) sb.append(s.charAt(i));
            }
            pal[mask] = lps(sb.toString());
        }

        int ans = 0;
        // 枚举所有不相交子集对
        for (int mask1 = 1; mask1 < total; mask1++) {
            int complement = (total - 1) ^ mask1;
            // 枚举complement的所有非空子集
            for (int mask2 = complement; mask2 > 0; mask2 = (mask2 - 1) & complement) {
                ans = Math.max(ans, pal[mask1] * pal[mask2]);
            }
        }
        return ans;
    }

    // 区间DP计算最长回文子序列
    private int lps(String t) {
        int m = t.length();
        if (m == 0) return 0;
        int[][] dp = new int[m][m];
        for (int i = 0; i < m; i++) dp[i][i] = 1;
        for (int len = 2; len <= m; len++) {
            for (int i = 0; i <= m - len; i++) {
                int j = i + len - 1;
                if (t.charAt(i) == t.charAt(j)) {
                    dp[i][j] = (len == 2 ? 0 : dp[i+1][j-1]) + 2;
                } else {
                    dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);
                }
            }
        }
        return dp[0][m-1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(3^n * n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 字符串长度 <= 12，可用位掩码枚举所有子集
2. 枚举补集的非空子集技巧：`mask2 = (mask2-1) & complement`
3. 区间 DP 精确计算最长回文子序列长度
