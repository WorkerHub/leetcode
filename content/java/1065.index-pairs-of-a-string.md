## 题目描述

给定字符串 text 和字符串数组 words，返回所有 [i,j] 使得 text[i..j] 在 words 中。结果按 i 升序，i 相同按 j 升序。

**示例：**
```
输入：text = "thestoryofleetcodeandme", words = ["story","fleet","leetcode"]
输出：[[3,7],[9,13],[10,17]]
```

## 解题思路

对每个起始位置检查所有 word 是否匹配。数据规模小可暴力枚举；也可用 Trie 优化。

## Java 代码实现

```java
class Solution {
    public int[][] indexPairs(String text, String[] words) {
        List<int[]> result = new ArrayList<>();

        for (int i = 0; i < text.length(); i++) {
            for (String word : words) {
                if (i + word.length() <= text.length() &&
                    text.substring(i, i + word.length()).equals(word)) {
                    result.add(new int[]{i, i + word.length() - 1});
                }
            }
        }

        result.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        return result.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m × k)，n=text长度，m=words数，k=平均word长度
- **空间复杂度**：O(结果数量)

## 关键点总结

1. **暴力枚举**：数据规模小，直接匹配
2. **排序要求**：先按 i 再按 j
3. **Trie 优化**：words 多时可用 Trie 加速
