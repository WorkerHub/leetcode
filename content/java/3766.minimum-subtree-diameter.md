## 题目描述

给定一棵 `n` 个节点的无向树，返回能涵盖整棵树直径的最小子树的节点数（子树必须包含直径路径的所有节点）。

## 解题思路

两次 BFS 找树的直径。第一次 BFS 从任意节点出发找最远节点 `u`，第二次从 `u` 出发找最远节点 `v`，`u-v` 路径的长度即为直径。最小子树就是直径路径，节点数 = 直径边数 + 1。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public int minimumSubtreeDiameter(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        // 第一次 BFS：找直径端点 u
        int u = bfs(0, graph, n)[0];
        // 第二次 BFS：从 u 出发找直径长度
        int diameter = bfs(u, graph, n)[1];

        return diameter + 1;
    }

    private int[] bfs(int start, List<List<Integer>> graph, int n) {
        int[] dist = new int[n];
        java.util.Arrays.fill(dist, -1);
        dist[start] = 0;
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        int farthest = start;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph.get(u)) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    if (dist[v] > dist[farthest]) farthest = v;
                    queue.offer(v);
                }
            }
        }
        return new int[]{farthest, dist[farthest]};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 两次 BFS 是求树直径的经典方法
2. 最小子树 = 直径路径本身，节点数 = 直径边数 + 1
3. 直径是边数，最终返回节点数需加 1
