## 题目描述

将n个饼干袋分给k个孩子，最小化所有孩子中获得饼干最多者的数量。

## 解题思路

回溯+剪枝：枚举每袋分给哪个孩子，当前最大值已超过最优解时剪枝。n<=8保证可行。

## Java 代码实现

```java
class Solution {
    private int ans = Integer.MAX_VALUE;
    private int[] distribute;

    public int distributeCookies(int[] cookies, int k) {
        distribute = new int[k];
        backtrack(cookies, 0, k);
        return ans;
    }

    private void backtrack(int[] cookies, int idx, int k) {
        if (idx == cookies.length) {
            int max = 0;
            for (int d : distribute) max = Math.max(max, d);
            ans = Math.min(ans, max);
            return;
        }

        Set<Integer> seen = new HashSet<>();
        for (int i = 0; i < k; i++) {
            // 剪枝：相同数值的孩子只试一次
            if (!seen.add(distribute[i])) continue;
            distribute[i] += cookies[idx];
            // 剪枝：当前最大值已超过答案
            if (distribute[i] < ans) {
                backtrack(cookies, idx + 1, k);
            }
            distribute[i] -= cookies[idx];
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k^N)，剪枝后远小于此
- **空间复杂度**：O(N + k)

## 关键点总结

1. **回溯枚举分配方案**：每袋尝试分给每个孩子
2. **剪枝1**：相同饼干数的孩子等价，只试一次
3. **剪枝2**：当前最大值已>=答案时剪枝
