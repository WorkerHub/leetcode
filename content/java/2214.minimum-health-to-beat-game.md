## 题目描述

顺序通过n关，每关受damage[i]伤害，有一次使用护甲机会减少min(armor,damage[i])伤害，求最少初始血量(通关后>0)。

## 解题思路

贪心：护甲用在伤害最大关卡效果最优。最少血量=总伤害-min(armor,max(damage))+1。

## Java 代码实现

```java
class Solution {
    public long minimumHealth(int[] damage, int armor) {
        long total = 0;
        int maxDmg = 0;
        for (int d : damage) {
            total += d;
            maxDmg = Math.max(maxDmg, d);
        }
        // 护甲减少量
        int reduction = Math.min(armor, maxDmg);
        return total - reduction + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心最优**：护甲用在伤害最大关卡减少最多总伤害
2. **护甲减少量**：min(armor, max(damage))
3. **+1要求**：通关时血量必须严格大于0
