## 题目描述

给你石子堆数组 `piles` 和操作次数 `k`，每次选最大堆移走一半（向下取整），返回 k 次操作后剩余石子最小总数。

## 解题思路

贪心 + 最大堆：每次对最大堆操作效果最优，操作后剩余 `(x+1)/2`（向上取整），重复 k 次后求和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minStoneSum(int[] piles, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        int total = 0;
        for (int p : piles) { heap.offer(p); total += p; }
        for (int i = 0; i < k; i++) {
            int x = heap.poll();
            int removed = x / 2;
            total -= removed;
            heap.offer(x - removed); // 剩余 ceil(x/2)
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + k) log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：每次对最大堆操作，减少量最大
2. 操作后剩余 = `x - x/2`（即 `ceil(x/2)`）
3. 维护总和而非最后求和更高效
