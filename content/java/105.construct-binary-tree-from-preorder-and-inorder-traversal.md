## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的前序遍历，`inorder` 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

**示例 1：**

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2：**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

**提示：**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均无重复元素
- `inorder` 均出现在 `preorder`
- `preorder` 保证为二叉树的前序遍历序列
- `inorder` 保证为二叉树的中序遍历序列

## 解题思路

这道题的核心是理解前序遍历和中序遍历的特点：

1. **前序遍历**：根节点 -> 左子树 -> 右子树
2. **中序遍历**：左子树 -> 根节点 -> 右子树

**关键观察**：
- 前序遍历的第一个元素一定是根节点
- 在中序遍历中找到根节点的位置后，其左边都是左子树的节点，右边都是右子树的节点
- 根据左子树节点的数量，可以在前序遍历中划分出左子树和右子树的部分

**算法流程**：
1. 从前序遍历中取出第一个元素作为根节点
2. 在中序遍历中找到根节点的位置
3. 根据位置计算左子树的节点数量
4. 递归构造左子树和右子树
5. 返回根节点

**优化技巧**：
- 使用哈希表存储中序遍历中每个值的索引，避免重复查找
- 使用索引范围而不是切片数组，避免额外的空间开销

## Java 代码实现

### 方法一：递归 + 哈希表（推荐）⭐

```java
class Solution {
    // 中序遍历值到索引的映射
    private Map<Integer, Integer> inorderMap = new HashMap<>();
    private int[] preorder;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        // 构建中序遍历值到索引的映射，方便快速查找根节点位置
        for (int i = 0; i < inorder.length; i++) {
            inorderMap.put(inorder[i], i);
        }
        return build(0, preorder.length - 1, 0, inorder.length - 1);
    }

    private TreeNode build(int preLeft, int preRight, int inLeft, int inRight) {
        // 递归终止条件：没有节点可以构建
        if (preLeft > preRight) return null;

        // 前序遍历的第一个节点就是根节点
        int rootVal = preorder[preLeft];
        TreeNode root = new TreeNode(rootVal);

        // 在中序遍历中找到根节点的位置
        int inRootIndex = inorderMap.get(rootVal);

        // 计算左子树的节点数量
        int leftSubtreeSize = inRootIndex - inLeft;

        // 递归构建左子树
        // 前序遍历：[preLeft+1, preLeft+leftSubtreeSize]
        // 中序遍历：[inLeft, inRootIndex-1]
        root.left = build(
            preLeft + 1,
            preLeft + leftSubtreeSize,
            inLeft,
            inRootIndex - 1
        );

        // 递归构建右子树
        // 前序遍历：[preLeft+leftSubtreeSize+1, preRight]
        // 中序遍历：[inRootIndex+1, inRight]
        root.right = build(
            preLeft + leftSubtreeSize + 1,
            preRight,
            inRootIndex + 1,
            inRight
        );

        return root;
    }
}
```

### 方法二：递归（直接查找，易理解版）

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        return build(preorder, 0, preorder.length - 1, inorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int preLeft, int preRight,
                           int[] inorder, int inLeft, int inRight) {
        if (preLeft > preRight) return null;

        // 前序遍历的第一个元素是根节点
        int rootVal = preorder[preLeft];
        TreeNode root = new TreeNode(rootVal);

        // 在中序遍历中找到根节点的位置
        int midIndex = inLeft;
        while (inorder[midIndex] != rootVal) midIndex++;

        int leftSize = midIndex - inLeft;

        // 递归构建左子树和右子树
        root.left = build(preorder, preLeft + 1, preLeft + leftSize,
                          inorder, inLeft, midIndex - 1);
        root.right = build(preorder, preLeft + leftSize + 1, preRight,
                           inorder, midIndex + 1, inRight);

        return root;
    }
}
```

### 方法三：迭代 + 栈

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        if (preorder.length == 0) return null;

        TreeNode root = new TreeNode(preorder[0]);
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        int inorderIndex = 0;

        // 遍历前序遍历的每个节点
        for (int i = 1; i < preorder.length; i++) {
            int preVal = preorder[i];
            TreeNode node = stack.peek();

            // 如果栈顶节点不等于中序遍历的当前节点
            // 说明还在构建左子树
            if (node.val != inorder[inorderIndex]) {
                node.left = new TreeNode(preVal);
                stack.push(node.left);
            } else {
                // 找到该开始构建右子树的节点
                while (!stack.isEmpty() && stack.peek().val == inorder[inorderIndex]) {
                    node = stack.pop();
                    inorderIndex++;
                }
                // 构建右子树
                node.right = new TreeNode(preVal);
                stack.push(node.right);
            }
        }

        return root;
    }
}
```

## 复杂度分析

### 方法一：递归 + 哈希表

- **时间复杂度**：O(n)，其中 n 是树中的节点数。每个节点都会被访问一次，哈希表查找的时间复杂度是 O(1)。
- **空间复杂度**：O(n)，哈希表需要存储 n 个节点的映射关系，递归调用栈的深度最坏情况下为 O(n)。

### 方法二：递归（直接查找）

- **时间复杂度**：O(n²)，每次递归都需要在中序数组中线性查找索引，最坏情况下是 O(n²)。
- **空间复杂度**：O(n)，递归调用栈。

### 方法三：迭代 + 栈

- **时间复杂度**：O(n)，每个节点入栈出栈各一次。
- **空间复杂度**：O(n)，栈的空间。

## 关键点总结

1. **理解遍历特性**：前序遍历第一个是根节点，中序遍历根节点将左右子树分开
2. **使用哈希表优化**：预先构建中序遍历的值到索引的映射，避免重复查找
3. **索引边界计算**：准确计算左子树大小，正确划分前序和中序遍历的区间
4. **递归终止条件**：当区间为空时（left > right）返回 null
5. **避免数组切片**：使用索引范围传递而不是切片，可以优化空间复杂度

## 易错点

1. **索引计算错误**：左子树大小的计算要特别小心，是 `inRootIndex - inLeft`
2. **边界条件**：递归的左右边界容易出错，要仔细推导
3. **哈希表构建**：确保中序遍历的值没有重复，题目已保证
4. **空节点处理**：要正确处理空树的情况
5. **Java int[] vs List**：Java 中数组不能直接切片，必须用索引范围
