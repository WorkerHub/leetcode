## 题目描述

给你二维整数数组 `groups` 和整数数组 `nums`，判断能否从 `nums` 中选出 n 个有序不重叠子数组，使第 i 个子数组与 `groups[i]` 完全相同。

## 解题思路

贪心：对每个 `group` 从当前起始位置开始在 `nums` 中寻找第一个匹配，找到后更新起始位置（跳过已匹配部分），继续下一个 group。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public boolean canChoose(int[][] groups, int[] nums) {
        int start = 0; // 当前在 nums 中的搜索起始位置

        for (int[] group : groups) {
            int gLen = group.length;
            boolean found = false;

            // 从 start 开始在 nums 中查找 group
            for (int i = start; i <= nums.length - gLen; i++) {
                if (Arrays.equals(Arrays.copyOfRange(nums, i, i + gLen), group)) {
                    start = i + gLen; // 下一个从匹配结束位置后开始
                    found = true;
                    break;
                }
            }

            if (!found) return false;
        }

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m)，n 为 nums 长度，m 为 groups 总长度
- **空间复杂度**：O(m)

## 关键点总结

1. 贪心：每个 group 尽量靠左匹配，为后续 group 留出更多空间
2. 匹配后起始位置前进到匹配结束位置
