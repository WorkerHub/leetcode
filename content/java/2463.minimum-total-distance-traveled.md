## 题目描述

给你机器人位置数组 `robot` 和工厂数组 `factory`（每个工厂有位置和容量限制），返回修理所有机器人的最小总移动距离。

## 解题思路

将工厂按容量展开为多个单容量单元，排序后使用 DP。`dp[i]` 表示前 `i` 个机器人被分配完毕的最小总距离。对每个工厂单元，从后往前枚举分配给该工厂的机器人数量，保证排序后无交叉分配。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumTotalDistance(List<Integer> robot, int[][] factory) {
        Collections.sort(robot);
        Arrays.sort(factory, (a, b) -> a[0] - b[0]);

        // 展开工厂为单容量单元
        List<Integer> fac = new ArrayList<>();
        for (int[] f : factory) {
            for (int i = 0; i < f[1]; i++) fac.add(f[0]);
        }

        int m = robot.size(), n = fac.size();
        long INF = Long.MAX_VALUE / 2;
        long[] dp = new long[m + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int j = 0; j < n; j++) {
            // 逆序遍历，防止同一工厂重复使用
            for (int i = m; i >= 1; i--) {
                long dist = 0;
                // 将机器人 [i-k, i-1] 分配给第 j 个工厂单元
                for (int k = 1; k <= i; k++) {
                    dist += Math.abs(robot.get(i - k) - fac.get(j));
                    if (dp[i - k] < INF) {
                        dp[i] = Math.min(dp[i], dp[i - k] + dist);
                    }
                }
            }
        }
        return dp[m];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × Σlimit)
- **空间复杂度**：O(m + Σlimit)

## 关键点总结

1. 排序后不交叉原则：最优分配中相邻分配不会交叉
2. 展开工厂为单容量单元简化 DP 状态定义
3. 逆序遍历保证每个工厂单元最多使用一次（0/1 背包）
