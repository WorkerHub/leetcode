## 题目描述

给定牌堆 `cardPoints` 和整数 `k`，每次只能从最左或最右取一张牌，恰好取 `k` 张，返回所取牌的最大总分。

## 解题思路

等价转化：取 k 张牌后，剩余 `n-k` 张牌构成连续中间段。问题转化为：在所有长度为 `n-k` 的子数组中找最小和，最大得分 = 总和 - 最小中间段和。

## Java 代码实现

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length;
        int windowSize = n - k; // 不取的中间段大小

        int total = 0;
        for (int v : cardPoints) total += v;

        // k == n 时全部取走
        if (windowSize == 0) return total;

        // 初始化长度为 windowSize 的窗口
        int windowSum = 0;
        for (int i = 0; i < windowSize; i++) windowSum += cardPoints[i];
        int minWindow = windowSum;

        // 滑动窗口求最小和
        for (int i = windowSize; i < n; i++) {
            windowSum += cardPoints[i] - cardPoints[i - windowSize];
            minWindow = Math.min(minWindow, windowSum);
        }

        return total - minWindow;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 核心转化：取 k 张 = 总和 - 中间不取的 n-k 张的最小和。
2. 固定大小 `n-k` 的滑动窗口求最小和。
3. 方法二枚举所有分配方式（左取 i 张 + 右取 k-i 张）。
