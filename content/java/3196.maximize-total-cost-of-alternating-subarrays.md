## 题目描述

将整数数组 `nums` 划分为若干连续子数组，每个子数组 `[a0,a1,a2,...]` 的代价为 `a0 - a1 + a2 - ...`（交替加减），返回所有子数组代价之和的最大值。

## 解题思路

DP：每个元素在其子数组中要么以正号出现（子数组起点），要么以负号出现（跟在正号元素之后）。`f` = 当前元素以正号出现时的最大总代价，`g` = 当前元素以负号出现时的最大总代价（只能接在正号元素后）。

## Java 代码实现

```java
class Solution {
    public long maximumTotalCost(int[] nums) {
        long f = nums[0]; // 以正号出现的最大代价
        long g = Long.MIN_VALUE / 2; // 以负号出现（初始不可能）

        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long newF = Math.max(f, g) + x; // 新子数组开头（正号），接在任意状态后
            long newG = f - x;              // 紧跟正号元素（负号），只能接在 f 后
            f = newF;
            g = newG;
        }
        return Math.max(f, g);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每个元素要么作为子数组起点（正号），要么跟在起点后（负号）
2. 负号元素只能紧接正号元素（不能连续负号）
3. 新子数组可以接在任意状态后，而负号只能接在正号（f）后
