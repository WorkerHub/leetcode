## 题目描述

给你整数数组 `nums` 和整数 `k`，返回 LCM 等于 `k` 的子数组数目。

## 解题思路

枚举所有子数组：以每个位置为起点向右延伸，动态维护当前 LCM，当 LCM 等于 k 时计数，超过 k 时提前终止。

## Java 代码实现

```java
class Solution {
    public int subarrayLCM(int[] nums, int k) {
        int ans = 0;
        for (int i = 0; i < nums.length; i++) {
            long cur = 1;
            for (int j = i; j < nums.length; j++) {
                // 更新当前子数组的 LCM
                cur = lcm(cur, nums[j]);
                if (cur == k) ans++;
                else if (cur > k) break; // LCM 只会增大，提前退出
            }
        }
        return ans;
    }

    private long lcm(long a, long b) {
        return a / gcd(a, b) * b;
    }

    private long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × log k)
- **空间复杂度**：O(1)

## 关键点总结

1. LCM 只会随子数组延伸单调不减，超过 k 时可提前终止
2. `lcm(a, b) = a / gcd(a, b) * b`，先除后乘防溢出
3. 使用 `long` 防止 LCM 计算中间值溢出
