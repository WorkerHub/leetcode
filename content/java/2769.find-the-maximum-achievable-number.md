## 题目描述

给你整数 `num` 和 `t`，每步操作可让 `num` 和某个可达数字各变化 ±1 互相接近，返回 `t` 步内可达的最大数字。

## Java 代码实现

```java
class Solution {
    public int theMaximumAchievableX(int num, int t) {
        // 每步操作使 x 和 num 差距减 2，t 步最多减 2t
        return num + 2 * t;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 每步 x 减 1，num 加 1，差距减少 2
2. t 步后最大差距 2t，所以最大 x = num + 2t
