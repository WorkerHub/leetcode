## 题目描述

给你 row×col 矩阵，`cells[i]` 表示第 i 天变为水的格子，返回最后一个能从最左列走到最右列的天数。

## 解题思路

逆向并查集：从最后一天（全水）逆向恢复陆地，每次将恢复的格子与相邻陆地合并，并连接左/右虚节点，检查左右虚节点何时连通。

## Java 代码实现

```java
class Solution {
    int[] parent, rank;

    public int latestDayToCross(int row, int col, int[][] cells) {
        int n = row * col;
        parent = new int[n + 2];
        rank = new int[n + 2];
        for (int i = 0; i <= n + 1; i++) parent[i] = i;

        int[][] grid = new int[row][col]; // 初始全为水（1）
        for (int[] r : grid) Arrays.fill(r, 1);

        int LEFT = n, RIGHT = n + 1;
        int[] dirs = {-1, 0, 1, 0, -1};

        for (int day = cells.length - 1; day >= 0; day--) {
            int r = cells[day][0] - 1, c = cells[day][1] - 1;
            grid[r][c] = 0;
            int idx = r * col + c;
            if (c == 0) union(idx, LEFT);
            if (c == col - 1) union(idx, RIGHT);
            for (int d = 0; d < 4; d++) {
                int nr = r + dirs[d], nc = c + dirs[d + 1];
                if (nr >= 0 && nr < row && nc >= 0 && nc < col && grid[nr][nc] == 0)
                    union(idx, nr * col + nc);
            }
            if (find(LEFT) == find(RIGHT)) return day;
        }
        return 0;
    }

    private int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * alpha)
- **空间复杂度**：O(n)

## 关键点总结

1. 逆向思路：从全水逐步恢复陆地，比正向更易实现连通判断
2. 左右虚节点简化边界连通判断
3. 路径压缩 + 按秩合并保证近乎 O(1) 的 union-find
