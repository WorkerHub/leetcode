## 题目描述

交互题：数组中相同值的元素聚集成块，求块的数量。用二分跳过整块减少API访问。

## 解题思路

从每块起始位置出发，用二分找到该块结尾（最后一个等于当前值的位置），跳到下一块。

## Java 代码实现

```java
class Solution {
    public int countBlocks(int[] nums) {
        int n = nums.length;
        int count = 0, start = 0;
        while (start < n) {
            count++;
            int target = nums[start];
            // 二分找该块最后一个位置
            int lo = start, hi = n - 1;
            while (lo < hi) {
                int mid = (lo + hi + 1) / 2;
                if (nums[mid] == target) {
                    lo = mid;
                } else {
                    hi = mid - 1;
                }
            }
            start = lo + 1;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(K logN)，K为块数
- **空间复杂度**：O(1)

## 关键点总结

1. **二分找最右等于target的位置**：快速跳过整块
2. **上取整防死循环**：mid=(lo+hi+1)/2
3. **交互题优化**：减少API调用次数
