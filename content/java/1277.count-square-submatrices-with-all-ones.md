## 题目描述

给定 m×n 的 0/1 矩阵，统计完全由 1 组成的正方形子矩阵的个数。

**示例：**
```
输入：matrix = [[0,1,1,1],[1,1,1,1],[0,1,1,1]]
输出：15
```

## 解题思路

DP：dp[i][j] = 以 (i,j) 为右下角的最大正方形边长。dp[i][j] 同时也是以该点为右下角的正方形个数。

## Java 代码实现

```java
class Solution {
    public int countSquares(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] dp = new int[m][n];
        int count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 1) {
                    if (i == 0 || j == 0) {
                        dp[i][j] = 1;
                    } else {
                        dp[i][j] = Math.min(Math.min(dp[i-1][j], dp[i][j-1]), dp[i-1][j-1]) + 1;
                    }
                    count += dp[i][j];
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **DP 定义**：dp[i][j] = 以 (i,j) 为右下角的最大正方形边长
2. **转移方程**：min(上, 左, 左上) + 1
3. **计数技巧**：dp[i][j] 就是以该点为右下角的正方形个数
4. **与 221 题关系**：221 求最大，本题求总数
