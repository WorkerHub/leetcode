## 题目描述

给定正整数 `n`，返回最小的正整数，使得该整数的二进制表示中至少有 n 个置位（二进制中值为 1 的位）。

## 解题思路

最小的含 n 个置位的正整数即低 n 位全为 1、其余位为 0，值为 `2^n - 1`。位运算实现：`(1 << n) - 1`。

## Java 代码实现

```java
class Solution {
    public int smallestNumber(int n) {
        // 低n位全为1，即 2^n - 1
        return (1 << n) - 1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. `(1 << n) - 1` 是生成低 n 位全为 1 掩码的标准写法
2. n 最大为 30，`1 << 30` 在 Java int 范围内
