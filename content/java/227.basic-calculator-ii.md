## 题目描述

给你一个字符串表达式 `s`，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 `[-2^31, 2^31 - 1]` 的范围内。

**注意：** 不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()`。

**示例 1：**

```
输入：s = "3+2*2"
输出：7
```

**示例 2：**

```
输入：s = " 3/2 "
输出：1
```

**示例 3：**

```
输入：s = " 3+5 / 2 "
输出：5
```

**提示：**

- `1 <= s.length <= 3 * 10^5`
- `s` 由整数和算符 `'+'`、`'-'`、`'*'`、`'/'` 组成，中间由一些空格隔开
- `s` 表示一个有效的表达式
- 表达式中的所有整数都是非负整数，且在范围 `[0, 2^31 - 1]` 内
- 题目数据保证答案是一个 32 位整数

## 解题思路

这道题是基本计算器系列的第二题，增加了乘除运算，因此需要考虑**运算符优先级**。

### 核心思想

由于乘除的优先级高于加减，不能简单地从左到右计算。使用**栈**来处理优先级：
1. 遇到加减：将数字（带符号）压入栈
2. 遇到乘除：从栈顶取出数字，与当前数字进行运算，将结果压回栈
3. 最后将栈中所有数字相加

### 算法流程

1. 维护一个栈和当前数字 `num`
2. 维护上一个运算符 `sign`（初始为 `+`）
3. 遍历字符串：
   - 遇到数字：构建完整的数字
   - 遇到运算符或到达末尾：
     - 根据上一个运算符处理当前数字
     - `+`：直接入栈
     - `-`：取负后入栈
     - `*`：与栈顶相乘，结果入栈
     - `/`：与栈顶相除，结果入栈
     - 更新 `sign` 为当前运算符
4. 求和栈中所有数字

## Java 代码实现

### 方法一：栈（推荐）

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        char sign = '+'; // 上一个运算符

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (Character.isDigit(c)) {
                // 构建多位数字
                num = num * 10 + (c - '0');
            }

            // 遇到运算符或到达末尾
            if ((!Character.isDigit(c) && c != ' ') || i == s.length() - 1) {
                // 根据上一个运算符处理数字
                if (sign == '+') {
                    stack.push(num);
                } else if (sign == '-') {
                    stack.push(-num);
                } else if (sign == '*') {
                    stack.push(stack.pop() * num);
                } else if (sign == '/') {
                    stack.push(stack.pop() / num);
                }

                // 更新运算符和数字
                sign = c;
                num = 0;
            }
        }

        // 求栈中所有数字之和
        int result = 0;
        while (!stack.isEmpty()) {
            result += stack.pop();
        }
        return result;
    }
}
```

### 方法三：不使用栈（空间优化）

```java
class Solution {
    public int calculate(String s) {
        s = s.replaceAll(" ", "");
        int num = 0;
        char sign = '+';
        int result = 0;    // 累加和
        int preNum = 0;    // 上一个数字（用于乘除）

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            }

            if (!Character.isDigit(c) || i == s.length() - 1) {
                if (sign == '+') {
                    result += preNum;
                    preNum = num;
                } else if (sign == '-') {
                    result += preNum;
                    preNum = -num;
                } else if (sign == '*') {
                    preNum *= num;
                } else if (sign == '/') {
                    preNum /= num;
                }

                sign = c;
                num = 0;
            }
        }

        return result + preNum;
    }
}
```

### 方法四：详细注释版（便于理解）

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public int calculate(String s) {
        /**
         * 基本计算器 II：支持加减乘除
         *
         * 核心思想：
         * 1. 加减：数字（带符号）直接入栈
         * 2. 乘除：与栈顶元素计算后入栈
         * 3. 最后求和栈中所有元素
         */
        Deque<Integer> stack = new ArrayDeque<>(); // 存储数字
        int num = 0;         // 当前正在构建的数字
        char sign = '+';     // 上一个运算符（初始为加号）

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            // 构建多位数字
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            }

            // 遇到运算符或到达末尾，处理之前的数字
            if ((!Character.isDigit(c) && c != ' ') || i == s.length() - 1) {
                if (sign == '+') {
                    // 加法：直接入栈
                    stack.push(num);
                } else if (sign == '-') {
                    // 减法：取负入栈
                    stack.push(-num);
                } else if (sign == '*') {
                    // 乘法：与栈顶相乘
                    stack.push(stack.pop() * num);
                } else if (sign == '/') {
                    // 除法：与栈顶相除（Java 整数除法自动向零截断）
                    stack.push(stack.pop() / num);
                }

                // 更新运算符
                sign = c;
                // 重置数字
                num = 0;
            }
        }

        // 栈中所有数字的和就是最终结果
        int result = 0;
        while (!stack.isEmpty()) {
            result += stack.pop();
        }
        return result;
    }
}
```

## 复杂度分析

**方法一、二、四：栈方法**
- 时间复杂度：O(n)，遍历字符串一次
- 空间复杂度：O(n)，栈中最多存储 n/2 个数字

**方法三：不使用栈**
- 时间复杂度：O(n)
- 空间复杂度：O(1)，只使用常数个变量

## 图解示例

以 `"3+2*2"` 为例：

```
字符 | num | sign | stack        | 说明
-----|-----|------|--------------|-----
3    | 3   | +    | []           | 构建数字
+    | 0   | +    | [3]          | 遇到 +，将 3 入栈，sign = '+'
2    | 2   | +    | [3]          | 构建数字
*    | 0   | *    | [3, 2]       | 遇到 *，将 2 入栈，sign = '*'
2    | 2   | *    | [3, 2]       | 构建数字
末尾  | 0   | *    | [3, 4]       | 到达末尾，2*2=4，结果入栈
                                  sum = 3 + 4 = 7
```

以 `"3+5/2"` 为例：

```
字符 | num | sign | stack        | 说明
-----|-----|------|--------------|-----
3    | 3   | +    | []           |
+    | 0   | +    | [3]          |
5    | 5   | +    | [3]          |
/    | 0   | /    | [3, 5]       | sign = '/'
2    | 2   | /    | [3, 5]       |
末尾  | 0   | /    | [3, 2]       | 5/2=2，结果入栈
                                  sum = 3 + 2 = 5
```

## 关键点总结

1. **优先级处理**：乘除立即计算，加减入栈延迟计算
2. **符号记录**：用变量记录上一个运算符
3. **除法处理**：Java 的整数除法 `/` 自动向零截断，与题目要求一致
4. **末尾处理**：循环结束时要处理最后一个数字
5. **栈的作用**：临时存储待加减的数字

## 易错点

1. **除法取整**：Java 的 `/` 对整数除法向零截断，行为正确；注意区别于 Python 的 `//`（向下取整）
2. **空格处理**：可以预处理去除空格，或在循环中跳过
3. **末尾数字**：循环结束时要处理最后一个数字
4. **运算符更新时机**：先处理数字，再更新运算符
5. **初始符号**：sign 初始化为 `'+'`，确保第一个数字被正确处理
