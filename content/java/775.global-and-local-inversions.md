## 题目描述

给定长度为 n 的排列 nums（0 到 n-1）。全局倒置是满足 i < j 且 nums[i] > nums[j] 的对数。局部倒置是满足 nums[i] > nums[i+1] 的个数。判断全局倒置数量是否等于局部倒置数量。

**示例：**
```
输入：nums = [1,0,2]
输出：true
```

## 解题思路

局部倒置一定是全局倒置，只需检查是否存在非局部的全局倒置，即每个元素只能偏离理想位置最多 1。

## Java 代码实现

```java
class Solution {
    public boolean isIdealPermutation(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (Math.abs(nums[i] - i) > 1) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **局部 ⊆ 全局**：局部倒置一定是全局倒置
2. **等价条件**：不存在跨度 > 1 的倒置
3. **位置约束**：|nums[i] - i| <= 1
