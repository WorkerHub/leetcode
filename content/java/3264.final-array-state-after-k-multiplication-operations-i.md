## 题目描述

给你整数数组 `nums`、整数 `k` 和整数 `multiplier`。每次操作找出 `nums` 中最小值（多个时取最左边），将其乘以 `multiplier`，执行 k 次后返回最终数组。

## 解题思路

使用最小堆（优先队列）模拟：堆中存储 `(值, 下标)` 对，每次弹出最小值，乘以 multiplier 后重新入堆。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] getFinalState(int[] nums, int k, int multiplier) {
        int n = nums.length;
        // 最小堆：(值, 下标)，值相同时下标小的优先
        PriorityQueue<int[]> pq = new PriorityQueue<>(
            (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]
        );
        for (int i = 0; i < n; i++) pq.offer(new int[]{nums[i], i});

        int[] result = nums.clone();
        for (int i = 0; i < k; i++) {
            int[] top = pq.poll();
            result[top[1]] = top[0] * multiplier;
            pq.offer(new int[]{top[0] * multiplier, top[1]});
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O((k + n) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 最小堆高效找最小值，值相同时按下标升序
2. 弹出最小值乘以 multiplier 后重新入堆
3. 数据范围小，模拟直接可行
