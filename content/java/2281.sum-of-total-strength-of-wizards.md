## 题目描述

所有子数组的"最小值×子数组和"之和，对1e9+7取模。

## 解题思路

单调栈+前缀和的前缀和：枚举每个元素作为最小值，用单调栈确定左右边界，用前缀和的前缀和O(1)计算贡献。

## Java 代码实现

```java
class Solution {
    public int totalStrength(int[] strength) {
        int MOD = 1_000_000_007;
        int n = strength.length;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + strength[i];

        // 前缀和的前缀和
        long[] pp = new long[n + 2];
        for (int i = 0; i <= n; i++) pp[i + 1] = pp[i] + prefix[i];

        long ans = 0;
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i <= n; i++) {
            while (!stack.isEmpty() && (i == n || strength[stack.peek()] >= strength[i])) {
                int mid = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int right = i;
                long leftCnt = mid - left;
                long rightCnt = right - mid;
                // 计算贡献
                long total = (rightCnt % MOD * ((pp[mid + 1] - pp[left + 1]) % MOD) % MOD
                           - leftCnt % MOD * ((pp[right + 1] - pp[mid + 1]) % MOD) % MOD) % MOD;
                ans = (ans + strength[mid] % MOD * total % MOD) % MOD;
            }
            stack.push(i);
        }
        return (int) ((ans % MOD + MOD) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **单调栈确定作用范围**：左严格小于，右小于等于
2. **前缀和的前缀和**：O(1)计算区间前缀和之和
3. **取模处理**：注意负数取模需+MOD
