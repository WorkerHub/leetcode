## 题目描述

给你整数 `zero`、`one`、`low`、`high`，从空字符串开始每次可在末尾添加 `zero` 个 `'0'` 或 `one` 个 `'1'`，返回长度在 `[low, high]` 之间的好字符串数量（结果对 10^9+7 取余）。

## 解题思路

线性 DP：`dp[i]` 为构造长度恰好为 `i` 的字符串的方案数。`dp[i] += dp[i-zero]`（末尾加 zero 个 0）和 `dp[i] += dp[i-one]`（末尾加 one 个 1）。答案为 `dp[low..high]` 的总和。

## Java 代码实现

```java
class Solution {
    public int countGoodStrings(int low, int high, int zero, int one) {
        final int MOD = 1_000_000_007;
        int[] dp = new int[high + 1];
        dp[0] = 1; // 空字符串一种

        for (int i = 1; i <= high; i++) {
            if (i >= zero) dp[i] = (dp[i] + dp[i - zero]) % MOD;
            if (i >= one)  dp[i] = (dp[i] + dp[i - one])  % MOD;
        }

        long ans = 0;
        for (int i = low; i <= high; i++) ans += dp[i];
        return (int) (ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(high)
- **空间复杂度**：O(high)

## 关键点总结

1. 类似爬楼梯问题，每次可跨 `zero` 或 `one` 步
2. 初始化 `dp[0] = 1`（空字符串是起点）
3. 答案是 `dp[low]` 到 `dp[high]` 的和，注意取模
