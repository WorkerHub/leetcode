## 题目描述

返回nums1中不在nums2中的不同整数列表，以及nums2中不在nums1中的不同整数列表。

## 解题思路

将两数组分别转为HashSet，遍历一个集合检查元素是否在另一个集合中。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        Set<Integer> set1 = new HashSet<>();
        Set<Integer> set2 = new HashSet<>();
        for (int x : nums1) set1.add(x);
        for (int x : nums2) set2.add(x);
        
        List<Integer> diff1 = new ArrayList<>();
        List<Integer> diff2 = new ArrayList<>();
        
        for (int x : set1) {
            if (!set2.contains(x)) diff1.add(x);
        }
        for (int x : set2) {
            if (!set1.contains(x)) diff2.add(x);
        }
        
        return Arrays.asList(diff1, diff2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)
- **空间复杂度**：O(M + N)

## 关键点总结

1. **集合去重**：自动去除重复元素
2. **差集运算**：遍历一个集合检查另一个
3. **结果顺序无要求**：任意顺序返回即可
