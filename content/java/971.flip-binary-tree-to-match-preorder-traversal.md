## 题目描述

翻转最少的二叉树节点，使先序遍历匹配给定序列 voyage。返回翻转的节点值列表，或 [-1]。

**示例：**
```
输入：root = [1,2,3], voyage = [1,3,2]
输出：[1]（翻转节点 1 的子树）
```

## 解题思路

DFS 先序遍历：维护指针追踪 voyage 位置。若左子节点不匹配 voyage 下一个值，则翻转（先右后左遍历）。

## Java 代码实现

```java
class Solution {
    private List<Integer> flipped = new ArrayList<>();
    private int idx = 0;

    public List<Integer> flipMatchVoyage(TreeNode root, int[] voyage) {
        if (dfs(root, voyage)) return flipped;
        return Arrays.asList(-1);
    }

    private boolean dfs(TreeNode node, int[] voyage) {
        if (node == null) return true;
        if (node.val != voyage[idx]) return false;
        idx++;

        if (node.left != null && node.left.val != voyage[idx]) {
            // 需要翻转：先右后左
            flipped.add(node.val);
            return dfs(node.right, voyage) && dfs(node.left, voyage);
        }

        return dfs(node.left, voyage) && dfs(node.right, voyage);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **先序遍历匹配**：idx 同步追踪位置
2. **贪心翻转**：左子不匹配时翻转
3. **提前终止**：不匹配立即返回 false
