## 题目描述

给你字符串数组 `words`，可在任意字符串间移动字符，若能使所有字符串相等返回 `true`，否则返回 `false`。

## 解题思路

统计所有字符串中每个字符的总出现次数，若每个字符的次数都能被 n（字符串数量）整除，则可以均分。

## Java 代码实现

```java
class Solution {
    public boolean makeEqual(String[] words) {
        int n = words.length;
        int[] freq = new int[26];
        for (String word : words) {
            for (char c : word.toCharArray()) {
                freq[c - 'a']++;
            }
        }
        // 每个字母的出现次数必须能被 n 整除
        for (int count : freq) {
            if (count % n != 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L)，n 为字符串数量，L 为平均长度
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 字符可任意移动，问题转化为每种字符总数能否被 n 整除
2. 频次为 0 的字符不影响结果
3. 用长度 26 的数组统计字母频次
