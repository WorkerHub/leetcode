## 题目描述

给定含小写字母和括号的字符串，从内到外逐层反转每对括号中的子字符串，返回最终结果（不含括号）。

**示例：**
```
输入：s = "(u(love)i)"
输出："iloveu"
```

## 解题思路

**方法一**：栈模拟。遇到 `(` 将当前字符串压栈开始新层；遇到 `)` 反转当前层并与栈顶拼接。

**方法二**：O(n) 预处理配对位置，遇到括号跳转到配对处并反向遍历。

## Java 代码实现

### 方法一：栈模拟

```java
class Solution {
    public String reverseParentheses(String s) {
        Deque<StringBuilder> stack = new ArrayDeque<>();
        StringBuilder current = new StringBuilder();
        
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(current);
                current = new StringBuilder();
            } else if (c == ')') {
                current.reverse();
                current = stack.pop().append(current);
            } else {
                current.append(c);
            }
        }
        
        return current.toString();
    }
}
```

### 方法二：O(n) 配对跳转

```java
class Solution {
    public String reverseParentheses(String s) {
        int n = s.length();
        int[] pair = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        
        // 预处理括号配对
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else if (s.charAt(i) == ')') {
                int j = stack.pop();
                pair[i] = j;
                pair[j] = i;
            }
        }
        
        // 遍历，遇到括号跳转并反向
        StringBuilder result = new StringBuilder();
        int i = 0, dir = 1;
        while (i < n && i >= 0) {
            if (s.charAt(i) == '(' || s.charAt(i) == ')') {
                i = pair[i];
                dir = -dir;
            } else {
                result.append(s.charAt(i));
            }
            i += dir;
        }
        
        return result.toString();
    }
}
```

## 复杂度分析

- **方法一**：时间 O(n²)，空间 O(n)
- **方法二**：时间 O(n)，空间 O(n)

## 关键点总结

1. **栈处理嵌套**：每对括号代表一层，用栈管理层级
2. **反转时机**：遇到 `)` 时反转当前层
3. **O(n) 优化**：预处理配对后，遇括号跳转并改变方向
4. **方向变量**：dir=1 向右，dir=-1 向左，模拟反转效果
