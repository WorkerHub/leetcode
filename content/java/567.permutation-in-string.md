## 题目描述

给你两个字符串 `s1` 和 `s2`，写一个函数来判断 `s2` 是否包含 `s1` 的排列。如果是，返回 `true`；否则，返回 `false`。

换句话说，`s1` 的排列之一是 `s2` 的**子串**。

**示例 1：**
```
输入：s1 = "ab", s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列之一（"ba"）
```

**示例 2：**
```
输入：s1 = "ab", s2 = "eidboaoo"
输出：false
```

**提示：**
- `1 <= s1.length, s2.length <= 10^4`
- `s1` 和 `s2` 仅包含小写字母

## 解题思路

使用滑动窗口 + 字符计数。

核心思想：
- 维护一个长度为 len(s1) 的滑动窗口
- 比较窗口内的字符频率与 s1 的字符频率

## Java 代码实现

### 方法一：滑动窗口 + 数组计数（推荐）⭐

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        // 滑动窗口 + 字符计数
        int len1 = s1.length(), len2 = s2.length();
        if (len1 > len2) return false;

        // 统计字符频率差值：s2窗口减去s1的频率
        int[] count = new int[26];
        for (int i = 0; i < len1; i++) {
            count[s1.charAt(i) - 'a']--;
            count[s2.charAt(i) - 'a']++;
        }

        // 检查初始窗口
        if (isZero(count)) return true;

        // 滑动窗口
        for (int i = len1; i < len2; i++) {
            count[s2.charAt(i) - 'a']++;             // 添加新字符
            count[s2.charAt(i - len1) - 'a']--;      // 移除旧字符
            if (isZero(count)) return true;
        }

        return false;
    }

    // 检查数组所有元素是否为 0
    private boolean isZero(int[] count) {
        for (int c : count) {
            if (c != 0) return false;
        }
        return true;
    }
}
```

### 方法二：维护匹配字符数

```java
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        // 维护匹配的字符数量
        int len1 = s1.length(), len2 = s2.length();
        if (len1 > len2) return false;

        int[] count = new int[26];
        for (char c : s1.toCharArray()) count[c - 'a']++;

        int[] window = new int[26];
        int matched = 0;

        for (int i = 0; i < len2; i++) {
            // 添加右边字符
            int rc = s2.charAt(i) - 'a';
            window[rc]++;
            if (window[rc] == count[rc]) matched++;
            else if (window[rc] == count[rc] + 1) matched--;  // 超过了，减少匹配数

            // 移除左边字符（窗口超出大小时）
            if (i >= len1) {
                int lc = s2.charAt(i - len1) - 'a';
                if (window[lc] == count[lc]) matched--;
                else if (window[lc] == count[lc] + 1) matched++;
                window[lc]--;
            }

            if (matched == 26) return true;
        }

        return false;
    }
}
```

### 方法三：使用 HashMap

```java
import java.util.*;

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        // 使用 HashMap 计数
        int len1 = s1.length(), len2 = s2.length();
        if (len1 > len2) return false;

        Map<Character, Integer> count1 = new HashMap<>();
        Map<Character, Integer> count2 = new HashMap<>();

        for (char c : s1.toCharArray()) count1.merge(c, 1, Integer::sum);
        for (int i = 0; i < len1; i++) count2.merge(s2.charAt(i), 1, Integer::sum);

        if (count1.equals(count2)) return true;

        for (int i = len1; i < len2; i++) {
            // 添加新字符
            count2.merge(s2.charAt(i), 1, Integer::sum);
            // 移除旧字符
            char old = s2.charAt(i - len1);
            count2.put(old, count2.get(old) - 1);
            if (count2.get(old) == 0) count2.remove(old);

            if (count1.equals(count2)) return true;
        }

        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 是 s2 的长度
- **空间复杂度**：O(1)，字符集大小固定（26个字母）

## 关键点总结

1. **滑动窗口**：固定窗口大小为 len(s1)
2. **字符计数**：比较字符频率
3. **数组优化**：使用长度为 26 的数组代替哈希表，速度更快
