## 题目描述

给定不可变链表，逆序打印每个节点的值。只能使用 printValue() 和 getNext() 接口。

**示例：**
```
输入：head = [1,2,3,4]
输出：4 3 2 1
```

## 解题思路

递归法：利用函数调用栈实现逆序，递归到末尾后在回溯时打印。也可用显式栈。

## Java 代码实现

```java
class Solution {
    // 方法一：递归
    public void printLinkedListInReverse(ImmutableListNode head) {
        if (head == null) return;
        printLinkedListInReverse(head.getNext());
        head.printValue();
    }
}
```

```java
class Solution {
    // 方法二：显式栈
    public void printLinkedListInReverse(ImmutableListNode head) {
        Deque<ImmutableListNode> stack = new ArrayDeque<>();
        ImmutableListNode curr = head;
        while (curr != null) {
            stack.push(curr);
            curr = curr.getNext();
        }
        while (!stack.isEmpty()) {
            stack.pop().printValue();
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)（递归栈或显式栈）

## 关键点总结

1. **递归逆序**：先递归再打印，利用调用栈
2. **显式栈**：遍历入栈，再弹出打印
3. **不可变约束**：不能修改节点，只能读取
