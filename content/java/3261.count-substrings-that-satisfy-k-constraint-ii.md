## 题目描述

给你二进制字符串 `s`、整数 `k` 和查询数组 `queries`，其中 `queries[i] = [li, ri]`。对每个查询，返回子字符串 `s[li..ri]` 中满足 k 约束的子字符串数量。

## 解题思路

滑动窗口预处理每个右端点的最小左端 `minLeft[r]`（满足 k 约束的最小左端）。由于 `minLeft` 单调不减，对查询 `[l, r]` 用二分找分界点 p：`[l, p-1]` 范围内左端被 l 限制，`[p, r]` 范围内直接用前缀和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long[] countKConstraintSubstrings(String s, int k, int[][] queries) {
        int n = s.length();
        int[] minLeft = new int[n];
        int cnt0 = 0, cnt1 = 0, left = 0;

        // 计算每个右端点对应的最小左端点
        for (int right = 0; right < n; right++) {
            if (s.charAt(right) == '0') cnt0++; else cnt1++;
            while (cnt0 > k && cnt1 > k) {
                if (s.charAt(left) == '0') cnt0--; else cnt1--;
                left++;
            }
            minLeft[right] = left;
        }

        // 前缀和：prefix[i] = sum(j - minLeft[j] + 1 for j = 0..i-1)
        long[] prefix = new long[n + 1];
        for (int j = 0; j < n; j++) {
            prefix[j + 1] = prefix[j] + (j - minLeft[j] + 1);
        }

        long[] ans = new long[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1];
            // 二分找第一个 j 满足 minLeft[j] >= l（在 [l, r] 范围内）
            int lo = l, hi = r + 1;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (minLeft[mid] >= l) hi = mid;
                else lo = mid + 1;
            }
            int p = lo;
            // [l, p-1]：minLeft[j] < l，每个右端 j 贡献 j - l + 1
            long cnt = p - l;
            long s1 = cnt * (cnt + 1) / 2; // 等差数列：1+2+...+cnt
            // [p, r]：直接用前缀和
            long s2 = prefix[r + 1] - prefix[p];
            ans[q] = s1 + s2;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 滑动窗口预处理 minLeft，该数组单调不减
2. 二分找分界点，将查询分两段处理
3. 前缀和加速区间求和
