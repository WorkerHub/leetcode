## 题目描述

统计长度为3且无重复字符的子串数量。

## 解题思路

枚举所有长度为3的子串，判断三个字符两两不同。

## Java 代码实现

```java
class Solution {
    public int countGoodSubstrings(String s) {
        int count = 0;
        for (int i = 0; i <= s.length() - 3; i++) {
            if (s.charAt(i) != s.charAt(i + 1) &&
                s.charAt(i + 1) != s.charAt(i + 2) &&
                s.charAt(i) != s.charAt(i + 2)) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **固定窗口大小3**：只需比较3个字符
2. **两两不同**：三个条件AND
