## 题目描述

给你正整数数组 `nums`，返回严格递增子数组的总数目（长度为 1 的子数组也算）。

## 解题思路

DP：设 `cur` 为以当前元素结尾的严格递增子数组数量。若 `nums[i] > nums[i-1]` 则 `cur++`，否则 `cur=1`，累加 `cur` 到答案。

## Java 代码实现

```java
class Solution {
    public long countSubarrays(int[] nums) {
        long total = 0;
        int cur = 1; // 以当前元素结尾的严格递增子数组数量
        for (int i = 0; i < nums.length; i++) {
            if (i > 0 && nums[i] > nums[i - 1]) {
                cur++;
            } else {
                cur = 1;
            }
            total += cur;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 以每个位置结尾的严格递增子数组数 = 当前连续递增段的长度。
2. 长度为 L 的连续递增段共有 L*(L+1)/2 个子数组，等价于逐步累加 cur。
3. 答案可达 n*(n+1)/2 ≈ 5×10^9，需用 `long`。
