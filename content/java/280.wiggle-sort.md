## 题目描述

给你一个整数数组 nums，将它重新排列成 nums[0] <= nums[1] >= nums[2] <= nums[3]... 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

**示例 1：**
```
输入: nums = [3,5,2,1,6,4]
输出: [3,5,1,6,2,4]
解释: [1,6,2,5,3,4] 也是有效的答案
```

**示例 2：**
```
输入: nums = [6,6,5,6,3,8]
输出: [6,6,5,6,3,8]
```

**提示：**
- 1 <= nums.length <= 5 * 10^4
- 0 <= nums[i] <= 10^4
- 题目数据保证可以找到满足题目要求的答案

**进阶：** 你能用 O(n) 时间复杂度和/或原地 O(1) 额外空间来实现吗？

## 解题思路

### 理解摆动排序

摆动排序的规律：
- 偶数索引（0, 2, 4, ...）：`nums[i] <= nums[i+1]`
- 奇数索引（1, 3, 5, ...）：`nums[i] >= nums[i+1]`

形象化：`小 <= 大 >= 小 <= 大 >= ...`

### 思路一：排序后交换（简单但非最优）

1. 对数组排序
2. 将排序后的数组按规则交换相邻元素
3. 时间复杂度：O(n log n)

### 思路二：贪心算法（最优解）

**核心观察：**
- 遍历数组，检查每个位置是否满足摆动条件
- 如果不满足，交换当前元素和下一个元素即可

**为什么贪心有效？**
- 对于偶数位置 i：如果 nums[i] > nums[i+1]，交换后 nums[i] <= nums[i+1]
- 交换不会影响前面已经满足的条件
- 时间复杂度：O(n)，空间复杂度：O(1)

## Java 代码实现

### 方法一：贪心算法（推荐）

```java
class Solution {
    public void wiggleSort(int[] nums) {
        // 贪心算法，原地修改，O(n) 时间，O(1) 空间
        for (int i = 0; i < nums.length - 1; i++) {
            if (i % 2 == 0) {
                // 偶数位置：期望 nums[i] <= nums[i+1]
                if (nums[i] > nums[i + 1]) {
                    swap(nums, i, i + 1);
                }
            } else {
                // 奇数位置：期望 nums[i] >= nums[i+1]
                if (nums[i] < nums[i + 1]) {
                    swap(nums, i, i + 1);
                }
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 方法二：更简洁的贪心写法

```java
class Solution {
    public void wiggleSort(int[] nums) {
        for (int i = 0; i < nums.length - 1; i++) {
            // 判断当前位置应该是 <= 还是 >=
            // 偶数位置应该 <=，奇数位置应该 >=
            boolean shouldBeLess = (i % 2 == 0);

            // 检查是否违反条件
            if ((nums[i] > nums[i + 1]) == shouldBeLess) {
                int temp = nums[i];
                nums[i] = nums[i + 1];
                nums[i + 1] = temp;
            }
        }
    }
}
```

### 方法四：详细注释版（便于理解）

```java
class Solution {
    public void wiggleSort(int[] nums) {
        int n = nums.length;

        // 遍历数组（不包括最后一个元素）
        for (int i = 0; i < n - 1; i++) {
            if (i % 2 == 0) {
                // 偶数位置（0, 2, 4, ...）
                // 期望：nums[i] <= nums[i+1]
                // 如果 nums[i] > nums[i+1]，则违反条件
                if (nums[i] > nums[i + 1]) {
                    // 交换使其满足条件
                    int temp = nums[i];
                    nums[i] = nums[i + 1];
                    nums[i + 1] = temp;
                }
            } else {
                // 奇数位置（1, 3, 5, ...）
                // 期望：nums[i] >= nums[i+1]
                // 如果 nums[i] < nums[i+1]，则违反条件
                if (nums[i] < nums[i + 1]) {
                    // 交换使其满足条件
                    int temp = nums[i];
                    nums[i] = nums[i + 1];
                    nums[i + 1] = temp;
                }
            }
        }
    }
}
```

### 方法五：使用异或技巧（一行判断）

```java
class Solution {
    public void wiggleSort(int[] nums) {
        for (int i = 0; i < nums.length - 1; i++) {
            // (nums[i] > nums[i+1]) ^ (i % 2 == 1) 判断是否需要交换
            // 偶数位置：期望 <=，如果 > 则交换（true ^ false = true）
            // 奇数位置：期望 >=，如果 < 则交换（false ^ true = true）
            if ((nums[i] > nums[i + 1]) ^ (i % 2 == 1)) {
                int temp = nums[i];
                nums[i] = nums[i + 1];
                nums[i + 1] = temp;
            }
        }
    }
}
```

## 复杂度分析

### 方法一、二、四、五：贪心算法

**时间复杂度：** O(n)
- 遍历数组一次
- 每次操作 O(1)

**空间复杂度：** O(1)
- 原地修改，不使用额外空间

### 方法三：排序后重排

**时间复杂度：** O(n log n)
- 排序：O(n log n)
- 交换：O(n)

**空间复杂度：** O(log n)
- 排序的递归栈空间

## 图解示例

**示例：** nums = [3, 5, 2, 1, 6, 4]

**贪心算法过程：**

```
初始: [3, 5, 2, 1, 6, 4]

i=0 (偶数位置，期望 <=):
  3 <= 5 ✓ 不需要交换
  [3, 5, 2, 1, 6, 4]

i=1 (奇数位置，期望 >=):
  5 >= 2 ✓ 不需要交换
  [3, 5, 2, 1, 6, 4]

i=2 (偶数位置，期望 <=):
  2 <= 1 ✗ 需要交换
  [3, 5, 1, 2, 6, 4]

i=3 (奇数位置，期望 >=):
  2 >= 6 ✗ 需要交换
  [3, 5, 1, 6, 2, 4]

i=4 (偶数位置，期望 <=):
  2 <= 4 ✓ 不需要交换
  [3, 5, 1, 6, 2, 4]

最终结果: [3, 5, 1, 6, 2, 4]
验证: 3<=5, 5>=1, 1<=6, 6>=2, 2<=4 ✓
```

## 关键点总结

1. **贪心策略**：逐个检查并修正，不会影响已处理的部分
2. **局部最优性**：交换相邻元素可以立即满足当前位置的条件
3. **不影响前面**：交换 i 和 i+1 不会破坏 i-1 和 i 的关系
4. **条件判断**：
   - 偶数位置：`nums[i] <= nums[i+1]`
   - 奇数位置：`nums[i] >= nums[i+1]`
5. **原地算法**：O(1) 空间复杂度

## 易错点

1. **索引的奇偶判断**
   ```java
   // 错误：混淆奇偶位置的条件
   if (i % 2 == 0 && nums[i] < nums[i + 1]) swap;  // 错误！应该是 >
   
   // 正确
   if (i % 2 == 0 && nums[i] > nums[i + 1]) swap;  // 偶数位置期望 <=
   ```

2. **方法返回类型**：Java 中原地修改，方法返回 void
   ```java
   // 正确：void 方法，原地修改
   public void wiggleSort(int[] nums) {
       // 直接修改 nums，不需要 return
   }
   ```

3. **数组越界**
   ```java
   // 错误：访问 nums[i+1] 时可能越界
   for (int i = 0; i < nums.length; i++)  // 错误！
   
   // 正确：循环到 nums.length - 1
   for (int i = 0; i < nums.length - 1; i++)
   ```

4. **排序法的交换范围**
   ```java
   // 错误：从索引 0 开始交换
   for (int i = 0; i < nums.length - 1; i += 2) swap(i, i+1);
   
   // 正确：从索引 1 开始交换
   for (int i = 1; i < nums.length - 1; i += 2) swap(i, i+1);
   ```
