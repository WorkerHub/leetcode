## 题目描述

给定一个二维网格 grid ，其中：
- '.' 是一个空房间
- '#' 是一堵墙
- '@' 是起点
- 小写字母表示钥匙
- 大写字母表示锁

我们从起点开始，一步步走到网格中的所有钥匙。可以通过空房间和已有钥匙对应的锁。

返回获取 所有钥匙 的最短路径的步数。如果无法获取所有钥匙，返回 -1 。

**示例 1：**
```
输入：grid = ["@.a..", "###.#", "b.A.B"]
输出：8
解释：目标是获取所有钥匙，而不是打开所有锁。
```

**示例 2：**
```
输入：grid = ["@..aA", "..B#.", "....b"]
输出：6
```

**提示：**
- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 30
- grid[i][j] 只含有 '.', '#', '@', 'a'-'f' 以及 'A'-'F'
- 钥匙的数目范围是 [1, 6]

## 解题思路

这是一道**状态压缩 BFS** 的经典题目。

**核心难点：**
- 不能简单地用 (x, y) 表示状态
- 相同位置但持有不同钥匙是不同状态

**状态定义：**
- 状态 = (x, y, keys)
- keys 用二进制表示持有的钥匙集合
- 例如：keys = 0b101 表示持有钥匙 'a' 和 'c'

**算法流程：**
1. BFS 从起点 '@' 开始
2. 状态：(x, y, keys)，keys 是位掩码
3. 遇到钥匙：更新 keys
4. 遇到锁：检查是否有对应钥匙
5. 收集到所有钥匙时返回步数

## Java 代码实现

### 方法一：状态压缩 BFS（推荐）

```java
class Solution {
    public int shortestPathAllKeys(String[] grid) {
        int m = grid.length, n = grid[0].length();

        // 找到起点和钥匙总数
        int startX = 0, startY = 0;
        int keyCount = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                char c = grid[i].charAt(j);
                if (c == '@') {
                    startX = i;
                    startY = j;
                } else if (c >= 'a' && c <= 'f') {
                    keyCount++;
                }
            }
        }

        // 所有钥匙的状态
        int allKeys = (1 << keyCount) - 1;

        // BFS: [x, y, keys]
        Queue<int[]> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer(new int[]{startX, startY, 0});
        String initState = startX + "," + startY + ",0";
        visited.add(initState);

        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int q = 0; q < size; q++) {
                int[] curr = queue.poll();
                int x = curr[0], y = curr[1], keys = curr[2];

                // 收集到所有钥匙
                if (keys == allKeys) return steps;

                // 四个方向
                for (int[] dir : directions) {
                    int nx = x + dir[0], ny = y + dir[1];

                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;

                    char cell = grid[nx].charAt(ny);

                    // 墙
                    if (cell == '#') continue;

                    int newKeys = keys;

                    // 钥匙
                    if (cell >= 'a' && cell <= 'f') {
                        newKeys |= (1 << (cell - 'a'));
                    }

                    // 锁，检查是否有对应钥匙
                    if (cell >= 'A' && cell <= 'F') {
                        if ((keys & (1 << (cell - 'A'))) == 0) continue;
                    }

                    // 新状态
                    String state = nx + "," + ny + "," + newKeys;
                    if (!visited.contains(state)) {
                        visited.add(state);
                        queue.offer(new int[]{nx, ny, newKeys});
                    }
                }
            }
            steps++;
        }

        return -1;
    }
}
```

**代码说明：**
- 状态：(x, y, keys)，keys 是位掩码
- `keys |= (1 << i)` 添加钥匙
- `keys & (1 << i)` 检查是否有钥匙
- 字符串拼接作为状态标识

## 复杂度分析

- **时间复杂度**：O(m × n × 2^k)，k 是钥匙数量。
- **空间复杂度**：O(m × n × 2^k)，visited 集合。

## 关键点总结

1. **状态压缩**：用位掩码表示钥匙集合
2. **三维状态**：(x, y, keys)
3. **BFS 最短路**：保证找到最短路径
4. **位运算**：添加、检查钥匙
5. **状态剪枝**：visited 去重

## 易错点

1. **状态定义不完整**：只用 (x, y) 会出错
2. **钥匙数量**：只有 1-6 个，适合位运算
3. **锁的处理**：检查是否有对应钥匙（对应大小写字母）
