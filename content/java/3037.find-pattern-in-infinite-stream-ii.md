## 题目描述

在无限二进制流中找pattern第一次出现的起始下标。（pattern长度<=10^6）

## 解题思路

流式KMP匹配：预处理失配表后，逐字符从流中读取并匹配。

## Java 代码实现

```java
class Solution {
    public int findPattern(InfiniteStream stream, int[] pattern) {
        int m = pattern.length;
        // KMP失配表
        int[] fail = new int[m];
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && pattern[i] != pattern[j]) j = fail[j - 1];
            if (pattern[i] == pattern[j]) j++;
            fail[i] = j;
        }

        // 流式匹配
        j = 0;
        int idx = 0;
        while (true) {
            int c = stream.next();
            while (j > 0 && c != pattern[j]) j = fail[j - 1];
            if (c == pattern[j]) j++;
            if (j == m) return idx - m + 1;
            idx++;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N+M)，N为读取字符数
- **空间复杂度**：O(M)

## 关键点总结

1. **流式KMP**：无需缓存整个流
2. **失配回退**：每字符均摊O(1)
3. **返回起始下标**：idx-m+1
