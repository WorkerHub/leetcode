## 题目描述

按顺序执行替换操作，将数组中original替换为replaced，返回最终数组。

## 解题思路

HashMap记录值到下标的映射，每次替换O(1)查找位置并更新映射。

## Java 代码实现

```java
class Solution {
    public int[] arrayChange(int[] nums, int[][] operations) {
        Map<Integer, Integer> pos = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            pos.put(nums[i], i);
        }

        for (int[] op : operations) {
            int idx = pos.get(op[0]);
            nums[idx] = op[1];
            pos.remove(op[0]);
            pos.put(op[1], idx);
        }
        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + Q)
- **空间复杂度**：O(N)

## 关键点总结

1. **HashMap维护值->下标映射**：O(1)查找
2. **每次替换更新映射**：删旧键加新键
3. **保证操作合法**：original存在，replaced不存在
