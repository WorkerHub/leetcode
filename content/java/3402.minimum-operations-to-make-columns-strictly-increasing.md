## 题目描述

给定 m×n 非负整数矩阵，每次操作可将任意元素加 1，返回使每列严格递增所需的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int totalOps = 0;

        for (int col = 0; col < n; col++) {
            int prev = grid[0][col];
            for (int row = 1; row < m; row++) {
                int cur = grid[row][col];
                if (cur <= prev) {
                    // 需要增加到 prev + 1
                    totalOps += prev + 1 - cur;
                    prev = prev + 1;
                } else {
                    prev = cur;
                }
            }
        }
        return totalOps;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)，遍历矩阵每个元素一次
- 空间复杂度：O(1)

## 关键点总结

1. 每列独立处理，互不影响。
2. 贪心地将当前元素调整为"恰好比前一个元素大 1"是最优策略。
3. 调整后的值需传递给下一行作为参考基准。
