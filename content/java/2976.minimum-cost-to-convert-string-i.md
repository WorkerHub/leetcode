## 题目描述

给你字符串 `source`、`target` 以及字符转换规则数组 `original`、`changed` 和 `cost`，返回将 source 转换为 target 的最少总代价，不可能则返回 -1。

## 解题思路

将 26 个字母视为图节点，转换规则为有向边。用 Floyd-Warshall 预计算所有字母对的最短转换代价（26³ = 17576 次），然后对每个位置查询对应字母对的代价。

## Java 代码实现

```java
class Solution {
    public long minimumCost(String source, String target, char[] original, char[] changed, int[] cost) {
        final long INF = Long.MAX_VALUE / 2;
        long[][] dist = new long[26][26];
        for (long[] row : dist) Arrays.fill(row, INF);
        for (int i = 0; i < 26; i++) dist[i][i] = 0;

        // 初始化转换边（取最小代价）
        for (int i = 0; i < cost.length; i++) {
            int u = original[i] - 'a', v = changed[i] - 'a';
            dist[u][v] = Math.min(dist[u][v], cost[i]);
        }

        // Floyd-Warshall
        for (int k = 0; k < 26; k++)
            for (int i = 0; i < 26; i++)
                for (int j = 0; j < 26; j++)
                    if (dist[i][k] + dist[k][j] < dist[i][j])
                        dist[i][j] = dist[i][k] + dist[k][j];

        long total = 0;
        for (int i = 0; i < source.length(); i++) {
            int u = source.charAt(i) - 'a', v = target.charAt(i) - 'a';
            if (u == v) continue;
            if (dist[u][v] == INF) return -1;
            total += dist[u][v];
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(26³ + n)
- **空间复杂度**：O(26²)

## 关键点总结

1. 字符转换问题转化为 26 节点图的最短路
2. Floyd-Warshall 对 26 个字母代价极低
3. 同一字母对可能有多条边，初始化时取最小代价
