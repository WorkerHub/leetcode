## 题目描述

对每个下标i，计算以i为中心、半径k的子数组平均值（向下取整），越界为-1。

## 解题思路

前缀和：窗口大小固定2k+1，prefix[i+k+1]-prefix[i-k]得区间和，除以窗口大小。

## Java 代码实现

```java
class Solution {
    public int[] getAverages(int[] nums, int k) {
        int n = nums.length;
        int[] avgs = new int[n];
        Arrays.fill(avgs, -1);
        int window = 2 * k + 1;
        if (window > n) return avgs;
        
        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        
        for (int i = k; i < n - k; i++) {
            long sum = prefix[i + k + 1] - prefix[i - k];
            avgs[i] = (int)(sum / window);
        }
        return avgs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **前缀和**：O(1)区间和查询
2. **long防溢出**：大数组元素之和可能超int
3. **有效范围**：中心在[k, n-k-1]
