## 题目描述

给定正整数 `n`，返回 [0, n] 范围内二进制表示不包含连续 1 的非负整数个数。

**示例：**
```
输入：n = 5
输出：5
```

## 解题思路

数位 DP + 斐波那契：不含连续 1 的 k 位二进制数个数满足斐波那契规律。

## Java 代码实现

```java
class Solution {
    public int findIntegers(int n) {
        // 转为二进制
        String binary = Integer.toBinaryString(n);
        int k = binary.length();

        // fib[i] 表示 i 位二进制中不含连续1的个数
        int[] fib = new int[k + 1];
        fib[0] = 1;
        fib[1] = 2;
        for (int i = 2; i <= k; i++) {
            fib[i] = fib[i - 1] + fib[i - 2];
        }

        int result = 0;
        int prevBit = 0;

        for (int i = 0; i < k; i++) {
            if (binary.charAt(i) == '1') {
                // 加上当前位为0的所有合法数
                result += fib[k - i - 1];
                // 连续1，后面都不合法
                if (prevBit == 1) return result;
                prevBit = 1;
            } else {
                prevBit = 0;
            }
        }
        return result + 1; // n 本身也合法
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **斐波那契**：不含连续 1 的数量 = fib 规律
2. **逐位处理**：遇到 1 时累加当前位为 0 的情况
3. **连续 1 终止**：出现连续 1 后面都不合法
