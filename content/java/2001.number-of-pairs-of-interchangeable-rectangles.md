## 题目描述

给定二维数组 `rectangles`，若两个矩形宽高比相同则可互换，返回可互换矩形对的数目。

## 解题思路

对每个矩形用 GCD 将宽高化简为最简分数，以此为键用哈希表计数。对相同比例的矩形数量 n，贡献 `n*(n-1)/2` 对。

## Java 代码实现

### 方法一：哈希表 + 组合计数（推荐）

```java
import java.util.*;

class Solution {
    public long interchangeableRectangles(int[][] rectangles) {
        Map<String, Integer> ratioCount = new HashMap<>();

        for (int[] r : rectangles) {
            int g = gcd(r[0], r[1]);
            // 用最简分数"w/h"作为键，避免浮点精度问题
            String key = (r[0] / g) + "/" + (r[1] / g);
            ratioCount.merge(key, 1, Integer::sum);
        }

        long result = 0;
        for (int cnt : ratioCount.values()) {
            result += (long) cnt * (cnt - 1) / 2;
        }
        return result;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = b;
            b = a % b;
            a = t;
        }
        return a;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log M)，M 为最大值（GCD 计算）
- 空间复杂度：O(n)

## 关键点总结

1. 用 GCD 将宽高比化简为最简分数，作为哈希表的键
2. 不能用浮点数比较宽高比，必须用整数最简分数避免精度问题
3. 组合数公式 `C(n,2) = n*(n-1)/2`，结果用 long 防止溢出
