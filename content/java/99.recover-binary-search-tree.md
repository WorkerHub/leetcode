## 题目描述

给你二叉搜索树的根节点 `root`，该树中的 **恰好** 两个节点的值被错误地交换。请在不改变其结构的情况下，恢复这棵树。

**示例 1：**

```
输入：root = [1,3,null,null,2]
输出：[3,1,null,null,2]
解释：3 不能是 1 的左孩子，因为 3 > 1。交换 1 和 3 使二叉搜索树有效。
```

**示例 2：**

```
输入：root = [3,1,4,null,null,2]
输出：[2,1,4,null,null,3]
解释：2 不能在 3 的右子树中，因为 2 < 3。交换 2 和 3 使二叉搜索树有效。
```

**提示：**

- 树上节点的数目在范围 `[2, 1000]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

**进阶：** 使用 O(n) 空间复杂度的解法很容易实现。你能想出一个只使用 O(1) 空间的解决方案吗？

## 解题思路

这道题建立在第 98 题（验证 BST）的基础上，需要利用 BST 的中序遍历性质。

**核心思想：**

1. **BST 性质：** 正确的 BST 中序遍历结果是严格递增序列
2. **错误特征：** 如果两个节点被交换，中序遍历会出现逆序对（前一个数大于后一个数）
3. **交换情况分析：**
   - **相邻交换：** 只有一个逆序对，如 `[1,3,2,4]`（交换了 3 和 2）
   - **不相邻交换：** 有两个逆序对，如 `[1,4,3,2,5]`（交换了 4 和 2）

**算法流程：**

1. 进行中序遍历，找到所有逆序对
2. 记录第一个逆序对的第一个节点（较大的）
3. 记录最后一个逆序对的第二个节点（较小的）
4. 交换这两个节点的值

**示例演示：**

- **相邻交换：** `[1, 3, 2, 4]`
  - 逆序对：3 > 2
  - 需要交换：3 和 2

- **不相邻交换：** `[1, 4, 3, 2, 5]`
  - 第一个逆序对：4 > 3（记录 4）
  - 第二个逆序对：3 > 2（记录 2）
  - 需要交换：4 和 2

## Java 代码实现

### 方法一：递归中序遍历（推荐）

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    private TreeNode first = null;  // 第一个错误节点（第一个逆序对的较大值）
    private TreeNode second = null; // 第二个错误节点（最后一个逆序对的较小值）
    private TreeNode prev = null;   // 中序遍历的前一个节点

    public void recoverTree(TreeNode root) {
        // 中序遍历找到错误节点
        inorder(root);

        // 交换两个错误节点的值
        if (first != null && second != null) {
            int temp = first.val;
            first.val = second.val;
            second.val = temp;
        }
    }

    // 中序遍历，找到被交换的节点
    private void inorder(TreeNode node) {
        if (node == null) {
            return;
        }

        // 遍历左子树
        inorder(node.left);

        // 检查当前节点
        if (prev != null && prev.val > node.val) {
            // 发现逆序对
            if (first == null) {
                // 第一个逆序对：记录较大的节点
                first = prev;
            }
            // 无论是第一个还是第二个逆序对，都更新 second
            // 这样可以处理相邻和不相邻两种情况
            second = node;
        }

        // 更新 prev
        prev = node;

        // 遍历右子树
        inorder(node.right);
    }
}
```

### 方法二：迭代中序遍历

```java
class Solution {
    public void recoverTree(TreeNode root) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode first = null, second = null, prev = null;
        TreeNode current = root;

        while (!stack.isEmpty() || current != null) {
            // 一直向左走
            while (current != null) {
                stack.push(current);
                current = current.left;
            }

            // 处理当前节点
            current = stack.pop();

            // 检查是否出现逆序
            if (prev != null && prev.val > current.val) {
                if (first == null) {
                    first = prev;
                }
                second = current;
            }

            prev = current;
            current = current.right;
        }

        // 交换节点值
        if (first != null && second != null) {
            int temp = first.val;
            first.val = second.val;
            second.val = temp;
        }
    }
}
```

### 方法三：Morris 中序遍历（O(1) 空间，进阶）

```java
class Solution {
    public void recoverTree(TreeNode root) {
        TreeNode first = null, second = null, prev = null;
        TreeNode current = root;

        while (current != null) {
            if (current.left == null) {
                // 没有左子树，直接处理当前节点
                if (prev != null && prev.val > current.val) {
                    if (first == null) {
                        first = prev;
                    }
                    second = current;
                }
                prev = current;
                current = current.right;
            } else {
                // 有左子树，找到前驱节点
                TreeNode predecessor = current.left;
                while (predecessor.right != null && predecessor.right != current) {
                    predecessor = predecessor.right;
                }

                if (predecessor.right == null) {
                    // 建立线索
                    predecessor.right = current;
                    current = current.left;
                } else {
                    // 已经建立过线索，说明左子树已遍历完
                    // 处理当前节点
                    if (prev != null && prev.val > current.val) {
                        if (first == null) {
                            first = prev;
                        }
                        second = current;
                    }
                    prev = current;

                    // 恢复树的结构
                    predecessor.right = null;
                    current = current.right;
                }
            }
        }

        // 交换节点值
        if (first != null && second != null) {
            int temp = first.val;
            first.val = second.val;
            second.val = temp;
        }
    }
}
```

### 方法四：数组法（最直观，适合初学者）

```java
class Solution {
    public void recoverTree(TreeNode root) {
        // 存储中序遍历的节点（不是值，是节点引用）
        List<TreeNode> nodes = new ArrayList<>();
        inorder(root, nodes);

        // 找到被交换的两个节点
        TreeNode first = null, second = null;
        for (int i = 0; i < nodes.size() - 1; i++) {
            if (nodes.get(i).val > nodes.get(i + 1).val) {
                if (first == null) {
                    first = nodes.get(i);
                }
                second = nodes.get(i + 1);
            }
        }

        // 交换节点值
        if (first != null && second != null) {
            int temp = first.val;
            first.val = second.val;
            second.val = temp;
        }
    }

    private void inorder(TreeNode node, List<TreeNode> nodes) {
        if (node == null) {
            return;
        }
        inorder(node.left, nodes);
        nodes.add(node);
        inorder(node.right, nodes);
    }
}
```

## 复杂度分析

**方法一、二、四：**

- **时间复杂度：** O(n)，n 是树中节点数量，需要遍历所有节点
- **空间复杂度：**
  - 方法一、二：O(h)，递归栈或迭代栈的空间，h 是树高
  - 方法四：O(n)，需要额外列表存储所有节点

**方法三（Morris）：**

- **时间复杂度：** O(n)，虽然有嵌套循环，但每条边最多访问 2 次
- **空间复杂度：** O(1)，只使用常量级别的额外空间

## 关键点总结

1. **中序遍历是关键：** BST 的中序遍历是递增序列，被交换的节点会破坏这个性质
2. **逆序对识别：**
   - 相邻交换：1 个逆序对
   - 不相邻交换：2 个逆序对
3. **节点记录策略：**
   - `first`：第一个逆序对的较大节点
   - `second`：持续更新为逆序对的较小节点（最后一次更新的值）
4. **交换的是值而非节点：** 题目要求不改变树的结构，所以交换节点的 `val` 而不是节点引用
5. **Morris 遍历：** 通过临时修改树结构实现 O(1) 空间，是进阶技巧

## 易错点

1. **记录节点而非值：**
   ```java
   // 错误：只记录值
   int firstVal = prev.val; // 无法后续交换

   // 正确：记录节点引用
   first = prev; // 可以通过 first.val 交换
   ```

2. **second 的更新策略：**
   ```java
   // 错误：只在第二个逆序对时更新
   // 正确：每次逆序都更新 second，相邻和不相邻都能处理
   if (first == null) {
       first = prev;
   }
   second = current; // 无论第几次逆序，都更新 second
   ```

3. **忘记交换：**
   - 找到节点后必须交换值，不能只是记录

4. **Morris 遍历恢复结构：**
   ```java
   // 必须恢复树的原始结构
   predecessor.right = null; // 断开临时建立的线索
   ```

5. **Java 中交换值需要临时变量：**
   ```java
   int temp = first.val;
   first.val = second.val;
   second.val = temp;
   ```
