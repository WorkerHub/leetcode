## 题目描述

n根不同高度木棍排列，从左看恰好能看到k根的排列方案数。对10^9+7取模。

## 解题思路

DP：dp[n][k] = dp[n-1][k-1] + (n-1)*dp[n-1][k]。最短木棍放最左则可见(+1)，放其他位置(n-1种)则不可见。即第一类无符号斯特林数。

## Java 代码实现

```java
class Solution {
    public int rearrangeSticks(int n, int k) {
        int MOD = 1_000_000_007;
        // 滚动数组优化
        long[] prev = new long[k + 1];
        prev[0] = 1;
        
        for (int i = 1; i <= n; i++) {
            long[] curr = new long[k + 1];
            for (int j = 1; j <= Math.min(i, k); j++) {
                curr[j] = (prev[j - 1] + (long)(i - 1) * prev[j]) % MOD;
            }
            prev = curr;
        }
        return (int) prev[k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × K)
- **空间复杂度**：O(K)

## 关键点总结

1. **递推公式**：dp[n][k] = dp[n-1][k-1] + (n-1)*dp[n-1][k]
2. **第一类斯特林数**：将n个元素排成k个循环的方案数
3. **滚动数组**：只需前一行数据
