## 题目描述

卡车有主油箱和副油箱，每消耗 5 升主油箱燃料可从副油箱补充 1 升，每升行驶 10 km，返回最大行驶距离。

## Java 代码实现

```java
class Solution {
    public int distanceTraveled(int mainTank, int additionalTank) {
        // 补充次数：每消耗5升补1升，不超过副油箱容量
        int refills = Math.min(mainTank / 5, additionalTank);
        // 总燃料 = 主油箱 + 补充量，每升10km
        return (mainTank + refills) * 10;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 补充次数上限是 `mainTank / 5`（消耗 5 升才补 1 升）
2. 不超过副油箱容量 `additionalTank`
