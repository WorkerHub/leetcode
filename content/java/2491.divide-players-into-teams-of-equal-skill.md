## 题目描述

给你偶数长度的技能数组 `skill`，将玩家两两配对使每队技能总和相同，返回所有队伍化学值（两人技能乘积）之和，无法满足则返回 -1。

## 解题思路

排序后双指针：最小和最大配对，次小和次大配对，以此类推。若任意一对的和不等于第一对的和，返回 -1；否则累加乘积。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long dividePlayers(int[] skill) {
        Arrays.sort(skill);
        int n = skill.length;
        int target = skill[0] + skill[n - 1]; // 目标每队技能总和
        long ans = 0;

        for (int l = 0, r = n - 1; l < r; l++, r--) {
            if (skill[l] + skill[r] != target) return -1;
            ans += (long) skill[l] * skill[r];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后，最小和最大必须配对，否则无法使所有队技能和相等
2. 双指针验证每对的和，不相等立即返回 -1
3. 化学值是乘积而非和，使用 `long` 防止溢出
