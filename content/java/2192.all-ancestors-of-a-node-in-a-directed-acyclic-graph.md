## 题目描述

DAG中找每个节点的所有祖先（能到达该节点的所有节点），按升序返回。

## 解题思路

拓扑排序传播祖先集合：按拓扑序处理，对每条边u->v，v的祖先=u的祖先+u。或对每个节点u做DFS将u加入所有可达节点的祖先集。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> getAncestors(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        
        // 对每个节点u做DFS，将u加入所有可达节点的祖先集
        Set<Integer>[] ancestors = new HashSet[n];
        for (int i = 0; i < n; i++) ancestors[i] = new HashSet<>();
        
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
        }
        
        for (int u = 0; u < n; u++) {
            // DFS从u出发
            dfs(u, u, graph, ancestors);
        }
        
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            List<Integer> list = new ArrayList<>(ancestors[i]);
            Collections.sort(list);
            result.add(list);
        }
        return result;
    }
    
    private void dfs(int start, int cur, List<List<Integer>> graph, Set<Integer>[] ancestors) {
        for (int nxt : graph.get(cur)) {
            if (!ancestors[nxt].contains(start)) {
                ancestors[nxt].add(start);
                dfs(start, nxt, graph, ancestors);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * (N + E))
- **空间复杂度**：O(N^2)

## 关键点总结

1. **对每个节点做DFS**：将该节点加入所有可达节点的祖先集
2. **剪枝**：若start已在ancestors[nxt]中则跳过
3. **最终排序输出**：set转sorted list
