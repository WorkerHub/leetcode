## 题目描述

给定二维数组 `properties`，每个元素为 `[attack, defense]`，若一个角色的攻击和防御均严格小于另一个角色，则该角色为弱角色，返回弱角色数量。

## 解题思路

按 attack 降序排序，相同 attack 时按 defense 升序（防止同 attack 互相误判）。从左到右维护已见最大 defense，若当前 defense 小于最大值则为弱角色。

## Java 代码实现

### 方法一：排序 + 贪心（推荐）

```java
import java.util.*;

class Solution {
    public int numberOfWeakCharacters(int[][] properties) {
        // attack降序，相同attack时defense升序
        Arrays.sort(properties, (a, b) -> {
            if (a[0] != b[0]) return b[0] - a[0];
            return a[1] - b[1];
        });

        int maxDef = 0, count = 0;
        for (int[] p : properties) {
            if (p[1] < maxDef) {
                count++;
            } else {
                maxDef = p[1];
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 按 attack 降序排序后，前面的角色 attack 都 >= 当前
2. 相同 attack 按 defense 升序，防止同 attack 角色互相误判为弱
3. 维护 maxDef：当前 defense < maxDef 则为弱角色
