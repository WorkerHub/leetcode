## 题目描述

给你整数数组 nums，返回所有满足 i < j < k 的三元组中 `(nums[i] - nums[j]) * nums[k]` 的最大值，若全为负则返回 0。

## 解题思路

数据量小（n ≤ 100），直接三重循环暴力枚举所有三元组。

## Java 代码实现

```java
class Solution {
    public long maximumTripletValue(int[] nums) {
        int n = nums.length;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    long val = (long) (nums[i] - nums[j]) * nums[k];
                    ans = Math.max(ans, val);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^3)
- **空间复杂度**：O(1)

## 关键点总结

1. 返回值 >= 0（全负时返回 0）
2. 使用 long 防止 `(nums[i] - nums[j]) * nums[k]` 溢出
3. 数据量小（n ≤ 100），三重循环完全可行
