## 题目描述

给你整数数组 `nums` 和查询数组 `queries`：类型 1 更新某元素，类型 2 查询子数组 `[l, r]` 内的峰值数量（峰值：`nums[i-1] < nums[i] > nums[i+1]`，1 <= i <= n-2）。

## 解题思路

用树状数组（BIT）维护峰值前缀计数。初始化时标记所有峰值；类型 1 更新时，重新判断修改位置及其相邻位置的峰值状态并更新 BIT；类型 2 查询时，对 `[l+1, r-1]` 范围做 BIT 区间求和。

## Java 代码实现

```java
class Solution {
    int[] bit, nums;
    int n;

    public List<Integer> countOfPeaks(int[] nums, int[][] queries) {
        this.nums = nums;
        this.n = nums.length;
        this.bit = new int[n + 1];

        // 初始化 BIT
        for (int i = 1; i < n - 1; i++) {
            if (isPeak(i)) update(i + 1, 1); // BIT 下标从 1 开始
        }

        List<Integer> ans = new ArrayList<>();
        for (int[] q : queries) {
            if (q[0] == 1) {
                int idx = q[1], val = q[2];
                // 记录邻居旧峰值状态
                boolean[] prev = new boolean[3];
                for (int k = -1; k <= 1; k++) {
                    int j = idx + k;
                    if (j > 0 && j < n - 1) prev[k + 1] = isPeak(j);
                }
                nums[idx] = val;
                // 更新邻居峰值状态
                for (int k = -1; k <= 1; k++) {
                    int j = idx + k;
                    if (j > 0 && j < n - 1) {
                        boolean cur = isPeak(j);
                        if (prev[k + 1] && !cur) update(j + 1, -1);
                        else if (!prev[k + 1] && cur) update(j + 1, 1);
                    }
                }
            } else {
                int l = q[1], r = q[2];
                // 峰值只在 [l+1, r-1] 范围内，BIT 下标 = nums 下标 + 1
                ans.add(l + 1 > r - 1 ? 0 : query(r) - query(l + 1));
            }
        }
        return ans;
    }

    private boolean isPeak(int i) {
        return nums[i - 1] < nums[i] && nums[i] > nums[i + 1];
    }

    private void update(int i, int delta) {
        for (; i <= n; i += i & -i) bit[i] += delta;
    }

    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & -i) s += bit[i];
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 树状数组维护峰值前缀计数，支持单点更新和前缀查询
2. 更新 nums[i] 时，需重新判断 i-1、i、i+1 三个位置的峰值状态
3. 查询 [l, r] 中的峰值实际对应 BIT 范围 [l+2, r]（BIT 下标 = nums 下标 + 1）
