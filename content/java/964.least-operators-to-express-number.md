## 题目描述

给定正整数 x，用 x 和 +、-、*、/ 运算构造等于 target 的表达式，返回所需最少运算符数。

**示例：**
```
输入：x = 3, target = 19
输出：5（3*3+3*3+3/3）
```

## 解题思路

将 target 按 x 进制分解。对每一位的余数 r，选择用 r 个 x^k 加上去或用 (x-r) 个 x^k 减掉（进位）。DP 追踪正向和负向的最小操作符数。

## Java 代码实现

```java
class Solution {
    public int leastOpsExpressTarget(int x, int target) {
        int pos = 0, neg = 0, k = 0;

        while (target > 0) {
            int remainder = target % x;
            target /= x;

            if (k == 0) {
                // x/x = 1，每个需要 2 个操作符
                pos = remainder * 2;
                neg = (x - remainder) * 2;
            } else {
                int newPos = Math.min(remainder * k + pos, (remainder + 1) * k + neg);
                int newNeg = Math.min((x - remainder) * k + pos, (x - remainder - 1) * k + neg);
                pos = newPos;
                neg = newNeg;
            }
            k++;
        }

        // 减 1 是因为第一个数不需要运算符
        return Math.min(pos - 1, k + neg - 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log_x(target))
- **空间复杂度**：O(1)

## 关键点总结

1. **进制分解**：target 按 x 进制逐位处理
2. **进位选择**：每位可以加上或进位减去
3. **操作符计算**：x^k 需要 k 个操作符，x/x 需要 2 个
4. **最终减 1**：第一个数不计算操作符
