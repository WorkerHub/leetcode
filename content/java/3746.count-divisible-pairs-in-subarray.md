## 题目描述

给定整数数组 `nums` 和整数 `k`，对于每个子数组 `[l, r]`，统计其中满足 `nums[i] % k == 0` 的元素数量。对所有子数组的这个计数求总和。

## 解题思路

对于每个位置 `i`，若 `nums[i] % k == 0`，则统计包含 `i` 的子数组数量。包含下标 `i` 的子数组个数 = `(i + 1) * (n - i)`。

## Java 代码实现

```java
class Solution {
    public long countDivisiblePairs(int[] nums, int k) {
        int n = nums.length;
        long total = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i] % k == 0) {
                // 包含下标 i 的子数组数量
                total += (long)(i + 1) * (n - i);
            }
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 元素 `i` 的贡献 = 包含 `i` 的子数组数量（若可整除）
2. 包含下标 `i` 的子数组数量 = `(i+1) * (n-i)`
3. 使用 `long` 防止整数溢出
