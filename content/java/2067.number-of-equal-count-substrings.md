## 题目描述

字符串 s 中，每种出现的字符恰好出现 count 次的子字符串称为等计数子字符串，返回其数目。

## 解题思路

枚举字符种数 k（1~26），固定窗口大小 `k*count`，滑动窗口同时维护当前窗口内频次恰好等于 count 的字符种数 `exactCount`，当 `len(freq)==k && exactCount==k` 时满足条件。

## Java 代码实现

### 方法一：枚举字符种数 + 滑动窗口（推荐）

```java
import java.util.*;

class Solution {
    public int equalCountSubstrings(String s, int count) {
        int n = s.length(), total = 0;
        for (int k = 1; k <= 26; k++) {
            int windowSize = k * count;
            if (windowSize > n) break;
            int[] freq = new int[26];
            int distinct = 0, exactCount = 0;

            for (int i = 0; i < n; i++) {
                // 加入右侧字符
                int ci = s.charAt(i) - 'a';
                if (freq[ci] == 0) distinct++;
                if (freq[ci] == count) exactCount--;
                freq[ci]++;
                if (freq[ci] == count) exactCount++;

                // 移除左侧字符
                if (i >= windowSize) {
                    int co = s.charAt(i - windowSize) - 'a';
                    if (freq[co] == count) exactCount--;
                    freq[co]--;
                    if (freq[co] == count) exactCount++;
                    if (freq[co] == 0) distinct--;
                }

                // 检查
                if (i >= windowSize - 1 && distinct == k && exactCount == k) total++;
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26 * n)
- 空间复杂度：O(26)

## 关键点总结

1. 枚举字符种数 k，固定窗口大小 k*count
2. 维护 distinct（不同字符数）和 exactCount（频次恰好为 count 的字符数）
3. 条件：`distinct == k && exactCount == k`
