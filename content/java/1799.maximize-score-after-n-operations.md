## 题目描述

给你 `2*n` 个正整数，执行 n 次操作，第 i 次操作选两个元素得 `i * gcd(x, y)` 分并移除。返回最大总分。

## 解题思路

状态压缩 DP：`dp[mask]` 表示已使用元素集合为 mask 时的最大得分。当前操作次序 = `popcount(mask)/2`。

每次固定 mask 中最低位元素 i，枚举另一个元素 j，从 `dp[mask ^ i ^ j]` 转移。预处理所有对的 GCD。

## Java 代码实现

```java
class Solution {
    public int maxScore(int[] nums) {
        int m = nums.length; // m = 2*n
        // 预计算所有对的 gcd
        int[][] g = new int[m][m];
        for (int i = 0; i < m; i++)
            for (int j = i + 1; j < m; j++)
                g[i][j] = gcd(nums[i], nums[j]);

        int[] dp = new int[1 << m];

        for (int mask = 1; mask < (1 << m); mask++) {
            int used = Integer.bitCount(mask);
            if (used % 2 != 0) continue; // 使用元素数必须为偶数
            int op = used / 2; // 当前是第 op 次操作

            // 固定最低位 i
            int lowBit = mask & (-mask);
            int i = Integer.numberOfTrailingZeros(lowBit);
            int rest = mask ^ lowBit;

            // 枚举 j（rest 中的每个位）
            for (int tmp = rest; tmp != 0; tmp &= (tmp - 1)) {
                int jBit = tmp & (-tmp);
                int j = Integer.numberOfTrailingZeros(jBit);
                int prev = mask ^ lowBit ^ jBit;
                dp[mask] = Math.max(dp[mask], dp[prev] + op * g[i][j]);
            }
        }

        return dp[(1 << m) - 1];
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(3^(2n))，枚举所有子集的子集
- **空间复杂度**：O(2^(2n))

## 关键点总结

1. 用二进制 mask 表示已使用元素集合，popcount/2 为操作次数
2. 固定最低位减少枚举冗余，枚举另一个元素 j
3. 预计算 GCD 避免重复计算
