## 题目描述

有 `n` 个城市，按从 `0` 到 `n-1` 编号。给你一个边数组 `edges`，其中 `edges[i] = [from_i, to_i, weight_i]` 代表 `from_i` 和 `to_i` 两个城市之间的双向加权边，距离阈值是一个整数 `distanceThreshold`。

返回能通过某些路径到达其他城市数目**最少**、且路径距离**最大**为 `distanceThreshold` 的城市。如果有多个这样的城市，则返回编号**最大**的城市。

注意，连接城市 i 和 j 的路径的距离等于沿该路径的所有边的权重之和。

**示例 1：**
```
输入：n = 4, edges = [[0,1,3],[1,2,1],[1,3,4],[2,3,1]], distanceThreshold = 4
输出：3
解释：城市 0 可以到达城市 {1, 2} (距离 ≤ 4)，共 2 个
     城市 1 可以到达城市 {0, 2, 3}，共 3 个
     城市 2 可以到达城市 {0, 1, 3}，共 3 个
     城市 3 可以到达城市 {1, 2}，共 2 个
     城市 0 和城市 3 都是 2 个，返回编号更大的 3。
```

**示例 2：**
```
输入：n = 5, edges = [[0,1,2],[0,4,8],[1,2,3],[1,4,2],[2,3,1],[3,4,1]], distanceThreshold = 2
输出：0
```

**提示：**
- `2 <= n <= 100`
- `1 <= edges.length <= n * (n - 1) / 2`
- `edges[i].length == 3`
- `0 <= from_i < to_i < n`
- `1 <= weight_i, distanceThreshold <= 10^4`
- 所有 `(from_i, to_i)` 对互不相同。

## 解题思路

**算法：Floyd-Warshall 全对最短路**

由于 n 最大为 100，我们需要求出任意两个城市之间的最短路径。Floyd-Warshall 算法时间复杂度 O(n^3)，对于 n=100 完全可以接受。

**Floyd-Warshall 核心思想：**
- 初始化距离矩阵：直接相邻的城市用边权，其他城市初始化为无穷大，自己到自己为 0
- 状态转移：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`
- 含义：通过中间节点 k，看是否能缩短 i 到 j 的距离
- 枚举所有中间节点 k，对所有 (i, j) 对更新

**最终统计：** 对每个城市，统计能在阈值内到达的城市数，取最少的（多个取编号最大）。

## Java 代码实现

### 方法一：Floyd-Warshall 算法（推荐）

```java
class Solution {
    public int findTheCity(int n, int[][] edges, int distanceThreshold) {
        final int INF = 10_000_000;
        
        // 初始化距离矩阵
        int[][] dist = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                dist[i][j] = (i == j) ? 0 : INF;
            }
        }
        
        // 根据边初始化直接相邻的距离（无向图，双向）
        for (int[] e : edges) {
            dist[e[0]][e[1]] = e[2];
            dist[e[1]][e[0]] = e[2];
        }
        
        // Floyd-Warshall：枚举中间节点 k（k 必须在最外层）
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dist[i][k] + dist[k][j] < dist[i][j]) {
                        dist[i][j] = dist[i][k] + dist[k][j];
                    }
                }
            }
        }
        
        // 找到可达城市数最少的城市（多个则取编号最大）
        int result = -1;
        int minCount = n;
        
        for (int i = 0; i < n; i++) {
            // 统计从城市 i 出发，距离 <= distanceThreshold 的城市数（不含自身）
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (i != j && dist[i][j] <= distanceThreshold) {
                    count++;
                }
            }
            // count 更少，或 count 相同但 i 更大（遍历顺序保证取最大编号）
            if (count <= minCount) {
                minCount = count;
                result = i;
            }
        }
        
        return result;
    }
}
```

### 方法二：Dijkstra 对每个城市求最短路

```java
import java.util.*;

class Solution {
    public int findTheCity(int n, int[][] edges, int distanceThreshold) {
        // 建立邻接表
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        
        int result = -1;
        int minCount = n;
        
        // 对每个城市运行 Dijkstra
        for (int src = 0; src < n; src++) {
            int[] dist = dijkstra(graph, n, src);
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (j != src && dist[j] <= distanceThreshold) count++;
            }
            if (count <= minCount) {
                minCount = count;
                result = src;
            }
        }
        
        return result;
    }
    
    private int[] dijkstra(List<int[]>[] graph, int n, int src) {
        final int INF = Integer.MAX_VALUE / 2;
        int[] dist = new int[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;
        // 最小堆：(距离, 节点)
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, src});
        
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue; // 已有更短路径，跳过
            for (int[] next : graph[u]) {
                int v = next[0], w = next[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }
        
        return dist;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| Floyd-Warshall | O(n^3) | O(n^2) |
| Dijkstra × n | O(n * (E + n) log n) | O(n + E) |

- Floyd-Warshall 在 n=100 时约 10^6 次操作，完全够用
- Dijkstra 适合稀疏图，但需要对每个城市各跑一次

## 关键点总结

1. Floyd-Warshall 是求全对最短路的标准算法，三重循环 `O(n^3)`
2. 枚举中间节点 k 时，k 必须是最外层循环（这是算法正确性的保证）
3. 找最少可达数的城市时，相同数量取编号更大的，可以用 `count <= minCount` 而非 `<`
4. 本题 n ≤ 100，Floyd-Warshall 是最简洁的选择

## 易错点

1. Floyd-Warshall 三重循环的顺序：k 必须在最外层，i 和 j 可以互换
2. 统计可达城市时要排除自身（`i != j`）
3. 找最大编号的城市：遍历从小到大，用 `<=` 更新（遇到相同可达数时更新为更大编号）
4. 初始化时用较大整数（如 `10_000_000`）而非 `Integer.MAX_VALUE`，避免加法溢出

## 学习建议

1. Floyd-Warshall 算法是图的基础知识，建议先理解其状态转移方程的含义
2. 三重循环的第一层是"中间节点"，不是起点或终点，初学者容易搞混
3. 对于稀疏图（边少），Dijkstra 更高效；对于稠密图（边多，n 小），Floyd 更简洁
4. 初始化很重要：对角线为 0，直接边为权重，其余为无穷大
