## 题目描述

你正在安装一个广告牌，并希望它高度最大。这块广告牌将有两个钢制支架，两边各一个。每个钢支架的高度必须相等。

你有一堆可以焊接在一起的钢筋 `rods`。举个例子，如果钢筋的长度为 `1`、`2` 和 `3`，则可以将它们焊接在一起形成长度为 `6` 的支架。

返回广告牌的最大可能安装高度。如果没法安装广告牌，请返回 `0`。

**示例 1：**
```
输入：rods = [1,2,3,6]
输出：6
解释：我们有两个支架，长度分别为 1+2+3=6 和 6
```

**示例 2：**
```
输入：rods = [1,2,3,4,5,6]
输出：10
解释：我们有两个支架，长度分别为 1+2+3+4=10 和 5+6=11，但是我们只能得到长度 10，因为我们需要两个等长的支架
```

**示例 3：**
```
输入：rods = [1,2]
输出：0
解释：无法让两个支架等高
```

**提示：**
- `1 <= rods.length <= 20`
- `1 <= rods[i] <= 1000`
- `sum(rods[i]) <= 5000`

## 解题思路

这道题要求将钢筋分成两组，使得两组的和相等，并且最大化这个和。

**核心思想：**

1. **动态规划**：定义状态 `dp[diff]` 表示两组高度差为 diff 时，较矮组的最大高度
2. **差值转移**：每根钢筋有三种选择：
   - 放到较高组：差值增大
   - 放到较矮组：差值减小
   - 不使用：差值不变

3. **状态压缩**：只关心差值，不关心具体哪组更高

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    /**
     * 动态规划：dp[diff] 表示两组高度差为 diff 时，较矮组的最大高度
     */
    public int tallestBillboard(int[] rods) {
        // dp[diff] = 较矮组的最大高度
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 0);

        for (int rod : rods) {
            // 必须使用新的字典，避免重复使用同一根钢筋
            Map<Integer, Integer> newDp = new HashMap<>(dp);

            for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                int diff = entry.getKey();
                int shorter = entry.getValue();
                int longer = shorter + diff;

                // 选择1：放到较高组
                int newDiff1 = diff + rod;
                newDp.put(newDiff1, Math.max(newDp.getOrDefault(newDiff1, 0), shorter));

                // 选择2：放到较矮组
                int newShorter = shorter + rod;
                int newDiff2 = Math.abs(newShorter - longer);
                int newShorterVal = Math.min(newShorter, longer);
                newDp.put(newDiff2, Math.max(newDp.getOrDefault(newDiff2, 0), newShorterVal));
            }

            dp = newDp;
        }

        return dp.getOrDefault(0, 0);
    }
}
```

### 方法二：简化的DP

```java
class Solution {
    /**
     * 简化版DP
     */
    public int tallestBillboard(int[] rods) {
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 0);

        for (int r : rods) {
            Map<Integer, Integer> newDp = new HashMap<>(dp);
            for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                int diff = entry.getKey();
                int y = entry.getValue();

                // 放到较高组
                newDp.put(diff + r, Math.max(newDp.getOrDefault(diff + r, 0), y));
                // 放到较矮组
                int newDiff = Math.abs(diff - r);
                int newY = Math.max(y, y + diff - r);
                newDp.put(newDiff, Math.max(newDp.getOrDefault(newDiff, 0), newY));
            }
            dp = newDp;
        }

        return dp.getOrDefault(0, 0);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × S)，N是钢筋数量，S是钢筋和的总和
- **空间复杂度**：O(S)

## 关键点总结

1. **状态定义**：用差值作为状态关键
2. **转移方程**：三种选择的状态转移
3. **HashMap优化**：使用 HashMap 而非数组节省空间

## 易错点

1. 必须复制 HashMap 避免重复使用
2. 差值可能为负，需要取绝对值
3. Java 中 HashMap 的 getOrDefault 避免空指针
