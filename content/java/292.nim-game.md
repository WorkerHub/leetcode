## 题目描述

你和你的朋友，两个人一起玩 Nim 游戏：

- 桌子上有一堆石头。
- 你们轮流进行自己的回合，你作为先手。
- 每一回合，轮到的人拿掉 1 - 3 块石头。
- 拿掉最后一块石头的人就是获胜者。

假设你们每一步都是最优解。请编写一个函数，来判断你是否可以在给定石头数量为 n 的情况下赢得游戏。如果可以赢，返回 true；否则，返回 false。

**示例 1：**
```
输入：n = 4
输出：false
解释：以下是可能的结果:
1. 移除1颗石头。你的朋友移除3颗石头，包括最后一颗。你的朋友赢了。
2. 移除2颗石头。你的朋友移除2颗石头，包括最后一颗。你的朋友赢了。
3. 移除3颗石头。你的朋友移除最后一颗石头。你的朋友赢了。
在所有结果中，你的朋友都赢了。
```

**示例 2：**
```
输入：n = 1
输出：true
```

**示例 3：**
```
输入：n = 2
输出：true
```

**提示：**
- 1 <= n <= 2^31 - 1

## 解题思路

这是一道经典的博弈论问题，看起来需要复杂的动态规划，实际上有巧妙的数学规律。

**核心观察：寻找必败态**

1. 从小到大分析：
   - n = 1：先手拿 1，必胜
   - n = 2：先手拿 2，必胜
   - n = 3：先手拿 3，必胜
   - n = 4：无论先手拿 1、2、3，后手都能拿完，必败
   - n = 5：先手拿 1，剩 4，后手必败，先手必胜
   - n = 6：先手拿 2，剩 4，后手必败，先手必胜
   - n = 7：先手拿 3，剩 4，后手必败，先手必胜
   - n = 8：无论先手拿多少，后手都能构造出 4 的倍数，必败

2. **规律发现：**
   - 当 n 是 4 的倍数时，先手必败
   - 当 n 不是 4 的倍数时，先手必胜

3. **证明：**
   - 如果 n % 4 == 0，无论先手拿走 k (1≤k≤3) 个，后手总可以拿走 4-k 个，保持总共拿走 4 个
   - 最终后手总能让先手面对 4 的倍数，直到先手面对 4，必败
   - 如果 n % 4 != 0，先手可以拿走 n % 4 个，让后手面对 4 的倍数，转化为必败态

## Java 代码实现

### 方法一：数学规律（推荐）

```java
class Solution {
    public boolean canWinNim(int n) {
        // 当 n 不是 4 的倍数时，先手必胜
        return n % 4 != 0;
    }
}
```

### 方法二：位运算优化

```java
class Solution {
    public boolean canWinNim(int n) {
        // n & 3 取最低两位，如果为 0 说明是 4 的倍数
        // 等价于 n % 4 != 0
        return (n & 3) != 0;
    }
}
```

### 方法三：动态规划（超时，仅用于理解）

```java
class Solution {
    public boolean canWinNim(int n) {
        // 注意：当 n 很大时（如 2^31-1），此方法会超时且内存溢出
        // 仅用于理解问题原理
        if (n <= 3) return true;

        // dp[i] = true 表示当前玩家必胜
        boolean[] dp = new boolean[n + 1];

        // 初始状态：1-3 个石头都是必胜
        dp[1] = dp[2] = dp[3] = true;

        // 状态转移：只要存在一种拿法让对手必败，当前就必胜
        for (int i = 4; i <= n; i++) {
            dp[i] = !dp[i - 1] || !dp[i - 2] || !dp[i - 3];
        }

        return dp[n];
    }
}
```

## 复杂度分析

### 方法一（数学规律）：

**时间复杂度：** O(1)
- 只需要一次取模运算

**空间复杂度：** O(1)
- 只使用常量空间

### 方法三（动态规划）：

**时间复杂度：** O(n)
- 需要遍历从 4 到 n 的所有数字

**空间复杂度：** O(n)
- 需要一个长度为 n+1 的数组

注意：对于 n 很大的情况（如 2^31 - 1），这个方法会超时和内存溢出

```
关键观察：

规律：n % 4 == 0 时先手必败
```

## 关键点总结

1. **寻找规律**：通过小数据找出 4 的倍数是必败态
2. **博弈论基础**：
   - 如果存在一种操作让对手进入必败态，当前就是必胜态
   - 如果所有操作都让对手进入必胜态，当前就是必败态
3. **数学证明**：证明 4 的倍数具有传递性
4. **优化思路**：从 O(n) 的 DP 优化到 O(1) 的数学规律
5. **Nim 游戏**：这是 Nim 游戏的简化版，经典的博弈论问题

## 易错点

1. **使用动态规划**
   ```java
   // 错误：会超时
   boolean[] dp = new boolean[n + 1]; // n 可能是 2^31-1

   // 正确：直接用数学规律
   return n % 4 != 0;
   ```

2. **整数溢出**
   ```java
   // 注意：n 的范围是 1 <= n <= 2^31-1（即 Integer.MAX_VALUE）
   // n % 4 不会溢出，直接使用即可
   return n % 4 != 0;
   ```

3. **判断条件写反**
   ```java
   // 错误：4的倍数是必胜（应该是必败）
   return n % 4 == 0;
   
   // 正确：4的倍数是必败
   return n % 4 != 0;
   ```
