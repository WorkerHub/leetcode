## 题目描述

给你一个单链表，随机选择链表的一个节点，并返回相应的节点值。每个节点**被选中的概率一样**。

实现 `Solution` 类：

- `Solution(ListNode head)` 使用整数数组初始化对象。
- `int getRandom()` 从链表中随机选择一个节点并返回该节点的值。链表中所有节点被选中的概率相等。

**示例 1:**

![](https://assets.leetcode.com/uploads/2021/03/16/getrand-linked-list.jpg)

```
输入
["Solution", "getRandom", "getRandom", "getRandom", "getRandom", "getRandom"]
[[[1, 2, 3]], [], [], [], [], []]
输出
[null, 1, 3, 2, 2, 3]

解释
Solution solution = new Solution([1, 2, 3]);
solution.getRandom(); // 返回 1
solution.getRandom(); // 返回 3
solution.getRandom(); // 返回 2
solution.getRandom(); // 返回 2
solution.getRandom(); // 返回 3
// getRandom() 应随机返回 1、2、3中的一个，每个元素被返回的概率相等。
```

**提示:**

- 链表中的节点数在范围 `[1, 10^4]` 内
- `-10^4 <= Node.val <= 10^4`
- 至多调用 `getRandom` 方法 `10^4` 次

**进阶:**

- 如果链表非常大且长度未知，该怎么办？
- 你能否在不使用额外空间的情况下解决这个问题？

## 解题思路

本题有两种经典解法：**预处理法**和**蓄水池抽样法**。

### 思路一：预处理 - 转换为数组

最简单的方法是在初始化时遍历链表，将所有节点值存入数组，然后随机返回数组中的元素。

**优点：** `getRandom()` 时间复杂度 O(1)  
**缺点：** 需要 O(n) 额外空间

### 思路二：蓄水池抽样（Reservoir Sampling）⭐

**核心思想：** 遍历链表一次，在不知道链表长度的情况下，保证每个节点被选中的概率相等。

**算法流程：**

1. 初始化结果为第一个节点的值
2. 遍历链表，对于第 `i` 个节点（i 从 1 开始）：
   - 以 `1/i` 的概率选择该节点替换当前结果
   - 即生成 `[0, i)` 范围的随机数，如果为 0，则替换结果
3. 遍历结束后返回结果

**数学证明（为什么每个节点概率相等）：**

对于第 `k` 个节点被最终选中的概率：
- 第 `k` 次时被选中的概率：`1/k`
- 后续不被替换的概率：`(k/(k+1)) * ((k+1)/(k+2)) * ... * ((n-1)/n) = k/n`
- 最终概率：`1/k * k/n = 1/n` ✓

每个节点被选中的概率都是 `1/n`。

## Java 代码实现

### 方法一：预处理为数组（推荐新手）

```java
import java.util.*;

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    private List<Integer> nums;
    private Random random;

    /** 初始化时将链表转换为数组，时间复杂度: O(n)，空间复杂度: O(n) */
    public Solution(ListNode head) {
        nums = new ArrayList<>();
        random = new Random();
        ListNode curr = head;
        while (curr != null) {
            nums.add(curr.val);
            curr = curr.next;
        }
    }

    /** 随机返回数组中的一个元素，时间复杂度: O(1) */
    public int getRandom() {
        return nums.get(random.nextInt(nums.size()));
    }
}
```

### 方法二：蓄水池抽样（推荐）⭐

```java
import java.util.Random;

class Solution {
    private ListNode head;
    private Random random;

    /** 初始化只保存链表头节点，时间复杂度: O(1)，空间复杂度: O(1) */
    public Solution(ListNode head) {
        this.head = head;
        this.random = new Random();
    }

    /**
     * 蓄水池抽样算法
     * 时间复杂度: O(n)
     * 空间复杂度: O(1)
     */
    public int getRandom() {
        ListNode curr = head;
        int result = curr.val;
        int i = 1; // 节点编号，从 1 开始

        curr = curr.next;
        while (curr != null) {
            i++;
            // 以 1/i 的概率选择当前节点（生成 [0, i) 的随机数，等于 0 则替换）
            if (random.nextInt(i) == 0) {
                result = curr.val;
            }
            curr = curr.next;
        }

        return result;
    }
}
```

### 方法三：蓄水池抽样（另一种写法）

```java
import java.util.Random;

class Solution {
    private ListNode head;
    private Random random;

    public Solution(ListNode head) {
        this.head = head;
        this.random = new Random();
    }

    /** 使用计数器实现，从第一个节点开始计数 */
    public int getRandom() {
        ListNode curr = head;
        int result = 0;
        int count = 0;

        while (curr != null) {
            count++;
            // 以 1/count 的概率选择当前节点
            if (random.nextInt(count) == 0) {
                result = curr.val;
            }
            curr = curr.next;
        }

        return result;
    }
}
```

## 复杂度分析

### 方法一：预处理为数组

**时间复杂度：**
- 初始化：O(n)，需要遍历整个链表
- `getRandom()`：O(1)，直接随机访问数组

**空间复杂度：** O(n)，需要额外数组存储所有节点值

### 方法二：蓄水池抽样

**时间复杂度：**
- 初始化：O(1)，只保存头节点引用
- `getRandom()`：O(n)，每次需要遍历整个链表

**空间复杂度：** O(1)，只使用常数额外空间

## 关键点总结

1. **蓄水池抽样算法**：在不知道总数的情况下等概率随机选择元素的经典算法
2. **概率证明**：理解为什么每个节点被选中的概率是 1/n
3. **时间空间权衡**：预处理空间换时间，蓄水池抽样时间换空间
4. **Java Random 使用**：`random.nextInt(i)` 生成 [0, i) 范围随机数
5. **应用场景**：处理数据流、超大数据集的随机抽样

## 易错点

1. **索引从 0 还是 1 开始**：蓄水池抽样通常从 1 开始计数更自然
2. **随机数范围**：`nextInt(i)` 是左闭右开 [0, i)，注意边界
3. **空链表处理**：题目保证至少有一个节点，但实际应用需要处理
4. **概率理解错误**：不是每次以 1/n 概率选择，而是第 i 个以 1/i 概率

## 图解示例

以链表 `[1, 2, 3]` 为例，蓄水池抽样过程：

```
初始状态：
链表: 1 -> 2 -> 3
result = 1 (第一个节点)

第 2 个节点:
随机数范围 [0, 2)
- 生成 0: 替换 result = 2 (概率 1/2)
- 生成 1: 保持 result = 1 (概率 1/2)

第 3 个节点:
随机数范围 [0, 3)
- 生成 0: 替换 result = 3 (概率 1/3)
- 生成 1/2: 保持当前 result (概率 2/3)

最终每个节点被选中的概率:
- 节点 1: 1 * (1/2) * (2/3) = 1/3
- 节点 2: (1/2) * (2/3) = 1/3
- 节点 3: 1/3
```
