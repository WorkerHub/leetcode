## 题目描述

给定环形整数数组 `nums`，返回非空子数组的最大可能和。环形数组意味着末端与开头相连。

**示例：**
```
输入：nums = [5,-3,5]
输出：10（子数组 [5,5] 跨越边界）
```

## 解题思路

两种情况：1）最大子数组不跨越边界（Kadane 算法）；2）跨越边界 = 总和 - 最小子数组和。特殊情况：全为负数时直接返回最大值。

## Java 代码实现

```java
class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int totalSum = 0;
        int maxSum = nums[0], curMax = 0;
        int minSum = nums[0], curMin = 0;

        for (int num : nums) {
            totalSum += num;
            // Kadane 求最大子数组和
            curMax = Math.max(curMax + num, num);
            maxSum = Math.max(maxSum, curMax);
            // Kadane 求最小子数组和
            curMin = Math.min(curMin + num, num);
            minSum = Math.min(minSum, curMin);
        }

        // 全为负数时，maxSum < 0，直接返回最大元素
        if (maxSum < 0) return maxSum;
        // 否则取两种情况的最大值
        return Math.max(maxSum, totalSum - minSum);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两种情况**：不跨越边界 vs 跨越边界
2. **问题转化**：跨越边界最大和 = 总和 - 最小子数组和
3. **特殊处理**：全负数时直接返回最大值
