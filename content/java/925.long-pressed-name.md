## 题目描述

检查键盘输入 typed 是否可能是 name 的长按版本（某些字符可能被重复输入）。

**示例：**
```
输入：name = "alex", typed = "aaleex"
输出：true
```

## 解题思路

双指针：同时遍历 name 和 typed。字符匹配则都前进；不匹配时若 typed 当前字符与前一个相同则跳过（长按）；否则返回 false。

## Java 代码实现

```java
class Solution {
    public boolean isLongPressedName(String name, String typed) {
        int i = 0, j = 0;
        int m = name.length(), n = typed.length();

        while (j < n) {
            if (i < m && name.charAt(i) == typed.charAt(j)) {
                i++;
                j++;
            } else if (j > 0 && typed.charAt(j) == typed.charAt(j - 1)) {
                j++; // 长按导致的重复
            } else {
                return false;
            }
        }

        return i == m;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针同步**：匹配时同步前进
2. **长按判断**：不匹配时检查是否是重复字符
3. **终止条件**：name 必须全部匹配完
