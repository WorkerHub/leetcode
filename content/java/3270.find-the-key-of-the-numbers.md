## 题目描述

给你三个正整数 `num1`、`num2` 和 `num3`（均不超过 9999）。对每一位从低到高取三者最小值，拼成新数即为**密钥**。

## 解题思路

逐位（个位、十位、百位、千位）取三个数字对应位的最小值，累加到结果中。

## Java 代码实现

```java
class Solution {
    public int generateKey(int num1, int num2, int num3) {
        int result = 0;
        int place = 1; // 当前位的权重（个位=1，十位=10，...）
        for (int i = 0; i < 4; i++) {
            int d1 = (num1 / place) % 10;
            int d2 = (num2 / place) % 10;
            int d3 = (num3 / place) % 10;
            result += Math.min(d1, Math.min(d2, d3)) * place;
            place *= 10;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)，最多处理 4 位
- 空间复杂度：O(1)

## 关键点总结

1. 按位取最小，位数不足时高位视为 0
2. 最大 4 位（1 <= num <= 9999）
3. 前导零在整数结果中自动忽略
