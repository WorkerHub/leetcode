## 题目描述

给定字符串 s，返回只含一个不同字母的子字符串个数。

**示例：**
```
输入: s = "aaaba"
输出: 8（"aaa"贡献6个 + "b"贡献1个 + "a"贡献1个）
```

## 解题思路

分组统计连续相同字符段的长度 n，每段贡献 n*(n+1)/2 个子串。

## Java 代码实现

```java
class Solution {
    public int countLetters(String s) {
        int result = 0, count = 1;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == s.charAt(i - 1)) {
                count++;
            } else {
                result += count * (count + 1) / 2;
                count = 1;
            }
        }
        // 处理最后一段
        result += count * (count + 1) / 2;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **数学公式**：n 个连续相同字符贡献 n*(n+1)/2 个子串
2. **分段计数**：遇到不同字符则结算上一段
3. **别忘最后一段**：循环结束后还要结算最后一段
4. **count 初始化为 1**：第一个字符本身就是一段的开始
