## 题目描述

交互题：在隐藏网格中，通过 `canMove(direction)` 移动并探索，`isTarget()` 判断是否到达终点。返回从起点到终点的最短路径长度（不可达返回 -1）。

## 解题思路

两步法：先用 DFS（带回溯）探索所有可达格子并记录终点位置，再在已知图上 BFS 求最短路。

## Java 代码实现

```java
import java.util.*;

// 接口定义（由平台提供）
interface GridMaster {
    boolean canMove(char direction);
    boolean isTarget();
}

class Solution {
    private static final char[] DIRS = {'U', 'D', 'L', 'R'};
    private static final int[][] DELTAS = {{-1,0},{1,0},{0,-1},{0,1}};
    private static final char[] OPP = {'D', 'U', 'R', 'L'}; // 反方向

    private Set<Long> passable = new HashSet<>();
    private long target = Long.MIN_VALUE;

    public int findShortestPath(GridMaster master) {
        dfs(master, 0, 0);
        if (target == Long.MIN_VALUE) return -1;

        // BFS 求最短路
        Deque<long[]> queue = new ArrayDeque<>();
        Set<Long> seen = new HashSet<>();
        queue.offer(new long[]{0, 0, 0});
        seen.add(encode(0, 0));

        while (!queue.isEmpty()) {
            long[] cur = queue.poll();
            int r = (int) cur[0], c = (int) cur[1], dist = (int) cur[2];
            if (encode(r, c) == target) return dist;

            for (int[] d : DELTAS) {
                int nr = r + d[0], nc = c + d[1];
                long key = encode(nr, nc);
                if (!seen.contains(key) && passable.contains(key)) {
                    seen.add(key);
                    queue.offer(new long[]{nr, nc, dist + 1});
                }
            }
        }

        return -1;
    }

    private void dfs(GridMaster master, int r, int c) {
        long key = encode(r, c);
        passable.add(key);
        if (master.isTarget()) target = key;

        for (int i = 0; i < 4; i++) {
            int nr = r + DELTAS[i][0], nc = c + DELTAS[i][1];
            long nkey = encode(nr, nc);
            if (!passable.contains(nkey) && master.canMove(DIRS[i])) {
                dfs(master, nr, nc);
                master.canMove(OPP[i]); // 回溯
            }
        }
    }

    private long encode(int r, int c) {
        return ((long)(r + 1000)) * 10000 + (c + 1000); // 偏移防负数
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. DFS 探图时需要回溯（通过反方向移动回原位）
2. 探图完成后 BFS 求最短路
