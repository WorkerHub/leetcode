## 题目描述

给定升序唯一整数数组 nums，返回从数组最左侧开始的第 k 个缺失数字。

**示例：**
```
输入：nums = [4,7,9,10], k = 3
输出：8（缺失：5,6,8,...，第3个是8）
```

## 解题思路

二分查找：位置 i 处缺失数量 = nums[i] - nums[0] - i。二分找第一个缺失数 ≥ k 的位置，然后计算具体值。

## Java 代码实现

```java
class Solution {
    public int missingElement(int[] nums, int k) {
        int n = nums.length;

        // 如果 k 超出数组范围
        int totalMissing = nums[n - 1] - nums[0] - (n - 1);
        if (k > totalMissing) {
            return nums[n - 1] + k - totalMissing;
        }

        // 二分查找第一个 missing(i) >= k 的位置
        int left = 0, right = n - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            int missing = nums[mid] - nums[0] - mid;
            if (missing < k) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        // 第 k 个缺失数在 nums[left-1] 之后
        return nums[left - 1] + k - (nums[left - 1] - nums[0] - (left - 1));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **缺失计算公式**：missing(i) = nums[i] - nums[0] - i
2. **二分目标**：找第一个缺失数 ≥ k 的位置
3. **边界处理**：k 超出数组范围时在末尾之后计算
