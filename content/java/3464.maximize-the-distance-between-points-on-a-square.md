## 题目描述

给你正方形边长 `side` 和边上的点数组 `points`，从中选 `k` 个点使相邻点（沿正方形边顺序）之间的最小距离最大化。返回这个最大化的最小距离。

## 解题思路

将点映射为沿正方形边的弧长坐标（0 到 4*side），二分最小距离 d，贪心验证：从每个起始点出发，依次选距离 >= d 的下一个点，检查是否能选出 k 个且首尾距离也 >= d。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxDistance(int side, int[][] points, int k) {
        int n = points.length;
        long[] arcs = new long[n];
        for (int i = 0; i < n; i++) {
            arcs[i] = toArc(points[i][0], points[i][1], side);
        }
        Arrays.sort(arcs);

        long P = 4L * side;
        long lo = 1, hi = P / k, ans = 0;

        while (lo <= hi) {
            long mid = (lo + hi) / 2;
            if (canPlace(arcs, n, k, mid, P)) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return (int) ans;
    }

    // 将点映射为沿正方形边的弧长坐标
    private long toArc(int x, int y, int side) {
        if (y == 0) return x;                         // 下边
        if (x == side) return side + y;               // 右边
        if (y == side) return 2L * side + (side - x); // 上边
        return 3L * side + (side - y);                // 左边
    }

    // 贪心验证：是否能选 k 个点使相邻弧长距离 >= d
    private boolean canPlace(long[] arcs, int n, int k, long d, long P) {
        for (int start = 0; start < n; start++) {
            int count = 1;
            long cur = arcs[start];

            for (int step = 0; step < k - 1; step++) {
                long target = cur + d;
                // 二分找 >= target 的下一个点（允许绕圈）
                long targetMod = target % P;
                int j = lowerBound(arcs, targetMod);
                if (j < n) {
                    cur = arcs[j] + (target >= P ? P : 0);
                } else {
                    // 绕回来
                    cur = arcs[0] + P;
                }
                count++;
            }

            if (count == k) {
                // 检查最后一个点到起始点的距离
                long gap = arcs[start] + P - cur;
                if (gap >= d) return true;
            }
        }
        return false;
    }

    // 二分查找第一个 >= target 的位置
    private int lowerBound(long[] arr, long target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n * log(P/k))
- 空间复杂度：O(n)

## 关键点总结

1. 将二维点映射为沿正方形边的一维弧长
2. 二分最小距离，贪心验证
3. 注意循环性：最后一个点到第一个点的距离也要 >= d
