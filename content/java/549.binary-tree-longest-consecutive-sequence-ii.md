## 题目描述

返回二叉树中最长连续序列路径的长度（可递增或递减，从任意节点开始）。

**示例：**
```
输入：root = [2,1,3]
输出：3
解释：路径 [1, 2, 3] 或 [3, 2, 1]
```

## 解题思路

后序遍历，每个节点返回 (递增长度, 递减长度)，最长路径 = inc + dec - 1。

## Java 代码实现

```java
class Solution {
    private int maxLen = 0;

    public int longestConsecutive(TreeNode root) {
        dfs(root);
        return maxLen;
    }

    // 返回 [递增长度, 递减长度]
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};

        int inc = 1, dec = 1;

        if (node.left != null) {
            int[] left = dfs(node.left);
            if (node.left.val == node.val + 1) {
                inc = Math.max(inc, left[0] + 1);
            } else if (node.left.val == node.val - 1) {
                dec = Math.max(dec, left[1] + 1);
            }
        }

        if (node.right != null) {
            int[] right = dfs(node.right);
            if (node.right.val == node.val + 1) {
                inc = Math.max(inc, right[0] + 1);
            } else if (node.right.val == node.val - 1) {
                dec = Math.max(dec, right[1] + 1);
            }
        }

        maxLen = Math.max(maxLen, inc + dec - 1);
        return new int[]{inc, dec};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **后序遍历**：先计算子树信息
2. **双状态返回**：递增长度 + 递减长度
3. **路径长度**：inc + dec - 1（当前节点只计一次）
