## 题目描述

给定整数数组 `nums`，通过对若干子数组执行按位 AND 操作，求数组所有元素按位 OR 的最大可能值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxValue(int[] nums) {
        // 对每个右端点维护所有以该点结尾的子数组 AND 值集合
        // 由于 AND 只会减少置位，集合大小 O(log max_val)
        int ans = 0;
        Set<Integer> curSet = new HashSet<>();

        for (int x : nums) {
            Set<Integer> newSet = new HashSet<>();
            newSet.add(x); // 单元素子数组
            for (int prev : curSet) {
                newSet.add(prev & x); // 与之前子数组 AND 扩展
            }
            curSet = newSet;
            // 将当前所有 AND 值累入全局 OR
            for (int v : curSet) ans |= v;
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log max_val)，每个位置 AND 集合大小为 O(log max_val)
- 空间复杂度：O(log max_val)

## 关键点总结

1. 子数组 AND 值集合随右端点移动时大小不超过 O(log max_val)
2. 所有可能的子数组 AND 值的总 OR 即为答案
3. 每步用新集合替换旧集合，包含单元素本身
