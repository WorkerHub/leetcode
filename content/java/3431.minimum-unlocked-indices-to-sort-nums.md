## 题目描述

给定只含 1、2、3 的整数数组 `nums` 和布尔数组 `locked`，返回最少需要解锁的位置数，使得数组可被排成不递减序列。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minUnlockedIndices(int[] nums, boolean[] locked) {
        int n = nums.length;
        // 目标排序数组
        int[] target = nums.clone();
        Arrays.sort(target);

        // 计算锁定但值不匹配目标的位置数
        int unlock = 0;
        for (int i = 0; i < n; i++) {
            if (locked[i] && nums[i] != target[i]) unlock++;
        }
        return unlock;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 由于 nums 只含 1、2、3，目标排序数组唯一确定
2. 锁定且与目标不匹配的位置必须解锁
3. 未锁定位置可自由重排，不计入解锁数
