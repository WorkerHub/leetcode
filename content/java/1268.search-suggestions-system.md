## 题目描述

给定产品数组和搜索词，每输入一个字符后推荐最多 3 个字典序最小的匹配产品（前缀匹配）。

**示例：**
```
输入：products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"
输出：[["mobile","moneypot","monitor"],["mobile","moneypot","monitor"],["mouse","mousepad"],["mouse","mousepad"],["mouse","mousepad"]]
```

## 解题思路

排序 + 二分查找：先排序，对每个前缀用二分找到第一个匹配位置，取最多 3 个。

## Java 代码实现

```java
class Solution {
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        Arrays.sort(products);
        List<List<String>> result = new ArrayList<>();
        String prefix = "";
        int start = 0;
        
        for (char c : searchWord.toCharArray()) {
            prefix += c;
            // 二分查找第一个 >= prefix 的位置
            start = lowerBound(products, prefix, start);
            
            List<String> suggestions = new ArrayList<>();
            for (int i = start; i < Math.min(start + 3, products.length); i++) {
                if (products[i].startsWith(prefix)) {
                    suggestions.add(products[i]);
                } else {
                    break;
                }
            }
            result.add(suggestions);
        }
        return result;
    }
    
    private int lowerBound(String[] arr, String target, int lo) {
        int hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid].compareTo(target) < 0) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m × log n)，n 为产品数，m 为搜索词长度
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **排序**：保证字典序，二分后连续的就是最小的
2. **二分查找**：找第一个 >= prefix 的位置
3. **前缀检查**：从二分位置取最多 3 个匹配项
4. **搜索范围缩小**：start 只增不减
