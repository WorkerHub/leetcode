## 题目描述

给你一个正整数数组 `values`，其中 `values[i]` 表示第 `i` 个观光景点的评分，并且两个景点 `i` 和 `j` 之间的距离为 `j - i`。

一对景点 `(i < j)` 组成的观光组合的得分为 `values[i] + values[j] + i - j`，也就是景点的评分之和减去它们两者之间的距离。

返回一对观光景点能取得的最高分。

**示例 1：**
```
输入：values = [8,1,5,2,6]
输出：11
解释：i = 0, j = 2, values[0] + values[2] + 0 - 2 = 8 + 5 + 0 - 2 = 11
```

**示例 2：**
```
输入：values = [1,2]
输出：2
```

**提示：**
- `2 <= values.length <= 5 * 10^4`
- `1 <= values[i] <= 1000`

## 解题思路

**核心观察**：将得分公式重组
- 原公式：`values[i] + values[j] + i - j`
- 重组：`(values[i] + i) + (values[j] - j)`

**关键发现**：
- 对于每个j，我们需要找到之前的最大的 `values[i] + i`
- 这样就可以O(1)时间计算当前的最大得分

**算法步骤**：
1. 维护变量maxI表示之前遇到的最大 `values[i] + i`
2. 对每个j，计算 `maxI + values[j] - j`
3. 更新全局最大值和maxI

## Java 代码实现

### 方法一：一次遍历（推荐）

```java
class Solution {
    public int maxScoreSightseeingPair(int[] values) {
        int maxScore = 0;
        int maxI = values[0] + 0; // values[i] + i 的最大值

        for (int j = 1; j < values.length; j++) {
            // 计算以j为右端点的最大得分
            maxScore = Math.max(maxScore, maxI + values[j] - j);

            // 更新maxI（values[i] + i 的最大值）
            maxI = Math.max(maxI, values[j] + j);
        }

        return maxScore;
    }
}
```

### 方法二：详细注释版

```java
class Solution {
    public int maxScoreSightseeingPair(int[] values) {
        /*
         * 公式分解：
         * 得分 = values[i] + values[j] + i - j
         *      = (values[i] + i) + (values[j] - j)
         *
         * 对于每个j，维护之前的max(values[i] + i)
         */
        int n = values.length;
        int result = 0;

        // 初始化：第一个景点作为左端点的贡献
        int leftMax = values[0] + 0;

        // 从第二个景点开始遍历，作为右端点
        for (int j = 1; j < n; j++) {
            // 当前景点作为右端点的贡献
            int rightContribution = values[j] - j;

            // 计算以j为右端点的最大得分
            result = Math.max(result, leftMax + rightContribution);

            // 更新左端点的最大贡献
            leftMax = Math.max(leftMax, values[j] + j);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，只需一次遍历
- **空间复杂度**：O(1)，只使用常数额外空间


## 关键点总结

1. **公式变换**：将得分公式拆分为两部分独立计算
2. **贪心思想**：维护左端点的最大贡献值
3. **一次遍历**：通过公式变换实现O(n)时间
4. **状态维护**：只需维护max(values[i] + i)
5. **边界处理**：从索引1开始遍历

## 易错点

1. **公式理解**：要正确理解得分公式的含义
2. **变量更新顺序**：先计算得分，再更新maxI
3. **初始值设置**：maxI初始为values[0]，不是0
4. **遍历起点**：从索引1开始，因为需要配对
5. **符号正负**：注意j的系数是负数
