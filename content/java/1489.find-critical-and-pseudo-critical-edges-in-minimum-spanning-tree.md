## 题目描述

给你一个 `n` 个节点的带权无向图，节点编号从 `0` 到 `n-1`。

图用 `edges` 表示，其中 `edges[i] = [u, v, weight]` 代表一条从节点 `u` 到节点 `v` 权值为 `weight` 的无向边。

请你找出所有的**关键边**和**伪关键边**，并分别将其以列表形式返回。

- **关键边**：若从图中删去该边，最小生成树（MST）的权值和会增大，或者无法形成 MST，则该边为关键边。
- **伪关键边**：若该边可以出现在某棵 MST 中，但并非所有 MST 中都有它（即它不是关键边），则该边为伪关键边。

**示例 1：**

```
输入：n = 5, edges = [[0,1,1],[1,2,1],[2,3,2],[0,3,2],[0,4,3],[3,4,3],[1,4,6]]
输出：[[0,1],[2,3,4,5]]
```

**示例 2：**

```
输入：n = 4, edges = [[0,1,1],[1,2,1],[0,2,1]]
输出：[[],[0,1,2]]
```

**提示：**

- `2 <= n <= 100`
- `1 <= edges.length <= min(200, n*(n-1)/2)`
- `edges[i].length == 3`
- `0 <= fromi, toi < n`
- `1 <= weighti <= 1000`
- 所有边不重复，且两端点不同。

## 解题思路

**核心思想：枚举每条边，用 Kruskal 算法验证。**

首先求出原始 MST 的权值 `base_weight`，然后对每条边 `e`：

1. **判断是否为关键边**：删去边 `e`，重新跑 Kruskal。若新 MST 权值大于 `base_weight` 或图变得不连通，则 `e` 是关键边。

2. **判断是否为伪关键边**：强制将边 `e` 加入（合并其两端点），再对剩余边跑 Kruskal。若得到的权值等于 `base_weight`，则 `e` 是伪关键边。

**并查集（Union-Find）** 是 Kruskal 的核心数据结构，支持高效的合并和查询操作。

**算法流程：**

```
1. 对所有边按权值排序（保留原始索引）
2. 用 Kruskal 求原始 MST 权值 base_weight
3. 对每条边 i：
   a. 删去边 i，跑 Kruskal，若结果 != base_weight → 关键边
   b. 若不是关键边，强制加入边 i，跑 Kruskal，若结果 == base_weight → 伪关键边
```

**Kruskal 算法回顾：**

- 将所有边按权值从小到大排序
- 依次考虑每条边，若它连接的两个节点不在同一连通分量中，则将其加入 MST
- 使用并查集判断连通性并合并

## Java 代码实现

### 方法一：枚举 + Kruskal + 并查集（推荐）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    // 并查集的 parent 和 rank 数组
    private int[] parent;
    private int[] rank;

    public List<List<Integer>> findCriticalAndPseudoCriticalEdges(int n, int[][] edges) {
        int m = edges.length;

        // 保留原始索引，以便最终返回正确的边编号
        // indexedEdges[i] = [weight, u, v, originalIndex]
        int[][] indexedEdges = new int[m][4];
        for (int i = 0; i < m; i++) {
            indexedEdges[i][0] = edges[i][2];  // 权值
            indexedEdges[i][1] = edges[i][0];  // u
            indexedEdges[i][2] = edges[i][1];  // v
            indexedEdges[i][3] = i;             // 原始索引
        }
        Arrays.sort(indexedEdges, (a, b) -> a[0] - b[0]);  // 按权值排序

        // 求原始 MST 权值
        int baseWeight = kruskal(n, indexedEdges, -1, -1, -1, 0);

        List<Integer> critical = new ArrayList<>();
        List<Integer> pseudoCritical = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            int w = indexedEdges[i][0];
            int u = indexedEdges[i][1];
            int v = indexedEdges[i][2];
            int origIdx = indexedEdges[i][3];

            // 1. 判断关键边：删去该边后 MST 权值变大或不连通
            int skipWeight = kruskal(n, indexedEdges, i, -1, -1, 0);
            if (skipWeight > baseWeight) {
                critical.add(origIdx);
                continue;
            }

            // 2. 判断伪关键边：强制加入后 MST 权值不变
            int forceWeight = kruskal(n, indexedEdges, -1, u, v, w);
            if (forceWeight == baseWeight) {
                pseudoCritical.add(origIdx);
            }
        }

        // 按原始索引排序
        critical.sort(null);
        pseudoCritical.sort(null);

        List<List<Integer>> result = new ArrayList<>();
        result.add(critical);
        result.add(pseudoCritical);
        return result;
    }

    /**
     * 运行 Kruskal 算法
     * skipIdx:   要跳过的边在 indexedEdges 中的下标（-1 表示不跳过）
     * forceU/V:  强制加入的边两端点（-1 表示不强制）
     * forceW:    强制加入边的权值
     * 返回 MST 权值（若不连通则返回 Integer.MAX_VALUE）
     */
    private int kruskal(int n, int[][] indexedEdges, int skipIdx,
                        int forceU, int forceV, int forceW) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        int totalWeight = 0;
        int edgeCount = 0;

        // 若有强制边，先加入
        if (forceU != -1) {
            union(forceU, forceV);
            totalWeight += forceW;
            edgeCount++;
        }

        // 按排序后的顺序加边
        for (int i = 0; i < indexedEdges.length; i++) {
            if (i == skipIdx) continue;
            int w = indexedEdges[i][0];
            int u = indexedEdges[i][1];
            int v = indexedEdges[i][2];
            if (union(u, v)) {
                totalWeight += w;
                edgeCount++;
            }
        }

        // 不连通时返回 MAX_VALUE
        return edgeCount == n - 1 ? totalWeight : Integer.MAX_VALUE;
    }

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }

    private boolean union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;
        if (rank[rx] < rank[ry]) {
            int tmp = rx; rx = ry; ry = tmp;
        }
        parent[ry] = rx;
        if (rank[rx] == rank[ry]) rank[rx]++;
        return true;
    }
}
```

### 方法二：并查集封装成内部类（更清晰的结构）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> findCriticalAndPseudoCriticalEdges(int n, int[][] edges) {
        int m = edges.length;
        int[][] newEdges = new int[m][4];
        for (int i = 0; i < m; i++) {
            newEdges[i] = new int[]{edges[i][0], edges[i][1], edges[i][2], i};
        }
        Arrays.sort(newEdges, (a, b) -> a[2] - b[2]);  // 按权值排序

        int base = getMstWeight(n, newEdges, -1, -1, -1, 0);

        List<Integer> critical = new ArrayList<>();
        List<Integer> pseudo = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            int u = newEdges[i][0], v = newEdges[i][1];
            int w = newEdges[i][2], origIdx = newEdges[i][3];

            // 关键边：删去后 MST 权值增大或不连通
            if (getMstWeight(n, newEdges, i, -1, -1, 0) > base) {
                critical.add(origIdx);
            }
            // 伪关键边：强制加入后权值等于 base
            else if (getMstWeight(n, newEdges, -1, u, v, w) == base) {
                pseudo.add(origIdx);
            }
        }

        critical.sort(null);
        pseudo.sort(null);

        return List.of(critical, pseudo);
    }

    private int getMstWeight(int n, int[][] edges, int skip,
                             int preU, int preV, int preW) {
        UnionFind uf = new UnionFind(n);
        int weight = 0;
        int cnt = 0;

        // 强制加入边
        if (preU != -1) {
            uf.union(preU, preV);
            weight += preW;
            cnt++;
        }

        for (int j = 0; j < edges.length; j++) {
            if (j == skip) continue;
            int u = edges[j][0], v = edges[j][1], w = edges[j][2];
            if (uf.union(u, v)) {
                weight += w;
                cnt++;
            }
        }

        return cnt == n - 1 ? weight : Integer.MAX_VALUE;
    }

    static class UnionFind {
        int[] parent, rank;

        UnionFind(int n) {
            parent = new int[n];
            rank = new int[n];
            for (int i = 0; i < n; i++) parent[i] = i;
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        boolean union(int x, int y) {
            int px = find(x), py = find(y);
            if (px == py) return false;
            if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
            parent[py] = px;
            if (rank[px] == rank[py]) rank[px]++;
            return true;
        }
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一/二 | O(m^2 * alpha(n)) | O(n) |

- `m` 为边数，`n` 为节点数，`alpha` 为反阿克曼函数（近似常数）
- 对每条边都跑两次 Kruskal，每次 Kruskal 是 O(m * alpha(n))
- 总体 O(m^2 * alpha(n))，由于 m <= 200，实际运行很快

## 关键点总结

1. **保留原始索引**：排序后边的顺序变化，必须记录原始位置以返回正确编号。
2. **关键边判断**：删去该边后 MST 权值严格增大，或图变得不连通（权值返回 MAX_VALUE）。
3. **伪关键边判断**：强制加入该边（先合并两端），再跑剩余 Kruskal，权值等于原始 MST 即可。
4. **并查集路径压缩 + 按秩合并**：保证接近 O(1) 的单次操作。
5. **不连通的处理**：删边后若图不连通，连通边数 < n-1，需要特判。

## 易错点

- **原始索引丢失**：排序时必须携带原始索引，否则无法返回正确答案。
- **强制加入边的顺序**：必须先加强制边，再跑剩余 Kruskal，否则结果不正确。
- **不连通的判断**：仅检查权值不够，需同时检查是否成功构建 n-1 条边的树。
- **边的去重**：题目保证无重边，但排序后相同权值的边处理需小心。
