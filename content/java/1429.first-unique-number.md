## 题目描述

设计一个 `FirstUnique` 类：

- `FirstUnique(int[] nums)`：初始化对象，将 `nums` 中的数字依次加入队列。
- `int showFirstUnique()`：返回队列最左边的唯一整数（即只出现过一次的最早入队元素）。若不存在则返回 `-1`。
- `void add(int value)`：在队列尾部添加一个整数。

**示例：**

```
输入：
["FirstUnique","showFirstUnique","add","add","add","add","add","showFirstUnique"]
[[[2,3,5]],[],[5],[2],[3],[3],[2],[]]
输出：
[null,2,null,null,null,null,null,3]

解释：
FirstUnique firstUnique = new FirstUnique([2,3,5]);
firstUnique.showFirstUnique(); // 返回 2
firstUnique.add(5);            // 队列变为 [2,3,5,5]
firstUnique.add(2);            // 队列变为 [2,3,5,5,2]
firstUnique.add(3);            // 队列变为 [2,3,5,5,2,3]
firstUnique.add(3);            // 队列变为 [2,3,5,5,2,3,3]
firstUnique.add(2);            // 队列变为 [2,3,5,5,2,3,3,2]
firstUnique.showFirstUnique(); // 返回 3（2、5 已出现多次）
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^8`
- `1 <= value <= 10^8`
- 最多调用 `showFirstUnique` 和 `add` 各 `10^5` 次

## 解题思路

核心问题：高效找到队列中第一个只出现过一次的元素。

**思路：双端队列 + 哈希集合**

- 维护一个有序队列（`ArrayDeque`）记录元素入队顺序。
- 维护一个哈希集合 `seen` 记录所有已入队元素，以及一个哈希集合 `duplicate` 记录出现超过一次的元素。
- `showFirstUnique()`：从队列头部弹出所有已在 `duplicate` 中的元素，返回队头（若存在）。
- `add(value)`：若 `value` 已经在 `seen` 中则加入 `duplicate`；否则加入 `seen` 并入队。

这样每次 `showFirstUnique` 时，队头一定是唯一元素（已重复的已被弹出）。

**关键点：**  
队列中的元素不删除，但在 `showFirstUnique` 时懒删除队头的重复元素，保证均摊 O(1)。

## Java 代码实现

### 方法一：双端队列 + 双哈希集合（推荐）

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class FirstUnique {
    private Deque<Integer> queue;    // 记录元素顺序（懒删除）
    private Set<Integer> seen;       // 见过的元素集合
    private Set<Integer> duplicate;  // 重复出现的元素集合

    public FirstUnique(int[] nums) {
        queue = new ArrayDeque<>();
        seen = new HashSet<>();
        duplicate = new HashSet<>();
        for (int num : nums) {
            add(num);
        }
    }

    public int showFirstUnique() {
        // 从队头弹出所有重复元素（懒删除）
        while (!queue.isEmpty() && duplicate.contains(queue.peekFirst())) {
            queue.pollFirst();
        }
        // 返回队头（唯一元素），不存在返回 -1
        return queue.isEmpty() ? -1 : queue.peekFirst();
    }

    public void add(int value) {
        if (seen.contains(value)) {
            // 已见过，标记为重复
            duplicate.add(value);
        } else {
            // 第一次见，加入队列和 seen
            seen.add(value);
            queue.offerLast(value);
        }
    }
}
```

### 方法二：LinkedHashMap（维护插入顺序）

```java
import java.util.LinkedHashMap;
import java.util.Map;

class FirstUnique {
    // LinkedHashMap 维护插入顺序，value 为出现次数
    private LinkedHashMap<Integer, Integer> count;

    public FirstUnique(int[] nums) {
        count = new LinkedHashMap<>();
        for (int num : nums) {
            add(num);
        }
    }

    public int showFirstUnique() {
        // 找到第一个出现次数为 1 的元素
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == 1) {
                return entry.getKey();
            }
        }
        return -1;
    }

    public void add(int value) {
        count.merge(value, 1, Integer::sum);
    }
}
```

**注意：** 方法二的 `showFirstUnique` 最坏情况 O(n)，不如方法一高效。

### 方法三：有序映射 + 已见集合（最优）

```java
import java.util.LinkedHashSet;
import java.util.HashSet;
import java.util.Set;

class FirstUnique {
    private LinkedHashSet<Integer> unique;  // 维护唯一元素的插入顺序
    private Set<Integer> allSeen;

    public FirstUnique(int[] nums) {
        unique = new LinkedHashSet<>();
        allSeen = new HashSet<>();
        for (int num : nums) {
            add(num);
        }
    }

    public int showFirstUnique() {
        // LinkedHashSet 保持插入顺序，取第一个元素
        return unique.isEmpty() ? -1 : unique.iterator().next();
    }

    public void add(int value) {
        if (allSeen.contains(value)) {
            // 已见过，从唯一集合中删除（如果在的话）
            unique.remove(value);
        } else {
            allSeen.add(value);
            unique.add(value);
        }
    }
}
```

## 复杂度分析

| 方法 | 初始化 | showFirstUnique | add |
|------|--------|-----------------|-----|
| 方法一（双端队列） | O(n) | 均摊 O(1) | O(1) |
| 方法二（LinkedHashMap） | O(n) | O(n) | O(1) |
| 方法三（有序集合） | O(n) | O(1) | O(1) |

- 空间复杂度：O(n)，存储所有入队元素。

## 关键点总结

1. 懒删除：队列中的重复元素不立即删除，在查询时才清理队头，保证均摊效率。
2. Java 的 `LinkedHashSet` 保持插入顺序，可替代 Python 的有序字典用法。
3. 用两个集合（`seen` 和 `duplicate`）可以 O(1) 判断一个元素是否重复。
4. `ArrayDeque` 的 `pollFirst()` 是 O(1)，比 `ArrayList` 的 `remove(0)` 高效。

## 易错点

- 忘记在 `showFirstUnique` 中做懒删除，导致返回了已重复的元素。
- 初始化时忘记调用 `add` 方法处理 `nums`，导致逻辑不统一。
- Java 中 `LinkedHashMap.merge()` 可以简洁地累加计数。
