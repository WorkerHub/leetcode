## 题目描述

给你二进制数组 `nums`，每次操作可翻转三个连续元素，返回使所有元素变为 1 的最少操作次数（无法完成返回 -1）。

## 解题思路

贪心：从左到右扫描，遇到 0 立即翻转以当前位为起点的三个元素（这是消除该 0 的唯一选择）。用差分数组（队列记录翻转右端点）避免实际修改数组，维护当前位的翻转奇偶性。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        int ops = 0;
        Deque<Integer> flips = new ArrayDeque<>(); // 记录翻转操作的右端点

        for (int i = 0; i < n; i++) {
            // 移除已过期的翻转记录（右端点 < i）
            while (!flips.isEmpty() && flips.peekFirst() < i) {
                flips.pollFirst();
            }
            // 当前实际值（考虑翻转次数奇偶性）
            int cur = nums[i] ^ (flips.size() % 2);
            if (cur == 0) {
                if (i + 2 >= n) return -1; // 无法翻转（越界）
                ops++;
                flips.addLast(i + 2); // 翻转 [i, i+1, i+2]，记录右端点
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：遇到 0 立即翻转，这是消除该 0 的唯一合法操作
2. 用队列记录翻转右端点，通过奇偶性计算当前实际值，避免修改数组
3. 到达最后两个位置仍为 0 时，无解返回 -1
