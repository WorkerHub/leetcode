## 题目描述

你需要制定一份 `d` 天的工作计划表。工作之间存在依赖，要想执行第 `i` 项工作，你必须完成全部 `j` 项工作（`0 <= j < i`）。

你每天**至少**需要完成一项任务。工作计划的总难度是这 `d` 天每一天的难度之和，而一天的工作难度是当天应该完成工作的最大难度指数。

给你一个整数数组 `jobDifficulty` 和整数 `d`，分别代表工作难度和需要计划的天数。第 `i` 项工作的难度是 `jobDifficulty[i]`。

返回整个工作计划的**最小难度**。如果无法制定工作计划，则返回 **-1**。

**示例 1：**
```
输入：jobDifficulty = [6,5,4,3,2,1], d = 2
输出：7
解释：第一天工作 [6,5,4,3,2]，难度 = 6；第二天工作 [1]，难度 = 1。总难度 = 7。
```

**示例 2：**
```
输入：jobDifficulty = [9,9,9], d = 4
输出：-1
解释：工作数量少于天数，无法安排。
```

**示例 3：**
```
输入：jobDifficulty = [1,1,1], d = 3
输出：3
解释：每天一项工作，总难度 = 3。
```

**提示：**
- `1 <= jobDifficulty.length <= 300`
- `0 <= jobDifficulty[i] <= 1000`
- `1 <= d <= 10`

## 解题思路

**动态规划（区间 DP）**

**状态定义：** `dp[i][j]` 表示前 `i` 天完成前 `j` 项工作的最小总难度（1-indexed）。

**边界条件：**
- 若 `n < d`，工作数少于天数，无法安排，返回 -1
- `dp[0][0] = 0`（0 天完成 0 项工作，难度为 0）

**状态转移：**
第 `i` 天的工作范围是 `[k+1, j]`（第 `i-1` 天完成了前 `k` 项，第 `i` 天完成 `k+1` 到 `j`）：

```
dp[i][j] = min(dp[i-1][k] + max(jobDifficulty[k..j-1]))
           其中 i-1 <= k < j
```

**优化：** 计算 `max(jobDifficulty[k..j-1])` 时，可以从右向左枚举 `k`，维护当前最大值。

## Java 代码实现

### 方法一：标准 DP（推荐）

```java
import java.util.Arrays;

class Solution {
    public int minDifficulty(int[] jobDifficulty, int d) {
        int n = jobDifficulty.length;
        
        // 工作数少于天数，无法安排（每天至少一项）
        if (n < d) return -1;
        
        final int INF = Integer.MAX_VALUE / 2;
        // dp[i][j]：前 i 天完成前 j 项工作的最小总难度
        int[][] dp = new int[d + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;
        
        for (int i = 1; i <= d; i++) {
            // 第 i 天至少需要完成第 i 项工作
            for (int j = i; j <= n - d + i; j++) {
                // 枚举第 i-1 天结束时完成了前 k 项工作
                // 第 i 天完成第 k 到第 j-1 项（0-indexed）
                int maxDiff = 0; // 当天工作的最大难度
                for (int k = j - 1; k >= i - 1; k--) {
                    // 从右向左枚举，维护 jobDifficulty[k..j-1] 的最大值
                    maxDiff = Math.max(maxDiff, jobDifficulty[k]);
                    if (dp[i - 1][k] < INF) {
                        dp[i][j] = Math.min(dp[i][j], dp[i - 1][k] + maxDiff);
                    }
                }
            }
        }
        
        return dp[d][n] < INF ? dp[d][n] : -1;
    }
}
```

### 方法二：空间优化（滚动数组）

```java
import java.util.Arrays;

class Solution {
    public int minDifficulty(int[] jobDifficulty, int d) {
        int n = jobDifficulty.length;
        if (n < d) return -1;
        
        final int INF = Integer.MAX_VALUE / 2;
        // 只保留上一天的 dp 值
        int[] prev = new int[n + 1];
        Arrays.fill(prev, INF);
        prev[0] = 0;
        
        for (int i = 1; i <= d; i++) {
            int[] curr = new int[n + 1];
            Arrays.fill(curr, INF);
            for (int j = i; j <= n - d + i; j++) {
                int maxDiff = 0;
                for (int k = j - 1; k >= i - 1; k--) {
                    maxDiff = Math.max(maxDiff, jobDifficulty[k]);
                    if (prev[k] < INF) {
                        curr[j] = Math.min(curr[j], prev[k] + maxDiff);
                    }
                }
            }
            prev = curr;
        }
        
        return prev[n] < INF ? prev[n] : -1;
    }
}
```

### 方法三：记忆化递归（自顶向下）

```java
import java.util.Arrays;

class Solution {
    private int[] job;
    private int n, d;
    private int[][] memo;
    
    public int minDifficulty(int[] jobDifficulty, int d) {
        this.job = jobDifficulty;
        this.n = job.length;
        this.d = d;
        if (n < d) return -1;
        
        memo = new int[d + 1][n];
        for (int[] row : memo) Arrays.fill(row, -1);
        
        int ans = dfs(d, 0);
        return ans == Integer.MAX_VALUE / 2 ? -1 : ans;
    }
    
    // 从第 day 天开始，从第 start 项工作开始安排
    private int dfs(int day, int start) {
        if (day == 1) {
            // 最后一天：完成所有剩余工作，返回最大难度
            int maxD = 0;
            for (int i = start; i < n; i++) maxD = Math.max(maxD, job[i]);
            return maxD;
        }
        if (memo[day][start] != -1) return memo[day][start];
        
        int result = Integer.MAX_VALUE / 2;
        int maxDiff = 0;
        // 当天完成 start 到 k（留 day-1 项给剩余天）
        for (int k = start; k <= n - day; k++) {
            maxDiff = Math.max(maxDiff, job[k]);
            int next = dfs(day - 1, k + 1);
            result = Math.min(result, maxDiff + next);
        }
        
        memo[day][start] = result;
        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（标准 DP） | O(d * n^2) | O(d * n) |
| 方法二（滚动数组） | O(d * n^2) | O(n) |
| 方法三（记忆化） | O(d * n^2) | O(d * n) |

## 图解示例

以 `jobDifficulty = [6,5,4,3,2,1], d = 2` 为例：

```
n=6, d=2

dp 状态转移（第 2 天，完成所有 6 项工作）：
dp[2][6] = min of:
  dp[1][1] + max(jobs[1..5]) = (6) + max(5,4,3,2,1) = 6 + 5 = 11
  dp[1][2] + max(jobs[2..5]) = (6) + max(4,3,2,1)   = 6 + 4 = 10
  dp[1][3] + max(jobs[3..5]) = (6) + max(3,2,1)      = 6 + 3 = 9
  dp[1][4] + max(jobs[4..5]) = (6) + max(2,1)        = 6 + 2 = 8
  dp[1][5] + max(jobs[5])    = (6) + 1               = 7    <-- 最小

答案：7
```

## 关键点总结

1. 状态 `dp[i][j]`：前 `i` 天完成前 `j` 项工作的最小难度
2. 每天至少完成一项工作，第 `i` 天完成的工作范围 `[k+1, j]` 需满足 `k >= i-1`
3. 从右向左枚举起点 `k` 时可以在 O(1) 维护当前最大难度
4. 工作不够分配（`n < d`）直接返回 -1

## 易错点

1. 越界：j 的范围 `[i, n - d + i]`，保证剩余工作够分配给剩余天数
2. 最大难度维护方向：从右到左枚举 k（从 j-1 递减），这样每次只需 `Math.max(current, new_val)`
3. 记忆化递归时，最后一天的 base case 要特殊处理
