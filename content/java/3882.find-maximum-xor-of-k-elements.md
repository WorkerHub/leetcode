## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，从 `nums` 中选出恰好 `k` 个元素（可重复选），使它们的异或值最大，返回该最大异或值。

## Java 代码实现

```java
class Solution {
    // 字典树节点
    private int[][] trie = new int[300001][2];
    private int trieSize = 1;

    private void insert(int num) {
        int node = 0;
        // 从高位到低位插入 30 位
        for (int i = 29; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (trie[node][bit] == 0) {
                trie[node][bit] = trieSize++;
            }
            node = trie[node][bit];
        }
    }

    private int maxXorWith(int num) {
        int node = 0;
        int result = 0;
        // 贪心：每位尽量选与当前位相反的方向
        for (int i = 29; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit;
            if (trie[node][want] != 0) {
                result |= (1 << i);
                node = trie[node][want];
            } else {
                node = trie[node][bit];
            }
        }
        return result;
    }

    public int maxXor(int[] nums, int k) {
        if (k % 2 == 1) {
            // 奇数个：偶数对两两抵消，等效于选 1 个，最大为 max(nums)
            int maxVal = 0;
            for (int x : nums) maxVal = Math.max(maxVal, x);
            return maxVal;
        }
        // 偶数个：等效于选 2 个元素，求最大异或值
        for (int x : nums) insert(x);
        int best = 0;
        for (int x : nums) best = Math.max(best, maxXorWith(x));
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 30)，Trie 插入与查询
- 空间复杂度：O(n * 30)，Trie 存储

## 关键点总结

1. 奇偶性决定策略：奇数 k 等效于选 1 个，偶数 k 等效于选 2 个（其余两两抵消）。
2. 最大单元素 = max(nums)；最大两元素异或用 Trie 在 O(n) 内求解。
3. 可以重复选是关键，使偶数对自消。
