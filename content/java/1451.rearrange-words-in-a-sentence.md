## 题目描述

给你一个句子 `text`（字符串），句子的格式满足以下条件：

1. 第一个单词的首字母大写，其余单词全部小写
2. 每个单词由单个空格分隔

请你重新排列 `text` 中的单词，使所有单词按其长度的升序排列；如果两个单词的长度相同，则保持其在原句子中的相对顺序（即稳定排序）。

返回新的句子，其中第一个单词的首字母大写，其余单词全部小写。

**示例 1：**
```
输入：text = "Leetcode is cool"
输出："Is cool leetcode"
解释：句子中共有 3 个单词，长度分别为 8、2、4。
     按长度升序排列："is"(2) -> "cool"(4) -> "leetcode"(8)
     第一个单词首字母大写："Is cool leetcode"
```

**示例 2：**
```
输入：text = "Keep calm and code on"
输出："On and keep calm code"
```

**示例 3：**
```
输入：text = "To be or not to be"
输出："To be or to be not"
```

**提示：**
- `text` 只包含大写和小写英文字母以及空格
- `text` 中至少有一个单词
- `text` 的单词之间只有单个空格
- 第一个单词的首字母大写，其余均为小写

## 解题思路

步骤拆解：

1. **全部转小写**：题目保证第一个单词首字母大写，先把整句转小写，便于统一处理
2. **分割单词**：按空格分割得到单词列表
3. **稳定排序**：按单词长度排序，Java 的 `Arrays.sort` 使用 TimSort，是稳定排序
4. **还原首字母大写**：将排序后列表的第一个单词首字母大写
5. **拼接结果**：`String.join(" ", words)` 拼成句子

## Java 代码实现

### 方法一：稳定排序（推荐）

```java
import java.util.Arrays;

class Solution {
    public String arrangeWords(String text) {
        // 第一步：全部转小写，消除首字母大写的影响
        text = text.toLowerCase();

        // 第二步：分割句子得到单词列表
        String[] words = text.split(" ");

        // 第三步：按单词长度稳定排序（Arrays.sort 是稳定排序）
        Arrays.sort(words, (a, b) -> a.length() - b.length());

        // 第四步：第一个单词首字母大写
        words[0] = Character.toUpperCase(words[0].charAt(0)) + words[0].substring(1);

        // 第五步：拼接结果
        return String.join(" ", words);
    }
}
```

### 方法二：显式保留原始下标（更清晰的稳定性保证）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String arrangeWords(String text) {
        // 分割并转小写
        String[] words = text.toLowerCase().split(" ");
        int n = words.length;

        // 创建带原始下标的数组，用于稳定排序
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;

        // 按长度排序，相同长度按原下标顺序（稳定）
        java.util.Arrays.sort(indices, (a, b) ->
                words[a].length() != words[b].length()
                        ? words[a].length() - words[b].length()
                        : a - b
        );

        // 按排序后的顺序拼接
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) sb.append(" ");
            String word = words[indices[i]];
            if (i == 0) {
                sb.append(Character.toUpperCase(word.charAt(0)));
                sb.append(word.substring(1));
            } else {
                sb.append(word);
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，n 为单词数量，排序的时间复杂度
- 空间复杂度：O(n)，存储单词列表

## 关键点总结

1. 先统一转小写，再排序，最后处理首字母大写
2. Java 的 `Arrays.sort` 对对象数组是稳定排序（TimSort），相同键值保持原顺序
3. `Character.toUpperCase(c)` 将字符转大写，`word.substring(1)` 获取剩余部分
4. `String.join(" ", array)` 是 Java 中拼接字符串数组的简洁方式

## 易错点

- 不要忘记先将第一个单词转为小写，否则排序时大写字母的 ASCII 值更小会影响结果
- Java 中字符串首字母大写：`Character.toUpperCase(word.charAt(0)) + word.substring(1)`
- `Arrays.sort(Object[])` 是稳定排序，`Arrays.sort(int[])` 是不稳定排序（使用双轴快排）
