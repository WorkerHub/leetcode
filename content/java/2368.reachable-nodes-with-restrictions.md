## 题目描述

给你一棵 n 个节点的无向树（根节点为 0）和受限节点列表 `restricted`，不能访问或经过受限节点，返回从根节点 0 出发可访问的最多节点数。

## 解题思路

将受限节点存入 HashSet，从根节点 0 开始 BFS，跳过受限节点，统计访问到的节点数。

## Java 代码实现

```java
class Solution {
    public int reachableNodes(int n, int[][] edges, int[] restricted) {
        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        Set<Integer> ban = new HashSet<>();
        for (int r : restricted) ban.add(r);

        // BFS 从 0 出发
        boolean[] visited = new boolean[n];
        visited[0] = true;
        Queue<Integer> queue = new ArrayDeque<>();
        queue.add(0);
        int count = 0;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            count++;
            for (int nb : graph.get(node)) {
                if (!visited[nb] && !ban.contains(nb)) {
                    visited[nb] = true;
                    queue.add(nb);
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 受限节点不能访问也不能经过，相当于将这些节点从图中删除后做 BFS。
2. 将受限节点放入 HashSet，O(1) 判断。
3. 根节点 0 保证不在 restricted 中，无需特殊处理。
