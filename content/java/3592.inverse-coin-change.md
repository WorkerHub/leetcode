## 题目描述

给定整数数组 `counts`，其中 `counts[i]` 为完全背包恰好凑成金额 `i+1` 的方案数，逆推使这些方案数成立的最小硬币面值集合，若无解返回空数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] findCoins(int[] counts) {
        int n = counts.length;
        long[] dp = new long[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) dp[i] = counts[i - 1];

        List<Integer> coins = new ArrayList<>();

        for (int i = 1; i <= n; i++) {
            // 已知 coins 对 dp[i] 的贡献
            long contrib = 0;
            for (int c : coins) {
                if (c <= i) contrib += dp[i - c];
            }
            long diff = dp[i] - contrib;
            if (diff == 0) {
                // i 不是硬币
            } else if (diff == 1) {
                coins.add(i);  // i 是硬币
            } else {
                return new int[0];  // 无解
            }
        }

        return coins.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，对每个位置枚举已知硬币
- 空间复杂度：O(n)

## 关键点总结

1. 利用完全背包 `dp[i] = sum(dp[i-c])` 逆推，按从小到大顺序确定各面值
2. 余量 = 0：i 不是硬币；= 1：i 是硬币；其他值：无解返回空数组
3. `dp[0] = 1` 是完全背包初始值
