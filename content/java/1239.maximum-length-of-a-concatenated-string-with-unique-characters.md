## 题目描述

给定字符串数组 arr，从中选取子序列拼接成字符串 s，要求 s 中每个字符只出现一次。返回 s 的最大长度。

**示例：**
```
输入：arr = ["un","iq","ue"]
输出：4（"uniq" 或 "ique"）
```

## 解题思路

回溯 + 位掩码：用 int 的 26 位表示已使用的字符集合。每个字符串选或不选，选时检查与已有集合是否有交集（AND 为 0）。

## Java 代码实现

```java
class Solution {
    private int maxLen = 0;
    
    public int maxLength(List<String> arr) {
        // 预处理：过滤有重复字符的字符串，并转为位掩码
        List<int[]> masks = new ArrayList<>(); // [mask, length]
        for (String s : arr) {
            int mask = 0;
            boolean valid = true;
            for (char c : s.toCharArray()) {
                int bit = 1 << (c - 'a');
                if ((mask & bit) != 0) { valid = false; break; }
                mask |= bit;
            }
            if (valid) masks.add(new int[]{mask, s.length()});
        }
        
        backtrack(masks, 0, 0, 0);
        return maxLen;
    }
    
    private void backtrack(List<int[]> masks, int idx, int curMask, int curLen) {
        maxLen = Math.max(maxLen, curLen);
        
        for (int i = idx; i < masks.size(); i++) {
            int[] item = masks.get(i);
            // 无交集才能选
            if ((curMask & item[0]) == 0) {
                backtrack(masks, i + 1, curMask | item[0], curLen + item[1]);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n)，n 为有效字符串数量（最多 16）
- **空间复杂度**：O(n)，递归深度

## 关键点总结

1. **位掩码**：26 位 int 表示字符集合，O(1) 判断交集
2. **预处理过滤**：自身有重复字符的直接排除
3. **回溯**：每个字符串选或不选，选的条件是无交集
4. **AND 判断**：(maskA & maskB) == 0 表示无重复字符
