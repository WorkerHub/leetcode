## 题目描述

给你整数数组 nums 和整数 k，定义 K-or 为：第 i 位上至少有 k 个元素为 1 则结果该位为 1，返回数组的 K-or 值。

## 解题思路

对每一个二进制位（0 到 30），统计 nums 中在该位上为 1 的元素个数，若 >= k 则答案对应位置 1。

## Java 代码实现

```java
class Solution {
    public int findKOr(int[] nums, int k) {
        int ans = 0;
        for (int bit = 0; bit < 31; bit++) {
            int count = 0;
            for (int x : nums) {
                if (((x >> bit) & 1) == 1) count++;
            }
            if (count >= k) ans |= (1 << bit);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(31 × n) = O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 按位独立处理，每一位的结果只取决于该位上有多少个 1
2. 条件为"至少 k 个"，非"恰好 k 个"
3. nums[i] ≤ 10^9 < 2^30，检查 31 位足够
