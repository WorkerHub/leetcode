## 题目描述

公路上有 n 个检查点，`position[i]` 为位置，`time[i]` 为通过速度。可合并相邻检查点最多 k 次（合并后速度取和）。通过某段公路的时间 = 段长 × 段入口处速度。求最少总时间。

## 解题思路

DP：`dp[i][j]` = 考虑前 `i+1` 个检查点（0-indexed）并进行了 `j` 次合并的最小时间。枚举 i 的"前驱保留检查点" `prev`，合并 `(i - prev - 1)` 次，花费 `dist(prev, i) * time[prev]`。

## Java 代码实现

```java
class Solution {
    public int minTravelTime(int l, int n, int k, int[] position, int[] time) {
        final int INF = Integer.MAX_VALUE / 2;
        // dp[i][j] = 前 i 个检查点，j 次合并的最小时间
        int[][] dp = new int[n][k + 1];
        for (int[] row : dp) java.util.Arrays.fill(row, INF);
        for (int j = 0; j <= k; j++) dp[0][j] = 0;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j <= k; j++) {
                // prev 是上一个保留的检查点（不被合并）
                for (int prev = Math.max(0, i - j - 1); prev < i; prev++) {
                    int merges = i - prev - 1; // 将 prev+1..i-1 合并进来
                    if (j - merges < 0) continue;
                    if (dp[prev][j - merges] == INF) continue;
                    int dist = position[i] - position[prev];
                    int cost = dp[prev][j - merges] + dist * time[prev];
                    if (cost < dp[i][j]) dp[i][j] = cost;
                }
            }
        }

        int ans = INF;
        for (int j = 0; j <= k; j++) ans = Math.min(ans, dp[n - 1][j]);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)
- 空间复杂度：O(n * k)

## 关键点总结

1. 通过一段的时间 = 段长 × 入口处速度（入口检查点的 time 值）
2. 合并 m 次等价于 m+1 个连续检查点变为 1 个
3. 枚举前驱检查点确定合并数量
