## 题目描述

实现快照数组 SnapshotArray：
- `SnapshotArray(length)` 初始化长度为 length 的数组（初值 0）
- `set(index, val)` 设置 index 处的值
- `snap()` 创建快照，返回快照编号
- `get(index, snap_id)` 返回指定快照中 index 的值

**示例：**
```
set(0,5) → snap() → set(0,6) → get(0,0) = 5
```

## 解题思路

每个索引维护修改历史 `List<int[]>` 存储 `{snap_id, val}`。set 时追加/更新当前版本记录。get 时二分查找 <= snap_id 的最大版本。

## Java 代码实现

```java
class SnapshotArray {
    private List<int[]>[] history;
    private int snapId;

    public SnapshotArray(int length) {
        history = new List[length];
        for (int i = 0; i < length; i++) {
            history[i] = new ArrayList<>();
            history[i].add(new int[]{0, 0}); // 初始版本 0，值 0
        }
        snapId = 0;
    }

    public void set(int index, int val) {
        List<int[]> h = history[index];
        // 同一快照版本更新最后一条
        if (h.get(h.size() - 1)[0] == snapId) {
            h.get(h.size() - 1)[1] = val;
        } else {
            h.add(new int[]{snapId, val});
        }
    }

    public int snap() {
        return snapId++;
    }

    public int get(int index, int snap_id) {
        List<int[]> h = history[index];
        // 二分查找 <= snap_id 的最大版本
        int lo = 0, hi = h.size() - 1, res = 0;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (h.get(mid)[0] <= snap_id) {
                res = h.get(mid)[1];
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return res;
    }
}
```

## 复杂度分析

- **set**：O(1)
- **snap**：O(1)
- **get**：O(log S)，S 为该索引的修改次数
- **空间**：O(总 set 次数)

## 关键点总结

1. **惰性快照**：snap 只递增 ID，不复制数组
2. **二分查找**：get 在有序历史中找 <= snap_id 的最新值
3. **同版本合并**：同一 snap_id 多次 set 只保留最后一次
4. **初始化**：每个索引加入 `{0, 0}` 作为初始记录
