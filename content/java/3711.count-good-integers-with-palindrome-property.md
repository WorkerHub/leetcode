## 题目描述

给定整数 `n` 和 `k`，统计所有满足以下条件的 n 位整数的个数：该整数是回文数且能被 k 整除。

## 解题思路

枚举前半部分生成所有 n 位回文数：前半长度为 `ceil(n/2)`，从 `10^(half-1)` 到 `10^half - 1`，按奇偶性镜像构造完整回文数，检查能否被 k 整除。

## Java 代码实现

```java
class Solution {
    public long countGoodIntegers(int n, int k) {
        long count = 0;
        int halfLen = (n + 1) / 2;
        long start = (long) Math.pow(10, halfLen - 1);
        long end = (long) Math.pow(10, halfLen);

        for (long half = start; half < end; half++) {
            String halfStr = Long.toString(half);
            // 构造完整回文串
            StringBuilder sb = new StringBuilder(halfStr);
            if (n % 2 == 0) {
                sb.append(new StringBuilder(halfStr).reverse());
            } else {
                // 奇数长度：中间字符不重复
                sb.append(new StringBuilder(halfStr.substring(0, halfLen - 1)).reverse());
            }
            long num = Long.parseLong(sb.toString());
            if (num % k == 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10^(n/2) * n)
- 空间复杂度：O(n)

## 关键点总结

1. n 位回文数由前 `ceil(n/2)` 位唯一确定
2. 奇数长度回文：后半 = 前半去掉最后一位后倒序；偶数长度：后半 = 前半倒序
3. 首位不能为 0，从 `10^(halfLen-1)` 开始枚举
