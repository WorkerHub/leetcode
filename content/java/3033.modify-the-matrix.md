## 题目描述

将矩阵中所有-1替换为该元素所在列的最大值。

## 解题思路

先计算每列最大值（排除-1），再将所有-1替换。

## Java 代码实现

```java
class Solution {
    public int[][] modifiedMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[] colMax = new int[n];
        for (int j = 0; j < n; j++) {
            int mx = -1;
            for (int i = 0; i < m; i++) {
                mx = Math.max(mx, matrix[i][j]);
            }
            colMax[j] = mx;
        }
        int[][] result = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[i][j] = matrix[i][j] == -1 ? colMax[j] : matrix[i][j];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N)
- **空间复杂度**：O(N)

## 关键点总结

1. **每列最大值排除-1**：题目保证列中有非-1值
2. **两遍扫描**：先求列最大，再替换
3. **返回新矩阵**
