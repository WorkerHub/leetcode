## 题目描述

与 3025 相同：Alice 选左上角，Bob 选右下角，矩形内无其他点，n 扩大到 1500。

## 解题思路

排序后 O(n²) 枚举：按 x 升序、x 相同按 y 降序排列，固定 Alice(i)，遍历 Bob(j) 时维护最大 y2（满足 y2≤y1 且是目前最大的），若当前 Bob 的 y2 > maxY2 则合法。

## Java 代码实现

```java
class Solution {
    public int numberOfPairs(int[][] points) {
        // 按 x 升序，x 相同则 y 降序
        Arrays.sort(points, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);
        int n = points.length, ans = 0;
        for (int i = 0; i < n; i++) {
            int x1 = points[i][0], y1 = points[i][1];
            int maxY2 = Integer.MIN_VALUE;
            for (int j = i + 1; j < n; j++) {
                int y2 = points[j][1];
                if (y2 > y1) continue; // Bob 必须在 Alice 下方或同高
                // y2 > maxY2 说明矩形内无其他更高点遮挡
                if (y2 > maxY2) {
                    maxY2 = y2;
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序保证遍历时 x2 ≥ x1
2. maxY2 记录目前最大合法 y2，当前 y2 > maxY2 时矩形内无其他点
3. x 相同时 y 降序，保证同 x 更高点先被"拦截"
