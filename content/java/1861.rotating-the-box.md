## 题目描述

箱子包含石头'#'、障碍物'*'和空位'.'。顺时针旋转90度后石头因重力下落，返回旋转后矩阵。

## 解题思路

两步：1) 模拟重力（石头向右落，双指针从右到左扫描）；2) 顺时针旋转90度（result[j][m-1-i] = box[i][j]）。

## Java 代码实现

```java
class Solution {
    public char[][] rotateTheBox(char[][] box) {
        int m = box.length, n = box[0].length;
        
        // 第一步：模拟重力（石头向右落）
        for (char[] row : box) {
            int empty = n - 1; // 空位指针
            for (int j = n - 1; j >= 0; j--) {
                if (row[j] == '#') {
                    row[j] = '.';
                    row[empty] = '#';
                    empty--;
                } else if (row[j] == '*') {
                    empty = j - 1;
                }
            }
        }
        
        // 第二步：顺时针旋转90度
        char[][] result = new char[n][m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[j][m - 1 - i] = box[i][j];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N)
- **空间复杂度**：O(M × N)

## 关键点总结

1. **重力方向是右**：旋转前先让石头向右落
2. **障碍物重置指针**：empty = j - 1
3. **旋转公式**：result[j][m-1-i] = box[i][j]
