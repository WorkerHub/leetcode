## 题目描述

对 nums 任意排列，使所有 requests 子数组和之总和最大。返回最大值对 10^9+7 取模。

## 解题思路

差分数组统计每个位置被覆盖次数，贪心：高频位置放大数。

## Java 代码实现

```java
class Solution {
    public int maxSumRangeQuery(int[] nums, int[][] requests) {
        long MOD = 1_000_000_007;
        int n = nums.length;
        // 差分数组
        int[] diff = new int[n + 1];
        for (int[] req : requests) {
            diff[req[0]]++;
            diff[req[1] + 1]--;
        }
        // 还原频次
        int[] freq = new int[n];
        freq[0] = diff[0];
        for (int i = 1; i < n; i++) {
            freq[i] = freq[i - 1] + diff[i];
        }
        
        Arrays.sort(freq);
        Arrays.sort(nums);
        
        // 贪心：大频次配大数
        long ans = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (freq[i] == 0) break;
            ans = (ans + (long)freq[i] * nums[i]) % MOD;
        }
        return (int)ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **差分数组**：O(R) 统计每个位置覆盖次数
2. **贪心匹配**：排序后大数配高频
3. **long 防溢出**：freq[i] * nums[i] 可能溢出 int
