## 题目描述

给你一个字符串 `s`，请你找出至多包含两个不同字符的最长子串，并返回该子串的长度。

**示例 1：**
```
输入：s = "eceba"
输出：3
解释：满足题意的子串是 "ece"，长度为 3。
```

**示例 2：**
```
输入：s = "ccaabbb"
输出：5
解释：满足题意的子串是 "aabbb"，长度为 5。
```

**提示：**
- 1 <= s.length <= 10^5
- s 由英文字母组成

## 解题思路

这是一道经典的滑动窗口问题，核心是维护一个至多包含两个不同字符的窗口。

**算法思路：**

1. **滑动窗口**：
   - 使用左右两个指针 `left` 和 `right` 表示窗口边界
   - 右指针不断向右扩展窗口
   - 当窗口内不同字符超过 2 个时，左指针向右收缩

2. **哈希表记录**：
   - 使用哈希表记录窗口内每个字符的出现次数
   - 当某个字符次数变为 0 时，从哈希表中删除
   - 哈希表的大小即为窗口内不同字符的个数

3. **更新最大长度**：
   - 每次窗口满足条件（不同字符 ≤ 2）时，更新最大长度
   - 最大长度 = right - left + 1

**优化思路：**
- 可以记录每个字符最后出现的位置，收缩时直接跳到最早出现字符的下一个位置

## Java 代码实现

### 方法一：滑动窗口 + HashMap（推荐）

```java
class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        /**
         * 滑动窗口 + HashMap
         * 时间复杂度：O(n)，其中 n 是字符串长度
         * 空间复杂度：O(1)，HashMap 最多存储 3 个字符
         */
        if (s.length() <= 2) return s.length();

        // HashMap 记录窗口内每个字符的出现次数
        Map<Character, Integer> charCount = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 扩展窗口：加入右边界字符
            char c = s.charAt(right);
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);

            // 如果窗口内不同字符超过 2 个，收缩窗口
            while (charCount.size() > 2) {
                char leftChar = s.charAt(left);
                charCount.put(leftChar, charCount.get(leftChar) - 1);
                if (charCount.get(leftChar) == 0) {
                    charCount.remove(leftChar);
                }
                left++;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法二：优化的滑动窗口（记录最后位置）

```java
class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        /**
         * 记录每个字符最后出现的位置，优化窗口收缩
         * 时间复杂度：O(n)
         * 空间复杂度：O(1)
         */
        if (s.length() <= 2) return s.length();

        // 记录每个字符最后出现的位置
        Map<Character, Integer> lastPos = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 更新当前字符的最后位置
            lastPos.put(s.charAt(right), right);

            // 如果不同字符超过 2 个
            if (lastPos.size() > 2) {
                // 找到最左边字符的最后位置
                int minPos = Collections.min(lastPos.values());
                // 删除该字符
                lastPos.remove(s.charAt(minPos));
                // 左指针移动到该字符的下一个位置
                left = minPos + 1;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法三：模板化滑动窗口（支持 k 个不同字符）

```java
class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        /**
         * 滑动窗口通用模板
         * 可以轻松修改为 k 个不同字符的版本
         */
        return atMostKDistinct(s, 2);
    }

    private int atMostKDistinct(String s, int k) {
        // 返回至多包含 k 个不同字符的最长子串长度
        Map<Character, Integer> charCount = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 扩展窗口
            char c = s.charAt(right);
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);

            // 收缩窗口
            while (charCount.size() > k) {
                char leftChar = s.charAt(left);
                charCount.put(leftChar, charCount.get(leftChar) - 1);
                if (charCount.get(leftChar) == 0) {
                    charCount.remove(leftChar);
                }
                left++;
            }

            // 更新答案
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法四：使用数组替代 HashMap（优化常数）

```java
class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        /**
         * 使用数组替代 HashMap，减少常数时间开销
         * （适用于字符集为 ASCII 的情况）
         */
        int[] count = new int[128];  // ASCII 字符集
        int distinctCount = 0;        // 不同字符数
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 扩展窗口
            char c = s.charAt(right);
            if (count[c] == 0) distinctCount++;
            count[c]++;

            // 收缩窗口
            while (distinctCount > 2) {
                char leftChar = s.charAt(left);
                count[leftChar]--;
                if (count[leftChar] == 0) distinctCount--;
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

## 复杂度分析

**方法一、三、四（标准滑动窗口）：**
- 时间复杂度：O(n)，每个字符最多被访问两次（右指针一次，左指针一次）
- 空间复杂度：O(1)，HashMap 最多存储 3 个字符（2 个合法 + 1 个待删除）

**方法二（优化版本）：**
- 时间复杂度：O(n)，每次收缩需要 O(1) 时间找最小位置（HashMap 最多 3 个元素）
- 空间复杂度：O(1)，HashMap 最多存储 3 个字符

## 关键点总结

1. **滑动窗口框架**：右指针扩展，左指针收缩，维护窗口性质
2. **HashMap 用途**：记录字符计数，判断不同字符个数
3. **删除时机**：字符计数变为 0 时从 HashMap 删除
4. **窗口收缩条件**：不同字符个数 > 2
5. **通用性**：可以轻松扩展为至多 k 个不同字符的版本

## 易错点

1. **边界情况**：字符串长度 ≤ 2 时直接返回长度
2. **删除字符**：计数变为 0 时必须从 HashMap 删除，否则 `size()` 不准确
3. **窗口长度计算**：是 `right - left + 1`，不是 `right - left`
4. **收缩条件**：是 `while charCount.size() > 2`，不是 `if`
5. **最大长度更新时机**：在窗口合法时更新，即收缩之后
