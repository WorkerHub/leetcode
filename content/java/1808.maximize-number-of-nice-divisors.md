## 题目描述

给你正整数 `primeFactors`，构造 n 使其质因子次数之和等于 `primeFactors`，最大化漂亮因子数（漂亮因子须被 n 的每个质因子整除）。返回最大漂亮因子数对 10^9+7 取余。

## 解题思路

漂亮因子数 = 各质因子幂次之积。将 `primeFactors` 拆分为若干正整数之和，使乘积最大——即 [LeetCode 343. Integer Break]：
- 尽量拆成 3；余 1 时用 4=2*2 替代 3+1；余 2 时直接保留 2
- 快速幂计算结果

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int maxNiceDivisors(int primeFactors) {
        int n = primeFactors;
        if (n <= 3) return n;

        int remainder = n % 3;
        int threes = n / 3;

        if (remainder == 0) {
            return (int) fastPow(3, threes);
        } else if (remainder == 1) {
            // 余 1：用 2*2=4 替代 3+1，少用一个 3
            return (int) (fastPow(3, threes - 1) * 4 % MOD);
        } else {
            // 余 2：保留 2
            return (int) (fastPow(3, threes) * 2 % MOD);
        }
    }

    private long fastPow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 本题与 343 整数拆分完全相同，答案 = 若干正整数乘积最大化
2. 余 1 时用两个 2（4=2*2）代替 3+1=4 但相等，或者 n=4 时直接返回 4
3. 快速幂防止溢出并取模
