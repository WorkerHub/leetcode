## 题目描述

m×n 矩阵中 0 为障碍，1 为地面，>1 为树（值为高度）。从 (0,0) 开始按高度从低到高砍树，返回最少步数，不可达返回 -1。

**示例：**
```
输入：forest = [[1,2,3],[0,0,4],[7,6,5]]
输出：6
```

## 解题思路

收集所有树按高度排序，依次 BFS 计算两点间最短路径，累加步数。

## Java 代码实现

```java
class Solution {
    private int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

    public int cutOffTree(List<List<Integer>> forest) {
        int m = forest.size(), n = forest.get(0).size();

        // 收集所有树并按高度排序
        List<int[]> trees = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (forest.get(i).get(j) > 1) {
                    trees.add(new int[]{forest.get(i).get(j), i, j});
                }
            }
        }
        trees.sort((a, b) -> a[0] - b[0]);

        // 依次砍树
        int total = 0;
        int curR = 0, curC = 0;
        for (int[] tree : trees) {
            int steps = bfs(forest, m, n, curR, curC, tree[1], tree[2]);
            if (steps == -1) return -1;
            total += steps;
            curR = tree[1];
            curC = tree[2];
        }
        return total;
    }

    private int bfs(List<List<Integer>> forest, int m, int n,
                    int sr, int sc, int er, int ec) {
        if (sr == er && sc == ec) return 0;

        boolean[][] visited = new boolean[m][n];
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{sr, sc, 0});
        visited[sr][sc] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int[] dir : dirs) {
                int nr = cur[0] + dir[0], nc = cur[1] + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && !visited[nr][nc] && forest.get(nr).get(nc) != 0) {
                    if (nr == er && nc == ec) return cur[2] + 1;
                    visited[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, cur[2] + 1});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × m × n)，k 为树的数量
- **空间复杂度**：O(m × n)

## 关键点总结

1. **问题分解**：排序 + 多次 BFS 最短路径
2. **BFS 应用**：网格两点间最短路径
3. **可达性检查**：任何一棵树不可达立即返回 -1
