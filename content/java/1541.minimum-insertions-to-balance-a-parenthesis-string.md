## 题目描述

括号字符串中每个 '(' 必须对应两个连续 '))'。每次可插入一个括号字符，返回使字符串平衡所需的最少插入次数。

**示例：**
```
输入：s = "(()))"
输出：1
```

## 解题思路

贪心扫描：用 open_cnt 记录未匹配左括号数。遇到右括号时判断是否连续两个，不够则补一个。

## Java 代码实现

```java
class Solution {
    public int minInsertions(String s) {
        int ans = 0;
        int openCnt = 0; // 未匹配的 '(' 数量
        int i = 0, n = s.length();
        
        while (i < n) {
            if (s.charAt(i) == '(') {
                openCnt++;
                i++;
            } else {
                // 遇到右括号，需要两个连续 '))'
                if (i + 1 < n && s.charAt(i + 1) == ')') {
                    // 有两个连续右括号
                    i += 2;
                } else {
                    // 只有一个右括号，需插入一个 ')'
                    ans++;
                    i++;
                }
                // 消耗一个 '('
                if (openCnt > 0) {
                    openCnt--;
                } else {
                    // 没有 '(' 匹配，需插入一个 '('
                    ans++;
                }
            }
        }
        // 剩余未匹配的 '(' 每个需要插入两个 ')'
        ans += openCnt * 2;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **1:2 匹配**：一个 '(' 对应两个 '))'
2. **贪心消耗**：遇到右括号先判断是否连续两个
3. **末尾处理**：剩余未匹配 '(' 每个需补两个 ')'
