## 题目描述

给你节点数 `n` 和无向边 `edges`，构造一个行×列的二维网格，使相邻格子当且仅当对应边存在。若存在则返回网格，否则返回空数组。（n×m ≤ 12）

## 解题思路

回溯法：枚举所有行列因数分解，以每个节点为起点，逐格填入满足约束的候选节点（第一行按左邻约束，其余行按上邻和左邻约束）。由于 n ≤ 12 约束严格，回溯很快。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[][] grid;
    private boolean[] used;
    private Set<Integer>[] adj;
    private int rows, cols;

    @SuppressWarnings("unchecked")
    public int[][] constructGridLayout(int n, int[][] edges) {
        adj = new Set[n];
        for (int i = 0; i < n; i++) adj[i] = new HashSet<>();
        for (int[] e : edges) { adj[e[0]].add(e[1]); adj[e[1]].add(e[0]); }

        // 枚举所有行列因数分解（rows <= cols）
        for (int r = 1; r * r <= n; r++) {
            if (n % r != 0) continue;
            rows = r; cols = n / r;
            grid = new int[rows][cols];
            used = new boolean[n];
            for (int[] row : grid) Arrays.fill(row, -1);
            // 尝试每个节点作为起始角节点
            for (int start = 0; start < n; start++) {
                Arrays.fill(used, false);
                for (int[] row : grid) Arrays.fill(row, -1);
                used[start] = true;
                grid[0][0] = start;
                if (backtrack(0, 1)) return grid;
            }
        }
        return new int[0][];
    }

    private boolean backtrack(int r, int c) {
        if (r == rows) return true;
        if (c == cols) return backtrack(r + 1, 0);

        List<Integer> candidates = new ArrayList<>();
        if (r == 0) {
            // 第一行：必须与左邻相邻
            for (int v : adj[grid[0][c - 1]]) {
                if (!used[v]) candidates.add(v);
            }
        } else {
            // 必须与上方相邻（且若有左邻，也必须与左邻相邻）
            for (int v : adj[grid[r - 1][c]]) {
                if (!used[v] && (c == 0 || adj[grid[r][c - 1]].contains(v))) {
                    candidates.add(v);
                }
            }
        }

        for (int v : candidates) {
            grid[r][c] = v;
            used[v] = true;
            if (backtrack(r, c + 1)) return true;
            used[v] = false;
            grid[r][c] = -1;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：实际很快，约束严格使回溯分支极少；理论上 O((n*m)!)
- 空间复杂度：O(n × m)

## 关键点总结

1. 相邻约束剪枝：每格候选仅为上方和左方共同邻居，候选极少
2. 枚举行列因数对（rows ≤ cols），每种尝试所有起始节点
3. n×m ≤ 12 保证回溯可行
