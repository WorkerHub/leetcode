## 题目描述

统计不同子数组数量，要求子数组中整除p的元素最多k个。

## 解题思路

字典树去重：枚举所有起点，向右扩展维护整除计数，用Trie记录路径，每个新节点代表一个新的不同子数组。

## Java 代码实现

```java
class Solution {
    public int countDistinct(int[] nums, int k, int p) {
        int n = nums.length;
        // 字典树用HashMap嵌套模拟
        Map<Integer, Object>[] trie = new Map[]{new HashMap<>()};
        int count = 0;

        for (int i = 0; i < n; i++) {
            Map<Integer, Object> node = (Map<Integer, Object>) trie[0];
            int divCnt = 0;
            for (int j = i; j < n; j++) {
                if (nums[j] % p == 0) divCnt++;
                if (divCnt > k) break;
                if (!node.containsKey(nums[j])) {
                    node.put(nums[j], new HashMap<>());
                    count++;
                }
                node = (Map<Integer, Object>) node.get(nums[j]);
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N²)
- **空间复杂度**：O(N²)

## 关键点总结

1. **字典树去重**：每个新节点对应一个新的不同子数组
2. **提前剪枝**：整除计数超k时break
3. **n<=200**：O(N²)复杂度完全可行
