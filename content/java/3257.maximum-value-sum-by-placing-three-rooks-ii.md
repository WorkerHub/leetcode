## 题目描述

与 3256 相同，但数据范围更大：`3 <= m, n <= 500`，`-10^9 <= board[i][j] <= 10^9`。

## 解题思路

与 3256 完全相同：每行保留 top3，前后缀合并，枚举中间行。O(m*n) 时间复杂度，完全适合 500x500 矩阵。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumValueSum(int[][] board) {
        int m = board.length, n = board[0].length;

        // 对每行取最大的 3 个 (value, col)
        long[][][] rows = new long[m][3][2];
        for (int r = 0; r < m; r++) {
            long[][] top3 = {{Long.MIN_VALUE, -1}, {Long.MIN_VALUE, -1}, {Long.MIN_VALUE, -1}};
            for (int c = 0; c < n; c++) {
                long v = board[r][c];
                if (v > top3[0][0]) {
                    top3[2] = top3[1]; top3[1] = top3[0];
                    top3[0] = new long[]{v, c};
                } else if (v > top3[1][0]) {
                    top3[2] = top3[1];
                    top3[1] = new long[]{v, c};
                } else if (v > top3[2][0]) {
                    top3[2] = new long[]{v, c};
                }
            }
            rows[r] = top3;
        }

        // 前缀 top3（行 0..i 合并）
        long[][][] prefix = new long[m][3][2];
        prefix[0] = rows[0];
        for (int i = 1; i < m; i++) {
            prefix[i] = mergeTop3(prefix[i - 1], rows[i]);
        }

        // 后缀 top3（行 i..m-1 合并）
        long[][][] suffix = new long[m][3][2];
        suffix[m - 1] = rows[m - 1];
        for (int i = m - 2; i >= 0; i--) {
            suffix[i] = mergeTop3(suffix[i + 1], rows[i]);
        }

        long ans = Long.MIN_VALUE;
        for (int r2 = 1; r2 < m - 1; r2++) {
            for (long[] t2 : rows[r2]) {
                long v2 = t2[0]; long c2 = t2[1];
                for (long[] t1 : prefix[r2 - 1]) {
                    long v1 = t1[0]; long c1 = t1[1];
                    if (c1 == c2) continue;
                    for (long[] t3 : suffix[r2 + 1]) {
                        long v3 = t3[0]; long c3 = t3[1];
                        if (c3 != c1 && c3 != c2) {
                            ans = Math.max(ans, v1 + v2 + v3);
                            break;
                        }
                    }
                    break;
                }
            }
        }
        return ans;
    }

    private long[][] mergeTop3(long[][] a, long[][] b) {
        long[][] combined = new long[6][2];
        System.arraycopy(a, 0, combined, 0, 3);
        System.arraycopy(b, 0, combined, 3, 3);
        Arrays.sort(combined, (x, y) -> Long.compare(y[0], x[0]));
        return Arrays.copyOf(combined, 3);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n + m * 27) = O(m * n)
- 空间复杂度：O(m * 3)

## 关键点总结

1. 每行只需 top3，枚举三行选三不同列最多 27 种组合
2. 前后缀合并保证跨行选最优候选
3. 枚举中间行，在前后缀中查找列不冲突的最大组合
