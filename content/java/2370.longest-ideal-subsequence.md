## 题目描述

给你小写字母字符串 `s` 和整数 `k`，返回 `s` 的最长理想子序列长度（子序列中相邻两字母在字母表中位次差不超过 `k`）。

## 解题思路

定义 `dp[c]` 为以字母 `c` 结尾的最长理想子序列长度。对 `s` 中每个字符 `c`，枚举所有与其差值 <= k 的字母取最大 dp 值，再加 1 更新 `dp[c]`。

## Java 代码实现

```java
class Solution {
    public int longestIdealString(String s, int k) {
        int[] dp = new int[26]; // dp[c] 表示以字母 c 结尾的最长理想子序列长度
        int ans = 0;
        for (char ch : s.toCharArray()) {
            int idx = ch - 'a';
            int best = 0;
            // 枚举差值 <= k 的前驱字母
            for (int prev = Math.max(0, idx - k); prev <= Math.min(25, idx + k); prev++) {
                best = Math.max(best, dp[prev]);
            }
            dp[idx] = best + 1;
            ans = Math.max(ans, dp[idx]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)，k <= 25 故近似 O(n)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. `dp[c]` 表示以字母 `c` 结尾的最长理想子序列，只有 26 个状态。
2. 每次遇到字符 `c`，枚举 `[c-k, c+k]` 范围的前驱字母取最大值再加 1。
3. 枚举范围需与 `[0, 25]` 取交集防止越界。
