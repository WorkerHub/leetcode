## 题目描述

n 个项目分为 m 个组，有依赖关系。排序要求：同组项目连续、依赖关系满足。返回合法排列或空数组。

**示例：**
```
输入：n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3,6],[],[],[]]
输出：[6,3,4,1,5,2,0,7]
```

## 解题思路

双层拓扑排序：1）将无组项目分配独立组号；2）构建组间依赖图和组内依赖图；3）对组拓扑排序确定组顺序；4）对每组内项目拓扑排序。

## Java 代码实现

```java
class Solution {
    public int[] sortItems(int n, int m, int[] group, List<List<Integer>> beforeItems) {
        // 为无组项目分配独立组号
        int groupId = m;
        for (int i = 0; i < n; i++) {
            if (group[i] == -1) group[i] = groupId++;
        }
        
        // 构建图
        List<List<Integer>> itemGraph = new ArrayList<>();
        List<List<Integer>> groupGraph = new ArrayList<>();
        int[] itemIndegree = new int[n];
        int[] groupIndegree = new int[groupId];
        
        for (int i = 0; i < n; i++) itemGraph.add(new ArrayList<>());
        for (int i = 0; i < groupId; i++) groupGraph.add(new ArrayList<>());
        
        // 记录每个组的项目
        List<List<Integer>> groupItems = new ArrayList<>();
        for (int i = 0; i < groupId; i++) groupItems.add(new ArrayList<>());
        for (int i = 0; i < n; i++) groupItems.get(group[i]).add(i);
        
        // 构建依赖关系（组间去重）
        Set<Long> groupEdges = new HashSet<>();
        for (int i = 0; i < n; i++) {
            for (int before : beforeItems.get(i)) {
                itemGraph.get(before).add(i);
                itemIndegree[i]++;
                if (group[before] != group[i]) {
                    long edge = (long) group[before] * groupId + group[i];
                    if (groupEdges.add(edge)) {
                        groupGraph.get(group[before]).add(group[i]);
                        groupIndegree[group[i]]++;
                    }
                }
            }
        }
        
        // 组拓扑排序
        List<Integer> groupOrder = topoSort(groupGraph, groupIndegree, groupId);
        if (groupOrder.isEmpty()) return new int[0];
        
        // 按组顺序，对每组内项目拓扑排序
        int[] result = new int[n];
        int idx = 0;
        for (int gid : groupOrder) {
            List<Integer> items = groupItems.get(gid);
            if (items.isEmpty()) continue;
            List<Integer> sorted = topoSortItems(itemGraph, itemIndegree, items);
            if (sorted.isEmpty() && !items.isEmpty()) return new int[0];
            for (int item : sorted) result[idx++] = item;
        }
        return result;
    }
    
    private List<Integer> topoSort(List<List<Integer>> graph, int[] indegree, int total) {
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < total; i++) {
            if (indegree[i] == 0) queue.offer(i);
        }
        List<Integer> result = new ArrayList<>();
        while (!queue.isEmpty()) {
            int node = queue.poll();
            result.add(node);
            for (int next : graph.get(node)) {
                if (--indegree[next] == 0) queue.offer(next);
            }
        }
        return result.size() == total ? result : Collections.emptyList();
    }
    
    private List<Integer> topoSortItems(List<List<Integer>> graph, int[] indegree, List<Integer> items) {
        Set<Integer> itemSet = new HashSet<>(items);
        Queue<Integer> queue = new LinkedList<>();
        for (int item : items) {
            if (indegree[item] == 0) queue.offer(item);
        }
        List<Integer> result = new ArrayList<>();
        while (!queue.isEmpty()) {
            int node = queue.poll();
            result.add(node);
            for (int next : graph.get(node)) {
                if (itemSet.contains(next) && --indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }
        return result.size() == items.size() ? result : Collections.emptyList();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m + E)
- **空间复杂度**：O(n + m + E)

## 关键点总结

1. **双层拓扑排序**：组间 + 组内分别拓扑排序
2. **无组项目**：分配独立组号避免混淆
3. **组间边去重**：同组间可能有多条依赖，需去重避免入度多算
4. **环检测**：拓扑排序节点数 < 总数则有环
