## 题目描述

给你二维数组 `queries`（每次在坐标 `(xi, yi)` 添加障碍物）和整数 `k`，每次添加后返回距原点第 `k` 近的曼哈顿距离，不足 k 个时返回 -1。

## 解题思路

维护大小为 k 的最大堆，堆顶即为第 k 近的距离。新距离若小于堆顶则替换，堆未满则返回 -1。

## Java 代码实现

```java
import java.util.PriorityQueue;
import java.util.Collections;

class Solution {
    public int[] resultsArray(int[][] queries, int k) {
        int n = queries.length;
        int[] ans = new int[n];
        // 最大堆，堆顶为当前前 k 近中最大的距离
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());

        for (int i = 0; i < n; i++) {
            int dist = Math.abs(queries[i][0]) + Math.abs(queries[i][1]);
            if (maxHeap.size() < k) {
                maxHeap.offer(dist);
            } else if (dist < maxHeap.peek()) {
                // 新距离更小，替换堆顶
                maxHeap.poll();
                maxHeap.offer(dist);
            }
            ans[i] = maxHeap.size() == k ? maxHeap.peek() : -1;
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log k)
- 空间复杂度：O(k)

## 关键点总结

1. 维护大小为 k 的最大堆，堆顶是第 k 近的距离
2. 新距离小于堆顶时才替换，否则不影响前 k 名
3. 堆未满（元素 < k）时返回 -1
