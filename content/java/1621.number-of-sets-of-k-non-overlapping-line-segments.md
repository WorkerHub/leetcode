## 题目描述

给你一维数轴上共有 `n+1` 个点，点的位置为 `0` 到 `n`。给你一个整数 `k`，请你返回所有 **k 个互不重叠的线段**的方案数，线段端点必须是整数点，并且线段长度至少为 1。

由于答案可能很大，请将答案对 `10^9 + 7` 取余后返回。

**提示：**
- `2 <= n <= 1000`
- `1 <= k <= n/2`

## 解题思路

使用**组合数公式**：k 个不重叠线段（端点可共享）的方案数等于 `C(n+k, 2k)`。

通过**动态规划**求组合数，用帕斯卡三角形避免求逆元。

## Java 代码实现

```java
class Solution {
    public int numberOfSets(int n, int k) {
        final int MOD = 1_000_000_007;
        // 计算 C(n+k, 2k)，使用帕斯卡三角形
        int total = n + k;
        int r = 2 * k;
        // dp[i][j] = C(i, j)
        long[][] dp = new long[total + 1][r + 1];
        dp[0][0] = 1;
        for (int i = 1; i <= total; i++) {
            dp[i][0] = 1;
            for (int j = 1; j <= Math.min(i, r); j++) {
                dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j]) % MOD;
            }
        }
        return (int) dp[total][r];
    }
}
```

### 方法二：标准 DP（前缀和优化）

```java
class Solution {
    public int numberOfSets(int n, int k) {
        final int MOD = 1_000_000_007;
        // dp[i][j][0]: 点 i 没有线段结尾，已选 j 个线段
        // dp[i][j][1]: 点 i 有线段结尾，已选 j 个线段
        long[][][] dp = new long[n + 1][k + 1][2];
        for (int i = 0; i <= n; i++) dp[i][0][0] = 1;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= k; j++) {
                // 点 i 不是线段末尾
                dp[i][j][0] = (dp[i - 1][j][0] + dp[i - 1][j][1]) % MOD;
                // 点 i 是线段末尾
                dp[i][j][1] = (dp[i - 1][j - 1][0] + dp[i - 1][j - 1][1] + dp[i][j][1]) % MOD;
            }
        }
        return (int) ((dp[n][k][0] + dp[n][k][1]) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n+k)^2)（帕斯卡三角形），O(n*k)（DP）
- **空间复杂度**：O((n+k)^2) 或 O(n*k)

## 关键点总结

1. k 个不重叠线段（端点可共享）的方案数等于 `C(n+k, 2k)`
2. Java 中用帕斯卡三角形计算组合数，避免模逆元
3. DP 方法使用两个状态（是否以点 i 为线段末尾）
