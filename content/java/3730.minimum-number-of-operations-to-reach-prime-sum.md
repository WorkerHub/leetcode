## 题目描述

给定整数 `n`，每次操作可将 `n` 加 1 或减 1，求使 `n` 变为素数所需的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int n) {
        // 向下找最近素数
        int lo = n;
        while (lo >= 2 && !isPrime(lo)) lo--;

        // 向上找最近素数
        int hi = n;
        while (!isPrime(hi)) hi++;

        if (lo < 2) return hi - n;
        return Math.min(n - lo, hi - n);
    }

    private boolean isPrime(int x) {
        if (x < 2) return false;
        if (x == 2) return true;
        if (x % 2 == 0) return false;
        for (int i = 3; (long) i * i <= x; i += 2) {
            if (x % i == 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(sqrt(n) * gap)，gap 为到最近素数的距离（通常很小）
- 空间复杂度：O(1)

## 关键点总结

1. 双向搜索：同时向上和向下找最近素数，取步数较小的
2. 素数判断只需检查到 sqrt(x)
3. 向下搜索不能低于 2（最小素数）
