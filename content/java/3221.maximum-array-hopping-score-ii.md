## 题目描述

与 3205 相同规则，数组规模更大（`n <= 10^5`），每次从下标 `i` 跳到 `j`（`i < j`）得分 `(j - i) * nums[j]`，返回从下标 `0` 跳到 `n-1` 的最大总分。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxScore(int[] nums) {
        int n = nums.length;
        // 从右到左构建单调递减栈，保留所有"有价值"的跳跃点（后缀最大值）
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = n - 1; i >= 0; i--) {
            if (stack.isEmpty() || nums[i] > nums[stack.peek()]) {
                stack.push(i);
            }
        }
        // 转为从左到右的列表（值单调递增）
        List<Integer> points = new ArrayList<>(stack);
        Collections.reverse(points);

        long ans = 0;
        int prev = points.get(0); // 起点应为 0
        for (int k = 1; k < points.size(); k++) {
            int j = points.get(k);
            ans += (long) (j - prev) * nums[j];
            prev = j;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单调栈
- 空间复杂度：O(n)

## 关键点总结

1. 最优跳跃路径只经过"后缀最大值"节点
2. 单调栈从右到左维护递减序列，得到关键节点
3. 在关键节点之间贪心跳跃，累加得分
