## 题目描述

n 个扇区的环形赛道，给定每圈结束位置 rounds 数组，返回访问次数最多的扇区列表（升序）。

**示例：**
```
输入：n = 4, rounds = [1,3,1,2]
输出：[1,2]
```

## 解题思路

关键观察：只需看起点 rounds[0] 和终点 rounds[-1]，中间完整圈每个扇区访问次数相同。

## Java 代码实现

```java
class Solution {
    public List<Integer> mostVisited(int n, int[] rounds) {
        int start = rounds[0];
        int end = rounds[rounds.length - 1];
        List<Integer> result = new ArrayList<>();
        
        if (start <= end) {
            // 终点在起点右侧
            for (int i = start; i <= end; i++) {
                result.add(i);
            }
        } else {
            // 绕过了 n，分两段
            for (int i = 1; i <= end; i++) {
                result.add(i);
            }
            for (int i = start; i <= n; i++) {
                result.add(i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **完整圈抵消**：中间完整圈每扇区等次访问
2. **只看首尾**：起点到终点之间的扇区多访问一次
3. **两种情况**：end ≥ start 直接范围，否则分两段
