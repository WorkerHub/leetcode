## 题目描述

给定 `buildings[i] = [start, end, height]`，每个位置高度为覆盖它的所有建筑物的平均高度（向下取整），返回平均高度连续相同段的列表（相邻段高度不同）。

## 解题思路

差分 + 扫描线：在 start 处高度和计数各 +1，在 end+1 处各 -1。收集所有事件点排序后扫描，对每段计算平均高度并合并相邻等高段。

## Java 代码实现

### 方法一：差分数组 + 扫描线（推荐）

```java
import java.util.*;

class Solution {
    public int[][] averageHeightOfBuildings(int n, int[][] buildings) {
        // 收集所有事件：(位置, 高度变化, 计数变化)
        Map<Integer, int[]> events = new TreeMap<>();
        for (int[] b : buildings) {
            events.computeIfAbsent(b[0], k -> new int[2]);
            events.get(b[0])[0] += b[2];
            events.get(b[0])[1] += 1;
            events.computeIfAbsent(b[1] + 1, k -> new int[2]);
            events.get(b[1] + 1)[0] -= b[2];
            events.get(b[1] + 1)[1] -= 1;
        }

        List<int[]> result = new ArrayList<>();
        int curHeight = 0, curCount = 0, prevPos = -1;

        for (Map.Entry<Integer, int[]> entry : events.entrySet()) {
            int pos = entry.getKey();
            // 结算上一段（若有建筑覆盖）
            if (curCount > 0 && prevPos != -1) {
                int avg = curHeight / curCount;
                if (!result.isEmpty() && result.get(result.size()-1)[2] == avg
                    && result.get(result.size()-1)[1] == pos - 1) {
                    result.get(result.size()-1)[1] = pos - 1; // 合并
                } else {
                    result.add(new int[]{prevPos, pos - 1, avg});
                }
            }
            curHeight += entry.getValue()[0];
            curCount += entry.getValue()[1];
            prevPos = pos;
        }

        // 处理最后一段
        if (curCount > 0) {
            int avg = curHeight / curCount;
            if (!result.isEmpty() && result.get(result.size()-1)[2] == avg
                && result.get(result.size()-1)[1] == prevPos - 1) {
                result.get(result.size()-1)[1] = n;
            } else {
                result.add(new int[]{prevPos, n, avg});
            }
        }

        return result.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m)，m 为 buildings 数量
- 空间复杂度：O(m)

## 关键点总结

1. 差分数组：在 start 加，在 end+1 减，通过前缀和还原每个位置的覆盖情况
2. 只处理有事件的关键点，不遍历全部 1 到 n
3. 合并相邻平均高度相同的段；区间是闭区间，差分在 end+1 处减
