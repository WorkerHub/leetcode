## 题目描述

有台奇怪的打印机有以下两个特殊要求：

1. 打印机每次只能打印由**同一个字符**组成的序列。
2. 每次可以在从起始到结束的任意位置打印新字符，并且会覆盖掉原来已有的字符。

给你一个字符串 `s`，你的任务是计算这个打印机打印它需要的最少打印次数。

**示例 1:**

```
输入：s = "aaabbb"
输出：2
解释：首先打印 "aaa"，然后打印 "bbb"
```

**示例 2:**

```
输入：s = "aba"
输出：2
解释：首先打印 "aaa"，然后在第二个位置打印 "b" 覆盖掉原来的字符 'a'
```

**提示:**
- `1 <= s.length <= 100`
- `s` 由小写英文字母组成

## 解题思路

这是一道经典的**区间 DP** 问题。

### 核心思想

定义 `dp[i][j]`：打印字符串 `s[i..j]` 所需的最少次数。

**状态转移：**

1. **基础情况**：单个字符只需打印一次，`dp[i][i] = 1`

2. **相同首尾**：如果 `s[i] == s[j]`
   - 可以在打印 `s[i..j-1]` 时一起打印 `s[j]`
   - `dp[i][j] = dp[i][j-1]`

3. **不同首尾**：枚举分割点 k
   - `dp[i][j] = min(dp[i][k] + dp[k+1][j])` for k in range(i, j)

## Java 代码实现

### 方法一：区间 DP（推荐）

```java
class Solution {
    public int strangePrinter(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];

        // 从右往左，从下往上填表
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                // 最坏情况：每个字符打印一次
                dp[i][j] = dp[i][j - 1] + 1;

                // 如果首尾相同，可以一起打印
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i][j - 1];
                }

                // 尝试分割
                for (int k = i; k < j; k++) {
                    dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j]);
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

### 方法二：记忆化搜索

```java
import java.util.*;

class Solution {
    private int[][] memo;
    private String s;

    public int strangePrinter(String s) {
        this.s = s;
        int n = s.length();
        memo = new int[n][n];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dp(0, n - 1);
    }

    private int dp(int i, int j) {
        if (i > j) return 0;
        if (i == j) return 1;
        if (memo[i][j] != -1) return memo[i][j];

        int result = dp(i, j - 1) + 1;

        for (int k = i; k < j; k++) {
            if (s.charAt(k) == s.charAt(j)) {
                result = Math.min(result, dp(i, k) + dp(k + 1, j - 1));
            }
        }

        memo[i][j] = result;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：子问题是区间
2. **首尾相同**：可以优化，不需要额外打印
3. **分割策略**：枚举所有可能的分割点

## 易错点

1. **DP 初始化**：
   ```java
   dp[i][i] = 1; // 单个字符需要打印一次
   ```

2. **循环顺序**：
   ```java
   // 外层从大到小，内层从小到大
   for (int i = n - 1; i >= 0; i--) {
       for (int j = i + 1; j < n; j++) { ... }
   }
   ```

3. **边界条件**：
   ```java
   if (i > j) return 0;
   ```
