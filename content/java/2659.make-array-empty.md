## 题目描述

给你含不同正整数的数组 `nums`，每步若首元素是最小值则删除，否则移到末尾，返回清空数组所需的总操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] bit;
    private int n;

    public long countOperationsToEmptyArray(int[] nums) {
        n = nums.length;
        bit = new int[n + 1];

        // 按值排序，得到删除顺序（存原始下标）
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> nums[a] - nums[b]);

        long ans = 0;
        int curPos = 0; // 当前位置（0-indexed）

        for (int rank = 0; rank < n; rank++) {
            int idx = order[rank] + 1; // 转为 1-indexed
            int remaining = n - rank;  // 当前剩余元素数

            if (idx > curPos) {
                // 目标在当前位置之后
                ans += idx - curPos - deletedInRange(curPos + 1, idx);
            } else {
                // 目标在当前位置之前，需绕一圈
                ans += (n - curPos - deletedInRange(curPos + 1, n))
                     + (idx - deletedInRange(1, idx));
            }
            curPos = idx;
            update(idx); // 标记为已删除
        }
        return ans;
    }

    private void update(int i) {
        for (; i <= n; i += i & (-i)) bit[i]++;
    }

    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & (-i)) s += bit[i];
        return s;
    }

    private int deletedInRange(int l, int r) {
        if (l > r) return 0;
        return query(r) - query(l - 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 按值从小到大依次删除，用树状数组记录已删除位置
2. 目标在当前位置之后：直接计算存活元素步数
3. 目标在当前位置之前：需绕一圈，步数 = 后半段存活数 + 前半段存活数
