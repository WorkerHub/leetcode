## 题目描述

给你二叉树的根节点 `root`，此外树的每个节点的值要么是 `0`，要么是 `1`。

返回移除了所有不包含 `1` 的子树的原二叉树。

节点 `node` 的子树为 `node` 本身加上所有 `node` 的后代。

**示例 1:**
```
输入: root = [1,null,0,0,1]
输出: [1,null,0,null,1]
```

**示例 2:**
```
输入: root = [1,0,1,0,0,0,1]
输出: [1,null,1,null,1]
```

**示例 3:**
```
输入: root = [1,1,0,1,1,0,1,0]
输出: [1,1,0,1,1,null,1]
```

**提示:**
- 树中节点的数目在范围 `[1, 200]` 内
- `Node.val` 为 `0` 或 `1`

## 解题思路

使用后序遍历（左右根），递归判断子树是否包含 1。

**递归逻辑：**
1. 递归处理左右子树
2. 如果子树不包含 1，则置为 null
3. 判断当前节点及其子树是否包含 1

## Java 代码实现

### 方法一：后序遍历（推荐）

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public TreeNode pruneTree(TreeNode root) {
        if (root == null) return null;

        // 递归处理左右子树
        root.left = pruneTree(root.left);
        root.right = pruneTree(root.right);

        // 如果当前节点值为 0 且左右子树都为空，删除当前节点
        if (root.val == 0 && root.left == null && root.right == null) {
            return null;
        }

        return root;
    }
}
```

### 方法二：辅助函数判断是否包含 1

```java
class Solution {
    public TreeNode pruneTree(TreeNode root) {
        // 如果整棵树都不包含 1，返回 null
        return containsOne(root) ? root : null;
    }

    /**
     * 判断以 node 为根的子树是否包含 1
     */
    private boolean containsOne(TreeNode node) {
        if (node == null) return false;

        // 递归处理左右子树
        boolean leftHasOne = containsOne(node.left);
        boolean rightHasOne = containsOne(node.right);

        // 如果左子树不包含 1，删除它
        if (!leftHasOne) node.left = null;

        // 如果右子树不包含 1，删除它
        if (!rightHasOne) node.right = null;

        // 当前子树包含 1 的条件：
        // 1. 当前节点值为 1，或
        // 2. 左子树包含 1，或
        // 3. 右子树包含 1
        return node.val == 1 || leftHasOne || rightHasOne;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，访问每个节点一次
- **空间复杂度**：O(h)，递归栈深度，h 为树的高度

## 关键点总结

1. **后序遍历**：先处理子树，再处理根
2. **递归返回**：返回处理后的子树
3. **删除条件**：值为 0 且没有子树

## 易错点

1. **遍历顺序**：必须是后序，不能前序
2. **null 处理**：空节点直接返回 null
3. **根节点**：整棵树可能都被删除
