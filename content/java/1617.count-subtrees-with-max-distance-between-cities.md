## 题目描述

n个城市构成树，返回数组ans[i]表示最大距离恰好为i+1的连通子树数目。n≤15。

## 解题思路

枚举所有子集（2^15），对每个子集检查连通性（边数=节点数-1）并用预处理距离计算最大距离。

## Java 代码实现

```java
class Solution {
    public int[] countSubgraphsForEachDiameter(int n, int[][] edges) {
        // 建图
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0] - 1).add(e[1] - 1);
            graph.get(e[1] - 1).add(e[0] - 1);
        }
        
        // BFS预处理任意两点距离
        int[][] dist = new int[n][n];
        for (int src = 0; src < n; src++) {
            Arrays.fill(dist[src], -1);
            dist[src][src] = 0;
            Queue<Integer> queue = new LinkedList<>();
            queue.offer(src);
            while (!queue.isEmpty()) {
                int u = queue.poll();
                for (int v : graph.get(u)) {
                    if (dist[src][v] == -1) {
                        dist[src][v] = dist[src][u] + 1;
                        queue.offer(v);
                    }
                }
            }
        }
        
        int[] ans = new int[n - 1];
        // 枚举所有子集
        for (int mask = 1; mask < (1 << n); mask++) {
            int cnt = Integer.bitCount(mask);
            if (cnt < 2) continue;
            
            // 检查连通性：边数 = 节点数 - 1
            int edgeCount = 0;
            for (int u = 0; u < n; u++) {
                if ((mask >> u & 1) == 0) continue;
                for (int v : graph.get(u)) {
                    if ((mask >> v & 1) == 1) edgeCount++;
                }
            }
            edgeCount /= 2;
            if (edgeCount != cnt - 1) continue;
            
            // 计算最大距离
            int maxDist = 0;
            for (int u = 0; u < n; u++) {
                if ((mask >> u & 1) == 0) continue;
                for (int v = u + 1; v < n; v++) {
                    if ((mask >> v & 1) == 0) continue;
                    maxDist = Math.max(maxDist, dist[u][v]);
                }
            }
            if (maxDist > 0) ans[maxDist - 1]++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^N × N²)
- **空间复杂度**：O(N²)

## 关键点总结

1. **N≤15**：枚举所有子集可行
2. **连通性判断**：边数=节点数-1
3. **预处理BFS距离**：O(1)查询任意两点距离
