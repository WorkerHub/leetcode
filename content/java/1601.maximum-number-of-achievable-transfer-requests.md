## 题目描述

n栋楼，requests[i]=[from,to]表示转移请求。选择请求子集使每栋楼净变化为0，求最多可完成的请求数。

**提示：** requests.length ≤ 16

## 解题思路

枚举子集：requests≤16，枚举所有2^m种组合，检查每栋楼净变化是否全为0。

## Java 代码实现

```java
class Solution {
    public int maximumRequests(int n, int[][] requests) {
        int m = requests.length;
        int ans = 0;
        
        // 枚举所有 2^m 个子集
        for (int mask = 0; mask < (1 << m); mask++) {
            int[] delta = new int[n];
            int count = 0;
            for (int i = 0; i < m; i++) {
                if ((mask >> i & 1) == 1) {
                    delta[requests[i][0]]--;
                    delta[requests[i][1]]++;
                    count++;
                }
            }
            // 检查是否所有楼净变化为0
            boolean valid = true;
            for (int d : delta) {
                if (d != 0) { valid = false; break; }
            }
            if (valid) ans = Math.max(ans, count);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^m × (m + n))
- **空间复杂度**：O(n)

## 关键点总结

1. **requests≤16**：枚举子集可行（2^16=65536）
2. **净变化为0**：每栋楼转入=转出
3. **位运算枚举**：mask>>i&1 判断第i个请求是否选中
