## 题目描述

给定一个由 `'B'`（黑色像素）和 `'W'`（白色像素）组成的二维数组 `picture`，找出所有"孤独的黑色像素"的数量。

"孤独的黑色像素"是指字符 `'B'`，它所在的行和列都只有这一个黑色像素。

**示例 1：**
```
输入: picture = [['W', 'W', 'B'],
                ['W', 'B', 'W'],
                ['B', 'W', 'W']]
输出: 3
```

**示例 2：**
```
输入: picture = [['B', 'B', 'B'],
                ['B', 'B', 'W'],
                ['B', 'W', 'W']]
输出: 0
```

## 解题思路

两次遍历：第一次统计每行每列的黑色像素数，第二次检查是否行列都为1。

## Java 代码实现

```java
class Solution {
    public int findLonelyPixel(char[][] picture) {
        int m = picture.length, n = picture[0].length;
        int[] rowCount = new int[m];
        int[] colCount = new int[n];

        // 第一次遍历：统计每行每列的黑色像素数
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (picture[i][j] == 'B') {
                    rowCount[i]++;
                    colCount[j]++;
                }
            }
        }

        // 第二次遍历：检查孤独像素
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (picture[i][j] == 'B' && rowCount[i] == 1 && colCount[j] == 1) {
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m + n)
