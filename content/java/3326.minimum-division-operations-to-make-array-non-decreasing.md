## 题目描述

给你整数数组 `nums`，每次操作可将某个元素除以其任意大于 1 的因数（取整），返回使数组非递减所需的最少操作次数，无法实现返回 -1。

## 解题思路

贪心从右到左：若 `nums[i] > nums[i+1]`，一次操作能得到的最大合法值是 `nums[i] / 最小质因子`（保留尽量大的值）。若操作后仍 > `nums[i+1]` 则无解。线性筛预处理每个数的最小质因子。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        final int MAX = 1_000_001;
        // 线性筛预处理最小质因子
        int[] spf = new int[MAX];
        for (int i = 0; i < MAX; i++) spf[i] = i;
        for (int i = 2; (long) i * i < MAX; i++) {
            if (spf[i] == i) { // i 是质数
                for (int j = i * i; j < MAX; j += i)
                    if (spf[j] == j) spf[j] = i;
            }
        }

        int n = nums.length, ops = 0;
        // 从右到左贪心
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] <= nums[i + 1]) continue;
            // 除以最小质因子，得到一次操作后的最大值
            nums[i] /= spf[nums[i]];
            if (nums[i] > nums[i + 1]) return -1;
            ops++;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(max_val + n)，筛法预处理 + 一次遍历
- 空间复杂度：O(max_val)，最小质因子数组

## 关键点总结

1. 除以最小质因子得到一次操作能保留的最大值（贪心保留尽量大）
2. 从右到左处理，右边已满足才能确定左边的目标
3. 一次操作后仍不满足则直接返回 -1（不可能再优化）
