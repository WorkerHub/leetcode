## 题目描述

游戏每轮恰好 15 分钟，给你登录时间 `loginTime` 和登出时间 `logoutTime`（格式 "HH:MM"，可能跨午夜），返回完整参与的轮次数。

## 解题思路

将时间转为分钟数，跨午夜则 logout += 1440，登录时间向上取整到 15 的倍数为第一轮开始，登出时间向下取整到 15 的倍数为最后一轮结束，轮次数 = `max(0, (end - start) / 15)`。

## Java 代码实现

```java
class Solution {
    public int numberOfRounds(String loginTime, String logoutTime) {
        int login = toMinutes(loginTime);
        int logout = toMinutes(logoutTime);

        // 跨午夜处理
        if (login > logout) logout += 24 * 60;

        // 第一个可参与的轮次开始时间（向上取整到 15 的倍数）
        int firstStart = (login + 14) / 15 * 15;
        // 最后一个完整轮次的结束时间（向下取整到 15 的倍数）
        int lastEnd = logout / 15 * 15;

        return Math.max(0, (lastEnd - firstStart) / 15);
    }

    private int toMinutes(String t) {
        int h = Integer.parseInt(t.substring(0, 2));
        int m = Integer.parseInt(t.substring(3));
        return h * 60 + m;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 时间统一转换为分钟数，跨午夜加 1440
2. 登录时间向上取整：`(login + 14) / 15 * 15`
3. 登出时间向下取整：`logout / 15 * 15`
