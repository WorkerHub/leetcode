## 题目描述

二叉布尔表达式树，叶子为0/1，内部节点为OR/AND/NOT，求最少翻转叶子次数使根为result。

## 解题思路

树形DP：每个节点返回(使其为false的最小翻转数, 使其为true的最小翻转数)。按节点类型组合子节点代价。

## Java 代码实现

```java
class Solution {
    public int minimumFlips(TreeNode root, boolean result) {
        int[] costs = dfs(root);
        return result ? costs[1] : costs[0];
    }

    // 返回 [使节点为false的代价, 使节点为true的代价]
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int val = node.val;
        // 叶子节点
        if (val == 0) return new int[]{0, 1};
        if (val == 1) return new int[]{1, 0};

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        if (val == 2) { // OR
            int cost0 = left[0] + right[0];
            int cost1 = Math.min(left[1] + right[0], Math.min(left[0] + right[1], left[1] + right[1]));
            return new int[]{cost0, cost1};
        } else if (val == 3) { // AND
            int cost0 = Math.min(left[0] + right[0], Math.min(left[0] + right[1], left[1] + right[0]));
            int cost1 = left[1] + right[1];
            return new int[]{cost0, cost1};
        } else { // NOT，只有右子
            return new int[]{right[1], right[0]};
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(H)，H为树高

## 关键点总结

1. **每个节点两个状态**：为false和为true的最小代价
2. **OR为false需两边都false**：代价相加
3. **NOT只有右子**：交换true/false代价
