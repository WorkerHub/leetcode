## 题目描述

给你一个数学表达式字符串，包含整数、运算符 `+`、`-`、`*`、`/` 和括号，按照标准运算符优先级计算并返回结果（除法向零截断）。

## 解题思路

双栈法：使用操作数栈，遇到括号时递归处理子表达式。按运算符优先级处理：`*` 和 `/` 立即计算（弹出栈顶乘/除当前数后入栈），`+` 和 `-` 将数直接入栈（负数取反），最后对栈求和。

## Java 代码实现

```java
class Solution {
    private String s;
    private int pos;

    public int calculate(String s) {
        this.s = s;
        this.pos = 0;
        return parseExpr();
    }

    // 解析加减表达式
    private int parseExpr() {
        int result = parseTerm();
        while (pos < s.length()) {
            char c = s.charAt(pos);
            if (c == '+' || c == '-') {
                pos++;
                int right = parseTerm();
                result = c == '+' ? result + right : result - right;
            } else {
                break;
            }
        }
        return result;
    }

    // 解析乘除表达式
    private int parseTerm() {
        int result = parseFactor();
        while (pos < s.length()) {
            char c = s.charAt(pos);
            if (c == '*' || c == '/') {
                pos++;
                int right = parseFactor();
                result = c == '*' ? result * right : (int)(result / (double)right); // 向零截断
            } else {
                break;
            }
        }
        return result;
    }

    // 解析因子（数字或括号内表达式）
    private int parseFactor() {
        // 跳过空格
        while (pos < s.length() && s.charAt(pos) == ' ') pos++;
        int result;
        if (s.charAt(pos) == '(') {
            pos++; // 跳过 '('
            result = parseExpr();
            pos++; // 跳过 ')'
        } else {
            // 解析整数
            int start = pos;
            while (pos < s.length() && Character.isDigit(s.charAt(pos))) pos++;
            result = Integer.parseInt(s.substring(start, pos));
        }
        // 跳过尾部空格
        while (pos < s.length() && s.charAt(pos) == ' ') pos++;
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归栈深度

## 关键点总结

1. 递归下降解析器按语法规则分层处理优先级
2. 除法向零截断：负数时需用 `(int)(a / (double)b)` 而非 `a / b`
3. 括号递归调用 `parseExpr`，自然处理嵌套
