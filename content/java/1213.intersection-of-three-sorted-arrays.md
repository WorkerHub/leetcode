## 题目描述

给定三个严格递增的整数数组 arr1、arr2 和 arr3，返回所有三个数组中共有的整数（严格递增）。

**示例：**
```
输入：arr1 = [1,2,3,4,5], arr2 = [1,2,5,7,9], arr3 = [1,3,4,5,8]
输出：[1,5]
```

## 解题思路

利用数组有序的特性，使用三指针同时遍历三个数组。当三指针指向值相等时加入结果，否则移动最小值对应的指针。

## Java 代码实现

### 方法一：三指针（推荐）

```java
class Solution {
    public List<Integer> arraysIntersection(int[] arr1, int[] arr2, int[] arr3) {
        List<Integer> result = new ArrayList<>();
        int i = 0, j = 0, k = 0;
        
        while (i < arr1.length && j < arr2.length && k < arr3.length) {
            if (arr1[i] == arr2[j] && arr2[j] == arr3[k]) {
                // 三者相等，加入结果
                result.add(arr1[i]);
                i++; j++; k++;
            } else {
                // 移动最小值对应的指针
                int minVal = Math.min(arr1[i], Math.min(arr2[j], arr3[k]));
                if (arr1[i] == minVal) i++;
                if (arr2[j] == minVal) j++;
                if (arr3[k] == minVal) k++;
            }
        }
        return result;
    }
}
```

### 方法二：哈希表计数

```java
class Solution {
    public List<Integer> arraysIntersection(int[] arr1, int[] arr2, int[] arr3) {
        List<Integer> result = new ArrayList<>();
        Map<Integer, Integer> count = new HashMap<>();
        
        // 统计每个数字出现在几个数组中
        for (int num : arr1) count.merge(num, 1, Integer::sum);
        for (int num : arr2) count.merge(num, 1, Integer::sum);
        for (int num : arr3) count.merge(num, 1, Integer::sum);
        
        // 出现 3 次的即为交集
        for (int num : arr1) {
            if (count.get(num) == 3) result.add(num);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n1 + n2 + n3)
- **空间复杂度**：O(1)（三指针法）

## 关键点总结

1. **三指针**：利用有序性，每次移动最小值的指针
2. **严格递增**：不需要额外去重
3. **计数法**：出现 3 次即为三数组交集
4. **遍历 arr1 输出**：保证结果有序
