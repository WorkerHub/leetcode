## 题目描述

给你字符串 `blocks`（由 'W' 和 'B' 组成）和整数 `k`，每次操作可将一个白色块涂黑，返回得到至少 k 个连续黑色块所需的最少操作次数。

## 解题思路

滑动窗口：在所有长度为 k 的窗口中，找白色块 'W' 最少的，该窗口内白色块数即为答案。

## Java 代码实现

```java
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int n = blocks.length();
        int white = 0;
        // 初始化第一个窗口
        for (int i = 0; i < k; i++) if (blocks.charAt(i) == 'W') white++;
        int minWhite = white;
        // 滑动窗口
        for (int i = k; i < n; i++) {
            if (blocks.charAt(i) == 'W') white++;
            if (blocks.charAt(i - k) == 'W') white--;
            minWhite = Math.min(minWhite, white);
        }
        return minWhite;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 将问题转化为：在所有长度为 k 的子串中找白色块最少的。
2. 滑动窗口维护当前窗口白色块数，O(1) 更新。
3. 最少操作次数等于窗口内白色块数。
