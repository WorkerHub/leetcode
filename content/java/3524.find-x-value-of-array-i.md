## 题目描述

给定整数数组 `nums` 和正整数 `k`。对每个右端点 `i`，统计有多少子数组 `nums[j..i]`（`j <= i`）的乘积对 `k` 取模等于目标值（此题关注余数为特定值的子数组数）。返回每个位置对应的计数数组。

## 解题思路

对每个右端点 `i`，从 `i` 向左枚举起始点 `j`，维护滚动乘积对 `k` 的余数，统计余数等于目标值的子数组数。一旦乘积中包含 k 的因子（余数变 0），其左侧所有起点也满足（可提前累加并跳出）。

## Java 代码实现

```java
class Solution {
    public long[] findXValue(int[] nums, int k) {
        int n = nums.length;
        long[] result = new long[n];
        for (int i = 0; i < n; i++) {
            long p = 1;
            for (int j = i; j >= 0; j--) {
                p = (p * nums[j]) % k;
                if (p == 0) {
                    // nums[j..i] 及更长（nums[0..i] 等）均余数为 0
                    result[i] += j + 1;
                    break;
                }
                // 若 p == 目标值则 result[i]++（此题统计余数为 0）
                if (p == 0) result[i]++;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 从右端向左滚动乘积，维护当前余数
2. 余数为 0 时，左侧所有起点均满足，可累加 j+1 并提前跳出
3. 乘法取模不能用前缀差代替
