## 题目描述

给你 happiness 数组和整数 k，每次选择一个孩子时所有未选孩子快乐值减 1（最小为 0），选 k 个孩子使选中快乐值总和最大。

## 解题思路

贪心降序选择：第 i 次（0-indexed）选的孩子快乐值为 `max(0, sorted_happiness[i] - i)`，选前 k 个求和。

## Java 代码实现

```java
class Solution {
    public long maximumHappinessSum(int[] happiness, int k) {
        Arrays.sort(happiness);
        long total = 0;
        int n = happiness.length;
        for (int i = 0; i < k; i++) {
            // 第 i 次选择时，该孩子快乐值减少 i
            long val = happiness[n - 1 - i] - (long) i;
            if (val <= 0) break; // 后续值更小，不再增加
            total += val;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 降序排序，每次选最大值（贪心正确性）
2. 第 i 次选择时该孩子快乐值减少 i（前面 i 次选择都跳过了它）
3. 快乐值不能为负，遇到 val <= 0 可提前退出
