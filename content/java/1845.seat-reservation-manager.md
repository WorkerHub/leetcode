## 题目描述

设计座位预约系统：reserve()返回最小可用座位编号，unreserve(seatNumber)释放座位。

## 解题思路

最小堆维护可用座位：reserve弹出堆顶，unreserve将座位加入堆。

## Java 代码实现

```java
class SeatManager {
    private PriorityQueue<Integer> available;

    public SeatManager(int n) {
        available = new PriorityQueue<>();
        for (int i = 1; i <= n; i++) {
            available.offer(i);
        }
    }

    public int reserve() {
        return available.poll();
    }

    public void unreserve(int seatNumber) {
        available.offer(seatNumber);
    }
}
```

## 复杂度分析

- **初始化**：O(N)
- **reserve/unreserve**：O(log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **PriorityQueue**：天然支持最小元素O(log N)提取
2. **简洁设计**：堆自动维护有序性
3. **延迟初始化优化**：可用计数器代替预填充堆
