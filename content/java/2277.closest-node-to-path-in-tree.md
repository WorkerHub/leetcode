## 题目描述

树中查询：找node3到路径node1-node2上任意节点的最短距离对应的路径节点。

## 解题思路

路径n1->n2上与n3最近的节点是LCA(n1,n2)、LCA(n1,n3)、LCA(n2,n3)三者中深度最大的。用倍增LCA实现O(log n)查询。

## Java 代码实现

```java
class Solution {
    private int[][] up;
    private int[] depth;
    private int LOG;

    public int[] closestNode(int n, int[][] edges, int[][] query) {
        LOG = Math.max(1, (int)(Math.ceil(Math.log(n) / Math.log(2))));
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        depth = new int[n];
        up = new int[LOG][n];
        Arrays.fill(depth, -1);
        depth[0] = 0;
        up[0][0] = 0;

        // BFS建树
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph.get(u)) {
                if (depth[v] == -1) {
                    depth[v] = depth[u] + 1;
                    up[0][v] = u;
                    queue.offer(v);
                }
            }
        }
        for (int k = 1; k < LOG; k++)
            for (int v = 0; v < n; v++)
                up[k][v] = up[k - 1][up[k - 1][v]];

        int[] ans = new int[query.length];
        for (int i = 0; i < query.length; i++) {
            int n1 = query[i][0], n2 = query[i][1], n3 = query[i][2];
            int a = lca(n1, n2), b = lca(n1, n3), c = lca(n2, n3);
            // 取深度最大的
            ans[i] = a;
            if (depth[b] > depth[ans[i]]) ans[i] = b;
            if (depth[c] > depth[ans[i]]) ans[i] = c;
        }
        return ans;
    }

    private int lca(int u, int v) {
        if (depth[u] < depth[v]) { int t = u; u = v; v = t; }
        int diff = depth[u] - depth[v];
        for (int k = 0; k < LOG; k++)
            if (((diff >> k) & 1) == 1) u = up[k][u];
        if (u == v) return u;
        for (int k = LOG - 1; k >= 0; k--)
            if (up[k][u] != up[k][v]) { u = up[k][u]; v = up[k][v]; }
        return up[0][u];
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + Q) log N)
- **空间复杂度**：O(N log N)

## 关键点总结

1. **三个LCA取深度最大**：路径上离n3最近的节点
2. **倍增LCA**：O(log N)单次查询
3. **BFS建树**：计算深度和父节点
