## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`，在 `s` 中添加加粗标签 `<b>` 和 `</b>` 来使得 `words` 中的所有字符串在 `s` 中都加粗。

返回添加加粗标签后的字符串。

如果两个加粗的子字符串重叠或相邻，你应该把它们合并成一个加粗的子字符串。

**示例 1:**
```
输入: s = "abcxyz123", words = ["abc","123"]
输出: "<b>abc</b>xyz<b>123</b>"
```

**示例 2:**
```
输入: s = "aaabbcc", words = ["aaa","aab","bc"]
输出: "<b>aaabbc</b>c"
```

**提示:**
- `1 <= s.length <= 1000`
- `0 <= words.length <= 100`
- `1 <= words[i].length <= 1000`
- `s` 和 `words[i]` 仅由小写英文字母组成

**注意：** 此题与 [616. Add Bold Tag in String](https://leetcode.com/problems/add-bold-tag-in-string/) 相同

## 解题思路

这道题需要两个步骤：
1. 标记所有需要加粗的位置
2. 合并相邻和重叠的区间，然后添加标签

**算法流程：**
1. 创建一个布尔数组标记每个字符是否需要加粗
2. 遍历所有 words，标记在 s 中出现的位置
3. 根据标记数组构建结果字符串

## Java 代码实现

### 方法一：标记数组（推荐）

```java
import java.util.List;

class Solution {
    public String boldWords(List<String> words, String s) {
        int n = s.length();
        boolean[] bold = new boolean[n];

        // 标记所有需要加粗的位置
        for (String word : words) {
            int wLen = word.length();
            int start = 0;
            // 查找 word 在 s 中的所有出现位置
            while (true) {
                int pos = s.indexOf(word, start);
                if (pos == -1) break;
                // 标记 [pos, pos + wLen) 范围
                for (int i = pos; i < pos + wLen; i++) {
                    bold[i] = true;
                }
                start = pos + 1;
            }
        }

        // 根据标记构建结果
        StringBuilder result = new StringBuilder();
        int i = 0;
        while (i < n) {
            if (bold[i]) {
                result.append("<b>");
                while (i < n && bold[i]) {
                    result.append(s.charAt(i));
                    i++;
                }
                result.append("</b>");
            } else {
                result.append(s.charAt(i));
                i++;
            }
        }

        return result.toString();
    }
}
```

### 方法二：区间合并

```java
import java.util.*;

class Solution {
    public String boldWords(List<String> words, String s) {
        // 收集所有需要加粗的区间
        List<int[]> intervals = new ArrayList<>();

        for (String word : words) {
            int start = 0;
            while (true) {
                int pos = s.indexOf(word, start);
                if (pos == -1) break;
                intervals.add(new int[]{pos, pos + word.length()});
                start = pos + 1;
            }
        }

        if (intervals.isEmpty()) return s;

        // 合并重叠和相邻的区间
        intervals.sort((a, b) -> a[0] - b[0]);
        List<int[]> merged = new ArrayList<>();
        merged.add(intervals.get(0));

        for (int[] interval : intervals) {
            int[] last = merged.get(merged.size() - 1);
            if (interval[0] <= last[1]) {
                // 重叠或相邻，合并
                last[1] = Math.max(last[1], interval[1]);
            } else {
                merged.add(interval);
            }
        }

        // 构建结果
        StringBuilder result = new StringBuilder();
        int prev = 0;
        for (int[] interval : merged) {
            result.append(s, prev, interval[0]);
            result.append("<b>");
            result.append(s, interval[0], interval[1]);
            result.append("</b>");
            prev = interval[1];
        }
        result.append(s.substring(prev));

        return result.toString();
    }
}
```

## 复杂度分析

**方法一：标记数组**
- **时间复杂度：** O(n * m * k)，其中 n 是 s 的长度，m 是 words 的数量，k 是平均单词长度
- **空间复杂度：** O(n)，标记数组

## 关键点总结

1. **标记法：** 使用布尔数组标记需要加粗的位置
2. **字符串查找：** 使用 `indexOf()` 查找所有出现位置
3. **区间合并：** 相邻和重叠的区间要合并
4. **构建结果：** 根据标记数组构建最终字符串
5. **优化技巧：** 字典树可以优化多模式匹配

## 易错点

1. **重复出现：** 一个单词可能在 s 中多次出现
2. **重叠处理：** 重叠的区间要合并，不能添加多个标签
3. **相邻合并：** 相邻的加粗区间也要合并
4. **索引边界：** 标记数组时注意不要越界
5. **空字符串：** words 可能为空，s 也可能不包含任何 word
