## 题目描述

给你两个字符串 `coordinate1` 和 `coordinate2`，表示国际象棋棋盘上的两个格子（如 "a1"、"h8"）。若两格颜色相同返回 `true`，否则返回 `false`。

## 解题思路

棋盘颜色由 (列号 + 行号) 的奇偶性决定，两格颜色相同当且仅当两格奇偶性相同。

## Java 代码实现

```java
class Solution {
    public boolean checkTwoChessboards(String coordinate1, String coordinate2) {
        // 颜色由 (列号 + 行号) 的奇偶性决定
        int p1 = (coordinate1.charAt(0) - 'a' + coordinate1.charAt(1) - '1') % 2;
        int p2 = (coordinate2.charAt(0) - 'a' + coordinate2.charAt(1) - '1') % 2;
        return p1 == p2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 棋盘颜色由 (列号 + 行号) 的奇偶性决定
2. 两格颜色相同等价于两格奇偶性相同
3. 用 `charAt(0) - 'a'` 和 `charAt(1) - '1'` 将字符转为 0-7 的数字
