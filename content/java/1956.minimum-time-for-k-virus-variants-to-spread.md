## 题目描述

给你 n 个病毒初始坐标和整数 k，病毒以切比雪夫距离扩散，返回恰好 k 种病毒共同覆盖某点的最早时间。

## 解题思路

切比雪夫距离转曼哈顿：`(x,y) → (x+y, x-y)` 后，k 个病毒覆盖区域有公共交点的时间等于 `ceil(max(x'范围, y'范围) / 2)`。枚举所有大小为 k 的子集取最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minDayskVariants(int[][] points, int k) {
        int n = points.length;
        // 切比雪夫转曼哈顿坐标
        int[] tx = new int[n], ty = new int[n];
        for (int i = 0; i < n; i++) {
            tx[i] = points[i][0] + points[i][1];
            ty[i] = points[i][0] - points[i][1];
        }

        int ans = Integer.MAX_VALUE;
        for (int mask = 0; mask < (1 << n); mask++) {
            if (Integer.bitCount(mask) != k) continue;
            int minX = Integer.MAX_VALUE, maxX = Integer.MIN_VALUE;
            int minY = Integer.MAX_VALUE, maxY = Integer.MIN_VALUE;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    minX = Math.min(minX, tx[i]); maxX = Math.max(maxX, tx[i]);
                    minY = Math.min(minY, ty[i]); maxY = Math.max(maxY, ty[i]);
                }
            }
            int range = Math.max(maxX - minX, maxY - minY);
            ans = Math.min(ans, (range + 1) / 2); // 向上取整
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(C(n,k) * k)
- **空间复杂度**：O(n)

## 关键点总结

1. 切比雪夫距离转曼哈顿：`(x+y, x-y)` 后切比雪夫圆变矩形
2. k 个矩形公共区域存在当且仅当 x' 和 y' 方向范围满足条件
3. 最早时间 = `ceil(max(x'范围, y'范围) / 2)`
