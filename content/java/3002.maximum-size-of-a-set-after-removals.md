## 题目描述

给两个长度为 n 的数组，各取至多 n/2 个元素，组成一个尽可能大的集合（无重复），返回集合最大大小。

## 解题思路

贪心：分别计算两数组独有元素和公共元素，各自最多取 n/2 个独有元素，剩余名额再从公共元素补充。

## Java 代码实现

```java
class Solution {
    public int maximumSetSize(int[] nums1, int[] nums2) {
        int n = nums1.length, half = n / 2;
        Set<Integer> s1 = new HashSet<>(), s2 = new HashSet<>();
        for (int x : nums1) s1.add(x);
        for (int x : nums2) s2.add(x);
        // 计算独有元素和公共元素
        Set<Integer> only1 = new HashSet<>(s1), only2 = new HashSet<>(s2), common = new HashSet<>(s1);
        only1.removeAll(s2);
        only2.removeAll(s1);
        common.retainAll(s2);
        int keep1 = Math.min(only1.size(), half);
        int keep2 = Math.min(only2.size(), half);
        int remain1 = half - keep1, remain2 = half - keep2;
        int commonTake = Math.min(common.size(), remain1 + remain2);
        return keep1 + keep2 + commonTake;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 独有元素优先放入，最多各取 n/2 个
2. 剩余名额从公共元素补充
3. 公共元素只算一次（集合无重复）
