## 题目描述

n 位格雷码序列是一个由 `2^n` 个整数组成的序列，其中：
- 每个整数都在范围 `[0, 2^n - 1]` 内（含 0 和 `2^n - 1`）
- 第一个整数是 `0`
- 一个整数在序列中出现不超过一次
- 每对相邻整数的二进制表示恰好一位不同，且
- 第一个和最后一个整数的二进制表示恰好一位不同

给你一个整数 `n`，返回任一有效的 n 位格雷码序列。

**示例 1：**
```
输入：n = 2
输出：[0,1,3,2]
解释：
[0,1,3,2] 的二进制表示是 [00,01,11,10]。
- 00 和 01 有一位不同
- 01 和 11 有一位不同
- 11 和 10 有一位不同
- 10 和 00 有一位不同
[0,2,3,1] 也是一个有效的格雷码序列，其二进制表示是 [00,10,11,01]。
- 00 和 10 有一位不同
- 10 和 11 有一位不同
- 11 和 01 有一位不同
- 01 和 00 有一位不同
```

**示例 2：**
```
输入：n = 1
输出：[0,1]
```

**提示：**
- `1 <= n <= 16`

## 解题思路

格雷码（Gray Code）是一个经典的数学问题，有多种生成方法。

**方法对比：**
1. **公式法（最简单）**：使用 `i ^ (i >> 1)` 公式直接生成
2. **镜像反射法**：利用格雷码的递归特性
3. **回溯法**：通过深度优先搜索生成

### 核心思想 1：公式法

格雷码有一个巧妙的数学性质：第 i 个格雷码可以通过公式 `gray(i) = i ^ (i >> 1)` 得到。

这个公式的含义：
- `i >> 1`：将 i 右移一位（相当于除以 2）
- `i ^ (i >> 1)`：i 与右移后的结果做异或运算

**为什么这个公式有效？**
- 格雷码的定义要求相邻两个数只有一位不同
- 通过这个公式生成的序列自然满足这个性质

### 核心思想 2：镜像反射法

格雷码的递归规律：
- 1 位格雷码：`[0, 1]`
- 2 位格雷码：在 1 位基础上，先保留 `[0, 1]`，再镜像反转后在最高位加 1，得到 `[0, 1, 3, 2]`
- 3 位格雷码：在 2 位基础上，先保留 `[0, 1, 3, 2]`，再镜像反转后在最高位加 1，得到 `[0, 1, 3, 2, 6, 7, 5, 4]`

规律：`n` 位格雷码 = `(n-1)` 位格雷码 + 镜像反转的 `(n-1)` 位格雷码（每个数加上 `2^(n-1)`）

## Java 代码实现

### 方法一：公式法（推荐）

```java
class Solution {
    public List<Integer> grayCode(int n) {
        // 使用格雷码公式：gray(i) = i ^ (i >> 1)
        List<Integer> result = new ArrayList<>();
        // 生成 2^n 个数
        for (int i = 0; i < (1 << n); i++) {
            // 格雷码公式
            result.add(i ^ (i >> 1));
        }
        return result;
    }
}
```

### 方法二：镜像反射法

```java
class Solution {
    public List<Integer> grayCode(int n) {
        // 初始：1 位格雷码
        List<Integer> result = new ArrayList<>();
        result.add(0);
        result.add(1);

        // 从 2 位开始，逐步构建到 n 位
        for (int i = 2; i <= n; i++) {
            // 当前需要在最高位加的值
            int highBit = 1 << (i - 1); // 2^(i-1)

            // 镜像：将现有结果反转，并在每个数前加上最高位
            int size = result.size();
            for (int j = size - 1; j >= 0; j--) {
                result.add(result.get(j) + highBit);
            }
        }

        return result;
    }
}
```

### 方法三：位运算优化版镜像法

```java
class Solution {
    public List<Integer> grayCode(int n) {
        // 位运算优化的镜像法
        List<Integer> result = new ArrayList<>();
        result.add(0);

        for (int i = 0; i < n; i++) {
            // 在第 i 位加 1
            int add = 1 << i;
            // 将现有结果反转后加上 add
            int size = result.size();
            for (int j = size - 1; j >= 0; j--) {
                result.add(result.get(j) + add);
            }
        }

        return result;
    }
}
```

### 方法四：回溯法（理解用）

```java
class Solution {
    private List<Integer> result = new ArrayList<>();
    private int n;

    public List<Integer> grayCode(int n) {
        this.n = n;
        result.add(0);
        Set<Integer> visited = new HashSet<>();
        visited.add(0);
        backtrack(0, visited);
        return result;
    }

    private boolean backtrack(int num, Set<Integer> visited) {
        if (result.size() == (1 << n)) {
            return true;
        }

        // 尝试改变每一位
        for (int i = 0; i < n; i++) {
            // 翻转第 i 位
            int nextNum = num ^ (1 << i);

            if (!visited.contains(nextNum)) {
                visited.add(nextNum);
                result.add(nextNum);

                if (backtrack(nextNum, visited)) {
                    return true;
                }

                // 回溯
                visited.remove(nextNum);
                result.remove(result.size() - 1);
            }
        }

        return false;
    }
}
```

## 复杂度分析

**方法一：公式法**
- 时间复杂度：O(2^n)，需要生成 2^n 个数
- 空间复杂度：O(1)，不考虑返回结果的空间

**方法二：镜像反射法**
- 时间复杂度：O(2^n)，每次迭代数组长度翻倍
- 空间复杂度：O(1)，不考虑返回结果的空间

**方法三：回溯法**
- 时间复杂度：O(n × 2^n)，最坏情况下需要尝试多次
- 空间复杂度：O(2^n)，需要 visited 集合

## 图解示例

以 n = 3 为例，使用镜像反射法：

```
n = 1: [0, 1]
       二进制：[0, 1]

n = 2: 
  原序列：[0, 1]
  镜像并加 2^1 = 2：[3, 2]
  合并：[0, 1, 3, 2]
  二进制：[00, 01, 11, 10]

n = 3:
  原序列：[0, 1, 3, 2]
  镜像并加 2^2 = 4：[6, 7, 5, 4]
  合并：[0, 1, 3, 2, 6, 7, 5, 4]
  二进制：[000, 001, 011, 010, 110, 111, 101, 100]
  
验证相邻数只差一位：
000 -> 001 (第 0 位不同)
001 -> 011 (第 1 位不同)
011 -> 010 (第 0 位不同)
010 -> 110 (第 2 位不同)
110 -> 111 (第 0 位不同)
111 -> 101 (第 1 位不同)
101 -> 100 (第 0 位不同)
```

使用公式法 `i ^ (i >> 1)`：

```
i = 0: 0 ^ (0 >> 1) = 0 ^ 0 = 0 (000)
i = 1: 1 ^ (1 >> 1) = 1 ^ 0 = 1 (001)
i = 2: 2 ^ (2 >> 1) = 2 ^ 1 = 3 (011)
i = 3: 3 ^ (3 >> 1) = 3 ^ 1 = 2 (010)
i = 4: 4 ^ (4 >> 1) = 4 ^ 2 = 6 (110)
i = 5: 5 ^ (5 >> 1) = 5 ^ 2 = 7 (111)
i = 6: 6 ^ (6 >> 1) = 6 ^ 3 = 5 (101)
i = 7: 7 ^ (7 >> 1) = 7 ^ 3 = 4 (100)

结果：[0, 1, 3, 2, 6, 7, 5, 4]
```

## 关键点总结

1. **公式法最简洁**：`gray(i) = i ^ (i >> 1)` 是最简单的实现方式
2. **镜像特性**：格雷码具有递归的镜像对称性质
3. **位运算技巧**：
   - `1 << n` 相当于 `2^n`
   - `i >> 1` 相当于 `i / 2`
   - `i ^ (1 << j)` 翻转第 j 位
4. **相邻性质**：任意相邻两个格雷码只有一位不同

## 易错点

1. **公式理解错误**：
   - 错误：以为格雷码就是 0 到 2^n-1 的自然序列
   - 正确：格雷码需要保证相邻数只有一位不同

2. **镜像法实现错误**：
   - 错误：直接反转数组而不是从后向前遍历
   - 正确：从后向前遍历等同于镜像效果

3. **位运算符优先级**：
   - 错误：`1 << i - 1`（会先算 i - 1）
   - 正确：`1 << (i - 1)`

4. **循环次数错误**：
   - 镜像法中循环应该从 2 开始到 n，而不是到 n-1

5. **Java 中 List 的使用**：回溯法中用 `result.remove(result.size() - 1)` 删除最后一个元素
