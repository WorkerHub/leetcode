## 题目描述

给你二维数组 `items`（每项含 profit 和 category）及整数 `k`，从中选 k 项使"总利润 + 不同类别数²"最大，返回最大优雅度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long findMaximumElegance(int[][] items, int k) {
        // 按利润降序排序
        Arrays.sort(items, (a, b) -> b[0] - a[0]);

        long totalProfit = 0;
        Set<Integer> categories = new HashSet<>();
        // 存储已选且类别重复的 item 利润（可被替换）
        PriorityQueue<Integer> dupHeap = new PriorityQueue<>(); // 最小堆

        // 先选利润最高的 k 个
        for (int i = 0; i < k; i++) {
            totalProfit += items[i][0];
            if (!categories.add(items[i][1])) {
                // 类别重复，加入可替换堆
                dupHeap.offer(items[i][0]);
            }
        }
        long best = totalProfit + (long) categories.size() * categories.size();

        // 考虑剩余 item：若引入新类别且有可替换的重复 item
        for (int i = k; i < items.length; i++) {
            int profit = items[i][0], cat = items[i][1];
            if (categories.contains(cat) || dupHeap.isEmpty()) continue;
            // 换出利润最小的重复类别 item，换入新类别
            totalProfit += profit - dupHeap.poll();
            categories.add(cat);
            best = Math.max(best, totalProfit + (long) categories.size() * categories.size());
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先选利润最高的 k 个，用最小堆维护重复类别 item 的利润
2. 对后续 item，若引入新类别且堆非空，则用新 item 替换堆中利润最小的重复类别 item
3. 只有引入新类别才有可能增加 distinct^2，已有类别的 item（利润更低）直接跳过
