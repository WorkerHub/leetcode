## 题目描述

请你实现一个类 `SubrectangleQueries`，它的构造函数的参数是一个 `rows x cols` 的矩形（这里用整数矩阵表示），并支持以下两种操作：

**1. `updateSubrectangle(int row1, int col1, int row2, int col2, int newValue)`**

用 `newValue` 更新以 `(row1, col1)` 为左上角、`(row2, col2)` 为右下角的子矩形中的所有值。

**2. `getValue(int row, int col)`**

返回矩形中坐标 `(row, col)` 的当前值。

**示例：**

```
输入：
["SubrectangleQueries","getValue","updateSubrectangle","getValue","getValue","updateSubrectangle","getValue","getValue"]
[[[1,2,1],[4,3,4],[3,2,1],[1,1,1]],[0,2],[0,0,3,2,5],[0,2],[3,1],[1,1,2,1,10],[1,1],[2,1]]
输出：
[null,1,null,5,5,null,10,5]
```

**提示：**
- `rows, cols <= 100`
- `0 <= row1 <= row2 < rows`
- `0 <= col1 <= col2 < cols`
- `1 <= newValue, rectangle[i][j] <= 10^9`
- 最多调用 `500` 次 `updateSubrectangle` 和 `getValue`

## 解题思路

**方法一：直接更新矩阵**
- `updateSubrectangle`：遍历子矩形内所有位置并更新值。
- `getValue`：直接返回矩阵对应位置的值。
- 简单直接，更新 O((r2-r1+1)*(c2-c1+1))，查询 O(1)。

**方法二：记录更新操作，查询时逆序查找**
- 不直接修改矩阵，而是记录每次更新操作（row1, col1, row2, col2, newValue）。
- `getValue(row, col)`：逆序遍历所有更新操作，找到第一个覆盖该点的更新，返回其值；若无则返回初始矩阵的值。
- 适合更新频繁、查询少的场景：更新 O(1)，查询 O(次数)。

## Java 代码实现

### 方法一：直接原地更新（推荐，简单直观）

```java
class SubrectangleQueries {
    private int[][] matrix;

    public SubrectangleQueries(int[][] rectangle) {
        this.matrix = rectangle;  // 直接引用矩阵
    }

    public void updateSubrectangle(int row1, int col1, int row2, int col2, int newValue) {
        // 遍历子矩形，更新所有位置
        for (int r = row1; r <= row2; r++) {
            for (int c = col1; c <= col2; c++) {
                matrix[r][c] = newValue;
            }
        }
    }

    public int getValue(int row, int col) {
        // 直接返回当前值
        return matrix[row][col];
    }
}
```

### 方法二：惰性更新（记录操作，查询时逆序查找）

```java
import java.util.ArrayList;
import java.util.List;

class SubrectangleQueries {
    private int[][] matrix;
    private List<int[]> updates;  // 记录所有更新操作 [row1, col1, row2, col2, newValue]

    public SubrectangleQueries(int[][] rectangle) {
        this.matrix = rectangle;
        this.updates = new ArrayList<>();
    }

    public void updateSubrectangle(int row1, int col1, int row2, int col2, int newValue) {
        // 记录操作，不立即修改矩阵
        updates.add(new int[]{row1, col1, row2, col2, newValue});
    }

    public int getValue(int row, int col) {
        // 逆序查找最近一次覆盖 (row, col) 的更新
        for (int i = updates.size() - 1; i >= 0; i--) {
            int[] op = updates.get(i);
            if (op[0] <= row && row <= op[2] && op[1] <= col && col <= op[3]) {
                return op[4];  // 找到最近的覆盖，返回新值
            }
        }

        // 没有更新操作覆盖该点，返回初始值
        return matrix[row][col];
    }
}
```

## 复杂度分析

| 方法 | updateSubrectangle | getValue | 空间 |
|------|-------------------|----------|------|
| 直接更新 | O(rows * cols) | O(1) | O(rows * cols) |
| 惰性更新 | O(1) | O(更新次数) | O(更新次数) |

- 方法一适合查询频繁、更新少的场景。
- 方法二适合更新频繁、查询少的场景。
- 本题数据范围较小（rows, cols <= 100，操作 <= 500），两种方法都可通过。

## 关键点总结

1. 两种设计权衡：**立即更新**（查询快）vs **惰性更新**（更新快）。
2. 惰性更新的关键是**逆序**查找更新记录，因为最新的更新优先级最高。
3. 对于点 `(row, col)` 是否在子矩形内的判断：`r1 <= row <= r2 && c1 <= col <= c2`。

## 易错点

- **下标包含边界**：子矩形从 `(row1, col1)` 到 `(row2, col2)` 均包含，循环要用 `<= row2`。
- **惰性更新要逆序**：`for (int i = updates.size() - 1; i >= 0; i--)` 保证找到的是最近的更新操作。
