## 题目描述

给你仅含大写字母的字符串 `s`，重复删除子串 "AB" 或 "CD"，返回最终字符串的最小长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minLength(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (!stack.isEmpty() &&
                ((stack.peek() == 'A' && c == 'B') || (stack.peek() == 'C' && c == 'D'))) {
                stack.pop(); // 删除 AB 或 CD
            } else {
                stack.push(c);
            }
        }
        return stack.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 栈模拟：遇到 B 且栈顶为 A，或遇到 D 且栈顶为 C，则弹出
2. 删除后产生新配对的情况由栈自动处理
