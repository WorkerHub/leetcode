## 题目描述

给你 `m x n` 棋盘和骑士的起始位置 `(r, c)`，找到骑士哈密顿回路，返回每个格子被访问的步数（0-indexed），不存在则返回空数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int[][] MOVES = {{-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}};
    private int m, n;
    private int[][] grid;

    public int[][] tourOfKnight(int m, int n, int r, int c) {
        this.m = m;
        this.n = n;
        grid = new int[m][n];
        for (int[] row : grid) Arrays.fill(row, -1);
        backtrack(r, c, 0);
        return grid;
    }

    private boolean backtrack(int x, int y, int step) {
        grid[x][y] = step;
        if (step == m * n - 1) return true;

        // Warnsdorff 启发：优先选择下一步可选格最少的方向
        int[][] nexts = new int[8][3];
        int cnt = 0;
        for (int[] move : MOVES) {
            int nx = x + move[0], ny = y + move[1];
            if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == -1) {
                nexts[cnt++] = new int[]{countMoves(nx, ny), nx, ny};
            }
        }
        Arrays.sort(nexts, 0, cnt, (a, b) -> a[0] - b[0]);

        for (int i = 0; i < cnt; i++) {
            if (backtrack(nexts[i][1], nexts[i][2], step + 1)) return true;
        }
        grid[x][y] = -1; // 回溯
        return false;
    }

    private int countMoves(int x, int y) {
        int cnt = 0;
        for (int[] move : MOVES) {
            int nx = x + move[0], ny = y + move[1];
            if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == -1) cnt++;
        }
        return cnt;
    }
}
```

## 复杂度分析

- 实践中借助 Warnsdorff 启发接近 O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 马的 8 种 L 形移动
2. Warnsdorff 启发：优先选择下一步可选格最少的方向，大幅减少回溯
3. 回溯时恢复 grid 状态
