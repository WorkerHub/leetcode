## 题目描述

给定两个字符串 `word1`、`word2` 和约束列表 `constraints`，每个约束禁止对特定位置使用特定操作（0=插入，1=删除，2=替换）。在满足约束的条件下，求最小编辑距离；若无法完成转换返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minEditDistance(String word1, String word2, int[][] constraints) {
        int m = word1.length(), n = word2.length();
        final int INF = Integer.MAX_VALUE / 2;

        // 预处理约束为集合
        Set<String> forbidden = new HashSet<>();
        for (int[] c : constraints) {
            forbidden.add(c[0] + "," + c[1] + "," + c[2]);
        }

        // dp[i][j]: word1[0..i-1] -> word2[0..j-1] 的最小操作数
        int[][] dp = new int[m + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = 0;

        // 初始化第一行（全删除）
        for (int i = 1; i <= m; i++) {
            if (!forbidden.contains("1," + (i - 1) + ",0") && dp[i - 1][0] != INF)
                dp[i][0] = dp[i - 1][0] + 1;
        }
        // 初始化第一列（全插入）
        for (int j = 1; j <= n; j++) {
            if (!forbidden.contains("0,0," + (j - 1)) && dp[0][j - 1] != INF)
                dp[0][j] = dp[0][j - 1] + 1;
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 字符相同，无需操作
                if (word1.charAt(i - 1) == word2.charAt(j - 1) && dp[i - 1][j - 1] != INF)
                    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j - 1]);
                // 删除 word1[i-1]
                if (!forbidden.contains("1," + (i - 1) + "," + (j - 1)) && dp[i - 1][j] != INF)
                    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j] + 1);
                // 插入 word2[j-1]
                if (!forbidden.contains("0," + (i - 1) + "," + (j - 1)) && dp[i][j - 1] != INF)
                    dp[i][j] = Math.min(dp[i][j], dp[i][j - 1] + 1);
                // 替换
                if (word1.charAt(i - 1) != word2.charAt(j - 1) &&
                    !forbidden.contains("2," + (i - 1) + "," + (j - 1)) && dp[i - 1][j - 1] != INF)
                    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j - 1] + 1);
            }
        }

        return dp[m][n] == INF ? -1 : dp[m][n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 带约束的编辑距离：在每次转移前检查该操作是否被禁止
2. 约束预处理为 Set，查询 O(1)
3. 无法到达的状态用 INF 标记，最终若 `dp[m][n] == INF` 则返回 -1
