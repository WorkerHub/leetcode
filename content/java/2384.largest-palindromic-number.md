## 题目描述

给你数字字符串 `num`，从中选取子集重新排列成最大的回文数字（不含前导零，除非结果为 "0"）。

## 解题思路

统计各数字出现次数，从大到小贪心选取成对数字构建前半部分，再从出现奇数次的数字中选最大的放中间，拼接得到完整回文串，去除前导零后处理边界情况。

## Java 代码实现

```java
class Solution {
    public String largestPalindromic(String num) {
        int[] cnt = new int[10];
        for (char c : num.toCharArray()) cnt[c - '0']++;

        StringBuilder half = new StringBuilder();
        char middle = 0;
        // 从大到小构建前半部分
        for (int d = 9; d >= 0; d--) {
            int pairs = cnt[d] / 2;
            for (int i = 0; i < pairs; i++) half.append((char) ('0' + d));
            // 记录最大的可放中间的数字
            if (cnt[d] % 2 == 1 && middle == 0) middle = (char) ('0' + d);
        }

        // 去除前导零
        int start = 0;
        while (start < half.length() - 1 && half.charAt(start) == '0') start++;
        String h = half.substring(start);

        if (h.isEmpty()) {
            // 前半部分全为 0 或空：结果只有中间位或 "0"
            return middle != 0 ? String.valueOf(middle) : "0";
        }
        String rev = new StringBuilder(h).reverse().toString();
        return h + (middle != 0 ? middle : "") + rev;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（10 种数字）

## 关键点总结

1. 从大（9）到小（0）贪心选成对数字构建前半部分，保证最大值。
2. 中间位选最大的出现奇数次的数字。
3. 前导零处理：去零后若前半为空，结果只有中间位（或 "0"）。
