## 题目描述

给你 n 个元素，可以调用 API `haveSameCategory(a, b)` 查询两个元素是否同类，在最多 4n 次查询内求不同类别数。

## Java 代码实现

```java
/**
 * interface CategoryHandler {
 *     boolean haveSameCategory(int a, int b);
 * }
 */
class Solution {
    int[] parent;

    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    void union(int x, int y) {
        parent[find(x)] = find(y);
    }

    public int numberOfCategories(int n, CategoryHandler handler) {
        parent = new int[n + 1];
        for (int i = 0; i <= n; i++) parent[i] = i;

        // 维护各类别的代表元素列表
        java.util.List<Integer> reps = new java.util.ArrayList<>();
        reps.add(1);

        for (int i = 2; i <= n; i++) {
            boolean found = false;
            for (int rep : reps) {
                if (handler.haveSameCategory(i, rep)) {
                    union(i, rep);
                    found = true;
                    break;
                }
            }
            if (!found) reps.add(i);
        }
        return reps.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，k 为类别数
- 查询次数：题目保证不超过 4n 次

## 关键点总结

1. 维护已知类别的代表元素，每个新元素依次与各代表比较
2. 找到同类则合并入并查集，否则作为新代表
3. 最终代表列表长度即为类别数
