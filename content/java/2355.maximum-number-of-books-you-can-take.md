## 题目描述

给你书架数组 `books`，从连续书架区间 `[l, r]` 取书，每个书架取的书数必须严格递增且不超过该书架实际书数，返回最多能取的书数。

## 解题思路

单调栈 + DP：`dp[i]` 为以书架 i 为右端点的最大取书数。以 i 为右端点的最优取法是从右往左形成公差为 1 的递减序列。单调栈维护有效左边界：若栈顶 `books[j] >= books[i]-(i-j)`，则 j 不是新的限制，弹出栈；否则 j 是限制，从 j+1 开始的段可用等差公式计算，再加上 `dp[j]`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumBooks(int[] books) {
        int n = books.length;
        long[] dp = new long[n];
        Deque<Integer> stack = new ArrayDeque<>();
        long ans = 0;

        for (int i = 0; i < n; i++) {
            // 弹出不满足条件的栈顶：books[j] >= books[i] - (i-j) 时弹出
            while (!stack.isEmpty() && books[stack.peek()] >= books[i] - (i - stack.peek())) {
                stack.pop();
            }
            int l = stack.isEmpty() ? 0 : stack.peek() + 1;
            dp[i] = (stack.isEmpty() ? 0 : dp[stack.isEmpty() ? 0 : stack.peek()]) + calc(books, l, i);
            if (!stack.isEmpty()) dp[i] = dp[stack.peek()] + calc(books, stack.peek() + 1, i);
            else dp[i] = calc(books, 0, i);
            ans = Math.max(ans, dp[i]);
            stack.push(i);
        }
        return ans;
    }

    // 计算从 l 到 r 以 books[r] 为最大的严格递增等差序列总和
    private long calc(int[] books, int l, int r) {
        long len = r - l + 1;
        long hi = books[r];
        long lo = hi - len + 1; // 序列首项
        if (lo <= 0) {
            // books[r] 不够形成长为 len 的序列，实际长度为 books[r]
            lo = 1;
            len = hi;
        }
        return (lo + hi) * len / 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 以 i 为右端点，形成最长严格递增序列（公差为 1，从右往左），用等差公式求和。
2. 单调栈保证每个元素入出栈各一次，整体 O(n)。
3. 当 `books[r]` 小于区间长度时，实际可形成的序列长度为 `books[r]`，首项为 1。
