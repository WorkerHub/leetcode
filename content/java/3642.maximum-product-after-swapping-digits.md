## 题目描述

给定两个非负整数 `num1` 和 `num2`，最多交换一次 `num1` 的某位数字和 `num2` 的某位数字，返回 `num1 * num2` 的最大值。

## Java 代码实现

```java
class Solution {
    public long maxProduct(int num1, int num2) {
        char[] s1 = String.valueOf(num1).toCharArray();
        char[] s2 = String.valueOf(num2).toCharArray();
        long ans = (long) num1 * num2;  // 不交换的情况

        for (int i = 0; i < s1.length; i++) {
            for (int j = 0; j < s2.length; j++) {
                // 交换 s1[i] 和 s2[j]
                char tmp = s1[i]; s1[i] = s2[j]; s2[j] = tmp;
                long product = Long.parseLong(new String(s1)) * Long.parseLong(new String(s2));
                ans = Math.max(ans, product);
                // 恢复
                tmp = s1[i]; s1[i] = s2[j]; s2[j] = tmp;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(d1 * d2 * (d1 + d2))，位数最多 10，共约 2000 次操作
- 空间复杂度：O(d1 + d2)

## 关键点总结

1. 枚举所有可能的交换位置，最多 10 * 10 = 100 种
2. 初始化答案为不交换的乘积（0 次操作也合法）
3. 使用 `long` 防止乘积溢出
