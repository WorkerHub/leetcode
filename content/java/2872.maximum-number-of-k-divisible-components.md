## 题目描述

给你一棵 n 个节点的无向树和节点值数组 values 及整数 k（总和能被 k 整除），每次可删除一条边，返回能使每个连通分量值之和都能被 k 整除的最多分量数。

## 解题思路

树形 DP：DFS 计算每个子树的值之和 mod k，若等于 0 则分割出去（计数+1），分割后向父节点贡献 0；因为总和能被 k 整除，剩余部分必然也满足条件。

## Java 代码实现

```java
class Solution {
    private List<Integer>[] graph;
    private long[] values;
    private int k, ans = 0;

    public int maxKDivisibleComponents(int n, int[][] edges, int[] vals, int k) {
        this.k = k;
        this.values = new long[n];
        for (int i = 0; i < n; i++) values[i] = vals[i] % k;

        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        dfs(0, -1);
        return ans;
    }

    private long dfs(int node, int parent) {
        long subtreeSum = values[node];
        for (int nei : graph[node]) {
            if (nei != parent) {
                subtreeSum = (subtreeSum + dfs(nei, node)) % k;
            }
        }
        if (subtreeSum % k == 0) {
            ans++;       // 这个子树可以分割为独立分量
            return 0;    // 分割后对父节点贡献为 0
        }
        return subtreeSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 子树和 mod k == 0 时可以分割，分割后向父贡献 0
2. 因总和能被 k 整除，切割操作不会破坏剩余部分的整除性
3. 对子树和取 mod k 防止溢出
