## 题目描述

删除所有相邻的同字母不同大小写字符对，返回最终的好字符串。

**示例：**
```
输入：s = "leEeetcode"
输出："leetcode"
```

## 解题思路

栈：若当前字符与栈顶同字母但不同大小写则弹出栈顶，否则入栈。

## Java 代码实现

```java
class Solution {
    public String makeGood(String s) {
        StringBuilder stack = new StringBuilder();
        for (char c : s.toCharArray()) {
            int len = stack.length();
            if (len > 0 && stack.charAt(len - 1) != c
                    && Character.toLowerCase(stack.charAt(len - 1)) == Character.toLowerCase(c)) {
                // 同字母不同大小写，消除
                stack.deleteCharAt(len - 1);
            } else {
                stack.append(c);
            }
        }
        return stack.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈模拟**：一次遍历即可
2. **判断条件**：字符不相等但小写相等
3. **StringBuilder 当栈**：效率更高
