## 题目描述

矩形以 [x1, y1, x2, y2] 表示（左下角和右上角），判断两个矩形是否重叠（面积为正）。

**示例：**
```
输入：rec1 = [0,0,2,2], rec2 = [1,1,3,3]
输出：true
```

## 解题思路

逆向思维：判断不重叠（一个在另一个的左/右/上/下），取反即为重叠。

## Java 代码实现

```java
class Solution {
    public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
        // 不重叠的四种情况取反
        return !(rec1[2] <= rec2[0] ||  // rec1 在左
                 rec1[0] >= rec2[2] ||  // rec1 在右
                 rec1[3] <= rec2[1] ||  // rec1 在下
                 rec1[1] >= rec2[3]);   // rec1 在上
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向思维**：判断不重叠更简单
2. **边界不算**：<= 表示仅边相切不重叠
3. **四种不重叠**：左右上下四个方向
