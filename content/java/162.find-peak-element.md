## 题目描述

峰值元素是指其值严格大于左右相邻值的元素。

给你一个整数数组 `nums`，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回任何一个峰值所在位置即可。

你可以假设 `nums[-1] = nums[n] = -∞`。换句话说，数组两端可以看作是负无穷大。

你必须实现时间复杂度为 `O(log n)` 的算法来解决此问题。

**示例 1：**
```
输入：nums = [1,2,3,1]
输出：2
解释：3 是峰值元素，你的函数应该返回其索引 2。
```

**示例 2：**
```
输入：nums = [1,2,1,3,5,6,4]
输出：5
解释：你的函数可以返回索引 1，其峰值元素为 2；
     或者返回索引 5，其峰值元素为 6。
```

**提示：**
- 1 <= nums.length <= 1000
- -2^31 <= nums[i] <= 2^31 - 1
- 对于所有有效的 i，都有 nums[i] != nums[i + 1]

## 解题思路

这道题要求 O(log n) 时间复杂度，提示使用二分查找。

### 思路一：线性扫描（不满足时间要求）

最简单的方法是遍历数组，找到第一个满足 `nums[i] > nums[i-1] && nums[i] > nums[i+1]` 的元素。时间复杂度 O(n)。

### 思路二：二分查找（推荐）⭐

**关键观察：**

1. 数组两端视为负无穷，所以必然存在峰值
2. 对于任意位置 mid：
   - 如果 `nums[mid] < nums[mid + 1]`，说明右侧存在上坡，右侧必然有峰值
   - 如果 `nums[mid] > nums[mid + 1]`，说明左侧存在上坡（或 mid 就是峰值），左侧必然有峰值

**算法流程：**

1. 初始化左右边界：left = 0, right = nums.length - 1
2. 循环条件：left < right
3. 计算中点：mid = (left + right) / 2
4. 比较 nums[mid] 和 nums[mid + 1]：
   - 如果 nums[mid] < nums[mid + 1]：峰值在右侧，left = mid + 1
   - 如果 nums[mid] > nums[mid + 1]：峰值在左侧（包括 mid），right = mid
5. 最终 left == right，即为峰值位置

**为什么一定有峰值？**
- 如果一直上升，最后一个元素就是峰值（右侧是 -∞）
- 如果一直下降，第一个元素就是峰值（左侧是 -∞）
- 中间必然有转折点，转折点就是峰值

## Java 代码实现

### 方法一：二分查找（推荐）⭐

```java
class Solution {
    public int findPeakElement(int[] nums) {
        int left = 0, right = nums.length - 1;

        while (left < right) {
            int mid = (left + right) / 2;

            // 比较 mid 和 mid+1
            if (nums[mid] < nums[mid + 1]) {
                // 右侧有上升趋势，峰值在右侧
                left = mid + 1;
            } else {
                // 左侧有上升趋势或 mid 就是峰值，峰值在左侧（包括 mid）
                right = mid;
            }
        }

        // left == right，找到峰值
        return left;
    }
}
```

### 方法二：二分查找（比较两侧）

```java
class Solution {
    public int findPeakElement(int[] nums) {
        int n = nums.length;

        // 特殊情况：只有一个元素
        if (n == 1) {
            return 0;
        }

        int left = 0, right = n - 1;

        while (left <= right) {
            int mid = (left + right) / 2;

            // 获取左右邻居的值（边界处理）
            long leftVal = (mid > 0) ? nums[mid - 1] : Long.MIN_VALUE;
            long rightVal = (mid < n - 1) ? nums[mid + 1] : Long.MIN_VALUE;

            // mid 是峰值
            if (nums[mid] > leftVal && nums[mid] > rightVal) {
                return mid;
            }

            // 右侧更大，峰值在右侧
            if (nums[mid] < rightVal) {
                left = mid + 1;
            } else {
                // 左侧更大，峰值在左侧
                right = mid - 1;
            }
        }

        return left;
    }
}
```

### 方法三：线性扫描（不推荐，不满足时间要求）

```java
class Solution {
    public int findPeakElement(int[] nums) {
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            // 获取左右邻居
            long leftVal = (i > 0) ? nums[i - 1] : Long.MIN_VALUE;
            long rightVal = (i < n - 1) ? nums[i + 1] : Long.MIN_VALUE;

            // 找到峰值
            if (nums[i] > leftVal && nums[i] > rightVal) {
                return i;
            }
        }

        // 理论上不会到这里
        return -1;
    }
}
```

### 方法四：递归二分查找

```java
class Solution {
    public int findPeakElement(int[] nums) {
        return binarySearch(nums, 0, nums.length - 1);
    }

    private int binarySearch(int[] nums, int left, int right) {
        if (left == right) {
            return left;
        }

        int mid = (left + right) / 2;

        if (nums[mid] < nums[mid + 1]) {
            return binarySearch(nums, mid + 1, right);
        } else {
            return binarySearch(nums, left, mid);
        }
    }
}
```

## 复杂度分析

**方法一（二分查找）：**
- 时间复杂度：O(log n)，每次将搜索空间减半
- 空间复杂度：O(1)，只使用常数额外空间

**方法三（线性扫描）：**
- 时间复杂度：O(n)，需要遍历整个数组
- 空间复杂度：O(1)

**方法四（递归）：**
- 时间复杂度：O(log n)
- 空间复杂度：O(log n)，递归调用栈

## 关键点总结

1. **二分查找条件**：比较 mid 和 mid+1，决定搜索方向
2. **边界处理**：数组两端视为负无穷，保证必有峰值
3. **终止条件**：left == right 时找到峰值
4. **任意峰值**：题目允许返回任意峰值，所以二分查找可行
5. **不需要比较所有元素**：利用上升/下降趋势确定峰值所在区域

## 易错点

1. **mid+1 越界**：需要确保 left < right，这样 mid < right，mid+1 不会越界
2. **无限循环**：更新 left 和 right 时要保证搜索空间缩小
   - 正确：left = mid + 1, right = mid
   - 错误：left = mid, right = mid（可能死循环）
3. **返回值**：返回索引，不是峰值本身
4. **边界比较**：方法二中使用 `long` 类型来表示负无穷，避免与 `int` 最小值混淆
5. **理解题意**：可以返回任意峰值，不需要找到最大值
