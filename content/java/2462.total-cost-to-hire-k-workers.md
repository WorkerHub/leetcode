## 题目描述

给你代价数组 `costs`、整数 `k` 和 `candidates`，每轮从最前/最后各 `candidates` 个工人中选代价最小者（相同时下标小），共选 `k` 轮，返回总代价。

## 解题思路

双堆 + 双指针：左堆维护前 `candidates` 个候选，右堆维护后 `candidates` 个候选，用 `(cost, index)` 实现代价相同时选下标小者。每次取两堆最小值，弹出后从相应端补充新候选。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long totalCost(int[] costs, int k, int candidates) {
        int n = costs.length;
        int l = 0, r = n - 1;
        PriorityQueue<long[]> leftHeap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]));
        PriorityQueue<long[]> rightHeap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]));

        // 初始化左堆
        for (int i = 0; i < candidates && l <= r; i++, l++) {
            leftHeap.offer(new long[]{costs[l], l});
        }
        // 初始化右堆（不与左堆重叠）
        for (int i = 0; i < candidates && l <= r; i++, r--) {
            rightHeap.offer(new long[]{costs[r], r});
        }

        long total = 0;
        for (int i = 0; i < k; i++) {
            long[] lTop = leftHeap.isEmpty() ? new long[]{Long.MAX_VALUE, Long.MAX_VALUE} : leftHeap.peek();
            long[] rTop = rightHeap.isEmpty() ? new long[]{Long.MAX_VALUE, Long.MAX_VALUE} : rightHeap.peek();

            if (lTop[0] <= rTop[0] || (lTop[0] == rTop[0] && lTop[1] <= rTop[1])) {
                total += leftHeap.poll()[0];
                if (l <= r) { leftHeap.offer(new long[]{costs[l], l}); l++; }
            } else {
                total += rightHeap.poll()[0];
                if (l <= r) { rightHeap.offer(new long[]{costs[r], r}); r--; }
            }
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((k + candidates) × log(candidates))
- **空间复杂度**：O(candidates)

## 关键点总结

1. 左右两个最小堆各维护 `candidates` 个候选工人
2. 元组 `(cost, index)` 实现代价相同时选下标小者
3. 弹出后需补充新候选（若 `l <= r`）
