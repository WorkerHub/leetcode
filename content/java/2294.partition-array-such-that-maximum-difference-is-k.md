## 题目描述

将数组划分为最少子序列数，使每个子序列中最大值与最小值之差不超过k。

## 解题思路

排序后贪心：从最小值开始尽量延伸当前子序列，直到某元素与起始值之差超k则新开子序列。

## Java 代码实现

```java
class Solution {
    public int partitionArray(int[] nums, int k) {
        Arrays.sort(nums);
        int count = 1;
        int start = nums[0];

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] - start > k) {
                count++;
                start = nums[i];
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后连续选取最优**：贪心策略
2. **以最小值为基准延伸**：max-min<=k
3. **超出时开新子序列**
