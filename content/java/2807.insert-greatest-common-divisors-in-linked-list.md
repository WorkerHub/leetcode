## 题目描述

给你链表头节点 `head`，在每对相邻节点之间插入一个值为两节点最大公约数（GCD）的新节点，返回插入后的链表头节点。

## Java 代码实现

```java
class Solution {
    public ListNode insertGreatestCommonDivisors(ListNode head) {
        ListNode cur = head;
        while (cur != null && cur.next != null) {
            int g = gcd(cur.val, cur.next.val);
            ListNode newNode = new ListNode(g);
            // 插入：cur -> newNode -> cur.next
            newNode.next = cur.next;
            cur.next = newNode;
            // 跳过刚插入的节点，移动到原来的下一节点
            cur = newNode.next;
        }
        return head;
    }

    int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log V)，V 为节点最大值
- 空间复杂度：O(1)

## 关键点总结

1. 链表插入：先设 `newNode.next = cur.next`，再设 `cur.next = newNode`
2. 插入后移动到原来的 `cur.next`（即 `newNode.next`），跳过刚插入节点
3. 辗转相除法计算 GCD
