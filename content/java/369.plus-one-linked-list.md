## 题目描述

给定一个用链表表示的非负整数，然后将这个整数加一。

整数的最高位位于链表的表头。

**示例 1：**

```
输入：head = [1,2,3]
输出：[1,2,4]
```

**示例 2：**

```
输入：head = [0]
输出：[1]
```

**示例 3：**

```
输入：head = [9,9,9]
输出：[1,0,0,0]
```

**提示：**
- 链表中节点数目在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 由链表表示的整数不含前导零（除了数字 0 本身）

## 解题思路

这道题的关键是处理进位问题。由于链表是从高位到低位，而加法是从低位到高位进行的，因此需要特殊处理。

### 核心思路

**方法一：反转链表**
1. 反转链表，使其从低位到高位
2. 从头开始加一，处理进位
3. 再次反转恢复原顺序

**方法二：递归**
从链表尾部开始加一，递归返回进位

**方法三：找到最右边的非9节点**
- 找到最右边值不为 9 的节点
- 该节点加一，其后所有节点置为 0
- 如果所有节点都是 9，则在头部插入 1

**方法四：栈**
使用栈存储节点，从栈顶（尾部）开始处理

## Java 代码实现

### 方法一：反转链表（推荐）

```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode plusOne(ListNode head) {
        // 反转链表
        ListNode reversedHead = reverse(head);

        // 加一操作
        ListNode current = reversedHead;
        int carry = 1;  // 初始进位为 1（加一）

        while (current != null && carry > 0) {
            int sum = current.val + carry;
            carry       = sum / 10;
            current.val = sum % 10;

            // 如果还有进位但已经到链表尾部，需要添加新节点
            if (carry > 0 && current.next == null) {
                current.next = new ListNode(0);
            }

            current = current.next;
        }

        // 再次反转恢复原顺序
        return reverse(reversedHead);
    }

    /** 反转链表 */
    private ListNode reverse(ListNode head) {
        ListNode prev    = null;
        ListNode current = head;

        while (current != null) {
            ListNode nextNode = current.next;
            current.next = prev;
            prev         = current;
            current      = nextNode;
        }

        return prev;
    }
}
```

### 方法二：递归（优雅）

```java
class Solution {
    public ListNode plusOne(ListNode head) {
        // 递归函数返回进位
        int carry = helper(head);

        // 如果还有进位，需要在头部插入新节点
        if (carry > 0) {
            ListNode newHead = new ListNode(1);
            newHead.next = head;
            return newHead;
        }

        return head;
    }

    /** 递归加一，返回进位 */
    private int helper(ListNode node) {
        if (node == null) return 1;  // 到达尾部，开始加一

        // 递归处理下一个节点，获取进位
        int carry = helper(node.next);

        // 当前节点加上进位
        int sum    = node.val + carry;
        node.val   = sum % 10;
        return sum / 10;
    }
}
```

### 方法三：找最右非9节点（最优）

```java
class Solution {
    public ListNode plusOne(ListNode head) {
        // 哨兵节点，处理全是 9 的情况
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // 找到最右边不为 9 的节点
        ListNode notNine = dummy;
        ListNode current = head;

        while (current != null) {
            if (current.val != 9) {
                notNine = current;
            }
            current = current.next;
        }

        // 最右非9节点加一
        notNine.val++;

        // 其后所有节点置为 0
        current = notNine.next;
        while (current != null) {
            current.val = 0;
            current = current.next;
        }

        // 如果哨兵节点变成了 1，说明原链表全是 9
        return dummy.val == 1 ? dummy : dummy.next;
    }
}
```

### 方法四：使用栈

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public ListNode plusOne(ListNode head) {
        // 将所有节点压入栈
        Deque<ListNode> stack = new ArrayDeque<>();
        ListNode current = head;
        while (current != null) {
            stack.push(current);
            current = current.next;
        }

        // 从栈顶（链表尾部）开始加一
        int carry = 1;
        while (!stack.isEmpty() && carry > 0) {
            ListNode node = stack.pop();
            int sum       = node.val + carry;
            carry         = sum / 10;
            node.val      = sum % 10;
        }

        // 如果还有进位，在头部插入新节点
        if (carry > 0) {
            ListNode newHead = new ListNode(1);
            newHead.next = head;
            return newHead;
        }

        return head;
    }
}
```

## 复杂度分析

### 方法一：反转链表
- 时间复杂度：O(n)，三次遍历
- 空间复杂度：O(1)

### 方法二：递归
- 时间复杂度：O(n)
- 空间复杂度：O(n)，递归栈

### 方法三：找最右非9节点
- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

### 方法四：栈
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **进位处理**：加法的关键是正确处理进位
2. **从低到高**：加法从低位到高位进行，但链表是高位在前
3. **最优方法**：方法三最优，只需一次遍历且 O(1) 空间
4. **边界情况**：全是 9 的情况需要在头部插入新节点
5. **哨兵技巧**：使用哨兵节点简化边界处理

## 易错点

1. **全是9的情况**：[9,9,9] 应该返回 [1,0,0,0]
2. **进位传播**：进位可能一直传播到链表头部
3. **链表修改**：注意是原地修改还是创建新链表
4. **空链表**：虽然题目说链表非空，但要注意
5. **单节点**：[9] 应该返回 [1,0]
