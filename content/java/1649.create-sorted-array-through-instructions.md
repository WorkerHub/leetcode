## 题目描述

按 `instructions` 顺序插入元素到有序数组，每次插入元素 x 的代价为 `min(严格小于 x 的数量, 严格大于 x 的数量)`。返回总代价（对 `10^9+7` 取余）。

## 解题思路

**树状数组（BIT）：** 维护每个数值的出现次数。对每个 x，用前缀和查询 `< x` 和 `> x` 的个数，O(log M) 完成查询和更新。

## Java 代码实现

```java
class Solution {
    private int[] tree;
    private int maxVal;

    public int createSortedArray(int[] instructions) {
        final int MOD = 1_000_000_007;
        maxVal = 0;
        for (int x : instructions) maxVal = Math.max(maxVal, x);
        tree = new int[maxVal + 1];

        long totalCost = 0;
        for (int idx = 0; idx < instructions.length; idx++) {
            int x = instructions[idx];
            // 严格小于 x 的数量
            int less = x > 1 ? query(x - 1) : 0;
            // 严格大于 x 的数量 = 当前已插入数 - 小于等于 x 的数量
            int greater = idx - query(x);
            totalCost = (totalCost + Math.min(less, greater)) % MOD;
            update(x);
        }
        return (int) totalCost;
    }

    // 单点更新：位置 i 加 1
    private void update(int i) {
        while (i <= maxVal) {
            tree[i]++;
            i += i & (-i);
        }
    }

    // 前缀查询：[1, i] 的和
    private int query(int i) {
        int res = 0;
        while (i > 0) {
            res += tree[i];
            i -= i & (-i);
        }
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)，M 为最大值（最大 10^5）
- **空间复杂度**：O(M)

## 关键点总结

1. 树状数组支持 O(log M) 的单点更新和前缀和查询
2. 严格小于 x：`query(x-1)`
3. 严格大于 x：`idx - query(x)`（已插入 idx 个减去 <= x 的数量）
4. 树状数组下标从 1 开始
