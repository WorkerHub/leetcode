## 题目描述

n 堆石头排成一排，每次将连续 k 堆合并为一堆，成本为这 k 堆的石头总数。返回合并成一堆的最低成本，不可能返回 -1。

**示例：**
```
输入：stones = [3,2,4,1], k = 2
输出：20
```

## 解题思路

区间 DP：dp[i][j][p] 表示将 stones[i..j] 合并成 p 堆的最小成本。合并成 1 堆需要先合并成 k 堆再最终合并。可行性条件：(n-1) % (k-1) == 0。

## Java 代码实现

```java
class Solution {
    public int mergeStones(int[] stones, int k) {
        int n = stones.length;
        if ((n - 1) % (k - 1) != 0) return -1;

        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + stones[i];
        }

        // dp[i][j][p] = 将 stones[i..j] 合并成 p 堆的最小成本
        int[][][] dp = new int[n][n][k + 1];
        for (int[][] a : dp) for (int[] b : a) Arrays.fill(b, Integer.MAX_VALUE);

        for (int i = 0; i < n; i++) dp[i][i][1] = 0;

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                // 合并成 p 堆（p >= 2）
                for (int p = 2; p <= k; p++) {
                    for (int mid = i; mid < j; mid += k - 1) {
                        if (dp[i][mid][1] != Integer.MAX_VALUE &&
                            dp[mid + 1][j][p - 1] != Integer.MAX_VALUE) {
                            dp[i][j][p] = Math.min(dp[i][j][p],
                                dp[i][mid][1] + dp[mid + 1][j][p - 1]);
                        }
                    }
                }
                // 合并成 1 堆 = 先合并成 k 堆 + 最终合并成本
                if (dp[i][j][k] != Integer.MAX_VALUE) {
                    dp[i][j][1] = dp[i][j][k] + prefix[j + 1] - prefix[i];
                }
            }
        }

        return dp[0][n - 1][1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³/k)
- **空间复杂度**：O(n² * k)

## 关键点总结

1. **可行性判断**：(n-1) % (k-1) == 0
2. **三维 DP**：记录区间和目标堆数
3. **步长 k-1**：中间分割点按 k-1 递增
4. **前缀和**：快速计算区间石头总数
