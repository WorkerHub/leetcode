## 题目描述

给定整数数组 `nums`，可以将任意子数组替换为该子数组的和（合并操作），求操作后能得到的最长非递减数组长度。

## 解题思路

前缀和 + DP：设 `dp[i]` 为以位置 `i` 结尾（最后一个合并块的末尾）的最长非递减数组长度，`lastVal[i]` 为对应最后一块的和。转移条件：上一块末尾 `j` 的 `lastVal[j] <= prefix[i] - prefix[j]`。贪心：当多个 j 都满足转移时，选 `lastVal` 最小的以便后续更容易满足非递减条件。

## Java 代码实现

```java
class Solution {
    public int findMaximumLength(int[] nums) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // dp[i]: 以第 i 个位置为最后一块末尾的最长非递减数组长度
        // lastVal[i]: 对应最后一块的值
        int[] dp = new int[n + 1];
        long[] lastVal = new long[n + 1];

        // 贪心优化：记录每个 dp 值下，lastVal 最小的 j 位置
        // 用指针 opt 记录最优的前驱位置
        int opt = 0; // 当前最优前驱
        for (int i = 1; i <= n; i++) {
            // 移动 opt：找最远的 j 满足 lastVal[j] <= prefix[i] - prefix[j]
            // 即 2*prefix[j] - lastVal[j] <= prefix[i] ... 这是线段树优化的核心
            // 简化：O(n^2) DP
            for (int j = 0; j < i; j++) {
                long blockVal = prefix[i] - prefix[j];
                if (lastVal[j] <= blockVal) {
                    if (dp[j] + 1 > dp[i] ||
                        (dp[j] + 1 == dp[i] && blockVal < lastVal[i])) {
                        dp[i] = dp[j] + 1;
                        lastVal[i] = blockVal;
                    }
                }
            }
        }

        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)；线段树优化可达 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 前缀和快速计算任意合并块的值
2. DP 转移时，同 dp 值选 `lastVal` 最小的方案，便于后续扩展
3. 线段树可优化查询"满足 `lastVal[j] <= prefix[i] - prefix[j]` 的最大 dp[j]"
