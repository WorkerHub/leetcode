## 题目描述

给你 `original`、`changed`、`cost` 三个数组，`original[i]` 可以用 `cost[i]` 的代价转换为 `changed[i]`（多步可组合）。另给 `source` 和 `target`，返回将 `source` 转换为 `target` 的最小总代价，无法转换返回 -1。

## 解题思路

建图 + Dijkstra + 离散化：将所有值离散化后建有向图，对每个唯一的源值运行 Dijkstra 求最短路，再累加每对 `(source[i], target[i])` 的转换代价。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumCost(int[] source, int[] target,
                            int[] original, int[] changed, int[] cost) {
        // 离散化：收集所有出现的值
        TreeSet<Integer> valSet = new TreeSet<>();
        for (int v : source) valSet.add(v);
        for (int v : target) valSet.add(v);
        for (int v : original) valSet.add(v);
        for (int v : changed) valSet.add(v);
        Map<Integer, Integer> rank = new HashMap<>();
        int idx = 0;
        for (int v : valSet) rank.put(v, idx++);
        int n = rank.size();

        // 建图
        List<long[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int i = 0; i < original.length; i++) {
            int u = rank.get(original[i]), v = rank.get(changed[i]);
            graph[u].add(new long[]{v, cost[i]});
        }

        // 对每个唯一源值运行Dijkstra，缓存结果
        Map<Integer, long[]> memo = new HashMap<>();

        long ans = 0;
        for (int i = 0; i < source.length; i++) {
            if (source[i] == target[i]) continue;
            int rs = rank.get(source[i]), rt = rank.get(target[i]);
            if (!memo.containsKey(rs)) memo.put(rs, dijkstra(graph, n, rs));
            long d = memo.get(rs)[rt];
            if (d == Long.MAX_VALUE / 2) return -1;
            ans += d;
        }
        return ans;
    }

    private long[] dijkstra(List<long[]>[] graph, int n, int src) {
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE / 2);
        dist[src] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, src});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0]; int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (long[] e : graph[u]) {
                int v = (int) e[0];
                long nd = d + e[1];
                if (nd < dist[v]) { dist[v] = nd; pq.offer(new long[]{nd, v}); }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V * V_src + n)，V_src 为唯一源值数
- 空间复杂度：O(V^2)

## 关键点总结

1. 多步转换通过最短路解决（转换可传递）
2. 值域大时必须离散化再建图
3. 对每个不同的源值只运行一次 Dijkstra，用 memo 缓存
