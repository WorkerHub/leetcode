## 题目描述

给你两个等长字符串 `s` 和 `t`，以及两个长度为 26 的整数数组 `nextCost` 和 `previousCost`。将 `s[i]` 变成 `t[i]` 可向后（字母表下一个，'z'->'a'）或向前移动，每步代价分别为 `nextCost[当前字符]` 和 `previousCost[当前字符]`。返回将 `s` 变成 `t` 的最小总代价。

## 解题思路

用前缀和预处理向后和向前移动的累积代价，O(1) 查询任意两字符间的移动代价。对每个位置独立取向前、向后两种方向的最小代价求和。

## Java 代码实现

```java
class Solution {
    public long shiftDistance(String s, String t, int[] nextCost, int[] previousCost) {
        // 向后移动前缀和：nextPrefix[i] = sum(nextCost[0..i-1])
        long[] nextPrefix = new long[27];
        for (int i = 0; i < 26; i++) {
            nextPrefix[i + 1] = nextPrefix[i] + nextCost[i];
        }

        // 向前移动前缀和：prevPrefix[i] = sum(previousCost[0..i-1])
        long[] prevPrefix = new long[27];
        for (int i = 0; i < 26; i++) {
            prevPrefix[i + 1] = prevPrefix[i] + previousCost[i];
        }

        long total = 0;
        for (int i = 0; i < s.length(); i++) {
            int a = s.charAt(i) - 'a';
            int b = t.charAt(i) - 'a';
            if (a == b) continue;

            // 向后从 a 到 b（顺时针：a -> a+1 -> ... -> b，可能绕圈）
            // 经过字符 a, a+1, ..., b-1 的 nextCost
            long forwardCost;
            if (b > a) {
                forwardCost = nextPrefix[b] - nextPrefix[a];
            } else {
                // 绕圈：a -> 25 -> 0 -> ... -> b-1
                forwardCost = nextPrefix[26] - nextPrefix[a] + nextPrefix[b];
            }

            // 向前从 a 到 b（逆时针：a -> a-1 -> ... -> b，可能绕圈）
            // 经过字符 a-1, a-2, ..., b 的 previousCost（即 previousCost[a-1]+...+previousCost[b]）
            // 等价于从 b 到 a 方向，sum(previousCost[b..a-1])
            long backwardCost;
            if (a > b) {
                backwardCost = prevPrefix[a] - prevPrefix[b];
            } else {
                // 绕圈：a -> 0 -> 25 -> ... -> b+1 -> b
                backwardCost = prevPrefix[a] + prevPrefix[26] - prevPrefix[b];
            }

            total += Math.min(forwardCost, backwardCost);
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符 O(1) 处理
- 空间复杂度：O(26)，前缀和数组

## 关键点总结

1. 每个字符独立，计算 s[i] 到 t[i] 的最小代价（向前或向后）。
2. 向后移动代价用 nextCost 前缀和，向前移动代价用 previousCost 前缀和。
3. 绕圈情况：总代价 = 后半段代价 + 前半段代价。
