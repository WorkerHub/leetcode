## 题目描述

给你 n×n 的 0/1/2 矩阵（n 为奇数），一次操作可将任意单元格值改为 0/1/2，返回使 Y 形内所有值相同且与 Y 形外所有值不同的最少操作次数。

## 解题思路

枚举 Y 形目标值（0/1/2），统计 Y 形内不等于目标值的单元格数和 Y 形外等于目标值的单元格数之和，取最小值。

## Java 代码实现

```java
class Solution {
    public int minimumOperationsToWriteY(int[][] grid) {
        int n = grid.length, mid = n / 2;
        int[] yCnt = new int[3], nonYCnt = new int[3];
        int yTotal = 0, nonYTotal = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                boolean inY = false;
                // 上半左对角线和右对角线
                if (i <= mid && (j == i || j == n - 1 - i)) inY = true;
                // 下半竖线
                if (i >= mid && j == mid) inY = true;

                if (inY) { yCnt[grid[i][j]]++; yTotal++; }
                else { nonYCnt[grid[i][j]]++; nonYTotal++; }
            }
        }

        int ans = Integer.MAX_VALUE;
        for (int target = 0; target < 3; target++) {
            // Y 形内修改数 + Y 形外等于 target 的需修改数
            int ops = (yTotal - yCnt[target]) + nonYCnt[target];
            ans = Math.min(ans, ops);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，遍历矩阵
- **空间复杂度**：O(1)（计数数组只有 3 个元素）

## 关键点总结

1. Y 形 = 上半两条对角线 + 下半竖线，中心点 `(mid, mid)` 计算一次
2. 枚举 Y 形目标值（0/1/2），计算总操作数取最小
3. Y 形外只需将等于 target 的单元格改掉，不要求外部互相相同
