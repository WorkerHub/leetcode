## 题目描述

给你两个整数数组 `wizard` 和 `potion`，巫师 i 按顺序酿造所有药水，酿造药水 j 需要 `wizard[i] * potion[j]` 时间，所有巫师同时开始，每种药水只需一个巫师完成，返回所有药水完成的最短时间。

## 解题思路

二分 + 贪心：二分答案 T（最长完成时间），检验时贪心地为每个巫师分配连续的一段药水（尽量多做）。用前缀和计算每个巫师在时间 T 内最多能完成多少前缀和的药水，若所有巫师合力能覆盖全部 m 种药水则可行。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private long[] prefix;
    private int[] wizard;
    private int m;

    public long minTime(int[] wizard, int[] potion) {
        this.wizard = wizard;
        m = potion.length;
        prefix = new long[m + 1];
        for (int j = 0; j < m; j++) prefix[j + 1] = prefix[j] + potion[j];

        long lo = 0;
        long maxW = 0;
        for (int w : wizard) maxW = Math.max(maxW, w);
        long hi = maxW * prefix[m];

        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (feasible(mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    private boolean feasible(long T) {
        int pos = 0; // 当前未分配的第一个药水
        for (int w : wizard) {
            if (pos >= m) return true;
            if (w == 0) { pos = m; return true; }
            long maxSum = T / w;
            // 找从 pos 开始，前缀和增量 <= maxSum 的最多药水数
            long target = prefix[pos] + maxSum;
            // 在 prefix[pos..m] 中找最大下标使 prefix[k] <= target
            int lo = pos, hi = m;
            while (lo < hi) {
                int mid = (lo + hi + 1) / 2;
                if (prefix[mid] <= target) lo = mid;
                else hi = mid - 1;
            }
            pos = lo;
        }
        return pos >= m;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log(W * P))，W 为最大巫师值，P 为药水前缀和
- 空间复杂度：O(m)

## 关键点总结

1. 二分最终时间 T，贪心分配连续药水段
2. 巫师 w 在时间 T 内可完成前缀和增量 <= T/w 的连续药水
3. 用前缀和数组上的二分查找定位每个巫师的最大分配范围
