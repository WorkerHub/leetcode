## 题目描述

有 `n` 座城市（编号 1 到 n），若两城市编号 `a`、`b` 的最大公约数 `gcd(a, b) > threshold`，则两城市间有一条边。给定查询数组，回答每个查询 `[a, b]` 中两城市是否连通。

**提示：**
- `2 <= n <= 10^4`，`0 <= threshold <= n`

## 解题思路

**筛法 + 并查集：** 对每个因数 `d > threshold`，将 d 的所有倍数都连接到同一并查集中（类似埃氏筛），时间复杂度类似调和级数。

## Java 代码实现

```java
class Solution {
    private int[] parent, rank;

    public List<Boolean> areConnected(int n, int threshold, int[][] queries) {
        // 初始化并查集
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int i = 0; i <= n; i++) parent[i] = i;

        // 筛法：对每个 d > threshold，连接 d 的所有倍数
        for (int d = threshold + 1; d <= n; d++) {
            for (int j = 2 * d; j <= n; j += d) {
                union(d, j);
            }
        }

        // 处理查询
        List<Boolean> result = new ArrayList<>();
        for (int[] q : queries) {
            result.add(find(q[0]) == find(q[1]));
        }
        return result;
    }

    private int find(int x) {
        // 路径压缩
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        // 按秩合并
        if (rank[rx] < rank[ry]) { int tmp = rx; rx = ry; ry = tmp; }
        parent[ry] = rx;
        if (rank[rx] == rank[ry]) rank[rx]++;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n * α(n))，类似调和级数
- **空间复杂度**：O(n)

## 关键点总结

1. 筛法：对每个 `d > threshold`，连接 d 与所有 d 的倍数
2. 若 `gcd(a,b) > threshold`，则 a 和 b 通过公因数 d 相连
3. 并查集路径压缩 + 按秩合并，支持高效连通性查询
