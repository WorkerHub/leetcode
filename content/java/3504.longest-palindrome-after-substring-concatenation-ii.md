## 题目描述

给你字符串 `s` 和 `t`（长度可达 1000），从 `s` 选一个子串，从 `t` 选一个子串，拼接后求能组成的最长回文串的长度。

## 解题思路

将 `t` 反转为 `t_rev`，问题变为从 `s` 选子串 A，从 `t_rev` 选子串 B，使 A+B 是回文。预处理 `s` 和 `t_rev` 的回文 DP，同时枚举 `s` 前缀和 `t_rev` 前缀的最长公共前缀（用哈希+二分）得到可拼接的镜像对，取最优结果。

## Java 代码实现

```java
class Solution {
    public int longestPalindrome(String s, String t) {
        String tRev = new StringBuilder(t).reverse().toString();
        int n = s.length(), m = tRev.length();
        int res = 1;

        // 预处理回文 DP
        boolean[][] dpS = palindromeDp(s);
        boolean[][] dpT = palindromeDp(tRev);

        // 单独子串的回文
        for (int i = 0; i < n; i++)
            for (int j = i; j < n; j++)
                if (dpS[i][j]) res = Math.max(res, j - i + 1);
        for (int i = 0; i < m; i++)
            for (int j = i; j < m; j++)
                if (dpT[i][j]) res = Math.max(res, j - i + 1);

        // 枚举 s 以 i 开头的前缀和 t_rev 以 p 开头的前缀，找最长公共前缀
        // 公共长度 lcp 表示 s[i..i+lcp-1] == t_rev[p..p+lcp-1]
        // 拼接后可构成长度 2*lcp 的回文（或更长，若剩余部分各自有回文延伸）
        for (int i = 0; i < n; i++) {
            for (int p = 0; p < m; p++) {
                int lcp = 0;
                int lo = 0, hi = Math.min(n - i, m - p);
                while (lo < hi) {
                    int mid = (lo + hi + 1) / 2;
                    if (s.substring(i, i + mid).equals(tRev.substring(p, p + mid))) {
                        lcp = mid; lo = mid;
                    } else hi = mid - 1;
                }
                if (lcp > 0) {
                    // 基础长度 2*lcp，左侧 s[0..i-1] 中后缀回文延伸
                    res = Math.max(res, 2 * lcp);
                    // 左侧延伸：s[0..i-1] 中以 i-1 结尾的最长回文
                    for (int ii = 0; ii < i; ii++)
                        if (dpS[ii][i - 1]) res = Math.max(res, 2 * lcp + (i - ii));
                    // 右侧延伸：t_rev[p+lcp..m-1] 中以 p+lcp 开头的最长回文
                    for (int pp = p + lcp; pp < m; pp++)
                        if (dpT[p + lcp][pp]) res = Math.max(res, 2 * lcp + (pp - p - lcp + 1));
                }
            }
        }

        return res;
    }

    private boolean[][] palindromeDp(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        for (int i = 0; i < n; i++) dp[i][i] = true;
        for (int i = 0; i + 1 < n; i++) dp[i][i + 1] = (s.charAt(i) == s.charAt(i + 1));
        for (int len = 3; len <= n; len++)
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = dp[i + 1][j - 1] && s.charAt(i) == s.charAt(j);
            }
        return dp;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 + m^2 + n * m * log(min(n,m)))
- 空间复杂度：O(n^2 + m^2)

## 关键点总结

1. 反转 t 后，A + B 是回文当且仅当 A 与 t_rev 中对应部分互相镜像
2. 最长公共前缀（LCP）对应可拼接的镜像长度，用二分加速
3. 左右两侧的独立回文部分可额外延伸总长度
