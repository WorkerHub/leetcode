## 题目描述

你正在参与祖玛游戏的一个变种。

在这个祖玛游戏变体中，桌面上有一排彩球，每个球的颜色可能是红色 'R'、黄色 'Y'、蓝色 'B'、绿色 'G' 或白色 'W'。你的手中也有一些彩球。

你的目标是清空桌面上所有的球。每一回合：
- 从你手里选出一颗球，插入到桌面上那一排球中的某一个位置上（包括最左端和最右端）。
- 如果这种操作使得桌面上有三个或更多连续颜色相同的球，就立即移除这些球。
- 如果移除之后又导致出现三个或更多的连续颜色相同的球，就继续移除这些球。
- 重复这个过程，直到桌面上没有更多的球。

给你一个字符串 board，表示桌面上最开始的那排球。另给你一个字符串 hand，表示手里的彩球。请你返回清空桌面上所有球所需的最少球数。如果不能清空桌面上所有的球，返回 -1。

**示例 1：**
```
输入：board = "WRRBBW", hand = "RB"
输出：-1
解释：无法清空桌面，因为只能放红色或蓝色球。
```

**示例 2：**
```
输入：board = "WWRRBBWW", hand = "WRBRW"
输出：2
解释：
- 在第一个 'W' 和第一个 'R' 之间插入 'R'，得到 WWRRRBBWW。
  WWRRRBBWW -> WWBBWW（移除 3 个 'R'）
- 在第一个 'B' 和第二个 'B' 之间插入 'B'，得到 WWBBBWW。
  WWBBBWW -> WWWW（移除 3 个 'B'）
  WWWW -> 空（移除 4 个 'W'）
```

**示例 3：**
```
输入：board = "G", hand = "GGGGG"
输出：2
解释：
- 在 'G' 后插入 'G'，得到 "GG"。
- 在 'GG' 后插入 'G'，得到 "GGG"，然后移除所有球。
```

**提示：**
- 1 <= board.length <= 16
- 1 <= hand.length <= 5
- board 和 hand 由字符 'R'、'Y'、'B'、'G' 和 'W' 组成
- 桌面上一开始的球中，不会有三个及三个以上颜色相同且连续的球

## 解题思路

这是一道搜索 + 剪枝的困难题，核心是通过 DFS/BFS 遍历所有可能的操作序列。

### 核心思想

1. **状态搜索**：
   - 每个状态：(当前 board, 剩余 hand)
   - 尝试将 hand 中的每个球插入到 board 的每个位置
   - 寻找最少步数

2. **剪枝优化**：
   - 只在有意义的位置插入球（相同颜色球旁边）
   - 使用记忆化避免重复计算
   - 如果 board 为空，返回 0

3. **消除逻辑**：
   - 插入球后检查是否有连续 3 个或更多相同颜色
   - 递归消除，直到没有可消除的球

4. **搜索策略**：
   - DFS + 记忆化：深度优先搜索所有可能
   - 记录 (board, hand) 状态避免重复

## Java 代码实现

### 方法一：DFS + 记忆化（推荐）

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<String, Integer> memo = new HashMap<>();

    public int findMinStep(String board, String hand) {
        // DFS + 记忆化搜索
        // 时间复杂度：O(n * m!)，n 是 board 长度，m 是 hand 长度
        // 空间复杂度：O(状态数)

        // 将 hand 转为字符计数数组
        int[] handCount = new int[26];
        for (char c : hand.toCharArray()) {
            handCount[c - 'A']++;
        }

        int result = dfs(board, handCount);
        return (result == Integer.MAX_VALUE) ? -1 : result;
    }

    private String removeConsecutive(String s) {
        // 移除连续 3 个或更多相同颜色的球
        int i = 0;
        while (i < s.length()) {
            int j = i;
            // 找到连续相同颜色的区间
            while (j < s.length() && s.charAt(j) == s.charAt(i)) {
                j++;
            }
            // 如果有 3 个或更多，移除并递归检查
            if (j - i >= 3) {
                return removeConsecutive(s.substring(0, i) + s.substring(j));
            }
            i = j;
        }
        return s;
    }

    private int dfs(String board, int[] hand) {
        // 返回清空 board 所需的最少球数
        if (board.isEmpty()) return 0;

        // 记忆化：以 board + hand 的字符串表示为 key
        String key = board + "#" + Arrays.toString(hand);
        if (memo.containsKey(key)) return memo.get(key);

        int minSteps = Integer.MAX_VALUE;
        int i = 0;
        int n = board.length();

        while (i < n) {
            int j = i + 1;
            // 找到连续相同颜色的区间
            while (j < n && board.charAt(j) == board.charAt(i)) {
                j++;
            }

            char color = board.charAt(i);
            // 需要多少个球才能消除这段
            int need = 3 - (j - i);

            if (hand[color - 'A'] >= need) {
                // 使用 need 个球
                hand[color - 'A'] -= need;
                // 消除这段并递归搜索
                String newBoard = removeConsecutive(board.substring(0, i) + board.substring(j));
                int step = dfs(newBoard, hand);
                if (step != Integer.MAX_VALUE) {
                    minSteps = Math.min(minSteps, step + need);
                }
                // 回溯
                hand[color - 'A'] += need;
            }

            i = j;
        }

        memo.put(key, minSteps);
        return minSteps;
    }
}
```

### 方法二：优化的 DFS（只在关键位置插入）

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<String, Integer> memo = new HashMap<>();

    public int findMinStep(String board, String hand) {
        // 优化的 DFS：只在可能消除的位置插入
        // 时间复杂度：O(n * m!)
        // 空间复杂度：O(状态数)
        int[] handCount = new int[26];
        for (char c : hand.toCharArray()) {
            handCount[c - 'A']++;
        }
        int result = dfs(board, handCount);
        return (result == Integer.MAX_VALUE) ? -1 : result;
    }

    private String removeSame(String s) {
        // 移除连续 3 个或更多相同球
        int i = 0, n = s.length();
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) {
                j++;
            }
            if (j - i >= 3) {
                return removeSame(s.substring(0, i) + s.substring(j));
            }
            i = j;
        }
        return s;
    }

    private int dfs(String board, int[] hand) {
        // 先消除已有的连续球
        board = removeSame(board);

        if (board.isEmpty()) return 0;

        // 检查是否还有手牌
        boolean hasCards = false;
        for (int cnt : hand) {
            if (cnt > 0) { hasCards = true; break; }
        }
        if (!hasCards) return Integer.MAX_VALUE;

        String key = board + "#" + Arrays.toString(hand);
        if (memo.containsKey(key)) return memo.get(key);

        int minStep = Integer.MAX_VALUE;
        int i = 0, n = board.length();

        while (i < n) {
            int j = i + 1;
            // 找到连续相同颜色的区间
            while (j < n && board.charAt(j) == board.charAt(i)) {
                j++;
            }

            char color = board.charAt(i);
            // 需要多少个球才能消除
            int need = 3 - (j - i);

            if (hand[color - 'A'] >= need) {
                // 使用 need 个球
                hand[color - 'A'] -= need;
                // 递归搜索
                int step = dfs(board.substring(0, i) + board.substring(j), hand);
                if (step != Integer.MAX_VALUE) {
                    minStep = Math.min(minStep, step + need);
                }
                // 回溯
                hand[color - 'A'] += need;
            }

            i = j;
        }

        memo.put(key, minStep);
        return minStep;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m!)
  - n 是 board 的长度
  - m 是 hand 的长度
  - 最坏情况需要尝试所有排列
  - 记忆化可以大幅减少实际计算量

- **空间复杂度**：O(状态数)
  - 记忆化存储的状态数
  - 递归栈深度最多 m

## 关键点总结

1. **搜索 + 剪枝**：遍历所有可能，使用剪枝优化
2. **消除逻辑**：递归消除连续 3 个或更多相同球
3. **记忆化**：避免重复计算相同状态
4. **优化插入位置**：只在有意义的位置插入
5. **状态表示**：(board, hand) 唯一确定一个状态

## 易错点

1. **消除逻辑不完整**
   - 移除后可能产生新的连续球
   - 需要递归消除

2. **重复状态**
   - 同一个 board 和 hand 可能通过不同路径达到
   - 必须使用记忆化

3. **插入位置优化**
   - 不是所有位置都需要尝试
   - 只在相同颜色旁边或能消除的位置插入

4. **hand 的表示**
   - 使用 int[] 数组更方便
   - 注意回溯时要恢复数组状态

5. **边界条件**
   - board 为空返回 0
   - hand 全为 0 但 board 不为空返回 -1（MAX_VALUE）
