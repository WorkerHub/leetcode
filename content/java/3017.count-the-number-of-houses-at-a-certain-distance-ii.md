## 题目描述

与 3015 相同，n 所房屋链式连接加一条额外边 x-y（n 达 10^5），返回各距离有序对数数组。

## 解题思路

图为链 + 一条捷径，任意两点最短距离为：直接链距离 vs 经过捷径两种路径的最小值。枚举所有点对，用差分数组统计各距离的有序对数。

## Java 代码实现

```java
class Solution {
    public long[] countOfPairs(int n, int x, int y) {
        if (x > y) { int tmp = x; x = y; y = tmp; }
        long[] result = new long[n];
        // 枚举所有有序对 (i, j), i < j，计算最短距离
        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                int d1 = j - i;                              // 直接链距离
                int d2 = Math.abs(i - x) + 1 + Math.abs(y - j); // 经过 x->y
                int d3 = Math.abs(i - y) + 1 + Math.abs(x - j); // 经过 y->x
                int d = Math.min(d1, Math.min(d2, d3));
                result[d - 1] += 2; // 有序对 (i,j) 和 (j,i) 各计一次
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)（竞赛中需 O(n) 差分优化）
- **空间复杂度**：O(n)

## 关键点总结

1. 最短距离 = min(直接链距离, 经过 x→y, 经过 y→x)
2. x > y 时先交换保证 x < y
3. 有序对 (i,j) 和 (j,i) 各计一次，结果 ×2
