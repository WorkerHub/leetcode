## 题目描述

通过"交换字符"或"将某种字符全部替换为另一种现有字符"可以从一个字符串得到另一个，则两字符串**接近**。判断 `word1` 和 `word2` 是否接近。

## 解题思路

两字符串接近的充要条件：
1. 字符集相同（出现的字符种类相同）
2. 频率的多重集合相同（频率排序后相等）

## Java 代码实现

```java
class Solution {
    public boolean closeStrings(String word1, String word2) {
        int[] cnt1 = new int[26], cnt2 = new int[26];
        for (char c : word1.toCharArray()) cnt1[c - 'a']++;
        for (char c : word2.toCharArray()) cnt2[c - 'a']++;

        // 条件 1：字符集相同（出现过的字符种类一致）
        for (int i = 0; i < 26; i++) {
            if ((cnt1[i] == 0) != (cnt2[i] == 0)) return false;
        }

        // 条件 2：频率多重集相同（排序后比较）
        Arrays.sort(cnt1);
        Arrays.sort(cnt2);
        return Arrays.equals(cnt1, cnt2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 26 log 26) = O(n)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 两个条件缺一不可：字符集相同 + 频率分布相同
2. 字符集比较：`cnt[i]==0` 的位置需一致
3. 频率比较：排序后逐位比较
