## 题目描述

给你字符串形式的整数 `num`（可达 10^100）和整数 `t`，返回大于等于 `num` 的最小整数（字符串形式），使得其各位数字的乘积能被 `t` 整除。若不存在则返回 `"-1"`。

## 解题思路

各位数字（1-9）的乘积质因子只有 2、3、5、7，若 `t` 含其他质因子则返回 "-1"。将 t 化简为只含 2、3、5、7 的剩余部分后，用贪心构造：从右到左枚举"进位位置" i，将第 i 位增加到某个值，后缀各位贪心选最小数字消除剩余需求。同时考虑原数本身是否满足条件。

## Java 代码实现

```java
import java.math.BigInteger;
import java.util.*;

class Solution {
    public String smallestNumber(String num, long t) {
        // 检查 t 只含 2,3,5,7 的质因子
        long tmp = t;
        for (int p : new int[]{2, 3, 5, 7}) {
            while (tmp % p == 0) tmp /= p;
        }
        if (tmp != 1) return "-1";

        int n = num.length();
        int[] digits = new int[n];
        for (int i = 0; i < n; i++) digits[i] = num.charAt(i) - '0';

        // 计算数字数组的乘积对 t 的整除需求（剩余）
        // 返回满足条件的最小后缀（长度 length，乘积能被 need 整除）
        // 若无法满足返回 null

        // 先检查原数是否满足
        long prod = 1;
        for (int d : digits) {
            if (d == 0) { prod = 0; break; }
            prod *= d;
            if (prod > (long)1e15) prod = (long)1e15; // 防溢出，只需知道能否整除
        }
        // 重新计算（精确）
        prod = digitProduct(digits, 0, n);
        if (prod % t == 0) return num;

        // 尝试在每个位置 i 进行"进位"操作
        String best = null;

        for (int i = n - 1; i >= 0; i--) {
            int startVal = (i == n - 1) ? digits[i] + 1 : digits[i] + 1;
            // 前缀乘积 digits[0..i-1]
            long prefProd = digitProduct(digits, 0, i);

            for (int newD = startVal; newD <= 9; newD++) {
                if (newD == 0) continue; // 0 会使乘积为 0
                long cur = prefProd * newD;
                // 后缀长度 n-1-i，需要使 cur * suffixProd % t == 0
                long need = t / gcd(cur % t == 0 ? t : cur % t > 0 ? reduceFactor(cur, t) : t, t);
                // 简化：need = t / gcd(cur, t)（剩余因子）
                need = t / gcd(cur, t);

                int suffLen = n - 1 - i;
                int[] suff = minSuffix(need, suffLen);
                if (suff != null) {
                    int[] candidate = new int[n];
                    System.arraycopy(digits, 0, candidate, 0, i);
                    candidate[i] = newD;
                    System.arraycopy(suff, 0, candidate, i + 1, suffLen);
                    String s = arrayToString(candidate);
                    if (best == null || compareNumStr(s, best) < 0) {
                        best = s;
                    }
                    break; // newD 从小到大，找到最小 newD 后就是最优
                }
            }
            if (best != null) break; // 已找到，不需要更高位进位
        }

        // 若仍未找到，需要更多位数的数（位数 = n+1, n+2, ...）
        if (best == null) {
            // 找最小位数 L > n，使得 L 位最小数（各位乘积 % t == 0）存在
            for (int L = n + 1; L <= n + 10; L++) {
                int[] suff = minSuffix(t, L);
                if (suff != null) {
                    // 构造 L 位数：前面尽量补 1
                    int[] candidate = new int[L];
                    Arrays.fill(candidate, 1);
                    // 用最小后缀覆盖
                    int[] opt = minSuffix(t, L);
                    best = arrayToString(opt);
                    break;
                }
            }
        }

        return best == null ? "-1" : best;
    }

    // 计算 digits[from..to-1] 的乘积，上限 Long.MAX_VALUE/10 防溢出
    private long digitProduct(int[] digits, int from, int to) {
        long prod = 1;
        for (int i = from; i < to; i++) {
            if (digits[i] == 0) return 0;
            prod *= digits[i];
            if (prod > (long)1e18) return (long)1e18;
        }
        return prod;
    }

    // 构造长度 length、乘积能被 need 整除的最小数字序列
    private int[] minSuffix(long need, int length) {
        if (need == 1) {
            int[] res = new int[length];
            Arrays.fill(res, 1);
            return res;
        }
        if (length == 0) return null;
        int[] result = new int[length];
        for (int pos = 0; pos < length; pos++) {
            boolean found = false;
            for (int d = 1; d <= 9; d++) {
                long newNeed = need / gcd(need, d);
                int remaining = length - pos - 1;
                // 检查剩余 remaining 位能否满足 newNeed
                if (canSatisfy(newNeed, remaining)) {
                    result[pos] = d;
                    need = newNeed;
                    found = true;
                    break;
                }
            }
            if (!found) return null;
        }
        return need == 1 ? result : null;
    }

    // 检查 length 个 1-9 的乘积能否整除 need
    private boolean canSatisfy(long need, int length) {
        if (need == 1) return true;
        if (length == 0) return false;
        // 贪心：每次用最大因子消除
        for (int i = 0; i < length; i++) {
            for (int d = 9; d >= 1; d--) {
                long g = gcd(need, d);
                if (g > 1) {
                    need /= g;
                    if (need == 1) return true;
                    break;
                }
            }
        }
        return need == 1;
    }

    private long reduceFactor(long cur, long t) {
        long g = gcd(cur, t);
        return g;
    }

    private long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    private String arrayToString(int[] digits) {
        StringBuilder sb = new StringBuilder();
        for (int d : digits) sb.append(d);
        return sb.toString();
    }

    private int compareNumStr(String a, String b) {
        if (a.length() != b.length()) return a.length() - b.length();
        return a.compareTo(b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 9 * L)，n 为位数，L 为后缀长度（最多 n）
- 空间复杂度：O(n)

## 关键点总结

1. 若 t 含大于 7 的质因子，直接返回 "-1"（各位数字乘积质因子只有 2、3、5、7）。
2. 贪心构造：从右到左枚举进位位置，后缀选最小满足条件的数字序列。
3. 用 gcd 计算剩余需要整除的因子，逐位贪心消除。
