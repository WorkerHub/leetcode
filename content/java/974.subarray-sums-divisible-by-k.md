## 题目描述

给定整数数组 nums 和整数 k，返回元素之和可被 k 整除的非空子数组数目。

**示例：**
```
输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
```

## 解题思路

前缀和取模 + 哈希表：两个前缀和 mod k 相同的位置之间的子数组和能被 k 整除。统计每个余数出现次数。

## Java 代码实现

```java
class Solution {
    public int subarraysDivByK(int[] nums, int k) {
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);

        int prefixSum = 0, result = 0;
        for (int num : nums) {
            prefixSum += num;
            // Java 取模可能为负，需要调整
            int mod = ((prefixSum % k) + k) % k;
            result += prefixCount.getOrDefault(mod, 0);
            prefixCount.merge(mod, 1, Integer::sum);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. **前缀和取模**：同余的前缀和之间子数组可整除
2. **负数取模**：Java 中 ((x % k) + k) % k 保证非负
3. **计数组合**：相同余数出现 c 次则有 C(c,2) 个子数组
