## 题目描述

给定一棵 N 叉树的根节点 `root`，返回该树的**深拷贝**（克隆）。

N 叉树中每个节点均包含一个整数值 `val` 和一个子节点列表 `children`。

```java
class Node {
    public int val;
    public List<Node> children;
}
```

**注意：** 深拷贝意味着新树中的每个节点都是全新创建的，不与原树共享引用。

**示例 1：**

```
输入：root = [1, null, 3, 2, 4, null, 5, 6]
输出：[1, null, 3, 2, 4, null, 5, 6]
```

**示例 2：**

```
输入：root = [1, null, 2, 3, 4, 5, null, null, 6, 7, null, 8, null, 9, 10, null, null, 11, null, 12, null, 13, null, null, 14]
输出：[1, null, 2, 3, 4, 5, null, null, 6, 7, null, 8, null, 9, 10, null, null, 11, null, 12, null, 13, null, null, 14]
```

**提示：**

- 节点总数在 `[0, 10^4]` 之间。
- 每个节点值 `0 <= Node.val <= 10^4`。
- N 叉树的高度不超过 1000。

## 解题思路

深拷贝一棵树，核心思路是：**为每个原节点创建一个对应的新节点，并递归处理其所有子节点。**

有两种经典的树遍历方式可以实现：

**方法一：DFS 递归**

- 若当前节点为空，直接返回 null
- 创建与当前节点值相同的新节点
- 递归克隆每个子节点，加入新节点的 children 列表
- 返回新节点

这种方式代码最简洁，利用系统调用栈完成深度优先遍历。

**方法二：BFS 迭代（使用队列）**

- 使用队列存储 (原节点, 克隆节点) 对
- 每次取出一对，对原节点的每个子节点创建克隆，加入克隆节点的 children，并将 (原子节点, 克隆子节点) 加入队列
- 直到队列为空

**方法三：DFS 迭代（使用栈）**

与 BFS 类似，用栈代替队列即可实现深度优先。

## Java 代码实现

### 方法一：DFS 递归（推荐，最简洁）

```java
import java.util.ArrayList;

class Solution {
    public Node cloneTree(Node root) {
        // 空节点直接返回
        if (root == null) return null;

        // 创建新节点
        Node newNode = new Node(root.val, new ArrayList<>());

        // 递归克隆每个子节点
        for (Node child : root.children) {
            newNode.children.add(cloneTree(child));
        }

        return newNode;
    }
}
```

### 方法二：BFS 迭代（使用队列）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;

class Solution {
    public Node cloneTree(Node root) {
        if (root == null) return null;

        // 克隆根节点
        Node newRoot = new Node(root.val, new ArrayList<>());

        // 队列存储 (原节点, 克隆节点) 对，用 Object[] 表示
        Deque<Object[]> queue = new ArrayDeque<>();
        queue.offer(new Object[]{root, newRoot});

        while (!queue.isEmpty()) {
            Object[] pair = queue.poll();
            Node origNode = (Node) pair[0];
            Node cloneNode = (Node) pair[1];

            // 克隆每个子节点
            for (Node child : origNode.children) {
                Node cloneChild = new Node(child.val, new ArrayList<>());
                cloneNode.children.add(cloneChild);
                queue.offer(new Object[]{child, cloneChild});
            }
        }

        return newRoot;
    }
}
```

### 方法三：DFS 迭代（使用栈）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;

class Solution {
    public Node cloneTree(Node root) {
        if (root == null) return null;

        Node newRoot = new Node(root.val, new ArrayList<>());
        // 栈存储 (原节点, 克隆节点) 对
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{root, newRoot});

        while (!stack.isEmpty()) {
            Object[] pair = stack.pop();
            Node origNode = (Node) pair[0];
            Node cloneNode = (Node) pair[1];

            for (Node child : origNode.children) {
                Node cloneChild = new Node(child.val, new ArrayList<>());
                cloneNode.children.add(cloneChild);
                stack.push(new Object[]{child, cloneChild});
            }
        }

        return newRoot;
    }
}
```

### 方法四：哈希表辅助（处理有环/重复引用的图结构变种）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<Node, Node> memo = new HashMap<>();

    public Node cloneTree(Node root) {
        if (root == null) return null;
        if (memo.containsKey(root)) return memo.get(root);

        Node clone = new Node(root.val, new ArrayList<>());
        memo.put(root, clone);

        for (Node child : root.children) {
            clone.children.add(cloneTree(child));
        }

        return clone;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DFS 递归 | O(n) | O(h)，h 为树高 |
| BFS 迭代 | O(n) | O(w)，w 为最大宽度 |
| DFS 迭代 | O(n) | O(h) |
| 哈希表辅助 | O(n) | O(n) |

- `n` 为节点总数，所有方法都需要访问每个节点一次
- 递归方法空间取决于递归深度（树高），最坏 O(n)（链状树）
- BFS 的队列空间取决于树的最大宽度

## 关键点总结

1. **深拷贝 vs 浅拷贝**：深拷贝要求每个节点都是新对象，修改克隆树不影响原树。
2. **递归思路最自然**：克隆当前节点，递归克隆子节点，组合即可。
3. **BFS/DFS 迭代适合大树**：避免递归深度过大导致栈溢出。
4. **children 列表也需新建**：构造 `new ArrayList<>()` 保证列表独立。

## 易错点

- **忘记处理空节点**：root 为 null 时应直接返回 null。
- **浅拷贝陷阱**：直接 `newNode.children = root.children` 会共享列表引用，修改一个会影响另一个。
- **DFS 迭代中子节点顺序**：使用栈时，子节点弹出顺序与压入顺序相反，但对于克隆来说顺序需要保持一致（按原顺序加入 children，逐个 push 到栈中）。

## 学习建议

1. 先理解**深拷贝**的含义：新旧两棵树互不影响，每个节点都是全新分配的对象。
2. 掌握 DFS 递归版本后，再学习 BFS 迭代版本，体会两种遍历方式的差异。
3. 对比 [133. 克隆图] 和本题，图需要哈希表防止重复访问，树则不需要（无环）。
4. N 叉树与二叉树的区别仅在于 children 是列表而非固定的 left/right，处理逻辑本质相同。
