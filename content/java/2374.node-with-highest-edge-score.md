## 题目描述

给你有向图 `edges`（`edges[i]` 表示 i 到 `edges[i]` 有边），节点 i 的边分数为所有指向它的边的源节点编号之和，返回边分数最高的节点（并列取编号最小的）。

## 解题思路

遍历一次 `edges`，对每个节点 i 将 i 累加到 `score[edges[i]]`，最后找分数最大（相同时取编号最小）的节点即可。注意 n 最大 10^5，分数最大约 5×10^9，需用 `long`。

## Java 代码实现

```java
class Solution {
    public int edgeScore(int[] edges) {
        int n = edges.length;
        long[] score = new long[n]; // 分数可能超 int 范围，用 long
        for (int i = 0; i < n; i++) {
            score[edges[i]] += i;
        }
        int best = 0;
        for (int i = 1; i < n; i++) {
            if (score[i] > score[best]) best = i; // 严格大于才更新，保证编号最小
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 遍历 edges，将每个源节点编号累加到目标节点的分数上。
2. 分数最大约 n*(n-1)/2 ≈ 5×10^9，超过 int 范围，必须用 `long`。
3. 枚举时严格大于才更新，保证相同分数时返回编号最小的节点。
