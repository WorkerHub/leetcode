## 题目描述

对每个查询值 `queries[i]`，返回将 `nums` 所有元素变为该值所需的最少操作数（每次操作对一个元素 +1 或 -1）。

## 解题思路

**排序 + 前缀和 + 二分查找**：对 `nums` 排序并构建前缀和。对每个查询 `q`，二分找到分界点 `k`（`<= q` 的元素个数），左侧贡献 `q*k - prefix[k]`，右侧贡献 `(prefix[n] - prefix[k]) - q*(n-k)`。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.List;
import java.util.ArrayList;

class Solution {
    public List<Long> minOperations(int[] nums, int[] queries) {
        Arrays.sort(nums);
        int n = nums.length;
        // 构建前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        List<Long> result = new ArrayList<>();
        for (int q : queries) {
            // 二分找第一个 > q 的位置（即 <= q 的元素个数）
            int k = upperBound(nums, q);
            long leftCost = (long) q * k - prefix[k];
            long rightCost = (prefix[n] - prefix[k]) - (long) q * (n - k);
            result.add(leftCost + rightCost);
        }
        return result;
    }

    // 返回 nums 中第一个严格大于 target 的下标
    private int upperBound(int[] nums, int target) {
        int lo = 0, hi = nums.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (nums[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，排序 O(n log n)，每次查询二分 O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后前缀和将区间求和转化为 O(1)
2. `upperBound` 找分界点，左侧元素需增加，右侧需减少
3. 用 `long` 防止整数溢出
