## 题目描述

给你一棵完整二叉树，叶子节点值为 0（false）或 1（true），非叶子节点值为 2（OR）或 3（AND），返回根节点的布尔运算结果。

## 解题思路

递归求解：叶子节点直接返回布尔值，非叶子节点根据 val 对左右子树结果做 OR 或 AND 运算。

## Java 代码实现

```java
class Solution {
    public boolean evaluateTree(TreeNode root) {
        // 叶子节点：左子为空即为叶子（完整二叉树无左必无右）
        if (root.left == null) return root.val == 1;
        boolean left = evaluateTree(root.left);
        boolean right = evaluateTree(root.right);
        return root.val == 2 ? (left || right) : (left && right); // 2=OR, 3=AND
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. 叶子节点用 `root.left == null` 判断（完整二叉树无左子即无右子）。
2. 2 对应 OR 运算，3 对应 AND 运算。
3. 完整二叉树保证非叶子节点必有两个子节点，无需特判单子节点。
