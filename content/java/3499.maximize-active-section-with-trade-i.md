## 题目描述

给你二进制字符串 `s`，可进行一次操作：将某个连续全 '1' 段转为全 '0'，同时将紧邻的左或右全 '0' 段转为全 '1'，返回操作后 '1' 的最大数量。

## 解题思路

分段枚举：将字符串分成交替段，对每个 '1' 段枚举操作——净变化 = max(左 '0' 段长度, 右 '0' 段长度) - '1' 段长度，取最大净变化加上原始 '1' 的总数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxActiveSectionsAfterTrade(String s) {
        int n = s.length();
        int totalOnes = 0;
        for (char c : s.toCharArray()) if (c == '1') totalOnes++;

        // 将字符串分成交替段 [char, length]
        List<int[]> segs = new ArrayList<>();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            segs.add(new int[]{s.charAt(i) - '0', j - i});
            i = j;
        }

        int bestGain = 0;
        for (int idx = 0; idx < segs.size(); idx++) {
            if (segs.get(idx)[0] == 1) { // '1' 段
                int onesLen = segs.get(idx)[1];
                int leftZeros = (idx > 0 && segs.get(idx - 1)[0] == 0) ? segs.get(idx - 1)[1] : 0;
                int rightZeros = (idx + 1 < segs.size() && segs.get(idx + 1)[0] == 0) ? segs.get(idx + 1)[1] : 0;
                int gain = Math.max(leftZeros, rightZeros) - onesLen;
                bestGain = Math.max(bestGain, gain);
            }
        }

        return totalOnes + Math.max(0, bestGain);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 分段后枚举每个 '1' 段及其相邻 '0' 段
2. 净变化 = max(左 '0' 段, 右 '0' 段) - '1' 段长度
3. 若净变化为负（操作不划算），取 max(0, bestGain)
