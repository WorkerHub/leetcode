## 题目描述

网格中 0=空，1=新鲜橘子，2=腐烂橘子。每分钟腐烂橘子四方向感染相邻新鲜橘子。返回所有橘子腐烂的最少分钟数，不可能则返回 -1。

**示例：**
```
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

## 解题思路

多源 BFS：将所有腐烂橘子作为起点同时入队，层序扩展，记录层数即为时间。

## Java 代码实现

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> queue = new LinkedList<>();
        int freshCount = 0;

        // 初始化：找所有腐烂橘子和新鲜橘子数
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    freshCount++;
                }
            }
        }

        if (freshCount == 0) return 0;

        int minutes = 0;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!queue.isEmpty()) {
            int size = queue.size();
            boolean rotted = false;

            for (int k = 0; k < size; k++) {
                int[] pos = queue.poll();
                for (int[] d : dirs) {
                    int ni = pos[0] + d[0], nj = pos[1] + d[1];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                        grid[ni][nj] = 2;
                        freshCount--;
                        queue.offer(new int[]{ni, nj});
                        rotted = true;
                    }
                }
            }

            if (rotted) minutes++;
        }

        return freshCount == 0 ? minutes : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. **多源 BFS**：所有腐烂橘子同时开始扩散
2. **层序遍历**：每层对应一分钟
3. **计数检查**：最终检查是否还有新鲜橘子
