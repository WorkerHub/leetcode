## 题目描述

`n` 个孩子站成一排。给你一个整数数组 `ratings` 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

- 每个孩子至少分配到 `1` 个糖果。
- 相邻两个孩子评分更高的孩子会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的**最少糖果数目**。

**示例 1：**
```
输入：ratings = [1,0,2]
输出：5
解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。
```

**示例 2：**
```
输入：ratings = [1,2,2]
输出：4
解释：你可以分别给第一个、第二个、第三个孩子分发 1、2、1 颗糖果。
     第三个孩子只得到 1 颗糖果，这满足题面中的两个条件。
```

**提示：**
- `n == ratings.length`
- `1 <= n <= 2 * 10^4`
- `0 <= ratings[i] <= 2 * 10^4`

## 解题思路

这道题是一道经典的贪心算法问题，关键在于如何同时满足左右两个方向的约束条件。

**核心思想：**
1. 我们需要保证每个孩子的糖果数量同时满足：
   - 如果比左边孩子评分高，糖果要比左边多
   - 如果比右边孩子评分高，糖果要比右边多

2. 贪心策略：两次遍历
   - **第一次从左到右**：保证如果 `ratings[i] > ratings[i-1]`，则 `candy[i] > candy[i-1]`
   - **第二次从右到左**：保证如果 `ratings[i] > ratings[i+1]`，则 `candy[i] > candy[i+1]`
   - 最终每个位置取两次遍历中的较大值

3. 为什么这样是最优的？
   - 初始化每个人都给 1 个糖果（最少）
   - 从左到右遍历时，只关注左边的约束，采用贪心策略：如果需要增加，就增加到刚好比左边多 1
   - 从右到左遍历时，只关注右边的约束，但要保证不破坏左边的约束，所以取 max

## Java 代码实现

### 方法一：两次遍历（推荐）

```java
class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        if (n == 0) return 0;
        
        // 初始化每个孩子都有 1 个糖果
        int[] candies = new int[n];
        Arrays.fill(candies, 1);
        
        // 第一次遍历：从左到右，保证右边评分高的比左边多
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }
        
        // 第二次遍历：从右到左，保证左边评分高的比右边多
        // 同时要保持第一次遍历的结果，所以取 max
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(candies[i], candies[i + 1] + 1);
            }
        }
        
        // 返回总糖果数
        int total = 0;
        for (int candy : candies) {
            total += candy;
        }
        return total;
    }
}
```

### 方法二：一次遍历（进阶优化）

```java
class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        if (n == 0) return 0;
        
        int total = 1; // 第一个孩子至少 1 个糖果
        int inc = 1;   // 递增序列长度
        int dec = 0;   // 递减序列长度
        int pre = 1;   // 前一个孩子的糖果数
        
        for (int i = 1; i < n; i++) {
            if (ratings[i] >= ratings[i - 1]) {
                // 递增或相等的情况
                dec = 0;
                if (ratings[i] == ratings[i - 1]) {
                    pre = 1;  // 相等时重置为 1
                } else {
                    pre += 1; // 递增时加 1
                }
                total += pre;
                inc = pre;
            } else {
                // 递减的情况
                dec++;
                if (dec == inc) {
                    // 递减长度等于之前递增长度，需要给峰值加 1
                    dec++;
                }
                total += dec;
                pre = 1;
            }
        }
        
        return total;
    }
}
```

## 复杂度分析

### 方法一：两次遍历
- **时间复杂度**：O(n)，需要遍历数组两次
- **空间复杂度**：O(n)，需要额外的数组存储每个孩子的糖果数

### 方法二：一次遍历
- **时间复杂度**：O(n)，只需遍历一次
- **空间复杂度**：O(1)，只使用常数个变量

## 图解示例

以 `ratings = [1,0,2]` 为例：

```
初始状态：
ratings: [1, 0, 2]
candies: [1, 1, 1]

第一次遍历（从左到右）：
i=1: ratings[1]=0 < ratings[0]=1，不变
     candies: [1, 1, 1]
i=2: ratings[2]=2 > ratings[1]=0，candies[2] = candies[1] + 1 = 2
     candies: [1, 1, 2]

第二次遍历（从右到左）：
i=1: ratings[1]=0 < ratings[2]=2，不变
     candies: [1, 1, 2]
i=0: ratings[0]=1 > ratings[1]=0，candies[0] = max(1, 1+1) = 2
     candies: [2, 1, 2]

结果：2 + 1 + 2 = 5
```

## 关键点总结

1. **贪心策略的应用**：分别从左右两个方向考虑约束条件，最后取最大值
2. **两次遍历的必要性**：一次遍历无法同时满足左右两个方向的约束
3. **初始化为 1**：每个孩子至少有 1 个糖果，这是贪心的基础
4. **取 max 的原因**：第二次遍历时要保证不破坏第一次遍历的结果
5. **边界处理**：注意第一个和最后一个孩子的特殊情况

## 易错点

1. **只遍历一次**：容易忽略需要同时满足左右约束的要求
2. **相等评分的处理**：评分相等时，糖果数可以不同，只需满足至少为 1
3. **第二次遍历的更新方式**：必须使用 `Math.max(candies[i], candies[i+1] + 1)`，不能直接赋值
4. **遍历方向**：第二次遍历必须从右到左
5. **边界条件**：空数组或单个元素的情况
