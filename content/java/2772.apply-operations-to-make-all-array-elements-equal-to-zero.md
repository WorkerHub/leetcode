## 题目描述

给你整数数组 `nums` 和正整数 `k`，可以选任意大小为 `k` 的子数组将所有元素减 1，返回是否能使所有元素等于 0。

## Java 代码实现

```java
class Solution {
    public boolean checkArray(int[] nums, int k) {
        int n = nums.length;
        int dec = 0;  // 当前累积减少量
        int[] diff = new int[n + 1];  // 差分数组
        for (int i = 0; i < n; i++) {
            dec += diff[i];
            int remaining = nums[i] - dec;
            if (remaining < 0) return false;  // 过度减少
            if (remaining > 0) {
                // 需要从 i 开始操作 remaining 次，子数组 [i..i+k-1]
                if (i + k > n) return false;
                dec += remaining;
                diff[i + k] -= remaining;  // 在 i+k 处取消这些操作
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：遇到不足的位置立即补充操作（从当前位置开始）
2. 差分数组高效维护累积操作量
3. 子数组结束位置超出边界时返回 false
