## 题目描述

给你字符串 `message` 和整数 `limit`，将消息分割成若干部分，每部分末尾追加 `<i/n>` 后缀，返回分割后的字符串数组，若无法分割返回空数组。

## 解题思路

二分枚举总份数 `k`：对每个 `k`，计算每个 `<i/k>` 后缀长度，统计所有部分可用字符总数，判断是否 >= len(message)。找到最小可行 `k` 后按贪心方式构造答案。

## Java 代码实现

```java
class Solution {
    public String[] splitMessage(String message, int limit) {
        int msgLen = message.length();
        int kLen = 0;   // len(str(k))
        int lo = 1, ans = -1;

        // 枚举 k，最多不超过 msgLen（每部分至少1字符）
        for (int k = 1; k <= msgLen; k++) {
            kLen = String.valueOf(k).length();
            // 计算 k 个部分中每部分后缀 <i/k> 的总长度
            // 后缀格式：<i/k>，长度 = len(i) + kLen + 3（< / >）
            long suffixTotal = 0;
            for (int d = 1; d <= kLen; d++) {
                // 位数为 d 的数字范围
                int from = (int) Math.pow(10, d - 1);
                int to = Math.min(k, (int) Math.pow(10, d) - 1);
                if (from > k) break;
                suffixTotal += (long)(to - from + 1) * (d + kLen + 3);
            }
            // 可用字符总数
            long available = (long) k * limit - suffixTotal;
            if (available >= msgLen) {
                ans = k;
                break;
            }
        }

        if (ans == -1) return new String[0];

        String[] result = new String[ans];
        String kStr = String.valueOf(ans);
        int idx = 0; // message 当前指针
        for (int i = 1; i <= ans; i++) {
            String suffix = "<" + i + "/" + ans + ">";
            int avail = limit - suffix.length();
            result[i - 1] = message.substring(idx, Math.min(idx + avail, msgLen)) + suffix;
            idx += avail;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log n)，枚举 k 时内层按位数统计为 O(log k)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举总份数 k，用位数分组统计后缀总长度，判断可行性
2. 后缀 `<i/k>` 长度 = len(i) + len(k) + 3
3. 找到最小可行 k 后，按贪心方式逐段填充消息
