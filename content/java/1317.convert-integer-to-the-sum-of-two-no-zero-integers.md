## 题目描述

**无零整数**是十进制表示中**不含任何 0** 的正整数。

给你一个整数 `n`，请你返回一个**由两个整数组成的列表** `[A, B]`，满足：

- `A` 和 `B` 都是无零整数
- `A + B = n`

题目保证至少存在一个有效的解。如果存在多个有效解，返回任意一个均可。

**示例 1：**

```
输入：n = 2
输出：[1,1]
解释：A = 1, B = 1。A + B = 2，且 A 和 B 都不含 0。
```

**示例 2：**

```
输入：n = 11
输出：[2,9]
```

**示例 3：**

```
输入：n = 10000
输出：[1,9999]
```

**示例 4：**

```
输入：n = 69
输出：[1,68]
```

**提示：**

- `2 <= n <= 10^4`

## 解题思路

**暴力枚举**

遍历 A 从 1 到 n-1，设 B = n - A，检查 A 和 B 是否都是无零整数（即十进制表示中不含 '0'）。找到第一个满足条件的 A 即可返回。

**判断是否为无零整数：**

将数字转换为字符串，检查是否包含字符 '0'。

由于 `n <= 10^4`，枚举最多 10^4 次，效率足够。

## Java 代码实现

### 方法一：枚举（推荐）

```java
class Solution {
    public int[] getNoZeroIntegers(int n) {
        for (int A = 1; A < n; A++) {
            int B = n - A;
            if (isNoZero(A) && isNoZero(B)) {
                return new int[]{A, B};
            }
        }
        // 题目保证有解，不会到达此处
        return new int[]{};
    }
    
    // 判断整数 x 是否不含数字 0
    private boolean isNoZero(int x) {
        while (x > 0) {
            if (x % 10 == 0) return false;
            x /= 10;
        }
        return true;
    }
}
```

### 方法二：使用字符串判断

```java
class Solution {
    public int[] getNoZeroIntegers(int n) {
        for (int A = 1; A < n; A++) {
            int B = n - A;
            // 将数字转为字符串，检查是否包含 '0'
            if (!String.valueOf(A).contains("0") && !String.valueOf(B).contains("0")) {
                return new int[]{A, B};
            }
        }
        return new int[]{};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * log n)，枚举 O(n) 次，每次检查 O(log n)
- **空间复杂度**：O(log n)，字符串转换的临时空间

由于 n <= 10^4，实际运行非常快，几乎瞬间完成。

## 关键点总结

1. 无零整数的判断：逐位检查是否含 0（x % 10 == 0）
2. 枚举 A 从 1 到 n-1，B = n - A，找到第一个满足条件的对即可
3. 题目保证有解，不需要处理无解情况
4. Java 中也可以用 `String.valueOf(x).contains("0")` 简化判断

## 易错点

1. **A 和 B 都要检查**：有时只检查了 A 而忘记检查 B
2. **B 的范围**：B = n - A，当 A 为 1 时 B = n-1，都在正整数范围内
3. **逐位检查时注意终止条件**：`while (x > 0)` 而不是 `while (x >= 0)`
