## 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的中位数。

算法的时间复杂度应该为 O(log(m+n))。

**示例 1：**
```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3]，中位数 2
```

**示例 2：**
```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4]，中位数 (2 + 3) / 2 = 2.5
```

## 解题思路

### 方法一：合并数组（简单但不满足时间要求）
- 合并两个有序数组，然后找中位数
- 时间复杂度 O(m+n)，不满足题目要求

### 方法二：二分查找（推荐）
要达到 O(log(m+n)) 的时间复杂度，需要使用二分查找。

**核心思想：**
- 中位数的本质是将数组分成左右两部分，左边所有元素 <= 右边所有元素
- 我们需要找到一个分割点，使得：
  - 左半部分长度 = 右半部分长度（或差1）
  - 左半部分最大值 <= 右半部分最小值

**具体步骤：**
1. 在较短的数组上进行二分查找（优化性能）
2. 根据一个数组的分割点，计算另一个数组的分割点
3. 检查分割是否有效
4. 根据检查结果调整二分查找范围

## Java 代码实现

### 方法一：二分查找（最优解）（推荐）

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 确保 nums1 是较短的数组，减少二分查找次数
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }
        
        int m = nums1.length, n = nums2.length;
        // 左半部分的总长度
        int totalLeft = (m + n + 1) / 2;
        
        // 在 nums1 上进行二分查找
        int left = 0, right = m;
        
        while (left < right) {
            // nums1 的分割点
            int i = left + (right - left + 1) / 2;
            // nums2 的分割点
            int j = totalLeft - i;
            
            // 如果 nums1[i-1] > nums2[j]，说明 i 太大了
            if (nums1[i - 1] > nums2[j]) {
                right = i - 1;
            } else {
                left = i;
            }
        }
        
        int i = left;
        int j = totalLeft - i;
        
        // 处理边界情况
        int nums1LeftMax = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
        int nums1RightMin = (i == m) ? Integer.MAX_VALUE : nums1[i];
        int nums2LeftMax = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
        int nums2RightMin = (j == n) ? Integer.MAX_VALUE : nums2[j];
        
        // 计算中位数
        if ((m + n) % 2 == 1) {
            // 总长度为奇数
            return Math.max(nums1LeftMax, nums2LeftMax);
        } else {
            // 总长度为偶数
            return (Math.max(nums1LeftMax, nums2LeftMax) +
                    Math.min(nums1RightMin, nums2RightMin)) / 2.0;
        }
    }
}
```

### 方法二：合并数组（简单解法）

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[] merged = new int[m + n];
        int i = 0, j = 0, k = 0;
        
        while (i < m && j < n) {
            if (nums1[i] <= nums2[j]) {
                merged[k++] = nums1[i++];
            } else {
                merged[k++] = nums2[j++];
            }
        }
        
        while (i < m) merged[k++] = nums1[i++];
        while (j < n) merged[k++] = nums2[j++];
        
        int total = m + n;
        if (total % 2 == 1) {
            return merged[total / 2];
        } else {
            return (merged[total / 2 - 1] + merged[total / 2]) / 2.0;
        }
    }
}
```

### 方法三：第K小元素

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int total = nums1.length + nums2.length;
        if (total % 2 == 1) {
            return getKthElement(nums1, nums2, total / 2 + 1);
        } else {
            return (getKthElement(nums1, nums2, total / 2) +
                    getKthElement(nums1, nums2, total / 2 + 1)) / 2.0;
        }
    }
    
    private int getKthElement(int[] nums1, int[] nums2, int k) {
        int i = 0, j = 0;
        while (true) {
            if (i == nums1.length) return nums2[j + k - 1];
            if (j == nums2.length) return nums1[i + k - 1];
            if (k == 1) return Math.min(nums1[i], nums2[j]);
            
            // 每次排除 k/2 个元素
            int newI = Math.min(i + k / 2 - 1, nums1.length - 1);
            int newJ = Math.min(j + k / 2 - 1, nums2.length - 1);
            
            if (nums1[newI] <= nums2[newJ]) {
                k -= newI - i + 1;
                i = newI + 1;
            } else {
                k -= newJ - j + 1;
                j = newJ + 1;
            }
        }
    }
}
```

## 复杂度分析

### 二分查找方法
- **时间复杂度**：O(log(min(m, n)))，在较短数组上二分查找
- **空间复杂度**：O(1)

### 合并数组方法
- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)

### 第K小元素方法
- **时间复杂度**：O(log(m + n))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分查找是关键**：要达到 O(log) 级别，必须使用二分
2. **在短数组上查找**：减少二分次数，提高效率
3. **分割点的计算**：理解左右两部分长度的关系
4. **边界处理**：分割点在数组边界时需要特殊处理
5. **奇偶数处理**：总长度为奇数和偶数时，中位数计算方式不同

## 难点解析

这道题是 Hard 难度，主要难点在于：
- 理解中位数的本质是数组分割
- 二分查找的边界条件较复杂
- 需要处理多种边界情况

建议初学者先掌握合并数组的方法，再尝试理解二分查找的解法。
