## 题目描述

有 `n` 台电脑，密码为 `complexity[i]`，电脑 0 默认解锁，解锁电脑 `i` 需要先解锁某台密码**严格小于** `complexity[i]` 的电脑，求合法解锁排列数，对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int countPermutations(int[] complexity) {
        int MOD = 1_000_000_007;
        int n = complexity.length;

        // 电脑 0 必须是密码最小的
        int minVal = complexity[0];
        for (int c : complexity) {
            if (c < minVal) return 0;
        }

        // 排序其余密码，按升序排列
        int[] others = Arrays.copyOfRange(complexity, 1, n);
        Arrays.sort(others);

        long result = 1;
        for (int i = 0; i < others.length; i++) {
            if (others[i] <= minVal) return 0;  // 无法被解锁（需要严格小于）
            // 前 i+1 台（电脑0 + 已处理的 i 台）密码严格小于当前
            result = result * (i + 1) % MOD;
        }
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 电脑 0 必须是密码最小的，否则答案为 0
2. 排序后，第 i 台电脑（按密码升序）有 i 个合法前驱可以选择
3. 答案 = `1 * 2 * ... * (n-1)` = `(n-1)!`（当所有密码合法唯一时）
