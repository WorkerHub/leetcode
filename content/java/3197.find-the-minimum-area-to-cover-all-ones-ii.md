## 题目描述

给你二进制矩阵 `grid`（最大 30×30），用 3 个不重叠矩形覆盖所有 1，返回 3 个矩形面积之和的最小值。

## 解题思路

枚举切分方案：(1) 横切两刀（3 行块），(2) 竖切两刀（3 列块），(3) 先横再竖（上块竖切 / 下块竖切）。对每种方案中每个子区域，找包含所有 1 的最小矩形面积，取所有方案的最小总面积。

## Java 代码实现

```java
class Solution {
    int[][] grid;
    int m, n;

    public int minimumSum(int[][] grid) {
        this.grid = grid;
        this.m = grid.length;
        this.n = grid[0].length;
        int ans = Integer.MAX_VALUE;

        // 方案1：横切两刀
        for (int i1 = 1; i1 < m; i1++) {
            for (int i2 = i1 + 1; i2 < m; i2++) {
                ans = Math.min(ans, minRect(0, i1, 0, n) + minRect(i1, i2, 0, n) + minRect(i2, m, 0, n));
            }
        }
        // 方案2：竖切两刀
        for (int j1 = 1; j1 < n; j1++) {
            for (int j2 = j1 + 1; j2 < n; j2++) {
                ans = Math.min(ans, minRect(0, m, 0, j1) + minRect(0, m, j1, j2) + minRect(0, m, j2, n));
            }
        }
        // 方案3：先横后竖（上+下竖切/左/右）
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 上块竖切：[0,i) 分成左右，下块不切
                ans = Math.min(ans, minRect(0, i, 0, j) + minRect(0, i, j, n) + minRect(i, m, 0, n));
                // 下块竖切：[i,m) 分成左右，上块不切
                ans = Math.min(ans, minRect(0, i, 0, n) + minRect(i, m, 0, j) + minRect(i, m, j, n));
            }
        }
        return ans;
    }

    // 子矩阵 [r1,r2) x [c1,c2) 中包含所有 1 的最小矩形面积
    private int minRect(int r1, int r2, int c1, int c2) {
        int minR = m, maxR = -1, minC = n, maxC = -1;
        for (int i = r1; i < r2; i++) {
            for (int j = c1; j < c2; j++) {
                if (grid[i][j] == 1) {
                    minR = Math.min(minR, i); maxR = Math.max(maxR, i);
                    minC = Math.min(minC, j); maxC = Math.max(maxC, j);
                }
            }
        }
        return maxR == -1 ? 0 : (maxR - minR + 1) * (maxC - minC + 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m^2 × n^2)（枚举切法），m, n ≤ 30 可行
- **空间复杂度**：O(1)

## 关键点总结

1. 3 个矩形的切分方式共 4 种：横横、竖竖、上竖切、下竖切
2. 对每个子区域求包含所有 1 的最小矩形（若无 1 则面积为 0）
3. 矩阵小（≤30），暴力枚举所有切法可行
