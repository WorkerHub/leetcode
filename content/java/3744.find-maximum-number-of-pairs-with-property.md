## 题目描述

给定整数数组 `nums`，找出最多有多少对 `(i, j)`（`i < j`），满足 `nums[i] + nums[j]` 是完全平方数。

## Java 代码实现

```java
class Solution {
    public int countPairs(int[] nums) {
        int n = nums.length;
        int count = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int s = nums[i] + nums[j];
                int sq = (int) Math.sqrt(s);
                if (sq * sq == s) count++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²)，枚举所有对
- 空间复杂度：O(1)

## 关键点总结

1. 数据量小（n ≤ 100），O(n²) 完全可行
2. 完全平方数判断：`(int)sqrt(s) * (int)sqrt(s) == s`
3. 注意浮点误差：用整数乘法验证，不直接比较浮点数
