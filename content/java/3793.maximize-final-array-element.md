## 题目描述

给定整数数组 `nums`，每次可以选择相邻两个元素，删除较小的那个，求最终留下的最后一个元素的最大值。

## Java 代码实现

```java
class Solution {
    public int maxElement(int[] nums) {
        // 每次删除相邻两者中较小的，全局最大值可以打败任何相邻元素，最终必然存活
        int max = nums[0];
        for (int x : nums) max = Math.max(max, x);
        return max;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每次保留相邻元素中较大的，全局最大值始终能击败相邻元素
2. 答案即数组最大值，无需模拟操作过程
