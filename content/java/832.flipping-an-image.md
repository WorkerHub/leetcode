## 题目描述

给定 n×n 二进制矩阵，先水平翻转（行逆序），再反转（0变1，1变0），返回结果。

**示例：**
```
输入：image = [[1,1,0],[1,0,1],[0,0,0]]
输出：[[1,0,0],[0,1,0],[1,1,1]]
```

## 解题思路

双指针一次遍历：对称位置交换并取反。用 ^1 实现 0/1 翻转。

## Java 代码实现

```java
class Solution {
    public int[][] flipAndInvertImage(int[][] image) {
        int n = image.length;
        for (int[] row : image) {
            int left = 0, right = n - 1;
            while (left <= right) {
                // 交换并取反
                int temp = row[left] ^ 1;
                row[left] = row[right] ^ 1;
                row[right] = temp;
                left++;
                right--;
            }
        }
        return image;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)，原地修改

## 关键点总结

1. **异或取反**：x ^ 1 实现 0/1 翻转
2. **双指针**：对称位置交换
3. **合并操作**：翻转 + 反转一步完成
