## 题目描述

给你禁用数组 `banned`、整数 `n` 和 `maxSum`，从 `[1, n]` 中选尽量多的整数（每个最多选一次，不在 banned 中），使总和 <= maxSum，返回最多能选的数目。

## 解题思路

贪心：从 1 到 n 从小到大依次选取不在 banned 中的整数，累加直到超过 maxSum 为止。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int maxCount(int[] banned, int n, int maxSum) {
        Set<Integer> bannedSet = new HashSet<>();
        for (int b : banned) bannedSet.add(b);

        int count = 0;
        long total = 0;
        for (int num = 1; num <= n; num++) {
            if (bannedSet.contains(num)) continue;
            if (total + num > maxSum) break;
            total += num;
            count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + |banned|)
- **空间复杂度**：O(|banned|)

## 关键点总结

1. 贪心选最小合法整数，可以选更多个
2. 从 1 到 n 顺序扫描，跳过 banned 中的数
3. 累计和超过 maxSum 时立即停止
