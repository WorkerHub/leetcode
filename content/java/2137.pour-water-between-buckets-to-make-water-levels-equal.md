## 题目描述

给定桶中水量数组buckets和损耗百分比loss，每次转移会损失loss%的水。求所有桶水位相等时的最大水位。

## 解题思路

二分目标水位：超出水位的桶供水（有效量=超出量*(1-loss/100)），低于水位的桶需水。供给>=需求则可行。

## Java 代码实现

```java
class Solution {
    public double equalizeWater(int[] buckets, int loss) {
        double retain = (100.0 - loss) / 100.0;
        double lo = 0, hi = 0;
        for (int b : buckets) hi = Math.max(hi, b);
        
        for (int iter = 0; iter < 100; iter++) {
            double mid = (lo + hi) / 2;
            double supply = 0, demand = 0;
            for (int b : buckets) {
                if (b > mid) supply += (b - mid) * retain;
                else demand += mid - b;
            }
            if (supply >= demand - 1e-9) {
                lo = mid;
            } else {
                hi = mid;
            }
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * log(max/eps))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分目标水位**：判断供给是否满足需求
2. **损耗处理**：有效供水 = 超出量 * retain
3. **浮点二分**：固定迭代次数更稳定
