## 题目描述

有 n 枚不规则硬币，prob[i] 为第 i 枚正面朝上的概率。每枚抛一次，求恰好有 target 枚正面朝上的概率。

**示例：**
```
输入：prob = [0.5,0.5,0.5,0.5,0.5], target = 0
输出：0.03125
```

## 解题思路

DP：dp[j] = 前 i 枚硬币中恰好 j 枚正面朝上的概率。转移：dp[j] = dp[j-1] × prob[i] + dp[j] × (1-prob[i])。倒序更新可优化为一维。

## Java 代码实现

```java
class Solution {
    public double probabilityOfHeads(double[] prob, int target) {
        int n = prob.length;
        // dp[j] = 恰好 j 枚正面朝上的概率
        double[] dp = new double[target + 1];
        dp[0] = 1.0;
        
        for (int i = 0; i < n; i++) {
            // 倒序更新避免覆盖
            for (int j = Math.min(i + 1, target); j >= 1; j--) {
                dp[j] = dp[j] * (1 - prob[i]) + dp[j - 1] * prob[i];
            }
            dp[0] *= (1 - prob[i]);
        }
        
        return dp[target];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × target)
- **空间复杂度**：O(target)

## 关键点总结

1. **概率 DP**：类似 0-1 背包，每枚硬币选择正面或反面
2. **倒序更新**：一维 DP 中避免同一轮内覆盖
3. **dp[0] 特殊处理**：全反面的概率需单独更新
4. **浮点运算**：直接用 double，精度在 10^-5 内即可
