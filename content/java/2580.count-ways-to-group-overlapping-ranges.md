## 题目描述

给你区间数组 `ranges`，将所有区间分成两组，同组内的区间不能重叠或相接，返回合法的分组方案数（模 10^9+7）。

## 解题思路

排序后合并区间，统计连通分量数 k（合并后的区间数）；每个连通分量可独立选组，答案为 2^k。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int countWays(int[][] ranges) {
        Arrays.sort(ranges, (a, b) -> a[0] - b[0]);
        int groups = 0, curEnd = -1;
        for (int[] r : ranges) {
            if (r[0] > curEnd + 1) {
                groups++; // 新的连通分量
                curEnd = r[1];
            } else {
                curEnd = Math.max(curEnd, r[1]);
            }
        }
        return pow(2, groups);
    }

    private long pow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 重叠或相接（`end+1 == start`）的区间必须在同一组
2. 连通分量数 k = 合并后区间数，答案 = 2^k
3. 快速幂计算 2^k 取模
