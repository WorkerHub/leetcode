## 题目描述

交互题：隐藏数组有唯一最大值，用 compareSub 比较两段子数组和，最多 20 次查询找到最大值下标。

## 解题思路

二分查找：每次将区间对半分，比较左右两半的和，最大值在和更大的那半。

## Java 代码实现

```java
class Solution {
    public int getIndex(ArrayReader reader) {
        int lo = 0, hi = reader.length() - 1;
        
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            int len = hi - lo + 1;
            
            if (len % 2 == 0) {
                // 偶数长度：左半 [lo, mid]，右半 [mid+1, hi]
                int cmp = reader.compareSub(lo, mid, mid + 1, hi);
                if (cmp == 1) hi = mid;
                else lo = mid + 1;
            } else {
                // 奇数长度：左半 [lo, mid-1]，右半 [mid+1, hi]
                int cmp = reader.compareSub(lo, mid - 1, mid + 1, hi);
                if (cmp == 1) hi = mid - 1;
                else if (cmp == -1) lo = mid + 1;
                else { lo = mid; hi = mid; } // 中间就是
            }
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n) 次查询
- **空间复杂度**：O(1)

## 关键点总结

1. **二分搜索**：每次缩小一半
2. **奇偶处理**：奇数长度需处理中间元素
3. **查询次数**：log2(n) ≤ 20
