## 题目描述

给定整数数组 asteroids 表示同一行的小行星，绝对值为大小，正负为方向（正向右，负向左）。找出碰撞后剩下的所有小行星。

**示例：**
```
输入：asteroids = [5,10,-5]
输出：[5,10]
```

## 解题思路

栈模拟碰撞：只有栈顶向右（正数）且当前向左（负数）才会碰撞。根据大小决定谁爆炸。

## Java 代码实现

```java
class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (int ast : asteroids) {
            boolean alive = true;
            // 当前向左且栈顶向右才碰撞
            while (alive && ast < 0 && !stack.isEmpty() && stack.peek() > 0) {
                if (stack.peek() < -ast) {
                    // 栈顶爆炸
                    stack.pop();
                } else if (stack.peek() == -ast) {
                    // 都爆炸
                    stack.pop();
                    alive = false;
                } else {
                    // 当前爆炸
                    alive = false;
                }
            }
            if (alive) {
                stack.push(ast);
            }
        }

        int[] result = new int[stack.size()];
        for (int i = result.length - 1; i >= 0; i--) {
            result[i] = stack.pop();
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **碰撞条件**：栈顶 > 0 且当前 < 0
2. **三种结果**：栈顶爆炸、都爆炸、当前爆炸
3. **while 循环**：一个小行星可能连续碰撞多个
