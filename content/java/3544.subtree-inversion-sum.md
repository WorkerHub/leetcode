## 题目描述

给定 n 个节点的树（根为 0），每个节点有值（可负）。每次操作选某节点将其整个子树的值取反。最多执行 k 次，求节点值总和的最大值。

## 解题思路

贪心：DFS 后序遍历计算每个子树的和，将所有负子树和收集起来排序，每次取绝对值最大的负子树和取反（最多 k 次），总和增量为 -2 * subSum。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] adj;
    private int[] nums;
    private List<Long> negSubs;

    @SuppressWarnings("unchecked")
    public long subtreeInversionSum(int[] nums, int[][] edges, int k) {
        int n = nums.length;
        this.nums = nums;
        this.negSubs = new ArrayList<>();
        adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) { adj[e[0]].add(e[1]); adj[e[1]].add(e[0]); }

        long totalSum = dfs(0, -1);

        // 贪心：取最负的子树和取反
        negSubs.sort(Comparator.naturalOrder()); // 最小（最负）在前
        for (int i = 0; i < Math.min(k, negSubs.size()); i++) {
            long s = negSubs.get(i);
            if (s >= 0) break;
            totalSum -= 2 * s; // 取反改变 -2*s（负数）
        }
        return totalSum;
    }

    private long dfs(int v, int parent) {
        long s = nums[v];
        for (int u : adj[v]) {
            if (u != parent) s += dfs(u, v);
        }
        if (s < 0) negSubs.add(s);
        return s;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS + 排序
- 空间复杂度：O(n)

## 关键点总结

1. 子树取反等价于该子树和取反，总和变化 = -2 * subSum
2. 贪心：优先取反绝对值最大的负子树，收益最大
3. 最多 k 次，负子树用完即停
