## 题目描述

给你按顺序插入 BST 的节点值数组 `order`，返回插入所有节点后 BST 的深度（根节点深度为 1）。

## 解题思路

新节点的父节点必定是已插入节点中与其值最接近的前驱或后继，深度为两者中较大深度 +1。用 TreeMap 维护已插入节点及其深度，以哨兵值 0 和 n+1（深度为 0）避免边界判断。

## Java 代码实现

```java
import java.util.TreeMap;

class Solution {
    public int maxDepthBST(int[] order) {
        int n = order.length;
        // key=节点值, value=深度；哨兵值 0 和 n+1 深度为 0
        TreeMap<Integer, Integer> depthMap = new TreeMap<>();
        depthMap.put(0, 0);
        depthMap.put(n + 1, 0);

        int maxDepth = 0;
        for (int num : order) {
            // 前驱（最大的小于 num 的已插入值）
            int pred = depthMap.floorKey(num - 1);
            // 后继（最小的大于 num 的已插入值）
            int succ = depthMap.ceilingKey(num + 1);
            // 当前节点深度 = 前驱/后继中较深的 + 1
            int d = Math.max(depthMap.get(pred), depthMap.get(succ)) + 1;
            depthMap.put(num, d);
            maxDepth = Math.max(maxDepth, d);
        }
        return maxDepth;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 新节点的父节点一定是已插入节点中的前驱或后继
2. 用 TreeMap 的 floorKey/ceilingKey 高效查找前驱后继
3. 哨兵值 0 和 n+1（深度为 0）避免边界特判
