## 题目描述

给定整数数组 `nums`，通过最少的相邻交换使奇偶元素交替排列，若无法实现返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minSwaps(int[] nums) {
        int n = nums.length;
        int oddCount = 0;
        for (int x : nums) if (x % 2 != 0) oddCount++;
        int evenCount = n - oddCount;

        if (Math.abs(oddCount - evenCount) > 1) return -1;

        long result = Long.MAX_VALUE;
        // 枚举两种目标模式
        if (oddCount >= evenCount) result = Math.min(result, calcCost(nums, true));
        if (evenCount >= oddCount) result = Math.min(result, calcCost(nums, false));

        return result == Long.MAX_VALUE ? -1 : result;
    }

    // 计算目标为 startWithOdd 模式的最少交换次数
    private long calcCost(int[] nums, boolean startWithOdd) {
        int n = nums.length;
        List<Integer> oddPos = new ArrayList<>();
        List<Integer> evenPos = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (nums[i] % 2 != 0) oddPos.add(i);
            else evenPos.add(i);
        }

        // 目标位置
        List<Integer> targetOdd = new ArrayList<>();
        List<Integer> targetEven = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((i % 2 == 0) == startWithOdd) targetOdd.add(i);
            else targetEven.add(i);
        }

        if (oddPos.size() != targetOdd.size() || evenPos.size() != targetEven.size())
            return Long.MAX_VALUE;

        // 贪心匹配：第 i 个奇数去第 i 个奇数目标位置
        long cost = 0;
        for (int i = 0; i < oddPos.size(); i++) cost += Math.abs(oddPos.get(i) - targetOdd.get(i));
        for (int i = 0; i < evenPos.size(); i++) cost += Math.abs(evenPos.get(i) - targetEven.get(i));
        return cost;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历两次
- 空间复杂度：O(n)

## 关键点总结

1. 奇偶数量差大于 1 时无解
2. 枚举两种目标模式（奇开头或偶开头），取最小代价
3. 贪心匹配：按原顺序将第 i 个奇数匹配到第 i 个奇数目标位置
