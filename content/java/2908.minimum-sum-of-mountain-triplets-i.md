## 题目描述

给你整数数组 nums，找满足 `i<j<k`、`nums[i]<nums[j]`、`nums[j]>nums[k]` 的山形三元组，返回 `nums[i]+nums[j]+nums[k]` 的最小值，不存在则返回 -1。数组长度 ≤ 50。

## 解题思路

数据范围极小（n ≤ 50），直接三重循环暴力枚举所有满足山形条件的 (i, j, k) 组合，取最小和。

## Java 代码实现

```java
class Solution {
    public int minimumSum(int[] nums) {
        int n = nums.length;
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[j] <= nums[i]) continue; // 不满足 nums[i] < nums[j]
                for (int k = j + 1; k < n; k++) {
                    if (nums[k] < nums[j]) { // 满足 nums[j] > nums[k]
                        ans = Math.min(ans, nums[i] + nums[j] + nums[k]);
                    }
                }
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)，三重循环枚举
- **空间复杂度**：O(1)

## 关键点总结

1. 山形三元组：中间元素是峰值，两侧元素严格小于它
2. 求最小和，因此希望两侧尽可能小
3. n ≤ 50 时暴力 O(n³) 完全可接受
