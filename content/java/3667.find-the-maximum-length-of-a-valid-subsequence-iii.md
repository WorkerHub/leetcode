## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，找到最长的子序列，使得相邻元素之和模 `k` 的值相同。返回该子序列的最大长度。

## 解题思路

DP：枚举目标余数 `r`（0 到 k-1）。`dp[v]` 表示相邻和模 k = r、以余数 v 结尾的最长子序列。对新元素 x，其余数为 `x % k`，可接在余数为 `(r - x%k + k) % k` 的序列后面。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums, int k) {
        int ans = 1;
        for (int r = 0; r < k; r++) {
            // dp[v] = 目标余数r，以余数v结尾的最长子序列
            int[] dp = new int[k];
            for (int x : nums) {
                int xmod = x % k;
                int prev = (r - xmod + k) % k;
                dp[xmod] = Math.max(dp[xmod], dp[prev] + 1);
                ans = Math.max(ans, dp[xmod]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 枚举目标余数 r，分别计算最优子序列
2. 新元素 x 接在余数为 `(r - x%k + k) % k` 的序列后
3. 所有目标余数中取最大值
