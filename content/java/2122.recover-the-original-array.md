## 题目描述

Alice将原数组每个元素±k得到lower和higher后打乱合并。给定合并数组changed，恢复原数组。

## 解题思路

排序后最小值必属于lower。枚举最小值的配对（得到k），验证时用计数器贪心从小到大匹配x和x+2k。

## Java 代码实现

```java
class Solution {
    public int[] recoverArray(int[] changed) {
        Arrays.sort(changed);
        int n = changed.length / 2;
        
        // 枚举changed[0]的配对元素
        for (int i = 1; i < changed.length; i++) {
            int diff = changed[i] - changed[0];
            if (diff == 0 || diff % 2 != 0) continue;
            int k = diff / 2;
            int[] res = tryK(changed, k);
            if (res.length > 0) return res;
        }
        return new int[0];
    }
    
    private int[] tryK(int[] changed, int k) {
        int n = changed.length / 2;
        TreeMap<Integer, Integer> cnt = new TreeMap<>();
        for (int x : changed) cnt.merge(x, 1, Integer::sum);
        
        int[] result = new int[n];
        int idx = 0;
        
        for (int x : changed) {
            if (cnt.getOrDefault(x, 0) == 0) continue;
            if (cnt.getOrDefault(x + 2 * k, 0) == 0) return new int[0];
            result[idx++] = x + k;
            cnt.merge(x, -1, Integer::sum);
            cnt.merge(x + 2 * k, -1, Integer::sum);
        }
        return idx == n ? result : new int[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2) 最差
- **空间复杂度**：O(N)

## 关键点总结

1. **最小值属于lower**：排序后changed[0]一定是某个lower值
2. **枚举k**：changed[0]的配对确定k，差必须为偶数
3. **贪心验证**：从小到大匹配x和x+2k
