## 题目描述

给定一个平衡括号字符串 s，按下述规则计算该字符串的分数：

- `()` 得 1 分。
- `AB` 得 `A + B` 分，其中 A 和 B 是平衡括号字符串。
- `(A)` 得 `2 * A` 分，其中 A 是平衡括号字符串。

**示例 1：**
```
输入：s = "()"
输出：1
```

**示例 2：**
```
输入：s = "(())"
输出：2
```

**示例 3：**
```
输入：s = "()()"
输出：2
```

**示例 4：**
```
输入：s = "(()(()))"
输出：6
解释：
( () (()) )
= ( 1 + 2 )
= ( 3 )
= 6
```

**提示：**
- 2 <= s.length <= 50
- s 由且仅由 '(' 和 ')' 组成
- s 是一个平衡括号字符串

## 解题思路

这道题有多种解法，核心是理解括号的嵌套结构和得分规则。

**核心观察：**
1. `()` 基础分数是 1
2. 每增加一层嵌套，分数翻倍
3. 并列的括号对分数相加

**关键发现：**
- 只有 `()` 贡献基础分数 1
- 外层每多一个括号，分数 × 2
- 可以用深度来计算：`()` 在深度 d 时贡献 2^(d-1) 分

## Java 代码实现

### 方法一：栈模拟（推荐）

```java
class Solution {
    public int scoreOfParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0); // 栈底存储当前层的分数

        for (char c : s.toCharArray()) {
            if (c == '(') {
                // 遇到左括号，进入新的一层
                stack.push(0);
            } else {
                // 遇到右括号，计算当前层的分数
                int curr = stack.pop();
                // () 得 1 分，(A) 得 2*A 分
                int score = Math.max(2 * curr, 1);
                // 加到上一层
                stack.push(stack.pop() + score);
            }
        }

        return stack.pop();
    }
}
```

**代码说明：**
- 栈存储每一层的分数累加和
- `(` 入栈一个新层（0）
- `)` 计算当前层分数并加到上一层
- `Math.max(2 * curr, 1)` 处理 `()` 和 `(A)` 两种情况

### 方法二：深度计算（最优解）

```java
class Solution {
    public int scoreOfParentheses(String s) {
        int result = 0;
        int depth = 0; // 当前深度

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                depth++;
            } else {
                depth--;
                // 如果是 ()，贡献 2^depth 分
                if (s.charAt(i - 1) == '(') {
                    result += 1 << depth; // 2^depth 用位运算
                }
            }
        }

        return result;
    }
}
```

**代码说明：**
- 只有 `()` 贡献分数
- 深度为 d 时，`()` 贡献 2^d 分（使用位运算 `1 << depth`）
- 时间复杂度 O(n)，空间复杂度 O(1)

## 复杂度分析

### 方法一：栈模拟
- **时间复杂度**：O(n)，遍历一次字符串。
- **空间复杂度**：O(n)，栈的空间。

### 方法二：深度计算
- **时间复杂度**：O(n)。
- **空间复杂度**：O(1)，最优解。

## 图解示例

**示例**：`s = "(()(()))"`

```
字符串: ( ( ) ( ( ) ) )
深度:   1 2 1 2 3 2 1 0

分析:
1. 位置 2: () 深度 1 → 贡献 2^1 = 2
2. 位置 5: () 深度 2 → 贡献 2^2 = 4

总分: 2 + 4 = 6
```

**栈模拟过程**：
```
初始: stack = [0]

遇到 '(': [0, 0]
遇到 '(': [0, 0, 0]
遇到 ')': curr=0, score=1, [0, 1]
遇到 '(': [0, 1, 0]
遇到 '(': [0, 1, 0, 0]
遇到 ')': curr=0, score=1, [0, 1, 1]
遇到 ')': curr=1, score=2, [0, 3]
遇到 ')': curr=3, score=6, [6]

结果: 6
```

## 关键点总结

1. **深度理解**：只有 `()` 贡献基础分数，深度决定倍数
2. **栈的应用**：用栈模拟括号匹配和分数计算
3. **数学规律**：深度 d 的 `()` 贡献 2^d 分
4. **空间优化**：方法二只用 O(1) 空间
5. **位运算**：`1 << depth` 代替 `Math.pow(2, depth)`

## 易错点

1. **栈初始化**：`stack.push(0)` 需要一个底层元素存储总分

2. **分数计算**：`Math.max(2 * curr, 1)` 而不是简单的 `2 * curr`
   - `()` 是特殊情况，分数是 1

3. **深度判断**：只有遇到 `()` 时才计算分数（检查前一个字符是否为 '('）

4. **深度变化时机**：
   - `(` 后 depth += 1
   - `)` 先检查，再 depth -= 1
