## 题目描述

给定字符串 `s` 和整数 `k`，统计子串中每种出现的字母恰好出现 `k` 次的子串数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countSubstrings(String s, int k) {
        // 「恰好 k 次」= 「至少 k 次」- 「至少 k+1 次」
        return atLeast(s, k) - atLeast(s, k + 1);
    }

    // 统计每种出现字母均 >= minK 次的子串数
    private int atLeast(String s, int minK) {
        int n = s.length();
        int[] freq = new int[26];
        int satisfied = 0; // 达到 minK 次的字母种类数
        int kinds = 0;     // 出现过的字母种类数
        int res = 0, left = 0;

        for (int right = 0; right < n; right++) {
            int c = s.charAt(right) - 'a';
            freq[c]++;
            if (freq[c] == 1) kinds++;
            if (freq[c] == minK) satisfied++;

            // 当所有出现字母都 >= minK 次时，收缩左端点
            while (satisfied == kinds && kinds > 0) {
                res += n - right; // 以 right 结尾且从 left 开始的所有右扩子串
                int lc = s.charAt(left) - 'a';
                if (freq[lc] == minK) satisfied--;
                freq[lc]--;
                if (freq[lc] == 0) kinds--;
                left++;
            }
        }

        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，滑动窗口
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 「恰好 k 次」= 「至少 k 次」- 「至少 k+1 次」
2. 滑动窗口维护所有字母均满足 >= minK 的最小左端点
3. 满足条件时以当前左端点为起点向右延伸的子串都合法
