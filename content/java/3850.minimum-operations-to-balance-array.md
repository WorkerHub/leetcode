## 题目描述

给你一个整数数组 `nums`，每次操作可以选择数组中的任意一个元素加 1 或减 1。返回使数组中所有元素相等所需的最少操作次数。

## 解题思路

使所有元素相等的最少操作次数等于以**中位数**为目标值时，各元素与中位数的绝对差之和。排序后取中间位置的元素作为中位数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minOperations(int[] nums) {
        Arrays.sort(nums);
        // 中位数为最优目标值
        int median = nums[nums.length / 2];
        long result = 0;
        // 计算所有元素与中位数的绝对差之和
        for (int x : nums) {
            result += Math.abs(x - median);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 使所有元素相等的最优目标是中位数，这是绝对值优化的经典结论。
2. 奇数长度数组的中位数唯一（`n/2`），偶数长度时两个中间值均可。
3. 结果可能超过 int 范围，使用 `long` 累加。
