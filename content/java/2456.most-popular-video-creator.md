## 题目描述

给你创作者数组 `creators`、视频 id 数组 `ids` 和播放量数组 `views`，找出流行度（总播放量）最高的创作者及其播放量最高（同播放量取字典序最小 id）的视频，返回所有满足条件的 `[creator, id]` 对。

## 解题思路

用两个哈希表：一个累计每个创作者的总播放量，另一个维护每个创作者播放量最高（相同时字典序最小）的视频 id。遍历一次完成统计，再筛选最大流行度的创作者。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<List<String>> mostPopularCreator(String[] creators, String[] ids, int[] views) {
        Map<String, Long> totalViews = new HashMap<>();
        Map<String, String> bestId = new HashMap<>();
        Map<String, Integer> bestViews = new HashMap<>();

        for (int i = 0; i < creators.length; i++) {
            String c = creators[i], id = ids[i];
            int v = views[i];
            totalViews.merge(c, (long) v, Long::sum);
            // 更新最佳视频：播放量更高，或相同时 id 字典序更小
            if (!bestId.containsKey(c) || v > bestViews.get(c)
                    || (v == bestViews.get(c) && id.compareTo(bestId.get(c)) < 0)) {
                bestId.put(c, id);
                bestViews.put(c, v);
            }
        }

        long maxViews = 0;
        for (long tv : totalViews.values()) maxViews = Math.max(maxViews, tv);

        List<List<String>> ans = new ArrayList<>();
        for (Map.Entry<String, Long> e : totalViews.entrySet()) {
            if (e.getValue() == maxViews) {
                ans.add(Arrays.asList(e.getKey(), bestId.get(e.getKey())));
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 两个哈希表分别维护总播放量和最佳视频
2. 最佳视频更新条件：播放量更高，或相同时 id 字典序更小
3. 总播放量可能溢出 int，使用 `long`
