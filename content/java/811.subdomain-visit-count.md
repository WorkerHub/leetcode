## 题目描述

网站域名 `"discuss.leetcode.com"` 由多个子域名组成。顶级域名为 `"com"`，二级域名为 `"leetcode.com"`，最低一级为 `"discuss.leetcode.com"`。当访问域名 `"discuss.leetcode.com"` 时，同时也会隐式访问其父域名 `"leetcode.com"` 以及 `"com"`。

**计数配对域名** 是遵循 `"rep d1.d2.d3"` 或 `"rep d1.d2"` 格式的一个域名表示，其中 `rep` 表示访问域名的次数，`d1.d2.d3` 为域名本身。

给你一个 **计数配对域名** 组成的数组 `cpdomains`，解析得到输入中每个子域名对应的 **计数配对域名**，并以数组形式返回。

**示例 1:**
```
输入: cpdomains = ["9001 discuss.leetcode.com"]
输出: ["9001 leetcode.com","9001 discuss.leetcode.com","9001 com"]
```

**示例 2:**
```
输入: cpdomains = ["900 google.mail.com", "50 yahoo.com", "1 intel.mail.com", "5 wiki.org"]
输出: ["901 mail.com","50 yahoo.com","900 google.mail.com","5 wiki.org","5 org","1 intel.mail.com","951 com"]
```

**提示:**
- `1 <= cpdomain.length <= 100`
- `1 <= cpdomain[i].length <= 100`

## 解题思路

这是一道哈希表 + 字符串处理的题目。核心思路是：
1. 解析每个计数配对，提取访问次数和域名
2. 生成该域名的所有子域名（包括自己）
3. 使用哈希表累计每个子域名的访问次数
4. 格式化输出结果

## Java 代码实现

### 方法一：哈希表（推荐）

```java
import java.util.*;

class Solution {
    public List<String> subdomainVisits(String[] cpdomains) {
        Map<String, Integer> count = new HashMap<>();

        for (String cpdomain : cpdomains) {
            // 分离访问次数和域名
            int spaceIdx = cpdomain.indexOf(' ');
            int times = Integer.parseInt(cpdomain.substring(0, spaceIdx));
            String domain = cpdomain.substring(spaceIdx + 1);

            // 生成所有子域名并累计
            String[] parts = domain.split("\\.");
            for (int i = 0; i < parts.length; i++) {
                // 拼接从第 i 部分开始的子域名
                StringBuilder sb = new StringBuilder();
                for (int j = i; j < parts.length; j++) {
                    if (j > i) sb.append('.');
                    sb.append(parts[j]);
                }
                String subdomain = sb.toString();
                count.put(subdomain, count.getOrDefault(subdomain, 0) + times);
            }
        }

        // 格式化输出
        List<String> result = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : count.entrySet()) {
            result.add(entry.getValue() + " " + entry.getKey());
        }

        return result;
    }
}
```

### 方法二：使用 String.join 简化拼接

```java
import java.util.*;

class Solution {
    public List<String> subdomainVisits(String[] cpdomains) {
        Map<String, Integer> count = new HashMap<>();

        for (String cpdomain : cpdomains) {
            String[] split = cpdomain.split(" ");
            int times = Integer.parseInt(split[0]);
            String domain = split[1];

            // 逐级生成子域名
            int dotIdx = -1;
            while ((dotIdx = domain.indexOf('.', dotIdx + 1)) != -1) {
                String subdomain = domain.substring(dotIdx + 1);
                count.put(subdomain, count.getOrDefault(subdomain, 0) + times);
            }
            // 完整域名本身
            count.put(domain, count.getOrDefault(domain, 0) + times);
        }

        List<String> result = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : count.entrySet()) {
            result.add(entry.getValue() + " " + entry.getKey());
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)，n 是数组长度，m 是域名的平均层数
- **空间复杂度**：O(n × m)，存储所有子域名

## 关键点总结

1. **字符串分割**：分离次数和域名
2. **子域名生成**：从右到左逐级生成
3. **哈希表累计**：使用 getOrDefault 方法
4. **字符串拼接**：Java 中使用 StringBuilder

## 易错点

1. **访问次数转换**：记得转换为整数
2. **子域名顺序**：从当前位置到末尾
3. **输出格式**：次数和域名之间有空格
