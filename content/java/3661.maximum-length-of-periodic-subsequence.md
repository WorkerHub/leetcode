## 题目描述

给你一个整数数组 `nums` 和整数 `d`，找到最长的子序列使得相邻元素之差的绝对值等于 `d`（公差为 ±d 的等差子序列）。返回该子序列的最大长度。

## 解题思路

DP + 哈希表：分别维护公差 +d 和 -d 两个方向的 DP。`dp_pos[v]` = 以值 v 结尾、公差 +d 的最长子序列长度。从左到右遍历，`dp_pos[v] = dp_pos[v-d] + 1`，`dp_neg[v] = dp_neg[v+d] + 1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxPeriodicLength(int[] nums, int d) {
        Map<Integer, Integer> dpPos = new HashMap<>(); // 公差 +d
        Map<Integer, Integer> dpNeg = new HashMap<>(); // 公差 -d
        int ans = 1;

        for (int v : nums) {
            // 公差 +d：接在 v-d 后面
            int posLen = dpPos.getOrDefault(v - d, 0) + 1;
            dpPos.put(v, Math.max(dpPos.getOrDefault(v, 0), posLen));
            // 公差 -d：接在 v+d 后面
            int negLen = dpNeg.getOrDefault(v + d, 0) + 1;
            dpNeg.put(v, Math.max(dpNeg.getOrDefault(v, 0), negLen));
            ans = Math.max(ans, Math.max(dpPos.get(v), dpNeg.get(v)));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 公差为 +d 时，`dp[v] = dp[v-d] + 1`；公差为 -d 时，`dp[v] = dp[v+d] + 1`
2. 从左到右遍历保证子序列顺序
3. 分别维护两个方向的 dp 哈希表
