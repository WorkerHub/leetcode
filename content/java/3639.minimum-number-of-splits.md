## 题目描述

给定正整数 `n`，将其分解为若干正整数之和，使这些数的最大公约数为 1，返回最少分解数量。

## Java 代码实现

```java
class Solution {
    public int minimumSplits(int n) {
        // n=1 时自身 GCD=1，答案为 1
        // n>=2 时分成 1 和 n-1，GCD(1, n-1)=1，答案为 2
        return n == 1 ? 1 : 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 只有 n=1 时单个数满足 GCD=1
2. n>=2 时，分成 1 和 n-1 即可（GCD(1, x)=1 恒成立）
