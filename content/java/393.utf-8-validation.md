## 题目描述

给定一个表示数据的整数数组 `data`，返回它是否为有效的 **UTF-8** 编码。

**UTF-8** 中的一个字符可能的长度为 **1 到 4 字节**，遵循以下规则：

1. 对于 **1 字节** 的字符，字节的第一位设为 0，后面 7 位为这个符号的 unicode 码。
2. 对于 **n 字节** 的字符 (n > 1)，第一个字节的前 n 位都设为 1，第 n+1 位设为 0，后面字节的前两位一律设为 10。剩下的没有提及的二进制位，全部为这个符号的 unicode 码。

这是 UTF-8 编码的工作方式：

```
   Char. number range  |        UTF-8 octet sequence
      (hexadecimal)    |              (binary)
   --------------------+---------------------------------------------
   0000 0000-0000 007F | 0xxxxxxx
   0000 0080-0000 07FF | 110xxxxx 10xxxxxx
   0000 0800-0000 FFFF | 1110xxxx 10xxxxxx 10xxxxxx
   0001 0000-0010 FFFF | 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx
```

**注意：** 输入是整数数组。只有每个整数的 **最低 8 个有效位** 用来存储数据。这意味着每个整数只表示 1 字节的数据。

**示例 1:**

```
输入：data = [197,130,1]
输出：true
解释：数据表示字节序列:11000101 10000010 00000001。
这是有效的 utf-8 编码，为一个 2 字节字符，跟着一个 1 字节字符。
```

**示例 2:**

```
输入：data = [235,140,4]
输出：false
解释：数据表示 8 位的序列: 11101011 10001100 00000100.
前 3 位都是 1 ，第 4 位为 0 表示它是一个 3 字节字符。
下一个字节是开头为 10 的延续字节，这是正确的。
但第二个延续字节不以 10 开头，所以是不符合规则的。
```

**提示:**

- `1 <= data.length <= 2 * 10^4`
- `0 <= data[i] <= 255`

## 解题思路

本题考查对 **UTF-8 编码规则** 和 **位运算** 的理解。

### 核心思想

**UTF-8 编码规则：**

1. **1 字节字符**：`0xxxxxxx` (0-127)
2. **2 字节字符**：`110xxxxx 10xxxxxx`
3. **3 字节字符**：`1110xxxx 10xxxxxx 10xxxxxx`
4. **4 字节字符**：`11110xxx 10xxxxxx 10xxxxxx 10xxxxxx`

**验证步骤：**

1. 判断当前字节是字符的第一个字节还是延续字节
2. 如果是第一个字节，确定字符的字节数（1-4）
3. 检查后续的延续字节是否都以 `10` 开头
4. 重复直到所有字节处理完

**位运算技巧：**

- 判断最高位：`num & 0b10000000`
- 判断前两位：`num & 0b11000000 == 0b10000000`
- 判断前 n 位的模式

## Java 代码实现

### 方法一：位运算 + 状态机（推荐）⭐

```java
class Solution {
    public boolean validUtf8(int[] data) {
        // 位运算验证 UTF-8 编码
        // 时间复杂度: O(n)
        // 空间复杂度: O(1)

        // 需要跟随的字节数
        int nBytes = 0;

        // 掩码
        int mask1 = 1 << 7;  // 10000000
        int mask2 = 1 << 6;  // 01000000

        for (int num : data) {
            // 获取最低 8 位
            num = num & 0xFF;

            if (nBytes == 0) {
                // 确定字符的字节数
                int mask = 1 << 7;
                while ((mask & num) != 0) {
                    nBytes++;
                    mask >>= 1;
                }

                // 1 字节字符
                if (nBytes == 0) continue;

                // UTF-8 字符最多 4 字节，最少 2 字节（nBytes=1 是延续字节）
                if (nBytes == 1 || nBytes > 4) return false;
            } else {
                // 检查延续字节：必须以 10 开头
                if ((num & mask1) == 0 || (num & mask2) != 0) return false;
            }

            nBytes--;
        }

        return nBytes == 0;
    }
}
```

### 方法二：使用掩码判断

```java
class Solution {
    public boolean validUtf8(int[] data) {
        // 使用掩码直接判断模式
        // 需要多少个延续字节
        int remaining = 0;

        for (int num : data) {
            // 只保留最低 8 位
            int bite = num & 0xFF;

            if (remaining == 0) {
                // 判断字节数
                if ((bite >> 5) == 0b110) {
                    remaining = 1;  // 2 字节字符
                } else if ((bite >> 4) == 0b1110) {
                    remaining = 2;  // 3 字节字符
                } else if ((bite >> 3) == 0b11110) {
                    remaining = 3;  // 4 字节字符
                } else if ((bite >> 7) == 0) {
                    remaining = 0;  // 1 字节字符
                } else {
                    return false;
                }
            } else {
                // 检查延续字节：必须以 10 开头
                if ((bite >> 6) != 0b10) return false;
                remaining--;
            }
        }

        return remaining == 0;
    }
}
```

### 方法三：更清晰的版本

```java
class Solution {
    public boolean validUtf8(int[] data) {
        // 更清晰的实现，使用辅助方法
        int i = 0;
        while (i < data.length) {
            int bite = data[i] & 0xFF;

            // 获取字符的字节数
            int nBytes = getBytesCount(bite);

            if (nBytes == -1) return false;

            // 检查是否有足够的延续字节
            if (i + nBytes > data.length) return false;

            // 检查所有延续字节
            for (int j = 1; j < nBytes; j++) {
                if (!isContinuation(data[i + j] & 0xFF)) return false;
            }

            i += nBytes;
        }

        return true;
    }

    /** 判断字符的字节数 */
    private int getBytesCount(int bite) {
        if ((bite >> 7) == 0) return 1;        // 0xxxxxxx
        if ((bite >> 5) == 0b110) return 2;    // 110xxxxx
        if ((bite >> 4) == 0b1110) return 3;   // 1110xxxx
        if ((bite >> 3) == 0b11110) return 4;  // 11110xxx
        return -1;  // 无效
    }

    /** 判断是否是延续字节 10xxxxxx */
    private boolean isContinuation(int bite) {
        return (bite >> 6) == 0b10;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历数组一次
- 每个字节的位运算是 O(1)

**空间复杂度：** O(1)
- 只使用常数额外空间

## 关键点总结

1. **UTF-8 规则理解**：字符可以是 1-4 字节，延续字节以 `10` 开头
2. **位运算技巧**：使用右移和掩码判断前几位的模式
3. **状态维护**：记录当前需要多少个延续字节
4. **边界检查**：延续字节不能超出数组范围
5. **最低 8 位**：题目说明只有最低 8 位有效，需要 `& 0xFF`

## 易错点

1. **忘记取最低 8 位**：输入可能大于 255，需要 `& 0xFF`
2. **延续字节判断**：必须是 `10xxxxxx`，不是 `1xxxxxxx`
3. **字节数判断**：1 字节是 `0xxxxxxx`，不需要延续字节
4. **数组越界**：检查是否有足够的延续字节
5. **最后的检查**：处理完所有字节后，`remaining` 必须为 0
