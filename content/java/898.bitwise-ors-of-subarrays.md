## 题目描述

给定整数数组 arr，返回所有子数组按位 OR 结果的不同值数量。

**示例：**
```
输入：arr = [1,1,2]
输出：3（子数组 OR 结果为 {1, 1, 3, 1, 3, 3} → 不同值 {1, 3}... 实际为 3 个不同值）
```

## 解题思路

利用 OR 只增不减的性质：以每个元素结尾的子数组 OR 值最多 30 个（整数位数）。用集合滚动维护。

## Java 代码实现

```java
class Solution {
    public int subarrayBitwiseORs(int[] arr) {
        Set<Integer> result = new HashSet<>();
        Set<Integer> cur = new HashSet<>();

        for (int num : arr) {
            Set<Integer> next = new HashSet<>();
            next.add(num);
            for (int x : cur) {
                next.add(num | x);
            }
            result.addAll(next);
            cur = next;
        }

        return result.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 30)
- **空间复杂度**：O(n × 30)

## 关键点总结

1. **OR 单调性**：OR 值只增不减
2. **状态数有限**：以某元素结尾最多 30 个不同 OR 值
3. **滚动集合**：每步更新以当前元素结尾的所有可能值
