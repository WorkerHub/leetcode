## 题目描述

给定整数数组 nums 和整数 k，返回所有数对距离（绝对差值）中第 k 小的。

**示例：**
```
输入：nums = [1,3,1], k = 1
输出：0
```

## 解题思路

二分查找答案 + 双指针统计：排序后二分距离 mid，用双指针 O(n) 统计距离 ≤ mid 的数对数，找第一个 count ≥ k 的距离。

## Java 代码实现

```java
class Solution {
    public int smallestDistancePair(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        int left = 0, right = nums[n - 1] - nums[0];

        while (left < right) {
            int mid = (left + right) / 2;
            if (countPairs(nums, mid) < k) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }

    private int countPairs(int[] nums, int mid) {
        int count = 0, left = 0;
        for (int right = 0; right < nums.length; right++) {
            while (nums[right] - nums[left] > mid) {
                left++;
            }
            count += right - left;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + n log D)，D 为最大距离
- **空间复杂度**：O(log n)，排序栈空间

## 关键点总结

1. **二分答案**：二分距离而不是枚举数对
2. **双指针统计**：排序后 O(n) 统计 ≤ mid 的数对数
3. **边界确定**：[0, max-min]
