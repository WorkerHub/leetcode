## 题目描述

字符串支持单点修改，每次修改后查询最长全同字符子串长度。

## 解题思路

线段树维护区间信息：前缀同字符长度lmax、后缀同字符长度rmax、区间最长ans、左端字符、右端字符。合并时若左尾==右首则可跨区间延伸。

## Java 代码实现

```java
class Solution {
    int[] lmax, rmax, ans, len;
    char[] lchar, rchar;
    char[] s;
    
    public int[] longestRepeating(String s, String queryCharacters, int[] queryIndices) {
        int n = s.length();
        this.s = s.toCharArray();
        lmax = new int[4 * n];
        rmax = new int[4 * n];
        ans = new int[4 * n];
        len = new int[4 * n];
        lchar = new char[4 * n];
        rchar = new char[4 * n];
        
        build(1, 0, n - 1);
        
        int k = queryIndices.length;
        int[] result = new int[k];
        for (int q = 0; q < k; q++) {
            int idx = queryIndices[q];
            char c = queryCharacters.charAt(q);
            this.s[idx] = c;
            update(1, 0, n - 1, idx, c);
            result[q] = ans[1];
        }
        return result;
    }
    
    private void build(int node, int start, int end) {
        len[node] = end - start + 1;
        if (start == end) {
            lmax[node] = rmax[node] = ans[node] = 1;
            lchar[node] = rchar[node] = s[start];
            return;
        }
        int mid = (start + end) / 2;
        build(2 * node, start, mid);
        build(2 * node + 1, mid + 1, end);
        pushup(node);
    }
    
    private void pushup(int node) {
        int l = 2 * node, r = 2 * node + 1;
        lchar[node] = lchar[l];
        rchar[node] = rchar[r];
        len[node] = len[l] + len[r];
        lmax[node] = lmax[l];
        rmax[node] = rmax[r];
        ans[node] = Math.max(ans[l], ans[r]);
        
        // 左区间右端字符==右区间左端字符，可跨越合并
        if (rchar[l] == lchar[r]) {
            int merge = rmax[l] + lmax[r];
            ans[node] = Math.max(ans[node], merge);
            if (lmax[l] == len[l]) lmax[node] = len[l] + lmax[r];
            if (rmax[r] == len[r]) rmax[node] = len[r] + rmax[l];
        }
    }
    
    private void update(int node, int start, int end, int idx, char c) {
        if (start == end) {
            lchar[node] = rchar[node] = c;
            return;
        }
        int mid = (start + end) / 2;
        if (idx <= mid) update(2 * node, start, mid, idx, c);
        else update(2 * node + 1, mid + 1, end, idx, c);
        pushup(node);
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + K) log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **线段树区间合并**：维护前缀、后缀同字符长度及区间最长
2. **合并条件**：左区间右端字符==右区间左端字符时可跨越
3. **前缀延伸**：若左区间全同字符则新前缀=左长度+右前缀
