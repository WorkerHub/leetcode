## 题目描述

给定四个点坐标，判断是否构成正方形。

## Java 代码实现

```java
class Solution {
    public boolean validSquare(int[] p1, int[] p2, int[] p3, int[] p4) {
        int[] dists = {
            dist(p1,p2), dist(p1,p3), dist(p1,p4),
            dist(p2,p3), dist(p2,p4), dist(p3,p4)
        };
        Arrays.sort(dists);
        // 4条边相等，2条对角线相等，边>0，对角线=2*边
        return dists[0] > 0
            && dists[0] == dists[1] && dists[1] == dists[2] && dists[2] == dists[3]
            && dists[4] == dists[5]
            && dists[3] * 2 == dists[4];
    }

    private int dist(int[] p, int[] q) {
        return (p[0]-q[0])*(p[0]-q[0]) + (p[1]-q[1])*(p[1]-q[1]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **距离平方**：避免浮点数
2. **排序判断**：前4边相等，后2对角线相等
3. **对角线 = 2*边**：正方形性质
