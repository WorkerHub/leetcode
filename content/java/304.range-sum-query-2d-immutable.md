## 题目描述

给定一个二维矩阵 `matrix`，以下类型的多个请求：

计算其子矩形范围内元素的总和，该子矩阵的**左上角**为 `(row1, col1)` ，**右下角**为 `(row2, col2)` 。

实现 `NumMatrix` 类：

- `NumMatrix(int[][] matrix)` 给定整数矩阵 `matrix` 进行初始化
- `int sumRegion(int row1, int col1, int row2, int col2)` 返回**左上角** `(row1, col1)` 、**右下角** `(row2, col2)` 所描述的子矩阵的元素**总和**。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/14/sum-grid.jpg)

```
输入: 
["NumMatrix", "sumRegion", "sumRegion", "sumRegion"]
[[[[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]], [2, 1, 4, 3], [1, 1, 2, 2], [1, 2, 2, 4]]
输出: 
[null, 8, 11, 12]

解释:
NumMatrix numMatrix = new NumMatrix([[3, 0, 1, 4, 2], [5, 6, 3, 2, 1], [1, 2, 0, 1, 5], [4, 1, 0, 1, 7], [1, 0, 3, 0, 5]]);
numMatrix.sumRegion(2, 1, 4, 3); // return 8 (红色矩形框的元素总和)
numMatrix.sumRegion(1, 1, 2, 2); // return 11 (绿色矩形框的元素总和)
numMatrix.sumRegion(1, 2, 2, 4); // return 12 (蓝色矩形框的元素总和)
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 200`
- `-10^5 <= matrix[i][j] <= 10^5`
- `0 <= row1 <= row2 < m`
- `0 <= col1 <= col2 < n`
- 最多调用 `10^4` 次 `sumRegion` 方法

## 解题思路

这是 303 题（一维前缀和）的二维扩展版本。

### 核心思想：二维前缀和

**定义**：`prefix[i][j]` 表示从 `(0, 0)` 到 `(i-1, j-1)` 的矩形区域的元素和。

**构建前缀和数组**：
```
prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + matrix[i-1][j-1]
```

**图解**：
```
prefix[i][j] = A + B + C + matrix[i-1][j-1]
其中：
A = prefix[i-1][j-1]
B = prefix[i-1][j] - prefix[i-1][j-1]
C = prefix[i][j-1] - prefix[i-1][j-1]
```

**查询区域和**：
```
sumRegion(r1, c1, r2, c2) = prefix[r2+1][c2+1] 
                           - prefix[r1][c2+1] 
                           - prefix[r2+1][c1] 
                           + prefix[r1][c1]
```

**图解**：
```
整个大矩形 - 上面矩形 - 左边矩形 + 左上角矩形（被减了两次，要加回来）
```

## Java 代码实现

### 方法一：二维前缀和（推荐）⭐

```java
class NumMatrix {
    private int[][] prefix;

    public NumMatrix(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return;

        int m = matrix.length, n = matrix[0].length;

        // prefix[i][j] 表示从 (0,0) 到 (i-1,j-1) 的矩形和
        // 大小为 (m+1) x (n+1)，第 0 行和第 0 列都是 0
        prefix = new int[m + 1][n + 1];

        // 构建前缀和数组
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = prefix[i-1][j]      // 上面的矩形
                             + prefix[i][j-1]      // 左边的矩形
                             - prefix[i-1][j-1]    // 减去重复计算的左上角
                             + matrix[i-1][j-1];   // 当前元素
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        // 返回子矩阵 (row1, col1) 到 (row2, col2) 的和
        return prefix[row2+1][col2+1]    // 整个大矩形
             - prefix[row1][col2+1]     // 减去上面的矩形
             - prefix[row2+1][col1]     // 减去左边的矩形
             + prefix[row1][col1];      // 加回左上角（被减了两次）
    }
}
```

### 方法二：逐行前缀和

```java
class NumMatrix {
    private int[][] rowSums;

    public NumMatrix(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return;

        int m = matrix.length, n = matrix[0].length;

        // 每一行都是一个前缀和数组
        rowSums = new int[m][n + 1];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                rowSums[i][j + 1] = rowSums[i][j] + matrix[i][j];
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        // 累加每一行的区间和
        int total = 0;
        for (int i = row1; i <= row2; i++) {
            total += rowSums[i][col2 + 1] - rowSums[i][col1];
        }
        return total;
    }
}
```

### 方法三：暴力方法（不推荐）

class NumMatrix {

    public NumMatrix(int[][] matrix) {

                total += matrix[i][j];

### 方法四：带注释的详细版本

```java
class NumMatrix {
    private int[][] prefix;

    public NumMatrix(int[][] matrix) {
        /**
         * 构建二维前缀和数组
         *
         * prefix[i][j] 的含义：
         * - 表示从 (0, 0) 到 (i-1, j-1) 的矩形区域的元素和
         * - prefix[0][j] = 0（第 0 行全为 0）
         * - prefix[i][0] = 0（第 0 列全为 0）
         */
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            prefix = new int[1][1];
            return;
        }

        int m = matrix.length, n = matrix[0].length;
        prefix = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 递推公式：prefix[i][j] = (上 + 左 - 左上 + 当前)
                prefix[i][j] = prefix[i-1][j]      // 上方矩形的和
                             + prefix[i][j-1]      // 左方矩形的和
                             - prefix[i-1][j-1]    // 左上角被计算了两次，减去
                             + matrix[i-1][j-1];   // 加上当前元素
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        /**
         * 计算子矩阵的和
         *
         * 思路：大矩形 - 上矩形 - 左矩形 + 左上矩形
         *
         * ┌─────────┬─────┐
         * │ 左上角  │ 上  │
         * ├─────────┼─────┤
         * │   左    │ 目标│
         * └─────────┴─────┘
         *
         * 目标 = prefix[r2+1][c2+1]
         *      - prefix[r1][c2+1]    (上矩形)
         *      - prefix[r2+1][c1]    (左矩形)
         *      + prefix[r1][c1]      (左上角，被减了两次)
         */
        return prefix[row2+1][col2+1]
             - prefix[row1][col2+1]
             - prefix[row2+1][col1]
             + prefix[row1][col1];
    }
}
```

## 复杂度分析

**方法一（二维前缀和）：**
- 时间复杂度：
  - 初始化：O(m × n)
  - 查询：O(1)
- 空间复杂度：O(m × n)

**方法二（逐行前缀和）：**
- 时间复杂度：
  - 初始化：O(m × n)
  - 查询：O(m)
- 空间复杂度：O(m × n)

**方法三（暴力）：**
- 时间复杂度：
  - 初始化：O(1)
  - 查询：O(m × n)
- 空间复杂度：O(1)

## 关键点总结

1. **二维前缀和公式**（构建）：
   ```
   prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] 
                - prefix[i-1][j-1] + matrix[i-1][j-1]
   ```

2. **区域和公式**（查询）：
   ```
   sum = prefix[r2+1][c2+1] - prefix[r1][c2+1] 
       - prefix[r2+1][c1] + prefix[r1][c1]
   ```

3. **数组大小**：`prefix` 是 `(m+1) × (n+1)`，第 0 行和第 0 列都是 0

4. **索引映射**：
   - `matrix[i][j]` 对应 `prefix[i+1][j+1]`
   - 查询 `(r1, c1)` 到 `(r2, c2)` 用 `prefix[r2+1][c2+1]` 等

5. **容斥原理**：加两次减两次的逻辑（左上角被计算/减去了两次）

## 易错点

1. **索引偏移**：`prefix` 比 `matrix` 多一行一列，索引要 +1
2. **公式记错**：特别是查询时的 4 个项，哪些是加哪些是减
3. **边界处理**：第 0 行和第 0 列必须初始化为 0
4. **容斥原理**：为什么要 `+ prefix[r1][c1]`（因为被减了两次）
