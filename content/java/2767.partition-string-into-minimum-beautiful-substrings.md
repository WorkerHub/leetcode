## 题目描述

给你仅含 '0' 和 '1' 的字符串 `s`，美丽字符串为无前导零且二进制值是 5 的幂次，返回将 `s` 分割成若干美丽字符串的最小份数（不可能则返回 -1）。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumBeautifulSubstrings(String s) {
        int n = s.length();
        // 预处理 5 的幂次的二进制字符串
        Set<String> powers = new HashSet<>();
        long p = 1;
        while (p <= (1 << 15)) {
            powers.add(Long.toBinaryString(p));
            p *= 5;
        }
        // dp[i] = 分割 s[0..i-1] 的最小份数
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (s.charAt(j) == '0') continue;  // 含前导零，跳过
                String sub = s.substring(j, i);
                if (powers.contains(sub) && dp[j] < Integer.MAX_VALUE / 2) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n] >= Integer.MAX_VALUE / 2 ? -1 : dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，L 为 5 的幂次二进制长度（最多 15）
- 空间复杂度：O(n)

## 关键点总结

1. 5 的幂次在 15 位二进制内只有少数个（1,5,25,125,625,3125,15625）
2. DP 定义清晰：dp[i] 为前 i 个字符的最小分割数
3. 前导零直接跳过
