## 题目描述

无限二维网格初始全白，第 1 分钟将 (0,0) 涂蓝，之后每分钟将所有与蓝色格子相邻的白格涂蓝，返回 n 分钟后蓝色格子总数。

## 解题思路

观察规律：每分钟新增 4*(i-1) 个格子，总数 = 1 + 4*(1+2+...+(n-1)) = 2n²-2n+1，直接返回公式结果。

## Java 代码实现

```java
class Solution {
    public long coloredCells(int n) {
        return 2L * n * n - 2L * n + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 等差数列求和：每分钟新增格子数为 4*(i-1)
2. 公式推导：`2n² - 2n + 1`
3. n 最大 10^5，结果约 2*10^10，需用 `long`
