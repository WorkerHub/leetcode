## 题目描述

统计数组中nums[i]*nums[j]能被k整除的下标对(i<j)数量。

## 解题思路

按gcd(x,k)分组：统计每种gcd值的数量，枚举k的因子对(d1,d2)，若d1*d2%k==0则贡献cnt[d1]*cnt[d2]（同组用组合数）。

## Java 代码实现

```java
class Solution {
    public long countPairs(int[] nums, int k) {
        // 统计每个gcd(x, k)的数量
        Map<Integer, Long> cnt = new HashMap<>();
        for (int x : nums) {
            int g = gcd(x, k);
            cnt.merge(g, 1L, Long::sum);
        }
        
        // 获取k的所有因子
        List<Integer> divisors = new ArrayList<>();
        for (int d = 1; d * d <= k; d++) {
            if (k % d == 0) {
                divisors.add(d);
                if (d != k / d) divisors.add(k / d);
            }
        }
        
        long ans = 0;
        for (int d1 : divisors) {
            for (int d2 : divisors) {
                if (d2 < d1) continue;
                if ((long) d1 * d2 % k != 0) continue;
                long c1 = cnt.getOrDefault(d1, 0L);
                long c2 = cnt.getOrDefault(d2, 0L);
                if (d1 == d2) {
                    ans += c1 * (c1 - 1) / 2;
                } else {
                    ans += c1 * c2;
                }
            }
        }
        return ans;
    }
    
    private int gcd(int a, int b) {
        while (b != 0) { int t = b; b = a % b; a = t; }
        return a;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + d(k)^2)，d(k)为k的因子数
- **空间复杂度**：O(d(k))

## 关键点总结

1. **gcd分组**：nums[i]*nums[j]%k==0等价于gcd(nums[i],k)*gcd(nums[j],k)%k==0
2. **枚举因子对**：k的因子数很小（k<=10^5时d(k)<=128）
3. **同组用组合数**：d1==d2时C(cnt,2)避免重复
