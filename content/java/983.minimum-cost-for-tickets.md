## 题目描述

给定旅行日期数组 days 和三种票价 costs（1天/7天/30天通行证），返回完成所有旅行的最低消费。

**示例：**
```
输入：days = [1,4,6,7,8,20], costs = [2,7,15]
输出：11
```

## 解题思路

动态规划：dp[i] 表示到第 i 天的最小花费。若第 i 天不旅行则 dp[i] = dp[i-1]；否则取三种票的最小值。

## Java 代码实现

```java
class Solution {
    public int mincostTickets(int[] days, int[] costs) {
        int lastDay = days[days.length - 1];
        boolean[] travel = new boolean[lastDay + 1];
        for (int day : days) travel[day] = true;

        int[] dp = new int[lastDay + 1];
        for (int i = 1; i <= lastDay; i++) {
            if (!travel[i]) {
                dp[i] = dp[i - 1];
            } else {
                dp[i] = Math.min(
                    dp[i - 1] + costs[0],
                    Math.min(
                        dp[Math.max(0, i - 7)] + costs[1],
                        dp[Math.max(0, i - 30)] + costs[2]
                    )
                );
            }
        }

        return dp[lastDay];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(days))
- **空间复杂度**：O(max(days))

## 关键点总结

1. **按天 DP**：遍历每一天而非每个旅行日
2. **非旅行日继承**：dp[i] = dp[i-1]
3. **三种选择取最小**：1天、7天、30天通行证
