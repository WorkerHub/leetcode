## 题目描述

给你整数数组 maxHeights（n 最大 10^5），找到和最大的山形塔数组，每个位置高度不超过 maxHeights[i]，返回高度之和的最大值。

## 解题思路

单调栈 O(n)：预处理 `left[i]`（以 i 为峰顶时左半部分的最优和）和 `right[i]`（右半部分最优和），用单调不减栈实现，转移公式 `left[i] = left[j] + (i-j) * maxH[i]`（j 是栈顶），最终答案 = `max(left[i] + right[i] - maxH[i])`。

## Java 代码实现

```java
class Solution {
    public long maximumSumOfHeights(List<Integer> maxHeights) {
        int n = maxHeights.size();
        long[] left = new long[n];
        long[] right = new long[n];
        Deque<Integer> stack = new ArrayDeque<>();

        // 从左到右计算 left[i]（单调不减栈）
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && maxHeights.get(stack.peek()) >= maxHeights.get(i)) {
                stack.pop();
            }
            if (stack.isEmpty()) {
                left[i] = (long) (i + 1) * maxHeights.get(i);
            } else {
                int j = stack.peek();
                left[i] = left[j] + (long) (i - j) * maxHeights.get(i);
            }
            stack.push(i);
        }

        stack.clear();
        // 从右到左计算 right[i]
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && maxHeights.get(stack.peek()) >= maxHeights.get(i)) {
                stack.pop();
            }
            if (stack.isEmpty()) {
                right[i] = (long) (n - i) * maxHeights.get(i);
            } else {
                int j = stack.peek();
                right[i] = right[j] + (long) (j - i) * maxHeights.get(i);
            }
            stack.push(i);
        }

        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, left[i] + right[i] - maxHeights.get(i));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. left[i] = left[j] + (i-j) * maxH[i]，j 是栈顶（左侧最近不小于 maxH[i] 的位置）
2. left[i] 和 right[i] 都包含第 i 个位置，最终减去一次 maxH[i]
3. 弹出条件用 `>=` 防止相等时重复累加
