## 题目描述

给定二进制字符串 `s` 和整数 `numOps`，每次可翻转任意一个字符，返回最多 `numOps` 次操作后，最长全相同字符子串的最小可能长度。

## Java 代码实现

```java
class Solution {
    public int minLength(String s, int numOps) {
        int n = s.length();

        // 二分答案
        int lo = 1, hi = n;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (cost(s, n, mid) <= numOps) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private int cost(String s, int n, int maxLen) {
        if (maxLen == 1) {
            // 变为交替字符串，取两种模式的最小代价
            int c0 = 0, c1 = 0;
            for (int i = 0; i < n; i++) {
                if (s.charAt(i) != "01".charAt(i % 2)) c0++;
                if (s.charAt(i) != "10".charAt(i % 2)) c1++;
            }
            return Math.min(c0, c1);
        }
        // 统计每段连续相同字符，计算打断代价
        int ops = 0, i = 0;
        while (i < n) {
            int j = i + 1;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            ops += (j - i) / (maxLen + 1); // 每段需要 L/(maxLen+1) 次操作
            i = j;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，二分 O(log n) 次，每次验证 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 二分目标长度，验证能否在 `numOps` 次内达成。
2. 长度为 L 的全相同段，限制最大长度为 mid，需 `L/(mid+1)` 次操作。
3. `mid=1` 时特殊处理：最优是变为交替字符串。
