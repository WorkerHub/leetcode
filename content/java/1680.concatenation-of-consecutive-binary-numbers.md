## 题目描述

给你整数 `n`，将 `1` 到 `n` 的二进制表示依次拼接，返回该二进制数对 `10^9 + 7` 取模的十进制值。

## 解题思路

**位运算：** 对每个数 `i`，计算其二进制位数 `bits`，将结果左移 `bits` 位后加上 `i`，每步取模。

位数计算：`bits = 32 - Integer.numberOfLeadingZeros(i)`。

## Java 代码实现

```java
class Solution {
    public int concatenatedBinary(int n) {
        final long MOD = 1_000_000_007L;
        long result = 0;
        for (int i = 1; i <= n; i++) {
            // 计算 i 的二进制位数
            int bits = 32 - Integer.numberOfLeadingZeros(i);
            result = ((result << bits) | i) % MOD;
        }
        return (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每步左移当前数的位数再按位或，等价于拼接二进制
2. `Integer.numberOfLeadingZeros(i)` 计算前导零数，`32 - 前导零 = 位数`
3. 用 `long` 防止中间结果溢出
