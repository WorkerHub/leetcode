## 题目描述

无限多个栈排成一排，每个容量为 capacity。push 推入最左边未满的栈，pop 弹出最右边非空栈顶，popAtStack(index) 弹出指定栈顶。

**示例：**
```
push(1), push(2), push(3) → 栈0=[1,2], 栈1=[3]（capacity=2）
popAtStack(0) → 2, pop() → 3
```

## 解题思路

列表存储所有栈 + 最小堆维护未满栈索引 + 变量跟踪最右非空栈。

## Java 代码实现

```java
class DinnerPlates {
    private List<Deque<Integer>> stacks;
    private TreeSet<Integer> available; // 未满栈的索引（有序集合）
    private int capacity;

    public DinnerPlates(int capacity) {
        this.capacity = capacity;
        this.stacks = new ArrayList<>();
        this.available = new TreeSet<>();
    }

    public void push(int val) {
        // 清理无效的可用索引
        while (!available.isEmpty() && available.first() < stacks.size()
               && stacks.get(available.first()).size() == capacity) {
            available.pollFirst();
        }

        if (available.isEmpty() || available.first() >= stacks.size()) {
            // 创建新栈
            available.clear();
            stacks.add(new ArrayDeque<>());
            int idx = stacks.size() - 1;
            stacks.get(idx).push(val);
            if (stacks.get(idx).size() < capacity) {
                available.add(idx);
            }
        } else {
            int idx = available.first();
            stacks.get(idx).push(val);
            if (stacks.get(idx).size() == capacity) {
                available.pollFirst();
            }
        }
    }

    public int pop() {
        // 找最右非空栈
        while (!stacks.isEmpty() && stacks.get(stacks.size() - 1).isEmpty()) {
            stacks.remove(stacks.size() - 1);
        }
        if (stacks.isEmpty()) return -1;
        int idx = stacks.size() - 1;
        int val = stacks.get(idx).pop();
        available.add(idx);
        return val;
    }

    public int popAtStack(int index) {
        if (index >= stacks.size() || stacks.get(index).isEmpty()) return -1;
        int val = stacks.get(index).pop();
        available.add(index);
        return val;
    }
}
```

## 复杂度分析

- **push**：O(log n)
- **pop**：均摊 O(log n)
- **popAtStack**：O(log n)

## 关键点总结

1. **TreeSet 维护可用索引**：有序获取最左未满栈
2. **动态扩展**：无可用栈时创建新栈
3. **右端收缩**：pop 时移除末尾空栈
4. **popAtStack 后标记可用**：弹出后该栈变为未满
