## 题目描述

给你字符串 `s` 和整数 `k`。若存在长度为 k 的子字符串满足：所有字符相同，且该字符在整个 s 中恰好出现 k 次，则返回 `true`，否则返回 `false`。

## 解题思路

遍历所有连续相同字符段，若某段长度恰好为 k，且该字符在 s 中总出现次数为 k，则返回 true。

## Java 代码实现

```java
class Solution {
    public boolean hasSpecialSubstring(String s, int k) {
        int n = s.length();
        // 统计每个字符的总出现频率
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        // 枚举所有连续相同字符段
        int i = 0;
        while (i < n) {
            char c = s.charAt(i);
            int j = i;
            while (j < n && s.charAt(j) == c) j++;
            int segLen = j - i;
            // 段长恰好为 k，且该字符总频率也为 k
            if (segLen == k && freq[c - 'a'] == k) return true;
            i = j;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 两个条件：连续 k 个相同字符 + 该字符在 s 中总出现恰好 k 次
2. 按连续段枚举，O(n) 完成
3. 预处理每个字符的总频率，O(1) 查询
