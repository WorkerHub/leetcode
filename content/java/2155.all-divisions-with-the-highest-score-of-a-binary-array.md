## 题目描述

二进制数组按下标i分为左右两部分，分割得分=左侧0的个数+右侧1的个数，返回所有得分最高的分割下标。

## 解题思路

遍历n+1个分割点，动态维护左侧0数和右侧1数，记录最大分数及其所有下标。

## Java 代码实现

```java
class Solution {
    public List<Integer> maxScoreIndices(int[] nums) {
        int n = nums.length;
        int rightOnes = 0;
        for (int x : nums) rightOnes += x;
        
        int leftZeros = 0;
        int maxScore = -1;
        List<Integer> result = new ArrayList<>();
        
        for (int i = 0; i <= n; i++) {
            int score = leftZeros + rightOnes;
            if (score > maxScore) {
                maxScore = score;
                result = new ArrayList<>();
                result.add(i);
            } else if (score == maxScore) {
                result.add(i);
            }
            // 更新计数
            if (i < n) {
                if (nums[i] == 0) leftZeros++;
                else rightOnes--;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)（不含结果）

## 关键点总结

1. **动态维护计数**：每移动分割点，更新左侧0数或右侧1数
2. **n+1个分割点**：i从0到n，包含左空和右空的情况
3. **先计算得分再更新**：nums[i]从右侧移到左侧
