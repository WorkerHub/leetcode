## 题目描述

设计SORTracker：add添加景点(name,score)，第i次get返回当前第i好的景点名。排序规则：分高优先，同分名字字典序小优先。

## 解题思路

用TreeSet维护有序集合，同时用一个指针追踪当前第i名。每次add后调整指针位置，get时返回指针指向的元素并前进。

## Java 代码实现

```java
class SORTracker {
    // 按(-score, name)排序，TreeSet存储
    private TreeSet<int[]> set;
    private int[] cursor; // 当前指向的元素
    private int queryCount;
    private Map<String, Integer> nameToId;
    private int id;
    
    // 用字符串拼接作为比较key更简洁
    private TreeSet<String> ts;
    private String cur;
    
    public SORTracker() {
        // 按分数降序，同分按名字升序
        ts = new TreeSet<>((a, b) -> {
            int scoreA = Integer.parseInt(a.substring(0, a.indexOf(',')));
            int scoreB = Integer.parseInt(b.substring(0, b.indexOf(',')));
            if (scoreA != scoreB) return scoreB - scoreA;
            return a.substring(a.indexOf(',') + 1).compareTo(b.substring(b.indexOf(',') + 1));
        });
        cur = null;
        queryCount = 0;
    }
    
    public void add(String name, int score) {
        String key = score + "," + name;
        ts.add(key);
        // 如果cursor还没初始化或者新元素在cursor之前（更好）
        if (cur == null) {
            cur = ts.first();
        } else if (ts.comparator().compare(key, cur) < 0) {
            // 新元素排在cursor前面，不影响cursor
        } else {
            // 新元素排在cursor后面或cursor位置，不移动
        }
    }
    
    public String get() {
        queryCount++;
        if (queryCount == 1) {
            cur = ts.first();
        } else {
            cur = ts.higher(cur);
        }
        return cur.substring(cur.indexOf(',') + 1);
    }
}
```

## Java 代码实现

```java
class SORTracker {
    // 双优先队列方案
    // good: 前i名（最大堆按排名规则的反序，即堆顶是第i名）
    // bad: 第i名之后（最小堆按排名规则）
    private PriorityQueue<int[]> good; // 堆顶是前i名中排名最差的
    private PriorityQueue<int[]> bad;  // 堆顶是剩余中排名最好的
    private List<String> names;
    private int idx;
    
    public SORTracker() {
        // good: 排名最差的在顶 -> 分数最低/名字最大
        good = new PriorityQueue<>((a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0]; // 分低在顶
            return names.get(b[1]).compareTo(names.get(a[1])); // 名字大在顶
        });
        // bad: 排名最好的在顶 -> 分数最高/名字最小
        bad = new PriorityQueue<>((a, b) -> {
            if (a[0] != b[0]) return b[0] - a[0]; // 分高在顶
            return names.get(a[1]).compareTo(names.get(b[1])); // 名字小在顶
        });
        names = new ArrayList<>();
        idx = 0;
    }
    
    public void add(String name, int score) {
        int id = names.size();
        names.add(name);
        int[] entry = new int[]{score, id};
        bad.offer(entry);
        // 如果bad堆顶比good堆顶更优，交换
        if (!good.isEmpty()) {
            int[] topBad = bad.peek();
            int[] topGood = good.peek();
            if (isBetter(topBad, topGood)) {
                bad.poll();
                good.poll();
                good.offer(topBad);
                bad.offer(topGood);
            }
        }
    }
    
    public String get() {
        // 将bad堆顶移入good
        int[] top = bad.poll();
        good.offer(top);
        // good堆顶即第i名
        return names.get(good.peek()[1]);
    }
    
    private boolean isBetter(int[] a, int[] b) {
        if (a[0] != b[0]) return a[0] > b[0];
        return names.get(a[1]).compareTo(names.get(b[1])) < 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：add O(log N)，get O(log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **双堆维护第i名**：good堆前i名，bad堆剩余
2. **排序规则**：分高优先，同分名字字典序小优先
3. **get时移动边界**：将bad堆顶移入good
