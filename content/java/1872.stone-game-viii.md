## 题目描述

两人轮流从最左取至少2个石子，取走后石子值之和替换为一块石子放回。双方最优策略，求Alice-Bob得分。

## 解题思路

前缀和+从右到左DP：dp表示当前玩家最优净得分。选择取到位置i，净得=prefix[i]-dp(对方最优)。dp = max(dp, prefix[i]-dp)从右到左更新。

## Java 代码实现

```java
class Solution {
    public int stoneGameVIII(int[] stones) {
        int n = stones.length;
        // 计算前缀和（原地）
        for (int i = 1; i < n; i++) {
            stones[i] += stones[i - 1];
        }
        
        // 从右到左DP
        // dp = 当前玩家面对[i..n-1]时的最优净得分
        int dp = stones[n - 1]; // i=n-1时只能全取
        for (int i = n - 2; i >= 1; i--) {
            dp = Math.max(dp, stones[i] - dp);
        }
        return dp;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和转化**：取前i+1个石子得prefix[i]
2. **净得分DP**：当前玩家净得 = prefix[i] - 对方最优净得
3. **从右到左**：dp = max(dp, prefix[i] - dp)
