## 题目描述

给你一个整数数组 `nums`，每次操作选两个不同下标的元素，移除较大值，代价为较小值。重复操作直到只剩一个元素，返回最小总代价。

## 解题思路

贪心：最小元素每次都与其他元素配对（代价为最小元素），而最小元素本身永不被移除。共执行 n-1 次操作，总代价 = `min(nums) * (n-1)`。

## Java 代码实现

```java
class Solution {
    public long minCost(int[] nums) {
        int minVal = Integer.MAX_VALUE;
        for (int x : nums) {
            minVal = Math.min(minVal, x);
        }
        // 最小值参与 n-1 次配对，每次代价均为最小值
        return (long) minVal * (nums.length - 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作移除较大值，代价为较小值
2. 最优策略：始终用最小元素配对，它永不被移除
3. 总代价 = `min * (n-1)`，使用 `long` 防止溢出
