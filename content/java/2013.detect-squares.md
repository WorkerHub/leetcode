## 题目描述

设计数据结构支持添加点（允许重复）和查询以给定点为角点的轴对齐正方形数目（重复点分别计数）。

## 解题思路

`count(px, py)` 时枚举与 (px, py) 同 x 坐标的所有点 (px, y)，确定边长 `side = |y-py|`，再查找另外两个角点 `(px+side, py)` 和 `(px+side, y)` 的出现次数之积（正负两个方向各枚举一次）。

## Java 代码实现

### 方法一：哈希表枚举对角点（推荐）

```java
import java.util.*;

class DetectSquares {
    private Map<String, Integer> pointCount;
    private Map<Integer, Set<Integer>> xToYs;

    public DetectSquares() {
        pointCount = new HashMap<>();
        xToYs = new HashMap<>();
    }

    public void add(int[] point) {
        int x = point[0], y = point[1];
        pointCount.merge(x + "," + y, 1, Integer::sum);
        xToYs.computeIfAbsent(x, k -> new HashSet<>()).add(y);
    }

    public int count(int[] point) {
        int px = point[0], py = point[1];
        int result = 0;

        if (!xToYs.containsKey(px)) return 0;

        // 枚举与point同x坐标的所有点(px, y)
        for (int y : xToYs.get(px)) {
            if (y == py) continue; // 边长不能为0
            int side = Math.abs(y - py);

            // 枚举两个方向的对角点
            for (int dx : new int[]{side, -side}) {
                int x = px + dx;
                int cnt1 = pointCount.getOrDefault(x + "," + py, 0);
                int cnt2 = pointCount.getOrDefault(x + "," + y, 0);
                int cnt3 = pointCount.getOrDefault(px + "," + y, 0);
                result += cnt1 * cnt2 * cnt3;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- add：O(1)
- count：O(n)，n 为不同 y 坐标数

## 关键点总结

1. 固定一个角点，枚举同 x 坐标的点确定边长，查找另外两个角点
2. 对角点在两个方向（+side 和 -side）都要枚举
3. 重复点乘以各角点出现次数之积
