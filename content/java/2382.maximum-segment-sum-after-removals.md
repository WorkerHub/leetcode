## 题目描述

给你整数数组 `nums` 和删除顺序数组 `removeQueries`，第 i 次查询删除 `removeQueries[i]` 位置的元素，返回每次查询后各连续非删除段的最大和。

## 解题思路

逆向 + 并查集：倒序处理（相当于逐步添加元素），用并查集维护连通分量及其和，每次添加一个元素时合并与左右邻居的分量，同时更新最大段和。

## Java 代码实现

```java
class Solution {
    private int[] parent;
    private long[] segSum;

    public long[] maximumSegmentSum(int[] nums, int[] removeQueries) {
        int n = nums.length;
        parent = new int[n];
        segSum = new long[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        boolean[] added = new boolean[n];
        long maxSum = 0;
        long[] ans = new long[n];

        // 逆向添加元素
        for (int i = n - 1; i >= 0; i--) {
            int idx = removeQueries[i];
            added[idx] = true;
            segSum[idx] = nums[idx];
            // 合并左邻
            if (idx > 0 && added[idx - 1]) union(idx, idx - 1);
            // 合并右邻
            if (idx < n - 1 && added[idx + 1]) union(idx, idx + 1);
            maxSum = Math.max(maxSum, segSum[find(idx)]);
            ans[i] = maxSum;
        }
        return ans;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        parent[ry] = rx;
        segSum[rx] += segSum[ry];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * alpha(n))
- **空间复杂度**：O(n)

## 关键点总结

1. 逆向思维：删除变添加，并查集维护连通分量。
2. 每次添加元素后合并左右邻居，更新分量和。
3. `maxSum` 单调不减，直接取历史最大值即可。
