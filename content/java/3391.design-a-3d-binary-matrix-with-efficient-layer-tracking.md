## 题目描述

设计三维二进制矩阵类，支持设置/清除单元格，以及查询 1 最多的层（固定 x 坐标的切面），相同时返回最大 x。

## Java 代码实现

```java
class Matrix3D {
    private int n;
    private boolean[][][] matrix;
    private int[] layerCount; // 每层（固定 x）中 1 的数量

    public Matrix3D(int n) {
        this.n = n;
        this.matrix = new boolean[n][n][n];
        this.layerCount = new int[n];
    }

    public void setCell(int x, int y, int z) {
        if (!matrix[x][y][z]) {
            matrix[x][y][z] = true;
            layerCount[x]++;
        }
    }

    public void unsetCell(int x, int y, int z) {
        if (matrix[x][y][z]) {
            matrix[x][y][z] = false;
            layerCount[x]--;
        }
    }

    public int largestMatrix() {
        int bestX = 0, bestCount = -1;
        // 遍历找最大计数，相同时取最大 x（用 >= 更新）
        for (int x = 0; x < n; x++) {
            if (layerCount[x] >= bestCount) {
                bestCount = layerCount[x];
                bestX = x;
            }
        }
        return bestX;
    }
}
```

## 复杂度分析

- `setCell` / `unsetCell`：O(1)
- `largestMatrix`：O(n)，遍历所有层

## 关键点总结

1. 维护每层（固定 x）的 1 计数，避免每次遍历整个矩阵。
2. 更新时先判断当前值，避免重复操作影响计数。
3. 相同计数取最大 x：遍历时用 `>=` 更新。
