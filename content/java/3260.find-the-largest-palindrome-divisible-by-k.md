## 题目描述

给你两个正整数 `n` 和 `k`（`1 <= k <= 9`），找出能被 `k` 整除的最大 `n` 位回文整数，以字符串形式返回，不存在则返回 `""`。

## 解题思路

回文数由前 `ceil(n/2)` 位决定。预计算每个位置的权重（对回文总数 mod k 的贡献），然后贪心从高位到低位每位尽量选 9，用回溯找到满足 mod k = 0 的方案。

## Java 代码实现

```java
class Solution {
    private int k;
    private int[] posWeight;
    private int[] digits;
    private int half;

    public String largestPalindrome(int n, int k) {
        this.k = k;
        half = (n + 1) / 2;
        digits = new int[half];
        posWeight = new int[half];

        // 预计算每个位置对回文数 mod k 的贡献权重
        for (int i = 0; i < half; i++) {
            int mirror = n - 1 - i;
            if (i == mirror) {
                // 中间位
                posWeight[i] = pow10mod(i, k);
            } else {
                posWeight[i] = (pow10mod(i, k) + pow10mod(mirror, k)) % k;
            }
        }

        if (!greedy(0, 0)) return "";

        // 构造回文字符串
        StringBuilder sb = new StringBuilder();
        for (int d : digits) sb.append(d);
        String front = sb.toString();
        String back = new StringBuilder(front).reverse().toString();
        if (n % 2 == 1) {
            return front + back.substring(1);
        } else {
            return front + back;
        }
    }

    private boolean greedy(int pos, int currentMod) {
        if (pos == half) return currentMod == 0;
        int start = (pos == 0) ? 1 : 0; // 首位不能为 0
        for (int d = 9; d >= start; d--) {
            int newMod = (currentMod + d * posWeight[pos]) % k;
            digits[pos] = d;
            if (greedy(pos + 1, newMod)) return true;
        }
        return false;
    }

    private int pow10mod(int exp, int mod) {
        // 计算 10^exp mod k
        long result = 1;
        for (int i = 0; i < exp; i++) result = result * 10 % mod;
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * n/2) = O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 回文数由前半部分唯一决定，每位对 mod k 的贡献可预计算
2. 贪心从高位到低位，每位尽量选 9
3. 首位不能为 0，k=1 时任何数都满足
