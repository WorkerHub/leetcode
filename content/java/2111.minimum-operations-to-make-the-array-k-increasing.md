## 题目描述

给定数组arr和正整数k，每次操作可改一个元素为任意值，求使数组变成k递增（arr[i-k]<=arr[i]）的最少操作次数。

## 解题思路

按步长k拆成k个子序列，每个子序列需不递减。最少操作 = 子序列长度 - 最长不递减子序列(LNDS)长度。用二分+patience sorting求LNDS。

## Java 代码实现

```java
class Solution {
    public int kIncreasing(int[] arr, int k) {
        int totalOps = 0;
        for (int start = 0; start < k; start++) {
            // 提取子序列
            List<Integer> subseq = new ArrayList<>();
            for (int i = start; i < arr.length; i += k) {
                subseq.add(arr[i]);
            }
            totalOps += subseq.size() - lndsLength(subseq);
        }
        return totalOps;
    }
    
    // 最长不递减子序列长度（允许相等）
    private int lndsLength(List<Integer> seq) {
        List<Integer> tails = new ArrayList<>();
        for (int x : seq) {
            // bisect_right: 找第一个 > x 的位置
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails.get(mid) <= x) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) {
                tails.add(x);
            } else {
                tails.set(lo, x);
            }
        }
        return tails.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **按步长k拆分**：k个独立子序列互不影响
2. **不递减用bisect_right**：允许相等所以找第一个严格大于的位置
3. **最少操作 = 长度 - LNDS长度**：保留最长不递减部分
