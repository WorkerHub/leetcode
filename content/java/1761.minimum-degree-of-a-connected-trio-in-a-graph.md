## 题目描述

给你 `n` 个节点的无向图，返回所有连通三元组（三个两两相连的节点）中度数的最小值（三节点度数之和减 6）。若不存在返回 `-1`。

## 解题思路

用邻接矩阵枚举所有三元组 `(u, v, w)`（u < v < w），若三对边均存在，则计算三元组度数 = `deg[u] + deg[v] + deg[w] - 6`，取最小值。

## Java 代码实现

```java
class Solution {
    public int minTrioDegree(int n, int[][] edges) {
        boolean[][] adj = new boolean[n + 1][n + 1];
        int[] deg = new int[n + 1];

        for (int[] e : edges) {
            adj[e[0]][e[1]] = true;
            adj[e[1]][e[0]] = true;
            deg[e[0]]++;
            deg[e[1]]++;
        }

        int ans = Integer.MAX_VALUE;

        // 枚举所有三元组 u < v < w
        for (int u = 1; u <= n; u++) {
            for (int v = u + 1; v <= n; v++) {
                if (!adj[u][v]) continue;
                for (int w = v + 1; w <= n; w++) {
                    if (adj[u][w] && adj[v][w]) {
                        // 内部三条边各被计数两次，共减 6
                        int degree = deg[u] + deg[v] + deg[w] - 6;
                        ans = Math.min(ans, degree);
                    }
                }
            }
        }

        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^3)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 邻接矩阵 O(1) 判断边是否存在
2. 三元组度数 = 三节点度数之和 - 6（三条内部边各计两次）
