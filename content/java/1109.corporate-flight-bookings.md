## 题目描述

n 个航班，预订记录 `bookings[i] = [first, last, seats]` 表示在 first 到 last 的每个航班预订 seats 个座位。返回每个航班的总座位数。

**示例：**
```
输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
```

## 解题思路

差分数组：对每个预订在 first 处 +seats、在 last+1 处 -seats，最后求前缀和得结果。

## Java 代码实现

```java
class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        int[] diff = new int[n + 2]; // 多分配避免越界

        // 差分操作
        for (int[] b : bookings) {
            diff[b[0]] += b[2];
            diff[b[1] + 1] -= b[2];
        }

        // 前缀和还原
        int[] answer = new int[n];
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += diff[i];
            answer[i - 1] = sum;
        }

        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)，m 为预订数
- **空间复杂度**：O(n)

## 关键点总结

1. **差分数组**：区间修改 O(1)，最后前缀和还原
2. **边界处理**：last+1 处减去，数组多分配 1 位防越界
3. **1-indexed**：航班从 1 编号，注意下标转换
