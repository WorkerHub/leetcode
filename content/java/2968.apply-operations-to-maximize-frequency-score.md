## 题目描述

给你整数数组 `nums` 和整数 `k`，每次操作可将任意元素加减 1，共可操作 k 次，返回操作后最高频率的最大值。

## 解题思路

排序后滑动窗口：以 nums[right] 为目标值，窗口内所有元素增大到 nums[right] 的代价 = `nums[right]*(right-left+1) - sum(window)`，超过 k 则收缩左端。用前缀和 O(1) 计算窗口和。

## Java 代码实现

```java
class Solution {
    public int maxFrequencyScore(int[] nums, long k) {
        Arrays.sort(nums);
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        int ans = 1, left = 0;
        for (int right = 0; right < n; right++) {
            // 窗口内全部变为 nums[right] 的代价
            while ((long) nums[right] * (right - left + 1) - (prefix[right + 1] - prefix[left]) > k) {
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序后以 nums[right] 为目标，代价 = target*len - windowSum
2. 前缀和 O(1) 查询窗口和
3. k 可达 10^14，代价计算需用 long
