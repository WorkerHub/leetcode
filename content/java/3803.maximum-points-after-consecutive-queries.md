## 题目描述

给定整数数组 `nums` 和查询数组 `queries`，每次查询将 `nums[l..r]` 加上 `val`，执行后选一个元素加入得分，返回所有查询后的最大总得分。

## Java 代码实现

```java
class Solution {
    private long[] tree, lazy;
    private int n;

    public long maximumPoints(int[] nums, int[][] queries) {
        n = nums.length;
        tree = new long[4 * n];
        lazy = new long[4 * n];
        build(nums, 1, 0, n - 1);

        long total = 0;
        for (int[] q : queries) {
            update(1, 0, n - 1, q[0], q[1], q[2]);
            total += tree[1]; // 根节点为全局最大值
        }
        return total;
    }

    private void build(int[] arr, int node, int start, int end) {
        if (start == end) { tree[node] = arr[start]; return; }
        int mid = (start + end) >>> 1;
        build(arr, 2 * node, start, mid);
        build(arr, 2 * node + 1, mid + 1, end);
        tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
    }

    private void pushDown(int node) {
        if (lazy[node] != 0) {
            for (int child : new int[]{2 * node, 2 * node + 1}) {
                tree[child] += lazy[node];
                lazy[child] += lazy[node];
            }
            lazy[node] = 0;
        }
    }

    private void update(int node, int start, int end, int l, int r, long val) {
        if (r < start || end < l) return;
        if (l <= start && end <= r) {
            tree[node] += val;
            lazy[node] += val;
            return;
        }
        pushDown(node);
        int mid = (start + end) >>> 1;
        update(2 * node, start, mid, l, r, val);
        update(2 * node + 1, mid + 1, end, l, r, val);
        tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. 线段树支持区间加和全局最大值查询
2. 懒惰传播保证区间更新 O(log n)
3. 每次查询后贪心取根节点（全局最大值）
