## 题目描述

给你整数数组 `nums`、`cost` 和整数 `k`，将 `nums` 分成若干子数组，第 j 个子数组（0-indexed）的代价为 `cost[j] * (该子数组首元素前所有元素之和 + k * j)`，返回最小总代价。

## 解题思路

二维 DP + 前缀和优化：`dp[i][t]` = 前 i 个元素分成 t 个子数组的最小代价。固定 t 后代价 = `cost[t-1] * k*(t-1)` + `cost[t-1] * prefix[j]`，维护 `min(prev[j] + cost[t-1] * prefix[j])` 随 i 增大逐步更新，内层转移 O(1)。

## Java 代码实现

```java
class Solution {
    public long minimumCost(int[] nums, int[] cost, int k) {
        int n = nums.length;
        long INF = Long.MAX_VALUE / 2;

        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        // 滚动数组：prev[j] = dp[j][t-1]
        long[] prev = new long[n + 1];
        java.util.Arrays.fill(prev, INF);
        prev[0] = 0;

        long ans = INF;

        for (int t = 1; t <= n; t++) {
            long[] curr = new long[n + 1];
            java.util.Arrays.fill(curr, INF);

            long c = cost[t - 1];
            long base = c * k * (t - 1); // 常数部分
            long minVal = INF;            // min(prev[j] + c * prefix[j])

            for (int i = t; i <= n; i++) {
                int j = i - 1;
                // 更新 minVal（j 从 t-1 到 i-1）
                if (prev[j] != INF) {
                    long candidate = prev[j] + c * prefix[j];
                    if (candidate < minVal) minVal = candidate;
                }
                if (minVal != INF) {
                    curr[i] = base + minVal;
                }
            }

            prev = curr;
            if (prev[n] != INF) ans = Math.min(ans, prev[n]);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，每层 t 的转移 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `dp[i][t] = base + min(prev[j] + c * prefix[j])`，分解常数和变量部分
2. minVal 随 i 增大单调更新，使内层 O(1)
3. 使用 `long` 防止 cost * k * n 溢出
