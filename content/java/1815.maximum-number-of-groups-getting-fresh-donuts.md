## 题目描述

给你 `batchSize` 和顾客批次数组 `groups`，每批顾客到来时若剩余甜甜圈为 0 则快乐。安排顾客顺序使快乐批次最多，返回最大快乐批次数。

## 解题思路

1. 余数为 0 的组直接快乐（贪心先放），互补余数 r 和 batchSize-r 的组配对也各贡献一个快乐组
2. 剩余组用状态压缩 DP：状态 = 各余数（1 ~ batchSize-1）的剩余数量（因 batchSize <= 9，状态空间有限）
3. 用 HashMap 做记忆化，key 为余数计数数组 + 当前剩余

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int batchSize;
    private Map<String, Integer> memo = new HashMap<>();

    public int maxHappyGroups(int batchSize, int[] groups) {
        this.batchSize = batchSize;
        int[] cnt = new int[batchSize];
        int result = 0;

        for (int g : groups) {
            int r = g % batchSize;
            if (r == 0) result++; // 余数为 0 直接快乐
            else cnt[r]++;
        }

        // 互补余数配对
        for (int r = 1; r <= batchSize / 2; r++) {
            int comp = batchSize - r;
            if (r == comp) {
                result += cnt[r] / 2;
                cnt[r] %= 2;
            } else {
                int pairs = Math.min(cnt[r], cnt[comp]);
                result += pairs;
                cnt[r] -= pairs;
                cnt[comp] -= pairs;
            }
        }

        // 余数 1 ~ batchSize-1 的剩余组用 DP
        return result + dp(Arrays.copyOfRange(cnt, 1, batchSize), 0);
    }

    private int dp(int[] state, int leftover) {
        String key = Arrays.toString(state) + "," + leftover;
        if (memo.containsKey(key)) return memo.get(key);

        int best = 0;
        for (int r = 1; r < batchSize; r++) {
            if (state[r - 1] > 0) {
                state[r - 1]--;
                int gain = (leftover == 0) ? 1 : 0;
                best = Math.max(best, gain + dp(state, (leftover + r) % batchSize));
                state[r - 1]++;
            }
        }

        memo.put(key, best);
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(batchSize * 状态数)，状态数由各余数计数决定
- **空间复杂度**：O(状态数)

## 关键点总结

1. 贪心预处理：余数 0 直接快乐，互补余数配对
2. 状态 = 各余数剩余数量 + 当前 leftover，与顺序无关
3. batchSize <= 9，余数种类少，状态空间可接受
