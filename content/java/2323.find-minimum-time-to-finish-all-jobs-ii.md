## 题目描述

给你两个长度为 n 的数组 `jobs` 和 `workers`，每份工作恰好由一名工人完成，完成工作 i 由工人 j 完成需要 `ceil(jobs[i]/workers[j])` 天，返回完成所有工作所需最大天数的最小值。

## 解题思路

贪心：将最大的工作分配给最强的工人。对 `jobs` 和 `workers` 分别排序后，按对应索引配对（大工作配大工人），可以最小化最大天数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumTime(int[] jobs, int[] workers) {
        Arrays.sort(jobs);
        Arrays.sort(workers);
        int ans = 0;
        for (int i = 0; i < jobs.length; i++) {
            // 向上取整：(jobs[i] + workers[i] - 1) / workers[i]
            int days = (jobs[i] + workers[i] - 1) / workers[i];
            ans = Math.max(ans, days);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心策略：大工作配大工人，通过交换论证法可证最优。
2. 整数向上取整公式：`(a + b - 1) / b`，避免浮点误差。
3. 两个数组分别排序后同索引配对。
