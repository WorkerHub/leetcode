## 题目描述

实现 `RandomizedSet` 类：

- `RandomizedSet()` 初始化 `RandomizedSet` 对象
- `bool insert(int val)` 当元素 `val` 不存在时，向集合中插入该项，并返回 `true`；否则，返回 `false`
- `bool remove(int val)` 当元素 `val` 存在时，从集合中移除该项，并返回 `true`；否则，返回 `false`
- `int getRandom()` 随机返回现有集合中的一项（测试用例保证调用此方法时集合中至少存在一个元素）。每个元素应该有相同的概率被返回

你必须实现类的所有函数，并满足每个函数的平均时间复杂度为 `O(1)`。

**示例：**

```
输入：
["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"]
[[], [1], [2], [2], [], [1], [2], []]

输出：
[null, true, false, true, 2, true, false, 2]

解释：
RandomizedSet randomizedSet = new RandomizedSet();
randomizedSet.insert(1);   // 向集合中插入 1，返回 true 表示 1 被成功地插入
randomizedSet.remove(2);   // 返回 false，表示集合中不存在 2
randomizedSet.insert(2);   // 向集合中插入 2，返回 true，集合现在包含 [1,2]
randomizedSet.getRandom(); // getRandom 应随机返回 1 或 2
randomizedSet.remove(1);   // 从集合中移除 1，返回 true，集合现在包含 [2]
randomizedSet.insert(2);   // 2 已在集合中，所以返回 false
randomizedSet.getRandom(); // 由于 2 是集合中唯一的数字，getRandom 总是返回 2
```

**提示：**
- `-2^31 <= val <= 2^31 - 1`
- 最多调用 `insert`、`remove` 和 `getRandom` 函数 `2 * 10^5` 次
- 在调用 `getRandom` 方法时，数据结构中至少存在一个元素

## 解题思路

这道题的核心挑战是：如何在 O(1) 时间内实现随机返回元素。

### 关键观察

- **插入/删除 O(1)**：可以用哈希表
- **随机返回 O(1)**：需要能用索引访问，即数组

### 解决方案：数组 + 哈希表

**数据结构组合**：
- `nums`：存储所有元素（ArrayList）
- `valToIndex`：存储值到索引的映射（HashMap）

**核心操作**：
1. **insert(val)**：
   - 检查 `val` 是否存在
   - 添加到数组末尾
   - 在哈希表中记录索引
   
2. **remove(val)**：
   - 检查 `val` 是否存在
   - 将数组最后一个元素移到要删除的位置（覆盖）
   - 更新哈希表中最后一个元素的索引
   - 删除数组最后一个元素
   - 删除哈希表中 `val` 的记录
   
3. **getRandom()**：
   - 随机生成索引
   - 返回对应元素

## Java 代码实现

### 方法一：ArrayList + HashMap（标准解法，推荐）

```java
import java.util.*;

class RandomizedSet {
    private List<Integer> nums;          // 存储元素
    private Map<Integer, Integer> valToIndex; // 值 -> 索引
    private Random random;

    public RandomizedSet() {
        nums = new ArrayList<>();
        valToIndex = new HashMap<>();
        random = new Random();
    }

    public boolean insert(int val) {
        // 元素已存在，返回 false
        if (valToIndex.containsKey(val)) return false;

        // 添加到数组末尾
        nums.add(val);
        // 记录索引（末尾索引 = 当前大小 - 1）
        valToIndex.put(val, nums.size() - 1);
        return true;
    }

    public boolean remove(int val) {
        // 元素不存在，返回 false
        if (!valToIndex.containsKey(val)) return false;

        // 获取要删除元素的索引
        int idx = valToIndex.get(val);
        // 获取数组最后一个元素
        int lastVal = nums.get(nums.size() - 1);

        // 将最后一个元素移到要删除的位置（覆盖）
        nums.set(idx, lastVal);
        valToIndex.put(lastVal, idx); // 更新最后一个元素的索引

        // 删除数组最后一个元素
        nums.remove(nums.size() - 1);
        // 删除哈希表中的记录
        valToIndex.remove(val);

        return true;
    }

    public int getRandom() {
        // 随机生成索引，返回对应元素
        return nums.get(random.nextInt(nums.size()));
    }
}
```

### 方法二：与方法一相同，注释更详细

```java
import java.util.*;

class RandomizedSet {
    /**
     * nums: 动态数组，存储所有元素，支持随机访问
     * valToIndex: 哈希表，存储值到索引的映射，支持 O(1) 查找
     */
    private List<Integer> nums;
    private Map<Integer, Integer> valToIndex;
    private Random random;

    public RandomizedSet() {
        nums = new ArrayList<>();
        valToIndex = new HashMap<>();
        random = new Random();
    }

    public boolean insert(int val) {
        /**
         * 插入步骤：
         * 1. 检查元素是否已存在
         * 2. 添加到数组末尾
         * 3. 记录索引到哈希表
         */
        if (valToIndex.containsKey(val)) return false;

        valToIndex.put(val, nums.size());
        nums.add(val);
        return true;
    }

    public boolean remove(int val) {
        /**
         * O(1) 删除的技巧：
         * 1. 将要删除的元素与数组最后一个元素交换（实际是覆盖）
         * 2. 删除数组最后一个元素（ArrayList.remove(size-1) 是 O(1)）
         * 3. 更新哈希表
         */
        if (!valToIndex.containsKey(val)) return false;

        // 要删除元素的索引
        int removeIdx = valToIndex.get(val);
        // 数组最后一个元素
        int lastElement = nums.get(nums.size() - 1);

        // 覆盖：将最后一个元素放到要删除的位置
        nums.set(removeIdx, lastElement);
        valToIndex.put(lastElement, removeIdx);

        // 删除数组最后一个元素和哈希表记录
        nums.remove(nums.size() - 1);
        valToIndex.remove(val);

        return true;
    }

    public int getRandom() {
        // 从数组中随机选择一个元素
        return nums.get(random.nextInt(nums.size()));
    }
}
```

## 复杂度分析

### 所有方法
- `insert`：O(1) 平均时间复杂度
- `remove`：O(1) 平均时间复杂度
- `getRandom`：O(1) 时间复杂度
- 空间复杂度：O(n)，n 为元素个数

## 关键点总结

1. **数据结构组合**：ArrayList + HashMap，各取所长
2. **O(1) 删除技巧**：用最后一个元素覆盖要删除的元素
3. **HashMap 作用**：
   - 快速查找元素是否存在
   - 快速获取元素在数组中的位置
4. **ArrayList 作用**：
   - 支持随机访问
   - 通过索引 O(1) 获取元素
5. **删除顺序很重要**：先更新哈希表，再删除元素

## 易错点

1. **删除顺序**：必须先更新哈希表，再删除元素
2. **边界情况**：删除最后一个元素时，`lastElement == val`，`valToIndex.put(lastElement, idx)` 会重新插入被删除的值，然后 `valToIndex.remove(val)` 会正确删除它
3. **索引更新**：覆盖后要更新最后一个元素的索引
4. **重复插入**：已存在的元素不能重复插入
5. **空集合**：题目保证 `getRandom` 时集合非空，否则要检查
6. **`nums.remove(int index)` vs `nums.remove(Object o)`**：Java 中 `List<Integer>` 调用 `remove(int)` 是按索引删除，`remove(Integer)` 是按值删除，注意区分

## 图解示例

### 示例：insert(1), insert(2), remove(1)

```
初始状态：
nums = []
valToIndex = {}

insert(1):
nums = [1]
valToIndex = {1: 0}

insert(2):
nums = [1, 2]
valToIndex = {1: 0, 2: 1}

remove(1):
1. 要删除的元素索引：0
2. 最后一个元素：2（索引 1）
3. 覆盖：nums[0] = 2
4. 更新：valToIndex[2] = 0
5. 删除：nums.remove(1) -> nums = [2]
6. 删除：valToIndex.remove(1)

结果：
nums = [2]
valToIndex = {2: 0}
```
