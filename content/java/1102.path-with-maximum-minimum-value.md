## 题目描述

给定 m x n 整数矩阵 grid，返回从 (0,0) 到 (m-1,n-1) 的路径中，路径最小值的最大值。只能上下左右移动。

**示例：**
```
输入：grid = [[5,4,5],[1,2,6],[7,4,6]]
输出：4
解释：路径 5→4→5→6→6，最小值为 4
```

## 解题思路

最大堆 + 类 Dijkstra：贪心选择当前能到达的最大值节点，维护路径最小值。到达终点时返回。

## Java 代码实现

```java
class Solution {
    public int maximumMinimumPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        // 最大堆：[路径最小值, 行, 列]
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        pq.offer(new int[]{grid[0][0], 0, 0});

        boolean[][] visited = new boolean[m][n];
        visited[0][0] = true;

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int currMin = curr[0], x = curr[1], y = curr[2];

            // 到达终点
            if (x == m - 1 && y == n - 1) return currMin;

            for (int[] d : dirs) {
                int nx = x + d[0], ny = y + d[1];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && !visited[nx][ny]) {
                    visited[nx][ny] = true;
                    pq.offer(new int[]{Math.min(currMin, grid[nx][ny]), nx, ny});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn log(mn))
- **空间复杂度**：O(mn)

## 关键点总结

1. **最大堆贪心**：优先扩展路径最小值最大的节点
2. **Dijkstra 变形**：松弛条件为 min 而非 sum
3. **visited 标记**：入堆时标记，避免重复访问
