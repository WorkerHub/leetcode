## 题目描述

给定一个整数数组 `nums`，将其排序后，求相邻元素之间差值的最大值。

## 解题思路

排序后，遍历相邻元素之差取最大值即可。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxGap(int[] nums) {
        Arrays.sort(nums);
        int maxDiff = 0;
        for (int i = 1; i < nums.length; i++) {
            maxDiff = Math.max(maxDiff, nums[i] - nums[i-1]);
        }
        return maxDiff;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 最大相邻差值一定在排序后的相邻元素之间取得
2. 所有元素相同时最大差值为 0
