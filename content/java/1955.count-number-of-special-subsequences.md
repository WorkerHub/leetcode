## 题目描述

给你只含 0、1、2 的数组 `nums`，特殊子序列为若干 0 接若干 1 接若干 2（每段至少一个），返回特殊子序列数量 mod 10^9+7。

## 解题思路

三状态 DP：`dp0` 为只含 0 的子序列数，`dp1` 为含 0..1 的子序列数，`dp2` 为完整特殊序列数。遇到数字 k 时：`dpk = dpk * 2 + dp(k-1)`（扩展已有或新接前一阶段）。

## Java 代码实现

```java
class Solution {
    public int countSpecialSubsequences(int[] nums) {
        final int MOD = 1_000_000_007;
        long dp0 = 0, dp1 = 0, dp2 = 0;
        for (int x : nums) {
            if (x == 0) dp0 = (dp0 * 2 + 1) % MOD;
            else if (x == 1) dp1 = (dp1 * 2 + dp0) % MOD;
            else dp2 = (dp2 * 2 + dp1) % MOD;
        }
        return (int) dp2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 三个阶段独立 DP，遇对应数字才更新
2. 转移公式：`dpk = dpk * 2 + dp(k-1)`（扩展已有 + 接在前一阶段末尾）
3. 用 `long` 计算后取模防止溢出
