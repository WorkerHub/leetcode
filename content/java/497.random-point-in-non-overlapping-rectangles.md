## 题目描述

给定一个由非重叠的轴对齐矩形的数组 rects，其中 rects[i] = [ai, bi, xi, yi] 表示 (ai, bi) 是第 i 个矩形的左下角点，(xi, yi) 是第 i 个矩形的右上角点。设计一个算法来随机挑选一个被某一矩形覆盖的整数点。矩形周边上的点也算做是被矩形覆盖。所有满足要求的点必须等概率被返回。

在给定的矩形覆盖的空间内的任何整数点都有可能被返回。

请注意，整数点是具有整数坐标的点。

实现 Solution 类:
- Solution(int[][] rects) 用给定的矩形数组 rects 初始化对象。
- int[] pick() 返回一个随机的整数点 [u, v] 在给定的矩形所覆盖的空间内。

**示例 1：**
```
输入：
["Solution", "pick", "pick", "pick", "pick", "pick"]
[[[[-2, -2, 1, 1], [2, 2, 4, 6]]], [], [], [], [], []]
输出：
[null, [1, -2], [1, -1], [-1, -2], [-2, -2], [0, 0]]

解释：
Solution solution = new Solution([[-2, -2, 1, 1], [2, 2, 4, 6]]);
solution.pick(); // 返回 [1, -2]
solution.pick(); // 返回 [1, -1]
solution.pick(); // 返回 [-1, -2]
solution.pick(); // 返回 [-2, -2]
solution.pick(); // 返回 [0, 0]
```

**提示：**
- 1 <= rects.length <= 100
- rects[i].length == 4
- -10^9 <= ai < xi <= 10^9
- -10^9 <= bi < yi <= 10^9
- xi - ai <= 2000
- yi - bi <= 2000
- 所有的矩形不重叠
- pick 最多被调用 10^4 次

## 解题思路

这道题的核心是实现等概率的随机选择。

### 核心思想

1. **权重随机**：
   - 每个矩形的点数不同
   - 点数多的矩形被选中的概率应该更大
   - 使用前缀和 + 二分查找实现权重随机

2. **两步随机**：
   - 第一步：根据点数权重随机选择一个矩形
   - 第二步：在选中的矩形内随机选择一个点

3. **点数计算**：
   - 矩形 [a, b, x, y] 包含的整数点数：
   - `(x - a + 1) * (y - b + 1)`

4. **前缀和优化**：
   - 预计算每个矩形的点数前缀和
   - 使用二分查找快速定位矩形

## Java 代码实现

### 方法一：前缀和 + 二分查找（推荐）

```java
import java.util.Random;

class Solution {
    private int[][] rects;
    private int[] prefixSum;
    private int total;
    private Random random;

    public Solution(int[][] rects) {
        this.rects = rects;
        this.prefixSum = new int[rects.length];
        this.random = new Random();
        int sum = 0;

        // 计算每个矩形的点数前缀和
        for (int i = 0; i < rects.length; i++) {
            // 矩形包含的整数点数
            int count = (rects[i][2] - rects[i][0] + 1) * (rects[i][3] - rects[i][1] + 1);
            sum += count;
            prefixSum[i] = sum;
        }

        this.total = sum;
    }

    public int[] pick() {
        // 随机选择一个点的序号（0 到 total - 1）
        int target = random.nextInt(total);

        // 二分查找该点所在的矩形（找第一个 prefixSum > target 的位置）
        int left = 0, right = rects.length - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            if (prefixSum[mid] <= target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        int idx = left;
        int[] rect = rects[idx];

        // 该矩形的起始序号
        int prev = idx > 0 ? prefixSum[idx - 1] : 0;
        // 在矩形内的偏移（0-based）
        int offset = target - prev;

        // 计算具体坐标
        int width = rect[2] - rect[0] + 1;
        int dx = offset % width;
        int dy = offset / width;

        return new int[]{rect[0] + dx, rect[1] + dy};
    }
}
```

### 方法二：权重随机（TreeMap 辅助）

```java
import java.util.*;

class Solution {
    private int[][] rects;
    private int[] weights;
    private int total;
    private Random random;

    public Solution(int[][] rects) {
        this.rects = rects;
        this.weights = new int[rects.length];
        this.random = new Random();
        int sum = 0;

        for (int i = 0; i < rects.length; i++) {
            int count = (rects[i][2] - rects[i][0] + 1) * (rects[i][3] - rects[i][1] + 1);
            sum += count;
            weights[i] = sum;
        }

        this.total = sum;
    }

    public int[] pick() {
        // 随机一个 [0, total) 范围的数
        int rand = random.nextInt(total);

        // 找到第一个前缀和 > rand 的矩形
        int idx = 0;
        for (int i = 0; i < weights.length; i++) {
            if (weights[i] > rand) {
                idx = i;
                break;
            }
        }

        int[] rect = rects[idx];

        // 在矩形内随机选择一个点
        int x = rect[0] + random.nextInt(rect[2] - rect[0] + 1);
        int y = rect[1] + random.nextInt(rect[3] - rect[1] + 1);

        return new int[]{x, y};
    }
}
```

### 方法三：TreeMap 实现权重随机

```java
import java.util.*;

class Solution {
    private int[][] rects;
    private TreeMap<Integer, Integer> prefixMap; // 前缀和 -> 矩形索引
    private int total;
    private Random random;

    public Solution(int[][] rects) {
        this.rects = rects;
        this.prefixMap = new TreeMap<>();
        this.random = new Random();
        int sum = 0;

        for (int i = 0; i < rects.length; i++) {
            int count = (rects[i][2] - rects[i][0] + 1) * (rects[i][3] - rects[i][1] + 1);
            sum += count;
            prefixMap.put(sum, i); // 存储前缀和到索引的映射
        }

        this.total = sum;
    }

    public int[] pick() {
        // 随机一个 [1, total] 范围的数
        int rand = random.nextInt(total) + 1;

        // 找到第一个 >= rand 的前缀和对应的矩形
        int idx = prefixMap.ceilingEntry(rand).getValue();
        int[] rect = rects[idx];

        // 计算矩形内的偏移
        int prevSum = prefixMap.floorKey(rand - 1) != null ? prefixMap.floorKey(rand - 1) : 0;
        int offset = rand - prevSum - 1;

        int width = rect[2] - rect[0] + 1;
        return new int[]{rect[0] + offset % width, rect[1] + offset / width};
    }
}
```

## 复杂度分析

**方法一：前缀和 + 二分**
- **初始化时间复杂度**：O(n)
  - 计算前缀和

- **pick 时间复杂度**：O(log n)
  - 二分查找矩形

- **空间复杂度**：O(n)
  - 存储前缀和数组

**方法二：线性扫描**
- **初始化时间复杂度**：O(n)

- **pick 时间复杂度**：O(n)
  - 线性扫描找矩形

- **空间复杂度**：O(n)

## 关键点总结

1. **权重随机**：点数多的矩形被选中概率大
2. **前缀和优化**：快速定位矩形
3. **二分查找**：O(log n) 查找
4. **坐标计算**：offset 转换为 (x, y)
5. **等概率保证**：每个点被选中的概率相同

## 易错点

1. **点数计算**
   - 是 (x2 - x1 + 1) * (y2 - y1 + 1)
   - 不要忘记 +1

2. **随机范围**
   - random.nextInt(total) 生成 [0, total) 范围
   - 要与前缀和的定义一致

3. **二分查找**
   - 找第一个 prefixSum > target 的位置
   - 注意边界条件

4. **offset 计算**
   - 需要减去前一个矩形的点数
   - 第一个矩形特殊处理（prev = 0）

5. **坐标转换**
   - offset % width 是 x 偏移
   - offset / width 是 y 偏移
