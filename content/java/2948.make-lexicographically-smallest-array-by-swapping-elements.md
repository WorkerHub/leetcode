## 题目描述

给你整数数组 `nums` 和正整数 `limit`，可以交换差值不超过 `limit` 的任意两个元素（传递可达），返回字典序最小的结果数组。

## 解题思路

按值排序后，相邻差值 <= limit 的元素属于同一组（可互相交换）。对每组内的原始下标按从小到大顺序依次填入排好序的值，即可得到字典序最小结果。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }

    public int[] lexicographicallySmallestArray(int[] nums, int limit) {
        int n = nums.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 按值排序的下标
        Integer[] sortedIdx = new Integer[n];
        for (int i = 0; i < n; i++) sortedIdx[i] = i;
        Arrays.sort(sortedIdx, (a, b) -> Integer.compare(nums[a], nums[b]));

        // 相邻排序后的元素差值 <= limit 则合并
        for (int i = 1; i < n; i++) {
            if ((long) nums[sortedIdx[i]] - nums[sortedIdx[i - 1]] <= limit) {
                union(sortedIdx[i], sortedIdx[i - 1]);
            }
        }

        // 按组收集原始下标（迭代顺序即为值有序）
        Map<Integer, List<Integer>> groupIdx = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int idx = sortedIdx[i];
            int root = find(idx);
            groupIdx.computeIfAbsent(root, x -> new ArrayList<>()).add(idx);
        }

        int[] ans = Arrays.copyOf(nums, n);
        for (List<Integer> indices : groupIdx.values()) {
            // values 已按值有序（sortedIdx 顺序），提取值
            List<Integer> values = new ArrayList<>();
            for (int idx : indices) values.add(nums[idx]);
            Collections.sort(indices); // 按原始下标排序
            for (int i = 0; i < indices.size(); i++) {
                ans[indices.get(i)] = values.get(i);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 按值排序后，相邻差值 <= limit 的元素在同一连通组（传递性）
2. 同一组内，原始下标越小的位置填入越小的值（字典序最小）
3. 组内按值有序的序列直接来自 sortedIdx 的迭代顺序
