## 题目描述

给你数组 `nums`，差异数组 `diff[i]` = 前缀 `nums[0..i]` 的不同元素数 - 后缀 `nums[i+1..n-1]` 的不同元素数，返回 `diff`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] distinctDifferenceArray(int[] nums) {
        int n = nums.length;
        // 预计算前缀不同元素数
        int[] prefix = new int[n];
        Set<Integer> seen = new HashSet<>();
        for (int i = 0; i < n; i++) {
            seen.add(nums[i]);
            prefix[i] = seen.size();
        }
        // 预计算后缀不同元素数
        int[] suffix = new int[n];
        seen.clear();
        for (int i = n - 1; i >= 0; i--) {
            if (i < n - 1) seen.add(nums[i + 1]);
            suffix[i] = seen.size();
        }
        int[] diff = new int[n];
        for (int i = 0; i < n; i++) diff[i] = prefix[i] - suffix[i];
        return diff;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `diff[i]` = 前缀不同数 - 后缀不同数，后缀从 `i+1` 开始
2. 分别预计算前缀和后缀的不同元素数
