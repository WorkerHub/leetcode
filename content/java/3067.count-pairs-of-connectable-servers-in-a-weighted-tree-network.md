## 题目描述

给你带权无向树和正整数 `signalSpeed`，对每个节点 c，统计通过 c 可连接的服务器对数（两端点到 c 的距离均为 signalSpeed 的倍数）。

## 解题思路

枚举每个节点 c 作为中转点，对 c 的每个子树用 DFS 统计距离为 signalSpeed 倍数的节点数，利用乘法原理统计不同子树间的节点对数。

## Java 代码实现

```java
class Solution {
    private List<int[]>[] graph;
    private int signalSpeed;

    public int[] countPairsOfConnectableServers(int[][] edges, int signalSpeed) {
        int n = edges.length + 1;
        this.signalSpeed = signalSpeed;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        int[] result = new int[n];
        for (int c = 0; c < n; c++) {
            int prev = 0;
            for (int[] nb : graph[c]) {
                // 统计该子树中距离为 signalSpeed 倍数的节点数
                int cnt = dfs(nb[0], c, nb[1]);
                result[c] += prev * cnt; // 与之前子树的节点配对
                prev += cnt;
            }
        }
        return result;
    }

    private int dfs(int node, int parent, int dist) {
        // 距离为 signalSpeed 倍数则计数
        int count = (dist % signalSpeed == 0) ? 1 : 0;
        for (int[] nb : graph[node]) {
            if (nb[0] != parent) {
                count += dfs(nb[0], node, dist + nb[1]);
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，枚举 n 个中转点，每次 DFS O(n)
- **空间复杂度**：O(n)，递归栈和图

## 关键点总结

1. 枚举每个节点 c 作为中转点
2. 对 c 的每个子树，统计距离为 signalSpeed 倍数的节点数
3. 不同子树的节点可以配对（乘法原理，用前缀和累计避免重复）
