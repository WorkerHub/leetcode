## 题目描述

给你整数数组 `nums` 和正整数 `k`，子数组的值定义为首尾元素的较大值，返回值等于 k 的子数组数量。

## 解题思路

枚举所有子数组的起点和终点，判断 `max(nums[i], nums[j]) == k` 即可（n <= 100，暴力可行）。

## Java 代码实现

```java
class Solution {
    public int countSubarrays(int[] nums, int k) {
        int n = nums.length, count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                // 子数组值为首尾元素的较大值
                if (Math.max(nums[i], nums[j]) == k) {
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，n <= 100 完全可行
- **空间复杂度**：O(1)

## 关键点总结

1. 子数组的值是首尾元素的最大值，不是整个子数组的最大值
2. 枚举所有 (i, j) 对（i <= j），包括单元素子数组（i == j）
3. 单元素子数组值 = nums[i] 本身
