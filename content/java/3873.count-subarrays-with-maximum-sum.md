## 题目描述

给你一个整数数组 `nums`，统计和等于全局最大子数组和的子数组数目。

## 解题思路

两步法：先用 Kadane 算法求出最大子数组和 `maxSum`；再用前缀和 + 哈希表统计所有和恰好等于 `maxSum` 的子数组数目（子数组和 = 当前前缀和 - 某历史前缀和，即查询 `prefix - maxSum` 是否在哈希表中）。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countSubarraysWithMaxSum(int[] nums) {
        // Step 1：Kadane 算法求最大子数组和
        long maxSum = Long.MIN_VALUE;
        long curr = 0;
        for (int v : nums) {
            curr = Math.max(v, curr + v);
            maxSum = Math.max(maxSum, curr);
        }

        // Step 2：前缀和 + 哈希表统计和等于 maxSum 的子数组数目
        Map<Long, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0L, 1); // 空前缀，前缀和为 0
        long prefix = 0;
        int count = 0;

        for (int v : nums) {
            prefix += v;
            // 若 prefix - maxSum 在前缀和中出现过，则存在和为 maxSum 的子数组
            count += prefixCount.getOrDefault(prefix - maxSum, 0);
            prefixCount.merge(prefix, 1, Integer::sum);
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希表存储前缀和

## 关键点总结

1. Kadane 算法求最大子数组和为 O(n)。
2. 前缀和 + 哈希表统计和为指定值的子数组数目为 O(n)。
3. 哈希表初始化 `prefixCount[0] = 1`（对应空前缀），查询时用 `prefix - maxSum`。
