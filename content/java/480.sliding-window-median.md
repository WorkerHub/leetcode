## 题目描述

中位数是有序序列最中间的那个数。如果序列的长度是偶数，则没有最中间的数；此时中位数是最中间的两个数的平均数。

例如：
- `[2,3,4]`，中位数是 `3`
- `[2,3]`，中位数是 `(2 + 3) / 2 = 2.5`

给你一个数组 `nums`，有一个长度为 `k` 的窗口从最左端滑动到最右端。窗口中有 `k` 个数，每次窗口向右移动 `1` 位。你的任务是找出每次窗口移动后得到的新窗口中元素的中位数，并输出由它们组成的数组。

**示例：**
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[1.00000,-1.00000,-1.00000,3.00000,5.00000,6.00000]
解释：
窗口位置                      中位数
---------------               -----
[1  3  -1] -3  5  3  6  7       1
 1 [3  -1  -3] 5  3  6  7      -1
 1  3 [-1  -3  5] 3  6  7      -1
 1  3  -1 [-3  5  3] 6  7       3
 1  3  -1  -3 [5  3  6] 7       5
 1  3  -1  -3  5 [3  6  7]      6
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 解题思路

**核心思想：** 使用两个堆维护窗口的有序状态。

- **大顶堆（小的一半）：** 存储较小的 k/2 个元素
- **小顶堆（大的一半）：** 存储较大的 k/2 个元素
- 中位数就在两个堆顶

**难点：** 滑动窗口需要删除元素，堆不支持高效删除。

**解决方案：** 延迟删除（懒删除）
- 用哈希表记录待删除的元素
- 在访问堆顶时清理

## Java 代码实现

### 方法一：双堆 + 延迟删除（推荐）⭐

```java
import java.util.*;

class Solution {
    public double[] medianSlidingWindow(int[] nums, int k) {
        // 大顶堆（存储较小的一半）
        PriorityQueue<Integer> small = new PriorityQueue<>(Collections.reverseOrder());
        // 小顶堆（存储较大的一半）
        PriorityQueue<Integer> large = new PriorityQueue<>();
        // 延迟删除的哈希表
        Map<Integer, Integer> delayed = new HashMap<>();

        // 初始化前 k 个元素
        for (int i = 0; i < k; i++) {
            small.offer(nums[i]);
        }

        // 平衡两个堆：将大顶堆多出的元素移入小顶堆
        for (int i = 0; i < k / 2; i++) {
            large.offer(small.poll());
        }

        int n = nums.length;
        double[] result = new double[n - k + 1];
        result[0] = getMedian(small, large, k);

        // 滑动窗口
        for (int i = k; i < n; i++) {
            // 移出的元素
            int outNum = nums[i - k];
            // 移入的元素
            int inNum = nums[i];

            // 记录延迟删除
            delayed.merge(outNum, 1, Integer::sum);

            // 根据移出/移入位置决定平衡方向
            int balance = 0;
            if (outNum <= small.peek()) {
                balance--;
            } else {
                balance++;
            }

            if (inNum <= small.peek()) {
                small.offer(inNum);
                balance++;
            } else {
                large.offer(inNum);
                balance--;
            }

            // 平衡堆大小
            if (balance < 0) {
                small.offer(large.poll());
            } else if (balance > 0) {
                large.offer(small.poll());
            }

            // 清理大顶堆堆顶的延迟删除元素
            while (!small.isEmpty() && delayed.getOrDefault(small.peek(), 0) > 0) {
                delayed.merge(small.peek(), -1, Integer::sum);
                small.poll();
            }

            // 清理小顶堆堆顶的延迟删除元素
            while (!large.isEmpty() && delayed.getOrDefault(large.peek(), 0) > 0) {
                delayed.merge(large.peek(), -1, Integer::sum);
                large.poll();
            }

            result[i - k + 1] = getMedian(small, large, k);
        }

        return result;
    }

    private double getMedian(PriorityQueue<Integer> small, PriorityQueue<Integer> large, int k) {
        if (k % 2 == 1) {
            return (double) small.peek();
        } else {
            return ((double) small.peek() + large.peek()) / 2.0;
        }
    }
}
```

### 方法二：TreeMap 模拟有序集合

```java
import java.util.*;

class Solution {
    public double[] medianSlidingWindow(int[] nums, int k) {
        // 使用 TreeMap 模拟有序多重集合（键为元素值，值为出现次数）
        TreeMap<Integer, Integer> window = new TreeMap<>();
        int n = nums.length;
        double[] result = new double[n - k + 1];

        // 初始化前 k 个元素
        for (int i = 0; i < k; i++) {
            window.merge(nums[i], 1, Integer::sum);
        }

        for (int i = 0; i <= n - k; i++) {
            // 计算中位数
            result[i] = getMedianFromMap(window, k);

            // 滑动窗口
            if (i + k < n) {
                // 移入新元素
                window.merge(nums[i + k], 1, Integer::sum);
                // 移出旧元素
                int old = nums[i];
                if (window.get(old) == 1) window.remove(old);
                else window.merge(old, -1, Integer::sum);
            }
        }

        return result;
    }

    // 从 TreeMap 中找第 need1 和 need2 小的元素并求均值
    private double getMedianFromMap(TreeMap<Integer, Integer> map, int k) {
        int need1 = (k + 1) / 2;  // 下中位（奇偶通用）
        int need2 = k / 2 + 1;   // 上中位（偶数时与 need1 不同）
        int count = 0;
        long val1 = 0, val2 = 0;
        boolean found1 = false, found2 = false;

        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            count += entry.getValue();
            if (!found1 && count >= need1) {
                val1 = entry.getKey();
                found1 = true;
            }
            if (!found2 && count >= need2) {
                val2 = entry.getKey();
                found2 = true;
            }
            if (found1 && found2) break;
        }

        // 奇数 k 时 val1 == val2，均值即中位数；偶数 k 时取两者平均
        return (val1 + val2) / 2.0;
    }
}
```

## 复杂度分析

**方法一（双堆）：**
- 时间复杂度：O(n log k)
- 空间复杂度：O(k)

**方法二（TreeMap）：**
- 时间复杂度：O(n log k)
- 空间复杂度：O(k)

## 关键点总结

1. **双堆维护：** 小的一半和大的一半
2. **延迟删除：** 哈希表记录，堆顶清理
3. **平衡策略：** 保持两个堆大小差不超过 1
4. **中位数计算：** 根据 k 的奇偶性

## 易错点

1. **堆的平衡：** 必须保持大小关系
2. **延迟删除的清理：** 访问堆顶前清理
3. **边界情况：** k = 1 或 k = n
