## 题目描述

给你完全二叉树的节点代价数组 `cost`，每次操作可对任意节点增加代价，使所有根到叶路径的总代价相等，返回最少增加的总代价。

## Java 代码实现

```java
class Solution {
    public int minIncrements(int n, int[] cost) {
        int ans = 0;
        // 从最后一个内部节点开始（倒序处理）
        for (int i = n / 2; i >= 1; i--) {
            int left = cost[2 * i - 1];  // 左子节点（0-indexed: 2i-1）
            int right = cost[2 * i];     // 右子节点（0-indexed: 2i）
            // 将较小的增加到较大，差值即为需要增加的代价
            ans += Math.abs(left - right);
            // 将较大值传递给父节点
            cost[i - 1] += Math.max(left, right);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：从叶节点往上，使兄弟节点的路径和相等（补差值）
2. 将较大值传递给父节点，父节点加上后再向上传递
