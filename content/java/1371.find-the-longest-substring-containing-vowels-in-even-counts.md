## 题目描述

给你一个字符串 `s`，返回满足每个元音字母（a/e/i/o/u）均出现偶数次（含 0 次）的最长子字符串的长度。

## 解题思路

用 5 位二进制掩码表示 5 个元音的奇偶状态（1 为奇数次，0 为偶数次），遍历时对当前字符对应位异或翻转。若子串 `s[l..r]` 满足条件，则 `state[r] == state[l-1]`，等价于找前缀状态中相同状态的最远距离。用哈希表记录每个状态首次出现位置，当前状态已出现过则更新最大长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findTheLongestSubstring(String s) {
        // 5 个元音对应的位：a→0, e→1, i→2, o→3, u→4
        Map<Character, Integer> vowelBit = new HashMap<>();
        vowelBit.put('a', 1);
        vowelBit.put('e', 2);
        vowelBit.put('i', 4);
        vowelBit.put('o', 8);
        vowelBit.put('u', 16);

        // 记录每个状态首次出现的位置，状态 0 在位置 -1（空前缀）
        int[] firstSeen = new int[32];
        Arrays.fill(firstSeen, Integer.MIN_VALUE);
        firstSeen[0] = -1;

        int state = 0;
        int maxLen = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            // 若是元音则翻转对应位
            if (vowelBit.containsKey(c)) {
                state ^= vowelBit.get(c);
            }
            if (firstSeen[state] != Integer.MIN_VALUE) {
                // 相同状态之前出现过，计算子串长度
                maxLen = Math.max(maxLen, i - firstSeen[state]);
            } else {
                // 首次见到该状态，记录位置
                firstSeen[state] = i;
            }
        }

        return maxLen;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历字符串一次。
- 空间复杂度：O(1)，状态数固定为 2^5 = 32。

## 关键点总结

1. 用位掩码压缩 5 个元音的奇偶状态，XOR 操作实现奇偶翻转，高效且简洁。
2. 子串两端前缀状态相同时，子串内所有元音均出现偶数次。
3. `firstSeen[0] = -1` 表示空前缀，不可省略，否则会漏掉从头开始的满足条件的子串。
