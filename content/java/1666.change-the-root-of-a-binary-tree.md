## 题目描述

给你一棵有父指针的二叉树和一个叶节点 `leaf`，将树重新生根，使 `leaf` 成为新根。从 `leaf` 到原根路径上的父子关系需要翻转。

## 解题思路

从 `leaf` 沿路径向上，逐步翻转父子关系。若 `child` 是 `parent` 的左子，翻转后 `parent` 成为 `child` 的右子（右边没有被占用的方向）。

## Java 代码实现

```java
class Solution {
    public Node flipBinaryTree(Node root, Node leaf) {
        Node child = leaf;
        Node parent = leaf.parent;

        while (parent != null) {
            Node grandparent = parent.parent; // 预先保存祖父节点

            boolean isLeftChild = (parent.left == child);

            // 翻转父子关系
            if (isLeftChild) {
                parent.left = child.parent; // parent 的左指针指向其自身原来的父
                child.right = parent;       // child 的右指针指向 parent（翻转）
            } else {
                parent.right = child.parent;
                child.left = parent;        // child 的左指针指向 parent（翻转）
            }

            parent.parent = child; // parent 的父指针指向 child

            child = parent;
            parent = grandparent;
        }

        leaf.parent = null; // 新根的父指针为 null
        return leaf;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(h)，h 为叶节点到根的路径长度
- **空间复杂度**：O(1)

## 关键点总结

1. 只翻转从 leaf 到原根路径上的节点
2. 左子翻转后父成为右子，右子翻转后父成为左子
3. 迭代时需预先保存 grandparent，因翻转后 parent 的 parent 会改变
