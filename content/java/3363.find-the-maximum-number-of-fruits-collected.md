## 题目描述

有 `n x n` 的网格，三个孩子同时到达 `(n-1, n-1)`：孩子 1 从 `(0,0)` 只能向右或向下，孩子 2 从 `(0,n-1)` 只能向下或向左，孩子 3 从 `(n-1,0)` 只能向右或向上。每格水果只能收集一次，返回三人能收集的最大水果总数。

## 解题思路

三条路径分别独立用 DP 计算最大收益（路径特性决定孩子 2、3 路径主要不与孩子 1 重叠），终点 `(n-1, n-1)` 被三人都经过，最终减去 2 次重复。

## Java 代码实现

```java
class Solution {
    public int maxCollectedFruits(int[][] fruits) {
        int n = fruits.length;
        final int NEG_INF = Integer.MIN_VALUE / 2;

        // 孩子 1：(0,0) -> (n-1,n-1)，向右或向下
        int[][] dp1 = new int[n][n];
        for (int[] row : dp1) Arrays.fill(row, NEG_INF);
        dp1[0][0] = fruits[0][0];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int best = NEG_INF;
                if (i > 0 && dp1[i-1][j] != NEG_INF) best = Math.max(best, dp1[i-1][j]);
                if (j > 0 && dp1[i][j-1] != NEG_INF) best = Math.max(best, dp1[i][j-1]);
                if (best != NEG_INF) dp1[i][j] = best + fruits[i][j];
            }
        }

        // 孩子 2：(0,n-1) -> (n-1,n-1)，向下或向左
        int[][] dp2 = new int[n][n];
        for (int[] row : dp2) Arrays.fill(row, NEG_INF);
        dp2[0][n-1] = fruits[0][n-1];
        for (int i = 0; i < n; i++) {
            for (int j = n-1; j >= 0; j--) {
                if (i == 0 && j == n-1) continue;
                int best = NEG_INF;
                if (i > 0 && dp2[i-1][j] != NEG_INF) best = Math.max(best, dp2[i-1][j]);
                if (j < n-1 && dp2[i][j+1] != NEG_INF) best = Math.max(best, dp2[i][j+1]);
                if (best != NEG_INF) dp2[i][j] = best + fruits[i][j];
            }
        }

        // 孩子 3：(n-1,0) -> (n-1,n-1)，向右或向上
        int[][] dp3 = new int[n][n];
        for (int[] row : dp3) Arrays.fill(row, NEG_INF);
        dp3[n-1][0] = fruits[n-1][0];
        for (int i = n-1; i >= 0; i--) {
            for (int j = 0; j < n; j++) {
                if (i == n-1 && j == 0) continue;
                int best = NEG_INF;
                if (i < n-1 && dp3[i+1][j] != NEG_INF) best = Math.max(best, dp3[i+1][j]);
                if (j > 0 && dp3[i][j-1] != NEG_INF) best = Math.max(best, dp3[i][j-1]);
                if (best != NEG_INF) dp3[i][j] = best + fruits[i][j];
            }
        }

        int child1 = dp1[n-1][n-1] == NEG_INF ? 0 : dp1[n-1][n-1];
        int child2 = dp2[n-1][n-1] == NEG_INF ? 0 : dp2[n-1][n-1];
        int child3 = dp3[n-1][n-1] == NEG_INF ? 0 : dp3[n-1][n-1];

        // 终点 (n-1,n-1) 被三个孩子都经过，减去 2 次重复
        return child1 + child2 + child3 - 2 * fruits[n-1][n-1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，三次 DP
- 空间复杂度：O(n^2)，三个 DP 数组

## 关键点总结

1. 三条路径独立 DP，终点 `(n-1, n-1)` 被三人都经过，最终减去 2 次重复计数。
2. 各孩子移动方向不同，DP 遍历顺序也不同。
3. 用 NEG_INF 标记不可达状态，转移时检查有效性。
