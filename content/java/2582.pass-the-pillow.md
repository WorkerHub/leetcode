## 题目描述

n 个人排成一排，抱枕从编号 1 的人开始，每秒传给旁边的人，到达端点后反向传递，返回经过 `time` 秒后持有抱枕的人的编号。

## 解题思路

周期为 `2*(n-1)`；对 time 取模后，余数 <= n-1 时在正向段（位置 = 1+余数），否则在反向段（位置 = 2n-1-余数）。

## Java 代码实现

```java
class Solution {
    public int passThePillow(int n, int time) {
        int cycle = 2 * (n - 1);
        int r = time % cycle;
        return r <= n - 1 ? 1 + r : 2 * n - 1 - r;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 完整往返周期为 `2*(n-1)`
2. 取模后根据余数判断正向（<=n-1）或反向（>n-1）
3. 反向时位置 = `2n-1-余数`
