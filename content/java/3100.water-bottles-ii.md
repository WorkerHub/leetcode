## 题目描述

给你满瓶数 `numBottles` 和初始兑换率 `numExchange`（每次兑换后加 1），每 numExchange 个空瓶换 1 满瓶。返回最多能喝的瓶数。

## 解题思路

模拟：每次用 numExchange 个空瓶换 1 瓶，喝掉后空瓶 +1，numExchange +1，直到空瓶不足兑换。

## Java 代码实现

```java
class Solution {
    public int maxBottlesDrunk(int numBottles, int numExchange) {
        int total = numBottles;   // 总喝数
        int empty = numBottles;   // 当前空瓶数

        while (empty >= numExchange) {
            empty = empty - numExchange + 1; // 消耗 numExchange 个，喝后得 1 个空瓶
            numExchange++;
            total++;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(sqrt(n))，兑换次数约 sqrt(2 * numBottles)
- 空间复杂度：O(1)

## 关键点总结

1. 每次兑换后 numExchange 递增，难度增加
2. 净变化：空瓶减少 numExchange - 1，总喝数 +1
