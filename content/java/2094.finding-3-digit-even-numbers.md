## 题目描述

用digits数组中的三个元素（各下标最多用一次）组成三位偶数，返回所有可能值升序。

## 解题思路

枚举100-998所有三位偶数，用频率数组验证各位数字是否可从digits中选出。

## Java 代码实现

```java
class Solution {
    public int[] findEvenNumbers(int[] digits) {
        int[] cnt = new int[10];
        for (int d : digits) cnt[d]++;
        
        List<Integer> result = new ArrayList<>();
        for (int num = 100; num <= 998; num += 2) {
            int[] need = new int[10];
            need[num / 100]++;
            need[(num / 10) % 10]++;
            need[num % 10]++;
            
            boolean valid = true;
            for (int d = 0; d < 10; d++) {
                if (need[d] > cnt[d]) { valid = false; break; }
            }
            if (valid) result.add(num);
        }
        
        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，固定枚举450个数
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举范围固定**：三位偶数只有约450个
2. **频率验证**：用数组计数比较
3. **百位非0，个位偶数**：枚举自动满足
