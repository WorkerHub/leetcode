## 题目描述

在由 2D 网格表示的校园里，有 `n` 名工人和 `m` 辆自行车，其中 `n <= m`。

每个工人和每辆自行车的位置都用一对整数 `[x, y]` 表示。

我们为每个工人分配一辆自行车，使得分配给每个工人的自行车与工人之间的**曼哈顿距离**最小化。

返回长度为 `n` 的数组 `answer`，其中 `answer[i]` 是第 `i` 个工人分配到的自行车的索引（从 0 开始）。如果有多个可行方案：
- 首先选择曼哈顿距离最小的
- 如果曼哈顿距离相同，选择工人索引最小的
- 如果工人索引相同，选择自行车索引最小的

两点 `p1` 和 `p2` 之间的**曼哈顿距离**为：`|p1.x - p2.x| + |p1.y - p2.y|`。

**示例 1：**
```
输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出：[1,0]
```

**示例 2：**
```
输入：workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]]
输出：[0,2,1]
```

**提示：**
- `n == workers.length`
- `m == bikes.length`
- `1 <= n <= m <= 1000`
- `workers[i].length == bikes[j].length == 2`
- `0 <= workers[i][0], workers[i][1] < 1000`
- `0 <= bikes[j][0], bikes[j][1] < 1000`
- 所有工人和自行车的位置都不相同

## 解题思路

这道题的核心是**贪心策略**：按照题目要求的优先级依次分配自行车。

**算法流程：**
1. 计算所有工人和自行车之间的距离
2. 按照 `(距离, 工人索引, 自行车索引)` 排序
3. 从小到大遍历，如果工人和自行车都未分配，则进行分配
4. 当所有工人都分配完毕时结束

## Java 代码实现

### 方法一：排序 + 贪心（推荐）

```java
import java.util.*;

class Solution {
    public int[] assignBikes(int[][] workers, int[][] bikes) {
        // 时间复杂度：O(mn log(mn))
        // 空间复杂度：O(mn)

        int n = workers.length, m = bikes.length;

        // 计算所有配对的距离
        List<int[]> distances = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int dist = Math.abs(workers[i][0] - bikes[j][0]) +
                           Math.abs(workers[i][1] - bikes[j][1]);
                distances.add(new int[]{dist, i, j});
            }
        }

        // 按照 (距离, 工人索引, 自行车索引) 排序
        distances.sort((a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0];
            if (a[1] != b[1]) return a[1] - b[1];
            return a[2] - b[2];
        });

        // 分配
        int[] result = new int[n];
        Arrays.fill(result, -1);
        boolean[] usedBikes = new boolean[m];
        int assignedCount = 0;

        for (int[] d : distances) {
            int worker = d[1], bike = d[2];

            // 如果工人已分配或自行车已被使用，跳过
            if (result[worker] != -1 || usedBikes[bike]) {
                continue;
            }

            // 分配自行车
            result[worker] = bike;
            usedBikes[bike] = true;
            assignedCount++;

            // 所有工人都分配完毕
            if (assignedCount == n) {
                break;
            }
        }

        return result;
    }
}
```

### 方法二：桶排序优化

```java
import java.util.*;

class Solution {
    public int[] assignBikes(int[][] workers, int[][] bikes) {
        // 利用距离范围有限，使用桶排序优化
        // 时间复杂度：O(mn + max_dist)
        // 空间复杂度：O(mn)

        int n = workers.length, m = bikes.length;

        // 曼哈顿距离的最大值为 1998（坐标范围 0-999）
        int MAX_DIST = 2000;
        List<int[]>[] buckets = new List[MAX_DIST];
        for (int i = 0; i < MAX_DIST; i++) {
            buckets[i] = new ArrayList<>();
        }

        // 将所有配对按距离放入桶中
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int dist = Math.abs(workers[i][0] - bikes[j][0]) +
                           Math.abs(workers[i][1] - bikes[j][1]);
                buckets[dist].add(new int[]{i, j});
            }
        }

        // 分配
        int[] result = new int[n];
        Arrays.fill(result, -1);
        boolean[] usedBikes = new boolean[m];
        int assignedCount = 0;

        // 按距离从小到大遍历桶
        for (int dist = 0; dist < MAX_DIST && assignedCount < n; dist++) {
            if (buckets[dist].isEmpty()) continue;

            // 同一距离内按 (工人索引, 自行车索引) 排序
            buckets[dist].sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

            for (int[] pair : buckets[dist]) {
                int worker = pair[0], bike = pair[1];
                if (result[worker] != -1 || usedBikes[bike]) continue;

                result[worker] = bike;
                usedBikes[bike] = true;
                assignedCount++;

                if (assignedCount == n) break;
            }
        }

        return result;
    }
}
```

## 复杂度分析

**方法一：排序 + 贪心**
- 时间复杂度：O(mn log(mn))，排序所有配对
- 空间复杂度：O(mn)，存储所有配对

**方法二：桶排序**
- 时间复杂度：O(mn + k)，k 是最大距离（2000）
- 空间复杂度：O(mn)
- 适用于距离范围有限的场景

## 关键点总结

1. **贪心策略**：按照距离、工人索引、自行车索引的优先级排序
2. **去重检查**：确保每个工人和自行车只分配一次
3. **排序关键字**：三元组 `(距离, 工人索引, 自行车索引)` 自然满足优先级
4. **优化方法**：利用距离范围有限可以使用桶排序

## 易错点

1. **排序优先级**：必须严格按照距离 → 工人索引 → 自行车索引排序
2. **重复分配**：需要同时检查工人是否已分配和自行车是否已使用
3. **提前终止**：当所有工人都分配完毕时可以提前结束
