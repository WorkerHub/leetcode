## 题目描述

子数组中满足nums[i]%modulo==k的元素个数cnt，若cnt%modulo==k则为有趣子数组，求有趣子数组数量。

## 解题思路

前缀和+哈希表：前缀和只记满足条件的元素个数mod modulo。利用(pre-prev)%mod==k转化为查找prev。

## Java 代码实现

```java
class Solution {
    public long countInterestingSubarrays(List<Integer> nums, int modulo, int k) {
        Map<Integer, Long> freq = new HashMap<>();
        freq.put(0, 1L);
        int pre = 0;
        long ans = 0;

        for (int x : nums) {
            if (x % modulo == k) {
                pre = (pre + 1) % modulo;
            }
            // 需要prev使得(pre - prev) % modulo == k
            int need = (pre - k + modulo) % modulo;
            ans += freq.getOrDefault(need, 0L);
            freq.merge(pre, 1L, Long::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(min(N, modulo))

## 关键点总结

1. **前缀和只关心mod modulo的值**
2. **(pre-k+modulo)%modulo防负数**
3. **先查找再记录**：避免重复计数
