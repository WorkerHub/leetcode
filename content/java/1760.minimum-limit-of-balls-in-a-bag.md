## 题目描述

给你整数数组 `nums`（袋子球数）和 `maxOperations`（最多操作次数，每次将一个袋子分成两个）。返回操作后可能的最小"最大球数"（开销）。

## 解题思路

二分答案：对开销上限 `limit` 二分，检验函数计算将每个 `nums[i]` 分割到不超过 `limit` 所需操作数 `(nums[i]-1)/limit`，总操作数 <= `maxOperations` 则可行。

## Java 代码实现

```java
class Solution {
    public int minimumSize(int[] nums, int maxOperations) {
        int left = 1, right = 0;
        for (int x : nums) right = Math.max(right, x); // 上界为最大值

        while (left < right) {
            int mid = (left + right) >>> 1;
            if (canAchieve(nums, maxOperations, mid)) {
                right = mid; // 尝试更小的上限
            } else {
                left = mid + 1;
            }
        }

        return left;
    }

    private boolean canAchieve(int[] nums, int maxOps, int limit) {
        int ops = 0;
        for (int x : nums) {
            ops += (x - 1) / limit; // 将 x 分割到不超过 limit 所需操作数
            if (ops > maxOps) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log(max_val))
- **空间复杂度**：O(1)

## 关键点总结

1. 二分答案，对开销上限进行二分
2. `(x-1)/limit` 等价于 `ceil(x/limit)-1`，即将 x 分割到不超过 limit 所需操作数
