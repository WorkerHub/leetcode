## 题目描述

给你长度为 `n` 的整数数组 `gain`，代表相邻海拔点的净变化，起始海拔为 0。返回最高点的海拔。

## 解题思路

遍历计算前缀和（当前海拔），维护最大值。初始最大值为 0（起始点海拔）。

## Java 代码实现

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int current = 0;
        int maxAlt = 0; // 起始点海拔为 0，也是候选值

        for (int g : gain) {
            current += g; // 更新当前海拔
            maxAlt = Math.max(maxAlt, current);
        }

        return maxAlt;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 前缀和即为各点海拔
2. 初始化 `maxAlt = 0` 以包含起始点海拔
