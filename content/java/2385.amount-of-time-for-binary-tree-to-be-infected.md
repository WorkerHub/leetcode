## 题目描述

给你二叉树（根节点为 `root`）和起始感染节点 `start`，每分钟感染向所有未感染邻居扩散，返回整棵树被感染所需的分钟数。

## 解题思路

将二叉树转为无向图（邻接表），从 `start` 出发 BFS，统计感染所有节点所需的层数（初始时间设为 -1 因为 start 在第 0 分钟已感染）。

## Java 代码实现

```java
class Solution {
    public int amountOfTime(TreeNode root, int start) {
        // 建立无向图
        Map<Integer, List<Integer>> graph = new HashMap<>();
        buildGraph(root, -1, graph);

        // BFS 从 start 扩散
        Set<Integer> visited = new HashSet<>();
        visited.add(start);
        Queue<Integer> queue = new ArrayDeque<>();
        queue.add(start);
        int time = -1;
        while (!queue.isEmpty()) {
            time++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int node = queue.poll();
                for (int nb : graph.getOrDefault(node, Collections.emptyList())) {
                    if (visited.add(nb)) queue.add(nb);
                }
            }
        }
        return time;
    }

    private void buildGraph(TreeNode node, int parent, Map<Integer, List<Integer>> graph) {
        if (node == null) return;
        graph.computeIfAbsent(node.val, k -> new ArrayList<>());
        if (parent != -1) {
            graph.get(node.val).add(parent);
            graph.computeIfAbsent(parent, k -> new ArrayList<>()).add(node.val);
        }
        buildGraph(node.left, node.val, graph);
        buildGraph(node.right, node.val, graph);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 二叉树感染需向父节点传播，先建无向图再 BFS。
2. BFS 初始 `time = -1`，start 第 0 分钟已感染，每层加 1。
3. 建图时双向连接父子节点。
