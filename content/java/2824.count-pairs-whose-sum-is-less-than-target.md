## 题目描述

统计数组中满足nums[i]+nums[j]<target的下标对(i,j)数量(i<j)。

## 解题思路

排序+双指针：若nums[l]+nums[r]<target，则l与l+1到r都配对，count+=r-l，l++；否则r--。

## Java 代码实现

```java
class Solution {
    public int countPairs(List<Integer> nums, int target) {
        Collections.sort(nums);
        int count = 0;
        int l = 0, r = nums.size() - 1;

        while (l < r) {
            if (nums.get(l) + nums.get(r) < target) {
                count += r - l;
                l++;
            } else {
                r--;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后双指针**：利用单调性快速计数
2. **满足条件时count+=r-l**：l与中间所有元素都配对
3. **不满足时缩小右指针**
