## 题目描述

栈中恰好k步操作（弹出顶部或放回已弹出元素），求操作后栈顶最大值。

## 解题思路

两种候选：移除恰好k个后的nums[k]；移除前i个(i<=k-1)中的最大值放回。n==1时奇数步返回-1。

## Java 代码实现

```java
class Solution {
    public int maximumTop(int[] nums, int k) {
        int n = nums.length;
        
        // 特殊情况：只有一个元素
        if (n == 1) {
            return k % 2 == 0 ? nums[0] : -1;
        }
        
        if (k == 0) return nums[0];
        
        int ans = -1;
        
        // 候选1：移除恰好k个，顶部是nums[k]
        if (k < n) {
            ans = Math.max(ans, nums[k]);
        }
        
        // 候选2：移除前i个(i<=min(k-1,n))中放回最大值
        int limit = Math.min(k - 1, n);
        for (int i = 0; i < limit; i++) {
            ans = Math.max(ans, nums[i]);
        }
        
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(k, n))
- **空间复杂度**：O(1)

## 关键点总结

1. **n==1特判**：偶数步可保留，奇数步必空返回-1
2. **两种候选方案**：直接露出nums[k]或放回前k-1个中最大值
3. **k>=n时**：可访问任意元素（全部移走再放回最大）
