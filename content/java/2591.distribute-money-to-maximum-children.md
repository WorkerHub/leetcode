## 题目描述

给你一个整数 `money` 和 `children`，将钱分给孩子，每人至少 1 美元，没有孩子得 4 美元，返回最多有多少个孩子能得到恰好 8 美元。

## 解题思路

**贪心**：先检查边界（钱不够或太多返回 -1），然后计算最多能给几个孩子 8 美元，再验证剩余孩子能否合法分配（关注只剩 1 个孩子时是否恰好为 4）。

## Java 代码实现

```java
class Solution {
    public int distMoney(int money, int children) {
        // 钱不够每人 1 美元，或钱太多无法分完
        if (money < children || money > 8 * children) return -1;

        // 最多 k 人得到 8 美元：先给每人 1，剩余每人追加 7
        int k = Math.min((money - children) / 7, children);

        int remainingMoney = money - 8 * k;
        int remainingChildren = children - k;

        // 只剩 1 个孩子且剩余钱为 4，需减少 k
        if (remainingChildren == 1 && remainingMoney == 4) k--;
        // 没有剩余孩子但还有剩余钱，也需减少 k
        else if (remainingChildren == 0 && remainingMoney != 0) k--;

        return Math.max(k, 0);
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 先检查边界：`money < children` 或 `money > 8*children` 返回 -1
2. 最大 k = `min((money - children) / 7, children)`
3. 不得 4 美元：关注只剩 1 个孩子时剩余钱是否恰好为 4
