## 题目描述

篮子能承载 5000 单位重量，给定每个苹果的重量数组，返回最多能放入的苹果数量。

**示例：**
```
输入：weight = [900,950,800,1000,700,800]
输出：5
```

## 解题思路

贪心：优先选重量轻的苹果。排序后从小到大累加，直到超重。

## Java 代码实现

```java
class Solution {
    public int maxNumberOfApples(int[] weight) {
        Arrays.sort(weight);
        int total = 0, count = 0;
        
        for (int w : weight) {
            if (total + w > 5000) break;
            total += w;
            count++;
        }
        
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **贪心**：优先选最轻的苹果，装入数量最多
2. **排序**：从小到大排序是贪心的前提
3. **提前终止**：一旦超重立即停止
