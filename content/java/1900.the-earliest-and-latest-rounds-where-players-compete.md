## 题目描述

n 名运动员每轮按首尾配对，较强者晋级，给你两位特定运动员编号（他们遇到对方前总是获胜），返回他们最早和最晚可能相遇的轮次。

## 解题思路

记忆化搜索：状态 `(n, f, s)` 表示当前 n 人中两位选手的位置（f < s）。若 f+s=n+1 则本轮相遇返回 (1,1)；否则利用对称性保证 f+s<=n+1，枚举其他选手晋级情况递归求解。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private Map<Long, int[]> memo = new HashMap<>();

    public int[] earliestAndLatest(int n, int firstPlayer, int secondPlayer) {
        return dp(n, firstPlayer, secondPlayer);
    }

    private int[] dp(int n, int f, int s) {
        if (f + s == n + 1) return new int[]{1, 1};
        if (f + s > n + 1) { // 镜像变换
            int tmp = n + 1 - s;
            s = n + 1 - f;
            f = tmp;
        }
        long key = ((long) n << 20) | ((long) f << 10) | s;
        if (memo.containsKey(key)) return memo.get(key);

        int half = n / 2;
        int nn = (n + 1) / 2; // 下一轮人数
        int earliest = Integer.MAX_VALUE, latest = 0;

        if (s <= half) {
            // f 和 s 都在左半，枚举 f 左侧和 f/s 之间的晋级人数
            for (int lf = 0; lf < f; lf++) {
                for (int mid = 0; mid < s - f; mid++) {
                    int nf = lf + 1, ns = lf + 1 + mid + 1;
                    if (nf < ns && ns <= nn) {
                        int[] res = dp(nn, nf, ns);
                        earliest = Math.min(earliest, res[0] + 1);
                        latest = Math.max(latest, res[1] + 1);
                    }
                }
            }
        } else {
            // f 在左半，s 在右半，中间有 half-f 对
            for (int lf = 0; lf < f; lf++) {
                for (int mid = 0; mid <= half - f; mid++) {
                    int nf = lf + 1, ns = lf + 1 + mid + 1;
                    if (nf < ns && ns <= nn) {
                        int[] res = dp(nn, nf, ns);
                        earliest = Math.min(earliest, res[0] + 1);
                        latest = Math.max(latest, res[1] + 1);
                    }
                }
            }
        }

        int[] result = new int[]{earliest, latest};
        memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^3)，状态数 O(n^2)，每个状态转移 O(n)
- **空间复杂度**：O(n^2)，记忆化缓存

## 关键点总结

1. 状态 `(n, f, s)` 表示当前 n 人中两位选手的位置
2. 对称性：f+s > n+1 时翻转，保证 f+s <= n+1
3. f+s == n+1 时两人本轮相遇，直接返回 (1, 1)
