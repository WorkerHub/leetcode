## 题目描述

给你 n×n 矩阵，可以将任意相邻两元素同时乘以 -1 任意次，返回矩阵所有元素的最大可能总和。

## 解题思路

贪心：负号可以通过相邻操作任意移动。统计负数个数：偶数个负号可全部消除，奇数个则将最小绝对值元素保留负号。答案 = 所有绝对值之和 - 2 * 最小绝对值（若负数个数为奇数）。

## Java 代码实现

```java
class Solution {
    public long maxMatrixSum(int[][] matrix) {
        long total = 0;
        int negCount = 0, minAbs = Integer.MAX_VALUE;
        for (int[] row : matrix) {
            for (int x : row) {
                total += Math.abs(x);
                if (x < 0) negCount++;
                minAbs = Math.min(minAbs, Math.abs(x));
            }
        }
        return negCount % 2 == 0 ? total : total - 2 * minAbs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. 负号可通过相邻操作移动，偶数个可全消
2. 奇数个负号：将最小绝对值元素保留负号，损失最小
3. 若有 0 则最小绝对值为 0，奇数个负号也能消除
