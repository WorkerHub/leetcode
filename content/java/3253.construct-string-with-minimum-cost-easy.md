## 题目描述

给你字符串 `target`、字符串数组 `words` 和整数数组 `costs`，每次操作可将某个 `words[i]` 追加到当前字符串末尾，花费 `costs[i]`。返回构造 `target` 的最小花费，无法构造返回 `-1`。

## 解题思路

DP：`dp[i]` 表示构造 `target[0..i-1]` 的最小花费。对每个位置 i，枚举所有 words 检查是否匹配 target 的子串。用哈希表存储每个单词的最小花费。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumCost(String target, String[] words, int[] costs) {
        // 构建 word -> 最小花费 映射
        Map<String, Integer> wordCost = new HashMap<>();
        for (int i = 0; i < words.length; i++) {
            wordCost.merge(words[i], costs[i], Math::min);
        }

        int n = target.length();
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            if (dp[i] == Integer.MAX_VALUE) continue;
            // 枚举以 i 开头的子串
            for (int j = i + 1; j <= n; j++) {
                String sub = target.substring(i, j);
                if (wordCost.containsKey(sub)) {
                    dp[j] = Math.min(dp[j], dp[i] + wordCost.get(sub));
                }
            }
        }

        return dp[n] == Integer.MAX_VALUE ? -1 : dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为 target 长度，L 为单词最大长度
- 空间复杂度：O(W)，W 为所有单词总长度

## 关键点总结

1. dp[i] 表示构造前 i 个字符的最小花费
2. 同一单词出现多次只保留最小花费
3. 无法构造时返回 -1
