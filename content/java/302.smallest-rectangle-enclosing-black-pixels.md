## 题目描述

给你一个由 `'0'` 和 `'1'` 组成的二维矩阵 `image`，其中 `'1'` 表示黑色像素，`'0'` 表示白色像素。

黑色像素是连通的，即只有一块黑色区域。像素是水平或竖直连接的。

给你黑色像素的位置 `(x, y)`，返回包含所有黑色像素的最小矩形的面积。

**示例 1：**
```
输入：image = [
  ["0","0","1","0"],
  ["0","1","1","0"],
  ["0","1","0","0"]
], x = 0, y = 2
输出：6
解释：最小矩形的左上角是 (0, 1)，右下角是 (2, 2)，面积为 6
```

**示例 2：**
```
输入：image = [["1"]], x = 0, y = 0
输出：1
```

**提示：**
- `m == image.length`
- `n == image[i].length`
- `1 <= m, n <= 100`
- `image[i][j]` 为 `'0'` 或 `'1'`
- `0 <= x < m`
- `0 <= y < n`
- `image[x][y] == '1'`
- `image` 中的黑色像素仅形成一个连通块

## 解题思路

题目要求找到包含所有黑色像素的最小矩形。有两种主要思路：

### 思路一：DFS/BFS 遍历所有黑色像素

从给定的黑色像素 `(x, y)` 出发，使用 DFS 或 BFS 遍历所有连通的黑色像素，记录最小和最大的行列坐标。

- 最小行：`min_row`
- 最大行：`max_row`
- 最小列：`min_col`
- 最大列：`max_col`

矩形面积 = `(max_row - min_row + 1) * (max_col - min_col + 1)`

### 思路二：二分查找边界（最优）⭐

利用题目的关键信息：**黑色像素是连通的**。这意味着：
- 在某一行，黑色像素一定是连续的
- 在某一列，黑色像素一定是连续的

我们可以使用二分查找找到矩形的四条边界：
1. **左边界**：最小的列，该列存在黑色像素
2. **右边界**：最大的列，该列存在黑色像素
3. **上边界**：最小的行，该行存在黑色像素
4. **下边界**：最大的行，该行存在黑色像素

## Java 代码实现

### 方法一：DFS 遍历

```java
class Solution {
    private int minRow, maxRow, minCol, maxCol;
    private boolean[][] visited;

    public int minArea(char[][] image, int x, int y) {
        if (image == null || image.length == 0) return 0;

        int m = image.length, n = image[0].length;
        // 初始化边界
        minRow = maxRow = x;
        minCol = maxCol = y;
        visited = new boolean[m][n];

        dfs(image, x, y, m, n);

        // 计算面积
        return (maxRow - minRow + 1) * (maxCol - minCol + 1);
    }

    private void dfs(char[][] image, int i, int j, int m, int n) {
        // 边界检查
        if (i < 0 || i >= m || j < 0 || j >= n) return;
        if (image[i][j] == '0' || visited[i][j]) return;

        // 标记访问
        visited[i][j] = true;

        // 更新边界
        minRow = Math.min(minRow, i);
        maxRow = Math.max(maxRow, i);
        minCol = Math.min(minCol, j);
        maxCol = Math.max(maxCol, j);

        // 四个方向递归
        dfs(image, i + 1, j, m, n);
        dfs(image, i - 1, j, m, n);
        dfs(image, i, j + 1, m, n);
        dfs(image, i, j - 1, m, n);
    }
}
```

### 方法二：BFS 遍历

```java
import java.util.*;

class Solution {
    public int minArea(char[][] image, int x, int y) {
        if (image == null || image.length == 0) return 0;

        int m = image.length, n = image[0].length;

        // 初始化边界
        int minRow = x, maxRow = x, minCol = y, maxCol = y;

        boolean[][] visited = new boolean[m][n];
        visited[x][y] = true;
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{x, y});

        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int i = curr[0], j = curr[1];

            // 更新边界
            minRow = Math.min(minRow, i);
            maxRow = Math.max(maxRow, i);
            minCol = Math.min(minCol, j);
            maxCol = Math.max(maxCol, j);

            // 四个方向扩展
            for (int[] dir : directions) {
                int ni = i + dir[0], nj = j + dir[1];

                if (ni >= 0 && ni < m && nj >= 0 && nj < n &&
                    image[ni][nj] == '1' && !visited[ni][nj]) {
                    visited[ni][nj] = true;
                    queue.offer(new int[]{ni, nj});
                }
            }
        }

        // 计算面积
        return (maxRow - minRow + 1) * (maxCol - minCol + 1);
    }
}
```

### 方法三：二分查找（最优）⭐⭐

```java
class Solution {
    private char[][] image;
    private int m, n;

    public int minArea(char[][] image, int x, int y) {
        this.image = image;
        m = image.length;
        n = image[0].length;

        // 二分查找左边界（最小列）
        int left = 0, right = y;
        while (left < right) {
            int mid = (left + right) / 2;
            if (hasBlackInCol(mid)) right = mid;
            else left = mid + 1;
        }
        int minCol = left;

        // 二分查找右边界（最大列）
        left = y; right = n - 1;
        while (left < right) {
            int mid = (left + right + 1) / 2;
            if (hasBlackInCol(mid)) left = mid;
            else right = mid - 1;
        }
        int maxCol = left;

        // 二分查找上边界（最小行）
        left = 0; right = x;
        while (left < right) {
            int mid = (left + right) / 2;
            if (hasBlackInRow(mid)) right = mid;
            else left = mid + 1;
        }
        int minRow = left;

        // 二分查找下边界（最大行）
        left = x; right = m - 1;
        while (left < right) {
            int mid = (left + right + 1) / 2;
            if (hasBlackInRow(mid)) left = mid;
            else right = mid - 1;
        }
        int maxRow = left;

        return (maxRow - minRow + 1) * (maxCol - minCol + 1);
    }

    private boolean hasBlackInCol(int col) {
        // 检查某一列是否有黑色像素
        for (int i = 0; i < m; i++) {
            if (image[i][col] == '1') return true;
        }
        return false;
    }

    private boolean hasBlackInRow(int row) {
        // 检查某一行是否有黑色像素
        for (int j = 0; j < n; j++) {
            if (image[row][j] == '1') return true;
        }
        return false;
    }
}
```

### 方法四：二分查找优化版

```java
class Solution {
    private char[][] image;
    private int m, n;

    public int minArea(char[][] image, int x, int y) {
        this.image = image;
        m = image.length;
        n = image[0].length;

        // 找四条边界
        int minRow = searchRows(0, x, true);
        int maxRow = searchRows(x, m - 1, false);
        int minCol = searchCols(0, y, true);
        int maxCol = searchCols(y, n - 1, false);

        return (maxRow - minRow + 1) * (maxCol - minCol + 1);
    }

    private int searchRows(int top, int bottom, boolean findMin) {
        // 在 [top, bottom] 范围内二分查找行边界
        while (top < bottom) {
            int mid = findMin ? (top + bottom) / 2 : (top + bottom + 1) / 2;
            // 检查第 mid 行是否有黑色像素
            boolean hasBlack = false;
            for (int j = 0; j < n; j++) {
                if (image[mid][j] == '1') { hasBlack = true; break; }
            }

            if (findMin) {
                if (hasBlack) bottom = mid;
                else top = mid + 1;
            } else {
                if (hasBlack) top = mid;
                else bottom = mid - 1;
            }
        }
        return top;
    }

    private int searchCols(int left, int right, boolean findMin) {
        // 在 [left, right] 范围内二分查找列边界
        while (left < right) {
            int mid = findMin ? (left + right) / 2 : (left + right + 1) / 2;
            // 检查第 mid 列是否有黑色像素
            boolean hasBlack = false;
            for (int i = 0; i < m; i++) {
                if (image[i][mid] == '1') { hasBlack = true; break; }
            }

            if (findMin) {
                if (hasBlack) right = mid;
                else left = mid + 1;
            } else {
                if (hasBlack) left = mid;
                else right = mid - 1;
            }
        }
        return left;
    }
}
```

## 复杂度分析

**方法一、二（DFS/BFS）：**
- 时间复杂度：O(m × n)，最坏情况下遍历所有像素
- 空间复杂度：O(m × n)，visited 集合或递归栈

**方法三、四（二分查找）：**
- 时间复杂度：O(m log n + n log m)
  - 查找左右边界：O(m × log n)
  - 查找上下边界：O(n × log m)
- 空间复杂度：O(1)

## 关键点总结

1. **利用连通性**：黑色像素是连通的，可以用 DFS/BFS 遍历所有像素
2. **二分查找优化**：连通性保证了行列的连续性，可以用二分查找边界
3. **二分查找技巧**：
   - 找最小值：`mid = (left + right) / 2`
   - 找最大值：`mid = (left + right + 1) / 2`
4. **边界更新**：注意二分查找时的边界更新逻辑
5. **面积计算**：`(max_row - min_row + 1) * (max_col - min_col + 1)`

## 易错点

1. **二分查找边界错误**：找最小值和最大值的逻辑不同
2. **面积计算错误**：忘记 +1（索引从 0 开始）
3. **DFS 栈溢出**：大数据量时递归深度过大
4. **边界检查遗漏**：数组越界
