## 题目描述

与 3162 题相同（`nums1[i]` 能被 `nums2[j]*k` 整除则为好数对），但数组长度和元素值最大达 10^6，需要高效算法。

## 解题思路

等价转化：先筛出 `nums1[i] % k == 0` 的元素，令 `v = nums1[i] / k`，则需要 `nums2[j]` 是 `v` 的因子。统计 nums2 中每个值的频率，对每个有效 v 枚举其所有因子并累加对应频率。

## Java 代码实现

```java
class Solution {
    public long numberOfPairs(int[] nums1, int[] nums2, int k) {
        // 统计 nums2 中每个值的出现次数
        Map<Integer, Integer> cnt2 = new HashMap<>();
        for (int b : nums2) cnt2.merge(b, 1, Integer::sum);

        long ans = 0;
        for (int a : nums1) {
            if (a % k != 0) continue;
            int v = a / k; // 需要 nums2[j] 是 v 的因子
            // 枚举 v 的所有因子
            for (int d = 1; (long) d * d <= v; d++) {
                if (v % d == 0) {
                    ans += cnt2.getOrDefault(d, 0);
                    if (d != v / d) {
                        ans += cnt2.getOrDefault(v / d, 0);
                    }
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n1 × sqrt(max_v / k) + n2)
- **空间复杂度**：O(n2)

## 关键点总结

1. 先过滤 `nums1[i] % k != 0` 的元素
2. 令 `v = nums1[i] / k`，枚举 v 的因子（O(sqrt(v))）
3. 枚举因子时避免重复（d != v/d）
