## 题目描述

向数组追加k个未出现的不同正整数使总和最小，返回追加的k个数之和。

## 解题思路

排序去重后遍历间隙，用等差数列公式快速求每段连续可用整数的和，直到凑够k个。

## Java 代码实现

```java
class Solution {
    public long minimalKSum(int[] nums, int k) {
        // 去重排序
        TreeSet<Integer> set = new TreeSet<>();
        for (int x : nums) set.add(x);
        
        long ans = 0;
        int prev = 0;
        
        for (int x : set) {
            if (k <= 0) break;
            // [prev+1, x-1]之间的整数可用
            int available = x - 1 - prev;
            int use = Math.min(available, k);
            if (use > 0) {
                long a = prev + 1, b = prev + use;
                ans += (a + b) * use / 2;
                k -= use;
            }
            prev = x;
        }
        
        // 剩余从prev+1开始
        if (k > 0) {
            long a = prev + 1, b = prev + k;
            ans += (a + b) * k / 2;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **去重排序后遍历间隙**：每两个相邻数之间的空隙是可用整数
2. **等差数列求和**：(a+b)*n/2快速计算连续整数和
3. **最后补充**：若间隙不够k个，从最大数之后继续取
