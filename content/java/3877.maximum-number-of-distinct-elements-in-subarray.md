## 题目描述

给你一个整数数组 `nums` 和整数 `k`，找到长度恰好为 `k` 的子数组中不同元素数量最多的那个，返回该最大不同元素数量。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxDistinctElements(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> freq = new HashMap<>();
        int distinct = 0;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            int c = nums[i];
            // 加入右端：若为新元素则 distinct 加 1
            if (freq.getOrDefault(c, 0) == 0) {
                distinct++;
            }
            freq.put(c, freq.getOrDefault(c, 0) + 1);

            // 移除左端（窗口超过 k 时）
            if (i >= k) {
                int lc = nums[i - k];
                freq.put(lc, freq.get(lc) - 1);
                if (freq.get(lc) == 0) {
                    distinct--;
                    freq.remove(lc);
                }
            }

            // 窗口已满时记录答案
            if (i >= k - 1) {
                ans = Math.max(ans, distinct);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)

## 关键点总结

1. 固定大小 k 的滑动窗口，维护不同元素计数。
2. 加入右端时若为新元素则计数加 1；移除左端时若频率降为 0 则计数减 1。
3. 数组计数比哈希表速度快，但空间依赖值域大小。
