## 题目描述

给定整数数组 `nums` 和整数 `k`，统计有多少个子数组中的不同元素之和（先去重再求和）恰好等于 `k`。

## 解题思路

枚举左端点，用哈希表统计窗口内元素频次。由于元素均为正整数，不同元素之和随右端点右移单调不减，可以提前终止内循环。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countSubarrays(int[] nums, int k) {
        int n = nums.length;
        long result = 0;

        for (int l = 0; l < n; l++) {
            Map<Integer, Integer> freq = new HashMap<>();
            long distinctSum = 0;

            for (int r = l; r < n; r++) {
                // 新元素首次出现才计入不同元素和
                freq.merge(nums[r], 1, Integer::sum);
                if (freq.get(nums[r]) == 1) {
                    distinctSum += nums[r];
                }
                if (distinctSum == k) {
                    result++;
                } else if (distinctSum > k) {
                    break; // 正整数情况下不同元素和单调递增，可提前退出
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2) 最坏，正整数情况下实际较快
- 空间复杂度：O(n)

## 关键点总结

1. 不同元素之和：每个值只计一次，用哈希表追踪出现次数
2. 正整数情况下不同元素和随子数组扩展单调不减，可提前终止
3. 结果用 `long` 防溢出
