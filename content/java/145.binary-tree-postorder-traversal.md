## 题目描述

给你一棵二叉树的根节点 `root`，返回其节点值的**后序遍历**。

**示例 1：**
```
输入：root = [1,null,2,3]
输出：[3,2,1]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [1]
输出：[1]
```

**提示：**
- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

## 解题思路

后序遍历的访问顺序是：**左子树 -> 右子树 -> 根节点**。

核心思想有两种：
1. **递归法**：利用系统栈，自然实现深度优先搜索
2. **迭代法**：手动维护栈，模拟递归过程

**关键观察：**
- 后序遍历是前序遍历的"镜像逆序"
- 前序遍历：根 -> 左 -> 右
- 调整为：根 -> 右 -> 左，然后反转结果即可得到后序遍历

## Java 代码实现

### 方法一：递归法（推荐-最简洁）

```java
// Definition for a binary tree node.
// class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(TreeNode node, List<Integer> result) {
        if (node == null) {
            return;
        }
        // 后序遍历顺序：左 -> 右 -> 根
        postorder(node.left, result);   // 遍历左子树
        postorder(node.right, result);  // 遍历右子树
        result.add(node.val);           // 访问根节点
    }
}
```

### 方法二：迭代法（使用栈）⭐

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        /**
         * 迭代实现后序遍历（推荐掌握）
         * 核心思路：前序遍历变体 + 反转
         * - 前序遍历：根 -> 左 -> 右
         * - 调整为：根 -> 右 -> 左
         * - 反转结果：左 -> 右 -> 根（后序遍历）
         */
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);

            // 注意：先压左子节点，后压右子节点
            // 这样弹出时先处理右子树
            if (node.left != null) {
                stack.push(node.left);
            }
            if (node.right != null) {
                stack.push(node.right);
            }
        }

        // 反转结果得到后序遍历
        Collections.reverse(result);
        return result;
    }
}
```

### 方法三：迭代法（标准实现）

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        // 标准迭代后序遍历，使用 prev 指针记录上次访问的节点
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode prev = null;
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            // 一直向左走到底
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }

            // 查看栈顶节点
            curr = stack.peek();

            // 如果右子树不存在或已被访问，则访问当前节点
            if (curr.right == null || curr.right == prev) {
                result.add(curr.val);
                stack.pop();
                prev = curr;  // 记录为已访问
                curr = null;  // 避免重复访问
            } else {
                // 否则访问右子树
                curr = curr.right;
            }
        }

        return result;
    }
}
```

## 复杂度分析

**方法一（递归）：**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(n)，递归栈深度，最坏情况下为 n（链式树）

**方法二（迭代变体）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，栈的大小

**方法三（标准迭代）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 图解示例

以示例 1 为例：`root = [1,null,2,3]`

```
    1
     \
      2
     /
    3
```

**后序遍历过程：**
```
1. 访问左子树（空）
2. 访问右子树：
   - 访问左子树（节点 3）
   - 访问右子树（空）
   - 访问根节点 2
3. 访问根节点 1

结果：[3, 2, 1]
```

## 关键点总结

1. **后序遍历顺序**：左 -> 右 -> 根
2. **递归实现**：最简洁，注意递归顺序
3. **迭代实现**：可以用"前序变体+反转"技巧，更容易理解
4. **标准迭代**：需要记录 prev 节点，判断右子树是否已访问
5. **应用场景**：删除树、计算树的高度等需要先处理子节点的问题

## 易错点

1. **递归顺序错误**：必须先递归左右子树，最后访问根节点
2. **迭代法栈操作**：方法二中要先压左节点再压右节点
3. **标准迭代中的判断**：需要判断右子树是否为 null 或已访问，防止重复访问
4. **空树处理**：记得处理 root 为 null 的情况
