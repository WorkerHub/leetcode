## 题目描述

给你两个字符串 `s` 和 `t`，以及整数 `k`。将 `s` 分成 `k` 个等长子串，判断这 `k` 个子串能否重新排列组成字符串 `t`。

## 解题思路

将 `s` 和 `t` 都按长度 `m = s.length() / k` 等分，得到各 `k` 个子串。用哈希表统计两组子串的频率，若频率相同则可以重排。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isPossibleToRearrange(String s, String t, int k) {
        int n = s.length();
        int m = n / k; // 每个子串的长度

        // 统计 s 分割后各子串的频率
        Map<String, Integer> freq = new HashMap<>();
        for (int i = 0; i < n; i += m) {
            String sub = s.substring(i, i + m);
            freq.merge(sub, 1, Integer::sum);
        }

        // 从 t 分割后的子串中扣减频率
        for (int i = 0; i < n; i += m) {
            String sub = t.substring(i, i + m);
            int cnt = freq.getOrDefault(sub, 0);
            if (cnt == 0) return false;
            if (cnt == 1) freq.remove(sub);
            else freq.put(sub, cnt - 1);
        }

        return freq.isEmpty();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，字符串分割和哈希
- 空间复杂度：O(n)，存储子串

## 关键点总结

1. 将 s 和 t 都按 k 等分，得到各 k 个子串。
2. 两组子串的多重集合相同则可以重排。
3. 用哈希表统计频率，扣减后检查是否全空。
