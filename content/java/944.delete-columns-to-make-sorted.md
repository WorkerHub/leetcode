## 题目描述

给定等长字符串数组 strs，排成网格后，删除不按字典序升序排列的列。返回需要删除的列数。

## 解题思路

逐列检查：对于每一列，如果存在相邻两行不满足升序关系则计数 +1。

## Java 代码实现

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int count = 0;
        int cols = strs[0].length();

        for (int col = 0; col < cols; col++) {
            for (int row = 1; row < strs.length; row++) {
                if (strs[row].charAt(col) < strs[row - 1].charAt(col)) {
                    count++;
                    break;
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)
- **空间复杂度**：O(1)

## 关键点总结

1. **逐列检查**：每列独立判断
2. **升序判断**：相邻行字符比较
3. **提前终止**：发现不满足立即 break
