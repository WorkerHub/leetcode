## 题目描述

给a,b,n，求(a XOR x)*(b XOR x)的最大值（0<=x<2^n），结果取模。

## 解题思路

逐位贪心：若a,b该位相同，让两者都为1；若不同，将1分配给当前较小的那个（缩小差值使乘积更大）。

## Java 代码实现

```java
class Solution {
    public int maximumXorProduct(long a, long b, int n) {
        long MOD = 1_000_000_007;
        long A = a, B = b;
        for (int k = n - 1; k >= 0; k--) {
            long bitA = (a >> k) & 1;
            long bitB = (b >> k) & 1;
            if (bitA == bitB) {
                // 让两者该位都为1
                A |= (1L << k);
                B |= (1L << k);
            } else {
                // 将1分配给较小的
                if (A < B) {
                    A |= (1L << k);
                    B &= ~(1L << k);
                } else {
                    A &= ~(1L << k);
                    B |= (1L << k);
                }
            }
        }
        return (int) (A % MOD * (B % MOD) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **同位相同则都设为1**：增大两者
2. **不同位给较小者**：AM-GM不等式，差越小乘积越大
3. **从高位到低位**：高位影响更大
