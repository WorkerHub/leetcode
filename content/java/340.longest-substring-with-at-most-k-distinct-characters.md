## 题目描述

给定一个字符串 `s` 和一个整数 `k`，返回**至多包含 `k` 个不同字符**的最长子串的长度。

**示例 1:**

```
输入：s = "eceba", k = 2
输出：3
解释：满足条件的子串是 "ece"，长度为 3。
```

**示例 2:**

```
输入：s = "aa", k = 1
输出：2
解释：满足条件的子串是 "aa"，长度为 2。
```

**提示:**

- `1 <= s.length <= 5 * 10^4`
- `0 <= k <= 50`

注意：这是一道 LeetCode 会员题（Premium）。

## 解题思路

这道题是经典的**滑动窗口**问题。

### 核心思想

1. **滑动窗口维护**：
   - 使用哈希表记录窗口内每个字符的出现次数
   - 维护窗口内不同字符的数量

2. **窗口扩展**：
   - 右指针右移，将新字符加入窗口
   - 更新字符计数

3. **窗口收缩**：
   - 当不同字符数 > k 时，左指针右移
   - 移除左边界字符，更新计数
   - 如果某字符计数为 0，从哈希表删除

4. **更新最大长度**：
   - 每次窗口合法时（不同字符数 <= k），更新最大长度

## Java 代码实现

### 方法一：滑动窗口 + HashMap（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        // 滑动窗口：维护至多 k 个不同字符
        if (k == 0) return 0;

        Map<Character, Integer> charCount = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 扩展窗口：加入右边界字符
            char c = s.charAt(right);
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);

            // 收缩窗口：保持不同字符数 <= k
            while (charCount.size() > k) {
                char leftChar = s.charAt(left);
                charCount.put(leftChar, charCount.get(leftChar) - 1);
                if (charCount.get(leftChar) == 0) {
                    charCount.remove(leftChar);
                }
                left++;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法二：使用数组（字符集为 ASCII）

```java
class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        // 使用数组替代 HashMap，适用于 ASCII 字符集
        if (k == 0) return 0;

        int[] charCount = new int[256];  // ASCII 字符数组
        int distinctCount = 0;  // 不同字符的数量
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 扩展窗口
            char c = s.charAt(right);
            if (charCount[c] == 0) {
                distinctCount++;  // 新字符加入
            }
            charCount[c]++;

            // 收缩窗口
            while (distinctCount > k) {
                char leftChar = s.charAt(left);
                charCount[leftChar]--;
                if (charCount[leftChar] == 0) {
                    distinctCount--;  // 该字符从窗口移除
                }
                left++;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法三：使用 LinkedHashMap（优化收缩）

```java
import java.util.LinkedHashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        // 使用 LinkedHashMap 记录每个字符最右边的位置，优化收缩过程
        if (k == 0) return 0;

        LinkedHashMap<Character, Integer> charIndex = new LinkedHashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

            // 如果字符已存在，先删除（重新插入保证最新位置在末尾）
            if (charIndex.containsKey(c)) {
                charIndex.remove(c);
            }
            charIndex.put(c, right);

            // 收缩窗口：删除最左边的字符
            if (charIndex.size() > k) {
                // LinkedHashMap 按插入顺序，第一个是最久未更新的
                Map.Entry<Character, Integer> leftmost = charIndex.entrySet().iterator().next();
                charIndex.remove(leftmost.getKey());
                left = leftmost.getValue() + 1;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法四：使用普通 HashMap（记录字符位置）

```java
import java.util.*;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        // 记录每个字符最右边的位置，收缩时找最小位置
        if (k == 0) return 0;

        Map<Character, Integer> charIndex = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            // 更新字符最右位置
            charIndex.put(s.charAt(right), right);

            // 收缩窗口：删除最左边的字符
            if (charIndex.size() > k) {
                // 找到最左边字符的位置（O(k)）
                int leftmostIndex = Collections.min(charIndex.values());
                charIndex.remove(s.charAt(leftmostIndex));
                left = leftmostIndex + 1;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法五：暴力解法（会超时）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        // 暴力解法：枚举所有子串，时间复杂度 O(n^2)
        if (k == 0) return 0;

        int maxLen = 0;
        int n = s.length();

        for (int i = 0; i < n; i++) {
            Set<Character> charSet = new HashSet<>();
            for (int j = i; j < n; j++) {
                charSet.add(s.charAt(j));

                if (charSet.size() <= k) {
                    maxLen = Math.max(maxLen, j - i + 1);
                } else {
                    break;  // 不同字符数超过 k，停止扩展
                }
            }
        }

        return maxLen;
    }
}
```

## 复杂度分析

**方法一/二：滑动窗口**

- **时间复杂度**：O(n)
  - 左右指针各遍历一次数组
  - HashMap 操作 O(1)
  
- **空间复杂度**：O(k)
  - HashMap 最多存储 k+1 个字符

**方法三：LinkedHashMap 优化**

- **时间复杂度**：O(n)
  - 每次收缩 O(1)（直接找第一个元素）
  
- **空间复杂度**：O(k)

**方法四：普通 HashMap + 最小值**

- **时间复杂度**：O(n * k)
  - 每次收缩需要 O(k) 找最小值
  
- **空间复杂度**：O(k)

**方法五：暴力解法**

- **时间复杂度**：O(n^2)
  - 双层循环
  
- **空间复杂度**：O(k)
  - 集合最多存储 k 个字符

## 关键点总结

1. **滑动窗口模板**：
   - 右指针扩展窗口
   - 左指针收缩窗口
   - 更新最大值

2. **HashMap 维护**：
   - 记录窗口内每个字符的出现次数
   - 计数为 0 时删除，保持 HashMap 大小 = 不同字符数

3. **窗口收缩条件**：`charCount.size() > k`

4. **长度计算**：`right - left + 1`

5. **边界情况**：
   - `k = 0`：返回 0
   - `k >= 字符种类数`：返回 `s.length()`

## 易错点

1. **忘记删除计数为 0 的字符**：
   - 必须 `charCount.remove(leftChar)`
   - 否则 `charCount.size()` 不准确

2. **窗口收缩条件**：
   - 正确：`while (charCount.size() > k)`
   - 错误：`while (charCount.size() >= k)`

3. **最大长度更新时机**：
   - 应该在窗口合法时更新
   - 即收缩窗口之后

4. **k = 0 的处理**：
   - 特殊情况，需要单独处理

5. **字符计数递减**：
   - 要先递减再判断是否删除
   - 不能先删除再递减

## 图解示例

示例 1：`s = "eceba", k = 2`

```
初始: left = 0, charCount = {}, maxLen = 0

right = 0, s[0] = 'e':
  charCount = {'e': 1}, size = 1
  maxLen = 1

right = 1, s[1] = 'c':
  charCount = {'e': 1, 'c': 1}, size = 2
  maxLen = 2

right = 2, s[2] = 'e':
  charCount = {'e': 2, 'c': 1}, size = 2
  maxLen = 3

right = 3, s[3] = 'b':
  charCount = {'e': 2, 'c': 1, 'b': 1}, size = 3
  不同字符数 > 2，收缩窗口：
    移除 s[0] = 'e': charCount = {'e': 1, 'c': 1, 'b': 1}
    仍然 > 2，继续收缩：
    移除 s[1] = 'c': charCount = {'e': 1, 'b': 1}
    left = 2
  maxLen = 3 (right - left + 1 = 3 - 2 + 1 = 2)

right = 4, s[4] = 'a':
  charCount = {'e': 1, 'b': 1, 'a': 1}, size = 3
  不同字符数 > 2，收缩窗口：
    移除 s[2] = 'e': charCount = {'b': 1, 'a': 1}
    left = 3
  maxLen = 3

最终: maxLen = 3
```
