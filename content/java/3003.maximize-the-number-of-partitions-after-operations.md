## 题目描述

给字符串 s 和整数 k，可以修改一个字符，将 s 分成最多段，使每段不超过 k 个不同字符，返回最大分段数。

## 解题思路

记忆化 DP：状态 (i, mask, changed)，mask 为当前段已有字符集（位掩码），changed 表示是否已修改过字符。每次若加入新字符超过 k 个则新开一段；changed=0 时可枚举 26 种替换尝试最大化分段数。

## Java 代码实现

```java
class Solution {
    private String s;
    private int k;
    private Map<Long, Integer> memo = new HashMap<>();

    public int maxPartitionsAfterOperations(String s, int k) {
        this.s = s;
        this.k = k;
        return dp(0, 0, 0);
    }

    private int dp(int i, int mask, int changed) {
        if (i == s.length()) return 1;
        long key = (long) i * 2 * (1 << 26) + (long) mask * 2 + changed;
        if (memo.containsKey(key)) return memo.get(key);
        int res = tryChar(i, mask, changed, s.charAt(i) - 'a');
        // 若还未修改，枚举所有替换
        if (changed == 0) {
            for (int c = 0; c < 26; c++) {
                res = Math.max(res, tryChar(i, mask, 1, c));
            }
        }
        memo.put(key, res);
        return res;
    }

    private int tryChar(int i, int mask, int changed, int c) {
        int newMask = mask | (1 << c);
        if (Integer.bitCount(newMask) > k) {
            // 当前字符开新段
            return 1 + dp(i + 1, 1 << c, changed);
        }
        return dp(i + 1, newMask, changed);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 2²⁶ × 2)（实际因剪枝远小于上界）
- **空间复杂度**：O(n × 2²⁶)

## 关键点总结

1. mask 记录当前分段内出现的字符集（位掩码）
2. changed 为 0 时枚举 26 种替换取最大值
3. 超过 k 个不同字符时强制开新段并累加计数
