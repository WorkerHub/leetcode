## 题目描述

字符串 s 由 '*'（盘子）和 '|'（蜡烛）组成，每次查询 [left, right] 返回子串中被两个蜡烛夹住的盘子数。

## 解题思路

预处理：前缀盘子数数组、每个位置左侧最近蜡烛 leftCandle、右侧最近蜡烛 rightCandle。查询时找区间最左蜡烛 lc = rightCandle[l]，最右蜡烛 rc = leftCandle[r]，若 lc < rc 则答案为 prefix[rc] - prefix[lc+1]。

## Java 代码实现

### 方法一：前缀和 + 预计算蜡烛位置（推荐）

```java
class Solution {
    public int[] platesBetweenCandles(String s, int[][] queries) {
        int n = s.length();
        int[] prefix = new int[n + 1]; // 前缀盘子数
        int[] leftCandle = new int[n]; // 左侧最近蜡烛
        int[] rightCandle = new int[n]; // 右侧最近蜡烛

        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + (s.charAt(i) == '*' ? 1 : 0);
        }

        // 从左往右，记录左侧最近蜡烛
        int last = -1;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '|') last = i;
            leftCandle[i] = last;
        }

        // 从右往左，记录右侧最近蜡烛
        int nxt = n;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '|') nxt = i;
            rightCandle[i] = nxt;
        }

        int[] res = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            int lc = rightCandle[l]; // 区间最左蜡烛
            int rc = leftCandle[r];  // 区间最右蜡烛
            if (lc < rc) {
                res[i] = prefix[rc] - prefix[lc + 1];
            }
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q)
- 空间复杂度：O(n)

## 关键点总结

1. 预处理三个数组后每次查询 O(1)
2. lc 用 rightCandle[l]，rc 用 leftCandle[r]
3. 两端蜡烛不计入盘子数：`prefix[rc] - prefix[lc+1]`
