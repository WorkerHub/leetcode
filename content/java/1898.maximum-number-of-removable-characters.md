## 题目描述

给你字符串 `s`、`p`（p 是 s 的子序列）和下标数组 `removable`，依次删除前 k 个下标，返回使 p 仍是 s 子序列的最大 k。

## 解题思路

删除数量具有单调性（删除越少越容易保持子序列关系），对 k 二分查找：验证删除前 k 个下标后 p 是否仍是 s 的子序列。

## Java 代码实现

```java
class Solution {
    public int maximumRemovals(String s, String p, int[] removable) {
        int lo = 0, hi = removable.length;
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (isSubseq(s, p, removable, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }

    // 删除前 k 个下标后，p 是否仍是 s 的子序列
    private boolean isSubseq(String s, String p, int[] removable, int k) {
        boolean[] deleted = new boolean[s.length()];
        for (int i = 0; i < k; i++) {
            deleted[removable[i]] = true;
        }
        int j = 0;
        for (int i = 0; i < s.length() && j < p.length(); i++) {
            if (!deleted[i] && s.charAt(i) == p.charAt(j)) {
                j++;
            }
        }
        return j == p.length();
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) * log r)，n 为 s 长度，m 为 p 长度，r 为 removable 长度
- **空间复杂度**：O(n)

## 关键点总结

1. 单调性：删除越少越容易保持子序列关系，适合二分
2. 求满足条件的最大 k，使用 `lo = mid`，`hi = mid - 1` 模板
3. 用布尔数组标记删除比 HashSet 更快
