## 题目描述

给定两棵树，可在树1的任意节点和树2的任意节点之间添加一条边，对树1每个节点 `v` 求连接后距离不超过 `k` 的节点总数的最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maxTargetNodes(int[][] edges1, int[][] edges2, int k) {
        int n = edges1.length + 1;
        int m = edges2.length + 1;

        List<List<Integer>> g1 = buildGraph(n, edges1);
        List<List<Integer>> g2 = buildGraph(m, edges2);

        // 计算树1每个节点距离 <= k 的节点数
        int[] cnt1 = new int[n];
        for (int v = 0; v < n; v++) cnt1[v] = dfsCount(g1, v, -1, k);

        // 计算树2每个节点距离 <= k-1 的节点数（连接边消耗1步）
        int maxCnt2 = 0;
        if (k >= 1) {
            for (int u = 0; u < m; u++) {
                maxCnt2 = Math.max(maxCnt2, dfsCount(g2, u, -1, k - 1));
            }
        }

        int[] result = new int[n];
        for (int v = 0; v < n; v++) result[v] = cnt1[v] + maxCnt2;
        return result;
    }

    private List<List<Integer>> buildGraph(int n, int[][] edges) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        return g;
    }

    // DFS 统计从 node 出发距离 <= maxD 的节点数
    private int dfsCount(List<List<Integer>> g, int node, int parent, int maxD) {
        if (maxD < 0) return 0;
        int count = 1;
        for (int nb : g.get(node)) {
            if (nb != parent) count += dfsCount(g, nb, node, maxD - 1);
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 + m^2)，对每个节点做 DFS
- 空间复杂度：O(n + m)

## 关键点总结

1. 连接一条边后，树2中的节点距离 = 树2内距离 + 1（连接边消耗1步）
2. 最优连接：选树2中"k-1 距离内节点数最多"的节点
3. 对每个树1节点独立计算答案
