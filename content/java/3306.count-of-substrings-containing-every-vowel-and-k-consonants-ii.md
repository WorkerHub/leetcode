## 题目描述

给你字符串 `word`（长度达 10^5）和非负整数 `k`，返回包含全部 5 个元音字母且恰好含 `k` 个辅音字母的子字符串数目。

## 解题思路

与 3305 完全相同的滑动窗口 + `至少k减至少k+1` 方法，O(n) 时间自然处理 10^5 数据量。

## Java 代码实现

```java
class Solution {
    public long countOfSubstrings(String word, int k) {
        return atLeast(word, k) - atLeast(word, k + 1);
    }

    private long atLeast(String word, int minK) {
        int n = word.length();
        boolean[] isVowel = new boolean[26];
        for (char c : "aeiou".toCharArray()) isVowel[c - 'a'] = true;
        int[] vowelCnt = new int[26];
        int vowelTypes = 0, consonantCnt = 0, l = 0;
        long count = 0;

        for (int r = 0; r < n; r++) {
            int ci = word.charAt(r) - 'a';
            if (isVowel[ci]) {
                if (vowelCnt[ci]++ == 0) vowelTypes++;
            } else {
                consonantCnt++;
            }
            while (vowelTypes == 5 && consonantCnt >= minK) {
                count += n - r; // 右端点延伸到末尾均合法
                int lci = word.charAt(l) - 'a';
                if (isVowel[lci]) {
                    if (--vowelCnt[lci] == 0) vowelTypes--;
                } else {
                    consonantCnt--;
                }
                l++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，两次滑动窗口各 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. `恰好k` = `至少k` - `至少k+1`，通用"恰好"型滑动窗口转化技巧
2. 本题与 3305 代码完全相同，O(n) 解法在两题中均适用
3. 用 `vowelTypes` 而非哈希表大小追踪元音种数，避免 `remove` 操作
