## 题目描述

数组中每次操作将某个元素+1，执行k次后求最大乘积（mod 10^9+7）。

## 解题思路

贪心：每次增加最小元素使乘积增量最大（元素越均等乘积越大）。用最小堆维护，k次操作后计算乘积。

## Java 代码实现

```java
class Solution {
    public int maximumProduct(int[] nums, int k) {
        int MOD = 1_000_000_007;
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for (int x : nums) pq.offer(x);
        
        for (int i = 0; i < k; i++) {
            pq.offer(pq.poll() + 1);
        }
        
        long result = 1;
        while (!pq.isEmpty()) {
            result = result * pq.poll() % MOD;
        }
        return (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + K) log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心最优**：每次增加最小值，均值不等式保证乘积最大化
2. **最小堆**：Java PriorityQueue默认最小堆
3. **最后取模**：乘积逐步取模防溢出
