## 题目描述

给定有 `n` 个节点的有向图和边集 `edges`，判断图中是否存在有向环，存在返回 `true`，否则返回 `false`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean hasCycle(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[n];
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            inDegree[e[1]]++;
        }

        // 拓扑排序：若无法处理所有节点，则有环
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++) if (inDegree[i] == 0) queue.offer(i);

        int visited = 0;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            visited++;
            for (int v : graph.get(u)) {
                if (--inDegree[v] == 0) queue.offer(v);
            }
        }

        return visited != n;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，拓扑排序线性
- 空间复杂度：O(n + m)

## 关键点总结

1. 有环的图无法完成拓扑排序（处理节点数 < n）
2. 自环会导致节点入度永远不为 0，也能正确检测
3. 拓扑排序比 DFS 染色更易实现且不受递归深度限制
