## 题目描述

矩形左下角在原点，给定右上角坐标。对每个查询点统计包含它的矩形数量。

## 解题思路

利用h<=100的约束，按高度分桶存储矩形宽度（排序）。查询点(x,y)时遍历h>=y的所有桶，二分查找l>=x的矩形数。

## Java 代码实现

```java
class Solution {
    public int[] countRectangles(int[][] rectangles, int[][] points) {
        int H_MAX = 101;
        List<List<Integer>> byHeight = new ArrayList<>();
        for (int i = 0; i < H_MAX; i++) byHeight.add(new ArrayList<>());

        for (int[] r : rectangles) {
            byHeight.get(r[1]).add(r[0]);
        }
        for (int h = 0; h < H_MAX; h++) {
            Collections.sort(byHeight.get(h));
        }

        int[] ans = new int[points.length];
        for (int i = 0; i < points.length; i++) {
            int x = points[i][0], y = points[i][1];
            int count = 0;
            for (int h = y; h < H_MAX; h++) {
                List<Integer> widths = byHeight.get(h);
                if (widths.isEmpty()) continue;
                // 二分查找第一个>=x的位置
                int pos = Collections.binarySearch(widths, x);
                if (pos < 0) pos = -pos - 1;
                count += widths.size() - pos;
            }
            ans[i] = count;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m·log m + n·H·log m)
- **空间复杂度**：O(m)

## 关键点总结

1. **按高度分桶**：利用h<=100的小范围约束
2. **桶内排序+二分**：快速统计l>=x的矩形数
3. **遍历h>=y的所有桶**：累加各桶的贡献
