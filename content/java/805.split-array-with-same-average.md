## 题目描述

给定你一个整数数组 `nums`。

我们要将 `nums` 数组中的每个元素移动到 `A` 数组或者 `B` 数组中，使得 `A` 数组和 `B` 数组不为空，并且 `A` 数组的平均值等于 `B` 数组的平均值。

如果可以完成则返回 `true`，否则返回 `false`。

**注意**：对于数组 `arr`，`arr` 的平均值是 `arr` 的所有元素之和除以 `arr.length`。

**示例 1:**
```
输入: nums = [1,2,3,4,5,6,7,8]
输出: true
解释: 我们可以将数组分割为 [1,4,5,8] 和 [2,3,6,7], 他们的平均值都是4.5。
```

**示例 2:**
```
输入: nums = [3,1]
输出: false
```

**提示:**
- `1 <= nums.length <= 30`
- `0 <= nums[i] <= 10^4`

## 解题思路

这是一道数学 + 动态规划的困难题。

**数学推导：**

假设数组总和为 `sum`，长度为 `n`。
将数组分为两部分 A 和 B：
- A 的长度为 `k`，和为 `sumA`
- B 的长度为 `n - k`，和为 `sum - sumA`

如果平均值相等：
```
sumA / k = (sum - sumA) / (n - k)
```

化简得：
```
sumA * n = sum * k
sumA = sum * k / n
```

**关键观察：**
1. `sumA` 必须是整数，所以 `sum * k % n == 0`
2. 我们只需要找到一个大小为 `k` 的子集，其和为 `sum * k / n`
3. 由于对称性，我们只需检查 `k <= n/2`

## Java 代码实现

### 方法一：动态规划（推荐）

```java
import java.util.*;

class Solution {
    public boolean splitArraySameAverage(int[] nums) {
        int n = nums.length;
        int totalSum = 0;
        for (int num : nums) {
            totalSum += num;
        }

        if (n == 1) return false;

        // dp[k] 存储所有长度为 k 的子集和
        int half = n / 2;
        @SuppressWarnings("unchecked")
        Set<Integer>[] possible = new HashSet[half + 1];
        for (int i = 0; i <= half; i++) {
            possible[i] = new HashSet<>();
        }
        possible[0].add(0);

        for (int num : nums) {
            // 从后往前遍历，避免重复使用
            for (int k = half; k >= 1; k--) {
                for (int prevSum : new ArrayList<>(possible[k - 1])) {
                    possible[k].add(prevSum + num);
                }
            }
        }

        // 检查是否存在满足条件的分割
        for (int k = 1; k <= half; k++) {
            // 需要满足：sumA = totalSum * k / n
            if (totalSum * k % n == 0) {
                int target = totalSum * k / n;
                if (possible[k].contains(target)) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

### 方法二：减去平均值后找和为 0 的子集

```java
import java.util.*;

class Solution {
    public boolean splitArraySameAverage(int[] nums) {
        int n = nums.length;
        int totalSum = 0;
        for (int num : nums) totalSum += num;

        if (n == 1) return false;

        int half = n / 2;
        // 使用整数避免浮点数：将 nums[i] * n - totalSum 替换原值
        // 问题转化：找一个大小为 k 的子集，使得 sum(nums[i]) * n == totalSum * k
        @SuppressWarnings("unchecked")
        Set<Integer>[] dp = new HashSet[half + 1];
        for (int i = 0; i <= half; i++) {
            dp[i] = new HashSet<>();
        }
        dp[0].add(0);

        for (int num : nums) {
            for (int k = half; k >= 1; k--) {
                for (int s : new ArrayList<>(dp[k - 1])) {
                    dp[k].add(s + num);
                }
            }
        }

        for (int k = 1; k <= half; k++) {
            if (totalSum * k % n == 0) {
                if (dp[k].contains(totalSum * k / n)) {
                    return true;
                }
            }
        }

        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × sum)，其中 n 是数组长度，sum 是数组总和
- **空间复杂度**：O(n × sum)

## 关键点总结

1. **数学推导**：将平均值相等转化为寻找特定和的子集
2. **对称性优化**：只需检查 `k <= n/2` 的情况
3. **整除性判断**：`sum * k % n == 0` 是必要条件
4. **动态规划**：背包问题的变种，需要同时记录大小和和
5. **集合遍历**：遍历时注意 ConcurrentModificationException，需要复制集合

## 易错点

1. **边界条件**：n = 1 时无法分割，直接返回 false
2. **整除判断**：必须先检查 `sum * k % n == 0`
3. **DP 更新顺序**：必须从后往前，避免重复使用元素
4. **空集问题**：两个集合都不能为空
5. **Java 遍历时修改**：需要用 `new ArrayList<>(set)` 避免并发修改异常
