## 题目描述

给定一个整数 n，返回小于或等于 n 的最大单调递增数字（每个相邻位数 x <= y）。

**示例：**
```
输入：n = 1332
输出：1299
```

## 解题思路

贪心：从左到右找第一个下降位置，向前回溯将该位减 1，后面全部填 9。

## Java 代码实现

```java
class Solution {
    public int monotoneIncreasingDigits(int n) {
        char[] digits = String.valueOf(n).toCharArray();
        int i = 1;

        // 找第一个下降位置
        while (i < digits.length && digits[i - 1] <= digits[i]) {
            i++;
        }

        // 已经单调递增
        if (i == digits.length) return n;

        // 向前回溯
        while (i > 0 && digits[i - 1] > digits[i]) {
            digits[i - 1]--;
            i--;
        }

        // 后面全部填 9
        for (int j = i + 1; j < digits.length; j++) {
            digits[j] = '9';
        }

        return Integer.parseInt(new String(digits));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **贪心思想**：尽可能保持高位不变
2. **向前回溯**：连续相等位需要继续回溯
3. **后缀填 9**：最大化结果
