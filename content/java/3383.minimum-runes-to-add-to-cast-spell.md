## 题目描述

给定有向图（n 个节点，flowFrom/flowTo 表示边），以及初始可达节点集 crystals，求使所有节点可达所需最少添加的起始节点数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minRunesToAdd(int n, int[] crystals, int[] flowFrom, int[] flowTo) {
        // 构建正向图和反向图
        List<List<Integer>> graph = new ArrayList<>();
        List<List<Integer>> revGraph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
            revGraph.add(new ArrayList<>());
        }
        for (int i = 0; i < flowFrom.length; i++) {
            graph.get(flowFrom[i]).add(flowTo[i]);
            revGraph.get(flowTo[i]).add(flowFrom[i]);
        }

        // BFS 从初始节点扩展可达集
        boolean[] reachable = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>();
        for (int c : crystals) {
            if (!reachable[c]) {
                reachable[c] = true;
                queue.offer(c);
            }
        }
        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int nb : graph.get(node)) {
                if (!reachable[nb]) {
                    reachable[nb] = true;
                    queue.offer(nb);
                }
            }
        }

        // 贪心：找前驱均不可达的不可达节点作为新起点
        int additions = 0;
        for (int i = 0; i < n; i++) {
            if (!reachable[i]) {
                // 检查是否有可达的前驱
                boolean hasPred = false;
                for (int pred : revGraph.get(i)) {
                    if (reachable[pred]) { hasPred = true; break; }
                }
                if (!hasPred) {
                    // i 是新起点，从 i 出发扩展
                    additions++;
                    reachable[i] = true;
                    queue.offer(i);
                    while (!queue.isEmpty()) {
                        int node = queue.poll();
                        for (int nb : graph.get(node)) {
                            if (!reachable[nb]) {
                                reachable[nb] = true;
                                queue.offer(nb);
                            }
                        }
                    }
                }
            }
        }
        return additions;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，图遍历
- 空间复杂度：O(n + m)

## 关键点总结

1. 初始可达集从 crystals 出发 BFS 扩展。
2. 新起点是"没有任何可达前驱的不可达节点"。
3. 每添加一个新起点立即 BFS 扩展，减少后续需要添加的节点数。
