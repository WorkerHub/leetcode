## 题目描述

给你一个二进制矩阵 `grid`，找出含有最多 1 的行，返回 `[行下标, 1的个数]`；若多行相同，返回下标最小的。

## Java 代码实现

```java
class Solution {
    public int[] rowAndMaximumOnes(int[][] grid) {
        int bestRow = 0, bestCount = 0;
        for (int i = 0; i < grid.length; i++) {
            int cnt = 0;
            for (int v : grid[i]) cnt += v; // 二进制行 sum 即为 1 的个数
            if (cnt > bestCount) {
                bestCount = cnt;
                bestRow = i;
            }
        }
        return new int[]{bestRow, bestCount};
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 矩阵元素为 0/1，行求和即为 1 的个数
2. 用 `>` 而非 `>=` 保证返回下标最小的行
