## 题目描述

对于给定的整数 n，如果 n 的 k（k >= 2）进制数的所有数位全为 1，则称 k（k >= 2）是 n 的一个好进制。

以字符串的形式给出 n，以字符串的形式返回 n 的最小好进制。

**示例 1：**
```
输入：n = "13"
输出："3"
解释：13 的 3 进制是 111。
```

**示例 2：**
```
输入：n = "4681"
输出："8"
解释：4681 的 8 进制是 11111。
```

**示例 3：**
```
输入：n = "1000000000000000000"
输出："999999999999999999"
解释：1000000000000000000 的 999999999999999999 进制是 11。
```

**提示：**
- n 的取值范围是 [3, 10^18]
- n 没有前导 0

## 解题思路

这道题的核心是理解数学关系和使用二分查找。

### 数学分析

如果 n 在 k 进制下表示为 m 个 1，即：111...1（m 个 1），那么：
```
n = k^(m-1) + k^(m-2) + ... + k + 1
```

这是一个等比数列求和：
```
n = (k^m - 1) / (k - 1)
```

变形得到：
```
n * (k - 1) = k^m - 1
n * k - n = k^m - 1
k^m = n * k - n + 1
k^m = n * (k - 1) + 1
```

### 关键观察

1. **长度 m 的范围**：
   - 最小：m = 2（二进制表示，如 11）
   - 最大：m ≈ log₂(n)（因为最小进制是 2）
   - 对于 n ≤ 10^18，m 最大约为 60

2. **对于固定的 m**：
   - k 越大，k^(m-1) + ... + k + 1 越大
   - 可以使用二分查找找到满足条件的 k

3. **要找最小的 k**：
   - 最小的 k 对应最大的 m
   - 所以从大到小枚举 m

### 算法流程

1. 从大到小枚举 m（位数）
2. 对于每个 m，使用二分查找找到对应的 k
3. 验证 k 是否满足等式
4. 找到的第一个满足条件的 k 就是答案

## Java 代码实现

### 方法一：枚举位数 + 二分查找（推荐）

```java
class Solution {
    public String smallestGoodBase(String n) {
        // 枚举位数，对每个位数二分查找进制
        // 时间复杂度：O(log²n)
        // 空间复杂度：O(1)
        long num = Long.parseLong(n);

        // m 是位数，从大到小枚举
        // 最大位数是 log₂(num) + 1，即 64 - numberOfLeadingZeros(num)
        int maxM = 63 - Long.numberOfLeadingZeros(num) + 1;

        // 从最大位数开始枚举（这样找到的 k 最小）
        for (int m = maxM; m >= 2; m--) {
            long k = binarySearch(num, m);
            if (k != -1) return String.valueOf(k);
        }

        // 如果都不满足，返回 n-1（因为 n 在 n-1 进制下是 11）
        return String.valueOf(num - 1);
    }

    private long binarySearch(long n, int m) {
        // 二分查找满足条件的进制 k
        // n = k^(m-1) + k^(m-2) + ... + k + 1
        long left = 2, right = (long) Math.pow(n, 1.0 / (m - 1)) + 1;

        while (left <= right) {
            long mid = left + (right - left) / 2;

            // 计算 mid^(m-1) + mid^(m-2) + ... + mid + 1
            long total = calculateSum(mid, m);

            if (total == n) return mid;
            else if (total < n) left = mid + 1;
            else right = mid - 1;
        }

        return -1;
    }

    private long calculateSum(long k, int m) {
        // 计算 k^(m-1) + k^(m-2) + ... + k + 1
        long total = 0;
        long power = 1;
        for (int i = 0; i < m; i++) {
            total += power;
            // 溢出检查：提前返回大值
            if (total < 0) return Long.MAX_VALUE;
            power *= k;
        }
        return total;
    }
}
```

### 方法二：使用等比数列公式（优化计算）

```java
class Solution {
    public String smallestGoodBase(String n) {
        // 使用等比数列求和公式优化计算
        // 时间复杂度：O(log²n)
        // 空间复杂度：O(1)
        long num = Long.parseLong(n);
        int maxM = 63 - Long.numberOfLeadingZeros(num) + 1;

        for (int m = maxM; m >= 2; m--) {
            // 使用直接计算 k 的初始值
            long k = (long) Math.pow(num, 1.0 / (m - 1));

            // 检查 k 和 k+1（由于浮点数精度问题）
            for (long base : new long[]{k, k + 1}) {
                if (base < 2) continue;

                // 检查 base 进制下 m 位全 1 是否等于 num
                if (check(num, base, m)) {
                    return String.valueOf(base);
                }
            }
        }

        return String.valueOf(num - 1);
    }

    private boolean check(long n, long k, int m) {
        // 检查 k 进制下 m 位全 1 是否等于 n
        // 计算 1 + k + k^2 + ... + k^(m-1)
        long total = 0;
        long power = 1;
        for (int i = 0; i < m; i++) {
            total += power;
            // 提前终止，避免溢出
            if (total > n || total < 0) return false;
            power *= k;
        }
        return total == n;
    }
}
```

### 方法三：数学公式直接求解

```java
class Solution {
    public String smallestGoodBase(String n) {
        // 直接使用数学公式求解
        // 时间复杂度：O(log²n)
        // 空间复杂度：O(1)
        long num = Long.parseLong(n);

        // 枚举位数 m
        int maxM = 63 - Long.numberOfLeadingZeros(num) + 1;
        for (int m = maxM; m >= 2; m--) {
            // 根据公式 n = (k^m - 1) / (k - 1)
            // k ≈ n^(1/(m-1))
            long k = (long) Math.pow(num, 1.0 / (m - 1));

            // 验证 k
            if (k >= 2) {
                // 计算等比数列和
                long total = 0, power = 1;
                boolean overflow = false;
                for (int i = 0; i < m; i++) {
                    total += power;
                    if (total < 0) { overflow = true; break; }
                    power *= k;
                }
                if (!overflow && total == num) return String.valueOf(k);
            }
        }

        return String.valueOf(num - 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²n)
  - 外层循环：O(log n)，枚举位数
  - 内层二分查找：O(log n)
  - 计算和：O(log n)
  - 总复杂度：O(log²n)

- **空间复杂度**：O(1)
  - 只使用常数额外空间

## 关键点总结

1. **数学转换**：将问题转换为等比数列求和
2. **位数枚举**：从大到小枚举位数，保证找到的 k 最小
3. **二分查找**：对于固定位数，用二分找 k
4. **浮点精度**：使用整数运算验证，避免浮点误差
5. **边界情况**：n-1 进制下 n 一定是 11

## 易错点

1. **浮点精度问题**
   - 计算 k = n^(1/(m-1)) 可能有精度误差
   - 需要检查 k 和 k+1

2. **溢出问题**
   - k^m 可能非常大，Java 中 long 运算可能溢出
   - 需要提前终止或检查溢出（使用负数判断）

3. **位数范围**
   - 最大位数是 log₂(n)
   - Java 中用 `63 - Long.numberOfLeadingZeros(num) + 1` 计算

4. **特殊情况**
   - n=3 时，最小好进制是 2（11 in base 2）
   - 任何 n 在 n-1 进制下都是 11

5. **等比数列公式**
   - (k^m - 1) / (k - 1) 要注意整除
   - 先验证 k^m - 1 能否被 k - 1 整除
