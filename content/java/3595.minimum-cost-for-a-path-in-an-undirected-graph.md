## 题目描述

给定无向加权图，有 `n` 个节点，从节点 0 出发到节点 `n-1`，求最小路径费用（包含边权和节点费用）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumCost(int n, int[][] edges, int[] nodeCost) {
        List<List<long[]>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(new long[]{e[1], e[2]});
            graph.get(e[1]).add(new long[]{e[0], e[2]});
        }

        // Dijkstra：dist[i] = 从节点 0 到节点 i 的最小费用
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE / 2);
        dist[0] = nodeCost[0];

        // 优先队列：(距离, 节点)
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{dist[0], 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;  // 过时条目
            if (u == n - 1) return d;

            for (long[] nb : graph.get(u)) {
                int v = (int) nb[0];
                long w = nb[1];
                long newD = d + w + nodeCost[v];
                if (newD < dist[v]) {
                    dist[v] = newD;
                    pq.offer(new long[]{newD, v});
                }
            }
        }
        return dist[n - 1] == Long.MAX_VALUE / 2 ? -1 : dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)，Dijkstra 标准复杂度
- 空间复杂度：O(V + E)

## 关键点总结

1. Dijkstra 适用于非负权图的单源最短路
2. 节点费用加到到达该节点的距离中，起点费用作为初始距离
3. 用 `long` 防止边权和节点费用累加溢出
