## 题目描述

有 `n` 种语言和若干用户，每个用户会若干语言。只能选择一种语言教授给任意数量的用户，使得所有好友对都有共同语言。返回需要教授的最少用户数（已会该语言的用户不计）。

## 解题思路

先找出所有无共同语言的好友对涉及的用户，再统计每种语言在这些用户中已有多少人会，选会该语言最多的那种，教授其余用户。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTeachings(int n, int[][] languages, int[][] friendships) {
        int m = languages.length;
        // 将每个用户的语言转为 Set
        Set<Integer>[] langSets = new HashSet[m];
        for (int i = 0; i < m; i++) {
            langSets[i] = new HashSet<>();
            for (int l : languages[i]) langSets[i].add(l);
        }

        // 找出不能沟通的好友对涉及的用户
        Set<Integer> badUsers = new HashSet<>();
        for (int[] f : friendships) {
            int u = f[0] - 1, v = f[1] - 1;
            // 判断是否有共同语言
            boolean canCommunicate = false;
            for (int l : langSets[u]) {
                if (langSets[v].contains(l)) { canCommunicate = true; break; }
            }
            if (!canCommunicate) {
                badUsers.add(u);
                badUsers.add(v);
            }
        }

        if (badUsers.isEmpty()) return 0;

        // 统计 badUsers 中每种语言已知人数
        Map<Integer, Integer> langCount = new HashMap<>();
        for (int u : badUsers) {
            for (int l : langSets[u]) {
                langCount.merge(l, 1, Integer::sum);
            }
        }

        // 最少教授人数 = badUsers 总数 - 已会最优语言的人数
        int maxKnow = 0;
        for (int cnt : langCount.values()) maxKnow = Math.max(maxKnow, cnt);

        return badUsers.size() - maxKnow;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * L + F * L)，L 为每人平均语言数，F 为好友对数
- **空间复杂度**：O(m * L)

## 关键点总结

1. 只关注"不能沟通"的好友对中涉及的用户
2. 教授已会最多人的语言，使教授人数最少
