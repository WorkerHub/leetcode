## 题目描述

有 n 个街区需建造，初始 1 个工人。工人可分裂（耗时 split）或建造街区（耗时 blocks[i]）。多工人并行工作。求建造所有街区的最少时间。

**示例：**
```
输入：blocks = [1,2,3], split = 1
输出：4
```

## 解题思路

哈夫曼树思想：用最小堆，每次取出两个最小时间合并为 `split + max(t1, t2)`，放回堆中。最终堆中剩余的值即为答案。

## Java 代码实现

```java
class Solution {
    public int minBuildTime(int[] blocks, int split) {
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for (int b : blocks) pq.offer(b);
        
        // 每次合并两个最小的
        while (pq.size() > 1) {
            int t1 = pq.poll();
            int t2 = pq.poll();
            // 分裂后并行建造，时间取 max
            pq.offer(split + Math.max(t1, t2));
        }
        
        return pq.poll();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **哈夫曼树**：每次合并最小的两个，使总时间最小
2. **合并公式**：`split + max(t1, t2)`，因为工人并行工作取 max
3. **贪心正确性**：大建造时间在树中深度浅（分裂次数少）
4. **终止条件**：堆中剩余 1 个元素即为答案
