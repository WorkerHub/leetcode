## 题目描述

在考场里，有 n 个座位排成一行，编号为 0 到 n - 1 。

当学生进入考场后，他必须坐在离最近的人最远的那个座位。如果有多个这样的座位，他会坐在编号最小的座位上。（另外，如果考场里没有人，那么学生就坐在 0 号座位上。）

设计一个模拟所述考场的类：

- `ExamRoom(int n)`：用座位数量 n 初始化考场对象。
- `int seat()`：返回下一个学生将会坐的座位编号。
- `void leave(int p)`：指定坐在座位 p 的学生离开。题目保证座位 p 上有学生。

**示例 1：**
```
输入：
["ExamRoom","seat","seat","seat","seat","leave","seat"]
[[10],[],[],[],[],[4],[]]
输出：
[null,0,9,4,2,null,5]
解释：
ExamRoom(10) -> null
seat() -> 0，没有人在考场里，学生坐在 0 号座位。
seat() -> 9，学生最远离 0 号座位（距离为 9），所以坐在 9 号座位。
seat() -> 4，学生坐在 0 和 9 之间，距离两边都是 4。
seat() -> 2，学生坐在 0 和 4 之间，距离为 2。
leave(4) -> null
seat() -> 5，学生坐在 0 和 9 之间，距离为 5。
```

**提示：**
- 1 <= n <= 10^9
- 最多调用 10^4 次 seat 和 leave 操作
- 保证调用 leave(p) 时，座位 p 上有学生

## 解题思路

这是一道**设计题**，需要动态维护座位的占用情况。

**核心问题：**
1. 如何快速找到"离最近的人最远"的座位？
2. 如何高效处理学生入座和离开？

**关键观察：**
1. **空考场**：第一个学生坐在位置 0
2. **两端座位**：距离是 `pos` 或 `n - 1 - pos`
3. **中间座位**：距离是 `(right - left) // 2`
4. **维护有序集合**：需要知道所有已占用座位的位置

**算法策略：**
- 用 TreeSet（有序集合）存储所有已占座位
- `seat()`：遍历相邻座位，找到最大间隔的中点
- `leave(p)`：从集合中删除 p

## Java 代码实现

### 方法一：TreeSet（推荐）

```java
class ExamRoom {
    private TreeSet<Integer> students;
    private int n;

    public ExamRoom(int n) {
        this.n = n;
        this.students = new TreeSet<>();
    }

    public int seat() {
        // 如果考场为空，坐在 0 号位置
        if (students.isEmpty()) {
            students.add(0);
            return 0;
        }

        // 计算最大距离和对应座位
        int maxDist = students.first(); // 最左边的距离
        int seatPos = 0;

        // 检查相邻学生之间的间隔
        int prev = -1;
        for (int curr : students) {
            if (prev != -1) {
                // 中点位置和到最近人的距离
                int dist = (curr - prev) / 2;
                if (dist > maxDist) {
                    maxDist = dist;
                    seatPos = prev + dist;
                }
            }
            prev = curr;
        }

        // 检查最右边的座位
        if (n - 1 - students.last() > maxDist) {
            seatPos = n - 1;
        }

        students.add(seatPos);
        return seatPos;
    }

    public void leave(int p) {
        students.remove(p);
    }
}
```

**代码说明：**
- `TreeSet` 自动维护有序，方便遍历相邻元素
- `seat()`：遍历所有间隔，找最大距离的中点
- `leave(p)`：直接删除
- Java 的 TreeSet 提供 O(log n) 的增删查操作

## 复杂度分析

- **seat() 时间复杂度**：O(n)，遍历所有学生。
- **leave() 时间复杂度**：O(log n)，TreeSet 删除。
- **空间复杂度**：O(n)，存储学生位置。

## 图解示例

**示例执行过程：**

```
n = 10，座位编号 0-9

1. seat() -> 0
   students = {0}
   
2. seat() -> 9
   最左距离 = 0, 最右距离 = 9 → 最大
   students = {0, 9}

3. seat() -> 4
   中间: (9-0)/2 = 4, 座位 0+4=4
   students = {0, 4, 9}

4. seat() -> 2
   中间: (4-0)/2 = 2, 座位 0+2=2
   中间: (9-4)/2 = 2, 座位 4+2=6 (距离相同选小的)
   students = {0, 2, 4, 9}

5. leave(4)
   students = {0, 2, 9}

6. seat() -> 5
   中间: (9-2)/2 = 3, 座位 2+3=5
   students = {0, 2, 5, 9}
```

## 关键点总结

1. **有序维护**：使用 TreeSet 存储座位，方便查找间隔
2. **三种情况**：最左边、中间、最右边座位的距离计算不同
3. **距离计算**：
   - 左边：`students.first()`
   - 中间：`(right - left) / 2`
   - 右边：`n - 1 - students.last()`
4. **TreeSet 优势**：自动维护有序，提供 first()/last() 方法
5. **贪心选择**：选择最大距离，距离相同选编号最小

## 易错点

1. **边界情况**：空考场时返回 0

2. **距离计算错误**：中间座位距离应该是间隔的一半

3. **座位选择错误**：距离相同时应该选编号最小的
   - 通过遍历顺序（TreeSet 按升序遍历）自然满足

4. **最右边距离**：是 `n - 1 - students.last()` 不是 `n - students.last()`
