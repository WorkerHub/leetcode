## 题目描述

给你字符串 `s`（含括号键）和键值对列表 `knowledge`，将所有括号内的键替换为对应值，不存在则替换为 `"?"`。

## 解题思路

先将 knowledge 构建为 HashMap，再扫描字符串：遇到 `(` 提取键名并查表，其余字符直接追加。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String evaluate(String s, List<List<String>> knowledge) {
        // 构建键值哈希表
        Map<String, String> map = new HashMap<>();
        for (List<String> kv : knowledge) map.put(kv.get(0), kv.get(1));

        StringBuilder sb = new StringBuilder();
        int n = s.length(), i = 0;

        while (i < n) {
            if (s.charAt(i) == '(') {
                // 提取括号内的键名
                int j = i + 1;
                while (j < n && s.charAt(j) != ')') j++;
                String key = s.substring(i + 1, j);
                sb.append(map.getOrDefault(key, "?"));
                i = j + 1; // 跳过右括号
            } else {
                sb.append(s.charAt(i++));
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + k)
- **空间复杂度**：O(n + k)

## 关键点总结

1. 先构建 HashMap，查询 O(1)
2. 遇到 `(` 找配对 `)` 提取键名，跳过右括号时 i = j+1
