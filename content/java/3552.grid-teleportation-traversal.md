## 题目描述

给定一个 `m x n` 的字符矩阵 `grid`，从左上角 `(0, 0)` 出发到达右下角 `(m-1, n-1)`。每步可以向上下左右移动一格（非 `#`），若当前格和另一格都是相同字母可以免费传送。求最少步数，无法到达返回 `-1`。

## 解题思路

0-1 BFS：普通移动代价为 1，同字母传送代价为 0。使用双端队列，0 代价加入队头，1 代价加入队尾。用集合记录已使用过传送的字母，避免重复处理。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minMoves(String[] grid) {
        int m = grid.length, n = grid[0].length();
        // 收集每种字母的坐标
        Map<Character, List<int[]>> letterPos = new HashMap<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                char ch = grid[r].charAt(c);
                if (ch >= 'a' && ch <= 'z') {
                    letterPos.computeIfAbsent(ch, k -> new ArrayList<>()).add(new int[]{r, c});
                }
            }
        }

        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;
        Deque<int[]> dq = new ArrayDeque<>();
        dq.addFirst(new int[]{0, 0});
        Set<Character> usedLetters = new HashSet<>();
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!dq.isEmpty()) {
            int[] cur = dq.pollFirst();
            int r = cur[0], c = cur[1], d = dist[r][c];
            if (r == m-1 && c == n-1) return d;

            // 传送（0代价）
            char ch = grid[r].charAt(c);
            if (ch >= 'a' && ch <= 'z' && !usedLetters.contains(ch)) {
                usedLetters.add(ch);
                for (int[] pos : letterPos.get(ch)) {
                    int nr = pos[0], nc = pos[1];
                    if (dist[nr][nc] > d) {
                        dist[nr][nc] = d;
                        dq.addFirst(new int[]{nr, nc}); // 0代价入队头
                    }
                }
            }
            // 普通移动（1代价）
            for (int[] dir : dirs) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr].charAt(nc) != '#') {
                    if (dist[nr][nc] > d + 1) {
                        dist[nr][nc] = d + 1;
                        dq.addLast(new int[]{nr, nc}); // 1代价入队尾
                    }
                }
            }
        }

        return dist[m-1][n-1] == Integer.MAX_VALUE ? -1 : dist[m-1][n-1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 26)，0-1 BFS
- 空间复杂度：O(m * n)

## 关键点总结

1. 传送为 0 代价，普通移动为 1 代价，使用 0-1 BFS（双端队列）
2. 每种字母只需处理一次传送（`usedLetters` 避免重复）
3. 0 代价入队头，1 代价入队尾
