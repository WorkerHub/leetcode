## 题目描述

求有效括号字符串的最大嵌套深度。

**示例：**
```
输入：s = "(1+(2*3)+((8)/4))+1"
输出：3
```

## 解题思路

计数器：遇`(`加1更新最大值，遇`)`减1。

## Java 代码实现

```java
class Solution {
    public int maxDepth(String s) {
        int depth = 0, maxDepth = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                depth++;
                maxDepth = Math.max(maxDepth, depth);
            } else if (c == ')') {
                depth--;
            }
        }
        return maxDepth;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **计数器模拟栈**：O(1)空间
2. **遇`(`后立即更新最大深度**
3. **其他字符忽略**
