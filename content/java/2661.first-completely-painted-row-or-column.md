## 题目描述

给你数组 `arr` 和矩阵 `mat`（含相同整数集合），按 `arr` 顺序给 `mat` 中对应格涂色，返回第一次某行或某列被完全涂色时的 `arr` 下标。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int firstCompleteIndex(int[] arr, int[][] mat) {
        int m = mat.length, n = mat[0].length;

        // 建立值到 (行, 列) 的映射
        int[] posRow = new int[m * n + 1];
        int[] posCol = new int[m * n + 1];
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                posRow[mat[r][c]] = r;
                posCol[mat[r][c]] = c;
            }
        }

        int[] rowCnt = new int[m];
        int[] colCnt = new int[n];

        for (int i = 0; i < arr.length; i++) {
            int val = arr[i];
            int r = posRow[val], c = posCol[val];
            rowCnt[r]++;
            colCnt[c]++;
            if (rowCnt[r] == n || colCnt[c] == m) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 建立值到位置的逆映射，O(1) 定位格子
2. 行完成条件为计数 == n，列完成条件为计数 == m
