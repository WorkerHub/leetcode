## 题目描述

如果整数 `n` 在 2 到 n-2 之间所有进制下都是回文数，则称为严格回文数。给你整数 `n`，判断是否为严格回文数。

## 解题思路

数学结论：对所有 n >= 4，在 n-2 进制下 n 表示为 "12"，不是回文数。因此答案永远是 `false`。

## Java 代码实现

```java
class Solution {
    public boolean isStrictlyPalindromic(int n) {
        // 数学证明：n 在 n-2 进制下表示为 "12"，不是回文数
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 任何 n >= 4 在 n-2 进制下表示为 "12"，不是回文数。
2. 因此严格回文数不存在，直接返回 false。
3. 本题考察对题意的数学分析能力。
