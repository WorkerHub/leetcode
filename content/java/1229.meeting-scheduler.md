## 题目描述

给定两人空闲时间表 slots1 和 slots2，以及会议时长 duration。返回两人都有空的最早时间段（长度 ≥ duration）。无满足条件的返回空数组。

**示例：**
```
输入：slots1 = [[10,50],[60,120],[140,210]], slots2 = [[0,15],[60,70]], duration = 8
输出：[60,68]
```

## 解题思路

排序后双指针：计算两个区间的交集，若交集长度 ≥ duration 则返回。移动结束时间更早的指针。

## Java 代码实现

```java
class Solution {
    public List<Integer> minAvailableDuration(int[][] slots1, int[][] slots2, int duration) {
        // 按开始时间排序
        Arrays.sort(slots1, (a, b) -> a[0] - b[0]);
        Arrays.sort(slots2, (a, b) -> a[0] - b[0]);
        
        int i = 0, j = 0;
        while (i < slots1.length && j < slots2.length) {
            // 计算交集
            int start = Math.max(slots1[i][0], slots2[j][0]);
            int end = Math.min(slots1[i][1], slots2[j][1]);
            
            if (end - start >= duration) {
                return Arrays.asList(start, start + duration);
            }
            
            // 移动结束时间更早的指针
            if (slots1[i][1] < slots2[j][1]) i++;
            else j++;
        }
        return new ArrayList<>();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m + n log n)（排序）
- **空间复杂度**：O(1)（不计排序空间）

## 关键点总结

1. **排序 + 双指针**：经典区间交集模式
2. **交集计算**：start = max(两开始), end = min(两结束)
3. **指针移动**：结束时间小的先移动，因为它不可能再与后续区间产生更长交集
4. **返回最早**：第一个满足条件的就是答案
