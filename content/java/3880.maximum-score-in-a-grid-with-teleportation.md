## 题目描述

给你一个 m×n 矩阵 `grid`，从 (0,0) 出发，每步可移动到相邻格子（得分加目标格子值）或传送到任意已访问格子（代价为 0），目标到达 (m-1,n-1)，返回最大得分。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maximumScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        boolean[][] visited = new boolean[m][n];
        int[] dx = {0, 0, 1, -1};
        int[] dy = {1, -1, 0, 0};

        dp[0][0] = grid[0][0];
        visited[0][0] = true;
        Deque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});

        // 已访问格子中的最大得分（用于传送决策）
        int bestVisited = dp[0][0];

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1];

            for (int d = 0; d < 4; d++) {
                int nr = r + dx[d], nc = c + dy[d];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;

                // 普通移动得分
                int moveScore = dp[r][c] + grid[nr][nc];
                // 传送到最优已访问格子再移动
                int teleportScore = bestVisited + grid[nr][nc];
                int newScore = Math.max(moveScore, teleportScore);

                if (newScore > dp[nr][nc]) {
                    dp[nr][nc] = newScore;
                    if (!visited[nr][nc]) {
                        visited[nr][nc] = true;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
            // 更新已访问集合的最大得分
            bestVisited = Math.max(bestVisited, dp[r][c]);
        }

        return dp[m - 1][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. 传送相当于 0 权重边连接所有已访问格子。
2. 维护已访问格子中的最大得分，移动时可选择从该最优点出发。
3. 简化方法：每次扩展时同时考虑普通移动和传送后移动两种得分取最大值。
