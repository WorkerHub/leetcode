## 题目描述

给你一个正整数数组 `nums`，找出 `[1, max(nums)]` 范围内最大的不在数组中的整数。若不存在，返回 -1。

## 解题思路

建立哈希集合，从 `max(nums) - 1` 向下扫描，找到第一个不在集合中的正整数即为答案（max 本身在数组中）。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int largestMissing(int[] nums) {
        Set<Integer> numSet = new HashSet<>();
        int maxVal = 0;
        for (int x : nums) { numSet.add(x); maxVal = Math.max(maxVal, x); }
        for (int x = maxVal - 1; x >= 1; x--) {
            if (!numSet.contains(x)) return x;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + max_val)
- 空间复杂度：O(n)

## 关键点总结

1. 从最大值向下找，第一个缺失的即为答案
2. max(nums) 本身在数组中，从 max-1 开始向下
3. 集合查找 O(1)
