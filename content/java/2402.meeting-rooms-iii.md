## 题目描述

有 n 个会议室（编号 0 到 n-1），给你会议数组 `meetings`（`[start, end]`）。规则：分配编号最小的空闲室；无空闲则等最早结束的会议室并推迟（时长不变）。返回举办次数最多的会议室（并列取编号最小）。

## 解题思路

双堆模拟：空闲堆按编号排序，使用堆按（结束时间，编号）排序。对每场会议，先释放结束时间 <= 当前开始时间的会议室；有空闲则取编号最小的，否则等最早结束的并推迟。结束时间需用 `long`。

## Java 代码实现

```java
class Solution {
    public int mostBooked(int n, int[][] meetings) {
        int[] count = new int[n];
        // 空闲堆：按编号排序
        PriorityQueue<Integer> idle = new PriorityQueue<>();
        for (int i = 0; i < n; i++) idle.add(i);
        // 使用堆：按 (结束时间, 编号) 排序
        PriorityQueue<long[]> used = new PriorityQueue<>((a, b) ->
                a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]));

        Arrays.sort(meetings, (a, b) -> a[0] - b[0]);

        for (int[] m : meetings) {
            long start = m[0], end = m[1];
            // 释放已结束的会议室
            while (!used.isEmpty() && used.peek()[0] <= start) {
                idle.add((int) used.poll()[1]);
            }
            if (!idle.isEmpty()) {
                int room = idle.poll();
                used.offer(new long[]{end, room});
                count[room]++;
            } else {
                long[] earliest = used.poll();
                long newEnd = earliest[0] + (end - start); // 推迟，保持时长
                used.offer(new long[]{newEnd, earliest[1]});
                count[(int) earliest[1]]++;
            }
        }

        int ans = 0;
        for (int i = 1; i < n; i++) if (count[i] > count[ans]) ans = i;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m + m log n)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 双堆：空闲堆按编号、使用堆按（结束时间，编号）排序。
2. 推迟会议：新结束时间 = 最早可用时间 + 原始时长（不是原始结束时间）。
3. 结束时间可能很大（累积推迟），必须用 `long`。
