## 题目描述

给定一个字符串 `s` 和整数 `k`。从字符串中找出最多数量的不相交（不重叠）长度为 `k` 的子字符串，使得这些子字符串两两不同。返回能找到的最大数量。

## 解题思路

贪心：从左到右扫描，遇到新的（未选过的）长度为 k 的子串时选取它，并将下一个可选起始位置移到当前结束位置之后。已选过的子串跳过，继续移动一位。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int maxNonIntersecting(String s, int k) {
        int n = s.length();
        Set<String> seen = new HashSet<>(); // 已选的子串
        int count = 0, i = 0;

        while (i + k <= n) {
            String sub = s.substring(i, i + k);
            if (!seen.contains(sub)) {
                seen.add(sub);
                count++;
                i += k; // 跳过当前子串
            } else {
                i++; // 移动一位继续找
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，字符串哈希
- 空间复杂度：O(n * k)，存储哈希

## 关键点总结

1. 贪心：优先选最早出现的不重叠唯一子串
2. 使用哈希集合确保选取的子串两两不同
3. 遇到已见过的子串时只移动一位，而非 k 位
