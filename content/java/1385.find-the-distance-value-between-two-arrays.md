## 题目描述

给你两个整数数组 arr1 和 arr2，以及整数 d。返回 arr1 中满足条件的元素数量：对于每个这样的元素 x，arr2 中所有元素 y 均满足 |x-y| > d。

## 解题思路

对 arr2 排序，对 arr1 中每个元素 x，用二分查找找 arr2 中第一个 >= x-d 的位置，若该位置的值 <= x+d，则 arr2 中存在落在 [x-d, x+d] 内的元素，x 不满足条件；否则计数加 1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findTheDistanceValue(int[] arr1, int[] arr2, int d) {
        Arrays.sort(arr2);
        int count = 0;

        for (int x : arr1) {
            int lo = x - d, hi = x + d;
            // 二分查找：找 arr2 中第一个 >= lo 的位置
            int pos = lowerBound(arr2, lo);
            // 若该位置的值 <= hi，说明 arr2 中存在落在 [lo,hi] 的元素
            if (pos == arr2.length || arr2[pos] > hi) {
                count++;
            }
        }

        return count;
    }

    // 返回 arr 中第一个 >= target 的下标（不存在则返回 arr.length）
    private int lowerBound(int[] arr, int target) {
        int left = 0, right = arr.length;
        while (left < right) {
            int mid = (left + right) / 2;
            if (arr[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
```

## 复杂度分析

- 时间复杂度：O((m+n) log n)，排序 O(n log n) + 每个 arr1 元素二分 O(m log n)。
- 空间复杂度：O(1)（不计排序辅助空间）。

## 关键点总结

1. `|x-y| > d` 等价于 `y < x-d 或 y > x+d`，即 y 不在 `[x-d, x+d]` 内。
2. 对 arr2 排序后，用 lower_bound 找第一个 >= x-d 的位置，再判断是否 <= x+d 即可。
3. 条件为严格大于 d，等于 d 时不满足，边界检查用 `arr2[pos] > hi`（严格大于）。
