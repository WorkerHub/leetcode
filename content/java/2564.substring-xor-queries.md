## 题目描述

给你二进制字符串 `s` 和查询数组 `queries`（`[first, second]`），每个查询找 `s` 中值等于 `first XOR second` 的最短子串（无前导零），返回其左右下标，不存在返回 `[-1,-1]`。

## 解题思路

预计算：对 `s` 每个非零起始位置，扩展至多 30 位（目标值最大 10^9 < 2^30），将值和 `[left, right]` 存入哈希表（只存最短即首次出现的）；起始为 0 时单独处理值 0 的情况。查询时直接哈希查找。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[][] substringXorQueries(String s, int[][] queries) {
        int n = s.length();
        Map<Integer, int[]> valToPos = new HashMap<>();

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') {
                // 单个 '0' 表示值 0（多位以 0 开头有前导零，跳过）
                valToPos.putIfAbsent(0, new int[]{i, i});
                continue;
            }
            int val = 0;
            // 至多扩展 30 位（10^9 < 2^30）
            for (int j = i; j < Math.min(i + 30, n); j++) {
                val = (val << 1) | (s.charAt(j) - '0');
                valToPos.putIfAbsent(val, new int[]{i, j});
            }
        }

        int[][] ans = new int[queries.length][2];
        for (int i = 0; i < queries.length; i++) {
            int target = queries[i][0] ^ queries[i][1];
            ans[i] = valToPos.getOrDefault(target, new int[]{-1, -1});
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(30n + q)
- **空间复杂度**：O(30n)

## 关键点总结

1. 预处理所有合法子串到哈希表，查询时 O(1)
2. 以 0 开头的多位子串有前导零，跳过；仅 "0" 本身有效
3. 每个起点最多扩展 30 位，控制时间复杂度
