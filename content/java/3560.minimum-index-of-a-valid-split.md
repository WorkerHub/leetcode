## 题目描述

给定一个整数数组 `nums`。若一个元素出现次数超过数组长度一半，则称其为"支配元素"。将数组分割为两个非空部分，若两部分都有同一个支配元素，则称该分割合法。返回最小的合法分割位置，若不存在则返回 `-1`。

## 解题思路

1. Boyer-Moore 投票算法 O(n) 找支配元素候选并验证
2. 从左到右枚举分割位置，维护前缀支配元素计数
3. 检查左半和右半是否都满足支配条件

## Java 代码实现

```java
class Solution {
    public int minimumIndex(int[] nums) {
        int n = nums.length;
        // Boyer-Moore 找支配元素候选
        int candidate = nums[0], count = 1;
        for (int i = 1; i < n; i++) {
            if (count == 0) { candidate = nums[i]; count = 1; }
            else if (nums[i] == candidate) count++;
            else count--;
        }

        // 验证候选
        int total = 0;
        for (int x : nums) if (x == candidate) total++;
        if (total * 2 <= n) return -1;

        // 枚举分割位置
        int leftCount = 0;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] == candidate) leftCount++;
            int leftLen = i + 1;
            int rightCount = total - leftCount;
            int rightLen = n - leftLen;
            if (leftCount * 2 > leftLen && rightCount * 2 > rightLen)
                return i;
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，Boyer-Moore + 前缀扫描
- 空间复杂度：O(1)

## 关键点总结

1. Boyer-Moore 投票算法 O(n) 找支配元素
2. 分割后两半的支配元素必须相同（即整个数组的支配元素）
3. 支配条件：出现次数**严格大于**数组长度一半
