## 题目描述

给你只含数字的字符串 `s`（长度 n）。每次操作将所有相邻两个数字替换为其和对 10 取模，重复直到长度为 2。判断最终两个数字是否相等。

## 解题思路

直接模拟：每次将所有相邻对同时替换，重复 n-2 次后得到长度为 2 的数组，比较两个数字是否相等。n <= 100，O(n^2) 可接受。

## Java 代码实现

```java
class Solution {
    public boolean hasSameDigits(String s) {
        int[] digits = new int[s.length()];
        for (int i = 0; i < s.length(); i++) {
            digits[i] = s.charAt(i) - '0';
        }

        // 每次将相邻对替换为和 mod 10
        while (digits.length > 2) {
            int[] next = new int[digits.length - 1];
            for (int i = 0; i < next.length; i++) {
                next[i] = (digits[i] + digits[i + 1]) % 10;
            }
            digits = next;
        }
        return digits[0] == digits[1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，模拟 n-2 次操作
- 空间复杂度：O(n)

## 关键点总结

1. 每次操作同时处理所有相邻对（不是只处理一对）
2. 和对 10 取模，保持数字在 0-9 范围内
3. n <= 100，模拟 O(n^2) 完全可接受
