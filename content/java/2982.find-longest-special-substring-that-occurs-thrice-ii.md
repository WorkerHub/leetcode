## 题目描述

给你字符串 `s`（长度最大 5×10^5），找到至少出现三次的最长特殊子字符串（只由单一字母重复组成），不存在则返回 -1。

## 解题思路

拆分为连续相同字符的段，对每个字符二分查找最大的 k：长度 k 的特殊子串出现次数 = 各段 max(0, L-k+1) 之和。利用单调性（k 越大出现次数越少）进行二分。

## Java 代码实现

```java
class Solution {
    public int maximumLength(String s) {
        int n = s.length();
        // 记录每个字符的连续段长度列表
        List<List<Integer>> runs = new ArrayList<>();
        for (int i = 0; i < 26; i++) runs.add(new ArrayList<>());

        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            runs.get(s.charAt(i) - 'a').add(j - i);
            i = j;
        }

        int ans = -1;
        for (int c = 0; c < 26; c++) {
            List<Integer> lengths = runs.get(c);
            if (lengths.isEmpty()) continue;
            int maxLen = Collections.max(lengths);
            // 二分：找最大 k 使得出现次数 >= 3
            int lo = 1, hi = maxLen;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (countOccurrences(lengths, mid) >= 3) {
                    ans = Math.max(ans, mid);
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
        }
        return ans;
    }

    private int countOccurrences(List<Integer> lengths, int k) {
        int total = 0;
        for (int L : lengths) total += Math.max(0, L - k + 1); // 长度 k 在长度 L 的段中出现次数
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 26 × R × log L)，R 为段数，L 为最大段长
- **空间复杂度**：O(n)

## 关键点总结

1. 每段长度 L 对长度 k 的贡献 = max(0, L-k+1)
2. 出现次数关于 k 单调递减，可二分
3. 对 26 个字符分别处理
