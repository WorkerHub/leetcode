## 题目描述

给你一个整数数组 `nums` 和整数 `k`，返回按位与值等于 `k` 的子数组数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countSubarrays(int[] nums, int k) {
        long ans = 0;
        // groups: int[]{andValue, count}，表示以当前位置为右端的各 AND 值对应子数组数量
        List<int[]> groups = new ArrayList<>();

        for (int x : nums) {
            List<int[]> newGroups = new ArrayList<>();
            for (int[] g : groups) {
                int newVal = g[0] & x;
                // 若与上一组 AND 值相同则合并
                if (!newGroups.isEmpty() && newGroups.get(newGroups.size() - 1)[0] == newVal) {
                    newGroups.get(newGroups.size() - 1)[1] += g[1];
                } else {
                    newGroups.add(new int[]{newVal, g[1]});
                }
            }
            // 加上只含当前元素的子数组
            if (!newGroups.isEmpty() && newGroups.get(newGroups.size() - 1)[0] == x) {
                newGroups.get(newGroups.size() - 1)[1]++;
            } else {
                newGroups.add(new int[]{x, 1});
            }
            groups = newGroups;

            // 统计 AND 值等于 k 的子数组数量
            for (int[] g : groups) {
                if (g[0] == k) {
                    ans += g[1];
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log C)，C 为最大值，每个右端点最多 O(log C) 种不同 AND 值
- 空间复杂度：O(log C)

## 关键点总结

1. 固定右端时，AND 值最多 O(log C) 种，可以分组维护
2. 每次向右扩展时，将所有组的 AND 值与新元素做 AND，合并相同值
3. 统计 AND == k 的组的计数即可
