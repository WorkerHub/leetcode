## 题目描述

给定字符串数组 `nums` 和字符串 `target`，返回 `nums[i] + nums[j]`（字符串连接，`i != j`）等于 `target` 的有序数对数目。

## 解题思路

用哈希表统计每个字符串出现次数，枚举 target 的所有分割点，查找前缀和后缀各自在哈希表中的频次之积（前缀等于后缀时需减 1 排除自身）。

## Java 代码实现

### 方法一：哈希表优化（推荐）

```java
import java.util.*;

class Solution {
    public int numOfPairs(String[] nums, String target) {
        Map<String, Integer> freq = new HashMap<>();
        for (String s : nums) freq.merge(s, 1, Integer::sum);

        int count = 0;
        int len = target.length();
        for (int i = 1; i < len; i++) {
            String prefix = target.substring(0, i);
            String suffix = target.substring(i);
            if (freq.containsKey(prefix) && freq.containsKey(suffix)) {
                if (prefix.equals(suffix)) {
                    int n = freq.get(prefix);
                    count += n * (n - 1); // 有序数对，排除自身
                } else {
                    count += freq.get(prefix) * freq.get(suffix);
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * L + L^2)，L 为字符串长度
- 空间复杂度：O(n * L)

## 关键点总结

1. 数对 (i, j) 是有序的（(i,j) 和 (j,i) 各算一次）
2. 枚举所有分割点查找前缀和后缀是否在 nums 中
3. 前缀等于后缀时用 `n*(n-1)` 而非 `n*n`（排除同下标自身配对）
