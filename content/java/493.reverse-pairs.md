## 题目描述

给定一个数组 nums，如果 i < j 且 nums[i] > 2 * nums[j]，我们就将 (i, j) 称作一个重要翻转对。

你需要返回给定数组中的重要翻转对的数量。

**示例 1：**
```
输入：nums = [1,3,2,3,1]
输出：2
```

**示例 2：**
```
输入：nums = [2,4,3,5,1]
输出：3
```

**提示：**
- 0 <= nums.length <= 5 * 10^4
- -2^31 <= nums[i] <= 2^31 - 1

## 解题思路

这道题是经典的逆序对问题的变种，可以使用归并排序、树状数组或线段树解决。

### 核心思想

1. **暴力解法**（O(n²)）：
   - 双重循环枚举所有 (i, j) 对
   - 检查是否满足条件
   - 超时，不可行

2. **归并排序**（推荐）：
   - 在归并排序过程中统计翻转对
   - 左右两部分各自有序后，统计跨越的翻转对
   - 时间复杂度 O(n log n)

3. **关键观察**：
   - 对于已排序的左右两部分
   - 对于左边的每个元素，找右边有多少个元素满足条件
   - 利用有序性快速统计

## Java 代码实现

### 方法一：归并排序（推荐）

```java
class Solution {
    public int reversePairs(int[] nums) {
        return mergeSort(nums, 0, nums.length - 1);
    }

    private int mergeSort(int[] nums, int start, int end) {
        if (start >= end) return 0;

        int mid = (start + end) / 2;
        // 递归统计左右两部分的翻转对
        int count = mergeSort(nums, start, mid) + mergeSort(nums, mid + 1, end);

        // 统计跨越中点的翻转对（注意用 long 防止溢出）
        int j = mid + 1;
        for (int i = start; i <= mid; i++) {
            while (j <= end && (long) nums[i] > 2L * nums[j]) {
                j++;
            }
            count += j - (mid + 1);
        }

        // 合并两个有序数组
        int[] temp = new int[end - start + 1];
        int left = start, right = mid + 1, k = 0;
        while (left <= mid && right <= end) {
            if (nums[left] <= nums[right]) {
                temp[k++] = nums[left++];
            } else {
                temp[k++] = nums[right++];
            }
        }
        while (left <= mid) temp[k++] = nums[left++];
        while (right <= end) temp[k++] = nums[right++];

        // 将排序结果写回原数组
        for (int i = 0; i < temp.length; i++) {
            nums[start + i] = temp[i];
        }

        return count;
    }
}
```

### 方法二：优化的归并排序（手动合并）

```java
class Solution {
    private int[] nums;

    public int reversePairs(int[] nums) {
        this.nums = nums;
        return mergeSortAndCount(0, nums.length - 1);
    }

    private int mergeSortAndCount(int start, int end) {
        if (start >= end) return 0;

        int mid = (start + end) / 2;
        int count = mergeSortAndCount(start, mid) + mergeSortAndCount(mid + 1, end);

        // 统计翻转对
        int j = mid + 1;
        for (int i = start; i <= mid; i++) {
            while (j <= end && (long) nums[i] > 2L * nums[j]) {
                j++;
            }
            count += j - (mid + 1);
        }

        // 手动合并
        int[] temp = new int[end - start + 1];
        int left = start, right = mid + 1, k = 0;
        while (left <= mid && right <= end) {
            if (nums[left] <= nums[right]) {
                temp[k++] = nums[left++];
            } else {
                temp[k++] = nums[right++];
            }
        }
        while (left <= mid) temp[k++] = nums[left++];
        while (right <= end) temp[k++] = nums[right++];

        System.arraycopy(temp, 0, nums, start, temp.length);

        return count;
    }
}
```

### 方法三：使用树状数组（Binary Indexed Tree）

```java
import java.util.*;

class Solution {
    private int[] bit;
    private int n;

    public int reversePairs(int[] nums) {
        // 离散化：收集所有需要的值（原值和 2 倍值）
        TreeSet<Long> valSet = new TreeSet<>();
        for (int num : nums) {
            valSet.add((long) num);
            valSet.add(2L * num);
        }

        // 建立值到排名的映射
        Map<Long, Integer> rank = new HashMap<>();
        int idx = 1;
        for (long val : valSet) {
            rank.put(val, idx++);
        }

        n = rank.size();
        bit = new int[n + 1];

        int count = 0;
        // 从右向左处理
        for (int i = nums.length - 1; i >= 0; i--) {
            // 查询有多少个数的排名 < 当前数 2 倍的排名
            count += query(rank.get((long) nums[i]) - 1);
            // 插入当前数对应的 2 倍值
            update(rank.get(2L * nums[i]));
        }

        return count;
    }

    private void update(int idx) {
        while (idx <= n) {
            bit[idx]++;
            idx += idx & (-idx);
        }
    }

    private int query(int idx) {
        int res = 0;
        while (idx > 0) {
            res += bit[idx];
            idx -= idx & (-idx);
        }
        return res;
    }
}
```

### 方法四：暴力解法（仅供理解）

```java
class Solution {
    public int reversePairs(int[] nums) {
        // 暴力解法，超时
        int count = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 用 long 防止溢出
                if ((long) nums[i] > 2L * nums[j]) {
                    count++;
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

**方法一、二：归并排序**
- **时间复杂度**：O(n log n)
  - 归并排序：O(n log n)
  - 统计翻转对：每层 O(n)，总共 log n 层

- **空间复杂度**：O(n)
  - 临时数组：O(n)
  - 递归栈：O(log n)

**方法三：树状数组**
- **时间复杂度**：O(n log n)
  - 离散化：O(n log n)
  - 树状数组操作：每次 O(log n)，总共 n 次

- **空间复杂度**：O(n)
  - 树状数组：O(n)

**方法四：暴力**
- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **分治思想**：将问题分解为子问题
2. **归并排序应用**：在合并过程中统计
3. **有序性利用**：左右两部分有序后快速统计
4. **双指针技巧**：统计时使用双指针
5. **溢出处理**：2 * nums[j] 可能超出 int 范围，必须用 long

## 易错点

1. **条件判断**
   - 是 nums[i] > 2 * nums[j]，不是 nums[i] > nums[j]
   - 注意是严格大于

2. **统计时机**
   - 在归并之前统计翻转对
   - 不是在归并过程中统计

3. **指针初始化**
   - j 从 mid + 1 开始
   - 每次外层循环不需要重置 j（利用单调性）

4. **数组合并**
   - 统计和合并是两个独立的过程
   - 不要在统计时修改数组

5. **溢出问题**
   - 2 * nums[j] 在 Java 中可能溢出（int 范围 -2^31 ~ 2^31-1）
   - 必须将 nums[i] 或 nums[j] 转为 long：(long) nums[i] > 2L * nums[j]
