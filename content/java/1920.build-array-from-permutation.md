## 题目描述

给你 `[0, n-1]` 的排列 `nums`，构建数组 `ans` 使得 `ans[i] = nums[nums[i]]`，返回 `ans`。

## 解题思路

直接按定义模拟：`ans[i] = nums[nums[i]]`。进阶可用原地编码（`nums[i] += (nums[nums[i]] % n) * n`）实现 O(1) 额外空间。

## Java 代码实现

```java
class Solution {
    public int[] buildArray(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            ans[i] = nums[nums[i]]; // 按定义直接构建
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 题目定义直接：`ans[i] = nums[nums[i]]`
2. O(1) 空间进阶：利用 nums[i] < n，用 `nums[i] += (nums[nums[i]] % n) * n` 同时存新旧值
