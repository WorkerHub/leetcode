## 题目描述

求乘积为正数的最长子数组长度。

**示例：**
```
输入：nums = [1,-2,-3,4]
输出：4
```

## 解题思路

DP：维护 pos（正乘积最长长度）和 neg（负乘积最长长度），遇到正数/负数/0 分别转移。

## Java 代码实现

```java
class Solution {
    public int getMaxLen(int[] nums) {
        int pos = 0, neg = 0, ans = 0;
        for (int num : nums) {
            if (num > 0) {
                pos++;
                neg = neg > 0 ? neg + 1 : 0;
            } else if (num < 0) {
                int newPos = neg > 0 ? neg + 1 : 0;
                int newNeg = pos + 1;
                pos = newPos;
                neg = newNeg;
            } else {
                pos = 0;
                neg = 0;
            }
            ans = Math.max(ans, pos);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **正数**：pos 延长，neg 也延长（若存在）
2. **负数**：pos 和 neg 互换（符号翻转）
3. **零**：全部重置
