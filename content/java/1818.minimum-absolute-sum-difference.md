## 题目描述

给你等长正整数数组 `nums1` 和 `nums2`，可将 `nums1` 中一个元素替换为 `nums1` 中另一个元素，使绝对差值和最小。返回最小绝对差值和，对 10^9+7 取余。

## 解题思路

排序 nums1 的副本，对每个位置 i，二分查找最接近 nums2[i] 的 nums1 值，计算最大可节省量，从总和中减去。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minAbsoluteSumDiff(int[] nums1, int[] nums2) {
        final int MOD = 1_000_000_007;
        int n = nums1.length;
        int[] sorted = nums1.clone();
        Arrays.sort(sorted);

        long total = 0;
        long maxSave = 0;

        for (int i = 0; i < n; i++) {
            int diff = Math.abs(nums1[i] - nums2[i]);
            total += diff;

            // 二分查找 sorted 中最接近 nums2[i] 的值
            int pos = lowerBound(sorted, nums2[i]);
            // 检查 pos 和 pos-1 两个候选
            if (pos < n) {
                long save = diff - Math.abs(sorted[pos] - nums2[i]);
                if (save > maxSave) maxSave = save;
            }
            if (pos > 0) {
                long save = diff - Math.abs(sorted[pos - 1] - nums2[i]);
                if (save > maxSave) maxSave = save;
            }
        }

        return (int) ((total - maxSave) % MOD);
    }

    // 返回 sorted 中第一个 >= target 的下标
    private int lowerBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 最优替换：nums1 中最接近 nums2[i] 的值（二分查找）
2. 检查二分查找结果的左右两个候选
3. 节省量可能为负（无法改善），取最大值
