## 题目描述

给你一个整数数组 `nums` 和整数 `k`，找到长度至多为 `k` 的连续子数组，使其元素之和最大，返回该最大和。

## 解题思路

前缀和 + 单调队列：`sum[i..j] = prefix[j+1] - prefix[i]`，最大化差值，约束 `j+1-i <= k`。对每个 `j`，在 `[j+1-k, j]` 范围内找最小前缀和，用单调递增队列维护。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxSumSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        long ans = Long.MIN_VALUE;
        Deque<Integer> dq = new ArrayDeque<>(); // 单调递增队列，存前缀和下标

        for (int j = 1; j <= n; j++) {
            // 移除窗口外的元素（下标 < j - k）
            while (!dq.isEmpty() && dq.peekFirst() < j - k) dq.pollFirst();
            // 当前子数组和 = prefix[j] - prefix[队头]
            if (!dq.isEmpty()) ans = Math.max(ans, prefix[j] - prefix[dq.peekFirst()]);
            // 维护单调递增队列（移除队尾大于等于 prefix[j] 的元素）
            while (!dq.isEmpty() && prefix[dq.peekLast()] >= prefix[j]) dq.pollLast();
            dq.addLast(j);
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 前缀和将子数组和转为两端前缀和之差
2. 单调队列维护滑动窗口内的最小前缀和
3. 窗口大小约束转化为下标范围约束
