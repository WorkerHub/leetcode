## 题目描述

给定字符串 s 和字符串数组 words，返回 words 中是 s 的子序列的单词个数。

**示例：**
```
输入：s = "abcde", words = ["a","bb","acd","ace"]
输出：3
```

## 解题思路

预处理 s 中每个字符的位置列表，对每个 word 用二分查找逐字符匹配。

## Java 代码实现

```java
class Solution {
    public int numMatchingSubseq(String s, String[] words) {
        // 预处理 s 中每个字符的位置
        List<Integer>[] positions = new List[26];
        for (int i = 0; i < 26; i++) positions[i] = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            positions[s.charAt(i) - 'a'].add(i);
        }

        int count = 0;
        for (String word : words) {
            if (isSubseq(word, positions)) count++;
        }
        return count;
    }

    private boolean isSubseq(String word, List<Integer>[] positions) {
        int prev = -1;
        for (char c : word.toCharArray()) {
            List<Integer> pos = positions[c - 'a'];
            // 二分查找第一个 > prev 的位置
            int idx = Collections.binarySearch(pos, prev + 1);
            if (idx < 0) idx = -idx - 1;
            if (idx == pos.size()) return false;
            prev = pos.get(idx);
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m × L × log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **预处理位置**：记录 s 中每个字符出现的所有位置
2. **二分查找**：快速找到字符在 s 中的下一个出现位置
3. **贪心匹配**：每次选择最近的合法位置
