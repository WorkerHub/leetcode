## 题目描述

设计一个贪吃蛇游戏，该游戏将在给定的屏幕大小上运行。如果你不熟悉这个游戏，可以参考维基百科。

实现 `SnakeGame` 类：

- `SnakeGame(int width, int height, int[][] food)` 初始化对象，屏幕大小为 `width x height`，`food` 是食物位置数组，格式为 `food = [[r1, c1], [r2, c2], ...]`。
- `int move(String direction)` 返回蛇吃掉食物后的得分。如果游戏结束返回 `-1`。

**规则：**
- 蛇初始时在 `(0, 0)` 位置，身体长度为 1 个单元格
- 你会获得一个食物位置列表，当蛇吃到食物时，身体长度增加 1
- 如果蛇撞墙或撞到自己的身体，游戏结束
- 食物按顺序出现（吃完一个才出现下一个）

**示例：**
```
输入：
["SnakeGame", "move", "move", "move", "move", "move", "move"]
[[3, 2, [[1, 2], [0, 1]]], ["R"], ["D"], ["R"], ["U"], ["L"], ["U"]]
输出：
[null, 0, 0, 1, 1, 2, -1]

解释：
SnakeGame snakeGame = new SnakeGame(3, 2, [[1, 2], [0, 1]]);
snakeGame.move("R"); // 返回 0
snakeGame.move("D"); // 返回 0
snakeGame.move("R"); // 返回 1，蛇吃掉第一个食物，长度增加
snakeGame.move("U"); // 返回 1
snakeGame.move("L"); // 返回 2，蛇吃掉第二个食物
snakeGame.move("U"); // 返回 -1，游戏结束（撞墙）
```

**提示：**
- `1 <= width, height <= 10^4`
- `1 <= food.length <= 50`
- `food[i].length == 2`
- `0 <= ri < height`
- `0 <= ci < width`
- `direction.length == 1`
- `direction` 为 `'U'`、`'D'`、`'L'` 或 `'R'`
- 最多调用 `10^4` 次 `move`

## 解题思路

这道题需要模拟贪吃蛇的移动过程。

**核心数据结构：**
- 双端队列（ArrayDeque）：存储蛇的身体坐标
- 集合（HashSet）：快速判断蛇身是否碰撞

**移动逻辑：**
1. 计算新的头部位置
2. 检查是否出界或撞到自己
3. 检查是否吃到食物
   - 是：头部入队，不删除尾部
   - 否：头部入队，删除尾部

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class SnakeGame {
    private int width, height;
    private int[][] food;
    private int foodIndex;
    private Deque<Integer> snake; // 蛇的身体（双端队列，存储编码后的坐标）
    private Set<Integer> snakeSet; // 蛇身集合（用于快速碰撞检测）

    public SnakeGame(int width, int height, int[][] food) {
        this.width = width;
        this.height = height;
        this.food = food;
        this.foodIndex = 0;

        snake = new ArrayDeque<>();
        snakeSet = new HashSet<>();

        // 初始位置 (0, 0)
        snake.addFirst(encode(0, 0));
        snakeSet.add(encode(0, 0));
    }

    // 将坐标编码为唯一整数，避免使用 int[] 作为集合键
    private int encode(int r, int c) {
        return r * (width + 1) + c;
    }

    public int move(String direction) {
        // 当前头部位置（解码）
        int head = snake.peekFirst();
        int headR = head / (width + 1);
        int headC = head % (width + 1);

        // 计算新头部位置
        int newR = headR, newC = headC;
        switch (direction) {
            case "U": newR--; break;
            case "D": newR++; break;
            case "L": newC--; break;
            case "R": newC++; break;
        }

        // 检查是否出界
        if (newR < 0 || newR >= height || newC < 0 || newC >= width) {
            return -1;
        }

        // 检查是否吃到食物
        boolean ateFood = false;
        if (foodIndex < food.length && newR == food[foodIndex][0] && newC == food[foodIndex][1]) {
            ateFood = true;
            foodIndex++;
        }

        // 如果没吃到食物，移除尾部
        if (!ateFood) {
            int tail = snake.pollLast();
            snakeSet.remove(tail);
        }

        // 检查是否撞到自己（在移除尾部后检查）
        int newHead = encode(newR, newC);
        if (snakeSet.contains(newHead)) {
            return -1;
        }

        // 添加新头部
        snake.addFirst(newHead);
        snakeSet.add(newHead);

        // 返回当前得分
        return snake.size() - 1;
    }
}
```

**时间复杂度：** O(1)
**空间复杂度：** O(W × H)，最坏情况蛇占满整个屏幕

## 关键点总结

1. **双数据结构**：Deque 维护顺序，HashSet 快速查询
2. **碰撞检测顺序**：先移除尾部再检测碰撞
3. **边界检查**：出界和自撞分开处理
4. **食物索引**：按顺序消费食物
5. **坐标编码**：用整数表示坐标，方便放入 HashSet

## 易错点

1. **碰撞检测顺序**
   ```java
   // 错误：先检测碰撞再移除尾部
   if (snakeSet.contains(newHead)) return -1;
   if (!ateFood) snake.pollLast();

   // 正确：先移除尾部再检测
   if (!ateFood) {
       int tail = snake.pollLast();
       snakeSet.remove(tail);
   }
   if (snakeSet.contains(newHead)) return -1;
   ```

2. **返回值**
   ```java
   // 错误：返回长度
   return snake.size();

   // 正确：返回得分（长度-1）
   return snake.size() - 1;
   ```

3. **坐标编码**
   ```java
   // 注意：width+1 防止 r*(width)+c 出现碰撞
   private int encode(int r, int c) {
       return r * (width + 1) + c;
   }
   ```
