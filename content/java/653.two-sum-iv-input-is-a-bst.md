## 题目描述

给定一个二叉搜索树 `root` 和一个目标结果 `k`，如果二叉搜索树中存在两个元素且它们的和等于给定的目标结果，则返回 `true`。

**示例 1:**

```
输入: root = [5,3,6,2,4,null,7], k = 9
输出: true
```

**示例 2:**

```
输入: root = [5,3,6,2,4,null,7], k = 28
输出: false
```

**提示:**
- 树中节点数目在范围 `[1, 10⁴]` 内
- `-10⁴ <= Node.val <= 10⁴`
- 题目数据保证，输入的 `root` 是一棵**有效**的二叉搜索树
- `-10⁵ <= k <= 10⁵`

## 解题思路

这道题是经典的 Two Sum 问题在二叉搜索树上的变种。有多种解法：

### 思路一：哈希表法（最直观）

像普通数组的 Two Sum 一样，用哈希表记录遍历过的值，查找 `k - node.val` 是否存在。

**步骤：**
1. 遍历二叉树（任何遍历方式都可以）
2. 对于每个节点值 `val`，检查 `k - val` 是否在哈希表中
3. 如果存在，返回 true
4. 否则将 `val` 加入哈希表

### 思路二：中序遍历 + 双指针（利用 BST 性质）

BST 的中序遍历结果是有序数组，可以使用双指针法。

**步骤：**
1. 中序遍历得到有序数组
2. 使用双指针在有序数组中找 Two Sum

### 思路三：BFS + 哈希表

使用广度优先搜索遍历所有节点，配合哈希表查找。

## Java 代码实现

### 方法一：哈希表（推荐新手）

```java
import java.util.*;

class Solution {
    Set<Integer> seen = new HashSet<>();

    public boolean findTarget(TreeNode root, int k) {
        // 使用哈希表记录已访问的值
        return dfs(root, k);
    }

    private boolean dfs(TreeNode node, int k) {
        if (node == null) return false;

        // 检查 k - node.val 是否存在
        if (seen.contains(k - node.val)) return true;

        // 将当前值加入哈希表
        seen.add(node.val);

        // 递归搜索左右子树
        return dfs(node.left, k) || dfs(node.right, k);
    }
}
```

### 方法二：中序遍历 + 双指针

```java
import java.util.*;

class Solution {
    public boolean findTarget(TreeNode root, int k) {
        // 中序遍历得到有序数组
        List<Integer> nums = new ArrayList<>();
        inorder(root, nums);

        // 双指针查找
        int left = 0, right = nums.size() - 1;
        while (left < right) {
            int sum = nums.get(left) + nums.get(right);
            if (sum == k) return true;
            else if (sum < k) left++;
            else right--;
        }

        return false;
    }

    private void inorder(TreeNode node, List<Integer> nums) {
        if (node == null) return;
        inorder(node.left, nums);
        nums.add(node.val);
        inorder(node.right, nums);
    }
}
```

### 方法三：BFS + 哈希表

```java
import java.util.*;

class Solution {
    public boolean findTarget(TreeNode root, int k) {
        if (root == null) return false;

        Set<Integer> seen = new HashSet<>();
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();

            // 检查是否存在配对值
            if (seen.contains(k - node.val)) return true;

            seen.add(node.val);

            // 将子节点加入队列
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }

        return false;
    }
}
```

## 复杂度分析

### 方法一：哈希表
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，哈希表和递归栈

### 方法二：中序遍历 + 双指针
- **时间复杂度**：O(n)，中序遍历 + 双指针遍历
- **空间复杂度**：O(n)，存储中序遍历结果

### 方法三：BFS + 哈希表
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(n)，队列和哈希表

## 关键点总结

1. **利用 BST 性质**：中序遍历是有序的，可以使用双指针
2. **哈希表通用性强**：不需要利用 BST 特性，适用于普通二叉树
3. **空间优化**：BST 迭代器只需 O(h) 空间
4. **遍历方式灵活**：DFS、BFS 都可以，根据场景选择
5. **提前终止**：找到答案后立即返回，不需要遍历完所有节点

## 易错点

1. **忘记检查同一节点**：
   ```java
   // 正确：先检查再加入
   if (seen.contains(k - node.val)) return true;
   seen.add(node.val);
   ```

2. **双指针边界条件**：
   ```java
   // 确保 left < right，避免同一元素使用两次
   while (left < right)
   ```

3. **空树处理**：
   ```java
   if (root == null) return false;
   ```

4. **整数溢出**：Java 中 int 相加可能溢出，需要注意范围
5. **equals 比较**：Integer 对象比较要用 equals()，不能用 ==
