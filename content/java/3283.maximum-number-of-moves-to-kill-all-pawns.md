## 题目描述

50×50 棋盘上有骑士和若干兵（最多 15 个）。Alice 移动骑士捕获兵得 1 分，Bob 可移除任意兵。Alice 最大化、Bob 最小化得分，返回最优策略下 Alice 能获得的最多兵数。

## 解题思路

BFS 预计算骑士从各位置到各兵的最少步数，再用状态压缩博弈 DP：`dp(mask, last)` 表示已捕获 mask 中的兵、最后到达 last 处时的最优额外得分。已捕获兵数为偶数时 Alice 行动（最大化），奇数时 Bob 行动（最小化）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int n;
    private int[][] dist;      // dist[i][j] = 从第 i 个点到第 j 个兵的最少步数
    private int[][] positions;
    private int[][] memo;

    public int maxMoves(int kx, int ky, int[][] positions) {
        this.n = positions.length;
        this.positions = positions;
        // 所有关键点：0..n-1 是兵，n 是起始位置
        int[][] allPos = new int[n + 1][2];
        for (int i = 0; i < n; i++) allPos[i] = positions[i];
        allPos[n] = new int[]{kx, ky};

        dist = new int[n + 1][n];
        int[][] dirs = {{-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}};
        for (int i = 0; i <= n; i++) {
            // BFS 从 allPos[i] 出发，计算到每个兵的最少步数
            int[] d = new int[50 * 50];
            Arrays.fill(d, -1);
            int sx = allPos[i][0], sy = allPos[i][1];
            d[sx * 50 + sy] = 0;
            Queue<int[]> q = new LinkedList<>();
            q.offer(new int[]{sx, sy});
            while (!q.isEmpty()) {
                int[] cur = q.poll();
                for (int[] dir : dirs) {
                    int nx = cur[0] + dir[0], ny = cur[1] + dir[1];
                    if (nx >= 0 && nx < 50 && ny >= 0 && ny < 50 && d[nx * 50 + ny] == -1) {
                        d[nx * 50 + ny] = d[cur[0] * 50 + cur[1]] + 1;
                        q.offer(new int[]{nx, ny});
                    }
                }
            }
            for (int j = 0; j < n; j++) {
                dist[i][j] = d[positions[j][0] * 50 + positions[j][1]];
            }
        }

        memo = new int[1 << n][n + 1];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dp(0, n);
    }

    private int dp(int mask, int last) {
        if (mask == (1 << n) - 1) return 0;
        if (memo[mask][last] != -1) return memo[mask][last];
        int captured = Integer.bitCount(mask);
        boolean isAlice = (captured % 2 == 0);
        int best = isAlice ? 0 : Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) continue;
            int result = 1 + dp(mask | (1 << i), i);
            if (isAlice) best = Math.max(best, result);
            else         best = Math.min(best, result);
        }
        memo[mask][last] = best;
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × 50² + n² × 2^n)，BFS 预计算 + DP
- 空间复杂度：O(n × 2^n)

## 关键点总结

1. BFS 预计算骑士移动距离，骑士在 50×50 棋盘上最多 2500 个格子
2. 已捕获兵数的奇偶性决定谁在行动（Alice 偶数轮，Bob 奇数轮）
3. Bob 只移除兵不捕获，所以只影响后续可选目标集合
