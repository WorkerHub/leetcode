## 题目描述

为搜索引擎设计自动补全系统，每输入一个字符返回热度前 3 的匹配句子。

**示例：**
```
输入 'i' → ["i love you", "island", "i love leetcode"]
输入 '#' → 保存句子，返回 []
```

## 解题思路

哈希表存储句子频率，每次输入时查找以当前前缀开头的句子，排序返回前 3。

## Java 代码实现

```java
class AutocompleteSystem {
    private Map<String, Integer> freq;
    private StringBuilder curInput;

    public AutocompleteSystem(String[] sentences, int[] times) {
        freq = new HashMap<>();
        curInput = new StringBuilder();
        for (int i = 0; i < sentences.length; i++) {
            freq.put(sentences[i], times[i]);
        }
    }

    public List<String> input(char c) {
        if (c == '#') {
            // 保存当前输入
            String sentence = curInput.toString();
            freq.put(sentence, freq.getOrDefault(sentence, 0) + 1);
            curInput = new StringBuilder();
            return new ArrayList<>();
        }

        curInput.append(c);
        String prefix = curInput.toString();

        // 查找匹配的句子
        List<Map.Entry<String, Integer>> matches = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : freq.entrySet()) {
            if (entry.getKey().startsWith(prefix)) {
                matches.add(entry);
            }
        }

        // 按热度降序，相同热度按字典序
        matches.sort((a, b) -> {
            if (!a.getValue().equals(b.getValue())) {
                return b.getValue() - a.getValue();
            }
            return a.getKey().compareTo(b.getKey());
        });

        List<String> result = new ArrayList<>();
        for (int i = 0; i < Math.min(3, matches.size()); i++) {
            result.add(matches.get(i).getKey());
        }
        return result;
    }
}
```

## 复杂度分析

- **input**：O(n log n)，n 为句子总数
- **空间复杂度**：O(m)，m 为所有句子的总字符数

## 关键点总结

1. **HashMap 存频率**：方便增减和查询
2. **排序规则**：先按热度降序，再按字典序升序
3. **'#' 结束输入**：保存当前句子
