## 题目描述

给定一个二叉树，判断它是否是高度平衡的二叉树。

本题中，一棵高度平衡二叉树定义为：一个二叉树每个节点的左右两个子树的高度差的绝对值不超过 1。

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：true
```

**示例 2：**

```
输入：root = [1,2,2,3,3,null,null,4,4]
输出：false
```

**示例 3：**

```
输入：root = []
输出：true
```

**提示：**

- 树中的节点数在范围 `[0, 5000]` 内
- `-10^4 <= Node.val <= 10^4`

## 解题思路

这道题要判断一棵树是否平衡，需要理解平衡二叉树的定义：

**平衡二叉树的条件**（必须同时满足）：
1. 左子树是平衡二叉树
2. 右子树是平衡二叉树
3. 左右子树的高度差不超过 1

### 核心思路

**方法一：自顶向下（暴力法）**
- 对每个节点，分别计算左右子树的高度
- 检查高度差是否 ≤ 1
- 递归检查左右子树是否平衡
- 时间复杂度：O(n²)，因为每个节点都要重复计算高度

**方法二：自底向上（优化）**
- 后序遍历（左-右-根）
- 在计算高度的同时判断是否平衡
- 如果发现不平衡，立即返回特殊值（如 -1）剪枝
- 时间复杂度：O(n)，每个节点只访问一次

## Java 代码实现

### 方法一：自顶向下（易理解）

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        // 空树是平衡的
        if (root == null) return true;

        // 检查三个条件：
        // 1. 左子树平衡
        // 2. 右子树平衡
        // 3. 左右子树高度差 <= 1
        return isBalanced(root.left)
            && isBalanced(root.right)
            && Math.abs(height(root.left) - height(root.right)) <= 1;
    }

    // 计算树的高度
    private int height(TreeNode node) {
        if (node == null) return 0;
        return Math.max(height(node.left), height(node.right)) + 1;
    }
}
```

### 方法二：自底向上（推荐）⭐

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        // 返回高度不为 -1 表示树是平衡的
        return height(root) != -1;
    }

    /**
     * 计算节点高度，如果不平衡则返回 -1
     * 返回值：
     *   -1: 表示子树不平衡
     *   >= 0: 表示子树平衡，返回高度
     */
    private int height(TreeNode node) {
        // 空节点高度为 0
        if (node == null) return 0;

        // 递归计算左子树高度
        int leftHeight = height(node.left);
        if (leftHeight == -1) return -1;  // 左子树不平衡，直接返回

        // 递归计算右子树高度
        int rightHeight = height(node.right);
        if (rightHeight == -1) return -1;  // 右子树不平衡，直接返回

        // 检查当前节点是否平衡
        if (Math.abs(leftHeight - rightHeight) > 1) return -1;

        // 返回当前节点的高度
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

### 方法三：自底向上（返回包装类）

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        return check(root)[0] == 1;
    }

    /**
     * 返回 int[]{isBalanced, height}
     * isBalanced: 1 表示平衡，0 表示不平衡
     */
    private int[] check(TreeNode node) {
        // 空节点：平衡，高度为 0
        if (node == null) return new int[]{1, 0};

        // 检查左子树
        int[] left = check(node.left);
        if (left[0] == 0) return new int[]{0, 0};

        // 检查右子树
        int[] right = check(node.right);
        if (right[0] == 0) return new int[]{0, 0};

        // 检查当前节点
        if (Math.abs(left[1] - right[1]) > 1) return new int[]{0, 0};

        int height = Math.max(left[1], right[1]) + 1;
        return new int[]{1, height};
    }
}
```

### 方法四：使用成员变量标记

```java
class Solution {
    private boolean balanced = true;  // 标记是否平衡

    public boolean isBalanced(TreeNode root) {
        height(root);
        return balanced;
    }

    private int height(TreeNode node) {
        if (node == null || !balanced) return 0;

        int leftHeight = height(node.left);
        int rightHeight = height(node.right);

        // 检查当前节点是否平衡
        if (Math.abs(leftHeight - rightHeight) > 1) {
            balanced = false;
        }

        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

## 复杂度分析

### 方法一：自顶向下

- **时间复杂度**：O(n²)
  - 每个节点都要调用 height 函数
  - height 函数需要遍历子树的所有节点
  - 最坏情况下（链式树），复杂度为 O(n²)
- **空间复杂度**：O(n)，递归调用栈，最坏情况下为树的高度

### 方法二、三、四：自底向上

- **时间复杂度**：O(n)，每个节点只访问一次
- **空间复杂度**：O(n)，递归调用栈，最坏情况下为树的高度

## 图解示例

### 示例 1：平衡树

```
      3
     / \
    9   20
       /  \
      15   7

节点 3：
  左子树（9）高度 = 1
  右子树（20）高度 = 2
  高度差 = |1 - 2| = 1 ≤ 1 ✓

节点 9：
  左子树高度 = 0
  右子树高度 = 0
  高度差 = 0 ≤ 1 ✓

节点 20：
  左子树（15）高度 = 1
  右子树（7）高度 = 1
  高度差 = 0 ≤ 1 ✓

结论：平衡 ✓
```

### 示例 2：不平衡树

```
        1
       / \
      2   2
     / \
    3   3
   / \
  4   4

节点 1：
  左子树高度 = 3
  右子树高度 = 1
  高度差 = |3 - 1| = 2 > 1 ✗

结论：不平衡 ✗
```

### 方法二执行流程

```
      3
     / \
    9   20
       /  \
      15   7

后序遍历（左-右-根）：

1. 访问节点 9
   左高度 = 0, 右高度 = 0
   高度差 = 0 ✓
   返回高度 1

2. 访问节点 15
   返回高度 1

3. 访问节点 7
   返回高度 1

4. 访问节点 20
   左高度 = 1, 右高度 = 1
   高度差 = 0 ✓
   返回高度 2

5. 访问节点 3
   左高度 = 1, 右高度 = 2
   高度差 = 1 ✓
   返回高度 3
```

## 关键点总结

1. **理解平衡定义**：每个节点的左右子树高度差不超过 1
2. **自底向上优化**：边计算高度边判断，避免重复计算
3. **剪枝策略**：发现不平衡立即返回 -1，不再继续计算
4. **后序遍历**：必须先知道子树信息才能判断当前节点
5. **高度计算**：空节点高度为 0，非空节点高度为 max(左, 右) + 1

## 易错点

1. **高度定义混淆**：
   - 高度：从节点到叶子的最长路径
   - 深度：从根到节点的路径长度
   - 空节点高度为 0
2. **平衡条件不完整**：不仅要检查当前节点，还要确保左右子树也平衡
3. **重复计算**：方法一每次都重新计算高度，效率低
4. **边界条件**：空树是平衡的，要返回 true
5. **剪枝遗漏**：方法二中如果左子树已经不平衡，应立即返回 -1
