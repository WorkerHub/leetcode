## 题目描述

给定两个字符串 `s1` 和 `s2`，返回使两个字符串相同所需删除字符的 ASCII 值的最小和。

**示例 1：**

```
输入：s1 = "sea", s2 = "eat"
输出：231
解释：在 "sea" 中删除 "s" 的 ASCII 值为 115。
在 "eat" 中删除 "t" 的 ASCII 值为 116。
结束时，两个字符串都等于 "ea"，答案为 115 + 116 = 231。
```

**示例 2：**

```
输入：s1 = "delete", s2 = "leet"
输出：403
解释：在 "delete" 中删除 "dee" 和在 "leet" 中删除 "e"，最终两个字符串都等于 "let"。
删除的字符的 ASCII 值总和为 100[d] + 101[e] + 101[e] + 101[e] = 403。
```

**提示：**
- `0 <= s1.length, s2.length <= 1000`
- `s1` 和 `s2` 由小写英文字母组成

## 解题思路

这是一道经典的动态规划问题，类似于最长公共子序列（LCS），但优化目标不同。

**核心思想：**
- 保留公共部分，删除不同部分
- 最小化删除字符的 ASCII 值总和
- 等价于最大化保留字符的 ASCII 值总和

**动态规划定义：**
- `dp[i][j]`：使 `s1[0:i]` 和 `s2[0:j]` 相同所需删除的最小 ASCII 值和

**状态转移：**
1. 如果 `s1[i-1] == s2[j-1]`：
   - 不需要删除，`dp[i][j] = dp[i-1][j-1]`
   
2. 如果 `s1[i-1] != s2[j-1]`：
   - 删除 `s1[i-1]`：`dp[i-1][j] + s1.charAt(i-1)`
   - 删除 `s2[j-1]`：`dp[i][j-1] + s2.charAt(j-1)`
   - 取两者最小值

**边界条件：**
- `dp[0][j]`：s1 为空，需要删除 s2 的所有字符
- `dp[i][0]`：s2 为空，需要删除 s1 的所有字符

## Java 代码实现

### 方法一：二维 DP（推荐）⭐

```java
class Solution {
    public int minimumDeleteSum(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        
        // 创建 DP 表
        int[][] dp = new int[m + 1][n + 1];
        
        // 初始化边界
        // dp[0][j]: s1 为空，需要删除 s2 的所有字符
        for (int j = 1; j <= n; j++) {
            dp[0][j] = dp[0][j - 1] + s2.charAt(j - 1);
        }
        
        // dp[i][0]: s2 为空，需要删除 s1 的所有字符
        for (int i = 1; i <= m; i++) {
            dp[i][0] = dp[i - 1][0] + s1.charAt(i - 1);
        }
        
        // 填充 DP 表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    // 字符相同，不需要删除
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 字符不同，选择删除 s1[i-1] 或 s2[j-1]
                    dp[i][j] = Math.min(
                        dp[i - 1][j] + s1.charAt(i - 1),  // 删除 s1[i-1]
                        dp[i][j - 1] + s2.charAt(j - 1)   // 删除 s2[j-1]
                    );
                }
            }
        }
        
        return dp[m][n];
    }
}
```

### 方法二：空间优化（一维 DP）

```java
class Solution {
    public int minimumDeleteSum(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        
        // 使用一维数组，长度为 n + 1
        int[] dp = new int[n + 1];
        
        // 初始化：s1 为空的情况
        for (int j = 1; j <= n; j++) {
            dp[j] = dp[j - 1] + s2.charAt(j - 1);
        }
        
        // 逐行更新
        for (int i = 1; i <= m; i++) {
            // prev 保存左上角的值（dp[i-1][j-1]）
            int prev = dp[0];
            // 更新 dp[0]（s2 为空的情况）
            dp[0] = dp[0] + s1.charAt(i - 1);
            
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 保存当前值，下次迭代作为左上角
                
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[j] = prev;
                } else {
                    dp[j] = Math.min(
                        dp[j] + s1.charAt(i - 1),     // 删除 s1[i-1]
                        dp[j - 1] + s2.charAt(j - 1)  // 删除 s2[j-1]
                    );
                }
                
                prev = temp;
            }
        }
        
        return dp[n];
    }
}
```

## 复杂度分析

### 二维 DP：
- **时间复杂度：** O(m × n)，填充 DP 表
- **空间复杂度：** O(m × n)

### 一维 DP：
- **时间复杂度：** O(m × n)
- **空间复杂度：** O(n)

## 关键点总结

1. **DP 定义**：明确 `dp[i][j]` 的含义，注意索引对应关系
2. **状态转移**：字符相同不删除，不同则选择删除代价小的
3. **边界处理**：一个字符串为空时，需删除另一个字符串的所有字符
4. **ASCII 值**：Java 中 `char` 可以直接参与数值运算
5. **空间优化**：可以使用滚动数组将空间优化到 O(n)

## 易错点

1. **索引错位**：`dp[i][j]` 对应 `s1.charAt(i-1)` 和 `s2.charAt(j-1)`
2. **边界初始化**：忘记初始化 `dp[0][j]` 和 `dp[i][0]`
3. **字符比较**：注意是 `s1.charAt(i-1)` 和 `s2.charAt(j-1)` 比较
4. **空间优化时的变量保存**：需要正确保存左上角的值
5. **ASCII 值计算**：Java 中 char 可直接参与加法运算
