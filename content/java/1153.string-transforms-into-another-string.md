## 题目描述

给定两个等长字符串 str1 和 str2，判断能否通过若干次转换将 str1 变为 str2。每次转换将 str1 中所有某字符替换为另一个小写字母。

**示例：**
```
输入: str1 = "aabcc", str2 = "ccdee"
输出: true（c→e, b→d, a→c）
```

## 解题思路

1. 映射一致性：str1 中同一字符必须映射到 str2 中同一字符
2. 临时字符：如果存在循环映射，需要临时字符打破循环
3. 关键判断：若 str2 使用了全部 26 个字母且 str1 != str2，则无临时字符可用，返回 false

## Java 代码实现

```java
class Solution {
    public boolean canConvert(String str1, String str2) {
        if (str1.equals(str2)) return true;

        // 建立 str1 到 str2 的字符映射
        Map<Character, Character> mapping = new HashMap<>();
        for (int i = 0; i < str1.length(); i++) {
            char c1 = str1.charAt(i), c2 = str2.charAt(i);
            if (mapping.containsKey(c1)) {
                // 同一字符映射到不同目标，无法转换
                if (mapping.get(c1) != c2) return false;
            } else {
                mapping.put(c1, c2);
            }
        }

        // str2 使用了全部 26 个字母则无临时字符可用
        Set<Character> chars = new HashSet<>();
        for (char c : str2.toCharArray()) chars.add(c);
        return chars.size() < 26;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，最多 26 个映射

## 关键点总结

1. **映射一致性**：一个字符只能映射到一个目标
2. **str1 == str2**：直接返回 true
3. **26 字母检查**：str2 用满 26 字母时无法打破循环
4. **多对一允许**：多个字符可以映射到同一目标
