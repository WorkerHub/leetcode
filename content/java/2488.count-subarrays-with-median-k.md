## 题目描述

给你包含 1 到 n 所有整数的数组 `nums` 和整数 `k`，返回中位数恰好为 `k` 的子数组数目。

## 解题思路

找到 k 的位置 `pos`。将每个元素转化为 +1（大于 k）、-1（小于 k）、0（等于 k），则含 k 的子数组中位数为 k 当且仅当前缀和差值（balance）为 0（奇数长度）或 1（偶数长度）。用哈希表记录 `[0, pos]` 的前缀和频次，枚举右边界查询。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countSubarrays(int[] nums, int k) {
        int n = nums.length, pos = -1;
        for (int i = 0; i < n; i++) if (nums[i] == k) { pos = i; break; }

        // 统计 [0, pos] 的前缀和频次
        Map<Integer, Integer> freq = new HashMap<>();
        int preSum = 0;
        freq.put(0, 1);
        for (int i = 0; i < pos; i++) {
            preSum += nums[i] > k ? 1 : -1;
            freq.merge(preSum, 1, Integer::sum);
        }

        // 枚举右边界 r（从 pos 到 n-1）
        int ans = 0;
        preSum = 0;
        for (int r = pos; r < n; r++) {
            preSum += nums[r] > k ? 1 : (nums[r] < k ? -1 : 0);
            // balance=0 或 1 时中位数为 k
            ans += freq.getOrDefault(preSum, 0);
            ans += freq.getOrDefault(preSum - 1, 0);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 子数组必须包含 k，转化为 +1/-1 后统计 balance
2. balance=0 对应奇数长度，balance=1 对应偶数长度（偶数时取较小中位数）
3. 哈希表预存左侧前缀和，右侧扩展时查询
