## 题目描述

给你字符串 `s` 和整数 `k`，返回 `s` 中至少有一个字符出现次数 >= `k` 的子字符串数目。

## 解题思路

枚举每个左端点 `i`，向右扩展右端点 `j`，一旦某字符频率达到 `k`，则从 `j` 到 `n-1` 的所有右端点都满足，直接加 `n - j` 并 break。利用提前退出降低常数，O(n^2) 对 n <= 3000 可通过。

## Java 代码实现

```java
class Solution {
    public int numberOfSubstrings(String s, int k) {
        int n = s.length(), ans = 0;
        for (int i = 0; i < n; i++) {
            int[] freq = new int[26];
            for (int j = i; j < n; j++) {
                freq[s.charAt(j) - 'a']++;
                if (freq[s.charAt(j) - 'a'] >= k) {
                    // s[i..j] 及更长的子串都满足，直接累计
                    ans += n - j;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，双重循环，提前退出
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 固定左端点，向右找第一个满足条件的右端点 j，则 j 到 n-1 均满足，加 `n - j`
2. 提前 break 避免不必要计算，实际运行远快于理论上界
3. n <= 3000 时 O(n^2) 完全可行
