## 题目描述

给定整数数组 `nums`，找最左边的中间位置下标，使该下标左侧所有元素之和等于右侧所有元素之和，不存在返回 -1。

## 解题思路

计算总和 `total`，从左向右扫描维护左侧前缀和 `leftSum`，判断 `leftSum == total - leftSum - nums[i]` 即可。

## Java 代码实现

### 方法一：前缀和（推荐）

```java
class Solution {
    public int findMiddleIndex(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;

        int leftSum = 0;
        for (int i = 0; i < nums.length; i++) {
            // 右侧和 = total - leftSum - nums[i]
            if (leftSum == total - leftSum - nums[i]) {
                return i;
            }
            leftSum += nums[i];
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 条件等价于 `2 * leftSum + nums[i] == total`
2. 先判断再更新 `leftSum`，顺序不能错
