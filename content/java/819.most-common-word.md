## 题目描述

给定一个段落 `paragraph` 和一个禁用单词列表 `banned`。返回出现次数最多的非禁用单词。

题目保证至少有一个非禁用单词，且答案唯一。

段落中的单词 **不区分大小写**，答案应以 **小写** 形式返回。

**示例:**
```
输入: paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
输出: "ball"
```

**提示:**
- `1 <= paragraph.length <= 1000`
- `paragraph` 由小写英文字母、空格和符号 `!?',;.` 组成
- `0 <= banned.length <= 100`
- `1 <= banned[i].length <= 10`
- `banned[i]` 仅由小写英文字母组成

## 解题思路

1. 将段落转为小写，提取所有单词
2. 统计非禁用单词的频率
3. 返回频率最高的单词

## Java 代码实现

### 方法一：字符处理（推荐）

```java
import java.util.*;

class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        // 禁用词集合
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));

        // 提取所有单词（转为小写）
        Map<String, Integer> count = new HashMap<>();
        int n = paragraph.length();
        int i = 0;

        while (i < n) {
            // 跳过非字母字符
            while (i < n && !Character.isLetter(paragraph.charAt(i))) {
                i++;
            }

            if (i >= n) break;

            // 提取一个单词
            StringBuilder sb = new StringBuilder();
            while (i < n && Character.isLetter(paragraph.charAt(i))) {
                sb.append(Character.toLowerCase(paragraph.charAt(i)));
                i++;
            }

            String word = sb.toString();
            if (!bannedSet.contains(word)) {
                count.put(word, count.getOrDefault(word, 0) + 1);
            }
        }

        // 找频率最高的词
        String result = "";
        int maxCount = 0;
        for (Map.Entry<String, Integer> entry : count.entrySet()) {
            if (entry.getValue() > maxCount) {
                maxCount = entry.getValue();
                result = entry.getKey();
            }
        }

        return result;
    }
}
```

### 方法二：正则表达式分割

```java
import java.util.*;

class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));

        // 替换标点为空格，转为小写，分割
        String[] words = paragraph.toLowerCase().split("[^a-z]+");

        Map<String, Integer> count = new HashMap<>();
        for (String word : words) {
            if (!word.isEmpty() && !bannedSet.contains(word)) {
                count.put(word, count.getOrDefault(word, 0) + 1);
            }
        }

        return Collections.max(count.entrySet(), Map.Entry.comparingByValue()).getKey();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 是段落长度，m 是禁用词长度
- **空间复杂度**：O(n)

## 关键点总结

1. **大小写转换**：统一转为小写处理
2. **集合查找**：禁用词用 Set 存储，O(1) 查找
3. **字符分类**：使用 Character.isLetter 判断字母
4. **频率统计**：HashMap 统计单词频率

## 易错点

1. **大小写**：必须转为小写
2. **标点符号**：需要正确处理非字母字符
3. **禁用词检查**：不要统计禁用词
