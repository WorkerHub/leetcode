## 题目描述

替换最少元素使数组变为非递减或非递增。

## 解题思路

最少操作=n-最长非递减子序列长度。分别对非递减和非递增求LIS（允许等号用bisect_right），取最小操作数。

## Java 代码实现

```java
class Solution {
    public int convertArray(int[] nums) {
        int n = nums.length;
        // 非递减：n - 最长非递减子序列
        int nonDec = n - lisNonDecreasing(nums);
        // 非递增：反转后求非递减
        int[] rev = new int[n];
        for (int i = 0; i < n; i++) rev[i] = nums[n - 1 - i];
        int nonInc = n - lisNonDecreasing(rev);
        return Math.min(nonDec, nonInc);
    }

    // 最长非递减子序列长度（允许等号）
    private int lisNonDecreasing(int[] arr) {
        List<Integer> tails = new ArrayList<>();
        for (int x : arr) {
            // 找第一个>x的位置（upper_bound）
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails.get(mid) <= x) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) tails.add(x);
            else tails.set(lo, x);
        }
        return tails.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **问题转化**：最少操作=n-最长合法子序列
2. **非递减用upper_bound**：允许相等元素
3. **非递增=反转后非递减**
