## 题目描述

给定有序不重叠区间列表和待删除区间 toBeRemoved，返回删除后剩余的区间列表。

**示例：**
```
输入：intervals = [[0,2],[3,4],[5,7]], toBeRemoved = [1,6]
输出：[[0,1],[6,7]]
```

## 解题思路

遍历每个区间，与 toBeRemoved 比较：无交集则保留，部分重叠则保留不重叠部分，完全包含则删除。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> removeInterval(int[][] intervals, int[] toBeRemoved) {
        List<List<Integer>> result = new ArrayList<>();
        int c = toBeRemoved[0], d = toBeRemoved[1];
        
        for (int[] interval : intervals) {
            int a = interval[0], b = interval[1];
            // 无交集：完全在左边或右边
            if (b <= c || a >= d) {
                result.add(Arrays.asList(a, b));
            } else {
                // 左侧剩余
                if (a < c) result.add(Arrays.asList(a, c));
                // 右侧剩余
                if (b > d) result.add(Arrays.asList(d, b));
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **三种情况**：无交集、部分重叠、完全包含
2. **左右剩余**：分别判断左端和右端是否超出删除区间
3. **一次遍历**：O(n) 完成
