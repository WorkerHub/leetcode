## 题目描述

给定整数数组 `nums`，从下标 `0` 出发，每次可从位置 `i` 跳到 `i + nums[i]` 或 `i - nums[i]`（合法下标内）。求到达最后下标 `n-1` 的最少跳跃次数，不可达返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minJumps(int[] nums) {
        int n = nums.length;
        if (n == 1) return 0;

        boolean[] visited = new boolean[n];
        visited[0] = true;
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0);
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                int i = queue.poll();
                for (int nxt : new int[]{i + nums[i], i - nums[i]}) {
                    if (nxt == n - 1) return steps;
                    if (nxt >= 0 && nxt < n && !visited[nxt]) {
                        visited[nxt] = true;
                        queue.offer(nxt);
                    }
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，BFS 每个节点访问一次
- 空间复杂度：O(n)，visited 数组和队列

## 关键点总结

1. BFS 自然求最短路，适合无权图的最少步数问题
2. 每个节点最多访问一次，用 visited 数组防止重复
3. 每步可以跳正负两个方向，注意边界检查
