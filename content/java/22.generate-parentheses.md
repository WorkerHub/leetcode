## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

**示例 1：**
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2：**
```
输入：n = 1
输出：["()"]
```

**提示：**
- `1 <= n <= 8`

## 解题思路

核心思想：回溯生成所有有效组合

**关键规则：**
1. 左括号数量不超过 n
2. 右括号数量不超过左括号数量

## Java 代码实现

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(result, new StringBuilder(), 0, 0, n);
        return result;
    }

    private void backtrack(List<String> result, StringBuilder path, int left, int right, int n) {
        // 生成完成
        if (path.length() == 2 * n) {
            result.add(path.toString());
            return;
        }

        // 可以添加左括号
        if (left < n) {
            path.append('(');
            backtrack(result, path, left + 1, right, n);
            path.deleteCharAt(path.length() - 1); // 回溯
        }

        // 可以添加右括号
        if (right < left) {
            path.append(')');
            backtrack(result, path, left, right + 1, n);
            path.deleteCharAt(path.length() - 1); // 回溯
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(4^n / √n)，卡特兰数
- 空间复杂度：O(n)

## 关键点总结

1. **左括号条件**：left < n
2. **右括号条件**：right < left
3. **终止条件**：长度为 2n
4. **回溯**：使用 StringBuilder 并在回退时删除最后一个字符

## 易错点

1. **右括号条件**：必须 right < left
2. **回溯操作**：Java 中用 `deleteCharAt(path.length() - 1)` 回退
