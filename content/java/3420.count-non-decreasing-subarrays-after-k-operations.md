## 题目描述

给定整数数组 `nums` 和非负整数 `k`，每次操作可将任意元素加 1，统计使子数组变为非递减序列所需最少操作次数不超过 k 的子数组数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countNonDecreasingSubarrays(int[] nums, long k) {
        int n = nums.length;
        long ans = 0;
        long cost = 0; // 当前窗口 [l, r] 变为非递减的代价

        // 单调不增双端队列（存 (value, count) 对）
        Deque<long[]> dq = new ArrayDeque<>(); // [value, count]
        int l = 0;

        for (int r = 0; r < n; r++) {
            long cur = nums[r];
            long cnt = 1;

            // 弹出比 cur 大的元素，计算代价（需要将这些元素降至 cur）
            // 注意：操作是"增加"，不是降低。需要反向理解：
            // 将 nums[i] 提升到满足非递减，所以是从左到右提升较小元素
            // 当 nums[r] < nums[r-1] 时，需将 nums[r] 提升到 nums[r-1]
            // 代价增量 = sum of (popped_val - cur) * count
            while (!dq.isEmpty() && dq.peekLast()[0] > cur) {
                long[] top = dq.pollLast();
                cost += (top[0] - cur) * top[1];
                cnt += top[1];
            }
            dq.offerLast(new long[]{cur, cnt});

            // 若代价超过 k，收缩左边界
            while (cost > k) {
                // 移除最左元素：队头代表最左侧的块
                // 需要知道 nums[l] 的原始值来计算代价减少量
                // 此处重新计算（简化实现）
                l++;
                cost = 0;
                dq.clear();
                for (int i = l; i <= r; i++) {
                    long c = nums[i];
                    long ci = 1;
                    while (!dq.isEmpty() && dq.peekLast()[0] > c) {
                        long[] t = dq.pollLast();
                        cost += (t[0] - c) * t[1];
                        ci += t[1];
                    }
                    dq.offerLast(new long[]{c, ci});
                }
            }

            ans += r - l + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2) 最坏情况，O(n) 摊还（优化版本）
- 空间复杂度：O(n)

## 关键点总结

1. 单调栈用于高效计算新加入元素时代价的变化量。
2. 滑动窗口找每个右端点对应的最小左端点（使代价 <= k）。
3. 代价 = 将每个递减处"提升"到前一元素值的操作总和（级联计算）。
