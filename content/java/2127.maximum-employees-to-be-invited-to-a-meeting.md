## 题目描述

n名员工各有一个最喜欢的人，圆桌会议要求每人坐在喜欢的人旁边。求最多能邀请多少人。

## 解题思路

功能图分析：每个分量有一个环。环>=3时只能用环本身取最大；环==2时（互相喜欢）可延伸入链，所有长度2的环可叠加。答案=max(最大环, 所有哑铃链之和)。

## Java 代码实现

```java
class Solution {
    public int maximumInvitations(int[] favorite) {
        int n = favorite.length;
        int[] inDegree = new int[n];
        for (int f : favorite) inDegree[f]++;
        
        // 拓扑排序剥离链，计算每个节点的最长入链
        int[] depth = new int[n];
        Arrays.fill(depth, 1);
        boolean[] onCycle = new boolean[n];
        Arrays.fill(onCycle, true);
        
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }
        
        while (!queue.isEmpty()) {
            int u = queue.poll();
            onCycle[u] = false;
            int v = favorite[u];
            inDegree[v]--;
            depth[v] = Math.max(depth[v], depth[u] + 1);
            if (inDegree[v] == 0) queue.offer(v);
        }
        
        int maxCycle = 0; // 环>=3的最大长度
        int chainSum = 0; // 环==2的所有哑铃链长之和
        boolean[] visited = new boolean[n];
        
        for (int i = 0; i < n; i++) {
            if (onCycle[i] && !visited[i]) {
                int cycleLen = 0;
                int cur = i;
                while (!visited[cur]) {
                    visited[cur] = true;
                    cur = favorite[cur];
                    cycleLen++;
                }
                if (cycleLen == 2) {
                    chainSum += depth[i] + depth[favorite[i]];
                } else {
                    maxCycle = Math.max(maxCycle, cycleLen);
                }
            }
        }
        return Math.max(maxCycle, chainSum);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **功能图**：每个分量恰有一个环
2. **环>=3**：只能整体参会，取最大
3. **环==2**：可延伸入链且多个可叠加
