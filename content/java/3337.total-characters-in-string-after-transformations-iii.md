## 题目描述

与 3336 相同的转换规则，但 `t` 可达 10^15。给你字符串 `s`、整数 `t` 和长度为 26 的数组 `nums`，返回 `t` 次转换后字符串长度（模 10^9+7）。

## 解题思路

与 3336 完全相同的矩阵快速幂方法。26x26 转移矩阵，O(26^3 log t) 复杂度，即使 t=10^15 也能在 O(26^3 * 50) ≈ 90 万次操作内完成。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int lengthAfterTransformations(String s, long t, List<Integer> nums) {
        long[][] M = new long[26][26];
        for (int i = 0; i < 26; i++)
            for (int k = 1; k <= nums.get(i); k++)
                M[(i + k) % 26][i]++;

        long[][] Mt = matPow(M, t);

        long[] cnt = new long[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        long ans = 0;
        for (int j = 0; j < 26; j++) {
            long val = 0;
            for (int i = 0; i < 26; i++) val = (val + Mt[j][i] * cnt[i]) % MOD;
            ans = (ans + val) % MOD;
        }
        return (int) ans;
    }

    private long[][] matMul(long[][] A, long[][] B) {
        long[][] C = new long[26][26];
        for (int i = 0; i < 26; i++)
            for (int k = 0; k < 26; k++) {
                if (A[i][k] == 0) continue;
                for (int j = 0; j < 26; j++)
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
            }
        return C;
    }

    private long[][] matPow(long[][] M, long p) {
        long[][] R = new long[26][26];
        for (int i = 0; i < 26; i++) R[i][i] = 1;
        while (p > 0) {
            if ((p & 1) == 1) R = matMul(R, M);
            M = matMul(M, M);
            p >>= 1;
        }
        return R;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26^3 * log t + |s|)，即使 t=10^15 也约 90 万次操作
- 空间复杂度：O(26^2)

## 关键点总结

1. 矩阵快速幂处理极大 t（10^15），时间复杂度 O(26^3 * log t)
2. 转移矩阵 M[j][i] 统计字符 i 转换后贡献给字符 j 的次数
3. 所有计算对 MOD 取模防止溢出
