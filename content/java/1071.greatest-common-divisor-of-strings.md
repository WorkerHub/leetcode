## 题目描述

给定两个字符串 `str1` 和 `str2`，返回最长的字符串 `X`，使得 `X` 能够同时整除 `str1` 和 `str2`。

**示例：**
```
输入：str1 = "ABCABC", str2 = "ABC"
输出："ABC"
```

## 解题思路

GCD + 字符串拼接验证：若 str1+str2 != str2+str1 则无解；否则答案为 str1 前 gcd(len1, len2) 个字符。

## Java 代码实现

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        // 如果存在公共整除字符串，拼接顺序不影响结果
        if (!(str1 + str2).equals(str2 + str1)) {
            return "";
        }
        // 答案长度为两字符串长度的最大公约数
        int gcdLen = gcd(str1.length(), str2.length());
        return str1.substring(0, gcdLen);
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)，拼接字符串

## 关键点总结

1. **拼接验证**：str1+str2 == str2+str1 是存在公共整除字符串的充要条件
2. **GCD 性质**：公共整除字符串长度必为两串长度的最大公约数
3. **数学转化**：字符串整除问题转化为长度的 GCD 问题
