## 题目描述

给你一个整数数组 `nums` 和整数 `k`，可以将数组中任意 k 个元素取反（乘以 -1）。返回操作后的最大子数组乘积（对 `10^9 + 7` 取模）。

## 解题思路

DP：`dpMax[j]` 和 `dpMin[j]` 分别表示用了 j 次取反、以当前元素结尾的最大和最小乘积。对每个元素枚举取反或不取反两种情况，同时维护"重新开始"选项。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxProduct(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        final long INF = Long.MAX_VALUE / 2;
        long[] dpMax = new long[k + 1], dpMin = new long[k + 1];
        Arrays.fill(dpMax, -INF);
        Arrays.fill(dpMin, INF);
        long ans = Long.MIN_VALUE;

        for (int x : nums) {
            long[] newMax = new long[k + 1], newMin = new long[k + 1];
            Arrays.fill(newMax, -INF);
            Arrays.fill(newMin, INF);

            for (int j = 0; j <= k; j++) {
                // 不取反x
                if (dpMax[j] != -INF) {
                    newMax[j] = Math.max(newMax[j], dpMax[j] * x);
                    newMin[j] = Math.min(newMin[j], dpMin[j] * x);
                }
                // 重新开始
                newMax[j] = Math.max(newMax[j], x);
                newMin[j] = Math.min(newMin[j], x);
                // 取反x（j+1次）
                if (j + 1 <= k) {
                    long nx = -x;
                    if (dpMax[j] != -INF) {
                        newMax[j+1] = Math.max(newMax[j+1], dpMax[j] * nx);
                        newMin[j+1] = Math.min(newMin[j+1], dpMin[j] * nx);
                    }
                    newMax[j+1] = Math.max(newMax[j+1], nx);
                    newMin[j+1] = Math.min(newMin[j+1], nx);
                }
                if (newMax[j] != -INF) ans = Math.max(ans, newMax[j]);
            }
            dpMax = newMax; dpMin = newMin;
        }
        return (int)(ans % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 同时维护最大和最小乘积（负负得正）
2. 取反在 DP 中通过增加取反计数处理
3. 每个位置允许重新开始子数组
