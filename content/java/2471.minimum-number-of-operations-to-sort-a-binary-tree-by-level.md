## 题目描述

给你二叉树根节点 `root`，每次操作可交换同一层的两个节点值，返回将每层节点值排成升序所需的最少操作次数。

## 解题思路

BFS 逐层收集节点值，对每层用置换环法计算最少交换次数：最少交换数 = 元素总数 - 置换环数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumOperations(TreeNode root) {
        int ans = 0;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            int[] vals = new int[size];
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                vals[i] = node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            ans += minSwaps(vals);
        }
        return ans;
    }

    private int minSwaps(int[] arr) {
        int n = arr.length;
        // 将排序后位置映射到当前位置
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> arr[a] - arr[b]);

        // perm[i] = 当前第 i 个位置的元素在排序后应去的位置
        int[] perm = new int[n];
        for (int i = 0; i < n; i++) perm[idx[i]] = i;

        boolean[] visited = new boolean[n];
        int cycles = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                cycles++;
                int j = i;
                while (!visited[j]) {
                    visited[j] = true;
                    j = perm[j];
                }
            }
        }
        return n - cycles;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. BFS 逐层收集节点值，对每层独立计算最少交换次数
2. 最少交换数 = 元素总数 - 置换环数
3. 长度为 k 的置换环需要 k-1 次交换
