## 题目描述

给定编号从 `0` 到 `n-1` 的 `n` 个节点和一个无向边列表（每条边都是一对节点），判断这些边是否能够形成一个有效的树。

树的定义：
- 包含 n 个节点的连通图
- 恰好有 n-1 条边
- 无环

**示例 1：**
```
输入: n = 5, edges = [[0,1], [0,2], [0,3], [1,4]]
输出: true
```

**示例 2：**
```
输入: n = 5, edges = [[0,1], [1,2], [2,3], [1,3], [1,4]]
输出: false
```

**提示：**
- `1 <= n <= 2000`
- `0 <= edges.length <= 5000`
- `edges[i].length == 2`
- `0 <= ai, bi < n`
- `ai != bi`
- 不存在重复的边

## 解题思路

判断一个无向图是否为树，需要满足两个条件：

1. **连通性**：所有节点都连通
2. **无环性**：图中没有环

根据树的性质，还可以得出：
- 对于 n 个节点的树，必须恰好有 n-1 条边
- 如果边数不等于 n-1，直接返回 false

常见的三种解法：
1. **并查集（Union-Find）**：检测环和连通性
2. **DFS（深度优先搜索）**：检测环和连通性
3. **BFS（广度优先搜索）**：检测环和连通性

## Java 代码实现

### 方法一：并查集（推荐）⭐

```java
class Solution {
    // 并查集的父节点数组
    private int[] parent;

    public boolean validTree(int n, int[][] edges) {
        // 树必须有 n-1 条边
        if (edges.length != n - 1) {
            return false;
        }

        // 初始化并查集
        parent = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }

        // 遍历所有边，尝试合并
        for (int[] edge : edges) {
            if (!union(edge[0], edge[1])) {
                return false; // 发现环
            }
        }

        // 能执行到这里，说明没有环且边数正确（n-1条边）
        return true;
    }

    // 查找根节点，路径压缩优化
    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // 合并两个集合，如果已在同一集合则返回 false（有环）
    private boolean union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);

        if (rootX == rootY) {
            return false; // 已在同一集合，形成环
        }

        parent[rootX] = rootY;
        return true;
    }
}
```

### 方法二：DFS（深度优先搜索）

```java
import java.util.*;

class Solution {
    public boolean validTree(int n, int[][] edges) {
        // 树必须有 n-1 条边
        if (edges.length != n - 1) {
            return false;
        }

        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }

        // DFS 检测连通性
        boolean[] visited = new boolean[n];
        dfs(graph, visited, 0, -1);

        // 检查是否所有节点都被访问（连通性）
        for (boolean v : visited) {
            if (!v) return false;
        }
        return true;
    }

    // DFS 遍历，parent 是父节点，用于避免回到父节点
    private boolean dfs(List<List<Integer>> graph, boolean[] visited, int node, int parent) {
        visited[node] = true;

        for (int neighbor : graph.get(node)) {
            if (neighbor == parent) {
                continue; // 跳过父节点
            }
            if (visited[neighbor]) {
                return false; // 访问到已访问节点，说明有环
            }
            if (!dfs(graph, visited, neighbor, node)) {
                return false;
            }
        }
        return true;
    }
}
```

### 方法三：BFS（广度优先搜索）

```java
import java.util.*;

class Solution {
    public boolean validTree(int n, int[][] edges) {
        // 树必须有 n-1 条边
        if (edges.length != n - 1) {
            return false;
        }

        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }

        // BFS 检查连通性
        boolean[] visited = new boolean[n];
        visited[0] = true;
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0);
        int count = 1;

        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int neighbor : graph.get(node)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                    count++;
                }
            }
        }

        // 检查是否所有节点都被访问
        return count == n;
    }
}
```

## 复杂度分析

### 方法一（并查集）
- **时间复杂度**：O(n + E⋅α(n))，其中 E 是边数，α(n) 是阿克曼函数的反函数，几乎为常数
- **空间复杂度**：O(n)，存储并查集数组

### 方法二、三（DFS/BFS）
- **时间复杂度**：O(n + E)，遍历所有节点和边
- **空间复杂度**：O(n + E)，存储图的邻接表和访问记录

## 关键点总结

1. **树的判定条件**：n 个节点的树必须满足恰好有 n-1 条边、连通、无环
2. **边数快速判断**：先判断边数是否为 n-1，可以快速排除大部分情况
3. **并查集适用性**：并查集天然适合处理连通性和环检测问题
4. **DFS/BFS 记录父节点**：在无向图中用 DFS 检测环时，需要记录父节点避免回头
5. **优化技巧**：如果边数已经是 n-1，只需检查连通性即可（无需额外检测环）

## 易错点

1. **忘记判断边数**：必须先判断 `edges.length != n - 1`
2. **DFS 回到父节点**：在无向图中，邻居包含父节点，需要跳过父节点
3. **连通性检查**：即使没有环，也需要检查是否所有节点都连通
4. **并查集的环检测**：如果两个节点已在同一集合，再连边就形成环
5. **空图处理**：n=1, edges=[] 是有效的树

## 学习建议

1. **理解树的性质**：n 个节点的树有 n-1 条边，这是一个重要的数学性质
2. **掌握并查集**：这是处理图连通性问题的经典数据结构，建议熟练掌握
3. **图的遍历**：DFS 和 BFS 是图论的基础，要能灵活运用
4. **环检测技巧**：
   - 并查集：两节点已在同一集合再连边

   - BFS：一般配合边数判断
5. **从简单到复杂**：先理解 BFS 连通性检查，再学习并查集
