## 题目描述

给你整数数组 nums 和正整数 k，可以将任意两元素替换为它们的 OR 和 AND，选出 k 个元素使平方和最大，返回最大值对 10^9+7 取模。

## 解题思路

OR+AND 操作保持每个二进制位上 1 的总数不变，因此统计各位 1 的个数后，贪心为 k 个数从高位到低位依次分配 1，使平方集中（凸性保证这样最优）。

## Java 代码实现

```java
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int maxSum(int[] nums, int k) {
        // 统计每个二进制位上 1 的总数
        int[] cnt = new int[30];
        for (int num : nums) {
            for (int bit = 0; bit < 30; bit++) {
                if ((num >> bit & 1) == 1) cnt[bit]++;
            }
        }

        // 贪心为 k 个数分配 1：每次取尽量高位的 1 构造最大数
        long ans = 0;
        for (int i = 0; i < k; i++) {
            long x = 0;
            for (int bit = 29; bit >= 0; bit--) {
                if (cnt[bit] > 0) {
                    x |= (1L << bit);
                    cnt[bit]--;
                }
            }
            ans = (ans + x % MOD * (x % MOD)) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + k) × 30) = O(n + k)
- **空间复杂度**：O(30) = O(1)

## 关键点总结

1. OR+AND 操作不改变每个二进制位上 1 的总数
2. 平方的凸性：将 1 集中到少数几个数上比分散更优
3. 贪心：每次为当前数从高位到低位取 1，取 k 次
