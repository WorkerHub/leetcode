## 题目描述

给你 n 节点带权无根树，路径分数 = 路径节点价格之和减去某端点价格（取两端点中使分数更大的那个），返回所有路径中的最大分数。

## 解题思路

DFS 时维护每个节点向下的两种最大链：含自身端点的（`withEnd`）和不含自身端点的（`withoutEnd`）。合并两子链时枚举四种组合，更新全局答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    int[] price;
    List<Integer>[] graph;
    long ans = 0;

    public long maxOutput(int n, int[][] edges, int[] price) {
        this.price = price;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }
        dfs(0, -1);
        return ans;
    }

    // 返回 [含当前节点端点的最大链和, 不含当前节点端点的最大链和]
    private long[] dfs(int node, int parent) {
        long withEnd = price[node];    // 含 node 自身的最大链
        long withoutEnd = 0;           // 不含 node 端点的最大链

        for (int child : graph[node]) {
            if (child == parent) continue;
            long[] res = dfs(child, node);
            long childWith = res[0], childWithout = res[1];

            // 合并当前链与子链，枚举端点是否包含
            ans = Math.max(ans, withEnd + childWithout);       // node 含，child 不含
            ans = Math.max(ans, withoutEnd + childWith);       // node 不含，child 含
            ans = Math.max(ans, withEnd - price[node] + childWith); // 两端都含，减去 node 价格（node 为去掉的端点）

            // 更新当前节点的状态
            withoutEnd = Math.max(withoutEnd, childWith);
            withEnd = Math.max(withEnd, childWith + price[node]);
        }
        // 单独叶节点或链端点
        ans = Math.max(ans, withEnd - price[node]); // 仅 node 自身链，分数为 0（单点路径）
        ans = Math.max(ans, withoutEnd);
        return new long[]{withEnd, withoutEnd};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 路径分数 = 路径总和 - 某端点价格，等价于含端点链 + 不含端点链的组合
2. DFS 维护两种状态：含当前节点端点的最大链和、不含当前节点端点的最大链和
3. 合并两子链时需考虑三种组合（含/不含两端节点）
