## 题目描述

给你两个长度为 n 的整数数组 `nums1`、`nums2` 和正整数 `k`，从中选 k 个下标，得分为选中 `nums1` 值之和乘以选中 `nums2` 值的最小值，返回最大得分。

## 解题思路

按 `nums2` 降序枚举（保证当前位置的 nums2 是最小值），用大小为 k 的最小堆维护前 k 大的 `nums1` 值。堆满时计算得分取最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxScore(int[] nums1, int[] nums2, int k) {
        int n = nums1.length;
        // 按 nums2 降序排列索引
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> nums2[b] - nums2[a]);

        PriorityQueue<Integer> minHeap = new PriorityQueue<>(); // 最小堆
        long sumN1 = 0, ans = 0;

        for (int i : idx) {
            minHeap.offer(nums1[i]);
            sumN1 += nums1[i];
            // 维护堆大小为 k
            if (minHeap.size() > k) sumN1 -= minHeap.poll();
            // 堆满时 nums2[i] 是当前选中元素中最小的 nums2
            if (minHeap.size() == k) ans = Math.max(ans, sumN1 * nums2[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + n log k)
- **空间复杂度**：O(k)

## 关键点总结

1. 按 nums2 降序枚举，当前位置的 nums2 即为所选元素中的最小值
2. 最小堆维护当前最大的 k 个 nums1 值（超出 k 时弹出最小值）
3. 用 `long` 累加 sumN1 和得分，防止整数溢出
