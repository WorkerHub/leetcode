## 题目描述

给定两个一维向量，实现一个迭代器，交替返回它们的元素。

**示例 1:**

```
输入:
v1 = [1,2]
v2 = [3,4,5,6] 
输出: [1,3,2,4,5,6]
解释: 调用 next() 会逐个返回 [1,3,2,4,5,6]。
```

**示例 2:**

```
输入:
v1 = [1]
v2 = []
输出: [1]
```

**示例 3:**

```
输入:
v1 = []
v2 = [1]
输出: [1]
```

**进阶：** 如果给定 k 个一维向量，你的代码能否正确运行？

## 解题思路

这道题要求实现一个迭代器，能够交替返回两个列表的元素。核心思想是维护两个指针，分别指向两个列表的当前位置，并记录当前应该从哪个列表取元素。

**关键观察：**

1. 需要记录每个列表的当前索引位置
2. 需要标记当前轮到哪个列表
3. 当一个列表遍历完后，只从另一个列表取元素
4. 可以使用队列存储所有非空列表，实现更优雅的解法

**算法流程：**

方法一（双指针）：
1. 使用两个指针 `i1` 和 `i2` 分别跟踪两个列表的位置
2. 使用标志位 `turn` 标记当前轮到哪个列表
3. 在 `next()` 中，根据 `turn` 从对应列表取元素
4. 如果当前列表已用完，自动切换到另一个列表

方法二（队列）：
1. 将所有非空列表及其索引存入队列
2. 每次取队首列表的当前元素
3. 如果该列表还有剩余元素，将其重新加入队尾
4. 实现了真正的"轮转"机制

## Java 代码实现

### 方法一：双指针标记法

```java
import java.util.List;

public class ZigzagIterator {
    private List<Integer> v1;
    private List<Integer> v2;
    private int i1;  // v1 的当前索引
    private int i2;  // v2 的当前索引
    private int turn; // 当前轮到哪个列表，1 表示 v1，2 表示 v2

    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        this.v1 = v1;
        this.v2 = v2;
        this.i1 = 0;
        this.i2 = 0;
        // 如果 v1 为空，从 v2 开始
        this.turn = v1.isEmpty() ? 2 : 1;
    }

    public int next() {
        if (turn == 1) {
            // 当前轮到 v1
            int val = v1.get(i1++);
            // 切换到 v2，除非 v2 已用完
            if (i2 < v2.size()) {
                turn = 2;
            }
            return val;
        } else {
            // 当前轮到 v2
            int val = v2.get(i2++);
            // 切换到 v1，除非 v1 已用完
            if (i1 < v1.size()) {
                turn = 1;
            }
            return val;
        }
    }

    public boolean hasNext() {
        return i1 < v1.size() || i2 < v2.size();
    }
}
```

### 方法二：队列法（推荐，支持 k 个列表）

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

public class ZigzagIterator {
    // 队列中存储 (列表, 当前索引) 的整数数组
    private Deque<int[]> queue;
    private List<List<Integer>> lists;

    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        queue = new ArrayDeque<>();
        lists = new java.util.ArrayList<>();
        lists.add(v1);
        lists.add(v2);

        // 将非空列表的 (列表索引, 当前元素索引) 加入队列
        for (int i = 0; i < lists.size(); i++) {
            if (!lists.get(i).isEmpty()) {
                queue.offer(new int[]{i, 0}); // [列表索引, 元素索引]
            }
        }
    }

    public int next() {
        // 取队首
        int[] curr = queue.poll();
        int listIdx = curr[0];
        int elemIdx = curr[1];

        int val = lists.get(listIdx).get(elemIdx);

        // 如果该列表还有剩余元素，重新加入队尾
        if (elemIdx + 1 < lists.get(listIdx).size()) {
            queue.offer(new int[]{listIdx, elemIdx + 1});
        }

        return val;
    }

    public boolean hasNext() {
        return !queue.isEmpty();
    }
}
```

### 方法三：通用的 k 个列表解法

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Iterator;
import java.util.List;

public class ZigzagIterator {
    // 存储每个列表的迭代器
    private Deque<Iterator<Integer>> queue;

    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {
        queue = new ArrayDeque<>();
        // 将非空列表的迭代器加入队列
        if (!v1.isEmpty()) queue.offer(v1.iterator());
        if (!v2.isEmpty()) queue.offer(v2.iterator());
    }

    public int next() {
        // 取队首迭代器
        Iterator<Integer> it = queue.poll();
        int val = it.next();
        // 如果迭代器还有元素，重新加入队尾
        if (it.hasNext()) {
            queue.offer(it);
        }
        return val;
    }

    public boolean hasNext() {
        return !queue.isEmpty();
    }
}

/**
 * 使用示例：
 * List<Integer> v1 = Arrays.asList(1, 2);
 * List<Integer> v2 = Arrays.asList(3, 4, 5, 6);
 * ZigzagIterator it = new ZigzagIterator(v1, v2);
 * while (it.hasNext()) System.out.print(it.next() + " ");
 * // 输出：1 3 2 4 5 6
 */
```

## 复杂度分析

**方法一：双指针法**
- 时间复杂度：`O(1)` 对于每次 `next()` 和 `hasNext()` 操作
- 空间复杂度：`O(1)` 只使用常数额外空间

**方法二：队列法**
- 时间复杂度：`O(1)` 对于每次 `next()` 和 `hasNext()` 操作，队列操作都是 O(1)
- 空间复杂度：`O(k)` 其中 k 是列表数量，队列中最多存储 k 个元素

## 关键点总结

1. **迭代器设计模式**：实现 `next()` 和 `hasNext()` 两个核心方法
2. **状态维护**：需要记录每个列表的当前位置和轮转状态
3. **边界处理**：当某个列表为空或遍历完时的处理逻辑
4. **扩展性**：队列法更容易扩展到 k 个列表的情况
5. **轮转机制**：队列的先进先出特性天然支持轮转访问

## 易错点

1. **空列表处理**：初始化时需要检查列表是否为空，避免访问越界
2. **切换逻辑**：在双指针法中，切换到下一个列表前需要检查是否还有元素
3. **队列为空**：`next()` 调用前应确保 `hasNext()` 返回 true
4. **索引越界**：确保在访问列表元素前检查索引有效性
5. **重新入队**：在队列法中，取出元素后要判断是否需要重新加入队尾
