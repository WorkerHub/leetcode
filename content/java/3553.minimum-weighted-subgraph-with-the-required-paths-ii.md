## 题目描述

给定一棵有 `n` 个节点的加权树，以及若干查询。每个查询给出三个节点 `src1, src2, dest`，求包含从 `src1` 到 `dest` 的路径和从 `src2` 到 `dest` 的路径的最小权重子图的总边权。

## 解题思路

两条路径的并集形成 Y 形结构，汇合点 `meet` 是三个两两 LCA 中深度最大的节点。总权重 = `dist(src1, meet) + dist(src2, meet) + dist(meet, dest)`。使用二进制提升实现 O(log n) LCA 查询。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int LOG;
    private int[] depth;
    private long[] distRoot;
    private int[][] parent;

    public long[] minimumWeight(int n, int[][] edges, int[][] queries) {
        LOG = 1;
        while ((1 << LOG) < n) LOG++;
        LOG++;

        List<long[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new long[]{e[1], e[2]});
            graph[e[1]].add(new long[]{e[0], e[2]});
        }

        depth = new int[n];
        distRoot = new long[n];
        parent = new int[LOG][n];
        for (int[] row : parent) Arrays.fill(row, 0);

        // BFS 建树（以 0 为根）
        boolean[] visited = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(0);
        visited[0] = true;
        parent[0][0] = 0;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (long[] nw : graph[u]) {
                int v = (int) nw[0];
                long w = nw[1];
                if (!visited[v]) {
                    visited[v] = true;
                    depth[v] = depth[u] + 1;
                    distRoot[v] = distRoot[u] + w;
                    parent[0][v] = u;
                    queue.add(v);
                }
            }
        }

        // 二进制提升
        for (int k = 1; k < LOG; k++)
            for (int u = 0; u < n; u++)
                parent[k][u] = parent[k-1][parent[k-1][u]];

        long[] result = new long[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int s1 = queries[i][0], s2 = queries[i][1], dest = queries[i][2];
            int l12 = lca(s1, s2), l1d = lca(s1, dest), l2d = lca(s2, dest);
            // 汇合点是深度最大的 LCA
            int meet = l12;
            if (depth[l1d] > depth[meet]) meet = l1d;
            if (depth[l2d] > depth[meet]) meet = l2d;
            result[i] = dist(s1, meet) + dist(s2, meet) + dist(meet, dest);
        }
        return result;
    }

    private int lca(int u, int v) {
        if (depth[u] < depth[v]) { int tmp = u; u = v; v = tmp; }
        int diff = depth[u] - depth[v];
        for (int k = 0; k < LOG; k++)
            if ((diff >> k & 1) == 1) u = parent[k][u];
        if (u == v) return u;
        for (int k = LOG-1; k >= 0; k--)
            if (parent[k][u] != parent[k][v]) { u = parent[k][u]; v = parent[k][v]; }
        return parent[0][u];
    }

    private long dist(int u, int v) {
        int l = lca(u, v);
        return distRoot[u] + distRoot[v] - 2 * distRoot[l];
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，二进制提升 LCA
- 空间复杂度：O(n log n)，存储祖先表

## 关键点总结

1. 两条路径的并集形成 Y 形，汇合点 = 三个两两 LCA 中深度最大的
2. 树上距离 = `distRoot[u] + distRoot[v] - 2 * distRoot[LCA]`
3. 二进制提升实现 O(log n) 的 LCA 查询
