## 题目描述

有 `n` 个城市，连通道路 `roads[i] = [u, v, cost]`（双向），苹果价格为 `appleCost[i]`。从城市 `s` 出发，驱车到城市 `t` 购买苹果并返回，路程花费为往返代价（去程 1 倍 + 回程 k 倍）。对每个城市，返回从该城市出发购买苹果的最小总代价。

## 解题思路

多源 Dijkstra：将每个城市以 `appleCost[i]` 为初始距离加入优先队列，边权乘以 `(1+k)` 代表往返代价，一次 Dijkstra 即可求出所有城市的答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long[] minCost(int n, int[][] roads, int[] appleCost, int k) {
        // 构建邻接表
        List<long[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] r : roads) {
            graph[r[0]].add(new long[]{r[1], r[2]});
            graph[r[1]].add(new long[]{r[0], r[2]});
        }

        long[] dist = new long[n];
        // 多源Dijkstra：初始距离为各城市苹果价格
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        for (int i = 0; i < n; i++) {
            dist[i] = appleCost[i];
            pq.offer(new long[]{dist[i], i});
        }

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (long[] e : graph[u]) {
                int v = (int) e[0];
                // 往返代价 = 路程 * (1 + k)
                long nd = d + e[1] * (1 + k);
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{nd, v});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)
- 空间复杂度：O(V + E)

## 关键点总结

1. 多源 Dijkstra：将所有"购买点"作为虚拟源点，初始距离为 appleCost
2. 往返代价 = 路程 * (1 + k)
3. 使用 long 防止大数溢出
