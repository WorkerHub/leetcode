## 题目描述

与 3330 类似，但允许多次长按，且要求原始字符串长度 >= `k`。给你字符串 `word` 和整数 `k`，返回满足条件的原始字符串数（对 10^9+7 取模）。

## 解题思路

将 `word` 分成连续字符段，段长为 `l_i`，每段可贡献 1 到 `l_i` 个字符。总方案数 = ∏l_i。用 DP + 前缀和计算长度 < k 的方案数（不合法），用总数减去。`dp[j]` = 当前阶段原始长度恰好为 j 的方案数，每段转移用前缀和加速到 O(k)。

## Java 代码实现

```java
class Solution {
    public int possibleStringCount(String word, int k) {
        final int MOD = 1_000_000_007;
        // 分段
        List<Integer> segs = new ArrayList<>();
        int i = 0, n = word.length();
        while (i < n) {
            int j = i + 1;
            while (j < n && word.charAt(j) == word.charAt(i)) j++;
            segs.add(j - i);
            i = j;
        }

        // 总方案数 = ∏l_i
        long total = 1;
        for (int l : segs) total = total * l % MOD;

        // DP 计算长度 < k 的方案数
        // dp[j] = 处理完当前段后，原始长度恰为 j 的方案数（j in [0, k-1]）
        long[] dp = new long[k];
        dp[0] = 1;
        for (int l : segs) {
            // 前缀和加速：new_dp[j] = sum(dp[j-c] for c in 1..l)
            long[] prefix = new long[k + 1];
            for (int j = 0; j < k; j++) prefix[j + 1] = (prefix[j] + dp[j]) % MOD;
            long[] newDp = new long[k];
            for (int j = 1; j < k; j++) {
                int lo = Math.max(0, j - l);
                newDp[j] = (prefix[j] - prefix[lo] + MOD) % MOD;
            }
            dp = newDp;
        }

        long invalid = 0;
        for (long v : dp) invalid = (invalid + v) % MOD;
        return (int) ((total - invalid + MOD) % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * k)，m 为段数，k 为目标长度
- 空间复杂度：O(k)

## 关键点总结

1. 总方案数 = 各段长度之积（各段独立选 1 到 l_i）
2. 用 DP 计算长度 < k 的方案数再从总数减去
3. 前缀和将每段 DP 转移优化为 O(k)
