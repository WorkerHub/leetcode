## 题目描述

循环数组中每次可对元素+1或-1，求使所有长度为k的子数组和相等的最少操作次数。

## 解题思路

数论分析：等价于下标模gcd(n,k)相同的元素必须相等。分组后每组变为中位数操作次数最少。

## Java 代码实现

```java
class Solution {
    public long makeSubKSumEqual(int[] arr, int k) {
        int n = arr.length;
        int g = gcd(n, k);
        long totalOps = 0;

        for (int start = 0; start < g; start++) {
            // 收集同组元素
            List<Long> group = new ArrayList<>();
            for (int i = start; i < n; i += g) {
                group.add((long) arr[i]);
            }
            Collections.sort(group);
            long median = group.get(group.size() / 2);
            for (long x : group) {
                totalOps += Math.abs(x - median);
            }
        }
        return totalOps;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **分组依据gcd(n,k)**：循环关系的等价类
2. **中位数最优**：最小绝对偏差和
3. **用long防溢出**：arr[i]可达10^9
