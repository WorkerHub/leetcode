## 题目描述

给你字符串 s 和整数 k，将 s 分成 k 个非空子字符串，每个子字符串需变为半回文串（存在因子 d < len，使按步长 d 分成的每组子序列都是回文），返回最少修改次数。

## 解题思路

预处理 `cost[l][r]`（将 s[l..r] 变为半回文串的最少修改次数），枚举所有合法因子 d，取最小代价。然后区间 DP：`dp[i][j]` 表示将 s[0..i-1] 分成 j 段的最少修改数。

## Java 代码实现

```java
class Solution {
    public int minimumChanges(String s, int k) {
        int n = s.length();
        int[][] cost = new int[n][n];

        // 预计算 cost[l][r]：将 s[l..r] 变为半回文串的最少修改数
        for (int l = 0; l < n; l++) {
            for (int r = l + 1; r < n; r++) {
                int len = r - l + 1;
                int best = Integer.MAX_VALUE;
                // 枚举因子 d（1 <= d < len 且 d | len）
                for (int d = 1; d < len; d++) {
                    if (len % d != 0) continue;
                    int changes = 0;
                    for (int offset = 0; offset < d; offset++) {
                        // 子序列长度 = len / d
                        int lo = 0, hi = len / d - 1;
                        while (lo < hi) {
                            if (s.charAt(l + offset + lo * d) != s.charAt(l + offset + hi * d))
                                changes++;
                            lo++;
                            hi--;
                        }
                    }
                    best = Math.min(best, changes);
                }
                cost[l][r] = best;
            }
        }

        // dp[i][j]：将 s[0..i-1] 分成 j 段的最少修改数
        int[][] dp = new int[n + 1][k + 1];
        for (int[] row : dp) java.util.Arrays.fill(row, Integer.MAX_VALUE / 2);
        dp[0][0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= k; j++) {
                // 最后一段 s[p..i-1]，长度至少 2
                for (int p = j - 1; p <= i - 2; p++) {
                    if (dp[p][j - 1] == Integer.MAX_VALUE / 2) continue;
                    dp[i][j] = Math.min(dp[i][j], dp[p][j - 1] + cost[p][i - 1]);
                }
            }
        }
        return dp[n][k];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³ + n²k)，预处理 cost O(n³)，DP 转移 O(n²k)
- **空间复杂度**：O(n² + nk)

## 关键点总结

1. 半回文串定义：存在因子 d，按步长 d 分成的 d 组子序列均为回文
2. 预计算 cost 数组后区间 DP 转移清晰，dp[0][0]=0 其余为无穷大
3. 子串长度至少 2（d < len 要求），枚举 p 从 j-1 到 i-2
