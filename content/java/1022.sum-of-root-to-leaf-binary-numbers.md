## 题目描述

二叉树每个节点值为 0 或 1，每条根到叶路径代表一个二进制数。返回所有路径代表的数之和。

**示例：**
```
输入：root = [1,0,1,0,1,0,1]
输出：22（4+5+6+7）
```

## 解题思路

DFS：从根到叶传递当前路径值，每到一个节点 val = val * 2 + node.val。到达叶子节点时累加。

## Java 代码实现

```java
class Solution {
    public int sumRootToLeaf(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int val) {
        if (node == null) return 0;

        val = val * 2 + node.val;

        // 叶子节点返回当前路径值
        if (node.left == null && node.right == null) {
            return val;
        }

        return dfs(node.left, val) + dfs(node.right, val);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **路径值构建**：val = val * 2 + node.val
2. **叶子节点累加**：只在叶子节点返回路径值
3. **递归传递**：自顶向下传递当前值
