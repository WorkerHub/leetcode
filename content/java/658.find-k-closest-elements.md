## 题目描述

给定一个**排序好**的数组 `arr`，两个整数 `k` 和 `x`，从数组中找到最靠近 `x`（两数之差最小）的 `k` 个数。返回的结果必须要是按**升序**排好的。

整数 `a` 比整数 `b` 更接近 `x` 需要满足：

- `|a - x| < |b - x|` 或者
- `|a - x| == |b - x|` 且 `a < b`

**示例 1:**

```
输入：arr = [1,2,3,4,5], k = 4, x = 3
输出：[1,2,3,4]
```

**示例 2:**

```
输入：arr = [1,2,3,4,5], k = 4, x = -1
输出：[1,2,3,4]
```

**提示:**
- `1 <= k <= arr.length`
- `1 <= arr.length <= 10^4`
- `arr` 按**升序**排列
- `-10^4 <= arr[i], x <= 10^4`

## 解题思路

这道题有多种解法，从简单到优化：

### 思路一：排序法（最直观）

1. 按照与 x 的距离对数组排序
2. 取前 k 个元素
3. 对结果排序返回

### 思路二：双指针（滑动窗口）

利用数组有序的性质：

1. 使用双指针维护一个大小为 k 的窗口
2. 比较窗口两端与 x 的距离
3. 移除距离较远的一端

### 思路三：二分查找（最优）

关键观察：k 个最近元素在数组中是**连续**的。

问题转化为：找到这个长度为 k 的连续子数组的起始位置。

使用二分查找找到最优的左边界：
- 左边界的范围：`[0, n-k]`
- 比较 `arr[mid]` 和 `arr[mid+k]` 与 x 的距离

## Java 代码实现

### 方法一：排序法（新手推荐）

```java
import java.util.*;

class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        // 按照距离排序，距离相同时按值排序
        List<Integer> list = new ArrayList<>();
        for (int num : arr) list.add(num);

        list.sort((a, b) -> {
            int distA = Math.abs(a - x);
            int distB = Math.abs(b - x);
            if (distA != distB) return distA - distB;
            return a - b;
        });

        // 取前 k 个元素
        List<Integer> result = list.subList(0, k);

        // 结果需要按升序排列
        Collections.sort(result);
        return new ArrayList<>(result);
    }
}
```

### 方法二：双指针（滑动窗口）

```java
import java.util.*;

class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        int left = 0, right = arr.length - 1;

        // 不断缩小窗口，直到只剩 k 个元素
        while (right - left >= k) {
            // 比较两端与 x 的距离
            if (Math.abs(arr[left] - x) <= Math.abs(arr[right] - x)) {
                // 左端更近或相等（相等时保留较小的），移除右端
                right--;
            } else {
                // 右端更近，移除左端
                left++;
            }
        }

        List<Integer> result = new ArrayList<>();
        for (int i = left; i <= right; i++) {
            result.add(arr[i]);
        }
        return result;
    }
}
```

### 方法三：二分查找（最优解）

```java
import java.util.*;

class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        int left = 0, right = arr.length - k;

        while (left < right) {
            int mid = (left + right) / 2;

            // 比较 arr[mid] 和 arr[mid+k] 谁离 x 更远
            // 如果 arr[mid] 离 x 更远，说明最优区间在右边
            if (x - arr[mid] > arr[mid + k] - x) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        List<Integer> result = new ArrayList<>();
        for (int i = left; i < left + k; i++) {
            result.add(arr[i]);
        }
        return result;
    }
}
```

### 方法四：二分查找 + 扩展（另一种思路）

```java
import java.util.*;

class Solution {
    public List<Integer> findClosestElements(int[] arr, int k, int x) {
        // 二分查找第一个 >= x 的位置
        int left = 0, right = arr.length - 1;

        while (left < right) {
            int mid = (left + right) / 2;
            if (arr[mid] < x) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        // left 是第一个 >= x 的位置
        // 设置双指针
        int i = left - 1; // x 左边
        int j = left;     // x 右边

        // 扩展 k 个元素
        for (int count = 0; count < k; count++) {
            if (i < 0) {
                j++;
            } else if (j >= arr.length) {
                i--;
            } else if (Math.abs(arr[i] - x) <= Math.abs(arr[j] - x)) {
                i--;
            } else {
                j++;
            }
        }

        List<Integer> result = new ArrayList<>();
        for (int idx = i + 1; idx < j; idx++) {
            result.add(arr[idx]);
        }
        return result;
    }
}
```

## 复杂度分析

### 方法一：排序法
- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)，排序需要额外空间

### 方法二：双指针
- **时间复杂度**：O(n)，最多遍历 n-k 次
- **空间复杂度**：O(1)，不算返回值

### 方法三：二分查找
- **时间复杂度**：O(log(n-k) + k)
  - 二分查找：O(log(n-k))
  - 复制结果：O(k)
- **空间复杂度**：O(1)，不算返回值

### 方法四：二分 + 扩展
- **时间复杂度**：O(log n + k)
- **空间复杂度**：O(1)

## 图解示例

示例 1：`arr = [1,2,3,4,5], k = 4, x = 3`

**双指针法：**

```
初始：left=0, right=4
[1, 2, 3, 4, 5]
 ↑           ↑

比较：|1-3|=2, |5-3|=2
距离相等，保留较小的 1，移除 5
right = 3

[1, 2, 3, 4, 5]
 ↑        ↑

现在窗口大小 = 4，停止
结果：[1, 2, 3, 4]
```

**二分查找法：**

```
寻找左边界，范围 [0, 5-4] = [0, 1]

初始：left=0, right=1
mid = 0

比较 arr[0]=1 和 arr[4]=5：
x-arr[0] = 3-1 = 2
arr[4]-x = 5-3 = 2
2 不大于 2，right = mid = 0

left = right = 0，停止
结果：arr[0:4] = [1, 2, 3, 4]
```

## 关键点总结

1. **数组有序**：利用有序性质，最近的 k 个元素一定是连续的
2. **距离定义**：距离相等时选择较小的值
3. **双指针技巧**：从两端向中间缩小，保留距离更近的一端
4. **二分查找**：找到最优左边界，直接截取子数组
5. **返回格式**：结果必须按升序排列

## 易错点

1. **距离相等时的处理**：
   ```java
   // 错误：距离相等时没有优先选择较小值
   if (Math.abs(arr[left] - x) < Math.abs(arr[right] - x))
   
   // 正确：使用 <=
   if (Math.abs(arr[left] - x) <= Math.abs(arr[right] - x))
   ```

2. **循环条件**：
   ```java
   // 双指针：要保留 k 个元素
   while (right - left >= k) // 不是 >
   ```

3. **二分边界**：
   ```java
   // 左边界范围是 [0, n-k]，不是 [0, n-1]
   int left = 0, right = arr.length - k;
   ```

4. **二分比较条件**：
   ```java
   // 比较的是距离差
   if (x - arr[mid] > arr[mid + k] - x)
   ```
