## 题目描述

给定单链表的头节点 `head`，将所有索引为奇数的节点和索引为偶数的节点分别组合在一起，然后返回重新排序的列表。

第一个节点的索引被认为是**奇数**，第二个节点的索引为**偶数**，以此类推。

请注意，偶数组和奇数组内部的相对顺序应该与输入时保持一致。

你必须在 `O(1)` 的额外空间复杂度和 `O(n)` 的时间复杂度下解决这个问题。

**示例 1:**

```
输入: head = [1,2,3,4,5]
输出: [1,3,5,2,4]
```

**示例 2:**

```
输入: head = [2,1,3,5,6,4,7]
输出: [2,3,6,7,1,5,4]
```

**提示:**

- `n == 链表中的节点数`
- `0 <= n <= 10^4`
- `-10^6 <= Node.val <= 10^6`

## 解题思路

这道题要求将链表按索引的奇偶性重新排列，核心思想是**分离 + 拼接**。

### 核心思想

1. **分离奇偶节点**：
   - 使用两个指针 `odd` 和 `even` 分别指向奇数和偶数节点
   - 遍历链表，将奇数节点连成一条链，偶数节点连成另一条链
   
2. **拼接两条链**：
   - 遍历结束后，将偶数链接到奇数链的末尾
   
3. **保持原顺序**：
   - 奇数链和偶数链内部的相对顺序与原链表一致

### 算法流程

1. 特殊情况：空链表或单节点，直接返回
2. 初始化：`odd = head`，`even = head.next`，`evenHead = even`
3. 遍历链表：
   - `odd.next = even.next`（奇数节点指向下一个奇数节点）
   - `odd = odd.next`（移动奇数指针）
   - `even.next = odd.next`（偶数节点指向下一个偶数节点）
   - `even = even.next`（移动偶数指针）
4. 拼接：`odd.next = evenHead`

## Java 代码实现

### 方法一：双指针分离（推荐）⭐

```java
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

class Solution {
    public ListNode oddEvenList(ListNode head) {
        // 双指针分离奇偶节点，然后拼接
        // 边界情况
        if (head == null || head.next == null) return head;

        // 初始化指针
        ListNode odd = head;           // 奇数节点链的当前节点
        ListNode even = head.next;     // 偶数节点链的当前节点
        ListNode evenHead = even;      // 记录偶数链的头节点

        // 遍历链表，分离奇偶节点
        while (even != null && even.next != null) {
            // 奇数节点指向下一个奇数节点
            odd.next = even.next;
            odd = odd.next;

            // 偶数节点指向下一个偶数节点
            even.next = odd.next;
            even = even.next;
        }

        // 将偶数链接到奇数链的末尾
        odd.next = evenHead;

        return head;
    }
}
```

### 方法二：详细注释版（便于理解）

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        // 分离奇偶节点并拼接
        // 空链表或单节点，直接返回
        if (head == null || head.next == null) return head;

        // 奇数链：1 -> 3 -> 5 -> ...
        ListNode odd = head;
        // 偶数链：2 -> 4 -> 6 -> ...
        ListNode even = head.next;
        // 记录偶数链的头节点，最后用于拼接
        ListNode evenHead = even;

        // 循环条件：偶数节点存在且有下一个节点
        // 因为偶数节点在奇数节点后面，它决定了链表的结束
        while (even != null && even.next != null) {
            // 步骤 1：奇数节点跳过偶数节点，指向下一个奇数节点
            // 例如：1 -> 2 -> 3，变为 1 -> 3
            odd.next = even.next;
            odd = odd.next;  // 移动奇数指针

            // 步骤 2：偶数节点跳过奇数节点，指向下一个偶数节点
            // 例如：2 -> 3 -> 4，变为 2 -> 4
            even.next = odd.next;
            even = even.next;  // 移动偶数指针
        }

        // 步骤 3：将偶数链接到奇数链的末尾
        // 例如：1 -> 3 -> 5 接上 2 -> 4
        odd.next = evenHead;

        return head;
    }
}
```

### 方法三：使用虚拟头节点（另一种写法）

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        // 使用虚拟头节点构建奇偶链表
        if (head == null) return head;

        // 虚拟头节点
        ListNode oddDummy = new ListNode(0);
        ListNode evenDummy = new ListNode(0);
        ListNode oddTail = oddDummy;
        ListNode evenTail = evenDummy;

        // 遍历原链表，按索引奇偶分配节点
        ListNode current = head;
        int index = 1;

        while (current != null) {
            if (index % 2 == 1) {
                // 奇数索引
                oddTail.next = current;
                oddTail = oddTail.next;
            } else {
                // 偶数索引
                evenTail.next = current;
                evenTail = evenTail.next;
            }

            current = current.next;
            index++;
        }

        // 断开偶数链的末尾（防止成环）
        evenTail.next = null;
        // 拼接奇数链和偶数链
        oddTail.next = evenDummy.next;

        return oddDummy.next;
    }
}
```

## 复杂度分析

**所有方法**

- **时间复杂度**：O(n)
  - 遍历链表一次，每个节点访问常数次
  
- **空间复杂度**：O(1)
  - 只使用了常数个指针变量

## 关键点总结

1. **双指针技巧**：`odd` 和 `even` 分别维护奇偶链表
2. **循环条件**：`while (even != null && even.next != null)`
   - `even != null` 确保偶数节点存在
   - `even.next != null` 确保还有下一个奇数节点
3. **记录偶数链头**：`evenHead = even`，用于最后拼接
4. **原地操作**：只改变 `next` 指针，不创建新节点
5. **相对顺序保持**：遍历过程中按原顺序分配节点

## 易错点

1. **循环条件错误**：
   - 错误：`while (odd != null && odd.next != null)`（会提前结束）
   - 正确：`while (even != null && even.next != null)`
   
2. **忘记记录偶数链头**：
   - 必须在开始时记录 `evenHead = even`
   - 否则最后无法找到偶数链的头节点

3. **未断开偶数链末尾**：
   - 方法三中必须 `evenTail.next = null`
   - 否则可能形成环

4. **空链表处理**：
   - 要检查 `head` 和 `head.next` 是否为空

5. **指针移动顺序**：
   - 必须先修改 `next` 指针，再移动指针
   - 顺序错误会导致丢失节点

## 图解示例

示例：`head = [1, 2, 3, 4, 5]`

```
初始状态：
1 -> 2 -> 3 -> 4 -> 5 -> null
^    ^
odd  even

第一次循环：
odd.next = even.next:  1 -> 3
odd = odd.next:        odd 指向 3
even.next = odd.next:  2 -> 4
even = even.next:      even 指向 4

当前状态：
1 -> 3 -> 4 -> 5 -> null
     ^    ^
    odd  even
2 -> 4 -> 5 -> null

第二次循环：
odd.next = even.next:  3 -> 5
odd = odd.next:        odd 指向 5
even.next = odd.next:  4 -> null
even = even.next:      even 指向 null

当前状态：
1 -> 3 -> 5 -> null
          ^
         odd
2 -> 4 -> null
          ^
        even

拼接：
odd.next = evenHead:  5 -> 2

最终结果：
1 -> 3 -> 5 -> 2 -> 4 -> null
```
