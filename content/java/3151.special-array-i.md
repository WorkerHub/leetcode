## 题目描述

如果数组中每对相邻元素的奇偶性不同（奇偶交替），则称该数组为**特殊**数组。给你整数数组 `nums`，判断其是否为特殊数组。

## 解题思路

遍历数组，检查每对相邻元素的奇偶性是否不同，发现相同则返回 false。

## Java 代码实现

```java
class Solution {
    public boolean isArraySpecial(int[] nums) {
        // 检查每对相邻元素奇偶性是否不同
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] % 2 == nums[i - 1] % 2) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 奇偶性用 `x % 2` 判断
2. 长度为 1 的数组无相邻对，直接返回 true
3. 等价判断：`(nums[i] ^ nums[i-1]) & 1 == 1`（异或低位为 1 表示奇偶不同）
