## 题目描述

给定正整数 `a`，找出最小的正整数 `b`，使得 `b` 的各位数字相乘等于 `a`。无解或超过 32 位整数返回 0。

**示例：**
```
输入：a = 48
输出：68
解释：48 = 6 × 8
```

## 解题思路

贪心：从 9 到 2 尝试分解，优先使用大因子减少位数，最后倒序排列得到最小数。

## Java 代码实现

```java
class Solution {
    public int smallestFactorization(int a) {
        if (a < 2) return a;

        List<Integer> factors = new ArrayList<>();

        // 从9到2尝试分解
        for (int d = 9; d >= 2; d--) {
            while (a % d == 0) {
                factors.add(d);
                a /= d;
            }
        }

        // 有大于9的质因子，无解
        if (a > 1) return 0;

        // 倒序排列得到最小数
        long result = 0;
        for (int i = factors.size() - 1; i >= 0; i--) {
            result = result * 10 + factors.get(i);
        }

        // 检查32位整数范围
        return result > Integer.MAX_VALUE ? 0 : (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log a)
- **空间复杂度**：O(log a)

## 关键点总结

1. **贪心**：从大到小分解减少位数
2. **倒序排列**：小因子在高位，大因子在低位
3. **范围检查**：用 long 中间计算避免溢出
