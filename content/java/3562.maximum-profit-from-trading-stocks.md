## 题目描述

给定两个整数数组 `present` 和 `future`（长度均为 `n`），以及整数 `budget`。`present[i]` 是第 `i` 支股票的当前价格，`future[i]` 是其未来价格。在预算 `budget` 内购买若干股票（每支最多一次），求最大利润。

## 解题思路

0-1 背包问题：每支股票的代价为 `present[i]`，价值为 `max(0, future[i] - present[i])`，只考虑利润为正的股票。背包容量为 `budget`，用 dp 数组维护每个预算下的最大利润。

## Java 代码实现

```java
class Solution {
    public int maximumProfit(int[] present, int[] future, int budget) {
        int n = present.length;
        // 只考虑有利润的股票
        int[] dp = new int[budget + 1];
        for (int i = 0; i < n; i++) {
            int cost = present[i];
            int profit = future[i] - present[i];
            if (profit <= 0 || cost > budget) continue;
            // 0-1 背包，从大到小遍历
            for (int j = budget; j >= cost; j--) {
                dp[j] = Math.max(dp[j], dp[j - cost] + profit);
            }
        }
        return dp[budget];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * budget)
- 空间复杂度：O(budget)

## 关键点总结

1. 只购买利润为正的股票（future > present）
2. 标准 0-1 背包：dp[j] = 预算为 j 时的最大利润
3. 背包遍历时从大到小防止同一物品被选多次
