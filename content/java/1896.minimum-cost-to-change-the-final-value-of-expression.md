## 题目描述

给你一个合法布尔表达式字符串 `expression`（含 `0`、`1`、`&`、`|` 和括号），可将任意字符改为另一个同类字符（1/0互换，&/|互换），返回改变最终值所需的最小操作数。

## 解题思路

对每个子表达式维护 `(val, cost0, cost1)`，分别表示当前值、变为0的最小代价和变为1的最小代价。合并时枚举两个操作数的目标值和新操作符的所有组合（8种），取最优。用递归解析实现。

## Java 代码实现

```java
class Solution {
    private String expr;
    private int idx;

    public int minOperationsToFlip(String expression) {
        this.expr = expression;
        this.idx = 0;
        int[] res = parse();
        // res[0]=val, res[1]=cost0, res[2]=cost1
        return res[0] == 1 ? res[1] : res[2]; // 改变当前值的代价
    }

    // 递归解析，返回 [val, cost0, cost1]
    private int[] parse() {
        int[] left = parseAtom();
        while (idx < expr.length() && (expr.charAt(idx) == '&' || expr.charAt(idx) == '|')) {
            char op = expr.charAt(idx++);
            int[] right = parseAtom();
            left = combine(left, op, right);
        }
        return left;
    }

    private int[] parseAtom() {
        char ch = expr.charAt(idx++);
        if (ch == '(') {
            int[] res = parse();
            idx++; // 跳过 ')'
            return res;
        } else {
            int v = ch - '0';
            return new int[]{v, v, 1 - v}; // val, cost0, cost1
        }
    }

    private int[] combine(int[] a, char op, int[] b) {
        int valA = a[0], valB = b[0];
        int val = (op == '&') ? (valA & valB) : (valA | valB);
        int best0 = Integer.MAX_VALUE, best1 = Integer.MAX_VALUE;

        // 枚举两个操作数的目标值和操作符的所有 8 种组合
        for (int ta = 0; ta <= 1; ta++) {
            for (int tb = 0; tb <= 1; tb++) {
                int ca = (ta == 0) ? a[1] : a[2];
                int cb = (tb == 0) ? b[1] : b[2];
                for (char nop : new char[]{'&', '|'}) {
                    int opCost = (nop == op) ? 0 : 1;
                    int res = (nop == '&') ? (ta & tb) : (ta | tb);
                    int total = ca + cb + opCost;
                    if (res == 0) best0 = Math.min(best0, total);
                    else best1 = Math.min(best1, total);
                }
            }
        }
        return new int[]{val, best0, best1};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，递归栈深度

## 关键点总结

1. 每个子表达式维护 `(val, cost0, cost1)` 三元组
2. 合并时枚举所有 8 种组合（2个目标值 × 2个操作符）
3. 改变操作符也算一次操作，代价为 1
