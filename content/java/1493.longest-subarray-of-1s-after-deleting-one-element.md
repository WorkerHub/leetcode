## 题目描述

给你一个二进制数组 `nums`，你需要从中**删掉一个元素**。

请你在删掉元素的结果数组中，返回最长的**只包含 1 的非空子数组的长度**。

**注意：** 删除操作不可撤销，且**必须恰好删除一个元素**。

**示例 1：**

```
输入：nums = [1,1,0,1]
输出：3
解释：删掉位置 2 的 0，得到 [1,1,1]，最长全 1 子数组长度为 3。
```

**示例 2：**

```
输入：nums = [0,1,1,1,0,1,1,0,1]
输出：5
解释：删掉位置 4 的 0，左边 3 个 1，右边 2 个 1，合计 5。
```

**示例 3：**

```
输入：nums = [1,1,1]
输出：2
解释：必须删除一个元素，最长全 1 子数组长度为 2。
```

**提示：**

- `1 <= nums.length <= 10^5`
- `nums[i]` 不是 `0` 就是 `1`

## 解题思路

**方法一：滑动窗口（推荐，O(n)）**

关键观察：删除一个元素后的最长全 1 子数组，等价于原数组中**最多包含一个 0** 的最长子数组，再减去 1（因为那个 0 被删掉了）。

若原数组全为 1，则必须删一个 1，答案为 `n - 1`。

滑动窗口维护两个指针 `left` 和 `right`，保证窗口 `[left, right]` 内最多有一个 0：
- 若 `nums[right] == 0`，零计数加 1
- 当零计数超过 1 时，移动 `left` 直到窗口内只有一个 0
- 更新答案为 `(right - left + 1) - 1`（窗口大小减去那个 0）

**方法二：动态规划（O(n)）**

定义：
- `dp0`：以当前位置为结尾，不含 0 的最长全 1 子数组长度
- `dp1`：以当前位置为结尾，恰好含 1 个 0 的最长子数组中，1 的个数

转移方程：
- 若 `nums[i] == 1`：`dp0 = dp0 + 1`；`dp1 = dp1 + 1`
- 若 `nums[i] == 0`：`dp1 = dp0`；`dp0 = 0`

答案为 `min(max(dp1), n - 1)`。

**方法三：双指针 + 记录左侧 1 的长度**

枚举每个位置，计算左侧连续 1 的长度和右侧连续 1 的长度，两者相加即为删去该位置后的全 1 段长度。

## Java 代码实现

### 方法一：滑动窗口（推荐）

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int left = 0;        // 窗口左边界
        int zeroCount = 0;   // 窗口内 0 的数量
        int ans = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                zeroCount++;
            }

            // 当窗口内 0 超过 1 个，移动左边界
            while (zeroCount > 1) {
                if (nums[left] == 0) {
                    zeroCount--;
                }
                left++;
            }

            // 窗口大小减 1（删去一个元素）
            // 若窗口内没有 0，也必须删一个 1，仍然是 right - left
            ans = Math.max(ans, right - left);
        }

        return ans;
    }
}
```

### 方法二：动态规划

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int n = nums.length;
        // dp0: 以当前位置结尾，0 个零的最长连续 1 的长度
        // dp1: 以当前位置结尾，1 个零的子数组中连续 1 的总长度
        int dp0 = 0, dp1 = 0;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i] == 1) {
                // 1 延续：两个 dp 都加 1
                dp0++;
                dp1++;
            } else {
                // 遇到 0：dp1 继承 dp0（把这个 0 作为唯一的零）
                dp1 = dp0;
                dp0 = 0;
            }

            // dp1 表示恰好有一个 0 的子数组的 1 的个数
            ans = Math.max(ans, dp1);
        }

        // 必须删除一个元素；若全是 1 则 ans = n，需减 1
        return Math.min(ans, n - 1);
    }
}
```

### 方法三：枚举每个位置（直观易懂）

```java
class Solution {
    public int longestSubarray(int[] nums) {
        int n = nums.length;

        // 预处理：leftOnes[i] 表示 i 往左的连续 1 的长度（不含 i）
        int[] leftOnes = new int[n];
        for (int i = 1; i < n; i++) {
            if (nums[i - 1] == 1) {
                leftOnes[i] = leftOnes[i - 1] + 1;
            }
        }

        // 预处理：rightOnes[i] 表示 i 往右的连续 1 的长度（不含 i）
        int[] rightOnes = new int[n];
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i + 1] == 1) {
                rightOnes[i] = rightOnes[i + 1] + 1;
            }
        }

        // 枚举删除每个位置
        int ans = 0;
        for (int i = 0; i < n; i++) {
            // 删去位置 i，左右连续 1 拼接
            ans = Math.max(ans, leftOnes[i] + rightOnes[i]);
        }

        return ans;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（滑动窗口） | O(n) | O(1) |
| 方法二（动态规划） | O(n) | O(1) |
| 方法三（枚举） | O(n) | O(n) |

## 图解示例

以 `nums = [0,1,1,1,0,1,1,0,1]` 为例，滑动窗口过程：

```
right=0: nums[0]=0, zeroCount=1, 窗口[0,0], 长度=0-0=0
right=4: nums[4]=0, zeroCount=2, 移动left到2, 窗口[2,4], 长度=4-2=2
right=7: nums[7]=0, zeroCount=2, 移动left到5, 窗口[5,7], 长度=7-5=2
...最大为 right=6 时窗口[2,6]或[3,7]等，长度5
```

## 关键点总结

1. **转化问题**：删一个元素后最长全 1 子数组，等价于原数组中至多含 1 个 0 的最长子数组长度减 1。
2. **滑动窗口结果**：`right - left`（不是 `+1`），因为已经减去了那个 0。
3. **全为 1 的特殊情况**：方法一自然处理（窗口内 0 始终为 0，`right - left` 即为 n-1）；方法二用 `Math.min(ans, n-1)` 处理。
4. **DP 空间压缩**：只需记录前一个位置的 dp0/dp1，用两个变量即可。

## 易错点

- **必须删除一个元素**：若数组全为 1，答案是 `n-1`，不是 `n`。
- **滑动窗口长度计算**：窗口大小为 `right - left + 1`，删去一个 0 后为 `right - left`，别写成 `right - left + 1`。
- **DP 转移中 dp1 的含义**：`dp1` 是以当前位置结尾且恰好含 1 个 0 的子数组中 1 的总数，不含那个 0。
