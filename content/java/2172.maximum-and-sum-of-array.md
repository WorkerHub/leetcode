## 题目描述

将n个数放入numSlots个槽（每槽最多2个），最大化每个数与槽编号按位与的总和。

## 解题思路

三进制状态压缩DP：每个槽0/1/2个数字，dp[state]=已放k个数字的最大与和。枚举将nums[k]放入哪个未满槽。

## Java 代码实现

```java
class Solution {
    public int maximumANDSum(int[] nums, int numSlots) {
        int n = nums.length;
        int totalStates = (int) Math.pow(3, numSlots);
        int[] dp = new int[totalStates];
        int ans = 0;
        
        // 预计算3的幂
        int[] pow3 = new int[numSlots + 1];
        pow3[0] = 1;
        for (int i = 1; i <= numSlots; i++) pow3[i] = pow3[i - 1] * 3;
        
        for (int state = 0; state < totalStates; state++) {
            // 计算已放数字数
            int k = 0;
            int s = state;
            for (int i = 0; i < numSlots; i++) {
                k += s % 3;
                s /= 3;
            }
            if (k >= n) continue;
            
            // 枚举将nums[k]放入哪个槽
            s = state;
            for (int slot = 0; slot < numSlots; slot++) {
                int digit = s % 3;
                s /= 3;
                if (digit < 2) {
                    int newState = state + pow3[slot];
                    int gain = nums[k] & (slot + 1);
                    if (dp[state] + gain > dp[newState]) {
                        dp[newState] = dp[state] + gain;
                        ans = Math.max(ans, dp[newState]);
                    }
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(3^S * S)，S=numSlots<=9
- **空间复杂度**：O(3^S)

## 关键点总结

1. **三进制状态**：每槽0/1/2，共3^numSlots个状态
2. **已放数字数=各位之和**：确定当前应放nums[k]
3. **槽编号从1开始**：gain = nums[k] & (slot+1)
