## 题目描述

巨无霸汉堡需 4 片番茄 + 2 片奶酪，小汉堡需 2 片番茄 + 1 片奶酪。给定番茄和奶酪总片数，求刚好用完的方案 [巨无霸数, 小汉堡数]，无解返回空。

**示例：**
```
输入：tomatoSlices = 16, cheeseSlices = 7
输出：[1,6]
```

## 解题思路

解二元一次方程：4x + 2y = t, x + y = c → x = (t - 2c) / 2, y = c - x。验证非负整数。

## Java 代码实现

```java
class Solution {
    public List<Integer> numOfBurgers(int tomatoSlices, int cheeseSlices) {
        // 4x + 2y = t, x + y = c
        // x = (t - 2c) / 2, y = c - x
        int t = tomatoSlices, c = cheeseSlices;
        if ((t - 2 * c) % 2 != 0) return new ArrayList<>();
        int x = (t - 2 * c) / 2;
        int y = c - x;
        if (x < 0 || y < 0) return new ArrayList<>();
        return Arrays.asList(x, y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **解方程**：两个等式两个未知数
2. **整数检查**：(t - 2c) 必须为偶数
3. **非负检查**：x >= 0 且 y >= 0
