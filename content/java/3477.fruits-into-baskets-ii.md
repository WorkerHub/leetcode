## 题目描述

给你整数数组 `fruits` 和整数 `k`，每个篮子最多装 k 个同种水果，每次遇到一种水果放入该种现有未满篮子（若满则开新篮子），返回所需最少篮子数。

## 解题思路

模拟：用哈希表记录每种水果当前活跃篮子的剩余容量。遇到该种水果时：若有剩余容量则减一；否则开新篮子并重置剩余容量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int numBaskets(int[] fruits, int k) {
        // 记录每种水果当前活跃篮子的剩余容量
        Map<Integer, Integer> remaining = new HashMap<>();
        int baskets = 0;

        for (int f : fruits) {
            int rem = remaining.getOrDefault(f, 0);
            if (rem == 0) {
                // 开新篮子
                baskets++;
                remaining.put(f, k - 1);
            } else {
                remaining.put(f, rem - 1);
            }
        }

        return baskets;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(m)，m 为不同水果种类数

## 关键点总结

1. 每种水果独立管理篮子，只需记录当前活跃篮子的剩余容量
2. 剩余容量为 0 时需开新篮子（而非 -1）
3. 不同种类水果之间互不干扰
