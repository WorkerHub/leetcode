## 题目描述

同3034但n,m扩大到10^6，必须用KMP算法O(N+M)匹配。

## 解题思路

将nums转为差分符号数组后，用KMP在其中匹配pattern。

## Java 代码实现

```java
class Solution {
    public int countMatchingSubarrays(int[] nums, int[] pattern) {
        int n = nums.length, m = pattern.length;
        int[] diff = new int[n - 1];
        for (int i = 0; i < n - 1; i++) {
            diff[i] = Integer.compare(nums[i + 1], nums[i]);
        }

        // KMP失配表
        int[] fail = new int[m];
        int j = 0;
        for (int i = 1; i < m; i++) {
            while (j > 0 && pattern[i] != pattern[j]) j = fail[j - 1];
            if (pattern[i] == pattern[j]) j++;
            fail[i] = j;
        }

        // KMP匹配
        int count = 0;
        j = 0;
        for (int x : diff) {
            while (j > 0 && x != pattern[j]) j = fail[j - 1];
            if (x == pattern[j]) j++;
            if (j == m) {
                count++;
                j = fail[j - 1];
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N+M)
- **空间复杂度**：O(N+M)

## 关键点总结

1. **KMP保证O(N+M)**：失配函数避免重复比较
2. **差分符号转换**：Integer.compare返回-1/0/1
3. **匹配后回退**：j=fail[j-1]继续搜索
