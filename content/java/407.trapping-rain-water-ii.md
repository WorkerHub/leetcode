## 题目描述

给你一个 m x n 的矩阵，其中的值均为非负整数，代表二维高度图每个单元的高度，请计算图中形状最多能接多少体积的雨水。

**示例 1：**
```
输入: heightMap = [[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]
输出: 4
解释: 下雨后，雨水将会被上图蓝色的方块中。总的接雨水量为 1+2+1=4。
```

**示例 2：**
```
输入: heightMap = [[3,3,3,3,3],[3,2,2,2,3],[3,2,1,2,3],[3,2,2,2,3],[3,3,3,3,3]]
输出: 10
```

**提示：**
- m == heightMap.length
- n == heightMap[i].length
- 1 <= m, n <= 200
- 0 <= heightMap[i][j] <= 2 * 10^4

## 解题思路

这道题是 [42. Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/) 的二维扩展，难度更高。

核心思想：
1. 水能否留在某个位置，取决于周围的"最短板"（类似木桶原理）
2. 从外围向内部推进，使用优先队列（最小堆）维护边界
3. 水位由周围已访问的最低边界决定

算法流程（优先队列 BFS）：
1. 将矩阵的所有边界点加入最小堆
2. 每次从堆中取出高度最小的点（当前水位）
3. 访问其相邻的未访问点：
   - 如果相邻点高度 < 当前水位，可以蓄水
   - 更新相邻点的有效高度为 max(相邻点高度, 当前水位)
4. 将相邻点加入堆，继续处理

关键观察：
- 水从外围向内流，外围是边界
- 使用最小堆保证总是从最低的边界开始
- 已访问的点形成新的边界

## Java 代码实现

### 方法一：优先队列 BFS（推荐）

```java
import java.util.PriorityQueue;

class Solution {
    public int trapRainWater(int[][] heightMap) {
        if (heightMap == null || heightMap.length == 0 || heightMap[0].length == 0) {
            return 0;
        }

        int m = heightMap.length, n = heightMap[0].length;
        // 矩阵太小，无法蓄水
        if (m < 3 || n < 3) return 0;

        // 最小堆：[高度, 行索引, 列索引]
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        // 访问标记
        boolean[][] visited = new boolean[m][n];

        // 将所有边界点加入堆
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 第一行、最后一行、第一列、最后一列
                if (i == 0 || i == m - 1 || j == 0 || j == n - 1) {
                    heap.offer(new int[]{heightMap[i][j], i, j});
                    visited[i][j] = true;
                }
            }
        }

        // 四个方向
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int water = 0;

        // BFS 处理
        while (!heap.isEmpty()) {
            // 取出当前最低的边界点
            int[] curr = heap.poll();
            int height = curr[0], x = curr[1], y = curr[2];

            // 检查四个方向的相邻点
            for (int[] dir : directions) {
                int nx = x + dir[0], ny = y + dir[1];

                // 边界检查和访问检查
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && !visited[nx][ny]) {
                    visited[nx][ny] = true;

                    // 如果相邻点低于当前边界，可以蓄水
                    if (heightMap[nx][ny] < height) {
                        water += height - heightMap[nx][ny];
                    }

                    // 将相邻点加入堆
                    // 新的边界高度是 max(原高度, 当前水位)
                    heap.offer(new int[]{Math.max(heightMap[nx][ny], height), nx, ny});
                }
            }
        }

        return water;
    }
}
```

### 方法二：详细注释版

```java
import java.util.PriorityQueue;

class Solution {
    public int trapRainWater(int[][] heightMap) {
        if (heightMap == null || heightMap.length == 0 || heightMap[0].length == 0) {
            return 0;
        }

        int m = heightMap.length, n = heightMap[0].length;

        // 矩阵太小，无法蓄水
        if (m < 3 || n < 3) return 0;

        // 最小堆存储边界点，按高度排序
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        boolean[][] visited = new boolean[m][n];

        // 步骤 1：初始化边界
        // 将矩阵外围一圈的所有点加入堆
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                boolean isBorder = (i == 0 || i == m - 1 || j == 0 || j == n - 1);
                if (isBorder) {
                    minHeap.offer(new int[]{heightMap[i][j], i, j});
                    visited[i][j] = true;
                }
            }
        }

        int totalWater = 0;
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

        // 步骤 2：从最低边界开始向内推进
        while (!minHeap.isEmpty()) {
            // 当前最低边界点
            int[] curr = minHeap.poll();
            int currentHeight = curr[0], row = curr[1], col = curr[2];

            // 步骤 3：检查四个相邻点
            for (int[] dir : directions) {
                int newRow = row + dir[0], newCol = col + dir[1];

                // 检查是否在边界内且未访问
                if (newRow >= 0 && newRow < m && newCol >= 0 && newCol < n
                        && !visited[newRow][newCol]) {

                    visited[newRow][newCol] = true;
                    int neighborHeight = heightMap[newRow][newCol];

                    // 步骤 4：计算蓄水量
                    // 如果相邻点低于当前水位，可以蓄水
                    if (neighborHeight < currentHeight) {
                        totalWater += currentHeight - neighborHeight;
                    }

                    // 步骤 5：更新边界
                    // 新边界的有效高度是两者较大值
                    int newBoundaryHeight = Math.max(neighborHeight, currentHeight);
                    minHeap.offer(new int[]{newBoundaryHeight, newRow, newCol});
                }
            }
        }

        return totalWater;
    }
}
```

### 方法三：使用辅助方法封装

```java
import java.util.PriorityQueue;

class Solution {
    private int m, n;
    private int[][] heightMap;
    private boolean[][] visited;

    public int trapRainWater(int[][] heightMap) {
        if (heightMap == null || heightMap.length == 0 || heightMap[0].length == 0) {
            return 0;
        }

        this.m = heightMap.length;
        this.n = heightMap[0].length;
        this.heightMap = heightMap;
        this.visited = new boolean[m][n];

        if (m < 3 || n < 3) return 0;

        // 初始化边界堆
        PriorityQueue<int[]> heap = initBorders();

        // BFS 计算蓄水量
        return bfs(heap);
    }

    /** 初始化边界点 */
    private PriorityQueue<int[]> initBorders() {
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (isBorder(i, j)) {
                    heap.offer(new int[]{heightMap[i][j], i, j});
                    visited[i][j] = true;
                }
            }
        }
        return heap;
    }

    /** 判断是否是边界点 */
    private boolean isBorder(int i, int j) {
        return i == 0 || i == m - 1 || j == 0 || j == n - 1;
    }

    /** BFS 计算蓄水量 */
    private int bfs(PriorityQueue<int[]> heap) {
        int water = 0;
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

        while (!heap.isEmpty()) {
            int[] curr = heap.poll();
            int height = curr[0], x = curr[1], y = curr[2];

            for (int[] dir : directions) {
                int nx = x + dir[0], ny = y + dir[1];

                if (isValid(nx, ny)) {
                    visited[nx][ny] = true;

                    if (heightMap[nx][ny] < height) {
                        water += height - heightMap[nx][ny];
                    }

                    heap.offer(new int[]{Math.max(heightMap[nx][ny], height), nx, ny});
                }
            }
        }

        return water;
    }

    /** 检查坐标是否有效且未访问 */
    private boolean isValid(int i, int j) {
        return i >= 0 && i < m && j >= 0 && j < n && !visited[i][j];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n * log(m * n))
  - 每个点最多入堆一次：m * n 个点
  - 每次堆操作：O(log(m * n))

- **空间复杂度**：O(m * n)
  - visited 数组：O(m * n)
  - 堆的大小：最多 O(m * n)

## 图解示例

以 `heightMap = [[3,3,3,3,3],[3,2,2,2,3],[3,2,1,2,3],[3,2,2,2,3],[3,3,3,3,3]]` 为例：

```
初始矩阵（边界用 * 标记）：
*3  *3  *3  *3  *3
*3   2   2   2  *3
*3   2   1   2  *3
*3   2   2   2  *3
*3  *3  *3  *3  *3

步骤 1：边界高度都是 3，形成围墙

步骤 2：从边界向内推进
- 遇到高度 2 的点，当前水位是 3，不蓄水（2 < 3 但会被更新为 3）
- 继续向内，遇到高度 1 的点，当前水位是 3，蓄水 3-1=2

最终蓄水示例：
3  3  3  3  3
3  3  3  3  3  <- 这层高度为 3（原来是 2）
3  3  3  3  3  <- 中心点高度 1 + 蓄水 2 = 3
3  3  3  3  3
3  3  3  3  3

蓄水量计算：
- 四个角的 2：每个蓄水 1，共 4 个
- 中心的 1：蓄水 2
- 四条边的 2：每个蓄水 1，共 4 个
- 总计：4*1 + 2 + 4*1 = 10
```

## 关键点总结

1. **木桶原理**：水位由周围最低的边界决定
2. **从外向内**：从边界开始，逐步向内部推进
3. **最小堆**：保证总是从最低的边界开始处理
4. **高度更新**：新边界的有效高度是 max(原高度, 当前水位)
5. **BFS 思想**：逐层扩展，已访问的点形成新边界

## 易错点

1. **边界初始化**：
   - 必须将整个外围一圈都加入堆
   - 不能只加入四个角

2. **高度更新**：
   - 新边界高度是 `Math.max(neighborHeight, currentHeight)`
   - 不能直接使用 neighborHeight

3. **蓄水条件**：
   - 只有当 `neighborHeight < currentHeight` 时才蓄水
   - 蓄水量是两者之差

4. **访问标记**：
   - 必须标记已访问的点，避免重复处理
   - 标记时机：加入堆时立即标记（不是出堆时）

5. **边界情况**：
   - 矩阵小于 3x3 时无法蓄水
   - 空矩阵的处理
