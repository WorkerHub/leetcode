## 题目描述

给你活塞高度数组 `heights`、方向数组 `directions`（'U'/'D'）和上界 `maxVal`，活塞碰到 0 或 maxVal 时反弹。返回任意时刻所有活塞高度之和的最大值。

## 解题思路

活塞位置之和的变化率只在碰到边界时改变。用差分字典记录各时刻变化率的改变量，遍历关键事件，在每段等速区间中取最大值（若变化率>0则终点最大，否则起点最大）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumTotalAreaOccupied(int[] heights, String[] directions, int maxVal) {
        int n = heights.length;
        TreeMap<Integer, Integer> diff = new TreeMap<>();

        long initChange = 0;
        long initSum = 0;
        for (int i = 0; i < n; i++) {
            initSum += heights[i];
            if (directions[i].equals("U")) {
                initChange++;
                // 碰到 maxVal 的时刻
                int t = maxVal - heights[i];
                diff.merge(t, -2, Integer::sum);
                // 碰到 0 的时刻
                diff.merge(2 * maxVal - heights[i], 2, Integer::sum);
            } else {
                initChange--;
                // 碰到 0 的时刻
                diff.merge(heights[i], 2, Integer::sum);
                // 碰到 maxVal 的时刻
                diff.merge(heights[i] + maxVal, -2, Integer::sum);
            }
        }

        long curSum = initSum;
        long curChange = initChange;
        long maxSum = curSum;
        int prevT = 0;

        for (Map.Entry<Integer, Integer> entry : diff.entrySet()) {
            int t = entry.getKey();
            // [prevT, t) 这段时间内 change 不变
            if (curChange > 0) {
                maxSum = Math.max(maxSum, curSum + curChange * (t - prevT - 1));
            }
            maxSum = Math.max(maxSum, curSum);
            curSum += curChange * (t - prevT);
            curChange += entry.getValue();
            prevT = t;
        }
        maxSum = Math.max(maxSum, curSum);
        return maxSum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，TreeMap 插入和遍历
- 空间复杂度：O(n)

## 关键点总结

1. 活塞总和的变化率只在碰到边界时改变，用差分跳过无事件时间段
2. 每个上移活塞在 `maxVal-h` 时刻反弹（变化率 -2），在 `2*maxVal-h` 时刻再次反弹
3. 在每段等速区间，若变化率为正则末尾最大，否则起点最大
