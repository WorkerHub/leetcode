## 题目描述

给定整数数组 `nums` 和正整数 `k`。每次操作将任意元素减 1，求最少操作次数使数组之和能被 `k` 整除。

## 解题思路

数组和 `s` 对 `k` 取余得 `r = s % k`，需减少 `r` 次（每次减 1）使和被 `k` 整除，答案直接为 `s % k`。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int s = 0;
        for (int x : nums) s += x;
        return s % k;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只能减少，最少操作数 = `sum % k`
2. 若 `sum % k == 0` 则返回 0
