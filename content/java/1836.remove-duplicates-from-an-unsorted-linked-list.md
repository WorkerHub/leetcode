## 题目描述

删除未排序链表中所有出现不止一次的节点。

## 解题思路

两次遍历：第一次统计频率，第二次用哑节点跳过频率>1的节点。

## Java 代码实现

```java
class Solution {
    public ListNode deleteDuplicatesUnsorted(ListNode head) {
        // 第一次遍历统计频率
        Map<Integer, Integer> freq = new HashMap<>();
        ListNode node = head;
        while (node != null) {
            freq.merge(node.val, 1, Integer::sum);
            node = node.next;
        }
        
        // 第二次遍历删除重复节点
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy, curr = head;
        while (curr != null) {
            if (freq.get(curr.val) > 1) {
                prev.next = curr.next; // 跳过
            } else {
                prev = curr; // 保留
            }
            curr = curr.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **未排序链表**：不能只比较相邻，需全局统计频率
2. **哑节点**：简化头节点可能被删除的处理
3. **两次遍历**：先统计后删除
