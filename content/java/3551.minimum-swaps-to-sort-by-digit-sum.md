## 题目描述

给定一个整数数组 `nums`，定义排序规则：首先按各位数字之和升序排列，各位数字之和相同时按数值本身升序排列。求将 `nums` 按此规则排序所需的最少交换次数。

## 解题思路

1. 按目标规则排序，得到目标排列的下标映射
2. 最少交换次数 = n - 置换中循环的个数，等价于 sum(cycle_length - 1)
3. 用哈希表处理重复元素，同值元素按原顺序一一对应

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int digitSum(int x) {
        int s = 0;
        while (x > 0) { s += x % 10; x /= 10; }
        return s;
    }

    public int minSwaps(int[] nums) {
        int n = nums.length;
        // 按目标规则对下标排序
        Integer[] indexed = new Integer[n];
        for (int i = 0; i < n; i++) indexed[i] = i;
        Arrays.sort(indexed, (a, b) -> {
            int da = digitSum(nums[a]), db = digitSum(nums[b]);
            if (da != db) return da - db;
            return nums[a] - nums[b];
        });

        // indexed[i] = 原数组中排序后第 i 位应放的元素的原始索引
        // 计算置换循环数
        boolean[] visited = new boolean[n];
        int swaps = 0;
        for (int i = 0; i < n; i++) {
            if (visited[i] || indexed[i] == i) continue;
            int cycle = 0, j = i;
            while (!visited[j]) {
                visited[j] = true;
                j = indexed[j];
                cycle++;
            }
            swaps += cycle - 1;
        }

        return swaps;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 自定义排序键：(数字之和, 数值本身)
2. 最少交换次数 = sum(cycle_length - 1)
3. 置换分析：原位置到目标位置的映射
