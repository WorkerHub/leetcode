## 题目描述

给你两个整数数组 `lane1` 和 `lane2`，代表两条车道上的硬币分布（正数表示硬币，负数表示障碍/损失）。你驾驶一辆车，从最左边出发，最多换一次车道，求可以收集到的最大硬币数。

## 解题思路

DP：维护两组状态——`dp_ns[j]`（在车道 j，未换过道的最大收益）和 `dp_sw[j]`（在车道 j，已换过一次道的最大收益）。逐位置更新：不换道则继续在同侧累加；换道则从另一侧的未换状态转移。

## Java 代码实现

```java
class Solution {
    public long maxCoins(int[] lane1, int[] lane2) {
        int n = lane1.length;
        long NEG_INF = Long.MIN_VALUE / 2;

        // dp_ns[j]: 在车道 j，未换过道的最大收益
        // dp_sw[j]: 在车道 j，已换过一次道的最大收益
        long[] dp_ns = {lane1[0], lane2[0]};
        long[] dp_sw = {lane1[0], lane2[0]};

        long ans = Math.max(dp_ns[0], dp_ns[1]);

        for (int i = 1; i < n; i++) {
            long[] new_ns = {NEG_INF, NEG_INF};
            long[] new_sw = {NEG_INF, NEG_INF};
            int[] val = {lane1[i], lane2[i]};

            for (int j = 0; j < 2; j++) {
                // 继续在车道 j（未换道）
                if (dp_ns[j] != NEG_INF)
                    new_ns[j] = Math.max(new_ns[j], dp_ns[j] + val[j]);
                // 在位置 i 换道（第一次）：从 1-j 换到 j
                if (dp_ns[1 - j] != NEG_INF)
                    new_sw[j] = Math.max(new_sw[j], dp_ns[1 - j] + val[j]);
                // 已换道后继续在车道 j
                if (dp_sw[j] != NEG_INF)
                    new_sw[j] = Math.max(new_sw[j], dp_sw[j] + val[j]);
            }

            dp_ns = new_ns;
            dp_sw = new_sw;
            ans = Math.max(ans, Math.max(Math.max(dp_ns[0], dp_ns[1]),
                                         Math.max(dp_sw[0], dp_sw[1])));
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（滚动数组）

## 关键点总结

1. 两个状态维度：当前车道 + 是否已换道
2. 换道只能发生一次，换道后状态从"未换"转为"已换"
3. 使用 `long` 防止累加溢出
