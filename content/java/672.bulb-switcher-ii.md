## 题目描述

n 盏灯初始全开，4 种按钮分别翻转：所有灯、偶数灯、奇数灯、3k+1 灯。按 presses 次后，返回可能的灯状态数量。

**示例：**
```
输入：n = 3, presses = 1
输出：4
```

## 解题思路

数学分析：按同一按钮两次等于没按（异或），前3个灯可代表整个序列状态。按 n 和 presses 分类讨论。

## Java 代码实现

```java
class Solution {
    public int flipLights(int n, int presses) {
        if (presses == 0) return 1;

        if (n == 1) return 2;

        if (n == 2) {
            return presses == 1 ? 3 : 4;
        }

        // n >= 3
        if (presses == 1) return 4;
        if (presses == 2) return 7;
        return 8;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **异或性质**：按两次等于不按
2. **前缀代表**：前3个灯的状态代表整个序列
3. **分类讨论**：按 n 和 presses 大小分情况
