## 题目描述

给你整数数组 `workers`、二维数组 `tasks`（`tasks[i] = [需求技能, 利润]`），每个工人最多完成一个技能等级不超过自身的任务，返回最大总利润。

## 解题思路

排序 + 最小堆：将工人按技能从小到大遍历，对每个工人将其能完成的任务利润加入最大堆，每次从堆中取出利润最大的任务分配。最小堆用负值模拟最大堆。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxProfit(int[] workers, int[][] tasks, int[] profits) {
        int n = workers.length, m = tasks.length;

        // 按任务需求技能排序，合并 tasks 和 profits
        Integer[] taskIdx = new Integer[m];
        for (int i = 0; i < m; i++) taskIdx[i] = i;
        Arrays.sort(taskIdx, (a, b) -> tasks[a][0] - tasks[b][0]);

        int[] sortedWorkers = workers.clone();
        Arrays.sort(sortedWorkers);

        // 最大堆（存利润）
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        long total = 0;
        int j = 0;

        for (int w : sortedWorkers) {
            // 将当前工人能完成的所有任务加入堆
            while (j < m && tasks[taskIdx[j]][0] <= w) {
                maxHeap.offer(profits[taskIdx[j]]);
                j++;
            }
            // 选利润最大的任务
            if (!maxHeap.isEmpty()) {
                total += maxHeap.poll();
            }
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log m)，排序和堆操作
- 空间复杂度：O(m)

## 关键点总结

1. 贪心：工人从小到大遍历，逐步扩大可选任务集合
2. 最大堆始终从当前可选任务中贪心选利润最大的
3. 每个任务只被选一次，堆弹出后自动标记为已用
