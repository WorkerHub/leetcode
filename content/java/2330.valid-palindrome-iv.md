## 题目描述

给你字符串 `s`，最多可以修改任意两个字符，判断是否能使 `s` 变成回文串。

## 解题思路

双指针从两端向中间扫描，统计左右字符不相等的对数。若不匹配对数不超过 2，则可通过最多 2 次修改变为回文。

## Java 代码实现

```java
class Solution {
    public boolean makePalindrome(String s) {
        int left = 0, right = s.length() - 1, diff = 0;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                diff++;
                if (diff > 2) return false; // 提前剪枝
            }
            left++;
            right--;
        }
        return true; // 不匹配对数 <= 2
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每次修改一个字符可消除一对不匹配，不匹配对数 <= 2 即满足条件。
2. 奇数长度的中间字符无需配对，自动忽略。
3. 超过 2 对立即返回 false，避免遍历完整字符串。
