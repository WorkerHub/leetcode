## 题目描述

给定 `m x n` 棋盘，每次可选一行或一列将所有元素减 1，格子变 0 被清除，返回清除所有格子的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[][] board) {
        int m = board.length, n = board[0].length;
        // 策略一：行操作数 = 行最大值，列操作补足
        int res1 = 0;
        int[] rowOps = new int[m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) rowOps[i] = Math.max(rowOps[i], board[i][j]);
            res1 += rowOps[i];
        }
        for (int j = 0; j < n; j++) {
            int colNeed = 0;
            for (int i = 0; i < m; i++) colNeed = Math.max(colNeed, Math.max(0, board[i][j] - rowOps[i]));
            res1 += colNeed;
        }
        // 策略二：列操作数 = 列最大值，行操作补足
        int res2 = 0;
        int[] colOps = new int[n];
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) colOps[j] = Math.max(colOps[j], board[i][j]);
            res2 += colOps[j];
        }
        for (int i = 0; i < m; i++) {
            int rowNeed = 0;
            for (int j = 0; j < n; j++) rowNeed = Math.max(rowNeed, Math.max(0, board[i][j] - colOps[j]));
            res2 += rowNeed;
        }
        return Math.min(res1, res2);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m + n)

## 关键点总结

1. 每个格子 `(i,j)` 满足 `rowOps[i] + colOps[j] >= board[i][j]`
2. 两种贪心策略：先确定行操作量或先确定列操作量，取最优
3. 补足量 = `max(0, board[i][j] - rowOps[i])`（不能为负）
