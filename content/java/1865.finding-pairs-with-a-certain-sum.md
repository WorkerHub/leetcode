## 题目描述

设计数据结构支持：add(index, val)给nums2[index]加val；count(tot)返回nums1[i]+nums2[j]==tot的数对数。

## 解题思路

对较长的nums2维护频率哈希表，count时遍历较短的nums1查询freq[tot-x]。add时同步更新频率表。

## Java 代码实现

```java
class FindSumPairs {
    private int[] nums1;
    private int[] nums2;
    private Map<Integer, Integer> freq2;

    public FindSumPairs(int[] nums1, int[] nums2) {
        this.nums1 = nums1;
        this.nums2 = nums2;
        this.freq2 = new HashMap<>();
        for (int x : nums2) {
            freq2.merge(x, 1, Integer::sum);
        }
    }

    public void add(int index, int val) {
        // 先减旧值频率
        freq2.merge(nums2[index], -1, Integer::sum);
        nums2[index] += val;
        // 再加新值频率
        freq2.merge(nums2[index], 1, Integer::sum);
    }

    public int count(int tot) {
        int result = 0;
        for (int x : nums1) {
            result += freq2.getOrDefault(tot - x, 0);
        }
        return result;
    }
}
```

## 复杂度分析

- **add**：O(1)
- **count**：O(len(nums1))
- **空间复杂度**：O(len(nums2))

## 关键点总结

1. **哈希表维护频率**：对较长数组建表，遍历较短数组查询
2. **add同步更新**：先减旧值再加新值
3. **时间权衡**：nums1短(≤1000)，count遍历它即可
