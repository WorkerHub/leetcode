## 题目描述

给你字符串 s，如果 s 中存在长度为 2 的子字符串同时也是 s 反转字符串的子字符串，则返回 true，否则返回 false。

## 解题思路

收集 s 中所有长度为 2 的子字符串，检查是否存在某个子串的反转也在集合中（即 s 中同时含有 "ab" 和 "ba" 的情况）。

## Java 代码实现

```java
class Solution {
    public boolean isSubstringPresent(String s) {
        // 收集所有长度为 2 的子字符串
        Set<String> set = new HashSet<>();
        for (int i = 0; i + 1 < s.length(); i++) {
            set.add(s.substring(i, i + 2));
        }
        // 检查是否有某子串的反转也在集合中
        for (String sub : set) {
            String rev = "" + sub.charAt(1) + sub.charAt(0);
            if (set.contains(rev)) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 个长度为 2 的子字符串，每次检查 O(1)
- **空间复杂度**：O(n)，存储子字符串集合

## 关键点总结

1. 长度为 2 的子字符串最多 26^2 = 676 种
2. "ab" 在反转字符串中 = "ba" 在原字符串中
3. 用集合存储所有长度为 2 的子串，O(1) 查询
