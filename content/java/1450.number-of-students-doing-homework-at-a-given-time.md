## 题目描述

给你两个整数数组 `startTime`（开始时间）和 `endTime`（结束时间），以及整数 `queryTime`（查询时间）。

第 `i` 名学生在 `startTime[i]` 时开始做作业，并于 `endTime[i]` 时完成。

返回在时间 `queryTime` 时正在做作业的学生人数。形式上，返回能够使 `startTime[i] <= queryTime <= endTime[i]` 成立的学生人数。

**示例 1：**
```
输入：startTime = [1,2,3], endTime = [3,2,7], queryTime = 4
输出：1
解释：一共有 3 名学生。
第一名学生在时间 1 开始做作业，并于时间 3 完成。
第二名学生在时间 2 开始做作业，并于时间 2 完成。
第三名学生在时间 3 开始做作业，并于时间 7 完成。
在时间 4，只有第三名学生在做作业。
```

**示例 2：**
```
输入：startTime = [4], endTime = [4], queryTime = 4
输出：1
解释：在查询时间 4，唯一一名学生在做作业。
```

**提示：**
- `startTime.length == endTime.length`
- `1 <= startTime.length <= 100`
- `1 <= startTime[i] <= endTime[i] <= 1000`
- `1 <= queryTime <= 1000`

## 解题思路

这道题非常直接：遍历每名学生，检查查询时间是否在该学生的作业时间段内（即 `startTime[i] <= queryTime <= endTime[i]`），满足条件则计数加一。

## Java 代码实现

### 方法一：直接遍历（推荐）

```java
class Solution {
    public int busyStudent(int[] startTime, int[] endTime, int queryTime) {
        int count = 0;
        for (int i = 0; i < startTime.length; i++) {
            // 判断 queryTime 是否在学生的作业时间区间内
            if (startTime[i] <= queryTime && queryTime <= endTime[i]) {
                count++;
            }
        }
        return count;
    }
}
```

### 方法二：差分数组（了解思路，适合大量查询场景）

```java
class Solution {
    public int busyStudent(int[] startTime, int[] endTime, int queryTime) {
        // 差分数组方法：适合多次查询的场景
        int maxTime = 0;
        for (int e : endTime) maxTime = Math.max(maxTime, e);

        int[] diff = new int[maxTime + 2];
        for (int i = 0; i < startTime.length; i++) {
            diff[startTime[i]]++;      // 在 s 时刻开始一个学生
            diff[endTime[i] + 1]--;    // 在 e+1 时刻结束
        }

        // 前缀和还原每个时刻的在读人数
        int current = 0;
        for (int t = 0; t <= maxTime; t++) {
            current += diff[t];
            if (t == queryTime) return current;
        }

        return 0;
    }
}
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，n 为学生数量
- 空间复杂度：O(1)

**方法二（差分数组）：**
- 时间复杂度：O(n + max_time)
- 空间复杂度：O(max_time)
- 适用场景：有大量查询时，预处理后每次查询 O(1)

## 关键点总结

1. 核心条件：`startTime[i] <= queryTime && queryTime <= endTime[i]` 同时成立
2. 对于单次查询，直接遍历即可；多次查询可考虑差分数组
3. 注意区间是**闭区间**，两端均包含（`<=` 而非 `<`）

## 易错点

- 注意区间是**闭区间**，两端均包含（`<=` 而非 `<`）
- 不要误写成 `startTime[i] < queryTime && queryTime < endTime[i]`（漏掉等号情况）
