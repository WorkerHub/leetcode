## 题目描述

给定两个等长字符串 `s` 和 `t`，每次操作可将 `s` 中某个字符改为下一个字母（循环），或将某个子串循环移位（末字符移到首），求将 `s` 变为 `t` 的最少操作次数。

## Java 代码实现

```java
class Solution {
    private String s, t;
    private int n;
    private Integer[][] memo;

    public int minOperations(String s, String t) {
        this.s = s;
        this.t = t;
        this.n = s.length();
        this.memo = new Integer[n][n];
        return dp(0, n - 1);
    }

    // 将 s[i..j] 变为 t[i..j] 的最少操作数
    private int dp(int i, int j) {
        if (i > j) return 0;
        if (memo[i][j] != null) return memo[i][j];

        // 方法1：逐字符修改 s[i]
        int res = charDist(s.charAt(i), t.charAt(i)) + dp(i + 1, j);

        // 方法2：对子串 s[i..k] 做一次循环移位，移位后 s[k] 移到 s[i] 位置
        for (int k = i; k <= j; k++) {
            // 循环移位后 s[i..k] 变为 s[k] + s[i..k-1]
            int costAfter = charDist(s.charAt(k), t.charAt(i));
            for (int p = i; p < k; p++) {
                costAfter += charDist(s.charAt(p), t.charAt(p + 1));
            }
            res = Math.min(res, 1 + costAfter + dp(k + 1, j));
        }

        return memo[i][j] = res;
    }

    // 字符 a 变为字符 b 需要的步数（向前循环）
    private int charDist(char a, char b) {
        return (b - a + 26) % 26;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)，区间 DP 共 O(n^2) 状态，每个状态枚举 O(n) 个移位
- 空间复杂度：O(n^2)，记忆化数组

## 关键点总结

1. 区间 DP 处理字符串转换，状态为 `dp[i][j]` = 将 `s[i..j]` 变为 `t[i..j]` 的代价
2. 循环移位操作将末字符移到开头，代价为 1 加上后续逐字符修改代价
3. 字符距离用 `(b - a + 26) % 26` 计算循环前向距离
