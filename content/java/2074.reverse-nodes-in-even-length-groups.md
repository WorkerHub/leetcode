## 题目描述

链表分组，第 i 组预期包含 i 个节点（最后一组可能不足），对所有实际长度为偶数的组反转，返回修改后的链表。

## 解题思路

逐组遍历，计算每组实际长度，若为偶数则反转该组（标准链表反转，注意保存组后指针）。

## Java 代码实现

### 方法一：逐组处理（推荐）

```java
class Solution {
    public ListNode reverseEvenLengthGroups(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy;
        int groupSize = 1;

        while (prev.next != null) {
            // 计算实际组大小
            int actualSize = 0;
            ListNode node = prev.next;
            while (node != null && actualSize < groupSize) {
                node = node.next;
                actualSize++;
            }
            // 偶数长度则反转
            if (actualSize % 2 == 0) {
                prev.next = reverseGroup(prev.next, actualSize);
            }
            // 移到本组末尾
            for (int i = 0; i < actualSize; i++) prev = prev.next;
            groupSize++;
        }
        return dummy.next;
    }

    private ListNode reverseGroup(ListNode start, int size) {
        // 找组尾，保存组后节点
        ListNode tail = start;
        for (int i = 0; i < size - 1; i++) tail = tail.next;
        ListNode after = tail.next;
        // 反转
        ListNode prevNode = after, cur = start;
        for (int i = 0; i < size; i++) {
            ListNode nxt = cur.next;
            cur.next = prevNode;
            prevNode = cur;
            cur = nxt;
        }
        return prevNode; // 新头节点
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每组实际大小可能小于预期（最后一组）
2. 反转时需保存组后节点作为新尾的 next
