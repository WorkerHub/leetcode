## 题目描述

给定二进制字符串 `s`，每次可将 `"00"` 替换为 `"10"`（任意次），返回字典序最大的结果。

## Java 代码实现

```java
class Solution {
    public String maximumBinaryString(String s) {
        int n = s.length();
        // 找第一个 '0' 的位置
        int firstZero = s.indexOf('0');
        if (firstZero == -1) return s; // 全是 '1'

        // 统计从 firstZero 到末尾的 '0' 个数
        int countZeros = 0;
        for (int i = firstZero; i < n; i++) if (s.charAt(i) == '0') countZeros++;

        // 结果：firstZero + (countZeros-1) 个 '1' + '0' + 剩余 '1'
        StringBuilder sb = new StringBuilder();
        int onesBeforeZero = firstZero + countZeros - 1;
        for (int i = 0; i < onesBeforeZero; i++) sb.append('1');
        sb.append('0');
        for (int i = onesBeforeZero + 1; i < n; i++) sb.append('1');
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 操作 "00"→"10" 相当于将 '0' 向右移动，消耗一个 '0' 变为 '1'
2. 最终只剩一个 '0'，位于 `firstZero + countZeros - 1` 处
3. 第一个 '0' 之前的 '1' 不受影响
