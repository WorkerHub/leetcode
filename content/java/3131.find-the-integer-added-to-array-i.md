## 题目描述

找整数x使得nums1每个元素加x后与nums2相同（不计顺序）。

## 解题思路

x = min(nums2) - min(nums1)，因为加x不改变相对大小。

## Java 代码实现

```java
class Solution {
    public int addedInteger(int[] nums1, int[] nums2) {
        int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;
        for (int v : nums1) min1 = Math.min(min1, v);
        for (int v : nums2) min2 = Math.min(min2, v);
        return min2 - min1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **整体加x不改变相对大小**
2. **最小值之差即为x**
3. **x可以为负数**
