## 题目描述

给定有效 IPv4 地址，将每个 `"."` 替换为 `"[.]"` 返回。

**示例：**
```
输入：address = "1.1.1.1"
输出："1[.]1[.]1[.]1"
```

## 解题思路

字符串替换：遍历字符，遇到 '.' 替换为 "[.]"。

## Java 代码实现

```java
class Solution {
    public String defangIPaddr(String address) {
        return address.replace(".", "[.]");
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **String.replace**：直接调用内置方法
2. **不需要正则**：replace 是字面量替换，非正则
