## 题目描述

长度为 `n` 的全 0 数组，每次操作将指定位置改为指定颜色，每次操作后返回相邻且颜色相同（非 0）的元素对数。

## Java 代码实现

```java
class Solution {
    public int[] colorTheArray(int n, int[][] queries) {
        int[] nums = new int[n];
        int[] result = new int[queries.length];
        int ans = 0;

        for (int i = 0; i < queries.length; i++) {
            int idx = queries[i][0], color = queries[i][1];
            // 减去原来的配对
            if (nums[idx] != 0) {
                if (idx > 0 && nums[idx - 1] == nums[idx]) ans--;
                if (idx < n - 1 && nums[idx + 1] == nums[idx]) ans--;
            }
            // 更新颜色
            nums[idx] = color;
            // 加上新的配对
            if (idx > 0 && nums[idx - 1] == nums[idx]) ans++;
            if (idx < n - 1 && nums[idx + 1] == nums[idx]) ans++;
            result[i] = ans;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q)，q 为操作数
- 空间复杂度：O(n)

## 关键点总结

1. 每次操作只影响与 `index` 相邻的配对，先减旧配对再加新配对
2. 颜色 0 不参与统计
