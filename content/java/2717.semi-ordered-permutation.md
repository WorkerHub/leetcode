## 题目描述

给你长度为 `n` 的排列 `nums`，每步可以交换相邻元素，返回将 `1` 移到开头、`n` 移到末尾所需的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int semiOrderedPermutation(int[] nums) {
        int n = nums.length;
        int pos1 = -1, posn = -1;
        // 找到 1 和 n 的位置
        for (int i = 0; i < n; i++) {
            if (nums[i] == 1) pos1 = i;
            if (nums[i] == n) posn = i;
        }
        // 1 移到开头需要 pos1 次；n 移到末尾需要 n-1-posn 次
        int steps = pos1 + (n - 1 - posn);
        // 如果 1 在 n 的右边，移动 1 时会推着 n 往右，少一次操作
        if (pos1 > posn) steps--;
        return steps;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 相邻交换的操作次数等于元素移动的距离
2. 当 `1` 在 `n` 右边时，两者的移动路径有重叠，总次数少 1
