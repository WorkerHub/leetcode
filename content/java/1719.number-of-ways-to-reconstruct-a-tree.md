## 题目描述

`pairs[i] = [xi, yi]` 表示两节点互为祖先/后代关系，返回满足条件的有根树数量：0 无解，1 唯一，2 多种。

## 解题思路

**关键性质：** 父节点的邻居集合（含自身）包含子节点的邻居集合。对每条边 `(u, v)`（`deg[u] <= deg[v]`），若 `neighbors[u]` 不是 `neighbors[v]` 的子集则无解；若度数相等则有多解。且必须存在一个根节点（度数等于节点总数）。

## Java 代码实现

```java
class Solution {
    public int checkWays(int[][] pairs) {
        Map<Integer, Set<Integer>> adj = new HashMap<>();
        for (int[] p : pairs) {
            adj.computeIfAbsent(p[0], k -> new HashSet<>()).add(p[1]);
            adj.computeIfAbsent(p[1], k -> new HashSet<>()).add(p[0]);
        }
        // 每个节点加上自身
        for (int node : adj.keySet()) adj.get(node).add(node);

        int n = adj.size();
        // 检查是否存在根节点（度数 = n）
        boolean hasRoot = adj.values().stream().anyMatch(s -> s.size() == n);
        if (!hasRoot) return 0;

        int result = 1;
        for (int[] p : pairs) {
            int u = p[0], v = p[1];
            // 让 u 为度数较小的
            if (adj.get(u).size() > adj.get(v).size()) { int t = u; u = v; v = t; }
            // u 的邻居集合必须是 v 的邻居集合的子集
            if (!adj.get(v).containsAll(adj.get(u))) return 0;
            // 度数相等则有多解
            if (adj.get(u).size() == adj.get(v).size()) result = 2;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(p * n)
- **空间复杂度**：O(p + n)

## 关键点总结

1. 邻居集合含自身，父节点集合包含子节点集合
2. 根节点与所有其他节点均相邻（度数 = 节点总数）
3. 度数相等说明父子可互换，有多解
