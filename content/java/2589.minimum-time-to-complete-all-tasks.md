## 题目描述

给你任务数组 `tasks[i] = [start, end, duration]`，每个任务需在 [start, end] 内运行 duration 个时刻，返回完成所有任务所需的最少运行时刻总数。

## 解题思路

按截止时间排序后贪心：对每个任务，统计 [start, end] 内已安排的时刻数，不足则从 end 向左贪心填充未使用时刻（越靠右与后续任务重叠概率越大）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int findMinimumTime(int[][] tasks) {
        Arrays.sort(tasks, (a, b) -> a[1] - b[1]); // 按截止时间排序
        boolean[] run = new boolean[2001];

        for (int[] task : tasks) {
            int start = task[0], end = task[1], duration = task[2];
            // 统计 [start, end] 内已安排的时刻数
            int already = 0;
            for (int t = start; t <= end; t++) {
                if (run[t]) already++;
            }
            int need = duration - already;
            // 从右向左贪心填充
            for (int t = end; t >= start && need > 0; t--) {
                if (!run[t]) {
                    run[t] = true;
                    need--;
                }
            }
        }
        int total = 0;
        for (boolean v : run) if (v) total++;
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * T)，T = 2000
- **空间复杂度**：O(T)

## 关键点总结

1. 按截止时间排序，优先处理截止时间早的任务
2. 从右向左贪心填充：靠近截止时间的时刻与后续任务重叠概率更高
3. 利用已有运行时刻减少额外需求
