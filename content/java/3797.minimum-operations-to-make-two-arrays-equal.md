## 题目描述

给定两个长度为 `n` 的整数数组 `arr1` 和 `arr2`，每次操作将某个元素加 1 或减 1，求使两个数组相等的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] arr1, int[] arr2) {
        // 每个位置独立处理，最少操作 = 各位差值绝对值之和
        long total = 0;
        for (int i = 0; i < arr1.length; i++) {
            total += Math.abs(arr1[i] - arr2[i]);
        }
        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最少操作数等于各位置元素差值绝对值之和
2. 每个位置独立处理，贪心最优
3. 用 `long` 防止累加溢出
