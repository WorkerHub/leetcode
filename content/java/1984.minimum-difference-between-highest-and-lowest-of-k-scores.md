## 题目描述

从整数数组 `nums` 中选 `k` 个数，使最大值与最小值之差最小，返回该最小差值。

## 解题思路

排序后，极差最小的 k 个数一定是有序数组中连续的 k 个。枚举所有长度为 k 的窗口，取 `nums[i+k-1] - nums[i]` 的最小值。

## Java 代码实现

### 方法一：排序 + 滑动窗口（推荐）

```java
import java.util.*;

class Solution {
    public int minimumDifference(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        int ans = Integer.MAX_VALUE;
        // 枚举每个长度为k的连续窗口
        for (int i = 0; i <= n - k; i++) {
            ans = Math.min(ans, nums[i + k - 1] - nums[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后极差最小的 k 个数一定是连续段
2. 枚举所有长度 k 的窗口，取最小差值
