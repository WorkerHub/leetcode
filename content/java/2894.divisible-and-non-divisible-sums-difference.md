## 题目描述

给你正整数 n 和 m，返回 1 到 n 中不能被 m 整除的数之和减去能被 m 整除的数之和。

## 解题思路

数学公式：总和 = `n*(n+1)/2`，能被 m 整除的和 = `m * k*(k+1)/2`（k = n/m），答案 = `total - 2 * div_sum`。

## Java 代码实现

```java
class Solution {
    public int differenceOfSums(int n, int m) {
        // 1 到 n 的总和
        int total = n * (n + 1) / 2;
        // n 以内 m 的倍数个数
        int k = n / m;
        // 能被 m 整除的数之和：m + 2m + ... + km = m * k*(k+1)/2
        int divSum = m * k * (k + 1) / 2;
        // num1 - num2 = (total - divSum) - divSum = total - 2 * divSum
        return total - 2 * divSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 核心公式：`num1 - num2 = total - 2 * div_sum`
2. 能被 m 整除的数为等差数列，求和公式 `m * k*(k+1)/2`
3. `k = n / m` 是 n 以内 m 的倍数个数（整数除法）
