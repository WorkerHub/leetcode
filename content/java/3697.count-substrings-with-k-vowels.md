## 题目描述

给你一个字符串 `s` 和整数 `k`，返回恰好包含 k 个元音字母（a, e, i, o, u）的子字符串数量。

## 解题思路

"恰好 k 个元音" = "至多 k 个" - "至多 k-1 个"。用滑动窗口计算至多 k 个元音的子串数：维护左指针，每次右端扩展后若超出限制则收缩左端，以 right 结尾的合法子串数为 `right - left + 1`。

## Java 代码实现

```java
class Solution {
    public long countSubstrings(String s, int k) {
        return atMost(s, k) - atMost(s, k - 1);
    }

    private long atMost(String s, int limit) {
        if (limit < 0) return 0;
        long count = 0;
        int left = 0, vowelCount = 0;
        String vowels = "aeiou";
        for (int right = 0; right < s.length(); right++) {
            if (vowels.indexOf(s.charAt(right)) >= 0) vowelCount++;
            while (vowelCount > limit) {
                if (vowels.indexOf(s.charAt(left)) >= 0) vowelCount--;
                left++;
            }
            count += right - left + 1;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. "恰好 k 个" = "至多 k 个" - "至多 k-1 个"
2. 滑动窗口统计以 right 结尾的合法子串数
3. limit < 0 时直接返回 0
