## 题目描述

给定整数数组 `nums` 和整数 `k`，子序列的代价定义为所有元素的按位或（OR），返回长度为 `k` 的子序列的最小代价。

## Java 代码实现

```java
class Solution {
    public int minOrAfterOperations(int[] nums, int k) {
        int ans = 0;

        for (int bit = 29; bit >= 0; bit--) {
            // 尝试将第 bit 位设为 0
            int candidate = ans;
            int mask = (1 << (bit + 1)) - 1;
            int groups = 0;
            int curOr = 0;

            for (int x : nums) {
                curOr |= (x & mask);
                if (curOr == candidate) {
                    // 当前段满足约束，分一组
                    groups++;
                    curOr = 0;
                }
            }

            if (groups < k) {
                // 第 bit 位无法为 0，必须为 1
                ans |= (1 << bit);
            }
            // 否则该位保持为 0
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(30n)，对每个二进制位扫描数组
- 空间复杂度：O(1)

## 关键点总结

1. OR 操作单调递增，贪心从高位到低位逐位决策
2. 统计"合法段数"：连续 OR 满足约束则切段，段数 >= k 说明该位可为 0
3. `mask` 只考虑当前位及其高位，屏蔽低位的干扰
