## 题目描述

初始全 0 字符串，每次可选一个后缀翻转（0↔1），求变为 target 的最少操作次数。

**示例：**
```
输入：target = "10111"
输出：3
```

## 解题思路

贪心：从左到右，每当当前位与 target 不匹配时翻转（等价于统计 target 中相邻字符不同的次数 + 首位为 1 则 +1）。

## Java 代码实现

```java
class Solution {
    public int minFlips(String target) {
        int flips = 0;
        char current = '0';
        for (char c : target.toCharArray()) {
            if (c != current) {
                flips++;
                current = c;
            }
        }
        return flips;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心**：不匹配时必须翻转
2. **等价**：统计从 '0' 开始的字符变化次数
3. **后缀翻转**：后面全部取反，所以后续状态跟踪
