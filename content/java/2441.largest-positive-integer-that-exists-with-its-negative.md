## 题目描述

给你不含零的整数数组 `nums`，找出自身与对应负整数都在数组中存在的最大正整数 `k`，若不存在返回 `-1`。

## 解题思路

将数组存入哈希集合，遍历所有正整数，检查其负值是否也在集合中，取最大值。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findMaxK(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);

        int ans = -1;
        for (int x : nums) {
            // 只检查正整数，且其负值也在集合中
            if (x > 0 && set.contains(-x)) {
                ans = Math.max(ans, x);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 哈希集合 O(1) 查找，高效检查 `-k` 是否存在
2. 只遍历正整数，避免重复检查
3. 遍历所有元素取最大值
