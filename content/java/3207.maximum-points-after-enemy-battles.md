## 题目描述

给你敌人能量数组 `enemyEnergies` 和当前能量 `currentEnergy`，可以打败能量不超过当前的敌人得 1 分（消耗对应能量），或吸收敌人能量（增加能量但不得分），返回最大得分。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maximumPoints(int[] enemyEnergies, int currentEnergy) {
        Arrays.sort(enemyEnergies);
        int n = enemyEnergies.length;

        // 若连最弱的都打不过，先吸收最强的
        if (currentEnergy < enemyEnergies[0]) {
            currentEnergy += enemyEnergies[n - 1];
            // 吸收后仍打不过，或只有一个敌人，返回 0
            if (currentEnergy < enemyEnergies[0] || n == 1) {
                return 0;
            }
            // 最强的已吸收，只剩前 n-1 个敌人
            n--;
        }

        long ans = 0;
        // 贪心：优先打最弱的，每次尽量多打
        for (int i = 0; i < n; i++) {
            if (currentEnergy >= enemyEnergies[i]) {
                ans += currentEnergy / enemyEnergies[i];
                currentEnergy %= enemyEnergies[i];
            } else {
                break; // 已排序，后面更强打不过
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：打最弱敌人效率最高（每单位能量换最多分数）
2. 若初始无法打任何人，需要先吸收最强的敌人
3. 吸收操作只能用一次，多次吸收会减少得分机会
