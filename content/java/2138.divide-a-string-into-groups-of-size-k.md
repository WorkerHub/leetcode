## 题目描述

将字符串s按大小k分组，最后一组不足k个用fill字符补齐。

## 解题思路

先将字符串补齐到k的倍数长度，再按k分割。

## Java 代码实现

```java
class Solution {
    public String[] divideString(String s, int k, char fill) {
        int remainder = s.length() % k;
        if (remainder != 0) {
            StringBuilder sb = new StringBuilder(s);
            for (int i = 0; i < k - remainder; i++) sb.append(fill);
            s = sb.toString();
        }
        
        String[] result = new String[s.length() / k];
        for (int i = 0; i < result.length; i++) {
            result[i] = s.substring(i * k, (i + 1) * k);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **补齐到k的倍数**：余数不为0时补fill字符
2. **按k分割**：substring取每段
3. **补充数量**：k - remainder个fill字符
