## 题目描述

给你一个整数 `n`，返回所有长度为 `n` 的中心对称数。你可以按任何顺序返回答案。

中心对称数是指一个数字在旋转了 180 度之后看起来依旧相同的数字（或者上下颠倒地看）。

**示例 1：**
```
输入: n = 2
输出: ["11","69","88","96"]
```

**示例 2：**
```
输入: n = 1
输出: ["0","1","8"]
```

**提示：**
- 1 <= n <= 14

## 解题思路

这道题是 [LeetCode 246](https://leetcode.com/problems/strobogrammatic-number/) 的扩展，从判断变成生成所有可能的中心对称数。

**核心思想：**
- 使用递归或迭代，从中间向两边构建中心对称数
- 每次在两端添加一对对称的数字
- 注意特殊情况：不能有前导零（除了 "0" 本身）

**关键观察：**
1. **对称对**：可以添加的数字对有：('0','0'), ('1','1'), ('6','9'), ('8','8'), ('9','6')
2. **递归结构**：
   - n = 1: ["0", "1", "8"]
   - n = 2: 在 n=0 的基础上两端加对称对
   - n = 3: 在 n=1 的基础上两端加对称对
3. **前导零问题**：最外层不能是 '0'（除非 n=1 且结果是 "0"）

**递归思路：**
- base case: n = 0 返回 [""]，n = 1 返回 ["0", "1", "8"]
- recursive case: 在 n-2 的结果两端添加对称对
- 特殊处理：最外层过滤掉前导零的情况

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<String> findStrobogrammatic(int n) {
        return helper(n, n);
    }
    
    private List<String> helper(int n, int length) {
        // 递归终止条件
        if (n == 0) {
            return new ArrayList<>(Arrays.asList(""));
        }
        if (n == 1) {
            return new ArrayList<>(Arrays.asList("0", "1", "8"));
        }
        
        // 递归获取 n-2 长度的所有中心对称数
        List<String> middles = helper(n - 2, length);
        List<String> result = new ArrayList<>();
        
        // 在每个中间结果两端添加对称对
        char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
        for (String middle : middles) {
            for (char[] pair : pairs) {
                // 最外层不能有前导零
                if (n != length || pair[0] != '0') {
                    result.add(pair[0] + middle + pair[1]);
                }
            }
        }
        
        return result;
    }
}
```

### 方法二：迭代法（自底向上）

```java
import java.util.*;

class Solution {
    public List<String> findStrobogrammatic(int n) {
        // 初始化
        List<String> result;
        if (n % 2 == 0) {
            result = new ArrayList<>(Arrays.asList(""));
        } else {
            result = new ArrayList<>(Arrays.asList("0", "1", "8"));
        }
        
        // 对称对
        char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
        
        // 从中间向两边扩展，每次增加 2 个字符
        for (int i = (n % 2 == 0) ? 0 : 1; i < n - 1; i += 2) {
            List<String> newResult = new ArrayList<>();
            for (String num : result) {
                for (char[] pair : pairs) {
                    newResult.add(pair[0] + num + pair[1]);
                }
            }
            result = newResult;
        }
        
        // 过滤掉前导零（除了 "0"）
        if (n > 1) {
            List<String> filtered = new ArrayList<>();
            for (String num : result) {
                if (num.charAt(0) != '0') {
                    filtered.add(num);
                }
            }
            return filtered;
        }
        
        return result;
    }
}
```

### 方法三：简化迭代法

```java
import java.util.*;

class Solution {
    public List<String> findStrobogrammatic(int n) {
        List<String> cur;
        
        // 根据奇偶性设置初始状态
        if (n % 2 == 0) {
            cur = Arrays.asList("");
        } else {
            cur = Arrays.asList("0", "1", "8");
        }
        
        // 逐层向外扩展
        for (int i = (n % 2 == 0 ? 0 : 1); i + 2 <= n; i += 2) {
            List<String> next = new ArrayList<>();
            for (String s : cur) {
                if (i + 2 < n) {
                    // 非最外层，可以使用 '0'
                    next.add("0" + s + "0");
                }
                next.add("1" + s + "1");
                next.add("6" + s + "9");
                next.add("8" + s + "8");
                next.add("9" + s + "6");
            }
            cur = next;
        }
        
        return cur;
    }
}
```

### 方法四：回溯法

```java
import java.util.*;

class Solution {
    private List<String> result = new ArrayList<>();
    private char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
    
    public List<String> findStrobogrammatic(int n) {
        char[] buf = new char[n];
        backtrack(buf, 0, n - 1, n);
        return result;
    }
    
    private void backtrack(char[] buf, int left, int right, int n) {
        if (left > right) {
            // 收集结果
            result.add(new String(buf));
            return;
        }
        
        for (char[] pair : pairs) {
            // 处理单个字符位置（奇数长度时中间字符）
            if (left == right) {
                // 中间字符只能是 0、1、8（自对称）
                if (pair[0] == pair[1] && pair[0] != '9') {
                    buf[left] = pair[0];
                    backtrack(buf, left + 1, right - 1, n);
                }
                continue;
            }
            
            // 最外层不能有前导零
            if (left == 0 && pair[0] == '0') {
                continue;
            }
            
            buf[left] = pair[0];
            buf[right] = pair[1];
            backtrack(buf, left + 1, right - 1, n);
        }
    }
}
```

## 复杂度分析

所有方法的复杂度类似：
- **时间复杂度**：O(5^(n/2))，每一层最多有 5 种选择
- **空间复杂度**：O(5^(n/2))，存储所有结果

对于 n=14（最大值），结果数量约为 5^7 ≈ 78,125，是可以接受的。

## 关键点总结

1. **递归结构**：n 长度的问题可以拆解成 n-2 长度的子问题
2. **对称对**：5 对对称数字：(0,0), (1,1), (6,9), (8,8), (9,6)
3. **前导零处理**：最外层不能是 0，但中间层可以
4. **奇偶处理**：奇数长度有中间字符，偶数长度没有
5. **base case**：n=0 返回 [""]，n=1 返回 ["0","1","8"]

## 易错点

1. **前导零**：忘记过滤前导零，导致 "00"、"010" 等错误结果
2. **递归终止**：n=0 和 n=1 的 base case 要正确处理
3. **参数传递**：需要知道是否是最外层，才能判断是否允许 '0'
4. **奇偶性**：n 为奇数和偶数的初始状态不同
5. **Java 字符串拼接**：char 和 String 拼接时注意类型转换
