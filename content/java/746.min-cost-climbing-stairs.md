## 题目描述

给定整数数组 cost，cost[i] 是从第 i 个台阶向上爬的费用。可以选择从下标 0 或 1 开始，每次爬一个或两个台阶。返回到达顶部的最低花费。

**示例：**
```
输入：cost = [10,15,20]
输出：15（从下标1开始，花费15，跳两步到顶部）
```

## 解题思路

动态规划：dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])，空间优化为两个变量。

## Java 代码实现

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int prev2 = 0, prev1 = 0;

        for (int i = 2; i <= cost.length; i++) {
            int curr = Math.min(prev1 + cost[i - 1], prev2 + cost[i - 2]);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **起点选择**：可以从第 0 或第 1 个台阶开始（初始代价为 0）
2. **状态转移**：从前一步或前两步转移取最小
3. **空间优化**：只需两个变量
