## 题目描述

给你二叉树根节点 `root` 和整数 `k`，返回第 `k` 大的完美子树（满二叉树）的节点数，不存在返回 `-1`。

## 解题思路

DFS 后序遍历：对每个节点，若左右子树均为完美树且大小相等，则当前子树也是完美树，大小为 `left + right + 1`，否则返回 -1。收集所有完美子树大小，排序后返回第 k 大。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer> sizes = new ArrayList<>();

    public int kthLargestPerfectSubtree(TreeNode root, int k) {
        dfs(root);
        if (sizes.size() < k) return -1;
        sizes.sort(Collections.reverseOrder());
        return sizes.get(k - 1);
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int l = dfs(node.left), r = dfs(node.right);
        // 左或右不是完美树，或大小不相等，则不是完美树
        if (l == -1 || r == -1 || l != r) return -1;
        int size = l + r + 1;
        sizes.add(size);
        return size;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，DFS O(n) + 排序 O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 完美二叉树：左右子树都是完美树且大小相等（保证高度相同）
2. DFS 返回子树大小，-1 表示不是完美树
3. 单叶节点大小为 1，也是完美树
