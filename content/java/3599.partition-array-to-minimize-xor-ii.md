## 题目描述

给定整数数组 `nums`，将其分成 `k` 个非空连续子数组，使每个子数组的异或值的最大值最小化，返回该最小的最大异或值。

## Java 代码实现

```java
class Solution {
    public int minimizeXor(int[] nums, int k) {
        int n = nums.length;
        // 前缀异或
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] ^ nums[i];

        // 二分答案
        int lo = 0, hi = (1 << 30) - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (feasible(nums, prefix, k, mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    // 贪心验证：能否用 <= k 段使每段异或 <= mid
    private boolean feasible(int[] nums, int[] prefix, int k, int mid) {
        int count = 0;
        int curXor = 0;
        for (int x : nums) {
            curXor ^= x;
            if (curXor > mid) {
                // 当前段超过 mid，在此之前分割
                count++;
                curXor = x;
                if (curXor > mid) return false;  // 单元素超限，无解
            }
        }
        count++;
        return count <= k;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(MAX))，二分约 30 次，每次 O(n) 贪心验证
- 空间复杂度：O(n)

## 关键点总结

1. 二分答案：验证给定上限时，贪心检查能否用 <= k 段覆盖
2. 贪心方向：让每段异或值尽量不超过 mid，超过立即分割
3. 单个元素超过 mid 则此上限无解
