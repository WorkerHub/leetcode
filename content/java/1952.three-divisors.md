## 题目描述

给你整数 `n`，若 `n` 恰好有三个正因子则返回 `true`，否则返回 `false`。

## 解题思路

恰好有 3 个因子等价于 n = p²（p 为质数），因子为 1、p、p²。枚举 1 到 sqrt(n) 统计因子数是否为 3。

## Java 代码实现

```java
class Solution {
    public boolean isThree(int n) {
        int count = 0;
        for (int i = 1; i * i <= n; i++) {
            if (n % i == 0) {
                count++;
                if (i != n / i) count++;
            }
        }
        return count == 3;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sqrt(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 枚举到 sqrt(n)，成对统计因子
2. 恰好 3 个因子等价于完全平方数且平方根为质数（n = p²）
3. n=1 只有 1 个因子，不满足
