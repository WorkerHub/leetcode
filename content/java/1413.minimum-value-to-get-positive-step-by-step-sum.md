## 题目描述

给你一个整数数组 `nums`。你可以选择任意一个 `startValue` 作为初始值。

接着，你需要对数组 `nums` 从左到右执行"逐步累加"操作，具体过程如下：

- 初始值为 `startValue`
- 每步将当前值加上 `nums[i]`

要求在整个过程的每一步（包括初始值），累加值都 **≥ 1**。

请找到满足条件的 **最小正整数** `startValue`。

**示例 1：**

```
输入：nums = [-3,2,-3,4,2]
输出：5
解释：
startValue = 5
步骤  nums[i]  累加值
  1     -3       2   = 5 + (-3)
  2      2       4   = 2 + 2
  3     -3       1   = 4 + (-3)
  4      4       5   = 1 + 4
  5      2       7   = 5 + 2
所有步骤累加值 ≥ 1，5 是满足条件的最小值。
```

**示例 2：**

```
输入：nums = [1,2]
输出：1
解释：最小正整数是 1，startValue = 1 时累加值始终为正。
```

**示例 3：**

```
输入：nums = [1,-2,-3]
输出：5
```

**提示：**

- `1 <= nums.length <= 100`
- `-100 <= nums[i] <= 100`

## 解题思路

### 核心思路：前缀和最小值

设前缀和数组 `prefix[i] = nums[0] + nums[1] + ... + nums[i]`。

在第 `i` 步（1-indexed），累加值为 `startValue + prefix[i-1]`（`prefix[0] = 0` 为空前缀）。

我们需要对所有 `i` 满足：

```
startValue + prefix[i] >= 1
```

即：

```
startValue >= 1 - prefix[i]，对所有 i
```

因此：

```
startValue >= max(1 - prefix[i]) = 1 - min(prefix[i])
```

又因为 `startValue` 必须是正整数（≥ 1），所以：

```
startValue = max(1, 1 - min_prefix)
```

其中 `min_prefix` 是所有前缀和（包括空前缀 0）的最小值。

### 步骤

1. 遍历 `nums`，维护当前前缀和及最小前缀和
2. 最小前缀和初始值为 0（对应空前缀，即 startValue 本身）
3. 答案 = `max(1, 1 - min_prefix)`

## Java 代码实现

### 方法一：前缀和（推荐）

```java
class Solution {
    public int minStartValue(int[] nums) {
        int minPrefix = 0;  // 空前缀的前缀和为 0
        int prefixSum = 0;

        for (int num : nums) {
            prefixSum += num;
            // 更新最小前缀和
            minPrefix = Math.min(minPrefix, prefixSum);
        }

        // startValue 需要满足：startValue + minPrefix >= 1
        // 同时 startValue 必须是正整数（>= 1）
        return Math.max(1, 1 - minPrefix);
    }
}
```

### 方法二：先求所有前缀和，再找最小值

```java
class Solution {
    public int minStartValue(int[] nums) {
        int n = nums.length;
        int[] prefixSums = new int[n];
        prefixSums[0] = nums[0];
        for (int i = 1; i < n; i++) {
            prefixSums[i] = prefixSums[i - 1] + nums[i];
        }

        // 最小前缀和（包含空前缀 0）
        int minPrefix = 0;
        for (int ps : prefixSums) {
            minPrefix = Math.min(minPrefix, ps);
        }

        return Math.max(1, 1 - minPrefix);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 前缀和 | O(n) | O(1) |
| 数组版 | O(n) | O(n) |

最优解为 O(n) 时间、O(1) 空间的前缀和方法。

## 图解示例

以 `nums = [-3, 2, -3, 4, 2]` 为例：

```
前缀和数组：[-3, -1, -4, 0, 2]
（加上空前缀 0）：[0, -3, -1, -4, 0, 2]
最小值：-4
答案：max(1, 1 - (-4)) = max(1, 5) = 5
```

验证：startValue=5，累加序列：5, 2, 4, 1, 5, 7，全部 ≥ 1。

## 关键点总结

1. 将问题转化为：`startValue >= 1 - min(所有前缀和)`
2. 前缀和的起点包含"空前缀"（值为 0），对应初始值本身
3. `startValue` 必须是正整数，所以答案是 `Math.max(1, 1 - min_prefix)`
4. 一次遍历即可，无需额外空间

## 易错点

1. 初始前缀和要从 0 开始（空前缀），不然会漏掉 startValue 本身的约束
2. `startValue` 要求是**正整数**（≥ 1），不是非负整数（≥ 0）
3. 当所有前缀和都 ≥ 0 时，`1 - min_prefix` 可能 ≤ 1，此时答案就是 1
