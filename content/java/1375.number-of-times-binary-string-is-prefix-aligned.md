## 题目描述

有一个长度为 n 的二进制字符串，初始全为 '0'。按 `flips` 数组依次将对应位翻转为 '1'，每步后若已翻转的位恰好构成从头开始的连续前缀则计数，返回总计数。

## 解题思路

前缀对齐的等价条件：已翻转位中的最大编号 == 当前翻转次数。因为 flips 是排列（各位置唯一），k 个不重复正整数的最大值为 k 意味着它们恰好是 {1,...,k}。只需维护一个最大值变量，O(n) 时间 O(1) 空间。

## Java 代码实现

```java
class Solution {
    public int numTimesAllBlue(int[] flips) {
        int maxFlip = 0; // 目前翻转过的位中最大的编号
        int count = 0;

        for (int i = 0; i < flips.length; i++) {
            // 更新最大编号
            maxFlip = Math.max(maxFlip, flips[i]);
            // 若最大编号 == 当前步数（从1开始），则前缀对齐
            if (maxFlip == i + 1) {
                count++;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历 flips 数组一次。
- 空间复杂度：O(1)，只需一个变量维护最大值。

## 关键点总结

1. 前缀对齐等价于：`max(已翻转编号) == 当前翻转次数`，无需维护集合。
2. flips 是排列，k 个互不相同的正整数最大值为 k 意味着恰好是 {1,...,k}。
3. 步数从 1 开始计数，第 i 步（0-indexed）对应第 i+1 次翻转。
