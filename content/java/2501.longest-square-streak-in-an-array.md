## 题目描述

给你整数数组 `nums`，子序列中每个元素（除第一个）都是前一个元素的平方，返回最长此类子序列的长度，不存在则返回 -1。

## 解题思路

排序后 DP：`dp[x]` 表示以 `x` 结尾的最长平方序列。从小到大处理，若 `x` 的整数平方根 `r` 满足 `r²==x` 且 `r` 在 dp 中，则 `dp[x] = dp[r] + 1`，否则 `dp[x] = 1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int longestSquareStreak(int[] nums) {
        Arrays.sort(nums);
        Map<Integer, Integer> dp = new HashMap<>();
        int ans = -1;

        for (int x : nums) {
            if (dp.containsKey(x)) continue; // 去重
            int r = (int) Math.sqrt(x);
            if ((long) r * r == x && dp.containsKey(r)) {
                dp.put(x, dp.get(r) + 1);
            } else {
                dp.put(x, 1);
            }
            if (dp.get(x) >= 2) ans = Math.max(ans, dp.get(x));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序后从小到大处理，平方根必然在当前元素之前被处理
2. 用 `(long) r * r == x` 严格验证完全平方数，避免浮点误差
3. 需要去重（相同元素只处理一次）
