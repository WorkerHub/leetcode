## 题目描述

整数 x 的权重定义为将 x 变为 1 所需步数（偶数除 2，奇数乘 3 加 1）。将 [lo, hi] 中所有整数按权重升序排序（相同权重按数值升序），返回第 k 个数。

## 解题思路

用 HashMap 做记忆化缓存权重计算结果，避免重复计算（Collatz 序列会经过很大的中间值）。将 [lo, hi] 中所有整数收集后，以 `(权重, 数值)` 为键排序，返回第 k-1 个元素。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private Map<Integer, Integer> cache = new HashMap<>();

    public int getKth(int lo, int hi, int k) {
        cache.put(1, 0);

        Integer[] nums = new Integer[hi - lo + 1];
        for (int i = lo; i <= hi; i++) nums[i - lo] = i;

        // 按（权重, 数值）排序
        Arrays.sort(nums, (a, b) -> {
            int pa = power(a), pb = power(b);
            return pa != pb ? pa - pb : a - b;
        });

        return nums[k - 1];
    }

    private int power(int x) {
        if (cache.containsKey(x)) return cache.get(x);
        int next = (x % 2 == 0) ? x / 2 : 3 * x + 1;
        int result = 1 + power(next);
        cache.put(x, result);
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m × W)（均摊，m = hi-lo+1，W 为最大权重），排序 O(m log m)。
- 空间复杂度：O(W)，缓存中间计算值。

## 关键点总结

1. Collatz 序列的中间值可能远大于原始数，记忆化缓存这些中间值避免重复计算。
2. 排序时以 `(权重, 数值)` 为比较键，权重相同时按数值升序。
3. k 从 1 开始，返回 `nums[k-1]`。
