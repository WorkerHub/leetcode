## 题目描述

一行多米诺骨牌，初始状态有的向左推 'L'、向右推 'R' 或竖立 '.'。模拟最终状态。

**示例：**
```
输入：dominoes = ".L.R...LR..L.."
输出："LL.RR.LLRRLL.."
```

## 解题思路

力的模型：分别计算右推力和左推力，力随距离衰减。合力决定最终方向。

## Java 代码实现

```java
class Solution {
    public String pushDominoes(String dominoes) {
        int n = dominoes.length();
        int[] forces = new int[n];

        // 计算右推力
        int force = 0;
        for (int i = 0; i < n; i++) {
            if (dominoes.charAt(i) == 'R') force = n;
            else if (dominoes.charAt(i) == 'L') force = 0;
            else force = Math.max(force - 1, 0);
            forces[i] += force;
        }

        // 计算左推力
        force = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (dominoes.charAt(i) == 'L') force = n;
            else if (dominoes.charAt(i) == 'R') force = 0;
            else force = Math.max(force - 1, 0);
            forces[i] -= force;
        }

        // 合力判断方向
        StringBuilder sb = new StringBuilder();
        for (int f : forces) {
            if (f > 0) sb.append('R');
            else if (f < 0) sb.append('L');
            else sb.append('.');
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **力的模型**：右推为正，左推为负
2. **力的衰减**：每远一格减 1
3. **合力判断**：正为 R，负为 L，零为不动
