## 题目描述

在柠檬水摊上，每一杯柠檬水的售价为 5 美元。顾客排队购买你的产品，（按账单 bills 支付的顺序）一次购买一杯。

每位顾客只买一杯柠檬水，然后向你付 5 美元、10 美元或 20 美元。你必须给每个顾客正确找零，也就是说净交易是每位顾客向你支付 5 美元。

注意，一开始你手头没有任何零钱。

给你一个整数数组 bills ，其中 bills[i] 是第 i 位顾客付的账。如果你能给每位顾客正确找零，返回 true ，否则返回 false 。

**示例 1：**
```
输入：bills = [5,5,5,10,20]
输出：true
```

**示例 2：**
```
输入：bills = [5,5,10,10,20]
输出：false
```

**提示：**
- 1 <= bills.length <= 10^5
- bills[i] 不是 5 就是 10 或是 20

## 解题思路

这是一道典型的**贪心算法**题目。

**核心思想：**
- 维护手头的 5 美元和 10 美元钞票数量
- 找零时优先使用大面额（10 美元）

**找零规则：**
1. **收到 5 美元**：直接收下，不需要找零
2. **收到 10 美元**：找零 5 美元
3. **收到 20 美元**：找零 15 美元
   - 优先：1张10美元 + 1张5美元
   - 其次：3张5美元

**为什么优先使用 10 美元找零？**
- 5 美元更通用，10 美元只能找 20 美元
- 保留更多 5 美元可以应对更多情况

## Java 代码实现

### 方法一：贪心算法（推荐）

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        int five = 0; // 5 美元的数量
        int ten = 0;  // 10 美元的数量

        for (int bill : bills) {
            if (bill == 5) {
                // 收到 5 美元，不需要找零
                five++;
            } else if (bill == 10) {
                // 收到 10 美元，找零 5 美元
                if (five == 0) return false;
                five--;
                ten++;
            } else { // bill == 20
                // 收到 20 美元，找零 15 美元
                // 优先：1张10 + 1张5
                if (ten > 0 && five > 0) {
                    ten--;
                    five--;
                // 其次：3张5
                } else if (five >= 3) {
                    five -= 3;
                } else {
                    return false;
                }
            }
        }

        return true;
    }
}
```

**代码说明：**
- 只需要记录 5 和 10 的数量，不需要记录 20（20 不能用来找零）
- 找 20 时优先用 10+5 而不是 5+5+5

## 复杂度分析

- **时间复杂度**：O(n)，遍历一次数组。
- **空间复杂度**：O(1)，只用了常数个变量。

## 图解示例

**示例 1**：bills = [5,5,5,10,20]

```
初始: five=0, ten=0

顾客1付5:  five=1, ten=0

```

## 关键点总结

1. **贪心策略**：找 20 时优先用 10+5 而不是 5+5+5
2. **只记录 5 和 10**：20 不能用来找零，无需记录
3. **即时判断**：一旦无法找零立即返回 false
4. **优先级**：5 美元比 10 美元更重要，因为更通用

## 易错点

1. **找零顺序错误**：应该优先使用 10+5，而不是 5+5+5

2. **记录 20 的数量**：20 无法用来找零，记录它没有意义

3. **条件判断不完整**：找零之前要先检查是否有足够的零钱
