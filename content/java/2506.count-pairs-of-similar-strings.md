## 题目描述

给你字符串数组 `words`，两个字符串相似当且仅当它们由相同的字符组成（不计重复），返回相似字符串对的数目。

## 解题思路

用 26 位掩码表示每个字符串的字符集合，用哈希表统计各掩码出现次数，相同掩码出现 k 次贡献 k*(k-1)/2 对。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int similarPairs(String[] words) {
        Map<Integer, Integer> count = new HashMap<>();
        for (String w : words) {
            int mask = 0;
            for (char c : w.toCharArray()) mask |= 1 << (c - 'a');
            count.merge(mask, 1, Integer::sum);
        }
        int ans = 0;
        for (int v : count.values()) ans += v * (v - 1) / 2;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L)，L 为平均单词长度
- **空间复杂度**：O(n)

## 关键点总结

1. 26 位掩码表示字符集合，去除重复字符和顺序影响
2. 相同掩码出现 k 次，贡献 k*(k-1)/2 对
3. 位掩码比 frozenset 效率更高
