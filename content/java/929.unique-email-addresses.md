## 题目描述

每个邮件地址由本地名和域名组成。本地名中 '.' 被忽略，'+' 之后的内容被忽略。统计有多少不同的实际收件地址。

**示例：**
```
输入：emails = ["test.email+alex@leetcode.com","test.e.mail+bob.cathy@leetcode.com","testemail+david@lee.tcode.com"]
输出：2
```

## 解题思路

对每个邮件地址：分割本地名和域名，处理本地名（去 '.'、截断 '+' 之后），用 HashSet 去重。

## Java 代码实现

```java
class Solution {
    public int numUniqueEmails(String[] emails) {
        Set<String> unique = new HashSet<>();

        for (String email : emails) {
            String[] parts = email.split("@");
            String local = parts[0];
            String domain = parts[1];

            // 移除 '+' 及之后的字符
            int plusIdx = local.indexOf('+');
            if (plusIdx != -1) local = local.substring(0, plusIdx);
            // 移除 '.'
            local = local.replace(".", "");

            unique.add(local + "@" + domain);
        }

        return unique.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)，m 为邮箱平均长度
- **空间复杂度**：O(n × m)

## 关键点总结

1. **字符串处理**：split、indexOf、replace
2. **HashSet 去重**：标准化后去重
3. **规则只作用于本地名**：域名不做处理
