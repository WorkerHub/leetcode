## 题目描述

给你整数数组 `prices`（n 最大 10^6），购买第 i 种水果可免费获得后续 i 种水果，返回购买所有水果的最少花费。

## 解题思路

定义 `f[i]` 为获得前 i 种水果的最小花费。转移：`f[i] = min(f[k] + prices[k])` 其中 k 在 `[(i-1)/2, i-1]`（0-indexed）。用单调队列维护滑动窗口最小值，O(n) 完成。

## Java 代码实现

```java
class Solution {
    public long minimumCoins(int[] prices) {
        int n = prices.length;
        long[] f = new long[n + 1];
        // deque 存 (f[k] + prices[k], k) 的对，按值单调递增
        Deque<long[]> dq = new ArrayDeque<>();

        for (int i = 1; i <= n; i++) {
            int k = i - 1;
            long val = f[k] + prices[k]; // 以购买第 k+1 种水果为起点的代价
            while (!dq.isEmpty() && dq.peekLast()[0] >= val) dq.pollLast();
            dq.addLast(new long[]{val, k});

            // 移除窗口左端过期元素，窗口下界 (i-1)/2
            int lo = (i - 1) / 2;
            while (!dq.isEmpty() && dq.peekFirst()[1] < lo) dq.pollFirst();

            f[i] = dq.peekFirst()[0];
        }
        return f[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 单调队列维护滑动窗口最小值，窗口范围 `[(i-1)/2, i-1]`
2. 先添加右端，再移除左端过期元素，再取队头最小值
3. prices 最大 10^15，f 和代价需用 long
