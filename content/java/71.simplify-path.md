## 题目描述

给你一个字符串 `path`，表示指向某一文件或目录的Unix风格绝对路径（以 `'/'` 开头），请你将其转化为更加简洁的规范路径。

在Unix风格的文件系统中，一个点（`.`）表示当前目录本身；此外，两个点 (`..`) 表示将目录切换到上一级（指向父目录）；两者都可以是复杂相对路径的组成部分。任意多个连续的斜杠（即，`'//'`）都被视为单个斜杠 `'/'`。

返回的规范路径必须遵循下述格式：
- 始终以斜杠 `'/'` 开头
- 两个目录名之间必须只有一个斜杠 `'/'`
- 最后一个目录名（如果存在）不能以 `'/'` 结尾
- 此外，路径仅包含从根目录到目标文件或目录的路径上的目录（即，不含 `'.'` 或 `'..'`）

返回简化后得到的规范路径。

**示例 1：**
```
输入：path = "/home/"
输出："/home"
```

**示例 2：**
```
输入：path = "/../"
输出："/"
解释：从根目录向上一级是不可行的，因为根是你可以到达的最高级
```

**示例 3：**
```
输入：path = "/home//foo/"
输出："/home/foo"
```

**提示：**
- `1 <= path.length <= 3000`
- `path` 由英文字母，数字，`'.'`，`'/'` 或 `'_'` 组成
- `path` 是一个有效的 Unix 风格绝对路径

## 解题思路

核心思想：使用栈处理路径

关键步骤：
1. 按 `/` 分割路径
2. 遇到 `..` 弹栈，遇到 `.` 或空跳过
3. 其他正常目录名压栈
4. 最后用 `/` 连接栈中元素

## Java 代码实现

```java
class Solution {
    public String simplifyPath(String path) {
        Deque<String> stack = new ArrayDeque<>();

        // 按 '/' 分割路径
        for (String part : path.split("/")) {
            if (part.equals("..")) {
                // 返回上一级目录
                if (!stack.isEmpty()) {
                    stack.pop();
                }
            } else if (!part.isEmpty() && !part.equals(".")) {
                // 正常目录名压栈
                stack.push(part);
            }
        }

        // 将栈中元素拼接成路径
        StringBuilder sb = new StringBuilder();
        // 使用 descendingIterator 保持正序
        for (String dir : (Iterable<String>) stack::descendingIterator) {
            sb.append("/").append(dir);
        }

        return sb.length() == 0 ? "/" : sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **栈的应用**：处理上一级目录
2. **分割处理**：按 `/` 分割
3. **特殊情况**：`.` 和空字符串跳过

## 易错点

1. **空字符串**：连续 `/` 会产生空字符串，需过滤
2. **根目录**：`..` 在根目录无效
3. **字符串比较**：Java 中必须使用 `equals` 而非 `==`
