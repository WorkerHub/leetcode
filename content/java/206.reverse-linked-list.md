## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**示例 2：**
```
输入：head = [1,2]
输出：[2,1]
```

**示例 3：**
```
输入：head = []
输出：[]
```

**提示：**
- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶**：链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

## 解题思路

反转链表是**链表操作中最经典的题目**，必须掌握。

### 核心思想

将链表的指针方向反转：
```
原链表：1 -> 2 -> 3 -> 4 -> 5 -> null
反转后：null <- 1 <- 2 <- 3 <- 4 <- 5
```

### 关键操作

1. **保存 next 指针**：在修改指针前，先保存下一个节点
2. **反转指针**：将当前节点的 next 指向前一个节点
3. **移动指针**：前进到下一个节点

### 两种实现方式

1. **迭代法**：使用三个指针（prev, curr, next）
2. **递归法**：递归到链表尾部，然后反转指针

## Java 代码实现

### 方法一：迭代法（推荐）⭐

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        // prev：前一个节点，初始为 null
        ListNode prev = null;
        // curr：当前节点，从头节点开始
        ListNode curr = head;
        
        // 遍历整个链表
        while (curr != null) {
            // 1. 保存下一个节点
            ListNode nextNode = curr.next;
            
            // 2. 反转指针：当前节点指向前一个节点
            curr.next = prev;
            
            // 3. 移动指针：prev 和 curr 都向前移动
            prev = curr;
            curr = nextNode;
        }
        
        // 最后 prev 指向新的头节点
        return prev;
    }
}
```

**代码说明**：
- **三个指针**：
  - `prev`：指向已反转部分的头节点
  - `curr`：指向当前处理的节点
  - `nextNode`：临时保存下一个节点
- **核心操作**：`curr.next = prev` 反转指针
- **循环不变量**：每次循环后，prev 到 curr 之前的部分已反转

**图解过程**（以 [1,2,3] 为例）：
```
初始：
prev = null, curr = 1
null    1 -> 2 -> 3 -> null

第一步：
1.next = null  (反转)
null <- 1    2 -> 3 -> null
prev = 1, curr = 2

第二步：
2.next = 1  (反转)
null <- 1 <- 2    3 -> null
prev = 2, curr = 3

第三步：
3.next = 2  (反转)
null <- 1 <- 2 <- 3
prev = 3, curr = null

返回 prev = 3
```

### 方法二：递归法⭐

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        // 递归终止条件：空链表或只有一个节点
        if (head == null || head.next == null) {
            return head;
        }
        
        // 递归反转后面的链表，返回新的头节点
        ListNode newHead = reverseList(head.next);
        
        // 反转当前节点和下一个节点的指针
        // head.next 是原来的下一个节点，现在让它指向 head
        head.next.next = head;
        
        // 当前节点变成尾节点，指向 null
        head.next = null;
        
        // 返回新的头节点（始终是原链表的尾节点）
        return newHead;
    }
}
```

**代码说明**：
- **递归思路**：假设后面的链表已经反转完成，只需处理当前节点
- **关键操作**：`head.next.next = head` 让下一个节点反向指向当前节点
- **终止条件**：空链表或单节点链表，直接返回

**递归过程图解**（以 [1,2,3] 为例）：
```
调用栈：
reverseList(1)
  reverseList(2)
    reverseList(3)
      return 3  (终止条件)
    
    此时：3 <- 2    1 (处理节点2)
    head.next.next = head  // 3.next = 2
    head.next = null       // 2.next = null
    return 3
  
  此时：3 <- 2 <- 1 (处理节点1)
  head.next.next = head  // 2.next = 1
  head.next = null       // 1.next = null
  return 3

最终：3 <- 2 <- 1
```

### 方法三：栈辅助（不推荐，仅用于理解）

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null) {
            return null;
        }
        
        // 用栈存储所有节点
        Deque<ListNode> stack = new ArrayDeque<>();
        ListNode curr = head;
        while (curr != null) {
            stack.push(curr);
            curr = curr.next;
        }
        
        // 从栈中弹出节点，重建链表
        ListNode newHead = stack.pop();
        curr = newHead;
        while (!stack.isEmpty()) {
            curr.next = stack.pop();
            curr = curr.next;
        }
        curr.next = null;
        
        return newHead;
    }
}
```

**注意**：使用额外的栈空间，空间复杂度 O(n)，不推荐。

## 复杂度分析

### 方法一：迭代法
- **时间复杂度**：O(n)，遍历链表一次
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法二：递归法
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(n)，递归调用栈的深度

### 方法三：栈辅助
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈存储所有节点

## 关键点总结

1. **三指针迭代**：prev, curr, nextNode 是经典的链表反转模式
2. **递归理解**：假设后面已经反转完成，处理当前节点
3. **指针操作顺序**：先保存 next，再反转，最后移动
4. **边界情况**：空链表和单节点链表
5. **两种方法对比**：
   - 迭代法：空间 O(1)，更常用
   - 递归法：代码简洁，但占用栈空间

## 易错点

1. **丢失节点**：没有保存 next 指针，导致链表断裂
   ```java
   // 错误示例
   curr.next = prev;  // 此时 curr.next 的原值丢失了
   curr = curr.next;  // curr 变成了 prev，而不是原来的下一个节点
   ```

2. **返回值错误**：返回 head 而不是 prev（head 已经变成尾节点）

3. **递归理解错误**：
   - 错误：认为 `reverseList(head.next)` 只反转了一个节点
   - 正确：递归会反转整个后续链表

4. **空指针异常**：访问 `head.next` 前没有判断 `head` 是否为 null

5. **修改指针顺序错误**：
   ```java
   // 错误示例
   prev = curr;       // 先移动 prev
   curr.next = prev;  // 此时指向的是自己，形成环
   ```
