## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`，将其沿某条水平线或垂直线分割成两个非空部分，允许将切割线相邻行/列中的某个元素移到另一侧，判断是否能实现等分。

## 解题思路

枚举所有切割位置，对每个位置计算两侧之差 `diff`。若 `diff == 0` 直接返回 true；若 `diff` 为偶数，检查切割线相邻行/列中是否存在值为 `|diff|/2` 的元素（将较大侧该值移到较小侧使两侧相等）。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean canPartitionGrid(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        long total = 0;
        for (int[] row : grid)
            for (int val : row)
                total += val;

        // 检查水平切割
        long rowPrefix = 0;
        for (int i = 0; i < m - 1; i++) {
            for (int val : grid[i]) rowPrefix += val;
            long top = rowPrefix, bottom = total - rowPrefix;
            if (top == bottom) return true;
            long diff = top - bottom; // 可正可负
            if (diff % 2 == 0) {
                long target = diff / 2; // 从上半移出 target，或从下半移出 -target
                // 检查切割线（行 i 和行 i+1）
                for (int val : grid[i]) {
                    if (val == target) return true;
                }
                for (int val : grid[i + 1]) {
                    if (val == -target) return true;
                }
            }
        }

        // 检查垂直切割
        long colPrefix = 0;
        for (int j = 0; j < n - 1; j++) {
            for (int r = 0; r < m; r++) colPrefix += grid[r][j];
            long left = colPrefix, right = total - colPrefix;
            if (left == right) return true;
            long diff = left - right;
            if (diff % 2 == 0) {
                long target = diff / 2;
                for (int r = 0; r < m; r++) {
                    if (grid[r][j] == target) return true;
                }
                for (int r = 0; r < m; r++) {
                    if (grid[r][j + 1] == -target) return true;
                }
            }
        }

        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)，枚举所有切割位置
- 空间复杂度：O(1)

## 关键点总结

1. 枚举水平和垂直切割位置，计算两侧差值
2. 差值必须为偶数才可能找到合适的移动元素
3. 移动元素 v 后差值改变 2v，需要找切割线上值为 `|diff|/2` 的元素
