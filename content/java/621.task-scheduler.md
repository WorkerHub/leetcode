## 题目描述

给你一个用字符数组 `tasks` 表示的 CPU 需要执行的任务列表，两个**相同种类**的任务之间必须有长度为整数 `n` 的冷却时间。计算完成所有任务所需要的**最短时间**。

**示例：**
```
输入：tasks = ["A","A","A","B","B","B"], n = 2
输出：8
解释：A -> B -> 待命 -> A -> B -> 待命 -> A -> B
```

## 解题思路

贪心 + 数学公式：最多任务决定最小时间。设最多任务出现 `maxCount` 次，有 `maxTasks` 个任务达到此次数：
```
时间 = max(len(tasks), (maxCount - 1) * (n + 1) + maxTasks)
```

## Java 代码实现

```java
class Solution {
    public int leastInterval(char[] tasks, int n) {
        // 统计每个任务的频率
        int[] freq = new int[26];
        for (char task : tasks) {
            freq[task - 'A']++;
        }

        // 找到最大频率
        int maxCount = 0;
        for (int f : freq) {
            maxCount = Math.max(maxCount, f);
        }

        // 统计有多少个任务达到最大频率
        int maxTasks = 0;
        for (int f : freq) {
            if (f == maxCount) maxTasks++;
        }

        // 计算最短时间
        return Math.max(tasks.length, (maxCount - 1) * (n + 1) + maxTasks);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m)，m 为任务数
- **空间复杂度**：O(1)，最多 26 个字母

## 关键点总结

1. **贪心思想**：最多的任务决定最小时间
2. **数学公式**：`(maxCount - 1) * (n + 1) + maxTasks`
3. **边界情况**：任务足够多时不需要待命，直接返回任务总数
