## 题目描述

给你一个整数数组 `nums`，其中恰好有两个元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。你可以按任意顺序返回答案。

**进阶：** 你的算法应该具有线性时间复杂度。你能否仅使用常数空间复杂度来实现？

**示例 1：**

```
输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5,3] 也是有效的答案
```

**示例 2：**

```
输入：nums = [-1,0]
输出：[-1,0]
```

**示例 3：**

```
输入：nums = [0,1]
输出：[1,0]
```

**提示：**
- `2 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 除两个数字只出现一次外，其余所有数字均出现两次

## 解题思路

这道题是"只出现一次的数字"系列的进阶版，需要用到位运算的技巧。

核心思想：
1. 利用异或运算的性质：`a ^ a = 0`，`a ^ 0 = a`
2. 将所有数字异或，得到两个只出现一次的数字的异或结果
3. 找到这个结果中任意一个为 1 的位（说明两个数在这一位不同）
4. 根据这一位将数组分成两组，每组包含一个只出现一次的数字
5. 分别对两组进行异或，得到最终结果

关键技巧：
- 异或运算：相同为 0，不同为 1
- 分组依据：选择任意一个为 1 的位进行分组
- 获取最低位的 1：`x & (-x)`

## Java 代码实现

### 方法一：位运算（推荐）⭐

```java
class Solution {
    public int[] singleNumber(int[] nums) {
        // 时间复杂度：O(n)，空间复杂度：O(1)

        // 第一步：将所有数字异或，得到两个唯一数字的异或结果
        int xorResult = 0;
        for (int num : nums) {
            xorResult ^= num;
        }

        // 第二步：找到 xorResult 中最低位的 1
        // 这一位在两个唯一数字中必然不同（一个为 0，一个为 1）
        // x & (-x) 可以提取最低位的 1
        int diffBit = xorResult & (-xorResult);

        // 第三步：根据这一位将数组分成两组，分别异或
        int num1 = 0, num2 = 0;
        for (int num : nums) {
            if ((num & diffBit) != 0) {
                // 这一位为 1 的分到第一组
                num1 ^= num;
            } else {
                // 这一位为 0 的分到第二组
                num2 ^= num;
            }
        }

        return new int[]{num1, num2};
    }
}
```

### 方法二：位运算详细注释版

```java
class Solution {
    public int[] singleNumber(int[] nums) {
        // 步骤1：获取两个唯一数字的异或结果
        // 假设两个唯一数字是 a 和 b
        // 其他数字都出现两次，异或后为 0
        // 所以最终结果是 a ^ b
        int xorAll = 0;
        for (int num : nums) {
            xorAll ^= num;
        }

        // 步骤2：找到 a 和 b 不同的某一位
        // 因为 a ≠ b，所以 a ^ b 至少有一位是 1
        // 使用 x & (-x) 获取最右边的 1
        //
        // 原理（以 x = 0110 为例）：
        // -x 在补码中：先取反再加1
        // ~x = 1001，-x = 1010
        // x & (-x) = 0010（只保留最右边的 1）
        int rightmostOne = xorAll & (-xorAll);

        // 步骤3：根据这一位将数字分成两组
        // 一组在这一位是 1，一组在这一位是 0
        // a 和 b 必然在不同的组
        // 其他成对出现的数字会在同一组，异或后为 0
        int a = 0, b = 0;
        for (int num : nums) {
            if ((num & rightmostOne) != 0) {
                a ^= num; // 这一位是 1 的分到 a 组
            } else {
                b ^= num; // 这一位是 0 的分到 b 组
            }
        }

        return new int[]{a, b};
    }
}
```

### 方法三：哈希表（直观但不满足进阶要求）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] singleNumber(int[] nums) {
        // 使用哈希表统计每个数字的出现次数
        // 时间复杂度：O(n)，空间复杂度：O(n)
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        int[] result = new int[2];
        int idx = 0;
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == 1) {
                result[idx++] = entry.getKey();
            }
        }

        return result;
    }
}
```

### 方法四：使用集合

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int[] singleNumber(int[] nums) {
        // 使用集合模拟异或效果
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (!seen.add(num)) {
                // 如果已存在，说明出现两次，从集合中移除
                seen.remove(num);
            }
        }

        // 集合中剩余的就是只出现一次的数字
        int[] result = new int[2];
        int idx = 0;
        for (int num : seen) {
            result[idx++] = num;
        }
        return result;
    }
}
```

## 复杂度分析

**方法一、二（位运算）：**
- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)，只使用常数额外空间

**方法三、四（哈希表/集合）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 图解示例

以 `nums = [1,2,1,3,2,5]` 为例：

### 步骤1：全部异或

```
1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5
= (1 ^ 1) ^ (2 ^ 2) ^ 3 ^ 5
= 0 ^ 0 ^ 3 ^ 5
= 3 ^ 5
= 0011 ^ 0101
= 0110
= 6
```

### 步骤2：找到不同的位

```
xorResult = 6 = 0110 (二进制)

获取最低位的 1：
6 的二进制：  0110
-6 的补码：   1010
6 & (-6)：    0010 = 2

所以用第 2 位（从右往左，从 1 开始）来分组
```

### 步骤3：分组异或

```
diffBit = 2 = 0010

检查每个数字的第 2 位：
1 = 0001，第2位=0 → 分到第二组
2 = 0010，第2位=1 → 分到第一组
1 = 0001，第2位=0 → 分到第二组
3 = 0011，第2位=1 → 分到第一组
2 = 0010，第2位=1 → 分到第一组
5 = 0101，第2位=0 → 分到第二组

第一组：2, 3, 2 → 2 ^ 3 ^ 2 = 3
第二组：1, 1, 5 → 1 ^ 1 ^ 5 = 5

结果：[3, 5]
```

## 位运算技巧详解

### 获取最低位的 1

```java
// x & (-x) 原理（以 x = 12 = 1100 为例）：
// x = 1100
// -x（补码）= ~x + 1 = 0011 + 1 = 0100
// x & (-x) = 1100 & 0100 = 0100

// 观察：
// x 的最低位 1 右边的部分都是 0
// -x 会将这些 0 变成 1，最低位的 1 也变成 1（进位效果）
// x 和 -x 按位与，只有最低位的 1 保留
```

## 关键点总结

1. **异或性质**：`a ^ a = 0`, `a ^ 0 = a`，成对的数字异或后为 0
2. **分组思想**：找到区分两个数字的位，进行分组
3. **lowbit 技巧**：`x & (-x)` 获取最低位的 1
4. **位运算优势**：O(1) 空间复杂度，满足进阶要求
5. **分组保证**：成对出现的数字一定在同一组

## 易错点

1. **Java 中负数的处理**
   ```java
   // Java 使用补码，x & (-x) 对负数也适用
   // 但要注意：如果 xorResult 是 Integer.MIN_VALUE，
   // 则 -xorResult 溢出，此时 xorResult & (-xorResult) 仍然正确
   int diffBit = xorResult & (-xorResult);
   ```

2. **分组条件**
   ```java
   // 错误：可能因为 == diffBit 的判断漏掉某些数
   if ((num & diffBit) == diffBit)

   // 正确：判断是否非零（该位是否为 1）
   if ((num & diffBit) != 0)
   ```

3. **理解异或的交换律和结合律**
   ```java
   // 异或满足交换律和结合律
   // a ^ b ^ c = (a ^ b) ^ c = a ^ (b ^ c)
   // 因此遍历顺序不影响结果
   ```

4. **返回类型**：Java 返回 `int[]` 而不是 `List`
