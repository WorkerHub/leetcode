## 题目描述

给你字符串 `word1` 和 `word2`，恰好交换一次（各取一个字符互换），若交换后两字符串中不同字符数相同则返回 `true`。

## 解题思路

枚举所有字符对 `(c1, c2)` 共 26*26 种，计算交换后两字符串不同字符数的变化是否相等。当 `c1 == c2` 时不同字符数不变；否则根据各字符在原串中是否存在来更新计数。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isItPossible(String word1, String word2) {
        int[] freq1 = new int[26], freq2 = new int[26];
        for (char c : word1.toCharArray()) freq1[c - 'a']++;
        for (char c : word2.toCharArray()) freq2[c - 'a']++;
        int d1 = countDistinct(freq1), d2 = countDistinct(freq2);

        for (int i = 0; i < 26; i++) {
            if (freq1[i] == 0) continue;
            for (int j = 0; j < 26; j++) {
                if (freq2[j] == 0) continue;
                if (i == j) {
                    // 交换相同字符，不同字符数不变
                    if (d1 == d2) return true;
                    continue;
                }
                // 计算交换 c1(i) 和 c2(j) 后的不同字符数
                int nd1 = d1, nd2 = d2;
                if (freq1[i] == 1) nd1--; // c1 从 word1 消失
                if (freq1[j] == 0) nd1++; // c2 新加入 word1
                if (freq2[j] == 1) nd2--; // c2 从 word2 消失
                if (freq2[i] == 0) nd2++; // c1 新加入 word2
                if (nd1 == nd2) return true;
            }
        }
        return false;
    }

    private int countDistinct(int[] freq) {
        int cnt = 0;
        for (int f : freq) if (f > 0) cnt++;
        return cnt;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|word1| + |word2| + 26²)
- **空间复杂度**：O(26)

## 关键点总结

1. 枚举字符对而非下标对，共 676 种可能
2. c1 == c2 时两串不同字符数不变，仅需判断原始是否相等
3. 交换后不同字符数变化只取决于 c1/c2 在各自字符串中的频次
