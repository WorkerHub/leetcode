## 题目描述

给定无向图 graph，判断是否为二分图（能否用两种颜色染色，使相邻节点不同色）。

**示例：**
```
输入：graph = [[1,3],[0,2],[1,3],[0,2]]
输出：true（分为 {0,2} 和 {1,3}）
```

## 解题思路

DFS 染色：给节点染色 1/-1，邻居染相反色。若发现冲突则不是二分图。注意图可能不连通。

## Java 代码实现

```java
class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n]; // 0=未染色, 1/-1=两种颜色

        for (int i = 0; i < n; i++) {
            if (color[i] == 0 && !dfs(graph, color, i, 1)) {
                return false;
            }
        }
        return true;
    }

    private boolean dfs(int[][] graph, int[] color, int node, int c) {
        color[node] = c;
        for (int neighbor : graph[node]) {
            if (color[neighbor] == c) return false;
            if (color[neighbor] == 0 && !dfs(graph, color, neighbor, -c)) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V)

## 关键点总结

1. **DFS 染色**：相邻节点染相反颜色
2. **冲突检测**：邻居已同色则非二分图
3. **不连通图**：需遍历所有节点作为起点
