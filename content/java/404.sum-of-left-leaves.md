## 题目描述

给定二叉树的根节点 root，返回所有左叶子之和。

**示例 1：**
```
    3
   / \
  9  20
    /  \
   15   7

输入：root = [3,9,20,null,null,15,7]
输出：24
解释：在这个二叉树中，有两个左叶子，分别是 9 和 15，所以返回 24
```

**示例 2：**
```
输入：root = [1]
输出：0
```

**提示：**
- 节点数在 [1, 1000] 范围内
- -1000 <= Node.val <= 1000

## 解题思路

这道题的关键是理解什么是"左叶子"：
- 叶子节点：没有左右子节点的节点
- 左叶子：是其父节点的左子节点，且本身是叶子节点

核心思路：
1. 遍历二叉树的所有节点
2. 判断当前节点的左子节点是否是叶子节点
3. 如果是，累加其值
4. 递归处理左右子树

解决方案：
- **方法一（推荐）**：递归（DFS）
- **方法二**：递归（传递 isLeft 标志）
- **方法三**：迭代（DFS 栈）
- **方法四**：迭代（BFS 队列）
- **方法五**：Morris 遍历

## Java 代码实现

### 方法一：递归（推荐）

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        // 递归求解：判断左子节点是否为叶子节点
        if (root == null) return 0;

        int total = 0;

        // 检查左子节点是否为叶子节点
        if (root.left != null) {
            // 左子节点存在且没有子节点，说明是左叶子
            if (root.left.left == null && root.left.right == null) {
                total += root.left.val;
            } else {
                // 左子节点不是叶子，继续递归
                total += sumOfLeftLeaves(root.left);
            }
        }

        // 递归处理右子树（右子树中也可能有左叶子）
        total += sumOfLeftLeaves(root.right);

        return total;
    }
}
```

### 方法二：递归（简洁版，传递标志）

```java
class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        // 更简洁的递归写法，通过参数传递是否为左子节点
        return dfs(root, false);
    }

    /**
     * node:   当前节点
     * isLeft: 当前节点是否为其父节点的左子节点
     */
    private int dfs(TreeNode node, boolean isLeft) {
        if (node == null) return 0;

        // 如果是左叶子节点，返回其值
        if (isLeft && node.left == null && node.right == null) {
            return node.val;
        }

        // 递归处理左右子树
        return dfs(node.left, true) + dfs(node.right, false);
    }
}
```

### 方法三：迭代（DFS 栈）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        // 使用栈进行迭代 DFS
        if (root == null) return 0;

        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        int total = 0;

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();

            // 检查左子节点是否为叶子
            if (node.left != null) {
                if (node.left.left == null && node.left.right == null) {
                    total += node.left.val;  // 是左叶子，直接累加
                } else {
                    stack.push(node.left);  // 不是叶子，继续搜索
                }
            }

            // 右子节点入栈（不是左叶子，但可能包含左叶子）
            if (node.right != null) {
                stack.push(node.right);
            }
        }

        return total;
    }
}
```

### 方法四：迭代（BFS 队列）

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        // 使用队列进行 BFS 层序遍历
        if (root == null) return 0;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int total = 0;

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();

            // 检查左子节点
            if (node.left != null) {
                if (node.left.left == null && node.left.right == null) {
                    // 是左叶子
                    total += node.left.val;
                } else {
                    // 不是叶子，继续遍历
                    queue.offer(node.left);
                }
            }

            // 右子节点
            if (node.right != null) {
                queue.offer(node.right);
            }
        }

        return total;
    }
}
```

### 方法五：Morris 遍历（空间优化）

```java
class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        // Morris 遍历：O(1) 空间复杂度
        int total = 0;
        TreeNode current = root;

        while (current != null) {
            if (current.left == null) {
                // 没有左子树，移动到右子树
                current = current.right;
            } else {
                // 找到左子树的最右节点（前驱节点）
                TreeNode predecessor = current.left;
                while (predecessor.right != null && predecessor.right != current) {
                    predecessor = predecessor.right;
                }

                if (predecessor.right == null) {
                    // 建立线索（第一次访问）
                    predecessor.right = current;

                    // 检查左子节点是否为叶子
                    if (current.left.left == null && current.left.right == null) {
                        total += current.left.val;
                    }

                    current = current.left;
                } else {
                    // 恢复树结构（第二次访问，断开线索）
                    predecessor.right = null;
                    current = current.right;
                }
            }
        }

        return total;
    }
}
```

## 复杂度分析

### 方法一、二：递归

- **时间复杂度**：O(n)
  - 需要遍历所有节点一次

- **空间复杂度**：O(h)
  - h 是树的高度，递归栈的深度
  - 最坏情况（链表）：O(n)
  - 平衡树：O(log n)

### 方法三、四：迭代

- **时间复杂度**：O(n)
  - 遍历所有节点

- **空间复杂度**：O(n)
  - 栈或队列最多存储 O(n) 个节点

### 方法五：Morris 遍历

- **时间复杂度**：O(n)
  - 每个节点最多访问两次

- **空间复杂度**：O(1)
  - 不使用额外的栈或队列

## 关键点总结

1. **左叶子的定义**：
   - 必须是其父节点的左子节点
   - 必须是叶子节点（无左右子节点）

2. **判断逻辑**：
   - 在父节点处判断其左子节点是否为叶子
   - 不能在节点自身判断，因为节点不知道自己是左还是右

3. **遍历方式**：
   - 任何遍历方式都可以（前序、中序、后序、层序）
   - 关键是在每个节点检查其左子节点

4. **边界条件**：
   - 空树返回 0
   - 只有根节点返回 0（根节点不是任何节点的左子节点）

## 易错点

1. **概念混淆**：
   - 错误：认为所有叶子节点都是左叶子
   - 正确：只有是父节点左子节点的叶子节点才是左叶子

2. **判断位置**：
   - 错误：在当前节点判断自己是否是左叶子
   - 正确：在父节点判断左子节点是否是叶子

3. **右子树遗漏**：
   - 错误：只递归左子树
   - 正确：右子树也要递归（右子树中可能有左叶子）

4. **根节点处理**：
   - 根节点本身不可能是左叶子
   - 但根节点的左子节点可能是左叶子
