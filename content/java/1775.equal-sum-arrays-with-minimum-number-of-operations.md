## 题目描述

给你值均在 1-6 之间的整数数组 `nums1` 和 `nums2`，每次操作可将任意元素改为 1-6 中的任意值，返回使两数组和相等的最少操作数（不可能则返回 -1）。

## 解题思路

设 s1 < s2（否则交换），差值 `diff = s2 - s1`。贪心：每次操作优先选贡献最大的（将 nums1 中的元素增到 6，或将 nums2 中的元素减到 1），用桶统计 1-5 各贡献值的操作数，从大到小消耗差值。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums1, int[] nums2) {
        int s1 = 0, s2 = 0;
        for (int x : nums1) s1 += x;
        for (int x : nums2) s2 += x;

        if (s1 == s2) return 0;

        // 保证 s1 < s2，若不然则交换
        if (s1 > s2) {
            int[] tmp = nums1; nums1 = nums2; nums2 = tmp;
            int t = s1; s1 = s2; s2 = t;
        }

        // 不可行性检查
        if (6L * nums1.length < (long) nums2.length) return -1;

        int diff = s2 - s1;
        int[] gain = new int[7]; // gain[g] = 贡献为 g 的操作数量

        for (int y : nums1) gain[6 - y]++; // nums1 增大到 6，贡献 6-y
        for (int x : nums2) gain[x - 1]++; // nums2 减小到 1，贡献 x-1

        int ops = 0;
        for (int g = 5; g >= 1 && diff > 0; g--) {
            // 使用贡献为 g 的操作，最多用 gain[g] 次
            int use = Math.min(gain[g], (diff + g - 1) / g);
            diff -= use * g;
            ops += use;
        }

        return diff <= 0 ? ops : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：优先使用贡献最大（5）的操作
2. 值域 1-6，贡献范围 1-5，用桶统计代替排序
3. 不妨设 s1 < s2，统一处理方向
