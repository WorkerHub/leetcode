## 题目描述

给你双向链表的某个节点（不一定是头节点），将整个链表转换为数组返回（按链表顺序）。

## 解题思路

先通过 `prev` 指针向左找到头节点（prev 为 null 的节点），再从头节点沿 `next` 遍历整个链表。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] toArray(Node node) {
        // 先通过 prev 指针找到头节点
        while (node.prev != null) node = node.prev;
        // 从头节点遍历
        List<Integer> result = new ArrayList<>();
        while (node != null) {
            result.add(node.val);
            node = node.next;
        }
        int[] arr = new int[result.size()];
        for (int i = 0; i < arr.length; i++) arr[i] = result.get(i);
        return arr;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 双向链表通过 `prev` 指针可以向左找到头节点
2. 找到头节点后正向遍历即可
3. 与 3263 的区别：输入是链表中任意节点，需先找头节点
