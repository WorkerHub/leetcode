## 题目描述

给你 `n` 台服务器、请求日志 `logs` 和查询数组 `queries`，对每个查询 `[l, r]` 返回在时间范围 `[l, r]` 内没有收到任何请求的服务器数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countServers(int n, int[][] logs, int x, int[][] queries) {
        // 日志按时间排序
        Arrays.sort(logs, (a, b) -> a[1] - b[1]);
        // 查询按右端排序，保留原始下标
        int q = queries.length;
        Integer[] qi = new Integer[q];
        for (int i = 0; i < q; i++) qi[i] = i;
        Arrays.sort(qi, (a, b) -> queries[a][1] - queries[b][1]);

        int[] ans = new int[q];
        Map<Integer, Integer> cnt = new HashMap<>();
        int active = 0, left = 0, right = 0;

        for (int idx : qi) {
            int l = queries[idx][1] - x, r = queries[idx][1];
            // 扩展右端：加入所有 time <= r 的日志
            while (right < logs.length && logs[right][1] <= r) {
                int sid = logs[right][0];
                if (cnt.merge(sid, 1, Integer::sum) == 1) active++;
                right++;
            }
            // 收缩左端：移除所有 time < l 的日志
            while (left < right && logs[left][1] < l) {
                int sid = logs[left][0];
                if (cnt.merge(sid, -1, Integer::sum) == 0) {
                    cnt.remove(sid);
                    active--;
                }
                left++;
            }
            ans[idx] = n - active;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，排序
- 空间复杂度：O(n + q)

## 关键点总结

1. 离线按查询右端排序，配合双指针维护滑动窗口
2. 哈希表维护窗口内活跃服务器集合
3. 答案 = 总服务器数 - 活跃服务器数
