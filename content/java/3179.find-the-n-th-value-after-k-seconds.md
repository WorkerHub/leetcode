## 题目描述

初始数组为 n 个 1，每秒将每个元素替换为其自身到末尾的后缀和，返回 k 秒后第一个元素的值（对 10^9+7 取模）。

## 解题思路

通过数学推导，k 秒后 `a[0] = C(n+k-1, k)`。等价地，每秒操作相当于求前缀和（从右向左），k 次后第一个元素等于放球模型的组合数。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public int valueAfterKSeconds(int n, int k) {
        // a[0] = C(n+k-1, k) mod MOD
        return comb(n + k - 1, k);
    }

    private int comb(int n, int r) {
        // 计算 C(n, r) mod MOD，使用逐步乘除法
        r = Math.min(r, n - r);
        long num = 1, den = 1;
        for (int i = 0; i < r; i++) {
            num = num * (n - i) % MOD;
            den = den * (i + 1) % MOD;
        }
        // 费马小定理求逆元：den^(MOD-2) mod MOD
        return (int) (num * modPow(den, MOD - 2, MOD) % MOD);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k log MOD)（组合数计算 + 快速幂）
- **空间复杂度**：O(1)

## 关键点总结

1. k 秒后 a[0] = C(n+k-1, k)，可通过归纳证明
2. 组合数对大素数取模，用费马小定理求逆元
3. 模拟方法也可用：从右向左做 k 次前缀和累加
