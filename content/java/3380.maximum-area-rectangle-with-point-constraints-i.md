## 题目描述

给你平面点集 `points`，找一个轴对齐矩形，四顶点均在 `points` 中且矩形严格内部无其他点，返回最大矩形面积，不存在则返回 -1。

## 解题思路

数据量极小（n <= 10），枚举所有 x 坐标对和 y 坐标对，检验四个角是否都在点集中，以及矩形严格内部是否无点，取满足条件的最大面积。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxRectangleArea(int[][] points) {
        Set<String> pointSet = new HashSet<>();
        for (int[] p : points) pointSet.add(p[0] + "," + p[1]);

        // 收集所有不重复的 x、y 坐标
        Set<Integer> xSet = new TreeSet<>(), ySet = new TreeSet<>();
        for (int[] p : points) { xSet.add(p[0]); ySet.add(p[1]); }
        Integer[] xs = xSet.toArray(new Integer[0]);
        Integer[] ys = ySet.toArray(new Integer[0]);

        long best = -1;
        for (int i = 0; i < xs.length; i++) {
            for (int j = i + 1; j < xs.length; j++) {
                int x1 = xs[i], x2 = xs[j];
                for (int k = 0; k < ys.length; k++) {
                    for (int l = k + 1; l < ys.length; l++) {
                        int y1 = ys[k], y2 = ys[l];
                        // 检查四个角是否在点集中
                        if (!pointSet.contains(x1 + "," + y1)) continue;
                        if (!pointSet.contains(x1 + "," + y2)) continue;
                        if (!pointSet.contains(x2 + "," + y1)) continue;
                        if (!pointSet.contains(x2 + "," + y2)) continue;
                        // 检查严格内部是否有点
                        boolean hasInner = false;
                        for (int[] p : points) {
                            if (p[0] > x1 && p[0] < x2 && p[1] > y1 && p[1] < y2) {
                                hasInner = true;
                                break;
                            }
                        }
                        if (!hasInner) {
                            best = Math.max(best, (long)(x2 - x1) * (y2 - y1));
                        }
                    }
                }
            }
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^5)，枚举 4 组坐标 * n 个点检验（n <= 10 实际很快）
- 空间复杂度：O(n)

## 关键点总结

1. 轴对齐矩形由两个 x 坐标和两个 y 坐标唯一确定。
2. 四个角都必须在 points 中。
3. 严格内部（`x1 < px < x2 && y1 < py < y2`）不能有其他点。
