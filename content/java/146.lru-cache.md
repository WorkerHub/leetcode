## 题目描述

请你设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以正整数作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1`
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value`；如果不存在，则向缓存中插入该组 `key-value`。如果插入操作导致关键字数量超过 `capacity`，则应该逐出最久未使用的关键字

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

**示例：**

```
输入
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
输出
[null, null, null, 1, null, -1, null, -1, 3, 4]

解释
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1
lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4
```

**提示：**

- `1 <= capacity <= 3000`
- `0 <= key <= 10000`
- `0 <= value <= 10^5`
- 最多调用 `2 * 10^5` 次 `get` 和 `put`

## 解题思路

LRU（Least Recently Used）缓存是一种常见的缓存淘汰策略，核心思想是：当缓存满时，优先淘汰最久未被访问的数据。

要实现 O(1) 的 get 和 put 操作，需要同时满足：
1. 快速查找：需要哈希表
2. 维护访问顺序：需要链表
3. 快速删除和插入：需要双向链表

**数据结构设计：**

- **哈希表**：存储 key 到链表节点的映射，实现 O(1) 查找
- **双向链表**：维护数据的访问顺序
  - 链表头部：最近使用的数据
  - 链表尾部：最久未使用的数据

**核心操作：**

1. **get(key)**：
   - 如果 key 存在，将对应节点移到链表头部（标记为最近使用）
   - 返回 value

2. **put(key, value)**：
   - 如果 key 已存在，更新 value，将节点移到头部
   - 如果 key 不存在：
     - 插入新节点到头部
     - 如果超过容量，删除尾部节点

## Java 代码实现

### 方法一：哈希表 + 双向链表（推荐）

```java
class LRUCache {
    // 双向链表节点
    private static class DListNode {
        int key;
        int value;
        DListNode prev;
        DListNode next;

        DListNode() {}

        DListNode(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private int capacity;
    private Map<Integer, DListNode> cache;  // key -> DListNode
    // 使用虚拟头尾节点简化边界处理
    private DListNode head;
    private DListNode tail;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.cache = new HashMap<>();
        this.head = new DListNode();
        this.tail = new DListNode();
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        if (!cache.containsKey(key)) {
            return -1;
        }
        DListNode node = cache.get(key);
        moveToHead(node);  // 标记为最近使用
        return node.value;
    }

    public void put(int key, int value) {
        if (cache.containsKey(key)) {
            // 更新已存在的节点
            DListNode node = cache.get(key);
            node.value = value;
            moveToHead(node);
        } else {
            // 插入新节点
            DListNode node = new DListNode(key, value);
            cache.put(key, node);
            addToHead(node);

            // 检查容量
            if (cache.size() > capacity) {
                // 删除最久未使用的节点
                DListNode removed = removeTail();
                cache.remove(removed.key);
            }
        }
    }

    private void removeNode(DListNode node) {
        // 从链表中移除节点
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addToHead(DListNode node) {
        // 将节点添加到链表头部
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void moveToHead(DListNode node) {
        // 将节点移动到链表头部
        removeNode(node);
        addToHead(node);
    }

    private DListNode removeTail() {
        // 移除链表尾部节点
        DListNode node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

### 方法二：使用 LinkedHashMap（Java 内置实现）

```java
class LRUCache extends LinkedHashMap<Integer, Integer> {
    private int capacity;

    public LRUCache(int capacity) {
        // accessOrder=true 表示按访问顺序排序
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }

    public int get(int key) {
        return super.getOrDefault(key, -1);
    }

    public void put(int key, int value) {
        super.put(key, value);
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        // 当元素数量超过容量时，删除最旧的元素
        return size() > capacity;
    }
}
```

## 复杂度分析

**方法一：哈希表 + 双向链表**

- 时间复杂度：
  - `get`: O(1) - 哈希查找 + 链表操作
  - `put`: O(1) - 哈希查找/插入 + 链表操作
- 空间复杂度：O(capacity) - 哈希表和链表存储 capacity 个节点

**方法二：LinkedHashMap**

- 时间复杂度：
  - `get`: O(1)
  - `put`: O(1)
- 空间复杂度：O(capacity)

## 关键点总结

1. **数据结构组合**：哈希表提供快速查找，双向链表维护顺序
2. **虚拟头尾节点**：简化链表的边界处理，避免空指针判断
3. **同时维护两个数据结构**：每次操作都要同步更新哈希表和链表
4. **访问即更新**：get 操作也会改变节点位置，将其标记为最近使用
5. **Java LinkedHashMap**：内部实现了哈希表 + 双向链表，是更简洁的方案

## 易错点

1. **忘记在 get 中更新位置**：get 操作也算一次访问，需要将节点移到头部
2. **链表操作顺序错误**：移除和插入节点时，要注意更新前后节点的指针
3. **哈希表与链表不同步**：删除节点时，要同时从哈希表和链表中删除
4. **边界情况处理**：
   - capacity = 1 时的特殊情况
   - 更新已存在的 key 时不应该增加节点数量
5. **虚拟节点的使用**：不要将虚拟头尾节点的 key 加入哈希表
