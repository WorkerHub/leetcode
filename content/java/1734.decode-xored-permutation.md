## 题目描述

未知排列 `arr` 由 `1` 到 `n`（`n` 为奇数）组成，`encoded[i] = arr[i] XOR arr[i+1]`。已知 `encoded`，还原 `arr`。

## 解题思路

1. 计算 `total = 1 XOR 2 XOR ... XOR n`
2. `encoded[1] XOR encoded[3] XOR ...`（奇数索引）= `arr[1] XOR arr[2] XOR ... XOR arr[n-1]`（n 为奇数时成立）
3. `arr[0] = total XOR (奇数索引 encoded 之 XOR)`
4. 按 `arr[i+1] = arr[i] XOR encoded[i]` 依次还原

## Java 代码实现

```java
class Solution {
    public int[] decode(int[] encoded) {
        int n = encoded.length + 1;

        // 计算 1 XOR 2 XOR ... XOR n
        int total = 0;
        for (int i = 1; i <= n; i++) total ^= i;

        // 计算 encoded[1] XOR encoded[3] XOR ...（奇数索引）
        // 等于 arr[1] ^ arr[2] ^ ... ^ arr[n-1]
        int xorRest = 0;
        for (int i = 1; i < encoded.length; i += 2) {
            xorRest ^= encoded[i];
        }

        // arr[0] = total ^ xorRest
        int[] arr = new int[n];
        arr[0] = total ^ xorRest;

        // 依次还原
        for (int i = 0; i < encoded.length; i++) {
            arr[i + 1] = arr[i] ^ encoded[i];
        }

        return arr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `n` 为奇数时，奇数索引的 encoded 之 XOR 恰等于除 `arr[0]` 外所有元素的 XOR
2. 利用全集 XOR 推导第一个元素，再依次还原
