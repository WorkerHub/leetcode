## 题目描述

将字符串中每个 '?' 替换为小写字母，使替换后没有相邻重复字符。

**示例：**
```
输入：s = "?zs"
输出："azs"
```

## 解题思路

贪心：每个 '?' 只需避开前后字符，从 'a','b','c' 中选即可。

## Java 代码实现

```java
class Solution {
    public String modifyString(String s) {
        char[] arr = s.toCharArray();
        int n = arr.length;
        for (int i = 0; i < n; i++) {
            if (arr[i] == '?') {
                for (char c = 'a'; c <= 'c'; c++) {
                    boolean ok = true;
                    if (i > 0 && arr[i - 1] == c) ok = false;
                    if (i < n - 1 && arr[i + 1] == c) ok = false;
                    if (ok) { arr[i] = c; break; }
                }
            }
        }
        return new String(arr);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **只需 3 个字母**：最多避开 2 个字符，第 3 个必可用
2. **原地修改**：后续 ? 依赖前面已替换的值
