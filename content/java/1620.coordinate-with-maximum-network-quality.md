## 题目描述

信号塔towers[i]=[x,y,q]，坐标(x,y)的网络质量=所有距离≤radius的塔贡献之和（floor(q/(1+d))）。求质量最大的最小整数坐标。

## 解题思路

暴力枚举：坐标范围0-50，枚举所有整数坐标计算网络质量。

## Java 代码实现

```java
class Solution {
    public int[] bestCoordinate(int[][] towers, int radius) {
        int maxQuality = 0;
        int[] best = {0, 0};
        
        for (int x = 0; x <= 50; x++) {
            for (int y = 0; y <= 50; y++) {
                int quality = 0;
                for (int[] t : towers) {
                    double d = Math.sqrt((t[0] - x) * (t[0] - x) + (t[1] - y) * (t[1] - y));
                    if (d <= radius) {
                        quality += (int)(t[2] / (1 + d));
                    }
                }
                if (quality > maxQuality) {
                    maxQuality = quality;
                    best = new int[]{x, y};
                }
            }
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(51 × 51 × M)，M为塔数
- **空间复杂度**：O(1)

## 关键点总结

1. **坐标范围有限(0-50)**：暴力枚举可行
2. **欧氏距离**：Math.sqrt
3. **严格大于才更新**：保证取最小坐标（x升序y升序遍历）
