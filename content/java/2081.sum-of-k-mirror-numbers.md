## 题目描述

k进制镜像数：十进制和k进制下都是回文数。返回最小n个k进制镜像数的十进制总和。

## 解题思路

枚举十进制回文数（按位数从小到大生成前半部分镜像），验证其k进制表示是否也是回文。

## Java 代码实现

```java
class Solution {
    public long kMirror(int k, int n) {
        long total = 0;
        int count = 0;
        
        for (int length = 1; count < n; length++) {
            // 枚举length位的十进制回文数
            int half = (length + 1) / 2;
            long start = (long) Math.pow(10, half - 1);
            long end = (long) Math.pow(10, half);
            
            for (long h = start; h < end && count < n; h++) {
                // 构造回文数
                String s = String.valueOf(h);
                StringBuilder sb = new StringBuilder(s);
                if (length % 2 == 0) {
                    sb.append(new StringBuilder(s).reverse());
                } else {
                    sb.append(new StringBuilder(s.substring(0, s.length() - 1)).reverse());
                }
                long num = Long.parseLong(sb.toString());
                
                // 验证k进制是否回文
                if (isPalindromeInBase(num, k)) {
                    total += num;
                    count++;
                }
            }
        }
        return total;
    }
    
    private boolean isPalindromeInBase(long num, int k) {
        // 将num转为k进制并检查回文
        long reversed = 0, original = num;
        while (num > 0) {
            reversed = reversed * k + num % k;
            num /= k;
        }
        return reversed == original;
    }
}
```

## 复杂度分析

- **时间复杂度**：与镜像数分布相关，约O(n × 10^(len/2))
- **空间复杂度**：O(log num)

## 关键点总结

1. **生成十进制回文**：构造前半部分再镜像
2. **验证k进制回文**：反转数字比较（无需转字符串）
3. **按位数枚举**：保证从小到大
