## 题目描述

给你整数数组 `nums`，返回全为零的子数组数目。

## 解题思路

遍历统计连续零的长度，每遇到一个新的零，当前连续零长度加 1，新增子数组数等于当前连续零长度（以当前位置结尾的全零子数组）。非零时重置计数器。

## Java 代码实现

```java
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long ans = 0, consecutive = 0;
        for (int x : nums) {
            if (x == 0) {
                consecutive++;
                ans += consecutive; // 以当前位置结尾的全零子数组数
            } else {
                consecutive = 0;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 遇到 0 时，连续零数 +1，新增子数组数等于当前连续零长度。
2. 连续 k 个零的子数组总数为 `k*(k+1)/2`（等差数列）。
3. 答案可能超过 int 范围，用 `long`。
