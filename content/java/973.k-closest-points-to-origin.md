## 题目描述

返回距离原点最近的 k 个点。

**示例：**
```
输入：points = [[1,3],[-2,2]], k = 1
输出：[[-2,2]]
```

## 解题思路

TopK 问题：排序取前 k 个，或用最大堆维护 k 个最近点。比较距离平方即可无需开方。

## Java 代码实现

```java
class Solution {
    public int[][] kClosest(int[][] points, int k) {
        Arrays.sort(points, (a, b) ->
            (a[0] * a[0] + a[1] * a[1]) - (b[0] * b[0] + b[1] * b[1]));
        return Arrays.copyOfRange(points, 0, k);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. **距离平方**：比较无需开方
2. **排序法**：简洁直接
3. **TopK 问题**：排序/堆/快速选择均可
