## 题目描述

给你两个列表 `scores` 和 `ages`，分别表示每个球员的得分和年龄。若较年长者的得分少于较年轻者，则两球员之间存在冲突（同龄无冲突）。返回所有无冲突球队中**得分最高**的总分。

**提示：**
- `1 <= scores.length == ages.length <= 1000`
- `1 <= scores[i] <= 10^6`，`1 <= ages[i] <= 1000`

## 解题思路

按**年龄升序**排序（同年龄按得分升序），转化为"得分不递减子序列的最大总分"DP 问题。

**DP 定义：** `dp[i]` = 以第 i 个球员结尾的无冲突球队最大总分。

## Java 代码实现

```java
class Solution {
    public int bestTeamScore(int[] scores, int[] ages) {
        int n = scores.length;
        // 将球员按年龄升序排序，同年龄按得分升序
        int[][] players = new int[n][2];
        for (int i = 0; i < n; i++) {
            players[i][0] = ages[i];
            players[i][1] = scores[i];
        }
        Arrays.sort(players, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        // dp[i]：以第 i 个球员结尾的无冲突球队最大总分
        int[] dp = new int[n];
        int ans = 0;
        for (int i = 0; i < n; i++) {
            dp[i] = players[i][1]; // 初始：单人球队
            for (int j = 0; j < i; j++) {
                // 年龄已排序，只需保证得分不递减
                if (players[j][1] <= players[i][1]) {
                    dp[i] = Math.max(dp[i], dp[j] + players[i][1]);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，双重循环 DP
- **空间复杂度**：O(n)，DP 数组

## 关键点总结

1. 排序后问题转化为"得分不递减子序列的最大总分"
2. 同年龄按得分升序排，避免同年龄错误排除
3. DP 初始值为每个球员单独的得分
4. 最终答案是 `max(dp)`
