## 题目描述

将长度为 n 的数组分成 3 个非空连续子数组，每段代价为首元素，返回最小总代价。

## 解题思路

第一段代价固定为 nums[0]，从 nums[1..n-1] 中找最小的两个值作为后两段的首元素。

## Java 代码实现

```java
class Solution {
    public int minimumCost(int[] nums) {
        int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] <= min1) {
                min2 = min1;
                min1 = nums[i];
            } else if (nums[i] < min2) {
                min2 = nums[i];
            }
        }
        return nums[0] + min1 + min2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 第一段代价固定为 nums[0]
2. 从 nums[1:] 中找最小和次小值
3. n ≤ 50，枚举所有分割点也可行
