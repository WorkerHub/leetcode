## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，其中 `nums2` 是 `nums1` 的一个变位词（anagram）。

变位词是指两个数组包含相同的元素，但顺序可能不同。

找到一个索引映射数组 `P`，使得 `nums1[i] = nums2[P[i]]`，对于所有 `0 <= i < nums1.length`。

返回数组 `P`。

**示例 1:**
```
输入: nums1 = [12,28,46,32,50], nums2 = [50,12,32,46,28]
输出: [1,4,3,2,0]
解释: P[0] = 1，因为 nums1[0] = 12 对应 nums2[1] = 12
      P[1] = 4，因为 nums1[1] = 28 对应 nums2[4] = 28
      P[2] = 3，因为 nums1[2] = 46 对应 nums2[3] = 46
      P[3] = 2，因为 nums1[3] = 32 对应 nums2[2] = 32
      P[4] = 0，因为 nums1[4] = 50 对应 nums2[0] = 50
```

**示例 2:**
```
输入: nums1 = [84,46], nums2 = [46,84]
输出: [1,0]
```

**提示:**
- `nums1.length == nums2.length`
- `1 <= nums1.length <= 100`
- `0 <= nums1[i], nums2[i] <= 10^5`

## 解题思路

这是一道简单的哈希表应用题。

**核心思想：**
1. 构建 nums2 的值到索引的映射
2. 对于 nums1 中的每个元素，在映射中查找对应的索引

**注意：** 如果有重复元素，需要特殊处理。

## Java 代码实现

### 方法一：哈希表（推荐）

```java
import java.util.*;

class Solution {
    public int[] anagramMappings(int[] nums1, int[] nums2) {
        // 构建 nums2 的值到索引列表的映射
        Map<Integer, Deque<Integer>> indexMap = new HashMap<>();
        for (int i = 0; i < nums2.length; i++) {
            indexMap.computeIfAbsent(nums2[i], k -> new ArrayDeque<>()).addLast(i);
        }

        // 对于每个 nums1 中的元素，找到对应的索引
        int[] result = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            result[i] = indexMap.get(nums1[i]).pollFirst();
        }

        return result;
    }
}
```

### 方法二：简单哈希表（无重复值时）

```java
import java.util.*;

class Solution {
    public int[] anagramMappings(int[] nums1, int[] nums2) {
        // 构建 nums2 的值到索引的映射
        Map<Integer, Integer> indexMap = new HashMap<>();
        for (int i = 0; i < nums2.length; i++) {
            indexMap.put(nums2[i], i);
        }

        // 查找每个 nums1 中元素对应的索引
        int[] result = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            result[i] = indexMap.get(nums1[i]);
        }

        return result;
    }
}
```

## 复杂度分析

**方法一：哈希表（带列表）**
- **时间复杂度：** O(n)，其中 n 是数组长度
- **空间复杂度：** O(n)，哈希表空间

**方法二：简单哈希表**
- **时间复杂度：** O(n)
- **空间复杂度：** O(n)

## 关键点总结

1. **哈希表应用：** 使用哈希表快速查找
2. **重复值处理：** 使用队列或指针处理重复值
3. **索引映射：** 理解题目要求的映射关系
4. **时间优化：** 预处理映射比每次查找更高效
5. **Java 集合：** 合理使用 HashMap 和 ArrayDeque

## 易错点

1. **重复值：** 如果数组有重复值，简单映射可能不够
2. **索引顺序：** 要返回的是 nums2 中的索引，不是 nums1
3. **边界情况：** 空数组、单元素数组要正确处理
4. **映射方向：** 要建立 nums2 的映射，不是 nums1
