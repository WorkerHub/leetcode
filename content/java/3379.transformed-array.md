## 题目描述

给你整数数组 `nums`，对每个下标 `i`：若 `nums[i] > 0` 向右循环跳 `nums[i]` 步，若 `nums[i] < 0` 向左循环跳，若为 0 则结果为 0，`result[i]` 取到达位置的 `nums` 值，返回结果数组。

## 解题思路

直接模拟：目标位置 = `(i + nums[i]) % n`。Java 中负数取模结果可能为负，需加 n 后再取模保证非负。

## Java 代码实现

```java
class Solution {
    public int[] constructTransformedArray(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            if (nums[i] == 0) {
                result[i] = 0;
            } else {
                // Java 负数取模可能为负，加 n 保证结果非负
                int target = ((i + nums[i]) % n + n) % n;
                result[i] = nums[target];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(n)，结果数组

## 关键点总结

1. 目标位置 = `((i + nums[i]) % n + n) % n`，处理负数取模。
2. `nums[i] == 0` 时结果为 0。
3. 模运算循环处理数组边界。
