## 题目描述

给定括号字符串 s，返回使其有效所需添加的最少括号数。

**示例：**
```
输入：s = "())"
输出：1
```

## 解题思路

计数器法：维护未匹配的左括号数 left 和需要添加的左括号数 right。遇到 `)` 时若 left > 0 则匹配，否则 right++。最终答案 = left + right。

## Java 代码实现

```java
class Solution {
    public int minAddToMakeValid(String s) {
        int left = 0;  // 未匹配的左括号数
        int right = 0; // 需要添加的左括号数

        for (char c : s.toCharArray()) {
            if (c == '(') {
                left++;
            } else {
                if (left > 0) {
                    left--; // 匹配一个左括号
                } else {
                    right++; // 需要添加一个左括号
                }
            }
        }

        return left + right;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **计数器代替栈**：O(1) 空间
2. **两种不匹配**：左括号多余或右括号多余
3. **贪心匹配**：遇到 `)` 优先匹配已有的 `(`
