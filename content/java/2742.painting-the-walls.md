## 题目描述

给你 `cost` 和 `time` 数组，雇佣画家 `i` 粉刷一面墙（花费 `cost[i]`，时间 `time[i]`），同时免费画家可粉刷 `time[i]` 面墙，返回粉刷 `n` 面墙的最低费用。

## Java 代码实现

```java
class Solution {
    public int paintWalls(int[] cost, int[] time) {
        int n = cost.length;
        // dp[j] 表示还剩 j 面墙要刷的最小费用
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;
        for (int i = 0; i < n; i++) {
            // 倒序枚举（0-1 背包），雇佣画家 i 覆盖 time[i]+1 面墙
            for (int j = n; j >= 1; j--) {
                int prev = Math.max(j - time[i] - 1, 0);
                dp[j] = Math.min(dp[j], dp[prev] + cost[i]);
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 雇佣画家 i 可覆盖 `time[i] + 1` 面墙（+1 是画家本身）
2. 转化为 0-1 背包问题
3. 倒序枚举避免重复使用同一画家
