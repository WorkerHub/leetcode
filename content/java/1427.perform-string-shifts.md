## 题目描述

给你一个字符串 `s`（由若干小写英文字母组成）和一个整数数组 `shift`，其中 `shift[i] = [direction, amount]`：

- `direction` 为 `0` 表示左移，`1` 表示右移
- `amount` 表示移动的字符个数

左移 1 位的意思：将字符串的第一个字符移动到最后。  
右移 1 位的意思：将字符串的最后一个字符移动到第一位。

请你按照 `shift` 数组依次对 `s` 进行移位操作，然后返回最终结果。

**示例 1：**

```
输入：s = "abc", shift = [[0,1],[1,2]]
输出："cab"
解释：
[0,1] 左移 1 位，"abc" → "bca"
[1,2] 右移 2 位，"bca" → "cab"
```

**示例 2：**

```
输入：s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]
输出："efgabcd"
解释：
[1,1] 右移 1 位，"abcdefg" → "gabcdef"
[1,1] 右移 1 位，"gabcdef" → "fgabcde"
[0,2] 左移 2 位，"fgabcde" → "abcdefg"
[1,3] 右移 3 位，"abcdefg" → "efgabcd"
```

**提示：**

- `1 <= s.length <= 100`
- `1 <= shift.length <= 100`
- `shift[i].length == 2`
- `0 <= shift[i][0] <= 1`
- `0 <= shift[i][1] <= 100`

## 解题思路

### 关键观察：合并所有移位

多次移位操作可以合并为一次：

- 左移 amount 等价于右移 -amount（负数表示左移）
- 将所有移位求代数和：正数表示右移，负数表示左移
- 对字符串长度取模，得到等效的单次移位

**合并规则：**
```
total = sum(amount if direction==1 else -amount)
total = total % n  // n = len(s)，消除冗余移位
```

右移 total 位：`s[-total:] + s[:-total]`（Java 中用子串拼接）

## Java 代码实现

### 方法一：合并移位（推荐）

```java
class Solution {
    public String stringShift(String s, int[][] shift) {
        int n = s.length();
        if (n == 0) return s;

        // 合并所有移位：右移为正，左移为负
        int total = 0;
        for (int[] op : shift) {
            if (op[0] == 1) {
                total += op[1];   // 右移
            } else {
                total -= op[1];   // 左移
            }
        }

        // 取模，得到等效的净右移量（0 <= total < n）
        total = ((total % n) + n) % n;  // 确保结果非负

        // 右移 total 位：最后 total 个字符移到前面
        if (total == 0) return s;
        return s.substring(n - total) + s.substring(0, n - total);
    }
}
```

### 方法二：逐步模拟（理解用）

```java
class Solution {
    public String stringShift(String s, int[][] shift) {
        int n = s.length();

        for (int[] op : shift) {
            int direction = op[0];
            int amount = op[1] % n;  // 防止 amount >= n 的冗余移位
            if (amount == 0) continue;

            if (direction == 0) {
                // 左移 amount 位：前 amount 个字符移到末尾
                s = s.substring(amount) + s.substring(0, amount);
            } else {
                // 右移 amount 位：后 amount 个字符移到前面
                s = s.substring(n - amount) + s.substring(0, n - amount);
            }
        }

        return s;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 合并移位 | O(len(shift) + n) | O(n) |
| 逐步模拟 | O(len(shift) * n) | O(n) |

合并移位是最优解，先合并再执行一次移位，避免了多次字符串切片。

## 图解示例

以 `s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]` 为例：

```
合并：total = +1 + 1 - 2 + 3 = 3（净右移 3 位）
total % 7 = 3

右移 3 位：s.substring(7-3) + s.substring(0, 7-3) = "efg" + "abcd" = "efgabcd" ✓
```

## 关键点总结

1. 多次移位可以合并：右移为正，左移为负，求代数和
2. 对字符串长度取模，消除冗余移位（移位 n 次等于不移）
3. Java 中右移 k 位的字符串操作：`s.substring(n-k) + s.substring(0, n-k)`
4. 注意 Java 中取模可能得到负数：用 `((total % n) + n) % n` 确保非负

## 易错点

1. `amount` 可以超过字符串长度，需要取模
2. Java 中 `total % n` 可能为负数（当 total < 0 时），需要额外加 n 再取模
3. 左移 k 位的操作：`s.substring(k) + s.substring(0, k)`；右移 k 位：`s.substring(n-k) + s.substring(0, n-k)`
