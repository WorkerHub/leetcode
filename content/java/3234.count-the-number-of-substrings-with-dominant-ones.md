## 题目描述

给你一个二进制字符串 `s`，若子字符串中 `'1'` 的数量大于等于 `'0'` 数量的平方，返回满足条件的子字符串数量。

## Java 代码实现

```java
class Solution {
    public int numberOfSubstrings(String s) {
        int n = s.length();
        // 前缀 1 的数量
        int[] ones = new int[n + 1];
        for (int i = 0; i < n; i++) {
            ones[i + 1] = ones[i] + (s.charAt(i) == '1' ? 1 : 0);
        }

        // 收集所有 0 的位置
        int[] zeroPos = new int[n];
        int m = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '0') zeroPos[m++] = i;
        }

        long ans = 0;

        // z=0：全 1 子串，统计连续 1 段的贡献
        int cnt1 = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') { cnt1++; ans += cnt1; }
            else cnt1 = 0;
        }

        // z>=1：枚举子串中恰好有 z 个 0
        for (int z = 1; z <= m; z++) {
            if ((long) z * z > n) break;
            int need = z * z + z - 1; // 子串长度至少需要 right - left >= need

            for (int i = 0; i + z - 1 < m; i++) {
                int leftZero = zeroPos[i];
                int rightZero = zeroPos[i + z - 1];
                int leftMin = i > 0 ? zeroPos[i - 1] + 1 : 0;
                int rightMax = (i + z < m) ? zeroPos[i + z] - 1 : n - 1;

                // 对于固定左端 l，右端 r >= max(rightZero, l + need)
                for (int l = leftMin; l <= leftZero; l++) {
                    int rMin = Math.max(rightZero, l + need);
                    if (rMin <= rightMax) {
                        ans += rightMax - rMin + 1;
                    }
                }
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(n))
- 空间复杂度：O(n)

## 关键点总结

1. 枚举 0 的数量 z（最多 sqrt(n) 种有意义的 z）
2. 对每个 z，枚举包含恰好 z 个 0 的子串组
3. 用前缀和快速统计满足条件的右端点数量
