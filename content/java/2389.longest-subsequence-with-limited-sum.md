## 题目描述

给你整数数组 `nums` 和查询数组 `queries`，对每个查询返回 `nums` 中元素之和不超过该查询值的子序列最大长度。

## 解题思路

贪心选最小的元素：对 `nums` 排序后计算前缀和，对每个查询用二分查找前缀和数组，找最大的个数使得前缀和 <= 查询值。

## Java 代码实现

```java
class Solution {
    public int[] answerQueries(int[] nums, int[] queries) {
        Arrays.sort(nums);
        int n = nums.length;
        long[] prefix = new long[n]; // 用 long 防止溢出
        prefix[0] = nums[0];
        for (int i = 1; i < n; i++) prefix[i] = prefix[i - 1] + nums[i];

        int m = queries.length;
        int[] result = new int[m];
        for (int i = 0; i < m; i++) {
            // 二分找最右一个 prefix[j] <= queries[i]
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (prefix[mid] <= queries[i]) lo = mid + 1;
                else hi = mid;
            }
            result[i] = lo; // lo 即为 <= queries[i] 的前缀和个数
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心选最小的若干元素使长度最大，排序后前缀和对应最优子序列。
2. 二分查找前缀和数组，找最多能取多少个元素使和 <= 查询值。
3. 前缀和可能超 int 范围（10^3 个 10^6），用 `long`。
