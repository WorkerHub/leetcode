## 题目描述

给你整数数组 `nums`、查询数组 `queries` 和整数 `x`，对每个查询 `queries[i]` 返回 `x` 在 `nums` 中第 `queries[i]` 次出现的下标，不足则返回 -1。

## 解题思路

预处理：收集 x 在 nums 中所有出现位置存入列表。每个查询 q 直接访问 `positions[q-1]`（1-indexed），越界则返回 -1。

## Java 代码实现

```java
class Solution {
    public int[] occurrencesOfElement(int[] nums, int[] queries, int x) {
        // 收集 x 的所有出现位置
        List<Integer> positions = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == x) positions.add(i);
        }
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int q = queries[i];
            // 第 q 次出现对应下标 q-1（1-indexed 转 0-indexed）
            ans[i] = q <= positions.size() ? positions.get(q - 1) : -1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)
- **空间复杂度**：O(n)

## 关键点总结

1. 预处理位置列表后，每次查询 O(1) 直接索引
2. 查询是 1-indexed，访问 `positions.get(q - 1)`
