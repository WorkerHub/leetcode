## 题目描述

你有 `n` 个工作和 `m` 个工人。给定三个数组：`difficulty`, `profit` 和 `worker`，其中:

- `difficulty[i]` 和 `profit[i]` 表示第 `i` 个工作的难度和利润
- `worker[j]` 是第 `j` 个工人的能力，即该工人只能完成难度小于等于 `worker[j]` 的工作

每个工人最多只能安排 **一个** 工作，但是一个工作可以 **完成多次**。

返回我们所能获得的最大利润。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxProfitAssignment(int[] difficulty, int[] profit, int[] worker) {
        int n = difficulty.length;

        // 将工作按难度排序
        int[][] jobs = new int[n][2];
        for (int i = 0; i < n; i++) {
            jobs[i] = new int[]{difficulty[i], profit[i]};
        }
        Arrays.sort(jobs, (a, b) -> a[0] - b[0]);
        Arrays.sort(worker);

        int maxProfit = 0;
        int best = 0;  // 当前难度下的最大利润
        int i = 0;

        for (int ability : worker) {
            // 更新当前能力下的最大利润
            while (i < n && jobs[i][0] <= ability) {
                best = Math.max(best, jobs[i][1]);
                i++;
            }
            maxProfit += best;
        }

        return maxProfit;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m log m)
- **空间复杂度**：O(n)

## 关键点总结

1. **排序**：工作和工人都按能力排序
2. **贪心**：每个工人选择能做的最高利润工作
3. **双指针**：维护当前最大利润

## 学习建议

1. **贪心策略**：局部最优到全局最优
2. **双指针**：有序数组的处理
