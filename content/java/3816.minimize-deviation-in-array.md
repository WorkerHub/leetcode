## 题目描述

给定正整数数组 `nums`，偶数可除以 2，奇数可乘以 2，返回数组最大值与最小值之差的最小可能值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumDeviation(int[] nums) {
        // 所有奇数乘以 2，统一变为偶数后只需不断缩小最大值
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        int minVal = Integer.MAX_VALUE;
        for (int num : nums) {
            if (num % 2 == 1) num *= 2;
            maxHeap.offer(num);
            minVal = Math.min(minVal, num);
        }

        int result = Integer.MAX_VALUE;
        while (!maxHeap.isEmpty()) {
            int maxVal = maxHeap.poll();
            result = Math.min(result, maxVal - minVal);
            if (maxVal % 2 == 1) break; // 最大值为奇数，无法继续缩小
            int newVal = maxVal / 2;
            minVal = Math.min(minVal, newVal);
            maxHeap.offer(newVal);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n * log(max_val))
- 空间复杂度：O(n)

## 关键点总结

1. 先将所有奇数乘以 2，后续只需不断缩小偶数最大值
2. 最大堆每次取出最大值除以 2，同步维护最小值
3. 最大值为奇数时停止（无法继续缩小）
