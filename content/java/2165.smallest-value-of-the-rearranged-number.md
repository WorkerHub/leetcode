## 题目描述

重排整数num的各位数字，正数使值最小（无前导零），负数使绝对值最大。

## 解题思路

正数：数字升序排列，最小非零数字放首位避免前导零。负数：数字降序排列使绝对值最大。

## Java 代码实现

```java
class Solution {
    public long smallestNumber(long num) {
        if (num == 0) return 0;
        
        boolean negative = num < 0;
        char[] digits = String.valueOf(Math.abs(num)).toCharArray();
        Arrays.sort(digits);
        
        if (negative) {
            // 降序排列使绝对值最大
            int l = 0, r = digits.length - 1;
            while (l < r) {
                char t = digits[l]; digits[l] = digits[r]; digits[r] = t;
                l++; r--;
            }
            return -Long.parseLong(new String(digits));
        } else {
            // 升序排列，将最小非零数字放首位
            int firstNonZero = 0;
            while (firstNonZero < digits.length && digits[firstNonZero] == '0') {
                firstNonZero++;
            }
            char t = digits[0]; digits[0] = digits[firstNonZero]; digits[firstNonZero] = t;
            return Long.parseLong(new String(digits));
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(D log D)，D为位数
- **空间复杂度**：O(D)

## 关键点总结

1. **正数升序+处理前导零**：最小非零数字放首位
2. **负数降序**：绝对值越大负数越小
3. **用long**：num范围到10^15，超出int
