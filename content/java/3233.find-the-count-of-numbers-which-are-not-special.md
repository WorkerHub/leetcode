## 题目描述

给你两个正整数 `l` 和 `r`，若一个数恰好有 2 个约数（不含自身）则为特殊数（即质数的平方），返回 `[l, r]` 中非特殊数的数量。

## Java 代码实现

```java
class Solution {
    public int nonSpecialCount(int l, int r) {
        int maxP = (int) Math.sqrt(r);

        // 埃氏筛找出 [2, maxP] 内的所有质数
        boolean[] isComposite = new boolean[maxP + 1];
        isComposite[0] = isComposite[1] = true;
        for (int i = 2; (long) i * i <= maxP; i++) {
            if (!isComposite[i]) {
                for (int j = i * i; j <= maxP; j += i) {
                    isComposite[j] = true;
                }
            }
        }

        // 统计 p^2 在 [l, r] 内的质数个数（即特殊数数量）
        int specialCount = 0;
        for (int p = 2; p <= maxP; p++) {
            if (!isComposite[p]) {
                long sq = (long) p * p;
                if (sq >= l && sq <= r) specialCount++;
            }
        }
        return (r - l + 1) - specialCount;
    }
}
```

## 复杂度分析

- 时间复杂度：O(sqrt(r) * log(log(sqrt(r))))，埃氏筛
- 空间复杂度：O(sqrt(r))

## 关键点总结

1. 特殊数 = 恰好有 2 个约数（除自身），即质数的平方
2. 在 `[l, r]` 内的特殊数对应 `[2, sqrt(r)]` 内满足 `p^2 >= l` 的质数
3. 注意用 `long` 避免 `p * p` 溢出
