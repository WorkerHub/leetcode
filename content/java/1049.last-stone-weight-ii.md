## 题目描述

每回合选任意两块石头粉碎（x≤y，剩 y-x），返回最后剩余石头的最小可能重量。

**示例：**
```
输入：stones = [2,7,4,1,8,1]
输出：1
```

## 解题思路

问题转化为 0-1 背包：将石头分两组，最小化差值。等价于找一个子集使其和尽可能接近 sum/2。dp[i] 表示能否凑出重量 i。

## Java 代码实现

```java
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int total = 0;
        for (int s : stones) total += s;
        int target = total / 2;

        // dp[i] 表示能否凑出重量 i
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int stone : stones) {
            // 倒序遍历，保证每块石头只用一次
            for (int i = target; i >= stone; i--) {
                dp[i] = dp[i] || dp[i - stone];
            }
        }

        // 找最接近 target 的可凑出重量
        for (int i = target; i >= 0; i--) {
            if (dp[i]) {
                return total - 2 * i;
            }
        }
        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × sum/2)
- **空间复杂度**：O(sum/2)

## 关键点总结

1. **问题转化**：石头粉碎 → 分两组最小化差值 → 0-1 背包
2. **倒序遍历**：保证每块石头只使用一次
3. **结果公式**：result = total - 2 * maxSum（maxSum ≤ total/2）
