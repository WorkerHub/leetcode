## 题目描述

给定字符串 `s`、整数 `k`、字母 `letter` 和整数 `repetition`，返回长度为 k 且 `letter` 至少出现 `repetition` 次的字典序最小子序列。

## 解题思路

贪心 + 单调栈：维护栈使字典序尽可能小，弹出栈顶条件为：当前字符更小、剩余字符数够填满 k 个、且弹出后 letter 数量仍满足要求。决定是否加入当前字符时，考虑剩余空间与 letter 需求的平衡。

## Java 代码实现

### 方法一：贪心单调栈（推荐）

```java
class Solution {
    public String smallestSubsequence(String s, int k, char letter, int repetition) {
        int n = s.length();
        // 预计算后缀letter计数
        int[] suffixLetter = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suffixLetter[i] = suffixLetter[i + 1] + (s.charAt(i) == letter ? 1 : 0);
        }

        char[] stack = new char[k];
        int top = 0; // 栈大小
        int letterCount = 0; // 栈中letter数量

        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            // 尝试弹出栈顶
            while (top > 0 && c < stack[top - 1]) {
                boolean topIsLetter = (stack[top - 1] == letter);
                // 弹出后字符数是否足够
                if (top - 1 + (n - i) < k) break;
                // 弹出后letter数量是否足够
                int newLetterCount = letterCount - (topIsLetter ? 1 : 0);
                if (newLetterCount + suffixLetter[i] < repetition) break;
                if (topIsLetter) letterCount--;
                top--;
            }
            // 决定是否加入当前字符
            if (top < k) {
                int slotsLeft = k - top;
                int lettersNeeded = repetition - letterCount;
                // 必须加入：当前是letter，或非letter但还有多余位置
                if (c == letter) {
                    stack[top++] = c;
                    letterCount++;
                } else if (slotsLeft > suffixLetter[i + 1] - (lettersNeeded - (c == letter ? 1 : 0))) {
                    // 如果不加入当前字符，后面的letter也能满足需求时才可以不加
                    // 简化：剩余空间 > 需要的letter数时可以加非letter字符
                    if (slotsLeft > repetition - letterCount) {
                        stack[top++] = c;
                    }
                }
            }
            // 更新后缀（已在suffixLetter数组中）
        }

        return new String(stack, 0, top);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 单调栈贪心找字典序最小子序列，同时维护 letter 出现次数约束
2. 弹出栈顶需满足：字符数够用、letter 数量不会不足
3. 预计算后缀 letter 计数便于快速判断弹出条件
