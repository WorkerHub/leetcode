## 题目描述

给你整数 `num1` 和 `num2`，每步操作选择整数 `i`（`0 <= i <= 60`）令 `num1 -= (2^i + num2)`，返回使 `num1` 变为 0 的最少操作次数，不可能则返回 -1。

## Java 代码实现

```java
class Solution {
    public int makeTheIntegerZero(int num1, int num2) {
        for (int k = 1; k <= 63; k++) {
            long val = (long) num1 - (long) k * num2;
            // val 必须 > 0，且二进制 1 的个数 <= k
            if (val > 0 && Long.bitCount(val) <= k) {
                return k;
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(60)
- 空间复杂度：O(1)

## 关键点总结

1. `k` 次操作相当于凑出 `val = num1 - k * num2` 的二进制表示
2. `val` 的 1 的个数是最少需要的操作次数，允许"重复"（将 2^i 拆分），所以 bits <= k 即可
3. 同时需要 `val > 0`（不能是负数或 0）
