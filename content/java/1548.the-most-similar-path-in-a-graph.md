## 题目描述

n 个城市各有名字，m 条双向道路。给定目标路径 targetPath，找图中等长路径使对应位置名字不同数最少。返回路径城市编号列表。

## 解题思路

DP：dp[i][v] = 走到第 i 步在城市 v 时与目标的最小不同数。用 parent 数组回溯路径。

## Java 代码实现

```java
class Solution {
    public List<Integer> mostSimilar(int n, int[][] roads, String[] names, String[] targetPath) {
        // 建邻接表
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] road : roads) {
            adj.get(road[0]).add(road[1]);
            adj.get(road[1]).add(road[0]);
        }
        
        int L = targetPath.length;
        int[][] dp = new int[L][n];
        int[][] parent = new int[L][n];
        
        // 初始化第 0 步
        for (int v = 0; v < n; v++) {
            dp[0][v] = names[v].equals(targetPath[0]) ? 0 : 1;
            parent[0][v] = -1;
        }
        
        // 状态转移
        for (int i = 1; i < L; i++) {
            Arrays.fill(dp[i], Integer.MAX_VALUE);
            for (int v = 0; v < n; v++) {
                int cost = names[v].equals(targetPath[i]) ? 0 : 1;
                for (int u : adj.get(v)) {
                    if (dp[i - 1][u] + cost < dp[i][v]) {
                        dp[i][v] = dp[i - 1][u] + cost;
                        parent[i][v] = u;
                    }
                }
            }
        }
        
        // 找最优终点
        int end = 0;
        for (int v = 1; v < n; v++) {
            if (dp[L - 1][v] < dp[L - 1][end]) end = v;
        }
        
        // 回溯路径
        List<Integer> path = new ArrayList<>();
        int cur = end;
        for (int i = L - 1; i >= 0; i--) {
            path.add(cur);
            cur = parent[i][cur];
        }
        Collections.reverse(path);
        return path;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(L × (N + M))
- **空间复杂度**：O(L × N)

## 关键点总结

1. **DP 定义**：dp[step][v] = 走到第 step 步在城市 v 的最小不同数
2. **转移**：枚举前驱邻居 u
3. **路径回溯**：用 parent 数组从终点回溯
