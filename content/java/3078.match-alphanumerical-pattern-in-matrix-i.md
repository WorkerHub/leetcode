## 题目描述

给你整数矩阵 `board` 和字符串 `pattern`（含数字和字母），找出所有满足 pattern 的子矩阵左上角坐标（字母可映射到任意数字，不同字母映射不同数字）。

## 解题思路

枚举所有可能的左上角位置，维护字母到数字和数字到字母的双向映射，验证每个位置是否匹配 pattern。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findPattern(int[][] board, String[] pattern) {
        int rows = board.length, cols = board[0].length;
        int pm = pattern.length, pn = pattern[0].length();
        List<List<Integer>> result = new ArrayList<>();

        for (int r = 0; r + pm <= rows; r++) {
            for (int c = 0; c + pn <= cols; c++) {
                if (matches(board, pattern, r, c, pm, pn)) {
                    result.add(Arrays.asList(r, c));
                }
            }
        }
        return result;
    }

    private boolean matches(int[][] board, String[] pattern, int r, int c, int pm, int pn) {
        int[] charToDigit = new int[26]; // 字母到数字的映射
        int[] digitToChar = new int[10]; // 数字到字母（字母 ASCII - 'a' + 1）
        Arrays.fill(charToDigit, -1);
        Arrays.fill(digitToChar, -1);

        for (int i = 0; i < pm; i++) {
            for (int j = 0; j < pn; j++) {
                char p = pattern[i].charAt(j);
                int d = board[r + i][c + j];
                if (Character.isDigit(p)) {
                    if (p - '0' != d) return false; // 数字字符直接匹配
                } else {
                    int ci = p - 'a';
                    if (charToDigit[ci] == -1 && digitToChar[d] == -1) {
                        charToDigit[ci] = d; // 建立字母到数字的映射
                        digitToChar[d] = ci;
                    } else if (charToDigit[ci] != d || digitToChar[d] != ci) {
                        return false; // 映射不一致
                    }
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(R * C * P)，R 和 C 为矩阵大小，P 为 pattern 元素总数
- **空间复杂度**：O(1)（映射数组固定大小）

## 关键点总结

1. 双向映射确保字母到数字的一一对应（不同字母对应不同数字）
2. 数字字符直接匹配，字母字符通过映射验证
3. 同一字母在整个匹配中必须映射到同一数字
