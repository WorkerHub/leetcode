## 题目描述

设计ATM机支持5种面额(20,50,100,200,500)的存取款操作。取款优先使用大面额。

## 解题思路

维护各面额库存。取款时贪心从大到小取，模拟成功后再更新库存，失败返回[-1]。

## Java 代码实现

```java
class ATM {
    private long[] counts;
    private int[] denoms = {20, 50, 100, 200, 500};
    
    public ATM() {
        counts = new long[5];
    }
    
    public void deposit(int[] banknotesCount) {
        for (int i = 0; i < 5; i++) {
            counts[i] += banknotesCount[i];
        }
    }
    
    public int[] withdraw(int amount) {
        int[] used = new int[5];
        long remaining = amount;
        
        // 从大面额到小面额贪心取款
        for (int i = 4; i >= 0; i--) {
            long take = Math.min(counts[i], remaining / denoms[i]);
            used[i] = (int) take;
            remaining -= take * denoms[i];
        }
        
        if (remaining != 0) return new int[]{-1};
        
        // 更新库存
        for (int i = 0; i < 5; i++) {
            counts[i] -= used[i];
        }
        return used;
    }
}
```

## 复杂度分析

- **时间复杂度**：deposit O(1)，withdraw O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心取款**：从500到20优先使用大面额
2. **先模拟后更新**：取款失败不修改库存
3. **long类型**：counts用long防止钞票数溢出
