## 题目描述

给你一个整数数组 `arr`，请你统计数组中满足以下条件的元素个数：

- 对于元素 `x`，若数组中存在 `x + 1`，则计数加一

注意，允许重复。

**示例 1：**

```
输入：arr = [1,2,3]
输出：2
解释：1 的下一个元素 2 存在，所以 1 计数；2 的下一个元素 3 存在，所以 2 计数；3 的下一个元素 4 不存在。共 2 个。
```

**示例 2：**

```
输入：arr = [1,1,2]
输出：2
解释：arr 中有两个 1，且 arr 中存在 2，所以计数 2 个。
```

**示例 3：**

```
输入：arr = [1,3,2,3,5,0]
输出：3
解释：0, 1, 2 的下一个元素分别是 1, 2, 3，都存在于 arr 中，计数 3 个。
```

**提示：**

- `1 <= arr.length <= 1000`
- `0 <= arr[i] <= 1000`

## 解题思路

### 哈希集合

将数组中所有元素存入集合，然后遍历数组，对每个元素 `x`，检查 `x + 1` 是否在集合中，若在则计数加一。

- 时间复杂度：O(n)（一次遍历建集合，一次遍历检查）
- 空间复杂度：O(n)（集合大小）

注意：允许重复，即同一个值出现多次，每次出现都单独计数。

## Java 代码实现

### 方法一：哈希集合（推荐）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countElements(int[] arr) {
        // 将所有元素存入集合，O(1) 查询
        Set<Integer> numSet = new HashSet<>();
        for (int x : arr) numSet.add(x);

        int count = 0;
        for (int x : arr) {
            // 若 x+1 存在于数组中，则计数
            if (numSet.contains(x + 1)) {
                count++;
            }
        }

        return count;
    }
}
```

### 方法二：排序后双指针（无额外哈希空间）

```java
import java.util.Arrays;

class Solution {
    public int countElements(int[] arr) {
        Arrays.sort(arr);
        int count = 0;

        for (int i = 0; i < arr.length; i++) {
            // 二分查找 arr[i]+1 是否存在
            int target = arr[i] + 1;
            int lo = i + 1, hi = arr.length - 1;
            boolean found = false;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (arr[mid] == target) {
                    found = true;
                    break;
                } else if (arr[mid] < target) {
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            if (found) count++;
        }

        return count;
    }
}
```

### 方法三：HashMap 统计（利用频率）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countElements(int[] arr) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : arr) cnt.merge(x, 1, Integer::sum);

        int count = 0;
        for (Map.Entry<Integer, Integer> entry : cnt.entrySet()) {
            int x = entry.getKey();
            int freq = entry.getValue();
            // 若 x+1 也在数组中，x 出现的所有 freq 次都计数
            if (cnt.containsKey(x + 1)) {
                count += freq;
            }
        }

        return count;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希集合 | O(n) | O(n) |
| 排序+二分 | O(n log n) | O(1) |
| HashMap | O(n) | O(n) |

## 关键点总结

1. 用集合存储所有值，查找 x+1 的时间复杂度为 O(1)
2. 允许重复：即使多个 x 值相同，只要 x+1 存在就每个都计数
3. HashMap 方法更高效：对每个唯一值只查询一次，避免重复查询

## 易错点

1. 集合（HashSet）和列表（List）的区别：用集合查询 O(1)，用列表查询 O(n)
2. 允许重复意味着不能只遍历唯一值，每个元素都要单独判断
3. 方法三中需要乘以频率（每个唯一值出现 freq 次，都满足条件就计 freq 次）

- 注意区分"遍历唯一值"和"遍历所有元素"的不同场景
