## 题目描述

你被给定一个 `m × n` 的二维网格 `rooms`，网格中有以下三种可能的初始化值：

- `-1` 表示墙或是障碍物
- `0` 表示一扇门
- `INF` 无限大表示一个空房间。我们使用 `2^31 - 1 = 2147483647` 代表 `INF`。你可以认为通往门的距离总是小于 `2147483647` 的。

你要给每个空房间填上该房间到最近门的距离，如果无法到达门，则填 `INF`。

**示例 1:**

```
输入: rooms = [
  [2147483647,-1,0,2147483647],
  [2147483647,2147483647,2147483647,-1],
  [2147483647,-1,2147483647,-1],
  [0,-1,2147483647,2147483647]
]
输出: [
  [3,-1,0,1],
  [2,2,1,-1],
  [1,-1,2,-1],
  [0,-1,3,4]
]
```

**示例 2:**

```
输入: rooms = [[-1]]
输出: [[-1]]
```

**示例 3:**

```
输入: rooms = [[2147483647]]
输出: [[2147483647]]
```

**示例 4:**

```
输入: rooms = [[0]]
输出: [[0]]
```

**提示:**

- `m == rooms.length`
- `n == rooms[i].length`
- `1 <= m, n <= 250`
- `rooms[i][j]` 是 `-1`、`0` 或 `2^31 - 1`

## 解题思路

这是一道典型的多源 BFS（广度优先搜索）问题。核心思想是从所有门同时开始扩散，计算每个房间到最近门的距离。

**核心思想：**

1. 多源 BFS：将所有门作为起点同时进行 BFS
2. 层次遍历：每扩散一层，距离加 1
3. 原地修改：直接在原数组上更新距离

**为什么用 BFS 而不是 DFS？**

- BFS 保证找到的是最短距离
- DFS 可能找到的不是最短路径

**算法流程：**

1. 将所有门（值为 0）的位置加入队列
2. 从队列中取出一个位置，向四个方向扩散
3. 如果相邻位置是空房间（INF），更新距离并加入队列
4. 重复步骤 2-3 直到队列为空

**关键观察：**

- 从多个门同时 BFS，天然保证每个房间得到的是最短距离
- 已访问的房间不需要再访问（第一次访问就是最短距离）

## Java 代码实现

### 方法一：多源 BFS（推荐）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public void wallsAndGates(int[][] rooms) {
        // 多源 BFS，从所有门同时扩散
        // 时间复杂度 O(m*n)，空间复杂度 O(m*n)
        if (rooms == null || rooms.length == 0) return;

        int m = rooms.length, n = rooms[0].length;
        final int INF = Integer.MAX_VALUE;

        // 队列，存储所有门的位置
        Deque<int[]> queue = new ArrayDeque<>();

        // 将所有门加入队列
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) {
                    queue.offer(new int[]{i, j});
                }
            }
        }

        // 四个方向：上下左右
        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        // BFS 扩散
        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int x = curr[0], y = curr[1];

            // 向四个方向扩散
            for (int[] dir : directions) {
                int nx = x + dir[0], ny = y + dir[1];

                // 边界检查 + 只访问空房间（INF）
                if (nx >= 0 && nx < m && ny >= 0 && ny < n
                        && rooms[nx][ny] == INF) {
                    // 更新距离
                    rooms[nx][ny] = rooms[x][y] + 1;
                    // 加入队列继续扩散
                    queue.offer(new int[]{nx, ny});
                }
            }
        }
    }
}
```

### 方法二：层次遍历版本（更清晰）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public void wallsAndGates(int[][] rooms) {
        if (rooms == null || rooms.length == 0) return;

        int m = rooms.length, n = rooms[0].length;
        final int INF = Integer.MAX_VALUE;
        Deque<int[]> queue = new ArrayDeque<>();

        // 收集所有门，并存储距离信息 [x, y, distance]
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) {
                    queue.offer(new int[]{i, j, 0}); // (x, y, 距离)
                }
            }
        }

        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int x = curr[0], y = curr[1], dist = curr[2];

            for (int[] dir : directions) {
                int nx = x + dir[0], ny = y + dir[1];

                // 检查边界和是否为空房间
                if (nx >= 0 && nx < m && ny >= 0 && ny < n
                        && rooms[nx][ny] == INF) {
                    rooms[nx][ny] = dist + 1;
                    queue.offer(new int[]{nx, ny, dist + 1});
                }
            }
        }
    }
}
```

### 方法三：详细注释版（新手友好）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    /**
     * 墙和门问题：计算每个空房间到最近门的距离
     *
     * 算法：多源 BFS
     * 1. 找出所有门，作为 BFS 的起点
     * 2. 从所有门同时向外扩散
     * 3. 遇到空房间就更新距离
     *
     * 为什么多源 BFS？
     * - 单源 BFS 需要对每个门分别运行，效率低
     * - 多源 BFS 一次遍历就能更新所有房间
     */
    public void wallsAndGates(int[][] rooms) {
        if (rooms == null || rooms.length == 0) return;

        int m = rooms.length, n = rooms[0].length;
        final int INF = Integer.MAX_VALUE;

        // 初始化队列，包含所有门的位置
        Deque<int[]> queue = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) {
                    queue.offer(new int[]{i, j});
                }
            }
        }

        // 定义四个移动方向（上、下、左、右）
        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        // BFS 遍历
        while (!queue.isEmpty()) {
            // 取出当前位置
            int[] cell = queue.poll();
            int row = cell[0], col = cell[1];
            int currentDist = rooms[row][col];

            // 尝试向四个方向扩散
            for (int[] dir : directions) {
                int newRow = row + dir[0];
                int newCol = col + dir[1];

                // 检查新位置是否合法：
                // 1. 在边界内
                // 2. 是空房间（值为 INF）
                if (newRow >= 0 && newRow < m
                        && newCol >= 0 && newCol < n
                        && rooms[newRow][newCol] == INF) {

                    // 更新距离
                    rooms[newRow][newCol] = currentDist + 1;

                    // 加入队列，继续扩散
                    queue.offer(new int[]{newRow, newCol});
                }
            }
        }
    }
}
```

## 复杂度分析

**BFS 方法：**
- 时间复杂度：`O(m * n)` 每个单元格最多访问一次
- 空间复杂度：`O(m * n)` 队列最多包含所有单元格

## 关键点总结

1. **多源 BFS**：将所有起点同时加入队列，一次遍历完成
2. **原地修改**：直接在原数组上更新，节省空间
3. **访问标记**：利用 INF 判断是否访问过，不需要额外 visited 数组
4. **最短路径**：BFS 保证第一次到达某点时就是最短距离
5. **方向数组**：使用 directions 数组简化四方向遍历

## 易错点

1. **单源 BFS**：错误地对每个门分别 BFS，时间复杂度过高
2. **忘记边界检查**：访问数组前没有检查索引合法性
3. **重复访问**：没有判断 `rooms[nx][ny] == INF`，导致重复处理
4. **距离计算错误**：应该是 `rooms[x][y] + 1`
5. **使用 DFS**：DFS 不能保证最短路径，除非加额外判断
