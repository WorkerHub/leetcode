## 题目描述

给你数组 `power`、`damage`（长度均为 `n`）和整数 `health`。Bob 每回合攻击一个敌人造成 1 点伤害，消灭第 `i` 个敌人需 `power[i]` 回合，存活时每回合对 Bob 造成 `damage[i]` 伤害。求最优击杀顺序下 Bob 受到的最小总伤害。

## 解题思路

贪心：比较先击杀 a 后击杀 b 与先 b 后 a 的代价，推导排序准则为按 `power[i]/damage[i]` 升序排列。总伤害 = Σ(damage[i] × 击杀时刻[i])，击杀时刻为按顺序的前缀和。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minDamage(int[] power, int[] damage, int health) {
        int n = power.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        // 按 power[i]/damage[i] 升序：若 power[a]*damage[b] < power[b]*damage[a] 则 a 先
        Arrays.sort(idx, (a, b) ->
            (long) power[a] * damage[b] < (long) power[b] * damage[a] ? -1 : 1
        );

        long totalDamage = 0;
        long time = 0;
        for (int i : idx) {
            time += power[i];                          // 消灭该敌人的时刻
            totalDamage += (long) damage[i] * time;    // 该敌人在消灭前造成的总伤害
        }
        return totalDamage;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)

## 关键点总结

1. 贪心排序准则：按 `power[i]/damage[i]` 升序（比率小的先打）
2. 总伤害 = Σ(damage[i] × 击杀时刻[i])，击杀时刻为前缀和
3. 比较时用乘法避免浮点误差，注意用 `long` 防溢出
