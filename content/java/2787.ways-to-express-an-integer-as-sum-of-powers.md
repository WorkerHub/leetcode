## 题目描述

给你正整数 `n` 和 `x`，返回将 `n` 表示为若干不同正整数的 x 次幂之和的方案数（对 10^9+7 取模）。

## Java 代码实现

```java
class Solution {
    public int numberOfWays(int n, int x) {
        final int MOD = 1_000_000_007;
        int[] dp = new int[n + 1];
        dp[0] = 1;
        // 0-1 背包：物品为所有 i^x <= n 的正整数幂
        for (int i = 1; (long) Math.pow(i, x) <= n; i++) {
            int pw = (int) Math.pow(i, x);
            // 倒序遍历保证每个数只用一次
            for (int j = n; j >= pw; j--) {
                dp[j] = (dp[j] + dp[j - pw]) % MOD;
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^(1+1/x))，幂次数约 n^(1/x)，每次遍历 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每个正整数只能用一次，使用 0-1 背包（倒序遍历）
2. 物品为所有满足 `i^x <= n` 的正整数幂
3. 倒序遍历 dp 数组保证不重复选取同一元素
