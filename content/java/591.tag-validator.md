## 题目描述

验证代码片段中的标签是否有效（标签匹配、CDATA 处理、标签名规则）。

## Java 代码实现

```java
class Solution {
    public boolean isValid(String code) {
        Deque<String> stack = new ArrayDeque<>();
        int i = 0;

        while (i < code.length()) {
            if (stack.isEmpty() && i > 0) return false;

            // 处理 CDATA
            if (code.startsWith("<![CDATA[", i)) {
                if (stack.isEmpty()) return false;
                int j = code.indexOf("]]>", i + 9);
                if (j < 0) return false;
                i = j + 3;
            }
            // 处理闭合标签
            else if (code.startsWith("</", i)) {
                int j = code.indexOf('>', i);
                if (j < 0) return false;
                String tag = code.substring(i + 2, j);
                if (stack.isEmpty() || !stack.peek().equals(tag)) return false;
                stack.pop();
                i = j + 1;
            }
            // 处理开始标签
            else if (code.charAt(i) == '<') {
                int j = code.indexOf('>', i);
                if (j < 0) return false;
                String tag = code.substring(i + 1, j);
                if (tag.length() < 1 || tag.length() > 9) return false;
                for (char c : tag.toCharArray()) {
                    if (c < 'A' || c > 'Z') return false;
                }
                stack.push(tag);
                i = j + 1;
            } else {
                i++;
            }
        }
        return stack.isEmpty();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈匹配**：开始标签入栈，闭合标签弹出匹配
2. **CDATA**：`<![CDATA[...]]>` 整段跳过
3. **标签名验证**：大写字母，长度 1-9
