## 题目描述

两组点，cost[i][j]表示连接代价。用最小代价使每个点都至少与另一组的一个点相连。

## 解题思路

状态压缩DP：size2≤12，用位掩码表示第二组覆盖状态。逐个处理第一组的点，枚举连接第二组哪个点。处理完后补齐未覆盖点。

## Java 代码实现

```java
class Solution {
    public int connectTwoGroups(List<List<Integer>> cost) {
        int size1 = cost.size(), size2 = cost.get(0).size();
        int full = (1 << size2) - 1;
        
        // 预处理：每个第二组点的最小连接代价
        int[] minCost = new int[size2];
        for (int j = 0; j < size2; j++) {
            minCost[j] = Integer.MAX_VALUE;
            for (int i = 0; i < size1; i++) {
                minCost[j] = Math.min(minCost[j], cost.get(i).get(j));
            }
        }
        
        int[] dp = new int[1 << size2];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        
        for (int i = 0; i < size1; i++) {
            int[] newDp = new int[1 << size2];
            Arrays.fill(newDp, Integer.MAX_VALUE);
            for (int mask = 0; mask <= full; mask++) {
                if (dp[mask] == Integer.MAX_VALUE) continue;
                // 第i个点连接第二组第j个点
                for (int j = 0; j < size2; j++) {
                    int newMask = mask | (1 << j);
                    newDp[newMask] = Math.min(newDp[newMask], dp[mask] + cost.get(i).get(j));
                }
            }
            dp = newDp;
        }
        
        // 补齐未覆盖的第二组点
        int ans = Integer.MAX_VALUE;
        for (int mask = 0; mask <= full; mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            int extra = 0;
            for (int j = 0; j < size2; j++) {
                if ((mask >> j & 1) == 0) {
                    extra += minCost[j];
                }
            }
            ans = Math.min(ans, dp[mask] + extra);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(size1 × size2 × 2^size2)
- **空间复杂度**：O(2^size2)

## 关键点总结

1. **位掩码**：表示第二组覆盖状态（size2≤12）
2. **逐个处理第一组**：每个点至少连一个第二组点
3. **补全未覆盖点**：用全局最小代价
