## 题目描述

给你一个下标从 1 开始的整数数组 `numbers`，该数组已按**非递减顺序排列**，请你从数组中找出满足相加之和等于目标数 `target` 的两个数。如果设这两个数分别是 `numbers[index1]` 和 `numbers[index2]`，则 `1 <= index1 < index2 <= numbers.length`。

以长度为 2 的整数数组 `[index1, index2]` 的形式返回这两个整数的下标 `index1` 和 `index2`。

你可以假设每个输入只对应唯一的答案，而且你不可以重复使用相同的元素。

你所设计的解决方案必须只使用常量级的额外空间。

**示例 1：**
```
输入：numbers = [2,7,11,15], target = 9
输出：[1,2]
解释：2 与 7 之和等于目标数 9。因此 index1 = 1, index2 = 2。返回 [1, 2]。
```

**示例 2：**
```
输入：numbers = [2,3,4], target = 6
输出：[1,3]
解释：2 与 4 之和等于目标数 6。因此 index1 = 1, index2 = 3。返回 [1, 3]。
```

**示例 3：**
```
输入：numbers = [-1,0], target = -1
输出：[1,2]
解释：-1 与 0 之和等于目标数 -1。因此 index1 = 1, index2 = 2。返回 [1, 2]。
```

**提示：**
- 2 <= numbers.length <= 3 * 10^4
- -1000 <= numbers[i] <= 1000
- numbers 按**非递减顺序**排列
- -1000 <= target <= 1000
- **仅存在一个有效答案**

## 解题思路

这是**第 1 题两数之和的进阶版**，关键区别是：
1. 数组**已排序**
2. 下标从**1 开始**
3. 要求**O(1) 空间复杂度**（不能用哈希表）

**核心算法：双指针（对撞指针）**

利用数组已排序的特性，使用两个指针分别指向数组的头尾：
- 如果两数之和**大于** target，右指针左移（减小和）
- 如果两数之和**小于** target，左指针右移（增大和）
- 如果两数之和**等于** target，找到答案

**为什么双指针可行？**
- 数组有序，左指针右移会增大和，右指针左移会减小和
- 每次移动都会排除一个不可能的元素
- 最终必然相遇在答案位置

## Java 代码实现

### 方法一：双指针（推荐，O(1) 空间）⭐

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        // 左右指针
        int left = 0, right = numbers.length - 1;

        while (left < right) {
            int currentSum = numbers[left] + numbers[right];

            if (currentSum == target) {
                // 注意：返回的下标从 1 开始
                return new int[]{left + 1, right + 1};
            } else if (currentSum < target) {
                // 和太小，左指针右移
                left++;
            } else {
                // 和太大，右指针左移
                right--;
            }
        }

        // 题目保证有解，这里不会执行
        return new int[]{};
    }
}
```

### 方法二：二分查找

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        // 固定第一个数，二分查找第二个数
        for (int i = 0; i < numbers.length - 1; i++) {
            // 在右侧查找 target - numbers[i]
            int left = i + 1, right = numbers.length - 1;
            int complement = target - numbers[i];

            while (left <= right) {
                int mid = (left + right) / 2;
                if (numbers[mid] == complement) {
                    return new int[]{i + 1, mid + 1};
                } else if (numbers[mid] < complement) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return new int[]{};
    }
}
```

### 方法三：哈希表（不符合空间要求，但可对比）

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        // 使用字典存储值和索引（不满足 O(1) 空间要求）
        Map<Integer, Integer> seen = new HashMap<>();

        for (int i = 0; i < numbers.length; i++) {
            int complement = target - numbers[i];
            if (seen.containsKey(complement)) {
                return new int[]{seen.get(complement) + 1, i + 1};
            }
            seen.put(numbers[i], i);
        }

        return new int[]{};
    }
}
```

## 复杂度分析

### 方法一：双指针
- **时间复杂度：** O(n)，最多遍历一次数组
- **空间复杂度：** O(1)，只使用两个指针

### 方法二：二分查找
- **时间复杂度：** O(n log n)，外层循环 O(n)，内层二分 O(log n)
- **空间复杂度：** O(1)

### 方法三：哈希表
- **时间复杂度：** O(n)
- **空间复杂度：** O(n)，不符合题目要求

## 图解示例

以 `numbers = [2, 7, 11, 15], target = 9` 为例：

```
初始状态：
        ↓left          right↓
index:  0   1   2    3
值:    [2,  7,  11,  15]
和:     2 + 15 = 17 > 9，右指针左移

第二步：
        ↓left      right↓
index:  0   1   2    3
值:    [2,  7,  11,  15]
和:     2 + 11 = 13 > 9，右指针左移

第三步：
        ↓left  right↓
index:  0   1   2    3
值:    [2,  7,  11,  15]
和:     2 + 7 = 9 = 9，找到答案！
返回：[1, 2]（下标从1开始）
```

## 关键点总结

1. **利用有序性**：双指针能工作的前提是数组有序
2. **对撞指针**：从两端向中间收缩，逐步逼近答案
3. **下标转换**：题目要求下标从 1 开始，返回时需 +1
4. **空间要求**：O(1) 空间排除了哈希表方案
5. **贪心思想**：每次移动都朝着答案方向前进

## 易错点

1. **忘记下标从 1 开始**
   - 错误：`return new int[]{left, right}`
   - 正确：`return new int[]{left + 1, right + 1}`

2. **边界条件错误**
   - 双指针：`left < right`（不能相等）
   - 二分查找：`left <= right`

3. **移动方向错误**
   - 和太小时应该增大和，移动**左指针**
   - 和太大时应该减小和，移动**右指针**

4. **死循环风险**
   - 找到答案后必须立即返回
   - 每次循环必须移动指针
