## 题目描述

给你整数数组 `nums`，每秒可对任意元素加 1。返回使 `nums` 变为山脉数组（存在峰值，左侧严格递增，右侧严格递减）的最少秒数。

## 解题思路

枚举峰值位置，对每个峰值计算左侧和右侧的 LIS 长度。不在 LIS 中的元素需要增加，代价为 `(peak+1 - leftLis[peak]) + (n-peak - rightLis[peak])`（需要修改的元素数）。用耐心排序（二分）O(n log n) 计算 LIS。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumSeconds(int[] nums) {
        int n = nums.length;
        // leftLis[i] = 以 nums[i] 结尾的最长严格递增子序列长度
        int[] leftLis = new int[n];
        List<Integer> tails = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            int pos = Collections.binarySearch(tails, nums[i]);
            if (pos < 0) pos = -pos - 1;
            if (pos == tails.size()) tails.add(nums[i]);
            else tails.set(pos, nums[i]);
            leftLis[i] = tails.size();
        }
        // rightLis[i] = 从 nums[i] 开始向右的最长严格递减子序列长度（等价于从右往左的 LIS）
        int[] rightLis = new int[n];
        tails.clear();
        for (int i = n - 1; i >= 0; i--) {
            int pos = Collections.binarySearch(tails, nums[i]);
            if (pos < 0) pos = -pos - 1;
            if (pos == tails.size()) tails.add(nums[i]);
            else tails.set(pos, nums[i]);
            rightLis[i] = tails.size();
        }
        // 枚举峰值（1 <= peak <= n-2），计算最少修改元素数
        long ans = Long.MAX_VALUE;
        for (int peak = 1; peak < n - 1; peak++) {
            long cost = (peak + 1 - leftLis[peak]) + (n - peak - rightLis[peak]);
            ans = Math.min(ans, cost);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，耐心排序计算 LIS
- 空间复杂度：O(n)

## 关键点总结

1. 枚举峰值，左侧保留 LIS 个元素不动，右侧保留 LIS 个元素不动
2. 不在 LIS 中的元素每个至少需要加 1，总代价为需修改元素数
3. 峰值必须在内部（0 < peak < n-1），且左右两侧的 LIS 不包含重叠
