## 题目描述

每个元素可以+1或保持不变，选出子集使最终值构成连续整数序列，求最大选出元素数。

## 解题思路

排序后DP：dp[v]表示以v结尾的最长连续序列长度。每个x可选用x或x+1两种值转移。

## Java 代码实现

```java
class Solution {
    public int maxSelectedElements(int[] nums) {
        Arrays.sort(nums);
        Map<Integer, Integer> dp = new HashMap<>();
        int ans = 1;
        for (int x : nums) {
            // 选x+1（x变成x+1）
            int val1 = dp.getOrDefault(x, 0) + 1;
            dp.put(x + 1, val1);
            // 选x（保持不变）
            int val2 = dp.getOrDefault(x - 1, 0) + 1;
            dp.put(x, val2);
            ans = Math.max(ans, Math.max(val1, val2));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **每个元素只有两种选择**：保持x或变为x+1
2. **排序保证DP转移正确**：小值先处理
3. **先更新x+1再更新x**：避免覆盖
