## 题目描述

找强对(x,y)满足|x-y|<=min(x,y)，求最大XOR值。（n<=5*10^4, nums[i]<=2^20）

## 解题思路

排序后用双指针维护满足y<=2x的窗口，字典树支持动态插入/删除和查询最大XOR。

## Java 代码实现

```java
class Solution {
    private static final int BITS = 20;
    private int[][] trie;
    private int[] cnt;
    private int idx;

    public int maximumStrongPairXor(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        trie = new int[n * BITS + 1][2];
        cnt = new int[n * BITS + 1];
        idx = 0;

        int ans = 0, left = 0;
        for (int right = 0; right < n; right++) {
            insert(nums[right], 1);
            while (nums[right] > 2 * nums[left]) {
                insert(nums[left], -1);
                left++;
            }
            ans = Math.max(ans, queryMaxXor(nums[right]));
        }
        return ans;
    }

    private void insert(int val, int delta) {
        int node = 0;
        for (int bit = BITS - 1; bit >= 0; bit--) {
            int b = (val >> bit) & 1;
            if (trie[node][b] == 0) {
                trie[node][b] = ++idx;
            }
            node = trie[node][b];
            cnt[node] += delta;
        }
    }

    private int queryMaxXor(int val) {
        int node = 0, xor = 0;
        for (int bit = BITS - 1; bit >= 0; bit--) {
            int b = (val >> bit) & 1;
            int want = 1 - b;
            if (trie[node][want] != 0 && cnt[trie[node][want]] > 0) {
                xor |= (1 << bit);
                node = trie[node][want];
            } else {
                node = trie[node][b];
            }
        }
        return xor;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * BITS)
- **空间复杂度**：O(N * BITS)

## 关键点总结

1. **排序+双指针**：维护y<=2x的有效窗口
2. **字典树查最大XOR**：贪心选每一位的互补方向
3. **引用计数支持删除**：左指针移动时减少计数
