## 题目描述

给定 `eventTime` 和 n 个无重叠会议的 `startTime`/`endTime` 数组，最多移动 k 个会议（不改变时长），返回移动后能获得的最大连续空闲时间。

## Java 代码实现

```java
class Solution {
    public int maxFreeTime(int eventTime, int k, int[] startTime, int[] endTime) {
        int n = startTime.length;

        // 构建空隙数组（n+1 个）
        int[] gaps = new int[n + 1];
        gaps[0] = startTime[0];
        for (int i = 1; i < n; i++) gaps[i] = startTime[i] - endTime[i - 1];
        gaps[n] = eventTime - endTime[n - 1];

        // 会议时长
        int[] dur = new int[n];
        for (int i = 0; i < n; i++) dur[i] = endTime[i] - startTime[i];

        // 滑动窗口：移走 k 个连续会议，合并 k+1 个相邻空隙
        int wGaps = 0, wDur = 0;
        for (int i = 0; i <= k; i++) wGaps += gaps[i];
        for (int i = 0; i < k; i++) wDur += dur[i];

        int ans = wGaps + wDur;

        for (int l = 1; l <= n - k; l++) {
            wGaps -= gaps[l - 1];
            wGaps += gaps[l + k];
            wDur -= dur[l - 1];
            wDur += dur[l + k - 1];
            ans = Math.max(ans, wGaps + wDur);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 移动 k 个连续会议 = 合并相邻的 k+1 个空隙
2. 合并后的空闲时间 = k+1 个空隙之和 + k 个被移走会议的时长之和
3. 空隙数组比会议数组多 1 个（首尾各一个）
