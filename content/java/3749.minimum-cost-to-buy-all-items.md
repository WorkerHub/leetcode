## 题目描述

有 `n` 件物品，每件物品可单独购买（代价 `cost[i]`），或通过购买第 `i` 件后以 `discount[i]` 的代价购买第 `next[i]` 件。求购买所有 `n` 件物品的最小总代价。

## 解题思路

贪心：先计算全部单买的总价，然后对每件物品，若通过折扣购买更便宜，则从总价中减去节省额。每件物品取所有可用折扣来源中最便宜的一个。

## Java 代码实现

```java
class Solution {
    public long minCost(int[] cost, int[] discount, int[] nxt) {
        int n = cost.length;
        long total = 0;
        for (int c : cost) total += c;

        // 对每件物品，找能通过折扣购买的最便宜方式
        int[] minDisc = cost.clone(); // minDisc[j] = 购买 j 的最低价
        for (int i = 0; i < n; i++) {
            int j = nxt[i];
            if (discount[i] < minDisc[j]) {
                minDisc[j] = discount[i];
            }
        }

        // 贪心：对每件物品，若折扣价更便宜则节省差额
        for (int j = 0; j < n; j++) {
            if (minDisc[j] < cost[j]) {
                total -= (cost[j] - minDisc[j]);
            }
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 每件物品可被多个来源折扣，取最便宜的折扣来源
2. 贪心：尽量使用折扣节省费用
3. 使用 `long` 防止整数溢出
