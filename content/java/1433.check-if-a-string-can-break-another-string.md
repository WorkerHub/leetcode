## 题目描述

给你两个字符串 `s1` 和 `s2`，它们长度相同，每个字符串都只含有小写英文字母。

如果某个字符串 `s` 能打破字符串 `t`，需要满足：对 `s` 和 `t` 的某一排列，使得所有下标 `i` 满足 `s[i] >= t[i]`（即 `s` 的每个字符都大于或等于 `t` 对应位置的字符）。

判断字符串 `s1` 是否能打破 `s2`，**或者** `s2` 是否能打破 `s1`。若任意一个成立则返回 `true`。

**示例 1：**
```
输入：s1 = "abc", s2 = "xya"
输出：true
解释：s2 排列 "ayx" 可被 s1 "abc" 打破（a>=a, b>=y? 否）
实际：s1="abc"排序, s2="axy"排序，逐位 a>=a, b>=x? 否
     s2="axy" vs s1="abc"，a>=a, x>=b, y>=c，全部满足，s2 打破 s1，返回 true
```

**示例 2：**
```
输入：s1 = "abe", s2 = "acd"
输出：false
解释：排序后 s1="abe", s2="acd"
     s1打破s2：a>=a, b>=c? 否（不满足）
     s2打破s1：a>=a, c>=b, d>=e? 否（不满足）
     返回 false
```

**示例 3：**
```
输入：s1 = "leetcodee", s2 = "interview"
输出：true
```

**提示：**
- `s1.length == s2.length`
- `1 <= s1.length <= 10^5`
- `s1` 和 `s2` 仅由小写英文字母组成

## 解题思路

**贪心观察：**

要使 `s1` 的某个排列能打破 `s2` 的某个排列，最优策略是对两者都排序后逐位比较。

**证明：**  
如果存在某排列使得 `s1[i] >= s2[i]` 对所有 `i` 成立，那么对两者都排序（升序）后同样满足。这是因为排序是一种"最优匹配"——将最小的对应最小的，保证差距最合理。

**算法：**
1. 将 `s1` 和 `s2` 各自排序。
2. 检查 `s1` 是否逐位 `>=` `s2`（即 `s1` 打破 `s2`）。
3. 检查 `s2` 是否逐位 `>=` `s1`（即 `s2` 打破 `s1`）。
4. 任意一个条件成立则返回 `true`。

## Java 代码实现

### 方法一：排序 + 逐位比较（推荐）

```java
import java.util.Arrays;

class Solution {
    public boolean checkIfCanBreak(String s1, String s2) {
        // 对两个字符串排序
        char[] arr1 = s1.toCharArray();
        char[] arr2 = s2.toCharArray();
        Arrays.sort(arr1);
        Arrays.sort(arr2);

        return canBreak(arr1, arr2) || canBreak(arr2, arr1);
    }

    // 检查 a 是否能打破 b（逐位 a[i] >= b[i]）
    private boolean canBreak(char[] a, char[] b) {
        for (int i = 0; i < a.length; i++) {
            if (a[i] < b[i]) return false;
        }
        return true;
    }
}
```

### 方法二：一次遍历同时判断两个方向

```java
import java.util.Arrays;

class Solution {
    public boolean checkIfCanBreak(String s1, String s2) {
        char[] arr1 = s1.toCharArray();
        char[] arr2 = s2.toCharArray();
        Arrays.sort(arr1);
        Arrays.sort(arr2);

        boolean s1BreaksS2 = true;  // s1 是否能打破 s2
        boolean s2BreaksS1 = true;  // s2 是否能打破 s1

        for (int i = 0; i < arr1.length; i++) {
            if (arr1[i] < arr2[i]) s1BreaksS2 = false;  // s1 有位置不够大
            if (arr2[i] < arr1[i]) s2BreaksS1 = false;  // s2 有位置不够大
        }

        return s1BreaksS2 || s2BreaksS1;
    }
}
```

### 方法三：计数排序优化（适合字符集小的情况）

```java
class Solution {
    public boolean checkIfCanBreak(String s1, String s2) {
        // 使用计数数组代替排序，复杂度从 O(n log n) 降至 O(n + 26)
        int[] count1 = new int[26];
        int[] count2 = new int[26];

        for (char c : s1.toCharArray()) count1[c - 'a']++;
        for (char c : s2.toCharArray()) count2[c - 'a']++;

        // 生成排序后的字符数组（通过计数还原）
        char[] sorted1 = expand(count1, s1.length());
        char[] sorted2 = expand(count2, s2.length());

        boolean s1BreaksS2 = true, s2BreaksS1 = true;
        for (int i = 0; i < sorted1.length; i++) {
            if (sorted1[i] < sorted2[i]) s1BreaksS2 = false;
            if (sorted2[i] < sorted1[i]) s2BreaksS1 = false;
        }

        return s1BreaksS2 || s2BreaksS1;
    }

    private char[] expand(int[] count, int n) {
        char[] result = new char[n];
        int idx = 0;
        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < count[i]; j++) {
                result[idx++] = (char) ('a' + i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n log n)，主要来自排序。使用计数排序可降至 O(n + 26) = O(n)。
- **空间复杂度：** O(n)，存储排序后的字符数组。

## 图解示例

```
s1 = "abc", s2 = "xya"

排序后：
arr1 = ['a', 'b', 'c']
arr2 = ['a', 'x', 'y']

检查 s1 打破 s2：
  a >= a -> true
  b >= x -> false（'b' < 'x'）
  s1 不能打破 s2

检查 s2 打破 s1：
  a >= a -> true
  x >= b -> true
  y >= c -> true
  s2 能打破 s1！

返回 true
```

## 关键点总结

1. 排序后比较是贪心最优策略：升序对升序，使得匹配最"公平"。
2. 只需要检查两个方向（s1 打破 s2，或 s2 打破 s1），任一成立即可。
3. Java 中可用 `Arrays.sort(char[])` 直接对字符数组排序。
4. 计数排序适用于字符集固定且小的场景，能优化常数。

## 易错点

- 不对字符串排序直接比较，漏掉了"可以重新排列"这一关键条件。
- 只检查一个方向（s1 打破 s2），忘记检查 s2 打破 s1。
- 字符串比较用 `>=` 而非 `>`（允许相等）。
