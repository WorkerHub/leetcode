## 题目描述

`n` 人过同一扇门，同时只能一人通过。若有多人等待，优先与上次通过方向相同的人，若无相同方向则优先方向 0（右到左），返回每个人过门的时刻。

## 解题思路

双队列模拟：维护方向 0 和方向 1 的等待队列，每时刻先加入新到达的人，按优先规则出队，两侧均空时时间跳跃到下一到达时刻并重置优先方向为 0。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] timeTaken(int[] arrival, int[] state) {
        int n = arrival.length;
        int[] ans = new int[n];
        Deque<Integer>[] queue = new Deque[2];
        queue[0] = new ArrayDeque<>();
        queue[1] = new ArrayDeque<>();

        int curTime = 0, lastDir = 1, ptr = 0;

        while (ptr < n || !queue[0].isEmpty() || !queue[1].isEmpty()) {
            // 加入当前时刻到达的人
            while (ptr < n && arrival[ptr] <= curTime) {
                queue[state[ptr]].add(ptr++);
            }

            if (queue[0].isEmpty() && queue[1].isEmpty()) {
                // 队列为空，跳跃到下一人到达时刻，重置优先方向
                if (ptr < n) curTime = arrival[ptr];
                lastDir = 1; // 空闲后优先方向 0
                continue;
            }

            int chosenDir;
            if (!queue[0].isEmpty() && !queue[1].isEmpty()) {
                chosenDir = lastDir; // 两侧都有人，优先上次方向
            } else {
                chosenDir = queue[0].isEmpty() ? 1 : 0;
            }

            int person = queue[chosenDir].poll();
            ans[person] = curTime;
            lastDir = chosenDir;
            curTime++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + T)，T 为最大过门时刻
- **空间复杂度**：O(n)

## 关键点总结

1. 双队列按方向分别维护等待人员
2. 门空闲后再有人到达时，优先方向重置为 0（右到左）
3. 两队都有等待人员时，延续上次通过方向
