## 题目描述

花朵有 n 片北向花瓣和 m 片南向花瓣，Alice 和 Bob 轮流摘，Alice 先手，摘最后一片者胜。返回 1≤n≤x 且 1≤m≤y 中 Alice 获胜的 (n,m) 对数。

## 解题思路

总花瓣 n+m 为奇数时 Alice 必胜（先手优势），即 n 和 m 一奇一偶。用奇偶计数公式直接求答案。

## Java 代码实现

```java
class Solution {
    public long flowerGame(int n, int m) {
        long oddN = (n + 1) / 2;  // [1,n] 中奇数个数
        long evenN = n / 2;        // [1,n] 中偶数个数
        long oddM = (m + 1) / 2;  // [1,m] 中奇数个数
        long evenM = m / 2;        // [1,m] 中偶数个数
        // n 奇 m 偶 + n 偶 m 奇
        return oddN * evenM + evenN * oddM;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. n+m 为奇数时 Alice 必胜，即 n 和 m 奇偶性不同
2. [1,n] 中奇数个数 = (n+1)/2，偶数个数 = n/2
3. n、m 最大 10^9，结果可能超 int 范围，用 long
