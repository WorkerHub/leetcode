## 题目描述

给定 BST，按中序遍历重新排列为只有右子树的递增搜索树。

**示例：**
```
输入：root = [5,3,6,2,4,null,8,1,null,null,null,7,9]
输出：[1,null,2,null,3,null,4,null,5,null,6,null,7,null,8,null,9]
```

## 解题思路

中序遍历 BST，将每个节点的 left 置空，用 right 连成链。

## Java 代码实现

```java
class Solution {
    private TreeNode curr;

    public TreeNode increasingBST(TreeNode root) {
        TreeNode dummy = new TreeNode(0);
        curr = dummy;
        inorder(root);
        return dummy.right;
    }

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        node.left = null;
        curr.right = node;
        curr = node;
        inorder(node.right);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **中序遍历**：BST 中序有序
2. **重建链**：每个节点 left=null，right 指向下一个
3. **dummy 节点**：简化头节点处理
