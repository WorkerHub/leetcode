## 题目描述

给你 `n` 个节点的无向图和边数组 `edges`，将节点分组使相邻节点所在组号差为 1，返回最多分组数，不可行返回 -1。

## 解题思路

先用 BFS 染色检验是否为二分图（有奇数环则返回 -1）；再对每个连通分量，枚举分量内每个节点作为 BFS 起点，取最大 BFS 层数作为该分量的最优分组数，各分量之和即为答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int magnificentSets(int n, int[][] edges) {
        List<Integer>[] adj = new List[n + 1];
        for (int i = 1; i <= n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            adj[e[0]].add(e[1]);
            adj[e[1]].add(e[0]);
        }

        int[] color = new int[n + 1];
        Arrays.fill(color, -1);
        // BFS 染色判断二分图，同时记录连通分量
        List<List<Integer>> components = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (color[i] != -1) continue;
            List<Integer> comp = new ArrayList<>();
            Queue<Integer> q = new LinkedList<>();
            q.offer(i);
            color[i] = 0;
            comp.add(i);
            while (!q.isEmpty()) {
                int u = q.poll();
                for (int v : adj[u]) {
                    if (color[v] == -1) {
                        color[v] = 1 - color[u];
                        q.offer(v);
                        comp.add(v);
                    } else if (color[v] == color[u]) {
                        return -1; // 奇数环
                    }
                }
            }
            components.add(comp);
        }

        int ans = 0;
        for (List<Integer> comp : components) {
            int best = 0;
            // 对分量内每个节点做 BFS，取最大层数
            for (int src : comp) {
                best = Math.max(best, bfsDepth(src, adj, n));
            }
            ans += best;
        }
        return ans;
    }

    private int bfsDepth(int src, List<Integer>[] adj, int n) {
        int[] dist = new int[n + 1];
        Arrays.fill(dist, -1);
        dist[src] = 0;
        Queue<Integer> q = new LinkedList<>();
        q.offer(src);
        int maxD = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : adj[u]) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    maxD = Math.max(maxD, dist[v]);
                    q.offer(v);
                }
            }
        }
        return maxD + 1; // 层数
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × (n + m))
- **空间复杂度**：O(n + m)

## 关键点总结

1. 有奇数环（非二分图）则无法分组，返回 -1
2. 对每个连通分量，最优分组数 = 以分量内某节点为起点的 BFS 最大层数
3. 各连通分量独立分组，结果相加
