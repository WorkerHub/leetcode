## 题目描述

把字符串分成两个非空部分，使前后两部分的不同字符数相等。返回好的分割数。

**示例：**
```
输入：s = "aacaba"
输出：2
```

## 解题思路

预计算前缀和后缀的不同字符数，枚举分割位置比较。

## Java 代码实现

```java
class Solution {
    public int numSplits(String s) {
        int n = s.length();
        int[] leftDistinct = new int[n];
        int[] rightDistinct = new int[n];
        
        // 前缀不同字符数
        Set<Character> seen = new HashSet<>();
        for (int i = 0; i < n; i++) {
            seen.add(s.charAt(i));
            leftDistinct[i] = seen.size();
        }
        
        // 后缀不同字符数
        seen.clear();
        for (int i = n - 1; i >= 0; i--) {
            seen.add(s.charAt(i));
            rightDistinct[i] = seen.size();
        }
        
        int count = 0;
        for (int i = 0; i < n - 1; i++) {
            if (leftDistinct[i] == rightDistinct[i + 1]) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀统计**：从左到右累计不同字符
2. **后缀统计**：从右到左累计不同字符
3. **枚举分割点**：比较 left[i] 和 right[i+1]
