## 题目描述

从第 0 站到第 n 站，可走普通铁路（费用 `regular[i]`）或快速铁路（费用 `express[i]`，进入时额外付 `expressCost`，从快速到普通免费），返回到达每个站的最小费用数组。

## 解题思路

DP 维护两个状态：`dpR`（当前在普通铁路的最小花费）和 `dpE`（当前在快速铁路的最小花费）。初始时在普通铁路花费 0，在快速铁路需先付 `expressCost`。每步取两种转移方式的最小值。

## Java 代码实现

```java
class Solution {
    public long[] minimumCosts(int[] regular, int[] express, int expressCost) {
        int n = regular.length;
        long[] costs = new long[n];
        long dpR = 0, dpE = expressCost; // 在普通铁路和快速铁路的最小费用

        for (int i = 0; i < n; i++) {
            long newR = Math.min(dpR + regular[i], dpE + express[i]); // 到达 i+1 站的普通铁路状态
            long newE = Math.min(dpR + expressCost + express[i], dpE + express[i]); // 快速铁路状态
            dpR = newR;
            dpE = newE;
            costs[i] = Math.min(dpR, dpE);
        }
        return costs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不含输出数组）

## 关键点总结

1. 两个 DP 状态：普通铁路和快速铁路的最小花费。
2. 初始状态：`dpR=0`，`dpE=expressCost`（进入快速铁路需付费）。
3. 从快速到普通免费，从普通到快速需付 `expressCost`。
