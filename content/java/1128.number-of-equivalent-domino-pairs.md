## 题目描述

给定多米诺骨牌列表 `dominoes`，`[a,b]` 和 `[c,d]` 等价当且仅当 `(a==c && b==d)` 或 `(a==d && b==c)`。求等价骨牌对的数量。

**示例：**
```
输入：dominoes = [[1,2],[2,1],[3,4],[5,6]]
输出：1
```

## 解题思路

将每张骨牌标准化为 `(min(a,b), max(a,b))`，编码为两位数 `min*10+max`。由于值域 1-9，可用长度 100 的数组计数。每次遇到已有的相同骨牌，累加之前的计数。

## Java 代码实现

```java
class Solution {
    public int numEquivDominoPairs(int[][] dominoes) {
        // 值域 1-9，编码为两位数，最大 99
        int[] count = new int[100];
        int result = 0;

        for (int[] d : dominoes) {
            // 标准化：较小的在十位
            int key = d[0] < d[1] ? d[0] * 10 + d[1] : d[1] * 10 + d[0];
            // 累加之前相同骨牌的数量
            result += count[key];
            count[key]++;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，固定大小数组

## 关键点总结

1. **标准化表示**：`(min, max)` 消除旋转等价
2. **数字编码**：`min*10+max` 映射到数组下标
3. **累加技巧**：每次遇到重复时直接累加已有计数，等价于 C(n,2)
4. **值域小**：1-9 使得数组替代 HashMap 更高效
