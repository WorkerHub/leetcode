## 题目描述

给你一个 `n * n` 矩阵 `grid`，矩阵由若干 `0` 和 `1` 组成。请你用四叉树表示该矩阵。

你需要返回能表示矩阵的四叉树的根节点。

四叉树数据结构中，每个内部节点只有四个子节点。此外，每个节点都有两个属性：
- `val`：储存叶子节点所代表的区域的值。1 对应 True，0 对应 False
- `isLeaf`：当这个节点是一个叶子节点时为 True，如果它有 4 个子节点则为 False

```
class Node {
    public boolean val;
    public boolean isLeaf;
    public Node topLeft;
    public Node topRight;
    public Node bottomLeft;
    public Node bottomRight;
}
```

我们可以按以下步骤为二维区域构建四叉树：
1. 如果当前网格的值相同（即，全为 `0` 或者全为 `1`），将 `isLeaf` 设为 True，将 `val` 设为网格相应的值，并将四个子节点都设为 Null 然后停止。
2. 如果当前网格的值不同，将 `isLeaf` 设为 False，将 `val` 设为任意值，然后如下图所示，将当前网格划分为四个子网格。
3. 使用适当的子网格递归每个子节点。


**提示：**
- `n == grid.length == grid[i].length`
- `n == 2^x` 其中 `0 <= x <= 6`

## 解题思路

这道题要求构建四叉树来表示二维矩阵。核心思想是分治递归。

**关键观察：**
1. 如果区域内所有值相同，创建叶子节点
2. 如果区域内值不同，将区域四等分，递归构建四个子节点
3. 四个子区域分别是：左上、右上、左下、右下

**算法流程：**
1. 检查当前区域是否所有值相同
2. 如果相同，创建叶子节点
3. 如果不同，将区域分成四个子区域
4. 递归构建四个子节点
5. 创建非叶子节点，连接四个子节点

## Java 代码实现

### 方法一：分治递归 ⭐ 推荐

```java
class Solution {
    private int[][] grid;

    public Node construct(int[][] grid) {
        this.grid = grid;
        int n = grid.length;
        return build(0, 0, n);
    }

    private boolean isAllSame(int x, int y, int length) {
        // 检查区域内是否所有值相同
        int val = grid[x][y];
        for (int i = x; i < x + length; i++) {
            for (int j = y; j < y + length; j++) {
                if (grid[i][j] != val) {
                    return false;
                }
            }
        }
        return true;
    }

    private Node build(int x, int y, int length) {
        // 如果区域内所有值相同，创建叶子节点
        if (isAllSame(x, y, length)) {
            return new Node(grid[x][y] == 1, true, null, null, null, null);
        }

        // 值不同，分成四个子区域
        int half = length / 2;

        // 递归构建四个子节点
        Node topLeft = build(x, y, half);
        Node topRight = build(x, y + half, half);
        Node bottomLeft = build(x + half, y, half);
        Node bottomRight = build(x + half, y + half, half);

        // 创建非叶子节点（val 可以是任意值）
        return new Node(true, false, topLeft, topRight, bottomLeft, bottomRight);
    }
}
```

### 方法二：优化版（使用前缀和检查）

```java
class Solution {
    private int[][] prefix;

    public Node construct(int[][] grid) {
        int n = grid.length;

        // 构建前缀和数组，用于快速判断区域是否全0或全1
        prefix = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = grid[i-1][j-1]
                        + prefix[i-1][j]
                        + prefix[i][j-1]
                        - prefix[i-1][j-1];
            }
        }

        return build(0, 0, n);
    }

    private int getSum(int x, int y, int length) {
        // 获取区域的和（利用前缀和 O(1) 查询）
        int x2 = x + length, y2 = y + length;
        return prefix[x2][y2] - prefix[x][y2] - prefix[x2][y] + prefix[x][y];
    }

    private Node build(int x, int y, int length) {
        int total = getSum(x, y, length);
        int area = length * length;

        // 全1或全0
        if (total == 0 || total == area) {
            return new Node(total == area, true, null, null, null, null);
        }

        // 分成四个子区域
        int half = length / 2;
        return new Node(
                true, false,
                build(x, y, half),
                build(x, y + half, half),
                build(x + half, y, half),
                build(x + half, y + half, half)
        );
    }
}
```

### 方法三：简化版

```java
class Solution {
    private int[][] grid;

    public Node construct(int[][] grid) {
        this.grid = grid;
        return dfs(0, 0, grid.length);
    }

    private Node dfs(int x, int y, int n) {
        // 检查是否全部相同
        int val = grid[x][y];
        boolean allSame = true;

        outer:
        for (int i = x; i < x + n; i++) {
            for (int j = y; j < y + n; j++) {
                if (grid[i][j] != val) {
                    allSame = false;
                    break outer;
                }
            }
        }

        // 叶子节点
        if (allSame) {
            return new Node(val == 1, true, null, null, null, null);
        }

        // 非叶子节点
        int half = n / 2;
        return new Node(
                true, false,
                dfs(x, y, half),
                dfs(x, y + half, half),
                dfs(x + half, y, half),
                dfs(x + half, y + half, half)
        );
    }
}
```

## 复杂度分析

**方法一：基础分治**
- 时间复杂度：O(n² × log n)
  - 每层递归需要 O(n²) 检查是否相同
  - 递归深度为 O(log n)
- 空间复杂度：O(log n)，递归栈空间

**方法二：前缀和优化**
- 时间复杂度：O(n²)
  - 构建前缀和：O(n²)
  - 递归构建：每次判断 O(1)，共 O(n²) 个节点
- 空间复杂度：O(n²)，前缀和数组

## 关键点总结

1. **分治思想**：将大问题分解为四个相同的小问题
2. **递归终止条件**：区域内所有值相同时创建叶子节点
3. **区域划分**：每次将区域四等分（左上、右上、左下、右下）
4. **前缀和优化**：使用前缀和快速判断区域是否全0或全1
5. **节点属性**：叶子节点的 isLeaf=true，非叶子节点的 isLeaf=false

## 易错点

1. **边界计算**：划分子区域时，起始坐标和长度要计算正确
2. **叶子节点判断**：只有所有值相同才是叶子节点
3. **坐标系统**：要注意行列索引，避免混淆 x 和 y
4. **非叶子节点的 val**：非叶子节点的 val 可以是任意值
5. **递归顺序**：四个子节点的顺序是固定的（左上、右上、左下、右下）
