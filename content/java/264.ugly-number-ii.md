## 题目描述

给你一个整数 `n`，请你找出并返回第 `n` 个丑数。

丑数是只包含质因数 `2`、`3` 和 `5` 的正整数。

**示例 1：**
```
输入: n = 10
输出: 12
解释: [1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是前 10 个丑数
```

**示例 2：**
```
输入: n = 1
输出: 1
解释: 1 没有质因数，被视为第 1 个丑数
```

**提示：**
- `1 <= n <= 1690`

## 解题思路

这道题是"丑数 I"的进阶版，不能简单地逐个判断，因为时间复杂度太高。

**核心观察：**
- 丑数可以由前面的丑数乘以 2、3 或 5 得到
- 第一个丑数是 1
- 后续丑数 = min(前面某个丑数 × 2, 前面某个丑数 × 3, 前面某个丑数 × 5)

**两种经典解法：**

### 解法 1：三指针动态规划（最优）
- 维护三个指针 p2, p3, p5，分别指向待乘以 2、3、5 的丑数位置
- 每次选择三者中的最小值作为下一个丑数
- 更新对应的指针

### 解法 2：最小堆
- 使用堆维护候选丑数
- 每次取出最小值，并生成新的候选（乘以 2、3、5）
- 使用集合去重

## Java 代码实现

### 方法一：三指针动态规划（推荐）⭐

```java
class Solution {
    public int nthUglyNumber(int n) {
        // dp[i] 表示第 i+1 个丑数
        int[] dp = new int[n];
        dp[0] = 1; // 第一个丑数是 1

        // 三个指针，分别指向待乘以 2、3、5 的丑数位置
        int p2 = 0, p3 = 0, p5 = 0;

        for (int i = 1; i < n; i++) {
            // 计算三个候选值
            int num2 = dp[p2] * 2;
            int num3 = dp[p3] * 3;
            int num5 = dp[p5] * 5;

            // 选择最小的作为下一个丑数
            dp[i] = Math.min(num2, Math.min(num3, num5));

            // 更新指针（注意：可能同时满足多个条件，都要更新）
            if (dp[i] == num2) p2++;
            if (dp[i] == num3) p3++;
            if (dp[i] == num5) p5++;
        }

        return dp[n - 1];
    }
}
```

### 方法二：最小堆

```java
import java.util.*;

class Solution {
    public int nthUglyNumber(int n) {
        // 最小堆，初始只有 1
        PriorityQueue<Long> heap = new PriorityQueue<>();
        Set<Long> seen = new HashSet<>();
        heap.offer(1L);
        seen.add(1L);

        long ugly = 1;
        int[] factors = {2, 3, 5};

        for (int i = 0; i < n; i++) {
            // 取出当前最小的丑数
            ugly = heap.poll();

            // 生成新的候选丑数
            for (int factor : factors) {
                long newUgly = ugly * factor;
                if (!seen.contains(newUgly)) {
                    seen.add(newUgly);
                    heap.offer(newUgly);
                }
            }
        }

        return (int) ugly;
    }
}
```

### 方法三：优化的三指针（更清晰的写法）

```java
class Solution {
    public int nthUglyNumber(int n) {
        int[] ugly = new int[n]; // 丑数列表
        ugly[0] = 1;
        int i2 = 0, i3 = 0, i5 = 0; // 三个指针

        for (int i = 1; i < n; i++) {
            // 计算下一个候选
            int next2 = ugly[i2] * 2;
            int next3 = ugly[i3] * 3;
            int next5 = ugly[i5] * 5;

            // 选择最小值
            int nextUgly = Math.min(next2, Math.min(next3, next5));
            ugly[i] = nextUgly;

            // 移动指针（可能同时移动多个）
            if (nextUgly == next2) i2++;
            if (nextUgly == next3) i3++;
            if (nextUgly == next5) i5++;
        }

        return ugly[n - 1];
    }
}
```

## 复杂度分析

### 方法一（三指针动态规划）
- **时间复杂度**：O(n)，需要计算 n 个丑数，每次 O(1) 操作
- **空间复杂度**：O(n)，存储 n 个丑数

### 方法二（最小堆）
- **时间复杂度**：O(n log n)，堆操作 log n，执行 n 次
- **空间复杂度**：O(n)，堆和集合最多存储 O(n) 个元素

## 图解示例

以 n = 10 为例，展示三指针的移动过程：

```

第 3 步:
  候选: 2×2=4, 3×3=9, 1×5=5

第 4 步:
  候选: 3×2=6, 3×3=9, 1×5=5

第 5 步:
  候选: 3×2=6, 3×3=9, 2×5=10
```

## 关键点总结

1. **动态规划思想**：每个丑数都由前面的丑数乘以 2、3 或 5 得到
2. **三指针维护**：
   - p2 指向待乘以 2 的位置
   - p3 指向待乘以 3 的位置
   - p5 指向待乘以 5 的位置
3. **去重关键**：同时满足多个条件时，所有指针都要移动
   - 例如：6 = 2×3 = 3×2，p2 和 p3 都要移动
4. **时间优化**：三指针法 O(n) 优于堆方法 O(n log n)
5. **Java 中使用 Math.min**：代替 Python 中的 min() 函数

## 易错点

1. **指针更新错误**：必须使用 if 而不是 else if
   ```java
   // 错误写法
   if (dp[i] == num2) p2++;
   else if (dp[i] == num3) p3++; // ❌ 应该用 if

   // 正确写法：都用 if，因为可能同时满足
   if (dp[i] == num2) p2++;
   if (dp[i] == num3) p3++;
   ```

2. **初始值设置**：dp[0] = 1，第一个丑数是 1

3. **返回值错误**：返回 dp[n-1] 而不是 dp[n]

4. **堆方法的溢出**：Java 中使用 long 避免乘法溢出

5. **边界情况**：n = 1 时直接返回 1

   - 这是典型的 DP 问题

   - 状态转移：从前面的丑数推导

2. **掌握三指针技巧**：
   - 这是一种常见的多路归并思想
   - 类似于合并 K 个有序链表
