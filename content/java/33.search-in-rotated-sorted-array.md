## 题目描述

整数数组 `nums` 按升序排列，数组中的值 **互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如，`[0,1,2,4,5,6,7]` 在下标 `3` 处经旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你 **旋转后** 的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**
```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**示例 3：**
```
输入：nums = [1], target = 0
输出：-1
```

## 解题思路

### 核心思想：改进的二分查找

旋转数组的特点：
- 数组被分成两段，每段都是升序的
- 例如 `[4,5,6,7,0,1,2]`，分为 `[4,5,6,7]` 和 `[0,1,2]`

**关键观察：**
在二分查找中，`mid` 必然在某一个有序的部分：
1. 如果 `nums[left] <= nums[mid]`，左半部分有序
2. 否则，右半部分有序

**算法流程：**
1. 计算 `mid`
2. 判断哪一半是有序的
3. 判断 `target` 是否在有序的那一半
4. 调整 `left` 或 `right`

## Java 代码实现

### 方法：改进的二分查找

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            // 找到目标值
            if (nums[mid] == target) {
                return mid;
            }
            
            // 判断哪一半是有序的
            if (nums[left] <= nums[mid]) {
                // 左半部分有序
                // 判断target是否在左半部分
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 右半部分有序
                // 判断target是否在右半部分
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，标准二分查找
- **空间复杂度**：O(1)，只使用常量额外空间

## 图解示例

### 示例：`nums = [4,5,6,7,0,1,2], target = 0`

```
第一次：
[4,5,6,7,0,1,2]
 ↑     ↑     ↑
left  mid  right

nums[mid]=7, nums[left]=4 <= nums[mid]=7
→ 左半部分 [4,5,6,7] 有序
target=0 不在 [4,7) 范围内
→ 搜索右半部分，left = mid + 1 = 4

第二次：
[4,5,6,7,0,1,2]
         ↑ ↑ ↑
       left mid right

nums[mid]=1, nums[left]=0 <= nums[mid]=1
→ 左半部分 [0,1] 有序
target=0 在 [0,1) 范围内
→ 搜索左半部分，right = mid - 1 = 4

第三次：
[4,5,6,7,0,1,2]
         ↑
    left/mid/right

nums[mid]=0 == target
→ 返回 4
```

## 关键点总结

1. **判断有序部分**：
   - `nums[left] <= nums[mid]`：左半部分有序
   - 否则：右半部分有序

2. **判断 target 位置**：
   - 在有序部分：判断 `target` 是否在有序区间内
   - 不在：搜索另一半

3. **边界条件**：
   - `nums[left] <= target < nums[mid]`（左边界有等号，右边界没有）
   - `nums[mid] < target <= nums[right]`（左边界没有，右边界有等号）

4. **为什么 `nums[left] <= nums[mid]`**：
   - 有等号是为了处理 `left == mid` 的情况
   - 例如只剩两个元素时

## 易错点

1. **判断有序的条件**：
   - 错误：`nums[left] < nums[mid]`（没有等号会漏掉边界情况）
   - 正确：`nums[left] <= nums[mid]`

2. **target 范围判断**：
   - 要用 `<=` 和 `<` 的组合，不要全用 `<=` 或全用 `<`
   - `nums[left] <= target && target < nums[mid]`
   - `nums[mid] < target && target <= nums[right]`

3. **循环条件**：
   - `while (left <= right)`（有等号）
