## 题目描述

给定 `m × n` 矩阵 `grid`，`grid[i][j]` 表示进入该单元格所需的最早时间。从 `(0,0)` 出发（时间 0），每步移动耗时 1，求到达 `(m-1,n-1)` 的最短时间，无法到达返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 若起点两邻都不可达，无法通过等待绕路
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;
        // 最小堆：{时间, 行, 列}
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int t = cur[0], i = cur[1], j = cur[2];
            if (i == m - 1 && j == n - 1) return t;
            if (t > dist[i][j]) continue;
            for (int[] d : dirs) {
                int ni = i + d[0], nj = j + d[1];
                if (ni < 0 || ni >= m || nj < 0 || nj >= n) continue;
                // 计算到达 (ni,nj) 的最早时间
                int diff = grid[ni][nj] - t - 1;
                int arrive;
                if (diff <= 0) arrive = t + 1;
                else if (diff % 2 == 0) arrive = grid[ni][nj];
                else arrive = grid[ni][nj] + 1;

                if (arrive < dist[ni][nj]) {
                    dist[ni][nj] = arrive;
                    pq.offer(new int[]{arrive, ni, nj});
                }
            }
        }

        return dist[m - 1][n - 1] == Integer.MAX_VALUE ? -1 : dist[m - 1][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))，Dijkstra
- 空间复杂度：O(mn)

## 关键点总结

1. 时间受限的格子可通过"来回等待"绕过，等待步数奇偶性决定到达时间
2. 若起点周围均受限（值 > 1），则无法到达终点
3. 此问题是 LeetCode 2577 的扩展版本
