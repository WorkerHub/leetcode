## 题目描述

给数组nums和模式pattern，统计匹配模式（相邻元素大小关系）的子数组数量。（n<=100）

## 解题思路

将nums转为差分符号数组sign(nums[i+1]-nums[i])，然后在sign中暴力匹配pattern。

## Java 代码实现

```java
class Solution {
    public int countMatchingSubarrays(int[] nums, int[] pattern) {
        int n = nums.length, m = pattern.length;
        int[] diff = new int[n - 1];
        for (int i = 0; i < n - 1; i++) {
            diff[i] = Integer.compare(nums[i + 1], nums[i]);
        }

        int count = 0;
        for (int i = 0; i <= diff.length - m; i++) {
            boolean match = true;
            for (int j = 0; j < m; j++) {
                if (diff[i + j] != pattern[j]) {
                    match = false;
                    break;
                }
            }
            if (match) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N*M)
- **空间复杂度**：O(N)

## 关键点总结

1. **转为符号数组**：sign(差值)映射到{-1,0,1}
2. **暴力匹配**：n<=100可行
3. **diff长度为n-1**
