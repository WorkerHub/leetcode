## 题目描述

在无限整数线上从 `startPos` 出发，每步向左或向右移动一位，恰好走 k 步到达 `endPos` 的不同走法数（对 10^9+7 取模）。

## 解题思路

设距离 `d = |endPos - startPos|`。若 `d > k` 或 `(k-d)%2 != 0` 则无解返回 0。否则正方向走 `r = (k+d)/2` 步，答案为 C(k, r) mod (10^9+7)。用 Pascal 三角预计算组合数。

## Java 代码实现

```java
class Solution {
    public int numberOfWays(int startPos, int endPos, int k) {
        final int MOD = 1_000_000_007;
        int d = Math.abs(endPos - startPos);
        if (d > k || (k - d) % 2 != 0) return 0;
        int r = (k + d) / 2;

        // 用 Pascal 三角计算 C(k, r) mod MOD
        long[] dp = new long[k + 1];
        dp[0] = 1;
        for (int i = 1; i <= k; i++) {
            for (int j = i; j >= 1; j--) {
                dp[j] = (dp[j] + dp[j - 1]) % MOD;
            }
        }
        return (int) dp[r];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k^2)，k <= 1000
- **空间复杂度**：O(k)

## 关键点总结

1. 净位移 d，总步数 k：当 `(k-d)` 为奇数或 `d > k` 时无解。
2. 正方向步数 `r = (k+d)/2`，答案为 `C(k, r) mod (10^9+7)`。
3. 滚动 Pascal 三角一维 DP 计算组合数，注意逆序更新避免覆盖。
