## 题目描述

n支队伍和有向边edges[i]=[u,v]表示u比v强，找入度为0的唯一节点作为冠军，不唯一返回-1。

## 解题思路

统计每个节点的入度，入度为0的节点就是没有被任何队伍打败的冠军。若入度为0的节点不唯一则返回-1。

## Java 代码实现

```java
class Solution {
    public int findChampion(int n, int[][] edges) {
        int[] indegree = new int[n];
        for (int[] e : edges) {
            indegree[e[1]]++;
        }
        int champion = -1;
        for (int i = 0; i < n; i++) {
            if (indegree[i] == 0) {
                if (champion != -1) return -1; // 不唯一
                champion = i;
            }
        }
        return champion;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + E)
- **空间复杂度**：O(N)

## 关键点总结

1. **入度为0即冠军**：没有队伍能击败它
2. **唯一性判断**：多个入度为0返回-1
3. **DAG性质**：题目保证无环
