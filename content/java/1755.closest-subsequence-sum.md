## 题目描述

给你整数数组 `nums`（长度 <= 40）和目标值 `goal`，从 `nums` 中选一个子序列使其和最接近 `goal`，返回最小绝对差。

## 解题思路

折半枚举（Meet in the Middle）：将数组分两半，分别枚举所有子集和（各 2^20 个），对后半排序，对前半每个和二分查找最接近 `goal - s1` 的值。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int minAbsDifference(int[] nums, int goal) {
        int n = nums.length;
        int half = n / 2;

        // 枚举前半部分所有子集和
        int[] left = getAllSums(nums, 0, half);
        // 枚举后半部分所有子集和
        int[] right = getAllSums(nums, half, n);
        Arrays.sort(right);

        int ans = Integer.MAX_VALUE;
        for (int s1 : left) {
            int target = goal - s1;
            // 在 right 中二分找最接近 target 的值
            int pos = lowerBound(right, target);
            // 检查 pos 和 pos-1
            if (pos < right.length) ans = Math.min(ans, Math.abs(s1 + right[pos] - goal));
            if (pos > 0) ans = Math.min(ans, Math.abs(s1 + right[pos - 1] - goal));
        }

        return ans;
    }

    private int[] getAllSums(int[] nums, int start, int end) {
        int len = end - start;
        int size = 1 << len;
        int[] sums = new int[size];
        for (int mask = 0; mask < size; mask++) {
            int s = 0;
            for (int i = 0; i < len; i++) {
                if (((mask >> i) & 1) == 1) s += nums[start + i];
            }
            sums[mask] = s;
        }
        return sums;
    }

    // lower_bound：找第一个 >= target 的位置
    private int lowerBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 2^(n/2))
- **空间复杂度**：O(2^(n/2))

## 关键点总结

1. 折半枚举将 O(2^n) 降为 O(2^(n/2))
2. 对后半排序后二分查找，检查前后两个候选值
