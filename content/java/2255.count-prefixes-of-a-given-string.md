## 题目描述

统计words中是字符串s的前缀的单词数量。

## 解题思路

遍历words，对每个单词检查s是否以它开头，统计满足条件的数量。

## Java 代码实现

```java
class Solution {
    public int countPrefixes(String[] words, String s) {
        int count = 0;
        for (String w : words) {
            if (s.startsWith(w)) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(所有单词长度之和)
- **空间复杂度**：O(1)

## 关键点总结

1. **startsWith方法**：直接判断前缀关系
2. **重复单词独立统计**：words中可能有重复
