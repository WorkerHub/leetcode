## 题目描述

给你环形 `colors` 数组（0/1）和查询数组：type=1 翻转某位置颜色；type=2 查询长度恰好为 `size` 的交替组数量。

## 解题思路

维护差分数组 `diff[i]=1` 表示 colors[i] 与 colors[(i-1+n)%n] 不同。长度 k 的交替组等价于差分数组中连续 k-1 个 1 的段。用 TreeSet 维护 diff=0 的位置，翻转时最多更新两个 diff 值，查询时枚举所有段计算贡献。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> numberOfAlternatingGroups(int[] colors, int[][] queries) {
        int n = colors.length;
        int[] diff = new int[n];
        for (int i = 0; i < n; i++) {
            diff[i] = (colors[i] != colors[(i - 1 + n) % n]) ? 1 : 0;
        }

        // 用 TreeSet 存储 diff=0 的位置（段的分隔符）
        TreeSet<Integer> zeros = new TreeSet<>();
        for (int i = 0; i < n; i++) {
            if (diff[i] == 0) zeros.add(i);
        }

        List<Integer> results = new ArrayList<>();

        for (int[] q : queries) {
            if (q[0] == 1) {
                // 翻转 colors[pos]
                int pos = q[1];
                colors[pos] ^= 1;
                // 更新 diff[pos] 和 diff[(pos+1)%n]
                for (int idx : new int[]{pos, (pos + 1) % n}) {
                    int newDiff = (colors[idx] != colors[(idx - 1 + n) % n]) ? 1 : 0;
                    if (diff[idx] != newDiff) {
                        if (newDiff == 0) zeros.add(idx);
                        else zeros.remove(idx);
                        diff[idx] = newDiff;
                    }
                }
            } else {
                // 查询长度 k 的交替组数
                int k = q[1];
                long count = 0;
                if (zeros.isEmpty()) {
                    // 全部交替：整个环都是交替组
                    count = n;
                } else {
                    // 枚举每段连续 1 的长度，计算贡献
                    for (int z : zeros) {
                        // 从 z 开始的段长度（到下一个 zero 之间）
                        Integer next = zeros.higher(z);
                        int segLen;
                        if (next == null) {
                            // 环形：绕到 zeros.first()
                            segLen = n - z - 1 + zeros.first();
                        } else {
                            segLen = next - z - 1;
                        }
                        if (segLen >= k - 1) {
                            count += segLen - (k - 2);
                        }
                    }
                }
                results.add((int) count);
            }
        }

        return results;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)，q 为查询数量
- 空间复杂度：O(n)

## 关键点总结

1. 差分数组：`diff[i]=1` 表示位置 i 与前一位颜色不同
2. 翻转操作最多影响相邻两个 diff 值（diff[pos] 和 diff[(pos+1)%n]）
3. 长度 k 的交替组等价于连续 k-1 个 1 的段，每段长 L 贡献 max(0, L-k+2) 个组
