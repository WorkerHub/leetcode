## 题目描述

给你整数数组 `hours` 和整数 `target`，返回工作时间至少为 `target` 小时的员工人数。

## Java 代码实现

```java
class Solution {
    public int numberOfEmployeesWhoMetTarget(int[] hours, int target) {
        int ans = 0;
        for (int h : hours) {
            if (h >= target) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 条件是 `>= target`（至少），包含等于
2. 遍历一次即可
