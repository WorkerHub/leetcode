## 题目描述

给定一个不为空的二叉搜索树和一个目标值 `target`，请在该二叉搜索树中找到最接近目标值的节点值。

**注意：**
- 给定的目标值 `target` 是一个浮点数
- 题目保证在该二叉搜索树中只会存在一个最接近目标值的数

**示例 1：**
```
输入: root = [4,2,5,1,3], target = 3.714286
输出: 4

    4
   / \
  2   5
 / \
1   3
```

**示例 2：**
```
输入: root = [1], target = 4.428571
输出: 1
```

**提示：**
- 树中节点数在范围 `[1, 10^4]` 内
- `0 <= Node.val <= 10^9`
- `-10^9 <= target <= 10^9`

## 解题思路

利用**二叉搜索树（BST）的性质**可以高效求解。

**BST 性质：**
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点

**核心思路：**

1. **二分搜索**：
   - 如果 target < root.val，向左子树搜索
   - 如果 target > root.val，向右子树搜索
   - 每次比较当前节点是否更接近 target

2. **中序遍历**：
   - BST 的中序遍历是升序序列
   - 找到第一个大于等于 target 的节点
   - 比较该节点和前一个节点哪个更接近

## Java 代码实现

### 方法一：迭代二分搜索（推荐）⭐

```java
class Solution {
    public int closestValue(TreeNode root, double target) {
        int closest = root.val;

        while (root != null) {
            // 更新最接近的值
            if (Math.abs(root.val - target) < Math.abs(closest - target)) {
                closest = root.val;
            }

            // 二分搜索
            if (target < root.val) {
                root = root.left;
            } else {
                root = root.right;
            }
        }

        return closest;
    }
}
```

### 方法二：递归二分搜索

```java
class Solution {
    private int closest;

    public int closestValue(TreeNode root, double target) {
        // 记录最接近的值
        closest = root.val;
        dfs(root, target);
        return closest;
    }

    private void dfs(TreeNode node, double target) {
        if (node == null) return;

        // 更新最接近的值
        if (Math.abs(node.val - target) < Math.abs(closest - target)) {
            closest = node.val;
        }

        // 利用 BST 性质进行二分搜索
        if (target < node.val) {
            dfs(node.left, target);
        } else {
            dfs(node.right, target);
        }
    }
}
```

### 方法三：中序遍历

```java
import java.util.Stack;

class Solution {
    public int closestValue(TreeNode root, double target) {
        // 中序遍历 BST 得到升序序列
        // 找到第一个 >= target 的节点，比较前后两个值
        Stack<TreeNode> stack = new Stack<>();
        int prev = Integer.MIN_VALUE;

        while (!stack.isEmpty() || root != null) {
            // 一直向左
            while (root != null) {
                stack.push(root);
                root = root.left;
            }

            // 处理当前节点
            root = stack.pop();

            // 如果当前值 >= target，比较前后两个值
            if (root.val >= target) {
                // 比较 prev 和 root.val 哪个更接近
                if (Math.abs(prev - target) < Math.abs(root.val - target)) {
                    return prev;
                } else {
                    return root.val;
                }
            }

            prev = root.val;
            root = root.right;
        }

        // 所有值都 < target，返回最后一个
        return prev;
    }
}
```

### 方法四：暴力遍历（不推荐）

```java
class Solution {
    private int closest;

    public int closestValue(TreeNode root, double target) {
        // 遍历所有节点，找最接近的
        // 没有利用 BST 性质，效率低
        closest = root.val;
        traverse(root, target);
        return closest;
    }

    private void traverse(TreeNode node, double target) {
        if (node == null) return;

        if (Math.abs(node.val - target) < Math.abs(closest - target)) {
            closest = node.val;
        }

        traverse(node.left, target);
        traverse(node.right, target);
    }
}
```

## 复杂度分析

### 方法一、二（二分搜索）
- **时间复杂度**：O(h)
  - h 是树的高度
  - 平衡树：O(log n)
  - 最坏情况（链状树）：O(n)
  
- **空间复杂度**：
  - 迭代：O(1)
  - 递归：O(h)，递归栈

### 方法三（中序遍历）
- **时间复杂度**：O(n)，最坏需要遍历所有节点
- **空间复杂度**：O(h)，栈空间

### 方法四（暴力遍历）
- **时间复杂度**：O(n)，遍历所有节点
- **空间复杂度**：O(h)，递归栈

## 图解示例

以示例 1 为例：`root = [4,2,5,1,3], target = 3.714286`

```

    1   3

搜索过程:

1. 从根节点 4 开始
   |4 - 3.714| = 0.286

2. 节点 2
   |2 - 3.714| = 1.714
   0.286 < 1.714, 不更新
   target > 2, 向右

3. 节点 3
   |3 - 3.714| = 0.714

   target > 3, 向右

   返回 closest = 4
```

## 关键点总结

1. **利用 BST 性质**：
   - target < node.val → 向左搜索
   - target > node.val → 向右搜索
   - 时间复杂度从 O(n) 降到 O(h)

2. **比较标准**：
   - 使用 `Math.abs(node.val - target)` 计算距离
   - 选择距离更小的节点

3. **迭代 vs 递归**：
   - 迭代空间复杂度更优（O(1)）
   - 递归代码更简洁

4. **中序遍历技巧**：
   - BST 中序遍历是升序
   - 找到第一个 >= target 的位置
   - 比较前后两个值

5. **Java 中注意**：
   - `target` 是 `double` 类型
   - 使用 `Math.abs()` 计算绝对值
   - 与 `int` 型节点值做差时会自动类型提升

## 易错点

1. **忘记利用 BST 性质**：
   ```java
   // 错误：遍历所有节点
   traverse(node.left);
   traverse(node.right);
   
   // 正确：二分搜索
   if (target < node.val) {
       dfs(node.left, target);
   } else {
       dfs(node.right, target);
   }
   ```

2. **距离计算错误**：
   ```java
   // 正确：要取绝对值
   Math.abs(node.val - target)
   
   // 错误：可能为负数
   node.val - target
   ```

3. **初始值设置**：
   ```java
   // 正确：初始化为根节点值
   int closest = root.val;
   
   // 错误：初始化为 0
   // 可能导致根节点本身就是答案时被忽略
   ```

4. **相等情况处理**：target == node.val 时，可向左或向右，通常向右（包含在 else 分支）

5. **中序遍历边界**：`prev` 初始化为 `Integer.MIN_VALUE`，防止所有值都 >= target 时出错
