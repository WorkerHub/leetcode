## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，恰好交换一次（各取一个元素），返回 `|set(nums1)| + |set(nums2)|` 的最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumDistinctValues(int[] nums1, int[] nums2) {
        Set<Integer> set1 = new HashSet<>(), set2 = new HashSet<>();
        Map<Integer, Integer> cnt1 = new HashMap<>(), cnt2 = new HashMap<>();
        for (int x : nums1) { set1.add(x); cnt1.merge(x, 1, Integer::sum); }
        for (int x : nums2) { set2.add(x); cnt2.merge(x, 1, Integer::sum); }

        int base = set1.size() + set2.size();
        // 收集有价值的候选：unique元素或公共元素（各取前4个）
        List<Integer> candA = candidates(set1, cnt1, set2);
        List<Integer> candB = candidates(set2, cnt2, set1);

        int minResult = base;
        for (int a : candA) {
            for (int b : candB) {
                int delta = 0;
                if (cnt1.get(a) == 1) delta--;       // set1 失去 a
                if (!set1.contains(b)) delta++;       // set1 获得新的 b
                if (cnt2.get(b) == 1) delta--;       // set2 失去 b
                if (!set2.contains(a)) delta++;       // set2 获得新的 a
                minResult = Math.min(minResult, base + delta);
            }
        }
        return minResult;
    }

    private List<Integer> candidates(Set<Integer> set, Map<Integer, Integer> cnt, Set<Integer> other) {
        List<Integer> res = new ArrayList<>();
        // 优先：唯一且在对方集合中的元素
        for (int x : set) if (cnt.get(x) == 1 && other.contains(x)) { res.add(x); if (res.size() == 2) break; }
        // 其次：唯一但不在对方中的元素
        for (int x : set) if (cnt.get(x) == 1 && !other.contains(x)) { res.add(x); if (res.size() == 4) break; }
        // 再次：在对方中的元素（cnt > 1）
        for (int x : set) if (cnt.get(x) > 1 && other.contains(x)) { res.add(x); if (res.size() == 5) break; }
        // 最后任意
        for (int x : set) { res.add(x); if (res.size() == 6) break; }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. 交换 a 和 b 的效果：set1 失去 a（若唯一）/获得 b（若 b 不在 set1），set2 类似
2. 只需检查少量有价值的候选元素（唯一元素和公共元素）
3. 必须恰好交换一次，可以交换相同值（无变化）
