## 题目描述

给你一个整数 `n`，用其各位数字（每个数字最多使用一次）构造最大的回文数，返回该回文数。

## 解题思路

贪心：统计各位数字频率，成对放两端（从大到小），奇数出现次数中选最大的数字放中间，构造最大回文。

## Java 代码实现

```java
class Solution {
    public long maximumPalindrome(long n) {
        int[] freq = new int[10];
        String s = Long.toString(n);
        for (char c : s.toCharArray()) freq[c - '0']++;

        StringBuilder half = new StringBuilder();
        int middle = -1;

        // 从大到小贪心构造
        for (int d = 9; d >= 0; d--) {
            int pairs = freq[d] / 2;
            for (int i = 0; i < pairs; i++) half.append((char)('0' + d));
            if (freq[d] % 2 == 1 && middle == -1) middle = d;
        }

        String halfStr = half.toString();
        StringBuilder palindrome = new StringBuilder(halfStr);
        if (middle != -1) palindrome.append((char)('0' + middle));
        palindrome.append(new StringBuilder(halfStr).reverse());

        String result = palindrome.toString();
        if (result.isEmpty()) return -1;
        return Long.parseLong(result);
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(log n)

## 关键点总结

1. 成对数字放两端，奇数出现时取最大的放中间
2. 从大到小贪心确保构造最大回文
3. 前半部分反转即为后半部分
