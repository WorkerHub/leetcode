## 题目描述

给定技能列表 req_skills 和人员列表 people[i]（每人拥有的技能），返回覆盖所有技能的最小团队的人员下标列表。

**示例：**
```
输入：req_skills = ["java","nodejs","reactjs"], people = [["java"],["nodejs"],["nodejs","reactjs"]]
输出：[0,2]
```

## 解题思路

状态压缩 DP：用二进制位表示技能集合，`dp[state]` 记录达到该状态的最小团队。遍历每个人，尝试将其加入已有状态并更新新状态。

## Java 代码实现

```java
class Solution {
    public int[] smallestSufficientTeam(String[] req_skills, List<List<String>> people) {
        int n = req_skills.length;
        // 技能到索引的映射
        Map<String, Integer> skillIdx = new HashMap<>();
        for (int i = 0; i < n; i++) skillIdx.put(req_skills[i], i);

        int target = (1 << n) - 1;
        // dp[state] = 达到该状态的最小团队
        List<Integer>[] dp = new List[1 << n];
        dp[0] = new ArrayList<>();

        // 将每个人的技能转为 bitmask
        int m = people.size();
        int[] personSkill = new int[m];
        for (int i = 0; i < m; i++) {
            int mask = 0;
            for (String s : people.get(i)) {
                mask |= (1 << skillIdx.get(s));
            }
            personSkill[i] = mask;
        }

        // 遍历每个人
        for (int i = 0; i < m; i++) {
            if (personSkill[i] == 0) continue;
            // 遍历所有已知状态
            for (int state = target; state >= 0; state--) {
                if (dp[state] == null) continue;
                int newState = state | personSkill[i];
                if (dp[newState] == null || dp[newState].size() > dp[state].size() + 1) {
                    dp[newState] = new ArrayList<>(dp[state]);
                    dp[newState].add(i);
                }
            }
        }

        return dp[target].stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × m)，n ≤ 16，m ≤ 60
- **空间复杂度**：O(2^n × m)

## 关键点总结

1. **状态压缩**：二进制位表示技能集合，n ≤ 16 使得 2^16 可行
2. **DP 转移**：`dp[state | personSkill] = dp[state] + person`
3. **从后向前遍历**：避免同一个人被重复使用
4. **目标状态**：`(1 << n) - 1` 即所有位为 1
