## 题目描述

给定字符串s和参数power/modulo/k/hashValue，找到第一个长度为k且哈希值等于hashValue的子串。

## 解题思路

从右向左滚动哈希避免除法：h[i] = val(s[i]) + power * (h[i+1] - val(s[i+k]) * power^(k-1))，记录最左匹配位置。

## Java 代码实现

```java
class Solution {
    public String subStrHash(String s, int power, int modulo, int k, int hashValue) {
        int n = s.length();
        long p = power, mod = modulo;
        long pkMinus1 = 1;
        for (int i = 0; i < k - 1; i++) {
            pkMinus1 = pkMinus1 * p % mod;
        }
        
        // 初始化最后一个窗口的哈希
        long h = 0;
        for (int i = n - 1; i >= n - k; i--) {
            h = (h * p + (s.charAt(i) - 'a' + 1)) % mod;
        }
        
        int ansStart = (h == hashValue) ? n - k : -1;
        
        // 从右向左滑动
        for (int i = n - k - 1; i >= 0; i--) {
            // 移出右端s[i+k]，移入左端s[i]
            long remove = (s.charAt(i + k) - 'a' + 1) * pkMinus1 % mod;
            h = ((h - remove + mod) * p + (s.charAt(i) - 'a' + 1)) % mod;
            if (h == hashValue) {
                ansStart = i;
            }
        }
        return s.substring(ansStart, ansStart + k);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **从右向左滚动**：避免需要模逆元的除法
2. **取模防负数**：`(h - remove + mod)` 保证非负
3. **记录最左匹配**：从右向左遍历，每次匹配更新答案
