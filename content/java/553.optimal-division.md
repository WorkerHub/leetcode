## 题目描述

给定一组正整数，相邻的整数之间将会进行浮点除法操作。例如，`[2,3,4] -> 2 / 3 / 4`。

但是，你可以在任意位置添加任意数量的括号，来改变算术运算的优先级。你需要找出怎么添加括号，以便得到**最大**的结果，并且以字符串格式返回相应的表达式。你的表达式不应该含有冗余的括号。

**示例 1：**
```
输入：nums = [1000,100,10,2]
输出："1000/(100/10/2)"
解释：
1000/(100/10/2) = 1000/((100/10)/2) = 200
但是，以下加粗的括号 "1000/((100/10)/2)" 是冗余的，
因为他们并不影响操作的优先级，所以你需要返回 "1000/(100/10/2)"。

其他用例：
1000/(100/10)/2 = 50
1000/(100/(10/2)) = 50
1000/100/10/2 = 0.5
1000/100/(10/2) = 2
```

**示例 2：**
```
输入：nums = [2,3,4]
输出："2/(3/4)"
解释：(2/(3/4)) = 8/3 = 2.667
它比以下其他可能性更大：
2/(3/4) = 2.667
2/3/4 = 0.167
2/(3/4) = 2.667
```

**示例 3：**
```
输入：nums = [2]
输出："2"
```

**提示：**
- `1 <= nums.length <= 10`
- `2 <= nums[i] <= 1000`
- 对于给定的输入，保证答案可以用 32 位浮点数表示

## 解题思路

这是一道数学+贪心的题目，关键在于理解除法运算的性质。

核心观察：
1. 连续除法 `a / b / c / d` 等价于 `a / (b * c * d)`
2. 要使结果最大，需要让分子最大，分母最小
3. 分子只能是第一个数 `nums[0]`
4. 分母应该尽可能小，即 `nums[1] / nums[2] / ... / nums[n-1]`

数学推导：
- 原式：`a / b / c / d = a / b / c / d`
- 加括号：`a / (b / c / d) = a / (b / (c * d)) = a * (c * d) / b`
- 继续优化：`a / (b / c / d) = a * c * d / b`

结论：
- 当 n = 1 时，直接返回 `nums[0]`
- 当 n = 2 时，返回 `nums[0]/nums[1]`
- 当 n >= 3 时，返回 `nums[0]/(nums[1]/nums[2]/.../nums[n-1])`

## Java 代码实现

### 方法一：数学贪心（推荐）⭐

```java
class Solution {
    public String optimalDivision(int[] nums) {
        // 数学贪心：要让结果最大，需要让分母最小
        // 当 n >= 3 时，最优解是 nums[0]/(nums[1]/nums[2]/.../nums[n-1])
        int n = nums.length;

        // 特殊情况
        if (n == 1) return String.valueOf(nums[0]);
        if (n == 2) return nums[0] + "/" + nums[1];

        // n >= 3 的情况：nums[0]/(nums[1]/nums[2]/.../nums[n-1])
        StringBuilder sb = new StringBuilder();
        sb.append(nums[0]).append("/(").append(nums[1]);
        for (int i = 2; i < n; i++) {
            sb.append("/").append(nums[i]);
        }
        sb.append(")");

        return sb.toString();
    }
}
```

### 方法二：简洁写法

```java
class Solution {
    public String optimalDivision(int[] nums) {
        // 更简洁的实现
        if (nums.length == 1) return String.valueOf(nums[0]);
        if (nums.length == 2) return nums[0] + "/" + nums[1];

        // 拼接 nums[1:] 部分加括号
        StringBuilder rest = new StringBuilder();
        for (int i = 1; i < nums.length; i++) {
            if (i > 1) rest.append("/");
            rest.append(nums[i]);
        }
        return nums[0] + "/(" + rest + ")";
    }
}
```

## 复杂度分析

**方法一、二（贪心）：**
- **时间复杂度**：O(n)，遍历数组一次，字符串拼接 O(n)
- **空间复杂度**：O(n)，存储结果字符串

## 关键点总结

1. **数学本质**：理解连续除法的性质，`a/b/c = a/(b*c)`
2. **贪心策略**：要让结果最大，需要让分母尽可能小
3. **最优解形式**：当 n >= 3 时，最优解一定是 `nums[0]/(nums[1]/.../nums[n-1])`
4. **括号规则**：只在 nums[1:] 外面加一对括号，避免冗余
5. **特殊情况**：n=1 和 n=2 需要单独处理

## 易错点

1. **理解题意**：
   - 要求最大值，不是最小值
   - 需要返回表达式字符串，不是计算结果
2. **括号位置**：
   - 只在 nums[1:] 外面加括号
   - 不要在 nums[0] 外面加括号
3. **边界情况**：
   - n=1：直接返回数字
   - n=2：返回 "a/b"，不需要括号
4. **冗余括号**：
   - `1000/((100/10)/2)` 是冗余的
   - 应该返回 `1000/(100/10/2)`
5. **字符串拼接**：Java 中使用 StringBuilder 提高效率
