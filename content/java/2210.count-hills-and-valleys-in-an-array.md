## 题目描述

统计数组中山峰（两侧都小于该元素）和山谷（两侧都大于该元素）的数量，相邻重复元素视为一组。

## 解题思路

先去除相邻重复元素得到去重数组，然后遍历中间元素判断是否为山峰或山谷。

## Java 代码实现

```java
class Solution {
    public int countHillValley(int[] nums) {
        // 去除相邻重复
        List<Integer> deduped = new ArrayList<>();
        deduped.add(nums[0]);
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) {
                deduped.add(nums[i]);
            }
        }
        
        int ans = 0;
        for (int i = 1; i < deduped.size() - 1; i++) {
            int left = deduped.get(i - 1);
            int mid = deduped.get(i);
            int right = deduped.get(i + 1);
            if ((left < mid && right < mid) || (left > mid && right > mid)) {
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **去除相邻重复**：相同值的连续元素视为一组
2. **山峰判断**：左右都小于中间
3. **山谷判断**：左右都大于中间
4. **首尾不算**：只判断去重后的中间元素
