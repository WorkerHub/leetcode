## 题目描述

给定字符串 `s` 和整数 `k`，统计满足条件的子串数量：子串中每种字母的出现次数都至少为 `k`。

## 解题思路

枚举左端点，向右扩展维护频率哈希表，统计窗口内"未满足（< k 次）的字母种类数"。当所有字母都满足时计数，右扩展后新字母 < k 则停止无意义（正整数频率，一旦满足后右扩不会变差，但可能增加新字母）。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countSubstrings(String s, int k) {
        int n = s.length();
        long result = 0;

        for (int l = 0; l < n; l++) {
            int[] freq = new int[26];
            int unsatisfied = 0; // 频率 > 0 但 < k 的字母种类数

            for (int r = l; r < n; r++) {
                int c = s.charAt(r) - 'a';
                freq[c]++;
                if (freq[c] == 1) unsatisfied++;      // 新字母出现，未满足
                if (freq[c] == k) unsatisfied--;       // 达到 k 次，已满足

                if (unsatisfied == 0) result++;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(26)

## 关键点总结

1. 维护"出现但未满足（< k）的字母种类数"，为 0 时计数
2. 字母首次出现时 `unsatisfied++`，达到 k 次时 `unsatisfied--`
3. 暴力 O(n^2) 对 n <= 10^5 可能较慢，适合 n <= 10^4
