## 题目描述

给你二叉树的根节点 `root` 和一个表示目标和的整数 `targetSum`。判断该树中是否存在根节点到叶子节点的路径，这条路径上所有节点值相加等于目标和 `targetSum`。如果存在，返回 `true`；否则，返回 `false`。

**叶子节点**是指没有子节点的节点。

**示例 1：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
输出：true
解释：等于目标和的根节点到叶子节点路径如图所示。
```

**示例 2：**

```
输入：root = [1,2,3], targetSum = 5
输出：false
解释：树中存在两条根节点到叶子节点的路径：
(1 --> 2): 和为 3
(1 --> 3): 和为 4
不存在 sum = 5 的根节点到叶子节点的路径。
```

**示例 3：**

```
输入：root = [], targetSum = 0
输出：false
解释：由于树为空，所以不存在根节点到叶子节点的路径。
```

**提示：**

- 树中节点的数目在范围 `[0, 5000]` 内
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`

## 解题思路

这道题要找从根节点到叶子节点的路径，使得路径和等于目标值。

### 核心要点

1. **必须是根到叶子的路径**：不能中途停止
2. **叶子节点定义**：左右子节点都为空
3. **路径和的计算**：累加路径上所有节点的值

### 解题方法

**方法一：DFS 递归（减法）**
- 从 targetSum 开始，每经过一个节点就减去该节点的值
- 到达叶子节点时，检查剩余值是否为 0
- 时间复杂度：O(n)

**方法二：DFS 递归（加法）**
- 累加路径上的节点值
- 到达叶子节点时，检查累加值是否等于 targetSum
- 时间复杂度：O(n)

**方法三：BFS（层序遍历）**
- 使用队列存储 (节点, 当前路径和)
- 遇到叶子节点时检查路径和
- 时间复杂度：O(n)

**方法四：DFS 迭代（栈）**
- 使用栈模拟递归过程
- 时间复杂度：O(n)

## Java 代码实现

### 方法一：DFS 递归 - 减法（推荐）⭐

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        // 边界情况：空树没有路径
        if (root == null) return false;

        // 到达叶子节点，检查路径和是否等于目标值
        if (root.left == null && root.right == null) {
            return root.val == targetSum;
        }

        // 递归检查左右子树
        // 目标值减去当前节点的值，传递给子树
        return hasPathSum(root.left, targetSum - root.val) ||
               hasPathSum(root.right, targetSum - root.val);
    }
}
```

### 方法二：DFS 递归 - 加法

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        return dfs(root, 0, targetSum);
    }

    private boolean dfs(TreeNode node, int currentSum, int targetSum) {
        // node 为空，没有路径
        if (node == null) return false;

        // 累加当前节点的值
        currentSum += node.val;

        // 到达叶子节点，检查路径和
        if (node.left == null && node.right == null) {
            return currentSum == targetSum;
        }

        // 递归检查左右子树
        return dfs(node.left, currentSum, targetSum) ||
               dfs(node.right, currentSum, targetSum);
    }
}
```

### 方法三：BFS 层序遍历

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;

        // 两个队列分别存储节点和对应的路径和
        Queue<TreeNode> nodeQueue = new ArrayDeque<>();
        Queue<Integer> sumQueue = new ArrayDeque<>();
        nodeQueue.offer(root);
        sumQueue.offer(root.val);

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            int currentSum = sumQueue.poll();

            // 到达叶子节点，检查路径和
            if (node.left == null && node.right == null) {
                if (currentSum == targetSum) return true;
                continue;
            }

            // 将子节点和更新后的路径和加入队列
            if (node.left != null) {
                nodeQueue.offer(node.left);
                sumQueue.offer(currentSum + node.left.val);
            }
            if (node.right != null) {
                nodeQueue.offer(node.right);
                sumQueue.offer(currentSum + node.right.val);
            }
        }

        return false;
    }
}
```

### 方法四：DFS 迭代（栈）

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;

        // 两个栈分别存储节点和对应的路径和
        Deque<TreeNode> nodeStack = new ArrayDeque<>();
        Deque<Integer> sumStack = new ArrayDeque<>();
        nodeStack.push(root);
        sumStack.push(root.val);

        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            int currentSum = sumStack.pop();

            // 到达叶子节点，检查路径和
            if (node.left == null && node.right == null) {
                if (currentSum == targetSum) return true;
                continue;
            }

            // 将子节点和更新后的路径和压入栈
            if (node.left != null) {
                nodeStack.push(node.left);
                sumStack.push(currentSum + node.left.val);
            }
            if (node.right != null) {
                nodeStack.push(node.right);
                sumStack.push(currentSum + node.right.val);
            }
        }

        return false;
    }
}
```

### 方法五：递归（简化版）

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;

        // 叶子节点
        if (root.left == null && root.right == null) {
            return root.val == targetSum;
        }

        // 检查左子树或右子树
        int newSum = targetSum - root.val;
        return hasPathSum(root.left, newSum) || hasPathSum(root.right, newSum);
    }
}
```

## 复杂度分析

### 所有方法

- **时间复杂度**：O(n)，其中 n 是树中的节点数。最坏情况下需要遍历所有节点。
- **空间复杂度**：
  - DFS 递归：O(h)，h 为树的高度（递归调用栈）
  - BFS：O(w)，w 为树的最大宽度（队列）
  - DFS 迭代：O(h)（栈）

## 关键点总结

1. **叶子节点判断**：`node.left == null && node.right == null`，这是关键条件
2. **路径定义**：必须从根到叶子，不能中途停止
3. **递归思路**：
   - 减法：每次将目标值减去当前节点值
   - 加法：累加路径和，到叶子节点时比较
4. **边界条件**：
   - 空树返回 false
   - 叶子节点时检查路径和
5. **短路优化**：使用 `||` 连接，找到一条路径即可返回

## 易错点

1. **忘记判断叶子节点**：
   ```java
   // 错误：在任意节点处返回
   if (root.val == targetSum) return true;

   // 正确：必须在叶子节点处判断
   if (root.left == null && root.right == null) {
       return root.val == targetSum;
   }
   ```

2. **空节点处理**：
   ```java
   // 错误：空节点返回 true（当 targetSum == 0 时）
   if (root == null) return targetSum == 0;

   // 正确：空节点返回 false（没有路径）
   if (root == null) return false;
   ```

3. **路径和计算**：
   ```java
   // 错误：忘记加当前节点的值
   return dfs(node.left, currentSum);

   // 正确：加上当前节点的值
   return dfs(node.left, currentSum + node.val, targetSum);
   ```

4. **目标值为 0 的情况**：即使 targetSum 为 0，也要走到叶子节点

5. **负数节点值**：节点值可能为负数，不能提前剪枝
