## 题目描述

给定整数数组 `nums` 和正整数 `k`，返回所有长度至多为 `k` 的非空子序列的最大值与最小值之和的总和，对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final long MOD = 1_000_000_007;

    public long minMaxSums(int[] nums, int k) {
        int n = nums.length;
        Arrays.sort(nums);

        // 预计算阶乘和逆阶乘
        long[] fact = new long[n + 1];
        long[] invFact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = modPow(fact[n], MOD - 2, MOD);
        for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

        // 预计算 sumC[i] = sum_{j=0}^{k-1} C(i, j)
        long[] sumC = new long[n + 1];
        for (int i = 0; i <= n; i++) {
            long s = 0;
            for (int j = 0; j < k && j <= i; j++) {
                s = (s + comb(i, j, fact, invFact)) % MOD;
            }
            sumC[i] = s;
        }

        long total = 0;
        for (int i = 0; i < n; i++) {
            long v = nums[i] % MOD;
            // a[i] 作为最小值：其余元素从右边 n-1-i 个中选 0..k-1 个
            total = (total + v * sumC[n - 1 - i]) % MOD;
            // a[i] 作为最大值：其余元素从左边 i 个中选 0..k-1 个
            total = (total + v * sumC[i]) % MOD;
        }

        return total;
    }

    private long comb(int n, int r, long[] fact, long[] invFact) {
        if (r < 0 || r > n) return 0;
        return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k + n log n)，排序与前缀组合数预计算
- 空间复杂度：O(n)

## 关键点总结

1. 排序后子序列的最小值是最左元素，最大值是最右元素
2. `a[i]` 作为最小值的方案数 = `sum_{j=0}^{k-1} C(n-1-i, j)`（从右侧选其余元素）
3. `a[i]` 作为最大值的方案数 = `sum_{j=0}^{k-1} C(i, j)`（从左侧选其余元素）
