## 题目描述

返回 [low, high] 之间奇数的个数。

**示例：**
```
输入：low = 3, high = 7
输出：3
```

## 解题思路

数学公式：[1,n] 中奇数个数 = (n+1)/2。答案 = count(high) - count(low-1)。

## Java 代码实现

```java
class Solution {
    public int countOdds(int low, int high) {
        return (high + 1) / 2 - low / 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **公式法**：(high+1)/2 - low/2
2. **等价理解**：区间长度/2，若端点为奇则多 1
