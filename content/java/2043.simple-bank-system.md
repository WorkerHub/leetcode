## 题目描述

设计简单银行系统，支持 transfer（转账）、deposit（存款）、withdraw（取款）操作，账户编号从 1 开始，余额可达 10^12。

## 解题思路

维护 long[] 余额数组，每次操作先验证账户合法性（1 <= account <= n）和余额充足性，再更新。

## Java 代码实现

### 方法一：直接模拟（推荐）

```java
class Bank {
    private long[] balance;
    private int n;

    public Bank(long[] balance) {
        this.n = balance.length;
        this.balance = balance;
    }

    public boolean transfer(int account1, int account2, long money) {
        if (account1 > n || account2 > n) return false;
        if (balance[account1 - 1] < money) return false;
        balance[account1 - 1] -= money;
        balance[account2 - 1] += money;
        return true;
    }

    public boolean deposit(int account, long money) {
        if (account > n) return false;
        balance[account - 1] += money;
        return true;
    }

    public boolean withdraw(int account, long money) {
        if (account > n) return false;
        if (balance[account - 1] < money) return false;
        balance[account - 1] -= money;
        return true;
    }
}
```

## 复杂度分析

- 每次操作时间复杂度：O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 账户编号从 1 开始，数组索引为 account-1
2. 余额最大 10^12 需使用 long 类型
3. 每次操作验证账户范围和余额充足
