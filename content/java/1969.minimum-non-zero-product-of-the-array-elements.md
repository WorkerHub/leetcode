## 题目描述

给你正整数 `p`，数组包含 1 到 `2^p-1` 的所有整数，可交换任意两数的任意对应位，返回数组所有元素乘积的最小非零值 mod 10^9+7。

## 解题思路

最优策略：保留最大值 `2^p-1`，将每对互补数 `(i, 2^p-1-i)` 通过位交换变为 `(1, 2^p-2)`，共 `2^(p-1)-1` 对。答案为 `(2^p-1) * (2^p-2)^(2^(p-1)-1) mod MOD`。

## Java 代码实现

```java
class Solution {
    static final long MOD = 1_000_000_007;

    public int minNonZeroProduct(int p) {
        long maxVal = (1L << p) - 1; // 2^p - 1
        long second = maxVal - 1;    // 2^p - 2
        long pairs = (1L << (p - 1)) - 1; // 2^(p-1) - 1
        return (int) (maxVal % MOD * pow(second, pairs) % MOD);
    }

    private long pow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log p)
- **空间复杂度**：O(1)

## 关键点总结

1. 互补数对 `(i, 2^p-1-i)` 通过位交换变为 `(1, 2^p-2)`，乘积从 `i*(2^p-1-i)` 最小化为 `2^p-2`
2. 共 `2^(p-1)-1` 对，保留 `2^p-1` 本身
3. 使用快速幂计算大指数
