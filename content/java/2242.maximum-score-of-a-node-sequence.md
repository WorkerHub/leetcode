## 题目描述

无向图中找4个互不相同节点a-b-c-d形成路径（相邻有边），使scores之和最大。

## 解题思路

每个节点只保留top-3分数邻居。枚举中间边(b,c)，从b的top-3选a(!=c)，从c的top-3选d(!=b且!=a)，取最大组合。

## Java 代码实现

```java
class Solution {
    public int maximumScore(int[] scores, int[][] edges) {
        int n = scores.length;
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }
        
        // 每个节点只保留分数top-3的邻居
        for (int i = 0; i < n; i++) {
            adj.get(i).sort((a, b) -> scores[b] - scores[a]);
            if (adj.get(i).size() > 3) {
                adj.set(i, new ArrayList<>(adj.get(i).subList(0, 3)));
            }
        }
        
        int ans = -1;
        for (int[] e : edges) {
            int b = e[0], c = e[1];
            for (int a : adj.get(b)) {
                if (a == c) continue;
                for (int d : adj.get(c)) {
                    if (d == b || d == a) continue;
                    ans = Math.max(ans, scores[a] + scores[b] + scores[c] + scores[d]);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M log N + M * 9)，排序邻居+枚举边
- **空间复杂度**：O(N + M)

## 关键点总结

1. **只保留top-3邻居**：4节点互不同最多需要3个候选
2. **枚举中间边**：从两端各选最大合法邻居
3. **top-3而非top-2**：需要跳过c/b/a的情况
