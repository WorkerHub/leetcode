## 题目描述

给你两个 `n x n` 的二进制矩阵 `mat` 和 `target`，判断能否通过将 `mat` 顺时针旋转 0、90、180 或 270 度后等于 `target`。

## 解题思路

枚举四种旋转（0、90、180、270 度），逐一与 target 比较。顺时针旋转 90 度变换：`new[i][j] = old[n-1-j][i]`。

## Java 代码实现

```java
class Solution {
    public boolean findRotation(int[][] mat, int[][] target) {
        int n = mat.length;
        for (int k = 0; k < 4; k++) {
            if (equals(mat, target, n)) return true;
            mat = rotate90(mat, n); // 顺时针旋转90度
        }
        return false;
    }

    // 顺时针旋转 90 度
    private int[][] rotate90(int[][] mat, int n) {
        int[][] res = new int[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                res[i][j] = mat[n - 1 - j][i];
        return res;
    }

    private boolean equals(int[][] a, int[][] b, int n) {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (a[i][j] != b[i][j]) return false;
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，旋转和比较各 O(n^2)，共 4 次
- **空间复杂度**：O(n^2)，存储旋转后的矩阵

## 关键点总结

1. 只需检查 4 种旋转（0、90、180、270 度）
2. 顺时针旋转 90 度：`new[i][j] = old[n-1-j][i]`
3. 连续旋转 4 次会回到原始状态
