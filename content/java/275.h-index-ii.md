## 题目描述

给你一个整数数组 citations，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数，citations 已经按照升序排列。计算并返回该研究者的 h 指数。

h 指数的定义：h 代表"高引用次数"，一名科研人员的 h 指数是指他（她）的（n 篇论文中）总共有 h 篇论文分别被引用了至少 h 次。且其余的 n - h 篇论文每篇被引用次数不超过 h 次。

如果 h 有多种可能的值，h 指数是其中最大的那个。

请你设计并实现对数时间复杂度的算法解决此问题。

**示例 1：**
```
输入: citations = [0,1,3,5,6]
输出: 3
解释: 给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 0, 1, 3, 5, 6 次。
     由于研究者有 3 篇论文每篇至少被引用了 3 次，其余 2 篇论文每篇被引用不多于 3 次，
     所以她的 h 指数是 3。
```

**示例 2：**
```
输入: citations = [1,2,100]
输出: 2
```

**提示：**
- n == citations.length
- 1 <= n <= 10^5
- 0 <= citations[i] <= 1000
- citations 按升序排列

**进阶：** 你能否设计一个时间复杂度为 O(log n) 的解决方案？

## 解题思路

这道题是 [274. H 指数](https://leetcode.com/problems/h-index/) 的进阶版本，区别在于：
1. 输入数组已经升序排列
2. 要求 O(log n) 的时间复杂度

### 关键观察

对于升序排列的数组 citations：
- 如果 citations[i] >= n - i，说明从位置 i 到末尾共有 n - i 篇论文，这些论文的引用次数都 >= citations[i]
- h 指数就是这些满足条件的论文数量的最大值

**示例分析：** citations = [0,1,3,5,6]

```
索引 i | 引用数 | 剩余论文数 (n-i) | citations[i] >= n-i？| 可能的 h 值
------|--------|-----------------|---------------------|-------------
  0   |   0    |       5         |    0 >= 5 ✗        |     -
  1   |   1    |       4         |    1 >= 4 ✗        |     -
  2   |   3    |       3         |    3 >= 3 ✓        |     3
  3   |   5    |       2         |    5 >= 2 ✓        |     2
  4   |   6    |       1         |    6 >= 1 ✓        |     1

最大的 h = 3（从索引 2 开始的论文）
```

### 二分查找思路

我们要找到最小的索引 i，使得 citations[i] >= n - i：
- 这个索引 i 右侧（包括 i）的所有论文引用次数都 >= n - i
- h 指数就是 n - i

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int left = 0, right = n - 1;

        // 二分查找最小的索引 i，使得 citations[i] >= n - i
        while (left <= right) {
            int mid = left + (right - left) / 2;

            // mid 位置及其右侧有 n - mid 篇论文
            if (citations[mid] >= n - mid) {
                // citations[mid] 足够大，可能还有更小的索引满足条件
                right = mid - 1;
            } else {
                // citations[mid] 太小，需要往右找
                left = mid + 1;
            }
        }

        // left 是第一个满足 citations[i] >= n - i 的位置
        // h 指数是从 left 到末尾的论文数量
        return n - left;
    }
}
```

### 方法二：二分查找（另一种写法）

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int left = 0, right = n;

        // 二分直接搜索 h 值
        while (left < right) {
            int mid = (left + right + 1) / 2; // 向上取整

            // 计算引用次数 >= mid 的论文数量
            // 由于数组升序，从后往前数 mid 篇
            if (citations[n - mid] >= mid) {
                // 至少有 mid 篇论文引用次数 >= mid
                left = mid;
            } else {
                // 不满足，h 指数更小
                right = mid - 1;
            }
        }

        return left;
    }
}
```

### 方法三：线性扫描（不满足时间要求，但易理解）

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;

        // 从前往后找第一个满足条件的位置
        for (int i = 0; i < n; i++) {
            // 从位置 i 到末尾有 n - i 篇论文
            if (citations[i] >= n - i) {
                return n - i;
            }
        }

        return 0;
    }
}
```

### 方法四：优化的二分查找（最清晰）

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int left = 0, right = n;

        while (left < right) {
            int mid = (left + right) / 2;

            // 从后往前数 mid+1 篇论文，看最小引用次数是否 >= mid+1
            if (citations[n - mid - 1] >= mid + 1) {
                // 至少有 mid+1 篇论文引用次数 >= mid+1
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return left;
    }
}
```

## 复杂度分析

### 方法一、二、四：二分查找

**时间复杂度：** O(log n)

**空间复杂度：** O(1)
- 只使用常数额外空间

### 方法三：线性扫描

**时间复杂度：** O(n)

**空间复杂度：** O(1)

## 图解示例

**示例：** citations = [0,1,3,5,6]

二分查找过程：

```
初始: left = 0, right = 4, n = 5

第一轮: mid = 2
  citations[2] = 3, n - mid = 3
  3 >= 3 ✓ → right = mid - 1 = 1

第二轮: left = 0, right = 1, mid = 0
  citations[0] = 0, n - mid = 5
  0 >= 5 ✗ → left = mid + 1 = 1

第三轮: left = 1, right = 1, mid = 1
  citations[1] = 1, n - mid = 4
  1 >= 4 ✗ → left = mid + 1 = 2

退出循环: left = 2, right = 1
h = n - left = 5 - 2 = 3
```

## 关键点总结

1. **利用有序性**：数组已升序排列，可以使用二分查找
2. **转换问题**：找最小的 i 使得 citations[i] >= n - i
3. **h 指数计算**：h = n - i，即从 i 到末尾的论文数量
4. **二分边界**：
   - citations[mid] >= n - mid：往左找（right = mid - 1）
   - citations[mid] < n - mid：往右找（left = mid + 1）
5. **时间优化**：从 O(n) 降到 O(log n)

## 易错点

1. **二分条件判断**：注意是 citations[mid] >= n - mid
   ```java
   // 错误：比较对象搞混
   if (citations[mid] >= mid)  // 错误
   
   // 正确：比较剩余论文数
   if (citations[mid] >= n - mid)  // 正确
   ```

2. **返回值计算**：h = n - left，不是 left
   ```java
   // 错误
   return left;
   
   // 正确
   return n - left;
   ```

3. **边界情况**：所有论文引用次数都很小
   ```java
   // citations = [0, 0, 0]，h = 0
   ```

4. **防止整数溢出**：计算 mid 时使用 `left + (right - left) / 2`
   ```java
   int mid = left + (right - left) / 2;
   ```

5. **升序 vs 降序**：这道题是升序，274 题需要降序
   ```java
   // 275 题：已经升序，直接使用
   // 274 题：需要先降序排序
   ```
