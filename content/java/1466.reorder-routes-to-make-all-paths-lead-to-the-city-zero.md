## 题目描述

`n` 座城市，从 `0` 到 `n-1` 编号，其间共有 `n-1` 条路线。因此，要想在两座不同城市之间旅行，唯一的方式就是沿着某条路线行驶。目前，沿不同路线行驶的方向可能不同。

所有路线构成一棵树（无环连通图），根节点为城市 0。

给你一个数组 `connections`，其中 `connections[i] = [ai, bi]` 表示从城市 `ai` 到城市 `bi` 的路线。

你的工作是重新定向一些路线，使得每个城市都可以访问城市 0。返回需要变更方向的最小路线数。

**保证**每个城市在重新定向变更后都能到达城市 0。

**示例 1：**
```
输入：n = 6, connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]
输出：3
```

**示例 2：**
```
输入：n = 5, connections = [[1,0],[1,2],[3,1],[3,4]]
输出：2
```

**提示：**
- `2 <= n <= 5 * 10^4`
- `connections.length == n - 1`
- `connections[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `ai != bi`

## 解题思路

**核心思路：以城市 0 为根，BFS/DFS 遍历树**

将图看成以城市 0 为根的树：
- 从城市 0 向外 BFS/DFS
- 遇到一条原始方向为"从 0 出发"（即远离根）的边，需要反转（代价 +1）
- 遇到一条原始方向为"指向 0"（即朝向根）的边，不需要反转（代价 0）

**实现技巧：**

构建无向图时，区分正向边和反向边：
- 对于 `connections[i] = [a, b]`（原始方向 a -> b）：
  - 在图中添加 `a -> b`，权重为 1（需要反转）
  - 在图中添加 `b -> a`，权重为 0（不需要反转）

从城市 0 开始 BFS，沿着无向图遍历，累计所有需要反转的边的权重。

## Java 代码实现

### 方法一：BFS（推荐）

```java
import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.List;

class Solution {
    public int minReorder(int n, int[][] connections) {
        // 构建带权无向邻接表
        // 权重 1 表示原始方向（需要反转），权重 0 表示反向（无需反转）
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();

        for (int[] conn : connections) {
            int a = conn[0], b = conn[1];
            graph[a].add(new int[]{b, 1});  // 原始方向 a -> b（从根出发，需反转）
            graph[b].add(new int[]{a, 0});  // 反向 b -> a（朝向根，不需反转）
        }

        // BFS 从城市 0 开始
        boolean[] visited = new boolean[n];
        visited[0] = true;
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        int changes = 0;

        while (!queue.isEmpty()) {
            int city = queue.poll();
            for (int[] edge : graph[city]) {
                int neighbor = edge[0], cost = edge[1];
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    changes += cost;  // 若是原始方向（远离根），需要反转
                    queue.offer(neighbor);
                }
            }
        }

        return changes;
    }
}
```

### 方法二：DFS（递归）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private int changes = 0;

    public int minReorder(int n, int[][] connections) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();

        for (int[] conn : connections) {
            int a = conn[0], b = conn[1];
            graph[a].add(new int[]{b, 1});  // 原始方向
            graph[b].add(new int[]{a, 0});  // 反向
        }

        boolean[] visited = new boolean[n];
        visited[0] = true;
        dfs(graph, visited, 0);
        return changes;
    }

    private void dfs(List<int[]>[] graph, boolean[] visited, int city) {
        for (int[] edge : graph[city]) {
            int neighbor = edge[0], cost = edge[1];
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                changes += cost;
                dfs(graph, visited, neighbor);
            }
        }
    }
}
```

### 方法三：DFS（返回值，不用实例变量）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int minReorder(int n, int[][] connections) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] conn : connections) {
            graph[conn[0]].add(new int[]{conn[1], 1});
            graph[conn[1]].add(new int[]{conn[0], 0});
        }

        return dfs(graph, 0, -1);
    }

    private int dfs(List<int[]>[] graph, int city, int parent) {
        int total = 0;
        for (int[] edge : graph[city]) {
            int neighbor = edge[0], cost = edge[1];
            if (neighbor != parent) {  // 避免回到父节点
                total += cost + dfs(graph, neighbor, city);
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，BFS/DFS 遍历 n 个节点，每条边被处理两次
- 空间复杂度：O(n)，邻接表和访问集合

## 关键点总结

1. 以城市 0 为根 BFS/DFS，判断每条边是否需要反转
2. 构建无向图时给边标注"是否是原始方向"（权重 1/0）
3. 原始方向为"远离根"的边（a -> b，其中 a 是父节点）需要反转

## 易错点

- 无向图遍历需要标记已访问节点，避免重复访问
- 区分"原始方向"和"反向"：`connections[i] = [a, b]` 表示 a -> b，a 是 b 的父节点（从 0 出发）时才是"远离根"的边
