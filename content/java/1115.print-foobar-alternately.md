## 题目描述

两个线程分别调用 foo() 和 bar()，确保交替输出 "foobar" 共 n 次。

**示例：**
```
输入：n = 2
输出："foobarfoobar"
```

## 解题思路

信号量交替：foo_sem 初始为 1 允许先执行，bar_sem 初始为 0。foo 执行后释放 bar_sem，bar 执行后释放 foo_sem。

## Java 代码实现

```java
class FooBar {
    private int n;
    private Semaphore fooSem = new Semaphore(1);
    private Semaphore barSem = new Semaphore(0);

    public FooBar(int n) {
        this.n = n;
    }

    public void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            fooSem.acquire();  // 等待允许执行 foo
            printFoo.run();
            barSem.release();  // 通知 bar 可以执行
        }
    }

    public void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            barSem.acquire();  // 等待允许执行 bar
            printBar.run();
            fooSem.release();  // 通知 foo 可以执行
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **Semaphore 交替**：两个信号量互相触发，形成乒乓效果
2. **初始值**：fooSem=1 保证 foo 先执行，barSem=0 让 bar 等待
3. **循环内同步**：每次迭代都完成一次 acquire-release 对
