## 题目描述

设计数据结构 MagicDictionary，支持 buildDict 和 search。search 判断能否将字符串中恰好一个字母换成另一个字母后匹配字典中的某个单词。

**示例：**
```
buildDict(["hello", "leetcode"])
search("hhllo") → true（换 h 为 e 匹配 hello）
search("hello") → false（不能不换）
```

## 解题思路

按长度分组，只检查相同长度的单词，统计不同字符数是否恰好为 1。

## Java 代码实现

```java
class MagicDictionary {
    private Map<Integer, List<String>> wordsByLen;

    public MagicDictionary() {
        wordsByLen = new HashMap<>();
    }

    public void buildDict(String[] dictionary) {
        for (String word : dictionary) {
            wordsByLen.computeIfAbsent(word.length(), k -> new ArrayList<>()).add(word);
        }
    }

    public boolean search(String searchWord) {
        int len = searchWord.length();
        List<String> words = wordsByLen.getOrDefault(len, Collections.emptyList());

        for (String word : words) {
            int diff = 0;
            for (int i = 0; i < len; i++) {
                if (searchWord.charAt(i) != word.charAt(i)) {
                    diff++;
                    if (diff > 1) break;
                }
            }
            if (diff == 1) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **buildDict**：O(n)
- **search**：O(m × L)，m 为相同长度单词数，L 为单词长度
- **空间复杂度**：O(n × L)

## 关键点总结

1. **恰好一次**：必须修改一个字符，不能不修改
2. **按长度分组**：不同长度不可能匹配
3. **提前终止**：差异超过1立即跳过
