## 题目描述

给你水果的价格数组 `price`、美味值数组 `tastiness`，以及预算 `maxAmount` 和优惠券数 `maxCoupons`（可将某水果价格减半），每种水果最多买一次，返回在预算内可获得的最大总美味值。

## 解题思路

二维 0/1 背包：`dp[j][k]` 表示花费 j 元、使用 k 张优惠券的最大美味值。每个水果三种选择：不买、原价买、半价买（用一张券）。逆序遍历两个维度防止重复选取。

## Java 代码实现

```java
class Solution {
    public int maxTastiness(int[] price, int[] tastiness, int maxAmount, int maxCoupons) {
        int n = price.length;
        // dp[j][k] = 花费 j 元使用 k 张券的最大美味值
        int[][] dp = new int[maxAmount + 1][maxCoupons + 1];

        for (int i = 0; i < n; i++) {
            int p = price[i], t = tastiness[i];
            int half = p / 2;
            // 逆序遍历（0/1 背包），防止同一水果重复选
            for (int j = maxAmount; j >= 0; j--) {
                for (int k = maxCoupons; k >= 0; k--) {
                    // 原价买
                    if (j >= p) {
                        dp[j][k] = Math.max(dp[j][k], dp[j - p][k] + t);
                    }
                    // 半价买（使用一张优惠券）
                    if (k >= 1 && j >= half) {
                        dp[j][k] = Math.max(dp[j][k], dp[j - half][k - 1] + t);
                    }
                }
            }
        }
        return dp[maxAmount][maxCoupons];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × maxAmount × maxCoupons)
- **空间复杂度**：O(maxAmount × maxCoupons)

## 关键点总结

1. 每个水果三种选择：不买、原价、半价（用券），是带两个约束的 0/1 背包
2. 两个维度均需逆序遍历，保证 0/1 背包的正确性
3. 价格减半用整数除法 `p / 2`
