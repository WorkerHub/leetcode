## 题目描述

给定一个字符串 `s`，你可以通过在字符串前面添加字符将其转换为回文串。找到并返回可以用这种方式转换的最短回文串。

**示例 1：**

```
输入：s = "aacecaaa"
输出："aaacecaaa"
```

**示例 2：**

```
输入：s = "abcd"
输出："dcbabcd"
```

**提示：**

- `0 <= s.length <= 5 * 10^4`
- `s` 仅由小写英文字母组成

## 解题思路

这道题的核心是找到从字符串开头开始的最长回文子串，然后将剩余部分反转后添加到前面。

**核心思想：**

1. **找最长回文前缀**：找到从 `s[0]` 开始的最长回文子串
2. **构造结果**：将不在回文前缀中的后缀反转，添加到 `s` 前面

**示例分析：**

```
s = "aacecaaa"
最长回文前缀 = "aacecaa"（长度 7）
剩余后缀 = "a"
结果 = "a" 的反转 + s = "a" + "aacecaaa" = "aaacecaaa"
```

**关键问题：** 如何高效找到最长回文前缀？

**多种方法：**
1. **暴力法**：逐个检查每个前缀是否为回文（O(N²)）
2. **KMP 算法**：利用 `s + "#" + reverse(s)` 的最长公共前后缀
3. **双指针**：线性扫描找最长回文前缀
4. **滚动哈希**：使用哈希快速判断回文

## Java 代码实现

### 方法一：KMP 算法（推荐）⭐

```java
class Solution {
    public String shortestPalindrome(String s) {
        if (s.isEmpty()) return s;

        // 构造新字符串：s + "#" + reverse(s)
        // "#" 防止原串和反串匹配
        String reversed = new StringBuilder(s).reverse().toString();
        String newStr = s + "#" + reversed;

        // 计算 KMP 的 next 数组（最长公共前后缀）
        int n = newStr.length();
        int[] next = new int[n];
        int j = 0;

        for (int i = 1; i < n; i++) {
            // 回退到可以匹配的位置
            while (j > 0 && newStr.charAt(i) != newStr.charAt(j)) {
                j = next[j - 1];
            }

            // 当前字符匹配
            if (newStr.charAt(i) == newStr.charAt(j)) {
                j++;
            }

            next[i] = j;
        }

        // next[n-1] 就是最长回文前缀的长度
        int palindromeLen = next[n - 1];

        // 将不在回文前缀中的后缀反转后加到前面
        String suffix = s.substring(palindromeLen);
        return new StringBuilder(suffix).reverse().toString() + s;
    }
}
```

### 方法二：双指针（易理解）

```java
class Solution {
    public String shortestPalindrome(String s) {
        if (s.isEmpty()) return s;

        int n = s.length();
        int end = n - 1;

        // 找到最长回文前缀：逐渐缩小右边界
        while (end >= 0 && !isPalindrome(s, 0, end)) {
            end--;
        }

        // 将后缀反转后加到前面
        String suffix = s.substring(end + 1);
        return new StringBuilder(suffix).reverse().toString() + s;
    }

    private boolean isPalindrome(String s, int left, int right) {
        // 判断 s[left..right] 是否为回文
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 方法三：滚动哈希（高效）

```java
class Solution {
    public String shortestPalindrome(String s) {
        if (s.isEmpty()) return s;

        int n = s.length();
        long base = 31;
        long mod = 1_000_000_007L;

        // 正向哈希和反向哈希
        long forwardHash = 0;
        long reverseHash = 0;
        long power = 1;
        int palindromeEnd = 0;

        for (int i = 0; i < n; i++) {
            long val = s.charAt(i) - 'a' + 1;
            // 正向哈希：从左到右
            forwardHash = (forwardHash * base + val) % mod;
            // 反向哈希：从右到左
            reverseHash = (reverseHash + val * power) % mod;
            power = (power * base) % mod;

            // 如果正向和反向哈希相等，说明 s[0..i] 是回文
            if (forwardHash == reverseHash) {
                palindromeEnd = i;
            }
        }

        // 构造结果
        String suffix = s.substring(palindromeEnd + 1);
        return new StringBuilder(suffix).reverse().toString() + s;
    }
}
```

### 方法四：暴力法（供对比学习）

```java
class Solution {
    public String shortestPalindrome(String s) {
        int n = s.length();

        // 从最长可能的回文前缀开始检查
        for (int i = n; i >= 0; i--) {
            String prefix = s.substring(0, i);
            // 检查是否为回文
            if (prefix.equals(new StringBuilder(prefix).reverse().toString())) {
                String suffix = s.substring(i);
                return new StringBuilder(suffix).reverse().toString() + s;
            }
        }

        return s;
    }
}
```

## 复杂度分析

**方法一（KMP）：**

- **时间复杂度：** O(N)，构造字符串 O(N) + KMP O(N)
- **空间复杂度：** O(N)，需要存储新字符串和 next 数组

**方法二（双指针）：**

- **时间复杂度：** O(N²)，最坏情况检查 N 次，每次 O(N)
- **空间复杂度：** O(N)，字符串操作

**方法三（滚动哈希）：**

- **时间复杂度：** O(N)
- **空间复杂度：** O(N)，字符串拼接
- **注意：** 存在哈希冲突的极小概率

**方法四（暴力）：**

- **时间复杂度：** O(N²)
- **空间复杂度：** O(N)，字符串切片和反转

## 关键点总结

1. **问题转化**：最短回文串 → 找最长回文前缀
2. **KMP 应用**：`s + "#" + reverse(s)` 的最长公共前后缀 = 最长回文前缀
3. **滚动哈希**：高效判断回文，正向和反向哈希值相等
4. **Java 字符串操作**：熟练使用 `substring`、`StringBuilder.reverse()`、字符串拼接
5. **边界情况**：空字符串、全回文、无回文前缀

## 易错点

1. **KMP 构造字符串时忘记分隔符**：
   ```java
   // 错误：没有 "#" 分隔
   String newStr = s + reversed;  // 可能导致错误匹配
   // 正确：使用分隔符
   String newStr = s + "#" + reversed;
   ```

2. **回文前缀长度计算错误**：
   ```java
   // 正确：直接使用 next[n-1]
   int palindromeLen = next[n - 1];
   ```

3. **滚动哈希溢出**：
   ```java
   // 错误：不取模可能溢出
   forwardHash = forwardHash * base + val;
   // 正确：每步都取模（使用 long 类型）
   forwardHash = (forwardHash * base + val) % mod;
   ```

4. **Java 字符串拼接顺序错误**：
   ```java
   // 错误：反转加在后面
   return s + new StringBuilder(suffix).reverse().toString();
   // 正确：反转加在前面
   return new StringBuilder(suffix).reverse().toString() + s;
   ```

5. **字符串比较使用 ==**：
   ```java
   // 错误：== 比较引用
   if (prefix == reversed)
   // 正确：使用 equals 比较内容
   if (prefix.equals(reversed))
   ```
