## 题目描述

给你一个链表的头节点 `head`，旋转链表，将链表每个节点向右移动 `k` 个位置。

**示例 1：**
```
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

**示例 2：**
```
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

**提示：**
- 链表中节点的数目在范围 `[0, 500]` 内
- `-100 <= Node.val <= 100`
- `0 <= k <= 2 * 10^9`

## 解题思路

核心思想：
1. 计算链表长度
2. k = k % length（处理k大于长度的情况）
3. 找到倒数第k+1个节点，断开并重新连接

## Java 代码实现

```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) {
            return head;
        }

        // 计算长度并找到尾节点
        int length = 1;
        ListNode tail = head;
        while (tail.next != null) {
            tail = tail.next;
            length++;
        }

        // k取模
        k = k % length;
        if (k == 0) {
            return head;
        }

        // 找到新的尾节点（倒数第k+1个节点）
        ListNode newTail = head;
        for (int i = 0; i < length - k - 1; i++) {
            newTail = newTail.next;
        }

        // 重新连接
        ListNode newHead = newTail.next;
        newTail.next = null;
        tail.next = head;

        return newHead;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **取模**：k % length
2. **找断点**：倒数第k+1个节点
3. **成环再断开**：尾连头，再断开

## 易错点

1. **k大于length**：需要取模
2. **k为0**：直接返回
