## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。你可以按任意顺序返回答案。

**示例 1：**
```
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

**示例 2：**
```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的

**进阶：** 你所设计算法的时间复杂度必须优于 O(n log n)，其中 n 是数组大小。

## 解题思路

这道题是经典的 TopK 问题，有多种解法。

**核心步骤：**
1. 统计每个元素的出现频率
2. 找出频率最高的 k 个元素

**多种解法：**
- 排序：统计频率后排序，取前 k 个，O(n log n)
- 堆：使用最小堆维护 k 个最高频元素，O(n log k)
- 桶排序：按频率分桶，从高到低取元素，O(n)
- 快速选择：类似快速排序的分区思想，平均 O(n)

**最优解：** 桶排序，时间复杂度 O(n)，满足进阶要求。

## Java 代码实现

### 方法一：哈希表 + 排序（最直观）

```java
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计频率
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        // 2. 按频率排序（降序）
        List<Integer> unique = new ArrayList<>(count.keySet());
        unique.sort((a, b) -> count.get(b) - count.get(a));

        // 3. 取前 k 个元素
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = unique.get(i);
        }
        return result;
    }
}
```

**时间复杂度：** O(n log n)
**空间复杂度：** O(n)

### 方法二：最小堆（推荐）⭐

```java
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计频率
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        // 2. 使用最小堆维护 k 个最高频元素
        // 堆按频率升序排列（最小堆）
        PriorityQueue<Integer> heap = new PriorityQueue<>(
            (a, b) -> count.get(a) - count.get(b)
        );

        for (int num : count.keySet()) {
            heap.offer(num);

            // 保持堆的大小为 k
            if (heap.size() > k) {
                heap.poll();  // 弹出频率最小的
            }
        }

        // 3. 将堆中的元素放入结果数组
        int[] result = new int[k];
        for (int i = k - 1; i >= 0; i--) {
            result[i] = heap.poll();
        }
        return result;
    }
}
```

**时间复杂度：** O(n log k)
**空间复杂度：** O(n)

### 方法三：桶排序（最优解）⭐⭐

```java
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 1. 统计频率
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        // 2. 创建桶，索引表示频率
        // 频率最大为 n（所有元素相同）
        int n = nums.length;
        List<Integer>[] buckets = new List[n + 1];
        for (int i = 0; i <= n; i++) {
            buckets[i] = new ArrayList<>();
        }

        // 3. 将元素放入对应频率的桶中
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            buckets[entry.getValue()].add(entry.getKey());
        }

        // 4. 从高频到低频收集元素
        int[] result = new int[k];
        int idx = 0;
        for (int freq = n; freq >= 1 && idx < k; freq--) {
            for (int num : buckets[freq]) {
                result[idx++] = num;
                if (idx == k) break;
            }
        }

        return result;
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

### 方法四：快速选择（平均最优）

```java
import java.util.*;

class Solution {
    private Map<Integer, Integer> count;

    public int[] topKFrequent(int[] nums, int k) {
        count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }

        int[] unique = count.keySet().stream().mapToInt(Integer::intValue).toArray();
        int n = unique.length;

        // 找第 n-k 小的元素，这样右边就是最大的 k 个
        quickSelect(unique, 0, n - 1, n - k);

        return Arrays.copyOfRange(unique, n - k, n);
    }

    private void quickSelect(int[] arr, int left, int right, int kSmallest) {
        if (left == right) return;

        // 随机选择 pivot
        Random rand = new Random();
        int pivotIndex = left + rand.nextInt(right - left + 1);

        pivotIndex = partition(arr, left, right, pivotIndex);

        if (kSmallest == pivotIndex) {
            return;
        } else if (kSmallest < pivotIndex) {
            quickSelect(arr, left, pivotIndex - 1, kSmallest);
        } else {
            quickSelect(arr, pivotIndex + 1, right, kSmallest);
        }
    }

    private int partition(int[] arr, int left, int right, int pivotIndex) {
        int pivotFreq = count.get(arr[pivotIndex]);
        // 将 pivot 移到末尾
        swap(arr, pivotIndex, right);

        // 将所有频率小于 pivot 的元素移到左边
        int storeIndex = left;
        for (int i = left; i < right; i++) {
            if (count.get(arr[i]) < pivotFreq) {
                swap(arr, storeIndex, i);
                storeIndex++;
            }
        }

        // 将 pivot 移到最终位置
        swap(arr, storeIndex, right);
        return storeIndex;
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

**时间复杂度：** 平均 O(n)，最坏 O(n^2)
**空间复杂度：** O(n)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 排序 | O(n log n) | O(n) | 简单直观 | 不满足进阶要求 |
| 最小堆 | O(n log k) | O(n) | 适合 k 很小 | k 大时慢 |
| 桶排序 | O(n) | O(n) | 最优解 | 需要额外空间 |
| 快速选择 | 平均 O(n) | O(n) | 平均最快 | 最坏 O(n^2) |

## 图解示例

```
输入：nums = [1,1,1,2,2,3], k = 2

步骤1：统计频率
count = {1: 3, 2: 2, 3: 1}

方法：桶排序
创建桶（索引为频率）：
buckets[0] = []
buckets[1] = [3]     ← 频率为 1 的元素
buckets[2] = [2]     ← 频率为 2 的元素
buckets[3] = [1]     ← 频率为 3 的元素
buckets[4] = []
...

从高频到低频遍历：
freq=3: [1]      → result = [1]
freq=2: [2]      → result = [1, 2]
len == k，停止

返回 [1, 2]

方法：最小堆
遍历 count：
1. heap.offer(1): heap = [1(freq=3)]
2. heap.offer(2): heap = [2(freq=2), 1(freq=3)]
3. heap.offer(3): heap = [3(freq=1), 1(freq=3), 2(freq=2)]
   len > k，堆顶 3(freq=1) 弹出: heap = [2(freq=2), 1(freq=3)]

最终堆: [2, 1]
返回 [1, 2]
```

## 关键点总结

1. **HashMap 使用**：统计频率的标准工具
2. **堆的应用**：维护 TopK 的经典数据结构
3. **桶排序思想**：将频率作为索引，O(n) 排序
4. **快速选择**：类似快排的分区思想
5. **空间换时间**：桶排序用额外空间换取 O(n) 时间

## 易错点

1. **堆的比较器方向**
   ```java
   // 错误：最大堆（会保留频率小的元素）
   PriorityQueue<Integer> heap = new PriorityQueue<>(
       (a, b) -> count.get(b) - count.get(a)
   );

   // 正确：最小堆（堆顶是频率最小的，超出 k 时弹出）
   PriorityQueue<Integer> heap = new PriorityQueue<>(
       (a, b) -> count.get(a) - count.get(b)
   );
   ```

2. **桶的大小**
   ```java
   // 错误：桶大小为 n
   List<Integer>[] buckets = new List[n];

   // 正确：桶大小为 n+1（频率可以从 1 到 n）
   List<Integer>[] buckets = new List[n + 1];
   ```

3. **堆的大小控制**
   ```java
   // 错误：先判断再入堆
   if (heap.size() < k) {
       heap.offer(num);
   }

   // 正确：先入堆再判断
   heap.offer(num);
   if (heap.size() > k) {
       heap.poll();
   }
   ```

4. **快速选择的位置**
   ```java
   // 要找频率最高的 k 个
   // 等价于找第 (n-k) 小的元素
   // 右侧就是最大的 k 个
   quickSelect(arr, 0, n - 1, n - k);
   return Arrays.copyOfRange(arr, n - k, n);
   ```
