## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，**捕获** 所有**被围绕的区域**：

- **连接**：一个单元格与水平或垂直方向上相邻的单元格连接。
- **区域**：连接所有 `'O'` 的单元格来形成一个区域。
- **围绕**：如果您可以用 `'X'` 单元格连接这个区域，并且区域中没有任何单元格位于 `board` 边缘，则该区域被 `'X'` 单元格围绕。

通过将输入矩阵 `board` 中的所有 `'O'` 替换为 `'X'` 来**捕获被围绕的区域**。

**示例 1：**
```
输入: board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
输出: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
解释:
在上图中，底部的区域没有被捕获，因为它在 board 的边缘并且不能被围绕。
```

**示例 2：**
```
输入: board = [["X"]]
输出: [["X"]]
```

**提示：**
- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`

## 解题思路

这道题的关键是理解**什么样的 'O' 不会被捕获**：
- 位于边界的 'O'
- 与边界 'O' 连通的 'O'

### 核心思想：反向思维

1. **找出不被捕获的 'O'**：从边界的 'O' 开始，标记所有连通的 'O'
2. **剩余的 'O' 都要被捕获**：将未标记的 'O' 改为 'X'
3. **恢复标记的 'O'**：将标记的 'O' 恢复

### 算法步骤（DFS/BFS）：

1. 遍历矩阵的四条边
2. 对边界上的每个 'O'，进行 DFS/BFS，将连通的 'O' 标记为特殊字符（如 '#'）
3. 遍历整个矩阵：
   - 'O' → 'X'（被围绕的区域）
   - '#' → 'O'（不被围绕的区域）

## Java 代码实现

### 方法一：DFS（推荐）

```java
class Solution {
    private int m, n;

    public void solve(char[][] board) {
        if (board == null || board.length == 0 || board[0].length == 0) return;

        m = board.length;
        n = board[0].length;

        // 1. 从边界的 'O' 开始 DFS，标记为 '#'
        // 第一行和最后一行
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') dfs(board, 0, j);
            if (board[m-1][j] == 'O') dfs(board, m-1, j);
        }

        // 第一列和最后一列
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O') dfs(board, i, 0);
            if (board[i][n-1] == 'O') dfs(board, i, n-1);
        }

        // 2. 处理剩余的 'O' 和 '#'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';  // 被围绕的区域
                } else if (board[i][j] == '#') {
                    board[i][j] = 'O';  // 不被围绕的区域
                }
            }
        }
    }

    private void dfs(char[][] board, int i, int j) {
        // 越界或不是 'O' 则返回
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O') return;

        // 标记为 '#'
        board[i][j] = '#';

        // 向四个方向递归
        dfs(board, i + 1, j);
        dfs(board, i - 1, j);
        dfs(board, i, j + 1);
        dfs(board, i, j - 1);
    }
}
```

### 方法二：BFS

```java
class Solution {
    public void solve(char[][] board) {
        if (board == null || board.length == 0 || board[0].length == 0) return;

        int m = board.length;
        int n = board[0].length;

        // BFS 标记与边界连通的 'O'
        Queue<int[]> queue = new LinkedList<>();

        // 将边界上的 'O' 加入队列
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') { board[0][j] = '#'; queue.offer(new int[]{0, j}); }
            if (board[m-1][j] == 'O') { board[m-1][j] = '#'; queue.offer(new int[]{m-1, j}); }
        }
        for (int i = 1; i < m - 1; i++) {
            if (board[i][0] == 'O') { board[i][0] = '#'; queue.offer(new int[]{i, 0}); }
            if (board[i][n-1] == 'O') { board[i][n-1] = '#'; queue.offer(new int[]{i, n-1}); }
        }

        // BFS 扩散
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int x = cell[0], y = cell[1];

            for (int[] dir : dirs) {
                int nx = x + dir[0];
                int ny = y + dir[1];

                if (nx >= 0 && nx < m && ny >= 0 && ny < n && board[nx][ny] == 'O') {
                    board[nx][ny] = '#';
                    queue.offer(new int[]{nx, ny});
                }
            }
        }

        // 处理剩余的 'O' 和 '#'
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                } else if (board[i][j] == '#') {
                    board[i][j] = 'O';
                }
            }
        }
    }
}
```

### 方法三：并查集

```java
class Solution {
    private int[] parent;

    public void solve(char[][] board) {
        if (board == null || board.length == 0 || board[0].length == 0) return;

        int m = board.length;
        int n = board[0].length;

        // 创建并查集，多一个虚拟节点代表边界
        parent = new int[m * n + 1];
        for (int i = 0; i <= m * n; i++) {
            parent[i] = i;
        }
        int dummy = m * n;  // 虚拟节点索引

        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    int idx = i * n + j;
                    // 边界的 'O' 与虚拟节点相连
                    if (i == 0 || i == m-1 || j == 0 || j == n-1) {
                        union(idx, dummy);
                    } else {
                        // 与四周的 'O' 相连
                        for (int[] dir : dirs) {
                            int ni = i + dir[0];
                            int nj = j + dir[1];
                            if (ni >= 0 && ni < m && nj >= 0 && nj < n && board[ni][nj] == 'O') {
                                union(idx, ni * n + nj);
                            }
                        }
                    }
                }
            }
        }

        // 不与虚拟节点连通的 'O' 要被捕获
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O' && find(i * n + j) != find(dummy)) {
                    board[i][j] = 'X';
                }
            }
        }
    }

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }

    private void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;
        }
    }
}
```

### 方法四：优化的 DFS（迭代版，避免栈溢出）

```java
class Solution {
    public void solve(char[][] board) {
        if (board == null || board.length == 0 || board[0].length == 0) return;

        int m = board.length;
        int n = board[0].length;

        // 从边界开始迭代 DFS
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') dfsIterative(board, 0, j, m, n);
            if (board[m-1][j] == 'O') dfsIterative(board, m-1, j, m, n);
        }
        for (int i = 1; i < m - 1; i++) {
            if (board[i][0] == 'O') dfsIterative(board, i, 0, m, n);
            if (board[i][n-1] == 'O') dfsIterative(board, i, n-1, m, n);
        }

        // 处理剩余的元素
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                } else if (board[i][j] == '#') {
                    board[i][j] = 'O';
                }
            }
        }
    }

    private void dfsIterative(char[][] board, int startI, int startJ, int m, int n) {
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{startI, startJ});

        while (!stack.isEmpty()) {
            int[] cell = stack.pop();
            int x = cell[0], y = cell[1];

            if (x < 0 || x >= m || y < 0 || y >= n || board[x][y] != 'O') continue;

            board[x][y] = '#';

            // 四个方向
            stack.push(new int[]{x + 1, y});
            stack.push(new int[]{x - 1, y});
            stack.push(new int[]{x, y + 1});
            stack.push(new int[]{x, y - 1});
        }
    }
}
```

## 复杂度分析

设矩阵大小为 m × n。

### 方法一/二：DFS/BFS
- **时间复杂度**：O(m × n)，最多访问每个格子一次
- **空间复杂度**：
  - DFS 递归：O(m × n)，最坏情况递归栈深度
  - BFS/迭代 DFS：O(m × n)，队列/栈空间

### 方法三：并查集
- **时间复杂度**：O(m × n × α(m×n))，α 是反阿克曼函数
- **空间复杂度**：O(m × n)，并查集数组

## 关键点总结

1. **反向思维**：不找被围绕的，找不被围绕的
2. **边界扩散**：从边界的 'O' 开始扩散，标记所有连通的 'O'
3. **临时标记**：用 '#' 标记不被围绕的 'O'，避免混淆
4. **原地修改**：直接在原矩阵上修改，节省空间
5. **四个方向遍历**：上下左右四个方向

## 易错点

1. **忘记检查边界**
   ```java
   // 错误：没检查边界就递归
   dfs(board, i + 1, j);

   // 正确：先检查边界
   if (i < 0 || i >= m || j < 0 || j >= n) return;
   ```

2. **只遍历部分边界**
   ```java
   // 错误：忘记遍历某些边
   for (int j = 0; j < n; j++) {
       if (board[0][j] == 'O') dfs(board, 0, j);
   }
   // 忘记最后一行、第一列、最后一列

   // 正确：遍历所有四条边
   ```

3. **标记字符选择不当**
   ```java
   // 错误：用 'O' 或 'X' 标记，会混淆
   board[i][j] = 'O';

   // 正确：用其他字符如 '#'
   board[i][j] = '#';
   ```

4. **递归栈溢出**：对于大矩阵（200×200），递归 DFS 可能栈溢出，解决方案是使用迭代 DFS 或 BFS

5. **修改顺序错误**：先标记所有不被围绕的，再统一修改；不要边遍历边修改
