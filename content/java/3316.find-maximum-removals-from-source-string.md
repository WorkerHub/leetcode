## 题目描述

给你字符串 `source`、`pattern` 及目标下标数组 `targetIndices`，每次操作可删除 `source` 中一个目标下标的字符。返回在 `pattern` 仍是 `source` 子序列的前提下，最多可删除的字符数。

## 解题思路

一维 DP：`dp[j]` 表示已匹配 `pattern[0..j-1]` 时的最大删除数（不可达为 -∞）。对每个 `source[i]`，复制当前 dp，若 `i` 在目标集合中则可删除（dp[j] + 1），否则若字符匹配则推进匹配状态。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxRemovals(String source, String pattern, int[] targetIndices) {
        int n = source.length(), m = pattern.length();
        boolean[] isTarget = new boolean[n];
        for (int idx : targetIndices) isTarget[idx] = true;

        final int NEG_INF = Integer.MIN_VALUE / 2;
        int[] dp = new int[m + 1];
        Arrays.fill(dp, NEG_INF);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            int[] newDp = dp.clone();
            for (int j = 0; j <= m; j++) {
                if (dp[j] == NEG_INF) continue;
                // 选择删除 source[i]（仅限目标下标）
                if (isTarget[i]) newDp[j] = Math.max(newDp[j], dp[j] + 1);
                // 选择用 source[i] 匹配 pattern[j]
                if (j < m && source.charAt(i) == pattern.charAt(j))
                    newDp[j + 1] = Math.max(newDp[j + 1], dp[j]);
                // 跳过（newDp 初始化时已复制 dp[j]，无需额外处理）
            }
            dp = newDp;
        }
        return dp[m] == NEG_INF ? 0 : dp[m];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m)，二维 DP 空间优化为一维
- 空间复杂度：O(m)

## 关键点总结

1. DP 状态 `dp[j]` 表示匹配了 pattern 前 j 个字符时的最大删除数
2. 删除操作只对 `targetIndices` 中的下标有效，删除后 j 不变
3. 每轮复制数组再更新，避免同一轮内状态互相影响
