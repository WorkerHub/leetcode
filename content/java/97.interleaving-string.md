## 题目描述

给定三个字符串 `s1`、`s2`、`s3`，请你判断 `s3` 是否由 `s1` 和 `s2` 交错组成。

两个字符串 `s` 和 `t` 交错的定义与过程如下，其中每个字符串都会被分割成若干非空子字符串：

- `s = s1 + s2 + ... + sn`
- `t = t1 + t2 + ... + tm`
- `|n - m| <= 1`
- 交错是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`

**注意**：`a + b` 意味着字符串 `a` 和 `b` 连接。

**示例 1：**
```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出：true
解释：一种可能的交错方式是：
s1: aa  bc    c
s2:   db  bca
s3: aadbbcbcac
```

**示例 2：**
```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出：false
```

**示例 3：**
```
输入：s1 = "", s2 = "", s3 = ""
输出：true
```

**提示：**
- `0 <= s1.length, s2.length <= 100`
- `0 <= s3.length <= 200`
- `s1`、`s2` 和 `s3` 由小写英文字母组成

## 解题思路

这是一道经典的二维动态规划问题。

### 核心思想

**问题分析：**

1. **长度检查**：如果 `s1.length() + s2.length() != s3.length()`，直接返回 false

2. **交错的本质**：s3 的每个字符必须来自 s1 或 s2，且保持各自的相对顺序不变

3. **动态规划思路**：
   - 状态定义：`dp[i][j]` 表示 s1 的前 i 个字符和 s2 的前 j 个字符能否交错组成 s3 的前 i+j 个字符
   - 决策：s3[i+j-1] 可能来自 s1[i-1] 或 s2[j-1]

4. **状态转移方程**：
   ```
   dp[i][j] = (dp[i-1][j] && s1[i-1] == s3[i+j-1]) ||
              (dp[i][j-1] && s2[j-1] == s3[i+j-1])
   ```

5. **初始状态**：
   - `dp[0][0] = true`（空字符串可以组成空字符串）
   - `dp[i][0]`：只用 s1 的前 i 个字符组成 s3 的前 i 个字符
   - `dp[0][j]`：只用 s2 的前 j 个字符组成 s3 的前 j 个字符

### 图解思路

可以将问题看作在一个二维网格中寻找路径：
- 从左上角 (0, 0) 到右下角 (len(s1), len(s2))
- 每次只能向右或向下移动
- 移动时必须匹配 s3 中对应的字符

## Java 代码实现

### 方法一：二维动态规划（推荐）

```java
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();

        // 长度不匹配，直接返回 false
        if (m + n != s3.length()) {
            return false;
        }

        // dp[i][j] 表示 s1[:i] 和 s2[:j] 能否交错组成 s3[:i+j]
        boolean[][] dp = new boolean[m + 1][n + 1];

        // 初始状态：空字符串
        dp[0][0] = true;

        // 初始化第一列：只使用 s1
        for (int i = 1; i <= m; i++) {
            dp[i][0] = dp[i - 1][0] && s1.charAt(i - 1) == s3.charAt(i - 1);
        }

        // 初始化第一行：只使用 s2
        for (int j = 1; j <= n; j++) {
            dp[0][j] = dp[0][j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
        }

        // 填充 dp 表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // s3 的当前位置
                int k = i + j - 1;
                // 情况1：s3[k] 来自 s1[i-1]
                if (s1.charAt(i - 1) == s3.charAt(k)) {
                    dp[i][j] = dp[i][j] || dp[i - 1][j];
                }
                // 情况2：s3[k] 来自 s2[j-1]
                if (s2.charAt(j - 1) == s3.charAt(k)) {
                    dp[i][j] = dp[i][j] || dp[i][j - 1];
                }
            }
        }

        return dp[m][n];
    }
}
```

### 方法二：一维动态规划（空间优化）

```java
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();

        if (m + n != s3.length()) {
            return false;
        }

        // 只使用一维数组，dp[j] 表示 s2[:j] 的状态
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;

        // 初始化第一行
        for (int j = 1; j <= n; j++) {
            dp[j] = dp[j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
        }

        // 逐行更新
        for (int i = 1; i <= m; i++) {
            // 更新当前行的第一个元素（j=0）
            dp[0] = dp[0] && s1.charAt(i - 1) == s3.charAt(i - 1);

            for (int j = 1; j <= n; j++) {
                int k = i + j - 1;
                // dp[j] 当前表示上一行的值（i-1, j）
                // dp[j-1] 表示当前行的前一个值（i, j-1）
                dp[j] = (dp[j] && s1.charAt(i - 1) == s3.charAt(k)) ||
                        (dp[j - 1] && s2.charAt(j - 1) == s3.charAt(k));
            }
        }

        return dp[n];
    }
}
```

### 方法三：递归 + 记忆化（便于理解）

```java
class Solution {
    private int[][] memo;
    private String s1, s2, s3;

    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();

        if (m + n != s3.length()) {
            return false;
        }

        this.s1 = s1;
        this.s2 = s2;
        this.s3 = s3;

        // -1 表示未计算，0 表示 false，1 表示 true
        memo = new int[m + 1][n + 1];
        for (int[] row : memo) {
            java.util.Arrays.fill(row, -1);
        }

        return dfs(0, 0);
    }

    // 判断 s1[i:] 和 s2[j:] 能否交错组成 s3[i+j:]
    private boolean dfs(int i, int j) {
        int m = s1.length(), n = s2.length();

        // 基本情况：都处理完了
        if (i == m && j == n) {
            return true;
        }

        // 查询缓存
        if (memo[i][j] != -1) {
            return memo[i][j] == 1;
        }

        int k = i + j; // s3 的当前位置
        boolean result = false;

        // 尝试从 s1 取字符
        if (i < m && s1.charAt(i) == s3.charAt(k)) {
            result = dfs(i + 1, j);
        }

        // 尝试从 s2 取字符
        if (!result && j < n && s2.charAt(j) == s3.charAt(k)) {
            result = dfs(i, j + 1);
        }

        // 缓存结果
        memo[i][j] = result ? 1 : 0;
        return result;
    }
}
```

## 复杂度分析

### 方法一：二维动态规划
- **时间复杂度**：O(m * n)
  - 需要填充 m * n 的二维表
- **空间复杂度**：O(m * n)
  - 需要 dp 二维数组

### 方法二：一维动态规划
- **时间复杂度**：O(m * n)
  - 同样需要遍历所有状态
- **空间复杂度**：O(n)
  - 只使用一维数组，空间优化

### 方法三：递归 + 记忆化
- **时间复杂度**：O(m * n)
  - 最多有 m * n 个不同的子问题
- **空间复杂度**：O(m * n)
  - 递归栈和二维数组的空间

## 图解示例

以 s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac" 为例：

```
二维 DP 表的填充过程（true 用 T 表示，false 用 F 表示）：

      ""  d   b   b   c   a
""    T   F   F   F   F   F
a     T   F   F   F   F   F
a     T   T   T   T   T   F
b     F   T   T   F   T   F
c     F   F   T   T   T   T
c     F   F   F   T   F   T

解释：
- dp[0][0] = true（空字符串匹配）
- dp[2][3] = true 表示 "aa" 和 "dbb" 可以交错组成 "aadbb"
- dp[5][5] = true 表示整个 s1 和 s2 可以交错组成 s3
```

## 关键点总结

1. **长度检查**：最基本的剪枝，s1.length() + s2.length() 必须等于 s3.length()
2. **二维 DP**：状态定义为两个字符串的前缀能否组成目标前缀
3. **状态转移**：当前字符可能来自 s1 或 s2，两种情况取或
4. **空间优化**：可以用一维数组优化空间，降到 O(n)
5. **字符比较**：Java 中用 `charAt()` 获取字符，用 `==` 比较字符

## 易错点

1. **索引混淆**
   - dp[i][j] 对应 s3 的索引是 i+j-1，不是 i+j
   - 字符串索引从 0 开始，但 dp 数组索引从 1 开始表示前缀

2. **初始化错误**
   - 必须正确初始化第一行和第一列
   - dp[0][0] = true 是基础

3. **状态转移逻辑**
   - 是"或"关系，不是"且"关系
   - 只要有一种方式能组成就返回 true

4. **Java 字符串获取字符**：使用 `charAt(i)` 而非下标运算符

5. **空间优化时的更新顺序**
   - 使用一维数组时，要注意更新顺序
   - dp[0] 需要特殊处理

## 学习建议

**新手学习路径：**

1. **理解问题本质**
   - 先手动尝试小例子（s1="ab", s2="cd", s3="acbd"）
   - 画出所有可能的交错方式
   - 理解"交错"的含义

2. **掌握 DP 状态定义**
   - 理解 dp[i][j] 表示什么
   - 为什么要用二维数组
   - 状态如何转移

3. **从递归到 DP**
   - 先写递归解法（方法三）
   - 观察重复子问题
   - 转化为 DP 解法

4. **画 DP 表**
   - 手动填充小规模的 DP 表
   - 观察状态转移的规律
   - 理解初始化的重要性

5. **空间优化**
   - 先掌握二维 DP
   - 再学习如何优化到一维
   - 理解滚动数组的思想
