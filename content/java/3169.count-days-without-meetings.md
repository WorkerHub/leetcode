## 题目描述

给你总天数 `days` 和会议区间数组 `meetings`，返回没有会议安排的工作天数。

## 解题思路

排序后合并重叠区间，计算覆盖的总天数，答案 = days - 覆盖天数。

## Java 代码实现

```java
class Solution {
    public int countDays(int days, int[][] meetings) {
        Arrays.sort(meetings, (a, b) -> a[0] - b[0]);
        int covered = 0;
        int curStart = -1, curEnd = -1; // 当前合并区间

        for (int[] m : meetings) {
            if (m[0] > curEnd + 1) {
                // 新区间，不与当前合并区间重叠
                if (curEnd >= 0) covered += curEnd - curStart + 1;
                curStart = m[0];
                curEnd = m[1];
            } else {
                // 合并区间
                curEnd = Math.max(curEnd, m[1]);
            }
        }
        // 处理最后一个合并区间
        if (curEnd >= 0) covered += curEnd - curStart + 1;

        return days - covered;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后合并相邻/重叠区间，计算总覆盖天数
2. 空闲天数 = days - 覆盖天数
3. 合并条件：`m[0] <= curEnd + 1`（连续也视为重叠）
