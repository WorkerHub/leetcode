## 题目描述

给定字符串 s，返回最长重复子串的长度。无则返回 0。

**示例：**
```
输入：s = "aabcaabdaab"
输出：3（"aab"出现3次）
```

## 解题思路

方法一：二分查找 + 滚动哈希（O(n log n)）。方法二：DP，dp[i][j] 表示以 s[i-1] 和 s[j-1] 结尾的最长公共后缀（i≠j），O(n²)。

## Java 代码实现

```java
class Solution {
    public int longestRepeatingSubstring(String s) {
        int n = s.length();
        // DP: dp[i][j] = s[0..i] 和 s[0..j] 的最长公共后缀 (i != j)
        int[][] dp = new int[n + 1][n + 1];
        int maxLen = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                if (s.charAt(i - 1) == s.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    maxLen = Math.max(maxLen, dp[i][j]);
                }
            }
        }

        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)，可优化为 O(n)

## 关键点总结

1. **DP 转化**：转化为字符串与自身的最长公共子串（不同位置）
2. **j > i 限制**：避免同一位置匹配自身
3. **二分+哈希**：可优化到 O(n log n)
