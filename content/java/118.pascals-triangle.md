## 题目描述

给定一个非负整数 `numRows`，生成杨辉三角的前 `numRows` 行。

在杨辉三角中，每个数是它左上方和右上方的数的和。

**示例 1：**

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2：**

```
输入：numRows = 1
输出：[[1]]
```

**提示：**

- `1 <= numRows <= 30`

## 解题思路

杨辉三角（Pascal's Triangle）是一个经典的数学结构，具有以下规律：

1. 每行的第一个和最后一个数字都是 1
2. 其他位置的数字等于上一行对应位置和前一个位置的数字之和
3. 第 n 行有 n 个数字（从 1 开始计数）

**核心思想：**

- 使用动态规划思想，当前行依赖上一行的结果
- 每次生成新行时，除了首尾的 1，中间的数字由上一行相邻两数相加得到

**数学公式：**

```
triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]
```

其中 `1 <= j < i`

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();

        for (int i = 0; i < numRows; i++) {
            // 创建当前行，初始化为全 1
            List<Integer> row = new ArrayList<>();
            for (int k = 0; k <= i; k++) row.add(1);

            // 计算中间的值（除了首尾）
            for (int j = 1; j < i; j++) {
                row.set(j, triangle.get(i-1).get(j-1) + triangle.get(i-1).get(j));
            }

            // 将当前行添加到结果中
            triangle.add(row);
        }

        return triangle;
    }
}
```

### 方法二：基于上一行构建

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();

        // 第一行
        List<Integer> firstRow = new ArrayList<>();
        firstRow.add(1);
        triangle.add(firstRow);

        for (int i = 1; i < numRows; i++) {
            // 获取上一行
            List<Integer> prevRow = triangle.get(triangle.size() - 1);

            // 构建当前行
            List<Integer> row = new ArrayList<>();
            row.add(1);  // 行首为 1

            // 中间的值
            for (int j = 0; j < prevRow.size() - 1; j++) {
                row.add(prevRow.get(j) + prevRow.get(j + 1));
            }

            row.add(1);  // 行尾为 1
            triangle.add(row);
        }

        return triangle;
    }
}
```

### 方法三：数学公式（组合数）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();

        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>();

            for (int j = 0; j <= i; j++) {
                // 使用组合数公式 C(i, j)
                if (j == 0 || j == i) {
                    row.add(1);
                } else {
                    // C(i, j) = C(i, j-1) * (i - j + 1) / j
                    row.add((int) ((long) row.get(j-1) * (i - j + 1) / j));
                }
            }

            triangle.add(row);
        }

        return triangle;
    }
}
```

### 方法四：简洁实现（错位相加）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();
        List<Integer> firstRow = new ArrayList<>();
        firstRow.add(1);
        triangle.add(firstRow);

        for (int i = 1; i < numRows; i++) {
            List<Integer> prev = triangle.get(i - 1);
            // 在上一行前后各加 0，然后错位相加
            List<Integer> row = new ArrayList<>();
            row.add(prev.get(0));  // 首元素 = 0 + prev[0]
            for (int j = 0; j < prev.size() - 1; j++) {
                row.add(prev.get(j) + prev.get(j + 1));
            }
            row.add(prev.get(prev.size() - 1));  // 尾元素 = prev[-1] + 0
            triangle.add(row);
        }

        return triangle;
    }
}
```

### 方法五：递归（不推荐，仅用于理解）

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        if (numRows == 1) {
            List<List<Integer>> result = new ArrayList<>();
            List<Integer> firstRow = new ArrayList<>();
            firstRow.add(1);
            result.add(firstRow);
            return result;
        }

        // 递归获取前 n-1 行
        List<List<Integer>> triangle = generate(numRows - 1);

        // 构建第 n 行
        List<Integer> prevRow = triangle.get(triangle.size() - 1);
        List<Integer> row = new ArrayList<>();
        row.add(1);
        for (int i = 0; i < prevRow.size() - 1; i++) {
            row.add(prevRow.get(i) + prevRow.get(i + 1));
        }
        row.add(1);

        triangle.add(row);
        return triangle;
    }
}
```

## 复杂度分析

**方法一、二、四：动态规划**
- 时间复杂度：O(numRows²)，需要生成 1 + 2 + ... + numRows = numRows × (numRows + 1) / 2 个数字
- 空间复杂度：O(1)，不计算返回值的空间

**方法三：数学公式**
- 时间复杂度：O(numRows²)
- 空间复杂度：O(1)

**方法五：递归**
- 时间复杂度：O(numRows²)
- 空间复杂度：O(numRows)，递归调用栈

## 关键点总结

1. **边界条件**：每行的首尾都是 1
2. **递推关系**：`triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]`
3. **索引处理**：第 i 行有 i+1 个元素（从 0 开始计数）
4. **Java 技巧**：使用 `List.set(index, value)` 修改列表元素
5. **组合数性质**：杨辉三角的每个数字等于组合数 C(n, k)

## 易错点

1. **索引越界**：计算中间值时要注意索引范围 `1 <= j < i`
2. **行数混淆**：第 i 行有 i+1 个元素，不要搞混
3. **初始化错误**：忘记初始化首尾为 1
4. **整数溢出**：使用组合数时要先转 long 再除法，避免溢出
   ```java
   // 正确：先转 long 再计算
   row.add((int) ((long) row.get(j-1) * (i - j + 1) / j));
   ```
5. **List 的修改**：Java 中用 `list.set(index, value)` 而不是 `list[index] = value`

## 杨辉三角的性质

1. **对称性**：每一行都是对称的
2. **组合数**：第 n 行第 k 个数是组合数 C(n, k)
3. **斐波那契数列**：斜线上的数字之和是斐波那契数列
4. **二项式系数**：(a + b)^n 展开式的系数
5. **奇偶性**：可以用来研究数论问题
