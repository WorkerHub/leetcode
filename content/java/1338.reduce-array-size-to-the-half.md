## 题目描述

给你一个整数数组 `arr`。你可以从中选出一个整数集合，并删除这些整数在数组中的每次出现。

返回**至少**能删除数组中的一半整数的整数集合的最小大小。

**示例 1：**
```
输入：arr = [3,3,3,3,5,5,5,2,2,7]
输出：2
解释：选择 {3,5} 之后：3 和 5 各出现 4 次，删除后数组长度从 10 变为 2。
     选择 {3,7} 也能满足：删除 4+1=5 个，数组长度从 10 变为 5（刚好是一半）。
     所以最小集合大小为 2。
```

**示例 2：**
```
输入：arr = [7,7,7,7,7,7]
输出：1
解释：只选 {7}，删除所有 7，数组长度变为 0 <= 3。
```

**提示：**
- `1 <= arr.length <= 10^5`
- `arr.length` 为偶数
- `2 <= arr[i] <= 10^5`

## 解题思路

**贪心策略：优先选出现次数最多的元素。**

要用最少数量的整数删除至少一半的数组元素，应该每次优先选择出现次数最多的元素，这样每选一个整数，就能删除最多的数组元素。

**算法步骤：**
1. 统计每个元素在数组中出现的次数
2. 将出现次数从高到低排序
3. 贪心地从出现次数最多的元素开始选，累加删除的元素数量
4. 直到删除数量 >= 数组长度的一半，返回已选元素的个数

## Java 代码实现

### 方法一：计数 + 排序贪心（推荐）

```java
import java.util.*;

class Solution {
    public int minSetSize(int[] arr) {
        int n = arr.length;
        int target = n / 2; // 需要删除至少这么多元素
        
        // 统计每个元素出现次数
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : arr) freq.merge(x, 1, Integer::sum);
        
        // 将频率从大到小排序
        List<Integer> freqs = new ArrayList<>(freq.values());
        freqs.sort(Collections.reverseOrder());
        
        int removed = 0; // 已删除的元素数量
        int count = 0;   // 选择的整数个数
        
        for (int f : freqs) {
            removed += f;
            count++;
            if (removed >= target) return count;
        }
        
        return count;
    }
}
```

### 方法二：使用大顶堆

```java
import java.util.*;

class Solution {
    public int minSetSize(int[] arr) {
        int n = arr.length;
        int half = n / 2;
        
        // 统计频率
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : arr) freq.merge(x, 1, Integer::sum);
        
        // 最大堆
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        maxHeap.addAll(freq.values());
        
        int removed = 0, count = 0;
        while (removed < half) {
            removed += maxHeap.poll(); // 弹出最大频率
            count++;
        }
        
        return count;
    }
}
```

### 方法三：桶排序思路（计数排序优化）

```java
class Solution {
    public int minSetSize(int[] arr) {
        int n = arr.length;
        int half = n / 2;
        
        // 统计每个元素的频率
        Map<Integer, Integer> freqMap = new HashMap<>();
        for (int x : arr) freqMap.merge(x, 1, Integer::sum);
        
        // 将频率转换为桶：bucket[f] = 频率为 f 的元素个数
        int[] bucket = new int[n + 1];
        for (int f : freqMap.values()) bucket[f]++;
        
        int removed = 0, count = 0;
        // 从最大频率开始贪心选择
        for (int f = n; f >= 1 && removed < half; f--) {
            // 有 bucket[f] 个元素出现频率为 f
            int take = Math.min(bucket[f], (half - removed + f - 1) / f);
            removed += take * f;
            count += take;
        }
        
        return count;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（排序） | O(n log n) | O(n) |
| 方法二（堆） | O(n + k log k) | O(k) |
| 方法三（桶排序） | O(n) | O(n) |

其中 k 是不同元素的数量，k ≤ n。

## 图解示例

以 `arr = [3,3,3,3,5,5,5,2,2,7]` 为例，n=10，目标删除 5 个：

```
频率统计：{3: 4, 5: 3, 2: 2, 7: 1}
降序排列：[4, 3, 2, 1]

贪心选择：
第1步：选频率=4（元素3），已删除4个，< 5，继续
第2步：选频率=3（元素5），已删除7个，>= 5，停止！

返回 2（选了2个整数）
```

## 关键点总结

1. 贪心策略：每次选频率最高的元素，使得每步删除最多的数组元素
2. 只需要关注频率，不需要关注具体是哪个元素
3. 累加到 >= n/2 时停止，统计选了几个整数
4. Java 中用 `HashMap` 统计频率，`PriorityQueue` 或排序处理

## 易错点

1. 目标是删除 `n / 2` 个（整除），不是浮点数
2. 条件是"至少"一半，所以是 `removed >= n / 2`
3. 只统计频率即可，不需要记录具体选了哪些元素

## 学习建议

1. 贪心的直觉：要用最少的整数删除最多的元素，当然要优先选出现次数最多的
2. 先用 HashMap 统计，再排序频率，这是处理频率相关问题的标准流程
3. 注意只需要频率值，不需要知道对应的具体元素
4. 尝试证明贪心的正确性：若选了出现次数少的元素 A 而不选出现次数多的元素 B，将 A 换成 B 只会让结果更好（删除数量不减）
