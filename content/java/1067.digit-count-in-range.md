## 题目描述

给定数字 d 和区间 [low, high]，返回 d 作为数位在该范围内所有数中出现的总次数。

**示例：**
```
输入：d = 1, low = 1, high = 13
输出：6
```

## 解题思路

数位 DP：count(high) - count(low-1)。对每一位分析：按 higher、cur、lower 分别计算 d 在该位出现的次数。d=0 时需特殊处理前导零。

## Java 代码实现

```java
class Solution {
    public int digitsCount(int d, int low, int high) {
        return countDigit(d, high) - countDigit(d, low - 1);
    }

    private int countDigit(int d, int n) {
        if (n < 0) return 0;

        int count = 0;
        long factor = 1; // 当前位权重

        while (factor <= n) {
            long higher = n / (factor * 10);
            int cur = (int) ((n / factor) % 10);
            long lower = n % factor;

            if (d == 0) {
                if (higher == 0) break;
                count += (higher - 1) * factor;
            } else {
                count += higher * factor;
            }

            if (cur > d) {
                count += factor;
            } else if (cur == d) {
                count += lower + 1;
            }

            factor *= 10;
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **区间转换**：count(high) - count(low-1)
2. **逐位分析**：higher、cur、lower 三部分贡献
3. **d=0 特殊处理**：避免计入前导零
