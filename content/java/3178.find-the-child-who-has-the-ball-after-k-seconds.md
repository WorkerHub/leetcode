## 题目描述

n 个孩子排成一排，第 0 秒 0 号孩子持球，球每秒传向相邻孩子，到达两端后方向反转，返回 k 秒后持球的孩子编号。

## 解题思路

球的运动周期为 `2*(n-1)`，对 k 取模后：若余数 < n 则直接返回，否则返回 `period - k`（反方向位置）。

## Java 代码实现

```java
class Solution {
    public int numberOfChild(int n, int k) {
        int period = 2 * (n - 1);
        k = k % period;
        // 前半周期向右，后半周期向左
        return k < n ? k : period - k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 周期为 2*(n-1)，对 k 取模
2. k < n 时在右行阶段，位置为 k；否则在左行阶段，位置为 period - k
