## 题目描述

给你整数数组 `nums`，交替子数组要求以偶数开头且相邻元素奇偶性严格交替，返回最长交替子数组的长度（不存在返回 -1）。

## Java 代码实现

```java
class Solution {
    public int alternatingSubarray(int[] nums) {
        int n = nums.length, ans = -1;
        int i = 0;
        while (i < n) {
            if (nums[i] % 2 != 0) { i++; continue; }
            int j = i + 1;
            // 向后延伸：相邻元素奇偶性严格交替
            while (j < n && nums[j] % 2 != nums[j - 1] % 2) j++;
            ans = Math.max(ans, j - i);
            i++;  // 下一个起点可以从 i+1 开始
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 起点必须是偶数
2. 奇偶严格交替
3. 长度为 1（只有起点）的子数组也合法
