## 题目描述

Android 设备有一个特殊的解锁模式，由 9 个点组成的 3 x 3 网格。

你可以按任意顺序连接这些点，但有以下限制：
- 每个点最多只能访问一次
- 如果连接两个连续的点，它们之间不能有未访问的点（除非该点在直线外）
- 两点之间的连线不能穿过未访问的点

给定两个整数 `m` 和 `n`，返回使用最少 `m` 个点和最多 `n` 个点可以形成的有效解锁模式的总数。

**示例 1：**
```
输入：m = 1, n = 1
输出：9
```

**示例 2：**
```
输入：m = 1, n = 2
输出：65
解释：
长度为 1 的模式：9 种（1-9 任意一个点）
长度为 2 的模式：56 种
总计：9 + 56 = 65
```

**提示：**
- `1 <= m <= n <= 9`

## 解题思路

这是一个典型的回溯问题。

**关键观察：**
1. 9 个点的布局有对称性
   - 四个角点（1,3,7,9）是等价的
   - 四个边点（2,4,6,8）是等价的
   - 中心点（5）独特
2. 跳过点的规则：
   - 1 到 3 必须先访问 2
   - 1 到 7 必须先访问 4
   - 1 到 9 必须先访问 5

**算法流程：**
1. 建立跳过点的映射表
2. DFS 回溯，尝试所有可能的路径
3. 利用对称性减少计算量

## Java 代码实现

### 方法一：回溯 + 剪枝⭐

```java
class Solution {
    public int numberOfPatterns(int m, int n) {
        // 跳过点映射表
        // skip[i][j] 表示从 i 到 j 需要经过的中间点
        int[][] skip = new int[10][10];

        // 横向跳跃
        skip[1][3] = skip[3][1] = 2;
        skip[4][6] = skip[6][4] = 5;
        skip[7][9] = skip[9][7] = 8;

        // 纵向跳跃
        skip[1][7] = skip[7][1] = 4;
        skip[2][8] = skip[8][2] = 5;
        skip[3][9] = skip[9][3] = 6;

        // 对角线跳跃
        skip[1][9] = skip[9][1] = 5;
        skip[3][7] = skip[7][3] = 5;

        boolean[] visited = new boolean[10];
        int result = 0;

        for (int length = m; length <= n; length++) {
            // 利用对称性：四个角点结果相同
            result += dfs(skip, visited, 1, length - 1) * 4;
            // 四个边点结果相同
            result += dfs(skip, visited, 2, length - 1) * 4;
            // 中心点
            result += dfs(skip, visited, 5, length - 1);
        }

        return result;
    }

    private int dfs(int[][] skip, boolean[] visited, int curr, int remaining) {
        if (remaining == 0) {
            return 1;
        }

        visited[curr] = true;
        int count = 0;

        // 尝试访问 1-9 每个点
        for (int next = 1; next <= 9; next++) {
            // 跳过已访问的点
            if (visited[next]) {
                continue;
            }
            // 如果没有跳过点，或者跳过点已被访问，则可以跳转
            if (skip[curr][next] == 0 || visited[skip[curr][next]]) {
                count += dfs(skip, visited, next, remaining - 1);
            }
        }

        visited[curr] = false; // 回溯
        return count;
    }
}
```

**时间复杂度：** O(n!)，最坏情况需要遍历所有排列
**空间复杂度：** O(n)，递归栈深度

### 方法二：优化版（合并长度遍历）

```java
class Solution {
    private int m, n;
    private int[][] skip;
    private boolean[] visited;

    public int numberOfPatterns(int m, int n) {
        this.m = m;
        this.n = n;
        skip = new int[10][10];

        skip[1][3] = skip[3][1] = 2;
        skip[4][6] = skip[6][4] = 5;
        skip[7][9] = skip[9][7] = 8;
        skip[1][7] = skip[7][1] = 4;
        skip[2][8] = skip[8][2] = 5;
        skip[3][9] = skip[9][3] = 6;
        skip[1][9] = skip[9][1] = 5;
        skip[3][7] = skip[7][3] = 5;

        visited = new boolean[10];

        // 利用对称性
        // (dfs(1,1) + dfs(2,1) + dfs(5,1)) * 4 - dfs(5,1) * 3
        // 解释：角点×4 + 边点×4 + 中心点×4 - 中心点×3
        return (dfs(1, 1) + dfs(2, 1) + dfs(5, 1)) * 4 - dfs(5, 1) * 3;
    }

    private int dfs(int curr, int length) {
        // 如果长度在 [m, n] 范围内，计数 +1
        int count = (length >= m && length <= n) ? 1 : 0;

        // 如果已达到最大长度，返回
        if (length == n) {
            return count;
        }

        visited[curr] = true;

        for (int next = 1; next <= 9; next++) {
            if (!visited[next]) {
                int mid = skip[curr][next];
                if (mid == 0 || visited[mid]) {
                    count += dfs(next, length + 1);
                }
            }
        }

        visited[curr] = false;
        return count;
    }
}
```

## 关键点总结

1. **跳过点映射**：建立跳跃规则表
2. **回溯框架**：标记访问、递归、撤销标记
3. **对称性优化**：减少重复计算
4. **剪枝**：长度超过 n 时提前返回
5. **状态记录**：使用布尔数组记录访问状态

## 易错点

1. **跳过点判断**
   ```java
   // 错误：只检查是否有跳过点
   if (skip[curr][next] == 0)
       count += dfs(skip, visited, next, remaining - 1);

   // 正确：还要检查跳过点是否已访问
   if (skip[curr][next] == 0 || visited[skip[curr][next]])
       count += dfs(skip, visited, next, remaining - 1);
   ```

2. **忘记回溯**
   ```java
   // 错误：
   visited[curr] = true;
   // ... dfs
   // 没有恢复状态

   // 正确：
   visited[curr] = true;
   // ... dfs
   visited[curr] = false;
   ```

3. **对称性计算**
   ```java
   // 简单但正确的方法：
   for (int start = 1; start <= 9; start++)
       result += dfs(skip, visited, start, length - 1);

   // 优化版（利用对称性）：
   result += dfs(skip, visited, 1, length - 1) * 4; // 角点
   result += dfs(skip, visited, 2, length - 1) * 4; // 边点
   result += dfs(skip, visited, 5, length - 1);      // 中心
   ```
