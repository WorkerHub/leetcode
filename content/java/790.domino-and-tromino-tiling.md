## 题目描述

用 2×1 的多米诺骨牌和 L 形三格骨牌铺满 2×n 的面板，返回方案数（对 10^9+7 取模）。

**示例：**
```
输入：n = 3
输出：5
```

## 解题思路

递推公式：dp[i] = 2*dp[i-1] + dp[i-3]。来源于分析完全铺满和部分铺满两种状态的转移。

## Java 代码实现

```java
class Solution {
    public int numTilings(int n) {
        if (n <= 2) return n;
        int MOD = 1_000_000_007;
        long dp0 = 1, dp1 = 1, dp2 = 2;

        for (int i = 3; i <= n; i++) {
            long dp3 = (2 * dp2 + dp0) % MOD;
            dp0 = dp1;
            dp1 = dp2;
            dp2 = dp3;
        }
        return (int) dp2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **递推公式**：dp[i] = 2*dp[i-1] + dp[i-3]
2. **初始值**：dp[0]=1, dp[1]=1, dp[2]=2
3. **取模**：每步运算后取模防止溢出
