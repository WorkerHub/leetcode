## 题目描述

与 3264 相同，但数据范围更大：`1 <= k <= 10^9`，`1 <= multiplier <= 10^6`。结果对 `10^9 + 7` 取模。

## 解题思路

直接模拟 k 次超时。关键观察：先用堆模拟直到所有元素值相近（均衡），之后剩余操作形成完整轮次，每轮 n 次对应每个元素各乘一次 multiplier。用快速幂计算大指数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] getFinalState(int[] nums, int k, int multiplier) {
        final int MOD = 1_000_000_007;
        int n = nums.length;

        if (multiplier == 1) {
            int[] res = new int[n];
            for (int i = 0; i < n; i++) res[i] = (int)(nums[i] % MOD);
            return res;
        }

        long[] result = new long[n];
        for (int i = 0; i < n; i++) result[i] = nums[i];

        // 最小堆：(值, 下标)
        PriorityQueue<long[]> pq = new PriorityQueue<>(
            (a, b) -> a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1])
        );
        for (int i = 0; i < n; i++) pq.offer(new long[]{result[i], i});

        // 第一阶段：模拟直到均衡（最大值 <= 最小值 * multiplier）
        int ops = 0;
        while (ops < k) {
            long minVal = pq.peek()[0];
            long maxVal = 0;
            for (long v : result) maxVal = Math.max(maxVal, v);
            if (maxVal <= minVal * (long) multiplier) break;
            long[] top = pq.poll();
            result[(int) top[1]] = top[0] * multiplier;
            pq.offer(new long[]{top[0] * multiplier, top[1]});
            ops++;
        }

        int remaining = k - ops;
        if (remaining == 0) {
            int[] res = new int[n];
            for (int i = 0; i < n; i++) res[i] = (int)(result[i] % MOD);
            return res;
        }

        // 第二阶段：均衡后按 (值, 下标) 排序，计算每个元素的指数
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> result[a] != result[b] ?
            Long.compare(result[a], result[b]) : a - b);

        int baseExp = remaining / n;
        int extra = remaining % n;

        int[] res = new int[n];
        for (int rank = 0; rank < n; rank++) {
            int i = order[rank];
            int exp = baseExp + (rank < extra ? 1 : 0);
            res[i] = (int)(result[i] % MOD * pow(multiplier, exp, MOD) % MOD);
        }
        return res;
    }

    private long pow(long base, int exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n * log(maxVal) + n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 先模拟至均衡，再按数学公式批量计算剩余操作
2. 均衡后排序靠前的元素多乘一次
3. 快速幂计算大指数取模
