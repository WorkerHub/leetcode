## 题目描述

给定等长字符串列表，判断是否存在两个字符串恰好只有一个字符不同。

**示例：**
```
输入：dict = ["abcd","acbd","aacd"]
输出：true
```

## 解题思路

遮蔽法：枚举每个位置，将该位置替换为通配符，用 HashSet 判断是否有重复。

## Java 代码实现

```java
class Solution {
    public boolean differByOne(String[] dict) {
        int L = dict[0].length();
        for (int j = 0; j < L; j++) {
            Set<String> seen = new HashSet<>();
            for (String s : dict) {
                // 遮蔽第 j 位
                String masked = s.substring(0, j) + "*" + s.substring(j + 1);
                if (seen.contains(masked)) return true;
                seen.add(masked);
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × L²)，字符串拼接 O(L)
- **空间复杂度**：O(N × L)

## 关键点总结

1. **遮蔽法**：枚举每个位置用通配符替换
2. **HashSet判重**：相同 masked 说明只差一位
3. **数据规模小**：N≤100, L≤20，暴力也可
