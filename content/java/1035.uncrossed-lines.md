## 题目描述

给定两个整数数组 nums1 和 nums2，绘制连接相等元素的直线且不能相交，返回最大连线数。

**示例：**
```
输入：nums1 = [1,4,2], nums2 = [1,2,4]
输出：2
```

## 解题思路

本质是最长公共子序列（LCS）。不相交连线等价于保持两数组中匹配元素的相对顺序一致。dp[i][j] 表示 nums1[0:i] 和 nums2[0:j] 的最大连线数。

## Java 代码实现

```java
class Solution {
    public int maxUncrossedLines(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    // 当前元素相等，可以连线
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 继承之前的最大值
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m×n)
- **空间复杂度**：O(m×n)，可优化为 O(n)

## 关键点总结

1. **问题转化**：不相交连线 = 最长公共子序列
2. **状态转移**：相等时 +1，不等时取 max
3. **空间优化**：可用滚动数组降至 O(n)
