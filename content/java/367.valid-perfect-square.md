## 题目描述

给你一个正整数 `num`，如果 `num` 是一个完全平方数，则返回 `true`，否则返回 `false`。

完全平方数是一个可以写成某个整数的平方的整数。换句话说，它可以写成某个整数和自身的乘积。

你不能使用任何内置的库函数，如 `sqrt`。

**示例 1：**

```
输入：num = 16
输出：true
解释：返回 true，因为 4 * 4 = 16 且 4 是一个整数
```

**示例 2：**

```
输入：num = 14
输出：false
解释：返回 false，因为 3.742 * 3.742 = 14 但 3.742 不是一个整数
```

**提示：**
- `1 <= num <= 2^31 - 1`

## 解题思路

判断一个数是否为完全平方数有多种方法，从简单到高级：

### 方法一：二分查找（推荐）

在 `[1, num]` 范围内二分查找，找到一个数 `x` 使得 `x * x == num`。

### 方法二：牛顿迭代法

使用牛顿法快速逼近平方根，然后判断结果是否为整数。

### 方法三：数学性质

利用完全平方数的性质：
- 完全平方数 = 1 + 3 + 5 + 7 + ... + (2n-1)
- 即奇数和

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        if (num == 1) return true;

        // 使用 long 避免 mid * mid 整数溢出（num 最大为 2^31 - 1）
        long left = 2, right = num / 2;

        while (left <= right) {
            long mid    = left + (right - left) / 2;
            long square = mid * mid;

            if (square == num) return true;
            else if (square < num) left  = mid + 1;
            else                   right = mid - 1;
        }

        return false;
    }
}
```

### 方法二：牛顿迭代法

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        if (num == 1) return true;

        // 牛顿迭代公式：x_{n+1} = (x_n + num / x_n) / 2
        long x = num;
        while (x * x > num) {
            // 牛顿迭代，快速逼近平方根
            x = (x + num / x) / 2;
        }

        return x * x == num;
    }
}
```

### 方法三：奇数和性质

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        /**
         * 利用完全平方数 = 奇数和的性质
         * n^2 = 1 + 3 + 5 + ... + (2n-1)
         *
         * 时间复杂度：O(sqrt(n))
         * 空间复杂度：O(1)
         */
        int i = 1;
        while (num > 0) {
            num -= i;
            i += 2;
        }
        return num == 0;
    }
}
```

### 方法四：直接开方（参考，题目不允许）

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        // 使用内置函数（题目不允许，仅供参考）
        // 注意要用 long 类型防止精度问题
        long sqrt = (long) Math.sqrt(num);

```

### 方法五：优化的二分查找

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        // 优化边界的二分查找
        // 对于 num >= 2，平方根不会超过 num / 2
        if (num < 2) return true;

        long left = 2, right = num / 2;

        while (left <= right) {
            long mid    = left + (right - left) / 2;
            long square = mid * mid;

            if (square == num) return true;
            else if (square < num) left  = mid + 1;
            else                   right = mid - 1;
        }

        return false;
    }
}
```

## 复杂度分析

### 方法一：二分查找
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

### 方法二：牛顿迭代法
- 时间复杂度：O(log n)，收敛速度比二分查找快
- 空间复杂度：O(1)

### 方法三：奇数和
- 时间复杂度：O(√n)
- 空间复杂度：O(1)

### 方法四：内置函数
- 时间复杂度：O(1)，但题目不允许
- 空间复杂度：O(1)

## 关键点总结

1. **二分查找边界**：搜索范围可以优化为 `[2, num/2]`
2. **溢出问题**：Java 中计算 `mid * mid` 时必须用 `long`，否则可能溢出
3. **牛顿迭代**：收敛速度快，适合大数
4. **数学性质**：奇数和性质巧妙但效率较低
5. **边界情况**：1 是完全平方数

## 易错点

1. **初始边界**：`num == 1` 需要特殊处理
2. **搜索范围**：注意 `right` 可以设为 `num / 2`
3. **整数溢出**：Java 中 `mid * mid` 如果 `mid` 是 `int` 型会溢出，必须用 `long`
4. **牛顿法初值**：初值设为 `num` 即可
5. **奇数和终止条件**：循环结束时 `num` 应该正好为 0

## 图解示例

### 示例：num = 16

**二分查找过程：**
```
[1, 8]
mid = 4, 4*4 = 16 ✓ 找到！

如果 num = 14：
[1, 7]
mid = 4, 4*4 = 16 > 14, right = 3
[1, 3]
mid = 2, 2*2 = 4 < 14, left = 3
[3, 3]
mid = 3, 3*3 = 9 < 14, left = 4
left > right，返回 false
```

**奇数和过程（num = 16）：**
```
16 - 1 = 15 (i=1)
15 - 3 = 12 (i=3)
12 - 5 = 7  (i=5)
7 - 7 = 0   (i=7)
结果为 0，返回 true
```

## 学习建议

1. **优先掌握二分查找**：这是最常用、最稳定的方法
2. **理解牛顿迭代**：
   - 原理：f(x) = x^2 - num = 0 的根
   - 公式推导：x_{n+1} = x_n - f(x_n)/f'(x_n)
3. **对比各方法优劣**：
   - 二分查找：稳定，易理解
   - 牛顿法：快速，需要理解原理
   - 奇数和：巧妙但慢
4. **注意边界优化**：
   - `num < 2` 直接返回 true
   - 搜索范围 `[2, num/2]`
5. **扩展思考**：
   - 如何判断立方数？
   - 如何找最接近的完全平方数？
