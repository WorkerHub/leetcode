## 题目描述

给你字符串 `s` 和 `t`，返回需要在 `s` 末尾追加的最少字符数，使得 `t` 成为 `s` 的子序列。

## 解题思路

双指针贪心：用指针 `j` 遍历 `t`，依次在 `s` 中找到 `t[j]` 的匹配位置，遍历完 `s` 后未匹配的 `t[j:]` 即需要追加的部分。

## Java 代码实现

```java
class Solution {
    public int appendCharacters(String s, String t) {
        int j = 0; // t 的匹配指针
        for (int i = 0; i < s.length() && j < t.length(); i++) {
            if (s.charAt(i) == t.charAt(j)) j++;
        }
        // t[j..] 未被匹配，需要追加
        return t.length() - j;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心地从左到右匹配 t 的前缀，j 表示已匹配的长度
2. 遍历 s 结束后，未匹配的 `t[j:]` 长度即为答案
3. 无需真正追加字符
