## 题目描述

给你一个 `m x n` 整数矩阵 `grid`，每列宽度等于该列中最长数字字符串的长度（负号计入长度），返回每列宽度组成的数组。

## Java 代码实现

```java
class Solution {
    public int[] findColumnWidth(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] ans = new int[n];
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                // 负数转字符串会自动包含负号
                int len = String.valueOf(grid[i][j]).length();
                ans[j] = Math.max(ans[j], len);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * log M)，M 为最大绝对值
- 空间复杂度：O(1)（不计输出）

## 关键点总结

1. `String.valueOf(x)` 对负数自动包含负号
2. 逐列扫描，维护每列最大长度
