## 题目描述

给你一个整数数组 `nums`，和一个表示限制的整数 `limit`，请你返回最长连续子数组的长度，该子数组中的任意两个元素之间的绝对差必须小于或等于 `limit`。

如果不存在满足条件的子数组，则返回 `0`。

**示例 1：**
```
输入：nums = [8,2,4,7], limit = 4
输出：2
解释：
所有子数组如下：
[8] 最大绝对差 0 <= 4，长度 1
[8,2] 最大绝对差 6 > 4，不满足
[2,4] 最大绝对差 2 <= 4，长度 2
[4,7] 最大绝对差 3 <= 4，长度 2
最长满足条件的子数组长度为 2。
```

**示例 2：**
```
输入：nums = [10,1,2,4,7,2], limit = 5
输出：4
解释：满足条件的最长子数组是 [2,4,7,2]，其最大绝对差为 5。
```

**示例 3：**
```
输入：nums = [4,2,2,2,4,4,2,2], limit = 0
输出：3
```

**提示：**
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `0 <= limit <= 10^9`

## 解题思路

**子数组中最大绝对差 = 最大值 - 最小值**（因为最大差一定在最大值和最小值之间取得）。

因此问题转化为：找最长的窗口 `[left, right]`，使得窗口内的 `max - min <= limit`。

**关键：如何高效维护滑动窗口的最大值和最小值？**

**方法：双单调双端队列**
- 用一个单调递减队列 `maxDq` 维护窗口最大值（队头为最大值）。
- 用一个单调递增队列 `minDq` 维护窗口最小值（队头为最小值）。
- 滑动窗口右移时，维护两个队列；若 `max - min > limit`，左移窗口并更新队列。

## Java 代码实现

### 方法一：双单调双端队列（推荐，O(n)）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int longestSubarray(int[] nums, int limit) {
        // maxDq: 单调递减队列，存下标，队头为窗口内最大值的下标
        Deque<Integer> maxDq = new ArrayDeque<>();
        // minDq: 单调递增队列，存下标，队头为窗口内最小值的下标
        Deque<Integer> minDq = new ArrayDeque<>();

        int left = 0;
        int result = 0;

        for (int right = 0; right < nums.length; right++) {
            int num = nums[right];

            // 维护 maxDq：保持递减，弹出所有比当前值小的
            while (!maxDq.isEmpty() && nums[maxDq.peekLast()] <= num) {
                maxDq.pollLast();
            }
            maxDq.offerLast(right);

            // 维护 minDq：保持递增，弹出所有比当前值大的
            while (!minDq.isEmpty() && nums[minDq.peekLast()] >= num) {
                minDq.pollLast();
            }
            minDq.offerLast(right);

            // 如果当前窗口不满足条件，收缩左边界
            while (nums[maxDq.peekFirst()] - nums[minDq.peekFirst()] > limit) {
                left++;
                // 弹出已不在窗口内的队头
                if (maxDq.peekFirst() < left) maxDq.pollFirst();
                if (minDq.peekFirst() < left) minDq.pollFirst();
            }

            // 更新最长长度
            result = Math.max(result, right - left + 1);
        }

        return result;
    }
}
```

### 方法二：最大堆 + 最小堆（懒删除）

```java
import java.util.PriorityQueue;

class Solution {
    public int longestSubarray(int[] nums, int limit) {
        // 最大堆：存 [值, 下标]，按值降序
        PriorityQueue<int[]> maxHeap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        // 最小堆：存 [值, 下标]，按值升序
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);

        int left = 0;
        int result = 0;

        for (int right = 0; right < nums.length; right++) {
            maxHeap.offer(new int[]{nums[right], right});
            minHeap.offer(new int[]{nums[right], right});

            // 懒删除：弹出已不在窗口的堆顶元素
            while (maxHeap.peek()[1] < left) maxHeap.poll();
            while (minHeap.peek()[1] < left) minHeap.poll();

            // 若不满足条件，收缩
            while (maxHeap.peek()[0] - minHeap.peek()[0] > limit) {
                left++;
                while (maxHeap.peek()[1] < left) maxHeap.poll();
                while (minHeap.peek()[1] < left) minHeap.poll();
            }

            result = Math.max(result, right - left + 1);
        }

        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（双单调队列） | O(n) | O(n) |
| 方法二（堆） | O(n log n) | O(n) |

- 方法一最优，每个元素最多进出队列各一次，均摊 O(1)。

## 图解示例

```
right=0, num=8:
  maxDq=[0], minDq=[0]
  max=8, min=8, 差=0 <= 4
  窗口 [0,0]，长度 1

right=1, num=2:
  maxDq=[0,1]（8>2，直接加），minDq=[1]（2<8，弹出0再加）
  max=8, min=2, 差=6 > 4

  差=2-2=0 <= 4，窗口 [1,1]，长度 1

right=2, num=4:
  maxDq=[2]（4>2，弹出1加2），minDq=[1,2]（直接加）
  max=4, min=2, 差=2 <= 4
  窗口 [1,2]，长度 2，result=2

right=3, num=7:
  maxDq=[3]（7>4，弹出2加3），minDq=[1,2,3]（直接加）
  max=7, min=2, 差=5 > 4
  left=2, minDq[0]=1 < 2，弹出 -> minDq=[2,3]
  max=7, min=4, 差=3 <= 4
  窗口 [2,3]，长度 2

```

## 关键点总结

1. 子数组最大差 = 最大值 - 最小值，因此问题等价于控制窗口内的最大值和最小值之差。
2. 双单调双端队列是维护滑动窗口最值的经典技巧，时间复杂度 O(n)。
3. `maxDq` 单调递减（队头最大），`minDq` 单调递增（队头最小），均存下标。
4. 收缩窗口时需同时检查两个队列的队头是否已离开窗口。

## 易错点

- 弹出条件写反：`maxDq` 应在新元素 `>=` 队尾时弹出（保持递减）。
- 收缩左边界时，忘记检查队头下标是否已小于 `left`，导致使用了过期的最大/最小值。
