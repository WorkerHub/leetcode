## 题目描述

给你整数数组 `nums` 和整数 `threshold`，若两个元素 `a`、`b` 满足 `lcm(a, b) <= threshold` 则连边，返回图的连通分量数。

## 解题思路

枚举公约数 d（1 到 threshold），将 nums 中所有 d 的倍数用并查集连通（同一公约数的倍数之间 lcm <= threshold）。遍历完所有 d 后，统计 nums 中元素的不同根节点数即为答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent, rank;

    public int countComponents(int[] nums, int threshold) {
        parent = new int[threshold + 1];
        rank = new int[threshold + 1];
        for (int i = 0; i <= threshold; i++) parent[i] = i;

        boolean[] present = new boolean[threshold + 1];
        for (int x : nums) present[x] = true;

        // 对每个 d，将 d 的所有倍数（出现在 nums 中的）连通
        for (int d = 1; d <= threshold; d++) {
            int first = -1;
            for (int multiple = d; multiple <= threshold; multiple += d) {
                if (present[multiple]) {
                    if (first == -1) {
                        first = multiple;
                    } else {
                        union(first, multiple);
                    }
                }
            }
        }

        // 统计 nums 中不同根节点数
        Set<Integer> roots = new HashSet<>();
        for (int x : nums) roots.add(find(x));
        return roots.size();
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) { int tmp = px; px = py; py = tmp; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }
}
```

## 复杂度分析

- 时间复杂度：O(threshold * log(threshold))，调和级数
- 空间复杂度：O(threshold)

## 关键点总结

1. 枚举公约数 d，将 nums 中所有 d 的倍数连通。
2. 并查集合并操作实现连通性，路径压缩 + 按秩合并优化。
3. 最终统计 nums 中元素的不同根节点数即为连通分量数。
