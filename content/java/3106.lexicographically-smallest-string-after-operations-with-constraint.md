## 题目描述

给你字符串 `s` 和整数 `k`，每次操作可将某字母替换为循环距离最近的字母（a 和 z 距离为 1）。返回至多 k 次操作后字典序最小的字符串。

## 解题思路

贪心从左到右：对每个字符计算变为 'a' 的最小循环距离，若不超过 k 则替换为 'a' 并扣减 k；否则将当前字符向 'a' 方向移动 k 步后停止（后续操作无法改善字典序）。

## Java 代码实现

```java
class Solution {
    public String getSmallestString(String s, int k) {
        char[] res = s.toCharArray();
        for (int i = 0; i < res.length; i++) {
            int val = res[i] - 'a';
            int dist = Math.min(val, 26 - val); // 最小循环距离
            if (dist <= k) {
                k -= dist;
                res[i] = 'a';
            } else {
                res[i] = (char) (res[i] - k); // 向 'a' 方向移动 k 步
                break;
            }
        }
        return new String(res);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 循环距离 = min(val, 26-val)，注意绕圈情况
2. 一旦无法将某字符变为 'a'，只能部分减小并立即停止
