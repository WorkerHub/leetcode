## 题目描述

n 首不同的歌，计划听 goal 首（可重复）。要求每首歌至少播放一次，且一首歌只有在其他 k 首歌播放完之后才能再次播放。返回播放列表数量，结果对 10^9+7 取余。

**示例：**
```
输入：n = 3, goal = 3, k = 1
输出：6
```

## 解题思路

dp[i][j] 表示播放 i 首歌、使用 j 首不同歌的方案数。第 i 首可以是新歌（n-j+1 种选择）或旧歌（max(0, j-k) 种选择）。

## Java 代码实现

```java
class Solution {
    public int numMusicPlaylists(int n, int goal, int k) {
        long MOD = 1_000_000_007;
        // dp[i][j] = 播放 i 首歌，使用 j 首不同歌的方案数
        long[][] dp = new long[goal + 1][n + 1];
        dp[0][0] = 1;

        for (int i = 1; i <= goal; i++) {
            for (int j = 1; j <= Math.min(i, n); j++) {
                // 播放一首新歌：有 n - j + 1 种选择
                dp[i][j] = dp[i - 1][j - 1] * (n - j + 1) % MOD;
                // 重复播放旧歌：有 j - k 种选择（需 j > k）
                if (j > k) {
                    dp[i][j] = (dp[i][j] + dp[i - 1][j] * (j - k)) % MOD;
                }
            }
        }

        return (int) dp[goal][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(goal × n)
- **空间复杂度**：O(goal × n)

## 关键点总结

1. **状态定义**：dp[i][j] 播放 i 首歌用 j 首不同歌
2. **新歌选择**：n - j + 1 种
3. **旧歌限制**：最近 k 首不能重复，可选 j - k 种
4. **取模运算**：每步都取模防止溢出
