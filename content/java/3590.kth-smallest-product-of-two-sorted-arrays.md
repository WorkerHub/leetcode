## 题目描述

给定两个有序整数数组 `nums1` 和 `nums2`（可含负数），从各取一个元素形成乘积，返回所有乘积中第 `k` 小的值（1-indexed）。

## Java 代码实现

```java
class Solution {
    public long kthSmallestProduct(int[] nums1, int[] nums2, long k) {
        long lo = -10_000_000_000L, hi = 10_000_000_000L;

        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (countLeq(nums1, nums2, mid) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    // 统计 nums1[i] * nums2[j] <= mid 的对数
    private long countLeq(int[] nums1, int[] nums2, long mid) {
        int n2 = nums2.length;
        long res = 0;

        for (int a : nums1) {
            if (a == 0) {
                if (mid >= 0) res += n2;
            } else if (a > 0) {
                // a * b <= mid => 在 nums2 中找最大的 b 使 a*b <= mid
                int lo = 0, hi = n2;
                while (lo < hi) {
                    int m = (lo + hi) / 2;
                    if ((long) a * nums2[m] <= mid) lo = m + 1;
                    else hi = m;
                }
                res += lo;
            } else {
                // a < 0，a * b <= mid，不等号翻转
                int lo = 0, hi = n2;
                while (lo < hi) {
                    int m = (lo + hi) / 2;
                    if ((long) a * nums2[m] <= mid) hi = m;
                    else lo = m + 1;
                }
                res += (n2 - lo);
            }
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * log(n) * log(MAX))，m 为 nums1 长度，n 为 nums2 长度
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案，对每个候选值 mid 统计乘积 <= mid 的对数
2. 固定 `a = nums1[i]`，在 nums2 中二分；`a > 0` 时正常二分，`a < 0` 时不等号翻转
3. 用 `long` 防止 `a * nums2[m]` 溢出，二分范围取 [-10^10, 10^10]
