## 题目描述

给定整数数组 `nums`，找出数组中任意两个元素的最大汉明距离（两个整数二进制表示中对应位不同的个数）。

## Java 代码实现

```java
class Solution {
    public int maxHammingDistance(int[] nums) {
        int n = nums.length;
        int maxDist = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 汉明距离 = 两数异或后的 popcount
                int dist = Integer.bitCount(nums[i] ^ nums[j]);
                maxDist = Math.max(maxDist, dist);
            }
        }

        return maxDist;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²)，枚举所有对
- 空间复杂度：O(1)

## 关键点总结

1. 汉明距离 = 两数异或后的置位数量（popcount）
2. Java 的 `Integer.bitCount()` 高效计算 popcount
3. 对于 n ≤ 10⁴，O(n²) 可以接受
