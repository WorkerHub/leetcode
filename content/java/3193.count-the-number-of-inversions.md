## 题目描述

给你整数 `n` 和约束 `requirements[i] = [end_i, cnt_i]`，返回 `[0..n-1]` 的排列数，使得每个约束点的前缀逆序对数恰好满足要求，结果对 10^9+7 取模。

## 解题思路

DP：`dp[j]` 表示当前已插入 i+1 个元素且逆序对数为 j 的方案数。将第 i 个元素插入前 i 个元素的排列时，可新增 0 到 i 个逆序对（插入位置决定）。用前缀和将每步转移从 O(i) 优化为 O(1)。遇到约束时，将非约束值归零。

## Java 代码实现

```java
class Solution {
    public int numberOfPermutations(int n, int[][] requirements) {
        final int MOD = 1_000_000_007;
        Map<Integer, Integer> req = new HashMap<>();
        int maxInv = 0;
        for (int[] r : requirements) {
            req.put(r[0], r[1]);
            maxInv = Math.max(maxInv, r[1]);
        }
        // 若 requirements 中包含 end=n-1，全局最大逆序对数由它决定
        if (req.containsKey(n - 1)) maxInv = req.get(n - 1);
        else maxInv = Math.max(maxInv, n * (n - 1) / 2);
        // 限制最大值（防止超出有效范围）
        maxInv = Math.min(maxInv, n * (n - 1) / 2);

        long[] dp = new long[maxInv + 1];
        dp[0] = 1;
        // 若位置 0 有约束
        if (req.containsKey(0)) {
            int c = req.get(0);
            long[] tmp = new long[maxInv + 1];
            if (c <= maxInv) tmp[c] = dp[c];
            dp = tmp;
        }

        for (int i = 1; i < n; i++) {
            // 用前缀和优化：dp_new[j] = sum(dp[j-k]) for k=0..i
            long[] prefix = new long[maxInv + 2];
            for (int j = 0; j <= maxInv; j++) {
                prefix[j + 1] = (prefix[j] + dp[j]) % MOD;
            }
            long[] newDp = new long[maxInv + 1];
            for (int j = 0; j <= maxInv; j++) {
                int lo = Math.max(0, j - i);
                newDp[j] = (prefix[j + 1] - prefix[lo] + MOD) % MOD;
            }
            // 应用约束
            if (req.containsKey(i)) {
                int c = req.get(i);
                long[] tmp = new long[maxInv + 1];
                if (c <= maxInv) tmp[c] = newDp[c];
                newDp = tmp;
            }
            dp = newDp;
        }

        Integer target = req.get(n - 1);
        if (target != null) return (int) dp[target];
        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × maxInv)
- **空间复杂度**：O(maxInv)

## 关键点总结

1. 逐步插入元素，新增 0 到 i 个逆序对，用前缀和优化转移
2. 遇到约束时，将其他逆序对数的 DP 值归零
3. 最大逆序对数由约束点决定，可有效剪枝
