## 题目描述

在一个仓库里，有一排条形码，其中第 `i` 个条形码为 `barcodes[i]`。

请你重新排列这些条形码，使其中任意两个相邻的条形码不能相等。你可以返回任何满足该要求的答案，此题保证存在答案。

**示例 1：**
```
输入：barcodes = [1,1,1,2,2,2]
输出：[2,1,2,1,2,1]
```

**示例 2：**
```
输入：barcodes = [1,1,1,1,2,2,3,3]
输出：[1,3,1,3,1,2,1,2]
```

**提示：**
- `1 <= barcodes.length <= 10000`
- `1 <= barcodes[i] <= 10000`

## 解题思路

这道题的核心是**如何避免相同元素相邻**。关键策略是：
1. 优先放置出现次数最多的元素
2. 采用"间隔放置"的方式

**贪心策略：**
- 先统计每个元素的出现次数
- 按照出现次数从大到小排序
- 先在偶数位置（0, 2, 4, ...）放置元素
- 偶数位置放满后，在奇数位置（1, 3, 5, ...）放置

**为什么这样可行？**
- 出现次数最多的元素最容易造成相邻
- 间隔放置可以保证同一元素至少相隔一个位置
- 题目保证有解，说明最高频元素的数量 ≤ (n+1)//2

## Java 代码实现

### 方法一：计数 + 间隔放置（推荐）

```java
import java.util.*;

class Solution {
    public int[] rearrangeBarcodes(int[] barcodes) {
        // 时间复杂度：O(n log k)，k 为不同元素个数
        // 空间复杂度：O(n)

        int n = barcodes.length;
        int[] result = new int[n];

        // 统计每个元素出现次数
        Map<Integer, Integer> counter = new HashMap<>();
        for (int b : barcodes) {
            counter.put(b, counter.getOrDefault(b, 0) + 1);
        }

        // 按出现次数从大到小排序
        List<int[]> sorted = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : counter.entrySet()) {
            sorted.add(new int[]{entry.getKey(), entry.getValue()});
        }
        sorted.sort((a, b) -> b[1] - a[1]);

        // 间隔放置
        int index = 0;
        for (int[] item : sorted) {
            int num = item[0], count = item[1];
            for (int i = 0; i < count; i++) {
                result[index] = num;
                index += 2;
                // 偶数位置填满后，从位置 1 开始填奇数位置
                if (index >= n) {
                    index = 1;
                }
            }
        }

        return result;
    }
}
```

### 方法二：使用最大堆

```java
import java.util.*;

class Solution {
    public int[] rearrangeBarcodes(int[] barcodes) {
        // 使用最大堆贪心选择
        // 时间复杂度：O(n log k)
        // 空间复杂度：O(n)

        // 统计频率
        Map<Integer, Integer> counter = new HashMap<>();
        for (int b : barcodes) {
            counter.put(b, counter.getOrDefault(b, 0) + 1);
        }

        // 构建最大堆（按频率排序）
        PriorityQueue<int[]> maxHeap = new PriorityQueue<>((a, b) -> b[1] - a[1]);
        for (Map.Entry<Integer, Integer> entry : counter.entrySet()) {
            maxHeap.offer(new int[]{entry.getKey(), entry.getValue()});
        }

        int[] result = new int[barcodes.length];
        int idx = 0;
        int[] prev = null; // 上一个被取出的元素

        while (!maxHeap.isEmpty()) {
            int[] curr = maxHeap.poll();
            result[idx++] = curr[0];

            // 如果前一个还有剩余，放回堆中
            if (prev != null && prev[1] > 0) {
                maxHeap.offer(prev);
            }

            // 当前元素使用一次，更新计数
            curr[1]--;
            prev = curr;
        }

        return result;
    }
}
```

## 复杂度分析

**方法一：计数 + 间隔放置**
- 时间复杂度：O(n log k)，其中 k 是不同元素个数，排序需要 O(k log k)，填充需要 O(n)
- 空间复杂度：O(n)，需要额外数组存储结果

**方法二：堆**
- 时间复杂度：O(n log k)，每次堆操作 O(log k)，共 n 次
- 空间复杂度：O(n)

## 关键点总结

1. **贪心策略**：优先放置出现次数最多的元素
2. **间隔放置**：先填偶数位置，再填奇数位置，保证相邻不同
3. **题目保证有解**：最高频元素数量不超过 ⌈n/2⌉
4. **多种方法**：计数排序、堆都可以解决

## 易错点

1. **索引越界**：填充偶数位置时注意 `index >= n` 要切换到奇数位置
2. **排序依据**：必须按出现次数降序排序，不能按元素值排序
3. **理解题意**：任意满足要求的答案都可以，不需要字典序最小
