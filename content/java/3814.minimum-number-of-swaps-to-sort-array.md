## 题目描述

给定各不相同的整数数组 `nums`，每次可交换任意两个元素，返回将数组排好序的最少交换次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minSwaps(int[] nums) {
        int n = nums.length;
        // 记录每个值排序后的目标位置
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        Map<Integer, Integer> pos = new HashMap<>();
        for (int i = 0; i < n; i++) pos.put(sorted[i], i);

        // 构建置换：perm[i] = 位置 i 的元素应去的位置
        int[] perm = new int[n];
        for (int i = 0; i < n; i++) perm[i] = pos.get(nums[i]);

        // 计算置换环的数量
        boolean[] visited = new boolean[n];
        int cycles = 0;
        for (int i = 0; i < n; i++) {
            if (visited[i]) continue;
            cycles++;
            int j = i;
            while (!visited[j]) {
                visited[j] = true;
                j = perm[j];
            }
        }
        // 最少交换次数 = n - 环的数量
        return n - cycles;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 置换环：长度为 k 的环需要 k-1 次交换
2. 总交换次数 = n - 置换环数量（含长度 1 的自环）
3. 先排序获取目标位置，再构建置换图
