## 题目描述

k个服务器处理请求，请求i优先分配给i%k号服务器，若忙则按编号顺序找下一个空闲服务器。返回处理最多请求的服务器列表。

## 解题思路

TreeSet存空闲服务器（支持ceiling查找），最小堆存忙碌服务器（按结束时间排序）。每个请求到达时先释放已完成的服务器。

## Java 代码实现

```java
class Solution {
    public List<Integer> busiestServers(int k, int[] arrival, int[] load) {
        // 空闲服务器（有序集合）
        TreeSet<Integer> available = new TreeSet<>();
        for (int i = 0; i < k; i++) available.add(i);
        // 忙碌服务器：(结束时间, 服务器编号)
        PriorityQueue<int[]> busy = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        int[] count = new int[k];
        
        for (int i = 0; i < arrival.length; i++) {
            int t = arrival[i];
            // 释放已完成的服务器
            while (!busy.isEmpty() && busy.peek()[0] <= t) {
                available.add(busy.poll()[1]);
            }
            if (available.isEmpty()) continue;
            
            int target = i % k;
            // 找编号 >= target 的最小空闲服务器
            Integer server = available.ceiling(target);
            if (server == null) {
                // 没有则取最小编号（环形）
                server = available.first();
            }
            available.remove(server);
            count[server]++;
            busy.offer(new int[]{t + load[i], server});
        }
        
        int maxCount = 0;
        for (int c : count) maxCount = Math.max(maxCount, c);
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            if (count[i] == maxCount) result.add(i);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log K)
- **空间复杂度**：O(K + N)

## 关键点总结

1. **TreeSet.ceiling()**：找>=target的最小值
2. **环形查找**：ceiling为null时取first()
3. **最小堆管理忙碌服务器**：按结束时间排序，到达时释放
