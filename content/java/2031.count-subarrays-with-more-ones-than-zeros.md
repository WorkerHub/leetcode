## 题目描述

给定二进制数组 `nums`，返回 1 的数量严格大于 0 的数量的子数组个数，结果对 10^9+7 取模。

## 解题思路

将 0 转为 -1，问题转为统计前缀和满足 `prefix[j] > prefix[i]`（i < j）的对数，用归并排序（逆序对变体）在 O(n log n) 内求解。

## Java 代码实现

### 方法一：归并排序（推荐）

```java
class Solution {
    private static final int MOD = 1_000_000_007;
    private long count = 0;

    public int countSubarrays(int[] nums) {
        int n = nums.length;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + (nums[i] == 1 ? 1 : -1);
        }
        count = 0;
        mergeSort(prefix, 0, n);
        return (int) (count % MOD);
    }

    private void mergeSort(int[] arr, int lo, int hi) {
        if (hi - lo <= 0) return;
        int mid = (lo + hi) / 2;
        mergeSort(arr, lo, mid);
        mergeSort(arr, mid + 1, hi);
        // 统计左半部分 < 右半部分的对数
        int j = mid + 1;
        for (int i = lo; i <= mid; i++) {
            while (j <= hi && arr[j] <= arr[i]) j++;
            count += (hi - j + 1);
        }
        // 合并
        int[] tmp = new int[hi - lo + 1];
        int p = lo, q = mid + 1, k = 0;
        while (p <= mid && q <= hi) {
            tmp[k++] = arr[p] <= arr[q] ? arr[p++] : arr[q++];
        }
        while (p <= mid) tmp[k++] = arr[p++];
        while (q <= hi) tmp[k++] = arr[q++];
        System.arraycopy(tmp, 0, arr, lo, tmp.length);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 0 转 -1 后，子数组 1 多于 0 等价于前缀和差 > 0
2. 归并排序统计 `prefix[i] < prefix[j]`（i < j）的对数
3. 结果对 10^9+7 取模
