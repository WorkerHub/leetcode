## 题目描述

给你一个整数数组 nums，返回 nums 中所有等差子序列的数目。

如果一个序列中至少有三个元素，并且任意两个相邻元素之间的差相同，则称该序列为等差序列。

- 例如，[1, 3, 5, 7, 9]、[7, 7, 7, 7] 和 [3, -1, -5, -9] 都是等差序列。
- 再例如，[1, 1, 2, 5, 7] 不是等差序列。

数组中的子序列是从数组中删除一些元素（也可能不删除）得到的一个序列。

- 例如，[2,5,10] 是 [1,2,1,2,4,1,5,10] 的一个子序列。

题目数据保证答案是一个 32-bit 整数。

**示例 1:**

```
输入: nums = [2,4,6,8,10]
输出: 7
解释: 所有的等差子序列为：
[2,4,6]
[4,6,8]
[6,8,10]
[2,4,6,8]
[4,6,8,10]
[2,4,6,8,10]
[2,6,10]
```

**示例 2:**

```
输入: nums = [7,7,7,7,7]
输出: 16
解释: 数组中的任意子序列都是等差子序列。
```

**提示:**

- 1 <= nums.length <= 1000
- -2^31 <= nums[i] <= 2^31 - 1

## 解题思路

这道题是 [413. Arithmetic Slices](https://leetcode.com/problems/arithmetic-slices/) 的进阶版，区别在于：
- 413 题要求连续子数组
- 本题要求子序列（可以不连续）

**动态规划 + 哈希表思路：**

定义 `dp[i][diff]` 表示以 `nums[i]` 结尾、公差为 `diff` 的等差子序列数量（包括长度为 2 的）。

**状态转移：**
- 对于每个位置 i，遍历所有 j < i
- 计算公差 `diff = nums[i] - nums[j]`
- 如果 `dp[j][diff]` 存在，说明可以将 `nums[i]` 加到以 `nums[j]` 结尾的等差序列后面
- `dp[i][diff] += dp[j][diff] + 1`
  - `dp[j][diff]`：所有以 j 结尾、公差为 diff 的序列（长度 >= 2）
  - `+1`：[nums[j], nums[i]] 这个新的长度为 2 的序列

**计数规则：**
- 只有长度 >= 3 的序列才计入答案
- 当 `dp[j][diff]` 存在时，将其加入答案（这些都是长度 >= 2 的，加上 nums[i] 后变成 >= 3）

## Java 代码实现

### 方法一：动态规划 + 哈希表（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfArithmeticSlices(int[] nums) {
        /**
         * 动态规划 + 哈希表
         * 时间复杂度: O(n^2)
         * 空间复杂度: O(n^2)
         * 注意：公差可能超出 int 范围（如 Integer.MIN_VALUE - Integer.MAX_VALUE），
         * 因此 diff 使用 long 类型作为 key
         */
        int n = nums.length;
        // dp[i] 是一个哈希表，key 是公差（long），value 是以 nums[i] 结尾的等差序列数量
        @SuppressWarnings("unchecked")
        Map<Long, Integer>[] dp = new HashMap[n];
        for (int i = 0; i < n; i++) {
            dp[i] = new HashMap<>();
        }

        int result = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                // 计算公差，使用 long 防止溢出
                long diff = (long) nums[i] - nums[j];

                // dp[j][diff] 表示以 j 结尾、公差为 diff 的序列数量（长度 >= 2）
                // 这些序列加上 nums[i] 后，变成长度 >= 3 的等差序列
                int countJ = dp[j].getOrDefault(diff, 0);
                result += countJ;

                // 更新 dp[i][diff]
                // dp[j][diff]: 以 j 结尾的等差序列，加上 nums[i]
                // +1: [nums[j], nums[i]] 这个长度为 2 的新序列
                dp[i].put(diff, dp[i].getOrDefault(diff, 0) + countJ + 1);
            }
        }

        return result;
    }
}
```

### 方法二：优化的动态规划（详细注释版）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfArithmeticSlices(int[] nums) {
        /**
         * 动态规划详细版
         * dp[i][diff] = 以 nums[i] 结尾、公差为 diff 的等差子序列数量
         */
        int n = nums.length;
        @SuppressWarnings("unchecked")
        Map<Long, Integer>[] dp = new HashMap[n];
        for (int i = 0; i < n; i++) {
            dp[i] = new HashMap<>();
        }

        int total = 0;

        for (int i = 1; i < n; i++) {  // 从第二个元素开始
            for (int j = 0; j < i; j++) {  // 遍历 i 之前的所有元素
                long diff = (long) nums[i] - nums[j];

                // 统计以 j 结尾、公差为 diff 的序列数量
                int countJ = dp[j].getOrDefault(diff, 0);

                // 这些序列加上 nums[i]，都变成了长度至少为 3 的等差序列
                total += countJ;

                // 更新 dp[i][diff]
                // 包括：
                // 1. 所有以 j 结尾的等差序列（加上 nums[i]）
                // 2. 新的长度为 2 的序列 [nums[j], nums[i]]
                dp[i].put(diff, dp[i].getOrDefault(diff, 0) + countJ + 1);
            }
        }

        return total;
    }
}
```

### 方法三：带详细追踪的版本（帮助理解）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfArithmeticSlices(int[] nums) {
        /**
         * 带追踪信息的版本，帮助理解
         */
        int n = nums.length;
        @SuppressWarnings("unchecked")
        Map<Long, Integer>[] dp = new HashMap[n];
        for (int i = 0; i < n; i++) {
            dp[i] = new HashMap<>();
        }

        int result = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                long diff = (long) nums[i] - nums[j];

                // dp[j][diff] 表示有多少个以 j 结尾、公差为 diff 的序列
                // 这些序列的长度都 >= 2
                int count = dp[j].getOrDefault(diff, 0);

                // 将这些序列加入结果
                // 因为它们加上 nums[i] 后，长度变成 >= 3
                result += count;

                // 更新 dp[i][diff]
                dp[i].put(diff, dp[i].getOrDefault(diff, 0) + count + 1);
            }
        }

        return result;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n^2)
- 外层循环 n 次
- 内层循环最多 n 次
- 哈希表操作 O(1)

**空间复杂度：** O(n^2)
- 最坏情况下，每个 dp[i] 中有 O(n) 个不同的公差
- 总共 n 个元素，所以是 O(n^2)

## 关键点总结

1. **DP 定义**：`dp[i][diff]` 包括长度为 2 的序列，便于递推
2. **计数时机**：只有当 `dp[j][diff] > 0` 时才计入结果（保证长度 >= 3）
3. **状态转移**：`dp[i][diff] += dp[j][diff] + 1`
4. **哈希表应用**：用于存储不同公差的序列数量
5. **long 防溢出**：公差 diff = nums[i] - nums[j] 可能超过 int 范围，必须用 long

## 易错点

1. **整数溢出**：
   ```java
   // 错误：int 类型可能溢出
   int diff = nums[i] - nums[j];

   // 正确：使用 long
   long diff = (long) nums[i] - nums[j];
   ```

2. **长度判断**：
   ```java
   // 错误：把长度为 2 的也计入
   result += dp[i].getOrDefault(diff, 0);

   // 正确：只计入长度 >= 3 的
   result += dp[j].getOrDefault(diff, 0);  // dp[j][diff] 表示长度 >= 2，加上 nums[i] 就 >= 3
   ```

3. **重复计数**：
   - 不要在更新 `dp[i][diff]` 时直接加入结果
   - 只在发现 `dp[j][diff] > 0` 时计入

4. **公差范围**：
   - 公差可能很大（跨越 long 范围的一半）
   - 不能用数组存储，只能用哈希表
