## 题目描述

树有 n 个节点，每个节点有标签（小写字母）。返回数组 ans[i] = 节点 i 子树中与 labels[i] 相同标签的节点数。

**示例：**
```
输入：n = 7, edges = [[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]], labels = "abaedcd"
输出：[2,1,1,1,1,1,1]
```

## 解题思路

DFS 后序遍历：每个节点返回子树中 26 个字母的频次数组，合并子节点结果后取自身标签的计数。

## Java 代码实现

```java
class Solution {
    public int[] countSubTrees(int n, int[][] edges, String labels) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        
        int[] ans = new int[n];
        dfs(0, -1, graph, labels, ans);
        return ans;
    }
    
    private int[] dfs(int node, int parent, List<List<Integer>> graph, String labels, int[] ans) {
        int[] count = new int[26];
        count[labels.charAt(node) - 'a'] = 1;
        
        for (int child : graph.get(node)) {
            if (child == parent) continue;
            int[] childCount = dfs(child, node, graph, labels, ans);
            for (int i = 0; i < 26; i++) count[i] += childCount[i];
        }
        
        ans[node] = count[labels.charAt(node) - 'a'];
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 26) = O(n)
- **空间复杂度**：O(n × 26)

## 关键点总结

1. **后序遍历**：先处理子节点再合并
2. **频次数组**：26 个字母的计数
3. **合并策略**：累加所有子节点的频次
4. **结果提取**：ans[node] = count[自身标签]
