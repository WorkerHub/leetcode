## 题目描述

构造长度为 n 的数组包含 1~n，使相邻元素差的绝对值恰好有 k 个不同值。

**示例：**
```
输入：n = 3, k = 2
输出：[1, 3, 2]（差值：2, 1，共2种）
```

## 解题思路

构造：前 n-k 个保持递增（只产生差值1），后 k+1 个交替取最小最大（产生 k 种差值）。

## Java 代码实现

```java
class Solution {
    public int[] constructArray(int n, int k) {
        int[] result = new int[n];

        // 前面部分递增：1, 2, ..., n-k
        for (int i = 0; i < n - k; i++) {
            result[i] = i + 1;
        }

        // 后面部分交替取最小和最大
        int left = n - k, right = n;
        for (int i = n - k; i < n; i++) {
            if ((i - (n - k)) % 2 == 0) {
                result[i] = right--;
            } else {
                result[i] = left++;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **递增部分**：只产生差值 1
2. **交替部分**：产生 k 种不同差值
3. **构造技巧**：前面固定，后面交替
