## 题目描述

给你字符串 `s` 和字符串数组 `words`，若 `s` 等于 `words` 中前若干个字符串的拼接则返回 `true`，否则返回 `false`。

## 解题思路

逐步拼接 words，超过 s 长度时返回 false，恰好相等时返回 true。

## Java 代码实现

```java
class Solution {
    public boolean isPrefixString(String s, String[] words) {
        StringBuilder cur = new StringBuilder();
        for (String word : words) {
            cur.append(word);
            if (cur.toString().equals(s)) return true;
            if (cur.length() > s.length()) return false;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 拼接超过 s 长度提前返回 false
2. 恰好等于 s 返回 true
3. 遍历完所有 words 仍未等于 s 返回 false
