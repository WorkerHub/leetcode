## 题目描述

给你两个长度为 n 的数组 `nums1` 和 `nums2`，可对 nums1 中的元素加减各至多 k1 次，对 nums2 加减至多 k2 次，使 `sum(|nums1[i]-nums2[i]|^2)` 最小，返回最小值。

## 解题思路

合并 `k = k1 + k2` 次操作（操作等价于减小差值）。构建差值数组，用桶排序从最大差值开始贪心减小：每次将最大差值批量减少到次大差值级别，直到用完操作次数。

## Java 代码实现

```java
class Solution {
    public long minSumOfSquaredDifferences(int[] nums1, int[] nums2, int k1, int k2) {
        int n = nums1.length;
        long k = (long) k1 + k2;
        int[] diff = new int[n];
        int maxDiff = 0;
        for (int i = 0; i < n; i++) {
            diff[i] = Math.abs(nums1[i] - nums2[i]);
            maxDiff = Math.max(maxDiff, diff[i]);
        }

        // 桶计数
        long[] bucket = new long[maxDiff + 1];
        for (int d : diff) bucket[d]++;

        // 贪心从最大差值开始减
        int cur = maxDiff;
        while (k > 0 && cur > 0) {
            if (bucket[cur] == 0) { cur--; continue; }
            long reduce = Math.min(k, bucket[cur]); // 本次最多减 reduce 个
            bucket[cur] -= reduce;
            bucket[cur - 1] += reduce;
            k -= reduce;
            if (bucket[cur] == 0) cur--;
        }

        long ans = 0;
        for (int i = 0; i <= maxDiff; i++) {
            ans += (long) i * i * bucket[i];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + maxDiff)，maxDiff 最大 10^5
- **空间复杂度**：O(maxDiff)

## 关键点总结

1. k1 和 k2 可合并为总操作数，本质都是减小某个位置的差值。
2. 桶排序+贪心：批量将最大差值下移到次大差值级别，避免逐一操作。
3. 计算最终答案时遍历桶数组，用 `long` 防止溢出。
