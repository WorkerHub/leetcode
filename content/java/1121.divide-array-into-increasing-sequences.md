## 题目描述

给定非递减整数数组 nums 和整数 K，判断能否将数组分成若干长度至少为 K 的不相交递增子序列。

**示例：**
```
输入：nums = [1,2,2,3,3,4,4], K = 3
输出：true
解释：可分为 [1,2,3,4] 和 [2,3,4]
```

## 解题思路

贪心/数学：出现频率最高的数字决定了至少需要多少个序列（因为相同数字不能在同一递增序列中），只需判断 `n >= maxFreq * K`。

## Java 代码实现

```java
class Solution {
    public boolean canDivideIntoSubsequences(int[] nums, int K) {
        int n = nums.length;
        int maxFreq = 1, currCount = 1;

        // 统计最大连续相同元素数（数组已排序）
        for (int i = 1; i < n; i++) {
            if (nums[i] == nums[i - 1]) {
                currCount++;
                maxFreq = Math.max(maxFreq, currCount);
            } else {
                currCount = 1;
            }
        }

        return n >= maxFreq * K;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心观察**：最大频率决定最少需要多少个序列
2. **必要充分条件**：`n >= maxFreq * K`
3. **数组已排序**：相同元素连续，一次遍历即可统计
