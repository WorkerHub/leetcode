## 题目描述

给你整数数组 `nums` 和正整数 `k`，返回所有**好下标**（下标 `i` 满足：前 `k` 个元素非递增且后 `k` 个元素非递减）组成的升序数组。

## 解题思路

预计算两个数组：`dec[i]` 表示以位置 `i` 结尾的非递增连续长度，`inc[i]` 表示以位置 `i` 开头的非递减连续长度。对下标 `i`，若 `dec[i-1] >= k` 且 `inc[i+1] >= k` 则为好下标。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> goodIndices(int[] nums, int k) {
        int n = nums.length;
        // dec[i] = 以 i 结尾的非递增连续长度
        int[] dec = new int[n];
        dec[0] = 1;
        for (int i = 1; i < n; i++) {
            dec[i] = (nums[i] <= nums[i - 1]) ? dec[i - 1] + 1 : 1;
        }
        // inc[i] = 以 i 开头的非递减连续长度
        int[] inc = new int[n];
        inc[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            inc[i] = (nums[i] <= nums[i + 1]) ? inc[i + 1] + 1 : 1;
        }

        List<Integer> ans = new ArrayList<>();
        for (int i = k; i < n - k; i++) {
            // i 前面 k 个非递增：dec[i-1] >= k
            // i 后面 k 个非递减：inc[i+1] >= k
            if (dec[i - 1] >= k && inc[i + 1] >= k) {
                ans.add(i);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 预计算 `dec[i]`（以 i 结尾的非递增长度）和 `inc[i]`（以 i 开头的非递减长度）
2. 好下标 i 的条件：`dec[i-1] >= k` 且 `inc[i+1] >= k`
3. 非递增/非递减均允许相等（使用 `<=`）
