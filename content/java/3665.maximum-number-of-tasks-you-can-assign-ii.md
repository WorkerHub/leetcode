## 题目描述

给你任务数组 `tasks`、工人数组 `workers`、药丸数量 `pills` 和药丸增益 `strength`。每个工人最多完成一个任务，能力 >= 难度方可完成，药丸可给工人加 strength 点能力。返回最多能完成的任务数量。

## 解题思路

二分答案 + 贪心验证：二分能完成的任务数 `mid`，验证时取最小的 `mid` 个任务和最强的 `mid` 个工人，从最难任务开始贪心分配（优先用直接够用的最弱工人，否则用药丸加强最弱工人）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxTaskAssign(int[] tasks, int[] workers, int pills, int strength) {
        Arrays.sort(tasks);
        Arrays.sort(workers);
        int n = tasks.length, m = workers.length;

        int lo = 0, hi = Math.min(n, m);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (canAssign(tasks, workers, pills, strength, mid, m)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean canAssign(int[] tasks, int[] workers, int pills, int strength, int mid, int m) {
        int p = pills;
        // 用最强的 mid 个工人，完成最简单的 mid 个任务
        TreeMap<Integer, Integer> pool = new TreeMap<>();
        for (int i = m - mid; i < m; i++) {
            pool.merge(workers[i], 1, Integer::sum);
        }

        for (int i = mid - 1; i >= 0; i--) { // 从最难任务开始
            int task = tasks[i];
            // 找能直接完成的最弱工人
            Integer key = pool.ceilingKey(task);
            if (key != null) {
                // 直接用该工人
                pool.merge(key, -1, Integer::sum);
                if (pool.get(key) == 0) pool.remove(key);
            } else {
                // 需要用药丸：找加了药丸后能完成的最弱工人
                if (p == 0) return false;
                Integer key2 = pool.ceilingKey(task - strength);
                if (key2 == null) return false;
                pool.merge(key2, -1, Integer::sum);
                if (pool.get(key2) == 0) pool.remove(key2);
                p--;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log(min(n,m)) * log(min(n,m)))
- 空间复杂度：O(min(n, m))

## 关键点总结

1. 二分最终完成任务数，验证时贪心分配
2. 从最难任务开始：优先直接分配，不足时用药丸加强最弱工人
3. TreeMap 提供 O(log n) 的有序集合操作
