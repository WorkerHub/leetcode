## 题目描述

无向图中边被细分为若干新节点。从节点 0 出发最多走 maxMoves 步，返回可到达的节点总数（包括原始节点和细分节点）。

**示例：**
```
输入：edges = [[0,1,10],[0,2,1],[1,2,2]], maxMoves = 6, n = 3
输出：13
```

## 解题思路

Dijkstra 最短路：计算到每个原始节点的最短距离，然后统计能到达的原始节点和边上的细分节点。

## Java 代码实现

```java
class Solution {
    public int reachableNodes(int[][] edges, int maxMoves, int n) {
        // 构建邻接表
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        // Dijkstra
        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 0});

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int d = curr[0], u = curr[1];
            if (d > dist[u]) continue;
            for (int[] edge : graph[u]) {
                int v = edge[0], cnt = edge[1];
                int newDist = d + cnt + 1;
                if (newDist < dist[v]) {
                    dist[v] = newDist;
                    pq.offer(new int[]{newDist, v});
                }
            }
        }

        // 统计可达的原始节点
        int result = 0;
        for (int i = 0; i < n; i++) {
            if (dist[i] <= maxMoves) result++;
        }

        // 统计可达的细分节点
        for (int[] e : edges) {
            int u = e[0], v = e[1], cnt = e[2];
            int fromU = dist[u] <= maxMoves ? maxMoves - dist[u] : 0;
            int fromV = dist[v] <= maxMoves ? maxMoves - dist[v] : 0;
            result += Math.min(cnt, fromU + fromV);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((V + E) log V)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **Dijkstra**：计算到所有原始节点的最短路
2. **细分节点统计**：从边两端分别能覆盖多少细分节点
3. **不超过边长**：min(cnt, fromU + fromV)
