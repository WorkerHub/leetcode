## 题目描述

统计在两个数组中都恰好出现一次的单词数目。

## 解题思路

分别用HashMap统计两个数组中各单词频次，找出两边频次都为1的单词。

## Java 代码实现

```java
class Solution {
    public int countWords(String[] words1, String[] words2) {
        Map<String, Integer> c1 = new HashMap<>();
        Map<String, Integer> c2 = new HashMap<>();
        for (String w : words1) c1.merge(w, 1, Integer::sum);
        for (String w : words2) c2.merge(w, 1, Integer::sum);
        
        int count = 0;
        for (Map.Entry<String, Integer> e : c1.entrySet()) {
            if (e.getValue() == 1 && c2.getOrDefault(e.getKey(), 0) == 1) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(N + M)

## 关键点总结

1. **分别统计频次**：两个HashMap
2. **双重条件**：两边都恰好出现1次
3. **getOrDefault**：不存在时返回0
