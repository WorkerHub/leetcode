## 题目描述

给定整数数组 `nums` 和整数 `k`，若子数组中任意两个质数之差的绝对值不超过 `k`，则称该子数组"质数差平衡"，返回满足条件的子数组数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countSubarrays(int[] nums, int k) {
        int n = nums.length;
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // 埃氏筛
        boolean[] isPrime = new boolean[maxVal + 1];
        Arrays.fill(isPrime, true);
        if (maxVal >= 0) isPrime[0] = false;
        if (maxVal >= 1) isPrime[1] = false;
        for (int i = 2; (long) i * i <= maxVal; i++) {
            if (isPrime[i]) for (int j = i * i; j <= maxVal; j += i) isPrime[j] = false;
        }

        // 单调队列维护窗口内质数的最大值和最小值
        Deque<Integer> maxDq = new ArrayDeque<>();  // 存下标，单调递减
        Deque<Integer> minDq = new ArrayDeque<>();  // 存下标，单调递增
        int left = 0;
        long ans = 0;

        for (int right = 0; right < n; right++) {
            if (isPrime[nums[right]]) {
                while (!maxDq.isEmpty() && nums[maxDq.peekLast()] <= nums[right]) maxDq.pollLast();
                maxDq.offerLast(right);
                while (!minDq.isEmpty() && nums[minDq.peekLast()] >= nums[right]) minDq.pollLast();
                minDq.offerLast(right);
            }

            // 收缩左边界，使 max - min <= k
            while (!maxDq.isEmpty() && !minDq.isEmpty()
                    && nums[maxDq.peekFirst()] - nums[minDq.peekFirst()] > k) {
                if (maxDq.peekFirst() == left) maxDq.pollFirst();
                if (minDq.peekFirst() == left) minDq.pollFirst();
                left++;
            }
            ans += (right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + maxVal)，滑动窗口 + 埃氏筛
- 空间复杂度：O(maxVal)

## 关键点总结

1. 平衡条件等价于窗口内质数的最大值 - 最小值 <= k
2. 滑动窗口：右端点固定时，找最小合法左端点，贡献 `right - left + 1`
3. 非质数元素不影响平衡条件，只关注质数的极值
