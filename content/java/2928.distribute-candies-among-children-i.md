## 题目描述

将n颗糖分给3个小朋友，每人至多limit颗，求方案数。（n,limit<=50）

## 解题思路

数据范围小，枚举前两个小朋友的分配，第三个自动确定，检查是否合法。

## Java 代码实现

```java
class Solution {
    public int distributeCandies(int n, int limit) {
        int count = 0;
        for (int a = 0; a <= Math.min(n, limit); a++) {
            for (int b = 0; b <= Math.min(n - a, limit); b++) {
                int c = n - a - b;
                if (c >= 0 && c <= limit) count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(limit^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举前两人**：第三人由总和确定
2. **合法性检查**：c在[0, limit]范围内
3. **数据范围小**：暴力枚举可行
