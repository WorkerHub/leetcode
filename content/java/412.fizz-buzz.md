## 题目描述

给你一个整数 n，找出从 1 到 n 各个整数的 Fizz Buzz 表示，并用字符串数组返回。

其中：
- 如果 i 能被 3 和 5 整除，输出 "FizzBuzz"
- 如果 i 能被 3 整除，输出 "Fizz"
- 如果 i 能被 5 整除，输出 "Buzz"
- 如果上述条件都不满足，输出 i 的字符串表示

**示例 1：**
```
输入：n = 3
输出：["1","2","Fizz"]
```

**示例 2：**
```
输入：n = 5
输出：["1","2","Fizz","4","Buzz"]
```

**示例 3：**
```
输入：n = 15
输出：["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]
```

## Java 代码实现

### 方法一：条件判断（推荐）

```java
import java.util.*;

class Solution {
    public List<String> fizzBuzz(int n) {
        // 条件判断，注意先判断 15
        List<String> result = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (i % 15 == 0) {
                result.add("FizzBuzz");
            } else if (i % 3 == 0) {
                result.add("Fizz");
            } else if (i % 5 == 0) {
                result.add("Buzz");
            } else {
                result.add(String.valueOf(i));
            }
        }
        return result;
    }
}
```

### 方法二：字符串拼接

```java
import java.util.*;

class Solution {
    public List<String> fizzBuzz(int n) {
        // 字符串拼接，更灵活，易于扩展
        List<String> result = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            StringBuilder sb = new StringBuilder();
            if (i % 3 == 0) sb.append("Fizz");
            if (i % 5 == 0) sb.append("Buzz");
            // 若字符串为空，则使用数字
            result.add(sb.length() > 0 ? sb.toString() : String.valueOf(i));
        }
        return result;
    }
}
```

### 方法三：Stream 流式写法

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public List<String> fizzBuzz(int n) {
        // 使用 Stream 流式处理
        return IntStream.rangeClosed(1, n)
            .mapToObj(i ->
                i % 15 == 0 ? "FizzBuzz" :
                i % 3 == 0  ? "Fizz" :
                i % 5 == 0  ? "Buzz" :
                String.valueOf(i)
            )
            .collect(Collectors.toList());
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计结果数组）

## 关键点总结

1. 注意判断顺序：先判断 15，再判断 3 和 5
2. 字符串拼接方法更灵活，易于扩展

## 易错点

1. 判断顺序错误（先判断 3 或 5 会遗漏 15 的情况）
2. 忘记转换数字为字符串
