## 题目描述

给定整数数组 `nums` 和查询列表，每个查询将区间 `[l, r]` 中的元素替换为 `val`，返回操作后数组中不同质数的个数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maximizeDistinctPrimes(int[] nums, int[][] queries) {
        int MAX_VAL = 1_000_001;
        // 埃氏筛预处理质数
        boolean[] isPrime = new boolean[MAX_VAL];
        Arrays.fill(isPrime, true);
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; (long) i * i < MAX_VAL; i++) {
            if (isPrime[i]) {
                for (int j = i * i; j < MAX_VAL; j += i) isPrime[j] = false;
            }
        }

        int n = nums.length;
        int[] arr = Arrays.copyOf(nums, n);
        int[] result = new int[queries.length];

        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1], val = queries[q][2];
            // 将区间 [l, r] 中的元素替换为 val
            for (int i = l; i <= r; i++) arr[i] = val;
            // 统计不同质数个数
            Set<Integer> primes = new HashSet<>();
            for (int x : arr) {
                if (isPrime[x]) primes.add(x);
            }
            result[q] = primes.size();
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(MAX_VAL + q * n)，埃氏筛 + 每次查询暴力统计
- 空间复杂度：O(MAX_VAL + n)

## 关键点总结

1. 埃氏筛预处理所有质数，范围覆盖值域上限
2. 区间更新后统计全数组不同质数（集合去重）
3. 用 `long` 防止筛法中 `i * i` 溢出
