## 题目描述

计算每个长度为k的子数组中不同整数的数目。

## 解题思路

滑动窗口+频率哈希表：窗口右移时加入新元素更新计数，左移时移除旧元素更新计数。

## Java 代码实现

```java
class Solution {
    public int[] distinctNumbers(int[] nums, int k) {
        int n = nums.length;
        int[] result = new int[n - k + 1];
        Map<Integer, Integer> freq = new HashMap<>();
        int distinct = 0;
        
        for (int i = 0; i < n; i++) {
            // 加入右端元素
            freq.merge(nums[i], 1, Integer::sum);
            if (freq.get(nums[i]) == 1) distinct++;
            
            // 移除超出窗口的左端元素
            if (i >= k) {
                int left = nums[i - k];
                freq.merge(left, -1, Integer::sum);
                if (freq.get(left) == 0) distinct--;
            }
            
            // 窗口大小达到k时记录
            if (i >= k - 1) {
                result[i - k + 1] = distinct;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(K)

## 关键点总结

1. **滑动窗口**：维护频率表和不同数计数
2. **频率为0时减计数**：只在频率降到0时distinct--
3. **HashMap.merge**：简化频率更新
