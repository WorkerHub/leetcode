## 题目描述

给定正整数 `num`，返回 `[1, num]` 中各位数字之和为偶数的整数数量。

## Java 代码实现

```java
class Solution {
    public int countEven(int num) {
        // num 的各位之和为偶数则有 num/2 个，否则有 (num-1)/2 个
        int digitSum = 0;
        int temp = num;
        while (temp > 0) {
            digitSum += temp % 10;
            temp /= 10;
        }
        return digitSum % 2 == 0 ? num / 2 : (num - 1) / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)，计算各位之和
- 空间复杂度：O(1)

## 关键点总结

1. 数学规律：`[1, num]` 中约一半整数字和为偶数
2. 若 `num` 字和为偶数，则满足条件的有 `num / 2` 个；否则有 `(num - 1) / 2` 个
