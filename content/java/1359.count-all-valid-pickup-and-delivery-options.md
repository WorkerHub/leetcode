## 题目描述

给你 `n` 笔订单，每笔订单都需要快递服务。

计算所有有效的取件/配送序列的数目，使得配送操作 `D_i` 总是在取件操作 `P_i` 之后进行。

答案由于很大，请返回对 `10^9 + 7` 取模后的结果。

**示例 1：**
```
输入：n = 1
输出：1
解释：只有一种序列：(P1, D1)
```

**示例 2：**
```
输入：n = 2
输出：6
解释：所有序列：
(P1,P2,D1,D2), (P1,P2,D2,D1), (P1,D1,P2,D2),
(P2,P1,D1,D2), (P2,P1,D2,D1), (P2,D2,P1,D1)
共 6 种。
注意不能是 (P1,D2,P2,D1)，因为 D2 在 P2 之前。
```

**示例 3：**
```
输入：n = 3
输出：90
```

**提示：**
- `1 <= n <= 500`

## 解题思路

**递推/数学推导：**

考虑逐步插入每一对 (P_i, D_i)：

当已经安排了 `i-1` 对订单（2(i-1) 个位置），现在要插入第 `i` 对。

**先插入 P_i：** 可以放在 `2(i-1)+1 = 2i-1` 个间隙中（包括两端）。

**再插入 D_i：** D_i 必须在 P_i 后面。P_i 放在第 k 个位置时，D_i 可以放在 P_i 后面的 `2i-k` 个位置中。

**关键公式：**

对于插入第 i 对，P_i 和 D_i 的总放置方案数：

```
sum_{k=1}^{2i-1} (2i - k) = (2i-1) + (2i-2) + ... + 1 = i * (2i-1)
```

所以：`f(i) = f(i-1) * i * (2i-1)`

**验证：**
- n=1: 1*1 = 1
- n=2: 1 * (2*3) = 6
- n=3: 1 * 6 * (3*5) = 90

## Java 代码实现

### 方法一：数学公式（推荐，最优）

```java
class Solution {
    public int countOrders(int n) {
        long MOD = 1_000_000_007L;
        long ans = 1;
        for (int i = 1; i <= n; i++) {
            // 插入第 i 对时，可选的方案数为 i * (2i-1)
            ans = ans * i % MOD * (2 * i - 1) % MOD;
        }
        return (int) ans;
    }
}
```

### 方法二：动态规划（从 n=1 递推）

```java
class Solution {
    public int countOrders(int n) {
        long MOD = 1_000_000_007L;
        // dp[i] 表示 i 对订单的有效序列数
        long[] dp = new long[n + 1];
        dp[1] = 1; // 只有 (P1, D1) 一种
        
        for (int i = 2; i <= n; i++) {
            // 在 2(i-1) 个已排好的位置中插入第 i 对
            // 总方案数 = dp[i-1] * i * (2i-1)
            dp[i] = dp[i - 1] * i % MOD * (2 * i - 1) % MOD;
        }
        
        return (int) dp[n];
    }
}
```

### 方法三：组合数学（全排列 / 2^n）

```java
class Solution {
    public int countOrders(int n) {
        /**
         * 另一种推导：
         * 2n 个元素全排列共 (2n)! 种。
         * 对于每对 (Pi, Di)，Pi 必须在 Di 之前，
         * 所以每对有一半的排列满足条件，共 n 对。
         * 答案 = (2n)! / 2^n
         */
        long MOD = 1_000_000_007L;
        
        // 计算 (2n)! mod p
        long numerator = 1;
        for (int i = 1; i <= 2 * n; i++) {
            numerator = numerator * i % MOD;
        }
        
        // 计算 2^n mod p
        long denominator = 1;
        for (int i = 0; i < n; i++) {
            denominator = denominator * 2 % MOD;
        }
        
        // 模逆元：a / b mod p = a * b^(p-2) mod p（费马小定理，p 为质数）
        long denominatorInv = pow(denominator, MOD - 2, MOD);
        
        return (int) (numerator * denominatorInv % MOD);
    }
    
    // 快速幂
    private long pow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(N)，循环 n 次。
- 空间复杂度：O(1)（方法一）或 O(N)（方法二 DP 数组）。

## 推导过程详解

用具体例子理解递推：

**n=2 时的插入过程：**

初始：(P1, D1) — 1 种排列，位置为：`_ P1 _ D1 _`（3 个间隙）

插入 P2：可以放在 3 个间隙的任意一个：
- `P2 P1 D1`（间隙 1）
- `P1 P2 D1`（间隙 2）
- `P1 D1 P2`（间隙 3）

对每种 P2 位置，插入 D2（必须在 P2 后）：
- P2 在间隙 1：D2 有 3 个位置（P2 后的所有间隙）
- P2 在间隙 2：D2 有 2 个位置
- P2 在间隙 3：D2 有 1 个位置

总方案数 = 3+2+1 = 6 = 2*(2*2-1) = 2*3 = 6

## 关键点总结

1. **递推公式**：`ans = product_{i=1}^{n} i*(2i-1)`，每步乘以第 i 对的插入方案数。
2. **组合意义**：`i*(2i-1)` 等于将 P_i 放入 2i-1 个位置后，D_i 在 P_i 之后所有可能位置数的总和。
3. **等价公式**：`ans = (2n)! / 2^n`，全排列除以每对 (Pi,Di) 的相对顺序选择数。
4. **取模运算**：每次乘法后立即取模，防止 long 溢出。
5. **模逆元**：方法三中除以 `2^n` 需要用费马小定理计算模逆元。

## 易错点

- 取模要在每次乘法后进行（使用 `long` 类型，两个不超过 10^9+6 的数相乘不超过 long 范围）。
- 方法三中直接计算 `(2n)! / 2^n` 不取模再相除是错误的，必须在模运算下进行（用模逆元代替直接除法）。
- 递推时 `i` 从 1 开始，`i=1` 时 `i*(2i-1) = 1*1 = 1`，即只有 1 对时只有 1 种排列，正确。
