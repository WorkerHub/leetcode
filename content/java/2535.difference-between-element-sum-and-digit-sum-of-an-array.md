## 题目描述

给你正整数数组 `nums`，返回元素和（所有元素之和）与数字和（所有元素各位数字之和）的绝对差。

## 解题思路

一次遍历同时累加元素和与数字和，逐位取模提取各位数字。

## Java 代码实现

```java
class Solution {
    public int differenceOfSum(int[] nums) {
        int elementSum = 0, digitSum = 0;
        for (int n : nums) {
            elementSum += n;
            // 逐位提取并累加
            int temp = n;
            while (temp > 0) {
                digitSum += temp % 10;
                temp /= 10;
            }
        }
        return Math.abs(elementSum - digitSum);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * d)，d 为最大位数（本题 d <= 4）
- **空间复杂度**：O(1)

## 关键点总结

1. 数字和是各元素每一位数字之和，而非元素本身之和
2. 元素和 >= 数字和（多位数贡献减少），差值非负
3. 逐位取模 `% 10` 和整除 `/ 10` 是提取各位的标准方法
