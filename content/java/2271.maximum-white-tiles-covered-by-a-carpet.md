## 题目描述

多段白色瓷砖区间，一块地毯长carpetLen，求地毯最多能覆盖多少白色格子。

## 解题思路

排序+前缀和+二分：地毯左端对齐某瓷砖起点最优。枚举每块瓷砖作为起点，二分找最后被覆盖的瓷砖，计算覆盖数（最后一块可能部分覆盖）。

## Java 代码实现

```java
class Solution {
    public int maximumWhiteTiles(int[][] tiles, int carpetLen) {
        Arrays.sort(tiles, (a, b) -> a[0] - b[0]);
        int n = tiles.length;
        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + tiles[i][1] - tiles[i][0] + 1;
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            int end = tiles[i][0] + carpetLen - 1;
            // 二分找最后一块左端点<=end的瓷砖
            int lo = i, hi = n - 1;
            while (lo < hi) {
                int mid = (lo + hi + 1) >>> 1;
                if (tiles[mid][0] <= end) lo = mid;
                else hi = mid - 1;
            }
            int j = lo;
            long covered = prefix[j + 1] - prefix[i];
            // 最后一块可能部分超出
            if (tiles[j][1] > end) {
                covered -= tiles[j][1] - end;
            }
            ans = Math.max(ans, (int) covered);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心**：地毯左端对齐瓷砖起点最优
2. **二分**：快速找到最后被覆盖的瓷砖
3. **部分覆盖处理**：最后一块超出部分需减去
