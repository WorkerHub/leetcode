## 题目描述

给你两个整数数组 `profit` 和 `loss` 及整数 `k`，可以交换 `profit[i]` 和 `loss[j]`（任意 i、j）最多 k 次，目标是最大化 `sum(profit) - sum(loss)`。

## 解题思路

贪心：每次交换 `profit[i]` 和 `loss[j]`，目标值变化量为 `2 * (loss[j] - profit[i])`。贪心选使增益最大的 k 对，即 loss 从大到小、profit 从小到大配对，只要增益 > 0 就交换。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maxProfit(int[] profit, int[] loss, int k) {
        long base = 0;
        for (int p : profit) base += p;
        for (int l : loss) base -= l;

        // 贪心：loss最大的k个 vs profit最小的k个配对
        Arrays.sort(profit);
        int[] sortedLoss = loss.clone();
        Arrays.sort(sortedLoss);
        // sortedLoss逆序遍历（最大值）
        int n = sortedLoss.length;
        for (int i = 0; i < k; i++) {
            long gain = 2L * (sortedLoss[n - 1 - i] - profit[i]);
            if (gain <= 0) break; // 后续增益更小，不再交换
            base += gain;
        }
        return base;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 每次交换增益 = `2 * (loss[j] - profit[i])`
2. 贪心：loss 最大 vs profit 最小配对，增益最大
3. 只有增益 > 0 时才值得交换
