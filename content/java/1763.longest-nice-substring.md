## 题目描述

给你字符串 `s`，若字符串中每种字母的大小写形式同时出现则称为"美好字符串"。返回 `s` 中最长的美好子字符串（多个最长取最早出现的）。

## 解题思路

分治：找第一个"大小写不同时出现"的字符，以其为分割点递归处理两侧，返回较长（等长取左）的结果。

## Java 代码实现

```java
class Solution {
    public String longestNiceSubstring(String s) {
        if (s.length() < 2) return "";

        // 找第一个不满足条件的字符（大小写只有一种）
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            // 判断 c 的大小写是否都在 s 中
            if (s.indexOf(Character.toLowerCase(c)) == -1 ||
                s.indexOf(Character.toUpperCase(c)) == -1) {
                // 以 i 为分割点，递归左右两部分
                String left = longestNiceSubstring(s.substring(0, i));
                String right = longestNiceSubstring(s.substring(i + 1));
                return left.length() >= right.length() ? left : right;
            }
        }

        // 所有字符都满足条件，整个字符串是美好的
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n)，递归栈

## 关键点总结

1. 分治：以不满足条件的字符为分割点，递归两侧
2. 等长时返回左侧（更早出现）
