## 题目描述

给定只包含 0 和 1 的网格，找出由 1 形成的角矩形数量。角矩形由四个不同位置的 1 构成矩形的四个角。

**示例：**
```
输入：grid = [[1,0,0,1,0],[0,0,1,0,1],[0,0,0,1,0],[1,0,1,0,1]]
输出：1
```

## 解题思路

枚举行对：对每对行统计同时为 1 的列数 matches，从中选 2 列组成矩形的数量为 C(matches, 2)。

## Java 代码实现

```java
class Solution {
    public int countCornerRectangles(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int count = 0;

        for (int r1 = 0; r1 < m; r1++) {
            for (int r2 = r1 + 1; r2 < m; r2++) {
                // 统计两行中同时为 1 的列数
                int matches = 0;
                for (int c = 0; c < n; c++) {
                    if (grid[r1][c] == 1 && grid[r2][c] == 1) {
                        matches++;
                    }
                }
                // C(matches, 2) = matches * (matches - 1) / 2
                count += matches * (matches - 1) / 2;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × n)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举行对**：固定两行，统计列匹配
2. **组合计数**：matches 列中选 2 列 = C(matches, 2)
3. **优化思路**：可以用哈希表存列对计数
