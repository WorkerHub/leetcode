## 题目描述

已知 n+m 次骰子投掷的平均值为 `mean`，已记录 m 次结果（`rolls` 数组），找出另外 n 次的结果（每次 1~6）使平均值满足要求，不存在则返回空数组。

## 解题思路

计算 n 次的目标总和 `need = mean*(n+m) - sum(rolls)`，验证 `n <= need <= 6n`，均匀分配：基础值 `need/n`，前 `need%n` 个各加 1。

## Java 代码实现

### 方法一：均匀分配（推荐）

```java
class Solution {
    public int[] missingRolls(int[] rolls, int mean, int n) {
        int m = rolls.length;
        int total = mean * (n + m);
        int rollsSum = 0;
        for (int r : rolls) rollsSum += r;
        int need = total - rollsSum; // n次观测的目标总和

        // 验证合法性
        if (need < n || need > 6 * n) return new int[0];

        int base = need / n;
        int remainder = need % n;
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            result[i] = base + (i < remainder ? 1 : 0);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n)

## 关键点总结

1. `need = mean*(n+m) - sum(rolls)`，验证 `n <= need <= 6n`
2. 均匀分配：`base = need/n`，前 `need%n` 个值为 `base+1`
3. 所有分配值均在 [1,6] 范围内
