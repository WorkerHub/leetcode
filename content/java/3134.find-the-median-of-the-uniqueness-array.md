## 题目描述

返回所有非空子数组的不同元素个数组成的数组的中位数。

## 解题思路

二分答案k，用滑动窗口统计不同元素<=k的子数组数量，找最小k使该数量>=中位数下标((total+1)/2)。

## Java 代码实现

```java
class Solution {
    public int medianOfUniquenessArray(int[] nums) {
        int n = nums.length;
        long total = (long) n * (n + 1) / 2;
        long target = (total + 1) / 2;

        int lo = 1, hi = n;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (countAtMost(nums, mid) >= target) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    // 统计不同元素数<=k的子数组数量
    private long countAtMost(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> freq = new HashMap<>();
        int distinct = 0, left = 0;
        long result = 0;
        for (int right = 0; right < n; right++) {
            freq.merge(nums[right], 1, Integer::sum);
            if (freq.get(nums[right]) == 1) distinct++;
            while (distinct > k) {
                freq.merge(nums[left], -1, Integer::sum);
                if (freq.get(nums[left]) == 0) distinct--;
                left++;
            }
            result += right - left + 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **二分答案k**：找最小k使count(<=k)>=target
2. **滑动窗口统计**：不同元素>k时收缩左端
3. **中位数下标=(total+1)/2**
