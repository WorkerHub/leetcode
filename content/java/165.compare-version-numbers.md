## 题目描述

给你两个版本号 `version1` 和 `version2`，请你比较它们。

版本号由一个或多个修订号组成，各修订号由一个 `'.'` 连接。每个修订号由多位数字组成，可能包含前导零。每个版本号至少包含一个字符。修订号从左到右编号，下标从 0 开始，最左边的修订号下标为 0，下一个修订号下标为 1，以此类推。例如 `2.5.33` 和 `0.1` 都是有效的版本号。

比较版本号时，请按从左到右的顺序依次比较它们的修订号。比较修订号时，只需比较忽略任何前导零后的整数值。也就是说，修订号 `1` 和修订号 `001` 相等。如果版本号没有指定某个下标处的修订号，则该修订号视为 0。例如，版本 `1.0` 小于版本 `1.1`，因为它们下标为 0 的修订号相同，而下标为 1 的修订号分别为 0 和 1，0 < 1。

返回规则如下：
- 如果 `version1 > version2` 返回 `1`
- 如果 `version1 < version2` 返回 `-1`
- 除此之外返回 `0`

**示例 1：**
```
输入：version1 = "1.01", version2 = "1.001"
输出：0
解释：忽略前导零，"01" 和 "001" 都表示相同的整数 "1"
```

**示例 2：**
```
输入：version1 = "1.0", version2 = "1.0.0"
输出：0
解释：version1 没有指定下标为 2 的修订号，即视为 "0"
```

**示例 3：**
```
输入：version1 = "0.1", version2 = "1.1"
输出：-1
解释：version1 中下标为 0 的修订号是 "0"，version2 中下标为 0 的修订号是 "1"。0 < 1，所以 version1 < version2
```

**提示：**
- 1 <= version1.length, version2.length <= 500
- version1 和 version2 仅包含数字和 '.'
- version1 和 version2 都是有效版本号
- version1 和 version2 的所有修订号都可以存储在 32 位整数中

## 解题思路

这道题的核心是模拟版本号比较的过程。

**关键点：**

1. **分割版本号**：用 `'.'` 分割字符串得到各个修订号
2. **忽略前导零**：将修订号转换为整数自动忽略前导零
3. **长度不同**：较短的版本号缺失的修订号视为 0
4. **逐段比较**：从左到右依次比较每个修订号

**算法流程：**

1. 按 `'.'` 分割两个版本号
2. 从左到右逐个比较修订号：
   - 将修订号转为整数（自动忽略前导零）
   - 如果某个版本号没有该位置的修订号，视为 0
   - 比较两个整数
3. 如果某个修订号不相等，立即返回结果
4. 如果所有修订号都相等，返回 0

## Java 代码实现

### 方法一：分割 + 逐段比较（推荐）⭐

```java
class Solution {
    public int compareVersion(String version1, String version2) {
        // 按 '.' 分割版本号（注意 Java 中需转义点号）
        String[] v1 = version1.split("\\.");
        String[] v2 = version2.split("\\.");

        int maxLen = Math.max(v1.length, v2.length);

        // 逐段比较
        for (int i = 0; i < maxLen; i++) {
            // 获取修订号，缺失的视为 0
            int num1 = (i < v1.length) ? Integer.parseInt(v1[i]) : 0;
            int num2 = (i < v2.length) ? Integer.parseInt(v2[i]) : 0;

            // 比较
            if (num1 < num2) return -1;
            if (num1 > num2) return 1;
        }

        // 所有修订号都相等
        return 0;
    }
}
```

### 方法二：双指针（不分割字符串）

```java
class Solution {
    public int compareVersion(String version1, String version2) {
        int n = version1.length(), m = version2.length();
        int i = 0, j = 0;

        while (i < n || j < m) {
            // 提取 version1 的下一个修订号
            int num1 = 0;
            while (i < n && version1.charAt(i) != '.') {
                num1 = num1 * 10 + (version1.charAt(i) - '0');
                i++;
            }
            i++; // 跳过 '.'

            // 提取 version2 的下一个修订号
            int num2 = 0;
            while (j < m && version2.charAt(j) != '.') {
                num2 = num2 * 10 + (version2.charAt(j) - '0');
                j++;
            }
            j++; // 跳过 '.'

            // 比较
            if (num1 < num2) return -1;
            if (num1 > num2) return 1;
        }

        return 0;
    }
}
```

### 方法三：填充到相同长度

```java
class Solution {
    public int compareVersion(String version1, String version2) {
        String[] v1 = version1.split("\\.");
        String[] v2 = version2.split("\\.");

        int maxLen = Math.max(v1.length, v2.length);

        // 填充到相同长度
        int[] nums1 = new int[maxLen];
        int[] nums2 = new int[maxLen];
        for (int i = 0; i < v1.length; i++) {
            nums1[i] = Integer.parseInt(v1[i]);
        }
        for (int i = 0; i < v2.length; i++) {
            nums2[i] = Integer.parseInt(v2[i]);
        }

        // 逐段比较
        for (int i = 0; i < maxLen; i++) {
            if (nums1[i] < nums2[i]) return -1;
            if (nums1[i] > nums2[i]) return 1;
        }

        return 0;
    }
}
```

## 复杂度分析

**方法一（分割）：**
- 时间复杂度：O(n + m)，其中 n 和 m 是两个版本号的长度
- 空间复杂度：O(n + m)，存储分割后的修订号数组

**方法二（双指针）：**
- 时间复杂度：O(n + m)
- 空间复杂度：O(1)，只使用常数额外空间

## 关键点总结

1. **分割字符串**：Java 中 `split("\\.")` 注意转义点号
2. **转换为整数**：`Integer.parseInt()` 自动忽略前导零
3. **处理长度差异**：较短版本号缺失部分视为 0
4. **逐段比较**：从左到右依次比较，一旦不等立即返回
5. **Java 特有注意**：`split(".")` 是错误的（`.` 是正则通配符），需用 `split("\\.")`

## 易错点

1. **正则表达式转义**：Java 的 `split` 方法使用正则，`.` 需写成 `\\.`
2. **前导零处理**：必须转为整数比较，不能直接比较字符串
3. **长度不同**：不能直接比较数组，需要处理长度差异
4. **返回值**：注意返回 1, -1, 0，不是 true/false
5. **字符转数字**：使用 `Character.getNumericValue()` 或 `- '0'`
