## 题目描述

给定整数 a 和 b，返回一个字符串 s，包含 a 个 'a' 和 b 个 'b'，且不含 "aaa" 或 "bbb" 子串。

**示例：**
```
输入：a = 1, b = 2
输出："abb"
```

## 解题思路

贪心：每次优先添加剩余数量多的字符，但若上两个字符相同则必须添加另一个字符，避免连续三个相同。

## Java 代码实现

```java
class Solution {
    public String strWithout3a3b(int a, int b) {
        StringBuilder sb = new StringBuilder();

        while (a > 0 || b > 0) {
            int len = sb.length();
            boolean writeA;

            if (len >= 2 && sb.charAt(len - 1) == sb.charAt(len - 2)) {
                // 上两个相同，必须写另一个
                writeA = sb.charAt(len - 1) == 'b';
            } else {
                // 写数量多的
                writeA = a >= b;
            }

            if (writeA) {
                sb.append('a');
                a--;
            } else {
                sb.append('b');
                b--;
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(a + b)
- **空间复杂度**：O(a + b)

## 关键点总结

1. **贪心选择**：优先放数量多的字符
2. **避免三连**：检查末尾两个字符是否相同
3. **保证有解**：题目保证输入有效
