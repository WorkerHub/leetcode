## 题目描述

给定字符串 `s` 和整数 `k`，从字符串开头算起，每 2k 个字符反转前 k 个字符。

**示例：**
```
输入: s = "abcdefg", k = 2
输出: "bacdfeg"
```

## 解题思路

步长 2k 遍历，每段反转前 k 个字符。

## Java 代码实现

```java
class Solution {
    public String reverseStr(String s, int k) {
        char[] arr = s.toCharArray();
        int n = arr.length;

        for (int i = 0; i < n; i += 2 * k) {
            int left = i;
            int right = Math.min(i + k - 1, n - 1);
            while (left < right) {
                char tmp = arr[left];
                arr[left] = arr[right];
                arr[right] = tmp;
                left++;
                right--;
            }
        }
        return new String(arr);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **步长 2k**：`for (int i = 0; i < n; i += 2 * k)`
2. **边界处理**：`Math.min(i + k - 1, n - 1)` 防止越界
3. **双指针反转**：原地交换字符
