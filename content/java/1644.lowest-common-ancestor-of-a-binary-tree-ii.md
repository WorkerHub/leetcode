## 题目描述

给定二叉树根节点 `root` 和两个节点 `p`、`q`，返回它们的最近公共祖先（LCA）。**与 236 题不同**：`p` 或 `q` 可能不在树中，若任一不在树中则返回 `null`。

## 解题思路

**DFS + 计数：** 用计数器记录找到 p 和 q 的数量，DFS 完成后若 found < 2 则返回 null。注意节点本身可能是另一个节点的祖先，遇到 p 或 q 后仍需继续遍历子树。

## Java 代码实现

```java
class Solution {
    private int found = 0; // 记录找到 p 和 q 的数量

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        found = 0;
        TreeNode result = dfs(root, p, q);
        return found == 2 ? result : null;
    }

    private TreeNode dfs(TreeNode node, TreeNode p, TreeNode q) {
        if (node == null) return null;

        TreeNode left = dfs(node.left, p, q);
        TreeNode right = dfs(node.right, p, q);

        // 若当前节点是 p 或 q，计数加 1
        if (node == p || node == q) {
            found++;
            // 子树中已找到 LCA，直接返回
            if (left != null || right != null) {
                return left != null ? left : right;
            }
            return node;
        }

        // 左右子树各找到一个，当前节点是 LCA
        if (left != null && right != null) return node;
        return left != null ? left : right;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历整棵树
- **空间复杂度**：O(h)，h 为树的高度

## 关键点总结

1. 与 236 题的关键区别：需要确认 p 和 q 都在树中
2. 遇到 p 或 q 后仍需继续遍历子树（节点本身可能是另一个的祖先）
3. DFS 结束后判断 found == 2，否则返回 null
