## 题目描述

给你正整数数组 `nums`，如果子数组中任意两个不同位置元素按位 AND 为 0，则称为优美子数组，返回最长优美子数组的长度。

## 解题思路

滑动窗口：用 `used` 记录窗口内所有数字已占用的位集合（按位 OR）。右指针右移时若 `nums[right] & used != 0` 则收缩左端（用 XOR 移除左端元素）直到无冲突，再加入右端元素。

## Java 代码实现

```java
class Solution {
    public int longestNiceSubarray(int[] nums) {
        int ans = 1, left = 0, used = 0;
        for (int right = 0; right < nums.length; right++) {
            // 当前数字与已占用位有重叠，收缩左端
            while ((used & nums[right]) != 0) {
                used ^= nums[left]; // 移除左端元素占用的位
                left++;
            }
            used |= nums[right];
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)（32 位整数最多 30 位，窗口最大 30 个元素）
- **空间复杂度**：O(1)

## 关键点总结

1. 优美子数组等价于窗口内所有元素的二进制位互不相交。
2. `used` 用按位 OR 维护窗口已占用的位，移除左端元素用 XOR（位不重叠时 XOR = 减法）。
3. 每个 32 位整数最多与 30 个其他整数互不重叠，窗口大小有上界。
