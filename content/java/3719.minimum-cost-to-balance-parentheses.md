## 题目描述

给定只含 `'('` 和 `')'` 的字符串 `s`，每次操作将一个括号换为另一种（代价为 1），返回使字符串变为有效括号序列的最小代价；若长度为奇数返回 `-1`。

## Java 代码实现

```java
class Solution {
    public int minCost(String s) {
        int n = s.length();
        if (n % 2 == 1) return -1;

        // 遍历统计多余的左括号和右括号
        int open = 0;   // 未匹配的 '('
        int extra = 0;  // 多余的 ')'
        for (char c : s.toCharArray()) {
            if (c == '(') {
                open++;
            } else {
                if (open > 0) open--; // 与前一个 '(' 匹配
                else extra++;         // 多余的 ')'
            }
        }

        // open 个多余的 '(' + extra 个多余的 ')'，每次操作消除 2 个不平衡
        return (open + extra) / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 奇数长度必然无法平衡，直接返回 -1
2. 贪心遍历：遇到 ')' 优先匹配已有的 '('，否则记为多余
3. 最终操作次数 = `(多余'(' + 多余')') / 2`，每次操作消除 2 个不平衡
