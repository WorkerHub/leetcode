## 题目描述

给定整数 `n` 和整数 `k`，翻转 `n` 的二进制表示中第 `k` 位（第 0 位是最低位），返回翻转后的结果。

## 解题思路

将 `n` 与 `1 << k` 进行异或（XOR）即可翻转第 `k` 位：该位为 0 则变为 1，为 1 则变为 0。

## Java 代码实现

```java
class Solution {
    public int flipBit(int n, int k) {
        // 将第 k 位翻转：与 (1 << k) 异或
        return n ^ (1 << k);
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. XOR 是翻转特定位的最简洁操作：`n ^ (1 << k)`
2. `1 << k` 生成只有第 k 位为 1 的掩码
3. k 最大 30，`1 << 30` 在 int 范围内
