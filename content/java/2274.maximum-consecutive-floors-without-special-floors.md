## 题目描述

楼层范围[bottom,top]中有特殊楼层，求没有特殊楼层的最长连续楼层段长度。

## 解题思路

将special排序，计算相邻特殊层之间以及首尾边界的空隙长度，取最大值。

## Java 代码实现

```java
class Solution {
    public int maxConsecutive(int bottom, int top, int[] special) {
        Arrays.sort(special);
        int ans = 0;
        // 首段
        ans = Math.max(ans, special[0] - bottom);
        // 中间段
        for (int i = 1; i < special.length; i++) {
            ans = Math.max(ans, special[i] - special[i - 1] - 1);
        }
        // 尾段
        ans = Math.max(ans, top - special[special.length - 1]);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后求间隔**：相邻特殊层间隔=special[i]-special[i-1]-1
2. **首尾边界**：首段=special[0]-bottom，尾段=top-special[-1]
3. **取最大间隔**
