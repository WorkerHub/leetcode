## 题目描述

请你设计一个迭代器，除了支持 `hasNext` 和 `next` 操作外，还支持 `peek` 操作。

实现 `PeekingIterator` 类：

- `PeekingIterator(Iterator<int> nums)` 使用指定整数迭代器 `nums` 初始化迭代器。
- `int next()` 返回数组中的下一个元素，并将指针移动到下个元素处。
- `bool hasNext()` 如果数组中存在下一个元素，返回 `true`；否则，返回 `false`。
- `int peek()` 返回数组中的下一个元素，但不移动指针。

**注意：** 每种语言可能有不同的构造函数和迭代器 `Iterator`，但均支持 `int next()` 和 `boolean hasNext()` 函数。

**示例 1:**

```
输入:
["PeekingIterator", "next", "peek", "next", "next", "hasNext"]
[[[1, 2, 3]], [], [], [], [], []]
输出:
[null, 1, 2, 2, 3, false]

解释:
PeekingIterator peekingIterator = new PeekingIterator([1, 2, 3]);
peekingIterator.next();    // 返回 1，指针移动到下一个元素 [1,2,3]
peekingIterator.peek();    // 返回 2，指针不移动 [1,2,3]
peekingIterator.next();    // 返回 2，指针移动到下一个元素 [1,2,3]
peekingIterator.next();    // 返回 3，指针移动到下一个元素 [1,2,3]
peekingIterator.hasNext(); // 返回 False
```

**提示:**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 1000`
- 对 `next` 和 `peek` 的调用均有效
- `next`、`hasNext` 和 `peek` 最多调用 `1000` 次

**进阶：** 你将如何拓展你的设计？使之变得通用化，从而适应所有的类型，而不只是整数型？

## 解题思路

这道题要求在标准迭代器的基础上增加 `peek` 功能。核心问题是如何在不移动迭代器指针的情况下查看下一个元素。

**核心思想：**

使用缓存（cache）机制：
1. 用一个变量缓存下一个要返回的元素
2. 用一个标志位表示缓存是否有效
3. `peek` 操作返回缓存值
4. `next` 操作返回缓存值并更新缓存
5. `hasNext` 检查缓存或底层迭代器

**关键观察：**

1. `peek` 需要看到下一个元素但不消费它
2. 可以提前调用一次 `next` 并缓存结果
3. 每次 `next` 后需要预先读取下一个元素到缓存

**两种设计思路：**

方法一：始终缓存下一个元素
- 初始化时就读取第一个元素到缓存
- `peek` 直接返回缓存
- `next` 返回缓存并更新缓存

方法二：按需缓存
- 只在调用 `peek` 时才缓存
- 使用标志位区分缓存是否有效

## Java 代码实现

### 方法一：预缓存法（推荐）

```java
import java.util.Iterator;

class PeekingIterator implements Iterator<Integer> {
    private Iterator<Integer> iterator;
    private Integer nextVal;  // 缓存下一个元素
    private boolean hasNextVal; // 是否有下一个元素

    public PeekingIterator(Iterator<Integer> iterator) {
        this.iterator = iterator;
        // 预读第一个元素
        if (iterator.hasNext()) {
            nextVal = iterator.next();
            hasNextVal = true;
        } else {
            hasNextVal = false;
        }
    }

    // 返回缓存的下一个元素，不移动指针
    public Integer peek() {
        return nextVal;
    }

    // 返回缓存的元素，并预读下一个元素
    @Override
    public Integer next() {
        Integer val = nextVal; // 保存当前缓存值

        // 更新缓存
        if (iterator.hasNext()) {
            nextVal = iterator.next();
            hasNextVal = true;
        } else {
            nextVal = null;
            hasNextVal = false;
        }

        return val;
    }

    @Override
    public boolean hasNext() {
        return hasNextVal;
    }
}
```

### 方法二：按需缓存法

```java
import java.util.Iterator;

class PeekingIterator implements Iterator<Integer> {
    private Iterator<Integer> iterator;
    private Integer peekedValue;  // 缓存的值
    private boolean hasPeeked;    // 是否已经 peek 过

    public PeekingIterator(Iterator<Integer> iterator) {
        this.iterator = iterator;
        this.hasPeeked = false;
    }

    // 如果没有缓存，就读取并缓存；否则返回缓存
    public Integer peek() {
        if (!hasPeeked) {
            peekedValue = iterator.next();
            hasPeeked = true;
        }
        return peekedValue;
    }

    // 如果有缓存，返回缓存并清空；否则调用底层 next
    @Override
    public Integer next() {
        if (hasPeeked) {
            Integer val = peekedValue;
            hasPeeked = false;
            peekedValue = null;
            return val;
        } else {
            return iterator.next();
        }
    }

    // 检查是否有缓存或底层迭代器是否有元素
    @Override
    public boolean hasNext() {
        return hasPeeked || iterator.hasNext();
    }
}
```

### 方法三：详细注释版（新手友好）

```java
import java.util.Iterator;

/**
 * 带 peek 功能的迭代器包装器
 *
 * 核心思想：
 * 1. 始终维护一个"缓冲区"，存储下一个要返回的元素
 * 2. peek() 只读取缓冲区，不修改状态
 * 3. next() 返回缓冲区的值，并从原迭代器读取新值填充缓冲区
 *
 * 状态变量：
 * - _next: 缓存的下一个元素值
 * - _hasNext: 是否还有下一个元素
 * - _iterator: 底层迭代器
 */
class PeekingIterator implements Iterator<Integer> {
    private Iterator<Integer> _iterator;
    private boolean _hasNext;
    private Integer _next;

    public PeekingIterator(Iterator<Integer> iterator) {
        // 保存底层迭代器
        _iterator = iterator;

        // 初始化缓存：预读第一个元素
        _hasNext = _iterator.hasNext();
        if (_hasNext) {
            _next = _iterator.next();
        }
    }

    /**
     * 返回下一个元素但不移动指针
     * 直接返回缓存值即可，因为我们始终维护了缓存
     */
    public Integer peek() {
        return _next;
    }

    /**
     * 返回下一个元素并移动指针
     *
     * 步骤：
     * 1. 保存当前缓存值（这就是要返回的值）
     * 2. 从底层迭代器读取新值更新缓存
     * 3. 返回保存的值
     */
    @Override
    public Integer next() {
        Integer current = _next; // 保存当前值

        // 更新缓存：从底层迭代器读取下一个值
        if (_iterator.hasNext()) {
            _next = _iterator.next();
            _hasNext = true;
        } else {
            _next = null;
            _hasNext = false;
        }

        return current;
    }

    /**
     * 判断是否还有下一个元素
     * 直接返回缓存标志即可
     */
    @Override
    public boolean hasNext() {
        return _hasNext;
    }
}

/**
 * 使用示例：
 * Iterator<Integer> iter = Arrays.asList(1, 2, 3).iterator();
 * PeekingIterator peekIter = new PeekingIterator(iter);
 * System.out.println(peekIter.peek());     // 1（不移动指针）
 * System.out.println(peekIter.peek());     // 1（还是 1，因为没有移动）
 * System.out.println(peekIter.next());     // 1（返回 1 并移动指针）
 * System.out.println(peekIter.peek());     // 2
 * System.out.println(peekIter.next());     // 2
 * System.out.println(peekIter.hasNext());  // true
 * System.out.println(peekIter.next());     // 3
 * System.out.println(peekIter.hasNext());  // false
 */
```

## 复杂度分析

**时间复杂度：**
- `peek()`: `O(1)` 直接返回缓存值
- `next()`: `O(1)` 返回缓存并更新
- `hasNext()`: `O(1)` 检查标志位

**空间复杂度：** `O(1)` 只使用常数额外空间存储缓存

## 关键点总结

1. **缓存机制**：核心是维护一个缓存变量，始终存储下一个要返回的元素
2. **状态管理**：需要标志位区分是否还有下一个元素
3. **初始化预读**：在构造函数中就读取第一个元素到缓存
4. **peek 不修改状态**：只读取缓存，不调用底层迭代器
5. **next 更新缓存**：返回当前缓存后，立即读取新值填充缓存

## 易错点

1. **忘记初始化缓存**：构造函数中忘记预读第一个元素
2. **peek 调用 next**：错误地在 peek 中调用底层的 next，导致指针移动
3. **缓存未更新**：next 返回后忘记更新缓存
4. **空迭代器处理**：没有处理初始迭代器为空的情况
5. **重复 peek**：没有正确处理连续多次 peek 的情况
