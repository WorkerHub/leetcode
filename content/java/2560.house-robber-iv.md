## 题目描述

沿街房屋金额为 `nums`，小偷不能偷相邻房屋，最少偷 `k` 栋，能力值为偷到的最大金额，返回最小能力值。

## 解题思路

二分答案：二分能力值 cap，贪心验证是否能偷至少 k 栋。贪心：从左到右，遇到 <= cap 的房屋立即偷并跳过下一栋。

## Java 代码实现

```java
class Solution {
    public int minCapability(int[] nums, int k) {
        int lo = Integer.MAX_VALUE, hi = 0;
        for (int x : nums) { lo = Math.min(lo, x); hi = Math.max(hi, x); }

        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (canRob(nums, k, mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }

    // 贪心验证：能力值为 cap 时能否偷 k 栋
    private boolean canRob(int[] nums, int k, int cap) {
        int count = 0, i = 0;
        while (i < nums.length) {
            if (nums[i] <= cap) {
                count++;
                i += 2; // 跳过相邻房屋
            } else {
                i++;
            }
        }
        return count >= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)，M 为最大值
- **空间复杂度**：O(1)

## 关键点总结

1. 最小化最大值 → 二分答案，找最小满足条件的 cap
2. 贪心验证：遇到合法房屋立即偷并跳过下一栋（最贪心策略）
3. 二分时找最小满足条件的值：`hi = mid` 收缩右边界
