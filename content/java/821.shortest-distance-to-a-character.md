## 题目描述

给你一个字符串 `s` 和一个字符 `c`，且 `c` 是 `s` 中出现过的字符。

返回一个整数数组 `answer`，其中 `answer.length == s.length` 且 `answer[i]` 是 `s` 中从下标 `i` 到离它 **最近** 的字符 `c` 的 **距离**。

**示例 1:**
```
输入: s = "loveleetcode", c = "e"
输出: [3,2,1,0,1,0,0,1,2,2,1,0]
```

**示例 2:**
```
输入: s = "aaab", c = "b"
输出: [3,2,1,0]
```

**提示:**
- `1 <= s.length <= 10^4`
- `s[i]` 和 `c` 均为小写英文字母
- 题目数据保证 `c` 在 `s` 中至少出现一次

## 解题思路

**两次遍历法：**
1. 从左到右遍历，记录每个位置到左边最近 `c` 的距离
2. 从右到左遍历，更新为到两边最近 `c` 的最小距离

## Java 代码实现

### 方法一：两次遍历（推荐）

```java
class Solution {
    public int[] shortestToChar(String s, char c) {
        int n = s.length();
        int[] result = new int[n];

        // 从左到右：记录到左边最近 c 的距离
        int prev = Integer.MIN_VALUE / 2;  // 用足够小的数代表负无穷
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            result[i] = Math.abs(i - prev);
        }

        // 从右到左：更新到右边最近 c 的距离
        prev = Integer.MAX_VALUE / 2;  // 用足够大的数代表正无穷
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            result[i] = Math.min(result[i], Math.abs(i - prev));
        }

        return result;
    }
}
```

### 方法二：记录所有位置

```java
import java.util.*;

class Solution {
    public int[] shortestToChar(String s, char c) {
        // 找到所有 c 的位置
        List<Integer> positions = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == c) {
                positions.add(i);
            }
        }

        int n = s.length();
        int[] result = new int[n];

        for (int i = 0; i < n; i++) {
            // 二分查找最近的 c 位置
            int idx = Collections.binarySearch(positions, i);
            if (idx < 0) idx = -(idx + 1);

            int minDist = Integer.MAX_VALUE;
            if (idx < positions.size()) {
                minDist = Math.min(minDist, Math.abs(i - positions.get(idx)));
            }
            if (idx > 0) {
                minDist = Math.min(minDist, Math.abs(i - positions.get(idx - 1)));
            }

            result[i] = minDist;
        }

        return result;
    }
}
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n)，两次遍历
- **空间复杂度**：O(n)，结果数组

### 方法二：
- **时间复杂度**：O(n log m)，m 是 c 出现次数
- **空间复杂度**：O(m + n)

## 关键点总结

1. **两次遍历**：分别处理左右方向
2. **距离更新**：取两个方向的最小值
3. **边界处理**：使用极大/极小值作为初始值

## 易错点

1. **初始值**：Java 中用 Integer.MIN_VALUE / 2 避免溢出
2. **绝对值**：距离是绝对值
3. **最小值更新**：需要比较左右两个方向
