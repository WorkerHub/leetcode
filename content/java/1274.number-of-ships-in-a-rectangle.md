## 题目描述

交互题：用 Sea.hasShips(topRight, bottomLeft) 判断矩形内是否有船，返回矩形内的船数量。最多调用 400 次 API。

**示例：**
```
输入：ships = [[1,1],[2,2],[3,3],[5,5]], topRight = [4,4], bottomLeft = [0,0]
输出：3
```

## 解题思路

分治：将矩形四分，若 hasShips 返回 false 则剪枝（不递归），否则继续分割直到单点。

## Java 代码实现

```java
class Solution {
    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {
        // 无效矩形或无船
        if (bottomLeft[0] > topRight[0] || bottomLeft[1] > topRight[1]) return 0;
        if (!sea.hasShips(topRight, bottomLeft)) return 0;
        
        // 单点
        if (topRight[0] == bottomLeft[0] && topRight[1] == bottomLeft[1]) return 1;
        
        int midX = (topRight[0] + bottomLeft[0]) / 2;
        int midY = (topRight[1] + bottomLeft[1]) / 2;
        
        // 四分矩形
        int count = 0;
        // 左下
        count += countShips(sea, new int[]{midX, midY}, bottomLeft);
        // 右下
        count += countShips(sea, new int[]{topRight[0], midY}, new int[]{midX + 1, bottomLeft[1]});
        // 左上
        count += countShips(sea, new int[]{midX, topRight[1]}, new int[]{bottomLeft[0], midY + 1});
        // 右上
        count += countShips(sea, topRight, new int[]{midX + 1, midY + 1});
        
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(S × log(max_coord))，S 为船的数量
- **空间复杂度**：O(log(max_coord))（递归深度）

## 关键点总结

1. **分治四分**：每次将矩形分为四个子矩形
2. **剪枝**：hasShips 返回 false 立即停止
3. **基础情况**：单点时返回 1
4. **调用次数**：剪枝保证不超过 400 次
