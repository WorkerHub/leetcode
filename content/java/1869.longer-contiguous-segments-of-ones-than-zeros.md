## 题目描述

判断二进制字符串中最长连续'1'段是否严格长于最长连续'0'段。

## 解题思路

线性扫描分别统计'1'和'0'的最长连续段长度，比较。

## Java 代码实现

```java
class Solution {
    public boolean checkZeroOnes(String s) {
        int maxOnes = 0, maxZeros = 0;
        int curOnes = 0, curZeros = 0;
        
        for (char c : s.toCharArray()) {
            if (c == '1') {
                curOnes++;
                curZeros = 0;
                maxOnes = Math.max(maxOnes, curOnes);
            } else {
                curZeros++;
                curOnes = 0;
                maxZeros = Math.max(maxZeros, curZeros);
            }
        }
        return maxOnes > maxZeros;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **一次遍历**：同时维护两种字符的连续计数
2. **严格大于**：maxOnes > maxZeros
