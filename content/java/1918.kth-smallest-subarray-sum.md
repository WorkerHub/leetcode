## 题目描述

给你正整数数组 `nums` 和整数 `k`，返回所有非空子数组和中第 k 小的值。

## 解题思路

二分答案：对目标值 mid 统计子数组和 ≤ mid 的数量（利用全正数特性用滑动窗口 O(n) 计算），找到使计数 >= k 的最小 mid。

## Java 代码实现

```java
class Solution {
    public int kthSmallestSubarraySum(int[] nums, int k) {
        int lo = Integer.MAX_VALUE, hi = 0;
        for (int x : nums) {
            lo = Math.min(lo, x);
            hi += x;
        }

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countLe(nums, mid) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    // 统计子数组和 <= target 的数量（滑动窗口，全正数）
    private long countLe(int[] nums, int target) {
        long cnt = 0;
        int windowSum = 0, left = 0;
        for (int right = 0; right < nums.length; right++) {
            windowSum += nums[right];
            while (windowSum > target) {
                windowSum -= nums[left++];
            }
            cnt += right - left + 1; // 以 right 为右端的合法子数组数
        }
        return cnt;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log(sum))
- **空间复杂度**：O(1)

## 关键点总结

1. 全正数时子数组和与滑动窗口结合高效计数
2. 二分的是答案值，二分终止后 lo 即为第 k 小的值
3. 左边界为 min(nums)，右边界为 sum(nums)
