## 题目描述

Alice 和 Bob 轮流操作数字 n（Alice 先手）：选择 0 < x < n 且 n % x == 0，将 n 替换为 n-x。无法操作者输。返回 Alice 是否必胜。

**示例：**
```
输入：n = 2
输出：true（Alice 选 1，Bob 面对 1 无法操作）
```

## 解题思路

数学规律：n 为偶数 Alice 必胜，n 为奇数 Alice 必败。奇数的因子都是奇数，奇数减奇数等于偶数，所以奇数只能变成偶数。

## Java 代码实现

```java
class Solution {
    public boolean divisorGame(int n) {
        return n % 2 == 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **偶数必胜**：选 1 把奇数留给对手
2. **奇数必败**：只能选奇因子，结果变偶数给对手
3. **归纳证明**：n=1 败，n=2 胜，递推可证
