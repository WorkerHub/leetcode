## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可将任意元素改为 `[nums[i]-k, nums[i]+k]` 范围内任意整数，返回操作后数组中不同元素的最大数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxDistinctElements(int[] nums, int k) {
        Arrays.sort(nums);
        int ans = 0;
        long last = Long.MIN_VALUE; // 上一个分配的值

        for (int x : nums) {
            long lo = (long) x - k, hi = (long) x + k;
            // 贪心：选在范围内尽量小的值（至少比 last 大 1）
            long chosen = Math.max(last + 1, lo);
            if (chosen <= hi) {
                ans++;
                last = chosen;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后贪心，每次选在范围内尽量小的值（`max(last+1, x-k)`）。
2. 若选出的值超出范围上界，则该元素无法增加不同值数量，跳过。
3. 贪心正确性：选尽量小的值为后续元素保留更多空间。
