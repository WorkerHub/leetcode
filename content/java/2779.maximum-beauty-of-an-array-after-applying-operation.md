## 题目描述

给你整数数组 `nums` 和整数 `k`，可以将每个元素替换为 `[nums[i]-k, nums[i]+k]` 范围内的任意整数，返回操作后数组中最长相等子序列的长度。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximumBeauty(int[] nums, int k) {
        Arrays.sort(nums);
        int ans = 1, left = 0;
        for (int right = 1; right < nums.length; right++) {
            // 若窗口内最大值与最小值之差 > 2*k，缩小左边界
            while (nums[right] - nums[left] > 2 * k) left++;
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)

## 关键点总结

1. 排序后问题转化为：找最长窗口使 `nums[right] - nums[left] <= 2*k`
2. 每个元素的可替换范围为 `[x-k, x+k]`，两个元素能取同一值当且仅当区间有交集
3. 滑动窗口维护合法区间
