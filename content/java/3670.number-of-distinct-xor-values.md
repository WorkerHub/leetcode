## 题目描述

给你整数数组 `nums` 和整数 `maximumBit`，对每个查询找最优非负整数 `k`（`k < 2^maximumBit`）使 `nums` 所有元素与 `k` 的异或最大，然后移除 `nums` 最后一个元素。返回每次查询的最优 k 值列表。

## 解题思路

维护所有元素的总异或值 `xorAll`。每次查询的最优 `k = xorAll ^ mask`（mask 为全 1）。移除最后一个元素等价于 `xorAll ^= nums[i]`（异或的逆操作）。

## Java 代码实现

```java
class Solution {
    public int[] getMaximumXor(int[] nums, int maximumBit) {
        int mask = (1 << maximumBit) - 1; // 全1掩码
        int xorAll = 0;
        for (int x : nums) xorAll ^= x;

        int n = nums.length;
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            // 最优k使xorAll^k最大
            result[i] = xorAll ^ mask;
            // 移除最后一个元素（异或自身抵消）
            xorAll ^= nums[n - 1 - i];
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 维护运行异或值，移除元素时再次异或（异或逆操作）
2. 最优 k = 当前总异或 ^ 全 1 掩码
3. 逆序处理：从末尾移除元素
