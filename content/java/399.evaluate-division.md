## 题目描述

给你一个变量对数组 `equations` 和一个实数值数组 `values` 作为已知条件，其中 `equations[i] = [Ai, Bi]` 和 `values[i]` 共同表示等式 `Ai / Bi = values[i]`。每个 `Ai` 或 `Bi` 是一个表示单个变量的字符串。

另有一些以数组 `queries` 表示的问题，其中 `queries[j] = [Cj, Dj]` 表示第 `j` 个问题，请你根据已知条件找出 `Cj / Dj = ?` 的结果作为答案。

返回 **所有问题的答案**。如果存在某个无法确定的答案，则用 `-1.0` 替代这个答案。如果问题中出现了给定的已知条件中没有出现的字符串，也需要根据情况返回 `-1.0`。

**注意：** 输入总是有效的。你可以假设除法运算中不会出现除数为 0 的情况，且不存在任何矛盾的结果。

**注意：** 未在等式列表中出现的变量是未定义的，因此无法确定它们的答案。

**示例 1:**

```
输入：equations = [["a","b"],["b","c"]], values = [2.0,3.0], queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
输出：[6.00000,0.50000,-1.00000,1.00000,-1.00000]
解释：
条件：a / b = 2.0, b / c = 3.0
问题：a / c = ?, b / a = ?, a / e = ?, a / a = ?, x / x = ?
结果：[6.0, 0.5, -1.0, 1.0, -1.0 ]
注意：x 是未定义的 => -1.0
```

**示例 2:**

```
输入：equations = [["a","b"],["b","c"],["bc","cd"]], values = [1.5,2.5,5.0], queries = [["a","c"],["c","b"],["bc","cd"],["cd","bc"]]
输出：[3.75000,0.40000,5.00000,0.20000]
```

**示例 3:**

```
输入：equations = [["a","b"]], values = [0.5], queries = [["a","b"],["b","a"],["a","c"],["x","y"]]
输出：[0.50000,2.00000,-1.00000,-1.00000]
```

**提示:**

- `1 <= equations.length <= 20`
- `equations[i].length == 2`
- `1 <= Ai.length, Bi.length <= 5`
- `values.length == equations.length`
- `0.0 < values[i] <= 20.0`
- `1 <= queries.length <= 20`
- `queries[i].length == 2`
- `1 <= Cj.length, Dj.length <= 5`
- `Ai, Bi, Cj, Dj` 由小写英文字母与数字组成

## 解题思路

本题可以建模为**带权图**问题，每个变量是节点，除法关系是边，边的权重是商值。

### 核心思想

**图的构建：**

- `a / b = 2.0` → 边 a→b 权重 2.0，边 b→a 权重 0.5
- 查询 `a / c` 就是找从 a 到 c 的路径，路径权重的乘积就是答案

**解法对比：**

| 方法 | 时间复杂度 | 特点 |
|------|------------|------|
| DFS | O(V + E) | 直观，适合稀疏图 |
| BFS | O(V + E) | 层序遍历 |
| 并查集 | O(α(V)) | 路径压缩，复杂 |
| Floyd | O(V³) | 预处理所有路径 |

## Java 代码实现

### 方法一：DFS 图遍历（推荐）⭐

```java
import java.util.*;

class Solution {
    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
        // 使用 DFS 在图中查找路径
        // 时间复杂度: O((V + E) * Q) - Q 是查询数量
        // 空间复杂度: O(V + E)

        // 构建图：变量 -> {邻接变量 -> 权重}
        Map<String, Map<String, Double>> graph = new HashMap<>();

        for (int i = 0; i < equations.size(); i++) {
            String dividend = equations.get(i).get(0);
            String divisor = equations.get(i).get(1);
            double value = values[i];

            graph.computeIfAbsent(dividend, k -> new HashMap<>()).put(divisor, value);
            graph.computeIfAbsent(divisor, k -> new HashMap<>()).put(dividend, 1.0 / value);
        }

        // 处理所有查询
        double[] results = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            String start = queries.get(i).get(0);
            String end = queries.get(i).get(1);
            results[i] = dfs(graph, start, end, new HashSet<>());
        }

        return results;
    }

    /** DFS 查找从 start 到 end 的路径 */
    private double dfs(Map<String, Map<String, Double>> graph, String start, String end, Set<String> visited) {
        // 变量不存在
        if (!graph.containsKey(start) || !graph.containsKey(end)) return -1.0;

        // 相同变量
        if (start.equals(end)) return 1.0;

        visited.add(start);

        // 遍历邻接节点
        for (Map.Entry<String, Double> entry : graph.get(start).entrySet()) {
            String neighbor = entry.getKey();
            double value = entry.getValue();

            if (visited.contains(neighbor)) continue;

            // 递归查找
            double result = dfs(graph, neighbor, end, visited);
            if (result != -1.0) {
                return value * result;
            }
        }

        return -1.0;
    }
}
```

### 方法二：BFS 图遍历

```java
import java.util.*;

class Solution {
    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
        // 构建图
        Map<String, Map<String, Double>> graph = new HashMap<>();
        for (int i = 0; i < equations.size(); i++) {
            String a = equations.get(i).get(0);
            String b = equations.get(i).get(1);
            graph.computeIfAbsent(a, k -> new HashMap<>()).put(b, values[i]);
            graph.computeIfAbsent(b, k -> new HashMap<>()).put(a, 1.0 / values[i]);
        }

        double[] results = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            results[i] = bfs(graph, queries.get(i).get(0), queries.get(i).get(1));
        }
        return results;
    }

    /** BFS 查找路径 */
    private double bfs(Map<String, Map<String, Double>> graph, String start, String end) {
        if (!graph.containsKey(start) || !graph.containsKey(end)) return -1.0;
        if (start.equals(end)) return 1.0;

        Queue<Object[]> queue = new LinkedList<>();  // [节点, 当前积]
        Set<String> visited = new HashSet<>();

        queue.offer(new Object[]{start, 1.0});
        visited.add(start);

        while (!queue.isEmpty()) {
            Object[] curr = queue.poll();
            String node = (String) curr[0];
            double product = (double) curr[1];

            if (node.equals(end)) return product;

            for (Map.Entry<String, Double> entry : graph.get(node).entrySet()) {
                String neighbor = entry.getKey();
                if (!visited.contains(neighbor)) {
                    visited.add(neighbor);
                    queue.offer(new Object[]{neighbor, product * entry.getValue()});
                }
            }
        }

        return -1.0;
    }
}
```

### 方法三：带权并查集

```java
import java.util.*;

class UnionFind {
    private Map<String, String> parent;
    private Map<String, Double> weight;  // weight[x] = x / parent[x]

    public UnionFind() {
        parent = new HashMap<>();
        weight = new HashMap<>();
    }

    /** 添加新节点 */
    public void add(String x) {
        if (!parent.containsKey(x)) {
            parent.put(x, x);
            weight.put(x, 1.0);
        }
    }

    /** 查找根节点，路径压缩 */
    public String find(String x) {
        if (!x.equals(parent.get(x))) {
            String origin = parent.get(x);
            parent.put(x, find(origin));
            weight.put(x, weight.get(x) * weight.get(origin));
        }
        return parent.get(x);
    }

    /** 合并：x / y = value */
    public void union(String x, String y, double value) {
        add(x);
        add(y);

        String rootX = find(x), rootY = find(y);

        if (!rootX.equals(rootY)) {
            parent.put(rootX, rootY);
            // weight[root_x] = weight[y] * value / weight[x]
            weight.put(rootX, weight.get(y) * value / weight.get(x));
        }
    }

    /** 查询 x / y */
    public double query(String x, String y) {
        if (!parent.containsKey(x) || !parent.containsKey(y)) return -1.0;

        String rootX = find(x), rootY = find(y);

        if (!rootX.equals(rootY)) return -1.0;

        // x / y = (x / root) * (root / y) = weight[x] / weight[y]
        return weight.get(x) / weight.get(y);
    }
}

class Solution {
    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
        // 使用带权并查集
        UnionFind uf = new UnionFind();

        // 构建并查集
        for (int i = 0; i < equations.size(); i++) {
            uf.union(equations.get(i).get(0), equations.get(i).get(1), values[i]);
        }

        // 处理查询
        double[] results = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            results[i] = uf.query(queries.get(i).get(0), queries.get(i).get(1));
        }
        return results;
    }
}
```

## 复杂度分析

### 方法一：DFS

**时间复杂度：** O((V + E) * Q)
- V 是变量数量，E 是等式数量，Q 是查询数量
- 每个查询需要 DFS 遍历图

**空间复杂度：** O(V + E)
- 图的存储空间

### 方法三：并查集

**时间复杂度：** O((V + E) * α(V) + Q * α(V))
- α 是反阿克曼函数，近似 O(1)
- 构建并查集 O((V + E) * α(V))
- 查询 O(Q * α(V))

**空间复杂度：** O(V)

## 关键点总结

1. **图建模**：除法关系可以建模为有向带权图
2. **双向边**：a/b=2 意味着 b/a=0.5，需要添加反向边
3. **路径乘积**：路径上权重的乘积就是答案
4. **未定义变量**：不在图中的变量返回 -1
5. **字符串比较**：Java 中用 equals() 比较字符串，不用 ==

## 易错点

1. **忘记添加反向边**：除法是双向关系
2. **未定义变量**：要检查变量是否在图中
3. **自环处理**：a/a 应该返回 1
4. **浮点精度**：题目保证不会有精度问题
5. **并查集权重**：带权并查集的权重更新比较复杂
