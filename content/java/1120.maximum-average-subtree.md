## 题目描述

给定二叉树根节点，返回所有子树平均值中的最大值。子树平均值 = 子树节点值之和 / 子树节点数。

**示例：**
```
输入：root = [5,6,1]
输出：6.00000
解释：节点 6 的子树平均值为 6/1 = 6，是最大的
```

## 解题思路

后序 DFS：递归返回 (子树和, 节点数)，在每个节点计算平均值并更新全局最大值。

## Java 代码实现

```java
class Solution {
    private double maxAvg = 0;

    public double maximumAverageSubtree(TreeNode root) {
        dfs(root);
        return maxAvg;
    }

    // 返回 [子树和, 节点数]
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        int sum = node.val + left[0] + right[0];
        int count = 1 + left[1] + right[1];

        maxAvg = Math.max(maxAvg, (double) sum / count);

        return new int[]{sum, count};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **后序遍历**：先算子树信息再算当前节点
2. **返回元组**：(sum, count) 供父节点汇总
3. **全局变量更新**：每个节点都比较一次平均值
