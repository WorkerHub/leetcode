## 题目描述

编码字符串将若干连续字符替换为一个正整数（表示字符数），给定两个编码字符串 s1 和 s2，判断是否存在同一个原始字符串能被编码为 s1 和 s2。

## 解题思路

记忆化 DFS：状态 `dp(i, j, diff)` 表示 s1 在位置 i、s2 在位置 j、s1 超前 s2 diff 个字符。diff>0 时 s2 消耗字符，diff<0 时 s1 消耗字符，diff=0 时两者同步匹配。

## Java 代码实现

### 方法一：记忆化 DFS（推荐）

```java
import java.util.*;

class Solution {
    private String s1, s2;
    private Map<Long, Boolean> memo = new HashMap<>();

    public boolean possiblyEquals(String s1, String s2) {
        this.s1 = s1; this.s2 = s2;
        return dp(0, 0, 0);
    }

    private boolean dp(int i, int j, int diff) {
        // diff: s1超前s2的字符数（正为s1超前，负为s2超前）
        if (i == s1.length() && j == s2.length()) return diff == 0;
        long key = ((long) i << 20 | j) << 14 | (diff + 7000); // diff范围约[-7000,7000]
        Boolean cached = memo.get(key);
        if (cached != null) return cached;

        boolean res = false;
        if (diff > 0) {
            // s1超前，消耗s2的字符
            if (j < s2.length() && Character.isLetter(s2.charAt(j))) {
                res = dp(i, j + 1, diff - 1);
            } else if (j < s2.length() && Character.isDigit(s2.charAt(j))) {
                int num = 0, jj = j;
                while (jj < s2.length() && Character.isDigit(s2.charAt(jj))) {
                    num = num * 10 + (s2.charAt(jj++) - '0');
                    if (dp(i, jj, diff - num)) { res = true; break; }
                }
            }
        } else if (diff < 0) {
            // s2超前，消耗s1的字符
            if (i < s1.length() && Character.isLetter(s1.charAt(i))) {
                res = dp(i + 1, j, diff + 1);
            } else if (i < s1.length() && Character.isDigit(s1.charAt(i))) {
                int num = 0, ii = i;
                while (ii < s1.length() && Character.isDigit(s1.charAt(ii))) {
                    num = num * 10 + (s1.charAt(ii++) - '0');
                    if (dp(ii, j, diff + num)) { res = true; break; }
                }
            }
        } else {
            // diff == 0，两者同步
            if (i < s1.length() && j < s2.length()) {
                char c1 = s1.charAt(i), c2 = s2.charAt(j);
                if (Character.isLetter(c1) && Character.isLetter(c2)) {
                    res = (c1 == c2) && dp(i + 1, j + 1, 0);
                } else if (Character.isLetter(c1)) {
                    // s2是数字，枚举s2数字长度
                    int num = 0, jj = j;
                    while (jj < s2.length() && Character.isDigit(s2.charAt(jj))) {
                        num = num * 10 + (s2.charAt(jj++) - '0');
                        if (dp(i, jj, -num)) { res = true; break; }
                    }
                } else if (Character.isLetter(c2)) {
                    // s1是数字
                    int num = 0, ii = i;
                    while (ii < s1.length() && Character.isDigit(s1.charAt(ii))) {
                        num = num * 10 + (s1.charAt(ii++) - '0');
                        if (dp(ii, j, num)) { res = true; break; }
                    }
                } else {
                    // 两者都是数字，枚举两者数字长度
                    int num1 = 0, ii = i;
                    while (ii < s1.length() && Character.isDigit(s1.charAt(ii))) {
                        num1 = num1 * 10 + (s1.charAt(ii++) - '0');
                        int num2 = 0, jj = j;
                        while (jj < s2.length() && Character.isDigit(s2.charAt(jj))) {
                            num2 = num2 * 10 + (s2.charAt(jj++) - '0');
                            if (dp(ii, jj, num1 - num2)) { res = true; break; }
                        }
                        if (res) break;
                    }
                }
            }
        }
        memo.put(key, res);
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * D)，D 约为字符串总长度
- 空间复杂度：O(m * n * D)

## 关键点总结

1. 状态 (i, j, diff) 中 diff 表示 s1 相对 s2 超前的字符数
2. 数字需枚举不同位数（逐位扩展）
3. diff 范围约 [-999, 999]（受字符串长度约束）
