## 题目描述

给你一个数组 `nums` 和一个值 `val`，你需要原地移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并原地修改输入数组。

元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

**示例 1：**
```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：函数应该返回新的长度 2，并且 nums 中的前两个元素均为 2。你不需要考虑数组中超出新长度后面的元素。例如，函数返回的新长度为 2，而 nums = [2,2,3,3] 或 nums = [2,2,0,0]，也会被视作正确答案。
```

**示例 2：**
```
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,3,0,4,_,_,_]
解释：函数应该返回新的长度 5，并且 nums 中的前五个元素为 0,1,3,0,4。注意这五个元素可以任意顺序返回。你不需要考虑数组中超出新长度后面的元素。
```

## 解题思路

### 方法一：双指针（快慢指针）⭐

**核心思想：**
- **慢指针**（`slow`）：指向下一个要填入的位置
- **快指针**（`fast`）：遍历整个数组

**算法流程：**
1. 慢指针 `slow` 从 0 开始
2. 快指针 `fast` 遍历数组
3. 如果 `nums[fast] != val`，将其复制到 `nums[slow]`，然后 `slow++`
4. 返回 `slow`（即新数组的长度）

### 方法二：双指针（首尾指针）

当要移除的元素很少时，可以从两端向中间移动：
- 左指针找到等于 `val` 的元素
- 用右指针的元素替换它
- 右指针左移

## Java 代码实现

### 方法一：快慢指针（推荐）

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0; // 慢指针

        // 快指针遍历数组
        for (int fast = 0; fast < nums.length; fast++) {
            // 如果当前元素不等于 val，保留它
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

### 方法二：首尾双指针（优化版）

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            if (nums[left] == val) {
                // 用右边的元素替换
                nums[left] = nums[right];
                right--;
            } else {
                left++;
            }
        }

        return left;
    }
}
```

## 复杂度分析

### 快慢指针
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(1)，原地修改

### 首尾指针
- **时间复杂度**：O(n)，最坏情况遍历一次
- **空间复杂度**：O(1)，原地修改

**首尾指针的优势：**
- 当要移除的元素很少时，减少了赋值次数
- 例如 `nums = [1,2,3,4,5], val = 5`，只需一次操作

## 图解示例

### 快慢指针示例：`nums = [3,2,2,3], val = 3`

```
初始状态：
nums = [3,2,2,3]
       ↑
     slow=0

fast=0: nums[0]=3 == val，跳过
fast=1: nums[1]=2 != val
  nums[0] = nums[1] = 2, slow++
  nums = [2,2,2,3]
         ↑
       slow=1

fast=2: nums[2]=2 != val
  nums[1] = nums[2] = 2, slow++
  nums = [2,2,2,3]
           ↑
         slow=2

fast=3: nums[3]=3 == val，跳过

返回 slow = 2
结果：[2,2,_,_]
```

## 关键点总结

1. **原地修改**：不能使用额外数组
2. **顺序可变**：不要求保持相对顺序（这是与26题的区别）
3. **两种思路**：
   - 快慢指针：保持相对顺序，适合所有情况
   - 首尾指针：不保持顺序，但当要移除的元素少时更高效

## 易错点

1. **循环条件**：
   - 快慢指针：`for (int fast = 0; fast < nums.length; fast++)`
   - 首尾指针：`while (left <= right)`（注意有等号）

2. **返回值**：
   - 快慢指针：返回 `slow`
   - 首尾指针：返回 `left`

3. **赋值时机**：
   - 快慢指针：先赋值，后移动 `slow`
   - 首尾指针：先赋值，后移动 `right`
