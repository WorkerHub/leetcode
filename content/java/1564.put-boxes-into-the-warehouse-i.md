## 题目描述

箱子从仓库左边推入，每个房间只能放一个箱子且高度受路径上所有房间限制。返回最多能放入的箱子数。

**示例：**
```
输入：boxes = [4,3,4,1], warehouse = [2,1,3,1,2]
输出：3
```

## 解题思路

预处理仓库有效高度（前缀最小值），排序后双指针贪心匹配。

## Java 代码实现

```java
class Solution {
    public int maxBoxesInWarehouse(int[] boxes, int[] warehouse) {
        int n = warehouse.length;
        // 预处理前缀最小值
        int[] effective = new int[n];
        effective[0] = warehouse[0];
        for (int i = 1; i < n; i++) {
            effective[i] = Math.min(effective[i - 1], warehouse[i]);
        }
        
        Arrays.sort(boxes);
        Arrays.sort(effective);
        
        // 双指针：小箱子匹配小格子
        int ans = 0, bi = 0;
        for (int i = 0; i < n && bi < boxes.length; i++) {
            if (boxes[bi] <= effective[i]) {
                ans++;
                bi++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m log m)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀最小值**：有效高度 = min(warehouse[0..i])
2. **排序+双指针**：小箱子优先匹配小格子
3. **从左推入**：路径上所有房间高度都是约束
