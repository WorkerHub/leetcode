## 题目描述

给你红色球 `red` 个和蓝色球 `blue` 个，排成三角形：第 i 行有 i 个球，相邻行颜色交替，返回可排成的最大高度。

## 解题思路

枚举两种颜色分配方式（谁负责奇数行），用数学公式计算奇数行总球数（ceil(h/2)^2）和偶数行总球数（floor(h/2)×(floor(h/2)+1)），找最大满足条件的高度。

## Java 代码实现

```java
class Solution {
    public int maxHeightOfTriangle(int red, int blue) {
        int ans = 0;
        // 枚举两种分配方式：(c1 负责奇数行, c2 负责偶数行)
        for (int t = 0; t < 2; t++) {
            int c1 = (t == 0) ? red : blue;
            int c2 = (t == 0) ? blue : red;
            for (int h = 1; h <= 200; h++) {
                int oddRows = (h + 1) / 2;
                int evenRows = h / 2;
                int oddSum = oddRows * oddRows;         // 1+3+...+(2k-1) = k^2
                int evenSum = evenRows * (evenRows + 1); // 2+4+...+2k = k*(k+1)
                if (oddSum <= c1 && evenSum <= c2) {
                    ans = Math.max(ans, h);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（h 上限约 sqrt(200) ≈ 14，枚举 200 次即可）
- **空间复杂度**：O(1)

## 关键点总结

1. 奇数行（1,3,5,...）总球数 = ceil(h/2)^2；偶数行总球数 = floor(h/2) × (floor(h/2)+1)
2. 两种颜色分配方式都需要检查，取最大高度
3. 球数约束：奇数行颜色的球数 >= oddSum，偶数行颜色 >= evenSum
