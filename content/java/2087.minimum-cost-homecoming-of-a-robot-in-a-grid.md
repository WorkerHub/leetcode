## 题目描述

机器人从startPos到homePos，移动到某行花费rowCosts[row]，移动到某列花费colCosts[col]。求最小代价。

## 解题思路

贪心：最优路径就是曼哈顿最短路径，绕路只增加代价。行和列独立累加。

## Java 代码实现

```java
class Solution {
    public int minCost(int[] startPos, int[] homePos, int[] rowCosts, int[] colCosts) {
        int cost = 0;
        int r1 = startPos[0], c1 = startPos[1];
        int r2 = homePos[0], c2 = homePos[1];
        
        // 行方向移动
        int dr = r1 < r2 ? 1 : -1;
        for (int r = r1 + dr; r != r2 + dr; r += dr) {
            cost += rowCosts[r];
        }
        
        // 列方向移动
        int dc = c1 < c2 ? 1 : -1;
        for (int c = c1 + dc; c != c2 + dc; c += dc) {
            cost += colCosts[c];
        }
        
        return cost;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|r2-r1| + |c2-c1|)
- **空间复杂度**：O(1)

## 关键点总结

1. **最短路径最优**：代价非负，绕路只增不减
2. **不含起始位置代价**：只计到达的行/列
3. **行列独立**：分别累加
