## 题目描述

给你含小写字母和 `?` 的字符串，将所有 `?` 替换为小写字母，使字符串值（每个字符左侧比它小的不同字母个数之和）最小，多种方案返回字典序最小的。

## 解题思路

贪心：每个 `?` 替换为当前频率最低的字母（代价最小）；用最小堆按频率分配，分配结果排序后依次填入 `?` 保证字典序最小。

## Java 代码实现

```java
class Solution {
    public String minimizeStringValue(String s) {
        int[] freq = new int[26];
        int qCount = 0;
        for (char c : s.toCharArray()) {
            if (c == '?') qCount++;
            else freq[c - 'a']++;
        }

        // 最小堆：{频率, 字母}，贪心为每个 ? 分配当前最低频字母
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        for (int i = 0; i < 26; i++) pq.offer(new int[]{freq[i], i});

        int[] chosen = new int[qCount];
        for (int i = 0; i < qCount; i++) {
            int[] top = pq.poll();
            chosen[i] = top[1];
            pq.offer(new int[]{top[0] + 1, top[1]});
        }
        Arrays.sort(chosen); // 排序后填入保证字典序最小

        StringBuilder sb = new StringBuilder(s);
        int ptr = 0;
        for (int i = 0; i < sb.length(); i++) {
            if (sb.charAt(i) == '?') {
                sb.setCharAt(i, (char) ('a' + chosen[ptr++]));
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q * log 26) = O(n)，q 为 ? 数量
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：每次将 ? 替换为当前频率最低的字母（代价最小）
2. 多个 ? 的分配结果排序后依次填入，保证字典序最小
3. 最小堆按 (频率, 字母) 排序，频率相同时字母字典序小的优先
