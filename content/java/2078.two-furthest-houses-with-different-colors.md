## 题目描述

给定房屋颜色数组，找颜色不同的距离最远的两栋房屋，返回最大距离。

## 解题思路

贪心：最优解必包含最左或最右的房屋。从左端向右找第一个不同色的，从右端向左找第一个不同色的，取两者最大值。

## Java 代码实现

### 方法一：贪心（推荐）

```java
class Solution {
    public int maxDistance(int[] colors) {
        int n = colors.length, ans = 0;
        // 固定左端点为 0，找最右的不同色
        for (int j = n - 1; j > 0; j--) {
            if (colors[j] != colors[0]) { ans = Math.max(ans, j); break; }
        }
        // 固定右端点为 n-1，找最左的不同色
        for (int i = 0; i < n - 1; i++) {
            if (colors[i] != colors[n - 1]) { ans = Math.max(ans, n - 1 - i); break; }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最优解一定涉及最左或最右的房屋
2. 两端分别查找第一个不同色的房屋即可
