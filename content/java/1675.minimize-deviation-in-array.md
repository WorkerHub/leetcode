## 题目描述

正整数数组 `nums`，奇数可乘 2，偶数可除 2（可操作任意次）。返回数组**偏差**（最大值 - 最小值）的最小值。

## 解题思路

**贪心 + 最大堆：** 先将所有奇数乘以 2（使所有元素能执行除 2 操作）。用最大堆维护当前最大值，每次将最大值除 2（若为偶数），更新最小值，记录当前偏差的最小值。直到最大值为奇数（无法再减小）。

## Java 代码实现

```java
class Solution {
    public int minimumDeviation(int[] nums) {
        // 最大堆（取负模拟）
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        int minVal = Integer.MAX_VALUE;

        // 将所有奇数乘以 2
        for (int x : nums) {
            if (x % 2 == 1) x *= 2;
            maxHeap.offer(x);
            minVal = Math.min(minVal, x);
        }

        int ans = maxHeap.peek() - minVal;

        while (maxHeap.peek() % 2 == 0) {
            int maxVal = maxHeap.poll();
            ans = Math.min(ans, maxVal - minVal);

            int newVal = maxVal / 2;
            minVal = Math.min(minVal, newVal);
            maxHeap.offer(newVal);
        }

        // 处理最后一个最大值（已为奇数）
        ans = Math.min(ans, maxHeap.peek() - minVal);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n * log(max_val))
- **空间复杂度**：O(n)

## 关键点总结

1. 先将奇数乘以 2，使所有元素可以通过"除 2"减小
2. 贪心：每次减小最大值（除以 2）
3. 停止条件：最大值是奇数（无法再除 2）
4. 每次操作后记录当前偏差，取最小值
