## 题目描述

给你 `n` 个二维平面上的点 `points`，找出**最宽的垂直区域**（两点之间不包含其他点的 x 坐标的最大宽度）。注意 y 坐标不影响结果。

## 解题思路

只关注 x 坐标：提取所有 x 坐标，排序后找相邻差的最大值。

## Java 代码实现

```java
class Solution {
    public int maxWidthOfVerticalArea(int[][] points) {
        // 提取并排序所有 x 坐标
        int[] xs = new int[points.length];
        for (int i = 0; i < points.length; i++) {
            xs[i] = points[i][0];
        }
        Arrays.sort(xs);

        // 找相邻差的最大值
        int ans = 0;
        for (int i = 1; i < xs.length; i++) {
            ans = Math.max(ans, xs[i] - xs[i - 1]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 题目只关注 x 坐标，y 坐标完全不影响结果
2. 排序后找最大相邻差
