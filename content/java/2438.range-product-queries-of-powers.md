## 题目描述

给你正整数 `n`（可表示为若干不同 2 的幂之和）和查询数组 `queries`，`powers` 为 `n` 分解的各 2 的幂从小到大排列，对每个查询 `[l, r]` 返回 `powers[l..r]` 的乘积对 10^9+7 的余数。

## 解题思路

先提取 `n` 二进制中所有 1 对应的 2 的幂构成 `powers`（最多 30 个）。由于 2 的幂的乘积 = 2^(指数之和)，预计算指数的前缀和，每次查询用快速幂计算 2^(区间指数和) 即可。

## Java 代码实现

```java
class Solution {
    public int[] productQueries(int n, int[][] queries) {
        final int MOD = 1_000_000_007;

        // 提取每个 2 的幂的指数
        int[] exponents = new int[30];
        int cnt = 0;
        for (int i = 0; i < 30; i++) {
            if ((n >> i & 1) == 1) {
                exponents[cnt++] = i;
            }
        }

        // 构建指数前缀和
        long[] prefix = new long[cnt + 1];
        for (int i = 0; i < cnt; i++) {
            prefix[i + 1] = prefix[i] + exponents[i];
        }

        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            // powers[l..r] 的乘积 = 2^(prefix[r+1] - prefix[l])
            long exp = prefix[r + 1] - prefix[l];
            ans[i] = (int) pow(2, exp, MOD);
        }
        return ans;
    }

    private long pow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q × log(exp))，q 为查询数
- **空间复杂度**：O(30) = O(1)

## 关键点总结

1. `powers` 由 `n` 二进制中各 1 对应的 2 的幂组成，最多 30 个
2. 2 的幂的乘积转化为指数相加，用前缀和优化区间查询
3. 快速幂计算 2^(区间指数和) mod 10^9+7
