## 题目描述

给你 n 个节点的树（根为 0）和字符数组 `s`，对每个节点 v，将其重新挂到祖先中最近的字符相同的节点下（若存在），返回操作后每个节点的子树大小。

## 解题思路

DFS 时维护 `last[c]` 表示当前路径上字符 c 的最近祖先。进入节点 v 时：查 `last[s[v]]`，若存在则记录新父节点；将 v 加入 `last`；递归子节点；回溯时恢复 `last`。最后按逆 DFS 序累加子树大小。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] findSubtreeSizes(int[] parent, String s) {
        int n = s.length();
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parent[i]).add(i);

        int[] newParent = parent.clone();
        int[] last = new int[26]; // last[c] = 当前路径上字符 c 的最近祖先，-1 表示无
        Arrays.fill(last, -1);
        List<Integer> order = new ArrayList<>(); // DFS 序

        // 迭代 DFS
        Deque<int[]> stack = new ArrayDeque<>(); // [node, phase]: phase=0进入, phase=1离开
        stack.push(new int[]{0, 0});
        while (!stack.isEmpty()) {
            int[] top = stack.pop();
            int v = top[0], phase = top[1];
            if (phase == 0) {
                order.add(v);
                int c = s.charAt(v) - 'a';
                int prev = last[c];
                if (v != 0 && prev != -1) newParent[v] = prev;
                // 离开时恢复
                stack.push(new int[]{v, 1});
                // 先压后访问的子节点（倒序保证顺序）
                List<Integer> ch = children.get(v);
                for (int i = ch.size() - 1; i >= 0; i--)
                    stack.push(new int[]{ch.get(i), 0});
                last[c] = v; // 进入后更新 last
                // 保存 prev 以便回溯（用 top 数组传递）
                top[1] = prev; // 复用 phase 位存 prev
                // 需要另一个变量... 改用显式存储 prev
            } else {
                // 离开节点 v，恢复 last
                int c = s.charAt(v) - 'a';
                last[c] = top[1]; // top[1] 存的是 prev（恢复值）
            }
        }
        // 注意：上面的进入/离开需要更小心处理 prev，重写如下：
        // 改用递归方式（增加栈大小）实际 n<=10^5 迭代更稳定
        Arrays.fill(last, -1);
        order.clear();
        newParent = parent.clone();
        iterDFS(0, children, s, last, newParent, order);

        // 按逆 DFS 序累加子树大小
        int[] size = new int[n];
        Arrays.fill(size, 1);
        for (int i = order.size() - 1; i >= 0; i--) {
            int v = order.get(i);
            if (v != 0) size[newParent[v]] += size[v];
        }
        return size;
    }

    private void iterDFS(int root, List<List<Integer>> children, String s,
                         int[] last, int[] newParent, List<Integer> order) {
        Deque<int[]> stack = new ArrayDeque<>();
        // [node, childIdx, prevLast]
        int c0 = s.charAt(root) - 'a';
        stack.push(new int[]{root, 0, last[c0]});
        last[c0] = root;
        order.add(root);
        while (!stack.isEmpty()) {
            int[] top = stack.peek();
            int v = top[0], ci = top[1];
            List<Integer> ch = children.get(v);
            if (ci < ch.size()) {
                top[1]++;
                int child = ch.get(ci);
                order.add(child);
                int cc = s.charAt(child) - 'a';
                int prev = last[cc];
                if (prev != -1) newParent[child] = prev;
                stack.push(new int[]{child, 0, prev});
                last[cc] = child;
            } else {
                // 离开 v，恢复 last
                int cv = s.charAt(v) - 'a';
                last[cv] = top[2];
                stack.pop();
            }
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，迭代 DFS 两步
- 空间复杂度：O(n)

## 关键点总结

1. DFS 路径上维护 `last[c]` 字符最近祖先，回溯时恢复
2. 每个节点重新挂载后，其自身子节点不变，只有父节点改变
3. 逆 DFS 序累加子树大小：子先父后
