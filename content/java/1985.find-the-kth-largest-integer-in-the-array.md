## 题目描述

给定字符串数组 `nums`（每个元素表示一个非负整数，最多 100 位）和整数 `k`，返回第 `k` 大的整数（字符串形式）。

## 解题思路

数字最多 100 位无法用 long 存储，用自定义字符串比较器：先比长度（长度大的数更大），长度相同再按字典序比较，排序后取第 k 个。

## Java 代码实现

### 方法一：自定义比较器排序（推荐）

```java
import java.util.*;

class Solution {
    public String kthLargestNumber(String[] nums, int k) {
        // 自定义比较器：先比长度，长度相同再按字典序，降序排列
        Arrays.sort(nums, (a, b) -> {
            if (a.length() != b.length()) {
                return b.length() - a.length(); // 长度大的排前面
            }
            return b.compareTo(a); // 字典序降序
        });
        return nums[k - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n * L)，L 为字符串最大长度
- 空间复杂度：O(1)

## 关键点总结

1. 大数字符串比较：先比长度，长度大的数更大；长度相同时字典序等价于数值大小
2. 不能转 long（最多 100 位），用自定义 Comparator
