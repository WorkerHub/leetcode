## 题目描述

城市的 **天际线** 是从远处观看该城市中所有建筑物形成的轮廓的外部轮廓。给你所有建筑物的位置和高度，请返回由这些建筑物形成的 **天际线**。

每个建筑物的几何信息由数组 `buildings` 表示，其中三元组 `buildings[i] = [lefti, righti, heighti]` 表示：

- `lefti` 是第 `i` 座建筑物左边缘的 x 坐标。
- `righti` 是第 `i` 座建筑物右边缘的 x 坐标。
- `heighti` 是第 `i` 座建筑物的高度。

你可以假设所有的建筑都是完美的长方形，在高度为 `0` 的绝对平坦的表面上。

**天际线** 应该表示为由 "关键点" 组成的列表，格式 `[[x1,y1],[x2,y2],...]`，并按 **x 坐标** 进行 **排序**。**关键点是水平线段的左端点**。列表中最后一个点是最右侧建筑物的终点，`y` 坐标始终为 `0`，仅用于标记天际线的终点。此外，任何两个相邻建筑物之间的地面都应被视为天际线轮廓的一部分。

**注意：** 输出天际线中不得有连续的相同高度的水平线。例如 `[...[2 3], [4 5], [7 5], [11 5], [12 7]...]` 是不正确的答案；三条高度为 5 的线应该在最终输出中合并为一个：`[...[2 3], [4 5], [12 7], ...]`

**示例 1：**

```
输入：buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]
输出：[[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]
```

**示例 2：**

```
输入：buildings = [[0,2,3],[2,5,3]]
输出：[[0,3],[5,0]]
```

**提示：**

- `1 <= buildings.length <= 10^4`
- `0 <= lefti < righti <= 2^31 - 1`
- `1 <= heighti <= 2^31 - 1`
- `buildings` 按 `lefti` 非递减顺序排列

## 解题思路

这是一道经典的困难题，考察扫描线算法和数据结构的综合应用。

**核心思想：**

1. **扫描线算法**：将所有建筑的左右边界作为关键事件点
2. **高度维护**：用 TreeMap（有序映射）维护当前活跃建筑的高度及其计数
3. **关键点识别**：当最大高度发生变化时，记录关键点

**算法流程：**

1. **提取事件**：
   - 左边界：`(x, -height)`（负号表示进入事件，排序时优先于正高度）
   - 右边界：`(x, +height)`（离开事件）

2. **排序事件**：
   - 按 x 坐标排序
   - 同一 x 坐标，左边界（负高度）优先于右边界（正高度）
   - 同为左边界，高的优先（负数更小，自然靠前）

3. **扫描处理**：
   - 遍历事件，维护当前活跃的建筑高度
   - 当最大高度变化时，记录关键点

4. **去重**：相邻关键点高度相同时合并

## Java 代码实现

### 方法一：扫描线 + TreeMap（推荐）⭐

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        // 提取所有事件点
        List<int[]> events = new ArrayList<>();
        for (int[] b : buildings) {
            events.add(new int[]{b[0], -b[2]}); // 左边界：负高度表示进入
            events.add(new int[]{b[1], b[2]});  // 右边界：正高度表示离开
        }

        // 排序：先按 x 坐标，同一 x 则负值（进入事件）优先
        events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        List<List<Integer>> result = new ArrayList<>();
        // TreeMap 降序存储当前活跃建筑的高度（高度 → 出现次数）
        TreeMap<Integer, Integer> heightMap = new TreeMap<>(Collections.reverseOrder());
        heightMap.put(0, 1); // 初始高度为 0（地面）

        for (int[] event : events) {
            int x = event[0];
            int h = Math.abs(event[1]);

            if (event[1] < 0) {
                // 进入事件：添加高度
                heightMap.merge(h, 1, Integer::sum);
            } else {
                // 离开事件：移除高度
                int count = heightMap.get(h);
                if (count == 1) {
                    heightMap.remove(h);
                } else {
                    heightMap.put(h, count - 1);
                }
            }

            // 当前最大高度
            int maxHeight = heightMap.firstKey();

            // 高度变化时记录关键点
            if (result.isEmpty() || result.get(result.size() - 1).get(1) != maxHeight) {
                result.add(Arrays.asList(x, maxHeight));
            }
        }

        return result;
    }
}
```

### 方法二：扫描线 + 优先队列（最大堆）

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        // 提取所有事件点
        List<int[]> events = new ArrayList<>();
        for (int[] b : buildings) {
            events.add(new int[]{b[0], -b[2], b[1]}); // 左边界：负高度，存右边界
            events.add(new int[]{b[1], 0, 0});          // 右边界
        }

        // 排序：按 x 坐标，同一 x 则高度小的（负值大）优先
        events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        List<List<Integer>> result = new ArrayList<>();
        // 最大堆：存储 [高度, 右边界]
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        heap.offer(new int[]{0, Integer.MAX_VALUE}); // 初始地面高度

        for (int[] event : events) {
            int x = event[0];

            if (event[1] < 0) {
                // 进入事件：将建筑加入堆
                heap.offer(new int[]{-event[1], event[2]});
            }

            // 移除已过期的建筑（右边界 <= 当前 x）
            while (heap.peek()[1] <= x) {
                heap.poll();
            }

            // 当前最大高度
            int maxHeight = heap.peek()[0];

            // 高度变化时记录关键点
            if (result.isEmpty() || result.get(result.size() - 1).get(1) != maxHeight) {
                result.add(Arrays.asList(x, maxHeight));
            }
        }

        return result;
    }
}
```

### 方法三：分治法

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        return divideAndConquer(buildings, 0, buildings.length - 1);
    }

    private List<List<Integer>> divideAndConquer(int[][] buildings, int left, int right) {
        if (left > right) return new ArrayList<>();

        if (left == right) {
            // 单个建筑的天际线
            List<List<Integer>> result = new ArrayList<>();
            result.add(Arrays.asList(buildings[left][0], buildings[left][2]));
            result.add(Arrays.asList(buildings[left][1], 0));
            return result;
        }

        // 分治
        int mid = (left + right) / 2;
        List<List<Integer>> leftSkyline = divideAndConquer(buildings, left, mid);
        List<List<Integer>> rightSkyline = divideAndConquer(buildings, mid + 1, right);

        // 合并两个天际线
        return mergeSkylines(leftSkyline, rightSkyline);
    }

    private List<List<Integer>> mergeSkylines(List<List<Integer>> left, List<List<Integer>> right) {
        List<List<Integer>> result = new ArrayList<>();
        int h1 = 0, h2 = 0; // 两个天际线当前高度
        int i = 0, j = 0;

        while (i < left.size() && j < right.size()) {
            int x, maxH;
            int lx = left.get(i).get(0);
            int rx = right.get(j).get(0);

            if (lx < rx) {
                h1 = left.get(i).get(1);
                x = lx;
                i++;
            } else if (lx > rx) {
                h2 = right.get(j).get(1);
                x = rx;
                j++;
            } else {
                h1 = left.get(i).get(1);
                h2 = right.get(j).get(1);
                x = lx;
                i++;
                j++;
            }

            maxH = Math.max(h1, h2);

            if (result.isEmpty() || result.get(result.size() - 1).get(1) != maxH) {
                result.add(Arrays.asList(x, maxH));
            }
        }

        // 追加剩余部分
        while (i < left.size()) result.add(left.get(i++));
        while (j < right.size()) result.add(right.get(j++));

        return result;
    }
}
```

## 复杂度分析

**方法一（扫描线 + TreeMap）：**

- **时间复杂度：** O(N log N)
  - 排序：O(N log N)
  - 每个事件的 TreeMap 操作：O(log N)
- **空间复杂度：** O(N)

**方法二（扫描线 + 优先队列）：**

- **时间复杂度：** O(N log N)，但惰性删除可能导致堆膨胀
- **空间复杂度：** O(N)

**方法三（分治）：**

- **时间复杂度：** O(N log N)
- **空间复杂度：** O(N log N)，递归栈 + 中间结果

## 关键点总结

1. **扫描线思想**：将二维问题转化为一维事件序列
2. **事件排序**：左边界、右边界的优先级和排序规则
3. **高度维护**：使用 TreeMap 维护当前最大高度（降序，firstKey 即最大值）
4. **关键点识别**：高度变化时才记录
5. **Java TreeMap**：天然支持有序操作，`firstKey()` 获取最大键

## 易错点

1. **事件排序规则错误**：
   ```java
   // 同一 x 时，进入事件（负高度）应优先处理
   events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
   // 因为负数比正数小，进入事件自然排在离开事件前面
   ```

2. **高度计数问题**：
   ```java
   // 同一高度可能被多个建筑共享
   // 错误：直接 remove
   heightMap.remove(h);
   // 正确：先减计数，为 0 时才移除
   int count = heightMap.get(h);
   if (count == 1) heightMap.remove(h);
   else heightMap.put(h, count - 1);
   ```

3. **相同高度合并**：
   ```java
   // 错误：每次都记录
   result.add(Arrays.asList(x, maxHeight));
   // 正确：检查是否与上一个高度相同
   if (result.isEmpty() || result.get(result.size() - 1).get(1) != maxHeight) {
       result.add(Arrays.asList(x, maxHeight));
   }
   ```

4. **整数溢出**：题目中 x 坐标和高度可能达到 `2^31 - 1`，排序比较时要注意
   ```java
   // 排序时避免直接相减（可能溢出）
   // 安全做法：使用 Integer.compare
   events.sort((a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
   ```

5. **TreeMap 的初始化**：
   ```java
   // 必须加入初始高度 0，否则所有建筑离开后无法获取高度 0
   heightMap.put(0, 1);
   ```

```
示例：buildings = [[2,9,10],[3,7,15],[5,12,12]]

事件提取：

(3, -15): 进入高度 15
(5, -12): 进入高度 12
(7,  15): 离开高度 15

(12, 12): 离开高度 12

扫描过程：
x=2: 加入10，heights={10:1,0:1}，max=10，记录 [2,10]

结果：[[2,10],[3,15],[7,12],[12,0]]
```

## 学习建议

1. **理解扫描线算法**：
   - 将复杂二维问题转化为一维事件序列
   - 按 x 坐标顺序处理事件
   - 维护当前状态（高度）

2. **Java TreeMap 特点**：
   - 基于红黑树，所有操作 O(log N)
   - `firstKey()` 获取最小键（降序时是最大高度）
   - `merge()` 方法简化计数更新

3. **数据结构选择**：
   - TreeMap：插入、删除、查询最大值都是 O(log N)，推荐
   - 优先队列：惰性删除可能导致性能退化
   - 有序列表：删除 O(N)，性能差

4. **测试用例**：
   ```java
   // 基础情况
   int[][] b1 = {{2,9,10},{3,7,15},{5,12,12}};
   // 边界重叠
   int[][] b2 = {{0,2,3},{2,5,3}};
   // 完全包含
   int[][] b3 = {{0,3,3},{1,2,4}};
   // 单个建筑
   int[][] b4 = {{0,2,3}};
   ```

5. **扩展思考**：
