## 题目描述

有序奖品位置数组 `prizePositions`，放两条长度为 `k` 的线段（可重叠），返回两条线段内包含的最多奖品数。

## 解题思路

滑动窗口 + 前缀最优：枚举第二条线段右端点 r，维护窗口大小（区间内奖品数）。`dp[r+1]` 记录前 r+1 个奖品中单段最优值。对每个 r，第一条线段最优 = `dp[left]`（left 是当前窗口左端）。

## Java 代码实现

```java
class Solution {
    public int maximizeWin(int[] prizePositions, int k) {
        int n = prizePositions.length;
        int[] dp = new int[n + 1]; // dp[i] = 用一条线段覆盖前 i 个奖品的最大数量
        int ans = 0, left = 0;

        for (int right = 0; right < n; right++) {
            // 维护窗口：[left, right] 内奖品距离 <= k
            while (prizePositions[right] - prizePositions[left] > k) left++;
            int windowSize = right - left + 1;
            // 更新前缀最优
            dp[right + 1] = Math.max(dp[right], windowSize);
            // 第一条线段最优位置 = left 之前的最优单段（不重叠）
            ans = Math.max(ans, dp[left] + windowSize);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举第二条线段（右端点 r），第一条线段最优位置在左端 left 之前
2. `dp[i]` 记录前 i 个奖品中单段的最优覆盖数，方便 O(1) 查询
3. 滑动窗口维护当前线段内奖品数，`dp[left]` 即第一条线段的最大贡献
