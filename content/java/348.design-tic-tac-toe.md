## 题目描述

请在一个 `n × n` 的棋盘上，实现一个判定井字棋（Tic-Tac-Toe）胜负的神器，判断每一次玩家落子后，是否有胜出的玩家。

在这个井字棋游戏中，会有 2 名玩家，他们将轮流在棋盘上放置自己的棋子。

第一个玩家（player 1）的棋子是 `X`，第二个玩家（player 2）的棋子是 `O`。

**规则如下：**
玩家轮流将棋子放在空方格（`" "`）上。
第一个玩家总是放棋子 `X`，且第二个玩家总是放棋子 `O`。
棋子只能放在空方格上，不能放在已经有棋子的方格上。
如果有 `n` 个相同的棋子排成一行（行、列、对角线）时，游戏结束，该玩家获胜。
如果所有方块都放满棋子了，还没有出现获胜的玩家，那么游戏平局。

实现 `TicTacToe` 类：

- `TicTacToe(int n)` 初始化游戏棋盘的大小 `n`。
- `int move(int row, int col, int player)` 玩家在坐标 `(row, col)` 放置棋子，返回游戏状态：
  - 如果玩家获胜，返回玩家编号（1 或 2）
  - 如果游戏平局或未结束，返回 0

**示例：**
```
输入：
```

**提示：**
- `2 <= n <= 100`
- player 的值为 1 或 2
- `0 <= row, col < n`
- `(row, col)` 是一个有效的空格位置
- 最多调用 `n^2` 次 `move`

**进阶：** 你能设计一个时间复杂度为 O(1) 的算法吗？

## 解题思路

这道题的关键是如何高效判断胜负。

**朴素解法：** 每次落子后检查该行、该列、两条对角线，时间复杂度 O(n)。

**优化思路：**
为每个玩家维护计数器：
- `n` 个行计数器
- `n` 个列计数器
- 2 个对角线计数器

**核心观察：**
- 玩家 1 落子：对应计数器 +1
- 玩家 2 落子：对应计数器 -1
- 如果某个计数器的绝对值等于 n，说明该玩家获胜

这样每次 move 只需 O(1) 时间更新计数器并判断。

## Java 代码实现

### 方法一：计数器优化（推荐）⭐

```java
class TicTacToe {
    private int n;
    private int[] rows;          // 行计数器
    private int[] cols;          // 列计数器
    private int diagonal;        // 主对角线计数器（左上到右下）
    private int antiDiagonal;    // 副对角线计数器（右上到左下）

    public TicTacToe(int n) {
        // 初始化棋盘大小和计数器
        this.n = n;
        this.rows = new int[n];
        this.cols = new int[n];
        this.diagonal = 0;
        this.antiDiagonal = 0;
    }

    public int move(int row, int col, int player) {
        // 确定增量：玩家 1 为 +1，玩家 2 为 -1
        int delta = (player == 1) ? 1 : -1;

        // 更新行计数器
        rows[row] += delta;

        // 更新列计数器
        cols[col] += delta;

        // 更新主对角线计数器（行号 == 列号）
        if (row == col) {
            diagonal += delta;
        }

        // 更新副对角线计数器（行号 + 列号 == n-1）
        if (row + col == n - 1) {
            antiDiagonal += delta;
        }

        // 检查是否获胜
        if (Math.abs(rows[row]) == n ||
            Math.abs(cols[col]) == n ||
            Math.abs(diagonal) == n ||
            Math.abs(antiDiagonal) == n) {
            return player;
        }

        // 无人获胜
        return 0;
    }
}
```

**时间复杂度：** O(1)
**空间复杂度：** O(n)

### 方法二：朴素解法（每次检查）

```java
class TicTacToe {
    private int n;
    private int[][] board;

    public TicTacToe(int n) {
        this.n = n;
        this.board = new int[n][n];
    }

    public int move(int row, int col, int player) {
        // 落子
        board[row][col] = player;

        // 检查行
        boolean win = true;
        for (int c = 0; c < n; c++) {
            if (board[row][c] != player) {
                win = false;
                break;
            }
        }
        if (win) return player;

        // 检查列
        win = true;
        for (int r = 0; r < n; r++) {
            if (board[r][col] != player) {
                win = false;
                break;
            }
        }
        if (win) return player;

        // 检查主对角线
        if (row == col) {
            win = true;
            for (int i = 0; i < n; i++) {
                if (board[i][i] != player) {
                    win = false;
                    break;
                }
            }
            if (win) return player;
        }

        // 检查副对角线
        if (row + col == n - 1) {
            win = true;
            for (int i = 0; i < n; i++) {
                if (board[i][n - 1 - i] != player) {
                    win = false;
                    break;
                }
            }
            if (win) return player;
        }

        return 0;
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n^2)

### 方法三：使用 HashMap 记录

```java
import java.util.HashMap;
import java.util.Map;

class TicTacToe {
    private int n;
    private Map<String, Integer> count;

    public TicTacToe(int n) {
        this.n = n;
        this.count = new HashMap<>();
    }

    public int move(int row, int col, int player) {
        int delta = (player == 1) ? 1 : -1;

        // 定义所有需要更新的键
        String[] keys = new String[]{
            "row" + row,
            "col" + col
        };

        // 更新行和列计数
        for (String key : keys) {
            count.put(key, count.getOrDefault(key, 0) + delta);
            if (Math.abs(count.get(key)) == n) return player;
        }

        // 更新主对角线
        if (row == col) {
            count.put("diag", count.getOrDefault("diag", 0) + delta);
            if (Math.abs(count.get("diag")) == n) return player;
        }

        // 更新副对角线
        if (row + col == n - 1) {
            count.put("antiDiag", count.getOrDefault("antiDiag", 0) + delta);
            if (Math.abs(count.get("antiDiag")) == n) return player;
        }

        return 0;
    }
}
```

## 复杂度分析

| 方法 | move() 时间 | 空间复杂度 | 优点 | 缺点 |
|------|------------|-----------|------|------|
| 计数器 | O(1) | O(n) | 最优解 | 需要理解技巧 |
| 朴素检查 | O(n) | O(n^2) | 直观 | 时间慢，空间大 |
| 字典 | O(1) | O(n) | 灵活 | 稍复杂 |

## 关键点总结

1. **计数器技巧**：用正负数区分两个玩家
2. **绝对值判断**：`Math.abs(count) == n` 判断获胜
3. **对角线条件**：主对角线 `row == col`，副对角线 `row + col == n-1`
4. **空间优化**：只需 O(n) 而不是 O(n^2)
5. **时间优化**：O(1) 判断而不是 O(n) 遍历

## 易错点

1. **玩家编号和增量**
   ```java
   // 错误：直接用 player 作为增量（player 是 1 或 2）
   int delta = player;

   // 正确：player 1 为 +1，player 2 为 -1
   int delta = (player == 1) ? 1 : -1;
   ```

2. **对角线判断**
   ```java
   // 错误：没有判断是否在对角线上，每次都更新
   diagonal += delta;

   // 正确：只有在对角线上才更新
   if (row == col) {
       diagonal += delta;
   }
   ```

3. **副对角线条件**
   ```java
   // 正确写法（两种都可以）：
   if (row + col == n - 1) { ... }
   // 等价于
   if (row == n - 1 - col) { ... }
   ```

4. **绝对值判断**
   ```java
   // 错误：只判断正数（忽略了玩家 2）
   if (rows[row] == n) return player;

   // 正确：用绝对值
   if (Math.abs(rows[row]) == n) return player;
   ```

5. **返回值**
   ```java
   // 错误：获胜时固定返回 1
   if (Math.abs(rows[row]) == n) return 1;

   // 正确：返回当前玩家编号
   if (Math.abs(rows[row]) == n) return player;
   ```
