## 题目描述

给你整数数组 `nums`，返回出现最频繁的偶数元素（相同频率时返回最小的），若无偶数返回 -1。

## 解题思路

用 HashMap 统计偶数频率，遍历找频率最大（相同时取值最小）的偶数。

## Java 代码实现

```java
class Solution {
    public int mostFrequentEven(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) if (x % 2 == 0) freq.merge(x, 1, Integer::sum);

        int ans = -1, maxFreq = 0;
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            int val = e.getKey(), cnt = e.getValue();
            // 频率更大，或频率相同但值更小，则更新
            if (cnt > maxFreq || (cnt == maxFreq && val < ans)) {
                maxFreq = cnt;
                ans = val;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 只统计偶数（包括 0）的频率，奇数忽略。
2. 找频率最大且值最小的偶数，频率相同时取较小值。
3. 若无偶数返回 -1。
