## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，按以下方法修改该数组：

- 选择某个下标 `i` 并将 `nums[i]` 替换为 `-nums[i]`

重复这个过程恰好 `k` 次。可以多次选择同一个下标 `i`。

以这种方式修改数组后，返回数组可能的最大和。

**示例 1：**
```
输入：nums = [4,2,3], k = 1
输出：5
解释：选择下标 1，nums 变为 [4,-2,3]。
```

**示例 2：**
```
输入：nums = [3,-1,0,2], k = 3
输出：6
解释：选择下标 (1, 2, 2)，nums 变为 [3,1,0,2]。
```

**示例 3：**
```
输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：选择下标 (1, 4)，nums 变为 [2,3,-1,5,4]。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-100 <= nums[i] <= 100`
- `1 <= k <= 10^4`

## 解题思路

这是一道贪心算法题，核心思想是：

**贪心策略：**
1. **优先翻转负数**：负数翻转后变成正数，和会增大
2. **从小到大翻转**：先翻转最小的负数（绝对值最大的负数），收益最大
3. **处理剩余次数**：
   - 如果 k 用完时还有负数，说明负数都翻转完了
   - 如果负数翻转完后 k 还有剩余，需要考虑剩余次数的奇偶性
   - 如果剩余次数是偶数，可以对同一个数翻转两次，相当于不变
   - 如果剩余次数是奇数，要翻转绝对值最小的数（使损失最小）

**算法流程：**
1. 将数组排序
2. 从左到右翻转负数，直到没有负数或 k 用完
3. 如果 k 还有剩余且为奇数，翻转绝对值最小的数
4. 返回数组和

## Java 代码实现

### 方法一：排序 + 贪心（推荐）

```java
import java.util.Arrays;

class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        // 排序，负数在前
        Arrays.sort(nums);

        // 尽可能翻转负数
        for (int i = 0; i < nums.length && k > 0 && nums[i] < 0; i++) {
            nums[i] = -nums[i];
            k--;
        }

        // 如果 k 还有剩余，且为奇数，翻转最小的数
        if (k % 2 == 1) {
            Arrays.sort(nums); // 重新排序找到最小值
            nums[0] = -nums[0];
        }

        // 计算总和
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        return sum;
    }
}
```

### 方法二：按绝对值降序排序（一次排序）

```java
import java.util.*;

class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        // 按绝对值从大到小排序
        Integer[] arr = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) arr[i] = nums[i];
        Arrays.sort(arr, (a, b) -> Math.abs(b) - Math.abs(a));

        // 从绝对值大的负数开始翻转
        for (int i = 0; i < arr.length; i++) {
            if (k > 0 && arr[i] < 0) {
                arr[i] = -arr[i];
                k--;
            }
        }

        // 如果 k 为奇数，翻转最后一个数（绝对值最小）
        if (k % 2 == 1) {
            arr[arr.length - 1] = -arr[arr.length - 1];
        }

        // 计算总和
        int sum = 0;
        for (int num : arr) sum += num;
        return sum;
    }
}
```

### 方法三：计数优化（适合数值范围小的情况）

```java
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        // 统计每个数出现的次数，范围 -100 到 100
        int[] count = new int[201];
        for (int num : nums) {
            count[num + 100]++;
        }

        // 从最小的负数开始翻转
        for (int i = 0; i < 100 && k > 0; i++) {
            if (count[i] > 0) {
                int ops = Math.min(count[i], k); // 翻转次数
                count[i] -= ops;
                count[200 - i] += ops; // 翻转后变成正数
                k -= ops;
            }
        }

        // 如果 k 为奇数，翻转绝对值最小的数
        if (k % 2 == 1) {
            // 找到最小的非零数
            for (int i = 100; i < 201; i++) {
                if (count[i] > 0) {
                    count[i]--;
                    count[200 - i]++;
                    break;
                }
            }
        }

        // 计算总和
        int total = 0;
        for (int i = 0; i < 201; i++) {
            total += (i - 100) * count[i];
        }
        return total;
    }
}
```

## 复杂度分析

**方法一：**
- **时间复杂度：** O(n log n)，主要是两次排序
- **空间复杂度：** O(log n)，排序的栈空间

**方法二：**
- **时间复杂度：** O(n log n)，一次排序
- **空间复杂度：** O(n)，Integer 数组

**方法三：**
- **时间复杂度：** O(n + C)，C 是数值范围（这里是 201）
- **空间复杂度：** O(C)

## 关键点总结

1. **贪心思想**：优先翻转绝对值大的负数，收益最大
2. **排序技巧**：按绝对值降序排序，可以一次遍历处理
3. **奇偶性**：剩余次数的奇偶性决定最后是否需要翻转
4. **最小损失**：如果必须翻转正数，选择绝对值最小的
5. **计数优化**：当数值范围小时，可以用计数数组代替排序

## 易错点

1. **重复排序**：方法一中需要两次排序，第二次是为了找最小值
2. **奇偶判断**：忘记判断剩余 k 的奇偶性
3. **边界情况**：
   - 数组中都是正数
   - 数组中都是负数
   - k 大于负数的个数
4. **0 的处理**：如果数组中有 0，剩余的 k 都可以用在 0 上
