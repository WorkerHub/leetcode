## 题目描述

给定一个二叉树和一个整数 k，返回距离值为 k 的节点最近的叶子节点的值。

**示例：**
```
输入：root = [1,2,3,4,null,null,null,5,null,6], k = 2
输出：3
```

## 解题思路

将树转换为无向图（建立父子双向连接），然后从目标节点 BFS 找最近叶子节点。

## Java 代码实现

```java
class Solution {
    public int findClosestLeaf(TreeNode root, int k) {
        // 构建无向图
        Map<TreeNode, List<TreeNode>> graph = new HashMap<>();
        TreeNode target = buildGraph(root, null, graph, k);

        // BFS 找最近叶子
        Queue<TreeNode> queue = new LinkedList<>();
        Set<TreeNode> visited = new HashSet<>();
        queue.offer(target);
        visited.add(target);

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            // 叶子节点判断
            if (node.left == null && node.right == null) {
                return node.val;
            }
            for (TreeNode neighbor : graph.getOrDefault(node, new ArrayList<>())) {
                if (!visited.contains(neighbor)) {
                    visited.add(neighbor);
                    queue.offer(neighbor);
                }
            }
        }
        return -1;
    }

    private TreeNode buildGraph(TreeNode node, TreeNode parent,
                                Map<TreeNode, List<TreeNode>> graph, int k) {
        if (node == null) return null;

        // 建立双向连接
        if (parent != null) {
            graph.computeIfAbsent(node, x -> new ArrayList<>()).add(parent);
            graph.computeIfAbsent(parent, x -> new ArrayList<>()).add(node);
        }

        TreeNode target = null;
        if (node.val == k) target = node;

        TreeNode left = buildGraph(node.left, node, graph, k);
        TreeNode right = buildGraph(node.right, node, graph, k);

        return target != null ? target : (left != null ? left : right);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **树转无向图**：支持向上遍历到父节点
2. **BFS 最短路径**：第一个遇到的叶子即最近
3. **叶子判断**：左右子节点均为 null
