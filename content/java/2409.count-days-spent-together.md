## 题目描述

给你 Alice 和 Bob 在罗马的到达和离开日期（格式 "MM-DD"，非闰年），返回两人同时在罗马的天数。

## 解题思路

将日期转为年中第几天，求两个区间 [arriveAlice, leaveAlice] 和 [arriveBob, leaveBob] 的重叠天数：`max(0, min(end1, end2) - max(start1, start2) + 1)`。

## Java 代码实现

```java
class Solution {
    private static final int[] DAYS = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

    public int countDaysTogether(String arriveAlice, String leaveAlice,
                                  String arriveBob, String leaveBob) {
        int a1 = toDay(arriveAlice), a2 = toDay(leaveAlice);
        int b1 = toDay(arriveBob), b2 = toDay(leaveBob);
        int overlap = Math.min(a2, b2) - Math.max(a1, b1) + 1;
        return Math.max(0, overlap);
    }

    private int toDay(String date) {
        int month = Integer.parseInt(date.substring(0, 2));
        int day = Integer.parseInt(date.substring(3));
        int total = day;
        for (int i = 0; i < month - 1; i++) total += DAYS[i];
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（固定 12 个月）
- **空间复杂度**：O(1)

## 关键点总结

1. 将 "MM-DD" 转为年中第几天，便于计算区间重叠。
2. 重叠公式：`max(0, min(end1, end2) - max(start1, start2) + 1)`，两端都包含需加 1。
3. 无重叠时公式结果为负或零，取 max(0, ...) 处理。
