## 题目描述

正方形字符数组，从右下角 'S' 到左上角 'E'，可上/左/左上移动，路径得分为经过数字之和。求 [最大得分, 最大得分的方案数]（mod 10^9+7）。

**示例：**
```
输入：board = ["E23","2X2","12S"]
输出：[7,1]
```

## 解题思路

DP：dp[i][j] = 到达 (i,j) 的最大得分，count[i][j] = 对应方案数。从右下到左上转移，每个位置从右/下/右下三个方向取最大值。

## Java 代码实现

```java
class Solution {
    public int[] pathsWithMaxScore(List<String> board) {
        int MOD = 1_000_000_007;
        int n = board.size();
        int[][] dp = new int[n][n];
        int[][] count = new int[n][n];
        
        count[n-1][n-1] = 1;
        
        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                char c = board.get(i).charAt(j);
                if (c == 'X' || count[i][j] == 0) continue;
                
                int val = (c == 'S' || c == 'E') ? 0 : c - '0';
                int[][] dirs = {{-1, 0}, {0, -1}, {-1, -1}};
                for (int[] d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni < 0 || nj < 0) continue;
                    if (board.get(ni).charAt(nj) == 'X') continue;
                    
                    int newScore = dp[i][j] + val;
                    if (c == 'S') newScore = 0;
                    
                    if (newScore > dp[ni][nj]) {
                        dp[ni][nj] = newScore;
                        count[ni][nj] = count[i][j];
                    } else if (newScore == dp[ni][nj]) {
                        count[ni][nj] = (count[ni][nj] + count[i][j]) % MOD;
                    }
                }
            }
        }
        return count[0][0] == 0 ? new int[]{0, 0} : new int[]{dp[0][0], count[0][0]};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **双 DP 数组**：dp 记录最大得分，count 记录方案数
2. **从起点推到终点**：从右下到左上
3. **更新规则**：更大则覆盖，相等则累加方案数
4. **障碍处理**：'X' 跳过
