## 题目描述

设计一个最大栈数据结构，既支持栈操作，又支持查找栈中最大元素。

实现 `MaxStack` 类：

- `MaxStack()` 初始化栈对象
- `void push(int x)` 将元素 x 压入栈中
- `int pop()` 移除栈顶元素并返回这个元素
- `int top()` 返回栈顶元素，无需移除
- `int peekMax()` 返回栈中最大元素，无需移除
- `int popMax()` 返回栈中最大元素，并将其删除。如果有多个最大元素，只删除最靠近栈顶的那个

**示例：**

```
输入
["MaxStack", "push", "push", "push", "top", "popMax", "top", "peekMax", "pop", "top"]
[[], [5], [1], [5], [], [], [], [], [], []]
输出
[null, null, null, null, 5, 5, 1, 5, 1, 5]
```

**提示：**
- `-10^7 <= x <= 10^7`
- 最多调用 `10^4` 次 `push`、`pop`、`top`、`peekMax` 和 `popMax`
- 调用 `pop`、`top`、`peekMax` 或 `popMax` 时，栈中至少存在一个元素

## 解题思路

这道题的难点在于 `popMax()` 操作，需要删除栈中间的元素。

**核心思想：**
- 使用双栈：一个普通栈 + 一个最大值栈
- popMax() 需要暂存并恢复

**方法对比：**
1. **双栈方法**：适合 push/pop/top/peekMax，但 popMax 需要 O(n)
2. **链表 + TreeMap**：所有操作都是 O(log n)

## Java 代码实现

### 方法一：双栈（简单但 popMax 较慢）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MaxStack {
    private Deque<Integer> stack;
    private Deque<Integer> maxStack;
    
    public MaxStack() {
        stack = new ArrayDeque<>();
        maxStack = new ArrayDeque<>();
    }
    
    public void push(int x) {
        stack.push(x);
        // 更新最大值栈
        if (maxStack.isEmpty()) {
            maxStack.push(x);
        } else {
            maxStack.push(Math.max(x, maxStack.peek()));
        }
    }
    
    public int pop() {
        maxStack.pop();
        return stack.pop();
    }
    
    public int top() {
        return stack.peek();
    }
    
    public int peekMax() {
        return maxStack.peek();
    }
    
    public int popMax() {
        // 找到最大值
        int maxVal = maxStack.peek();
        Deque<Integer> temp = new ArrayDeque<>();
        
        // 将最大值上面的元素暂存
        while (stack.peek() != maxVal) {
            temp.push(pop());
        }
        
        // 删除最大值
        pop();
        
        // 恢复暂存的元素
        while (!temp.isEmpty()) {
            push(temp.pop());
        }
        
        return maxVal;
    }
}
```

### 方法二：双向链表 + TreeMap（推荐，O(log n)）⭐

```java
import java.util.*;

class MaxStack {
    // 双向链表节点
    private static class Node {
        int val;
        Node prev, next;
        
        Node(int val) {
            this.val = val;
        }
    }
    
    private Node head, tail;  // 虚拟头尾节点
    // TreeMap: value -> list of nodes（从小到大排序）
    private TreeMap<Integer, List<Node>> map;
    
    public MaxStack() {
        head = new Node(0);
        tail = new Node(0);
        head.next = tail;
        tail.prev = head;
        map = new TreeMap<>();
    }
    
    public void push(int x) {
        // 添加到链表尾部（栈顶）
        Node node = new Node(x);
        node.prev = tail.prev;
        node.next = tail;
        tail.prev.next = node;
        tail.prev = node;
        
        // 更新 TreeMap
        map.computeIfAbsent(x, k -> new ArrayList<>()).add(node);
    }
    
    public int pop() {
        // 删除链表尾部节点
        Node node = tail.prev;
        removeNode(node);
        
        // 从 TreeMap 中删除
        List<Node> list = map.get(node.val);
        list.remove(list.size() - 1);
        if (list.isEmpty()) {
            map.remove(node.val);
        }
        
        return node.val;
    }
    
    public int top() {
        return tail.prev.val;
    }
    
    public int peekMax() {
        return map.lastKey();
    }
    
    public int popMax() {
        int maxVal = map.lastKey();
        List<Node> list = map.get(maxVal);
        
        // 删除最靠近栈顶的节点（list 最后一个）
        Node node = list.remove(list.size() - 1);
        if (list.isEmpty()) {
            map.remove(maxVal);
        }
        
        removeNode(node);
        
        return maxVal;
    }
    
    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
```

## 复杂度分析

### 方法一（双栈）：
- **push:** O(1)
- **pop:** O(1)
- **top:** O(1)
- **peekMax:** O(1)
- **popMax:** O(n)
- **空间复杂度：** O(n)

### 方法二（链表 + TreeMap）：
- **所有操作:** O(log n)
- **空间复杂度：** O(n)

## 关键点总结

1. **双栈思想**：维护普通栈和最大值栈
2. **popMax 优化**：使用链表可以 O(1) 删除任意节点
3. **TreeMap**：Java 中的 TreeMap 可以快速找到最大键
4. **双向链表**：方便删除中间节点
5. **最靠近栈顶**：TreeMap 中每个值对应的节点列表，最后一个是最靠近栈顶的

## 易错点

1. **popMax 实现**：要找最靠近栈顶的最大值
2. **链表删除**：要正确更新前后节点的指针
3. **TreeMap 维护**：删除元素后要检查列表是否为空
4. **多个最大值**：要删除最靠近栈顶的那个
5. **Java 的 ArrayDeque**：用 ArrayDeque 代替 Stack，性能更好
