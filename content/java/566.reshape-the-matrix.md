## 题目描述

在 MATLAB 中，有一个非常有用的函数 `reshape`，它可以将一个 `m x n` 矩阵重塑为另一个大小不同（`r x c`）的新矩阵，但保留其原始数据。

给你一个由二维数组 `mat` 表示的 `m x n` 矩阵，以及两个正整数 `r` 和 `c`，分别表示想要的重构的矩阵的行数和列数。

重构后的矩阵需要将原始矩阵的所有元素以相同的**行遍历顺序**填充。

如果具有给定参数的 `reshape` 操作是可行且合理的，则输出新的重塑矩阵；否则，输出原始矩阵。

**示例 1：**
```
输入：mat = [[1,2],[3,4]], r = 1, c = 4
输出：[[1,2,3,4]]
```

**示例 2：**
```
输入：mat = [[1,2],[3,4]], r = 2, c = 4
输出：[[1,2],[3,4]]
```

**提示：**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 100`
- `-1000 <= mat[i][j] <= 1000`
- `1 <= r, c <= 300`

## 解题思路

将二维数组展平后重新分组。

## Java 代码实现

### 方法一：索引映射（推荐）⭐

```java
class Solution {
    public int[][] matrixReshape(int[][] mat, int r, int c) {
        // 直接索引映射
        int m = mat.length, n = mat[0].length;

        // 检查是否可以重塑
        if (m * n != r * c) return mat;

        int[][] result = new int[r][c];

        for (int i = 0; i < m * n; i++) {
            // i 在原矩阵中的行列：i / n, i % n
            // i 在新矩阵中的行列：i / c, i % c
            result[i / c][i % c] = mat[i / n][i % n];
        }

        return result;
    }
}
```

### 方法二：展平后重新填充

```java
class Solution {
    public int[][] matrixReshape(int[][] mat, int r, int c) {
        // 先展平，再重新分组
        int m = mat.length, n = mat[0].length;

        if (m * n != r * c) return mat;

        // 展平到一维数组
        int[] flat = new int[m * n];
        int idx = 0;
        for (int[] row : mat) {
            for (int val : row) {
                flat[idx++] = val;
            }
        }

        // 重新填充到 r x c 矩阵
        int[][] result = new int[r][c];
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                result[i][j] = flat[i * c + j];
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)，输出数组

## 关键点总结

1. **合法性检查**：m × n == r × c
2. **索引转换**：一维索引 i 在矩阵中的行列为 `i/cols, i%cols`
3. **直接映射**：不需要真正展平，用索引映射即可
