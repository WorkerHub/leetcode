## 题目描述

将字符串 text 分成 k 块 (s1, s2, ..., sk)，要求 si == sk-i+1（回文对称），返回 k 的最大值。

**示例：**
```
输入：text = "ghiabcdefhelloadamhelloabcdefghi"
输出：7（"(ghi)(abcdef)(hello)(adam)(hello)(abcdef)(ghi)"）
```

## 解题思路

贪心：从两端同时匹配，尽早找到最短的相等子串即切分。越早切分块数越多。递归/迭代处理剩余中间部分。

## Java 代码实现

```java
class Solution {
    public int longestDecomposition(String text) {
        int n = text.length();
        if (n == 0) return 0;

        // 贪心：从两端尝试最短匹配
        for (int len = 1; len <= n / 2; len++) {
            if (text.substring(0, len).equals(text.substring(n - len))) {
                // 匹配成功，递归处理中间部分
                return 2 + longestDecomposition(text.substring(len, n - len));
            }
        }

        // 无法匹配，整个作为一块
        return 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，每层匹配 O(n)，最多 O(n) 层
- **空间复杂度**：O(n)，递归栈 + substring

## 关键点总结

1. **贪心正确性**：越早切分，剩余部分可切分的可能性越多
2. **两端匹配**：左前缀 == 右后缀时立即切分
3. **递归处理**：切掉两端后递归中间
4. **无匹配返回 1**：整个字符串不可再分时作为单独一块
