## 题目描述

给你正整数数组 `nums`，若子数组包含数组中所有不同值则称为完整子数组，返回完整子数组的数目。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countCompleteSubarrays(int[] nums) {
        int n = nums.length;
        // 统计整个数组不同值数量
        Set<Integer> all = new HashSet<>();
        for (int x : nums) all.add(x);
        int total = all.size();

        int ans = 0, left = 0, distinct = 0;
        Map<Integer, Integer> cnt = new HashMap<>();

        for (int right = 0; right < n; right++) {
            cnt.merge(nums[right], 1, Integer::sum);
            if (cnt.get(nums[right]) == 1) distinct++;

            // 收缩左端：窗口已满足条件时，right 之后的右端也满足
            while (distinct == total) {
                ans += n - right;
                cnt.merge(nums[left], -1, Integer::sum);
                if (cnt.get(nums[left]) == 0) distinct--;
                left++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为不同值数量

## 关键点总结

1. 滑动窗口维护窗口内不同值数量等于 total
2. 找到最小满足条件的右端后，`n - right` 为该左端的贡献
3. 收缩左端同时更新计数
