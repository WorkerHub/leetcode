## 题目描述

给你 `n` 个城市和道路数组 `roads`（含边权），路径分数为路径上的最小距离，路径可重复经过同一道路。返回城市 1 到城市 n 之间所有路径的最小分数。

## 解题思路

由于路径可以重复走边，城市 1 和城市 n 连通分量内的所有边均可使用，答案即为该连通分量中所有边的最小权重。BFS 从节点 1 遍历连通分量，收集所有边权取最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minScore(int n, int[][] roads) {
        List<int[]>[] adj = new List[n + 1];
        for (int i = 1; i <= n; i++) adj[i] = new ArrayList<>();
        for (int[] road : roads) {
            adj[road[0]].add(new int[]{road[1], road[2]});
            adj[road[1]].add(new int[]{road[0], road[2]});
        }

        // BFS 从节点 1 出发，找连通分量中所有边的最小权重
        boolean[] visited = new boolean[n + 1];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(1);
        visited[1] = true;
        int minScore = Integer.MAX_VALUE;

        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int[] e : adj[u]) {
                minScore = Math.min(minScore, e[1]); // 更新最小边权
                if (!visited[e[0]]) {
                    visited[e[0]] = true;
                    queue.offer(e[0]);
                }
            }
        }
        return minScore;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 路径可重复走边，因此 1 和 n 连通分量内的所有边都可使用
2. 答案 = 连通分量中所有边的最小权重，无需求最短路
3. BFS/DFS 遍历连通分量，收集所有边权取最小值即可
