## 题目描述

给你两个字符串 `s` 和 `t`（`t` 是 `s` 的排列），对 `s` 中每个字符计算其在 `s` 和 `t` 中位置的绝对差，返回所有差值之和（**排列差**）。

## 解题思路

用哈希表记录每个字符在 `t` 中的位置，遍历 `s` 累加每个字符的位置绝对差。

## Java 代码实现

```java
class Solution {
    public int findPermutationDifference(String s, String t) {
        // 记录每个字符在 t 中的位置
        int[] posT = new int[26];
        for (int i = 0; i < t.length(); i++) {
            posT[t.charAt(i) - 'a'] = i;
        }
        int ans = 0;
        // 遍历 s，累加位置绝对差
        for (int i = 0; i < s.length(); i++) {
            ans += Math.abs(i - posT[s.charAt(i) - 'a']);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（字母表大小固定为 26）

## 关键点总结

1. 用大小为 26 的数组代替哈希表，存储每个字符在 t 中的索引
2. 遍历 s，对每个字符计算位置差的绝对值并累加
