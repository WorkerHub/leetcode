## 题目描述

编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 `'1'` 的个数（也被称为汉明重量）。

**提示：**
- 请注意，在某些语言（如 Java）中，没有无符号整数类型。在这种情况下，输入和输出都将被指定为有符号整数类型，并且不应影响您的实现，因为无论整数是有符号的还是无符号的，其内部的二进制表示形式都是相同的。
- 在 Java 中，编译器使用二进制补码记法来表示有符号整数。因此，在上面的示例 3 中，输入表示有符号整数 `-3`。

**示例 1：**
```
输入：n = 00000000000000000000000000001011
输出：3
解释：输入的二进制串 00000000000000000000000000001011 中，共有三位为 '1'。
```

**示例 2：**
```
输入：n = 00000000000000000000000010000000
输出：1
解释：输入的二进制串 00000000000000000000000010000000 中，共有一位为 '1'。
```

**示例 3：**
```
输入：n = 11111111111111111111111111111101
输出：31
解释：输入的二进制串 11111111111111111111111111111101 中，共有 31 位为 '1'。
```

**提示：**
- 输入必须是长度为 `32` 的二进制串。

**进阶：**
- 如果多次调用这个函数，你将如何优化你的算法？

## 解题思路

这道题要求统计二进制中 1 的个数，是位运算的经典问题。

### 方法一：逐位检查

最直观的方法：遍历 32 位，检查每一位是否为 1。

### 方法二：n & (n-1) 技巧⭐

这是最优雅的解法，核心观察：
- `n & (n-1)` 会消除 n 最右边的一个 1
- 重复这个操作，直到 n 变为 0
- 操作次数就是 1 的个数

**为什么有效？**
- `n-1` 会将最右边的 1 变为 0，并将右边的所有 0 变为 1
- `n & (n-1)` 会消除最右边的 1

例如：
```
n     = 1100  (12)
n-1   = 1011  (11)
n&(n-1) = 1000  (8)  消除了最右边的 1
```

### 方法三：位移统计

每次右移一位，检查最低位是否为 1。

## Java 代码实现

### 方法一：n & (n-1) 技巧（推荐）⭐

```java
public class Solution {
    // 使用 n & (n-1) 消除最右边的 1
    // 时间复杂度：O(k)，k 是 1 的个数
    // 空间复杂度：O(1)
    public int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            n = n & (n - 1);  // 消除最右边的 1
            count++;
        }
        return count;
    }
}
```

### 方法二：逐位检查

```java
public class Solution {
    // 检查每一位是否为 1
    // 时间复杂度：O(32) = O(1)
    // 空间复杂度：O(1)
    public int hammingWeight(int n) {
        int count = 0;
        for (int i = 0; i < 32; i++) {
            if (((n >>> i) & 1) == 1) {  // 无符号右移，检查第 i 位是否为 1
                count++;
            }
        }
        return count;
    }
}
```

### 方法三：无符号右移 + 与运算

```java
public class Solution {
    // 每次检查最低位，然后无符号右移
    // 时间复杂度：O(32) = O(1)
    // 空间复杂度：O(1)
    public int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            count += n & 1;  // 检查最低位
            n >>>= 1;        // 无符号右移一位（避免符号位扩展）
        }
        return count;
    }
}
```

### 方法四：Java 内置函数（最简洁）

```java
public class Solution {
    // 使用 Java 内置的 Integer.bitCount()
    // 不推荐面试使用，但代码最简洁
    public int hammingWeight(int n) {
        return Integer.bitCount(n);
    }
}
```

### 方法五：查找表（进阶优化）

```java
public class Solution {
    // 预计算 8 位的所有情况（0-255）
    private int[] lookup = new int[256];

    public Solution() {
        for (int i = 1; i < 256; i++) {
            lookup[i] = (i & 1) + lookup[i >> 1];
        }
    }

    // 使用查找表，将 32 位分为 4 个 8 位处理
    // 多次调用时效率更高
    // 时间复杂度：O(1)，固定 4 次查表
    // 空间复杂度：O(1)，固定 256 个元素
    public int hammingWeight(int n) {
        int count = 0;
        for (int i = 0; i < 4; i++) {
            count += lookup[n & 0xff];  // 查表
            n >>>= 8;  // 处理下一个 8 位
        }
        return count;
    }
}
```

### 方法六：分治法（位运算魔法）

```java
public class Solution {
    // 使用位运算实现并行计数
    // SWAR (SIMD Within A Register) 算法
    public int hammingWeight(int n) {
        // 每 2 位一组，计算 1 的个数
        n = (n & 0x55555555) + ((n >>> 1) & 0x55555555);
        // 每 4 位一组，累加
        n = (n & 0x33333333) + ((n >>> 2) & 0x33333333);
        // 每 8 位一组，累加
        n = (n & 0x0f0f0f0f) + ((n >>> 4) & 0x0f0f0f0f);
        // 每 16 位一组，累加
        n = (n & 0x00ff00ff) + ((n >>> 8) & 0x00ff00ff);
        // 最后 32 位累加
        n = (n & 0x0000ffff) + ((n >>> 16) & 0x0000ffff);
        return n;
    }
}
```

## 复杂度分析

**方法一（n & (n-1)）：**
- **时间复杂度**：O(k)，k 是 1 的个数，最好情况 O(1)，最坏 O(32)
- **空间复杂度**：O(1)

**方法二、三：**
- **时间复杂度**：O(32) = O(1)，固定遍历 32 次
- **空间复杂度**：O(1)

**方法五（查找表）：**
- **时间复杂度**：O(1)，固定 4 次查表
- **空间复杂度**：O(1)，固定 256 个元素

## 关键点总结

1. **核心技巧**：`n & (n-1)` 消除最右边的 1
2. **位运算基础**：
   - `n & 1`：检查最低位是否为 1
   - `n >>> 1`：无符号右移一位（Java 中处理负数必须用 `>>>`）
   - `(n >>> i) & 1`：检查第 i 位
3. **时间优化**：方法一的循环次数取决于 1 的个数，而不是位数
4. **Java 特性**：虽然 `Integer.bitCount(n)` 最简洁，但面试建议用位运算
5. **进阶优化**：查找表、SWAR 算法适合多次调用

## 易错点

1. **循环条件错误**：应该是 `while (n != 0)`，而不是固定次数
   ```java
   while (n != 0) { ... }   // ✅ n 不为 0 就继续
   for (int i = 0; i < 32; i++) { ... }  // 也可以，但效率较低
   ```

2. **Java 中必须使用无符号右移**：
   ```java
   n >>>= 1;   // ✅ 无符号右移，高位补 0
   n >>= 1;    // ❌ 算术右移，负数时高位补 1，会导致死循环
   ```

3. **位运算优先级**：`&` 的优先级低于 `==`
   ```java
   if (((n >>> i) & 1) == 1) { ... }  // ✅ 正确（括号明确优先级）
   if ((n >>> i) & 1 == 1) { ... }    // ❌ 等价于 (n >>> i) & (1 == 1)
   ```

4. **n & (n-1) 的理解错误**：
   ```java
   n = n & (n - 1);   // ✅ 消除最右边的 1
   n = n & n - 1;     // ❌ 等价于 (n & n) - 1（运算符优先级问题）
   ```

5. **Java 中整数溢出**：
   ```java
   // Java 中 int 是有符号 32 位，但补码表示和无符号相同
   // 使用 >>> 进行无符号右移即可正确处理
   n >>>= 1;  // ✅ 正确处理负数（有符号整数的位操作）
   ```

## 学习建议

1. **掌握 n & (n-1) 技巧**：
   - 这是位运算中最重要的技巧之一
   - 理解为什么能消除最右边的 1
   - 在纸上手动模拟几个例子

2. **理解位运算基础**：
   ```java
   n & 1         // 取最低位
   n >>> 1       // 无符号右移一位（Java 推荐）
   n << 1        // 左移一位
   (n >>> i) & 1 // 取第 i 位
   ```

3. **比较不同方法**：
   - 方法一：最优雅，循环次数少
   - 方法三：最直观，容易理解
   - 方法四：最简洁，但不利于学习

4. **应用场景**：
   - 判断是否为 2 的幂：`n > 0 && (n & (n - 1)) == 0`
   - 计算汉明距离：`Integer.bitCount(x ^ y)`
   - 统计子集个数：需要遍历所有位

**新手学习路径**：
1. 先实现方法三（最直观）
2. 理解 `n & (n-1)` 的原理
3. 实现方法一（最优解）
4. 手动模拟几个例子加深理解
5. 进阶学习 SWAR 算法（可选）
