## 题目描述

给你整数数组 `nums` 和整数 `k`，可以从数组中删除最多 k 个元素，使得剩余数组的最大子数组和最大化。返回最大化后的最大子数组和。

## 解题思路

DP：`dp[j]` 表示删除了 j 个元素、以当前位置结尾的最大子数组和。对每个元素转移：加入当前元素（不删）或删除当前元素（删除数 +1）。同时维护"重新开始"的选项。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maxSubarraySum(int[] nums, int k) {
        int n = nums.length;
        long ans = Long.MIN_VALUE;
        final long NEG_INF = Long.MIN_VALUE / 2;

        // dp[j] = 删除j个元素，以当前位置结尾的最大子数组和
        long[] dp = new long[k + 2];
        Arrays.fill(dp, NEG_INF);

        for (int i = 0; i < n; i++) {
            long[] newDp = new long[k + 2];
            Arrays.fill(newDp, NEG_INF);
            for (int j = 0; j <= k; j++) {
                if (dp[j] == NEG_INF) continue;
                // 将nums[i]加入子数组
                newDp[j] = Math.max(newDp[j], dp[j] + nums[i]);
                // 删除nums[i]（删除数+1）
                if (j + 1 <= k) {
                    newDp[j + 1] = Math.max(newDp[j + 1], dp[j]);
                }
            }
            // 重新开始以nums[i]为起点的子数组
            newDp[0] = Math.max(newDp[0], nums[i]);
            dp = newDp;
            for (int j = 0; j <= k; j++) {
                if (dp[j] != NEG_INF) ans = Math.max(ans, dp[j]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. DP 状态：以 i 结尾，已删除 j 个元素的最大子数组和
2. 转移：加入当前元素（不删），或删除当前元素（删除数 +1）
3. 每个位置允许重新开始子数组
