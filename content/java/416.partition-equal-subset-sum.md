## 题目描述

给你一个只包含正整数的非空数组 nums。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**
```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11]
```

**示例 2：**
```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集
```

## 解题思路

这是一个经典的 0-1 背包问题。

核心观察：
1. 如果总和是奇数，不可能分成两个相等的子集
2. 问题转化为：能否从数组中选择若干数字，使得和为 total / 2

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public boolean canPartition(int[] nums) {
        // 0-1 背包问题
        int total = 0;
        for (int num : nums) total += num;

        // 总和为奇数，不可能分成两个相等的子集
        if (total % 2 != 0) return false;

        int target = total / 2;

        // dp[i] 表示能否凑出和为 i
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;  // 和为 0 总是可以（不选任何数）

        for (int num : nums) {
            // 从后向前遍历，避免重复使用同一个数
            for (int i = target; i >= num; i--) {
                dp[i] = dp[i] || dp[i - num];
            }
        }

        return dp[target];
    }
}
```

### 方法二：使用集合

```java
import java.util.*;

class Solution {
    public boolean canPartition(int[] nums) {
        // 使用集合记录所有可能的和
        int total = 0;
        for (int num : nums) total += num;
        if (total % 2 != 0) return false;

        int target = total / 2;
        Set<Integer> possibleSums = new HashSet<>();
        possibleSums.add(0);

        for (int num : nums) {
            // 创建新集合存储新的可能和（避免在遍历时修改）
            Set<Integer> newSums = new HashSet<>();
            for (int s : possibleSums) {
                if (s + num == target) return true;
                newSums.add(s + num);
            }
            possibleSums.addAll(newSums);
        }

        return possibleSums.contains(target);
    }
}
```

### 方法三：位运算优化

```java
import java.math.BigInteger;

class Solution {
    public boolean canPartition(int[] nums) {
        // 使用 BigInteger 模拟位运算（因 Java 的 int/long 位数有限）
        int total = 0;
        for (int num : nums) total += num;
        if (total % 2 != 0) return false;

        int target = total / 2;
        // bits 的第 i 位为 1 表示可以凑出和 i
        BigInteger bits = BigInteger.ONE;

        for (int num : nums) {
            bits = bits.or(bits.shiftLeft(num));
        }

        // 检查第 target 位是否为 1
        return bits.testBit(target);
    }
}
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n * target)
- **空间复杂度**：O(target)

## 关键点总结

1. 转化为 0-1 背包问题
2. 目标是 sum / 2
3. 从后向前更新避免重复使用

## 易错点

1. 忘记判断总和是否为奇数
2. 背包 DP 遍历顺序错误（应从后向前）
