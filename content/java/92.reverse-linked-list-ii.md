## 题目描述

给你单链表的头指针 `head` 和两个整数 `left` 和 `right`，其中 `left <= right`。请你反转从位置 `left` 到位置 `right` 的链表节点，返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5], left = 2, right = 4
输出：[1,4,3,2,5]
```

**示例 2：**
```
输入：head = [5], left = 1, right = 1
输出：[5]
```

**提示：**
- 链表中节点数目为 `n`
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

**进阶：** 你可以使用一趟扫描完成反转吗？

## 解题思路

**核心思想：部分链表反转**

这道题是在完整链表反转的基础上，只反转指定区间 `[left, right]` 的节点。

**关键观察：**
1. 需要找到 `left - 1` 位置的节点（反转区域的前一个节点）
2. 反转 `[left, right]` 区间的节点
3. 将反转后的部分重新连接到原链表

**步骤分解：**
1. 找到第 `left - 1` 个节点（称为 `pre`）
2. 从第 `left` 个节点开始反转，反转 `right - left + 1` 个节点
3. 连接三部分：前半部分 → 反转部分 → 后半部分

**两种方法：**
- 方法一：头插法（一次遍历）
- 方法二：穿针引线法（先反转再连接）

## Java 代码实现

### 方法一：头插法（推荐）

```java
// Definition for singly-linked list.
// public class ListNode {
//     int val;
//     ListNode next;
//     ListNode() {}
//     ListNode(int val) { this.val = val; }
//     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
// }

class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 使用哑节点简化边界处理
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode pre = dummy;

        // 找到 left - 1 位置的节点
        for (int i = 0; i < left - 1; i++) {
            pre = pre.next;
        }

        // cur 指向 left 位置的节点
        ListNode cur = pre.next;

        // 反转 right - left 次
        // 每次将 cur.next 移动到 pre.next
        for (int i = 0; i < right - left; i++) {
            // 保存要移动的节点
            ListNode nextNode = cur.next;
            // 将 cur.next 指向 nextNode.next
            cur.next = nextNode.next;
            // 将 nextNode 插入到 pre 后面
            nextNode.next = pre.next;
            pre.next = nextNode;
        }

        return dummy.next;
    }
}
```

### 方法二：穿针引线法

```java
class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 哑节点
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode pre = dummy;

        // 找到 left - 1 位置的节点
        for (int i = 0; i < left - 1; i++) {
            pre = pre.next;
        }

        // left 位置的节点
        ListNode leftNode = pre.next;

        // 找到 right 位置的节点
        ListNode rightNode = leftNode;
        for (int i = 0; i < right - left; i++) {
            rightNode = rightNode.next;
        }

        // 保存 right 后面的节点
        ListNode succ = rightNode.next;

        // 切断链表
        pre.next = null;
        rightNode.next = null;

        // 反转 [left, right] 部分
        reverseList(leftNode);

        // 重新连接
        pre.next = rightNode; // rightNode 现在是反转后的头节点
        leftNode.next = succ; // leftNode 现在是反转后的尾节点

        return dummy.next;
    }

    // 反转链表的辅助方法
    private ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode nextNode = cur.next;
            cur.next = pre;
            pre = cur;
            cur = nextNode;
        }
        return pre;
    }
}
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)，n 为链表长度，遍历一次
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 `head = [1,2,3,4,5], left = 2, right = 4` 为例（方法一：头插法）：

```
初始状态：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
        pre  cur

第 1 次操作（将节点 3 移到前面）：
dummy -> 1 -> 3 -> 2 -> 4 -> 5 -> null
        pre       cur

第 2 次操作（将节点 4 移到前面）：
dummy -> 1 -> 4 -> 3 -> 2 -> 5 -> null
        pre            cur

结果：[1,4,3,2,5]
```

**穿针引线法图解：**
```
原链表：
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> null
        pre  left      right succ

切断：
dummy -> 1    2 -> 3 -> 4    5 -> null
        pre  left      right succ

反转中间部分：
dummy -> 1    4 -> 3 -> 2    5 -> null
        pre  right     left succ

重新连接：
dummy -> 1 -> 4 -> 3 -> 2 -> 5 -> null
```

## 关键点总结

1. **哑节点**：处理从头节点开始反转的情况（left = 1）
2. **头插法**：每次将待反转的节点插入到反转区域的头部
3. **穿针引线**：先找到关键节点，断开、反转、重连
4. **反转次数**：需要反转 `right - left` 次，不是 `right - left + 1` 次
5. **指针维护**：pre 始终指向反转区域的前一个节点

## 易错点

1. **边界情况**：left = 1 时，需要反转头节点（使用哑节点解决）
2. **反转次数**：头插法需要操作 `right - left` 次
3. **指针混乱**：头插法中 cur 始终不动，移动的是 cur.next
4. **连接错误**：穿针引线法要正确连接三部分
5. **Java 中没有 null 检查**：访问节点前要确认节点不为 null
