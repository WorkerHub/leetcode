## 题目描述

给整数数组 nums，每步可交换相邻两个置位数（二进制 1 的个数）相同的元素，判断能否排序。

## 解题思路

将数组划分为连续的"块"（同一块内置位数相同），块内元素可任意排序。只需验证相邻块之间前块最大值 ≤ 后块最小值。

## Java 代码实现

```java
class Solution {
    public boolean canSortArray(int[] nums) {
        int n = nums.length;
        int i = 0;
        int prevMax = 0; // 上一个块的最大值
        while (i < n) {
            int j = i;
            int bits = Integer.bitCount(nums[i]);
            int blockMin = nums[i], blockMax = nums[i];
            // 找当前块的右边界
            while (j < n && Integer.bitCount(nums[j]) == bits) {
                blockMin = Math.min(blockMin, nums[j]);
                blockMax = Math.max(blockMax, nums[j]);
                j++;
            }
            // 当前块最小值必须大于上一块最大值
            if (blockMin < prevMax) return false;
            prevMax = blockMax;
            i = j;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 块是连续的同置位数段，不同置位数的元素不能越过彼此
2. 块内可任意排序，只需验证相邻块边界
3. Integer.bitCount() 直接获取置位数
