## 题目描述

矩阵初始全 0，每次操作将左上角子矩阵加 1。求最终矩阵最大值的个数。

**示例：**
```
输入：m = 3, n = 3, ops = [[2,2],[3,3]]
输出：4
```

## Java 代码实现

```java
class Solution {
    public int maxCount(int m, int n, int[][] ops) {
        if (ops.length == 0) return m * n;
        int minA = m, minB = n;
        for (int[] op : ops) {
            minA = Math.min(minA, op[0]);
            minB = Math.min(minB, op[1]);
        }
        return minA * minB;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k)
- **空间复杂度**：O(1)

## 关键点总结

1. 最大值出现在所有操作的交集区域
2. 交集面积 = min(所有a) × min(所有b)
