## 题目描述

给定两个以升序排列的整数数组 `nums1` 和 `nums2`，以及一个整数 `k`。

定义一对值 `(u, v)`，其中第一个元素来自 `nums1`，第二个元素来自 `nums2`。

请找到和最小的 `k` 个数对 `(u1, v1)`, `(u2, v2)` ... `(uk, vk)`。

**示例 1：**

```
输入：nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出：[[1,2],[1,4],[1,6]]
解释：返回序列中的前 3 对数：
     [1,2], [1,4], [1,6], [7,2], [7,4], [11,2] ...
```

**示例 2：**

```
输入：nums1 = [1,1,2], nums2 = [1,2,3], k = 2
输出：[[1,1],[1,1]]
解释：返回序列中的前 2 对数：
     [1,1], [1,1], [1,2], [1,2], [1,3], [2,1] ...
```

**提示：**
- `1 <= nums1.length, nums2.length <= 10^5`
- `-10^9 <= nums1[i], nums2[i] <= 10^9`
- `nums1` 和 `nums2` 均为升序排列
- `1 <= k <= 10^4`
- `k <= nums1.length * nums2.length`

## 解题思路

这道题类似于合并 k 个有序链表，核心思想是使用**最小堆**。

### 关键观察

1. `nums1` 和 `nums2` 都是有序的
2. 对于 `nums1[i]`，与 `nums2` 的配对 `(nums1[i], nums2[0])`, `(nums1[i], nums2[1])`, ... 和是递增的
3. 最小的数对一定是 `(nums1[0], nums2[0])`

### 算法思路

**方法一：最小堆（推荐）**
1. 初始化：将 `(nums1[i], nums2[0])` 加入最小堆（i 从 0 到 min(k, len(nums1))-1）
2. 每次从堆中取出和最小的数对 `(nums1[i], nums2[j])`
3. 将下一个候选 `(nums1[i], nums2[j+1])` 加入堆
4. 重复 k 次

**优化**：初始只加入前 k 个元素，避免堆过大。

## Java 代码实现

### 方法一：最小堆（推荐）

```java
import java.util.*;

class Solution {
    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        List<List<Integer>> result = new ArrayList<>();
        if (nums1.length == 0 || nums2.length == 0) return result;

        // 最小堆：存储 [和, nums1索引, nums2索引]
        // 按和升序排列
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);

        // 初始化：将 nums1 的前 k 个元素与 nums2[0] 配对加入堆
        for (int i = 0; i < Math.min(k, nums1.length); i++) {
            minHeap.offer(new int[]{nums1[i] + nums2[0], i, 0});
        }

        // 取出 k 个最小的数对
        while (k > 0 && !minHeap.isEmpty()) {
            int[] curr = minHeap.poll();
            int i = curr[1], j = curr[2];
            result.add(Arrays.asList(nums1[i], nums2[j]));

            // 将下一个候选加入堆（向下扩展）
            if (j + 1 < nums2.length) {
                minHeap.offer(new int[]{nums1[i] + nums2[j + 1], i, j + 1});
            }
            k--;
        }

        return result;
    }
}
```

### 方法二：使用 visited 集合避免重复

```java
import java.util.*;

class Solution {
    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        List<List<Integer>> result = new ArrayList<>();
        if (nums1.length == 0 || nums2.length == 0) return result;

        // 最小堆：[和, i, j]
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        Set<Long> visited = new HashSet<>();

        // 编码 (i, j) 为唯一 long，避免重复
        long key = (long) 0 * nums2.length + 0;
        minHeap.offer(new int[]{nums1[0] + nums2[0], 0, 0});
        visited.add(key);

        while (k > 0 && !minHeap.isEmpty()) {
            int[] curr = minHeap.poll();
            int i = curr[1], j = curr[2];
            result.add(Arrays.asList(nums1[i], nums2[j]));

            // 向右扩展
            if (i + 1 < nums1.length) {
                long nextKey = (long)(i + 1) * nums2.length + j;
                if (!visited.contains(nextKey)) {
                    minHeap.offer(new int[]{nums1[i + 1] + nums2[j], i + 1, j});
                    visited.add(nextKey);
                }
            }

            // 向下扩展
            if (j + 1 < nums2.length) {
                long nextKey = (long) i * nums2.length + (j + 1);
                if (!visited.contains(nextKey)) {
                    minHeap.offer(new int[]{nums1[i] + nums2[j + 1], i, j + 1});
                    visited.add(nextKey);
                }
            }

            k--;
        }

        return result;
    }
}
```

### 方法三：暴力 + 排序（不推荐，超时）

```java
import java.util.*;

class Solution {
    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        // 生成所有数对并排序
        List<int[]> pairs = new ArrayList<>();
        for (int num1 : nums1) {
            for (int num2 : nums2) {
                pairs.add(new int[]{num1, num2});
            }
        }

        // 按和排序
        pairs.sort((a, b) -> (a[0] + a[1]) - (b[0] + b[1]));

        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < Math.min(k, pairs.size()); i++) {
            result.add(Arrays.asList(pairs.get(i)[0], pairs.get(i)[1]));
        }
        return result;
    }
}
```

## 复杂度分析

### 方法一：最小堆
- 时间复杂度：O(k log k)
  - 堆初始化：O(min(k, m) log k)
  - k 次堆操作：O(k log k)
- 空间复杂度：O(min(k, m))，堆的大小

### 方法二：优化的最小堆
- 时间复杂度：O(k log k)
- 空间复杂度：O(k)

### 方法三：暴力
- 时间复杂度：O(m × n × log(m × n))
- 空间复杂度：O(m × n)

## 关键点总结

1. **最小堆的使用**：维护当前最小的候选数对
2. **初始化策略**：只初始化 nums1 的前 k 个与 nums2[0] 的配对
3. **扩展方向**：每次只向一个方向扩展（向下），避免重复
4. **优化边界**：`Math.min(k, nums1.length)` 避免不必要的初始化
5. **有序性利用**：利用数组有序的性质，逐步扩展

## 易错点

1. **重复添加**：如果不小心，可能会重复添加同一个数对
2. **堆的大小**：初始化时不要一次性加入所有可能的配对
3. **边界检查**：`j + 1 < nums2.length` 防止越界
4. **k 的限制**：k 可能大于实际数对数量
5. **空数组**：nums1 或 nums2 为空的情况
6. **整数溢出**：两数之和可能溢出 int，但本题数据范围不超出

## 图解示例

### 示例：nums1 = [1,7,11], nums2 = [2,4,6], k = 3

```
初始堆（只加入第一列）：
[(1+2, 0, 0), (7+2, 1, 0), (11+2, 2, 0)]
即：[(3, 0, 0), (9, 1, 0), (13, 2, 0)]

第 1 次：弹出 (3, 0, 0) -> [1, 2]
  加入 (1+4, 0, 1) = (5, 0, 1)
  堆：[(5, 0, 1), (9, 1, 0), (13, 2, 0)]

第 2 次：弹出 (5, 0, 1) -> [1, 4]
  加入 (1+6, 0, 2) = (7, 0, 2)
  堆：[(7, 0, 2), (9, 1, 0), (13, 2, 0)]

第 3 次：弹出 (7, 0, 2) -> [1, 6]
  j+1 = 3 >= nums2.length，不加入新元素
  堆：[(9, 1, 0), (13, 2, 0)]

结果：[[1,2], [1,4], [1,6]]
```
