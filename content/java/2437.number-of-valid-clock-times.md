## 题目描述

给你格式为 `hh:mm` 的字符串 `time`，其中部分数字被 `?` 替代，返回该模式可以表示的有效时间数目（有效时间为 `00:00` 到 `23:59`）。

## 解题思路

分别枚举合法的小时（0-23）和分钟（0-59），统计各自与模式匹配的个数，两者相乘即为答案。

## Java 代码实现

```java
class Solution {
    public int countTime(String time) {
        String hPat = time.substring(0, 2);
        String mPat = time.substring(3, 5);

        int hCount = 0, mCount = 0;
        // 统计合法小时数（0-23）
        for (int h = 0; h < 24; h++) {
            if (matches(hPat, h)) hCount++;
        }
        // 统计合法分钟数（0-59）
        for (int m = 0; m < 60; m++) {
            if (matches(mPat, m)) mCount++;
        }
        return hCount * mCount;
    }

    // 检查两位数 val 是否与模式 pat 匹配（? 可匹配任何数字）
    private boolean matches(String pat, int val) {
        String s = String.format("%02d", val);
        return (pat.charAt(0) == '?' || pat.charAt(0) == s.charAt(0))
            && (pat.charAt(1) == '?' || pat.charAt(1) == s.charAt(1));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(24 + 60) = O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 小时和分钟独立匹配，结果相乘
2. `?` 可以匹配任何数字字符
3. 小时范围 0-23，分钟范围 0-59
