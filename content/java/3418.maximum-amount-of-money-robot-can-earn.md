## 题目描述

给定 m×n 矩阵 `coins`（可含负数），机器人从 (0,0) 出发只能向右或向下，可中和最多 2 个负数格子（设为 0），返回能收集的最多金币。

## Java 代码实现

```java
class Solution {
    public int maximumAmount(int[][] coins) {
        int m = coins.length, n = coins[0].length;
        final int NEG_INF = Integer.MIN_VALUE / 2;

        // dp[i][j][k] = 到达 (i,j)，已用 k 次中和的最大金币
        int[][][] dp = new int[m][n][3];
        for (int[][] row : dp) for (int[] cell : row) java.util.Arrays.fill(cell, NEG_INF);

        dp[0][0][0] = coins[0][0];
        if (coins[0][0] < 0) dp[0][0][1] = 0; // 起点中和

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int c = coins[i][j];
                for (int k = 0; k < 3; k++) {
                    int fromUp = i > 0 ? dp[i-1][j][k] : NEG_INF;
                    int fromLeft = j > 0 ? dp[i][j-1][k] : NEG_INF;
                    int prev = Math.max(fromUp, fromLeft);
                    // 不使用中和
                    if (prev > NEG_INF) dp[i][j][k] = Math.max(dp[i][j][k], prev + c);
                    // 使用中和（k-1 -> k）
                    if (k > 0) {
                        int fromUpK1 = i > 0 ? dp[i-1][j][k-1] : NEG_INF;
                        int fromLeftK1 = j > 0 ? dp[i][j-1][k-1] : NEG_INF;
                        int prevK1 = Math.max(fromUpK1, fromLeftK1);
                        if (prevK1 > NEG_INF) dp[i][j][k] = Math.max(dp[i][j][k], prevK1);
                    }
                }
            }
        }

        return Math.max(dp[m-1][n-1][0], Math.max(dp[m-1][n-1][1], dp[m-1][n-1][2]));
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 3) = O(m * n)
- 空间复杂度：O(m * n * 3)

## 关键点总结

1. 状态：(位置, 已用中和次数)，共 3 层 DP（k=0,1,2）。
2. 转移：不使用中和时加当前格子值；使用中和时格子贡献为 0（相当于不加）。
3. 取终点三种状态的最大值。
