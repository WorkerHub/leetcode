## 题目描述

给你迷宫矩阵 `maze` 和入口 `entrance`，返回从入口到最近边界空格（出口）的最短步数，不存在则返回 -1（入口不算出口）。

## 解题思路

BFS 从入口出发，第一次到达边界空格即为最短路径。入口本身排除在外，访问标记在入队时设置。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int nearestExit(char[][] maze, int[] entrance) {
        int m = maze.length, n = maze[0].length;
        int sr = entrance[0], sc = entrance[1];
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{sr, sc, 0});
        maze[sr][sc] = '+'; // 标记入口已访问

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], steps = cur[2];
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && maze[nr][nc] == '.') {
                    // 是出口（边界且非入口）
                    if (nr == 0 || nr == m - 1 || nc == 0 || nc == n - 1) return steps + 1;
                    maze[nr][nc] = '+'; // 标记已访问
                    queue.offer(new int[]{nr, nc, steps + 1});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn)
- **空间复杂度**：O(mn)，队列

## 关键点总结

1. BFS 保证找到最短路径
2. 出口：在边界上的空格，且不是入口
3. 访问标记在入队时设置，防止重复入队
