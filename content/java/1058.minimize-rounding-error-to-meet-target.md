## 题目描述

给定价格字符串数组和目标整数 target，将每个价格向上或向下取整使总和等于 target，返回最小总舍入误差。不可能则返回 "-1"。

**示例：**
```
输入：prices = ["0.700","2.800","4.900"], target = 8
输出："1.000"
```

## 解题思路

贪心：计算全部向下取整的和 floor_sum，需要 k=target-floor_sum 个向上取整。选择小数部分最大的 k 个向上取整可最小化误差。

## Java 代码实现

```java
class Solution {
    public String minimizeError(String[] prices, int target) {
        List<Double> fractions = new ArrayList<>();
        int floorSum = 0;

        for (String p : prices) {
            double price = Double.parseDouble(p);
            int floor = (int) price;
            floorSum += floor;
            double frac = price - floor;
            if (frac > 1e-9) {
                fractions.add(frac);
            }
        }

        int needCeil = target - floorSum;

        // 可行性检查
        if (needCeil < 0 || needCeil > fractions.size()) {
            return "-1";
        }

        // 按小数部分降序排序
        fractions.sort(Collections.reverseOrder());

        double error = 0.0;
        // 前 needCeil 个向上取整
        for (int i = 0; i < needCeil; i++) {
            error += 1 - fractions.get(i);
        }
        // 其余向下取整
        for (int i = needCeil; i < fractions.size(); i++) {
            error += fractions.get(i);
        }

        return String.format("%.3f", error);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心**：小数部分大的向上取整误差小（1-frac 小）
2. **可行性**：floor_sum ≤ target ≤ floor_sum + 非整数个数
3. **格式化输出**：保留 3 位小数
