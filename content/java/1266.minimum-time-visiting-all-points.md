## 题目描述

平面上有 n 个点，八方向移动（每步可水平/垂直/对角），按顺序访问所有点的最少时间。

**示例：**
```
输入：points = [[1,1],[3,4],[-1,0]]
输出：7
解释：[1,1]->[3,4] 需 3 秒，[3,4]->[-1,0] 需 4 秒
```

## 解题思路

相邻两点的最少步数 = 切比雪夫距离 = max(|dx|, |dy|)。累加所有相邻点的距离即可。

## Java 代码实现

```java
class Solution {
    public int minTimeToVisitAllPoints(int[][] points) {
        int time = 0;
        for (int i = 1; i < points.length; i++) {
            int dx = Math.abs(points[i][0] - points[i-1][0]);
            int dy = Math.abs(points[i][1] - points[i-1][1]);
            time += Math.max(dx, dy); // 切比雪夫距离
        }
        return time;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **切比雪夫距离**：max(|dx|, |dy|) 即为八方向移动的最短步数
2. **对角移动**：先走 min(dx,dy) 步对角，再走剩余直线步
3. **按序累加**：必须按给定顺序访问
