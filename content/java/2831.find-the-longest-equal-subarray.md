## 题目描述

删除最多k个元素后，找最长的全相同元素子数组。

## 解题思路

对每种值v，记录其出现位置列表。滑动窗口：窗口内需删除的元素=窗口原数组长度-v出现次数，<=k时合法。

## Java 代码实现

```java
class Solution {
    public int longestEqualSubarray(List<Integer> nums, int k) {
        int n = nums.size();
        // 记录每个值出现的位置
        Map<Integer, List<Integer>> positions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            positions.computeIfAbsent(nums.get(i), x -> new ArrayList<>()).add(i);
        }

        int ans = 1;
        for (List<Integer> pos : positions.values()) {
            int left = 0;
            for (int right = 0; right < pos.size(); right++) {
                // 需删除的元素数 = 原数组窗口长度 - v出现次数
                while (pos.get(right) - pos.get(left) + 1 - (right - left + 1) > k) {
                    left++;
                }
                ans = Math.max(ans, right - left + 1);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **按值分组记录位置**：对每种值独立滑动窗口
2. **需删除数=原数组窗口长-v出现次数**
3. **所有值的窗口left移动次数总和为O(N)**
