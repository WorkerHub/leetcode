## 题目描述

给你两个正整数 `n` 和 `k`。

如果正整数 `i` 满足 `n % i == 0`，那么我们就说正整数 `i` 是整数 `n` 的因子。

请你返回 `n` 的第 `k` 个**最小因子**。如果 `n` 的因子数量少于 `k`，请你返回 **-1**。

**示例 1：**

```
输入：n = 12, k = 3
输出：3
解释：12 的因子有 1, 2, 3, 4, 6, 12，第 3 小的因子是 3。
```

**示例 2：**

```
输入：n = 7, k = 2
输出：7
解释：7 是质数，因子只有 1 和 7，第 2 小的因子是 7。
```

**示例 3：**

```
输入：n = 4, k = 4
输出：-1
解释：4 的因子有 1, 2, 4，共 3 个，第 4 小因子不存在，返回 -1。
```

**提示：**

- `1 <= k <= n <= 1000`

## 解题思路

**方法一：暴力枚举（O(n)）**

从 1 到 n 依次检查每个数是否为 n 的因子，找到第 k 个因子即返回。

适合 n 较小的情况（n <= 1000 完全够用）。

**方法二：枚举到 sqrt(n)（O(sqrt(n))）**

对于正整数 n，若 `i` 是 n 的因子，则 `n/i` 也是 n 的因子，且因子成对出现。

枚举 1 到 sqrt(n) 的所有因子，分为两组：
- 小因子：1 到 sqrt(n) 范围内整除 n 的数（按升序）
- 大因子：对应的 n/i（按降序）

将两组拼接，若 k 落在第一组则直接返回，否则在第二组中查找。

注意若 n 是完全平方数，sqrt(n) 只能算一次。

## Java 代码实现

### 方法一：暴力枚举（推荐，简单直观）

```java
class Solution {
    public int kthFactor(int n, int k) {
        int count = 0;  // 已找到的因子数量
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) {  // i 是 n 的因子
                count++;
                if (count == k) {
                    return i;
                }
            }
        }
        // 因子数不足 k 个
        return -1;
    }
}
```

### 方法二：枚举到 sqrt(n)，分两阶段查找（O(sqrt(n))）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int kthFactor(int n, int k) {
        // 第一阶段：收集小因子（1 到 sqrt(n)）
        List<Integer> smallFactors = new ArrayList<>();
        for (int i = 1; (long) i * i <= n; i++) {
            if (n % i == 0) {
                smallFactors.add(i);
            }
        }

        // 检查 k 是否在小因子中
        if (k <= smallFactors.size()) {
            return smallFactors.get(k - 1);
        }

        // 在大因子中查找
        k -= smallFactors.size();

        // 大因子从大到小，对应小因子从大到小
        // 跳过完全平方根（避免重复）
        int start = smallFactors.size() - 1;
        if ((long) smallFactors.get(start) * smallFactors.get(start) == n) {
            start--;  // 完全平方根已被计入小因子，跳过对应大因子
        }

        // 从大因子中找第 k 个
        for (int idx = start; idx >= 0; idx--) {
            k--;
            if (k == 0) {
                return n / smallFactors.get(idx);
            }
        }

        return -1;
    }
}
```

### 方法三：收集所有因子再索引（代码最简洁）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int kthFactor(int n, int k) {
        // 收集所有因子（按升序）
        List<Integer> factors = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) factors.add(i);
        }
        // 若存在第 k 个因子则返回，否则返回 -1
        return k <= factors.size() ? factors.get(k - 1) : -1;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（暴力枚举） | O(n) | O(1) |
| 方法二（sqrt 优化） | O(sqrt(n)) | O(sqrt(n)) |
| 方法三（收集因子） | O(n) | O(d(n))，d(n) 为因子个数 |

- 由于 `n <= 1000`，所有方法都非常快
- 方法二在数学上最优，但代码略复杂；对此题规模而言方法一更推荐

## 关键点总结

1. **因子成对出现**：若 `i` 整除 `n`，则 `n/i` 也整除 `n`，且 `i <= sqrt(n)` 时 `n/i >= sqrt(n)`。
2. **完全平方数特判**：当 `n` 是完全平方数时，`sqrt(n)` 只计算一次，避免重复。
3. **k 超过因子总数时返回 -1**：统计因子数量后判断即可。
4. **因子升序**：从 1 到 n 枚举天然保证升序。

## 易错点

- **完全平方数重复计算**：方法二中枚举到 sqrt(n) 时，若 `i * i == n`，大小因子相同，不能重复计数。
- **k 从 1 开始**：第 k 个因子对应 `get(k-1)`（0 索引）。
- **返回 -1 的条件**：因子总数 < k 时才返回 -1，等于时可以返回。
