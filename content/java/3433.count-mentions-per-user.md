## 题目描述

给定 `numberOfUsers` 和事件列表 `events`（MESSAGE 或 OFFLINE 类型），模拟用户在线状态并统计每个用户被 @ 的次数。离线用户 60 个时间单位后重新上线。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countMentions(int numberOfUsers, List<List<String>> events) {
        // 按时间排序，同时间戳时 OFFLINE 先处理
        events.sort((a, b) -> {
            int ta = Integer.parseInt(a.get(1)), tb = Integer.parseInt(b.get(1));
            if (ta != tb) return ta - tb;
            return a.get(0).equals("OFFLINE") ? -1 : 1;
        });

        int[] mentions = new int[numberOfUsers];
        // offlineUntil[i] = 用户 i 重新上线的时间（>时间戳时为离线）
        int[] offlineUntil = new int[numberOfUsers];

        for (List<String> event : events) {
            String type = event.get(0);
            int t = Integer.parseInt(event.get(1));

            if (type.equals("OFFLINE")) {
                int uid = Integer.parseInt(event.get(2));
                offlineUntil[uid] = t + 60;
            } else { // MESSAGE
                String data = event.get(2);
                if (data.equals("ALL")) {
                    // @所有用户
                    for (int i = 0; i < numberOfUsers; i++) mentions[i]++;
                } else if (data.equals("HERE")) {
                    // @在线用户（offlineUntil[i] <= t 表示在线）
                    for (int i = 0; i < numberOfUsers; i++) {
                        if (offlineUntil[i] <= t) mentions[i]++;
                    }
                } else {
                    // @具体用户列表
                    for (String uid : data.split(" ")) {
                        int id = Integer.parseInt(uid.substring(2)); // 去掉 "id" 前缀
                        mentions[id]++;
                    }
                }
            }
        }
        return mentions;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m + m * n)，m 为事件数，n 为用户数
- 空间复杂度：O(n + m)

## 关键点总结

1. 同时间戳时 OFFLINE 事件先于 MESSAGE 处理
2. HERE 只 @ 当前在线用户（offlineUntil[i] <= 当前时间）
3. 用户 ID 以 "id" 开头，转换时去掉前两个字符
