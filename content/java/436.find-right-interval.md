## 题目描述

给你一个区间数组 `intervals`，其中 `intervals[i] = [starti, endi]`，且每个 `starti` 都不同。

区间 `i` 的右侧区间可以记作区间 `j`，并满足 `startj >= endi`，且 `startj` 最小化。注意 `i` 可能等于 `j`。

返回一个由每个区间 `i` 的右侧区间在 `intervals` 中对应下标组成的数组。如果某个区间 `i` 不存在对应的右侧区间，则下标 `i` 处的值设为 `-1`。

**示例 1：**
```
输入：intervals = [[1,2]]
输出：[-1]
解释：集合中只有一个区间，所以输出-1。
```

**示例 2：**
```
输入：intervals = [[3,4],[2,3],[1,2]]
输出：[-1,0,1]
解释：对于 [3,4] ，没有满足条件的"右侧"区间。
对于 [2,3] ，区间[3,4]具有最小的"右"起点;
对于 [1,2] ，区间[2,3]具有最小的"右"起点。
```

**示例 3：**
```
输入：intervals = [[1,4],[2,3],[3,4]]
输出：[-1,2,-1]
解释：对于区间 [1,4] 和 [3,4] ，没有满足条件的"右侧"区间。
对于 [2,3] ，区间 [3,4] 有最小的"右"起点。
```

**提示：**
- `1 <= intervals.length <= 2 * 10^4`
- `intervals[i].length == 2`
- `-10^6 <= starti <= endi <= 10^6`
- 每个区间的起点都不相同

## 解题思路

这道题要求找到每个区间的"右侧区间"，即起点大于等于当前区间终点的最小起点区间。

**关键观察：**
1. 右侧区间的起点 >= 当前区间的终点
2. 要找起点最小的那个
3. 可以先按起点排序，然后用二分查找

**算法流程：**
1. 记录每个区间的原始索引
2. 按起点排序
3. 对每个区间，用二分查找找到起点 >= 其终点的最小区间
4. 返回原始索引

## Java 代码实现

### 方法一：TreeMap（ceilingKey）⭐ 推荐

```java
import java.util.*;

class Solution {
    public int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        
        // 建立起点到原始索引的映射（TreeMap 自动按 key 升序）
        TreeMap<Integer, Integer> map = new TreeMap<>();
        for (int i = 0; i < n; i++) {
            map.put(intervals[i][0], i);
        }
        
        int[] result = new int[n];
        
        for (int i = 0; i < n; i++) {
            int end = intervals[i][1];
            
            // ceilingEntry 返回键值 >= end 的最小条目
            Map.Entry<Integer, Integer> entry = map.ceilingEntry(end);
            result[i] = (entry == null) ? -1 : entry.getValue();
        }
        
        return result;
    }
}
```

### 方法二：排序 + 二分查找

```java
import java.util.*;

class Solution {
    public int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        
        // 创建 [起点, 原始索引] 的数组并排序
        int[][] starts = new int[n][2];
        for (int i = 0; i < n; i++) {
            starts[i] = new int[]{intervals[i][0], i};
        }
        Arrays.sort(starts, (a, b) -> a[0] - b[0]);
        
        // 提取排序后的起点值，用于二分查找
        int[] startVals = new int[n];
        for (int i = 0; i < n; i++) {
            startVals[i] = starts[i][0];
        }
        
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            int end = intervals[i][1];
            
            // 二分查找：找到第一个起点 >= end 的区间
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (startVals[mid] < end) {
                    lo = mid + 1;
                } else {
                    hi = mid;
                }
            }
            
            result[i] = lo < n ? starts[lo][1] : -1;
        }
        
        return result;
    }
}
```

### 方法三：暴力解法（超时，仅用于理解）

```java
class Solution {
    public int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        int[] result = new int[n];
        
        for (int i = 0; i < n; i++) {
            int end = intervals[i][1];
            int minStart = Integer.MAX_VALUE;
            int rightIdx = -1;
            
            // 遍历所有区间，找到起点最小的右侧区间
            for (int j = 0; j < n; j++) {
                int start = intervals[j][0];
                if (start >= end && start < minStart) {
                    minStart = start;
                    rightIdx = j;
                }
            }
            
            result[i] = rightIdx;
        }
        
        return result;
    }
}
```

### 方法四：双指针

```java
import java.util.*;

class Solution {
    public int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        
        // 按起点排序，记录原始索引
        int[][] startSorted = new int[n][2];
        int[][] endSorted = new int[n][2];
        for (int i = 0; i < n; i++) {
            startSorted[i] = new int[]{intervals[i][0], i};
            endSorted[i] = new int[]{intervals[i][1], i};
        }
        Arrays.sort(startSorted, (a, b) -> a[0] - b[0]);
        Arrays.sort(endSorted, (a, b) -> a[0] - b[0]);
        
        int[] result = new int[n];
        Arrays.fill(result, -1);
        int j = 0;
        
        // 遍历按终点排序的区间
        for (int[] endInfo : endSorted) {
            int end = endInfo[0];
            int origIdx = endInfo[1];
            
            // 找到第一个起点 >= end 的区间
            while (j < n && startSorted[j][0] < end) {
                j++;
            }
            
            if (j < n) {
                result[origIdx] = startSorted[j][1];
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

**方法一：TreeMap**
- 时间复杂度：O(n log n)
  - 建立 TreeMap：O(n log n)
  - 每次 ceilingEntry 查询：O(log n)，共 n 次
- 空间复杂度：O(n)

**方法二：排序 + 二分**
- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

**方法三：暴力**
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

## 图解示例

以 `intervals = [[3,4],[2,3],[1,2]]` 为例：

```
原始区间（索引）：
0: [3,4]
1: [2,3]
2: [1,2]

按起点排序（TreeMap）：
1 -> 索引2
2 -> 索引1
3 -> 索引0

查找过程：
- 区间0 [3,4]，end=4
  查找 start >= 4：无 → -1

- 区间1 [2,3]，end=3
  查找 start >= 3：找到起点3 → 索引0

- 区间2 [1,2]，end=2
  查找 start >= 2：找到起点2 → 索引1

结果：[-1, 0, 1]
```

## 关键点总结

1. **TreeMap 应用**：ceilingKey/ceilingEntry 可以直接找到第一个 >= 目标值的键
2. **二分查找应用**：在有序数组中查找第一个满足条件的元素
3. **索引映射**：排序后要保留原始索引
4. **边界处理**：查找结果可能不存在，返回 -1
5. **双指针优化**：按终点遍历，按起点查找

## 易错点

1. **索引保存**：排序后要记录原始索引
2. **ceilingEntry vs ceilingKey**：需要原始索引时用 ceilingEntry
3. **边界检查**：二分查找结果可能越界
4. **重复起点**：题目保证起点不重复，简化了问题
5. **自己可以是右侧**：区间可以是自己的右侧区间（i 可以等于 j）
