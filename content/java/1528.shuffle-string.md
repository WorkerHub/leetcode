## 题目描述

给定字符串 s 和 indices 数组，将 s[i] 移到 indices[i] 位置，返回结果。

**示例：**
```
输入：s = "codeleet", indices = [4,5,6,7,0,2,1,3]
输出："leetcode"
```

## 解题思路

新建字符数组，result[indices[i]] = s[i]。

## Java 代码实现

```java
class Solution {
    public String restoreString(String s, int[] indices) {
        char[] result = new char[s.length()];
        for (int i = 0; i < s.length(); i++) {
            result[indices[i]] = s.charAt(i);
        }
        return new String(result);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **映射关系**：indices[i] 是 s[i] 的目标位置
2. **一次遍历**：直接放置到正确位置
