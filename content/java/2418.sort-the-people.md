## 题目描述

给你字符串数组 `names` 和互不相同的正整数数组 `heights`，按身高**降序**返回对应的名字数组。

## 解题思路

将下标数组按对应身高降序排序，然后按排序后的下标提取名字即可。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public String[] sortPeople(String[] names, int[] heights) {
        int n = names.length;
        // 构建下标数组，按身高降序排序
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> heights[b] - heights[a]);

        // 按排序后的下标提取名字
        String[] ans = new String[n];
        for (int i = 0; i < n; i++) {
            ans[i] = names[indices[i]];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 对下标数组排序，避免直接修改原数组
2. 按身高降序排序（comparator 用 `heights[b] - heights[a]`）
3. 题目保证身高互不相同，无需处理相等情况
