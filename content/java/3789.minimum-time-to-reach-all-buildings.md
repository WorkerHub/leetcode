## 题目描述

给定 `m × n` 矩阵 `grid`（0=空格，1=建筑），找一个空格作为集合点，使从集合点到所有建筑物 BFS 距离之和最小，若无法到达所有建筑返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        // 收集所有建筑物位置
        List<int[]> buildings = new ArrayList<>();
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1) buildings.add(new int[]{i, j});

        int k = buildings.size();
        int[][] distSum = new int[m][n];
        int[][] reachCount = new int[m][n];

        // 从每个建筑物做 BFS
        for (int[] b : buildings) {
            int[][] dist = new int[m][n];
            for (int[] row : dist) Arrays.fill(row, -1);
            dist[b[0]][b[1]] = 0;
            Queue<int[]> queue = new LinkedList<>();
            queue.offer(b);
            while (!queue.isEmpty()) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && grid[nr][nc] == 0 && dist[nr][nc] == -1) {
                        dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
            for (int i = 0; i < m; i++)
                for (int j = 0; j < n; j++)
                    if (grid[i][j] == 0 && dist[i][j] != -1) {
                        distSum[i][j] += dist[i][j];
                        reachCount[i][j]++;
                    }
        }

        // 找能到达所有建筑物的空格中距离和最小的
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 0 && reachCount[i][j] == k)
                    ans = Math.min(ans, distSum[i][j]);

        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * mn)，k 为建筑物数量
- 空间复杂度：O(mn)

## 关键点总结

1. 从每个建筑物出发做 BFS，计算到所有空格的距离
2. 集合点必须能到达所有建筑物（`reachCount == k`）
3. 最小化所有到建筑物距离之和
