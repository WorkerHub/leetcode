## 题目描述

给定排列 `perm`（包含 0 到 n-1），每次可将一个元素移到数组末尾，求使数组升序排列的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] perm) {
        int n = perm.length;
        // 从后向前找最长连续有序后缀 [..., n-k, n-k+1, ..., n-1]
        int k = 0;
        int expected = n - 1;
        for (int i = n - 1; i >= 0; i--) {
            if (perm[i] == expected) {
                k++;
                expected--;
            } else break;
        }
        return n - k;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 从后向前找最长连续有序后缀，该后缀中的元素不需要移动
2. 后缀必须连续，一旦中断就停止计数
3. 最少操作 = n - 最长有序后缀长度
