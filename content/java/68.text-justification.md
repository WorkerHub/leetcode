## 题目描述

给定一个单词数组 `words` 和一个长度 `maxWidth`，重新排版单词，使其成为每行恰好有 `maxWidth` 个字符，且左右两端对齐的文本。

你应该使用贪心算法来放置给定的单词；也就是说，尽可能多地往每行中放置单词。必要时可用空格 `' '` 填充，使得每行恰好有 `maxWidth` 个字符。

要求尽可能均匀分配单词间的空格数量。如果某一行单词间的空格不能均匀分配，则左侧放置的空格数要多于右侧的空格数。

文本的最后一行应为左对齐，且单词之间不插入额外的空格。

**提示：**
- `1 <= words.length <= 300`
- `1 <= words[i].length <= 20`
- `words[i]` 由小写英文字母和符号组成
- `1 <= maxWidth <= 100`
- `words[i].length <= maxWidth`

## 解题思路

这道题较为繁琐，需要分情况处理：
1. 普通行：均匀分配空格
2. 最后一行：左对齐
3. 单词间隙分配空格

## Java 代码实现

```java
class Solution {
    public List<String> fullJustify(String[] words, int maxWidth) {
        List<String> result = new ArrayList<>();
        int i = 0;

        while (i < words.length) {
            // 确定当前行能放多少单词
            List<String> lineWords = new ArrayList<>();
            lineWords.add(words[i]);
            int lineLength = words[i].length();
            i++;

            while (i < words.length && lineLength + 1 + words[i].length() <= maxWidth) {
                lineWords.add(words[i]);
                lineLength += 1 + words[i].length();
                i++;
            }

            // 构建当前行
            StringBuilder line = new StringBuilder();
            if (i == words.length || lineWords.size() == 1) {
                // 最后一行或只有一个单词：左对齐
                line.append(String.join(" ", lineWords));
                // 右侧补空格
                while (line.length() < maxWidth) {
                    line.append(' ');
                }
            } else {
                // 普通行，均匀分配空格
                int totalChars = lineWords.stream().mapToInt(String::length).sum();
                int totalSpaces = maxWidth - totalChars;
                int gaps = lineWords.size() - 1;

                int spacePerGap = totalSpaces / gaps;
                int extraSpaces = totalSpaces % gaps;

                for (int j = 0; j < lineWords.size() - 1; j++) {
                    line.append(lineWords.get(j));
                    // 基础空格
                    for (int k = 0; k < spacePerGap; k++) {
                        line.append(' ');
                    }
                    // 多余的空格从左侧开始分配
                    if (j < extraSpaces) {
                        line.append(' ');
                    }
                }
                line.append(lineWords.get(lineWords.size() - 1));
            }

            result.add(line.toString());
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)
