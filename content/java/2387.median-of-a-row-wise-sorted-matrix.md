## 题目描述

给你 m×n 的整数矩阵 `grid`（每行已排序，m*n 为奇数），返回矩阵中的中位数。

## 解题思路

二分答案：在值域 [1, 10^6] 上二分，找最小的 x 使得矩阵中 <=x 的元素个数 >= (m*n+1)/2。对每行用 `Arrays.binarySearch` 或手写二分统计 <=x 的个数。

## Java 代码实现

```java
class Solution {
    public int matrixMedian(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int target = (m * n + 1) / 2; // 中位数排名
        int lo = 1, hi = 1_000_000;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            // 统计矩阵中 <= mid 的元素个数
            int count = 0;
            for (int[] row : grid) {
                // 二分找第一个 > mid 的位置
                int l = 0, r = n;
                while (l < r) {
                    int m2 = (l + r) / 2;
                    if (row[m2] <= mid) l = m2 + 1;
                    else r = m2;
                }
                count += l; // l 即为 <= mid 的个数
            }
            if (count >= target) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * log(n) * log(max_val))
- **空间复杂度**：O(1)

## 关键点总结

1. 二分答案在值域 [1, 10^6] 上进行，而非下标。
2. 每行用二分统计 <=x 的元素数，利用行有序特性。
3. 中位数是排名第 (m*n+1)/2 小的元素（总元素数为奇数）。
