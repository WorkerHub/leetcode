## 题目描述

给定长度为2的字符串数组words，选部分字符串拼成最长回文串，返回其长度。

## 解题思路

非对称词（如"lc"和"cl"）成对使用贡献4；对称词（如"gg"）偶数个对称使用贡献4，额外一个可放中心贡献2。

## Java 代码实现

```java
class Solution {
    public int longestPalindrome(String[] words) {
        Map<String, Integer> cnt = new HashMap<>();
        for (String w : words) cnt.merge(w, 1, Integer::sum);
        
        int ans = 0;
        boolean hasCenter = false;
        
        for (Map.Entry<String, Integer> entry : cnt.entrySet()) {
            String w = entry.getKey();
            int count = entry.getValue();
            String rev = "" + w.charAt(1) + w.charAt(0);
            
            if (w.equals(rev)) {
                // 对称词
                ans += (count / 2) * 4;
                if (count % 2 == 1) hasCenter = true;
            } else if (w.compareTo(rev) < 0) {
                // 非对称词对，只处理字典序小的
                int pairs = Math.min(count, cnt.getOrDefault(rev, 0));
                ans += pairs * 4;
            }
        }
        
        if (hasCenter) ans += 2;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **非对称词成对**：min(cnt[w], cnt[rev]) * 4
2. **对称词偶数对**：(count/2) * 4
3. **中心位置**：最多放一个奇数对称词
