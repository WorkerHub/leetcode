## 题目描述

给定整数 n，计算长度为 n 的字符串数量，满足：每个字符是元音(a,e,i,o,u)，且遵循后继规则：a→e, e→a/i, i→除i外所有, o→i/u, u→a。答案对 10^9+7 取模。

**示例：**
```
输入：n = 2
输出：10（"ae","ea","ei","ia","ie","io","iu","oi","ou","ua"）
```

## 解题思路

DP：dp[v] 表示以元音 v 结尾的字符串数量。根据规则反向推导：谁能转移到 v → dp[v] = 对应前驱之和。

## Java 代码实现

```java
class Solution {
    public int countVowelPermutation(int n) {
        long MOD = 1_000_000_007;
        // a=0, e=1, i=2, o=3, u=4
        long[] dp = new long[5];
        Arrays.fill(dp, 1); // 长度为 1 时每个元音各 1 种
        
        for (int i = 2; i <= n; i++) {
            long[] newDp = new long[5];
            // 以 a 结尾：前一个可以是 e, i, u
            newDp[0] = (dp[1] + dp[2] + dp[4]) % MOD;
            // 以 e 结尾：前一个可以是 a, i
            newDp[1] = (dp[0] + dp[2]) % MOD;
            // 以 i 结尾：前一个可以是 e, o
            newDp[2] = (dp[1] + dp[3]) % MOD;
            // 以 o 结尾：前一个只能是 i
            newDp[3] = dp[2] % MOD;
            // 以 u 结尾：前一个可以是 i, o
            newDp[4] = (dp[2] + dp[3]) % MOD;
            dp = newDp;
        }
        
        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（只用固定大小数组）

## 关键点总结

1. **反向转移**：从"谁能跟在 v 前面"推导状态转移
2. **滚动数组**：只需前一轮的状态，空间 O(1)
3. **取模**：每步运算后取模防止溢出
4. **用 long**：中间加法可能超过 int 范围
