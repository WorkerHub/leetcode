## 题目描述

在歌曲列表中，第 `i` 首歌曲的持续时间为 `time[i]` 秒。

返回其总持续时间（以秒为单位）可被 `60` 整除的歌曲对的数量。形式上，我们希望下标数字 `i` 和 `j` 满足 `i < j` 且 `(time[i] + time[j]) % 60 == 0`。

**示例 1：**
```
输入：time = [30,20,150,100,40]
输出：3
解释：这三对的总持续时间可被 60 整除：
(time[0] = 30, time[2] = 150): 总持续时间 180
(time[1] = 20, time[3] = 100): 总持续时间 120
(time[1] = 20, time[4] = 40): 总持续时间 60
```

**示例 2：**
```
输入：time = [60,60,60]
输出：3
解释：所有三对的总持续时间都是 120，可以被 60 整除。
```

**提示：**
- `1 <= time.length <= 6 * 10^4`
- `1 <= time[i] <= 500`

## 解题思路

这道题类似于"两数之和"问题，但目标是找和能被60整除的配对。

**核心观察**：
- `(a + b) % 60 == 0` 等价于 `(a % 60 + b % 60) % 60 == 0`
- 只需关注每个数对60的余数
- 余数范围：0-59

**配对规律**：
1. 余数为0的数，需要配对另一个余数为0的数
2. 余数为30的数，需要配对另一个余数为30的数
3. 余数为r的数，需要配对余数为(60-r)的数

**算法步骤**：
1. 统计每个余数出现的次数
2. 遍历数组，对每个数找它的配对余数
3. 累加配对数量

## Java 代码实现

### 方法一：一次遍历计数（推荐）

```java
class Solution {
    public int numPairsDivisibleBy60(int[] time) {
        // 记录每个余数出现的次数
        int[] remainderCount = new int[60];
        int result = 0;

        for (int t : time) {
            // 计算当前时间的余数
            int r = t % 60;

            // 需要配对的余数
            // 如果r=0，需要找余数也为0的（(60-0)%60 = 0）
            // 否则需要找余数为60-r的
            int target = (60 - r) % 60;

            // 累加之前出现过的配对数
            result += remainderCount[target];

            // 更新当前余数的计数
            remainderCount[r]++;
        }

        return result;
    }
}
```

### 方法二：详细分类讨论

```java
class Solution {
    public int numPairsDivisibleBy60(int[] time) {
        int[] remainderCount = new int[60];

        // 统计所有余数
        for (int t : time) {
            remainderCount[t % 60]++;
        }

        int result = 0;

        // 余数为0的情况：任意两个配对
        // C(n, 2) = n * (n-1) / 2
        long n0 = remainderCount[0];
        result += (int)(n0 * (n0 - 1) / 2);

        // 余数为30的情况：任意两个配对
        long n30 = remainderCount[30];
        result += (int)(n30 * (n30 - 1) / 2);

        // 其他余数：r和60-r配对
        for (int r = 1; r < 30; r++) {
            result += remainderCount[r] * remainderCount[60 - r];
        }

        return result;
    }
}
```

## 复杂度分析

所有方法的时间和空间复杂度：
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(1)，最多存储60个余数

其中 n 为数组长度

## 关键点总结

1. **取模运算**：`(a + b) % 60 == 0` 转化为余数问题
2. **哈希表应用**：记录余数出现次数，快速查找配对
3. **特殊情况**：余数0和30需要自己配对
4. **一次遍历**：边遍历边统计，避免重复计算
5. **组合数学**：n个相同余数配对数 = C(n,2) = n*(n-1)/2

## 易错点

1. **重复计数**：使用一次遍历时，先查找后更新，避免重复
2. **余数为0**：`(60 - 0) % 60 = 0`，需要特殊处理
3. **余数为30**：30+30=60，也能整除，不要遗漏
4. **配对公式**：相同余数配对用组合数，不同余数用乘法
5. **边界情况**：数组长度为1时返回0
