## 题目描述

给定 n×n 方形整数数组 matrix，返回下降路径的最小和。从第一行任意元素开始，每次可选正下方或左下/右下相邻的元素。

**示例：**
```
输入：matrix = [[2,1,3],[6,5,4],[7,8,9]]
输出：13（路径 1→5→7）
```

## 解题思路

动态规划：dp[j] 表示到达当前行第 j 列的最小路径和。每行更新时取上一行 j-1、j、j+1 的最小值。

## Java 代码实现

```java
class Solution {
    public int minFallingPathSum(int[][] matrix) {
        int n = matrix.length;
        int[] dp = matrix[0].clone();

        for (int i = 1; i < n; i++) {
            int[] newDp = new int[n];
            for (int j = 0; j < n; j++) {
                int minPrev = dp[j];
                if (j > 0) minPrev = Math.min(minPrev, dp[j - 1]);
                if (j < n - 1) minPrev = Math.min(minPrev, dp[j + 1]);
                newDp[j] = matrix[i][j] + minPrev;
            }
            dp = newDp;
        }

        int result = dp[0];
        for (int x : dp) result = Math.min(result, x);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **逐行 DP**：每行只依赖上一行
2. **三方向选择**：正下、左下、右下
3. **滚动数组**：空间从 O(n²) 优化到 O(n)
