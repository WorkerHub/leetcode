## 题目描述

给定二进制字符串 `s` 和 `k`（整除 `s` 的长度），通过最少翻转次数使字符串变为 k-周期字符串（`s[i] == s[i+k]`），返回最少翻转次数。

## Java 代码实现

```java
class Solution {
    public int minimumFlips(String s, int k) {
        int n = s.length();
        int total = 0;
        // 对每个列 j in [0, k)，统计 s[j], s[j+k], s[j+2k]... 中 0 和 1 的个数
        for (int j = 0; j < k; j++) {
            int ones = 0, count = 0;
            for (int i = j; i < n; i += k) {
                if (s.charAt(i) == '1') ones++;
                count++;
            }
            // 翻转较少的那种
            total += Math.min(ones, count - ones);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. k-周期 => 将字符串分为 k 列，每列内字符必须全部相同
2. 每列最少翻转 = `min(0的个数, 1的个数)`
3. 各列独立决策，总翻转为所有列的翻转之和
