## 题目描述

站在location处，视野角度为angle度可自由旋转，求能看到的最多点数。与location重合的点始终可见。

## 解题思路

极角排序+滑动窗口：将点转为极角（度数），排序后复制一份+360处理环形。滑动窗口找angle度内最多的点。

## Java 代码实现

```java
class Solution {
    public int visiblePoints(List<List<Integer>> points, int angle, List<Integer> location) {
        int ox = location.get(0), oy = location.get(1);
        List<Double> angles = new ArrayList<>();
        int same = 0;
        
        for (List<Integer> p : points) {
            int px = p.get(0), py = p.get(1);
            if (px == ox && py == oy) {
                same++;
                continue;
            }
            // 计算极角（度数）
            double a = Math.toDegrees(Math.atan2(py - oy, px - ox));
            angles.add(a);
        }
        
        Collections.sort(angles);
        int n = angles.size();
        // 复制一份+360处理环形
        List<Double> ext = new ArrayList<>(angles);
        for (double a : angles) ext.add(a + 360);
        
        // 滑动窗口
        int maxVisible = 0, left = 0;
        for (int right = 0; right < ext.size(); right++) {
            while (ext.get(right) - ext.get(left) > angle) {
                left++;
            }
            maxVisible = Math.max(maxVisible, right - left + 1);
        }
        
        return maxVisible + same;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **atan2(y,x)**：计算极角，注意参数顺序
2. **+360处理环形**：视野可跨越0度
3. **重合点单独计数**：避免atan2(0,0)
4. **边界可见**：用`>`而非`>=`
