## 题目描述

给定整数数组 `nums`，若两个元素 GCD 严格大于 1 则可互换，判断能否通过若干次交换使数组有序。

## 解题思路

GCD > 1 等价于共享质因数。用并查集将共享同一质因数的所有数合并。最后检查对每个位置 i，`nums[i]` 与排序后该位置的数是否在同一连通分量中。

## Java 代码实现

### 方法一：并查集 + 质因数分解（推荐）

```java
import java.util.*;

class Solution {
    private int[] parent;

    public boolean gcdSort(int[] nums) {
        int maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);
        parent = new int[maxVal + 1];
        for (int i = 0; i <= maxVal; i++) parent[i] = i;

        // 对每个数做质因数分解，将该数与其质因数合并
        for (int v : nums) {
            int x = v;
            for (int d = 2; (long) d * d <= x; d++) {
                if (x % d == 0) {
                    union(v, d);
                    while (x % d == 0) x /= d;
                }
            }
            if (x > 1) union(v, x);
        }

        // 检查排序后每个位置对应的数是否在同一连通分量
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        for (int i = 0; i < nums.length; i++) {
            if (find(nums[i]) != find(sorted[i])) return false;
        }
        return true;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]]; // 路径压缩
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(M) * α(M))，M = max(nums)
- 空间复杂度：O(M)

## 关键点总结

1. GCD > 1 等价于共享质因数，用并查集连通共享质因数的元素
2. 将每个数与其所有质因数合并（而非两两比较）
3. 并查集开到 max(nums)+1 大小，合并的是数值而非下标
