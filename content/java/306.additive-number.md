## 题目描述

**累加数**是一个字符串，组成它的数字可以形成累加序列。

一个有效的**累加序列**必须**至少**包含 3 个数。除了最开始的两个数以外，序列中的每个后续数字必须是它之前两个数字之和。

给你一个只包含数字 `'0'-'9'` 的字符串，编写一个算法来判断给定输入是否是**累加数**。如果是，返回 `true` ；否则，返回 `false` 。

**说明**：累加序列里的数，除数字 0 之外，**不会**以 0 开头，所以不会出现 `1, 2, 03` 或者 `1, 02, 3` 的情况。

**示例 1：**
```
输入："112358"
输出：true 
解释：累加序列为: 1, 1, 2, 3, 5, 8
     1 + 1 = 2, 1 + 2 = 3, 2 + 3 = 5, 3 + 5 = 8
```

**示例 2：**
```
输入："199100199"
输出：true 
解释：累加序列为: 1, 99, 100, 199
     1 + 99 = 100, 99 + 100 = 199
```

**示例 3：**
```
输入："0235813"
输出：false
```

**提示：**
- `1 <= num.length <= 35`
- `num` 仅由数字（`0` - `9`）组成

## 解题思路

这是一道典型的**回溯**问题。核心思路是：

1. **枚举前两个数**：
   - 前两个数确定后，后续的数都是固定的
   - 第一个数的长度：1 到 n/2
   - 第二个数的长度：1 到 (n - len1) / 2

2. **验证累加序列**：
   - 从第三个数开始，每个数必须等于前两个数之和
   - 如果能匹配到字符串末尾，返回 true

3. **剪枝条件**：
   - 数字不能以 0 开头（除了数字 0 本身）
   - 前两个数的长度和不能超过字符串长度的 2/3

## Java 代码实现

### 方法一：回溯（推荐）⭐

```java
class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();

        // 枚举第一个数的长度
        for (int i = 1; i < n; i++) {
            // 第一个数不能以 0 开头（除非是 0）
            if (num.charAt(0) == '0' && i > 1) break;

            // 枚举第二个数的长度
            for (int j = i + 1; j < n; j++) {
                // 第二个数不能以 0 开头（除非是 0）
                if (num.charAt(i) == '0' && j - i > 1) break;

                // 获取前两个数（用 long 处理大数防止溢出）
                long num1 = Long.parseLong(num.substring(0, i));
                long num2 = Long.parseLong(num.substring(i, j));

                // 验证从第三个数开始的累加序列
                if (isValid(num, j, num1, num2)) {
                    return true;
                }
            }
        }

        return false;
    }

    private boolean isValid(String num, int start, long num1, long num2) {
        // 从 start 位置开始验证累加序列
        // num1 和 num2 是前两个数
        if (start == num.length()) return true; // 已经到达字符串末尾，说明验证成功

        // 计算下一个数应该是多少
        long nextNum = num1 + num2;
        String nextStr = Long.toString(nextNum);

        // 检查字符串是否以 nextStr 开头
        if (!num.startsWith(nextStr, start)) return false;

        // 递归验证后续序列
        return isValid(num, start + nextStr.length(), num2, nextNum);
    }
}
```

### 方法二：迭代版本

```java
class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();

        // 枚举第一个数的长度
        for (int i = 1; i < n; i++) {
            if (num.charAt(0) == '0' && i > 1) break;

            // 枚举第二个数的长度
            for (int j = i + 1; j < n; j++) {
                if (num.charAt(i) == '0' && j - i > 1) break;

                long num1 = Long.parseLong(num.substring(0, i));
                long num2 = Long.parseLong(num.substring(i, j));

                // 迭代验证
                int start = j;
                while (start < n) {
                    long nextNum = num1 + num2;
                    String nextStr = Long.toString(nextNum);

                    // 检查是否匹配
                    if (!num.startsWith(nextStr, start)) break;

                    // 更新位置和数字
                    start += nextStr.length();
                    num1 = num2;
                    num2 = nextNum;
                }

                // 如果到达末尾，说明是累加数
                if (start == n) return true;
            }
        }

        return false;
    }
}
```

### 方法三：字符串操作优化（避免 long 溢出）

```java
class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();

        for (int i = 1; i < n; i++) {
            if (num.charAt(0) == '0' && i > 1) break;

            for (int j = i + 1; j < n; j++) {
                if (num.charAt(i) == '0' && j - i > 1) break;

                if (isValid(num.substring(0, i), num.substring(i, j), j, num)) {
                    return true;
                }
            }
        }

        return false;
    }

    private String addStrings(String s1, String s2) {
        // 字符串形式的加法，避免大数溢出
        StringBuilder result = new StringBuilder();
        int carry = 0;
        int i = s1.length() - 1, j = s2.length() - 1;

        while (i >= 0 || j >= 0 || carry > 0) {
            int digit1 = i >= 0 ? s1.charAt(i--) - '0' : 0;
            int digit2 = j >= 0 ? s2.charAt(j--) - '0' : 0;

            int total = digit1 + digit2 + carry;
            result.append((char) ('0' + total % 10));
            carry = total / 10;
        }

        return result.reverse().toString();
    }

    private boolean isValid(String s1, String s2, int start, String num) {
        // 验证从 start 开始的累加序列
        while (start < num.length()) {
            String nextStr = addStrings(s1, s2);

            if (!num.startsWith(nextStr, start)) return false;

            start += nextStr.length();
            s1 = s2;
            s2 = nextStr;
        }

        return true;
    }
}
```

### 方法四：带详细注释的版本

```java
class Solution {
    public boolean isAdditiveNumber(String num) {
        // 判断字符串是否是累加数
        int n = num.length();

        // 第一个数的长度最多到 n/2
        // 因为至少要有 3 个数，第三个数长度至少为 1
        for (int len1 = 1; len1 <= n / 2; len1++) {
            // 不能以 0 开头（除非就是 "0"）
            if (num.charAt(0) == '0' && len1 > 1) break;

            // 第二个数的长度
            for (int len2 = 1; len2 < n - len1; len2++) {
                // 第二个数也不能以 0 开头
                if (num.charAt(len1) == '0' && len2 > 1) break;

                // 提取前两个数（用 long 防止溢出）
                long first = Long.parseLong(num.substring(0, len1));
                long second = Long.parseLong(num.substring(len1, len1 + len2));

                // 验证累加序列
                if (check(num, len1 + len2, first, second)) {
                    return true;
                }
            }
        }

        return false;
    }

    private boolean check(String num, int start, long first, long second) {
        // 检查从 start 位置开始是否能形成累加序列
        if (start == num.length()) return true; // 已经检查到末尾，成功

        // 计算第三个数
        long third = first + second;
        String thirdStr = Long.toString(third);

        // 检查剩余字符串是否以 thirdStr 开头
        if (!num.startsWith(thirdStr, start)) return false;

        // 递归检查后续部分
        return check(num, start + thirdStr.length(), second, third);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)
  - 外层两个循环：O(n^2)
  - 验证累加序列：O(n)
- 空间复杂度：O(n)，递归栈的深度

## 关键点总结

1. **枚举前两个数**：前两个数确定后，后续序列唯一确定
2. **剪枝优化**：
   - 不能以 0 开头（除了数字 0）
   - 第一个数长度最多 n/2
3. **验证方法**：递归或迭代都可以
4. **大数处理**：Java 中用 `long` 类型处理，超长字符串可改用字符串加法
5. **边界条件**：至少需要 3 个数

## 易错点

1. **前导零处理**：`"0235813"` 中 `02` 是非法的
2. **单个 0 是合法的**：`"101"` 中第一个数可以是 `"0"`
3. **长度限制**：第一个数最长 n/2，第二个数最长 (n - len1)
4. **字符串匹配**：使用 `startsWith` 而不是直接截取比较
5. **递归终止条件**：`start == num.length()` 表示成功
