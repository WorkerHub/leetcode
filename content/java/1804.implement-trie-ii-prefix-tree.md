## 题目描述

实现字典树，支持：`insert(word)`、`countWordsEqualTo(word)`、`countWordsStartingWith(prefix)`、`erase(word)`（保证被删除词存在）。

## 解题思路

每个节点维护两个计数：`endCount`（以此节点结尾的完整单词数）和 `prefixCount`（经过此节点的单词数）。插入时沿路递增，删除时沿路递减。

## Java 代码实现

```java
class Trie {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int endCount = 0;    // 以此节点结尾的完整单词数
        int prefixCount = 0; // 经过此节点的单词数
    }

    private final TrieNode root = new TrieNode();

    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
            node.prefixCount++;
        }
        node.endCount++;
    }

    public int countWordsEqualTo(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return 0;
            node = node.children[idx];
        }
        return node.endCount;
    }

    public int countWordsStartingWith(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) return 0;
            node = node.children[idx];
        }
        return node.prefixCount;
    }

    public void erase(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            node = node.children[c - 'a'];
            node.prefixCount--;
        }
        node.endCount--;
    }
}
```

## 复杂度分析

- 所有操作：O(m)，m 为单词/前缀长度

## 关键点总结

1. 两个计数：`endCount`（完整单词）和 `prefixCount`（路径经过数）
2. erase 只递减计数，无需实际删除节点（题目保证被删词存在）
