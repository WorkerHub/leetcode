## 题目描述

m×n二进制矩阵上放stampHeight×stampWidth的印章（覆盖区域必须全0），判断能否使所有0格都被覆盖。

## 解题思路

二维前缀和判断区域是否全0（可放印章），二维差分数组标记覆盖，最后检查所有0格是否都被覆盖。

## Java 代码实现

```java
class Solution {
    public boolean possibleToStamp(int[][] grid, int stampHeight, int stampWidth) {
        int m = grid.length, n = grid[0].length;
        int sh = stampHeight, sw = stampWidth;
        
        // 二维前缀和
        int[][] ps = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ps[i+1][j+1] = grid[i][j] + ps[i][j+1] + ps[i+1][j] - ps[i][j];
        
        // 二维差分数组
        int[][] diff = new int[m + 2][n + 2];
        
        for (int i = 0; i + sh - 1 < m; i++) {
            for (int j = 0; j + sw - 1 < n; j++) {
                int r2 = i + sh - 1, c2 = j + sw - 1;
                // 区域和为0则可放印章
                int sum = ps[r2+1][c2+1] - ps[i][c2+1] - ps[r2+1][j] + ps[i][j];
                if (sum == 0) {
                    diff[i][j]++;
                    diff[i][c2+1]--;
                    diff[r2+1][j]--;
                    diff[r2+1][c2+1]++;
                }
            }
        }
        
        // 还原差分为覆盖次数
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i > 0) diff[i][j] += diff[i-1][j];
                if (j > 0) diff[i][j] += diff[i][j-1];
                if (i > 0 && j > 0) diff[i][j] -= diff[i-1][j-1];
                if (grid[i][j] == 0 && diff[i][j] == 0) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(M * N)

## 关键点总结

1. **二维前缀和**：O(1)查询矩形区域是否全0
2. **二维差分**：O(1)标记矩形覆盖
3. **最终检查**：所有原始0格必须覆盖次数>0
