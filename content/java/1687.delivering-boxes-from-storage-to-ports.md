## 题目描述

按顺序将货箱 `boxes[i] = [port, weight]` 运送到对应港口，卡车每次最多装 `maxBoxes` 个、总重 `maxWeight`，每切换港口花费 1 次行程，返回仓库花费 1 次。返回送完所有货箱的最少行程次数。

## 解题思路

**DP + 单调队列：** `dp[i]` 为送完前 `i` 个货箱的最少行程数。预处理相邻港口切换的前缀差分和，将转移方程变形为 `dp[i] = (dp[j] - diffSum[j]) + diffSum[i-1] + 2`，单调队列维护括号内的最小值。

## Java 代码实现

```java
class Solution {
    public int boxDelivering(int[][] boxes, int portsCount, int maxBoxes, int maxWeight) {
        int n = boxes.length;
        // diffSum[i] = boxes[0..i-1] 中相邻不同港口的次数
        int[] diffSum = new int[n + 1];
        for (int i = 1; i < n; i++) {
            diffSum[i] = diffSum[i - 1] + (boxes[i][0] != boxes[i - 1][0] ? 1 : 0);
        }
        diffSum[n] = diffSum[n - 1];

        // 重量前缀和
        long[] weightSum = new long[n + 1];
        for (int i = 0; i < n; i++) weightSum[i + 1] = weightSum[i] + boxes[i][1];

        int[] dp = new int[n + 1];
        // 单调队列存下标 j，维护 dp[j] - diffSum[j] 的最小值
        ArrayDeque<Integer> dq = new ArrayDeque<>();
        dq.addLast(0);

        for (int i = 1; i <= n; i++) {
            // 移除不满足约束的队首元素
            while (!dq.isEmpty() && (i - dq.peekFirst() > maxBoxes ||
                    weightSum[i] - weightSum[dq.peekFirst()] > maxWeight)) {
                dq.pollFirst();
            }
            int j = dq.peekFirst();
            dp[i] = dp[j] - diffSum[j] + diffSum[i - 1] + 2;

            // 维护单调递增队列（保留最小的 dp[j] - diffSum[j]）
            int val = dp[i] - diffSum[i];
            while (!dq.isEmpty() && dp[dq.peekLast()] - diffSum[dq.peekLast()] >= val) {
                dq.pollLast();
            }
            dq.addLast(i);
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 变形转移方程，将 j 相关部分提到括号内，用单调队列维护最小值
2. 同时用双端队列维护 maxBoxes 和 maxWeight 两个约束
3. 每次行程代价 = 港口切换次数 + 1（返回仓库），故最终 +2
