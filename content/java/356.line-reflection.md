## 题目描述

给定 n 个点 `points`，其中 `points[i] = [xi, yi]` 表示 X-Y 平面上的一个点。如果所有这些点关于某条与 Y 轴平行的线对称，则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：points = [[1,1],[-1,1]]
输出：true
解释：可以选择 x = 0 作为对称轴。
```

**示例 2：**
```
输入：points = [[1,1],[-1,-1]]
输出：false
解释：不存在对称轴。
```

**提示：**
- `n == points.length`
- `1 <= n <= 10^4`
- `-10^8 <= points[i][0], points[i][1] <= 10^8`

## 解题思路

**核心思想：**
1. 对称轴 x = mid，其中 mid = (min_x + max_x) / 2
2. 对于每个点 (x, y)，它的对称点是 (2*mid - x, y)
3. 检查所有点的对称点是否都存在

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isReflected(int[][] points) {
        // 去重并找到 x 坐标的范围
        Set<String> pointSet = new HashSet<>();
        int minX = Integer.MAX_VALUE, maxX = Integer.MIN_VALUE;

        for (int[] point : points) {
            // 将坐标转为字符串作为集合的键
            pointSet.add(point[0] + "," + point[1]);
            minX = Math.min(minX, point[0]);
            maxX = Math.max(maxX, point[0]);
        }

        // 对称轴为 x = (minX + maxX) / 2
        // 使用 sum = minX + maxX 避免浮点数
        int sum = minX + maxX;

        // 检查每个点的对称点是否存在
        for (int[] point : points) {
            // 对称点 x = sum - point[0], y = point[1]
            if (!pointSet.contains((sum - point[0]) + "," + point[1])) {
                return false;
            }
        }

        return true;
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

## 关键点总结

1. **对称轴计算**：(min_x + max_x) / 2
2. **对称点公式**：(2*mid - x, y) = (min_x + max_x - x, y)
3. **去重**：使用集合
4. **Y 坐标不变**：只需考虑 X 轴对称
5. **整数运算**：用 sum = min_x + max_x 避免除法产生浮点数

## 易错点

1. **忘记去重**：points 可能有重复
2. **浮点数精度**：用 2*mid（即 sum = minX + maxX）避免除法
3. **集合键的选择**：Java 中 `int[]` 作为键无法正确比较，需转成字符串或编码为 long
