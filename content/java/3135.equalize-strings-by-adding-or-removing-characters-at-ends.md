## 题目描述

通过在两端增删字符将initial变为target，求最少操作次数。

## 解题思路

操作只能在两端增删，等价于保留中间某段。找initial和target的最长公共子串(连续)，答案=len(initial)+len(target)-2*最长公共子串长度。用二分+滚动哈希高效求解。

## Java 代码实现

```java
class Solution {
    public int minOperations(String initial, String target) {
        int n = initial.length(), m = target.length();
        // 二分最长公共子串长度
        int lo = 0, hi = Math.min(n, m);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (hasCommonSubstr(initial, target, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return (n - lo) + (m - lo);
    }

    private boolean hasCommonSubstr(String s1, String s2, int len) {
        if (len == 0) return true;
        long MOD = (1L << 61) - 1;
        long BASE = 131;
        long power = modPow(BASE, len, MOD);

        // 计算s2所有长度为len的子串哈希
        Set<Long> hashes = new HashSet<>();
        long h = 0;
        for (int i = 0; i < len; i++) {
            h = modMul(h, BASE, MOD);
            h = (h + s2.charAt(i)) % MOD;
        }
        hashes.add(h);
        for (int i = len; i < s2.length(); i++) {
            h = modMul(h, BASE, MOD);
            h = (h - modMul(s2.charAt(i - len), power, MOD) % MOD + MOD + s2.charAt(i)) % MOD;
            hashes.add(h);
        }

        // 检查s1中是否存在匹配
        h = 0;
        for (int i = 0; i < len; i++) {
            h = modMul(h, BASE, MOD);
            h = (h + s1.charAt(i)) % MOD;
        }
        if (hashes.contains(h)) return true;
        for (int i = len; i < s1.length(); i++) {
            h = modMul(h, BASE, MOD);
            h = (h - modMul(s1.charAt(i - len), power, MOD) % MOD + MOD + s1.charAt(i)) % MOD;
            if (hashes.contains(h)) return true;
        }
        return false;
    }

    private long modMul(long a, long b, long mod) {
        return Math.floorMod(a * b, mod);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = modMul(result, base, mod);
            base = modMul(base, base, mod);
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+M) log(min(N,M)))
- **空间复杂度**：O(N+M)

## 关键点总结

1. **两端增删等价于保留中间段**：找最长公共子串
2. **答案=两串长度之和-2*最长公共子串**
3. **二分+滚动哈希**高效求最长公共子串
