## 题目描述

找出数组中只出现一次且相邻整数（x-1和x+1）都不在数组中的孤独数字。

## 解题思路

哈希表计数：对每个数x，若count[x]==1且count[x-1]==0且count[x+1]==0，则x是孤独数字。

## Java 代码实现

```java
class Solution {
    public List<Integer> findLonely(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : nums) {
            count.merge(x, 1, Integer::sum);
        }
        
        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            int x = entry.getKey();
            // x只出现一次，且x-1和x+1都不在数组中
            if (entry.getValue() == 1 
                && !count.containsKey(x - 1) 
                && !count.containsKey(x + 1)) {
                result.add(x);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **两个条件**：出现次数为1且相邻整数不存在
2. **HashMap计数**：containsKey判断相邻数是否存在
3. **遍历entrySet**：只需检查出现次数为1的数
