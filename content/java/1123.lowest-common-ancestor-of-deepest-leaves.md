## 题目描述

给定二叉树，返回最深叶子节点的最近公共祖先。

**示例：**
```
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：最深叶子是 7 和 4，LCA 是节点 2
```

## 解题思路

后序 DFS 返回 (LCA, depth)：左右深度相同则当前节点为 LCA，否则 LCA 在更深的那侧子树。

## Java 代码实现

```java
class Solution {
    public TreeNode lcaDeepestLeaves(TreeNode root) {
        return dfs(root)[0];
    }

    // 返回 [LCA节点, 深度]（用 Object[] 模拟元组）
    private Object[] dfs(TreeNode node) {
        if (node == null) return new Object[]{null, 0};

        Object[] left = dfs(node.left);
        Object[] right = dfs(node.right);

        int leftDepth = (int) left[1];
        int rightDepth = (int) right[1];

        if (leftDepth == rightDepth) {
            return new Object[]{node, leftDepth + 1};
        } else if (leftDepth > rightDepth) {
            return new Object[]{left[0], leftDepth + 1};
        } else {
            return new Object[]{right[0], rightDepth + 1};
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **后序遍历**：先知道子树深度才能判断
2. **深度相等**：左右深度相同时当前节点就是 LCA
3. **深度不等**：LCA 在更深的那侧
