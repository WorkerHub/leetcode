## 题目描述

在大小为 `n x n` 的网格 `grid` 上，每个单元格都有一盏灯，最初灯都处于关闭状态。

给你一个由灯的位置组成的二维数组 `lamps`，其中 `lamps[i] = [rowi, coli]` 表示打开位于 `grid[rowi][coli]` 的灯。即便同一盏灯可能在 `lamps` 中多次列出，不会影响这盏灯处于打开状态。

当一盏灯处于打开状态，它将会照亮自身所在单元格以及同一行、同一列和两条对角线上的所有其他单元格。

另给你一个二维数组 `queries`，其中 `queries[j] = [rowj, colj]`。对于第 `j` 个查询，如果单元格 `[rowj, colj]` 是被照亮的，则查询结果为 `1`，否则为 `0`。

在第 `j` 次查询之后（按照查询的顺序），关闭位于单元格 `grid[rowj][colj]` 上及相邻 8 个方向上（与单元格 `grid[rowi][coli]` 共享角或边）的任何灯。

返回一个整数数组 `ans`，`ans[j]` 应等于第 `j` 次查询 `queries[j]` 的结果，`1` 表示照亮，`0` 表示未照亮。

**示例 1：**
```
输入：n = 5, lamps = [[0,0],[4,4]], queries = [[1,1],[1,0]]
输出：[1,0]
解释：最初所有灯都是关闭的。在执行查询之前，打开位于 [0, 0] 和 [4, 4] 的灯。第 0 次查询检查 grid[1][1] 是否被照亮（蓝色方框）。该单元格被照亮，所以 ans[0] = 1 。然后，关闭红色方框中的所有灯。第 1 次查询检查 grid[1][0] 是否被照亮（蓝色方框）。该单元格没有被照亮，所以 ans[1] = 0 。因此，返回 [1,0] 。
```

**示例 2：**
```
输入：n = 5, lamps = [[0,0],[4,4]], queries = [[1,1],[1,1]]
输出：[1,1]
```

**示例 3：**
```
输入：n = 5, lamps = [[0,0],[0,4]], queries = [[0,4],[0,1],[1,4]]
输出：[1,1,0]
```

**提示：**
- `1 <= n <= 10^9`
- `0 <= lamps.length <= 20000`
- `0 <= queries.length <= 20000`
- `lamps[i].length == 2`
- `0 <= rowi, coli < n`
- `queries[j].length == 2`
- `0 <= rowj, colj < n`

## 解题思路

这是一道哈希表的经典题目，核心思想是：

1. **灯的照明规则**：一盏灯会照亮其所在的行、列、两条对角线
2. **关键观察**：我们不需要真正的二维数组，只需要记录每行、每列、每条对角线上有多少盏灯
3. **对角线的表示**：
   - 主对角线（左上到右下）：同一条对角线上的点满足 `row - col` 相同
   - 副对角线（右上到左下）：同一条对角线上的点满足 `row + col` 相同

**算法流程：**
1. 使用哈希表记录每行、每列、每条对角线上的灯数量
2. 使用集合记录所有亮着的灯的位置（去重）
3. 对于每次查询，检查该位置所在的行、列、对角线是否有灯
4. 查询后，关闭该位置及其 8 个相邻位置的灯

## Java 代码实现

### 方法一：哈希表（推荐）

```java
import java.util.*;

class Solution {
    public int[] gridIllumination(int n, int[][] lamps, int[][] queries) {
        // 用哈希表记录每行、每列、每条对角线上的灯数量
        Map<Integer, Integer> rowCount = new HashMap<>();   // 行
        Map<Integer, Integer> colCount = new HashMap<>();   // 列
        Map<Integer, Integer> diag1Count = new HashMap<>(); // 主对角线 (row - col)
        Map<Integer, Integer> diag2Count = new HashMap<>(); // 副对角线 (row + col)

        // 用集合记录所有亮着的灯（去重），用 long 编码坐标避免冲突
        Set<Long> lampSet = new HashSet<>();

        // 初始化所有灯
        for (int[] lamp : lamps) {
            int r = lamp[0], c = lamp[1];
            long key = (long) r * 1_000_000_007L + c;
            if (lampSet.contains(key)) continue; // 避免重复添加
            lampSet.add(key);
            rowCount.merge(r, 1, Integer::sum);
            colCount.merge(c, 1, Integer::sum);
            diag1Count.merge(r - c, 1, Integer::sum);
            diag2Count.merge(r + c, 1, Integer::sum);
        }

        int[] result = new int[queries.length];
        int[] dr = {-1, -1, -1, 0, 0, 0, 1, 1, 1};
        int[] dc = {-1, 0, 1, -1, 0, 1, -1, 0, 1};

        // 处理每个查询
        for (int i = 0; i < queries.length; i++) {
            int qr = queries[i][0], qc = queries[i][1];

            // 检查该位置是否被照亮
            if (rowCount.getOrDefault(qr, 0) > 0 ||
                colCount.getOrDefault(qc, 0) > 0 ||
                diag1Count.getOrDefault(qr - qc, 0) > 0 ||
                diag2Count.getOrDefault(qr + qc, 0) > 0) {
                result[i] = 1;
            }

            // 关闭该位置及其 8 个相邻位置的灯
            for (int d = 0; d < 9; d++) {
                int nr = qr + dr[d], nc = qc + dc[d];
                long key = (long) nr * 1_000_000_007L + nc;
                if (lampSet.contains(key)) {
                    lampSet.remove(key);
                    rowCount.merge(nr, -1, Integer::sum);
                    colCount.merge(nc, -1, Integer::sum);
                    diag1Count.merge(nr - nc, -1, Integer::sum);
                    diag2Count.merge(nr + nc, -1, Integer::sum);
                }
            }
        }

        return result;
    }
}
```

### 方法二：优化版（处理边界）

```java
import java.util.*;

class Solution {
    public int[] gridIllumination(int n, int[][] lamps, int[][] queries) {
        // 哈希表记录各方向上的灯数量
        Map<Integer, Integer> rows = new HashMap<>();
        Map<Integer, Integer> cols = new HashMap<>();
        Map<Integer, Integer> diag1 = new HashMap<>(); // row - col
        Map<Integer, Integer> diag2 = new HashMap<>(); // row + col

        // 记录所有亮着的灯
        Set<Long> lampsOn = new HashSet<>();

        // 打开所有灯
        for (int[] lamp : lamps) {
            int r = lamp[0], c = lamp[1];
            long pos = (long) r * 1_000_000_007L + c;
            if (!lampsOn.contains(pos)) {
                lampsOn.add(pos);
                rows.merge(r, 1, Integer::sum);
                cols.merge(c, 1, Integer::sum);
                diag1.merge(r - c, 1, Integer::sum);
                diag2.merge(r + c, 1, Integer::sum);
            }
        }

        int[] ans = new int[queries.length];
        int[][] directions = {{-1,-1},{-1,0},{-1,1},{0,-1},{0,0},{0,1},{1,-1},{1,0},{1,1}};

        for (int i = 0; i < queries.length; i++) {
            int r = queries[i][0], c = queries[i][1];

            // 检查是否被照亮
            boolean isLit = rows.getOrDefault(r, 0) > 0 ||
                            cols.getOrDefault(c, 0) > 0 ||
                            diag1.getOrDefault(r - c, 0) > 0 ||
                            diag2.getOrDefault(r + c, 0) > 0;
            ans[i] = isLit ? 1 : 0;

            // 关闭周围 9 个位置的灯
            for (int[] dir : directions) {
                int nr = r + dir[0], nc = c + dir[1];
                long pos = (long) nr * 1_000_000_007L + nc;
                if (lampsOn.contains(pos)) {
                    lampsOn.remove(pos);
                    rows.merge(nr, -1, Integer::sum);
                    cols.merge(nc, -1, Integer::sum);
                    diag1.merge(nr - nc, -1, Integer::sum);
                    diag2.merge(nr + nc, -1, Integer::sum);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

**时间复杂度：** O(L + Q)
- L 是 lamps 的长度，Q 是 queries 的长度
- 初始化灯需要 O(L) 时间
- 每次查询需要 O(1) 检查 + O(9) = O(1) 关灯时间
- 总时间为 O(L + Q)

**空间复杂度：** O(L)
- 需要存储所有灯的位置和各方向的计数
- 最多存储 L 盏灯

## 关键点总结

1. **空间优化**：n 可达 10^9，不能真正创建二维数组，必须用哈希表
2. **对角线表示**：
   - 主对角线：`row - col` 相同
   - 副对角线：`row + col` 相同
3. **去重处理**：同一盏灯可能在 lamps 中多次出现，用集合去重
4. **计数技巧**：用计数而不是列表，关灯时只需 O(1) 时间更新
5. **9 个方向**：查询后关闭的是 3x3 区域内的所有灯

## 易错点

1. **重复的灯**：lamps 中可能有重复位置，需要用集合去重
2. **边界检查**：虽然题目保证坐标合法，但关灯时不需要检查边界（因为用哈希表）
3. **计数为 0**：关灯后计数可能为 0，但不影响哈希表查询（默认返回 0）
4. **对角线公式**：不要搞混主对角线和副对角线的表示方式
5. **坐标编码**：Java 中需要将二维坐标编码为 long，避免哈希冲突
