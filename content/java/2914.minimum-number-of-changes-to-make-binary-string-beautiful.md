## 题目描述

给你长度为偶数的二进制字符串 s，返回使其变为"美丽字符串"（可分成若干偶数长度、全 0 或全 1 的子串）的最少修改次数。

## 解题思路

将字符串按位置 (0,1)、(2,3)、... 两两分组，每对若两字符不同则必须修改一个，代价为 1；相同则无需修改。累计不同对数即为答案。

## Java 代码实现

```java
class Solution {
    public int minChanges(String s) {
        int ans = 0;
        for (int i = 0; i < s.length(); i += 2) {
            if (s.charAt(i) != s.charAt(i + 1)) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每对 (2i, 2i+1) 必须相同，否则代价 1
2. 各对之间相互独立，贪心地对每对单独判断
3. 字符串长度保证为偶数，无需处理边界
