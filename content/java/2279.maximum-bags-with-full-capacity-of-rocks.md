## 题目描述

给定袋子容量和当前石块数，额外添加石块后最多能装满多少个袋子。

## 解题思路

贪心：计算每个袋子的缺口gap=capacity-rocks，排序后从最小缺口开始填，尽可能多装满。

## Java 代码实现

```java
class Solution {
    public int maximumBags(int[] capacity, int[] rocks, int additionalRocks) {
        int n = capacity.length;
        int[] gaps = new int[n];
        for (int i = 0; i < n; i++) gaps[i] = capacity[i] - rocks[i];
        Arrays.sort(gaps);

        int count = 0;
        for (int gap : gaps) {
            if (additionalRocks >= gap) {
                additionalRocks -= gap;
                count++;
            } else {
                break;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心**：优先填缺口最小的袋子
2. **gap=0已满**：直接计入答案不消耗石块
3. **不够填时break**：后续袋子缺口更大
