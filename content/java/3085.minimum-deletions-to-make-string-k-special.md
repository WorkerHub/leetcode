## 题目描述

给你字符串 s 和整数 k，若任意两字符频率之差不超过 k 则称 k-special，返回使字符串变为 k-special 的最少删除次数。

## 解题思路

排序字母频率后枚举最低频 `f = freq[i]`：删除频率小于 f 的所有字符，同时将频率超过 `f+k` 的削减到 `f+k`，用前缀和 O(1) 计算代价，取最小值。

## Java 代码实现

```java
class Solution {
    public int minimumDeletions(String s, int k) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        // 收集非零频率并排序
        int[] f = Arrays.stream(freq).filter(x -> x > 0).sorted().toArray();
        int m = f.length;

        // 前缀和
        int[] prefix = new int[m + 1];
        for (int i = 0; i < m; i++) prefix[i + 1] = prefix[i] + f[i];

        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < m; i++) {
            // 以 f[i] 为最低频
            int deleteLow = prefix[i]; // 删除前 i 个字母的所有字符

            // 削减频率 > f[i]+k 的字母
            int maxHigh = f[i] + k;
            // 用二分找第一个 > maxHigh 的位置
            int lo = i, hi = m;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (f[mid] <= maxHigh) lo = mid + 1;
                else hi = mid;
            }
            int deleteHigh = (prefix[m] - prefix[lo]) - (long)(m - lo) * maxHigh > 0
                ? (int)((prefix[m] - prefix[lo]) - (long)(m - lo) * maxHigh) : 0;

            ans = Math.min(ans, deleteLow + deleteHigh);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m)，m 为不同字母数（最多 26），实际 O(1)
- **空间复杂度**：O(m) = O(1)

## 关键点总结

1. 枚举最低频作为基准，频率过低的字母全删
2. 频率过高的字母削减到 `最低频 + k`
3. 前缀和 + 二分实现 O(1) 计算每种方案的代价
