## 题目描述

绳子上的气球有颜色和移除代价，要求没有相邻同色气球。返回最小移除代价。

**示例：**
```
输入：colors = "abaac", neededTime = [1,2,3,4,5]
输出：3
```

## 解题思路

贪心：每组连续同色气球保留代价最大的，删其余。每组费用 = 组总代价 - 组最大代价。

## Java 代码实现

```java
class Solution {
    public int minCost(String colors, int[] neededTime) {
        int ans = 0, n = colors.length();
        int i = 0;
        while (i < n) {
            int j = i;
            int groupSum = 0, groupMax = 0;
            // 找连续同色组
            while (j < n && colors.charAt(j) == colors.charAt(i)) {
                groupSum += neededTime[j];
                groupMax = Math.max(groupMax, neededTime[j]);
                j++;
            }
            // 保留最大的，删其余
            ans += groupSum - groupMax;
            i = j;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **分组处理**：连续同色为一组
2. **保留最贵**：每组只保留代价最大的气球
3. **费用公式**：组总代价 - 组最大代价
