## 题目描述

系统中存在 `n` 个进程，编号从 `0` 到 `n-1`。给你两个整数数组 `pid` 和 `ppid`，其中 `pid[i]` 是第 i 个进程的 ID，`ppid[i]` 是第 i 个进程的父进程 ID。

每个进程只有一个父进程，但可能有多个子进程。只有一个进程的 `ppid[i] = 0`，表示这个进程没有父进程（初始进程）。

当杀掉一个进程时，它的所有子进程和后代进程都会被杀掉。

给你一个整数 `kill` 表示要杀掉进程的 ID，返回被杀掉的进程的 ID 列表。可以按任意顺序返回答案。

**示例：**
```
输入：pid = [1,3,10,5], ppid = [3,0,5,3], kill = 5
输出：[5,10]
解释：杀掉进程 5 也会杀掉进程 10
```

**提示：**
- `n == pid.length == ppid.length`
- `1 <= n <= 5 * 10^4`
- `1 <= pid[i] <= 5 * 10^4`
- `0 <= ppid[i] <= 5 * 10^4`
- `ppid[0] = 0`
- `pid` 中的所有值互不相同
- 题目保证 `kill` 在 `pid` 中

## 解题思路

构建父子关系图，然后BFS/DFS遍历所有子孙进程。

## Java 代码实现

### 方法一：BFS（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<Integer> killProcess(List<Integer> pid, List<Integer> ppid, int kill) {
        // 构建父->子的映射
        Map<Integer, List<Integer>> children = new HashMap<>();
        for (int i = 0; i < pid.size(); i++) {
            int p = pid.get(i), pp = ppid.get(i);
            children.computeIfAbsent(pp, k -> new ArrayList<>()).add(p);
        }

        // BFS 遍历所有子进程
        List<Integer> result = new ArrayList<>();
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(kill);

        while (!queue.isEmpty()) {
            int current = queue.poll();
            result.add(current);
            List<Integer> childList = children.get(current);
            if (childList != null) queue.addAll(childList);
        }

        return result;
    }
}
```

### 方法二：DFS

```java
import java.util.*;

class Solution {
    public List<Integer> killProcess(List<Integer> pid, List<Integer> ppid, int kill) {
        // 构建父->子的映射
        Map<Integer, List<Integer>> children = new HashMap<>();
        for (int i = 0; i < pid.size(); i++) {
            int p = pid.get(i), pp = ppid.get(i);
            children.computeIfAbsent(pp, k -> new ArrayList<>()).add(p);
        }

        List<Integer> result = new ArrayList<>();
        dfs(children, kill, result);
        return result;
    }

    private void dfs(Map<Integer, List<Integer>> children, int node, List<Integer> result) {
        result.add(node);
        List<Integer> childList = children.get(node);
        if (childList != null) {
            for (int child : childList) {
                dfs(children, child, result);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **图构建**：建立父子关系（邻接表）
2. **BFS/DFS**：遍历所有后代
3. **哈希表**：快速查找子进程列表
