## 题目描述

给定二叉树的根节点 `root`，找出树中最大平衡子树的深度（高度）。平衡二叉树定义：每个节点的左右子树高度差不超过 1，且左右子树本身也都是平衡的。

## 解题思路

后序 DFS：对每个节点，若左右子树均平衡且高度差 <= 1，则当前子树平衡，更新全局最大深度，返回高度；否则返回 -1 向上传播不平衡信息。

## Java 代码实现

```java
class Solution {
    int ans = 0;

    public int maxBalancedDepth(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int left = dfs(node.left);
        int right = dfs(node.right);
        if (left == -1 || right == -1 || Math.abs(left - right) > 1) return -1;
        int height = Math.max(left, right) + 1;
        ans = Math.max(ans, height);
        return height;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(h)，h 为树高

## 关键点总结

1. 后序遍历：自底向上计算平衡信息
2. 返回 -1 表示不平衡，避免额外布尔变量
3. 根节点可能不是最大平衡子树的根
