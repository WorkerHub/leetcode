## 题目描述

给定两个整数数组 `nums1`、`nums2` 和整数 `k`，统计满足 `nums1[i] == nums2[j]` 且 `|i - j| <= k` 的元素对数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countCommonElements(int[] nums1, int[] nums2, int k) {
        // 构建 nums1 值 -> 有序下标列表
        Map<Integer, List<Integer>> map = new HashMap<>();
        for (int i = 0; i < nums1.length; i++) {
            map.computeIfAbsent(nums1[i], x -> new ArrayList<>()).add(i);
        }

        int ans = 0;
        for (int j = 0; j < nums2.length; j++) {
            List<Integer> indices = map.get(nums2[j]);
            if (indices == null) continue;
            // 二分统计 [j-k, j+k] 内的下标数
            int lo = lowerBound(indices, j - k);
            int hi = upperBound(indices, j + k);
            ans += hi - lo;
        }
        return ans;
    }

    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    private int upperBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (list.get(mid) <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，n 为 nums1 长度，m 为 nums2 长度
- 空间复杂度：O(n)

## 关键点总结

1. 哈希表预处理 nums1 值到有序下标列表
2. 对每个 nums2[j] 二分查找合法下标范围 [j-k, j+k]
3. 下标约束是双向的：j-k <= i <= j+k
