## 题目描述

给你两个长度相同的整数数组 `target` 和 `arr`。

每一步中，你可以选择 `arr` 的任意**非空子数组**并将它逆序。你可以执行此过程任意次。

如果你能让 `arr` 变得与 `target` 相同，返回 `True`；否则，返回 `False`。

**示例 1：**
```
输入：target = [1,2,3,4], arr = [2,4,1,3]
输出：true
解释：按照如下步骤可以将 arr 转变为 target：
     1. 逆序子数组 [2,4,1] ，arr 变成 [1,4,2,3]
     2. 逆序子数组 [4,2] ，arr 变成 [1,2,4,3]
     3. 逆序子数组 [4,3] ，arr 变成 [1,2,3,4]
```

**示例 2：**
```
输入：target = [7], arr = [7]
输出：true
解释：arr 等于 target 无需任何操作。
```

**示例 3：**
```
输入：target = [3,7,9], arr = [3,7,11]
输出：false
解释：arr 不包含值为 9 的元素，所以无论如何操作都不能变成 target。
```

**提示：**
- `target.length == arr.length`
- `1 <= target.length <= 1000`
- `1 <= target[i] <= 1000`
- `1 <= arr[i] <= 1000`

## 解题思路

**关键洞察：** 通过若干次子数组翻转，可以实现数组的**任意排列**（类似冒泡排序的原理）。

因此，`arr` 能变成 `target` 的充要条件是：**两个数组包含完全相同的元素（包括重复元素的个数）**。

验证方法：
1. **排序比较**：将两个数组排序后逐元素比较
2. **哈希表计数**：统计每个元素的出现次数，比较两个频率表

## Java 代码实现

### 方法一：排序比较（推荐，最简洁）

```java
import java.util.Arrays;

class Solution {
    public boolean canBeEqual(int[] target, int[] arr) {
        // 排序后比较，若相等则包含相同元素
        Arrays.sort(target);
        Arrays.sort(arr);
        return Arrays.equals(target, arr);
    }
}
```

### 方法二：哈希表计数

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean canBeEqual(int[] target, int[] arr) {
        // 统计 target 中每个元素的出现次数
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : target) {
            count.merge(num, 1, Integer::sum);
        }
        // 对 arr 中的元素做减法
        for (int num : arr) {
            count.merge(num, -1, Integer::sum);
        }
        // 如果所有元素的计数都归零，则两数组元素相同
        for (int v : count.values()) {
            if (v != 0) return false;
        }
        return true;
    }
}
```

### 方法三：数组计数（利用值范围 1-1000）

```java
class Solution {
    public boolean canBeEqual(int[] target, int[] arr) {
        // 元素值在 1~1000 之间，使用数组统计
        int[] count = new int[1001];
        for (int num : target) count[num]++;
        for (int num : arr) count[num]--;
        for (int v : count) {
            if (v != 0) return false;
        }
        return true;
    }
}
```

## 复杂度分析

**方法一（排序）：**
- 时间复杂度：O(n log n)，排序的时间
- 空间复杂度：O(1)（就地排序）

**方法二（HashMap）：**
- 时间复杂度：O(n)，遍历两个数组
- 空间复杂度：O(n)，哈希表存储频率

**方法三（数组计数）：**
- 时间复杂度：O(n + max_val)
- 空间复杂度：O(max_val)，利用值域范围固定

## 关键点总结

1. 子数组翻转可以实现任意排列（这是核心数学洞察）
2. 因此问题转化为：两数组是否包含完全相同的元素（频率也相同）
3. Java 的 `Arrays.sort()` + `Arrays.equals()` 可以简洁完成排序比较

## 易错点

- 不要忘记考虑重复元素：`[1,1,2]` 和 `[1,2,2]` 排序后不同，正确返回 false
- 不要仅比较元素种类（集合相等），还要比较每个元素的出现次数
- `Arrays.equals(int[], int[])` 是逐元素比较，不同于对象引用比较
