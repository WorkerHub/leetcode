## 题目描述

每买两块糖可免费获得一块价格不超过较便宜那块的糖。求买所有糖的最低花费。

## 解题思路

贪心：从贵到便宜排序，每三块一组中第三块免费（下标%3==2的跳过）。

## Java 代码实现

```java
class Solution {
    public int minimumCost(int[] cost) {
        Arrays.sort(cost);
        int total = 0;
        int n = cost.length;
        // 从贵到便宜，每三块第三块免费
        for (int i = n - 1, count = 0; i >= 0; i--, count++) {
            if (count % 3 != 2) {
                total += cost[i];
            }
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **降序排列**：让最贵的糖免费最大化折扣
2. **每三块第三块免费**：count%3==2时跳过
3. **贪心正确性**：买最贵的两块，免费第三贵的
