## 题目描述

给你字符串数组 words 和二进制数组 groups，选出最长子序列使相邻元素的 groups 值不同（交替 0 和 1），返回该子序列对应的 words。

## 解题思路

贪心：从左到右扫描，遇到与上一个选中元素 groups 值不同的元素就选入，保证最长。

## Java 代码实现

```java
class Solution {
    public List<String> getLongestSubsequence(String[] words, int[] groups) {
        List<String> ans = new ArrayList<>();
        ans.add(words[0]);
        int lastGroup = groups[0];

        for (int i = 1; i < words.length; i++) {
            // 遇到与上一个不同的 group 就选入
            if (groups[i] != lastGroup) {
                ans.add(words[i]);
                lastGroup = groups[i];
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：遇到不同 group 就选，保证最长且不会让后续变差
2. groups 只有 0 和 1，最长交替子序列等于去掉连续重复后的结果
3. 第一个元素一定选入
