## 题目描述

n个人，初始0和firstPerson知道秘密。按时间顺序处理会议，同时刻会议同时传播。返回最终所有知道秘密的人。

## 解题思路

并查集按时间分组：同一时刻的会议全部合并后，与0不连通的节点重置。或BFS按时间层从已知者传播。

## Java 代码实现

```java
class Solution {
    private int[] parent;
    
    public List<Integer> findAllPeople(int n, int[][] meetings, int firstPerson) {
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        union(0, firstPerson);
        
        // 按时间分组
        Arrays.sort(meetings, (a, b) -> a[2] - b[2]);
        int i = 0;
        while (i < meetings.length) {
            int t = meetings[i][2];
            List<Integer> people = new ArrayList<>();
            int j = i;
            // 处理同一时刻的所有会议
            while (j < meetings.length && meetings[j][2] == t) {
                union(meetings[j][0], meetings[j][1]);
                people.add(meetings[j][0]);
                people.add(meetings[j][1]);
                j++;
            }
            // 重置与0不连通的人
            for (int p : people) {
                if (find(p) != find(0)) {
                    parent[p] = p;
                }
            }
            i = j;
        }
        
        List<Integer> result = new ArrayList<>();
        for (int k = 0; k < n; k++) {
            if (find(k) == find(0)) result.add(k);
        }
        return result;
    }
    
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    
    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M log M + M × α(N))
- **空间复杂度**：O(N + M)

## 关键点总结

1. **按时间分组**：同一时刻会议必须同时处理
2. **合并后重置**：与0不连通的节点重置parent
3. **链式传播**：A-B, B-C同时刻，A知道则C也知道
