## 题目描述

给定整数 n，判断是否为阿姆斯特朗数（水仙花数）：一个 k 位数的每位数字的 k 次幂之和等于它本身。

**示例：**
```
输入：n = 153
输出：true（1³ + 5³ + 3³ = 153）
```

## 解题思路

先求位数 k，再逐位取出数字计算 k 次幂之和，比较是否等于原数。

## Java 代码实现

```java
class Solution {
    public boolean isArmstrong(int n) {
        // 计算位数
        int k = String.valueOf(n).length();

        // 逐位计算 k 次幂之和
        int sum = 0;
        int temp = n;
        while (temp > 0) {
            int digit = temp % 10;
            sum += Math.pow(digit, k);
            temp /= 10;
        }

        return sum == n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，位数为 log₁₀(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **位数计算**：`String.valueOf(n).length()` 或循环除 10
2. **取模取位**：`n % 10` 获取个位，`n /= 10` 去掉个位
3. **保留原值**：用 temp 遍历，n 保持不变用于最终比较
4. **单位数都是阿姆斯特朗数**：1¹=1, 2¹=2, ...
