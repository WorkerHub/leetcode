## 题目描述

给你一个偶数长度的整数数组 `nums`，将所有元素分成 n/2 对，每对代价为两元素差的绝对值，返回所有配对方案中总代价的最小值。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minimumCost(int[] nums) {
        // 排序后相邻配对是最优策略
        Arrays.sort(nums);
        long total = 0;
        // 步长为 2，对每对相邻元素（排序后差为非负）求和
        for (int i = 0; i < nums.length; i += 2) {
            total += nums[i + 1] - nums[i];
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)，原地排序

## 关键点总结

1. 排序后相邻配对总是最优解（数学可证）。
2. 排序后 `nums[i+1] - nums[i]` 总为非负，无需取绝对值。
3. 遍历步长为 2，取偶数下标和奇数下标的差。
