## 题目描述

飞镖靶是一个圆形，圆上有若干飞镖。给你一个大小为 `n` 的整数坐标数组 `darts`，其中 `darts[i] = [xi, yi]` 表示飞镖 i 在二维坐标中的位置，以及一个整数 `r`，表示圆形飞镖靶的半径。

返回能够被半径为 `r` 的圆覆盖的最多飞镖数量。

**示例 1：**
```
输入：darts = [[-2,0],[2,0],[0,2],[0,-2]], r = 2
输出：4
解释：圆心 (0,0) 的半径为 2 的圆可以覆盖所有 4 枚飞镖。
```

**示例 2：**
```
输入：darts = [[-3,0],[3,0],[2,6],[5,4],[0,2],[4,0]], r = 2
输出：4
```

**提示：**
- `1 <= darts.length <= 100`
- `-10^4 <= darts[i][0], darts[i][1] <= 10^4`
- `1 <= r <= 5000`
- 所有 `darts[i]` 各不相同

## 解题思路

**关键观察：** 最优圆的圆心位置一定可以通过平移，使得圆边上至少有两个飞镖（或只有一个飞镖时圆心就在该飞镖处）。

这给了我们一个枚举策略：**枚举圆边上的每一对飞镖，计算过这两点且半径为 r 的所有可能圆心，然后统计每个圆心覆盖的飞镖数。**

**几何推导：**

过两点 A、B 且半径为 r 的圆，圆心在 AB 的垂直平分线上。设 AB 的中点为 M，圆心到 M 的距离为 h：

```
h = sqrt(r^2 - (|AB|/2)^2)
```

圆心沿垂直平分线方向偏移 h，有两个圆心候选位置。

**算法流程：**

1. 枚举每对飞镖 (i, j)
2. 若距离 > 2r，则两点不能在同一圆内，跳过
3. 计算两个候选圆心
4. 对每个圆心，统计圆内的飞镖数
5. 取最大值

## Java 代码实现

### 方法一：O(n^3) 枚举圆心（推荐）

```java
class Solution {
    public int numPoints(int[][] darts, int r) {
        int n = darts.length;
        // 至少覆盖 1 个飞镖（圆心就在飞镖上）
        int result = 1;

        // 枚举每对飞镖作为圆边上的两点
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                double xi = darts[i][0], yi = darts[i][1];
                double xj = darts[j][0], yj = darts[j][1];

                // 计算两点之间的距离
                double d = Math.sqrt((xi - xj) * (xi - xj) + (yi - yj) * (yi - yj));

                // 如果两点距离超过直径，不可能在同一圆内
                if (d > 2.0 * r + 1e-6) continue;

                // 中点坐标
                double mx = (xi + xj) / 2;
                double my = (yi + yj) / 2;

                // 圆心到中点的距离 h
                double h = Math.sqrt(r * r - (d / 2) * (d / 2));

                // 垂直平分线方向的单位向量（旋转90度）
                double ux = -(yj - yi) / d;
                double uy = (xj - xi) / d;

                // 两个候选圆心
                for (int sign : new int[]{1, -1}) {
                    double cx = mx + sign * h * ux;
                    double cy = my + sign * h * uy;
                    result = Math.max(result, countDarts(darts, cx, cy, r));
                }
            }
        }

        return result;
    }

    // 统计圆心 (cx, cy) 的半径 r 圆覆盖的飞镖数
    private int countDarts(int[][] darts, double cx, double cy, int r) {
        int cnt = 0;
        for (int[] dart : darts) {
            double dist = Math.sqrt((dart[0] - cx) * (dart[0] - cx)
                    + (dart[1] - cy) * (dart[1] - cy));
            if (dist <= r + 1e-6) {  // 加小量误差处理浮点精度
                cnt++;
            }
        }
        return cnt;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^3)，枚举点对 O(n^2)，每次统计覆盖数 O(n)
- 空间复杂度：O(1)

进一步优化可以达到 O(n^2 log n)（角度扫描线），但对于 n ≤ 100 的数据量，O(n^3) 已经足够。

## 关键点总结

1. 最优圆一定可以在边上放置至少一个点（或两个点），这是枚举圆心的理论依据
2. 过两点确定圆心：利用中点和垂直平分线方向
3. 浮点比较需要加 epsilon（1e-6）处理精度误差
4. 两点距离超过直径 2r 时，可以直接跳过

## 易错点

- 浮点精度问题：判断点是否在圆内时，用 `dist <= r + 1e-6` 而不是严格的 `dist <= r`
- 枚举圆心时有两个候选（垂直平分线两侧），不要遗漏
- `Math.sqrt` 参数为负数时会返回 NaN，需要用 `Math.max(0, ...)` 处理边界情况
