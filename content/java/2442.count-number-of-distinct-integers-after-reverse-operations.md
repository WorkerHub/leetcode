## 题目描述

给你正整数数组 `nums`，将每个整数反转后追加到数组末尾，返回最终数组中不同整数的数目。

## 解题思路

将原数组中每个整数和其反转后的数字都加入哈希集合，返回集合大小。反转时用数学方法去掉前导零。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countDistinctIntegers(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            seen.add(x);
            seen.add(reverse(x)); // 加入反转后的数字
        }
        return seen.size();
    }

    // 数学方法反转整数（自动去掉前导零）
    private int reverse(int x) {
        int rev = 0;
        while (x > 0) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return rev;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(maxVal))
- **空间复杂度**：O(n)

## 关键点总结

1. 将原数组和反转后的数字都放入集合，利用集合自动去重
2. 数学反转整数自动去掉前导零（如 130 反转为 31）
3. 返回集合大小即为不同整数数目
