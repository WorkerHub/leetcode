## 题目描述

将有效括号字符串分成两个子序列 A 和 B，使 max(depth(A), depth(B)) 最小。返回分配数组（0 表示 A，1 表示 B）。

**示例：**
```
输入：seq = "(()())"
输出：[0,1,1,1,1,0]
```

## 解题思路

按深度奇偶交替分配：奇数层分配给 B（1），偶数层分配给 A（0），使嵌套深度均匀分摊。

## Java 代码实现

```java
class Solution {
    public int[] maxDepthAfterSplit(String seq) {
        int n = seq.length();
        int[] answer = new int[n];
        int depth = 0;

        for (int i = 0; i < n; i++) {
            if (seq.charAt(i) == '(') {
                depth++;
                answer[i] = depth % 2; // 奇数层 -> 1, 偶数层 -> 0
            } else {
                answer[i] = depth % 2;
                depth--;
            }
        }

        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计结果数组）

## 关键点总结

1. **按深度分配**：奇偶交替使两个子序列深度约为原深度的一半
2. **左括号先加后判**：先 depth++，再取 depth % 2
3. **右括号先判后减**：先取 depth % 2，再 depth--
