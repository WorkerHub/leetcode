## 题目描述

根据描述数组descriptions[i]=[parent,child,isLeft]构造二叉树并返回根节点。

## 解题思路

哈希表存储节点，遍历描述建立父子关系。根节点是从未作为孩子出现的节点。

## Java 代码实现

```java
class Solution {
    public TreeNode createBinaryTree(int[][] descriptions) {
        Map<Integer, TreeNode> nodes = new HashMap<>();
        Set<Integer> children = new HashSet<>();
        
        for (int[] d : descriptions) {
            int parent = d[0], child = d[1], isLeft = d[2];
            nodes.putIfAbsent(parent, new TreeNode(parent));
            nodes.putIfAbsent(child, new TreeNode(child));
            if (isLeft == 1) {
                nodes.get(parent).left = nodes.get(child);
            } else {
                nodes.get(parent).right = nodes.get(child);
            }
            children.add(child);
        }
        
        // 找根节点：出现为父但从未作为孩子
        for (int[] d : descriptions) {
            if (!children.contains(d[0])) {
                return nodes.get(d[0]);
            }
        }
        return null;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **哈希表按值索引节点**：避免重复创建
2. **根节点判断**：从未出现在child集合中的父节点
3. **一遍遍历建树**：同时建立父子关系和记录孩子集合
