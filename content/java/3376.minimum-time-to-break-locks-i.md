## 题目描述

给你整数数组 `strength` 和整数 `K`，初始能量 `X = 1`，破开第 `i` 把锁需要 X 是 `strength[i]` 的倍数（可等待），破开后 X 增加 K。返回任意顺序破开所有锁的最短总等待时间。

## 解题思路

n <= 8，使用状态压缩 DP。`dp[mask]` 表示破开 mask 中所有锁的最短等待时间。已破开 `k` 把锁时当前能量 `X = 1 + k * K`，破开第 `i` 把锁的等待时间 = `ceil(X / strength[i]) * strength[i] - X`。

## Java 代码实现

```java
class Solution {
    public int findMinimumTime(int[] strength, int K) {
        int n = strength.length;
        int[] dp = new int[1 << n];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            // 已破开的锁数量 = mask 的 popcount
            int opened = Integer.bitCount(mask);
            int X = 1 + opened * K; // 当前能量

            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) continue; // 已破开
                int s = strength[i];
                // 等待时间：使 X 变成 s 的最小倍数
                int wait = ((X + s - 1) / s) * s - X;
                int newMask = mask | (1 << i);
                dp[newMask] = Math.min(dp[newMask], dp[mask] + wait);
            }
        }
        return dp[(1 << n) - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)，状压 DP
- 空间复杂度：O(2^n)

## 关键点总结

1. 已破开 k 把锁后当前能量 `X = 1 + k * K`。
2. 等待时间 = `((X + s - 1) / s) * s - X`（整数除法上取整乘 s 再减 X）。
3. 状压 DP 枚举所有破锁顺序，找最小总等待时间。
