## 题目描述

给你整数数组 `nums` 和整数 `k`，返回每个元素出现频率至多为 `k` 的最长子数组长度。

## 解题思路

滑动窗口：右端扩展时更新频率，若 `nums[right]` 超频则收缩左端直到频率恢复 <= k，每次更新最大窗口长度。

## Java 代码实现

```java
class Solution {
    public int maxSubarrayLength(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        int left = 0, ans = 0;

        for (int right = 0; right < nums.length; right++) {
            freq.merge(nums[right], 1, Integer::sum); // 右端扩展
            while (freq.get(nums[right]) > k) {
                // 收缩左端直到 nums[right] 频率恢复
                freq.merge(nums[left], -1, Integer::sum);
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每次只有 nums[right] 可能超频，只需检查它
2. 收缩左端时减少 nums[left] 的频率，直到窗口合法
3. 每次右端扩展后更新答案
