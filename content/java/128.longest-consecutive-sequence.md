## 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**
```
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**
```
输入: nums = [0,3,7,2,5,8,4,6,0,1]
输出: 9
```

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这道题的关键是要在 **O(n)** 时间内完成，所以不能排序（排序至少 O(n log n)）。

### 核心思想：哈希表 + 智能跳过

1. **使用哈希集合存储所有数字**：O(1) 时间判断某个数是否存在
2. **只从序列起点开始计数**：如果 `num-1` 存在，说明不是起点，跳过
3. **从起点向后延伸**：计算以当前数字为起点的连续序列长度
4. **记录最大长度**

### 为什么时间复杂度是 O(n)？

虽然有嵌套循环，但每个数字**最多只会被访问两次**：
- 外层循环：遍历每个数字 O(n)
- 内层循环：只有序列起点才会进入，总共也是 O(n)
- 总时间复杂度：O(n) + O(n) = O(n)

## Java 代码实现

### 方法一：哈希表（推荐）

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 转换为集合，O(1) 查找
        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) {
            numSet.add(num);
        }

        int maxLength = 0;

        for (int num : numSet) {
            // 只从序列起点开始计数
            // 如果 num-1 存在，说明不是起点，跳过
            if (!numSet.contains(num - 1)) {
                int currentNum = num;
                int currentLength = 1;

                // 向后延伸，计算序列长度
                while (numSet.contains(currentNum + 1)) {
                    currentNum++;
                    currentLength++;
                }

                maxLength = Math.max(maxLength, currentLength);
            }
        }

        return maxLength;
    }
}
```

### 方法二：哈希表优化版（记忆化）

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) {
            numSet.add(num);
        }

        int maxLength = 0;
        Set<Integer> visited = new HashSet<>();  // 记录已经处理过的数字

        for (int num : numSet) {
            if (visited.contains(num)) continue;

            // 向左查找边界
            int left = num - 1;
            while (numSet.contains(left)) {
                visited.add(left);
                left--;
            }

            // 向右查找边界
            int right = num + 1;
            while (numSet.contains(right)) {
                visited.add(right);
                right++;
            }

            // 计算长度
            int currentLength = right - left - 1;
            maxLength = Math.max(maxLength, currentLength);
            visited.add(num);
        }

        return maxLength;
    }
}
```

### 方法三：并查集（进阶）

```java
class Solution {
    private int[] parent;
    private int[] size;

    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 使用哈希表映射数字到索引
        Map<Integer, Integer> indexMap = new HashMap<>();
        int n = nums.length;
        parent = new int[n];
        size = new int[n];

        for (int i = 0; i < n; i++) {
            // 跳过重复数字
            if (indexMap.containsKey(nums[i])) continue;
            indexMap.put(nums[i], i);
            parent[i] = i;
            size[i] = 1;
        }

        // 将连续的数字合并
        for (int num : indexMap.keySet()) {
            if (indexMap.containsKey(num + 1)) {
                union(indexMap.get(num), indexMap.get(num + 1));
            }
        }

        // 找最大连通分量大小
        int maxSize = 0;
        for (int i = 0; i < n; i++) {
            if (parent[i] == i) {  // 根节点
                maxSize = Math.max(maxSize, size[i]);
            }
        }

        return maxSize;
    }

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }

    private void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);

        if (rootX != rootY) {
            // 按大小合并
            if (size[rootX] < size[rootY]) {
                int tmp = rootX;
                rootX = rootY;
                rootY = tmp;
            }
            parent[rootY] = rootX;
            size[rootX] += size[rootY];
        }
    }
}
```

### 方法四：排序法（不满足 O(n) 要求）

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 排序 O(n log n)
        Arrays.sort(nums);

        int maxLength = 1;
        int currentLength = 1;

        for (int i = 1; i < nums.length; i++) {
            // 跳过重复元素
            if (nums[i] == nums[i - 1]) continue;

            // 连续
            if (nums[i] == nums[i - 1] + 1) {
                currentLength++;
            } else {
                // 不连续，重新开始
                maxLength = Math.max(maxLength, currentLength);
                currentLength = 1;
            }
        }

        return Math.max(maxLength, currentLength);
    }
}
```

## 复杂度分析

### 方法一：哈希表（推荐）
- **时间复杂度**：O(n)
  - 构建集合：O(n)
  - 遍历集合：每个元素最多访问两次，O(n)
- **空间复杂度**：O(n)，哈希集合

### 方法三：并查集
- **时间复杂度**：O(n × α(n)) ≈ O(n)，α 是反阿克曼函数，几乎为常数
- **空间复杂度**：O(n)

### 方法四：排序法
- **时间复杂度**：O(n log n)，不满足题目要求
- **空间复杂度**：O(1) 或 O(n)，取决于排序算法

## 关键点总结

1. **哈希表是关键**：O(1) 查找使得整体复杂度为 O(n)
2. **只从起点开始**：通过 `!numSet.contains(num - 1)` 判断起点，避免重复计算
3. **时间复杂度分析**：虽然有嵌套循环，但每个数最多访问两次
4. **集合去重**：转换为集合自动去重
5. **边界处理**：空数组返回 0

## 易错点

1. **忘记检查空数组**
   ```java
   if (nums == null || nums.length == 0) return 0;
   ```

2. **时间复杂度理解错误**
   ```java
   // 看起来是 O(n^2)，实际是 O(n)
   // 因为内层循环总共只执行 n 次
   for (int num : numSet) {
       if (!numSet.contains(num - 1)) {
           while (numSet.contains(currentNum + 1)) {
               // 每个数最多访问一次
           }
       }
   }
   ```

3. **没有跳过非起点**
   ```java
   // 错误：所有数字都计算（会导致 O(n^2)）
   for (int num : numSet) {
       int currentLength = 1;
       while (numSet.contains(currentNum + 1)) { ... }
   }

   // 正确：只从起点开始
   if (!numSet.contains(num - 1)) { ... }
   ```

4. **使用数组而不是集合**
   ```java
   // 错误：数组查找 O(n)
   // Arrays.asList(nums).contains(num)  // O(n)

   // 正确：集合查找 O(1)
   numSet.contains(num)  // O(1)
   ```
