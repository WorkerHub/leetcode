## 题目描述

给你严格递增的正整数数组 `arr`，返回最长的类斐波那契子序列（满足 `x[i+2] = x[i] + x[i+1]` 且长度 >= 3）的长度，不存在返回 0。

## 解题思路

DP + 哈希表：`dp[i][j]` 表示以 `arr[i]`, `arr[j]` 结尾的最长类斐波那契子序列长度。对每对 `(i, j)`，查哈希表是否存在 `arr[j] - arr[i]`（且值 < `arr[i]`），若存在 `arr[k]` 则 `dp[i][j] = dp[k][i] + 1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int lenLongestFibSubseq(int[] arr) {
        int n = arr.length;
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < n; i++) index.put(arr[i], i);

        int[][] dp = new int[n][n]; // dp[i][j] = 以 arr[i],arr[j] 结尾的最长长度
        int ans = 0;
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < j; i++) {
                int prev = arr[j] - arr[i];
                if (prev < arr[i] && index.containsKey(prev)) {
                    int k = index.get(prev);
                    dp[i][j] = (dp[k][i] > 0 ? dp[k][i] : 2) + 1;
                    ans = Math.max(ans, dp[i][j]);
                }
            }
        }
        return ans >= 3 ? ans : 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，双重循环，每次哈希表 O(1) 查询
- 空间复杂度：O(n^2)，DP 数组

## 关键点总结

1. 哈希表索引 O(1) 查找前驱元素 `arr[j] - arr[i]`
2. `prev < arr[i]` 确保序列严格递增
3. DP 初始长度为 2，满足 3 才记入答案
