## 题目描述

给定 DataFrame products，将 quantity 列中所有缺失值（NaN）填充为 0。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df['quantity'].fillna(0)` 填充缺失值。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df['col'].fillna(0) 等价于将 null 替换为 0

import java.util.*;

class Solution {
    // Java 中将 null 值替换为 0（使用 Integer 可存储 null）
    public List<Integer> fillMissingValues(List<Integer> quantities) {
        List<Integer> result = new ArrayList<>();
        for (Integer q : quantities) {
            result.add(q == null ? 0 : q);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. `df['col'].fillna(value)` 填充指定列的缺失值
2. `df.fillna({'col': val})` 字典方式批量填充不同列
3. Java 中 Integer 包装类可存储 null，对应 Pandas 的 NaN
