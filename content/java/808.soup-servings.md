## 题目描述

有 `A` 和 `B` 两种类型的汤。一开始每种类型的汤有 `n` 毫升。有四种分配操作：

1. 提供 100ml 的 **汤A** 和 0ml 的 **汤B**
2. 提供 75ml 的 **汤A** 和 25ml 的 **汤B**
3. 提供 50ml 的 **汤A** 和 50ml 的 **汤B**
4. 提供 25ml 的 **汤A** 和 75ml 的 **汤B**

每个回合，我们将从四种概率同为 0.25 的操作中进行分配选择。

返回 **汤A** 先分配完的概率 + **汤A和汤B** 同时分配完的概率 / 2。

**示例 1:**
```
输入: n = 50
输出: 0.62500
```

**示例 2:**
```
输入: n = 100
输出: 0.71875
```

**提示:**
- `0 <= n <= 10^9`

## 解题思路

这是一道概率 DP 问题，需要注意数学优化。

**核心思想：**
1. 用 `dp[a][b]` 表示当汤 A 剩余 a 份、汤 B 剩余 b 份时，满足条件的概率
2. 四种操作的概率均为 0.25
3. 当 n 很大时（如 n > 5000），由于 A 消耗总是 >= B，概率会非常接近 1

**状态转移：**
```
dp[a][b] = 0.25 * (dp[a-4][b] + dp[a-3][b-1] + dp[a-2][b-2] + dp[a-1][b-3])
```

**边界条件：**
- `dp[0][0] = 0.5`（同时为空，贡献 0.5）
- `dp[0][b] = 1`（A 先空，贡献 1）
- `dp[a][0] = 0`（B 先空，贡献 0）

**优化：**
- 将 n 转换为 25ml 的倍数（除以 25 向上取整）
- 当 n > 5000 时，直接返回 1

## Java 代码实现

### 方法一：自底向上 DP（推荐）

```java
class Solution {
    public double soupServings(int n) {
        // 当 n 很大时，概率接近 1
        if (n > 5000) return 1.0;

        // 转换为 25ml 的倍数（向上取整）
        n = (n + 24) / 25;

        // dp[a][b] 表示汤A剩余a份、汤B剩余b份时的概率
        double[][] dp = new double[n + 1][n + 1];

        // 边界条件
        dp[0][0] = 0.5;
        for (int b = 1; b <= n; b++) {
            dp[0][b] = 1.0;  // A 先空
        }
        // dp[a][0] = 0.0 默认值，B 先空

        // 状态转移
        for (int a = 1; a <= n; a++) {
            for (int b = 1; b <= n; b++) {
                dp[a][b] = 0.25 * (
                    dp[Math.max(0, a - 4)][b] +
                    dp[Math.max(0, a - 3)][Math.max(0, b - 1)] +
                    dp[Math.max(0, a - 2)][Math.max(0, b - 2)] +
                    dp[Math.max(0, a - 1)][Math.max(0, b - 3)]
                );
            }
        }

        return dp[n][n];
    }
}
```

### 方法二：记忆化递归

```java
import java.util.*;

class Solution {
    Map<Long, Double> memo = new HashMap<>();
    int N;

    public double soupServings(int n) {
        if (n > 5000) return 1.0;
        N = (n + 24) / 25;
        return dp(N, N);
    }

    private double dp(int a, int b) {
        // 边界条件
        if (a <= 0 && b <= 0) return 0.5;
        if (a <= 0) return 1.0;
        if (b <= 0) return 0.0;

        long key = (long) a * 10001 + b;
        if (memo.containsKey(key)) return memo.get(key);

        // 四种操作，每种概率 0.25
        double result = 0.25 * (
            dp(a - 4, b) +
            dp(a - 3, b - 1) +
            dp(a - 2, b - 2) +
            dp(a - 1, b - 3)
        );

        memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，最多计算 n² 个不同状态
- **空间复杂度**：O(n²)，DP 数组或记忆化缓存

## 关键点总结

1. **概率 DP**：状态转移方程包含概率权重
2. **数学优化**：n > 5000 时直接返回 1.0
3. **单位转换**：除以 25 减少状态数量
4. **边界处理**：三种边界情况需要分别处理
5. **向上取整**：`(n + 24) / 25`

## 易错点

1. **忘记数学优化**：n 很大时会超时，需要特判
2. **边界条件**：同时为空返回 0.5，不是 1
3. **单位转换**：必须向上取整
4. **概率计算**：每种操作概率是 0.25
5. **负数处理**：剩余量可能为负，需要用 Math.max(0, a - x)
