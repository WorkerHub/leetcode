## 题目描述

H表示仓鼠，.表示空格。水桶放空格处可喂相邻仓鼠。求喂饱所有仓鼠的最少水桶数，不可能返回-1。

## 解题思路

贪心右优先：遇到H优先在右侧放桶（可能覆盖下一只），右侧不行才左侧，都不行返回-1。

## Java 代码实现

```java
class Solution {
    public int minimumBuckets(String hamsters) {
        char[] s = hamsters.toCharArray();
        int n = s.length, ans = 0;
        
        for (int i = 0; i < n; i++) {
            if (s[i] == 'H') {
                if (i + 1 < n && s[i + 1] == '.') {
                    // 优先右侧放桶
                    s[i + 1] = '#';
                    ans++;
                } else if (i - 1 >= 0 && s[i - 1] == '.') {
                    // 右侧不行尝试左侧
                    s[i - 1] = '#';
                    ans++;
                } else {
                    return -1;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **右优先贪心**：右侧桶可能服务下一只仓鼠
2. **标记已用位置**：防止重复使用
3. **无解条件**：两侧都无法放桶
