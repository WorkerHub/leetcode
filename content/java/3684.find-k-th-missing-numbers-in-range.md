## 题目描述

给你一个整数数组 `nums`、整数 `lo`、`hi` 和整数 `k`。找出在范围 `[lo, hi]` 内未出现在 `nums` 中的第 k 个缺失数。

## 解题思路

建立 nums 的哈希集合，遍历 `[lo, hi]`，统计不在集合中的数，返回第 k 个。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findKthMissing(int[] nums, int lo, int hi, int k) {
        Set<Integer> numSet = new HashSet<>();
        for (int x : nums) numSet.add(x);
        int count = 0;
        for (int x = lo; x <= hi; x++) {
            if (!numSet.contains(x)) {
                count++;
                if (count == k) return x;
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + (hi - lo + 1))
- 空间复杂度：O(n)

## 关键点总结

1. 集合查找 O(1)，遍历范围一次即可
2. nums 中范围外的数不影响答案
3. 题目保证第 k 个缺失数存在
