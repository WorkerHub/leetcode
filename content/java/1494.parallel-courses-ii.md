## 题目描述

给你一个整数 `n`，表示编号从 `1` 到 `n` 的 `n` 门课，以及数组 `relations`，其中 `relations[i] = [prevCourse, nextCourse]` 表示课程 `prevCourse` 必须在 `nextCourse` 之前完成（先修课关系）。

每个学期，你可以选择**任意数量**的课程，但前提是所有先修课程**都已完成**。此外，每个学期**最多**可以选 `k` 门课。

请你返回学完所有课程所需的**最少学期数**。

**示例 1：**

```
输入：n = 4, dependencies = [[2,1],[3,1],[1,4]], k = 2
输出：3
解释：
第1学期：学 2 和 3
第2学期：学 1
第3学期：学 4
```

**示例 2：**

```
输入：n = 5, dependencies = [], k = 2
输出：3
解释：没有先修关系，每学期最多选 2 门，5 门课需要 3 学期。
```

**提示：**

- `1 <= n <= 15`
- `1 <= relations.length <= n*(n-1)/2`
- `1 <= k <= n`
- 不存在重复关系，且不存在自环。
- 保证给出的先修关系可以形成有向无环图。

## 解题思路

**n <= 15**，这提示我们使用**状态压缩动态规划**。

**状态定义：**

用一个 n 位的二进制数表示已完成课程的集合：第 `i` 位为 1 表示第 `i` 门课已完成。

`dp[mask]` = 完成 `mask` 表示的课程集合所需的最少学期数。

**关键步骤：**

1. **预处理先修课集合**：`pre[i]` = 第 `i` 门课的所有先修课组成的位掩码。

2. **转移**：对于状态 `mask`，找出所有"当前可学的课程"，即先修课都在 `mask` 中的未完成课程。

3. **枚举子集**：从可学课程集合中，枚举大小不超过 `k` 的子集 `sub`，转移到 `dp[mask | sub]`：

   ```
   dp[mask | sub] = min(dp[mask | sub], dp[mask] + 1)
   ```

4. **枚举子集的技巧**：对于集合 `available`，枚举其所有非空子集的标准写法：

   ```java
   for (int sub = available; sub > 0; sub = (sub - 1) & available) {
       // 处理 sub
   }
   ```

**时间复杂度：** O(3^n)，因为枚举所有状态的所有子集，总时间为 3^n（三项式定理）。

## Java 代码实现

### 方法一：状态压缩 DP + 枚举可选子集（推荐）

```java
import java.util.Arrays;

class Solution {
    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        // 预处理：pre[i] 表示第 i 门课（0 索引）的先修课位掩码
        int[] pre = new int[n];
        for (int[] rel : relations) {
            // 课程编号从 1 开始，转为 0 索引
            pre[rel[1] - 1] |= (1 << (rel[0] - 1));
        }

        // dp[mask] = 完成 mask 中所有课程所需最少学期数
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;  // 没完成任何课程，需要 0 学期

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;

            // 找出当前可以学习的课程（先修课都在 mask 中，且自身未在 mask 中）
            int available = 0;
            for (int i = 0; i < n; i++) {
                // 第 i 门课未完成，且所有先修课都已完成
                if ((mask >> i & 1) == 0 && (pre[i] & mask) == pre[i]) {
                    available |= (1 << i);
                }
            }

            // 枚举 available 的所有非空子集，选择大小不超过 k 的子集
            for (int sub = available; sub > 0; sub = (sub - 1) & available) {
                // 若子集大小不超过 k，才能在一个学期内完成
                if (Integer.bitCount(sub) <= k) {
                    int nextMask = mask | sub;
                    dp[nextMask] = Math.min(dp[nextMask], dp[mask] + 1);
                }
            }
        }

        return dp[(1 << n) - 1];
    }
}
```

### 方法二：带剪枝的优化版（popcount 优化）

```java
import java.util.Arrays;

class Solution {
    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        int[] pre = new int[n];
        for (int[] rel : relations) {
            pre[rel[1] - 1] |= (1 << (rel[0] - 1));
        }

        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;

            // 找可选课程
            int available = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 0 && (pre[i] & mask) == pre[i]) {
                    available |= (1 << i);
                }
            }

            int availCount = Integer.bitCount(available);

            // 若可选课程不超过 k，直接全选（贪心：尽量多选）
            if (availCount <= k) {
                int nextMask = mask | available;
                dp[nextMask] = Math.min(dp[nextMask], dp[mask] + 1);
                continue;
            }

            // 否则枚举大小恰好为 k 的子集（选满 k 门总比选少更优）
            for (int sub = available; sub > 0; sub = (sub - 1) & available) {
                if (Integer.bitCount(sub) == k) {
                    int nextMask = mask | sub;
                    dp[nextMask] = Math.min(dp[nextMask], dp[mask] + 1);
                }
            }
        }

        return dp[(1 << n) - 1];
    }
}
```

### 方法三：BFS 层次遍历（按学期层次推进）

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class Solution {
    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        int[] pre = new int[n];
        for (int[] rel : relations) {
            pre[rel[1] - 1] |= (1 << (rel[0] - 1));
        }

        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        int full = (1 << n) - 1;

        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0);

        while (!queue.isEmpty()) {
            int mask = queue.poll();
            int semester = dp[mask];

            // 找可学课程
            int available = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 0 && (pre[i] & mask) == pre[i]) {
                    available |= (1 << i);
                }
            }

            // 枚举子集
            for (int sub = available; sub > 0; sub = (sub - 1) & available) {
                if (Integer.bitCount(sub) <= k) {
                    int nxt = mask | sub;
                    if (dp[nxt] == Integer.MAX_VALUE) {
                        dp[nxt] = semester + 1;
                        if (nxt == full) return dp[nxt];
                        queue.offer(nxt);
                    }
                }
            }
        }

        return dp[full];
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一 | O(3^n) | O(2^n) |
| 方法二（剪枝） | O(3^n) | O(2^n) |
| 方法三（BFS） | O(3^n) | O(2^n) |

- `n <= 15`，`3^15 = 14348907`，完全可以接受
- 空间 `O(2^n)` 用于存储 dp 数组，`2^15 = 32768`

## 关键点总结

1. **状态压缩**：用二进制位表示课程完成状态，是处理 n <= 20 的集合问题的标准技巧。
2. **枚举子集**：`for (int sub = available; sub > 0; sub = (sub - 1) & available)` 是枚举集合所有非空子集的经典写法。
3. **贪心剪枝**：可选课程少于等于 k 时，直接全选是最优的（不会让后面更难）。
4. **先修课验证**：`(pre[i] & mask) == pre[i]` 判断课程 i 的所有先修课是否都已完成。
5. **Java 位操作**：`Integer.bitCount(mask)` 统计 1 的个数，等价于 Python 的 `bin(x).count('1')`。

## 图解示例

以 `n=4, relations=[[2,1],[3,1],[1,4]], k=2` 为例：

```
课程 1（0001）: 先修 2,3 → pre[0] = 0110
课程 2（0010）: 无先修 → pre[1] = 0000
课程 3（0100）: 无先修 → pre[2] = 0000
课程 4（1000）: 先修 1 → pre[3] = 0001

mask=0000: available={2,3}=0110, 全选 → mask=0110, dp[0110]=1
mask=0110: available={1}=0001, 全选 → mask=0111, dp[0111]=2
mask=0111: available={4}=1000, 全选 → mask=1111, dp[1111]=3
```

## 易错点

- **课程编号 1 到 n，转为 0 索引**：`prev-1` 和 `nxt-1`。
- **子集枚举终止条件**：`sub > 0` 而不是 `sub >= 0`，因为 sub=0 时循环结束。
- **枚举所有子集的效率**：直接枚举所有子集复杂度是 O(3^n)，不是 O(2^(2n))。
- **方法二的贪心**：只有"每次选满 k 门"才是最优的（选少会浪费学期），但子集枚举要特别注意。
