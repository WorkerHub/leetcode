## 题目描述

给你整数数组 `nums`，Alice 选所有个位数（1-9），Bob 选所有两位数（10-99），比较总和，返回 Alice 是否严格胜出。

## Java 代码实现

```java
class Solution {
    public boolean canAliceWin(int[] nums) {
        int alice = 0, bob = 0;
        for (int x : nums) {
            if (x < 10) alice += x;   // 个位数归 Alice
            else bob += x;            // 两位数归 Bob
        }
        return alice > bob;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 区分个位数（1-9）和两位数（10-99）
2. 比较两人总和，Alice 严格大于才赢
