## 题目描述

给你长度为 `n` 的 `[0,n-1]` 排列 `nums`，定义置换 `perm` 的花费为循环相邻元素差的绝对值之和，返回花费最小的字典序最小置换。

## 解题思路

状压 DP：固定 `perm[0]=0`（保证字典序最小），`dp[mask][last]` 表示已选集合为 `mask` 且最后一个元素为 `last` 时的最小花费。转移时枚举下一个元素，最终加上回到起点 0 的花费。回溯路径时，相同花费优先选字典序最小的下一个元素。

## Java 代码实现

```java
class Solution {
    public int[] findPermutation(int[] nums) {
        int n = nums.length;
        int full = (1 << n) - 1;
        int[][] dp = new int[1 << n][n];
        int[][] parent = new int[1 << n][n];
        final int INF = Integer.MAX_VALUE / 2;

        // 初始化 dp
        for (int[] row : dp) java.util.Arrays.fill(row, INF);
        for (int[] row : parent) java.util.Arrays.fill(row, -1);
        dp[1][0] = 0; // 只选了 0，最后是 0，花费为 0

        for (int mask = 1; mask <= full; mask++) {
            for (int last = 0; last < n; last++) {
                if ((mask >> last & 1) == 0 || dp[mask][last] == INF) continue;
                // 枚举下一个元素
                for (int nxt = 0; nxt < n; nxt++) {
                    if ((mask >> nxt & 1) != 0) continue;
                    int newMask = mask | (1 << nxt);
                    int cost = dp[mask][last] + Math.abs(nxt - nums[last]);
                    if (cost < dp[newMask][nxt]) {
                        dp[newMask][nxt] = cost;
                        parent[newMask][nxt] = last;
                    }
                }
            }
        }

        // 找最小总花费（含回到起点 0 的花费）
        int minCost = INF, bestLast = -1;
        for (int last = 0; last < n; last++) {
            int total = dp[full][last] + Math.abs(nums[last]);
            if (total < minCost) {
                minCost = total;
                bestLast = last;
            }
        }

        // 回溯路径
        int[] path = new int[n];
        int mask = full, cur = bestLast;
        for (int i = n - 1; i >= 0; i--) {
            path[i] = cur;
            int prev = parent[mask][cur];
            mask ^= (1 << cur);
            cur = prev;
        }
        return path;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × n^2)
- **空间复杂度**：O(2^n × n)

## 关键点总结

1. n ≤ 14，可用状压 DP 枚举所有子集
2. 固定起点为 0 以保证字典序最小
3. 花费包含最后一个元素回到起点 0 的距离（循环结构）
