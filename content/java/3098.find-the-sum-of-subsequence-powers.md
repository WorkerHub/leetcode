## 题目描述

给你整数数组 `nums` 和正整数 `k`。长度为 k 的子序列的**幂**定义为子序列相邻元素差的绝对值的最小值。返回所有长度为 k 的子序列的幂之和，答案对 `10^9 + 7` 取模。

## 解题思路

排序后 DP：`dp[i][j]` 为以 `nums[i]` 结尾、已选 j 个元素的方案集合（用 Map 存 minDiff -> 方案数）。枚举前驱 prev，更新 `minDiff = min(prev_minDiff, nums[i] - nums[prev])`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int sumOfPowers(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        int n = nums.length;

        // dp[i][j]: 以 nums[i] 结尾、已选 j 个的 {minDiff -> count}
        @SuppressWarnings("unchecked")
        Map<Long, Long>[][] dp = new HashMap[n][k + 1];
        for (int i = 0; i < n; i++)
            for (int j = 0; j <= k; j++)
                dp[i][j] = new HashMap<>();

        // 初始化：选 1 个，最小差为 Long.MAX_VALUE
        for (int i = 0; i < n; i++)
            dp[i][1].put(Long.MAX_VALUE, 1L);

        for (int j = 2; j <= k; j++) {
            for (int i = j - 1; i < n; i++) {
                for (int prev = 0; prev < i; prev++) {
                    long diff = (long) nums[i] - nums[prev];
                    for (Map.Entry<Long, Long> e : dp[prev][j - 1].entrySet()) {
                        long newMin = Math.min(e.getKey(), diff);
                        dp[i][j].merge(newMin, e.getValue(), (a, b) -> (a + b) % MOD);
                    }
                }
            }
        }

        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (Map.Entry<Long, Long> e : dp[i][k].entrySet()) {
                if (e.getKey() != Long.MAX_VALUE) {
                    ans = (ans + e.getKey() % MOD * e.getValue()) % MOD;
                }
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * k * D)，D 为不同差值数（n <= 50 可行）
- 空间复杂度：O(n * k * D)

## 关键点总结

1. 排序后子序列的幂 = 相邻选中元素之差的最小值
2. DP 状态中 minDiff 用 Map 存储，初始为 Long.MAX_VALUE
3. 注意差值可能超 int 范围，使用 long
