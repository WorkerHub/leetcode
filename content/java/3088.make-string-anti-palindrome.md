## 题目描述

若字符串中所有位置 i 均满足 s[i] != s[n-1-i]，则称为"反回文"，返回使 s 变为反回文所需最少操作次数，不可能则返回 -1。

## 解题思路

奇数长度必然返回 -1（中间字符自身配对）；统计相同配对对数即为最少操作数；若某字母在相同配对中出现次数超过 n/2，则无解。

## Java 代码实现

```java
class Solution {
    public int makeAntiPalindrome(String s) {
        int n = s.length();
        // 奇数长度：中间字符自身配对，无法满足反回文
        if (n % 2 == 1) return -1;

        int[] pairCount = new int[26]; // 相同配对中各字母出现次数
        int samePairs = 0;

        for (int i = 0; i < n / 2; i++) {
            char a = s.charAt(i), b = s.charAt(n - 1 - i);
            if (a == b) {
                samePairs++;
                pairCount[a - 'a']++;
            }
        }

        // 若某字母占据超过 n/2 个配对位置，无解
        for (int cnt : pairCount) {
            if (cnt > n / 2) return -1;
        }
        return samePairs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 奇数长度必然返回 -1（中间字符自身配对）
2. 每对相同配对至少修改一个，最少操作数 = 相同配对数
3. 若某字母占据超过 n/2 个配对位置，即使全都修改也无法避免冲突，返回 -1
