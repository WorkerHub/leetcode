## 题目描述

选一个整数 value，将数组中大于 value 的值变为 value，使数组和最接近 target。返回最小的 value。

**示例：**
```
输入：arr = [4,9,3], target = 10
输出：3
解释：value=3 时和为 9，value=4 时和为 11，都差 1，返回较小的 3
```

## 解题思路

二分查找：对 value 二分，计算变换后的和。找到使和最接近 target 的 value。

## Java 代码实现

```java
class Solution {
    public int findBestValue(int[] arr, int target) {
        Arrays.sort(arr);
        int n = arr.length;
        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + arr[i];
        }
        
        int lo = 0, hi = arr[n - 1];
        int bestValue = 0, bestDiff = Integer.MAX_VALUE;
        
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            int sum = computeSum(arr, prefix, mid);
            int diff = Math.abs(sum - target);
            
            if (diff < bestDiff || (diff == bestDiff && mid < bestValue)) {
                bestDiff = diff;
                bestValue = mid;
            }
            
            if (sum < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return bestValue;
    }
    
    private int computeSum(int[] arr, int[] prefix, int value) {
        // 二分找第一个 > value 的位置
        int idx = upperBound(arr, value);
        return prefix[idx] + value * (arr.length - idx);
    }
    
    private int upperBound(int[] arr, int value) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] <= value) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **二分答案**：对 value 进行二分搜索
2. **前缀和 + 二分**：快速计算变换后的和
3. **最接近**：找绝对值差最小的，相等取较小 value
4. **和的单调性**：value 越大，和越大
