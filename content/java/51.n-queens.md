## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

n 皇后问题研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n，返回所有不同的 n 皇后问题的解决方案。

**示例 1：**
```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
```

**示例 2：**
```
输入：n = 1
输出：[["Q"]]
```

**提示：**
- `1 <= n <= 9`

## 解题思路

核心思想：回溯 + 剪枝

**约束条件：**
1. 同一行只能有一个皇后
2. 同一列只能有一个皇后
3. 同一对角线只能有一个皇后

**对角线判断：**
- 主对角线：row - col 相同
- 副对角线：row + col 相同

## Java 代码实现

```java
class Solution {
    private List<List<String>> result = new ArrayList<>();
    private boolean[] cols;      // 列是否被占用
    private boolean[] diag1;     // 主对角线（row - col）是否被占用
    private boolean[] diag2;     // 副对角线（row + col）是否被占用
    private char[][] board;
    private int n;

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        cols = new boolean[n];
        diag1 = new boolean[2 * n - 1];
        diag2 = new boolean[2 * n - 1];
        board = new char[n][n];
        // 初始化棋盘
        for (char[] row : board) {
            Arrays.fill(row, '.');
        }
        backtrack(0);
        return result;
    }

    private void backtrack(int row) {
        if (row == n) {
            // 找到一个解，构建结果
            List<String> solution = new ArrayList<>();
            for (char[] r : board) {
                solution.add(new String(r));
            }
            result.add(solution);
            return;
        }

        for (int col = 0; col < n; col++) {
            // 检查是否可以放置
            if (cols[col] || diag1[row - col + n - 1] || diag2[row + col]) {
                continue;
            }

            // 放置皇后
            board[row][col] = 'Q';
            cols[col] = true;
            diag1[row - col + n - 1] = true;
            diag2[row + col] = true;

            // 递归下一行
            backtrack(row + 1);

            // 撤销选择
            board[row][col] = '.';
            cols[col] = false;
            diag1[row - col + n - 1] = false;
            diag2[row + col] = false;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n!)
- 空间复杂度：O(n)

## 关键点总结

1. **回溯框架**：逐行放置皇后
2. **剪枝条件**：检查列和对角线
3. **对角线公式**：row±col，注意 Java 中数组索引需要偏移 n-1 避免负数

## 易错点

1. **对角线判断**：主对角线 row-col 可能为负，需要加偏移量 n-1
2. **状态恢复**：回溯时要撤销所有状态
3. **结果构建**：需要用 `new String(charArray)` 构建字符串
