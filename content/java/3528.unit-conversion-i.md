## 题目描述

给定单位换算关系 `[unit1, unit2, factor]`（1 unit1 = factor unit2）和若干查询 `[from, to]`，求换算值，不可达返回 -1.0。

## 解题思路

双向建图（逆向因子为 1/factor），BFS 从起点出发沿路累乘换算因子找到终点。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public double[] unitConversion(String[][] conversions, String[][] queries) {
        Map<String, List<double[]>> graph = new HashMap<>(); // node -> [(neighbor, factor)]
        for (String[] conv : conversions) {
            double f = Double.parseDouble(conv[2]);
            graph.computeIfAbsent(conv[0], k -> new ArrayList<>()).add(new double[]{0, f});
            graph.computeIfAbsent(conv[1], k -> new ArrayList<>()).add(new double[]{0, 1.0 / f});
            // Store neighbor as index via name lookup
        }
        // Use string-keyed map properly
        Map<String, List<Object[]>> g = new HashMap<>();
        for (String[] conv : conversions) {
            double f = Double.parseDouble(conv[2]);
            g.computeIfAbsent(conv[0], k -> new ArrayList<>()).add(new Object[]{conv[1], f});
            g.computeIfAbsent(conv[1], k -> new ArrayList<>()).add(new Object[]{conv[0], 1.0 / f});
        }
        double[] result = new double[queries.length];
        for (int i = 0; i < queries.length; i++) {
            result[i] = bfs(g, queries[i][0], queries[i][1]);
        }
        return result;
    }

    private double bfs(Map<String, List<Object[]>> g, String start, String end) {
        if (start.equals(end)) return 1.0;
        Queue<Object[]> queue = new LinkedList<>();
        queue.offer(new Object[]{start, 1.0});
        Set<String> visited = new HashSet<>();
        visited.add(start);
        while (!queue.isEmpty()) {
            Object[] cur = queue.poll();
            String node = (String) cur[0];
            double val = (double) cur[1];
            List<Object[]> neighbors = g.getOrDefault(node, Collections.emptyList());
            for (Object[] nb : neighbors) {
                String next = (String) nb[0];
                double factor = (double) nb[1];
                if (next.equals(end)) return val * factor;
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(new Object[]{next, val * factor});
                }
            }
        }
        return -1.0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(q * (V + E))
- 空间复杂度：O(V + E)

## 关键点总结

1. 双向建图：正向 factor，逆向 1/factor
2. BFS 沿路累乘换算因子
3. 起终点相同返回 1.0，不可达返回 -1.0
