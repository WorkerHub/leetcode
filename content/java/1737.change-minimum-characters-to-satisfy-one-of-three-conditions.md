## 题目描述

给你两个小写字符串 `a` 和 `b`，每次操作可将任意字符改为任意小写字母。返回满足以下任一条件所需最少操作数：1. `a` 中每个字符严格小于 `b` 中每个字符；2. `b` 中每个字符严格小于 `a` 中每个字符；3. `a` 和 `b` 全由同一个字符组成。

## 解题思路

统计 `a`、`b` 的字母频率，用前缀和枚举条件1/2的分割点（25 个），枚举条件3的最终字符（26 个），取最小值。

## Java 代码实现

```java
class Solution {
    public int minCharacters(String a, String b) {
        int[] ca = new int[26], cb = new int[26];
        for (char c : a.toCharArray()) ca[c - 'a']++;
        for (char c : b.toCharArray()) cb[c - 'a']++;

        int la = a.length(), lb = b.length();
        int ans = la + lb;

        // 前缀和
        int[] pa = new int[27], pb = new int[27];
        for (int i = 0; i < 26; i++) {
            pa[i + 1] = pa[i] + ca[i];
            pb[i + 1] = pb[i] + cb[i];
        }

        for (int c = 0; c < 25; c++) {
            // 条件1：a 全 <= c，b 全 > c
            // a 中 > c 的需改变，b 中 <= c 的需改变
            int cost1 = (la - pa[c + 1]) + pb[c + 1];
            // 条件2：b 全 <= c，a 全 > c
            int cost2 = (lb - pb[c + 1]) + pa[c + 1];
            ans = Math.min(ans, Math.min(cost1, cost2));
        }

        // 条件3：a 和 b 全由同一字符组成
        for (int c = 0; c < 26; c++) {
            int cost = (la - ca[c]) + (lb - cb[c]);
            ans = Math.min(ans, cost);
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 26)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 三个条件分别计算，取最小
2. 前缀和加速条件1/2的枚举
3. 条件3取两字符串中同字母出现总次数最多的那个字符
