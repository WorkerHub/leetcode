## 题目描述

给定未排序整数数组，返回最长严格递增子序列的个数。

**示例：**
```
输入：nums = [1,3,5,4,7]
输出：2（[1,3,5,7] 和 [1,3,4,7]）
```

## 解题思路

在 LIS 基础上增加计数数组。dp[i] 表示以 nums[i] 结尾的 LIS 长度，count[i] 表示对应个数。找到更长则重置计数，长度相同则累加计数。

## Java 代码实现

```java
class Solution {
    public int findNumberOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];    // 以nums[i]结尾的LIS长度
        int[] count = new int[n]; // 对应的个数
        Arrays.fill(dp, 1);
        Arrays.fill(count, 1);

        int maxLen = 1;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    if (dp[j] + 1 > dp[i]) {
                        // 找到更长的子序列
                        dp[i] = dp[j] + 1;
                        count[i] = count[j];
                    } else if (dp[j] + 1 == dp[i]) {
                        // 长度相同，累加方案数
                        count[i] += count[j];
                    }
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }

        // 累加所有最长长度的计数
        int result = 0;
        for (int i = 0; i < n; i++) {
            if (dp[i] == maxLen) {
                result += count[i];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **状态扩展**：在 LIS 基础上增加计数维度
2. **计数累加**：长度相同时累加，长度更大时重置
3. **最终统计**：收集所有 dp[i]==maxLen 位置的 count
