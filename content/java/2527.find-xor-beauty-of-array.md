## 题目描述

给你整数数组 `nums`，定义三元组 `(i, j, k)` 的有效值为 `(nums[i] | nums[j]) & nums[k]`，返回所有三元组有效值的 XOR（XOR 美丽值）。

## 解题思路

利用 XOR 的对称性化简：当 `i != j` 时，`(i,j,k)` 与 `(j,i,k)` 有相同有效值，XOR 后为 0。只有 `i == j` 有贡献，化简后答案等于所有元素的 XOR。

## Java 代码实现

```java
class Solution {
    public int xorBeauty(int[] nums) {
        // 所有三元组有效值的 XOR 等于数组所有元素的 XOR
        int result = 0;
        for (int num : nums) result ^= num;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. `i != j` 的三元组对成抵消，XOR 贡献为 0
2. 只剩 `i == j` 的情况，继续化简后等于所有元素 XOR
3. 结论：答案是全数组 XOR，O(n) 一次遍历即可
