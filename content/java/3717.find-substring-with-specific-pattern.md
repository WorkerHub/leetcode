## 题目描述

给定字符串 `s` 和模式字符串 `pattern`，找出 `s` 中所有与 `pattern` 同构的子串起始下标（模式中相同字符对应子串中相同字符，不同字符对应不同字符）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> findSubstring(String s, String pattern) {
        int n = s.length(), m = pattern.length();
        List<Integer> result = new ArrayList<>();

        for (int i = 0; i <= n - m; i++) {
            if (matches(s, i, pattern, m)) {
                result.add(i);
            }
        }
        return result;
    }

    private boolean matches(String s, int start, String pattern, int m) {
        // 双向映射：pattern字符 -> s字符，s字符 -> pattern字符
        Map<Character, Character> p2s = new HashMap<>();
        Map<Character, Character> s2p = new HashMap<>();
        for (int k = 0; k < m; k++) {
            char pc = pattern.charAt(k), sc = s.charAt(start + k);
            if (p2s.containsKey(pc)) {
                if (p2s.get(pc) != sc) return false;
            } else {
                if (s2p.containsKey(sc) && s2p.get(sc) != pc) return false;
                p2s.put(pc, sc);
                s2p.put(sc, pc);
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m)，对每个起始位置检查长度 m 的子串
- 空间复杂度：O(m)，映射表大小

## 关键点总结

1. 双向映射（pattern->s 和 s->pattern）保证严格的双射关系
2. 只建立单向映射会导致不同 pattern 字符错误地映射到相同 s 字符
3. 遍历范围为 `[0, n-m]`，注意边界
