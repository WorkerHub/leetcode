## 题目描述

给定二维平面上 n 栋建筑 `(x, y)`。若某栋建筑在同一行有左侧和右侧各至少一栋建筑，且同一列有上方和下方各至少一栋建筑，则该建筑被"覆盖"。求被覆盖建筑数量。

## 解题思路

预处理：对每行记录 y 坐标最小值和最大值；对每列记录 x 坐标最小值和最大值。对每栋建筑判断四个条件是否均严格满足。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countCoveredBuildings(int n, int[][] buildings) {
        Map<Integer, int[]> rowRange = new HashMap<>(); // x -> [minY, maxY]
        Map<Integer, int[]> colRange = new HashMap<>(); // y -> [minX, maxX]

        for (int[] b : buildings) {
            int x = b[0], y = b[1];
            rowRange.merge(x, new int[]{y, y}, (a, v) -> new int[]{Math.min(a[0], v[0]), Math.max(a[1], v[1])});
            colRange.merge(y, new int[]{x, x}, (a, v) -> new int[]{Math.min(a[0], v[0]), Math.max(a[1], v[1])});
        }

        int count = 0;
        for (int[] b : buildings) {
            int x = b[0], y = b[1];
            int[] row = rowRange.get(x);
            int[] col = colRange.get(y);
            if (row[0] < y && row[1] > y && col[0] < x && col[1] > x) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 只需每行/列的 y/x 极值即可判断四方向覆盖
2. 严格小于/大于（当前建筑不能就是极值建筑）
3. HashMap merge 方便更新极值
