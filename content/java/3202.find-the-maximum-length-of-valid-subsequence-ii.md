## 题目描述

给你整数数组 `nums` 和正整数 `k`，若子序列中所有相邻元素之和对 k 取模的值相同，则称为有效子序列，返回最长有效子序列的长度。

## 解题思路

枚举目标余数 `r`（0 到 k-1），对每个 r 用 DP：`dp[j]` = 末尾元素模 k 为 j 时的最长有效子序列长度。对当前元素 `x`（cur = x%k），前一元素模 k 应为 `(r - cur + k) % k`，转移为 `dp[cur] = dp[(r-cur+k)%k] + 1`。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums, int k) {
        int ans = 0;
        int[] mods = new int[nums.length];
        for (int i = 0; i < nums.length; i++) mods[i] = nums[i] % k;

        // 枚举目标相邻和余数
        for (int r = 0; r < k; r++) {
            int[] dp = new int[k]; // dp[j]: 末尾元素 mod k == j 的最长有效子序列
            for (int cur : mods) {
                int prev = (r - cur + k) % k;
                dp[cur] = dp[prev] + 1;
            }
            for (int v : dp) ans = Math.max(ans, v);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × n)
- **空间复杂度**：O(k)

## 关键点总结

1. 固定目标余数 r，问题转化为一维 DP
2. 末尾为 cur 时，前一元素余数必须是 `(r - cur + k) % k`
3. n, k ≤ 1000，O(nk) = O(10^6) 可行
