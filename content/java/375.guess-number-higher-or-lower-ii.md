## 题目描述

我们正在玩一个猜数字游戏。游戏规则如下：

我从 `1` 到 `n` 之间选择一个数字。你需要猜我选的是哪个数字。

每次你猜错时，我会告诉你这个数字是大了还是小了。

然而，当你猜一个数字 `x` 并且猜错了的时候，你需要支付金额为 `x` 的现金。

给你一个特定的数字 `n`，返回能够确保你获胜的最小现金数，不管我选择哪个数字。

**示例 1：**

```
输入：n = 10
输出：16
解释：制胜策略如下：
- 数字范围是 [1,10]。你先猜测数字为 7 。
    - 如果这是我选中的数字，你的总费用为 $0 。否则，你需要支付 $7 。
    - 如果我的数字更大，则下一步需要猜测的数字范围是 [8,10] 。你可以猜 9 。
        - 如果这是我选中的数字，你的总费用为 $7 。否则，你需要支付 $9 。
        - 如果我的数字更大，那么这个数字一定是 10 。你猜测数字为 10 并赢得游戏，总费用为 $7 + $9 = $16 。
        - 如果我的数字更小，那么这个数字一定是 8 。你猜测数字为 8 并赢得游戏，总费用为 $7 + $9 = $16 。
    - 如果我的数字更小，则下一步需要猜测的数字范围是 [1,6] 。你可以猜 3 。
        - 如果这是我选中的数字，你的总费用为 $7 。否则，你需要支付 $3 。
        - 如果我的数字更大，则下一步需要猜测的数字范围是 [4,6] 。你可以猜 5 。
            - 如果这是我选中的数字，总费用为 $7 + $3 = $10 。否则，你需要支付 $5 。
            - 如果我的数字更大，那么这个数字一定是 6 。你猜测数字为 6 并赢得游戏，总费用为 $7 + $3 + $5 = $15 。
            - 如果我的数字更小，那么这个数字一定是 4 。你猜测数字为 4 并赢得游戏，总费用为 $7 + $3 + $5 = $15 。
        - 如果我的数字更小，则下一步需要猜测的数字范围是 [1,2] 。你可以猜 1 。
            - 如果这是我选中的数字，总费用为 $7 + $3 = $10 。否则，你需要支付 $1 。
            - 如果我的数字更大，那么这个数字一定是 2 。你猜测数字为 2 并赢得游戏，总费用为 $7 + $3 + $1 = $11 。
这是最坏情况下的 $16 。
```

## 解题思路

这是一道经典的**极小化极大**（Minimax）问题，使用动态规划求解。

### 问题理解

- 你的目标：最小化最坏情况下的总花费
- 对手的目标：让你花费最多（选择最坏的数字）
- 你需要找一个策略，使得无论对手怎么选，你的花费都最小

### 核心思想

**定义状态**：
- `dp[i][j]` 表示在范围 `[i, j]` 内确保获胜的最小花费

**状态转移**：
对于范围 `[i, j]`，我们可以选择猜任意数字 `k`（i ≤ k ≤ j）：
- 如果猜对了，花费为 0
- 如果猜错了：
  - 猜大了：继续在 `[i, k-1]` 中猜，花费为 `k + dp[i][k-1]`
  - 猜小了：继续在 `[k+1, j]` 中猜，花费为 `k + dp[k+1][j]`

由于对手会选择最坏的情况，我们取最大值：
```
cost(k) = k + max(dp[i][k-1], dp[k+1][j])
```

我们要最小化这个花费，所以：
```
dp[i][j] = min(cost(k)) for all k in [i, j]
```

### 边界条件

- `dp[i][i] = 0`（只有一个数字，直接猜对，花费为 0）
- `dp[i][j] = i` when `j = i + 1`（两个数字，猜小的那个）

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int getMoneyAmount(int n) {
        // dp[i][j] 表示在 [i, j] 范围内确保获胜的最小花费
        // 数组大小 (n+2) 是为了防止 k+1 越界
        int[][] dp = new int[n + 2][n + 2];

        // 枚举区间长度（从小到大）
        for (int length = 2; length <= n; length++) {
            // 枚举区间起点
            for (int i = 1; i <= n - length + 1; i++) {
                int j = i + length - 1;
                dp[i][j] = Integer.MAX_VALUE;

                // 枚举猜测的数字 k
                for (int k = i; k <= j; k++) {
                    // 左半边的花费（k 猜大了，继续在 [i, k-1] 猜）
                    int left = (k > i) ? dp[i][k - 1] : 0;
                    // 右半边的花费（k 猜小了，继续在 [k+1, j] 猜）
                    int right = (k < j) ? dp[k + 1][j] : 0;
                    // 猜 k 的总花费（对手选最坏情况）
                    int cost = k + Math.max(left, right);
                    // 我们选择花费最小的策略
                    dp[i][j] = Math.min(dp[i][j], cost);
                }
            }
        }

        return dp[1][n];
    }
}
```

### 方法二：记忆化搜索

```java
class Solution {
    private int[][] memo;

    public int getMoneyAmount(int n) {
        // 记忆化搜索（自顶向下）
        memo = new int[n + 1][n + 1];
        return dp(1, n);
    }

    private int dp(int i, int j) {
        // 返回在 [i, j] 范围内确保获胜的最小花费
        if (i >= j) {
            return 0;
        }

        if (memo[i][j] != 0) {
            return memo[i][j];
        }

        int minCost = Integer.MAX_VALUE;

        // 尝试猜测每个数字
        for (int k = i; k <= j; k++) {
            // 猜 k 的花费 = k + max(左边, 右边)
            int cost = k + Math.max(dp(i, k - 1), dp(k + 1, j));
            minCost = Math.min(minCost, cost);
        }

        memo[i][j] = minCost;
        return minCost;
    }
}
```

### 方法三：优化的动态规划（减少枚举范围）

```java
class Solution {
    public int getMoneyAmount(int n) {
        int[][] dp = new int[n + 2][n + 2];

        for (int length = 2; length <= n; length++) {
            for (int i = 1; i <= n - length + 1; i++) {
                int j = i + length - 1;
                dp[i][j] = Integer.MAX_VALUE;

                // 观察：最优 k 通常在区间中间偏右
                // 可以从 (i + j) / 2 开始搜索，但正确性需要验证
                // 此处仍然完整枚举，保证正确
                for (int k = i; k <= j; k++) {
                    int left = (k > i) ? dp[i][k - 1] : 0;
                    int right = (k < j) ? dp[k + 1][j] : 0;
                    int cost = k + Math.max(left, right);
                    dp[i][j] = Math.min(dp[i][j], cost);
                }
            }
        }

        return dp[1][n];
    }
}
```

## 复杂度分析

### 方法一/二/三：动态规划
- 时间复杂度：O(n^3)
  - 两层循环枚举区间：O(n^2)
  - 内层循环枚举猜测的数字：O(n)
- 空间复杂度：O(n^2)

## 关键点总结

1. **极小化极大**：你最小化，对手最大化
2. **动态规划**：自底向上，从小区间到大区间
3. **状态定义**：`dp[i][j]` 是关键
4. **状态转移**：
   ```
   dp[i][j] = min(k + max(dp[i][k-1], dp[k+1][j]))
   ```
5. **最坏情况**：对手会选择让你花费最多的情况

## 易错点

1. **边界条件**：`k - 1 < i` 或 `k + 1 > j` 时，对应子问题花费为 0
2. **遍历顺序**：必须先计算小区间，再计算大区间
3. **初始化**：`dp[i][i] = 0`（Java int 数组默认为 0，正好）
4. **范围**：注意是 `[1, n]`，不是 `[0, n-1]`
5. **max vs min**：
   - 内层 `Math.max`：对手选择最坏情况
   - 外层 `Math.min`：你选择最优策略
6. **数组越界**：使用 `(n+2)` 大小的数组，避免 `dp[k+1][j]` 越界

## 图解示例

### 示例：n = 3

```
dp[1][1] = 0
dp[2][2] = 0
dp[3][3] = 0

计算 dp[1][2]：
  猜 1: cost = 1 + max(0, dp[2][2]) = 1 + 0 = 1
  猜 2: cost = 2 + max(dp[1][1], 0) = 2 + 0 = 2
  dp[1][2] = min(1, 2) = 1

计算 dp[2][3]：
  猜 2: cost = 2 + max(0, dp[3][3]) = 2 + 0 = 2
  猜 3: cost = 3 + max(dp[2][2], 0) = 3 + 0 = 3
  dp[2][3] = min(2, 3) = 2

计算 dp[1][3]：
  猜 1: cost = 1 + max(0, dp[2][3]) = 1 + 2 = 3
  猜 2: cost = 2 + max(dp[1][1], dp[3][3]) = 2 + 0 = 2
  猜 3: cost = 3 + max(dp[1][2], 0) = 3 + 1 = 4
  dp[1][3] = min(3, 2, 4) = 2

答案：dp[1][3] = 2
```
