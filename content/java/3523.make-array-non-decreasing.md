## 题目描述

给定整数数组 `nums`，每次操作可将某元素替换为相邻元素的值。求使数组变为非递减所需的最少操作次数。

## 解题思路

最少操作次数 = `n - 最长非递减子序列长度`。用 `bisect_right` 等价的 `Arrays.binarySearch` 或手写二分，O(n log n) 求最长非递减子序列（LIS，允许相等）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumOperations(int[] nums) {
        int n = nums.length;
        int[] tails = new int[n];
        int len = 0;
        for (int x : nums) {
            // bisect_right：找第一个 > x 的位置
            int lo = 0, hi = len;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails[mid] <= x) lo = mid + 1;
                else hi = mid;
            }
            tails[lo] = x;
            if (lo == len) len++;
        }
        return n - len;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 最少操作数 = `n - 最长非递减子序列长度`
2. 允许相等：用 bisect_right（> x 的第一个位置）而非 bisect_left
3. 二分维护 tails 数组，O(log n) 每步
