## 题目描述

给定一个二进制数组 `data`，返回将数组中所有的 `1` 聚集在一起所需的最小交换次数。

**示例：**
```
输入: data = [1,0,1,0,1]
输出: 1
```

## 解题思路

滑动窗口：窗口大小 = 数组中 1 的总数。在所有该大小的窗口中，找到包含最多 1 的窗口，窗口内 0 的个数即为最小交换次数。

## Java 代码实现

```java
class Solution {
    public int minSwaps(int[] data) {
        // 统计 1 的总数作为窗口大小
        int ones = 0;
        for (int d : data) ones += d;
        if (ones <= 1) return 0;

        // 初始化第一个窗口内 1 的个数
        int currentOnes = 0;
        for (int i = 0; i < ones; i++) {
            currentOnes += data[i];
        }
        int maxOnes = currentOnes;

        // 滑动窗口
        for (int i = ones; i < data.length; i++) {
            currentOnes += data[i] - data[i - ones];
            maxOnes = Math.max(maxOnes, currentOnes);
        }

        // 需要交换的次数 = 窗口大小 - 窗口内最多的 1
        return ones - maxOnes;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **窗口大小**：等于数组中 1 的总数
2. **滑动窗口**：找包含最多 1 的窗口
3. **结果计算**：`ones - maxOnes` 即需要交换进来的 0 的个数
4. **边界处理**：ones <= 1 时无需交换
