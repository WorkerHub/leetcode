## 题目描述

给你偶数 `n`，初始排列 `perm[i]=i`。每步操作：偶数下标 `arr[i]=perm[i/2]`，奇数下标 `arr[i]=perm[n/2+(i-1)/2]`。返回使排列回到初始状态所需的最小操作步数。

## 解题思路

直接模拟：每步生成新数组，检测何时与初始排列相同。每次操作 O(n)，步数实际很小。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int reinitializePermutation(int n) {
        int[] perm = new int[n];
        for (int i = 0; i < n; i++) perm[i] = i;
        int[] original = perm.clone();
        int ops = 0;

        do {
            int[] arr = new int[n];
            for (int i = 0; i < n; i++) {
                if (i % 2 == 0) {
                    arr[i] = perm[i / 2];
                } else {
                    arr[i] = perm[n / 2 + (i - 1) / 2];
                }
            }
            perm = arr;
            ops++;
        } while (!Arrays.equals(perm, original));

        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k)，k 为操作步数（实际较小）
- **空间复杂度**：O(n)

## 关键点总结

1. 生成新数组 arr 后再赋值给 perm，不能边读边写
2. 偶数下标用 `i/2`，奇数下标用 `n/2 + (i-1)/2`
