## 题目描述

给定 m×n 二进制矩阵，返回元素全部为 1 的子矩形个数。

**示例：**
```
输入：mat = [[1,0,1],[1,1,0],[1,1,0]]
输出：13
```

## 解题思路

逐行处理：计算每格向左连续 1 的数量 h[i][j]，固定右下角 (i,j)，向上枚举取 min(h[k][j])，累加。

## Java 代码实现

```java
class Solution {
    public int numSubmat(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        // h[i][j] = 第 i 行第 j 列向左连续1的数量
        int[][] h = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 1) {
                    h[i][j] = (j > 0 ? h[i][j-1] : 0) + 1;
                }
            }
        }
        
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int minH = Integer.MAX_VALUE;
                for (int k = i; k >= 0 && h[k][j] > 0; k--) {
                    minH = Math.min(minH, h[k][j]);
                    count += minH;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **向左连续 1**：h[i][j] 预处理
2. **向上枚举**：取 min 即为该列高度范围内的宽度
3. **累加贡献**：每个 minH 代表新增的子矩形数
4. **单调栈优化**：可将 O(m²n) 降为 O(mn)
