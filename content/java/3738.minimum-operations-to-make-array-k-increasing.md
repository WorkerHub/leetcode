## 题目描述

给定整数数组 `arr` 和正整数 `k`，将数组按模 `k` 分成 `k` 组子序列，每次操作可将任意元素改为任意值，求使每组子序列都非递减所需的最少操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int kIncreasing(int[] arr, int k) {
        int totalOps = 0;
        for (int start = 0; start < k; start++) {
            // 提取第 start 组的元素
            List<Integer> group = new ArrayList<>();
            for (int i = start; i < arr.length; i += k) group.add(arr[i]);
            // 最少操作数 = 组长度 - 最长非递减子序列长度
            totalOps += group.size() - lisNonDecreasing(group);
        }
        return totalOps;
    }

    // 求最长非递减子序列长度（patience sorting，bisect_right）
    private int lisNonDecreasing(List<Integer> nums) {
        List<Integer> tails = new ArrayList<>();
        for (int x : nums) {
            // 找第一个 > x 的位置（允许相等，用 upperBound）
            int pos = upperBound(tails, x);
            if (pos == tails.size()) tails.add(x);
            else tails.set(pos, x);
        }
        return tails.size();
    }

    private int upperBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (list.get(mid) <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，每组 LIS 为 O(m log m)
- 空间复杂度：O(n/k)，每组的 tails 数组

## 关键点总结

1. 最少修改次数 = 总长度 - 最长非递减子序列长度
2. 非递减（允许相等）的 LIS 使用 `upperBound`（bisect_right）
3. 各组独立求解，结果求和
