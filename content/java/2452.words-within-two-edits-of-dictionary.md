## 题目描述

给你等长字符串数组 `queries` 和 `dictionary`，返回 `queries` 中与 `dictionary` 某个单词不同位置数 <= 2 的所有单词。

## 解题思路

暴力比较：对每个 query，遍历 dictionary 中每个单词计算不同位置数，若存在 <= 2 则加入结果。数组规模均 <= 100，暴力完全可行。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> twoEditWords(String[] queries, String[] dictionary) {
        List<String> result = new ArrayList<>();
        for (String q : queries) {
            for (String d : dictionary) {
                if (diffCount(q, d) <= 2) {
                    result.add(q);
                    break; // 找到一个满足条件的即可
                }
            }
        }
        return result;
    }

    // 计算两个字符串不同位置的数量
    private int diffCount(String s, String t) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != t.charAt(i)) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(Q × D × n)，Q、D 均 <= 100，n <= 100
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. 不同位置数 <= 2 的判断等价于汉明距离 <= 2
2. 题目规模小，暴力 O(Q × D × n) 完全可接受
3. 找到一个满足条件的词后立即 break，避免重复添加
