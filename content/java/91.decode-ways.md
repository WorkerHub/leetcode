## 题目描述

一条包含字母 `A-Z` 的消息通过以下映射进行了编码：

```
'A' -> "1"
'B' -> "2"
...
'Z' -> "26"
```

要解码已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。例如，`"11106"` 可以映射为：

- `"AAJF"` ，将消息分组为 `(1 1 10 6)`
- `"KJF"` ，将消息分组为 `(11 10 6)`

注意，消息不能分组为 `(1 11 06)`，因为 `"06"` 不能映射为 `"F"`，这是由于 `"6"` 和 `"06"` 在映射中并不等价。

给你一个只含数字的非空字符串 `s`，请计算并返回解码方法的总数。

题目数据保证答案肯定是一个 32 位的整数。

**示例 1：**
```
输入：s = "12"
输出：2
解释：它可以解码为 "AB"（1 2）或者 "L"（12）。
```

**示例 2：**
```
输入：s = "226"
输出：3
解释：它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6) 。
```

**示例 3：**
```
输入：s = "06"
输出：0
解释："06" 无法映射到 "F" ，因为存在前导零（"6" 和 "06" 不同）。
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含数字，并且可能包含前导零

## 解题思路

这是一道经典的动态规划题目，类似于爬楼梯问题，但增加了条件判断。

**核心思想：**
每个位置的解码方式数 = 单独解码当前数字的方式数 + 与前一位组合解码的方式数

**状态定义：**
- `dp[i]` 表示字符串前 `i` 个字符的解码方法总数

**状态转移方程：**
```
dp[i] = 0  // 初始值

// 情况1：当前字符单独解码（1-9有效，0无效）
if s[i-1] != '0':
    dp[i] += dp[i-1]

// 情况2：当前字符与前一个字符组合解码（10-26有效）
if i >= 2:
    two_digit = int(s[i-2:i])
    if 10 <= two_digit <= 26:
        dp[i] += dp[i-2]
```

**初始状态：**
- `dp[0] = 1`（空字符串有1种解码方式）
- `dp[1]`：第一个字符是 '0' 则为 0，否则为 1

**边界情况处理：**
1. **前导零**：如 "06"，无法解码，返回 0
2. **中间的零**：如 "10"，只能与前一位组合，不能单独解码
3. **无效组合**：如 "30"、"40"，无法解码

**图解示例（s = "226"）：**
```
位置:    0   1   2   3
字符:        2   2   6
dp:     1   1   2   3

i=1: "2" 可以单独解码 → dp[1] = dp[0] = 1
i=2: "2" 可以单独解码 → dp[2] += dp[1] = 1
     "22" 可以组合解码 → dp[2] += dp[0] = 1+1 = 2
i=3: "6" 可以单独解码 → dp[3] += dp[2] = 2
     "26" 可以组合解码 → dp[3] += dp[1] = 2+1 = 3
```

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int numDecodings(String s) {
        // 边界情况：空字符串或以0开头
        if (s == null || s.length() == 0 || s.charAt(0) == '0') {
            return 0;
        }

        int n = s.length();
        // dp[i] 表示前i个字符的解码方法数
        int[] dp = new int[n + 1];
        dp[0] = 1; // 空字符串
        dp[1] = 1; // 第一个字符（已排除'0'的情况）

        for (int i = 2; i <= n; i++) {
            // 情况1：单独解码当前字符（1-9）
            if (s.charAt(i - 1) != '0') {
                dp[i] += dp[i - 1];
            }

            // 情况2：与前一个字符组合解码（10-26）
            int twoDigit = Integer.parseInt(s.substring(i - 2, i));
            if (twoDigit >= 10 && twoDigit <= 26) {
                dp[i] += dp[i - 2];
            }
        }

        return dp[n];
    }
}
```

### 方法二：空间优化的动态规划

```java
class Solution {
    public int numDecodings(String s) {
        if (s == null || s.length() == 0 || s.charAt(0) == '0') {
            return 0;
        }

        int n = s.length();
        // 只需要保存前两个状态
        int prev2 = 1; // dp[i-2]
        int prev1 = 1; // dp[i-1]

        for (int i = 2; i <= n; i++) {
            int current = 0;

            // 单独解码
            if (s.charAt(i - 1) != '0') {
                current += prev1;
            }

            // 组合解码
            int twoDigit = Integer.parseInt(s.substring(i - 2, i));
            if (twoDigit >= 10 && twoDigit <= 26) {
                current += prev2;
            }

            // 更新状态
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
```

### 方法三：递归 + 记忆化（理解思路）

```java
class Solution {
    private int[] memo;

    public int numDecodings(String s) {
        memo = new int[s.length()];
        java.util.Arrays.fill(memo, -1);
        return dfs(s, 0);
    }

    private int dfs(String s, int index) {
        // 已解码完所有字符
        if (index == s.length()) {
            return 1;
        }

        // 遇到前导零或中间的零（无法单独解码）
        if (s.charAt(index) == '0') {
            return 0;
        }

        // 记忆化
        if (memo[index] != -1) {
            return memo[index];
        }

        // 情况1：解码一个字符
        int result = dfs(s, index + 1);

        // 情况2：解码两个字符（如果有效）
        if (index + 1 < s.length()) {
            int twoDigit = Integer.parseInt(s.substring(index, index + 2));
            if (twoDigit <= 26) {
                result += dfs(s, index + 2);
            }
        }

        memo[index] = result;
        return result;
    }
}
```

## 复杂度分析

**方法一（动态规划）：**
- 时间复杂度：O(n)，其中 n 是字符串长度，遍历一次
- 空间复杂度：O(n)，dp 数组

**方法二（空间优化）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)，只用常数个变量

**方法三（递归 + 记忆化）：**
- 时间复杂度：O(n)，每个位置最多计算一次
- 空间复杂度：O(n)，递归栈和记忆化数组

## 图解示例

### 示例 1：s = "226"

```
解码方式：
1. "2" + "2" + "6"  → B + B + F = BBF
2. "2" + "26"       → B + Z = BZ
3. "22" + "6"       → V + F = VF

动态规划过程：
索引:  0   1   2   3
字符:      2   2   6
dp:   1   1   2   3

解释：
- dp[0] = 1 (空字符串)
- dp[1] = 1 ("2"只有1种解码)
- dp[2] = 2 ("22"可以是"2"+"2"或"22")
- dp[3] = 3 ("226"可以是"2"+"26"或"22"+"6")
```

### 示例 2：s = "12"

```
解码方式：
1. "1" + "2"  → A + B = AB
2. "12"       → L

动态规划过程：
索引:  0   1   2
字符:      1   2
dp:   1   1   2

- dp[0] = 1
- dp[1] = 1 ("1")
- dp[2] = 2 ("1"+"2"或"12")
```

### 示例 3：s = "10"

```
解码方式：
1. "10"  → J (只能组合，不能分开)

注意："1"+"0" 无效，因为"0"无法映射

动态规划过程：
索引:  0   1   2
字符:      1   0
dp:   1   1   1

- dp[0] = 1
- dp[1] = 1 ("1")
- dp[2] = 1 ("0"不能单独解码，只能"10"组合)
```

## 关键点总结

1. **状态转移**：`dp[i]` 可能来自 `dp[i-1]`（单字符）和 `dp[i-2]`（双字符）
2. **边界条件**：'0' 不能单独解码，只能与前一位组合成 10 或 20
3. **有效范围**：单字符 1-9，双字符 10-26
4. **初始状态**：`dp[0]=1`（空字符串），`dp[1]` 取决于首字符
5. **空间优化**：可以用两个变量代替 dp 数组

## 易错点

1. **忘记处理前导零**：首字符为 '0' 时直接返回 0

2. **'0' 的处理不当**：'0' 不能单独解码，只能作为 10 或 20

3. **组合条件错误**：应该是 `10 <= twoDigit <= 26`

4. **Java 字符串比较**：字符比较用 `charAt(i) != '0'`，不能用 `==` 比较 String

5. **初始化错误**：`dp[0]` 必须为 1，代表空字符串有一种解码方式
