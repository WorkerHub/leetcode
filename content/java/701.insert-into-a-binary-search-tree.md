## 题目描述

给定二叉搜索树（BST）的根节点 `root` 和要插入树中的值 `value`，将值插入二叉搜索树。返回插入后二叉搜索树的根节点。输入数据保证，新值和原始二叉搜索树中的任意节点值都不同。

注意，可能存在多种有效的插入方式，只要树在插入后仍保持为二叉搜索树即可。你可以返回任意有效的结果。

**示例 1：**
```
输入：root = [4,2,7,1,3], val = 5
输出：[4,2,7,1,3,5]
解释：另一个满足题目要求可以通过的树是：
     4
   /   \
  2     7
 / \   /
1   3 5
```

**示例 2：**
```
输入：root = [40,20,60,10,30,50,70], val = 25
输出：[40,20,60,10,30,50,70,null,null,25]
```

**示例 3：**
```
输入：root = [4,2,7,1,3,null,null,null,null,null,null], val = 5
输出：[4,2,7,1,3,5]
```

**提示：**
- 树中的节点数将在 `[0, 10^4]` 的范围内
- `-10^8 <= Node.val <= 10^8`
- 所有值 `Node.val` 是独一无二的
- `-10^8 <= val <= 10^8`
- 保证 `val` 在原始 BST 中不存在

## 解题思路

二叉搜索树（BST）的核心性质：对于任意节点，其左子树所有节点值 < 当前节点值 < 右子树所有节点值。

**插入策略：**
1. 如果当前节点为空，创建新节点并返回
2. 如果插入值 < 当前节点值，递归插入到左子树
3. 如果插入值 > 当前节点值，递归插入到右子树
4. 利用 BST 性质，插入位置唯一确定（总是插入到叶子节点位置）

**关键观察：**
- BST 插入操作不需要复杂的树结构调整
- 按照 BST 性质一路向下查找，找到空位置即可插入
- 递归和迭代两种实现方式都很简洁

## Java 代码实现

### 方法一：递归实现（推荐）⭐

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        // 基础情况：找到插入位置（空节点）
        if (root == null) {
            return new TreeNode(val);
        }
        
        // 根据 BST 性质，决定插入到左子树还是右子树
        if (val < root.val) {
            root.left = insertIntoBST(root.left, val);
        } else { // val > root.val（题目保证值不重复）
            root.right = insertIntoBST(root.right, val);
        }
        
        return root;
    }
}
```

### 方法二：迭代实现

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        // 特殊情况：空树
        if (root == null) {
            return new TreeNode(val);
        }
        
        // 使用指针找到插入位置的父节点
        TreeNode current = root;
        while (true) {
            if (val < current.val) {
                // 应该插入到左子树
                if (current.left == null) {
                    current.left = new TreeNode(val);
                    break;
                }
                current = current.left;
            } else {
                // 应该插入到右子树
                if (current.right == null) {
                    current.right = new TreeNode(val);
                    break;
                }
                current = current.right;
            }
        }
        
        return root;
    }
}
```

### 方法三：简化的迭代实现

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) {
            return new TreeNode(val);
        }
        
        TreeNode node = root;
        while (node != null) {
            if (val < node.val) {
                if (node.left == null) {
                    node.left = new TreeNode(val);
                    return root;
                }
                node = node.left;
            } else {
                if (node.right == null) {
                    node.right = new TreeNode(val);
                    return root;
                }
                node = node.right;
            }
        }
        
        return root;
    }
}
```

## 复杂度分析

**方法一（递归）：**
- 时间复杂度：O(h)，其中 h 是树的高度
  - 平衡树：O(log n)
  - 最坏情况（链状树）：O(n)
- 空间复杂度：O(h)，递归调用栈深度

**方法二、三（迭代）：**
- 时间复杂度：O(h)
- 空间复杂度：O(1)，只使用常数个指针变量

## 关键点总结

1. **BST 性质应用**：左子树 < 根节点 < 右子树，确定唯一插入路径
2. **插入位置**：总是插入到叶子节点位置（找到第一个空位）
3. **递归思想**：递归处理子树，返回修改后的子树根节点
4. **边界处理**：空树情况需要特殊处理
5. **不需要平衡**：普通 BST 插入不需要旋转或重新平衡

## 易错点

1. **忘记处理空树**：`root` 为 `null` 时应直接返回新节点
2. **没有返回根节点**：递归函数需要返回当前子树的根
3. **迭代时没有保存根节点**：应该先保存 `root` 引用，最后返回
4. **误以为需要平衡**：题目只要求保持 BST 性质，不要求平衡
5. **遗漏等号情况**：虽然题目保证值不重复，但代码逻辑要清晰
