## 题目描述

对每个元素，求其作为最大值的最长子数组长度。

## 解题思路

单调栈：分别求每个元素左右第一个比它大的位置，ans[i]=right[i]-left[i]-1。

## Java 代码实现

```java
class Solution {
    public int[] maximumLengthOfRanges(int[] nums) {
        int n = nums.length;
        int[] left = new int[n];
        int[] right = new int[n];
        Arrays.fill(left, -1);
        Arrays.fill(right, n);

        // 单调递减栈求左边界
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }

        // 单调递减栈求右边界
        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            ans[i] = right[i] - left[i] - 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **单调递减栈求左右边界**：每个元素最多进出栈一次
2. **ans=right-left-1**：两个边界之间的距离
3. **元素互不相同**：不需处理相等情况
