## 题目描述

给你一个整数数组 `nums`，每次操作可将某个元素的任意位从 1 变为 0，求操作后数组所有元素异或的最大值。

## 解题思路

操作本质是可以将任意元素的任意位从 1 清零。若某一位在数组中至少有一个元素为 1，则可以保留该位的一个 1，其余清零，使得 XOR 该位为 1。因此最大 XOR 值等于所有元素的按位 OR。

## Java 代码实现

```java
class Solution {
    public int maximumXOR(int[] nums) {
        int result = 0;
        for (int num : nums) {
            result |= num; // 所有元素按位 OR
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 操作只能将位从 1 变 0，不能从 0 变 1。
2. 最大 XOR = 所有元素的按位 OR，每位只要有一个 1 就能保留。
3. 直接一次遍历求 OR 即可，无需模拟操作。
