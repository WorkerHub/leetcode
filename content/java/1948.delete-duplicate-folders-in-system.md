## 题目描述

给你文件夹路径列表，若两个文件夹的子树结构完全相同则均删除，返回删除后剩余的路径列表。

## 解题思路

字典树 + 子树序列化：构建 Trie，对每个节点递归序列化子树（子节点名称排序后拼接），用 HashMap 统计每种序列化的出现次数，出现 ≥ 2 次的子树标记删除，最后 DFS 收集未删除路径。

## Java 代码实现

```java
import java.util.*;

class Solution {
    Map<String, Integer> count = new HashMap<>();
    Map<TreeNode, String> serial = new HashMap<>();

    static class TreeNode {
        TreeMap<String, TreeNode> children = new TreeMap<>();
    }

    public List<List<String>> deleteDuplicateFolder(List<List<String>> paths) {
        TreeNode root = new TreeNode();
        // 建 Trie
        for (List<String> path : paths) {
            TreeNode cur = root;
            for (String f : path) cur = cur.children.computeIfAbsent(f, k -> new TreeNode());
        }
        // 序列化并计数
        serialize(root);
        // 收集未删除路径
        List<List<String>> result = new ArrayList<>();
        dfs(root, new ArrayList<>(), result);
        return result;
    }

    private String serialize(TreeNode node) {
        if (node.children.isEmpty()) return "";
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<String, TreeNode> e : node.children.entrySet())
            sb.append('(').append(e.getKey()).append(serialize(e.getValue())).append(')');
        String s = sb.toString();
        count.merge(s, 1, Integer::sum);
        serial.put(node, s);
        return s;
    }

    private void dfs(TreeNode node, List<String> path, List<List<String>> result) {
        for (Map.Entry<String, TreeNode> e : node.children.entrySet()) {
            TreeNode child = e.getValue();
            String s = serial.getOrDefault(child, "");
            if (!s.isEmpty() && count.get(s) >= 2) continue; // 重复子树，跳过
            path.add(e.getKey());
            result.add(new ArrayList<>(path));
            dfs(child, path, result);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * L * log L)
- **空间复杂度**：O(n * L)

## 关键点总结

1. TreeMap 保证子节点按名称排序，序列化结果唯一
2. 序列化时叶节点返回空串不计数，只计非叶子树
3. DFS 收集时跳过计数 ≥ 2 的子树（该子树整体删除）
