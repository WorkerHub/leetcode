## 题目描述

给定一个正整数数组 `nums` 和整数 `k`。找出最短的子数组，使得子数组中所有元素按位 OR 的结果包含 `k` 的所有设置位（即 `OR & k == k`）。返回该子数组的长度，若不存在则返回 `-1`。

## 解题思路

滑动窗口 + bit 计数。维护窗口内每个 bit 的出现次数，右指针右移时增加计数，左指针右移时减少计数（若某位计数变 0，该位从 OR 值中消失）。当窗口 OR 包含 k 的所有位时，尝试缩小窗口。

## Java 代码实现

```java
class Solution {
    public int smallestSubarray(int[] nums, int k) {
        int n = nums.length;
        // 先检查整个数组 OR 是否包含 k
        int totalOr = 0;
        for (int x : nums) totalOr |= x;
        if ((totalOr & k) != k) return -1;

        // 滑动窗口：维护每个 bit 的出现次数
        int[] bitCount = new int[30];
        int windowOr = 0, left = 0, ans = n + 1;

        for (int right = 0; right < n; right++) {
            int x = nums[right];
            // 更新 bit 计数
            for (int b = 0; b < 30; b++) {
                if ((x >> b & 1) == 1) {
                    bitCount[b]++;
                    windowOr |= (1 << b);
                }
            }
            // 若当前窗口 OR 包含 k，尝试缩小
            while ((windowOr & k) == k) {
                ans = Math.min(ans, right - left + 1);
                int y = nums[left++];
                for (int b = 0; b < 30; b++) {
                    if ((y >> b & 1) == 1) {
                        bitCount[b]--;
                        if (bitCount[b] == 0) windowOr &= ~(1 << b);
                    }
                }
            }
        }

        return ans <= n ? ans : -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 30)
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. OR 操作只增不减，需要用 bit 计数跟踪每个位是否还在窗口中
2. 窗口缩小时，若某位计数变 0，该位从 OR 值中消失
3. 条件是 `windowOr & k == k`（包含 k 的所有位）
