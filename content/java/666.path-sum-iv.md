## 题目描述

用三位整数数组表示深度<5 的二叉树（百位=深度，十位=位置，个位=值），返回所有根到叶路径和。

**示例：**
```
输入：nums = [113, 215, 221]
输出：12（路径：3+5=8, 3+1=4, 总和=12）
```

## 解题思路

哈希表存储节点，DFS 遍历累加路径和，左子节点(d+1, 2p-1)，右子节点(d+1, 2p)。

## Java 代码实现

```java
class Solution {
    private Map<Integer, Integer> tree = new HashMap<>();
    private int total = 0;

    public int pathSum(int[] nums) {
        // 建立哈希表：key = depth*10+pos, value = val
        for (int num : nums) {
            int key = num / 10;
            int val = num % 10;
            tree.put(key, val);
        }

        dfs(11, 0); // 从根节点(1,1)开始
        return total;
    }

    private void dfs(int key, int sum) {
        if (!tree.containsKey(key)) return;

        sum += tree.get(key);
        int depth = key / 10;
        int pos = key % 10;

        int leftKey = (depth + 1) * 10 + 2 * pos - 1;
        int rightKey = (depth + 1) * 10 + 2 * pos;

        // 叶子节点
        if (!tree.containsKey(leftKey) && !tree.containsKey(rightKey)) {
            total += sum;
            return;
        }

        dfs(leftKey, sum);
        dfs(rightKey, sum);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **编码解析**：key = depth*10 + pos
2. **子节点关系**：左(d+1, 2p-1)，右(d+1, 2p)
3. **叶子判断**：左右子节点都不存在
