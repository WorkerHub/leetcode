## 题目描述

给定一个整数数组，它表示二叉搜索树（BST）的前序遍历，请构造该树并返回其根节点。

保证对于给定的测试用例，总能找到满足要求的二叉搜索树。

**示例 1：**
```
输入：preorder = [8,5,1,7,10,12]
输出：[8,5,10,1,7,null,12]
```

**示例 2：**
```
输入：preorder = [1,3]
输出：[1,null,3]
```

**提示：**
- `1 <= preorder.length <= 100`
- `1 <= preorder[i] <= 10^8`
- `preorder` 中的值互不相同

## 解题思路

BST的性质：左子树所有节点值 < 根节点值 < 右子树所有节点值

前序遍历特点：根节点 -> 左子树 -> 右子树

**核心思想**：
1. 前序遍历的第一个元素是根节点
2. 找到第一个大于根节点的元素位置，将数组分为左右子树
3. 递归构造左右子树

**关键观察**：
- 利用BST的上下界性质可以优化
- 不需要真正分割数组，使用索引范围即可

## Java 代码实现

### 方法一：递归分治（推荐）

```java
class Solution {
    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, 0, preorder.length - 1);
    }

    private TreeNode build(int[] preorder, int start, int end) {
        // 递归终止条件
        if (start > end) return null;

        // 根节点
        TreeNode root = new TreeNode(preorder[start]);

        // 找到右子树的起始位置（第一个大于根节点值的位置）
        int i = start + 1;
        while (i <= end && preorder[i] < preorder[start]) {
            i++;
        }

        // 递归构造左右子树
        // 左子树：[start+1, i-1]
        // 右子树：[i, end]
        root.left = build(preorder, start + 1, i - 1);
        root.right = build(preorder, i, end);

        return root;
    }
}
```

### 方法二：利用上下界（O(n) 时间）

```java
class Solution {
    private int idx = 0; // 当前处理的索引

    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, Integer.MIN_VALUE, Integer.MAX_VALUE);
    }

    private TreeNode build(int[] preorder, int lower, int upper) {
        // 递归终止条件
        if (idx >= preorder.length) return null;

        int val = preorder[idx];
        // 如果当前值不在范围内，返回 null
        if (val < lower || val > upper) return null;

        // 创建节点并移动索引
        idx++;
        TreeNode root = new TreeNode(val);

        // 递归构造左右子树
        root.left = build(preorder, lower, val);
        root.right = build(preorder, val, upper);

        return root;
    }
}
```

### 方法三：单调栈优化（O(n) 时间）

```java
import java.util.*;

class Solution {
    public TreeNode bstFromPreorder(int[] preorder) {
        if (preorder.length == 0) return null;

        TreeNode root = new TreeNode(preorder[0]);
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        for (int i = 1; i < preorder.length; i++) {
            int val = preorder[i];
            TreeNode node = new TreeNode(val);

            // 如果当前值小于栈顶，作为左子节点
            if (val < stack.peek().val) {
                stack.peek().left = node;
            } else {
                // 找到第一个大于当前值的节点作为父节点
                TreeNode parent = stack.peek();
                while (!stack.isEmpty() && stack.peek().val < val) {
                    parent = stack.pop();
                }
                // 作为右子节点
                parent.right = node;
            }

            stack.push(node);
        }

        return root;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 方法一 | O(n²) | O(h) | 查找分界点需要 O(n) |
| 方法二 | O(n) | O(h) | 上下界递归，最优解之一 |
| 方法三 | O(n) | O(h) | 单调栈优化，最优解之一 |

其中 h 为树的高度，最坏 O(n)，平衡树 O(logn)

## 关键点总结

1. **BST性质**：利用左<根<右的性质分割子树
2. **前序遍历**：第一个元素是根节点
3. **优化方向**：
   - 避免重复查找 → 单调栈或上下界
4. **单调栈技巧**：维护根到当前节点的路径
5. **上下界技巧**：每个节点值都有范围限制

## 易错点

1. **数组越界**：查找分界点时要检查索引范围
2. **空树处理**：需要处理空数组情况
3. **单调栈逻辑**：理解何时作为左子节点、何时作为右子节点
4. **索引管理**：方法二中的全局索引要正确递增
5. **边界条件**：上下界的初始值用 Integer.MIN_VALUE 和 Integer.MAX_VALUE
