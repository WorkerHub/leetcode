## 题目描述

判断两棵只含加法运算的二叉表达式树是否等价（每个变量出现次数相同）。

## 解题思路

DFS统计每棵树的变量频次，比较是否相同。只有加法，满足交换律和结合律。

## Java 代码实现

```java
class Solution {
    public boolean checkEquivalence(Node root1, Node root2) {
        int[] freq = new int[26];
        countVars(root1, freq, 1);
        countVars(root2, freq, -1);
        for (int f : freq) {
            if (f != 0) return false;
        }
        return true;
    }
    
    private void countVars(Node node, int[] freq, int sign) {
        if (node == null) return;
        if (node.val != '+') {
            freq[node.val - 'a'] += sign;
        } else {
            countVars(node.left, freq, sign);
            countVars(node.right, freq, sign);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. **只有加法**：只需比较变量频次
2. **差分法**：tree1加，tree2减，最终全为0则等价
3. **叶节点是变量**：内部节点是'+'
