## 题目描述

给定整数数组 `nums` 和整数 `k`，统计满足条件的子数组数量：可以通过最多 `k` 次操作（每次将某元素增加 1）使该子数组变为非递减序列。

## 解题思路

滑动窗口 + 单调递减栈维护窗口代价。将子数组 `[l, r]` 变为非递减的代价为相邻下降对之和（简化模型）。当代价超过 `k` 时收缩左指针。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public long countSubarrays(int[] nums, long k) {
        int n = nums.length;
        long result = 0;
        long cost = 0; // 窗口 [left, right] 变为非递减的代价（相邻下降差之和）
        int left = 0;

        for (int right = 0; right < n; right++) {
            // 加入 nums[right]，更新与前一个元素的代价
            if (right > 0 && nums[right - 1] > nums[right]) {
                cost += (long)(nums[right - 1] - nums[right]);
            }

            // 收缩左边界，直到代价 <= k
            while (cost > k) {
                if (left + 1 < n && nums[left] > nums[left + 1]) {
                    cost -= (long)(nums[left] - nums[left + 1]);
                }
                left++;
            }

            result += (right - left + 1);
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 子数组变非递减的代价 = 所有相邻下降对差值之和
2. 滑动窗口：代价超过 k 时移动左指针，每次减去移除的相邻下降代价
3. 每个右端点对应的合法左端点区间长度即为贡献的子数组数量
