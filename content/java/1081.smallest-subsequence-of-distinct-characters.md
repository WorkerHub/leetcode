## 题目描述

返回字符串 s 的字典序最小的子序列，包含所有不同字符且每个字符只出现一次。与 316 题相同。

**示例：**
```
输入：s = "cbacdcbc"
输出："acdb"
```

## 解题思路

单调栈 + 贪心：维护递增栈，若栈顶字符大于当前字符且后面还会出现，则弹出栈顶。用 set 记录已在栈中的字符避免重复。

## Java 代码实现

```java
class Solution {
    public String smallestSubsequence(String s) {
        // 统计每个字符的剩余出现次数
        int[] remaining = new int[26];
        for (char c : s.toCharArray()) {
            remaining[c - 'a']++;
        }

        // 记录字符是否已在栈中
        boolean[] inStack = new boolean[26];
        StringBuilder stack = new StringBuilder();

        for (char c : s.toCharArray()) {
            remaining[c - 'a']--;

            // 已在栈中，跳过
            if (inStack[c - 'a']) continue;

            // 弹出栈顶：更大且后面还会出现
            while (stack.length() > 0 && stack.charAt(stack.length() - 1) > c
                    && remaining[stack.charAt(stack.length() - 1) - 'a'] > 0) {
                inStack[stack.charAt(stack.length() - 1) - 'a'] = false;
                stack.deleteCharAt(stack.length() - 1);
            }

            stack.append(c);
            inStack[c - 'a'] = true;
        }

        return stack.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个字符最多入栈出栈各一次
- **空间复杂度**：O(1)，栈最多 26 个字符

## 关键点总结

1. **单调栈**：维护字典序递增的字符序列
2. **贪心条件**：栈顶更大 + 后面还有该字符 → 弹出
3. **去重**：inStack 数组记录已在结果中的字符
4. **与 316 题相同**：Remove Duplicate Letters
