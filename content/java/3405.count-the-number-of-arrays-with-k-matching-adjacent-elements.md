## 题目描述

给定整数 `n`、`m` 和 `k`，统计长度为 n、元素在 [1,m] 内、恰好有 k 对相邻相等元素的数组数量，对 10^9+7 取模。

## Java 代码实现

```java
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int countGoodArrays(int n, int m, int k) {
        // 块数 t = n - k（每块内元素相同，相邻块不同）
        int t = n - k;
        if (t < 1 || t > n) return 0;

        // 预处理阶乘和逆元阶乘
        long[] fact = new long[n];
        long[] invFact = new long[n];
        fact[0] = 1;
        for (int i = 1; i < n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n - 1] = pow(fact[n - 1], MOD - 2);
        for (int i = n - 2; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;

        // C(n-1, t-1)：将 n 个位置分为 t 个非空块的方案数
        long waysSplit = comb(n - 1, t - 1, fact, invFact);

        // m * (m-1)^(t-1)：为 t 个块分配颜色的方案数
        long waysColor = (long) m % MOD * pow(m - 1, t - 1) % MOD;

        return (int) (waysplit * waysColor % MOD);
    }

    private long comb(int n, int r, long[] fact, long[] invFact) {
        if (r < 0 || r > n) return 0;
        return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
    }

    private long pow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，预处理阶乘
- 空间复杂度：O(n)，存储阶乘数组

## 关键点总结

1. 将"恰好 k 对相邻相等"转化为"分成 t = n-k 个连续块"。
2. 分块方案用插板法：C(n-1, t-1)。
3. 染色方案：m * (m-1)^(t-1)，第一块 m 种，后续每块不能和前一块同色。
