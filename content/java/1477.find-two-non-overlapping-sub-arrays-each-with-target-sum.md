## 题目描述

给你一个整数数组 `arr` 和一个整数值 `target`。

请你在 `arr` 中找**两个互不重叠的子数组**，且每个子数组的数字和都等于 `target`。可能会有多种方案，请你返回满足要求的两个子数组**长度之和的最小值**；如果无法找到这样的两个子数组，请返回 **-1**。

**子数组**是数组的一个连续部分。

**示例 1：**

```
输入：arr = [3,2,2,4,3], target = 3
输出：2
解释：找到两个子数组：[3]（长度1）和 [3]（长度1），长度之和=2
```

**示例 2：**

```
输入：arr = [7,3,4,7], target = 7
输出：2
解释：找到 [7]（下标0）和 [7]（下标3），长度和=2
```

**示例 3：**

```
输入：arr = [4,3,2,6,2,3,4], target = 6
输出：-1
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`
- **注意：数组元素均为正数**，这是滑动窗口可行的关键条件。

## 解题思路

**核心算法：滑动窗口 + 动态规划前缀最小值**

由于数组元素均为正数，可以用**滑动窗口**找到所有和等于 `target` 的子数组。

**步骤：**
1. 用滑动窗口遍历数组，找到所有和等于 `target` 的子数组，记录其结束位置和长度。
2. 维护前缀 DP 数组 `minLeft[i]`：以下标 `i` 为右端点，`arr[0..i]` 中和等于 `target` 的子数组的最短长度。
3. 再次用滑动窗口从左到右遍历，当找到一个以 `right` 结尾的目标子数组时，查看其左边（`arr[0..left-1]`）是否存在另一个目标子数组，用 `minLeft[left-1]` 获取最短长度并更新答案。

## Java 代码实现

### 方法一：滑动窗口 + 前缀DP（推荐）

```java
import java.util.Arrays;

class Solution {
    public int minSumOfLengths(int[] arr, int target) {
        int n = arr.length;
        final int INF = Integer.MAX_VALUE / 2;

        // minLeft[i]：arr[0..i] 范围内，和为 target 的子数组最短长度
        int[] minLeft = new int[n];
        Arrays.fill(minLeft, INF);

        int best = INF;  // 当前遇到的最短目标子数组长度
        int ans = INF;   // 最终答案

        int left = 0;
        int curSum = 0;

        for (int right = 0; right < n; right++) {
            curSum += arr[right];  // 扩展右边界

            // 窗口和超过 target 时，收缩左边界
            while (curSum > target) {
                curSum -= arr[left];
                left++;
            }

            // 找到和为 target 的窗口
            if (curSum == target) {
                int length = right - left + 1;  // 当前子数组长度

                // 如果左边存在另一个目标子数组，更新答案
                if (left > 0 && minLeft[left - 1] < INF) {
                    ans = Math.min(ans, minLeft[left - 1] + length);
                }

                best = Math.min(best, length);  // 更新最短长度
            }

            // 记录前缀最小值
            minLeft[right] = best;
        }

        return ans < INF ? ans : -1;
    }
}
```

### 方法二：哈希表记录前缀和

```java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int minSumOfLengths(int[] arr, int target) {
        int n = arr.length;
        final int INF = Integer.MAX_VALUE / 2;

        // 用哈希表记录前缀和出现的最近位置
        Map<Integer, Integer> prefixSumIndex = new HashMap<>();
        prefixSumIndex.put(0, -1);  // 前缀和 0 出现在下标 -1
        int curSum = 0;

        // best[i]：arr[0..i] 中和为 target 的子数组的最短长度
        int[] best = new int[n];
        Arrays.fill(best, INF);
        int curBest = INF;

        int ans = INF;

        for (int i = 0; i < n; i++) {
            curSum += arr[i];

            // 检查是否存在以 i 结尾、和为 target 的子数组
            if (prefixSumIndex.containsKey(curSum - target)) {
                int l = prefixSumIndex.get(curSum - target) + 1;  // 子数组起始位置
                int length = i - l + 1;

                // 查找左侧（l-1 之前）的最短目标子数组
                if (l > 0 && best[l - 1] < INF) {
                    ans = Math.min(ans, best[l - 1] + length);
                }

                curBest = Math.min(curBest, length);
            }

            best[i] = curBest;
            prefixSumIndex.put(curSum, i);  // 记录当前前缀和位置
        }

        return ans < INF ? ans : -1;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 + 前缀DP | O(n) | O(n) |
| 哈希表前缀和 | O(n) | O(n) |

- 所有方法时间复杂度均为 O(n)，一次线性扫描。

## 关键点总结

1. **数组元素为正数**是使用滑动窗口的前提，否则不能用滑动窗口（因为加入元素时窗口和单调增加）。
2. 前缀 DP 数组 `minLeft[i]` 记录 `arr[0..i]` 范围内最短的目标子数组长度，方便 O(1) 查询。
3. 找到以 `right` 结尾的目标子数组（起始 `left`）后，查 `minLeft[left-1]` 获取不重叠的最短子数组。
4. 注意处理 `left == 0` 的情况（子数组从头开始，左侧没有空间放第二个子数组）。

## 易错点

- **左侧越界**：当 `left == 0` 时，没有左侧空间，不能访问 `minLeft[-1]`。
- **不重叠条件**：两个子数组必须不重叠，所以第二个子数组的起始位置必须 > 第一个子数组的结束位置。
- **收缩条件**：滑动窗口收缩时，`while curSum > target` 而不是 `>=`，因为要允许 `curSum == target`。
