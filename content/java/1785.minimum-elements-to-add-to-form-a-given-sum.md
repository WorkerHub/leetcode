## 题目描述

给你整数数组 `nums`、整数 `limit` 和 `goal`。可向数组中添加元素（每个新元素绝对值不超过 `limit`），使得数组之和等于 `goal`。返回需要添加的最少元素数目。

## 解题思路

当前和与目标和的差值 `diff = abs(goal - sum(nums))`，每次最多弥补 `limit` 的差值，所以最少需要 `ceil(diff / limit)` 个元素。

使用整数向上取整公式 `(diff + limit - 1) / limit` 避免浮点误差。需用 `long` 防止溢出。

## Java 代码实现

```java
class Solution {
    public int minElements(int[] nums, int limit, int goal) {
        long currentSum = 0;
        for (int x : nums) currentSum += x;
        long diff = Math.abs((long) goal - currentSum);
        // 整数向上取整：(diff + limit - 1) / limit
        return (int) ((diff + limit - 1) / limit);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 差值 = `abs(goal - sum(nums))`，用 `long` 防溢出
2. 每次最多弥补 `limit`，向上取整即为答案
3. 整数向上取整 `(diff + limit - 1) / limit` 比浮点 ceil 更稳健
