## 题目描述

给定整数数组 `nums`，每次操作选择下标 i，将 `nums[i]` 移到数组末尾，耗时为 `i + 1`。求将数组变为非递减有序所需的最小总时间。

## 解题思路

贪心：找原数组中可以"原地保留"的最长有序前缀（与排序后相同），其余元素必须移动，代价为各自原始下标之和加上偏移。枚举保留前缀长度，选代价最小的方案。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumTime(int[] nums) {
        int n = nums.length;
        int[] sorted = nums.clone();
        Arrays.sort(sorted);

        // 找最长有序前缀（与排序后相同的前缀）
        int j = 0;
        while (j < n && nums[j] == sorted[j]) j++;

        // 下标 j 及之后的元素需要移动，代价为各自下标+1之和
        long total = 0;
        for (int i = j; i < n; i++) total += (i + 1);
        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 核心思路：找到原数组可以原地保留的最长有序前缀
2. 前缀必须是连续的，其余元素移动代价为原始下标之和
3. 贪心选择：尽量保留更多前缀元素减少总移动代价
