## 题目描述

实现一个 MyCalendarThree 类来存放日程安排。每次调用 book 方法时，返回所有事件中最大的 k 次预订。

**示例：**
```
myCalendar.book(10, 20); // 返回 1
myCalendar.book(50, 60); // 返回 1
myCalendar.book(10, 40); // 返回 2
myCalendar.book(5, 15);  // 返回 3
myCalendar.book(5, 10);  // 返回 3
myCalendar.book(25, 55); // 返回 3
```

## 解题思路

差分数组 + 扫描线：在 start 处 +1，end 处 -1，遍历所有时间点累加得到最大并发。

## Java 代码实现

```java
class MyCalendarThree {
    private TreeMap<Integer, Integer> delta;

    public MyCalendarThree() {
        delta = new TreeMap<>();
    }

    public int book(int start, int end) {
        delta.merge(start, 1, Integer::sum);
        delta.merge(end, -1, Integer::sum);

        // 扫描线求最大并发
        int active = 0, maxK = 0;
        for (int val : delta.values()) {
            active += val;
            maxK = Math.max(maxK, active);
        }
        return maxK;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，每次 book 遍历所有时间点
- **空间复杂度**：O(n)

## 关键点总结

1. **差分数组**：start 处 +1，end 处 -1
2. **TreeMap 有序**：自动按时间排序
3. **扫描线**：累加得到每个时刻的并发数
