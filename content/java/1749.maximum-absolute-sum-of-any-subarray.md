## 题目描述

给你整数数组 `nums`，返回任意子数组和的绝对值的最大值。

## 解题思路

最大绝对值子数组和 = max(最大子数组和, |最小子数组和|)。前缀和方法更简洁：答案 = 最大前缀和 - 最小前缀和。

## Java 代码实现

```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int prefix = 0;
        int maxPrefix = 0, minPrefix = 0;

        for (int x : nums) {
            prefix += x;
            maxPrefix = Math.max(maxPrefix, prefix); // 记录最大前缀和
            minPrefix = Math.min(minPrefix, prefix); // 记录最小前缀和
        }

        // 最大绝对值子数组和 = 最大前缀和 - 最小前缀和
        return maxPrefix - minPrefix;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 子数组和 = 两个前缀和之差，最大绝对值即最大前缀和与最小前缀和之差
2. 初始前缀和为 0 覆盖空前缀的情况
