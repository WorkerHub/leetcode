## 题目描述

给你两个整数数组 `groups` 和 `elements`。第 i 组需要分配一个代表元素，要求该元素是 `groups[i]` 的因子，且是 `elements` 中下标最小的那个因子。若不存在则返回 -1。

## 解题思路

筛法：对每个出现在 `elements` 中的值 v，标记其所有倍数的最优下标。最终对每个 `groups[i]` 直接查表，时间复杂度 O(MAX_VAL * log(MAX_VAL))。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[] assignElements(int[] groups, int[] elements) {
        int maxVal = 0;
        for (int g : groups) maxVal = Math.max(maxVal, g);
        for (int e : elements) maxVal = Math.max(maxVal, e);
        maxVal += 1;

        // valToIdx[v] = elements 中值为 v 的最小下标（未出现则为 Integer.MAX_VALUE）
        int[] valToIdx = new int[maxVal];
        Arrays.fill(valToIdx, Integer.MAX_VALUE);
        for (int j = 0; j < elements.length; j++) {
            int v = elements[j];
            if (v < maxVal) {
                valToIdx[v] = Math.min(valToIdx[v], j);
            }
        }

        // best[g] = groups[i]=g 时，elements 中 g 的因子的最小下标
        int[] best = new int[maxVal];
        Arrays.fill(best, Integer.MAX_VALUE);

        // 筛法：对每个 v，标记其所有倍数
        for (int v = 1; v < maxVal; v++) {
            if (valToIdx[v] == Integer.MAX_VALUE) continue;
            int idx = valToIdx[v];
            // v 的倍数：v, 2v, 3v, ...
            for (int multiple = v; multiple < maxVal; multiple += v) {
                best[multiple] = Math.min(best[multiple], idx);
            }
        }

        int[] result = new int[groups.length];
        for (int i = 0; i < groups.length; i++) {
            int g = groups[i];
            result[i] = (g < maxVal && best[g] != Integer.MAX_VALUE) ? best[g] : -1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(MAX_VAL * log(MAX_VAL))，调和级数筛法
- 空间复杂度：O(MAX_VAL)

## 关键点总结

1. 筛法：对每个出现在 elements 中的值 v，标记其所有倍数的最优下标
2. 每个 groups[i] 直接查 best 数组，O(1) 获取结果
3. 同一值 v 在 elements 中多次出现时，取最小下标
