## 题目描述

返回将start转变为goal所需的最少位翻转次数（汉明距离）。

## 解题思路

异或后统计1的个数：start^goal中为1的位即为需要翻转的位。

## Java 代码实现

```java
class Solution {
    public int minBitFlips(int start, int goal) {
        return Integer.bitCount(start ^ goal);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(max(start, goal)))
- **空间复杂度**：O(1)

## 关键点总结

1. **异或找不同位**：XOR结果中1的位置即不同的位
2. **Integer.bitCount()**：Java内置统计二进制1的个数
3. **汉明距离**：本质就是求两数的汉明距离
