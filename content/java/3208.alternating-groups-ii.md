## 题目描述

给你一个圆形整数数组 `colors` 和整数 `k`，返回长度为 `k` 的交替组的数量。

## Java 代码实现

```java
class Solution {
    public int numberOfAlternatingGroups(int[] colors, int k) {
        int n = colors.length;
        int ans = 0;
        int cnt = 1; // 以当前位置结尾的最长交替序列长度
        // 遍历整个圆两圈来处理圆形边界
        for (int i = 1; i < n + k - 1; i++) {
            if (colors[i % n] != colors[(i - 1) % n]) {
                cnt++;
            } else {
                cnt = 1;
            }
            // 从第 k-1 个位置开始，若连续交替长度 >= k 则计数
            if (i >= k - 1 && cnt >= k) {
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + k)
- 空间复杂度：O(1)

## 关键点总结

1. 圆形数组用取模处理，遍历 n + k - 1 次覆盖所有起点
2. 维护以当前位置结尾的最长交替序列长度
3. 交替组条件：连续交替长度不小于 k
