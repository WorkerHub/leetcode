## 题目描述

给你两个字符串数组 `word1` 和 `word2`，如果两个数组按顺序连接的字符串相同，返回 `true`。

## 解题思路

将两个数组分别拼接成字符串后比较。或用双指针逐字符比较，节省内存。

## Java 代码实现

```java
class Solution {
    public boolean arrayStringsAreEqual(String[] word1, String[] word2) {
        // 方法一：直接拼接比较
        StringBuilder sb1 = new StringBuilder();
        StringBuilder sb2 = new StringBuilder();
        for (String s : word1) sb1.append(s);
        for (String s : word2) sb2.append(s);
        return sb1.toString().equals(sb2.toString());
    }
}
```

### 方法二：双指针逐字符比较（节省内存）

```java
class Solution {
    public boolean arrayStringsAreEqual(String[] word1, String[] word2) {
        int i1 = 0, j1 = 0; // word1 中数组下标和字符下标
        int i2 = 0, j2 = 0; // word2 中数组下标和字符下标

        while (i1 < word1.length && i2 < word2.length) {
            if (word1[i1].charAt(j1) != word2[i2].charAt(j2)) return false;

            j1++;
            if (j1 == word1[i1].length()) { i1++; j1 = 0; }

            j2++;
            if (j2 == word2[i2].length()) { i2++; j2 = 0; }
        }

        return i1 == word1.length && i2 == word2.length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为所有字符总数
- **空间复杂度**：拼接法 O(n)，双指针 O(1)

## 关键点总结

1. 拼接法最简洁，适合一般场景
2. 双指针法节省空间，避免创建大字符串
3. 双指针结束后确认两数组都恰好遍历完
