## 题目描述

字符有自定义价值映射，求字符串中代价最大的子串的代价（空串代价为0）。

## 解题思路

Kadane算法（最大子数组和）：将字符串转化为价值数组，维护当前子数组和，负数时重置为0。

## Java 代码实现

```java
class Solution {
    public int maximumCostSubstring(String s, String chars, int[] vals) {
        // 构建字符价值映射
        int[] cost = new int[26];
        for (int i = 0; i < 26; i++) cost[i] = i + 1; // 默认字母序号
        for (int i = 0; i < chars.length(); i++) {
            cost[chars.charAt(i) - 'a'] = vals[i]; // 覆盖自定义价值
        }

        // Kadane算法
        int ans = 0, cur = 0;
        for (char c : s.toCharArray()) {
            cur += cost[c - 'a'];
            if (cur < 0) cur = 0;
            ans = Math.max(ans, cur);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **Kadane算法**：最大子数组和经典线性算法
2. **空串代价为0**：结果下界是0
3. **价值映射**：先设默认再覆盖自定义
