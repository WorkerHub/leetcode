## 题目描述

n 名乘客登机，第一人票丢了随机坐。后续乘客若自己座位空则坐自己的，否则随机选空位。求第 n 位乘客坐到自己座位的概率。

**示例：**
```
n = 1 → 1.0
n = 2 → 0.5
```

## 解题思路

数学归纳法可证明：对于 n ≥ 2，答案恒为 0.5。直觉上，最后一个人的座位要么被第一个人（或其替代者）占了，要么没有，概率对称。

## Java 代码实现

```java
class Solution {
    public double nthPersonGetsNthSeat(int n) {
        // n=1 时概率为 1，n>=2 时恒为 0.5
        return n == 1 ? 1.0 : 0.5;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **数学结论**：n ≥ 2 时答案恒为 1/2
2. **对称性**：最后一个座位只可能被第 1 人的座位或第 n 人的座位"填充"，概率相等
3. **归纳证明**：可通过递推关系 f(n) = 1/n + (n-2)/n × f(n-1) 归纳得出
