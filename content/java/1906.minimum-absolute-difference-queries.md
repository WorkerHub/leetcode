## 题目描述

给你整数数组 `nums`（值域 1~100）和查询数组 `queries`（每个查询为 `[l, r]`），对每个查询返回子数组 `nums[l..r]` 中不同元素间的最小绝对差（若所有元素相同返回 -1）。

## 解题思路

利用值域有限（1~100）建立前缀和计数数组 `prefix[i][v]` 表示前 i 个元素中值 v 的出现次数。对每个查询遍历值域，找出区间内存在的相邻值之间的最小差。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[] minDifference(int[] nums, int[][] queries) {
        int n = nums.length;
        // prefix[i][v] = nums[0..i-1] 中值 v 的出现次数
        int[][] prefix = new int[n + 1][101];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = Arrays.copyOf(prefix[i], 101);
            prefix[i + 1][nums[i]]++;
        }

        int[] result = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1];
            int prev = -1, minDiff = Integer.MAX_VALUE;
            for (int v = 1; v <= 100; v++) {
                // 判断值 v 是否在 [l, r] 内出现
                if (prefix[r + 1][v] - prefix[l][v] > 0) {
                    if (prev != -1) minDiff = Math.min(minDiff, v - prev);
                    prev = v;
                }
            }
            result[q] = (minDiff == Integer.MAX_VALUE) ? -1 : minDiff;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 100 + q * 100)
- **空间复杂度**：O(n * 100)

## 关键点总结

1. 值域有限（1~100）是关键，可用前缀和计数
2. `prefix[r+1][v] - prefix[l][v]` 判断 v 是否在区间内出现
3. 遍历值域时相邻两个出现的值之差最小
