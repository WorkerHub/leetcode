## 题目描述

给你一个 `m x n` 的矩阵 `grid`（元素为 0、1 或 2）。找从某点出发、沿对角方向行进、最多转一次方向（仅改变行方向），且路径值交替为 1->2->1->2... 的最长 V 形对角线段长度。

## 解题思路

记忆化 DFS：状态 `dp[r][c][dir][turned]` 表示从 (r,c) 出发，当前方向为 dir，是否已转向，能走的最长路径。每步路径值交替 1->2->1...，转向只改变行方向、列方向不变。

## Java 代码实现

```java
class Solution {
    private int m, n;
    private int[][] grid;
    // dp[r][c][dir][turned]: dir: 0=(1,1), 1=(1,-1), 2=(-1,1), 3=(-1,-1); turned: 0/1
    private int[][][][] memo;
    // 方向数组：(dr, dc)
    private static final int[][] DIRS = {{1, 1}, {1, -1}, {-1, 1}, {-1, -1}};

    public int lenOfVDiagonal(int[][] grid) {
        this.m = grid.length;
        this.n = grid[0].length;
        this.grid = grid;
        this.memo = new int[m][n][4][2];
        // -1 表示未计算
        for (int[][][] a : memo) for (int[][] b : a) for (int[] c : b) java.util.Arrays.fill(c, -1);

        int ans = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    // 枚举 4 个初始方向
                    for (int dir = 0; dir < 4; dir++) {
                        ans = Math.max(ans, dp(r, c, dir, 0, 1));
                    }
                }
            }
        }
        return ans;
    }

    // 从 (r,c) 出发，方向 dir，是否已转向 turned，期望当前值 expected
    private int dp(int r, int c, int dir, int turned, int expected) {
        if (r < 0 || r >= m || c < 0 || c >= n) return 0;
        if (grid[r][c] != expected) return 0;
        if (memo[r][c][dir][turned] != -1) return memo[r][c][dir][turned];

        int nextExp = (expected == 1) ? 2 : 1;
        int dr = DIRS[dir][0], dc = DIRS[dir][1];

        // 继续同方向
        int best = 1 + dp(r + dr, c + dc, dir, turned, nextExp);

        // 转向（只能转一次，改变行方向，列方向不变）
        if (turned == 0) {
            // 寻找新方向：行方向取反，列方向不变
            int newDr = -dr;
            // 找新方向的 dir 编号
            int newDir = -1;
            for (int d = 0; d < 4; d++) {
                if (DIRS[d][0] == newDr && DIRS[d][1] == dc) { newDir = d; break; }
            }
            if (newDir != -1) {
                best = Math.max(best, 1 + dp(r + newDr, c + dc, newDir, 1, nextExp));
            }
        }

        memo[r][c][dir][turned] = best;
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 4 * 2)，每个状态计算一次
- 空间复杂度：O(m * n * 8)

## 关键点总结

1. V 形路径：先沿一个对角方向，再转向（仅改变行方向，列方向不变）
2. 路径值交替 1->2->1->2...，转向只能发生一次
3. 记忆化 DFS 避免重复计算
