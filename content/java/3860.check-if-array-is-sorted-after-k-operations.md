## 题目描述

给你一个整数数组 `nums` 和一个正整数 `k`，每次操作可以选择数组中的任意一个元素加 1（但每个元素最多操作 `k` 次）。判断是否能通过这些操作使数组变为非递减序列。

## 解题思路

贪心模拟：从左到右遍历，每当 `nums[i] < nums[i-1]`，计算需要增加的次数 `need = nums[i-1] - nums[i]`。若 `need > k` 则无法完成；否则将 `nums[i]` 提升到 `nums[i-1]`，继续向右传递约束。

## Java 代码实现

```java
class Solution {
    public boolean isSortedAfterOperations(int[] nums, int k) {
        int n = nums.length;
        int prev = nums[0];

        for (int i = 1; i < n; i++) {
            if (nums[i] < prev) {
                int need = prev - nums[i];
                if (need > k) return false;
                // 将 nums[i] 增加到 prev，传递约束
            } else {
                prev = nums[i];
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 只能增加元素，不能减少，前面较大的元素是约束。
2. 贪心：每个元素只增加到恰好等于前一个元素（最少操作）。
3. 若某个元素需要增加 `need > k` 次，则不可能完成。
