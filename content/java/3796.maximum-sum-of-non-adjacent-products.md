## 题目描述

给定整数数组 `nums`，选择若干个不相邻的相邻元素对 `(i, i+1)`，使选出的乘积之和最大，结果对 `10^9+7` 取模。

## Java 代码实现

```java
class Solution {
    public int maxScore(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        // dp[i]: 前 i 个元素的最大乘积和
        // dp[i] = max(dp[i-1], dp[i-2] + nums[i-2]*nums[i-1])
        long prev2 = 0, prev1 = 0;

        for (int i = 2; i <= n; i++) {
            long product = (long) nums[i - 2] * nums[i - 1];
            long cur = Math.max(prev1, prev2 + product);
            prev2 = prev1;
            prev1 = cur;
        }

        return (int) (prev1 % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每次选一对相邻元素 `(i, i+1)`，选了后相邻对不能再选（间隔至少 1 个位置）
2. 类似打家劫舍问题，状态转移为选或不选当前对
3. 乘积可能很大，用 `long` 防止溢出，最终取模
