## 题目描述

给你正整数 `n` 和 `target`，找出最小非负整数 `x`，使得 `n + x` 的各位数字之和不超过 `target`。

## 解题思路

贪心进位：若当前各位之和 > target，将最低若干位进位清零（即找下一个 `base * 10` 的整数倍），重复此操作直到满足条件。每次进位使低位数字之和大幅减少，高位最多增加 1。

## Java 代码实现

```java
class Solution {
    public long makeIntegerBeautiful(long n, int target) {
        long original = n;
        long base = 1;

        while (digitSum(n) > target) {
            // 进位：找下一个 base * 10 的整数倍
            n = (n / (base * 10) + 1) * (base * 10);
            base *= 10;
        }
        return n - original;
    }

    private int digitSum(long x) {
        int sum = 0;
        while (x > 0) {
            sum += x % 10;
            x /= 10;
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log² n)，最多处理 log n 位，每次计算数字和 O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：从低位到高位，每次进位使低位变为 0
2. `n = (n / (base * 10) + 1) * (base * 10)` 将最低 `base` 位进位清零
3. `n` 可能超过 int 范围，使用 `long`
