## 题目描述

给你 `n` 个景点、`k` 天，`stayScore[day][city]` 为停留得分，`travelScore[from][to]` 为移动得分，每天可停留或移动，返回 k 天最大得分。

## 解题思路

DP：`dp[city]` 表示当前天在 city 的最大累计得分。每天枚举上一天所在城市，选择停留（加 stayScore）或移动（加 travelScore），转移更新下一天 dp。

## Java 代码实现

```java
class Solution {
    public int maxScore(int n, int k, int[][] stayScore, int[][] travelScore) {
        int[] dp = new int[n]; // 初始第 0 天各城市得分均为 0

        for (int day = 0; day < k; day++) {
            int[] newDp = new int[n];
            Arrays.fill(newDp, Integer.MIN_VALUE / 2);
            for (int from = 0; from < n; from++) {
                if (dp[from] == Integer.MIN_VALUE / 2) continue;
                // 停留
                newDp[from] = Math.max(newDp[from], dp[from] + stayScore[day][from]);
                // 移动到其他城市
                for (int to = 0; to < n; to++) {
                    if (to != from)
                        newDp[to] = Math.max(newDp[to], dp[from] + travelScore[from][to]);
                }
            }
            dp = newDp;
        }

        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * n^2)，每天枚举所有城市对
- 空间复杂度：O(n)

## 关键点总结

1. 初始 dp 全为 0（第 0 天在任意城市无得分）
2. 每天有停留和移动两种选择，取最大值
3. `travelScore[i][i] = 0`，移动到自身等同于停留但得分不同
