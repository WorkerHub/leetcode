## 题目描述

给你两个正整数 `a` 和 `b`，返回它们公因子的数目。

## 解题思路

公因子一定是最大公约数（GCD）的因子。先求 `g = gcd(a, b)`，再枚举 1 到 g 统计 g 的因子个数即可。

## Java 代码实现

```java
class Solution {
    public int commonFactors(int a, int b) {
        int g = gcd(a, b); // 最大公约数
        int count = 0;
        // 统计 g 的因子个数
        for (int i = 1; i <= g; i++) {
            if (g % i == 0) count++;
        }
        return count;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(a, b) + log(min(a, b)))，枚举因子 + 求 GCD
- **空间复杂度**：O(1)

## 关键点总结

1. 公因子一定是 GCD 的因子，先求 GCD 可缩小枚举范围
2. 枚举到 g（包含），不是 g-1
