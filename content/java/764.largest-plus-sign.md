## 题目描述

在一个 `n x n` 的矩阵 `grid` 中，除了在数组 `mines` 中给出的元素为 `0`，其他每个元素都为 `1`。`mines[i] = [xi, yi]` 表示 `grid[xi][yi] == 0`。

返回矩阵中最大的轴对齐加号标志的阶数。如果未找到加号标志，则返回 `0`。

一个 `k` 阶加号标志是由两条长度均为 `k - 1`、交叉于中心点的线段组成的十字形。

**示例 1:**
```
输入: n = 5, mines = [[4, 2]]
输出: 2
解释: 在上面的网格中，最大加号标志的阶数为 2。
```

**示例 2:**
```
输入: n = 1, mines = [[0, 0]]
输出: 0
```

**提示:**
- `1 <= n <= 500`
- `1 <= mines.length <= 5000`
- `0 <= xi, yi < n`
- 每一对 `(xi, yi)` 都不重复

## 解题思路

对于每个位置，我们需要知道它在四个方向（上下左右）上连续 1 的个数，取最小值就是以该位置为中心的加号的最大阶数。

**算法流程：**
1. 初始化一个 n×n 的矩阵，所有位置都设为 n
2. 将 mines 中的位置设为 0
3. 对每个位置，计算四个方向的连续 1 的个数
4. 取四个方向的最小值

## Java 代码实现

### 方法一：动态规划（推荐）

```java
import java.util.*;

class Solution {
    public int orderOfLargestPlusSign(int n, int[][] mines) {
        // 初始化 dp 数组，表示每个位置四个方向的最小臂长
        int[][] dp = new int[n][n];
        for (int[] row : dp) Arrays.fill(row, n);

        // 标记地雷位置
        Set<Integer> banned = new HashSet<>();
        for (int[] mine : mines) {
            banned.add(mine[0] * n + mine[1]);
            dp[mine[0]][mine[1]] = 0;
        }

        // 从左到右、从右到左、从上到下、从下到上四个方向各扫描一次
        int ans = 0;

        for (int i = 0; i < n; i++) {
            int count;

            // 向右扫描（左臂长）
            count = 0;
            for (int j = 0; j < n; j++) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = Math.min(dp[i][j], count);
            }

            // 向左扫描（右臂长）
            count = 0;
            for (int j = n - 1; j >= 0; j--) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = Math.min(dp[i][j], count);
            }

            // 向下扫描（上臂长）
            count = 0;
            for (int j = 0; j < n; j++) {
                count = banned.contains(j * n + i) ? 0 : count + 1;
                dp[j][i] = Math.min(dp[j][i], count);
            }

            // 向上扫描（下臂长），同时更新答案
            count = 0;
            for (int j = n - 1; j >= 0; j--) {
                count = banned.contains(j * n + i) ? 0 : count + 1;
                dp[j][i] = Math.min(dp[j][i], count);
                ans = Math.max(ans, dp[j][i]);
            }
        }

        return ans;
    }
}
```

### 方法二：四个方向分别计算

```java
import java.util.*;

class Solution {
    public int orderOfLargestPlusSign(int n, int[][] mines) {
        Set<Integer> banned = new HashSet<>();
        for (int[] mine : mines) {
            banned.add(mine[0] * n + mine[1]);
        }

        int[][] dp = new int[n][n];

        for (int i = 0; i < n; i++) {
            int count;

            // 左
            count = 0;
            for (int j = 0; j < n; j++) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = count;
            }

            // 右
            count = 0;
            for (int j = n - 1; j >= 0; j--) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = Math.min(dp[i][j], count);
            }
        }

        int ans = 0;

        for (int j = 0; j < n; j++) {
            int count;

            // 上
            count = 0;
            for (int i = 0; i < n; i++) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = Math.min(dp[i][j], count);
            }

            // 下
            count = 0;
            for (int i = n - 1; i >= 0; i--) {
                count = banned.contains(i * n + j) ? 0 : count + 1;
                dp[i][j] = Math.min(dp[i][j], count);
                ans = Math.max(ans, dp[i][j]);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n^2)
- **空间复杂度：** O(n^2)

## 关键点总结

1. **四个方向：** 需要计算上下左右四个方向
2. **取最小值：** 加号的阶数由最短的臂决定
3. **动态规划：** 一次遍历计算两个方向
4. **空间优化：** 可以用一个数组存储结果

## 易错点

1. **初始值：** dp 初始化为 n，不是 0
2. **边界处理：** 地雷位置要置 0
3. **更新时机：** 每个方向遍历完后更新答案
