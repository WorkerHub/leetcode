## 题目描述

给定股票价格数组 `prices` 和冷冻期 `k`，卖出后必须等待至少 `k` 天才能再次买入，求最大利润。

## Java 代码实现

```java
class Solution {
    public int maxProfit(int[] prices, int k) {
        int n = prices.length;
        if (n <= 1) return 0;

        // hold: 持有股票时的最大利润
        // free[i]: 第 i 天不持有且可以买入时的最大利润
        int hold = Integer.MIN_VALUE / 2;
        int[] free = new int[n + k + 1];  // 下标偏移，防止越界

        for (int i = 0; i < n; i++) {
            int newHold = Math.max(hold, free[i] - prices[i]);
            // 今天卖出后，第 i+k+1 天才能买入
            int soldToday = hold + prices[i];
            free[i + k + 1] = Math.max(free[i + k], Math.max(soldToday, 0));
            hold = newHold;
        }

        int ans = 0;
        for (int i = n; i <= n + k; i++) ans = Math.max(ans, free[i]);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(n + k)，free 数组

## 关键点总结

1. 卖出后需等 k 天（冷冻期）才能再次买入，第 `i+k+1` 天才可买
2. `hold` 表示持有股票的最大利润，初始为负无穷
3. `free[i]` 记录第 i 天不持有且可买入时的最大利润
