## 题目描述

给你整数数组 nums 和整数 target，在 nums 的无限拼接中找元素之和等于 target 的最短子数组长度，不存在则返回 -1。

## 解题思路

将 target 分解为 `q * total + r`（total 为 nums 总和），在 nums+nums 中用滑动窗口找和为 r（r=0 时找和为 total）的最短子数组，最终长度 = `extra * n + best`。

## Java 代码实现

```java
class Solution {
    public int minSizeSubarray(int[] nums, int target) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        long q = target / total;
        long r = target % total;

        // r=0 时找和为 total 的子数组；否则找和为 r 的子数组
        long need = r > 0 ? r : total;

        // 在 nums+nums（长 2n）中用滑动窗口找最短和 = need 的子数组
        int best = Integer.MAX_VALUE;
        long curSum = 0;
        int left = 0;

        for (int right = 0; right < 2 * n; right++) {
            curSum += nums[right % n];
            while (curSum > need) {
                curSum -= nums[left % n];
                left++;
            }
            if (curSum == need) {
                best = Math.min(best, right - left + 1);
            }
        }

        if (best == Integer.MAX_VALUE) return -1;

        // r>0 时用 q 个完整 nums；r=0 时用 q-1 个完整 nums
        long extraComplete = r > 0 ? q : q - 1;
        return (int) (extraComplete * n + best);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 分解 target = q*total + r，余数 r 的最短子数组用滑动窗口求
2. r=0 特殊处理：在 2*nums 中找和为 total 的最短子数组，总完整数减 1
3. 循环访问用 `nums[right % n]` 避免构造 doubled 数组
