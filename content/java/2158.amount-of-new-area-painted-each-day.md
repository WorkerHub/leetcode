## 题目描述

每天涂色一个区间[start,end)，返回每天新涂的区域长度（已涂区域不重复计算）。

## 解题思路

跳表法（并查集思想）：next[i]表示位置i及之后第一个未涂位置。涂色时从next[l]跳跃到r，路径压缩加速。

## Java 代码实现

```java
class Solution {
    int[] next;
    
    public int[] amountPainted(int[][] paint) {
        int MAX = 50001;
        next = new int[MAX + 1];
        for (int i = 0; i <= MAX; i++) next[i] = i;
        
        int[] result = new int[paint.length];
        for (int i = 0; i < paint.length; i++) {
            int l = paint[i][0], r = paint[i][1];
            int count = 0;
            int pos = findNext(l);
            while (pos < r) {
                count++;
                next[pos] = pos + 1; // 标记已涂
                pos = findNext(pos + 1);
            }
            result[i] = count;
        }
        return result;
    }
    
    private int findNext(int x) {
        if (next[x] == x) return x;
        next[x] = findNext(next[x]); // 路径压缩
        return next[x];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * α(MAX))，近似O(N)
- **空间复杂度**：O(MAX)

## 关键点总结

1. **跳表思想**：next[i]指向i及之后第一个未涂位置
2. **路径压缩**：每个位置只被涂一次，后续直接跳过
3. **每个位置只处理一次**：总工作量为O(MAX)
