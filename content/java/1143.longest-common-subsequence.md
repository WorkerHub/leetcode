## 题目描述

给定两个字符串 text1 和 text2，返回最长公共子序列的长度。子序列不要求连续。

**示例：**
```
输入：text1 = "abcde", text2 = "ace"
输出：3（LCS 为 "ace"）
```

## 解题思路

经典二维 DP：`dp[i][j]` = text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度。字符相同则 `dp[i-1][j-1]+1`，不同则 `max(dp[i-1][j], dp[i][j-1])`。

## Java 代码实现

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)，可优化为 O(min(m,n))

## 关键点总结

1. **DP 定义**：`dp[i][j]` 对应 text1[0..i-1] 和 text2[0..j-1]
2. **状态转移**：相同 +1，不同取 max
3. **边界**：第 0 行/列全为 0
4. **子序列 vs 子串**：子序列不要求连续
