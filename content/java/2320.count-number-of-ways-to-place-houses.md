## 题目描述

街道两侧各有 n 块地，同侧相邻地块不能同时放房子，返回所有放置方案数（模 10^9+7）。

## 解题思路

两侧独立，答案为单侧方案数的平方。单侧问题等价于斐波那契：`dp[i] = dp[i-1] + dp[i-2]`，其中 `dp[0]=1, dp[1]=2`。

## Java 代码实现

```java
class Solution {
    public int countHousePlacements(int n) {
        final int MOD = 1_000_000_007;
        long prev2 = 1; // dp[0]
        long prev1 = 2; // dp[1]
        if (n == 1) return (int)((prev1 * prev1) % MOD);
        for (int i = 2; i <= n; i++) {
            long cur = (prev1 + prev2) % MOD;
            prev2 = prev1;
            prev1 = cur;
        }
        // 两侧方案数相乘
        return (int)((prev1 * prev1) % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 两侧独立，答案为单侧方案数的平方。
2. 单侧满足斐波那契递推，`dp[0]=1`（空序列），`dp[1]=2`（放或不放）。
3. 注意中间计算时用 `long` 防止溢出，最后取模。
