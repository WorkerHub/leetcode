## 题目描述

设计MKAverage：维护最近m个元素，去掉最小k个和最大k个后的平均值。元素不足m个返回-1。

## 解题思路

三个TreeMap（低/中/高）维护滑动窗口，mid_sum记录中间部分总和。每次add后rebalance保持各部分大小固定。

## Java 代码实现

```java
class MKAverage {
    private int m, k;
    private Deque<Integer> window;
    private TreeMap<int[], Integer> low, mid, high; // 复杂，改用简化方案
    private long midSum;
    private int lowSize, midSize, highSize;
    // 使用一个有序结构+deque的方案
    private int[] sortedWindow;
    
    // 简化方案：用一个TreeMap维护整体，查询时计算
    private TreeMap<Integer, Integer> sorted;
    private long totalSum;
    private Deque<Integer> queue;
    
    public MKAverage(int m, int k) {
        this.m = m;
        this.k = k;
        this.queue = new ArrayDeque<>();
        this.sorted = new TreeMap<>();
        this.totalSum = 0;
    }
    
    public void addElement(int num) {
        queue.offer(num);
        sorted.merge(num, 1, Integer::sum);
        totalSum += num;
        
        if (queue.size() > m) {
            int old = queue.poll();
            totalSum -= old;
            int cnt = sorted.get(old);
            if (cnt == 1) sorted.remove(old);
            else sorted.put(old, cnt - 1);
        }
    }
    
    public int calculateMKAverage() {
        if (queue.size() < m) return -1;
        
        // 计算最小k个元素之和
        long lowSum = 0;
        int count = 0;
        for (Map.Entry<Integer, Integer> e : sorted.entrySet()) {
            int take = Math.min(e.getValue(), k - count);
            lowSum += (long) e.getKey() * take;
            count += take;
            if (count >= k) break;
        }
        
        // 计算最大k个元素之和
        long highSum = 0;
        count = 0;
        for (Map.Entry<Integer, Integer> e : sorted.descendingMap().entrySet()) {
            int take = Math.min(e.getValue(), k - count);
            highSum += (long) e.getKey() * take;
            count += take;
            if (count >= k) break;
        }
        
        return (int) ((totalSum - lowSum - highSum) / (m - 2 * k));
    }
}
```

## 复杂度分析

- **addElement**：O(log M)
- **calculateMKAverage**：O(K + log M)

## 关键点总结

1. **滑动窗口**：deque维护最近m个元素
2. **TreeMap有序**：方便找最小k个和最大k个
3. **totalSum维护**：快速计算中间部分和
