## 题目描述

返回数组所有元素乘积的符号（正1，负-1，零0）。

## 解题思路

不计算实际乘积，逐步翻转符号：遇0返回0，遇负数翻转。

## Java 代码实现

```java
class Solution {
    public int arraySign(int[] nums) {
        int sign = 1;
        for (int x : nums) {
            if (x == 0) return 0;
            if (x < 0) sign = -sign;
        }
        return sign;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **遇0直接返回0**
2. **负数个数奇偶决定符号**
3. **不计算实际乘积**：避免溢出
