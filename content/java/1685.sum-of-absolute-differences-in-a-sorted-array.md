## 题目描述

非递减有序整数数组 `nums`，返回数组 `result`，其中 `result[i]` = `sum(|nums[i] - nums[j]|)` 对所有 `j != i`。

## 解题思路

**前缀和：** 由于数组已排序，对位置 `i`：
- 左侧贡献 = `i * nums[i] - prefixSum[i]`
- 右侧贡献 = `(totalSum - prefixSum[i+1]) - (n-1-i) * nums[i]`

## Java 代码实现

```java
class Solution {
    public int[] getSumAbsoluteDifferences(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        int[] result = new int[n];
        long pre = 0; // nums[0..i-1] 的前缀和

        for (int i = 0; i < n; i++) {
            // 左侧 i 个元素都 <= nums[i]
            long left = (long) i * nums[i] - pre;
            // 右侧 n-1-i 个元素都 >= nums[i]
            long rightSum = total - pre - nums[i];
            long right = rightSum - (long) (n - 1 - i) * nums[i];
            result[i] = (int) (left + right);
            pre += nums[i];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计结果数组）

## 关键点总结

1. 数组已排序，左侧元素 <= 当前，右侧元素 >= 当前，绝对值可以去掉
2. 左侧贡献 = `左侧个数 * nums[i] - 左侧总和`
3. 右侧贡献 = `右侧总和 - 右侧个数 * nums[i]`
4. 注意用 `long` 防止溢出
