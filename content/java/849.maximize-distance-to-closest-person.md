## 题目描述

一排座位 seats[i]（1 有人，0 空），选一个空位坐下使得到最近的人的距离最大。返回该最大距离。

**示例：**
```
输入：seats = [1,0,0,0,1,0,1]
输出：2
```

## 解题思路

三种情况：开头空位取距离，中间空位取两人间距/2，结尾空位取距离。

## Java 代码实现

```java
class Solution {
    public int maxDistToClosest(int[] seats) {
        int n = seats.length;
        int prev = -1;
        int maxDist = 0;

        for (int i = 0; i < n; i++) {
            if (seats[i] == 1) {
                if (prev == -1) {
                    // 开头空位
                    maxDist = i;
                } else {
                    // 中间空位
                    maxDist = Math.max(maxDist, (i - prev) / 2);
                }
                prev = i;
            }
        }
        // 结尾空位
        maxDist = Math.max(maxDist, n - 1 - prev);

        return maxDist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **三种情况**：开头、中间、结尾分别处理
2. **中间距离**：两人间距整除 2
3. **一次遍历**：记录上一个人的位置
