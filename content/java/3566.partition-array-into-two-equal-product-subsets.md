## 题目描述

给定一个整数数组 `nums`（元素均为正整数），判断是否可以将数组分成两个非空子集，使得两个子集的元素乘积相等。

## 解题思路

两个子集乘积相等，且并集为整个数组，因此总乘积必须是完全平方数，每个子集乘积为 sqrt(P)。枚举所有非空真子集，检查是否存在乘积等于 sqrt(P) 的子集。

## Java 代码实现

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int n = nums.length;
        long totalProd = 1;
        for (int x : nums) totalProd *= x;

        // 总乘积必须是完全平方数
        long sqrtP = (long) Math.sqrt(totalProd);
        if (sqrtP * sqrtP != totalProd) return false;

        long target = sqrtP;
        // 枚举所有非空真子集
        for (int mask = 1; mask < (1 << n) - 1; mask++) {
            long prod = 1;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) {
                    prod *= nums[i];
                    if (prod > target) break;
                }
            }
            if (prod == target) return true;
        }

        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)，枚举子集
- 空间复杂度：O(1)

## 关键点总结

1. 两个子集乘积相等等价于总乘积是完全平方数
2. 每个子集乘积 = sqrt(总乘积)
3. 枚举非空真子集（不包含全集和空集）检查乘积
