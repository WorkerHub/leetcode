## 题目描述

给定整数数组 `nums` 和正整数 `k`，返回长度能被 `k` 整除的非空子数组的最大元素和。

## Java 代码实现

```java
class Solution {
    public long maxSubarraySum(int[] nums, int k) {
        int n = nums.length;
        // minPref[r] = 余数为 r 的前缀和最小值
        long[] minPref = new long[k];
        long INF = Long.MAX_VALUE / 2;
        java.util.Arrays.fill(minPref, INF);
        minPref[0] = 0; // prefix[0] = 0，余数 0

        long prefix = 0;
        long best = Long.MIN_VALUE;

        for (int i = 0; i < n; i++) {
            prefix += nums[i];
            int r = (i + 1) % k;
            if (minPref[r] != INF) {
                best = Math.max(best, prefix - minPref[r]);
            }
            minPref[r] = Math.min(minPref[r], prefix);
        }

        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(k)，余数数组

## 关键点总结

1. 子数组长度被 k 整除 <=> 左右端点前缀和下标模 k 相同。
2. 对每个右端点，找同余的最小前缀和使差值最大。
3. 初始化 `minPref[0] = 0`，允许从头开始的子数组。
