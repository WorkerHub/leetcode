## 题目描述

给你整数数组 `nums` 和整数 `k`，每次取最小两个元素 x、y，替换为 `x*2 + y`，重复直到所有元素 >= k，返回最少操作次数。

## 解题思路

使用最小堆模拟：每次取出最小两个元素合并后放回，直到堆顶元素 >= k。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        // 构建最小堆
        PriorityQueue<Long> pq = new PriorityQueue<>();
        for (int x : nums) pq.offer((long) x);

        int ops = 0;
        while (pq.peek() < k) {
            long x = pq.poll(); // 最小元素
            long y = pq.poll(); // 次小元素
            pq.offer(x * 2 + y); // 合并后放回
            ops++;
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，每次操作 O(log n)，最多 O(n) 次操作
- **空间复杂度**：O(n)，堆

## 关键点总结

1. 最小堆高效获取最小两个元素
2. 合并规则：`min*2 + max`（即 x*2 + y，x 是较小值）
3. 用 long 避免溢出（nums[i] 最大 10^9，合并后可能超 int 范围）
