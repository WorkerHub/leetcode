## 题目描述

从位置 -1 出发向右逐株浇水，水不够时需回到 -1 重新装满，返回总步数。

## 解题思路

直接模拟：每株植物，若水不足则加上回到 -1 再来的额外步数（`2*i`），无论如何前进 1 步。

## Java 代码实现

### 方法一：模拟（推荐）

```java
class Solution {
    public int wateringPlants(int[] plants, int capacity) {
        int steps = 0, water = capacity;
        for (int i = 0; i < plants.length; i++) {
            if (water < plants[i]) {
                steps += 2 * i; // 回到 -1 再走到 i（减去正向那1步，加上2*i步）
                water = capacity;
            }
            steps++; // 向前走 1 步
            water -= plants[i];
        }
        return steps;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 需要返回时额外步数为 `2*i`（从位置 i-1 回到 -1 再到 i，共 2*i 步，正向 1 步已另计）
2. 初始在 -1 位置，水壶满
