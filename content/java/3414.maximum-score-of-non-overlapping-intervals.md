## 题目描述

给定区间数组 `intervals[i] = [left, right, weight]`，选 4 个不重叠区间（两区间有公共点即重叠），最大化权重和，返回最大得分。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maximumScore(int[][] intervals) {
        // 按右端点排序
        Arrays.sort(intervals, (a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0]);
        int n = intervals.length;
        int[] rights = new int[n];
        for (int i = 0; i < n; i++) rights[i] = intervals[i][1];

        // dp 滚动：prevMax[i] 为前 i 个区间选 k-1 个的前缀最大值
        long[] prevMax = new long[n + 1]; // k=0: 选0个，均为0

        for (int k = 1; k <= 4; k++) {
            long[] dp = new long[n + 1];
            Arrays.fill(dp, Long.MIN_VALUE / 2);
            long[] curMax = new long[n + 1];

            for (int i = 1; i <= n; i++) {
                int left = intervals[i - 1][0];
                long weight = intervals[i - 1][2];

                // 不选第 i 个
                dp[i] = dp[i - 1];

                // 选第 i 个：找最后一个 right < left 的位置（严格小于，避免重叠）
                int pos = lowerBound(rights, left, i - 1); // rights[0..i-2] 中第一个 >= left 的位置
                // prevMax[pos] = 前 pos 个区间选 k-1 个的最大值
                if (prevMax[pos] > Long.MIN_VALUE / 2) {
                    dp[i] = Math.max(dp[i], prevMax[pos] + weight);
                }
            }

            // 计算前缀最大值
            curMax[0] = Long.MIN_VALUE / 2;
            for (int i = 1; i <= n; i++) {
                curMax[i] = Math.max(curMax[i - 1], dp[i]);
            }
            prevMax = curMax;
        }

        return Math.max(0, prevMax[n]);
    }

    // 在 rights[0..limit-1] 中找第一个 >= target 的位置
    private int lowerBound(int[] rights, int target, int limit) {
        int lo = 0, hi = limit;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (rights[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(4 * n log n)，4 层 DP，每层 O(n log n)
- 空间复杂度：O(n)，滚动数组

## 关键点总结

1. 排序后用二分查找找"不重叠的前一个区间"（right < left，严格小于）。
2. DP 固定 4 层，用滚动数组和前缀最大值优化。
3. 两区间有公共点即重叠，需严格 right < left 判断不重叠。
