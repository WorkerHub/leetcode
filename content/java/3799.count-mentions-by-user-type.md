## 题目描述

给定用户数 `numberOfUsers` 和事件列表 `events`，每个事件为 `[MESSAGE/OFFLINE, timestamp, data]`，模拟处理后返回每个用户被提及的次数（用户下线 60 单位后重新上线，HERE 消息只通知在线用户）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countMentions(int numberOfUsers, List<List<String>> events) {
        // 按时间戳排序，相同时间 OFFLINE 先处理
        events.sort((a, b) -> {
            int ta = Integer.parseInt(a.get(1)), tb = Integer.parseInt(b.get(1));
            if (ta != tb) return ta - tb;
            return a.get(0).equals("OFFLINE") ? -1 : 1;
        });

        int[] mentions = new int[numberOfUsers];
        int[] offlineUntil = new int[numberOfUsers]; // 用户下线结束时间

        for (List<String> event : events) {
            String etype = event.get(0);
            int ts = Integer.parseInt(event.get(1));
            String data = event.get(2);

            if (etype.equals("OFFLINE")) {
                int uid = Integer.parseInt(data);
                if (uid < numberOfUsers) offlineUntil[uid] = ts + 60;
            } else { // MESSAGE
                if (data.equals("ALL")) {
                    for (int i = 0; i < numberOfUsers; i++) mentions[i]++;
                } else if (data.equals("HERE")) {
                    for (int i = 0; i < numberOfUsers; i++)
                        if (offlineUntil[i] <= ts) mentions[i]++;
                } else {
                    for (String uid_str : data.split(" ")) {
                        int uid = Integer.parseInt(uid_str.substring(2));
                        if (uid < numberOfUsers) mentions[uid]++;
                    }
                }
            }
        }

        return mentions;
    }
}
```

## 复杂度分析

- 时间复杂度：O(E * N)，E 为事件数，N 为用户数
- 空间复杂度：O(N)

## 关键点总结

1. 事件按时间戳排序，相同时间 OFFLINE 先于 MESSAGE 处理
2. 维护每个用户的下线结束时间，HERE 消息只通知在线用户
3. 具体用户 ID 格式为 "id0", "id1" 等，需解析数字部分
