## 题目描述

给你 n×m 网格（含起点 S、终点 D、空地 .、水 *、障碍 X），水每秒向四方扩散，你同一秒可移动到相邻非水非障碍格，到达格子的时间必须严格小于该格子被淹时间，返回到达终点的最少秒数（不可能返回 -1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumSeconds(List<List<String>> land) {
        int n = land.size(), m = land.get(0).size();
        int[] dx = {0, 0, 1, -1}, dy = {1, -1, 0, 0};
        int[][] flood = new int[n][m];
        for (int[] row : flood) Arrays.fill(row, Integer.MAX_VALUE);

        int sr = 0, sc = 0, er = 0, ec = 0;
        Deque<int[]> waterQ = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                String c = land.get(i).get(j);
                switch (c) {
                    case "S": sr = i; sc = j; break;
                    case "D": er = i; ec = j; break;
                    case "*": flood[i][j] = 0; waterQ.offer(new int[]{i, j}); break;
                    case "X": flood[i][j] = -1; break; // 障碍，标记为不可扩散
                }
            }
        }

        // 水的多源 BFS
        while (!waterQ.isEmpty()) {
            int[] cur = waterQ.poll();
            for (int d = 0; d < 4; d++) {
                int nx = cur[0] + dx[d], ny = cur[1] + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < m
                    && flood[nx][ny] == Integer.MAX_VALUE
                    && !land.get(nx).get(ny).equals("X")) {
                    flood[nx][ny] = flood[cur[0]][cur[1]] + 1;
                    waterQ.offer(new int[]{nx, ny});
                }
            }
        }

        // 起点立刻被淹
        if (flood[sr][sc] == 0) return -1;

        // 人的 BFS
        boolean[][] visited = new boolean[n][m];
        visited[sr][sc] = true;
        Deque<int[]> personQ = new ArrayDeque<>();
        personQ.offer(new int[]{sr, sc, 0});

        while (!personQ.isEmpty()) {
            int[] cur = personQ.poll();
            int x = cur[0], y = cur[1], t = cur[2];
            if (x == er && y == ec) return t;
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < m && !visited[nx][ny]) {
                    String c = land.get(nx).get(ny);
                    if (c.equals("X") || c.equals("*")) continue;
                    int nt = t + 1;
                    // 到达时未被水淹（严格小于）
                    if (flood[nx][ny] == Integer.MAX_VALUE || nt < flood[nx][ny]) {
                        visited[nx][ny] = true;
                        personQ.offer(new int[]{nx, ny, nt});
                    }
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × m)，两次 BFS 各 O(n × m)
- 空间复杂度：O(n × m)

## 关键点总结

1. 先多源 BFS 计算每个格子被水淹的时间
2. 人到达格子的时间必须严格小于该格子被淹时间
3. 障碍 X 既不能被人走，也不会被水淹
