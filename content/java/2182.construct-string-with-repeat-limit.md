## 题目描述

用字符串s中的字符构造字典序最大的字符串，要求任何字母连续出现不超过repeatLimit次。

## 解题思路

贪心：从字典序最大字母开始，每次最多放repeatLimit个；若仍有剩余则用次大字母打断一次，再继续。

## Java 代码实现

```java
class Solution {
    public String repeatLimitedString(String s, int repeatLimit) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }
        
        StringBuilder sb = new StringBuilder();
        int i = 25; // 从最大字母开始
        
        while (i >= 0) {
            if (freq[i] == 0) { i--; continue; }
            
            // 最多放repeatLimit个
            int use = Math.min(freq[i], repeatLimit);
            for (int k = 0; k < use; k++) sb.append((char)('a' + i));
            freq[i] -= use;
            
            if (freq[i] > 0) {
                // 找次大字母打断
                int j = i - 1;
                while (j >= 0 && freq[j] == 0) j--;
                if (j < 0) break;
                sb.append((char)('a' + j));
                freq[j]--;
                // i不变，继续放最大字母
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心选最大字母**：字典序最大优先
2. **连续限制后用次大打断**：只插入一个次大字母
3. **打断后继续**：i不变，回到最大字母继续放
