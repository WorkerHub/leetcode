## 题目描述

给你两个只包含 0 和 1 的数组 `nums1` 和 `nums2`，长度均为 `n`。每次操作可以交换同一下标 `i` 处的两个值，目标是让两个数组都严格递增。返回最少操作次数，无法实现返回 `-1`。

## 解题思路

DP：`dp[s]` 表示当前位置状态为 `s`（0=不换，1=换）时的最少操作次数。逐位转移，检查严格递增约束。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums1, int[] nums2) {
        int n = nums1.length;
        final int INF = Integer.MAX_VALUE / 2;
        // dp[s] = 当前位置状态为 s 的最少操作次数（s=0: 不换，s=1: 换）
        int[] dp = {0, 1};

        for (int i = 1; i < n; i++) {
            int[] newDp = {INF, INF};
            for (int s = 0; s < 2; s++) {
                // 当前位置的值
                int aCur = s == 0 ? nums1[i] : nums2[i];
                int bCur = s == 0 ? nums2[i] : nums1[i];
                for (int sPrev = 0; sPrev < 2; sPrev++) {
                    if (dp[sPrev] == INF) continue;
                    int aPrev = sPrev == 0 ? nums1[i - 1] : nums2[i - 1];
                    int bPrev = sPrev == 0 ? nums2[i - 1] : nums1[i - 1];
                    // 检查严格递增
                    if (aCur > aPrev && bCur > bPrev) {
                        newDp[s] = Math.min(newDp[s], dp[sPrev] + s);
                    }
                }
            }
            dp = newDp;
        }

        int ans = Math.min(dp[0], dp[1]);
        return ans == INF ? -1 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每位枚举 4 种状态组合
- 空间复杂度：O(1)

## 关键点总结

1. 每个位置只有两个状态（换/不换），DP 空间为 O(1)
2. 转移时检查严格递增约束（`>`）
3. 对于 0/1 数组，严格递增意味着相邻位置值不同
