## 题目描述

返回所有 x^i + y^j <= bound 的强整数列表（去重）。

**示例：**
```
输入：x = 2, y = 3, bound = 10
输出：[2,3,4,5,7,9,10]
```

## 解题思路

枚举所有 x^i 和 y^j 的组合，用 HashSet 去重。注意 x=1 或 y=1 时幂次不增长需特殊处理。

## Java 代码实现

```java
class Solution {
    public List<Integer> powerfulIntegers(int x, int y, int bound) {
        Set<Integer> result = new HashSet<>();

        int xi = 1;
        for (int i = 0; xi < bound; i++) {
            int yj = 1;
            for (int j = 0; xi + yj <= bound; j++) {
                result.add(xi + yj);
                if (y == 1) break;
                yj *= y;
            }
            if (x == 1) break;
            xi *= x;
        }

        return new ArrayList<>(result);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²(bound))
- **空间复杂度**：O(log²(bound))

## 关键点总结

1. **幂次增长快**：循环次数很少
2. **x=1/y=1 特殊处理**：避免无限循环
3. **HashSet 去重**：自动去除重复结果
