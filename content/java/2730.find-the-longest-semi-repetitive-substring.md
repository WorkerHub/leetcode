## 题目描述

给你字符串 `s`，**半重复**字符串是指最多有一对相邻字符相等，返回最长半重复子字符串的长度。

## Java 代码实现

```java
class Solution {
    public int longestSemiRepetitiveSubstring(String s) {
        int n = s.length();
        int ans = 1, pairs = 0, left = 0;
        for (int right = 1; right < n; right++) {
            // 右指针扩展时检查是否新增相邻相等对
            if (s.charAt(right) == s.charAt(right - 1)) pairs++;
            // 超过 1 对时，移动左指针缩小窗口
            while (pairs > 1) {
                if (s.charAt(left) == s.charAt(left + 1)) pairs--;
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 半重复 = 最多一对相邻相等字符
2. 滑动窗口保持窗口内 `pairs <= 1`
3. 移动左指针时，检查 `s[left] == s[left+1]` 才使 `pairs -= 1`
