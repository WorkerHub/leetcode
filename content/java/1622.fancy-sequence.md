## 题目描述

实现 `Fancy` 类，支持：
- `append(val)`：将整数 `val` 加入序列末尾
- `addAll(inc)`：将序列中所有元素加上 `inc`
- `multAll(m)`：将序列中所有元素乘以 `m`
- `getIndex(idx)`：获取下标 `idx` 的元素，越界返回 `-1`，答案对 `10^9 + 7` 取余。

## 解题思路

**懒惰求值：** 维护全局的累积乘法因子 `multLazy` 和加法因子 `addLazy`。

`append` 时将 `val` 通过逆变换转换为"原始值"存入，`getIndex` 时应用当前变换即可得到真实值。

每次 `multAll(m)` 时，加法 lazy 也要乘以 m（因为变换为 `f(x) = mult*x + add`，全局乘 m 后变为 `m*mult*x + m*add`）。

## Java 代码实现

```java
class Fancy {
    private static final long MOD = 1_000_000_007L;
    private List<Long> vals;  // 存储原始值（逆变换后）
    private long addLazy;     // 累积加法因子
    private long multLazy;    // 累积乘法因子

    public Fancy() {
        vals = new ArrayList<>();
        addLazy = 0;
        multLazy = 1;
    }

    public void append(int val) {
        // 存储时反向计算原始值：raw = (val - addLazy) * inv(multLazy)
        long invMult = modPow(multLazy, MOD - 2, MOD);
        long raw = (val - addLazy % MOD + MOD) % MOD * invMult % MOD;
        vals.add(raw);
    }

    public void addAll(int inc) {
        addLazy = (addLazy + inc) % MOD;
    }

    public void multAll(int m) {
        multLazy = multLazy * m % MOD;
        addLazy = addLazy * m % MOD;
    }

    public int getIndex(int idx) {
        if (idx >= vals.size()) return -1;
        // 真实值 = raw * multLazy + addLazy
        return (int) ((vals.get(idx) * multLazy + addLazy) % MOD);
    }

    // 快速幂：计算 base^exp mod mod
    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：append O(log MOD)，addAll O(1)，multAll O(1)，getIndex O(1)
- **空间复杂度**：O(n)，n 为元素个数

## 关键点总结

1. 用懒惰求值维护全局的乘法因子和加法因子
2. `append` 时存储"原始值"（逆变换），`getIndex` 时直接应用当前变换
3. 模逆元使用费马小定理：`pow(a, MOD-2, MOD)`
4. 每次 `multAll(m)` 时，加法 lazy 也要乘以 m
