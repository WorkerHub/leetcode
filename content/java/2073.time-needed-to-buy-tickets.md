## 题目描述

n 人排队买票，每轮每人买 1 张，问第 k 个人买完所需总秒数。

## 解题思路

数学方法：k 之前的人最多买 `tickets[k]` 张，k 之后的人最多买 `tickets[k]-1` 张，累加 `min(tickets[i], tickets[k] - (i>k ? 1 : 0))`。

## Java 代码实现

### 方法一：数学公式（推荐）

```java
class Solution {
    public int timeRequiredToBuy(int[] tickets, int k) {
        int target = tickets[k], total = 0;
        for (int i = 0; i < tickets.length; i++) {
            total += Math.min(tickets[i], i <= k ? target : target - 1);
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. k 之前（含 k）的人：每人最多买 tickets[k] 张
2. k 之后的人：每人最多买 tickets[k]-1 张（k 在最后一轮提前离队）
