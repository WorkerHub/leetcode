## 题目描述

有向图中节点 0~n-1，边分红蓝两色。返回数组 answer，answer[x] 为从节点 0 到 x 的红蓝交替最短路径长度，不存在则为 -1。

**示例：**
```
输入：n = 3, red_edges = [[0,1],[1,2]], blue_edges = []
输出：[0,1,-1]
```

## 解题思路

BFS 扩展状态为 `(节点, 最后边颜色)`。从节点 0 出发有两个初始状态（先走红/先走蓝），每步只能走与上一步不同颜色的边。visited 用二维数组 `boolean[n][2]` 标记。

## Java 代码实现

```java
class Solution {
    public int[] shortestAlternatingPaths(int n, int[][] redEdges, int[][] blueEdges) {
        // 构建邻接表：graph[color][node] = 邻居列表
        List<Integer>[][] graph = new List[2][n];
        for (int c = 0; c < 2; c++)
            for (int i = 0; i < n; i++)
                graph[c][i] = new ArrayList<>();

        for (int[] e : redEdges) graph[0][e[0]].add(e[1]);
        for (int[] e : blueEdges) graph[1][e[0]].add(e[1]);

        int[] answer = new int[n];
        Arrays.fill(answer, -1);
        answer[0] = 0;

        // BFS：{节点, 颜色, 距离}
        // 颜色 0=红, 1=蓝
        Queue<int[]> queue = new LinkedList<>();
        boolean[][] visited = new boolean[n][2];

        // 两个初始状态：从节点 0 开始可先走红或蓝
        queue.offer(new int[]{0, 0, 0});
        queue.offer(new int[]{0, 1, 0});
        visited[0][0] = true;
        visited[0][1] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int node = cur[0], color = cur[1], dist = cur[2];

            // 下一步颜色交替
            int nextColor = 1 - color;
            for (int next : graph[nextColor][node]) {
                if (!visited[next][nextColor]) {
                    visited[next][nextColor] = true;
                    queue.offer(new int[]{next, nextColor, dist + 1});
                    if (answer[next] == -1) {
                        answer[next] = dist + 1;
                    } else {
                        answer[next] = Math.min(answer[next], dist + 1);
                    }
                }
            }
        }

        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + E)，E 为边总数
- **空间复杂度**：O(n + E)

## 关键点总结

1. **状态扩展**：`(节点, 颜色)` 二元组，而非仅节点
2. **两个初始状态**：从节点 0 可先走红或先走蓝
3. **颜色切换**：`1 - color` 实现 0↔1 交替
4. **BFS 保证最短**：第一次到达即为最短距离
5. **取最小值**：同一节点可能通过不同颜色路径到达
