## 题目描述

给定线段数组 `segments[i] = [start, end]`，返回可选出的最大不重叠线段数（两线段不重叠指一条终点严格小于另一条起点）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxNonOverlapping(int[][] segments) {
        // 按右端点升序排序，贪心选结束最早的线段
        Arrays.sort(segments, (a, b) -> a[1] - b[1]);
        int count = 0, lastEnd = Integer.MIN_VALUE;
        for (int[] seg : segments) {
            if (seg[0] > lastEnd) { // 严格不重叠
                count++;
                lastEnd = seg[1];
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 活动选择问题：按结束时间排序，优先选结束最早的
2. 不重叠条件为 `start > lastEnd`（严格大于）
3. 贪心正确性：选结束最早的线段为后续留下最大空间
