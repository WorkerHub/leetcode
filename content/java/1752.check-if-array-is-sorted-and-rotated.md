## 题目描述

给你数组 `nums`，判断它是否由某个非降序数组旋转得到（允许重复元素）。

## 解题思路

统计循环比较中"下降点"（`nums[i] > nums[(i+1)%n]`）的数量，至多 1 个则满足条件。

## Java 代码实现

```java
class Solution {
    public boolean check(int[] nums) {
        int n = nums.length;
        int drops = 0; // 下降点数量

        for (int i = 0; i < n; i++) {
            if (nums[i] > nums[(i + 1) % n]) {
                drops++;
            }
        }

        return drops <= 1; // 最多一个下降点则是旋转排序数组
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 旋转排序数组中循环比较最多有一个下降点
2. `(i+1) % n` 实现循环比较
