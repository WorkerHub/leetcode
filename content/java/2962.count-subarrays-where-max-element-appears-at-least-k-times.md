## 题目描述

给你整数数组 `nums` 和正整数 `k`，返回最大元素至少出现 `k` 次的子数组数目。

## 解题思路

滑动窗口：维护窗口内最大元素出现次数 cnt。当 cnt >= k 时收缩左端直到 cnt < k，此时左端点 0 到 left-1 均可作为有效左端，累加 left。

## Java 代码实现

```java
class Solution {
    public long countSubarrays(int[] nums, int k) {
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        long ans = 0;
        int cnt = 0, left = 0;
        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == maxVal) cnt++;
            // 收缩左端，直到最大元素出现次数小于 k
            while (cnt >= k) {
                if (nums[left] == maxVal) cnt--;
                left++;
            }
            // [0, left-1] 都是合法的左端点
            ans += left;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只关注全局最大元素的出现次数
2. 收缩到 cnt < k 后，左端点 0 到 left-1 均满足条件，贡献 left 个子数组
3. 返回值需用 long 防止溢出
