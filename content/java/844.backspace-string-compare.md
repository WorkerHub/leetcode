## 题目描述

给定两个字符串 s 和 t，其中 '#' 代表退格。判断经过退格处理后两字符串是否相等。

**示例：**
```
输入：s = "ab#c", t = "ad#c"
输出：true（都变成 "ac"）
```

## 解题思路

栈模拟：遇到普通字符压栈，遇到 '#' 弹栈。比较两个栈的最终内容。

## Java 代码实现

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        return build(s).equals(build(t));
    }

    private String build(String str) {
        StringBuilder sb = new StringBuilder();
        for (char c : str.toCharArray()) {
            if (c != '#') {
                sb.append(c);
            } else if (sb.length() > 0) {
                sb.deleteCharAt(sb.length() - 1);
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. **栈模拟**：StringBuilder 当栈用
2. **退格处理**：空时退格无效
3. **比较结果**：最终字符串相等即可
