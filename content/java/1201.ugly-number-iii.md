## 题目描述

找出第 n 个丑数（能被 a 或 b 或 c 整除的正整数）。

**示例：**
```
输入：n = 3, a = 2, b = 3, c = 5
输出：4
```

## 解题思路

二分查找 + 容斥原理。对于给定值 x，用容斥原理计算 [1,x] 中有多少个丑数：`x/a + x/b + x/c - x/lcm(a,b) - x/lcm(a,c) - x/lcm(b,c) + x/lcm(a,b,c)`。

## Java 代码实现

```java
class Solution {
    public int nthUglyNumber(int n, int a, int b, int c) {
        long lcmAB = lcm(a, b);
        long lcmAC = lcm(a, c);
        long lcmBC = lcm(b, c);
        long lcmABC = lcm(lcmAB, c);
        
        long left = 1, right = 2_000_000_000L;
        while (left < right) {
            long mid = left + (right - left) / 2;
            long count = mid / a + mid / b + mid / c
                       - mid / lcmAB - mid / lcmAC - mid / lcmBC
                       + mid / lcmABC;
            if (count < n) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return (int) left;
    }
    
    private long gcd(long x, long y) {
        while (y != 0) {
            long t = y;
            y = x % y;
            x = t;
        }
        return x;
    }
    
    private long lcm(long x, long y) {
        return x / gcd(x, y) * y;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(2×10⁹))，约 31 次二分
- **空间复杂度**：O(1)

## 关键点总结

1. **二分答案**：丑数个数关于 x 单调递增，可以二分
2. **容斥原理**：加单集 - 减交集 + 加三交集
3. **LCM 计算**：`lcm(a,b) = a / gcd(a,b) * b`，先除避免溢出
4. **用 long**：中间计算可能超过 int 范围
