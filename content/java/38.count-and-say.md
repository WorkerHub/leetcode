## 题目描述

「外观数列」是一个整数序列，从数字 1 开始，序列中的每一项都是对前一项的描述。

前五项如下：
```
1.     1
2.     11
3.     21
4.     1211
5.     111221
```

`1` 被读作 `"one 1"` (`"一个一"`) , 即 `11`。
`11` 被读作 `"two 1s"` (`"两个一"`），即 `21`。
`21` 被读作 `"one 2"`, `"one 1"` （`"一个二"`, `"一个一"`), 即 `1211`。

给定一个正整数 `n`，输出外观数列的第 `n` 项。

**示例 1：**
```
输入：n = 1
输出："1"
```

**示例 2：**
```
输入：n = 4
输出："1211"
```

**提示：**
- `1 <= n <= 30`

## 解题思路

核心思想：模拟生成过程

关键步骤：
1. 从 "1" 开始
2. 统计连续相同数字的个数
3. 生成 "个数 + 数字" 的描述
4. 重复 n-1 次

## Java 代码实现

```java
class Solution {
    public String countAndSay(int n) {
        String result = "1";
        
        for (int i = 1; i < n; i++) {
            result = getNext(result);
        }
        
        return result;
    }
    
    private String getNext(String s) {
        StringBuilder sb = new StringBuilder();
        int i = 0;
        
        while (i < s.length()) {
            char digit = s.charAt(i);
            int count = 1;
            
            // 统计连续相同数字
            while (i + count < s.length() && s.charAt(i + count) == digit) {
                count++;
            }
            
            // 添加 "个数 + 数字"
            sb.append(count).append(digit);
            i += count;
        }
        
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × m)，m 为字符串长度
- 空间复杂度：O(m)

## 关键点总结

1. **统计连续**：使用双指针统计连续相同数字
2. **拼接字符串**：个数 + 数字
3. **迭代生成**：重复 n-1 次

## 易错点

1. **初始值**：从 "1" 开始
2. **边界**：统计时注意数组越界
3. **Java 字符串拼接**：使用 `StringBuilder` 而非 `+` 拼接，性能更好
