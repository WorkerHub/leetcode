## 题目描述

给定整数数组 `nums` 和正整数 `k`，每次操作选最大元素加入得分，再将其替换为 `ceil(val/3)`，执行恰好 `k` 次，返回最大总得分。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxKelements(int[] nums, int k) {
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        for (int x : nums) maxHeap.offer(x);

        long score = 0;
        while (k-- > 0) {
            int val = maxHeap.poll();
            score += val;
            maxHeap.offer((val + 2) / 3); // ceil(val/3)
        }
        return score;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + k log n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：每次选当前最大值，最大堆维护
2. `ceil(val/3) = (val + 2) / 3`，整数运算避免浮点误差
3. 得分使用 long 防止溢出
