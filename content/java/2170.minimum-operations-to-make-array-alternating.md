## 题目描述

使数组交替（偶数下标相同值a，奇数下标相同值b，a!=b），求最少修改次数。

## 解题思路

分别统计偶数/奇数下标的频率前两名。若最高频值不同则各选最高频；若相同则取两种方案中更优的（偶高+奇次 或 偶次+奇高）。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[] nums) {
        int n = nums.length;
        // 统计偶数下标和奇数下标频率
        Map<Integer, Integer> evenCnt = new HashMap<>();
        Map<Integer, Integer> oddCnt = new HashMap<>();
        
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) evenCnt.merge(nums[i], 1, Integer::sum);
            else oddCnt.merge(nums[i], 1, Integer::sum);
        }
        
        // 获取前两高频
        int[][] evenTop = getTop2(evenCnt);
        int[][] oddTop = getTop2(oddCnt);
        
        int keep;
        if (evenTop[0][0] != oddTop[0][0]) {
            keep = evenTop[0][1] + oddTop[0][1];
        } else {
            keep = Math.max(evenTop[0][1] + oddTop[1][1], 
                           evenTop[1][1] + oddTop[0][1]);
        }
        return n - keep;
    }
    
    // 返回频率最高的两个[值, 频率]
    private int[][] getTop2(Map<Integer, Integer> cnt) {
        int[][] top = new int[][]{{-1, 0}, {-1, 0}};
        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {
            int val = e.getKey(), freq = e.getValue();
            if (freq > top[0][1]) {
                top[1] = top[0].clone();
                top[0] = new int[]{val, freq};
            } else if (freq > top[1][1]) {
                top[1] = new int[]{val, freq};
            }
        }
        return top;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分奇偶统计频率**：各取前两高频值
2. **贪心选择**：最高频不同直接选；相同则二选一退而求其次
3. **答案=n-keep**：保留最多等于修改最少
