## 题目描述

给定整数数组 nums 和查询数组 queries，每次查询将 nums[index] 加上 val，返回每次查询后数组中偶数的和。

**示例：**
```
输入：nums = [1,2,3,4], queries = [[1,0],[-3,1],[-4,0],[2,3]]
输出：[8,6,2,4]
```

## 解题思路

维护偶数和：每次查询前若原值为偶数则减去，修改后若新值为偶数则加上。

## Java 代码实现

```java
class Solution {
    public int[] sumEvenAfterQueries(int[] nums, int[][] queries) {
        int evenSum = 0;
        for (int num : nums) {
            if (num % 2 == 0) evenSum += num;
        }

        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int val = queries[i][0], idx = queries[i][1];
            int oldVal = nums[idx];
            int newVal = oldVal + val;

            // 旧值为偶数则从和中减去
            if (oldVal % 2 == 0) evenSum -= oldVal;
            // 新值为偶数则加入和
            if (newVal % 2 == 0) evenSum += newVal;

            nums[idx] = newVal;
            result[i] = evenSum;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 为数组长度，m 为查询数
- **空间复杂度**：O(1)

## 关键点总结

1. **增量更新**：不用每次重新计算偶数和
2. **奇偶判断**：修改前后分别检查奇偶性
3. **O(1) 维护**：每次查询只做常数操作
