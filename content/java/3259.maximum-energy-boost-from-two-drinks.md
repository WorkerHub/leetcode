## 题目描述

给你两个长度为 `n` 的整数数组 `energyDrinkA` 和 `energyDrinkB`。每小时可喝一种饮料，切换饮料需要等一小时（该小时不喝）。返回 n 小时内能量的最大提升。

## 解题思路

DP：`curA` = 当前时刻喝 A 的最大能量，`curB` = 喝 B 的最大能量。转移时：继续同种饮料累加，或从两步前切换过来（跳过一小时）。

## Java 代码实现

```java
class Solution {
    public long maxEnergyBoost(int[] energyDrinkA, int[] energyDrinkB) {
        int n = energyDrinkA.length;
        // prevA/prevB: 两步前的最大能量；curA/curB: 当前步的最大能量
        long prevA = 0, prevB = 0;
        long curA = energyDrinkA[0];
        long curB = energyDrinkB[0];

        for (int i = 1; i < n; i++) {
            long newA = Math.max(curA + energyDrinkA[i], prevB + energyDrinkA[i]);
            long newB = Math.max(curB + energyDrinkB[i], prevA + energyDrinkB[i]);
            prevA = curA;
            prevB = curB;
            curA = newA;
            curB = newB;
        }
        return Math.max(curA, curB);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 切换饮料需要间隔一小时，所以从 i-2 时刻切换
2. DP 转移：继续同种饮料或两步前切换过来
3. 使用 long 防止整数溢出
