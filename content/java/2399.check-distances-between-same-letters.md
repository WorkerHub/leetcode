## 题目描述

给你字符串 `s`（每个字母恰好出现两次）和长度为 26 的数组 `distance`，若每个字母两次出现的下标差等于 `distance[c-'a']`，返回 true，否则返回 false。

## 解题思路

数组记录每个字母首次出现的位置，第二次遇到时计算差值并与 `distance` 比较。

## Java 代码实现

```java
class Solution {
    public boolean checkDistances(String s, int[] distance) {
        int[] first = new int[26]; // 记录每个字母首次出现下标，0 表示未出现
        Arrays.fill(first, -1);
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (first[idx] == -1) {
                first[idx] = i; // 记录首次位置
            } else {
                if (i - first[idx] != distance[idx]) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（固定 26 个字母）

## 关键点总结

1. 每个字母恰好出现两次，第一次记录位置，第二次验证差值。
2. 字母 c 对应 `distance` 下标为 `c - 'a'`。
3. 两次下标差直接用 `i - first[idx]`（第二次下标更大，结果非负）。
