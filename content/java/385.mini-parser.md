## 题目描述

给定一个字符串 s 表示一个整数嵌套列表，实现一个解析它的语法分析器并返回解析的结果 `NestedInteger`。

列表中的每个元素只可能是整数或整数嵌套列表

**示例 1:**

```
输入：s = "324"
输出：324
解释：你应该返回一个 NestedInteger 对象，其中只包含整数值 324。
```

**示例 2:**

```
输入：s = "[123,[456,[789]]]"
输出：[123,[456,[789]]]
解释：返回一个 NestedInteger 对象包含一个有两个元素的嵌套列表：
1. 一个 integer 包含值 123
2. 一个包含两个元素的嵌套列表：
    i.  一个 integer 包含值 456
    ii. 一个包含一个元素的嵌套列表
         a. 一个 integer 包含值 789
```

**提示:**

- `1 <= s.length <= 5 * 10^4`
- `s` 由数字、方括号 `"[]"`、负号 `'-'`、逗号 `','` 组成
- `s` 是有效的 NestedInteger 表示
- 输入中的所有值的范围是 `[-10^6, 10^6]`

## 解题思路

本题是经典的**嵌套结构解析**问题，可以使用栈或递归来解决。

### 核心思想：栈模拟嵌套结构

**算法流程：**

1. **使用栈保存嵌套层级**：
   - 遇到 `[` 时，创建新的 NestedInteger 并压栈
   - 遇到 `]` 时，弹出栈顶，添加到新的栈顶（上一层）
   - 遇到数字时，解析完整数字并添加到当前层

2. **处理数字**：
   - 可能是多位数
   - 可能是负数
   - 需要在遇到 `,` 或 `]` 时完成解析

3. **边界情况**：
   - 单个整数（没有括号）
   - 空列表 `[]`
   - 负数

### 思路对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 栈 | 直观，易理解 | 需要额外空间 |
| 递归 | 代码简洁 | 理解稍难 |

## Java 代码实现

### 方法一：栈模拟（推荐）⭐

```java
import java.util.*;

/**
 * // This is the interface that allows for creating nested lists.
 * // You should not implement it, or speculate about its implementation
 * public interface NestedInteger {
 *     // Constructor initializes an empty nested list.
 *     public NestedInteger();
 *
 *     // Constructor initializes a single integer.
 *     public NestedInteger(int value);
 *
 *     // @return true if this NestedInteger holds a single integer, rather than a nested list.
 *     public boolean isInteger();
 *
 *     // @return the single integer that this NestedInteger holds, if it holds a single integer
 *     public Integer getInteger();
 *
 *     // Set this NestedInteger to hold a single integer.
 *     public void setInteger(int value);
 *
 *     // Set this NestedInteger to hold a nested list and adds a nested integer elem to it.
 *     public void add(NestedInteger ni);
 *
 *     // @return the nested list that this NestedInteger holds, if it holds a nested list
 *     public List<NestedInteger> getList();
 * }
 */
public class Solution {
    public NestedInteger deserialize(String s) {
        // 特殊情况：单个整数（不以 '[' 开头）
        if (s.charAt(0) != '[') {
            return new NestedInteger(Integer.parseInt(s));
        }

        Deque<NestedInteger> stack = new ArrayDeque<>();
        StringBuilder numStr = new StringBuilder(); // 累积当前数字字符

        for (char c : s.toCharArray()) {
            if (c == '[') {
                // 开始新的嵌套层级
                stack.push(new NestedInteger());

            } else if (c == ']') {
                // 完成当前数字（如果有）
                if (numStr.length() > 0) {
                    stack.peek().add(new NestedInteger(Integer.parseInt(numStr.toString())));
                    numStr.setLength(0);
                }
                // 弹出当前层，添加到上一层
                if (stack.size() > 1) {
                    NestedInteger top = stack.pop();
                    stack.peek().add(top);
                }

            } else if (c == ',') {
                // 完成当前数字（如果有）
                if (numStr.length() > 0) {
                    stack.peek().add(new NestedInteger(Integer.parseInt(numStr.toString())));
                    numStr.setLength(0);
                }

            } else {
                // 数字字符或负号，累积
                numStr.append(c);
            }
        }

        return stack.peek();
    }
}
```

### 方法二：更清晰的栈实现

```java
import java.util.*;

public class Solution {
    public NestedInteger deserialize(String s) {
        // 特殊情况
        if (s.isEmpty()) {
            return new NestedInteger();
        }
        if (s.charAt(0) != '[') {
            return new NestedInteger(Integer.parseInt(s));
        }

        Deque<NestedInteger> stack = new ArrayDeque<>();
        StringBuilder num = new StringBuilder();

        for (char c : s.toCharArray()) {
            if (c == '[') {
                stack.push(new NestedInteger());

            } else if (c == ']' || c == ',') {
                // 处理累积的数字
                if (num.length() > 0) {
                    stack.peek().add(new NestedInteger(Integer.parseInt(num.toString())));
                    num.setLength(0);
                }
                // 如果是右括号且不是最后一个，需要合并
                if (c == ']' && stack.size() > 1) {
                    NestedInteger top = stack.pop();
                    stack.peek().add(top);
                }

            } else if (c == '-' || Character.isDigit(c)) {
                // 数字或负号
                num.append(c);
            }
        }

        return stack.peek();
    }
}
```

### 方法三：递归解析

```java
public class Solution {
    private String s;
    private int index; // 当前解析位置

    public NestedInteger deserialize(String s) {
        this.s = s;
        this.index = 0;
        return parseNestedInteger();
    }

    /** 递归解析一个 NestedInteger */
    private NestedInteger parseNestedInteger() {
        if (s.charAt(index) == '[') {
            // 解析列表
            index++; // 跳过 '['
            NestedInteger result = new NestedInteger();

            while (s.charAt(index) != ']') {
                if (s.charAt(index) == ',') {
                    index++; // 跳过 ','
                }
                result.add(parseNestedInteger());
            }

            index++; // 跳过 ']'
            return result;
        } else {
            // 解析整数
            StringBuilder numStr = new StringBuilder();
            while (index < s.length() && (s.charAt(index) == '-' || Character.isDigit(s.charAt(index)))) {
                numStr.append(s.charAt(index));
                index++;
            }
            return new NestedInteger(Integer.parseInt(numStr.toString()));
        }
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历字符串的每个字符一次
- 每个字符最多被处理一次

**空间复杂度：** O(n)
- 栈的深度取决于嵌套层数，最坏情况 O(n)
- 递归调用栈也是 O(n)

## 关键点总结

1. **栈的使用**：用栈保存不同嵌套层级的 NestedInteger
2. **数字累积**：遇到数字字符时需要累积完整的数字（多位数、负数）
3. **边界处理**：单个整数、空列表、负数等特殊情况
4. **弹栈时机**：遇到 `]` 时完成当前层，弹出并添加到上一层
5. **逗号的作用**：分隔符，用于完成当前数字的解析

## 易错点

1. **忘记处理负数**：`-123` 需要正确解析为 -123
2. **多位数问题**：`123` 不是三个数字，需要累积
3. **空列表**：`[]` 是合法的嵌套列表
4. **单个整数**：`"123"` 没有括号，直接返回 NestedInteger
5. **逗号处理**：遇到逗号时要完成之前数字的解析
6. **最后的数字**：如 `[1,2,3]` 中的 `3` 后面是 `]` 而不是 `,`
7. **Java Deque 作栈**：使用 `ArrayDeque`，`push/pop/peek` 操作栈顶

## 图解示例

```
输入: "[123,[456,[789]]]"

解析过程:

1. 遇到 '[': stack = [NestedInteger()]
2. 遇到 '123': 累积数字
3. 遇到 ',': 完成数字 123，stack[-1].add(123)
4. 遇到 '[': stack = [NestedInteger(), NestedInteger()]
5. 遇到 '456': 累积数字
6. 遇到 ',': 完成数字 456，stack[-1].add(456)
7. 遇到 '[': stack = [外层, 中层, NestedInteger()]
8. 遇到 '789': 累积数字
9. 遇到 ']': 完成数字 789，弹出内层 [789]，添加到中层
              stack = [外层, 中层(含 456 和 [789])]
10. 遇到 ']': 弹出中层，添加到外层
              stack = [外层(含 123 和 [456,[789]])]
11. 遇到 ']': 完成，返回 stack.peek()

结果: [123,[456,[789]]]
```
