## 题目描述

设计内存分配器：`allocate(size, mID)` 找最左侧 `size` 个连续空闲单元分配给 `mID`，返回起始下标；`free(mID)` 释放所有 `mID` 单元并返回释放数量。

## 解题思路

用整数数组模拟内存，0 表示空闲，非零表示被对应 mID 占用。分配时从左扫描找连续空闲段，释放时遍历清零。

## Java 代码实现

```java
class Allocator {
    private int[] memory;
    private int n;

    public Allocator(int n) {
        this.n = n;
        this.memory = new int[n];
    }

    public int allocate(int size, int mID) {
        int count = 0, start = -1;
        for (int i = 0; i < n; i++) {
            if (memory[i] == 0) {
                if (count == 0) start = i;
                count++;
                if (count == size) {
                    // 找到连续空闲块，标记并返回起始下标
                    for (int j = start; j < start + size; j++) memory[j] = mID;
                    return start;
                }
            } else {
                count = 0; // 遇到占用单元，重置计数
            }
        }
        return -1;
    }

    public int free(int mID) {
        int freed = 0;
        for (int i = 0; i < n; i++) {
            if (memory[i] == mID) {
                memory[i] = 0;
                freed++;
            }
        }
        return freed;
    }
}
```

## 复杂度分析

- **时间复杂度**：allocate O(n)，free O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 数据规模小（n, 操作次数均 <= 1000），暴力模拟完全可行
2. 分配时找最左侧连续空闲块，遇占用单元时重置计数
3. 释放时同一 mID 可能分布在多处，需遍历全部清零
