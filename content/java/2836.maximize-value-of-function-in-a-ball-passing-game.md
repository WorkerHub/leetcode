## 题目描述

n个玩家传球k轮(k可达10^10)，从某玩家出发，求传球路径上所有玩家编号之和的最大值。

## 解题思路

二进制提升：jump[j][i]为从i出发走2^j步到达的位置，sum[j][i]为路径上编号之和。将k按二进制拆解。

## Java 代码实现

```java
class Solution {
    public long getMaxFunctionValue(List<Integer> receiver, long k) {
        int n = receiver.size();
        int LOG = Long.SIZE - Long.numberOfLeadingZeros(k);

        // jump[j][i] = 从i出发走2^j步到达的位置
        int[][] jump = new int[LOG + 1][n];
        // sum[j][i] = 从i出发走2^j步的路径编号之和（不含i）
        long[][] sum = new long[LOG + 1][n];

        for (int i = 0; i < n; i++) {
            jump[0][i] = receiver.get(i);
            sum[0][i] = receiver.get(i);
        }

        for (int j = 1; j <= LOG; j++) {
            for (int i = 0; i < n; i++) {
                jump[j][i] = jump[j - 1][jump[j - 1][i]];
                sum[j][i] = sum[j - 1][i] + sum[j - 1][jump[j - 1][i]];
            }
        }

        long ans = 0;
        for (int x = 0; x < n; x++) {
            long total = x;
            int cur = x;
            long remaining = k;
            int j = 0;
            while (remaining > 0) {
                if ((remaining & 1) == 1) {
                    total += sum[j][cur];
                    cur = jump[j][cur];
                }
                remaining >>= 1;
                j++;
            }
            ans = Math.max(ans, total);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * log K)
- **空间复杂度**：O(N * log K)

## 关键点总结

1. **二进制提升**：O(log K)级别跳跃代替逐步模拟
2. **同时维护位置和路径和**：两个提升表
3. **total包含起始玩家x**
