## 题目描述

给你原始树 `original`、结构完全相同的克隆树 `cloned`，以及原树中某节点的引用 `target`。找出克隆树中与 `target` 位置对应的节点并返回引用。树中节点值可能重复。

## 解题思路

同步 DFS 遍历两棵树，两棵树走相同路径。当原树当前节点是 `target` 时，返回克隆树对应节点。由于节点值可能重复，必须用引用相等（Java 的 `==`）来判断是否为 target，而不是值相等。

## Java 代码实现

```java
class Solution {
    public final TreeNode getTargetCopy(final TreeNode original, final TreeNode cloned, final TreeNode target) {
        if (original == null) return null;
        // 找到目标节点（引用相等判断）
        if (original == target) return cloned;
        // 先搜索左子树
        TreeNode left = getTargetCopy(original.left, cloned.left, target);
        if (left != null) return left;
        // 再搜索右子树
        return getTargetCopy(original.right, cloned.right, target);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，最坏情况遍历所有节点。
- 空间复杂度：O(h)，h 为树高，递归栈深度。

## 关键点总结

1. 同步遍历两棵树，始终保持相同路径，原树找到 target 时克隆树位置即为答案。
2. 节点值可能重复，必须用引用相等（`==`）判断是否为 target，不能用值比较。
3. 找到 target 后立即返回，无需继续搜索其他分支。
