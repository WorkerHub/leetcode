## 题目描述

给定一个整数 `n`，返回可表示为两个 `n` 位整数乘积的最大回文整数。因为答案可能非常大，所以返回它对 `1337` 取余。

**示例 1：**
```
输入：n = 2
输出：987
解释：99 x 91 = 9009, 9009 % 1337 = 987
```

**示例 2：**
```
输入：n = 1
输出：9
```

**提示：**
- `1 <= n <= 8`

## 解题思路

**暴力法：** 枚举所有 n 位数的乘积，检查是否为回文。

**优化：** 从大到小构造回文数，检查是否能分解为两个 n 位数。

## Java 代码实现

### 方法一：构造回文（推荐）⭐

```java
class Solution {
    public int largestPalindrome(int n) {
        if (n == 1) return 9;

        // 注意：n 最大为 8，10^8 - 1 = 99999999，需要用 long 防止溢出
        long upper = (long) Math.pow(10, n) - 1;  // 最大 n 位数
        long lower = (long) Math.pow(10, n - 1);  // 最小 n 位数

        // 从大到小构造回文数
        for (long i = upper; i >= lower; i--) {
            // 构造回文数：i 拼接 i 的反转
            String iStr = Long.toString(i);
            String reversed = new StringBuilder(iStr).reverse().toString();
            long palin = Long.parseLong(iStr + reversed);

            // 检查能否分解为两个 n 位数的乘积
            for (long j = upper; j >= lower; j--) {
                if (j * j < palin) break;  // 剪枝：j 已经过小

                if (palin % j == 0) {
                    long other = palin / j;
                    if (other <= upper && other >= lower) {
                        return (int) (palin % 1337);
                    }
                }
            }
        }

        return 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10^n)
- 空间复杂度：O(1)

## 关键点总结

1. **构造回文：** 从大到小
2. **分解检查：** 是否为两个 n 位数
3. **剪枝：** `j * j < palin` 时停止
4. **long 防溢出：** n 位数乘积可能超过 int 范围

## 易错点

1. **特殊情况：** n = 1 时返回 9
2. **整数溢出：** 使用 long 类型处理大数运算
