## 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。

**示例 1：**
```
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3
```

**示例 2：**
```
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1
```

**示例 3：**
```
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3
请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串
```

**提示：**
- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

## 解题思路

核心思想：滑动窗口 + 哈希表

**关键步骤：**
1. 使用双指针维护一个滑动窗口
2. 使用哈希表记录字符最后出现的位置
3. 遇到重复字符时，移动左指针
4. 不断更新最大长度

## Java 代码实现

### 方法一：滑动窗口 + 哈希表（推荐）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 记录字符最后出现的位置
        Map<Character, Integer> charIndex = new HashMap<>();
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果字符已出现且在当前窗口内
            if (charIndex.containsKey(c) && charIndex.get(c) >= left) {
                // 移动左指针到重复字符的下一个位置
                left = charIndex.get(c) + 1;
            }
            
            // 更新字符位置
            charIndex.put(c, right);
            
            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
}
```

### 方法二：使用集合

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> charSet = new HashSet<>();
        int left = 0;
        int maxLen = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果遇到重复字符，移除左边字符直到没有重复
            while (charSet.contains(c)) {
                charSet.remove(s.charAt(left));
                left++;
            }
            
            // 添加当前字符
            charSet.add(c);
            
            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
}
```

### 方法三：优化的滑动窗口（使用数组）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 使用数组代替哈希表（ASCII字符）
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 更新左指针
            left = Math.max(left, lastIndex[c] + 1);
            
            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
            
            // 更新字符最后出现位置
            lastIndex[c] = right;
        }
        
        return maxLen;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)
- 空间复杂度：O(min(m, n))，m 为字符集大小

## 图解示例

以 `s = "abcabcbb"` 为例：

```
初始：left = 0, right = 0
a -> {a}, maxLen = 1
ab -> {a,b}, maxLen = 2
abc -> {a,b,c}, maxLen = 3
abca -> 遇到重复'a'，left移到1, {b,c,a}, maxLen = 3
...
```

## 关键点总结

1. **滑动窗口**：双指针维护无重复字符的窗口
2. **哈希表**：快速查找字符是否在窗口内
3. **左指针移动**：跳到重复字符的下一个位置
4. **实时更新**：每次移动右指针都更新最大长度

## 易错点

1. **左指针更新**：`left = Math.max(left, charIndex.get(c) + 1)`，不能直接赋值
2. **索引含义**：`charIndex` 存的是索引，不是次数
3. **边界情况**：空字符串返回 0
