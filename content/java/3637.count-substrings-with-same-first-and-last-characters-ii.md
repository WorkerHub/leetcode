## 题目描述

给定字符串 `s`，返回首尾字符相同的子字符串数量（长度至少为 1）。

## Java 代码实现

```java
class Solution {
    public long countSubstrings(String s) {
        long[] freq = new long[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        long ans = 0;
        for (long k : freq) {
            // k 次出现：k 个单字符 + C(k,2) 个首尾相同的多字符子串
            ans += k * (k + 1) / 2;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 字符 `c` 出现 k 次时，首尾均为 `c` 的子串数为 `k*(k+1)/2`
2. 该公式包含长度为 1 的子串（k 个）和多字符子串（`k*(k-1)/2` 个）
3. 各字符的贡献互相独立，直接累加
