## 题目描述

给你整数数组 `nums`，每次取首尾两个元素拼接成字符串转为整数并累加，然后删除它们，若剩一个则直接加，返回拼接值。

## 解题思路

双指针从两端向中间移动，每次将首尾元素的字符串拼接转为整数累加，奇数长度时单独累加中间元素。

## Java 代码实现

```java
class Solution {
    public long findTheArrayConcVal(int[] nums) {
        int left = 0, right = nums.length - 1;
        long total = 0;

        while (left < right) {
            // 拼接首尾元素（字符串级别）
            String concat = nums[left] + "" + nums[right];
            total += Long.parseLong(concat);
            left++;
            right--;
        }
        // 奇数个元素时，中间元素直接加入
        if (left == right) total += nums[left];
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * d)，d 为最大位数
- **空间复杂度**：O(1)

## 关键点总结

1. 双指针从两端向中间，模拟对折操作
2. 拼接用字符串：`a + "" + b` 再 `Long.parseLong`
3. 奇数长度时，`left == right` 时单独加入中间元素
