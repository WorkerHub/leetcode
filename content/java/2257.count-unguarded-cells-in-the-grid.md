## 题目描述

网格中有守卫和墙，守卫向四方向警戒直到被墙或其他守卫遮挡。统计未被警戒的空单元格数。

## 解题思路

模拟：先标记守卫和墙为遮挡物，再对每个守卫向四方向延伸标记被守卫格子，最后统计未标记格子数。

## Java 代码实现

```java
class Solution {
    public int countUnguarded(int m, int n, int[][] guards, int[][] walls) {
        int[][] grid = new int[m][n];
        // 0=空, 1=被守卫, 2=守卫/墙
        for (int[] g : guards) grid[g[0]][g[1]] = 2;
        for (int[] w : walls) grid[w[0]][w[1]] = 2;

        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        for (int[] g : guards) {
            for (int[] d : dirs) {
                int r = g[0] + d[0], c = g[1] + d[1];
                while (r >= 0 && r < m && c >= 0 && c < n && grid[r][c] != 2) {
                    grid[r][c] = 1;
                    r += d[0];
                    c += d[1];
                }
            }
        }

        int count = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 0) count++;
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m*n + g*(m+n))
- **空间复杂度**：O(m*n)

## 关键点总结

1. **守卫和墙都是遮挡物**：统一标记为2
2. **四方向延伸**：遇到2停止
3. **先标记后延伸**：避免标记顺序影响结果
