## 题目描述

将数组偶数下标元素升序排列，奇数下标元素降序排列，返回结果数组。

## 解题思路

分别提取偶数下标和奇数下标元素，排序后合并回原位置。

## Java 代码实现

```java
class Solution {
    public int[] sortEvenOdd(int[] nums) {
        int n = nums.length;
        List<Integer> evens = new ArrayList<>();
        List<Integer> odds = new ArrayList<>();
        
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) evens.add(nums[i]);
            else odds.add(nums[i]);
        }
        
        Collections.sort(evens); // 升序
        odds.sort(Collections.reverseOrder()); // 降序
        
        int ei = 0, oi = 0;
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) nums[i] = evens.get(ei++);
            else nums[i] = odds.get(oi++);
        }
        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **偶数下标升序，奇数下标降序**：方向不要弄反
2. **分离排序合并**：提取后独立排序再放回
3. **Collections.reverseOrder()**：实现降序排列
