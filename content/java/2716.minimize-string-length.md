## 题目描述

给你一个字符串 `s`，每次操作可以删除某个字符左边或右边与其相同的字符，返回执行最优操作后字符串的最小长度。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimizedStringLength(String s) {
        // 每种字符最终只保留一个，最小长度等于不同字符的种类数
        Set<Character> set = new HashSet<>();
        for (char c : s.toCharArray()) {
            set.add(c);
        }
        return set.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（字符集大小固定为 26）

## 关键点总结

1. 每种字符可以通过操作消除所有重复，只保留一个
2. 最小长度 = 字符串中不同字符的种类数
