## 题目描述

`n` 支队伍参加淘汰赛，偶数时进行 `n/2` 场，奇数时进行 `(n-1)/2` 场并轮空一支。返回总比赛场数。

## 解题思路

**数学：** 每场比赛淘汰 1 支队伍，从 n 支到 1 支需淘汰 `n-1` 支，答案为 `n - 1`。

## Java 代码实现

```java
class Solution {
    public int numberOfMatches(int n) {
        // 每场比赛恰好淘汰一支队伍，最终从 n 支到 1 支冠军，共 n-1 场
        return n - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 每场比赛淘汰 1 支，共淘汰 n-1 支，答案就是 n-1
2. 无需模拟，数学推导一行解决
