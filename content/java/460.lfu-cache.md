## 题目描述

设计并实现一个最不经常使用（LFU）缓存。

实现 `LFUCache` 类：

- `LFUCache(int capacity)` - 用数据结构的容量 `capacity` 初始化对象
- `int get(int key)` - 如果键 `key` 存在于缓存中，则获取键的值，否则返回 `-1`
- `void put(int key, int value)` - 如果键已存在，则变更其值；如果键不存在，则插入键值对。当缓存达到其容量 `capacity` 时，应该在插入新项之前，移除最不经常使用的项。在此问题中，当存在平局（即两个或更多个键具有相同使用频率）时，应该去除最近最久未使用的键

为了确定最不常使用的键，可以为缓存中的每个键维护一个使用计数器。使用计数最小的键是最不经常使用的键。

当一个键首次插入到缓存中时，它的使用计数器被设置为 `1`（由于 `put` 操作）。对缓存中的键执行 `get` 或 `put` 操作时，使用计数器的值将会递增。

函数 `get` 和 `put` 必须以 O(1) 的平均时间复杂度运行。

**示例：**
```
输入:
["LFUCache", "put", "put", "get", "put", "get", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [3], [4, 4], [1], [3], [4]]
输出:
[null, null, null, 1, null, -1, 3, null, -1, 3, 4]

解释:
// cnt(x) = 键 x 的使用计数
// cache=[] 将显示最后使用的顺序（最左边的元素是最近的）
LFUCache lfu = new LFUCache(2);
lfu.put(1, 1);   // cache=[1,_], cnt(1)=1
lfu.put(2, 2);   // cache=[2,1], cnt(2)=1, cnt(1)=1
lfu.get(1);      // 返回 1
                 // cache=[1,2], cnt(2)=1, cnt(1)=2
lfu.put(3, 3);   // 2 是 LFU 键因为 cnt(2)=1 最小，移除键 2
                 // cache=[3,1], cnt(3)=1, cnt(1)=2
lfu.get(2);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,1], cnt(3)=2, cnt(1)=2
lfu.put(4, 4);   // 1 和 3 的 cnt 相同，但 1 最久未使用，移除键 1
                 // cache=[4,3], cnt(4)=1, cnt(3)=2
lfu.get(1);      // 返回 -1（未找到）
lfu.get(3);      // 返回 3
                 // cache=[3,4], cnt(4)=1, cnt(3)=3
lfu.get(4);      // 返回 4
                 // cache=[4,3], cnt(4)=2, cnt(3)=3
```

**提示：**
- `1 <= capacity <= 10^4`
- `0 <= key <= 10^5`
- `0 <= value <= 10^9`
- 最多调用 `2 * 10^5` 次 `get` 和 `put` 方法

## 解题思路

LFU 缓存需要满足两个条件：
1. 移除访问频率最低的键
2. 频率相同时，移除最久未使用的键（LRU）

**数据结构设计：**

1. **哈希表** `keyMap`: `{key: Node}` - 快速查找节点
2. **频率哈希表** `freqMap`: `{freq: DoublyLinkedList}` - 管理每个频率的节点链表
3. **最小频率** `minFreq`: 记录当前最小访问频率
4. **双向链表**: 每个频率对应一个双向链表，维护 LRU 顺序

**核心操作：**

### get(key):
1. 如果 key 不存在，返回 -1
2. 获取节点值
3. 增加节点频率（从旧频率链表移除，加入新频率链表）
4. 返回值

### put(key, value):
1. 如果 key 已存在，更新值并增加频率
2. 如果 key 不存在：
   - 如果缓存已满，移除 `minFreq` 链表的最后一个节点
   - 创建新节点，频率为 1
   - 加入频率 1 的链表
   - 更新 `minFreq` 为 1

### 增加频率:
1. 从当前频率链表移除节点
2. 如果链表为空且该频率是 `minFreq`，则 `minFreq++`
3. 节点频率 +1
4. 加入新频率链表的头部（最近使用）

## Java 代码实现

### 方法一：哈希表 + 双向链表（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class LFUCache {

    /** 双向链表节点 */
    private static class Node {
        int key, value, freq;
        Node prev, next;

        Node(int key, int value) {
            this.key = key;
            this.value = value;
            this.freq = 1; // 初始频率为 1
        }
    }

    /** 双向链表，维护 LRU 顺序（头部为最近使用） */
    private static class DoublyLinkedList {
        Node head, tail; // 哨兵节点
        int size;

        DoublyLinkedList() {
            head = new Node(-1, -1);
            tail = new Node(-1, -1);
            head.next = tail;
            tail.prev = head;
            size = 0;
        }

        /** 在链表头部添加节点（最近使用） */
        void addFirst(Node node) {
            node.prev = head;
            node.next = head.next;
            head.next.prev = node;
            head.next = node;
            size++;
        }

        /** 移除指定节点 */
        void remove(Node node) {
            node.prev.next = node.next;
            node.next.prev = node.prev;
            node.prev = null;
            node.next = null;
            size--;
        }

        /** 移除最后一个节点（最久未使用） */
        Node removeLast() {
            if (isEmpty()) return null;
            Node last = tail.prev;
            remove(last);
            return last;
        }

        /** 检查链表是否为空 */
        boolean isEmpty() {
            return size == 0;
        }
    }

    private final int capacity;
    private int minFreq;                              // 当前最小访问频率
    private final Map<Integer, Node> keyMap;          // key -> Node
    private final Map<Integer, DoublyLinkedList> freqMap; // freq -> DoublyLinkedList

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.minFreq = 0;
        this.keyMap = new HashMap<>();
        this.freqMap = new HashMap<>();
    }

    /** 获取键的值 */
    public int get(int key) {
        if (capacity == 0 || !keyMap.containsKey(key)) {
            return -1;
        }
        Node node = keyMap.get(key);
        incrFreq(node); // 增加频率
        return node.value;
    }

    /** 插入或更新键值对 */
    public void put(int key, int value) {
        if (capacity == 0) return;

        // 键已存在，更新值和频率
        if (keyMap.containsKey(key)) {
            Node node = keyMap.get(key);
            node.value = value;
            incrFreq(node);
            return;
        }

        // 键不存在，需要插入
        // 如果缓存已满，移除最不常用的键
        if (keyMap.size() == capacity) {
            DoublyLinkedList list = freqMap.get(minFreq);
            Node removed = list.removeLast();
            if (removed != null) {
                keyMap.remove(removed.key);
            }
        }

        // 创建新节点并添加
        Node node = new Node(key, value);
        keyMap.put(key, node);
        addNode(node);
        minFreq = 1; // 新节点频率为 1
    }

    /** 增加节点的访问频率 */
    private void incrFreq(Node node) {
        int freq = node.freq;
        DoublyLinkedList list = freqMap.get(freq);
        list.remove(node); // 从当前频率链表移除

        // 如果当前频率链表为空，更新 minFreq
        if (list.isEmpty()) {
            freqMap.remove(freq);
            if (freq == minFreq) {
                minFreq++;
            }
        }

        // 增加频率并添加到新链表
        node.freq++;
        addNode(node);
    }

    /** 将节点添加到对应频率的链表头部 */
    private void addNode(Node node) {
        int freq = node.freq;
        freqMap.computeIfAbsent(freq, k -> new DoublyLinkedList()).addFirst(node);
    }
}

/**
 * 使用示例:
 * LFUCache obj = new LFUCache(capacity);
 * int param1 = obj.get(key);
 * obj.put(key, value);
 */
```

## 复杂度分析

- **时间复杂度**：
  - `get`: O(1) - 哈希表查找 + 链表操作
  - `put`: O(1) - 哈希表操作 + 链表操作
  
- **空间复杂度**：O(capacity)
  - 存储最多 `capacity` 个节点
  - 频率链表数量最多为 `capacity`

## 关键点总结

1. **双向链表维护 LRU 顺序**：同频率的节点按访问时间排序
2. **频率分组**：每个频率对应一个链表
3. **最小频率跟踪**：用 `minFreq` 快速定位要移除的节点
4. **节点移动**：访问时从旧频率链表移到新频率链表
5. **哨兵节点**：简化链表操作，避免空指针判断

## 易错点

1. **忘记更新 minFreq**
   ```java
   // 错误：移除后没有更新 minFreq
   if (list.isEmpty()) {
       freqMap.remove(freq);
   }

   // 正确：检查并更新
   if (list.isEmpty()) {
       freqMap.remove(freq);
       if (freq == minFreq) {
           minFreq++;
       }
   }
   ```

2. **节点频率更新顺序**
   ```java
   // 正确顺序：先移除，再增加频率，最后添加
   list.remove(node);
   node.freq++;
   addNode(node);
   ```

3. **put 时更新现有键**
   ```java
   // 必须检查键是否已存在
   if (keyMap.containsKey(key)) {
       // 更新值和频率
       return;
   }
   // 否则插入新键
   ```
