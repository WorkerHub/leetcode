## 题目描述

偶数位只能是偶数（5种），奇数位只能是质数（4种），给你 `n`，返回长度为 n 的好数字字符串数目，结果对 10^9+7 取余。

## 解题思路

偶数位有 `(n+1)/2` 个，奇数位有 `n/2` 个，答案为 `5^((n+1)/2) * 4^(n/2) % MOD`，用快速幂计算（n 最大 10^15）。

## Java 代码实现

```java
class Solution {
    static final long MOD = 1_000_000_007L;

    public int countGoodNumbers(long n) {
        long evenCount = (n + 1) / 2; // 偶数位个数
        long oddCount = n / 2;         // 奇数位个数
        return (int) (pow(5, evenCount) * pow(4, oddCount) % MOD);
    }

    private long pow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 偶数位个数是 `(n+1)/2`（含第 0 位），奇数位是 `n/2`
2. n 最大 10^15，必须使用快速幂
3. 两个快速幂结果相乘后还需 % MOD
