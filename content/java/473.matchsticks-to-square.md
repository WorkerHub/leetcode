## 题目描述

你将得到一个整数数组 `matchsticks`，其中 `matchsticks[i]` 是第 `i` 根火柴棒的长度。你要用所有的火柴棍拼成一个正方形。你不能折断任何一根火柴棒，但你可以把它们连在一起，而且每根火柴棒必须使用一次。

如果你能使这个正方形，则返回 `true`，否则返回 `false`。

**示例 1：**
```
输入：matchsticks = [1,1,2,2,2]
输出：true
解释：能拼成一个边长为 2 的正方形，每边两根火柴。
```

**示例 2：**
```
输入：matchsticks = [3,3,3,3,4]
输出：false
解释：不能用所有火柴拼成一个正方形。
```

**提示：**
- `1 <= matchsticks.length <= 15`
- `1 <= matchsticks[i] <= 10^8`

## 解题思路

这是一道**回溯 + 剪枝**的经典问题，类似于"划分为 k 个相等子集"。

**核心思想：**
1. 正方形有 4 条边，每条边长度相等
2. 边长 = 总长度 / 4
3. 问题转化为：能否将火柴分成 4 组，每组和相等

**算法流程：**
1. 计算总长度，检查能否被 4 整除
2. 使用回溯尝试将每根火柴放入 4 条边之一
3. 剪枝优化：
   - 从大到小排序（大火柴先放，减少回溯）
   - 跳过重复的火柴长度
   - 当前边超过目标长度时剪枝

## Java 代码实现

### 方法一：回溯（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    private int[] matchsticks;
    private int target;

    public boolean makesquare(int[] matchsticks) {
        int total = 0;
        for (int stick : matchsticks) total += stick;

        // 边界检查
        if (total % 4 != 0) return false;

        target = total / 4;

        // 优化：从大到小排序
        Arrays.sort(matchsticks);
        // 反转数组（Arrays.sort 无法直接对基本类型倒序）
        for (int i = 0, j = matchsticks.length - 1; i < j; i++, j--) {
            int tmp = matchsticks[i];
            matchsticks[i] = matchsticks[j];
            matchsticks[j] = tmp;
        }
        this.matchsticks = matchsticks;

        // 如果最大的火柴超过边长，直接返回 false
        if (matchsticks[0] > target) return false;

        // 4 条边的当前长度
        int[] sides = new int[4];

        return backtrack(0, sides);
    }

    private boolean backtrack(int idx, int[] sides) {
        // 所有火柴都已放置
        if (idx == matchsticks.length) {
            return sides[0] == target && sides[1] == target && sides[2] == target;
        }

        // 尝试将当前火柴放入每条边
        for (int i = 0; i < 4; i++) {
            // 剪枝 1：当前边加上火柴后超过目标
            if (sides[i] + matchsticks[idx] > target) continue;

            // 剪枝 2：避免重复（相同长度的边不需要重复尝试）
            if (i > 0 && sides[i] == sides[i - 1]) continue;

            // 放置火柴
            sides[i] += matchsticks[idx];

            // 递归
            if (backtrack(idx + 1, sides)) return true;

            // 回溯
            sides[i] -= matchsticks[idx];
        }

        return false;
    }
}
```

### 方法二：状态压缩 DP

```java
import java.util.Arrays;

class Solution {
    public boolean makesquare(int[] matchsticks) {
        int total = 0;
        for (int stick : matchsticks) total += stick;
        if (total % 4 != 0) return false;

        int target = total / 4;
        int n = matchsticks.length;

        // dp[mask] 表示使用 mask 对应的火柴，当前边已完成部分的长度
        int[] dp = new int[1 << n];
        Arrays.fill(dp, -1);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == -1) continue;

            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) continue;

                int nextMask = mask | (1 << i);
                int nextLen = dp[mask] + matchsticks[i];

                if (nextLen <= target) {
                    dp[nextMask] = nextLen % target;
                }
            }
        }

        return dp[(1 << n) - 1] == 0;
    }
}
```

## 复杂度分析

**方法一（回溯）：**
- 时间复杂度：O(4^n)，最坏情况
- 空间复杂度：O(n)，递归栈

**实际优化：** 剪枝后远小于 O(4^n)

## 关键点总结

1. **等分检查：** 总长度必须能被 4 整除
2. **排序优化：** 大火柴先放，减少回溯次数
3. **剪枝策略：**
   - 超过边长剪枝
   - 相同长度的边去重
4. **回溯模板：** 尝试 -> 递归 -> 撤销

## 易错点

1. **忘记排序：** 排序可显著提升效率
2. **去重剪枝：** 相同长度的边不重复尝试
3. **边界检查：** 最大火柴 > 边长时直接返回
