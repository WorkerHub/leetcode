## 题目描述

泰波那契序列：T0=0, T1=1, T2=1, Tn = Tn-1 + Tn-2 + Tn-3。给定 n，返回 Tn。

**示例：**
```
输入：n = 4
输出：4（T3=2, T4=1+1+2=4）
```

## 解题思路

滚动变量：只保留前三个数，每步更新。

## Java 代码实现

```java
class Solution {
    public int tribonacci(int n) {
        if (n == 0) return 0;
        if (n <= 2) return 1;

        int a = 0, b = 1, c = 1;
        for (int i = 3; i <= n; i++) {
            int next = a + b + c;
            a = b;
            b = c;
            c = next;
        }
        return c;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **滚动变量**：a, b, c 依次前移，避免数组开销
2. **边界处理**：n=0 返回 0，n=1,2 返回 1
3. **状态转移**：`next = a + b + c`，然后平移
