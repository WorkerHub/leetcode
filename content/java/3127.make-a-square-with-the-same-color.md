## 题目描述

3x3矩阵中最多改一个格子，能否让某个2x2子矩阵全同色。

## 解题思路

枚举4个2x2子矩阵，统计黑白数量，若某色>=3则返回true。

## Java 代码实现

```java
class Solution {
    public boolean canMakeSquare(char[][] grid) {
        for (int r = 0; r < 2; r++) {
            for (int c = 0; c < 2; c++) {
                int b = 0;
                if (grid[r][c] == 'B') b++;
                if (grid[r][c + 1] == 'B') b++;
                if (grid[r + 1][c] == 'B') b++;
                if (grid[r + 1][c + 1] == 'B') b++;
                // 至少3个同色即可
                if (b >= 3 || b <= 1) return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **3x3矩阵只有4个2x2子矩阵**
2. **4格中>=3同色**：最多改1格即可全同
3. **b<=1等价于白色>=3**
