## 题目描述

购买k块巧克力，价格<=m免费，>m支付price-m，最小化总loss。

## 解题思路

排序+前缀和：价格<=m的都免费(loss=0)，>m的取最便宜的(loss=price-m)。二分找m的位置，右侧取最左j个。

## Java 代码实现

```java
class Solution {
    public long[] minimumRelativeLosses(int[] prices, int[][] queries) {
        Arrays.sort(prices);
        int n = prices.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + prices[i];
        }

        long[] ans = new long[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int k = queries[q][0];
            long m = queries[q][1];
            // pos = 左侧<=m的数量
            int pos = upperBound(prices, (int) m);
            // 从右侧(>m)取j个，从左侧(<=m)取k-j个
            int jLo = Math.max(0, k - pos);
            int jHi = Math.min(k, n - pos);
            long best = Long.MAX_VALUE;
            for (int j = jLo; j <= jHi; j++) {
                // 右侧取最左j个，loss = sum(prices[pos..pos+j-1]) - j*m
                long rightLoss = prefix[pos + j] - prefix[pos] - (long) j * m;
                best = Math.min(best, rightLoss);
            }
            ans[q] = best;
        }
        return ans;
    }

    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N + Q * K)
- **空间复杂度**：O(N)

## 关键点总结

1. **排序后二分找m位置**：区分免费和付费区域
2. **前缀和快速求区间和**
3. **右侧取最便宜的j个**：贪心最小化loss
