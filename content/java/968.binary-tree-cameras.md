## 题目描述

在二叉树节点上安装摄像头，每个摄像头可监控父节点、自身和子节点。求监控所有节点的最少摄像头数。

## 解题思路

贪心 + 后序遍历：三种状态（0=未监控，1=有摄像头，2=被监控）。子节点未监控则当前必须放摄像头；子节点有摄像头则当前被监控；否则当前未监控。

## Java 代码实现

```java
class Solution {
    private int cameras = 0;

    public int minCameraCover(TreeNode root) {
        if (dfs(root) == 0) cameras++;
        return cameras;
    }

    // 返回：0=未监控，1=有摄像头，2=被监控
    private int dfs(TreeNode node) {
        if (node == null) return 2;

        int left = dfs(node.left);
        int right = dfs(node.right);

        // 子节点有未监控的，当前必须放摄像头
        if (left == 0 || right == 0) {
            cameras++;
            return 1;
        }

        // 子节点有摄像头，当前被监控
        if (left == 1 || right == 1) {
            return 2;
        }

        // 子节点都被监控，当前未监控（让父节点处理）
        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)

## 关键点总结

1. **贪心策略**：优先在叶子的父节点放摄像头
2. **三种状态**：清晰表示监控情况
3. **根节点特判**：根节点未监控时需额外加一个
