## 题目描述

给你 `2n` 个球，每种颜色的球个数由数组 `balls` 给出，其中 `balls[i]` 是第 `i` 种颜色球的个数（编号从 0 开始）。

所有的球会被放入两个盒子里，**每个盒子接收 n 个球**。

给你一个整数数组 `balls`，其中 `balls.length` 等于颜色种数 k（`balls` 的长度），`sum(balls) = 2n`。

返回两个盒子**各自包含不同颜色数量相同**的概率。

**示例 1：**
```
输入：balls = [1,1]
输出：1.00000
解释：每种颜色各一个球，每盒各放一球，两盒颜色种数都是 1，概率为 1。
```

**示例 2：**
```
输入：balls = [2,1,1]
输出：0.66667
解释：4 个球共 4!/(2!1!1!) = 12 种不同排列。
     其中两盒颜色种数相同的情况为 8 种，概率 = 8/12 ≈ 0.66667。
```

**示例 3：**
```
输入：balls = [1,1,1,1,1,1]
输出：0.90000
解释：6 种颜色各一个球，放入两盒各 3 个，概率为 0.9。
```

**提示：**
- `1 <= balls.length <= 8`
- `1 <= balls[i] <= 6`
- `sum(balls)` 是偶数

## 解题思路

**概率 = 满足条件的方案数 / 总方案数**

**总方案数：** 将 `2n` 个有区别的球（同种颜色不同编号）放入两个盒子，每盒 n 个：
`C(2n, n)`（从 2n 个球中选 n 个放入盒子 1）

**满足条件的方案数：** 两盒颜色种数相同

**方法：回溯枚举**

逐种颜色处理，枚举该种颜色有多少个球放入盒子 1（0 到 `balls[i]`），追踪：
- 盒子 1 已放球数
- 盒子 1 已有颜色数
- 盒子 2 已有颜色数

当所有颜色处理完后，检查两盒球数是否都等于 n，且颜色种数相同。

## Java 代码实现

### 方法一：回溯 + 组合数（推荐）

```java
class Solution {
    private int[] balls;
    private int k, n;
    private long totalWays = 0;
    private long validWays = 0;

    public double getProbability(int[] balls) {
        this.balls = balls;
        this.k = balls.length;
        this.n = 0;
        for (int b : balls) n += b;
        n /= 2;  // 每盒球数

        dfs(0, 0, 0, 0, 0, 1L);
        return (double) validWays / totalWays;
    }

    private void dfs(int idx, int box1Count, int box2Count,
                     int box1Colors, int box2Colors, long ways) {
        if (idx == k) {
            // 所有颜色处理完毕
            if (box1Count == n && box2Count == n) {
                totalWays += ways;
                if (box1Colors == box2Colors) {
                    validWays += ways;
                }
            }
            return;
        }

        // 当前颜色有 balls[idx] 个球，枚举放入盒子1的个数（0 到 balls[idx]）
        for (int put1 = 0; put1 <= balls[idx]; put1++) {
            int put2 = balls[idx] - put1;
            // 当前颜色分配的方案数（组合数）
            long colorWays = comb(balls[idx], put1);
            // 当前颜色是否在盒子1/2中出现
            int newBox1Colors = box1Colors + (put1 > 0 ? 1 : 0);
            int newBox2Colors = box2Colors + (put2 > 0 ? 1 : 0);
            dfs(idx + 1, box1Count + put1, box2Count + put2,
                newBox1Colors, newBox2Colors, ways * colorWays);
        }
    }

    // 计算组合数 C(n, k)
    private long comb(int n, int k) {
        if (k > n - k) k = n - k;
        long result = 1;
        for (int i = 0; i < k; i++) {
            result = result * (n - i) / (i + 1);
        }
        return result;
    }
}
```

### 方法二：动态规划

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public double getProbability(int[] balls) {
        int k = balls.length;
        int n = 0;
        for (int b : balls) n += b;
        n /= 2;

        // dp[cnt1][col1][col2] = 方案数
        // 逐种颜色更新，状态: (盒1球数, 盒1颜色数, 盒2颜色数)
        Map<Long, Long> dp = new HashMap<>();
        dp.put(encode(0, 0, 0), 1L);

        for (int i = 0; i < k; i++) {
            Map<Long, Long> newDp = new HashMap<>();
            for (Map.Entry<Long, Long> entry : dp.entrySet()) {
                int[] state = decode(entry.getKey());
                int cnt1 = state[0], col1 = state[1], col2 = state[2];
                long ways = entry.getValue();
                for (int put1 = 0; put1 <= balls[i]; put1++) {
                    int put2 = balls[i] - put1;
                    long c = comb(balls[i], put1);
                    int newCol1 = col1 + (put1 > 0 ? 1 : 0);
                    int newCol2 = col2 + (put2 > 0 ? 1 : 0);
                    long key = encode(cnt1 + put1, newCol1, newCol2);
                    newDp.merge(key, ways * c, Long::sum);
                }
            }
            dp = newDp;
        }

        long valid = 0, total = 0;
        for (Map.Entry<Long, Long> entry : dp.entrySet()) {
            int[] state = decode(entry.getKey());
            if (state[0] == n) {
                total += entry.getValue();
                if (state[1] == state[2]) valid += entry.getValue();
            }
        }

        return (double) valid / total;
    }

    private long encode(int cnt1, int col1, int col2) {
        return cnt1 * 100L + col1 * 10L + col2;
    }

    private int[] decode(long key) {
        return new int[]{(int)(key / 100), (int)(key / 10 % 10), (int)(key % 10)};
    }

    private long comb(int n, int k) {
        if (k > n - k) k = n - k;
        long result = 1;
        for (int i = 0; i < k; i++) {
            result = result * (n - i) / (i + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(∏(balls[i] + 1))，枚举每种颜色的分配方式，最坏 O(7^8)
- 空间复杂度：O(k)，递归深度

由于 k ≤ 8，balls[i] ≤ 6，枚举空间在可接受范围内。

## 关键点总结

1. 概率 = 满足条件的方案数 / 总方案数
2. 逐种颜色枚举分配方式，用组合数 `C(balls[i], put_in_box1)` 计算每种颜色的分法
3. 追踪状态：(已处理颜色数, 盒1球数, 盒1颜色数, 盒2颜色数)
4. 满足条件：两盒各有 n 个球，且颜色种数相同

## 易错点

- 每种颜色的球是**有区别的**（虽然颜色相同），分配方式用组合数计算
- 追踪的是"颜色种数"而非"球数"，所以 put_in_box1 > 0 才算一种颜色
- Java 中计算组合数要防止溢出，建议用 `long`
