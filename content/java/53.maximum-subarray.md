## 题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

**示例 1：**
```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6
```

**示例 2：**
```
输入：nums = [1]
输出：1
```

**示例 3：**
```
输入：nums = [5,4,-1,7,8]
输出：23
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**进阶：** 如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的分治法求解。

## 解题思路

核心思想：动态规划（Kadane算法）

关键观察：
- 如果前面的和为负数，不如从当前位置重新开始
- dp[i] = max(nums[i], dp[i-1] + nums[i])

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int maxSum = nums[0];
        int currentSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            // 要么加上当前数，要么从当前数重新开始
            currentSum = Math.max(nums[i], currentSum + nums[i]);
            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
```

### 方法二：分治法

```java
class Solution {
    public int maxSubArray(int[] nums) {
        return helper(nums, 0, nums.length - 1);
    }

    private int helper(int[] nums, int left, int right) {
        if (left == right) {
            return nums[left];
        }

        int mid = (left + right) / 2;

        // 左半部分的最大和
        int leftMax = helper(nums, left, mid);
        // 右半部分的最大和
        int rightMax = helper(nums, mid + 1, right);

        // 跨越中点的最大和（从中点向左延伸）
        int leftSum = Integer.MIN_VALUE;
        int currentSum = 0;
        for (int i = mid; i >= left; i--) {
            currentSum += nums[i];
            leftSum = Math.max(leftSum, currentSum);
        }

        // 跨越中点的最大和（从中点向右延伸）
        int rightSum = Integer.MIN_VALUE;
        currentSum = 0;
        for (int i = mid + 1; i <= right; i++) {
            currentSum += nums[i];
            rightSum = Math.max(rightSum, currentSum);
        }

        int crossSum = leftSum + rightSum;

        return Math.max(Math.max(leftMax, rightMax), crossSum);
    }
}
```

## 复杂度分析

**方法一：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

**方法二：**
- 时间复杂度：O(n log n)
- 空间复杂度：O(log n)

## 关键点总结

1. **Kadane算法**：局部最优推导全局最优
2. **状态转移**：currentSum = Math.max(nums[i], currentSum + nums[i])
3. **分治思想**：分为左、右、跨中点三种情况

## 易错点

1. **初始值**：maxSum 初始化为 nums[0]，不能是 0（可能全是负数）
2. **整数最小值**：分治中使用 Integer.MIN_VALUE 代替 Python 的 float('-inf')
