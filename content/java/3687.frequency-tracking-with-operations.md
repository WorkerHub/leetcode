## 题目描述

设计一个数据结构，支持 `add(number)`、`remove(number)` 和 `hasFrequency(frequency)` 三种操作，分别添加、移除一个数，以及查询是否存在出现次数恰好为 frequency 的数。

## 解题思路

双哈希表：`count[num]` 记录每个数的出现次数；`freqCount[f]` 记录出现次数恰好为 f 的数字个数。每次 add/remove 时同步更新两个表，所有操作 O(1)。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class FrequencyTracker {
    private Map<Integer, Integer> count = new HashMap<>();    // 每个数字的频率
    private Map<Integer, Integer> freqCount = new HashMap<>(); // 每种频率的数字数

    public void add(int number) {
        int oldFreq = count.getOrDefault(number, 0);
        if (oldFreq > 0) freqCount.merge(oldFreq, -1, Integer::sum);
        count.put(number, oldFreq + 1);
        freqCount.merge(oldFreq + 1, 1, Integer::sum);
    }

    public void remove(int number) {
        int oldFreq = count.getOrDefault(number, 0);
        if (oldFreq == 0) return;
        freqCount.merge(oldFreq, -1, Integer::sum);
        count.put(number, oldFreq - 1);
        if (oldFreq - 1 > 0) freqCount.merge(oldFreq - 1, 1, Integer::sum);
    }

    public boolean hasFrequency(int frequency) {
        return freqCount.getOrDefault(frequency, 0) > 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1) 所有操作
- 空间复杂度：O(n)

## 关键点总结

1. 双哈希表维护"频率的频率"
2. 更新顺序：先减少旧频率计数，再增加新频率计数
3. count 减为 0 时不更新 freqCount[0]
