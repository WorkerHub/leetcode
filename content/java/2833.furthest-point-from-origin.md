## 题目描述

字符串含L/R/_，L左移R右移_任选方向，求执行后距原点最远距离。

## 解题思路

所有_分配给L和R中较多的方向。答案=|countL-countR|+count_。

## Java 代码实现

```java
class Solution {
    public int furthestDistanceFromOrigin(String moves) {
        int l = 0, r = 0, u = 0;
        for (char c : moves.toCharArray()) {
            if (c == 'L') l++;
            else if (c == 'R') r++;
            else u++;
        }
        return Math.abs(l - r) + u;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **_全分配给多的方向**：最大化净位移
2. **答案=|L-R|+_**：无论哪方多都成立
3. **一次遍历计数**
