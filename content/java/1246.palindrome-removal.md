## 题目描述

每次操作可移除一个回文子数组，移除后两侧元素合并。求移除所有元素的最少操作次数。

**示例：**
```
输入：arr = [1,3,4,1,5]
输出：3（移除 [4]→[1,3,1,5]，移除 [1,3,1]→[5]，移除 [5]）
```

## 解题思路

区间 DP：dp[i][j] = 移除 arr[i..j] 的最少操作次数。若 arr[i]==arr[j]，则 dp[i][j] = dp[i+1][j-1]（可以和中间的回文一起移除）。否则枚举分割点。

## Java 代码实现

```java
class Solution {
    public int minimumMoves(int[] arr) {
        int n = arr.length;
        int[][] dp = new int[n][n];
        
        // 单个元素需要 1 次
        for (int i = 0; i < n; i++) dp[i][i] = 1;
        
        // 按长度递增填表
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                // 初始值：先移除 arr[i]，再处理剩余
                dp[i][j] = dp[i + 1][j] + 1;
                
                // 如果 arr[i] == arr[j]，可以和中间一起构成回文
                if (arr[i] == arr[j]) {
                    dp[i][j] = Math.min(dp[i][j], 
                        len == 2 ? 1 : dp[i + 1][j - 1]);
                }
                
                // 枚举中间的分割点
                for (int k = i + 1; k < j; k++) {
                    if (arr[i] == arr[k]) {
                        dp[i][j] = Math.min(dp[i][j], 
                            dp[i + 1][k - 1] + dp[k][j]);
                    }
                }
            }
        }
        
        return dp[0][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：dp[i][j] 表示清除 arr[i..j] 的最少步数
2. **两端相同可合并**：arr[i]==arr[j] 时两端可附着在中间回文上一起移除
3. **枚举配对点**：arr[i] 可以和中间某个 arr[k] 配对
4. **基础情况**：len==2 且相等时只需 1 次
