## 题目描述

有一个 m × n 的矩形岛屿，与太平洋和大西洋相邻。太平洋处于岛屿的左边界和上边界，而大西洋处于岛屿的右边界和下边界。

岛屿被分割成一个个方格网格。给定一个 m x n 的整数矩阵 heights，heights[r][c] 表示坐标 (r, c) 上单元格高于海平面的高度。

岛屿的雨水较多，水可以向相邻单元格流动，前提是相邻单元格的高度小于或等于当前单元格的高度。

请找出那些水流既可以流动到太平洋，也可以流动到大西洋的陆地单元的坐标。

**示例 1：**
```
输入：heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
输出：[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

## 解题思路

逆向思维：从海洋出发，找能到达的陆地。

核心思路：
1. 从太平洋边界开始 DFS/BFS，标记能到达的格子
2. 从大西洋边界开始 DFS/BFS，标记能到达的格子
3. 同时被两个海洋标记的格子就是答案

## Java 代码实现

### 方法一：DFS（推荐）

```java
import java.util.*;

class Solution {
    private int m, n;
    private int[][] heights;
    private int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        // 从两个海洋边界出发进行 DFS
        if (heights == null || heights.length == 0) return new ArrayList<>();

        m = heights.length;
        n = heights[0].length;
        this.heights = heights;

        // 标记能到达的格子
        boolean[][] pacific = new boolean[m][n];
        boolean[][] atlantic = new boolean[m][n];

        // 从太平洋边界（上边和左边）开始
        for (int i = 0; i < m; i++) dfs(i, 0, pacific);
        for (int j = 0; j < n; j++) dfs(0, j, pacific);

        // 从大西洋边界（下边和右边）开始
        for (int i = 0; i < m; i++) dfs(i, n - 1, atlantic);
        for (int j = 0; j < n; j++) dfs(m - 1, j, atlantic);

        // 找出同时能到达两个海洋的格子
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (pacific[i][j] && atlantic[i][j]) {
                    result.add(Arrays.asList(i, j));
                }
            }
        }

        return result;
    }

    private void dfs(int r, int c, boolean[][] visited) {
        // 从 (r, c) 开始 DFS，标记能反向到达的格子
        visited[r][c] = true;

        for (int[] dir : dirs) {
            int nr = r + dir[0], nc = c + dir[1];
            // 边界检查，未访问，且高度不降（逆向思维）
            if (nr >= 0 && nr < m && nc >= 0 && nc < n
                    && !visited[nr][nc]
                    && heights[nr][nc] >= heights[r][c]) {
                dfs(nr, nc, visited);
            }
        }
    }
}
```

### 方法二：BFS

```java
import java.util.*;

class Solution {
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        // 使用 BFS
        if (heights == null || heights.length == 0) return new ArrayList<>();

        int m = heights.length, n = heights[0].length;
        boolean[][] pacific = new boolean[m][n];
        boolean[][] atlantic = new boolean[m][n];
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

        // 初始化两个海洋的 BFS 队列
        Queue<int[]> pacificQueue = new ArrayDeque<>();
        Queue<int[]> atlanticQueue = new ArrayDeque<>();

        for (int i = 0; i < m; i++) {
            pacificQueue.offer(new int[]{i, 0});
            atlanticQueue.offer(new int[]{i, n - 1});
        }
        for (int j = 0; j < n; j++) {
            pacificQueue.offer(new int[]{0, j});
            atlanticQueue.offer(new int[]{m - 1, j});
        }

        // BFS 遍历
        bfs(pacificQueue, pacific, heights, m, n, dirs);
        bfs(atlanticQueue, atlantic, heights, m, n, dirs);

        // 找出同时能到达两个海洋的格子
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (pacific[i][j] && atlantic[i][j]) {
                    result.add(Arrays.asList(i, j));
                }
            }
        }

        return result;
    }

    private void bfs(Queue<int[]> queue, boolean[][] visited,
                     int[][] heights, int m, int n, int[][] dirs) {
        // BFS 遍历，标记可达格子
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0], c = cell[1];
            visited[r][c] = true;

            for (int[] dir : dirs) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && !visited[nr][nc]
                        && heights[nr][nc] >= heights[r][c]) {
                    queue.offer(new int[]{nr, nc});
                    visited[nr][nc] = true;
                }
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. 逆向思维：从海洋到陆地
2. 两次 DFS/BFS 分别标记
3. 找交集

## 易错点

1. 水流方向理解错误（应该是高度不降）
2. 忘记处理边界重叠的情况
