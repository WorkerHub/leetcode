## 题目描述

`n` 个机器人在 1D 轨道上按 positions 和 directions 移动，相撞时血量少的消失、多的减 1（血量相等则同归于尽），返回按初始下标排序的幸存机器人血量数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> survivedRobotsHealths(int[] positions, int[] healths, String directions) {
        int n = positions.length;
        // 按位置排序，记录原始下标
        Integer[] robots = new Integer[n];
        for (int i = 0; i < n; i++) robots[i] = i;
        Arrays.sort(robots, (a, b) -> positions[a] - positions[b]);

        Deque<Integer> stack = new ArrayDeque<>(); // 向右移动机器人的原始下标
        int[] hp = healths.clone();
        boolean[] survived = new boolean[n];

        for (int i : robots) {
            if (directions.charAt(i) == 'R') {
                stack.push(i);
            } else {
                // 向左机器人与栈中向右机器人碰撞
                while (!stack.isEmpty() && hp[i] > 0) {
                    int top = stack.peek();
                    if (hp[top] > hp[i]) {
                        hp[top]--;    // 栈顶胜，血量减 1
                        hp[i] = 0;
                    } else if (hp[top] < hp[i]) {
                        stack.pop();  // 当前机器人胜，栈顶消亡
                        hp[i]--;
                    } else {
                        stack.pop();  // 同归于尽
                        hp[i] = 0;
                    }
                }
                if (hp[i] > 0) survived[i] = true;  // 向左机器人幸存
            }
        }
        // 栈中剩余的向右机器人幸存
        for (int i : stack) survived[i] = true;

        // 按原始下标顺序返回幸存者血量
        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (survived[i]) ans.add(hp[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(n)

## 关键点总结

1. 按位置排序后才能正确模拟碰撞
2. 栈维护向右移动的机器人，向左的机器人与栈顶碰撞
3. 碰撞后需继续检查（while 循环），直到栈为空或当前机器人消亡
