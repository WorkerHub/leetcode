## 题目描述

从一个由括号和整数组成的字符串构建一棵二叉树。格式为 `value(left)(right)`。

**示例：**
```
输入: s = "4(2(3)(1))(6(5))"
输出: [4,2,6,3,1,5]
```

## 解题思路

使用栈模拟递归：遇到数字创建节点入栈，遇到 `)` 弹出栈顶连接到父节点。

## Java 代码实现

### 方法一：迭代 + 栈（推荐）

```java
class Solution {
    public TreeNode str2tree(String s) {
        if (s == null || s.isEmpty()) return null;

        Deque<TreeNode> stack = new ArrayDeque<>();
        int i = 0;

        while (i < s.length()) {
            if (s.charAt(i) == ')') {
                stack.pop();
                i++;
            } else if (s.charAt(i) == '(') {
                i++;
            } else {
                // 解析数字（可能是负数或多位数）
                int j = i;
                if (s.charAt(i) == '-') i++;
                while (i < s.length() && Character.isDigit(s.charAt(i))) i++;

                TreeNode node = new TreeNode(Integer.parseInt(s.substring(j, i)));
                if (!stack.isEmpty()) {
                    TreeNode parent = stack.peek();
                    if (parent.left == null) {
                        parent.left = node;
                    } else {
                        parent.right = node;
                    }
                }
                stack.push(node);
            }
        }
        return stack.isEmpty() ? null : stack.peek();
    }
}
```

### 方法二：递归

```java
class Solution {
    private int index = 0;

    public TreeNode str2tree(String s) {
        if (s == null || s.isEmpty()) return null;
        return dfs(s);
    }

    private TreeNode dfs(String s) {
        if (index >= s.length()) return null;

        // 解析数字
        int start = index;
        if (s.charAt(index) == '-') index++;
        while (index < s.length() && Character.isDigit(s.charAt(index))) index++;
        TreeNode node = new TreeNode(Integer.parseInt(s.substring(start, index)));

        // 解析左子树
        if (index < s.length() && s.charAt(index) == '(') {
            index++; // 跳过 '('
            node.left = dfs(s);
            index++; // 跳过 ')'
        }

        // 解析右子树
        if (index < s.length() && s.charAt(index) == '(') {
            index++; // 跳过 '('
            node.right = dfs(s);
            index++; // 跳过 ')'
        }

        return node;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈法**：数字入栈，`)` 弹出连接父节点
2. **负数处理**：注意 `-` 号
3. **左右子树**：parent.left 为 null 时连左，否则连右
