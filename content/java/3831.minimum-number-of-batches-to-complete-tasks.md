## 题目描述

给定任务数组 `tasks` 和每批次上限 `batchSize`，返回完成所有任务所需的最少批次数。

## Java 代码实现

```java
class Solution {
    public int minimumBatches(int[] tasks, int batchSize) {
        int n = tasks.length;
        // 向上取整：(n + batchSize - 1) / batchSize
        return (n + batchSize - 1) / batchSize;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 最少批次数 = ceil(n / batchSize) = (n + batchSize - 1) / batchSize
2. 与具体任务持续时间无关，只取决于任务总数和每批上限
3. 整数向上取整的标准公式
