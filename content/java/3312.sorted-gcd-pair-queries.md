## 题目描述

给你整数数组 `nums` 和查询数组 `queries`，对每个查询返回所有对 `(i<j)` 的 gcd 值中第 `queries[j]` 小的（0 索引）。

## 解题思路

1. `cnt[d]` = nums 中 d 的倍数个数（从大到小累加因数）
2. `exact[d]` = gcd 恰好为 d 的对数（容斥：`C(cnt[d],2)` 减去所有倍数的 exact 值）
3. 构建前缀和，二分查找回答每个查询

## Java 代码实现

```java
class Solution {
    public int[] gcdValues(int[] nums, long[] queries) {
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // cnt[d] = nums 中 d 的倍数个数
        int[] cnt = new int[maxVal + 1];
        for (int x : nums) cnt[x]++;
        for (int d = maxVal; d >= 1; d--) {
            for (int k = 2 * d; k <= maxVal; k += d) cnt[d] += cnt[k];
        }

        // exact[d] = gcd 恰好为 d 的对数（容斥原理）
        long[] exact = new long[maxVal + 1];
        for (int d = maxVal; d >= 1; d--) {
            exact[d] = (long) cnt[d] * (cnt[d] - 1) / 2;
            for (int k = 2 * d; k <= maxVal; k += d) exact[d] -= exact[k];
        }

        // 前缀和：prefix[d] = gcd <= d 的对数
        long[] prefix = new long[maxVal + 2];
        for (int d = 1; d <= maxVal; d++) prefix[d] = prefix[d - 1] + exact[d];

        // 二分回答查询
        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            long q = queries[i];
            int lo = 1, hi = maxVal;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (prefix[mid] > q) hi = mid;
                else lo = mid + 1;
            }
            result[i] = lo;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(max_val × log(max_val) + q × log(max_val))，调和级数统计 + 二分查询
- 空间复杂度：O(max_val)

## 关键点总结

1. 利用因数枚举（调和级数 O(V log V)）统计每个 gcd 值的对数
2. 容斥：`exact[d] = C(cnt[d],2) - Σexact[kd]`（k≥2），从大到小处理保证依赖已计算
3. 查询用 `long` 类型（最大约 n²/2 ~ 5×10^9）
