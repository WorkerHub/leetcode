## 题目描述

你从 [0,0] 出发到 target，鬼魂从各自位置出发。每轮各移动一步。若你能在鬼魂之前到达目标返回 true（同时到达算失败）。

**示例：**
```
输入：ghosts = [[1,0],[0,3]], target = [0,1]
输出：true
```

## 解题思路

曼哈顿距离：只需比较你和所有鬼魂到目标的曼哈顿距离。若所有鬼魂距离都严格大于你的距离，则可逃脱。

## Java 代码实现

```java
class Solution {
    public boolean escapeGhosts(int[][] ghosts, int[] target) {
        int myDist = Math.abs(target[0]) + Math.abs(target[1]);

        for (int[] ghost : ghosts) {
            int ghostDist = Math.abs(target[0] - ghost[0]) + Math.abs(target[1] - ghost[1]);
            if (ghostDist <= myDist) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为鬼魂数量
- **空间复杂度**：O(1)

## 关键点总结

1. **曼哈顿距离**：网格中最短步数
2. **贪心观察**：鬼魂最优策略是直接去目标等候
3. **严格大于**：同时到达算失败
