## 题目描述

返回两个整数的和。

## 解题思路

直接返回num1+num2。

## Java 代码实现

```java
class Solution {
    public int sum(int num1, int num2) {
        return num1 + num2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **入门题**：直接加法运算
2. **位运算变体**：可用异或+与实现不用+号的加法
