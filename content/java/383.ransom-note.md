## 题目描述

给你两个字符串：`ransomNote` 和 `magazine`，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。

如果可以，返回 `true`；否则返回 `false`。

`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

**示例 1:**

```
输入：ransomNote = "a", magazine = "b"
输出：false
```

**示例 2:**

```
输入：ransomNote = "aa", magazine = "ab"
输出：false
```

**示例 3:**

```
输入：ransomNote = "aa", magazine = "aab"
输出：true
```

**提示:**

- `1 <= ransomNote.length, magazine.length <= 10^5`
- `ransomNote` 和 `magazine` 由小写英文字母组成

## 解题思路

本题是典型的**字符计数**问题，核心是判断 `magazine` 中每个字符的数量是否足够构成 `ransomNote`。

**核心思想：**

1. 统计 `magazine` 中每个字符的出现次数
2. 遍历 `ransomNote`，检查每个字符是否在 `magazine` 中有足够的数量
3. 如果某个字符不够，返回 `false`
4. 全部检查通过，返回 `true`

**多种实现方式：**

- **哈希表计数**：使用 HashMap 统计字符频次
- **数组计数**：因为只有小写字母，可以用长度为 26 的数组
- **减法计数**：统计两个字符串的字符差异

## Java 代码实现

### 方法一：数组计数（推荐）⭐

```java
class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        // 创建长度为 26 的数组，存储每个字母的计数
        int[] counts = new int[26];

        // 统计 magazine 中的字符
        for (char c : magazine.toCharArray()) {
            counts[c - 'a']++;
        }

        // 检查 ransomNote 的字符
        for (char c : ransomNote.toCharArray()) {
            int idx = c - 'a';
            if (counts[idx] == 0) {
                return false;
            }
            counts[idx]--;
        }

        return true;
    }
}
```

### 方法二：HashMap 计数

```java
import java.util.*;

class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        // 使用 HashMap 统计 magazine 的字符频次
        Map<Character, Integer> charCount = new HashMap<>();

        // 统计 magazine
        for (char c : magazine.toCharArray()) {
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);
        }

        // 检查 ransomNote
        for (char c : ransomNote.toCharArray()) {
            if (!charCount.containsKey(c) || charCount.get(c) == 0) {
                return false;
            }
            charCount.put(c, charCount.get(c) - 1);
        }

        return true;
    }
}
```

### 方法三：两次统计后比较

```java
import java.util.*;

class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        // 统计两个字符串各字母的出现次数
        int[] ransomCount = new int[26];
        int[] magazineCount = new int[26];

        for (char c : ransomNote.toCharArray()) {
            ransomCount[c - 'a']++;
        }
        for (char c : magazine.toCharArray()) {
            magazineCount[c - 'a']++;
        }

        // 检查 magazine 中每个字母的数量是否足够
        for (int i = 0; i < 26; i++) {
            if (ransomCount[i] > magazineCount[i]) {
                return false;
            }
        }

        return true;
    }
}
```

### 方法四：提前统计差值

```java
class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        // 用一个数组统计差值：magazine 加，ransomNote 减
        int[] diff = new int[26];

        for (char c : magazine.toCharArray()) {
            diff[c - 'a']++;
        }
        for (char c : ransomNote.toCharArray()) {
            diff[c - 'a']--;
            // 一旦某字母不足，立即返回
            if (diff[c - 'a'] < 0) {
                return false;
            }
        }

        return true;
    }
}
```

## 复杂度分析

**时间复杂度：** O(m + n)
- m 是 `magazine` 的长度，n 是 `ransomNote` 的长度
- 需要遍历两个字符串各一次

**空间复杂度：** O(1)
- 虽然使用了哈希表/数组，但最多存储 26 个小写字母
- 常数空间，不随输入规模增长

## 关键点总结

1. **字符计数问题的标准解法**：使用哈希表或数组统计频次
2. **数组优化**：只有 26 个小写字母时，数组比 HashMap 更高效
3. **空间优化**：只有 26 个字母时，可用数组代替哈希表
4. **边界处理**：注意字符不存在和数量不足两种情况
5. **提前终止**：发现不满足条件时立即返回，减少不必要的计算

## 易错点

1. **重复使用字符**：同一个字符在 magazine 中只能使用一次，需要减去计数
2. **大小写问题**：题目说明是小写字母，但实际应用需要注意
3. **空字符串**：ransomNote 为空时应该返回 `true`（循环不执行直接返回 true）
4. **Java 字符操作**：`c - 'a'` 得到 0-25 的索引，注意 char 和 int 的转换
