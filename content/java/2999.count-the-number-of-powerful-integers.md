## 题目描述

给你整数 `start`、`finish`、`limit` 和字符串 `s`，若正整数每位 <= limit 且以 s 结尾，则为强大整数，返回 [start, finish] 中强大整数的个数。

## 解题思路

数位 DP：计算 count(n) = [1,n] 中满足条件的数个数，答案 = count(finish) - count(start-1)。强大整数 = 前缀（每位 <= limit）+ 固定后缀 s。对总长度 < len(n) 的直接累加自由选择方案，对等于 len(n) 的逐位枚举前缀。

## Java 代码实现

```java
class Solution {
    public long numberOfPowerfulInt(long start, long finish, int limit, String s) {
        return count(finish, limit, s) - count(start - 1, limit, s);
    }

    private long count(long n, int limit, String s) {
        if (n <= 0) return 0;
        String t = Long.toString(n);
        int lt = t.length(), ls = s.length();
        if (lt < ls) return 0;
        // 检查后缀 s 每位是否 <= limit
        for (char c : s.toCharArray()) if (c - '0' > limit) return 0;

        int preLen = lt - ls;
        long res = 0;

        // 统计总长度 < lt 的（前缀长度 0 到 preLen-1）
        for (int p = 0; p < preLen; p++) {
            if (p == 0) {
                res += 1; // 数就是 s 本身（长度 ls < lt，一定 <= n）
            } else {
                // 前缀长度 p，首位 1~limit，其余 0~limit
                res += (long) limit * pow(limit + 1, p - 1);
            }
        }

        // 统计总长度 = lt，逐位构建前缀
        boolean tight = true;
        for (int i = 0; i < preLen && tight; i++) {
            int lo = (i == 0) ? 1 : 0;
            int upper = Math.min(t.charAt(i) - '0', limit);
            if (lo > upper) { tight = false; break; }
            res += (long)(upper - lo) * pow(limit + 1, preLen - i - 1);
            if (t.charAt(i) - '0' > limit) tight = false;
        }
        // 前缀完全匹配时，检查后缀 s 是否 <= t 的后 ls 位
        if (tight) {
            String suffix = t.substring(preLen);
            if (s.compareTo(suffix) <= 0) res++;
        }
        return res;
    }

    private long pow(int base, int exp) {
        long result = 1;
        for (int i = 0; i < exp; i++) result *= base;
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log finish)
- **空间复杂度**：O(log finish)

## 关键点总结

1. 数位 DP：count(n) = [1,n] 满足条件的数个数
2. 前缀首位不能为 0，其余每位在 [0, limit]
3. 后缀固定为 s，需检查 s 本身每位 <= limit
