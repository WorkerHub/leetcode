## 题目描述

给你三元组数组 `triplets` 和目标 `target`，合并操作取两个三元组的逐元素最大值，判断能否通过若干次合并得到 target。

## 解题思路

过滤掉任意分量超过 target 对应分量的三元组（合并后会破坏 target），将剩余三元组逐元素取最大值合并，检查是否等于 target。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public boolean mergeTriplets(int[][] triplets, int[] target) {
        int[] merged = new int[3];
        for (int[] t : triplets) {
            // 跳过任意分量超过 target 对应值的三元组
            if (t[0] <= target[0] && t[1] <= target[1] && t[2] <= target[2]) {
                merged[0] = Math.max(merged[0], t[0]);
                merged[1] = Math.max(merged[1], t[1]);
                merged[2] = Math.max(merged[2], t[2]);
            }
        }
        return Arrays.equals(merged, target);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 合并是取逐元素最大值，分量超过 target 的三元组会污染结果
2. 只选分量不超过 target 的三元组参与合并
3. 合并结果要恰好等于 target，不能多也不能少
