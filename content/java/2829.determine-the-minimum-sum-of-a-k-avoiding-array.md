## 题目描述

构造n个不同正整数，任意两数之和!=k，求最小元素和。

## 解题思路

数学：可安全选1到k/2（互不配对），不够时从k开始继续选。等差数列求和。

## Java 代码实现

```java
class Solution {
    public int minimumSum(int n, int k) {
        int half = k / 2;
        if (n <= half) {
            return n * (n + 1) / 2;
        }
        // 先选1..half，再从k开始选
        int sum1 = half * (half + 1) / 2;
        int remaining = n - half;
        // k, k+1, ..., k+remaining-1
        int sum2 = remaining * k + remaining * (remaining - 1) / 2;
        return sum1 + sum2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **1到k/2互不配对**：任意两数之和<k
2. **超出后从k开始选**：与前面任何数之和>k
3. **等差数列公式求和**
