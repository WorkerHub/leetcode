## 题目描述

给你一个整数数组 `nums` 和整数 `k`，判断是否存在下标 `a`，使得 `nums[a..a+k-1]` 和 `nums[a+k..a+2k-1]` 都是严格递增的（两段相邻且不重叠）。

## 解题思路

预处理 `inc[i]`（从位置 i 开始的最长严格递增子数组长度），然后枚举起始位置 `a`，检查 `inc[a] >= k && inc[a+k] >= k`。

## Java 代码实现

```java
class Solution {
    public boolean hasIncreasingSubarrays(int[] nums, int k) {
        int n = nums.length;

        // inc[i] = 从 i 开始的最长严格递增子数组长度
        int[] inc = new int[n];
        inc[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            inc[i] = nums[i] < nums[i + 1] ? inc[i + 1] + 1 : 1;
        }

        // 枚举第一段起始位置 a
        for (int a = 0; a <= n - 2 * k; a++) {
            if (inc[a] >= k && inc[a + k] >= k) {
                return true;
            }
        }

        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，预处理 + 一次遍历
- 空间复杂度：O(n)，递增长度数组

## 关键点总结

1. 预处理每个位置的最长严格递增子数组长度，可 O(1) 验证每个起始位置。
2. 两段相邻且不重叠，第二段从 `a + k` 开始。
3. 枚举范围：`a` 最大为 `n - 2k`（确保两段都在数组内）。
