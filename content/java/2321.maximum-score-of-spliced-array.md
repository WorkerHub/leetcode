## 题目描述

给你两个长度为 n 的整数数组 `nums1` 和 `nums2`，可以选一个区间 `[left, right]` 将其中一个数组的该区间替换为另一个数组的对应元素，返回某一数组的最大元素和。

## 解题思路

将 `nums1[l..r]` 替换为 `nums2` 对应区间后，`nums1` 的和变为 `sum(nums1) + sum(diff[l..r])`，其中 `diff[i] = nums2[i] - nums1[i]`。因此目标是求 `diff` 数组的最大子数组和（Kadane 算法），对两个方向各求一次取最大值。

## Java 代码实现

```java
class Solution {
    // Kadane 算法：求最大子数组和（最小增益为 0，即可以不替换）
    private int maxSubarrayGain(int[] a, int[] b) {
        int sum = 0;
        for (int x : a) sum += x;
        int gain = 0, cur = 0;
        for (int i = 0; i < a.length; i++) {
            cur = Math.max(0, cur + b[i] - a[i]); // 用 b 替换 a 的增益
            gain = Math.max(gain, cur);
        }
        return sum + gain;
    }

    public int maximumsSplicedArray(int[] nums1, int[] nums2) {
        // 两种方向都要尝试
        return Math.max(maxSubarrayGain(nums1, nums2), maxSubarrayGain(nums2, nums1));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 替换一段区间等价于在差分数组上求最大子数组和。
2. Kadane 算法初始 `cur=0`，允许"不替换任何元素"（增益为 0）。
3. 两个方向（用 nums2 换 nums1，或反过来）都要尝试并取最大值。
