## 题目描述

给定整数数组 `nums` 和整数 `m`，找出长度为 `m` 的子序列使其第一个元素和最后一个元素的乘积最大，返回该最大乘积。

## Java 代码实现

```java
class Solution {
    public long maxProduct(int[] nums, int m) {
        int n = nums.length;
        long result = Long.MIN_VALUE;

        // 前缀最大值和最小值
        long prefixMax = nums[0];
        long prefixMin = nums[0];

        // 枚举右端点 j（j >= m-1），左端点范围 [0, j-m+1]
        for (int j = m - 1; j < n; j++) {
            // 先更新前缀最大最小值（加入新的左端点 j-m+1）
            if (j > m - 1) {
                int newLeft = j - m + 1;
                prefixMax = Math.max(prefixMax, nums[newLeft]);
                prefixMin = Math.min(prefixMin, nums[newLeft]);
            }
            long v = nums[j];
            result = Math.max(result, Math.max(v * prefixMax, v * prefixMin));
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历维护前缀最大最小值
- 空间复杂度：O(1)

## 关键点总结

1. 枚举右端点 j，左端点范围为 `[0, j-m+1]`（保证子序列长度为 m）
2. 乘积最大需考虑 `nums[j]` 的正负，选左端的最大值或最小值
3. 用 `long` 防止乘积溢出（值域最大 10^9，两者相乘可达 10^18）
