## 题目描述

两名玩家轮流从数组左端或右端取数加入得分，两人均采取最优策略，返回先手玩家能获得的最大得分。

## Java 代码实现

```java
class Solution {
    public int maximumScore(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        // dp[i][j] = 在 nums[i..j] 上先手的最大得分差（自己 - 对手）
        long[][] dp = new long[n][n];
        for (int i = 0; i < n; i++) dp[i][i] = nums[i];

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                long takeLeft = nums[i] - dp[i + 1][j];
                long takeRight = nums[j] - dp[i][j - 1];
                dp[i][j] = Math.max(takeLeft, takeRight);
            }
        }
        // 甲得分 = (总分 + 得分差) / 2
        return (int) ((total + dp[0][n - 1]) / 2);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 记录得分差而非绝对得分，因为两人总和固定
2. `dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])`
3. 最终甲得分 = `(total + dp[0][n-1]) / 2`
