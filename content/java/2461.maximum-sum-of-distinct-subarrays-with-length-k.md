## 题目描述

给你整数数组 `nums` 和整数 `k`，返回长度为 `k` 且所有元素各不相同的子数组的最大和，若不存在返回 0。

## 解题思路

固定大小为 k 的滑动窗口，用哈希表维护窗口内元素频率。当哈希表大小等于 k 时（所有元素唯一），更新最大和。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long maximumSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        long windowSum = 0, ans = 0;

        for (int right = 0; right < nums.length; right++) {
            // 加入右端元素
            freq.merge(nums[right], 1, Integer::sum);
            windowSum += nums[right];

            // 窗口超过 k，移除左端元素
            if (right >= k) {
                int left = nums[right - k];
                windowSum -= left;
                freq.merge(left, -1, Integer::sum);
                if (freq.get(left) == 0) freq.remove(left);
            }

            // 窗口大小恰好为 k 且元素全唯一时更新答案
            if (right >= k - 1 && freq.size() == k) {
                ans = Math.max(ans, windowSum);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. 固定大小 k 的滑动窗口，维护元素频率表
2. `freq.size() == k` 等价于窗口内所有元素唯一
3. 频率归零时需从哈希表删除，否则 size 统计不准
