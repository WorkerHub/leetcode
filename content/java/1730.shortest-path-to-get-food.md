## 题目描述

在网格中，`'*'` 为起点，`'X'` 为食物，`'#'` 为墙，`'O'` 为空格。每次可上下左右移动一步，返回从 `'*'` 到任意 `'X'` 的最短路径长度，不可达则返回 `-1`。

## 解题思路

从 `'*'` 出发做 BFS，遇到 `'X'` 立即返回当前步数。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int getFood(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int sr = -1, sc = -1;

        // 找起点
        outer:
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '*') {
                    sr = i; sc = j;
                    break outer;
                }
            }
        }

        int[] dr = {0, 0, 1, -1};
        int[] dc = {1, -1, 0, 0};

        Deque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{sr, sc, 0});
        grid[sr][sc] = '#'; // 标记已访问

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], steps = cur[2];

            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                if (grid[nr][nc] == 'X') return steps + 1; // 到达食物
                if (grid[nr][nc] == 'O') {
                    grid[nr][nc] = '#'; // 标记已访问
                    queue.offer(new int[]{nr, nc, steps + 1});
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)

## 关键点总结

1. 标准 BFS 求最短路
2. 修改格子值为 `'#'` 代替 visited 集合，节省空间
3. 遇到食物立即返回，无需遍历全图
