## 题目描述

给你一个列表 `interests`，其中 `interests[i]` 是第 i 个人的兴趣集合。如果两个人有共同兴趣则为朋友（朋友关系传递）。返回朋友群体的数量。

## 解题思路

并查集：对每个兴趣，将拥有该兴趣的所有人合并到同一集合。最终统计不同连通分量的数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    int[] parent;

    public int friendGroups(int[][] interests) {
        int n = interests.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 按兴趣建立映射，将有共同兴趣的人合并
        Map<Integer, Integer> interestToFirst = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int interest : interests[i]) {
                if (interestToFirst.containsKey(interest)) {
                    union(i, interestToFirst.get(interest));
                } else {
                    interestToFirst.put(interest, i);
                }
            }
        }
        // 统计连通分量数
        Set<Integer> roots = new HashSet<>();
        for (int i = 0; i < n; i++) roots.add(find(i));
        return roots.size();
    }

    private int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k * α(n))，k 为平均兴趣数
- 空间复杂度：O(n + 总兴趣数)

## 关键点总结

1. 按兴趣建立映射，同兴趣的人用并查集合并
2. 路径压缩提高 find 效率
3. 最终统计不同根节点数即为群体数
