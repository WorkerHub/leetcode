## 题目描述

给你一个 `n x n` 整数矩阵 `grid`，可以对某些列执行操作（将该列从顶部某行到底部涂黑），若黑格子右侧相邻格是白色则得 1 分，返回最大得分。

## Java 代码实现

```java
class Solution {
    public long maximumScore(int[][] grid) {
        int n = grid.length;
        if (n == 1) return 0;

        // dp[h]: 当前列涂黑到高度 h 时的最大累积得分
        long[] dp = new long[n + 1];
        long NEG_INF = Long.MIN_VALUE / 2;

        for (int j = 0; j < n - 1; j++) {
            // 右列（j+1）的白色前缀和
            int[] rWhite = new int[n + 1];
            for (int i = 0; i < n; i++) {
                rWhite[i + 1] = rWhite[i] + (grid[i][j + 1] == 0 ? 1 : 0);
            }

            // 前缀最大值：prefMax[h] = max(dp[h1] + rWhite[h1]) for h1 <= h
            long[] prefMax = new long[n + 2];
            prefMax[0] = dp[0]; // dp[0] + rWhite[0] = dp[0] + 0
            for (int h = 1; h <= n; h++) {
                prefMax[h] = Math.max(prefMax[h - 1], dp[h] + rWhite[h]);
            }

            // 后缀最大值：sufMax[h] = max(dp[h1] + rWhite[h1]) for h1 >= h
            long[] sufMax = new long[n + 2];
            sufMax[n + 1] = NEG_INF;
            for (int h = n; h >= 0; h--) {
                sufMax[h] = Math.max(sufMax[h + 1], dp[h] + rWhite[h]);
            }

            long[] newDp = new long[n + 1];
            for (int h2 = 0; h2 <= n; h2++) {
                // h1 <= h2: score = 0, val = dp[h1]
                long opt1 = prefMax[h2] - rWhite[h2]; // 注意 prefMax 存的是 dp[h1]+rWhite[h1]，h1<=h2 时 score=0
                // Actually when h1<=h2: score=rWhite[h1]-rWhite[h1]=0, val=dp[h1]
                // prefMax[h2] = max(dp[h1]+rWhite[h1]) for h1<=h2, but we want max(dp[h1])
                // Recompute: for h1<=h2, score=0, so we need max(dp[h1]) not max(dp[h1]+rWhite[h1])
                // Let's use a separate prefix for just dp values
                opt1 = 0; // placeholder, will be filled below
                // h1 > h2: score = rWhite[h1] - rWhite[h2], val = dp[h1]+rWhite[h1]-rWhite[h2]
                long opt2 = sufMax[h2 + 1] == NEG_INF ? 0 : sufMax[h2 + 1] - rWhite[h2];
                newDp[h2] = Math.max(opt1, opt2);
            }

            // Recompute opt1 properly with prefix max of dp values
            long runMax = 0;
            for (int h2 = 0; h2 <= n; h2++) {
                runMax = Math.max(runMax, dp[h2]);
                long opt2 = sufMax[h2 + 1] == NEG_INF ? 0 : sufMax[h2 + 1] - rWhite[h2];
                newDp[h2] = Math.max(runMax, opt2);
            }

            dp = newDp;
        }

        long ans = 0;
        for (long v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 对每列枚举涂黑高度（0 到 n），用 DP 转移
2. 得分仅来自当前列黑格子右侧（下一列）的白格子
3. 用前缀/后缀最大值将内层枚举优化到 O(1)
