## 题目描述

二叉树中有一个无效节点，其右子指针指向了**同一深度的另一个节点**（横向指针而非向下）。找到并移除该无效节点，返回修正后的根节点。

## 解题思路

**BFS + 访问集合：** 同层按从右到左的顺序将节点加入 visited。若某节点的右子节点已在 visited 中，说明该右指针是无效的，将其置为 null。

## Java 代码实现

```java
class Solution {
    public TreeNode correctBinaryTree(TreeNode root) {
        Set<TreeNode> visited = new HashSet<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();

                // 先处理右子节点（无效指针指向同层右边的节点，右边先被访问）
                if (node.right != null) {
                    if (visited.contains(node.right)) {
                        node.right = null; // 断开无效指针
                        continue;
                    }
                    visited.add(node.right);
                    queue.offer(node.right);
                }
                if (node.left != null) {
                    if (visited.contains(node.left)) {
                        node.left = null;
                        continue;
                    }
                    visited.add(node.left);
                    queue.offer(node.left);
                }
            }
        }

        return root;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 无效节点的右指针指向同层更右边的节点
2. BFS 同层按右到左处理，被指向的目标节点先被访问到
3. 发现右子节点已在 visited 中，说明该指针无效，断开即可
