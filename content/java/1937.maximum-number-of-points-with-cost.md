## 题目描述

给你 m×n 矩阵 `points`，每行选一格，总得分为选中格子值之和减去相邻行选中列的绝对差之和，返回最大得分。

## 解题思路

DP + 前缀最大值优化：`dp[j]` 为选当前行第 j 列的最大得分。转移拆分为左侧（维护 `max(dp[k]+k)`）和右侧（维护 `max(dp[k]-k)`）两次线性扫描，将 O(n²) 优化到 O(n)。

## Java 代码实现

```java
class Solution {
    public long maxPoints(int[][] points) {
        int m = points.length, n = points[0].length;
        long[] dp = new long[n];
        for (int j = 0; j < n; j++) dp[j] = points[0][j];

        for (int i = 1; i < m; i++) {
            long[] ndp = new long[n];
            // 从左到右：处理 k <= j，维护 max(dp[k]+k)
            long leftMax = Long.MIN_VALUE / 2;
            for (int j = 0; j < n; j++) {
                leftMax = Math.max(leftMax, dp[j] + j);
                ndp[j] = Math.max(ndp[j], leftMax - j + points[i][j]);
            }
            // 从右到左：处理 k >= j，维护 max(dp[k]-k)
            long rightMax = Long.MIN_VALUE / 2;
            for (int j = n - 1; j >= 0; j--) {
                rightMax = Math.max(rightMax, dp[j] - j);
                ndp[j] = Math.max(ndp[j], rightMax + j + points[i][j]);
            }
            dp = ndp;
        }

        long ans = Long.MIN_VALUE;
        for (long v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn)
- **空间复杂度**：O(n)

## 关键点总结

1. 关键拆分：`|j-k|` 分左侧（k≤j）和右侧（k≥j）分别处理
2. 左侧维护 `max(dp[k]+k)`，右侧维护 `max(dp[k]-k)`
3. 使用 `long` 防止溢出
