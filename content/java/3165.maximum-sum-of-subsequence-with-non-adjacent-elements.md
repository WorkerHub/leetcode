## 题目描述

给你整数数组 `nums` 和查询 `queries[i] = [pos, x]`，每次将 `nums[pos]` 改为 x 后计算不相邻子序列的最大和，返回所有查询答案之和对 10^9+7 取模。

## 解题思路

线段树维护区间的 4 个状态（首端/尾端是否选择），每个节点存 `(f00, f01, f10, f11)` 表示不同端点选择组合下的最大不相邻子序列和。合并时类似矩阵乘法（取 max）。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;
    static final long NEG_INF = Long.MIN_VALUE / 2;
    // 每个节点存 {f00, f01, f10, f11}
    long[][] tree;
    int n;

    public int maximumSumSubsequence(int[] nums, int[][] queries) {
        n = nums.length;
        tree = new long[4 * n][4];
        build(nums, 1, 0, n - 1);
        long ans = 0;
        for (int[] q : queries) {
            update(1, 0, n - 1, q[0], q[1]);
            // 根节点的最大值（4 个状态中取最大）
            long[] root = tree[1];
            ans = (ans + Math.max(Math.max(root[0], root[1]), Math.max(root[2], root[3]))) % MOD;
        }
        return (int) ans;
    }

    private long[] makeLeaf(long v) {
        // 单个元素：f00=0(不选), f01=f10=NEG_INF(首尾一个元素无法只选一端), f11=v(选)
        return new long[]{0, NEG_INF, NEG_INF, v};
    }

    private long[] combine(long[] L, long[] R) {
        // L[i][j]: 左区间首选i、尾选j; R同理
        long f00 = max3(L[0] + R[0], L[0] + R[2], L[1] + R[0]);
        long f01 = max3(L[0] + R[1], L[0] + R[3], L[1] + R[1]);
        long f10 = max3(L[2] + R[0], L[2] + R[2], L[3] + R[0]);
        long f11 = max3(L[2] + R[1], L[2] + R[3], L[3] + R[1]);
        return new long[]{f00, f01, f10, f11};
    }

    private long max3(long a, long b, long c) {
        return Math.max(a, Math.max(b, c));
    }

    private void build(int[] nums, int node, int l, int r) {
        if (l == r) { tree[node] = makeLeaf(nums[l]); return; }
        int mid = (l + r) / 2;
        build(nums, 2 * node, l, mid);
        build(nums, 2 * node + 1, mid + 1, r);
        tree[node] = combine(tree[2 * node], tree[2 * node + 1]);
    }

    private void update(int node, int l, int r, int pos, long val) {
        if (l == r) { tree[node] = makeLeaf(val); return; }
        int mid = (l + r) / 2;
        if (pos <= mid) update(2 * node, l, mid, pos, val);
        else update(2 * node + 1, mid + 1, r, pos, val);
        tree[node] = combine(tree[2 * node], tree[2 * node + 1]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 区间节点维护 4 种端点选择状态（首/尾各选或不选）
2. 合并时枚举左区间尾端和右区间首端的连接（相邻则不能都选）
3. 单叶节点 f01=f10=NEG_INF（一个元素不能同时有独立的首端和尾端）
