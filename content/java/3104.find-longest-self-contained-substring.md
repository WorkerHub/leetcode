## 题目描述

给你字符串 `s`，若子串 `t` 中出现的每个字母在 `s` 的其他位置都不出现，则 `t` 为自包含子串。返回最长自包含子串的长度，不存在返回 -1（`s` 本身不算）。

## 解题思路

预处理每个字符的首次和最后出现位置。枚举左端点（只考虑字符首次出现位置），扩展右端点：若子串内某字符在左端点之前出现则不合法，否则将右端点扩展至该字符最后出现位置，直到覆盖所有字符。

## Java 代码实现

```java
class Solution {
    public int longestSelfContainedSubstring(String s) {
        int n = s.length();
        int[] first = new int[26], last = new int[26];
        java.util.Arrays.fill(first, -1);
        java.util.Arrays.fill(last, -1);
        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }
        int ans = -1;
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1) continue;
            int l = first[c], r = last[c];
            boolean valid = true;
            for (int i = l; i <= r; i++) {
                int ch = s.charAt(i) - 'a';
                if (first[ch] < l) { valid = false; break; } // ch 在 l 之前出现
                r = Math.max(r, last[ch]); // 扩展右端点
            }
            if (valid && r - l + 1 < n) {
                ans = Math.max(ans, r - l + 1);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 只需从每个字符首次出现位置枚举左端点
2. 扩展右端点时若发现某字符在 l 之前出现则不合法
3. 排除整个字符串本身
