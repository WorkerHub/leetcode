## 题目描述

实现 MapSum 类：insert(key, val) 插入键值对（重复 key 则更新），sum(prefix) 返回所有以 prefix 为前缀的键的值的总和。

**示例：**
```
insert("apple", 3), sum("ap") → 3
insert("app", 2), sum("ap") → 5
```

## 解题思路

字典树 + 前缀和：每个节点存储经过该节点的所有值的和。插入时用增量更新路径上所有节点。

## Java 代码实现

```java
class MapSum {
    private TrieNode root;
    private Map<String, Integer> map;

    public MapSum() {
        root = new TrieNode();
        map = new HashMap<>();
    }

    public void insert(String key, int val) {
        // 计算增量
        int delta = val - map.getOrDefault(key, 0);
        map.put(key, val);

        // 更新 Trie 路径上所有节点
        TrieNode node = root;
        for (char c : key.toCharArray()) {
            if (node.children[c - 'a'] == null) {
                node.children[c - 'a'] = new TrieNode();
            }
            node = node.children[c - 'a'];
            node.sum += delta;
        }
    }

    public int sum(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            if (node.children[c - 'a'] == null) return 0;
            node = node.children[c - 'a'];
        }
        return node.sum;
    }

    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int sum = 0;
    }
}
```

## 复杂度分析

- **insert**：O(k)，k 为 key 长度
- **sum**：O(k)，k 为 prefix 长度
- **空间复杂度**：O(总字符数)

## 关键点总结

1. **增量更新**：delta = new_val - old_val，处理重复 key
2. **前缀和存储**：节点存储经过该节点所有值的和
3. **HashMap 辅助**：记录已插入的 key-val
