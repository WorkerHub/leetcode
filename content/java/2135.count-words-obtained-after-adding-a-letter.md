## 题目描述

对targetWords中每个字符串，判断能否由startWords中某个字符串添加一个字母并重排得到。返回满足条件的target数量。

## 解题思路

位掩码表示字符集合。对每个target尝试移除每个字符后查找是否在start集合中。

## Java 代码实现

```java
class Solution {
    public int wordCount(String[] startWords, String[] targetWords) {
        Set<Integer> startMasks = new HashSet<>();
        for (String word : startWords) {
            int mask = 0;
            for (char c : word.toCharArray()) mask |= 1 << (c - 'a');
            startMasks.add(mask);
        }
        
        int ans = 0;
        for (String word : targetWords) {
            int mask = 0;
            for (char c : word.toCharArray()) mask |= 1 << (c - 'a');
            // 尝试移除每个字符
            for (char c : word.toCharArray()) {
                if (startMasks.contains(mask ^ (1 << (c - 'a')))) {
                    ans++;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((S + T) * L)
- **空间复杂度**：O(S)

## 关键点总结

1. **位掩码表示字符集**：26位对应26个字母
2. **异或移除字符**：mask ^ bit移除某个字母
3. **HashSet查找O(1)**：快速判断是否匹配
