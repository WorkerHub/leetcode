## 题目描述

判断sub经过mappings允许的字符替换后，是否能成为s的子串。

## 解题思路

预处理每个字符的可替换集合（含自身），枚举s中每个起始位置逐字符匹配。

## Java 代码实现

```java
class Solution {
    public boolean matchReplacement(String s, String sub, char[][] mappings) {
        // 构建替换集合：can[c] 表示 c 可以变成的字符集
        Set<Character>[] can = new HashSet[128];
        for (int i = 0; i < 128; i++) can[i] = new HashSet<>();
        for (char c : sub.toCharArray()) can[c].add(c);
        for (char[] m : mappings) {
            can[m[0]].add(m[1]);
        }

        int n = s.length(), m = sub.length();
        for (int i = 0; i <= n - m; i++) {
            boolean matched = true;
            for (int j = 0; j < m; j++) {
                if (!can[sub.charAt(j)].contains(s.charAt(i + j))) {
                    matched = false;
                    break;
                }
            }
            if (matched) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * M + K)
- **空间复杂度**：O(K)

## 关键点总结

1. **预处理替换集合**：字符本身也要加入集合
2. **枚举起始位置逐字符匹配**：暴力但数据范围允许
3. **mappings的方向**：sub中的字符可以替换为目标字符
