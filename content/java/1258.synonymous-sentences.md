## 题目描述

给定同义词列表 synonyms 和句子 text，返回所有可能的同义句子（按字典序排序）。同义关系可传递。

**示例：**
```
synonyms = [["happy","joy"],["sad","sorrow"],["joy","cheerful"]]
text = "I am happy today but was sad yesterday"
输出 6 种组合（happy/joy/cheerful × sad/sorrow）
```

## 解题思路

并查集将同义词分组。对句子中每个单词，若有同义词组则生成所有替换可能。回溯生成所有组合。

## Java 代码实现

```java
class Solution {
    public List<String> generateSentences(List<List<String>> synonyms, String text) {
        // 并查集分组同义词
        Map<String, String> parent = new HashMap<>();
        for (List<String> pair : synonyms) {
            union(parent, pair.get(0), pair.get(1));
        }
        
        // 按组收集同义词
        Map<String, TreeSet<String>> groups = new HashMap<>();
        for (String word : parent.keySet()) {
            String root = find(parent, word);
            groups.computeIfAbsent(root, k -> new TreeSet<>()).add(word);
        }
        
        // 对句子中每个单词找可替换集合
        String[] words = text.split(" ");
        List<String> result = new ArrayList<>();
        backtrack(words, groups, parent, 0, result);
        Collections.sort(result);
        return result;
    }
    
    private void backtrack(String[] words, Map<String, TreeSet<String>> groups, 
                          Map<String, String> parent, int idx, List<String> result) {
        if (idx == words.length) {
            result.add(String.join(" ", words));
            return;
        }
        
        String root = find(parent, words[idx]);
        if (groups.containsKey(root)) {
            String original = words[idx];
            for (String synonym : groups.get(root)) {
                words[idx] = synonym;
                backtrack(words, groups, parent, idx + 1, result);
            }
            words[idx] = original;
        } else {
            backtrack(words, groups, parent, idx + 1, result);
        }
    }
    
    private String find(Map<String, String> parent, String x) {
        if (!parent.containsKey(x)) return x;
        if (!parent.get(x).equals(x)) parent.put(x, find(parent, parent.get(x)));
        return parent.get(x);
    }
    
    private void union(Map<String, String> parent, String a, String b) {
        if (!parent.containsKey(a)) parent.put(a, a);
        if (!parent.containsKey(b)) parent.put(b, b);
        String pa = find(parent, a), pb = find(parent, b);
        if (!pa.equals(pb)) parent.put(pa, pb);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k^m)，k 为最大同义词组大小，m 为有同义词的单词数
- **空间复杂度**：O(n + 结果数)

## 关键点总结

1. **并查集**：处理同义词的传递性
2. **TreeSet**：自动排序同义词组
3. **回溯**：生成所有单词替换组合
4. **最终排序**：按字典序输出
