## 题目描述

给定递增质数数组 arr 和整数 k，对所有 i < j 构成分数 arr[i]/arr[j]，返回第 k 小的分数。

**示例：**
```
输入：arr = [1,2,3,5], k = 3
输出：[2,5]
```

## 解题思路

最小堆：初始化将每个分子配最大分母入堆，每次弹出最小分数后加入同分子的下一个分母。

## Java 代码实现

```java
class Solution {
    public int[] kthSmallestPrimeFraction(int[] arr, int k) {
        int n = arr.length;
        // 最小堆：(分数值, 分子索引, 分母索引)
        PriorityQueue<int[]> pq = new PriorityQueue<>(
            (a, b) -> arr[a[0]] * arr[b[1]] - arr[b[0]] * arr[a[1]]
        );

        // 初始化：每个分子配最大分母
        for (int i = 0; i < n - 1; i++) {
            pq.offer(new int[]{i, n - 1});
        }

        // 弹出 k-1 次
        for (int i = 0; i < k - 1; i++) {
            int[] curr = pq.poll();
            int numIdx = curr[0], denIdx = curr[1];
            // 同分子，下一个更小的分母
            if (denIdx - 1 > numIdx) {
                pq.offer(new int[]{numIdx, denIdx - 1});
            }
        }

        int[] result = pq.poll();
        return new int[]{arr[result[0]], arr[result[1]]};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **避免交叉乘法比较**：用 a[0]*b[1] vs b[0]*a[1] 避免浮点数
2. **堆初始化**：每个分子配最大分母（最小分数）
3. **堆扩展**：弹出后将分母减小一个
