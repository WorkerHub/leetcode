## 题目描述

若两个字符串中每种字母出现频率差的绝对值都不超过 3，则称它们几乎等价，返回判断结果。

## 解题思路

统计每种字母在两个字符串中的出现次数差，检查所有 26 个字母的绝对差值是否 <= 3。

## Java 代码实现

### 方法一：数组计数（推荐）

```java
class Solution {
    public boolean checkAlmostEquivalent(String word1, String word2) {
        int[] diff = new int[26];
        for (char c : word1.toCharArray()) diff[c - 'a']++;
        for (char c : word2.toCharArray()) diff[c - 'a']--;
        for (int d : diff) if (Math.abs(d) > 3) return false;
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 需检查全部 26 个字母（未出现的差值为 0，满足条件）
2. 一次遍历统计差值，再检查所有差值
