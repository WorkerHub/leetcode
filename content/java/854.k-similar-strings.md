## 题目描述

对于某些非负整数 k ，如果交换 s1 中两个字母的位置恰好 k 次，能够使结果字符串等于 s2 ，则认为字符串 s1 和 s2 的 相似度为 k 。

给你两个字母异位词 s1 和 s2 ，返回 s1 和 s2 的相似度 k 的最小值。

**示例 1：**
```
输入：s1 = "ab", s2 = "ba"
输出：1
```

**示例 2：**
```
输入：s1 = "abc", s2 = "bca"
输出：2
```

**提示：**
- 1 <= s1.length <= 20
- s2.length == s1.length
- s1 和 s2 只包含集合 {'a', 'b', 'c', 'd', 'e', 'f'} 中的小写字母
- s2 是 s1 的一个字母异位词

## 解题思路

这是一道**最短路径问题**，可以用 BFS（广度优先搜索）求解。

**核心观察：**
1. 每次交换看作一次状态转移
2. 我们要找从 s1 到 s2 的最短路径（最少交换次数）
3. BFS 能保证找到最短路径

**优化策略：**
1. **贪心选择**：每次只交换能使 s1[i] == s2[i] 的位置（有意义的交换）
2. **剪枝**：只考虑第一个不匹配位置的交换
3. **去重**：使用 set 记录访问过的状态

**算法流程：**
1. 使用 BFS，队列初始状态为 s1
2. 对于当前字符串，找到第一个不匹配的位置 i
3. 尝试将 i 与后面所有能使 s1[i] == s2[i] 的位置交换
4. 如果交换后的字符串等于 s2，返回步数
5. 否则将新状态加入队列

## Java 代码实现

### 方法一：BFS + 贪心剪枝（推荐）

```java
class Solution {
    public int kSimilarity(String s1, String s2) {
        if (s1.equals(s2)) return 0;

        // BFS：(当前字符串, 交换次数)
        Queue<String> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer(s1);
        visited.add(s1);
        int swaps = 0;

        while (!queue.isEmpty()) {
            swaps++;
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                String curr = queue.poll();

                // 找到第一个不匹配的位置
                int i = 0;
                while (i < curr.length() && curr.charAt(i) == s2.charAt(i)) {
                    i++;
                }

                // 尝试交换 i 与后面的位置
                char[] arr = curr.toCharArray();
                for (int j = i + 1; j < curr.length(); j++) {
                    // 只考虑有意义的交换：arr[j] == s2[i]
                    if (arr[j] == s2.charAt(i)) {
                        // 执行交换
                        char tmp = arr[i];
                        arr[i] = arr[j];
                        arr[j] = tmp;
                        String nextState = new String(arr);

                        // 找到答案
                        if (nextState.equals(s2)) return swaps;

                        // 加入队列
                        if (!visited.contains(nextState)) {
                            visited.add(nextState);
                            queue.offer(nextState);
                        }

                        // 恢复交换
                        tmp = arr[i];
                        arr[i] = arr[j];
                        arr[j] = tmp;
                    }
                }
            }
        }

        return -1;
    }
}
```

**代码说明：**
- 只交换能使 curr[i] == s2[i] 的位置
- 使用 visited 去重，避免重复搜索
- BFS 保证找到最短路径

## 复杂度分析

- **时间复杂度**：O(n! / (k! × (n-k)!))，最坏情况需要遍历很多状态，但剪枝后实际很小。
- **空间复杂度**：O(n!)，visited 集合的大小。

## 图解示例

**示例**：s1 = "abc", s2 = "bca"

```
初始状态：abc
目标状态：bca

第一步：交换位置 0 和 1
abc → bac
现在 bac[0] = b = bca[0] ✓

第二步：交换位置 1 和 2
bac → bca
现在 bca = bca ✓

最少交换次数：2
```

## 关键点总结

1. **BFS 应用**：最短路径问题的经典算法
2. **贪心剪枝**：只考虑第一个不匹配位置，大幅减少搜索空间
3. **有意义的交换**：只交换能让 curr[i] == s2[i] 的位置
4. **去重优化**：使用 visited 集合避免重复状态
5. **字符数组操作**：Java 中字符串不可变，需要转为 char[] 再交换

## 易错点

1. **交换所有位置**：不应该尝试所有可能的交换，只交换有意义的

2. **忘记去重**：会导致重复搜索，超时

3. **字符串不可变**：Java 字符串不可变，需要转为 char[] 再交换，操作完要 new String(arr)

4. **忘记还原**：在同一个 char[] 上做交换时，记得还原（否则下次循环基于错误状态）
