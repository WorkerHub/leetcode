## 题目描述

修复连续k个坑洼需花费k+1预算，给定总预算，求最多修复多少个坑洼。

## 解题思路

贪心：找出所有连续坑洼段长度，按降序排列，优先修长段（性价比高）。预算不足时部分修复。

## Java 代码实现

```java
class Solution {
    public int maxPotholes(String road, int budget) {
        List<Integer> segments = new ArrayList<>();
        int count = 0;
        for (char c : road.toCharArray()) {
            if (c == 'x') {
                count++;
            } else {
                if (count > 0) segments.add(count);
                count = 0;
            }
        }
        if (count > 0) segments.add(count);

        segments.sort(Collections.reverseOrder());
        int ans = 0;
        for (int seg : segments) {
            if (budget <= 1) break;
            int fix = Math.min(seg, budget - 1);
            ans += fix;
            budget -= fix + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **修复k个坑花费k+1**：有固定开销
2. **贪心修最长段**：单位费用最低
3. **部分修复**：预算不够整段时取budget-1个
