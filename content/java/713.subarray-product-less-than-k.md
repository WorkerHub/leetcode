## 题目描述

给定一个正整数数组 `nums` 和整数 `k`，请找出该数组内乘积小于 `k` 的连续的子数组的个数。

**示例 1：**

```
输入：nums = [10,5,2,6], k = 100
输出：8
解释：8 个乘积小于 100 的子数组分别为：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。
需要注意的是 [10,5,2] 并不是乘积小于 100 的子数组。
```

**示例 2：**

```
输入：nums = [1,2,3], k = 0
输出：0
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 10^6`

## 解题思路

这是一道典型的滑动窗口问题。

**核心思想：**
- 使用双指针维护一个窗口，窗口内元素的乘积小于 k
- 对于每个右端点，计算以该端点结尾的符合条件的子数组个数

**关键观察：**
- 如果 `[left, right]` 区间的乘积小于 k
- 那么以 right 为结尾的所有子数组个数为 `right - left + 1`
- 这些子数组为：`[right]`, `[right-1, right]`, ..., `[left, ..., right]`

**算法流程：**
1. 使用 left 和 right 两个指针
2. right 向右扩展，将 `nums[right]` 乘入窗口乘积
3. 如果乘积 >= k，左指针右移，缩小窗口
4. 每次右指针移动后，累加以 right 为结尾的子数组个数

## Java 代码实现

### 方法一：滑动窗口（推荐）⭐

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        // 特殊情况：k <= 1，不可能有乘积小于 k 的子数组
        if (k <= 1) {
            return 0;
        }
        
        int count = 0;
        long product = 1;
        int left = 0;
        
        // 右指针遍历数组
        for (int right = 0; right < nums.length; right++) {
            // 将当前元素乘入窗口
            product *= nums[right];
            
            // 如果乘积 >= k，收缩左边界
            while (product >= k) {
                product /= nums[left];
                left++;
            }
            
            // 以 right 为结尾的子数组个数为 right - left + 1
            count += right - left + 1;
        }
        
        return count;
    }
}
```

### 方法二：详细注释版

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        // 边界情况：k <= 1 时，任何正整数的乘积都不会小于 k
        if (k <= 1) {
            return 0;
        }
        
        int count = 0;    // 符合条件的子数组个数
        long product = 1; // 当前窗口的乘积（用 long 防溢出）
        int left = 0;     // 窗口左边界
        
        for (int right = 0; right < nums.length; right++) {
            // 扩展窗口：右边界右移
            product *= nums[right];
            
            // 收缩窗口：当乘积 >= k 时，左边界右移
            while (left <= right && product >= k) {
                product /= nums[left];
                left++;
            }
            
            // 计算以 right 为右端点的子数组个数
            // 例如：left=1, right=3 时，子数组有 [3], [2,3], [1,2,3] 共 3 个
            count += right - left + 1;
        }
        
        return count;
    }
}
```

## 复杂度分析

### 滑动窗口：
- **时间复杂度：** O(n)，left 和 right 指针最多各移动 n 次
- **空间复杂度：** O(1)

## 关键点总结

1. **滑动窗口模板**：右指针扩展，左指针收缩
2. **计数技巧**：以 right 为右端点的子数组个数 = `right - left + 1`
3. **边界条件**：`k <= 1` 时，返回 0
4. **乘积维护**：使用除法缩小窗口时，避免浮点数运算
5. **long 防溢出**：乘积可能较大，使用 long 类型

## 易错点

1. **k <= 1 的处理**：忘记特判，导致死循环或错误结果
2. **计数公式理解错误**：应该是 `right - left + 1`，不是 1
3. **除法顺序**：先除再移动 left
4. **整数溢出**：使用 long 保存乘积，避免溢出
5. **while 条件**：应该是 `product >= k`，不是 `product > k`
