## 题目描述

从startPos出发最多走k步，沿数轴采摘水果，求最多能采摘的水果总数。

## 解题思路

滑动窗口：最优路径是先走一个方向再折回。对区间[l,r]判断可达性：min(左距,右距)*2+max(左距,右距)<=k。窗口右端右移时左端单调不降。

## Java 代码实现

```java
class Solution {
    public int maxTotalFruits(int[][] fruits, int startPos, int k) {
        int n = fruits.length;
        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + fruits[i][1];
        }
        
        int ans = 0, l = 0;
        for (int r = 0; r < n; r++) {
            // 收缩左边界直到可达
            while (!canReach(fruits, l, r, startPos, k)) {
                l++;
            }
            ans = Math.max(ans, (int)(prefix[r + 1] - prefix[l]));
        }
        return ans;
    }
    
    private boolean canReach(int[][] fruits, int l, int r, int startPos, int k) {
        int leftPos = fruits[l][0];
        int rightPos = fruits[r][0];
        if (leftPos > startPos) {
            return rightPos - startPos <= k;
        }
        if (rightPos < startPos) {
            return startPos - leftPos <= k;
        }
        int goLeft = startPos - leftPos;
        int goRight = rightPos - startPos;
        return Math.min(goLeft, goRight) * 2 + Math.max(goLeft, goRight) <= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **最优路径**：先走一个方向再折回，不会来回多次
2. **可达判断**：min(左距,右距)*2 + max(左距,右距) <= k
3. **滑动窗口**：左边界单调不降保证O(N)
