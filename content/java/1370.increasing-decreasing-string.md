## 题目描述

按规则重新构造字符串：每轮先从小到大各取一个字母，再从大到小各取一个字母，直到所有字符用完，返回结果字符串。

## 解题思路

用长度 26 的计数数组统计各字母频次，每轮正序遍历 a-z 取一个、逆序遍历 z-a 取一个，天然满足"比上一个更大/更小"的条件，重复直到所有字符取完。

## Java 代码实现

```java
class Solution {
    public String sortString(String s) {
        // 统计每个字母的出现次数
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }

        StringBuilder sb = new StringBuilder();
        while (sb.length() < s.length()) {
            // 从小到大：遍历 a 到 z
            for (int i = 0; i < 26; i++) {
                if (freq[i] > 0) {
                    sb.append((char) ('a' + i));
                    freq[i]--;
                }
            }
            // 从大到小：遍历 z 到 a
            for (int i = 25; i >= 0; i--) {
                if (freq[i] > 0) {
                    sb.append((char) ('a' + i));
                    freq[i]--;
                }
            }
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × 26) = O(n)，外层循环最多 n/26+1 次，每轮内层遍历 26 个字母。
- 空间复杂度：O(26) = O(1)，计数数组固定大小。

## 关键点总结

1. 按字母顺序正向/逆向遍历，天然满足"比上一个更大/更小"的条件，无需额外排序。
2. 每轮每个字母最多取一个，需循环直到所有字母用完。
3. 使用 `StringBuilder` 累积结果，避免字符串反复创建的性能开销。
