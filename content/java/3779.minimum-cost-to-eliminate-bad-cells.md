## 题目描述

给定 `m × n` 的矩阵，`0` 表示空格，`1` 表示坏格子。可以花费代价消除坏格子，只能向右或向下移动，求从左上角到右下角的路径中不含坏格子的最小代价。

## 解题思路

0-1 BFS 最短路：每格代价为 `grid[i][j]`（0 或 1），代价为 0 的边放队首，代价为 1 的边放队尾。若只能向右/向下，DP 更简单直接。

## Java 代码实现

```java
class Solution {
    public int minCostPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        for (int[] row : dp) java.util.Arrays.fill(row, Integer.MAX_VALUE);
        dp[0][0] = grid[0][0];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int best = Integer.MAX_VALUE;
                if (i > 0 && dp[i - 1][j] != Integer.MAX_VALUE)
                    best = Math.min(best, dp[i - 1][j]);
                if (j > 0 && dp[i][j - 1] != Integer.MAX_VALUE)
                    best = Math.min(best, dp[i][j - 1]);
                dp[i][j] = best + grid[i][j];
            }
        }

        return dp[m - 1][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. 坏格子代价为 1，好格子代价为 0，求最小代价路径
2. 只能向右/向下时 DP 最优，`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`
3. 起点代价为 `grid[0][0]`（起点本身可能是坏格）
