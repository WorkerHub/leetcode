## 题目描述

给你一个整数数组 `nums`（长度为偶数），将数组分成 `n/2` 对，每对取较大值加入总分。返回可获得的最大总分。

## 解题思路

贪心：排序后将相邻两个元素配对，取每对中的较大值（奇数下标元素）之和。这样保证较小元素尽量与相近的元素配对，最大化较大值之和。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximumSum(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int sum = 0;
        // 排序后相邻配对，取每对较大值（奇数下标）
        for (int i = 1; i < n; i += 2) {
            sum += nums[i];
        }
        return sum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后相邻配对可以最大化每对中较大值之和。
2. 奇数下标元素（1, 3, 5, ...）之和即为所求。
3. 贪心证明：任何非相邻配对方案都不优于相邻配对方案。
