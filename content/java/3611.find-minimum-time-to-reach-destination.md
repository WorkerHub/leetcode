## 题目描述

给定有向加权图，从节点 0 到 `n-1`，在每个节点若当前时间不是 `k` 的倍数需等待到下一个倍数才能出发，返回最短到达时间。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int n, int[][] edges, int k) {
        List<List<int[]>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) graph.get(e[0]).add(new int[]{e[1], e[2]});

        // Dijkstra
        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[0] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int time = cur[0], node = cur[1];
            if (time > dist[node]) continue;
            if (node == n - 1) return time;

            // 计算出发时间（等待到 k 的倍数）
            int depart = (time % k == 0) ? time : time + (k - time % k);

            for (int[] nb : graph.get(node)) {
                int newTime = depart + nb[1];
                if (newTime < dist[nb[0]]) {
                    dist[nb[0]] = newTime;
                    pq.offer(new int[]{newTime, nb[0]});
                }
            }
        }
        return dist[n - 1] == Integer.MAX_VALUE ? -1 : dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)，Dijkstra 标准复杂度
- 空间复杂度：O(V + E)

## 关键点总结

1. Dijkstra 处理带等待时间的最短路
2. 等待时间：`t % k == 0` 时无需等待，否则等 `k - (t % k)` 个单位
3. 出发时间在离开节点时处理，而非到达时
