## 题目描述

二指输入法定制键盘在 `XY` 平面上的布局如下图所示，其中每个大写英文字母都位于某个坐标处：

```
A(0,0) B(0,1) C(0,2) D(0,3) E(0,4) F(0,5)
G(1,0) H(1,1) I(1,2) J(1,3) K(1,4) L(1,5)
M(2,0) N(2,1) O(2,2) P(2,3) Q(2,4) R(2,5)
S(3,0) T(3,1) U(3,2) V(3,3) W(3,4) X(3,5)
Y(4,0) Z(4,1)
```

两根手指的起始位置是零代价的，不计入距离。每次移动手指时，代价为两点的曼哈顿距离：`|row1 - row2| + |col1 - col2|`。

给你一个字符串 `word`，返回使用两根手指输入 `word` 中所有字符的最小移动总距离。

**示例 1：**

```
输入：word = "CAKE"
输出：3
```

**示例 2：**

```
输入：word = "HAPPY"
输出：6
```

**提示：**

- `2 <= word.length <= 300`
- `word` 仅由大写英文字母组成

## 解题思路

**动态规划（DP）**

**状态定义：**

`dp[j]` = 已经输入当前字符，其中一只手指在当前字符上，另一只手指在字母 `j` 上（用 0-25 表示 A-Z，用 26 表示"还未放置"）时的最小总移动距离。

**转移分析：**

对于第 `i+1` 个字符 `word[i+1]`，我们有两种选择：

1. **移动当前手指**（在 word[i] 上的手指）：从 `word[i]` 移到 `word[i+1]`
2. **移动另一只手指**（在 j 上的手指）：从 `j` 移到 `word[i+1]`

## Java 代码实现

### 方法一：动态规划（推荐）

```java
import java.util.*;

class Solution {
    public int minimumDistance(String word) {
        int n = word.length();
        int INF = Integer.MAX_VALUE / 2;
        
        // dp[j] 表示：一只手在当前字符，另一只手在字母 j 时的最小代价
        // j = 26 表示另一只手还未放置
        int[] dp = new int[27];
        Arrays.fill(dp, INF);
        dp[26] = 0; // 初始状态：两只手都未放置，代价为 0
        
        for (int i = 0; i < n - 1; i++) {
            int curr = word.charAt(i) - 'A';
            int nxt = word.charAt(i + 1) - 'A';
            int[] newDp = new int[27];
            Arrays.fill(newDp, INF);
            
            for (int j = 0; j < 27; j++) {
                if (dp[j] == INF) continue;
                
                // 选择1：移动"当前手指"（在 word[i] 上的）去打 word[i+1]
                // 另一只手仍在 j
                int cost1 = dp[j] + dist(curr, nxt);
                if (cost1 < newDp[j]) newDp[j] = cost1;
                
                // 选择2：移动"另一只手指"（在 j 上的）去打 word[i+1]
                // 当前手指仍在 word[i]，变为新的"另一只手"
                int cost2 = dp[j] + dist(j, nxt);
                if (cost2 < newDp[curr]) newDp[curr] = cost2;
            }
            
            dp = newDp;
        }
        
        int result = INF;
        for (int v : dp) result = Math.min(result, v);
        return result;
    }
    
    // 计算字母 a 和 b 之间的曼哈顿距离
    // 26 表示"未放置"，移动代价为 0
    private int dist(int a, int b) {
        if (a == 26) return 0;
        return Math.abs(a / 6 - b / 6) + Math.abs(a % 6 - b % 6);
    }
}
```

### 方法二：记忆化搜索（自顶向下）

```java
import java.util.*;

class Solution {
    private int n;
    private String word;
    private int[][] memo;
    
    public int minimumDistance(String word) {
        this.n = word.length();
        this.word = word;
        this.memo = new int[n][27];
        for (int[] row : memo) Arrays.fill(row, -1);
        
        return dp(0, 26); // 初始：两只手都未放置
    }
    
    private int dp(int i, int other) {
        if (i == n - 1) return 0; // 已输入所有字符
        if (memo[i][other] != -1) return memo[i][other];
        
        int curr = word.charAt(i) - 'A';
        int nxt = word.charAt(i + 1) - 'A';
        
        // 选择1：移动当前手指到下一个字符
        int moveCurrent = dist(curr, nxt) + dp(i + 1, other);
        
        // 选择2：移动另一只手到下一个字符，当前手停在 curr
        int moveOther = dist(other, nxt) + dp(i + 1, curr);
        
        return memo[i][other] = Math.min(moveCurrent, moveOther);
    }
    
    private int dist(int a, int b) {
        if (a == 26) return 0;
        return Math.abs(a / 6 - b / 6) + Math.abs(a % 6 - b % 6);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * 27)，n 为 word 长度，每个位置枚举另一只手的 27 种状态
- **空间复杂度**：O(27) = O(1)，滚动数组优化后只需常数空间

## 关键点总结

1. 状态设计：`dp[j]` 表示"一手在当前字符，另一手在 j"的最小代价
2. j=26 代表"另一只手还没有放置"，此时移动代价为 0
3. 每次转移有两种选择：移动"当前手"或移动"另一只手"
4. 键盘布局：字母 x 的坐标为 `(x/6, x%6)`（x 是 0-25 的整数）

## 易错点

1. **键盘布局**：每行 6 个字母（A-F, G-L, M-R, S-X, Y-Z），字母 x 的行为 `x/6`，列为 `x%6`
2. **未放置手指的距离为 0**：初始状态两只手都未放置，第一次放置不计代价
3. **DP 滚动**：必须先用 `newDp` 保存更新结果，不能在同一个 `dp` 数组上就地更新
4. **Java 中整数除法**：`a / 6` 是整数除法，与 Python 的 `a // 6` 相同
