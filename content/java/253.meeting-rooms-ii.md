## 题目描述

给你一个会议时间安排的数组 `intervals`，每个会议时间都会包括开始和结束的时间 `intervals[i] = [starti, endi]`，返回所需会议室的最小数量。

**示例 1：**

```
输入：intervals = [[0,30],[5,10],[15,20]]
输出：2
解释：
- 会议1: [0,30]
- 会议2: [5,10]
- 会议3: [15,20]
在时间点 5，会议1和会议2同时进行，需要 2 个会议室
```

**示例 2：**

```
输入：intervals = [[7,10],[2,4]]
输出：1
解释：两个会议不重叠，只需要 1 个会议室
```

**提示：**
- `1 <= intervals.length <= 10^4`
- `0 <= starti < endi <= 10^6`

## 解题思路

这道题是 252 题的进阶版，不仅要判断是否冲突，还要求出最少需要多少个会议室。

核心思想有两种：

### 思路一：最小堆（优先队列）

1. 将所有会议按开始时间排序
2. 使用最小堆维护当前正在使用的会议室的结束时间
3. 对于每个新会议：
   - 如果堆顶（最早结束的会议）已经结束，可以复用这个会议室
   - 否则，需要分配新的会议室
4. 堆的大小就是同时需要的最多会议室数量

### 思路二：双指针（扫描线）

1. 分别提取所有会议的开始时间和结束时间
2. 对这两个数组分别排序
3. 使用双指针扫描：
   - 遇到开始时间，会议室数量 +1
   - 遇到结束时间，会议室数量 -1
4. 记录过程中的最大值

## Java 代码实现

### 方法一：最小堆（推荐）⭐

```java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return 0;

        // 按照会议开始时间排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        // 最小堆，存储每个会议室的结束时间（堆顶是最早结束的会议）
        PriorityQueue<Integer> heap = new PriorityQueue<>();

        // 遍历每个会议
        for (int[] interval : intervals) {
            int start = interval[0], end = interval[1];

            // 如果最早结束的会议已经结束，可以复用该会议室
            if (!heap.isEmpty() && heap.peek() <= start) {
                heap.poll();
            }

            // 将当前会议的结束时间加入堆
            heap.offer(end);
        }

        // 堆的大小就是需要的最少会议室数量
        return heap.size();
    }
}
```

### 方法二：双指针扫描线（推荐）⭐

```java
import java.util.Arrays;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return 0;

        int n = intervals.length;

        // 分别提取开始时间和结束时间
        int[] starts = new int[n];
        int[] ends = new int[n];
        for (int i = 0; i < n; i++) {
            starts[i] = intervals[i][0];
            ends[i] = intervals[i][1];
        }

        // 分别排序
        Arrays.sort(starts);
        Arrays.sort(ends);

        int rooms = 0;    // 当前使用的会议室数量
        int maxRooms = 0; // 需要的最大会议室数量
        int startPtr = 0; // 开始时间指针
        int endPtr = 0;   // 结束时间指针

        // 使用双指针扫描
        while (startPtr < n) {
            // 如果当前开始时间 < 最早结束时间，需要新会议室
            if (starts[startPtr] < ends[endPtr]) {
                rooms++;
                maxRooms = Math.max(maxRooms, rooms);
                startPtr++;
            } else {
                // 有会议结束，释放一个会议室
                rooms--;
                endPtr++;
            }
        }

        return maxRooms;
    }
}
```

### 方法三：事件排序（更直观的扫描线）

```java
import java.util.Arrays;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        int n = intervals.length;

        // 创建事件数组：[时间, 类型]
        // 开始事件类型为 1，结束事件类型为 -1
        int[][] events = new int[2 * n][2];
        for (int i = 0; i < n; i++) {
            events[2 * i] = new int[]{intervals[i][0], 1};     // 会议开始
            events[2 * i + 1] = new int[]{intervals[i][1], -1}; // 会议结束
        }

        // 排序：先按时间，时间相同时结束事件优先于开始事件（-1 < 1）
        Arrays.sort(events, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        int rooms = 0, maxRooms = 0;
        for (int[] event : events) {
            rooms += event[1];
            maxRooms = Math.max(maxRooms, rooms);
        }

        return maxRooms;
    }
}
```

## 复杂度分析

**方法一（最小堆）：**
- 时间复杂度：O(n log n)，排序 O(n log n) + 堆操作 O(n log n)
- 空间复杂度：O(n)，堆的大小最多为 n

**方法二（双指针）：**
- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(n)，需要存储开始和结束时间数组

## 关键点总结

1. **排序是基础**：所有方法都需要先排序或处理时间顺序
2. **最小堆的意义**：维护最早结束的会议，判断能否复用会议室
3. **扫描线思想**：将问题转化为处理开始和结束事件
4. **双指针技巧**：分别处理有序的开始和结束时间
5. **贪心策略**：总是优先复用最早结束的会议室

## 易错点

1. **堆中存储的内容**
   ```java
   // 错误：存储整个区间
   heap.offer(Arrays.toString(interval));

   // 正确：只存储结束时间
   heap.offer(interval[1]);
   ```

2. **双指针的比较条件**
   ```java
   // 注意使用 < 而不是 <=
   // 如果一个会议刚好结束，另一个开始，可以复用会议室
   if (starts[startPtr] < ends[endPtr]) {
       rooms++;
   }
   ```

3. **事件排序的优先级**
   ```java
   // 结束事件应该优先于开始事件（-1 < 1）
   // 这样可以在时间相同时先释放会议室
   Arrays.sort(events, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
   ```

4. **忘记更新最大值**：在双指针方法中，要实时更新 `maxRooms`
