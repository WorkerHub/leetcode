## 题目描述

给你 `m x n` 偶数矩阵 `grid` 和整数 `k`，对每一层元素顺时针循环旋转 k 次，返回旋转后的矩阵。

## 解题思路

将每层元素按顺时针顺序提取为一维数组，取 `k % len` 后进行循环位移，再写回原位置。

## Java 代码实现

```java
class Solution {
    public int[][] rotateGrid(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        int numLayers = Math.min(m, n) / 2;

        for (int layer = 0; layer < numLayers; layer++) {
            // 提取该层元素（顺时针）
            List<Integer> elems = extractLayer(grid, layer, m, n);
            int L = elems.size();
            int shift = k % L;
            // 右旋 shift 步
            List<Integer> rotated = new java.util.ArrayList<>();
            rotated.addAll(elems.subList(L - shift, L));
            rotated.addAll(elems.subList(0, L - shift));
            // 写回
            writeLayer(grid, layer, m, n, rotated);
        }
        return grid;
    }

    private java.util.List<Integer> extractLayer(int[][] grid, int layer, int m, int n) {
        java.util.List<Integer> elems = new java.util.ArrayList<>();
        int top = layer, bot = m - 1 - layer;
        int left = layer, right = n - 1 - layer;
        for (int j = left; j < right; j++) elems.add(grid[top][j]);       // 上边
        for (int i = top; i < bot; i++) elems.add(grid[i][right]);        // 右边
        for (int j = right; j > left; j--) elems.add(grid[bot][j]);       // 下边
        for (int i = bot; i > top; i--) elems.add(grid[i][left]);         // 左边
        return elems;
    }

    private void writeLayer(int[][] grid, int layer, int m, int n, java.util.List<Integer> elems) {
        int top = layer, bot = m - 1 - layer;
        int left = layer, right = n - 1 - layer;
        int idx = 0;
        for (int j = left; j < right; j++) grid[top][j] = elems.get(idx++);
        for (int i = top; i < bot; i++) grid[i][right] = elems.get(idx++);
        for (int j = right; j > left; j--) grid[bot][j] = elems.get(idx++);
        for (int i = bot; i > top; i--) grid[i][left] = elems.get(idx++);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn)
- **空间复杂度**：O(min(m, n))，每层提取的数组

## 关键点总结

1. 将每层元素提取为一维数组，右旋 k%L 步后写回
2. `k % L` 避免无效的重复旋转
3. 提取和写回的顺序必须完全一致（顺时针）
