## 题目描述

给你字符串 `s` 和整数 `t`，每次转换将每个字符替换为下一个字母（'z' 变为 "ab"），返回 `t` 次转换后字符串的长度（模 10^9+7）。

## 解题思路

只需统计各字母数量，不需要实际构造字符串。每次转换：字符 i(0-24) 的数量转移到 i+1；字符 z(25) 的数量分别贡献给 a(0) 和 b(1)。循环 t 次，最终求所有字母数量之和。

## Java 代码实现

```java
class Solution {
    public int lengthAfterTransformations(String s, int t) {
        final int MOD = 1_000_000_007;
        long[] cnt = new long[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        for (int round = 0; round < t; round++) {
            long[] newCnt = new long[26];
            for (int i = 0; i < 25; i++)
                newCnt[i + 1] = (newCnt[i + 1] + cnt[i]) % MOD;
            // 'z' -> 'a' + 'b'
            newCnt[0] = (newCnt[0] + cnt[25]) % MOD;
            newCnt[1] = (newCnt[1] + cnt[25]) % MOD;
            cnt = newCnt;
        }

        long ans = 0;
        for (long v : cnt) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26 * t)，每轮更新 26 个字母
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 只统计各字母数量，避免实际构造字符串
2. 'z'(25) 转换时同时贡献给 'a'(0) 和 'b'(1)
3. 每轮需要新数组，不能原地修改
