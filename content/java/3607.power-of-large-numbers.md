## 题目描述

给定用字符串表示的大整数 `base` 和 `exp`，返回 `base^exp` 对 `10^9 + 7` 取模的结果。

## Java 代码实现

```java
import java.math.BigInteger;

class Solution {
    public int powerOfLargeNumbers(String base, String exp) {
        int MOD = 1_000_000_007;
        BigInteger b = new BigInteger(base);
        BigInteger e = new BigInteger(exp);
        // BigInteger.modPow 高效计算大整数模幂
        return b.modPow(e, BigInteger.valueOf(MOD)).intValue();
    }
}
```

## 复杂度分析

- 时间复杂度：O(len(exp) * len(base)^2)，BigInteger 快速幂
- 空间复杂度：O(len(base) + len(exp))

## 关键点总结

1. Java `BigInteger.modPow(exp, mod)` 直接支持大整数模幂运算
2. 快速幂将时间复杂度从 O(exp) 降低到 O(log exp)
3. 取模运算在每步乘法后进行，防止中间结果无限增大
