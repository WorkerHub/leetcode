## 题目描述

每次操作可将一个元素+1，至多k次操作后，求数组中频率最高元素的最大频率。

## 解题思路

排序+滑动窗口：将窗口内所有元素变为nums[r]的代价 = nums[r]*窗口大小 - 窗口和。保持代价≤k，维护最大窗口。

## Java 代码实现

```java
class Solution {
    public int maxFrequency(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        long windowSum = 0;
        int left = 0, result = 1;
        
        for (int right = 0; right < n; right++) {
            windowSum += nums[right];
            // 代价 = nums[right] * 窗口大小 - 窗口和
            while ((long) nums[right] * (right - left + 1) - windowSum > k) {
                windowSum -= nums[left];
                left++;
            }
            result = Math.max(result, right - left + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后目标是窗口最大值**：将所有元素变成nums[r]
2. **代价公式**：nums[r]*windowSize - windowSum
3. **long防溢出**：乘法可能溢出int
