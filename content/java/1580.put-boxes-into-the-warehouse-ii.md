## 题目描述

与题 1564 类似，但可从左边或右边推入箱子。返回最多能放入的箱子数。

## 解题思路

双向预处理：每个位置有效高度 = max(左前缀最小值, 右后缀最小值)。排序后双指针贪心匹配。

## Java 代码实现

```java
class Solution {
    public int maxBoxesInWarehouse(int[] boxes, int[] warehouse) {
        int n = warehouse.length;
        // 从左的前缀最小值
        int[] leftMin = new int[n];
        leftMin[0] = warehouse[0];
        for (int i = 1; i < n; i++) {
            leftMin[i] = Math.min(leftMin[i - 1], warehouse[i]);
        }
        // 从右的后缀最小值
        int[] rightMin = new int[n];
        rightMin[n - 1] = warehouse[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMin[i] = Math.min(rightMin[i + 1], warehouse[i]);
        }
        // 有效高度 = max(左进, 右进)
        int[] effective = new int[n];
        for (int i = 0; i < n; i++) {
            effective[i] = Math.max(leftMin[i], rightMin[i]);
        }
        
        Arrays.sort(effective);
        Arrays.sort(boxes);
        
        int ans = 0, bi = 0;
        for (int i = 0; i < n && bi < boxes.length; i++) {
            if (boxes[bi] <= effective[i]) {
                ans++;
                bi++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + m log m)
- **空间复杂度**：O(n)

## 关键点总结

1. **双向进入**：有效高度取 max（选更好的方向）
2. **与题1564区别**：1564 只能从左进，有效高度取前缀最小
3. **贪心匹配**：排序后小箱子放小格子
