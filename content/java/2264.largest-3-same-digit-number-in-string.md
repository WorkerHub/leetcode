## 题目描述

返回字符串中最大的由3个相同数字组成的子串，不存在返回空字符串。

## 解题思路

从9到0枚举，检查"ddd"是否在字符串中，返回第一个找到的。

## Java 代码实现

```java
class Solution {
    public String largestGoodInteger(String num) {
        for (char d = '9'; d >= '0'; d--) {
            String target = "" + d + d + d;
            if (num.contains(target)) return target;
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(10 * N) = O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **只有10种可能**：从"999"到"000"
2. **从大到小枚举**：第一个找到的即为最大
3. **"000"也是合法答案**
