## 题目描述

跳蚤从位置 0 出发，目标位置 `x`，每次可向前跳 `a` 或向后跳 `b`（不能连续向后跳两次），不能停在 `forbidden` 中的位置。返回最少跳数，不可达返回 `-1`。

## 解题思路

**BFS：** 状态为 `(位置, 上一跳是否向后)`。设搜索上界为 `max(forbidden) + a + b`，BFS 找最短路。

## Java 代码实现

```java
class Solution {
    public int minimumJumps(int[] forbidden, int a, int b, int x) {
        Set<Integer> forbiddenSet = new HashSet<>();
        for (int f : forbidden) forbiddenSet.add(f);

        // 搜索上界
        int upper = x + a + b;
        for (int f : forbidden) upper = Math.max(upper, f + a + b);

        // BFS：状态 (pos, back) -> back=1 表示上一跳向后
        boolean[][] visited = new boolean[upper + 1][2];
        visited[0][0] = true;

        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0, 0}); // (位置, 上一跳是否向后, 步数)

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int pos = curr[0], back = curr[1], steps = curr[2];

            if (pos == x) return steps;

            // 向前跳
            int np = pos + a;
            if (np <= upper && !forbiddenSet.contains(np) && !visited[np][0]) {
                visited[np][0] = true;
                queue.offer(new int[]{np, 0, steps + 1});
            }

            // 向后跳（不能连续向后）
            if (back == 0) {
                np = pos - b;
                if (np > 0 && !forbiddenSet.contains(np) && !visited[np][1]) {
                    visited[np][1] = true;
                    queue.offer(new int[]{np, 1, steps + 1});
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(upper)，upper ≈ max(forbidden) + a + b
- **空间复杂度**：O(upper)

## 关键点总结

1. 状态包含"上一跳是否向后"，因为不能连续向后跳
2. 搜索上界：`max(forbidden) + a + b`（更大位置无意义）
3. BFS 保证找到最少跳数
