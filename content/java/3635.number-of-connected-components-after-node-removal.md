## 题目描述

给定 `n` 个节点的无向图，对每个节点 `i`，返回移除节点 `i` 及其关联边后剩余图的连通分量数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countComponents(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        int[] ans = new int[n];
        for (int skip = 0; skip < n; skip++) {
            boolean[] visited = new boolean[n];
            visited[skip] = true;  // 标记被移除节点
            int cc = 0;
            for (int i = 0; i < n; i++) {
                if (!visited[i]) {
                    cc++;
                    // BFS 遍历该连通分量
                    Queue<Integer> q = new LinkedList<>();
                    q.offer(i);
                    visited[i] = true;
                    while (!q.isEmpty()) {
                        int u = q.poll();
                        for (int v : graph.get(u)) {
                            if (!visited[v]) {
                                visited[v] = true;
                                q.offer(v);
                            }
                        }
                    }
                }
            }
            ans[skip] = cc;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * (n + E))，每个节点做一次 BFS
- 空间复杂度：O(n + E)

## 关键点总结

1. 移除节点等价于将其标记为"已访问"再做 BFS/DFS
2. 对每个起点计数独立连通分量，累加 `cc`
3. 被移除的节点本身不计入分量数
