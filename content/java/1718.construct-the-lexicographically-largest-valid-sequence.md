## 题目描述

构造长度 `2n-1` 的序列：1 出现一次，2 到 n 各出现两次，数字 `i` 两次出现之间的距离恰好为 `i`，返回字典序最大的方案。

## 解题思路

**回溯：** 从第一个空位开始，从大到小尝试放置数字（保证字典序最大）。数字 `i >= 2` 需同时占 `pos` 和 `pos + i` 两个位置；1 只占一个位置。放置成功则递归下一空位，否则回溯。

## Java 代码实现

```java
class Solution {
    private int[] result;
    private boolean[] used;
    private int n;

    public int[] constructDistancedSequence(int n) {
        this.n = n;
        result = new int[2 * n - 1];
        used = new boolean[n + 1];
        backtrack(0);
        return result;
    }

    private boolean backtrack(int pos) {
        // 跳过已填充的位置
        while (pos < result.length && result[pos] != 0) pos++;
        if (pos == result.length) return true;

        // 从大到小尝试，保证字典序最大
        for (int num = n; num >= 1; num--) {
            if (used[num]) continue;
            if (num == 1) {
                result[pos] = 1;
                used[1] = true;
                if (backtrack(pos + 1)) return true;
                result[pos] = 0;
                used[1] = false;
            } else {
                int second = pos + num;
                if (second < result.length && result[second] == 0) {
                    result[pos] = num;
                    result[second] = num;
                    used[num] = true;
                    if (backtrack(pos + 1)) return true;
                    result[pos] = 0;
                    result[second] = 0;
                    used[num] = false;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：最坏 O(n!)，实际因剪枝较快
- **空间复杂度**：O(n)

## 关键点总结

1. 从大到小放置数字，保证字典序最大
2. 数字 i 需同时占 pos 和 pos+i 两个位置
3. 回溯时清除两个位置的值
