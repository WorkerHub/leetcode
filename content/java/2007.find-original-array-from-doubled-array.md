## 题目描述

数组 `changed` 由原始数组 `original` 的每个元素 x 以及 2x 混合而成，给定 `changed` 还原 `original`，不合法则返回空数组。

## 解题思路

排序后从小到大贪心匹配：每次取最小未使用元素 x，若 2x 存在则 x 是原始元素（消耗 x 和 2x 各一个），否则不合法。特殊处理 x=0（需要成对出现）。

## Java 代码实现

### 方法一：排序 + 哈希计数（推荐）

```java
import java.util.*;

class Solution {
    public int[] findOriginalArray(int[] changed) {
        if (changed.length % 2 != 0) return new int[0];

        Arrays.sort(changed);
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : changed) count.merge(x, 1, Integer::sum);

        int[] result = new int[changed.length / 2];
        int idx = 0;

        for (int x : changed) {
            if (count.getOrDefault(x, 0) == 0) continue; // 已被消耗
            if (count.getOrDefault(2 * x, 0) == 0) return new int[0]; // 找不到2x

            result[idx++] = x;
            count.merge(x, -1, Integer::sum);
            count.merge(2 * x, -1, Integer::sum);
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后从小到大处理，保证先用小值做原始元素（贪心正确性）
2. 用哈希计数表跟踪每个元素剩余数量，x=0 时 2*0=0 自然成对处理
3. `changed.length` 必须是偶数，否则直接返回空数组
