## 题目描述

给你一个 `m x n` 的矩阵 `grid`，矩阵中的元素**无论是按行还是按列，都以非递增顺序排列**。

请你统计并返回 `grid` 中 **负数** 的数目。

**示例 1：**
```
输入：grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]
输出：8
```

**示例 2：**
```
输入：grid = [[3,2],[1,0]]
输出：0
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `-100 <= grid[i][j] <= 100`
- `grid` 的每行和每列都是非递增排列的

## 解题思路

本题矩阵按行列均非递增排列，即每行从左到右递减，每列从上到下递减。

**三种思路：**

1. **暴力遍历**：O(m*n)，逐个检查是否为负数，代码最简单。
2. **逐行二分查找**：O(m*log(n))，对每行用二分查找第一个负数的位置，该位置右侧的数全为负。
3. **从右上角遍历**：O(m+n)，利用矩阵的有序性，从右上角开始，遇到非负数则向左移，遇到负数则当前列从该行到最后一行都是负数，向下移动。

对于本题约束范围（m,n <= 100），三种方法都够用，但理解方法三的思想对做更难的矩阵题有帮助。

## Java 代码实现

### 方法一：暴力遍历（最简单）

```java
class Solution {
    public int countNegatives(int[][] grid) {
        int count = 0;
        for (int[] row : grid) {
            for (int val : row) {
                if (val < 0) count++;
            }
        }
        return count;
    }
}
```

### 方法二：逐行二分查找（推荐）

```java
class Solution {
    public int countNegatives(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int count = 0;
        
        for (int[] row : grid) {
            // 每行是非递增的，找第一个负数的下标
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (row[mid] < 0) {
                    hi = mid; // 负数，尝试更左边
                } else {
                    lo = mid + 1; // 非负数，向右
                }
            }
            // lo 是第一个负数的下标，负数个数为 n - lo
            count += n - lo;
        }
        return count;
    }
}
```

### 方法三：从右上角遍历（O(m+n)，最优）

```java
class Solution {
    public int countNegatives(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int count = 0;
        // 从右上角 (0, n-1) 开始
        int r = 0, c = n - 1;
        
        while (r < m && c >= 0) {
            if (grid[r][c] < 0) {
                // 当前位置是负数
                // 由于每列非递增，该列从第 r 行到最后一行都是负数
                // 本列负数有 m - r 个
                count += m - r;
                c--; // 向左移一列
            } else {
                // 当前位置非负，向下移一行
                r++;
            }
        }
        
        return count;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 暴力遍历 | O(m*n) | O(1) |
| 逐行二分 | O(m*log n) | O(1) |
| 右上角遍历 | O(m+n) | O(1) |

## 图解示例

以 `grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]` 为例，方法三的遍历过程：

```
初始位置：(0, 3)，值 = -1 < 0
  -> 该列（列3）从第0行到第3行都是负数，count += 4，c=2

位置 (0, 2)，值 = 2 >= 0
  -> 向下，r=1

位置 (1, 2)，值 = 1 >= 0
  -> 向下，r=2

位置 (2, 2)，值 = -1 < 0
  -> 该列（列2）从第2行到第3行都是负数，count += 2，c=1

位置 (2, 1)，值 = 1 >= 0
  -> 向下，r=3

位置 (3, 1)，值 = -1 < 0
  -> 该列（列1）从第3行到第3行都是负数，count += 1，c=0

位置 (3, 0)，值 = -1 < 0
  -> 该列（列0）从第3行到第3行都是负数，count += 1，c=-1

c < 0，结束，count = 4+2+1+1 = 8
```

## 关键点总结

1. 矩阵非递增排列的性质可以被充分利用，避免逐个检查。
2. 逐行二分查找：每行找第一个负数下标，负数个数 = n - 该下标。
3. 右上角遍历：利用"行从左到右不增，列从上到下不增"的单调性，每步排除一行或一列，总步数最多 m+n。
4. 对于面试，能说出三种方法并分析复杂度会加分。

## 易错点

- 二分查找时注意边界：寻找"第一个小于 0 的位置"，`hi` 的初始值应为 `n`（不是 `n-1`），因为可能整行都是负数。
- 右上角遍历中，`count += m - r` 是加上从当前行到最后一行的负数个数，不是 `m`。
- 注意矩阵是"非递增"而非"严格递减"，相邻元素可以相等。
