## 题目描述

N 叉树中，将 p 子树移动到 q 下面。若 p 已是 q 子节点不操作；若 q 在 p 子树中，需先处理。

## 解题思路

DFS 找父节点，判断 q 是否在 p 子树中。分情况处理：从原位置移除 p，若 q 在 p 子树中先将 q 提升，最后将 p 加入 q 的 children。

## Java 代码实现

```java
class Solution {
    public Node moveSubTree(Node root, Node p, Node q) {
        if (q.children.contains(p)) return root; // p 已是 q 子节点（题意是 p 是 q 的子节点）
        
        // 找父节点
        Map<Node, Node> parent = new HashMap<>();
        parent.put(root, null);
        findParents(root, parent);
        
        // 判断 q 是否在 p 的子树中
        boolean qUnderP = isAncestor(p, q);
        
        // 从 p 的父节点中移除 p
        Node pParent = parent.get(p);
        if (pParent != null) pParent.children.remove(p);
        
        if (qUnderP) {
            // q 在 p 子树中：将 q 的子树提升到 p 原位置
            Node qParent = parent.get(q);
            qParent.children.remove(q);
            if (pParent != null) {
                pParent.children.add(q);
            }
            // q 变成新的位置
        }
        
        // 将 p 加入 q 的 children
        q.children.add(p);
        
        if (pParent == null && !qUnderP) return q; // root 被移走了
        if (pParent == null && qUnderP) return q;
        return root;
    }
    
    private void findParents(Node node, Map<Node, Node> parent) {
        for (Node child : node.children) {
            parent.put(child, node);
            findParents(child, parent);
        }
    }
    
    private boolean isAncestor(Node ancestor, Node target) {
        if (ancestor == target) return true;
        for (Node child : ancestor.children) {
            if (isAncestor(child, target)) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **父节点映射**：DFS 构建
2. **祖先判断**：q 是否在 p 子树中
3. **分情况处理**：q 在/不在 p 子树中逻辑不同
4. **根节点特判**：p 为根时需更换根
