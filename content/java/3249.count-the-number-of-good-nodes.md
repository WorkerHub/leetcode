## 题目描述

给你一棵以节点 0 为根的 `n` 个节点无向树，若一个节点的所有子树大小相同则称为好节点，返回好节点数量。

## 解题思路

DFS 后序遍历：对每个节点计算所有子树大小，若所有子树大小相同（或无子节点），则该节点是好节点。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<List<Integer>> graph;
    private int ans = 0;

    public int countGoodNodes(int n, int[][] edges) {
        graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        dfs(0, -1);
        return ans;
    }

    private int dfs(int node, int parent) {
        int totalSize = 1;
        int firstChildSize = -1;
        boolean isGood = true;
        for (int child : graph.get(node)) {
            if (child == parent) continue;
            int childSize = dfs(child, node);
            // 检查所有子树大小是否相同
            if (firstChildSize == -1) {
                firstChildSize = childSize;
            } else if (childSize != firstChildSize) {
                isGood = false;
            }
            totalSize += childSize;
        }
        if (isGood) ans++;
        return totalSize;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. DFS 后序遍历，先计算子节点再判断当前节点
2. 好节点条件：所有子树大小相同（叶节点自动满足）
3. 无向树 DFS 需记录父节点避免回头
