## 题目描述

给你无向**连通**图中一个节点的引用，请你返回该图的**深拷贝**（克隆）。

图中的每个节点都包含它的值 `val`（`int`）和其邻居的列表（`List[Node]`）。

```
class Node {
    public int val;
    public List<Node> neighbors;
}
```

**测试用例格式：**

简单起见，每个节点的值都和它的索引相同。例如，第一个节点值为 1（`val = 1`），第二个节点值为 2（`val = 2`），以此类推。该图在测试用例中使用邻接列表表示。

**邻接列表**是用于表示有限图的无序列表的集合。每个列表都描述了图中节点的邻居集。

给定节点将始终是图中的第一个节点（值为 1）。你必须将**给定节点的拷贝**作为对克隆图的引用返回。

**示例 1：**
```
输入: adjList = [[2,4],[1,3],[2,4],[1,3]]
输出: [[2,4],[1,3],[2,4],[1,3]]
解释:
图中有 4 个节点。
节点 1 的值是 1，它有两个邻居：节点 2 和 4 。
节点 2 的值是 2，它有两个邻居：节点 1 和 3 。
节点 3 的值是 3，它有两个邻居：节点 2 和 4 。
节点 4 的值是 4，它有两个邻居：节点 1 和 3 。
```

**示例 2：**
```
输入: adjList = [[]]
输出: [[]]
解释: 输入包含一个空列表。该图仅仅只有一个值为 1 的节点，它没有任何邻居。
```

**示例 3：**
```
输入: adjList = []
输出: []
解释: 这个图是空的，它不含任何节点。
```

**提示：**
- 图中节点数在 `[0, 100]` 范围内
- `1 <= Node.val <= 100`
- 每个节点值 `Node.val` 都是唯一的
- 图中没有重复的边，也没有自环
- 图是连通的，从给定节点可以访问到所有节点

## 解题思路

这是一道经典的**图的深拷贝**问题，核心是处理**节点的引用关系**。

### 核心难点：

1. **避免重复克隆**：一个节点可能被多个节点引用，需要用哈希表记录已克隆的节点
2. **保持引用关系**：克隆图的节点之间要保持与原图相同的连接关系
3. **处理循环引用**：图中可能有环，需要避免无限递归

### 解法思路：

**使用哈希表 + DFS/BFS**

- **哈希表**：`{原节点: 克隆节点}` 映射关系
  - 避免重复克隆
  - 建立新旧节点对应关系
- **DFS/BFS**：遍历图的所有节点
  - 克隆节点
  - 建立邻居关系

### 算法步骤（DFS）：

1. 如果节点为空，返回 null
2. 如果节点已克隆（在哈希表中），直接返回克隆节点
3. 创建新节点（值相同）
4. 将映射关系加入哈希表
5. 递归克隆所有邻居节点
6. 返回克隆节点

## Java 代码实现

### 方法一：DFS + 哈希表（推荐）⭐

```java
class Solution {
    // 哈希表：{原节点: 克隆节点}
    private Map<Node, Node> visited = new HashMap<>();
    
    public Node cloneGraph(Node node) {
        if (node == null) {
            return null;
        }
        
        // 已经克隆过，直接返回
        if (visited.containsKey(node)) {
            return visited.get(node);
        }
        
        // 克隆当前节点
        Node clone = new Node(node.val, new ArrayList<>());
        visited.put(node, clone);
        
        // 递归克隆所有邻居
        for (Node neighbor : node.neighbors) {
            clone.neighbors.add(cloneGraph(neighbor));
        }
        
        return clone;
    }
}
```

### 方法二：BFS + 哈希表

```java
class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) {
            return null;
        }
        
        // 哈希表：{原节点: 克隆节点}
        Map<Node, Node> visited = new HashMap<>();
        visited.put(node, new Node(node.val, new ArrayList<>()));
        
        // BFS 队列
        Queue<Node> queue = new ArrayDeque<>();
        queue.offer(node);
        
        while (!queue.isEmpty()) {
            Node current = queue.poll();
            
            // 遍历当前节点的所有邻居
            for (Node neighbor : current.neighbors) {
                if (!visited.containsKey(neighbor)) {
                    // 克隆邻居节点
                    visited.put(neighbor, new Node(neighbor.val, new ArrayList<>()));
                    queue.offer(neighbor);
                }
                // 建立克隆节点之间的连接
                visited.get(current).neighbors.add(visited.get(neighbor));
            }
        }
        
        return visited.get(node);
    }
}
```

### 方法三：迭代 DFS（使用栈）

```java
class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) {
            return null;
        }
        
        Map<Node, Node> visited = new HashMap<>();
        visited.put(node, new Node(node.val, new ArrayList<>()));
        Deque<Node> stack = new ArrayDeque<>();
        stack.push(node);
        
        while (!stack.isEmpty()) {
            Node current = stack.pop();
            
            for (Node neighbor : current.neighbors) {
                if (!visited.containsKey(neighbor)) {
                    // 克隆邻居
                    visited.put(neighbor, new Node(neighbor.val, new ArrayList<>()));
                    stack.push(neighbor);
                }
                // 建立连接
                visited.get(current).neighbors.add(visited.get(neighbor));
            }
        }
        
        return visited.get(node);
    }
}
```

### 方法四：两遍遍历（先克隆节点，再建立连接）

```java
class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) {
            return null;
        }
        
        Map<Node, Node> visited = new HashMap<>();
        
        // 第一遍：克隆所有节点
        Queue<Node> queue = new ArrayDeque<>();
        queue.offer(node);
        visited.put(node, new Node(node.val, new ArrayList<>()));
        
        while (!queue.isEmpty()) {
            Node current = queue.poll();
            for (Node neighbor : current.neighbors) {
                if (!visited.containsKey(neighbor)) {
                    visited.put(neighbor, new Node(neighbor.val, new ArrayList<>()));
                    queue.offer(neighbor);
                }
            }
        }
        
        // 第二遍：建立邻居关系
        for (Map.Entry<Node, Node> entry : visited.entrySet()) {
            Node original = entry.getKey();
            Node clone = entry.getValue();
            for (Node neighbor : original.neighbors) {
                clone.neighbors.add(visited.get(neighbor));
            }
        }
        
        return visited.get(node);
    }
}
```

## 复杂度分析

设图的节点数为 N，边数为 E。

### 所有方法
- **时间复杂度**：O(N + E)
  - 每个节点访问一次：O(N)
  - 每条边访问一次：O(E)
- **空间复杂度**：O(N)
  - 哈希表存储 N 个节点
  - 递归栈/队列最多 N 个节点

## 关键点总结

1. **哈希表是关键**：记录原节点到克隆节点的映射，避免重复克隆
2. **处理循环引用**：用哈希表判断节点是否已访问
3. **深拷贝 vs 浅拷贝**：要创建新节点，不能直接复制引用
4. **建立邻居关系**：克隆节点的邻居也必须是克隆节点
5. **DFS vs BFS**：两种方法都可以，DFS 代码更简洁

## 易错点

1. **浅拷贝错误**
   ```java
   // 错误：浅拷贝，直接复制引用
   clone.neighbors = node.neighbors;
   
   // 正确：深拷贝，克隆每个邻居
   for (Node neighbor : node.neighbors) {
       clone.neighbors.add(cloneGraph(neighbor));
   }
   ```

2. **重复克隆**
   ```java
   // 错误：没有检查是否已克隆
   Node clone = new Node(node.val, new ArrayList<>());
   
   // 正确：先检查哈希表
   if (visited.containsKey(node)) {
       return visited.get(node);
   }
   ```

3. **忘记记录映射**
   ```java
   // 创建克隆节点后，必须立即记录映射
   Node clone = new Node(node.val, new ArrayList<>());
   visited.put(node, clone);  // 重要！防止循环引用时无限递归
   ```

4. **邻居连接错误**
   ```java
   // 错误：连接到原节点
   clone.neighbors.add(neighbor);
   
   // 正确：连接到克隆节点
   clone.neighbors.add(visited.get(neighbor));
   ```

5. **空节点处理**
   ```java
   // 必须处理空节点
   if (node == null) {
       return null;
   }
   ```
