## 题目描述

返回[a,b]范围内各位数字互不相同的整数个数。（b<=1000）

## 解题思路

数据范围小，直接枚举每个数，判断各位是否有重复。

## Java 代码实现

```java
class Solution {
    public int numberCount(int a, int b) {
        int count = 0;
        for (int n = a; n <= b; n++) {
            if (hasUniqueDigits(n)) count++;
        }
        return count;
    }

    private boolean hasUniqueDigits(int n) {
        boolean[] seen = new boolean[10];
        while (n > 0) {
            int d = n % 10;
            if (seen[d]) return false;
            seen[d] = true;
            n /= 10;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(B-A)
- **空间复杂度**：O(1)

## 关键点总结

1. **逐位检查重复**：用boolean数组记录已出现数字
2. **范围小直接枚举**：b<=1000无需数位DP
3. **包含端点a和b**
