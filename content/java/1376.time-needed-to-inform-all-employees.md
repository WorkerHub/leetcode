## 题目描述

公司有 n 名员工，headID 是老板。manager[i] 是员工 i 的直属上级，informTime[i] 是员工 i 通知所有直属下属所需分钟数。老板向下传达消息，可并行通知，返回通知所有员工所需的总分钟数。

## 解题思路

等价于：从 headID 出发，找树中从根到最远叶子路径上所有 informTime 之和的最大值。建邻接表后 DFS，每个节点返回 `informTime[node] + max(子节点递归结果)`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int numOfMinutes(int n, int headID, int[] manager, int[] informTime) {
        // 建立每个员工的直属下属列表
        List<List<Integer>> subordinates = new ArrayList<>();
        for (int i = 0; i < n; i++) subordinates.add(new ArrayList<>());
        for (int i = 0; i < n; i++) {
            if (manager[i] != -1) {
                subordinates.get(manager[i]).add(i);
            }
        }
        return dfs(headID, subordinates, informTime);
    }

    private int dfs(int node, List<List<Integer>> subordinates, int[] informTime) {
        int maxTime = 0;
        // 取所有直属下属中耗时最长的
        for (int sub : subordinates.get(node)) {
            maxTime = Math.max(maxTime, dfs(sub, subordinates, informTime));
        }
        // 当前节点通知时间 + 下属中最慢的
        return informTime[node] + maxTime;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(n)，邻接表和递归栈。

## 关键点总结

1. 答案等于从根到最远叶子路径上所有 informTime 之和的最大值（并行通知取最长路径）。
2. 将 manager 数组转化为子节点列表（邻接表），便于自上而下 DFS。
3. 递推关系：`f(node) = informTime[node] + max(f(sub) for sub in subordinates)`。
