## 题目描述

给你一棵二叉树，它的根为 `root`。请你删除 1 条边，使二叉树分裂成两棵子树，且它们所有节点值之积**最大**。

由于答案可能很大，请你将结果对 `10^9 + 7` 取模后再返回。

**示例 1：**
```
输入：root = [1,2,3,4,5,6]
输出：110
解释：删除红色的边后，得到两棵子树，节点值分别为 [1,2,3,4,5] 和 [6]，乘积 = 26 * 6 = 110。
```

**示例 2：**
```
输入：root = [1,null,2,3,4]
输出：6
```

**示例 3：**
```
输入：root = [1,2,3,null,4,null,5]
输出：1000
```

**提示：**
- 每棵树最多有 `50000` 个节点，且至少有 `2` 个节点。
- 每个节点的值在 `[1, 10000]` 之间。

## 解题思路

**核心观察：**

删除一条边后，树分成两部分：一部分是某个子树（设其节点和为 `sub`），另一部分是剩余的树（节点和为 `total - sub`）。

因此，乘积 = `sub * (total - sub)`。

**算法步骤：**
1. 第一次 DFS：计算整棵树所有节点的总和 `total`
2. 第二次 DFS：计算每个子树的节点和，寻找使 `sub * (total - sub)` 最大的 `sub`
3. 返回最大乘积对 `10^9 + 7` 取模的结果

**注意：** 取模应在最后取，中间计算时不能取模（取模会影响大小比较）。

## Java 代码实现

### 方法一：两次 DFS（推荐）

```java
class Solution {
    private long maxProd = 0;
    private long total = 0;
    
    public int maxProduct(TreeNode root) {
        final int MOD = 1_000_000_007;
        
        // 第一次 DFS：计算整棵树的总和
        total = treeSum(root);
        
        // 第二次 DFS：遍历每个子树和，找最大乘积
        dfs(root);
        
        return (int)(maxProd % MOD);
    }
    
    private long treeSum(TreeNode node) {
        if (node == null) return 0;
        return node.val + treeSum(node.left) + treeSum(node.right);
    }
    
    private long dfs(TreeNode node) {
        if (node == null) return 0;
        // 当前子树的节点和
        long sub = node.val + dfs(node.left) + dfs(node.right);
        // 删除连接此节点与父节点的边，乘积为 sub * (total - sub)
        maxProd = Math.max(maxProd, sub * (total - sub));
        return sub;
    }
}
```

### 方法二：一次 DFS（记录所有子树和）

```java
import java.util.*;

class Solution {
    public int maxProduct(TreeNode root) {
        final int MOD = 1_000_000_007;
        
        // 收集所有子树的节点和
        List<Long> subSums = new ArrayList<>();
        
        long total = dfs(root, subSums);
        
        // 对每个子树和，计算乘积 sub * (total - sub)
        long maxProd = 0;
        for (long sub : subSums) {
            maxProd = Math.max(maxProd, sub * (total - sub));
        }
        
        return (int)(maxProd % MOD);
    }
    
    private long dfs(TreeNode node, List<Long> subSums) {
        if (node == null) return 0;
        long s = node.val + dfs(node.left, subSums) + dfs(node.right, subSums);
        subSums.add(s);
        return s;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（两次DFS） | O(n) | O(h)（h为树高） |
| 方法二（一次DFS） | O(n) | O(n)（存储所有子树和） |

- 树高 h 最坏为 O(n)（退化链表），平均 O(log n)
- 方法二需要 O(n) 空间存储所有子树和

## 图解示例

```
      1
    /   \
   2     3
  / \   /
 4   5 6

总和 total = 1+2+3+4+5+6 = 21

各子树和：
- 节点4: sub=4,  乘积 = 4*(21-4) = 4*17 = 68
- 节点5: sub=5,  乘积 = 5*(21-5) = 5*16 = 80
- 节点2: sub=11, 乘积 = 11*(21-11) = 11*10 = 110  <-- 最大
- 节点6: sub=6,  乘积 = 6*(21-6) = 6*15 = 90
- 节点3: sub=9,  乘积 = 9*(21-9) = 9*12 = 108
- 节点1: sub=21, 乘积 = 21*0 = 0

最大乘积 = 110
```

## 关键点总结

1. 删边等价于枚举每个子树：子树和为 `sub`，另一部分为 `total - sub`
2. 先求总和，再找使 `sub * (total - sub)` 最大的分割点
3. **取模必须在最后**，中间不能取模（取模后不能正确比较大小）
4. 需要用 `long` 计算乘积，避免整数溢出

## 易错点

1. 取模时机：一定要先找最大乘积，最后才对结果取模
2. 乘积可能很大，必须用 `long` 而不是 `int`
3. 节点值都是正数，所以 `sub` 越接近 `total/2`，乘积越大
