## 题目描述

给定整数数组 nums，不使用内置函数将其升序排列。要求 O(n log n) 时间复杂度。

**示例：**
```
输入：nums = [5,2,3,1]
输出：[1,2,3,5]
```

## 解题思路

经典排序算法实现：归并排序、快速排序或堆排序。

## Java 代码实现

### 快速排序（随机化）

```java
class Solution {
    private Random rand = new Random();

    public int[] sortArray(int[] nums) {
        quickSort(nums, 0, nums.length - 1);
        return nums;
    }

    private void quickSort(int[] nums, int left, int right) {
        if (left >= right) return;
        int pivot = partition(nums, left, right);
        quickSort(nums, left, pivot - 1);
        quickSort(nums, pivot + 1, right);
    }

    private int partition(int[] nums, int left, int right) {
        // 随机选基准
        int idx = left + rand.nextInt(right - left + 1);
        int temp = nums[left]; nums[left] = nums[idx]; nums[idx] = temp;

        int pivot = nums[left];
        int i = left + 1, j = right;
        while (true) {
            while (i <= j && nums[i] <= pivot) i++;
            while (i <= j && nums[j] >= pivot) j--;
            if (i > j) break;
            temp = nums[i]; nums[i] = nums[j]; nums[j] = temp;
        }
        nums[left] = nums[j];
        nums[j] = pivot;
        return j;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n) 平均
- **空间复杂度**：O(log n) 递归栈

## 关键点总结

1. **随机化**：避免有序数组导致最坏情况
2. **双指针分区**：从两端向中间扫描
3. **原地排序**：不需额外数组
