## 题目描述

给定整数数组 `nums` 和整数 `k`，从中选两个不重叠子序列使各自元素和均为 `k`，返回两子序列元素乘积之积的最大值，不存在则返回 `-1`。

## 解题思路

枚举分割点：前缀 DP 计算 `nums[0..i-1]` 中和为 `k` 的子序列的最大乘积；后缀 DP 计算 `nums[i..n-1]` 中和为 `k` 的子序列的最大乘积。枚举每个分割位置 `i`，若两侧均可达到和 `k`，则取乘积最大值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxProduct(int[] nums, int k) {
        int n = nums.length;

        // prefix[i]: 使用 nums[0..i-1] 子集，sum->maxProduct
        @SuppressWarnings("unchecked")
        HashMap<Integer, Long>[] prefix = new HashMap[n + 1];
        prefix[0] = new HashMap<>();
        prefix[0].put(0, 1L); // 空集：和为 0，积为 1
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = new HashMap<>(prefix[i]);
            for (Map.Entry<Integer, Long> e : prefix[i].entrySet()) {
                int ns = e.getKey() + nums[i];
                long np = e.getValue() * nums[i];
                prefix[i + 1].merge(ns, np, Math::max);
            }
        }

        // suffix[i]: 使用 nums[i..n-1] 子集，sum->maxProduct
        @SuppressWarnings("unchecked")
        HashMap<Integer, Long>[] suffix = new HashMap[n + 1];
        suffix[n] = new HashMap<>();
        suffix[n].put(0, 1L);
        for (int i = n - 1; i >= 0; i--) {
            suffix[i] = new HashMap<>(suffix[i + 1]);
            for (Map.Entry<Integer, Long> e : suffix[i + 1].entrySet()) {
                int ns = e.getKey() + nums[i];
                long np = e.getValue() * nums[i];
                suffix[i].merge(ns, np, Math::max);
            }
        }

        long best = -1;
        for (int i = 0; i <= n; i++) {
            if (prefix[i].containsKey(k) && suffix[i].containsKey(k)) {
                best = Math.max(best, prefix[i].get(k) * suffix[i].get(k));
            }
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * k)，每个分割点 O(n * k) 的 DP 构建
- 空间复杂度：O(n * k)，前缀和后缀 DP 表

## 关键点总结

1. 枚举分割点保证两子序列不重叠（不共享元素下标）
2. 空集和为 0、积为 1，作为 DP 初始状态
3. 前缀 DP 与后缀 DP 独立计算，O(1) 合并分割点结果
