## 题目描述

给定整数数组 `nums` 和整数 `k`，将数组元素分成若干组（每组至少两个元素），使每组元素之和不超过 k。返回最多可以形成的组数。

## 解题思路

贪心 + 排序 + 双指针：排序后用最小值配最大值。若 `nums[left] + nums[right] <= k` 则配对，否则放弃最大值右指针左移。贪心策略确保用最小元素消耗最大元素，最大化组数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximizeGroups(int[] nums, long k) {
        Arrays.sort(nums);
        int left = 0, right = nums.length - 1, count = 0;
        while (left < right) {
            if ((long) nums[left] + nums[right] <= k) {
                count++;
                left++;
                right--;
            } else {
                right--;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(1)

## 关键点总结

1. 排序后双指针：用最小值配最大值
2. 当最大值无法与最小值配对时，必然无法与任何元素配对
3. 注意 int 相加可能溢出，用 long 比较
