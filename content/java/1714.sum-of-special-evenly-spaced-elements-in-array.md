## 题目描述

查询 `queries[i] = [x, y]`，返回从下标 `x` 以步长 `y` 取元素的和（对 `10^9 + 7` 取余）。

## 解题思路

**根号分治：** 设阈值 `T = sqrt(n)`。步长 `y >= T` 时步数 <= sqrt(n)，直接暴力；步长 `y < T` 时预处理后缀和 `dp[y][i]`（从 `i` 开始步长 `y` 的累加和），O(1) 查询。

## Java 代码实现

```java
class Solution {
    public int[] solve(int[] nums, int[][] queries) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        int T = (int) Math.sqrt(n) + 1;

        // 预处理步长 < T 的后缀和：dp[y][i] = nums[i] + dp[y][i+y]
        int[][] dp = new int[T][n];
        for (int y = 1; y < T; y++) {
            for (int i = n - 1; i >= 0; i--) {
                dp[y][i] = nums[i] % MOD;
                if (i + y < n) dp[y][i] = (dp[y][i] + dp[y][i + y]) % MOD;
            }
        }

        int[] ans = new int[queries.length];
        for (int k = 0; k < queries.length; k++) {
            int x = queries[k][0], y = queries[k][1];
            if (y < T) {
                ans[k] = dp[y][x];
            } else {
                long total = 0;
                for (int idx = x; idx < n; idx += y) {
                    total = (total + nums[idx]) % MOD;
                }
                ans[k] = (int) total;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * sqrt(n) + m * sqrt(n))
- **空间复杂度**：O(n * sqrt(n))

## 关键点总结

1. 根号分治平衡预处理和查询时间
2. 小步长预处理后缀和，大步长直接暴力
3. 阈值 T = sqrt(n) 使两者时间均为 O(sqrt(n))
