## 题目描述

给你一个由小写英文字母组成的回文字符串 `palindrome`，请你将其中**一个**字符用任意小写英文字母替换，使得结果字符串的字典序**最小**，且**不是**回文串。

请你返回结果字符串。如果无法做到，则返回一个**空字符串**。

**示例 1：**

```
输入：palindrome = "abccba"
输出："aaccba"
解释：在所有方法中，"aaccba" 的字典序最小。
```

**示例 2：**

```
输入：palindrome = "a"
输出：""
解释：不存在替换一个字符使 "a" 变成非回文且有意义的字符串。
```

**提示：**

- `1 <= palindrome.length <= 1000`
- `palindrome` 仅由小写英文字母组成

## 解题思路

**贪心策略**

要让结果字典序最小，优先修改**前半部分**（高位权重大，改小影响更大）。

**分两种情况：**

**情况 1：前半部分存在非 'a' 字符**

将前半部分第一个非 'a' 的字符改为 'a'。这样：
- 字典序变小（'a' 是最小字母）
- 打破了回文对称性（该位置原本是非 'a'，改为 'a'，其镜像位置仍是原字符）

特别注意：只需遍历 `range(n/2)`，这样自然跳过奇数长度字符串的中间字符。

**情况 2：前半部分全是 'a'（字符串形如 "aaa...aaa" 或 "aaa...a...aaa"）**

将**最后一个字符**改为 'b'，打破回文性质。

## Java 代码实现

### 方法一：贪心（推荐）

```java
class Solution {
    public String breakPalindrome(String palindrome) {
        int n = palindrome.length();
        
        // 长度为 1 时，无法修改成非回文
        if (n == 1) return "";
        
        char[] s = palindrome.toCharArray();
        
        // 遍历前半部分，找第一个非 'a' 的位置
        for (int i = 0; i < n / 2; i++) {
            if (s[i] != 'a') {
                s[i] = 'a';
                return new String(s);
            }
        }
        
        // 前半部分全是 'a'
        // 将最后一个字符改为 'b'（字典序最小的非 'a' 字母）
        s[n - 1] = 'b';
        return new String(s);
    }
}
```

### 方法二：字符串拼接版

```java
class Solution {
    public String breakPalindrome(String palindrome) {
        int n = palindrome.length();
        if (n == 1) return "";
        
        // 寻找前半部分第一个非 'a' 字符（排除中间字符）
        for (int i = 0; i < n / 2; i++) {
            if (palindrome.charAt(i) != 'a') {
                // 将该字符改为 'a'
                return palindrome.substring(0, i) + 'a' + palindrome.substring(i + 1);
            }
        }
        
        // 所有可修改位置都是 'a'，改最后一个为 'b'
        return palindrome.substring(0, n - 1) + 'b';
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，最多遍历字符串一次
- **空间复杂度**：O(n)，转换为字符数组

## 图解示例

```
palindrome = "abccba"，n=6

遍历前半部分（下标 0, 1, 2）：
  i=0: s[0]='a' == 'a'，跳过
  i=1: s[1]='b' != 'a'，改为 'a'
  返回 "aaccba"

palindrome = "aaaa"，n=4

遍历前半部分（下标 0, 1）：
  i=0: 'a' == 'a'，跳过
  i=1: 'a' == 'a'，跳过
策略 2：改最后一个为 'b'
返回 "aaab"

palindrome = "aba"，n=3（奇数长度）

遍历前半部分（下标 0，只有 n/2=1 个）：
  i=0: 'a' == 'a'，跳过
策略 2：改最后一个为 'b'
返回 "abb"
```

## 关键点总结

1. 只遍历前半部分（`i < n/2`），奇数长度时中间字符自然被排除
2. 找到第一个非 'a' 字符改为 'a'，字典序最优
3. 前半部分全为 'a' 时，改最后一个字符为 'b'
4. 长度为 1 时无解，返回空字符串

## 易错点

1. **中间字符的处理**：改中间字符不会打破回文（中间字符对称于自身），遍历 `i < n/2` 自然跳过中间字符
2. **长度为 1 的特殊处理**：单字符无论改成什么都是回文，返回 ""
3. **Java 字符串不可变**：需要转为 `char[]` 或用 `substring` 拼接
