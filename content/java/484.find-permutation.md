## 题目描述

现在给定一个只由字符 'D' 和 'I' 组成的字符串 s。其中 'D' 表示递减（decreasing），'I' 表示递增（increasing）。

有效排列是对有 n 个从 1 到 n 的不同整数的排列 perm，使得对所有的 i：
- 如果 s[i] == 'D'，那么 perm[i] > perm[i+1]
- 如果 s[i] == 'I'，那么 perm[i] < perm[i+1]

返回有效排列 perm 的长度最小的字典序排列。

**示例 1：**
```
输入：s = "I"
输出：[1,2]
解释：[1,2] 是唯一合法的排列。
```

**示例 2：**
```
输入：s = "DI"
输出：[2,1,3]
解释：[2,1,3] 和 [3,1,2] 都是合法排列，但是 [2,1,3] 的字典序更小。
```

**示例 3：**
```
输入：s = "DDI"
输出：[3,2,1,4]
```

**提示：**
- 1 <= s.length <= 10^5
- s 只包含字符 'I' 或 'D'

## 解题思路

这道题要求找到字典序最小的排列，满足给定的 D/I 模式。

### 核心思想

1. **贪心策略**：
   - 为了字典序最小，我们希望尽可能使用小的数字
   - 遇到 'I' 时，应该放置当前可用的最小数字
   - 遇到 'D' 时，需要预留空间给后续的递减

2. **栈的应用**：
   - 使用栈来处理连续的 'D'
   - 遇到 'I' 或到达末尾时，将栈中元素弹出

3. **算法流程**：
   - 初始化数字 1 到 n+1（n 是字符串长度）
   - 从左到右扫描字符串
   - 将数字依次入栈
   - 遇到 'I' 或末尾时，将栈中元素全部弹出到结果

### 图解示例

对于 s = "DDI"：
```
步骤1: 遇到 D，数字 1 入栈: [1]
步骤2: 遇到 D，数字 2 入栈: [1,2]
步骤3: 遇到 I，数字 3 入栈: [1,2,3]，然后遇到 I 弹出所有: 结果 [3,2,1]
步骤4: 末尾，数字 4 入栈: [4]，弹出: 结果 [3,2,1,4]
```

## Java 代码实现

### 方法一：使用栈（推荐）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] findPermutation(String s) {
        // 使用栈处理 D/I 模式
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)
        int n = s.length();
        int[] result = new int[n + 1];
        int idx = 0;
        Deque<Integer> stack = new ArrayDeque<>();

        // 遍历字符串，索引 i 对应数字 i+1
        for (int i = 0; i < n; i++) {
            // 将数字 i+1 入栈
            stack.push(i + 1);

            // 如果当前字符是 'I'，弹出栈中所有元素
            if (s.charAt(i) == 'I') {
                while (!stack.isEmpty()) {
                    result[idx++] = stack.pop();
                }
            }
        }

        // 最后一个数字入栈
        stack.push(n + 1);

        // 弹出剩余元素
        while (!stack.isEmpty()) {
            result[idx++] = stack.pop();
        }

        return result;
    }
}
```

### 方法二：反转子数组（更直观）

```java
class Solution {
    public int[] findPermutation(String s) {
        // 先构建递增序列，然后反转 D 对应的区间
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)
        int n = s.length();
        // 初始化为递增序列 [1, 2, 3, ..., n+1]
        int[] result = new int[n + 1];
        for (int i = 0; i <= n; i++) {
            result[i] = i + 1;
        }

        // 找到连续的 D 并反转对应区间
        int i = 0;
        while (i < n) {
            if (s.charAt(i) == 'D') {
                // 找到连续 D 的起始和结束位置
                int j = i;
                while (j < n && s.charAt(j) == 'D') {
                    j++;
                }
                // 反转 [i, j] 区间
                reverse(result, i, j);
                i = j;
            } else {
                i++;
            }
        }

        return result;
    }

    private void reverse(int[] arr, int left, int right) {
        // 反转数组指定区间
        while (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 方法三：贪心构造（逐步填充）

```java
class Solution {
    public int[] findPermutation(String s) {
        // 贪心构造，计算每个位置应该放的数字
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)
        int n = s.length();
        int[] result = new int[n + 1];

        // 从 1 开始分配数字
        int num = 1;

        int i = 0;
        while (i <= n) {
            // 找到连续 D 的长度
            int j = i;
            while (j < n && s.charAt(j) == 'D') {
                j++;
            }

            // 从 j 倒着填充到 i
            for (int k = j; k >= i; k--) {
                result[k] = num++;
            }

            i = j + 1;
        }

        return result;
    }
}
```

### 方法四：简洁的栈实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] findPermutation(String s) {
        // 简洁的栈实现
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)
        int n = s.length();
        int[] result = new int[n + 1];
        int idx = 0;
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            stack.push(i + 1);
            if (s.charAt(i) == 'I') {
                // 遇到 I，将栈中元素全部弹出到结果
                while (!stack.isEmpty()) {
                    result[idx++] = stack.pop();
                }
            }
        }

        // 添加最后一个数字并弹出
        stack.push(n + 1);
        while (!stack.isEmpty()) {
            result[idx++] = stack.pop();
        }

        return result;
    }
}
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(n)
  - 遍历字符串一次
  - 每个元素最多入栈出栈一次
  
- **空间复杂度**：O(n)
  - 栈的空间：O(n)
  - 结果数组：O(n)

## 关键点总结

1. **贪心思想**：为了字典序最小，尽量使用小的数字
2. **栈的妙用**：处理连续 D 的情况
3. **边界处理**：最后一个数字需要单独处理
4. **模式识别**：识别连续的 D 区间
5. **反转技巧**：可以先构造递增序列再反转

## 易错点

1. **最后一个数字**
   - 字符串长度为 n，但排列有 n+1 个数字
   - 容易忘记处理最后一个数字

2. **栈的清空时机**
   - 遇到 'I' 时要清空栈
   - 字符串末尾也要清空栈

3. **区间反转边界**
   - 反转时要包含区间两端
   - 注意索引的对应关系

4. **空字符串**
   - s = "" 时，结果应该是 [1]
   - 要确保边界情况正确

5. **连续 D 的处理**
   - 要找到整个连续 D 的区间
   - 不能一个一个处理
