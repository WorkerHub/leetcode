## 题目描述

统计满足左侧和>=右侧和的合法分割点数量（分割点不能是最后一个下标）。

## 解题思路

前缀和：遍历计算左侧和prefix，右侧和=total-prefix，检查prefix>=total-prefix。

## Java 代码实现

```java
class Solution {
    public int waysToSplitArray(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;

        long prefix = 0;
        int count = 0;
        for (int i = 0; i < n - 1; i++) {
            prefix += nums[i];
            if (prefix >= total - prefix) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和**：O(1)计算左右两侧和
2. **long防溢出**：元素和可能超int
3. **分割点范围**：0到n-2（右侧至少一个元素）
