## 题目描述

给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 `true`；否则，返回 `false`。

整数 `n` 是 3 的幂次方需满足：存在整数 `x` 使得 `n == 3^x`。

**示例 1:**

```
输入：n = 27
输出：true
解释：27 = 3^3
```

**示例 2:**

```
输入：n = 0
输出：false
解释：不存在 x 使得 3^x = 0
```

**示例 3:**

```
输入：n = 9
输出：true
解释：9 = 3^2
```

**示例 4:**

```
输入：n = 45
输出：false
```

**提示:**

- `-2^31 <= n <= 2^31 - 1`

**进阶：** 你能不使用循环或者递归来完成本题吗？

## 解题思路

判断一个数是否是 3 的幂次方，有多种方法。

### 思路一：循环除法（最直观）

- 如果 `n` 是 3 的幂次方，那么不断除以 3，最终会得到 1
- 如果中途出现无法整除的情况，则不是 3 的幂次方

### 思路二：递归

- 基础情况：`n == 1` 返回 `true`，`n <= 0` 或 `n % 3 != 0` 返回 `false`
- 递归情况：`isPowerOfThree(n / 3)`

### 思路三：对数法

- 如果 `n = 3^x`，则 `x = log₃(n) = log(n) / log(3)`
- 判断 `x` 是否为整数

### 思路四：最大 3 的幂次方（最巧妙）

- 在 32 位整数范围内，3 的最大幂次方是 `3^19 = 1162261467`
- 如果 `n` 是 3 的幂次方，则 `1162261467 % n == 0`
- 这是因为 3 的幂次方只包含质因子 3

## Java 代码实现

### 方法一：循环除法（推荐新手）⭐

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 循环除法：不断除以 3，看最终是否为 1
        if (n <= 0) return false;

        while (n % 3 == 0) {
            n /= 3;
        }

        return n == 1;
    }
}
```

### 方法二：递归

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 递归解法
        if (n == 1) return true;
        if (n <= 0 || n % 3 != 0) return false;

        return isPowerOfThree(n / 3);
    }
}
```

### 方法三：对数法

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 对数法：判断 log₃(n) 是否为整数
        if (n <= 0) return false;

        // 计算 log₃(n) = log(n) / log(3)
        double x = Math.log(n) / Math.log(3);

        // 判断 x 是否为整数（考虑浮点数精度误差）
        return Math.abs(x - Math.round(x)) < 1e-10;
    }
}
```

### 方法四：最大 3 的幂次方（巧妙）⭐

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 利用 3 的最大幂次方：3^19 = 1162261467
        // 如果 n 是 3 的幂次方，则 3^19 % n == 0
        return n > 0 && 1162261467 % n == 0;
    }
}
```

### 方法五：三进制字符串法

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 转换为三进制字符串，检查是否为 1000...0 的形式
        if (n <= 0) return false;

        // 使用 Java 内置函数转换为三进制字符串
        String base3 = Integer.toString(n, 3);

        // 检查是否为 "1" 后面跟若干 "0"
        return base3.matches("10*");
    }
}
```

### 方法六：位运算辅助

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 结合方法四，利用最大幂次方整除判断
        // 3^19 = 1162261467 是 int 范围内 3 的最大幂
        if (n <= 0) return false;

        // 不断除以 3，最终为 1 则是 3 的幂次方
        while (n % 3 == 0) {
            n /= 3;
        }
        return n == 1;
    }
}
```

## 复杂度分析

**方法一：循环除法**

- **时间复杂度**：O(log₃n)
  - 循环次数等于 n 中包含质因子 3 的个数
  
- **空间复杂度**：O(1)

**方法二：递归**

- **时间复杂度**：O(log₃n)
- **空间复杂度**：O(log₃n)
  - 递归栈的深度

**方法三：对数法**

- **时间复杂度**：O(1)
  - 对数计算是常数时间
  
- **空间复杂度**：O(1)

**方法四：最大 3 的幂次方**

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **边界情况**：`n <= 0` 一定不是 3 的幂次方
2. **循环除法**：最直观，不断除以 3 直到无法整除
3. **对数法**：需要注意浮点数精度问题
4. **最大幂次方法**：利用 3 的质因数特性，非常巧妙
   - 32 位整数范围内，3 的最大幂是 `3^19 = 1162261467`
   - 只有 3 的幂次方才能整除它
5. **三进制表示**：3 的幂次方在三进制下是 `1000...0` 的形式

## 易错点

1. **忘记处理负数和 0**：`n <= 0` 直接返回 `false`
2. **对数精度问题**：浮点数计算有误差，需要设置容差 `1e-10`
3. **整除判断**：要用 `n % 3 == 0`，不能混淆条件
4. **最大值计算错误**：
   - 正确：`3^19 = 1162261467`
   - 错误：`3^20 = 3486784401 > 2^31 - 1`（超出 32 位整数范围）
5. **递归栈溢出**：对于很大的 n，递归深度可能很深

## 图解示例

示例：`n = 27`

```
循环除法：
27 % 3 == 0 ✓ → n = 27 / 3 = 9
9 % 3 == 0 ✓ → n = 9 / 3 = 3
3 % 3 == 0 ✓ → n = 3 / 3 = 1
n == 1 ✓ → 返回 true

对数法：
log₃(27) = log(27) / log(3) = 3.0
3.0 是整数 ✓ → 返回 true

最大幂次方法：
1162261467 % 27 = 0 ✓ → 返回 true

三进制表示：
27 = 1000₃（1 后面跟 3 个 0）✓
```
