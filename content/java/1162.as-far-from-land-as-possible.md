## 题目描述

n×n 网格中 0 代表海洋、1 代表陆地，找到离陆地最远的海洋单元格的曼哈顿距离。全海洋或全陆地返回 -1。

**示例：**
```
输入：grid = [[1,0,1],[0,0,0],[1,0,1]]
输出：2
```

## 解题思路

多源 BFS：将所有陆地加入初始队列，同时向外扩散，最后到达的海洋单元格即为最远点。

## Java 代码实现

```java
class Solution {
    public int maxDistance(int[][] grid) {
        int n = grid.length;
        Queue<int[]> queue = new LinkedList<>();

        // 所有陆地作为起点
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1)
                    queue.offer(new int[]{i, j});

        // 边界：全陆地或全海洋
        if (queue.size() == 0 || queue.size() == n * n) return -1;

        int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}};
        int dist = -1;

        while (!queue.isEmpty()) {
            dist++;
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                int[] cell = queue.poll();
                for (int[] d : dirs) {
                    int nx = cell[0] + d[0], ny = cell[1] + d[1];
                    if (nx >= 0 && nx < n && ny >= 0 && ny < n && grid[nx][ny] == 0) {
                        grid[nx][ny] = 1; // 标记已访问
                        queue.offer(new int[]{nx, ny});
                    }
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，每个单元格最多访问一次
- **空间复杂度**：O(n²)，队列最多存储所有单元格

## 关键点总结

1. **多源 BFS**：所有陆地同时出发，逐层扩散
2. **层序计数**：BFS 层数即为距离
3. **原地标记**：将海洋标为陆地避免重复访问
4. **边界处理**：全陆地或全海洋返回 -1
