## 题目描述

每次选数组中最小的未标记元素加入分数，并标记它和左右相邻元素，重复直到所有元素被标记，返回最终分数。

## 解题思路

**最小堆模拟**：将 `(值, 下标)` 入堆，每次弹出最小未标记元素，加分并标记相邻，弹出时跳过已标记元素。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public long findScore(int[] nums) {
        int n = nums.length;
        // 最小堆：按值升序，值相同按下标升序
        PriorityQueue<int[]> pq = new PriorityQueue<>(
            (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]
        );
        for (int i = 0; i < n; i++) {
            pq.offer(new int[]{nums[i], i});
        }

        boolean[] marked = new boolean[n];
        long score = 0;

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int val = cur[0], i = cur[1];
            if (marked[i]) continue; // 已标记则跳过
            score += val;
            // 标记当前及左右相邻元素
            marked[i] = true;
            if (i > 0) marked[i - 1] = true;
            if (i < n - 1) marked[i + 1] = true;
        }

        return score;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，堆操作
- 空间复杂度：O(n)

## 关键点总结

1. 用最小堆每次取最小未标记元素，值相同时下标小的优先
2. 弹出时检查是否已被标记（可能被相邻元素操作标记）
3. 返回值用 `long` 避免溢出
