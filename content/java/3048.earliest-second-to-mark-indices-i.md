## 题目描述

给你整数数组 `nums` 和 `changeIndices`，每秒可以对某下标减 1 或（当该下标值为 0 时）标记它，返回标记所有下标的最早秒数，不可能则返回 -1。

## 解题思路

二分答案：二分最早时间 T，贪心验证前 T 秒内是否能标记所有下标。从前向后扫描，按每个下标在 `changeIndices` 中最后出现的时刻排序，依次分配标记机会，空闲时刻累计用于减 1 操作。

## Java 代码实现

```java
class Solution {
    private int[] nums;
    private int[] changeIndices;
    private int n;

    public int earliestSecondToMarkIndices(int[] nums, int[] changeIndices) {
        this.nums = nums;
        this.changeIndices = changeIndices;
        this.n = nums.length;
        int m = changeIndices.length;

        int lo = n, hi = m;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        return check(lo) ? lo : -1;
    }

    private boolean check(int T) {
        // 找每个下标在前 T 秒内最后出现的位置
        int[] last = new int[n];
        Arrays.fill(last, -1);
        for (int t = 0; t < T; t++) {
            last[changeIndices[t] - 1] = t;
        }
        // 若某下标从未出现则无法标记
        for (int x : last) {
            if (x == -1) return false;
        }
        // 按最后出现时刻排序
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> last[a] - last[b]);

        int free = 0, ptr = 0;
        for (int t = 0; t < T; t++) {
            int idx = changeIndices[t] - 1;
            // 若此时刻是某下标的最后出现时刻，则在此处标记
            if (ptr < n && last[order[ptr]] == t) {
                if (free < nums[order[ptr]]) return false;
                free -= nums[order[ptr]];
                ptr++;
            } else {
                free++; // 空闲时刻用于减 1
            }
        }
        return ptr == n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m)，二分 O(log m) 次，每次验证 O(n log n + m)
- **空间复杂度**：O(n)

## 关键点总结

1. 二分答案：时间 T 越大越容易成功，具有单调性
2. 每个下标需要一个专门的"标记时刻"（其最后出现时刻）
3. 剩余时刻用于减 1 操作，空闲时刻数必须 >= 总减 1 需求
