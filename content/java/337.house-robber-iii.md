## 题目描述

小偷又发现了一个新的可行窃的地区。这个地区只有一个入口，我们称之为 `root`。

除了 `root` 之外，每栋房子有且只有一个"父"房子与之相连。一番侦察之后，聪明的小偷意识到"这个地方的所有房屋的排列类似于一棵二叉树"。如果**两个直接相连的房子在同一天晚上被打劫**，房屋将自动报警。

给定二叉树的 `root`。返回**在不触动警报的情况下**，小偷能够盗取的最高金额。

**示例 1:**

```
输入: root = [3,2,3,null,3,null,1]
输出: 7
解释: 小偷一晚能够盗取的最高金额 3 + 3 + 1 = 7
     3
    / \
   2   3
    \   \ 
     3   1
```

**示例 2:**

```
输入: root = [3,4,5,1,3,null,1]
输出: 9
解释: 小偷一晚能够盗取的最高金额 4 + 5 = 9
     3
    / \
   4   5
  / \   \ 
 1   3   1
```

**提示:**

- 树的节点数在 `[1, 10^4]` 范围内
- `0 <= Node.val <= 10^4`

## 解题思路

这道题是 **House Robber** 系列的树版本，使用**树形 DP**求解。

### 核心思想

对于每个节点，有两种选择：
1. **抢劫当前节点**：不能抢劫子节点，只能抢劫孙子节点
2. **不抢劫当前节点**：可以选择抢劫或不抢劫子节点

### 状态定义

对于每个节点，返回一个二元组 `(rob, notRob)`：
- `rob`：抢劫当前节点能获得的最大金额
- `notRob`：不抢劫当前节点能获得的最大金额

### 状态转移

设左子树返回 `(leftRob, leftNotRob)`，右子树返回 `(rightRob, rightNotRob)`：

1. **抢劫当前节点**：
   ```
   rob = node.val + leftNotRob + rightNotRob
   ```

2. **不抢劫当前节点**：
   ```
   notRob = max(leftRob, leftNotRob) + max(rightRob, rightNotRob)
   ```

## Java 代码实现

### 方法一：树形 DP（推荐）⭐

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public int rob(TreeNode root) {
        // 树形 DP：返回 int[2] = {抢劫当前节点, 不抢劫当前节点}
        int[] result = dfs(root);
        return Math.max(result[0], result[1]);
    }

    /**
     * 返回 int[2]: {rob（抢当前节点）, notRob（不抢当前节点）}
     */
    private int[] dfs(TreeNode node) {
        // 空节点
        if (node == null) {
            return new int[]{0, 0};
        }

        // 递归处理左右子树
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        // 抢劫当前节点：不能抢劫子节点
        int rob = node.val + left[1] + right[1];

        // 不抢劫当前节点：可以选择抢劫或不抢劫子节点
        int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

        return new int[]{rob, notRob};
    }
}
```

### 方法二：记忆化递归（朴素思路）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<TreeNode, Integer> memo = new HashMap<>();

    public int rob(TreeNode root) {
        // 记忆化递归：直接计算每个节点的最大金额
        return dfs(root);
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        if (memo.containsKey(node)) return memo.get(node);

        // 方案 1: 抢劫当前节点（跳过子节点，从孙子节点偷）
        int robCurrent = node.val;
        if (node.left != null) {
            robCurrent += dfs(node.left.left) + dfs(node.left.right);
        }
        if (node.right != null) {
            robCurrent += dfs(node.right.left) + dfs(node.right.right);
        }

        // 方案 2: 不抢劫当前节点
        int notRobCurrent = dfs(node.left) + dfs(node.right);

        // 取最大值
        int result = Math.max(robCurrent, notRobCurrent);
        memo.put(node, result);
        return result;
    }
}
```

### 方法三：暴力递归（会超时）

```java
class Solution {
    public int rob(TreeNode root) {
        // 暴力递归：没有记忆化，会有大量重复计算
        if (root == null) return 0;

        // 方案 1: 抢劫当前节点
        int robCurrent = root.val;
        if (root.left != null) {
            robCurrent += rob(root.left.left) + rob(root.left.right);
        }
        if (root.right != null) {
            robCurrent += rob(root.right.left) + rob(root.right.right);
        }

        // 方案 2: 不抢劫当前节点
        int notRobCurrent = rob(root.left) + rob(root.right);

        return Math.max(robCurrent, notRobCurrent);
    }
}
```

### 方法四：使用数组明确存储状态

```java
class Solution {
    public int rob(TreeNode root) {
        // 同方法一，用 int[2] 明确存储 rob 和 notRob 状态
        int[] res = robHelper(root);
        return Math.max(res[0], res[1]);
    }

    // res[0] = 抢当前节点的最大收益
    // res[1] = 不抢当前节点的最大收益
    private int[] robHelper(TreeNode node) {
        if (node == null) return new int[]{0, 0};

        int[] left = robHelper(node.left);
        int[] right = robHelper(node.right);

        // 抢当前节点
        int rob = node.val + left[1] + right[1];

        // 不抢当前节点
        int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);

        return new int[]{rob, notRob};
    }
}
```

## 复杂度分析

**方法一：树形 DP**

- **时间复杂度**：O(n)
  - 每个节点访问一次
  
- **空间复杂度**：O(h)
  - h：树的高度，递归栈的空间

**方法二：记忆化递归**

- **时间复杂度**：O(n)
  - 每个节点计算一次，记忆化避免重复
  
- **空间复杂度**：O(n)
  - memo HashMap + 递归栈

**方法三：暴力递归**

- **时间复杂度**：O(2^n)
  - 大量重复计算，会超时
  
- **空间复杂度**：O(h)
  - 递归栈

## 关键点总结

1. **树形 DP**：后序遍历，自底向上传递状态
2. **状态定义**：每个节点返回 `(rob, notRob)` 两个状态
3. **状态转移**：
   - 抢当前 = 当前值 + 不抢子节点
   - 不抢当前 = max(抢子节点, 不抢子节点)
4. **后序遍历**：先处理子树，再处理当前节点
5. **记忆化优化**：避免重复计算子问题

## 易错点

1. **忘记返回两个状态**：只返回一个值会丢失信息

2. **状态转移错误**：
   - 抢当前：必须用 `left[1]`（不抢左子节点）和 `right[1]`（不抢右子节点）
   - 不抢当前：可以用 `Math.max(left[0], left[1])`

3. **空节点处理**：返回 `{0, 0}` 而不是 `null`

4. **最终结果**：要取 `Math.max(result[0], result[1])`

5. **方法二的孙子节点**：要检查子节点是否为 `null` 再访问孙子节点

## 图解示例

示例 1：`root = [3,2,3,null,3,null,1]`

```
     3
    / \
   2   3
    \   \ 
     3   1

后序遍历过程：

1. 节点 3 (左子树的右子节点):
   rob = 3, notRob = 0
   返回 [3, 0]

2. 节点 2:
   left = [0, 0]
   right = [3, 0]
   rob = 2 + 0 + 0 = 2
   notRob = max(0, 0) + max(3, 0) = 3
   返回 [2, 3]

3. 节点 1 (右子树的右子节点):
   rob = 1, notRob = 0
   返回 [1, 0]

4. 节点 3 (右子节点):
   left = [0, 0]
   right = [1, 0]
   rob = 3 + 0 + 0 = 3
   notRob = max(0, 0) + max(1, 0) = 1
   返回 [3, 1]

5. 根节点 3:
   left = [2, 3]
   right = [3, 1]
   rob = 3 + 3 + 1 = 7
   notRob = max(2, 3) + max(3, 1) = 3 + 3 = 6
   返回 [7, 6]

结果: max(7, 6) = 7
```
