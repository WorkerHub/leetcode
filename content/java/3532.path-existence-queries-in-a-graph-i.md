## 题目描述

给定 n 个节点，若 `|nums[u] - nums[v]| <= maxDiff` 则 u 和 v 之间有边。对每个查询 `[u, v]` 判断是否连通。

## 解题思路

并查集：预处理所有满足条件的边，将节点合并。对每个查询直接判断是否同根。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public boolean[] pathExistenceQueries(int n, int[] nums, int maxDiff, int[][] queries) {
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (Math.abs(nums[i] - nums[j]) <= maxDiff) union(i, j);

        boolean[] res = new boolean[queries.length];
        for (int i = 0; i < queries.length; i++)
            res[i] = find(queries[i][0]) == find(queries[i][1]);
        return res;
    }

    private int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 + q * alpha(n))
- 空间复杂度：O(n)

## 关键点总结

1. 边的存在条件：权值差不超过 maxDiff
2. 并查集一次预处理，O(1) 回答每个查询
3. 路径压缩保证查询效率
