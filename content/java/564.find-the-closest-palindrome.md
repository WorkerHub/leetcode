## 题目描述

给定一个表示整数的字符串 `n`，返回与它最近的回文整数（不包括自身）。如果有多个结果，返回较小的那个。

"最近的"定义为两个整数差的绝对值最小。

**示例 1：**
```
输入：n = "123"
输出："121"
```

**示例 2：**
```
输入：n = "1"
输出："0"
解释：0 和 2 是最近的回文数，但我们返回最小的，也就是 0。
```

**提示：**
- `1 <= n.length <= 18`
- `n` 只由数字组成
- `n` 不含前导 0
- `n` 代表范围在 `[1, 10^18 - 1]` 内的整数

## 解题思路

这是一道困难的数学题，需要考虑多种情况。

候选回文数：
1. 镜像中间部分（保持原长度）
2. 镜像中间部分 + 1
3. 镜像中间部分 - 1
4. 10^(n-1) - 1（例如：999）
5. 10^n + 1（例如：10001）

## Java 代码实现

### 方法一：枚举候选（推荐）⭐

```java
import java.util.*;

class Solution {
    public String nearestPalindromic(String n) {
        // 枚举所有可能的候选回文数
        int length = n.length();
        long num = Long.parseLong(n);

        Set<Long> candidates = new HashSet<>();

        // 候选1: 999...9 (length - 1 位)
        candidates.add((long) Math.pow(10, length - 1) - 1);

        // 候选2: 100...001 (length + 1 位)
        candidates.add((long) Math.pow(10, length) + 1);

        // 候选3, 4, 5: 基于前半部分的镜像
        long prefix = Long.parseLong(n.substring(0, (length + 1) / 2));
        for (long delta = -1; delta <= 1; delta++) {
            long newPrefix = prefix + delta;
            String prefixStr = String.valueOf(newPrefix);
            String palin;
            // 根据长度奇偶决定镜像方式
            if (length % 2 == 0) {
                palin = prefixStr + new StringBuilder(prefixStr).reverse().toString();
            } else {
                palin = prefixStr + new StringBuilder(prefixStr.substring(0, prefixStr.length() - 1)).reverse().toString();
            }
            candidates.add(Long.parseLong(palin));
        }

        // 移除自身
        candidates.remove(num);

        // 找最接近的（距离相同时选较小的）
        long result = -1;
        for (long candidate : candidates) {
            if (result == -1 ||
                Math.abs(candidate - num) < Math.abs(result - num) ||
                (Math.abs(candidate - num) == Math.abs(result - num) && candidate < result)) {
                result = candidate;
            }
        }

        return String.valueOf(result);
    }
}
```

### 方法二：辅助函数版本

```java
class Solution {
    public String nearestPalindromic(String n) {
        int length = n.length();
        long num = Long.parseLong(n);
        boolean isOdd = length % 2 == 1;
        int midLen = (length + 1) / 2;
        long prefix = Long.parseLong(n.substring(0, midLen));

        long[] candidates = {
            getPalindrome(prefix, isOdd),
            getPalindrome(prefix + 1, isOdd),
            getPalindrome(prefix - 1, isOdd),
            (long) Math.pow(10, length - 1) - 1,
            (long) Math.pow(10, length) + 1
        };

        long result = -1;
        for (long c : candidates) {
            if (c == num) continue;
            if (result == -1 ||
                Math.abs(c - num) < Math.abs(result - num) ||
                (Math.abs(c - num) == Math.abs(result - num) && c < result)) {
                result = c;
            }
        }

        return String.valueOf(result);
    }

    // 根据前半部分构造回文数
    private long getPalindrome(long half, boolean isOdd) {
        String s = String.valueOf(half);
        String rev = new StringBuilder(s).reverse().toString();
        // 奇数长度：中间字符不重复
        return Long.parseLong(isOdd ? s + rev.substring(1) : s + rev);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，候选数量固定（最多 5 个）
- **空间复杂度**：O(1)

## 关键点总结

1. **候选枚举**：关键是找到所有可能的候选
2. **特殊情况**：999, 10001 等边界情况
3. **镜像构造**：根据长度奇偶性构造回文数
4. **最小优先**：距离相同时选较小的
5. **long 类型**：n 最大为 10^18，必须使用 long

## 易错点

1. **排除自身**：候选中要排除 n 本身
2. **奇偶处理**：长度奇偶影响镜像方式
3. **边界情况**：10^k - 1 和 10^k + 1
4. **最小优先**：距离相同时选较小值
5. **整数溢出**：使用 long 而不是 int
