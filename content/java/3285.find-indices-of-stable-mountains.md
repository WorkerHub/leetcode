## 题目描述

给你整数数组 `height` 和整数 `threshold`。若山 `i`（i≠0）的前一座山高度严格大于 `threshold`，则称山 `i` 为**稳定的山**。返回所有稳定山的下标。

## 解题思路

遍历 i 从 1 到 n-1，检查 `height[i-1] > threshold`，满足则加入结果。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> stableMountains(int[] height, int threshold) {
        List<Integer> result = new ArrayList<>();
        for (int i = 1; i < height.length; i++) {
            if (height[i - 1] > threshold) { // 前一座山严格大于 threshold
                result.add(i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，k 为结果数量

## 关键点总结

1. 稳定条件：前一座山高度严格大于 threshold（`>`，非 `>=`）
2. 从 i=1 开始遍历（i=0 无前山）
3. 检查的是 `height[i-1]` 而不是 `height[i]`
