## 题目描述

给你字符串 `word`，统计只含元音且包含全部五种元音（a,e,i,o,u 各至少一次）的子字符串数目。

## 解题思路

枚举所有起始位置，内层遍历时遇辅音立即 break，用集合记录已出现元音种类，集合大小为 5 时计数。

## Java 代码实现

```java
class Solution {
    public int countVowelSubstrings(String word) {
        Set<Character> vowels = Set.of('a', 'e', 'i', 'o', 'u');
        int n = word.length(), ans = 0;

        for (int i = 0; i < n; i++) {
            if (!vowels.contains(word.charAt(i))) continue;
            Set<Character> seen = new HashSet<>();
            for (int j = i; j < n; j++) {
                char c = word.charAt(j);
                if (!vowels.contains(c)) break; // 遇辅音停止
                seen.add(c);
                if (seen.size() == 5) ans++; // 包含全部五种元音
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)（集合最多 5 个元素）

## 关键点总结

1. 遇到辅音立即 break，确保子串只含元音
2. 集合大小达到 5 表示包含全部五种元音
3. n <= 100，O(n²) 足够
