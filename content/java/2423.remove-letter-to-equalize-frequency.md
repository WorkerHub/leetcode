## 题目描述

给你只含小写字母的字符串 `word`，判断是否能仅删除某个字母的**一次**出现，使所有剩余字母出现频率相同。

## 解题思路

统计每个字母的频率，枚举每个字母，临时将其频率减一（为 0 则移除），检查剩余非零频率是否全部相同。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean equalFrequency(String word) {
        int[] freq = new int[26];
        for (char c : word.toCharArray()) freq[c - 'a']++;

        for (int i = 0; i < 26; i++) {
            if (freq[i] == 0) continue;
            // 临时减少字母 i 的频率
            freq[i]--;
            // 收集所有非零频率
            Set<Integer> distinct = new HashSet<>();
            for (int f : freq) {
                if (f > 0) distinct.add(f);
            }
            // 所有非零频率相同则成功
            if (distinct.size() == 1) return true;
            freq[i]++; // 恢复
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(26 × 26) = O(1)，字母最多 26 种
- **空间复杂度**：O(1)

## 关键点总结

1. 枚举每个出现的字母，临时减去一次出现，检查频率是否均等
2. 频率为 0 的字母不参与频率比较
3. 验证时只需检查非零频率的集合大小是否为 1
