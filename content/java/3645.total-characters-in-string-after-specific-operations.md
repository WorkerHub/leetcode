## 题目描述

给定字符串 `s` 和整数 `k`，每次操作在每两个相邻字符间插入一个字符，执行 `k` 次，返回最终字符串长度（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int lengthAfterTransformations(String s, int k) {
        // 递推：L_{i+1} = 2*L_i - 1，通项：L_k = (n-1)*2^k + 1
        long n = s.length();
        long pow2k = modpow(2, k);
        return (int) (((n - 1) * pow2k % MOD + 1) % MOD);
    }

    private long modpow(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log k)，快速幂
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作在 n-1 个间隔各插入一个字符，长度变为 `2n-1`
2. 递推通项：`L_k = (n-1) * 2^k + 1`
3. 用快速幂计算 `2^k mod (10^9+7)`
