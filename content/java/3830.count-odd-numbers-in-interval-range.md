## 题目描述

给定非负整数 `low` 和 `high`，返回区间 `[low, high]` 内奇数的数目。

## Java 代码实现

```java
class Solution {
    public int countOdds(int low, int high) {
        // [1, n] 中奇数个数为 (n+1)/2
        // [low, high] = count(high) - count(low-1)
        return (high + 1) / 2 - low / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 前缀奇数计数公式：`[1, n]` 中奇数个数 = `(n+1)/2`
2. `[low, high]` 的奇数数 = `(high+1)/2 - low/2`
3. low=0 时 `low/2 = 0`，处理正确
