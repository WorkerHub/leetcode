## 题目描述

给你两个整数 `lo` 和 `hi`，统计满足以下条件的整数数目：该整数的各位数字之和被 3 整除（即数字和 % 3 == 0）。

## 解题思路

数位 DP：计算 `[1, n]` 中各位数字和被 3 整除的整数数目，答案为 `count(hi) - count(lo-1)`。状态为（当前位、数字和余数、是否受上界约束、是否已有非零前导数字）。

## Java 代码实现

```java
class Solution {
    private int[] digits;
    private int[][][] memo;

    public int countIntegers(int lo, int hi) {
        return countUpTo(hi) - countUpTo(lo - 1);
    }

    private int countUpTo(int n) {
        if (n <= 0) return 0;
        String s = Integer.toString(n);
        int L = s.length();
        digits = new int[L];
        for (int i = 0; i < L; i++) digits[i] = s.charAt(i) - '0';
        // memo[pos][rem][tight]，started 通过 rem=-1 表示未开始
        memo = new int[L][3][2];
        for (int[][] a : memo) for (int[] b : a) java.util.Arrays.fill(b, -1);
        return dp(0, 0, true, false);
    }

    private int dp(int pos, int rem, boolean tight, boolean started) {
        if (pos == digits.length) {
            return (started && rem == 0) ? 1 : 0;
        }
        int t = tight ? 1 : 0;
        if (started && memo[pos][rem][t] != -1) return memo[pos][rem][t];

        int limit = tight ? digits[pos] : 9;
        int result = 0;
        for (int d = 0; d <= limit; d++) {
            boolean newTight = tight && (d == limit);
            if (!started && d == 0) {
                result += dp(pos + 1, 0, newTight, false);
            } else {
                result += dp(pos + 1, (rem + d) % 3, newTight, true);
            }
        }
        if (started) memo[pos][rem][t] = result;
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * L * 3)，L 为数字位数（最多 10 位）
- 空间复杂度：O(L * 3)，记忆化数组

## 关键点总结

1. 数位 DP 状态：位置、数字和余数（0/1/2）、是否受上界约束。
2. `count(lo, hi) = countUpTo(hi) - countUpTo(lo - 1)`。
3. 前导零不计入数字（`started = false` 时跳过）。
