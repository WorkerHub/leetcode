## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格；整数 `fee` 代表了交易股票的手续费用。

你可以无限次地完成交易，但是你每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前你就不能再继续购买股票了。

返回获得利润的最大值。

**注意：** 这里的一笔交易指买入持有并卖出股票的整个过程，每笔交易你只需要为支付一次手续费。

**示例 1：**

```
输入：prices = [1,3,2,8,4,9], fee = 2
输出：8
解释：能够达到的最大利润:  
在此处买入 prices[0] = 1
在此处卖出 prices[3] = 8
在此处买入 prices[4] = 4
在此处卖出 prices[5] = 9
总利润: ((8 - 1) - 2) + ((9 - 4) - 2) = 8
```

**示例 2：**

```
输入：prices = [1,3,7,5,10,3], fee = 3
输出：6
```

**提示：**
- `1 <= prices.length <= 5 * 10^4`
- `1 <= prices[i] < 5 * 10^4`
- `0 <= fee < 5 * 10^4`

## 解题思路

这是经典的股票买卖系列问题，需要考虑交易手续费。

**核心思想：**
- 使用动态规划，维护每天的两种状态：持有股票和不持有股票
- 手续费可以在买入时扣除，也可以在卖出时扣除（本题在卖出时扣除）

**动态规划定义：**
- `cash`：当天不持有股票时的最大利润
- `hold`：当天持有股票时的最大利润

**状态转移：**
1. 不持有股票：
   - 前一天就不持有：`cash`
   - 前一天持有，今天卖出：`hold + prices[i] - fee`
   - 取两者最大值

2. 持有股票：
   - 前一天就持有：`hold`
   - 前一天不持有，今天买入：`cash - prices[i]`
   - 取两者最大值

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        int n = prices.length;
        if (n == 0) return 0;
        
        // 初始化
        int cash = 0;              // 第 0 天不持有股票，利润为 0
        int hold = -prices[0];     // 第 0 天持有股票，花费 prices[0]
        
        // 状态转移
        for (int i = 1; i < n; i++) {
            // 更新不持有股票的最大利润
            cash = Math.max(cash, hold + prices[i] - fee);
            // 更新持有股票的最大利润
            hold = Math.max(hold, cash - prices[i]);
        }
        
        // 最后一天不持有股票的利润一定大于等于持有股票
        return cash;
    }
}
```

### 方法二：详细注释版

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        // cash: 当前不持有股票的最大利润
        // hold: 当前持有股票的最大利润
        int cash = 0;
        int hold = -prices[0]; // 初始持有，花费第一天的价格
        
        for (int i = 1; i < prices.length; i++) {
            // 保存前一天的状态（避免状态污染）
            int prevCash = cash;
            int prevHold = hold;
            
            // 今天不持有股票的最大利润
            // 选项1: 昨天就不持有，今天继续不持有
            // 选项2: 昨天持有，今天卖出（获得 prices[i]，支付手续费 fee）
            cash = Math.max(prevCash, prevHold + prices[i] - fee);
            
            // 今天持有股票的最大利润
            // 选项1: 昨天就持有，今天继续持有
            // 选项2: 昨天不持有，今天买入（支付 prices[i]）
            hold = Math.max(prevHold, prevCash - prices[i]);
        }
        
        // 返回最后不持有股票的利润
        return cash;
    }
}
```

### 方法三：贪心算法

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        // 贪心思想：维护最小买入价格，遇到更好的卖出机会就卖出
        int profit = 0;
        int minPrice = prices[0]; // 当前最低买入价格
        
        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            if (price < minPrice) {
                // 更新最低买入价格
                minPrice = price;
            } else if (price > minPrice + fee) {
                // 有利可图，卖出
                profit += price - minPrice - fee;
                // 更新买入价格为 price - fee
                // 这样如果后续价格更高，可以继续获利
                minPrice = price - fee;
            }
        }
        
        return profit;
    }
}
```

## 复杂度分析

### 动态规划：
- **时间复杂度：** O(n)，遍历一次数组
- **空间复杂度：** O(1)，只使用两个变量

### 贪心算法：
- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 图解示例

以 `prices = [1,3,2,8,4,9]`, `fee = 2` 为例：

```
Day 0: price = 1
  cash = 0 (不持有)
  hold = -1 (买入，花费 1)

Day 1: price = 3
  cash = max(0, -1+3-2) = 0 (卖出不划算)
  hold = max(-1, 0-3) = -1 (继续持有)

Day 3: price = 8
  cash = max(0, -1+8-2) = 5 (卖出！)
  hold = max(-1, 5-8) = -1

Day 4: price = 4
  cash = max(5, -1+4-2) = 5
  hold = max(-1, 5-4) = 1 (买入！)

Day 5: price = 9
  cash = max(5, 1+9-2) = 8 (卖出！)

最终利润: 8
```

## 关键点总结

1. **状态定义**：持有和不持有两种状态，维护各自的最大利润
2. **手续费扣除时机**：可以在买入或卖出时扣除，结果相同
3. **空间优化**：只需要维护两个变量，不需要数组
4. **贪心策略**：维护最低买入价，遇到好机会就卖出
5. **最终状态**：返回不持有股票的利润（一定最优）

## 易错点

1. **初始状态错误**：`hold` 初始化为 `-prices[0]`，不是 0
2. **手续费重复扣除**：每笔交易只扣一次，不要在买入和卖出时都扣
3. **状态污染**：更新 cash 和 hold 时，要用前一天的值
4. **返回值错误**：应该返回 `cash`，不是 `Math.max(cash, hold)`
5. **贪心算法的买入价更新**：卖出后更新为 `price - fee`，不是 `price`
