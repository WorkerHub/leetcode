## 题目描述

给定整数数组 nums 和整数 k，返回恰好包含 k 个奇数的连续子数组数量（"优美子数组"）。

**示例：**
```
输入：nums = [1,1,2,1,1], k = 3
输出：2（[1,1,2,1] 和 [1,2,1,1]）
```

## 解题思路

前缀和 + 哈希表：将奇数记为 1、偶数记为 0，问题转化为前缀和之差为 k 的子数组计数。

## Java 代码实现

```java
class Solution {
    public int numberOfSubarrays(int[] nums, int k) {
        // prefixCount[i] = 前缀中奇数个数为 i 的前缀数量
        Map<Integer, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0, 1);
        int oddCount = 0, result = 0;
        
        for (int num : nums) {
            if (num % 2 != 0) oddCount++;
            // 查找前缀和为 oddCount - k 的个数
            result += prefixCount.getOrDefault(oddCount - k, 0);
            prefixCount.merge(oddCount, 1, Integer::sum);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **转化为前缀和问题**：奇数个数的前缀和之差 = k
2. **哈希表计数**：记录每个前缀和出现次数
3. **经典模式**：与 "子数组和为 K" 完全相同
