## 题目描述

给定冰淇淋价格数组和零花钱，返回最多能买几支。

## 解题思路

贪心：排序后从最便宜的开始买，直到钱不够。

## Java 代码实现

```java
class Solution {
    public int maxIceCream(int[] costs, int coins) {
        Arrays.sort(costs);
        int count = 0;
        for (int cost : costs) {
            if (coins >= cost) {
                coins -= cost;
                count++;
            } else {
                break;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心策略**：优先买最便宜的
2. **排序后遍历**：不够钱就break
3. **简单直接**
