## 题目描述

给定一个二叉树的根节点 `root`，和一个整数 `targetSum`，求该二叉树里节点值之和等于 `targetSum` 的路径的数目。

路径不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/04/09/pathsum3-1-tree.jpg)

```
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条，如图所示。
```

**示例 2：**
```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3
```

**提示：**
- 二叉树的节点个数的范围是 `[0, 1000]`
- `-10^9 <= Node.val <= 10^9`
- `-1000 <= targetSum <= 1000`

## 解题思路

这道题要求找到所有路径和等于目标值的路径数量。关键是路径可以从任意节点开始。

**关键观察：**
1. 路径必须是向下的（父到子）
2. 路径可以不从根节点开始，也可以不在叶子结束
3. 可以使用前缀和的思想

**算法流程：**

**方法一：双重递归**
1. 对每个节点，计算从该节点开始的所有路径
2. 递归处理左右子树

**方法二：前缀和 + 哈希表**
1. 维护从根到当前节点的路径和
2. 使用哈希表记录前缀和出现的次数
3. 如果 `当前和 - targetSum` 在哈希表中，说明存在符合条件的路径

## Java 代码实现

### 方法一：双重递归

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        if (root == null) return 0;
        
        // 从当前节点开始的路径数 + 左子树的路径数 + 右子树的路径数
        return pathSumFrom(root, (long) targetSum)
             + pathSum(root.left, targetSum)
             + pathSum(root.right, targetSum);
    }
    
    // 计算从 node 开始的路径数（使用 long 防止节点值累加溢出）
    private int pathSumFrom(TreeNode node, long target) {
        if (node == null) return 0;
        
        int count = (node.val == target) ? 1 : 0;
        
        // 继续在左右子树中查找
        count += pathSumFrom(node.left, target - node.val);
        count += pathSumFrom(node.right, target - node.val);
        
        return count;
    }
}
```

### 方法二：前缀和 + 哈希表 ⭐ 推荐

```java
import java.util.*;

class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        // 前缀和计数，初始化空路径的和为 0
        Map<Long, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0L, 1);
        return dfs(root, 0L, (long) targetSum, prefixCount);
    }
    
    private int dfs(TreeNode node, long currSum, long target, Map<Long, Integer> prefixCount) {
        if (node == null) return 0;
        
        // 更新当前路径和
        currSum += node.val;
        
        // 查找有多少个前缀和等于 currSum - target
        // 如果存在，说明从那个前缀到当前节点的路径和为 target
        int count = prefixCount.getOrDefault(currSum - target, 0);
        
        // 记录当前前缀和
        prefixCount.put(currSum, prefixCount.getOrDefault(currSum, 0) + 1);
        
        // 递归处理左右子树
        count += dfs(node.left, currSum, target, prefixCount);
        count += dfs(node.right, currSum, target, prefixCount);
        
        // 回溯：移除当前节点的前缀和
        prefixCount.put(currSum, prefixCount.get(currSum) - 1);
        
        return count;
    }
}
```

### 方法三：简化的双重递归

```java
class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        if (root == null) return 0;
        
        // 从根开始 + 从左子树开始 + 从右子树开始
        return dfs(root, (long) targetSum)
             + pathSum(root.left, targetSum)
             + pathSum(root.right, targetSum);
    }
    
    // 从 node 开始，和为 target 的路径数
    private int dfs(TreeNode node, long target) {
        if (node == null) return 0;
        
        int count = (node.val == target) ? 1 : 0;
        count += dfs(node.left, target - node.val);
        count += dfs(node.right, target - node.val);
        
        return count;
    }
}
```

## 复杂度分析

**方法一：双重递归**
- 时间复杂度：O(n²)
  - 最坏情况下（链表形），每个节点都要遍历其下所有节点
- 空间复杂度：O(h)，h 是树的高度（递归栈）

**方法二：前缀和**
- 时间复杂度：O(n)，每个节点访问一次
- 空间复杂度：O(h)，递归栈和哈希表

## 关键点总结

1. **前缀和思想**：利用前缀和快速计算子路径和
2. **哈希表优化**：记录前缀和出现次数，避免重复计算
3. **回溯处理**：递归返回时要恢复哈希表状态
4. **路径方向**：只能从父到子，不能回头
5. **初始化**：`prefixCount.put(0L, 1)` 表示空路径

## 易错点

1. **整数溢出**：节点值最大 10^9，路径最长 1000 个节点，路径和可达 10^12，必须使用 long
2. **回溯遗漏**：递归返回时要移除当前前缀和
3. **初始值**：要初始化 `prefixCount.put(0L, 1)`
4. **路径定义**：路径必须连续向下，不能跳跃
5. **重复计数**：同一路径不能重复计数
