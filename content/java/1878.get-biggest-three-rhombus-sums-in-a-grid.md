## 题目描述

在矩阵中找最大的三个不同菱形和（菱形边界上格子之和），降序返回。

## 解题思路

枚举所有中心和半径，用对角线前缀和O(1)计算菱形边界和。维护最大3个不同值的集合。

## Java 代码实现

```java
class Solution {
    public int[] getBiggestThree(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        TreeSet<Integer> top3 = new TreeSet<>();
        
        // 对角线前缀和
        // dl[i][j]: 从左上到(i,j)的'\'方向前缀和
        // dr[i][j]: 从右上到(i,j)的'/'方向前缀和
        int[][] dl = new int[m][n], dr = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dl[i][j] = grid[i][j] + (i > 0 && j > 0 ? dl[i-1][j-1] : 0);
                dr[i][j] = grid[i][j] + (i > 0 && j < n-1 ? dr[i-1][j+1] : 0);
            }
        }
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                addTop3(top3, grid[i][j]); // k=0
                int maxK = Math.min(Math.min(i, m - 1 - i), Math.min(j, n - 1 - j));
                for (int k = 1; k <= maxK; k++) {
                    // 计算菱形和：四条对角线段
                    int sum = getLineSum(dl, i-k, j, i, j+k) 
                            + getLineSum(dl, i, j-k, i+k, j)
                            + getLineSum(dr, i-k, j, i, j-k)
                            + getLineSum(dr, i, j+k, i+k, j)
                            - grid[i-k][j] - grid[i+k][j] - grid[i][j-k] - grid[i][j+k];
                    addTop3(top3, sum);
                }
            }
        }
        
        int[] result = new int[top3.size()];
        int idx = 0;
        for (int val : top3.descendingSet()) result[idx++] = val;
        return result;
    }
    
    // 获取'\' 方向从(r1,c1)到(r2,c2)的线段和
    private int getLineSum(int[][] dl, int r1, int c1, int r2, int c2) {
        return dl[r2][c2] - (r1 > 0 && c1 > 0 ? dl[r1-1][c1-1] : 0);
    }
    
    private void addTop3(TreeSet<Integer> set, int val) {
        set.add(val);
        if (set.size() > 3) set.pollFirst();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N × min(M,N))
- **空间复杂度**：O(M × N)

## 关键点总结

1. **对角线前缀和**：O(1)计算菱形边段和
2. **TreeSet维护top3**：自动排序去重
3. **四顶点去重**：被相邻两边各计算一次需减去
