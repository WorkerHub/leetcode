## 题目描述

技能等级为 `r` 的机械师修 `n` 辆车需要 `r * n^2` 分钟，所有机械师可同时工作，返回修完所有 `cars` 辆车的最少时间。

## 解题思路

**二分答案**：二分时间 `t`，验证在时间 `t` 内所有机械师合计能修的车辆数是否 `>= cars`。技能等级 `r` 的机械师在时间 `t` 内最多修 `floor(sqrt(t / r))` 辆。

## Java 代码实现

```java
class Solution {
    public long repairCars(int[] ranks, int cars) {
        // 二分范围：[1, min_rank * cars^2]
        long lo = 1, hi = (long) getMin(ranks) * cars * cars;

        while (lo < hi) {
            long mid = (lo + hi) / 2;
            if (canFinish(ranks, cars, mid)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private boolean canFinish(int[] ranks, int cars, long t) {
        long total = 0;
        for (int r : ranks) {
            total += (long) Math.sqrt((double) t / r); // floor(sqrt(t/r))
            if (total >= cars) return true; // 提前终止
        }
        return total >= cars;
    }

    private int getMin(int[] arr) {
        int min = arr[0];
        for (int x : arr) min = Math.min(min, x);
        return min;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log(min_rank * cars^2))，二分 × 验证 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 二分时间，验证可行性
2. rank=r 的机械师在时间 t 内能修 `floor(sqrt(t/r))` 辆
3. 二分上界：最快机械师（rank 最小）单独修完所有车的时间，注意用 `long` 防溢出
