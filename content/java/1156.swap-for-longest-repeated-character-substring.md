## 题目描述

给定字符串 text，可以交换其中两个字符（最多一次），返回交换后最长重复字符子串的长度。

**示例：**
```
输入: text = "aaabaaa"
输出: 6（交换 'b' 和末尾 'a'，得到 "aaaaaa b"→长度6）
```

## 解题思路

分组统计连续相同字符块，考虑两种情况：
1. 单块 + 从别处交换一个字符过来延长
2. 两块中间只隔一个字符，合并后可能再 +1

## Java 代码实现

```java
class Solution {
    public int maxRepOpt1(String text) {
        // 统计每个字符的总数
        int[] count = new int[26];
        for (char c : text.toCharArray()) count[c - 'a']++;

        // 分组：记录每个连续块的字符和长度
        List<int[]> groups = new ArrayList<>(); // {字符索引, 长度}
        int i = 0, n = text.length();
        while (i < n) {
            int j = i;
            while (j < n && text.charAt(j) == text.charAt(i)) j++;
            groups.add(new int[]{text.charAt(i) - 'a', j - i});
            i = j;
        }

        int maxLen = 0;
        for (int idx = 0; idx < groups.size(); idx++) {
            int ch = groups.get(idx)[0], len = groups.get(idx)[1];
            // 情况1：单块，从其他位置交换一个过来
            maxLen = Math.max(maxLen, Math.min(len + 1, count[ch]));

            // 情况2：两块中间只隔一个字符，合并
            if (idx + 2 < groups.size()
                && groups.get(idx + 2)[0] == ch
                && groups.get(idx + 1)[1] == 1) {
                int combined = len + groups.get(idx + 2)[1];
                // 如果总数大于合并长度，还能再交换一个过来
                maxLen = Math.max(maxLen, Math.min(combined + 1, count[ch]));
            }
        }
        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，分组列表

## 关键点总结

1. **字符总数限制**：结果不能超过该字符总出现次数
2. **分组统计**：连续相同字符为一组
3. **两种合并**：单块+1 和 跨间隔合并+1
4. **间隔检查**：中间块长度必须为 1 才能合并
