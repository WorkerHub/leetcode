## 题目描述

与 3176 题相同（最长好子序列），但数据范围更大：`n` 最大 10^5，`k` 最大 10^3，需要 O(n×k) 算法。

## 解题思路

与 3176 方法相同，使用哈希表维护每个值结尾的 DP 状态，并维护全局最优。关键在于：接在"不同值"后时，若全局最优恰好来自值 x 本身，则应使用全局次优，以避免错误地将相同值计为不同。需维护每个 j 的最优值和对应的数值，以及次优值。

## Java 代码实现

```java
class Solution {
    public int maximumLength(int[] nums, int k) {
        Map<Integer, int[]> best = new HashMap<>();
        // top1[j], top2[j]: 全局最优和次优（用于处理"不同值"排除自身）
        int[] top1 = new int[k + 1], top2 = new int[k + 1];
        int[] top1Val = new int[k + 1];
        Arrays.fill(top1Val, -1);
        int ans = 0;

        for (int x : nums) {
            int[] old = best.getOrDefault(x, new int[k + 1]);
            int[] nb = new int[k + 1];
            for (int j = 0; j <= k; j++) {
                // 接在相同值后
                nb[j] = old[j] + 1;
                // 接在不同值后，排除自身贡献
                if (j > 0) {
                    int add = (top1Val[j - 1] != x) ? top1[j - 1] : top2[j - 1];
                    nb[j] = Math.max(nb[j], add + 1);
                }
            }
            // 更新 best[x]
            int[] cur = best.computeIfAbsent(x, v -> new int[k + 1]);
            for (int j = 0; j <= k; j++) {
                cur[j] = Math.max(cur[j], nb[j]);
            }
            // 更新全局最优
            for (int j = 0; j <= k; j++) {
                int v = cur[j];
                if (v >= top1[j]) {
                    if (top1Val[j] != x) top2[j] = top1[j];
                    top1[j] = v;
                    top1Val[j] = x;
                } else if (v > top2[j] && top1Val[j] != x) {
                    top2[j] = v;
                }
                ans = Math.max(ans, v);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)
- **空间复杂度**：O(V × k)，V 为不同值数量

## 关键点总结

1. 接在不同值后时需排除自身（x）的全局贡献，使用次优值
2. 维护每个 j 的全局最优值和次优值及对应的数值
3. 先算新值，再更新 best[x]，最后更新全局
