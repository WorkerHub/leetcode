## 题目描述

判断矩阵是否满足：同列元素相等且相邻列值不同。

## 解题思路

遍历每列检查所有元素与首行相同，再检查相邻列首行值不同。

## Java 代码实现

```java
class Solution {
    public boolean satisfiesConditions(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        for (int j = 0; j < n; j++) {
            for (int i = 1; i < m; i++) {
                if (grid[i][j] != grid[0][j]) return false;
            }
            if (j > 0 && grid[0][j] == grid[0][j - 1]) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N)
- **空间复杂度**：O(1)

## 关键点总结

1. **同列相等**：每列所有元素等于grid[0][j]
2. **相邻列不等**：比较第一行即可
3. **两个条件一趟遍历同时检查**
