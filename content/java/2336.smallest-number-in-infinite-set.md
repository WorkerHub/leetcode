## 题目描述

实现 `SmallestInfiniteSet` 类，初始包含所有正整数，支持 `popSmallest()`（移除并返回最小值）和 `addBack(num)`（将正整数加回集合，若已存在则忽略）。

## 解题思路

用指针 `cur` 表示"连续正整数从哪开始"，用最小堆存放被加回来的数（均 < cur）。`popSmallest` 优先取堆顶，堆空或堆顶 >= cur 时取 cur 并自增。用 HashSet 避免重复入堆。

## Java 代码实现

```java
import java.util.*;

class SmallestInfiniteSet {
    private int cur = 1;
    private PriorityQueue<Integer> heap = new PriorityQueue<>();
    private Set<Integer> inHeap = new HashSet<>();

    public int popSmallest() {
        if (!heap.isEmpty() && heap.peek() < cur) {
            int val = heap.poll();
            inHeap.remove(val);
            return val;
        }
        return cur++; // 取 cur 并自增
    }

    public void addBack(int num) {
        // 只对 num < cur 且不在堆中的情况有效
        if (num < cur && inHeap.add(num)) {
            heap.offer(num);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：`popSmallest` O(log n)，`addBack` O(log n)
- **空间复杂度**：O(n)，n 为 addBack 调用次数

## 关键点总结

1. 用 `cur` 指针维护"未被取出的连续正整数起点"。
2. 最小堆仅存放被加回来的数（都 < cur），保证取最小值正确。
3. HashSet 防止重复加入堆，保持堆的正确性。
