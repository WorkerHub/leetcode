## 题目描述

两个内存条，第i秒从较大的分配i位内存（相等选第一个），直到两个都不够分配i位时崩溃。返回[崩溃时间, 剩余内存1, 剩余内存2]。

## 解题思路

直接模拟：步数约sqrt(2*总内存)≈63246次，可接受。

## Java 代码实现

```java
class Solution {
    public int[] memLeak(int memory1, int memory2) {
        int i = 1;
        while (memory1 >= i || memory2 >= i) {
            if (memory1 >= memory2) {
                memory1 -= i;
            } else {
                memory2 -= i;
            }
            i++;
        }
        return new int[]{i, memory1, memory2};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sqrt(M))，M为总内存
- **空间复杂度**：O(1)

## 关键点总结

1. **循环条件**：至少一个够分配就继续（or）
2. **相等选第一个**：memory1 >= memory2 时选内存条1
3. **步数有限**：约63000次，无需优化
