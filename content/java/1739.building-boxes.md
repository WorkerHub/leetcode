## 题目描述

给定整数 `n`，在角落里堆放 `n` 个盒子（下层支撑上层），返回接触地板的最少盒子数量。

## 解题思路

三角数规律：前 `k` 层完整堆放总容量为 `k*(k+1)*(k+2)/6`，底面积为 `k*(k+1)/2`。找最大完整层数 `k` 后，剩余盒子额外放在斜面上，每新增一个底面格可多放若干个盒子（累积三角数）。

## Java 代码实现

```java
class Solution {
    public int minimumBoxes(int n) {
        // 找最大完整层数 k，使 k*(k+1)*(k+2)/6 <= n
        int k = 0;
        long total = 0;
        while (total + (long)(k + 1) * (k + 2) / 2 <= n) {
            k++;
            total += (long) k * (k + 1) / 2; // 第 k 层新增的盒子数
        }

        // k 层的底面积
        int base = k * (k + 1) / 2;

        // 剩余需要放的盒子数
        long remaining = n - total;

        // 额外底面格：第 j 个额外格累计可放 j*(j+1)/2 个盒子
        int extra = 0;
        while ((long) extra * (extra + 1) / 2 < remaining) {
            extra++;
        }

        return base + extra;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^(1/3))
- **空间复杂度**：O(1)

## 关键点总结

1. 前 k 层总容量为三维三角数 `k*(k+1)*(k+2)/6`
2. 先找最大完整层数，再处理剩余盒子需要的额外底面格
3. 注意用 `long` 防止整数溢出
