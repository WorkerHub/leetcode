## 题目描述

给你一个链表，返回一个包含链表中每个唯一值出现频率的链表，结果顺序任意。

## 解题思路

遍历链表用哈希表统计每个值的频率，再将频率值构建成新链表返回。

## Java 代码实现

```java
class Solution {
    public ListNode frequenciesOfElements(ListNode head) {
        // 统计每个值的出现频率
        Map<Integer, Integer> freq = new HashMap<>();
        for (ListNode node = head; node != null; node = node.next) {
            freq.merge(node.val, 1, Integer::sum);
        }
        // 将频率值构建成新链表
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        for (int count : freq.values()) {
            cur.next = new ListNode(count);
            cur = cur.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，遍历链表一次
- **空间复杂度**：O(k)，k 为不同值的数量

## 关键点总结

1. 哈希表高效统计频率
2. 频率值即为结果链表的节点值
3. 结果顺序任意，遍历 map 的 values 即可
