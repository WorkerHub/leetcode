## 题目描述

恶魔们抓住了公主并将她关在了地下城 `dungeon` 的**右下角**。地下城是由 `m x n` 个房间组成的二维网格。我们英勇的骑士最初被安置在**左上角**的房间里，他必须穿过地下城并通过对抗恶魔来拯救公主。

骑士的初始健康点数为一个正整数。如果他的健康点数在某一时刻降至 0 或以下，他会立即死亡。

有些房间由恶魔守卫，因此骑士在进入这些房间时会失去健康点数（若房间里的值为负整数，则表示骑士将损失健康点数）；其他房间要么是空的（房间里的值为 0），要么包含增加骑士健康点数的魔法球（若房间里的值为正整数，则表示骑士将增加健康点数）。

为了尽快解救公主，骑士决定每次只**向右**或**向下**移动一步。

返回确保骑士能够拯救到公主所需的最低初始健康点数。

**注意：** 任何房间都可能对骑士的健康点数造成威胁，也可能增加骑士的健康点数，包括骑士进入的左上角房间以及公主被监禁的右下角房间。

**示例 1：**
```
输入：dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]]
输出：7
解释：如果骑士遵循最佳路径：右 -> 右 -> 下 -> 下 ，则骑士的初始健康点数至少为 7 。
```

**示例 2：**
```
输入：dungeon = [[0]]
输出：1
```

**提示：**
- m == dungeon.length
- n == dungeon[i].length
- 1 <= m, n <= 200
- -1000 <= dungeon[i][j] <= 1000

## 解题思路

这是一道**逆向动态规划**的经典题目。

### 为什么不能从左上到右下？

**错误思路：** 从 (0,0) 出发，记录最小初始血量。

**问题：** 
- 路径的最优性取决于**终点状态**而非起点
- 中间可能有大量增益，但最后一步掉血很多
- 无法用贪心或传统 DP 解决

**正确思路：** 从右下角**逆向推导**。

### 逆向 DP 思路

**状态定义：**
`dp[i][j]` = 从 (i,j) 到达终点所需的**最低初始血量**

**转移方程：**
```
dp[i][j] = max(1, min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j])
```

**解释：**
1. 从 (i,j) 可以向右或向下，选择需求血量更少的方向
2. `min(dp[i+1][j], dp[i][j+1])` 是下一步的需求
3. 减去当前房间的影响 `dungeon[i][j]`
4. 血量至少为 1，所以 `max(1, ...)`

**边界条件：**
- 终点：`dp[m-1][n-1] = max(1, 1 - dungeon[m-1][n-1])`
- 最后一行：只能向右
- 最后一列：只能向下

**关键点：**
- 从右下往左上推导
- 每个位置保证到达时血量 >= 1

## Java 代码实现

### 方法一：二维 DP（推荐）

```java
class Solution {
    public int calculateMinimumHP(int[][] dungeon) {
        int m = dungeon.length;
        int n = dungeon[0].length;

        // dp[i][j] 表示从 (i,j) 到终点所需的最低初始血量
        int[][] dp = new int[m + 1][n + 1];

        // 初始化为最大值（不可达状态）
        for (int[] row : dp) {
            java.util.Arrays.fill(row, Integer.MAX_VALUE);
        }

        // 边界：终点右边和下边设为 1（虚拟节点）
        dp[m][n - 1] = 1;
        dp[m - 1][n] = 1;

        // 从右下往左上遍历
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                // 需要的血量 = 下一步的最小需求 - 当前房间的影响
                int minHp = Math.min(dp[i + 1][j], dp[i][j + 1]) - dungeon[i][j];
                // 血量至少为 1
                dp[i][j] = Math.max(1, minHp);
            }
        }

        return dp[0][0];
    }
}
```

### 方法二：空间优化（一维 DP）

```java
class Solution {
    public int calculateMinimumHP(int[][] dungeon) {
        int m = dungeon.length;
        int n = dungeon[0].length;

        // 只需要一行的空间
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE);
        dp[n - 1] = 1;  // 终点右边的虚拟节点

        // 从右下往左上遍历
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (i == m - 1 && j == n - 1) {
                    // 终点
                    dp[j] = Math.max(1, 1 - dungeon[i][j]);
                } else {
                    // 状态转移
                    int minHp = Math.min(dp[j], dp[j + 1]) - dungeon[i][j];
                    dp[j] = Math.max(1, minHp);
                }
            }
        }

        return dp[0];
    }
}
```

### 方法三：带注释的详细版本

```java
class Solution {
    public int calculateMinimumHP(int[][] dungeon) {
        int m = dungeon.length;
        int n = dungeon[0].length;

        // 创建 DP 表，多一行一列用于边界处理
        int[][] dp = new int[m + 1][n + 1];

        // 初始化边界为最大值（不可达）
        for (int i = 0; i <= m; i++) {
            dp[i][n] = Integer.MAX_VALUE;
        }
        for (int j = 0; j <= n; j++) {
            dp[m][j] = Integer.MAX_VALUE;
        }

        // 终点的右边和下边设为 1
        dp[m][n - 1] = 1;
        dp[m - 1][n] = 1;

        // 从右下到左上填表
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                // 到达下一步所需的最低血量
                int minNext = Math.min(dp[i + 1][j], dp[i][j + 1]);

                // 当前位置需要的血量 = 下一步需求 - 当前房间影响
                int need = minNext - dungeon[i][j];

                // 血量不能低于 1
                dp[i][j] = Math.max(1, need);
            }
        }

        return dp[0][0];
    }
}
```

## 复杂度分析

**时间复杂度：** O(m × n)
- 遍历整个矩阵一次

**空间复杂度：**
- 方法一：O(m × n)
- 方法二：O(n)，只用一行空间

## 图解示例

以 `dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]]` 为例：

```
地牢：
-2  -3   3
-5 -10   1
10  30  -5

逆向 DP 过程：

步骤1：终点 (2,2)
  dp[2][2] = max(1, 1 - (-5)) = max(1, 6) = 6

步骤2：最后一行
  dp[2][1] = max(1, 6 - 30) = max(1, -24) = 1
  dp[2][0] = max(1, 1 - 10) = max(1, -9) = 1

步骤3：最后一列
  dp[1][2] = max(1, 6 - 1) = 5
  dp[0][2] = max(1, 5 - 3) = 2

步骤4：中间位置
  dp[1][1] = max(1, min(1, 5) - (-10)) = max(1, 11) = 11
  dp[1][0] = max(1, min(1, 11) - (-5)) = max(1, 6) = 6
  dp[0][1] = max(1, min(11, 2) - (-3)) = max(1, 5) = 5
  dp[0][0] = max(1, min(6, 5) - (-2)) = max(1, 7) = 7

最终 DP 表：
 7   5   2
 6  11   5
 1   1   6

答案：dp[0][0] = 7
```

**最优路径验证：**
```
起点血量：7
(0,0): 7 - 2 = 5
(0,1): 5 - 3 = 2
(0,2): 2 + 3 = 5
(1,2): 5 + 1 = 6
(2,2): 6 - 5 = 1（到达终点，血量 >= 1）
```

## 关键点总结

1. **逆向思维**：从终点倒推到起点
2. **血量限制**：任何时刻血量必须 >= 1
3. **状态定义**：到达某点所需的最低初始血量
4. **边界处理**：虚拟节点简化边界条件
5. **贪心选择**：选择下一步需求更小的方向

## 易错点

1. **正向 DP 陷阱**
   - 从左上到右下无法得到正确答案
   - 必须逆向推导

2. **忘记 Math.max(1, ...)**
   - 血量不能为 0 或负数
   - 即使下一步需求为 0，当前也至少需要 1

3. **边界初始化错误**
   - 终点旁边的虚拟节点应为 1，不是 0
   - 其他边界为 `Integer.MAX_VALUE`

4. **状态转移方向错误**
   - 应该是 `minNext - dungeon[i][j]`
   - 不是 `dungeon[i][j] - minNext`

5. **遍历顺序**
   - 必须从右下到左上
   - `for (int i = m - 1; i >= 0; i--)`

3. **手动演算**：在纸上画出 DP 表的填充过程

**进阶学习：**
1. 理解何时需要逆向 DP
2. 掌握虚拟节点简化边界的技巧
3. 学习空间优化方法

**逆向 DP 的应用场景：**
- 终点状态影响中间决策
- 需要保证全局约束（如血量 >= 1）
- 贪心策略无法从起点确定

**调试技巧：**
- 打印 DP 表验证每个位置
- 手动模拟一条路径验证答案
- 检查边界条件是否正确

**Java 技巧：**
- `Integer.MAX_VALUE` 表示最大整数值（代替无穷大）
- `Math.min(a, b)` 求两数最小值
- `Math.max(1, need)` 确保血量不低于 1
- `Arrays.fill(arr, value)` 快速初始化数组

**测试用例：**
```java
[[-2,-3,3],[-5,-10,1],[10,30,-5]] -> 7
[[0]] -> 1
[[1,-3,3],[0,-2,0],[-3,-3,-3]] -> 3
[[-200]] -> 201
[[100]] -> 1
```

**常见错误示例：**
```java
// 错误：正向 DP
dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]) + dungeon[i][j];

// 正确：逆向 DP
dp[i][j] = Math.max(1, Math.min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j]);
```
