## 题目描述

给定整数数组 `nums`，对每个下标 i（1 <= i <= n-2），若 `nums[i]` 大于左侧所有元素且小于右侧所有元素则美丽值为 2，仅满足 `nums[i-1] < nums[i] < nums[i+1]` 则为 1，否则为 0，返回美丽值之和。

## 解题思路

预处理前缀最大值 `prefixMax[i]` 和后缀最小值 `suffixMin[i]`，对每个 i 先判断是否满足美丽值 2，再判断美丽值 1。

## Java 代码实现

### 方法一：前缀最大值 + 后缀最小值（推荐）

```java
class Solution {
    public int sumOfBeauties(int[] nums) {
        int n = nums.length;
        int[] prefixMax = new int[n];
        int[] suffixMin = new int[n];

        prefixMax[0] = nums[0];
        for (int i = 1; i < n; i++) prefixMax[i] = Math.max(prefixMax[i-1], nums[i]);

        suffixMin[n-1] = nums[n-1];
        for (int i = n - 2; i >= 0; i--) suffixMin[i] = Math.min(suffixMin[i+1], nums[i]);

        int result = 0;
        for (int i = 1; i < n - 1; i++) {
            if (prefixMax[i-1] < nums[i] && nums[i] < suffixMin[i+1]) {
                result += 2; // 严格大于左侧所有，严格小于右侧所有
            } else if (nums[i-1] < nums[i] && nums[i] < nums[i+1]) {
                result += 1; // 仅满足相邻元素条件
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 预处理前缀最大值和后缀最小值是关键
2. 先判断条件 2（更严格），再判断条件 1，两者互斥
3. 注意下标范围：i 从 1 到 n-2，不含首尾
