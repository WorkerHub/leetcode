## 题目描述

删除最少数字使数字能被25整除。

## 解题思路

能被25整除的数末尾为00/25/50/75。对每种末尾从右向左找两个字符，计算需删除的数。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(String num) {
        int n = num.length();
        int ans = n - 1; // 最坏保留一个0

        String[] targets = {"00", "25", "50", "75"};
        for (String target : targets) {
            // 从右向左找target[1]
            int j = n - 1;
            while (j >= 0 && num.charAt(j) != target.charAt(1)) j--;
            if (j < 0) continue;
            // 从j-1向左找target[0]
            int i = j - 1;
            while (i >= 0 && num.charAt(i) != target.charAt(0)) i--;
            if (i < 0) continue;
            // 删除数 = j右边的 + i和j之间的
            int ops = (n - 1 - j) + (j - 1 - i);
            ans = Math.min(ans, ops);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **被25整除末尾只有4种**：00/25/50/75
2. **从右向左贪心找**：保留尽量多字符
3. **最坏情况删到只剩0**：ans初始为n-1
