## 题目描述

给定 `m x n` 矩阵 `grid` 和整数 `k`，统计元素和不超过 `k` 的子矩阵数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countSubmatrixesWithSumAtMostK(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;

        for (int r1 = 0; r1 < m; r1++) {
            int[] colSum = new int[n];
            for (int r2 = r1; r2 < m; r2++) {
                // 更新每列在 [r1, r2] 行的累计和
                for (int j = 0; j < n; j++) colSum[j] += grid[r2][j];

                // 统计 colSum 中子数组和 <= k 的数量（前缀和 + TreeMap）
                TreeMap<Long, Integer> sortedPrefixes = new TreeMap<>();
                sortedPrefixes.put(0L, 1);
                long cur = 0;
                for (int s : colSum) {
                    cur += s;
                    // 找满足 cur - prev <= k 的 prev，即 prev >= cur - k
                    Long floor = cur - k;
                    NavigableMap<Long, Integer> sub = sortedPrefixes.tailMap(floor, true);
                    for (int cnt : sub.values()) ans += cnt;
                    sortedPrefixes.merge(cur, 1, Integer::sum);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m² * n log n)
- 空间复杂度：O(n)，前缀和空间

## 关键点总结

1. 枚举行范围将二维问题降维为一维子数组和问题
2. 一维子数组和 ≤ k 的计数用前缀和 + TreeMap 实现
3. TreeMap 的 `tailMap` 方法快速统计满足条件的前缀和数量
