## 题目描述

给你整数数组 `nums` 和整数 `k`，找按位或 OR 值至少为 k 的最短子数组长度，不存在返回 -1。

## 解题思路

滑动窗口 + 位计数数组：用 `bitCount[b]` 记录窗口内第 b 位为 1 的元素个数，移出元素时若某位计数归零则从 OR 中清除该位，从而支持 O(30) 的窗口 OR 维护。

## Java 代码实现

```java
class Solution {
    public int minimumSubarrayLength(int[] nums, int k) {
        if (k == 0) return 1;
        int n = nums.length;
        int[] bitCount = new int[30];
        int curOr = 0, left = 0, ans = Integer.MAX_VALUE;

        for (int right = 0; right < n; right++) {
            // 加入 nums[right]
            for (int b = 0; b < 30; b++) {
                if (((nums[right] >> b) & 1) == 1) {
                    if (++bitCount[b] == 1) curOr |= (1 << b);
                }
            }
            // 收缩：当 OR >= k 时尝试缩短窗口
            while (curOr >= k && left <= right) {
                ans = Math.min(ans, right - left + 1);
                for (int b = 0; b < 30; b++) {
                    if (((nums[left] >> b) & 1) == 1) {
                        if (--bitCount[b] == 0) curOr &= ~(1 << b);
                    }
                }
                left++;
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 30) = O(n)
- 空间复杂度：O(30) = O(1)

## 关键点总结

1. 位计数数组解决 OR 不可逆问题，计数归零时清除对应位
2. 滑动窗口：OR >= k 时收缩左边界
