## 题目描述

你总共需要上 `n` 门课，课程编号依次为 `0` 到 `n-1`。

给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]` 表示如果你想学课程 `bi`，你**必须**先学课程 `ai`。（先修课关系为直接或间接的）

给你一个数组 `queries`，其中 `queries[j] = [uj, vj]`，请你判断课程 `uj` 是否是课程 `vj` 的先修课。

注意：题目给出的先修课关系是**传递**的。如果课程 a 是课程 b 的先修课，课程 b 是课程 c 的先修课，那么课程 a 也是课程 c 的先修课。

请你返回一个布尔数组 `answer`，其中 `answer[j]` 是第 `j` 个查询的答案。

**示例 1：**
```
输入：n = 2, prerequisites = [[1,0]], queries = [[0,1],[1,0]]
输出：[false, true]
解释：课程 0 不是课程 1 的先修课，但课程 1 是课程 0 的先修课。
```

**示例 2：**
```
输入：n = 2, prerequisites = [[1,0],[0,1]], queries = [[1,0],[1,1]]
输出：[true, true]
```

**示例 3：**
```
输入：n = 3, prerequisites = [[1,2],[1,0],[2,0]], queries = [[1,0],[1,2]]
输出：[true, true]
```

**提示：**
- `2 <= n <= 100`
- `0 <= prerequisite.length <= (n * (n-1) / 2)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `ai != bi`
- 每组先修课关系 `[ai, bi]` 都是唯一的
- `1 <= queries.length <= 10^4`
- `queries[j].length == 2`
- `0 <= uj, vj <= n-1`

## 解题思路

**问题本质：有向图的传递闭包**

求图的传递闭包，即判断任意两点 (u, v) 是否存在从 u 到 v 的有向路径。

**方法一：Floyd-Warshall 算法（推荐）**

Floyd-Warshall 是求所有点对之间可达性（传递闭包）的经典算法：

`reachable[i][j] = true` 表示从节点 i 可以到达节点 j。

```
初始化：根据 prerequisites 直接设置 reachable[a][b] = true
更新：对每个中间节点 k：
  若 reachable[i][k] 且 reachable[k][j]，则 reachable[i][j] = true
```

三层循环后，`reachable` 就是完整的传递闭包。

**方法二：对每个节点做 BFS/DFS**

从每个节点出发做 BFS，记录所有可达节点，预处理后 O(1) 回答查询。

## Java 代码实现

### 方法一：Floyd-Warshall 传递闭包（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Boolean> checkIfPrerequisite(int n, int[][] prerequisites, int[][] queries) {
        // reachable[i][j] 表示节点 i 是否可以到达节点 j
        boolean[][] reachable = new boolean[n][n];

        // 初始化直接先修课关系
        for (int[] pre : prerequisites) {
            reachable[pre[0]][pre[1]] = true;
        }

        // Floyd-Warshall：枚举所有中间节点（k 必须在最外层）
        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    // 若 i 能到 k，且 k 能到 j，则 i 能到 j
                    if (reachable[i][k] && reachable[k][j]) {
                        reachable[i][j] = true;
                    }
                }
            }
        }

        // 回答每个查询
        List<Boolean> result = new ArrayList<>();
        for (int[] query : queries) {
            result.add(reachable[query[0]][query[1]]);
        }
        return result;
    }
}
```

### 方法二：BFS 预处理（每个节点做一次 BFS）

```java
import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<Boolean> checkIfPrerequisite(int n, int[][] prerequisites, int[][] queries) {
        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] pre : prerequisites) {
            graph.get(pre[0]).add(pre[1]);
        }

        // reachable[i] 是从节点 i 出发可以到达的所有节点
        boolean[][] reachable = new boolean[n][n];

        // 对每个节点做 BFS
        for (int start = 0; start < n; start++) {
            Deque<Integer> queue = new ArrayDeque<>();
            queue.offer(start);
            boolean[] visited = new boolean[n];
            visited[start] = true;
            while (!queue.isEmpty()) {
                int node = queue.poll();
                for (int neighbor : graph.get(node)) {
                    if (!visited[neighbor]) {
                        visited[neighbor] = true;
                        reachable[start][neighbor] = true;
                        queue.offer(neighbor);
                    }
                }
            }
        }

        // 回答查询
        List<Boolean> result = new ArrayList<>();
        for (int[] query : queries) {
            result.add(reachable[query[0]][query[1]]);
        }
        return result;
    }
}
```

### 方法三：拓扑排序 + 传递闭包

```java
import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<Boolean> checkIfPrerequisite(int n, int[][] prerequisites, int[][] queries) {
        // 构建图和入度
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[n];
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] pre : prerequisites) {
            graph.get(pre[0]).add(pre[1]);
            inDegree[pre[1]]++;
        }

        // preSet[i] 存储节点 i 的所有先修课（包括传递的）
        Set<Integer>[] preSet = new Set[n];
        for (int i = 0; i < n; i++) preSet[i] = new HashSet<>();
        for (int[] pre : prerequisites) {
            preSet[pre[1]].add(pre[0]);
        }

        // 拓扑排序（Kahn 算法）
        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }
        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int neighbor : graph.get(node)) {
                // neighbor 的先修课 = neighbor 的直接先修课 + node 的所有先修课 + node 本身
                preSet[neighbor].add(node);
                preSet[neighbor].addAll(preSet[node]);
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0) queue.offer(neighbor);
            }
        }

        // 回答查询：u 是 v 的先修课 <=> u 在 preSet[v] 中
        List<Boolean> result = new ArrayList<>();
        for (int[] query : queries) {
            result.add(preSet[query[1]].contains(query[0]));
        }
        return result;
    }
}
```

## 复杂度分析

**方法一（Floyd-Warshall）：**
- 时间复杂度：O(n^3 + Q)，n 为课程数，Q 为查询数
- 空间复杂度：O(n^2)，传递闭包矩阵

**方法二（BFS）：**
- 时间复杂度：O(n × (n + E) + Q)，E 为边数
- 空间复杂度：O(n^2)，每个节点的可达集合

## 关键点总结

1. 问题本质是图的**传递闭包**，Floyd-Warshall 是最简洁的解法
2. Floyd-Warshall 三层循环中，k（中间节点）必须在最外层
3. 预处理后，每次查询 O(1) 回答，适合大量查询场景
4. n ≤ 100，O(n^3) 完全够用

## 易错点

- Floyd-Warshall 中，`k` 必须在**最外层**循环，否则结果不正确
- 初始化只设置直接先修课，Floyd-Warshall 会自动推导传递关系
- 方法三中，`preSet[v]` 存的是 v 的先修课，所以查询是 `preSet[v].contains(u)`
