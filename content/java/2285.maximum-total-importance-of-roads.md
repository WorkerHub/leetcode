## 题目描述

给城市分配1到n的值，使所有道路（两端城市值之和）的总重要性最大。

## 解题思路

贪心：度数越大的城市分配越大的值。总重要性=sum(degree[i]*value[i])，排序后依次分配1到n。

## Java 代码实现

```java
class Solution {
    public long maximumImportance(int n, int[][] roads) {
        int[] degree = new int[n];
        for (int[] r : roads) {
            degree[r[0]]++;
            degree[r[1]]++;
        }
        Arrays.sort(degree);

        long ans = 0;
        for (int i = 0; i < n; i++) {
            ans += (long)(i + 1) * degree[i];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N + M)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心**：度数大的城市分配大值
2. **总重要性=sum(degree*value)**：排序对齐最优
3. **long防溢出**：degree*value累加可能超int
