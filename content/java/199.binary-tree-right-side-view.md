## 题目描述

给定一个二叉树的**根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**

```
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]

        1            <---
       / \
      2   3          <---
       \   \
        5   4        <---
        
从右侧看：能看到 1, 3, 4
```

**示例 2：**
```
输入：root = [1,null,3]
输出：[1,3]
```

**示例 3：**
```
输入：root = []
输出：[]
```

**提示：**
- 二叉树的节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`

## 解题思路

这道题要求从右侧观察二叉树，每层只能看到最右边的节点。

**核心思想：**

从右侧看二叉树，每一层只能看到最右边的节点。因此：
- 方法1：层序遍历，取每层的最后一个节点
- 方法2：深度优先遍历，优先遍历右子树，每层第一个访问到的节点就是答案

**解法对比：**

| 方法 | 思路 | 实现难度 |
|------|------|----------|
| BFS 层序遍历 | 每层取最右节点 | 简单直观 |
| DFS 先右后左 | 每层第一次访问的节点 | 需要记录深度 |

## Java 代码实现

### 方法一：BFS 层序遍历（推荐）⭐

```java
import java.util.*;

// Definition for a binary tree node.
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    // BFS 层序遍历，每层取最后一个节点
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();

            // 遍历当前层的所有节点
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();

                // 当前层的最后一个节点
                if (i == levelSize - 1) {
                    result.add(node.val);
                }

                // 将下一层节点加入队列
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }

        return result;
    }
}
```

**时间复杂度：** O(n) - 每个节点访问一次  
**空间复杂度：** O(n) - 队列最多存储一层的节点

### 方法二：BFS 简化版

```java
import java.util.*;

class Solution {
    // BFS 更简洁的写法：直接取每层最后一个节点
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            // 每层最后一个节点就是右视图能看到的（队尾元素）
            result.add(((LinkedList<TreeNode>) queue).peekLast().val);

            // 处理当前层，将下一层加入队列
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }

        return result;
    }
}
```

**时间复杂度：** O(n)  
**空间复杂度：** O(n)

### 方法三：DFS 深度优先（右→左）⭐

```java
import java.util.*;

class Solution {
    private List<Integer> result = new ArrayList<>();

    // DFS 深度优先遍历
    // 优先遍历右子树，保证每层第一个访问的是最右节点
    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        return result;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) {
            return;
        }

        // 如果当前深度第一次访问，说明这是该层最右边的节点
        if (depth == result.size()) {
            result.add(node.val);
        }

        // 先访问右子树，再访问左子树
        dfs(node.right, depth + 1);
        dfs(node.left, depth + 1);
    }
}
```

**时间复杂度：** O(n)  
**空间复杂度：** O(h) - h 为树的高度（递归栈）

### 方法四：DFS 迭代版本

```java
import java.util.*;

class Solution {
    // DFS 迭代实现（使用栈）
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) {
            return result;
        }

        // 栈中存储节点和对应的深度
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{root, 0});

        while (!stack.isEmpty()) {
            Object[] pair = stack.pop();
            TreeNode node = (TreeNode) pair[0];
            int depth = (int) pair[1];

            // 当前深度第一次访问
            if (depth == result.size()) {
                result.add(node.val);
            }

            // 先压左子树，再压右子树（保证右子树先出栈）
            if (node.left != null) {
                stack.push(new Object[]{node.left, depth + 1});
            }
            if (node.right != null) {
                stack.push(new Object[]{node.right, depth + 1});
            }
        }

        return result;
    }
}
```

**时间复杂度：** O(n)  
**空间复杂度：** O(h)

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| BFS 层序 | O(n) | O(w) | w 为树的最大宽度 |
| DFS 递归 | O(n) | O(h) | h 为树的高度 |
| DFS 迭代 | O(n) | O(h) | 栈空间 |

**注意：** 
- 完全二叉树：w ≈ n/2，h = log(n)
- 链式树：w = 1，h = n

## 图解示例

**示例树：**
```
        1            深度 0: [1]      → 取 1
       / \
      2   3          深度 1: [2,3]    → 取 3
       \   \
        5   4        深度 2: [5,4]    → 取 4

右视图：[1, 3, 4]
```

**BFS 过程：**
```
队列变化：
初始: [1]                    → 取 1
第1轮: [2,3]                 → 取 3 (最后一个)
第2轮: [5,4]                 → 取 4 (最后一个)
结果: [1,3,4]
```

**DFS 过程（右→左）：**
```
访问顺序: 1 → 3 → 4 → 2 → 5
深度记录: 0   1   2   1   2

深度0: 第一次访问 → 记录 1
深度1: 第一次访问 → 记录 3
深度2: 第一次访问 → 记录 4
深度1: 已访问过 → 跳过 2
深度2: 已访问过 → 跳过 5
```

## 关键点总结

1. **问题本质**：每层取最右节点
   - BFS：直接取每层最后一个
   - DFS：先右后左，每层第一个访问的就是答案

2. **BFS 优势**：
   - 思路直观，符合题意
   - 代码简单，不易出错
   - 直接按层处理

3. **DFS 技巧**：
   - 使用深度标记访问顺序
   - `depth == result.size()` 判断是否首次访问该层
   - 先右后左的遍历顺序很关键

4. **深度和层的关系**：
   - 深度从 0 开始
   - `result.size()` 表示已访问的层数
   - 两者相等说明进入新层

5. **边界处理**：
   - 空树返回空列表
   - 单节点返回该节点值

## 易错点

1. **BFS 中取错节点**：
   - 错误：取队列第一个节点
   - 正确：取每层最后一个节点（`i == levelSize - 1`）

2. **DFS 遍历顺序错误**：
   - 错误：先左后右（会看到左侧节点）
   - 正确：先右后左

3. **深度判断条件**：
   - 错误：`depth >= result.size()`（会重复添加）
   - 正确：`depth == result.size()`（仅首次添加）

4. **迭代 DFS 的栈顺序**：
   - 错误：先压右，再压左（左先出栈）
   - 正确：先压左，再压右（右先出栈）

5. **空节点处理**：
   - 忘记判断 `if (root == null)`
   - 添加子节点前忘记判空

## 学习建议

1. **掌握两种遍历**：
   - BFS（广度优先）：队列实现，按层访问
   - DFS（深度优先）：递归或栈实现，按深度访问

2. **Java 层序遍历模板**：
   ```java
   Queue<TreeNode> queue = new LinkedList<>();
   queue.offer(root);
   while (!queue.isEmpty()) {
       int levelSize = queue.size();
       for (int i = 0; i < levelSize; i++) {
           TreeNode node = queue.poll();
           // 处理节点
           if (node.left != null) queue.offer(node.left);
           if (node.right != null) queue.offer(node.right);
       }
   }
   ```

3. **DFS 深度记录技巧**：
   - 使用参数传递深度
   - 使用 `result.size()` 判断是否新层
   - 理解先右后左的访问顺序

4. **变体练习**：
   - 左视图：先左后右
   - 每层最大/最小值
   - 每层平均值
   - 之字形遍历

5. **时间空间权衡**：
   - BFS 空间：O(最大宽度)
   - DFS 空间：O(树高度)
   - 根据树的形状选择合适方法

6. **调试技巧**：
   - 画出树的结构

   - 打印中间状态
