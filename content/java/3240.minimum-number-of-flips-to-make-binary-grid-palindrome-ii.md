## 题目描述

与 3239 相同的矩阵回文要求，但额外条件是矩阵中 1 的总数必须能被 4 整除，返回满足条件的最少翻转次数。

## Java 代码实现

```java
class Solution {
    public int minFlips(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int ans = 0;
        int diff = 0; // 当前 1 的总数模 4

        // 处理四格对称组
        for (int i = 0; i < m / 2; i++) {
            for (int j = 0; j < n / 2; j++) {
                int c = grid[i][j] + grid[i][n-1-j]
                      + grid[m-1-i][j] + grid[m-1-i][n-1-j];
                ans += Math.min(c, 4 - c);
                // 四格组翻转后选全 0 或全 1（贡献 0 或 4 个 1，均不影响 mod 4）
                int best = (c >= 2) ? 4 : 0;
                diff = (diff + best) % 4;
            }
        }

        // 中间行（m 为奇数）
        if (m % 2 == 1) {
            int midRow = m / 2;
            for (int j = 0; j < n / 2; j++) {
                int a = grid[midRow][j], b = grid[midRow][n-1-j];
                if (a != b) {
                    ans++;
                    diff = (diff + 2) % 4; // 翻为相同后贡献 2 个 1
                } else {
                    diff = (diff + 2 * a) % 4;
                }
            }
        }

        // 中间列（n 为奇数）
        if (n % 2 == 1) {
            int midCol = n / 2;
            for (int i = 0; i < m / 2; i++) {
                int a = grid[i][midCol], b = grid[m-1-i][midCol];
                if (a != b) {
                    ans++;
                    diff = (diff + 2) % 4;
                } else {
                    diff = (diff + 2 * a) % 4;
                }
            }
        }

        // 中心格（m 和 n 均为奇数）
        if (m % 2 == 1 && n % 2 == 1) {
            diff = (diff + grid[m/2][n/2]) % 4;
            if (diff != 0) ans++; // 翻转中心格即可修复余量
        } else if (diff != 0) {
            ans += 2; // 翻转某对中间行/列配对
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(1)

## 关键点总结

1. 四格组翻转后贡献 0 或 4 个 1，不影响总数的模 4
2. 中间行/列的配对每次贡献 0 或 2 个 1，需要追踪 mod 4 余量
3. 中心格可微调 ±1，若无中心格则需额外 2 次翻转
