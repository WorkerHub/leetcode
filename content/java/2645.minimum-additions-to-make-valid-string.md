## 题目描述

给你只含 `a`、`b`、`c` 的字符串 `word`，每次可在任意位置插入 `a`、`b` 或 `c`，返回使 `word` 成为若干 "abc" 拼接的最少插入次数。

## Java 代码实现

```java
class Solution {
    public int addMinimum(String word) {
        // 统计需要多少组 abc：当 word[i] <= word[i-1] 时开始新的一组
        int groups = 1;
        for (int i = 1; i < word.length(); i++) {
            if (word.charAt(i) <= word.charAt(i - 1)) {
                groups++; // 字符未递增，需要新开一组 abc
            }
        }
        // 每组需要 3 个字符，实际有 word.length() 个，补充 3*groups - n
        return 3 * groups - word.length();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 当下一个字符 <= 前一个字符时需要新开 abc 组（如 "ba" 必须拆成两组）
2. 答案 = 组数 × 3 - 字符串长度
