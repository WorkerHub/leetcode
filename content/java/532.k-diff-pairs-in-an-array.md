## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，返回数组中唯一的 k-diff 数对的数量。

一个 **k-diff 数对** 是一个整数对 `(nums[i], nums[j])`，满足：`i != j` 且 `|nums[i] - nums[j]| == k`。

**示例 1：**
```
输入: nums = [3,1,4,1,5], k = 2
输出: 2
```

**示例 2：**
```
输入: nums = [1,2,3,4,5], k = 1
输出: 4
```

## 解题思路

哈希表法：遍历数组，对每个数检查 `x-k` 和 `x+k` 是否已出现过。

## Java 代码实现

### 方法一：哈希表（推荐）

```java
class Solution {
    public int findPairs(int[] nums, int k) {
        Set<Integer> visited = new HashSet<>();
        Set<Integer> pairs = new HashSet<>();

        for (int x : nums) {
            if (visited.contains(x - k)) {
                pairs.add(x - k);
            }
            if (visited.contains(x + k)) {
                pairs.add(x);
            }
            visited.add(x);
        }
        return pairs.size();
    }
}
```

### 方法二：Counter 法

```java
class Solution {
    public int findPairs(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.merge(num, 1, Integer::sum);
        }

        int result = 0;
        for (int num : count.keySet()) {
            if (k == 0) {
                if (count.get(num) >= 2) result++;
            } else {
                if (count.containsKey(num + k)) result++;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **唯一性**：用 Set 存储较小值去重
2. **k=0 特殊处理**：找重复元素
3. **双向检查**：检查 x-k 和 x+k
