## 题目描述

给定三个点，判断是否构成回旋镖（三点各不相同且不共线）。

**示例：**
```
输入：points = [[1,1],[2,3],[3,2]]
输出：true
```

## 解题思路

判断三点是否共线。使用向量叉积：若叉积为 0 则共线，否则不共线。避免除法运算防止精度问题。

## Java 代码实现

```java
class Solution {
    public boolean isBoomerang(int[][] points) {
        // 向量 AB 和 AC 的叉积
        int x1 = points[1][0] - points[0][0];
        int y1 = points[1][1] - points[0][1];
        int x2 = points[2][0] - points[0][0];
        int y2 = points[2][1] - points[0][1];

        // 叉积不为 0 表示不共线
        return x1 * y2 - y1 * x2 != 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **叉积判断共线**：AB × AC ≠ 0 则不共线
2. **避免除法**：用乘法代替斜率比较，防止除零和精度问题
3. **等价关系**：叉积为零 ⇔ 三角形面积为零 ⇔ 三点共线
