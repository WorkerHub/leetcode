## 题目描述

给你一个整数数组 `nums`，除某个元素仅出现**一次**外，其余每个元素都恰出现**三次**。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。

**示例 1：**
```
输入：nums = [2,2,3,2]
输出：3
```

**示例 2：**
```
输入：nums = [0,1,0,1,0,1,99]
输出：99
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `nums` 中，除某个元素仅出现一次外，其余每个元素都恰出现三次

## 解题思路

这道题是 LeetCode 136 的进阶版，不能直接使用异或运算，需要更高级的位运算技巧。

**核心思想：统计每一位上 1 出现的次数**

1. **基本原理**：
   - 如果某一位上 1 出现的次数不是 3 的倍数，说明只出现一次的数字在这一位上是 1
   - 对于 32 位整数，统计每一位上所有数字中 1 出现的次数
   - 将出现次数对 3 取模，余数就是答案在该位上的值

2. **算法流程**：
   - 遍历 32 位，对每一位统计所有数字在该位上 1 的个数
   - 如果个数 % 3 == 1，说明只出现一次的数字在该位是 1
   - 将所有为 1 的位组合起来就是答案

3. **状态机方法**（进阶）：
   - 使用两个变量 `ones` 和 `twos` 记录每一位出现 1 次和 2 次的状态
   - 当某一位出现 3 次时，将其从 `ones` 和 `twos` 中清除
   - 最终 `ones` 就是只出现一次的数字

## Java 代码实现

### 方法一：统计每一位（推荐，易理解）

```java
class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;
        // 遍历 32 位（Java int 是 32 位有符号整数）
        for (int i = 0; i < 32; i++) {
            int bitSum = 0;
            // 统计所有数字在第 i 位上 1 的个数
            for (int num : nums) {
                bitSum += (num >> i) & 1;
            }
            
            // 如果不是 3 的倍数，说明答案在这一位是 1
            if (bitSum % 3 != 0) {
                result |= (1 << i);
            }
        }
        return result;
    }
}
```

### 方法二：状态机（最优解）

```java
class Solution {
    public int singleNumber(int[] nums) {
        int ones = 0;  // 记录出现 1 次的位
        int twos = 0;  // 记录出现 2 次的位
        
        for (int num : nums) {
            // 更新 twos：之前在 ones 中且当前数字也有这一位的，移到 twos
            twos |= ones & num;
            // 更新 ones：异或操作
            ones ^= num;
            // 清除出现 3 次的位（同时在 ones 和 twos 中的）
            int threes = ones & twos;
            ones &= ~threes;
            twos &= ~threes;
        }
        
        return ones;
    }
}
```

### 方法三：哈希表（不满足空间要求，但直观）

```java
class Solution {
    public int singleNumber(int[] nums) {
        // 统计每个数字出现的次数
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }
        // 找出出现次数为 1 的数字
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == 1) {
                return entry.getKey();
            }
        }
        return -1;
    }
}
```

### 方法四：数学方法

```java
class Solution {
    public int singleNumber(int[] nums) {
        // (3 * 所有不重复数字的和 - 所有数字的和) / 2 = 只出现一次的数字
        Set<Integer> numSet = new HashSet<>();
        long sumAll = 0;
        for (int num : nums) {
            numSet.add(num);
            sumAll += num;
        }
        long sumSet = 0;
        for (int num : numSet) {
            sumSet += num;
        }
        return (int)((3 * sumSet - sumAll) / 2);
    }
}
```

## 复杂度分析

### 方法一：统计每一位
- **时间复杂度**：O(n × 32) = O(n)，需要遍历 32 位，每位遍历所有数字
- **空间复杂度**：O(1)，只使用常数个变量

### 方法二：状态机
- **时间复杂度**：O(n)，只需遍历数组一次
- **空间复杂度**：O(1)，只使用两个变量

### 方法三：哈希表
- **时间复杂度**：O(n)，遍历数组一次
- **空间复杂度**：O(n)，需要存储计数

### 方法四：数学方法
- **时间复杂度**：O(n)，需要遍历和创建集合
- **空间复杂度**：O(n)，需要创建集合

每一位统计：

```
初始：ones = 0, twos = 0

处理 2 (010):
  twos = 0 | (0 & 010) = 000
  ones = 0 ^ 010 = 010
  threes = 010 & 000 = 000
  → ones = 010, twos = 000

处理 2 (010):
  twos = 000 | (010 & 010) = 010
  ones = 010 ^ 010 = 000
  threes = 000 & 010 = 000
  → ones = 000, twos = 010

处理 3 (011):
  twos = 010 | (000 & 011) = 010
  ones = 000 ^ 011 = 011
  threes = 011 & 010 = 010
  ones = 011 & ~010 = 001
  twos = 010 & ~010 = 000
  → ones = 001, twos = 000

处理 2 (010):
  twos = 000 | (001 & 010) = 000
  ones = 001 ^ 010 = 011
  threes = 011 & 000 = 000
  → ones = 011, twos = 000

结果：ones = 011 = 3
```

## 关键点总结

1. **位运算的思维转换**：从"数字"到"每一位"的思考方式
2. **取模操作的应用**：出现 3 次的位对 3 取模为 0
3. **状态机设计**：用 `ones` 和 `twos` 记录位的出现次数
4. **Java 整数类型**：Java int 是 32 位有符号，无需特别处理符号位
5. **通用性**：这个方法可以推广到"其他数字出现 k 次，一个数字出现 1 次"的问题

## 易错点

1. **位数范围**：Java int 是 32 位，遍历 0~31 位即可
2. **方法二的更新顺序**：`ones` 和 `twos` 的更新顺序不能颠倒
3. **取模运算**：别忘了对 3 取模
4. **位运算优先级**：注意括号的使用，如 `(num >> i) & 1`
5. **数学方法溢出**：Java 中求和可能溢出，需要用 `long` 计算
