## 题目描述

给你一个整数 `columnNumber`，返回它在 Excel 表中相对应的列名称。

例如：
```
A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...
```

**示例 1：**
```
输入：columnNumber = 1
输出："A"
```

**示例 2：**
```
输入：columnNumber = 28
输出："AB"
```

**示例 3：**
```
输入：columnNumber = 701
输出："ZY"
```

**提示：**
- 1 <= columnNumber <= 2^31 - 1

## 解题思路

这道题本质上是**十进制转26进制**的问题，但有个特殊之处：Excel 列名是**从 1 开始**而非从 0 开始。

**标准 26 进制对比：**
- 标准 26 进制：0-25 对应 A-Z
- Excel 列名：1-26 对应 A-Z（没有 0）

**关键观察：**
1. 这是一个**类 26 进制**问题，但索引从 1 开始
2. 每次需要将 `columnNumber - 1` 再取模、除法
3. 从右向左构建结果字符串

**转换规则：**
```
1 -> A    (1-1=0, 0%26=0, 'A'+0='A')
26 -> Z   (26-1=25, 25%26=25, 'A'+25='Z')
27 -> AA  (27-1=26, 26%26=0->'A', 26/26=1, 1-1=0->'A')
```

**算法步骤：**
1. 将 `columnNumber` 减 1（转换为 0 索引）
2. 取模 26 得到当前位字符
3. 整除 26 得到下一轮的数字
4. 重复直到数字为 0
5. 反转结果字符串

## Java 代码实现

### 方法一：迭代转换（推荐）⭐

```java
class Solution {
    public String convertToTitle(int columnNumber) {
        StringBuilder result = new StringBuilder();

        while (columnNumber > 0) {
            // 关键：先减 1，转换为 0-25 的索引
            columnNumber--;
            // 取模得到当前位字符
            result.append((char) ('A' + columnNumber % 26));
            // 整除得到下一轮的数字
            columnNumber /= 26;
        }

        // 反转结果（因为是从低位到高位构建的）
        return result.reverse().toString();
    }
}
```

### 方法二：字符串前插版本

```java
class Solution {
    public String convertToTitle(int columnNumber) {
        StringBuilder result = new StringBuilder();

        while (columnNumber > 0) {
            columnNumber--; // 转为 0 索引
            // 在前面插入字符，省去反转步骤
            result.insert(0, (char) (columnNumber % 26 + 'A'));
            columnNumber /= 26;
        }

        return result.toString();
    }
}
```

### 方法三：递归实现

```java
class Solution {
    public String convertToTitle(int columnNumber) {
        if (columnNumber == 0) {
            return "";
        }

        // 先减 1
        columnNumber--;
        // 递归构建高位 + 当前位
        return convertToTitle(columnNumber / 26) + (char) ('A' + columnNumber % 26);
    }
}
```

## 复杂度分析

**时间复杂度：** O(log₂₆n)
- n 是 columnNumber，相当于 26 进制的位数

**空间复杂度：** O(log₂₆n)
- 方法一：存储结果的 StringBuilder
- 方法三：递归调用栈

## 图解示例

以 `columnNumber = 701` 为例：

```
第一步：701
  701 - 1 = 700
  700 % 26 = 24 -> 'Y'（'A' + 24）
  700 / 26 = 26

第二步：26
  26 - 1 = 25
  25 % 26 = 25 -> 'Z'（'A' + 25）
  25 / 26 = 0

结果：反转 ['Y', 'Z'] -> "ZY"
```

**为什么要减 1？**

```
不减 1 的问题：
26 % 26 = 0 -> 'A'  (错误！26 应该是 'Z')
26 / 26 = 1 -> 'A'  (得到 "AA"，错误！)

减 1 后：
25 % 26 = 25 -> 'Z'  (正确！)
25 / 26 = 0 -> 结束  (得到 "Z"，正确！)
```

## 关键点总结

1. **索引转换**：Excel 列从 1 开始，需要先 `-1` 转为 0 索引
2. **26 进制**：本质是进制转换，但不是标准 26 进制
3. **构建顺序**：从低位到高位，最后需要反转（或前插）
4. **字符转换**：`(char)('A' + offset)` 将数字转为字母
5. **循环条件**：`while (columnNumber > 0)`

## 易错点

1. **忘记减 1**
   - 错误：直接 `columnNumber % 26`
   - 正确：先 `columnNumber--`，再取模
   - 影响：26 会被错误转换为 'A' 而非 'Z'

2. **字符转换错误**
   - 错误：`(char)(columnNumber % 26)`
   - 正确：`(char)('A' + columnNumber % 26)`

3. **反转遗漏**
   - 从低位到高位构建，最后必须反转
   - 或者用 `insert(0, char)` 直接前插

4. **边界情况**
   - `columnNumber = 26` -> "Z"（不是 "AA"）
   - `columnNumber = 52` -> "AZ"（不是 "BA"）

5. **整除时机**
   - 必须在减 1 和取模之后才能整除

**常见陷阱：**
- 26、52、78 等 26 的倍数是易错点
- 验证代码时务必测试这些边界值

**Java 技巧：**
- `(char)('A' + n)` 将数字偏移转为字符（n 在 0~25 之间）
- `StringBuilder.reverse()` 原地反转，高效
- `StringBuilder.insert(0, char)` 在头部插入字符，但频繁插入效率低，推荐先 append 再 reverse
