## 题目描述

给你坐标数组 coordinates 和整数 k，距离定义为 `(x1 XOR x2) + (y1 XOR y2)`，返回距离恰好等于 k 的点对数。

## 解题思路

k 很小（≤100），枚举 `x1 XOR x2 = t`（t 从 0 到 k），则 `y1 XOR y2 = k-t`，用哈希表存储已处理点，查找配对数。

## Java 代码实现

```java
class Solution {
    public int countPairs(List<List<Integer>> coordinates, int k) {
        Map<Long, Integer> cnt = new HashMap<>();
        int ans = 0;

        for (List<Integer> point : coordinates) {
            int x = point.get(0), y = point.get(1);
            // 枚举 x1 XOR x2 的所有可能值 t（0 到 k）
            for (int t = 0; t <= k; t++) {
                int needX = x ^ t;
                int needY = y ^ (k - t);
                // 用 long 编码 (needX, needY) 以便作为 HashMap key
                long key = ((long) needX << 20) | needY;
                ans += cnt.getOrDefault(key, 0);
            }
            // 将当前点加入哈希表（先查询再插入，避免自配对）
            long key = ((long) x << 20) | y;
            cnt.merge(key, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k)
- **空间复杂度**：O(n)

## 关键点总结

1. k ≤ 100，可枚举 XOR 分拆：`a + b = k`，`x1 = x2 ^ a`，`y1 = y2 ^ (k-a)`
2. 先查哈希表再插入当前点，避免重复计数
3. 用 long 编码坐标对作为哈希表键（坐标 ≤ 10^6，20 位足够）
