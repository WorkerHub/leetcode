## 题目描述

n支队伍，grid[i][j]==1表示i比j强，找冠军（比所有其他队伍强的队伍）。

## 解题思路

冠军的行和为n-1（胜过所有其他队伍），遍历每行统计即可。

## Java 代码实现

```java
class Solution {
    public int findChampion(int[][] grid) {
        int n = grid.length;
        for (int i = 0; i < n; i++) {
            int wins = 0;
            for (int j = 0; j < n; j++) {
                wins += grid[i][j];
            }
            if (wins == n - 1) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **冠军行和为n-1**：胜过所有其他队伍
2. **保证唯一冠军**：题目条件保证存在且唯一
3. **也可逐列检查列和为0的列**
