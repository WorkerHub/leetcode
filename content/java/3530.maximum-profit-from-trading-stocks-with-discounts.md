## 题目描述

给定组织架构树（根为 0，父节点 = i/2），`present[i]` 表示该员工是否产生收益（0 或 1），`cost[i]` 原价，`discount[i]` 折扣价。若父节点购买则子节点可用折扣价；给定 `budget`，求最大收益总量。

## 解题思路

树形背包 DP：对每个节点维护两个 DP 数组 `dp_no[0..budget]`（节点未购买）和 `dp_yes[0..budget]`（节点已购买），分别与每个子节点的两种状态做背包合并。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] children;
    private int[] present, cost, discount;
    private int budget;

    @SuppressWarnings("unchecked")
    public int maxProfit(int n, int[] present, int[] cost, int[] discount, int budget) {
        this.present = present; this.cost = cost;
        this.discount = discount; this.budget = budget;
        children = new List[n];
        for (int i = 0; i < n; i++) children[i] = new ArrayList<>();
        for (int i = 1; i < n; i++) children[i / 2].add(i);
        int[] dp = dfs(0, false);
        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }

    // 返回 dp[0..budget]：以当前节点为根，花费 j 时的最大收益
    // parentBought: 父节点是否购买
    private int[] dfs(int v, boolean parentBought) {
        int[] dpNo = new int[budget + 1]; // v 不购买
        int[] dpYes = new int[budget + 1]; // v 购买
        Arrays.fill(dpYes, -1); // -1 表示不可达
        int c = parentBought ? discount[v] : cost[v];
        if (c <= budget) dpYes[c] = present[v]; // v 购买的基础收益

        for (int child : children[v]) {
            int[] childNo = dfs(child, false);  // v 不买，child 用原价
            int[] childYes = dfs(child, true);  // v 买，child 可用折扣

            // 更新 dpNo（v 不买，子节点用 childNo）
            int[] newNo = new int[budget + 1];
            for (int j = budget; j >= 0; j--) {
                for (int k = 0; k <= budget - j; k++) {
                    newNo[j + k] = Math.max(newNo[j + k], dpNo[j] + childNo[k]);
                }
            }
            dpNo = newNo;

            // 更新 dpYes（v 买，子节点用 childYes）
            int[] newYes = new int[budget + 1];
            Arrays.fill(newYes, -1);
            for (int j = 0; j <= budget; j++) {
                if (dpYes[j] < 0) continue;
                for (int k = 0; k <= budget - j; k++) {
                    if (childYes[k] >= 0)
                        newYes[j + k] = Math.max(newYes[j + k], dpYes[j] + childYes[k]);
                }
            }
            dpYes = newYes;
        }

        // 合并 dpNo 和 dpYes
        int[] result = new int[budget + 1];
        for (int j = 0; j <= budget; j++) {
            result[j] = dpNo[j];
            if (dpYes[j] >= 0) result[j] = Math.max(result[j], dpYes[j]);
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * budget^2)，树形背包合并
- 空间复杂度：O(n * budget)

## 关键点总结

1. 树形 DP：父节点购买状态影响子节点可用价格
2. 背包合并：两层循环枚举当前 dp 花费和子节点花费
3. dpYes 用 -1 标记不可达状态
