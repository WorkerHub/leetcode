## 题目描述

给你整数数组 `nums` 和整数 `x`，每次可以删去最左或最右的元素并从 `x` 减去，返回使 `x` 恰好为 0 的最少操作次数，不可能则返回 `-1`。

## 解题思路

逆向思维：从两端删元素使和为 x，等价于保留中间最长子数组使和为 `sum - x`，滑动窗口求该最长子数组长度，答案为 `n - maxLen`。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int total = 0;
        for (int v : nums) total += v;
        int target = total - x;
        if (target < 0) return -1;
        if (target == 0) return nums.length;

        int n = nums.length, maxLen = -1, curSum = 0, left = 0;
        for (int right = 0; right < n; right++) {
            curSum += nums[right];
            while (curSum > target) curSum -= nums[left++];
            if (curSum == target) maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen == -1 ? -1 : n - maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 逆向：找中间最长子数组使和 = `sum - x`
2. nums 全正时滑动窗口具有单调性，可用双指针
3. 最少操作 = `n - maxLen`
