## 题目描述

删除最少元素使数组长度为偶数且每对偶数位和奇数位相邻元素不相等。

## 解题思路

贪心配对：遍历数组模拟配对，当前偶数位元素与下一个相等则删除跳过，最后若剩余奇数个有效元素再删一个。

## Java 代码实现

```java
class Solution {
    public int minDeletion(int[] nums) {
        int n = nums.length;
        int deleted = 0;
        int i = 0;
        
        while (i < n - 1) {
            if (nums[i] == nums[i + 1]) {
                // 当前偶数位和下一个相等，删除当前
                deleted++;
                i++;
            } else {
                // 接受这对
                i += 2;
            }
        }
        
        // 若剩余未配对元素（有效长度为奇数）
        if ((n - deleted) % 2 == 1) {
            deleted++;
        }
        return deleted;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心配对**：相邻相等则删一个跳过，否则接受这对跳两步
2. **最后检查奇偶**：有效长度为奇数需额外删一个
3. **只需一次遍历**：模拟即可
