## 题目描述

给你正整数数组 `nums` 和正整数 `k`，若 `popcount(num1 OR num2) + popcount(num1 AND num2) >= k`，则 `(num1, num2)` 是优质数对，返回优质数对的数目（下标不同但值可相同）。

## 解题思路

关键等式：`popcount(a OR b) + popcount(a AND b) = popcount(a) + popcount(b)`。因此条件化简为 `popcount(a) + popcount(b) >= k`。去重后对 popcount 计数，排序后用双指针或后缀和统计满足条件的有序对数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long countExcellentPairs(int[] nums, int k) {
        // 去重
        Set<Integer> unique = new HashSet<>();
        for (int x : nums) unique.add(x);

        // 计算每个唯一值的 popcount 并排序
        int[] pops = new int[unique.size()];
        int idx = 0;
        for (int x : unique) pops[idx++] = Integer.bitCount(x);
        Arrays.sort(pops);

        int n = pops.length;
        long ans = 0;
        // 双指针：左指针 i，右指针 j 从右往左找第一个满足 pops[i]+pops[j]>=k 的位置
        int j = n - 1;
        for (int i = 0; i < n; i++) {
            // 收缩 j 直到 pops[i]+pops[j] < k
            while (j >= 0 && pops[i] + pops[j] >= k) j--;
            // pops[i] 与 pops[j+1..n-1] 中每个元素配对都满足条件
            ans += (long)(n - 1 - j);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序主导
- **空间复杂度**：O(n)

## 关键点总结

1. 核心等式：`popcount(OR) + popcount(AND) = popcount(a) + popcount(b)`。
2. 去重后只考虑不同值之间的组合（有序对 (a,b) 和 (b,a) 都算）。
3. 双指针在排序后的 popcount 数组上统计满足条件的有序对。
