## 题目描述

m×n 二进制矩阵（最大 3×3），每次翻转一个格子及其四邻居（0↔1）。求将矩阵变全零的最少翻转次数，不可能返回 -1。

**示例：**
```
输入：mat = [[0,0],[0,1]]
输出：3
```

## 解题思路

状态压缩 + BFS：将矩阵编码为整数（最多 9 位），BFS 搜索从初始状态到 0 的最短路径。

## Java 代码实现

```java
class Solution {
    public int minFlips(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        // 编码初始状态
        int start = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 1) start |= (1 << (i * n + j));
            }
        }
        
        if (start == 0) return 0;
        
        // BFS
        Set<Integer> visited = new HashSet<>();
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{start, 0});
        visited.add(start);
        
        int[][] dirs = {{0,0},{0,1},{0,-1},{1,0},{-1,0}};
        
        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int state = curr[0], steps = curr[1];
            
            // 尝试翻转每个位置
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    int next = state;
                    // 翻转该位置及四邻居
                    for (int[] d : dirs) {
                        int ni = i + d[0], nj = j + d[1];
                        if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                            next ^= (1 << (ni * n + nj));
                        }
                    }
                    if (next == 0) return steps + 1;
                    if (!visited.contains(next)) {
                        visited.add(next);
                        queue.offer(new int[]{next, steps + 1});
                    }
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^(m×n) × m × n)
- **空间复杂度**：O(2^(m×n))

## 关键点总结

1. **状态压缩**：矩阵 → 整数，最多 2^9 = 512 种状态
2. **BFS 最短路**：每次翻转为一步
3. **异或翻转**：XOR 操作实现 0↔1
4. **小规模**：3×3 保证 BFS 可行
