## 题目描述

骑士在电话拨号盘上跳 n-1 步，返回能拨出的不同电话号码数量，结果对 10^9+7 取模。

## 解题思路

动态规划：dp[i] 表示当前在数字 i 上的方案数。根据骑士跳跃规则转移。

## Java 代码实现

```java
class Solution {
    public int knightDialer(int n) {
        long MOD = 1_000_000_007;
        // 每个数字可以跳到的位置
        int[][] moves = {
            {4, 6},    // 0
            {6, 8},    // 1
            {7, 9},    // 2
            {4, 8},    // 3
            {0, 3, 9}, // 4
            {},        // 5
            {0, 1, 7}, // 6
            {2, 6},    // 7
            {1, 3},    // 8
            {2, 4}     // 9
        };

        long[] dp = new long[10];
        Arrays.fill(dp, 1);

        for (int step = 1; step < n; step++) {
            long[] newDp = new long[10];
            for (int i = 0; i < 10; i++) {
                for (int j : moves[i]) {
                    newDp[j] = (newDp[j] + dp[i]) % MOD;
                }
            }
            dp = newDp;
        }

        long result = 0;
        for (long x : dp) result = (result + x) % MOD;
        return (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，只用 10 个状态

## 关键点总结

1. **跳跃映射表**：预定义每个数字的合法跳跃目标
2. **逐步转移**：每步从旧状态转移到新状态
3. **5 是死角**：从 5 无法跳到任何位置
