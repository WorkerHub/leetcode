## 题目描述

给你一个整数数组 `nums` 和整数 `k`，若子数组中满足 `i < j` 且 `nums[i] == nums[j]` 的相等元素对数不少于 `k`，则称该子数组为"好子数组"，返回好子数组的数目。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countGoodSubarrays(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> freq = new HashMap<>();
        long pairs = 0;  // 当前窗口内的相等对数
        long ans = 0;
        int left = 0;

        for (int right = 0; right < n; right++) {
            int v = nums[right];
            // 加入右端：新增对数 = v 在窗口内已出现的次数
            pairs += freq.getOrDefault(v, 0);
            freq.put(v, freq.getOrDefault(v, 0) + 1);

            // 收缩左端，找到最小满足条件的窗口左边界
            while (pairs >= k) {
                int lv = nums[left];
                freq.put(lv, freq.get(lv) - 1);
                // 移除左端后减少的对数 = 移除后 lv 的频率
                pairs -= freq.get(lv);
                left++;
            }

            // [left, right] 不满足条件，好的左端点为 0 到 left-1，共 left 个
            ans += left;
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各移动 n 次
- 空间复杂度：O(n)，频率表

## 关键点总结

1. 加入元素 v 时，新增对数 = `freq[v]`（v 在窗口内出现的次数）。
2. 移除左端元素 lv 时，减少对数 = 移除后 lv 的频率（先减频率再减 pairs）。
3. 以 right 为右端的好子数组数量 = 满足条件的左端点个数 = `left`。
