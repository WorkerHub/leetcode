## 题目描述

给定整数数组 `nums`，每次操作选一个非空连续子数组将所有元素减 1，返回使数组所有元素变为 0 的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        // 最少操作数 = 差分数组中正值之和（每次上升需要开始一次新操作）
        int ops = 0, prev = 0;
        for (int v : nums) {
            int diff = v - prev;
            if (diff > 0) ops += diff;
            prev = v;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每次操作等价于差分数组某区间两端点的加减，操作数 = 差分正值之和
2. 只有上升台阶需要新操作，下降不需要
3. `diff[0] = nums[0] - 0 = nums[0]`（首元素），始终为正
