## 题目描述

给你 m×n 成绩矩阵 `score` 和整数 `k`，按第 k 列成绩降序排序整个矩阵，返回排序后的矩阵。

## 解题思路

直接使用 Java 的 `Arrays.sort` 并自定义比较器，按每行第 k 个元素降序排序。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[][] sortTheStudents(int[][] score, int k) {
        // 按第 k 列降序排序，整行一起移动
        Arrays.sort(score, (a, b) -> b[k] - a[k]);
        return score;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m)
- **空间复杂度**：O(m)

## 关键点总结

1. 比较器按第 k 列降序：`(a, b) -> b[k] - a[k]`
2. 排序时整行作为单元一起移动，保持行内数据完整
3. 矩阵中无重复元素，结果唯一
