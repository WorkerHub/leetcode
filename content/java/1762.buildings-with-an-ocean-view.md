## 题目描述

给你建筑高度数组 `heights`，返回所有能看到海洋（右侧无相同或更高建筑）的建筑下标（升序）。

## 解题思路

从右往左遍历，维护右侧最大高度，若当前建筑严格高于右侧最大高度则可看到海洋，记录下标后反转输出。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] findBuildings(int[] heights) {
        int n = heights.length;
        List<Integer> result = new ArrayList<>();
        int maxRight = 0; // 当前建筑右侧的最大高度

        for (int i = n - 1; i >= 0; i--) {
            if (heights[i] > maxRight) {
                result.add(i); // 能看到海洋
                maxRight = heights[i];
            }
        }

        // 反转结果（从右往左添加的）
        int[] ans = new int[result.size()];
        for (int i = 0; i < ans.length; i++) {
            ans[i] = result.get(ans.length - 1 - i);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 能看到海洋 = 右侧无高度 >= 自身的建筑（严格大于）
2. 从右往左扫描，维护右侧最大高度
