## 题目描述

文件系统操作日志，`"../"` 返回父目录，`"./"` 停留，`"x/"` 进入子目录。求最终回到主目录的最少操作数。

**示例：**
```
输入：logs = ["d1/","d2/","../","d21/","./"]
输出：2
```

## 解题思路

只需追踪深度：`"../"` 深度减1（最小为0），`"./"` 不变，其他加1。

## Java 代码实现

```java
class Solution {
    public int minOperations(String[] logs) {
        int depth = 0;
        for (String log : logs) {
            if (log.equals("../")) {
                depth = Math.max(0, depth - 1);
            } else if (!log.equals("./")) {
                depth++;
            }
        }
        return depth;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **只需维护深度**：不需要真正存储路径
2. **深度最小为0**：在主目录时 `"../"` 无效
3. **字符串比较用equals**：Java中不能用==比较字符串内容
