## 题目描述

使矩阵每列值相同且相邻列值不同，求最少修改次数。

## 解题思路

DP：dp[j][v]表示第j列统一为v的最小操作数，转移时确保与前一列不同。每列修改代价=列长-该值出现次数。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] cost = new int[n][10]; // cost[j][v] = 第j列改为v的代价
        for (int j = 0; j < n; j++) {
            Arrays.fill(cost[j], m);
            for (int i = 0; i < m; i++) {
                cost[j][grid[i][j]]--;
            }
        }

        int[][] dp = new int[n][10];
        for (int v = 0; v < 10; v++) dp[0][v] = cost[0][v];

        for (int j = 1; j < n; j++) {
            // 找前一列最小值和次小值
            int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE, minIdx = -1;
            for (int v = 0; v < 10; v++) {
                if (dp[j - 1][v] < min1) {
                    min2 = min1; min1 = dp[j - 1][v]; minIdx = v;
                } else if (dp[j - 1][v] < min2) {
                    min2 = dp[j - 1][v];
                }
            }
            for (int v = 0; v < 10; v++) {
                dp[j][v] = cost[j][v] + (v == minIdx ? min2 : min1);
            }
        }

        int ans = Integer.MAX_VALUE;
        for (int v = 0; v < 10; v++) ans = Math.min(ans, dp[n - 1][v]);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N + N*10)
- **空间复杂度**：O(N*10)

## 关键点总结

1. **每列10种选择(0-9)**：统计代价后DP
2. **相邻列不同**：用最小/次小值优化转移
3. **代价=列长-该值出现次数**
