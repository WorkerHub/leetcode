## 题目描述

给你二进制字符串 `boxes`（'1' 表示有球），返回数组 `answer`，`answer[i]` 为将所有球移到第 i 个盒子所需的最少操作数。

## 解题思路

两遍扫描前缀和：从左到右维护左侧球数和累计操作数（每向右移一步，左侧所有球各多走一步），从右到左同理，两遍结果相加即为答案。

## Java 代码实现

```java
class Solution {
    public int[] minOperations(String boxes) {
        int n = boxes.length();
        int[] ans = new int[n];

        // 从左往右：计算左侧所有球移到当前位置的操作数
        int cnt = 0, ops = 0;
        for (int i = 0; i < n; i++) {
            ans[i] += ops;
            cnt += boxes.charAt(i) - '0'; // 当前位置的球计入左侧
            ops += cnt; // 下一步所有左侧球各多走一步
        }

        // 从右往左：计算右侧所有球移到当前位置的操作数
        cnt = 0; ops = 0;
        for (int i = n - 1; i >= 0; i--) {
            ans[i] += ops;
            cnt += boxes.charAt(i) - '0';
            ops += cnt;
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. 维护方向球数 `cnt` 和累计操作数 `ops`，`ops += cnt` 表示每步所有球多走一步
2. 先更新 `ans[i]`，再更新 `cnt` 和 `ops`（当前位置的球不算作已过去的一侧）
