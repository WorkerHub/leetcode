## 题目描述

给你物品数组 `items`（每项含价格和重量）和背包容量 `capacity`，每件物品可整体或部分放入，返回背包能装的最大总价格。

## 解题思路

经典分数背包贪心：按单位价格（price/weight）降序排列，依次尽量多地放入，最后一件物品可按比例部分放入。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public double maxPrice(int[][] items, int capacity) {
        // 按单位价格降序排列
        Arrays.sort(items, (a, b) -> Double.compare((double) b[0] / b[1], (double) a[0] / a[1]));

        double totalPrice = 0.0;
        int remaining = capacity;

        for (int[] item : items) {
            if (remaining <= 0) break;
            int price = item[0], weight = item[1];
            int take = Math.min(weight, remaining);
            totalPrice += (double) price * take / weight; // 按比例计算价格
            remaining -= take;
        }
        return totalPrice;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 分数背包贪心：优先选单位价格最高的物品
2. 最后一件物品可部分放入，按 `price * take / weight` 计算价格
3. 物品总重量可能 < capacity，此时全部放入即为最优
