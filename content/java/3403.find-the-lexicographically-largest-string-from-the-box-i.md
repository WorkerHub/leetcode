## 题目描述

将字符串 `word` 分成 `numFriends` 个非空部分，返回所有可能分割方式中字典序最大的那段字符串。

## Java 代码实现

```java
class Solution {
    public String answerString(String word, int numFriends) {
        int n = word.length();
        if (numFriends == 1) return word;

        // 每个分段的最大可能长度
        int maxLen = n - numFriends + 1;
        String result = "";

        for (int i = 0; i < n; i++) {
            // 从位置 i 开始，取最多 maxLen 个字符
            String candidate = word.substring(i, Math.min(i + maxLen, n));
            if (candidate.compareTo(result) > 0) {
                result = candidate;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举每个起始位置并进行字符串比较
- 空间复杂度：O(n)，存储候选子串

## 关键点总结

1. 某个分段的最大长度被限制为 `n - numFriends + 1`。
2. `numFriends == 1` 时直接返回整个字符串。
3. 枚举所有起始位置，取字典序最大的候选子串。
