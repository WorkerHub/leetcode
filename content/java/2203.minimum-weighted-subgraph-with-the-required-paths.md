## 题目描述

有向加权图中找最小权值子图，使src1和src2都能到达dest，返回最小权值和。

## 解题思路

Y形结构：两路径在某节点v汇合后到dest。三次Dijkstra（src1正向、src2正向、dest反向图），枚举v取min(dist1[v]+dist2[v]+distRev[v])。

## Java 代码实现

```java
class Solution {
    public long minimumWeight(int n, int[][] edges, int src1, int src2, int dest) {
        // 建正向图和反向图
        List<long[]>[] graph = new List[n];
        List<long[]>[] rgraph = new List[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
            rgraph[i] = new ArrayList<>();
        }
        for (int[] e : edges) {
            graph[e[0]].add(new long[]{e[1], e[2]});
            rgraph[e[1]].add(new long[]{e[0], e[2]});
        }
        
        long[] dist1 = dijkstra(n, graph, src1);
        long[] dist2 = dijkstra(n, graph, src2);
        long[] dist3 = dijkstra(n, rgraph, dest);
        
        long ans = Long.MAX_VALUE;
        for (int v = 0; v < n; v++) {
            if (dist1[v] < Long.MAX_VALUE && dist2[v] < Long.MAX_VALUE && dist3[v] < Long.MAX_VALUE) {
                ans = Math.min(ans, dist1[v] + dist2[v] + dist3[v]);
            }
        }
        return ans == Long.MAX_VALUE ? -1 : ans;
    }
    
    private long[] dijkstra(int n, List<long[]>[] graph, int src) {
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[src] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[1], b[1]));
        pq.offer(new long[]{src, 0});
        
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int u = (int) cur[0];
            long d = cur[1];
            if (d > dist[u]) continue;
            for (long[] edge : graph[u]) {
                int v = (int) edge[0];
                long nd = d + edge[1];
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{v, nd});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + M) log N)
- **空间复杂度**：O(N + M)

## 关键点总结

1. **Y形最优结构**：src1→v + src2→v + v→dest
2. **反向图Dijkstra**：从dest在反向图跑等价于原图各点到dest的最短路
3. **用long防溢出**：三个距离相加可能超int范围
