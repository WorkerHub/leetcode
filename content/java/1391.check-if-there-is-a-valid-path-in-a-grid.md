## 题目描述

网格中每个格子是一种街道类型(1-6)，判断从左上角到右下角是否存在有效路径（相邻格子必须双向连通）。

## 解题思路

BFS遍历，用方向集合定义每种街道的可达方向，移动时双向验证：当前格有出口且目标格有对应入口。

## Java 代码实现

```java
class Solution {
    public boolean hasValidPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 上=0,下=1,左=2,右=3
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        int[] opposite = {1, 0, 3, 2};
        // 每种街道类型的可达方向
        Set<Integer>[] streetDirs = new Set[7];
        streetDirs[1] = Set.of(2, 3); // 左右
        streetDirs[2] = Set.of(0, 1); // 上下
        streetDirs[3] = Set.of(2, 1); // 左下
        streetDirs[4] = Set.of(3, 1); // 右下
        streetDirs[5] = Set.of(2, 0); // 左上
        streetDirs[6] = Set.of(3, 0); // 右上

        boolean[][] visited = new boolean[m][n];
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{0, 0});
        visited[0][0] = true;

        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0], c = cell[1];
            if (r == m - 1 && c == n - 1) return true;

            for (int d = 0; d < 4; d++) {
                int nr = r + dirs[d][0], nc = c + dirs[d][1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                    // 双向验证：当前格有d方向出口，目标格有反方向入口
                    if (streetDirs[grid[r][c]].contains(d) &&
                        streetDirs[grid[nr][nc]].contains(opposite[d])) {
                        visited[nr][nc] = true;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }
        return visited[m - 1][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(M * N)

## 关键点总结

1. **方向集合定义街道连通性**：便于快速查询
2. **双向验证**：A有出口朝B，B有入口朝A
3. **opposite数组**：快速获取反方向
