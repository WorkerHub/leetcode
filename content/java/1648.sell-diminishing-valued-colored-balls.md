## 题目描述

每种颜色的球数量由 `inventory` 给出，第 i 次卖某颜色球的利润为当前该颜色剩余数量。需卖出 `orders` 个球，返回**最大利润**（对 `10^9+7` 取余）。

## 解题思路

**贪心 + 二分查找阈值：** 每次卖最多颜色的球。二分找阈值 t，将所有 > t 的颜色批量降至 t（用等差数列求和计算利润），再处理剩余 orders。

## Java 代码实现

```java
class Solution {
    public int maxProfit(int[] inventory, int orders) {
        final long MOD = 1_000_000_007L;
        Arrays.sort(inventory);
        int n = inventory.length;

        // 二分查找阈值 t：使高于 t 的总球数 >= orders 的最大 t
        int lo = 0, hi = inventory[n - 1];
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            long count = 0;
            for (int x : inventory) count += Math.max(0, x - mid);
            if (count >= orders) lo = mid + 1; // 还可以更高
            else hi = mid;
        }
        int t = lo - 1; // 阈值

        // 计算高于 t 部分的利润（等差数列求和）
        long profit = 0;
        long remaining = orders;

        for (int x : inventory) {
            if (x > t) {
                long ballsSold = x - t;
                // 利润 = (t+1) + (t+2) + ... + x = (t+1+x)*(x-t)/2
                profit = (profit + (long)(t + 1 + x) * (x - t) / 2) % MOD;
                remaining -= ballsSold;
            }
        }

        // 剩余 remaining 个球以价格 t 卖出
        if (remaining > 0) {
            profit = (profit + remaining * t) % MOD;
        }

        return (int) profit;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + n log M)，M 为最大库存值
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：每次卖最多颜色的球（从高价到低价）
2. 批量处理：找阈值 t，一次性计算多层利润（等差数列）
3. 等差数列求和：`(首项+末项)*项数/2`
4. 剩余 orders 以价格 t 卖出
