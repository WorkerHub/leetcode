## 题目描述

给你 n 个城市、时间限制 `maxTime`、边数组 `edges` 和通行费数组 `passingFees`，从城市 0 出发，在不超过 maxTime 分钟内到达城市 n-1，返回最低通行费总和，无法到达返回 -1。

## 解题思路

二维 DP：`dp[t][v]` = 恰好用时 t 分钟到达城市 v 的最低费用。遍历所有时间点和边进行状态转移，答案取所有合法时间到达终点的最小费用。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minCost(int maxTime, int[][] edges, int[] passingFees) {
        int n = passingFees.length;
        int INF = Integer.MAX_VALUE / 2;
        int[][] dp = new int[maxTime + 1][n];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[0][0] = passingFees[0]; // 从城市 0 出发就要付费

        for (int t = 1; t <= maxTime; t++) {
            for (int[] e : edges) {
                int u = e[0], v = e[1], time = e[2];
                if (time <= t) {
                    // 从 u 到 v
                    if (dp[t - time][u] < INF)
                        dp[t][v] = Math.min(dp[t][v], dp[t - time][u] + passingFees[v]);
                    // 从 v 到 u（双向边）
                    if (dp[t - time][v] < INF)
                        dp[t][u] = Math.min(dp[t][u], dp[t - time][v] + passingFees[u]);
                }
            }
        }

        int ans = INF;
        for (int t = 1; t <= maxTime; t++) ans = Math.min(ans, dp[t][n - 1]);
        return ans == INF ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(maxTime * E)
- **空间复杂度**：O(maxTime * n)

## 关键点总结

1. 二维状态（城市 + 已用时间）才能正确限制总时间
2. DP 按时间层次递推，避免图中环路问题
3. 初始化 `dp[0][0] = passingFees[0]`（出发即付费）
