## 题目描述

给你一个正整数数组 `nums`，每次操作可以将两个相邻元素合并（替换为它们的和），返回将数组变成回文数组所需的最少操作数。

## 解题思路

双指针贪心：左右指针各维护一个累加值，若左值小则合并左端下一个元素（操作数+1），若右值小则合并右端下一个元素（操作数+1），相等则双指针同时向内移动。正整数保证合并只增大值，贪心有效。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(int[] nums) {
        int left = 0, right = nums.length - 1;
        long lVal = nums[left], rVal = nums[right]; // 使用 long 防止溢出
        int ops = 0;

        while (left < right) {
            if (lVal == rVal) {
                // 两端相等，同时向中间移动
                left++;
                right--;
                if (left < right) {
                    lVal = nums[left];
                    rVal = nums[right];
                }
            } else if (lVal < rVal) {
                // 左端偏小，合并左端的下一个元素
                left++;
                lVal += nums[left];
                ops++;
            } else {
                // 右端偏小，合并右端的下一个元素
                right--;
                rVal += nums[right];
                ops++;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 双指针从两端向中间靠拢，每次对较小的一端进行合并
2. 所有元素为正整数，合并只增大值，贪心策略有效
3. 使用 `long` 累加值防止溢出
