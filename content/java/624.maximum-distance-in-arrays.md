## 题目描述

给定 `m` 个升序数组，从两个不同的数组中各选一个数字，使得距离 `|a - b|` 最大。

**示例：**
```
输入：arrays = [[1,2,3],[4,5],[1,2,3]]
输出：4
```

## 解题思路

贪心：维护全局最小值和最大值，逐个处理每个数组时计算当前最大距离。

## Java 代码实现

```java
class Solution {
    public int maxDistance(List<List<Integer>> arrays) {
        // 用第一个数组初始化
        int globalMin = arrays.get(0).get(0);
        int globalMax = arrays.get(0).get(arrays.get(0).size() - 1);
        int result = 0;

        // 从第二个数组开始遍历
        for (int i = 1; i < arrays.size(); i++) {
            List<Integer> arr = arrays.get(i);
            int curMin = arr.get(0);
            int curMax = arr.get(arr.size() - 1);

            // 计算当前数组与之前数组的最大距离
            result = Math.max(result, Math.max(curMax - globalMin, globalMax - curMin));

            // 更新全局极值
            globalMin = Math.min(globalMin, curMin);
            globalMax = Math.max(globalMax, curMax);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m)，m 为数组个数
- **空间复杂度**：O(1)

## 关键点总结

1. **利用升序特性**：首尾元素即为最小/最大值
2. **贪心维护全局极值**：边遍历边更新
3. **保证不同数组**：先计算距离再更新极值
