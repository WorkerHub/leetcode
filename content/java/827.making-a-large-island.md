## 题目描述

给你一个大小为 `n x n` 二进制矩阵 `grid`。**最多** 只能将一格 `0` 变成 `1`。

返回执行此操作后，`grid` 中最大的岛屿面积是多少？

**岛屿** 由一组上、下、左、右四个方向相连的 `1` 形成。

**示例 1:**
```
输入: grid = [[1,0],[0,1]]
输出: 3
```

**示例 2:**
```
输入: grid = [[1,1],[1,0]]
输出: 4
```

**示例 3:**
```
输入: grid = [[1,1],[1,1]]
输出: 4
```

## Java 代码实现

```java
import java.util.*;

class Solution {
    int n;
    int[][] grid;
    int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

    public int largestIsland(int[][] grid) {
        this.n = grid.length;
        this.grid = grid;
        int islandId = 2;  // 从 2 开始标记岛屿（0和1已用）
        Map<Integer, Integer> area = new HashMap<>();

        // 标记每个岛屿并计算面积
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    area.put(islandId, dfs(i, j, islandId));
                    islandId++;
                }
            }
        }

        // 如果没有陆地
        if (area.isEmpty()) return 1;

        // 如果全是陆地
        int maxArea = 0;
        for (int val : area.values()) {
            maxArea = Math.max(maxArea, val);
        }

        // 尝试将每个 0 变成 1
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 0) {
                    Set<Integer> neighbors = new HashSet<>();
                    for (int[] dir : directions) {
                        int ni = i + dir[0], nj = j + dir[1];
                        if (ni >= 0 && ni < n && nj >= 0 && nj < n && grid[ni][nj] > 1) {
                            neighbors.add(grid[ni][nj]);
                        }
                    }

                    int newArea = 1;
                    for (int id : neighbors) {
                        newArea += area.get(id);
                    }
                    maxArea = Math.max(maxArea, newArea);
                }
            }
        }

        return maxArea;
    }

    private int dfs(int i, int j, int id) {
        if (i < 0 || i >= n || j < 0 || j >= n || grid[i][j] != 1) {
            return 0;
        }
        grid[i][j] = id;
        int size = 1;
        for (int[] dir : directions) {
            size += dfs(i + dir[0], j + dir[1], id);
        }
        return size;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **岛屿标记**：给每个岛屿唯一 ID（从 2 开始）
2. **面积预计算**：先计算所有岛屿面积
3. **枚举 0**：尝试每个 0，合并相邻岛屿
