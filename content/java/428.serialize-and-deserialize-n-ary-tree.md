## 题目描述

序列化是指将一个数据结构转化为位序列的过程，因此可以将其存储在文件中或内存缓冲区中，以便稍后在相同或不同的计算机环境中恢复结构。

设计一个序列化和反序列化 N 叉树的算法。一个 N 叉树是指每个节点都有不超过 N 个孩子节点的有根树。序列化 / 反序列化算法的算法实现没有限制。你只需要保证 N 叉树可以被序列化为一个字符串并且该字符串可以被反序列化成原树结构即可。

**示例 1：**

![](https://assets.leetcode.com/uploads/2018/10/12/narytreeexample.png)

```
输入：root = [1,null,3,2,4,null,5,6]
输出：[1,null,3,2,4,null,5,6]
```

**示例 2：**
```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

**示例 3：**
```
输入：root = []
输出：[]
```

**提示：**
- 树的节点数在范围 `[0, 10^4]` 内
- `0 <= Node.val <= 10^4`
- N 叉树的高度小于或等于 1000
- 不要使用类成员 / 全局变量 / 静态变量来存储状态。你的序列化和反序列化算法应是无状态的。

## 解题思路

这道题要求设计 N 叉树的序列化和反序列化算法。关键是如何编码树的结构信息。

**核心思想：**
1. 序列化时需要记录每个节点的值和子节点数量
2. 可以使用前序遍历或层序遍历
3. 使用特殊标记来分隔节点和子节点列表

**常用方案：**

**方案一：前序遍历 + 子节点数量**
- 格式：`值,子节点数,[子节点1],[子节点2],...`
- 例如：`1,3,3,0,2,0,4,0` 表示根节点1有3个子节点

**方案二：层序遍历 + 子节点数量**
- 使用队列按层处理节点
- 每个节点后跟其子节点数量

**方案三：括号表示法**
- 格式：`值[子树1][子树2]...`
- 例如：`1[3[5][6]][2][4]`

## Java 代码实现

### 方法一：前序遍历 + 子节点数量 ⭐ 推荐

```java
import java.util.*;

public class Codec {
    public String serialize(Node root) {
        // 编码：将树转为字符串
        if (root == null) {
            return "";
        }

        StringBuilder result = new StringBuilder();
        dfsSerialize(root, result);
        // 去掉末尾多余的逗号
        return result.substring(0, result.length() - 1);
    }

    private void dfsSerialize(Node node, StringBuilder result) {
        if (node == null) {
            return;
        }

        // 记录节点值和子节点数量
        result.append(node.val).append(',');
        result.append(node.children.size()).append(',');

        // 递归处理所有子节点
        for (Node child : node.children) {
            dfsSerialize(child, result);
        }
    }

    public Node deserialize(String data) {
        // 解码：将字符串转为树
        if (data.isEmpty()) {
            return null;
        }

        String[] tokens = data.split(",");
        int[] index = {0};  // 使用数组模拟引用传递

        return dfsDeserialize(tokens, index);
    }

    private Node dfsDeserialize(String[] tokens, int[] index) {
        if (index[0] >= tokens.length) {
            return null;
        }

        // 读取节点值和子节点数量
        int val = Integer.parseInt(tokens[index[0]++]);
        int childrenCount = Integer.parseInt(tokens[index[0]++]);

        // 创建节点
        Node node = new Node(val, new ArrayList<>());

        // 递归构建所有子节点
        for (int i = 0; i < childrenCount; i++) {
            node.children.add(dfsDeserialize(tokens, index));
        }

        return node;
    }
}
```

### 方法二：层序遍历

```java
import java.util.*;

public class Codec {
    public String serialize(Node root) {
        if (root == null) {
            return "";
        }

        StringBuilder result = new StringBuilder();
        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            Node node = queue.poll();
            // 记录节点值和子节点数量
            result.append(node.val).append(',');
            result.append(node.children.size()).append(',');

            for (Node child : node.children) {
                queue.offer(child);
            }
        }

        return result.substring(0, result.length() - 1);
    }

    public Node deserialize(String data) {
        if (data.isEmpty()) {
            return null;
        }

        String[] tokens = data.split(",");
        // 根节点：值=tokens[0]，子节点数=tokens[1]
        Node root = new Node(Integer.parseInt(tokens[0]), new ArrayList<>());

        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);
        int index = 2;  // 跳过根节点的值和子节点数

        while (!queue.isEmpty()) {
            Node node = queue.poll();
            // tokens[index-1] 是当前节点的子节点数量
            int childrenCount = Integer.parseInt(tokens[index - 1]);

            for (int i = 0; i < childrenCount; i++) {
                Node child = new Node(Integer.parseInt(tokens[index]), new ArrayList<>());
                node.children.add(child);
                queue.offer(child);
                index += 2;  // 跳过值和子节点数
            }
        }

        return root;
    }
}
```

### 方法三：括号表示法

```java
import java.util.*;

public class Codec {
    public String serialize(Node root) {
        if (root == null) {
            return "";
        }
        return dfs(root);
    }

    private String dfs(Node node) {
        if (node == null) {
            return "";
        }

        // 节点值
        StringBuilder s = new StringBuilder(String.valueOf(node.val));

        // 如果有子节点，用括号包围
        if (!node.children.isEmpty()) {
            s.append('[');
            List<String> childStrs = new ArrayList<>();
            for (Node child : node.children) {
                childStrs.add(dfs(child));
            }
            s.append(String.join(",", childStrs));
            s.append(']');
        }

        return s.toString();
    }

    public Node deserialize(String data) {
        if (data.isEmpty()) {
            return null;
        }

        int[] index = {0};
        return dfs(data, index);
    }

    private Node dfs(String data, int[] index) {
        if (index[0] >= data.length()) {
            return null;
        }

        // 读取节点值（可能是多位数）
        int val = 0;
        while (index[0] < data.length() && Character.isDigit(data.charAt(index[0]))) {
            val = val * 10 + (data.charAt(index[0]++) - '0');
        }

        Node node = new Node(val, new ArrayList<>());

        // 如果有左括号，说明有子节点
        if (index[0] < data.length() && data.charAt(index[0]) == '[') {
            index[0]++;  // 跳过 '['

            while (index[0] < data.length() && data.charAt(index[0]) != ']') {
                node.children.add(dfs(data, index));
                // 跳过逗号
                if (index[0] < data.length() && data.charAt(index[0]) == ',') {
                    index[0]++;
                }
            }

            index[0]++;  // 跳过 ']'
        }

        return node;
    }
}
```

### 方法四：迭代 DFS（使用显式栈）

```java
import java.util.*;

public class Codec {
    public String serialize(Node root) {
        if (root == null) {
            return "";
        }

        StringBuilder result = new StringBuilder();
        // 使用栈模拟前序遍历，同时记录剩余子节点数
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{root, 0});

        while (!stack.isEmpty()) {
            Object[] top = stack.peek();
            Node node = (Node) top[0];
            int childIndex = (int) top[1];

            if (childIndex == 0) {
                // 第一次访问该节点：记录值和子节点数
                result.append(node.val).append(',');
                result.append(node.children.size()).append(',');
            }

            if (childIndex < node.children.size()) {
                // 还有子节点未处理
                top[1] = childIndex + 1;
                stack.push(new Object[]{node.children.get(childIndex), 0});
            } else {
                // 所有子节点已处理，弹出
                stack.pop();
            }
        }

        return result.substring(0, result.length() - 1);
    }

    public Node deserialize(String data) {
        if (data.isEmpty()) {
            return null;
        }

        String[] tokens = data.split(",");
        int[] index = {0};
        return buildNode(tokens, index);
    }

    private Node buildNode(String[] tokens, int[] index) {
        int val = Integer.parseInt(tokens[index[0]++]);
        int count = Integer.parseInt(tokens[index[0]++]);
        Node node = new Node(val, new ArrayList<>());
        for (int i = 0; i < count; i++) {
            node.children.add(buildNode(tokens, index));
        }
        return node;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是节点数量
  - 序列化：需要访问每个节点一次
  - 反序列化：需要创建每个节点一次
- 空间复杂度：O(n)
  - 存储序列化字符串：O(n)
  - 递归栈空间：O(h)，h 是树的高度

## 关键点总结

1. **编码方案设计**：需要同时编码节点值和结构信息（子节点数量）
2. **前序遍历**：递归处理根节点和所有子节点
3. **索引管理**：反序列化时需要维护当前读取位置（Java 用数组包装实现引用传递）
4. **子节点数量**：记录子节点数量是恢复树结构的关键
5. **边界处理**：空树要特殊处理

## 易错点

1. **索引越界**：反序列化时要检查索引是否超出范围
2. **子节点数量**：必须在序列化时记录，反序列化时读取
3. **递归终止**：空节点要正确处理
4. **分隔符选择**：避免与节点值冲突
5. **Java 引用传递**：Java 基本类型不能直接作为引用传递，需用数组或包装类
