## 题目描述

返回arr1中某整数与arr2中某整数的最长公共前缀长度（前缀为从最高位开始的连续数字）。

## 解题思路

将arr1所有整数的所有前缀存入HashSet，枚举arr2中每个整数的前缀查找最长匹配。

## Java 代码实现

```java
class Solution {
    public int longestCommonPrefix(int[] arr1, int[] arr2) {
        Set<String> prefixSet = new HashSet<>();
        for (int num : arr1) {
            String s = String.valueOf(num);
            for (int i = 1; i <= s.length(); i++) {
                prefixSet.add(s.substring(0, i));
            }
        }

        int ans = 0;
        for (int num : arr2) {
            String s = String.valueOf(num);
            for (int i = s.length(); i >= 1; i--) {
                if (prefixSet.contains(s.substring(0, i))) {
                    ans = Math.max(ans, i);
                    break;
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+M)*L)，L为数字最大位数(9)
- **空间复杂度**：O(N*L)

## 关键点总结

1. **前缀是从最高位开始**：转字符串操作
2. **HashSet存所有前缀**：查询O(1)
3. **从最长前缀开始查**：找到即停止
