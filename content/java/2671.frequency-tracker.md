## 题目描述

设计数据结构，支持添加数字、删除一个数字、查询是否有数字恰好出现指定次数，均要求 O(1) 时间。

## Java 代码实现

```java
import java.util.*;

class FrequencyTracker {
    private Map<Integer, Integer> count;     // number -> 出现次数
    private Map<Integer, Integer> freqCount; // 频率 -> 有多少数有此频率

    public FrequencyTracker() {
        count = new HashMap<>();
        freqCount = new HashMap<>();
    }

    public void add(int number) {
        int oldFreq = count.getOrDefault(number, 0);
        if (oldFreq > 0) freqCount.merge(oldFreq, -1, Integer::sum);
        count.put(number, oldFreq + 1);
        freqCount.merge(oldFreq + 1, 1, Integer::sum);
    }

    public void deleteOne(int number) {
        int oldFreq = count.getOrDefault(number, 0);
        if (oldFreq == 0) return;
        freqCount.merge(oldFreq, -1, Integer::sum);
        count.put(number, oldFreq - 1);
        if (oldFreq - 1 > 0) freqCount.merge(oldFreq - 1, 1, Integer::sum);
    }

    public boolean hasFrequency(int frequency) {
        return freqCount.getOrDefault(frequency, 0) > 0;
    }
}
```

## 复杂度分析

- 时间复杂度：add/deleteOne/hasFrequency 均 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 双哈希表：`count` 记录每个数的频率，`freqCount` 记录有多少数具有某频率
2. 每次操作先减去旧频率统计，再增加新频率统计
