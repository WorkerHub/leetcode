## 题目描述

给你一棵 n 个节点的无向树（根为 0），每个节点有值 `nums[i]`，删去两条边将树分成三个连通分量，分数为三个分量 XOR 值的最大值减最小值，返回最小分数。

## 解题思路

DFS 预处理每个节点的子树 XOR 值 `sub[v]` 和进出时间戳（用于 O(1) 判断祖孙关系）。枚举所有节点对 `(u, v)`（各代表删去其与父节点的边），根据祖孙关系推算三个分量的 XOR 值，取最小分数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] sub, tin, tout;
    private int timer = 0;
    private List<Integer>[] graph;

    @SuppressWarnings("unchecked")
    public int minimumScore(int[] nums, int[][] edges) {
        int n = nums.length;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }
        sub = new int[n];
        tin = new int[n];
        tout = new int[n];
        for (int i = 0; i < n; i++) sub[i] = nums[i];
        dfs(0, -1);
        int total = sub[0];

        int ans = Integer.MAX_VALUE;
        for (int u = 1; u < n; u++) {
            for (int v = u + 1; v < n; v++) {
                int x1, x2, x3;
                if (isAncestor(u, v)) {
                    // u 是 v 的祖先
                    x1 = sub[v]; x2 = sub[u] ^ sub[v]; x3 = total ^ sub[u];
                } else if (isAncestor(v, u)) {
                    // v 是 u 的祖先
                    x1 = sub[u]; x2 = sub[v] ^ sub[u]; x3 = total ^ sub[v];
                } else {
                    // 无祖孙关系
                    x1 = sub[u]; x2 = sub[v]; x3 = total ^ sub[u] ^ sub[v];
                }
                int score = Math.max(x1, Math.max(x2, x3)) - Math.min(x1, Math.min(x2, x3));
                ans = Math.min(ans, score);
            }
        }
        return ans;
    }

    private void dfs(int node, int parent) {
        tin[node] = timer++;
        for (int nb : graph[node]) {
            if (nb != parent) {
                dfs(nb, node);
                sub[node] ^= sub[nb]; // 子树 XOR 累计
            }
        }
        tout[node] = timer++;
    }

    // 判断 u 是否是 v 的祖先
    private boolean isAncestor(int u, int v) {
        return tin[u] <= tin[v] && tout[v] <= tout[u];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，n <= 1000
- **空间复杂度**：O(n)

## 关键点总结

1. 删去节点 v 与父节点的边，等价于将 `sub[v]` 从树中割离。
2. 利用 DFS 进出时间戳 O(1) 判断祖孙关系。
3. 三个分量的 XOR 可由子树 XOR 值和总 XOR 推导。
