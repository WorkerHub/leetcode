## 题目描述

设计支持前、中、后三个位置 push 和 pop 的队列。若有两个中间位置，选靠前的（偶数长度时取前一个中间）。

## 解题思路

使用**两个 ArrayDeque**：`left` 存前半，`right` 存后半。维持 `left.size() == right.size()` 或 `left.size() == right.size() + 1`（奇数时左多一个）。每次操作后平衡两个队列。

## Java 代码实现

```java
class FrontMiddleBackQueue {
    private Deque<Integer> left;  // 前半部分
    private Deque<Integer> right; // 后半部分

    public FrontMiddleBackQueue() {
        left = new ArrayDeque<>();
        right = new ArrayDeque<>();
    }

    // 平衡两个队列
    private void balance() {
        if (left.size() > right.size() + 1) {
            right.addFirst(left.removeLast());
        } else if (right.size() > left.size()) {
            left.addLast(right.removeFirst());
        }
    }

    public void pushFront(int val) {
        left.addFirst(val);
        balance();
    }

    public void pushMiddle(int val) {
        if (left.size() > right.size()) {
            right.addFirst(left.removeLast());
        }
        left.addLast(val);
        // 已手动平衡，无需调用 balance
    }

    public void pushBack(int val) {
        right.addLast(val);
        balance();
    }

    public int popFront() {
        if (left.isEmpty() && right.isEmpty()) return -1;
        int val = left.isEmpty() ? right.removeFirst() : left.removeFirst();
        balance();
        return val;
    }

    public int popMiddle() {
        if (left.isEmpty() && right.isEmpty()) return -1;
        int val = left.removeLast(); // 中间元素在 left 的末尾
        balance();
        return val;
    }

    public int popBack() {
        if (left.isEmpty() && right.isEmpty()) return -1;
        int val = right.isEmpty() ? left.removeLast() : right.removeLast();
        balance();
        return val;
    }
}
```

## 复杂度分析

- **时间复杂度**：所有操作 O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. 左半（left）存前一半，右半（right）存后一半
2. 奇数长度时 left 比 right 多一个，中间元素是 left 的最后一个
3. 每次操作后调用 balance 维持平衡
