## 题目描述

给定两个字符串 `low` 和 `high` 表示两个整数，返回范围 `[low, high]` 内所有中心对称数的个数。

中心对称数是指一个数字在旋转了 180 度之后看起来依旧相同的数字（或者上下颠倒地看）。

**示例 1：**
```
输入: low = "50", high = "100"
输出: 3
解释: 中心对称数有 "69", "88", "96"
```

**示例 2：**
```
输入: low = "0", high = "0"
输出: 1
```

**提示：**
- 1 <= low.length, high.length <= 15
- low 和 high 仅由数字组成
- low <= high
- low 和 high 不含前导零（除了零本身）

## 解题思路

这道题是 [LeetCode 247](https://leetcode.com/problems/strobogrammatic-number-ii/) 的扩展，从生成所有中心对称数变成统计范围内的个数。

**核心思想：**
- 利用 247 题的方法生成中心对称数
- 对每个生成的数判断是否在 [low, high] 范围内
- 优化：不生成所有数，只统计符合条件的个数

**关键观察：**
1. **按长度枚举**：从 low.length 到 high.length，枚举每种长度的中心对称数
2. **字符串比较**：由于是字符串，需要注意长度和字典序
3. **边界处理**：
   - 长度小于 low 的不计入
   - 长度大于 high 的不计入
   - 相同长度的要比较字典序
4. **前导零**：长度大于 1 时不能有前导零

**优化思路：**
- 不需要存储所有数字，只需计数
- 可以在生成过程中就判断范围，剪枝

## Java 代码实现

### 方法一：生成所有数后过滤（基础版）

```java
import java.util.*;

class Solution {
    private String low, high;
    
    public int strobogrammaticInRange(String low, String high) {
        this.low = low;
        this.high = high;
        
        int count = 0;
        
        // 枚举每种长度
        for (int length = low.length(); length <= high.length(); length++) {
            List<String> nums = findStrobogrammatic(length);
            
            for (String num : nums) {
                // 检查是否在范围内
                if (isInRange(num)) {
                    count++;
                }
            }
        }
        
        return count;
    }
    
    // 生成所有长度为 n 的中心对称数（来自 247 题）
    private List<String> findStrobogrammatic(int n) {
        return helper(n, n);
    }
    
    private List<String> helper(int n, int length) {
        if (n == 0) {
            return new ArrayList<>(Arrays.asList(""));
        }
        if (n == 1) {
            return new ArrayList<>(Arrays.asList("0", "1", "8"));
        }
        
        List<String> middles = helper(n - 2, length);
        List<String> result = new ArrayList<>();
        
        char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
        for (String middle : middles) {
            for (char[] pair : pairs) {
                if (n != length || pair[0] != '0') {
                    result.add(pair[0] + middle + pair[1]);
                }
            }
        }
        
        return result;
    }
    
    // 判断 num 是否在 [low, high] 范围内
    private boolean isInRange(String num) {
        // 长度不同时直接比较长度
        if (num.length() < low.length() || num.length() > high.length()) {
            return false;
        }
        
        // 长度相同时比较字典序
        if (num.length() == low.length() && num.compareTo(low) < 0) {
            return false;
        }
        if (num.length() == high.length() && num.compareTo(high) > 0) {
            return false;
        }
        
        return true;
    }
}
```

### 方法二：递归 + 计数（推荐）⭐

```java
class Solution {
    private int count = 0;
    private String low, high;
    
    public int strobogrammaticInRange(String low, String high) {
        this.count = 0;
        this.low = low;
        this.high = high;
        
        // 枚举每种长度
        for (int length = low.length(); length <= high.length(); length++) {
            dfs("", "", length, length);
        }
        
        return count;
    }
    
    /**
     * 从两端向中间构建中心对称数
     * left: 左半部分
     * right: 右半部分
     * currentLen: 当前还需要填充的长度
     * targetLen: 目标长度
     */
    private void dfs(String left, String right, int currentLen, int targetLen) {
        // 递归终止
        if (currentLen == 0) {
            String num = left + right;
            if (isValid(num)) {
                count++;
            }
            return;
        }
        
        // 中间字符（长度为奇数时）
        if (currentLen == 1) {
            for (char digit : new char[]{'0', '1', '8'}) {
                String num = left + digit + right;
                if (isValid(num)) {
                    count++;
                }
            }
            return;
        }
        
        // 递归添加两端
        char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
        for (char[] pair : pairs) {
            // 最外层不能是 0
            if (currentLen != targetLen || pair[0] != '0') {
                dfs(left + pair[0], pair[1] + right, currentLen - 2, targetLen);
            }
        }
    }
    
    // 检查 num 是否在 [low, high] 范围内
    private boolean isValid(String num) {
        if (num.length() < low.length() || num.length() > high.length()) {
            return false;
        }
        if (num.length() == low.length() && num.compareTo(low) < 0) {
            return false;
        }
        if (num.length() == high.length() && num.compareTo(high) > 0) {
            return false;
        }
        return true;
    }
}
```

### 方法三：优化计数（不存储字符串）⭐

```java
class Solution {
    private String low, high;
    
    public int strobogrammaticInRange(String low, String high) {
        this.low = low;
        this.high = high;
        
        int count = 0;
        for (int length = low.length(); length <= high.length(); length++) {
            count += countHelper(new StringBuilder(), new StringBuilder(), length);
        }
        
        return count;
    }
    
    private int countHelper(StringBuilder left, StringBuilder right, int remaining) {
        if (remaining == 0) {
            String num = left.toString() + right.toString();
            return inRange(num) ? 1 : 0;
        }
        
        if (remaining == 1) {
            int count = 0;
            for (char mid : new char[]{'0', '1', '8'}) {
                String num = left.toString() + mid + right.toString();
                if (inRange(num)) {
                    count++;
                }
            }
            return count;
        }
        
        int count = 0;
        char[][] pairs = {{'0', '0'}, {'1', '1'}, {'6', '9'}, {'8', '8'}, {'9', '6'}};
        for (char[] pair : pairs) {
            // 最外层不能是 0
            if (left.length() > 0 || pair[0] != '0') {
                left.append(pair[0]);
                right.insert(0, pair[1]);
                count += countHelper(left, right, remaining - 2);
                left.deleteCharAt(left.length() - 1);
                right.deleteCharAt(0);
            }
        }
        
        return count;
    }
    
    private boolean inRange(String num) {
        if (num.length() > high.length() || num.length() < low.length()) {
            return false;
        }
        if (num.length() == low.length() && num.compareTo(low) < 0) {
            return false;
        }
        if (num.length() == high.length() && num.compareTo(high) > 0) {
            return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(5^(n/2) * k)，其中 n 是 high 的长度，k 是长度范围
- **空间复杂度**：O(n)，递归栈深度

对于最大长度 15，最多有 5^7 ≈ 78,125 个数，是可以接受的。

```

  长度 1：生成 ["0", "1", "8"]

结果：1
```

## 关键点总结

1. **按长度枚举**：从 low 的长度到 high 的长度逐个枚举
2. **字符串比较**：使用 `compareTo()` 进行字典序比较，相同长度才能比
3. **边界检查**：生成后立即检查是否在范围内
4. **前导零**：长度大于 1 时最外层不能是 0
5. **不用 Integer/Long 转换**：数字可能超过 long 的范围，必须用字符串比较

## 易错点

1. **字符串比较**：不能用 `Integer.parseInt()` 转换，因为数字可能超过 long 的范围
2. **长度边界**：要包含 low 和 high 的长度（`<=` 而不是 `<`）
3. **前导零**：特殊处理 "0" 这个数字
4. **范围判断**：要同时考虑长度和字典序
5. **compareTo 使用**：`num.compareTo(low) < 0` 表示 num < low
