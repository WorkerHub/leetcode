## 题目描述

给你 n 个节点的无向树，每次操作可对一条边的两端点值均异或 k，执行任意次操作，返回所有节点值总和的最大值。

## 解题思路

关键观察：每次操作同时改变两端点的异或状态，最终被异或 k 的节点数必须为偶数。贪心：计算每个节点异或后的增益，每次选两个增益为正的节点（保持偶数约束）。

## Java 代码实现

```java
class Solution {
    public long maximumValueSum(int[] nums, int k, int[][] edges) {
        long total = 0;
        // 计算每个节点异或 k 后的增益，按降序排序
        int n = nums.length;
        int[] gains = new int[n];
        for (int i = 0; i < n; i++) {
            total += nums[i];
            gains[i] = (nums[i] ^ k) - nums[i];
        }
        Arrays.sort(gains);

        // 从最大增益开始，每次取两个正增益对
        long extra = 0;
        for (int i = n - 1; i >= 1; i -= 2) {
            int pairGain = gains[i] + gains[i - 1];
            if (pairGain > 0) extra += pairGain;
            else break;
        }
        return total + extra;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. 树结构不影响最终结果，关键是偶数个节点被异或的约束
2. 贪心选最大增益对（两个一组保证偶数约束）
3. 用 long 累计总和防止溢出
