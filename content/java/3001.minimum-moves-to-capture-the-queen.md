## 题目描述

8x8 棋盘上有白色车（a,b）、白色象（c,d）和黑色皇后（e,f），返回白方捕获皇后所需的最少移动次数。

## 解题思路

答案只有 1 或 2。检查三种一步到位的情况：车同行且象不阻挡；车同列且象不阻挡；象与皇后同对角线且车不阻挡。否则返回 2。

## Java 代码实现

```java
class Solution {
    public int minMovesToCaptureTheQueen(int a, int b, int c, int d, int e, int f) {
        // 车同行攻击：象不在中间
        if (a == e && !(c == a && between(d, b, f))) return 1;
        // 车同列攻击：象不在中间
        if (b == f && !(d == b && between(c, a, e))) return 1;
        // 象同对角线攻击：车不在中间
        if (Math.abs(c - e) == Math.abs(d - f)) {
            if (!(Math.abs(a - c) == Math.abs(b - d) && between(a, c, e) && between(b, d, f)))
                return 1;
        }
        return 2;
    }

    // 判断 x 是否严格在 lo 和 hi 之间
    private boolean between(int x, int lo, int hi) {
        return Math.min(lo, hi) < x && x < Math.max(lo, hi);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 答案只有 1 或 2（不可能是 0，初始不重合）
2. 阻挡条件：阻挡棋子严格在两者之间（严格不等号）
3. 车两步内必能捕获（先对齐行或列再攻击）
