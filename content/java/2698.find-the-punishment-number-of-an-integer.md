## 题目描述

给你正整数 `n`，若 `i^2` 的字符串可以分割成各部分整数之和等于 `i`，则 `i` 满足条件，返回 `[1, n]` 内所有满足条件的 `i^2` 之和（惩罚数）。

## Java 代码实现

```java
class Solution {
    public int punishmentNumber(int n) {
        int total = 0;
        for (int i = 1; i <= n; i++) {
            String s = String.valueOf(i * i);
            if (canPartition(s, 0, i)) {
                total += i * i;
            }
        }
        return total;
    }

    // 回溯：从 idx 开始分割，剩余目标为 remaining
    private boolean canPartition(String s, int idx, int remaining) {
        if (idx == s.length()) return remaining == 0;
        int num = 0;
        for (int j = idx; j < s.length(); j++) {
            num = num * 10 + (s.charAt(j) - '0');
            if (num > remaining) break; // 剪枝
            if (canPartition(s, j + 1, remaining - num)) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 2^L)，L 为 `i^2` 的位数（最多 7 位）
- 空间复杂度：O(L)，递归深度

## 关键点总结

1. 对每个 `i` 用回溯验证 `i^2` 字符串是否存在满足条件的分割
2. 当前数值超过剩余目标时剪枝
