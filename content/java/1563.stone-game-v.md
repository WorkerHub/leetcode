## 题目描述

石子序列每轮分成左右两段，移除和更大的段，得分为剩下段的和。Alice 最大化得分，Bob 最小化。返回 Alice 最大得分。

**提示：** 1 <= stoneValue.length <= 500

## 解题思路

区间 DP：dp[i][j] = 对子数组 [i,j] 当前玩家能获得的最大分数。枚举分割点 k。

## Java 代码实现

```java
class Solution {
    public int stoneGameV(int[] stoneValue) {
        int n = stoneValue.length;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + stoneValue[i];
        }
        
        int[][] dp = new int[n][n];
        
        // 按区间长度从小到大
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                for (int k = i; k < j; k++) {
                    int left = prefix[k + 1] - prefix[i];
                    int right = prefix[j + 1] - prefix[k + 1];
                    if (left < right) {
                        dp[i][j] = Math.max(dp[i][j], left + dp[i][k]);
                    } else if (left > right) {
                        dp[i][j] = Math.max(dp[i][j], right + dp[k + 1][j]);
                    } else {
                        dp[i][j] = Math.max(dp[i][j],
                            Math.max(left + dp[i][k], right + dp[k + 1][j]));
                    }
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：状态为区间 [i,j]
2. **保留小段**：得分 = 小段和 + 子问题最优解
3. **两段相等**：取两边递归的最大值
