## 题目描述

给定一棵有 `n` 个节点的树，根节点为 `1`。为每条边分配权重 1 或 2，对于查询 `(u, v)`，求有多少种边权分配方案使得路径长度的奇偶性为奇数，对 `10^9 + 7` 取模。

## 解题思路

路径上有 `e` 条边时，选奇数个权重为 1 的方案数为 `2^(e-1)`，路径外 `n-1-e` 条边任意分配为 `2^(n-1-e)`，总方案 = `2^(n-2)`（与 e 无关，只要 e > 0）。使用二进制提升计算 LCA 和路径边数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int LOG;
    private int[] depth;
    private int[][] parent;

    public int[] assignEdgeWeights(int n, int[][] edges, int[][] queries) {
        final int MOD = 1_000_000_007;
        LOG = 1;
        while ((1 << LOG) <= n) LOG++;

        List<Integer>[] graph = new List[n + 1];
        for (int i = 0; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        depth = new int[n + 1];
        parent = new int[LOG][n + 1];

        // BFS 建树
        boolean[] visited = new boolean[n + 1];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(1);
        visited[1] = true;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (!visited[v]) {
                    visited[v] = true;
                    depth[v] = depth[u] + 1;
                    parent[0][v] = u;
                    queue.add(v);
                }
            }
        }

        // 二进制提升
        for (int k = 1; k < LOG; k++)
            for (int u = 1; u <= n; u++)
                parent[k][u] = parent[k-1][parent[k-1][u]];

        // 预计算 2^(n-2) mod MOD
        long pow = 1;
        for (int i = 0; i < n - 2; i++) pow = pow * 2 % MOD;

        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int u = queries[i][0], v = queries[i][1];
            int l = lca(u, v);
            int e = depth[u] + depth[v] - 2 * depth[l]; // 路径边数
            result[i] = (e == 0) ? 0 : (int) pow;
        }
        return result;
    }

    private int lca(int u, int v) {
        if (depth[u] < depth[v]) { int tmp = u; u = v; v = tmp; }
        int diff = depth[u] - depth[v];
        for (int k = 0; k < LOG; k++)
            if ((diff >> k & 1) == 1) u = parent[k][u];
        if (u == v) return u;
        for (int k = LOG - 1; k >= 0; k--)
            if (parent[k][u] != parent[k][v]) { u = parent[k][u]; v = parent[k][v]; }
        return parent[0][u];
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n log n)

## 关键点总结

1. 路径边数 e > 0 时，答案固定为 `2^(n-2)`（与 e 无关）
2. u == v 时路径长度为 0，奇数方案数为 0
3. 二进制提升实现 O(log n) LCA 查询
