## 题目描述

给你每个节点至多一条出边的有向图（`edges` 数组），返回最长环的长度，不存在环则返回 -1。

## 解题思路

DFS + 时间戳：遍历每个未访问节点，沿出边行走并记录进入时间戳。遇到已访问节点时，若该节点时间戳 >= 本次 DFS 起始时间戳，则找到环，长度为当前时间 - 该节点时间戳。

## Java 代码实现

```java
class Solution {
    public int longestCycle(int[] edges) {
        int n = edges.length;
        int[] visited = new int[n]; // 0=未访问，>0=访问时间戳
        int ans = -1, timer = 1;

        for (int start = 0; start < n; start++) {
            if (visited[start] != 0) continue;
            int cur = start, startTimer = timer;
            while (cur != -1 && visited[cur] == 0) {
                visited[cur] = timer++;
                cur = edges[cur];
            }
            // cur != -1 且已访问：检查是否在本次 DFS 路径上
            if (cur != -1 && visited[cur] >= startTimer) {
                ans = Math.max(ans, timer - visited[cur]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每个节点至多一条出边，图为"rho"形结构（链 + 环）。
2. 时间戳判断环：`visited[cur] >= startTimer` 确保是本次路径上的节点。
3. 环长度 = 当前时间戳 - 环入口节点的时间戳。
