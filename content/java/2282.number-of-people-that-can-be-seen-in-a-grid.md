## 题目描述

矩阵中每人在其行和列中能看到的人数（中间无人严格高于两者较矮者）。

## 解题思路

行和列独立处理，用单调递减栈统计可见对。弹出时栈顶与当前元素互相可见，等高元素需特殊处理避免重复计数。

## Java 代码实现

```java
class Solution {
    public int[][] seePeople(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        int[][] ans = new int[m][n];

        // 处理每一行
        for (int i = 0; i < m; i++) {
            processLine(heights[i], ans[i]);
        }
        // 处理每一列
        for (int j = 0; j < n; j++) {
            int[] col = new int[m];
            for (int i = 0; i < m; i++) col[i] = heights[i][j];
            int[] colAns = new int[m];
            processLine(col, colAns);
            for (int i = 0; i < m; i++) ans[i][j] += colAns[i];
        }
        return ans;
    }

    private void processLine(int[] arr, int[] result) {
        Deque<Integer> stack = new ArrayDeque<>(); // 存下标
        for (int i = 0; i < arr.length; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] <= arr[i]) {
                int idx = stack.pop();
                result[idx]++;
                result[i]++;
                // 等高处理：如果栈顶与被弹出的等高，i不应重复计
                if (!stack.isEmpty() && arr[stack.peek()] == arr[idx]) {
                    result[i]--;
                }
            }
            if (!stack.isEmpty()) {
                // 栈顶比当前高，栈顶能看到当前
                result[stack.peek()]++;
            }
            stack.push(i);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(max(m, n))

## 关键点总结

1. **行列独立处理**：分别用单调栈统计
2. **单调递减栈**：弹出时两者互相可见
3. **等高特殊处理**：避免重复计数
