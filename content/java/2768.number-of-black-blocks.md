## 题目描述

给你 `m x n` 矩阵和黑色格子坐标 `coordinates`，返回长度为 5 的数组，`arr[i]` 为恰好包含 `i` 个黑色格子的 2x2 子矩阵数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long[] countBlackBlocks(int m, int n, int[][] coordinates) {
        // 用 HashMap 统计每个 2x2 子矩阵（左上角 r*100001+c）中黑色格子数
        Map<Long, Integer> blockCount = new HashMap<>();
        for (int[] coord : coordinates) {
            int x = coord[0], y = coord[1];
            // 该格子属于左上角为 (x-dr, y-dc) 的 2x2 子矩阵
            for (int dr = 0; dr <= 1; dr++) {
                for (int dc = 0; dc <= 1; dc++) {
                    int r = x - dr, c = y - dc;
                    if (r >= 0 && r <= m - 2 && c >= 0 && c <= n - 2) {
                        long key = (long) r * 100001 + c;
                        blockCount.merge(key, 1, Integer::sum);
                    }
                }
            }
        }
        long[] ans = new long[5];
        for (int cnt : blockCount.values()) ans[cnt]++;
        // 0 个黑色格子的 2x2 子矩阵数 = 总数 - 有黑色格子的数
        long total = (long) (m - 1) * (n - 1);
        ans[0] = total - (ans[1] + ans[2] + ans[3] + ans[4]);
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k)，k 为黑色格子数
- 空间复杂度：O(k)

## 关键点总结

1. 每个黑色格子最多影响 4 个 2x2 子矩阵
2. 用哈希表记录各子矩阵中黑色格子数
3. 总 2x2 子矩阵数 = `(m-1) * (n-1)`
