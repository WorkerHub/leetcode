## 题目描述

给定非负整数数组 `nums`，每次操作选择一个子数组将所有元素减 1（要求所有元素 >= 1）。求将所有元素变为 0 的最少操作次数。

## 解题思路

等价于直方图层数统计：对差分数组中正差分（当前值大于前一值）求和即为答案。维护前一个值，若 `nums[i] > prev` 则操作数 += `nums[i] - prev`。

## Java 代码实现

```java
class Solution {
    public long minOperations(int[] nums) {
        long ops = 0;
        int prev = 0;
        for (int x : nums) {
            if (x > prev) ops += x - prev;
            prev = x;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 操作数等于正差分之和（直方图新增层数）
2. 只需记录前一个值，O(1) 额外空间
3. 结果用 long 防止溢出
