## 题目描述

有 n 种金属、k 台机器，每台机器有各自的合金配方，给定库存和购买费用及预算，每次只能用一台机器，返回能制造的最多合金数量。

## 解题思路

二分答案：二分制造数量 mid，对每台机器计算制造 mid 个合金所需的额外购买费用，若任意一台机器的费用不超过预算则可行。

## Java 代码实现

```java
class Solution {
    public int maxNumberOfAlloys(int n, int k, int budget,
                                  List<List<Integer>> composition,
                                  List<Integer> stock,
                                  List<Integer> cost) {
        int lo = 0, hi = (int) 1e9;

        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (canMake(mid, n, k, budget, composition, stock, cost)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }

    private boolean canMake(long amount, int n, int k, long budget,
                             List<List<Integer>> composition,
                             List<Integer> stock,
                             List<Integer> cost) {
        for (int i = 0; i < k; i++) {
            long totalCost = 0;
            boolean ok = true;
            for (int j = 0; j < n; j++) {
                long need = (long) composition.get(i).get(j) * amount;
                long extra = Math.max(0, need - stock.get(j));
                totalCost += extra * cost.get(j);
                if (totalCost > budget) { ok = false; break; }
            }
            if (ok) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × k × log(max_ans))
- **空间复杂度**：O(1)

## 关键点总结

1. 二分答案：制造数量具有单调性
2. 每次检查枚举所有机器，任一机器可行即返回 true
3. 使用 long 防止 `composition * amount` 溢出
