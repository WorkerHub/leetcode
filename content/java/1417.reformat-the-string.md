## 题目描述

给你一个混合了数字和字母的字符串 `s`，其中的字母均为小写英文字母。

请你将该字符串重新格式化，使得任意两个相邻字符的类型都不同。也就是说，字母后面跟着数字，或者数字后面跟着字母。

重新格式化后，返回新的字符串；如果无法重新格式化，则返回一个 **空字符串**。

**示例 1：**

```
输入：s = "a0b1c2"
输出："0a1b2c" 或 "a0b1c2"（任意合法结果均可）
```

**示例 2：**

```
输入：s = "leetcode"
输出：""
解释：只有字母，无法重新格式化。
```

**示例 3：**

```
输入：s = "1229857369"
输出：""
解释：只有数字，无法重新格式化。
```

**示例 4：**

```
输入：s = "covid2019"
输出："c2o0v1i9d"
```

**提示：**

- `1 <= s.length <= 500`
- `s` 仅由小写英文字母和/或数字组成

## 解题思路

### 核心思路

1. 分别收集所有字母和所有数字到两个列表
2. 检查合法性：字母数量和数字数量之差最多为 1（否则无法交替）
3. 若合法，交替合并两个列表

**判断合法性：**
- 若 `|len(letters) - len(digits)| > 1`，返回 `""`
- 若 `len(letters) == len(digits)`，字母开头或数字开头均可
- 若 `len(letters) > len(digits)`，字母开头
- 若 `len(digits) > len(letters)`，数字开头

## Java 代码实现

### 方法一：分组后交替合并（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String reformat(String s) {
        // 分别收集字母和数字
        List<Character> letters = new ArrayList<>();
        List<Character> digits = new ArrayList<>();
        for (char c : s.toCharArray()) {
            if (Character.isLetter(c)) {
                letters.add(c);
            } else {
                digits.add(c);
            }
        }

        // 检查合法性：数量差超过 1 则无法交替
        if (Math.abs(letters.size() - digits.size()) > 1) {
            return "";
        }

        // 确保 letters 和 digits 中较多的那个放在前面
        // 若数字更多，交换使数字先出现
        if (digits.size() > letters.size()) {
            List<Character> temp = letters;
            letters = digits;
            digits = temp;
        }

        // 交替合并：letters 开头（数量 >= digits）
        StringBuilder result = new StringBuilder();
        for (int i = 0; i < digits.size(); i++) {
            result.append(letters.get(i));
            result.append(digits.get(i));
        }
        // 若 letters 比 digits 多一个，追加最后一个 letter
        if (letters.size() > digits.size()) {
            result.append(letters.get(letters.size() - 1));
        }

        return result.toString();
    }
}
```

### 方法二：使用数组（更简洁）

```java
class Solution {
    public String reformat(String s) {
        StringBuilder letters = new StringBuilder();
        StringBuilder digits = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetter(c)) {
                letters.append(c);
            } else {
                digits.append(c);
            }
        }

        int lLen = letters.length(), dLen = digits.length();
        if (Math.abs(lLen - dLen) > 1) return "";

        // 确保 letters 包含较多的那类（数量 >= digits）
        if (dLen > lLen) {
            StringBuilder temp = letters;
            letters = digits;
            digits = temp;
            int tmp = lLen;
            lLen = dLen;
            dLen = tmp;
        }

        StringBuilder result = new StringBuilder();
        for (int i = 0; i < dLen; i++) {
            result.append(letters.charAt(i));
            result.append(digits.charAt(i));
        }
        if (lLen > dLen) {
            result.append(letters.charAt(lLen - 1));
        }

        return result.toString();
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 所有方法 | O(n) | O(n) |

`n` 为字符串长度，只需一次遍历分组，一次遍历合并。

## 关键点总结

1. 分开收集字母和数字，检查数量差是否 ≤ 1
2. 较多的那类字符放在前面（决定首字符类型）
3. 交替合并，最后追加多余的那个字符
4. Java 中用 `Character.isLetter()` 和 `Character.isDigit()` 判断字符类型

## 易错点

1. 题目要求返回**任意合法结果**，不需要特定顺序（但需要交替）
2. 只有字母或只有数字时，`Math.abs(letters.size() - digits.size()) > 1`，正确返回 ""
3. 字母和数字恰好一样多时，字母开头或数字开头均可
