## 题目描述

给定整数 `n`，提取各位数字，返回最大两个数字的乘积。

## 解题思路

维护最大值和次大值，遍历各位数字更新。

## Java 代码实现

```java
class Solution {
    public int maxProduct(int n) {
        int first = 0, second = 0;
        while (n > 0) {
            int d = n % 10;
            n /= 10;
            if (d >= first) { second = first; first = d; }
            else if (d > second) second = d;
        }
        return first * second;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)
- 空间复杂度：O(1)

## 关键点总结

1. 维护最大和次大值，一次遍历
2. 更新时先判断是否 >= 最大值，若是则最大变次大
