## 题目描述

给定任务数组 `tasks[i] = [start, end, duration]`，每个任务须在 `[start, end]` 内完成，需要连续 `duration` 个时间单位，任务可中断，每次只能执行一个，返回完成所有任务的最短时间，无法完成返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int[][] tasks) {
        // 按截止时间排序
        Arrays.sort(tasks, Comparator.comparingInt(t -> t[1]));

        int maxEnd = tasks[tasks.length - 1][1];
        // run[t] = 1 表示时间 t 被占用
        int[] run = new int[maxEnd + 2];

        for (int[] task : tasks) {
            int start = task[0], end = task[1], duration = task[2];
            // 统计 [start, end] 内已占用时间
            int already = 0;
            for (int t = start; t <= end; t++) already += run[t];
            int need = duration - already;

            // 从 end 向前填充 need 个空闲槽
            int t = end;
            while (need > 0) {
                if (t < start) return -1;  // 窗口内空间不足
                if (run[t] == 0) {
                    run[t] = 1;
                    need--;
                }
                t--;
            }
        }

        int total = 0;
        for (int v : run) total += v;
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * T)，T 为最大时间窗口（可用线段树优化到 O(n log T)）
- 空间复杂度：O(T)

## 关键点总结

1. EDF（最早截止时间优先）贪心策略：按截止时间升序排序
2. 从截止时间向前靠后填充，为早截止任务保留前面的时间槽
3. 若窗口内空闲时间不足 `duration`，返回 -1
