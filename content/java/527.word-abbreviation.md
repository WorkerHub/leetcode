## 题目描述

给定一个由不同字符串组成的数组 `words`，返回每个单词的最小可能缩写。

字符串缩写的规则如下：

1. 每个单词的初始缩写是：第一个字符，然后是中间的字符数量，最后是最后一个字符
2. 如果多个单词共享相同的缩写，则执行以下操作：
   - 将它们每个缩写的前缀（第一部分的字符）增加 1
   - 重复此操作，直到每个缩写都是唯一的
3. 最后，如果缩写没有使单词变短，则保留原始单词

**示例 1：**
```
输入: words = ["like","god","internal","me","internet","interval","intension","face","intrusion"]
输出: ["l2e","god","internal","me","i6t","interval","inte4n","f2e","intr4n"]
```

**示例 2：**
```
输入: words = ["aa","aaa"]
输出: ["aa","aaa"]
```

**提示：**
- `1 <= words.length <= 400`
- `2 <= words[i].length <= 400`
- `words[i]` 由小写英文字母组成
- `words` 的所有字符串都是唯一的

## 解题思路

按（长度，尾字母）分组，每组构建 Trie，查找唯一前缀后生成缩写。

## Java 代码实现

### 方法一：分组 + 字典树（推荐）

```java
class Solution {
    public List<String> wordsAbbreviation(List<String> words) {
        int n = words.size();
        // 按（长度，尾字母）分组
        Map<String, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            String word = words.get(i);
            String key = word.length() + "_" + word.charAt(word.length() - 1);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(i);
        }
        
        // 为每组查找唯一前缀
        int[] prefixLens = new int[n];
        for (List<Integer> indices : groups.values()) {
            // 构建 Trie
            int[][] children = new int[400 * indices.size()][26];
            int[] cnt = new int[400 * indices.size()];
            int nodeCount = 1;
            
            for (int i : indices) {
                String word = words.get(i);
                int node = 0;
                for (char c : word.toCharArray()) {
                    int idx = c - 'a';
                    if (children[node][idx] == 0) {
                        children[node][idx] = nodeCount++;
                    }
                    node = children[node][idx];
                    cnt[node]++;
                }
            }
            
            // 查找唯一前缀
            for (int i : indices) {
                String word = words.get(i);
                int node = 0;
                for (int j = 0; j < word.length(); j++) {
                    int idx = word.charAt(j) - 'a';
                    node = children[node][idx];
                    if (cnt[node] == 1) {
                        prefixLens[i] = j + 1;
                        break;
                    }
                }
                if (prefixLens[i] == 0) {
                    prefixLens[i] = word.length();
                }
            }
        }
        
        // 生成缩写
        List<String> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String word = words.get(i);
            int prefixLen = prefixLens[i];
            int middleCount = word.length() - prefixLen - 1;
            
            if (middleCount <= 1) {
                // 缩写不比原词短
                result.add(word);
            } else {
                String abbr = word.substring(0, prefixLen) + middleCount + word.charAt(word.length() - 1);
                result.add(abbr.length() < word.length() ? abbr : word);
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(L)，L 是所有单词的总长度
- **空间复杂度**：O(L)，Trie 存储

## 关键点总结

1. **分组策略**：只有长度和尾字母相同的单词可能冲突
2. **Trie 计数**：`cnt` 记录经过每个节点的单词数
3. **唯一前缀**：第一个 `cnt == 1` 的节点
4. **缩写验证**：必须比原单词短才使用

## 易错点

1. **缩写长度计算**：数字可能是多位
2. **Java Trie 实现**：使用数组模拟比对象更高效
3. **分组键**：必须同时包含长度和尾字母
