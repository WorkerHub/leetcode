## 题目描述

给定一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

返回一个表示每个字符串片段的长度的列表。

**示例 1:**
```
输入: s = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释:
划分结果为 "ababcbaca", "defegde", "hijhklij"
每个字母最多出现在一个片段中。
```

**示例 2:**
```
输入: s = "eccbbbbdec"
输出: [10]
```

**提示:**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 解题思路

这是一个经典的贪心算法问题。

**核心思想：**
1. 记录每个字符最后出现的位置
2. 遍历字符串，维护当前片段的结束位置
3. 当遍历到当前片段的结束位置时，可以进行切分

**算法流程：**
1. 第一次遍历：记录每个字符最后出现的位置
2. 第二次遍历：
   - 维护当前片段的结束位置
   - 如果当前字符的最后位置超过当前结束位置，更新结束位置
   - 当遍历到结束位置时，切分片段

## Java 代码实现

### 方法一：贪心算法（推荐）

```java
import java.util.*;

class Solution {
    public List<Integer> partitionLabels(String s) {
        // 记录每个字符最后出现的位置
        int[] lastOccurrence = new int[26];
        for (int i = 0; i < s.length(); i++) {
            lastOccurrence[s.charAt(i) - 'a'] = i;
        }

        List<Integer> result = new ArrayList<>();
        int start = 0;
        int end = 0;

        for (int i = 0; i < s.length(); i++) {
            // 更新当前片段的结束位置
            end = Math.max(end, lastOccurrence[s.charAt(i) - 'a']);

            // 如果到达当前片段的结束位置，进行切分
            if (i == end) {
                result.add(end - start + 1);
                start = i + 1;
            }
        }

        return result;
    }
}
```

### 方法二：详细注释版（易理解）

```java
import java.util.*;

class Solution {
    public List<Integer> partitionLabels(String s) {
        // 步骤 1: 记录每个字符最后出现的位置
        int[] lastPosition = new int[26];
        for (int index = 0; index < s.length(); index++) {
            lastPosition[s.charAt(index) - 'a'] = index;
        }

        // 步骤 2: 遍历字符串，划分片段
        List<Integer> partitions = new ArrayList<>();
        int partitionStart = 0;  // 当前片段的起始位置
        int partitionEnd = 0;    // 当前片段的结束位置

        for (int currentIndex = 0; currentIndex < s.length(); currentIndex++) {
            int charLastPos = lastPosition[s.charAt(currentIndex) - 'a'];

            // 更新当前片段的结束位置
            // 必须包含当前字符的所有出现
            partitionEnd = Math.max(partitionEnd, charLastPos);

            // 如果当前位置就是片段的结束位置，说明可以在这里切分
            if (currentIndex == partitionEnd) {
                // 计算片段长度
                int length = partitionEnd - partitionStart + 1;
                partitions.add(length);

                // 更新下一个片段的起始位置
                partitionStart = currentIndex + 1;
            }
        }

        return partitions;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，需要两次遍历字符串
- **空间复杂度：** O(1)，最多存储 26 个字母的位置

## 关键点总结

1. **贪心策略：** 尽可能早地切分片段
2. **最后位置：** 记录每个字符的最后出现位置是关键
3. **动态更新：** 片段结束位置需要动态更新
4. **切分时机：** 当到达当前片段结束位置时切分
5. **片段独立：** 每个片段内的字符不会在其他片段出现

## 易错点

1. **结束位置更新：** 要取所有已遍历字符的最后位置的最大值
2. **切分条件：** 是 `i == end`，不是 `i >= end`
3. **起始位置更新：** 新片段从 `i + 1` 开始
4. **长度计算：** 长度是 `end - start + 1`
5. **边界情况：** 所有字符都不同或所有字符都相同的情况
