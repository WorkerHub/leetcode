## 题目描述

给你一个整数数组 `nums`，返回**元素和为奇数**的非空子序列的数量，对 `10^9 + 7` 取模。

## 解题思路

设奇数个数为 `odd`，偶数个数为 `even`。和为奇数的子序列必须包含奇数个奇数元素。由二项式定理推导：答案 = `2^even * 2^(odd-1)` = `2^(n-1)`（当 odd > 0），否则为 0。

## Java 代码实现

```java
class Solution {
    public int subsequenceCount(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        // 统计奇数个数
        int odd = 0;
        for (int x : nums) {
            if (x % 2 == 1) odd++;
        }
        // 全是偶数则无法得到奇数和
        if (odd == 0) return 0;
        // 答案 = 2^(n-1)
        long result = 1;
        for (int i = 0; i < n - 1; i++) {
            result = result * 2 % MOD;
        }
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 和为奇数 = 子序列中奇数个数为奇数
2. 数学推导：答案 = `2^(n-1)`（当有奇数元素时）
3. 当数组中没有奇数时，所有子序列和为偶数，答案为 0
