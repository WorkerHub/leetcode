## 题目描述

给你两个数组 `nums1` 和 `nums2`。

请你返回 `nums1` 和 `nums2` 中两个长度相同的**非空子序列**的最大**点积**。

数组的**子序列**是从数组中删除某些元素（可能一个都不删除）后剩余元素构成的序列。如果顺序不变，还可以不删除任何元素。

**点积**的定义是：给定两个子序列 `a` 和 `b`，对应位置的元素相乘后求和：`sum(a[i] * b[i])`。

**示例 1：**
```
输入：nums1 = [2,1,-2,5], nums2 = [3,0,-6]
输出：18
```

**示例 2：**
```
输入：nums1 = [3,-2], nums2 = [2,-6,7]
输出：21
解释：取 nums1[0]=3 和 nums2[2]=7，点积 = 21。
```

**示例 3：**
```
输入：nums1 = [-1,-1], nums2 = [1,1]
输出：-1
解释：子序列必须非空，最小损失选 nums1[0]*nums2[0] = -1。
```

**提示：**
- `1 <= nums1.length, nums2.length <= 500`
- `-1000 <= nums1[i], nums2[i] <= 1000`

## 解题思路

**动态规划**

定义 `dp[i][j]` 为 `nums1` 前 `i` 个元素和 `nums2` 前 `j` 个元素中，非空子序列的最大点积。

**状态转移：**

对于每个 `(i, j)` 位置：
1. **配对**：将 `nums1[i-1]` 与 `nums2[j-1]` 配对（必须选，至少选这一对）
   - 仅选这一对：`nums1[i-1] * nums2[j-1]`
   - 在前面已有配对基础上追加：`dp[i-1][j-1] + nums1[i-1] * nums2[j-1]`（前提是 dp[i-1][j-1] > 0，否则还不如不加）
   - 合并：`max(nums1[i-1] * nums2[j-1], dp[i-1][j-1] + nums1[i-1] * nums2[j-1])`
2. **跳过 nums1[i-1]**：`dp[i-1][j]`
3. **跳过 nums2[j-1]**：`dp[i][j-1]`

综合：
```
dp[i][j] = max(
    nums1[i-1] * nums2[j-1],
    dp[i-1][j-1] + nums1[i-1] * nums2[j-1],
    dp[i-1][j],
    dp[i][j-1]
)
```

**初始化：** `dp[i][j]` = `Integer.MIN_VALUE / 2`（表示不可达/非法）

因为子序列必须非空，初始状态都是非法的，通过转移方程填入合法值。

## Java 代码实现

### 方法一：二维 DP（推荐）

```java
class Solution {
    public int maxDotProduct(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        final int NEG_INF = Integer.MIN_VALUE / 2;

        // dp[i][j] 表示 nums1[:i] 和 nums2[:j] 的非空子序列最大点积
        // 初始化为负无穷（表示无合法子序列）
        int[][] dp = new int[m + 1][n + 1];
        for (int[] row : dp) java.util.Arrays.fill(row, NEG_INF);

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 当前配对的乘积
                int product = nums1[i - 1] * nums2[j - 1];

                // 选择1：仅使用当前配对（新的起点）
                dp[i][j] = product;

                // 选择2：在之前的最优基础上追加当前配对
                if (dp[i - 1][j - 1] != NEG_INF) {
                    dp[i][j] = Math.max(dp[i][j], dp[i - 1][j - 1] + product);
                }

                // 选择3：跳过 nums1[i-1]（不配对）
                if (dp[i - 1][j] != NEG_INF) {
                    dp[i][j] = Math.max(dp[i][j], dp[i - 1][j]);
                }

                // 选择4：跳过 nums2[j-1]（不配对）
                if (dp[i][j - 1] != NEG_INF) {
                    dp[i][j] = Math.max(dp[i][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

### 方法二：简化版 DP（统一处理负无穷）

```java
class Solution {
    public int maxDotProduct(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        final int NEG_INF = Integer.MIN_VALUE / 2;

        int[][] dp = new int[m + 1][n + 1];
        for (int[] row : dp) java.util.Arrays.fill(row, NEG_INF);

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                int product = nums1[i - 1] * nums2[j - 1];
                // max(dp[i-1][j-1], 0)：如果之前的最大点积为负，不如从头开始
                int prev = dp[i - 1][j - 1] != NEG_INF ? Math.max(dp[i - 1][j - 1], 0) : 0;
                dp[i][j] = prev + product;  // 追加当前配对

                if (dp[i - 1][j] != NEG_INF) dp[i][j] = Math.max(dp[i][j], dp[i - 1][j]);  // 跳过 i
                if (dp[i][j - 1] != NEG_INF) dp[i][j] = Math.max(dp[i][j], dp[i][j - 1]);  // 跳过 j
            }
        }

        return dp[m][n];
    }
}
```

### 方法三：空间优化版（滚动数组）

```java
class Solution {
    public int maxDotProduct(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        final int NEG_INF = Integer.MIN_VALUE / 2;

        // 只保留两行，节省空间
        int[] prev = new int[n + 1];
        java.util.Arrays.fill(prev, NEG_INF);

        for (int i = 1; i <= m; i++) {
            int[] curr = new int[n + 1];
            java.util.Arrays.fill(curr, NEG_INF);
            for (int j = 1; j <= n; j++) {
                int product = nums1[i - 1] * nums2[j - 1];

                // 取 prev[j-1] 和 0 的最大值（负数不如不选）
                int bestPrev = prev[j - 1] != NEG_INF ? Math.max(prev[j - 1], 0) : 0;
                curr[j] = bestPrev + product;

                if (prev[j] != NEG_INF) curr[j] = Math.max(curr[j], prev[j]);      // 跳过 nums1[i-1]
                if (curr[j - 1] != NEG_INF) curr[j] = Math.max(curr[j], curr[j - 1]);  // 跳过 nums2[j-1]
            }
            prev = curr;
        }

        return prev[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m × n)，两层循环
- 空间复杂度：O(m × n)（方法一）或 O(n)（方法三）

## 关键点总结

1. DP 定义：`dp[i][j]` 是 nums1 前 i 个和 nums2 前 j 个的非空子序列最大点积
2. 转移来源：配对当前元素 / 跳过 nums1 当前元素 / 跳过 nums2 当前元素
3. 配对时：`max(0, dp[i-1][j-1]) + product` 等价于"如果之前的结果有利则累加，否则从头开始"
4. 初始化为 `Integer.MIN_VALUE / 2` 表示没有合法子序列（除以 2 是为了防止加法溢出）

## 易错点

- 子序列必须**非空**，所以初始值不能是 0（用 `NEG_INF` 表示无效）
- 当 `dp[i-1][j-1]` 为负时，强行叠加会更差，用 `max(dp[i-1][j-1], 0)` 处理
- Java 中用 `Integer.MIN_VALUE / 2` 而不是 `Integer.MIN_VALUE`，避免加法时整数溢出
- 与最长公共子序列(LCS)的 DP 结构类似，可以对比学习
