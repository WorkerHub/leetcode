## 题目描述

给定一个 24 小时制的时间列表 `"HH:MM"`，找出任意两个时间点之间的最小时间差（分钟）。

**示例：**
```
输入: timePoints = ["23:59","00:00"]
输出: 1
```

## 解题思路

转换为分钟数，排序后比较相邻差值，注意环形处理（首尾差值）。

## Java 代码实现

```java
class Solution {
    public int findMinDifference(List<String> timePoints) {
        // 鸽笼原理
        if (timePoints.size() > 1440) return 0;

        int[] mins = new int[timePoints.size()];
        for (int i = 0; i < timePoints.size(); i++) {
            String t = timePoints.get(i);
            mins[i] = Integer.parseInt(t.substring(0, 2)) * 60
                    + Integer.parseInt(t.substring(3));
        }

        Arrays.sort(mins);

        int minDiff = mins[0] + 1440 - mins[mins.length - 1]; // 环形差值
        for (int i = 1; i < mins.length; i++) {
            minDiff = Math.min(minDiff, mins[i] - mins[i - 1]);
        }
        return minDiff;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **鸽笼原理**：超过 1440 个时间点必有重复
2. **环形处理**：首尾差值 = `mins[0] + 1440 - mins[last]`
3. **排序后相邻比较**：最小差一定在相邻元素间
