## 题目描述

给定整数数组 `nums` 和整数 `k`，可以将任意元素替换为其与 `k` 的取模结果，求操作后数组的最小可能元素值。

## Java 代码实现

```java
class Solution {
    public int minElement(int[] nums, int k) {
        int ans = Integer.MAX_VALUE;
        for (int x : nums) {
            ans = Math.min(ans, x % k);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历数组
- 空间复杂度：O(1)

## 关键点总结

1. 取模运算 `x % k` 结果在 `[0, k-1]`，当 `x >= k` 时替换总是有益的
2. 当 `x < k` 时 `x % k = x`，替换前后等价
3. 全局最小值即为所有取模值的最小值
