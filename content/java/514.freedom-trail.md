## 题目描述

电子游戏"辐射4"中，任务 **"通向自由"** 要求玩家到达名为 **"Freedom Trail Ring"** 的金属表盘，并使用表盘拼写特定关键词才能开门。

给定一个字符串 `ring`，表示刻在外环上的编码；给定另一个字符串 `key`，表示需要拼写的关键词。您需要算出能够拼写关键词中所有字符的**最少**步数。

最初，`ring` 的第一个字符与 12:00 方向对齐。您需要顺时针或逆时针旋转 `ring` 以使 `key` 的一个字符在 12:00 方向对齐，然后按下中心按钮，以此逐个拼写完 `key` 中的所有字符。

旋转 `ring` 拼出 `key` 字符 `key[i]` 的阶段中：
1. 您可以将 `ring` 顺时针或逆时针旋转一个位置，计为1步。旋转的最终目的是将字符串 `ring` 的一个字符与 12:00 方向对齐，并且这个字符必须等于字符 `key[i]`。
2. 如果字符 `key[i]` 已经对齐到12:00方向，您需要按下中心按钮进行拼写，这也将算作1步。按完之后，您可以开始拼写 `key` 的下一个字符（下一阶段）, 直至完成所有拼写。

**示例 1：**
```
输入：ring = "godding", key = "gd"
输出：4
解释：
对于 key 的第一个字符 'g'，已经在正确位置, 我们只需要1步来拼写这个字符。 
对于 key 的第二个字符 'd'，我们需要逆时针旋转 ring "godding" 2步使它变成 "ddinggo"。
当然, 我们还需要1步进行拼写。
因此最终的输出是 4。
```

**示例 2：**
```
输入：ring = "godding", key = "godding"
输出：13
```

**提示：**
- `1 <= ring.length, key.length <= 100`
- `ring` 和 `key` 只包含小写英文字母
- 保证字符串 `key` 一定可以由字符串 `ring` 旋转拼出

## 解题思路

这是一道复杂的动态规划题目，需要考虑：
1. 每个字符在 ring 中可能有多个位置
2. 旋转可以顺时针或逆时针
3. 需要找最少步数

### 核心思想：
**状态定义**：`dp[i][j]` = 拼写完 key 的前 i 个字符，且 ring 当前位置在 j 时的最少步数

**状态转移**：
- 对于 key[i]，找到 ring 中所有等于 key[i] 的位置 pos
- 从上一个状态 dp[i-1][prev_pos] 转移到 dp[i][pos]
- 距离 = min(顺时针距离, 逆时针距离) + 1（按按钮）

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
import java.util.*;

class Solution {
    public int findRotateSteps(String ring, String key) {
        // 动态规划
        // 时间复杂度：O(m * n^2)，m = key.length(), n = ring.length()
        // 空间复杂度：O(m * n)
        int n = ring.length(), m = key.length();

        // 记录每个字符在 ring 中的所有位置
        Map<Character, List<Integer>> charPositions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            char ch = ring.charAt(i);
            charPositions.computeIfAbsent(ch, k -> new ArrayList<>()).add(i);
        }

        // dp[i][j] = 拼写完 key[:i] 且 ring 当前在位置 j 的最小步数
        int[][] dp = new int[m + 1][n];
        for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
        dp[0][0] = 0;  // 初始在位置 0

        for (int i = 0; i < m; i++) {
            char ch = key.charAt(i);

            // 遍历当前字符在 ring 中的所有位置
            for (int curPos : charPositions.get(ch)) {
                // 遍历上一个可能的位置
                for (int prevPos = 0; prevPos < n; prevPos++) {
                    if (dp[i][prevPos] == Integer.MAX_VALUE / 2) continue;

                    // 计算从 prevPos 到 curPos 的距离
                    int clockwise = Math.abs(curPos - prevPos);  // 顺时针距离
                    int counterClockwise = n - clockwise;         // 逆时针距离
                    int dist = Math.min(clockwise, counterClockwise);  // 取最小距离

                    // 更新 dp，+1 是按按钮
                    dp[i + 1][curPos] = Math.min(dp[i + 1][curPos], dp[i][prevPos] + dist + 1);
                }
            }
        }

        // 返回拼写完所有字符的最小步数
        int result = Integer.MAX_VALUE;
        for (int val : dp[m]) {
            result = Math.min(result, val);
        }
        return result;
    }
}
```

### 方法二：记忆化DFS

```java
class Solution {
    private int n;
    private int[][] memo;
    private Map<Character, List<Integer>> charPositions;

    public int findRotateSteps(String ring, String key) {
        // 记忆化DFS
        // 时间复杂度：O(m * n^2)
        // 空间复杂度：O(m * n)
        n = ring.length();
        int m = key.length();
        memo = new int[m][n];
        for (int[] row : memo) Arrays.fill(row, -1);

        charPositions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            char ch = ring.charAt(i);
            charPositions.computeIfAbsent(ch, k -> new ArrayList<>()).add(i);
        }

        return dfs(ring, key, 0, 0);
    }

    private int dfs(String ring, String key, int ringPos, int keyIdx) {
        // 从 ringPos 开始，拼写 key[keyIdx:] 的最小步数
        if (keyIdx == key.length()) return 0;
        if (memo[keyIdx][ringPos] != -1) return memo[keyIdx][ringPos];

        char ch = key.charAt(keyIdx);
        int minSteps = Integer.MAX_VALUE;

        for (int nextPos : charPositions.get(ch)) {
            // 计算距离
            int clockwise = Math.abs(nextPos - ringPos);
            int counterClockwise = n - clockwise;
            int dist = Math.min(clockwise, counterClockwise);

            // 递归计算后续步数
            int steps = dist + 1 + dfs(ring, key, nextPos, keyIdx + 1);
            minSteps = Math.min(minSteps, steps);
        }

        memo[keyIdx][ringPos] = minSteps;
        return minSteps;
    }
}
```

### 方法三：优化的DP（空间优化）

```java
class Solution {
    public int findRotateSteps(String ring, String key) {
        // 滚动数组优化空间
        // 时间复杂度：O(m * n^2)
        // 空间复杂度：O(n)
        int n = ring.length(), m = key.length();

        Map<Character, List<Integer>> charPositions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            char ch = ring.charAt(i);
            charPositions.computeIfAbsent(ch, k -> new ArrayList<>()).add(i);
        }

        // 只保留两行
        int[] prev = new int[n];
        Arrays.fill(prev, Integer.MAX_VALUE / 2);
        prev[0] = 0;

        for (int i = 0; i < m; i++) {
            char ch = key.charAt(i);
            int[] curr = new int[n];
            Arrays.fill(curr, Integer.MAX_VALUE / 2);

            for (int curPos : charPositions.get(ch)) {
                for (int prevPos = 0; prevPos < n; prevPos++) {
                    if (prev[prevPos] == Integer.MAX_VALUE / 2) continue;

                    int dist = Math.min(Math.abs(curPos - prevPos), n - Math.abs(curPos - prevPos));
                    curr[curPos] = Math.min(curr[curPos], prev[prevPos] + dist + 1);
                }
            }

            prev = curr;
        }

        int result = Integer.MAX_VALUE;
        for (int val : prev) result = Math.min(result, val);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n²)
  - m 是 key 的长度
  - n 是 ring 的长度
  - 对每个 key 字符，遍历所有 ring 位置组合
- **空间复杂度**：
  - DP 数组：O(m * n)
  - 优化后：O(n)

## 关键点总结

1. **距离计算**：min(顺时针, 逆时针) = min(|a-b|, n - |a-b|)
2. **字符位置**：预处理所有字符在 ring 中的位置
3. **状态转移**：从上一个位置到当前位置的最优路径
4. **边界条件**：初始在位置 0，步数为 0
5. **最终答案**：拼写完所有字符后，任意位置的最小值

## 易错点

1. **忘记 +1**：每次按按钮都要 +1 步
2. **距离计算错误**：要考虑环形，取两个方向的最小值
3. **初始化**：dp[0][0] = 0，其余为大整数（注意不要用 Integer.MAX_VALUE 防止溢出）
4. **字符不存在**：题目保证能拼出，无需处理
5. **溢出问题**：Java 中使用 Integer.MAX_VALUE / 2 避免加法溢出

```
   - 选择位置 2：1 + 2 + 1 = 4

总步数：4
```
