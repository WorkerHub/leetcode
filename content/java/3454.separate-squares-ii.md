## 题目描述

与 3453 相同，但正方形数量更大，且要求精确计算（结果是有理数，精确到小数点后 5 位）。给你一个二维整数数组 `squares`，找一条水平线使上下面积相等，返回最小高度 h。

## 解题思路

扫描线算法：`below_area(h)` 是分段线性函数，在正方形的上下边界处斜率改变。排序所有关键高度，在每段区间内用线性插值精确求解目标高度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public double separateSquares(int[][] squares) {
        // 计算总面积
        long totalArea = 0;
        for (int[] sq : squares) {
            totalArea += (long) sq[2] * sq[2];
        }
        double half = totalArea / 2.0;

        // 收集所有 y 关键点事件：(高度, 边长, +1/-1)
        List<long[]> events = new ArrayList<>();
        for (int[] sq : squares) {
            int y = sq[1], l = sq[2];
            events.add(new long[]{y, l, 1});      // 进入
            events.add(new long[]{(long) y + l, l, -1}); // 离开
        }
        events.sort(Comparator.comparingLong(e -> e[0]));

        // 扫描线从下到上
        long currentSumL = 0; // 当前穿过的正方形宽度之和
        double accumulated = 0.0; // 已累积的下方面积
        double prevH = events.get(0)[0];

        int ei = 0;
        int n = events.size();

        while (ei < n) {
            double curH = events.get(ei)[0];

            // 从 prevH 到 curH，面积增量 = currentSumL * (curH - prevH)
            double delta = currentSumL * (curH - prevH);

            if (accumulated + delta >= half) {
                // 目标在 [prevH, curH] 内，线性插值求精确解
                if (currentSumL == 0) return prevH;
                return prevH + (half - accumulated) / currentSumL;
            }

            accumulated += delta;
            prevH = curH;

            // 处理所有在 curH 处的事件
            while (ei < n && events.get(ei)[0] == curH) {
                long[] ev = events.get(ei);
                currentSumL += ev[1] * ev[2]; // l * (+1 或 -1)
                ei++;
            }
        }

        return prevH;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，事件排序
- 空间复杂度：O(n)

## 关键点总结

1. `below_area(h)` 是分段线性函数，在关键高度处斜率改变
2. 扫描线算法维护当前穿过的正方形宽度之和（斜率）
3. 在目标区间内使用线性插值求精确解
