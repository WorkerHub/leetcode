## 题目描述

给你一个所有数字位数相同的正整数数组 `nums`，两数字差定义为对应位上不同的位数，返回所有数对数字差之和。

## 解题思路

按位分解：对每一位，统计各数字（0-9）出现次数，该位的贡献 = 总对数 - 同一数字构成的对数之和（即 `n*(n-1)/2 - sum(c*(c-1)/2)`）。

## Java 代码实现

```java
class Solution {
    public long sumDigitDifferences(int[] nums) {
        int n = nums.length;
        long totalPairs = (long) n * (n - 1) / 2;
        // 确定位数
        int digits = String.valueOf(nums[0]).length();
        long ans = 0;

        for (int k = 0; k < digits; k++) {
            int[] cnt = new int[10]; // 统计第 k 位（从右）各数字出现次数
            int div = (int) Math.pow(10, k);
            for (int x : nums) {
                cnt[(x / div) % 10]++;
            }
            // 该位贡献 = 总对数 - 相同数字对数
            long same = 0;
            for (int c : cnt) {
                same += (long) c * (c - 1) / 2;
            }
            ans += totalPairs - same;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × d)，d 为位数（最多 9）
- **空间复杂度**：O(1)（每位统计数组大小固定为 10）

## 关键点总结

1. 按位分解，各位独立贡献
2. 第 k 位贡献 = 总对数 - 该位数字相同的对数
3. 结果可能超过 int 范围，使用 `long`
