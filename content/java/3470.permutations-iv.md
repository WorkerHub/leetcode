## 题目描述

给你整数 `n` 和 `k`，返回 `[1, n]` 中所有相邻元素差的绝对值不为 1 的排列里，字典序第 `k` 个排列；若不足 `k` 个则返回空数组。

## 解题思路

逐位确定：对第 i 个位置，按字典序枚举候选数字，用位掩码 DP 统计"给定上一个数字和剩余可用集合"下的有效排列数。若计数 >= k 则选当前数字，否则 k 减去该计数，继续枚举。n <= 20 时使用位掩码记忆化，超过时有效排列数远超 10^15，前几步即可确定。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private Map<Long, Long> memo = new HashMap<>();

    // 统计以 last 开头、available 中可用数字的有效排列数（上限 cap 防止溢出）
    private long count(int last, int available, int n, long cap) {
        if (available == 0) return 1;
        long key = (long) last * (1 << n) + available;
        if (memo.containsKey(key)) return memo.get(key);

        long total = 0;
        for (int v = 1; v <= n && total < cap; v++) {
            if ((available & (1 << (v - 1))) == 0) continue;
            if (last != 0 && Math.abs(v - last) == 1) continue;
            total += count(v, available ^ (1 << (v - 1)), n, cap);
            if (total > cap) { total = cap + 1; break; }
        }
        memo.put(key, Math.min(total, cap + 1));
        return memo.get(key);
    }

    public int[] permute(int n, long k) {
        if (n > 20) return new int[0];

        int fullMask = (1 << n) - 1;
        long total = count(0, fullMask, n, k);
        if (total < k) return new int[0];

        int[] result = new int[n];
        int available = fullMask;
        int last = 0;

        for (int pos = 0; pos < n; pos++) {
            boolean found = false;
            for (int v = 1; v <= n; v++) {
                if ((available & (1 << (v - 1))) == 0) continue;
                if (last != 0 && Math.abs(v - last) == 1) continue;

                int newAvail = available ^ (1 << (v - 1));
                long cnt = count(v, newAvail, n, k);

                if (cnt >= k) {
                    result[pos] = v;
                    available = newAvail;
                    last = v;
                    found = true;
                    break;
                } else {
                    k -= cnt;
                }
            }
            if (!found) return new int[0];
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 2^n)（记忆化后）
- 空间复杂度：O(n * 2^n)

## 关键点总结

1. 逐位确定，每次用 DP 统计候选数字后的有效排列数
2. 位掩码表示可用数字集合，记忆化避免重复计算
3. 计数时设上限 cap 防止 long 溢出
