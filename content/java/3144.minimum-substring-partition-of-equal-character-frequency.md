## 题目描述

将字符串划分为最少数量的均衡子串（每个子串中所有出现字符频率相同）。

## 解题思路

DP：dp[i]表示s[0..i-1]的最少划分数。枚举划分点j，若s[j..i-1]均衡则dp[i]=min(dp[j]+1)。判断均衡：所有出现字符频率相同。

## Java 代码实现

```java
class Solution {
    public int minimumSubstringsInPartition(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            int[] freq = new int[26];
            for (int j = i - 1; j >= 0; j--) {
                freq[s.charAt(j) - 'a']++;
                if (isBalanced(freq) && dp[j] != Integer.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n];
    }

    private boolean isBalanced(int[] freq) {
        int target = 0;
        for (int f : freq) {
            if (f > 0) {
                if (target == 0) target = f;
                else if (f != target) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2 * 26)
- **空间复杂度**：O(N)

## 关键点总结

1. **均衡子串**：所有出现字符频率相同
2. **DP枚举划分点**：逆序扫描维护频率数组
3. **判断均衡**：频率集合大小为1
