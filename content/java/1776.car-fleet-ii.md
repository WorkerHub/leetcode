## 题目描述

在单行道上，n 辆车同向行驶，`cars[i] = [position, speed]`。车追上前方车队后合并。对每辆车，返回它追上紧前方车队所需的时间（追不上则返回 -1）。

## 解题思路

从右往左用单调栈：维护尚未被追上的有效车队。对每辆车 i，检查能否追上栈顶车 j：若 speed[i] <= speed[j] 则追不上；若追上时间 t >= ans[j]（栈顶在 t 之前已被合并），则 j 无效，弹出继续检查。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public double[] getCollisionTimes(int[][] cars) {
        int n = cars.length;
        double[] ans = new double[n];
        java.util.Arrays.fill(ans, -1.0);
        Deque<Integer> stack = new ArrayDeque<>(); // 存下标

        for (int i = n - 1; i >= 0; i--) {
            int pos = cars[i][0], speed = cars[i][1];

            while (!stack.isEmpty()) {
                int j = stack.peek();
                int pj = cars[j][0], sj = cars[j][1];

                if (speed <= sj) {
                    // 追不上，弹出（对当前车无用）
                    stack.pop();
                    continue;
                }

                // 追上时间
                double t = (double)(pj - pos) / (speed - sj);

                // 栈顶在 t 时刻之前已被合并，弹出
                if (ans[j] > 0 && t >= ans[j]) {
                    stack.pop();
                    continue;
                }

                ans[i] = t;
                break;
            }

            stack.push(i);
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每辆车最多入栈出栈一次
- **空间复杂度**：O(n)

## 关键点总结

1. 从右往左处理，单调栈维护有效追赶目标
2. 速度不大于前车则追不上；若前车先被合并则也无效，均需弹出
