## 题目描述

计算所有数对(i,j)的floor(nums[i]/nums[j])之和，对10^9+7取模。

## 解题思路

前缀和+枚举除数：对每个除数d，枚举商q，被除数在[q*d, (q+1)*d-1]范围内的元素个数用前缀和O(1)查询。总时间为调和级数O(max_val * log(max_val))。

## Java 代码实现

```java
class Solution {
    public int sumOfFlooredPairs(int[] nums) {
        int MOD = 1_000_000_007;
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);
        
        // 频率数组和前缀和
        int[] freq = new int[maxVal + 2];
        for (int x : nums) freq[x]++;
        
        long[] prefix = new long[maxVal + 2];
        for (int i = 1; i <= maxVal; i++) {
            prefix[i] = prefix[i - 1] + freq[i];
        }
        
        long result = 0;
        for (int d = 1; d <= maxVal; d++) {
            if (freq[d] == 0) continue;
            // 枚举商q
            for (int q = 1; (long) q * d <= maxVal; q++) {
                int lo = q * d;
                int hi = Math.min((q + 1) * d - 1, maxVal);
                long count = prefix[hi] - prefix[lo - 1];
                result = (result + (long) freq[d] * q % MOD * count) % MOD;
            }
        }
        return (int) result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max_val × log(max_val))，调和级数
- **空间复杂度**：O(max_val)

## 关键点总结

1. **枚举除数+商**：不枚举数对
2. **前缀和**：O(1)查询区间内元素数量
3. **调和级数**：总枚举次数为∑(max_val/d) ≈ max_val × ln(max_val)
