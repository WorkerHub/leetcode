## 题目描述

给你整数数组 `nums` 和整数 `k`，每次取当前最大元素 `m` 删除并插入 `m+1`，执行 `k` 次后返回数组总和。

## Java 代码实现

```java
class Solution {
    public int maximizeSum(int[] nums, int k) {
        int m = 0;
        int total = 0;
        for (int x : nums) {
            total += x;
            m = Math.max(m, x);
        }
        // k 次操作取走 m, m+1, ..., m+k-1，删去原来的 m
        // 最终总和 = total - m + sum(m..m+k-1)
        return total - m + k * m + k * (k - 1) / 2;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. k 次操作取走 m, m+1, ..., m+k-1（每次取最大值递增）
2. 最终总和 = 原总和 - m + sum(m..m+k-1) = 原总和 + k*(k-1)/2 + (k-1)*m
