## 题目描述

给你一个非空数组，返回此数组中第三大的数。如果不存在，则返回数组中最大的数。

**示例 1：**
```
输入：[3, 2, 1]
输出：1
解释：第三大的数是 1
```

**示例 2：**
```
输入：[1, 2]
输出：2
解释：第三大的数不存在，所以返回最大的数 2
```

**示例 3：**
```
输入：[2, 2, 3, 1]
输出：1
解释：注意，要求返回第三大的数，是指在所有不同数字中排第三大的数。
此例中存在两个值为 2 的数，它们都排第二。在所有不同数字中排第三大的数为 1
```

## Java 代码实现

### 方法一：维护三个变量（推荐）

```java
class Solution {
    public int thirdMax(int[] nums) {
        // 维护最大、第二大、第三大三个值（用 Long 包装类，null 表示未赋值）
        Long first = null, second = null, third = null;

        for (int num : nums) {
            long n = (long) num;
            // 跳过已存在的值（去重）
            if ((first != null && n == first) ||
                (second != null && n == second) ||
                (third != null && n == third)) {
                continue;
            }

            if (first == null || n > first) {
                // 更新最大值，其余依次后移
                third = second;
                second = first;
                first = n;
            } else if (second == null || n > second) {
                // 更新第二大值
                third = second;
                second = n;
            } else if (third == null || n > third) {
                // 更新第三大值
                third = n;
            }
        }

        // 不存在第三大值时返回最大值
        return (int) (long) (third != null ? third : first);
    }
}
```

### 方法二：集合 + 排序

```java
import java.util.*;

class Solution {
    public int thirdMax(int[] nums) {
        // 去重后排序
        TreeSet<Integer> set = new TreeSet<>();
        for (int num : nums) {
            set.add(num);
        }

        if (set.size() >= 3) {
            // 移除最大值两次，获取第三大值
            set.pollLast();
            set.pollLast();
            return set.last();
        }
        // 不足 3 个不同元素，返回最大值
        return set.last();
    }
}
```

### 方法三：使用 PriorityQueue（最小堆）

```java
import java.util.*;

class Solution {
    public int thirdMax(int[] nums) {
        // 使用最小堆维护前三大的数
        Set<Integer> unique = new HashSet<>();
        for (int num : nums) unique.add(num);

        if (unique.size() < 3) {
            return Collections.max(unique);
        }

        // 维护大小为 3 的最小堆
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int num : unique) {
            heap.offer(num);
            if (heap.size() > 3) {
                heap.poll();  // 弹出最小值，保留前三大
            }
        }

        return heap.peek();  // 堆顶是第三大的数
    }
}
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

### 方法二：
- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 需要去重
2. 不足 3 个不同数字时返回最大值
3. 使用三个变量最优

## 易错点

1. 忘记去重
2. 忘记处理不足 3 个数字的情况
3. 用 `Long` 包装类（可以为 null）避免与 `Integer.MIN_VALUE` 混淆
