## 题目描述

给你一个整数 n ，返回大于或等于 n 的最小回文质数。

整数是 回文 当它正着读和反着读都一样。

**示例 1：**
```
输入：n = 6
输出：7
```

**示例 2：**
```
输入：n = 8
输出：11
```

**示例 3：**
```
输入：n = 13
输出：101
```

**提示：**
- 1 <= n <= 10^8

## 解题思路

**关键观察：**
1. 偶数位的回文数（除11外）都能被11整除，不是质数
2. 所以主要检查奇数位的回文数

**算法流程：**
1. 从 n 开始遍历
2. 检查是否是回文
3. 检查是否是质数
4. 跳过偶数位回文数（优化）

## Java 代码实现

### 方法一：暴力+优化（推荐）

```java
class Solution {
    public int primePalindrome(int n) {
        // 特殊处理 8-11 范围（唯一的偶数位回文质数是 11）
        if (n >= 8 && n <= 11) return 11;

        // 从 n 开始枚举，跳过偶数
        if (n % 2 == 0) n++;

        while (true) {
            // 跳过偶数位数范围（除11外没有回文质数）
            if (n > 10000000 && n < 100000000) {
                n = 100000000; // 直接跳到 10^8
            }

            if (isPalindrome(n) && isPrime(n)) {
                return n;
            }
            n += 2; // 只检查奇数
        }
    }

    private boolean isPalindrome(int x) {
        String s = Integer.toString(x);
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }

    private boolean isPrime(int x) {
        if (x < 2) return false;
        if (x == 2) return true;
        if (x % 2 == 0) return false;
        for (int i = 3; (long) i * i <= x; i += 2) {
            if (x % i == 0) return false;
        }
        return true;
    }
}
```

**代码说明：**
- 只检查奇数（偶数除 2 外不是质数）
- 跳过偶数位数范围（无回文质数）
- 判断回文：双指针比较字符串
- 判断质数：枚举到 sqrt(x)

## 复杂度分析

- **时间复杂度**：取决于答案位置，实际运行很快。
- **空间复杂度**：O(log n)，字符串长度。

## 关键点总结

1. **偶数位优化**：跳过偶数位回文数范围（10^7 到 10^8 之间没有回文质数）
2. **质数判断**：优化到 √n，注意 `(long) i * i` 防溢出
3. **只检查奇数**：偶数（除2）不是质数
4. **特殊情况**：8-11 范围特殊处理

## 易错点

1. **整数溢出**：`i * i <= x` 中 i 较大时可能溢出，需要 `(long) i * i`

2. **偶数位回文**：错误地检查了偶数位范围导致超时

3. **特殊情况**：`n = 8` 时答案是 11，不能直接从 n 开始加
