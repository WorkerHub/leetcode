## 题目描述

设计 Excel 求和公式功能：支持 `set`、`get`、`sum` 操作，sum 公式设置后值会自动更新。

**示例：**
```
Excel excel = new Excel(3, "C");
excel.set(1, "A", 2);
excel.sum(3, "C", ["A1", "A1:B2"]);  // 返回 4
excel.set(2, "B", 2);
excel.get(3, "C");                   // 返回 6（自动更新）
```

## 解题思路

存储公式（依赖的单元格列表），get 时递归计算所有依赖值。

## Java 代码实现

```java
class Excel {
    private int[][] cells;
    private Map<String, List<String>> formulas; // 存储公式依赖
    private int height;

    public Excel(int height, char width) {
        this.height = height;
        int w = width - 'A' + 1;
        cells = new int[height + 1][w];
        formulas = new HashMap<>();
    }

    public void set(int row, char column, int val) {
        String key = "" + column + row;
        // 清除公式
        formulas.remove(key);
        cells[row][column - 'A'] = val;
    }

    public int get(int row, char column) {
        String key = "" + column + row;
        if (formulas.containsKey(key)) {
            // 递归计算公式值
            int sum = 0;
            for (String cell : formulas.get(key)) {
                sum += getValue(cell);
            }
            return sum;
        }
        return cells[row][column - 'A'];
    }

    public int sum(int row, char column, String[] numbers) {
        String key = "" + column + row;
        // 解析所有依赖单元格
        List<String> deps = new ArrayList<>();
        for (String num : numbers) {
            if (num.contains(":")) {
                // 范围：如 "A1:B2"
                String[] parts = num.split(":");
                char c1 = parts[0].charAt(0), c2 = parts[1].charAt(0);
                int r1 = Integer.parseInt(parts[0].substring(1));
                int r2 = Integer.parseInt(parts[1].substring(1));
                for (char c = c1; c <= c2; c++) {
                    for (int r = r1; r <= r2; r++) {
                        deps.add("" + c + r);
                    }
                }
            } else {
                deps.add(num);
            }
        }
        formulas.put(key, deps);
        return get(row, column);
    }

    private int getValue(String cell) {
        char col = cell.charAt(0);
        int row = Integer.parseInt(cell.substring(1));
        return get(row, col);
    }
}
```

## 复杂度分析

- **set**：O(1)
- **get**：O(d)，d 为依赖深度
- **sum**：O(n)，n 为涉及的单元格数
- **空间复杂度**：O(h × w)

## 关键点总结

1. **公式与值分离**：有公式时 get 动态计算
2. **范围解析**：正确解析 "A1:B2" 格式
3. **自动更新**：set 改变值后，依赖它的公式会在 get 时重新计算
