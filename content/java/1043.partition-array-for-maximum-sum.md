## 题目描述

将数组分隔为长度最多为 k 的子数组，每个子数组的值都变为该子数组最大值，返回最大元素总和。

**示例：**
```
输入：arr = [1,15,7,9,2,5,10], k = 3
输出：84
```

## 解题思路

动态规划：dp[i] 表示前 i 个元素的最大和。对每个位置尝试最后 1~k 个元素作为一个子数组，取最优。

## Java 代码实现

```java
class Solution {
    public int maxSumAfterPartitioning(int[] arr, int k) {
        int n = arr.length;
        int[] dp = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            int maxVal = 0;
            // 尝试最后 j 个元素作为一个子数组
            for (int j = 1; j <= Math.min(k, i); j++) {
                maxVal = Math.max(maxVal, arr[i - j]);
                dp[i] = Math.max(dp[i], dp[i - j] + j * maxVal);
            }
        }

        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n×k)
- **空间复杂度**：O(n)

## 关键点总结

1. **状态定义**：dp[i] = 前 i 个元素的最大和
2. **转移方程**：枚举最后子数组长度 j，dp[i] = max(dp[i-j] + j*max)
3. **最大值维护**：内循环中逐步更新，避免重复计算
