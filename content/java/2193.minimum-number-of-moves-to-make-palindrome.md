## 题目描述

每次交换相邻两字符，求将字符串变为回文串的最少操作次数。

## 解题思路

贪心：每次处理最左字符，在右侧找匹配并交换到最右位置；找不到则交换到中间。模拟交换过程统计步数。

## Java 代码实现

```java
class Solution {
    public int minMovesToMakePalindrome(String s) {
        char[] arr = s.toCharArray();
        int n = arr.length;
        int ans = 0;
        int left = 0, right = n - 1;
        
        while (left < right) {
            // 在右侧找和arr[left]相同的字符
            int r = right;
            while (r > left && arr[r] != arr[left]) {
                r--;
            }
            
            if (r == left) {
                // 奇数次字符，交换到下一位
                char tmp = arr[left];
                arr[left] = arr[left + 1];
                arr[left + 1] = tmp;
                ans++;
                // left不移动，继续处理
            } else {
                // 将arr[r]交换到right位置
                while (r < right) {
                    char tmp = arr[r];
                    arr[r] = arr[r + 1];
                    arr[r + 1] = tmp;
                    r++;
                    ans++;
                }
                left++;
                right--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心匹配**：最左字符在右侧找配对，移到最右
2. **奇数字符处理**：找不到匹配时向右交换一步，之后继续
3. **模拟交换**：实际修改数组统计步数
