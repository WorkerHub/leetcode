## 题目描述

任务数组 `tasks[i] = [actual_i, minimum_i]`，完成任务需消耗 `actual_i` 能量，开始前需至少 `minimum_i` 能量。返回完成所有任务所需的**最少初始能量**。

## 解题思路

**贪心排序：** 按 `minimum - actual`（余量）从大到小排序。余量大的任务先做。

排序后从最后一个任务反推：执行前需要的能量 = `max(minimum, 后续所需能量 + actual)`。

## Java 代码实现

```java
class Solution {
    public int minimumEffort(int[][] tasks) {
        // 按 minimum - actual（余量）从大到小排序
        Arrays.sort(tasks, (a, b) -> (a[0] - a[1]) - (b[0] - b[1]));

        // 从后往前反推最少初始能量
        int energy = 0;
        for (int i = tasks.length - 1; i >= 0; i--) {
            int actual = tasks[i][0], minimum = tasks[i][1];
            // 执行此任务前需要 max(minimum, energy + actual)
            energy = Math.max(minimum, energy + actual);
        }

        return energy;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 余量 = `minimum - actual`，余量大的任务先做
2. 从后往前反推：`energy = max(minimum, energy + actual)`
3. 反推时 `energy` 表示"执行此任务及后续所有任务需要的最低能量"
