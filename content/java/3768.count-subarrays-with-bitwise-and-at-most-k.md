## 题目描述

给定整数数组 `nums` 和整数 `k`，统计所有子数组中按位与（AND）的结果不超过 `k` 的子数组数量。

## 解题思路

利用按位 AND 的单调性：子数组越长，AND 值只会减小或不变。以每个右端点结尾的子数组 AND 值最多有 O(log max_val) 种。维护 AND 值到子数组数量的映射，每步更新后统计满足条件的数量。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countSubarrays(int[] nums, int k) {
        long result = 0;
        // curAnds: AND值 -> 以当前位置结尾的该AND值子数组数量
        Map<Integer, Integer> curAnds = new HashMap<>();

        for (int x : nums) {
            Map<Integer, Integer> newAnds = new HashMap<>();
            for (Map.Entry<Integer, Integer> entry : curAnds.entrySet()) {
                int newVal = entry.getKey() & x;
                newAnds.merge(newVal, entry.getValue(), Integer::sum);
            }
            // 加入以当前元素为单独子数组
            newAnds.merge(x, 1, Integer::sum);
            curAnds = newAnds;

            // 统计 AND <= k 的子数组数量
            for (Map.Entry<Integer, Integer> entry : curAnds.entrySet()) {
                if (entry.getKey() <= k) {
                    result += entry.getValue();
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log max_val)
- 空间复杂度：O(log max_val)

## 关键点总结

1. 以每个右端点结尾的子数组 AND 值最多有 O(log max_val) 种
2. 维护 AND 值及子数组数量的映射，每步更新
3. AND 操作具有单调性：子数组延长时 AND 值不增
