## 题目描述

将nums划分为m段，第i段的AND值等于andValues[i]，最小化每段末尾元素之和。

## 解题思路

记忆化搜索：dp(i,j,curAnd)表示从位置i开始完成第j段，当前AND为curAnd的最小代价。AND<target时剪枝。

## Java 代码实现

```java
class Solution {
    private int[] nums, andValues;
    private int n, m;
    private Map<Long, Integer> memo = new HashMap<>();
    private static final int INF = Integer.MAX_VALUE / 2;

    public int minimumValueSum(int[] nums, int[] andValues) {
        this.nums = nums;
        this.andValues = andValues;
        this.n = nums.length;
        this.m = andValues.length;
        int ans = dp(0, 0, (1 << 17) - 1);
        return ans >= INF ? -1 : ans;
    }

    private int dp(int i, int j, int curAnd) {
        if (j == m) return i == n ? 0 : INF;
        if (i == n) return INF;
        long key = ((long) i << 22) | ((long) j << 17) | curAnd;
        if (memo.containsKey(key)) return memo.get(key);

        curAnd &= nums[i];
        int target = andValues[j];
        if (curAnd < target) { memo.put(key, INF); return INF; }

        int res = dp(i + 1, j, curAnd); // 扩展当前段
        if (curAnd == target) {
            res = Math.min(res, nums[i] + dp(i + 1, j + 1, (1 << 17) - 1));
        }
        memo.put(key, res);
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N*M*logV)，AND值最多logV种不同值
- **空间复杂度**：O(N*M*logV)

## 关键点总结

1. **AND单调不增**：扩展区间AND只减不增
2. **AND<target时剪枝**：不可能再等于target
3. **记忆化搜索**：状态(i,j,curAnd)
