## 题目描述

给你字符串 `s` 和查询数组 `queries`，每次查询 `[l, r]` 返回 `s[l..r]` 中以相同字符开头和结尾的子字符串数目。

## 解题思路

预处理 26 个字符的前缀计数 `cnt[c][i]`。对查询 `[l, r]`，字符 c 的出现次数 `freq = cnt[c][r+1] - cnt[c][l]`，贡献为 `freq*(freq+1)/2`（选 1 或 2 个相同字符位置）。

## Java 代码实现

```java
class Solution {
    public int[] sameEndSubstringCount(String s, int[][] queries) {
        int n = s.length();
        // cnt[c][i] = 字符 c 在 s[0..i-1] 中的出现次数
        int[][] cnt = new int[26][n + 1];
        for (int i = 0; i < n; i++) {
            for (int c = 0; c < 26; c++) cnt[c][i + 1] = cnt[c][i];
            cnt[s.charAt(i) - 'a'][i + 1]++;
        }

        int[] result = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1];
            int total = 0;
            for (int c = 0; c < 26; c++) {
                int freq = cnt[c][r + 1] - cnt[c][l]; // 区间内字符 c 的频次
                total += freq * (freq + 1) / 2;
            }
            result[q] = total;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(26n + 26q)
- **空间复杂度**：O(26n)

## 关键点总结

1. 以字符 c 开头和结尾的子串数 = freq*(freq+1)/2（含单字符子串）
2. 前缀计数支持 O(1) 查询任意区间的字符频率
3. 26 个字符的贡献求和得到查询答案
