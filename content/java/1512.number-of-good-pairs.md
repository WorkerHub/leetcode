## 题目描述

给定整数数组，返回满足 nums[i]==nums[j] 且 i<j 的好数对数目。

**示例：**
```
输入：nums = [1,2,3,1,1,3]
输出：4
```

## 解题思路

HashMap 计数：遍历时每遇到一个数，之前出现的次数就是新增的好数对数。

## Java 代码实现

```java
class Solution {
    public int numIdenticalPairs(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        int pairs = 0;
        for (int num : nums) {
            int c = count.getOrDefault(num, 0);
            pairs += c;
            count.put(num, c + 1);
        }
        return pairs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **在线计数**：遍历时累加已出现次数
2. **组合数**：也可最后用 C(count, 2) 计算
3. **等价**：count × (count-1) / 2
