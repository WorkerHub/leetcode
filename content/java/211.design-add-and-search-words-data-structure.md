## 题目描述

请你设计一个数据结构，支持 添加新单词 和 查找字符串是否与任何先前添加的字符串匹配。

实现词典类 `WordDictionary`：

- `WordDictionary()` 初始化词典对象
- `void addWord(word)` 将 `word` 添加到数据结构中，之后可以对它进行匹配
- `bool search(word)` 如果数据结构中存在字符串与 `word` 匹配，则返回 `true`；否则，返回 `false`。`word` 中可能包含一些 `'.'`，每个 `.` 都可以表示任何一个字母。

**示例 1：**

```
输入：
["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
输出：
[null,null,null,null,false,true,true,true]

解释：
WordDictionary wordDictionary = new WordDictionary();
wordDictionary.addWord("bad");
wordDictionary.addWord("dad");
wordDictionary.addWord("mad");
wordDictionary.search("pad"); // 返回 False
wordDictionary.search("bad"); // 返回 True
wordDictionary.search(".ad"); // 返回 True
wordDictionary.search("b.."); // 返回 True
```

**提示：**

- `1 <= word.length <= 25`
- `addWord` 中的 `word` 由小写英文字母组成
- `search` 中的 `word` 由 `'.'` 或小写英文字母组成
- 最多调用 `10^4` 次 `addWord` 和 `search`

## 解题思路

这道题是经典的字典树（Trie）应用题，核心挑战在于如何处理通配符 `.`。

**核心思想：**

1. **字典树结构**：使用 Trie 存储所有添加的单词，每个节点包含：
   - 一个长度为 26 的数组（children）存储子节点
   - 一个布尔值（isEnd）标记是否是单词结尾

2. **添加单词**：按字符逐层插入 Trie

3. **搜索单词**：
   - 遇到普通字符：直接在对应子节点查找
   - 遇到通配符 `.`：需要尝试所有可能的子节点（DFS）

**算法流程：**

1. 添加单词时，从根节点开始，逐字符创建/访问节点
2. 搜索时，使用 DFS 递归：
   - 如果当前字符是 `.`，遍历所有子节点递归搜索
   - 如果是普通字符，只在对应子节点继续搜索
   - 到达字符串末尾时，检查当前节点是否为单词结尾

## Java 代码实现

### 方法一：字典树 + DFS（推荐）⭐

```java
class WordDictionary {
    // 字典树节点
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26]; // 存储26个小写字母的子节点
        boolean isEnd = false; // 标记是否为单词结尾
    }

    private TrieNode root;

    public WordDictionary() {
        root = new TrieNode();
    }

    public void addWord(String word) {
        // 添加单词到字典树
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            // 如果字符不存在，创建新节点
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            node = node.children[idx];
        }
        node.isEnd = true; // 标记单词结束
    }

    public boolean search(String word) {
        // 搜索单词，支持通配符 '.'
        return dfsSearch(word, 0, root);
    }

    private boolean dfsSearch(String word, int index, TrieNode node) {
        // 已经遍历完整个单词
        if (index == word.length()) {
            return node.isEnd;
        }

        char c = word.charAt(index);

        if (c == '.') {
            // 通配符：尝试所有子节点
            for (TrieNode child : node.children) {
                if (child != null && dfsSearch(word, index + 1, child)) {
                    return true;
                }
            }
            return false;
        } else {
            // 普通字符：直接查找对应子节点
            int idx = c - 'a';
            if (node.children[idx] == null) {
                return false;
            }
            return dfsSearch(word, index + 1, node.children[idx]);
        }
    }
}
```

### 方法二：字典树 + 迭代（BFS）

```java
class WordDictionary {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd = false;
    }

    private TrieNode root;

    public WordDictionary() {
        root = new TrieNode();
    }

    public void addWord(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        // 使用队列进行 BFS，处理通配符
        Queue<TrieNode> queue = new LinkedList<>();
        queue.offer(root);

        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            int size = queue.size();

            // 处理当前层的所有节点
            for (int k = 0; k < size; k++) {
                TrieNode node = queue.poll();
                if (c == '.') {
                    // 通配符：将所有子节点加入队列
                    for (TrieNode child : node.children) {
                        if (child != null) {
                            queue.offer(child);
                        }
                    }
                } else {
                    // 普通字符：只加入对应子节点
                    int idx = c - 'a';
                    if (node.children[idx] != null) {
                        queue.offer(node.children[idx]);
                    }
                }
            }

            if (queue.isEmpty()) return false;
        }

        // 检查是否有单词结尾节点
        for (TrieNode node : queue) {
            if (node.isEnd) return true;
        }
        return false;
    }
}
```

## 复杂度分析

**方法一（字典树 + DFS）：**

- **时间复杂度：**
  - `addWord`：O(L)，L 为单词长度
  - `search`：
    - 最坏情况（全是通配符）：O(26^L)
    - 平均情况：O(L)
- **空间复杂度：** O(N × L)，N 为单词数量

**方法二（迭代 BFS）：**

- **时间复杂度：** 与方法一相同
- **空间复杂度：** O(N × L + K)，K 为队列大小

## 关键点总结

1. **字典树是处理字符串前缀的高效数据结构**，适合词典类问题
2. **通配符处理需要 DFS**，遍历所有可能的分支
3. **Java 中用数组代替 HashMap**：`TrieNode[26]` 比 `HashMap<Character, TrieNode>` 更高效
4. **递归思路**：每次处理一个字符，剩余字符递归处理
5. **性能优化**：字典树避免了重复存储公共前缀

## 易错点

1. **忘记标记单词结尾**：只添加节点不标记 `isEnd`，导致前缀被当作完整单词
   ```java
   // 错误示例：循环结束后未设置 isEnd
   for (char c : word.toCharArray()) { ... }
   // node.isEnd = true; // 漏掉了这行
   ```

2. **通配符处理不完整**：只检查第一个匹配的子节点，应该检查所有
   ```java
   // 错误：遇到第一个匹配就返回，忽略后续分支
   for (TrieNode child : node.children) {
       if (child != null) return dfsSearch(word, index + 1, child);
   }
   // 正确：必须遍历所有可能
   for (TrieNode child : node.children) {
       if (child != null && dfsSearch(word, index + 1, child)) {
           return true;
       }
   }
   ```

3. **索引越界**：递归前未检查 `index` 是否超出范围

4. **字符索引计算错误**：
   ```java
   int idx = c - 'a'; // 正确：得到 0-25 的索引
   int idx = c;        // 错误：ASCII 值，不是相对索引
   ```
