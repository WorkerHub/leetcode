## 题目描述

n 个学生与 n 个导师一一匹配，兼容性得分为答案相同的问题数，返回所有匹配的最大兼容性得分之和（m ≤ 8）。

## 解题思路

状态压缩 DP：`dp[mask]` 表示已分配 mask 中为 1 的导师时的最大得分，第 `popcount(mask)-1` 个学生与最后加入的导师匹配。

## Java 代码实现

```java
class Solution {
    public int maxCompatibilitySum(int[][] students, int[][] mentors) {
        int m = students.length, n = students[0].length;
        // 预计算兼容性得分矩阵
        int[][] score = new int[m][m];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < m; j++)
                for (int k = 0; k < n; k++)
                    if (students[i][k] == mentors[j][k]) score[i][j]++;

        int[] dp = new int[1 << m];
        for (int mask = 1; mask < (1 << m); mask++) {
            int studentIdx = Integer.bitCount(mask) - 1; // 当前安排的学生索引
            for (int j = 0; j < m; j++) {
                if ((mask & (1 << j)) != 0) {
                    int prev = mask ^ (1 << j);
                    dp[mask] = Math.max(dp[mask], dp[prev] + score[studentIdx][j]);
                }
            }
        }
        return dp[(1 << m) - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² * 2^m)
- **空间复杂度**：O(2^m)

## 关键点总结

1. m ≤ 8，状态压缩 DP 或回溯都可行
2. `Integer.bitCount(mask) - 1` 得到当前应匹配的学生索引
3. 预计算兼容性矩阵避免重复计算
