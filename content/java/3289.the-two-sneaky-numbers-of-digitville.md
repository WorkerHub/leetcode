## 题目描述

数组 `nums`（长度 n+2）包含 0 到 n-1，其中恰好有两个数字各出现两次，其余出现一次。返回这两个重复的数字。

## 解题思路

计数数组统计每个数字出现次数，找出出现 2 次的数字。

## Java 代码实现

```java
class Solution {
    public int[] getSneakyNumbers(int[] nums) {
        int[] cnt = new int[100]; // 0 <= nums[i] < n <= 100
        for (int x : nums) cnt[x]++;
        int[] result = new int[2];
        int idx = 0;
        for (int i = 0; i < 100; i++) {
            if (cnt[i] == 2) result[idx++] = i;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（计数数组大小固定为 100）

## 关键点总结

1. 约束 n <= 100，计数数组大小固定
2. 遍历计数数组找出现 2 次的数字
3. 题目保证恰好 2 个数字重复
