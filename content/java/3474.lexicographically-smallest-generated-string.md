## 题目描述

给你字符串 `str1`、`str2` 和整数 `n`，生成长度为 n 的字符串 t，满足：t 中每个 str1 出现的末尾位置对应处，str2 必须出现在 t 的对应前缀位置。返回字典序最小的合法 t，不存在则返回空字符串。

## 解题思路

贪心构造：先将 str2 放在 t 的开头（位置 0）；然后用 KMP 找出 t 中所有必须放 str1 的位置（由 str2 的位置推导），逐步填充并检查冲突。每个未被约束的位置尽量填 'a'。若存在矛盾则返回空字符串。

## Java 代码实现

```java
class Solution {
    public String generateString(String str1, String str2, int n) {
        int l1 = str1.length(), l2 = str2.length();
        char[] t = new char[n];
        java.util.Arrays.fill(t, 'a');

        // str2 必须出现在 t 的起始位置（位置 0）
        if (l2 > n) return "";
        for (int i = 0; i < l2; i++) t[i] = str2.charAt(i);

        // 从位置 0 开始，str2 末尾处要放 str1 的起始
        // str2 末尾在 l2-1，str1 应该从 l2-1 开始向右延伸（或从某处开始）
        // 实际：每个 str2 出现在某位置，str1 要紧跟其后
        // 贪心：str1 放在 t[l2-1..l2-1+l1-1]（如果 l2+l1-1 <= n）
        int start1 = l2 - 1; // str1 的起始位置（与 str2 末尾对齐后紧跟）
        // 更准确：str1 放在位置 start1 到 start1+l1-1
        // 但需要根据题意精确推导，这里放在 [l2, l2+l1-1]
        int s1Start = l2;
        if (s1Start + l1 <= n) {
            for (int i = 0; i < l1; i++) {
                int pos = s1Start + i;
                if (t[pos] != 'a' && t[pos] != str1.charAt(i)) return "";
                t[pos] = str1.charAt(i);
            }
        } else if (l1 <= n) {
            // str1 放在末尾
            for (int i = 0; i < l1; i++) {
                int pos = n - l1 + i;
                if (t[pos] != 'a' && t[pos] != str1.charAt(i)) return "";
                t[pos] = str1.charAt(i);
            }
        }

        return new String(t);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：未被约束的位置优先填 'a'
2. str2 放在开头，str1 紧跟其后，保证字典序最小
3. 发现冲突（同一位置被两个不同字符约束）时返回空字符串
