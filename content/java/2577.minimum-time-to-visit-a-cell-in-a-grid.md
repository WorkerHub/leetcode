## 题目描述

给你 m×n 矩阵 `grid`，`grid[i][j]` 表示进入该格所需的最早时间，从 (0,0) 时刻 0 出发每步花费 1 时间，返回到达 (m-1,n-1) 的最少时间，无法到达返回 -1。

## 解题思路

Dijkstra 最短路：若当前时间 `t+1 >= grid[nr][nc]` 则直接进入；否则通过来回移动等待，根据等待步数奇偶性计算实际到达时间（偶数额外 +1）。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 起点两邻居均不可达，则无解
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        int[][] dist = new int[m][n];
        for (int[] row : dist) java.util.Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        // 最小堆：{时间, 行, 列}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int t = cur[0], r = cur[1], c = cur[2];
            if (r == m - 1 && c == n - 1) return t;
            if (t > dist[r][c]) continue;
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int nt;
                if (t + 1 >= grid[nr][nc]) {
                    nt = t + 1;
                } else {
                    // 等待时间的奇偶决定最终到达时间
                    int wait = grid[nr][nc] - (t + 1);
                    nt = (wait % 2 == 0) ? grid[nr][nc] + 1 : grid[nr][nc];
                }
                if (nt < dist[nr][nc]) {
                    dist[nr][nc] = nt;
                    pq.offer(new int[]{nt, nr, nc});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn log(mn))
- **空间复杂度**：O(mn)

## 关键点总结

1. 等待策略：等待步数为偶数时需额外 +1 到达，奇数时直接到达
2. 特判：起点上下左右邻居若都需要 >1 时间才能进入则无解
3. Dijkstra 保证每格以最优时间扩展
