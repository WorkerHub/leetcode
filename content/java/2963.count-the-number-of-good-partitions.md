## 题目描述

给你整数数组 `nums`，将其分成若干子数组，要求每个值的所有出现位置都在同一子数组中，返回满足条件的分法数目（对 10^9+7 取模）。

## 解题思路

预处理每个值的最后出现位置。从左到右扫描，维护当前子数组必须延伸到的最右位置 maxEnd。当 `i == maxEnd` 时，当前位置是合法分割点，统计分割点数 k。答案为 2^(k-1)（k-1 个内部分割点各自可选）。

## Java 代码实现

```java
class Solution {
    public int numberOfGoodPartitions(int[] nums) {
        final int MOD = 1_000_000_007;
        Map<Integer, Integer> last = new HashMap<>();
        for (int i = 0; i < nums.length; i++) last.put(nums[i], i);

        int maxEnd = 0, partitions = 0;
        for (int i = 0; i < nums.length; i++) {
            maxEnd = Math.max(maxEnd, last.get(nums[i])); // 更新当前子数组最右边界
            if (i == maxEnd) partitions++; // 当前位置是合法分割点
        }
        // k 个强制块，k-1 个可选分割点，方案数 2^(k-1)
        return (int) powMod(2, partitions - 1, MOD);
    }

    private long powMod(long base, int exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每个值 [first, last] 区间必须在同一子数组，等价于合并所有这样的区间
2. 合并后 k 个强制块，块间有 k-1 个可选分割点
3. 答案 2^(k-1) 需用快速幂对 10^9+7 取模
