## 题目描述

给定二进制数组 nums，将 nums[0..i] 视为二进制数，返回布尔数组表示该二进制前缀是否能被 5 整除。

**示例：**
```
输入：nums = [0,1,1]
输出：[true,false,false]
```

## 解题思路

逐位构建并取模：num = (num * 2 + bit) % 5，只需维护余数即可避免溢出。

## Java 代码实现

```java
class Solution {
    public List<Boolean> prefixesDivBy5(int[] nums) {
        List<Boolean> result = new ArrayList<>();
        int num = 0;

        for (int bit : nums) {
            num = (num * 2 + bit) % 5;
            result.add(num == 0);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **取模性质**：(a*2+b)%5 = ((a%5)*2+b)%5
2. **防溢出**：每步取模，只保留余数
3. **二进制构建**：左移一位加新位
