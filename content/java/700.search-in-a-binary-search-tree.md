## 题目描述

在 BST 中找到值等于 val 的节点，返回以该节点为根的子树，不存在返回 null。

**示例：**
```
输入：root = [4,2,7,1,3], val = 2
输出：[2,1,3]
```

## 解题思路

利用 BST 性质：val < root.val 搜左子树，val > root.val 搜右子树，相等则找到。

## Java 代码实现

```java
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        while (root != null) {
            if (val == root.val) return root;
            else if (val < root.val) root = root.left;
            else root = root.right;
        }
        return null;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(h)，h 为树高
- **空间复杂度**：O(1)

## 关键点总结

1. **BST 性质**：左小右大
2. **搜索方向**：根据值大小选择左/右子树
3. **迭代实现**：无需递归，空间 O(1)
