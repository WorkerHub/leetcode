## 题目描述

请设计一个类，使该类的构造函数能够接收一个字符串数组。然后实现一个方法，该方法能够分别接收两个单词 `word1` 和 `word2`，并返回列表中这两个单词之间的最短距离。

您的方法将被以不同的参数调用多次。

**示例：**
```
假设 wordsDict = ["practice", "makes", "perfect", "coding", "makes"]

输入: word1 = "coding", word2 = "practice"
输出: 3

输入: word1 = "makes", word2 = "coding"
输出: 1
```

**注意：** 你可以假设 word1 和 word2 都在列表中。

## 解题思路

这道题是 [LeetCode 243](https://leetcode.com/problems/shortest-word-distance/) 的扩展，关键区别是**需要多次查询**。

**核心思想：**
- 由于需要多次查询，每次都遍历整个数组会超时
- 应该在构造函数中**预处理**，把每个单词的所有位置存储起来
- 查询时，只需要在两个位置列表中找最小距离

**关键观察：**
1. 预处理：用哈希表存储每个单词的所有出现位置
2. 查询：两个有序数组找最小差值，使用双指针
3. 时间换空间：构造时 O(n)，查询时 O(m+k)，其中 m、k 是两个单词出现的次数

**双指针查找最小距离：**
- 两个有序数组 positions1 和 positions2
- 使用两个指针 i、j，初始都指向数组开头
- 计算当前距离，然后移动较小的指针
- 这样可以在 O(m+k) 时间内找到最小距离

## Java 代码实现

### 方法一：哈希表 + 双指针（推荐）⭐

```java
import java.util.*;

class WordDistance {
    // 哈希表：单词 -> 位置列表
    private Map<String, List<Integer>> locations;
    
    /**
     * 构造函数：预处理，记录每个单词的所有位置
     * 时间复杂度：O(n)，n 是数组长度
     * 空间复杂度：O(n)，存储所有单词的位置
     */
    public WordDistance(String[] wordsDict) {
        locations = new HashMap<>();
        for (int i = 0; i < wordsDict.length; i++) {
            String word = wordsDict[i];
            locations.computeIfAbsent(word, k -> new ArrayList<>()).add(i);
        }
    }
    
    /**
     * 双指针找最小距离
     * 时间复杂度：O(m+k)，m、k 是两个单词的出现次数
     */
    public int shortest(String word1, String word2) {
        List<Integer> positions1 = locations.get(word1);
        List<Integer> positions2 = locations.get(word2);
        
        int minDistance = Integer.MAX_VALUE;
        int i = 0, j = 0;
        
        while (i < positions1.size() && j < positions2.size()) {
            // 计算当前距离
            minDistance = Math.min(minDistance, Math.abs(positions1.get(i) - positions2.get(j)));
            
            // 移动较小的指针
            if (positions1.get(i) < positions2.get(j)) {
                i++;
            } else {
                j++;
            }
        }
        
        return minDistance;
    }
}
```

### 方法二：暴力查询（不推荐，但易理解）

```java
import java.util.*;

class WordDistance {
    private Map<String, List<Integer>> locations;
    
    public WordDistance(String[] wordsDict) {
        locations = new HashMap<>();
        for (int i = 0; i < wordsDict.length; i++) {
            locations.computeIfAbsent(wordsDict[i], k -> new ArrayList<>()).add(i);
        }
    }
    
    /**
     * 暴力枚举所有组合
     * 时间复杂度：O(m*k)，对于多次查询效率低
     */
    public int shortest(String word1, String word2) {
        List<Integer> positions1 = locations.get(word1);
        List<Integer> positions2 = locations.get(word2);
        
        int minDistance = Integer.MAX_VALUE;
        for (int pos1 : positions1) {
            for (int pos2 : positions2) {
                minDistance = Math.min(minDistance, Math.abs(pos1 - pos2));
            }
        }
        
        return minDistance;
    }
}
```

### 方法三：优化的双指针（带提前退出）

```java
import java.util.*;

class WordDistance {
    private Map<String, List<Integer>> wordPositions;
    
    public WordDistance(String[] wordsDict) {
        wordPositions = new HashMap<>();
        for (int idx = 0; idx < wordsDict.length; idx++) {
            wordPositions.computeIfAbsent(wordsDict[idx], k -> new ArrayList<>()).add(idx);
        }
    }
    
    public int shortest(String word1, String word2) {
        List<Integer> list1 = wordPositions.get(word1);
        List<Integer> list2 = wordPositions.get(word2);
        
        int minDist = Integer.MAX_VALUE;
        int i = 0, j = 0;
        
        while (i < list1.size() && j < list2.size()) {
            minDist = Math.min(minDist, Math.abs(list1.get(i) - list2.get(j)));
            
            // 优化：如果差值为 1，不可能更小，直接返回
            if (minDist == 1) {
                return 1;
            }
            
            // 移动指针
            if (list1.get(i) < list2.get(j)) {
                i++;
            } else {
                j++;
            }
        }
        
        return minDist;
    }
}
```

## 复杂度分析

| 方法 | 构造函数 | shortest 方法 | 空间复杂度 | 说明 |
|------|---------|--------------|-----------|------|
| 暴力查询 | O(n) | O(m*k) | O(n) | 多次查询效率低 |
| 双指针 | O(n) | O(m+k) | O(n) | 推荐，最优解 |

其中 n 是数组长度，m 和 k 是两个单词的出现次数。

## 关键点总结

1. **预处理思想**：多次查询的问题，通常需要预处理来优化
2. **哈希表存储**：用 HashMap 存储每个单词的所有位置
3. **双指针技巧**：两个有序数组找最小差值的经典算法
4. **时间权衡**：构造时花费 O(n)，每次查询只需 O(m+k)
5. **提前返回**：如果距离已经是 1，可以直接返回（不会有更小的）

## 易错点

1. **忘记预处理**：如果每次查询都遍历整个数组，会超时
2. **双指针移动**：要移动值较小的指针，而不是随机移动
3. **Java Map 操作**：使用 `computeIfAbsent` 或 `getOrDefault` 简化代码
4. **初始化哈希表**：使用 `HashMap` 搭配 `computeIfAbsent` 避免空指针
5. **绝对值计算**：计算距离时要用 `Math.abs()`
