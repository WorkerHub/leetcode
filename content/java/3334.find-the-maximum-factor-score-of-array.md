## 题目描述

给你整数数组 `nums`，因子得分 = GCD * LCM。最多删除一个元素，返回最大因子得分。

## 解题思路

预处理前缀和后缀的 GCD 与 LCM，枚举删除哪个下标（或不删），O(1) 查询删除后的 GCD 和 LCM，取最大值。

## Java 代码实现

```java
class Solution {
    public long maxScore(int[] nums) {
        int n = nums.length;
        long[] preGcd = new long[n + 1], preLcm = new long[n + 1];
        long[] sufGcd = new long[n + 1], sufLcm = new long[n + 1];
        preLcm[0] = sufLcm[n] = 1;
        for (int i = 0; i < n; i++) {
            preGcd[i + 1] = gcd(preGcd[i], nums[i]);
            preLcm[i + 1] = lcm(preLcm[i], nums[i]);
        }
        for (int i = n - 1; i >= 0; i--) {
            sufGcd[i] = gcd(sufGcd[i + 1], nums[i]);
            sufLcm[i] = lcm(sufLcm[i + 1], nums[i]);
        }

        // 不删除
        long best = preGcd[n] * preLcm[n];
        // 枚举删除第 i 个
        for (int i = 0; i < n; i++) {
            long g = gcd(preGcd[i], sufGcd[i + 1]);
            long l = lcm(preLcm[i], sufLcm[i + 1]);
            best = Math.max(best, g * l);
        }
        return best;
    }

    private long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }
    private long lcm(long a, long b) { return a == 0 || b == 0 ? a + b : a / gcd(a, b) * b; }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))，前缀/后缀预处理
- 空间复杂度：O(n)

## 关键点总结

1. 因子得分 = GCD * LCM，删除元素后重新计算
2. 前缀/后缀预处理实现 O(1) 查询删除某元素后的 GCD 和 LCM
3. GCD 初始值为 0（gcd(0,x)=x），LCM 初始值为 1（lcm(1,x)=x）
