## 题目描述

给你循环字符串数组 `words` 和目标字符串 `target`，从 `startIndex` 出发可顺/逆时针移动，返回到达任意 `target` 的最短距离，不存在则返回 -1。

## 解题思路

遍历所有 target 出现的位置，对每个位置取顺时针和逆时针距离的较小值，取所有候选的最小值。

## Java 代码实现

```java
class Solution {
    public int closetTarget(String[] words, String target, int startIndex) {
        int n = words.length, ans = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            if (words[i].equals(target)) {
                int diff = Math.abs(i - startIndex);
                ans = Math.min(ans, Math.min(diff, n - diff));
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L)，L 为字符串平均长度
- **空间复杂度**：O(1)

## 关键点总结

1. 循环数组两点间最短距离 = `min(diff, n - diff)`，其中 `diff = |i - j|`
2. 可能有多个 target 位置，遍历全部取最小
3. target 不存在时返回 -1
