## 题目描述

n 名玩家按技能值 `skills` 排队，每轮技能高者获胜并继续对阵下一人，输者排到末尾，返回第一个连续赢 k 场的玩家索引。

## 解题思路

若 `k >= n-1`，技能最大的玩家必然是答案（最多经历 n-1 场必遇）。否则线性扫描：维护当前赢家和连胜数，遇到更强对手则更新赢家并重置连胜为 1。

## Java 代码实现

```java
class Solution {
    public int findWinningPlayer(int[] skills, int k) {
        int n = skills.length;
        // k >= n-1 时直接找最大技能玩家
        if (k >= n - 1) {
            int maxIdx = 0;
            for (int i = 1; i < n; i++) {
                if (skills[i] > skills[maxIdx]) maxIdx = i;
            }
            return maxIdx;
        }
        // 线性模拟
        int cur = 0, wins = 0;
        for (int i = 1; i < n; i++) {
            if (skills[cur] > skills[i]) {
                wins++;
            } else {
                cur = i;
                wins = 1;
            }
            if (wins == k) return cur;
        }
        return cur;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. k >= n-1 时最大技能玩家必然胜出，无需模拟
2. 线性扫描维护赢家和连胜数，比队列模拟更高效
3. 遇更强对手时，连胜重置为 1（不是 0）
