## 题目描述

给定一副牌 deck，判断是否存在 X≥2 使得每种数字的数量都是 X 的倍数。

**示例：**
```
输入：deck = [1,2,3,4,4,3,2,1]
输出：true（X=2）
```

## 解题思路

统计每个数字的出现次数，求所有次数的 GCD。GCD≥2 则可分组。

## Java 代码实现

```java
class Solution {
    public boolean hasGroupsSizeX(int[] deck) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int card : deck) {
            count.merge(card, 1, Integer::sum);
        }

        int g = 0;
        for (int cnt : count.values()) {
            g = gcd(g, cnt);
        }
        return g >= 2;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + k log C)
- **空间复杂度**：O(k)

## 关键点总结

1. **GCD 判定**：所有计数的 GCD ≥ 2 即可
2. **gcd(0, x) = x**：初始值设为 0 可直接累加
3. **数学本质**：分组大小必须是所有计数的公约数
