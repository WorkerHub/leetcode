## 题目描述

n个花园种花，花满target得full分，否则所有非满花园的最小值*partial得分。分配newFlowers朵额外花求最大美丽值。

## 解题思路

排序后枚举完整花园数j（最大的j个填满），剩余花用于提升前n-j个花园的最小值。二分查找最大可行最小值m，前缀和快速计算提升花费。

## Java 代码实现

```java
class Solution {
    public long maximumBeauty(int[] flowers, long newFlowers, int target, int full, int partial) {
        int n = flowers.length;
        Arrays.sort(flowers);
        // 截断超过target的
        for (int i = 0; i < n; i++) {
            flowers[i] = Math.min(flowers[i], target);
        }
        
        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + flowers[i];
        }
        
        long ans = 0;
        long cost = 0; // 将最大j个花园填满的花费
        
        for (int j = 0; j <= n; j++) {
            long remaining = newFlowers - cost;
            if (remaining < 0) break;
            
            int left = n - j; // 非完整花园数量
            if (left == 0) {
                ans = Math.max(ans, (long) j * full);
            } else {
                // 二分最大可行最小值m
                long lo = flowers[0], hi = target - 1;
                while (lo < hi) {
                    long mid = (lo + hi + 1) / 2;
                    // 计算将前left个花园提升到mid的花费
                    int pos = lowerBound(flowers, left, (int) mid);
                    long needed = mid * pos - prefix[pos];
                    if (needed <= remaining) {
                        lo = mid;
                    } else {
                        hi = mid - 1;
                    }
                }
                // 验证
                int pos = lowerBound(flowers, left, (int) lo);
                long needed = lo * pos - prefix[pos];
                if (needed <= remaining) {
                    ans = Math.max(ans, (long) j * full + (long) partial * lo);
                }
            }
            
            // 下一轮：将flowers[n-j-1]填满
            if (j < n) {
                cost += target - flowers[n - j - 1];
            }
        }
        return ans;
    }
    
    private int lowerBound(int[] arr, int end, int target) {
        int lo = 0, hi = end;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **枚举完整花园数**：从右往左逐个填满
2. **二分最大最小值**：前left个花园用剩余花能达到的最大min
3. **前缀和加速**：快速计算"提升到m所需花数"
