## 题目描述

我们可以为二叉树 T 定义一个翻转操作，如下所示：选择任意节点，然后交换它的左子树和右子树。

只要经过一定次数的翻转操作后，能使 X 等于 Y，我们就称二叉树 X 翻转等价于二叉树 Y。

编写一个判断两个二叉树是否翻转等价的函数。这些树由根节点 `root1` 和 `root2` 给出。

**示例 1：**
```
输入：root1 = [1,2,3,4,5,6,null,null,null,7,8], root2 = [1,3,2,null,6,4,5,null,null,null,null,8,7]
输出：true
解释：我们翻转值为 1，3 以及 5 的三个节点。
```

**示例 2：**
```
输入：root1 = [], root2 = []
输出：true
```

**示例 3：**
```
输入：root1 = [], root2 = [1]
输出：false
```

**提示：**
- 每棵树节点数在 `[0, 100]` 范围内
- 每棵树中的每个值都是唯一的、在 `[0, 99]` 范围内的整数

## 解题思路

这道题要求判断两棵二叉树是否翻转等价。翻转等价的定义是：通过交换任意节点的左右子树，能让两棵树完全相同。

**核心思想：**
1. 两棵树翻转等价，当且仅当它们的根节点值相同，且：
   - 左子树与左子树翻转等价，右子树与右子树翻转等价（不翻转）
   - 或者左子树与右子树翻转等价，右子树与左子树翻转等价（翻转）

2. 这是一个典型的递归问题，对于每个节点，我们有两种情况需要检查：
   - 不翻转：`flipEquiv(root1.left, root2.left) && flipEquiv(root1.right, root2.right)`
   - 翻转：`flipEquiv(root1.left, root2.right) && flipEquiv(root1.right, root2.left)`

3. 递归终止条件：
   - 如果两个节点都为空，返回 true
   - 如果只有一个为空，返回 false
   - 如果节点值不相同，返回 false

## Java 代码实现

### 方法一：递归（推荐）⭐

```java
// 二叉树节点定义
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    /**
     * 判断两棵二叉树是否翻转等价
     * 思路：递归检查每个节点，考虑翻转和不翻转两种情况
     */
    public boolean flipEquiv(TreeNode root1, TreeNode root2) {
        // 递归终止条件：两个都为空
        if (root1 == null && root2 == null) return true;
        // 只有一个为空
        if (root1 == null || root2 == null) return false;
        // 节点值不同
        if (root1.val != root2.val) return false;

        // 情况1：不翻转，左对左，右对右
        boolean noFlip = flipEquiv(root1.left, root2.left) &&
                         flipEquiv(root1.right, root2.right);

        // 情况2：翻转，左对右，右对左
        boolean flip = flipEquiv(root1.left, root2.right) &&
                       flipEquiv(root1.right, root2.left);

        // 只要有一种情况成立即可
        return noFlip || flip;
    }
}
```

### 方法二：递归优化版（简化代码）

```java
class Solution {
    /**
     * 简化版递归实现
     */
    public boolean flipEquiv(TreeNode root1, TreeNode root2) {
        // 两个都为空
        if (root1 == null && root2 == null) return true;
        // 只有一个为空，或值不同
        if (root1 == null || root2 == null || root1.val != root2.val) return false;

        // 一行判断两种情况
        return (flipEquiv(root1.left, root2.left) && flipEquiv(root1.right, root2.right)) ||
               (flipEquiv(root1.left, root2.right) && flipEquiv(root1.right, root2.left));
    }
}
```

### 方法三：标准化树结构（规范化方法）

```java
class Solution {
    /**
     * 通过标准化树的结构来判断
     * 标准化规则：对于每个节点，如果左子节点值大于右子节点值，则交换
     */
    public boolean flipEquiv(TreeNode root1, TreeNode root2) {
        // 标准化两棵树后比较
        return isSameTree(canonicalize(root1), canonicalize(root2));
    }

    /** 标准化树的结构 */
    private TreeNode canonicalize(TreeNode node) {
        if (node == null) return null;

        // 递归标准化左右子树
        node.left = canonicalize(node.left);
        node.right = canonicalize(node.right);

        // 如果左子节点值大于右子节点值，交换它们
        if (node.left != null && node.right != null) {
            if (node.left.val > node.right.val) {
                TreeNode tmp = node.left;
                node.left = node.right;
                node.right = tmp;
            }
        } else if (node.left != null) {
            // 只有左子节点，移到右边（确保右子节点优先）
            // 这里保持原样即可，因为单侧不影响比较
        }

        return node;
    }

    /** 判断两棵树是否完全相同 */
    private boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

## 复杂度分析

**方法一和方法二：**
- **时间复杂度**：O(min(N1, N2))，其中 N1 和 N2 分别是两棵树的节点数。在最坏情况下，我们需要访问两棵树的所有节点。
- **空间复杂度**：O(min(H1, H2))，其中 H1 和 H2 分别是两棵树的高度。递归调用栈的深度等于树的高度。

**方法三：**
- **时间复杂度**：O(N1 + N2)，需要遍历两棵树各一次进行标准化，再遍历一次进行比较。
- **空间复杂度**：O(H1 + H2)，递归调用栈的空间。

## 关键点总结

1. **递归思维**：将大问题分解为子问题，每个节点只需考虑两种情况（翻转或不翻转）
2. **终止条件**：空节点、单个空节点、值不同三种情况
3. **逻辑或运算**：两种情况只要有一种成立即可，使用 `||` 连接
4. **对称性**：翻转操作本质上是左右子树的对称比较
5. **树的遍历**：使用深度优先搜索（DFS）递归遍历

## 易错点

1. **空节点判断顺序**：必须先判断两个都为空，再判断只有一个为空，否则会出现空指针异常
2. **短路求值**：Java 的 `&&` 和 `||` 具有短路特性，要注意判断顺序
3. **递归边界**：容易忘记判断节点值是否相等
4. **逻辑运算符优先级**：`&&` 优先级高于 `||`，注意加括号
5. **修改原树**：方法三会修改原树结构，如果不允许修改，需要先复制树
