## 题目描述

返回 [low, high] 范围内所有"连续整数"（每位比前一位大 1）。

**示例：**
```
输入：low = 100, high = 300
输出：[123, 234]
```

## 解题思路

所有连续整数都是 "123456789" 的连续子串。枚举所有子串长度和起始位置，筛选范围内的。

## Java 代码实现

```java
class Solution {
    public List<Integer> sequentialDigits(int low, int high) {
        String s = "123456789";
        List<Integer> result = new ArrayList<>();
        
        for (int len = 2; len <= 9; len++) {
            for (int start = 0; start + len <= 9; start++) {
                int num = Integer.parseInt(s.substring(start, start + len));
                if (num >= low && num <= high) {
                    result.add(num);
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，最多 45 个连续整数
- **空间复杂度**：O(1)

## 关键点总结

1. **子串枚举**：所有连续整数 = "123456789" 的子串
2. **总数有限**：只有 45 个
3. **自然有序**：先按长度再按起始位置枚举即为升序
