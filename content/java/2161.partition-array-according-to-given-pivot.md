## 题目描述

将数组按pivot分为三组：小于/等于/大于，各组内保持相对顺序。

## 解题思路

三分法：分别收集小于、等于、大于pivot的元素，拼接即可。

## Java 代码实现

```java
class Solution {
    public int[] pivotArray(int[] nums, int pivot) {
        int n = nums.length;
        int[] result = new int[n];
        int idx = 0;
        // 先放小于pivot的
        for (int x : nums) {
            if (x < pivot) result[idx++] = x;
        }
        // 再放等于pivot的
        for (int x : nums) {
            if (x == pivot) result[idx++] = x;
        }
        // 最后放大于pivot的
        for (int x : nums) {
            if (x > pivot) result[idx++] = x;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **三次遍历**：分别收集小于、等于、大于的元素
2. **保持相对顺序**：顺序遍历自然保持稳定性
3. **与快排partition不同**：本题需要稳定分区
