## 题目描述

给你整数 `n`，判断是否能将 `n` 表示为若干个不同的三的幂之和。

## 解题思路

将 `n` 转为三进制，若每一位都是 0 或 1（不含 2），则可以表示为不同的三的幂之和。

## Java 代码实现

```java
class Solution {
    public boolean checkPowersOfThree(int n) {
        while (n > 0) {
            if (n % 3 == 2) return false; // 三进制某位为 2，需要两个相同的幂
            n /= 3;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log_3(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 三进制表示中每位只能是 0 或 1，不能出现 2
2. 类比于二进制表示中每位代表一个不同的 2 的幂
