## 题目描述

给定书籍数组 `books[i] = [thickness, height]` 和书架宽度 shelfWidth，按顺序将书摆放到书架上。每层的高度由最高的书决定。返回最小总高度。

**示例：**
```
输入：books = [[1,1],[2,3],[2,3],[1,1],[1,1],[1,1],[1,2]], shelfWidth = 4
输出：6
```

## 解题思路

动态规划：`dp[i]` 表示放置前 i 本书的最小高度。对第 i 本书，逆向枚举同层的起始位置 j，在宽度允许范围内取最小的 `dp[j-1] + 层高`。

## Java 代码实现

```java
class Solution {
    public int minHeightShelves(int[][] books, int shelfWidth) {
        int n = books.length;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            int width = 0;
            int height = 0;
            // 逆向枚举当前层包含的书
            for (int j = i; j >= 1; j--) {
                width += books[j - 1][0];
                if (width > shelfWidth) break;
                height = Math.max(height, books[j - 1][1]);
                dp[i] = Math.min(dp[i], dp[j - 1] + height);
            }
        }

        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **DP 定义**：`dp[i]` = 前 i 本书的最小高度
2. **逆向枚举**：从当前书向前扫描同层的书，宽度超限则停止
3. **顺序限制**：不能调整书的顺序，只能决定每层放多少本
