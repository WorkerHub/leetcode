## 题目描述

给你一个整数数组 `nums`。如果一个子序列中相邻元素之差的绝对值恰好为 1，则称该子序列为好子序列。返回所有好子序列的元素之和（对 10^9 + 7 取模）。

## 解题思路

DP：`dp[v]` 为以值 v 结尾的所有好子序列元素之和，`cnt[v]` 为数量。每个新元素 v 可以接在 v-1 或 v+1 结尾的子序列后，也可以单独成一个子序列。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int sumOfGoodSubsequences(int[] nums) {
        final int MOD = 1_000_000_007;

        // dp[v] = 以值 v 结尾的所有好子序列的元素之和
        // cnt[v] = 以值 v 结尾的好子序列的数量
        Map<Integer, Long> dp = new HashMap<>();
        Map<Integer, Long> cnt = new HashMap<>();

        for (int v : nums) {
            long prevCnt = cnt.getOrDefault(v - 1, 0L) + cnt.getOrDefault(v + 1, 0L);
            long prevDp = dp.getOrDefault(v - 1, 0L) + dp.getOrDefault(v + 1, 0L);

            // 新增子序列数量：来自 v-1 和 v+1 的子序列 + 单独的 {v}
            long newCnt = (prevCnt + 1) % MOD;
            // 新增子序列元素和：旧子序列的和 + 新末尾 v 的贡献
            long newDp = (prevDp + prevCnt % MOD * v % MOD + v) % MOD;

            cnt.merge(v, newCnt, (a, b) -> (a + b) % MOD);
            dp.merge(v, newDp, (a, b) -> (a + b) % MOD);
        }

        long ans = 0;
        for (long val : dp.values()) {
            ans = (ans + val) % MOD;
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(max_val) 哈希表

## 关键点总结

1. 同时维护 `dp[v]`（和）和 `cnt[v]`（数量）两个哈希表
2. 新元素 v 可接在 v-1 或 v+1 结尾的子序列后，或单独成子序列
3. 模运算要全程使用，防止溢出
