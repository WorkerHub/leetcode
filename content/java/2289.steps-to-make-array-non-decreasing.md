## 题目描述

每步同时删除所有nums[i-1]>nums[i]的元素，求变为非递减所需步数。

## 解题思路

单调栈DP：dp[i]表示nums[i]被删除的步数。单调递减栈弹出时传递删除步数，dp[i]=max(弹出元素的dp)+1（当栈非空时）。答案为max(dp)。

## Java 代码实现

```java
class Solution {
    public int totalSteps(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        int ans = 0;

        for (int i = 0; i < n; i++) {
            int curDp = 0;
            while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {
                curDp = Math.max(curDp, dp[stack.pop()]);
            }
            if (!stack.isEmpty()) {
                dp[i] = curDp + 1;
                ans = Math.max(ans, dp[i]);
            }
            stack.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **dp[i]=被删除的步数**：0表示不被删
2. **弹出时取max**：当前元素需等待所有被弹出元素先删
3. **栈为空则dp[i]=0**：左侧无更大值不会被删
