## 题目描述

给定行和数组 `rowSum` 和列和数组 `colSum`，构造一个非负整数矩阵，使每行之和等于 `rowSum[i]`，每列之和等于 `colSum[j]`（保证输入合法）。

## Java 代码实现

```java
class Solution {
    public int[][] restoreMatrix(int[] rowSum, int[] colSum) {
        int m = rowSum.length, n = colSum.length;
        int[][] result = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 贪心：每格填入 min(行剩余, 列剩余)
                int val = Math.min(rowSum[i], colSum[j]);
                result[i][j] = val;
                rowSum[i] -= val;
                colSum[j] -= val;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)，输出矩阵

## 关键点总结

1. 贪心策略：每次取 `min(rowSum[i], colSum[j])`，将某一方向"消耗完"
2. 保证任何时候行和与列和均非负，总和守恒保证合法解存在
3. 逐格填充，会修改传入的 rowSum/colSum 数组（注意是否需要拷贝）
