## 题目描述

二进制矩阵中的所有元素不是 0 就是 1。

给你两个四叉树，`quadTree1` 和 `quadTree2`。其中 `quadTree1` 表示一个 `n * n` 二进制矩阵，而 `quadTree2` 表示另一个 `n * n` 二进制矩阵。

请你返回一个表示 `n * n` 二进制矩阵的四叉树，它是 `quadTree1` 和 `quadTree2` 所表示的两个二进制矩阵进行**按位逻辑或运算**的结果。

注意，当 `isLeaf` 为 **False** 时，你可以把 **True** 或者 **False** 赋值给节点，两个数值都会被判题机制**接受**。

四叉树数据结构中，每个内部节点只有四个子节点。此外，每个节点都有两个属性：

- `val`：储存叶子结点所代表的区域的值。1 对应 True，0 对应 False
- `isLeaf`：当这个节点是一个叶子结点时为 True，如果它有 4 个子节点则为 False

我们可以按以下步骤为二维区域构建四叉树：

1. 如果当前网格的值相同（即，全为 0 或者全为 1），将 `isLeaf` 设为 True，将 `val` 设为网格相应的值，并将四个子节点都设为 Null 然后停止。
2. 如果当前网格的值不同，将 `isLeaf` 设为 False，将 `val` 设为任意值，然后如下图所示，将当前网格划分为四个子网格。
3. 使用适当的子网格递归每个子节点。

**提示：**
- `quadTree1` 和 `quadTree2` 都是符合题目要求的四叉树，每个都代表一个 `n * n` 的矩阵
- `n == 2^x` 其中 `0 <= x <= 9`

## 解题思路

这是一道四叉树的分治题目。

核心思想：
1. 如果两棵树都是叶子节点，直接进行 OR 运算
2. 如果其中一个是叶子节点值为 1，整个区域结果为 1
3. 否则递归处理四个子区域
4. 检查四个子节点是否可以合并为叶子节点

## Java 代码实现

### 方法一：递归分治（推荐）⭐

```java
class Solution {
    public Node intersect(Node quadTree1, Node quadTree2) {
        // 情况1：两个都是叶子节点，直接 OR 运算
        if (quadTree1.isLeaf && quadTree2.isLeaf) {
            return new Node(
                quadTree1.val || quadTree2.val,  // OR 运算
                true,                             // 是叶子节点
                null, null, null, null
            );
        }

        // 情况2：quadTree1 是叶子节点
        if (quadTree1.isLeaf) {
            // 如果值为 1，整个区域都是 1
            if (quadTree1.val) return new Node(true, true, null, null, null, null);
            // 如果值为 0，返回 quadTree2
            return quadTree2;
        }

        // 情况3：quadTree2 是叶子节点
        if (quadTree2.isLeaf) {
            if (quadTree2.val) return new Node(true, true, null, null, null, null);
            return quadTree1;
        }

        // 情况4：两个都不是叶子节点，递归处理四个子区域
        Node topLeft = intersect(quadTree1.topLeft, quadTree2.topLeft);
        Node topRight = intersect(quadTree1.topRight, quadTree2.topRight);
        Node bottomLeft = intersect(quadTree1.bottomLeft, quadTree2.bottomLeft);
        Node bottomRight = intersect(quadTree1.bottomRight, quadTree2.bottomRight);

        // 检查是否可以合并为一个叶子节点
        if (topLeft.isLeaf && topRight.isLeaf &&
            bottomLeft.isLeaf && bottomRight.isLeaf &&
            topLeft.val == topRight.val &&
            topLeft.val == bottomLeft.val &&
            topLeft.val == bottomRight.val) {
            return new Node(topLeft.val, true, null, null, null, null);
        }

        // 不能合并，返回内部节点
        return new Node(false, false, topLeft, topRight, bottomLeft, bottomRight);
    }
}
```

### 方法二：简化版本

```java
class Solution {
    public Node intersect(Node q1, Node q2) {
        // 如果 q1 是叶子节点
        if (q1.isLeaf) return q1.val ? q1 : q2;
        // 如果 q2 是叶子节点
        if (q2.isLeaf) return q2.val ? q2 : q1;

        // 递归处理四个子区域
        Node tl = intersect(q1.topLeft, q2.topLeft);
        Node tr = intersect(q1.topRight, q2.topRight);
        Node bl = intersect(q1.bottomLeft, q2.bottomLeft);
        Node br = intersect(q1.bottomRight, q2.bottomRight);

        // 尝试合并
        if (tl.isLeaf && tr.isLeaf && bl.isLeaf && br.isLeaf &&
            tl.val == tr.val && tl.val == bl.val && tl.val == br.val) {
            return new Node(tl.val, true, null, null, null, null);
        }

        return new Node(false, false, tl, tr, bl, br);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，最坏情况下需要访问所有节点
- **空间复杂度**：O(log n)，递归调用栈的深度

## 关键点总结

1. **四叉树性质**：理解四叉树的递归结构
2. **OR 运算优化**：如果一个节点值为 1，结果必为 1
3. **节点合并**：四个子节点值相同时可以合并
4. **递归分治**：将问题分解为四个子问题
5. **边界情况**：两个都是叶子节点时直接计算

## 易错点

1. **OR 运算性质**：1 OR x = 1，0 OR x = x
2. **节点类型**：区分叶子节点和内部节点
3. **合并条件**：四个子节点都是叶子且值相同才能合并
4. **val 的值**：内部节点的 val 可以是任意值
5. **递归顺序**：按照 topLeft, topRight, bottomLeft, bottomRight 的顺序
