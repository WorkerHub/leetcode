## 题目描述

正整数数组 `nums`，选择一个**无重复元素**的子数组，返回其最大元素和。

## 解题思路

**滑动窗口：** 用 HashSet 维护窗口内的不重复元素，右指针扩展时若遇到重复则左指针收缩，同时维护窗口元素和，记录最大值。

## Java 代码实现

```java
class Solution {
    public int maximumUniqueSubarray(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        int windowSum = 0, maxSum = 0;
        int l = 0;

        for (int r = 0; r < nums.length; r++) {
            // 窗口内有重复，缩小左边界
            while (seen.contains(nums[r])) {
                seen.remove(nums[l]);
                windowSum -= nums[l];
                l++;
            }
            seen.add(nums[r]);
            windowSum += nums[r];
            maxSum = Math.max(maxSum, windowSum);
        }
        return maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 滑动窗口保持窗口内元素无重复
2. 遇到重复元素时逐步收缩左指针，同时更新窗口和
3. 每步更新最大和
