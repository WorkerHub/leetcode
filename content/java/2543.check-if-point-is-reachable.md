## 题目描述

从 `(1, 1)` 出发，每次可以 `(x,y)→(x+y,y)` 或 `(x,y)→(x,x+y)`，判断能否到达 `(targetX, targetY)`。

## 解题思路

逆向操作等价于辗转相减法（GCD）。结论：`(targetX, targetY)` 可达当且仅当 `gcd(targetX, targetY)` 是 2 的幂次方（包括 1）。

## Java 代码实现

```java
class Solution {
    public boolean isReachable(int targetX, int targetY) {
        // 可达当且仅当 gcd(targetX, targetY) 是 2 的幂
        int g = gcd(targetX, targetY);
        return (g & (g - 1)) == 0; // 判断是否为 2 的幂
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(min(targetX, targetY)))
- **空间复杂度**：O(1)

## 关键点总结

1. 逆向操作本质是辗转相减，与求 GCD 等价
2. 关键结论：可达 ↔ gcd(targetX, targetY) 是 2 的幂次方
3. 判断 n 是 2 的幂：`n > 0 && (n & (n-1)) == 0`
