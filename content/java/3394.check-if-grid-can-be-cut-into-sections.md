## 题目描述

给定 n×n 网格和若干不重叠矩形，判断能否用两条水平线或两条垂直线将网格切成三部分，使每部分恰好包含一个完整矩形。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean checkValidCuts(int n, int[][] rectangles) {
        // 检查 x 轴投影（垂直切割）
        int[][] xIntervals = new int[rectangles.length][2];
        int[][] yIntervals = new int[rectangles.length][2];
        for (int i = 0; i < rectangles.length; i++) {
            xIntervals[i] = new int[]{rectangles[i][0], rectangles[i][2]};
            yIntervals[i] = new int[]{rectangles[i][1], rectangles[i][3]};
        }
        return canSplit(xIntervals) || canSplit(yIntervals);
    }

    private boolean canSplit(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        int groups = 0, maxEnd = 0;
        for (int[] iv : intervals) {
            if (iv[0] >= maxEnd) {
                // 新的不重叠区间组
                groups++;
                if (groups >= 3) return true;
            }
            maxEnd = Math.max(maxEnd, iv[1]);
        }
        return groups >= 3;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导（n 为矩形数量）
- 空间复杂度：O(n)

## 关键点总结

1. 问题转化为：矩形在某一轴的投影是否能合并成 3 个或更多不重叠区间。
2. 合并区间后，区间数 >= 3 意味着存在至少 2 个分割点。
3. 判断不重叠用 `start >= maxEnd`（允许端点相连）。
