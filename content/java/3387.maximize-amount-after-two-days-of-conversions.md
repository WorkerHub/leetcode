## 题目描述

初始持有 `initialCurrency` 金额 1.0，第一天用 `pairs1/rates1` 汇率图转换，第二天用 `pairs2/rates2` 汇率图转换，返回最终 `finalCurrency` 的最大金额。

```java
import java.util.*;

class Solution {
    public double maxAmount(String initialCurrency, List<List<String>> pairs1,
                            double[] rates1, List<List<String>> pairs2,
                            double[] rates2, String finalCurrency) {
        // 第一天最大金额
        Map<String, Double> day1 = maxReachable(pairs1, rates1, initialCurrency, 1.0);

        double best = 0.0;
        for (Map.Entry<String, Double> e : day1.entrySet()) {
            // 第二天从 day1 每个货币出发
            Map<String, Double> day2 = maxReachable(pairs2, rates2, e.getKey(), e.getValue());
            best = Math.max(best, day2.getOrDefault(finalCurrency, 0.0));
        }
        return best;
    }

    private Map<String, Double> maxReachable(List<List<String>> pairs, double[] rates,
                                              String start, double startAmt) {
        // 构建无向汇率图
        Map<String, List<Object[]>> graph = new HashMap<>();
        for (int i = 0; i < pairs.size(); i++) {
            String a = pairs.get(i).get(0), b = pairs.get(i).get(1);
            double r = rates[i];
            graph.computeIfAbsent(a, k -> new ArrayList<>()).add(new Object[]{b, r});
            graph.computeIfAbsent(b, k -> new ArrayList<>()).add(new Object[]{a, 1.0 / r});
        }
        Map<String, Double> best = new HashMap<>();
        best.put(start, startAmt);
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{start, startAmt});
        while (!stack.isEmpty()) {
            Object[] cur = stack.pop();
            String curr = (String) cur[0];
            double amt = (double) cur[1];
            for (Object[] edge : graph.getOrDefault(curr, Collections.emptyList())) {
                String next = (String) edge[0];
                double newAmt = amt * (double) edge[1];
                // 若金额更大则更新并继续搜索
                if (newAmt > best.getOrDefault(next, 0.0)) {
                    best.put(next, newAmt);
                    stack.push(new Object[]{next, newAmt});
                }
            }
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(V1 * E2)，V1 是第一天可达货币数，E2 是第二天边数
- 空间复杂度：O(V + E)

## 关键点总结

1. 汇率图是无向的，双向转换汇率互为倒数。
2. 第一天找从初始货币出发的所有最大金额。
3. 第二天从第一天每个可达货币出发，找到达目标货币的最大金额。
