## 题目描述

给定一个员工的工作时间表列表 `schedule`，表示每个员工的工作时间。

每个员工都有一个非重叠的时间段列表 `Intervals`，这些时间段已经排好序。

返回所有员工的共同空闲时间的有限区间列表，同样需要排好序。

**示例 1:**
```
输入: schedule = [[[1,2],[5,6]],[[1,3]],[[4,10]]]
输出: [[3,4]]
解释:
共有三个员工，他们各自的工作时间是:
员工 1: [1,2], [5,6]
员工 2: [1,3]
员工 3: [4,10]
共同的空闲时间是 [3,4]
```

**示例 2:**
```
输入: schedule = [[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]
输出: [[5,6],[7,9]]
```

**提示:**
- `1 <= schedule.length <= 50`
- `1 <= schedule[i].length <= 50`
- `0 <= schedule[i][j].start < schedule[i][j].end <= 10^8`

## 解题思路

这道题的关键是找到所有员工都空闲的时间段，也就是所有工作时间段之间的间隙。

**核心思想：**
1. 将所有员工的工作时间段合并到一起
2. 按开始时间排序
3. 合并重叠的时间段
4. 找出合并后相邻时间段之间的间隙

**算法流程：**
1. 收集所有时间段并排序
2. 合并重叠的时间段
3. 输出相邻时间段之间的空隙

## Java 代码实现

### 方法一：扁平化 + 区间合并（推荐）

```java
import java.util.*;

class Solution {
    public List<Interval> employeeFreeTime(List<List<Interval>> schedule) {
        // 将所有时间段扁平化
        List<Interval> intervals = new ArrayList<>();
        for (List<Interval> employee : schedule) {
            intervals.addAll(employee);
        }

        // 按开始时间排序
        intervals.sort((a, b) -> a.start - b.start);

        // 合并重叠的时间段
        List<Interval> merged = new ArrayList<>();
        merged.add(intervals.get(0));
        for (int i = 1; i < intervals.size(); i++) {
            Interval curr = intervals.get(i);
            Interval last = merged.get(merged.size() - 1);
            if (curr.start <= last.end) {
                // 重叠，合并
                last.end = Math.max(last.end, curr.end);
            } else {
                // 不重叠，添加新区间
                merged.add(curr);
            }
        }

        // 找出空闲时间（相邻区间之间的间隙）
        List<Interval> result = new ArrayList<>();
        for (int i = 0; i < merged.size() - 1; i++) {
            result.add(new Interval(merged.get(i).end, merged.get(i + 1).start));
        }

        return result;
    }
}
```

### 方法二：使用堆（优先队列）

```java
import java.util.*;

class Solution {
    public List<Interval> employeeFreeTime(List<List<Interval>> schedule) {
        // 使用最小堆，存储 [开始时间, 结束时间]
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        for (List<Interval> employee : schedule) {
            for (Interval interval : employee) {
                heap.offer(new int[]{interval.start, interval.end});
            }
        }

        List<Interval> result = new ArrayList<>();
        int[] prev = heap.poll();

        while (!heap.isEmpty()) {
            int[] curr = heap.poll();
            if (curr[0] > prev[1]) {
                // 发现空闲时间
                result.add(new Interval(prev[1], curr[0]));
                prev = curr;
            } else {
                // 重叠，更新结束时间
                prev[1] = Math.max(prev[1], curr[1]);
            }
        }

        return result;
    }
}
```

### 方法三：一次遍历版本

```java
import java.util.*;

class Solution {
    public List<Interval> employeeFreeTime(List<List<Interval>> schedule) {
        // 收集并排序所有区间
        List<Interval> times = new ArrayList<>();
        for (List<Interval> emp : schedule) {
            times.addAll(emp);
        }
        times.sort((a, b) -> a.start - b.start);

        List<Interval> result = new ArrayList<>();
        int end = times.get(0).end;

        for (int i = 1; i < times.size(); i++) {
            Interval interval = times.get(i);
            if (interval.start > end) {
                // 找到空闲时间
                result.add(new Interval(end, interval.start));
                end = interval.end;
            } else {
                // 更新结束时间
                end = Math.max(end, interval.end);
            }
        }

        return result;
    }
}
```

## 复杂度分析

**方法一：扁平化 + 区间合并**
- **时间复杂度：** O(N log N)，其中 N 是所有时间段的总数，主要是排序的时间
- **空间复杂度：** O(N)，存储所有时间段

**方法二：堆**
- **时间复杂度：** O(N log N)，堆操作
- **空间复杂度：** O(N)

## 关键点总结

1. **问题转化：** 将问题转化为区间合并问题
2. **扁平化：** 将所有员工的时间段合并到一起处理
3. **排序：** 按开始时间排序是关键
4. **区间合并：** 合并重叠的工作时间段
5. **空隙查找：** 合并后的相邻时间段之间的间隙就是空闲时间

## 易错点

1. **排序遗漏：** 忘记排序会导致结果错误
2. **合并逻辑：** 合并条件是 `start <= prev_end`，不是 `<`
3. **更新结束时间：** 合并时要取较大的结束时间
4. **边界情况：** 只有一个合并区间时，没有空闲时间
5. **数据结构：** 注意 Interval 类的定义和使用
