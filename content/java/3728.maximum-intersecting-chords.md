## 题目描述

给定圆上 `2n` 个按顺序排列的点，用 `n` 条弦连接（每点属于一条弦），求最大相交弦对数。

## Java 代码实现

```java
class Solution {
    public int maxIntersections(int n) {
        // dp[i]: 2i 个点构成 i 条弦的最大相交对数
        int[] dp = new int[n + 1];

        for (int i = 2; i <= n; i++) {
            // 固定点 0，枚举与其配对的点 k（k 为奇数，保证两侧点数为偶数）
            for (int k = 1; k < 2 * i; k += 2) {
                int left = (k - 1) / 2;      // 左侧弦数
                int right = i - 1 - left;     // 右侧弦数
                int pairs = left * right;      // 左侧弦与右侧弦的相交对数
                dp[i] = Math.max(dp[i], dp[left] + dp[right] + pairs);
            }
        }

        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²)，双重循环
- 空间复杂度：O(n)

## 关键点总结

1. 固定一条弦将问题分解为两个独立子问题（左侧和右侧）
2. 跨越该弦的弦对数 = 左侧弦数 × 右侧弦数
3. 枚举配对点 k 时必须为奇数，保证两侧各有偶数个点
