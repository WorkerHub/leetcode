## 题目描述

给你字符串 `s` 和 `pattern`，若子串与 `pattern` 至多有一个位置字符不同，则称为"几乎相等"。返回第一个几乎相等子串的起始下标，不存在返回 -1。

## 解题思路

Z 函数方法：对 `pattern+"#"+s` 求 Z 函数得到前向匹配长度 `l`，对反转串求 Z 函数得到后向匹配长度 `r`。若 `l + r >= m - 1` 则该位置合法（至多一处不同）。

## Java 代码实现

```java
class Solution {
    public int minStartingIndex(String s, String pattern) {
        int n = s.length(), m = pattern.length();
        // 前向 Z 函数：pattern + '#' + s
        int[] zPre = zFunction(pattern + "#" + s);
        // 后向 Z 函数：reverse(pattern) + '#' + reverse(s)
        String revP = new StringBuilder(pattern).reverse().toString();
        String revS = new StringBuilder(s).reverse().toString();
        int[] zSuf = zFunction(revP + "#" + revS);

        for (int i = 0; i <= n - m; i++) {
            int l = Math.min(zPre[m + 1 + i], m);         // 前缀匹配长度
            int r = Math.min(zSuf[m + 1 + (n - i - m)], m); // 后缀匹配长度
            if (l + r >= m - 1) return i;
        }
        return -1;
    }

    private int[] zFunction(String t) {
        int n = t.length();
        int[] z = new int[n];
        z[0] = n;
        int l = 0, r = 0;
        for (int i = 1; i < n; i++) {
            if (i < r) z[i] = Math.min(r - i, z[i - l]);
            while (i + z[i] < n && t.charAt(z[i]) == t.charAt(i + z[i])) z[i]++;
            if (i + z[i] > r) { l = i; r = i + z[i]; }
        }
        return z;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，Z 函数构造和遍历均为线性
- 空间复杂度：O(n + m)

## 关键点总结

1. Z 函数在 O(n) 时间计算字符串所有位置与前缀的最长公共前缀
2. 前向 + 后向 Z 函数组合，快速判断"至多一处不同"：`l + r >= m - 1`
3. 拼接字符串中需要 `#` 分隔符，防止模式和文本间的越界匹配
