## 题目描述

不断将相邻两数之和取模10替换数组直到剩一个元素，返回该元素。

## 解题思路

直接模拟：每轮将数组长度减1，nums[i]=(nums[i]+nums[i+1])%10，直到剩一个。

## Java 代码实现

```java
class Solution {
    public int triangularSum(int[] nums) {
        int n = nums.length;
        for (int len = n; len > 1; len--) {
            for (int i = 0; i < len - 1; i++) {
                nums[i] = (nums[i] + nums[i + 1]) % 10;
            }
        }
        return nums[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)，原地修改

## 关键点总结

1. **原地模拟**：每轮从左到右更新，数组有效长度减1
2. **取模10**：每次相加后取个位
3. **组合数学本质**：最终结果等于各元素乘二项式系数之和mod10
