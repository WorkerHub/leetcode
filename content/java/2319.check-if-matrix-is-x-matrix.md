## 题目描述

判断一个 n×n 矩阵是否为 X 矩阵：对角线上所有元素非零，对角线外所有元素为零。

## 解题思路

遍历矩阵每个元素，根据是否在主对角线（`i == j`）或副对角线（`i + j == n-1`）上，分别检验元素非零或为零的条件。

## Java 代码实现

```java
class Solution {
    public boolean checkXMatrix(int[][] grid) {
        int n = grid.length;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                boolean onDiagonal = (i == j) || (i + j == n - 1);
                if (onDiagonal) {
                    if (grid[i][j] == 0) return false; // 对角线上必须非零
                } else {
                    if (grid[i][j] != 0) return false; // 非对角线必须为零
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(1)

## 关键点总结

1. 主对角线：`i == j`；副对角线：`i + j == n - 1`。
2. 两条对角线的交叉元素（奇数阶矩阵中心）也属于对角线，同样需非零。
