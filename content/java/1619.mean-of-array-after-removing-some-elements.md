## 题目描述

删除数组中最小5%和最大5%的元素后，求剩余元素的平均值。

## 解题思路

排序后取中间90%的切片求均值。5%即n/20个元素。

## Java 代码实现

```java
class Solution {
    public double trimMean(int[] arr) {
        Arrays.sort(arr);
        int n = arr.length;
        int remove = n / 20; // 5%
        double sum = 0;
        for (int i = remove; i < n - remove; i++) {
            sum += arr[i];
        }
        return sum / (n - 2 * remove);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **5% = n/20**：题目保证n是20的倍数
2. **排序后跳过前后各remove个**
3. **返回浮点数**：sum/(n-2*remove)
