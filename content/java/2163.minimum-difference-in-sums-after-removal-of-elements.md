## 题目描述

长度3n的数组去除n个元素，剩余2n个中前n个之和减后n个之和的最小值。

## 解题思路

双堆：枚举分割点i(n到2n)，left[i]=前i个中最小n个之和（最大堆维护），right[i]=后3n-i个中最大n个之和（最小堆维护），答案=min(left[i]-right[i])。

## Java 代码实现

```java
class Solution {
    public long minimumDifference(int[] nums) {
        int n = nums.length / 3;
        int total = 3 * n;
        
        // left[i]: nums[0..i-1]中最小n个之和
        long[] left = new long[total + 1];
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        long sum = 0;
        for (int i = 0; i < n; i++) {
            maxHeap.offer(nums[i]);
            sum += nums[i];
        }
        left[n] = sum;
        
        for (int i = n; i < 2 * n; i++) {
            maxHeap.offer(nums[i]);
            sum += nums[i];
            // 弹出最大的，保留最小n个
            sum -= maxHeap.poll();
            left[i + 1] = sum;
        }
        
        // right[i]: nums[i..3n-1]中最大n个之和
        long[] right = new long[total + 1];
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        long sum2 = 0;
        for (int i = total - 1; i >= total - n; i--) {
            minHeap.offer(nums[i]);
            sum2 += nums[i];
        }
        right[2 * n] = sum2;
        
        for (int i = 2 * n - 1; i >= n; i--) {
            minHeap.offer(nums[i]);
            sum2 += nums[i];
            // 弹出最小的，保留最大n个
            sum2 -= minHeap.poll();
            right[i] = sum2;
        }
        
        // 枚举分割点
        long ans = Long.MAX_VALUE;
        for (int i = n; i <= 2 * n; i++) {
            ans = Math.min(ans, left[i] - right[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **分割点枚举**：i从n到2n，前i个选最小n个，后3n-i个选最大n个
2. **最大堆维护前缀最小n个**：超过n个时弹出最大值
3. **最小堆维护后缀最大n个**：超过n个时弹出最小值
