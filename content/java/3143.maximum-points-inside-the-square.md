## 题目描述

以原点为中心的正方形中最多包含多少个点，要求每个标签最多出现一次。

## 解题思路

每个点的切比雪夫距离=max(|x|,|y|)。按距离排序后分层扫描，维护已选标签集合，遇到重复标签则停止。

## Java 代码实现

```java
class Solution {
    public int maxPointsInsideSquare(int[][] points, String s) {
        int n = points.length;
        int[] dist = new int[n];
        for (int i = 0; i < n; i++) {
            dist[i] = Math.max(Math.abs(points[i][0]), Math.abs(points[i][1]));
        }
        // 按距离排序
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> dist[a] - dist[b]);

        Set<Character> seen = new HashSet<>();
        int ans = 0, i = 0;
        while (i < n) {
            int j = i;
            int curDist = dist[order[i]];
            // 找同距离的所有点
            while (j < n && dist[order[j]] == curDist) j++;
            // 检查这层是否有重复或与已选冲突
            boolean conflict = false;
            Set<Character> layer = new HashSet<>();
            for (int k = i; k < j; k++) {
                char c = s.charAt(order[k]);
                if (seen.contains(c) || layer.contains(c)) {
                    conflict = true;
                    break;
                }
                layer.add(c);
            }
            if (conflict) break;
            seen.addAll(layer);
            ans += j - i;
            i = j;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **切比雪夫距离=max(|x|,|y|)**
2. **按距离分层**：同层点必须同时包含或排除
3. **遇到标签冲突立即停止**
