## 题目描述

给你正整数 `n` 和 `k`，若一个 `n` 位整数既是回文数又能被 `k` 整除，则称其为**好整数**。返回 `n` 位好整数的数量。

## 解题思路

回文数由前 `ceil(n/2)` 位唯一决定。枚举前半部分（首位非零），构造完整回文数，判断能否被 `k` 整除。

## Java 代码实现

```java
class Solution {
    public long countGoodIntegers(int n, int k) {
        int half = (n + 1) / 2;
        int start = (int) Math.pow(10, half - 1); // 前半部分最小值（首位不为 0）
        int end = (int) Math.pow(10, half);        // 前半部分最大值 + 1
        long ans = 0;

        for (int firstHalf = start; firstHalf < end; firstHalf++) {
            String s = String.valueOf(firstHalf);
            // 构造回文数
            StringBuilder sb = new StringBuilder(s);
            if (n % 2 == 0) {
                sb.append(new StringBuilder(s).reverse());
            } else {
                sb.append(new StringBuilder(s.substring(0, s.length() - 1)).reverse());
            }
            long num = Long.parseLong(sb.toString());
            if (num % k == 0) {
                ans++;
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10^(n/2))，枚举前半部分
- 空间复杂度：O(n)

## 关键点总结

1. 回文数由前半部分唯一决定，枚举范围为 `[10^(half-1), 10^half)`
2. n 为奇数时中间位只出现一次，镜像时去掉最后一位
3. 使用 `long` 解析回文数避免溢出（n=10 时最大 10 位）
