## 题目描述

给定二叉树，每个节点值 0-25 对应字母 a-z，返回从叶子到根的字典序最小字符串。

**示例：**
```
输入：root = [0,1,2,3,4,3,4]
输出："dba"
```

## 解题思路

DFS：从根向下遍历，在路径开头添加当前字符（反向构建）。到达叶子时与当前最优解比较。

## Java 代码实现

```java
class Solution {
    private String result = null;

    public String smallestFromLeaf(TreeNode root) {
        dfs(root, new StringBuilder());
        return result;
    }

    private void dfs(TreeNode node, StringBuilder path) {
        if (node == null) return;

        // 在路径开头插入当前字符
        path.insert(0, (char)('a' + node.val));

        if (node.left == null && node.right == null) {
            String current = path.toString();
            if (result == null || current.compareTo(result) < 0) {
                result = current;
            }
        } else {
            dfs(node.left, path);
            dfs(node.right, path);
        }

        // 回溯：删除开头字符
        path.deleteCharAt(0);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * h)，h 为树高（字符串比较开销）
- **空间复杂度**：O(h)

## 关键点总结

1. **反向构建**：从叶子到根，所以在开头插入字符
2. **叶子判断**：左右子节点都为空
3. **回溯**：恢复路径状态
