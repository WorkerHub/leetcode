## 题目描述

给你一棵二叉树，如果节点 `X` 在树中的路径（从根到 `X`）上，**没有任何其他节点的值比 `X` 的值大**，那么这个节点 `X` 就是**好节点**（即从根到该节点路径上的最大值 <= 该节点的值）。

返回二叉树中**好节点**的数量。

**注意：** 根节点始终是好节点（路径上只有它自己）。

**示例 1：**
```
输入：root = [3,1,4,3,null,1,5]
输出：4
解释：
        3           <- 好节点（路径最大值3<=3）
       / \
      1   4         <- 4是好节点（路径3<=4），1不是（3>1）
     /   / \
    3   1   5       <- 3是好节点（路径3<=3），5是好节点（路径4<=5），1不是（4>1）
```

**示例 2：**
```
输入：root = [3,3,null,4,2]
输出：3
解释：
        3           <- 好节点
       /
      3             <- 好节点（路径最大3=3）
     / \
    4   2           <- 4是好节点（路径3<=4），2不是（3>2）
```

**示例 3：**
```
输入：root = [1]
输出：1
```

**提示：**
- 二叉树中节点数目在 `[1, 10^5]` 范围内
- 每个节点权值的范围是 `[-10^4, 10^4]`

## 解题思路

**DFS，传递路径最大值：**

从根节点开始 DFS，同时传递"从根到当前节点路径上的最大值" `maxSoFar`：
1. 若 `node.val >= maxSoFar`，当前节点是好节点，计数 +1，更新 `maxSoFar = node.val`。
2. 否则，不计数，`maxSoFar` 保持不变（因为已知路径上有更大的值）。
3. 递归处理左右子树。

## Java 代码实现

### 方法一：DFS 递归（推荐）

```java
class Solution {
    public int goodNodes(TreeNode root) {
        return dfs(root, Integer.MIN_VALUE);
    }

    private int dfs(TreeNode node, int maxSoFar) {
        if (node == null) return 0;

        // 判断当前节点是否为好节点
        int count = node.val >= maxSoFar ? 1 : 0;

        // 更新路径最大值
        int newMax = Math.max(maxSoFar, node.val);

        // 递归左右子树
        count += dfs(node.left, newMax);
        count += dfs(node.right, newMax);

        return count;
    }
}
```

### 方法二：BFS（广度优先搜索）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int goodNodes(TreeNode root) {
        if (root == null) return 0;

        int count = 0;
        // 队列存储 [节点, 到达该节点时路径的最大值]
        Deque<Object[]> queue = new ArrayDeque<>();
        queue.offer(new Object[]{root, Integer.MIN_VALUE});

        while (!queue.isEmpty()) {
            Object[] pair = queue.poll();
            TreeNode node = (TreeNode) pair[0];
            int maxSoFar = (int) pair[1];

            // 判断是否为好节点
            if (node.val >= maxSoFar) count++;

            int newMax = Math.max(maxSoFar, node.val);

            if (node.left != null) queue.offer(new Object[]{node.left, newMax});
            if (node.right != null) queue.offer(new Object[]{node.right, newMax});
        }

        return count;
    }
}
```

### 方法三：DFS 迭代（显式栈）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int goodNodes(TreeNode root) {
        if (root == null) return 0;

        int count = 0;
        // 栈存储 [节点, 路径最大值]
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{root, Integer.MIN_VALUE});

        while (!stack.isEmpty()) {
            Object[] pair = stack.pop();
            TreeNode node = (TreeNode) pair[0];
            int maxSoFar = (int) pair[1];

            // 判断是否为好节点
            if (node.val >= maxSoFar) count++;

            int newMax = Math.max(maxSoFar, node.val);

            if (node.left != null) stack.push(new Object[]{node.left, newMax});
            if (node.right != null) stack.push(new Object[]{node.right, newMax});
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，每个节点访问一次。
- **空间复杂度：** O(h)，h 为树的高度。递归版本使用调用栈，最坏 O(n)（链状树），平衡树 O(log n)。

## 图解示例

```
树：
        3
       / \
      1   4
     /   / \
    3   1   5

DFS 过程（传递路径最大值）：

dfs(3, MIN): 3 >= MIN -> 好节点，newMax=3，count=1
  dfs(1, 3): 1 < 3 -> 不是好节点，newMax=3，count=0
    dfs(3, 3): 3 >= 3 -> 好节点，count=1
  小计：dfs(1)=1

  dfs(4, 3): 4 >= 3 -> 好节点，newMax=4，count=1
    dfs(1, 4): 1 < 4 -> 不是好节点，count=0
    dfs(5, 4): 5 >= 4 -> 好节点，count=1
  小计：dfs(4)=2

总计：1 + 1 + 2 = 4，正确！
```

## 关键点总结

1. 好节点的定义：路径上（从根到当前节点）的最大值 <= 当前节点的值。
2. DFS 传递状态：将"路径最大值"作为参数传递，避免每次重新计算路径。
3. 根节点始终是好节点（初始 `maxSoFar = Integer.MIN_VALUE`，任何值都 >= 最小整数）。
4. 三种遍历方式（递归/BFS/DFS迭代）逻辑完全一致，只是实现形式不同。

## 易错点

- 初始 `maxSoFar` 用 0 而非 `Integer.MIN_VALUE`，导致负数节点值被错误地判断为非好节点。
- 在递归调用前忘记更新 `maxSoFar`（应取 `Math.max(当前最大, node.val)`）。
- 将条件写成 `node.val > maxSoFar`（严格大于），遗漏了等号的情况（相等也是好节点）。
