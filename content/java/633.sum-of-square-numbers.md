## 题目描述

给定非负整数 `c`，判断是否存在两个整数 `a` 和 `b` 使得 `a² + b² = c`。

**示例：**
```
输入：c = 5
输出：true（1² + 2² = 5）
```

## 解题思路

双指针：left=0, right=√c，根据平方和与 c 的关系移动指针。

## Java 代码实现

```java
class Solution {
    public boolean judgeSquareSum(int c) {
        long left = 0;
        long right = (long) Math.sqrt(c);

        while (left <= right) {
            long sum = left * left + right * right;
            if (sum == c) {
                return true;
            } else if (sum < c) {
                left++;
            } else {
                right--;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(√c)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针**：从两端向中间逼近
2. **用 long**：避免 left*left 溢出
3. **right 初始值**：Math.sqrt(c)
