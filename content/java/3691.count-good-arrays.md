## 题目描述

给你三个整数 `n`、`m` 和 `k`，构造一个长度为 `n`、每个元素在 `[1, m]` 之间且恰好有 k 对相邻元素相等的数组。返回这样的数组数量，对 `10^9 + 7` 取模。

## 解题思路

组合数学：从 n-1 个相邻对中选 k 个相等，有 `C(n-1, k)` 种；合并后有 `n-k` 个"段"，第一段 m 种选法，后续每段 m-1 种（与前段不同）。总方案数 = `C(n-1, k) * m * (m-1)^(n-1-k)`。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public int countGoodArrays(int n, int m, int k) {
        if (k > n - 1) return 0;
        // C(n-1, k) * m * (m-1)^(n-1-k)
        long ans = comb(n - 1, k) * m % MOD;
        ans = ans * pow(m - 1, n - 1 - k) % MOD;
        return (int) ans;
    }

    private long comb(int n, int k) {
        if (k > n) return 0;
        long num = 1, den = 1;
        for (int i = 0; i < k; i++) {
            num = num * ((n - i) % MOD) % MOD;
            den = den * (i + 1) % MOD;
        }
        return num * pow(den, MOD - 2) % MOD; // 费马小定理求逆元
    }

    private long pow(long base, long exp) {
        long result = 1; base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD; exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k + log MOD)
- 空间复杂度：O(1)

## 关键点总结

1. 核心公式：`C(n-1, k) * m * (m-1)^(n-1-k)`
2. k 个相等对将数组分成 n-k 段，第一段 m 种，后续 m-1 种
3. 组合数用费马小定理求模逆元
