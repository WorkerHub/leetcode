## 题目描述

给定整数数组 `nums` 和操作列表 `ops[i] = [l, r, val]`（将 `nums[l..r]` 替换为 `val`），按顺序执行所有操作后返回最大子数组和。

## Java 代码实现

```java
class Solution {
    public long maximumSubarraySum(int[] nums, int[][] ops) {
        int[] arr = nums.clone();
        // 逆序应用操作，已被后续覆盖的位置跳过
        boolean[] covered = new boolean[arr.length];
        for (int i = ops.length - 1; i >= 0; i--) {
            int l = ops[i][0], r = ops[i][1], val = ops[i][2];
            for (int j = l; j <= r; j++) {
                if (!covered[j]) { arr[j] = val; covered[j] = true; }
            }
        }
        // Kadane 算法求最大子数组和
        long maxSum = arr[0], curSum = arr[0];
        for (int i = 1; i < arr.length; i++) {
            curSum = Math.max(arr[i], curSum + arr[i]);
            maxSum = Math.max(maxSum, curSum);
        }
        return maxSum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * q)（暴力应用操作）
- 空间复杂度：O(n)

## 关键点总结

1. 区间赋值操作后只有最后一次覆盖有效，逆序处理避免重复赋值
2. Kadane 算法 O(n) 求最大子数组和
3. 初始值取 arr[0] 处理全为负数的情况
