## 题目描述

**Trie**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word`。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false`。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix`，返回 `true`；否则，返回 `false`。

**示例：**
```
输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 true
trie.search("app");     // 返回 false
trie.startsWith("app"); // 返回 true
trie.insert("app");
trie.search("app");     // 返回 true
```

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数总计不超过 `3 * 10^4` 次

## 解题思路

**Trie（前缀树/字典树）** 是一种专门处理字符串的树形数据结构。

### Trie 的特点

1. **根节点不包含字符**，其他每个节点包含一个字符
2. **从根到某一节点的路径**，路径上的字符连接起来，就是该节点对应的字符串
3. **每个节点的所有子节点**包含的字符都不相同
4. **标记结束**：需要标记某个节点是否为单词的结尾

### 节点设计

每个节点需要包含：
1. **子节点**：通常用数组存储（26个小写字母）
2. **标记位**：表示从根到当前节点是否构成一个完整的单词

### 基本操作

1. **插入（insert）**：
   - 从根节点开始，逐个字符创建或查找节点
   - 最后标记单词结束

2. **搜索（search）**：
   - 从根节点开始，逐个字符查找
   - 最后检查是否为单词结束标记

3. **前缀搜索（startsWith）**：
   - 类似 search，但不需要检查结束标记

## Java 代码实现

### 方法一：使用数组存储子节点（推荐）⭐

```java
class Trie {
    // Trie 节点内部类
    private class TrieNode {
        TrieNode[] children;  // 26 个小写字母
        boolean isEnd;        // 标记是否为单词结尾
        
        public TrieNode() {
            children = new TrieNode[26];
            isEnd = false;
        }
    }
    
    private TrieNode root;
    
    public Trie() {
        // 初始化根节点
        root = new TrieNode();
    }
    
    public void insert(String word) {
        TrieNode node = root;
        
        // 遍历单词的每个字符
        for (char c : word.toCharArray()) {
            int index = c - 'a';  // 计算字符对应的索引
            if (node.children[index] == null) {
                node.children[index] = new TrieNode();  // 创建新节点
            }
            node = node.children[index];  // 移动到子节点
        }
        
        // 标记单词结束
        node.isEnd = true;
    }
    
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        // 需要找到节点，且该节点标记为单词结尾
        return node != null && node.isEnd;
    }
    
    public boolean startsWith(String prefix) {
        // 只需要找到前缀对应的节点即可
        return searchPrefix(prefix) != null;
    }
    
    // 辅助方法：搜索前缀，返回最后的节点
    private TrieNode searchPrefix(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                return null;  // 前缀不存在
            }
            node = node.children[index];
        }
        return node;
    }
}
```

**代码说明**：
- **TrieNode**：内部类，包含 26 个子节点数组和结束标记
- **insert**：逐字符插入，最后标记结束
- **search**：调用 `searchPrefix`，再检查 `isEnd`
- **startsWith**：只需调用 `searchPrefix` 检查路径是否存在
- **searchPrefix**：公共辅助方法，避免代码重复

### 方法二：使用 HashMap 存储子节点

```java
import java.util.HashMap;
import java.util.Map;

class Trie {
    private class TrieNode {
        Map<Character, TrieNode> children;  // 用 HashMap 存储子节点
        boolean isEnd;
        
        public TrieNode() {
            children = new HashMap<>();
            isEnd = false;
        }
    }
    
    private TrieNode root;
    
    public Trie() {
        root = new TrieNode();
    }
    
    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            if (!node.children.containsKey(c)) {
                node.children.put(c, new TrieNode());
            }
            node = node.children.get(c);
        }
        node.isEnd = true;
    }
    
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        return node != null && node.isEnd;
    }
    
    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }
    
    private TrieNode searchPrefix(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            if (!node.children.containsKey(c)) {
                return null;
            }
            node = node.children.get(c);
        }
        return node;
    }
}
```

**优点**：
- 灵活，适合字符集大或字符种类多的情况
- 只存储实际使用的字符，节省空间

**缺点**：
- HashMap 有额外开销，速度比数组稍慢

### 方法三：节点展开（无内部类）

```java
class Trie {
    private Trie[] children;  // 26 个子节点
    private boolean isEnd;
    
    public Trie() {
        children = new Trie[26];
        isEnd = false;
    }
    
    public void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                node.children[index] = new Trie();
            }
            node = node.children[index];
        }
        node.isEnd = true;
    }
    
    public boolean search(String word) {
        Trie node = searchPrefix(word);
        return node != null && node.isEnd;
    }
    
    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }
    
    private Trie searchPrefix(String prefix) {
        Trie node = this;
        for (char c : prefix.toCharArray()) {
            int index = c - 'a';
            if (node.children[index] == null) {
                return null;
            }
            node = node.children[index];
        }
        return node;
    }
}
```

**优化说明**：
- Trie 类本身就是节点，减少额外内部类
- LeetCode 常见写法，代码更简洁

## 复杂度分析

设 n 为单词长度，m 为单词数量。

### 时间复杂度
- **insert**：O(n)，需要遍历单词的每个字符
- **search**：O(n)，需要遍历单词的每个字符
- **startsWith**：O(n)，需要遍历前缀的每个字符

### 空间复杂度
- **总空间**：O(m × n)，最坏情况下所有单词没有公共前缀
- **单个节点（数组实现）**：O(26) = O(1)
- **单个节点（HashMap 实现）**：O(字符种类数)

## 关键点总结

1. **节点设计**：children（子节点数组）+ isEnd（结束标记）
2. **数组 vs HashMap**：
   - 数组：速度快，适合只含小写字母的场景
   - HashMap：灵活，适合字符集大的场景
3. **search vs startsWith**：区别在于是否检查 isEnd
4. **前缀共享**：Trie 的核心优势，节省空间
5. **应用场景**：自动补全、拼写检查、IP 路由、字符串匹配

## 易错点

1. **忘记标记结束**：insert 后忘记设置 `isEnd = true`

2. **search 和 startsWith 混淆**：
   - search 需要检查 `isEnd`
   - startsWith 只需要找到路径

3. **索引计算错误**：
   ```java
   int index = c - 'a';  // 正确
   int index = c;         // 错误，索引会超出范围
   ```

4. **边界情况**：
   - 重复插入相同单词（不会出错，只是 isEnd 重复设为 true）
   - 搜索空字符串（题目保证长度 >= 1）

5. **空指针异常**：访问 `node.children[index]` 之前需确保 `node` 不为 null
