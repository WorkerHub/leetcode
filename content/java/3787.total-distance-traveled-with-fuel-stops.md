## 题目描述

一辆车从位置 0 出发，初始油量 `fuel`，每行驶 1 单位消耗 1 油量。给定加油站列表 `stations[i] = [position, fuel]`，求车能行驶的最大总距离。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxDistance(int fuel, int[][] stations) {
        // 贪心 + 最大堆：前进时收集经过的加油站燃油入堆，燃油不足时取最大值补充
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        int curFuel = fuel;
        int prev = 0;

        for (int[] station : stations) {
            int pos = station[0], f = station[1];
            curFuel -= (pos - prev);
            prev = pos;
            heap.offer(f);
            // 若燃油不足到达当前位置，回头取最大油量补充
            while (curFuel < 0 && !heap.isEmpty()) {
                curFuel += heap.poll();
            }
        }

        // 当前位置 + 剩余燃油（可继续行驶）
        return prev + curFuel;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，最大堆操作
- 空间复杂度：O(n)，堆的大小

## 关键点总结

1. 贪心：优先使用最多的燃油补充（从堆中取最大值）
2. "回头加油"等价于在之前某站提前加满油
3. 最终答案 = 当前位置 + 剩余燃油
