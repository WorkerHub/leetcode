## 题目描述

给定股票价格数组prices，平滑下降时段要求每天价格恰好比前一天少1。返回平滑下降时段总数。

## 解题思路

DP：dp表示以当前元素结尾的平滑下降时段数。若prices[i]==prices[i-1]-1则dp=dp+1，否则dp=1。答案为所有dp之和。

## Java 代码实现

```java
class Solution {
    public long getDescentPeriods(int[] prices) {
        long ans = 1;
        long dp = 1;
        for (int i = 1; i < prices.length; i++) {
            if (prices[i] == prices[i - 1] - 1) {
                dp++;
            } else {
                dp = 1;
            }
            ans += dp;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **递推关系**：连续递减则dp累加，否则重置为1
2. **条件是恰好少1**：不是任意递减
3. **用long**：结果可能很大
