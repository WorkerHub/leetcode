## 题目描述

给你一个整数数组 `nums`，将其分割成若干严格递增子序列，返回所需的最少子序列数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minSubsequences(int[] nums) {
        // 最少严格递增子序列数 = 最长非递增子序列长度（Dilworth 定理）
        // 等价于对 -nums 求最长严格递增子序列（LIS）
        List<Integer> tails = new ArrayList<>();

        for (int x : nums) {
            int neg = -x;
            // 二分查找第一个 >= neg 的位置（lower_bound）
            int lo = 0, hi = tails.size();
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails.get(mid) < neg) lo = mid + 1;
                else hi = mid;
            }
            if (lo == tails.size()) tails.add(neg);
            else tails.set(lo, neg);
        }
        return tails.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 最少分割成严格递增子序列数 = 最长非递增子序列长度（Dilworth 定理）
2. 求最长非递增子序列等价于对取负后的数组求 LIS
3. 耐心排序 + 二分查找高效求解
