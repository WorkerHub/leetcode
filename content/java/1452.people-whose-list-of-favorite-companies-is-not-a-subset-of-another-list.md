## 题目描述

给你一个数组 `favoriteCompanies`，其中 `favoriteCompanies[i]` 是第 `i` 名用户收藏的公司清单（下标从 0 开始）。

找出不是其他任何人收藏的公司清单的**子集**的收藏清单，并以列表形式返回这些清单对应的下标。返回的答案需按升序排列。

**示例 1：**
```
输入：favoriteCompanies = [["leetcode","google","facebook"],["google","microsoft"],["google","facebook"],["google"],["amazon"]]
输出：[0,1,4]
解释：
- favoriteCompanies[2] = ["google","facebook"] 是 favoriteCompanies[0] 的子集。
- favoriteCompanies[3] = ["google"] 是 favoriteCompanies[0]、favoriteCompanies[1]、favoriteCompanies[2] 的子集。
- 其他的收藏清单不是其他人收藏清单的子集。
```

**示例 2：**
```
输入：favoriteCompanies = [["leetcode","google","facebook"],["leetcode","amazon"],["facebook","google"]]
输出：[0,1,2]
解释：三个清单互不为子集。
```

**示例 3：**
```
输入：favoriteCompanies = [["leetcode"],["google"],["facebook"],["amazon"]]
输出：[0,1,2,3]
```

**提示：**
- `1 <= favoriteCompanies.length <= 100`
- `1 <= favoriteCompanies[i].length <= 500`
- `1 <= favoriteCompanies[i][j].length <= 20`
- 每个公司名字只由小写英文字母组成
- 同一个用户的收藏清单内不会存在重复元素
- 所有用户的收藏清单合并后也不包含重复元素（即公司名字在所有清单中唯一）

## 解题思路

**核心思路：集合的子集判断**

将每个用户的公司列表转换为集合，然后对每个用户 `i` 检查：是否存在另一个用户 `j`（`j != i`），使得 `set[i]` 是 `set[j]` 的严格子集。

- 若不存在这样的 `j`，则下标 `i` 加入答案
- Java 中 `Set.containsAll(otherSet)` 可以检查 `set[j]` 是否包含 `set[i]` 的所有元素

## Java 代码实现

### 方法一：集合 + 双重遍历（推荐）

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<Integer> peopleIndexes(List<List<String>> favoriteCompanies) {
        int n = favoriteCompanies.size();
        // 将每个用户的公司列表转为集合，方便子集判断
        List<Set<String>> sets = new ArrayList<>();
        for (List<String> companies : favoriteCompanies) {
            sets.add(new HashSet<>(companies));
        }

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            boolean isSubset = false;
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                // 检查 sets[i] 是否是 sets[j] 的真子集
                // sets[j].containsAll(sets[i]) 且 sets[i] != sets[j]
                if (sets[j].containsAll(sets[i]) && sets[i].size() < sets[j].size()) {
                    isSubset = true;
                    break;
                }
            }
            if (!isSubset) {
                result.add(i);
            }
        }

        return result;
    }
}
```

### 方法二：公司名映射为整数集合（优化版）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public List<Integer> peopleIndexes(List<List<String>> favoriteCompanies) {
        // 将所有公司名映射为唯一整数 ID
        Map<String, Integer> companyToId = new HashMap<>();
        int idx = 0;
        for (List<String> companies : favoriteCompanies) {
            for (String c : companies) {
                if (!companyToId.containsKey(c)) {
                    companyToId.put(c, idx++);
                }
            }
        }

        // 转换为整数集合
        int n = favoriteCompanies.size();
        List<Set<Integer>> sets = new ArrayList<>();
        for (List<String> companies : favoriteCompanies) {
            Set<Integer> set = new HashSet<>();
            for (String c : companies) {
                set.add(companyToId.get(c));
            }
            sets.add(set);
        }

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            boolean isSubset = false;
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                if (sets[j].containsAll(sets[i]) && sets[i].size() < sets[j].size()) {
                    isSubset = true;
                    break;
                }
            }
            if (!isSubset) result.add(i);
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 × m)，n 为用户数，m 为平均清单长度。集合子集判断需要 O(min(|A|, |B|))，最坏 O(m)
- 空间复杂度：O(n × m)，存储所有集合

## 关键点总结

1. 将列表转为集合是子集判断的关键操作
2. Java 中 `setB.containsAll(setA)` 检查 setA 是否是 setB 的子集（包含相等情况）
3. 需要加上 `setA.size() < setB.size()` 来排除相等的情况（真子集）
4. 题目保证公司名全局唯一，所以两个不同用户的清单不会完全相同（其实可以用 `<=` 但保险起见加上大小判断）

## 易错点

- 注意是"严格子集"：清单 A 是清单 B 的子集且 A ≠ B，需要同时检查 containsAll 和大小关系
- 不要忘记跳过 `i == j` 的情况（不与自身比较）
- 答案要求升序，由于我们按序枚举 `i`，结果天然有序
