## 题目描述

有 n 个房间，每天的访问规则为：奇数次访问房间 i 后前往 `nextVisit[i]`，偶数次访问后前往 `(i+1) % n`。从房间 0 的第 0 天开始，返回第一次进入每个房间的最早天数（对 `10^9+7` 取余）。

## 解题思路

设 `dp[i]` 为第一次到达房间 i 的天数。第一次到 i（奇数次）后去 `nextVisit[i]=j`，再从 j 回到 i 需 `dp[i]-dp[j]` 天，再前往 `i+1` 需 1 天，故 `dp[i+1] = 2*dp[i] - dp[j] + 2`。

## Java 代码实现

### 方法一：DP（推荐）

```java
class Solution {
    public int firstDayBeenInAllRooms(int[] nextVisit) {
        final int MOD = 1_000_000_007;
        int n = nextVisit.length;
        long[] dp = new long[n];

        for (int i = 0; i < n - 1; i++) {
            int j = nextVisit[i];
            // dp[i+1] = 2*dp[i] - dp[j] + 2，注意取模后减法要加MOD防止负数
            dp[i + 1] = (2 * dp[i] - dp[j] + 2 + MOD) % MOD;
        }

        return (int) dp[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `nextVisit[i] <= i`，回退不会越界
2. 状态转移：`dp[i+1] = 2*dp[i] - dp[nextVisit[i]] + 2`
3. Java 减法取模需加 MOD 防止负数（Python 自动处理，Java 不会）
