## 题目描述

从 `m x n` 矩阵 `mat` 的每一行各选一个整数，使所选元素之和与 `target` 的绝对差最小，返回该最小绝对差。

## 解题思路

用集合维护当前所有可能的行选择之和，逐行扩展。初始集合为 `{0}`，每行将集合中每个值加上本行各元素得到新集合，最终求集合中与 target 最近的值。

## Java 代码实现

### 方法一：集合 DP（推荐）

```java
import java.util.*;

class Solution {
    public int minimizeTheDifference(int[][] mat, int target) {
        // 当前可达和的集合
        Set<Integer> dp = new HashSet<>();
        dp.add(0);

        for (int[] row : mat) {
            // 行内去重，减少重复计算
            Set<Integer> rowVals = new HashSet<>();
            for (int v : row) rowVals.add(v);

            Set<Integer> newDp = new HashSet<>();
            for (int s : dp) {
                for (int v : rowVals) {
                    newDp.add(s + v);
                }
            }
            dp = newDp;
        }

        int ans = Integer.MAX_VALUE;
        for (int s : dp) {
            ans = Math.min(ans, Math.abs(s - target));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * S)，S 为可达和数目（最大约 4900）
- 空间复杂度：O(S)

## 关键点总结

1. 集合 DP：每行扩展可达和集合
2. 行内去重（`Set`）减少重复计算
3. 总和上限 = 70 * 70 = 4900，集合大小有界
