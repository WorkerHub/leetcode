## 题目描述

给你整数数组 `nums`，返回所有非空子序列之和的按位或。

## 解题思路

维护累计前缀和并对结果持续取 OR：每个元素本身（单元素子序列）以及所有前缀和都会作为某个子序列的和参与 OR，一次遍历即可得到答案。

## Java 代码实现

```java
class Solution {
    public long subsequenceSumOr(int[] nums) {
        long result = 0, prefixSum = 0;
        for (int num : nums) {
            prefixSum += num;
            result |= prefixSum; // 前缀和覆盖高位贡献
            result |= num;       // 单元素子序列贡献
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 所有前缀和的 OR 已覆盖高位贡献，每个元素本身也需 OR（单元素子序列）
2. 总和可达 n × 10^9 ≈ 10^14，需使用 `long`
3. 空子序列和为 0，OR 上 0 不影响结果
