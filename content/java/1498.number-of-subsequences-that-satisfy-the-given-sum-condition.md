## 题目描述

给你一个整数数组 `nums` 和一个整数 `target`。

请你统计并返回 `nums` 中能满足其**最小元素与最大元素**之和**小于或等于** `target` 的**非空子序列**数目。

由于答案可能很大，请对 `10^9 + 7` 取余后返回。

**示例 1：**

```
输入：nums = [3,5,6,7], target = 9
输出：4
解释：满足条件的子序列有 [3],[3,5],[3,6],[3,5,6]
（子序列 [3,7],[5,6,7] 等不满足，因为最大+最小 > 9）
```

**示例 2：**

```
输入：nums = [3,3,6,8], target = 10
输出：6
解释：满足条件的子序列有 [3],[3],[3,3],[3,6],[3,6],[3,3,6]
```

**示例 3：**

```
输入：nums = [2,3,3,4,6,7], target = 12
输出：61
```

**提示：**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= target <= 10^6`

## 解题思路

**关键观察：子序列中最小值和最大值**

对于任意子序列，最小值 + 最大值 <= target 是限制条件。

**排序不影响子序列数量**：子序列由元素本身决定（不是位置），排序后选取的元素子集数量不变。

**排序 + 双指针思路：**

1. 对 `nums` 排序。
2. 用左指针 `left` 固定子序列的**最小值**，右指针 `right` 找满足条件的最大**右端**。
3. 对于固定的 `left`，最大的 `right` 满足 `nums[left] + nums[right] <= target`。
4. 在 `[left, right]` 范围内，`nums[left]` 一定是最小值，任意包含 `nums[left]` 的子集都满足条件（因为最大值 <= `nums[right]` <= target - nums[left]）。
5. 包含 `left` 的子集数量：从 `[left+1, right]` 中任意选取剩余元素，共 `2^(right-left)` 种。

**贡献计算：**

- 固定 `left`，最大右端 `right` 满足 `nums[left] + nums[right] <= target`
- 贡献 = `2^(right - left)`（其余 `right-left` 个元素自由选择，包含或不包含 `left` 的那个选法）

注意：`2^(right-left)` 需要预计算并取模。

## Java 代码实现

### 方法一：排序 + 双指针（推荐）

```java
import java.util.Arrays;

class Solution {
    public int numSubseq(int[] nums, int target) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        int n = nums.length;

        // 预计算 2 的幂次，避免重复计算
        // pow2[i] = 2^i % MOD
        int[] pow2 = new int[n];
        pow2[0] = 1;
        for (int i = 1; i < n; i++) {
            pow2[i] = (int) ((long) pow2[i - 1] * 2 % MOD);
        }

        long ans = 0;
        int left = 0, right = n - 1;

        while (left <= right) {
            if (nums[left] + nums[right] <= target) {
                // 固定 left 为最小值，[left+1, right] 内任意选
                // 共 2^(right - left) 个子序列
                ans = (ans + pow2[right - left]) % MOD;
                left++;
            } else {
                // 当前 right 过大，缩小右端
                right--;
            }
        }

        return (int) ans;
    }
}
```

### 方法二：排序 + 二分查找（每个 left 单独二分）

```java
import java.util.Arrays;

class Solution {
    public int numSubseq(int[] nums, int target) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        int n = nums.length;

        // 预计算 2 的幂次
        int[] pow2 = new int[n];
        pow2[0] = 1;
        for (int i = 1; i < n; i++) {
            pow2[i] = (int) ((long) pow2[i - 1] * 2 % MOD);
        }

        long ans = 0;
        for (int left = 0; left < n; left++) {
            // nums[left] 是最小值，找最大的 right 使 nums[left]+nums[right] <= target
            int maxRightVal = target - nums[left];
            if (maxRightVal < nums[left]) break;  // 连单元素都不满足，后面更不满足

            // 二分查找最大的 right（从 left 到 n-1）
            int lo = left, hi = n - 1, right = left - 1;
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (nums[mid] <= maxRightVal) {
                    right = mid;
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }

            if (right >= left) {
                // 子序列数量 = 2^(right - left)
                ans = (ans + pow2[right - left]) % MOD;
            }
        }

        return (int) ans;
    }
}
```

### 方法三：双指针 + 快速幂（不预处理幂次）

```java
import java.util.Arrays;

class Solution {
    public int numSubseq(int[] nums, int target) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        int n = nums.length;
        int left = 0, right = n - 1;
        long ans = 0;

        while (left <= right) {
            if (nums[left] + nums[right] <= target) {
                // 快速幂计算 2^(right-left) % MOD
                ans = (ans + fastPow(2, right - left, MOD)) % MOD;
                left++;
            } else {
                right--;
            }
        }

        return (int) ans;
    }

    private long fastPow(long base, int exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（双指针+预处理） | O(n log n) | O(n) |
| 方法二（排序+二分） | O(n log n) | O(n) |
| 方法三（双指针+快速幂） | O(n log n) | O(1) |

- 排序 O(n log n)，双指针 O(n)，预处理 O(n)
- 方法二每次循环有 O(log n) 的二分，整体仍是 O(n log n)

## 图解示例

以 `nums = [3,5,6,7], target = 9` 为例：

```
排序后：[3, 5, 6, 7]
         L        R

步骤1：left=0(3), right=3(7), 3+7=10>9, right--
步骤2：left=0(3), right=2(6), 3+6=9<=9, 贡献 2^(2-0)=4, left++
步骤3：left=1(5), right=2(6), 5+6=11>9, right--
步骤4：left=1(5), right=1(5), 5+5=10>9, right--
步骤5：left=1 > right=0, 循环结束

总贡献 = 4
子序列：[3],[3,5],[3,6],[3,5,6] → 恰好 4 个 ✓
```

## 关键点总结

1. **排序后子序列数不变**：子序列是元素子集，与顺序无关，排序后可以用双指针。
2. **固定最小值，自由选择中间元素**：`left` 固定为最小值，`[left+1, right]` 内的元素任意选。
3. **2^(right-left) 的来源**：`right-left` 个中间元素，每个独立地选或不选，共 `2^(right-left)` 种。
4. **取模操作**：每步都对 `MOD` 取模，预计算幂次避免超时。
5. **双指针的正确性**：`left` 增加时，满足条件的最右端 `right` 单调不减（因为 `nums[left]` 增大）。

## 易错点

- **排序是否影响答案**：不影响，子序列的最小/最大值不依赖顺序，只依赖选取的元素值。
- **幂次计算越界**：`right - left` 可达 `n-1 = 10^5-1`，`2^(10^5)` 极大，必须取模。
- **Java long 运算**：`pow2[i-1] * 2` 可能溢出 int，用 `(long) pow2[i-1] * 2 % MOD` 防止溢出。
- **循环终止条件**：`left <= right`，不是 `left < right`，因为单元素子序列 `[nums[left]]` 也需要计入（此时 `right == left`）。

## 学习建议

1. 先理解排序不影响子序列计数的关键洞察，这是本题的核心突破口。
2. 掌握"固定一端，移动另一端"的双指针模板，这是处理有序数组配对/子序列问题的标准方法。
3. `2^(right-left)` 的推导过程要弄懂：中间元素自由选择 = 每个元素独立的二选一 = `2^(元素个数)`。
4. 取模运算在涉及大数时是必须的，养成写 `% MOD` 的习惯，注意 Java 的整数溢出问题。
