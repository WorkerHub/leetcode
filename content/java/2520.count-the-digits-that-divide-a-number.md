## 题目描述

给你整数 `num`，返回 `num` 中能整除 `num` 的数字的数目（若 `num % digit == 0` 则该数字满足条件）。

## 解题思路

逐位取出数字（通过取模和整除），跳过数字 0，检查 `num % digit == 0` 并计数。

## Java 代码实现

```java
class Solution {
    public int countDigits(int num) {
        int count = 0, temp = num;
        while (temp > 0) {
            int d = temp % 10; // 取最后一位
            // 跳过 0，检查是否整除
            if (d != 0 && num % d == 0) count++;
            temp /= 10;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log num)
- **空间复杂度**：O(1)

## 关键点总结

1. 数字 0 不能作除数，需跳过
2. 重复数字需重复计算，不去重
3. 检查的是 `num % digit == 0`，而非 `digit % num == 0`
