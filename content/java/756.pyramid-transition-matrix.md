## 题目描述

你正在把积木堆成金字塔。每个块都有一个颜色，用一个字母表示。每一行的块比它下面的行少一个块，并且居中。

为了让金字塔美观，只有特定的三角形可以被允许。一个三角形的形式是 `ABC`，表示你可以把 `C` 放在 `A` 和 `B` 上面。

你从底部的一行开始，表示为一个字符串 `bottom`，其中每个字符代表该行中的块的颜色。

你还会得到一个字符串列表 `allowed`。`allowed[i]` 的形式是 `XYZ`，表示你可以把 `Z` 块放在 `X` 和 `Y` 块上面。

如果你可以按照这些规则建造金字塔一直到顶部，返回 `true`。否则，返回 `false`。

**示例 1:**
```
输入: bottom = "BCD", allowed = ["BCC","CDE","CEA","FFF"]
输出: true
```

**示例 2:**
```
输入: bottom = "AAAA", allowed = ["AAB","AAC","BCD","BBE","DEF"]
输出: false
```

**提示：**
- `2 <= bottom.length <= 6`
- `0 <= allowed.length <= 216`
- `allowed[i].length == 3`
- 所有字符串中的字母都在 `{'A', 'B', 'C', 'D', 'E', 'F', 'G'}` 中

## 解题思路

这是一个典型的回溯问题。我们需要逐层构建金字塔，每一层都基于下一层。

**核心思想：**
1. 从底层开始，逐层向上构建
2. 对于每一对相邻的块，尝试所有可能的上层块
3. 使用回溯法探索所有可能的构建方式
4. 如果能构建到顶部（只有一个块），返回 true

## Java 代码实现

### 方法一：回溯 + 哈希表（推荐）

```java
import java.util.*;

class Solution {
    private Map<String, List<Character>> mapping;

    public boolean pyramidTransition(String bottom, List<String> allowed) {
        // 构建映射：两字符组合 -> 可能的上层块列表
        mapping = new HashMap<>();
        for (String triple : allowed) {
            String key = triple.substring(0, 2);
            mapping.computeIfAbsent(key, k -> new ArrayList<>()).add(triple.charAt(2));
        }
        return buildLevel(bottom, new StringBuilder(), 0);
    }

    private boolean buildLevel(String currentLevel, StringBuilder nextLevel, int pos) {
        // 如果当前层只有一个块，成功
        if (currentLevel.length() == 1) return true;

        // 如果下一层构建完成，递归构建更上一层
        if (pos == currentLevel.length() - 1) {
            return buildLevel(nextLevel.toString(), new StringBuilder(), 0);
        }

        // 获取当前两块的组合
        String key = currentLevel.substring(pos, pos + 2);
        List<Character> tops = mapping.getOrDefault(key, Collections.emptyList());

        // 尝试所有可能的上层块
        for (char top : tops) {
            nextLevel.append(top);
            if (buildLevel(currentLevel, nextLevel, pos + 1)) return true;
            nextLevel.deleteCharAt(nextLevel.length() - 1);
        }

        return false;
    }
}
```

### 方法二：DFS + 记忆化

```java
import java.util.*;

class Solution {
    private Map<String, List<Character>> mapping;
    private Map<String, Boolean> memo;

    public boolean pyramidTransition(String bottom, List<String> allowed) {
        mapping = new HashMap<>();
        for (String triple : allowed) {
            String key = triple.substring(0, 2);
            mapping.computeIfAbsent(key, k -> new ArrayList<>()).add(triple.charAt(2));
        }
        memo = new HashMap<>();
        return dfs(bottom);
    }

    private boolean dfs(String current) {
        if (current.length() == 1) return true;
        if (memo.containsKey(current)) return memo.get(current);

        boolean result = buildNext(current, new StringBuilder(), 0);
        memo.put(current, result);
        return result;
    }

    private boolean buildNext(String current, StringBuilder next, int pos) {
        if (pos == current.length() - 1) {
            return dfs(next.toString());
        }
        String key = current.substring(pos, pos + 2);
        List<Character> tops = mapping.getOrDefault(key, Collections.emptyList());
        for (char top : tops) {
            next.append(top);
            if (buildNext(current, next, pos + 1)) return true;
            next.deleteCharAt(next.length() - 1);
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(A^L)，其中 A 是字母表大小（最多 7），L 是底部字符串长度。最坏情况下需要尝试所有可能的金字塔。
- **空间复杂度：** O(L^2)，递归深度为 L，每层需要存储字符串。

## 关键点总结

1. **映射表构建：** 预处理 allowed 数组，快速查找可能的上层块
2. **回溯框架：** 逐层构建，每层尝试所有可能性
3. **递归结构：** 构建完一层后，递归构建上一层
4. **剪枝优化：** 如果某个位置找不到合法的块，立即回溯
5. **记忆化：** 缓存已经计算过的层，避免重复计算

## 易错点

1. **索引越界：** 构建下一层时，循环范围是 `len(current) - 1`
2. **映射表键值：** 键是两字符组合字符串
3. **基本情况：** 长度为 1 时要返回 True，不是 0
4. **回溯逻辑：** 要尝试所有可能，找到一个成功的就返回 True
5. **空列表处理：** 如果某对块没有对应的规则，要正确处理
