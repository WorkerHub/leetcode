## 题目描述

给你整数数组 `nums`，返回无法由 `nums` 的子集 OR 得到的最小正整数。

## 解题思路

依次检查 1, 2, 4, 8, ... 等 2 的幂次，若当前幂次不在 nums 中，则它无法被 OR 表示出来，直接返回；若存在，则继续检查下一个幂次。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minImpossibleOR(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);
        // 检查每个 2 的幂次是否存在
        for (int power = 1; ; power <<= 1) {
            if (!set.contains(power)) return power;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + log M)，M 为 nums 最大值
- **空间复杂度**：O(n)

## 关键点总结

1. 若 2^k 不在 nums 中，则所有包含 2^k 位的整数都无法被表示
2. 第一个缺失的 2 的幂次即为答案
3. 用 HashSet 实现 O(1) 查找
