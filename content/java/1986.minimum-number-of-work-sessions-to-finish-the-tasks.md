## 题目描述

给定任务持续时间数组 `tasks` 和每个工作阶段最长时间 `sessionTime`，每阶段内任务总时间不超过 `sessionTime`，返回完成所有任务所需的最少工作阶段数。

## 解题思路

`n <= 14` 用状态压缩 DP。`dp[mask]` 表示完成 mask 中所有任务的最少阶段数，`rem[mask]` 表示当前阶段剩余时间（贪心最大化）。枚举下一个任务，若剩余时间够则加入当前阶段，否则开新阶段。

## Java 代码实现

### 方法一：状态压缩 DP（推荐）

```java
import java.util.*;

class Solution {
    public int minSessions(int[] tasks, int sessionTime) {
        int n = tasks.length;
        int total = 1 << n;
        int[] dp = new int[total];
        int[] rem = new int[total];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 1;
        rem[0] = sessionTime;

        for (int mask = 0; mask < total; mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) continue; // 任务i已完成
                int newMask = mask | (1 << i);
                if (rem[mask] >= tasks[i]) {
                    // 当前阶段可以容纳任务i
                    if (dp[mask] < dp[newMask] ||
                        (dp[mask] == dp[newMask] && rem[mask] - tasks[i] > rem[newMask])) {
                        dp[newMask] = dp[mask];
                        rem[newMask] = rem[mask] - tasks[i];
                    }
                } else {
                    // 需要开新阶段
                    int newSessions = dp[mask] + 1;
                    int newRem = sessionTime - tasks[i];
                    if (newSessions < dp[newMask] ||
                        (newSessions == dp[newMask] && newRem > rem[newMask])) {
                        dp[newMask] = newSessions;
                        rem[newMask] = newRem;
                    }
                }
            }
        }

        return dp[total - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(2^n)

## 关键点总结

1. `n <= 14` 决定用状态压缩 DP，bitmask 表示已完成任务集合
2. 同时维护剩余时间 `rem`，贪心最大化以减少开新阶段的概率
3. 更新条件：阶段数更少，或阶段数相同但剩余时间更多
