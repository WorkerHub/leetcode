## 题目描述

多种轮胎各有初始耗时fi和乘数ri（第k圈耗时fi*ri^(k-1)），换胎耗changeTime，求完成numLaps圈的最少时间。

## 解题思路

预处理best[k]=用一套轮胎连续跑k圈的最小时间（因ri>=2指数增长，k最多约18圈）。然后DP：dp[i]=跑完i圈最少时间，dp[i]=min(dp[i-k]+changeTime+best[k])。

## Java 代码实现

```java
class Solution {
    public int minimumFinishTime(int[][] tires, int changeTime, int numLaps) {
        int MAX_K = 18;
        long[] best = new long[MAX_K + 1];
        Arrays.fill(best, Long.MAX_VALUE);
        
        // 预处理每种轮胎连续跑k圈的最小时间
        for (int[] tire : tires) {
            long f = tire[0], r = tire[1];
            long cur = f, total = 0;
            for (int k = 1; k <= MAX_K; k++) {
                total += cur;
                best[k] = Math.min(best[k], total);
                cur *= r;
                if (cur > f + changeTime) break; // 超过换胎成本
            }
        }
        
        // DP
        int[] dp = new int[numLaps + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        
        for (int i = 1; i <= numLaps; i++) {
            for (int k = 1; k <= Math.min(i, MAX_K); k++) {
                if (best[k] == Long.MAX_VALUE) continue;
                int cost = (int) best[k] + (i - k > 0 ? changeTime : 0);
                if (dp[i - k] != Integer.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[i - k] + cost);
                }
            }
        }
        return dp[numLaps];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(numLaps * MAX_K + tires.length * MAX_K)
- **空间复杂度**：O(numLaps)

## 关键点总结

1. **指数增长限制连续圈数**：ri>=2时约18圈后超过换胎成本
2. **预处理best[k]**：所有轮胎中连续跑k圈的最小时间
3. **DP转移**：每段连续使用一套轮胎，段间加换胎时间
