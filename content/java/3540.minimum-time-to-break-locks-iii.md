## 题目描述

有 n 个锁（n <= 8），每个锁强度为 `strength[i]`。剑初始强度为 1，每轮加 k。解第 i 把锁需要 `ceil((strength[i] - cur) / k)` 轮（cur 为当前剑强度）。求解开所有锁的最少总轮数。

## 解题思路

bitmask DP：`dp[mask]` = 解开 mask 中所有锁的最少轮数。当前剑强度 = `1 + dp[mask] * k`。枚举下一把要解的锁，计算所需额外轮数并更新。

## Java 代码实现

```java
class Solution {
    public int findMinimumTime(int[] strength, int k) {
        int n = strength.length;
        int full = (1 << n) - 1;
        int[] dp = new int[1 << n];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE / 2) continue;
            long cur = 1L + (long) dp[mask] * k; // 当前剑强度
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) continue;
                // 解锁 i 所需轮数
                long needed = Math.max(0, (long) Math.ceil((double)(strength[i] - cur) / k));
                int newTime = dp[mask] + (int) needed;
                int newMask = mask | (1 << i);
                if (newTime < dp[newMask]) dp[newMask] = newTime;
            }
        }
        return dp[full];
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(2^n)

## 关键点总结

1. 剑强度随总轮数增长：`cur = 1 + dp[mask] * k`
2. 解锁所需轮数用 ceil 计算，注意当前强度 >= 目标时为 0
3. bitmask DP 枚举所有解锁顺序取最优
