## 题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

**示例 1：**
```
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

**示例 2：**
```
输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 都是 ASCII 码表中的可打印字符

## 解题思路

这是一道经典的双指针问题，也是学习原地算法的入门题。

**核心思想：**
使用两个指针，一个指向开头，一个指向末尾，不断交换并向中间移动，直到两指针相遇。

**算法流程：**
1. 左指针 left 从 0 开始，右指针 right 从 s.length-1 开始
2. 交换 s[left] 和 s[right]
3. left 向右移动，right 向左移动
4. 重复 2-3 直到 left >= right

**时间复杂度：** O(n)，遍历半个数组
**空间复杂度：** O(1)，只使用常数额外空间

## Java 代码实现

### 方法一：双指针 while 循环（标准解法）⭐

```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;

        while (left < right) {
            // 交换左右指针的字符
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;

            // 移动指针
            left++;
            right--;
        }
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

### 方法二：for 循环版本

```java
class Solution {
    public void reverseString(char[] s) {
        int n = s.length;

        // 只需遍历前半部分
        for (int i = 0; i < n / 2; i++) {
            // 交换对称位置的字符
            char temp = s[i];
            s[i] = s[n - 1 - i];
            s[n - 1 - i] = temp;
        }
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

### 方法三：递归实现

```java
class Solution {
    public void reverseString(char[] s) {
        helper(s, 0, s.length - 1);
    }

    private void helper(char[] s, int left, int right) {
        if (left >= right) return;

        // 交换
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;

        // 递归处理子问题
        helper(s, left + 1, right - 1);
    }
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)，递归调用栈的深度

**注意：** 递归方法不符合 O(1) 空间要求。

### 方法四：使用异或交换（无需临时变量）

```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;

        while (left < right) {
            // 用异或交换，无需临时变量
            s[left] ^= s[right];
            s[right] ^= s[left];
            s[left] ^= s[right];

            left++;
            right--;
        }
    }
}
```

**注意：** 异或交换在 left == right 时会将字符归零，所以需要保证 left < right。

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 是否原地 | 备注 |
|------|-----------|-----------|---------|------|
| 双指针 while | O(n) | O(1) | 是 | 标准解法 |
| 双指针 for | O(n) | O(1) | 是 | 更简洁 |
| 递归 | O(n) | O(n) | 是 | 调用栈开销 |
| 异或交换 | O(n) | O(1) | 是 | 无需临时变量 |

## 图解示例

```
输入：s = ['h','e','l','l','o']

初始状态：
 left              right
  ↓                 ↓
['h', 'e', 'l', 'l', 'o']

第一次交换：
     left      right
      ↓         ↓
['o', 'e', 'l', 'l', 'h']

第二次交换：
         left right
          ↓   ↓
['o', 'l', 'l', 'e', 'h']

left >= right，停止
```

## 关键点总结

1. **双指针技巧**：从两端向中间移动是处理对称问题的常用技巧
2. **原地操作**：通过交换实现，不使用额外数组
3. **循环条件**：left < right（不是 left <= right，因为中间元素不需要交换）
4. **Java char[]**：Java 中字符数组可以直接原地修改，不像 String 不可变
5. **边界情况**：空数组和单字符数组都能正确处理

## 易错点

1. **循环条件错误**
   ```java
   // 错误：使用 <=，会导致中间元素被交换两次
   while (left <= right) {
       char temp = s[left];
       s[left] = s[right];
       s[right] = temp;
   }

   // 正确：
   while (left < right) {
       char temp = s[left];
       s[left] = s[right];
       s[right] = temp;
       left++;
       right--;
   }
   ```

2. **忘记移动指针**
   ```java
   // 错误：死循环
   while (left < right) {
       char temp = s[left];
       s[left] = s[right];
       s[right] = temp;
       // 忘记移动指针
   }

   // 正确：
   while (left < right) {
       char temp = s[left];
       s[left] = s[right];
       s[right] = temp;
       left++;
       right--;
   }
   ```

3. **for 循环范围错误**
   ```java
   // 错误：遍历整个数组，导致反转两次
   for (int i = 0; i < s.length; i++) {
       char temp = s[i];
       s[i] = s[s.length - 1 - i];
       s[s.length - 1 - i] = temp;
   }

   // 正确：只遍历前半部分
   for (int i = 0; i < s.length / 2; i++) {
       char temp = s[i];
       s[i] = s[s.length - 1 - i];
       s[s.length - 1 - i] = temp;
   }
   ```

public String reverseString(String s) {
    // 方法1：转换成 char 数组再反转
    char[] chars = s.toCharArray();
    int left = 0, right = chars.length - 1;
    while (left < right) {
        char temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;
        left++;
        right--;
    }
    return new String(chars);

**问题3：反转单词顺序（保持单词内部不变）**
```java
// 输入："hello world"
// 输出："world hello"
public String reverseWords(String s) {
    String[] words = s.trim().split("\\s+");
    StringBuilder sb = new StringBuilder();
    for (int i = words.length - 1; i >= 0; i--) {
        sb.append(words[i]);
        if (i > 0) sb.append(" ");
    }
    return sb.toString();
}
```
