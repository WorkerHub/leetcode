## 题目描述

给定 `m x n` 矩阵 `grid`，判断是否可通过若干次水平或垂直切割，将矩阵分成若干元素之和相等的块。

## Java 代码实现

```java
class Solution {
    public boolean canPartition(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 计算行和与列和
        int[] rowSum = new int[m], colSum = new int[n];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++) {
                rowSum[i] += grid[i][j];
                colSum[j] += grid[i][j];
            }

        return canSplit(rowSum) || canSplit(colSum);
    }

    private boolean canSplit(int[] arr) {
        int total = 0;
        for (int x : arr) total += x;

        int prefix = 0;
        for (int i = 0; i < arr.length - 1; i++) {
            prefix += arr[i];
            if (total % prefix == 0) {
                // 验证每段是否等于 prefix
                int target = prefix, curr = 0;
                boolean valid = true;
                for (int x : arr) {
                    curr += x;
                    if (curr == target) curr = 0;
                    else if (curr > target) { valid = false; break; }
                }
                if (valid && curr == 0) return true;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n + (m + n)^2)
- 空间复杂度：O(m + n)

## 关键点总结

1. 水平切割等价于检查行和数组能否均等分，垂直切割同理
2. 一维等分判断：枚举前缀和，验证能否整除总和且实际每段相等
3. 只需满足一种方向的切割即可
