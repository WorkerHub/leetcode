## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是**回文串**。返回 `s` 所有可能的分割方案。

**示例 1：**
```
输入: s = "aab"
输出: [["a","a","b"],["aa","b"]]
```

**示例 2：**
```
输入: s = "a"
输出: [["a"]]
```

**提示：**
- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## 解题思路

这是一道典型的**回溯 + 动态规划优化**问题。

### 核心思想：回溯搜索所有可能的分割方案

1. **回溯框架**：从字符串开头开始，尝试所有可能的分割点
2. **剪枝优化**：只有当前子串是回文串时，才继续递归
3. **动态规划预处理**：提前计算所有子串是否为回文，避免重复判断

### 算法步骤：

1. **预处理**（可选）：使用动态规划计算所有子串是否为回文
2. **回溯搜索**：
   - 从当前位置开始，尝试每个可能的结束位置
   - 如果当前子串是回文，加入路径，继续递归
   - 递归到字符串末尾，将当前路径加入结果
   - 回溯，尝试其他分割方案

### 示例演示：

```
输入: s = "aab"

回溯树：
              ""
            /  |  \
          a    aa  aab(×)
         / \    |
       a   ab(×) b
      /
     b
   结果

路径1: ["a", "a", "b"]
路径2: ["aa", "b"]
```

## Java 代码实现

### 方法一：回溯 + DP 预处理（推荐）⭐

```java
class Solution {
    public List<List<String>> partition(String s) {
        int n = s.length();
        
        // DP 预处理：计算所有子串是否为回文
        // dp[i][j] 表示 s[i..j] 是否为回文
        boolean[][] dp = new boolean[n][n];
        
        // 每个单字符是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }
        
        // 长度为 2 的子串
        for (int i = 0; i < n - 1; i++) {
            dp[i][i + 1] = (s.charAt(i) == s.charAt(i + 1));
        }
        
        // 长度 >= 3 的子串
        for (int length = 3; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                dp[i][j] = (s.charAt(i) == s.charAt(j) && dp[i + 1][j - 1]);
            }
        }
        
        List<List<String>> result = new ArrayList<>();
        List<String> path = new ArrayList<>();
        
        backtrack(s, 0, n, dp, path, result);
        return result;
    }
    
    private void backtrack(String s, int start, int n, boolean[][] dp,
                           List<String> path, List<List<String>> result) {
        // 到达字符串末尾，记录当前路径
        if (start == n) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        // 尝试所有可能的结束位置
        for (int end = start; end < n; end++) {
            // 如果 s[start..end] 是回文
            if (dp[start][end]) {
                path.add(s.substring(start, end + 1));
                backtrack(s, end + 1, n, dp, path, result);
                path.remove(path.size() - 1);  // 回溯
            }
        }
    }
}
```

### 方法二：回溯 + 双指针判断回文

```java
class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> result = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backtrack(s, 0, path, result);
        return result;
    }
    
    private void backtrack(String s, int start, List<String> path, List<List<String>> result) {
        if (start == s.length()) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        for (int end = start; end < s.length(); end++) {
            if (isPalindrome(s, start, end)) {
                path.add(s.substring(start, end + 1));
                backtrack(s, end + 1, path, result);
                path.remove(path.size() - 1);  // 回溯
            }
        }
    }
    
    // 判断 s[left..right] 是否为回文
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 方法三：中心扩展 + 回溯

```java
class Solution {
    public List<List<String>> partition(String s) {
        int n = s.length();
        List<List<Integer>> palindromes = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            palindromes.add(new ArrayList<>());
        }
        
        // 中心扩展，预处理所有回文子串的终止位置
        for (int i = 0; i < n; i++) {
            expandAroundCenter(s, i, i, palindromes);      // 奇数长度
            expandAroundCenter(s, i, i + 1, palindromes);  // 偶数长度
        }
        
        List<List<String>> result = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backtrack(s, 0, palindromes, path, result);
        return result;
    }
    
    private void expandAroundCenter(String s, int left, int right, List<List<Integer>> palindromes) {
        int n = s.length();
        while (left >= 0 && right < n && s.charAt(left) == s.charAt(right)) {
            // s[left..right] 是回文
            palindromes.get(left).add(right);
            left--;
            right++;
        }
    }
    
    private void backtrack(String s, int start, List<List<Integer>> palindromes,
                           List<String> path, List<List<String>> result) {
        if (start == s.length()) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int end : palindromes.get(start)) {
            path.add(s.substring(start, end + 1));
            backtrack(s, end + 1, palindromes, path, result);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

设字符串长度为 n。

### 方法一：回溯 + DP 预处理
- **时间复杂度**：O(n × 2^n)
  - DP 预处理：O(n^2)
  - 回溯：最坏情况有 2^n 种分割方案，每种方案需要 O(n) 复制
- **空间复杂度**：O(n^2)，DP 数组 + 递归栈

### 方法二：回溯 + 双指针
- **时间复杂度**：O(n × 2^n)
  - 每次判断回文：O(n)
  - 回溯：2^n 种方案
- **空间复杂度**：O(n)，递归栈

## 关键点总结

1. **回溯框架**：枚举所有分割点，递归搜索所有方案
2. **剪枝优化**：只有当前子串是回文时才继续
3. **DP 预处理**：提前计算所有子串是否回文，避免重复判断
4. **路径记录**：使用 `new ArrayList<>(path)` 复制当前路径
5. **回溯操作**：`path.remove(path.size() - 1)` 恢复状态

## 易错点

1. **忘记复制路径**
   ```java
   // 错误：直接添加引用
   result.add(path);
   
   // 正确：复制路径
   result.add(new ArrayList<>(path));
   ```

2. **回文判断错误**
   ```java
   // 错误：索引范围错误
   dp[i][j] = (s.charAt(i) == s.charAt(j) && dp[i][j-1]);
   
   // 正确：内部子串
   dp[i][j] = (s.charAt(i) == s.charAt(j) && dp[i+1][j-1]);
   ```

3. **DP 初始化顺序错误**
   ```java
   // 必须按长度递增的顺序初始化
   for (int length = 3; length <= n; length++) {
       for (int i = 0; i <= n - length; i++) { ... }
   }
   ```

4. **忘记回溯**
   ```java
   path.add(s.substring(start, end + 1));
   backtrack(s, end + 1, n, dp, path, result);
   // 必须回溯
   path.remove(path.size() - 1);
   ```

5. **Java 字符串比较**
   ```java
   // Java 中用 charAt 比较字符，不能用 == 比较字符串
   s.charAt(i) == s.charAt(j)  // 正确
   ```
