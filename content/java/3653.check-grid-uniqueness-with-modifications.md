## 题目描述

给你一个 `m x n` 的矩阵 `grid` 和修改列表 `mods`（`mods[i] = [r, c, val]`），应用所有修改后，判断矩阵每行每列是否都包含唯一元素。

## 解题思路

先应用所有修改，再检验每行每列是否有重复元素（集合大小等于元素数则无重复）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean checkUniqueness(int[][] grid, int[][] mods) {
        int m = grid.length, n = grid[0].length;
        // 深拷贝 grid
        int[][] g = new int[m][n];
        for (int i = 0; i < m; i++) g[i] = grid[i].clone();

        // 应用所有修改
        for (int[] mod : mods) g[mod[0]][mod[1]] = mod[2];

        // 检查每行
        for (int i = 0; i < m; i++) {
            Set<Integer> seen = new HashSet<>();
            for (int j = 0; j < n; j++) {
                if (!seen.add(g[i][j])) return false;
            }
        }

        // 检查每列
        for (int j = 0; j < n; j++) {
            Set<Integer> seen = new HashSet<>();
            for (int i = 0; i < m; i++) {
                if (!seen.add(g[i][j])) return false;
            }
        }

        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n + len(mods))
- 空间复杂度：O(m * n)

## 关键点总结

1. 先应用所有修改，再统一检验
2. 用 HashSet 检测重复元素，`add` 返回 false 表示有重复
3. 行列分开检验
