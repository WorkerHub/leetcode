## 题目描述

给定数组 `arr`、`brr` 和整数 `k`，每次可将 `arr` 任意元素加减 1（代价 1），或将整个 `arr` 排序（代价 k），返回使 `arr` 等于 `brr` 的最小总代价。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minCost(int[] arr, int[] brr, long k) {
        int n = arr.length;

        // 策略 1：不排序，逐位调整
        long cost1 = 0;
        for (int i = 0; i < n; i++) cost1 += Math.abs((long) arr[i] - brr[i]);

        // 策略 2：排序一次（代价 k）后逐位匹配
        int[] sortedArr = arr.clone();
        int[] sortedBrr = brr.clone();
        Arrays.sort(sortedArr);
        Arrays.sort(sortedBrr);
        long cost2 = k;
        for (int i = 0; i < n; i++) cost2 += Math.abs((long) sortedArr[i] - sortedBrr[i]);

        return Math.min(cost1, cost2);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(n)

## 关键点总结

1. 两种策略：排序或不排序。
2. 排序后按位置匹配是最优的（贪心：小的配小的，大的配大的）。
3. 使用 `long` 防止溢出。
