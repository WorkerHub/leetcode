## 题目描述

给定查询数组和固定长度intLength，找出每个查询对应的第k个该长度回文整数。

## 解题思路

intLength位回文数由前半部分决定。前半部分长度为(intLength+1)/2，第k个的前半部分=10^(half-1)+k-1，拼接镜像得回文数。

## Java 代码实现

```java
class Solution {
    public long[] kthPalindrome(int[] queries, int intLength) {
        int half = (intLength + 1) / 2;
        long start = (long) Math.pow(10, half - 1);
        long end = (long) Math.pow(10, half) - 1;
        
        long[] result = new long[queries.length];
        for (int q = 0; q < queries.length; q++) {
            long prefix = start + queries[q] - 1;
            if (prefix > end) {
                result[q] = -1;
                continue;
            }
            // 构造回文数
            String prefixStr = String.valueOf(prefix);
            StringBuilder sb = new StringBuilder(prefixStr);
            // 镜像部分：偶数长度反转整个前缀，奇数长度反转去掉最后一位
            int mirrorStart = intLength % 2 == 0 ? half - 1 : half - 2;
            for (int i = mirrorStart; i >= 0; i--) {
                sb.append(prefixStr.charAt(i));
            }
            result[q] = Long.parseLong(sb.toString());
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(Q * intLength)
- **空间复杂度**：O(intLength)

## 关键点总结

1. **前半部分决定回文**：后半部分是前半的镜像
2. **第k个前半部分**：10^(half-1) + k - 1
3. **奇偶处理不同**：奇数长度镜像时去掉中间字符
