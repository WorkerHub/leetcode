## 题目描述

给你路段距离数组 `dist`、速度 `speed` 和时限 `hoursBefore`，每段路后需等到整点才能继续（可跳过休息），返回在时限内到达所需的最少跳过次数，无法到达返回 -1。

## 解题思路

DP：`dp[i][j]` 表示通过前 i 条路恰好跳过 j 次所需的最短距离（乘以 speed 转为整数避免浮点误差）。不跳过则向上取整到 speed 的倍数，跳过则直接累加。

## Java 代码实现

```java
class Solution {
    public int minSkips(int[] dist, int speed, int hoursBefore) {
        int n = dist.length;
        long INF = Long.MAX_VALUE / 2;
        // dp[i][j] = 前 i 条路跳过 j 次的最短距离（*speed）
        long[][] dp = new long[n + 1][n + 1];
        for (long[] row : dp) java.util.Arrays.fill(row, INF);
        dp[0][0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= i; j++) {
                // 不跳过第 i 段后的休息
                if (j < i && dp[i - 1][j] != INF) {
                    long val = dp[i - 1][j] + dist[i - 1];
                    // 向上取整到 speed 的倍数
                    long rounded = ((val + speed - 1) / speed) * speed;
                    dp[i][j] = Math.min(dp[i][j], rounded);
                }
                // 跳过第 i 段后的休息
                if (j > 0 && dp[i - 1][j - 1] != INF) {
                    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j - 1] + dist[i - 1]);
                }
            }
        }

        for (int j = 0; j <= n; j++) {
            if (dp[n][j] <= (long) hoursBefore * speed) {
                return j;
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n^2)

## 关键点总结

1. 用整数避免浮点精度问题：所有时间乘以 speed 转为距离
2. 整数向上取整到 speed 的倍数：`(x + speed - 1) / speed * speed`
3. 最后一条路后不需要等待，跳过次数范围为 0 到 n
