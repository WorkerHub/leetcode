## 题目描述

给你一个整数 `n`，请你返回所有 `0 < numerator < denominator <= n` 且是**最简分数**的分数列表。

最简分数要求分子和分母的**最大公约数（GCD）等于 1**。

可以以任意顺序返回答案。

**示例 1：**
```
输入：n = 2
输出：["1/2"]
解释：1/2 是唯一满足条件的最简分数，因为 gcd(1,2) = 1。
```

**示例 2：**
```
输入：n = 3
输出：["1/2","1/3","2/3"]
```

**示例 3：**
```
输入：n = 4
输出：["1/2","1/3","1/4","2/3","3/4"]
解释：2/4 不是最简分数，因为 gcd(2,4) = 2。
```

**示例 4：**
```
输入：n = 1
输出：[]
解释：不存在满足条件的分数（分子必须严格小于分母且 > 0）。
```

**提示：**
- `1 <= n <= 100`

## 解题思路

**暴力枚举 + GCD 判断：**

枚举所有满足 `1 <= numerator < denominator <= n` 的分数对，判断 `gcd(numerator, denominator) == 1` 即为最简分数。

**GCD（最大公约数）：** 欧几里得算法（辗转相除法）是计算 GCD 的经典算法，时间复杂度 O(log min(a,b))。

**时间复杂度：** O(n² * log n)，外层两重循环 O(n²)，每次 gcd 计算 O(log n)。

## Java 代码实现

### 方法一：双重循环 + GCD（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> simplifiedFractions(int n) {
        List<String> result = new ArrayList<>();
        for (int denominator = 2; denominator <= n; denominator++) {
            for (int numerator = 1; numerator < denominator; numerator++) {
                // 判断是否为最简分数（gcd 为 1）
                if (gcd(numerator, denominator) == 1) {
                    result.add(numerator + "/" + denominator);
                }
            }
        }
        return result;
    }

    // 欧几里得算法求最大公约数
    private int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
}
```

### 方法二：使用 StringBuilder 优化字符串拼接

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> simplifiedFractions(int n) {
        List<String> result = new ArrayList<>();
        for (int den = 2; den <= n; den++) {
            for (int num = 1; num < den; num++) {
                if (gcd(num, den) == 1) {
                    result.add(num + "/" + den);
                }
            }
        }
        return result;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);  // 递归版欧几里得算法
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n² log n)，双重循环 O(n²)，每次 `gcd` 调用 O(log n)。
- **空间复杂度：** O(1)（不计输出列表）。

## 图解示例

```
n = 4

枚举：
  den=2: num=1, gcd(1,2)=1 -> "1/2"
  den=3: num=1, gcd(1,3)=1 -> "1/3"
         num=2, gcd(2,3)=1 -> "2/3"
  den=4: num=1, gcd(1,4)=1 -> "1/4"
         num=2, gcd(2,4)=2 -> 跳过（非最简）
         num=3, gcd(3,4)=1 -> "3/4"

结果：["1/2","1/3","2/3","1/4","3/4"]
```

## 关键点总结

1. 最简分数 = 分子分母互质 = `gcd(分子, 分母) == 1`。
2. 欧几里得算法（辗转相除法）是计算 GCD 的经典算法，时间复杂度 O(log min(a,b))。
3. Java 中可以用 `num + "/" + den` 直接拼接字符串。

## 易错点

- 条件应为 `0 < num < den <= n`，而非 `1 <= num <= den`（分子严格小于分母）。
- 枚举顺序：外层枚举分母，内层枚举分子（`num < den`），确保分数 `< 1`。
- `n=1` 时没有有效分数，直接返回空列表（循环不会执行，自然处理）。
