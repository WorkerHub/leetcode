## 题目描述

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

**示例 1：**
```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

**示例 2：**
```
输入：lists = []
输出：[]
```

**示例 3：**
```
输入：lists = [[]]
输出：[]
```

**提示：**
- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按升序排列
- `lists[i].length` 的总和不超过 `10^4`

## 解题思路

这道题是合并两个有序链表的升级版，有多种解法：

**方法对比：**
1. **暴力法**：收集所有节点，排序后重建链表
2. **逐一合并**：依次合并两个链表
3. **分治法**：类似归并排序（推荐）
4. **优先队列（堆）**：每次取最小的节点

## Java 代码实现

### 方法一：分治法（推荐）

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }
        // 分治合并
        return merge(lists, 0, lists.length - 1);
    }

    private ListNode merge(ListNode[] lists, int left, int right) {
        // 只有一个链表
        if (left == right) {
            return lists[left];
        }
        // 分治
        int mid = (left + right) / 2;
        ListNode l1 = merge(lists, left, mid);
        ListNode l2 = merge(lists, mid + 1, right);
        // 合并两个有序链表
        return mergeTwoLists(l1, l2);
    }

    private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }

        current.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

### 方法二：优先队列（堆）

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // 优先队列，按节点值升序排列
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);

        // 将所有链表的头节点加入堆
        for (ListNode node : lists) {
            if (node != null) {
                pq.offer(node);
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        while (!pq.isEmpty()) {
            // 取出最小的节点
            ListNode node = pq.poll();
            current.next = node;
            current = current.next;

            // 如果该链表还有下一个节点，加入堆
            if (node.next != null) {
                pq.offer(node.next);
            }
        }

        return dummy.next;
    }
}
```

### 方法三：逐一合并

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }

        ListNode result = null;
        for (ListNode lst : lists) {
            result = mergeTwoLists(result, lst);
        }

        return result;
    }

    private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }

        current.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

## 复杂度分析

设 k 为链表数量，n 为所有节点总数。

**方法一（分治法）：**
- 时间复杂度：O(n log k)
  - 分治的深度为 log k
  - 每层合并的总节点数为 n
- 空间复杂度：O(log k)，递归调用栈

**方法二（堆）：**
- 时间复杂度：O(n log k)
  - 每个节点进出堆一次，堆操作为 O(log k)
- 空间复杂度：O(k)，堆的大小

**方法三（逐一合并）：**
- 时间复杂度：O(kn)
  - 第一次合并：n1 + n2
  - 第二次合并：(n1 + n2) + n3
  - ...
  - 总计约 O(kn)
- 空间复杂度：O(1)

## 关键点总结

1. **分治思想**：将 k 个链表分成两半，递归合并
2. **堆的应用**：维护 k 个链表的当前最小值
3. **合并两链表**：基础操作，需要熟练掌握
4. **Lambda 比较器**：Java 中使用 `(a, b) -> a.val - b.val` 定义优先级

## 易错点

1. **空链表处理**：
   - 空数组 `lists = []`
   - 包含空链表 `lists = [[]]`
2. **PriorityQueue 排序**：自定义比较器按节点值升序排列
3. **分治边界**：`left == right` 时返回单个链表
4. **空指针**：加入堆前要检查节点是否为 null
