## 题目描述

两个整数的汉明距离指的是这两个数字的二进制数对应位不同的数量。

给你一个整数数组 `nums`，请你计算并返回 `nums` 中任意两个数之间汉明距离的总和。

**示例 1：**
```
输入：nums = [4,14,2]
输出：6
解释：在二进制表示中，4 表示为 0100，14 表示为 1110，2表示为 0010。（这样表示是为了体现后四位之间关系）
所以答案为：
HammingDistance(4, 14) + HammingDistance(4, 2) + HammingDistance(14, 2) = 2 + 2 + 2 = 6
```

**示例 2：**
```
输入：nums = [4,14,4]
输出：4
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^9`

## 解题思路

**暴力法：** 两两计算汉明距离，O(n^2 × 32)，会超时。

**优化思路：** 按位统计
- 对于每一位，统计有多少个数该位为 1，多少个为 0
- 该位对总汉明距离的贡献 = count_1 × count_0

## Java 代码实现

### 方法一：按位统计（推荐）⭐

```java
class Solution {
    public int totalHammingDistance(int[] nums) {
        int total = 0;
        int n = nums.length;

        // 遍历每一位（最多 32 位）
        for (int bit = 0; bit < 32; bit++) {
            int count1 = 0;

            // 统计该位为 1 的数字个数
            for (int num : nums) {
                if (((num >> bit) & 1) == 1) {
                    count1++;
                }
            }

            // 该位的贡献：count1 个 1 与 (n - count1) 个 0 配对
            int count0 = n - count1;
            total += count1 * count0;
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(32n) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **按位统计：** 避免两两比较
2. **贡献计算：** count1 × count0
3. **位运算：** `(num >> bit) & 1`
