## 题目描述

给定 `m x n` 网格，从中选 `k` 个格子放棋子，返回所有放置方案中所有棋子对的曼哈顿距离之和的总和，对 `10^9 + 7` 取模。

## Java 代码实现

```java
class Solution {
    static final long MOD = 1_000_000_007;

    public int distanceSum(int m, int n, int k) {
        long mn = (long) m * n;

        // 行距离和 = n^2 * sum_{d=1}^{m-1} d*(m-d)
        long rowDist = 0;
        for (long d = 1; d < m; d++) {
            rowDist = (rowDist + d % MOD * ((m - d) % MOD)) % MOD;
        }
        rowDist = rowDist * (n % MOD) % MOD * (n % MOD) % MOD;

        // 列距离和 = m^2 * sum_{d=1}^{n-1} d*(n-d)
        long colDist = 0;
        for (long d = 1; d < n; d++) {
            colDist = (colDist + d % MOD * ((n - d) % MOD)) % MOD;
        }
        colDist = colDist * (m % MOD) % MOD * (m % MOD) % MOD;

        long total = (rowDist + colDist) % MOD;

        // 每对格子被 k 个棋子覆盖的方案数 = C(mn-2, k-2)
        long ways = comb(mn - 2, k - 2);

        return (int)(total * ways % MOD);
    }

    // 乘法公式计算 C(N, r) mod MOD（r 较小）
    private long comb(long N, int r) {
        if (r < 0 || N < r) return 0;
        long num = 1, den = 1;
        for (int i = 0; i < r; i++) {
            num = num * ((N - i) % MOD) % MOD;
            den = den * (i + 1) % MOD;
        }
        return num * modPow(den, MOD - 2, MOD) % MOD;
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m + n + k)，行列循环与组合数计算
- 空间复杂度：O(1)

## 关键点总结

1. 曼哈顿距离分解为行差与列差，分别累计所有格子对的贡献
2. 行距离和 = `n^2 * sum_{d=1}^{m-1} d*(m-d)`，列对称
3. 每对格子被包含的方案数 = C(mn-2, k-2)，用乘法公式避免大数组
