## 题目描述

给定整数数组 `nums` 和整数 `k`，返回异或值恰好等于 `k` 的子集数目（模 `10^9+7`）。

## Java 代码实现

```java
class Solution {
    public int countSubsets(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        final int MAX = 1 << 20; // nums[i] <= 10^6 < 2^20
        long[] dp = new long[MAX];
        dp[0] = 1; // 空集

        for (int num : nums) {
            long[] newDp = dp.clone();
            for (int x = 0; x < MAX; x++) {
                if (dp[x] > 0) {
                    newDp[x ^ num] = (newDp[x ^ num] + dp[x]) % MOD;
                }
            }
            dp = newDp;
        }
        return (int) dp[k];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 2^20)
- 空间复杂度：O(2^20)

## 关键点总结

1. 异或 DP：dp[x] = 异或值为 x 的子集数目，初始 dp[0]=1
2. 每次用新数组 newDp 存储更新结果，避免同一元素被多次选取
3. dp 数组大小为 2^20（覆盖所有可能的异或值）
