## 题目描述

偶数堆石子排成一行，Alice 和 Bob 轮流从两端取整堆石子（Alice 先手）。石子总数为奇数。判断 Alice 是否必胜。

**示例：**
```
输入：piles = [5,3,4,5]
输出：true
```

## 解题思路

数学结论：偶数堆 + 奇数总和 → Alice 必胜。她可以选择拿所有奇数位或偶数位中较大的一组。

### DP 解法（学习用）

```java
class Solution {
    public boolean stoneGameDP(int[] piles) {
        int n = piles.length;
        // dp[i][j] 表示面对 piles[i..j] 先手能多拿多少
        int[][] dp = new int[n][n];
        for (int i = 0; i < n; i++) dp[i][i] = piles[i];

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = Math.max(piles[i] - dp[i + 1][j], piles[j] - dp[i][j - 1]);
            }
        }
        return dp[0][n - 1] > 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（数学解）/ O(n²)（DP 解）
- **空间复杂度**：O(1) / O(n²)

## 关键点总结

1. **数学必胜**：偶数堆先手可控制奇偶位选择
2. **博弈 DP**：dp[i][j] = 先手最大领先差值
3. **状态转移**：选左或选右取最大
