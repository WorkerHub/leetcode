## 题目描述

给你一个字符串 `s`，请你判断它是否有效。

字符串 `s` 有效需要满足：假设开始有一个空字符串 `t = ""`，你可以执行任意次下述操作将 `t` 转换为 `s`：
- 将字符串 `"abc"` 插入到 `t` 中的任意位置。形式上，`t` 变为 `tleft + "abc" + tright`，其中 `t == tleft + tright`。注意，`tleft` 和 `tright` 可能为空。

如果字符串 `s` 有效，则返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。
```

**示例 2：**
```
输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。
```

**示例 3：**
```
输入：s = "abccba"
输出：false
```

**提示：**
- `1 <= s.length <= 2 * 10^4`
- `s` 由字母 `'a'`、`'b'` 和 `'c'` 组成

## 解题思路

这道题的本质是**括号匹配**的变形，只不过这里匹配的是 `"abc"` 这个序列。

**核心思想：**
1. 如果字符串有效，我们可以反向操作：不断删除 `"abc"` 子串
2. 如果最终字符串变为空，说明原字符串有效
3. 这个过程可以用**栈**来高效实现

**算法流程：**
1. 遍历字符串的每个字符
2. 将字符压入栈
3. 每次压栈后，检查栈顶是否形成 `"abc"` 序列
4. 如果形成 `"abc"`，则弹出这三个字符（相当于删除）
5. 最后检查栈是否为空

**为什么用栈？**
- 栈可以方便地检查最近添加的字符
- 栈可以高效地删除匹配的序列
- 时间复杂度 O(n)，空间复杂度 O(n)

## Java 代码实现

### 方法一：栈（推荐）

```java
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            // 将字符压入栈
            stack.push(c);

            // 检查栈顶是否形成 "abc"（至少有 3 个元素）
            if (stack.size() >= 3) {
                // 取栈顶三个元素检查
                char top1 = stack.pop();  // 最顶层（对应 'c'）
                char top2 = stack.pop();  // 次顶层（对应 'b'）
                char top3 = stack.pop();  // 第三层（对应 'a'）

                if (top3 == 'a' && top2 == 'b' && top1 == 'c') {
                    // 匹配成功，不把这三个字符放回去
                } else {
                    // 不匹配，放回去
                    stack.push(top3);
                    stack.push(top2);
                    stack.push(top1);
                }
            }
        }

        // 如果栈为空，说明所有字符都被成功匹配
        return stack.isEmpty();
    }
}
```

### 方法二：优化版（遇到 'c' 时检查）

```java
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == 'c') {
                // 如果当前是 'c'，检查前两个是否是 'a' 和 'b'
                if (stack.size() < 2) return false;
                char top1 = stack.pop(); // 应该是 'b'
                char top2 = stack.pop(); // 应该是 'a'
                if (top2 != 'a' || top1 != 'b') return false;
            } else {
                stack.push(c);
            }
        }

        // 如果栈为空，说明有效
        return stack.isEmpty();
    }
}
```

### 方法三：使用 StringBuilder 模拟栈

```java
class Solution {
    public boolean isValid(String s) {
        StringBuilder sb = new StringBuilder();

        for (char c : s.toCharArray()) {
            sb.append(c);
            // 检查末尾是否形成 "abc"
            int len = sb.length();
            if (len >= 3 &&
                sb.charAt(len - 3) == 'a' &&
                sb.charAt(len - 2) == 'b' &&
                sb.charAt(len - 1) == 'c') {
                // 删除末尾三个字符
                sb.delete(len - 3, len);
            }
        }

        return sb.length() == 0;
    }
}
```

## 复杂度分析

**方法一（栈）：**
- **时间复杂度：** O(n)，每个字符最多入栈和出栈一次
- **空间复杂度：** O(n)，最坏情况栈的大小

**方法三（StringBuilder）：**
- **时间复杂度：** O(n)，每个字符最多被处理两次
- **空间复杂度：** O(n)，StringBuilder 的大小

## 关键点总结

1. **问题转换**：插入操作的逆操作是删除，问题可以转换为不断删除 `"abc"`
2. **栈的应用**：栈适合处理"最近添加的元素"相关的问题
3. **匹配模式**：类似括号匹配，但这里匹配的是三字符序列
4. **优化技巧**：在遇到特定字符（如 'c'）时再检查，可以减少检查次数
5. **Java 栈**：Java 中推荐使用 ArrayDeque 而不是 Stack 类

## 易错点

1. **边界检查**：检查栈顶前要确保栈中至少有 3 个元素
2. **弹出顺序**：Java 中栈是后进先出，弹出顺序要注意
3. **空字符串**：空字符串应该返回 `true`（符合题意：从空字符串开始）
4. **ArrayDeque vs Stack**：Java 中 ArrayDeque 作为栈使用时，push/pop 操作的顺序要熟悉
