## 题目描述

给定 `n` 个骰子，每个有 `k` 个面（面值 1 到 k），返回所有可能的点数之和的集合（不重复）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> diceOutcomes(int n, int k) {
        // n 个骰子（面值 1..k）的可能总和为连续区间 [n, n*k]
        List<Integer> result = new ArrayList<>();
        for (int s = n; s <= n * k; s++) result.add(s);
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)（结果大小）
- 空间复杂度：O(n * k)

## 关键点总结

1. n 个连续面值骰子的总和覆盖连续区间 [n, n*k]
2. 每次将某个骰子的值增加 1 即可使总和增加 1，覆盖所有中间值
3. 直接生成 range(n, n*k+1) 无需 DP
