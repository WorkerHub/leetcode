## 题目描述

给你棋盘坐标字符串（如 "a1"），若该格是白色返回 `true`，黑色返回 `false`。

## 解题思路

列字母序号（a=1,...,h=8）与行数字之和为奇数则是白色，为偶数则是黑色。等价地，用两个字符的 ASCII 码异或最低位判断。

## Java 代码实现

```java
class Solution {
    public boolean squareIsWhite(String coordinates) {
        // 两个字符 ASCII 码异或，若最低位为 1 则是白色
        return ((coordinates.charAt(0) ^ coordinates.charAt(1)) & 1) == 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. `(col序号 + row数字) % 2 == 1` 为白色；等价于两字符 ASCII 异或最低位
2. `'a'=97`（奇），`'1'=49`（奇），异或最低位为 0 → 黑色（符合 a1 为黑色）
