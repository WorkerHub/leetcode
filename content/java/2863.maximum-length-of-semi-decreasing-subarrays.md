## 题目描述

给你整数数组 nums，若子数组第一个元素严格大于最后一个元素则为半递减子数组，返回最长半递减子数组的长度。

## 解题思路

单调栈：从左到右建严格递减栈存潜在起点下标，从右向左遍历末尾位置 j，弹出不满足 `nums[i] > nums[j]` 的起点，栈底（最远位置）即为最优起点。

## Java 代码实现

```java
class Solution {
    public int maxSubarrayLength(int[] nums) {
        int n = nums.length;
        // 从左到右构建严格递减的单调栈（存下标）
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (stack.isEmpty() || nums[stack.peekLast()] > nums[i]) {
                stack.addLast(i);
            }
        }

        int ans = 0;
        // 从右向左遍历，找每个 j 对应的最远合法起点
        for (int j = n - 1; j >= 0; j--) {
            // 弹出不满足 nums[i] > nums[j] 的（栈顶）
            while (!stack.isEmpty() && nums[stack.peekLast()] <= nums[j]) {
                stack.pollLast();
            }
            if (!stack.isEmpty()) {
                // 栈底是最远满足条件的起点
                ans = Math.max(ans, j - ((ArrayDeque<Integer>) stack).peekFirst());
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 单调递减栈记录左侧所有潜在起点（严格递减）
2. 从右到左遍历末尾位置，弹出不满足条件的栈顶
3. 栈底（最远位置）是最优起点，答案为 `j - stack[0]`
