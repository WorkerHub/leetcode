## 题目描述

给定房间列表(id,size)和查询(preferred,minSize)，找满足size>=minSize且id最接近preferred的房间。等距取较小id。

## 解题思路

离线查询：按minSize降序处理查询，房间按size降序排入TreeSet，对每个查询用ceiling/floor二分找最近id。

## Java 代码实现

```java
class Solution {
    public int[] closestRoom(int[][] rooms, int[][] queries) {
        int n = rooms.length, q = queries.length;
        // 给查询加上原始下标
        int[][] sortedQueries = new int[q][3];
        for (int i = 0; i < q; i++) {
            sortedQueries[i] = new int[]{queries[i][0], queries[i][1], i};
        }
        // 查询按minSize降序
        Arrays.sort(sortedQueries, (a, b) -> b[1] - a[1]);
        // 房间按size降序
        Arrays.sort(rooms, (a, b) -> b[1] - a[1]);
        
        TreeSet<Integer> ids = new TreeSet<>();
        int[] result = new int[q];
        int roomPtr = 0;
        
        for (int[] query : sortedQueries) {
            int preferred = query[0], minSize = query[1], idx = query[2];
            // 将size >= minSize的房间加入TreeSet
            while (roomPtr < n && rooms[roomPtr][1] >= minSize) {
                ids.add(rooms[roomPtr][0]);
                roomPtr++;
            }
            
            if (ids.isEmpty()) {
                result[idx] = -1;
                continue;
            }
            
            // 查找最近的id
            Integer floor = ids.floor(preferred);
            Integer ceil = ids.ceiling(preferred);
            int best = -1;
            if (floor != null && ceil != null) {
                // 等距取较小id
                best = (preferred - floor <= ceil - preferred) ? floor : ceil;
            } else if (floor != null) {
                best = floor;
            } else {
                best = ceil;
            }
            result[idx] = best;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + Q) log N)
- **空间复杂度**：O(N + Q)

## 关键点总结

1. **离线处理**：按minSize降序，房间单调加入
2. **TreeSet**：floor/ceiling实现O(log N)最近查找
3. **等距取较小**：floor优先（preferred - floor <= ceil - preferred）
