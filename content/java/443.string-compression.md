## 题目描述

给你一个字符数组 chars，请使用下述算法压缩：

从一个空字符串 s 开始。对于 chars 中的每组连续重复字符：

- 如果这一组长度为 1，则将字符追加到 s 中。
- 否则，需要向 s 追加字符，后跟这一组的长度。

压缩后得到的字符串 s 不应该直接返回，需要转储到字符数组 chars 中。需要注意的是，如果组长度为 10 或 10 以上，则在 chars 数组中会被拆分为多个字符。

请在修改完输入数组后，返回该数组的新长度。

你必须设计并实现一个只使用常量额外空间的算法来解决此问题。

**示例 1:**

```
输入: chars = ["a","a","b","b","c","c","c"]
输出: 返回 6，输入数组的前 6 个字符应该是：["a","2","b","2","c","3"]
解释: "aa" 被 "a2" 替代。"bb" 被 "b2" 替代。"ccc" 被 "c3" 替代。
```

**示例 2:**

```
输入: chars = ["a"]
输出: 返回 1，输入数组的前 1 个字符应该是：["a"]
解释: 唯一的组是 "a"，它保持未压缩，因为它是单个字符。
```

**示例 3:**

```
输入: chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
输出: 返回 4，输入数组的前 4 个字符应该是：["a","b","1","2"]
解释: 由于字符 "a" 不重复，所以不会被压缩。"bbbbbbbbbbbb" 被 "b12" 替代。
```

**提示:**

- 1 <= chars.length <= 2000
- chars[i] 可以是小写英文字母、大写英文字母、数字或符号

## 解题思路

这道题需要**原地修改**数组，使用**双指针**技术来实现字符串压缩。

**核心思路：**

1. **读指针 i**：遍历原数组，找到每组相同字符
2. **写指针 write**：记录压缩后应该写入的位置
3. **分组统计**：对每组连续相同字符进行计数
4. **写入规则**：
   - 先写入字符本身
   - 如果计数 > 1，将计数转为字符串逐个写入

**关键点：**
- 必须原地修改，空间复杂度 O(1)
- 处理多位数字（如 12 要拆分为 '1', '2'）
- 返回新数组的有效长度

## Java 代码实现

### 方法一：双指针法（推荐）

```java
class Solution {
    public int compress(char[] chars) {
        /**
         * 双指针原地压缩
         * 时间复杂度: O(n)
         * 空间复杂度: O(1)
         */
        int write = 0;  // 写指针
        int i = 0;      // 读指针

        while (i < chars.length) {
            char c = chars[i];
            int count = 0;

            // 统计当前字符出现次数
            while (i < chars.length && chars[i] == c) {
                count++;
                i++;
            }

            // 写入字符
            chars[write++] = c;

            // 如果计数大于 1，写入数字
            if (count > 1) {
                // 将数字转为字符串，逐个字符写入
                for (char digit : String.valueOf(count).toCharArray()) {
                    chars[write++] = digit;
                }
            }
        }

        return write;
    }
}
```

### 方法二：更简洁的双指针实现

```java
class Solution {
    public int compress(char[] chars) {
        /**
         * 简化版双指针
         */
        int write = 0;
        int i = 0;
        int n = chars.length;

        while (i < n) {
            // 记录当前字符组的起始位置
            int start = i;
            char currentChar = chars[i];

            // 移动 i 直到遇到不同字符
            while (i < n && chars[i] == currentChar) {
                i++;
            }

            // 写入字符
            chars[write++] = currentChar;

            // 计算长度
            int length = i - start;
            if (length > 1) {
                // 写入长度的每一位数字
                for (char c : String.valueOf(length).toCharArray()) {
                    chars[write++] = c;
                }
            }
        }

        return write;
    }
}
```

### 方法三：手动处理数字写入（不依赖 String.valueOf）

```java
class Solution {
    public int compress(char[] chars) {
        /**
         * 手动写入数字，不借助字符串转换
         */
        int write = 0;
        int i = 0;

        while (i < chars.length) {
            char c = chars[i];
            int count = 0;

            while (i < chars.length && chars[i] == c) {
                count++;
                i++;
            }

            chars[write++] = c;

            if (count > 1) {
                // 将数字逐位写入：先确定位数，再从高位到低位写
                int numStart = write;
                while (count > 0) {
                    chars[write++] = (char)('0' + count % 10);
                    count /= 10;
                }
                // 反转数字部分（因为是从低位到高位写入的）
                int left = numStart, right = write - 1;
                while (left < right) {
                    char tmp = chars[left];
                    chars[left++] = chars[right];
                    chars[right--] = tmp;
                }
            }
        }

        return write;
    }
}
```

## 复杂度分析

**方法一和方法二：**
- 时间复杂度：O(n)，每个字符最多访问两次
- 空间复杂度：O(1)，只使用常量额外空间

**方法三：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)，完全不使用额外字符串

## 关键点总结

1. **双指针技巧**：读指针遍历原数组，写指针记录压缩后的位置
2. **分组统计**：使用内层循环统计每组相同字符的数量
3. **数字拆分**：`String.valueOf(count).toCharArray()` 将数字转为字符数组逐位写入
4. **原地修改**：不使用额外数组，直接在原数组上操作
5. **返回长度**：write 指针的最终位置就是新数组的长度

## 易错点

1. **忘记处理多位数**：
   ```java
   // 错误：直接写入 int 类型
   chars[write] = (char) count;  // 这写入的是 ASCII 码，不是数字字符

   // 正确：拆分数字写入
   for (char digit : String.valueOf(count).toCharArray()) {
       chars[write++] = digit;
   }
   ```

2. **单字符不写数字**：
   - count == 1 时，只写字符，不写 "1"
   - 这是题目的明确要求

3. **边界条件**：
   - 只有一个字符的情况
   - 所有字符都相同的情况
   - 字符串末尾的处理

4. **读写指针混淆**：
   - 读指针用于遍历和统计
   - 写指针用于记录压缩后的位置
   - 两者速度不同，不能混用
