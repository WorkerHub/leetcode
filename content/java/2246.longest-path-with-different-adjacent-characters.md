## 题目描述

树中找最长路径，要求路径上相邻节点字符不同，返回路径节点数。

## 解题思路

树形DP：对每个节点维护最长和次长的子链（子节点字符不同才延伸），答案为最大的top1+top2+1。

## Java 代码实现

```java
class Solution {
    private List<List<Integer>> children;
    private String s;
    private int ans;

    public int longestPath(int[] parent, String s) {
        int n = parent.length;
        this.s = s;
        this.ans = 1;
        children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parent[i]).add(i);
        dfs(0);
        return ans;
    }

    private int dfs(int u) {
        int top1 = 0, top2 = 0;
        for (int v : children.get(u)) {
            int down = dfs(v);
            if (s.charAt(v) == s.charAt(u)) continue;
            if (down > top1) { top2 = top1; top1 = down; }
            else if (down > top2) top2 = down;
        }
        ans = Math.max(ans, top1 + top2 + 1);
        return top1 + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **树形DP**：每个节点合并最长两条子链
2. **字符不同才延伸**：相同字符跳过但子树仍需处理
3. **答案更新**：top1+top2+1为通过当前节点的最长路径
