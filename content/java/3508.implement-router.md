## 题目描述

设计路由器，支持：`addPacket(source, destination, timestamp)` 去重添加（内存满时移除最旧包）、`forwardPacket()` 转发最旧包、`getCount(destination, startTime, endTime)` 查询目的地在时间段内的数据包数。

## 解题思路

三种数据结构组合：1) 双端队列维护插入顺序；2) HashSet 实现 O(1) 去重；3) `HashMap<destination, TreeMap<timestamp, count>>` 支持高效区间计数（subMap + 求和）。

## Java 代码实现

```java
import java.util.*;

class Router {
    private final int limit;
    private final Deque<int[]> queue;
    private final Set<String> seen;
    private final Map<Integer, TreeMap<Integer, Integer>> destTs;

    public Router(int memoryLimit) {
        this.limit = memoryLimit;
        this.queue = new ArrayDeque<>();
        this.seen = new HashSet<>();
        this.destTs = new HashMap<>();
    }

    public boolean addPacket(int source, int destination, int timestamp) {
        String key = source + "," + destination + "," + timestamp;
        if (seen.contains(key)) return false;
        if (queue.size() >= limit) {
            int[] old = queue.pollFirst();
            seen.remove(old[0] + "," + old[1] + "," + old[2]);
            removeFromDestTs(old[1], old[2]);
        }
        queue.addLast(new int[]{source, destination, timestamp});
        seen.add(key);
        destTs.computeIfAbsent(destination, d -> new TreeMap<>())
              .merge(timestamp, 1, Integer::sum);
        return true;
    }

    public int[] forwardPacket() {
        if (queue.isEmpty()) return new int[0];
        int[] pkt = queue.pollFirst();
        seen.remove(pkt[0] + "," + pkt[1] + "," + pkt[2]);
        removeFromDestTs(pkt[1], pkt[2]);
        return pkt;
    }

    public int getCount(int destination, int startTime, int endTime) {
        TreeMap<Integer, Integer> tm = destTs.get(destination);
        if (tm == null) return 0;
        // 对 [startTime, endTime] 内所有时间戳的计数求和
        return tm.subMap(startTime, true, endTime, true)
                 .values().stream().mapToInt(Integer::intValue).sum();
    }

    private void removeFromDestTs(int destination, int timestamp) {
        TreeMap<Integer, Integer> tm = destTs.get(destination);
        if (tm == null) return;
        int cnt = tm.getOrDefault(timestamp, 0);
        if (cnt <= 1) tm.remove(timestamp);
        else tm.put(timestamp, cnt - 1);
    }
}
```

## 复杂度分析

- `addPacket`：O(log n)
- `forwardPacket`：O(log n)
- `getCount`：O(k)，k 为区间内不同时间戳数
- 空间复杂度：O(memoryLimit)

## 关键点总结

1. 移除包时需同步更新 queue、seen、destTs 三处
2. TreeMap 用 timestamp->count 支持重复时间戳（同一目的地不同来源）
3. subMap 获取区间内所有时间戳后求和计数
