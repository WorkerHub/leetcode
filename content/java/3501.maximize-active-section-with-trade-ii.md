## 题目描述

给你二进制字符串 `s` 和查询数组，每个查询 `[l, r]` 在区间内执行一次操作：将某段连续 '1' 替换为 '0'，将相邻某段连续 '0' 替换为 '1'（块交换），求每次查询后区间内 '1' 的最大连续段长度。

## 解题思路

将字符串压缩为"块"列表，对每个查询在区间 [l, r] 内截断块、枚举相邻两个 '1' 块通过中间 '0' 块合并的最大长度，同时考虑不操作时单个 '1' 块的最大长度。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maximizeActiveSections(String s, int[][] queries) {
        int n = s.length();
        // 构建块列表：[char(0/1), startPos, endPos]
        List<int[]> blocks = new ArrayList<>();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            blocks.add(new int[]{s.charAt(i) - '0', i, j - 1});
            i = j;
        }

        // 每个位置映射到块下标
        int[] blockIdx = new int[n];
        for (int bi = 0; bi < blocks.size(); bi++) {
            int[] b = blocks.get(bi);
            for (int pos = b[1]; pos <= b[2]; pos++) blockIdx[pos] = bi;
        }

        int[] result = new int[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int l = queries[q][0], r = queries[q][1];
            int bl = blockIdx[l], br = blockIdx[r];
            int best = 0;

            // 遍历区间内的块
            for (int bi = bl; bi <= br; bi++) {
                int[] b = blocks.get(bi);
                int al = Math.max(b[1], l), ar = Math.min(b[2], r);
                int len = ar - al + 1;
                if (b[0] == 1) {
                    best = Math.max(best, len); // 不操作时单个 '1' 块
                }
                // 枚举以 bi 为中间 '0' 块合并左右 '1' 块
                if (b[0] == 0 && bi > bl && bi < br) {
                    int[] lb = blocks.get(bi - 1);
                    int[] rb = blocks.get(bi + 1);
                    if (lb[0] == 1 && rb[0] == 1) {
                        int leftLen = Math.min(lb[2], r) - Math.max(lb[1], l) + 1;
                        int rightLen = Math.min(rb[2], r) - Math.max(rb[1], l) + 1;
                        best = Math.max(best, leftLen + rightLen);
                    }
                }
            }

            result[q] = best;
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q * B)，B 为每次查询涉及的块数（最坏 O(n * q)）
- 空间复杂度：O(n)

## 关键点总结

1. 压缩为块列表后，每次查询枚举涉及的块
2. 一次交换等价于合并两个相邻 '1' 块（通过中间 '0' 块）
3. 查询边界处的块需截断计算有效长度
