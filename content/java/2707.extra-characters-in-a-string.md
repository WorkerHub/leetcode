## 题目描述

给你字符串 `s` 和单词字典 `dictionary`，将 `s` 分割为若干字典中的子字符串，返回不属于任何子字符串的最少剩余字符数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minExtraChar(String s, String[] dictionary) {
        int n = s.length();
        Set<String> wordSet = new HashSet<>(Arrays.asList(dictionary));
        int[] dp = new int[n + 1];
        // dp[i] 表示处理前 i 个字符的最少剩余字符数

        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1] + 1; // 跳过 s[i-1]，作为剩余字符
            for (int j = 0; j < i; j++) {
                if (wordSet.contains(s.substring(j, i))) {
                    dp[i] = Math.min(dp[i], dp[j]); // s[j..i-1] 匹配字典词
                }
            }
        }
        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，L 为单词最大长度
- 空间复杂度：O(n + m * L)，m 为字典大小

## 关键点总结

1. `dp[i]` = 前 i 个字符的最少剩余数，默认跳过当前字符 `dp[i-1]+1`
2. 若 `s[j..i-1]` 在字典中，则 `dp[i] = min(dp[i], dp[j])`
