## 题目描述

数组元素都是2的幂，可将元素分裂为两个一半，求最少操作使某子序列和为target。

## 解题思路

贪心从低位到高位：统计每个2^i的个数。需要target某位为1时，从当前位取或从高位分裂。多余的低位可合并到高位。

## Java 代码实现

```java
class Solution {
    public int minOperations(List<Integer> nums, int target) {
        long total = 0;
        int[] cnt = new int[21];
        for (int v : nums) {
            total += v;
            cnt[Integer.numberOfTrailingZeros(Integer.highestOneBit(v))]++;
        }
        if (total < target) return -1;

        int ops = 0;
        for (int i = 0; i < 21; i++) {
            int bit = (target >> i) & 1;
            if (bit == 1) {
                if (cnt[i] > 0) {
                    cnt[i]--;
                } else {
                    // 从高位分裂
                    int j = i + 1;
                    while (j < 21 && cnt[j] == 0) j++;
                    if (j >= 21) return -1;
                    ops += j - i;
                    cnt[j]--;
                    // 分裂过程中每一层多出一个
                    for (int k = j - 1; k > i; k--) {
                        cnt[k]++;
                    }
                    // 不需要cnt[i]++再--, 已经用掉
                }
            }
            // 剩余的合并到高位
            cnt[i + 1] += cnt[i] / 2;
            // cnt[i]不再需要（已处理完第i位）
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + 21^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **从低位到高位贪心**：先满足低位需求
2. **不够时从高位分裂**：代价=层数差
3. **多余低位合并到高位**：两个2^i=一个2^(i+1)
