## 题目描述

给定单词数组 words 和字符串 chars，返回所有能由 chars 中字符构成的单词的长度之和（每个字符只能用一次）。

**示例：**
```
输入: words = ["cat","bt","hat","tree"], chars = "atach"
输出: 6（"cat" + "hat" = 3 + 3）
```

## 解题思路

统计 chars 中每个字符的频次，对每个单词检查其字符频次是否都不超过 chars 的频次。

## Java 代码实现

```java
class Solution {
    public int countCharacters(String[] words, String chars) {
        // 统计 chars 字符频次
        int[] charCount = new int[26];
        for (char c : chars.toCharArray()) charCount[c - 'a']++;

        int total = 0;
        for (String word : words) {
            // 统计单词字符频次
            int[] wordCount = new int[26];
            for (char c : word.toCharArray()) wordCount[c - 'a']++;

            // 检查是否可以构成
            boolean canForm = true;
            for (int i = 0; i < 26; i++) {
                if (wordCount[i] > charCount[i]) {
                    canForm = false;
                    break;
                }
            }
            if (canForm) total += word.length();
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m + |chars|)，n 为单词数，m 为平均单词长度
- **空间复杂度**：O(1)，固定大小 26 的数组

## 关键点总结

1. **频次比较**：比较每个字符的频次，不是简单判断包含
2. **int[26] 数组**：比 HashMap 更高效
3. **每字符只用一次**：频次必须 <=，不是存在即可
4. **累加长度**：返回长度之和而非单词数
