## 题目描述

给定两个以负二进制（base -2）表示的数组，返回它们之和的负二进制表示。

**示例：**
```
输入：arr1 = [1,1,1,1,1], arr2 = [1,0,1]
输出：[1,0,0,0,0]
```

## 解题思路

模拟加法：从低位到高位逐位相加，关键是进位规则：carry = -(sum / 2)，因为 base 是 -2。

## Java 代码实现

```java
class Solution {
    public int[] addNegabinary(int[] arr1, int[] arr2) {
        List<Integer> result = new ArrayList<>();
        int carry = 0;
        int i = arr1.length - 1, j = arr2.length - 1;

        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += arr1[i--];
            if (j >= 0) sum += arr2[j--];

            // 当前位的值
            result.add(sum & 1);
            // 负二进制的进位是负的
            carry = -(sum >> 1);
        }

        // 去除前导零
        while (result.size() > 1 && result.get(result.size() - 1) == 0) {
            result.remove(result.size() - 1);
        }

        // 反转结果（低位在前→高位在前）
        int[] ans = new int[result.size()];
        for (int k = 0; k < ans.length; k++) {
            ans[k] = result.get(ans.length - 1 - k);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(m, n))
- **空间复杂度**：O(max(m, n))

## 关键点总结

1. **负进位**：carry = -(sum / 2)，这是与普通二进制加法的关键区别
2. **位运算**：sum & 1 取当前位，sum >> 1 用于计算进位
3. **去前导零**：结果可能有多余前导零需要移除
