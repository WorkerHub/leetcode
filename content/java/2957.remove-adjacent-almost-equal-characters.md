## 题目描述

给你字符串 `word`，若两相邻字符差值绝对值 <= 1 则称为几乎相等，每次操作可修改任意字符，返回消除所有相邻几乎相等对的最少操作次数。

## 解题思路

贪心：从左到右遍历，遇到相邻几乎相等对时修改右侧字符（操作数+1），并跳过该字符（i+=2），避免引入新冲突。

## Java 代码实现

```java
class Solution {
    public int removeAlmostEqualCharacters(String word) {
        int n = word.length(), ans = 0, i = 0;
        while (i < n - 1) {
            if (Math.abs(word.charAt(i) - word.charAt(i + 1)) <= 1) {
                // 相邻几乎相等，修改右侧字符并跳过
                ans++;
                i += 2;
            } else {
                i++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：遇到冲突修改右侧字符，跳过 i+1（已修改，从 i+2 重新检查）
2. 相邻差值 <= 1 即为几乎相等，包含相同字符（差值 0）
3. 修改后跳过一位防止重复处理已修改字符
