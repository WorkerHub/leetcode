## 题目描述

给你障碍物高度数组 `obstacles`，对每个位置 i，返回以 `obstacles[i]` 结尾的最长非递减子序列长度。

## 解题思路

类 LIS 二分法：维护 `tails` 数组（长度 k+1 的非递减子序列末尾最小值），对每个元素用 `upperBound`（找第一个严格大于 x 的位置）确定插入位置，记录答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] longestObstacleCourseAtEachPosition(int[] obstacles) {
        int n = obstacles.length;
        int[] ans = new int[n];
        int[] tails = new int[n];
        int size = 0;

        for (int i = 0; i < n; i++) {
            int x = obstacles[i];
            // 找第一个严格大于 x 的位置（允许等于，故用 upper_bound）
            int lo = 0, hi = size;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (tails[mid] <= x) lo = mid + 1;
                else hi = mid;
            }
            ans[i] = lo + 1;
            tails[lo] = x;
            if (lo == size) size++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 非递减（允许等于）使用 upperBound（找第一个 > x 的位置）
2. 严格递增 LIS 使用 lowerBound（找第一个 >= x 的位置）
3. `tails[pos] = x` 更新维护最优末尾值
