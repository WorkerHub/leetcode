## 题目描述

删除一个子数组使剩余元素构成非递减数组，返回最短删除子数组长度。

**示例：**
```
输入：arr = [1,2,3,10,4,2,3,5]
输出：3
```

## 解题思路

双指针：找前缀非递减段和后缀非递减段，枚举拼接方案取最短删除长度。

## Java 代码实现

```java
class Solution {
    public int findLengthOfShortestSubarray(int[] arr) {
        int n = arr.length;
        // 前缀非递减段右端点
        int left = 0;
        while (left < n - 1 && arr[left] <= arr[left + 1]) left++;
        if (left == n - 1) return 0; // 已有序
        
        // 后缀非递减段左端点
        int right = n - 1;
        while (right > 0 && arr[right - 1] <= arr[right]) right--;
        
        // 只保留前缀或只保留后缀
        int ans = Math.min(n - left - 1, right);
        
        // 双指针：枚举前缀+后缀拼接
        int i = 0, j = right;
        while (i <= left && j < n) {
            if (arr[i] <= arr[j]) {
                ans = Math.min(ans, j - i - 1);
                i++;
            } else {
                j++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀+后缀**：保留两端有序段，删除中间
2. **双指针**：arr[i]<=arr[j] 时前缀可延伸
3. **三种候选**：只保留前缀、只保留后缀、拼接
