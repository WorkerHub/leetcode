## 题目描述

给你整数数组 `nums`，其中部分元素为 `-1`（缺失值）。将每个 `-1` 替换为任意正整数，最小化替换后数组中相邻元素差的最大绝对值。

## 解题思路

二分答案 `d`：若最大差值为 `d` 可行则 `d+1` 也可行。验证函数 `check(d)` 遍历所有相邻非 -1 值对 `(nums[i], nums[j])`（中间有 `j-i-1` 个 -1，步数为 `j-i`），检查 `|nums[i] - nums[j]| <= (j-i) * d`。

## Java 代码实现

```java
class Solution {
    public int minDifference(int[] nums) {
        int n = nums.length;

        // 特殊情况：全是 -1
        boolean allMinus = true;
        for (int x : nums) {
            if (x != -1) { allMinus = false; break; }
        }
        if (allMinus) return 0;

        // 找最大非 -1 值作为二分上界
        int maxVal = 0;
        for (int x : nums) {
            if (x != -1) maxVal = Math.max(maxVal, x);
        }

        int lo = 0, hi = maxVal;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (check(nums, n, mid)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }

        return lo;
    }

    private boolean check(int[] nums, int n, int d) {
        int i = 0;
        // 跳过左端 -1 段
        while (i < n && nums[i] == -1) i++;

        while (i < n) {
            // 找下一个非 -1 值
            int j = i + 1;
            while (j < n && nums[j] == -1) j++;

            if (j < n) {
                // [i, j] 之间步数为 j-i，需要 |nums[i]-nums[j]| <= (j-i)*d
                long diff = Math.abs((long) nums[j] - nums[i]);
                if (diff > (long) (j - i) * d) {
                    return false;
                }
            }
            i = j;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val))，二分 * 验证
- 空间复杂度：O(1)

## 关键点总结

1. 两个非 -1 值之间有 `k` 个 -1（步数 `k+1`），需要 `|a-b| <= (k+1) * d`。
2. 二分答案 `d`，验证所有相邻非 -1 对是否满足条件。
3. 端点的 -1 段（只有一侧有值）不构成约束，可以自由设置。
