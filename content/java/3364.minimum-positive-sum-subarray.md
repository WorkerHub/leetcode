## 题目描述

给你整数数组 `nums` 和两个整数 `l`、`r`，找出长度在 `[l, r]` 之间且元素和最小的正数（> 0）。返回该最小正数和，若不存在返回 -1。

## 解题思路

数据范围小（n <= 100），用前缀和暴力枚举所有长度在 `[l, r]` 之间的子数组，找最小正数和。

## Java 代码实现

```java
class Solution {
    public int minimumSumSubarray(int[] nums, int l, int r) {
        int n = nums.length;

        // 前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        int minPositive = Integer.MAX_VALUE;

        for (int i = 0; i < n; i++) {
            for (int len = l; len <= r && i + len <= n; len++) {
                int s = prefix[i + len] - prefix[i];
                if (s > 0) {
                    minPositive = Math.min(minPositive, s);
                }
            }
        }

        return minPositive == Integer.MAX_VALUE ? -1 : minPositive;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * (r - l + 1))，枚举起始位置和长度
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 数据范围小，暴力枚举即可。
2. 子数组和严格 > 0（不包含 0）。
3. 前缀和 O(1) 计算任意子数组和。
