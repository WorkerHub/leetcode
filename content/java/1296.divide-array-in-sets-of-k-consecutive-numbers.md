## 题目描述

判断数组能否划分成若干组，每组恰好 k 个连续数字。

**示例：**
```
输入：nums = [1,2,3,3,4,4,5,6], k = 4
输出：true
解释：分为 [1,2,3,4] 和 [3,4,5,6]
```

## 解题思路

贪心：排序后用 TreeMap 计数，每次从最小数开始尝试凑 k 个连续数。

## Java 代码实现

```java
class Solution {
    public boolean isPossibleDivide(int[] nums, int k) {
        if (nums.length % k != 0) return false;
        
        TreeMap<Integer, Integer> count = new TreeMap<>();
        for (int num : nums) {
            count.merge(num, 1, Integer::sum);
        }
        
        while (!count.isEmpty()) {
            int start = count.firstKey();
            for (int i = start; i < start + k; i++) {
                Integer cnt = count.get(i);
                if (cnt == null) return false;
                if (cnt == 1) count.remove(i);
                else count.put(i, cnt - 1);
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **长度检查**：n % k != 0 直接返回 false
2. **TreeMap**：有序计数，快速取最小值
3. **贪心**：从最小数开始凑连续 k 个
4. **等价题**：与 846. Hand of Straights 相同
