## 题目描述

循环二进制数组中，求将所有1聚在一起的最少交换次数。

## 解题思路

滑动窗口：设1的总数为k，在长度为k的窗口中找最多的1数量。答案=k-窗口内最多1数。循环处理用数组展开为两倍长。

## Java 代码实现

```java
class Solution {
    public int minSwaps(int[] nums) {
        int n = nums.length;
        int k = 0;
        for (int x : nums) k += x;
        if (k == 0 || k == n) return 0;
        
        // 初始窗口[0, k-1]
        int windowOnes = 0;
        for (int i = 0; i < k; i++) {
            windowOnes += nums[i];
        }
        int maxOnes = windowOnes;
        
        // 滑动窗口遍历循环数组
        for (int i = 1; i < n; i++) {
            windowOnes += nums[(i + k - 1) % n] - nums[i - 1];
            maxOnes = Math.max(maxOnes, windowOnes);
        }
        return k - maxOnes;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **窗口大小=1的总数k**：目标是让窗口内1最多
2. **循环数组**：用取模处理或展开两倍
3. **答案=k-maxOnes**：需要移出的0的个数
