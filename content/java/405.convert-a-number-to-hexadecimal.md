## 题目描述

给定一个整数 num，返回它的十六进制字符串表示。对于负整数，我们通常使用补码运算方法。

注意：
1. 十六进制中所有字母（a-f）都必须是小写。
2. 十六进制字符串中不能包含多余的前导零。如果要转化的数为 0，那么以单个字符 '0' 来表示；对于其他情况，十六进制字符串中的第一个字符将不会是 0 字符。
3. 给定的数确保在 32 位有符号整数范围内。
4. 不能使用任何由库提供的将数字直接转换或格式化为十六进制的方法。

**示例 1：**
```
输入：num = 26
输出："1a"
```

**示例 2：**
```
输入：num = -1
输出："ffffffff"
```

**提示：**
- -2^31 <= num <= 2^31 - 1

## 解题思路

这道题要求将整数转换为十六进制字符串，关键是处理负数的补码表示。

核心知识点：
1. 十六进制每位可以表示 4 个二进制位（0-15）
2. 负数使用补码表示：在 32 位系统中，-1 的补码是 0xFFFFFFFF
3. 可以通过位运算每次取出最低 4 位

Java 特点：
- Java 的 `int` 类型本身就是 32 位有符号补码整数
- 对负数使用无符号右移 `>>>` 可以高位填 0，自然处理补码
- 无需像 Python 一样手动截取低 32 位

算法流程：
1. 特殊处理：num = 0 直接返回 "0"
2. 每次取最低 4 位转换为十六进制字符
3. 使用无符号右移 `>>>= 4` 处理下一组 4 位
4. 反转结果字符串

## Java 代码实现

### 方法一：位运算（推荐）

```java
class Solution {
    public String toHex(int num) {
        // 特殊情况：0 直接返回
        if (num == 0) return "0";

        // 十六进制字符映射
        String hexChars = "0123456789abcdef";
        StringBuilder result = new StringBuilder();

        // Java 的 int 是 32 位补码，使用无符号右移 >>> 处理负数
        // >>> 高位填 0，最终 num 会变为 0 停止循环
        while (num != 0) {
            // 取最低 4 位（0-15）
            result.append(hexChars.charAt(num & 0xF));
            // 无符号右移 4 位（高位填 0）
            num >>>= 4;
        }

        // 反转结果（因为是从低位到高位处理的）
        return result.reverse().toString();
    }
}
```

### 方法二：除法取余

```java
class Solution {
    public String toHex(int num) {
        // 使用除法和取余，类似十进制转换
        if (num == 0) return "0";

        // 将负数转换为无符号 32 位整数（使用 long 避免溢出）
        long n = num & 0xFFFFFFFFL;

        String hexChars = "0123456789abcdef";
        StringBuilder result = new StringBuilder();

        while (n != 0) {
            result.append(hexChars.charAt((int)(n % 16)));
            n /= 16;
        }

        return result.reverse().toString();
    }
}
```

### 方法三：固定 8 位处理

```java
class Solution {
    public String toHex(int num) {
        // 32 位整数最多 8 个十六进制字符
        if (num == 0) return "0";

        String hexChars = "0123456789abcdef";
        StringBuilder result = new StringBuilder();

        // 最多处理 8 次（32 位 = 8 个十六进制字符）
        for (int i = 0; i < 8 && num != 0; i++) {
            result.append(hexChars.charAt(num & 0xF));
            num >>>= 4;  // 无符号右移
        }

        return result.reverse().toString();
    }
}
```

### 方法四：递归实现

```java
class Solution {
    private final String hexChars = "0123456789abcdef";

    public String toHex(int num) {
        if (num == 0) return "0";

        // 使用 long 处理负数，避免无限递归
        long n = num & 0xFFFFFFFFL;
        return convert(n);
    }

    private String convert(long n) {
        if (n == 0) return "";
        // 递归：先处理高位，再拼接当前位
        return convert(n >>> 4) + hexChars.charAt((int)(n & 0xF));
    }
}
```

### 方法五：char 数组构建

```java
class Solution {
    public String toHex(int num) {
        if (num == 0) return "0";

        char[] hexChars = "0123456789abcdef".toCharArray();
        // 32 位最多 8 个十六进制字符
        char[] buf = new char[8];
        int pos = 8;  // 从末尾往前填充

        // 使用无符号右移，循环直到 num 为 0
        while (num != 0) {
            buf[--pos] = hexChars[num & 0xF];
            num >>>= 4;
        }

        return new String(buf, pos, 8 - pos);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
  - 32 位整数最多 8 个十六进制位
  - 固定迭代 8 次（或更少）

- **空间复杂度**：O(1)
  - 结果字符串最多 8 个字符
  - 常数级别的额外空间

### 位运算过程（num = 26）：

```
初始：num = 26 = 0x1A

第 1 次：
  num & 0xF = 0x1A & 0xF = 10 (0xA) -> 'a'
  num >>>= 4: num = 1

第 2 次：
  num & 0xF = 0x1 & 0xF = 1 -> '1'
  num >>>= 4: num = 0

反转：['a', '1'] -> "1a"
```

## 关键点总结

1. **Java int 天然是 32 位补码**：
   - 不需要像 Python 一样手动用 `& 0xFFFFFFFF` 截取低 32 位
   - 直接对 int 使用无符号右移 `>>>` 即可

2. **`>>` vs `>>>`**：
   - `>>`（算术右移）：高位填符号位（负数高位填 1）
   - `>>>`（逻辑右移/无符号右移）：高位填 0
   - 对负数处理必须使用 `>>>`，否则永远不会变为 0

3. **字符映射**：
   - 使用字符串 "0123456789abcdef" 作为映射表
   - 索引 0-15 对应十六进制字符

4. **反转结果**：
   - 从低位到高位处理，最后需要反转
   - 或用 char 数组从末尾往前填充，避免反转

## 易错点

1. **`>>` 和 `>>>` 混淆**：
   - 错误：使用 `num >>= 4`，负数时高位填 1，循环永不结束
   - 正确：使用 `num >>>= 4`，高位填 0，最终变为 0

2. **字符大小写**：
   - 题目要求小写字母（a-f）
   - 不能使用大写（A-F）

3. **前导零**：
   - 0 应该返回 "0" 而不是空字符串
   - 其他情况不应该有前导零

4. **禁止使用内置函数**：
   - 不能使用 `Integer.toHexString()`、`String.format("%x", n)` 等库方法
   - 要手动实现转换逻辑
