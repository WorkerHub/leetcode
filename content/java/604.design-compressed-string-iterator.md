## 题目描述

设计并实现一个迭代器来压缩一个字符串，其中重复的字符将被表示为字符后跟重复的次数。

实现 `StringIterator` 类：
- `StringIterator(String compressedString)` 用压缩字符串初始化对象
- `char next()` 返回下一个字符
- `boolean hasNext()` 如果仍有字符返回 true

**示例：**

```
StringIterator iterator = new StringIterator("L1e2t1C1o1d1e1");
iterator.next(); // 返回 'L'
iterator.next(); // 返回 'e'
iterator.next(); // 返回 'e'
iterator.next(); // 返回 't'
iterator.next(); // 返回 'C'
iterator.next(); // 返回 'o'
iterator.next(); // 返回 'd'
iterator.hasNext(); // 返回 true
iterator.next(); // 返回 'e'
iterator.hasNext(); // 返回 false
iterator.next(); // 返回 ' '
```

## Java 代码实现

```java
class StringIterator {
    private String s;
    private int ptr;
    private char currentChar;
    private int count;

    public StringIterator(String compressedString) {
        this.s = compressedString;
        this.ptr = 0;
        this.currentChar = ' ';
        this.count = 0;
    }

    public char next() {
        if (!hasNext()) {
            return ' ';
        }

        // 当前计数为0，解析下一个字符及其数量
        if (count == 0) {
            currentChar = s.charAt(ptr);
            ptr++;
            StringBuilder numStr = new StringBuilder();
            while (ptr < s.length() && Character.isDigit(s.charAt(ptr))) {
                numStr.append(s.charAt(ptr));
                ptr++;
            }
            count = Integer.parseInt(numStr.toString());
        }

        count--;
        return currentChar;
    }

    public boolean hasNext() {
        return ptr < s.length() || count > 0;
    }
}
```
