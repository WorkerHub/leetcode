## 题目描述

给你正整数数组 `nums`，可将某个元素替换为两个正整数之和等于它，返回使数组非递减所需的最少替换次数。

## 解题思路

从后向前贪心：维护当前允许的最大上界 `limit`（初始为最后一个元素）。若当前元素 > limit，则分成 `k = ceil(v/limit)` 份，需要 k-1 次操作；最左份取 `v/k`（整除）以尽量小，给左边元素更大空间。

## Java 代码实现

```java
class Solution {
    public long minimumReplacement(int[] nums) {
        int n = nums.length;
        long ops = 0;
        long limit = nums[n - 1]; // 当前允许的最大值

        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] <= limit) {
                limit = nums[i]; // 无需替换
            } else {
                long k = (nums[i] + limit - 1) / limit; // ceil(v/limit)
                ops += k - 1; // k 份需 k-1 次操作
                limit = nums[i] / k; // 最左份尽量小
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 从右向左处理，右边元素确定上界，左边元素不能超过该上界。
2. 分成 k 份需 k-1 次操作；最左份取 `v/k`（整除），为左边保留最大空间。
3. 答案可能很大（n 最大 10^5，每次操作可达 10^9/1=10^9 份），用 `long`。
