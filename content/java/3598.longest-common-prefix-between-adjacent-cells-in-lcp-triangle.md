## 题目描述

给定字符串数组 `words`，构建 LCP 三角形（`lcp[i][j]` 为 `words[i]` 和 `words[j]` 的最长公共前缀长度），求三角形中所有相邻单元格之差的绝对值的最大值。

## Java 代码实现

```java
class Solution {
    public int maxDifference(String[] words) {
        int n = words.length;
        int[][] lcp = new int[n][n];

        // 预计算 lcp 矩阵
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int k = 0;
                while (k < words[i].length() && k < words[j].length()
                        && words[i].charAt(k) == words[j].charAt(k)) k++;
                lcp[i][j] = lcp[j][i] = k;
            }
        }

        int ans = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 同行相邻：(i, j) 和 (i, j+1)
                if (j + 1 < n) ans = Math.max(ans, Math.abs(lcp[i][j] - lcp[i][j + 1]));
                // 列向相邻：(i, j) 和 (i+1, j)
                if (i + 1 < j) ans = Math.max(ans, Math.abs(lcp[i][j] - lcp[i + 1][j]));
                // 对角线相邻：(i, j) 和 (i+1, j+1)
                if (i + 1 < n && j + 1 < n) ans = Math.max(ans, Math.abs(lcp[i][j] - lcp[i + 1][j + 1]));
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * L)，n 为单词数，L 为最长单词长度
- 空间复杂度：O(n^2)

## 关键点总结

1. 预计算所有 `lcp[i][j]` 避免重复计算
2. 三角形中的相邻关系有三种：同行、列向、对角线
3. 枚举所有相邻对取差的绝对值最大值
