## 题目描述

给你二叉树根节点 `root` 和查询数组 `queries`，每次查询独立地删除以指定节点为根的子树，返回删除后的树高度。

## 解题思路

两次 DFS 预处理：第一次 DFS 计算每个节点的高度；第二次 DFS 传递「不含当前子树时树的最大高度」—— 递归左子树时，右子树贡献 `depth + 1 + rightHeight`，反之亦然，取与父节点传入值的最大值作为答案。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<TreeNode, Integer> heightMap = new HashMap<>();
    private Map<Integer, Integer> ansMap = new HashMap<>();

    public int[] treeQueries(TreeNode root, int[] queries) {
        computeHeight(root);
        dfs(root, 0, 0);
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            ans[i] = ansMap.get(queries[i]);
        }
        return ans;
    }

    // 计算每个节点的高度（到最深叶子的距离）
    private int computeHeight(TreeNode node) {
        if (node == null) return -1;
        int h = 1 + Math.max(computeHeight(node.left), computeHeight(node.right));
        heightMap.put(node, h);
        return h;
    }

    // DFS 传递「不含当前子树的最大高度」
    private void dfs(TreeNode node, int depth, int maxWithout) {
        if (node == null) return;
        // 删除当前节点子树后，树高度为 maxWithout
        ansMap.put(node.val, maxWithout);
        int leftH = heightMap.getOrDefault(node.left, -1);
        int rightH = heightMap.getOrDefault(node.right, -1);
        // 递归左子树：右子树贡献 depth + 1 + rightH
        dfs(node.left, depth + 1, Math.max(maxWithout, depth + 1 + rightH));
        // 递归右子树：左子树贡献 depth + 1 + leftH
        dfs(node.right, depth + 1, Math.max(maxWithout, depth + 1 + leftH));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 为节点数，m 为查询数
- **空间复杂度**：O(n)

## 关键点总结

1. 预处理每个节点删除后的树高度，存入哈希表，查询时 O(1) 回答
2. DFS 传入「当前路径上不含该子树的已知最大高度」
3. 利用兄弟子树高度更新传给子节点的参数
