## 题目描述

给你一个整数数组 `nums`，每次操作选择最大元素将其替换为 `ceil(max / 2)`，执行 k 次操作后返回数组的最大元素。

## 解题思路

二分答案：二分最终最大值 `mid`，验证每个元素减小到 <= mid 所需操作次数总和是否 <= k。每次操作将值向上取整除以 2，单个元素所需步数为 `ceil(log2(x/mid))`。

## Java 代码实现

```java
class Solution {
    public int minimizeMax(int[] nums, int k) {
        int left = 1, right = 0;
        for (int x : nums) right = Math.max(right, x);

        while (left < right) {
            int mid = (left + right) / 2;
            if (check(nums, mid, k)) right = mid;
            else left = mid + 1;
        }
        return left;
    }

    private boolean check(int[] nums, int target, int k) {
        long totalOps = 0;
        for (int x : nums) {
            // 将x减小到<=target所需操作次数
            while (x > target) { x = (x + 1) / 2; totalOps++; }
            if (totalOps > k) return false;
        }
        return totalOps <= k;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log(max_val) * log(max_val))
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案：对最终最大值二分，验证 k 次是否足够
2. `ceil(x/2) = (x+1)/2` 用整数除法实现
3. 提前终止：总操作数超过 k 时直接返回 false
