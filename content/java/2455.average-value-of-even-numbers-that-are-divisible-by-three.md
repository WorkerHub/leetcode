## 题目描述

给你正整数数组 `nums`，返回其中能被 3 整除的所有偶数的平均值（向下取整），若不存在则返回 0。

## 解题思路

既是偶数又能被 3 整除，等价于能被 6 整除。筛选所有 6 的倍数，计算其平均值。

## Java 代码实现

```java
class Solution {
    public int averageValue(int[] nums) {
        long sum = 0;
        int count = 0;
        for (int x : nums) {
            // 偶数且被 3 整除 = 被 6 整除
            if (x % 6 == 0) {
                sum += x;
                count++;
            }
        }
        return count == 0 ? 0 : (int) (sum / count);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 偶数 + 能被 3 整除 = 能被 6 整除（6 = lcm(2, 3)）
2. 平均值向下取整（整数除法）
3. 没有满足条件的元素时返回 0
