## 题目描述

n 个人站成一排，`heights[i]` 为第 i 个人的身高（互不相同）。第 i 个人能看到右边第 j 个人，当且仅当 i 和 j 之间没有比 `heights[j]` 更高的人。返回每个人能看到的人数。

## 解题思路

单调递减栈（从左到右）：遍历到第 i 个人时，弹出所有比 `heights[i]` 矮的栈顶（这些人对左侧某人可见，ans 对应增加），若栈不为空则栈顶（第一个更高的人）也可见。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] canSeePersonsCount(int[] heights) {
        int n = heights.length;
        int[] ans = new int[n];
        Deque<Integer> stack = new ArrayDeque<>(); // 单调递减栈（存索引）

        for (int i = 0; i < n; i++) {
            // 弹出所有比 heights[i] 矮的人，他们对左侧最近能看到他们的人可见
            while (!stack.isEmpty() && heights[stack.peek()] < heights[i]) {
                int j = stack.pop();
                ans[j]++; // j 能看到 i（heights[i] 更高，j 可以看穿那些矮的人到达 i）
            }
            // 栈顶（第一个 >= heights[i] 的人）也能看到 i
            if (!stack.isEmpty()) ans[stack.peek()]++;
            stack.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 单调递减栈：被弹出的元素说明被当前更高的人挡住，之前遮挡它的人可以看到当前人
2. 每次弹出一个比当前矮的人，对应左侧 `j` 能看到当前人 ans[j]++
3. 栈顶（第一个更高的）也对当前左侧人可见
