## 题目描述

给定 `n` 个节点的有向加权图，节点 0 是源节点，信号从 0 出发沿边传播，返回所有节点都激活所需的最短时间，若无法全部激活返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int networkRecoveryTime(int n, int[][] edges) {
        List<List<int[]>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) graph.get(e[0]).add(new int[]{e[1], e[2]});

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;

        // Dijkstra
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int node = (int) cur[1];
            if (d > dist[node]) continue;
            for (int[] nb : graph.get(node)) {
                long nd = d + nb[1];
                if (nd < dist[nb[0]]) {
                    dist[nb[0]] = nd;
                    pq.offer(new long[]{nd, nb[0]});
                }
            }
        }

        long ans = 0;
        for (long d : dist) {
            if (d == Long.MAX_VALUE) return -1;
            ans = Math.max(ans, d);
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)，Dijkstra 标准复杂度
- 空间复杂度：O(V + E)

## 关键点总结

1. 单源最短路，答案为所有节点最短距离的最大值
2. 若存在不可达节点（距离为无穷大），返回 -1
3. 有向图需注意边方向，不要建反向边
