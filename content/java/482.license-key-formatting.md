## 题目描述

给定一个许可密钥字符串 s，仅由字母、数字字符和破折号组成。字符串由 n 个破折号分隔成 n + 1 组。你也会得到一个整数 k。

我们想要重新格式化字符串 s，使每一组包含 k 个字符，除了第一组，它可以比 k 短，但仍必须包含至少一个字符。此外，两组之间必须插入破折号，并且应该将所有小写字母转换为大写字母。

返回重新格式化的许可密钥。

**示例 1：**
```
输入：s = "5F3Z-2e-9-w", k = 4
输出："5F3Z-2E9W"
解释：字符串 s 被分成了两个部分，每部分 4 个字符；
     注意，两个额外的破折号需要删掉。
```

**示例 2：**
```
输入：s = "2-5g-3-J", k = 2
输出："2-5G-3J"
解释：字符串 s 被分成了 3 个部分，按照前面的规则描述，第一部分的字符可以少于给定的数量，其余部分皆为 2 个字符。
```

**提示：**
- 1 <= s.length <= 10^5
- s 只包含字母、数字和破折号 '-'
- 1 <= k <= 10^4

## 解题思路

这是一道字符串格式化题目，核心思路是：

1. **移除所有破折号**：先将字符串中的所有 '-' 去掉
2. **转换为大写**：将所有字母转为大写
3. **从后向前分组**：
   - 从字符串末尾开始，每 k 个字符分为一组
   - 第一组（最前面）可以少于 k 个字符
4. **插入破折号**：在各组之间插入 '-'

**关键观察**：
- 从后向前处理更简单，因为最后一组一定是满的（k 个字符）
- 第一组是剩余的字符，可能少于 k 个
- 使用反转可以简化逻辑

## Java 代码实现

### 方法一：逆序处理（推荐）

```java
class Solution {
    public String licenseKeyFormatting(String s, int k) {
        // 从后向前每 k 个字符分组
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)

        // 移除破折号并转大写
        s = s.replace("-", "").toUpperCase();

        if (s.isEmpty()) return "";

        // 从后向前每 k 个字符分组
        StringBuilder result = new StringBuilder();
        int count = 0;

        for (int i = s.length() - 1; i >= 0; i--) {
            // 每 k 个字符添加一个破折号（第一个字符除外）
            if (count == k) {
                result.append('-');
                count = 0;
            }
            result.append(s.charAt(i));
            count++;
        }

        // 反转结果（因为是从后向前构建的）
        return result.reverse().toString();
    }
}
```

### 方法二：切片分组（更直观）

```java
class Solution {
    public String licenseKeyFormatting(String s, int k) {
        // 计算第一组长度后逐段添加
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)

        // 移除破折号并转大写
        s = s.replace("-", "").toUpperCase();

        if (s.isEmpty()) return "";

        // 计算第一组的长度
        int firstGroupLen = s.length() % k;
        if (firstGroupLen == 0) firstGroupLen = k;

        // 构建结果
        StringBuilder result = new StringBuilder();

        // 添加第一组
        result.append(s, 0, firstGroupLen);

        // 添加后续组（每组 k 个字符）
        for (int i = firstGroupLen; i < s.length(); i += k) {
            result.append('-');
            result.append(s, i, i + k);
        }

        return result.toString();
    }
}
```

### 方法三：使用栈（从后向前）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String licenseKeyFormatting(String s, int k) {
        // 使用栈从后向前处理
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)

        // 移除破折号并转大写
        s = s.replace("-", "").toUpperCase();

        if (s.isEmpty()) return "";

        Deque<Character> stack = new ArrayDeque<>();
        int count = 0; // 当前组中的字符数

        // 从后向前遍历
        for (int i = s.length() - 1; i >= 0; i--) {
            if (count == k) {
                // 当前组满了，压入破折号
                stack.push('-');
                count = 0;
            }
            stack.push(s.charAt(i));
            count++;
        }

        // 从栈中取出结果
        StringBuilder result = new StringBuilder();
        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }

        return result.toString();
    }
}
```

### 方法四：正向处理（计算偏移）

```java
class Solution {
    public String licenseKeyFormatting(String s, int k) {
        // 正向处理，先计算第一组的大小
        // 时间复杂度：O(n)
        // 空间复杂度：O(n)

        // 移除破折号并转大写
        String cleaned = s.replace("-", "").toUpperCase();

        if (cleaned.isEmpty()) return "";

        int n = cleaned.length();
        // 第一组的大小
        int first = (n % k != 0) ? n % k : k;

        // 构建结果
        StringBuilder sb = new StringBuilder();
        int idx = 0;

        // 添加第一组
        sb.append(cleaned, idx, idx + first);
        idx += first;

        // 添加剩余组
        while (idx < n) {
            sb.append('-');
            sb.append(cleaned, idx, idx + k);
            idx += k;
        }

        return sb.toString();
    }
}
```

## 复杂度分析

所有方法的复杂度都相同：

- **时间复杂度**：O(n)
  - 遍历字符串一次：O(n)
  - 构建结果：O(n)
  - 总复杂度：O(n)

- **空间复杂度**：O(n)
  - 需要存储处理后的字符串
  - 结果数组也是 O(n)

## 关键点总结

1. **预处理字符串**：先移除破折号并转大写
2. **从后向前处理**：避免计算第一组大小的复杂性
3. **边界处理**：空字符串、第一组大小的特殊情况
4. **使用内置函数**：`replace()`、`toUpperCase()`、`StringBuilder` 简化代码
5. **反转技巧**：从后向前构建，最后反转结果

## 易错点

1. **忘记转大写**
   - 题目要求将所有小写字母转为大写
   - 在预处理阶段就应该处理

2. **第一组长度计算错误**
   - 第一组长度 = len(s) % k
   - 但如果恰好整除，第一组应该是 k 个，不是 0 个

3. **空字符串处理**
   - 移除所有破折号后可能为空
   - 需要特殊处理

4. **破折号位置**
   - 不应该在开头或结尾添加破折号
   - 只在组与组之间添加

5. **索引越界**
   - 使用 `substring` 时注意不要越界
   - Java 的 `StringBuilder.append(str, start, end)` 可以安全截取
