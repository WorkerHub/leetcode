## 题目描述

给定安保数组security和整数time，返回所有"好日子"下标：前time天非递增且后time天非递减。

## 解题思路

预计算dec[i]（以i结尾的非递增长度）和inc[i]（以i起始的非递减长度），好日子条件：dec[i]>=time且inc[i]>=time。

## Java 代码实现

```java
class Solution {
    public List<Integer> goodDaysToRobBank(int[] security, int time) {
        int n = security.length;
        int[] dec = new int[n]; // 以i结尾的非递增长度
        int[] inc = new int[n]; // 以i起始的非递减长度
        
        for (int i = 1; i < n; i++) {
            if (security[i] <= security[i - 1]) {
                dec[i] = dec[i - 1] + 1;
            }
        }
        for (int i = n - 2; i >= 0; i--) {
            if (security[i] <= security[i + 1]) {
                inc[i] = inc[i + 1] + 1;
            }
        }
        
        List<Integer> result = new ArrayList<>();
        for (int i = time; i < n - time; i++) {
            if (dec[i] >= time && inc[i] >= time) {
                result.add(i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **前缀计数dec**：从左往右记录非递增长度
2. **后缀计数inc**：从右往左记录非递减长度
3. **遍历范围**：i从time到n-time-1确保两侧有足够天数
