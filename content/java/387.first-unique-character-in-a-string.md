## 题目描述

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

**示例 1:**

```
输入: s = "leetcode"
输出: 0
```

**示例 2:**

```
输入: s = "loveleetcode"
输出: 2
```

**示例 3:**

```
输入: s = "aabb"
输出: -1
```

**提示:**

- `1 <= s.length <= 10^5`
- `s` 只包含小写字母

## 解题思路

本题是经典的**字符计数**问题，有多种解法。

### 核心思想

**方法对比：**

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 两次遍历 | O(n) | O(1) | 简单直观 |
| 一次遍历 | O(n) | O(1) | 稍微复杂 |
| 数组计数 | O(n) | O(1) | 空间固定 |

### 思路一：两次遍历（推荐新手）

1. 第一次遍历：统计每个字符的出现次数
2. 第二次遍历：找到第一个出现次数为 1 的字符

### 思路二：一次遍历

使用哈希表记录每个字符的第一次出现位置和是否重复。

### 思路三：数组计数

因为只有小写字母，可以用长度 26 的数组代替哈希表。

## Java 代码实现

### 方法一：数组计数（推荐）⭐

```java
class Solution {
    public int firstUniqChar(String s) {
        // 统计每个字母的出现次数
        int[] counts = new int[26];

        for (char c : s.toCharArray()) {
            counts[c - 'a']++;
        }

        // 找到第一个出现一次的字符
        for (int i = 0; i < s.length(); i++) {
            if (counts[s.charAt(i) - 'a'] == 1) {
                return i;
            }
        }

        return -1;
    }
}
```

### 方法二：HashMap 计数

```java
import java.util.*;

class Solution {
    public int firstUniqChar(String s) {
        // 手动使用 HashMap 统计频次
        Map<Character, Integer> charCount = new HashMap<>();

        // 第一次遍历：统计频次
        for (char c : s.toCharArray()) {
            charCount.put(c, charCount.getOrDefault(c, 0) + 1);
        }

        // 第二次遍历：找第一个不重复的
        for (int i = 0; i < s.length(); i++) {
            if (charCount.get(s.charAt(i)) == 1) {
                return i;
            }
        }

        return -1;
    }
}
```

### 方法三：记录索引（一次遍历思路）

```java
import java.util.*;

class Solution {
    public int firstUniqChar(String s) {
        // 用数组记录每个字符的最后出现索引，-1 表示重复
        int[] lastIndex = new int[26];
        Arrays.fill(lastIndex, -2); // -2 表示未出现

        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            if (lastIndex[idx] == -2) {
                // 第一次出现，记录索引
                lastIndex[idx] = i;
            } else {
                // 重复出现，标记为 -1
                lastIndex[idx] = -1;
            }
        }

        // 找到最小的非负索引（第一个不重复字符的位置）
        int result = Integer.MAX_VALUE;
        for (int idx : lastIndex) {
            if (idx >= 0) {
                result = Math.min(result, idx);
            }
        }

        return result == Integer.MAX_VALUE ? -1 : result;
    }
}
```

### 方法四：使用 indexOf 和 lastIndexOf

```java
class Solution {
    public int firstUniqChar(String s) {
        // 如果字符只出现一次，indexOf 和 lastIndexOf 相等
        // 时间复杂度: O(n * 26) = O(n)
        int result = -1;

        for (char c = 'a'; c <= 'z'; c++) {
            int first = s.indexOf(c);
            if (first != -1 && first == s.lastIndexOf(c)) {
                // 该字符只出现一次
                if (result == -1 || first < result) {
                    result = first;
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历字符串最多两次
- 统计频次需要 O(n)
- 查找第一个唯一字符需要 O(n)

**空间复杂度：** O(1)
- 虽然使用了哈希表或数组，但最多存储 26 个小写字母
- 常数空间，不随输入规模增长

## 关键点总结

1. **两次遍历模式**：先统计，再查找，逻辑清晰
2. **数组优化**：Java 中 26 个字母用数组比 HashMap 更高效
3. **字符下标**：`c - 'a'` 得到 0-25 的索引
4. **索引技巧**：`indexOf()` 返回第一次出现，`lastIndexOf()` 返回最后一次
5. **空间常数性**：虽然用了额外结构，但大小固定

## 易错点

1. **返回值错误**：要返回索引，不是字符本身
2. **找不到的情况**：返回 `-1`，不是 `null`
3. **空字符串**：题目保证长度至少为 1
4. **重复的定义**：出现次数大于 1 就是重复
5. **第一个的含义**：是原字符串中第一次出现的位置，不是字母表顺序
