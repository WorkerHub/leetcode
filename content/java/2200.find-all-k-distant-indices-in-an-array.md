## 题目描述

找出数组中所有与某个值为key的元素距离不超过k的下标，升序返回。

## 解题思路

收集所有key的位置，双指针遍历每个下标i，维护满足|i-j|<=k的key下标，存在则加入结果。

## Java 代码实现

```java
class Solution {
    public List<Integer> findKDistantIndices(int[] nums, int key, int k) {
        int n = nums.length;
        // 收集所有key的位置
        List<Integer> keyPos = new ArrayList<>();
        for (int j = 0; j < n; j++) {
            if (nums[j] == key) keyPos.add(j);
        }
        
        List<Integer> result = new ArrayList<>();
        int ptr = 0;
        for (int i = 0; i < n; i++) {
            // 跳过距离超过k的key位置
            while (ptr < keyPos.size() && keyPos.get(ptr) < i - k) {
                ptr++;
            }
            // 检查是否存在距离<=k的key
            if (ptr < keyPos.size() && keyPos.get(ptr) <= i + k) {
                result.add(i);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **双指针优化**：避免对每个i重新搜索key位置
2. **滑动窗口思想**：ptr只增不减，总移动次数O(N)
3. **边界处理**：max(0,j-k)和min(n-1,j+k)防越界
