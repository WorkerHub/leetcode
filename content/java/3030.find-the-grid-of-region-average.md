## 题目描述

像素矩阵中相邻像素差<=threshold构成连通区域，每个区域像素替换为区域平均值（向下取整）。

## 解题思路

BFS/并查集求连通分量，计算每个区域的平均值，统一替换。

## Java 代码实现

```java
class Solution {
    public int[][] resultGrid(int[][] image, int threshold) {
        int m = image.length, n = image[0].length;
        int[] parent = new int[m * n];
        int[] size = new int[m * n];
        long[] total = new long[m * n];
        for (int i = 0; i < m * n; i++) {
            parent[i] = i;
            size[i] = 1;
            total[i] = image[i / n][i % n];
        }

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 右邻
                if (j + 1 < n && Math.abs(image[i][j] - image[i][j + 1]) <= threshold) {
                    union(parent, size, total, i * n + j, i * n + j + 1);
                }
                // 下邻
                if (i + 1 < m && Math.abs(image[i][j] - image[i + 1][j]) <= threshold) {
                    union(parent, size, total, i * n + j, (i + 1) * n + j);
                }
            }
        }

        int[][] result = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int root = find(parent, i * n + j);
                result[i][j] = (int) (total[root] / size[root]);
            }
        }
        return result;
    }

    private int find(int[] parent, int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int[] parent, int[] size, long[] total, int x, int y) {
        int rx = find(parent, x), ry = find(parent, y);
        if (rx == ry) return;
        if (size[rx] < size[ry]) { int t = rx; rx = ry; ry = t; }
        parent[ry] = rx;
        size[rx] += size[ry];
        total[rx] += total[ry];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M*N*α(M*N))
- **空间复杂度**：O(M*N)

## 关键点总结

1. **并查集求连通分量**：相邻差<=threshold则合并
2. **每个连通分量统一替换为平均值**
3. **向下取整**：整除即可
