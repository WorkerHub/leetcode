## 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**不允许修改**链表。

**示例 1：**
```
输入：head = [3,2,0,-4], pos = 1
输出：返回索引为 1 的链表节点
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**
```
输入：head = [1,2], pos = 0
输出：返回索引为 0 的链表节点
解释：链表中有一个环，其尾部连接到第一个节点。
```

**示例 3：**
```
输入：head = [1], pos = -1
输出：返回 null
解释：链表中没有环。
```

**提示：**
- 链表中节点的数目范围在 `[0, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`
- `pos` 的值为 `-1` 或者链表中的一个有效索引

**进阶：** 你是否可以使用 O(1) 空间解决此题？

## 解题思路

这道题是 LeetCode 141 的进阶版，不仅要判断有无环，还要找到环的入口。

**核心思想：Floyd 判圈算法（快慢指针）**

### 数学证明：

假设：
- 链表头到环入口的距离为 `a`
- 环入口到相遇点的距离为 `b`
- 相遇点到环入口的距离为 `c`
- 环的长度为 `b + c`

**第一阶段：快慢指针相遇**
- 慢指针走的距离：`a + b`
- 快指针走的距离：`a + b + n(b + c)`（n 为快指针在环内走的圈数）
- 因为快指针速度是慢指针的 2 倍：`2(a + b) = a + b + n(b + c)`
- 化简得：`a + b = n(b + c)`，即 `a = n(b + c) - b = (n-1)(b + c) + c`

**第二阶段：找环入口**
- 从相遇点和链表头同时出发，每次走 1 步
- 当链表头指针走了 `a` 步到达环入口时
- 相遇点指针走了 `a = (n-1)(b + c) + c` 步，也到达环入口
- 两指针相遇的位置就是环入口

### 算法步骤：

1. **判断是否有环**：使用快慢指针，如果相遇说明有环
2. **找环入口**：
   - 一个指针从链表头出发
   - 另一个指针从相遇点出发
   - 两指针同时每次走 1 步，相遇点即为环入口

## Java 代码实现

### 方法一：快慢指针（推荐）

```java
// Definition for singly-linked list.
// class ListNode {
//     int val;
//     ListNode next;
//     ListNode(int x) {
//         val = x;
//         next = null;
//     }
// }

public class Solution {
    public ListNode detectCycle(ListNode head) {
        // 边界情况
        if (head == null || head.next == null) {
            return null;
        }

        // 第一阶段：快慢指针找相遇点
        ListNode slow = head, fast = head;
        boolean hasCycle = false;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                hasCycle = true;
                break;
            }
        }

        // 如果无环，返回 null
        if (!hasCycle) {
            return null;
        }

        // 第二阶段：找环入口
        // 一个指针从头开始，一个从相遇点开始
        ListNode ptr1 = head;
        ListNode ptr2 = slow;

        while (ptr1 != ptr2) {
            ptr1 = ptr1.next;
            ptr2 = ptr2.next;
        }

        // 相遇点即为环入口
        return ptr1;
    }
}
```

### 方法二：快慢指针（简化版）

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head, fast = head;

        // 第一阶段：判断是否有环
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                // 第二阶段：找环入口
                slow = head;
                while (slow != fast) {
                    slow = slow.next;
                    fast = fast.next;
                }
                return slow;
            }
        }

        return null;
    }
}
```

### 方法三：哈希表（不满足空间要求，但直观）

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        Set<ListNode> seen = new HashSet<>();
        ListNode curr = head;

        while (curr != null) {
            // 如果节点已访问过，说明这是环的入口
            if (seen.contains(curr)) {
                return curr;
            }
            seen.add(curr);
            curr = curr.next;
        }

        // 无环
        return null;
    }
}
```

## 复杂度分析

### 方法一、二：快慢指针
- **时间复杂度**：O(n)
  - 第一阶段找相遇点：O(n)
  - 第二阶段找环入口：O(n)
- **空间复杂度**：O(1)，只使用几个指针

### 方法三：哈希表
- **时间复杂度**：O(n)，遍历链表一次
- **空间复杂度**：O(n)，需要存储所有访问过的节点

## 图解示例

以 `head = [3,2,0,-4], pos = 1` 为例：

```
链表结构：
       入口
        ↓
3 → 2 → 0 → -4
    ↑________|

距离标注：
head 到入口(2): a = 1
入口(2) 到相遇点: b
相遇点 到入口(2): c
环长度: b + c

快慢指针移动过程：

初始：slow = 3, fast = 3

第1步：slow = 2, fast = 0

第2步：slow = 0, fast = 2

第3步：slow = -4, fast = -4  (相遇！)

数学关系：
slow 走了: a + b
fast 走了: a + b + (b + c) = a + 2b + c
因为 fast 是 slow 的 2 倍:
2(a + b) = a + 2b + c
a = c

找入口：
ptr1 从 head(3) 出发
ptr2 从相遇点(-4) 出发

ptr1: 3 → 2 (走了 a=1 步)
ptr2: -4 → 2 (走了 c=1 步)

相遇于节点 2，即环入口！
```

## 关键点总结

1. **数学推导**：`a = c` 是关键，理解为什么从头和相遇点同时出发会在环入口相遇
2. **两阶段算法**：
   - 第一阶段：快慢指针判断有无环并找相遇点
   - 第二阶段：双指针找环入口
3. **指针重置**：相遇后，将一个指针重置到头部，另一个保持在相遇点
4. **同步移动**：第二阶段两指针都每次走 1 步
5. **Floyd 算法**：时间 O(n)，空间 O(1)，是最优解

## 易错点

1. **忘记判断无环**：第一阶段如果 fast 到达末尾，要返回 null
2. **指针重置位置**：第二阶段要把一个指针重置到 head，不是都重置
3. **移动步长**：第二阶段两指针都是每次走 1 步，不再是 1 步和 2 步
4. **相遇判断**：要判断指针引用相等（`==`），不是值相等
5. **边界情况**：空链表、单节点、无环等情况要处理
