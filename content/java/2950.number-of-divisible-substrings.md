## 题目描述

每个字母映射到数字（a-i→1，j-r→2，s-z→3），统计字符串 `word` 中数字之和能被子串长度整除的子串数目。

## 解题思路

平均值只可能为 1、2、3。枚举每个候选平均值 t，将问题转化为：数组 `a[i] = digit(s[i]) - t` 的前缀和为 0 的子数组计数问题，用哈希表 O(n) 完成。

## Java 代码实现

```java
class Solution {
    public int countDivisibleSubstrings(String word) {
        int n = word.length();
        int[] digits = new int[n];
        for (int i = 0; i < n; i++) {
            digits[i] = (word.charAt(i) - 'a') / 9 + 1; // a-i:1, j-r:2, s-z:3
        }

        int ans = 0;
        // 枚举平均值 t = 1, 2, 3
        for (int t = 1; t <= 3; t++) {
            Map<Integer, Integer> cnt = new HashMap<>();
            cnt.put(0, 1); // 空前缀
            int prefix = 0;
            for (int d : digits) {
                prefix += d - t;
                ans += cnt.getOrDefault(prefix, 0);
                cnt.merge(prefix, 1, Integer::sum);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)（枚举 3 个平均值，每次 O(n)）
- **空间复杂度**：O(n)

## 关键点总结

1. 子串平均值只可能是 1、2、3（字母数字映射范围）
2. 对每个候选平均值 t，令 `a[i] = digit(i) - t`，子串和为 0 等价于平均值为 t
3. 前缀和 + 哈希表统计前缀和相等的对数
