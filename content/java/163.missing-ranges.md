## 题目描述

给定一个排序的整数数组 `nums`，其中元素的范围在闭区间 `[lower, upper]` 当中，返回不包含在数组中的缺失区间。

**示例 1：**
```
输入：nums = [0, 1, 3, 50, 75], lower = 0, upper = 99
输出：[[2,2],[4,49],[51,74],[76,99]]
解释：返回的区间是：
[2,2]
[4,49]
[51,74]
[76,99]
```

**示例 2：**
```
输入：nums = [-1], lower = -1, upper = -1
输出：[]
解释：没有缺失的区间，因为没有被覆盖的数字。
```

**提示：**
- -10^9 <= lower <= upper <= 10^9
- 0 <= nums.length <= 100
- lower <= nums[i] <= upper
- nums 中的所有值互不相同

## 解题描述

这道题要求找出 [lower, upper] 范围内，不在 nums 数组中的所有缺失区间。

**核心思路：**

1. **遍历数组**，检查相邻元素之间的间隙
2. **特殊处理**：
   - 第一个元素前的间隙（从 lower 到 nums[0] - 1）
   - 相邻元素之间的间隙
   - 最后一个元素后的间隙（从 nums[-1] + 1 到 upper）

3. **间隙判断**：
   - 如果前一个数 + 1 < 后一个数，说明有缺失区间
   - 缺失区间为 [前一个数 + 1, 后一个数 - 1]

**算法流程：**

1. 初始化 prev = lower - 1（虚拟的前一个数）
2. 遍历 nums，最后追加 upper + 1（虚拟的后一个数）
3. 对于每个当前数 curr：
   - 如果 prev + 1 < curr，存在缺失区间 [prev + 1, curr - 1]
   - 更新 prev = curr

## Java 代码实现

### 方法一：一次遍历（推荐）⭐

```java
class Solution {
    public List<List<Integer>> findMissingRanges(int[] nums, int lower, int upper) {
        List<List<Integer>> result = new ArrayList<>();

        // prev 表示前一个已处理的数字
        // 使用 long 避免 lower - 1 溢出
        long prev = (long) lower - 1;

        for (int i = 0; i <= nums.length; i++) {
            // 使用 long 避免 upper + 1 溢出
            long curr = (i < nums.length) ? nums[i] : (long) upper + 1;

            // 检查是否有缺失区间
            if (prev + 1 < curr) {
                List<Integer> range = new ArrayList<>();
                range.add((int)(prev + 1));  // 缺失区间的起点
                range.add((int)(curr - 1));  // 缺失区间的终点
                result.add(range);
            }

            // 更新 prev
            prev = curr;
        }

        return result;
    }
}
```

### 方法二：分段处理（更清晰）

```java
class Solution {
    public List<List<Integer>> findMissingRanges(int[] nums, int lower, int upper) {
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;

        // 特殊情况：空数组
        if (n == 0) {
            result.add(Arrays.asList(lower, upper));
            return result;
        }

        // 1. 处理第一个元素前的间隙
        if (nums[0] > lower) {
            result.add(Arrays.asList(lower, nums[0] - 1));
        }

        // 2. 处理相邻元素之间的间隙
        for (int i = 1; i < n; i++) {
            if (nums[i] - nums[i - 1] > 1) {
                result.add(Arrays.asList(nums[i - 1] + 1, nums[i] - 1));
            }
        }

        // 3. 处理最后一个元素后的间隙
        if (nums[n - 1] < upper) {
            result.add(Arrays.asList(nums[n - 1] + 1, upper));
        }

        return result;
    }
}
```

### 方法三：辅助函数版本

```java
class Solution {
    public List<List<Integer>> findMissingRanges(int[] nums, int lower, int upper) {
        List<List<Integer>> result = new ArrayList<>();
        long prev = (long) lower - 1;

        for (int i = 0; i < nums.length; i++) {
            long curr = nums[i];
            // 添加 prev+1 到 curr-1 的缺失区间
            addRange(result, prev + 1, curr - 1);
            prev = curr;
        }

        // 添加最后的缺失区间
        addRange(result, prev + 1, upper);

        return result;
    }

    private void addRange(List<List<Integer>> result, long start, long end) {
        // 添加有效区间到结果中
        if (start <= end) {
            result.add(Arrays.asList((int) start, (int) end));
        }
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是数组长度，需要遍历数组一次
- 空间复杂度：O(1)，不计入结果数组的空间

## 图解示例

示例 1：nums = [0, 1, 3, 50, 75], lower = 0, upper = 99

```
lower = 0                                    upper = 99
|                                                     |
0   1       3               50      75               99
|   |       |               |       |                |
    
缺失区间：
1. nums[0]=0 前：无缺失（0 == lower）
2. 0 和 1 之间：无缺失（连续）
3. 1 和 3 之间：[2, 2]
4. 3 和 50 之间：[4, 49]
5. 50 和 75 之间：[51, 74]
6. 75 之后到 upper：[76, 99]

结果：[[2,2], [4,49], [51,74], [76,99]]
```

示例 2：nums = [-1], lower = -1, upper = -1

```
lower = -1, upper = -1, nums = [-1]

-1 正好覆盖了整个范围
结果：[]
```

## 关键点总结

1. **虚拟边界**：使用 prev = lower - 1 和 upper + 1 简化边界处理
2. **间隙判断**：prev + 1 < curr 表示有缺失区间
3. **区间表示**：缺失区间为 [prev + 1, curr - 1]
4. **边界情况**：空数组、单元素数组、完全覆盖等
5. **使用 long**：避免 lower - 1 或 upper + 1 的整数溢出

## 易错点

1. **边界处理**：
   - 忘记处理第一个元素前的间隙
   - 忘记处理最后一个元素后的间隙
2. **间隙判断条件**：
   - 应该是 `prev + 1 < curr`，不是 `prev < curr`
   - 缺失区间是 `[prev + 1, curr - 1]`
3. **空数组**：nums 为空时，整个 [lower, upper] 都是缺失区间
4. **整数溢出**：Java 中 `lower - 1` 若 lower 为 Integer.MIN_VALUE 会溢出，需用 `long`
5. **完全覆盖**：nums 恰好覆盖 [lower, upper] 时返回空列表
