## 题目描述

给定整数数组 `nums` 和整数 `k`，统计满足 `nums[i] + nums[j] <= k`（`i < j`）的配对数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPairs(int[] nums, int k) {
        Arrays.sort(nums);
        int l = 0, r = nums.length - 1;
        int count = 0;

        while (l < r) {
            if (nums[l] + nums[r] <= k) {
                // nums[l] 与 nums[l+1..r] 的任意元素配对都满足
                count += r - l;
                l++;
            } else {
                r--;
            }
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，主要是排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后双指针是解决"两数之和满足不等式条件"的经典技巧
2. 当 `nums[l] + nums[r] <= k` 时，`l` 与 `l+1` 到 `r` 间的所有元素配对均满足
3. 计数为 `r - l`（不加 1，因为 l 不与自身配对）
