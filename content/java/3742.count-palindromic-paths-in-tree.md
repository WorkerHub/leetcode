## 题目描述

给定一棵 `n` 个节点的无向树，每条边有一个小写字母标签，统计所有路径上的字符构成回文串的点对 `(u, v)`（`u < v`）的数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private long ans = 0;
    private Map<Integer, Integer> maskCount = new HashMap<>();
    private List<int[]>[] graph;

    public long countPalindromicPaths(int n, int[][] edges) {
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            int bit = 1 << (e[2] - 'a');
            graph[e[0]].add(new int[]{e[1], bit});
            graph[e[1]].add(new int[]{e[0], bit});
        }

        maskCount.put(0, 1); // 根节点虚拟起点掩码为 0
        dfs(0, -1, 0);
        return ans;
    }

    private void dfs(int node, int parent, int mask) {
        // 统计与当前掩码配对的历史掩码数量
        ans += maskCount.getOrDefault(mask, 0); // 差为 0
        for (int i = 0; i < 26; i++) {
            ans += maskCount.getOrDefault(mask ^ (1 << i), 0); // 差为一位
        }

        maskCount.merge(mask, 1, Integer::sum);

        for (int[] nei : graph[node]) {
            if (nei[0] != parent) {
                dfs(nei[0], node, mask ^ nei[1]);
            }
        }

        // 回溯
        maskCount.merge(mask, -1, Integer::sum);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，每个节点处理 26 种可能的掩码
- 空间复杂度：O(n)

## 关键点总结

1. 路径回文 ⟺ 路径字符的奇偶掩码 XOR 为 0 或 2 的幂（至多一个奇数次字符）
2. 从根到各节点的路径掩码 XOR 等于路径 `(u, v)` 的掩码
3. DFS 回溯时需恢复 maskCount 哈希表
