## 题目描述

给你一个数组 `nums` ，请你完成两类查询。

1. 其中一类查询要求**更新**数组 `nums` 下标对应的值
2. 另一类查询要求返回数组 `nums` 中索引 `left` 和索引 `right` 之间（**包含**）的nums元素的**和**，其中 `left <= right`

实现 `NumArray` 类：

- `NumArray(int[] nums)` 用整数数组 `nums` 初始化对象
- `void update(int index, int val)` 将 `nums[index]` 的值**更新**为 `val`
- `int sumRange(int left, int right)` 返回数组 `nums` 中索引 `left` 和索引 `right` 之间（**包含**）的nums元素的**和**（即，`nums[left] + nums[left + 1], ..., nums[right]`）

**示例 1：**
```
输入：
["NumArray", "sumRange", "update", "sumRange"]
[[[1, 3, 5]], [0, 2], [1, 2], [0, 2]]
输出：
[null, 9, null, 8]

解释：
NumArray numArray = new NumArray([1, 3, 5]);
numArray.sumRange(0, 2); // 返回 1 + 3 + 5 = 9
numArray.update(1, 2);   // nums = [1,2,5]
numArray.sumRange(0, 2); // 返回 1 + 2 + 5 = 8
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `0 <= index < nums.length`
- `-100 <= val <= 100`
- `0 <= left <= right < nums.length`
- 调用 `update` 和 `sumRange` 方法次数不大于 `3 * 10^4`

## 解题思路

这道题相比 303 题（不可变数组）增加了**更新操作**，需要支持动态修改。

### 方法对比

| 方法 | 更新时间 | 查询时间 | 空间 | 适用场景 |
|------|---------|---------|------|----------|
| 暴力 | O(1) | O(n) | O(1) | 更新多、查询少 |
| 前缀和 | O(n) | O(1) | O(n) | 只查询不更新 |
| 树状数组 | O(log n) | O(log n) | O(n) | **推荐** |
| 线段树 | O(log n) | O(log n) | O(n) | 功能更强大 |

### 树状数组（Binary Indexed Tree / Fenwick Tree）⭐

**核心思想**：用一个数组 `tree` 维护前缀和，每个位置存储部分区间的和。

**lowbit(x)**：`x` 的二进制表示中最低位的 1 及其后面的 0 组成的数
- 例如：`lowbit(6) = lowbit(110₂) = 10₂ = 2`
- 计算：`lowbit(x) = x & (-x)`

**tree[i] 的含义**：从 `i - lowbit(i) + 1` 到 `i` 的区间和

## Java 代码实现

### 方法一：树状数组（推荐）⭐

```java
class NumArray {
    private int n;
    private int[] nums;  // 原数组
    private int[] tree;  // 树状数组（索引从 1 开始）

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = new int[n];
        this.tree = new int[n + 1];

        // 初始化
        for (int i = 0; i < n; i++) {
            update(i, nums[i]);
        }
    }

    public void update(int index, int val) {
        // 更新 nums[index] 的值为 val
        // 计算差值
        int delta = val - nums[index];
        nums[index] = val;

        // 更新树状数组
        int i = index + 1; // 树状数组索引从 1 开始
        while (i <= n) {
            tree[i] += delta;
            i += lowbit(i);
        }
    }

    public int sumRange(int left, int right) {
        // 返回区间 [left, right] 的和
        return prefixSum(right) - prefixSum(left - 1);
    }

    private int prefixSum(int index) {
        // 计算前缀和 nums[0..index]
        if (index < 0) return 0;

        int result = 0;
        int i = index + 1; // 树状数组索引从 1 开始
        while (i > 0) {
            result += tree[i];
            i -= lowbit(i);
        }

        return result;
    }

    private int lowbit(int x) {
        // 计算 lowbit(x)
        return x & (-x);
    }
}
```

### 方法二：线段树

```java
class NumArray {
    private int n;
    private int[] nums;
    private int[] tree; // 线段树数组，大小为 4n

    public NumArray(int[] nums) {
        this.n = nums.length;
        this.nums = nums.clone();
        // 线段树数组大小为 4n
        this.tree = new int[4 * n];

        // 构建线段树
        if (n > 0) buildTree(0, 0, n - 1);
    }

    private void buildTree(int node, int start, int end) {
        // 构建线段树
        if (start == end) {
            // 叶子节点
            tree[node] = nums[start];
            return;
        }

        int mid = (start + end) / 2;
        int leftNode = 2 * node + 1;
        int rightNode = 2 * node + 2;

        // 递归构建左右子树
        buildTree(leftNode, start, mid);
        buildTree(rightNode, mid + 1, end);

        // 当前节点的值是左右子树的和
        tree[node] = tree[leftNode] + tree[rightNode];
    }

    public void update(int index, int val) {
        // 更新 nums[index] 的值为 val
        nums[index] = val;
        updateTree(0, 0, n - 1, index, val);
    }

    private void updateTree(int node, int start, int end, int index, int val) {
        // 更新线段树
        if (start == end) {
            // 找到叶子节点
            tree[node] = val;
            return;
        }

        int mid = (start + end) / 2;
        int leftNode = 2 * node + 1;
        int rightNode = 2 * node + 2;

        if (index <= mid) {
            // 在左子树
            updateTree(leftNode, start, mid, index, val);
        } else {
            // 在右子树
            updateTree(rightNode, mid + 1, end, index, val);
        }

        // 更新当前节点
        tree[node] = tree[leftNode] + tree[rightNode];
    }

    public int sumRange(int left, int right) {
        // 返回区间 [left, right] 的和
        return queryTree(0, 0, n - 1, left, right);
    }

    private int queryTree(int node, int start, int end, int left, int right) {
        // 查询线段树
        // 区间完全不重叠
        if (right < start || left > end) return 0;

        // 区间完全包含
        if (left <= start && end <= right) return tree[node];

        // 部分重叠，分别查询左右子树
        int mid = (start + end) / 2;
        int leftNode = 2 * node + 1;
        int rightNode = 2 * node + 2;

        int leftSum = queryTree(leftNode, start, mid, left, right);
        int rightSum = queryTree(rightNode, mid + 1, end, left, right);

        return leftSum + rightSum;
    }
}
```

### 方法三：分块（Block Decomposition）

```java
class NumArray {
    private int[] nums;
    private int n;
    private int blockSize;
    private int[] blocks;

    public NumArray(int[] nums) {
        this.nums = nums.clone();
        this.n = nums.length;

        // 块的大小，通常取 sqrt(n)
        this.blockSize = (int) Math.sqrt(n) + 1;
        int blockCount = (n + blockSize - 1) / blockSize;
        this.blocks = new int[blockCount];

        // 初始化块
        for (int i = 0; i < n; i++) {
            blocks[i / blockSize] += nums[i];
        }
    }

    public void update(int index, int val) {
        // 更新 nums[index] 的值为 val
        int blockIdx = index / blockSize;
        blocks[blockIdx] += val - nums[index];
        nums[index] = val;
    }

    public int sumRange(int left, int right) {
        // 返回区间 [left, right] 的和
        int result = 0;
        int leftBlock = left / blockSize;
        int rightBlock = right / blockSize;

        if (leftBlock == rightBlock) {
            // 在同一个块内
            for (int i = left; i <= right; i++) {
                result += nums[i];
            }
        } else {
            // 跨多个块
            // 左边块的部分元素
            for (int i = left; i < (leftBlock + 1) * blockSize; i++) {
                result += nums[i];
            }

            // 中间的完整块
            for (int i = leftBlock + 1; i < rightBlock; i++) {
                result += blocks[i];
            }

            // 右边块的部分元素
            for (int i = rightBlock * blockSize; i <= right; i++) {
                result += nums[i];
            }
        }

        return result;
    }
}
```

### 方法四：暴力方法（不推荐）

```java
class NumArray {
    private int[] nums;

    public NumArray(int[] nums) {
        this.nums = nums.clone();
    }

    public void update(int index, int val) {
        nums[index] = val;
    }

    public int sumRange(int left, int right) {
        int sum = 0;
        for (int i = left; i <= right; i++) {
            sum += nums[i];
        }
        return sum;
    }
}
```

## 复杂度分析

| 方法 | 初始化 | 更新 | 查询 | 空间 |
|------|--------|------|------|------|
| 树状数组 | O(n log n) | O(log n) | O(log n) | O(n) |
| 线段树 | O(n) | O(log n) | O(log n) | O(n) |
| 分块 | O(n) | O(1) | O(√n) | O(n) |
| 暴力 | O(1) | O(1) | O(n) | O(1) |

## 关键点总结

1. **树状数组核心**：
   - `lowbit(x) = x & (-x)`
   - 更新：向上传播（`i += lowbit(i)`）
   - 查询：向下累加（`i -= lowbit(i)`）

2. **树状数组索引**：通常从 1 开始，0 位置不用

3. **线段树特点**：
   - 功能更强大（支持区间更新）
   - 实现稍复杂
   - 空间 4n

4. **选择建议**：
   - 单点更新 + 区间查询：树状数组
   - 区间更新 + 区间查询：线段树
   - 追求简单：分块

## 易错点

1. **树状数组索引**：注意从 1 开始，需要 +1/-1 转换
2. **lowbit 计算**：`x & (-x)` 不要写错
3. **更新逻辑**：树状数组更新的是差值，不是绝对值
4. **边界条件**：`prefixSum(-1)` 应该返回 0
5. **初始化**：树状数组需要逐个 update，不能直接赋值
