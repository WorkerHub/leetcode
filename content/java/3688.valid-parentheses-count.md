## 题目描述

给你一个包含 `(`、`)` 和 `?` 的字符串 `s`，其中 `?` 可以替换为 `(` 或 `)`。返回能使字符串成为有效括号序列的方案数，对 `10^9 + 7` 取模。

## 解题思路

DP：`dp[j]` 表示当前未匹配 `(` 数量为 j 的方案数。对 `(` 转移到 j+1，对 `)` 转移到 j-1（j>0），对 `?` 两种转移都做。最终 `dp[0]` 为答案。

## Java 代码实现

```java
class Solution {
    public int countWays(String s) {
        final int MOD = 1_000_000_007;
        int n = s.length();
        long[] dp = new long[n + 1];
        dp[0] = 1;

        for (char c : s.toCharArray()) {
            long[] newDp = new long[n + 1];
            for (int j = 0; j <= n; j++) {
                if (dp[j] == 0) continue;
                if (c == '(' || c == '?') {
                    if (j + 1 <= n) newDp[j + 1] = (newDp[j + 1] + dp[j]) % MOD;
                }
                if (c == ')' || c == '?') {
                    if (j > 0) newDp[j - 1] = (newDp[j - 1] + dp[j]) % MOD;
                }
            }
            dp = newDp;
        }
        return (int) dp[0];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. DP 状态为当前未匹配的 `(` 数量
2. `?` 尝试两种转移
3. 最终未匹配数为 0 才有效
