## 题目描述

给你一个整数数组 `possible`，Alice 选前 k 个关卡，Bob 选剩余关卡，1 分/0 扣 1 分。返回使 Alice 得分严格大于 Bob 的最小 k，不存在返回 -1。

## 解题思路

将 0 转为 -1 计算得分，用前缀和遍历所有分割点 k（1 到 n-1），找第一个满足 alice > bob 的 k。

## Java 代码实现

```java
class Solution {
    public int minimumLevels(int[] possible) {
        int n = possible.length;
        // 计算总得分（0 视为 -1）
        int total = 0;
        for (int x : possible) total += x == 1 ? 1 : -1;

        int alice = 0;
        for (int k = 1; k < n; k++) {
            alice += possible[k - 1] == 1 ? 1 : -1;
            int bob = total - alice;
            if (alice > bob) return k;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 将二值数组转为 (+1/-1) 得分，用总分减去 Alice 部分得 Bob 部分
2. k 范围 1 到 n-1，条件为严格大于
