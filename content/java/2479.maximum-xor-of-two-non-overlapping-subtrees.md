## 题目描述

给你 `n` 节点无权无向树，每节点有值 `val[i]`，找两棵不重叠子树使其节点值之和的异或值最大，返回该最大异或值。

## 解题思路

枚举删边：删去一条树边后树分成两部分，两部分节点值之和的异或即为候选答案。先 DFS 计算每棵以节点 v 为根的子树值之和，枚举每条边找最大异或。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<Integer>[] adj;
    private long[] subSum;

    public long maxXor(int n, int[][] edges, int[] values) {
        adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            adj[e[0]].add(e[1]);
            adj[e[1]].add(e[0]);
        }
        subSum = new long[n];
        for (int i = 0; i < n; i++) subSum[i] = values[i];
        // 计算每棵子树的节点值之和
        calcSum(0, -1);

        long total = subSum[0];
        long ans = 0;
        // 枚举每条边，删去后两部分为 subSum[child] 和 total - subSum[child]
        for (int[] e : edges) {
            // 确定哪侧是子节点（子树之和较小的一侧）
            long s = Math.min(subSum[e[0]], subSum[e[1]]);
            ans = Math.max(ans, s ^ (total - s));
        }
        return ans;
    }

    private void calcSum(int node, int parent) {
        for (int nb : adj[node]) {
            if (nb != parent) {
                calcSum(nb, node);
                subSum[node] += subSum[nb];
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 删去一条边 = 将树分成两个不重叠子树，异或两部分的节点值之和
2. DFS 后序计算子树和，较小子树的和即为子节点方向的子树和
3. 使用 `long` 防止节点值之和溢出
