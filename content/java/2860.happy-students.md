## 题目描述

给你整数数组 nums，`nums[i]` 为第 i 名学生期望被选中的人数下限，从 n 人中选 k 人时被选者需 `k > nums[i]`，未选者需 `k < nums[i]`，返回让所有人都满意的选法数量。

## 解题思路

排序后枚举 k（0 到 n）：对于选 k 人，检查 `nums[k-1] < k`（被选者满意）且 `nums[k] > k`（未选者满意），k=0 和 k=n 特殊处理。

## Java 代码实现

```java
class Solution {
    public int countWays(List<Integer> nums) {
        List<Integer> sorted = new ArrayList<>(nums);
        Collections.sort(sorted);
        int n = sorted.size(), ans = 0;

        // k=0：所有人未被选，需要 nums[0] > 0
        if (sorted.get(0) > 0) ans++;

        // k=1 到 k=n-1
        for (int k = 1; k < n; k++) {
            // 最后一个被选者满足 nums[k-1] < k，第一个未选者满足 nums[k] > k
            if (sorted.get(k - 1) < k && sorted.get(k) > k) ans++;
        }

        // k=n：所有人被选，需要 nums[n-1] < n
        if (sorted.get(n - 1) < n) ans++;

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 排序后只需检查边界：被选者中最大的和未选者中最小的
2. 条件 `nums[k-1] < k < nums[k]` 覆盖一般情况
3. k=0 和 k=n 边界单独处理
