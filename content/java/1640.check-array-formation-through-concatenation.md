## 题目描述

给你整数数组 `arr` 和整数数组的数组 `pieces`（各数组首元素互不相同）。你可以任意顺序拼接 `pieces` 中的数组（每个只用一次，内部顺序不变），判断能否构成 `arr`。

## 解题思路

用 HashMap 将每个 piece 的**首元素**映射到该 piece，遍历 arr 时找对应 piece 并顺序验证。

## Java 代码实现

```java
class Solution {
    public boolean canFormArray(int[] arr, int[][] pieces) {
        // 以首元素作为 key，映射到对应 piece
        Map<Integer, int[]> pieceMap = new HashMap<>();
        for (int[] piece : pieces) {
            pieceMap.put(piece[0], piece);
        }

        int i = 0;
        while (i < arr.length) {
            if (!pieceMap.containsKey(arr[i])) return false; // 当前元素没有对应 piece

            int[] piece = pieceMap.get(arr[i]);
            // 检查 piece 中所有元素是否顺序匹配
            for (int j = 0; j < piece.length; j++) {
                if (i + j >= arr.length || arr[i + j] != piece[j]) return false;
            }
            i += piece.length; // 跳过已匹配的部分
        }

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 arr 长度
- **空间复杂度**：O(m)，m 为 pieces 总元素数

## 关键点总结

1. 以首元素为 key 建立 HashMap，O(1) 查找对应 piece
2. 找到 piece 后顺序验证所有元素
3. 题目保证 pieces 中整数各不相同，首元素唯一
