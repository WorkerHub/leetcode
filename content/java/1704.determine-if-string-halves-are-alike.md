## 题目描述

偶数长度字符串 `s`，前半部分 `a` 和后半部分 `b`，若两者元音数量相同则**相似**。返回是否相似。

## 解题思路

分别统计前后两半的元音数量，比较是否相等。

## Java 代码实现

```java
class Solution {
    public boolean halvesAreAlike(String s) {
        String vowels = "aeiouAEIOU";
        int n = s.length(), count = 0;
        for (int i = 0; i < n / 2; i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) count++;
        }
        for (int i = n / 2; i < n; i++) {
            if (vowels.indexOf(s.charAt(i)) != -1) count--;
        }
        return count == 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 元音包含大小写共 10 个字符
2. 统计前半+1、后半-1，最终为 0 则相似
