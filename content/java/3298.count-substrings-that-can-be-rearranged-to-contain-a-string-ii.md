## 题目描述

与 3297 完全相同的问题，但数据范围更大（`word1` 长度达 10^6），需要确保 O(n) 算法。

## 解题思路

与 3297 完全相同的滑动窗口算法，O(|word1| + |word2|) 即可处理更大数据量。

## Java 代码实现

```java
class Solution {
    public long validSubstringCount(String word1, String word2) {
        int[] need = new int[26];
        for (char c : word2.toCharArray()) need[c - 'a']++;
        int deficit = 0;
        for (int x : need) if (x > 0) deficit++;

        int[] have = new int[26];
        long ans = 0;
        int left = 0, n = word1.length();

        for (int right = 0; right < n; right++) {
            int ci = word1.charAt(right) - 'a';
            have[ci]++;
            if (need[ci] > 0 && have[ci] == need[ci]) deficit--;

            while (deficit == 0) {
                ans += n - right; // 以 left 开头、right 到 n-1 结尾的子串均满足
                int lci = word1.charAt(left) - 'a';
                have[lci]--;
                if (need[lci] > 0 && have[lci] < need[lci]) deficit++;
                left++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(|word1| + |word2|)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 与 3297 算法相同，滑动窗口 O(n) 天然支持 10^6 数据量
2. `deficit` 追踪未满足需求的字符种数，窗口有效时 deficit == 0
3. 结果用 `long` 防溢出（最大约 n*(n+1)/2 ~ 5×10^11）
