## 题目描述

给你正整数 `n`，三角形第 `i` 行有 `2i-1` 个单元格，找到涂最少单元格为红色的方案，使得不存在全为红色的向上朝向三角形，返回所有涂红单元格的 `[行, 列]`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[][] colorRed(int n) {
        List<int[]> ans = new ArrayList<>();
        // 每 4 行一个周期，根据距底部的偏移 (n - r) % 4 决定染色模式
        for (int r = 1; r <= n; r++) {
            int mod = (n - r) % 4;
            if (mod == 0) {
                // 涂所有奇数列
                for (int c = 1; c <= 2 * r - 1; c += 2) {
                    ans.add(new int[]{r, c});
                }
            } else if (mod == 1) {
                // 涂最后两列
                int total = 2 * r - 1;
                if (total >= 2) ans.add(new int[]{r, total - 1});
                ans.add(new int[]{r, total});
            } else if (mod == 2) {
                // 只涂第一列
                ans.add(new int[]{r, 1});
            }
            // mod == 3：不涂
        }
        return ans.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，最多每格涂一次
- 空间复杂度：O(n^2)，输出结果

## 关键点总结

1. 以 4 行为周期，用距底部偏移 `(n - r) % 4` 确定染色模式
2. 行和列均为 1-indexed，第 r 行有 2r-1 个格子
