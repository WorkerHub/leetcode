## 题目描述

给你由数字 1-9 组成的字符串 `s` 和整数 `k`，将 `s` 分割成若干值 <= `k` 的子字符串，返回最少分割数，无法完成则返回 `-1`。

## 解题思路

贪心：从左到右尽量延伸当前段，一旦再加一位就超过 `k` 则切割。若某单字符本身 > k 则直接返回 -1。

## Java 代码实现

```java
class Solution {
    public int minimumPartition(String s, int k) {
        int parts = 1;
        long cur = 0; // 当前段的数值，用 long 防止溢出

        for (char ch : s.toCharArray()) {
            int d = ch - '0';
            // 单字符超过 k，无法分割
            if (d > k) return -1;
            long newVal = cur * 10 + d;
            if (newVal > k) {
                // 当前段已满，开启新段
                parts++;
                cur = d;
            } else {
                cur = newVal;
            }
        }
        return parts;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心策略：每段尽可能长，值不超过 k
2. 若某单字符 > k，直接返回 -1（无法分割）
3. 整数拼接用 `cur * 10 + digit`，超过 k 时切割并重置
