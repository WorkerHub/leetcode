## 题目描述

实现 `LockingTree` 类，支持对 n 个节点的树进行 lock、unlock 和 upgrade 操作（upgrade 要求节点未锁定、无祖先被锁定、至少一个后代被锁定，成功则解锁所有后代锁并锁定该节点）。

## 解题思路

维护 `locked` 数组记录每个节点的锁定者（0 表示未锁定）和子节点列表。`lock`/`unlock` 直接操作；`upgrade` 向上检查祖先链，再 BFS 收集被锁定后代，满足条件后统一解锁并锁定目标节点。

## Java 代码实现

### 方法一：树模拟（推荐）

```java
import java.util.*;

class LockingTree {
    private int[] parent;
    private int[] locked;  // 0表示未锁定，>0表示锁定者userId
    private List<List<Integer>> children;

    public LockingTree(int[] parent) {
        int n = parent.length;
        this.parent = parent;
        this.locked = new int[n];
        this.children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) {
            children.get(parent[i]).add(i);
        }
    }

    public boolean lock(int num, int user) {
        if (locked[num] == 0) {
            locked[num] = user;
            return true;
        }
        return false;
    }

    public boolean unlock(int num, int user) {
        if (locked[num] == user) {
            locked[num] = 0;
            return true;
        }
        return false;
    }

    public boolean upgrade(int num, int user) {
        // 条件1：节点未被锁定
        if (locked[num] != 0) return false;

        // 条件3：祖先均未被锁定
        int cur = parent[num];
        while (cur != -1) {
            if (locked[cur] != 0) return false;
            cur = parent[cur];
        }

        // 条件2：BFS找被锁定的后代
        List<Integer> toUnlock = new ArrayList<>();
        Queue<Integer> queue = new LinkedList<>(children.get(num));
        while (!queue.isEmpty()) {
            int node = queue.poll();
            if (locked[node] != 0) toUnlock.add(node);
            queue.addAll(children.get(node));
        }

        if (toUnlock.isEmpty()) return false;

        // 解锁所有后代，锁定num
        for (int node : toUnlock) locked[node] = 0;
        locked[num] = user;
        return true;
    }
}
```

## 复杂度分析

- lock/unlock：O(1)
- upgrade：O(n)

## 关键点总结

1. `locked` 数组记录锁定者，0 表示未锁定（用户编号从 1 开始）
2. `upgrade` 需全部条件成立后才修改状态（先检查再修改）
3. BFS 收集后代中所有被锁定节点，统一解锁
