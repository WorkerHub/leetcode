## 题目描述

给你循环数组 `nums` 和查询数组 `queries`，对每个查询位置，找循环数组中最近的相同值元素的距离（不存在则 -1）。

## 解题思路

预计算：对每种值的所有下标排序存储。对每个查询位置，二分找到前后最近同值下标，用循环距离公式 `min(|a-b|, n-|a-b|)` 取最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] solveQueries(int[] nums, int[] queries) {
        int n = nums.length;

        // 预计算每个位置的最近相同值距离
        Map<Integer, List<Integer>> posMap = new HashMap<>();
        for (int i = 0; i < n; i++) {
            posMap.computeIfAbsent(nums[i], x -> new ArrayList<>()).add(i);
        }

        int[] dist = new int[n];
        Arrays.fill(dist, -1);

        for (Map.Entry<Integer, List<Integer>> entry : posMap.entrySet()) {
            List<Integer> inds = entry.getValue();
            int m = inds.size();
            if (m == 1) continue;

            for (int i = 0; i < m; i++) {
                int pos = inds.get(i);
                int prev = inds.get((i - 1 + m) % m);
                int next = inds.get((i + 1) % m);
                // 循环距离：顺时针和逆时针取最小
                int d = Math.min((pos - prev + n) % n, (next - pos + n) % n);
                dist[pos] = d;
            }
        }

        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            result[i] = dist[queries[i]];
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q)，预处理 O(n)，查询 O(1)
- 空间复杂度：O(n)

## 关键点总结

1. 预计算每个位置的答案，查询时 O(1) 直接返回
2. 循环距离：前一个同值距离 `(pos-prev+n)%n`，后一个 `(next-pos+n)%n`，取最小
3. 只有一个该值下标时返回 -1
