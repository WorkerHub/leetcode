## 题目描述

统计长度为n的小写字母字符串中，重排后能包含"leet"子串的数量（即至少1个l、2个e、1个t）。

## 解题思路

容斥原理：总数26^n减去不满足条件的（l=0或e<2或t=0的方案数）。

## Java 代码实现

```java
class Solution {
    private static final long MOD = 1_000_000_007;

    public int stringCount(int n) {
        // 容斥：26^n - |A∪B∪C|
        long total = pow(26, n);
        long A = pow(25, n); // l=0
        long B = (pow(25, n) + (long) n % MOD * pow(25, n - 1)) % MOD; // e<2
        long C = pow(25, n); // t=0

        long AB = (pow(24, n) + (long) n % MOD * pow(24, n - 1)) % MOD; // l=0,e<2
        long AC = pow(24, n); // l=0,t=0
        long BC = (pow(24, n) + (long) n % MOD * pow(24, n - 1)) % MOD; // e<2,t=0

        long ABC = (pow(23, n) + (long) n % MOD * pow(23, n - 1)) % MOD; // l=0,e<2,t=0

        long bad = ((A + B + C - AB - AC - BC + ABC) % MOD + MOD) % MOD;
        return (int) ((total - bad + MOD) % MOD);
    }

    private long pow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(logN)
- **空间复杂度**：O(1)

## 关键点总结

1. **转化条件**：包含"leet"等价于至少1个l、2个e、1个t
2. **容斥原理求补集**：不满足条件的更好计算
3. **快速幂取模**：n可达10^5
