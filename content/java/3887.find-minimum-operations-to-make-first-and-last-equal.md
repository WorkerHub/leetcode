## 题目描述

给你一个字符串 `s`，每次操作可以删除第一个或最后一个字符，返回使首尾字符相等所需的最少操作次数。

## 解题思路

枚举最终保留的 `(left, right)` 对（满足 `s[left] == s[right]`），操作数 = left + (n-1-right)，取最小值。特殊情况：删到只剩 1 个字符需 n-1 次。

## Java 代码实现

```java
class Solution {
    public int minOperations(String s) {
        int n = s.length();
        int ans = n - 1; // 最坏情况：删到只剩 1 个字符

        // 枚举所有 (left, right) 使 s[left] == s[right]，left < right
        for (int left = 0; left < n; left++) {
            for (int right = left + 1; right < n; right++) {
                if (s.charAt(left) == s.charAt(right)) {
                    // 操作数 = 删除前 left 个 + 删除后 (n-1-right) 个
                    int ops = left + (n - 1 - right);
                    ans = Math.min(ans, ops);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有 (left, right) 对
- 空间复杂度：O(1)

## 关键点总结

1. 最终需要找一对 `(left, right)` 使 `s[left] == s[right]`，操作数 = left + (n-1-right)。
2. 枚举所有合法 (left, right) 取最小操作数。
3. 特殊情况：只剩 1 个字符时首尾相同，代价 n-1。
