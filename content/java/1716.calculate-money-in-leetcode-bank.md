## 题目描述

第 `k` 周第 `d` 天存 `k + d - 1` 元（k、d 均从 1 开始），返回第 `n` 天结束时的总存款。

## 解题思路

**数学公式：** 设完整周数 `w = n / 7`，剩余天数 `r = n % 7`。完整周总和 = `7 * w*(w+1)/2 + 21*w`，剩余天总和 = `w*r + r*(r+1)/2`。

## Java 代码实现

```java
class Solution {
    public int totalMoney(int n) {
        int weeks = n / 7, days = n % 7;
        // 完整周总和：第 k 周贡献 7k+21，k=1..weeks
        int fullWeeks = 7 * weeks * (weeks + 1) / 2 + 21 * weeks;
        // 剩余不完整周（第 weeks+1 周）前 days 天
        int partial = weeks * days + days * (days + 1) / 2;
        return fullWeeks + partial;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 第 k 周第 d 天存 `k + d - 1`
2. 数学公式 O(1) 解决，无需模拟
