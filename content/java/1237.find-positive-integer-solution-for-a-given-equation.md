## 题目描述

给定单调递增函数 f(x,y) 和值 z，找出所有满足 f(x,y) == z 的正整数对 [x,y]。x, y 范围为 [1,1000]。

**示例：**
```
输入：f(x,y) = x + y, z = 5
输出：[[1,4],[2,3],[3,2],[4,1]]
```

## 解题思路

双指针：x 从 1 开始增大，y 从 1000 开始减小。利用 f 在两个维度上的单调性。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findSolution(CustomFunction customfunction, int z) {
        List<List<Integer>> result = new ArrayList<>();
        int x = 1, y = 1000;
        
        while (x <= 1000 && y >= 1) {
            int val = customfunction.f(x, y);
            if (val == z) {
                result.add(Arrays.asList(x, y));
                x++;
                y--;
            } else if (val < z) {
                x++;
            } else {
                y--;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n = 1000，最多移动 2000 步
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针**：类似有序矩阵搜索，从右上角出发
2. **单调性**：x 增大则 f 增大，y 减小则 f 减小
3. **找到后两指针同时移动**：因为 f 严格递增，不可能有相同 x 或 y
