## 题目描述

n 个筹码在不同位置，移动 2 单位代价为 0，移动 1 单位代价为 1。求将所有筹码移到同一位置的最小代价。

**示例：**
```
输入：position = [1,2,3]
输出：1
```

## 解题思路

移动偶数单位免费（多次移动 2），移动奇数单位代价为 1。所以同奇偶位置间移动免费，跨奇偶代价为 1。最优策略：将少数派移到多数派。

## Java 代码实现

```java
class Solution {
    public int minCostToMoveChips(int[] position) {
        int oddCount = 0, evenCount = 0;
        for (int pos : position) {
            if (pos % 2 == 0) evenCount++;
            else oddCount++;
        }
        // 将少数派移到多数派
        return Math.min(oddCount, evenCount);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **奇偶性**：同奇偶间移动免费，跨奇偶代价 1
2. **贪心**：将少数派移向多数派，代价最小
3. **答案**：min(奇数位置筹码数, 偶数位置筹码数)
