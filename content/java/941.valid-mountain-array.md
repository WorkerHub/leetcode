## 题目描述

判断数组是否为有效山脉数组（先严格递增后严格递减，山峰不在两端）。

**示例：**
```
输入：arr = [0,3,2,1]
输出：true
```

## 解题思路

从左向右找山峰（递增终止位置），再继续检查是否单调递减到末尾。山峰不能在首尾。

## Java 代码实现

```java
class Solution {
    public boolean validMountainArray(int[] arr) {
        int n = arr.length;
        if (n < 3) return false;

        int i = 0;
        // 上坡
        while (i + 1 < n && arr[i] < arr[i + 1]) i++;
        // 山峰不能在首尾
        if (i == 0 || i == n - 1) return false;
        // 下坡
        while (i + 1 < n && arr[i] > arr[i + 1]) i++;

        return i == n - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两阶段扫描**：先上坡再下坡
2. **山峰边界检查**：不能在数组首尾
3. **严格单调**：不允许相等相邻元素
