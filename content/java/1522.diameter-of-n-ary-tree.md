## 题目描述

给定 N 叉树根节点，计算树的直径（任意两节点间最长路径的边数）。

## 解题思路

DFS：每个节点返回最大深度，用最长两条子路径之和更新全局直径。

## Java 代码实现

```java
class Solution {
    private int diameter = 0;
    
    public int diameter(Node root) {
        dfs(root);
        return diameter;
    }
    
    private int dfs(Node node) {
        if (node == null) return 0;
        
        int max1 = 0, max2 = 0; // 最长和次长子路径
        for (Node child : node.children) {
            int depth = dfs(child) + 1;
            if (depth > max1) { max2 = max1; max1 = depth; }
            else if (depth > max2) { max2 = depth; }
        }
        
        diameter = Math.max(diameter, max1 + max2);
        return max1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)（递归深度）

## 关键点总结

1. **最长两条路径**：经过当前节点的直径 = max1 + max2
2. **返回最大深度**：供父节点使用
3. **全局更新**：每个节点都尝试更新答案
