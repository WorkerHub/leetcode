## 题目描述

三个线程分别调用 zero()、even()、odd()，输出序列 "0102030405..."（长度 2n）。zero 输出 0，odd 输出奇数，even 输出偶数。

**示例：**
```
输入：n = 5
输出："0102030405"
```

## 解题思路

三个信号量协调：zero 执行后根据当前轮次奇偶释放 odd_sem 或 even_sem，odd/even 执行后释放 zero_sem。

## Java 代码实现

```java
class ZeroEvenOdd {
    private int n;
    private Semaphore zeroSem = new Semaphore(1);
    private Semaphore oddSem = new Semaphore(0);
    private Semaphore evenSem = new Semaphore(0);

    public ZeroEvenOdd(int n) {
        this.n = n;
    }

    public void zero(IntConsumer printNumber) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            zeroSem.acquire();
            printNumber.accept(0);
            // 奇数轮释放 odd，偶数轮释放 even
            if (i % 2 == 0) oddSem.release();
            else evenSem.release();
        }
    }

    public void even(IntConsumer printNumber) throws InterruptedException {
        for (int i = 2; i <= n; i += 2) {
            evenSem.acquire();
            printNumber.accept(i);
            zeroSem.release();
        }
    }

    public void odd(IntConsumer printNumber) throws InterruptedException {
        for (int i = 1; i <= n; i += 2) {
            oddSem.acquire();
            printNumber.accept(i);
            zeroSem.release();
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **三信号量协调**：zero_sem=1 先执行，odd/even 初始为 0 等待
2. **奇偶轮次判断**：zero 内部 i%2==0 释放 odd，否则释放 even
3. **循环范围**：odd 输出 1,3,5...；even 输出 2,4,6...
