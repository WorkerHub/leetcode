## 题目描述

给定糖果数组candies和整数k，弟弟选连续k个糖果，返回你能获得的最多不同口味数。

## 解题思路

滑动窗口维护弟弟选的k个糖果，用哈希表统计窗口外（你的）不同口味数。窗口滑动时动态更新计数。

## Java 代码实现

```java
class Solution {
    public int shareCandies(int[] candies, int k) {
        int n = candies.length;
        if (k == 0) {
            Set<Integer> set = new HashSet<>();
            for (int c : candies) set.add(c);
            return set.size();
        }
        
        // 统计所有糖果频次
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int c : candies) cnt.merge(c, 1, Integer::sum);
        
        // 初始窗口[0, k-1]从cnt中减去
        for (int i = 0; i < k; i++) {
            cnt.merge(candies[i], -1, Integer::sum);
            if (cnt.get(candies[i]) == 0) cnt.remove(candies[i]);
        }
        
        int ans = cnt.size();
        
        // 滑动窗口
        for (int i = k; i < n; i++) {
            // 右边界加入窗口（从你的集合移除）
            cnt.merge(candies[i], -1, Integer::sum);
            if (cnt.get(candies[i]) == 0) cnt.remove(candies[i]);
            
            // 左边界移出窗口（归还你的集合）
            cnt.merge(candies[i - k], 1, Integer::sum);
            
            ans = Math.max(ans, cnt.size());
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **滑动窗口**：维护弟弟选的k个糖果区间
2. **动态更新**：窗口右移时加入新元素、移出旧元素
3. **删除零值键**：保证map.size()准确反映不同口味数
