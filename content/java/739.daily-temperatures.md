## 题目描述

给定整数数组 temperatures 表示每天的温度，返回数组 answer，其中 answer[i] 是第 i 天之后下一个更高温度出现在几天后。如果之后都不会更高，用 0 代替。

**示例：**
```
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
```

## 解题思路

单调栈：维护一个递减栈（存索引），遇到更高温度时弹出栈顶并计算天数差。

## Java 代码实现

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 当前温度高于栈顶，弹出并计算天数差
            while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
                int prevIndex = stack.pop();
                answer[prevIndex] = i - prevIndex;
            }
            stack.push(i);
        }
        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多入栈出栈一次
- **空间复杂度**：O(n)

## 关键点总结

1. **单调递减栈**：栈中索引对应的温度递减
2. **栈存索引**：方便计算天数差
3. **默认值 0**：栈中剩余的索引无需额外处理
