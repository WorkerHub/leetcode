## 题目描述

N×N 网格中，0 为空格，1 有樱桃，-1 有荆棘。从 (0,0) 到 (N-1,N-1) 再返回，摘取最多樱桃。

**示例：**
```
输入：grid = [[0,1,-1],[1,0,-1],[1,1,1]]
输出：5
```

## 解题思路

将往返问题转化为两个人同时从 (0,0) 走到 (N-1,N-1)。用三维 DP：dp[r1][c1][r2]，其中 c2 = r1+c1-r2。

## Java 代码实现

```java
class Solution {
    private int[][][] memo;
    private int[][] grid;
    private int n;

    public int cherryPickup(int[][] grid) {
        this.grid = grid;
        this.n = grid.length;
        this.memo = new int[n][n][n];
        for (int[][] layer : memo)
            for (int[] row : layer)
                Arrays.fill(row, Integer.MIN_VALUE);

        return Math.max(0, dfs(0, 0, 0));
    }

    private int dfs(int r1, int c1, int r2) {
        int c2 = r1 + c1 - r2;

        // 越界或遇到荆棘
        if (r1 >= n || c1 >= n || r2 >= n || c2 >= n) return -1;
        if (grid[r1][c1] == -1 || grid[r2][c2] == -1) return -1;

        // 到达终点
        if (r1 == n - 1 && c1 == n - 1) return grid[r1][c1];

        // 记忆化
        if (memo[r1][c1][r2] != Integer.MIN_VALUE) return memo[r1][c1][r2];

        // 摘樱桃
        int cherries = grid[r1][c1];
        if (r1 != r2) cherries += grid[r2][c2];

        // 四种移动组合
        int best = Math.max(
            Math.max(dfs(r1 + 1, c1, r2 + 1), dfs(r1, c1 + 1, r2 + 1)),
            Math.max(dfs(r1 + 1, c1, r2), dfs(r1, c1 + 1, r2))
        );

        if (best < 0) {
            memo[r1][c1][r2] = -1;
        } else {
            memo[r1][c1][r2] = cherries + best;
        }
        return memo[r1][c1][r2];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n³)

## 关键点总结

1. **问题转化**：往返 → 两人同时前进
2. **状态压缩**：c2 可由 r1+c1-r2 推出
3. **同一格去重**：两人在同一格时只摘一次
