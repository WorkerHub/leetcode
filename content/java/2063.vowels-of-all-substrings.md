## 题目描述

给定字符串 `word`，返回所有子字符串中元音字母的总数目。

## 解题思路

贡献法：位置 i 的元音字符出现在 `(i+1) * (n-i)` 个子串中（左端点 i+1 种，右端点 n-i 种），累加所有元音位置的贡献。注意结果可能超 int 范围，用 long。

## Java 代码实现

### 方法一：数学贡献法（推荐）

```java
class Solution {
    public long countVowels(String word) {
        int n = word.length();
        long total = 0;
        String vowels = "aeiou";
        for (int i = 0; i < n; i++) {
            if (vowels.indexOf(word.charAt(i)) >= 0) {
                total += (long)(i + 1) * (n - i);
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 位置 i 的字符出现在 `(i+1)*(n-i)` 个子串中
2. 只累加元音字符的贡献
3. 结果用 long（最大约 n^2/4 ~ 2.5*10^9）
