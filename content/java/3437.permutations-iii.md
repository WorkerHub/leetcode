## 题目描述

给定正整数 `n`，生成 `[1, n]` 所有相邻元素绝对差不为 1 的排列，按字典序返回。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private boolean[] used;
    private int n;

    public List<List<Integer>> permute(int n) {
        this.n = n;
        this.used = new boolean[n + 1];
        backtrack(new ArrayList<>());
        return result;
    }

    private void backtrack(List<Integer> current) {
        if (current.size() == n) {
            result.add(new ArrayList<>(current));
            return;
        }
        for (int num = 1; num <= n; num++) {
            if (used[num]) continue;
            // 剪枝：与上一个元素差不能为 1
            if (!current.isEmpty() && Math.abs(current.get(current.size() - 1) - num) == 1) continue;
            used[num] = true;
            current.add(num);
            backtrack(current);
            current.remove(current.size() - 1);
            used[num] = false;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n! * n)，最坏情况
- 空间复杂度：O(n)，递归栈深度

## 关键点总结

1. 回溯时提前剪枝：当前末尾与候选元素差为 1 时跳过
2. 从 1 到 n 依次尝试，生成结果自然按字典序排列
3. 条件是绝对差为 1（而非等于 1），要用 `Math.abs()`
