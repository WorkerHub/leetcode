## 题目描述

单词的**缩写**需要遵循 `<起始字母><省略字母的数量><结尾字母>` 这样的格式。

以下是一些单词缩写的范例：

```
a) it                      --> it    (没有缩写)
     1
b) d|o|g                   --> d1g
              1    1  1
     1---5----0----5--8
c) i|nternationalizatio|n  --> i18n
              1
     1---5----0
d) l|ocalizatio|n          --> l10n
```

假设你有一个字典和一个单词，请你判断该单词的**所有可能的缩写**。

返回答案时，你的答案需要按字典序排序。

**示例 1：**
```
输入：word = "word"
输出：["4","3d","2r1","2rd","1o2","1o1d","1or1","1ord","w3","w2d","w1r1","w1rd","wo2","wo1d","wor1","word"]
```

**示例 2：**
```
输入：word = "a"
输出：["1","a"]
```

**提示：**
- `1 <= word.length <= 15`
- `word` 仅由小写英文字母组成

## 解题思路

每个字符有两种选择：
1. **保留**：直接加入结果
2. **缩写**：计数，连续缩写的字符合并为一个数字

这是一个典型的**回溯**问题，也可以用**位运算**枚举。

### 方法对比

| 方法 | 说明 | 时间复杂度 |
|------|------|-----------|
| 回溯 | DFS遍历所有可能 | O(2^n × n) |
| 位运算 | 枚举所有子集 | O(2^n × n) |

## Java 代码实现

### 方法一：回溯（推荐）⭐

```java
import java.util.*;

class Solution {
    private List<String> result = new ArrayList<>();
    private String word;

    public List<String> generateAbbreviations(String word) {
        this.word = word;
        backtrack(0, new StringBuilder(), 0);
        return result;
    }

    /**
     * pos: 当前处理的位置
     * path: 当前构建的缩写
     * count: 当前连续缩写的字符数
     */
    private void backtrack(int pos, StringBuilder path, int count) {
        if (pos == word.length()) {
            // 如果还有未添加的计数，加上
            if (count > 0) path.append(count);
            result.add(path.toString());
            // 回溯：恢复 path
            if (count > 0) path.delete(path.length() - String.valueOf(count).length(), path.length());
            return;
        }

        // 选择1：缩写当前字符（计数加1）
        backtrack(pos + 1, path, count + 1);

        // 选择2：保留当前字符
        // 先加上之前的计数（如果有），再加当前字符
        int lenBefore = path.length();
        if (count > 0) path.append(count);
        path.append(word.charAt(pos));
        backtrack(pos + 1, path, 0);
        // 回溯
        path.delete(lenBefore, path.length());
    }
}
```

### 方法二：位运算

```java
import java.util.*;

class Solution {
    public List<String> generateAbbreviations(String word) {
        int n = word.length();
        List<String> result = new ArrayList<>();

        // 枚举所有可能的掩码
        for (int mask = 0; mask < (1 << n); mask++) {
            StringBuilder abbr = new StringBuilder();
            int count = 0;

            for (int i = 0; i < n; i++) {
                // 第 i 位为 1：缩写
                if ((mask & (1 << i)) != 0) {
                    count++;
                } else {
                    // 第 i 位为 0：保留
                    if (count > 0) {
                        abbr.append(count);
                        count = 0;
                    }
                    abbr.append(word.charAt(i));
                }
            }

            // 最后可能还有计数
            if (count > 0) abbr.append(count);

            result.add(abbr.toString());
        }

        return result;
    }
}
```

### 方法三：带详细注释的回溯

```java
import java.util.*;

class Solution {
    /**
     * 回溯生成所有缩写
     *
     * 核心思想：
     * - 每个字符有两种选择：保留 或 缩写
     * - 连续缩写的字符计数合并
     *
     * 例如 "word":
     * - 全保留: "word"
     * - 全缩写: "4"
     * - 部分: "w3", "w2d", "1ord", ...
     */
    public List<String> generateAbbreviations(String word) {
        List<String> result = new ArrayList<>();
        dfs(word, 0, new StringBuilder(), 0, result);
        return result;
    }

    /**
     * index: 当前处理的字符位置
     * current: 当前已构建的字符串
     * abbrCount: 当前连续缩写的字符数
     */
    private void dfs(String word, int index, StringBuilder current, int abbrCount, List<String> result) {
        // 递归终止：处理完所有字符
        if (index == word.length()) {
            // 如果还有未写入的缩写计数，加上
            if (abbrCount > 0) current.append(abbrCount);
            result.add(current.toString());
            // 回溯
            if (abbrCount > 0) current.delete(current.length() - String.valueOf(abbrCount).length(), current.length());
            return;
        }

        // 选择1：缩写当前字符（计数加1，字符串不变）
        dfs(word, index + 1, current, abbrCount + 1, result);

        // 选择2：保留当前字符
        // 先写入之前的缩写计数（如果有），再加当前字符
        int lenBefore = current.length();
        if (abbrCount > 0) current.append(abbrCount);
        current.append(word.charAt(index));

        dfs(word, index + 1, current, 0, result);

        // 回溯：恢复字符串
        current.delete(lenBefore, current.length());
    }
}
```

### 方法四：位运算详细版

```java
import java.util.*;

class Solution {
    public List<String> generateAbbreviations(String word) {
        int n = word.length();
        List<String> result = new ArrayList<>();

        // 枚举 [0, 2^n) 的所有数字
        for (int mask = 0; mask < (1 << n); mask++) {
            StringBuilder abbr = new StringBuilder();
            int abbrCount = 0;

            for (int i = 0; i < n; i++) {
                // 检查第 i 位是否为 1
                if ((mask & (1 << i)) != 0) {
                    // 缩写第 i 个字符
                    abbrCount++;
                } else {
                    // 保留第 i 个字符
                    // 先加缩写计数（如果有）
                    if (abbrCount > 0) {
                        abbr.append(abbrCount);
                        abbrCount = 0;
                    }
                    // 再加字符本身
                    abbr.append(word.charAt(i));
                }
            }

            // 处理剩余的缩写计数
            if (abbrCount > 0) abbr.append(abbrCount);

            result.add(abbr.toString());
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n × n)，生成 2^n 个结果，每个需要 O(n) 构建
- 空间复杂度：O(2^n × n)，存储所有结果

## 关键点总结

1. **两种选择**：每个字符保留或缩写
2. **计数合并**：连续缩写的字符合并为一个数字
3. **回溯模板**：标准的决策树遍历
4. **位运算枚举**：用二进制表示所有可能
5. **注意计数**：递归结束时可能还有未写入的计数

## 易错点

1. **计数处理**：
   - 递归结束时要检查是否还有计数
   - 保留字符前要先写入计数
2. **位运算**：第 i 位对应第 i 个字符
3. **回溯恢复**：Java 中使用 StringBuilder 需要记录长度并 delete 恢复
4. **边界情况**：空字符串、单字符
