## 题目描述

街道上有 n 盏灯，`lights[i] = [position, range]` 表示灯照亮 `[position-range, position+range]`，返回被照亮次数最多的最小位置。

## 解题思路

差分思想：在 `pos-range` 处亮度 +1，在 `pos+range+1` 处亮度 -1。用 TreeMap 存储差分事件，排序后扫描累加，第一次达到最大亮度时记录（升序扫描保证最小坐标）。

## Java 代码实现

### 方法一：差分 + 排序扫描（推荐）

```java
import java.util.*;

class Solution {
    public int brightestPosition(int[][] lights) {
        TreeMap<Integer, Integer> diff = new TreeMap<>();

        for (int[] light : lights) {
            int pos = light[0], r = light[1];
            diff.merge(pos - r, 1, Integer::sum);     // 进入区间
            diff.merge(pos + r + 1, -1, Integer::sum); // 离开区间
        }

        int maxBright = 0, curBright = 0, ans = 0;

        for (Map.Entry<Integer, Integer> entry : diff.entrySet()) {
            curBright += entry.getValue();
            if (curBright > maxBright) {
                maxBright = curBright;
                ans = entry.getKey(); // 升序扫描，第一次达到最大值即最小坐标
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 差分在 `pos+range+1` 处减 1（闭区间右端后一位）
2. TreeMap 保证按坐标升序，第一次达到最大亮度时即最小坐标
3. 坐标范围大（2*10^8），用 Map 代替数组
