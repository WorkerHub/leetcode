## 题目描述

给定两个字符串 `s` 和 `t`，如果它们的编辑距离为 1，则返回 `true`，否则返回 `false`。

字符串 s 和字符串 t 之间的编辑距离为 1 有三种可能的情况：
- 往 s 中插入恰好一个字符得到 t
- 从 s 中删除恰好一个字符得到 t
- 在 s 中用一个不同的字符替换恰好一个字符得到 t

**示例 1：**
```
输入：s = "ab", t = "acb"
输出：true
解释：可以将 'c' 插入字符串 s 来得到 t。
```

**示例 2：**
```
输入：s = "", t = ""
输出：false
解释：无法从空字符串变为另一个空字符串。
```

**示例 3：**
```
输入：s = "a", t = ""
输出：true
```

**示例 4：**
```
输入：s = "", t = "A"
输出：true
```

**提示：**
- 0 <= s.length, t.length <= 10^4
- s 和 t 由小写字母、大写字母和数字组成

## 解题思路

这道题要求判断两个字符串的编辑距离是否恰好为 1，注意是**恰好为 1**，不是小于等于 1。

**关键观察：**

1. **长度关系**：
   - 如果 `|len(s) - len(t)| > 1`，编辑距离必然大于 1，返回 false
   - 如果 `len(s) == len(t)`，只能是替换操作
   - 如果 `len(s) + 1 == len(t)` 或 `len(s) == len(t) + 1`，是插入或删除操作

2. **遍历策略**：
   - 同时遍历两个字符串
   - 遇到第一个不同字符时：
     - 长度相同：跳过这个字符，后续必须完全相同（替换）
     - 长度不同：跳过长字符串的字符，后续必须完全相同（插入/删除）
   - 如果发现第二个不同字符，返回 false

3. **边界情况**：
   - 两个空字符串：编辑距离为 0，返回 false
   - 两个完全相同的字符串：编辑距离为 0，返回 false

## Java 代码实现

### 方法一：一次遍历（推荐）⭐

```java
class Solution {
    public boolean isOneEditDistance(String s, String t) {
        int ns = s.length(), nt = t.length();

        // 确保 s 是较短的字符串，简化后续逻辑
        if (ns > nt) {
            return isOneEditDistance(t, s);
        }

        // 长度差大于 1，不可能是编辑距离 1
        if (nt - ns > 1) {
            return false;
        }

        // 遍历较短的字符串
        for (int i = 0; i < ns; i++) {
            if (s.charAt(i) != t.charAt(i)) {
                // 找到第一个不同的字符
                if (ns == nt) {
                    // 长度相同：替换操作，后续字符必须完全相同
                    return s.substring(i + 1).equals(t.substring(i + 1));
                } else {
                    // 长度不同：插入/删除操作
                    // s 的后续字符应该等于 t 跳过当前字符后的字符
                    return s.substring(i).equals(t.substring(i + 1));
                }
            }
        }

        // 所有字符都相同
        // 只有当长度差为 1 时才是编辑距离 1（在末尾插入/删除）
        // 如果长度相同且所有字符都相同，编辑距离为 0
        return ns + 1 == nt;
    }
}
```

### 方法二：双指针（更直观）

```java
class Solution {
    public boolean isOneEditDistance(String s, String t) {
        int ns = s.length(), nt = t.length();

        // 长度差大于 1
        if (Math.abs(ns - nt) > 1) {
            return false;
        }

        // 长度相同且字符串相同，编辑距离为 0
        if (ns == nt && s.equals(t)) {
            return false;
        }

        // 长度差为 0，需要恰好一次替换
        if (ns == nt) {
            int diffCount = 0;
            for (int i = 0; i < ns; i++) {
                if (s.charAt(i) != t.charAt(i)) {
                    diffCount++;
                    if (diffCount > 1) {
                        return false;
                    }
                }
            }
            return diffCount == 1;
        }

        // 长度差为 1，需要恰好一次插入/删除
        // 确保 s 是较短的字符串
        if (ns > nt) {
            String temp = s;
            s = t;
            t = temp;
            int tempLen = ns;
            ns = nt;
            nt = tempLen;
        }

        int i = 0; // s 的指针
        int j = 0; // t 的指针
        boolean foundDiff = false;

        while (i < ns && j < nt) {
            if (s.charAt(i) != t.charAt(j)) {
                if (foundDiff) {
                    return false;
                }
                foundDiff = true;
                j++; // 跳过 t 中的字符（删除操作）
            } else {
                i++;
                j++;
            }
        }

        return true;
    }
}
```

### 方法三：优化的一次遍历

```java
class Solution {
    public boolean isOneEditDistance(String s, String t) {
        int ns = s.length(), nt = t.length();

        // 确保 s 不长于 t
        if (ns > nt) {
            return isOneEditDistance(t, s);
        }

        // 长度差 > 1 或完全相同
        if (nt - ns > 1 || s.equals(t)) {
            return false;
        }

        // 查找第一个不同的位置
        for (int i = 0; i < ns; i++) {
            if (s.charAt(i) != t.charAt(i)) {
                // 长度相同：替换
                if (ns == nt) {
                    return s.substring(i + 1).equals(t.substring(i + 1));
                }
                // 长度不同：插入/删除
                return s.substring(i).equals(t.substring(i + 1));
            }
        }

        // 没有不同字符，说明 s 是 t 的前缀，且长度差为 1
        return true;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，其中 n 是较短字符串的长度，最多遍历一次
- 空间复杂度：O(1)（方法一、二）或 O(n)（substring 切片）

## 图解示例

**示例 1：s = "ab", t = "acb"（插入）**
```
s:  a   b
t:  a c b
    ↑ ↑
    相同，继续
      ↑
      不同！长度差为 1
      检查 s[1:] == t[2:]
      "b" == "b" ✓
      返回 true
```

**示例 2：s = "abc", t = "adc"（替换）**
```
s: a b c
t: a d c
   ↑ ↑
   相同，继续
     ↑
     不同！长度相同
     检查 s[2:] == t[2:]
     "c" == "c" ✓
     返回 true
```

**示例 3：s = "abc", t = "abcd"（末尾插入）**
```
s: a b c
t: a b c d
   
遍历完成，所有字符相同
长度差为 1
返回 true
```

## 关键点总结

1. **长度差判断**：首先通过长度差快速排除不可能的情况
2. **确保 s 较短**：交换 s 和 t 可以简化代码逻辑
3. **找第一个不同位置**：一旦找到，根据长度关系判断后续
4. **恰好为 1**：注意是恰好编辑距离 1，不是小于等于 1
5. **完全相同情况**：编辑距离为 0，应该返回 false

## 易错点

1. **完全相同的字符串**：编辑距离为 0，应返回 false，不是 true
2. **空字符串**：两个空字符串编辑距离为 0，返回 false
3. **长度判断**：要考虑 `nt - ns > 1` 的情况
4. **替换和插入混淆**：长度相同是替换，长度差 1 是插入/删除
5. **Java 字符串比较**：使用 `equals()` 而非 `==`
