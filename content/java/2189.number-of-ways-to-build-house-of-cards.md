## 题目描述

用恰好n张牌搭建纸牌屋，每层k个三角形消耗3k-1张牌，层数从下到上三角形严格递减，求方案数。

## 解题思路

记忆化递归/DP：dp(remaining, maxK)表示剩余remaining张牌、本层最多maxK个三角形时的方案数。枚举本层三角形数k并递归。

## Java 代码实现

```java
class Solution {
    private int[][] memo;
    
    public int houseOfCards(int n) {
        int maxK = (n + 1) / 3 + 1;
        memo = new int[n + 1][maxK + 1];
        for (int[] row : memo) Arrays.fill(row, -1);
        
        int ans = 0;
        for (int k = 1; 3 * k - 1 <= n; k++) {
            ans += dp(n - (3 * k - 1), k - 1);
        }
        return ans;
    }
    
    private int dp(int remaining, int maxTriangles) {
        if (remaining == 0) return 1;
        if (maxTriangles == 0) return 0;
        if (memo[remaining][maxTriangles] != -1) return memo[remaining][maxTriangles];
        
        int ans = 0;
        for (int k = 1; k <= maxTriangles; k++) {
            int cost = 3 * k - 1;
            if (cost > remaining) break;
            ans += dp(remaining - cost, k - 1);
        }
        memo[remaining][maxTriangles] = ans;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(N^2)

## 关键点总结

1. **每层消耗3k-1张牌**：2k张斜牌+k-1张水平牌
2. **严格递减约束**：上层三角形数<下层
3. **记忆化递归**：(remaining, maxTriangles)状态
