## 题目描述

给你一个混合字符串 `s`（由小写字母和数字组成），返回 `s` 中**第二大**的数字，不存在则返回 -1。

## 解题思路

维护最大值 `first` 和第二大值 `second`（初始为 -1），遍历字符串一次更新。

## Java 代码实现

```java
class Solution {
    public int secondHighest(String s) {
        int first = -1, second = -1; // 最大值和第二大值

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                int d = c - '0';
                if (d > first) {
                    second = first;
                    first = d;
                } else if (d > second && d != first) {
                    second = d;
                }
            }
        }

        return second;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 维护最大和第二大两个变量，一次遍历完成
2. 更新第二大值的条件：`d > second` 且 `d != first`（严格不同）
3. 初始值 -1 直接作为"不存在"的返回值
