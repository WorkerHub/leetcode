## 题目描述

给二进制数组 pattern 和无限二进制流 stream（通过 stream.next() 读取），返回 pattern 第一次出现的起始下标。

## 解题思路

KMP 算法流式匹配：预处理 pattern 的失配表，每次从 stream 读一个字符，用 KMP 更新已匹配前缀长度，匹配完整 pattern 时返回起始位置。

## Java 代码实现

```java
class Solution {
    public int findPattern(InfiniteStream stream, int[] pattern) {
        int m = pattern.length;
        // 构建 KMP 失配表
        int[] fail = new int[m];
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && pattern[i] != pattern[j]) j = fail[j - 1];
            if (pattern[i] == pattern[j]) j++;
            fail[i] = j;
        }
        // 流式 KMP 匹配
        int j = 0, idx = 0;
        while (true) {
            int c = stream.next();
            while (j > 0 && c != pattern[j]) j = fail[j - 1];
            if (c == pattern[j]) j++;
            if (j == m) return idx - m + 1;
            idx++;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，n 为找到匹配前读取的字符数
- **空间复杂度**：O(m)

## 关键点总结

1. KMP 适合流式匹配，每字符 O(1) 均摊更新状态
2. 失配表使回退效率高，不重复读字符
3. 起始下标 = idx - m + 1（idx 为当前末字符下标）
