## 题目描述

在社交媒体网站上有 `n` 个用户。给你一个整数数组 `ages`，其中 `ages[i]` 是第 `i` 个用户的年龄。

如果下述任意一个条件为真，那么用户 `x` 将不会向用户 `y`（`x != y`）发送好友请求：
- `age[y] <= 0.5 * age[x] + 7`
- `age[y] > age[x]`
- `age[y] > 100 && age[x] < 100`

否则，`x` 将会向 `y` 发送一个好友请求。

注意，如果 `x` 向 `y` 发送请求，`y` 不一定会向 `x` 发送请求。另外，用户不会向自己发送好友请求。

返回在该社交媒体网站上产生的好友请求总数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int numFriendRequests(int[] ages) {
        // 计数每个年龄的人数
        int[] count = new int[121];
        for (int age : ages) {
            count[age]++;
        }

        int result = 0;

        for (int ageX = 1; ageX <= 120; ageX++) {
            if (count[ageX] == 0) continue;

            for (int ageY = 1; ageY <= 120; ageY++) {
                if (count[ageY] == 0) continue;

                // 检查是否会发送请求（检查不发送的条件）
                if (ageY <= 0.5 * ageX + 7) continue;
                if (ageY > ageX) continue;
                if (ageY > 100 && ageX < 100) continue;

                // 计算请求数
                result += count[ageX] * count[ageY];
                // 同龄人不会向自己发送请求
                if (ageX == ageY) {
                    result -= count[ageX];
                }
            }
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(A²)，A 是年龄范围（最多 120）
- **空间复杂度**：O(A)

## 关键点总结

1. **计数优化**：相同年龄的人一起处理
2. **条件简化**：第三个条件可以省略（年龄 ≤ 120）
3. **自己排除**：同龄人之间要减去自己

## 学习建议

1. **计数优化**：统计频率减少重复计算
2. **逻辑化简**：简化复杂条件
