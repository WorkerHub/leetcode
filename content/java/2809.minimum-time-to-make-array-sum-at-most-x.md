## 题目描述

给你整数数组 `nums1` 和 `nums2`，每秒 `nums1[i]` 增加 `nums2[i]`，每秒可将某个 `nums1[i]` 清零，返回使 `nums1` 之和不超过 `x` 的最少操作次数（无法实现返回 -1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(List<Integer> nums1, List<Integer> nums2, int x) {
        int n = nums1.size();
        long sum1 = 0, sum2 = 0;
        for (int v : nums1) sum1 += v;
        for (int v : nums2) sum2 += v;

        // 按 nums2 升序排序后做 0-1 背包
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums2.get(i); // b
            pairs[i][1] = nums1.get(i); // a
        }
        Arrays.sort(pairs, (p, q) -> p[0] - q[0]);

        // dp[j] = 选 j 个元素能减少的最大值
        long[] dp = new long[n + 1];
        for (int i = 0; i < n; i++) {
            long b = pairs[i][0], a = pairs[i][1];
            for (int j = i + 1; j >= 1; j--) {
                // 选当前元素作为第 j 个操作，减少量 = a + j * b
                dp[j] = Math.max(dp[j], dp[j - 1] + a + (long) j * b);
            }
        }

        for (int t = 0; t <= n; t++) {
            if (sum1 + (long) t * sum2 - dp[t] <= x) return t;
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. 按 nums2 升序排序，排在第 j 位（1-indexed）的元素减少量为 `a + j*b`
2. 0-1 背包逆序更新防止重复选取同一元素
3. 枚举操作次数 t，检查 `sum1 + t*sum2 - dp[t] <= x`
