## 题目描述

给定矩阵 `board`（`' '` 为空格，`'#'` 为障碍，小写字母为已填字母），判断字符串 `word` 是否能水平或垂直放置（两端紧接边界或 `'#'`，空格可填，字母必须匹配）。

## 解题思路

枚举每行和每列由 `#` 或边界分隔的段，对段长等于单词长度的段检查是否可以放置（正向或反向，因为另一端可以从对面开始）。

## Java 代码实现

### 方法一：逐行/列枚举段（推荐）

```java
import java.util.*;

class Solution {
    public boolean placeWordInCrossword(char[][] board, String word) {
        int m = board.length, n = board[0].length;

        // 检查所有行（水平放置）
        for (int r = 0; r < m; r++) {
            List<Character> seg = new ArrayList<>();
            for (int c = 0; c <= n; c++) {
                if (c == n || board[r][c] == '#') {
                    if (canPlace(seg, word)) return true;
                    seg.clear();
                } else {
                    seg.add(board[r][c]);
                }
            }
        }

        // 检查所有列（垂直放置）
        for (int c = 0; c < n; c++) {
            List<Character> seg = new ArrayList<>();
            for (int r = 0; r <= m; r++) {
                if (r == m || board[r][c] == '#') {
                    if (canPlace(seg, word)) return true;
                    seg.clear();
                } else {
                    seg.add(board[r][c]);
                }
            }
        }

        return false;
    }

    private boolean canPlace(List<Character> seg, String word) {
        if (seg.size() != word.length()) return false;
        int k = word.length();
        // 正向检查
        boolean fwd = true;
        for (int i = 0; i < k; i++) {
            char c = seg.get(i);
            if (c != ' ' && c != word.charAt(i)) { fwd = false; break; }
        }
        if (fwd) return true;
        // 反向检查
        for (int i = 0; i < k; i++) {
            char c = seg.get(i);
            if (c != ' ' && c != word.charAt(k - 1 - i)) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * L)，L 为单词长度
- 空间复杂度：O(m + n)

## 关键点总结

1. 只有段长度等于单词长度时才需要检查
2. 单词可以正向或反向放置（反向等于从另一端开始）
3. 空格可任意填充，已有字母必须与单词对应字符相同
