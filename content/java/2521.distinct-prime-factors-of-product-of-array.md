## 题目描述

给你正整数数组 `nums`，返回所有元素乘积中**不同质因数**的数目（同一质因数多次出现只计 1 次）。

## 解题思路

无需实际求乘积。乘积的质因数等于各元素质因数的并集，对每个元素逐一分解质因数并收集到集合中，最终返回集合大小。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int distinctPrimeFactors(int[] nums) {
        Set<Integer> primes = new HashSet<>();
        for (int num : nums) {
            // 对每个数进行质因数分解
            for (int d = 2; (long) d * d <= num; d++) {
                if (num % d == 0) {
                    primes.add(d);
                    while (num % d == 0) num /= d;
                }
            }
            // 剩余部分本身是质数
            if (num > 1) primes.add(num);
        }
        return primes.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * sqrt(M))，M 为元素最大值（1000）
- **空间复杂度**：O(P)，P 为不同质因数数量

## 关键点总结

1. 乘积的质因数 = 各元素质因数的并集，无需求实际乘积
2. 标准质因数分解：从 2 到 sqrt(n) 试除
3. 试除后若剩余 > 1，该剩余数本身是质因数
