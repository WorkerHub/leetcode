## 题目描述

给定字符串 order 定义自定义顺序，对字符串 s 进行排序，使 s 中字符按 order 中的顺序排列。不在 order 中的字符可放任意位置。

**示例：**
```
输入：order = "cba", s = "abcd"
输出："cbad"
```

## 解题思路

计数 + 按序构建：统计 s 中每个字符频率，按 order 顺序输出，最后追加剩余字符。

## Java 代码实现

```java
class Solution {
    public String customSortString(String order, String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        StringBuilder sb = new StringBuilder();
        // 按 order 顺序添加
        for (char c : order.toCharArray()) {
            while (count[c - 'a'] > 0) {
                sb.append(c);
                count[c - 'a']--;
            }
        }
        // 添加剩余字符
        for (int i = 0; i < 26; i++) {
            while (count[i] > 0) {
                sb.append((char) ('a' + i));
                count[i]--;
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(1)，固定 26 个字母

## 关键点总结

1. **计数法**：统计 s 中字符频率
2. **按序输出**：先按 order 顺序，再输出剩余
3. **O(n) 优于排序**：比自定义比较器排序更快
