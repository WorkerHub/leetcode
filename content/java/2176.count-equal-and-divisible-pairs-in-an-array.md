## 题目描述

统计满足i<j、nums[i]==nums[j]且(i*j)%k==0的下标对数量。

## 解题思路

n<=100，O(n^2)暴力枚举所有对逐一检查三个条件。

## Java 代码实现

```java
class Solution {
    public int countPairs(int[] nums, int k) {
        int n = nums.length;
        int count = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] == nums[j] && (i * j) % k == 0) {
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(1)

## 关键点总结

1. **n<=100直接暴力**：O(n^2)完全可行
2. **三个条件**：下标有序、值相等、乘积整除k
3. **无需优化**：数据规模小
