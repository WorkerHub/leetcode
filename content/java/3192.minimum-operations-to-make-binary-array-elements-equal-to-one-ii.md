## 题目描述

给你二进制数组 `nums`，每次操作可将某下标到末尾的后缀全部翻转，返回使所有元素变为 1 的最少操作次数。

## 解题思路

贪心：从左到右扫描，用 `flipped` 记录当前累积翻转的奇偶性。遇到实际值为 0 的元素（`nums[i] XOR flipped == 0`），执行一次后缀翻转（翻转 flipped，操作数 +1）。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int ops = 0;
        int flipped = 0; // 当前累积翻转奇偶性

        for (int x : nums) {
            int cur = x ^ flipped; // 当前实际值
            if (cur == 0) {
                ops++;
                flipped ^= 1; // 执行后缀翻转
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 后缀翻转等价于改变此后所有元素的极性，用单个变量 `flipped` 记录
2. 遇到实际值为 0 时立即翻转，贪心策略保证最少操作次数
3. 实际值 = `nums[i] XOR flipped`
