## 题目描述

给正整数数组 nums，每次选两个不同下标 i、j，将 nums[i] 更新为 nums[i] % nums[j]（结果为 0 则可删除）。返回操作后数组最小长度。

## 解题思路

计算所有元素的 GCD：若 GCD < 最小值，则能产生更小的数，最终可将所有元素缩至 1 个；否则（GCD = 最小值），非最小值全可被删除，最小值之间两两取模每次消一个，最终剩 ceil(count/2)。

## Java 代码实现

```java
class Solution {
    public int minimumArrayLength(int[] nums) {
        int minVal = nums[0], g = nums[0];
        for (int x : nums) {
            minVal = Math.min(minVal, x);
            g = gcd(g, x);
        }
        // GCD < 最小值：可以产生更小的数，最终缩为 1
        if (g < minVal) return 1;
        // GCD == 最小值：只有最小值本身无法被完全消除
        int count = 0;
        for (int x : nums) if (x == minVal) count++;
        return (count + 1) / 2;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)
- **空间复杂度**：O(1)

## 关键点总结

1. GCD < 最小值时，答案为 1
2. GCD = 最小值时，非最小值元素全可删除
3. count 个相同值互相取模，最终剩 ceil(count/2)
