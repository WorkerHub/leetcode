## 题目描述

给定整数数组 `nums`，判断是否可以通过若干次相邻元素 AND/OR 操作使数组所有元素相等。

## Java 代码实现

```java
class Solution {
    public boolean canMakeEqual(int[] nums) {
        int n = nums.length;
        // 对每一位，若该位有些为 0 有些为 1（不一致），则无法使所有元素相等
        for (int b = 0; b < 30; b++) {
            int ones = 0;
            for (int x : nums) ones += (x >> b) & 1;
            if (ones != 0 && ones != n) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 30)
- 空间复杂度：O(1)

## 关键点总结

1. 若所有元素的每一位都一致（全 0 或全 1），则元素已相等
2. AND/OR 操作在相邻元素间进行，但若各位本身已一致则无需操作
3. 30 位足以覆盖 10^9 范围
