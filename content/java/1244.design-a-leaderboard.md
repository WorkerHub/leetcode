## 题目描述

设计排行榜，支持：addScore(playerId, score) 累加分数、top(K) 返回前 K 名总分和、reset(playerId) 重置为 0。

**示例：**
```
addScore(1,73), addScore(2,56), addScore(3,39)...
top(1) → 73
reset(1), reset(2), addScore(2,51)
top(3) → 141
```

## Java 代码实现

```java
class Leaderboard {
    private Map<Integer, Integer> scores;
    
    public Leaderboard() {
        scores = new HashMap<>();
    }
    
    public void addScore(int playerId, int score) {
        scores.merge(playerId, score, Integer::sum);
    }
    
    public int top(int K) {
        // 使用最小堆维护 top K
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        for (int score : scores.values()) {
            minHeap.offer(score);
            if (minHeap.size() > K) minHeap.poll();
        }
        int sum = 0;
        while (!minHeap.isEmpty()) sum += minHeap.poll();
        return sum;
    }
    
    public void reset(int playerId) {
        scores.remove(playerId);
    }
}
```

## 复杂度分析

- **addScore**：O(1)
- **top(K)**：O(n log K)
- **reset**：O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **HashMap 存分数**：playerId → 累积分数
2. **最小堆 top K**：维护 K 个最大值，堆顶是最小的
3. **reset = remove**：分数为 0 等于不存在
4. **merge 方法**：`scores.merge(id, score, Integer::sum)` 简洁累加
