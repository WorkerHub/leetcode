## 题目描述

3条跑道，obstacles[i]表示第i点的障碍跑道。从第2跑道出发，沿跑道前进免费，侧跳花费1次。求到终点的最少侧跳次数。

## 解题思路

DP：dp[j]表示当前在第j跑道的最少跳跃次数。每个点先标记障碍为INF，再用全局最小值+1更新无障碍跑道。

## Java 代码实现

```java
class Solution {
    public int minSideJumps(int[] obstacles) {
        int INF = Integer.MAX_VALUE / 2;
        int[] dp = {1, 0, 1}; // 起点在跑道2（索引1）
        
        for (int i = 1; i < obstacles.length; i++) {
            int obs = obstacles[i] - 1; // 转为0-indexed，-1表示无障碍
            if (obs >= 0) dp[obs] = INF;
            
            int minDp = Math.min(dp[0], Math.min(dp[1], dp[2]));
            for (int j = 0; j < 3; j++) {
                if (obstacles[i] != j + 1) { // 无障碍的跑道
                    dp[j] = Math.min(dp[j], minDp + 1);
                }
            }
        }
        return Math.min(dp[0], Math.min(dp[1], dp[2]));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **dp数组只需3个元素**：跑道数固定
2. **先标记障碍为INF**：再用最小值+1更新
3. **处理顺序重要**：先障碍后更新
