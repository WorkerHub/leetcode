## 题目描述

给你 `m x n` 的二进制矩阵 `grid`，返回最大好子集（子集中任意两行按位与为 0）的行下标，不存在则返回空数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> goodSubsetofBinaryMatrix(int[][] grid) {
        Map<Integer, Integer> seen = new HashMap<>();
        for (int i = 0; i < grid.length; i++) {
            // 将当前行编码为整数掩码
            int mask = 0;
            for (int j = 0; j < grid[i].length; j++) {
                if (grid[i][j] == 1) mask |= (1 << j);
            }
            // 全零行直接返回
            if (mask == 0) return List.of(i);
            // 找之前是否有行与当前行按位与为 0
            for (Map.Entry<Integer, Integer> entry : seen.entrySet()) {
                if ((entry.getKey() & mask) == 0) {
                    List<Integer> res = new ArrayList<>();
                    res.add(entry.getValue());
                    res.add(i);
                    Collections.sort(res);
                    return res;
                }
            }
            seen.put(mask, i);
        }
        return new ArrayList<>();
    }
}
```

## 复杂度分析

- 时间复杂度：O(m^2)，枚举行对
- 空间复杂度：O(m)

## 关键点总结

1. 好子集最大为 2，只需考虑 1 行或 2 行的情况
2. 两行按位与为 0 等价于没有列同时为 1
3. 优先检查全零行（任何行与之按位与均为 0）
