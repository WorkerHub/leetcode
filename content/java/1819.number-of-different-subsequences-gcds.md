## 题目描述

给你正整数数组 `nums`，返回其所有非空子序列的不同 GCD 数目。

## 解题思路

枚举每个候选 GCD 值 `g`（1 到 max(nums)）：在 nums 中找所有 g 的倍数，计算它们的 GCD；若等于 g 则 g 合法。总时间复杂度 O(max_val * log(max_val))（调和级数）。

## Java 代码实现

```java
class Solution {
    public int countDifferentSubsequenceGCDs(int[] nums) {
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // 标记哪些值在 nums 中出现
        boolean[] present = new boolean[maxVal + 1];
        for (int x : nums) present[x] = true;

        int result = 0;
        for (int g = 1; g <= maxVal; g++) {
            int curGcd = 0;
            // 枚举 g 的所有倍数
            for (int multiple = g; multiple <= maxVal; multiple += g) {
                if (present[multiple]) {
                    curGcd = gcd(curGcd, multiple);
                    if (curGcd == g) break; // 提前退出
                }
            }
            if (curGcd == g) result++;
        }

        return result;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max_val * log(max_val))
- **空间复杂度**：O(max_val)

## 关键点总结

1. 子序列 GCD 为 g 等价于：nums 中 g 的所有倍数的 GCD 恰好为 g
2. `gcd(0, x) = x`，初始 curGcd=0 是正确技巧
3. 发现 curGcd==g 时可提前退出内层循环
