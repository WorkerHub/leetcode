## 题目描述

对每个查询点，找包含它的最小区间的大小。不存在返回-1。

## 解题思路

离线查询+最小堆：查询按值排序，区间按左端点排序。扫描时将左端点≤q的区间入堆(按大小)，移除右端点<q的过期区间，堆顶即答案。

## Java 代码实现

```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        int n = intervals.length, m = queries.length;
        // 区间按左端点排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        // 查询按值排序，保留原始下标
        int[][] sortedQ = new int[m][2];
        for (int i = 0; i < m; i++) sortedQ[i] = new int[]{queries[i], i};
        Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);
        
        int[] result = new int[m];
        Arrays.fill(result, -1);
        // 最小堆：(区间大小, 右端点)
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        int ptr = 0;
        
        for (int[] q : sortedQ) {
            int val = q[0], idx = q[1];
            // 将左端点 <= val 的区间加入堆
            while (ptr < n && intervals[ptr][0] <= val) {
                int size = intervals[ptr][1] - intervals[ptr][0] + 1;
                pq.offer(new int[]{size, intervals[ptr][1]});
                ptr++;
            }
            // 移除右端点 < val 的过期区间
            while (!pq.isEmpty() && pq.peek()[1] < val) {
                pq.poll();
            }
            if (!pq.isEmpty()) {
                result[idx] = pq.peek()[0];
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N + M) log N)
- **空间复杂度**：O(N + M)

## 关键点总结

1. **离线处理**：查询排序后顺序扫描
2. **最小堆按区间大小**：堆顶就是最小包含区间
3. **懒删除**：移除右端点<当前查询的过期区间
