## 题目描述

给定整数数组 `nums` 和整数 `k`，选出恰好 `k` 个元素的子集使乘积最大，返回最大乘积（模 `10^9+7`）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maximumProduct(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        Arrays.sort(nums);
        int n = nums.length;
        // 同时维护最大值和最小值（负负得正）
        long[] dpMax = new long[k + 1], dpMin = new long[k + 1];
        long INF = Long.MAX_VALUE / 2;
        Arrays.fill(dpMax, -INF);
        Arrays.fill(dpMin, INF);
        dpMax[0] = dpMin[0] = 1;

        for (int num : nums) {
            // 倒序遍历，0-1 背包
            for (int j = Math.min(/* already processed */ k, k); j >= 1; j--) {
                if (dpMax[j - 1] == -INF) continue;
                long a = dpMax[j - 1] * num, b = dpMin[j - 1] * num;
                long newMax = Math.max(a, b), newMin = Math.min(a, b);
                if (newMax > dpMax[j]) dpMax[j] = newMax;
                if (newMin < dpMin[j]) dpMin[j] = newMin;
            }
        }
        return (int) (dpMax[k] % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)
- 空间复杂度：O(k)

## 关键点总结

1. 含负数时需同时维护 DP 最大值和最小值（负负得正）
2. 0-1 背包倒序更新，每个元素最多选一次
3. 最终取 dpMax[k] 对 MOD 取模
