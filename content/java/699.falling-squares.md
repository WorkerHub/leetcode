## 题目描述

正方形从高处落下，positions[i]=[left, sideLength]。落在重叠的已有正方形上方。每次落下后返回当前最大高度。

**示例：**
```
输入：positions = [[1,2],[2,3],[6,1]]
输出：[2,5,5]
```

## 解题思路

暴力模拟：记录每个正方形的区间和高度，新正方形找所有重叠区间的最大高度作为基础高度。区间重叠条件：left < r && l < right。

## Java 代码实现

```java
class Solution {
    public List<Integer> fallingSquares(int[][] positions) {
        List<int[]> intervals = new ArrayList<>(); // [left, right, height]
        List<Integer> result = new ArrayList<>();
        int maxHeight = 0;

        for (int[] pos : positions) {
            int left = pos[0], side = pos[1];
            int right = left + side;

            // 找重叠区间的最大高度
            int baseHeight = 0;
            for (int[] interval : intervals) {
                if (left < interval[1] && interval[0] < right) {
                    baseHeight = Math.max(baseHeight, interval[2]);
                }
            }

            int curHeight = baseHeight + side;
            intervals.add(new int[]{left, right, curHeight});

            maxHeight = Math.max(maxHeight, curHeight);
            result.add(maxHeight);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **区间重叠判断**：left < r && l < right（左闭右开）
2. **高度计算**：基础高度 + 自身边长
3. **全局最大值**：每次落下后更新并记录
