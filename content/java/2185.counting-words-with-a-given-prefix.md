## 题目描述

统计字符串数组中以给定前缀pref开头的字符串数目。

## 解题思路

遍历数组，用startsWith判断每个字符串是否以pref开头。

## Java 代码实现

```java
class Solution {
    public int prefixCount(String[] words, String pref) {
        int count = 0;
        for (String w : words) {
            if (w.startsWith(pref)) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * M)，N为单词数，M为前缀长度
- **空间复杂度**：O(1)

## 关键点总结

1. **String.startsWith()**：Java内置前缀判断方法
2. **直接遍历统计**：数据规模小无需优化
3. **pref比word长时自动返回false**
