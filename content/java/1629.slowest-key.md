## 题目描述

给你字符串 `keysPressed` 和升序排列的 `releaseTimes`，第 i 个键的持续时间为 `releaseTimes[i] - releaseTimes[i-1]`（第一个键为 `releaseTimes[0]`）。返回持续时间**最长**的键，若有并列则返回**字典序最大**的键。

## 解题思路

一次遍历，计算每个键的持续时间，维护最长持续时间和对应的字典序最大键。

## Java 代码实现

```java
class Solution {
    public char slowestKey(int[] releaseTimes, String keysPressed) {
        // 初始化：第一个键
        int maxDuration = releaseTimes[0];
        char ans = keysPressed.charAt(0);

        for (int i = 1; i < releaseTimes.length; i++) {
            int duration = releaseTimes[i] - releaseTimes[i - 1];
            char key = keysPressed.charAt(i);

            // 更新条件：持续时间更长，或持续时间相同且字典序更大
            if (duration > maxDuration || (duration == maxDuration && key > ans)) {
                maxDuration = duration;
                ans = key;
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历
- **空间复杂度**：O(1)

## 关键点总结

1. 第一个键持续时间特殊处理（从时刻 0 开始）
2. 更新条件：时间更长，或时间相同且字典序更大
3. 字符比较直接用 `>` 即可
