## 题目描述

机器人在数轴上移动，碰撞时互换方向（等价于穿透），经过 `d` 秒后返回所有机器人对之间距离的总和（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int sumDistance(int[] nums, String s, int d) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        // 计算每个机器人 d 秒后的位置（碰撞等价于穿透）
        long[] pos = new long[n];
        for (int i = 0; i < n; i++) {
            pos[i] = s.charAt(i) == 'R' ? (long) nums[i] + d : (long) nums[i] - d;
        }
        Arrays.sort(pos);
        // 排序后用前缀和计算所有对距离之和
        // 对第 i 个元素：贡献 = pos[i]*i - prefix（前 i 个元素之和）
        long ans = 0, prefix = 0;
        for (int i = 0; i < n; i++) {
            ans = (ans + (pos[i] % MOD * i % MOD - prefix % MOD + MOD) % MOD) % MOD;
            prefix += pos[i];
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 碰撞等价于穿透，最终位置集合不变
2. 排序后用前缀和 O(n) 计算所有对距离之和
3. 对第 `i` 个（0-indexed）元素，前面有 `i` 个更小的，贡献 `pos[i] * i - prefix`
