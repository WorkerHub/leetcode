## 题目描述

给定一个不为空的二叉搜索树和一个目标值 target，找到 BST 中最接近目标值的 k 个值。

**示例 1：**
```
输入: root = [4,2,5,1,3], target = 3.714286, k = 2
输出: [4,3]
```

**示例 2：**
```
输入: root = [1], target = 0.000000, k = 1
输出: [1]
```

**提示：**
- 树中节点数量在 [1, 10^4] 范围内
- 0 <= Node.val <= 10^9
- -10^9 <= target <= 10^9
- 1 <= k <= 树中节点总数

**注意：**
- 假设 BST 是平衡的
- 返回的结果顺序不重要

## 解题思路

这道题要求在 BST 中找到最接近目标值的 k 个值，有多种解法思路。

### 思路一：中序遍历 + 排序

1. BST 的中序遍历得到有序数组
2. 在有序数组中找到最接近 target 的 k 个值
3. 可以使用双指针或者堆来选择最近的 k 个值

### 思路二：最大堆

1. 维护一个大小为 k 的最大堆
2. 遍历 BST，将节点值与 target 的差值存入堆
3. 堆的大小超过 k 时，弹出差值最大的元素
4. 最后堆中剩余的就是最接近的 k 个值

### 思路三：双指针（中序遍历 + 滑动窗口）

1. 中序遍历得到有序数组
2. 找到最接近 target 的位置
3. 使用双指针从该位置向两边扩展，选择最接近的 k 个值

## Java 代码实现

### 方法一：中序遍历 + 双指针（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        // 中序遍历获取有序数组
        List<Integer> nums = new ArrayList<>();
        inorder(root, nums);

        // 二分查找找到第一个 >= target 的位置
        int left = 0, right = nums.size() - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            if (nums.get(mid) < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        // left 指向第一个 >= target 的位置
        // 左指针指向小于 target 的最大值，右指针指向大于等于 target 的最小值
        int lo = left - 1;
        int hi = left;

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            // 左指针越界，只能选右边
            if (lo < 0) {
                result.add(nums.get(hi++));
            // 右指针越界，只能选左边
            } else if (hi >= nums.size()) {
                result.add(nums.get(lo--));
            // 比较左右两边哪个更接近
            } else if (Math.abs(nums.get(lo) - target) <= Math.abs(nums.get(hi) - target)) {
                result.add(nums.get(lo--));
            } else {
                result.add(nums.get(hi++));
            }
        }

        return result;
    }

    // 中序遍历
    private void inorder(TreeNode node, List<Integer> nums) {
        if (node == null) return;
        inorder(node.left, nums);
        nums.add(node.val);
        inorder(node.right, nums);
    }
}
```

### 方法二：最大堆

```java
import java.util.ArrayList;
import java.util.List;
import java.util.PriorityQueue;

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        // 最大堆，按差值的大小排序（差值大的在堆顶）
        PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
            (a, b) -> Double.compare(Math.abs(b[0] - target), Math.abs(a[0] - target))
        );

        dfs(root, target, k, maxHeap);

        // 提取堆中的值
        List<Integer> result = new ArrayList<>();
        while (!maxHeap.isEmpty()) {
            result.add(maxHeap.poll()[0]);
        }
        return result;
    }

    private void dfs(TreeNode node, double target, int k, PriorityQueue<int[]> maxHeap) {
        if (node == null) return;

        // 将当前节点加入堆
        maxHeap.offer(new int[]{node.val});

        // 堆超过 k 个，移除差值最大的
        if (maxHeap.size() > k) {
            maxHeap.poll();
        }

        dfs(node.left, target, k, maxHeap);
        dfs(node.right, target, k, maxHeap);
    }
}
```

### 方法三：优化的中序遍历（一次遍历）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        // 使用双端队列维护滑动窗口
        Deque<Integer> window = new ArrayDeque<>();
        inorder(root, target, k, window);
        return new ArrayList<>(window);
    }

    private void inorder(TreeNode node, double target, int k, Deque<Integer> window) {
        if (node == null) return;

        inorder(node.left, target, k, window);

        // 处理当前节点
        if (window.size() < k) {
            window.addLast(node.val);
        } else {
            // 窗口已满，判断是否需要替换
            // 队首是窗口中最小的值（距离 target 最远的候选）
            if (Math.abs(node.val - target) < Math.abs(window.peekFirst() - target)) {
                window.pollFirst();
                window.addLast(node.val);
            } else {
                // 由于中序遍历是有序的，后面的值只会越来越远，提前终止
                return;
            }
        }

        inorder(node.right, target, k, window);
    }
}
```

### 方法四：排序简洁版

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        // 中序遍历获取所有值
        List<Integer> nums = new ArrayList<>();
        inorder(root, nums);

        // 按照与 target 的距离排序，取前 k 个
        nums.sort((a, b) -> Double.compare(Math.abs(a - target), Math.abs(b - target)));
        return nums.subList(0, k);
    }

    private void inorder(TreeNode node, List<Integer> nums) {
        if (node == null) return;
        inorder(node.left, nums);
        nums.add(node.val);
        inorder(node.right, nums);
    }
}
```

## 复杂度分析

### 方法一：中序遍历 + 双指针

**时间复杂度：** O(n)
- 中序遍历：O(n)
- 双指针选择：O(k)
- 总体：O(n)

**空间复杂度：** O(n)
- 存储中序遍历结果

### 方法二：最大堆

**时间复杂度：** O(n log k)
- 遍历所有节点：O(n)
- 每次堆操作：O(log k)

**空间复杂度：** O(k + h)
- 堆空间：O(k)
- 递归栈：O(h)，h 为树的高度

### 方法三：优化的中序遍历

**时间复杂度：** O(n)（最坏情况）
- 可能提前终止，平均情况更好

**空间复杂度：** O(k + h)

### 方法四：排序

**时间复杂度：** O(n log n)
- 中序遍历：O(n)
- 排序：O(n log n)

**空间复杂度：** O(n)

## 关键点总结

1. **利用 BST 性质**：中序遍历得到有序数组
2. **双指针技巧**：在有序数组中，从最接近位置向两边扩展
3. **堆的应用**：维护大小为 k 的最大堆，保存最小的 k 个差值
4. **剪枝优化**：利用有序性，可以提前终止遍历
5. **Java 注意**：`PriorityQueue` 默认是最小堆，需要传入比较器实现最大堆

## 易错点

1. **双指针初始化**：找到最接近 target 的位置后，正确设置左右指针
   ```java
   // 注意：lo 初始化为 left - 1（小于 target 的那侧）
   int lo = left - 1;
   int hi = left;
   ```

2. **边界判断**：双指针扩展时要检查越界
   ```java
   if (lo < 0) {
       // 只能选右边
   } else if (hi >= nums.size()) {
       // 只能选左边
   }
   ```

3. **距离比较**：使用 `Math.abs` 比较浮点数距离
   ```java
   Math.abs(nums.get(lo) - target) <= Math.abs(nums.get(hi) - target)
   ```

4. **Java 最大堆**：`PriorityQueue` 默认最小堆，要通过比较器取反实现最大堆
   ```java
   PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
       (a, b) -> Double.compare(Math.abs(b[0] - target), Math.abs(a[0] - target))
   );
   ```
