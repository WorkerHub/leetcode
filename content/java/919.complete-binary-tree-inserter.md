## 题目描述

设计数据结构 `CBTInserter`，用完全二叉树初始化，支持：插入新节点保持完全二叉树性质并返回父节点值；获取根节点。

**示例：**
```
CBTInserter cbt = new CBTInserter([1, 2]);
cbt.insert(3);  // 返回 1
cbt.insert(4);  // 返回 2
```

## 解题思路

BFS 初始化时找到所有未填满的节点放入队列。插入时从队首取父节点，填满后出队，新节点入队。

## Java 代码实现

```java
class CBTInserter {
    private TreeNode root;
    private Queue<TreeNode> candidates;

    public CBTInserter(TreeNode root) {
        this.root = root;
        this.candidates = new LinkedList<>();

        // BFS 找到所有未填满的节点
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node.left == null || node.right == null) {
                candidates.offer(node);
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }

    public int insert(int val) {
        TreeNode newNode = new TreeNode(val);
        TreeNode parent = candidates.peek();

        if (parent.left == null) {
            parent.left = newNode;
        } else {
            parent.right = newNode;
            candidates.poll(); // 父节点已填满
        }

        candidates.offer(newNode); // 新节点将来可能成为父节点
        return parent.val;
    }

    public TreeNode get_root() {
        return root;
    }
}
```

## 复杂度分析

- **初始化**：O(n)
- **插入**：O(1)
- **空间复杂度**：O(n)

## 关键点总结

1. **队列维护**：存储所有未填满的节点
2. **BFS 初始化**：层序遍历找候选父节点
3. **填满出队**：节点两个子节点都有时移出队列
