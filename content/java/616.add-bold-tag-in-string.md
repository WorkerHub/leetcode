## 题目描述

给定一个字符串 `s` 和一个字符串数组 `words`，请你在 `s` 中找到所有 `words` 中的字符串，并在其前后添加粗体标签 `<b>` 和 `</b>`。

如果两个这样的字符串重叠，你应该把它们合并成一个只有一对粗体标签的字符串。如果两个字符串接连发生，你也应该把它们合并成一个粗体字符串。

**示例：**

```
输入：s = "abcxyz123", words = ["abc","123"]
输出："<b>abc</b>xyz<b>123</b>"
```

## Java 代码实现

```java
class Solution {
    public String addBoldTag(String s, String[] words) {
        int n = s.length();
        boolean[] bold = new boolean[n];

        // 标记所有匹配位置
        for (String word : words) {
            int start = 0;
            while (true) {
                int pos = s.indexOf(word, start);
                if (pos == -1) break;
                for (int i = pos; i < pos + word.length(); i++) {
                    bold[i] = true;
                }
                start = pos + 1;
            }
        }

        // 构建结果
        StringBuilder result = new StringBuilder();
        int i = 0;
        while (i < n) {
            if (bold[i]) {
                result.append("<b>");
                while (i < n && bold[i]) {
                    result.append(s.charAt(i));
                    i++;
                }
                result.append("</b>");
            } else {
                result.append(s.charAt(i));
                i++;
            }
        }

        return result.toString();
    }
}
```
