## 题目描述

在山脉数组中查找 target，返回最小索引。通过接口访问数组（get 调用不超过 100 次）。

**示例：**
```
输入：array = [1,2,3,4,5,3,1], target = 3
输出：2
```

## 解题思路

三次二分：1) 找峰值索引；2) 在升序部分查找（优先，因为要最小索引）；3) 在降序部分查找。

## Java 代码实现

```java
class Solution {
    public int findInMountainArray(int target, MountainArray mountainArr) {
        int n = mountainArr.length();

        // 1. 找峰值
        int left = 0, right = n - 1;
        while (left < right) {
            int mid = (left + right) / 2;
            if (mountainArr.get(mid) < mountainArr.get(mid + 1)) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        int peak = left;

        // 2. 升序部分查找
        left = 0;
        right = peak;
        while (left <= right) {
            int mid = (left + right) / 2;
            int val = mountainArr.get(mid);
            if (val == target) return mid;
            else if (val < target) left = mid + 1;
            else right = mid - 1;
        }

        // 3. 降序部分查找
        left = peak + 1;
        right = n - 1;
        while (left <= right) {
            int mid = (left + right) / 2;
            int val = mountainArr.get(mid);
            if (val == target) return mid;
            else if (val < target) right = mid - 1; // 降序：值小则往左
            else left = mid + 1;
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **三次二分**：峰值 + 升序查找 + 降序查找
2. **优先左侧**：要最小索引，先搜升序部分
3. **降序二分**：比较逻辑反转（值小向左，值大向右）
4. **调用限制**：3×log(10⁴) ≈ 42 次 < 100 次
