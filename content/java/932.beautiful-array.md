## 题目描述

给定 n，返回 1~n 的一个排列，使得对于任意 i < k < j，都不满足 nums[k]*2 == nums[i]+nums[j]。

## 解题思路

分治构造：如果 arr 是漂亮数组，则 2*arr-1（奇数）和 2*arr（偶数）拼接仍是漂亮数组。因为奇+偶=奇，不可能是某个数的两倍。

## Java 代码实现

```java
class Solution {
    public int[] beautifulArray(int n) {
        List<Integer> result = new ArrayList<>();
        result.add(1);

        while (result.size() < n) {
            List<Integer> temp = new ArrayList<>();
            // 奇数部分
            for (int x : result) {
                if (2 * x - 1 <= n) temp.add(2 * x - 1);
            }
            // 偶数部分
            for (int x : result) {
                if (2 * x <= n) temp.add(2 * x);
            }
            result = temp;
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) ans[i] = result.get(i);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **分治构造**：奇数部分 + 偶数部分
2. **性质保持**：线性变换不破坏漂亮数组性质
3. **奇偶分离**：奇+偶=奇，不可能是 2 的倍数
