## 题目描述

排序后返回target在数组中的所有下标。

## 解题思路

计数法：统计小于target的个数为起始下标，等于target的个数为连续范围。无需真正排序。

## Java 代码实现

```java
class Solution {
    public List<Integer> targetIndices(int[] nums, int target) {
        int less = 0, count = 0;
        for (int x : nums) {
            if (x < target) less++;
            else if (x == target) count++;
        }
        List<Integer> result = new ArrayList<>();
        for (int i = less; i < less + count; i++) {
            result.add(i);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **计数法**：无需排序，O(N)
2. **起始下标**：等于小于target的元素个数
3. **连续范围**：[less, less+count-1]
