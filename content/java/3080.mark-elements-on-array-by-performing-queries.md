## 题目描述

给你 nums 数组和查询数组（每个查询 [index, k]），每次查询先标记 nums[index]，再标记最小的 k 个未标记元素，返回每次查询后未标记元素总和。

## 解题思路

用最小堆（懒删除）模拟：维护全局未标记总和，每次标记时减去对应值；堆中已标记元素在弹出时跳过（懒删除）。

## Java 代码实现

```java
class Solution {
    public long[] unmarkedSumArray(int[] nums, int[][] queries) {
        int n = nums.length;
        boolean[] marked = new boolean[n];
        long total = 0;
        for (int x : nums) total += x;

        // 最小堆：{value, index}，按值升序，值相同按下标升序
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        for (int i = 0; i < n; i++) heap.offer(new int[]{nums[i], i});

        long[] result = new long[queries.length];
        for (int q = 0; q < queries.length; q++) {
            int idx = queries[q][0], k = queries[q][1];
            // 先标记 nums[idx]
            if (!marked[idx]) {
                marked[idx] = true;
                total -= nums[idx];
            }
            // 标记最小的 k 个未标记元素（懒删除）
            int remaining = k;
            while (remaining > 0 && !heap.isEmpty()) {
                int[] top = heap.peek();
                if (marked[top[1]]) { heap.poll(); continue; } // 已标记则跳过
                heap.poll();
                marked[top[1]] = true;
                total -= top[0];
                remaining--;
            }
            result[q] = total;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) log n)，堆操作 O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 懒删除：堆中已标记的元素在弹出时跳过，无需主动删除
2. 维护全局未标记总和，每次标记时减去对应值
3. 每次查询先标记 nums[index]，再标记最小 k 个（顺序重要）
