## 题目描述

给定一个由不同正整数组成的数组 `nums`，返回 `nums` 中最大连通组件的大小。

如果两个或更多数字之间存在任何公因数大于 1，则这些数字可以连通。

**示例 1：**
```
输入：nums = [4,6,15,35]
输出：4
解释：
4 和 6 有公因数 2
6 和 15 有公因数 3
15 和 35 有公因数 5
因此，这 4 个数字形成一个连通组件
```

**示例 2：**
```
输入：nums = [20,50,9,63]
输出：2
解释：
20 和 50 有公因数 2 和 5
9 和 63 有公因数 3 和 9
因此，最大连通组件大小为 2
```

**示例 3：**
```
输入：nums = [2,3,6,7,4,12,21,39]
输出：8
解释：所有数字都通过某些公因数连通
```

**提示：**
- `1 <= nums.length <= 2 * 10^4`
- `1 <= nums[i] <= 10^5`
- `nums` 中所有值都不同

## 解题思路

这道题的核心是找连通组件，关键在于如何定义"连通"：两个数有大于 1 的公因数就连通。

**核心思想：**

1. **并查集（Union-Find）**：这是解决连通性问题的经典数据结构
   - 将有公因数的数字合并到同一个集合
   - 最后统计最大集合的大小

2. **质因数分解**：不需要两两比较所有数字
   - 对每个数字进行质因数分解
   - 将数字与其所有质因数建立连接
   - 拥有相同质因数的数字会被连接在一起

3. **优化策略**：
   - 不需要找出所有因数，只需要质因数
   - 使用并查集的路径压缩和按秩合并优化

**算法流程：**
1. 初始化并查集
2. 对每个数字进行质因数分解
3. 将数字与其每个质因数连接（合并到同一集合）
4. 统计每个集合的大小，返回最大值

## Java 代码实现

### 方法一：并查集 + 质因数分解（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    // 并查集的父节点数组
    private int[] parent;
    // 按秩合并
    private int[] rank;

    public int largestComponentSize(int[] nums) {
        // 找出最大值，初始化并查集
        int maxNum = 0;
        for (int num : nums) maxNum = Math.max(maxNum, num);
        parent = new int[maxNum + 1];
        rank = new int[maxNum + 1];
        for (int i = 0; i <= maxNum; i++) parent[i] = i;

        // 对每个数字进行质因数分解并连接
        for (int num : nums) {
            int[] primes = getPrimeFactors(num);
            // 将数字与其所有质因数合并
            for (int prime : primes) {
                union(num, prime);
            }
        }

        // 统计每个连通组件的大小
        Map<Integer, Integer> count = new HashMap<>();
        int result = 0;
        for (int num : nums) {
            int root = find(num);
            count.put(root, count.getOrDefault(root, 0) + 1);
            result = Math.max(result, count.get(root));
        }
        return result;
    }

    /** 查找根节点，带路径压缩 */
    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    /** 合并两个集合，按秩合并 */
    private void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return;

        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }

    /** 获取 n 的所有质因数 */
    private int[] getPrimeFactors(int n) {
        java.util.List<Integer> factors = new java.util.ArrayList<>();

        // 处理因数 2
        if (n % 2 == 0) {
            factors.add(2);
            while (n % 2 == 0) n /= 2;
        }

        // 处理奇数因数，从 3 开始
        for (int i = 3; (long) i * i <= n; i += 2) {
            if (n % i == 0) {
                factors.add(i);
                while (n % i == 0) n /= i;
            }
        }

        // 如果 n 大于 1，说明 n 本身是质数
        if (n > 1) factors.add(n);

        return factors.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

### 方法二：优化的并查集（使用 HashMap）

```java
class Solution {
    private Map<Integer, Integer> parent = new HashMap<>();

    public int largestComponentSize(int[] nums) {
        // 对每个数字进行质因数分解并合并
        for (int num : nums) {
            int k = num;
            // 处理因数 2
            if (k % 2 == 0) {
                union(num, 2);
                while (k % 2 == 0) k /= 2;
            }
            // 处理奇数因数
            for (int i = 3; (long) i * i <= k; i += 2) {
                if (k % i == 0) {
                    union(num, i);
                    while (k % i == 0) k /= i;
                }
            }
            // k 本身是质数
            if (k > 1) union(num, k);
        }

        // 统计每个连通组件的大小
        Map<Integer, Integer> count = new HashMap<>();
        int result = 0;
        for (int num : nums) {
            int root = find(num);
            count.put(root, count.getOrDefault(root, 0) + 1);
            result = Math.max(result, count.get(root));
        }
        return result;
    }

    /** 查找根节点 */
    private int find(int x) {
        parent.putIfAbsent(x, x);
        if (!parent.get(x).equals(x)) {
            parent.put(x, find(parent.get(x)));
        }
        return parent.get(x);
    }

    /** 合并两个集合 */
    private void union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX != rootY) {
            parent.put(rootX, rootY);
        }
    }
}
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(N√M + Nα(M))
  - N 是数组长度，M 是数组中的最大值
  - 质因数分解：O(√M) 每个数字
  - 并查集操作：O(α(M))，α 是阿克曼函数的反函数，几乎为常数
- **空间复杂度**：O(M)，并查集需要 O(M) 空间

**方法二：**
- **时间复杂度**：O(N√M + Nα(N))
- **空间复杂度**：O(N + K)，K 是不同质因数的个数

## 关键点总结

1. **并查集的应用**：连通性问题的标准解法，需要掌握路径压缩和按秩合并
2. **质因数分解**：不需要找所有因数，只需质因数即可建立连接
3. **优化技巧**：只需要遍历到 √n 即可完成质因数分解
4. **数据结构选择**：数组实现快但占空间，HashMap 实现省空间
5. **统计技巧**：使用哈希表统计每个根节点的出现次数

## 易错点

1. **并查集初始化**：要初始化到 max(nums) + 1，而不是 nums.length
2. **质因数分解边界**：容易忘记处理剩余的大质数（n > 1 的情况）
3. **合并策略**：不能直接合并数字本身，要通过质因数建立连接
4. **整数溢出**：i * i 可能溢出，用 (long) i * i <= n 避免
5. **重复质因数**：质因数分解时要去除重复，只保留一个
