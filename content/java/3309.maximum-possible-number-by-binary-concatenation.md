## 题目描述

给你长度为 3 的整数数组 `nums`，将 3 个数的二进制表示按某种顺序拼接，返回所有排列中最大的十进制值。

## 解题思路

枚举全部 6 种排列，计算每种排列二进制拼接后的值（`result = (result << bitLen(x)) | x`），取最大值。

## Java 代码实现

```java
class Solution {
    public int maximumNumber(int[] nums) {
        int[][] perms = {{0,1,2},{0,2,1},{1,0,2},{1,2,0},{2,0,1},{2,1,0}};
        int maxVal = 0;
        for (int[] perm : perms) {
            int result = 0;
            for (int i : perm) {
                int x = nums[i];
                // 计算 x 的二进制位数（Integer.SIZE - numberOfLeadingZeros(x)）
                int bits = 32 - Integer.numberOfLeadingZeros(x);
                result = (result << bits) | x;
            }
            maxVal = Math.max(maxVal, result);
        }
        return maxVal;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)，固定 6 种排列
- 空间复杂度：O(1)

## 关键点总结

1. 数组长度固定为 3，全排列只有 6 种，直接枚举
2. 二进制拼接：`(a << bitLen(b)) | b` 将 a 放在 b 前面
3. `Integer.numberOfLeadingZeros(x)` 计算前导零数，`32 - 前导零数` = 二进制位数
