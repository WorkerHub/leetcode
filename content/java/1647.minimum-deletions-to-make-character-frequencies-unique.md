## 题目描述

如果字符串中不存在两个不同字符频率相同，则称为**优质字符串**。给你字符串 `s`，返回使 `s` 成为优质字符串需要删除的**最少字符数**。

## 解题思路

**贪心：** 统计频率，按降序排序。对每个频率，若已被使用则将其减 1 直到找到未使用的值（或为 0）。

## Java 代码实现

```java
class Solution {
    public int minDeletions(String s) {
        // 统计每个字符的频率
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        // 收集频率并降序排序
        int[] freqs = Arrays.stream(cnt).filter(f -> f > 0).toArray();
        Arrays.sort(freqs);
        // 转为降序（反转）
        for (int i = 0, j = freqs.length - 1; i < j; i++, j--) {
            int tmp = freqs[i]; freqs[i] = freqs[j]; freqs[j] = tmp;
        }

        Set<Integer> used = new HashSet<>();
        int deletions = 0;

        for (int f : freqs) {
            // 找到 <= f 的最大未使用频率
            while (f > 0 && used.contains(f)) {
                f--;
                deletions++;
            }
            if (f > 0) used.add(f);
        }

        return deletions;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 26 * max_freq)，最坏 O(n)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 贪心：当频率冲突时减少到最近可用值
2. 按降序处理：让大频率优先占用较大值
3. 频率可以减为 0（全部删除该字符）
