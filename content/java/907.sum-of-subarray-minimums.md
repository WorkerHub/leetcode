## 题目描述

给定一个整数数组 `arr`，找到 `min(b)` 的总和，其中 `b` 的范围为 `arr` 的每个（连续）子数组。

由于答案可能很大，因此 **返回答案模 `10^9 + 7`**。

**示例 1：**
```
输入：arr = [3,1,2,4]
输出：17
解释：
子数组为 [3], [1], [2], [4], [3,1], [1,2], [2,4], [3,1,2], [1,2,4], [3,1,2,4]。
最小值为 3, 1, 2, 4, 1, 1, 2, 1, 1, 1。
总和为 17。
```

**示例 2：**
```
输入：arr = [11,81,94,43,3]
输出：444
```

**提示：**
- `1 <= arr.length <= 3 * 10^4`
- `1 <= arr[i] <= 3 * 10^4`

## 解题思路

这道题要求计算所有子数组的最小值之和。暴力解法是 O(n^2) 或 O(n^3)，需要优化。

**关键观察：**
- 对于每个元素 `arr[i]`，计算它作为最小值时，能贡献多少次
- 如果 `arr[i]` 是某个子数组的最小值，那么这个子数组必须：
  - 包含 `arr[i]`
  - 左边界在 `arr[i]` 左侧第一个比它小的元素之后
  - 右边界在 `arr[i]` 右侧第一个比它小的元素之前

**单调栈解法：**
1. 使用单调栈找到每个元素左边第一个比它小的位置（left）
2. 使用单调栈找到每个元素右边第一个比它小的位置（right）
3. 对于位置 `i`，它作为最小值的子数组数量 = `(i - left) * (right - i)`
4. 贡献值 = `arr[i] * (i - left) * (right - i)`

## Java 代码实现

### 方法一：单调栈（推荐）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int sumSubarrayMins(int[] arr) {
        int MOD = 1_000_000_007;
        int n = arr.length;

        // left[i]: 左边第一个小于 arr[i] 的位置
        // right[i]: 右边第一个小于等于 arr[i] 的位置（注意用<=避免重复计数）
        int[] left = new int[n];
        int[] right = new int[n];

        // 使用单调栈找左边界
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }

        // 使用单调栈找右边界
        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            // 注意：这里使用 >= 而不是 >，避免重复计数
            while (!stack.isEmpty() && arr[stack.peek()] >= arr[i]) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }

        // 计算结果
        long result = 0;
        for (int i = 0; i < n; i++) {
            // arr[i] 作为最小值的子数组数量
            long count = (long)(i - left[i]) * (right[i] - i);
            result = (result + (long) arr[i] * count) % MOD;
        }

        return (int) result;
    }
}
```

### 方法二：一次遍历优化

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int sumSubarrayMins(int[] arr) {
        int MOD = 1_000_000_007;
        int n = arr.length;
        long result = 0;
        Deque<Integer> stack = new ArrayDeque<>(); // 单调递增栈，存储索引

        for (int i = 0; i <= n; i++) {
            // 处理到数组末尾时，使用一个很小的值触发所有元素出栈
            int current = (i == n) ? 0 : arr[i];

            while (!stack.isEmpty() && arr[stack.peek()] > current) {
                int mid = stack.pop();
                // left 是栈顶元素（如果栈为空，则为 -1）
                int lft = stack.isEmpty() ? -1 : stack.peek();
                int rgt = i;

                // arr[mid] 作为最小值的子数组数量
                long count = (long)(mid - lft) * (rgt - mid);
                result = (result + (long) arr[mid] * count) % MOD;
            }

            stack.push(i);
        }

        return (int) result;
    }
}
```

### 方法三：暴力解法（超时，仅供理解）

```java
class Solution {
    public int sumSubarrayMins(int[] arr) {
        int MOD = 1_000_000_007;
        int n = arr.length;
        long result = 0;

        // 枚举所有子数组
        for (int i = 0; i < n; i++) {
            int minVal = arr[i];
            for (int j = i; j < n; j++) {
                minVal = Math.min(minVal, arr[j]);
                result = (result + minVal) % MOD;
            }
        }

        return (int) result;
    }
}
```

## 复杂度分析

**方法一/二：单调栈**
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，栈的空间

**方法三：暴力解法**
- 时间复杂度：O(n^2)，枚举所有子数组
- 空间复杂度：O(1)

## 关键点总结

1. **单调栈的应用**：找每个元素左右两边第一个更小的元素
2. **贡献法**：计算每个元素作为最小值能贡献多少次
3. **避免重复**：右边界使用 `>=` 而不是 `>`，防止相同元素重复计数
4. **取模运算**：结果很大，需要取模 10^9 + 7
5. **long 类型**：Java 中注意使用 long 避免乘法溢出

## 易错点

1. **重复计数**：相同元素可能导致重复计数，需要在左/右边界处理时注意
2. **取模时机**：每次累加时都要取模，避免溢出
3. **单调栈方向**：左边界从左到右，右边界从右到左
4. **边界初始化**：left 初始化为 -1，right 初始化为 n
5. **类型转换**：Java 中乘法要先转 long，否则可能溢出
