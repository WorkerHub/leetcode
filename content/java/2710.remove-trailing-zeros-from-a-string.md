## 题目描述

给你用字符串表示的正整数 `num`，返回移除尾随零后的字符串。

## Java 代码实现

```java
class Solution {
    public String removeTrailingZeros(String num) {
        int i = num.length() - 1;
        while (i >= 0 && num.charAt(i) == '0') i--;
        return num.substring(0, i + 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 从末尾向前找第一个非零字符，截取前缀
