## 题目描述

三个字符串只能删末尾字符，求使三者相等的最少操作次数，不可能返回-1。

## 解题思路

最终相等的字符串必为公共前缀。找最长公共前缀长度k，操作数=三者长度之和-3k。k=0返回-1。

## Java 代码实现

```java
class Solution {
    public int findMinimumOperations(String s1, String s2, String s3) {
        int minLen = Math.min(s1.length(), Math.min(s2.length(), s3.length()));
        int k = 0;
        for (int i = 0; i < minLen; i++) {
            if (s1.charAt(i) == s2.charAt(i) && s2.charAt(i) == s3.charAt(i)) {
                k++;
            } else {
                break;
            }
        }
        if (k == 0) return -1;
        return s1.length() + s2.length() + s3.length() - 3 * k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(L1, L2, L3))
- **空间复杂度**：O(1)

## 关键点总结

1. **只能删末尾**：最终结果必为某公共前缀
2. **最长公共前缀最优**：删除最少字符
3. **k=0不可能**：首字符不同则无法相等
