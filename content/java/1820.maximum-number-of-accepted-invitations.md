## 题目描述

`m x n` 矩阵 `grid[i][j]=1` 表示第 i 个男生可邀请第 j 个女生。每人最多配对一次，返回最多配对数。

## 解题思路

二分图最大匹配，使用匈牙利算法：对每个男生尝试寻找匹配，若目标女生已被匹配则递归尝试为其重新寻找（增广路）。

## Java 代码实现

```java
class Solution {
    private int[][] grid;
    private int[] matchGirl; // matchGirl[j] = 与第 j 个女生匹配的男生编号，-1 表示未匹配
    private int n;

    public int maximumInvitations(int[][] grid) {
        int m = grid.length;
        this.n = grid[0].length;
        this.grid = grid;
        this.matchGirl = new int[n];
        java.util.Arrays.fill(matchGirl, -1);

        int result = 0;
        for (int boy = 0; boy < m; boy++) {
            boolean[] visited = new boolean[n];
            if (dfs(boy, visited)) result++;
        }
        return result;
    }

    private boolean dfs(int boy, boolean[] visited) {
        for (int girl = 0; girl < n; girl++) {
            if (grid[boy][girl] == 1 && !visited[girl]) {
                visited[girl] = true;
                // 若该女生未被匹配，或原匹配男生能换到其他女生
                if (matchGirl[girl] == -1 || dfs(matchGirl[girl], visited)) {
                    matchGirl[girl] = boy;
                    return true;
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * (m + n))
- **空间复杂度**：O(m + n)

## 关键点总结

1. 匈牙利算法：增广路思想，每个男生 DFS 时独立重置 visited
2. visited 每轮（每个男生）重置，避免影响其他增广路
