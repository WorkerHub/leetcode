## 题目描述

给你整数数组 `hours`，返回两元素之和为 24 整数倍的员工对数目。

## 解题思路

对所有时长取模 24，用哈希表统计余数频次。余数 r 和 `(24-r)%24` 配对；r 与自身配对（r=0 或 r=12）时用组合数 C(n,2)。

## Java 代码实现

```java
class Solution {
    public int countCompleteDayPairs(int[] hours) {
        int[] cnt = new int[24];
        for (int h : hours) cnt[h % 24]++;

        int ans = 0;
        for (int r = 0; r < 24; r++) {
            int pair = (24 - r) % 24;
            if (r < pair) {
                // 不同余数配对
                ans += cnt[r] * cnt[pair];
            } else if (r == pair) {
                // 相同余数（r=0 或 r=12），选 C(cnt[r],2)
                ans += cnt[r] * (cnt[r] - 1) / 2;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（大小 24 的数组）

## 关键点总结

1. `(a+b) % 24 == 0` 等价于 `(a%24 + b%24) % 24 == 0`
2. 余数 r=0 和 r=12 时与自身配对，使用组合数公式
3. 遍历 r 只统计 r < pair 的情况避免重复
