## 题目描述

给你两个长为 `n` 的整数数组 `nums1` 和 `nums2`，对每个下标从两个数组中选一个值构成 `nums3`，返回 `nums3` 的最长非递减子数组长度。

## Java 代码实现

```java
class Solution {
    public int maxNonDecreasingLength(int[] nums1, int[] nums2) {
        int n = nums1.length;
        // dp0: 以 nums1[i] 结尾的最长非递减子数组长度
        // dp1: 以 nums2[i] 结尾的最长非递减子数组长度
        int dp0 = 1, dp1 = 1, ans = 1;
        for (int i = 1; i < n; i++) {
            int new0 = 1, new1 = 1;
            // 以 nums1[i] 结尾
            if (nums1[i - 1] <= nums1[i]) new0 = Math.max(new0, dp0 + 1);
            if (nums2[i - 1] <= nums1[i]) new0 = Math.max(new0, dp1 + 1);
            // 以 nums2[i] 结尾
            if (nums1[i - 1] <= nums2[i]) new1 = Math.max(new1, dp0 + 1);
            if (nums2[i - 1] <= nums2[i]) new1 = Math.max(new1, dp1 + 1);
            dp0 = new0; dp1 = new1;
            ans = Math.max(ans, Math.max(dp0, dp1));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. DP 状态只需保留上一位的两个值
2. 每个位置有两种选择，分别对应两种结尾
3. 四种转移路径（前位两种选择 x 当前两种选择）
