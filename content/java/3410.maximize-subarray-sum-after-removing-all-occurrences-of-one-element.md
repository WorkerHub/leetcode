## 题目描述

给定整数数组 `nums`，可选择删除某个值的所有出现（或不删），返回操作后的最大子数组和（空子数组和为 0）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    // 线段树节点：(最大子数组和, 最大前缀和, 最大后缀和, 区间总和)
    private long[] maxSub, maxPre, maxSuf, total;
    private int n;

    public long maxSubarraySum(int[] nums) {
        n = nums.length;
        maxSub = new long[4 * n];
        maxPre = new long[4 * n];
        maxSuf = new long[4 * n];
        total = new long[4 * n];
        build(nums, 1, 0, n - 1);

        long result = maxSub[1]; // 不删任何元素

        // 按值分组
        Map<Integer, List<Integer>> valIdx = new HashMap<>();
        for (int i = 0; i < n; i++) {
            valIdx.computeIfAbsent(nums[i], k -> new ArrayList<>()).add(i);
        }

        for (Map.Entry<Integer, List<Integer>> e : valIdx.entrySet()) {
            int v = e.getKey();
            List<Integer> indices = e.getValue();
            // 将所有 v 位置设为 0
            for (int idx : indices) update(1, 0, n - 1, idx, 0);
            result = Math.max(result, maxSub[1]);
            // 恢复
            for (int idx : indices) update(1, 0, n - 1, idx, v);
        }
        return result;
    }

    private void pushUp(int node) {
        long ls = maxSuf[2 * node], rs = maxPre[2 * node + 1];
        maxSub[node] = Math.max(Math.max(maxSub[2 * node], maxSub[2 * node + 1]), ls + rs);
        maxPre[node] = Math.max(maxPre[2 * node], total[2 * node] + maxPre[2 * node + 1]);
        maxSuf[node] = Math.max(maxSuf[2 * node + 1], total[2 * node + 1] + maxSuf[2 * node]);
        total[node] = total[2 * node] + total[2 * node + 1];
    }

    private void build(int[] arr, int node, int start, int end) {
        if (start == end) {
            long v = arr[start];
            maxSub[node] = maxPre[node] = maxSuf[node] = Math.max(0, v);
            total[node] = v;
            return;
        }
        int mid = (start + end) / 2;
        build(arr, 2 * node, start, mid);
        build(arr, 2 * node + 1, mid + 1, end);
        pushUp(node);
    }

    private void update(int node, int start, int end, int idx, long val) {
        if (start == end) {
            maxSub[node] = maxPre[node] = maxSuf[node] = Math.max(0, val);
            total[node] = val;
            return;
        }
        int mid = (start + end) / 2;
        if (idx <= mid) update(2 * node, start, mid, idx, val);
        else update(2 * node + 1, mid + 1, end, idx, val);
        pushUp(node);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，每次更新 O(log n)，共 O(n) 次更新
- 空间复杂度：O(n)，线段树空间

## 关键点总结

1. 删除某个值的所有出现，相当于将这些位置设为 0（对子数组和无贡献）。
2. 线段树每个节点维护 (最大子数组和, 最大前缀和, 最大后缀和, 区间总和)，支持合并。
3. 枚举每个不同值，删除后查询，再恢复，取所有结果最大值。
