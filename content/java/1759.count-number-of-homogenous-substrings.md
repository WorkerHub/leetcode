## 题目描述

给你字符串 `s`，返回同质子字符串（所有字符相同）的数目，对 `10^9+7` 取余。

## 解题思路

统计每段连续相同字符的长度 `k`，该段贡献 `k*(k+1)/2` 个同质子串，所有段求和。

## Java 代码实现

```java
class Solution {
    public int countHomogenous(String s) {
        final int MOD = 1_000_000_007;
        long ans = 0;
        int i = 0, n = s.length();

        while (i < n) {
            int j = i;
            // 找当前字符的连续段
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            long k = j - i; // 连续段长度
            ans = (ans + k * (k + 1) / 2) % MOD; // 贡献同质子串数
            i = j;
        }

        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 长度为 k 的连续同字符段贡献 `k*(k+1)/2` 个同质子串
2. 注意取模，`k*(k+1)/2` 可能较大
