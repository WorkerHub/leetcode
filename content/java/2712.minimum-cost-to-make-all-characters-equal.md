## 题目描述

给你二进制字符串 `s`，每次操作可翻转前缀 `s[0..i]`（代价 `i+1`）或后缀 `s[i..n-1]`（代价 `n-i`），返回使所有字符相等的最小代价。

## Java 代码实现

```java
class Solution {
    public long minimumCost(String s) {
        int n = s.length();
        long cost = 0;
        for (int i = 1; i < n; i++) {
            if (s.charAt(i) != s.charAt(i - 1)) {
                // 在分割点 i 处：翻转前缀代价 i，翻转后缀代价 n-i
                cost += Math.min(i, n - i);
            }
        }
        return cost;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每对相邻不同字符构成一个分割点，需要代价消除
2. 在分割点 i 处取 `min(i, n-i)` 即选代价最小的翻转方向
