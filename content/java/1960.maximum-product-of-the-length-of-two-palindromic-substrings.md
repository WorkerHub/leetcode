## 题目描述

给你偶数长度字符串 `s`，枚举分割点 j，返回 `s[0..j]` 内最长奇数回文长度与 `s[j+1..n-1]` 内最长奇数回文长度之积的最大值。

## 解题思路

Manacher 算法求所有回文半径，正向传播得 `left[j]`（s[0..j] 内最长奇数回文长度），反向传播得 `right[j]`，枚举分割点取最大乘积。

## Java 代码实现

```java
class Solution {
    public long maxProduct(String s) {
        int n = s.length();
        int[] p = manacher(s);

        // left[j] = s[0..j] 中完整放置的最长奇数回文长度
        int[] left = new int[n];
        Arrays.fill(left, 1);
        for (int c = 0; c < n; c++) {
            int end = c + p[c];
            if (end < n) left[end] = Math.max(left[end], 2 * p[c] + 1);
        }
        for (int j = 1; j < n; j++) left[j] = Math.max(left[j], left[j - 1]);

        // right[j] = s[j..n-1] 中完整放置的最长奇数回文长度
        int[] right = new int[n];
        Arrays.fill(right, 1);
        for (int c = 0; c < n; c++) {
            int start = c - p[c];
            if (start >= 0) right[start] = Math.max(right[start], 2 * p[c] + 1);
        }
        for (int j = n - 2; j >= 0; j--) right[j] = Math.max(right[j], right[j + 1]);

        long ans = 0;
        for (int j = 0; j < n - 1; j++)
            ans = Math.max(ans, (long) left[j] * right[j + 1]);
        return ans;
    }

    private int[] manacher(String s) {
        int n = s.length();
        int[] p = new int[n];
        int c = 0, r = 0;
        for (int i = 0; i < n; i++) {
            if (i < r) p[i] = Math.min(r - i, p[2 * c - i]);
            while (i + p[i] + 1 < n && i - p[i] - 1 >= 0
                    && s.charAt(i + p[i] + 1) == s.charAt(i - p[i] - 1))
                p[i]++;
            if (i + p[i] > r) { c = i; r = i + p[i]; }
        }
        return p;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. Manacher 算法 O(n) 计算所有奇数回文半径
2. 正向传播：每个中心的右端点更新 left，再取前缀最大
3. 反向传播：每个中心的左端点更新 right，再取后缀最大
