## 题目描述

初始 nums=[1]，每次可将某元素 +1 或复制某元素追加到末尾，返回使所有元素之和 >= k 的最少操作总次数。

## 解题思路

设最终每个元素值为 v（需 v-1 次增加），数组大小为 m（需 m-1 次复制），则总操作 = v+m-2，约束 v*m >= k。枚举 v，m = ceil(k/v)，取最小总操作数（最优在 v≈sqrt(k) 附近）。

## Java 代码实现

```java
class Solution {
    public int minOperations(int k) {
        if (k == 1) return 0;
        int ans = Integer.MAX_VALUE;
        // 枚举每个元素的值 v（从 1 到 k）
        for (int v = 1; v <= k; v++) {
            int m = (k + v - 1) / v; // ceil(k / v)
            ans = Math.min(ans, (v - 1) + (m - 1));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k)，枚举所有 v（也可 O(sqrt(k)) 优化）
- **空间复杂度**：O(1)

## 关键点总结

1. 最终状态：v 的值重复 m 次，满足 `v * m >= k`
2. 操作数 = (v-1) + (m-1)，v-1 次增加 + m-1 次复制
3. 最优在 v≈sqrt(k) 附近（AM-GM 不等式）
