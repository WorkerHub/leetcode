## 题目描述

设计地铁系统：记录乘客签到签出，计算两站之间的平均行程时间。

## 解题思路

双HashMap：一个记录在途乘客签到信息(id->(station,time))，一个记录路线统计((start,end)->(totalTime,count))。

## Java 代码实现

```java
class UndergroundSystem {
    // 在途乘客：id -> (station, time)
    private Map<Integer, String[]> checkInData;
    // 路线统计：start_end -> [totalTime, count]
    private Map<String, long[]> tripData;

    public UndergroundSystem() {
        checkInData = new HashMap<>();
        tripData = new HashMap<>();
    }

    public void checkIn(int id, String stationName, int t) {
        checkInData.put(id, new String[]{stationName, String.valueOf(t)});
    }

    public void checkOut(int id, String stationName, int t) {
        String[] info = checkInData.remove(id);
        String key = info[0] + "_" + stationName;
        int duration = t - Integer.parseInt(info[1]);
        long[] data = tripData.computeIfAbsent(key, k -> new long[2]);
        data[0] += duration;
        data[1]++;
    }

    public double getAverageTime(String startStation, String endStation) {
        long[] data = tripData.get(startStation + "_" + endStation);
        return (double) data[0] / data[1];
    }
}
```

## 复杂度分析

- **时间复杂度**：所有操作O(1)
- **空间复杂度**：O(P + R)，P为在途乘客数，R为路线数

## 关键点总结

1. **双HashMap设计**：分别记录在途信息和路线统计
2. **checkOut时remove**：清除在途记录节省空间
3. **路线键用拼接字符串**：start + "_" + end
