## 题目描述

假设有打乱顺序的一群人站成一个队列，数组 people 表示队列中一些人的属性（不一定按顺序）。每个 people[i] = [hi, ki] 表示第 i 个人的身高为 hi，前面正好有 ki 个身高大于或等于 hi 的人。

请你重新构造并返回输入数组 people 所表示的队列。返回的队列应该格式化为数组 queue，其中 queue[j] = [hj, kj] 是队列中第 j 个人的属性（queue[0] 是排在队列前面的人）。

**示例 1：**
```
输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
解释：
编号为 0 的人身高为 5，前面没有身高大于或等于 5 的人。
编号为 1 的人身高为 7，前面没有身高大于或等于 7 的人。
编号为 2 的人身高为 5，前面有 2 个身高大于或等于 5 的人，即编号为 0 和 1 的人。
编号为 3 的人身高为 6，前面有 1 个身高大于或等于 6 的人，即编号为 1 的人。
编号为 4 的人身高为 4，前面有 4 个身高大于或等于 4 的人，即编号为 0、1、2、3 的人。
编号为 5 的人身高为 7，前面有 1 个身高大于或等于 7 的人，即编号为 1 的人。
因此 [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]] 是重新构造后的队列。
```

**示例 2：**
```
输入：people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]
输出：[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]
```

**提示：**
- 1 <= people.length <= 2000
- 0 <= hi <= 10^6
- 0 <= ki < people.length
- 题目数据确保队列可以被重建

## 解题思路

这是一道经典的贪心算法题，关键是找到正确的排序和插入策略。

核心观察：
1. 身高较高的人不会影响身高较矮的人的 k 值
2. 身高相同的人，k 值较小的应该排在前面
3. 可以先处理身高高的人，再处理身高矮的人

贪心策略：
1. 按身高降序排序，身高相同则按 k 升序排序
2. 按顺序将每个人插入到结果数组的第 k 个位置
3. 由于先插入的都是身高较高或相等的人，所以插入位置就是正确的位置

为什么这样做是对的？
- 先插入身高高的人，他们的相对位置确定
- 后插入身高矮的人时，不会影响已插入的高个子的 k 值
- 矮个子插入到第 k 个位置，前面正好有 k 个身高大于等于自己的人

## Java 代码实现

### 方法一：贪心 + 插入（推荐）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 排序：身高降序，k 升序
        // 身高高的先处理，k 小的先处理
        Arrays.sort(people, (a, b) -> a[0] != b[0] ? b[0] - a[0] : a[1] - b[1]);

        // 使用 List 支持任意位置插入
        List<int[]> result = new ArrayList<>();

        // 按排序后的顺序，插入到第 k 个位置
        for (int[] person : people) {
            // 在索引 person[1] 处插入
            result.add(person[1], person);
        }

        return result.toArray(new int[people.length][]);
    }
}
```

### 方法二：详细注释版

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 步骤 1：排序
        // 按 (身高降序, k 升序) 排序
        // 例如：[[7,0],[7,1],[6,1],[5,0],[5,2],[4,4]]
        Arrays.sort(people, (a, b) -> {
            if (a[0] != b[0]) {
                return b[0] - a[0];  // 身高降序
            }
            return a[1] - b[1];      // k 升序
        });

        List<int[]> result = new ArrayList<>();

        // 步骤 2：依次插入
        // 因为已经按身高排序，插入时前面的人身高都 >= 当前人
        // 所以插入位置 k 就是前面有 k 个身高 >= 自己的人
        for (int[] person : people) {
            int k = person[1];
            // 在第 k 个位置插入
            // 例如：[7,1] 表示前面有 1 个身高 >= 7 的人
            //       所以插入到索引 1 的位置
            result.add(k, person);
        }

        return result.toArray(new int[people.length][]);
    }
}
```

### 方法三：使用 LinkedList 优化插入

```java
import java.util.Arrays;
import java.util.LinkedList;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // LinkedList 的中间插入比 ArrayList 更高效（无需移动元素）
        Arrays.sort(people, (a, b) -> a[0] != b[0] ? b[0] - a[0] : a[1] - b[1]);

        LinkedList<int[]> result = new LinkedList<>();

        for (int[] person : people) {
            // LinkedList.add(index, element) 直接在链表指定位置插入
            result.add(person[1], person);
        }

        return result.toArray(new int[people.length][]);
    }
}
```

### 方法四：自定义 Comparator（不使用 lambda）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 自定义比较器：身高降序，k 升序
        Arrays.sort(people, new Comparator<int[]>() {
            @Override
            public int compare(int[] a, int[] b) {
                if (a[0] != b[0]) {
                    return b[0] - a[0];  // 身高降序
                }
                return a[1] - b[1];      // k 升序
            }
        });

        List<int[]> result = new ArrayList<>();
        for (int[] person : people) {
            result.add(person[1], person);
        }

        return result.toArray(new int[people.length][]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
  - 排序：O(n log n)
  - n 次插入操作，每次插入最坏 O(n)（ArrayList 需要移动元素）
  - 总时间：O(n^2)

- **空间复杂度**：O(n)
  - 结果数组的空间
  - 排序的空间复杂度 O(log n)

## 关键点总结

1. **贪心策略**：先处理身高高的人，再处理身高矮的人
   - 高个子的位置确定后，矮个子插入不会影响他们

2. **排序规则**：
   - 第一关键字：身高降序（从高到矮）
   - 第二关键字：k 升序（k 小的优先）

3. **插入位置**：直接插入到索引 k 的位置
   - 因为已排序，前面的人身高都 >= 当前人
   - 所以索引 k 就是正确的位置

4. **正确性证明**：
   - 插入高个子时，不影响其他高个子的 k 值
   - 插入矮个子时，不影响高个子的 k 值（矮个子对高个子不可见）

## 易错点

1. **排序方向错误**：
   - 错误：身高升序排序
   - 正确：身高降序排序（从高到矮）

2. **k 值排序错误**：
   - 错误：身高相同时 k 降序
   - 正确：k 升序（k 小的先插入）

3. **插入位置错误**：
   - 错误：插入到末尾或其他位置
   - 正确：插入到索引 k 的位置

4. **理解 k 的含义**：
   - k 是前面有多少个身高 >= 自己的人
   - 不是身高 > 自己的人（注意是"大于或等于"）
