## 题目描述

给定一个 `m x n` 的整数矩阵 `grid` 和整数 `k`。对每个 `k x k` 的子矩阵，计算其中任意两个不同元素之差的绝对值的最小值。返回所有子矩阵的最小差组成的二维列表。

## 解题思路

枚举所有 `(m-k+1) * (n-k+1)` 个 k×k 子矩阵，对每个子矩阵排序后找相邻元素的最小差。数据范围较小（m, n <= 30, k <= 30），直接枚举可行。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[][] minAbsDiff(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        int rowsOut = m - k + 1, colsOut = n - k + 1;
        int[][] result = new int[rowsOut][colsOut];
        int[] elements = new int[k * k];

        for (int r = 0; r < rowsOut; r++) {
            for (int c = 0; c < colsOut; c++) {
                // 提取 k x k 子矩阵的所有元素
                int idx = 0;
                for (int dr = 0; dr < k; dr++)
                    for (int dc = 0; dc < k; dc++)
                        elements[idx++] = grid[r + dr][c + dc];

                // 排序后找最小差
                Arrays.sort(elements);
                int minDiff = Integer.MAX_VALUE;
                for (int i = 1; i < elements.length; i++) {
                    if (elements[i] != elements[i - 1])
                        minDiff = Math.min(minDiff, elements[i] - elements[i - 1]);
                }
                result[r][c] = (minDiff == Integer.MAX_VALUE) ? 0 : minDiff;
            }
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * k^2 * log k)
- 空间复杂度：O(k^2)

## 关键点总结

1. 枚举所有 `(m-k+1) * (n-k+1)` 个子矩阵
2. 对每个子矩阵排序，相邻元素之差的最小值就是答案
3. 所有元素相同时，最小差为 0
