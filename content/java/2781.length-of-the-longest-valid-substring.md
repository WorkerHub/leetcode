## 题目描述

给你字符串 `word` 和字符串数组 `forbidden`，返回不含任何禁止字符串作为子字符串的最长有效子字符串的长度（forbidden 中每个字符串长度不超过 10）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int longestValidSubstring(String word, List<String> forbidden) {
        Set<String> forbidSet = new HashSet<>(forbidden);
        int n = word.length(), ans = 0, left = 0;
        for (int right = 0; right < n; right++) {
            // 只需检查以 right 结尾、长度最多 10 的后缀
            for (int l = right; l >= Math.max(left, right - 9); l--) {
                if (forbidSet.contains(word.substring(l, right + 1))) {
                    left = l + 1;
                    break;
                }
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10n)，每个右端点最多检查 10 个子串
- 空间复杂度：O(总字符数)，哈希集合存储

## 关键点总结

1. forbidden 字符串长度最多 10，每次只需检查末尾 10 个后缀
2. 从右往左检查后缀，找到最靠右的禁止串以最小化 left 移动
3. left 只能右移，不能左移
