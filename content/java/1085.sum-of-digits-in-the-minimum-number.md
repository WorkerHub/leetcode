## 题目描述

给定整数数组，返回最小元素各位数字之和的奇偶性。偶数返回 1，奇数返回 0。

**示例：**
```
输入：nums = [34,23,1,24,75,33,54,8]
输出：0
```

## 解题思路

找最小值，计算各位数字之和，判断奇偶。

## Java 代码实现

```java
class Solution {
    public int sumOfDigits(int[] nums) {
        // 找最小值
        int min = nums[0];
        for (int num : nums) {
            min = Math.min(min, num);
        }

        // 计算各位数字之和
        int digitSum = 0;
        while (min > 0) {
            digitSum += min % 10;
            min /= 10;
        }

        // 偶数返回1，奇数返回0
        return 1 - (digitSum % 2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **找最小值**：遍历数组
2. **数位分离**：% 10 取末位，/ 10 去末位
3. **返回值含义**：注意题目要求偶数返回 1，奇数返回 0（与直觉相反）
