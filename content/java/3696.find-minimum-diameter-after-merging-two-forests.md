## 题目描述

给你两棵树（边集分别为 `edges1` 和 `edges2`，节点数分别为 n 和 m），通过一条新边将两棵树连接，返回合并后图的最小可能直径。

## 解题思路

合并后直径为三种情况的最大值：树 1 原直径、树 2 原直径、跨树路径（`ceil(d1/2) + 1 + ceil(d2/2)`）。用两次 BFS 求每棵树的直径（先从任意点找最远点，再从最远点找直径端点）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumDiameterAfterMerge(int n, int[][] edges1, int m, int[][] edges2) {
        int d1 = treeDiameter(n, edges1);
        int d2 = treeDiameter(m, edges2);
        int combined = (d1 + 1) / 2 + 1 + (d2 + 1) / 2;
        return Math.max(Math.max(d1, d2), combined);
    }

    private int treeDiameter(int n, int[][] edges) {
        if (n == 1) return 0;
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) { graph[e[0]].add(e[1]); graph[e[1]].add(e[0]); }
        // 两次BFS求直径
        int far1 = bfs(0, graph, n)[0];
        return bfs(far1, graph, n)[1];
    }

    private int[] bfs(int start, List<Integer>[] graph, int n) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        dist[start] = 0;
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(start);
        int farthest = start;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph[u]) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    if (dist[v] > dist[farthest]) farthest = v;
                    queue.offer(v);
                }
            }
        }
        return new int[]{farthest, dist[farthest]};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(n + m)

## 关键点总结

1. 合并后直径取三种情况最大值
2. 最优连接点是树的中心，连接代价 = `ceil(d1/2) + 1 + ceil(d2/2)`
3. `ceil(d/2) = (d+1)/2`（整数上取整）
