## 题目描述

n 个橘子，每天可吃 1 个，或（能整除2时）吃 n/2 个，或（能整除3时）吃 2n/3 个。求吃完最少天数。

**示例：**
```
输入：n = 10
输出：4
```

## 解题思路

记忆化搜索：dp(n) = min(n%2+1+dp(n/2), n%3+1+dp(n/3))。先凑整再除，状态数仅 O(log²n)。

## Java 代码实现

```java
class Solution {
    private Map<Integer, Integer> memo = new HashMap<>();
    
    public int minDays(int n) {
        if (n <= 1) return n;
        if (memo.containsKey(n)) return memo.get(n);
        
        int res = Math.min(
            n % 2 + 1 + minDays(n / 2),  // 先吃 n%2 个凑整，再吃一半
            n % 3 + 1 + minDays(n / 3)   // 先吃 n%3 个凑整，再吃三分之二
        );
        memo.put(n, res);
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²n)
- **空间复杂度**：O(log²n)

## 关键点总结

1. **贪心除法**：每步尽量除以 2 或 3
2. **凑整代价**：吃 n%2 或 n%3 个橘子（最多 2 天）
3. **状态稀疏**：实际记忆化状态数远小于 n
