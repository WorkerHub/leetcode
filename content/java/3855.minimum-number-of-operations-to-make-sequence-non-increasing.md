## 题目描述

给你一个整数数组 `nums`，每次操作可以将数组中的任意一个元素减 1（不能低于 0）。返回使数组变为非递增序列所需的最少操作次数。

## 解题思路

贪心：从左到右遍历，维护当前允许的最大值。每当 `nums[i] > curr_max`，需要将其减到 `curr_max`，操作数累加差值；否则更新 `curr_max = nums[i]`。

## Java 代码实现

```java
class Solution {
    public long minOperations(int[] nums) {
        long ops = 0;
        int currMax = Integer.MAX_VALUE;

        for (int v : nums) {
            if (v > currMax) {
                // 需要将 v 减到 currMax
                ops += v - currMax;
            } else {
                // 更新允许的最大值
                currMax = v;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：从左到右，每次将当前元素降到不大于前一个元素的值。
2. 只能减少元素，不能增加；若已满足条件则更新 `currMax`。
3. 操作数可能超出 int 范围，使用 `long` 累加。
