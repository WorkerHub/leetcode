## 题目描述

按字典 `wordList` 完成从单词 `beginWord` 到单词 `endWord` 转化，一个表示此过程的转换序列是形如 `beginWord -> s1 -> s2 -> ... -> sk` 的单词序列，并满足：

- 每对相邻的单词之间仅有单个字母不同
- 转换过程中的每个单词 `si`（`1 <= i <= k`）必须是字典 `wordList` 中的单词。注意，`beginWord` 不必是字典 `wordList` 中的单词
- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord`，以及一个字典 `wordList`。请你找出并返回所有从 `beginWord` 到 `endWord` 的**最短转换序列**，如果不存在这样的转换序列，返回一个空列表。每个序列都应该以单词列表 `[beginWord, s1, s2, ..., sk]` 的形式返回。

**示例 1：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出: [["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]
解释: 存在 2 种最短的转换序列：
"hit" -> "hot" -> "dot" -> "dog" -> "cog"
"hit" -> "hot" -> "lot" -> "log" -> "cog"
```

**示例 2：**
```
输入: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出: []
解释: endWord "cog" 不在字典 wordList 中，所以不存在符合要求的转换序列。
```

**提示：**
- `1 <= beginWord.length <= 5`
- `endWord.length == beginWord.length`
- `1 <= wordList.length <= 500`
- `wordList[i].length == beginWord.length`
- `beginWord`、`endWord` 和 `wordList[i]` 由小写英文字母组成
- `beginWord != endWord`
- `wordList` 中的所有单词互不相同

## 解题思路

这道题是 [127. 单词接龙](https://leetcode.com/problems/word-ladder/) 的进阶版，不仅要找到最短路径长度，还要**找出所有最短路径**。

核心思路：**BFS 建图 + DFS 回溯**

### 算法步骤：

1. **BFS 阶段**（从 beginWord 出发）：
   - 找到从 beginWord 到每个单词的最短距离
   - 构建一个有向图，记录最短路径上的前驱关系

2. **DFS 回溯阶段**（从 endWord 回溯）：
   - 利用 BFS 建立的前驱关系
   - 从 endWord 反向搜索到 beginWord
   - 收集所有最短路径

### 关键点：

- **双向 BFS 优化**：可以从两端同时搜索，减少搜索空间
- **前驱记录**：记录每个单词在最短路径中的所有前驱节点
- **距离控制**：只记录距离相同层的前驱，确保是最短路径

## Java 代码实现

### 方法一：BFS + DFS（推荐）

```java
class Solution {
    public List<List<String>> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        List<List<String>> result = new ArrayList<>();

        // endWord 必须在字典中
        if (!wordSet.contains(endWord)) return result;

        // 记录每个单词的前驱节点（可能有多个）
        Map<String, Set<String>> predecessors = new HashMap<>();
        // 记录每个单词的层数（距离）
        Map<String, Integer> distance = new HashMap<>();

        distance.put(beginWord, 0);
        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        boolean found = false;
        int currentLevel = 0;

        while (!queue.isEmpty() && !found) {
            currentLevel++;
            int levelSize = queue.size();
            // 本层访问的新节点
            Set<String> currentLevelVisited = new HashSet<>();

            for (int i = 0; i < levelSize; i++) {
                String word = queue.poll();
                char[] wordChars = word.toCharArray();

                for (int j = 0; j < wordChars.length; j++) {
                    char original = wordChars[j];

                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;
                        wordChars[j] = c;
                        String nextWord = new String(wordChars);

                        if (wordSet.contains(nextWord)) {
                            // 如果是第一次访问这个词
                            if (!distance.containsKey(nextWord)) {
                                distance.put(nextWord, currentLevel);
                                currentLevelVisited.add(nextWord);
                                predecessors.computeIfAbsent(nextWord, k -> new HashSet<>()).add(word);
                                if (nextWord.equals(endWord)) found = true;
                            }
                            // 如果在同一层访问过，说明有多条最短路径
                            else if (distance.get(nextWord) == currentLevel) {
                                predecessors.get(nextWord).add(word);
                            }
                        }

                        wordChars[j] = original;
                    }
                }
            }

            // 将本层新访问的节点加入队列
            queue.addAll(currentLevelVisited);
        }

        // 如果找不到 endWord
        if (!distance.containsKey(endWord)) return result;

        // DFS 回溯阶段：从 endWord 反向构建所有路径
        Deque<String> path = new ArrayDeque<>();
        path.addFirst(endWord);
        dfs(beginWord, endWord, predecessors, path, result);

        return result;
    }

    private void dfs(String beginWord, String word,
                     Map<String, Set<String>> predecessors,
                     Deque<String> path,
                     List<List<String>> result) {
        if (word.equals(beginWord)) {
            result.add(new ArrayList<>(path));
            return;
        }

        if (!predecessors.containsKey(word)) return;

        for (String prevWord : predecessors.get(word)) {
            path.addFirst(prevWord);
            dfs(beginWord, prevWord, predecessors, path, result);
            path.removeFirst();
        }
    }
}
```

### 方法二：简化版（容易理解）

```java
class Solution {
    public List<List<String>> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList);
        List<List<String>> result = new ArrayList<>();

        if (!wordSet.contains(endWord)) return result;

        // BFS 建立层级关系（前驱映射）
        Map<String, Set<String>> layers = new HashMap<>();
        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        Set<String> visited = new HashSet<>();
        visited.add(beginWord);
        boolean found = false;

        while (!queue.isEmpty() && !found) {
            int levelSize = queue.size();
            Set<String> nextVisited = new HashSet<>();

            for (int i = 0; i < levelSize; i++) {
                String word = queue.poll();
                char[] wordChars = word.toCharArray();

                for (int j = 0; j < wordChars.length; j++) {
                    char original = wordChars[j];

                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == original) continue;
                        wordChars[j] = c;
                        String neighbor = new String(wordChars);

                        if (wordSet.contains(neighbor)) {
                            if (neighbor.equals(endWord)) found = true;

                            if (!visited.contains(neighbor)) {
                                nextVisited.add(neighbor);
                                layers.computeIfAbsent(neighbor, k -> new HashSet<>()).add(word);
                            } else if (nextVisited.contains(neighbor)) {
                                layers.get(neighbor).add(word);
                            }
                        }

                        wordChars[j] = original;
                    }
                }
            }

            queue.addAll(nextVisited);
            visited.addAll(nextVisited);
        }

        if (!layers.containsKey(endWord)) return result;

        // DFS 回溯所有路径
        Deque<String> path = new ArrayDeque<>();
        path.addFirst(endWord);
        backtrack(beginWord, endWord, layers, path, result);

        return result;
    }

    private void backtrack(String beginWord, String word,
                           Map<String, Set<String>> layers,
                           Deque<String> path,
                           List<List<String>> result) {
        if (word.equals(beginWord)) {
            result.add(new ArrayList<>(path));
            return;
        }

        if (!layers.containsKey(word)) return;

        for (String prev : layers.get(word)) {
            path.addFirst(prev);
            backtrack(beginWord, prev, layers, path, result);
            path.removeFirst();
        }
    }
}
```

## 复杂度分析

设单词长度为 L，字典大小为 N。

- **时间复杂度**：O(N * L * 26)
  - BFS：O(N * L * 26)，每个单词尝试 L 个位置，每个位置 26 个字母
  - DFS：最坏情况下所有路径，复杂度较高

- **空间复杂度**：O(N * L)
  - 存储字典、队列、前驱关系等

## 关键点总结

1. **分两阶段处理**：先 BFS 找最短路径，再 DFS 回溯所有路径
2. **前驱记录**：每个单词记录所有可能的前驱节点
3. **层级控制**：只在同一层级建立前驱关系，保证最短路径
4. **去重处理**：访问过的单词要及时标记
5. **路径反向构建**：从 endWord 反向回溯到 beginWord，用 `addFirst` 维护正确顺序

## 易错点

1. **忘记检查 endWord 是否在字典中**
   ```java
   // 必须先检查
   if (!wordSet.contains(endWord)) return result;
   ```

2. **前驱记录错误**
   ```java
   // 错误：只记录一个前驱
   predecessors.put(nextWord, word);

   // 正确：记录所有前驱（用集合）
   predecessors.computeIfAbsent(nextWord, k -> new HashSet<>()).add(word);
   ```

3. **层级混淆**：必须在同一层内建立前驱关系，使用 `currentLevelVisited` 记录本层新访问的节点

4. **路径构建顺序**：DFS 从 endWord 回溯到 beginWord，使用 `Deque` 的 `addFirst/removeFirst` 保持正确顺序
