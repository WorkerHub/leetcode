## 题目描述

给你整数数组 `nums`，返回最大元素与最小元素的最大公约数（GCD）。

## 解题思路

找到最大值和最小值，用辗转相除法（欧几里得算法）求 GCD。

## Java 代码实现

```java
class Solution {
    public int findGCD(int[] nums) {
        int min = nums[0], max = nums[0];
        for (int x : nums) { min = Math.min(min, x); max = Math.max(max, x); }
        return gcd(max, min);
    }

    private int gcd(int a, int b) {
        while (b != 0) { int t = b; b = a % b; a = t; }
        return a;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + log(min))
- **空间复杂度**：O(1)

## 关键点总结

1. 只需求最大值和最小值的 GCD
2. 欧几里得算法：`gcd(a, b) = gcd(b, a%b)`
