## 题目描述

给你矩形右上角坐标 `(xCorner, yCorner)` 和圆数组 `circles[i] = [xi, yi, ri]`，判断是否存在从 `(0,0)` 到 `(xCorner, yCorner)` 不穿过任何圆内部、且在矩形内的路径。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public boolean canReachCorner(int xCorner, int yCorner, int[][] circles) {
        int n = circles.length;
        parent = new int[n + 2]; // n=左上障碍, n+1=右下障碍
        for (int i = 0; i < parent.length; i++) parent[i] = i;

        // 检查起点/终点是否在圆内（严格内部）
        for (int[] c : circles) {
            long dx0 = c[0], dy0 = c[1], r = c[2];
            if (dx0 * dx0 + dy0 * dy0 < r * r) return false;
            long dx1 = c[0] - xCorner, dy1 = c[1] - yCorner;
            if (dx1 * dx1 + dy1 * dy1 < r * r) return false;
        }

        for (int i = 0; i < n; i++) {
            long x = circles[i][0], y = circles[i][1], r = circles[i][2];
            // 圆与左边界(x=0)或上边界(y=yCorner)相交
            if (x <= r || y + r >= yCorner) union(i, n);
            // 圆与下边界(y=0)或右边界(x=xCorner)相交
            if (y <= r || x + r >= xCorner) union(i, n + 1);

            for (int j = i + 1; j < n; j++) {
                long dx = circles[i][0] - circles[j][0];
                long dy = circles[i][1] - circles[j][1];
                long rSum = circles[i][2] + (long) circles[j][2];
                if (dx * dx + dy * dy <= rSum * rSum) union(i, j);
            }
        }
        return find(n) != find(n + 1);
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px != py) parent[px] = py;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * alpha(n))，枚举所有圆对
- 空间复杂度：O(n)

## 关键点总结

1. 路径不可达 = 存在圆的障碍链将矩形从左上到右下切断
2. 用并查集合并相交的圆，以及与对应边界相交的圆
3. 全程使用整数平方比较，避免浮点精度问题
