## 题目描述

给你二维整数数组 `properties`，若两个元素的属性集合有至少 k 个公共属性则连边，返回属性图中连通分量的数量。

## 解题思路

并查集：对每对 (i, j) 计算集合交集大小，若 >= k 则合并。最终统计不同根节点数即连通分量数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent;

    public int numberOfComponents(int[][] properties, int k) {
        int n = properties.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 将每个属性集合转为 HashSet
        Set<Integer>[] sets = new HashSet[n];
        for (int i = 0; i < n; i++) {
            sets[i] = new HashSet<>();
            for (int v : properties[i]) sets[i].add(v);
        }

        // 枚举所有对，判断交集是否 >= k
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int common = 0;
                for (int v : sets[i]) {
                    if (sets[j].contains(v)) common++;
                }
                if (common >= k) union(i, j);
            }
        }

        // 统计连通分量数
        Set<Integer> roots = new HashSet<>();
        for (int i = 0; i < n; i++) roots.add(find(i));
        return roots.size();
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 * p)，n 为元素数，p 为属性集合大小
- 空间复杂度：O(n * p)

## 关键点总结

1. HashSet 快速计算两个集合的交集大小
2. 并查集路径压缩高效维护连通性
3. 统计不同根节点数即连通分量数
