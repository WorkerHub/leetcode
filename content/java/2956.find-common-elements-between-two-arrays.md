## 题目描述

给你两个整数数组 `nums1` 和 `nums2`，返回 `[answer1, answer2]`，其中 `answer1` 为 `nums1` 中在 `nums2` 里存在的元素个数（含重复），`answer2` 反之。

## 解题思路

将两个数组分别转为集合，然后遍历各数组统计在另一集合中存在的元素个数。

## Java 代码实现

```java
class Solution {
    public int[] findIntersectionValues(int[] nums1, int[] nums2) {
        Set<Integer> set1 = new HashSet<>();
        Set<Integer> set2 = new HashSet<>();
        for (int x : nums1) set1.add(x);
        for (int x : nums2) set2.add(x);

        int a1 = 0, a2 = 0;
        for (int x : nums1) if (set2.contains(x)) a1++; // nums1 中在 nums2 中存在的元素数
        for (int x : nums2) if (set1.contains(x)) a2++; // nums2 中在 nums1 中存在的元素数
        return new int[]{a1, a2};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 用集合实现 O(1) 查找
2. 统计时含重复计数（遍历原数组而非集合）
3. 两个方向分别统计
