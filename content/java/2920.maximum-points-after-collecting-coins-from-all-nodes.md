## 题目描述

给你 n 个节点的无根树（根为 0）和整数数组 coins，每个节点可选：操作 1 收集 coins[i]-k 分；操作 2 该节点得 0 分但子树所有节点金币减半。返回最大总得分。

## 解题思路

树形 DP + 位运算优化。coins[i] ≤ 10^4 < 2^14，故最多减半 14 次后金币为 0。定义 `dp[node][j]` 为该子树金币已减半 j 次时的最大得分，操作 1 贡献 `(coins[node]>>j) - k` 加子节点 dp[j]，操作 2 贡献子节点 dp[j+1]。

## Java 代码实现

```java
class Solution {
    int[] coins;
    int k;
    List<Integer>[] graph;
    int[][] dp;
    static final int MAX_H = 14;

    public int maximumPoints(int[][] edges, int[] coins, int k) {
        int n = coins.length;
        this.coins = coins;
        this.k = k;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        dp = new int[n][MAX_H];
        for (int[] row : dp) Arrays.fill(row, Integer.MIN_VALUE);

        // 迭代后序遍历
        int[] parent = new int[n];
        Arrays.fill(parent, -1);
        int[] order = new int[n];
        int idx = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        boolean[] visited = new boolean[n];
        stack.push(0);
        while (!stack.isEmpty()) {
            int node = stack.pop();
            if (visited[node]) { order[idx++] = node; continue; }
            visited[node] = true;
            stack.push(node);
            for (int child : graph[node]) {
                if (child != parent[node]) {
                    parent[child] = node;
                    stack.push(child);
                }
            }
        }

        for (int i = 0; i < n; i++) {
            int node = order[i];
            for (int j = 0; j < MAX_H; j++) {
                int c = coins[node] >> j;
                int res1 = c - k; // 操作 1
                int res2 = 0;     // 操作 2
                for (int child : graph[node]) {
                    if (child == parent[node]) continue;
                    res1 += dp[child][j];
                    if (j + 1 < MAX_H) res2 += dp[child][j + 1];
                    // j+1 >= MAX_H 时子树金币为 0，操作 2 贡献 0
                }
                dp[node][j] = Math.max(res1, res2);
            }
        }
        return dp[0][0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(14n)，每个节点计算 14 个状态
- **空间复杂度**：O(14n)

## 关键点总结

1. coins ≤ 10^4，连续减半 14 次后为 0，状态数有限
2. `coins[node] >> j` 表示减半 j 次后的金币数
3. 操作 2 节点本身得 0 分，但子节点继承 j+1 次减半
