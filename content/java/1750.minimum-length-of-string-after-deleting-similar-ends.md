## 题目描述

给你只含 `'a'`、`'b'`、`'c'` 的字符串 `s`，可以反复删除两端字符相同的最长同字符前缀和后缀（不重叠）。返回操作后字符串的最短长度。

## 解题思路

双指针贪心：两端字符相同时，同时向内跳过所有相同字符，直到两端字符不同或指针交叉。

## Java 代码实现

```java
class Solution {
    public int minimumLength(String s) {
        int left = 0, right = s.length() - 1;

        while (left < right && s.charAt(left) == s.charAt(right)) {
            char c = s.charAt(left);
            // 删除左端所有 c
            while (left <= right && s.charAt(left) == c) left++;
            // 删除右端所有 c
            while (left <= right && s.charAt(right) == c) right--;
        }

        return right - left + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：每次尽量多删两端的相同字符
2. 边界条件：内层循环需检查 `left <= right`
