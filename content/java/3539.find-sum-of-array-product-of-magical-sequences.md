## 题目描述

给定数组 `nums` 和整数 `k`。"魔法序列"是从 nums 中有序选取恰好 k 个元素（允许重复位置），使得它们的 AND 等于 0。求所有魔法序列的元素乘积之和，对 10^9+7 取模。

## 解题思路

容斥原理：`f(0) = sum_{mask} (-1)^popcount(mask) * g(mask)`，其中 `g(mask)` = 所有元素均包含 mask 的所有位的有序 k 元序列的乘积和 = `(满足 (x & mask)==mask 的元素之和)^k`。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public long sumOfMagicSequences(int[] nums, int k) {
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);
        int bits = 0;
        while ((1 << bits) <= maxVal) bits++;

        long result = 0;
        for (int mask = 0; mask < (1 << bits); mask++) {
            // 计算满足 (x & mask) == mask 的元素之和
            long s = 0;
            for (int x : nums) if ((x & mask) == mask) s = (s + x) % MOD;
            long g = pow(s, k);
            int pc = Integer.bitCount(mask);
            if (pc % 2 == 0) result = (result + g) % MOD;
            else result = (result - g + MOD) % MOD;
        }
        return result;
    }

    private long pow(long base, int exp) {
        long res = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) res = res * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^bits * n + 2^bits * log k)
- 空间复杂度：O(1)

## 关键点总结

1. 容斥：AND 恰为 0 = `sum (-1)^popcount(mask) * g(mask)`
2. `g(mask)` = 满足条件的元素之和的 k 次幂（有序选取）
3. 快速幂计算 `s^k mod p`
