## 题目描述

给你两个长度为 `n` 的整数数组 `nums1` 和 `nums2`，每次可交换 `nums1[i]` 和 `nums1[j]`（代价 `i+j`），使 `nums1[i] != nums2[i]` 对所有 `i` 成立，返回最小总代价或 -1。

## 解题思路

冲突位置（`nums1[i] == nums2[i]`）必须被移走，将这些下标汇入交换池并累加代价。若池中某值 dominant 超过半数，需继续引入不含该值的非冲突位置以平衡，直到 dominant 不超半或无法平衡（返回 -1）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minimumTotalCost(int[] nums1, int[] nums2) {
        int n = nums1.length;
        long cost = 0;
        int total = 0, dominant = -1, domCnt = 0;
        int[] cnt = new int[n + 1];

        for (int i = 0; i < n; i++) {
            if (nums1[i] == nums2[i]) {
                // 冲突位置，必须纳入交换池
                cost += i;
                total++;
                cnt[nums1[i]]++;
                if (cnt[nums1[i]] > domCnt) {
                    domCnt = cnt[nums1[i]];
                    dominant = nums1[i];
                }
            }
            // 若主导值超过一半，引入非冲突且不含 dominant 的位置
            if (domCnt * 2 > total && nums1[i] != nums2[i]
                    && nums1[i] != dominant && nums2[i] != dominant) {
                cost += i;
                total++;
            }
        }
        return domCnt * 2 > total ? -1 : cost;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 冲突位置的元素必须被交换出去，形成"交换池"
2. 若池中某值超过总数的一半，内部无法解决，需引入外部非冲突位置
3. 引入外部位置时，选不含 dominant 值的位置（否则问题更严重）
