## 题目描述

给定非负整数数组 nums，返回所有排列中满足每对相邻元素之和为完全平方数的排列数。

**示例：**
```
输入：nums = [1,17,8]
输出：2（[1,8,17] 和 [17,8,1]）
```

## 解题思路

回溯 + 去重：用 Counter 统计每个数的出现次数，DFS 枚举排列，检查相邻和是否为完全平方数。

## Java 代码实现

```java
class Solution {
    private int result = 0;

    public int numSquarefulPerms(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) count.merge(num, 1, Integer::sum);

        dfs(count, -1, nums.length);
        return result;
    }

    private void dfs(Map<Integer, Integer> count, int prev, int remaining) {
        if (remaining == 0) {
            result++;
            return;
        }

        for (int num : new ArrayList<>(count.keySet())) {
            if (count.get(num) == 0) continue;
            if (prev != -1 && !isPerfectSquare(prev + num)) continue;

            count.put(num, count.get(num) - 1);
            dfs(count, num, remaining - 1);
            count.put(num, count.get(num) + 1);
        }
    }

    private boolean isPerfectSquare(int n) {
        int root = (int) Math.sqrt(n);
        return root * root == n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n!)
- **空间复杂度**：O(n)

## 关键点总结

1. **Counter 去重**：避免重复排列
2. **回溯剪枝**：相邻和非完全平方数时跳过
3. **完全平方判断**：sqrt 取整后验证
