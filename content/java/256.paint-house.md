## 题目描述

假如有一排房子，共 n 个，每个房子可以被粉刷成红色、蓝色或者绿色这三种颜色中的一种。你需要粉刷所有的房子并且使其相邻的两个房子颜色不能相同。

每个房子粉刷成不同颜色的成本是不同的。你需要设计一个方案，使得粉刷所有房子的总成本最低。

**注意：** 所有成本都是正整数。

**示例：**

```
输入：costs = [[17,2,17],[16,16,5],[14,3,19]]
输出：10
解释：
将第 0 个房子粉刷成蓝色，第 1 个房子粉刷成绿色，第 2 个房子粉刷成蓝色。
最低成本: 2 + 5 + 3 = 10
```

**提示：**
- `costs.length == n`
- `costs[i].length == 3`
- `1 <= n <= 100`
- `1 <= costs[i][j] <= 20`

**进阶：** 你能否在 O(1) 的空间复杂度内解决它？

## 解题思路

这是一道经典的动态规划问题，类似于"打家劫舍"系列。

核心思想：
- 状态定义：`dp[i][j]` 表示粉刷到第 i 个房子，且第 i 个房子粉刷成颜色 j 时的最小成本
- 状态转移：第 i 个房子的颜色不能和第 i-1 个房子相同
- 最终答案：`min(dp[n-1][0], dp[n-1][1], dp[n-1][2])`

状态转移方程：
```
dp[i][0] = costs[i][0] + min(dp[i-1][1], dp[i-1][2])  // 粉刷成红色
dp[i][1] = costs[i][1] + min(dp[i-1][0], dp[i-1][2])  // 粉刷成蓝色
dp[i][2] = costs[i][2] + min(dp[i-1][0], dp[i-1][1])  // 粉刷成绿色
```

## Java 代码实现

### 方法一：动态规划（二维 DP）⭐

```java
class Solution {
    public int minCost(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        int n = costs.length;
        // dp[i][j] 表示粉刷到第 i 个房子，第 i 个房子颜色为 j 的最小成本
        int[][] dp = new int[n][3];

        // 初始化：第一个房子
        dp[0][0] = costs[0][0]; // 红色
        dp[0][1] = costs[0][1]; // 蓝色
        dp[0][2] = costs[0][2]; // 绿色

        // 状态转移
        for (int i = 1; i < n; i++) {
            // 粉刷成红色：前一个房子只能是蓝色或绿色
            dp[i][0] = costs[i][0] + Math.min(dp[i - 1][1], dp[i - 1][2]);
            // 粉刷成蓝色：前一个房子只能是红色或绿色
            dp[i][1] = costs[i][1] + Math.min(dp[i - 1][0], dp[i - 1][2]);
            // 粉刷成绿色：前一个房子只能是红色或蓝色
            dp[i][2] = costs[i][2] + Math.min(dp[i - 1][0], dp[i - 1][1]);
        }

        // 返回最后一个房子三种颜色的最小值
        return Math.min(dp[n - 1][0], Math.min(dp[n - 1][1], dp[n - 1][2]));
    }
}
```

### 方法二：空间优化（一维 DP）⭐

```java
class Solution {
    public int minCost(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        // 只需要保存前一个房子的三种颜色最小成本
        int prevRed = costs[0][0];
        int prevBlue = costs[0][1];
        int prevGreen = costs[0][2];

        for (int i = 1; i < costs.length; i++) {
            // 先计算当前房子所有颜色的成本（不能边算边更新 prev 变量）
            int currRed = costs[i][0] + Math.min(prevBlue, prevGreen);
            int currBlue = costs[i][1] + Math.min(prevRed, prevGreen);
            int currGreen = costs[i][2] + Math.min(prevRed, prevBlue);

            // 统一更新为当前状态
            prevRed = currRed;
            prevBlue = currBlue;
            prevGreen = currGreen;
        }

        return Math.min(prevRed, Math.min(prevBlue, prevGreen));
    }
}
```

### 方法三：原地修改（最优空间）⭐

```java
class Solution {
    public int minCost(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        // 直接在原数组上更新，实现 O(1) 额外空间
        for (int i = 1; i < costs.length; i++) {
            // 注意：先保存旧值，避免覆盖
            int r = costs[i - 1][0], b = costs[i - 1][1], g = costs[i - 1][2];
            costs[i][0] += Math.min(b, g); // 红色：取前一行蓝色和绿色的最小值
            costs[i][1] += Math.min(r, g); // 蓝色：取前一行红色和绿色的最小值
            costs[i][2] += Math.min(r, b); // 绿色：取前一行红色和蓝色的最小值
        }

        int last = costs.length - 1;
        return Math.min(costs[last][0], Math.min(costs[last][1], costs[last][2]));
    }
}
```

### 方法四：通用解法（适用于 k 种颜色）

```java
class Solution {
    public int minCost(int[][] costs) {
        if (costs == null || costs.length == 0) return 0;

        int k = costs[0].length; // 颜色数量
        int[] prev = costs[0].clone();

        for (int i = 1; i < costs.length; i++) {
            int[] curr = new int[k];
            for (int j = 0; j < k; j++) {
                // 找出除了颜色 j 之外的最小成本
                int minPrev = Integer.MAX_VALUE;
                for (int p = 0; p < k; p++) {
                    if (p != j) {
                        minPrev = Math.min(minPrev, prev[p]);
                    }
                }
                curr[j] = costs[i][j] + minPrev;
            }
            prev = curr;
        }

        int result = Integer.MAX_VALUE;
        for (int cost : prev) result = Math.min(result, cost);
        return result;
    }
}
```

## 复杂度分析

**方法一（二维 DP）：**
- 时间复杂度：O(n)，n 为房子数量
- 空间复杂度：O(n)

**方法二、三（空间优化）：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 图解示例

以 `costs = [[17,2,17],[16,16,5],[14,3,19]]` 为例：

```
房子:    0        1        2
颜色:  R  B  G   R  B  G   R  B  G
成本: 17  2 17  16 16  5  14  3 19

DP 过程：
初始化: dp[0] = [17, 2, 17]

房子1:
  dp[1][R] = 16 + min(2, 17) = 18
  dp[1][B] = 16 + min(17, 17) = 33
  dp[1][G] = 5 + min(17, 2) = 7
  dp[1] = [18, 33, 7]

房子2:
  dp[2][R] = 14 + min(33, 7) = 21
  dp[2][B] = 3 + min(18, 7) = 10  ← 最小
  dp[2][G] = 19 + min(18, 33) = 37
  dp[2] = [21, 10, 37]

最终答案: min(21, 10, 37) = 10

最优方案：房子0-蓝色(2) → 房子1-绿色(5) → 房子2-蓝色(3)
```

## 关键点总结

1. **DP 状态设计**：需要记录当前房子的颜色，确保相邻房子颜色不同
2. **状态转移**：当前颜色的成本 = 当前粉刷成本 + 前一房子其他颜色的最小成本
3. **空间优化**：只需要保存前一个房子的状态，可优化到 O(1)
4. **原地修改**：可以直接在原数组上修改，进一步优化空间
5. **通用性**：算法可以扩展到 k 种颜色的情况

## 易错点

1. **忘记限制相邻房子颜色不同**
   ```java
   // 错误：没有限制颜色
   dp[i][j] = costs[i][j] + min(dp[i-1]);

   // 正确：排除相同颜色
   dp[i][0] = costs[i][0] + Math.min(dp[i-1][1], dp[i-1][2]);
   ```

2. **空间优化时的变量更新顺序**
   ```java
   // 错误：边计算边更新，后面的计算用到了新值
   prevRed = costs[i][0] + Math.min(prevBlue, prevGreen);
   prevBlue = costs[i][1] + Math.min(prevRed, prevGreen); // prevRed 已被更新！

   // 正确：先全部计算，再统一更新
   int currRed = costs[i][0] + Math.min(prevBlue, prevGreen);
   int currBlue = costs[i][1] + Math.min(prevRed, prevGreen);
   int currGreen = costs[i][2] + Math.min(prevRed, prevBlue);
   prevRed = currRed; prevBlue = currBlue; prevGreen = currGreen;
   ```

3. **原地修改时注意读取旧值**
   ```java
   // 正确：先保存旧值再修改
   int r = costs[i-1][0], b = costs[i-1][1], g = costs[i-1][2];
   costs[i][0] += Math.min(b, g);
   ```

4. **边界条件**：注意处理只有一个房子的情况
