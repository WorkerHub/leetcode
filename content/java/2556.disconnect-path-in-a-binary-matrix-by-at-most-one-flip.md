## 题目描述

给你 m×n 二进制矩阵 `grid`，最多将一个 1 改为 0，判断是否能断开从 `(0,0)` 到 `(m-1,n-1)` 的所有路径（只能向右或向下，只经过 1）。

## 解题思路

两次 DFS：第一次 DFS 找一条路径并将路径格子标记为 0（除起终点），第二次 DFS 检查是否还有路径。若第二次仍有路径说明存在两条不相交路径，无法断开，返回 false。

## Java 代码实现

```java
class Solution {
    int[][] grid;
    int m, n;

    public boolean isPossibleToCutPath(int[][] grid) {
        this.grid = grid;
        this.m = grid.length;
        this.n = grid[0].length;

        // 第一次 DFS：标记一条路径为 0
        if (!dfs(0, 0)) return true; // 原本就无路径
        // 恢复起终点
        grid[0][0] = 1;
        grid[m - 1][n - 1] = 1;
        // 第二次 DFS：检查是否还有路径
        return !dfs(0, 0);
    }

    private boolean dfs(int r, int c) {
        if (r == m - 1 && c == n - 1) return true;
        grid[r][c] = 0; // 标记已访问（路径格子设为 0）
        // 只能向下或向右
        if (r + 1 < m && grid[r + 1][c] == 1 && dfs(r + 1, c)) return true;
        if (c + 1 < n && grid[r][c + 1] == 1 && dfs(r, c + 1)) return true;
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m + n)（递归栈深度）

## 关键点总结

1. 两次 DFS：第一次标记路径，第二次验证是否断开
2. 恢复起点 `(0,0)` 和终点 `(m-1,n-1)` 不被标记为 0
3. 两条不相交路径存在时，无法通过删一个格子断开
