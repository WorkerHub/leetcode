## 题目描述

我们定义，在以下情况时，单词的大写用法是正确的：

- 全部字母都是大写，比如 `"USA"`
- 单词中所有字母都不是大写，比如 `"leetcode"`
- 如果单词不只含有一个字母，只有首字母大写， 比如 `"Google"`

给你一个字符串 `word`。如果大写用法正确，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：word = "USA"
输出：true
```

**示例 2：**
```
输入：word = "FlaG"
输出：false
```

**提示：**
- `1 <= word.length <= 100`
- `word` 由小写和大写英文字母组成

## 解题思路

判断三种合法情况：
1. 全大写
2. 全小写
3. 首字母大写，其余小写

## Java 代码实现

### 方法一：使用字符串方法（推荐）⭐

```java
class Solution {
    public boolean detectCapitalUse(String word) {
        // 利用 Java 字符串方法
        // 时间复杂度：O(n)，空间复杂度：O(n)（toUpperCase 创建新字符串）
        return word.equals(word.toUpperCase()) ||   // 全大写
               word.equals(word.toLowerCase()) ||   // 全小写
               (Character.isUpperCase(word.charAt(0)) &&  // 首字母大写
                word.substring(1).equals(word.substring(1).toLowerCase())); // 其余小写
    }
}
```

### 方法二：计数大写字母

```java
class Solution {
    public boolean detectCapitalUse(String word) {
        // 统计大写字母数量
        // 时间复杂度：O(n)，空间复杂度：O(1)
        int upperCount = 0;
        for (char c : word.toCharArray()) {
            if (Character.isUpperCase(c)) upperCount++;
        }

        // 全大写 或 全小写 或 只有首字母大写
        return upperCount == word.length() ||
               upperCount == 0 ||
               (upperCount == 1 && Character.isUpperCase(word.charAt(0)));
    }
}
```

### 方法三：逐一判断

```java
class Solution {
    public boolean detectCapitalUse(String word) {
        // 手动判断三种情况
        // 时间复杂度：O(n)，空间复杂度：O(1)
        if (word.length() == 1) return true;

        // 情况1：全大写（第一个字母大写，第二个字母也大写）
        if (Character.isUpperCase(word.charAt(0)) && Character.isUpperCase(word.charAt(1))) {
            // 检查全都大写
            for (int i = 2; i < word.length(); i++) {
                if (!Character.isUpperCase(word.charAt(i))) return false;
            }
            return true;
        }

        // 情况2 或 3：其余字符都要小写
        for (int i = 1; i < word.length(); i++) {
            if (!Character.isLowerCase(word.charAt(i))) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（方法二、三），方法一为 O(n) 因为创建了新字符串

## 关键点总结

1. **Java 字符方法**：
   - `Character.isUpperCase(c)`：判断大写
   - `Character.isLowerCase(c)`：判断小写
   - `String.toUpperCase()`：转大写
   - `String.toLowerCase()`：转小写

2. **三种合法情况**：全大写 / 全小写 / 首字母大写
3. **计数方法**：最简洁的解法

## 易错点

1. **单字母**：单个大写或小写字母都是合法的
2. **substring(1)**：处理除首字母外的部分
3. **空字符串**：题目保证长度 >= 1
