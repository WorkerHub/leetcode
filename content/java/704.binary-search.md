## 题目描述

给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`，写一个函数搜索 `nums` 中的 `target`，如果目标值存在返回下标，否则返回 `-1`。

**示例 1：**
```
输入: nums = [-1,0,3,5,9,12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4
```

**示例 2：**
```
输入: nums = [-1,0,3,5,9,12], target = 2
输出: -1
解释: 2 不存在 nums 中因此返回 -1
```

**提示：**
- 你可以假设 `nums` 中的所有元素是不重复的
- `n` 将在 `[1, 10000]` 之间
- `nums` 的每个元素都将在 `[-9999, 9999]` 之间

## 解题思路

这是**二分查找**的标准模板题，必须掌握。

**二分查找原理：**
1. 前提条件：数组有序
2. 核心思想：每次比较中间元素，排除一半的搜索空间
3. 时间复杂度：O(log n)

**算法流程：**
1. 初始化左右指针：`left = 0, right = n - 1`
2. 循环条件：`left <= right`
3. 计算中点：`mid = left + (right - left) / 2`
4. 比较判断：
   - `nums[mid] == target`：找到，返回 `mid`
   - `nums[mid] < target`：目标在右半部分，`left = mid + 1`
   - `nums[mid] > target`：目标在左半部分，`right = mid - 1`
5. 未找到返回 `-1`

**关键细节：**
- 使用 `left + (right - left) / 2` 避免整数溢出
- 循环条件是 `left <= right`（等号很重要）
- 边界更新是 `mid + 1` 和 `mid - 1`（不包含 mid）

## Java 代码实现

### 方法一：标准二分查找（推荐）⭐

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            // 计算中点，避免整数溢出
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                // 目标在右半部分
                left = mid + 1;
            } else {
                // 目标在左半部分
                right = mid - 1;
            }
        }
        
        // 未找到目标
        return -1;
    }
}
```

### 方法二：使用 Arrays.binarySearch

```java
import java.util.Arrays;

class Solution {
    public int search(int[] nums, int target) {
        // Java 内置二分查找
        int index = Arrays.binarySearch(nums, target);
        // 找到返回索引（可能为负值表示未找到），未找到返回负数
        return index >= 0 ? index : -1;
    }
}
```

### 方法三：递归实现

```java
class Solution {
    public int search(int[] nums, int target) {
        return binarySearch(nums, target, 0, nums.length - 1);
    }
    
    private int binarySearch(int[] nums, int target, int left, int right) {
        if (left > right) {
            return -1;
        }
        
        int mid = left + (right - left) / 2;
        
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            return binarySearch(nums, target, mid + 1, right);
        } else {
            return binarySearch(nums, target, left, mid - 1);
        }
    }
}
```

### 方法四：位运算优化（进阶）

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        
        while (left <= right) {
            // 使用无符号右移，避免整数溢出
            int mid = (left + right) >>> 1;
            
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return -1;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(log n)
  - 每次比较排除一半元素
  - 最多需要 log₂n 次比较
- 空间复杂度：
  - 迭代版本：O(1)
  - 递归版本：O(log n)，递归调用栈深度

## 关键点总结

1. **有序数组**：二分查找的前提条件
2. **中点计算**：使用 `left + (right - left) / 2` 防溢出
3. **循环条件**：`left <= right` 包含等号
4. **边界更新**：`left = mid + 1` 和 `right = mid - 1`
5. **返回值**：找到返回索引，未找到返回 -1

## 易错点

1. **中点计算错误**：使用 `(left + right) / 2` 当 left 和 right 都很大时会溢出
2. **循环条件错误**：写成 `left < right` 会遗漏单元素情况
3. **边界更新错误**：写成 `left = mid` 或 `right = mid` 可能死循环
4. **整数溢出**：Java 中 int 范围是 -2^31 到 2^31-1，使用 `>>>` 无符号右移更安全
5. **Arrays.binarySearch 的返回值**：未找到时返回负数（插入点的负值减一）

## 图解示例

以 `nums = [-1,0,3,5,9,12], target = 9` 为例：

```
初始: left=0, right=5
      [-1, 0, 3, 5, 9, 12]
       ↑           ↑      ↑
      left        mid   right
      
步骤1: mid=2, nums[2]=3 < 9
      left = mid + 1 = 3
      [-1, 0, 3, 5, 9, 12]
                 ↑  ↑    ↑
               left mid right
               
步骤2: mid=4, nums[4]=9 == 9
      找到！返回 4
```
