## 题目描述

给你两个正整数 `left` 和 `right`，找出 `[left, right]` 范围内差值最小的两个质数 `num1 < num2`，返回 `[num1, num2]`；若范围内质数不足 2 则返回 `[-1, -1]`。

## 解题思路

用埃拉托色尼筛法预计算 `[left, right]` 内所有质数，然后遍历相邻质数对找最小差值。

## Java 代码实现

```java
class Solution {
    public int[] closestPrimes(int left, int right) {
        // 埃氏筛预计算质数
        boolean[] isComposite = new boolean[right + 1];
        isComposite[0] = isComposite[1] = true;
        for (int i = 2; (long) i * i <= right; i++) {
            if (!isComposite[i]) {
                for (int j = i * i; j <= right; j += i) {
                    isComposite[j] = true;
                }
            }
        }

        int prev = -1, minDiff = Integer.MAX_VALUE;
        int[] ans = {-1, -1};
        for (int p = left; p <= right; p++) {
            if (!isComposite[p]) {
                if (prev != -1 && p - prev < minDiff) {
                    minDiff = p - prev;
                    ans[0] = prev;
                    ans[1] = p;
                }
                prev = p;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(right * log log right)
- **空间复杂度**：O(right)

## 关键点总结

1. 埃氏筛高效预计算大范围质数
2. 差值最小的一定是相邻质数对，无需检查非相邻对
3. 若范围内质数不足 2，保持初始 `[-1, -1]` 返回
