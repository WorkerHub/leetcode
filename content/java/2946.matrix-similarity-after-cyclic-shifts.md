## 题目描述

给你一个 `m x n` 整数矩阵 `mat` 和整数 `k`，奇数行向右循环移位 `k` 次，偶数行向左循环移位 `k` 次，判断移位后矩阵是否与原矩阵相同。

## 解题思路

对每行计算实际移位量 `shift = k % n`，若为 0 直接返回 true。否则检查每个元素移位后是否与原位置相同。

## Java 代码实现

```java
class Solution {
    public boolean areSimilar(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;
        int shift = k % n;
        if (shift == 0) return true;

        for (int i = 0; i < m; i++) {
            int[] row = mat[i];
            for (int j = 0; j < n; j++) {
                if (i % 2 == 0) {
                    // 奇数行（1-indexed），向右移 shift
                    if (row[j] != row[(j - shift + n) % n]) return false;
                } else {
                    // 偶数行（1-indexed），向左移 shift
                    if (row[j] != row[(j + shift) % n]) return false;
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)
- **空间复杂度**：O(1)

## 关键点总结

1. 循环移位对 n 取余，减少实际移位量
2. 向右移 shift：位置 j 对应旧位置 `(j - shift + n) % n`
3. k % n == 0 时任何移位都不改变数组，直接返回 true
