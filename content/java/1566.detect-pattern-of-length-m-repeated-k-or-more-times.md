## 题目描述

找出数组中长度为 m 且连续重复至少 k 次的模式是否存在。

**示例：**
```
输入：arr = [1,2,4,4,4,4], m = 1, k = 3
输出：true
```

## 解题思路

连续匹配计数：若 arr[i]==arr[i+m] 则 count++，否则清零。count 达到 m*(k-1) 说明找到。

## Java 代码实现

```java
class Solution {
    public boolean containsPattern(int[] arr, int m, int k) {
        int count = 0;
        for (int i = 0; i + m < arr.length; i++) {
            if (arr[i] == arr[i + m]) {
                count++;
                if (count == m * (k - 1)) return true;
            } else {
                count = 0;
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **连续匹配**：arr[i]==arr[i+m] 表示模式可在此延续
2. **阈值**：count 达到 m*(k-1) 即找到 k 次重复
3. **中断重置**：不匹配时 count 归零
