## 题目描述

返回数组所有非空子集的XOR总和之和。

## 解题思路

数学公式：每一位独立分析，若至少一个元素该位为1，则恰好2^(n-1)个子集该位为1。答案=(所有元素OR) × 2^(n-1)。

## Java 代码实现

```java
class Solution {
    public int subsetXORSum(int[] nums) {
        int orAll = 0;
        for (int x : nums) orAll |= x;
        return orAll * (1 << (nums.length - 1));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **按位分析**：每位独立贡献
2. **公式**：答案 = OR(所有元素) × 2^(n-1)
3. **核心观察**：某位至少有一个1时，恰好一半子集该位XOR为1
