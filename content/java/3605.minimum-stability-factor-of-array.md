## 题目描述

给定整数数组 `nums`，返回数组的最小稳定因子：使整个数组中任意相邻元素之差的绝对值不超过该值的最小非负整数。

## Java 代码实现

```java
class Solution {
    public int minimumStabilityFactor(int[] nums) {
        if (nums.length <= 1) return 0;
        int ans = 0;
        for (int i = 1; i < nums.length; i++) {
            ans = Math.max(ans, Math.abs(nums[i] - nums[i - 1]));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 稳定因子由所有相邻元素差的绝对值最大值决定
2. 只需一次遍历即可找到最大相邻差
3. 单元素数组稳定因子为 0
