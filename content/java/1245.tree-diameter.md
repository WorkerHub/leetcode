## 题目描述

给定一棵无向树的边数组 edges，返回树的直径（任意两节点间最长路径的边数）。

**示例：**
```
输入：edges = [[0,1],[1,2],[2,3],[1,4],[4,5]]
输出：4（路径 3-2-1-4-5）
```

## 解题思路

两次 BFS/DFS：从任意点出发找最远点 A，再从 A 出发找最远点 B，A 到 B 的距离即为直径。

## Java 代码实现

```java
class Solution {
    public int treeDiameter(int[][] edges) {
        int n = edges.length + 1;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        
        // 第一次 BFS：从 0 出发找最远点
        int[] first = bfs(graph, 0, n);
        // 第二次 BFS：从最远点出发找直径
        int[] second = bfs(graph, first[0], n);
        return second[1];
    }
    
    // 返回 [最远节点, 最远距离]
    private int[] bfs(List<List<Integer>> graph, int start, int n) {
        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(start);
        visited[start] = true;
        int farthest = start, maxDist = 0, dist = 0;
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int node = queue.poll();
                farthest = node;
                maxDist = dist;
                for (int next : graph.get(node)) {
                    if (!visited[next]) {
                        visited[next] = true;
                        queue.offer(next);
                    }
                }
            }
            dist++;
        }
        return new int[]{farthest, maxDist};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，两次 BFS
- **空间复杂度**：O(n)

## 关键点总结

1. **两次 BFS**：第一次找端点，第二次量直径
2. **正确性**：从任意点出发最远点必为直径端点（可证明）
3. **层次 BFS**：按层遍历记录距离
4. **也可用 DFS**：对每个节点记录最深两条路径之和
