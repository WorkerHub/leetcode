## 题目描述

`n` 个工人搬运 `k` 件货物，桥每次只能过一人。每人有过桥（左右）和仓库操作时间，效率低的（`leftToRight + rightToLeft` 大）优先过桥，右侧等待回来的人优先于左侧。返回最后一个工人到达左岸的时刻。

## 解题思路

维护四个堆：等待过桥的左/右两侧（按效率低优先排序）和正在工作的左/右两侧（按完成时间排序）。模拟每个时刻的调度，无人等待时时间跳跃到最近完成事件。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findCrossingTime(int n, int k, int[][] time) {
        // 等待队列：(-效率, 工人编号)，效率 = leftToRight + rightToLeft
        PriorityQueue<int[]> waitLeft = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        PriorityQueue<int[]> waitRight = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        // 工作队列：(完成时间, 工人编号)
        PriorityQueue<int[]> workLeft = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        PriorityQueue<int[]> workRight = new PriorityQueue<>((a, b) -> a[0] - b[0]);

        for (int i = 0; i < n; i++) {
            waitLeft.offer(new int[]{time[i][0] + time[i][2], i});
        }

        int curTime = 0, rem = k;
        while (rem > 0 || !waitRight.isEmpty() || !workRight.isEmpty()) {
            // 释放完成工作的工人进等待队列
            while (!workRight.isEmpty() && workRight.peek()[0] <= curTime) {
                int[] w = workRight.poll();
                waitRight.offer(new int[]{time[w[1]][0] + time[w[1]][2], w[1]});
            }
            while (!workLeft.isEmpty() && workLeft.peek()[0] <= curTime) {
                int[] w = workLeft.poll();
                waitLeft.offer(new int[]{time[w[1]][0] + time[w[1]][2], w[1]});
            }

            if (!waitRight.isEmpty()) {
                // 右侧有人等待回来，优先处理
                int i = waitRight.poll()[1];
                curTime += time[i][2];
                if (rem == 0 && waitRight.isEmpty() && workRight.isEmpty()) return curTime;
                workLeft.offer(new int[]{curTime + time[i][3], i});
            } else if (rem > 0 && !waitLeft.isEmpty()) {
                // 左侧有人去搬运
                int i = waitLeft.poll()[1];
                curTime += time[i][0];
                rem--;
                workRight.offer(new int[]{curTime + time[i][1], i});
            } else {
                // 时间跳跃到最近完成事件
                int nxt = Integer.MAX_VALUE;
                if (!workRight.isEmpty()) nxt = Math.min(nxt, workRight.peek()[0]);
                if (rem > 0 && !workLeft.isEmpty()) nxt = Math.min(nxt, workLeft.peek()[0]);
                curTime = nxt;
            }
        }
        return curTime;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 四个堆分别管理等待/工作状态的左右侧工人
2. 优先级：效率低（`leftToRight + rightToLeft` 大）先过桥；右侧等待优先于左侧
3. 两侧都无等待时时间跳跃到最近完成时刻，避免逐秒模拟
