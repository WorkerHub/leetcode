## 题目描述

给定整数数组 `nums` 和整数 `k`，统计满足 `nums[i] * nums[j] == k`（`i < j`）的配对数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countProductPairs(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        int result = 0;

        for (int num : nums) {
            if (k % num == 0) {
                // 找之前出现的 k / num
                int complement = k / num;
                result += count.getOrDefault(complement, 0);
            }
            // 将当前数加入哈希表
            count.merge(num, 1, Integer::sum);
        }

        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表一次遍历
- 空间复杂度：O(n)，哈希表存储所有元素

## 关键点总结

1. 经典"两数之积等于 k"用哈希表解决，类似于两数之和
2. 先检查整除关系（`k % num == 0`）再查找配对，避免浮点误差
3. 先查询再插入，自动保证 `i < j`
