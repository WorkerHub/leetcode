## 题目描述

给你一个二进制字符串 `s`，每次操作可以交换相邻两位。返回使字符串变为非递减（所有 0 在所有 1 之前）所需的最少操作次数。

## 解题思路

最少相邻交换次数 = 逆序对数（冒泡排序原理）。每个 0 需要跨过其左边的 1 的数量，线性扫描统计即可。

## Java 代码实现

```java
class Solution {
    public long minOperations(String s) {
        long onesCount = 0, ops = 0;
        for (char c : s.toCharArray()) {
            if (c == '1') onesCount++;
            else ops += onesCount; // 这个0需要跨过左边的onesCount个1
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 逆序对数 = 最少相邻交换次数
2. 每个 0 需要跨过的步数 = 其左边 1 的个数
3. 线性扫描累加，结果可能较大需用 long
