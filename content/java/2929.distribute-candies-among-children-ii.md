## 题目描述

将n颗糖分给3个小朋友，每人至多limit颗，求方案数。（n,limit<=10^6）

## 解题思路

枚举第一个小朋友的分配a，剩余m=n-a分给两人，合法b的范围为[max(0,m-limit), min(m,limit)]，方案数为区间长度。

## Java 代码实现

```java
class Solution {
    public long distributeCandies(int n, int limit) {
        long count = 0;
        for (int a = 0; a <= Math.min(n, limit); a++) {
            int m = n - a;
            int lo = Math.max(0, m - limit);
            int hi = Math.min(m, limit);
            if (lo <= hi) count += hi - lo + 1;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(min(N, limit))
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举一人O(1)算另外两人**：固定a后b+c=m的合法范围
2. **区间长度**：hi-lo+1即方案数
3. **也可用容斥O(1)解**：同III的公式
