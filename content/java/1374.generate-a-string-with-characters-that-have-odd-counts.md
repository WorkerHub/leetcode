## 题目描述

给你一个整数 `n`，返回一个含 `n` 个字符的字符串，其中每种字符恰好出现奇数次（只含小写英文字母）。

## 解题思路

n 为奇数时直接返回 n 个 'a'；n 为偶数时返回 (n-1) 个 'a' 加 1 个 'b'，(n-1) 为奇数，'b' 出现 1 次（奇数），满足条件。

## Java 代码实现

```java
class Solution {
    public String generateTheString(int n) {
        StringBuilder sb = new StringBuilder();
        if (n % 2 == 1) {
            // n 为奇数：n 个 'a'，出现奇数次
            for (int i = 0; i < n; i++) sb.append('a');
        } else {
            // n 为偶数：(n-1) 个 'a' + 1 个 'b'
            // 'a' 出现 n-1 次（奇数），'b' 出现 1 次（奇数）
            for (int i = 0; i < n - 1; i++) sb.append('a');
            sb.append('b');
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，构造长度为 n 的字符串。
- 空间复杂度：O(n)，输出字符串长度为 n。

## 关键点总结

1. n 为奇数时全用一种字符即可，n 个相同字符出现奇数次。
2. n 为偶数时用两种字符：n-1 个 'a'（奇数）加 1 个 'b'（奇数），总长度仍为 n。
3. 不可将偶数 n 平均分成两种字符（各出现偶数次），会违反条件。
