## 题目描述

句子中以$开头的纯数字单词为价格，按discount%打折后保留两位小数。

## 解题思路

按空格分割，判断每个单词是否是价格（$开头且后续为纯数字），是则计算折后价格格式化为$xx.xx。

## Java 代码实现

```java
class Solution {
    public String discountPrices(String sentence, int discount) {
        String[] words = sentence.split(" ");
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            if (word.length() > 1 && word.charAt(0) == '$' && isDigits(word.substring(1))) {
                long price = Long.parseLong(word.substring(1));
                double discounted = price * (100.0 - discount) / 100.0;
                sb.append(String.format("$%.2f", discounted));
            } else {
                sb.append(word);
            }
            if (i < words.length - 1) sb.append(' ');
        }
        return sb.toString();
    }

    private boolean isDigits(String s) {
        for (char c : s.toCharArray()) {
            if (c < '0' || c > '9') return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **价格判断**：$开头且后续全为数字
2. **格式化两位小数**：String.format("$%.2f", value)
3. **用long解析价格**：防止大数字溢出int
