## 题目描述

给定一个字符串数组 `wordsDict` 和两个字符串 `word1` 和 `word2`，返回列表中这两个单词之间的最短距离。

**注意：** `word1` 和 `word2` 可能相同，此时你需要找到数组中这个单词相邻出现位置的最短距离。

**示例 1：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "makes", word2 = "coding"
输出: 1
```

**示例 2：**
```
输入: wordsDict = ["practice", "makes", "perfect", "coding", "makes"], word1 = "makes", word2 = "makes"
输出: 3
解释: "makes" 出现在索引 1 和 4，最短距离是 3
```

**提示：**
- 1 <= wordsDict.length <= 10^5
- 1 <= wordsDict[i].length <= 10
- wordsDict[i] 由小写英文字母组成
- word1 和 word2 在 wordsDict 中

## 解题思路

这道题是 [LeetCode 243](https://leetcode.com/problems/shortest-word-distance/) 的扩展，关键区别是**word1 和 word2 可能相同**。

**核心思想：**
- 当 word1 != word2 时，使用 243 题的双指针方法
- 当 word1 == word2 时，找该单词相邻出现的最小距离

**关键观察：**
1. **相同单词的情况**：需要找到同一个单词的两个不同位置，且距离最小
2. **不同单词的情况**：和 243 题完全一样
3. **统一处理**：可以用一个算法同时处理两种情况

**算法设计：**
- 使用两个指针 pos1 和 pos2
- 当单词相同时，每次更新时 pos1 = pos2，pos2 = 当前位置
- 当单词不同时，分别更新对应的指针

## Java 代码实现

### 方法一：分情况讨论（易理解）

```java
class Solution {
    public int shortestWordDistance(String[] wordsDict, String word1, String word2) {
        if (word1.equals(word2)) {
            // 情况1：相同单词，找相邻出现的最小距离
            return shortestSameWord(wordsDict, word1);
        } else {
            // 情况2：不同单词，使用 243 题的方法
            return shortestDiffWord(wordsDict, word1, word2);
        }
    }
    
    // 找同一个单词相邻出现的最小距离
    private int shortestSameWord(String[] wordsDict, String word) {
        int minDistance = Integer.MAX_VALUE;
        int prevPos = -1;
        
        for (int i = 0; i < wordsDict.length; i++) {
            if (wordsDict[i].equals(word)) {
                if (prevPos != -1) {
                    minDistance = Math.min(minDistance, i - prevPos);
                }
                prevPos = i;
            }
        }
        
        return minDistance;
    }
    
    // 找两个不同单词的最小距离（243 题的方法）
    private int shortestDiffWord(String[] wordsDict, String word1, String word2) {
        int minDistance = Integer.MAX_VALUE;
        int pos1 = -1, pos2 = -1;
        
        for (int i = 0; i < wordsDict.length; i++) {
            if (wordsDict[i].equals(word1)) {
                pos1 = i;
                if (pos2 != -1) {
                    minDistance = Math.min(minDistance, pos1 - pos2);
                }
            } else if (wordsDict[i].equals(word2)) {
                pos2 = i;
                if (pos1 != -1) {
                    minDistance = Math.min(minDistance, pos2 - pos1);
                }
            }
        }
        
        return minDistance;
    }
}
```

### 方法二：统一处理（推荐）⭐

```java
class Solution {
    public int shortestWordDistance(String[] wordsDict, String word1, String word2) {
        int minDistance = Integer.MAX_VALUE;
        int pos1 = -1, pos2 = -1;
        boolean same = word1.equals(word2);
        
        for (int i = 0; i < wordsDict.length; i++) {
            String word = wordsDict[i];
            
            if (word.equals(word1)) {
                // 如果 word1 == word2，pos1 保存上一个位置
                if (same) {
                    pos1 = pos2;
                } else {
                    pos1 = i;
                }
            }
            
            if (word.equals(word2)) {
                pos2 = i;
            }
            
            // 两个位置都有效且不同，计算距离
            if (pos1 != -1 && pos2 != -1 && pos1 != pos2) {
                minDistance = Math.min(minDistance, Math.abs(pos1 - pos2));
            }
        }
        
        return minDistance;
    }
}
```

### 方法三：更简洁的统一处理⭐

```java
class Solution {
    public int shortestWordDistance(String[] wordsDict, String word1, String word2) {
        int minDistance = Integer.MAX_VALUE;
        int pos1 = -1, pos2 = -1;
        
        for (int i = 0; i < wordsDict.length; i++) {
            String word = wordsDict[i];
            
            // 先保存 pos2 的旧值（用于 word1 == word2 的情况）
            if (word.equals(word1)) {
                pos1 = word1.equals(word2) ? pos2 : i;
            }
            
            // 更新 pos2
            if (word.equals(word2)) {
                pos2 = i;
            }
            
            // 两个位置都有效且不同，计算距离
            if (pos1 != -1 && pos2 != -1 && pos1 != pos2) {
                minDistance = Math.min(minDistance, Math.abs(pos1 - pos2));
            }
        }
        
        return minDistance;
    }
}
```

class Solution {
    public int shortestWordDistance(String[] wordsDict, String word1, String word2) {

### 方法五：单指针法（最简洁）

```java
class Solution {
    public int shortestWordDistance(String[] wordsDict, String word1, String word2) {
        int minDistance = Integer.MAX_VALUE;
        int prevPos = -1;
        
        for (int i = 0; i < wordsDict.length; i++) {
            String word = wordsDict[i];
            if (word.equals(word1) || word.equals(word2)) {
                // 如果上一个位置有效，且满足条件，计算距离
                if (prevPos != -1) {
                    // word1 == word2: 总是计算距离
                    // word1 != word2: 只有当前单词与上一个不同时才计算
                    if (word1.equals(word2) || !wordsDict[prevPos].equals(word)) {
                        minDistance = Math.min(minDistance, i - prevPos);
                    }
                }
                prevPos = i;
            }
        }
        
        return minDistance;
    }
}
```

## 复杂度分析

所有方法的复杂度都相同：
- **时间复杂度**：O(n)，遍历一次数组
- **空间复杂度**：O(1)，只使用常量额外空间

## 图解示例

**示例 1：** `wordsDict = ["practice", "makes", "perfect", "coding", "makes"]`, `word1 = "makes"`, `word2 = "coding"`

```
索引:   0          1       2         3        4
单词: practice   makes  perfect  coding   makes

word1 != word2，使用双指针：

i=1: "makes" == word1, pos1=1
i=3: "coding" == word2, pos2=3
     minDistance = min(MAX, |1-3|) = 2
i=4: "makes" == word1, pos1=4
     minDistance = min(2, |4-3|) = 1

结果：1
```

**示例 2：** `wordsDict = ["practice", "makes", "perfect", "coding", "makes"]`, `word1 = "makes"`, `word2 = "makes"`

```
word1 == word2，找相邻出现：

i=1: "makes" 第一次出现，pos2=1
i=4: "makes" 第二次出现
     pos1 = pos2 = 1  (保存上一个位置)
     pos2 = 4         (更新当前位置)
     minDistance = min(MAX, |4-1|) = 3

结果：3
```

## 关键点总结

1. **区分两种情况**：word1 == word2 需要特殊处理
2. **相邻位置更新**：相同单词时，要保存上一个位置
3. **统一算法**：可以用一个算法同时处理两种情况
4. **位置判断**：计算距离前要确保 pos1 != pos2（避免同一位置）
5. **Java 字符串比较**：必须使用 `equals()` 方法

## 易错点

1. **相同单词处理**：忘记 word1 == word2 的情况，导致结果错误
2. **位置更新顺序**：相同单词时，要先保存 pos2 到 pos1，再更新 pos2
3. **距离判断条件**：要确保 pos1 != pos2，否则距离为 0
4. **边界情况**：只出现一次的单词（相同单词情况下）
5. **初始化**：pos1 和 pos2 初始化为 -1 而不是 0
