## 题目描述

给定只含数字字符的字符串 `s`，找出最靠左的一对相邻相同数字，且该数字在整个字符串中恰好出现 2 次，返回该两字符组成的字符串，否则返回空字符串。

## Java 代码实现

```java
class Solution {
    public String findValidPair(String s) {
        // 统计每个数字的出现次数
        int[] freq = new int[10];
        for (char c : s.toCharArray()) freq[c - '0']++;

        // 扫描相邻相同对，且该数字恰好出现 2 次
        for (int i = 0; i < s.length() - 1; i++) {
            char c = s.charAt(i);
            if (c == s.charAt(i + 1) && freq[c - '0'] == 2) {
                return "" + c + c;
            }
        }
        return "";
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 先统计频率，再扫描，避免重复 count 调用
2. 两个条件：相邻相同 + 该数字在全串中恰好出现 2 次
3. 返回最靠左的满足条件的对（两字符）
