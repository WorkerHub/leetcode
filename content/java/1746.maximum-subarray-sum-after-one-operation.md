## 题目描述

给你整数数组 `nums`，必须恰好执行一次操作：选一个元素替换为其平方。返回操作后的最大子数组和。

## 解题思路

DP 两状态：`dp0` 表示以当前元素结尾、未使用平方的最大子数组和；`dp1` 表示已使用一次平方的最大子数组和。转移：`dp1 = max(max(dp0,0) + x^2, dp1 + x)`，`dp0 = max(dp0 + x, x)`。

## Java 代码实现

```java
class Solution {
    public int maxSumAfterOperation(int[] nums) {
        // dp0: 未使用平方的最大子数组和（以当前元素结尾）
        // dp1: 已使用一次平方的最大子数组和（以当前元素结尾）
        long dp0 = nums[0];
        long dp1 = (long) nums[0] * nums[0]; // 在第一个元素使用平方
        long ans = dp1;

        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long newDp1 = Math.max(Math.max(dp0, 0) + x * x, dp1 + x); // 在此处平方或延续之前的平方
            long newDp0 = Math.max(dp0 + x, x); // 标准 Kadane
            dp0 = newDp0;
            dp1 = newDp1;
            ans = Math.max(ans, dp1);
        }

        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 两状态 DP：是否已使用平方操作
2. 转移类似 Kadane 算法，在每个位置决定是否在此处使用平方
