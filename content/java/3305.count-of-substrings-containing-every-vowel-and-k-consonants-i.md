## 题目描述

给你字符串 `word` 和非负整数 `k`，返回包含全部 5 个元音字母且恰好含 `k` 个辅音字母的子字符串数目。

## 解题思路

`恰好k个辅音` = `至少k个辅音（含所有元音）` - `至少k+1个辅音（含所有元音）`。用滑动窗口实现 `atLeast(minK)` 函数：当窗口满足条件时，以当前左端点为起点、右端点可延伸到末尾，贡献 `n-r` 个子串，然后收缩左端。

## Java 代码实现

```java
class Solution {
    public int countOfSubstrings(String word, int k) {
        return (int) (atLeast(word, k) - atLeast(word, k + 1));
    }

    private long atLeast(String word, int minK) {
        int n = word.length();
        boolean[] isVowel = new boolean[26];
        for (char c : "aeiou".toCharArray()) isVowel[c - 'a'] = true;
        int[] vowelCnt = new int[26];
        int vowelTypes = 0, consonantCnt = 0, l = 0;
        long count = 0;

        for (int r = 0; r < n; r++) {
            int ci = word.charAt(r) - 'a';
            if (isVowel[ci]) {
                if (vowelCnt[ci]++ == 0) vowelTypes++; // 新出现的元音种类
            } else {
                consonantCnt++;
            }
            // 窗口满足条件时，右端点还可延伸，累加并收缩左端
            while (vowelTypes == 5 && consonantCnt >= minK) {
                count += n - r;
                int lci = word.charAt(l) - 'a';
                if (isVowel[lci]) {
                    if (--vowelCnt[lci] == 0) vowelTypes--;
                } else {
                    consonantCnt--;
                }
                l++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，两次滑动窗口
- 空间复杂度：O(1)

## 关键点总结

1. `恰好k` = `至少k` - `至少k+1`，是处理"恰好"型滑动窗口的标准转化
2. 窗口满足条件时，右端点 r 可继续延伸，贡献 `n-r` 个子串
3. 用 `vowelTypes` 追踪元音种类数，避免低效的集合大小判断
