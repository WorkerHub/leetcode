## 题目描述

给定整数数组 `nums`，每次可删除任意一个元素，返回使 `nums` 成为回文数组所需的最少删除次数。

## 解题思路

转化为最长回文子序列（LPS）问题：最少删除次数 = n - LPS 长度。区间 DP：`dp[i][j]` 表示 `nums[i..j]` 的 LPS 长度，两端相等时 `dp[i][j] = dp[i+1][j-1] + 2`，否则取左右子问题最大值。

## Java 代码实现

```java
class Solution {
    public int minimumDeletions(int[] nums) {
        int n = nums.length;
        // dp[i][j] = nums[i..j] 的最长回文子序列长度
        int[][] dp = new int[n][n];

        // 长度为 1 的子数组都是回文
        for (int i = 0; i < n; i++) dp[i][i] = 1;

        // 按子数组长度从小到大枚举
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (nums[i] == nums[j]) {
                    // 两端相等，两端都取
                    dp[i][j] = (len > 2 ? dp[i + 1][j - 1] : 0) + 2;
                } else {
                    // 删左端或删右端，取较优
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }

        // 最少删除 = 总长度 - 最长回文子序列
        return n - dp[0][n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子数组
- 空间复杂度：O(n^2)，DP 表

## 关键点总结

1. 核心转化：最少删除 = n - 最长回文子序列（LPS）长度。
2. LPS 区间 DP：两端相等时 `dp[i][j] = dp[i+1][j-1] + 2`，否则取左右最大。
3. 区间 DP 枚举顺序：按长度从小到大（确保子问题先求解）。
