## 题目描述

给你整数数组 `nums` 和整数 `x`，每次从最左或最右移除一个元素并从 x 中减去。返回使 x 恰好减为 0 的**最少操作数**，不可达返回 `-1`。

## 解题思路

**等价转化：** 从两端移除总和为 x 的元素，等价于找**中间子数组的最大长度**使其和为 `sum - x`。用**滑动窗口**找最长满足条件的子数组。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int total = 0;
        for (int num : nums) total += num;
        int target = total - x;

        if (target < 0) return -1;
        if (target == 0) return nums.length; // 全部移除

        int n = nums.length;
        int maxLen = -1;
        int currSum = 0;
        int left = 0;

        for (int right = 0; right < n; right++) {
            currSum += nums[right];

            // 若当前和超过 target，缩小左边界
            while (currSum > target && left <= right) {
                currSum -= nums[left++];
            }

            if (currSum == target) {
                maxLen = Math.max(maxLen, right - left + 1);
            }
        }

        return maxLen == -1 ? -1 : n - maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 问题转化：找最长子数组使和为 `sum - x`
2. 数组元素均为正，滑动窗口具有单调性
3. 最少操作数 = `n - 最长中间子数组长度`
