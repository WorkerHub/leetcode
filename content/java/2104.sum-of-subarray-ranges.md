## 题目描述

给定整数数组nums，返回所有子数组范围（最大值-最小值）之和。

## 解题思路

范围之和 = 所有子数组最大值之和 - 所有子数组最小值之和。用单调栈O(N)计算每个元素作为极值时的贡献。

## Java 代码实现

```java
class Solution {
    public long subArrayRanges(int[] nums) {
        return sumSubarrayMaxs(nums) - sumSubarrayMins(nums);
    }
    
    private long sumSubarrayMins(int[] nums) {
        int n = nums.length;
        long result = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i <= n; i++) {
            while (!stack.isEmpty() && (i == n || nums[stack.peek()] >= nums[i])) {
                int mid = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int right = i;
                result += (long) nums[mid] * (mid - left) * (right - mid);
            }
            stack.push(i);
        }
        return result;
    }
    
    private long sumSubarrayMaxs(int[] nums) {
        int n = nums.length;
        long result = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i <= n; i++) {
            while (!stack.isEmpty() && (i == n || nums[stack.peek()] <= nums[i])) {
                int mid = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int right = i;
                result += (long) nums[mid] * (mid - left) * (right - mid);
            }
            stack.push(i);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **拆分问题**：范围和 = 最大值之和 - 最小值之和
2. **单调栈求贡献**：每个元素作为极值的子数组数 = (mid-left)*(right-mid)
3. **用long**：累加结果可能溢出int
