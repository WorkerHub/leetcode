## 题目描述

给你字符串 `s`（长度 <= 500），返回不同子字符串的数目。

## 解题思路

**集合暴力：** n <= 500 时，枚举所有子串加入 HashSet，返回大小。也可用**字典树**：从每个位置逐字符插入，每创建新节点计数 +1。

## Java 代码实现

```java
class Solution {
    public int countDistinct(String s) {
        Set<String> set = new HashSet<>();
        int n = s.length();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j <= n; j++) {
                set.add(s.substring(i, j));
            }
        }
        return set.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^3)（子串哈希）
- **空间复杂度**：O(n^2)

## 关键点总结

1. n <= 500 时集合暴力完全够用
2. 字典树方法：每插入新节点代表发现一个新不同子串，时间 O(n^2)
3. 后缀数组方法：不同子串数 = `n*(n+1)/2 - sum(LCP)`
