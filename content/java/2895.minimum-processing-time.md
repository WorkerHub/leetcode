## 题目描述

有 n 个处理器各有 4 个核心，给定处理器空闲时刻数组和 4n 个任务用时，将任务分配给处理器（每个处理器 4 个任务同时执行），返回所有任务完成的最早时间。

## 解题思路

贪心：处理器按空闲时刻升序排列，任务按用时降序排列，最早空闲的处理器分配最耗时的 4 个任务，完成时刻 = 空闲时刻 + 该批任务的最大用时。

## Java 代码实现

```java
class Solution {
    public int minProcessingTime(List<Integer> processorTime, List<Integer> tasks) {
        List<Integer> proc = new ArrayList<>(processorTime);
        List<Integer> task = new ArrayList<>(tasks);

        Collections.sort(proc);               // 处理器按空闲时刻升序
        task.sort(Collections.reverseOrder()); // 任务按用时降序

        int ans = 0;
        for (int i = 0; i < proc.size(); i++) {
            // 第 i 个处理器分配任务 task[4i..4i+3]，最大用时为 task[4i]
            ans = Math.max(ans, proc.get(i) + task.get(4 * i));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：最早空闲的处理器配最耗时的任务（交换后证明不会更好）
2. 处理器完成时刻 = `processorTime[i] + tasks[4*i]`（取该批最大值）
3. 4 个任务同时执行，完成时间由最慢的任务决定
