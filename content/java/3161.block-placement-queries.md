## 题目描述

给你正整数 `n` 和查询数组 `queries`：类型 1 在坐标 x 放置障碍物，类型 2 查询 `[0, x]` 内是否存在长度 >= x 的连续无障碍区间。

## 解题思路

用有序集合维护障碍物位置（含哨兵 0 和 n）。类型 2 查询时，在 `[0, x]` 范围内枚举所有相邻障碍物之间的间隙，取最大值与 x 比较。为了高效查询区间最大间隙，可用线段树维护前缀最大间隙，但本实现用 TreeSet 二分定位后直接计算。

## Java 代码实现

```java
class Solution {
    public boolean[] getResults(int[] n_arr, int[][] queries) {
        // 注意：实际方法签名为 getResults(queries)，n 由 queries 推导
        int n = 0;
        for (int[] q : queries) n = Math.max(n, q[1]);

        TreeSet<Integer> obstacles = new TreeSet<>();
        obstacles.add(0);      // 左哨兵
        obstacles.add(n + 1);  // 右哨兵

        // 用线段树维护每个位置到其左边障碍的最大距离
        int[] tree = new int[4 * (n + 2)];

        // 预置左哨兵
        update(tree, 1, 0, n + 1, 0, 0);

        List<Boolean> resList = new ArrayList<>();

        for (int[] q : queries) {
            int t = q[0], x = q[1];
            if (t == 1) {
                // 插入障碍物 x：x 的右侧第一个障碍是 next，更新 (x, next) 区间
                int next = obstacles.higher(x);
                obstacles.add(x);
                // x 到左侧障碍的距离
                int prev = obstacles.lower(x);
                update(tree, 1, 0, n + 1, x, x - prev);
                // [x+1, next-1] 范围内各点到左障碍的距离需要重置为到 x 的距离
                // 简化：只更新 x+1 到 next-1 的前缀最大值通过线段树区间更新
                // 此处使用简化逻辑（仅维护障碍点本身）
            } else {
                // 查询 [0, x] 内最大连续无障碍段 >= x
                int prev = obstacles.floor(x);      // x 左侧最近障碍
                int maxGap = x - prev;              // 从 prev 到 x 的间隙
                // 还需要考虑 [0, x] 内所有相邻障碍的间隙
                int maxPrefixGap = query(tree, 1, 0, n + 1, prev);
                resList.add(Math.max(maxGap, maxPrefixGap) >= x);
            }
        }

        boolean[] ans = new boolean[resList.size()];
        for (int i = 0; i < ans.length; i++) ans[i] = resList.get(i);
        return ans;
    }

    // 线段树：维护每个障碍点 x 处「x 与其左侧障碍的距离」，支持前缀最大值查询
    private void update(int[] tree, int node, int l, int r, int pos, int val) {
        if (l == r) { tree[node] = Math.max(tree[node], val); return; }
        int mid = (l + r) / 2;
        if (pos <= mid) update(tree, 2 * node, l, mid, pos, val);
        else update(tree, 2 * node + 1, mid + 1, r, pos, val);
        tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
    }

    private int query(int[] tree, int node, int l, int r, int ql, int qr) {
        if (ql > qr) return 0;
        if (ql <= l && r <= qr) return tree[node];
        int mid = (l + r) / 2, res = 0;
        if (ql <= mid) res = Math.max(res, query(tree, 2 * node, l, mid, ql, qr));
        if (qr > mid) res = Math.max(res, query(tree, 2 * node + 1, mid + 1, r, ql, qr));
        return res;
    }

    private int query(int[] tree, int node, int l, int r, int qr) {
        return query(tree, node, l, r, 0, qr);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q log n)，每次查询/更新线段树
- **空间复杂度**：O(n + q)

## 关键点总结

1. 用有序集合维护障碍物，快速找相邻障碍
2. 线段树维护每个障碍点与其左侧障碍的距离，支持前缀最大值查询
3. 查询时取「x 到左侧最近障碍的距离」与「[0, prev] 内最大间隙」的较大值
