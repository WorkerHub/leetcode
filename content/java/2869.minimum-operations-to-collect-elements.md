## 题目描述

给你正整数数组 nums 和正整数 k，每次操作从末尾删除一个元素，返回使剩余数组包含 1 到 k 所有元素所需的最少操作次数。

## 解题思路

从末尾向前遍历，收集 1~k 范围内的元素，当集合大小等于 k 时停止，操作次数 = `n - 当前下标`。

## Java 代码实现

```java
class Solution {
    public int minOperations(List<Integer> nums, int k) {
        int n = nums.size();
        // 用位掩码记录已收集的元素（1~k 映射到第 0~k-1 位）
        int mask = 0;
        int target = (1 << k) - 1;

        for (int i = n - 1; i >= 0; i--) {
            int x = nums.get(i);
            if (x >= 1 && x <= k) {
                mask |= (1 << (x - 1));
            }
            if (mask == target) {
                return n - i; // 从末尾删除了 n - i 个元素
            }
        }
        return n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 从末尾向前扫描，收集 1~k 范围内的元素
2. 位掩码 O(1) 检查是否收集完全（比 HashSet 更高效）
3. 操作次数 = 从末尾扫描到的位置数 `n - i`
