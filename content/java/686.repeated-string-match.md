## 题目描述

给定字符串 a 和 b，求重复叠加 a 的最小次数使 b 成为子串，不存在返回 -1。

**示例：**
```
输入：a = "abcd", b = "cdabcdab"
输出：3（"abcdabcdabcd" 包含 b）
```

## 解题思路

至少重复 ceil(len(b)/len(a)) 次，最多再多 1 次。尝试两次即可。

## Java 代码实现

```java
class Solution {
    public int repeatedStringMatch(String a, String b) {
        int minRepeat = (b.length() - 1) / a.length() + 1;

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < minRepeat; i++) {
            sb.append(a);
        }

        if (sb.toString().contains(b)) return minRepeat;

        sb.append(a);
        if (sb.toString().contains(b)) return minRepeat + 1;

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n+m) × m)
- **空间复杂度**：O(n × k)，k 为重复次数

## 关键点总结

1. **最少重复次数**：ceil(len(b)/len(a))
2. **最多多重复1次**：处理边界对齐问题
3. **子串检查**：contains 方法
