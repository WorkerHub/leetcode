## 题目描述

给你一个 m×n 的矩阵，元素各不相同。返回所有幸运数：既是所在行最小值，又是所在列最大值的元素。

## 解题思路

预计算每行最小值和每列最大值，遍历矩阵找出同时满足两个条件的元素。由于所有元素各不相同，用值来标识不会产生歧义。时间复杂度 O(m×n)。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> luckyNumbers(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;

        // 预计算每行的最小值
        int[] rowMin = new int[m];
        Arrays.fill(rowMin, Integer.MAX_VALUE);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                rowMin[i] = Math.min(rowMin[i], matrix[i][j]);
            }
        }

        // 预计算每列的最大值
        int[] colMax = new int[n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                colMax[j] = Math.max(colMax[j], matrix[i][j]);
            }
        }

        // 找出既是行最小值又是列最大值的元素
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == rowMin[i] && matrix[i][j] == colMax[j]) {
                    result.add(matrix[i][j]);
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m×n)，三次线性扫描矩阵。
- 空间复杂度：O(m+n)，存储行最小值和列最大值数组。

## 关键点总结

1. 预计算行最小值和列最大值，避免对每个元素重新扫描行列（O(m×n) vs O(m×n×(m+n))）。
2. 矩阵元素各不相同，可直接用值比较，不会出现歧义。
3. 幸运数最多只有 1 个（可以证明若存在两个则产生矛盾）。
