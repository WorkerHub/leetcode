## 题目描述

给你一个 `m x n` 的矩阵 `seats`，矩阵的每个位置要么是 `'.'` 要么是 `'#'` 。

- `'.'` 表示可以坐人的空位；
- `'#'` 表示不可以坐人的损坏座位。

学生可以坐在可用的位置上，但需要遵守以下规则：**不允许两个学生相邻坐在一起（左右相邻、或斜上方相邻）**，具体来说，如果某位置 `(r, c)` 坐了学生，则以下位置不能坐人：
- `(r, c-1)`、`(r, c+1)` — 同行左右邻座
- `(r-1, c-1)`、`(r-1, c+1)` — 上一行的左上和右上座位

返回可以参加考试的最多学生数。

**示例 1：**
```
输入：seats = [
  ["#",".","#","#",".","#"],
  [".","#","#","#","#","."],
  ["#",".","#","#",".","#"]
]
输出：4
```

**示例 2：**
```
输入：seats = [
  [".","#"],
  ["#","#"],
  ["#","."],
  ["#","#"],
  [".","#"]
]
输出：3
```

**示例 3：**
```
输入：seats = [
  ["#",".",".",".","#"],
  [".","#",".","#","."],
  [".",".","#",".","."],
  [".","#",".","#","."],
  ["#",".",".",".","#"]
]
输出：10
```

**提示：**
- `seats` 只包含字符 `'.'` 和字符 `'#'`
- `m == seats.length`
- `n == seats[i].length`
- `1 <= m <= 8`
- `1 <= n <= 8`

## 解题思路

这道题是经典的**状态压缩动态规划**问题。由于每行最多 8 个座位，可以用一个二进制数表示该行的就座状态（第 i 位为 1 表示第 i 列坐了学生）。

**核心思想：**
1. 将每一行的座位状态压缩成一个二进制整数（最多 8 位，即 256 个状态）。
2. 逐行枚举合法的就座方案，并结合上一行的状态转移。

**状态定义：**
- `dp[mask]` = 当前行状态为 `mask` 时，前若干行的最大学生总数。

**合法性检查：**
- 当前行状态 `mask` 合法：
  - `mask & (mask >> 1) == 0`：同行不相邻（没有两个相邻的 1）
  - `(mask & valid) == mask`：只坐在没有损坏的座位上（`valid` 为该行可用位的掩码）
- 与上一行状态 `prev` 合法：
  - `mask & (prev >> 1) == 0`：当前行没有人坐在上一行人的右下方
  - `mask & (prev << 1) == 0`：当前行没有人坐在上一行人的左下方

**时间复杂度分析：** m 行，每行 2^n 个状态，转移也是 2^n，总体 O(m * 4^n)，n<=8 完全可行。

## Java 代码实现

### 方法一：状态压缩 DP（推荐）

```java
import java.util.Arrays;

class Solution {
    public int maxStudents(char[][] seats) {
        int m = seats.length, n = seats[0].length;
        
        // 预处理每行的合法座位掩码（'.' 对应位为 1，'#' 对应位为 0）
        int[] valid = new int[m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (seats[i][j] == '.') {
                    valid[i] |= (1 << j);
                }
            }
        }
        
        // dp[mask] = 当前行状态为 mask 时的最大学生数（-1 表示不可达）
        int[] dp = new int[1 << n];
        Arrays.fill(dp, -1);
        
        // 初始化第 0 行
        for (int mask = 0; mask < (1 << n); mask++) {
            // mask 必须是 valid[0] 的子集，且同行不相邻
            if ((mask & valid[0]) == mask && (mask & (mask >> 1)) == 0) {
                dp[mask] = Integer.bitCount(mask);
            }
        }
        
        // 逐行转移
        for (int i = 1; i < m; i++) {
            int[] newDp = new int[1 << n];
            Arrays.fill(newDp, -1);
            
            for (int cur = 0; cur < (1 << n); cur++) {
                // 当前行状态 cur 必须合法
                if ((cur & valid[i]) != cur) continue;
                if ((cur & (cur >> 1)) != 0) continue;
                
                for (int prev = 0; prev < (1 << n); prev++) {
                    if (dp[prev] < 0) continue;
                    // 行间约束：cur 和 prev 无斜向相邻
                    if ((cur & (prev << 1)) != 0) continue;
                    if ((cur & (prev >> 1)) != 0) continue;
                    
                    int val = dp[prev] + Integer.bitCount(cur);
                    if (val > newDp[cur]) newDp[cur] = val;
                }
            }
            dp = newDp;
        }
        
        int ans = 0;
        for (int v : dp) ans = Math.max(ans, v);
        return ans;
    }
}
```

### 方法二：记忆化递归（自顶向下）

```java
import java.util.Arrays;

class Solution {
    private int[] valid;
    private int[][] memo;
    private int m, n;
    
    public int maxStudents(char[][] seats) {
        m = seats.length;
        n = seats[0].length;
        
        valid = new int[m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (seats[i][j] == '.') valid[i] |= (1 << j);
            }
        }
        
        // memo[row][prevMask]
        memo = new int[m][1 << n];
        for (int[] row : memo) Arrays.fill(row, -1);
        
        return dfs(0, 0);
    }
    
    // 返回从第 row 行开始，上一行状态为 prevMask 时的最大学生数
    private int dfs(int row, int prevMask) {
        if (row == m) return 0;
        if (memo[row][prevMask] != -1) return memo[row][prevMask];
        
        int best = 0;
        for (int cur = 0; cur < (1 << n); cur++) {
            // 只坐可用座位
            if ((cur & valid[row]) != cur) continue;
            // 同行不相邻
            if ((cur & (cur >> 1)) != 0) continue;
            // 与上一行不冲突
            if ((cur & (prevMask << 1)) != 0) continue;
            if ((cur & (prevMask >> 1)) != 0) continue;
            
            int cnt = Integer.bitCount(cur) + dfs(row + 1, cur);
            best = Math.max(best, cnt);
        }
        
        memo[row][prevMask] = best;
        return best;
    }
}
```

## 复杂度分析

**方法一（状态压缩 DP）：**
- 时间复杂度：O(m * 4^n)。m 行，每行枚举当前状态 2^n，每个状态再枚举上一行状态 2^n。n<=8，4^8=65536，m<=8，总计约 52 万次运算。
- 空间复杂度：O(2^n)，只保留上一行 DP 数组。

**方法二（记忆化递归）：**
- 时间复杂度：O(m * 4^n)，与方法一相同。
- 空间复杂度：O(m * 2^n)，记忆化缓存大小。

## 关键点总结

1. **状态压缩**：每行最多 8 位，用二进制整数表示就座状态，枚举 2^n 种可能。
2. **同行合法性**：`mask & (mask >> 1) == 0` 保证没有相邻学生。
3. **行间合法性**：用位移操作检查斜向冲突，`cur & (prev << 1)` 和 `cur & (prev >> 1)`。
4. **子集约束**：就座状态必须是可用座位掩码的子集，即 `(mask & valid) == mask`。
5. **转移顺序**：从第 0 行到第 m-1 行，每行仅依赖上一行，空间可优化为 O(2^n)。

## 易错点

- 位移方向容易搞混：`prev << 1` 表示 prev 的每个位向高位移动，等价于"上一行每个人都整体右移一列"，此时检查 `cur & (prev << 1)` 是在查当前行是否在上一行某人的左下方（从上往下看，左下方斜邻）。
- 损坏座位的掩码处理：一定要用 `(mask & valid[i]) == mask` 而不是 `mask & valid[i] != 0`，否则只要有交集就通过，会包含损坏座位。
- 初始状态 dp 需要设为 -1 来区分"不可达"和"0人就座"两种情况。
