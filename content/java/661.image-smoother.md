## 题目描述

图像平滑器是大小为 `3 x 3` 的过滤器，用于对图像的每个单元格平滑处理。平滑处理计算该单元格自身和其周围八个单元格的平均值（向下取整）。如果一个单元格周围存在的单元格少于九个，则取所有存在的单元格的平均值。

给你一个表示图像灰度的 `m x n` 整数矩阵 `img`，返回对图像的每个单元格平滑处理后的图像。

**示例 1:**

```
输入：img = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[0,0,0],[0,0,0],[0,0,0]]
解释：
对于点 (0,0)：周围有 4 个单元格，平均值 = (1+1+1+0)/4 = 0.75 = 0
对于点 (0,1)：周围有 6 个单元格，平均值 = (1+1+1+1+0+1)/6 = 0.833 = 0
对于点 (1,1)：周围有 9 个单元格，平均值 = (1+1+1+1+0+1+1+1+1)/9 = 0.888 = 0
```

**示例 2:**

```
输入：img = [[100,200,100],[200,50,200],[100,200,100]]
输出：[[137,141,137],[141,138,141],[137,141,137]]
解释：
对于点 (0,0)：(100+200+200+50)/4 = 137.5 = 137
对于点 (0,1)：(100+200+100+200+50+200)/6 = 141.666 = 141
对于点 (1,1)：(100+200+100+200+50+200+100+200+100)/9 = 138.888 = 138
```

**提示:**
- `m == img.length`
- `n == img[i].length`
- `1 <= m, n <= 200`
- `0 <= img[i][j] <= 255`

## 解题思路

这是一道简单的矩阵遍历题，关键是正确处理边界。

### 核心思路

1. **遍历每个单元格**
2. **计算周围 3x3 区域的和与数量**
3. **取平均值（向下取整）**

### 边界处理

对于位置 `(i, j)`，周围的 8 个邻居是：
- `(i-1, j-1)`, `(i-1, j)`, `(i-1, j+1)`
- `(i, j-1)`, `(i, j+1)`
- `(i+1, j-1)`, `(i+1, j)`, `(i+1, j+1)`

需要检查每个邻居是否在矩阵范围内。

## Java 代码实现

### 方法一：直接模拟（推荐）

```java
class Solution {
    public int[][] imageSmoother(int[][] img) {
        int m = img.length, n = img[0].length;
        int[][] result = new int[m][n];

        // 8个方向 + 自己
        int[][] directions = {{-1,-1}, {-1,0}, {-1,1}, {0,-1}, {0,0}, {0,1}, {1,-1}, {1,0}, {1,1}};

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int totalSum = 0;
                int count = 0;

                // 遍历周围的单元格
                for (int[] dir : directions) {
                    int ni = i + dir[0], nj = j + dir[1];
                    // 检查边界
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                        totalSum += img[ni][nj];
                        count++;
                    }
                }

                // 计算平均值（向下取整）
                result[i][j] = totalSum / count;
            }
        }

        return result;
    }
}
```

### 方法二：嵌套循环版本

```java
class Solution {
    public int[][] imageSmoother(int[][] img) {
        int m = img.length, n = img[0].length;
        int[][] result = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int totalSum = 0;
                int count = 0;

                // 遍历 3x3 区域
                for (int x = Math.max(0, i - 1); x <= Math.min(m - 1, i + 1); x++) {
                    for (int y = Math.max(0, j - 1); y <= Math.min(n - 1, j + 1); y++) {
                        totalSum += img[x][y];
                        count++;
                    }
                }

                result[i][j] = totalSum / count;
            }
        }

        return result;
    }
}
```

### 方法三：辅助函数版本

```java
class Solution {
    public int[][] imageSmoother(int[][] img) {
        int m = img.length, n = img[0].length;
        int[][] result = new int[m][n];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[i][j] = getAverage(img, i, j, m, n);
            }
        }

        return result;
    }

    private int getAverage(int[][] img, int i, int j, int m, int n) {
        int totalSum = 0, count = 0;
        for (int x = Math.max(0, i - 1); x <= Math.min(m - 1, i + 1); x++) {
            for (int y = Math.max(0, j - 1); y <= Math.min(n - 1, j + 1); y++) {
                totalSum += img[x][y];
                count++;
            }
        }
        return totalSum / count;
    }
}
```

## 复杂度分析

### 所有方法
- **时间复杂度**：O(m × n)，遍历每个单元格，每个单元格最多检查 9 个邻居
- **空间复杂度**：O(m × n)，存储结果矩阵

## 关键点总结

1. **边界处理**：使用 `Math.max(0, i-1)` 和 `Math.min(m-1, i+1)` 处理边界
2. **向下取整**：Java 整数除法自动向下取整
3. **3x3 区域**：包括自己和周围 8 个邻居
4. **遍历技巧**：可以用方向数组或嵌套循环
5. **结果矩阵**：需要新建矩阵，不能原地修改

## 易错点

1. **边界范围**：
   ```java
   // 错误：可能越界
   for (int x = i - 1; x <= i + 1; x++)
   
   // 正确：限制范围
   for (int x = Math.max(0, i - 1); x <= Math.min(m - 1, i + 1); x++)
   ```

2. **包含自己**：
   ```java
   // 记得包含 (i, j) 自己
   // 8个邻居 + 自己 = 最多9个
   ```

3. **原地修改**：
   ```java
   // 不能直接修改原矩阵
   // 需要创建新矩阵存储结果
   int[][] result = new int[m][n];
   ```

4. **边界上界**：
   ```java
   // Java 的 for 循环上界用 <=，不像 Python 用 range
   for (int x = start; x <= end; x++)
   ```
