## 题目描述

给定有向无环图（DAG），graph[i] 表示节点 i 可以到达的所有节点。返回从节点 0 到节点 n-1 的所有路径。

**示例：**
```
输入：graph = [[1,2],[3],[3],[]]
输出：[[0,1,3],[0,2,3]]
```

## 解题思路

DFS 回溯：从节点 0 出发，遍历所有可能路径，到达 n-1 时记录当前路径。DAG 无需 visited 数组。

## Java 代码实现

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();

    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<Integer> path = new ArrayList<>();
        path.add(0);
        dfs(graph, 0, path);
        return result;
    }

    private void dfs(int[][] graph, int node, List<Integer> path) {
        if (node == graph.length - 1) {
            result.add(new ArrayList<>(path));
            return;
        }
        for (int next : graph[node]) {
            path.add(next);
            dfs(graph, next, path);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × n)，最坏情况路径数指数级
- **空间复杂度**：O(n)，递归栈深度

## 关键点总结

1. **DAG 无环**：不需要 visited 数组
2. **回溯模板**：添加 → 递归 → 移除
3. **深拷贝路径**：添加到结果时需要 new ArrayList<>(path)
