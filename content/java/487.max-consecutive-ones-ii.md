## 题目描述

给定一个二进制数组 nums，如果最多可以翻转一个 0，则返回数组中连续 1 的最大个数。

**示例 1：**
```
输入：nums = [1,0,1,1,0]
输出：4
解释：翻转第一个 0 可以得到最长的连续 1。
     当翻转以后，最大长度为 4。
```

**示例 2：**
```
输入：nums = [1,0,1,1,0,1]
输出：4
解释：翻转第一个 0 或第二个 0 都可以得到最大连续 1 的个数 4。
```

**提示：**
- 1 <= nums.length <= 10^5
- nums[i] 不是 0 就是 1

**进阶：**
如果输入的数字是以无限流的形式逐个给出的，你该如何处理？换句话说，你不能把所有数字都存在内存中，因为内存是有限的。你能否用 O(1) 的空间复杂度解决这个问题？

## 解题思路

这道题是 [485. Max Consecutive Ones](https://leetcode.com/problems/max-consecutive-ones/) 的进阶版，关键是可以翻转一个 0。

### 核心思想

1. **滑动窗口**：
   - 维护一个窗口，窗口内最多有 1 个 0
   - 当窗口内有超过 1 个 0 时，收缩左边界
   - 窗口大小就是可能的最大连续 1 的个数

2. **双指针**：
   - 左指针 left：窗口左边界
   - 右指针 right：窗口右边界
   - 记录窗口内 0 的个数

3. **三种情况**：
   - 遇到 1：扩展窗口
   - 遇到第一个 0：继续扩展（可以翻转）
   - 遇到第二个 0：收缩左边界直到窗口内只有 1 个 0

## Java 代码实现

### 方法一：滑动窗口（推荐）

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 滑动窗口，维护窗口内最多 1 个 0
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int left = 0;
        int maxLen = 0;
        int zeroCount = 0; // 窗口内 0 的个数

        for (int right = 0; right < nums.length; right++) {
            // 右指针扩展
            if (nums[right] == 0) {
                zeroCount++;
            }

            // 如果窗口内超过 1 个 0，收缩左边界
            while (zeroCount > 1) {
                if (nums[left] == 0) {
                    zeroCount--;
                }
                left++;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法二：记录最后一个 0 的位置

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 记录最后一个 0 的位置
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxLen = 0;
        int lastZeroIndex = -1; // 最后一个 0 的位置
        int left = 0;           // 窗口左边界

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                // 遇到 0，左边界移动到上一个 0 的下一个位置
                left = lastZeroIndex + 1;
                // 更新最后一个 0 的位置
                lastZeroIndex = right;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法三：队列记录 0 的位置

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 使用队列记录 0 的位置（支持翻转 k 个 0 的扩展）
        // 时间复杂度：O(n)
        // 空间复杂度：O(k)，这里 k=1
        int maxLen = 0;
        int left = 0;
        Deque<Integer> zeroPositions = new ArrayDeque<>(); // 记录窗口内 0 的位置

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                zeroPositions.addLast(right);
            }

            // 如果窗口内超过 1 个 0
            if (zeroPositions.size() > 1) {
                // 移除最左边的 0
                left = zeroPositions.pollFirst() + 1;
            }

            // 更新最大长度
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

### 方法四：流式处理（进阶要求）

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // O(1) 空间复杂度，适合流式数据处理
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int maxLen = 0;
        // prevLen: 前一段连续 1 的长度（不包括翻转的 0）
        // currLen: 当前段连续 1 的长度（包括翻转的 0）
        int prevLen = 0;
        int currLen = 0;

        for (int num : nums) {
            if (num == 1) {
                currLen++;
            } else {
                // 遇到 0，可以翻转
                // 新的 currLen = prevLen + 1（翻转这个 0）
                // 新的 prevLen = currLen
                prevLen = currLen;
                currLen = prevLen + 1;
            }

            maxLen = Math.max(maxLen, currLen);
        }

        return maxLen;
    }
}
```

### 方法五：简洁的滑动窗口

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        // 最简洁的滑动窗口实现
        // 时间复杂度：O(n)
        // 空间复杂度：O(1)
        int left = 0;
        int zeros = 0;
        int maxLen = 0;

        for (int right = 0; right < nums.length; right++) {
            zeros += (1 - nums[right]); // 如果是 0，则 zeros+1
            if (zeros > 1) {
                zeros -= (1 - nums[left]);
                left++;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

## 复杂度分析

所有方法：
- **时间复杂度**：O(n)
  - 遍历数组一次
  - 每个元素最多被访问两次（右指针和左指针）
  
- **空间复杂度**：
  - 方法一、二、四、五：O(1)
  - 方法三：O(k)，这里 k=1，所以也是 O(1)

## 关键点总结

1. **滑动窗口思想**：维护一个满足条件的窗口
2. **窗口约束**：窗口内最多 1 个 0
3. **左边界移动**：当违反约束时收缩窗口
4. **最大值更新**：每次扩展窗口时更新最大长度
5. **流式处理**：使用有限变量记录关键信息

## 易错点

1. **窗口收缩条件**
   - 当 zeroCount > 1 时才收缩
   - 不是 zeroCount >= 1

2. **左边界更新**
   - 使用 while 循环收缩，不是 if
   - 确保窗口内最多 1 个 0

3. **最后的数组索引**
   - 方法五中，若 nums 为空需要处理（题目保证非空）
   - 注意初始化 maxLen 变量

4. **边界情况**
   - 全 1 数组：应该返回数组长度
   - 全 0 数组：应该返回 1（翻转一个 0）
   - 单个元素：[0] 返回 1，[1] 返回 1

5. **流式处理的状态维护**
   - prevLen 和 currLen 的更新顺序
   - 遇到 0 时的处理逻辑

   - 左指针收缩窗口
   - 更新答案

   - 本题约束：窗口内最多 1 个 0
   - 扩展：最多 k 个 0（题目 1004）

3. **优化空间复杂度**：
   - 从记录所有信息到只记录关键信息
   - 方法四是 O(1) 空间的典范

4. **变种练习**：
   - 如果可以翻转 k 个 0 呢？
   - 如果是删除一个元素呢？
   - 如果是字符串中的字符替换呢？

5. **流式数据处理**：
   - 理解进阶要求的意义
   - 学习如何在有限空间内处理无限数据流
   - 只保存必要的状态信息

6. **代码简洁性**：
   - `zeros += (1 - nums[right])` 是一个技巧
   - 等价于 `if (nums[right] == 0) zeros++;`
