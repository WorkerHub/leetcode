## 题目描述

给定一个字符串 `s`，返回其通过重新排列组合后所有可能的回文字符串，并去除重复的组合。

如果不能形成任何回文排列，则返回一个空列表。

**示例 1：**
```
输入: s = "aabb"
输出: ["abba", "baab"]
```

**示例 2：**
```
输入: s = "abc"
输出: []
```

**提示：**
- `1 <= s.length <= 16`
- `s` 只包含小写英文字母

## 解题思路

这道题是"回文排列 I"的进阶版，不仅要判断能否组成回文，还要生成所有可能的回文排列。

**关键观察：**
1. 回文串的特点：左半部分 + 中心字符（可选）+ 右半部分（左半部分的镜像）
2. 只需要生成左半部分的所有排列，然后镜像即可
3. 如果有奇数次的字符，它必须放在中间

**算法步骤：**

1. **预处理：检查是否能组成回文**
   - 统计字符频率
   - 出现奇数次的字符不能超过 1 个
   
2. **构建左半部分**
   - 所有字符频率除以 2
   - 保存奇数次的字符作为中心

3. **回溯生成排列**
   - 对左半部分的字符进行全排列
   - 每个排列加上中心字符和镜像得到回文串

4. **去重**
   - 使用回溯剪枝避免重复排列

## Java 代码实现

### 方法一：回溯 + 剪枝（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<String> generatePalindromes(String s) {
        // 统计字符频率
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }

        // 检查是否能组成回文，找中心字符
        String center = "";
        List<Character> half = new ArrayList<>();

        for (int i = 0; i < 26; i++) {
            if (count[i] % 2 == 1) {
                if (!center.isEmpty()) {
                    return new ArrayList<>(); // 超过一个奇数次字符，无法组成回文
                }
                center = String.valueOf((char) ('a' + i));
            }
            // 构建左半部分字符列表
            for (int j = 0; j < count[i] / 2; j++) {
                half.add((char) ('a' + i));
            }
        }

        // 回溯生成所有排列
        List<String> result = new ArrayList<>();
        boolean[] used = new boolean[half.size()];
        String finalCenter = center;

        backtrack(half, used, new StringBuilder(), result, finalCenter);

        return result;
    }

    private void backtrack(List<Character> half, boolean[] used,
                           StringBuilder path, List<String> result, String center) {
        if (path.length() == half.size()) {
            // 构造回文：左半部分 + 中心 + 右半部分（镜像）
            String left = path.toString();
            String right = new StringBuilder(left).reverse().toString();
            result.add(left + center + right);
            return;
        }

        for (int i = 0; i < half.size(); i++) {
            // 剪枝：跳过已使用的字符
            if (used[i]) continue;

            // 剪枝：跳过重复字符（关键优化，需要先排序）
            if (i > 0 && half.get(i).equals(half.get(i - 1)) && !used[i - 1]) {
                continue;
            }

            used[i] = true;
            path.append(half.get(i));
            backtrack(half, used, path, result, center);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}
```

### 方法二：使用字符计数的回溯

```java
import java.util.*;

class Solution {
    public List<String> generatePalindromes(String s) {
        // 统计字符频率
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        // 找中心字符和构建左半部分计数
        String center = "";
        Map<Character, Integer> halfCount = new HashMap<>();

        for (Map.Entry<Character, Integer> entry : count.entrySet()) {
            char ch = entry.getKey();
            int freq = entry.getValue();
            if (freq % 2 == 1) {
                if (!center.isEmpty()) {
                    return new ArrayList<>();
                }
                center = String.valueOf(ch);
            }
            if (freq / 2 > 0) {
                halfCount.put(ch, freq / 2);
            }
        }

        // 左半部分总长度
        int totalLen = halfCount.values().stream().mapToInt(Integer::intValue).sum();

        // 回溯
        List<String> result = new ArrayList<>();
        String finalCenter = center;

        backtrack(halfCount, new StringBuilder(), result, finalCenter, totalLen);

        return result;
    }

    private void backtrack(Map<Character, Integer> halfCount, StringBuilder path,
                           List<String> result, String center, int totalLen) {
        if (path.length() == totalLen) {
            String left = path.toString();
            String right = new StringBuilder(left).reverse().toString();
            result.add(left + center + right);
            return;
        }

        for (char ch : halfCount.keySet()) {
            if (halfCount.get(ch) > 0) {
                halfCount.put(ch, halfCount.get(ch) - 1);
                path.append(ch);
                backtrack(halfCount, path, result, center, totalLen);
                path.deleteCharAt(path.length() - 1);
                halfCount.put(ch, halfCount.get(ch) + 1);
            }
        }
    }
}
```

## 复杂度分析

### 方法一、二（回溯）
- **时间复杂度**：O((n/2)!)
  - 生成左半部分的全排列
  - n 是字符串长度，左半部分长度约为 n/2
  - 全排列的时间复杂度是阶乘级别
  
- **空间复杂度**：O(n)
  - 递归栈深度 O(n/2)
  - 存储结果 O(结果数量)

## 图解示例

以 `s = "aabb"` 为例：

```
1. 统计频率:
   a: 2, b: 2
   
2. 检查回文条件:
   奇数次字符: 0 个 ✓
   中心字符: "" (空)
   
3. 构建左半部分:
   a 出现 2 次 → 左半部分取 1 个 a
   b 出现 2 次 → 左半部分取 1 个 b
   half = ['a', 'b']
   
4. 生成左半部分的全排列:
   排列 1: "ab" + "" + "ba" = "abba"
   排列 2: "ba" + "" + "ab" = "baab"
   
5. 结果: ["abba", "baab"]
```

## 关键点总结

1. **回文构造**：左半部分 + 中心 + 右半部分（镜像）
2. **预处理检查**：出现奇数次的字符不能超过 1 个
3. **优化思路**：只需生成左半部分的排列，排序后剪枝避免重复
4. **去重技巧**：排序后，跳过相同且前一个未使用的字符
5. **镜像操作**：Java 中用 `new StringBuilder(left).reverse().toString()` 生成右半部分

## 易错点

1. **忘记排序**：必须先排序再回溯，否则去重剪枝失效
2. **去重条件错误**：
   ```java
   // 正确
   if (i > 0 && half.get(i).equals(half.get(i-1)) && !used[i-1])
       continue;
   
   // 错误：会漏掉一些排列
   if (i > 0 && half.get(i).equals(half.get(i-1)))
       continue;
   ```
3. **中心字符处理**：有奇数次字符时要记得加到中间
4. **频率除以 2**：左半部分的字符数是总频率的一半
5. **StringBuilder 的使用**：Java 中拼接字符串推荐用 StringBuilder
