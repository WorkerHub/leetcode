## 题目描述

给你非负整数数组 `nums`，对每个元素找到其右侧第二个严格大于它的元素，不存在则为 -1。

## 解题思路

双单调栈：`stack1` 存放等待找第一大值的下标，`stack2` 存放已找到第一大值、等待找第二大值的下标。遍历时先用当前值更新 `stack2`（找第二大），再将 `stack1` 中满足条件的元素转移到 `stack2`（找到第一大），最后将当前下标压入 `stack1`。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] secondGreaterElement(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        java.util.Arrays.fill(ans, -1);

        Deque<Integer> stack1 = new ArrayDeque<>(); // 等待第一大值
        Deque<Integer> stack2 = new ArrayDeque<>(); // 等待第二大值

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            // 先处理 stack2：弹出所有值 < x 的元素，x 是它们的第二大值
            Deque<Integer> temp2 = new ArrayDeque<>();
            while (!stack2.isEmpty() && nums[stack2.peek()] < x) {
                ans[stack2.pop()] = x;
            }

            // 将 stack1 中值 < x 的元素转移到 stack2（临时存储保持顺序）
            Deque<Integer> temp = new ArrayDeque<>();
            while (!stack1.isEmpty() && nums[stack1.peek()] < x) {
                temp.push(stack1.pop());
            }
            // temp 中元素逆序压入 stack2 保持单调递减
            while (!temp.isEmpty()) {
                stack2.push(temp.pop());
            }

            stack1.push(i);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多进出各栈一次
- **空间复杂度**：O(n)

## 关键点总结

1. 两个栈分阶段处理：第一阶段找第一大值，第二阶段找第二大值
2. 必须先处理 `stack2` 再处理 `stack1`，避免同一元素被重复计算
3. 从 `stack1` 转移到 `stack2` 时需逆序以保持 `stack2` 单调递减
