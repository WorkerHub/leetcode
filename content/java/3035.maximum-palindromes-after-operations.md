## 题目描述

可以在字符串数组中任意交换字符，求最多能构成多少个回文字符串（长度不变）。

## 解题思路

贪心：统计所有字符的配对数，按字符串长度从小到大分配配对，优先满足短字符串。

## Java 代码实现

```java
class Solution {
    public int maxPalindromesAfterOperations(String[] words) {
        int[] freq = new int[26];
        for (String w : words) {
            for (char c : w.toCharArray()) freq[c - 'a']++;
        }

        int pairs = 0;
        for (int f : freq) pairs += f / 2;

        int[] lengths = new int[words.length];
        for (int i = 0; i < words.length; i++) lengths[i] = words[i].length();
        Arrays.sort(lengths);

        int ans = 0;
        for (int len : lengths) {
            int need = len / 2;
            if (pairs >= need) {
                pairs -= need;
                ans++;
            } else {
                break;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N*L + N logN)
- **空间复杂度**：O(N)

## 关键点总结

1. **字符可自由移动**：只有总频率限制
2. **回文需要len/2对字符**：奇数长度中间字符总能找到
3. **贪心从短到长**：短字符串需要的配对少
