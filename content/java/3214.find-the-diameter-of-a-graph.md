## 题目描述

给你一个无向连通图（共 `n` 个节点），边信息为 `edges[i] = [ui, vi, wi]`，返回图的直径（所有节点对最短路径中的最大值）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long findDiameter(int n, int[][] edges) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        // 两次 Dijkstra：先从节点 0 找最远点，再从最远点确定直径
        long[] dist0 = dijkstra(0, n, graph);
        int far = 0;
        for (int i = 1; i < n; i++) {
            if (dist0[i] > dist0[far]) far = i;
        }
        long[] dist1 = dijkstra(far, n, graph);
        long ans = 0;
        for (long d : dist1) ans = Math.max(ans, d);
        return ans;
    }

    private long[] dijkstra(int start, int n, List<int[]>[] graph) {
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE / 2);
        dist[start] = 0;
        // 优先队列：{距离, 节点}
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, start});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (int[] next : graph[u]) {
                int v = next[0], w = next[1];
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.offer(new long[]{dist[v], v});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)，两次 Dijkstra
- 空间复杂度：O(n + m)

## 关键点总结

1. 图的直径是所有节点对最短路径的最大值
2. 两次 Dijkstra：先找最远点，再从最远点求直径
3. 边权可能较大，距离使用 `long` 防止溢出
