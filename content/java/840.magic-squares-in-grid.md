## 题目描述

给定 row×col 矩阵 grid，计算其中有多少个 3×3 的幻方子矩阵（包含 1-9 且行列对角线和都为 15）。

**示例：**
```
输入：grid = [[4,3,8,4],[9,5,1,9],[2,7,6,2]]
输出：1
```

## 解题思路

枚举所有 3×3 子矩阵，验证是否满足幻方条件：包含 1-9 无重复，所有行列对角线和为 15。

## Java 代码实现

```java
class Solution {
    public int numMagicSquaresInside(int[][] grid) {
        int rows = grid.length, cols = grid[0].length;
        int count = 0;

        for (int i = 0; i <= rows - 3; i++) {
            for (int j = 0; j <= cols - 3; j++) {
                if (isMagic(grid, i, j)) count++;
            }
        }
        return count;
    }

    private boolean isMagic(int[][] grid, int r, int c) {
        // 检查是否包含 1-9
        boolean[] seen = new boolean[10];
        for (int i = r; i < r + 3; i++) {
            for (int j = c; j < c + 3; j++) {
                int val = grid[i][j];
                if (val < 1 || val > 9 || seen[val]) return false;
                seen[val] = true;
            }
        }

        // 检查行、列、对角线和是否为 15
        for (int i = 0; i < 3; i++) {
            if (grid[r + i][c] + grid[r + i][c + 1] + grid[r + i][c + 2] != 15) return false;
            if (grid[r][c + i] + grid[r + 1][c + i] + grid[r + 2][c + i] != 15) return false;
        }
        if (grid[r][c] + grid[r + 1][c + 1] + grid[r + 2][c + 2] != 15) return false;
        if (grid[r][c + 2] + grid[r + 1][c + 1] + grid[r + 2][c] != 15) return false;

        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)

## 关键点总结

1. **幻方条件**：1-9 无重复，和均为 15
2. **枚举窗口**：遍历所有 3×3 位置
3. **提前剪枝**：先检查数值范围再验证和
