## 题目描述

一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start"）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish"）。

问总共有多少条不同的路径？

**示例 1：**
```
输入：m = 3, n = 7
输出：28
```

**示例 2：**
```
输入：m = 3, n = 2
输出：3
解释：从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**提示：**
- `1 <= m, n <= 100`

## 解题思路

**方法对比：**
1. **动态规划**：dp[i][j] = dp[i-1][j] + dp[i][j-1]
2. **组合数学**：C(m+n-2, m-1)

## Java 代码实现

### 方法一：动态规划

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];

        // 初始化第一行和第一列为1
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;

        // 状态转移
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }

        return dp[m-1][n-1];
    }
}
```

### 方法二：空间优化

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        // 初始化第一行全为1
        for (int j = 0; j < n; j++) dp[j] = 1;

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j-1];
            }
        }

        return dp[n-1];
    }
}
```

### 方法三：组合数学

```java
class Solution {
    public int uniquePaths(int m, int n) {
        // 总共需要走 m-1 步向下，n-1 步向右
        // 从 m+n-2 步中选 m-1 步向下
        long result = 1;
        // 计算 C(m+n-2, m-1)
        for (int i = 0; i < m - 1; i++) {
            result = result * (n + i) / (i + 1);
        }
        return (int) result;
    }
}
```

## 复杂度分析

**动态规划：**
- 时间复杂度：O(m × n)
- 空间复杂度：O(n)（优化后）

**组合数学：**
- 时间复杂度：O(m+n)
- 空间复杂度：O(1)

## 关键点总结

1. **状态转移**：当前格子 = 上方 + 左方
2. **边界条件**：第一行和第一列都是1
3. **组合数**：本质是排列组合问题

## 易错点

1. **初始化**：第一行和第一列要初始化为1
2. **索引**：注意从1开始遍历
3. **组合数溢出**：Java中计算组合数注意用 long 防止溢出
