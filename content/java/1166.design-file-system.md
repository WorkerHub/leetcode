## 题目描述

设计文件系统：createPath(path, value) 创建路径并关联值（父路径必须存在，路径不能重复），get(path) 返回关联值。

**示例：**
```
createPath("/leet", 1) → true
createPath("/leet/code", 2) → true
get("/leet/code") → 2
createPath("/c/d", 1) → false（父路径 "/c" 不存在）
```

## 解题思路

哈希表存储路径到值的映射。createPath 时通过 lastIndexOf('/') 找父路径并验证其存在性。

## Java 代码实现

```java
class FileSystem {
    private Map<String, Integer> paths;

    public FileSystem() {
        paths = new HashMap<>();
    }

    public boolean createPath(String path, int value) {
        // 路径已存在
        if (paths.containsKey(path)) return false;

        // 找父路径
        int lastSlash = path.lastIndexOf('/');
        String parent = path.substring(0, lastSlash);

        // 一级路径（parent为空）或父路径存在
        if (parent.isEmpty() || paths.containsKey(parent)) {
            paths.put(path, value);
            return true;
        }
        return false;
    }

    public int get(String path) {
        return paths.getOrDefault(path, -1);
    }
}
```

## 复杂度分析

- **createPath**：O(n)，n 为路径长度
- **get**：O(1)，哈希表查找
- **空间复杂度**：O(总路径数 * 平均路径长度)

## 关键点总结

1. **父路径验证**：lastIndexOf('/') 截取父路径
2. **一级路径特判**：如 "/a"，父路径为空串，直接允许
3. **哈希表存储**：简单高效
4. **重复检查**：containsKey 判断路径是否已存在
