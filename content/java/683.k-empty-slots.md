## 题目描述

n 个位置的花园，bulbs[i]=x 表示第 i+1 天位置 x 开花。找到是否存在某天恰好有 k 个空位夹在两朵花之间，返回天数，否则 -1。

**示例：**
```
输入：bulbs = [1,3,2], k = 1
输出：2（第2天位置1和3之间有1个空位）
```

## 解题思路

滑动窗口：days[i] 记录位置 i 在哪天开花，窗口大小 k+2，检查中间 k 个位置的开花时间是否都晚于两端。

## Java 代码实现

```java
class Solution {
    public int kEmptySlots(int[] bulbs, int k) {
        int n = bulbs.length;
        // days[i] 表示位置 i+1 在第几天开花
        int[] days = new int[n];
        for (int i = 0; i < n; i++) {
            days[bulbs[i] - 1] = i + 1;
        }

        int ans = Integer.MAX_VALUE;
        int left = 0, right = k + 1;

        while (right < n) {
            boolean valid = true;
            for (int i = left + 1; i < right; i++) {
                // 中间位置必须在两端之后开花
                if (days[i] < days[left] || days[i] < days[right]) {
                    left = i;
                    right = i + k + 1;
                    valid = false;
                    break;
                }
            }
            if (valid) {
                ans = Math.min(ans, Math.max(days[left], days[right]));
                left = right;
                right = left + k + 1;
            }
        }

        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个位置最多被访问两次
- **空间复杂度**：O(n)

## 关键点总结

1. **逆向思维**：从"哪天开什么"变成"什么时候开"
2. **滑动窗口**：窗口大小 k+2，检查中间 k 个位置
3. **窗口有效性**：中间位置开花时间必须晚于两端
