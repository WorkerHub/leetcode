## 题目描述

设计待办事项清单，支持添加任务（返回递增 ID）、获取用户所有未完成任务（按截止日期排序）、按标签筛选任务、标记任务完成。

## 解题思路

用 HashMap 存储每个用户的任务列表，任务包含 id、描述、截止日期、标签集合、完成状态；查询时过滤未完成任务后按 (截止日期, id) 排序返回。

## Java 代码实现

```java
import java.util.*;

class TodoList {
    private int nextId = 1;
    // userId -> list of tasks: {id, desc, due, tags, done}
    private Map<Integer, List<int[]>> userTasks = new HashMap<>();
    private Map<Integer, String> taskDesc = new HashMap<>();
    private Map<Integer, Set<String>> taskTags = new HashMap<>();
    private Set<Integer> done = new HashSet<>();

    public int addTask(int userId, String taskDescription, int dueDate, List<String> tags) {
        int id = nextId++;
        userTasks.computeIfAbsent(userId, k -> new ArrayList<>())
                 .add(new int[]{id, dueDate});
        taskDesc.put(id, taskDescription);
        taskTags.put(id, new HashSet<>(tags));
        return id;
    }

    public List<String> getAllTasks(int userId) {
        List<int[]> tasks = userTasks.getOrDefault(userId, Collections.emptyList());
        // 过滤未完成，按 (due, id) 排序
        return tasks.stream()
                .filter(t -> !done.contains(t[0]))
                .sorted((a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0])
                .map(t -> taskDesc.get(t[0]))
                .collect(java.util.stream.Collectors.toList());
    }

    public List<String> getTasksForTag(int userId, String tag) {
        List<int[]> tasks = userTasks.getOrDefault(userId, Collections.emptyList());
        return tasks.stream()
                .filter(t -> !done.contains(t[0]) && taskTags.get(t[0]).contains(tag))
                .sorted((a, b) -> a[1] != b[1] ? a[1] - b[1] : a[0] - b[0])
                .map(t -> taskDesc.get(t[0]))
                .collect(java.util.stream.Collectors.toList());
    }

    public void completeTask(int userId, int taskId) {
        List<int[]> tasks = userTasks.getOrDefault(userId, Collections.emptyList());
        for (int[] t : tasks) {
            if (t[0] == taskId) { done.add(taskId); return; }
        }
    }
}
```

## 复杂度分析

- **addTask**：O(1)
- **getAllTasks / getTasksForTag**：O(m log m)，m 为用户任务数
- **completeTask**：O(m)

## 关键点总结

1. 任务 ID 全局递增，不是每用户单独计数
2. 排序键为 (截止日期, id)，保证截止日期相同时按添加顺序
3. 标签存为 Set，O(1) 查询是否含某标签
