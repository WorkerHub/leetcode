## 题目描述

给你一个二进制数组 `nums`，每次操作可以交换相邻两个元素。返回将所有 `1` 聚合在一起（即所有 `1` 连续排列）所需的最少交换次数。

## 解题思路

设 1 的总数为 k。滑动窗口：找长度为 k 的窗口中 1 最多的位置，最少交换次数 = k - 窗口内 1 的最大数量（即窗口内 0 的最少数量）。

## Java 代码实现

```java
class Solution {
    public int minSwaps(int[] nums) {
        int k = 0;
        for (int v : nums) k += v;
        if (k == 0 || k == nums.length) return 0;

        int n = nums.length;
        // 初始化第一个窗口
        int onesInWindow = 0;
        for (int i = 0; i < k; i++) onesInWindow += nums[i];
        int maxOnes = onesInWindow;

        // 滑动窗口，每次移动一格
        for (int i = k; i < n; i++) {
            onesInWindow += nums[i] - nums[i - k];
            maxOnes = Math.max(maxOnes, onesInWindow);
        }

        // 最少交换 = 窗口内 0 的最少数量
        return k - maxOnes;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 滑动窗口大小固定为 k（总 1 的个数）。
2. 最少交换次数 = k - 窗口内最多 1 的数量（即最少 0 的数量）。
3. 特判 k == 0 或 k == n 时无需交换。
