## 题目描述

用最少数量的正方形地砖铺满 n × m 的地板。返回最少正方形数量。

**示例：**
```
输入：n = 2, m = 3
输出：3（1 块 2×2 + 2 块 1×1）
```

## 解题思路

回溯 + 剪枝：用高度数组记录每列已填充高度。每次找最低位置，尝试放入不同大小的正方形。全局最优值用于剪枝。

## Java 代码实现

```java
class Solution {
    private int n, m;
    private int result;
    
    public int tilingRectangle(int n, int m) {
        this.n = n;
        this.m = m;
        this.result = n * m; // 最坏情况：全 1×1
        
        int[] heights = new int[m]; // 每列的高度
        backtrack(heights, 0);
        return result;
    }
    
    private void backtrack(int[] heights, int count) {
        // 剪枝
        if (count >= result) return;
        
        // 找到最低列
        int minHeight = n, minIdx = -1;
        for (int i = 0; i < m; i++) {
            if (heights[i] < minHeight) {
                minHeight = heights[i];
                minIdx = i;
            }
        }
        
        // 全部填满
        if (minHeight == n) {
            result = Math.min(result, count);
            return;
        }
        
        // 计算可以放的最大正方形边长
        int maxSide = 1;
        while (minIdx + maxSide <= m && minHeight + maxSide <= n) {
            // 检查从 minIdx 到 minIdx+maxSide-1 的列高度是否都为 minHeight
            boolean valid = true;
            for (int i = minIdx; i < minIdx + maxSide; i++) {
                if (heights[i] != minHeight) { valid = false; break; }
            }
            if (!valid) break;
            maxSide++;
        }
        maxSide--;
        
        // 从大到小尝试放正方形
        for (int side = maxSide; side >= 1; side--) {
            // 放置正方形
            for (int i = minIdx; i < minIdx + side; i++) {
                heights[i] += side;
            }
            backtrack(heights, count + 1);
            // 回溯
            for (int i = minIdx; i < minIdx + side; i++) {
                heights[i] -= side;
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：指数级（NP 难问题），通过剪枝在小规模下可行
- **空间复杂度**：O(m)，高度数组 + 递归栈

## 关键点总结

1. **NP 难问题**：没有多项式算法，只能搜索+剪枝
2. **高度数组**：记录每列填充高度，找最低点放正方形
3. **从大到小尝试**：先放大正方形，更快找到最优解用于剪枝
4. **剪枝**：当前块数 ≥ 已知最优时直接返回
