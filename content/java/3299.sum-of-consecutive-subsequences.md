## 题目描述

给你整数数组 `nums`，若子序列中相邻元素差恰好为 1（+1 或 -1），则称为**连续子序列**。返回所有连续子序列的元素和之总和，对 `10^9+7` 取模。

## 解题思路

DP：`cnt[v]` = 以值 v 结尾的连续子序列数，`sumDp[v]` = 这些子序列的元素总和。新元素 v 可接在以 v-1 或 v+1 结尾的子序列后面，每次更新贡献 `newSum` 并累加到答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int getSum(int[] nums) {
        final int MOD = 1_000_000_007;
        Map<Integer, Long> cnt = new HashMap<>();
        Map<Integer, Long> sumDp = new HashMap<>();
        long total = 0;

        for (int v : nums) {
            long newCnt = 1;
            long newSum = v;
            // 接在以 v-1 结尾的子序列后面
            long cntPrev = cnt.getOrDefault(v - 1, 0L);
            long sumPrev = sumDp.getOrDefault(v - 1, 0L);
            newCnt = (newCnt + cntPrev) % MOD;
            newSum = (newSum + sumPrev + (long) v * cntPrev) % MOD;
            // 接在以 v+1 结尾的子序列后面
            long cntNext = cnt.getOrDefault(v + 1, 0L);
            long sumNext = sumDp.getOrDefault(v + 1, 0L);
            newCnt = (newCnt + cntNext) % MOD;
            newSum = (newSum + sumNext + (long) v * cntNext) % MOD;

            cnt.merge(v, newCnt, (a, b) -> (a + b) % MOD);
            sumDp.merge(v, newSum, (a, b) -> (a + b) % MOD);
            total = (total + newSum) % MOD;
        }
        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(max_val)，HashMap 存储各值的 cnt 和 sumDp

## 关键点总结

1. `cnt[v]` 和 `sumDp[v]` 分别记录以值 v 结尾的子序列数量和总和
2. 新元素 v 可接在 v-1 或 v+1 结尾的子序列后，同时自身单独成一个子序列
3. 与 3284（子数组）不同，这里是子序列，使用 HashMap 按值而非位置索引
