## 题目描述

给你一个字符串 `s`，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

**示例 1：**
```
输入：s = "bbbab"
输出：4
解释：一个可能的最长回文子序列为 "bbbb"。
```

**示例 2：**
```
输入：s = "cbbd"
输出：2
解释：一个可能的最长回文子序列为 "bb"。
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

## 解题思路

这是一道经典的**区间 DP** 问题。

### 核心思想：
`dp[i][j]` = s[i..j] 的最长回文子序列长度

**状态转移：**
- 如果 `s[i] == s[j]`：`dp[i][j] = dp[i+1][j-1] + 2`
- 否则：`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        // 区间 DP
        // 时间复杂度：O(n^2)，空间复杂度：O(n^2)
        int n = s.length();
        int[][] dp = new int[n][n];

        // 单个字符都是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }

        // 从长度 2 开始枚举
        for (int length = 2; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;

                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

### 方法二：记忆化DFS

```java
import java.util.*;

class Solution {
    private int[][] memo;
    private String s;

    public int longestPalindromeSubseq(String s) {
        // 记忆化递归
        // 时间复杂度：O(n^2)，空间复杂度：O(n^2)
        this.s = s;
        int n = s.length();
        memo = new int[n][n];
        for (int[] row : memo) Arrays.fill(row, -1);

        return dfs(0, n - 1);
    }

    private int dfs(int i, int j) {
        if (i > j) return 0;
        if (i == j) return 1;
        if (memo[i][j] != -1) return memo[i][j];

        int result;
        if (s.charAt(i) == s.charAt(j)) {
            result = dfs(i + 1, j - 1) + 2;
        } else {
            result = Math.max(dfs(i + 1, j), dfs(i, j - 1));
        }

        memo[i][j] = result;
        return result;
    }
}
```

### 方法三：与最长公共子序列关联

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        // 转化为 LCS 问题：s 和 reverse(s) 的最长公共子序列
        // 时间复杂度：O(n^2)，空间复杂度：O(n^2)
        String reversed = new StringBuilder(s).reverse().toString();
        return longestCommonSubsequence(s, reversed);
    }

    private int longestCommonSubsequence(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：从小区间到大区间
2. **状态转移**：两端相等加 2，否则取左右最大
3. **初始化**：单字符长度为 1
4. **遍历顺序**：按区间长度递增

## 易错点

1. **遍历顺序**：要按区间长度枚举
2. **边界条件**：i > j 返回 0
3. **状态定义**：是子序列不是子串
4. **长度为 2 时**：dp[i+1][j-1] 中 i+1 > j-1 时值为 0，需要确保初始化正确
