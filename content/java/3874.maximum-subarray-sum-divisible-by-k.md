## 题目描述

给你一个整数数组 `nums` 和正整数 `k`，返回和能被 `k` 整除的子数组中的最大和，不存在则返回 0。

## 解题思路

前缀和 + 哈希表：子数组 `[l, r]` 的和被 k 整除，等价于 `prefix[r+1] % k == prefix[l] % k`。对每个余数保存最小前缀和（使 `prefix[r+1] - min_prefix` 最大），从而在 O(n) 内求出最大可整除子数组和。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long maxSubarraySumDivisibleByK(int[] nums, int k) {
        // best[r] = 具有余数 r 的最小前缀和（使子数组和最大）
        Map<Integer, Long> best = new HashMap<>();
        best.put(0, 0L); // 空前缀，余数为 0，前缀和为 0

        long prefix = 0;
        long ans = 0;

        for (int v : nums) {
            prefix += v;
            // Java 中负数取模可能为负，调整为非负余数
            int rem = (int) ((prefix % k + k) % k);
            if (best.containsKey(rem)) {
                // 子数组和 = prefix - 最小前缀和，取最大
                ans = Math.max(ans, prefix - best.get(rem));
            }
            // 保存具有余数 rem 的最小前缀和
            best.merge(rem, prefix, Math::min);
        }
        return Math.max(ans, 0);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(k)，哈希表存储 k 个不同余数

## 关键点总结

1. 两个前缀和余数相同，其差（子数组和）必被 k 整除。
2. 要最大化子数组和，对每个余数应保存最小前缀和（不是最大）。
3. Java 中负数取模结果可能为负，需用 `(prefix % k + k) % k` 调整为非负。
