## 题目描述

给定一棵n节点无向树和每个节点的金币数(0或1)，选任一节点出发收集所有金币，每条边最多走两次，求最少移动次数。

## 解题思路

拓扑排序剪枝：先删无金币叶子，再删两轮叶子（收集范围为2），剩余边数×2即答案。

## Java 代码实现

```java
class Solution {
    public int collectTheCoins(int[] coins, int[][] edges) {
        int n = coins.length;
        Set<Integer>[] graph = new HashSet[n];
        for (int i = 0; i < n; i++) graph[i] = new HashSet<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        // 第一步：删除无金币的叶子节点
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (graph[i].size() == 1 && coins[i] == 0) queue.offer(i);
        }
        while (!queue.isEmpty()) {
            int node = queue.poll();
            if (graph[node].isEmpty()) continue;
            int neighbor = graph[node].iterator().next();
            graph[node].remove(neighbor);
            graph[neighbor].remove(node);
            if (graph[neighbor].size() == 1 && coins[neighbor] == 0) {
                queue.offer(neighbor);
            }
        }

        // 第二步：再删两轮叶子
        for (int round = 0; round < 2; round++) {
            List<Integer> leaves = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                if (graph[i].size() == 1) leaves.add(i);
            }
            for (int leaf : leaves) {
                if (graph[leaf].isEmpty()) continue;
                int neighbor = graph[leaf].iterator().next();
                graph[leaf].remove(neighbor);
                graph[neighbor].remove(leaf);
            }
        }

        // 统计剩余边数
        int edgeCount = 0;
        for (int i = 0; i < n; i++) edgeCount += graph[i].size();
        return edgeCount; // 每条边计了两次，edgeCount/2*2 = edgeCount
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **删无金币叶子**：不影响收集结果
2. **再删两轮叶子**：收集范围为2步
3. **剩余边×2**：每条边来回各一次
