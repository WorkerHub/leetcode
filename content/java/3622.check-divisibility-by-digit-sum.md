## 题目描述

给定正整数 `n`，若 `n` 能被其各位数字之和整除则返回 `true`，否则返回 `false`。

## Java 代码实现

```java
class Solution {
    public boolean isDivisible(int n) {
        int digitSum = 0;
        int temp = n;
        while (temp > 0) {
            digitSum += temp % 10;
            temp /= 10;
        }
        return n % digitSum == 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log n)，计算各位之和
- 空间复杂度：O(1)

## 关键点总结

1. 哈沙德数（Harshad Number）：能被各位之和整除的数
2. `n >= 1` 时各位之和至少为 1，无需担心除以 0
