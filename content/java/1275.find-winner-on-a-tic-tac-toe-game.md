## 题目描述

3×3 井字棋，A 先手 B 后手，给定 moves 数组，返回结果："A"、"B"、"Draw" 或 "Pending"。

**示例：**
```
输入：moves = [[0,0],[2,0],[1,1],[2,1],[2,2]]
输出："A"
```

## 解题思路

用计数数组记录每行、每列、两条对角线的得分。A 加 1，B 减 1，绝对值达到 3 即获胜。

## Java 代码实现

```java
class Solution {
    public String tictactoe(int[][] moves) {
        // rows[0-2], cols[0-2], diag, antiDiag
        int[] rows = new int[3], cols = new int[3];
        int diag = 0, antiDiag = 0;
        
        for (int i = 0; i < moves.length; i++) {
            int r = moves[i][0], c = moves[i][1];
            int val = (i % 2 == 0) ? 1 : -1; // A=1, B=-1
            
            rows[r] += val;
            cols[c] += val;
            if (r == c) diag += val;
            if (r + c == 2) antiDiag += val;
            
            if (Math.abs(rows[r]) == 3 || Math.abs(cols[c]) == 3 ||
                Math.abs(diag) == 3 || Math.abs(antiDiag) == 3) {
                return val == 1 ? "A" : "B";
            }
        }
        return moves.length == 9 ? "Draw" : "Pending";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 moves 长度（最多 9）
- **空间复杂度**：O(1)

## 关键点总结

1. **计数法**：A 加 1，B 减 1，绝对值 3 即胜
2. **四条线**：3 行 + 3 列 + 2 对角线
3. **结果判断**：有人赢返回名字，满了返回 Draw，否则 Pending
