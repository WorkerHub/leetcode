## 题目描述

假设有 `n` 台超级洗衣机放在同一排上。开始时，每台洗衣机内可能有一定量的衣服，也可能是空的。

在每一步操作中，你可以选择任意 `m` (1 <= m <= n) 台洗衣机，与此同时将每台洗衣机的一件衣服送到相邻的一台洗衣机。

给定一个整数数组 `machines` 代表从左至右每台洗衣机中的衣物数量，请返回使所有洗衣机中衣物的数量相等所需的最少步数。如果不能使每台洗衣机中衣物的数量相等，则返回 `-1`。

**示例 1：**
```
输入：machines = [1,0,5]
输出：3
解释：
第一步：1     0 <-- 5    =>    1     1     4
第二步：1 <-- 1 <-- 4    =>    2     1     3    
第三步：2     1 <-- 3    =>    2     2     2   
```

**示例 2：**
```
输入：machines = [0,3,0]
输出：2
解释：
第一步：0 <-- 3     0    =>    1     2     0    
第二步：1     2 --> 0    =>    1     1     1    
```

**示例 3：**
```
输入：machines = [0,2,0]
输出：-1
解释：不可能使所有三个洗衣机同时剩下相同数量的衣物。
```

**提示：**
- `n == machines.length`
- `1 <= n <= 10^4`
- `0 <= machines[i] <= 10^5`

## 解题思路

这是一道非常难的贪心题。

### 核心观察：
1. 总衣服数必须能被机器数整除
2. 答案由两个因素决定：
   - 单台机器需要出去的衣服数
   - 经过某台机器的流量

### 算法：
计算每台机器的"负载"（需要平衡的衣服数），答案是所有机器负载的最大值。

## Java 代码实现

### 方法一：贪心算法⭐

```java
class Solution {
    public int findMinMoves(int[] machines) {
        // 贪心算法
        // 时间复杂度：O(n)，空间复杂度：O(1)
        int total = 0;
        for (int m : machines) total += m;
        int n = machines.length;

        // 无法平均分配
        if (total % n != 0) return -1;

        int avg = total / n;
        int result = 0;
        int toLeft = 0;  // 左边需要的衣服数（负数表示左边需要向右传）

        for (int machine : machines) {
            // 当前机器与平均值的差
            int diff = machine - avg;
            // 累计左边需要的衣服
            toLeft += diff;
            // 更新结果：
            // abs(toLeft) 表示经过当前位置的流量
            // diff 表示当前机器需要发出的衣服数（只有正值有意义）
            result = Math.max(result, Math.max(Math.abs(toLeft), diff));
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **平均值检查**：总数不能整除返回 -1
2. **贪心策略**：每台机器的最大负载
3. **流量计算**：累计左边的需求
4. **两个约束**：流量约束和单机约束

## 易错点

1. **整除性检查**：必须先判断
2. **方向问题**：要同时考虑左右
3. **绝对值**：流量要取绝对值
4. **只取 diff 正值**：单机约束只看超出平均的部分
