## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

**示例 1：**
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**
```
输入：s = ""
输出：0
```

**提示：**
- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

## 解题思路

这道题有多种解法：

**方法对比：**
1. **栈**：记录索引，计算长度
2. **动态规划**：dp[i] 表示以 i 结尾的最长有效长度
3. **双向扫描**：从左到右、从右到左两次扫描

## Java 代码实现

### 方法一：栈（推荐）

```java
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);  // 初始化一个-1作为基准
        int maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {  // ')'
                stack.pop();
                if (stack.isEmpty()) {
                    // 栈空了，说明当前 ')' 无法匹配
                    stack.push(i);  // 将当前位置作为新基准
                } else {
                    // 计算当前有效长度
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        
        return maxLen;
    }
}
```

### 方法二：动态规划

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        if (n == 0) return 0;
        
        // dp[i] 表示以 i 结尾的最长有效括号长度
        int[] dp = new int[n];
        int maxLen = 0;
        
        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == ')') {
                if (s.charAt(i - 1) == '(') {
                    // ...()
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (i - dp[i - 1] > 0 && s.charAt(i - dp[i - 1] - 1) == '(') {
                    // ...))
                    dp[i] = dp[i - 1] + 2 + (i - dp[i - 1] >= 2 ? dp[i - dp[i - 1] - 2] : 0);
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }
        
        return maxLen;
    }
}
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **栈的应用**：记录索引而非字符
2. **动态规划**：根据前一个位置的结果推导
3. **连续性**：必须是连续的有效括号

## 易错点

1. **初始值**：栈初始化时压入 -1（Java 用 `stack.push(-1)`）
2. **边界处理**：空字符串返回 0
3. **Java 字符比较**：用 `s.charAt(i) == '('`，不要用字符串 equals
