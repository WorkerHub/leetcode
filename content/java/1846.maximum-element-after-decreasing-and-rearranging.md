## 题目描述

正整数数组可重排和减小元素，要求arr[0]==1且相邻差≤1，求最大可能元素。

## 解题思路

排序后贪心：第一个设为1，之后每个元素为 min(arr[i], arr[i-1]+1)，最后一个即答案。

## Java 代码实现

```java
class Solution {
    public int maximumElementAfterDecrementingAndRearranging(int[] arr) {
        Arrays.sort(arr);
        arr[0] = 1;
        for (int i = 1; i < arr.length; i++) {
            arr[i] = Math.min(arr[i], arr[i - 1] + 1);
        }
        return arr[arr.length - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后贪心**：每个元素最大为前一个+1
2. **只能减小不能增大**：取 min(原值, 前一个+1)
3. **最大值上界为N**：N个数从1开始每次最多+1
