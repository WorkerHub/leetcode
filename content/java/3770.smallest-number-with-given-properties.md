## 题目描述

给定整数 `n` 和 `t`，找最小的正整数 `x`，使得 `x >= n` 且 `x` 的各位数字之和等于 `t`。

## 解题思路

贪心逐位构造：枚举"第一个偏离 n 的位置"，在该位加 1，后续位从右往左填 9 使数字和恰好为 `t`。若当前位数内无解，构造 `len+1` 位的最小满足数。

## Java 代码实现

```java
class Solution {
    public long smallestNumber(long n, int t) {
        char[] s = Long.toString(n).toCharArray();
        int L = s.length;

        // 在 L 位数内尝试找答案
        long res = tryFind(s, t, L);
        if (res != -1) return res;

        // 尝试 L+1 位（最多两轮）
        for (int len = L + 1; len <= L + 2; len++) {
            if (t >= 1 && t <= 9 * len) {
                char[] r = new char[len];
                java.util.Arrays.fill(r, '0');
                int rem = t;
                // 从右往左填 9
                for (int i = len - 1; i >= 1 && rem > 0; i--) {
                    int d = Math.min(9, rem);
                    r[i] = (char) ('0' + d);
                    rem -= d;
                }
                if (rem >= 1 && rem <= 9) {
                    r[0] = (char) ('0' + rem);
                    return Long.parseLong(new String(r));
                }
            }
        }
        return -1;
    }

    private long tryFind(char[] s, int t, int L) {
        int prefixSum = 0;
        for (int i = 0; i < L; i++) {
            int cur = s[i] - '0';
            // 在位置 i 尝试比当前值大的数字（偏离紧约束）
            for (int newD = cur + 1; newD <= 9; newD++) {
                int rem = t - prefixSum - newD;
                int slots = L - i - 1;
                if (rem < 0) break;          // 数字和已超 t
                if (rem > 9 * slots) continue; // 后续位不够填
                // 构造结果：后续位从右往左填 9
                char[] r = new char[L];
                for (int k = 0; k < i; k++) r[k] = s[k];
                r[i] = (char) ('0' + newD);
                java.util.Arrays.fill(r, i + 1, L, '0');
                int fill = rem;
                for (int k = L - 1; k > i && fill > 0; k--) {
                    int d = Math.min(9, fill);
                    r[k] = (char) ('0' + d);
                    fill -= d;
                }
                if (fill == 0) return Long.parseLong(new String(r));
            }
            prefixSum += cur;
        }
        // n 本身的数字和等于 t
        return prefixSum == t ? Long.parseLong(new String(s)) : -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * L)，L 为位数（最多 10）
- 空间复杂度：O(L)

## 关键点总结

1. 枚举"偏离位置"，之前保持与 n 相同，该位加 1，之后贪心填最小值
2. 后续位从右往左填 9 以最小化高位、最大化低位
3. 若 L 位内无解，构造 L+1 位最小满足数（首位尽量小，低位填 9）
