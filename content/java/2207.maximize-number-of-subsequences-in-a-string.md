## 题目描述

在字符串任意位置插入一个字符，使pattern(长度2)作为子序列出现次数最大化。

## 解题思路

贪心：插入pattern[0]到最前（与所有pattern[1]配对）或插入pattern[1]到最后（与所有pattern[0]配对），取增量较大者加上原有子序列数。

## Java 代码实现

```java
class Solution {
    public long maximumSubsequenceCount(String text, String pattern) {
        char p0 = pattern.charAt(0), p1 = pattern.charAt(1);
        long countP0 = 0, countP1 = 0;
        long subseq = 0;
        
        for (char ch : text.toCharArray()) {
            // 先统计p1配对（避免p0==p1时重复计数）
            if (ch == p1) {
                subseq += countP0;
                countP1++;
            }
            if (ch == p0) {
                countP0++;
            }
        }
        
        // 插入p0到最前增加countP1个，插入p1到最后增加countP0个
        return subseq + Math.max(countP0, countP1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **两种贪心策略**：p0插最前或p1插最后，取最大增量
2. **一遍遍历计算原有子序列数**：遇p1时加上已有的p0计数
3. **p0==p1时**：先处理p1再处理p0，避免同一字符自配对
