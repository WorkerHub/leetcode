## 题目描述

走廊上有座位'S'和植物'P'，安装隔板使每段恰好有两把椅子，求不同安装方式数（模10^9+7）。

## 解题思路

记录所有'S'位置，每两个为一组，隔板放在第2k个和第2k+1个座位之间。间隙位置数相乘即为总方案数。

## Java 代码实现

```java
class Solution {
    public int numberOfWays(String corridor) {
        int MOD = 1_000_000_007;
        // 收集所有座位位置
        List<Integer> seats = new ArrayList<>();
        for (int i = 0; i < corridor.length(); i++) {
            if (corridor.charAt(i) == 'S') {
                seats.add(i);
            }
        }
        
        int n = seats.size();
        // 座位数为奇数或0，无法分割
        if (n == 0 || n % 2 != 0) return 0;
        
        long ans = 1;
        // 每对座位之间的间隙
        for (int i = 1; i < n / 2; i++) {
            // 第2i-1和第2i个座位之间的间隙数
            long gap = seats.get(2 * i) - seats.get(2 * i - 1);
            ans = ans * gap % MOD;
        }
        
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **总椅子数必须为偶数**：否则无法分割
2. **隔板位置固定在组间**：第2k和第2k+1把椅子之间
3. **乘法原理**：各间隙的位置数相乘
