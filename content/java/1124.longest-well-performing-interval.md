## 题目描述

给定工作时间数组 hours，工作时间 >8 为"劳累天"。找最长的连续时间段使得劳累天数严格大于不劳累天数。

**示例：**
```
输入：hours = [9,9,6,0,6,6,9]
输出：3
解释：[9,9,6] 中劳累 2 天 > 不劳累 1 天
```

## 解题思路

前缀和 + 哈希表：将 >8 标记为 +1，<=8 标记为 -1。前缀和 >0 则从头到当前都满足；否则找 prefix_sum-1 第一次出现的位置。

## Java 代码实现

```java
class Solution {
    public int longestWPI(int[] hours) {
        int n = hours.length;
        int prefixSum = 0;
        int maxLen = 0;
        // 记录每个前缀和第一次出现的位置
        Map<Integer, Integer> firstOccurrence = new HashMap<>();

        for (int i = 0; i < n; i++) {
            prefixSum += (hours[i] > 8) ? 1 : -1;

            if (prefixSum > 0) {
                // 从 0 到 i 整段都满足
                maxLen = i + 1;
            } else {
                // 找 prefixSum-1 第一次出现的位置
                if (firstOccurrence.containsKey(prefixSum - 1)) {
                    maxLen = Math.max(maxLen, i - firstOccurrence.get(prefixSum - 1));
                }
            }

            // 只记录第一次出现
            firstOccurrence.putIfAbsent(prefixSum, i);
        }

        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **+1/-1 转化**：将问题转为找和 >0 的最长子数组
2. **前缀和 >0**：整段从头到当前都满足
3. **找 prefix-1**：差为 1 意味着子数组和恰好为 1（>0）
4. **只记录首次出现**：保证找到的是最左位置，子数组最长
