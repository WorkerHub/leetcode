## 题目描述

给定整数数组nums和整数k，返回长度为k的子序列的最大偶数和，不存在返回-1。

## 解题思路

贪心取最大k个数，若和为偶数直接返回。若为奇数，尝试两种替换：换出已选最小奇数换入未选最大偶数，或换出已选最小偶数换入未选最大奇数，取最优。

## Java 代码实现

```java
class Solution {
    public long largestEvenSum(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        
        // 取最大的k个数
        long total = 0;
        for (int i = n - k; i < n; i++) {
            total += nums[i];
        }
        
        if (total % 2 == 0) return total;
        
        // 需要调整：换出selected中最小奇/偶数，换入rest中最大偶/奇数
        long best = -1;
        
        // 方案A：换出selected中最小奇数，换入rest中最大偶数
        int minOddSel = -1;
        for (int i = n - k; i < n; i++) {
            if (nums[i] % 2 == 1) { minOddSel = nums[i]; break; }
        }
        int maxEvenRest = -1;
        for (int i = n - k - 1; i >= 0; i--) {
            if (nums[i] % 2 == 0) { maxEvenRest = nums[i]; break; }
        }
        if (minOddSel != -1 && maxEvenRest != -1) {
            best = Math.max(best, total - minOddSel + maxEvenRest);
        }
        
        // 方案B：换出selected中最小偶数，换入rest中最大奇数
        int minEvenSel = -1;
        for (int i = n - k; i < n; i++) {
            if (nums[i] % 2 == 0) { minEvenSel = nums[i]; break; }
        }
        int maxOddRest = -1;
        for (int i = n - k - 1; i >= 0; i--) {
            if (nums[i] % 2 == 1) { maxOddRest = nums[i]; break; }
        }
        if (minEvenSel != -1 && maxOddRest != -1) {
            best = Math.max(best, total - minEvenSel + maxOddRest);
        }
        
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心取最大k个**：排序后取末尾k个元素
2. **奇数和调整**：两种替换方案取最优
3. **使用long**：避免求和溢出
