## 题目描述

给你两个等长正整数数组 `nums` 和 `target`，每次操作可将 `nums` 的一个连续子数组所有元素加 1 或减 1，返回使 `nums` 等于 `target` 的最少操作次数。

## Java 代码实现

```java
class Solution {
    public long minimumOperations(int[] nums, int[] target) {
        int n = nums.length;
        // 转化为差分数组 d[i] = target[i] - nums[i]
        // 最少操作次数 = 对 d 做区间加减 1 使其全为 0 的次数
        // = abs(d[0]) + sum(max(0, d[i]-d[i-1])) for i=1..n-1
        // 等价于：统计 d 从 0 开始的正向上升量

        long ans = 0;
        long prev = 0;
        for (int i = 0; i < n; i++) {
            long d = (long) target[i] - nums[i];
            if (d > 0 && d > prev) {
                // d 为正且比前一个更大，需要额外正向操作
                ans += d - Math.max(0, prev);
            } else if (d < 0 && d < prev) {
                // d 为负且比前一个更小，需要额外负向操作
                ans += Math.abs(d) - Math.abs(Math.min(0, prev));
            }
            prev = d;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 转化为差分数组 d = target - nums，问题变为最少操作使 d 全零
2. 操作次数 = d 数组中"新增正向增量"与"新增负向增量"之和
3. 贪心：相邻同方向增量可复用之前的操作
