## 题目描述

给定 `2n` 个元素（每个值恰好出现两次），排成一排后目标是每对相邻位置 `(2i, 2i+1)` 的元素值相同，求达成目标所需的最少交换次数。

## Java 代码实现

```java
class Solution {
    public int minSwaps(int[] nums) {
        int[] arr = nums.clone();
        int n = arr.length;
        int swaps = 0;

        for (int i = 0; i < n; i += 2) {
            if (arr[i] != arr[i + 1]) {
                // 在 i+2 之后找与 arr[i] 相同的元素
                int j = i + 2;
                while (j < n && arr[j] != arr[i]) j++;
                // 将 arr[j] 换到 i+1 处
                int temp = arr[i + 1];
                arr[i + 1] = arr[j];
                arr[j] = temp;
                swaps++;
            }
        }

        return swaps;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n²) 最坏情况；可用哈希表优化到 O(n)
- 空间复杂度：O(n)，数组副本

## 关键点总结

1. 贪心：遍历每对位置，若不匹配则找配对元素换到正确位置
2. 每次交换使当前位置正确匹配，不影响之前已处理的对
3. 修改数组副本，不影响原数组
