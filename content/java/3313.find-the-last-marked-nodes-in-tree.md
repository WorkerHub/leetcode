## 题目描述

给你一棵 n 个节点的树，对于每个起始节点 s，返回距离 s 最远且距离为偶数的节点（相同距离取编号最大）。

## 解题思路

两次 BFS 找树的直径端点 u 和 v，预计算所有节点到 u 和 v 的距离。对每个节点 s，答案是 u 或 v 中距离为偶数且更远的那个（利用树直径端点是任意节点最远候选节点的性质）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] lastMarkedNodes(int[][] edges) {
        int n = edges.length + 1;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) { graph.get(e[0]).add(e[1]); graph.get(e[1]).add(e[0]); }

        // 第一次 BFS 找直径一端 u（从偶数距离最远的节点出发）
        int[] d0 = bfs(0, graph, n);
        int u = farthestEven(d0, n);
        // 第二次 BFS 预计算所有节点到 u 的距离，找直径另一端 v
        int[] du = bfs(u, graph, n);
        int v = farthestEven(du, n);
        // 第三次 BFS 预计算所有节点到 v 的距离
        int[] dv = bfs(v, graph, n);

        int[] answer = new int[n];
        for (int s = 0; s < n; s++) {
            int distU = du[s], distV = dv[s];
            int best = -1, bestDist = -1;
            if (distU % 2 == 0) { best = u; bestDist = distU; }
            if (distV % 2 == 0 && (bestDist < distV || (bestDist == distV && v > best))) {
                best = v; bestDist = distV;
            }
            if (best == -1) best = (distU >= distV ? u : v); // 退化情况
            answer[s] = best;
        }
        return answer;
    }

    private int[] bfs(int start, List<List<Integer>> graph, int n) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        dist[start] = 0;
        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        while (!q.isEmpty()) {
            int node = q.poll();
            for (int nb : graph.get(node)) {
                if (dist[nb] == -1) { dist[nb] = dist[node] + 1; q.offer(nb); }
            }
        }
        return dist;
    }

    private int farthestEven(int[] dist, int n) {
        int best = 0;
        for (int i = 1; i < n; i++) {
            if (dist[i] % 2 == 0 && (dist[i] > dist[best] || (dist[i] == dist[best] && i > best))) {
                best = i;
            }
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，三次 BFS
- 空间复杂度：O(n)

## 关键点总结

1. 树中任意节点的最远节点一定是直径端点之一，对偶数距离限制同样成立
2. 三次 BFS：找直径端点 u、v，预计算所有节点到 u、v 的距离
3. 相同距离取编号最大的节点
