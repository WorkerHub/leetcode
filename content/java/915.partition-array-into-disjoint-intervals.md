## 题目描述

将数组划分为两个连续非空子数组 left 和 right，使 left 每个元素 ≤ right 每个元素，返回 left 的最小长度。

**示例：**
```
输入：nums = [5,0,3,8,6]
输出：3（left=[5,0,3], right=[8,6]）
```

## 解题思路

一次遍历：维护左部分最大值和全局最大值。遇到小于左部分最大值的元素时扩展左部分。

## Java 代码实现

```java
class Solution {
    public int partitionDisjoint(int[] nums) {
        int leftMax = nums[0];
        int maxSoFar = nums[0];
        int partition = 0;

        for (int i = 1; i < nums.length; i++) {
            maxSoFar = Math.max(maxSoFar, nums[i]);
            if (nums[i] < leftMax) {
                // 必须扩展左边部分
                partition = i;
                leftMax = maxSoFar;
            }
        }

        return partition + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **动态分割**：遇到比左最大值小的元素时扩展
2. **两个最大值**：leftMax 和 maxSoFar 分开维护
3. **贪心**：第一个满足条件的分割点
