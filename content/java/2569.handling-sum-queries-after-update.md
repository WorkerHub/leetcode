## 题目描述

给你二进制数组 `nums1`、整数数组 `nums2` 和查询数组 `queries`，支持三种操作：翻转 nums1 的区间、将 nums2[i] 加上 p*sum(nums1)、查询 nums2 的总和。

## 解题思路

用懒线段树维护 nums1，支持区间翻转和查询区间 1 的个数；用变量 extra 记录累加到 nums2 的增量，查询时返回 sum2 + extra。

## Java 代码实现

```java
class Solution {
    int[] cnt1, lazy;
    int n;

    void build(int[] nums1, int node, int l, int r) {
        if (l == r) { cnt1[node] = nums1[l]; return; }
        int mid = (l + r) / 2;
        build(nums1, 2 * node, l, mid);
        build(nums1, 2 * node + 1, mid + 1, r);
        cnt1[node] = cnt1[2 * node] + cnt1[2 * node + 1];
    }

    void pushDown(int node, int l, int r) {
        if (lazy[node] == 1) {
            int mid = (l + r) / 2;
            // 翻转左子节点
            cnt1[2 * node] = (mid - l + 1) - cnt1[2 * node];
            lazy[2 * node] ^= 1;
            // 翻转右子节点
            cnt1[2 * node + 1] = (r - mid) - cnt1[2 * node + 1];
            lazy[2 * node + 1] ^= 1;
            lazy[node] = 0;
        }
    }

    void flip(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) {
            cnt1[node] = (r - l + 1) - cnt1[node];
            lazy[node] ^= 1;
            return;
        }
        pushDown(node, l, r);
        int mid = (l + r) / 2;
        if (ql <= mid) flip(2 * node, l, mid, ql, qr);
        if (qr > mid) flip(2 * node + 1, mid + 1, r, ql, qr);
        cnt1[node] = cnt1[2 * node] + cnt1[2 * node + 1];
    }

    public long[] handleQuery(int[] nums1, int[] nums2, int[][] queries) {
        n = nums1.length;
        cnt1 = new int[4 * n];
        lazy = new int[4 * n];
        build(nums1, 1, 0, n - 1);

        long sum2 = 0;
        for (int x : nums2) sum2 += x;
        long extra = 0;

        java.util.List<Long> res = new java.util.ArrayList<>();
        for (int[] q : queries) {
            if (q[0] == 1) {
                // 翻转 nums1[l..r]
                flip(1, 0, n - 1, q[1], q[2]);
            } else if (q[0] == 2) {
                // nums2 所有元素加 p * sum(nums1)
                extra += (long) q[1] * cnt1[1];
            } else {
                // 查询 sum(nums2)
                res.add(sum2 + extra);
            }
        }
        return res.stream().mapToLong(Long::longValue).toArray();
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 线段树懒标记实现区间翻转：`cnt = len - cnt`，异或传播标记
2. nums2 的修改用累加变量 extra 跟踪，避免 O(n) 更新
3. 查询直接返回 `sum2 + extra`
