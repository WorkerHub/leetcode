## 题目描述

给你一棵二叉树的根节点 `root` ，返回所有**重复的子树**。

对于同一类的重复子树，你只需要返回其中任意**一棵**的根结点即可。

如果两棵树具有**相同的结构**和**相同的结点值**，则认为二者是重复的。

**示例 1:**

```
        1
       / \
      2   3
     /   / \
    4   2   4
       /
      4

输入：root = [1,2,3,4,null,2,4,null,null,4]
输出：[[2,4],[4]]
```

**示例 2:**

```
        2
       / \
      1   1

输入：root = [2,1,1]
输出：[[1]]
```

**示例 3:**

```
        2
       / \
      2   2
     /   /
    3   3

输入：root = [2,2,2,3,null,3,null]
输出：[[2,3],[3]]
```

**提示:**
- 树中的结点数在 `[1, 5000]` 范围内
- `-200 <= Node.val <= 200`

## 解题思路

这道题的核心是如何**识别重复的子树**。需要解决两个关键问题：

1. **如何表示一棵树**？使用序列化方法将树转换为字符串
2. **如何检测重复**？使用哈希表记录每种子树出现的次数

**算法流程：**

1. **后序遍历**：从叶子节点开始向上构建
2. **序列化子树**：将每个子树序列化为唯一的字符串表示
3. **哈希计数**：用哈希表记录每种子树出现的次数
4. **收集结果**：当某种子树第二次出现时，将其根节点加入结果

**序列化方案：**
- 使用后序遍历：`左子树序列化 + 右子树序列化 + 当前节点值`
- 空节点用特殊符号（如 `#`）表示
- 使用分隔符（如 `,`）分隔节点

## Java 代码实现

### 方法一：后序遍历 + 序列化（推荐）

```java
import java.util.*;

class Solution {
    // 哈希表：序列化字符串 -> 出现次数
    Map<String, Integer> subtreeCount = new HashMap<>();
    // 存储结果
    List<TreeNode> result = new ArrayList<>();

    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {
        serialize(root);
        return result;
    }

    private String serialize(TreeNode node) {
        // 空节点用 "#" 表示
        if (node == null) return "#";

        // 后序遍历：左 -> 右 -> 根
        String leftSerial = serialize(node.left);
        String rightSerial = serialize(node.right);

        // 构建当前子树的序列化字符串
        String currentSerial = leftSerial + "," + rightSerial + "," + node.val;

        // 记录当前子树出现次数
        subtreeCount.put(currentSerial, subtreeCount.getOrDefault(currentSerial, 0) + 1);

        // 如果这是第二次出现，加入结果（只在第二次出现时添加，避免重复）
        if (subtreeCount.get(currentSerial) == 2) {
            result.add(node);
        }

        return currentSerial;
    }
}
```

### 方法二：使用 ID 优化（空间优化）

```java
import java.util.*;

class Solution {
    // 子树结构 -> ID 映射
    Map<String, Integer> treeToId = new HashMap<>();
    // ID -> 出现次数
    Map<Integer, Integer> idCount = new HashMap<>();
    List<TreeNode> result = new ArrayList<>();

    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {
        serialize(root);
        return result;
    }

    private int serialize(TreeNode node) {
        // 空节点返回 ID 0
        if (node == null) return 0;

        // 后序遍历
        int leftId = serialize(node.left);
        int rightId = serialize(node.right);

        // 构建当前子树的唯一标识
        String currentKey = node.val + "," + leftId + "," + rightId;

        // 获取或分配 ID
        int currentId = treeToId.computeIfAbsent(currentKey, k -> treeToId.size() + 1);

        idCount.put(currentId, idCount.getOrDefault(currentId, 0) + 1);

        if (idCount.get(currentId) == 2) {
            result.add(node);
        }

        return currentId;
    }
}
```

### 方法三：简洁版本

```java
import java.util.*;

class Solution {
    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {
        List<TreeNode> result = new ArrayList<>();
        Map<String, Integer> count = new HashMap<>();
        dfs(root, count, result);
        return result;
    }

    private String dfs(TreeNode node, Map<String, Integer> count, List<TreeNode> result) {
        if (node == null) return "#";

        // 后序遍历序列化
        String serial = dfs(node.left, count, result) + ","
                      + dfs(node.right, count, result) + ","
                      + node.val;

        count.put(serial, count.getOrDefault(serial, 0) + 1);

        // 第二次出现时加入结果
        if (count.get(serial) == 2) {
            result.add(node);
        }

        return serial;
    }
}
```

## 复杂度分析

### 方法一：后序遍历 + 序列化
- **时间复杂度**：O(n²)
  - 遍历所有节点：O(n)
  - 每个节点的序列化可能需要 O(n)（字符串拼接）
  - 总体：O(n²)
- **空间复杂度**：O(n²)
  - 哈希表存储所有子树的序列化字符串
  - 递归调用栈：O(h)，h 为树高

### 方法二：使用 ID 优化
- **时间复杂度**：O(n)，每个节点只访问一次
- **空间复杂度**：O(n)，存储 ID 映射

```
原始树：

序列化过程（后序遍历）：

节点 4（左下）：  "#,#,4"

节点 4（右下左）："#,#,4"  ← 重复！
节点 2（右中）：  "#,#,4,#,2"  ← 重复！
节点 4（右下右）："#,#,4"
节点 3：         "#,#,4,#,2,#,#,4,3"
节点 1：         整棵树

重复的子树：
1. "#,#,4" - 节点值为 4 的叶子节点
2. "#,#,4,#,2" - 以 2 为根，左子节点为 4 的子树
```

## 关键点总结

1. **后序遍历**：必须从叶子节点开始向上构建，确保子树信息完整
2. **序列化唯一性**：序列化字符串要能唯一表示一棵树的结构和值
3. **去重技巧**：只在第二次出现时加入结果，避免重复添加
4. **数据结构选择**：字符串、元组、ID 各有优劣
5. **空节点处理**：必须标记空节点，否则不同结构可能产生相同序列化

## 易错点

1. **忘记处理空节点**：必须标记空节点
2. **重复添加结果**：只在 count == 2 时添加，不是 > 1
3. **序列化顺序错误**：后序遍历更可靠
4. **缺少分隔符**：使用 "," 分隔，防止歧义
5. **返回值类型**：题目要求返回节点列表，不是序列化字符串
