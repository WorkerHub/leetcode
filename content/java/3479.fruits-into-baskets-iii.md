## 题目描述

给你整数数组 `fruits` 和二维数组 `baskets`（`baskets[i] = [容量, 类型]`），每个水果放入最左边类型匹配且有剩余容量的篮子，无法放置则跳过。返回无法放置的水果数量。

## 解题思路

按类型分组篮子，用 TreeMap 维护每种类型的篮子（按下标排序，只保留有剩余容量的）。对每个水果取该类型下标最小的篮子，减少其容量；容量为 0 时从集合中移除。Java 中用 TreeSet 存有剩余容量的篮子下标，O(log m) 查找最小下标。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int numUnplacedFruits(int[] fruits, int[][] baskets) {
        int m = baskets.length;
        int[] cap = new int[m];
        Map<Integer, TreeSet<Integer>> typeAvail = new HashMap<>();

        for (int i = 0; i < m; i++) {
            cap[i] = baskets[i][0];
            int type = baskets[i][1];
            if (cap[i] > 0) {
                typeAvail.computeIfAbsent(type, x -> new TreeSet<>()).add(i);
            }
        }

        int unplaced = 0;
        for (int f : fruits) {
            TreeSet<Integer> avail = typeAvail.get(f);
            if (avail == null || avail.isEmpty()) {
                unplaced++;
            } else {
                int idx = avail.first(); // 下标最小的可用篮子
                cap[idx]--;
                if (cap[idx] == 0) {
                    avail.remove(idx);
                }
            }
        }

        return unplaced;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log m)
- 空间复杂度：O(m)

## 关键点总结

1. 按类型分组篮子，每种类型用 TreeSet 维护有剩余容量的篮子下标
2. TreeSet.first() 直接获取最小下标（最左边），O(log m)
3. 容量耗尽时从 TreeSet 中移除，保证集合有效性
