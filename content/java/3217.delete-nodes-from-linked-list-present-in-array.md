## 题目描述

给你整数数组 `nums` 和链表头节点 `head`，删除链表中所有值存在于 `nums` 中的节点，返回修改后的链表头节点。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public ListNode modifiedList(int[] nums, ListNode head) {
        // 将 nums 转为集合，O(1) 查询
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);

        // 虚拟头节点，方便处理头节点被删除的情况
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy, curr = head;

        while (curr != null) {
            if (set.contains(curr.val)) {
                // 跳过该节点
                prev.next = curr.next;
            } else {
                prev = curr;
            }
            curr = curr.next;
        }
        return dummy.next;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为链表长度，m 为 nums 长度
- 空间复杂度：O(m)，哈希集合

## 关键点总结

1. 先将 nums 转为 HashSet，查询时间 O(1)
2. 虚拟头节点处理头节点被删除的情况
3. 维护前驱节点 prev，只有保留节点时才移动 prev
