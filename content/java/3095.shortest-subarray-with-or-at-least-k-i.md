## 题目描述

给你非负整数数组 nums 和整数 k，返回按位或 >= k 的最短子数组长度，不存在则返回 -1。

## 解题思路

数据范围小（n <= 50），暴力枚举所有子数组的按位或，找最短满足条件的。

## Java 代码实现

```java
class Solution {
    public int minimumSubarrayLength(int[] nums, int k) {
        int n = nums.length, ans = n + 1;
        for (int i = 0; i < n; i++) {
            int curOr = 0;
            for (int j = i; j < n; j++) {
                curOr |= nums[j];
                if (curOr >= k) {
                    ans = Math.min(ans, j - i + 1);
                    break; // 以 i 开头的最短子数组已找到
                }
            }
        }
        return ans <= n ? ans : -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)，n <= 50 完全可行
- **空间复杂度**：O(1)

## 关键点总结

1. 按位或是单调的（子数组扩大，OR 只增不减），找到满足条件的即可 break
2. 枚举所有起点，找以该起点开头的最短满足子数组
3. 最终若 ans > n 则不存在，返回 -1
