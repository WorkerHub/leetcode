## 题目描述

统计[1,num]范围内各位数字之和为偶数的正整数数目。

## 解题思路

数学规律：若num各位数字和为偶数则答案=num/2，否则答案=(num-1)/2。

## Java 代码实现

```java
class Solution {
    public int countEven(int num) {
        int digitSum = 0;
        int temp = num;
        while (temp > 0) {
            digitSum += temp % 10;
            temp /= 10;
        }
        if (digitSum % 2 == 0) {
            return num / 2;
        } else {
            return (num - 1) / 2;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log num)
- **空间复杂度**：O(1)

## 关键点总结

1. **数学规律**：约一半的数各位和为偶数
2. **判断num本身的各位和**：决定是num/2还是(num-1)/2
3. **O(1)计算**：无需遍历所有数
