## 题目描述

交易无效的条件：金额 > 1000，或同名不同城市且时间差 <= 60 分钟。返回所有无效交易。

**示例：**
```
输入：["alice,20,800,mtv","alice,50,100,beijing"]
输出：["alice,20,800,mtv","alice,50,100,beijing"]（时间差30<=60，不同城市）
```

## 解题思路

解析交易信息，按名字分组。对每笔交易检查金额和同名不同城市时间差两个条件。

## Java 代码实现

```java
class Solution {
    public List<String> invalidTransactions(String[] transactions) {
        int n = transactions.length;
        String[] names = new String[n];
        int[] times = new int[n];
        int[] amounts = new int[n];
        String[] cities = new String[n];

        // 解析交易
        for (int i = 0; i < n; i++) {
            String[] parts = transactions[i].split(",");
            names[i] = parts[0];
            times[i] = Integer.parseInt(parts[1]);
            amounts[i] = Integer.parseInt(parts[2]);
            cities[i] = parts[3];
        }

        Set<Integer> invalid = new HashSet<>();
        for (int i = 0; i < n; i++) {
            // 条件1：金额超过1000
            if (amounts[i] > 1000) invalid.add(i);

            // 条件2：同名不同城市时间差<=60
            for (int j = i + 1; j < n; j++) {
                if (names[i].equals(names[j])
                    && !cities[i].equals(cities[j])
                    && Math.abs(times[i] - times[j]) <= 60) {
                    invalid.add(i);
                    invalid.add(j);
                }
            }
        }

        List<String> result = new ArrayList<>();
        for (int idx : invalid) result.add(transactions[idx]);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **两个条件**：金额>1000 或 同名不同城市时间差<=60
2. **双重标记**：条件2 满足时两笔交易都无效
3. **集合去重**：用索引集合避免重复
4. **字符串比较**：Java 用 equals()
