## 题目描述

给定字符串 s，返回不同非空子序列的个数，结果对 10^9+7 取模。

**示例：**
```
输入：s = "aba"
输出：6（"a", "b", "ab", "ba", "aa", "aba"）
```

## 解题思路

dp[c] 表示以字符 c 结尾的不同子序列数。遇到字符 c 时，dp[c] = 所有 dp 之和 + 1（单个字符）。总答案为所有 dp 之和。

## Java 代码实现

```java
class Solution {
    public int distinctSubseqII(String s) {
        long MOD = 1_000_000_007;
        long[] dp = new long[26]; // dp[i] = 以字符 i 结尾的子序列数

        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            long total = 0;
            for (long x : dp) total += x;
            // 以当前字符结尾的子序列数 = 已有子序列总数 + 1
            dp[idx] = (total + 1) % MOD;
        }

        long result = 0;
        for (long x : dp) result += x;
        return (int) (result % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 26) = O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **按末尾字符分类**：避免重复计数
2. **覆盖更新**：相同字符直接覆盖，自动去重
3. **+1 表示单字符**：每次新增单字符本身
