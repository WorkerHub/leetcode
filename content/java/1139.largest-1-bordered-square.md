## 题目描述

给定 0/1 矩阵 grid，找出边界全由 1 组成的最大正方形，返回其面积。内部可以是任意值。

**示例：**
```
输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：9
```

## 解题思路

预处理每个位置向右 (right) 和向下 (down) 连续 1 的个数。从大到小枚举边长，验证四个角点的 right/down 值是否 >= 边长。

## Java 代码实现

```java
class Solution {
    public int largest1BorderedSquare(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // right[i][j]：从 (i,j) 向右连续 1 的个数
        // down[i][j]：从 (i,j) 向下连续 1 的个数
        int[][] right = new int[m][n];
        int[][] down = new int[m][n];

        // 从右下角逆向计算
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (grid[i][j] == 1) {
                    right[i][j] = (j == n - 1) ? 1 : right[i][j + 1] + 1;
                    down[i][j] = (i == m - 1) ? 1 : down[i + 1][j] + 1;
                }
            }
        }

        // 从大到小枚举边长
        for (int len = Math.min(m, n); len >= 1; len--) {
            for (int i = 0; i <= m - len; i++) {
                for (int j = 0; j <= n - len; j++) {
                    // 检查四个角点
                    if (right[i][j] >= len &&
                        down[i][j] >= len &&
                        right[i + len - 1][j] >= len &&
                        down[i][j + len - 1] >= len) {
                        return len * len;
                    }
                }
            }
        }

        return 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n × min(m,n))
- **空间复杂度**：O(m × n)

## 关键点总结

1. **前缀和预处理**：right/down 数组 O(1) 判断边是否全为 1
2. **四角验证**：左上角的 right/down + 右上角的 down + 左下角的 right
3. **从大到小枚举**：第一个满足条件的即为最大，提前返回
4. **返回面积**：`len * len`，不是边长
