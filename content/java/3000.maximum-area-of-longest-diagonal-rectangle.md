## 题目描述

给你二维整数数组 `dimensions`，返回对角线最长的矩形面积，对角线相同时返回面积最大的。

## 解题思路

遍历所有矩形，用对角线的平方（l²+w²）比较大小（避免浮点运算），记录最长对角线对应的最大面积。

## Java 代码实现

```java
class Solution {
    public int areaOfMaxDiagonal(int[][] dimensions) {
        int maxDiagSq = 0, ans = 0;
        for (int[] d : dimensions) {
            int diagSq = d[0] * d[0] + d[1] * d[1]; // 对角线平方（避免浮点）
            int area = d[0] * d[1];
            if (diagSq > maxDiagSq) {
                maxDiagSq = diagSq;
                ans = area;
            } else if (diagSq == maxDiagSq) {
                ans = Math.max(ans, area); // 对角线相同取最大面积
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 用 l²+w² 比较对角线长度，避免浮点精度问题
2. 对角线相同时取面积最大的矩形
3. 一次遍历维护最优解
