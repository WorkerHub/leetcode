## 题目描述

给你数字字符串 `num1`、`num2` 和整数 `min_sum`、`max_sum`，统计 `[num1, num2]` 中各位数字之和在 `[min_sum, max_sum]` 范围内的整数数目（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    private int minSum, maxSum;
    private String num;
    private int[][] memo;
    private static final int MOD = 1_000_000_007;

    public int count(String num1, String num2, int min_sum, int max_sum) {
        this.minSum = min_sum;
        this.maxSum = max_sum;
        // 答案 = f(num2) - f(num1) + (num1 本身是否满足)
        long ans = (solve(num2) - solve(num1) + MOD) % MOD;
        int s1 = 0;
        for (char c : num1.toCharArray()) s1 += c - '0';
        if (min_sum <= s1 && s1 <= max_sum) ans = (ans + 1) % MOD;
        return (int) ans;
    }

    private long solve(String n) {
        this.num = n;
        memo = new int[n.length()][401];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dfs(0, 0, true);
    }

    private long dfs(int pos, int sum, boolean tight) {
        if (sum > maxSum) return 0;
        if (pos == num.length()) return sum >= minSum ? 1 : 0;
        // tight 状态不缓存（路径唯一），只缓存非 tight 状态
        if (!tight && memo[pos][sum] != -1) return memo[pos][sum];
        int limit = tight ? (num.charAt(pos) - '0') : 9;
        long res = 0;
        for (int d = 0; d <= limit; d++) {
            res = (res + dfs(pos + 1, sum + d, tight && d == limit)) % MOD;
        }
        if (!tight) memo[pos][sum] = (int) res;
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(L * max_sum * 10)，L 为数字位数（最多 23）
- 空间复杂度：O(L * max_sum)

## 关键点总结

1. 数位 DP 模板：`tight` 标志是否仍受上界约束
2. 利用区间差值：答案 = f(num2) - f(num1 - 1)
3. 大数字符串的 `-1` 操作复杂，改为 f(num2) - f(num1) + (num1 是否满足)
