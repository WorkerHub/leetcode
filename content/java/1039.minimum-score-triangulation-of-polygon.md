## 题目描述

给定凸多边形顶点值数组 values，将多边形剖分为三角形，每个三角形的值为其三个顶点值之积，求所有三角形值之和的最小值。

**示例：**
```
输入：values = [3,7,4,5]
输出：144
```

## 解题思路

区间 DP（类似矩阵链乘法）。dp[i][j] 表示顶点 i 到 j 形成的多边形的最小剖分分数。固定边 (i,j)，枚举中间顶点 k。

## Java 代码实现

```java
class Solution {
    public int minScoreTriangulation(int[] values) {
        int n = values.length;
        int[][] dp = new int[n][n];

        // 按区间长度从小到大遍历
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;

                // 枚举中间顶点 k
                for (int k = i + 1; k < j; k++) {
                    int score = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j];
                    dp[i][j] = Math.min(dp[i][j], score);
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **区间 DP**：固定一条边，枚举第三个顶点分割子问题
2. **遍历顺序**：按区间长度从小到大，保证子问题已计算
3. **边界条件**：区间长度 < 3 时分数为 0
