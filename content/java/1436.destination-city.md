## 题目描述

给你一份旅游线路图，该线路图中的旅行路线规则如下：

- 每个城市最多出发一次。
- 每个城市最多到达一次。
- 除了目的地城市，所有城市都是某一旅行路线的起点。

给你一个数组 `paths`，其中 `paths[i] = [cityAi, cityBi]` 表示从城市 `cityAi` 出发前往城市 `cityBi` 的路线。

请你找出并返回旅途的**终点城市**，即没有出发路线的那个城市。

**示例 1：**
```
输入：paths = [["London","New York"],["New York","Lima"],["Lima","Sao Paulo"]]
输出："Sao Paulo"
解释：
London    -> New York
New York  -> Lima
Lima      -> Sao Paulo
"Sao Paulo" 没有出发路线，是终点。
```

**示例 2：**
```
输入：paths = [["B","C"],["D","B"],["C","A"]]
输出："A"
```

**示例 3：**
```
输入：paths = [["A","Z"]]
输出："Z"
```

**提示：**
- `1 <= paths.length <= 100`
- `paths[i].length == 2`
- `1 <= cityAi.length, cityBi.length <= 10`
- `cityAi != cityBi`
- 所有路线的起点互不相同。
- 题目保证有且只有一个终点城市。

## 解题思路

**思路：哈希集合**

终点城市的特征：它**不是**任何路线的起点（出发城市）。

**算法：**
1. 将所有起点城市收集到一个集合 `starts`。
2. 遍历所有终点城市，找到不在 `starts` 中的那个。
3. 题目保证唯一答案，返回该城市。

这里用集合而不是列表，是因为查找操作 O(1)（列表 O(n)）。

## Java 代码实现

### 方法一：哈希集合（推荐）

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public String destCity(List<List<String>> paths) {
        // 收集所有起点城市
        Set<String> starts = new HashSet<>();
        for (List<String> path : paths) {
            starts.add(path.get(0));
        }

        // 找到不是起点的终点城市
        for (List<String> path : paths) {
            if (!starts.contains(path.get(1))) {
                return path.get(1);
            }
        }
        return "";  // 题目保证一定有答案，此行不会执行到
    }
}
```

### 方法二：集合差运算

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public String destCity(List<List<String>> paths) {
        // 起点集合
        Set<String> starts = new HashSet<>();
        // 终点集合
        Set<String> ends = new HashSet<>();

        for (List<String> path : paths) {
            starts.add(path.get(0));
            ends.add(path.get(1));
        }

        // 终点集合中不在起点集合里的城市即为答案
        ends.removeAll(starts);
        return ends.iterator().next();
    }
}
```

### 方法三：统计出度（直观版）

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

class Solution {
    public String destCity(List<List<String>> paths) {
        // 统计每个城市作为"起点"的次数（出度）
        Map<String, Integer> outDegree = new HashMap<>();
        Set<String> allCities = new HashSet<>();

        for (List<String> path : paths) {
            String src = path.get(0);
            String dst = path.get(1);
            outDegree.merge(src, 1, Integer::sum);
            allCities.add(src);
            allCities.add(dst);
        }

        // 出度为 0 的城市是终点
        for (String city : allCities) {
            if (!outDegree.containsKey(city)) {
                return city;
            }
        }
        return "";
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，n 为路径数，遍历一到两次。
- **空间复杂度：** O(n)，存储起点集合。

## 图解示例

```
paths = [["London","New York"],["New York","Lima"],["Lima","Sao Paulo"]]

起点集合 starts = {"London", "New York", "Lima"}

遍历终点：
  "New York"   in starts -> 跳过
  "Lima"       in starts -> 跳过
  "Sao Paulo"  NOT in starts -> 返回 "Sao Paulo"
```

## 关键点总结

1. 终点城市 = 不是任何路线起点的城市。
2. 集合的 `contains()` 操作时间复杂度 O(1)，比列表的 `contains()` 快得多。
3. Java 中 `Set.removeAll(otherSet)` 实现集合差运算，非常简洁。
4. 题目保证唯一答案，不需要处理多个结果的情况。

## 易错点

- 用列表而非集合存储起点，导致查找效率降低（虽然数据量小不影响结果）。
- 误以为终点是出现次数最少的城市（不对，只有唯一出现在终点列中且不在起点列的才是）。
