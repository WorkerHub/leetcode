## 题目描述

每轮相邻两元素按新下标奇偶取min或max，反复直到剩一个元素。

## 解题思路

模拟：每轮生成新数组，新下标为偶数取min，奇数取max，直到长度为1。

## Java 代码实现

```java
class Solution {
    public int minMaxGame(int[] nums) {
        while (nums.length > 1) {
            int[] newNums = new int[nums.length / 2];
            for (int i = 0; i < nums.length; i += 2) {
                int idx = i / 2;
                if (idx % 2 == 0) {
                    newNums[idx] = Math.min(nums[i], nums[i + 1]);
                } else {
                    newNums[idx] = Math.max(nums[i], nums[i + 1]);
                }
            }
            nums = newNums;
        }
        return nums[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **新下标的奇偶性**：idx=i/2，判断idx%2
2. **每轮长度减半**：log N轮后结束
3. **总操作O(N)**：等比数列求和
