## 题目描述

设计游程编码（RLE）迭代器。encoding[i] 表示 encoding[i+1] 重复的次数。next(n) 消耗 n 个元素并返回最后一个。

**示例：**
```
输入：encoding = [3,8,0,9,2,5]，next(2) → 8，next(1) → 8，next(1) → 5
```

## 解题思路

维护当前段的索引和已消耗数量，next 时逐段消耗直到满足 n 个。

## Java 代码实现

```java
class RLEIterator {
    private int[] encoding;
    private int index;
    private long used; // 用 long 防止溢出

    public RLEIterator(int[] encoding) {
        this.encoding = encoding;
        this.index = 0;
        this.used = 0;
    }

    public int next(int n) {
        while (index < encoding.length) {
            long remaining = encoding[index] - used;
            if (n <= remaining) {
                used += n;
                return encoding[index + 1];
            } else {
                n -= remaining;
                index += 2;
                used = 0;
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：next 均摊 O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **游程编码**：[count, value] 成对存储
2. **状态维护**：index 和 used 追踪当前位置
3. **跨段消耗**：一次 next 可能跨越多个段
