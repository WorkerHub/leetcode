## 题目描述

给定非递减排序数组 nums 和整数 target，判断 target 是否为主要元素（出现次数 > n/2）。

**示例：**
```
输入：nums = [2,4,5,5,5,5,5,6,6], target = 5
输出：true（5 出现 5 次 > 9/2）
```

## 解题思路

二分查找 target 第一次出现的位置 left，若 `nums[left + n/2] == target` 则为主要元素（因为从首次出现跨 n/2 位仍是 target，说明出现 > n/2 次）。

## Java 代码实现

```java
class Solution {
    public boolean isMajorityElement(int[] nums, int target) {
        int n = nums.length;
        // 二分查找 target 第一次出现的位置
        int left = lowerBound(nums, target);

        // 检查 target 是否存在且跨越 n/2
        return left + n / 2 < n && nums[left + n / 2] == target;
    }

    private int lowerBound(int[] nums, int target) {
        int lo = 0, hi = nums.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (nums[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **利用有序性**：二分查找首次出现位置
2. **跨越检查**：`nums[left + n/2] == target` 即出现 > n/2 次
3. **边界检查**：`left + n/2 < n` 防止越界
4. **严格大于**：> n/2，不是 >= n/2
