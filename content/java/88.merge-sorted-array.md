## 题目描述

给你两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你合并 `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0`，应忽略。`nums2` 的长度为 `n`。

**示例 1：**
```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6]。
合并结果是 [1,2,2,3,5,6]，其中斜体加粗标注的为 nums1 中的元素。
```

**示例 2：**
```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 []。
合并结果是 [1]。
```

**示例 3：**
```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组分别是 [] 和 [1]。
合并结果是 [1]。
注意，因为 m = 0，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。
```

**提示：**
- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

**进阶：**
- 你可以设计实现一个时间复杂度为 O(m + n) 的算法解决此问题吗？

## 解题思路

这道题的关键在于原地修改 `nums1`，而不能使用额外的空间来存储合并结果。

**核心思想：从后向前双指针**

为什么从后向前？
- 如果从前向后合并，会覆盖 `nums1` 中还未处理的元素
- 从后向前合并，`nums1` 的后半部分都是空位（0），可以直接填充
- 这样避免了额外的空间使用

**算法流程：**
1. 设置三个指针：
   - `p1 = m - 1`：指向 `nums1` 中有效元素的最后一个
   - `p2 = n - 1`：指向 `nums2` 的最后一个元素
   - `p = m + n - 1`：指向 `nums1` 的最后一个位置
2. 从后向前比较 `nums1[p1]` 和 `nums2[p2]`：
   - 将较大的元素放到 `nums1[p]` 位置
   - 移动对应的指针
3. 如果 `nums2` 还有剩余元素，将它们复制到 `nums1` 的前面

## Java 代码实现

### 方法一：从后向前双指针（推荐）

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        // p1 指向 nums1 有效元素的末尾
        int p1 = m - 1;
        // p2 指向 nums2 的末尾
        int p2 = n - 1;
        // p 指向 nums1 的末尾（包括预留空间）
        int p = m + n - 1;

        // 从后向前合并，每次选择较大的元素
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] > nums2[p2]) {
                nums1[p] = nums1[p1];
                p1--;
            } else {
                nums1[p] = nums2[p2];
                p2--;
            }
            p--;
        }

        // 如果 nums2 还有剩余元素，复制到 nums1 前面
        // 注意：如果 nums1 还有剩余，它们已经在正确的位置了
        while (p2 >= 0) {
            nums1[p] = nums2[p2];
            p2--;
            p--;
        }
    }
}
```

### 方法二：使用内置排序（不推荐，仅供理解）

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        // 将 nums2 的元素复制到 nums1 的后面
        System.arraycopy(nums2, 0, nums1, m, n);
        // 排序（时间复杂度 O((m+n)log(m+n))，不是最优解）
        Arrays.sort(nums1);
    }
}
```

### 方法三：简化版双指针

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        // 从后向前填充
        while (m > 0 && n > 0) {
            if (nums1[m - 1] > nums2[n - 1]) {
                nums1[m + n - 1] = nums1[m - 1];
                m--;
            } else {
                nums1[m + n - 1] = nums2[n - 1];
                n--;
            }
        }

        // 如果 nums2 还有剩余（nums1 剩余的话已经在正确位置）
        while (n > 0) {
            nums1[n - 1] = nums2[n - 1];
            n--;
        }
    }
}
```

## 复杂度分析

**方法一：从后向前双指针**
- 时间复杂度：O(m + n)，只需要遍历一次两个数组
- 空间复杂度：O(1)，只使用了常数个额外变量

**方法二：使用内置排序**
- 时间复杂度：O((m + n) log(m + n))，排序的时间复杂度
- 空间复杂度：O(log(m + n))，排序所需的栈空间

    p1     p

        ↑

## 关键点总结

1. **从后向前遍历**：避免覆盖未处理的元素，这是解决原地合并的关键
2. **三个指针**：p1 指向 nums1 有效元素末尾，p2 指向 nums2 末尾，p 指向填充位置
3. **边界处理**：当 p1 < 0 时，只需复制 nums2 剩余元素；当 p2 < 0 时，nums1 剩余元素已经在正确位置
4. **时间最优**：O(m + n) 只需一次遍历，满足进阶要求

## 易错点

1. **指针初始化错误**：
   - 错误：`p1 = m`, `p2 = n`, `p = m + n`
   - 正确：`p1 = m - 1`, `p2 = n - 1`, `p = m + n - 1`（索引从 0 开始）

2. **忘记处理 nums2 的剩余元素**：
   - 当 `nums1` 的元素都比 `nums2` 的大时，`nums2` 会有剩余
   - 必须复制 `nums2` 的剩余元素到 `nums1` 前面

3. **从前向后合并**：
   - 会覆盖 `nums1` 中未处理的元素，需要额外空间
   - 违背了题目的原地要求

4. **边界情况未考虑**：
   - `m = 0` 时，`nums1` 为空，需要将 `nums2` 全部复制
   - `n = 0` 时，`nums2` 为空，`nums1` 已经是结果
