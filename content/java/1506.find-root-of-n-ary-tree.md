## 题目描述

给定 N 叉树所有节点列表，找出并返回树的根节点。

**提示：** 根节点不是任何节点的子节点。

## 解题思路

方法一：用 Set 收集所有子节点，不在其中的就是根。方法二：XOR 所有节点值和所有子节点值，剩余的就是根。

## Java 代码实现

```java
class Solution {
    public Node findRoot(List<Node> tree) {
        // XOR 方法：所有节点值 XOR 两次（一次在列表，一次在 children）抵消
        // 只有根不在任何 children 中，XOR 后剩余
        int xor = 0;
        for (Node node : tree) {
            xor ^= node.val;
            for (Node child : node.children) {
                xor ^= child.val;
            }
        }
        for (Node node : tree) {
            if (node.val == xor) return node;
        }
        return null;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **XOR 技巧**：出现两次的抵消，出现一次的保留
2. **根的特征**：不在任何节点的 children 中
3. **O(1) 空间**：XOR 不需额外存储
