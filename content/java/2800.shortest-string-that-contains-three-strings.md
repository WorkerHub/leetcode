## 题目描述

给你三个字符串 `a`、`b`、`c`，返回最短的（同长取字典序最小）包含三者作为子字符串的字符串。

## Java 代码实现

```java
class Solution {
    // 合并 s 和 t：找 s 的最长后缀与 t 的前缀重叠
    String merge(String s, String t) {
        if (s.contains(t)) return s;
        for (int i = Math.min(s.length(), t.length()); i > 0; i--) {
            if (s.endsWith(t.substring(0, i))) return s + t.substring(i);
        }
        return s + t;
    }

    public String minimumString(String a, String b, String c) {
        String[] strs = {a, b, c};
        String ans = null;
        // 枚举 3! = 6 种排列
        int[][] perms = {{0,1,2},{0,2,1},{1,0,2},{1,2,0},{2,0,1},{2,1,0}};
        for (int[] p : perms) {
            String merged = merge(merge(strs[p[0]], strs[p[1]]), strs[p[2]]);
            if (ans == null || merged.length() < ans.length() ||
                (merged.length() == ans.length() && merged.compareTo(ans) < 0)) {
                ans = merged;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(L^2)，L 为字符串总长度
- 空间复杂度：O(L)

## 关键点总结

1. 枚举 6 种排列，对每种顺序依次合并
2. 合并时先检查 t 是否已是 s 的子串
3. 最长公共前后缀保证最大重叠，减少结果长度
