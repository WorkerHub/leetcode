## 题目描述

给你数组 `nums`（长度 n）和 `multipliers`（长度 m，n >= m），每步操作选 `nums` 首尾其中一个元素与 `multipliers[i]` 相乘加入分数，执行 m 步，返回最大分数。

## 解题思路

记忆化搜索 DP：状态 `(step, left)` 表示第 `step` 步时从前端已取 `left` 个，后端已取 `step-left` 个。对每个状态选前端或后端取值，取最大。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    private int[] nums, multipliers;
    private int n, m;
    private int[][] memo;

    public int maximumScore(int[] nums, int[] multipliers) {
        this.nums = nums;
        this.multipliers = multipliers;
        this.n = nums.length;
        this.m = multipliers.length;
        this.memo = new int[m + 1][m + 1];
        for (int[] row : memo) Arrays.fill(row, Integer.MIN_VALUE);
        return dp(0, 0);
    }

    private int dp(int step, int left) {
        if (step == m) return 0;
        if (memo[step][left] != Integer.MIN_VALUE) return memo[step][left];

        int mult = multipliers[step];
        int right = step - left; // 已从后取了 right 个

        // 取前端
        int takeLeft = nums[left] * mult + dp(step + 1, left + 1);
        // 取后端
        int takeRight = nums[n - 1 - right] * mult + dp(step + 1, left);

        memo[step][left] = Math.max(takeLeft, takeRight);
        return memo[step][left];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m^2)
- **空间复杂度**：O(m^2)

## 关键点总结

1. 状态 `(step, left)` 唯一确定后端取数量（`step - left`）
2. 记忆化搜索避免重复计算
