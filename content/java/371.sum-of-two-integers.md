## 题目描述

给你两个整数 `a` 和 `b`，不使用运算符 `+` 和 `-`，计算并返回两整数之和。

**示例 1：**

```
输入：a = 1, b = 2
输出：3
```

**示例 2：**

```
输入：a = 2, b = 3
输出：5
```

**提示：**
- `-1000 <= a, b <= 1000`

## 解题思路

这道题考察位运算的基础知识。关键是理解加法的本质：

### 加法的位运算实现

加法可以分解为两个步骤：
1. **不考虑进位的加法**：使用异或运算（XOR）`a ^ b`
2. **计算进位**：使用与运算（AND）再左移 `(a & b) << 1`

重复这两步，直到没有进位为止。

### 示例演示

```
a = 5 (101)
b = 3 (011)

第一轮：
  不进位加法：101 ^ 011 = 110 (6)
  进位：      (101 & 011) << 1 = 001 << 1 = 010 (2)

第二轮：
  a = 110, b = 010
  不进位加法：110 ^ 010 = 100 (4)
  进位：      (110 & 010) << 1 = 010 << 1 = 100 (4)

第三轮：
  a = 100, b = 100
  不进位加法：100 ^ 100 = 000 (0)
  进位：      (100 & 100) << 1 = 100 << 1 = 1000 (8)

第四轮：
  a = 000, b = 1000
  不进位加法：000 ^ 1000 = 1000 (8)
  进位：      (000 & 1000) << 1 = 0

结果：8 (5 + 3 = 8)
```

### Java 与 Python 的区别

Java 中 `int` 是固定的 32 位有符号整数，天然支持补码运算，无需 Python 中的掩码处理，代码更简洁。

## Java 代码实现

### 方法一：位运算迭代（推荐）

```java
class Solution {
    public int getSum(int a, int b) {
        // Java 的 int 是 32 位有符号整数，直接进行位运算即可
        while (b != 0) {
            // 不考虑进位的加法
            int sumWithoutCarry = a ^ b;
            // 计算进位（左移一位）
            int carry = (a & b) << 1;
            a = sumWithoutCarry;
            b = carry;
        }
        return a;
    }
}
```

### 方法二：递归实现

```java
class Solution {
    public int getSum(int a, int b) {
        // 递归终止条件：没有进位
        if (b == 0) {
            return a;
        }
        // 不考虑进位的和
        int sumWithoutCarry = a ^ b;
        // 进位
        int carry = (a & b) << 1;
        return getSum(sumWithoutCarry, carry);
    }
}
```

### 方法三：简化版（单行）

```java
class Solution {
    public int getSum(int a, int b) {
        // 利用三目运算符简化
        return b == 0 ? a : getSum(a ^ b, (a & b) << 1);
    }
}
```

## 复杂度分析

### 方法一/二/三：位运算
- 时间复杂度：O(1)，最多循环 32 次（32 位整数）
- 空间复杂度：O(1)

## 关键点总结

1. **异或（XOR）**：不考虑进位的加法
   - `1 ^ 1 = 0`
   - `1 ^ 0 = 1`
   - `0 ^ 0 = 0`
2. **与（AND）+ 左移**：计算进位
   - `(a & b) << 1`
3. **循环终止**：当没有进位时（`b == 0`）
4. **Java 优势**：int 是 32 位固定大小，无需掩码处理负数
5. **补码自动处理**：Java 的 int 使用补码表示负数，位运算天然正确

## 易错点

1. **Python vs Java**：Python 整数是无限精度的，需要掩码；Java 不需要
2. **死循环**：Python 中忘记使用掩码会导致死循环，Java 不存在此问题
3. **整数溢出**：Java 的 int 溢出时会自动截断高位，符合预期
4. **边界值**：`Integer.MAX_VALUE = 0x7FFFFFFF`（2^31 - 1）
5. **符号位**：Java 中 `>>` 是算术右移（保留符号位），`>>>` 是逻辑右移

## 图解示例

### 示例：a = 1, b = 2

```
a = 1 (001)
b = 2 (010)

第一轮：
  a ^ b = 001 ^ 010 = 011 (3)
  (a & b) << 1 = (001 & 010) << 1 = 000 << 1 = 000 (0)
  
  a = 3, b = 0

b == 0，返回 a = 3
```

### 示例：a = -1, b = 1

```
在 32 位补码表示中：
a = -1 = 0xFFFFFFFF (全 1)
b = 1  = 0x00000001

第一轮：
  a ^ b = 0xFFFFFFFE
  (a & b) << 1 = 0x00000002
  
  ... (继续迭代直到 b = 0)

最终结果：0 (即 -1 + 1 = 0)
```

## 学习建议

1. **理解位运算**：
   - XOR（异或）：不同为 1，相同为 0
   - AND（与）：都为 1 才为 1
   - 左移：相当于乘以 2
2. **加法本质**：
   - 无进位加法 = XOR
   - 进位 = AND + 左移
3. **掌握补码**：负数在计算机中用补码表示
4. **Java 特性**：
   - int 是固定 32 位，天然支持位运算
   - 比 Python 版本更简单，无需掩码
5. **其他语言对比**：
   - Java/C++：有固定位数，更简单
   - Python：需要额外处理 32 位限制
6. **扩展思考**：
   - 如何用位运算实现减法？（a - b = a + (-b)）
   - 如何实现乘法？（累加或移位累加）
   - 如何实现除法？（减法 + 移位）
