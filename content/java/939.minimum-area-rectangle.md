## 题目描述

给定 xy 平面上的点集，找出边平行于坐标轴的矩形的最小面积。无法构成则返回 0。

## 解题思路

枚举对角线的两个点 (x1,y1) 和 (x2,y2)（要求 x1≠x2 且 y1≠y2），用 HashSet 检查另外两个角是否存在。

## Java 代码实现

```java
class Solution {
    public int minAreaRect(int[][] points) {
        Set<Long> pointSet = new HashSet<>();
        for (int[] p : points) {
            pointSet.add((long) p[0] * 40001 + p[1]);
        }

        int minArea = Integer.MAX_VALUE;
        for (int i = 0; i < points.length; i++) {
            for (int j = i + 1; j < points.length; j++) {
                int x1 = points[i][0], y1 = points[i][1];
                int x2 = points[j][0], y2 = points[j][1];

                if (x1 != x2 && y1 != y2) {
                    // 检查另外两个角
                    if (pointSet.contains((long) x1 * 40001 + y2) &&
                        pointSet.contains((long) x2 * 40001 + y1)) {
                        int area = Math.abs(x1 - x2) * Math.abs(y1 - y2);
                        minArea = Math.min(minArea, area);
                    }
                }
            }
        }

        return minArea == Integer.MAX_VALUE ? 0 : minArea;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **枚举对角线**：只需检查两个对角点
2. **HashSet 查找**：O(1) 验证另两个角是否存在
3. **坐标编码**：将 (x, y) 编码为唯一 long 值
