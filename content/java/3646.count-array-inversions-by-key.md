## 题目描述

给你两个整数数组 `key` 和 `value`，长度均为 `n`。定义一对 `(i, j)` 为逆序对，当且仅当 `i < j` 且（`key[i] > key[j]`，或 `key[i] == key[j]` 且 `value[i] > value[j]`）。返回逆序对的数量，结果对 `10^9 + 7` 取模。

## 解题思路

将 `(key[i], value[i])` 视为二元组，离散化后使用树状数组统计逆序对。从左到右遍历，对每个元素查询已插入中比它大的元素个数，然后将其插入树状数组。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] bit;
    private int N;

    public int countInversions(int[] key, int[] value) {
        int MOD = 1_000_000_007;
        int n = key.length;
        // 构造二元组并排序离散化
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = key[i];
            pairs[i][1] = value[i];
        }
        int[][] sorted = pairs.clone();
        Arrays.sort(sorted, (a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
        // 去重并建立排名映射
        Map<String, Integer> rank = new HashMap<>();
        int idx = 1;
        for (int[] p : sorted) {
            String key2 = p[0] + "," + p[1];
            if (!rank.containsKey(key2)) {
                rank.put(key2, idx++);
            }
        }
        N = idx - 1;
        bit = new int[N + 1];

        long ans = 0;
        for (int[] p : pairs) {
            int r = rank.get(p[0] + "," + p[1]);
            // 比 r 大的已插入元素数 = 总插入数 - query(r)
            long already = query(N) - query(r);
            ans = (ans + already) % MOD;
            update(r);
        }
        return (int) ans;
    }

    private void update(int i) {
        for (; i <= N; i += i & (-i)) bit[i]++;
    }

    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & (-i)) s += bit[i];
        return s;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 二元组比较：先比较 key，相同再比较 value
2. 树状数组统计逆序对：已插入中比当前元素大的数量
3. 离散化将二元组映射到连续整数排名
