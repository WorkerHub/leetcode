## 题目描述

给定一个 N 叉树，找到其最大深度。

最大深度是指从根节点到最远叶子节点的最长路径上的节点总数。

N 叉树输入按层序遍历序列化表示，每组子节点由空值分隔。

**示例 1：**
```
输入：root = [1,null,3,2,4,null,5,6]
输出：3
```

**示例 2：**
```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：5
```

**提示：**
- 树的深度不会超过 `1000`
- 树的节点数目位于 `[0, 10^4]` 之间

## 解题思路

这是一道简单的树的遍历题，可以使用 DFS 或 BFS 求解。

## Java 代码实现

### 方法一：递归 DFS（推荐）⭐

```java
import java.util.List;

class Solution {
    public int maxDepth(Node root) {
        // 递归 DFS
        if (root == null) return 0;
        if (root.children == null || root.children.isEmpty()) return 1;

        int maxChildDepth = 0;
        for (Node child : root.children) {
            maxChildDepth = Math.max(maxChildDepth, maxDepth(child));
        }
        return 1 + maxChildDepth;
    }
}
```

### 方法二：BFS

```java
import java.util.*;

class Solution {
    public int maxDepth(Node root) {
        // BFS 层序遍历
        if (root == null) return 0;

        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 0;

        while (!queue.isEmpty()) {
            depth++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                Node node = queue.poll();
                if (node.children != null) {
                    queue.addAll(node.children);
                }
            }
        }

        return depth;
    }
}
```

### 方法三：迭代 DFS

```java
import java.util.*;

class Solution {
    public int maxDepth(Node root) {
        // 迭代 DFS
        if (root == null) return 0;

        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0}); // 用索引模拟，实际需要存节点和深度
        // 改用 Pair 形式存储节点和深度
        Deque<Object[]> dfsStack = new ArrayDeque<>();
        dfsStack.push(new Object[]{root, 1});
        int maxDepth = 0;

        while (!dfsStack.isEmpty()) {
            Object[] top = dfsStack.pop();
            Node node = (Node) top[0];
            int depth = (int) top[1];
            maxDepth = Math.max(maxDepth, depth);

            if (node.children != null) {
                for (Node child : node.children) {
                    dfsStack.push(new Object[]{child, depth + 1});
                }
            }
        }

        return maxDepth;
    }
}
```

## 复杂度分析

**所有方法：**
- **时间复杂度**：O(n)，需要访问所有节点
- **空间复杂度**：O(h) 到 O(n)，取决于方法

## 关键点总结

1. **N 叉树遍历**：与二叉树类似，但子节点是列表
2. **递归思路**：深度 = 1 + max(子节点深度)
3. **BFS 层数**：每遍历一层深度加 1
4. **边界情况**：空树或叶子节点
