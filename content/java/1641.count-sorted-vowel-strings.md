## 题目描述

给你整数 `n`，返回长度为 `n`、仅由元音（a/e/i/o/u）组成且按**字典序非递减**排列的字符串数目。

## 解题思路

**组合数公式：** 等价于隔板法，从 5 个元音中有重复地选 n 个（非递减），方案数为 `C(n+4, 4)`。

**DP 方法：** `dp[j]` = 当前长度下以第 j 个元音结尾的字符串数，逐步用前缀和更新。

## Java 代码实现

```java
class Solution {
    public int countVowelStrings(int n) {
        // 组合数公式：C(n+4, 4)
        // 用 long 防止中间计算溢出
        long res = 1;
        for (int i = 0; i < 4; i++) {
            res = res * (n + 4 - i) / (i + 1);
        }
        return (int) res;
    }
}
```

### 方法二：DP 前缀和

```java
class Solution {
    public int countVowelStrings(int n) {
        // dp[j] = 当前长度下以第 j 个元音结尾的字符串数
        int[] dp = {1, 1, 1, 1, 1}; // 长度为 1 时各 1 种

        for (int i = 1; i < n; i++) {
            // 前缀和更新：dp[j] += dp[j-1]
            for (int j = 1; j < 5; j++) {
                dp[j] += dp[j - 1];
            }
        }

        int ans = 0;
        for (int x : dp) ans += x;
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)（组合数公式），O(5n) = O(n)（DP）
- **空间复杂度**：O(1)

## 关键点总结

1. 数学本质：有重复的非递减选择 = 隔板法 = `C(n+4, 4)`
2. DP 方法：前缀和更新，从小到大遍历
3. 组合数计算时注意 long 防溢出
