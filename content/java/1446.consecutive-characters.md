## 题目描述

给你一个字符串 `s`，字符串的**幂字符串**是指一个由某个字母重复至少一次而形成的非空字符串（即连续相同字符组成的子字符串）。

返回字符串 `s` 中最长的幂字符串的长度。

**示例 1：**
```
输入：s = "leetcode"
输出：2
解释：子字符串 "ee" 是最长的幂字符串。
```

**示例 2：**
```
输入：s = "abbcccddddeeeeedcba"
输出：5
解释：子字符串 "eeeee" 是最长的幂字符串。
```

**示例 3：**
```
输入：s = "triplepillooooow"
输出：5
```

**示例 4：**
```
输入：s = "hooraaaaaaaaaaay"
输出：11
```

**示例 5：**
```
输入：s = "tourist"
输出：1
```

**提示：**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 解题思路

**一次遍历计数：**

维护一个计数器 `count`，记录当前连续相同字符的长度：
1. 从第二个字符开始遍历。
2. 若当前字符与前一个字符相同，`count += 1`。
3. 若不同，重置 `count = 1`。
4. 每步都更新最大值。

## Java 代码实现

### 方法一：一次遍历（推荐）

```java
class Solution {
    public int maxPower(String s) {
        int maxLen = 1;
        int count = 1;

        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == s.charAt(i - 1)) {
                count++;  // 与前一字符相同，连续长度加 1
                maxLen = Math.max(maxLen, count);
            } else {
                count = 1;  // 字符不同，重置计数
            }
        }

        return maxLen;
    }
}
```

### 方法二：双指针（滑动窗口）

```java
class Solution {
    public int maxPower(String s) {
        int maxLen = 0;
        int left = 0;

        for (int right = 0; right < s.length(); right++) {
            if (s.charAt(right) != s.charAt(left)) {
                left = right;  // 重置窗口起点
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)，遍历字符串一次。
- **空间复杂度：** O(1)，仅用常数空间。

## 图解示例

```
s = "abbcccddddeeeeedcba"

i=1: 'b' != 'a', count=1, max=1
i=2: 'b' == 'b', count=2, max=2
i=3: 'c' != 'b', count=1, max=2
i=4: 'c' == 'c', count=2, max=2
i=5: 'c' == 'c', count=3, max=3
i=6: 'd' != 'c', count=1, max=3
...
i=14: 'e' == 'e', count=5, max=5
i=15: 'd' != 'e', count=1, max=5
...

最终 max=5
```

## 关键点总结

1. 问题本质是"最长连续相同字符子串"，一次遍历即可解决。
2. 双指针（方法二）也是处理"连续满足条件的子串"的通用框架。
3. 初始化 `count = 1` 而非 `count = 0`，确保单字符的情况正确返回 1。

## 易错点

- 初始化 `count = 0` 而非 `count = 1`，导致单字符的情况返回 0。
- 忘记更新 `maxLen`，只返回最终的 `count`（会错过中间的最大值）。
