## 题目描述

Alice 从 `word="a"` 开始，按 `operations` 数组执行操作：0=复制追加，1=字符+1后追加。给你整数 `k`（1 索引，可达 10^14），返回第 `k` 个字符。

## 解题思路

逆向追溯：字符串每次翻倍，若第 `k` 个位置（0 索引）在后半段，则它来自前半段位置 `k-2^i`，若该次操作为 1 则偏移量 +1；若在前半段则继续向上追溯。最终结果为 `chr('a' + offset % 26)`。

## Java 代码实现

```java
class Solution {
    public char kthCharacter(long k, int[] operations) {
        k--; // 转为 0 索引
        int offset = 0;
        // 从最后一次操作往前追溯
        for (int i = operations.length - 1; i >= 0; i--) {
            long length = 1L << i; // 第 i 轮后前半段长度
            if (k >= length) {
                k -= length;           // 在后半段，映射到前半段
                offset += operations[i]; // op=1 则偏移 +1
            }
        }
        return (char) ('a' + offset % 26);
    }
}
```

## 复杂度分析

- 时间复杂度：O(log k)，最多追溯 log k 次
- 空间复杂度：O(1)

## 关键点总结

1. 逆向追溯：每一轮若 k 在后半段则映射回前半段，记录操作类型为 1 的累计次数
2. k 需转为 0 索引（k-1），且使用 `long` 防溢出（k 可达 10^14）
3. 偏移量 mod 26 处理 'z' 后循环的情况
