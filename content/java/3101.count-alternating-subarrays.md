## 题目描述

给你一个二进制数组 `nums`，如果子数组中任意两个相邻元素值不同，则称为交替子数组。返回所有交替子数组的数量。

## 解题思路

以当前位置结尾的交替子数组数等于以该位置结尾的最长交替段长度 `cur`。相邻不同则 cur+1，否则重置为 1，累加所有 cur 即为答案。

## Java 代码实现

```java
class Solution {
    public long countAlternatingSubarrays(int[] nums) {
        long ans = 0;
        int cur = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) cur++;
            else cur = 1;
            ans += cur;
        }
        return ans + 1; // 加上第一个元素本身
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 以位置 i 结尾的交替子数组数 = 以 i 结尾的最长交替段长度
2. 答案可能超 int，使用 long
