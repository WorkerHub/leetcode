## 题目描述

设计算法接收字符流，检查字符流的后缀是否匹配给定单词数组中的某个字符串。

**示例：**
```
输入：words = ["cd","f","kl"]，查询序列 a,b,c,d,e,f...
输出：..., false, true(cd), false, true(f)...
```

## 解题思路

反向 Trie：将所有单词反向插入字典树，每次查询时从最新字符开始在 Trie 中查找，后缀匹配变前缀匹配。

## Java 代码实现

```java
class StreamChecker {
    private int[][] trie;
    private boolean[] isEnd;
    private int cnt = 0;
    private StringBuilder stream = new StringBuilder();
    private int maxLen = 0;

    public StreamChecker(String[] words) {
        // 估算 Trie 大小
        int size = 0;
        for (String w : words) {
            size += w.length();
            maxLen = Math.max(maxLen, w.length());
        }
        trie = new int[size + 1][26];
        isEnd = new boolean[size + 1];

        // 反向插入所有单词
        for (String word : words) {
            int node = 0;
            for (int i = word.length() - 1; i >= 0; i--) {
                int c = word.charAt(i) - 'a';
                if (trie[node][c] == 0) {
                    trie[node][c] = ++cnt;
                }
                node = trie[node][c];
            }
            isEnd[node] = true;
        }
    }

    public boolean query(char letter) {
        stream.append(letter);
        int node = 0;
        // 从最新字符开始在 Trie 中查找
        for (int i = stream.length() - 1; i >= Math.max(0, stream.length() - maxLen); i--) {
            int c = stream.charAt(i) - 'a';
            if (trie[node][c] == 0) return false;
            node = trie[node][c];
            if (isEnd[node]) return true;
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：初始化 O(N*L)，query O(L)，L 为最长单词长度
- **空间复杂度**：O(N*L)

## 关键点总结

1. **反向插入 Trie**：后缀匹配转化为前缀匹配
2. **搜索深度限制**：只搜索最长单词长度
3. **流式处理**：每次 query 只需从最新字符开始查
