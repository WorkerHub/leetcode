## 题目描述

给你一个 `m x n` 的矩阵 `grid`，`grid[i][j]` 表示到达该单元格的最早时刻。从 `(0,0)` 在时刻 `0` 出发，每步耗时 1，若到达时刻早于 `grid[i][j]` 则需等待（来回走保持奇偶性）。返回到达 `(m-1, n-1)` 的最短时间，不可达返回 -1。

## 解题思路

Dijkstra 最短路：状态为 `(当前时刻, 行, 列)`。到达邻居 `(nr, nc)` 的时刻为 `max(t+1, grid[nr][nc])`，若需等待且奇偶性不对则再加 1。初始检查若 `(0,1)` 和 `(1,0)` 都无法在时刻 1 到达则返回 -1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 特判：起点周围都无法到达
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;
        // 最小堆：(时刻, 行, 列)
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int t = cur[0], r = cur[1], c = cur[2];
            if (t > dist[r][c]) continue;
            if (r == m - 1 && c == n - 1) return t;
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int arrive = t + 1;
                if (arrive < grid[nr][nc]) {
                    // 需要等待，来回走保证奇偶性
                    int wait = grid[nr][nc] - arrive;
                    arrive = grid[nr][nc] + (wait % 2);
                }
                if (arrive < dist[nr][nc]) {
                    dist[nr][nc] = arrive;
                    pq.offer(new int[]{arrive, nr, nc});
                }
            }
        }
        return dist[m-1][n-1] == Integer.MAX_VALUE ? -1 : dist[m-1][n-1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * log(m * n))
- 空间复杂度：O(m * n)

## 关键点总结

1. 等待时奇偶性调整：`wait % 2` 决定是否多等一步
2. 初始判断：若 `(0,1)` 和 `(1,0)` 都在时刻 > 1 才能进入则不可达
3. Dijkstra 按时刻最小先处理
