## 题目描述

几张牌 **排成一行**，每张牌都有一个对应的点数。点数由整数数组 `cardPoints` 给出。

每次行动，你可以从行的开头或者末尾拿一张牌，最终你必须恰好拿 `k` 张牌。

你的点数就是你拿到手中的所有牌的点数之和。

给你一个整数数组 `cardPoints` 和整数 `k`，返回你可以获得的最大点数。

**示例 1：**

```
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
解释：第一次行动，不管从开头还是末尾拿，手上的牌点数 = 1，
     拿了 3 张后最大点数 = 1+6+5 = 12（从末尾拿3张）。
```

**示例 2：**

```
输入：cardPoints = [2,2,2], k = 2
输出：4
```

**示例 3：**

```
输入：cardPoints = [9,7,7,9,7,7,9], k = 7
输出：55
解释：必须拿所有牌。
```

**提示：**

- `1 <= cardPoints.length <= 10^5`
- `1 <= cardPoints[i] <= 10^4`
- `1 <= k <= cardPoints.length`

## 解题思路

### 逆向思维：求中间最小子数组和

从两端取 `k` 张牌，等价于**留下中间连续的 `n-k` 张牌**。

总和固定为 `sum(cardPoints)`，减去中间留下的那部分，剩余即为取到的点数。

因此，目标转化为：**求长度为 `n-k` 的连续子数组的最小和**，然后用总和减去它。

使用滑动窗口维护长度为 `n-k` 的窗口的最小和。

## Java 代码实现

### 方法一：滑动窗口（推荐）

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length;
        int total = 0;
        for (int p : cardPoints) total += p;

        // 取所有牌
        if (k == n) return total;

        int windowSize = n - k;  // 中间留下的牌的数量

        // 计算初始窗口（前 windowSize 张牌）的和
        int windowSum = 0;
        for (int i = 0; i < windowSize; i++) {
            windowSum += cardPoints[i];
        }
        int minWindow = windowSum;

        // 滑动窗口：向右移动，每次加入右边一张，移出左边一张
        for (int i = windowSize; i < n; i++) {
            windowSum += cardPoints[i];
            windowSum -= cardPoints[i - windowSize];
            minWindow = Math.min(minWindow, windowSum);
        }

        return total - minWindow;
    }
}
```

### 方法二：枚举两端（正向思路）

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length;
        int maxScore = 0;

        // 计算从左取 k 张的前缀和
        int[] prefix = new int[k + 1];
        for (int i = 0; i < k; i++) {
            prefix[i + 1] = prefix[i] + cardPoints[i];
        }

        // 计算从右取 k 张的后缀和
        int[] suffix = new int[k + 1];
        for (int i = 0; i < k; i++) {
            suffix[i + 1] = suffix[i] + cardPoints[n - 1 - i];
        }

        // 枚举从左取 i 张，从右取 k-i 张（i 从 0 到 k）
        for (int i = 0; i <= k; i++) {
            maxScore = Math.max(maxScore, prefix[i] + suffix[k - i]);
        }

        return maxScore;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 滑动窗口 | O(n) | O(1) |
| 枚举两端 | O(k) | O(k) |

方法二的时间复杂度最优（O(k)），因为只需要计算两端各 k 个元素的前缀/后缀和。

## 图解示例

以 `cardPoints = [1,2,3,4,5,6,1], k = 3` 为例（方法一）：

```
n = 7, total = 22, windowSize = 7-3 = 4

初始窗口 [1,2,3,4]，windowSum = 10

i=4: 加入5，移出1，windowSum = 10+5-1 = 14
i=5: 加入6，移出2，windowSum = 14+6-2 = 18
i=6: 加入1，移出3，windowSum = 18+1-3 = 16

最小窗口和 = 10（初始窗口）
答案 = 22 - 10 = 12 ✓
```

## 关键点总结

1. 核心转化：从两端取 k 张 = 中间留 n-k 张，最大化取得的牌 = 最小化留下的牌
2. 滑动窗口维护固定长度子数组的最小和
3. 方法二更直接，枚举"从左取 i 张，从右取 k-i 张"的所有组合

## 易错点

1. 当 `k == n` 时，窗口大小为 0，需要特殊处理（或者方法二不需要）
2. 滑动窗口初始计算前 `windowSize` 个元素的和，然后从索引 `windowSize` 开始滑动
3. 方法二中 `prefix[i]` 是前 `i` 张，`suffix[k-i]` 是后 `k-i` 张，注意下标
