## 题目描述

修剪 BST 使所有节点值在 [low, high] 范围内。

**示例：**
```
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
```

## 解题思路

利用 BST 性质递归修剪：值 < low 则返回修剪后的右子树，值 > high 则返回修剪后的左子树。

## Java 代码实现

```java
class Solution {
    public TreeNode trimBST(TreeNode root, int low, int high) {
        if (root == null) return null;

        // 当前值太小，整个左子树都太小
        if (root.val < low) {
            return trimBST(root.right, low, high);
        }
        // 当前值太大，整个右子树都太大
        if (root.val > high) {
            return trimBST(root.left, low, high);
        }

        // 在范围内，递归修剪子树
        root.left = trimBST(root.left, low, high);
        root.right = trimBST(root.right, low, high);
        return root;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，递归栈

## 关键点总结

1. **BST 性质**：左子树 < 根 < 右子树
2. **递归返回值**：可能返回子树替代当前节点
3. **三种情况**：太小/太大/在范围内
