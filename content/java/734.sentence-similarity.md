## 题目描述

给定两个句子 sentence1 和 sentence2（字符串数组），以及相似词对列表 similarPairs。判断两个句子是否相似（不传递）。

**示例：**
```
输入：sentence1 = ["great","acting"], sentence2 = ["fine","drama"], similarPairs = [["great","fine"],["acting","drama"]]
输出：true
```

## 解题思路

用 HashSet 存储所有相似词对（双向），逐位比较两个句子中的单词。

## Java 代码实现

```java
class Solution {
    public boolean areSentencesSimilar(String[] sentence1, String[] sentence2, List<List<String>> similarPairs) {
        if (sentence1.length != sentence2.length) return false;

        Set<String> similar = new HashSet<>();
        for (List<String> pair : similarPairs) {
            similar.add(pair.get(0) + "#" + pair.get(1));
            similar.add(pair.get(1) + "#" + pair.get(0));
        }

        for (int i = 0; i < sentence1.length; i++) {
            if (sentence1[i].equals(sentence2[i])) continue;
            if (!similar.contains(sentence1[i] + "#" + sentence2[i])) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(m)

## 关键点总结

1. **哈希集合**：用分隔符拼接存储词对
2. **双向关系**：(a,b) 和 (b,a) 都要存
3. **长度检查**：长度不等直接返回 false
