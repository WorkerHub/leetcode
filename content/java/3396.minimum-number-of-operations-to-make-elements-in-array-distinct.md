## 题目描述

给定整数数组 `nums`，每次操作删除前 3 个元素（不足 3 个则删全部），返回使数组所有元素互不相同所需的最少操作次数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumOperations(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        int n = nums.length;

        // 从后向前找第一个重复元素
        for (int i = n - 1; i >= 0; i--) {
            if (!seen.add(nums[i])) {
                // nums[i] 重复，需要删除 nums[0..i]，即 i//3 + 1 次操作
                return i / 3 + 1;
            }
        }
        return 0; // 无重复
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)，哈希集合

## 关键点总结

1. 每次删前 3 个，等价于找最小 k 使 `nums[3k:]` 无重复。
2. 从后向前找第一个重复位置 i，答案为 `i / 3 + 1`。
3. 无重复则返回 0。
