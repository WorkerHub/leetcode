## 题目描述

给你两个正整数 `num1` 和 `num2`，找出与 `num2` 置位数相同且 `x XOR num1` 最小的整数 `x`。

## 解题思路

设 `k = popcount(num2)`，贪心构造 x：优先从高位开始与 num1 的 1 对齐（使 XOR 为 0）。若 k <= popcount(num1)，取 num1 最高的 k 个 1；若 k > popcount(num1)，先保留 num1 全部 1，再从低位补充不足的 1（低位影响最小）。

## Java 代码实现

```java
class Solution {
    public int minimizeXor(int num1, int num2) {
        int k = Integer.bitCount(num2); // 需要的置位数
        int x = 0;
        int used = 0;

        // 从 num1 高位 1 开始取，优先与 num1 对齐
        for (int i = 29; i >= 0 && used < k; i--) {
            if ((num1 >> i & 1) == 1) {
                x |= (1 << i);
                used++;
            }
        }
        // 若还不够，从低位补充置 1
        for (int i = 0; i < 30 && used < k; i++) {
            if ((x >> i & 1) == 0) {
                x |= (1 << i);
                used++;
            }
        }
        return x;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(30) = O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 优先从 num1 高位的 1 中取，使 XOR 高位为 0（影响更大）
2. k > popcount(num1) 时从低位补充额外的 1
3. `Integer.bitCount()` 计算置位数
