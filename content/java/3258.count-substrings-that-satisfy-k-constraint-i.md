## 题目描述

给你二进制字符串 `s` 和正整数 `k`。若子字符串中 `'0'` 的数量至多为 k，或 `'1'` 的数量至多为 k，则称满足 k 约束。返回满足 k 约束的子字符串数量。

## 解题思路

滑动窗口：维护窗口内 0 和 1 的计数。当两个计数都超过 k 时收缩左端，每个右端点对应的满足条件子字符串数为 `right - left + 1`。

## Java 代码实现

```java
class Solution {
    public int countKConstraintSubstrings(String s, int k) {
        int n = s.length();
        int cnt0 = 0, cnt1 = 0, left = 0, ans = 0;

        for (int right = 0; right < n; right++) {
            // 扩展右端
            if (s.charAt(right) == '0') cnt0++;
            else cnt1++;
            // 当两个计数都超过 k 时，收缩左端
            while (cnt0 > k && cnt1 > k) {
                if (s.charAt(left) == '0') cnt0--;
                else cnt1--;
                left++;
            }
            // 以 right 结尾且满足条件的子字符串数
            ans += right - left + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. k 约束：0 的数量 <= k 或 1 的数量 <= k（满足其一即可）
2. 仅当两个计数都超过 k 时窗口不满足，需要收缩
3. 每个右端点满足条件的子字符串数 = right - left + 1
