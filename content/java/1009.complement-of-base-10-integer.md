## 题目描述

每个非负整数 `n` 都有其二进制表示。例如，`5` 可以被表示为二进制的 `"101"`。

我们可以将二进制的每一位翻转（0 变成 1，1 变成 0），得到这个数的补数。例如，`5` 的二进制补数是 `"010"`，也就是十进制的 `2`。

给你一个整数 `n`，返回其二进制表示的补数（十进制）。

**示例 1：**
```
输入：n = 5
输出：2
解释：5 的二进制表示为 "101"，其补数为 "010"，也就是十进制的 2。
```

**示例 2：**
```
输入：n = 7
输出：0
解释：7 的二进制表示为 "111"，其补数为 "000"，也就是十进制的 0。
```

**示例 3：**
```
输入：n = 10
输出：5
解释：10 的二进制表示为 "1010"，其补数为 "0101"，也就是十进制的 5。
```

**提示：**
- `0 <= n < 10^9`

**注意**：本题与 [476. 数字的补数](https://leetcode.com/problems/number-complement/) 相同

## 解题思路

**核心思想**：找到一个全1的掩码，与n异或即可得到补数

例如：
- n = 5 = 101
- mask = 111 (3位全1)
- 补数 = n ^ mask = 101 ^ 111 = 010 = 2

**关键步骤**：
1. 找到n的最高位1的位置
2. 构造相同位数的全1掩码
3. n与掩码异或得到结果

**特殊情况**：n = 0 时，补数为 1

## Java 代码实现

### 方法一：位运算构造掩码（推荐）

```java
class Solution {
    public int bitwiseComplement(int n) {
        // 特殊情况：0的补数是1
        if (n == 0) return 1;

        // 计算n的位数
        int bitLength = Integer.SIZE - Integer.numberOfLeadingZeros(n);

        // 构造全1掩码：2^bitLength - 1
        int mask = (1 << bitLength) - 1;

        // 异或得到补数
        return n ^ mask;
    }
}
```

### 方法二：逐位构造掩码

```java
class Solution {
    public int bitwiseComplement(int n) {
        // 特殊情况
        if (n == 0) return 1;

        // 通过移位找到比n大的最小2的幂
        int mask = 1;
        int temp = n;

        while (temp > 0) {
            mask <<= 1;
            temp >>= 1;
        }

        // mask 现在是比n大的最小2的幂，减1得到全1掩码
        mask -= 1;

        // 异或得到补数
        return n ^ mask;
    }
}
```

### 方法三：数学公式（最简洁）

```java
class Solution {
    public int bitwiseComplement(int n) {
        // 特殊情况
        if (n == 0) return 1;

        // 找到大于n的最小2的幂
        int powerOf2 = 1;
        while (powerOf2 <= n) {
            powerOf2 <<= 1;
        }

        // 公式：补数 = 全1掩码 - n = (2^位数 - 1) - n
        return powerOf2 - 1 - n;
    }
}
```

### 方法四：逐位处理

```java
class Solution {
    public int bitwiseComplement(int n) {
        if (n == 0) return 1;

        int result = 0;
        int power = 0; // 当前位的权重

        int temp = n;
        while (temp > 0) {
            // 取最后一位并翻转
            int bit = temp & 1;
            int flippedBit = 1 - bit;

            // 添加到结果中
            result += flippedBit * (1 << power);

            // 移到下一位
            temp >>= 1;
            power++;
        }

        return result;
    }
}
```

## 图解示例

以 n = 5 为例：

```
n = 5
二进制：101

步骤1：找到位数 = 3
步骤2：构造掩码 = 111 (二进制) = 7 (十进制)
步骤3：异或 = 101 ^ 111 = 010 = 2

或者用公式：
2^3 - 1 - 5 = 8 - 1 - 5 = 2
```

## 关键点总结

1. **异或性质**：a ^ 1 = 位翻转
2. **掩码构造**：2^位数 - 1 得到全1掩码
3. **Java内置**：`Integer.numberOfLeadingZeros(n)` 可快速获取位数
4. **特殊情况**：0的补数是1（不是0）
5. **等价公式**：n ^ mask = mask - n

## 易错点

1. **忘记处理 n=0**：0的补数是1，不是0
2. **掩码位数错误**：要确保掩码与n位数相同
3. **整数溢出**：虽然本题数据不超 int 范围，但要注意
4. **异或理解**：1^1=0, 0^1=1，即与1异或等于翻转
5. **公式理解**：mask - n 等价于 n ^ mask
