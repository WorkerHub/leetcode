## 题目描述

给你一个大小为 m x n 的矩阵 board 表示甲板，其中，每个单元格可以是一艘战舰 'X' 或者是一个空位 '.'，返回在甲板 board 上放置的战舰的数量。

战舰只能水平或者垂直放置在 board 上。换句话说，战舰只能按 1 × k（1 行，k 列）或 k × 1（k 行，1 列）的形状放置，其中 k 可以是任意大小。两艘战舰之间至少有一个水平或垂直的空位分隔（即没有相邻的战舰）。

**示例 1：**
```
输入：board = [["X",".",".","X"],[".",".",".","X"],[".",".",".","X"]]
输出：2
```

**示例 2：**
```
输入：board = [["."]]
输出：0
```

## 解题思路

核心观察：
1. 只需要统计战舰的起始点
2. 一个 'X' 是起始点当且仅当它的左边和上边都不是 'X'

## Java 代码实现

### 方法一：一次遍历（推荐）

```java
class Solution {
    public int countBattleships(char[][] board) {
        // 只统计战舰的起始点，O(1) 空间
        int m = board.length, n = board[0].length;
        int count = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'X') {
                    // 检查是否是起始点：左边和上边都不是 'X'
                    if ((i == 0 || board[i - 1][j] == '.') &&
                        (j == 0 || board[i][j - 1] == '.')) {
                        count++;
                    }
                }
            }
        }

        return count;
    }
}
```

### 方法二：DFS

```java
class Solution {
    public int countBattleships(char[][] board) {
        // 使用 DFS 标记整艘战舰
        int m = board.length, n = board[0].length;
        int count = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'X') {
                    count++;
                    dfs(board, i, j, m, n);
                }
            }
        }

        return count;
    }

    private void dfs(char[][] board, int i, int j, int m, int n) {
        // 将战舰的所有格子标记为 '.'
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] == '.') {
            return;
        }

        board[i][j] = '.';
        // 只向右和向下搜索（避免重复）
        dfs(board, i + 1, j, m, n);
        dfs(board, i, j + 1, m, n);
    }
}
```

## 复杂度分析

### 方法一：
- **时间复杂度**：O(m * n)
- **空间复杂度**：O(1)

### 方法二：
- **时间复杂度**：O(m * n)
- **空间复杂度**：O(m * n)（递归栈）

## 关键点总结

1. 识别战舰起始点
2. 左边和上边都不是 'X' 即为起始点
3. 一次遍历即可

## 易错点

1. 统计所有 'X' 而不是战舰数量
2. 边界检查错误
