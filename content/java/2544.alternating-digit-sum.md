## 题目描述

给你正整数 `n`，最高位数字符号为正，其余位交替正负，返回所有数字及其符号的和。

## 解题思路

将 n 转为字符串，从左（最高位）到右交替用 +1/-1 符号乘以各位数字后累加。

## Java 代码实现

```java
class Solution {
    public int alternateDigitSum(int n) {
        int result = 0, sign = 1; // 最高位为正
        for (char ch : Integer.toString(n).toCharArray()) {
            result += sign * (ch - '0');
            sign = -sign; // 交替正负
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(log n)

## 关键点总结

1. 最高位（字符串第 0 位）符号为正，之后每位交替
2. 用 `sign` 变量每次乘以 -1 切换符号
3. `Integer.toString(n)` 从高位到低位，直接遍历即可
