## 题目描述

n×n 网格中 grid[i][j] 为平台高度。时间 t 时水位为 t，只能游到水位同时淹没的相邻平台。从左上角到右下角，返回最早到达时间。

**示例：**
```
输入：grid = [[0,2],[1,3]]
输出：3
```

## 解题思路

Dijkstra 变体：使用优先队列，路径代价为经过的最大高度值。每次取出当前最小代价的格子扩展。

## Java 代码实现

```java
class Solution {
    public int swimInWater(int[][] grid) {
        int n = grid.length;
        boolean[][] visited = new boolean[n][n];
        // 优先队列：(时间/高度, x, y)
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{grid[0][0], 0, 0});
        visited[0][0] = true;

        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int time = curr[0], x = curr[1], y = curr[2];

            if (x == n - 1 && y == n - 1) return time;

            for (int[] d : dirs) {
                int nx = x + d[0], ny = y + d[1];
                if (nx >= 0 && nx < n && ny >= 0 && ny < n && !visited[nx][ny]) {
                    visited[nx][ny] = true;
                    pq.offer(new int[]{Math.max(time, grid[nx][ny]), nx, ny});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² log n)
- **空间复杂度**：O(n²)

## 关键点总结

1. **路径最大值最小化**：Dijkstra 变体
2. **优先队列**：每次处理代价最小的格子
3. **代价定义**：路径上经过的最大高度
