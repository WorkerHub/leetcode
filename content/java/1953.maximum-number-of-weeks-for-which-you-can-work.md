## 题目描述

给你 n 个项目的里程碑数组，每周做一个项目的一个里程碑且相邻两周不能做同一项目，返回能工作的最多周数。

## 解题思路

贪心：设最大里程碑数为 `maxM`，其余之和为 `rest`。若 `maxM <= rest + 1`，所有里程碑都能完成，答案为总和；否则只能穿插完成 `2 * rest + 1` 周。

## Java 代码实现

```java
class Solution {
    public long numberOfWeeks(int[] milestones) {
        long total = 0, maxM = 0;
        for (int m : milestones) {
            total += m;
            maxM = Math.max(maxM, m);
        }
        long rest = total - maxM;
        return maxM <= rest + 1 ? total : rest * 2 + 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 瓶颈在最大里程碑项目能否均匀穿插
2. `maxM <= rest + 1` 时全部完成，否则 `2 * rest + 1`
3. 使用 `long` 防止溢出
