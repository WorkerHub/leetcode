## 题目描述

整数的数组形式 num 和整数 k，返回 num + k 的数组形式。

**示例：**
```
输入：num = [1,2,0,0], k = 34
输出：[1,2,3,4]
```

## 解题思路

从右到左逐位相加：将 k 当作进位加到数组末尾，每次取个位作为结果，十位作为新进位。

## Java 代码实现

```java
class Solution {
    public List<Integer> addToArrayForm(int[] num, int k) {
        LinkedList<Integer> result = new LinkedList<>();
        int i = num.length - 1;

        while (i >= 0 || k > 0) {
            if (i >= 0) {
                k += num[i];
                i--;
            }
            result.addFirst(k % 10);
            k /= 10;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(max(n, log k))
- **空间复杂度**：O(1)

## 关键点总结

1. **k 当进位**：将 k 整体作为初始进位处理
2. **从右到左**：模拟加法从个位开始
3. **LinkedList.addFirst**：避免最后反转
