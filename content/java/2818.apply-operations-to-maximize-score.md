## 题目描述

选k个子数组，每次得分为子数组中质数分数最高元素的值，最大化所有得分的乘积(mod 10^9+7)。

## 解题思路

线性筛求质数分数，单调栈求每个元素作为最大质数分数的子数组数量，按值降序贪心选取，快速幂计算答案。

## Java 代码实现

```java
class Solution {
    public int maximumScore(List<Integer> nums, int k) {
        long MOD = 1_000_000_007;
        int n = nums.size();

        // 计算质数分数
        int maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);
        int[] primeScore = new int[maxVal + 1];
        for (int p = 2; p <= maxVal; p++) {
            if (primeScore[p] == 0) { // p是质数
                for (int m = p; m <= maxVal; m += p) {
                    primeScore[m]++;
                }
            }
        }

        int[] scores = new int[n];
        for (int i = 0; i < n; i++) scores[i] = primeScore[nums.get(i)];

        // 单调栈求左右边界
        int[] left = new int[n]; // 左边第一个score>=scores[i]的位置
        int[] right = new int[n]; // 右边第一个score>scores[i]的位置
        Arrays.fill(left, -1);
        Arrays.fill(right, n);

        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && scores[stack.peek()] < scores[i]) {
                right[stack.pop()] = i;
            }
            stack.push(i);
        }
        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && scores[stack.peek()] <= scores[i]) {
                left[stack.pop()] = i;
            }
            stack.push(i);
        }

        // 按值降序排序
        int[][] elements = new int[n][2]; // [value, count]
        for (int i = 0; i < n; i++) {
            long cnt = (long)(i - left[i]) * (right[i] - i);
            elements[i][0] = nums.get(i);
            elements[i][1] = (int) Math.min(cnt, (long) k);
        }
        Arrays.sort(elements, (a, b) -> b[0] - a[0]);

        // 贪心计算答案
        long ans = 1;
        long remaining = k;
        for (int[] e : elements) {
            if (remaining <= 0) break;
            long take = Math.min(e[1], remaining);
            ans = ans * power(e[0], take, MOD) % MOD;
            remaining -= take;
        }
        return (int) ans;
    }

    private long power(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M log log M + N log N)
- **空间复杂度**：O(M + N)

## 关键点总结

1. **线性筛求质数分数**：每个数的不同质因子个数
2. **单调栈求左右边界**：左>=右>防重复计数
3. **贪心+快速幂**：按值降序，优先选大值
