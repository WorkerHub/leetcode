## 题目描述

实现数据结构 `DataStream(int value, int k)`，每次调用 `consec(int num)` 将 `num` 加入流，若最后 `k` 个数全部等于 `value` 则返回 `true`，否则返回 `false`。

## 解题思路

维护计数器 `count` 记录当前连续等于 `value` 的数目：`num == value` 则自增，否则归零；`count >= k` 时返回 `true`。

## Java 代码实现

```java
class DataStream {
    private final int value;
    private final int k;
    private int count; // 当前连续等于 value 的数量

    public DataStream(int value, int k) {
        this.value = value;
        this.k = k;
        this.count = 0;
    }

    public boolean consec(int num) {
        if (num == value) {
            count++;
        } else {
            // 连续性打破，重置计数
            count = 0;
        }
        return count >= k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1) 每次操作
- **空间复杂度**：O(1)

## 关键点总结

1. 只需维护连续计数器，无需存储历史数据
2. 计数超过 k 仍返回 true（如 count=10, k=3 也满足）
3. 只要某次 num != value，连续性打破，计数归零
