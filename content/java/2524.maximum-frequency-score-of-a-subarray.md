## 题目描述

给你整数数组 `nums` 和正整数 `k`，子数组的频率分数定义为每个不同元素出现次数的幂次方之和（即 x 出现 freq 次贡献 `x^freq`），返回长度恰好为 `k` 的子数组的最大频率分数（结果对 `10^9+7` 取模）。

## 解题思路

滑动窗口维护当前分数：加入元素 x（频率 freq -> freq+1）时分数 += `x^(freq+1) - x^freq`；移出元素 y（频率 freq -> freq-1）时分数 -= `y^freq - y^(freq-1)`。用快速幂计算幂次。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    static final long MOD = 1_000_000_007;

    public int maxFrequencyScore(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> freq = new HashMap<>();
        long score = 0;

        // 初始化前 k 个元素
        for (int i = 0; i < k; i++) {
            int x = nums[i];
            int f = freq.getOrDefault(x, 0);
            // 加入 x：score += x^(f+1) - x^f
            score = (score + pow(x, f + 1) - pow(x, f) + MOD) % MOD;
            freq.put(x, f + 1);
        }

        long ans = score;

        // 滑动窗口向右移动
        for (int i = k; i < n; i++) {
            int x = nums[i];
            int fx = freq.getOrDefault(x, 0);
            score = (score + pow(x, fx + 1) - pow(x, fx) + MOD) % MOD;
            freq.put(x, fx + 1);

            int y = nums[i - k];
            int fy = freq.get(y);
            score = (score - pow(y, fy) + pow(y, fy - 1) + MOD) % MOD;
            freq.put(y, fy - 1);

            ans = Math.max(ans, score);
        }
        return (int) ans;
    }

    // 快速幂（取模）
    private long pow(long base, int exp) {
        if (exp == 0) return 1;
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)，每次窗口移动调用快速幂 O(log M)
- **空间复杂度**：O(k)

## 关键点总结

1. 滑动窗口每次只调整变化的元素，避免重新计算整个窗口
2. 加入/移出时分数增量：`x^(f+1) - x^f` 和 `x^(f-1) - x^f`
3. 减法取模时加 MOD 防止结果为负
