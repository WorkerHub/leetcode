## 题目描述

给你一个整数数组 `arr` 和一个整数 `k`。

设 `m` 为数组的**中位数**，只要满足下述两个前提之一，则认为元素 `v1` 比 `v2` **更强**：

- `|v1 - m| > |v2 - m|`
- `|v1 - m| == |v2 - m|` 且 `v1 > v2`

请你返回由数组中最强的 `k` 个值组成的列表。答案可以以**任意顺序**返回。

**中位数**是一个有序整数列表中处于中间位置的值。形式上，如果列表的长度为 `n`，中位数就是有序列表（下标从 0 开始）中位于 `((n - 1) / 2)` 处（向下取整）的那个元素。

**示例 1：**

```
输入：arr = [1,2,3,4,5], k = 2
输出：[5,1]
解释：中位数为 3，|5-3|=2, |1-3|=2（相同则取较大值5）→ 5最强
```

**示例 2：**

```
输入：arr = [1,1,3,5,5], k = 2
输出：[5,5]
解释：中位数为 3，|5-3|=2 最大，有两个 5，所以答案是 [5,5]
```

**示例 3：**

```
输入：arr = [6,7,11,7,6,8], k = 5
输出：[11,8,6,6,7,7]
```

**提示：**
- `1 <= arr.length <= 10^5`
- `-10^5 <= arr[i] <= 10^5`
- `1 <= k <= arr.length`

## 解题思路

**关键步骤：**
1. **排序**数组，找到中位数 `m = arr[(n-1)/2]`。
2. 按"强度"排序，选出前 k 个。

**双指针优化：**
- 排序后，最强的元素一定在两端（距离中位数最远）。
- 用左指针 `left = 0`，右指针 `right = n-1`，每次比较两端哪个更强，选较强的一个，重复 k 次。

**强度比较规则：**
- `|arr[right] - m| >= |arr[left] - m|` 时，右端更强（相同时右端值更大）。
- 否则左端更强。

## Java 代码实现

### 方法一：双指针（推荐）

```java
import java.util.Arrays;

class Solution {
    public int[] getStrongest(int[] arr, int k) {
        Arrays.sort(arr);  // 先排序
        int n = arr.length;
        int m = arr[(n - 1) / 2];  // 中位数

        int[] result = new int[k];
        int left = 0, right = n - 1;  // 双指针

        for (int i = 0; i < k; i++) {
            // 比较左右端哪个更强
            // 相同强度时右端（值更大）更强，条件用 >=
            if (arr[right] - m >= m - arr[left]) {
                result[i] = arr[right--];
            } else {
                result[i] = arr[left++];
            }
        }

        return result;
    }
}
```

### 方法二：自定义排序（直观版）

```java
import java.util.Arrays;

class Solution {
    public int[] getStrongest(int[] arr, int k) {
        Arrays.sort(arr);
        int n = arr.length;
        final int m = arr[(n - 1) / 2];  // 中位数（final 供 lambda 捕获）

        // 将 int[] 转为 Integer[] 以使用自定义比较器
        Integer[] boxed = new Integer[n];
        for (int i = 0; i < n; i++) boxed[i] = arr[i];

        // 自定义排序键：按绝对差降序，相同则按值降序
        Arrays.sort(boxed, (a, b) -> {
            int da = Math.abs(a - m), db = Math.abs(b - m);
            return da != db ? db - da : b - a;
        });

        int[] result = new int[k];
        for (int i = 0; i < k; i++) result[i] = boxed[i];
        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n log n) | O(k) |
| 自定义排序 | O(n log n) | O(n) |

- **时间复杂度**：主要由排序决定 O(n log n)。
- **空间复杂度**：结果数组 O(k)，排序原地进行。

## 图解示例

以 `arr = [1,2,3,4,5], k = 2` 为例：

```
排序后：[1, 2, 3, 4, 5]
中位数 m = arr[(5-1)/2] = arr[2] = 3

双指针初始：left=0(值1), right=4(值5)

第1轮：
  arr[right]-m = 5-3 = 2
  m-arr[left] = 3-1 = 2
  相等时取右端 → 选 5，right=3

第2轮：
  arr[right]-m = 4-3 = 1
  m-arr[left] = 3-1 = 2
  左端更强 → 选 1，left=1

结果：[5, 1]
```

## 关键点总结

1. 中位数的下标是 `(n-1)/2`（整数除法向下取整），不是 `n/2`。
2. 强度相同时，**值更大**的更强，因此右端（排序后较大）优先。
3. 双指针法利用了"排序后最强元素在两端"的性质，避免全局重新排序。
4. 比较条件 `arr[right] - m >= m - arr[left]` 同时处理了强度更大和强度相等两种情况。

## 易错点

- **中位数下标错误**：应为 `(n-1)/2`，而非 `n/2`。例如 n=5 时 `(5-1)/2=2`，n=6 时 `(6-1)/2=2`。
- **强度相等时的比较**：要选值更大的（即右端），所以条件是 `>=` 而不是 `>`。
- **中位数是排序后的值**：必须先排序再取中位数。
