## 题目描述

给你 `n` 个长方体 `cuboids[i] = [width, length, height]`，可旋转任意面作为高度。若长方体 `i` 的三维均不超过 `j` 的三维则可放 `i` 于 `j` 上。返回堆叠的最大高度。

## 解题思路

**排序 + DP：** 将每个长方体的三边排序（最大边为高），再对所有长方体三维升序排序。类似 LIS，`dp[i]` = 以第 `i` 个为顶的最大高度，枚举 `j < i` 检查三维条件进行转移。

## Java 代码实现

```java
class Solution {
    public int maxHeight(int[][] cuboids) {
        // 每个长方体三边排序，最大边为高
        for (int[] c : cuboids) Arrays.sort(c);
        // 所有长方体按三维升序排序
        Arrays.sort(cuboids, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] != b[1] ? a[1] - b[1] : a[2] - b[2]);

        int n = cuboids.length;
        int[] dp = new int[n];
        int ans = 0;

        for (int i = 0; i < n; i++) {
            dp[i] = cuboids[i][2]; // 仅当前长方体
            for (int j = 0; j < i; j++) {
                // j 能否放在 i 下面（j 的三维均 <= i 的三维）
                if (cuboids[j][0] <= cuboids[i][0] &&
                    cuboids[j][1] <= cuboids[i][1] &&
                    cuboids[j][2] <= cuboids[i][2]) {
                    dp[i] = Math.max(dp[i], dp[j] + cuboids[i][2]);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n)

## 关键点总结

1. 先对每个长方体三边排序，最大边作为高度（贪心最优）
2. 全局排序后，三维条件等价于在排序后的序列中找递增子序列
3. `dp[i]` 初始化为 `cuboids[i][2]`（仅放当前长方体）
