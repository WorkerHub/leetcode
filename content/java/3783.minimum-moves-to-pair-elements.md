## 题目描述

给定长度为 `2n` 的整数数组 `nums`，通过若干次移动（每次将某元素移动一步）使相同值的元素相邻配对，求最少移动次数。

## 解题思路

贪心：记录每种值的所有出现位置，排序后两两相邻配对（第 0、1 个配对，第 2、3 个配对...），每对代价为两位置之差减 1（距离 -1 步使它们相邻）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minMoves(int[] nums) {
        Map<Integer, List<Integer>> pos = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            pos.computeIfAbsent(nums[i], x -> new ArrayList<>()).add(i);
        }

        long moves = 0;
        for (List<Integer> positions : pos.values()) {
            Collections.sort(positions);
            // 两两配对：(p0,p1), (p2,p3), ...
            for (int i = 0; i < positions.size(); i += 2) {
                moves += positions.get(i + 1) - positions.get(i) - 1;
            }
        }

        return moves;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 同一值的相邻两个位置配对最优（贪心证明：交叉配对不优于相邻配对）
2. 配对代价 = `b - a - 1`（将两个位置合并到相邻所需步数）
3. 不同值的配对相互独立，分别计算后累加
