## 题目描述

二进制字符串中选3个下标严格递增且类型交替(010或101)的方案数。

## 解题思路

动态维护：遍历时统计c0/c1(已遍历的0/1数量)、c01/c10(长度2子序列数)。遇到'0'时ans+=c10、c01+=c1；遇到'1'时ans+=c01、c10+=c0。

## Java 代码实现

```java
class Solution {
    public long numberOfWays(String s) {
        long c0 = 0, c1 = 0, c01 = 0, c10 = 0;
        long ans = 0;
        
        for (char ch : s.toCharArray()) {
            if (ch == '0') {
                ans += c10;   // 新的010
                c01 += c1;    // 新的01子序列
                c0++;
            } else {
                ans += c01;   // 新的101
                c10 += c0;    // 新的10子序列
                c1++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **只有010和101两种模式**：枚举中间元素，左右异类数量相乘
2. **动态维护子序列计数**：逐步累加长度1→2→3的子序列数
3. **一遍遍历O(1)空间**：无需前缀和数组
