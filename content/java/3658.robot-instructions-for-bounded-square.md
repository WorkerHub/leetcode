## 题目描述

机器人从 `(0,0)` 出发面向北，指令集为 `G`（前进）、`L`（左转 90 度）、`R`（右转 90 度）。执行指令字符串一次后，判断机器人是否在有界圆内（无论重复多少次都在某圆范围内）。

## 解题思路

执行一次指令后，有界充要条件：(1) 回到原点，或 (2) 不朝北（面向其他方向时最多执行 4 次会回到原点）。

## Java 代码实现

```java
class Solution {
    public boolean isRobotBounded(String instructions) {
        // 方向：0=北, 1=东, 2=南, 3=西
        int[] dx = {0, 1, 0, -1}; // 北东南西 x 偏移
        int[] dy = {1, 0, -1, 0}; // 北东南西 y 偏移
        int x = 0, y = 0, dir = 0;

        for (char cmd : instructions.toCharArray()) {
            if (cmd == 'G') {
                x += dx[dir];
                y += dy[dir];
            } else if (cmd == 'L') {
                dir = (dir + 3) % 4; // 左转 = 逆时针
            } else {
                dir = (dir + 1) % 4; // 右转 = 顺时针
            }
        }

        // 有界条件：回到原点，或方向不朝北
        return (x == 0 && y == 0) || dir != 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，n 为指令长度
- 空间复杂度：O(1)

## 关键点总结

1. 有界充要条件：执行一次后回到原点，或不朝北
2. 不朝北时最多执行 4 次指令即回到原点
3. 只需模拟一次指令执行
