## 题目描述

给你整数 `n` 和严格递增数组 `sick`，表示已感染天。计算感染可能性总数：边界空隙（单侧感染源）贡献空隙长度，内部空隙（双侧感染源）贡献 2^(gap-1)，结果对 10^9+7 取模。

## 解题思路

分三段处理：左边界空隙、相邻感染日之间的内部空隙、右边界空隙。内部空隙 gap 的贡献用快速幂计算 2^(gap-1)。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public long countDaysBetweenDates(int n, int[] sick) {
        if (sick.length == 0) return 0;

        long ans = 0;
        // 左边界空隙（单侧感染源）
        ans = (ans + sick[0]) % MOD;
        // 右边界空隙（单侧感染源）
        ans = (ans + n - 1 - sick[sick.length - 1]) % MOD;
        // 内部空隙（双侧感染源）
        for (int i = 0; i < sick.length - 1; i++) {
            int gap = sick[i + 1] - sick[i] - 1;
            if (gap > 0) {
                ans = (ans + pow2(gap - 1)) % MOD;
            }
        }
        return ans;
    }

    private long pow2(int exp) {
        // 快速幂计算 2^exp % MOD
        long base = 2, result = 1;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(len(sick) * log(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 边界空隙（单侧感染源）贡献为空隙长度
2. 内部空隙（双侧感染源）贡献为 2^(gap-1)
3. 答案可能很大，需对 10^9+7 取模
