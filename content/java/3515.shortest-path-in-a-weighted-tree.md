## 题目描述

给定 n 个节点的加权树（根节点为 1），支持两类查询：类型 1 更新某条边权重，类型 2 查询根节点 1 到节点 v 的距离。

## 解题思路

DFS 序 + 线段树（区间加、单点查）：DFS 记录每个节点的入/出时间戳，子树对应连续区间。更新边 (u,v) 权重时，将子节点子树区间整体加上差值 delta；查询节点 v 距离时，单点查 in[v]。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] in, out, parent;
    private int[] parentEdgeIdx; // 节点到其父边在 edgeW 中的下标
    private long[] tree, lazy;
    private int timer, n;

    public int[] treeQueries(int n, int[][] edges, int[][] queries) {
        this.n = n;
        in = new int[n + 1]; out = new int[n + 1];
        parent = new int[n + 1];
        parentEdgeIdx = new int[n + 1];
        long[] dist = new long[n + 1];
        int[] edgeW = new int[edges.length];
        for (int i = 0; i < edges.length; i++) edgeW[i] = edges[i][2];

        // 建邻接表（存边下标）
        List<int[]>[] adj = new List[n + 1];
        for (int i = 1; i <= n; i++) adj[i] = new ArrayList<>();
        for (int i = 0; i < edges.length; i++) {
            adj[edges[i][0]].add(new int[]{edges[i][1], i});
            adj[edges[i][1]].add(new int[]{edges[i][0], i});
        }

        // 迭代 DFS
        timer = 0;
        int[] stack = new int[n + 1]; int top = 0;
        boolean[] vis = new boolean[n + 1];
        stack[top++] = 1; vis[1] = true; parent[1] = 0;
        int[] order = new int[n]; int oi = 0;
        // 用递归 DFS 记录 in/out（迭代版）
        // 重新用显式栈带 phase 标记
        int[][] dfsStack = new int[n + 1][2]; // [node, adjIdx]
        int dTop = 0;
        dfsStack[dTop][0] = 1; dfsStack[dTop][1] = 0; dTop++;
        vis = new boolean[n + 1]; vis[1] = true;
        while (dTop > 0) {
            int u = dfsStack[dTop-1][0], idx = dfsStack[dTop-1][1];
            if (idx == 0) { in[u] = ++timer; }
            boolean pushed = false;
            while (dfsStack[dTop-1][1] < adj[u].size()) {
                int[] nb = adj[u].get(dfsStack[dTop-1][1]++);
                int v = nb[0]; int ei = nb[1];
                if (!vis[v]) {
                    vis[v] = true;
                    parent[v] = u;
                    parentEdgeIdx[v] = ei;
                    dist[v] = dist[u] + edgeW[ei];
                    dfsStack[dTop][0] = v; dfsStack[dTop][1] = 0; dTop++;
                    pushed = true; break;
                }
            }
            if (!pushed) { out[u] = timer; dTop--; }
        }

        // 线段树初始化
        tree = new long[4 * (n + 1)];
        lazy = new long[4 * (n + 1)];
        for (int v = 1; v <= n; v++) update(1, 1, n, in[v], in[v], dist[v]);

        List<Integer> result = new ArrayList<>();
        for (int[] q : queries) {
            if (q[0] == 2) {
                result.add((int) query(1, 1, n, in[q[1]]));
            } else {
                int u = q[1], v = q[2], newW = q[3];
                // 确定子节点
                int child = (parent[v] == u) ? v : u;
                int ei = parentEdgeIdx[child];
                int delta = newW - edgeW[ei];
                edgeW[ei] = newW;
                update(1, 1, n, in[child], out[child], delta);
            }
        }
        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private void pushDown(int node) {
        if (lazy[node] != 0) {
            tree[2*node] += lazy[node]; lazy[2*node] += lazy[node];
            tree[2*node+1] += lazy[node]; lazy[2*node+1] += lazy[node];
            lazy[node] = 0;
        }
    }

    private void update(int node, int start, int end, int l, int r, long val) {
        if (r < start || end < l) return;
        if (l <= start && end <= r) { tree[node] += val; lazy[node] += val; return; }
        pushDown(node);
        int mid = (start + end) / 2;
        update(2*node, start, mid, l, r, val);
        update(2*node+1, mid+1, end, l, r, val);
    }

    private long query(int node, int start, int end, int idx) {
        if (start == end) return tree[node];
        pushDown(node);
        int mid = (start + end) / 2;
        return idx <= mid ? query(2*node, start, mid, idx) : query(2*node+1, mid+1, end, idx);
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + q) log n)
- 空间复杂度：O(n)

## 关键点总结

1. DFS 序将子树映射为连续区间，支持线段树区间操作
2. 更新边权时对子节点子树整体加 delta
3. 线段树 lazy 标记实现 O(log n) 区间加和单点查
