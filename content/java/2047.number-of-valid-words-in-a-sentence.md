## 题目描述

句子由小写字母、数字、连字符、标点（!.,）和空格组成，有效单词须满足：不含数字、最多一个末尾标点、最多一个两侧均为字母的连字符。返回有效单词数目。

## 解题思路

按空格分割后逐 token 验证：含数字无效；标点不在末尾无效；连字符超过一个或两侧非字母无效。

## Java 代码实现

### 方法一：逐 token 验证（推荐）

```java
class Solution {
    public int countValidWords(String sentence) {
        int count = 0;
        for (String token : sentence.split(" ")) {
            if (!token.isEmpty() && isValid(token)) count++;
        }
        return count;
    }

    private boolean isValid(String token) {
        int n = token.length();
        int hyphenCount = 0;
        for (int i = 0; i < n; i++) {
            char c = token.charAt(i);
            if (Character.isDigit(c)) return false; // 含数字
            if (c == '!' || c == '.' || c == ',') {
                if (i != n - 1) return false; // 标点不在末尾
            } else if (c == '-') {
                hyphenCount++;
                if (hyphenCount > 1) return false; // 超过一个连字符
                if (i == 0 || i == n - 1) return false; // 首尾无法两侧都有字母
                if (!Character.isLetter(token.charAt(i - 1)) ||
                    !Character.isLetter(token.charAt(i + 1))) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. `split(" ")` 而非 `split("\\s+")` 保留空串（多个空格产生的空 token）
2. 标点必须在末尾，连字符两侧必须是字母
