## 题目描述

给定长格式 DataFrame weather（每行含 month、city、temperature），将其转换为宽格式（每行一个城市，每列一个月份）。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.pivot(index='city', columns='month', values='temperature')` 长格式转宽格式。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.pivot(index, columns, values) 长格式转宽格式
// 等价于按行分组、列展开的二维表格转换

import java.util.*;

class Solution {
    // Java 中模拟 pivot：以 city 为行键，month 为列键，temperature 为值
    public Map<String, Map<String, Integer>> pivotTable(List<String[]> weather) {
        // weather[i] = [month, city, temperature]
        Map<String, Map<String, Integer>> result = new TreeMap<>();
        for (String[] row : weather) {
            String month = row[0], city = row[1];
            int temp = Integer.parseInt(row[2]);
            result.computeIfAbsent(city, k -> new TreeMap<>()).put(month, temp);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `df.pivot(index, columns, values)` 长格式转宽格式
2. 有重复键时用 `pivot_table` 指定聚合函数
3. 宽格式转长格式用 `pd.melt()`（2890 题）
