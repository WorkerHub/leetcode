## 题目描述

n人围坐，每数到第k个淘汰，求最后胜者编号（约瑟夫环）。

## 解题思路

约瑟夫环递推公式：f(1)=0，f(n)=(f(n-1)+k)%n，结果+1转为1-indexed。

## Java 代码实现

```java
class Solution {
    public int findTheWinner(int n, int k) {
        // 约瑟夫环递推
        int pos = 0; // 1人时胜者在位置0
        for (int i = 2; i <= n; i++) {
            pos = (pos + k) % i;
        }
        return pos + 1; // 转为1-indexed
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **约瑟夫环公式**：f(n)=(f(n-1)+k)%n
2. **0-indexed到1-indexed**：结果+1
3. **O(1)空间**：只维护一个变量
