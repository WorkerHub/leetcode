## 题目描述

每次可加1/5/15/60分钟，求将current时间转为correct时间的最少操作次数。

## 解题思路

贪心找零：计算分钟差，优先使用大步长(60→15→5→1)，每步取商累加操作数。

## Java 代码实现

```java
class Solution {
    public int convertTime(String current, String correct) {
        int cur = Integer.parseInt(current.substring(0, 2)) * 60 + Integer.parseInt(current.substring(3));
        int cor = Integer.parseInt(correct.substring(0, 2)) * 60 + Integer.parseInt(correct.substring(3));
        int diff = cor - cur;
        
        int ops = 0;
        int[] steps = {60, 15, 5, 1};
        for (int step : steps) {
            ops += diff / step;
            diff %= step;
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **时间转分钟**：HH*60+MM
2. **贪心从大到小**：60→15→5→1保证最少操作
3. **保证diff>=0**：题目保证correct>=current
