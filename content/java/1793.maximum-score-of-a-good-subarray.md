## 题目描述

子数组 `(i, j)` 的分数 = `min(nums[i..j]) * (j-i+1)`。**好子数组**满足 `i <= k <= j`。返回好子数组的最大分数。

## 解题思路

**双指针贪心**：从 k 出发，左右指针初始均在 k，每次向使当前最小值更大的方向扩展（比较 `nums[l-1]` 和 `nums[r+1]`），维护最小值并更新答案。

## Java 代码实现

```java
class Solution {
    public int maximumScore(int[] nums, int k) {
        int n = nums.length;
        int l = k, r = k;
        int minVal = nums[k];
        int ans = nums[k];

        while (l > 0 || r < n - 1) {
            // 向使最小值更大的方向扩展
            if (l == 0) {
                r++;
            } else if (r == n - 1) {
                l--;
            } else if (nums[l - 1] >= nums[r + 1]) {
                l--;
            } else {
                r++;
            }
            // 更新最小值和答案
            minVal = Math.min(minVal, Math.min(nums[l], nums[r]));
            ans = Math.max(ans, minVal * (r - l + 1));
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 子数组必须包含下标 k（好子数组定义）
2. 贪心：每次选择能保留较大最小值的扩展方向
3. 初始得分为 `nums[k]`（区间只有 k 时）
