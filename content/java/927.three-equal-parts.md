## 题目描述

给定由 0 和 1 组成的数组 arr，将其分成 3 个非空部分，使得三部分表示相同的二进制值。返回分割点 [i, j]，或 [-1, -1]。

**示例：**
```
输入：arr = [1,0,1,0,1]
输出：[0,3]（[1,0] [1,0] [1] 都表示 1）
```

## 解题思路

1 的总数必须是 3 的倍数。找到三部分第一个 1 的位置，以最后一部分为基准同步匹配三个指针。

## Java 代码实现

```java
class Solution {
    public int[] threeEqualParts(int[] arr) {
        int ones = 0;
        for (int x : arr) ones += x;

        if (ones % 3 != 0) return new int[]{-1, -1};
        if (ones == 0) return new int[]{0, 2};

        int target = ones / 3;
        int n = arr.length;

        // 找到三部分第一个 1 的位置
        int first = -1, second = -1, third = -1;
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 1) {
                count++;
                if (count == 1) first = i;
                else if (count == target + 1) second = i;
                else if (count == 2 * target + 1) third = i;
            }
        }

        // 从第三部分开始匹配，确保三部分相同
        while (third < n) {
            if (arr[first] != arr[second] || arr[second] != arr[third]) {
                return new int[]{-1, -1};
            }
            first++;
            second++;
            third++;
        }

        return new int[]{first - 1, second};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **1 的个数约束**：必须是 3 的倍数
2. **以最后一部分为基准**：它决定了尾部 0 的个数
3. **三指针同步匹配**：确保每一位都相同
