## 题目描述

字符串 s 只含 'Q','W','E','R'，长度为 n。平衡字符串要求四种字符各出现 n/4 次。通过替换一个子串使其平衡，求最小子串长度。

**示例：**
```
输入：s = "QQWE"
输出：1（替换一个 'Q' 为 'R'）
```

## 解题思路

滑动窗口：窗口外的字符每种都不超过 n/4 时，窗口内可以通过替换使整体平衡。找满足条件的最小窗口。

## Java 代码实现

```java
class Solution {
    public int balancedString(String s) {
        int n = s.length();
        int target = n / 4;
        int[] count = new int[128]; // 字符计数
        for (char c : s.toCharArray()) count[c]++;
        
        // 已经平衡
        if (count['Q'] == target && count['W'] == target 
            && count['E'] == target && count['R'] == target) {
            return 0;
        }
        
        int minLen = n;
        int left = 0;
        for (int right = 0; right < n; right++) {
            // 窗口扩大，从窗口外移入
            count[s.charAt(right)]--;
            
            // 当窗口外所有字符都 <= target 时，窗口合法
            while (count['Q'] <= target && count['W'] <= target
                   && count['E'] <= target && count['R'] <= target) {
                minLen = Math.min(minLen, right - left + 1);
                count[s.charAt(left)]++;
                left++;
            }
        }
        return minLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向思维**：不关心窗口内怎么替换，只需窗口外每种字符 ≤ n/4
2. **滑动窗口**：右边扩大找可行解，左边收缩找最优解
3. **减法思想**：扩大窗口 = 从窗口外"拿走"字符（count--）
