## 题目描述

给你一个字符串 `sentence` 作为句子，并指定检索词为 `searchWord`，其中句子由若干用**单个空格**分隔的单词组成。

请你检查检索词 `searchWord` 是否为句子 `sentence` 中任意单词的**前缀**。

- 如果 `searchWord` 是某一个单词的前缀，则返回句子 `sentence` 中该单词所对应的下标（**下标从 1 开始**）。
- 如果 `searchWord` 是多个单词的前缀，则返回匹配的第一个单词的下标。
- 如果 `searchWord` 不是任何单词的前缀，则返回 `-1`。

**示例 1：**
```
输入：sentence = "i love eating burger", searchWord = "burg"
输出：4
解释："burg" 是 "burger" 的前缀，"burger" 是句子第 4 个单词。
```

**示例 2：**
```
输入：sentence = "this problem is an easy problem", searchWord = "pro"
输出：2
解释："pro" 是 "problem" 的前缀，"problem" 分别是第 2 个和第 6 个单词，返回最小下标 2。
```

**示例 3：**
```
输入：sentence = "i am tired", searchWord = "you"
输出：-1
```

**提示：**
- `1 <= sentence.length <= 100`
- `1 <= searchWord.length <= 10`
- `sentence` 由小写英文字母和空格组成
- `searchWord` 由小写英文字母组成
- 句子中单词之间只有单个空格

## 解题思路

分割句子为单词列表，然后逐个检查每个单词是否以 `searchWord` 开头。

Java 的字符串方法 `startsWith()` 可以直接完成前缀判断，配合下标从 1 开始计数。

## Java 代码实现

### 方法一：split + startsWith（推荐）

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        // 分割句子为单词列表
        String[] words = sentence.split(" ");

        // 下标从 1 开始（题目要求 1-indexed）
        for (int i = 0; i < words.length; i++) {
            if (words[i].startsWith(searchWord)) {
                return i + 1;  // 返回第一个匹配的下标（1-indexed）
            }
        }

        return -1;  // 没有找到
    }
}
```

### 方法二：字符串切片手动判断前缀

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        String[] words = sentence.split(" ");
        int n = searchWord.length();

        for (int i = 0; i < words.length; i++) {
            // 手动检查前缀：截取单词前 n 个字符比较
            if (words[i].length() >= n && words[i].substring(0, n).equals(searchWord)) {
                return i + 1;
            }
        }

        return -1;
    }
}
```

### 方法三：indexOf 方法

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        String[] words = sentence.split(" ");

        for (int i = 0; i < words.length; i++) {
            // indexOf 返回 searchWord 在 word 中首次出现的位置
            // 如果是前缀，则出现在位置 0
            if (words[i].indexOf(searchWord) == 0) {
                return i + 1;
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × m)，n 为单词数，m 为 searchWord 长度
- 空间复杂度：O(n)，split 后的单词列表

## 关键点总结

1. `String.startsWith(prefix)` 是 Java 判断前缀的最简洁方式
2. 下标从 1 开始，`i + 1` 即可转换为 1-indexed
3. 遇到第一个匹配就立刻返回，自然保证返回最小下标

## 易错点

- 注意下标从 **1** 开始，不是 0；Java 数组下标从 0 开始，返回时需要 `i + 1`
- 不要混淆"前缀"和"包含"：`word.contains(searchWord)` 是包含，`word.startsWith(searchWord)` 才是前缀判断
- Java 字符串比较需要用 `equals()`，不能用 `==`
