## 题目描述

树中每个节点有值，可以收集节点的值（置零）获得分数，但要求每条从根到叶的路径至少有一个非零节点，求最大得分。

## 解题思路

树形DP：最大得分=总和-最小保留代价。对每个子树，保留代价=min(自身值, 所有子树保留代价之和)。

## Java 代码实现

```java
class Solution {
    private List<Integer>[] adj;
    private int[] values;

    public long maximumScoreAfterOperations(int[][] edges, int[] values) {
        int n = values.length;
        this.values = values;
        adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            adj[e[0]].add(e[1]);
            adj[e[1]].add(e[0]);
        }
        long total = 0;
        for (int v : values) total += v;
        // 最小保留代价
        return total - dfs(0, -1);
    }

    private long dfs(int u, int parent) {
        long childrenCost = 0;
        boolean isLeaf = true;
        for (int v : adj[u]) {
            if (v == parent) continue;
            isLeaf = false;
            childrenCost += dfs(v, u);
        }
        if (isLeaf) return values[u]; // 叶子必须保留
        // 要么保留自己，要么保留所有子树的最小代价
        return Math.min((long) values[u], childrenCost);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **转化为最小保留代价**：最大得分=总和-最小代价
2. **叶子必须保留**：每条路径至少一个非零
3. **非叶节点选择**：保留自己 vs 保留所有子树代价的较小值
