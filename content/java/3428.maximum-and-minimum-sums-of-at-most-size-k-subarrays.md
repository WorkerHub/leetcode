## 题目描述

给定整数数组 `nums` 和正整数 `k`，返回所有长度至多为 `k` 的非空子数组的最大值与最小值之和的总和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long minMaxSubarraySum(int[] nums, int k) {
        int n = nums.length;
        return sumOfExtremes(nums, n, k, true) + sumOfExtremes(nums, n, k, false);
    }

    private long sumOfExtremes(int[] nums, int n, int k, boolean isMax) {
        int[] leftBound = new int[n];
        int[] rightBound = new int[n];
        Arrays.fill(leftBound, -1);
        Arrays.fill(rightBound, n);

        Deque<Integer> stk = new ArrayDeque<>();

        // 计算 rightBound：右侧第一个不劣于当前的位置
        for (int i = 0; i < n; i++) {
            while (!stk.isEmpty() &&
                   (isMax ? nums[stk.peek()] <= nums[i] : nums[stk.peek()] >= nums[i])) {
                rightBound[stk.pop()] = i;
            }
            stk.push(i);
        }
        stk.clear();

        // 计算 leftBound：左侧第一个严格优于当前的位置（从右向左扫）
        for (int i = n - 1; i >= 0; i--) {
            while (!stk.isEmpty() &&
                   (isMax ? nums[stk.peek()] < nums[i] : nums[stk.peek()] > nums[i])) {
                leftBound[stk.pop()] = i;
            }
            stk.push(i);
        }

        long total = 0;
        for (int i = 0; i < n; i++) {
            int l = leftBound[i];  // 左边界（不含）
            int r = rightBound[i]; // 右边界（不含）
            int L = Math.max(l + 1, i - k + 1);
            int H = i;
            if (L > H) continue;

            // 分段计算贡献：lend 为子数组左端点，rend_max = min(r-1, lend+k-1)
            // Case 1: lend <= r-k-1，rend_max = lend+k-1，cnt = lend+k-i
            int a1 = L, b1 = Math.min(H, r - k - 1);
            if (a1 <= b1) {
                long cnt = b1 - a1 + 1;
                long sumLend = (long)(a1 + b1) * cnt / 2;
                long sum1 = cnt * (k - i) + sumLend;
                total += (long) nums[i] * sum1;
            }

            // Case 2: lend >= r-k，rend_max = r-1，cnt = r-i
            int a2 = Math.max(L, r - k), b2 = H;
            if (a2 <= b2) {
                long cnt = b2 - a2 + 1;
                total += (long) nums[i] * cnt * (r - i);
            }
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单调栈 + O(1) 贡献计算
- 空间复杂度：O(n)

## 关键点总结

1. 将问题拆分为"所有子数组最大值之和"与"最小值之和"分别计算
2. 单调栈找每个元素作为极值的左右边界，O(1) 公式计算它在长度 <= k 子数组中的贡献次数
3. 左右边界的严格/非严格判断要一致，避免重复计数
