## 题目描述

对数组中每个元素，求其与数组中所有元素的最大汉明距离。

## 解题思路

关键转化：max_hamming(x) = m - min_hamming(~x)。多源BFS从所有nums中的点出发，求超立方体上每点到nums的最短汉明距离，则ans[i] = m - dist[~nums[i]]。

## Java 代码实现

```java
class Solution {
    public int[] maximumHammingDistances(int[] nums, int m) {
        int size = 1 << m;
        int mask = size - 1;
        int[] dist = new int[size];
        Arrays.fill(dist, -1);

        // 多源BFS：从nums中所有点出发
        Queue<Integer> queue = new LinkedList<>();
        for (int x : nums) {
            if (dist[x] == -1) {
                dist[x] = 0;
                queue.offer(x);
            }
        }
        while (!queue.isEmpty()) {
            int x = queue.poll();
            for (int i = 0; i < m; i++) {
                int y = x ^ (1 << i);
                if (dist[y] == -1) {
                    dist[y] = dist[x] + 1;
                    queue.offer(y);
                }
            }
        }

        int[] ans = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            ans[i] = m - dist[~nums[i] & mask];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^m * m)
- **空间复杂度**：O(2^m)

## 关键点总结

1. **关键转化**：max_hamming(x) = m - dist[~x]
2. **多源BFS**在超立方体上扩散
3. **取反时需要& mask**只保留低m位
