## 题目描述

猫鼠博弈：无向图上老鼠从节点 1 出发，猫从节点 2 出发，节点 0 为洞。老鼠先手轮流移动。猫不能进洞。判断最优策略下谁赢（或平局）。

**示例：**
```
输入：graph = [[2,5],[3],[0,4,5],[1,4,5],[2,3],[0,2,3]]
输出：0（平局）
```

## 解题思路

拓扑排序 + BFS 逆推：从已知终态（猫抓到鼠、鼠入洞）逆推所有状态的胜负。

## Java 代码实现

```java
class Solution {
    public int catMouseGame(int[][] graph) {
        int n = graph.length;
        int DRAW = 0, MOUSE = 1, CAT = 2;

        // result[mouse][cat][turn]: 0-draw, 1-mouse wins, 2-cat wins
        int[][][] result = new int[n][n][3];
        int[][][] degree = new int[n][n][3];

        // 计算出度
        for (int m = 0; m < n; m++) {
            for (int c = 0; c < n; c++) {
                degree[m][c][1] = graph[m].length;
                for (int next : graph[c]) {
                    if (next != 0) degree[m][c][2]++;
                }
            }
        }

        // 初始化已知状态
        Queue<int[]> queue = new LinkedList<>();
        for (int i = 1; i < n; i++) {
            for (int t = 1; t <= 2; t++) {
                result[0][i][t] = MOUSE;
                queue.offer(new int[]{0, i, t, MOUSE});
                result[i][i][t] = CAT;
                queue.offer(new int[]{i, i, t, CAT});
            }
        }

        // BFS 逆推
        while (!queue.isEmpty()) {
            int[] state = queue.poll();
            int mouse = state[0], cat = state[1], turn = state[2], res = state[3];

            // 找前驱状态
            int prevTurn = turn == 1 ? 2 : 1;
            if (prevTurn == 1) { // 前一步是老鼠走
                for (int prevMouse : graph[mouse]) {
                    if (result[prevMouse][cat][1] != 0) continue;
                    if (res == MOUSE) {
                        result[prevMouse][cat][1] = MOUSE;
                        queue.offer(new int[]{prevMouse, cat, 1, MOUSE});
                    } else {
                        if (--degree[prevMouse][cat][1] == 0) {
                            result[prevMouse][cat][1] = CAT;
                            queue.offer(new int[]{prevMouse, cat, 1, CAT});
                        }
                    }
                }
            } else { // 前一步是猫走
                for (int prevCat : graph[cat]) {
                    if (prevCat == 0) continue;
                    if (result[mouse][prevCat][2] != 0) continue;
                    if (res == CAT) {
                        result[mouse][prevCat][2] = CAT;
                        queue.offer(new int[]{mouse, prevCat, 2, CAT});
                    } else {
                        if (--degree[mouse][prevCat][2] == 0) {
                            result[mouse][prevCat][2] = MOUSE;
                            queue.offer(new int[]{mouse, prevCat, 2, MOUSE});
                        }
                    }
                }
            }
        }

        return result[1][2][1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 关键点总结

1. **博弈逆推**：从终态逆推所有状态
2. **三维状态**：(鼠位置, 猫位置, 轮次)
3. **出度递减**：所有后继都输则当前输
