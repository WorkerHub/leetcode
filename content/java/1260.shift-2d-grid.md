## 题目描述

给定 m×n 网格 grid 和整数 k，执行 k 次移位（每次所有元素向右移一位，行末移到下一行首，末尾移到开头）。

**示例：**
```
输入：grid = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出：[[9,1,2],[3,4,5],[6,7,8]]
```

## 解题思路

将二维展开为一维，循环右移 k 位（等价于 k % (m*n)），再填回二维。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> shiftGrid(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        int total = m * n;
        k %= total;
        
        List<List<Integer>> result = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            List<Integer> row = new ArrayList<>();
            for (int j = 0; j < n; j++) {
                // 新位置 (i,j) 对应原位置 (i*n+j - k + total) % total
                int origIdx = (i * n + j - k + total) % total;
                row.add(grid[origIdx / n][origIdx % n]);
            }
            result.add(row);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **一维化**：二维坐标 (i,j) ↔ 一维索引 i*n+j
2. **取模**：k %= total 避免多余循环
3. **逆向映射**：新位置反推原位置
4. **公式**：原索引 = (新索引 - k + total) % total
