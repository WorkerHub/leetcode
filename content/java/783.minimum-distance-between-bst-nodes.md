## 题目描述

给定 BST 的根节点，返回任意两个不同节点值之间的最小差值。

**示例：**
```
输入：root = [4,2,6,1,3]
输出：1
```

## 解题思路

BST 中序遍历为递增序列，最小差值一定在相邻元素之间。维护前一个值，边遍历边计算。

## Java 代码实现

```java
class Solution {
    private int minDiff = Integer.MAX_VALUE;
    private Integer prev = null;

    public int minDiffInBST(TreeNode root) {
        inorder(root);
        return minDiff;
    }

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        if (prev != null) {
            minDiff = Math.min(minDiff, node.val - prev);
        }
        prev = node.val;
        inorder(node.right);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **BST 性质**：中序遍历有序
2. **相邻比较**：最小差值只在相邻节点间
3. **一次遍历**：边遍历边更新最小值
