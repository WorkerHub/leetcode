## 题目描述

给定 RGB 颜色字符串，找到与它最相似的"类似颜色"（每个分量两位十六进制相同，如 #aabbcc）。

**示例：**
```
输入：color = "#09f166"
输出："#11ee66"
```

## 解题思路

类似颜色值都是 17 的倍数（0x11=17）。对每个分量除以 17 四舍五入即可。

## Java 代码实现

```java
class Solution {
    public String similarRGB(String color) {
        return "#" + findSimilar(color.substring(1, 3))
                   + findSimilar(color.substring(3, 5))
                   + findSimilar(color.substring(5, 7));
    }

    private String findSimilar(String component) {
        int value = Integer.parseInt(component, 16);
        // 四舍五入到最近的 17 的倍数
        int nearest = Math.round((float) value / 17) * 17;
        return String.format("%02x", nearest);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **17 的倍数**：类似颜色的数值特征是 17 的倍数
2. **四舍五入**：value / 17 四舍五入后乘回 17
3. **格式化输出**：使用 %02x 确保两位小写十六进制
