## 题目描述

n座城市和roads，城市对(i,j)的网络秩=两城市度之和（共享道路只算一次）。求最大网络秩。

## 解题思路

枚举所有城市对，网络秩 = degree[i] + degree[j] - (直连则减1)。

## Java 代码实现

```java
class Solution {
    public int maximalNetworkRank(int n, int[][] roads) {
        int[] degree = new int[n];
        boolean[][] adj = new boolean[n][n];
        
        for (int[] road : roads) {
            int a = road[0], b = road[1];
            degree[a]++;
            degree[b]++;
            adj[a][b] = true;
            adj[b][a] = true;
        }
        
        int maxRank = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int rank = degree[i] + degree[j] - (adj[i][j] ? 1 : 0);
                maxRank = Math.max(maxRank, rank);
            }
        }
        return maxRank;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N² + M)
- **空间复杂度**：O(N²)

## 关键点总结

1. **网络秩公式**：degree[i]+degree[j]-直连标志
2. **邻接矩阵**：O(1)判断直连
3. **枚举所有对**：N≤100，O(N²)可行
