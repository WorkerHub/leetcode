## 题目描述

有一组物品，每个有值和标签。选最多 numWanted 个，每个标签最多用 useLimit 次，使值之和最大。

**示例：**
```
输入：values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1
输出：9
```

## 解题思路

贪心：按值降序排序，依次选择满足标签限制的物品。

## Java 代码实现

```java
class Solution {
    public int largestValsFromLabels(int[] values, int[] labels, int numWanted, int useLimit) {
        int n = values.length;
        // 按值降序排序（使用索引排序）
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> values[b] - values[a]);

        Map<Integer, Integer> labelCount = new HashMap<>();
        int total = 0, selected = 0;

        for (int idx : indices) {
            int label = labels[idx];
            int count = labelCount.getOrDefault(label, 0);
            if (count < useLimit) {
                total += values[idx];
                labelCount.put(label, count + 1);
                selected++;
                if (selected == numWanted) break;
            }
        }

        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：值大的优先选
2. **标签计数**：HashMap 记录每个标签已使用次数
3. **双重约束**：同时满足总数和标签限制
