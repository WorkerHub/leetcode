## 题目描述

给你一个大小为 m x n 的二元矩阵 grid ，矩阵中每个元素的值为 0 或 1 。

一次 移动 是指选择任一行或列，并转换该行或列中的每一个值：将所有 0 都更改为 1，将所有 1 都更改为 0。

在做出任意次数的移动后，将该矩阵的每一行都按照二进制数来解释，矩阵的 得分 就是这些数字的总和。

在执行任意次 移动 后（含 0 次），返回可能的最高分数。

**示例 1：**
```
输入：grid = [[0,0,1,1],[1,0,1,0],[1,1,0,0]]
输出：39
解释：0b1111 + 0b1001 + 0b1111 = 15 + 9 + 15 = 39
```

**示例 2：**
```
输入：grid = [[0]]
输出：1
```

**提示：**
- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 20
- grid[i][j] 为 0 或 1

## 解题思路

这道题的核心是**贪心策略**。

**关键观察：**
1. 最高位的权重最大：第一列的权重是 2^(n-1)，最后一列是 2^0
2. 第一列必须全是 1：翻转行使得第一列为 1
3. 其他列选择 1 更多的状态

**贪心策略：**
1. **行翻转**：保证每一行的第一位是 1（最高位）
2. **列翻转**：对于每一列，如果 0 的数量 > 1 的数量，就翻转该列

## Java 代码实现

### 方法一：贪心算法（推荐）

```java
class Solution {
    public int matrixScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 步骤1：翻转行，确保第一列全是 1
        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 0) {
                // 翻转整行
                for (int j = 0; j < n; j++) {
                    grid[i][j] ^= 1; // 异或翻转：0变1，1变0
                }
            }
        }

        // 步骤2：对每一列（除第一列外），如果0多就翻转
        for (int j = 1; j < n; j++) {
            int countOne = 0;
            for (int i = 0; i < m; i++) {
                countOne += grid[i][j];
            }
            // 如果 1 的数量 < 0 的数量，翻转这一列
            if (countOne < m - countOne) {
                for (int i = 0; i < m; i++) {
                    grid[i][j] ^= 1;
                }
            }
        }

        // 计算分数
        int result = 0;
        for (int[] row : grid) {
            int num = 0;
            for (int val : row) {
                num = num * 2 + val; // 二进制转十进制
            }
            result += num;
        }

        return result;
    }
}
```

### 方法二：不修改原数组（直接计算）

```java
class Solution {
    public int matrixScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;

        // 第一列全是 1，贡献 m * 2^(n-1)
        int result = m * (1 << (n - 1));

        // 对于每一列 j (j >= 1)
        for (int j = 1; j < n; j++) {
            int countOne = 0;
            for (int i = 0; i < m; i++) {
                // 如果这一行被翻转了（第一位原本是0），那么当前位也要翻转
                countOne += (grid[i][0] == grid[i][j]) ? 1 : 0;
            }
            // 选择 1 多的状态
            countOne = Math.max(countOne, m - countOne);
            result += countOne * (1 << (n - 1 - j));
        }

        return result;
    }
}
```

**代码说明：**
- `grid[i][0] == grid[i][j]` 巧妙判断翻转后的值（若第一位为1则保持，否则取反）
- 不修改原数组，直接计算最优结果

## 复杂度分析

- **时间复杂度**：O(m × n)，遍历矩阵。
- **空间复杂度**：O(1)，方法二不修改原数组。

## 关键点总结

1. **贪心策略**：高位优先，第一列必须全是 1
2. **行翻转**：根据第一位决定是否翻转整行
3. **列翻转**：选择 1 更多的状态
4. **位运算**：`^= 1` 翻转，`1 << k` 计算权重
5. **不修改原数组**：方法二最优雅

## 易错点

1. **翻转顺序**：必须先行后列

2. **列翻转判断**：比较 1 和 0 的数量，取较多者

3. **权重计算**：第 j 列的权重是 2^(n-1-j)

4. **边界情况**：第一列特殊处理，不参与列翻转
