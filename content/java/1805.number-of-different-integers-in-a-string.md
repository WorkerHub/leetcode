## 题目描述

给你由数字和小写字母组成的字符串 `word`，提取其中所有数字段，去重后（数值相同视为同一整数，忽略前导零）返回不同整数的个数。

## 解题思路

扫描字符串提取每个数字段，去除前导零后存入 HashSet，最终返回集合大小。由于数字可能超过 long 范围，用去除前导零后的字符串比较。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int numDifferentIntegers(String word) {
        Set<String> seen = new HashSet<>();
        int n = word.length(), i = 0;

        while (i < n) {
            if (Character.isDigit(word.charAt(i))) {
                // 跳过前导零
                while (i < n && word.charAt(i) == '0') i++;
                // 收集后续数字
                int start = i;
                while (i < n && Character.isDigit(word.charAt(i))) i++;
                seen.add(word.substring(start, i)); // 已去除前导零
            } else {
                i++;
            }
        }

        return seen.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 前导零不影响数值，需要先跳过前导零再截取字符串
2. 全零段（如 "000"）去除前导零后为空字符串，代表数值 0
3. 用字符串存入 HashSet 避免超出 long 范围
