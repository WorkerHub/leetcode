## 题目描述

给定两个整数，分别表示分数的分子 `numerator` 和分母 `denominator`，以字符串形式返回小数。

如果小数部分为循环小数，则将循环的部分括在括号内。

如果存在多个答案，只需返回任意一个。

对于所有给定的输入，保证答案字符串的长度小于 10^4。

**示例 1：**
```
输入：numerator = 1, denominator = 2
输出："0.5"
```

**示例 2：**
```
输入：numerator = 2, denominator = 1
输出："2"
```

**示例 3：**
```
输入：numerator = 4, denominator = 333
输出："0.(012)"
```

**提示：**
- -2^31 <= numerator, denominator <= 2^31 - 1
- denominator != 0

## 解题思路

这道题的核心是**模拟长除法过程**，并识别循环小数部分。

**关键观察：**
1. **整数部分**容易计算：`numerator / denominator`
2. **小数部分**通过不断取余数、乘以 10、再除以分母的方式计算
3. **循环识别**：当某个余数**第二次出现**时，说明进入循环
4. 使用**哈希表**记录每个余数第一次出现的位置

**算法流程：**
1. 处理符号（负数情况）
2. 计算整数部分
3. 计算小数部分，使用哈希表记录余数位置
4. 检测到重复余数时，插入括号

**边界情况：**
- 能整除的情况（无小数部分）
- 负数情况
- 0 的处理

## Java 代码实现

### 方法一：哈希表模拟长除法（推荐）⭐

```java
class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        // 处理零
        if (numerator == 0) return "0";

        StringBuilder result = new StringBuilder();

        // 处理符号：使用异或判断符号是否相反
        if ((numerator < 0) ^ (denominator < 0)) {
            result.append("-");
        }

        // 转为 long 避免溢出（-2^31 取绝对值会溢出 int）
        long num = Math.abs((long) numerator);
        long den = Math.abs((long) denominator);

        // 整数部分
        result.append(num / den);
        long remainder = num % den;

        // 能整除，直接返回
        if (remainder == 0) {
            return result.toString();
        }

        result.append(".");

        // 小数部分：哈希表记录余数首次出现的位置
        StringBuilder fractionPart = new StringBuilder();
        Map<Long, Integer> remainderMap = new HashMap<>();

        while (remainder != 0) {
            if (remainderMap.containsKey(remainder)) {
                // 找到循环起点，插入括号
                int insertIdx = remainderMap.get(remainder);
                fractionPart.insert(insertIdx, "(");
                fractionPart.append(")");
                break;
            }

            // 记录当前余数的位置
            remainderMap.put(remainder, fractionPart.length());

            // 模拟长除法
            remainder *= 10;
            fractionPart.append(remainder / den);
            remainder %= den;
        }

        result.append(fractionPart);
        return result.toString();
    }
}
```

### 方法二：优化的字符串构建

```java
class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        // 处理整除情况
        if (numerator % denominator == 0) {
            return String.valueOf(numerator / denominator);
        }

        StringBuilder result = new StringBuilder();

        // 处理符号
        if ((numerator < 0) ^ (denominator < 0)) {
            result.append("-");
        }

        // 转为 long 避免溢出
        long num = Math.abs((long) numerator);
        long den = Math.abs((long) denominator);

        // 整数部分
        result.append(num / den);
        result.append(".");

        // 小数部分
        long remainder = num % den;
        Map<Long, Integer> positionMap = new HashMap<>();
        StringBuilder fraction = new StringBuilder();

        while (remainder != 0 && !positionMap.containsKey(remainder)) {
            positionMap.put(remainder, fraction.length());
            remainder *= 10;
            fraction.append(remainder / den);
            remainder %= den;
        }

        // 检查是否有循环
        if (remainder != 0) {
            int insertIdx = positionMap.get(remainder);
            fraction.insert(insertIdx, "(");
            fraction.append(")");
        }

        result.append(fraction);
        return result.toString();
    }
}
```

## 复杂度分析

**时间复杂度：** O(D)
- D 是分母的大小，最多有 D 个不同的余数

**空间复杂度：** O(D)
- 哈希表存储余数，最多 D 个

## 图解示例

以 `4 / 333` 为例：

```
4 ÷ 333 = 0 ... 余 4
40 ÷ 333 = 0 ... 余 40   (位置0，记录 4 -> 0)
400 ÷ 333 = 1 ... 余 67  (位置1，记录 40 -> 1)
670 ÷ 333 = 2 ... 余 4   (位置2，记录 67 -> 2)
4 重复出现！循环从位置 0 开始

结果：0.(012)
```

## 关键点总结

1. **符号处理**：使用异或 `^` 确定结果符号
2. **循环检测**：哈希表记录余数首次出现位置
3. **长除法模拟**：余数乘 10 再除以分母
4. **边界情况**：整除、零、负数都需特殊处理
5. **使用 long**：Java 中 Integer.MIN_VALUE 的绝对值会溢出 int，必须转 long

## 易错点

1. **符号处理错误**
   - 错误：`numerator < 0 || denominator < 0`
   - 正确：`(numerator < 0) ^ (denominator < 0)` 使用异或

2. **整数溢出**
   - `-2^31` 取绝对值会溢出 int（结果仍是 -2^31）
   - 必须先转为 `long`：`Math.abs((long) numerator)`

3. **括号插入位置错误**
   - 应该在**循环开始的位置**插入左括号

4. **0 的特殊处理**
   - `0 / 任何数 = 0`，直接返回 "0"

5. **StringBuilder.insert**
   - Java 的 `StringBuilder.insert(index, str)` 在指定位置插入字符串
