## 题目描述

给你活动数组 `events[i] = [startDay, endDay, value]` 和整数 `k`（最多参加 k 个活动，同一天只能参加一个）。返回能获得的最大价值。

## 解题思路

按结束日期排序，DP + 二分查找：`dp[j][i]` 表示前 i 个活动最多参加 j 个的最大价值。对第 i 个活动，二分找最后一个结束日期 < 当前开始日期的活动位置 p，则 `dp[j][i] = max(dp[j][i-1], dp[j-1][p] + value_i)`。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxValue(int[][] events, int k) {
        // 按结束日期排序
        Arrays.sort(events, (a, b) -> a[1] - b[1]);
        int n = events.length;

        // endDays 用于二分查找
        int[] endDays = new int[n];
        for (int i = 0; i < n; i++) endDays[i] = events[i][1];

        // prev[i] = 前 i 个活动参加 j-1 个的最大价值（滚动）
        int[] prev = new int[n + 1];

        for (int j = 1; j <= k; j++) {
            int[] curr = new int[n + 1];
            for (int i = 1; i <= n; i++) {
                int start = events[i - 1][0];
                int val = events[i - 1][2];

                // 不参加第 i 个活动
                curr[i] = curr[i - 1];

                // 参加第 i 个活动：找最后一个结束日期 < start 的位置
                // 在 endDays[0..i-2] 中二分找第一个 >= start 的位置
                int lo = 0, hi = i - 1;
                while (lo < hi) {
                    int mid = (lo + hi) >>> 1;
                    if (endDays[mid] < start) lo = mid + 1;
                    else hi = mid;
                }
                // lo 是第一个 >= start 的，lo-1 之前的活动均不重叠（但这里找 < start）
                // 用 bisect_left 找 < start 的个数
                int p = lowerBound(endDays, 0, i - 1, start);
                curr[i] = Math.max(curr[i], prev[p] + val);
            }
            prev = curr;
        }

        return prev[n];
    }

    // 返回 [lo, hi) 中第一个 >= target 的位置（lower_bound）
    private int lowerBound(int[] arr, int lo, int hi, int target) {
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * k * log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 按结束日期排序后，DP 转移用二分查找前驱活动
2. 活动结束日期包含当天，下一个活动的开始日期必须 > 当前结束日期
