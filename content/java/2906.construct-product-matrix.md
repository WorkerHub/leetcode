## 题目描述

给你 p×q 整数矩阵 grid，构建新矩阵 ans，其中 `ans[i][j]` 等于除 `grid[i][j]` 以外所有元素之积，结果对 12345 取余。

## 解题思路

将二维矩阵展开为一维处理。先正向扫描存前缀积，再反向扫描乘后缀积，两步合一原地完成，无需额外数组。

## Java 代码实现

```java
class Solution {
    public int[][] constructProductMatrix(int[][] grid) {
        final int MOD = 12345;
        int p = grid.length, q = grid[0].length;
        int n = p * q;
        int[][] ans = new int[p][q];

        // 正向：ans[i][j] 先存其左侧所有元素的前缀积
        long prod = 1;
        for (int k = 0; k < n; k++) {
            int i = k / q, j = k % q;
            ans[i][j] = (int) prod;
            prod = prod * grid[i][j] % MOD;
        }

        // 反向：乘上右侧所有元素的后缀积
        long suffix = 1;
        for (int k = n - 1; k >= 0; k--) {
            int i = k / q, j = k % q;
            ans[i][j] = (int) (ans[i][j] * suffix % MOD);
            suffix = suffix * grid[i][j] % MOD;
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(p×q)，两次线性扫描
- **空间复杂度**：O(1)，输出矩阵不算额外空间

## 关键点总结

1. 二维坐标与一维下标互转：`i = k/q, j = k%q`
2. 前缀积和后缀积原地合并，正向存前缀积、反向乘后缀积
3. 模数是 12345，注意不是常见的 10^9+7
