## 题目描述

给你整数数组 `nums` 和整数 `k`，返回元素最大公因数恰好等于 `k` 的子数组数目。

## 解题思路

枚举每个起点 `i`，向右扩展维护当前子数组的 GCD。若 GCD 等于 k 则计数，若小于 k 则提前终止（GCD 单调不增，后续只会更小）。

## Java 代码实现

```java
class Solution {
    public int subarrayGCD(int[] nums, int k) {
        int n = nums.length;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            int curGcd = 0;
            for (int j = i; j < n; j++) {
                curGcd = gcd(curGcd, nums[j]);
                if (curGcd == k) {
                    ans++;
                } else if (curGcd < k) {
                    break; // GCD 只会减小，不可能再等于 k
                }
            }
        }
        return ans;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × log(maxVal))
- **空间复杂度**：O(1)

## 关键点总结

1. GCD 随子数组增长单调不增，可提前终止
2. `gcd(0, x) = x`，初始化为 0 方便处理第一个元素
3. 只有 k 的倍数才能使 GCD 等于 k，可进一步剪枝
