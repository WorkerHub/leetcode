## 题目描述

交互题：调用 `commonSetBits(num)` 返回 num 与隐藏数 n 按位与的置位数，最多调用 30 次，返回隐藏整数 n（1 <= n <= 2^30）。

## 解题思路

与 3064 完全相同：逐位询问，对第 i 位调用 `commonSetBits(1 << i)`，若返回值 > 0 则 n 的第 i 位为 1，30 次覆盖全部位。

## Java 代码实现

```java
/**
 * 接口由 LeetCode 提供
 * int commonSetBits(int num);
 */
class Solution {
    public int findNumber() {
        int n = 0;
        for (int i = 0; i < 30; i++) {
            // 询问第 i 位是否为 1
            if (commonSetBits(1 << i) > 0) {
                n |= (1 << i);
            }
        }
        return n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(30) = O(1)，恰好 30 次询问
- **空间复杂度**：O(1)

## 关键点总结

1. 每次只询问一个位（2 的幂次方），独立确定每一位
2. 30 次询问覆盖位 0 到 29，完全确定 n 的值
3. n 的范围是 1 到 2^30，需要询问 30 位
