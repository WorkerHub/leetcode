## 题目描述

字符串数组中每个字符串字母不重复，通过添加/删除/替换一个字符可连通的字符串归为同组，求组数和最大组大小。

## 解题思路

每个字符串用26位掩码表示，并查集合并掩码相同或相差一位（添加/删除）或交换一位（替换）的字符串。

## Java 代码实现

```java
class Solution {
    int[] parent, size;
    
    public int[] groupStrings(String[] words) {
        int n = words.length;
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
        
        // mask -> 第一个出现的下标
        Map<Integer, Integer> maskToIdx = new HashMap<>();
        int[] masks = new int[n];
        
        for (int i = 0; i < n; i++) {
            int mask = 0;
            for (char c : words[i].toCharArray()) {
                mask |= 1 << (c - 'a');
            }
            masks[i] = mask;
            if (maskToIdx.containsKey(mask)) {
                union(i, maskToIdx.get(mask));
            } else {
                maskToIdx.put(mask, i);
            }
        }
        
        for (int i = 0; i < n; i++) {
            int mask = masks[i];
            for (int b = 0; b < 26; b++) {
                // 添加或删除一位
                int nm = mask ^ (1 << b);
                if (maskToIdx.containsKey(nm)) {
                    union(i, maskToIdx.get(nm));
                }
                // 替换：删除b位后添加另一位
                if ((mask >> b & 1) == 1) {
                    int base = mask ^ (1 << b);
                    for (int b2 = 0; b2 < 26; b2++) {
                        if ((base >> b2 & 1) == 0) {
                            int nm2 = base | (1 << b2);
                            if (maskToIdx.containsKey(nm2)) {
                                union(i, maskToIdx.get(nm2));
                            }
                        }
                    }
                }
            }
        }
        
        // 统计组数和最大组大小
        int groups = 0, maxSize = 0;
        for (int i = 0; i < n; i++) {
            if (find(i) == i) {
                groups++;
                maxSize = Math.max(maxSize, size[i]);
            }
        }
        return new int[]{groups, maxSize};
    }
    
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    
    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (size[px] < size[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        size[px] += size[py];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * 26^2)
- **空间复杂度**：O(N)

## 关键点总结

1. **位掩码表示字符集**：每个字母最多出现一次，恰好对应26位
2. **三种连通操作**：相同掩码、差一位（增删）、交换一位（替换）
3. **并查集按大小合并**：高效合并连通分量
