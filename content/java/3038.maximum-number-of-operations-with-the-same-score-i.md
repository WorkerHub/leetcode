## 题目描述

每次取数组前两个元素相加为分数，所有操作分数必须相同，求最多操作次数。

## 解题思路

第一次操作确定目标分数，之后连续取前两个元素检查是否等于目标。

## Java 代码实现

```java
class Solution {
    public int maxOperations(int[] nums) {
        int n = nums.length;
        if (n < 2) return 0;
        int target = nums[0] + nums[1];
        int count = 0;
        for (int i = 0; i + 1 < n; i += 2) {
            if (nums[i] + nums[i + 1] == target) {
                count++;
            } else {
                break;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **目标分数由第一次操作决定**
2. **步长为2连续取**：不满足则立即停止
3. **不能跳过不匹配的对**
