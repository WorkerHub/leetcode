## 题目描述

给你 `logs[i] = [ID, time]` 和整数 `k`，统计每种 UAM 值（1~k）对应的用户数。UAM = 用户操作的唯一分钟数。

## 解题思路

用 HashMap<Integer, Set<Integer>> 记录每个用户操作的唯一时间，再统计各 UAM 值的用户数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] findingUsersActiveMinutes(int[][] logs, int k) {
        Map<Integer, Set<Integer>> userTimes = new HashMap<>();

        for (int[] log : logs) {
            int uid = log[0], time = log[1];
            userTimes.computeIfAbsent(uid, x -> new HashSet<>()).add(time);
        }

        int[] answer = new int[k];
        for (Set<Integer> times : userTimes.values()) {
            int uam = times.size();
            if (uam <= k) answer[uam - 1]++;
        }

        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 用 Set 自动去重，每个用户同一分钟多次操作只算一次
2. 结果数组下标：UAM 值 j 对应 answer[j-1]
