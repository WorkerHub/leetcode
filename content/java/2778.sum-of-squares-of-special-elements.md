## 题目描述

给你整数数组 `nums`，若下标 `i`（1-indexed）能整除数组长度 `n`，则 `nums[i]` 为特殊元素，返回所有特殊元素的平方和。

## Java 代码实现

```java
class Solution {
    public int sumOfSquares(int[] nums) {
        int n = nums.length, ans = 0;
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) {
                ans += nums[i - 1] * nums[i - 1];
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 下标从 1 开始，`i` 能整除 `n` 即为特殊元素
2. 注意数组访问使用 `nums[i-1]`（0-indexed）
3. 直接枚举所有下标判断即可
