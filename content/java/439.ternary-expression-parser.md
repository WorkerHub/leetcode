## 题目描述

给定一个由数字、字母、`'?'` 和 `':'` 组成的字符串，表示一个三元表达式，请你对其进行求值并返回结果。

三元表达式的格式为 `条件 ? 值1 : 值2`，其中条件为 `'T'`（true）或 `'F'`（false）。

**示例 1：**
```
输入：expression = "T?2:3"
输出："2"
解释：如果条件为真，结果为2；如果条件为假，结果为3。
```

**示例 2：**
```
输入：expression = "F?1:T?4:5"
输出："4"
解释：条件表达式从右向左结合。相当于 F ? 1 : (T ? 4 : 5) = (T ? 4 : 5) = 4
```

**示例 3：**
```
输入：expression = "T?T?F:5:3"
输出："F"
解释：条件表达式从右向左结合。相当于 T ? (T ? F : 5) : 3 = (T ? F : 5) = F
```

**提示：**
- `5 <= expression.length <= 10^4`
- `expression` 由数字、`'T'`、`'F'`、`'?'` 和 `':'` 组成
- 保证是一个有效的三元表达式，并且每个数字都是一位数

## 解题思路

这道题要求解析并求值三元表达式。核心思想是从右向左使用栈处理。

**关键观察：**
1. 三元表达式是右结合的：`a?b:c?d:e` = `a?b:(c?d:e)`
2. 从右向左扫描更容易处理
3. 可以使用栈或递归

**算法流程（栈）：**
1. 从右向左遍历表达式
2. 遇到普通字符（数字、T、F）入栈
3. 遇到 `?` 时，弹出 trueVal 和 falseVal，读取条件，根据条件压入结果
4. 遇到 `:` 跳过（不入栈）

## Java 代码实现

### 方法一：栈（从右向左）⭐ 推荐

```java
import java.util.*;

class Solution {
    public String parseTernary(String expression) {
        Deque<Character> stack = new ArrayDeque<>();
        int i = expression.length() - 1;
        
        while (i >= 0) {
            char c = expression.charAt(i);
            
            if (c != '?' && c != ':') {
                // 普通字符（数字、T、F）直接入栈
                stack.push(c);
            } else if (c == '?') {
                // 弹出 trueVal 和 falseVal
                char trueVal = stack.pop();
                char falseVal = stack.pop();
                
                // 获取条件（? 左边的字符）
                i--;
                char condition = expression.charAt(i);
                
                // 根据条件选择压入结果
                stack.push(condition == 'T' ? trueVal : falseVal);
            }
            // ':' 不处理，直接跳过
            
            i--;
        }
        
        return String.valueOf(stack.peek());
    }
}
```

### 方法二：栈（改进版）

```java
import java.util.*;

class Solution {
    public String parseTernary(String expression) {
        Deque<Character> stack = new ArrayDeque<>();
        
        // 从右向左遍历
        for (int i = expression.length() - 1; i >= 0; i--) {
            char c = expression.charAt(i);
            
            if (!stack.isEmpty() && stack.peek() == '?') {
                // 当前字符是条件
                stack.pop();  // 弹出 '?'
                char trueVal = stack.pop();
                stack.pop();  // 弹出 ':'
                char falseVal = stack.pop();
                
                stack.push(c == 'T' ? trueVal : falseVal);
            } else {
                stack.push(c);
            }
        }
        
        return String.valueOf(stack.peek());
    }
}
```

### 方法三：递归

```java
class Solution {
    public String parseTernary(String expression) {
        return parse(expression);
    }
    
    private String parse(String s) {
        if (s.length() == 1) return s;
        
        // 找到第一个 '?' 对应的 ':'（要考虑嵌套）
        char condition = s.charAt(0);
        int count = 0;
        int colonIdx = 0;
        
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == '?') {
                count++;
            } else if (s.charAt(i) == ':') {
                if (count == 0) {
                    colonIdx = i;
                    break;
                }
                count--;
            }
        }
        
        // 分割出 truePart 和 falsePart
        String truePart = s.substring(2, colonIdx);
        String falsePart = s.substring(colonIdx + 1);
        
        // 根据条件递归求值
        if (condition == 'T') {
            return parse(truePart);
        } else {
            return parse(falsePart);
        }
    }
}
```

### 方法四：优化递归（索引版）

```java
class Solution {
    private int index;
    
    public String parseTernary(String expression) {
        index = 0;
        return String.valueOf(parse(expression));
    }
    
    private char parse(String expression) {
        // 读取当前字符
        char c = expression.charAt(index++);
        
        // 如果后面有 '?'，说明这是一个条件
        if (index < expression.length() && expression.charAt(index) == '?') {
            index++;  // 跳过 '?'
            
            // 解析 true 部分
            char trueVal = parse(expression);
            
            index++;  // 跳过 ':'
            
            // 解析 false 部分
            char falseVal = parse(expression);
            
            // 根据条件返回
            return c == 'T' ? trueVal : falseVal;
        } else {
            // 叶子节点，直接返回
            return c;
        }
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O(n)，n 是表达式长度
  - 每个字符最多访问常数次
- 空间复杂度：O(n)
  - 栈或递归的深度

## 图解示例

以 `expression = "T?T?F:5:3"` 为例：

```
从右向左扫描（方法一）：

步骤1：i=8, '3' 不是 '?' 也不是 ':'，入栈
栈：[3]

步骤2：i=7, ':' 跳过
栈：[3]

步骤3：i=6, '5' 入栈
栈：[3, 5]

步骤4：i=5, ':' 跳过
栈：[3, 5]

步骤5：i=4, 'F' 入栈
栈：[3, 5, F]

步骤6：i=3, '?' 处理
弹出 trueVal=F，弹出 falseVal=5
i-=1, i=2, condition='T'
condition=='T'，压入 F
栈：[3, F]

步骤7：i=1, ':' 跳过，i-=1
步骤8：i=0, '?' 处理
弹出 trueVal=F，弹出 falseVal=3
i-=1, i=-1（注意这里 i 已为 -1，循环会在步骤结束后退出）
condition='T'（来自 i=0 的 '?' 处理中读取的 i-- 操作，实际上条件 T 是下标 0，而 ? 是下标 1）
```

**正确流程说明：** 在方法一中，当 `i=1` 遇到 `?` 时：`i--` 得到 `i=0`，读取 `expression.charAt(0)='T'` 为条件，然后循环末尾 `i--` 得到 `i=-1`，循环结束。

```
结果：F
```

## 关键点总结

1. **右结合性**：三元表达式从右向左结合
2. **栈的使用**：从右向左扫描，用栈存储中间结果
3. **嵌套处理**：要正确处理嵌套的三元表达式
4. **递归思路**：也可以用递归自然地处理嵌套
5. **索引管理**：要正确维护当前处理位置

## 易错点

1. **结合方向**：要从右向左处理
2. **栈操作顺序**：先弹出的是 trueVal（因为它更靠右/靠近 ?）
3. **冒号处理**：遇到 `:` 要跳过，不入栈
4. **嵌套问题**：递归时要找到正确的 `:` 位置
5. **索引管理**：方法一中 `i--` 既在 `?` 分支内部用于获取条件，也在循环末尾用于前进
