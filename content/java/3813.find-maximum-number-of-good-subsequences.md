## 题目描述

给定整数数组 `nums`，"好子序列"是相邻元素差的绝对值不超过 1 的子序列，返回所有好子序列的数目（模 `10^9+7`）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countGoodSubsequences(int[] nums) {
        final int MOD = 1_000_000_007;
        // dp.get(v) = 以值 v 结尾的好子序列数
        Map<Integer, Long> dp = new HashMap<>();

        for (int v : nums) {
            long prev = dp.getOrDefault(v, 0L);
            // 可以接在 v-1, v, v+1 结尾的子序列后面，或单独成序列
            long newCount = (dp.getOrDefault(v - 1, 0L)
                           + prev
                           + dp.getOrDefault(v + 1, 0L) + 1) % MOD;
            dp.put(v, newCount);
        }

        long total = 0;
        for (long cnt : dp.values()) total = (total + cnt) % MOD;
        return (int) total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 哈希表 DP：按元素值记录以该值结尾的好子序列数
2. 当前元素 v 可以接在值为 v-1、v、v+1 的子序列后，或单独成序列（+1）
3. 更新 dp[v] 前先保存旧值，防止用更新后的值计算
