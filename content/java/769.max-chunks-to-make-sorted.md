## 题目描述

给定一个长度为 `n` 的整数数组 `arr`，它表示在 `[0, n - 1]` 范围内的整数的排列。

将 `arr` 分割成若干块，对每个块单独排序后再连接起来，使得连接的结果和按升序排序后的原数组相同。

返回数组能分成的最多块数量。

**示例 1:**
```
输入: arr = [4,3,2,1,0]
输出: 1
```

**示例 2:**
```
输入: arr = [1,0,2,3,4]
输出: 4
```

## 解题思路

对于位置 i，如果前 i+1 个元素的最大值等于 i，说明可以在此处分块。

## Java 代码实现

```java
class Solution {
    public int maxChunksToSorted(int[] arr) {
        int chunks = 0;
        int maxVal = 0;

        for (int i = 0; i < arr.length; i++) {
            // 更新前缀最大值
            maxVal = Math.max(maxVal, arr[i]);
            // 如果最大值等于索引，说明可以切分一块
            if (maxVal == i) {
                chunks++;
            }
        }

        return chunks;
    }
}
```

## 复杂度分析

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 关键点总结

1. **分块条件：** 最大值等于索引
2. **一次遍历**
3. **贪心策略**
