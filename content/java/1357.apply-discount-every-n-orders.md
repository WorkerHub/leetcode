## 题目描述

有一个超市，超市里有 `n` 件商品。超市给每隔 `n` 位顾客（第 `n`、`2n`、`3n`……位）提供折扣。

请你实现 `Cashier` 类：
- `Cashier(int n, int discount, int[] products, int[] prices)` — 初始化对象，其中 `n` 表示每 n 个顾客一次折扣，`discount` 是折扣的百分比，`products` 和 `prices` 分别为商品编号和价格的数组（对应关系）。
- `double getBill(int[] product, int[] amount)` — 返回账单的总金额。`product[i]` 是第 i 件商品的编号，`amount[i]` 是购买数量。如果当前顾客是享受折扣的顾客（第 n、2n…位），则账单打折。最终结果需保留小数。

**示例：**
```
输入：
["Cashier","getBill","getBill","getBill","getBill","getBill","getBill","getBill"]
[[3,50,[1,2,3,4,5,6,7],[100,200,300,400,300,200,100]],
 [[1,2],[1,2]],[[3,7],[10,10]],[[1,2,3,4,5,6,7],[1,1,1,1,1,1,1]],
 [[4],[10]],[[7,3],[10,10]],[[7,5,3,1,6,4,2],[10,10,10,9,9,9,7]],
 [[2,3,5],[5,3,2]]]
输出：[null,500.0,4000.0,800.0,4000.0,4000.0,7350.0,2500.0]
```

**提示：**
- `1 <= n <= 10^4`
- `0 <= discount <= 100`
- `1 <= products.length <= 200`
- `1 <= products[i] <= 200`
- `products` 数组中的元素各不相同
- `prices.length == products.length`
- `1 <= prices[i] <= 1000`
- `getBill` 最多被调用 1000 次

## 解题思路

这道题是直接模拟题，核心逻辑简单：

1. 在构造函数中建立商品价格的哈希表，维护顾客计数器。
2. 在 `getBill` 中：
   - 顾客计数器加 1。
   - 按商品和数量计算总价。
   - 判断是否是第 n、2n、3n… 位顾客（即计数器能被 n 整除），是则打折。

折扣计算：原价 `total` 打 `discount` 折扣后为 `total * (100 - discount) / 100`。

## Java 代码实现

### 方法一：HashMap + 计数器（推荐）

```java
import java.util.*;

class Cashier {
    private int n;           // 每隔 n 位顾客享受折扣
    private int discount;    // 折扣百分比（如 50 表示打五折）
    private int count;       // 顾客计数器
    private Map<Integer, Integer> priceMap; // 商品编号到价格的映射
    
    public Cashier(int n, int discount, int[] products, int[] prices) {
        this.n = n;
        this.discount = discount;
        this.count = 0;
        // 建立商品编号到价格的哈希表
        priceMap = new HashMap<>();
        for (int i = 0; i < products.length; i++) {
            priceMap.put(products[i], prices[i]);
        }
    }
    
    public double getBill(int[] product, int[] amount) {
        count++; // 新顾客来了，计数加 1
        
        // 计算总价 = sum(单价 * 数量)
        double total = 0;
        for (int i = 0; i < product.length; i++) {
            total += priceMap.get(product[i]) * amount[i];
        }
        
        // 是第 n、2n、3n... 位顾客则享受折扣
        if (count % n == 0) {
            total = total * (100 - discount) / 100.0;
        }
        
        return total;
    }
}
```

### 方法二：数组代替哈希表（更高效）

```java
class Cashier {
    private int n;
    private int discount;
    private int count;
    private int[] prices; // 直接用商品编号作为下标（编号 1-200）
    
    public Cashier(int n, int discount, int[] products, int[] priceArr) {
        this.n = n;
        this.discount = discount;
        this.count = 0;
        // 商品编号范围 1-200，用数组代替哈希表
        prices = new int[201];
        for (int i = 0; i < products.length; i++) {
            prices[products[i]] = priceArr[i];
        }
    }
    
    public double getBill(int[] product, int[] amount) {
        count++;
        
        double total = 0;
        for (int i = 0; i < product.length; i++) {
            total += (long) prices[product[i]] * amount[i];
        }
        
        // 判断是否享受折扣
        if (count % n == 0) {
            total = total * (100 - discount) / 100.0;
        }
        
        return total;
    }
}
```

## 复杂度分析

- 构造函数时间复杂度：O(P)，P 是商品数量，建立哈希表。
- `getBill` 时间复杂度：O(Q)，Q 是本次购买的商品种数。
- 空间复杂度：O(P)，存储商品价格的哈希表。

## 关键点总结

1. 用哈希表存储商品价格，实现 O(1) 查询。
2. 维护顾客计数器 `count`，每次 `getBill` 时加 1，用 `count % n == 0` 判断是否打折。
3. 折扣计算：`total * (100 - discount) / 100.0`，注意除以浮点数（不是整数除法）。
4. 题目保证 `product` 中的商品编号都在初始化时提供过，无需处理未知商品。

## 易错点

- 折扣是"减去 discount%"，而非"乘以 discount%"。折后价格 = 原价 * (1 - discount/100) = 原价 * (100-discount)/100。
- 计数器必须在每次 `getBill` 开头就加 1（先到先得），不能在最后加。
- 注意 Java 整数除法：`(100 - discount) / 100` 如果是整数运算会截断，需要写成 `/ 100.0` 确保浮点除法。
