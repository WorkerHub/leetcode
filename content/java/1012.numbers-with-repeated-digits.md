## 题目描述

给定正整数 `n`，返回在 `[1, n]` 范围内具有至少 1 位重复数字的正整数的个数。

**示例 1：**
```
输入：n = 20
输出：1
解释：只有 11 包含重复的数字。
```

**示例 2：**
```
输入：n = 100
输出：10
解释：包含重复数字的数字是：11, 22, 33, 44, 55, 66, 77, 88, 99, 100
```

**示例 3：**
```
输入：n = 1000
输出：262
```

**提示：**
- `1 <= n <= 10^9`

## 解题思路

这是一道经典的数位DP问题。与其直接计算有重复数字的个数，不如计算没有重复数字的个数，然后用总数减去。

**核心思想**：
- 答案 = n - (没有重复数字的个数)
- 计算不大于n且无重复数字的数的个数

**分两部分计算**：
1. 位数小于n的无重复数字的数
2. 位数等于n的无重复数字的数

## Java 代码实现

### 方法一：数位DP（推荐）

```java
class Solution {
    public int numDupDigitsAtMostN(int n) {
        // 将n转为数字列表
        int[] digits = getDigits(n);
        int numDigits = digits.length;

        int countNoDup = 0; // 无重复数字的个数

        // 1. 计算位数小于n的无重复数字的数
        for (int i = 1; i < numDigits; i++) {
            if (i == 1) {
                // 1位数：1-9，共9个
                countNoDup += 9;
            } else {
                // i位数：首位1-9共9种选择，其余位从剩余9个数字中选
                countNoDup += 9 * permutation(9, i - 1);
            }
        }

        // 2. 计算位数等于n的无重复数字的数
        boolean[] used = new boolean[10]; // 已使用的数字
        boolean complete = true; // 是否遍历完所有位

        for (int i = 0; i < numDigits; i++) {
            int d = digits[i];

            // 计算当前位填小于d的数字的方案数
            int start = (i == 0) ? 1 : 0; // 首位不能为0
            for (int smaller = start; smaller < d; smaller++) {
                if (!used[smaller]) {
                    // 剩余位数
                    int remaining = numDigits - i - 1;
                    // 可用数字个数（10个数字 - 已使用数量 - 1个刚选的）
                    int available = 10 - countUsed(used) - 1;
                    countNoDup += permutation(available, remaining);
                }
            }

            // 如果当前数字已使用过，后续不可能无重复
            if (used[d]) {
                complete = false;
                break;
            }

            used[d] = true;
        }

        // 如果n本身无重复数字，也算一个
        if (complete) countNoDup++;

        return n - countNoDup;
    }

    // 计算排列数 A(m, k) = m * (m-1) * ... * (m-k+1)
    private int permutation(int m, int k) {
        if (k == 0) return 1;
        int result = 1;
        for (int i = 0; i < k; i++) {
            result *= (m - i);
        }
        return result;
    }

    // 将数字n分解为各位数字数组
    private int[] getDigits(int n) {
        String s = String.valueOf(n);
        int[] digits = new int[s.length()];
        for (int i = 0; i < s.length(); i++) {
            digits[i] = s.charAt(i) - '0';
        }
        return digits;
    }

    // 统计 used 数组中已使用的数字个数
    private int countUsed(boolean[] used) {
        int cnt = 0;
        for (boolean b : used) if (b) cnt++;
        return cnt;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(D²)，D为n的位数，最多10位
  - 外层循环D次
  - 内层循环最多10次
  - 排列数计算O(D)
- **空间复杂度**：O(D)，存储数字和已使用集合

## 图解示例

以 n = 100 为例：

```
100的数字表示：[1, 0, 0]
长度为3

第一部分：位数小于3的无重复数字
- 1位数：1-9，共9个
- 2位数：首位1-9(9种)，第二位从剩余9个选1个
  9 * A(9,1) = 9 * 9 = 81个
小计：90个

第二部分：3位数且≤100的无重复数字
首位只能填1（因为首位范围[1, digits[0])=[1,1)为空）
首位填1后，第二位可以填0
  剩余1位，可用8个数字
  A(8, 1) = 8
100本身：1已用，0已用，0重复 → 不算

无重复总数 = 90 + ... 
有重复 = 100 - 90 = 10
```

## 关键点总结

1. **反向思考**：计算无重复数字更简单
2. **分段计算**：位数小于n + 位数等于n
3. **排列组合**：A(m,n) = m!/(m-n)!
4. **数位DP**：逐位枚举，维护已使用数字
5. **提前终止**：发现重复数字立即break

## 易错点

1. **首位不能为0**：多位数的首位只能是1-9
2. **排列数计算**：是排列不是组合，顺序重要
3. **边界条件**：n本身是否无重复要单独判断
4. **已使用集合**：要正确维护used数组
5. **循环范围**：第i位的范围要根据是否首位决定
