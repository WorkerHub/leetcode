## 题目描述

DNA 序列由一系列核苷酸组成，缩写为 `'A'`、`'C'`、`'G'` 和 `'T'`。

例如，`"ACGAATTCCG"` 是一个 DNA 序列。

在研究 DNA 时，识别 DNA 中的重复序列非常有用。

给定一个表示 DNA 序列的字符串 `s`，返回所有在 DNA 分子中出现不止一次的长度为 `10` 的序列（子字符串）。你可以按任意顺序返回答案。

**示例 1：**
```
输入：s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
输出：["AAAAACCCCC","CCCCCAAAAA"]
```

**示例 2：**
```
输入：s = "AAAAAAAAAAAAA"
输出：["AAAAAAAAAA"]
```

**提示：**
- `1 <= s.length <= 10^5`
- `s[i]` 为 `'A'`、`'C'`、`'G'` 或 `'T'`

## 解题思路

这道题的核心是找出所有**重复出现**的长度为 10 的子串。

### 基本思路

使用**滑动窗口 + 哈希表**：
1. 用滑动窗口遍历所有长度为 10 的子串
2. 用哈希表记录每个子串出现的次数
3. 返回出现次数大于 1 的子串

### 优化思路

由于 DNA 只有 4 种字符（A, C, G, T），可以用**位运算**优化：
- 用 2 位二进制表示一个字符：A=00, C=01, G=10, T=11
- 10 个字符只需要 20 位（一个整数）
- 比较整数比比较字符串快得多

## Java 代码实现

### 方法一：哈希表 + 滑动窗口（推荐新手）

```java
import java.util.*;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        int n = s.length();
        if (n < 10) return new ArrayList<>();

        // 记录每个子串出现的次数
        Map<String, Integer> seen = new HashMap<>();
        List<String> result = new ArrayList<>();

        // 滑动窗口遍历所有长度为 10 的子串
        for (int i = 0; i <= n - 10; i++) {
            String sub = s.substring(i, i + 10);
            seen.put(sub, seen.getOrDefault(sub, 0) + 1);

            // 第一次重复时加入结果（避免重复添加）
            if (seen.get(sub) == 2) {
                result.add(sub);
            }
        }

        return result;
    }
}
```

### 方法二：使用两个集合（简洁版）

```java
import java.util.*;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        if (s.length() < 10) return new ArrayList<>();

        Set<String> seen = new HashSet<>();     // 已经见过的子串
        Set<String> repeated = new HashSet<>();  // 重复出现的子串

        for (int i = 0; i <= s.length() - 10; i++) {
            String sub = s.substring(i, i + 10);
            if (seen.contains(sub)) {
                repeated.add(sub); // Set 自动去重
            } else {
                seen.add(sub);
            }
        }

        return new ArrayList<>(repeated);
    }
}
```

### 方法三：位运算优化（进阶）

```java
import java.util.*;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        int n = s.length();
        if (n < 10) return new ArrayList<>();

        // 字符到数字的映射：A=0, C=1, G=2, T=3
        int[] charMap = new int[128];
        charMap['A'] = 0;
        charMap['C'] = 1;
        charMap['G'] = 2;
        charMap['T'] = 3;

        Set<Integer> seen = new HashSet<>();
        Set<Integer> repeated = new HashSet<>();

        // 计算第一个窗口的哈希值
        int hashVal = 0;
        for (int i = 0; i < 10; i++) {
            hashVal = (hashVal << 2) | charMap[s.charAt(i)];
        }
        seen.add(hashVal);

        // 滑动窗口
        int mask = (1 << 20) - 1; // 保留低 20 位（10 个字符 * 2 位）
        for (int i = 1; i <= n - 10; i++) {
            // 移除最高位的字符，添加新字符
            hashVal = ((hashVal << 2) & mask) | charMap[s.charAt(i + 9)];

            if (seen.contains(hashVal)) {
                repeated.add(hashVal);
            } else {
                seen.add(hashVal);
            }
        }

        // 将哈希值转回字符串
        char[] numToChar = {'A', 'C', 'G', 'T'};
        List<String> result = new ArrayList<>();
        for (int val : repeated) {
            char[] chars = new char[10];
            for (int i = 9; i >= 0; i--) {
                chars[i] = numToChar[val & 3];
                val >>= 2;
            }
            result.add(new String(chars));
        }

        return result;
    }
}
```

## 复杂度分析

**方法一、二：**
- **时间复杂度**：O(n × L)，其中 n 是字符串长度，L = 10 是子串长度。需要遍历 n - 9 个子串，每次提取子串需要 O(L)。
- **空间复杂度**：O(n × L)，最坏情况下所有子串都不同。

**方法三（位运算）：**
- **时间复杂度**：O(n)，只需要位运算，不需要提取子串。
- **空间复杂度**：O(n)，存储整数比存储字符串节省空间。

## 关键点总结

1. **滑动窗口**：固定窗口大小为 10，每次移动一位
2. **去重处理**：使用 Set 或判断 `count == 2` 来避免重复添加
3. **位运算优化**：将字符编码为 2 位二进制，加速比较
4. **哈希表应用**：记录子串出现次数，快速查找重复
5. **Java 特点**：`substring` 方法的时间复杂度是 O(L)，大量调用会影响性能

## 易错点

1. **重复添加结果**：一个子串可能出现 3 次以上，但只应添加到结果一次
   ```java
   // 错误写法（使用 List 时）
   if (seen.contains(sub)) {
       result.add(sub); // 可能重复添加
   }
   
   // 正确写法一：判断第二次出现
   if (seen.get(sub) == 2) {
       result.add(sub);
   }
   
   // 正确写法二：使用 Set 自动去重
   repeated.add(sub); // Set 保证不重复
   ```

2. **字符串长度检查**：如果字符串长度小于 10，直接返回空列表
   ```java
   if (s.length() < 10) return new ArrayList<>();
   ```

3. **窗口边界**：循环范围是 `i <= n - 10`，而不是 `i < n`
   ```java
   for (int i = 0; i <= n - 10; i++) // 正确
   for (int i = 0; i < n; i++)        // 错误，会越界
   ```

4. **位运算的掩码**：需要用掩码保留低 20 位
   ```java
   int mask = (1 << 20) - 1; // 0xFFFFF
   hashVal = ((hashVal << 2) & mask) | newChar;
   ```
