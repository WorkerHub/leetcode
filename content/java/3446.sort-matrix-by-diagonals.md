## 题目描述

给你一个 `n x n` 的整数矩阵 `grid`，对每条对角线独立排序：左下半部分（含主对角线）升序，右上半部分降序。返回排序后的矩阵。

## 解题思路

同一对角线上的元素满足 `row - col = d`（常数）。d >= 0 为左下半部分，升序；d < 0 为右上半部分，降序。对每条对角线提取元素、排序后放回。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[][] sortMatrix(int[][] grid) {
        int n = grid.length;
        // 按对角线分组，key = row - col
        Map<Integer, List<Integer>> diag = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int d = i - j;
                diag.computeIfAbsent(d, k -> new ArrayList<>()).add(grid[i][j]);
            }
        }
        // 对每条对角线排序
        for (Map.Entry<Integer, List<Integer>> entry : diag.entrySet()) {
            int d = entry.getKey();
            List<Integer> vals = entry.getValue();
            Collections.sort(vals);
            if (d < 0) {
                // 右上半部分：降序
                Collections.reverse(vals);
            }
            // d >= 0：升序（已排好）
        }
        // 将排序后的值放回矩阵
        int[][] result = new int[n][n];
        Map<Integer, Integer> pos = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int d = i - j;
                int idx = pos.getOrDefault(d, 0);
                result[i][j] = diag.get(d).get(idx);
                pos.put(d, idx + 1);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 log n)，每条对角线排序
- 空间复杂度：O(n^2)

## 关键点总结

1. 对角线由 `row - col` 唯一确定
2. `d >= 0`（下半部分）升序，`d < 0`（上半部分）降序
3. 对角线上的元素按 row（或 col）升序排列
