## 题目描述

给你怪兽距离数组 `dist` 和速度数组 `speed`，每分钟消灭一只怪兽，若怪兽到达城市则游戏结束，返回最多可消灭的怪兽数量。

## 解题思路

贪心：计算每只怪兽到达时间（向上取整），按到达时间升序排序，在第 i 分钟消灭第 i 只怪兽，若到达时间 <= i 则游戏结束。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int eliminateMaximum(int[] dist, int[] speed) {
        int n = dist.length;
        int[] arrive = new int[n];
        for (int i = 0; i < n; i++) {
            // 向上取整：ceil(dist/speed)
            arrive[i] = (dist[i] + speed[i] - 1) / speed[i];
        }
        Arrays.sort(arrive);

        for (int i = 0; i < n; i++) {
            if (arrive[i] <= i) return i; // 第 i 分钟前已到达，游戏结束
        }
        return n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：优先消灭最快到达的怪兽
2. 在第 i 分钟消灭第 i 只怪兽，到达时间必须 > i
3. 向上取整：`(d + s - 1) / s`
