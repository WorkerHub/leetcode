## 题目描述

给你一个整数数组 `arr`，请你将数组中的元素按照其二进制表示中数字 `1` 的数目升序排序。

如果存在多个数字的 `1` 的数目相同，则必须将它们按照**数值大小升序**排列。

请你返回排序后的数组。

**示例 1：**
```
输入：arr = [0,1,2,3,4,5,6,7,8]
输出：[0,1,2,4,8,3,5,6,7]
解释：[0] 是唯一一个有 0 个 1 的数。
     [1,2,4,8] 都有 1 个 1。
     [3,5,6] 有 2 个 1。
     [7] 有 3 个 1。
```

**示例 2：**
```
输入：arr = [1024,512,256,128,64,32,16,8,4,2,1]
输出：[1,2,4,8,16,32,64,128,256,512,1024]
解释：所有整数有且仅有 1 个 1 ，所以按数值大小升序排列。
```

**示例 3：**
```
输入：arr = [10000,10000]
输出：[10000,10000]
```

**提示：**
- `1 <= arr.length <= 500`
- `0 <= arr[i] <= 10^4`

## 解题思路

题目要求自定义排序：**主键**为二进制中 1 的个数（升序），**次键**为数值本身（升序）。

统计一个整数二进制中 1 的个数有多种方法：
1. Java 内置 `Integer.bitCount(x)`
2. 手动位运算：`x & (x-1)` 消去最低位的 1，计数循环次数

## Java 代码实现

### 方法一：Integer.bitCount + 自定义排序（推荐）

```java
import java.util.*;

class Solution {
    public int[] sortByBits(int[] arr) {
        // 将 int[] 转为 Integer[] 以使用自定义比较器
        Integer[] boxed = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) boxed[i] = arr[i];
        
        // 自定义排序：先按 1 的个数升序，再按数值升序
        Arrays.sort(boxed, (a, b) -> {
            int diff = Integer.bitCount(a) - Integer.bitCount(b);
            return diff != 0 ? diff : a - b;
        });
        
        // 转回 int[]
        for (int i = 0; i < arr.length; i++) arr[i] = boxed[i];
        return arr;
    }
}
```

### 方法二：Brian Kernighan 算法统计 1 的个数

```java
import java.util.*;

class Solution {
    public int[] sortByBits(int[] arr) {
        Integer[] boxed = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) boxed[i] = arr[i];
        
        Arrays.sort(boxed, (a, b) -> {
            int diff = countOnes(a) - countOnes(b);
            return diff != 0 ? diff : a - b;
        });
        
        for (int i = 0; i < arr.length; i++) arr[i] = boxed[i];
        return arr;
    }
    
    // Brian Kernighan 算法：统计二进制中 1 的个数
    private int countOnes(int x) {
        int count = 0;
        while (x != 0) {
            x &= (x - 1); // 消去最低位的 1
            count++;
        }
        return count;
    }
}
```

**Brian Kernighan 算法说明：** `x & (x-1)` 会将 x 最低位的 1 变为 0（其余不变），循环直到 x 为 0，循环次数即为 1 的个数。

**示例：** x=6（二进制 110）
```
x=6（110）: 6 & 5 = 4（100），count=1
x=4（100）: 4 & 3 = 0（000），count=2
x=0，结束，返回 2
```

### 方法三：预处理 + 排序（大数据量时更高效）

```java
import java.util.*;

class Solution {
    public int[] sortByBits(int[] arr) {
        // 预先计算所有值的 1 的个数，避免重复计算
        int[] bitCount = new int[10001];
        for (int i = 1; i <= 10000; i++) {
            bitCount[i] = Integer.bitCount(i);
        }
        
        Integer[] boxed = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) boxed[i] = arr[i];
        
        Arrays.sort(boxed, (a, b) -> {
            int diff = bitCount[a] - bitCount[b];
            return diff != 0 ? diff : a - b;
        });
        
        for (int i = 0; i < arr.length; i++) arr[i] = boxed[i];
        return arr;
    }
}
```

## 复杂度分析

- 时间复杂度：O(N log N * K)，其中 N 是数组长度，K 是统计 1 个数的时间（对于 `Integer.bitCount()` 为 O(1)，对于 Brian Kernighan 算法约 O(popcount)）。整体约 O(N log N)。
- 空间复杂度：O(N)，排序的额外空间（Integer 数组）。

## 二进制 1 的个数统计方法对比

| 方法 | 时间复杂度 | 代码简洁度 | 说明 |
|------|------------|------------|------|
| `Integer.bitCount(x)` | O(1) | 最简洁 | Java 内置，推荐 |
| Brian Kernighan | O(popcount) | 较复杂 | 理解位运算的好方法 |
| 预处理打表 | O(1) | 较复杂 | 值域固定时高效 |

## 关键点总结

1. Java 中 `Integer.bitCount(x)` 是统计二进制 1 个数的最简写法。
2. Java 自定义排序需要 `Integer[]`（装箱类型），不能直接对 `int[]` 使用 Comparator。
3. 比较器返回负数表示第一个参数排前面，正数表示第二个排前面，0 表示相等。
4. Brian Kernighan 算法 `x & (x-1)` 是位运算中的经典技巧，每次消去最低位的 1。
5. 多级排序：先比较主键（1 的个数），若相同再比次键（数值大小）。

## 易错点

- Java 中不能直接对 `int[]` 使用 lambda 比较器，需先转为 `Integer[]`，排序完再转回。
- 对 x=0 的处理：`Integer.bitCount(0) = 0`，结果正确，不需要特判。
- 比较器中 `diff = Integer.bitCount(a) - Integer.bitCount(b)` 可能溢出（但本题数值范围在 0-10^4，bitCount 最大为 14，差值不会溢出）。
