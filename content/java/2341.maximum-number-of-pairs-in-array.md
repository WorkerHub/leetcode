## 题目描述

给你整数数组 `nums`，每次操作删除两个相等的元素，返回最大操作次数和操作后剩余元素数目。

## 解题思路

统计每个数的出现次数，每个数出现 k 次可配对 `k/2` 次，剩余 `k%2` 个，求所有数的配对总数和剩余总数。

## Java 代码实现

```java
class Solution {
    public int[] numberOfPairs(int[] nums) {
        int[] count = new int[101]; // 值域 [0, 100]
        for (int x : nums) count[x]++;
        int pairs = 0, remaining = 0;
        for (int c : count) {
            pairs += c / 2;
            remaining += c % 2;
        }
        return new int[]{pairs, remaining};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（值域固定为 101）

## 关键点总结

1. 每个数出现 k 次可配对 `k/2` 次，剩余 `k%2` 个。
2. 剩余总数也可用 `len(nums) - pairs*2` 计算。
3. 值域 [0,100] 可用数组替代哈希表。
