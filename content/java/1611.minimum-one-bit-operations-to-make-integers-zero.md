## 题目描述

将整数n通过特定位操作变为0的最小操作数。本质是格雷码逆变换。

## 解题思路

格雷码转换：将格雷码n转为对应的自然数就是答案。累积XOR：result = n XOR (n>>1) XOR (n>>2) ...

## Java 代码实现

```java
class Solution {
    public int minimumOneBitOperations(int n) {
        // 格雷码逆变换：累积 XOR
        int result = 0;
        while (n != 0) {
            result ^= n;
            n >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **格雷码逆变换**：累积XOR得到自然数
2. **递归公式**：f(2^k | rest) = 2^(k+1) - 1 - f(rest)
3. **O(log N)位操作**：逐位右移并XOR
