## 题目描述

给定整数数组 `nums`，定义前缀异或值 `prefix[i] = nums[0] XOR ... XOR nums[i]`，找出所有前缀异或值中两两异或的最大值。

## 解题思路

字典树（Trie）求最大异或：先计算所有前缀异或值（包含初始值 0），逐一插入 Trie，同时查询与当前值异或最大的已存在值，从最高位贪心选择互补位。

## Java 代码实现

```java
class Solution {
    private int[][] trie;
    private int cnt;

    public int findMaximumXOR(int[] nums) {
        int n = nums.length;
        trie = new int[32 * (n + 1) + 5][2];
        cnt = 1;

        // 计算前缀异或并插入 Trie
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] ^ nums[i];

        int ans = 0;
        for (int p : prefix) {
            insert(p);
            ans = Math.max(ans, query(p));
        }
        return ans;
    }

    private void insert(int num) {
        int node = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (trie[node][bit] == 0) trie[node][bit] = cnt++;
            node = trie[node][bit];
        }
    }

    private int query(int num) {
        int node = 0, xor = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit; // 希望异或为 1
            if (trie[node][want] != 0) {
                xor |= (1 << i);
                node = trie[node][want];
            } else {
                node = trie[node][bit];
            }
        }
        return xor;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 32)
- 空间复杂度：O(n * 32)

## 关键点总结

1. 前缀列表包含初始值 0，确保考虑以 0 开始的子数组
2. Trie 贪心：从最高位开始，尽量选与当前位互补的分支
3. `prefix[i] XOR prefix[j]` 等于子数组 `[i+1, j]` 的 XOR
