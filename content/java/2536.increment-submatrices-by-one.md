## 题目描述

给你正整数 `n` 和查询数组 `queries`，每个查询将子矩阵内所有元素加 1，返回执行所有查询后的 n×n 矩阵。

## 解题思路

二维差分数组：对矩形 `(r1,c1)` 到 `(r2,c2)` 加 1，仅更新差分数组的 4 个角点，最后对差分数组做二维前缀和还原。

## Java 代码实现

```java
class Solution {
    public int[][] rangeAddQueries(int n, int[][] queries) {
        // 差分数组大小 (n+1)x(n+1) 防止越界
        int[][] diff = new int[n + 1][n + 1];

        for (int[] q : queries) {
            int r1 = q[0], c1 = q[1], r2 = q[2], c2 = q[3];
            diff[r1][c1]++;
            diff[r1][c2 + 1]--;
            diff[r2 + 1][c1]--;
            diff[r2 + 1][c2 + 1]++;
        }

        // 二维前缀和还原（先行后列）
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i > 0) diff[i][j] += diff[i - 1][j];
                if (j > 0) diff[i][j] += diff[i][j - 1];
                if (i > 0 && j > 0) diff[i][j] -= diff[i - 1][j - 1];
            }
        }

        int[][] ans = new int[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                ans[i][j] = diff[i][j];
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q + n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. 二维差分：矩形区域更新只需操作 4 个角点
2. 差分数组需要 `(n+1)×(n+1)` 大小，避免 `r2+1` 或 `c2+1` 越界
3. 前缀和还原用容斥公式：加上上方和左方，减去重叠的左上角
