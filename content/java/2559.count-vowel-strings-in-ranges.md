## 题目描述

给你字符串数组 `words` 和查询数组 `queries`（每个查询为区间 `[l, r]`），对每个查询返回 `words[l..r]` 中以元音字母开头且结尾的字符串数目。

## 解题思路

前缀和：预计算 `prefix[i]` = words[0..i-1] 中满足条件的字符串数，查询答案为 `prefix[r+1] - prefix[l]`。

## Java 代码实现

```java
class Solution {
    public int[] vowelStrings(String[] words, int[][] queries) {
        String vowels = "aeiou";
        int n = words.length;
        int[] prefix = new int[n + 1];

        for (int i = 0; i < n; i++) {
            String w = words[i];
            // 首字符和末字符均为元音则计入
            boolean isVowel = vowels.indexOf(w.charAt(0)) >= 0
                           && vowels.indexOf(w.charAt(w.length() - 1)) >= 0;
            prefix[i + 1] = prefix[i] + (isVowel ? 1 : 0);
        }

        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            ans[i] = prefix[queries[i][1] + 1] - prefix[queries[i][0]];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + q)
- **空间复杂度**：O(n)

## 关键点总结

1. 前缀和将区间查询优化为 O(1)
2. 只需判断首末字符是否为元音，与字符串长度无关
3. 查询闭区间 [l,r] 对应 `prefix[r+1] - prefix[l]`
