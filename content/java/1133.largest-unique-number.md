## 题目描述

给定整数数组 nums，返回仅出现一次的最大整数。如果不存在返回 -1。

**示例：**
```
输入：nums = [5,7,3,9,4,9,8,3,1]
输出：8
```

## 解题思路

值域 0-1000，用数组计数。从大到小扫描，找第一个计数为 1 的数。

## Java 代码实现

```java
class Solution {
    public int largestUniqueNumber(int[] nums) {
        // 值域 0-1000
        int[] count = new int[1001];
        for (int num : nums) {
            count[num]++;
        }

        // 从大到小找第一个只出现一次的
        for (int i = 1000; i >= 0; i--) {
            if (count[i] == 1) return i;
        }

        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 1001) = O(n)
- **空间复杂度**：O(1)，固定大小数组

## 关键点总结

1. **计数数组**：值域小时优于 HashMap
2. **从大到小扫描**：第一个 count==1 即为答案
3. **返回 -1**：所有数字都重复时的边界处理
