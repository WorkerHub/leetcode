## 题目描述

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：

- 只使用数字 1 到 9
- 每个数字最多使用一次

返回所有可能的有效组合的列表。该列表不能包含相同的组合两次，组合可以以任何顺序返回。

**示例 1：**

```
输入：k = 3, n = 7
输出：[[1,2,4]]
解释：
1 + 2 + 4 = 7
没有其他符合的组合了。
```

**示例 2：**

```
输入：k = 3, n = 9
输出：[[1,2,6],[1,3,5],[2,3,4]]
解释：
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
没有其他符合的组合了。
```

**示例 3：**

```
输入：k = 4, n = 1
输出：[]
解释：不存在有效的组合。
在 [1,9] 范围内使用 4 个不同的数字，我们可以得到的最小和是 1+2+3+4 = 10，因为 10 > 1，没有有效的组合。
```

**提示：**

- `2 <= k <= 9`
- `1 <= n <= 60`

## 解题思路

这是经典的回溯（Backtracking）问题，类似于组合问题，但增加了和的约束。

**核心思想：**

1. **回溯搜索**：从 1 到 9 中选择 k 个数，使其和为 n
2. **剪枝优化**：
   - 如果当前和已经超过 n，停止搜索
   - 如果剩余数字不够，停止搜索
   - 如果剩余数字的最小和都大于目标，停止搜索

**算法流程：**

1. 定义回溯函数 `backtrack(start, path, currentSum)`
2. 终止条件：
   - 如果 `path.size() == k` 且 `currentSum == n`，加入结果
   - 如果 `path.size() == k` 但和不等于 n，返回
   - 如果 `currentSum > n`，返回（剪枝）
3. 递归：从 `start` 到 9，依次选择数字
4. 回溯：移除最后一个数字，尝试其他选择

## Java 代码实现

### 方法一：回溯 + 剪枝（推荐）⭐

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();

    public List<List<Integer>> combinationSum3(int k, int n) {
        backtrack(1, new ArrayList<>(), 0, k, n);
        return result;
    }

    private void backtrack(int start, List<Integer> path, int currentSum, int k, int n) {
        // 剪枝：和已经超过目标
        if (currentSum > n) return;

        // 找到一个有效组合
        if (path.size() == k) {
            if (currentSum == n) {
                result.add(new ArrayList<>(path)); // 复制一份加入结果
            }
            return;
        }

        // 剪枝：剩余数字不够
        if (9 - start + 1 < k - path.size()) return;

        // 从 start 到 9 选择数字
        for (int num = start; num <= 9; num++) {
            path.add(num);
            backtrack(num + 1, path, currentSum + num, k, n);
            path.remove(path.size() - 1); // 回溯：移除最后一个元素
        }
    }
}
```

### 方法二：回溯 + 更多剪枝

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();

    public List<List<Integer>> combinationSum3(int k, int n) {
        backtrack(1, new ArrayList<>(), 0, k, n);
        return result;
    }

    private void backtrack(int start, List<Integer> path, int currentSum, int k, int n) {
        // 剪枝1：和已经超过目标
        if (currentSum > n) return;

        // 剪枝2：已选 k 个数
        if (path.size() == k) {
            if (currentSum == n) {
                result.add(new ArrayList<>(path));
            }
            return;
        }

        // 剩余需要选择的数字个数
        int remainCount = k - path.size();

        // 剪枝3：剩余数字不够
        if (9 - start + 1 < remainCount) return;

        // 剪枝4：剩余最小和都大于目标
        // 剩余最小和 = start + (start+1) + ... + (start+remainCount-1)
        int minSum = remainCount * start + remainCount * (remainCount - 1) / 2;
        if (currentSum + minSum > n) return;

        // 剪枝5：剩余最大和都小于目标
        // 剩余最大和 = 9 + 8 + ... + (9-remainCount+1)
        int maxSum = remainCount * 9 - remainCount * (remainCount - 1) / 2;
        if (currentSum + maxSum < n) return;

        for (int num = start; num <= 9; num++) {
            path.add(num);
            backtrack(num + 1, path, currentSum + num, k, n);
            path.remove(path.size() - 1);
        }
    }
}
```

### 方法三：迭代版本（使用栈）

```java
class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> result = new ArrayList<>();

        // 栈存储：(起始数字, 当前路径, 当前和)
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{1, new ArrayList<Integer>(), 0});

        while (!stack.isEmpty()) {
            Object[] state = stack.pop();
            int start = (int) state[0];
            List<Integer> path = (List<Integer>) state[1];
            int currentSum = (int) state[2];

            // 找到有效组合
            if (path.size() == k) {
                if (currentSum == n) {
                    result.add(new ArrayList<>(path));
                }
                continue;
            }

            // 剪枝
            if (currentSum >= n) continue;

            // 从大到小遍历（栈的特性，保证最终顺序正确）
            for (int num = 9; num >= start; num--) {
                if (currentSum + num <= n) {
                    List<Integer> newPath = new ArrayList<>(path);
                    newPath.add(num);
                    stack.push(new Object[]{num + 1, newPath, currentSum + num});
                }
            }
        }

        return result;
    }
}
```

### 方法四：简洁版（易理解）

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();

    public List<List<Integer>> combinationSum3(int k, int n) {
        backtrack(1, new ArrayList<>(), 0, k, n);
        return result;
    }

    private void backtrack(int start, List<Integer> path, int sum, int k, int n) {
        // 找到有效组合
        if (path.size() == k && sum == n) {
            result.add(new ArrayList<>(path));
            return;
        }

        // 剪枝：数字已经够了 或 和已经超过目标
        if (path.size() == k || sum >= n) return;

        // 选择数字
        for (int num = start; num <= 9; num++) {
            // 剪枝：加上当前数字已经超过目标
            if (sum + num > n) break;
            path.add(num);
            backtrack(num + 1, path, sum + num, k, n);
            path.remove(path.size() - 1);
        }
    }
}
```

## 复杂度分析

**方法一（回溯 + 剪枝）：**

- **时间复杂度：** O(C(9, k))，最多从 9 个数中选 k 个
  - 实际复杂度远小于此，因为剪枝大幅减少搜索空间
- **空间复杂度：** O(k)
  - 递归栈深度：O(k)
  - 路径数组：O(k)

**方法三（迭代）：**

- **时间复杂度：** O(C(9, k))
- **空间复杂度：** O(k × 结果数量)，栈中存储路径副本

## 关键点总结

1. **回溯模板**：选择 → 递归 → 撤销选择
2. **去重策略**：通过 `start` 参数保证只向后选择，避免重复
3. **剪枝优化**：
   - 和超过目标：提前返回
   - 数字不够：提前返回
   - 最小和/最大和检查：减少无效搜索
4. **边界处理**：`path.size() == k` 时检查和是否等于 n
5. **路径复制**：`new ArrayList<>(path)` 而不是直接使用 `path`

## 易错点

1. **忘记复制路径**：
   ```java
   // 错误：path 会继续变化
   result.add(path);
   // 正确：复制一份
   result.add(new ArrayList<>(path));
   ```

2. **去重逻辑错误**：
   ```java
   // 错误：从 1 开始会产生重复
   for (int num = 1; num <= 9; num++)
   // 正确：从 start 开始
   for (int num = start; num <= 9; num++)
   ```

3. **回溯时移除元素错误**：
   ```java
   // 错误：移除指定值（可能移除错误位置的元素）
   path.remove(Integer.valueOf(num));
   // 正确：移除最后一个位置（O(1)）
   path.remove(path.size() - 1);
   ```

4. **边界情况未处理**：
   ```java
   // k=9, n=45 时，结果是 [1,2,3,4,5,6,7,8,9]
   // k=2, n=1 时，结果是 []（最小和是 1+2=3）
   ```

5. **剪枝条件遗漏**：
   ```java
   // 不剪枝会多做无效计算
   if (currentSum > n) return;
   ```
