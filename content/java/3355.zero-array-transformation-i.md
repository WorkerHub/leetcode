## 题目描述

给你整数数组 `nums` 和二维数组 `queries`，其中 `queries[i] = [l, r]`。每次查询对 `nums[l..r]` 中每个元素减 1（不低于 0）。执行所有查询后，判断 `nums` 是否能变为全 0 数组。

## 解题思路

用差分数组统计每个位置被查询覆盖的次数：对每个查询 `[l, r]`，执行 `diff[l]++, diff[r+1]--`。还原前缀和后，检验每个位置的覆盖次数是否 >= `nums[i]`。

## Java 代码实现

```java
class Solution {
    public boolean isZeroArray(int[] nums, int[][] queries) {
        int n = nums.length;

        // 差分数组：记录每个位置被覆盖的次数
        int[] diff = new int[n + 1];
        for (int[] q : queries) {
            diff[q[0]]++;
            diff[q[1] + 1]--;
        }

        // 还原前缀和，验证每个位置覆盖次数 >= nums[i]
        int cover = 0;
        for (int i = 0; i < n; i++) {
            cover += diff[i];
            if (nums[i] > cover) {
                return false;
            }
        }

        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + q)，差分数组操作 + 一次前缀和
- 空间复杂度：O(n)，差分数组

## 关键点总结

1. 差分数组将区间操作化为单点操作，前缀和还原每个位置的覆盖次数。
2. `nums[i] > cover[i]` 时该位置无法被减为 0，返回 false。
3. 差分数组大小需要 `n+1`（防止 `r+1 == n` 越界）。
