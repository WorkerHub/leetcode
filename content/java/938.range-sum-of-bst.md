## 题目描述

给定 BST 根节点和范围 [low, high]，返回值在范围内的所有节点值之和。

## 解题思路

利用 BST 性质剪枝：当前值小于 low 只搜右子树，大于 high 只搜左子树。

## Java 代码实现

```java
class Solution {
    public int rangeSumBST(TreeNode root, int low, int high) {
        if (root == null) return 0;

        int sum = 0;
        if (root.val >= low && root.val <= high) {
            sum += root.val;
        }
        if (root.val > low) {
            sum += rangeSumBST(root.left, low, high);
        }
        if (root.val < high) {
            sum += rangeSumBST(root.right, low, high);
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，最坏遍历所有节点
- **空间复杂度**：O(h)，递归栈深度

## 关键点总结

1. **BST 剪枝**：利用有序性跳过不可能的子树
2. **递归遍历**：三种情况分别处理
3. **范围判断**：节点值与 low/high 比较决定方向
