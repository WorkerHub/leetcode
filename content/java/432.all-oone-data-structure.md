## 题目描述

请你设计一个用于存储字符串计数的数据结构，并能够返回计数最小和最大的字符串。

实现 `AllOne` 类：

- `AllOne()` 初始化数据结构的对象。
- `inc(String key)` 字符串 `key` 的计数增加 1。如果数据结构中尚不存在 `key`，那么插入计数为 1 的 `key`。
- `dec(String key)` 字符串 `key` 的计数减少 1。如果 `key` 的计数在减少后为 0，那么需要将这个 `key` 从数据结构中删除。测试用例保证：在减少计数前，`key` 存在于数据结构中。
- `getMaxKey()` 返回任意一个计数最大的字符串。如果没有元素存在，返回一个空字符串 `""`。
- `getMinKey()` 返回任意一个计数最小的字符串。如果没有元素存在，返回一个空字符串 `""`。

**注意**：每个函数都应当满足 O(1) 平均时间复杂度。

**示例：**
```
输入
["AllOne", "inc", "inc", "getMaxKey", "getMinKey", "inc", "getMaxKey", "getMinKey"]
[[], ["hello"], ["hello"], [], [], ["leet"], [], []]
输出
[null, null, null, "hello", "hello", null, "hello", "leet"]

解释
AllOne allOne = new AllOne();
allOne.inc("hello");
allOne.inc("hello");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "hello"
allOne.inc("leet");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "leet"
```

**提示：**
- `1 <= key.length <= 10`
- `key` 由小写英文字母组成
- 测试用例保证：在每次调用 `dec` 时，数据结构中总存在 `key`
- 最多调用 `inc`、`dec`、`getMaxKey` 和 `getMinKey` 方法 `5 * 10^4` 次

## 解题思路

这道题要求实现一个全 O(1) 的数据结构。核心思想是使用哈希表 + 双向链表。

**关键观察：**
1. 需要 O(1) 时间获取最大和最小计数的 key
2. 需要 O(1) 时间增加和减少计数
3. 可以使用双向链表维护计数的有序性
4. 使用哈希表快速定位 key 所在的节点

**数据结构设计：**
1. **Bucket（桶）**：存储相同计数的所有 key
   - count: 计数值
   - keys: 该计数下的所有 key（使用集合）
   
2. **双向链表**：按计数值升序连接所有桶
   - head -> 计数最小的桶 -> ... -> 计数最大的桶 -> tail

3. **哈希表**：
   - keyBucket: key -> 所在的桶节点
   
**算法流程：**
- `inc(key)`: 
  1. 如果 key 不存在，加入计数为 1 的桶
  2. 如果 key 存在，从当前桶移到下一个桶（count+1）
  
- `dec(key)`:
  1. 从当前桶移到上一个桶（count-1）
  2. 如果 count 变为 0，删除 key

- `getMaxKey()`: 返回尾部桶中的任意 key
- `getMinKey()`: 返回头部桶中的任意 key

## Java 代码实现

### 方法一：双向链表 + 哈希表 ⭐ 推荐

```java
import java.util.*;

class AllOne {
    // 存储相同计数的所有 key 的桶节点
    private class Bucket {
        int count;
        Set<String> keys;
        Bucket prev;
        Bucket next;
        
        Bucket(int count) {
            this.count = count;
            this.keys = new HashSet<>();
        }
    }
    
    private Bucket head;  // 哨兵头节点
    private Bucket tail;  // 哨兵尾节点
    private Map<String, Bucket> keyBucket;  // key -> Bucket 映射
    
    public AllOne() {
        head = new Bucket(0);
        tail = new Bucket(0);
        head.next = tail;
        tail.prev = head;
        keyBucket = new HashMap<>();
    }
    
    // 在 prevBucket 后插入 newBucket
    private void insertBucketAfter(Bucket newBucket, Bucket prevBucket) {
        newBucket.prev = prevBucket;
        newBucket.next = prevBucket.next;
        prevBucket.next.prev = newBucket;
        prevBucket.next = newBucket;
    }
    
    // 移除空桶
    private void removeBucket(Bucket bucket) {
        bucket.prev.next = bucket.next;
        bucket.next.prev = bucket.prev;
    }
    
    public void inc(String key) {
        if (keyBucket.containsKey(key)) {
            // key 已存在，移动到下一个桶
            Bucket bucket = keyBucket.get(key);
            int newCount = bucket.count + 1;
            
            // 确保下一个桶的计数等于 newCount
            if (bucket.next.count != newCount) {
                Bucket created = new Bucket(newCount);
                insertBucketAfter(created, bucket);
            }
            // 现在 bucket.next 就是 newCount 的桶
            Bucket nextBucket = bucket.next;
            nextBucket.keys.add(key);
            keyBucket.put(key, nextBucket);
            
            // 从旧桶移除
            bucket.keys.remove(key);
            if (bucket.keys.isEmpty()) {
                removeBucket(bucket);
            }
        } else {
            // key 不存在，加入计数为 1 的桶
            if (head.next.count != 1) {
                Bucket created = new Bucket(1);
                insertBucketAfter(created, head);
            }
            head.next.keys.add(key);
            keyBucket.put(key, head.next);
        }
    }
    
    public void dec(String key) {
        Bucket bucket = keyBucket.get(key);
        
        if (bucket.count == 1) {
            // 计数变为 0，删除 key
            keyBucket.remove(key);
        } else {
            // 移动到上一个桶
            int newCount = bucket.count - 1;
            
            // 确保前一个桶的计数等于 newCount
            if (bucket.prev.count != newCount) {
                Bucket created = new Bucket(newCount);
                insertBucketAfter(created, bucket.prev);
            }
            // 现在 bucket.prev 就是 newCount 的桶
            Bucket prevBucket = bucket.prev;
            prevBucket.keys.add(key);
            keyBucket.put(key, prevBucket);
        }
        
        // 从旧桶移除
        bucket.keys.remove(key);
        if (bucket.keys.isEmpty()) {
            removeBucket(bucket);
        }
    }
    
    public String getMaxKey() {
        if (tail.prev == head) return "";
        return tail.prev.keys.iterator().next();
    }
    
    public String getMinKey() {
        if (head.next == tail) return "";
        return head.next.keys.iterator().next();
    }
}
```

### 方法二：TreeMap 版本（简化实现）

```java
import java.util.*;

class AllOne {
    private Map<String, Integer> keyCount;        // key -> 计数
    private TreeMap<Integer, Set<String>> countKeys;  // 计数 -> key集合（按计数升序）
    
    public AllOne() {
        keyCount = new HashMap<>();
        countKeys = new TreeMap<>();
    }
    
    public void inc(String key) {
        int count = keyCount.getOrDefault(key, 0);
        int newCount = count + 1;
        
        // 更新 keyCount
        keyCount.put(key, newCount);
        
        // 从旧计数中移除
        if (count > 0) {
            countKeys.get(count).remove(key);
            if (countKeys.get(count).isEmpty()) {
                countKeys.remove(count);
            }
        }
        
        // 加入新计数
        countKeys.computeIfAbsent(newCount, k -> new HashSet<>()).add(key);
    }
    
    public void dec(String key) {
        int count = keyCount.get(key);
        
        // 从旧计数中移除
        countKeys.get(count).remove(key);
        if (countKeys.get(count).isEmpty()) {
            countKeys.remove(count);
        }
        
        if (count == 1) {
            // 删除 key
            keyCount.remove(key);
        } else {
            // 移动到新计数
            int newCount = count - 1;
            keyCount.put(key, newCount);
            countKeys.computeIfAbsent(newCount, k -> new HashSet<>()).add(key);
        }
    }
    
    public String getMaxKey() {
        if (countKeys.isEmpty()) return "";
        return countKeys.lastEntry().getValue().iterator().next();
    }
    
    public String getMinKey() {
        if (countKeys.isEmpty()) return "";
        return countKeys.firstEntry().getValue().iterator().next();
    }
}
```

## 复杂度分析

**方法一：双向链表**
- 时间复杂度：所有操作都是 O(1)
  - inc/dec: O(1) 插入/删除操作
  - getMaxKey/getMinKey: O(1) 访问头尾
- 空间复杂度：O(n)，n 是不同 key 的数量

**方法二：TreeMap 版本**
- 时间复杂度：
  - inc/dec: O(log n)，TreeMap 操作
  - getMaxKey/getMinKey: O(log n)
- 空间复杂度：O(n)

## 关键点总结

1. **双向链表设计**：按计数值升序维护桶节点
2. **桶的概念**：相同计数的 key 放在同一个桶中
3. **哨兵节点**：简化边界处理
4. **空桶删除**：桶中没有 key 时要及时删除
5. **O(1) 保证**：通过双向链表和哈希表实现常数时间操作

## 易错点

1. **空桶处理**：桶为空时必须从链表中移除
2. **边界情况**：第一个/最后一个桶的特殊处理
3. **iterator().next()**：从集合中获取任意元素用 `iterator().next()`
4. **哨兵节点**：使用哨兵简化插入和删除逻辑
5. **链表操作**：双向链表的插入和删除要更新两个方向的指针
