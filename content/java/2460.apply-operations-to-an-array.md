## 题目描述

给你非负整数数组 `nums`，依次执行 n-1 次操作：若 `nums[i] == nums[i+1]` 则 `nums[i]` 乘 2，`nums[i+1]` 变为 0。操作结束后将所有 0 移到末尾，返回结果数组。

## 解题思路

先按顺序执行所有合并操作，再用双指针将非零元素移到前面、0 填充末尾。两步不能颠倒。

## Java 代码实现

```java
class Solution {
    public int[] applyOperations(int[] nums) {
        int n = nums.length;

        // 执行合并操作
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] != 0 && nums[i] == nums[i + 1]) {
                nums[i] *= 2;
                nums[i + 1] = 0;
            }
        }

        // 双指针：将非零元素移到前面
        int write = 0;
        for (int read = 0; read < n; read++) {
            if (nums[read] != 0) {
                nums[write++] = nums[read];
            }
        }
        // 填充 0
        while (write < n) nums[write++] = 0;

        return nums;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 先执行所有合并操作（按顺序），再将 0 移到末尾，两步不能颠倒
2. 双指针移零：write 指针追踪下一个非零写入位置
3. 合并时需排除 nums[i] 为 0 的情况（0 == 0 不应合并）
