## 题目描述

给你一个二叉树的根节点 `root`，计算出现最频繁的子树元素和。一个节点的子树元素和定义为以该节点为根的二叉树上所有节点的元素之和（包括节点本身）。

你需要返回出现频率最高的子树元素和。如果有多个元素出现的频率相同，返回所有出现频率最高的子树元素和（不限顺序）。

**示例 1：**
```
输入：root = [5,2,-3]
输出：[2,-3,4]
```

**示例 2：**
```
输入：root = [5,2,-5]
输出：[2]
解释：2 出现的频率最高，为 2 次。
```

**提示：**
- 树中节点数目在范围 `[1, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这道题需要：
1. 计算每个子树的元素和
2. 统计每个和出现的频率
3. 找出频率最高的所有和

### 核心思想：
- 使用**后序遍历**（DFS）计算子树和
- 使用**哈希表**统计频率
- 找出最大频率，返回所有对应的和

### 算法流程：
1. 定义递归函数，返回子树和
2. 后序遍历：先计算左右子树和，再加上根节点
3. 用哈希表记录每个和出现的次数
4. 遍历哈希表，找出最大频率
5. 返回所有频率等于最大频率的和

## Java 代码实现

### 方法一：DFS + 哈希表（推荐）⭐

```java
import java.util.*;

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    private Map<Integer, Integer> count = new HashMap<>();

    public int[] findFrequentTreeSum(TreeNode root) {
        // 后序遍历计算子树和，哈希表统计频率
        // 时间复杂度：O(n)，空间复杂度：O(n)
        if (root == null) return new int[0];

        dfs(root);

        // 找出最大频率
        int maxCount = 0;
        for (int cnt : count.values()) {
            maxCount = Math.max(maxCount, cnt);
        }

        // 返回所有频率等于最大频率的和
        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == maxCount) {
                result.add(entry.getKey());
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private int dfs(TreeNode node) {
        // 计算以 node 为根的子树和（后序遍历）
        if (node == null) return 0;

        // 后序遍历：左 -> 右 -> 根
        int leftSum = dfs(node.left);
        int rightSum = dfs(node.right);

        // 当前子树和
        int treeSum = node.val + leftSum + rightSum;

        // 记录频率
        count.put(treeSum, count.getOrDefault(treeSum, 0) + 1);

        return treeSum;
    }
}
```

### 方法二：一次遍历（边计算边找最大）

```java
class Solution {
    private Map<Integer, Integer> count = new HashMap<>();
    private int maxCount = 0;

    public int[] findFrequentTreeSum(TreeNode root) {
        // 边遍历边维护最大频率和结果
        // 时间复杂度：O(n)，空间复杂度：O(n)
        if (root == null) return new int[0];

        dfs(root);

        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == maxCount) {
                result.add(entry.getKey());
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        int treeSum = node.val + dfs(node.left) + dfs(node.right);
        int freq = count.getOrDefault(treeSum, 0) + 1;
        count.put(treeSum, freq);

        // 更新最大频率
        maxCount = Math.max(maxCount, freq);

        return treeSum;
    }
}
```

### 方法三：收集所有子树和后统计

```java
class Solution {
    private List<Integer> sums = new ArrayList<>();

    public int[] findFrequentTreeSum(TreeNode root) {
        // 收集所有子树和，再统计频率
        // 时间复杂度：O(n)，空间复杂度：O(n)
        if (root == null) return new int[0];

        dfs(root);

        // 统计频率
        Map<Integer, Integer> count = new HashMap<>();
        for (int s : sums) {
            count.put(s, count.getOrDefault(s, 0) + 1);
        }

        int maxCount = 0;
        for (int cnt : count.values()) {
            maxCount = Math.max(maxCount, cnt);
        }

        List<Integer> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            if (entry.getValue() == maxCount) {
                result.add(entry.getKey());
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        int leftSum = dfs(node.left);
        int rightSum = dfs(node.right);
        int treeSum = node.val + leftSum + rightSum;

        sums.add(treeSum);
        return treeSum;
    }
}
```

## 复杂度分析

所有方法的复杂度相同：
- **时间复杂度**：O(n)
  - 遍历所有节点一次：O(n)
  - 查找最大频率和结果：O(n)
- **空间复杂度**：O(n)
  - 递归栈深度：O(h)，最坏 O(n)
  - 哈希表：O(n)

## 关键点总结

1. **后序遍历**：先计算子树和，再处理根节点
2. **子树和定义**：节点值 + 左子树和 + 右子树和
3. **频率统计**：使用哈希表
4. **多个结果**：可能有多个和的频率相同
5. **返回格式**：返回数组，不限顺序

## 易错点

1. **遍历顺序**：必须是后序遍历，不能是前序或中序
2. **空节点处理**：空节点的子树和为 0，不计入统计
3. **负数情况**：节点值可以为负，子树和也可能为负
4. **返回格式**：返回的是 int[]，需要转换
5. **频率相同**：注意处理多个和频率相同的情况
