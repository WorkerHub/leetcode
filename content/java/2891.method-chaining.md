## 题目描述

给定 DataFrame animals，用方法链筛选体重超过 100 kg 的动物，只保留 name 列，并按 name 降序排列。

## 解题思路

本题为 Python Pandas 专项练习，展示方法链式调用：过滤 → 选列 → 排序，每个操作返回新 DataFrame 并继续链式调用。

## Java 代码实现

```java
// 本题为 Pandas 专项练习，展示方法链式操作
// 等价于：filter(weight > 100) -> select(name) -> sort(name desc)

import java.util.*;
import java.util.stream.*;

class Solution {
    // Java Stream API 实现同等链式操作
    public List<String> findHeavyAnimals(List<String[]> animals) {
        // animals[i] = [name, weight]
        return animals.stream()
            .filter(a -> Integer.parseInt(a[1]) > 100) // 过滤体重 > 100
            .map(a -> a[0])                             // 只保留 name
            .sorted(Comparator.reverseOrder())          // 按 name 降序
            .collect(Collectors.toList());
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. Pandas 方法链：每个操作返回新 DataFrame，可继续调用下一个方法
2. `sort_values(ascending=False)` 降序排列
3. Java Stream API 提供类似的链式操作能力
