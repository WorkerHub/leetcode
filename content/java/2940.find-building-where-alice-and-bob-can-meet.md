## 题目描述

每栋楼有高度，人只能向右移动到严格更高的楼。对每个查询(a,b)，找最左的楼使两人都能到达。

## 解题思路

离线处理：标准化a<=b后，简单情况直接回答，困难情况按b排序，从左到右扫描用最小堆管理悬挂查询。

## Java 代码实现

```java
class Solution {
    public int[] leftmostBuildingQueries(int[] heights, int[][] queries) {
        int n = heights.length, q = queries.length;
        int[] ans = new int[q];
        Arrays.fill(ans, -1);

        // 按右端点分组的悬挂查询
        List<int[]>[] pending = new List[n];
        for (int i = 0; i < n; i++) pending[i] = new ArrayList<>();

        for (int i = 0; i < q; i++) {
            int a = queries[i][0], b = queries[i][1];
            if (a > b) { int t = a; a = b; b = t; }
            if (a == b || heights[a] < heights[b]) {
                ans[i] = b;
            } else {
                // 需要找b右边第一个 > heights[a] 的位置
                pending[b].add(new int[]{heights[a], i});
            }
        }

        // 最小堆：{需要的最小高度, 查询下标}
        PriorityQueue<int[]> pq = new PriorityQueue<>((x, y) -> x[0] - y[0]);
        for (int i = 0; i < n; i++) {
            // 加入以i为右端点的查询
            for (int[] p : pending[i]) {
                pq.offer(p);
            }
            // 当前楼高度能满足哪些查询
            while (!pq.isEmpty() && pq.peek()[0] < heights[i]) {
                ans[pq.poll()[1]] = i;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+Q) logQ)
- **空间复杂度**：O(N+Q)

## 关键点总结

1. **标准化a<=b**：简化分析
2. **简单情况直接回答**：a==b或heights[a]<heights[b]
3. **离线+最小堆**：从左到右扫描，堆中查询按需要高度排序
