## 题目描述

给定严格递增的正整数数组 arr，找到最长的斐波那契式子序列的长度（X_i + X_{i+1} = X_{i+2}）。

**示例：**
```
输入：arr = [1,2,3,4,5,6,7,8]
输出：5（子序列 [1,2,3,5,8]）
```

## 解题思路

DP + 哈希表：dp[i][j] 表示以 arr[i], arr[j] 结尾的最长斐波那契子序列长度。通过哈希表快速查找前一个元素。

## Java 代码实现

```java
class Solution {
    public int lenLongestFibSubseq(int[] arr) {
        int n = arr.length;
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < n; i++) index.put(arr[i], i);

        int[][] dp = new int[n][n];
        int result = 0;

        for (int j = 0; j < n; j++) {
            for (int i = 0; i < j; i++) {
                int target = arr[j] - arr[i];
                // target 必须小于 arr[i] 才有效
                if (target < arr[i] && index.containsKey(target)) {
                    int k = index.get(target);
                    dp[i][j] = dp[k][i] + 1;
                    result = Math.max(result, dp[i][j]);
                }
            }
        }

        return result >= 1 ? result + 2 : 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **DP 状态**：以两个数结尾定义子序列
2. **哈希查找**：O(1) 查找前一个元素
3. **递推关系**：dp[i][j] = dp[k][i] + 1
