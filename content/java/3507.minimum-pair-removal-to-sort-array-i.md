## 题目描述

给定整数数组 `nums`（长度 <= 50）。每次操作选相邻两元素替换为它们的和，求使数组变为非递减有序所需的最少操作次数。

## 解题思路

数据规模小（n <= 50），直接模拟：每轮找第一个逆序对（`nums[i] > nums[i+1]`）并合并（取和），统计操作次数，直至无逆序对。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int minimumPairRemoval(int[] nums) {
        // 使用 ArrayList 方便删除元素
        List<Long> arr = new ArrayList<>();
        for (int x : nums) arr.add((long) x);

        int ops = 0;
        while (true) {
            int idx = -1;
            for (int i = 0; i < arr.size() - 1; i++) {
                if (arr.get(i) > arr.get(i + 1)) { idx = i; break; }
            }
            if (idx == -1) break; // 无逆序对
            arr.set(idx, arr.get(idx) + arr.get(idx + 1));
            arr.remove(idx + 1);
            ops++;
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，每次操作 O(n) 扫描，共至多 n-1 次
- 空间复杂度：O(n)

## 关键点总结

1. 每次合并第一个逆序对（较大元素在前），合并后可能产生新逆序对
2. 使用 long 防止合并后溢出
3. 结果初始值 0（已有序时直接返回）
