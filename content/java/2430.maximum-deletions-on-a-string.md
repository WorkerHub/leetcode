## 题目描述

给你仅由小写字母组成的字符串 `s`，每次操作可删除整个字符串，或若前 `i` 个字符等于接下来的 `i` 个字符则删除前 `i` 个字符。返回删除 `s` 所需的最大操作数。

## 解题思路

DP + Z 函数：`dp[i]` 为删除 `s[i:]` 的最大操作数，从右向左转移。对每个位置 `i` 计算 `s[i:]` 的 Z 函数，若 `z[j] >= j` 则说明 `s[i:i+j] == s[i+j:i+2j]`，可以转移 `dp[i] = max(dp[i], dp[i+j] + 1)`。

## Java 代码实现

```java
class Solution {
    // 计算字符串 t 的 Z 函数
    private int[] zFunction(char[] t, int start, int len) {
        int[] z = new int[len];
        z[0] = len;
        int l = 0, r = 0;
        for (int i = 1; i < len; i++) {
            if (i < r) z[i] = Math.min(r - i, z[i - l]);
            while (i + z[i] < len && t[start + z[i]] == t[start + i + z[i]]) {
                z[i]++;
            }
            if (i + z[i] > r) { l = i; r = i + z[i]; }
        }
        return z;
    }

    public int deleteString(String s) {
        int n = s.length();
        char[] ch = s.toCharArray();
        int[] dp = new int[n];

        for (int i = n - 1; i >= 0; i--) {
            dp[i] = 1; // 至少删除一次（整个字符串）
            int[] z = zFunction(ch, i, n - i);
            // 枚举可以删除的前缀长度 j
            for (int j = 1; j <= (n - i) / 2; j++) {
                // z[j] >= j 说明 s[i:i+j] == s[i+j:i+2j]
                if (z[j] >= j) {
                    dp[i] = Math.max(dp[i], dp[i + j] + 1);
                }
            }
        }
        return dp[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，每个位置计算 Z 函数 O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. DP 从右向左，`dp[i]` 依赖 `dp[i+j]`（j > 0）
2. Z 函数快速判断前缀相等：`z[j] >= j` 说明前 j 字符等于其后 j 字符
3. 初始化 `dp[i] = 1`（至少一次整体删除）
