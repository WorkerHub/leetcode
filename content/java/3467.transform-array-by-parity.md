## 题目描述

给你一个整数数组 `nums`，将所有奇数替换为 1、偶数替换为 0，然后对结果排序，返回变换后的数组。

## 解题思路

统计奇数个数（结果中 1 的个数），偶数个数（结果中 0 的个数），直接构造结果数组（先填 0，再填 1），无需真正排序。

## Java 代码实现

```java
class Solution {
    public int[] transformArray(int[] nums) {
        int oddCount = 0;
        for (int x : nums) {
            if (x % 2 == 1) oddCount++;
        }

        int[] result = new int[nums.length];
        // 后 oddCount 个位置填 1，其余填 0（数组默认为 0）
        for (int i = nums.length - oddCount; i < nums.length; i++) {
            result[i] = 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 奇数变 1，偶数变 0：等价于 `x % 2`
2. 排序后必然是先所有 0，再所有 1
3. 只需统计奇数个数，无需真正排序
