## 题目描述

解析字符串 `command`：`"G"` 保持不变，`"()"` 解释为 `"o"`，`"(al)"` 解释为 `"al"`。

## 解题思路

**字符串替换：** 依次将 `"()"` 替换为 `"o"`，`"(al)"` 替换为 `"al"`。

## Java 代码实现

```java
class Solution {
    public String interpret(String command) {
        return command.replace("()", "o").replace("(al)", "al");
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. Java `String.replace()` 替换所有出现的子串
2. 先替换 `"()"` 再替换 `"(al)"`，顺序不影响结果
