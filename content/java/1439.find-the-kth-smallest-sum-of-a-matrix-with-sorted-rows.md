## 题目描述

给你一个 `m x n` 的矩阵 `mat`，以及一个整数 `k`，矩阵中的每一行都以非递减顺序排列。

你可以从每一行中选出 1 个元素形成一个数组。返回所有可能数组中的第 `k` 个最小数组和。

**示例 1：**
```
输入：mat = [[1,3,11],[2,4,6]], k = 5
输出：7
解释：从每行选一个元素的所有可能数组和为：
[1+2, 1+4, 1+6, 3+2, 3+4, 3+6, 11+2, 11+4, 11+6]
= [3, 5, 7, 5, 7, 9, 13, 15, 17]
排序后：[3, 5, 5, 7, 7, 9, 13, 15, 17]
第 5 小的是 7。
```

**示例 2：**
```
输入：mat = [[1,3,11],[2,4,6]], k = 9
输出：17
```

**示例 3：**
```
输入：mat = [[1,10],[2,15],[3,25]], k = 3
输出：23
解释：[1+2+3, 1+2+25, 1+15+3] = [6, 28, 19]，前三小为 [6, 19, 28]，第 3 小为 23。
```

**提示：**
- `m == mat.length`
- `n == mat[0].length`
- `1 <= m, n <= 40`
- `1 <= mat[i][j] <= 5000`
- `1 <= k <= min(200, n^m)`
- `mat[i]` 是按非递减顺序排列的

## 解题思路

**核心思路：逐行合并，维护前 k 小的和**

将问题分解：先只考虑前 1 行，和就是第 1 行各元素；再合并第 2 行，和就是前 1 行每个值加上第 2 行每个值...

**逐行合并步骤：**
1. 初始 `candidates = row[0]`（第 1 行所有元素）。
2. 对于每一新行，将 `candidates` 中每个值与新行每个值相加，得到新的候选集合。
3. 对新候选集合排序，只保留前 `k` 个（因为之后只需第 k 小）。
4. 重复直到所有行处理完。

**为什么只保留前 k 个？**  
每次合并只需最终前 k 小的值，中间步骤中超过 k 的值不可能成为最终答案。

## Java 代码实现

### 方法一：逐行合并 + 排序保留前 k（推荐）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.List;

class Solution {
    public int kthSmallest(int[][] mat, int k) {
        int m = mat.length, n = mat[0].length;

        // 初始候选集合：第一行前 k 个元素
        List<Integer> candidates = new ArrayList<>();
        for (int j = 0; j < Math.min(n, k); j++) {
            candidates.add(mat[0][j]);
        }

        for (int rowIdx = 1; rowIdx < m; rowIdx++) {
            List<Integer> newCandidates = new ArrayList<>();

            // 将当前候选集中每个值与新行每个值相加
            for (int s : candidates) {
                for (int val : mat[rowIdx]) {
                    newCandidates.add(s + val);
                }
            }

            // 排序并保留前 k 个最小值
            Collections.sort(newCandidates);
            candidates = newCandidates.subList(0, Math.min(k, newCandidates.size()));
        }

        return candidates.get(k - 1);
    }
}
```

### 方法二：最小堆优化合并（更高效）

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class Solution {
    private int k;

    public int kthSmallest(int[][] mat, int k) {
        this.k = k;
        int m = mat.length;

        // 逐行合并
        int[] current = mat[0];
        for (int rowIdx = 1; rowIdx < m; rowIdx++) {
            current = mergeTwoRows(current, mat[rowIdx]);
        }

        return current[k - 1];
    }

    private int[] mergeTwoRows(int[] row1, int[] row2) {
        // 使用最小堆合并两行，返回前 k 个最小和
        // 堆元素：[和, row1下标, row2下标]
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        heap.offer(new int[]{row1[0] + row2[0], 0, 0});

        Map<Long, Boolean> visited = new HashMap<>();
        visited.put((long) 0 * 100 + 0, true);

        List<Integer> result = new java.util.ArrayList<>();

        while (!heap.isEmpty() && result.size() < k) {
            int[] curr = heap.poll();
            int s = curr[0], i = curr[1], j = curr[2];
            result.add(s);

            // 扩展 row1 的下一个（i+1）
            if (i + 1 < row1.length) {
                long key = (long) (i + 1) * 100 + j;
                if (!visited.containsKey(key)) {
                    heap.offer(new int[]{row1[i + 1] + row2[j], i + 1, j});
                    visited.put(key, true);
                }
            }

            // 扩展 row2 的下一个（j+1）
            if (j + 1 < row2.length) {
                long key = (long) i * 100 + (j + 1);
                if (!visited.containsKey(key)) {
                    heap.offer(new int[]{row1[i] + row2[j + 1], i, j + 1});
                    visited.put(key, true);
                }
            }
        }

        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

## 复杂度分析

- **方法一：**
  - 时间复杂度：O(m * k * n * log(kn))，每行合并时产生 k*n 个候选值，排序取前 k。
  - 空间复杂度：O(k*n)。
- **方法二（堆优化）：**
  - 时间复杂度：O(m * k * log k)，每行合并最多取 k 个元素，每次堆操作 O(log k)。
  - 空间复杂度：O(k)。

## 图解示例

```
mat = [[1,3,11],[2,4,6]], k=5

第一行：candidates = [1, 3, 11]（取前 k=5 个）

合并第二行 [2, 4, 6]：
  1+2=3, 1+4=5, 1+6=7
  3+2=5, 3+4=7, 3+6=9
  11+2=13, 11+4=15, 11+6=17
  全部：[3,5,7,5,7,9,13,15,17]
  排序：[3,5,5,7,7,9,13,15,17]
  保留前 5：[3,5,5,7,7]

第 k=5 小 = candidates.get(4) = 7
```

## 关键点总结

1. 逐行合并是分治的思想，每次合并两个有序数组的所有组合之和的前 k 小。
2. 只保留前 k 个候选值是关键剪枝：合并时超过 k 的值不可能成为最终第 k 小。
3. 方法二的堆优化在 k 小、n 大时效率更高。
4. Java 中 `Collections.sort()` 对 `List` 排序，`subList()` 截取前 k 个。

## 易错点

- 初始候选集合应只取第一行的前 k 个（已排序），而非全部。
- `candidates.get(k-1)` 而非 `candidates.get(k)`（下标从 0 开始）。
- 合并两行时注意生成的候选数量可能很大（k*n），需要排序后截断。
