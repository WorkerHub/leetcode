## 题目描述

给你一个日志数组 `logs`，其中 `logs[i] = [timestamp, x, y]` 表示 x 和 y 在时间 timestamp 成为朋友。返回所有人都成为熟人的最早时间，不存在返回 -1。

**示例：**
```
输入：logs = [[20190101,0,1],[20190104,3,4],[20190107,2,3],[20190211,1,5],[20190224,2,4],[20190301,0,3],[20190312,1,2],[20190322,4,5]], n = 6
输出：20190301
```

## 解题思路

并查集：按时间排序处理事件，每次合并两人所在集合，连通分量减为 1 时返回当前时间戳。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public int earliestAcq(int[][] logs, int n) {
        // 按时间戳排序
        Arrays.sort(logs, (a, b) -> a[0] - b[0]);

        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        int count = n; // 连通分量数

        for (int[] log : logs) {
            int rootX = find(log[1]);
            int rootY = find(log[2]);
            if (rootX != rootY) {
                parent[rootX] = rootY;
                count--;
                if (count == 1) return log[0];
            }
        }
        return -1;
    }

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log m + m α(n))，排序 + 并查集操作
- **空间复杂度**：O(n)

## 关键点总结

1. **并查集**：动态维护连通分量
2. **路径压缩**：优化 find 操作
3. **连通判断**：count == 1 表示所有人连通
