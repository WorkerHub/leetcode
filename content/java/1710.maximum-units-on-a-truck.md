## 题目描述

`boxTypes[i] = [numberOfBoxes, numberOfUnitsPerBox]`，卡车最多装 `truckSize` 箱，返回最大单元数量。

## 解题思路

**贪心：** 按每箱单元数降序排序，优先装单元数最多的箱子，直到装满。

## Java 代码实现

```java
class Solution {
    public int maximumUnits(int[][] boxTypes, int truckSize) {
        // 按每箱单元数降序排序
        Arrays.sort(boxTypes, (a, b) -> b[1] - a[1]);
        int totalUnits = 0, remaining = truckSize;
        for (int[] box : boxTypes) {
            int take = Math.min(box[0], remaining);
            totalUnits += take * box[1];
            remaining -= take;
            if (remaining == 0) break;
        }
        return totalUnits;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：每箱单元数越大越优先
2. 取 `min(可用箱数, 剩余容量)` 装箱
