## 题目描述

给定 m×n 矩阵和阈值 threshold，返回元素总和 ≤ threshold 的正方形区域的最大边长。无满足条件的返回 0。

**示例：**
```
输入：mat = [[1,1,3,2,4,3,2],[1,1,3,2,4,3,2],[1,1,3,2,4,3,2]], threshold = 4
输出：2
```

## 解题思路

二维前缀和 + 枚举边长：预计算前缀和数组，枚举每个位置和边长，O(1) 计算区域和。

## Java 代码实现

```java
class Solution {
    public int maxSideLength(int[][] mat, int threshold) {
        int m = mat.length, n = mat[0].length;
        int[][] prefix = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefix[i][j] = mat[i-1][j-1] + prefix[i-1][j]
                             + prefix[i][j-1] - prefix[i-1][j-1];
            }
        }
        
        int maxSide = 0;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                for (int k = maxSide + 1; i - k >= 0 && j - k >= 0; k++) {
                    int sum = prefix[i][j] - prefix[i-k][j]
                            - prefix[i][j-k] + prefix[i-k][j-k];
                    if (sum <= threshold) maxSide = k;
                    else break;
                }
            }
        }
        return maxSide;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n × min(m, n))
- **空间复杂度**：O(m × n)

## 关键点总结

1. **二维前缀和**：O(1) 计算任意矩形区域和
2. **单调性优化**：从 maxSide+1 开始尝试
3. **break 剪枝**：超过阈值后更大的边长也不行
