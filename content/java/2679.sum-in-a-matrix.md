## 题目描述

给你矩阵 `nums`，每步从每行取最大值删除，将本步所有行最大值中的最大值计入分数，重复直到矩阵为空，返回总分数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int matrixSum(int[][] nums) {
        // 对每行降序排序，第 j 列对应第 j 轮的每行最大值
        for (int[] row : nums) Arrays.sort(row);
        int m = nums.length, n = nums[0].length;
        int ans = 0;
        for (int j = n - 1; j >= 0; j--) {
            // 第 j 轮：取各行在 j 列的值中的最大值
            int colMax = 0;
            for (int i = 0; i < m; i++) colMax = Math.max(colMax, nums[i][j]);
            ans += colMax;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 对每行排序后，第 j 轮 = 各行第 j 大元素（排序后的第 j 列）中的最大值
2. 每轮分数为列最大值，不是所有行最大值之和
