## 题目描述

给你两个长度相等的字符串 `s` 和 `t`。每一步中，你可以选择将 `t` 中的**任一字符**替换为**其他任意字符**。

返回使 `t` 成为 `s` 的异位词的最少步骤数。

**异位词** 是指字母相同，但排列不同（或相同）的字符串。

**示例 1：**
```
输入：s = "bab", t = "aba"
输出：1
解释：把 t 中第一个 'a' 替换为 'b'，t = "bba"，t 是 s 的异位词。
```

**示例 2：**
```
输入：s = "leetcode", t = "practice"
输出：5
解释：把 t 替换5个字符，使 t 成为 s 的异位词。
```

**示例 3：**
```
输入：s = "anagram", t = "mangaar"
输出：0
解释：s 和 t 已经是异位词了。
```

**提示：**
- `1 <= s.length <= 50000`
- `s.length == t.length`
- `s` 和 `t` 只包含小写英文字母

## 解题思路

**核心思路：统计字符频率差**

异位词要求两个字符串每个字母出现次数相同。

**分析：**
- 统计 `s` 中每个字符出现的次数 `freqS`
- 统计 `t` 中每个字符出现的次数 `freqT`
- 对于每个字符 `c`：
  - 若 `freqS[c] > freqT[c]`：`t` 中需要增加 `freqS[c] - freqT[c]` 个 `c`
  - 若 `freqS[c] < freqT[c]`：`t` 中需要减少 `freqT[c] - freqS[c]` 个 `c`

每次替换可以将多余的字符换成缺少的字符，因此步骤数 = 需要增加的字符总数（等于需要减少的字符总数）。

**结论：** 答案 = `sum(max(0, freqS[c] - freqT[c]) for each c in 'a'-'z')`

## Java 代码实现

### 方法一：字符频率数组（推荐）

```java
class Solution {
    public int minSteps(String s, String t) {
        // 使用频率数组，26个字母
        int[] freq = new int[26];
        
        // s 的字符计数 +1
        for (char c : s.toCharArray()) freq[c - 'a']++;
        
        // t 的字符计数 -1
        for (char c : t.toCharArray()) freq[c - 'a']--;
        
        // 正值之和 = 需要替换的步数
        int steps = 0;
        for (int f : freq) steps += Math.max(0, f);
        return steps;
    }
}
```

### 方法二：HashMap 统计差值

```java
import java.util.*;

class Solution {
    public int minSteps(String s, String t) {
        Map<Character, Integer> freqS = new HashMap<>();
        Map<Character, Integer> freqT = new HashMap<>();
        
        // 统计 s 的字符频率
        for (char c : s.toCharArray()) freqS.merge(c, 1, Integer::sum);
        // 统计 t 的字符频率
        for (char c : t.toCharArray()) freqT.merge(c, 1, Integer::sum);
        
        // 计算 s 中比 t 多的字符数之和
        int steps = 0;
        for (char c : freqS.keySet()) {
            int diff = freqS.get(c) - freqT.getOrDefault(c, 0);
            if (diff > 0) steps += diff;
        }
        return steps;
    }
}
```

### 方法三：一次遍历，逐步消耗

```java
import java.util.*;

class Solution {
    public int minSteps(String s, String t) {
        // 统计 s 的字符频率
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) count.merge(c, 1, Integer::sum);
        
        // 从 t 的字符中消耗 count
        for (char c : t.toCharArray()) {
            if (count.getOrDefault(c, 0) > 0) {
                count.merge(c, -1, Integer::sum);
            }
        }
        
        // 剩余未被消耗的是需要额外补充的
        int steps = 0;
        for (int v : count.values()) if (v > 0) steps += v;
        return steps;
    }
}
```

## 图解示例

以 `s = "leetcode", t = "practice"` 为例：

```
s 的字符频率：{l:1, e:3, t:1, c:1, o:1, d:1}
t 的字符频率：{p:1, r:1, a:1, c:2, t:1, i:1, e:1}

差值（s - t）：
l: 1-0 = +1（需要增加）
e: 3-1 = +2（需要增加）
t: 1-1 = 0
c: 1-2 = -1（t 中有多余的 c）
o: 1-0 = +1（需要增加）
d: 1-0 = +1（需要增加）
p: 0-1 = -1（t 中有多余的 p）
r: 0-1 = -1（t 中有多余的 r）
a: 0-1 = -1（t 中有多余的 a）
i: 0-1 = -1（t 中有多余的 i）

需要增加的总量 = 1 + 2 + 1 + 1 = 5

答案：5
```

## 关键点总结

1. 异位词要求每个字符出现次数相同
2. 每次替换可以同时减少一个多余字符并增加一个缺少字符
3. 步骤数 = s 中比 t 多的字符总数（等于 t 中比 s 多的字符总数）
4. 使用长度 26 的数组比 HashMap 更高效

## 易错点

1. 注意理解"步骤数 = 正差之和"：因为每步替换同时处理一个多余的和一个缺少的
2. 方法一中 `freq` 正值和等于负值和（因为两字符串长度相同），所以只统计正值即可
3. Java 中 `char` 减法和加法：`c - 'a'` 得到 0~25 的索引
