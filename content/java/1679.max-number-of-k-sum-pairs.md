## 题目描述

整数数组 `nums` 和整数 `k`，每次操作选两个数之和等于 `k` 的元素并移除。返回最多操作次数。

## 解题思路

**排序 + 双指针：** 排序后，左右指针逼近。和等于 k 时计数并双向移动；和小于 k 则左指针右移；和大于 k 则右指针左移。

## Java 代码实现

```java
class Solution {
    public int maxOperations(int[] nums, int k) {
        Arrays.sort(nums);
        int left = 0, right = nums.length - 1, ops = 0;
        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == k) {
                ops++;
                left++;
                right--;
            } else if (sum < k) {
                left++;
            } else {
                right--;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后双指针贪心匹配
2. 等于 k：两端同时移动，计数加一
3. 也可用 HashMap 计数（O(n) 时间）
