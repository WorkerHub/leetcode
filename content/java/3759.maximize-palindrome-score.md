## 题目描述

给定字符串 `s` 和整数 `k`，可以修改最多 `k` 个字符位置（替换为任意字符）。求修改后 `s` 的最长回文子串的长度。

## 解题思路

区间 DP 计算将 `s[i..j]` 变为回文的最少修改次数。若 `s[i] == s[j]` 则递归内层；否则代价加 1。枚举所有满足 `cost <= k` 的子串，取最长。

## Java 代码实现

```java
class Solution {
    public int maxPalindromeScore(String s, int k) {
        int n = s.length();
        // minOps[i][j]: 将 s[i..j] 变为回文的最少操作数
        int[][] minOps = new int[n][n];

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    minOps[i][j] = len > 2 ? minOps[i+1][j-1] : 0;
                } else {
                    minOps[i][j] = (len > 2 ? minOps[i+1][j-1] : 0) + 1;
                }
            }
        }

        int best = 1;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (minOps[i][j] <= k) {
                    best = Math.max(best, j - i + 1);
                }
            }
        }

        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)

## 关键点总结

1. 区间 DP 计算将子串变为回文的最少修改次数
2. 若 `s[i] == s[j]` 不需要额外修改；否则修改一次
3. 枚举所有满足 `cost <= k` 的子串取最长
