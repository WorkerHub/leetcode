## 题目描述

给你一个字符串 `s`，每一次操作你都可以在字符串的任意位置插入任意字符。

请你返回让 `s` 成为回文字符串的**最少操作次数**。

「回文字符串」是正读和反读都相同的字符串。

**示例 1：**

```
输入：s = "zzazz"
输出：0
解释："zzazz" 已经是回文串了，不需要任何插入操作
```

**示例 2：**

```
输入：s = "mbadm"
输出：2
解释：字符串可变为 "mbdadbm" 或者 "mdbabdm"
```

**示例 3：**

```
输入：s = "leetcode"
输出：5
解释：插入 5 个字符后字符串变为 "leetcodocteel"
```

**提示：**

- `1 <= s.length <= 500`
- `s` 中所有字符都是小写字母

## 解题思路

**方法一：转化为最长回文子序列（推荐）**

**核心结论：最少插入次数 = n - 最长回文子序列的长度**

**为什么？**

要把 `s` 变成回文串，最优策略是保留 `s` 中尽量长的回文子序列，然后对序列外的字符进行补全。每个不在最长回文子序列中的字符都需要插入一个对称字符。

因此：**最少插入次数 = n - LPS(s)**，其中 LPS = Longest Palindromic Subsequence（最长回文子序列）。

**LPS 的计算：**

`LPS(s) = LCS(s, reverse(s))`，即 s 与其反转的最长公共子序列。

---

**方法二：区间 DP 直接求解**

定义 `dp[i][j]` = 使子串 `s[i..j]` 成为回文串的最少插入次数。

状态转移：
- 若 `s[i] == s[j]`：`dp[i][j] = dp[i+1][j-1]`（两端字符相同，不需要额外插入）
- 若 `s[i] != s[j]`：`dp[i][j] = min(dp[i+1][j], dp[i][j-1]) + 1`

## Java 代码实现

### 方法一：转化为最长回文子序列（推荐）

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        // 最长回文子序列 = LCS(s, reversed(s))
        String t = new StringBuilder(s).reverse().toString();
        
        // 标准 LCS 动态规划
        int[][] dp = new int[n + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (s.charAt(i - 1) == t.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        
        int lps = dp[n][n]; // 最长回文子序列长度
        return n - lps;     // 需要插入的字符数
    }
}
```

### 方法二：区间 DP（直接求解）

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        // dp[i][j] 表示使 s[i..j] 成为回文串的最少插入次数
        int[][] dp = new int[n][n];
        
        // 按区间长度从小到大填表
        // 长度为 1 的区间：dp[i][i] = 0（单字符本身就是回文）
        // 从长度 2 开始枚举
        for (int length = 2; length <= n; length++) {
            for (int i = 0; i <= n - length; i++) {
                int j = i + length - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    // 两端相同，递归处理内部子串
                    dp[i][j] = (length > 2) ? dp[i + 1][j - 1] : 0;
                } else {
                    // 两端不同，选择代价更小的一侧插入
                    dp[i][j] = Math.min(dp[i + 1][j], dp[i][j - 1]) + 1;
                }
            }
        }
        
        return dp[0][n - 1];
    }
}
```

### 方法三：区间 DP（空间优化版）

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        // 滚动数组优化空间，每次只需要上一行
        int[] prev = new int[n];
        int[] curr = new int[n];
        
        for (int i = n - 2; i >= 0; i--) { // 从下往上遍历
            curr = new int[n];
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    curr[j] = prev[j - 1]; // 对应 dp[i+1][j-1]
                } else {
                    curr[j] = Math.min(prev[j], curr[j - 1]) + 1;
                }
            }
            prev = curr.clone();
        }
        
        return prev[n - 1];
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 最长回文子序列（LCS） | O(n^2) | O(n^2) |
| 区间 DP | O(n^2) | O(n^2) |
| 区间 DP 空间优化 | O(n^2) | O(n) |

## 图解示例

以 `s = "leetcode"` 为例，展示区间 DP 的思路：

```
s = "leetcode"，n = 8
最长回文子序列："ete" 或 "eoe" 等，长度为 3
最少插入次数 = 8 - 3 = 5
```

## 关键点总结

1. **关键转化**：最少插入次数 = n - 最长回文子序列长度
2. **最长回文子序列 = LCS(s, s的反转)**
3. 区间 DP 的枚举顺序：按区间长度从小到大（或 i 从大到小）
4. 两端字符相同时不需要额外操作，直接继承内部子串的结果
5. 两端字符不同时，选择 min(左端向内，右端向内) + 1

## 易错点

1. **区间 DP 初始化**：长度为 1 时 `dp[i][i] = 0`，长度为 2 时需要特殊处理避免 `dp[i+1][j-1]` 中 `i+1 > j-1`
2. **枚举顺序**：区间 DP 必须保证计算 `dp[i][j]` 时 `dp[i+1][j-1]`、`dp[i+1][j]`、`dp[i][j-1]` 已计算完
3. **LCS 解法的正确性**：需理解"保留最长回文子序列，为其余字符补对称字符"这一思路
