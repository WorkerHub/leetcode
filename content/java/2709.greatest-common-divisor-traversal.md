## 题目描述

给你整数数组 `nums`，若两数 GCD > 1 则可互相移动，判断是否能从任意数出发遍历所有数。

## Java 代码实现

```java
class Solution {
    private int[] parent;

    public boolean canTraverseAllPairs(int[] nums) {
        int n = nums.length;
        if (n == 1) return true;

        int MAX = 0;
        for (int v : nums) MAX = Math.max(MAX, v);

        parent = new int[n + MAX + 1];
        for (int i = 0; i < parent.length; i++) parent[i] = i;

        for (int i = 0; i < n; i++) {
            int temp = nums[i];
            // 分解质因数，将数与质因数合并
            for (int d = 2; (long) d * d <= temp; d++) {
                if (temp % d == 0) {
                    union(i, n + d); // 数 i 与质因数 d 合并（质因数偏移 n）
                    while (temp % d == 0) temp /= d;
                }
            }
            if (temp > 1) union(i, n + temp); // 剩余的大质因数
        }

        // 检查所有数是否在同一连通分量
        int root = find(0);
        for (int i = 1; i < n; i++) {
            if (find(i) != root) return false;
        }
        return true;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * sqrt(max(nums)))
- 空间复杂度：O(n + max(nums))

## 关键点总结

1. 质因数作为桥梁节点：两数有公共质因数则连通
2. 并查集节点 0..n-1 为数组元素，n..n+MAX 为质因数
3. n=1 时特判，数组中含 1 时该元素孤立（直接返回 false）
