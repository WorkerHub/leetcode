## 题目描述

给你字符串数组 `message` 和 `bannedWords`，若 message 中包含至少 2 个 bannedWords 中的单词则返回 `true`，否则返回 `false`。

## 解题思路

将 bannedWords 转为 HashSet，遍历 message 统计命中数量，遇到第 2 个命中立即返回 true。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public boolean reportSpam(String[] message, String[] bannedWords) {
        Set<String> banned = new HashSet<>(Arrays.asList(bannedWords));
        int count = 0;
        for (String word : message) {
            if (banned.contains(word)) {
                count++;
                if (count >= 2) return true; // 早退优化
            }
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，n 为 message 长度，m 为 bannedWords 长度
- 空间复杂度：O(m)

## 关键点总结

1. bannedWords 转为 HashSet，O(1) 查询
2. 统计 message 中被封禁单词数，≥2 即为垃圾邮件
3. 提前退出：找到第 2 个命中立即返回
