## 题目描述

给你正整数数组 `nums`，每次操作可将相邻两元素之一替换为它们的 GCD，返回将所有元素变为 1 的最少操作次数，不可能则返回 -1。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        // 若已有 1，直接扩散
        int ones = 0;
        for (int x : nums) if (x == 1) ones++;
        if (ones > 0) return n - ones;

        // 找最短 GCD 为 1 的子数组
        int minLen = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int g = 0;
            for (int j = i; j < n; j++) {
                g = gcd(g, nums[j]);
                if (g == 1) {
                    minLen = Math.min(minLen, j - i);
                    break;
                }
            }
        }
        // 不存在 GCD=1 的子数组，返回 -1
        return minLen == Integer.MAX_VALUE ? -1 : minLen + n - 1;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 log M)，M 为最大值
- 空间复杂度：O(1)

## 关键点总结

1. 若总 GCD != 1，不可能全变 1（返回 -1）
2. 已有 1 时直接扩散：`n - ones` 次
3. 无 1 时：先用 `minLen` 次生成 1，再扩散 `n - 1` 次，共 `minLen + n - 1` 次
