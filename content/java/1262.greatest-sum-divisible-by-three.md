## 题目描述

给定整数数组 nums，返回能被 3 整除的元素最大和。

**示例：**
```
输入：nums = [3,6,5,1,8]
输出：18
解释：选出 3, 6, 1, 8，和为 18
```

## 解题思路

DP 状态机：dp[i] 表示余数为 i 时的最大和。对每个数，更新三个状态。

## Java 代码实现

```java
class Solution {
    public int maxSumDivThree(int[] nums) {
        // dp[i] 表示余数为 i 的最大和
        long[] dp = new long[]{0, Long.MIN_VALUE, Long.MIN_VALUE};
        
        for (int num : nums) {
            long[] temp = dp.clone();
            for (int i = 0; i < 3; i++) {
                int newRemainder = (int)((temp[i] + num) % 3);
                dp[newRemainder] = Math.max(dp[newRemainder], temp[i] + num);
            }
        }
        return (int) dp[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **状态定义**：dp[r] = 余数为 r 的最大和
2. **状态转移**：加入新数后余数变化
3. **初始化**：dp[0]=0，dp[1]=dp[2]=负无穷
4. **答案**：dp[0] 即余数为 0 的最大和
