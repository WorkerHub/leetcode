## 题目描述

给你一个数组 `rectangles`，其中 `rectangles[i] = [xi, yi, ai, bi]` 表示一个坐标轴平行的矩形。这个矩形的左下顶点是 `(xi, yi)`，右上顶点是 `(ai, bi)`。

如果所有矩形一起精确覆盖了某个矩形区域，则返回 `true`；否则，返回 `false`。

**示例 1:**

![](https://assets.leetcode.com/uploads/2021/03/27/perectrec1-plane.jpg)

```
输入：rectangles = [[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]
输出：true
解释：5 个矩形一起可以精确地覆盖一个矩形区域。
```

**示例 2:**

![](https://assets.leetcode.com/uploads/2021/03/27/perfectrec2-plane.jpg)

```
输入：rectangles = [[1,1,2,3],[1,3,2,4],[3,1,4,2],[3,2,4,4]]
输出：false
解释：两个矩形之间有间隔，无法覆盖成一个大的矩形。
```

**示例 3:**

![](https://assets.leetcode.com/uploads/2021/03/27/perfecrrec4-plane.jpg)

```
输入：rectangles = [[1,1,3,3],[3,1,4,2],[1,3,2,4],[2,2,4,4]]
输出：false
解释：因为中间有相交区域，虽然形成了矩形，但不是精确覆盖。
```

**提示:**

- `1 <= rectangles.length <= 2 * 10^4`
- `rectangles[i].length == 4`
- `-10^5 <= xi < ai <= 10^5`
- `-10^5 <= yi < bi <= 10^5`

## 解题思路

这是一道经典的**几何问题**，需要判断多个矩形是否恰好组成一个大矩形（无重叠、无间隙）。

### 核心思想

**判断条件：**

1. **面积相等**：所有小矩形面积之和 = 大矩形面积
2. **顶点唯一性**：
   - 大矩形的 4 个顶点各出现 1 次
   - 内部顶点（公共点）必须出现偶数次（2 次或 4 次）

**为什么检查顶点？**

- 如果矩形完美拼接，内部的点会被多个矩形共享
- 每个内部点被偶数个矩形的角覆盖（2 次或 4 次）
- 只有大矩形的 4 个角点出现奇数次（1 次）

**算法流程：**

1. 计算大矩形的边界和面积
2. 计算所有小矩形面积之和
3. 使用集合记录每个顶点的出现次数
4. 检查：
   - 面积是否相等
   - 是否恰好有 4 个出现奇数次的点
   - 这 4 个点是否是大矩形的 4 个角

## Java 代码实现

### 方法一：顶点计数 + 面积检查（推荐）⭐

```java
import java.util.*;

class Solution {
    public boolean isRectangleCover(int[][] rectangles) {
        // 计算大矩形的边界
        int x1 = Integer.MAX_VALUE, y1 = Integer.MAX_VALUE;
        int x2 = Integer.MIN_VALUE, y2 = Integer.MIN_VALUE;

        for (int[] rect : rectangles) {
            x1 = Math.min(x1, rect[0]);
            y1 = Math.min(y1, rect[1]);
            x2 = Math.max(x2, rect[2]);
            y2 = Math.max(y2, rect[3]);
        }

        // 大矩形的面积
        long expectedArea = (long)(x2 - x1) * (y2 - y1);

        // 所有小矩形的面积之和
        long actualArea = 0;

        // 记录每个顶点出现的次数（奇偶切换）
        Set<String> points = new HashSet<>();

        for (int[] rect : rectangles) {
            int xLeft = rect[0], yBottom = rect[1], xRight = rect[2], yTop = rect[3];

            // 累加面积
            actualArea += (long)(xRight - xLeft) * (yTop - yBottom);

            // 记录 4 个顶点
            String[] corners = {
                xLeft + "," + yBottom,
                xLeft + "," + yTop,
                xRight + "," + yBottom,
                xRight + "," + yTop
            };

            for (String corner : corners) {
                if (!points.add(corner)) {
                    points.remove(corner);  // 出现偶数次，删除
                }
            }
        }

        // 检查条件：
        // 1. 面积相等
        // 2. 只有 4 个点出现奇数次
        // 3. 这 4 个点恰好是大矩形的 4 个角
        if (actualArea != expectedArea) return false;
        if (points.size() != 4) return false;

        Set<String> expectedCorners = new HashSet<>(Arrays.asList(
            x1 + "," + y1, x1 + "," + y2,
            x2 + "," + y1, x2 + "," + y2
        ));
        return points.equals(expectedCorners);
    }
}
```

### 方法二：使用 HashMap 计数

```java
import java.util.*;

class Solution {
    public boolean isRectangleCover(int[][] rectangles) {
        // 计算边界
        int x1 = Integer.MAX_VALUE, y1 = Integer.MAX_VALUE;
        int x2 = Integer.MIN_VALUE, y2 = Integer.MIN_VALUE;

        for (int[] r : rectangles) {
            x1 = Math.min(x1, r[0]);
            y1 = Math.min(y1, r[1]);
            x2 = Math.max(x2, r[2]);
            y2 = Math.max(y2, r[3]);
        }

        long expectedArea = (long)(x2 - x1) * (y2 - y1);
        long actualArea = 0;

        Map<String, Integer> pointCount = new HashMap<>();

        for (int[] rect : rectangles) {
            int xLeft = rect[0], yBottom = rect[1], xRight = rect[2], yTop = rect[3];
            actualArea += (long)(xRight - xLeft) * (yTop - yBottom);

            // 记录 4 个顶点
            String[] corners = {
                xLeft + "," + yBottom,
                xLeft + "," + yTop,
                xRight + "," + yBottom,
                xRight + "," + yTop
            };
            for (String corner : corners) {
                pointCount.merge(corner, 1, Integer::sum);
            }
        }

        // 面积检查
        if (actualArea != expectedArea) return false;

        // 找出出现奇数次的点
        Set<String> oddPoints = new HashSet<>();
        for (Map.Entry<String, Integer> entry : pointCount.entrySet()) {
            int count = entry.getValue();
            if (count % 2 == 1) {
                oddPoints.add(entry.getKey());
            } else if (count != 2 && count != 4) {
                // 内部点必须出现 2 次或 4 次
                return false;
            }
        }

        // 检查奇数点是否是 4 个角
        Set<String> expectedCorners = new HashSet<>(Arrays.asList(
            x1 + "," + y1, x1 + "," + y2,
            x2 + "," + y1, x2 + "," + y2
        ));
        return oddPoints.equals(expectedCorners);
    }
}
```

### 方法三：优化的集合操作

```java
import java.util.*;

class Solution {
    public boolean isRectangleCover(int[][] rectangles) {
        long area = 0;
        Set<String> points = new HashSet<>();

        int xMin = Integer.MAX_VALUE, yMin = Integer.MAX_VALUE;
        int xMax = Integer.MIN_VALUE, yMax = Integer.MIN_VALUE;

        for (int[] rect : rectangles) {
            int x1 = rect[0], y1 = rect[1], x2 = rect[2], y2 = rect[3];

            // 更新边界
            xMin = Math.min(xMin, x1);
            yMin = Math.min(yMin, y1);
            xMax = Math.max(xMax, x2);
            yMax = Math.max(yMax, y2);

            // 累加面积
            area += (long)(x2 - x1) * (y2 - y1);

            // 切换顶点状态
            String[] corners = {
                x1 + "," + y1, x1 + "," + y2,
                x2 + "," + y1, x2 + "," + y2
            };
            for (String corner : corners) {
                if (!points.add(corner)) {
                    points.remove(corner);
                }
            }
        }

        // 检查
        long expectedArea = (long)(xMax - xMin) * (yMax - yMin);
        Set<String> expectedCorners = new HashSet<>(Arrays.asList(
            xMin + "," + yMin, xMin + "," + yMax,
            xMax + "," + yMin, xMax + "," + yMax
        ));

        return area == expectedArea && points.equals(expectedCorners);
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 需要遍历所有矩形一次
- 每个矩形处理 4 个顶点，集合操作 O(1)

**空间复杂度：** O(n)
- 最坏情况下，集合需要存储所有顶点
- 实际上内部顶点会抵消，空间较小

## 关键点总结

1. **面积检查**：必要但不充分条件，还需要检查顶点
2. **顶点奇偶性**：内部点出现偶数次，角点出现奇数次
3. **集合的妙用**：通过添加/删除实现计数的奇偶性检查
4. **边界计算**：找到所有矩形的最小/最大坐标
5. **完整性检查**：面积 + 顶点两个条件缺一不可

## 易错点

1. **只检查面积**：面积相等不代表无重叠
2. **顶点计数错误**：内部点可能出现 2 次或 4 次
3. **浮点数精度**：本题是整数坐标，不用担心精度问题
4. **边界情况**：单个矩形、矩形退化为线等
5. **忘记检查角点**：必须验证 4 个奇数点是否是预期的角
