## 题目描述

给你 n 节点无根树、猜测列表 `guesses`（[u,v] 表示 u 是 v 的父节点）和整数 k，返回选择多少个根节点时至少有 k 个猜测正确。

## 解题思路

换根 DP：先以 0 为根做 DFS 计算基准正确猜测数；再做第二次 DFS 换根，从父节点切换到子节点时调整计数（(p,c) 失效，(c,p) 可能生效），统计满足条件的根数。

## Java 代码实现

```java
import java.util.*;

class Solution {
    List<Integer>[] graph;
    Set<Long> guessSet;
    int[] cnt;
    int k, ans;

    public int rootCount(int[][] edges, int[][] guesses, int k) {
        int n = edges.length + 1;
        this.k = k;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }
        guessSet = new HashSet<>();
        for (int[] g : guesses) guessSet.add((long) g[0] * n + g[1]);

        // 第一次 DFS：计算以 0 为根的正确猜测数
        int base = dfs1(0, -1, n);

        // 第二次 DFS：换根统计
        ans = 0;
        dfs2(0, -1, base);
        return ans;
    }

    private int dfs1(int node, int parent, int n) {
        int count = 0;
        for (int child : graph[node]) {
            if (child != parent) {
                if (guessSet.contains((long) node * (graph.length) + child)) count++;
                count += dfs1(child, node, n);
            }
        }
        return count;
    }

    private void dfs2(int node, int parent, int curCount) {
        if (curCount >= k) ans++;
        for (int child : graph[node]) {
            if (child != parent) {
                int next = curCount;
                if (guessSet.contains((long) node * graph.length + child)) next--;
                if (guessSet.contains((long) child * graph.length + node)) next++;
                dfs2(child, node, next);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + |guesses|)
- **空间复杂度**：O(n + |guesses|)

## 关键点总结

1. 换根时只有直接父子关系的猜测受影响：(p,c) 失效，(c,p) 可能生效
2. 用 `node * n + child` 编码边为 long，HashSet 实现 O(1) 查找
3. 两次 DFS 完成换根 DP，避免 O(n²) 暴力枚举
