## 题目描述

给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 `0` 到 `9` 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：

- 例如，从根节点到叶节点的路径 `1 -> 2 -> 3` 表示数字 `123`。

计算从根节点到叶节点生成的**所有数字之和**。

**叶节点**是指没有子节点的节点。

**示例 1：**
```
输入: root = [1,2,3]
    1
   / \
  2   3
输出: 25
解释:
从根到叶子节点路径 1->2 代表数字 12
从根到叶子节点路径 1->3 代表数字 13
因此，数字总和 = 12 + 13 = 25
```

**示例 2：**
```
输入: root = [4,9,0,5,1]
      4
     / \
    9   0
   / \
  5   1
输出: 1026
解释:
从根到叶子节点路径 4->9->5 代表数字 495
从根到叶子节点路径 4->9->1 代表数字 491
从根到叶子节点路径 4->0 代表数字 40
因此，数字总和 = 495 + 491 + 40 = 1026
```

**提示：**
- 树中节点的数目在范围 `[1, 1000]` 内
- `0 <= Node.val <= 9`
- 树的深度不超过 `10`

## 解题思路

这是一道典型的**二叉树路径问题**，核心是 **DFS（深度优先搜索）**。

### 核心思想：

1. **DFS 遍历所有路径**：从根节点到每个叶子节点
2. **累加路径数字**：每向下一层，当前数字 = 上层数字 × 10 + 当前节点值
3. **叶子节点处理**：到达叶子节点时，将当前数字加入总和

### 算法步骤：

1. 定义递归函数 `dfs(node, currentNum)`
2. 如果是叶子节点，返回当前累积的数字
3. 如果不是叶子节点，递归左右子树，累加结果
4. 每次递归时，更新当前数字：`currentNum = currentNum * 10 + node.val`

### 示例演示：

```
输入: [1,2,3]
    1
   / \
  2   3

路径1: 1 -> 2
  第1层: currentNum = 0 * 10 + 1 = 1
  第2层: currentNum = 1 * 10 + 2 = 12 (叶子节点)

路径2: 1 -> 3
  第1层: currentNum = 0 * 10 + 1 = 1
  第2层: currentNum = 1 * 10 + 3 = 13 (叶子节点)

总和: 12 + 13 = 25
```

## Java 代码实现

### 方法一：递归 DFS（推荐）

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int currentNum) {
        if (node == null) return 0;

        // 更新当前路径的数字
        currentNum = currentNum * 10 + node.val;

        // 叶子节点：返回当前数字
        if (node.left == null && node.right == null) {
            return currentNum;
        }

        // 非叶子节点：递归左右子树，累加结果
        return dfs(node.left, currentNum) + dfs(node.right, currentNum);
    }
}
```

### 方法二：迭代 DFS（使用栈）

```java
class Solution {
    public int sumNumbers(TreeNode root) {
        if (root == null) return 0;

        int totalSum = 0;
        // 栈中存储 [节点, 当前路径数字]
        Deque<int[]> stack = new ArrayDeque<>();
        // 使用 Object 数组存储节点和数字
        Deque<Object[]> objStack = new ArrayDeque<>();
        objStack.push(new Object[]{root, root.val});

        while (!objStack.isEmpty()) {
            Object[] top = objStack.pop();
            TreeNode node = (TreeNode) top[0];
            int currentNum = (int) top[1];

            // 叶子节点
            if (node.left == null && node.right == null) {
                totalSum += currentNum;
            }

            // 右子树（后进先出，所以先压入右子树）
            if (node.right != null) {
                objStack.push(new Object[]{node.right, currentNum * 10 + node.right.val});
            }

            // 左子树
            if (node.left != null) {
                objStack.push(new Object[]{node.left, currentNum * 10 + node.left.val});
            }
        }

        return totalSum;
    }
}
```

### 方法三：BFS（使用队列）

```java
class Solution {
    public int sumNumbers(TreeNode root) {
        if (root == null) return 0;

        int totalSum = 0;
        // 队列中存储节点，另一个队列存储对应的路径数字
        Queue<TreeNode> nodeQueue = new LinkedList<>();
        Queue<Integer> numQueue = new LinkedList<>();
        nodeQueue.offer(root);
        numQueue.offer(root.val);

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            int currentNum = numQueue.poll();

            // 叶子节点
            if (node.left == null && node.right == null) {
                totalSum += currentNum;
            }

            // 左子树
            if (node.left != null) {
                nodeQueue.offer(node.left);
                numQueue.offer(currentNum * 10 + node.left.val);
            }

            // 右子树
            if (node.right != null) {
                nodeQueue.offer(node.right);
                numQueue.offer(currentNum * 10 + node.right.val);
            }
        }

        return totalSum;
    }
}
```

### 方法四：实例变量版

```java
class Solution {
    private int total = 0;

    public int sumNumbers(TreeNode root) {
        dfs(root, 0);
        return total;
    }

    private void dfs(TreeNode node, int currentNum) {
        if (node == null) return;

        currentNum = currentNum * 10 + node.val;

        // 叶子节点
        if (node.left == null && node.right == null) {
            total += currentNum;
            return;
        }

        dfs(node.left, currentNum);
        dfs(node.right, currentNum);
    }
}
```

## 复杂度分析

设树的节点数为 n。

### 方法一：递归 DFS
- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(h)，h 是树的高度
  - 最好情况（平衡树）：O(log n)
  - 最坏情况（链状树）：O(n)

### 方法二/三：迭代 DFS/BFS
- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，栈/队列最多存储所有节点

## 关键点总结

1. **数字构造方式**：`currentNum = currentNum * 10 + node.val`
2. **叶子节点判断**：`node.left == null && node.right == null`
3. **累加时机**：只在叶子节点累加，非叶子节点继续递归
4. **初始值传递**：从根节点开始，初始值为 0
5. **递归返回值**：返回左右子树的和

## 易错点

1. **非叶子节点也累加**
   ```java
   // 错误：所有节点都累加
   totalSum += currentNum;

   // 正确：只在叶子节点累加
   if (node.left == null && node.right == null) {
       totalSum += currentNum;
   }
   ```

2. **数字构造错误**
   ```java
   // 错误：数字拼接方式错误
   currentNum = currentNum + node.val;

   // 正确：每下一层乘以 10
   currentNum = currentNum * 10 + node.val;
   ```

3. **空节点处理**
   ```java
   // 必须处理空节点
   if (node == null) return 0;
   ```

4. **初始值错误**
   ```java
   // 错误：初始值传入 node.val
   dfs(root, root.val)

   // 正确：初始值为 0，在函数内计算
   dfs(root, 0)
   ```

5. **只有根节点的情况**：根节点也是叶子节点，`node.left == null && node.right == null` 可以正确处理
