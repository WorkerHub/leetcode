## 题目描述

给定字符串如 "{a,b}c{d,e}f"，花括号内为多选一，返回所有可能的单词（字典序）。

**示例：**
```
输入：s = "{a,b}c{d,e}f"
输出：["acdf","acef","bcdf","bcef"]
```

## 解题思路

解析字符串为选项组列表，然后回溯生成所有组合（笛卡尔积）。每组内排序保证字典序。

## Java 代码实现

```java
class Solution {
    public String[] expand(String s) {
        // 解析选项组
        List<char[]> options = new ArrayList<>();
        int i = 0;
        while (i < s.length()) {
            if (s.charAt(i) == '{') {
                int j = s.indexOf('}', i);
                char[] choices = s.substring(i + 1, j).replace(",", "").toCharArray();
                Arrays.sort(choices);
                options.add(choices);
                i = j + 1;
            } else {
                options.add(new char[]{s.charAt(i)});
                i++;
            }
        }

        // 回溯生成所有组合
        List<String> result = new ArrayList<>();
        backtrack(options, 0, new StringBuilder(), result);
        return result.toArray(new String[0]);
    }

    private void backtrack(List<char[]> options, int idx, StringBuilder sb, List<String> result) {
        if (idx == options.size()) {
            result.add(sb.toString());
            return;
        }
        for (char c : options.get(idx)) {
            sb.append(c);
            backtrack(options, idx + 1, sb, result);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m^k)，m 为平均选项数，k 为选项组数
- **空间复杂度**：O(m^k)

## 关键点总结

1. **字符串解析**：识别花括号与普通字符
2. **组内排序**：保证生成结果的字典序
3. **回溯模板**：选择→递归→撤销
