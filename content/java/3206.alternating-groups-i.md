## 题目描述

给你一个圆形整数数组 `colors`（0 表示红色，1 表示蓝色），返回长度为 3 的交替组（红蓝红或蓝红蓝）的数量。

## Java 代码实现

```java
class Solution {
    public int numberOfAlternatingGroups(int[] colors) {
        int n = colors.length;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            // 检查长度为 3 的窗口 [i-1, i, i+1]（圆形取模）
            int prev = colors[(i - 1 + n) % n];
            int curr = colors[i];
            int next = colors[(i + 1) % n];
            // 交替条件：中间元素与两侧都不同
            if (curr != prev && curr != next) {
                ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 圆形数组用取模 `% n` 处理边界
2. 交替组的判断：中间元素与两端均不相同
