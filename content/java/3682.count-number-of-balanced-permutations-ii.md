## 题目描述

给你一个数字字符串 `num`，如果排列中奇数下标的数字之和等于偶数下标的数字之和，则称其为平衡排列。返回不同平衡排列的数量，对 `10^9 + 7` 取模。

## 解题思路

DP + 组合数：若总和为奇数则无解。设目标 `half = total/2`，奇数位槽数 `odd = ceil(n/2)`。逐数字（9 到 0）决定放几个到奇数位，用 `C(剩余奇数槽, j) * C(剩余偶数槽, k-j)` 计算放置方式，DP 状态为 `(已占奇数槽数, 奇数位当前和)`。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    static final int MOD = 1_000_000_007;

    public int countBalancedPermutations(String num) {
        int n = num.length();
        int total = 0;
        int[] freq = new int[10];
        for (char c : num.toCharArray()) { int d = c - '0'; freq[d]++; total += d; }
        if (total % 2 != 0) return 0;

        int half = total / 2;
        int oddSlots = (n + 1) / 2;
        int evenSlots = n / 2;

        // 预计算组合数
        long[][] C = new long[n + 1][n + 1];
        for (int i = 0; i <= n; i++) {
            C[i][0] = 1;
            for (int j = 1; j <= i; j++) C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
        }

        // dp: key=(已占奇数槽, 奇数位当前和), value=方案数
        Map<Long, Long> dp = new HashMap<>();
        dp.put(0L, 1L);
        int placed = 0;

        for (int digit = 9; digit >= 0; digit--) {
            int k = freq[digit];
            if (k == 0) continue;
            Map<Long, Long> newDp = new HashMap<>();
            for (Map.Entry<Long, Long> e : dp.entrySet()) {
                int ou = (int)(e.getKey() >> 16);
                int os = (int)(e.getKey() & 0xFFFF);
                int eu = placed - ou;
                for (int j = 0; j <= k; j++) {
                    int nou = ou + j, nos = os + digit * j, neu = eu + (k - j);
                    if (nou > oddSlots || neu > evenSlots || nos > half) continue;
                    long ways = e.getValue() * C[oddSlots - ou][j] % MOD * C[evenSlots - eu][k - j] % MOD;
                    long key = ((long) nou << 16) | nos;
                    newDp.merge(key, ways, (a, b) -> (a + b) % MOD);
                }
            }
            dp = newDp;
            placed += k;
        }
        long key = ((long) oddSlots << 16) | half;
        return (int) dp.getOrDefault(key, 0L);
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * n * S)，S 为数字总和
- 空间复杂度：O(n * S)

## 关键点总结

1. 总和为奇数时无解；奇/偶位槽数固定
2. 用 DP + 组合数处理重复数字的分配
3. `C(奇数剩余槽, j) * C(偶数剩余槽, k-j)` 计算分配方式数
