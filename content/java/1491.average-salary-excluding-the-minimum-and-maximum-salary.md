## 题目描述

给你一个整数数组 `salary`，数组里每个数都是**唯一**的，且都是正整数。

请你返回去掉最低工资和最高工资以后，剩余员工工资的**平均值**。

**示例 1：**

```
输入：salary = [4000, 3000, 1000, 2000]
输出：2500.00000
解释：最低工资 1000，最高工资 4000，去掉后平均值 = (3000+2000)/2 = 2500
```

**示例 2：**

```
输入：salary = [1000, 2000, 3000]
输出：2000.00000
解释：最低工资 1000，最高工资 3000，去掉后平均值 = 2000/1 = 2000
```

**提示：**

- `3 <= salary.length <= 100`
- `10^3 <= salary[i] <= 10^6`
- `salary` 中的所有数字都是唯一的。

## 解题思路

**方法一：数学公式（O(n)，推荐）**

直接利用公式：

```
平均值 = (总和 - 最大值 - 最小值) / (n - 2)
```

一次遍历同时求总和、最大值、最小值，效率最高。

**方法二：排序**

将数组排序后，去掉第一个（最小值）和最后一个（最大值），对中间元素求平均。

排序需要 O(n log n)，比方法一慢，但代码更直观。

## Java 代码实现

### 方法一：数学公式（推荐）

```java
class Solution {
    public double average(int[] salary) {
        // 利用公式：(总和 - 最大 - 最小) / (n - 2)
        int total = 0, minSal = Integer.MAX_VALUE, maxSal = Integer.MIN_VALUE;
        for (int s : salary) {
            total += s;
            minSal = Math.min(minSal, s);
            maxSal = Math.max(maxSal, s);
        }
        return (double) (total - minSal - maxSal) / (salary.length - 2);
    }
}
```

### 方法二：排序后截取

```java
import java.util.Arrays;

class Solution {
    public double average(int[] salary) {
        // 排序后去掉头尾元素
        Arrays.sort(salary);
        int sum = 0;
        // 跳过第一个（最小）和最后一个（最大）
        for (int i = 1; i < salary.length - 1; i++) {
            sum += salary[i];
        }
        return (double) sum / (salary.length - 2);
    }
}
```

### 方法三：一次遍历（手动维护最大最小值）

```java
class Solution {
    public double average(int[] salary) {
        int minSal = Integer.MAX_VALUE;   // 最低工资
        int maxSal = Integer.MIN_VALUE;   // 最高工资
        int total = 0;

        for (int s : salary) {
            total += s;
            if (s < minSal) minSal = s;
            if (s > maxSal) maxSal = s;
        }

        // 去掉最高和最低后求平均
        return (double) (total - minSal - maxSal) / (salary.length - 2);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（公式） | O(n) | O(1) |
| 方法二（排序） | O(n log n) | O(1) |
| 方法三（一次遍历） | O(n) | O(1) |

- 对于 `n <= 100` 的数据规模，所有方法实际运行时间几乎相同
- 方法一最优，O(n) 时间，O(1) 空间

## 关键点总结

1. **公式推导**：`(sum - max - min) / (n - 2)` 是最简洁的解法。
2. **Java 浮点除法**：`(double) (total - minSal - maxSal) / (salary.length - 2)` 中需要显式转为 `double`，否则会整除。
3. **排序法**：`Arrays.sort()` 后对 `[1, n-1)` 范围求和。
4. **题目保证**：所有数字唯一，数组长度 >= 3，无需处理边界情况。

## 易错点

- **整除问题**：Java 中整数除以整数会截断小数，返回 `double` 前必须先转型：`(double) 分子 / 分母`。
- **分母计算**：去掉两个元素后，分母是 `salary.length - 2`，不要写成 `salary.length`。
- **初始化极值**：`minSal` 初始为 `Integer.MAX_VALUE`，`maxSal` 初始为 `Integer.MIN_VALUE`。
