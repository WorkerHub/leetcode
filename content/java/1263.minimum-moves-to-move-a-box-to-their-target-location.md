## 题目描述

推箱子游戏：m×n 网格中，'S' 为玩家，'B' 为箱子，'T' 为目标，'.' 为空地，'#' 为墙。求将箱子推到目标的最少推动次数，无法完成返回 -1。

**示例：**
```
输入：grid = [["#","#","#","#","#","#"],
             ["#","T","#","#","#","#"],
             ["#",".",".","B",".","#"],
             ["#",".","#","#",".","#"],
             ["#",".",".",".","S","#"],
             ["#","#","#","#","#","#"]]
输出：3
```

## 解题思路

双层 BFS：外层 BFS 搜索箱子位置（每推一次为一步），内层 BFS 判断玩家能否到达推箱子所需的位置。状态为 (箱子位置, 玩家位置)。

## Java 代码实现

```java
class Solution {
    private static final int[][] DIRS = {{0,1},{0,-1},{1,0},{-1,0}};
    
    public int minPushBox(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] box = new int[2], player = new int[2], target = new int[2];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 'B') { box[0] = i; box[1] = j; }
                else if (grid[i][j] == 'S') { player[0] = i; player[1] = j; }
                else if (grid[i][j] == 'T') { target[0] = i; target[1] = j; }
            }
        }
        
        // 状态：(箱子行, 箱子列, 玩家行, 玩家列)
        // 用 0-1 BFS（Deque），推箱子代价1，玩家移动代价0
        boolean[][][][] visited = new boolean[m][n][m][n];
        Deque<int[]> deque = new ArrayDeque<>();
        deque.offerFirst(new int[]{box[0], box[1], player[0], player[1], 0});
        visited[box[0]][box[1]][player[0]][player[1]] = true;
        
        while (!deque.isEmpty()) {
            int[] curr = deque.pollFirst();
            int bx = curr[0], by = curr[1], px = curr[2], py = curr[3], pushes = curr[4];
            
            if (bx == target[0] && by == target[1]) return pushes;
            
            // 玩家移动（代价0）
            for (int[] d : DIRS) {
                int npx = px + d[0], npy = py + d[1];
                if (npx < 0 || npx >= m || npy < 0 || npy >= n) continue;
                if (grid[npx][npy] == '#') continue;
                if (npx == bx && npy == by) continue; // 不能走到箱子位置
                if (visited[bx][by][npx][npy]) continue;
                visited[bx][by][npx][npy] = true;
                deque.offerFirst(new int[]{bx, by, npx, npy, pushes});
            }
            
            // 推箱子（代价1）：玩家必须在箱子旁边且推动方向上箱子可移动
            for (int[] d : DIRS) {
                // 玩家需要在箱子的反方向
                int needPx = bx - d[0], needPy = by - d[1];
                int nbx = bx + d[0], nby = by + d[1];
                if (px != needPx || py != needPy) continue;
                if (nbx < 0 || nbx >= m || nby < 0 || nby >= n) continue;
                if (grid[nbx][nby] == '#') continue;
                if (visited[nbx][nby][bx][by]) continue;
                visited[nbx][nby][bx][by] = true;
                deque.offerLast(new int[]{nbx, nby, bx, by, pushes + 1});
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × n²)
- **空间复杂度**：O(m² × n²)

## 关键点总结

1. **0-1 BFS**：玩家移动代价 0（加队首），推箱子代价 1（加队尾）
2. **四维状态**：(箱子位置, 玩家位置) 避免重复
3. **推动条件**：玩家必须在箱子推动方向的反方向
4. **推后状态**：玩家移到箱子原位置
