## 题目描述

给你整数 `n` 和区间数组 `ranges`，返回 `[0, n-1]` 中未被任何区间覆盖的整数构成的最大区间列表（按起始值升序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[][] findMaximalUncoveredRanges(int n, int[][] ranges) {
        if (ranges.length == 0) return new int[][]{{0, n - 1}};

        Arrays.sort(ranges, (a, b) -> a[0] - b[0]);
        List<int[]> ans = new ArrayList<>();
        int prevEnd = -1;

        for (int[] range : ranges) {
            int start = range[0], end = range[1];
            // 当前区间左端与上一区间右端之间存在间隙
            if (start > prevEnd + 1) {
                ans.add(new int[]{prevEnd + 1, start - 1});
            }
            prevEnd = Math.max(prevEnd, end); // 合并重叠区间
        }
        // 检查末尾间隙
        if (prevEnd < n - 1) ans.add(new int[]{prevEnd + 1, n - 1});

        return ans.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m)，m 为区间数量
- 空间复杂度：O(m)

## 关键点总结

1. 排序后线性扫描，用 `prevEnd` 维护已覆盖右端
2. 间隙即为相邻覆盖区间之间的空隙，首尾需单独处理
