## 题目描述

找出平均数最大且长度为 `k` 的连续子数组，输出最大平均数。

**示例：**
```
输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75000
```

## 解题思路

固定大小滑动窗口：先计算前 k 个和，然后减左加右滑动。

## Java 代码实现

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        // 计算前k个元素的和
        int windowSum = 0;
        for (int i = 0; i < k; i++) {
            windowSum += nums[i];
        }
        int maxSum = windowSum;

        // 滑动窗口
        for (int i = k; i < nums.length; i++) {
            windowSum += nums[i] - nums[i - k];
            maxSum = Math.max(maxSum, windowSum);
        }

        return (double) maxSum / k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **固定窗口滑动**：减左加右
2. **记录最大和**：最后除以 k 得平均值
