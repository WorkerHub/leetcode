## 题目描述

给定 n 个节点的无向连通树，返回数组 answer，其中 answer[i] 是节点 i 到所有其他节点的距离之和。

**示例：**
```
输入：n = 6, edges = [[0,1],[0,2],[2,3],[2,4],[2,5]]
输出：[8,12,6,10,10,10]
```

## 解题思路

两次 DFS 换根 DP：第一次以 0 为根算出 ans[0] 和每个子树大小；第二次从根向下换根推导所有节点的答案。

## Java 代码实现

```java
class Solution {
    private List<Integer>[] graph;
    private int[] count; // 子树节点数
    private int[] ans;
    private int n;

    public int[] sumOfDistancesInTree(int n, int[][] edges) {
        this.n = n;
        graph = new List[n];
        count = new int[n];
        ans = new int[n];
        Arrays.fill(count, 1);

        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        // 第一次 DFS：计算子树大小和 ans[0]
        dfs(0, -1);
        // 第二次 DFS：换根
        dfs2(0, -1);
        return ans;
    }

    private void dfs(int node, int parent) {
        for (int child : graph[node]) {
            if (child != parent) {
                dfs(child, node);
                count[node] += count[child];
                ans[node] += ans[child] + count[child];
            }
        }
    }

    private void dfs2(int node, int parent) {
        for (int child : graph[node]) {
            if (child != parent) {
                // 从 node 换到 child：child 子树内节点近 1，外部节点远 1
                ans[child] = ans[node] - count[child] + (n - count[child]);
                dfs2(child, node);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **换根 DP**：利用父节点答案推导子节点答案
2. **两次 DFS**：第一次自底向上，第二次自顶向下
3. **公式推导**：ans[child] = ans[parent] - count[child] + (n - count[child])
