## 题目描述

将非负整数 num 转换为其对应的英文表示。

**示例 1：**
```
输入: num = 123
输出: "One Hundred Twenty Three"
```

**示例 2：**
```
输入: num = 12345
输出: "Twelve Thousand Three Hundred Forty Five"
```

**示例 3：**
```
输入: num = 1234567
输出: "One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven"
```

**提示：**
- 0 <= num <= 2^31 - 1

## 解题思路

这道题看似复杂，但只要找到规律就不难。

### 核心思路

英文数字的表示有规律：
1. **基本单位**：个位（0-9）、十位（10-19）、整十位（20-90）
2. **更大单位**：Hundred（百）、Thousand（千）、Million（百万）、Billion（十亿）

### 关键观察

1. 数字可以按照每三位分组：个、千、百万、十亿
   - 1234567 = 1,234,567 = 1 Million, 234 Thousand, 567
   
2. 每组内部的处理方式相同：
   - 百位 + "Hundred"
   - 十位和个位（特殊处理 10-19）

3. 特殊情况：
   - 0 单独处理为 "Zero"
   - 10-19 有特殊单词（Eleven, Twelve 等）
   - 避免多余空格

### 算法步骤

1. 准备单词映射表
2. 按照 Billion、Million、Thousand 的顺序处理每组
3. 每组内部按照百位、十位、个位处理
4. 拼接结果，去除多余空格

## Java 代码实现

### 方法一：递归分组处理（推荐）

```java
class Solution {
    // 1-19 的英文单词
    private final String[] BELOW_20 = {
        "", "One", "Two", "Three", "Four", "Five", "Six", "Seven",
        "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen",
        "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"
    };

    // 整十位的英文单词
    private final String[] TENS = {
        "", "", "Twenty", "Thirty", "Forty", "Fifty",
        "Sixty", "Seventy", "Eighty", "Ninety"
    };

    // 单位词（对应 10^0, 10^3, 10^6, 10^9）
    private final String[] THOUSANDS = {"", "Thousand", "Million", "Billion"};

    public String numberToWords(int num) {
        if (num == 0) return "Zero";

        StringBuilder result = new StringBuilder();
        int i = 0;

        // 从低位到高位，每三位处理一次
        while (num > 0) {
            if (num % 1000 != 0) {
                String part = helper(num % 1000);
                if (THOUSANDS[i].isEmpty()) {
                    result.insert(0, part.trim());
                } else {
                    result.insert(0, part.trim() + " " + THOUSANDS[i] + (result.length() > 0 ? " " : ""));
                }
            }
            num /= 1000;
            i++;
        }

        return result.toString().trim();
    }

    /**
     * 处理小于 1000 的数字，返回带尾部空格的字符串
     */
    private String helper(int n) {
        if (n == 0) {
            return "";
        } else if (n < 20) {
            return BELOW_20[n] + " ";
        } else if (n < 100) {
            return TENS[n / 10] + " " + helper(n % 10);
        } else {
            return BELOW_20[n / 100] + " Hundred " + helper(n % 100);
        }
    }
}
```

### 方法二：迭代处理（更清晰）

```java
class Solution {
    private final String[] ONES = {
        "", "One", "Two", "Three", "Four", "Five", "Six", "Seven",
        "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen",
        "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"
    };

    private final String[] TENS = {
        "", "", "Twenty", "Thirty", "Forty", "Fifty",
        "Sixty", "Seventy", "Eighty", "Ninety"
    };

    public String numberToWords(int num) {
        if (num == 0) return "Zero";

        // 处理每个单位
        long n = num; // 用 long 防止 2^31-1 处理时溢出
        long billion = n / 1_000_000_000;
        long million = (n / 1_000_000) % 1000;
        long thousand = (n / 1000) % 1000;
        long remainder = n % 1000;

        StringBuilder result = new StringBuilder();

        if (billion > 0) {
            result.append(convertBelowThousand((int) billion)).append(" Billion");
        }
        if (million > 0) {
            if (result.length() > 0) result.append(" ");
            result.append(convertBelowThousand((int) million)).append(" Million");
        }
        if (thousand > 0) {
            if (result.length() > 0) result.append(" ");
            result.append(convertBelowThousand((int) thousand)).append(" Thousand");
        }
        if (remainder > 0) {
            if (result.length() > 0) result.append(" ");
            result.append(convertBelowThousand((int) remainder));
        }

        return result.toString();
    }

    /**
     * 转换小于 1000 的数字
     */
    private String convertBelowThousand(int n) {
        if (n == 0) return "";
        if (n < 20) return ONES[n];
        if (n < 100) {
            String rest = n % 10 == 0 ? "" : " " + ONES[n % 10];
            return TENS[n / 10] + rest;
        }
        // 三位数
        String rest = n % 100 == 0 ? "" : " " + convertBelowThousand(n % 100);
        return ONES[n / 100] + " Hundred" + rest;
    }
}
```

### 方法三：完全展开版本（易理解）

```java
class Solution {
    private final String[] BELOW_20 = {
        "", "One", "Two", "Three", "Four", "Five", "Six",
        "Seven", "Eight", "Nine", "Ten", "Eleven", "Twelve",
        "Thirteen", "Fourteen", "Fifteen", "Sixteen",
        "Seventeen", "Eighteen", "Nineteen"
    };

    private final String[] TENS = {
        "", "", "Twenty", "Thirty", "Forty", "Fifty",
        "Sixty", "Seventy", "Eighty", "Ninety"
    };

    // 注意：从大到小排列，对应 Billion, Million, Thousand, 无后缀
    private final long[] UNITS = {1_000_000_000L, 1_000_000L, 1_000L, 1L};
    private final String[] UNIT_WORDS = {"Billion", "Million", "Thousand", ""};

    public String numberToWords(int num) {
        if (num == 0) return "Zero";
        return intToString(num).trim();
    }

    private String intToString(long num) {
        if (num == 0) return "";
        if (num < 20) return BELOW_20[(int) num] + " ";
        if (num < 100) return TENS[(int) (num / 10)] + " " + intToString(num % 10);
        if (num < 1000) return BELOW_20[(int) (num / 100)] + " Hundred " + intToString(num % 100);

        // 处理 thousand、million、billion
        for (int i = 0; i < UNITS.length - 1; i++) {
            if (num >= UNITS[i]) {
                return intToString(num / UNITS[i]) + UNIT_WORDS[i] + " " + intToString(num % UNITS[i]);
            }
        }
        return "";
    }
}
```

## 复杂度分析

**时间复杂度：** O(1)
- 虽然有循环和递归，但数字最大为 2^31 - 1
- 最多处理 4 组（Billion, Million, Thousand, 个位）
- 可以认为是常数时间

**空间复杂度：** O(1)
- 使用固定大小的字符串数组
- 递归深度有限（最多 4 层）

## 关键点总结

1. **分组思想**：按照每三位分组，分别处理 Billion、Million、Thousand
2. **递归处理**：每组内部可以用递归处理百位、十位、个位
3. **特殊情况**：
   - 0 单独返回 "Zero"
   - 10-19 有特殊单词
   - 避免多余空格
4. **边界处理**：每组为 0 时不添加单位词
5. **Java 注意**：使用 `long` 类型处理 num，避免 `2^31-1` 时的整数溢出风险；使用 `StringBuilder` 拼接字符串

## 易错点

1. **0 的处理**：单独处理，直接返回 "Zero"
   ```java
   if (num == 0) return "Zero";
   ```

2. **10-19 的特殊处理**：这些数字有独立的单词
   ```java
   // BELOW_20[10] = "Ten", BELOW_20[11] = "Eleven", ... BELOW_20[19] = "Nineteen"
   ```

3. **空格处理**：避免多余空格，最后使用 `trim()` 清理
   ```java
   return result.toString().trim();
   ```

4. **分组边界**：每组为 0 时不添加单位
   ```java
   if (billion > 0) {
       result.append(convertBelowThousand((int) billion)).append(" Billion");
   }
   ```

5. **单词拼写**：注意英文单词的正确拼写
   - Forty（不是 Fourty）
   - Twelve（不是 Tweleve）
