## 题目描述

给数组 nums 和查询数组 queries，每次查询可移除 nums 首或尾元素（需严格大于查询值），若两端均不满足则停止，返回最多能处理的查询数。

## 解题思路

区间 DP：dp[l][r] 表示 nums 剩余 [l..r] 时还能额外处理的查询数。已处理查询数 = l + (n-1-r)，由此确定当前查询索引，无需额外参数。

## Java 代码实现

```java
class Solution {
    private int[] nums, queries;
    private int n, m;
    private int[][] memo;

    public int maximumProcessableQueries(int[] nums, int[] queries) {
        this.nums = nums;
        this.queries = queries;
        n = nums.length;
        m = queries.length;
        memo = new int[n][n];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dp(0, n - 1);
    }

    private int dp(int l, int r) {
        int processed = l + (n - 1 - r); // 已处理的查询数
        if (processed >= m) return 0;
        if (memo[l][r] != -1) return memo[l][r];
        int q = queries[processed];
        int res = 0;
        // 从左端移除 nums[l]
        if (nums[l] > q) res = Math.max(res, 1 + dp(l + 1, r));
        // 从右端移除 nums[r]
        if (nums[r] > q) res = Math.max(res, 1 + dp(l, r - 1));
        return memo[l][r] = res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. 状态 (l, r) 隐式确定已处理查询数 = l + (n-1-r)
2. 每个状态只有从左或从右移除两种选择
3. 记忆化避免重复计算
