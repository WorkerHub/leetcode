## 题目描述

与 3218 题相同，但数据规模更大（`m, n <= 10^5`，切割成本可达 `10^9`），需要使用 `long` 防止溢出。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long minimumCost(int m, int n, int[] horizontalCut, int[] verticalCut) {
        // 降序排序，优先执行成本高的切割
        Arrays.sort(horizontalCut);
        Arrays.sort(verticalCut);

        long hSegs = 1, vSegs = 1; // 当前水平/垂直段数
        long total = 0;
        int i = horizontalCut.length - 1, j = verticalCut.length - 1;

        while (i >= 0 || j >= 0) {
            long hVal = i >= 0 ? horizontalCut[i] : -1;
            long vVal = j >= 0 ? verticalCut[j] : -1;

            if (hVal >= vVal) {
                // 水平切割，成本乘以当前垂直段数
                total += hVal * vSegs;
                hSegs++;
                i--;
            } else {
                // 垂直切割，成本乘以当前水平段数
                total += vVal * hSegs;
                vSegs++;
                j--;
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O((m + n) log(m + n))，排序
- 空间复杂度：O(1)

## 关键点总结

1. 和 3218 完全相同的贪心思路，只是数据范围更大
2. 答案最大可达 10^14，必须使用 `long` 类型防溢出
3. 同等成本时，水平和垂直切割先后顺序不影响结果
