## 题目描述

给你字符串 `s`，将其分割成若干子字符串使每个子字符串中所有字符唯一，返回最少子字符串数目。

## 解题思路

贪心：尽量延长当前子字符串，遇到重复字符才开启新分区。用位掩码记录当前分区已用字符。

## Java 代码实现

```java
class Solution {
    public int partitionString(String s) {
        int ans = 1, mask = 0;
        for (char c : s.toCharArray()) {
            int bit = 1 << (c - 'a');
            if ((mask & bit) != 0) {
                // 当前字符已出现，开启新分区
                ans++;
                mask = 0;
            }
            mask |= bit; // 标记当前字符
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：当前分区尽量延长，遇到重复才新开一段。
2. 位掩码代替 HashSet，O(1) 查询和更新。
3. 初始化 `ans=1` 因为最后一段不会触发新分区计数。
