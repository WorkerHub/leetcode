## 题目描述

给你一个整数数组 `nums`（`nums[i] <= 10^9`）和整数 `k`、`numOperations`。每次操作将某个元素 +1 或 -1，总共最多 `k` 次，每个元素最多 `numOperations` 次。返回操作后某个值的最大出现频率。

## 解题思路

枚举候选目标值（数组中每个元素及其 ±numOperations），对每个候选值用二分查找左右两侧能纳入的最大元素数，使总操作数 <= k。排序 + 前缀和支持 O(log n) 查询。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] nums;
    private long[] prefix;
    private int n;
    private int numOperations;
    private long k;

    public int maxFrequency(int[] nums, int k, int numOperations) {
        Arrays.sort(nums);
        this.nums = nums;
        this.n = nums.length;
        this.numOperations = numOperations;
        this.k = k;

        // 前缀和
        prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        // 候选目标值：每个元素及其 ±numOperations
        Set<Integer> candidateSet = new HashSet<>();
        for (int x : nums) {
            candidateSet.add(x);
            candidateSet.add(x + numOperations);
            candidateSet.add(x - numOperations);
        }

        int ans = 0;
        for (int target : candidateSet) {
            ans = Math.max(ans, count(target));
        }
        return ans;
    }

    private int count(long target) {
        // 可参与的元素范围：[target - numOperations, target + numOperations]
        int lo = lowerBound(target - numOperations);
        int hi = upperBound(target + numOperations) - 1;
        if (lo > hi) return 0;

        // 找 target 在排序数组中的插入位置
        int mid = lowerBound(target + 1); // nums[mid-1] <= target < nums[mid]

        // 左侧（<= target）：从 lo 到 mid-1，总操作 = target*(mid-l) - sum(nums[l..mid-1])
        // 找最小 l >= lo 使操作 <= k
        int lLeft = lo;
        while (lLeft < mid) {
            long ops = target * (mid - lLeft) - (prefix[mid] - prefix[lLeft]);
            if (ops <= k) break;
            lLeft++;
        }
        int leftCount = mid - lLeft;

        // 右侧（> target）：从 mid 到 hi，总操作 = sum(nums[mid..r]) - target*(r-mid+1)
        // 找最大 r <= hi 使操作 <= k
        int rRight = hi;
        while (rRight >= mid) {
            long ops = (prefix[rRight + 1] - prefix[mid]) - target * (rRight - mid + 1);
            if (ops <= k) break;
            rRight--;
        }
        int rightCount = rRight >= mid ? rRight - mid + 1 : 0;

        return leftCount + rightCount;
    }

    private int lowerBound(long val) {
        int lo = 0, hi = n;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (nums[mid] < val) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    private int upperBound(long val) {
        int lo = 0, hi = n;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (nums[mid] <= val) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 对每个候选值 O(n) 扫描（最多 3n 个候选）
- 空间复杂度：O(n)，前缀和

## 关键点总结

1. 候选目标值为每个元素及其 ±numOperations，最优解一定在这些值处取到。
2. 对每个目标值，左右两侧分别用线性扫描找满足总操作 <= k 的最大元素数。
3. 前缀和支持 O(1) 计算区间操作总数。
