## 题目描述

与 3341 类似，但每步移动时间交替为 1 秒（奇数步）和 2 秒（偶数步），返回从 `(0,0)` 到 `(n-1, m-1)` 的最短时间。

## 解题思路

Dijkstra + 奇偶步状态：状态扩展为 `[时间, 行, 列, 步数奇偶]`（0=奇数步耗 1 秒，1=偶数步耗 2 秒）。每移动一次奇偶性翻转。到达时间 = `max(当前时间, moveTime[nr][nc]) + move_cost`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minTimeToReach(int[][] moveTime) {
        int n = moveTime.length, m = moveTime[0].length;
        int[][][] dist = new int[n][m][2];
        for (int[][] plane : dist) for (int[] row : plane) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0][0] = 0; // 初始即将走第 1 步（奇数步，parity=0）

        // 最小堆：[时间, 行, 列, 奇偶]
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0, 0, 0});

        int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int t = cur[0], r = cur[1], c = cur[2], par = cur[3];
            if (t > dist[r][c][par]) continue;
            if (r == n - 1 && c == m - 1) return t;
            int cost = (par == 0) ? 1 : 2; // 奇数步 1 秒，偶数步 2 秒
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
                int arrive = Math.max(t, moveTime[nr][nc]) + cost;
                int npar = 1 - par; // 下一步奇偶性翻转
                if (arrive < dist[nr][nc][npar]) {
                    dist[nr][nc][npar] = arrive;
                    pq.offer(new int[]{arrive, nr, nc, npar});
                }
            }
        }
        return Math.min(dist[n-1][m-1][0], dist[n-1][m-1][1]);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m * log(n * m))，Dijkstra（状态数翻倍）
- 空间复杂度：O(n * m)

## 关键点总结

1. 移动代价交替：奇数步 1 秒，偶数步 2 秒
2. 状态扩展一维记录当前步奇偶性，每移一步翻转
3. 到达终点时两种奇偶状态都可能是答案，取最小值
