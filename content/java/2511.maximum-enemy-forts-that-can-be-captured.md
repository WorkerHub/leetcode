## 题目描述

给你整数数组 `forts`（1=己方要塞，-1=敌方要塞，0=空地），从己方要塞出发向左或向右穿越空地到达另一要塞，返回可经过的最多空地数。

## 解题思路

遍历所有非零位置对，若相邻两个非零值之和为 0（一个为 1 一个为 -1），则中间的空地数为候选答案，取最大值。

## Java 代码实现

```java
class Solution {
    public int captureForts(int[] forts) {
        int n = forts.length, ans = 0, prev = -1;
        for (int i = 0; i < n; i++) {
            if (forts[i] != 0) {
                if (prev != -1 && forts[prev] + forts[i] == 0) {
                    // 一个为 1，一个为 -1，中间全为 0
                    ans = Math.max(ans, i - prev - 1);
                }
                prev = i;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只考虑相邻非零位置对（中间全为 0）
2. 两端值之和为 0 说明一个是 1 一个是 -1（合法移动）
3. 空地数 = 右端位置 - 左端位置 - 1
