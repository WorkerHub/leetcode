## 题目描述

将数字字符串分割为至少2个子串，使得相邻子串的整数值恰好递减1。判断是否可行。

## 解题思路

回溯：枚举第一段确定起始值，之后每段必须恰好比前一段小1，递归验证。

## Java 代码实现

```java
class Solution {
    public boolean splitString(String s) {
        // 枚举第一个子串的结束位置
        for (int i = 1; i < s.length(); i++) {
            long firstVal = Long.parseLong(s.substring(0, i));
            if (dfs(s, i, firstVal, 1)) return true;
        }
        return false;
    }
    
    private boolean dfs(String s, int index, long prev, int count) {
        if (index == s.length()) {
            return count >= 2;
        }
        for (int end = index + 1; end <= s.length(); end++) {
            // 避免溢出：子串过长时跳过
            if (end - index > 18) break;
            long curr = Long.parseLong(s.substring(index, end));
            if (curr == prev - 1) {
                if (dfs(s, end, curr, count + 1)) return true;
            } else if (curr < prev - 1) {
                break; // 值只会更大，提前终止
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(N)，递归栈

## 关键点总结

1. **回溯枚举**：确定第一个数后后续固定为减1
2. **剪枝**：当前值<期望值时break
3. **长度限制**：超过18位会溢出long，跳过
