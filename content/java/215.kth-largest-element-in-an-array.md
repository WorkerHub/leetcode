## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**

```
输入：[3,2,1,5,6,4], k = 2
输出：5
```

**示例 2：**

```
输入：[3,2,3,1,2,4,5,5,6], k = 4
输出：4
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 解题思路

这是经典的 "TopK" 问题，有多种解法，各有优劣。

**核心思想：**

1. **排序法**：直接排序后取第 k 大元素（简单但不是最优）
2. **堆排序**：使用小顶堆维护 k 个最大元素
3. **快速选择**：基于快速排序的分治思想（最优解）

**快速选择算法（Quick Select）：**

- 类似快速排序，但只需递归一侧
- 每次选择一个 pivot，将数组分为：`> pivot`、`= pivot`、`< pivot`
- 根据 pivot 位置决定在哪一侧继续查找
- 平均时间复杂度 O(N)，最坏 O(N²)

**算法流程（快速选择）：**

1. 随机选择 pivot（降低最坏情况概率）
2. 分区：将大于 pivot 的放左边
3. 判断第 k 大元素在哪个部分：
   - 如果 pivot 的位置恰好是 k-1（从 0 开始），直接返回
   - 如果 k 更小，在左侧继续查找
   - 如果 k 更大，在右侧继续查找

## Java 代码实现

### 方法一：快速选择（推荐）⭐

```java
class Solution {
    private Random random = new Random();

    public int findKthLargest(int[] nums, int k) {
        return quickSelect(nums, 0, nums.length - 1, k);
    }

    private int partition(int[] nums, int left, int right) {
        // 随机选择 pivot 并移到末尾
        int pivotIndex = left + random.nextInt(right - left + 1);
        swap(nums, pivotIndex, right);
        int pivot = nums[right];

        // 双指针分区，大于 pivot 的放左边（因为找第 k 大）
        int i = left;
        for (int j = left; j < right; j++) {
            if (nums[j] > pivot) {
                swap(nums, i, j);
                i++;
            }
        }

        // pivot 放到正确位置
        swap(nums, i, right);
        return i;
    }

    private int quickSelect(int[] nums, int left, int right, int k) {
        if (left == right) return nums[left];

        // 分区，获取 pivot 的最终位置
        int pivotIndex = partition(nums, left, right);

        // pivotIndex + 1 代表从大到小排名第 (pivotIndex + 1) 的元素
        if (k == pivotIndex + 1) {
            return nums[pivotIndex];
        } else if (k < pivotIndex + 1) {
            // 第 k 大在左侧（更大的那部分）
            return quickSelect(nums, left, pivotIndex - 1, k);
        } else {
            // 第 k 大在右侧（更小的那部分）
            return quickSelect(nums, pivotIndex + 1, right, k);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 方法二：小顶堆（稳定高效）

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 使用小顶堆维护 k 个最大元素
        PriorityQueue<Integer> heap = new PriorityQueue<>(k);

        for (int num : nums) {
            heap.offer(num);
            // 保持堆的大小为 k
            if (heap.size() > k) {
                heap.poll(); // 移除最小值
            }
        }

        // 堆顶就是第 k 大元素
        return heap.peek();
    }
}
```

### 方法三：排序法（基准解法）

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 直接排序（降序）
        Arrays.sort(nums);
        return nums[nums.length - k]; // 从小到大排序，第 k 大在倒数第 k 个位置
    }
}
```

### 方法四：快速选择（三路划分版）

```java
class Solution {
    private Random random = new Random();

    public int findKthLargest(int[] nums, int k) {
        return quickSelect(nums, 0, nums.length - 1, k);
    }

    private int quickSelect(int[] nums, int left, int right, int k) {
        // 随机选择 pivot
        int pivotIndex = left + random.nextInt(right - left + 1);
        int pivot = nums[pivotIndex];

        // 三路划分：greater | equal | less
        int g = 0, e = 0, l = 0;
        int[] greater = new int[right - left + 1];
        int[] equal = new int[right - left + 1];
        int[] less = new int[right - left + 1];

        for (int i = left; i <= right; i++) {
            if (nums[i] > pivot) greater[g++] = nums[i];
            else if (nums[i] == pivot) equal[e++] = nums[i];
            else less[l++] = nums[i];
        }

        // 回填数组
        int idx = left;
        for (int i = 0; i < g; i++) nums[idx++] = greater[i];
        for (int i = 0; i < e; i++) nums[idx++] = equal[i];
        for (int i = 0; i < l; i++) nums[idx++] = less[i];

        // 判断第 k 大在哪个部分
        if (k <= g) {
            // 在 greater 部分
            return quickSelect(nums, left, left + g - 1, k);
        } else if (k <= g + e) {
            // 就是 pivot
            return pivot;
        } else {
            // 在 less 部分
            return quickSelect(nums, left + g + e, right, k - g - e);
        }
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 快速选择（原地） | 平均 O(N)，最坏 O(N²) | O(log N) | 递归栈空间 |
| 小顶堆 | O(N log K) | O(K) | 稳定性能 |
| 排序 | O(N log N) | O(log N) | 简单但不最优 |

**最优解：** 快速选择（原地分区版）

## 关键点总结

1. **快速选择精髓**：每次只需递归一侧，平均 O(N)
2. **随机 pivot**：降低最坏情况概率，提高稳定性
3. **第 k 大 vs 第 k 小**：注意分区时的比较方向（找第 k 大时大于 pivot 的放左边）
4. **堆的选择**：第 k 大用小顶堆，第 k 小用大顶堆
5. **权衡**：快速选择最快但不稳定，堆稳定但慢一些

## 易错点

1. **第 k 大的索引**：
   ```java
   // 错误：升序排序后取 k-1 索引
   Arrays.sort(nums);
   return nums[k - 1]; // 这是第 k 小！
   // 正确：第 k 大在倒数第 k 个位置
   Arrays.sort(nums);
   return nums[nums.length - k];
   ```

2. **分区方向错误**：
   ```java
   // 找第 k 大：大于 pivot 的放左边
   if (nums[j] > pivot) {
       swap(nums, i, j);
       i++;
   }
   // 找第 k 小：小于 pivot 的放左边
   if (nums[j] < pivot) { ... }
   ```

3. **堆的类型搞反**：
   ```java
   // 错误：第 k 大用大顶堆
   PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder()); // 错误
   // 正确：第 k 大用小顶堆（默认）
   PriorityQueue<Integer> heap = new PriorityQueue<>(k);
   ```

4. **快速选择的递归条件**：
   ```java
   // 注意：pivotIndex 是绝对位置，k 是相对位置（从 1 开始）
   if (k == pivotIndex + 1) return nums[pivotIndex];
   ```

5. **随机数范围**：
   ```java
   // 正确：在 [left, right] 范围内随机选择
   int pivotIndex = left + random.nextInt(right - left + 1);
   ```
