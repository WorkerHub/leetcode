## 题目描述

给你两棵树（邻接表 `edges1` 和 `edges2`），可在树 1 的某节点和树 2 的某节点之间连一条边。对树 1 中每个节点 `i`，找最优连接方式使距离 <= k 的节点数最多，返回每个节点能覆盖的最大节点数。

## 解题思路

分步计算：对树 1 每个节点 `i`，BFS 计算距离 <= k 的节点数 `c1[i]`；对树 2 每个节点 `j`，BFS 计算距离 <= k-1 的节点数 `c2[j]`（新加的边占用 1 步）。答案 = `c1[i] + max(c2)`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] maxTargetNodes(int[][] edges1, int[][] edges2, int k) {
        int n1 = edges1.length + 1;
        int n2 = edges2.length + 1;

        List<List<Integer>> g1 = buildGraph(edges1, n1);
        List<List<Integer>> g2 = buildGraph(edges2, n2);

        // 计算树 1 每个节点距离 <= k 的节点数
        int[] c1 = new int[n1];
        for (int i = 0; i < n1; i++) {
            c1[i] = bfsCount(g1, n1, i, k);
        }

        // 计算树 2 每个节点距离 <= k-1 的节点数
        int bestC2 = 0;
        for (int j = 0; j < n2; j++) {
            bestC2 = Math.max(bestC2, bfsCount(g2, n2, j, k - 1));
        }

        int[] ans = new int[n1];
        for (int i = 0; i < n1; i++) {
            ans[i] = c1[i] + bestC2;
        }
        return ans;
    }

    private List<List<Integer>> buildGraph(int[][] edges, int n) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        return g;
    }

    private int bfsCount(List<List<Integer>> g, int n, int src, int maxDist) {
        if (maxDist < 0) return 0;
        boolean[] visited = new boolean[n];
        visited[src] = true;
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{src, 0});
        int count = 1;
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int node = cur[0], dist = cur[1];
            if (dist >= maxDist) continue;
            for (int nb : g.get(node)) {
                if (!visited[nb]) {
                    visited[nb] = true;
                    queue.offer(new int[]{nb, dist + 1});
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n1 + n2) * (n1 + n2))，每个节点做一次 BFS
- 空间复杂度：O(n1 + n2)

## 关键点总结

1. 连接边占 1 步，树 2 中覆盖半径是 `k-1`。
2. 对每个树 1 节点，选树 2 中 `c2[j]` 最大的节点连接。
3. 答案 = `c1[i] + max(c2)`。
