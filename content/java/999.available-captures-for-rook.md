## 题目描述

8x8 棋盘上有白色车 'R'、白色象 'B'、黑色卒 'p'。车沿四个方向移动，遇象停止，遇卒捕获。返回车一次移动能捕获的卒数。

**示例：**
```
输入：board（8x8 棋盘）
输出：能捕获的卒数
```

## 解题思路

模拟：找到车的位置，四个方向逐步移动，遇到象停止，遇到卒计数后停止。

## Java 代码实现

```java
class Solution {
    public int numRookCaptures(char[][] board) {
        // 找到车的位置
        int rx = 0, ry = 0;
        for (int i = 0; i < 8; i++) {
            for (int j = 0; j < 8; j++) {
                if (board[i][j] == 'R') {
                    rx = i;
                    ry = j;
                }
            }
        }

        int captures = 0;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        for (int[] d : dirs) {
            int x = rx + d[0], y = ry + d[1];
            while (x >= 0 && x < 8 && y >= 0 && y < 8) {
                if (board[x][y] == 'B') break;
                if (board[x][y] == 'p') {
                    captures++;
                    break;
                }
                x += d[0];
                y += d[1];
            }
        }

        return captures;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)，棋盘固定 8x8
- **空间复杂度**：O(1)

## 关键点总结

1. **四方向遍历**：上下左右逐步移动
2. **遇障停止**：白象阻挡，黑卒捕获
3. **固定大小**：8x8 棋盘，常数复杂度
