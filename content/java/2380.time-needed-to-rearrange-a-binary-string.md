## 题目描述

给你二进制字符串 `s`，每秒所有 "01" 同时替换为 "10"（所有 1 向左移），返回使所有 1 都在所有 0 之前所需的秒数。

## 解题思路

DP：从左到右遍历，用 `zeros` 记录已遇到的 0 的数量，`ans` 为当前所有 1 到达正确位置的最大时间。遇到 '1' 且左边有 0 时，更新 `ans = max(ans+1, zeros)`，相邻 1 可以"接力"节省时间。

## Java 代码实现

```java
class Solution {
    public int secondsToRemoveOccurrences(String s) {
        int ans = 0, zeros = 0;
        for (char c : s.toCharArray()) {
            if (c == '0') {
                zeros++;
            } else if (zeros > 0) {
                // 此 1 需要跨越 zeros 个 0；连续 1 接力，只需 ans+1
                ans = Math.max(ans + 1, zeros);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 每个 '1' 需要跨越其左侧所有 '0'，至少需要 `zeros` 秒。
2. 相邻 '1' 可以同步移动接力，实际时间为 `max(ans+1, zeros)`。
3. 只需一次遍历，O(n) 完成。
