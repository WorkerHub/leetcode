## 题目描述

带权无向图中，从节点 0 出发，在 maxTime 时间内必须回到 0，每个节点价值只计一次，返回可收集的最大总价值。

## 解题思路

回溯 DFS：从节点 0 出发探索所有路径，每次到达节点 0 时更新答案。用 visited 数组记录访问状态，回溯时恢复。maxTime <= 100 且每条边权 >= 1，路径条数有限。

## Java 代码实现

### 方法一：回溯 DFS（推荐）

```java
import java.util.*;

class Solution {
    private int[] values;
    private List<int[]>[] graph;
    private boolean[] visited;
    private int maxTime;
    private int ans = 0;

    @SuppressWarnings("unchecked")
    public int maximalPathQuality(int[] values, int[][] edges, int maxTime) {
        int n = values.length;
        this.values = values;
        this.maxTime = maxTime;
        this.visited = new boolean[n];
        this.graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        visited[0] = true;
        dfs(0, 0, values[0]);
        return ans;
    }

    private void dfs(int node, int elapsed, int gain) {
        if (node == 0) ans = Math.max(ans, gain); // 回到0时更新答案
        for (int[] next : graph[node]) {
            int nei = next[0], t = next[1];
            if (elapsed + t <= maxTime) {
                if (!visited[nei]) {
                    visited[nei] = true;
                    dfs(nei, elapsed + t, gain + values[nei]);
                    visited[nei] = false;
                } else {
                    dfs(nei, elapsed + t, gain); // 已访问，价值不重复计
                }
            }
        }
    }
}
```

## 复杂度分析

- 时间复杂度：受 maxTime 限制，实际远小于指数级
- 空间复杂度：O(n + E)

## 关键点总结

1. 到达节点 0 时（不只是结束时）更新答案
2. 节点可重复经过但价值只计一次，用 visited 判断
3. 剪枝：剩余时间不足则不继续
