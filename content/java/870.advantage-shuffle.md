## 题目描述

给定两个大小相等的数组 nums1 和 nums2，nums1 相对于 nums2 的优势可以用满足 nums1[i] > nums2[i] 的索引 i 的数目来描述。

返回 nums1 的任意排列，使其相对于 nums2 的优势最大化。

**示例 1：**
```
输入：nums1 = [2,7,11,15], nums2 = [1,10,4,11]
输出：[2,11,7,15]
```

**示例 2：**
```
输入：nums1 = [12,24,8,32], nums2 = [13,25,32,11]
输出：[24,32,8,12]
```

**提示：**
- 1 <= nums1.length <= 10^5
- nums2.length == nums1.length
- 0 <= nums1[i], nums2[i] <= 10^9

## 解题思路

这是经典的"田忌赛马"问题。

**贪心策略：**
1. 对 nums1 排序
2. 对 nums2 的索引按值从大到小排序
3. 对于 nums2 中每个值（从大到小）：
   - 如果 nums1 最大值能赢，用它（匹配最大的）
   - 否则用 nums1 最小的值（反正也赢不了，浪费最小资源）

## Java 代码实现

### 方法一：贪心 + 双指针（推荐）

```java
class Solution {
    public int[] advantageCount(int[] nums1, int[] nums2) {
        int n = nums1.length;
        Arrays.sort(nums1); // nums1 从小到大排序

        // nums2 的索引按值从大到小排序
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> nums2[b] - nums2[a]);

        int[] result = new int[n];
        int left = 0, right = n - 1;

        // 从大到小处理 nums2
        for (int idx : indices) {
            // 如果 nums1 最大值能赢，用它
            if (nums1[right] > nums2[idx]) {
                result[idx] = nums1[right--];
            // 否则用最小值（反正赢不了）
            } else {
                result[idx] = nums1[left++];
            }
        }

        return result;
    }
}
```

**代码说明：**
- nums1 排序后，用双指针 left（最小）和 right（最大）维护可用的值
- 从 nums2 最大值开始处理，尽量用刚好能赢的值
- 赢不了就用最小值，减少损失

## 复杂度分析

- **时间复杂度**：O(n log n)，排序。
- **空间复杂度**：O(n)，索引数组和结果数组。

## 关键点总结

1. **田忌赛马**：能赢就用刚好能赢的，赢不了就用最弱的
2. **双指针**：维护 nums1 的最大和最小可用值
3. **排序技巧**：对索引排序保持原始位置信息
4. **从大到小**：先处理 nums2 中较大的值

## 易错点

1. **处理顺序**：应该从 nums2 最大值开始处理

2. **结果索引**：结果放在 nums2 对应的原始位置，而不是排序后的位置

3. **赢的判断**：严格大于才算赢
