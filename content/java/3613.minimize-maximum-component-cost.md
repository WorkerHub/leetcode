## 题目描述

给定 `n` 个节点的无向加权图，将节点分成连通分量，每个分量代价为其内部最大边权，返回所有分量最大代价的最小可能值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent;

    public int minimizeMaxCost(int n, int[][] edges) {
        Arrays.sort(edges, Comparator.comparingInt(e -> e[2]));
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // Kruskal：最小生成树的最大边权即为答案（瓶颈最小生成树）
        int components = n;
        int maxW = 0;

        for (int[] e : edges) {
            if (union(e[0], e[1])) {
                components--;
                maxW = e[2];
                if (components == 1) return maxW;
            }
        }
        return components > 1 ? -1 : maxW;
    }

    private boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        parent[px] = py;
        return true;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
}
```

## 复杂度分析

- 时间复杂度：O(E log E)，排序为主要开销
- 空间复杂度：O(n)

## 关键点总结

1. 最小化最大代价等价于最小生成树的最大边权（瓶颈最小生成树）
2. Kruskal 按权重升序加边，最后加入的树边即为答案
3. 若图不连通，返回 -1
