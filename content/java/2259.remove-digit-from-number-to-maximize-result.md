## 题目描述

从数字字符串中删除一个指定digit字符，使结果最大。

## 解题思路

贪心：找第一个digit位置使得下一位比digit大，删除该位；若无则删除最后一个digit。

## Java 代码实现

```java
class Solution {
    public String removeDigit(String number, char digit) {
        int lastPos = -1;
        for (int i = 0; i < number.length(); i++) {
            if (number.charAt(i) == digit) {
                lastPos = i;
                // 下一位比digit大，删除当前位最优
                if (i + 1 < number.length() && number.charAt(i + 1) > digit) {
                    return number.substring(0, i) + number.substring(i + 1);
                }
            }
        }
        // 删除最后一个digit
        return number.substring(0, lastPos) + number.substring(lastPos + 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **贪心策略**：删除后使高位变大
2. **第一个后面有更大字符的位置**：删除使结果最大
3. **无更大字符时删最后一个**：减少低位影响
