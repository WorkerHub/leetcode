## 题目描述

给你一个二叉树的根节点 `root`，按任意顺序，返回所有从根节点到叶子节点的路径。

叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
解释：
    1
   / \
  2   3
   \
    5
```

**示例 2：**

```
输入：root = [1]
输出：["1"]
```

**提示：**
- 树中节点的数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 解题思路

这是一道经典的树的遍历问题，需要找出所有从根到叶子的路径。

核心思想：
1. 使用深度优先搜索（DFS）遍历树
2. 维护当前路径
3. 当到达叶子节点时，将路径加入结果
4. 回溯到父节点，继续探索其他路径

关键点：
- 叶子节点：左右子节点都为空
- 路径格式：使用 "->" 连接节点值
- 回溯：在递归返回时需要恢复状态

## Java 代码实现

### 方法一：DFS + StringBuilder 回溯（推荐）⭐

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;
        // 使用 StringBuilder 可以高效回溯（通过 setLength 恢复）
        dfs(root, new StringBuilder(), result);
        return result;
    }

    private void dfs(TreeNode node, StringBuilder path, List<String> result) {
        // 记录当前路径长度，用于回溯
        int len = path.length();

        // 非空路径需要添加分隔符
        if (len > 0) path.append("->");
        path.append(node.val);

        // 如果是叶子节点，记录路径
        if (node.left == null && node.right == null) {
            result.add(path.toString());
        } else {
            // 递归遍历左子树
            if (node.left != null) dfs(node.left, path, result);
            // 递归遍历右子树
            if (node.right != null) dfs(node.right, path, result);
        }

        // 回溯：恢复路径到进入本节点之前的状态
        path.setLength(len);
    }
}
```

### 方法二：DFS + 字符串拼接（不需要显式回溯）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;
        dfs(root, "", result);
        return result;
    }

    private void dfs(TreeNode node, String path, List<String> result) {
        // 如果是叶子节点，记录完整路径
        if (node.left == null && node.right == null) {
            result.add(path + node.val);
            return;
        }

        // 非叶子节点，继续拼接路径
        String newPath = path + node.val + "->";

        if (node.left != null) dfs(node.left, newPath, result);
        if (node.right != null) dfs(node.right, newPath, result);
    }
}
```

### 方法三：BFS（层序遍历）

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;

        // 队列同时存储节点和对应的路径字符串
        Deque<TreeNode> nodeQueue = new ArrayDeque<>();
        Deque<String> pathQueue = new ArrayDeque<>();
        nodeQueue.offer(root);
        pathQueue.offer(String.valueOf(root.val));

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            String path = pathQueue.poll();

            // 如果是叶子节点，记录路径
            if (node.left == null && node.right == null) {
                result.add(path);
                continue;
            }

            // 将子节点和路径加入队列
            if (node.left != null) {
                nodeQueue.offer(node.left);
                pathQueue.offer(path + "->" + node.left.val);
            }
            if (node.right != null) {
                nodeQueue.offer(node.right);
                pathQueue.offer(path + "->" + node.right.val);
            }
        }

        return result;
    }
}
```

### 方法四：递归分治

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;

        // 叶子节点直接返回自身的值
        if (root.left == null && root.right == null) {
            result.add(String.valueOf(root.val));
            return result;
        }

        // 获取左子树的所有路径，拼接当前节点
        for (String path : binaryTreePaths(root.left)) {
            result.add(root.val + "->" + path);
        }

        // 获取右子树的所有路径，拼接当前节点
        for (String path : binaryTreePaths(root.right)) {
            result.add(root.val + "->" + path);
        }

        return result;
    }
}
```

## 复杂度分析

所有方法的复杂度相同：
- 时间复杂度：O(n)，需要访问每个节点一次
- 空间复杂度：O(n)，递归栈或队列的空间，最坏情况下（链状树）为 O(n)

## 图解示例

以 `root = [1,2,3,null,5]` 为例：

```
树结构：
    1
   / \
  2   3
   \
    5

DFS 遍历过程：
1. 访问节点 1，path = "1"
   ├─ 访问节点 2，path = "1->2"
   │  ├─ 左子树为空
   │  └─ 访问节点 5，path = "1->2->5"
   │     └─ 叶子节点！记录 "1->2->5"
   │     └─ 回溯到节点 2（path 恢复为 "1->2"）
   └─ 回溯到节点 1（path 恢复为 "1"）
   └─ 访问节点 3，path = "1->3"
      └─ 叶子节点！记录 "1->3"

结果：["1->2->5", "1->3"]
```

## 关键点总结

1. **叶子节点判断**：左右子节点都为空时才是叶子
2. **路径维护**：使用 StringBuilder 或字符串维护当前路径
3. **回溯技巧**：StringBuilder 用 `setLength` 回溯，字符串不可变故无需回溯
4. **DFS vs BFS**：两种方法都可以，DFS 更常用
5. **路径格式**：使用 "->" 连接节点值

## 易错点

1. **忘记判断叶子节点**
   ```java
   // 错误：只要节点存在就记录
   result.add(path);

   // 正确：只有叶子节点才记录
   if (node.left == null && node.right == null) {
       result.add(path);
   }
   ```

2. **StringBuilder 回溯错误**
   ```java
   // 错误：没有在进入节点前保存 len
   sb.append(node.val);
   dfs(node.left, sb, result);
   // 此时 sb 已被左子树修改，无法正确回溯

   // 正确：进入节点前记录长度
   int len = sb.length();
   sb.append(node.val);
   dfs(node.left, sb, result);
   sb.setLength(len); // 回溯
   ```

3. **路径格式错误**
   ```java
   // 错误：第一个节点前会多一个 "->"
   path.append("->").append(node.val);

   // 正确：非空路径才加分隔符
   if (path.length() > 0) path.append("->");
   path.append(node.val);
   ```

4. **空树处理**
   ```java
   // 记得处理 root 为 null 的情况
   if (root == null) return new ArrayList<>();
   ```
