## 题目描述

正多边形有 n 个顶点，每顶点一只猴子随机选择顺时针或逆时针移动一步，求发生碰撞的方案数（对 `10^9+7` 取模）。

## 解题思路

不碰撞只有两种（全顺时针、全逆时针），总方案 `2^n`，碰撞方案数 = `2^n - 2`，用快速幂计算。

## Java 代码实现

```java
class Solution {
    static final int MOD = 1_000_000_007;

    public int monkeyMove(int n) {
        // 碰撞方案数 = 2^n - 2
        return (int) ((pow(2, n) - 2 + MOD) % MOD);
    }

    private long pow(long base, int exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. 不碰撞只有全顺时针或全逆时针 2 种，总方案 2^n
2. 答案为 `2^n - 2`，n 最大 10^9 需用快速幂
3. 减法取模加 MOD 防负数：`(2^n - 2 + MOD) % MOD`
