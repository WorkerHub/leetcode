## 题目描述

给你一棵 n 个节点的无向树，若路径上恰好有 1 个质数节点则为有效路径，返回有效路径的数量。

## 解题思路

树形 DP：DFS 时维护每个节点出发的 cnt0（经过 0 个质数的路径数）和 cnt1（经过 1 个质数的路径数），合并子树时根据当前节点是否为质数分情况统计答案，并用埃氏筛预处理质数。

## Java 代码实现

```java
class Solution {
    private boolean[] isPrime;
    private List<Integer>[] graph;
    private long ans = 0;

    public long countValidPaths(int n, int[][] edges) {
        // 埃氏筛预处理质数
        isPrime = new boolean[n + 1];
        Arrays.fill(isPrime, true);
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; (long) i * i <= n; i++) {
            if (isPrime[i]) for (int j = i * i; j <= n; j += i) isPrime[j] = false;
        }

        graph = new List[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        dfs(1, -1);
        return ans;
    }

    // 返回 [cnt0, cnt1]：从 node 出发经过 0 个/1 个质数的路径数
    private long[] dfs(int node, int parent) {
        long c0 = isPrime[node] ? 0 : 1;
        long c1 = isPrime[node] ? 1 : 0;

        for (int nei : graph[node]) {
            if (nei == parent) continue;
            long[] res = dfs(nei, node);
            long nc0 = res[0], nc1 = res[1];
            if (isPrime[node]) {
                // node 是质数：两侧都有 0 个质数时路径有效
                ans += c0 * nc0;
                c1 += nc0; // 从 nei 来的无质数路径加上 node 变为有质数路径
            } else {
                // node 不是质数：一侧 1 个质数 + 另一侧 0 个
                ans += c0 * nc1 + c1 * nc0;
                c0 += nc0;
                c1 += nc1;
            }
        }
        return new long[]{c0, c1};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log log n)（埃氏筛）+ O(n)（DFS）
- **空间复杂度**：O(n)

## 关键点总结

1. 树形 DP 维护每个节点出发的 0/1 质数路径数
2. 合并子树时先统计答案再更新计数，顺序不能错
3. 质数节点只能出现在路径中间（贡献 1 个），非质数节点不影响计数
