## 题目描述

给你三个整数数组 `a`、`b`、`c`，返回满足 `Integer.bitCount(a[i] ^ b[j] ^ c[k])` 为偶数的三元组 `(i, j, k)` 数量。

## 解题思路

`popcount(x ^ y ^ z)` 的奇偶性等于 `popcount(x) ^ popcount(y) ^ popcount(z)` 的值。先统计三个数组中各数 popcount 的奇偶性分布（偶数/奇数个数），再用乘法组合：三者奇偶 XOR 为 0 的方案有 4 种（偶偶偶、奇奇偶、奇偶奇、偶奇奇）。

## Java 代码实现

```java
class Solution {
    public int countTriplets(int[] a, int[] b, int[] c) {
        // 统计每个数组中 popcount 为偶数/奇数的个数
        int a0 = 0, a1 = 0, b0 = 0, b1 = 0, c0 = 0, c1 = 0;
        for (int x : a) { if (Integer.bitCount(x) % 2 == 0) a0++; else a1++; }
        for (int x : b) { if (Integer.bitCount(x) % 2 == 0) b0++; else b1++; }
        for (int x : c) { if (Integer.bitCount(x) % 2 == 0) c0++; else c1++; }
        // 三者奇偶 XOR = 0 的组合：偶偶偶、奇奇偶、奇偶奇、偶奇奇
        return a0 * b0 * c0 + a1 * b1 * c0 + a1 * b0 * c1 + a0 * b1 * c1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n1 + n2 + n3)
- **空间复杂度**：O(1)

## 关键点总结

1. `popcount(x ^ y ^ z)` 的奇偶 = 三个数 popcount 的奇偶 XOR
2. 结果为偶数的条件：三者奇偶 XOR = 0（偶偶偶 或 任意两奇一偶）
3. 用乘法组合计数，避免 O(n^3) 枚举
