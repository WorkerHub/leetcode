## 题目描述

给定 DataFrame employees，创建新列 bonus，值为每个员工 salary 的两倍。

## 解题思路

本题为 Python Pandas 专项练习，使用向量化列运算 `df['bonus'] = df['salary'] * 2` 添加新列。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// Pandas 向量化列运算：df['bonus'] = df['salary'] * 2

import java.util.*;

class Solution {
    // Java 中为每条记录添加 bonus 字段（salary * 2）
    public List<int[]> createBonusColumn(List<int[]> employees) {
        // employees[i] = [emp_id, salary]，返回 [emp_id, salary, bonus]
        List<int[]> result = new ArrayList<>();
        for (int[] row : employees) {
            result.add(new int[]{row[0], row[1], row[1] * 2});
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `df['new_col'] = expression` 直接添加新列
2. 列运算是向量化的，性能优于逐行循环
3. `df.assign(col=expr)` 是不修改原 DataFrame 的等价写法
