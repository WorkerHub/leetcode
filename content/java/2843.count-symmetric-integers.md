## 题目描述

统计[low,high]中对称整数个数（偶数位数且前半数字和=后半数字和）。

## 解题思路

数据范围<=10^4，直接枚举判断：偶数位数时比较前后半数字和。

## Java 代码实现

```java
class Solution {
    public int countSymmetricIntegers(int low, int high) {
        int count = 0;
        for (int n = low; n <= high; n++) {
            String s = String.valueOf(n);
            int len = s.length();
            if (len % 2 != 0) continue;
            int half = len / 2;
            int front = 0, back = 0;
            for (int i = 0; i < half; i++) front += s.charAt(i) - '0';
            for (int i = half; i < len; i++) back += s.charAt(i) - '0';
            if (front == back) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((high-low) * log(high))
- **空间复杂度**：O(log(high))

## 关键点总结

1. **偶数位数才可能对称**
2. **前半数字和==后半数字和**
3. **数据范围小直接枚举**
