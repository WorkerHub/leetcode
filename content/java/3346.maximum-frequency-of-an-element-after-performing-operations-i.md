## 题目描述

给你一个整数数组 `nums` 和两个整数 `k`（操作次数）和 `numOperations`。每次操作可以将数组中某个元素加 1 或减 1，每个元素最多操作 `numOperations` 次，总共最多 `k` 次。返回操作后数组中某个元素的**最大频率**。

## 解题思路

排序后以每个元素 `nums[r]` 为目标值，用滑动窗口维护左指针满足 per-element 约束（`target - nums[l] <= numOperations`），再用二分查找在窗口内找满足总操作数 <= k 的最大子窗口，用前缀和 O(1) 计算总操作数。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxFrequency(int[] nums, int k, int numOperations) {
        Arrays.sort(nums);
        int n = nums.length;

        // 前缀和
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        int ans = 1;
        int l = 0;

        for (int r = 0; r < n; r++) {
            long target = nums[r];

            // per-element 约束：窗口内每个元素变成 target 的步骤 <= numOperations
            while (target - nums[l] > numOperations) {
                l++;
            }

            // 计算窗口 [l, r] 的总操作数
            long totalOps = target * (r - l + 1) - (prefix[r + 1] - prefix[l]);

            if (totalOps <= k) {
                ans = Math.max(ans, r - l + 1);
            } else {
                // 二分找满足 k 约束的最大子窗口左边界
                int lo = l, hi = r;
                while (lo < hi) {
                    int mid = (lo + hi) / 2;
                    long ops = target * (r - mid + 1) - (prefix[r + 1] - prefix[mid]);
                    if (ops <= k) {
                        hi = mid;
                    } else {
                        lo = mid + 1;
                    }
                }
                ans = Math.max(ans, r - lo + 1);
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 + 每次二分
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 排序后以每个元素为目标值，利用排序单调性用滑动窗口处理 per-element 约束。
2. 前缀和快速计算窗口内所有元素到目标值的总操作次数。
3. 两个约束（numOperations 和 k）需要同时满足，先滑窗后二分。
