## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积，它们的乘积也表示为字符串形式。

**注意：** 不能使用任何内置的大数库或直接将输入转换为整数。

**示例 1：**
```
输入：num1 = "2", num2 = "3"
输出："6"
```

**示例 2：**
```
输入：num1 = "123", num2 = "456"
输出："56088"
```

**提示：**
- `1 <= num1.length, num2.length <= 200`
- `num1` 和 `num2` 只能由数字组成
- `num1` 和 `num2` 都不包含任何前导零，除了数字0本身

## 解题思路

核心思想：模拟竖式乘法

关键观察：
- num1[i] × num2[j] 的结果位于 result[i+j] 和 result[i+j+1]
- 长度为 m 和 n 的数相乘，结果最多 m+n 位

## Java 代码实现

```java
class Solution {
    public String multiply(String num1, String num2) {
        if (num1.equals("0") || num2.equals("0")) {
            return "0";
        }

        int m = num1.length(), n = num2.length();
        int[] result = new int[m + n];

        // 从右向左遍历
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                // 两位数字相乘
                int mul = (num1.charAt(i) - '0') * (num2.charAt(j) - '0');
                // 结果位置
                int p1 = i + j, p2 = i + j + 1;
                // 加上之前的进位
                int total = mul + result[p2];

                result[p2] = total % 10;
                result[p1] += total / 10;
            }
        }

        // 转换为字符串，跳过前导零
        StringBuilder sb = new StringBuilder();
        for (int digit : result) {
            if (sb.length() == 0 && digit == 0) {
                continue; // 跳过前导零
            }
            sb.append(digit);
        }

        return sb.length() == 0 ? "0" : sb.toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m + n)

## 关键点总结

1. **位置关系**：i × j 的结果在 i+j 和 i+j+1 位置
2. **进位处理**：每次计算要加上之前的进位
3. **前导零**：最后去除前导零

## 易错点

1. **特殊情况**：任一为 "0" 直接返回 "0"
2. **字符串比较**：Java 中字符串比较要用 equals，不能用 ==
3. **索引计算**：注意 p1 和 p2 的位置关系
