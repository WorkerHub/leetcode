## 题目描述

给你整数数组 `nums`，每次操作可将某元素加减 1（代价 1），使所有元素变为同一回文数，返回最少总代价。

## 解题思路

最优目标值是中位数附近的回文数。排序找中位数，向左向右各找最近的回文数，取代价最小的。

## Java 代码实现

```java
class Solution {
    public long minimumCost(int[] nums) {
        Arrays.sort(nums);
        int median = nums[nums.length / 2];

        // 向左找最近的回文数
        int left = median;
        while (!isPalindrome(left)) left--;

        // 向右找最近的回文数
        int right = median;
        while (!isPalindrome(right)) right++;

        return Math.min(cost(nums, left), cost(nums, right));
    }

    private boolean isPalindrome(int x) {
        String s = Integer.toString(x);
        int l = 0, r = s.length() - 1;
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) return false;
            l++; r--;
        }
        return true;
    }

    private long cost(int[] nums, int target) {
        long total = 0;
        for (int x : nums) total += Math.abs(x - target);
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + Dn)，D 为搜索步数（实际很小）
- **空间复杂度**：O(1)

## 关键点总结

1. 最优目标值是中位数（L1 最小化），必须是回文数所以取中位数最近的回文数
2. 向左右各找一个最近的回文数，两者之一是最优解
3. 代价累加用 long 防溢出
