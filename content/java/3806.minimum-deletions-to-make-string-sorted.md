## 题目描述

给定字符串 `s`，返回使其变为非递减有序所需删除的最少字符数。

## Java 代码实现

```java
class Solution {
    public int minimumDeletions(String s) {
        // dp[c] = 以字符 c 结尾的最长非递减子序列长度
        int[] dp = new int[26];
        for (char ch : s.toCharArray()) {
            int c = ch - 'a';
            // 找 dp[0..c] 中的最大值
            int best = 0;
            for (int i = 0; i <= c; i++) best = Math.max(best, dp[i]);
            dp[c] = best + 1;
        }
        int longest = 0;
        for (int x : dp) longest = Math.max(longest, x);
        return s.length() - longest;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26n) = O(n)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 最少删除数 = 总长度 - 最长非递减子序列长度
2. 只有 26 个字母，用 dp[26] 数组记录每个字符结尾的最长非递减子序列
3. 非递减允许相等，所以查 dp[0..c] 前缀最大值（含自身）
