## 题目描述

给定整数数组 nums，每次操作可将某元素 +1。返回使所有值唯一的最少操作次数。

## 解题思路

排序后贪心：排序后遍历，如果当前值 ≤ 前一个值，则将其增加到前一个值 +1。

## Java 代码实现

```java
class Solution {
    public int minIncrementForUnique(int[] nums) {
        Arrays.sort(nums);
        int moves = 0;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] <= nums[i - 1]) {
                int increment = nums[i - 1] - nums[i] + 1;
                moves += increment;
                nums[i] += increment;
            }
        }

        return moves;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)，原地排序

## 关键点总结

1. **排序 + 贪心**：排序后保证每个值大于前一个
2. **增量计算**：差值 +1 即为所需操作数
3. **原地修改**：直接修改数组记录新值
