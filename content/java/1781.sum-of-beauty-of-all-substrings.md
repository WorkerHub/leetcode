## 题目描述

一个字符串的**美丽值**定义为：出现频率最高的字符频率与出现频率最低的字符频率之差。

给你一个字符串 `s`，返回其所有子字符串的**美丽值**之和。

## 解题思路

暴力枚举所有子字符串（O(n^2)），对每个子字符串用 int[26] 维护字符频率，计算最大频率与最小频率（只考虑出现过的字符）之差。n <= 500，O(n^2 * 26) 足够。

## Java 代码实现

```java
class Solution {
    public int beautySum(String s) {
        int n = s.length();
        int total = 0;

        for (int i = 0; i < n; i++) {
            int[] count = new int[26];
            for (int j = i; j < n; j++) {
                count[s.charAt(j) - 'a']++;
                // 计算最大频率和最小频率（只考虑出现过的字符）
                int maxFreq = 0, minFreq = Integer.MAX_VALUE;
                for (int c : count) {
                    if (c > 0) {
                        maxFreq = Math.max(maxFreq, c);
                        minFreq = Math.min(minFreq, c);
                    }
                }
                total += maxFreq - minFreq;
            }
        }

        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2 * 26)
- **空间复杂度**：O(26) = O(1)

## 关键点总结

1. 枚举起点 `i`，内层扩展 `j` 时增量更新 count 数组
2. 每次 O(26) 求最大最小频率
3. 美丽值 = 最高频率 - 最低频率（只考虑出现过的字符）
