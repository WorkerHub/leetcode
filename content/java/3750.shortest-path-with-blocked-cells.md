## 题目描述

给定 `m × n` 矩阵，`0` 表示空格，`1` 表示障碍物。从左上角 `(0,0)` 到右下角 `(m-1,n-1)`，求最短路径步数，不可达返回 `-1`。

## 解题思路

标准 BFS，从起点层序遍历，找到终点时返回步数。

## Java 代码实现

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int shortestPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        if (grid[0][0] == 1 || grid[m-1][n-1] == 1) return -1;
        if (m == 1 && n == 1) return 0;

        boolean[][] visited = new boolean[m][n];
        visited[0][0] = true;
        Deque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0, 0}); // 行、列、步数
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], steps = cur[2];
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && !visited[nr][nc] && grid[nr][nc] == 0) {
                    if (nr == m-1 && nc == n-1) return steps + 1;
                    visited[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, steps + 1});
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)

## 关键点总结

1. BFS 保证找到最短路径（无权图）
2. 标记 visited 防止重复访问
3. 起点或终点为障碍物时直接返回 -1
