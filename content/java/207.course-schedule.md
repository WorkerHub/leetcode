## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi`。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0`，你需要先完成课程 `1`。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0。这是可能的。
```

**示例 2：**
```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，需要先完成课程 0；学习课程 0 之前，又需要先完成课程 1。这是不可能的。
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有课程对 **互不相同**

## 解题思路

这道题的本质是**判断有向图中是否存在环**。

### 问题建模

1. **图的表示**：
   - 每门课程是一个节点
   - `[a, b]` 表示有向边 `b → a`（先学 b，才能学 a）

2. **问题转化**：
   - 能完成所有课程 ⟺ 有向图无环
   - 不能完成 ⟺ 有向图有环（循环依赖）

### 解决方案

判断有向图是否有环，有两种经典方法：

1. **拓扑排序（BFS）**：基于入度的广度优先搜索
2. **深度优先搜索（DFS）**：检测回边（环）

## Java 代码实现

### 方法一：拓扑排序（BFS）推荐⭐

```java
import java.util.*;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建图和入度数组
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[numCourses];  // 每个节点的入度
        
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        
        for (int[] pre : prerequisites) {
            int course = pre[0];
            int prereq = pre[1];
            graph.get(prereq).add(course);  // prereq -> course
            inDegree[course]++;  // course 的入度加 1
        }
        
        // 2. 将所有入度为 0 的节点加入队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        // 3. BFS 拓扑排序
        int count = 0;  // 已处理的课程数
        while (!queue.isEmpty()) {
            int course = queue.poll();
            count++;
            
            // 处理所有依赖当前课程的课程
            for (int nextCourse : graph.get(course)) {
                inDegree[nextCourse]--;
                // 如果入度变为 0，加入队列
                if (inDegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }
        
        // 4. 判断是否所有课程都被处理
        return count == numCourses;
    }
}
```

**算法思路**：
1. **构建图**：使用邻接表表示有向图
2. **计算入度**：统计每个节点的入度（有多少条边指向它）
3. **初始化队列**：将所有入度为 0 的节点加入队列
4. **BFS 过程**：
   - 从队列取出节点，处理计数加 1
   - 将该节点指向的所有节点入度减 1
   - 如果某个节点入度变为 0，加入队列
5. **判断结果**：如果处理了所有节点，说明无环；否则有环

**为什么能检测环？**
- 如果有环，环上的节点入度永远不会为 0
- 这些节点永远不会进入队列
- 最终 `count < numCourses`

### 方法二：深度优先搜索（DFS）⭐

```java
import java.util.*;

class Solution {
    // 节点状态：0=未访问，1=访问中，2=已完成
    private int[] visited;
    private List<List<Integer>> graph;
    
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建图
        graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] pre : prerequisites) {
            graph.get(pre[1]).add(pre[0]);
        }
        
        // 2. 初始化状态数组
        visited = new int[numCourses];
        
        // 3. 对每个未访问的节点进行 DFS
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0) {
                if (hasCycle(i)) {
                    return false;
                }
            }
        }
        
        return true;
    }
    
    private boolean hasCycle(int course) {
        if (visited[course] == 1) {
            // 访问到「访问中」的节点，说明有环
            return true;
        }
        if (visited[course] == 2) {
            // 已经确认无环的节点，直接返回
            return false;
        }
        
        // 标记为「访问中」
        visited[course] = 1;
        
        // 递归访问所有邻居
        for (int nextCourse : graph.get(course)) {
            if (hasCycle(nextCourse)) {
                return true;
            }
        }
        
        // 标记为「已完成」
        visited[course] = 2;
        return false;
    }
}
```

**算法思路**：
- **三色标记法**：
  - 0（白色）：未访问
  - 1（灰色）：访问中（在当前 DFS 路径上）
  - 2（黑色）：已完成（确认无环）
- **环的检测**：如果访问到「灰色」节点，说明形成了环
- **优化**：已访问过的节点（黑色）不需要重复访问

## 复杂度分析

### 方法一、二：拓扑排序（BFS）/ DFS
- **时间复杂度**：O(V + E)
  - V 是课程数（节点数）
  - E 是先修关系数（边数）
  - 每个节点和边都访问一次
- **空间复杂度**：O(V + E)
  - 邻接表存储图：O(E)
  - 入度数组：O(V)
  - 队列/递归栈：O(V)

## 图解示例

### 示例 1：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]

```
图的表示：
0 → 1 → 3
↓     ↗
2 ----

拓扑排序过程：

初始入度：
0: 0 ✓
1: 1
2: 1
3: 2

步骤1：处理节点 0（入度 0）
队列：[0]
处理 0，count = 1
更新：1 入度 → 0，2 入度 → 0
队列：[1, 2]

步骤2：处理节点 1
处理 1，count = 2
更新：3 入度 → 1

步骤3：处理节点 2
处理 2，count = 3
更新：3 入度 → 0

步骤4：处理节点 3
处理 3，count = 4

结果：count = 4 = numCourses，返回 true
```

### 示例 2：numCourses = 2, prerequisites = [[1,0],[0,1]]

```
图的表示（有环）：
0 ⇄ 1

初始入度：
0: 1
1: 1

队列为空（没有入度为 0 的节点）
count = 0 ≠ numCourses

结果：返回 false
```

## 关键点总结

1. **问题建模**：课程依赖 → 有向图，能否完成 → 是否有环
2. **拓扑排序**：基于入度的 BFS，能完整排序说明无环
3. **DFS 三色标记**：检测回边（访问到灰色节点）
4. **两种方法对比**：
   - BFS：更直观，容易理解
   - DFS：代码简洁，空间可能更优
5. **实际应用**：任务调度、编译依赖、安装包管理等

## 易错点

1. **边的方向**：`[a, b]` 表示 `b → a`（先学 b 才能学 a）
   - 容易理解反了

2. **入度计算错误**：
   ```java
   // 错误
   inDegree[prereq]++;  // 应该是 course
   ```

3. **忘记初始化队列**：需要将所有入度为 0 的节点加入队列

4. **DFS 状态错误**：
   - 忘记将节点标记为「访问中」
   - 忘记在完成后标记为「已完成」

5. **边界情况**：
   - numCourses = 1, prerequisites = []（单个课程，无依赖）
   - 没有先修关系（全是独立课程）
