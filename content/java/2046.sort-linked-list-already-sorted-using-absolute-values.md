## 题目描述

给定按绝对值非递减排列的链表，返回按实际值非递减排列的链表。

## 解题思路

将链表分为负数链（头插法使其变为升序）和非负数链，再归并合并两条有序链表，O(n) 时间 O(1) 空间。

## Java 代码实现

### 方法一：分离 + 头插反转 + 合并（推荐）

```java
class Solution {
    public ListNode sortLinkedList(ListNode head) {
        ListNode negHead = null; // 负数链头（头插法构建，自然有序）
        ListNode posDummy = new ListNode(0);
        ListNode posTail = posDummy;

        ListNode cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;
            if (cur.val < 0) {
                // 头插到负数链
                cur.next = negHead;
                negHead = cur;
            } else {
                // 尾插到正数链
                posTail.next = cur;
                cur.next = null;
                posTail = cur;
            }
            cur = nxt;
        }

        // 归并两条有序链表
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        ListNode p1 = negHead, p2 = posDummy.next;
        while (p1 != null && p2 != null) {
            if (p1.val <= p2.val) {
                tail.next = p1;
                p1 = p1.next;
            } else {
                tail.next = p2;
                p2 = p2.next;
            }
            tail = tail.next;
        }
        tail.next = (p1 != null) ? p1 : p2;
        return dummy.next;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 负数部分按绝对值递增即按实际值递减，头插法使其变为升序
2. 正数部分保持原顺序即为升序
3. 归并两条有序链表
