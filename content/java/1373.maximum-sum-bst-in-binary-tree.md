## 题目描述

给你一棵以 `root` 为根的二叉树，返回任意二叉搜索树子树的最大键值和，若所有 BST 子树键值和为负则返回 0。

## 解题思路

后序 DFS，每个节点返回四元组 `(isBST, minVal, maxVal, sum)`。若左右子树均为 BST 且满足 BST 条件（左最大 < 当前值 < 右最小），则当前子树也是 BST，更新全局最大和。空节点返回 `(true, +INF, -INF, 0)` 作为哨兵值。

## Java 代码实现

```java
class Solution {
    private int ans = 0;

    public int maxSumBST(TreeNode root) {
        dfs(root);
        return ans;
    }

    // 返回 int[]：{isBST(1/0), minVal, maxVal, sum}
    private int[] dfs(TreeNode node) {
        if (node == null) {
            // 空节点：是 BST，用 INF/-INF 作为哨兵不影响父节点判断
            return new int[]{1, Integer.MAX_VALUE, Integer.MIN_VALUE, 0};
        }

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        int val = node.val;
        // 判断当前子树是否满足 BST 条件
        if (left[0] == 1 && right[0] == 1
                && left[2] < val && val < right[1]) {
            int sum = left[3] + right[3] + val;
            ans = Math.max(ans, sum);
            int minVal = Math.min(left[1], val);
            int maxVal = Math.max(right[2], val);
            return new int[]{1, minVal, maxVal, sum};
        }
        // 非 BST，向上传播无效标记
        return new int[]{0, 0, 0, 0};
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点只访问一次。
- 空间复杂度：O(h)，h 为树的高度，递归栈深度。

## 关键点总结

1. 后序 DFS 先获取子树信息再合并，一次遍历完成 BST 验证和键值和统计。
2. 空节点哨兵值 `(+INF, -INF)` 保证叶子节点的 BST 判断正确，无需特判。
3. 非 BST 子树向上传播无效标记，父树也必然非 BST，整体剪枝效果显著。
