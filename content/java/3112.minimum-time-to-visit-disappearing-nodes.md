## 题目描述

给你 n 个顶点的无向加权图和消失时间数组 `disappear`（顶点 i 在 disappear[i] 时刻消失）。返回从顶点 0 出发到每个顶点的最短到达时间，无法到达返回 -1。

## 解题思路

Dijkstra 最短路，松弛时额外判断到达时间必须严格小于目标顶点的消失时间（`nd < disappear[v]`）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] minimumTime(int n, int[][] edges, int[] disappear) {
        List<int[]>[] adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            adj[e[0]].add(new int[]{e[1], e[2]});
            adj[e[1]].add(new int[]{e[0], e[2]});
        }

        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue;
            for (int[] next : adj[u]) {
                int v = next[0], nd = d + next[1];
                // 到达时间必须严格小于消失时间
                if (nd < disappear[v] && nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new int[]{nd, v});
                }
            }
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) ans[i] = dist[i] == Integer.MAX_VALUE ? -1 : dist[i];
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + m) log n)
- 空间复杂度：O(n + m)

## 关键点总结

1. 标准 Dijkstra 加消失时间约束：nd < disappear[v]
2. 起点 0 的消失时间也需满足（dist[0]=0 < disappear[0]）
