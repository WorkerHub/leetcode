## 题目描述

给你一个只包含整数的有序数组，其中每个元素都会出现两次，唯有一个数只会出现一次。找出只出现一次的那个数。要求 O(log n) 时间复杂度。

**示例：**
```
输入: nums = [1,1,2,3,3,4,4,8,8]
输出: 2
```

## 解题思路

二分查找：将 mid 调整为偶数，若 `nums[mid] == nums[mid+1]`，单独元素在右侧；否则在左侧。

## Java 代码实现

```java
class Solution {
    public int singleNonDuplicate(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            // 确保 mid 是偶数
            if (mid % 2 == 1) mid--;

            if (nums[mid] == nums[mid + 1]) {
                // 单独元素在右侧
                left = mid + 2;
            } else {
                // 单独元素在左侧（含 mid）
                right = mid;
            }
        }
        return nums[left];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **偶数索引对齐**：将 mid 调整为偶数简化判断
2. **配对规律**：单独元素前，偶数索引与下一个相等；之后规律反转
3. **循环条件**：`left < right`，最终 left 即答案
