## 题目描述

给你两棵二叉树的根节点 `p` 和 `q`，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

**示例 1：**
```
输入：p = [1,2,3], q = [1,2,3]
输出：true
```

**示例 2：**
```
输入：p = [1,2], q = [1,null,2]
输出：false
```

**示例 3：**
```
输入：p = [1,2,1], q = [1,1,2]
输出：false
```

**提示：**
- 两棵树上的节点数目都在范围 `[0, 100]` 内
- `-10^4 <= Node.val <= 10^4`

## 解题思路

这是一道经典的二叉树递归问题，需要同时遍历两棵树并比较对应位置的节点。

**核心思想：**
1. 如果两棵树都为空，则相同
2. 如果一棵为空另一棵不为空，则不相同
3. 如果两棵树的根节点值不同，则不相同
4. 递归检查左子树和右子树是否分别相同

**为什么使用递归？**
- 树的结构本身就是递归定义的
- 子问题具有相同的结构：判断两棵子树是否相同
- 递归代码简洁清晰，符合树的特性

**DFS vs BFS：**
- DFS（深度优先搜索）：使用递归或栈，先深入到叶子节点
- BFS（广度优先搜索）：使用队列，逐层比较节点

## Java 代码实现

### 方法一：递归 DFS（推荐）

```java
// Definition for a binary tree node.
// public class TreeNode {
//     int val;
//     TreeNode left;
//     TreeNode right;
//     TreeNode() {}
//     TreeNode(int val) { this.val = val; }
//     TreeNode(int val, TreeNode left, TreeNode right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        // 基本情况：两棵树都为空
        if (p == null && q == null) {
            return true;
        }

        // 一棵为空，另一棵不为空
        if (p == null || q == null) {
            return false;
        }

        // 当前节点值不同
        if (p.val != q.val) {
            return false;
        }

        // 递归检查左子树和右子树
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

### 方法二：迭代 BFS（使用队列）

```java
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        // 使用队列进行层序遍历
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(p);
        queue.offer(q);

        while (!queue.isEmpty()) {
            TreeNode node1 = queue.poll();
            TreeNode node2 = queue.poll();

            // 两个节点都为空，继续下一对
            if (node1 == null && node2 == null) {
                continue;
            }

            // 一个为空另一个不为空，或值不同
            if (node1 == null || node2 == null || node1.val != node2.val) {
                return false;
            }

            // 将左右子节点加入队列
            queue.offer(node1.left);
            queue.offer(node2.left);
            queue.offer(node1.right);
            queue.offer(node2.right);
        }

        return true;
    }
}
```

### 方法三：迭代 DFS（使用栈）

```java
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        // 使用栈进行深度优先遍历
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(p);
        stack.push(q);

        while (!stack.isEmpty()) {
            TreeNode node1 = stack.pop();
            TreeNode node2 = stack.pop();

            // 两个节点都为空
            if (node1 == null && node2 == null) {
                continue;
            }

            // 一个为空另一个不为空，或值不同
            if (node1 == null || node2 == null || node1.val != node2.val) {
                return false;
            }

            // 将子节点压入栈（注意顺序：先右后左，或成对入栈）
            stack.push(node1.right);
            stack.push(node2.right);
            stack.push(node1.left);
            stack.push(node2.left);
        }

        return true;
    }
}
```

## 复杂度分析

### 递归 DFS
- **时间复杂度**：O(min(m, n))，其中 m 和 n 分别是两棵树的节点数。最坏情况下需要遍历所有节点。
- **空间复杂度**：O(min(m, n))，递归调用栈的深度取决于树的高度，最坏情况下为 O(n)。

### 迭代 BFS/DFS
- **时间复杂度**：O(min(m, n))
- **空间复杂度**：O(min(m, n))，队列或栈中最多存储一层的节点

## 关键点总结

1. **边界条件处理**：优先处理空节点的情况，避免空指针错误
2. **递归三要素**：
   - 终止条件：节点为空或值不同
   - 递归逻辑：比较左右子树
   - 返回值：布尔值表示是否相同
3. **短路逻辑**：使用 `&&` 连接递归调用，一旦发现不同立即返回 `false`
4. **三种实现方式**：递归 DFS 最简洁，迭代方法避免栈溢出
5. **对称性检查**：同时遍历两棵树的对应位置

## 易错点

1. **空节点判断顺序**：
   ```java
   // 错误：可能导致空指针异常
   if (p.val != q.val) return false;

   // 正确：先判断是否为空
   if (p == null && q == null) return true;
   if (p == null || q == null) return false;
   if (p.val != q.val) return false;
   ```

2. **递归返回值**：
   ```java
   // 错误：忘记返回递归结果
   isSameTree(p.left, q.left);
   isSameTree(p.right, q.right);

   // 正确：使用 && 连接并返回
   return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
   ```

3. **BFS 队列中成对入队**：
   ```java
   // 注意：两棵树的节点必须成对加入队列，然后成对取出比较
   queue.offer(node1.left);
   queue.offer(node2.left);
   ```

4. **Java 中整数比较**：节点值用 `p.val != q.val` 比较，不涉及 `equals`
