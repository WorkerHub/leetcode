## 题目描述

给定出生和死亡年份数组，人在[birth, death-1]存活，求人口最多的最早年份。年份范围1950-2050。

## 解题思路

差分数组：出生年+1，死亡年-1，前缀和得每年人口，找最大值对应最早年份。

## Java 代码实现

```java
class Solution {
    public int maximumPopulation(int[][] logs) {
        int[] diff = new int[102]; // 下标0对应1950年
        
        for (int[] log : logs) {
            diff[log[0] - 1950]++;
            diff[log[1] - 1950]--;
        }
        
        int maxPop = 0, curPop = 0, bestYear = 1950;
        for (int i = 0; i < 101; i++) {
            curPop += diff[i];
            if (curPop > maxPop) {
                maxPop = curPop;
                bestYear = 1950 + i;
            }
        }
        return bestYear;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **差分数组**：高效处理区间加减
2. **死亡年不算存活**：diff[death-1950]-- 而非 diff[death-1950+1]--
3. **前缀和求每年人口**：遍历时取第一个最大值
