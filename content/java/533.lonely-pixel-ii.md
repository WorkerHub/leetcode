## 题目描述

给定一个由 `'B'` 和 `'W'` 组成的二维数组 `picture` 以及整数 `target`，返回黑色孤独像素的数量。

黑色孤独像素 `(r, c)` 满足：
1. 行 `r` 和列 `c` 都恰好包含 `target` 个黑色像素
2. 对于所有在列 `c` 上有黑色像素的行，它们必须与行 `r` 完全相同

## 解题思路

统计每行每列黑色像素数，按列验证行是否全部相同。

## Java 代码实现

```java
class Solution {
    public int findBlackPixel(char[][] picture, int target) {
        int m = picture.length, n = picture[0].length;
        int[] rowCount = new int[m];
        List<List<Integer>> colRows = new ArrayList<>();

        for (int j = 0; j < n; j++) {
            colRows.add(new ArrayList<>());
        }

        // 统计每行黑色像素数，记录每列黑色像素所在行
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (picture[i][j] == 'B') {
                    rowCount[i]++;
                    colRows.get(j).add(i);
                }
            }
        }

        int ans = 0;
        for (int j = 0; j < n; j++) {
            List<Integer> rows = colRows.get(j);
            if (rows.isEmpty()) continue;

            int firstRow = rows.get(0);
            // 条件1：该行恰好有 target 个黑色像素
            if (rowCount[firstRow] != target) continue;
            // 条件2：该列恰好有 target 个黑色像素
            if (rows.size() != target) continue;

            // 条件3：所有行都与第一行相同
            boolean allSame = true;
            for (int i : rows) {
                if (!Arrays.equals(picture[i], picture[firstRow])) {
                    allSame = false;
                    break;
                }
            }
            if (allSame) {
                ans += target;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n²)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **按列处理**：避免重复计数
2. **行相等判断**：Arrays.equals 比较整行
3. **条件同时满足**：行数和列数都要等于 target
