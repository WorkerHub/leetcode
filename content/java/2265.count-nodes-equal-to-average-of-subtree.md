## 题目描述

统计节点值等于其子树平均值（向下取整）的节点数量。

## 解题思路

DFS后序遍历，每个节点返回(子树总和, 子树节点数)，判断val==sum/count。

## Java 代码实现

```java
class Solution {
    private int ans = 0;

    public int averageOfSubtree(TreeNode root) {
        dfs(root);
        return ans;
    }

    // 返回 [子树总和, 子树节点数]
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);
        int sum = left[0] + right[0] + node.val;
        int cnt = left[1] + right[1] + 1;
        if (node.val == sum / cnt) ans++;
        return new int[]{sum, cnt};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(H)，H为树高

## 关键点总结

1. **后序遍历**：先处理子节点再计算当前节点
2. **返回(sum, count)**：向上传递合并
3. **整数除法**：Java的/天然向下取整
