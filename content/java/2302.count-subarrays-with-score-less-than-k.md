## 题目描述

子数组的分数=子数组之和*长度，返回分数严格小于k的非空子数组数目。

## 解题思路

滑动窗口：全为正数保证单调性，窗口扩大分数增大。对每个右端点找最小合法左端点。

## Java 代码实现

```java
class Solution {
    public long countSubarrays(int[] nums, long k) {
        long ans = 0;
        long total = 0;
        int left = 0;

        for (int right = 0; right < nums.length; right++) {
            total += nums[right];
            // 窗口分数 >= k 时缩小左边界
            while (total * (right - left + 1) >= k) {
                total -= nums[left];
                left++;
            }
            ans += right - left + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **正整数保证单调性**：适合滑动窗口
2. **分数=和*长度**：两者随窗口扩大而增大
3. **long防溢出**：和与长度乘积可能很大
