## 题目描述

给你一个整数数组 `nums` 和两个整数 `p`、`q`，统计 `nums` 中同时能被 `p` 和 `q` 整除的元素数目。

## 解题思路

同时被 `p` 和 `q` 整除等价于被 `lcm(p, q)` 整除，其中 `lcm(p, q) = p * q / gcd(p, q)`，遍历统计即可。

## Java 代码实现

```java
class Solution {
    public int findDivisibleCount(int[] nums, int p, int q) {
        // 计算 lcm(p, q) = p * q / gcd(p, q)
        int lcm = p / gcd(p, q) * q;

        int count = 0;
        for (int v : nums) {
            if (v % lcm == 0) count++;
        }
        return count;
    }

    // 辗转相除法求最大公约数
    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 同时被 p 和 q 整除等价于被 `lcm(p, q)` 整除。
2. `lcm(p, q) = p * q / gcd(p, q)`，先除后乘避免溢出。
3. gcd 用辗转相除法实现。
