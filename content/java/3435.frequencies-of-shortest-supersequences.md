## 题目描述

给定字符串数组 `words`，找出所有最短超序列（每个 word 都是其子序列）的字符频率数组，去重后按字典序返回。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<List<Integer>> supersequences(String[] words) {
        // 每个字母的最低需求：各单词中该字母出现次数的最大值
        int[] minCount = new int[26];
        for (String w : words) {
            int[] freq = new int[26];
            for (char c : w.toCharArray()) freq[c - 'a']++;
            for (int i = 0; i < 26; i++) minCount[i] = Math.max(minCount[i], freq[i]);
        }

        // 构建依赖图：dep[i][j] 表示某单词中字符 i 在字符 j 之前出现
        boolean[][] dep = new boolean[26][26];
        for (String w : words) {
            boolean[] seen = new boolean[26];
            for (char c : w.toCharArray()) {
                int ci = c - 'a';
                for (int j = 0; j < 26; j++) {
                    if (seen[j]) dep[j][ci] = true;
                }
                seen[ci] = true;
            }
        }

        // Floyd-Warshall 计算传递闭包
        boolean[][] reach = new boolean[26][26];
        for (int i = 0; i < 26; i++) System.arraycopy(dep[i], 0, reach[i], 0, 26);
        for (int k = 0; k < 26; k++)
            for (int i = 0; i < 26; i++)
                if (reach[i][k])
                    for (int j = 0; j < 26; j++)
                        if (reach[k][j]) reach[i][j] = true;

        // 找在环中的字符（reach[i][i] = true）
        int[] cc = new int[26];
        int m = 0;
        for (int i = 0; i < 26; i++) if (reach[i][i]) cc[m++] = i;

        // 提取环中字符的子图邻接矩阵
        boolean[][] subDep = new boolean[m][m];
        for (int i = 0; i < m; i++)
            for (int j = 0; j < m; j++)
                subDep[i][j] = dep[cc[i]][cc[j]];

        // 枚举哪些环中字符需要 +1（最小反馈顶点集）
        int minExtra = m + 1;
        Set<List<Integer>> seen2 = new HashSet<>();

        for (int mask = 0; mask < (1 << m); mask++) {
            int extra = Integer.bitCount(mask);
            if (extra > minExtra) continue;
            // 检查删除 mask 中字符后子图是否为 DAG
            if (isDAGAfterRemoval(subDep, m, mask)) {
                if (extra < minExtra) {
                    minExtra = extra;
                    seen2.clear();
                }
                int[] cand = minCount.clone();
                for (int bit = 0; bit < m; bit++)
                    if ((mask >> bit & 1) == 1) cand[cc[bit]]++;
                List<Integer> list = new ArrayList<>();
                for (int v : cand) list.add(v);
                seen2.add(list);
            }
        }

        List<List<Integer>> res = new ArrayList<>(seen2);
        res.sort((a, b) -> {
            for (int i = 0; i < 26; i++) if (!a.get(i).equals(b.get(i))) return a.get(i) - b.get(i);
            return 0;
        });
        return res;
    }

    // Kahn 拓扑排序：检查删除 mask 后子图是否为 DAG
    private boolean isDAGAfterRemoval(boolean[][] adj, int m, int mask) {
        int[] indeg = new int[m];
        int remaining = 0;
        for (int i = 0; i < m; i++) {
            if ((mask >> i & 1) == 1) continue;
            remaining++;
            for (int j = 0; j < m; j++) {
                if ((mask >> j & 1) == 0 && adj[j][i]) indeg[i]++;
            }
        }
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < m; i++)
            if ((mask >> i & 1) == 0 && indeg[i] == 0) q.offer(i);
        int cnt = 0;
        while (!q.isEmpty()) {
            int u = q.poll(); cnt++;
            for (int v = 0; v < m; v++) {
                if ((mask >> v & 1) == 0 && adj[u][v])
                    if (--indeg[v] == 0) q.offer(v);
            }
        }
        return cnt == remaining;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^m * m^2)，m 为环中字符数（实际较小）
- 空间复杂度：O(26^2 + 2^m)

## 关键点总结

1. 每个字母最低需求 = 各单词中该字母出现次数的最大值
2. Floyd-Warshall 检测字符间传递依赖，`reach[i][i]` 为 true 表示字符在环中
3. 枚举最小反馈顶点集：移除哪些环中字符（+1 其计数）后依赖图变为 DAG
