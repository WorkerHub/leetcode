## 题目描述

n×n 网格上叠放立方体（grid[i][j] 个），求这些立方体拼接后的总表面积。

**示例：**
```
输入：grid = [[1,2],[3,4]]
输出：34
```

## 解题思路

每个非零格子贡献顶底 2 面 + 侧面 4×height，减去竖直和相邻遮挡的面。

## Java 代码实现

```java
class Solution {
    public int surfaceArea(int[][] grid) {
        int n = grid.length;
        int area = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] > 0) {
                    // 顶底 2 面 + 四个侧面
                    area += 2 + grid[i][j] * 4;
                    // 减去竖直遮挡
                    area -= (grid[i][j] - 1) * 2;
                    // 减去相邻遮挡
                    if (i > 0) area -= Math.min(grid[i][j], grid[i - 1][j]) * 2;
                    if (j > 0) area -= Math.min(grid[i][j], grid[i][j - 1]) * 2;
                }
            }
        }
        return area;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **基础表面积**：每根柱子贡献 2 + 4h
2. **竖直遮挡**：同列相邻层 (h-1)×2
3. **水平遮挡**：相邻柱子 min(h1,h2)×2
