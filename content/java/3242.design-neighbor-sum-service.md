## 题目描述

给你一个 `n x n` 矩阵，实现类支持两种查询：返回某值上下左右四个相邻元素之和，以及四个对角相邻元素之和。

## Java 代码实现

```java
class NeighborSum {
    private int[][] grid;
    private int n;
    private int[] row, col; // row[v], col[v] = 值 v 的位置

    public NeighborSum(int[][] grid) {
        this.grid = grid;
        this.n = grid.length;
        int total = n * n;
        row = new int[total];
        col = new int[total];
        // 预处理每个值的位置
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                row[grid[i][j]] = i;
                col[grid[i][j]] = j;
            }
        }
    }

    public int adjacentSum(int value) {
        int r = row[value], c = col[value], total = 0;
        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        for (int[] d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr >= 0 && nr < n && nc >= 0 && nc < n) total += grid[nr][nc];
        }
        return total;
    }

    public int diagonalSum(int value) {
        int r = row[value], c = col[value], total = 0;
        int[][] dirs = {{-1,-1},{-1,1},{1,-1},{1,1}};
        for (int[] d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr >= 0 && nr < n && nc >= 0 && nc < n) total += grid[nr][nc];
        }
        return total;
    }
}
```

## 复杂度分析

- 构造：O(n^2)
- 查询：O(1)
- 空间：O(n^2)

## 关键点总结

1. 预处理数组记录每个值的位置，查询时 O(1) 定位
2. 上下左右和对角分别用方向数组遍历
3. 注意边界检查防止越界
