## 题目描述

给你字符串 `s` 和正整数 `k`，若子字符串元音数等于辅音数且两者乘积能被 `k` 整除，则称其为美丽子字符串，返回美丽子字符串的数目。

## 解题思路

n <= 1000，直接 O(n²) 枚举所有子串。设子串元音数为 v，辅音数为 c，检查 `v == c` 且 `v * c % k == 0` 即可。

## Java 代码实现

```java
class Solution {
    public int beautifulSubstrings(String s, int k) {
        Set<Character> vowels = Set.of('a', 'e', 'i', 'o', 'u');
        int n = s.length(), ans = 0;

        for (int l = 0; l < n; l++) {
            int vCount = 0; // 元音个数
            for (int r = l; r < n; r++) {
                if (vowels.contains(s.charAt(r))) vCount++;
                int length = r - l + 1;
                int cCount = length - vCount; // 辅音个数
                if (vCount == cCount && (long) vCount * cCount % k == 0) ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. 元音数 = 辅音数意味着子串长度为偶数
2. 条件等价于 m² % k == 0（m = 元音数）
3. n <= 1000 时 O(n²) 完全够用
