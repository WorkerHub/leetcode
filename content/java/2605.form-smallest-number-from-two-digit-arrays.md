## 题目描述

给两个数字数组(1-9)，返回能由两数组各取一个数字组成的最小数（有公共元素返回该元素）。

## 解题思路

先找公共元素(取最小即一位数)，无公共元素则取各自最小值组成两位数，较小放十位。

## Java 代码实现

```java
class Solution {
    public int minNumber(int[] nums1, int[] nums2) {
        boolean[] set1 = new boolean[10], set2 = new boolean[10];
        for (int x : nums1) set1[x] = true;
        for (int x : nums2) set2[x] = true;

        // 找最小公共元素
        for (int i = 1; i <= 9; i++) {
            if (set1[i] && set2[i]) return i;
        }
        // 无公共元素，取各自最小值组成两位数
        int a = nums1[0], b = nums2[0];
        for (int x : nums1) a = Math.min(a, x);
        for (int x : nums2) b = Math.min(b, x);
        return Math.min(a * 10 + b, b * 10 + a);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + M)
- **空间复杂度**：O(1)

## 关键点总结

1. **公共元素优先**：一位数一定比两位数小
2. **无公共时取最小值组合**：较小数放十位
3. **布尔数组代替HashSet**：数字范围1-9
