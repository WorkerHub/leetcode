## 题目描述

两个等长字符串 s1、s2 只含 'x' 和 'y'。可以交换 s1[i] 和 s2[j]。求使 s1==s2 的最小交换次数，不可能则返回 -1。

**示例：**
```
输入：s1 = "xx", s2 = "yy"
输出：1（交换 s1[0] 和 s2[1]）
```

## 解题思路

统计不匹配位置：s1[i]='x',s2[i]='y' 记为 xy 对，反之记为 yx 对。两个 xy 对或两个 yx 对可以 1 次交换解决；一个 xy + 一个 yx 需要 2 次。若总不匹配数为奇数则无解。

## Java 代码实现

```java
class Solution {
    public int minimumSwap(String s1, String s2) {
        int xy = 0, yx = 0;
        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) == 'x' && s2.charAt(i) == 'y') xy++;
            else if (s1.charAt(i) == 'y' && s2.charAt(i) == 'x') yx++;
        }
        // 总不匹配数必须为偶数
        if ((xy + yx) % 2 != 0) return -1;
        // 每对同类型 1 次，剩余混合对 2 次
        return xy / 2 + yx / 2 + (xy % 2) * 2;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **分类计数**：xy 对和 yx 对分开统计
2. **同类型配对**：2 个 xy 或 2 个 yx 只需 1 次交换
3. **混合配对**：1 个 xy + 1 个 yx 需要 2 次交换
4. **无解条件**：(xy + yx) 为奇数时无法配对
