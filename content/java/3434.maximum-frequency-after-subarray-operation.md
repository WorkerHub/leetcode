## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可选一个连续子数组并将其中所有等于某值 `x` 的元素改为 `k`，返回操作后 `k` 的最大频率。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxFrequency(int[] nums, int k) {
        int totalK = 0;
        Set<Integer> distinct = new HashSet<>();
        for (int v : nums) {
            if (v == k) totalK++;
            else distinct.add(v);
        }

        int bestGain = 0;

        // 枚举替换目标值 x，转化为求最大子数组和（Kadane）
        for (int x : distinct) {
            int cur = 0, maxGain = 0;
            for (int v : nums) {
                if (v == x) cur++;
                else if (v == k) cur--;
                if (cur < 0) cur = 0;  // 重置：允许不操作
                if (cur > maxGain) maxGain = cur;
            }
            if (maxGain > bestGain) bestGain = maxGain;
        }

        return totalK + bestGain;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * D)，D 为不同值的数量，最坏 O(n^2)
- 空间复杂度：O(D)

## 关键点总结

1. 枚举替换目标值 x，将问题转化为最大子数组和（Kadane 算法）
2. 辅助数组中 x 对应 +1，k 对应 -1，其他为 0
3. 最终答案 = 原有的 k 数量 + 最大可增加量
