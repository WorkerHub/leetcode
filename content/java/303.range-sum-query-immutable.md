## 题目描述

给定一个整数数组 `nums`，处理以下类型的多个查询:

1. 计算索引 `left` 和 `right` （包含 `left` 和 `right`）之间的 `nums` 元素的**和**，其中 `left <= right`

实现 `NumArray` 类：

- `NumArray(int[] nums)` 使用数组 `nums` 初始化对象
- `int sumRange(int left, int right)` 返回数组 `nums` 中索引 `left` 和 `right` 之间的元素的**总和**，包含 `left` 和 `right` 两点（也就是 `nums[left] + nums[left + 1] + ... + nums[right]`）

**示例 1：**
```
输入：
["NumArray", "sumRange", "sumRange", "sumRange"]
[[[-2, 0, 3, -5, 2, -1]], [0, 2], [2, 5], [0, 5]]
输出：
[null, 1, -1, -3]

解释：
NumArray numArray = new NumArray([-2, 0, 3, -5, 2, -1]);
numArray.sumRange(0, 2); // return 1 ((-2) + 0 + 3)
numArray.sumRange(2, 5); // return -1 (3 + (-5) + 2 + (-1)) 
numArray.sumRange(0, 5); // return -3 ((-2) + 0 + 3 + (-5) + 2 + (-1))
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^5 <= nums[i] <= 10^5`
- `0 <= left <= right < nums.length`
- 最多调用 `10^4` 次 `sumRange` 方法

## 解题思路

这是一道经典的**前缀和（Prefix Sum）**问题。

### 暴力方法

每次查询时遍历 `[left, right]` 区间求和：
- 时间复杂度：O(n) per query
- 不适合大量查询的场景

### 前缀和优化（推荐）⭐

**核心思想**：提前计算好前缀和数组，将区间求和转化为 O(1) 的查询。

**前缀和定义**：
- `prefix[i]` = `nums[0] + nums[1] + ... + nums[i-1]`
- `prefix[0] = 0`（方便计算）

**区间和公式**：
```
sumRange(left, right) = prefix[right+1] - prefix[left]
```

**图解示例**：
```
nums    = [-2,  0,  3, -5,  2, -1]
prefix  = [0, -2, -2,  1, -4, -2, -3]
           ↑   ↑       ↑
          i=0 i=1     i=3

sumRange(0, 2) = prefix[3] - prefix[0] = 1 - 0 = 1
sumRange(2, 5) = prefix[6] - prefix[2] = -3 - (-2) = -1
```

## Java 代码实现

### 方法一：前缀和（推荐）⭐

```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        // 初始化前缀和数组
        // prefix[i] 表示 nums[0..i-1] 的和
        int n = nums.length;
        prefix = new int[n + 1];

        // 构建前缀和数组
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }

    public int sumRange(int left, int right) {
        // 返回区间 [left, right] 的和
        // 公式：prefix[right+1] - prefix[left]
        return prefix[right + 1] - prefix[left];
    }
}
```

### 方法二：暴力方法（不推荐，仅供对比）

```java
class NumArray {
    private int[] nums;

    public NumArray(int[] nums) {
        this.nums = nums;
    }

    public int sumRange(int left, int right) {
        // 每次查询时遍历区间
        int sum = 0;
        for (int i = left; i <= right; i++) {
            sum += nums[i];
        }
        return sum;
    }
}
```

### 方法三：使用循环累积和

```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        // 通过循环构建累积和，等价于 Python itertools.accumulate
        // prefix[0] = 0, prefix[i+1] = prefix[i] + nums[i]
        int n = nums.length;
        prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }

    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
}
```

### 方法四：原地修改（节省空间）

```java
class NumArray {
    private int[] prefix;

    public NumArray(int[] nums) {
        // 注意：这里 clone 原数组，不破坏入参
        int[] copy = nums.clone();
        for (int i = 1; i < copy.length; i++) {
            copy[i] += copy[i - 1];
        }
        // 在前面补 0，构造 prefix 数组
        prefix = new int[copy.length + 1];
        System.arraycopy(copy, 0, prefix, 1, copy.length);
    }

    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
}
```

## 复杂度分析

**方法一（前缀和）：**
- 时间复杂度：
  - 初始化：O(n)
  - 查询：O(1)
- 空间复杂度：O(n)，存储前缀和数组

**方法二（暴力）：**
- 时间复杂度：
  - 初始化：O(1)
  - 查询：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. **前缀和公式**：`prefix[i] = prefix[i-1] + nums[i-1]`
2. **区间和公式**：`sumRange(left, right) = prefix[right+1] - prefix[left]`
3. **索引处理**：`prefix` 数组长度为 `n+1`，`prefix[0] = 0`
4. **以空间换时间**：通过 O(n) 的空间将查询优化到 O(1)
5. **适用场景**：数组不可变，需要大量区间和查询

## 易错点

1. **索引错误**：
   - `prefix` 数组长度是 `n+1` 而不是 `n`
   - `sumRange(left, right)` 应该是 `prefix[right+1] - prefix[left]`
   
2. **边界情况**：
   - `left = 0` 的情况
   - `left = right` 的情况（单个元素）

3. **前缀和初始值**：
   - `prefix[0]` 必须是 0，不能省略

4. **原地修改陷阱**：
   - Java 中直接修改传入的 nums 数组会影响调用方，建议 clone

## 学习建议

前缀和是非常重要的基础技巧：

1. **理解核心思想**：用空间换时间，提前计算好累积和
2. **掌握公式推导**：理解为什么是 `prefix[right+1] - prefix[left]`
3. **索引处理**：为什么 `prefix` 要多一位（方便处理 `left=0` 的情况）
4. **扩展学习**：
   - 二维前缀和（304 题）
   - 可变数组的区间和（307 题，需要用树状数组或线段树）
   - 前缀和 + 哈希表（560 题）
5. **应用场景**：
   - 频繁的区间和查询
   - 数组不可变或查询次数远大于修改次数
   - 需要 O(1) 查询时间的场景
