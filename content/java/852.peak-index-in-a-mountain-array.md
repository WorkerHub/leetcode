## 题目描述

符合下列属性的数组 arr 称为 山脉数组：
- arr.length >= 3
- 存在 i（0 < i < arr.length - 1）使得：
  - arr[0] < arr[1] < ... arr[i-1] < arr[i]
  - arr[i] > arr[i+1] > ... > arr[arr.length - 1]

给你由整数组成的山脉数组 arr ，返回满足 arr[0] < arr[1] < ... arr[i - 1] < arr[i] > arr[i + 1] > ... > arr[arr.length - 1] 的下标 i 。

你必须设计并实现时间复杂度为 O(log(n)) 的解决方案。

**示例 1：**
```
输入：arr = [0,1,0]
输出：1
```

**示例 2：**
```
输入：arr = [0,2,1,0]
输出：1
```

**示例 3：**
```
输入：arr = [0,10,5,2]
输出：1
```

**提示：**
- 3 <= arr.length <= 10^5
- 0 <= arr[i] <= 10^6
- 题目数据保证 arr 是一个山脉数组

## 解题思路

这是一道经典的**二分查找**题目。山脉数组的特性保证了只有一个峰值，我们可以利用这个特性进行二分搜索。

**核心观察：**
1. 山脉数组先递增后递减，峰值唯一
2. 如果 `arr[mid] < arr[mid + 1]`，说明 mid 在上升阶段，峰值在右边
3. 如果 `arr[mid] > arr[mid + 1]`，说明 mid 在下降阶段或就是峰值，峰值在左边（包括 mid）

**算法流程：**
1. 使用二分查找，左边界 left = 0，右边界 right = n - 1
2. 每次取中点 mid，比较 `arr[mid]` 和 `arr[mid + 1]`
3. 根据比较结果调整搜索范围
4. 最终 left == right 时即为峰值

**为什么是 O(log n)？**
每次二分都将搜索范围缩小一半，所以时间复杂度是 O(log n)。

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public int peakIndexInMountainArray(int[] arr) {
        int left = 0, right = arr.length - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            // 如果 mid 处于上升阶段，峰值在右边
            if (arr[mid] < arr[mid + 1]) {
                left = mid + 1;
            } else {
                // mid 处于下降阶段或就是峰值，峰值在左边（包括 mid）
                right = mid;
            }
        }

        return left;
    }
}
```

**代码说明：**
- 比较 `arr[mid]` 和 `arr[mid + 1]` 判断上升或下降
- 上升阶段：峰值在右边，`left = mid + 1`
- 下降阶段：峰值在左边或就是 mid，`right = mid`
- 循环结束时 `left == right`，即为峰值

### 方法二：三分查找

```java
class Solution {
    public int peakIndexInMountainArray(int[] arr) {
        int left = 0, right = arr.length - 1;

        while (left < right) {
            int mid1 = left + (right - left) / 3;
            int mid2 = right - (right - left) / 3;

            if (arr[mid1] < arr[mid2]) {
                left = mid1 + 1;
            } else {
                right = mid2 - 1;
            }
        }

        return left;
    }
}
```

**代码说明：**
- 三分查找将区间分为三部分
- 每次排除 1/3 的区间
- 理论上略慢于二分，但也是 O(log n)

### 方法三：线性扫描（不推荐，不满足题目要求）

```java
class Solution {
    public int peakIndexInMountainArray(int[] arr) {
        // 找到第一个下降的位置
        for (int i = 0; i < arr.length - 1; i++) {
            if (arr[i] > arr[i + 1]) {
                return i;
            }
        }
        return arr.length - 1;
    }
}
```

**代码说明：**
- 简单直接，但时间复杂度 O(n)
- 不满足题目 O(log n) 的要求

## 复杂度分析

### 方法一：二分查找
- **时间复杂度**：O(log n)，每次减半搜索范围。
- **空间复杂度**：O(1)，只用了常数个变量。

### 方法二：三分查找
- **时间复杂度**：O(log₃ n) ≈ O(log n)，每次减少 1/3 搜索范围。
- **空间复杂度**：O(1)。

### 方法三：线性方法
- **时间复杂度**：O(n)，需要遍历数组。
- **空间复杂度**：O(1)。

## 图解示例

以 `arr = [0, 2, 5, 10, 8, 3, 1]` 为例：

```
索引：  0  1  2   3  4  5  6
数值：  0  2  5  10  8  3  1
              ↑ 峰值在索引 3

第一次二分：
left = 0, right = 6, mid = 3
arr[3] = 10 > arr[4] = 8  → 下降阶段，right = 3

第二次二分：
left = 0, right = 3, mid = 1
arr[1] = 2 < arr[2] = 5  → 上升阶段，left = 2

第三次二分：
left = 2, right = 3, mid = 2
arr[2] = 5 < arr[3] = 10  → 上升阶段，left = 3

left == right == 3，返回 3
```

## 关键点总结

1. **二分查找应用**：利用山脉数组的单峰性质进行二分
2. **比较策略**：通过 `arr[mid]` 和 `arr[mid + 1]` 的大小关系判断方向
3. **边界处理**：`right = mid` 而不是 `mid - 1`，因为 mid 可能就是峰值
4. **循环条件**：`while (left < right)`，结束时 `left == right`
5. **时间优化**：从 O(n) 优化到 O(log n)

## 易错点

1. **边界更新错误**：
   ```java
   // 错误：可能跳过峰值
   if (arr[mid] > arr[mid + 1]) right = mid - 1;
   
   // 正确：保留 mid 作为候选
   if (arr[mid] > arr[mid + 1]) right = mid;
   ```

2. **比较对象错误**：应该比较 `arr[mid]` 和 `arr[mid + 1]`，而不是 `arr[mid - 1]` 和 `arr[mid]`

3. **数组越界**：当 `mid = arr.length - 1` 时，`arr[mid + 1]` 会越界
   - 解决方法：确保 `right` 初始化为 `arr.length - 1`，这样 mid 不会取到最后一个元素

4. **循环条件**：使用 `while (left < right)` 而不是 `while (left <= right)`
