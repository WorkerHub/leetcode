## 题目描述

等差数列中缺失一个数字（非首尾），找出并返回该数字。

**示例：**
```
输入：arr = [5,7,11,13]
输出：9（原数列 [5,7,9,11,13]）
```

## 解题思路

方法一：求和法，期望和 - 实际和 = 缺失值。方法二：根据首尾计算期望公差，找到不满足公差的位置。

## Java 代码实现

### 方法一：求和法（推荐）

```java
class Solution {
    public int missingNumber(int[] arr) {
        int n = arr.length;
        // 期望公差（包含缺失数后共 n+1 个数）
        int expectedSum = (arr[0] + arr[n - 1]) * (n + 1) / 2;
        int actualSum = 0;
        for (int num : arr) actualSum += num;
        return expectedSum - actualSum;
    }
}
```

### 方法二：遍历查找

```java
class Solution {
    public int missingNumber(int[] arr) {
        int n = arr.length;
        // 期望公差
        int diff = (arr[n - 1] - arr[0]) / n;
        for (int i = 1; i < n; i++) {
            if (arr[i] - arr[i - 1] != diff) {
                return arr[i - 1] + diff;
            }
        }
        return arr[0]; // 无缺失（diff=0 的情况）
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **求和法**：等差数列求和公式 (首+尾)×项数/2
2. **期望公差**：diff = (arr[n-1] - arr[0]) / n（n 是当前数组长度）
3. **特殊情况**：公差为 0 时所有数相同，无缺失
