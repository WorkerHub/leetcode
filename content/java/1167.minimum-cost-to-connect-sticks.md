## 题目描述

将所有木棍连接成一根，每次连接两根长度为 x 和 y 的木棍花费 x+y。返回最小总花费。

**示例：**
```
输入：sticks = [2,4,3]
输出：14（连接2+3=5花费5，连接5+4=9花费9，总14）
```

## 解题思路

贪心 + 最小堆：每次取两根最短的连接（哈夫曼编码思想），短的先连花费的累加次数最少。

## Java 代码实现

```java
class Solution {
    public int connectSticks(int[] sticks) {
        if (sticks.length <= 1) return 0;

        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for (int s : sticks) pq.offer(s);

        int totalCost = 0;
        while (pq.size() > 1) {
            int combined = pq.poll() + pq.poll();
            totalCost += combined;
            pq.offer(combined);
        }
        return totalCost;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，n-1 次堆操作
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：每次取最短两根连接
2. **最小堆**：高效获取最小元素
3. **连接后放回**：新木棍参与后续连接
4. **哈夫曼思想**：短的先合并，总成本最优
