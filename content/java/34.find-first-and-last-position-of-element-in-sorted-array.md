## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

**示例 2：**
```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

**示例 3：**
```
输入：nums = [], target = 0
输出：[-1,-1]
```

## 解题思路

### 核心思想：两次二分查找

要求 O(log n) 时间复杂度，必须使用二分查找。

**关键点：**
- 找左边界：找第一个等于 `target` 的位置
- 找右边界：找最后一个等于 `target` 的位置

**算法流程：**
1. 用二分查找找左边界
2. 用二分查找找右边界
3. 如果没找到，返回 `[-1, -1]`

## Java 代码实现

### 方法一：两次二分查找（标准解法）

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int leftPos = findLeft(nums, target);
        if (leftPos == -1) {
            return new int[]{-1, -1};
        }
        int rightPos = findRight(nums, target);
        return new int[]{leftPos, rightPos};
    }
    
    /** 找第一个等于target的位置 */
    private int findLeft(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                // nums[mid] >= target，继续向左找
                right = mid - 1;
            }
        }
        // 检查是否找到
        if (left < nums.length && nums[left] == target) {
            return left;
        }
        return -1;
    }
    
    /** 找最后一个等于target的位置 */
    private int findRight(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] <= target) {
                // nums[mid] <= target，继续向右找
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        // 检查是否找到
        if (right >= 0 && nums[right] == target) {
            return right;
        }
        return -1;
    }
}
```

### 方法二：简化版（统一模板）

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int leftPos = binarySearch(nums, target, true);
        if (leftPos == -1) {
            return new int[]{-1, -1};
        }
        int rightPos = binarySearch(nums, target, false);
        return new int[]{leftPos, rightPos};
    }
    
    private int binarySearch(int[] nums, int target, boolean findLeft) {
        int left = 0, right = nums.length - 1;
        int result = -1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                result = mid;
                if (findLeft) {
                    // 找左边界，继续向左搜索
                    right = mid - 1;
                } else {
                    // 找右边界，继续向右搜索
                    left = mid + 1;
                }
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)，两次二分查找
- **空间复杂度**：O(1)，只使用常量额外空间

## 图解示例

### 示例：`nums = [5,7,7,8,8,10], target = 8`

**查找左边界：**
```
[5,7,7,8,8,10]
 ↑     ↑    ↑
left  mid right

nums[mid]=7 < 8, left = mid + 1

[5,7,7,8,8,10]
       ↑ ↑  ↑
     left mid right

nums[mid]=8 >= 8, right = mid - 1

[5,7,7,8,8,10]
       ↑↑
    right left

left=3, nums[3]=8，找到左边界 = 3
```

**查找右边界：**
```
[5,7,7,8,8,10]
 ↑     ↑    ↑
left  mid right

nums[mid]=7 <= 8, left = mid + 1

[5,7,7,8,8,10]
       ↑ ↑  ↑
     left mid right

nums[mid]=8 <= 8, left = mid + 1

[5,7,7,8,8,10]
         ↑ ↑
      right left

right=4, nums[4]=8，找到右边界 = 4
```

结果：`[3, 4]`

## 关键点总结

1. **找左边界**：
   - 当 `nums[mid] >= target` 时，`right = mid - 1`
   - 最后检查 `nums[left]` 是否等于 `target`

2. **找右边界**：
   - 当 `nums[mid] <= target` 时，`left = mid + 1`
   - 最后检查 `nums[right]` 是否等于 `target`

3. **优化**：
   - 先找左边界，如果找不到，直接返回 `[-1, -1]`
   - 省去一次二分查找

4. **边界检查**：
   - 找左边界后检查 `left < nums.length`
   - 找右边界后检查 `right >= 0`

## 易错点

1. **循环结束后的检查**：
   - 找左边界：检查 `nums[left] == target`
   - 找右边界：检查 `nums[right] == target`
   - 不要忘记边界检查

2. **更新条件**：
   - 找左边界：`nums[mid] >= target` 时 `right = mid - 1`
   - 找右边界：`nums[mid] <= target` 时 `left = mid + 1`

3. **Java 数组初始化**：
   - 返回 `new int[]{-1, -1}` 而不是 Python 的列表

## 二分查找的四种模板

| 目标 | 条件 | 返回 | 检查 |
|------|------|------|------|
| 找第一个等于target | `nums[mid] >= target` 时 `right=mid-1` | `left` | `nums[left]==target` |
| 找最后一个等于target | `nums[mid] <= target` 时 `left=mid+1` | `right` | `nums[right]==target` |
| 找第一个大于target | `nums[mid] > target` 时 `right=mid-1` | `left` | - |
| 找最后一个小于target | `nums[mid] < target` 时 `left=mid+1` | `right` | - |
