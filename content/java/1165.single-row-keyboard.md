## 题目描述

单行键盘 keyboard（26个不同字母的排列），手指初始在索引 0。输入 word 需要的总移动时间（每次移动 |i-j|）。

**示例：**
```
输入：keyboard = "abcdefghijklmnopqrstuvwxyz", word = "cba"
输出：4（0→2 + 2→1 + 1→0 = 2+1+1）
```

## 解题思路

用数组记录每个字符在键盘上的位置，遍历 word 累加移动距离。

## Java 代码实现

```java
class Solution {
    public int calculateTime(String keyboard, String word) {
        // 字符到位置的映射
        int[] pos = new int[26];
        for (int i = 0; i < 26; i++) {
            pos[keyboard.charAt(i) - 'a'] = i;
        }

        int total = 0, cur = 0;
        for (char c : word.toCharArray()) {
            int target = pos[c - 'a'];
            total += Math.abs(cur - target);
            cur = target;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 word 长度
- **空间复杂度**：O(1)，固定大小 26 的数组

## 关键点总结

1. **预处理位置**：int[26] 存储每个字符的键盘索引
2. **维护当前位置**：每次移动后更新 cur
3. **绝对值距离**：|cur - target|
4. **初始位置为 0**
