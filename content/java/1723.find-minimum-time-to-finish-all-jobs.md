## 题目描述

给你整数数组 `jobs` 和整数 `k`（工人数），每名工人最多只能做两项工作。返回工人最大工作时间的**最小值**。

**示例：** `jobs = [1,2,4,7,8], k = 2` → 输出 `11`

## 解题思路

**状态压缩 DP**：用位掩码表示已分配工作子集，`dp[mask]` 表示用若干工人分配 `mask` 中工作时最大工作时间的最小值。枚举 `mask` 的补集子集分配给新工人，滚动更新 k 轮。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumTimeRequired(int[] jobs, int k) {
        int n = jobs.length;
        int totalMasks = 1 << n;

        // 预计算每个子集的工作时间总和
        int[] subsetSum = new int[totalMasks];
        for (int mask = 1; mask < totalMasks; mask++) {
            int lsb = mask & (-mask); // 最低位的 1
            int bit = Integer.numberOfTrailingZeros(lsb);
            subsetSum[mask] = subsetSum[mask ^ lsb] + jobs[bit];
        }

        // dp[mask] = 分配 mask 中工作时，最大工作时间的最小值
        int[] dp = new int[totalMasks];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int j = 0; j < k; j++) {
            // 每轮代表多一个工人，从后向前遍历防止重复
            int[] newDp = Arrays.copyOf(dp, totalMasks);
            for (int mask = 0; mask < totalMasks; mask++) {
                if (dp[mask] == Integer.MAX_VALUE) continue;
                // 枚举 mask 补集的所有子集
                int remaining = (totalMasks - 1) ^ mask;
                for (int sub = remaining; sub > 0; sub = (sub - 1) & remaining) {
                    int newMask = mask | sub;
                    int cost = Math.max(dp[mask], subsetSum[sub]);
                    newDp[newMask] = Math.min(newDp[newMask], cost);
                }
            }
            dp = newDp;
        }

        return dp[totalMasks - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k * 3^n)，枚举所有子集的子集
- **空间复杂度**：O(2^n)

## 关键点总结

1. 子集枚举：`sub = (sub - 1) & remaining` 遍历补集的所有子集
2. 滚动数组：每轮新建 `newDp` 避免同一工人重复使用
3. 预计算子集和减少重复计算
