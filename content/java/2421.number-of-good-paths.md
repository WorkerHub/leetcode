## 题目描述

给你一棵 `n` 个节点的树和每个节点的值数组 `vals`，返回**好路径**的数目（好路径两端节点值相同，且路径上所有节点值不超过端点值；单节点也算好路径）。

## 解题思路

并查集 + 按值排序：将边按两端节点的最大值排序，逐步加入。处理值 `v` 时，将所有值 `<= v` 的相邻节点合并。统计同一连通分量中值为 `v` 的节点数 `cnt`，累加 `cnt*(cnt-1)/2` 个好路径。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private int[] parent, rank;

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) { int t = px; px = py; py = t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }

    public int numberOfGoodPaths(int[] vals, int[][] edges) {
        int n = vals.length;
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        // 建立邻接表
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        // 按节点值分组
        Map<Integer, List<Integer>> valToNodes = new TreeMap<>();
        for (int i = 0; i < n; i++) {
            valToNodes.computeIfAbsent(vals[i], k -> new ArrayList<>()).add(i);
        }

        boolean[] activated = new boolean[n];
        int ans = n; // 每个单节点本身是好路径

        for (Map.Entry<Integer, List<Integer>> entry : valToNodes.entrySet()) {
            List<Integer> nodes = entry.getValue();
            // 激活当前值的节点，连接已激活的相邻节点
            for (int node : nodes) {
                activated[node] = true;
                for (int neighbor : adj.get(node)) {
                    if (activated[neighbor]) {
                        union(node, neighbor);
                    }
                }
            }
            // 统计同一连通分量中值相同的节点数量
            Map<Integer, Integer> rootCount = new HashMap<>();
            for (int node : nodes) {
                int root = find(node);
                rootCount.merge(root, 1, Integer::sum);
            }
            // 每组 cnt 个同值节点，好路径数为 C(cnt, 2)
            for (int cnt : rootCount.values()) {
                ans += cnt * (cnt - 1) / 2;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n × α(n))，排序 + 并查集
- **空间复杂度**：O(n)

## 关键点总结

1. 按节点值从小到大处理，保证连通分量内只有 `<= v` 的节点
2. 同一连通分量中值等于 `v` 的节点两两构成好路径
3. 使用 `TreeMap` 自动按值排序
