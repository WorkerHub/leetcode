## 题目描述

给你整数数组 nums，返回所有子数组的不同元素计数的平方和。数组长度 ≤ 100。

## 解题思路

数据范围小，枚举所有起点 l，右端点 r 从 l 向右扩展时用集合增量维护不同元素个数，直接累加平方值。

## Java 代码实现

```java
class Solution {
    public int sumCounts(int[] nums) {
        int n = nums.length;
        long ans = 0;
        for (int l = 0; l < n; l++) {
            Set<Integer> seen = new HashSet<>();
            for (int r = l; r < n; r++) {
                seen.add(nums[r]); // 增量更新，O(1)
                long d = seen.size();
                ans += d * d;
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，枚举所有子数组
- **空间复杂度**：O(n)，集合最多存 n 个元素

## 关键点总结

1. 固定左端点 l，右端点 r 向右扩展时增量更新集合，每次 O(1)
2. 平方和直接累加，无需额外处理
3. n ≤ 100 时 O(n²) 完全可接受
