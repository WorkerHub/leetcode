## 题目描述

给定已排序的循环链表和待插入值 `insertVal`，将其插入后链表仍保持有序，返回任意节点引用。

## Java 代码实现

```java
class Solution {
    public Node insert(Node head, int insertVal) {
        Node newNode = new Node(insertVal);
        // 空链表，创建自环
        if (head == null) {
            newNode.next = newNode;
            return newNode;
        }

        Node curr = head;
        while (true) {
            // 情况 1：普通插入，在 curr 和 curr.next 之间
            if (curr.val <= insertVal && insertVal <= curr.next.val) break;
            // 情况 2：断点处（curr 是最大值节点），insertVal 超出最大或小于最小
            if (curr.val > curr.next.val) {
                if (insertVal >= curr.val || insertVal <= curr.next.val) break;
            }
            curr = curr.next;
            // 情况 3：绕一圈，直接插入（所有值相同）
            if (curr == head) break;
        }

        newNode.next = curr.next;
        curr.next = newNode;
        return head;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 三种插入情况：普通位置、断点处（最大到最小的跳变）、全相同绕一圈
2. 断点处 `curr.val > curr.next.val`，insertVal 大于最大值或小于最小值时在此插入
3. 绕一圈未找到时直接在当前位置后插入
