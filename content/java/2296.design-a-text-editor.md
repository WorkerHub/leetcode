## 题目描述

设计文本编辑器，支持添加文本、删除光标左侧字符、左移/右移光标，返回光标左侧最多10个字符。

## 解题思路

双栈模拟：左栈存光标左侧字符，右栈存光标右侧字符。添加压左栈，删除弹左栈，左移弹左压右，右移弹右压左。

## Java 代码实现

```java
class TextEditor {
    private StringBuilder left;
    private StringBuilder right;

    public TextEditor() {
        left = new StringBuilder();
        right = new StringBuilder();
    }

    public void addText(String text) {
        left.append(text);
    }

    public int deleteText(int k) {
        int del = Math.min(k, left.length());
        left.delete(left.length() - del, left.length());
        return del;
    }

    public String cursorLeft(int k) {
        int move = Math.min(k, left.length());
        for (int i = 0; i < move; i++) {
            right.append(left.charAt(left.length() - 1));
            left.deleteCharAt(left.length() - 1);
        }
        return getLeftText();
    }

    public String cursorRight(int k) {
        int move = Math.min(k, right.length());
        for (int i = 0; i < move; i++) {
            left.append(right.charAt(right.length() - 1));
            right.deleteCharAt(right.length() - 1);
        }
        return getLeftText();
    }

    private String getLeftText() {
        int start = Math.max(0, left.length() - 10);
        return left.substring(start);
    }
}
```

## 复杂度分析

- **时间复杂度**：addText O(L)，deleteText O(k)，cursorLeft/Right O(k)
- **空间复杂度**：O(N)，N为总字符数

## 关键点总结

1. **双栈/双StringBuilder**：光标左右各一个
2. **右栈反序存储**：末尾即光标相邻字符
3. **返回左侧最多10字符**：substring截取
