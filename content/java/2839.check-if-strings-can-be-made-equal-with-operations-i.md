## 题目描述

长度4的字符串，可交换下标0和2或下标1和3，判断s1能否变为s2。

## 解题思路

偶数位(0,2)可互换，奇数位(1,3)可互换。分别比较两组字符的多重集是否相同。

## Java 代码实现

```java
class Solution {
    public boolean canBeEqual(String s1, String s2) {
        // 偶数位字符排序后相同
        char[] even1 = {s1.charAt(0), s1.charAt(2)};
        char[] even2 = {s2.charAt(0), s2.charAt(2)};
        Arrays.sort(even1);
        Arrays.sort(even2);
        // 奇数位字符排序后相同
        char[] odd1 = {s1.charAt(1), s1.charAt(3)};
        char[] odd2 = {s2.charAt(1), s2.charAt(3)};
        Arrays.sort(odd1);
        Arrays.sort(odd2);
        return Arrays.equals(even1, even2) && Arrays.equals(odd1, odd2);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **操作只能在同奇偶位之间交换**
2. **判断偶数位和奇数位字符集分别相同**
3. **用排序比较多重集**
