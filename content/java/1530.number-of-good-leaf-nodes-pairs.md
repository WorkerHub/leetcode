## 题目描述

二叉树中，两个叶节点最短路径 ≤ distance 为一组好叶子节点对。返回好对数。

**示例：**
```
输入：root = [1,2,3,4,5,6,7], distance = 3
输出：2
```

## 解题思路

DFS 后序：每个节点返回到各叶子的距离列表，内部节点用左右子树的距离列表两两比较统计。

## Java 代码实现

```java
class Solution {
    private int count = 0;
    
    public int countPairs(TreeNode root, int distance) {
        dfs(root, distance);
        return count;
    }
    
    private List<Integer> dfs(TreeNode node, int distance) {
        if (node == null) return new ArrayList<>();
        if (node.left == null && node.right == null) {
            List<Integer> list = new ArrayList<>();
            list.add(0);
            return list;
        }
        
        List<Integer> left = dfs(node.left, distance);
        List<Integer> right = dfs(node.right, distance);
        
        // 统计好对
        for (int l : left) {
            for (int r : right) {
                if (l + r + 2 <= distance) count++;
            }
        }
        
        // 向上传递，距离 +1
        List<Integer> result = new ArrayList<>();
        for (int l : left) if (l + 1 < distance) result.add(l + 1);
        for (int r : right) if (r + 1 < distance) result.add(r + 1);
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × distance²)
- **空间复杂度**：O(n × distance)

## 关键点总结

1. **后序遍历**：先处理子树再合并
2. **距离列表**：每个节点返回到叶子的距离
3. **两两配对**：左右子树距离之和 +2 ≤ distance
4. **剪枝**：距离 ≥ distance 的不再向上传递
