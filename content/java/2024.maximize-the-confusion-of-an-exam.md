## 题目描述

给定答案字符串 `answerKey`（只含 T/F）和整数 `k`，最多改变 k 个答案，返回最长连续相同子字符串的长度。

## 解题思路

分别对 T 和 F 各运行一次滑动窗口：维护窗口使窗口内目标字符（需要改变的）数量 <= k，更新最大窗口长度，取两种情况的最大值。

## Java 代码实现

### 方法一：滑动窗口（推荐）

```java
class Solution {
    public int maxConsecutiveAnswers(String answerKey, int k) {
        return Math.max(maxWindow(answerKey, k, 'T'), maxWindow(answerKey, k, 'F'));
    }

    // 最多改变k个字符c，返回最长连续相同子串长度
    private int maxWindow(String s, int k, char c) {
        int left = 0, changeCount = 0, maxLen = 0;
        for (int right = 0; right < s.length(); right++) {
            if (s.charAt(right) == c) changeCount++; // 需要改变的字符数
            while (changeCount > k) {
                if (s.charAt(left) == c) changeCount--;
                left++;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 分别对"全部变为 T"和"全部变为 F"各运行一次滑动窗口
2. 计数的是需要改变的字符数（少数字符），超过 k 时收缩左边界
3. 两种情况取最大值
