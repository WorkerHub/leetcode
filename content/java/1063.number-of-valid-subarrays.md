## 题目描述

返回非空子数组数量，使得最左侧元素不大于子数组中其他元素。

**示例：**
```
输入：nums = [1,4,2,5,3]
输出：11
```

## 解题思路

单调栈：对每个位置 i，找右侧第一个小于 nums[i] 的位置 j，以 i 开头的有效子数组有 j-i 个。

## Java 代码实现

```java
class Solution {
    public int validSubarrays(int[] nums) {
        int n = nums.length;
        int result = 0;
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 弹出所有大于当前元素的栈顶（它们的右边界找到了）
            while (!stack.isEmpty() && nums[stack.peek()] > nums[i]) {
                result += i - stack.pop();
            }
            stack.push(i);
        }

        // 处理栈中剩余元素（右边界为数组末尾）
        while (!stack.isEmpty()) {
            result += n - stack.pop();
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **单调栈**：维护递增栈，找"下一个更小元素"
2. **贡献计算**：每个位置 i 贡献 (右边界 - i) 个有效子数组
3. **剩余处理**：栈中剩余元素的右边界是 n
