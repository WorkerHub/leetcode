## 题目描述

给你内存需求数组 `nums` 和最多调整次数 `k`，每段内存块固定为该段最大值，返回最少总浪费内存量。

## 解题思路

DP：`dp[r][j]` 为处理完前 r+1 个元素且已调整 j 次的最小浪费。区间 `[l,r]` 的浪费量为 `max(nums[l..r]) * (r-l+1) - sum(nums[l..r])`，预计算后转移。

## Java 代码实现

```java
class Solution {
    public int minSpaceWastedKResizing(int[] nums, int k) {
        int n = nums.length;
        int INF = Integer.MAX_VALUE / 2;
        // 预计算区间浪费量
        int[][] waste = new int[n][n];
        for (int l = 0; l < n; l++) {
            int maxVal = 0, total = 0;
            for (int r = l; r < n; r++) {
                maxVal = Math.max(maxVal, nums[r]);
                total += nums[r];
                waste[l][r] = maxVal * (r - l + 1) - total;
            }
        }
        // dp[r][j]
        int[][] dp = new int[n][k + 1];
        for (int[] row : dp) Arrays.fill(row, INF);
        for (int r = 0; r < n; r++) dp[r][0] = waste[0][r];

        for (int j = 1; j <= k; j++)
            for (int r = j; r < n; r++)
                for (int l = j; l <= r; l++)
                    if (dp[l - 1][j - 1] < INF)
                        dp[r][j] = Math.min(dp[r][j], dp[l - 1][j - 1] + waste[l][r]);

        int ans = INF;
        for (int v : dp[n - 1]) ans = Math.min(ans, v);
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² * k)
- **空间复杂度**：O(n * k)

## 关键点总结

1. 将数组分成 k+1 段，每段固定最大值
2. 区间浪费量 = 最大值 × 长度 - 段内总和
3. DP 转移枚举每段起始位置
