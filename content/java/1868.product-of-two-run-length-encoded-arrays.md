## 题目描述

给定两个游程编码(RLE)数组，返回按元素相乘后的RLE结果。

## 解题思路

双指针：每次取两段中较短的重叠部分，计算乘积，合并相邻相同乘积的段。

## Java 代码实现

```java
class Solution {
    public List<List<Integer>> findRLEArray(int[][] encoded1, int[][] encoded2) {
        List<List<Integer>> result = new ArrayList<>();
        int i = 0, j = 0;
        
        while (i < encoded1.length && j < encoded2.length) {
            int val1 = encoded1[i][0], freq1 = encoded1[i][1];
            int val2 = encoded2[j][0], freq2 = encoded2[j][1];
            
            int overlap = Math.min(freq1, freq2);
            int product = val1 * val2;
            
            // 合并相邻相同乘积
            if (!result.isEmpty() && result.get(result.size() - 1).get(0) == product) {
                result.get(result.size() - 1).set(1, 
                    result.get(result.size() - 1).get(1) + overlap);
            } else {
                result.add(new ArrayList<>(Arrays.asList(product, overlap)));
            }
            
            encoded1[i][1] -= overlap;
            encoded2[j][1] -= overlap;
            if (encoded1[i][1] == 0) i++;
            if (encoded2[j][1] == 0) j++;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)
- **空间复杂度**：O(M + N)

## 关键点总结

1. **双指针同步**：每次处理两段重叠部分
2. **合并相邻段**：乘积相同的连续段合并
3. **频率递减**：处理完overlap后减去对应频率
