## 题目描述

给你一个数组 `nums`，数组中有 `2n` 个元素，按 `[x1, x2, ..., xn, y1, y2, ..., yn]` 的格式排列。

请你将数组按 `[x1, y1, x2, y2, ..., xn, yn]` 格式重新排列，返回重排后的数组。

**示例 1：**

```
输入：nums = [2,5,1,3,4,7], n = 3
输出：[2,3,5,4,1,7]
解释：由于 x1=2, x2=5, x3=1, y1=3, y2=4, y3=7，
     所以答案为 [2,3,5,4,1,7]
```

**示例 2：**

```
输入：nums = [1,2,3,4,4,3,2,1], n = 4
输出：[1,4,2,3,3,2,4,1]
```

**示例 3：**

```
输入：nums = [1,1,2,2], n = 2
输出：[1,2,1,2]
```

**提示：**
- `1 <= n <= 500`
- `nums.length == 2n`
- `1 <= nums[i] <= 10^3`

## 解题思路

**核心思想：** 前半部分是 x 序列（索引 0 到 n-1），后半部分是 y 序列（索引 n 到 2n-1）。交错合并两个序列即可。

**具体方法：**
- 对于 `i` 从 0 到 n-1，依次取 `nums[i]`（x 序列）和 `nums[i+n]`（y 序列）。

## Java 代码实现

### 方法一：普通循环（推荐）

```java
class Solution {
    public int[] shuffle(int[] nums, int n) {
        int[] result = new int[2 * n];
        for (int i = 0; i < n; i++) {
            result[2 * i] = nums[i];       // 取 x[i]
            result[2 * i + 1] = nums[i + n]; // 取 y[i]
        }
        return result;
    }
}
```

### 方法二：ArrayList 拼接

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] shuffle(int[] nums, int n) {
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            result.add(nums[i]);       // 取 x[i]
            result.add(nums[i + n]);   // 取 y[i]
        }
        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

### 方法三：原地位操作（进阶，O(1) 额外空间）

```java
class Solution {
    public int[] shuffle(int[] nums, int n) {
        // 利用 nums[i] <= 1000 < 1024 = 2^10
        // 将新旧值都存在一个数组槽中：低 10 位存原始值，高 10 位存新值
        // 最终只取高 10 位
        for (int i = 0; i < n; i++) {
            // 新数组中，位置 2i 放 nums[i]，位置 2i+1 放 nums[i+n]
            // 将新值（高 10 位）写入对应位置
            nums[2 * i] |= (nums[i] & 1023) << 10;
            nums[2 * i + 1] |= (nums[i + n] & 1023) << 10;
        }
        // 右移 10 位，取出高 10 位的新值
        for (int i = 0; i < 2 * n; i++) {
            nums[i] >>= 10;
        }
        return nums;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 普通循环 | O(n) | O(n) |
| ArrayList | O(n) | O(n) |
| 原地位操作 | O(n) | O(1) |

- **时间复杂度 O(n)**：遍历 n 对元素。
- **空间复杂度 O(n)**：结果数组长度为 2n（方法三除外）。

## 关键点总结

1. 数组前半部分是 x 序列（索引 `[0, n)`），后半部分是 y 序列（索引 `[n, 2n)`）。
2. 交错合并：第 `i` 对元素是 `nums[i]` 和 `nums[i+n]`，放置到 `result[2i]` 和 `result[2i+1]`。
3. Java 数组下标计算：`result[2*i]` 和 `result[2*i+1]` 存放第 i 对。

## 易错点

- **下标偏移错误**：y 序列的起始索引是 `n` 而不是 `n+1`。
- **结果数组大小**：结果数组长度为 `2*n`，而不是 `n`。
