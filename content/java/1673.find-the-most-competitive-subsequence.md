## 题目描述

给你整数数组 `nums` 和正整数 `k`，返回最具**竞争力**（字典序最小）的 k 个元素子序列。

## 解题思路

**单调栈（贪心）：** 维护单调递增栈（长度不超过 k）。当当前元素 < 栈顶且后面还有足够元素时，弹出栈顶，然后压入当前元素。

## Java 代码实现

```java
class Solution {
    public int[] mostCompetitive(int[] nums, int k) {
        int n = nums.length;
        int[] stack = new int[k];
        int top = 0; // 栈顶指针

        for (int i = 0; i < n; i++) {
            // 弹出条件：当前元素更小 + 后面还有足够元素
            while (top > 0 && nums[i] < stack[top - 1] && top + (n - i) > k) {
                top--;
            }
            if (top < k) {
                stack[top++] = nums[i];
            }
        }

        return stack;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. 单调递增栈：维护当前最具竞争力的子序列
2. 弹出条件：`top + (n - i) > k`（弹出后还能凑够 k 个）
3. 压栈条件：`top < k`
