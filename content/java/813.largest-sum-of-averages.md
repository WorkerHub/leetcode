## 题目描述

给定数组 `nums` 和一个整数 `k`。我们将给定的数组 `nums` 分成 **最多** `k` 个非空子数组，使得它们的每个子数组的平均值之和最大。

返回这个最大的平均值之和。误差在 `10^-6` 内的答案将被视为正确答案。

**示例 1:**
```
输入: nums = [9,1,2,3,9], k = 3
输出: 20.00000
解释: 最优分割是 [9], [1, 2, 3], [9]。平均值和为 9 + 2 + 9 = 20。
```

**示例 2:**
```
输入: nums = [1,2,3,4,5,6,7], k = 4
输出: 20.50000
```

**提示:**
- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

使用动态规划。`dp[i][k]` 表示前 `i` 个数分成 `k` 组的最大平均值和。

**状态转移：**
```
dp[i][k] = max(dp[j][k-1] + avg(j+1, i)) for all j < i
```

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public double largestSumOfAverages(int[] nums, int k) {
        int n = nums.length;

        // 前缀和，方便计算子数组平均值
        double[] prefix = new double[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        // dp[i][groups] 表示前 i 个数分成 groups 组的最大平均值和
        double[][] dp = new double[n + 1][k + 1];

        // 初始化：每个数自成一组
        for (int i = 1; i <= n; i++) {
            dp[i][1] = prefix[i] / i;
        }

        // 状态转移
        for (int groups = 2; groups <= k; groups++) {
            for (int i = groups; i <= n; i++) {
                for (int j = groups - 1; j < i; j++) {
                    // 前 j 个数分成 groups-1 组，再加上 j+1 到 i 的平均值
                    double avg = (prefix[i] - prefix[j]) / (i - j);
                    dp[i][groups] = Math.max(dp[i][groups], dp[j][groups - 1] + avg);
                }
            }
        }

        return dp[n][k];
    }
}
```

### 方法二：记忆化递归

```java
import java.util.*;

class Solution {
    double[] prefix;
    double[][] memo;
    int n;

    public double largestSumOfAverages(int[] nums, int k) {
        n = nums.length;
        prefix = new double[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        memo = new double[n + 1][k + 1];
        return dp(n, k);
    }

    private double dp(int i, int groups) {
        if (groups == 1) {
            return prefix[i] / i;
        }

        if (memo[i][groups] != 0) {
            return memo[i][groups];
        }

        double maxSum = 0;
        for (int j = groups - 1; j < i; j++) {
            double avg = (prefix[i] - prefix[j]) / (i - j);
            maxSum = Math.max(maxSum, dp(j, groups - 1) + avg);
        }

        return memo[i][groups] = maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n × k)

## 关键点总结

1. **前缀和优化**：快速计算子数组和
2. **DP状态设计**：二维状态表示位置和组数
3. **枚举分割点**：最后一组从哪里开始

## 易错点

1. **平均值计算**：使用前缀和避免重复计算
2. **初始化**：第一组的情况要单独处理
3. **循环范围**：注意边界条件
