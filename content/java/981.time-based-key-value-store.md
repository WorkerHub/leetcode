## 题目描述

设计基于时间的键值存储结构，支持在不同时间戳存储同一键的多个值，并能根据时间戳检索值（返回 <= 给定时间戳的最新值）。

**示例：**
```
输入：set("foo", "bar", 1), get("foo", 1) -> "bar", get("foo", 3) -> "bar"
```

## 解题思路

HashMap + 二分查找：每个 key 存储按时间戳排序的 (timestamp, value) 列表，get 时二分查找 <= timestamp 的最大时间戳。

## Java 代码实现

```java
class TimeMap {
    private Map<String, List<int[]>> timeMap;
    private Map<String, List<String>> valueMap;

    public TimeMap() {
        timeMap = new HashMap<>();
        valueMap = new HashMap<>();
    }

    public void set(String key, String value, int timestamp) {
        timeMap.computeIfAbsent(key, k -> new ArrayList<>()).add(new int[]{timestamp});
        valueMap.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
    }

    public String get(String key, int timestamp) {
        if (!timeMap.containsKey(key)) return "";

        List<int[]> times = timeMap.get(key);
        List<String> values = valueMap.get(key);

        // 二分查找 <= timestamp 的最大时间戳
        int lo = 0, hi = times.size() - 1, ans = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (times.get(mid)[0] <= timestamp) {
                ans = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }

        return ans == -1 ? "" : values.get(ans);
    }
}
```

## 复杂度分析

- **时间复杂度**：set O(1)，get O(log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **二分查找**：找 <= timestamp 的最大值
2. **时间戳递增**：题目保证 set 的时间戳严格递增
3. **HashMap + List**：每个 key 维护有序列表
