## 题目描述

给你一个字符串 `n` 表示一个整数（可能为负数）以及整数 `x`，在 `n` 的某个位置插入 `x` 使结果最大，返回插入后的整数字符串。

## 解题思路

贪心：正数找第一个比 x 小的位置插入（使高位更大），负数找第一个比 x 大的位置插入（使绝对值更小）。

## Java 代码实现

```java
class Solution {
    public String maxValue(String n, int x) {
        boolean isNegative = n.charAt(0) == '-';
        String xStr = String.valueOf(x);
        int start = isNegative ? 1 : 0;

        for (int i = start; i < n.length(); i++) {
            char d = n.charAt(i);
            // 正数：找第一个比 x 小的位置；负数：找第一个比 x 大的位置
            if ((!isNegative && d < xStr.charAt(0)) || (isNegative && d > xStr.charAt(0))) {
                return n.substring(0, i) + xStr + n.substring(i);
            }
        }
        // 没找到，插入末尾
        return n + xStr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 正数：贪心在高位插入更大的数（找第一个比 x 小的位置）
2. 负数：贪心在高位插入更小的数（绝对值更小，整体更大）
