## 题目描述

给你整数数组 `nums` 和正整数 `k`。若长度为 `k` 的子数组元素连续且递增（差为 1），则其幂为最大值；否则为 `-1`。返回所有长度为 `k` 的子数组的幂。

## 解题思路

滑动窗口：维护以当前位置结尾的最长连续递增（步长 1）子数组长度 `cnt`。若 `cnt >= k`，则当前子数组的幂为 `nums[i]`，否则为 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] resultsArray(int[] nums, int k) {
        int n = nums.length;
        int[] ans = new int[n - k + 1];
        int cnt = 1; // 以当前位置结尾的最长连续递增长度

        for (int i = 0; i < n; i++) {
            // 更新连续递增长度
            if (i > 0 && nums[i] == nums[i - 1] + 1) {
                cnt++;
            } else {
                cnt = 1;
            }
            // 填充结果
            if (i >= k - 1) {
                ans[i - k + 1] = cnt >= k ? nums[i] : -1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（不含输出数组）

## 关键点总结

1. 维护以每个位置结尾的最长连续递增长度（步长恰好为 1）
2. 与前一位置差为 1 时长度加 1，否则重置为 1
3. 连续递增长度 >= k 时，子数组幂为最后一个元素
