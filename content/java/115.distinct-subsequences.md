## 题目描述

给定一个字符串 `s` 和一个字符串 `t`，计算在 `s` 的子序列中 `t` 出现的个数。

字符串的一个子序列是指，通过删除一些（也可以不删除）字符且不干扰剩余字符相对位置所组成的新字符串。（例如，`"ACE"` 是 `"ABCDE"` 的一个子序列，而 `"AEC"` 不是）

题目数据保证答案符合 32 位带符号整数范围。

**示例 1：**

```
输入：s = "rabbbit", t = "rabbit"
输出：3
解释：
如下所示，有 3 种可以从 s 中得到 "rabbit" 的方案。
rabbbit
rabbbit
rabbbit
```

**示例 2：**

```
输入：s = "babgbag", t = "bag"
输出：5
解释：
如下所示，有 5 种可以从 s 中得到 "bag" 的方案。
babgbag
babgbag
babgbag
babgbag
babgbag
```

**提示：**

- `1 <= s.length, t.length <= 1000`
- `s` 和 `t` 由英文字母组成

## 解题思路

这是一道经典的动态规划问题，需要统计字符串 `s` 的子序列中有多少个等于字符串 `t`。

**核心思想：**

1. 定义状态：`dp[i][j]` 表示 `s[0:i]` 的子序列中 `t[0:j]` 出现的个数
2. 状态转移：
   - 如果 `s[i-1] == t[j-1]`，有两种选择：
     - 使用 `s[i-1]` 匹配 `t[j-1]`：`dp[i-1][j-1]`
     - 不使用 `s[i-1]`：`dp[i-1][j]`
     - 因此：`dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`
   - 如果 `s[i-1] != t[j-1]`，只能不使用 `s[i-1]`：
     - `dp[i][j] = dp[i-1][j]`
3. 初始化：
   - `dp[i][0] = 1`（空字符串是任何字符串的子序列）
   - `dp[0][j] = 0`（`j > 0` 时，空字符串不包含非空字符串）

## Java 代码实现

### 方法一：二维动态规划（推荐）

```java
class Solution {
    public int numDistinct(String s, String t) {
        int m = s.length(), n = t.length();

        // 如果 t 比 s 长，不可能是子序列
        if (n > m) return 0;

        // dp[i][j] 表示 s[0:i] 的子序列中 t[0:j] 出现的个数
        int[][] dp = new int[m + 1][n + 1];

        // 初始化：空字符串是任何字符串的子序列
        for (int i = 0; i <= m; i++) {
            dp[i][0] = 1;
        }

        // 填充 DP 表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 不使用 s[i-1]
                dp[i][j] = dp[i-1][j];

                // 如果字符匹配，可以使用 s[i-1] 匹配 t[j-1]
                if (s.charAt(i-1) == t.charAt(j-1)) {
                    dp[i][j] += dp[i-1][j-1];
                }
            }
        }

        return dp[m][n];
    }
}
```

### 方法二：空间优化的一维动态规划

```java
class Solution {
    public int numDistinct(String s, String t) {
        int m = s.length(), n = t.length();

        if (n > m) return 0;

        // 使用一维数组，从后向前更新
        int[] dp = new int[n + 1];
        dp[0] = 1;  // 空字符串

        for (int i = 1; i <= m; i++) {
            // 从后向前更新，避免覆盖未使用的值
            for (int j = n; j >= 1; j--) {
                if (s.charAt(i-1) == t.charAt(j-1)) {
                    dp[j] += dp[j-1];
                }
            }
        }

        return dp[n];
    }
}
```

### 方法三：记忆化递归

```java
class Solution {
    private int[][] memo;
    private String s, t;

    public int numDistinct(String s, String t) {
        this.s = s;
        this.t = t;
        int m = s.length(), n = t.length();
        // 初始化为 -1 表示未计算
        memo = new int[m][n];
        for (int[] row : memo) Arrays.fill(row, -1);
        return dfs(0, 0);
    }

    private int dfs(int i, int j) {
        // t 已经匹配完成
        if (j == t.length()) return 1;

        // s 已经用完，但 t 还没匹配完
        if (i == s.length()) return 0;

        if (memo[i][j] != -1) return memo[i][j];

        // 不使用 s[i]
        int res = dfs(i + 1, j);

        // 如果字符匹配，可以使用 s[i]
        if (s.charAt(i) == t.charAt(j)) {
            res += dfs(i + 1, j + 1);
        }

        memo[i][j] = res;
        return res;
    }
}
```

## 复杂度分析

**方法一：二维 DP**
- 时间复杂度：O(m × n)，其中 m 和 n 分别是 s 和 t 的长度
- 空间复杂度：O(m × n)，需要二维 DP 表

**方法二：一维 DP**
- 时间复杂度：O(m × n)
- 空间复杂度：O(n)，只需要一维数组

**方法三：记忆化递归**
- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)，递归栈和缓存

## 关键点总结

1. **DP 定义**：`dp[i][j]` 表示 `s[0:i]` 的子序列中 `t[0:j]` 出现的个数
2. **状态转移**：字符匹配时累加两种情况（使用和不使用当前字符）
3. **初始化**：空字符串的处理很关键，`dp[i][0] = 1`
4. **优化技巧**：可以用一维数组优化空间，注意从后向前更新
5. **边界条件**：`t` 比 `s` 长时直接返回 0

## 易错点

1. **初始化错误**：忘记设置 `dp[i][0] = 1`，导致所有结果为 0
2. **状态转移理解**：字符匹配时是累加（`+=`）而不是赋值（`=`）
3. **一维优化方向**：必须从后向前更新，否则会覆盖还需要使用的值
4. **索引混淆**：`dp[i][j]` 对应的是 `s.charAt(i-1)` 和 `t.charAt(j-1)`
5. **边界判断**：没有处理 `t` 比 `s` 长的特殊情况
