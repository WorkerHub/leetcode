## 题目描述

两个非负整数，每步将较大的减去较小的，直到一个为0，求操作次数。

## 解题思路

类GCD优化：每次num1>=num2时批量减num1/num2次（取模），操作次数加num1/num2。

## Java 代码实现

```java
class Solution {
    public int countOperations(int num1, int num2) {
        int ops = 0;
        while (num1 != 0 && num2 != 0) {
            if (num1 >= num2) {
                ops += num1 / num2;
                num1 %= num2;
            } else {
                ops += num2 / num1;
                num2 %= num1;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log(min(num1, num2)))
- **空间复杂度**：O(1)

## 关键点总结

1. **类GCD算法**：批量减法等价于取模
2. **操作次数累加商**：num1/num2次减法合并为一步
3. **终止条件**：一个为0时停止
