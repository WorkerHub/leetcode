## 题目描述

连通无向图恰含一个环，求每个节点到环上最近节点的最短距离。

## 解题思路

拓扑排序剥叶：不断删除度为1的节点，剩余即为环。然后多源BFS从环上所有节点同时向外扩展计算距离。

## Java 代码实现

```java
class Solution {
    public int[] distanceToCycle(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        int[] degree = new int[n];
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
            degree[e[0]]++;
            degree[e[1]]++;
        }
        
        // 拓扑排序剥叶子
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (degree[i] == 1) queue.offer(i);
        }
        
        boolean[] inCycle = new boolean[n];
        Arrays.fill(inCycle, true);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            inCycle[u] = false;
            for (int v : graph.get(u)) {
                if (--degree[v] == 1) {
                    queue.offer(v);
                }
            }
        }
        
        // 多源BFS从环向外扩展
        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        Queue<Integer> bfs = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (inCycle[i]) {
                ans[i] = 0;
                bfs.offer(i);
            }
        }
        
        while (!bfs.isEmpty()) {
            int u = bfs.poll();
            for (int v : graph.get(u)) {
                if (ans[v] == -1) {
                    ans[v] = ans[u] + 1;
                    bfs.offer(v);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **拓扑排序识别环**：度为1的节点不断剥离，剩余即为环节点
2. **多源BFS**：所有环节点同时出发，保证每个节点获得最短距离
3. **图的性质**：n节点n条边连通图恰含一个环
