## 题目描述

给定一个含有 `n` 个正整数的数组和一个正整数 `target`。

找出该数组中满足其总和大于等于 `target` 的长度最小的 **连续子数组** `[numsl, numsl+1, ..., numsr-1, numsr]`，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

**示例 1：**
```
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。
```

**示例 2：**
```
输入：target = 4, nums = [1,4,4]
输出：1
```

**示例 3：**
```
输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0
```

**提示：**
- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

**进阶：**
- 如果你已经实现 `O(n)` 时间复杂度的解法，请尝试设计一个 `O(n log n)` 时间复杂度的解法。

## 解题思路

这道题是**滑动窗口**的经典应用。

### 问题特点

1. **连续子数组**：不能跳跃，必须连续
2. **正整数数组**：所有元素都是正数（关键！）
3. **和大于等于 target**：满足条件
4. **最小长度**：求最小值

### 方法演进

1. **暴力法**：枚举所有子数组 → O(n²)，会超时
2. **滑动窗口**：利用正整数特性，双指针 → O(n) ⭐
3. **前缀和 + 二分查找**：O(n log n)

### 核心思想：滑动窗口

**为什么可以用滑动窗口？**
- 数组元素都是正数
- 子数组越长，和越大；子数组越短，和越小
- 具有**单调性**，可以用双指针

**窗口调整规则**：
1. **扩展右边界**：当前和 < target，右指针右移，扩大窗口
2. **收缩左边界**：当前和 >= target，左指针右移，缩小窗口
3. **更新答案**：每次满足条件时，更新最小长度

## Java 代码实现

### 方法一：滑动窗口（推荐）⭐

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;  // 左指针
        int currentSum = 0;  // 当前窗口的和
        int minLen = Integer.MAX_VALUE;  // 最小长度，初始为最大值
        
        // 右指针遍历数组
        for (int right = 0; right < n; right++) {
            // 扩展窗口：加入右边界元素
            currentSum += nums[right];
            
            // 收缩窗口：当和 >= target 时，尝试缩小窗口
            while (currentSum >= target) {
                // 更新最小长度
                minLen = Math.min(minLen, right - left + 1);
                
                // 移除左边界元素，收缩窗口
                currentSum -= nums[left];
                left++;
            }
        }
        
        // 如果找到了答案，返回长度；否则返回 0
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

**代码说明**：
- **双指针**：left 和 right 构成滑动窗口
- **右指针遍历**：for 循环遍历右指针
- **左指针收缩**：while 循环移动左指针
- **时间复杂度**：O(n)，每个元素最多被访问两次（一次进窗口，一次出窗口）

**算法过程**（以 target = 7, nums = [2,3,1,2,4,3] 为例）：
```
初始：left=0, right=0, sum=0, minLen=MAX

right=0: sum=2, 不满足
right=1: sum=5, 不满足
right=2: sum=6, 不满足
right=3: sum=8 >= 7 ✓
  更新 minLen=4 (0到3)
  收缩：sum=6, left=1
  
right=4: sum=10 >= 7 ✓
  更新 minLen=4 (1到4)
  收缩：sum=7, left=2
  更新 minLen=3 (2到4)
  收缩：sum=6, left=3
  
right=5: sum=9 >= 7 ✓
  更新 minLen=3 (3到5)
  收缩：sum=7, left=4
  更新 minLen=2 (4到5) ← 最小值
  收缩：sum=3, left=5

结果：minLen = 2
```

### 方法二：滑动窗口（简化版）

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;
        int currentSum = 0;
        int minLen = n + 1;  // 用 n+1 表示未找到，避免 Integer.MAX_VALUE
        
        for (int right = 0; right < n; right++) {
            currentSum += nums[right];
            
            while (currentSum >= target) {
                minLen = Math.min(minLen, right - left + 1);
                currentSum -= nums[left];
                left++;
            }
        }
        
        return minLen <= n ? minLen : 0;
    }
}
```

**优化说明**：
- 用 `n + 1` 代替 `Integer.MAX_VALUE`，避免可能的数值问题
- 最后判断 `minLen <= n` 即可

### 方法三：前缀和 + 二分查找

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        
        // 构建前缀和数组
        int[] prefixSum = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefixSum[i + 1] = prefixSum[i] + nums[i];
        }
        
        // 如果总和都小于 target，返回 0
        if (prefixSum[n] < target) {
            return 0;
        }
        
        int minLen = n + 1;
        
        // 对每个起始位置，二分查找结束位置
        for (int i = 1; i <= n; i++) {
            // 寻找满足 prefixSum[j] - prefixSum[i-1] >= target 的最小 j
            // 即 prefixSum[j] >= target + prefixSum[i-1]
            int toFind = target + prefixSum[i - 1];
            
            // 二分查找
            int lo = i, hi = n;
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (prefixSum[mid] >= toFind) {
                    minLen = Math.min(minLen, mid - i + 1);
                    hi = mid - 1;
                } else {
                    lo = mid + 1;
                }
            }
        }
        
        return minLen <= n ? minLen : 0;
    }
}
```

**代码说明**：
- **前缀和**：prefixSum[i] 表示 nums[0..i-1] 的和
- **二分查找**：对每个起始位置，二分查找最小的结束位置
- **时间复杂度**：O(n log n)
- **注意**：Java 中用 `lo + (hi - lo) / 2` 防止溢出

**为什么可以二分？**
- 前缀和数组是单调递增的（元素都是正数）
- 可以用二分查找加速

### 方法四：暴力法（会超时，仅用于理解）

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int minLen = Integer.MAX_VALUE;
        
        // 枚举所有起始位置
        for (int i = 0; i < n; i++) {
            int currentSum = 0;
            // 枚举所有结束位置
            for (int j = i; j < n; j++) {
                currentSum += nums[j];
                // 如果满足条件，更新最小长度
                if (currentSum >= target) {
                    minLen = Math.min(minLen, j - i + 1);
                    break;  // 优化：找到即可跳出
                }
            }
        }
        
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

**时间复杂度**：O(n²)，会超时。

## 复杂度分析

### 方法一、二：滑动窗口
- **时间复杂度**：O(n)
  - 右指针遍历一次：O(n)
  - 左指针总共最多移动 n 次：O(n)
  - 总共：O(n)
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法三：前缀和 + 二分
- **时间复杂度**：O(n log n)
  - 构建前缀和：O(n)
  - n 次二分查找，每次 O(log n)：O(n log n)
- **空间复杂度**：O(n)，前缀和数组

### 方法四：暴力法
- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **滑动窗口适用条件**：数组元素都是正数，具有单调性
2. **双指针技巧**：右指针扩展，左指针收缩
3. **时间复杂度**：O(n)，每个元素最多进出窗口各一次
4. **边界情况**：无解时返回 0
5. **进阶方法**：前缀和 + 二分，O(n log n)
6. **Java 注意**：初始值用 `Integer.MAX_VALUE` 或 `n + 1`，二分防溢出用 `lo + (hi - lo) / 2`

## 易错点

1. **忘记检查无解情况**：
   - 数组总和都小于 target
   - 返回 0 而不是 `Integer.MAX_VALUE`

2. **窗口收缩条件**：
   - 用 `while` 而不是 `if`
   - 因为可能需要连续收缩多次

3. **最小长度初始化**：
   - 用 `Integer.MAX_VALUE` 或 `n + 1`
   - 不能用 0（会被最小值覆盖）

4. **边界计算错误**：
   - 长度是 `right - left + 1`
   - 不是 `right - left`

5. **误用滑动窗口**：
   - 如果数组有负数，不能用滑动窗口
   - 因为窗口扩大，和不一定增大

6. **二分溢出**：用 `lo + (hi - lo) / 2` 而非 `(lo + hi) / 2`
