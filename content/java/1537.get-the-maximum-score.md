## 题目描述

两个有序整数数组，从任一开头出发向右走，在公共元素处可切换数组。求经过数之和的最大值，结果对 10^9+7 取模。

**示例：**
```
输入：nums1 = [2,4,5,8,10], nums2 = [4,6,8,9]
输出：30
```

## 解题思路

双指针贪心：在公共元素之间分别累加两段和，到达公共元素时取较大段和加入答案。

## Java 代码实现

```java
class Solution {
    public int maxSum(int[] nums1, int[] nums2) {
        long MOD = 1_000_000_007;
        int i = 0, j = 0;
        long s1 = 0, s2 = 0, ans = 0;
        int n1 = nums1.length, n2 = nums2.length;
        
        while (i < n1 && j < n2) {
            if (nums1[i] < nums2[j]) {
                s1 += nums1[i++];
            } else if (nums1[i] > nums2[j]) {
                s2 += nums2[j++];
            } else {
                // 公共元素，取两段较大值
                ans += Math.max(s1, s2) + nums1[i];
                s1 = s2 = 0;
                i++;
                j++;
            }
        }
        // 处理剩余
        while (i < n1) s1 += nums1[i++];
        while (j < n2) s2 += nums2[j++];
        ans += Math.max(s1, s2);
        
        return (int)(ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针**：利用有序性找公共元素
2. **贪心选择**：每段取和更大的路径
3. **取模时机**：最后统一取模（用 long 防溢出）
4. **剩余处理**：末尾段也要取 max
