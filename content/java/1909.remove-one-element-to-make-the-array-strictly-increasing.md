## 题目描述

给你整数数组 `nums`，判断恰好删除一个元素后剩余元素能否构成严格递增数组（数组本身已严格递增也返回 true）。

## 解题思路

找到第一个违规位置 i（nums[i] >= nums[i+1]），只需验证删除 i 或删除 i+1 两种情况之一是否使数组严格递增。

## Java 代码实现

```java
class Solution {
    public boolean canBeIncreasing(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] >= nums[i + 1]) {
                // 尝试删除 i 或 i+1
                return isIncreasing(nums, i) || isIncreasing(nums, i + 1);
            }
        }
        return true; // 原数组已严格递增
    }

    // 跳过 skip 位置，检查剩余数组是否严格递增
    private boolean isIncreasing(int[] nums, int skip) {
        int prev = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (i == skip) continue;
            if (nums[i] <= prev) return false;
            prev = nums[i];
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 最多只有一个违规位置，找到后只需验证两种删除方案
2. 用 skip 参数跳过对应索引，无需真正删除元素
3. 原数组无违规位置直接返回 true
