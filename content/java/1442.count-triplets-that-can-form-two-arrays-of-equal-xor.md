## 题目描述

给你一个整数数组 `arr`。

现需要从数组中取三个下标 `i`、`j` 和 `k`，其中 `(0 <= i < j <= k < arr.length)`。

定义：
- `a = arr[i] XOR arr[i+1] XOR ... XOR arr[j-1]`
- `b = arr[j] XOR arr[j+1] XOR ... XOR arr[k]`

注意，当 `j == i + 1` 时，`a` 等于 `arr[i]`。

请返回能够令 `a == b` 成立的三元组 `(i, j, k)` 的数目。

**示例 1：**
```
输入：arr = [2,3,1,6,7]
输出：4
```

**示例 2：**
```
输入：arr = [1,1,1,1,1]
输出：10
```

**提示：**
- `1 <= arr.length <= 300`
- `1 <= arr[i] <= 10^8`

## 解题思路

**关键数学推导：**

若 `a == b`，则 `a XOR b == 0`。

而 `a XOR b = arr[i] XOR arr[i+1] XOR ... XOR arr[k]`（即 `i` 到 `k` 的全部元素的 XOR）。

所以条件等价于：**`arr[i] XOR arr[i+1] XOR ... XOR arr[k] == 0`**。

也就是说，对于任意满足 `prefix_xor[i] == prefix_xor[k+1]` 的一对 `(i, k+1)`，区间 `[i, k]` 内的 XOR 为 0，`j` 可以是 `[i+1, k]` 中的任意值，共有 `k - i` 种选择。

**算法：**
1. 计算前缀 XOR 数组 `prefix`，其中 `prefix[i] = arr[0] XOR ... XOR arr[i-1]`。
2. 对所有 `i < k+1` 且 `prefix[i] == prefix[k+1]` 的对，贡献 `k - i` 个三元组。

## Java 代码实现

### 方法一：暴力枚举（O(n³)，用于理解）

```java
class Solution {
    public int countTriplets(int[] arr) {
        int n = arr.length;
        int count = 0;

        for (int i = 0; i < n; i++) {
            for (int k = i + 1; k < n; k++) {
                // 计算 arr[i..k] 的总 XOR
                int xorTotal = 0;
                for (int x = i; x <= k; x++) {
                    xorTotal ^= arr[x];
                }

                // 若总 XOR 为 0，则 j 可以是 i+1 到 k 中的任意值
                if (xorTotal == 0) {
                    count += k - i;  // j 的选择数量为 k - i
                }
            }
        }

        return count;
    }
}
```

### 方法二：前缀 XOR + O(n²) 枚举（推荐）

```java
class Solution {
    public int countTriplets(int[] arr) {
        int n = arr.length;
        // 构建前缀 XOR，prefix[i] = arr[0] XOR ... XOR arr[i-1]
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] ^ arr[i];
        }

        int count = 0;
        // 枚举 i 和 k，注意 i < k（j 至少有一个选择）
        for (int i = 0; i < n; i++) {
            for (int k = i + 1; k < n; k++) {
                // arr[i..k] 的 XOR = prefix[k+1] XOR prefix[i]
                if (prefix[k + 1] == prefix[i]) {
                    // j 可以是 i+1 到 k，共 k-i 种
                    count += k - i;
                }
            }
        }

        return count;
    }
}
```

### 方法三：哈希表优化（O(n)）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countTriplets(int[] arr) {
        // 哈希表记录每个前缀 XOR 值出现的下标和频次
        Map<Integer, Integer> countMap = new HashMap<>();  // 前缀 XOR -> 出现次数
        Map<Integer, Integer> indexMap = new HashMap<>();  // 前缀 XOR -> 出现下标之和

        countMap.put(0, 1);  // prefix[0] = 0，出现 1 次
        indexMap.put(0, 0);  // 下标 0

        int prefix = 0;
        int result = 0;

        for (int k = 0; k < arr.length; k++) {
            prefix ^= arr[k];
            int cur = k + 1;  // 当前前缀 XOR 的下标（prefix[k+1]）

            // 找所有 prefix[i] == prefix[k+1] 的 i（i < cur）
            // 贡献为 sum(cur - 1 - i) = 频次 * (cur-1) - 下标之和
            if (countMap.containsKey(prefix)) {
                result += countMap.get(prefix) * (cur - 1) - indexMap.get(prefix);
            }

            countMap.merge(prefix, 1, Integer::sum);
            indexMap.merge(prefix, cur, Integer::sum);
        }

        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 方法一（暴力） | O(n³) | O(1) |
| 方法二（前缀XOR） | O(n²) | O(n) |
| 方法三（哈希表） | O(n) | O(n) |

## 图解示例

```
arr = [2,3,1,6,7]
前缀 XOR：prefix = [0, 2, 1, 0, 6, 1]
                    0  1  2  3  4  5

找所有 i < k+1 使得 prefix[i] == prefix[k+1]：
  prefix[0]=0, prefix[3]=0 → i=0, k+1=3, k=2，贡献 2-0=2
  prefix[2]=1, prefix[5]=1 → i=2, k+1=5, k=4，贡献 4-2=2

总计：2 + 2 = 4，答案正确！
```

## 关键点总结

1. 核心数学：`a == b` 等价于 `a XOR b == 0`，等价于区间 `[i, k]` 的总 XOR 为 0。
2. 前缀 XOR：`xor(i, k) = prefix[k+1] XOR prefix[i]`，O(1) 查询区间 XOR。
3. `j` 的贡献：一旦确定 `(i, k)` 满足条件，`j` 有 `k - i` 种选择。
4. 哈希表优化：记录每个前缀 XOR 出现的下标和，一次遍历 O(n)。

## 易错点

- 混淆 `j` 的范围：`j` 从 `i+1` 到 `k`（含 k），共 `k - i` 种（不是 `k - i + 1`）。
- 前缀 XOR 下标偏移：`prefix[i]` 表示 `arr[0..i-1]` 的 XOR，区间 `[i, k]` 的 XOR 是 `prefix[k+1] XOR prefix[i]`。
- 方法三中对初始状态的处理：`prefix[0] = 0` 需要预置到哈希表中。
