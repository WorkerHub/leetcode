## 题目描述

给定整数数组 `nums`，求数组中任意一个偶数元素与任意一个奇数元素之差的最大绝对值。

## Java 代码实现

```java
class Solution {
    public int maxDifference(int[] nums) {
        int maxEven = Integer.MIN_VALUE, minEven = Integer.MAX_VALUE;
        int maxOdd = Integer.MIN_VALUE, minOdd = Integer.MAX_VALUE;

        for (int x : nums) {
            if (x % 2 == 0) {
                maxEven = Math.max(maxEven, x);
                minEven = Math.min(minEven, x);
            } else {
                maxOdd = Math.max(maxOdd, x);
                minOdd = Math.min(minOdd, x);
            }
        }

        // 最大差：偶数最大 - 奇数最小，或 奇数最大 - 偶数最小
        return Math.max(maxEven - minOdd, maxOdd - minEven);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 最大绝对差一定在"一种类型的最大值"与"另一种类型的最小值"之间取得
2. 两种方向都需要考虑（偶-奇 和 奇-偶）
