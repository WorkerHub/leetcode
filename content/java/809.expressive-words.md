## 题目描述

有时候人们会用重复写一些字母来表示额外的感受，比如 `"hello" -> "heeellooo"`, `"hi" -> "hiii"`。我们将相邻字母都相同的一串字符定义为相同字母组，例如："h", "eee", "ll", "ooo"。

对于一个给定的字符串 `s`，如果另一个单词能够通过将一些字母组扩张从而使其和 `s` 相同，我们将这个单词定义为 **可扩张的**（stretchy）。扩张操作定义如下：选择一个字母组（包含字母 `c`），然后往其中添加相同的字母 `c` 使其长度达到 **3 或以上**。

给你一个字符串 `s` 和一个字符串数组 `words`，返回 `words` 中可扩张的单词个数。

**示例 1:**
```
输入: s = "heeellooo", words = ["hello", "hi", "helo"]
输出: 1
```

**示例 2:**
```
输入: s = "zzzzzyyyyy", words = ["zzyy","zy","zyy"]
输出: 3
```

**提示:**
- `1 <= s.length, words.length <= 100`
- `1 <= words[i].length <= 100`
- `s` 和 `words[i]` 只由小写字母组成

## 解题思路

这道题的核心是理解"可扩张"的规则，然后使用双指针比较字符串。

**关键规则：**
1. 字母顺序必须完全相同
2. 对于 s 中的每个字母组：
   - 如果长度 >= 3，word 中对应组可以是任意长度（1 到 s 中的长度）
   - 如果长度 < 3，word 中对应组长度必须相等

## Java 代码实现

### 方法一：字母组比较（推荐）

```java
import java.util.*;

class Solution {
    public int expressiveWords(String s, String[] words) {
        int count = 0;
        for (String word : words) {
            if (isStretchy(s, word)) {
                count++;
            }
        }
        return count;
    }

    /**
     * 判断 word 是否可以扩张成 s
     */
    private boolean isStretchy(String s, String word) {
        int i = 0, j = 0;
        int sLen = s.length(), wLen = word.length();

        while (i < sLen && j < wLen) {
            // 字母不同，无法匹配
            if (s.charAt(i) != word.charAt(j)) {
                return false;
            }

            // 统计 s 中当前字母的数量
            int sCount = 1;
            while (i + sCount < sLen && s.charAt(i + sCount) == s.charAt(i)) {
                sCount++;
            }

            // 统计 word 中当前字母的数量
            int wCount = 1;
            while (j + wCount < wLen && word.charAt(j + wCount) == word.charAt(j)) {
                wCount++;
            }

            // 检查是否满足扩张规则
            if (wCount > sCount) {
                return false;
            }
            if (sCount < 3 && sCount != wCount) {
                return false;
            }

            i += sCount;
            j += wCount;
        }

        // 两个字符串都必须完全遍历
        return i == sLen && j == wLen;
    }
}
```

### 方法二：字母组列表比较

```java
import java.util.*;

class Solution {
    public int expressiveWords(String s, String[] words) {
        int[][] sGroups = getGroups(s);
        int count = 0;

        for (String word : words) {
            int[][] wGroups = getGroups(word);

            // 字母组数量必须相同
            if (sGroups.length != wGroups.length) continue;

            boolean valid = true;
            for (int k = 0; k < sGroups.length; k++) {
                int sChar = sGroups[k][0], sLen = sGroups[k][1];
                int wChar = wGroups[k][0], wLen = wGroups[k][1];

                // 字母必须相同
                if (sChar != wChar) {
                    valid = false;
                    break;
                }

                // word 的长度不能大于 s
                if (wLen > sLen) {
                    valid = false;
                    break;
                }

                // 如果 s 的长度 < 3，word 必须长度相同
                if (sLen < 3 && sLen != wLen) {
                    valid = false;
                    break;
                }
            }

            if (valid) count++;
        }

        return count;
    }

    /**
     * 将字符串转换为 [[字母编码, 长度], ...] 格式
     */
    private int[][] getGroups(String str) {
        List<int[]> groups = new ArrayList<>();
        int i = 0;

        while (i < str.length()) {
            int c = str.charAt(i);
            int count = 1;
            while (i + count < str.length() && str.charAt(i + count) == c) {
                count++;
            }
            groups.add(new int[]{c, count});
            i += count;
        }

        return groups.toArray(new int[0][]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × (m + k))，其中 n 是 words 的长度，m 是 s 的长度，k 是每个 word 的平均长度
- **空间复杂度**：O(m + k)，存储字母组信息

## 关键点总结

1. **字母组概念**：将字符串分解为连续相同字母的组
2. **扩张规则**：长度 >= 3 的组可以扩张，< 3 的组不能
3. **双指针技巧**：同时遍历两个字符串的字母组
4. **边界条件**：长度关系的判断很关键

## 易错点

1. **长度 < 3 的情况**：必须长度完全相等
2. **字母顺序**：不能改变字母的顺序
3. **完全遍历**：两个字符串都必须完全匹配
