## 题目描述

给你字符串数组 `patterns` 和字符串 `word`，统计 `patterns` 中有多少字符串是 `word` 的子字符串。

## 解题思路

对每个 pattern 用 `word.contains(pattern)` 判断是否为子串，统计计数。

## Java 代码实现

```java
class Solution {
    public int numOfStrings(String[] patterns, String word) {
        int count = 0;
        for (String p : patterns)
            if (word.contains(p)) count++;
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sum(|p| * |word|))
- **空间复杂度**：O(1)

## 关键点总结

1. `String.contains()` 判断子串，内部使用 KMP 或类似算法
