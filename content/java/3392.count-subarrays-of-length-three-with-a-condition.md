## 题目描述

给定整数数组 `nums`，返回满足 `2*(nums[i] + nums[i+2]) == nums[i+1]` 的长度为 3 的子数组数量。

## Java 代码实现

```java
class Solution {
    public int countSubarrays(int[] nums) {
        int count = 0;
        for (int i = 0; i < nums.length - 2; i++) {
            // 条件：a + c = b / 2，等价于 2*(a+c) = b，避免浮点误差
            if (2 * (nums[i] + nums[i + 2]) == nums[i + 1]) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 条件 `a + c == b / 2` 用整数等价式 `2*(a+c) == b` 避免浮点误差。
2. 只需枚举所有长度为 3 的子数组，共 n-2 个。
3. 代码极其简洁，直接遍历即可。
