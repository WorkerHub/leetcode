## 题目描述

删除二叉树中所有不足节点：通过该节点的每条根到叶路径的值总和都小于 limit。

**示例：**
```
输入：root = [1,2,-3,-5,null,4,null], limit = -1
输出：[1,null,-3,4]
```

## 解题思路

后序遍历 + 剪枝：先递归处理子树，叶子节点判断路径和是否 >= limit；非叶子节点如果左右子树都被删除则自己也被删除。

## Java 代码实现

```java
class Solution {
    public TreeNode sufficientSubset(TreeNode root, int limit) {
        return dfs(root, 0, limit);
    }

    private TreeNode dfs(TreeNode node, long currentSum, int limit) {
        if (node == null) return null;

        currentSum += node.val;

        // 叶子节点：判断路径和是否足够
        if (node.left == null && node.right == null) {
            return currentSum < limit ? null : node;
        }

        // 递归处理左右子树
        node.left = dfs(node.left, currentSum, limit);
        node.right = dfs(node.right, currentSum, limit);

        // 如果左右子树都被删除，当前节点也删除
        if (node.left == null && node.right == null) {
            return null;
        }

        return node;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(h)，h 为树高

## 关键点总结

1. **后序遍历**：必须先处理子树，再决定当前节点
2. **叶子判断**：叶子节点直接比较路径和与 limit
3. **向上传播删除**：子树全删→当前节点也删
4. **long 防溢出**：路径和可能超出 int 范围
