## 题目描述

你的国家有无数多个湖泊，所有湖泊一开始都是空的。当第 `n` 个湖泊下雨前是满的，它将会**发洪水**。你的目标是避免任何湖泊发洪水。

给你一个整数数组 `rains`，其中：
- `rains[i] > 0`：第 `i` 天，编号为 `rains[i]` 的湖泊下雨，湖泊变满。
- `rains[i] == 0`：第 `i` 天是晴天，你可以选择**一个**湖泊进行抽水，使其变空。

请返回一个数组 `ans`，满足：
- `ans.length == rains.length`
- 若 `rains[i] != 0`：`ans[i] == -1`。
- 若 `rains[i] == 0`：`ans[i]` 是你选择抽水的湖泊编号（1 到 10^9 之间）。

如果没有办法阻止洪水，请返回一个**空数组**。

**示例 1：**

```
输入：rains = [1,2,3,4]
输出：[-1,-1,-1,-1]
解释：没有晴天，每个湖泊只下一次雨，不会发洪水。
```

**示例 2：**

```
输入：rains = [1,2,0,0,2,1]
输出：[-1,-1,2,1,-1,-1]
解释：
第0天：湖1下雨，满。
第1天：湖2下雨，满。
第2天：晴天，选择抽空湖2（因为湖2即将再次下雨）。
第3天：晴天，选择抽空湖1（因为湖1即将再次下雨）。
第4天：湖2下雨，满（之前已抽空）。
第5天：湖1下雨，满（之前已抽空）。
```

**示例 3：**

```
输入：rains = [1,2,0,1,2]
输出：[]
解释：第2天是唯一的晴天，无法同时抽空湖1和湖2，发洪水。
```

**提示：**
- `1 <= rains.length <= 10^5`
- `0 <= rains[i] <= 10^9`

---

## 解题思路

**贪心策略：** 晴天选择抽水时，应优先抽**最快会下雨**的湖泊，这样可以最大化利用晴天。

**具体算法：**
1. 用哈希表 `full` 记录当前装满水的湖泊及其**上次下雨的日期**。
2. 用有序集合（TreeSet）记录所有**晴天的日期**。
3. 遇到下雨天（`rains[i] > 0`）：
   - 如果该湖泊已满 → 在两次下雨之间找一个晴天抽干。
   - 否则将湖泊标记为满。
4. 遇到晴天（`rains[i] == 0`）：
   - 将该天加入有序集合，暂不决定抽哪个湖（延迟决策）。
5. 当某个湖泊第二次下雨时，必须找到一个**在两次下雨之间的晴天**来抽干它（用 `ceiling` 二分查找最近的晴天）。

## Java 代码实现

### 方法一：哈希表 + TreeSet（推荐）

```java
import java.util.HashMap;
import java.util.Map;
import java.util.TreeSet;

class Solution {
    public int[] avoidFlood(int[] rains) {
        int n = rains.length;
        int[] ans = new int[n];

        Map<Integer, Integer> full = new HashMap<>();  // 湖泊编号 -> 上次下雨的天数
        TreeSet<Integer> dryDays = new TreeSet<>();    // 还未被使用的晴天（存储下标）

        for (int i = 0; i < n; i++) {
            if (rains[i] == 0) {
                // 晴天：先加入集合，等待分配
                dryDays.add(i);
                ans[i] = 1;  // 占位，后续可能更新（抽任意湖）
            } else {
                int lake = rains[i];
                if (full.containsKey(lake)) {
                    // 该湖已满，必须在 full[lake] 之后找一个晴天来抽水
                    int prevRain = full.get(lake);

                    // 用 ceiling 查找严格大于 prevRain 的最小晴天下标
                    Integer dryDay = dryDays.ceiling(prevRain + 1);
                    if (dryDay == null) {
                        // 没有可用的晴天 → 洪水无法避免
                        return new int[0];
                    }

                    ans[dryDay] = lake;      // 在这一天抽干该湖
                    dryDays.remove(dryDay);  // 该晴天已被使用
                }

                // 更新：湖泊 lake 在第 i 天下雨，现在是满的
                full.put(lake, i);
                ans[i] = -1;  // 下雨天，ans 为 -1
            }
        }

        return ans;
    }
}
```

### 方法二：哈希表 + 数组二分查找（不依赖 TreeSet）

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] avoidFlood(int[] rains) {
        int n = rains.length;
        int[] ans = new int[n];
        Arrays.fill(ans, 1);  // 先填充 1，晴天占位；雨天后面设为 -1

        Map<Integer, Integer> full = new HashMap<>();  // 湖泊编号 -> 上次下雨的天数
        List<Integer> dryDays = new ArrayList<>();      // 晴天日期列表（保持有序，因为按顺序加入）

        for (int i = 0; i < n; i++) {
            if (rains[i] == 0) {
                // 晴天加入列表
                dryDays.add(i);
            } else {
                int lake = rains[i];
                ans[i] = -1;  // 下雨天

                if (full.containsKey(lake)) {
                    int prevRain = full.get(lake);

                    // 二分查找 dryDays 中第一个 > prevRain 的值
                    int lo = 0, hi = dryDays.size();
                    while (lo < hi) {
                        int mid = (lo + hi) / 2;
                        if (dryDays.get(mid) > prevRain) hi = mid;
                        else lo = mid + 1;
                    }

                    if (lo == dryDays.size()) {
                        return new int[0];  // 没有可用晴天
                    }

                    int dryDay = dryDays.remove(lo);  // 移除并使用该晴天
                    ans[dryDay] = lake;
                }

                full.put(lake, i);
            }
        }

        return ans;
    }
}
```

### 方法三：暴力法（超时，仅用于理解）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] avoidFlood(int[] rains) {
        int n = rains.length;
        int[] ans = new int[n];
        Map<Integer, Integer> full = new HashMap<>();  // 湖泊编号 -> 上次下雨天数
        List<Integer> sunny = new ArrayList<>();        // 晴天列表（下标）

        for (int i = 0; i < n; i++) {
            if (rains[i] == 0) {
                sunny.add(i);
                ans[i] = 1;  // 占位
            } else {
                int lake = rains[i];
                if (full.containsKey(lake)) {
                    // 暴力：线性查找第一个合适的晴天
                    boolean found = false;
                    for (int j = 0; j < sunny.size(); j++) {
                        if (sunny.get(j) > full.get(lake)) {
                            ans[sunny.get(j)] = lake;   // 这一天抽干湖 lake
                            sunny.remove(j);
                            found = true;
                            break;
                        }
                    }
                    if (!found) {
                        return new int[0];
                    }
                }
                full.put(lake, i);
                ans[i] = -1;
            }
        }

        return ans;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| TreeSet（方法一） | O(n log n) | O(n) |
| 暴力（方法三） | O(n^2) | O(n) |

- `TreeSet` 的插入、删除、`ceiling` 查找均为 O(log n)，总体 O(n log n)。
- 暴力线性查找每次 O(n)，最坏 O(n^2)，数据量大时会超时。

## 图解示例

以 `rains = [1,2,0,0,2,1]` 为例：

```
i=0, rain=1: 湖1下雨，full={1:0}，ans=[-1,...]
i=1, rain=2: 湖2下雨，full={1:0, 2:1}，ans=[-1,-1,...]
i=2, rain=0: 晴天，dryDays=[2]，ans[-1,-1,1,...]
i=3, rain=0: 晴天，dryDays=[2,3]，ans=[-1,-1,1,1,...]

i=4, rain=2: 湖2再次下雨！full[2]=1（上次在第1天）
  ceiling(2) = 2（dryDays 中 > 1 的最小值）
  ans[2] = 2（第2天抽干湖2），dryDays=[3]
  full[2]=4，ans=[-1,-1,2,-1,-1,...]

i=5, rain=1: 湖1再次下雨！full[1]=0（上次在第0天）
  ceiling(1) = 3（dryDays 中 > 0 的最小值）
  ans[3] = 1（第3天抽干湖1），dryDays=[]
  full[1]=5，ans=[-1,-1,2,1,-1,-1]

最终：[-1,-1,2,1,-1,-1]
```

## 关键点总结

1. **贪心策略**：晴天应该用来抽即将发洪水的湖泊，且应使用**最近的**可用晴天（贪心最优）。
2. **TreeSet** 支持 O(log n) 的插入、删除和 `ceiling` 查找，是 Java 中解决本题的关键数据结构。
3. `dryDays.ceiling(prevRain + 1)` 找到上次下雨之后的第一个晴天。
4. 如果找不到合适的晴天（`ceiling` 返回 null），返回空数组。

---

## 易错点

- **晴天的决策是延迟的**：遇到晴天时不立即决定抽哪个湖，而是等到需要时（某湖将发洪水时）再分配。
- **`ceiling(prevRain + 1)`**：找严格大于 `prevRain` 的第一个晴天（因为当天下雨就不能同时抽水）。
- **剩余晴天的处理**：未分配的晴天可以抽任意不满的湖，`ans[i] = 1` 是合法的占位值。

## 学习建议

1. 本题是贪心 + 数据结构的综合题，需要选择合适的数据结构（TreeSet）支持高效的范围查询。
2. 贪心策略的核心：当某湖必须在某天之前抽干时，选择最近的晴天来抽，将远处的晴天留给其他湖泊。
3. Java 的 `TreeSet` 相当于 Python 的 `SortedList`，`ceiling(x)` 对应 `bisect_right` 的功能。
4. 遇到"需要在某个范围内快速找到最小/最大值"的问题，优先考虑 `TreeSet` 或二分查找。
