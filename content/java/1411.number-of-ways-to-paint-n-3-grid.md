## 题目描述

你有一个 `n x 3` 的网格，你需要用 **3 种不同颜色**涂色，使得相邻的格子（上下左右）颜色不同。

请问有多少种涂色方案？答案对 `10^9 + 7` 取模。

**示例 1：**

```
输入：n = 1
输出：12
解释：对于 1×3 的网格，每行3格，相邻格子不同色，方案数为 3*2*2 = 12。
```

**示例 2：**

```
输入：n = 2
输出：54
```

**示例 3：**

```
输入：n = 3
输出：246
```

**提示：**

- `1 <= n <= 5000`

## 解题思路

这道题的核心在于：**每一行的涂色方案只有两类**。

### 关键观察：行的模式分类

对于一行 3 个格子，相邻格子颜色不同，设三种颜色为 1、2、3：

**ABA 型（首尾相同，共 6 种）：**

- 第1格和第3格颜色相同，第2格不同
- 例如：(1,2,1), (1,3,1), (2,1,2), (2,3,2), (3,1,3), (3,2,3) → 共 **6 种**

**ABC 型（三格颜色各不同，共 6 种）：**

- 三格颜色两两不同
- A 有 3 种，B 有 2 种（不等于A），C 有 1 种（不等于A也不等于B）
- 共 3 * 2 * 1 = **6 种**

总计 6 + 6 = 12 种，与 n=1 时答案吻合。

### 行间转换规则

**ABA 型转下一行：**
- 转 ABA 型：共 **3 种**
- 转 ABC 型：共 **2 种**

**ABC 型转下一行：**
- 转 ABA 型：共 **2 种**
- 转 ABC 型：共 **2 种**

转换系数汇总：
- ABA → ABA: 3
- ABA → ABC: 2
- ABC → ABA: 2
- ABC → ABC: 2

### DP 状态定义

设 `aba` 和 `abc` 分别为当前行使用 ABA 型和 ABC 型的方案总数：

- 初始值：`aba = 6`，`abc = 6`
- 转移：`new_aba = aba * 3 + abc * 2`，`new_abc = aba * 2 + abc * 2`

答案为 `aba + abc`。

## Java 代码实现

### 方法一：DP（推荐）

```java
class Solution {
    public int numOfWays(int n) {
        int MOD = 1_000_000_007;

        // 初始化第一行
        // ABA 型（首尾颜色相同）：共 6 种
        long aba = 6;
        // ABC 型（三色各不同）：共 6 种
        long abc = 6;

        for (int i = 1; i < n; i++) {
            // 计算下一行的方案数
            // 新 ABA = 旧 ABA * 3 + 旧 ABC * 2
            // 新 ABC = 旧 ABA * 2 + 旧 ABC * 2
            long newAba = (aba * 3 + abc * 2) % MOD;
            long newAbc = (aba * 2 + abc * 2) % MOD;
            aba = newAba;
            abc = newAbc;
        }

        return (int) ((aba + abc) % MOD);
    }
}
```

### 方法二：矩阵快速幂（适合超大 n）

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    // 2x2 矩阵乘法
    private long[][] matrixMult(long[][] A, long[][] B) {
        int n = A.length;
        long[][] C = new long[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                for (int k = 0; k < n; k++) {
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
                }
            }
        }
        return C;
    }

    // 矩阵快速幂
    private long[][] matrixPow(long[][] M, int p) {
        int n = M.length;
        // 初始化单位矩阵
        long[][] result = new long[n][n];
        for (int i = 0; i < n; i++) result[i][i] = 1;

        while (p > 0) {
            if ((p & 1) == 1) {
                result = matrixMult(result, M);
            }
            M = matrixMult(M, M);
            p >>= 1;
        }
        return result;
    }

    public int numOfWays(int n) {
        // 转移矩阵：[[3, 2], [2, 2]]
        long[][] M = {{3, 2}, {2, 2}};

        // 计算 M^(n-1)
        long[][] Mn = matrixPow(M, n - 1);

        // 初始 state = [6, 6]
        long aba = (Mn[0][0] * 6 + Mn[0][1] * 6) % MOD;
        long abc = (Mn[1][0] * 6 + Mn[1][1] * 6) % MOD;

        return (int) ((aba + abc) % MOD);
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(n) | O(1) |
| 矩阵快速幂 | O(log n) | O(1) |

本题 `n <= 5000`，O(n) DP 完全够用。

## 图解示例

以 n=2 验证：

```
第1行（12种）：ABA(6种) + ABC(6种)
第2行：
  ABA 贡献：6 * 3 + 6 * 2 = 30 种 ABA
  ABC 贡献：6 * 2 + 6 * 2 = 24 种 ABC
  总计：30 + 24 = 54 ✓
```

## 关键点总结

1. 将每行的12种合法方案归为 ABA（首尾同色）和 ABC（三色不同）两类
2. 推导两类之间的转移系数：ABA→ABA=3, ABA→ABC=2, ABC→ABA=2, ABC→ABC=2
3. 转移系数的推导需要枚举，确保理解正确
4. 每步取模，防止大数溢出
5. 矩阵快速幂可进一步优化到 O(log n)，适用于 n 极大的场景

## 易错点

1. 转移系数推导错误：建议手动枚举 (a,b,a) 的所有下一行情况来验证
2. 初始值：第1行 ABA 和 ABC 各有 6 种，总计 12 种
3. 模运算：每一步都要取模，不能只在最后取模
4. Java 中用 `long` 存储中间结果，防止乘法溢出
