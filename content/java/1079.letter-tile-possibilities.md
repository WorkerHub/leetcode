## 题目描述

给定一套字母瓷砖，返回可以组成的非空字母序列的数量。

**示例：**
```
输入：tiles = "AAB"
输出：8
解释：可能的序列为 "A", "B", "AA", "AB", "BA", "AAB", "ABA", "BAA"
```

## 解题思路

回溯 + 频率统计：用字母频率数组避免重复。每次选择一个可用字母，计数+1，递归继续选择，回溯恢复。

## Java 代码实现

```java
class Solution {
    public int numTilePossibilities(String tiles) {
        // 统计每个字母的频率
        int[] count = new int[26];
        for (char c : tiles.toCharArray()) {
            count[c - 'A']++;
        }
        return backtrack(count);
    }

    private int backtrack(int[] count) {
        int total = 0;
        for (int i = 0; i < 26; i++) {
            if (count[i] == 0) continue;
            // 选择字母 i，形成一个新序列
            total++;
            count[i]--;
            // 继续选择后续字母
            total += backtrack(count);
            // 回溯
            count[i]++;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n!)，n 为瓷砖数（最多 7）
- **空间复杂度**：O(n)，递归栈深度

## 关键点总结

1. **频率去重**：用计数数组而非标记数组，自动避免重复排列
2. **计数技巧**：每选一个字母就形成一个新序列，直接 +1
3. **回溯模板**：选择→递归→撤销
