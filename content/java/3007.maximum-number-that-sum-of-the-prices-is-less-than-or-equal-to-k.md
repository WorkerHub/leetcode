## 题目描述

定义数 n 的"价格"为其二进制中第 x、2x、3x...位（从右 1-indexed）为 1 的位数。返回使 1..n 价格总和 ≤ k 的最大 n。

## 解题思路

二分答案 n，计算 1..n 的价格总和：对每个目标位 b（x, 2x, ...），利用周期公式统计该位在 1..n 中为 1 的总次数。

## Java 代码实现

```java
class Solution {
    public long findMaximumNumber(long k, int x) {
        long lo = 1, hi = (k + 1) * (1L << x);
        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (countPrice(mid, x) <= k) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    // 计算 1..n 中所有数字的价格总和
    private long countPrice(long n, int x) {
        long total = 0;
        for (int bit = x; (1L << (bit - 1)) <= n; bit += x) {
            long p = 1L << (bit - 1);   // 该位的权重
            long cycle = p << 1;         // 周期 = 2 * p
            long full = n / cycle;       // 完整周期数
            long rem = n % cycle;        // 余数
            total += full * p + Math.max(0, rem - p + 1);
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log²n)
- **空间复杂度**：O(1)

## 关键点总结

1. 答案具有单调性，适合二分
2. 第 b 位在 1..n 中为 1 的个数：full·p + max(0, rem-p+1)
3. k 最大 10^15，需用 long 类型
