## 题目描述

给定 n 个节点的二叉树（由 parents 数组描述），删除节点 x 后树分裂为至多三部分（左子树、右子树、祖先部分），分数为各非空部分节点数的乘积。返回分数最高的节点数目。

## 解题思路

迭代后序 DFS 计算每个节点的子树大小 subtree[x]，祖先部分大小为 `n - subtree[x]`。枚举每个节点计算分数，统计最大分数的节点个数。注意分数可达 n^3 需使用 long。

## Java 代码实现

### 方法一：迭代 DFS + 枚举（推荐）

```java
import java.util.*;

class Solution {
    public int countHighestScoreNodes(int[] parents) {
        int n = parents.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parents[i]).add(i);

        // 迭代后序遍历计算子树大小
        int[] subtree = new int[n];
        Arrays.fill(subtree, 1);
        int[] order = new int[n];
        int idx = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        while (!stack.isEmpty()) {
            int node = stack.pop();
            order[idx++] = node;
            for (int child : children.get(node)) stack.push(child);
        }
        for (int i = idx - 1; i >= 0; i--) {
            int node = order[i];
            for (int child : children.get(node)) subtree[node] += subtree[child];
        }

        long maxScore = 0;
        int count = 0;
        for (int x = 0; x < n; x++) {
            long score = 1;
            int remaining = n - 1;
            for (int child : children.get(x)) {
                score *= subtree[child];
                remaining -= subtree[child];
            }
            if (remaining > 0) score *= remaining; // 祖先部分
            if (score > maxScore) {
                maxScore = score;
                count = 1;
            } else if (score == maxScore) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 祖先部分大小 = `n - subtree[x]`
2. 零大小的部分不参与乘积计算
3. 分数最大可达 n^3，需使用 long
