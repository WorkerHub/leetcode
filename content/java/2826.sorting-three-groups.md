## 题目描述

数组元素为1/2/3，求最少替换次数使数组非递减。

## 解题思路

最少操作=n-最长非递减子序列长度。值只有3种，dp[v]表示以值v结尾的最长非递减子序列长度。

## Java 代码实现

```java
class Solution {
    public int minimumOperations(List<Integer> nums) {
        int n = nums.size();
        // dp[i] = 以值i+1结尾的最长非递减子序列长度
        int[] dp = new int[3];

        for (int x : nums) {
            int v = x - 1;
            // 以值<=x结尾的最大长度+1
            int best = 0;
            for (int i = 0; i <= v; i++) {
                best = Math.max(best, dp[i]);
            }
            dp[v] = best + 1;
        }
        return n - Math.max(dp[0], Math.max(dp[1], dp[2]));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **最少操作=n-最长非递减子序列**
2. **值域只有3**：DP状态只需3个
3. **更新dp[v]=max(dp[0..v])+1**
