## 题目描述

给定二进制字符串，返回所有字符都是 1 的子字符串数目（mod 10^9+7）。

**示例：**
```
输入：s = "0110111"
输出：9
```

## 解题思路

找每段连续 1 的长度 L，贡献 = L×(L+1)/2。累加所有段。

## Java 代码实现

```java
class Solution {
    public int numSub(String s) {
        int MOD = 1_000_000_007;
        long count = 0;
        int consecutive = 0;
        
        for (char c : s.toCharArray()) {
            if (c == '1') {
                consecutive++;
                count = (count + consecutive) % MOD;
            } else {
                consecutive = 0;
            }
        }
        return (int) count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **连续段贡献**：长度 L 贡献 L*(L+1)/2
2. **在线累加**：每遇到 1 就加上当前连续长度
3. **等价理解**：每个新的 1 新增 consecutive 个子串
