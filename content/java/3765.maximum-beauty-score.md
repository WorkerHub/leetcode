## 题目描述

给定整数数组 `nums` 和整数 `k`，对于每个下标 `i`，其"美丽分"为与 `nums[i]` 差值绝对值不超过 `k` 的其他元素个数。返回最大美丽分。

## 解题思路

排序后，满足差值 <= k 的元素构成连续区间。用双指针维护滑动窗口，窗口内最大值和最小值差 <= k，窗口大小减 1 即为当前美丽分。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximumBeauty(int[] nums, int k) {
        int[] sorted = nums.clone();
        Arrays.sort(sorted);
        int n = sorted.length;
        int ans = 0;
        int left = 0;

        for (int right = 0; right < n; right++) {
            // 收缩窗口直到差值 <= k
            while (sorted[right] - sorted[left] > k) {
                left++;
            }
            // 美丽分 = 窗口大小 - 1（排除自身）
            ans = Math.max(ans, right - left);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 排序后差值 <= k 的元素构成连续区间
2. 双指针维护满足条件的滑动窗口
3. 美丽分 = 窗口大小 - 1（不计自身）
