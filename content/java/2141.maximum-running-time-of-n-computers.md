## 题目描述

n台电脑m个电池，电池可自由切换。求n台电脑同时运行的最长时间。

## 解题思路

二分目标时间T：每块电池贡献min(b,T)分钟（超出T无用），总供电量>=n*T则可行。或贪心：排序后大电池独占一台电脑，剩余均分。

## Java 代码实现

```java
class Solution {
    public long maxRunTime(int n, int[] batteries) {
        long total = 0;
        for (int b : batteries) total += b;
        
        long lo = 0, hi = total / n;
        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (canRun(batteries, n, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }
    
    private boolean canRun(int[] batteries, int n, long T) {
        long supply = 0;
        for (int b : batteries) {
            supply += Math.min(b, T);
        }
        return supply >= (long) n * T;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * log(sum/N))
- **空间复杂度**：O(1)

## 关键点总结

1. **每块电池贡献上限为T**：超出T的部分无用
2. **总供电量>=n*T则可行**：可以自由调度
3. **二分上界**：sum/n（总电量均分）
