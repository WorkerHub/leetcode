## 题目描述

商店有 n 件商品和一些大礼包，给定需要购买的清单 needs，返回满足购买清单的最低价格。

**示例：**
```
输入：price = [2,5], special = [[3,0,5],[1,2,10]], needs = [3,2]
输出：14
```

## 解题思路

记忆化搜索：对当前需求，尝试使用每个大礼包或直接购买，取最小价格。

## Java 代码实现

```java
class Solution {
    private Map<List<Integer>, Integer> memo = new HashMap<>();

    public int shoppingOffers(List<Integer> price, List<List<Integer>> special, List<Integer> needs) {
        return dfs(price, special, needs);
    }

    private int dfs(List<Integer> price, List<List<Integer>> special, List<Integer> needs) {
        if (memo.containsKey(needs)) return memo.get(needs);

        // 不使用大礼包的价格
        int res = 0;
        for (int i = 0; i < needs.size(); i++) {
            res += needs.get(i) * price.get(i);
        }

        // 尝试使用每个大礼包
        for (List<Integer> offer : special) {
            List<Integer> newNeeds = new ArrayList<>();
            boolean valid = true;
            for (int i = 0; i < needs.size(); i++) {
                if (needs.get(i) < offer.get(i)) {
                    valid = false;
                    break;
                }
                newNeeds.add(needs.get(i) - offer.get(i));
            }
            if (valid) {
                res = Math.min(res, offer.get(offer.size() - 1) + dfs(price, special, newNeeds));
            }
        }

        memo.put(needs, res);
        return res;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × k^n)，m 为大礼包数，k 为需求上限，n 为商品种类
- **空间复杂度**：O(k^n)

## 关键点总结

1. **记忆化搜索**：用 needs 列表作为 key 缓存结果
2. **检查大礼包可用性**：每个商品需求不能为负
3. **比较两种方案**：使用 vs 不使用大礼包
