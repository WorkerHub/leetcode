## 题目描述

给你一个数组 `nums`，每个数字要么出现一次要么恰好出现两次，返回所有出现两次的数字的按位异或结果（若无则返回 0）。

## 解题思路

用集合记录已见过的数字，第二次遇到某数字时将其加入异或结果。

## Java 代码实现

```java
class Solution {
    public int duplicateNumbersXOR(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        int ans = 0;
        for (int x : nums) {
            if (!seen.add(x)) {
                // 第二次出现，加入异或
                ans ^= x;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. `HashSet.add()` 返回 false 表示元素已存在（即第二次出现）
2. 只对出现两次的数字做异或，出现一次的忽略
