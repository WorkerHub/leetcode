## 题目描述

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

**示例 1：**
```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

**示例 2：**
```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```

**提示：**
- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## 解题思路

核心思想：动态规划

状态定义：
- dp[i][j] 表示 word1[0:i] 转换为 word2[0:j] 的最少操作数

状态转移：
- 如果 word1[i-1] == word2[j-1]：dp[i][j] = dp[i-1][j-1]
- 否则取三种操作的最小值：
  - 插入：dp[i][j-1] + 1
  - 删除：dp[i-1][j] + 1
  - 替换：dp[i-1][j-1] + 1

## Java 代码实现

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];

        // 初始化：word1 转换为空字符串需要 i 次删除
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        // 初始化：空字符串转换为 word2 需要 j 次插入
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // 填表
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相同，无需操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(
                        dp[i - 1][j] + 1,      // 删除
                        Math.min(
                            dp[i][j - 1] + 1,   // 插入
                            dp[i - 1][j - 1] + 1 // 替换
                        )
                    );
                }
            }
        }

        return dp[m][n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(m × n)
- 空间复杂度：O(m × n)

## 关键点总结

1. **状态定义**：前i个字符转换为前j个字符
2. **状态转移**：分字符相同和不同两种情况
3. **初始化**：第一行和第一列分别为j和i

## 易错点

1. **初始化**：第一行和第一列很重要
2. **索引对应**：dp[i][j]对应word1[i-1]和word2[j-1]
3. **charAt**：Java 使用 `charAt` 获取字符，不能直接用下标
