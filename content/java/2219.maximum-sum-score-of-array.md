## 题目描述

数组每个下标的得分为max(前缀和,后缀和)，返回所有下标得分的最大值。

## 解题思路

一遍遍历计算前缀和，利用suffix[i]=total-prefix[i-1]计算后缀和，每个位置取较大值更新全局最大。

## Java 代码实现

```java
class Solution {
    public long maximumSumScore(int[] nums) {
        int n = nums.length;
        long total = 0;
        for (int x : nums) total += x;
        
        long prefix = 0;
        long ans = Long.MIN_VALUE;
        
        for (int i = 0; i < n; i++) {
            prefix += nums[i];
            long suffix = total - prefix + nums[i];
            ans = Math.max(ans, Math.max(prefix, suffix));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和与后缀和关系**：suffix[i] = total - prefix[i-1]
2. **一遍遍历**：同时计算前缀和并推导后缀和
3. **用long防溢出**：前缀和可能超int范围
