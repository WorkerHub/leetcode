## 题目描述

多项式链表每个节点含 `coefficient`（系数）和 `power`（指数），按指数**降序**排列。给你两个多项式链表，返回它们的和。

## 解题思路

类似有序链表归并，比较指数大小：指数大的先加入，指数相同则系数相加（和为 0 时跳过）。

## Java 代码实现

```java
class Solution {
    public PolyNode addPoly(PolyNode poly1, PolyNode poly2) {
        PolyNode dummy = new PolyNode(); // 哑头节点
        PolyNode curr = dummy;
        PolyNode p1 = poly1, p2 = poly2;

        while (p1 != null && p2 != null) {
            if (p1.power > p2.power) {
                // p1 指数更大，直接加入结果
                curr.next = new PolyNode(p1.coefficient, p1.power);
                curr = curr.next;
                p1 = p1.next;
            } else if (p1.power < p2.power) {
                // p2 指数更大
                curr.next = new PolyNode(p2.coefficient, p2.power);
                curr = curr.next;
                p2 = p2.next;
            } else {
                // 指数相同，系数相加
                int coeffSum = p1.coefficient + p2.coefficient;
                if (coeffSum != 0) {
                    curr.next = new PolyNode(coeffSum, p1.power);
                    curr = curr.next;
                }
                p1 = p1.next;
                p2 = p2.next;
            }
        }

        // 处理剩余部分
        curr.next = (p1 != null) ? p1 : p2;

        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)，m、n 为两链表长度
- **空间复杂度**：O(1)（不含结果链表）

## 关键点总结

1. 按指数降序归并，类似有序链表合并
2. 指数相同时系数相加，和为 0 则不加入结果
3. 双指针都需前移
4. 哑头节点简化链表操作
