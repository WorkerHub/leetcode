## 题目描述

`nums` 中所有元素不同，找字典序最大的长度为 `k` 的子数组。

## 解题思路

**贪心：** 所有元素不同，字典序最大的长度 `k` 子数组第一个元素必须是数组最大值，找最大值下标返回之后 `k` 个元素。

## Java 代码实现

```java
class Solution {
    public int[] largestSubarray(int[] nums, int k) {
        int maxIdx = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }
        return Arrays.copyOfRange(nums, maxIdx, maxIdx + k);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. 所有元素不同，字典序最大子数组的第一个元素必为全局最大值
2. `Arrays.copyOfRange` 提取子数组
