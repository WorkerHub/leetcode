## 题目描述

统计长度为n、字典序在[s1,s2]之间、且不包含evil子串的字符串数目。

## 解题思路

数位DP+KMP：dp(pos, evilPos, tightLo, tightHi)，用KMP状态跟踪已匹配evil的前缀长度，匹配完整则无效。

## Java 代码实现

```java
class Solution {
    private int n, m;
    private String s1, s2, evil;
    private int[] next;
    private Long[][][][] memo;
    private static final long MOD = 1_000_000_007;

    public int findGoodStrings(int n, String s1, String s2, String evil) {
        this.n = n; this.m = evil.length();
        this.s1 = s1; this.s2 = s2; this.evil = evil;
        this.next = buildKMP(evil);
        this.memo = new Long[n][m][2][2];
        return (int) dp(0, 0, true, true);
    }

    private long dp(int pos, int evilPos, boolean tightLo, boolean tightHi) {
        if (evilPos == m) return 0; // 包含evil，无效
        if (pos == n) return 1;

        int tl = tightLo ? 1 : 0, th = tightHi ? 1 : 0;
        if (memo[pos][evilPos][tl][th] != null) return memo[pos][evilPos][tl][th];

        char lo = tightLo ? s1.charAt(pos) : 'a';
        char hi = tightHi ? s2.charAt(pos) : 'z';
        long result = 0;

        for (char c = lo; c <= hi; c++) {
            int newEvilPos = kmpNext(evilPos, c);
            boolean newTl = tightLo && (c == s1.charAt(pos));
            boolean newTh = tightHi && (c == s2.charAt(pos));
            result = (result + dp(pos + 1, newEvilPos, newTl, newTh)) % MOD;
        }

        memo[pos][evilPos][tl][th] = result;
        return result;
    }

    private int kmpNext(int state, char c) {
        while (state > 0 && c != evil.charAt(state)) {
            state = next[state - 1];
        }
        if (c == evil.charAt(state)) state++;
        return state;
    }

    private int[] buildKMP(String s) {
        int[] next = new int[s.length()];
        int j = 0;
        for (int i = 1; i < s.length(); i++) {
            while (j > 0 && s.charAt(i) != s.charAt(j)) j = next[j - 1];
            if (s.charAt(i) == s.charAt(j)) j++;
            next[i] = j;
        }
        return next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * M * 26)
- **空间复杂度**：O(N * M)

## 关键点总结

1. **数位DP+KMP组合**：DP维度包含KMP匹配状态
2. **tightLo/tightHi双边界**：同时控制上下界
3. **evilPos==m时剪枝**：已包含evil则方案无效
