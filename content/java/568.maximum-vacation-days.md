## 题目描述

LeetCode 想让一位员工在 N 个城市出差 K 周。每周你可以选择留在当前城市或飞到另一个城市。每个城市每周有不同的休假天数。

给定两个矩阵 `flights` 和 `days`：
- `flights[i][j]` 表示城市 i 到城市 j 是否有航班（1 表示有，0 表示没有）
- `days[i][j]` 表示在第 j 周在城市 i 可以休假的天数

返回你可以获得的最大休假天数。初始时你在城市 0。

**示例：**
```
输入：flights = [[0,1,1],[1,0,1],[1,1,0]], days = [[1,3,1],[6,0,3],[3,3,3]]
输出：12
解释：
周0: 城市0 -> 城市1 (休假3天)
周1: 城市1 -> 城市2 (休假3天)
周2: 城市2 (休假3天)
```

**提示：**
- `n == flights.length`
- `n == flights[i].length`
- `n == days.length`
- `k == days[i].length`
- `1 <= n, k <= 100`
- `0 <= flights[i][j] <= 1`
- `0 <= days[i][j] <= 7`
- `flights[i][i] == 0`

## 解题思路

动态规划问题。

状态定义：
- `dp[i][j]` 表示第 j 周在城市 i 能获得的最大休假天数

转移方程：
- `dp[i][week] = max(dp[k][week-1]) + days[i][week]`，其中 k 可以飞到 i

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
class Solution {
    public int maxVacationDays(int[][] flights, int[][] days) {
        // 动态规划
        int n = days.length, k = days[0].length;

        // dp[i][j] = 第 j 周在城市 i 的最大休假天数，-1 表示不可达
        int[][] dp = new int[n][k];
        for (int[] row : dp) java.util.Arrays.fill(row, -1);
        dp[0][0] = days[0][0];

        for (int week = 0; week < k; week++) {
            for (int city = 0; city < n; city++) {
                if (week == 0 && city == 0) continue;

                // 从其他城市飞来，或留在原地
                for (int prevCity = 0; prevCity < n; prevCity++) {
                    if (prevCity == city || flights[prevCity][city] == 1) {
                        if (week == 0) {
                            // 第 0 周只能从城市 0 出发
                            if (prevCity == 0) {
                                dp[city][week] = Math.max(dp[city][week], days[city][week]);
                            }
                        } else {
                            if (dp[prevCity][week - 1] != -1) {
                                dp[city][week] = Math.max(
                                    dp[city][week],
                                    dp[prevCity][week - 1] + days[city][week]
                                );
                            }
                        }
                    }
                }
            }
        }

        int result = 0;
        for (int i = 0; i < n; i++) {
            result = Math.max(result, dp[i][k - 1]);
        }
        return result;
    }
}
```

### 方法二：空间优化（滚动数组）

```java
class Solution {
    public int maxVacationDays(int[][] flights, int[][] days) {
        // 滚动数组优化空间
        int n = days.length, k = days[0].length;

        int[] prev = new int[n];
        java.util.Arrays.fill(prev, Integer.MIN_VALUE);
        prev[0] = 0;  // 初始在城市 0

        for (int week = 0; week < k; week++) {
            int[] curr = new int[n];
            java.util.Arrays.fill(curr, Integer.MIN_VALUE);

            for (int city = 0; city < n; city++) {
                for (int prevCity = 0; prevCity < n; prevCity++) {
                    // 可以留在原城市或飞到 city
                    if (prevCity == city || flights[prevCity][city] == 1) {
                        if (prev[prevCity] != Integer.MIN_VALUE) {
                            curr[city] = Math.max(curr[city], prev[prevCity] + days[city][week]);
                        }
                    }
                }
            }
            prev = curr;
        }

        int result = 0;
        for (int val : prev) {
            result = Math.max(result, val);
        }
        return result;
    }
}
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n × k)

**方法二：**
- **时间复杂度**：O(n² × k)
- **空间复杂度**：O(n)

## 关键点总结

1. **DP 状态**：`dp[city][week]` 表示该周在该城市的最大休假天数
2. **转移条件**：可以从同一城市或有航班的城市转移
3. **初始状态**：第 0 周在城市 0
4. **空间优化**：只需要前一周的状态
