## 题目描述

字母值a=0,b=1,...,z=25。将单词按字母值拼接成数字，判断firstWord+secondWord是否等于targetWord。

## 解题思路

将每个单词转为数字（每个字母值作为一位十进制数字拼接），判断两数之和。

## Java 代码实现

```java
class Solution {
    public boolean isSumEqual(String firstWord, String secondWord, String targetWord) {
        return wordToNum(firstWord) + wordToNum(secondWord) == wordToNum(targetWord);
    }
    
    private int wordToNum(String word) {
        int num = 0;
        for (char c : word.toCharArray()) {
            num = num * 10 + (c - 'a');
        }
        return num;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **字母值映射**：c - 'a' 得到0-25
2. **拼接成数字**：num = num * 10 + digit
