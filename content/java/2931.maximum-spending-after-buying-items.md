## 题目描述

m个商店各有n件物品（每行从左到右非递增），每次只能买某商店最右边的物品，第d天买花费value*d，求最大总花费。

## 解题思路

贪心：小价值物品先买（d小），大价值后买（d大）。用最小堆维护各商店当前最右可购买物品。

## Java 代码实现

```java
class Solution {
    public long maxSpending(int[][] values) {
        int m = values.length, n = values[0].length;
        // 最小堆：{value, shop, index}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        for (int i = 0; i < m; i++) {
            pq.offer(new int[]{values[i][n - 1], i, n - 1});
        }

        long ans = 0;
        long day = 1;
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            ans += (long) cur[0] * day;
            day++;
            int shop = cur[1], j = cur[2];
            if (j > 0) {
                pq.offer(new int[]{values[shop][j - 1], shop, j - 1});
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(MN logM)
- **空间复杂度**：O(M)

## 关键点总结

1. **贪心**：价值小的先买（天数小），价值大的后买（天数大）
2. **最小堆维护各商店当前可购买物品**
3. **每行非递增保证右边最小**：买完右边才能买左边
