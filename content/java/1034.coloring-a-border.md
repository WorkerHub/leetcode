## 题目描述

给定二维数组 grid 和起始点 (row, col)，将包含该点的连通分量的边界着色为指定颜色。边界定义为在矩阵边缘或至少有一个邻居不属于同一连通分量的格子。

**示例：**
```
输入：grid = [[1,1],[1,2]], row = 0, col = 0, color = 3
输出：[[3,3],[3,2]]
```

## 解题思路

DFS/BFS 找连通分量，判断边界后着色。先遍历找到所有连通分量格子，再判断哪些是边界并着色。

## Java 代码实现

```java
class Solution {
    public int[][] colorBorder(int[][] grid, int row, int col, int color) {
        int m = grid.length, n = grid[0].length;
        int originalColor = grid[row][col];
        boolean[][] visited = new boolean[m][n];
        List<int[]> border = new ArrayList<>();

        // DFS 找连通分量并标记边界
        dfs(grid, row, col, m, n, originalColor, visited, border);

        // 给边界着色
        for (int[] cell : border) {
            grid[cell[0]][cell[1]] = color;
        }
        return grid;
    }

    private void dfs(int[][] grid, int r, int c, int m, int n,
                     int originalColor, boolean[][] visited, List<int[]> border) {
        if (r < 0 || r >= m || c < 0 || c >= n) return;
        if (visited[r][c] || grid[r][c] != originalColor) return;

        visited[r][c] = true;
        boolean isBorder = false;

        // 在矩阵边缘
        if (r == 0 || r == m - 1 || c == 0 || c == n - 1) {
            isBorder = true;
        }

        // 检查四个方向
        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        for (int[] d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                if (grid[nr][nc] != originalColor && !visited[nr][nc]) {
                    isBorder = true;
                }
            }
            dfs(grid, nr, nc, m, n, originalColor, visited, border);
        }

        if (isBorder) {
            border.add(new int[]{r, c});
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m×n)
- **空间复杂度**：O(m×n)

## 关键点总结

1. **边界判定**：矩阵边缘 或 有邻居不属于连通分量
2. **先遍历后着色**：避免着色影响连通性判断
3. **visited 标记**：防止重复访问
