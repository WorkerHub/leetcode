## 题目描述

给定整数数组 nums，每次选择 nums[i] 获得该点数，同时必须删除所有等于 nums[i]-1 和 nums[i]+1 的元素。返回能获得的最大点数。

**示例：**
```
输入：nums = [2,2,3,3,3,4]
输出：9（删除三次3，获得 3+3+3=9）
```

## 解题思路

转化为打家劫舍问题：统计每个数字的总贡献，对连续数字做"选或不选"的 DP。

## Java 代码实现

```java
class Solution {
    public int deleteAndEarn(int[] nums) {
        int maxVal = 0;
        for (int num : nums) maxVal = Math.max(maxVal, num);

        // 统计每个数字的总点数
        int[] points = new int[maxVal + 1];
        for (int num : nums) points[num] += num;

        // 打家劫舍 DP
        int prev = 0, curr = 0;
        for (int point : points) {
            int temp = curr;
            curr = Math.max(curr, prev + point);
            prev = temp;
        }
        return curr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + M)，M 为数字范围
- **空间复杂度**：O(M)

## 关键点总结

1. **问题转化**：转化为打家劫舍问题
2. **点数统计**：points[i] = i × count(i)
3. **空间优化**：只需前两个状态
