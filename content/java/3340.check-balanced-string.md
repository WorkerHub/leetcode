## 题目描述

给你数字字符串 `num`，若奇数位（1 索引）数字之和等于偶数位数字之和，返回 `true`。

## 解题思路

遍历字符串，按 0 索引的奇偶性分别累加（0 索引偶数位对应 1 索引奇数位），比较两个和是否相等。

## Java 代码实现

```java
class Solution {
    public boolean isBalanced(String num) {
        int odd = 0, even = 0;
        for (int i = 0; i < num.length(); i++) {
            int d = num.charAt(i) - '0';
            if (i % 2 == 0) odd += d;   // 0 索引偶数 = 1 索引奇数位
            else even += d;
        }
        return odd == even;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 0 索引的偶数位（0,2,4...）对应 1 索引的奇数位（1,3,5...）
2. 两个和相等即为平衡字符串
