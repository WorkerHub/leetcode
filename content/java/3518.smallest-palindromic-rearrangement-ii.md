## 题目描述

给定回文字符串 `s` 和整数 `k`，返回所有回文重排中字典序第 `k` 小的字符串，不足 `k` 种则返回空字符串。

## 解题思路

回文串的字典序由前半部分决定，问题转化为求前半部分字符集的第 k 小多重集排列。逐位枚举：对每个位置从 a 到 z 枚举字符，用多重集排列数公式 `n!/(c1!*c2!*...)` 判断选该字符后的剩余排列数，若 `k <= count` 则选该字符，否则 `k -= count` 继续枚举。

## Java 代码实现

```java
import java.math.BigInteger;

class Solution {
    public String smallestPalindrome(String s, long k) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        int[] half = new int[26];
        char mid = 0;
        for (int i = 0; i < 26; i++) {
            half[i] = cnt[i] / 2;
            if (cnt[i] % 2 == 1) mid = (char)('a' + i);
        }
        int halfLen = 0;
        for (int v : half) halfLen += v;

        // 计算多重集排列数（上限 k，超出则返回 k+1）
        BigInteger bigK = BigInteger.valueOf(k);
        if (permCount(half, halfLen).compareTo(bigK) < 0) return "";

        StringBuilder res = new StringBuilder();
        for (int pos = 0; pos < halfLen; pos++) {
            for (int i = 0; i < 26; i++) {
                if (half[i] == 0) continue;
                half[i]--;
                BigInteger cnt2 = permCount(half, halfLen - pos - 1);
                if (bigK.compareTo(cnt2) <= 0) {
                    res.append((char)('a' + i));
                    break;
                }
                bigK = bigK.subtract(cnt2);
                half[i]++;
            }
        }

        String h = res.toString();
        StringBuilder full = new StringBuilder(h);
        if (mid != 0) full.append(mid);
        full.append(new StringBuilder(h).reverse());
        return full.toString();
    }

    private BigInteger permCount(int[] half, int total) {
        BigInteger res = factorial(total);
        for (int v : half) if (v > 1) res = res.divide(factorial(v));
        return res;
    }

    private BigInteger factorial(int n) {
        BigInteger r = BigInteger.ONE;
        for (int i = 2; i <= n; i++) r = r.multiply(BigInteger.valueOf(i));
        return r;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26)，n 为前半部分长度
- 空间复杂度：O(n)

## 关键点总结

1. 回文的字典序等价于其前半部分的字典序
2. 逐位确定：用剩余多重集排列数决定选哪个字符
3. 阶乘可能极大，使用 BigInteger 避免溢出
