## 题目描述

统计字符串 `s` 中回文子串的数目。

**示例：**
```
输入：s = "aaa"
输出：6（"a","a","a","aa","aa","aaa"）
```

## 解题思路

中心扩展法：对每个位置分别以奇数和偶数长度为中心向两边扩展。

## Java 代码实现

```java
class Solution {
    public int countSubstrings(String s) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度
            count += expand(s, i, i);
            // 偶数长度
            count += expand(s, i, i + 1);
        }
        return count;
    }

    private int expand(String s, int left, int right) {
        int count = 0;
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            count++;
            left--;
            right++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **中心扩展**：每个位置做两次扩展（奇/偶）
2. **计数**：每次扩展成功就是一个回文子串
3. **无需额外空间**：比 DP 的 O(n²) 空间更优
