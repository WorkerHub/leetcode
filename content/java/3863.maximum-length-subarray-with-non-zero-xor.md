## 题目描述

给你一个整数数组 `nums`，找到最长的连续子数组，使得子数组中所有元素的异或值不为 0。返回该最长子数组的长度。

## 解题思路

若全数组异或值 `total != 0`，直接返回 n。否则全数组异或为 0，去掉第一个元素或最后一个元素后异或不为 0，最长子数组长度为 n-1（特判长度为 1 时全为 0 的情况）。

## Java 代码实现

```java
class Solution {
    public int maxLengthSubarrayNonZeroXor(int[] nums) {
        int n = nums.length;
        int total = 0;
        for (int v : nums) total ^= v;

        // 全数组异或不为 0，直接返回 n
        if (total != 0) return n;

        // 全数组异或为 0，找最长的非零异或子数组
        // 去掉第一个非零元素或最后一个非零元素，长度为 n-1
        if (n == 1) return 0; // 单个元素为 0，无法构成非零异或子数组

        // 从左找第一个非零元素位置
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) {
                // 去掉 nums[i]，剩余子数组异或不为 0（因为 total=0 去掉一个非零元素后变非零）
                return n - 1;
            }
        }

        // 全为 0，任何子数组异或都为 0
        return 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 若全数组异或 != 0，答案为 n。
2. 若全数组异或 = 0，去掉一个非零元素可使剩余部分异或非零，答案为 n-1。
3. 若全为 0，任何子数组异或均为 0，答案为 0。
