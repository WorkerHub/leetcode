## 题目描述

给你数组 `nums`，求每个长度为 `k` 的子数组的美丽值：若有至少 `x` 个负整数则为第 `x` 小的负整数，否则为 0。

## Java 代码实现

```java
class Solution {
    public int[] getSubarrayBeauty(int[] nums, int k, int x) {
        int n = nums.length;
        int[] freq = new int[101]; // 偏移 50，映射 [-50,50] 到 [0,100]
        int[] ans = new int[n - k + 1];

        // 初始化前 k 个元素
        for (int i = 0; i < k; i++) freq[nums[i] + 50]++;

        ans[0] = findXthSmallest(freq, x);

        for (int i = k; i < n; i++) {
            freq[nums[i] + 50]++;           // 加入新元素
            freq[nums[i - k] + 50]--;       // 移除旧元素
            ans[i - k + 1] = findXthSmallest(freq, x);
        }
        return ans;
    }

    // 从 -50 到 -1 累积频次，找第 x 小的负数
    private int findXthSmallest(int[] freq, int x) {
        int count = 0;
        for (int val = -50; val < 0; val++) {
            count += freq[val + 50];
            if (count >= x) return val;
        }
        return 0;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n × 50)，固定范围遍历
- 空间复杂度：O(1)，频次数组大小固定

## 关键点总结

1. 元素范围 [-50, 50]，频次数组大小固定为 101
2. 查找第 x 小负数只遍历 [-50, -1]，固定 50 次
3. 滑动窗口：加入新元素、移除旧元素各 O(1)
