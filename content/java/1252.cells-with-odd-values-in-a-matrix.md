## 题目描述

m×n 矩阵初始全 0，给定操作 indices[i]=[ri,ci] 表示第 ri 行和第 ci 列全部加 1。执行所有操作后，返回奇数值单元格的数目。

**示例：**
```
输入：m = 2, n = 3, indices = [[0,1],[1,1]]
输出：6
```

## 解题思路

统计每行被加的次数和每列被加的次数。某格 (i,j) 的值 = row[i] + col[j]，为奇数当且仅当 row[i] 和 col[j] 奇偶不同。

## Java 代码实现

```java
class Solution {
    public int oddCells(int m, int n, int[][] indices) {
        int[] row = new int[m], col = new int[n];
        for (int[] idx : indices) {
            row[idx[0]]++;
            col[idx[1]]++;
        }
        
        // 统计奇数行数和奇数列数
        int oddRows = 0, oddCols = 0;
        for (int r : row) if (r % 2 != 0) oddRows++;
        for (int c : col) if (c % 2 != 0) oddCols++;
        
        // 奇数格 = 奇数行×偶数列 + 偶数行×奇数列
        return oddRows * (n - oddCols) + (m - oddRows) * oddCols;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k + m + n)，k 为操作次数
- **空间复杂度**：O(m + n)

## 关键点总结

1. **行列分离**：每格值 = 所在行被加次数 + 所在列被加次数
2. **奇偶性**：奇+偶=奇，偶+奇=奇，其他为偶
3. **数学公式**：oddRows×evenCols + evenRows×oddCols
