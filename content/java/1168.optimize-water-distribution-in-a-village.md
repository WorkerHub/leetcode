## 题目描述

n 栋房子，可在房子内建井（花费 wells[i]）或铺管道引水（pipes[i]=[house1,house2,cost]）。求为所有房子供水的最小总成本。

**示例：**
```
输入：n=3, wells=[1,2,2], pipes=[[1,2,1],[2,3,1]]
输出：3（建井1 + 管道1→2花费1 + 管道2→3花费1）
```

## 解题思路

引入虚拟节点 0 代表水源，建井转化为虚拟节点到房子的边。问题变为标准最小生成树（Kruskal + 并查集）。

## Java 代码实现

```java
class Solution {
    private int[] parent, rank;

    public int minCostToSupplyWater(int n, int[] wells, int[][] pipes) {
        // 构建边集：虚拟节点0到每栋房子 + 管道边
        List<int[]> edges = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            edges.add(new int[]{wells[i], 0, i + 1});
        }
        for (int[] p : pipes) {
            edges.add(new int[]{p[2], p[0], p[1]});
        }

        // 按成本排序
        edges.sort((a, b) -> a[0] - b[0]);

        // 并查集初始化
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int i = 0; i <= n; i++) parent[i] = i;

        int totalCost = 0, edgesUsed = 0;
        for (int[] e : edges) {
            if (union(e[1], e[2])) {
                totalCost += e[0];
                if (++edgesUsed == n) break;
            }
        }
        return totalCost;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private boolean union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;
        if (rank[rx] < rank[ry]) parent[rx] = ry;
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else { parent[ry] = rx; rank[rx]++; }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n+m) log(n+m))，排序边
- **空间复杂度**：O(n+m)

## 关键点总结

1. **虚拟节点技巧**：建井成本转为虚拟节点到房子的边
2. **Kruskal 算法**：按成本排序 + 并查集贪心选边
3. **MST 需要 n 条边**：连接 n+1 个节点（含虚拟节点）
4. **路径压缩 + 按秩合并**：优化并查集
