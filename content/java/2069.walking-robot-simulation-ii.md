## 题目描述

机器人在 width×height 网格上沿边界顺时针行走，实现 step(num)、getPos()、getDir() 操作。

## 解题思路

网格外周长为 `2*(width+height-2)`，step 时用步数取模周长定位边界位置。预计算边界每个位置的坐标和方向，O(1) 查询。特殊处理：机器人从未移动时方向为 East。

## Java 代码实现

### 方法一：周长取模 + 预计算路径（推荐）

```java
class Robot {
    private int[] x, y;
    private String[] dirs;
    private int perimeter, pos;
    private boolean moved = false;

    public Robot(int width, int height) {
        perimeter = 2 * (width + height - 2);
        x = new int[perimeter];
        y = new int[perimeter];
        dirs = new String[perimeter];
        int idx = 0;
        // 底边向东
        for (int i = 0; i < width - 1; i++) { x[idx] = i; y[idx] = 0; dirs[idx++] = "East"; }
        // 右边向北
        for (int i = 0; i < height - 1; i++) { x[idx] = width-1; y[idx] = i; dirs[idx++] = "North"; }
        // 顶边向西
        for (int i = 0; i < width - 1; i++) { x[idx] = width-1-i; y[idx] = height-1; dirs[idx++] = "West"; }
        // 左边向南
        for (int i = 0; i < height - 1; i++) { x[idx] = 0; y[idx] = height-1-i; dirs[idx++] = "South"; }
        pos = 0;
    }

    public void step(int num) {
        moved = true;
        pos = (pos + num) % perimeter;
    }

    public int[] getPos() {
        return new int[]{x[pos], y[pos]};
    }

    public String getDir() {
        if (!moved) return "East";
        return dirs[pos];
    }
}
```

## 复杂度分析

- 构造：O(perimeter)
- step/getPos/getDir：O(1)

## 关键点总结

1. 步数取模周长避免逐步模拟
2. 机器人移动后回到 (0,0) 时方向为 "South"（从左侧来），而非初始 "East"
3. 预计算边界路径 dirs 时，位置 0 对应的方向是 "East"（出发方向）
