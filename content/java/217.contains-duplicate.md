## 题目描述

给你一个整数数组 `nums`。如果任一值在数组中出现 **至少两次**，返回 `true`；如果数组中每个元素互不相同，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1]
输出：true
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：false
```

**示例 3：**

```
输入：nums = [1,1,1,3,3,4,3,2,4,2]
输出：true
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路

这是一道简单题，主要考察基础数据结构的使用。

**核心思想：**

判断数组中是否有重复元素，本质上是检查是否有两个相同的值。

**多种解法：**

1. **哈希集合**：遍历数组，将元素加入集合，如果已存在则返回 true
2. **排序**：排序后检查相邻元素是否相同
3. **集合长度**：将数组转为集合，比较长度是否变化

## Java 代码实现

### 方法一：哈希集合（推荐）⭐

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        // 使用集合检测重复
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (seen.contains(num)) {
                return true; // 发现重复，立即返回
            }
            seen.add(num);
        }
        return false;
    }
}
```

### 方法二：集合长度比较（简洁）

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        // 集合会自动去重，长度不同说明有重复
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }
        return set.size() < nums.length;
    }
}
```

### 方法三：排序后检查

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        // 排序后相同元素会相邻
        Arrays.sort(nums);
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1]) {
                return true;
            }
        }
        return false;
    }
}
```

### 方法四：使用 Stream（Java 8+）

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        // 使用 Stream 的 distinct 去重后比较长度
        return Arrays.stream(nums).distinct().count() < nums.length;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希集合（方法一） | O(N) | O(N) | 最优时间，可提前返回 |
| 集合长度（方法二） | O(N) | O(N) | 代码简洁 |
| 排序（方法三） | O(N log N) | O(log N) | 时间慢但空间更优 |
| Stream（方法四） | O(N) | O(N) | 代码最简洁 |

**推荐：** 方法一（哈希集合），遇到重复立即返回，性能最优

## 关键点总结

1. **集合特性**：HashSet 自动去重，可用于检测重复
2. **提前返回**：方法一遇到重复立即返回，不需遍历全部
3. **空间换时间**：使用 O(N) 空间换取 O(N) 时间
4. **排序思想**：排序后重复元素相邻，便于检测
5. **Java HashSet**：`contains` 和 `add` 操作平均 O(1)

## 易错点

1. **集合的 contains 操作**：
   ```java
   // 正确：HashSet 的 contains 是 O(1) 平均
   if (seen.contains(num))
   // 错误：如果误用 ArrayList，contains 是 O(N)
   ```

2. **排序修改原数组**：
   ```java
   // 方法三会修改原数组，如果不能修改需要先复制
   int[] sorted = nums.clone();
   Arrays.sort(sorted);
   ```

3. **整数装箱问题**：
   ```java
   // 使用 HashSet<Integer> 时，int 会自动装箱为 Integer
   // 比较用 contains 而不是 ==
   Set<Integer> seen = new HashSet<>();
   seen.contains(num); // 正确：equals 比较值
   ```

4. **空数组处理**：
   ```java
   // 题目保证 nums.length >= 1，但自测时注意
   int[] nums = {};  // 应返回 false
   ```

5. **大数值处理**：
   ```java
   // 题目说 -10^9 <= nums[i] <= 10^9
   // int 范围足够，但注意 HashSet 装箱时的性能
   ```

## 图解示例

```
示例：nums = [1,2,3,1]

方法一（哈希集合）：
遍历过程：
num=1: seen={} → seen={1}
num=2: seen={1} → seen={1,2}
num=3: seen={1,2} → seen={1,2,3}
num=1: seen={1,2,3}，1 已存在，返回 True

方法三（排序）：
排序前：[1,2,3,1]
排序后：[1,1,2,3]
检查相邻：nums[1]=1 == nums[0]=1，返回 True
```


   ```java
   public List<Integer> findDuplicates(int[] nums) {
       Set<Integer> seen = new HashSet<>();
       Set<Integer> duplicates = new HashSet<>();
       for (int num : nums) {
           if (!seen.add(num)) { // add 返回 false 说明已存在
               duplicates.add(num);
           }
       }
       return new ArrayList<>(duplicates);
   }
   ```
