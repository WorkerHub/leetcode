## 题目描述

每个班 `[pass, total]`，可加入 `extraStudents` 名必过学生，使所有班级的平均通过率最大。

## 解题思路

贪心：每次将额外学生加入增益最大的班级。增益 = `(p+1)/(t+1) - p/t`，用最大堆维护。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public double maxAverageRatio(int[][] classes, int extraStudents) {
        // 最大堆：以加入一名学生的增益为优先级（大根堆）
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> {
            // gain(b) - gain(a) > 0 则 b 优先（降序）
            // gain(p,t) = (p+1)/(t+1) - p/t
            double ga = (double)(a[0] + 1) / (a[1] + 1) - (double)a[0] / a[1];
            double gb = (double)(b[0] + 1) / (b[1] + 1) - (double)b[0] / b[1];
            return Double.compare(gb, ga); // 大增益优先
        });

        for (int[] c : classes) pq.offer(c.clone());

        for (int i = 0; i < extraStudents; i++) {
            int[] top = pq.poll();
            // 加入一名额外学生
            pq.offer(new int[]{top[0] + 1, top[1] + 1});
        }

        // 计算最终平均通过率
        double sum = 0;
        int n = pq.size();
        for (int[] c : pq) sum += (double) c[0] / c[1];
        return sum / n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + extraStudents) * log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：每次加入增益最大的班级
2. 增益 `(p+1)/(t+1) - p/t` 随班级人数增加而递减（边际递减）
3. 最大堆每次弹出增益最大的班级，更新后重新入堆
