## 题目描述

给你一个整数数组 `digits`，你可以通过按任意顺序连接其中某些数字来形成 **3 的倍数**，请你返回所能得到的**最大的 3 的倍数**。

由于答案可能不在整数范围内，请以字符串形式返回答案。如果无法得到答案，请返回一个空字符串 `""`。返回的结果不应包含不必要的前导零。

**示例 1：**
```
输入：digits = [8,1,9]
输出："981"
解释：981 = 9 * 109，是 3 的倍数，且是最大值。
```

**示例 2：**
```
输入：digits = [8,6,7,1,0]
输出："8760"
```

**示例 3：**
```
输入：digits = [1]
输出：""
```

**示例 4：**
```
输入：digits = [0,0,0,0,0,0]
输出："0"
```

**提示：**
- `1 <= digits.length <= 10^4`
- `0 <= digits[i] <= 9`

## 解题思路

一个数是 3 的倍数，当且仅当它的**各位数字之和是 3 的倍数**。

**贪心策略：**

设所有数字之和为 `S`，`r = S % 3`：

- **r == 0**：直接用所有数字组成最大数（降序排列）。
- **r == 1**：需要去掉"余数贡献为 1 的最小代价"：
  - 方案 A：去掉 1 个余数为 1 的最小数字（如 1, 4, 7 中最小的那个）
  - 方案 B：去掉 2 个余数为 2 的最小数字（如最小的两个属于 {2,5,8} 的数）
  - 选代价最小（去掉后剩余数字最多且最大）的方案
- **r == 2**：类似地：
  - 方案 A：去掉 1 个余数为 2 的最小数字
  - 方案 B：去掉 2 个余数为 1 的最小数字

**最后组合：** 用剩余数字降序排列组成最大数。注意处理全为 0 的情况（返回 "0" 而非 "000"）。

## Java 代码实现

### 方法一：贪心（推荐）

```java
import java.util.*;

class Solution {
    public String largestMultipleOfThree(int[] digits) {
        Arrays.sort(digits); // 升序排列
        int total = 0;
        for (int d : digits) total += d;
        int r = total % 3;
        
        if (r == 0) {
            return buildResult(digits, new int[0]);
        }
        
        // 按余数分组
        // rem[k] 存储所有 d%3==k 的数字（已按升序），方便取最小
        List<Integer>[] rem = new List[3];
        for (int i = 0; i < 3; i++) rem[i] = new ArrayList<>();
        for (int d : digits) rem[d % 3].add(d);
        
        String best = "";
        
        if (r == 1) {
            // 方案 A：去掉 1 个余数为 1 的最小数字
            String optA = tryRemove(digits, rem[1], 1);
            // 方案 B：去掉 2 个余数为 2 的最小数字
            String optB = tryRemove(digits, rem[2], 2);
            best = isBetter(optA, optB) ? optA : optB;
        } else { // r == 2
            // 方案 A：去掉 1 个余数为 2 的最小数字
            String optA = tryRemove(digits, rem[2], 1);
            // 方案 B：去掉 2 个余数为 1 的最小数字
            String optB = tryRemove(digits, rem[1], 2);
            best = isBetter(optA, optB) ? optA : optB;
        }
        
        return best;
    }
    
    // 从 digits 中移除 candidates 的前 count 个元素后，构建最大数字字符串
    private String tryRemove(int[] digits, List<Integer> candidates, int count) {
        if (candidates.size() < count) return "";
        
        // 标记要移除的数字（从 candidates 取 count 个最小的）
        int[] toRemove = new int[count];
        for (int i = 0; i < count; i++) toRemove[i] = candidates.get(i);
        
        // 构建剩余数字列表
        int[] remaining = digits.clone();
        int[] used = remaining.clone();
        
        // 从 digits 中移除 toRemove 中的数字（每个移除一次）
        List<Integer> rem = new ArrayList<>();
        boolean[] removed = new boolean[digits.length];
        
        for (int rv : toRemove) {
            // 找第一个未被移除的、值为 rv 的元素
            for (int i = 0; i < digits.length; i++) {
                if (!removed[i] && digits[i] == rv) {
                    removed[i] = true;
                    break;
                }
            }
        }
        
        // 收集剩余数字（降序排列）
        List<Integer> remList = new ArrayList<>();
        for (int i = 0; i < digits.length; i++) {
            if (!removed[i]) remList.add(digits[i]);
        }
        
        return buildString(remList);
    }
    
    // 从 digits（升序）中移除指定元素并组成降序字符串
    private String buildResult(int[] digits, int[] removeList) {
        List<Integer> list = new ArrayList<>();
        for (int d : digits) list.add(d);
        for (int rv : removeList) list.remove(Integer.valueOf(rv));
        return buildString(list);
    }
    
    private String buildString(List<Integer> list) {
        if (list.isEmpty()) return "";
        list.sort(Collections.reverseOrder()); // 降序
        StringBuilder sb = new StringBuilder();
        for (int d : list) sb.append(d);
        String res = sb.toString();
        // 处理前导零（全为 0 时返回 "0"）
        return res.charAt(0) == '0' ? "0" : res;
    }
    
    // 比较两个数字字符串，a 更大返回 true
    private boolean isBetter(String a, String b) {
        if (a.isEmpty()) return false;
        if (b.isEmpty()) return true;
        if (a.length() != b.length()) return a.length() > b.length();
        return a.compareTo(b) > 0;
    }
}
```

### 方法二：贪心（简洁版）

```java
import java.util.*;

class Solution {
    public String largestMultipleOfThree(int[] digits) {
        // 统计每种数字的频率
        int[] freq = new int[10];
        int total = 0;
        for (int d : digits) {
            freq[d]++;
            total += d;
        }
        
        int r = total % 3;
        if (r == 0) return buildMax(freq);
        
        String best = "";
        
        if (r == 1) {
            // 方案 A：从 {1,4,7} 中去掉最小的一个
            String optA = removeMin(freq, 1, 1);
            // 方案 B：从 {2,5,8} 中去掉最小的两个
            String optB = removeMin(freq, 2, 2);
            best = isBetter(optA, optB) ? optA : optB;
        } else {
            // 方案 A：从 {2,5,8} 中去掉最小的一个
            String optA = removeMin(freq, 2, 1);
            // 方案 B：从 {1,4,7} 中去掉最小的两个
            String optB = removeMin(freq, 1, 2);
            best = isBetter(optA, optB) ? optA : optB;
        }
        
        return best;
    }
    
    // 从余数为 mod 的最小数字开始，移除 count 个
    private String removeMin(int[] freq, int mod, int count) {
        int[] f = freq.clone();
        for (int d = mod; d <= 9 && count > 0; d += 3) {
            while (f[d] > 0 && count > 0) {
                f[d]--;
                count--;
            }
        }
        if (count > 0) return ""; // 数量不足
        return buildMax(f);
    }
    
    private String buildMax(int[] freq) {
        StringBuilder sb = new StringBuilder();
        for (int d = 9; d >= 0; d--) {
            for (int i = 0; i < freq[d]; i++) sb.append(d);
        }
        if (sb.length() == 0) return "";
        return sb.charAt(0) == '0' ? "0" : sb.toString();
    }
    
    private boolean isBetter(String a, String b) {
        if (a.isEmpty()) return false;
        if (b.isEmpty()) return true;
        if (a.length() != b.length()) return a.length() > b.length();
        return a.compareTo(b) > 0;
    }
}
```

## 关键点总结

1. **核心定理**：数是 3 的倍数当且仅当各位数字之和是 3 的倍数。
2. **贪心策略**：根据总和的余数 r，决定去掉哪些数字使余数归零。r==1 时去 1 个余 1 或 2 个余 2；r==2 时去 1 个余 2 或 2 个余 1。
3. **最大化结果**：优先保留更多数字（位数更多），同等位数时保留数值更大的。
4. **前导零处理**：如果所有数字都是 0，结果为 "0"，而不是 "" 或 "000"。
5. **两方案比较**：不能贪心只选一种方案，要把两种方案都算出来，选更优的。

## 易错点

- 去掉"最小代价"的数字：应该去掉满足余数条件的**最小数字**（值最小），而不是位置最靠前的。
- 前导零情况：如果结果字符串第一个字符是 '0'，说明剩余数字全为 0，返回 "0"。
- 两种方案都可能为空（无法实施），需要检查并跳过。
- 方案 B（去两个）在对应余数类别数量不足 2 个时不可行，必须判断。
