## 题目描述

给定整数数组 `nums` 和整数 `k`，每次操作可将某元素加 1 或减 1，最多操作 `k` 次，返回操作后出现频率最高的元素的最大可能频率。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxFrequency(int[] nums, int k) {
        Arrays.sort(nums);
        int left = 0;
        long windowSum = 0;
        int ans = 1;

        for (int right = 0; right < nums.length; right++) {
            windowSum += nums[right];
            // 将窗口内所有元素变为 nums[right] 的代价
            while ((long) nums[right] * (right - left + 1) - windowSum > k) {
                windowSum -= nums[left];
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序为主要开销
- 空间复杂度：O(1)

## 关键点总结

1. 排序后最优目标值一定是某个数组元素（窗口最大值）
2. 代价公式：`target * len - windowSum`，超出 k 则收缩左边界
3. 使用 `long` 防止代价计算溢出
