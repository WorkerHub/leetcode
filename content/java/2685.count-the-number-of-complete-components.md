## 题目描述

给你 `n` 个节点的无向图，若连通分量是完全图（任意两节点间都有边），则为**完全连通分量**，返回其数量。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countCompleteComponents(int n, int[][] edges) {
        List<Integer>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }

        boolean[] visited = new boolean[n];
        int ans = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                // BFS 找连通分量
                List<Integer> comp = new ArrayList<>();
                Queue<Integer> queue = new LinkedList<>();
                queue.offer(i);
                visited[i] = true;
                while (!queue.isEmpty()) {
                    int u = queue.poll();
                    comp.add(u);
                    for (int v : graph[u]) {
                        if (!visited[v]) {
                            visited[v] = true;
                            queue.offer(v);
                        }
                    }
                }
                int k = comp.size();
                // 统计分量内的边数（每条边被两端各计一次，除以2）
                int edgeCount = 0;
                for (int u : comp) edgeCount += graph[u].size();
                edgeCount /= 2;
                if (edgeCount == k * (k - 1) / 2) ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 完全图：k 个节点恰好 `k*(k-1)/2` 条边
2. 单节点（孤立节点）也是完全连通分量
