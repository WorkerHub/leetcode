## 题目描述

给你两个等长正整数数组 `nums` 和 `target`，每次操作可选两个不同下标 `i`、`j`，将 `nums[i]` 加 2，`nums[j]` 减 2。返回使 `nums` 与 `target` 相似（每个元素出现频率相同）所需的最少操作次数。

## 解题思路

操作不改变奇偶性，因此奇数只能匹配奇数，偶数只能匹配偶数。将两个数组分别按奇偶分组排序后一一对应，排序匹配是最优的（贪心）。操作次数 = 总绝对差 / 4（每次操作使总差减少 4）。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public long makeSimilar(int[] nums, int[] target) {
        // 按奇偶分组
        List<Integer> numsOdd = new ArrayList<>(), numsEven = new ArrayList<>();
        List<Integer> tgtOdd = new ArrayList<>(), tgtEven = new ArrayList<>();
        for (int x : nums) { if (x % 2 == 1) numsOdd.add(x); else numsEven.add(x); }
        for (int x : target) { if (x % 2 == 1) tgtOdd.add(x); else tgtEven.add(x); }

        Collections.sort(numsOdd);
        Collections.sort(numsEven);
        Collections.sort(tgtOdd);
        Collections.sort(tgtEven);

        long total = 0;
        for (int i = 0; i < numsOdd.size(); i++) {
            total += Math.abs(numsOdd.get(i) - tgtOdd.get(i));
        }
        for (int i = 0; i < numsEven.size(); i++) {
            total += Math.abs(numsEven.get(i) - tgtEven.get(i));
        }
        // 每次操作减少总绝对差 4
        return total / 4;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 操作不改变奇偶性，奇数只能匹配奇数，偶数只能匹配偶数
2. 排序后一一对应是最优匹配（贪心）
3. 操作次数 = 总绝对差 / 4（一次操作 +2 和 -2 共影响 4 的总差）
