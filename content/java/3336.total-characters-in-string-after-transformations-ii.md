## 题目描述

给你字符串 `s`、整数 `t` 和长度为 26 的数组 `nums`，字符 `i` 每次变为接下来 `nums[i]` 个字符（循环），`t` 可达 10^9，返回 `t` 次转换后字符串长度（模 10^9+7）。

## 解题思路

构造 26x26 转移矩阵 M：`M[j][i] = 1` 表示字符 i 转换后包含字符 j。由于 t 很大，用矩阵快速幂计算 M^t，再乘以初始字符计数向量，求所有字母数量之和。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int lengthAfterTransformations(String s, int t, List<Integer> nums) {
        // 构建转移矩阵 M[j][i]：字符 i 转换后产生字符 (i+1)...(i+nums[i]) mod 26
        long[][] M = new long[26][26];
        for (int i = 0; i < 26; i++)
            for (int k = 1; k <= nums.get(i); k++)
                M[(i + k) % 26][i]++;

        long[][] Mt = matPow(M, t);

        // 初始字符计数
        long[] cnt = new long[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        long ans = 0;
        for (int j = 0; j < 26; j++) {
            long val = 0;
            for (int i = 0; i < 26; i++) val = (val + Mt[j][i] * cnt[i]) % MOD;
            ans = (ans + val) % MOD;
        }
        return (int) ans;
    }

    private long[][] matMul(long[][] A, long[][] B) {
        int n = 26;
        long[][] C = new long[n][n];
        for (int i = 0; i < n; i++)
            for (int k = 0; k < n; k++) {
                if (A[i][k] == 0) continue;
                for (int j = 0; j < n; j++)
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
            }
        return C;
    }

    private long[][] matPow(long[][] M, long p) {
        int n = 26;
        long[][] R = new long[n][n];
        for (int i = 0; i < n; i++) R[i][i] = 1; // 单位矩阵
        while (p > 0) {
            if ((p & 1) == 1) R = matMul(R, M);
            M = matMul(M, M);
            p >>= 1;
        }
        return R;
    }
}
```

## 复杂度分析

- 时间复杂度：O(26^3 * log t + |s|)，矩阵快速幂
- 空间复杂度：O(26^2)

## 关键点总结

1. 转移矩阵 M[j][i] 表示字符 i 转换后贡献给字符 j 的数量
2. t 次转换对应矩阵 M 的 t 次幂，用快速幂实现
3. 26x26 矩阵乘法是常数级，整体复杂度 O(26^3 log t)
