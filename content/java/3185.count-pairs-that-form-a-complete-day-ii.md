## 题目描述

与 3184 相同（`(hours[i] + hours[j]) % 24 == 0` 的数对数量），但数组长度最大 5×10^5，答案需用 `long` 返回。

## 解题思路

与 3184 完全相同，用大小为 24 的计数数组统计余数，一次遍历完成。因数组较大，答案用 `long`。

## Java 代码实现

```java
class Solution {
    public long countCompleteDayPairs(int[] hours) {
        int[] cnt = new int[24];
        long ans = 0;
        for (int h : hours) {
            int r = h % 24;
            int need = (24 - r) % 24;
            ans += cnt[need]; // 使用 long 避免溢出
            cnt[r]++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 算法与 3184 完全相同，只需将返回值改为 `long`
2. 固定 24 个桶统计余数，效率优于哈希表
3. 答案可能超过 int 范围（最多约 (5×10^5)^2/2），需用 `long`
