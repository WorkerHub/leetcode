## 题目描述

有一个特殊的正方形房间，每面墙上都有一面镜子。除西南角以外，每个角落都有一个接受器，编号为 0、1 和 2 。

正方形房间的墙壁长度为 p，一束激光从西南角射出，首先会与东墙相遇，入射点到接收器 0 的距离为 q 。

返回光线最先遇到的接收器的编号（保证光线最终会遇到一个接收器）。

**示例 1：**
```
输入：p = 2, q = 1
输出：2
解释：光线在第一次反射后到达接收器 2。
```

**示例 2：**
```
输入：p = 3, q = 1
输出：1
```

**提示：**
- 1 <= q <= p <= 1000

## 题目理解

房间布局：
```
接收器1 -------- 接收器2
  |                |
  |                |
  |                |
激光源 ---------- 接收器0
(西南角)
```

- 正方形边长为 p
- 激光从 (0, 0) 射出，首先与东墙相遇于 (p, q)
- 三个接收器位置：
  - 接收器 0：东南角 (p, 0)
  - 接收器 1：西北角 (0, p)
  - 接收器 2：东北角 (p, p)

## 解题思路

这道题看似复杂，实际上可以通过**数学方法**巧妙求解。

**核心思想：镜像展开**

与其模拟光线反射，不如将房间镜像展开：
- 水平方向：每次碰到墙就展开一个镜像房间
- 竖直方向：每次碰到墙就展开一个镜像房间

光线在展开后的平面中**直线前进**，直到碰到某个接收器。

**数学分析：**

1. 设光线到达点 (m×p, n×q)，其中 m, n 是最小的正整数使得 m×p = n×q
   - 即 m/n = q/p，化简得 m = q/gcd(p,q), n = p/gcd(p,q)

2. 根据 m, n 的奇偶性判断接收器：
   - m 偶，n 奇 → 接收器 0（东南角）
   - m 奇，n 奇 → 接收器 1（西北角）
   - m 奇，n 偶 → 接收器 2（东北角）

## Java 代码实现

### 方法一：数学方法（推荐）

```java
class Solution {
    public int mirrorReflection(int p, int q) {
        // 求最大公约数
        int g = gcd(p, q);

        // 化简后的倍数
        int m = q / g; // 水平方向的房间数
        int n = p / g; // 竖直方向的房间数

        // 根据奇偶性判断
        if (m % 2 == 0) {
            return 0; // 接收器 0
        } else if (n % 2 == 0) {
            return 2; // 接收器 2
        } else {
            return 1; // 接收器 1
        }
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(a, b % a);
    }
}
```

**代码说明：**
- 使用 gcd 化简 p 和 q
- 根据化简后的奇偶性判断接收器

## 复杂度分析

- **时间复杂度**：O(log(min(p, q)))，gcd 的时间复杂度。
- **空间复杂度**：O(1)。

## 图解示例

**示例 1**：p = 2, q = 1

```
gcd(2, 1) = 1
m = 1/1 = 1 (奇数)
n = 2/1 = 2 (偶数)
→ 接收器 2
```

**示例 2**：p = 3, q = 1

```
gcd(3, 1) = 1
m = 1/1 = 1 (奇数)
n = 3/1 = 3 (奇数)
→ 接收器 1
```

## 关键点总结

1. **镜像展开**：将反射问题转化为直线运动
2. **最大公约数**：化简 p 和 q 到最简形式
3. **奇偶判断**：根据化简后的奇偶性确定接收器
4. **数学规律**：
   - m 偶 → 接收器 0
   - m 奇，n 偶 → 接收器 2
   - m 奇，n 奇 → 接收器 1

## 易错点

1. **m 和 n 的定义混淆**：注意 m = q/gcd，n = p/gcd

2. **奇偶判断顺序**：先判断 m 偶（接收器 0），再判断 n 偶（接收器 2），否则接收器 1

3. **Java 中 gcd**：需要自行实现或使用 BigInteger.gcd()
