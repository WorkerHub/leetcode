## 题目描述

给你字符串 `word1` 和 `word2`，返回 `word1` 中能重排为包含 `word2` 所有字符的子字符串数量。

## 解题思路

滑动窗口：子串能包含 word2 的重排等价于子串中各字符数量均不少于 word2 中对应字符数量。维护窗口 [left, right]，当窗口满足条件时，以 left 开头、以 right 及以后位置结尾的子串均满足，计数 `n - right`，然后缩小左端继续统计。

## Java 代码实现

```java
class Solution {
    public long validSubstringCount(String word1, String word2) {
        int[] need = new int[26];
        for (char c : word2.toCharArray()) need[c - 'a']++;
        // deficit = 尚未满足需求的字符种数
        int deficit = 0;
        for (int x : need) if (x > 0) deficit++;

        int[] have = new int[26];
        long ans = 0;
        int left = 0, n = word1.length();

        for (int right = 0; right < n; right++) {
            int ci = word1.charAt(right) - 'a';
            have[ci]++;
            if (need[ci] > 0 && have[ci] == need[ci]) deficit--; // 满足一种字符

            // 当窗口满足条件时，以 left 开头、right 及以后结尾的子串均有效
            while (deficit == 0) {
                ans += n - right;
                int lci = word1.charAt(left) - 'a';
                have[lci]--;
                if (need[lci] > 0 && have[lci] < need[lci]) deficit++; // 破坏一种字符
                left++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(|word1| + |word2|)
- 空间复杂度：O(26) = O(1)

## 关键点总结

1. 子串能包含 word2 重排 = 子串各字符数量均 >= word2 对应数量
2. 窗口 [left, right] 满足时，以 left 开头、right 到 n-1 结尾的 `n-right` 个子串均满足
3. `deficit` 记录尚未满足的字符种数，为 0 时窗口有效
