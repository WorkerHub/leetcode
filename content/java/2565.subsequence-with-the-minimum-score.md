## 题目描述

给你字符串 `s` 和 `t`，每次操作从 `t` 中删除一个字符，返回使 `t` 成为 `s` 的子序列所需的最少删除数（等价于删除 `t` 中某连续子串后前后缀能匹配 `s`）。

## 解题思路

预计算前缀匹配数组 `pre[i]`（t[0..i-1] 能匹配到 s 的位置）和后缀匹配数组 `suf[i]`（t[i..m-1] 匹配 s 后缀需从 s 的哪个位置开始）。枚举删除起点 l，利用 `suf` 的单调性二分找最短合法删除区间。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minimumScore(String s, String t) {
        int m = t.length(), n = s.length();

        // pre[i] = t[0..i-1] 在 s 中最多匹配到 s 的前 pre[i] 个字符
        int[] pre = new int[m + 1];
        int j = 0;
        for (int i = 0; i < m; i++) {
            if (j < n && t.charAt(i) == s.charAt(j)) j++;
            pre[i + 1] = j;
        }

        // suf[i] = t[i..m-1] 匹配 s 后缀，需要 s 从位置 suf[i] 开始
        int[] suf = new int[m + 1];
        suf[m] = n;
        j = n - 1;
        for (int i = m - 1; i >= 0; i--) {
            if (j >= 0 && t.charAt(i) == s.charAt(j)) j--;
            suf[i] = j + 1;
        }

        int ans = m; // 最多删除 m 个
        for (int l = 0; l <= m; l++) {
            // 前缀 t[0..l-1] 匹配到 s[0..pre[l]-1]
            // 二分找最小 r >= l 使 suf[r] >= pre[l]
            int lo = l, hi = m;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (suf[mid] >= pre[l]) hi = mid;
                else lo = mid + 1;
            }
            ans = Math.min(ans, lo - l);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((m + n) + m log m)
- **空间复杂度**：O(m)

## 关键点总结

1. 前缀数组 `pre[i]` 和后缀数组 `suf[i]` 各 O(m+n) 预计算
2. `suf` 数组具有单调不减性，可用二分查找
3. 枚举删除起点 l，二分找最短区间，答案取最小值
