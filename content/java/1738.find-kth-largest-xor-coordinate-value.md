## 题目描述

给你 `m x n` 矩阵 `matrix` 和整数 `k`，坐标 `(a,b)` 的值为左上角到 `(a,b)` 所有元素的 XOR。返回所有坐标值中第 `k` 大的值。

## 解题思路

用二维前缀异或预处理：`prefix[i][j] = prefix[i-1][j] ^ prefix[i][j-1] ^ prefix[i-1][j-1] ^ matrix[i][j]`，然后对所有值排序求第 k 大，或用最小堆维护前 k 大。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int kthLargestValue(int[][] matrix, int k) {
        int m = matrix.length, n = matrix[0].length;

        // 原地计算二维前缀异或
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i > 0) matrix[i][j] ^= matrix[i - 1][j];
                if (j > 0) matrix[i][j] ^= matrix[i][j - 1];
                if (i > 0 && j > 0) matrix[i][j] ^= matrix[i - 1][j - 1];
            }
        }

        // 最小堆维护前 k 大
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                minHeap.offer(matrix[i][j]);
                if (minHeap.size() > k) minHeap.poll();
            }
        }

        return minHeap.peek();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(mn log k)
- **空间复杂度**：O(k)

## 关键点总结

1. 二维前缀异或：通过三个邻居异或推导当前坐标值
2. 最小堆维护前 k 大，堆顶即为第 k 大
