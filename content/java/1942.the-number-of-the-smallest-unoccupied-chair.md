## 题目描述

n 个朋友按到达时间依次就坐编号最小的空椅子，离开后椅子释放，给你 `targetFriend` 的索引，返回他坐的椅子编号。

## 解题思路

双堆模拟：`available` 最小堆存可用椅子编号，`occupied` 最小堆存 `(离开时间, 椅子编号)`。每次处理到达事件前先释放已离开的椅子，再取最小椅子。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int smallestChair(int[][] times, int targetFriend) {
        int n = times.length;
        int targetArrival = times[targetFriend][0];

        // 按到达时间排序（记录原始索引）
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> times[a][0] - times[b][0]);

        // 可用椅子最小堆
        PriorityQueue<Integer> available = new PriorityQueue<>();
        for (int i = 0; i < n; i++) available.offer(i);

        // 已占用：(离开时间, 椅子编号)
        PriorityQueue<int[]> occupied = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));

        for (int idx : order) {
            int arrival = times[idx][0], leaving = times[idx][1];
            // 释放已离开的椅子
            while (!occupied.isEmpty() && occupied.peek()[0] <= arrival)
                available.offer(occupied.poll()[1]);
            int chair = available.poll();
            if (idx == targetFriend) return chair;
            occupied.offer(new int[]{leaving, chair});
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 按到达时间排序，模拟就座过程
2. `occupied` 堆按离开时间排序，处理到达时先释放
3. `available` 堆保证取出编号最小的椅子
