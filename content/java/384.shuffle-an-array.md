## 题目描述

给你一个整数数组 `nums`，设计算法来打乱一个没有重复元素的数组。打乱后，数组的所有排列应该是**等可能**的。

实现 `Solution` class:

- `Solution(int[] nums)` 使用整数数组 `nums` 初始化对象
- `int[] reset()` 重设数组到它的初始状态并返回
- `int[] shuffle()` 返回数组随机打乱后的结果

**示例 1:**

```
输入
["Solution", "shuffle", "reset", "shuffle"]
[[[1, 2, 3]], [], [], []]
输出
[null, [3, 1, 2], [1, 2, 3], [1, 3, 2]]

解释
Solution solution = new Solution([1, 2, 3]);
solution.shuffle();    // 打乱数组 [1,2,3] 并返回结果。任何 [1,2,3]的排列返回的概率应该相同。例如，返回 [3, 1, 2]
solution.reset();      // 重设数组到它的初始状态 [1, 2, 3] 。返回 [1, 2, 3]
solution.shuffle();    // 随机返回数组 [1, 2, 3] 打乱后的结果。例如，返回 [1, 3, 2]
```

**提示:**

- `1 <= nums.length <= 50`
- `-10^6 <= nums[i] <= 10^6`
- `nums` 中的所有元素都是**唯一**的
- 最多可以调用 `10^4` 次 `reset` 和 `shuffle`

## 解题思路

本题是经典的**数组洗牌**问题，关键在于保证所有排列的概率相等。

### 核心算法：Fisher-Yates 洗牌算法（Knuth 洗牌）

**算法思想：**

从后向前遍历数组，对于位置 `i`，从 `[0, i]` 范围内随机选择一个索引 `j`，交换 `nums[i]` 和 `nums[j]`。

**为什么是等概率的？**

- 第 n 个位置：从 n 个元素中选择，每个元素概率 1/n
- 第 n-1 个位置：从剩余 n-1 个元素中选择，每个元素概率 1/(n-1)
- 总概率：1/n × 1/(n-1) × ... × 1/1 = 1/n!

每种排列的概率都是 1/n!，完全随机。

**算法流程：**

```
for i from n-1 down to 1:
    j = random(0, i)  # 从 [0, i] 中随机选择
    swap(nums[i], nums[j])
```

## Java 代码实现

### 方法一：Fisher-Yates 洗牌算法（推荐）⭐

```java
import java.util.Random;

class Solution {
    private int[] original; // 保存原始数组的副本
    private int[] array;    // 工作数组
    private Random random;

    public Solution(int[] nums) {
        original = nums.clone(); // 保存原始数组的副本
        array = nums.clone();    // 工作数组初始化
        random = new Random();
    }

    /** 重置为原始数组，时间复杂度: O(n) */
    public int[] reset() {
        array = original.clone();
        return array;
    }

    /**
     * Fisher-Yates 洗牌算法（从后向前）
     * 时间复杂度: O(n)
     * 空间复杂度: O(1) - 原地修改
     */
    public int[] shuffle() {
        int n = array.length;

        // 从后向前遍历
        for (int i = n - 1; i > 0; i--) {
            // 在 [0, i] 范围内随机选择一个索引
            int j = random.nextInt(i + 1);
            // 交换元素
            int temp = array[i];
            array[i] = array[j];
            array[j] = temp;
        }

        return array;
    }
}
```

### 方法二：从前向后的洗牌算法

```java
import java.util.Random;

class Solution {
    private int[] original;
    private int[] array;
    private Random random;

    public Solution(int[] nums) {
        original = nums.clone();
        array = nums.clone();
        random = new Random();
    }

    public int[] reset() {
        array = original.clone();
        return array;
    }

    /** 从前向后的 Fisher-Yates 算法，时间复杂度: O(n) */
    public int[] shuffle() {
        int n = array.length;

        // 从前向后遍历
        for (int i = 0; i < n; i++) {
            // 在 [i, n-1] 范围内随机选择
            int j = i + random.nextInt(n - i);
            // 交换元素
            int temp = array[i];
            array[i] = array[j];
            array[j] = temp;
        }

        return array;
    }
}
```

### 方法三：使用 Collections.shuffle（简洁写法）

```java
import java.util.*;

class Solution {
    private int[] original;
    private List<Integer> list;
    private Random random;

    public Solution(int[] nums) {
        original = nums.clone();
        list = new ArrayList<>();
        for (int num : nums) {
            list.add(num);
        }
        random = new Random();
    }

    public int[] reset() {
        return original.clone();
    }

    /**
     * 使用 Collections.shuffle() 内置函数
     * 底层实现也是 Fisher-Yates 算法
     * 时间复杂度: O(n)
     */
    public int[] shuffle() {
        Collections.shuffle(list, random);
        int[] result = new int[list.size()];
        for (int i = 0; i < list.size(); i++) {
            result[i] = list.get(i);
        }
        return result;
    }
}
```

## 复杂度分析

**时间复杂度：**
- `Solution(nums)`: O(n) - 复制数组
- `reset()`: O(n) - 复制数组
- `shuffle()`: O(n) - 遍历数组一次

**空间复杂度：** O(n)
- 需要保存原始数组的副本
- 洗牌操作本身是 O(1) 原地操作

## 关键点总结

1. **Fisher-Yates 算法**：最经典高效的洗牌算法，保证等概率
2. **原地操作**：不需要额外数组，直接在原数组上交换元素
3. **保存原始状态**：需要保存一份原始数组的副本用于 reset
4. **从后向前 vs 从前向后**：两种方向都可以，效果相同
5. **随机数范围**：关键是每次从 `[0, i]` 或 `[i, n-1]` 中随机选择

## 易错点

1. **随机数范围错误**：
   - 错误：`random.nextInt(i)` - 范围太小，不包含 i
   - 正确：`random.nextInt(i + 1)` - 包含当前位置 i

2. **不保存原始数组**：必须保存副本，否则 reset 无法恢复

3. **使用错误的洗牌算法**：简单的随机交换不能保证等概率
   ```java
   // 错误示例：每个位置从全部范围随机交换
   for (int i = 0; i < n; i++) {
       int j = random.nextInt(n); // 范围不对，不是等概率
       swap(arr[i], arr[j]);
   }
   ```

4. **Java 数组复制**：使用 `clone()` 或 `Arrays.copyOf()` 进行深拷贝

## 数学证明

**为什么 Fisher-Yates 是等概率的？**

对于长度为 n 的数组，总共有 n! 种排列。

以第一个位置为例，证明每个元素出现在第一个位置的概率都是 1/n：

- 算法从最后一个位置开始，每次从前面的元素中随机选择
- 第一个位置最后被确定（如果从后向前）
- 每个元素被选到第一个位置的概率 = 1/n

严格证明需要用到概率论和数学归纳法，这里给出直观理解：
- 每一步的随机选择都是独立的
- 所有可能的交换序列概率相等
- 最终每种排列的概率都是 1/n!
