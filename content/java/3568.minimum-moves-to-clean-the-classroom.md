## 题目描述

给定字符矩阵 `classroom`，从起点 `'S'` 出发，经过含 `'L'` 的格子时自动清除垃圾，不能进入 `'X'`，求清除所有垃圾的最少步数，无法完成返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minMoves(String[] classroom) {
        int m = classroom.length, n = classroom[0].length();
        // 收集垃圾位置和起点
        Map<Integer, Integer> litterId = new HashMap<>();
        int startR = 0, startC = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                char ch = classroom[r].charAt(c);
                if (ch == 'S') {
                    startR = r; startC = c;
                } else if (ch == 'L') {
                    litterId.put(r * n + c, litterId.size());
                }
            }
        }

        int k = litterId.size();
        if (k == 0) return 0;

        int fullMask = (1 << k) - 1;
        int initMask = litterId.getOrDefault(startR * n + startC, -1);
        initMask = initMask >= 0 ? (1 << initMask) : 0;

        // BFS 状态：(行, 列, 已清除掩码)
        int[][][] dist = new int[m][n][1 << k];
        for (int[][] a : dist) for (int[] b : a) Arrays.fill(b, -1);
        dist[startR][startC][initMask] = 0;

        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{startR, startC, initMask, 0});

        int[] dr = {0, 0, 1, -1};
        int[] dc = {1, -1, 0, 0};

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], mask = cur[2], steps = cur[3];
            if (mask == fullMask) return steps;

            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                if (classroom[nr].charAt(nc) == 'X') continue;
                int newMask = mask;
                Integer lid = litterId.get(nr * n + nc);
                if (lid != null) newMask |= (1 << lid);
                if (dist[nr][nc][newMask] == -1) {
                    dist[nr][nc][newMask] = steps + 1;
                    queue.offer(new int[]{nr, nc, newMask, steps + 1});
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 2^k)，k 为垃圾数量
- 空间复杂度：O(m * n * 2^k)

## 关键点总结

1. 状态压缩 BFS：状态为 (位置, 已清除垃圾掩码)
2. 垃圾数量 <= 10，掩码最多 2^10 = 1024 种
3. BFS 保证找到最短路径
