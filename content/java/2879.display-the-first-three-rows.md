## 题目描述

给定 DataFrame employees，显示前 3 行数据。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.head(3)` 获取前 3 行。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.head(3) 等价于获取列表前 3 个元素

import java.util.*;

class Solution {
    public <T> List<T> selectFirstRows(List<T> data, int n) {
        // subList 获取前 n 行（Java 列表等价操作）
        return data.subList(0, Math.min(n, data.size()));
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. `df.head(n)` 返回前 n 行，默认 5 行
2. `df.iloc[:3]` 用位置切片等效
3. Java 列表用 `subList(0, 3)` 等价
