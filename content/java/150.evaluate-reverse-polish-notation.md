## 题目描述

给你一个字符串数组 `tokens`，表示一个根据逆波兰表示法表示的算术表达式。

请你计算该表达式。返回表示表达式值的整数。

**注意：**

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'`
- 每个操作数（运算对象）都可以是一个整数或另一个表达式
- 两个整数之间的除法总是向零截断
- 表达式中不含除零运算
- 输入是一个根据逆波兰表示法表示的算术表达式
- 答案及所有中间计算结果可以用 32 位整数表示

**示例 1：**

```
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为: ((2 + 1) * 3) = 9
```

**示例 2：**

```
输入: tokens = ["4","13","5","/","+"]
输出: 6
解释: 该算式转化为常见的中缀算术表达式为: (4 + (13 / 5)) = 6
```

**示例 3：**

```
输入: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
输出: 22
解释: 该算式转化为常见的中缀算术表达式为:
  ((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 22
```

**提示：**

- `1 <= tokens.length <= 10^4`
- `tokens[i]` 是一个算符（`"+"`、`"-"`、`"*"` 或 `"/"`），或是在范围 `[-200, 200]` 内的一个整数

## 解题思路

**逆波兰表达式（后缀表达式）**：运算符位于操作数之后。

例如：
- 中缀表达式：`(2 + 1) * 3`
- 后缀表达式：`2 1 + 3 *`

**求值规则：**

从左到右扫描表达式：
1. 遇到数字：压入栈
2. 遇到运算符：从栈中弹出两个数，计算结果，再压入栈
3. 最终栈中只剩一个数，即为结果

**为什么使用栈？**

- 后缀表达式的求值天然符合栈的后进先出特性
- 遇到运算符时，最近的两个操作数就是栈顶的两个元素

**算法流程：**

```
创建栈 stack
for token in tokens:
    if token 是数字:
        stack.push(token)
    else:  // 是运算符
        num2 = stack.pop()
        num1 = stack.pop()
        result = num1 operator num2
        stack.push(result)
return stack.top()
```

## Java 代码实现

### 方法一：栈（标准解法，推荐）

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        Set<String> operators = new HashSet<>(Arrays.asList("+", "-", "*", "/"));

        for (String token : tokens) {
            if (!operators.contains(token)) {
                // 是数字，压入栈
                stack.push(Integer.parseInt(token));
            } else {
                // 是运算符，弹出两个数计算
                int num2 = stack.pop();
                int num1 = stack.pop();
                int result;

                switch (token) {
                    case "+":
                        result = num1 + num2;
                        break;
                    case "-":
                        result = num1 - num2;
                        break;
                    case "*":
                        result = num1 * num2;
                        break;
                    default:  // "/"
                        // Java 的整数除法天然向零截断，符合题目要求
                        result = num1 / num2;
                        break;
                }

                stack.push(result);
            }
        }

        return stack.pop();
    }
}
```

### 方法二：使用字符比较优化

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String token : tokens) {
            // 判断是否为运算符
            // 长度大于 1 的一定是数字（如 "-11"），长度为 1 时看是否是运算符字符
            if (token.length() > 1 || Character.isDigit(token.charAt(0))) {
                stack.push(Integer.parseInt(token));
            } else {
                int num2 = stack.pop();
                int num1 = stack.pop();

                switch (token.charAt(0)) {
                    case '+': stack.push(num1 + num2); break;
                    case '-': stack.push(num1 - num2); break;
                    case '*': stack.push(num1 * num2); break;
                    case '/': stack.push(num1 / num2); break;
                }
            }
        }

        return stack.pop();
    }
}
```

### 方法三：try-catch 解析（简洁写法）

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String token : tokens) {
            try {
                // 尝试解析为数字
                stack.push(Integer.parseInt(token));
            } catch (NumberFormatException e) {
                // 解析失败，说明是运算符
                int num2 = stack.pop();
                int num1 = stack.pop();

                if (token.equals("+")) stack.push(num1 + num2);
                else if (token.equals("-")) stack.push(num1 - num2);
                else if (token.equals("*")) stack.push(num1 * num2);
                else stack.push(num1 / num2);
            }
        }

        return stack.pop();
    }
}
```

## 复杂度分析

**方法一、二、三：**

- 时间复杂度：O(n)
  - 遍历 tokens 数组一次
  - 每个元素的入栈、出栈操作都是 O(1)
- 空间复杂度：O(n)
  - 栈最多存储 n/2 个数字（最坏情况：所有数字在前，运算符在后）

## 关键点总结

1. **栈的完美应用场景**：
   - 后缀表达式求值是栈的经典应用
   - 运算符总是作用于最近的两个操作数

2. **弹出顺序**：
   - 先弹出的是右操作数（num2）
   - 后弹出的是左操作数（num1）
   - 对于减法和除法，顺序很重要：`num1 - num2`

3. **Java 除法的特性**：
   - Java 的整数除法天然向零截断（`/`），符合题目要求
   - 不需要像 Python 那样特殊处理

4. **数字识别**：
   - 负数也是数字，例如 `"-11"`
   - 可以用 `token.length() > 1` 或尝试 `parseInt` 来判断

5. **最终结果**：
   - 有效的后缀表达式求值后栈中只剩一个元素
   - 即为最终结果

## 易错点

1. **操作数顺序**：
   - 减法: `num1 - num2`，不是 `num2 - num1`
   - 除法: `num1 / num2`，不是 `num2 / num1`
   - 先弹出的是 num2，后弹出的是 num1

2. **负数的处理**：
   - `"-11"` 是一个负数，不是减法运算符
   - 判断运算符时要注意区分，不能只看第一个字符是否为 `-`

3. **Java 与 Python 除法的区别**：
   - Python 的 `//` 是向下取整（floor）
   - Java 的 `/` 是向零截断（truncate towards zero）
   - 本题 Java 版本不需要特殊处理除法

4. **栈空判断**：
   - 题目保证表达式有效，不需要检查栈空
   - 如果需要检查，应在弹出前判断

5. **字符串比较**：
   - Java 中字符串比较必须用 `.equals()`，不能用 `==`
