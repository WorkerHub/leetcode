## 题目描述

每朵花有开放时间段，对每个查询时间统计正在开放的花朵数。

## 解题思路

分别对starts和ends排序。时刻t开放的花=start<=t的数量-end<t的数量，用二分查找快速统计。

## Java 代码实现

```java
class Solution {
    public int[] fullBloomFlowers(int[][] flowers, int[] people) {
        int m = flowers.length;
        int[] starts = new int[m], ends = new int[m];
        for (int i = 0; i < m; i++) {
            starts[i] = flowers[i][0];
            ends[i] = flowers[i][1];
        }
        Arrays.sort(starts);
        Arrays.sort(ends);

        int[] ans = new int[people.length];
        for (int i = 0; i < people.length; i++) {
            int t = people[i];
            // start<=t的数量
            int opened = upperBound(starts, t);
            // end<t的数量
            int closed = lowerBound(ends, t);
            ans[i] = opened - closed;
        }
        return ans;
    }

    // 返回第一个>t的位置（即<=t的数量）
    private int upperBound(int[] arr, int t) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] <= t) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    // 返回第一个>=t的位置（即<t的数量）
    private int lowerBound(int[] arr, int t) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (arr[mid] < t) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((m + n) log m)
- **空间复杂度**：O(m)

## 关键点总结

1. **开放花数=已开放-已凋谢**：start<=t的数量减去end<t的数量
2. **二分查找**：upperBound统计<=t，lowerBound统计<t
3. **分别排序starts和ends**：独立处理开始和结束时间
