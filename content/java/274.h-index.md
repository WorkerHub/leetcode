## 题目描述

给你一个整数数组 citations，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数。

根据维基百科上 h 指数的定义：h 代表"高引用次数"，一名科研人员的 h 指数是指他（她）的（n 篇论文中）总共有 h 篇论文分别被引用了至少 h 次。且其余的 n - h 篇论文每篇被引用次数不超过 h 次。

如果 h 有多种可能的值，h 指数是其中最大的那个。

**示例 1：**
```
输入: citations = [3,0,6,1,5]
输出: 3
解释: 给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 3, 0, 6, 1, 5 次。
     由于研究者有 3 篇论文每篇至少被引用了 3 次，其余 2 篇论文每篇被引用不多于 3 次，
     所以她的 h 指数是 3。
```

**示例 2：**
```
输入: citations = [1,3,1]
输出: 1
```

**提示：**
- n == citations.length
- 1 <= n <= 5000
- 0 <= citations[i] <= 1000

## 解题思路

### 理解 h 指数

h 指数的定义：
- 至少有 h 篇论文被引用了至少 h 次
- 其余论文被引用次数不超过 h 次

换句话说：
- 如果我们按引用次数从高到低排序
- h 指数是满足"至少有 h 篇论文引用次数 >= h"的最大值

### 思路一：排序后查找

1. 将引用次数降序排序
2. 从前往后遍历，找到满足条件的最大 h
3. 第 i 篇论文（从 0 开始），如果 citations[i] >= i+1，说明至少有 i+1 篇论文被引用了至少 i+1 次

### 思路二：计数排序

1. 统计每个引用次数的论文数量
2. 从高引用次数向低遍历，累计论文数
3. 当累计论文数 >= 当前引用次数时，就找到了 h 指数

## Java 代码实现

### 方法一：排序法（推荐，易理解）

```java
import java.util.Arrays;

class Solution {
    public int hIndex(int[] citations) {
        // 降序排序
        Arrays.sort(citations);
        // 转为降序：Java 没有直接的 int[] 降序，手动反转
        int n = citations.length;
        int h = 0;

        for (int i = 0; i < n; i++) {
            // 降序索引：排序后第 i 小的是倒序第 i 个
            int citation = citations[n - 1 - i];
            // 如果当前论文引用次数 >= 当前位置（从 1 开始）
            if (citation >= i + 1) {
                h = i + 1;
            } else {
                // 由于是降序，后面的论文引用次数更少，可以退出
                break;
            }
        }

        return h;
    }
}
```

### 方法二：使用 Integer 数组降序排序

```java
import java.util.Arrays;

class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        // 使用 Integer 数组进行降序排序
        Integer[] cits = new Integer[n];
        for (int i = 0; i < n; i++) cits[i] = citations[i];
        Arrays.sort(cits, (a, b) -> b - a);

        int h = 0;
        for (int i = 0; i < n; i++) {
            if (cits[i] >= i + 1) {
                h = i + 1;
            } else {
                break;
            }
        }
        return h;
    }
}
```

### 方法三：计数排序（O(n) 时间）

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;

        // 计数数组，count[i] 表示引用次数为 i 的论文数量
        // 引用次数大于 n 的都归为 count[n]
        int[] count = new int[n + 1];
        for (int c : citations) {
            if (c >= n) {
                count[n]++;
            } else {
                count[c]++;
            }
        }

        // 从高引用次数向低遍历
        int total = 0; // 引用次数 >= i 的论文总数
        for (int i = n; i >= 0; i--) {
            total += count[i];
            // 如果有至少 i 篇论文被引用了至少 i 次
            if (total >= i) {
                return i;
            }
        }

        return 0;
    }
}
```

### 方法四：简洁版（直接统计）

```java
import java.util.Arrays;

class Solution {
    public int hIndex(int[] citations) {
        Arrays.sort(citations);
        int n = citations.length;
        int h = 0;

        // 从后往前统计满足条件的 h
        for (int i = n - 1; i >= 0; i--) {
            // 从末尾起第 (n - i) 篇论文
            if (citations[i] >= n - i) {
                h = n - i;
            } else {
                break;
            }
        }

        return h;
    }
}
```

## 复杂度分析

### 方法一、二：排序法

**时间复杂度：** O(n log n)
- 排序：O(n log n)
- 遍历：O(n)

**空间复杂度：** O(log n)
- 排序的栈空间

### 方法三：计数排序

**时间复杂度：** O(n)
- 统计：O(n)
- 遍历计数数组：O(n)

**空间复杂度：** O(n)
- 计数数组

## 图解示例

以 citations = [3,0,6,1,5] 为例：

**排序后（降序）：** [6, 5, 3, 1, 0]

```
位置 i | 引用数 | 至少 i+1 篇 >= i+1 次？| h 值
------|--------|---------------------|-----
  0   |   6    |   6 >= 1 ✓         |  1
  1   |   5    |   5 >= 2 ✓         |  2
  2   |   3    |   3 >= 3 ✓         |  3
  3   |   1    |   1 >= 4 ✗         |  -
  4   |   0    |   0 >= 5 ✗         |  -

最大 h = 3
```

**计数排序方法：**

```
引用次数 | 论文数 | 累计 >= 该次数的论文数 | 满足 h 指数？
--------|-------|---------------------|-------------
  5     |  2    |         2           |  2 < 5 ✗
  4     |  0    |         2           |  2 < 4 ✗
  3     |  1    |         3           |  3 >= 3 ✓

h = 3
```

## 关键点总结

1. **理解 h 指数定义**：至少有 h 篇论文被引用至少 h 次
2. **排序思路**：降序排序后，第 i 篇论文如果 citations[i] >= i+1，则 h >= i+1
3. **计数排序优化**：可以将时间复杂度降到 O(n)
4. **边界情况**：
   - 所有论文引用次数都很高：h = n
   - 所有论文引用次数都为 0：h = 0
5. **Java 注意**：int[] 不能直接降序排序，可以先升序再反向遍历，或者转为 Integer[] 后用 Comparator

## 易错点

1. **h 指数的理解**：注意是"至少 h 篇"，不是"恰好 h 篇"

2. **索引与数量的对应**：排序后第 i 个元素代表第 i+1 篇论文
   ```java
   // i 从 0 开始，但论文数从 1 开始
   if (citations[n - 1 - i] >= i + 1) {
       h = i + 1;
   }
   ```

3. **计数数组的范围**：引用次数可能超过 n，需要归并处理
   ```java
   // 引用次数 > n 的都记录在 count[n]
   if (c >= n) count[n]++;
   ```

4. **Java 的 int[] 排序只能升序**，需要变换遍历方向或转 Integer[]
