## 题目描述

给一个严格升序正整数数组 arr 和整数 k，找第 k 个缺失的正整数。

**示例：**
```
输入：arr = [2,3,4,7,11], k = 5
输出：9
解释：缺失 1,5,6,8,9...，第 5 个是 9
```

## 解题思路

二分查找：arr[i] 之前缺失数量 = arr[i] - (i+1)。二分找临界位置，答案 = lo + k。

## Java 代码实现

```java
class Solution {
    public int findKthPositive(int[] arr, int k) {
        // arr[i] 之前缺失的数量 = arr[i] - i - 1
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (arr[mid] - mid - 1 >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        // 答案 = lo + k
        return lo + k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **缺失数量公式**：arr[i] - i - 1 = 位置 i 之前缺失的正整数个数
2. **二分目标**：找第一个缺失数 ≥ k 的位置
3. **答案公式**：lo + k（简洁推导）
