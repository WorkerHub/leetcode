## 题目描述

设计视频共享平台，支持上传/删除/观看/点赞/点踩操作，上传优先复用已删除的最小ID。

## 解题思路

最小堆管理可复用ID，HashMap存储视频内容和统计数据。上传时优先从堆取最小ID，否则递增。

## Java 代码实现

```java
class VideoSharingPlatform {
    private Map<Integer, String> videos;
    private Map<Integer, int[]> stats; // [likes, dislikes, views]
    private PriorityQueue<Integer> available;
    private int nextId;

    public VideoSharingPlatform() {
        videos = new HashMap<>();
        stats = new HashMap<>();
        available = new PriorityQueue<>();
        nextId = 0;
    }

    public int upload(String video) {
        int vid = available.isEmpty() ? nextId++ : available.poll();
        videos.put(vid, video);
        stats.put(vid, new int[3]);
        return vid;
    }

    public void remove(int videoId) {
        if (videos.containsKey(videoId)) {
            videos.remove(videoId);
            stats.remove(videoId);
            available.offer(videoId);
        }
    }

    public String watch(int videoId, int startMinute, int endMinute) {
        if (!videos.containsKey(videoId)) return "-1";
        stats.get(videoId)[2]++;
        String v = videos.get(videoId);
        return v.substring(startMinute, Math.min(endMinute + 1, v.length()));
    }

    public void like(int videoId) {
        if (stats.containsKey(videoId)) stats.get(videoId)[0]++;
    }

    public void dislike(int videoId) {
        if (stats.containsKey(videoId)) stats.get(videoId)[1]++;
    }

    public int[] getLikesAndDislikes(int videoId) {
        if (!stats.containsKey(videoId)) return new int[]{-1};
        int[] s = stats.get(videoId);
        return new int[]{s[0], s[1]};
    }

    public int getViews(int videoId) {
        if (!stats.containsKey(videoId)) return -1;
        return stats.get(videoId)[2];
    }
}
```

## 复杂度分析

- **upload/remove**：O(log n)，堆操作
- **watch/like/dislike/get**：O(1)

## 关键点总结

1. **最小堆管理可复用ID**：优先使用已删除的最小ID
2. **HashMap存储数据**：O(1)查询视频是否存在
3. **删除时归还ID到堆**：下次上传可复用
