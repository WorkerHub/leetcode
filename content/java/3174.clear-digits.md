## 题目描述

给你含字母和数字的字符串 `s`，重复操作：删除第一个数字及其左侧最近的字母，返回最终无数字的字符串。

## 解题思路

栈模拟：字母入栈，遇到数字则弹出栈顶字母（最近的字母），数字本身不入栈。最终栈中内容就是答案。

## Java 代码实现

```java
class Solution {
    public String clearDigits(String s) {
        StringBuilder stack = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 弹出栈顶字母（最近的字母）
                if (stack.length() > 0) {
                    stack.deleteCharAt(stack.length() - 1);
                }
            } else {
                stack.append(c);
            }
        }
        return stack.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 字母入栈，数字触发弹栈（删除最近字母），数字不入栈
2. 题目保证每个数字左边都有字母，无需处理越界
