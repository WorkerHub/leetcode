## 题目描述

给定二进制字符串 s，可以翻转任意位，返回使 s 变为单调递增（前缀全0后缀全1）的最小翻转次数。

**示例：**
```
输入：s = "010110"
输出：2
```

## 解题思路

动态规划：维护 ones（前面1的个数）和 flips（最小翻转次数）。遇到 0 时选择翻转它（flips+1）或把前面所有 1 翻转（ones），取较小值。

## Java 代码实现

```java
class Solution {
    public int minFlipsMonoIncr(String s) {
        int ones = 0;  // 前面出现的 1 的个数
        int flips = 0; // 最小翻转次数

        for (char c : s.toCharArray()) {
            if (c == '1') {
                ones++;
            } else {
                // 遇到 0：翻转它（flips+1）或翻转前面所有 1（ones）
                flips = Math.min(flips + 1, ones);
            }
        }

        return flips;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心 + DP**：遇到 0 时做局部最优决策
2. **两种选择**：翻转当前 0 为 1，或翻转前面所有 1 为 0
3. **单调递增本质**：字符串分为前半 0 和后半 1
