## 题目描述

你参加 n 场竞赛，需要精力和经验均严格大于对手才能获胜，获胜后精力减少、经验增加。每小时训练可增加 1 点精力或 1 点经验，返回最少训练时数。

## 解题思路

精力和经验分开贪心：精力每场必减，初始精力至少为所有对手精力之和加 1；经验逐场模拟，若当前经验不足则补充到对手经验加 1，累计补充量。

## Java 代码实现

```java
class Solution {
    public int minNumberOfHours(int initialEnergy, int initialExperience,
                                int[] energy, int[] experience) {
        int hours = 0;
        // 精力：必须严格大于所有对手精力之和
        int totalEnergy = 0;
        for (int e : energy) totalEnergy += e;
        if (initialEnergy <= totalEnergy) hours += totalEnergy + 1 - initialEnergy;

        // 经验：逐场模拟，不足则补充
        int curExp = initialExperience;
        for (int exp : experience) {
            if (curExp <= exp) {
                hours += exp + 1 - curExp;
                curExp = exp + 1;
            }
            curExp += exp; // 获胜后经验增加
        }
        return hours;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 精力在竞赛前总额固定（每场减去对手精力），初始精力需大于总消耗。
2. 经验只增不减，逐场贪心补足至 `exp+1`。
3. 条件是严格大于（>），所以需要 `exp+1` 而非 `exp`。
