## 题目描述

给你两个含正整数和 0 的数组 nums1、nums2，可将任意 0 替换为正整数，使两数组元素和相等，返回最小可能的相等和，无法做到则返回 -1。

## 解题思路

每个 0 至少替换为 1，故最小可能和 = 非零元素之和 + 零的个数。目标和 = max(min1, min2)。若某数组没有 0 而其最小和小于目标，则无法增大，返回 -1。

## Java 代码实现

```java
class Solution {
    public long minSum(int[] nums1, int[] nums2) {
        long sum1 = 0, sum2 = 0;
        int zeros1 = 0, zeros2 = 0;
        for (int x : nums1) { sum1 += x; if (x == 0) zeros1++; }
        for (int x : nums2) { sum2 += x; if (x == 0) zeros2++; }

        long min1 = sum1 + zeros1; // nums1 最小可能和
        long min2 = sum2 + zeros2; // nums2 最小可能和
        long target = Math.max(min1, min2);

        // 若某数组无 0，其和固定，若不足 target 则无解
        if (zeros1 == 0 && min1 < target) return -1;
        if (zeros2 == 0 && min2 < target) return -1;

        return target;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(1)

## 关键点总结

1. 每个 0 至少换为 1，最小可能和 = 原和 + 零的个数
2. 目标和取两最小可能和的最大值
3. 无 0 的数组和固定，若不足目标则返回 -1
