## 题目描述

给定整数数组，返回元素和为奇数的子数组数目（mod 10^9+7）。

**示例：**
```
输入：arr = [1,3,5]
输出：4
```

## 解题思路

前缀和奇偶性：子数组和为奇 ⟺ 前缀和奇偶性不同。统计前缀和为奇/偶的个数。

## Java 代码实现

```java
class Solution {
    public int numOfSubarrays(int[] arr) {
        int MOD = 1_000_000_007;
        int odd = 0, even = 1; // even 初始为 1（空前缀和为 0，偶数）
        int prefixSum = 0;
        long count = 0;
        
        for (int num : arr) {
            prefixSum += num;
            if (prefixSum % 2 == 0) {
                count = (count + odd) % MOD; // 偶 - 奇 = 奇
                even++;
            } else {
                count = (count + even) % MOD; // 奇 - 偶 = 奇
                odd++;
            }
        }
        return (int) count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **前缀和奇偶**：奇-偶=奇，偶-奇=奇
2. **计数法**：维护已出现的奇/偶前缀和个数
3. **初始化**：even=1 代表空前缀
