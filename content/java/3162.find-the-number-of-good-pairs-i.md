## 题目描述

给你整数数组 `nums1`、`nums2` 和整数 `k`，若 `nums1[i]` 能被 `nums2[j] * k` 整除则称 `(i, j)` 为好数对，返回好数对的数量。

## 解题思路

数据范围小（均不超过 50），直接暴力枚举所有 (i, j) 对，判断整除条件。

## Java 代码实现

```java
class Solution {
    public int numberOfPairs(int[] nums1, int[] nums2, int k) {
        int ans = 0;
        for (int a : nums1) {
            for (int b : nums2) {
                // 判断 nums1[i] 是否被 nums2[j]*k 整除
                if (a % (b * k) == 0) ans++;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × m)
- **空间复杂度**：O(1)

## 关键点总结

1. 整除条件：`a % (b * k) == 0`
2. 数据范围小，暴力枚举即可
