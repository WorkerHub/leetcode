## 题目描述

给你两个长度为 `n` 的整数数组 `nums1`、`nums2` 和整数 `diff`，统计满足 `0 <= i < j <= n-1` 且 `nums1[i] - nums1[j] <= nums2[i] - nums2[j] + diff` 的数对数目。

## 解题思路

令 `arr[k] = nums1[k] - nums2[k]`，条件等价于 `arr[i] <= arr[j] + diff`（i < j）。从左到右遍历，对每个 j 用树状数组查询已插入元素中 `<= arr[j] + diff` 的个数，再将 `arr[j]` 插入。需坐标压缩将值域映射到正整数范围。

## Java 代码实现

```java
import java.util.Arrays;
import java.util.TreeMap;

class Solution {
    // 树状数组：支持单点加和前缀查询
    private int[] bit;
    private int bitSize;

    private void update(int i) {
        for (; i <= bitSize; i += i & -i) bit[i]++;
    }

    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & -i) s += bit[i];
        return s;
    }

    public long numberOfPairs(int[] nums1, int[] nums2, int diff) {
        int n = nums1.length;
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) arr[i] = nums1[i] - nums2[i];

        // 坐标压缩
        int[] sorted = arr.clone();
        Arrays.sort(sorted);
        // 去重后建立排名映射
        int[] unique = Arrays.stream(sorted).distinct().toArray();
        bitSize = unique.length;
        bit = new int[bitSize + 1];

        long ans = 0;
        for (int j = 0; j < n; j++) {
            // 查询 <= arr[j] + diff 的元素个数
            int threshold = arr[j] + diff;
            // 二分找 threshold 在 unique 中的位置（upper_bound - 1）
            int lo = 0, hi = unique.length;
            while (lo < hi) {
                int mid = (lo + hi) / 2;
                if (unique[mid] <= threshold) lo = mid + 1;
                else hi = mid;
            }
            // lo 即为 <= threshold 的元素个数（1-based rank 上界）
            ans += query(lo);
            // 插入 arr[j]，找其在 unique 中的 1-based rank
            int rank = Arrays.binarySearch(unique, arr[j]) + 1;
            update(rank);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 条件变形：转化为单数组中 `arr[i] <= arr[j] + diff`（i < j）的数对数
2. 遍历 j，先查询再插入，保证只统计 i < j 的情况
3. 坐标压缩将值域映射到 [1, m]，适配树状数组
