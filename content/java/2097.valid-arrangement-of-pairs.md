## 题目描述

给定整数对数组pairs，找到一种有效排列使得相邻对首尾相连（pairs[i][1] == pairs[i+1][0]）。

## 解题思路

将每对看做有向边，问题转化为求欧拉路径。用Hierholzer算法：找起点（出度-入度=1），DFS+栈后序记录路径。

## Java 代码实现

```java
class Solution {
    public int[][] validArrangement(int[][] pairs) {
        // 构建邻接表
        Map<Integer, Deque<Integer>> graph = new HashMap<>();
        Map<Integer, Integer> outDeg = new HashMap<>();
        Map<Integer, Integer> inDeg = new HashMap<>();
        
        for (int[] p : pairs) {
            graph.computeIfAbsent(p[0], k -> new ArrayDeque<>()).add(p[1]);
            outDeg.merge(p[0], 1, Integer::sum);
            inDeg.merge(p[1], 1, Integer::sum);
        }
        
        // 找欧拉路径起点
        int start = pairs[0][0];
        for (int node : outDeg.keySet()) {
            if (outDeg.getOrDefault(node, 0) - inDeg.getOrDefault(node, 0) == 1) {
                start = node;
                break;
            }
        }
        
        // Hierholzer算法（迭代版）
        List<Integer> path = new ArrayList<>();
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(start);
        
        while (!stack.isEmpty()) {
            int u = stack.peek();
            Deque<Integer> neighbors = graph.getOrDefault(u, new ArrayDeque<>());
            if (!neighbors.isEmpty()) {
                stack.push(neighbors.poll());
            } else {
                path.add(stack.pop());
            }
        }
        
        // 逆序转换为边
        Collections.reverse(path);
        int[][] result = new int[pairs.length][2];
        for (int i = 0; i < pairs.length; i++) {
            result[i][0] = path.get(i);
            result[i][1] = path.get(i + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(E)，E为边数
- **空间复杂度**：O(V + E)

## 关键点总结

1. **欧拉路径**：每条边恰好访问一次
2. **起点选择**：出度-入度=1的节点；若无则任意节点
3. **Hierholzer算法**：DFS+后序记录，最终逆序得到路径
