## 题目描述

实现类 `DistanceLimitedPathsExist`，支持在线查询：给定图（n 个节点，带权无向边），`query(p, q, limit)` 返回是否存在从 `p` 到 `q` 且路径上每条边权重**严格小于** `limit` 的路径。

## 解题思路

**Kruskal 重构树 + 倍增 LCA**：按边权排序构建重构树，每次合并两个连通分量时新建虚拟节点（权值为当前边权）作为父节点。查询时在重构树上求 LCA，若 LCA 权值 < limit 则路径存在。用倍增法实现 O(log n) 的 LCA 查询。

## Java 代码实现

```java
import java.util.Arrays;

class DistanceLimitedPathsExist {
    private int[] parent;
    private int[] nodeVal;
    private int[][] up; // 倍增表
    private int[] depth;
    private static final int LOG = 15;

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    public DistanceLimitedPathsExist(int n, int[][] edgeList) {
        int maxNodes = 2 * n;
        parent = new int[maxNodes];
        nodeVal = new int[maxNodes];
        depth = new int[maxNodes];
        up = new int[maxNodes][LOG];

        for (int i = 0; i < maxNodes; i++) parent[i] = i;

        // 按边权升序排序
        Arrays.sort(edgeList, (a, b) -> a[2] - b[2]);

        int nodeCnt = n;

        // Kruskal 重构树构建
        for (int[] edge : edgeList) {
            int u = edge[0], v = edge[1], w = edge[2];
            int ru = find(u), rv = find(v);
            if (ru == rv) continue;
            // 新建虚拟节点
            nodeVal[nodeCnt] = w;
            parent[nodeCnt] = nodeCnt;
            parent[ru] = nodeCnt;
            parent[rv] = nodeCnt;
            up[ru][0] = nodeCnt;
            up[rv][0] = nodeCnt;
            depth[ru] = depth[nodeCnt] + 1;
            depth[rv] = depth[nodeCnt] + 1;
            nodeCnt++;
        }

        // 构建倍增表
        for (int k = 1; k < LOG; k++) {
            for (int v = 0; v < nodeCnt; v++) {
                up[v][k] = up[up[v][k - 1]][k - 1];
            }
        }
    }

    public boolean query(int p, int q, int limit) {
        // 将深度较大的节点提升到与另一节点相同深度
        if (depth[p] < depth[q]) {
            int tmp = p; p = q; q = tmp;
        }
        int diff = depth[p] - depth[q];
        for (int k = 0; k < LOG; k++) {
            if (((diff >> k) & 1) == 1) p = up[p][k];
        }
        if (p == q) return nodeVal[p] < limit;

        // 同步上移找 LCA
        for (int k = LOG - 1; k >= 0; k--) {
            if (up[p][k] != up[q][k]) {
                p = up[p][k];
                q = up[q][k];
            }
        }
        int lca = up[p][0];
        return nodeVal[lca] < limit;
    }
}
```

## 复杂度分析

- **时间复杂度**：预处理 O(E log E + N log N)，每次查询 O(log N)
- **空间复杂度**：O(N log N)

## 关键点总结

1. Kruskal 重构树将路径最大边权转化为 LCA 权值问题
2. 倍增法支持 O(log n) 在线 LCA 查询
3. 虚拟节点编号从 n 开始，数组大小需为 2n
