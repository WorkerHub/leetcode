## 题目描述

设计加解密类：encrypt将字母按映射替换，decrypt统计字典中能加密成给定字符串的单词数。

## 解题思路

预处理：初始化时将字典所有单词加密后计入频次表。encrypt直接查映射拼接，decrypt直接查频次表O(1)。

## Java 代码实现

```java
class Encrypter {
    private Map<Character, String> encMap;
    private Map<String, Integer> decCount;
    
    public Encrypter(char[] keys, String[] values, String[] dictionary) {
        encMap = new HashMap<>();
        for (int i = 0; i < keys.length; i++) {
            encMap.put(keys[i], values[i]);
        }
        
        // 预处理：将字典所有单词加密计频
        decCount = new HashMap<>();
        for (String word : dictionary) {
            String enc = encrypt(word);
            if (!enc.isEmpty()) {
                decCount.merge(enc, 1, Integer::sum);
            }
        }
    }
    
    public String encrypt(String word1) {
        StringBuilder sb = new StringBuilder();
        for (char ch : word1.toCharArray()) {
            if (!encMap.containsKey(ch)) return "";
            sb.append(encMap.get(ch));
        }
        return sb.toString();
    }
    
    public int decrypt(String word2) {
        return decCount.getOrDefault(word2, 0);
    }
}
```

## 复杂度分析

- **时间复杂度**：初始化O(D*L)，encrypt O(L)，decrypt O(1)
- **空间复杂度**：O(D*L)

## 关键点总结

1. **逆向思维**：不直接解密，而是预先将字典加密后统计
2. **decrypt O(1)**：直接查频次表
3. **多对一映射**：不同字母可能映射到相同加密串，导致解密歧义
