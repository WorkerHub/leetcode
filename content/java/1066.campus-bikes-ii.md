## 题目描述

n 个工人和 n 辆自行车（n≤10），为每个工人分配一辆自行车，使曼哈顿距离总和最小。

**示例：**
```
输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出：6
```

## 解题思路

状态压缩 DP：用位掩码表示已使用的自行车集合。dp[mask] = 分配 popcount(mask) 个工人后的最小距离和。

## Java 代码实现

```java
class Solution {
    public int assignBikes(int[][] workers, int[][] bikes) {
        int n = workers.length;

        // 预计算距离
        int[][] dist = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                dist[i][j] = Math.abs(workers[i][0] - bikes[j][0])
                           + Math.abs(workers[i][1] - bikes[j][1]);
            }
        }

        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;

            // 当前要分配的工人索引
            int workerIdx = Integer.bitCount(mask);
            if (workerIdx == n) continue;

            // 为该工人尝试每辆未使用的自行车
            for (int bikeIdx = 0; bikeIdx < n; bikeIdx++) {
                if ((mask & (1 << bikeIdx)) == 0) {
                    int newMask = mask | (1 << bikeIdx);
                    dp[newMask] = Math.min(dp[newMask], dp[mask] + dist[workerIdx][bikeIdx]);
                }
            }
        }

        return dp[(1 << n) - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^n × n)
- **空间复杂度**：O(2^n)

## 关键点总结

1. **状态压缩**：位掩码表示自行车使用状态
2. **工人索引**：popcount(mask) = 已分配工人数
3. **预计算距离**：避免重复计算曼哈顿距离
