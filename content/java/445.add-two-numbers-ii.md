## 题目描述

给你两个非空链表来代表两个非负整数。数字最高位位于链表开始位置。它们的每个节点只存储一位数字。将这两数相加会返回一个新的链表。

你可以假设除了数字 0 之外，这两个数字都不会以零开头。

**示例 1:**

```
输入: l1 = [7,2,4,3], l2 = [5,6,4]
输出: [7,8,0,7]
解释: 7243 + 564 = 7807
```

**示例 2:**

```
输入: l1 = [2,4,3], l2 = [5,6,4]
输出: [8,0,7]
```

**示例 3:**

```
输入: l1 = [0], l2 = [0]
输出: [0]
```

**提示:**

- 链表的长度范围为 [1, 100]
- 0 <= Node.val <= 9
- 题目数据保证列表表示的数字不含前导零

**进阶:** 如果输入链表不能修改该如何处理？换句话说，不能对列表中的节点进行翻转。

## 解题思路

这道题是 [2. Add Two Numbers](https://leetcode.com/problems/add-two-numbers/) 的变体，区别在于：
- 第 2 题：数字低位在前，可以直接从头开始相加
- 本题：数字高位在前，需要从低位开始相加

**解决方案：**

1. **栈方法（推荐）**：
   - 使用两个栈分别存储两个链表的节点值
   - 从栈顶（低位）开始相加
   - 处理进位，构建结果链表

2. **反转链表法**：
   - 先反转两个链表
   - 按照第 2 题的方法相加
   - 再反转结果链表

3. **递归法**：
   - 先对齐两个链表（补齐短链表）
   - 递归相加，返回进位

**核心思想：** 无论哪种方法，都需要**从低位到高位**进行加法运算。

## Java 代码实现

### 方法一：栈方法（推荐，符合进阶要求）

```java
import java.util.ArrayDeque;
import java.util.Deque;

class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        /**
         * 使用栈实现，不修改原链表
         * 时间复杂度: O(max(m, n))
         * 空间复杂度: O(m + n)
         */
        // 将链表值压入栈
        Deque<Integer> stack1 = new ArrayDeque<>();
        Deque<Integer> stack2 = new ArrayDeque<>();

        while (l1 != null) {
            stack1.push(l1.val);
            l1 = l1.next;
        }
        while (l2 != null) {
            stack2.push(l2.val);
            l2 = l2.next;
        }

        // 从栈顶开始相加（从低位到高位）
        int carry = 0;
        ListNode head = null;

        while (!stack1.isEmpty() || !stack2.isEmpty() || carry != 0) {
            int val1 = stack1.isEmpty() ? 0 : stack1.pop();
            int val2 = stack2.isEmpty() ? 0 : stack2.pop();

            int total = val1 + val2 + carry;
            carry = total / 10;
            int digit = total % 10;

            // 头插法构建结果链表
            ListNode newNode = new ListNode(digit);
            newNode.next = head;
            head = newNode;
        }

        return head;
    }
}
```

### 方法二：反转链表法

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        /**
         * 反转链表后相加
         * 时间复杂度: O(max(m, n))
         * 空间复杂度: O(1)
         */
        // 反转两个链表
        l1 = reverseList(l1);
        l2 = reverseList(l2);

        // 相加（类似第 2 题）
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int val1 = (l1 != null) ? l1.val : 0;
            int val2 = (l2 != null) ? l2.val : 0;

            int total = val1 + val2 + carry;
            carry = total / 10;
            int digit = total % 10;

            current.next = new ListNode(digit);
            current = current.next;

            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }

        // 反转结果链表
        return reverseList(dummy.next);
    }

    private ListNode reverseList(ListNode head) {
        /**反转链表*/
        ListNode prev = null;
        ListNode current = head;

        while (current != null) {
            ListNode nextNode = current.next;
            current.next = prev;
            prev = current;
            current = nextNode;
        }

        return prev;
    }
}
```

### 方法三：递归法（先对齐再相加）

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        /**
         * 递归实现
         * 时间复杂度: O(max(m, n))
         * 空间复杂度: O(max(m, n)) - 递归栈
         */
        // 获取链表长度
        int len1 = getLength(l1);
        int len2 = getLength(l2);

        // 对齐两个链表（在短链表前面补 0）
        if (len1 < len2) {
            l1 = padList(l1, len2 - len1);
        } else if (len2 < len1) {
            l2 = padList(l2, len1 - len2);
        }

        // 递归相加
        int[] carryRef = new int[1];  // 用数组传递进位引用
        ListNode result = addHelper(l1, l2, carryRef);

        // 如果有进位，在最前面加一个节点
        if (carryRef[0] != 0) {
            ListNode newHead = new ListNode(carryRef[0]);
            newHead.next = result;
            return newHead;
        }

        return result;
    }

    private int getLength(ListNode head) {
        /**获取链表长度*/
        int length = 0;
        while (head != null) {
            length++;
            head = head.next;
        }
        return length;
    }

    private ListNode padList(ListNode head, int count) {
        /**在链表前面补 0*/
        for (int i = 0; i < count; i++) {
            ListNode newNode = new ListNode(0);
            newNode.next = head;
            head = newNode;
        }
        return head;
    }

    private ListNode addHelper(ListNode l1, ListNode l2, int[] carryRef) {
        /**
         * 递归相加，通过 carryRef[0] 返回进位
         */
        if (l1 == null && l2 == null) {
            carryRef[0] = 0;
            return null;
        }

        // 递归处理后续节点
        ListNode nextNode = addHelper(l1.next, l2.next, carryRef);

        // 计算当前位
        int total = l1.val + l2.val + carryRef[0];
        int digit = total % 10;
        carryRef[0] = total / 10;

        // 创建当前节点
        ListNode current = new ListNode(digit);
        current.next = nextNode;

        return current;
    }
}
```

### 方法四：简化版（转为数字，仅用于理解）

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        /**
         * 先转为字符串做大数加法，再转回链表
         * 不推荐：数字很长时需要用 BigInteger，仅用于理解题意
         */
        // 链表转字符串
        StringBuilder sb1 = new StringBuilder();
        StringBuilder sb2 = new StringBuilder();

        while (l1 != null) { sb1.append(l1.val); l1 = l1.next; }
        while (l2 != null) { sb2.append(l2.val); l2 = l2.next; }

        // 大数相加（逐位加法，避免 overflow）
        int i = sb1.length() - 1, j = sb2.length() - 1;
        int carry = 0;
        ListNode head = null;

        while (i >= 0 || j >= 0 || carry != 0) {
            int d1 = (i >= 0) ? sb1.charAt(i--) - '0' : 0;
            int d2 = (j >= 0) ? sb2.charAt(j--) - '0' : 0;
            int sum = d1 + d2 + carry;
            carry = sum / 10;
            ListNode node = new ListNode(sum % 10);
            node.next = head;
            head = node;
        }

        return head;
    }
}
```

## 复杂度分析

**方法一（栈）：**
- 时间复杂度：O(max(m, n))，m 和 n 分别是两个链表的长度
- 空间复杂度：O(m + n)，需要两个栈

**方法二（反转链表）：**
- 时间复杂度：O(max(m, n))
- 空间复杂度：O(1)，只需要常量空间（但会修改原链表）

**方法三（递归）：**
- 时间复杂度：O(max(m, n))
- 空间复杂度：O(max(m, n))，递归调用栈

## 图解示例

以 l1 = [7,2,4,3], l2 = [5,6,4] 为例（方法一）：

```
l1: 7 -> 2 -> 4 -> 3  (表示 7243)
l2: 5 -> 6 -> 4       (表示 564)

步骤 1: 压栈
stack1: [7, 2, 4, 3]（栈顶为 3）
stack2: [5, 6, 4]（栈顶为 4）

步骤 2: 从栈顶开始相加（从低位到高位）

第 1 步: 3 + 4 = 7, carry = 0
  result: 7

第 2 步: 4 + 6 = 10, carry = 1
  result: 0 -> 7

第 3 步: 2 + 5 + 1 = 8, carry = 0
  result: 8 -> 0 -> 7

第 4 步: 7 + 0 = 7, carry = 0
  result: 7 -> 8 -> 0 -> 7

最终结果: [7, 8, 0, 7] (表示 7807)
```

## 关键点总结

1. **栈的应用**：通过栈实现"反向访问"，不修改原链表
2. **头插法**：构建结果链表时使用头插法，避免再次反转
3. **进位处理**：与第 2 题相同，注意最高位的进位
4. **边界条件**：两个链表长度不同、最后的进位等
5. **空间权衡**：栈方法需要额外空间，但不修改原链表

## 易错点

1. **忘记处理最后的进位**：
   ```java
   // 错误：循环结束后忘记检查 carry
   while (!stack1.isEmpty() || !stack2.isEmpty()) {
       ...
   }

   // 正确：循环条件包含 carry
   while (!stack1.isEmpty() || !stack2.isEmpty() || carry != 0) {
       ...
   }
   ```

2. **链表构建顺序**：
   - 使用头插法：`newNode.next = head; head = newNode;`
   - 确保结果链表的顺序正确

3. **空栈处理**：
   ```java
   // 正确处理空栈
   int val1 = stack1.isEmpty() ? 0 : stack1.pop();
   int val2 = stack2.isEmpty() ? 0 : stack2.pop();
   ```

4. **反转链表的副作用**：
   - 方法二会修改原链表
   - 如果不允许修改，必须使用栈或先复制链表
