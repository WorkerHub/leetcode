## 题目描述

给你一个方程，左边用 `words` 表示，右边用 `result` 表示。

你需要根据以下规则检查方程是否可解：

- 每个字符都会被解码成一位数字（0-9）
- 每对不同的字符必须映射到不同的数字
- 每个 `words[i]` 和 `result` 都会被解码成一个没有前导零的数字
- 左侧数字之和（`words`）等于右侧数字（`result`）

如果方程可解，返回 `true`，否则返回 `false`。

示例 1：
```
输入：words = ["SEND","MORE"], result = "MONEY"
输出：true
解释：映射 'S'-> 9, 'E'->5, 'N'->6, 'D'->7, 'M'->1, 'O'->0, 'R'->8, 'Y'->2
所以 "SEND" + "MORE" = "MONEY" ,  9567 + 1085 = 10652
```

示例 2：
```
输入：words = ["SIX","SEVEN","SEVEN"], result = "TWENTY"
输出：true
解释：映射 'S'-> 6, 'I'->5, 'X'->0, 'E'->8, 'V'->7, 'N'->2, 'T'->1, 'W'->'3', 'Y'->4
所以 "SIX" + "SEVEN" + "SEVEN" = "TWENTY" ,  650 + 68782 + 68782 = 138214
```

示例 3：
```
输入：words = ["LEET","CODE"], result = "POINT"
输出：false
解释：无解，无法使等式成立
```

提示：
- `2 <= words.length <= 5`
- `1 <= words[i].length, result.length <= 7`
- `words[i]`, `result` 只包含大写英文字母
- 表达式中使用的不同字符数不会超过 10

## 解题思路

这是一个典型的约束满足问题（CSP），使用回溯算法求解。

关键点：
1. 每个字母对应一个 0-9 的数字，且映射关系是一一对应的
2. 每个单词和结果都不能有前导零
3. 所有单词的数值之和必须等于结果的数值

优化策略：
1. 按列从右到左处理（从个位到高位），可以提前剪枝
2. 维护进位信息，及时发现不可行的分配
3. 使用位掩码快速判断数字是否已被使用

## Java 代码实现

### 方法一：回溯（推荐）

```java
import java.util.*;

class Solution {
    private int[] charToDigit = new int[26]; // 字符到数字的映射
    private boolean[] usedDigits = new boolean[10]; // 数字是否已被使用
    private boolean[] noZero = new boolean[26]; // 不能为 0 的字符
    private char[] chars; // 所有唯一字符
    private String[] words;
    private String result;
    
    public boolean isSolvable(String[] words, String result) {
        this.words = words;
        this.result = result;
        
        Arrays.fill(charToDigit, -1);
        
        // 收集所有唯一字符
        Set<Character> charSet = new HashSet<>();
        for (String word : words) {
            for (char c : word.toCharArray()) charSet.add(c);
        }
        for (char c : result.toCharArray()) charSet.add(c);
        
        // 如果字符数超过 10，无解
        if (charSet.size() > 10) return false;
        
        // 不能为 0 的字符（首字母）
        for (String word : words) {
            if (word.length() > 1) noZero[word.charAt(0) - 'A'] = true;
        }
        if (result.length() > 1) noZero[result.charAt(0) - 'A'] = true;
        
        chars = new char[charSet.size()];
        int idx = 0;
        for (char c : charSet) chars[idx++] = c;
        
        return backtrack(0);
    }
    
    private boolean backtrack(int idx) {
        // 所有字符都已分配，验证等式
        if (idx == chars.length) {
            return verify();
        }
        
        char c = chars[idx];
        int ci = c - 'A';
        
        // 尝试为当前字符分配 0-9
        for (int digit = 0; digit <= 9; digit++) {
            // 跳过已使用的数字
            if (usedDigits[digit]) continue;
            // 前导字符不能为 0
            if (digit == 0 && noZero[ci]) continue;
            
            // 分配
            charToDigit[ci] = digit;
            usedDigits[digit] = true;
            
            if (backtrack(idx + 1)) return true;
            
            // 回溯
            charToDigit[ci] = -1;
            usedDigits[digit] = false;
        }
        
        return false;
    }
    
    private boolean verify() {
        long total = 0;
        for (String word : words) {
            long num = 0;
            for (char c : word.toCharArray()) {
                num = num * 10 + charToDigit[c - 'A'];
            }
            total += num;
        }
        
        long resultNum = 0;
        for (char c : result.toCharArray()) {
            resultNum = resultNum * 10 + charToDigit[c - 'A'];
        }
        
        return total == resultNum;
    }
}
```

### 方法二：简化版回溯

```java
import java.util.*;

class Solution {
    public boolean isSolvable(String[] words, String result) {
        // 收集所有字符
        Set<Character> allCharsSet = new LinkedHashSet<>();
        for (String word : words) {
            for (char c : word.toCharArray()) allCharsSet.add(c);
        }
        for (char c : result.toCharArray()) allCharsSet.add(c);
        
        if (allCharsSet.size() > 10) return false;
        
        char[] chars = new char[allCharsSet.size()];
        int idx = 0;
        for (char c : allCharsSet) chars[idx++] = c;
        
        // 不能为 0 的字符
        Set<Character> noZero = new HashSet<>();
        for (String word : words) {
            if (word.length() > 1) noZero.add(word.charAt(0));
        }
        if (result.length() > 1) noZero.add(result.charAt(0));
        
        int[] mapping = new int[26];
        Arrays.fill(mapping, -1);
        boolean[] used = new boolean[10];
        
        return bt(chars, 0, noZero, mapping, used, words, result);
    }
    
    private boolean bt(char[] chars, int pos, Set<Character> noZero,
                        int[] mapping, boolean[] used,
                        String[] words, String result) {
        if (pos == chars.length) {
            // 检查等式
            long left = 0;
            for (String w : words) {
                long num = 0;
                for (char c : w.toCharArray()) num = num * 10 + mapping[c - 'A'];
                left += num;
            }
            long right = 0;
            for (char c : result.toCharArray()) right = right * 10 + mapping[c - 'A'];
            return left == right;
        }
        
        char c = chars[pos];
        for (int d = 0; d <= 9; d++) {
            if (used[d]) continue;
            if (d == 0 && noZero.contains(c)) continue;
            
            mapping[c - 'A'] = d;
            used[d] = true;
            
            if (bt(chars, pos + 1, noZero, mapping, used, words, result)) return true;
            
            mapping[c - 'A'] = -1;
            used[d] = false;
        }
        
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10!)，最坏情况下需要尝试所有可能的字母到数字的映射。实际运行中由于剪枝会快很多。
- 空间复杂度：O(n)，其中 n 是字符的数量，主要是递归栈和映射表的空间

## 关键点总结

1. 这是一个约束满足问题，使用回溯算法
2. 需要记录哪些数字已被使用（避免重复分配）
3. 首字母不能映射到 0（避免前导零）
4. 可以按列从右到左处理，结合进位进行剪枝优化
5. 字符数超过 10 时直接返回 false

## 易错点

1. 忘记检查前导零的约束
2. 没有正确维护已使用数字的集合
3. 回溯时忘记恢复状态
4. 字符数超过 10 的边界情况
5. Java 中注意使用 long 避免整数溢出
