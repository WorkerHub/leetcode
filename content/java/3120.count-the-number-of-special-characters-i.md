## 题目描述

统计字符串中大小写形式都出现的字母数量（特殊字母）。

## 解题思路

用集合存储所有出现字符，遍历26个字母检查大小写是否都存在。

## Java 代码实现

```java
class Solution {
    public int numberOfSpecialChars(String word) {
        boolean[] has = new boolean[128];
        for (char c : word.toCharArray()) has[c] = true;
        int ans = 0;
        for (char c = 'a'; c <= 'z'; c++) {
            if (has[c] && has[c - 32]) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **大小写对应**：'a'和'A'差32
2. **26个字母逐一检查**
3. **用boolean数组替代Set**
