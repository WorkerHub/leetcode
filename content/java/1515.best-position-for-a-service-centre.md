## 题目描述

给定客户位置数组，找到使所有客户到该点欧几里得距离之和最小的服务中心位置。

## 解题思路

几何中位数问题（费马点）。用 Weiszfeld 迭代算法或模拟退火求解。

## Java 代码实现

```java
class Solution {
    public double getMinDistSum(int[][] positions) {
        // 初始点：重心
        double cx = 0, cy = 0;
        for (int[] p : positions) { cx += p[0]; cy += p[1]; }
        cx /= positions.length;
        cy /= positions.length;
        
        // 模拟退火
        double step = 100;
        double eps = 1e-7;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        
        while (step > eps) {
            boolean moved = false;
            double curDist = totalDist(positions, cx, cy);
            for (int[] d : dirs) {
                double nx = cx + step * d[0];
                double ny = cy + step * d[1];
                double newDist = totalDist(positions, nx, ny);
                if (newDist < curDist) {
                    cx = nx;
                    cy = ny;
                    curDist = newDist;
                    moved = true;
                    break;
                }
            }
            if (!moved) step *= 0.5;
        }
        return totalDist(positions, cx, cy);
    }
    
    private double totalDist(int[][] positions, double cx, double cy) {
        double sum = 0;
        for (int[] p : positions) {
            sum += Math.sqrt((cx - p[0]) * (cx - p[0]) + (cy - p[1]) * (cy - p[1]));
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(1/eps))
- **空间复杂度**：O(1)

## 关键点总结

1. **几何中位数**：不是算术平均值
2. **模拟退火**：四方向探索，步长减半
3. **初始点**：从重心出发加速收敛
4. **精度控制**：步长 < 1e-7 时停止
