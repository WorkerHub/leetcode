## 题目描述

返回发送单词总数最多的发件人，同数量取字典序最大的。

## 解题思路

HashMap统计每个发件人的单词总数（按空格split），遍历找最大值（同值取字典序大的）。

## Java 代码实现

```java
class Solution {
    public String largestWordCount(String[] messages, String[] senders) {
        Map<String, Integer> count = new HashMap<>();
        for (int i = 0; i < messages.length; i++) {
            int words = messages[i].split(" ").length;
            count.merge(senders[i], words, Integer::sum);
        }

        String best = "";
        int bestCount = 0;
        for (var entry : count.entrySet()) {
            String sender = entry.getKey();
            int cnt = entry.getValue();
            if (cnt > bestCount || (cnt == bestCount && sender.compareTo(best) > 0)) {
                best = sender;
                bestCount = cnt;
            }
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * L)，L为平均消息长度
- **空间复杂度**：O(K)，K为不同发件人数

## 关键点总结

1. **split(" ")计算单词数**
2. **同单词数取字典序最大**：compareTo>0
3. **merge累加单词计数**
