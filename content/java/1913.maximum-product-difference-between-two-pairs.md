## 题目描述

给你整数数组 `nums`，选四个不同下标使 `(nums[w] * nums[x]) - (nums[y] * nums[z])` 最大，返回最大乘积差。

## 解题思路

贪心：最大乘积差 = 最大两数的乘积 - 最小两数的乘积。排序后取两端即可。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maxProductDifference(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        // 最大两数乘积 - 最小两数乘积
        return nums[n - 1] * nums[n - 2] - nums[0] * nums[1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，排序
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：最大乘积在最大两数，最小乘积在最小两数
2. 排序后直接取两端，四个下标自然不同（数组长度 >= 4）
