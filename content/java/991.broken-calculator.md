## 题目描述

坏计算器上显示数字 startValue，可以乘 2 或减 1，返回得到 target 的最小操作数。

**示例：**
```
输入：startValue = 2, target = 3
输出：2（2 -> 4 -> 3）
```

## 解题思路

逆向贪心：从 target 逆推到 startValue。偶数除以 2，奇数加 1。当 target <= startValue 时只能加。

## Java 代码实现

```java
class Solution {
    public int brokenCalc(int startValue, int target) {
        int ops = 0;

        while (target > startValue) {
            if (target % 2 == 0) {
                target /= 2;
            } else {
                target += 1;
            }
            ops++;
        }

        return ops + (startValue - target);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log target)
- **空间复杂度**：O(1)

## 关键点总结

1. **逆向思考**：从 target 推回 startValue 更简单
2. **贪心选择**：偶数必除 2，奇数必加 1
3. **终止条件**：target <= startValue 后只需加
