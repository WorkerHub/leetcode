## 题目描述

给定链表头节点，重复删除所有和为 0 的连续节点序列，返回最终链表。

**示例：**
```
输入：head = [1,2,-3,3,1]
输出：[3,1]
```

## 解题思路

前缀和 + 哈希表：如果两个位置前缀和相同，说明中间节点和为 0。第一遍记录前缀和到节点映射（相同前缀和覆盖为最后出现的节点），第二遍重新遍历，跳过中间节点。

## Java 代码实现

```java
class Solution {
    public ListNode removeZeroSumSublists(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        // 第一遍：记录前缀和 → 最后出现的节点
        Map<Integer, ListNode> prefixMap = new HashMap<>();
        int prefix = 0;
        for (ListNode node = dummy; node != null; node = node.next) {
            prefix += node.val;
            prefixMap.put(prefix, node);
        }

        // 第二遍：跳过和为0的段
        prefix = 0;
        for (ListNode node = dummy; node != null; node = node.next) {
            prefix += node.val;
            node.next = prefixMap.get(prefix).next;
        }

        return dummy.next;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **前缀和相同**：两位置间节点和为 0
2. **两次遍历**：第一次建映射，第二次跳过
3. **dummy 节点**：处理头部被删除的情况
4. **覆盖存储**：同一前缀和保留最后节点，自动跳过中间
