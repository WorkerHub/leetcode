## 题目描述

在无限大网格中，每步可向 8 个方向移动或原地不动，判断能否恰好经过 t 步从 `(sx, sy)` 到 `(fx, fy)`。

## 解题思路

切比雪夫距离：8 方向移动的最短路径 = `max(|dx|, |dy|)`，只要 `t >= dist` 即可（多余步数可来回消化）；特殊情况：起点等于终点时 t=1 不可达。

## Java 代码实现

```java
class Solution {
    public boolean isReachableAtTime(int sx, int sy, int fx, int fy, int t) {
        // 切比雪夫距离（8 方向最少步数）
        int dist = Math.max(Math.abs(fx - sx), Math.abs(fy - sy));

        // 起点等于终点的特殊情况：t=1 时无法原地返回
        if (dist == 0) {
            return t != 1;
        }

        // 步数足够即可（多余步数可通过来回移动消化）
        return t >= dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 8 方向移动的最短路径是切比雪夫距离，不是曼哈顿距离
2. 多余步数无奇偶限制，可走对角线来回消化
3. 起点等于终点且 t=1 是唯一特殊的不可达情况
