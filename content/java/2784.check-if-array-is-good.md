## 题目描述

给你整数数组 `nums`，判断它是否是"好数组"：存在正整数 n 使得数组由 1 个 1 和 n 个 n 组成（即排序后为 `[1, n, n, ..., n]`）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public boolean isGood(int[] nums) {
        int n = nums.length - 1; // n + 1 个元素，n 推断为 len-1
        Arrays.sort(nums);
        if (nums[0] != 1) return false;
        for (int i = 1; i <= n; i++) {
            if (nums[i] != n) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序主导
- 空间复杂度：O(1)

## 关键点总结

1. 数组长度为 n+1，故 `n = nums.length - 1`
2. 排序后验证 `[1, n, n, ..., n]`
3. n=1 时数组应为 `[1, 1]`，特殊情况自然处理
