## 题目描述

给你 m 行 n 列的网格图，用 3 种颜色涂色，相邻格子颜色不同，返回方案数 mod 10^9+7（1 ≤ m ≤ 5，1 ≤ n ≤ 1000）。

## 解题思路

列状态压缩 DP：用三进制数表示每列的涂色方案，预计算合法列状态和相邻列的兼容关系，按列递推 dp。

## Java 代码实现

```java
import java.util.*;

class Solution {
    static final int MOD = 1_000_000_007;

    public int colorTheGrid(int m, int n) {
        // 枚举合法列状态（列内相邻格颜色不同）
        List<int[]> validCols = new ArrayList<>();
        int total = (int) Math.pow(3, m);
        for (int mask = 0; mask < total; mask++) {
            int[] col = new int[m];
            int tmp = mask;
            boolean ok = true;
            for (int i = 0; i < m; i++) {
                col[i] = tmp % 3;
                tmp /= 3;
                if (i > 0 && col[i] == col[i - 1]) { ok = false; break; }
            }
            if (ok) validCols.add(col);
        }

        int sz = validCols.size();
        // 预计算两列是否兼容（同行颜色不同）
        boolean[][] compat = new boolean[sz][sz];
        for (int i = 0; i < sz; i++)
            for (int j = 0; j < sz; j++) {
                boolean ok = true;
                for (int r = 0; r < m; r++)
                    if (validCols.get(i)[r] == validCols.get(j)[r]) { ok = false; break; }
                compat[i][j] = ok;
            }

        // DP
        long[] dp = new long[sz];
        Arrays.fill(dp, 1); // 第一列每种合法状态各 1 种
        for (int col = 1; col < n; col++) {
            long[] ndp = new long[sz];
            for (int j = 0; j < sz; j++)
                for (int i = 0; i < sz; i++)
                    if (compat[i][j]) ndp[j] = (ndp[j] + dp[i]) % MOD;
            dp = ndp;
        }

        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * S^2)，S 为合法列状态数（m=5 时约 48）
- **空间复杂度**：O(S^2)

## 关键点总结

1. 三进制状态压缩，列内相邻格不同色
2. 预计算兼容矩阵，相邻列同行颜色不同
3. 按列滚动 DP，答案为最后一列所有状态之和
