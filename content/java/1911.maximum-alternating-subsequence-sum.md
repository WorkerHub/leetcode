## 题目描述

给你数组 `nums`，交替子序列和定义为偶数下标元素之和减去奇数下标元素之和，返回任意子序列的最大交替子序列和。

## 解题思路

DP：维护两个状态——`even`（当前子序列长度为偶数时的最大交替和）和 `odd`（奇数长度时的最大交替和）。每个元素既可以加入（取偶数位）也可以减去（取奇数位）。

## Java 代码实现

```java
class Solution {
    public long maxAlternatingSum(int[] nums) {
        long even = 0, odd = Long.MIN_VALUE / 2;

        for (int x : nums) {
            long newEven = Math.max(even, odd + x); // 在奇数位后加一个偶数位元素
            long newOdd = Math.max(odd, even - x);  // 在偶数位后减一个奇数位元素
            even = newEven;
            odd = newOdd;
        }
        return even; // 答案是偶数长度（含空子序列）的最大值
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. `even` 初始化为 0（空子序列），`odd` 初始化为负无穷
2. 偶数位加、奇数位减，状态转移同时更新两个变量
3. 注意使用 long 防止溢出
