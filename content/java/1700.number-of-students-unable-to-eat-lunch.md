## 题目描述

学生队列（喜欢 0 或 1），三明治栈（0 或 1）。每轮队首学生喜欢栈顶则取走，否则移到队尾。直到无人喜欢栈顶为止，返回无法吃到的学生数。

## 解题思路

**计数法：** 学生可以无限循环队尾，因此只要还有学生喜欢当前栈顶即可继续。统计喜欢 0 和 1 的学生数，按栈顺序分配，某类型计数为 0 时停止。

## Java 代码实现

```java
class Solution {
    public int countStudents(int[] students, int[] sandwiches) {
        int[] count = new int[2];
        for (int s : students) count[s]++;
        for (int s : sandwiches) {
            if (count[s] == 0) break; // 无人喜欢当前三明治
            count[s]--;
        }
        return count[0] + count[1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 学生可以反复排到队尾，顺序不重要，只有"人数"重要
2. 当某类型三明治对应学生数为 0 时，后续均无法匹配，直接停止
