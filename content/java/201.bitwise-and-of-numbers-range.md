## 题目描述

给你两个整数 `left` 和 `right`，表示区间 `[left, right]`，返回此区间内所有数字按位与的结果（包含 `left`、`right` 端点）。

**示例 1：**
```
输入：left = 5, right = 7
输出：4
解释：5 & 6 & 7 = 4
```

**示例 2：**
```
输入：left = 0, right = 0
输出：0
```

**示例 3：**
```
输入：left = 1, right = 2147483647
输出：0
```

**提示：**
- `0 <= left <= right <= 2^31 - 1`

## 解题思路

这道题目的关键在于理解**连续数字按位与的规律**。

### 核心观察

1. **连续数字的特点**：在一个连续的数字范围内，低位的二进制位会不断变化
2. **按位与的特性**：只要有一个 0，结果就是 0
3. **关键发现**：对于连续的数字，从某一位开始，右边的所有位一定会出现 0

**举例说明**：
```
5 = 101
6 = 110
7 = 111

5 & 6 & 7 = 100 = 4
```

可以看到，从右往左数第 1 位和第 2 位，在 5、6、7 中会出现不同的值，按位与后变为 0。只有最高位保持不变。

### 解题方法

**方法核心**：找到 left 和 right 的**公共前缀**，后面的位数全部置为 0。

为什么？因为：
- left 和 right 之间的所有数字，在公共前缀之后的位数上，一定会经历从 0 到 1 的变化
- 一旦出现 0，按位与的结果就是 0

**实现方式**：
1. 不断右移 left 和 right，直到两者相等（找到公共前缀）
2. 记录右移的次数
3. 将公共前缀左移相应次数

## Java 代码实现

### 方法一：位移找公共前缀（推荐）⭐

```java
class Solution {
    public int rangeBitwiseAnd(int left, int right) {
        // 记录右移次数
        int shift = 0;
        
        // 不断右移，直到 left 和 right 相等（找到公共前缀）
        while (left < right) {
            left >>= 1;
            right >>= 1;
            shift++;
        }
        
        // 将公共前缀左移回原位置
        return left << shift;
    }
}
```

**代码说明**：
- 通过右移操作，逐步去除右边的不同位
- 当 left == right 时，说明找到了公共前缀
- 左移 shift 位，恢复到原来的位数

### 方法二：Brian Kernighan 算法优化

```java
class Solution {
    public int rangeBitwiseAnd(int left, int right) {
        // 不断消除 right 最右边的 1，直到 right <= left
        while (left < right) {
            // right & (right - 1) 可以消除最右边的 1
            right = right & (right - 1);
        }
        
        return right;
    }
}
```

**代码说明**：
- `right & (right - 1)` 是 Brian Kernighan 算法，可以清除最右边的 1
- 持续清除 right 的最右边的 1，直到 right <= left
- 此时的 right 就是结果

**示例演示**（left = 5, right = 7）：
```
right = 7 (111)
7 & 6 = 110 (清除最右边的 1)
6 & 5 = 100 (清除最右边的 1)
此时 right = 4 <= left = 5 的下一个值，停止
结果 = 4
```

### 方法三：暴力法（仅用于理解，会超时）

```java
class Solution {
    public int rangeBitwiseAnd(int left, int right) {
        // 从 left 开始，逐个进行按位与
        int result = left;
        for (int num = left + 1; num <= right; num++) {
            result &= num;
            // 优化：如果 result 已经为 0，可以提前退出
            if (result == 0) {
                break;
            }
        }
        return result;
    }
}
```

**注意**：这种方法在范围很大时会超时，不推荐使用。

## 复杂度分析

### 方法一：位移找公共前缀
- **时间复杂度**：O(log n)，n 是 right 的值。最多右移 32 次（整数的位数）
- **空间复杂度**：O(1)，只使用常数额外空间

### 方法二：Brian Kernighan 算法
- **时间复杂度**：O(log n)，最坏情况下需要清除所有的 1
- **空间复杂度**：O(1)

### 方法三：暴力法
- **时间复杂度**：O(right - left)，需要遍历所有数字
- **空间复杂度**：O(1)

## 关键点总结

1. **核心思想**：连续数字的按位与结果等于它们的公共前缀
2. **位运算技巧**：通过右移找公共前缀，或通过 Brian Kernighan 算法清除 1
3. **性能优化**：不需要遍历所有数字，时间复杂度降到 O(log n)
4. **边界情况**：left == right 时，直接返回 left 即可

## 易错点

1. **暴力遍历超时**：范围可能很大（最大到 2^31 - 1），不能逐个遍历
2. **位运算理解**：需要理解 `&` 操作的特性，以及右移、左移的含义
3. **公共前缀概念**：要理解为什么找公共前缀就是答案
4. **边界处理**：left = 0 的情况需要特别注意
