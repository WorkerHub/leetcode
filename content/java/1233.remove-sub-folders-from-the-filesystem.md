## 题目描述

给定文件夹列表 folder，删除所有子文件夹，返回剩余文件夹。folder[i] 是 folder[j] 的子文件夹当且仅当 folder[i] 以 folder[j] + "/" 开头。

**示例：**
```
输入：folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
输出：["/a","/c/d","/c/f"]
```

## 解题思路

排序后，父文件夹一定在子文件夹前面。遍历时检查当前路径是否以上一个保留路径 + "/" 开头。

## Java 代码实现

```java
class Solution {
    public List<String> removeSubfolders(String[] folder) {
        Arrays.sort(folder);
        List<String> result = new ArrayList<>();
        result.add(folder[0]);
        
        for (int i = 1; i < folder.length; i++) {
            String last = result.get(result.size() - 1);
            // 检查是否是子文件夹
            if (!folder[i].startsWith(last + "/")) {
                result.add(folder[i]);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L × log n)，L 为路径平均长度
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **排序**：字典序排序后父文件夹在子文件夹前面
2. **startsWith + "/"**：必须加 "/"，防止 "/a/b" 误判为 "/a/bc" 的父目录
3. **只需比较上一个保留的**：排序保证中间不会有其他父目录
