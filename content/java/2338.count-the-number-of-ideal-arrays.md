## 题目描述

返回长度为 n、每个元素在 [1, maxValue] 范围内、且每个元素都能被前一个整除的不同数组数目（模 10^9+7）。

## 解题思路

每个理想数组对应一条严格递增因子链（长度 k），再将 k 个不同值分配到 n 个位置（隔板法：C(n-1, k-1) 种）。预处理 `f[v][k]`（以 v 结尾、长度为 k 的因子链数），链长最大 log2(maxValue)≈14。

## Java 代码实现

```java
class Solution {
    public int idealArrays(int n, int maxValue) {
        final int MOD = 1_000_000_007;
        final int MAX_K = 14; // 因子链最大长度

        // f[v][k]：以 v 结尾长度为 k 的严格递增因子链数
        long[][] f = new long[maxValue + 1][MAX_K + 1];
        for (int v = 1; v <= maxValue; v++) f[v][1] = 1;

        for (int k = 1; k < MAX_K; k++) {
            for (int v = 1; v <= maxValue; v++) {
                if (f[v][k] == 0) continue;
                for (int mul = 2 * v; mul <= maxValue; mul += v) {
                    f[mul][k + 1] = (f[mul][k + 1] + f[v][k]) % MOD;
                }
            }
        }

        // 预处理组合数 C(n-1, k-1)
        long[] comb = new long[MAX_K + 1];
        comb[0] = 1;
        for (int k = 1; k <= MAX_K; k++) {
            // C(n-1, k-1) = C(n-1, k-2) * (n-k+1) / (k-1)
            comb[k] = comb[k - 1] * (n - k + 1) % MOD;
            // 需要除以 k，用逆元
            comb[k] = comb[k] * modInverse(k, MOD) % MOD;
        }

        long ans = 0;
        for (int v = 1; v <= maxValue; v++) {
            for (int k = 1; k <= MAX_K; k++) {
                ans = (ans + f[v][k] * comb[k - 1]) % MOD;
            }
        }
        return (int) ans;
    }

    private long modInverse(long a, long mod) {
        // 费马小定理：a^(mod-2) mod mod
        long result = 1, exp = mod - 2;
        a %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * a % mod;
            a = a * a % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(maxValue × log(maxValue) × MAX_K)
- **空间复杂度**：O(maxValue × MAX_K)

## 关键点总结

1. 理想数组 = 因子链 + 隔板法分配，转化为组合数问题。
2. 因子链最长 log2(10^4)≈14，状态空间可控。
3. 组合数 C(n-1, k-1) 需用费马小定理求逆元进行模除。
