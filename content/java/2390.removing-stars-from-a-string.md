## 题目描述

给你含 `*` 的字符串 `s`，每个 `*` 可以删除其左侧最近的非 `*` 字符及其自身，返回移除所有星号后的字符串。

## 解题思路

栈模拟：遇到字母则压栈，遇到 `*` 则弹出栈顶，最后栈中字符从底到顶拼接即为答案。

## Java 代码实现

```java
class Solution {
    public String removeStars(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (c == '*') {
                sb.deleteCharAt(sb.length() - 1); // 弹出最近的字符
            } else {
                sb.append(c); // 普通字符入栈
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 用 `StringBuilder` 模拟栈，`deleteCharAt(length-1)` 等价于弹栈。
2. 遇到 `*` 删除最近字符，遇到字母追加，最后直接 `toString()`。
3. 题目保证每个 `*` 都有对应可删除字符，无需检查空栈。
