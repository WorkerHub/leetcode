## 题目描述

给定两个单词 `word1` 和 `word2`，返回使得它们相同所需的最小删除步数。

**示例：**
```
输入：word1 = "sea", word2 = "eat"
输出：2
```

## 解题思路

转化为 LCS 问题：最小删除步数 = m + n - 2 * LCS。

## Java 代码实现

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        // 求 LCS
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return m + n - 2 * dp[m][n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **LCS 转化**：删除步数 = m + n - 2*LCS
2. **状态转移**：字符相同取对角+1，不同取上/左最大
