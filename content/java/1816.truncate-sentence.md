## 题目描述

给你句子 `s` 和整数 `k`，返回前 `k` 个单词组成的字符串。

## 解题思路

扫描字符串，遇到第 k 个空格时截断返回；若未遇到则返回整个字符串。

## Java 代码实现

```java
class Solution {
    public String truncateSentence(String s, int k) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == ' ') {
                count++;
                if (count == k) return s.substring(0, i);
            }
        }
        return s; // k 等于总单词数，返回整个句子
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计输出）

## 关键点总结

1. 遇到第 k 个空格时截取该空格之前的子字符串
2. k 等于总单词数时不存在第 k 个空格，返回整个字符串
