## 题目描述

给你一个 3×3 矩阵，每次可将一块石头移到相邻格子，返回使每格恰好有 1 块石头所需的最少移动次数。

## 解题思路

将多余石头和空格分别收集，用状态压缩 DP 枚举最优匹配：`dp[mask]` 表示已填充 mask 对应空格所需最少移动，移动代价为曼哈顿距离。

## Java 代码实现

```java
class Solution {
    public int minimumMoves(int[][] grid) {
        List<int[]> extras = new ArrayList<>(); // 多余石头位置（每块单独记录）
        List<int[]> empties = new ArrayList<>(); // 空格位置

        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (grid[i][j] > 1) {
                    for (int k = 0; k < grid[i][j] - 1; k++) {
                        extras.add(new int[]{i, j});
                    }
                } else if (grid[i][j] == 0) {
                    empties.add(new int[]{i, j});
                }
            }
        }

        int n = empties.size();
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            int assigned = Integer.bitCount(mask); // 已分配的多余石头数
            if (assigned >= n) continue;
            // 将 extras[assigned] 分配到某个未分配的空格
            for (int j = 0; j < n; j++) {
                if ((mask >> j & 1) == 0) {
                    int dist = Math.abs(extras.get(assigned)[0] - empties.get(j)[0])
                             + Math.abs(extras.get(assigned)[1] - empties.get(j)[1]);
                    dp[mask | (1 << j)] = Math.min(dp[mask | (1 << j)], dp[mask] + dist);
                }
            }
        }

        return dp[(1 << n) - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^k × k)，k 为空格数（最多 8）
- **空间复杂度**：O(2^k)

## 关键点总结

1. 多余石头和空格数相等，问题转化为最优二分匹配
2. 状态压缩 DP：mask 表示已分配的空格集合
3. extras 按序分配，枚举为哪个空格赋值，转移时复杂度为 O(k)
