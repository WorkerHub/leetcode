## 题目描述

给定数组 `nums`（n <= 13）和整数 `k`。找字典序最小的排列，使所有元素拼接成的数能被 `k` 整除，不存在返回空数组。

## 解题思路

状态压缩 DP：`dp[mask][r]` 表示使用 mask 中的元素能否拼接出余数为 r 的数。拼接公式：在余数 r 后追加数字 x（d 位）得 `(r * 10^d + x) % k`。字典序最小重建：另建反向 DP `back[mask][r]` 表示从余数 r 出发，使用 mask 中元素能否最终余数为 0，逐位贪心选最小元素。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[] concatenatedDivisibility(int[] nums, int k) {
        int n = nums.length;
        int full = (1 << n) - 1;

        // 预计算每个数字追加时的乘数 10^d % k
        int[] pow10 = new int[n];
        for (int i = 0; i < n; i++) {
            int p = 1, x = nums[i];
            while (x > 0) { p = p * 10 % k; x /= 10; }
            pow10[i] = p;
        }

        // 前向 dp[mask][r]: 使用 mask 中元素，能否拼成余数 r
        boolean[][] dp = new boolean[1 << n][k];
        dp[0][0] = true;
        for (int mask = 0; mask < (1 << n); mask++) {
            for (int r = 0; r < k; r++) {
                if (!dp[mask][r]) continue;
                for (int i = 0; i < n; i++) {
                    if ((mask & (1 << i)) != 0) continue;
                    int nr = (r * pow10[i] + nums[i] % k) % k;
                    dp[mask | (1 << i)][nr] = true;
                }
            }
        }

        if (!dp[full][0]) return new int[0];

        // 反向 back[mask][r]: 从余数 r 出发，使用 mask 中元素能否到余数 0
        boolean[][] back = new boolean[1 << n][k];
        back[0][0] = true;
        for (int mask = 1; mask < (1 << n); mask++) {
            for (int r = 0; r < k; r++) {
                for (int i = 0; i < n; i++) {
                    if ((mask & (1 << i)) == 0) continue;
                    int nr = (r * pow10[i] + nums[i] % k) % k;
                    if (back[mask ^ (1 << i)][nr]) { back[mask][r] = true; break; }
                }
            }
        }

        // 贪心重建：每次选值最小的合法元素
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> nums[a] - nums[b]);

        int[] result = new int[n];
        int usedMask = 0, currR = 0;
        for (int step = 0; step < n; step++) {
            for (int idx : order) {
                if ((usedMask & (1 << idx)) != 0) continue;
                int nr = (currR * pow10[idx] + nums[idx] % k) % k;
                int remainMask = full ^ (usedMask | (1 << idx));
                if (back[remainMask][nr]) {
                    result[step] = nums[idx];
                    usedMask |= (1 << idx);
                    currR = nr;
                    break;
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n * k)
- 空间复杂度：O(2^n * k)

## 关键点总结

1. 拼接余数公式：`(r * 10^d + x) % k`
2. 反向 DP `back[mask][r]` 支持贪心重建时的可行性验证
3. 字典序最小：按元素值排序后逐位选最小合法元素
