## 题目描述

与 3291 相同，从 words 的前缀拼接 target，但数据范围更大（words 和 target 长度均达 5×10^4），需要 O(n log n) 算法。

## 解题思路

字符串哈希 + 二分 + DP：预计算 target 的前缀哈希及所有 words 前缀按长度分组的哈希集合。对每个位置 i，二分查找最长可匹配前缀长度 `best`，再更新 `dp[i+1..i+best]`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minValidStrings(String[] words, String target) {
        int n = target.length();
        long MOD = (1L << 61) - 1;
        long BASE = 131;

        // 预计算 target 的前缀哈希和幂次
        long[] h = new long[n + 1], pw = new long[n + 1];
        pw[0] = 1;
        for (int i = 0; i < n; i++) {
            h[i + 1] = (h[i] * BASE + target.charAt(i)) % MOD;
            pw[i + 1] = pw[i] * BASE % MOD;
        }

        // 按长度分组，收集 words 所有前缀的哈希值
        int maxLen = 0;
        for (String w : words) maxLen = Math.max(maxLen, w.length());
        Map<Integer, Set<Long>> lenToHashes = new HashMap<>();
        for (String word : words) {
            long hw = 0;
            for (int i = 0; i < word.length(); i++) {
                hw = (hw * BASE + word.charAt(i)) % MOD;
                lenToHashes.computeIfAbsent(i + 1, x -> new HashSet<>()).add(hw);
            }
        }

        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            if (dp[i] == Integer.MAX_VALUE) continue;
            // 二分查找从 i 开始的最长可匹配前缀长度
            int lo = 1, hi = Math.min(n - i, maxLen), best = 0;
            while (lo <= hi) {
                int mid = (lo + hi) >>> 1;
                long hashVal = ((h[i + mid] - h[i] * pw[mid]) % MOD + MOD) % MOD;
                Set<Long> set = lenToHashes.get(mid);
                if (set != null && set.contains(hashVal)) {
                    best = mid;
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            // 更新 [i+1, i+best] 的 dp 值
            for (int j = i + 1; j <= i + best; j++) {
                dp[j] = Math.min(dp[j], dp[i] + 1);
            }
        }
        return dp[n] == Integer.MAX_VALUE ? -1 : dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O((n + Σ|words|) log n)，二分 O(log n)，总体 O(n log n + Σ|words|)
- 空间复杂度：O(n + Σ|words|)

## 关键点总结

1. 字符串哈希支持 O(1) 查询子串哈希值
2. 若长度 `len` 可匹配则所有更短长度也可匹配，保证二分单调性
3. 用 `(1L << 61) - 1` 作为 MOD（梅森素数），减少哈希冲突
