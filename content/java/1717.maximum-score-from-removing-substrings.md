## 题目描述

字符串 `s`，删除 `"ab"` 得 `x` 分，删除 `"ba"` 得 `y` 分，可无限次操作，返回最大得分。

## 解题思路

**贪心 + 栈：** 先删分值高的子字符串，再删分值低的。用栈模拟：遍历时若栈顶与当前字符构成目标串则弹栈计分，否则入栈。两遍处理即可。

## Java 代码实现

```java
class Solution {
    public int maximumGain(String s, int x, int y) {
        // 高分目标优先
        char high1, high2, low1, low2;
        int highScore, lowScore;
        if (x >= y) {
            high1 = 'a'; high2 = 'b'; highScore = x;
            low1 = 'b'; low2 = 'a'; lowScore = y;
        } else {
            high1 = 'b'; high2 = 'a'; highScore = y;
            low1 = 'a'; low2 = 'b'; lowScore = x;
        }

        int total = 0;
        // 第一遍删高分串
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (sb.length() > 0 && sb.charAt(sb.length() - 1) == high1 && c == high2) {
                sb.deleteCharAt(sb.length() - 1);
                total += highScore;
            } else sb.append(c);
        }
        // 第二遍删低分串
        StringBuilder sb2 = new StringBuilder();
        for (int i = 0; i < sb.length(); i++) {
            char c = sb.charAt(i);
            if (sb2.length() > 0 && sb2.charAt(sb2.length() - 1) == low1 && c == low2) {
                sb2.deleteCharAt(sb2.length() - 1);
                total += lowScore;
            } else sb2.append(c);
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：高分操作先做，不影响低分操作
2. 栈模拟删除：遇到目标串就弹栈计分
