## 题目描述

用以太网线缆将 `n` 台计算机连接成一个网络，计算机的编号从 `0` 到 `n-1`。

线缆用 `connections` 表示，其中 `connections[i] = [a, b]` 表示第 `i` 条线缆连接了计算机 `a` 和 `b`。

网络中的任何一台计算机都可以通过网络**直接或者间接**访问同一个网络中其他任意一台计算机。

给你这个计算机网络的初始布线 `connections`，你可以拔开任意两台直连计算机之间的线缆，并用它来连接一对未直连的计算机。

请你计算并返回使所有计算机都连通所需的**最少操作次数**。如果不可能，则返回 `-1`。

**示例 1：**

```
输入：n = 4, connections = [[0,1],[0,2],[1,2]]
输出：1
解释：拔下 [1,2] 连接 [3,?] 即可
```

**示例 2：**

```
输入：n = 6, connections = [[0,1],[0,2],[0,3],[1,2],[1,3]]
输出：2
```

**示例 3：**

```
输入：n = 6, connections = [[0,1],[0,2],[0,3],[1,2]]
输出：-1
解释：线缆数量不足，无法连通所有计算机
```

**提示：**

- `1 <= n <= 10^5`
- `1 <= connections.length <= min(n*(n-1)/2, 10^5)`
- `connections[i].length == 2`
- `0 <= connections[i][0], connections[i][1] < n`
- 没有重复的连接

## 解题思路

**关键观察：**

1. **线缆数量检查**：要将 n 台计算机连成一个连通网络，至少需要 n-1 条线缆。如果 `connections.length < n-1`，直接返回 -1。

2. **最少操作次数**：

   设当前网络有 k 个连通分量（即 k 个独立的小网络），要将它们合并为 1 个，需要 **k-1** 次操作。

3. **如何求连通分量数**：使用**并查集（Union-Find）**。

## Java 代码实现

### 方法一：并查集（推荐）

```java
class Solution {
    private int[] parent;
    private int[] rank;
    private int count;
    
    public int makeConnected(int n, int[][] connections) {
        // 线缆不足，无法连通所有计算机
        if (connections.length < n - 1) return -1;
        
        // 初始化并查集
        parent = new int[n];
        rank = new int[n];
        count = n;
        for (int i = 0; i < n; i++) parent[i] = i;
        
        for (int[] conn : connections) {
            union(conn[0], conn[1]);
        }
        
        // 连通分量数 - 1 即为所需操作次数
        return count - 1;
    }
    
    private int find(int x) {
        // 路径压缩
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    private void union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return; // 已在同一分量
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            int tmp = rootX; rootX = rootY; rootY = tmp;
        }
        parent[rootY] = rootX;
        if (rank[rootX] == rank[rootY]) rank[rootX]++;
        count--;
    }
}
```

### 方法二：BFS 求连通分量数

```java
import java.util.*;

class Solution {
    public int makeConnected(int n, int[][] connections) {
        if (connections.length < n - 1) return -1;
        
        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] conn : connections) {
            graph.get(conn[0]).add(conn[1]);
            graph.get(conn[1]).add(conn[0]);
        }
        
        boolean[] visited = new boolean[n];
        int components = 0;
        
        for (int start = 0; start < n; start++) {
            if (!visited[start]) {
                // BFS 遍历整个连通分量
                Queue<Integer> queue = new LinkedList<>();
                queue.offer(start);
                visited[start] = true;
                while (!queue.isEmpty()) {
                    int node = queue.poll();
                    for (int neighbor : graph.get(node)) {
                        if (!visited[neighbor]) {
                            visited[neighbor] = true;
                            queue.offer(neighbor);
                        }
                    }
                }
                components++;
            }
        }
        
        return components - 1;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 并查集 | O((n+E) * α(n)) | O(n) |
| DFS/BFS | O(n + E) | O(n + E) |

其中 E 为边数，α(n) 是反阿克曼函数（极小，近似 O(1)）。

## 关键点总结

1. **必要条件**：线缆数 >= n-1，否则无解
2. **最少操作数 = 连通分量数 - 1**（每次操作减少一个分量）
3. 并查集是求连通分量数的高效工具
4. 路径压缩 + 按秩合并使并查集接近 O(1) 每次操作

## 易错点

1. **先判断线缆数量**：在做并查集之前先检查 `connections.length < n-1`，直接返回 -1
2. **连通分量数减 1**：k 个分量需要 k-1 次操作，不要返回 k
3. **并查集初始化**：每个节点的父节点初始化为自身
