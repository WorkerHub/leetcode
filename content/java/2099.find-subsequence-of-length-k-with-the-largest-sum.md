## 题目描述

给定整数数组nums和整数k，返回和最大的长度为k的子序列，元素按原始数组顺序排列。

## 解题思路

对(值,下标)排序取最大k个，再按原下标排序输出对应值。

## Java 代码实现

```java
class Solution {
    public int[] maxSubsequence(int[] nums, int k) {
        int n = nums.length;
        // 按值排序取最大k个的下标
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> nums[b] - nums[a]);
        
        // 取前k个下标并按原顺序排列
        int[] topK = new int[k];
        for (int i = 0; i < k; i++) topK[i] = indices[i];
        Arrays.sort(topK);
        
        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = nums[topK[i]];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(N)

## 关键点总结

1. **排序取前k大**：按值降序排列取前k个下标
2. **恢复原顺序**：对选中下标升序排列后输出值
3. **重复值处理**：通过下标区分不同元素
