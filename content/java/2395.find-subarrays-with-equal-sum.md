## 题目描述

给你整数数组 `nums`，判断是否存在两个不同起始下标的长度为 2 的子数组，使它们的和相等。

## 解题思路

用哈希集合记录已遇到的相邻两数之和，若当前和已在集合中则返回 true，否则加入集合。

## Java 代码实现

```java
class Solution {
    public boolean findSubarrays(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int i = 0; i < nums.length - 1; i++) {
            int sum = nums[i] + nums[i + 1];
            if (!seen.add(sum)) return true; // add 返回 false 说明已存在
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 只需找两个不同起始下标的长度为 2 的子数组和相等。
2. 遍历所有相邻对的和，用 HashSet 检测重复，`add()` 返回 false 即表示重复。
3. 一次遍历 O(n) 完成。
