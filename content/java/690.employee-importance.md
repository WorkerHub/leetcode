## 题目描述

每个员工有 id、重要度和直接下属 id 列表。给定一个员工 id，返回该员工和所有下属的重要度之和。

**示例：**
```
输入：[[1,5,[2,3]], [2,3,[]], [3,3,[]]], id = 1
输出：11（5+3+3）
```

## 解题思路

用 HashMap 映射 id 到员工对象，DFS/BFS 遍历所有下属，累加重要度。

## Java 代码实现

```java
class Solution {
    public int getImportance(List<Employee> employees, int id) {
        Map<Integer, Employee> map = new HashMap<>();
        for (Employee emp : employees) {
            map.put(emp.id, emp);
        }
        return dfs(map, id);
    }

    private int dfs(Map<Integer, Employee> map, int id) {
        Employee emp = map.get(id);
        int total = emp.importance;
        for (int subId : emp.subordinates) {
            total += dfs(map, subId);
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **HashMap 快速查找**：id 到员工对象的映射
2. **DFS 遍历**：递归访问所有下属
3. **累加重要度**：当前员工 + 所有下属
