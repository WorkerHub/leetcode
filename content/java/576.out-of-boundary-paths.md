## 题目描述

给你一个大小为 `m x n` 的网格和一个球。球的起始坐标为 `[startRow, startColumn]`。你可以将球移动到在四个方向上相邻的单元格内（可以穿过网格边界到达网格之外）。你最多可以移动 `maxMove` 次球。

给你五个整数 `m`、`n`、`maxMove`、`startRow` 以及 `startColumn`，找出并返回可以将球移出边界的路径数量。因为答案可能非常大，返回对 `10^9 + 7` **取余** 后的结果。

**示例 1：**
```
输入：m = 2, n = 2, maxMove = 2, startRow = 0, startColumn = 0
输出：6
```

**示例 2：**
```
输入：m = 1, n = 3, maxMove = 3, startRow = 0, startColumn = 1
输出：12
```

**提示：**
- `1 <= m, n <= 50`
- `0 <= maxMove <= 50`
- `0 <= startRow < m`
- `0 <= startColumn < n`

## 解题思路

三维动态规划问题。

状态定义：
- `dp[k][i][j]` 表示移动 k 次后在位置 (i,j) 的路径数

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
class Solution {
    public int findPaths(int m, int n, int maxMove, int startRow, int startColumn) {
        // 三维 DP（滚动数组优化）
        final int MOD = 1_000_000_007;
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

        // dp[i][j] 表示当前步数到达 (i,j) 的路径数
        int[][] dp = new int[m][n];
        dp[startRow][startColumn] = 1;

        int result = 0;

        for (int move = 0; move < maxMove; move++) {
            int[][] temp = new int[m][n];
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (dp[i][j] > 0) {
                        for (int[] dir : directions) {
                            int ni = i + dir[0], nj = j + dir[1];
                            if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                                // 仍在边界内，累加路径数
                                temp[ni][nj] = (temp[ni][nj] + dp[i][j]) % MOD;
                            } else {
                                // 出界，累加到结果
                                result = (result + dp[i][j]) % MOD;
                            }
                        }
                    }
                }
            }
            dp = temp;
        }

        return result;
    }
}
```

### 方法二：记忆化搜索

```java
import java.util.*;

class Solution {
    private int[][][] memo;
    private int m, n;
    private static final int MOD = 1_000_000_007;
    private static final int[][] DIRS = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    public int findPaths(int m, int n, int maxMove, int startRow, int startColumn) {
        this.m = m;
        this.n = n;
        this.memo = new int[m][n][maxMove + 1];
        for (int[][] arr2 : memo) for (int[] arr1 : arr2) Arrays.fill(arr1, -1);
        return dfs(startRow, startColumn, maxMove);
    }

    private int dfs(int i, int j, int moves) {
        // 出界，路径数 +1
        if (i < 0 || i >= m || j < 0 || j >= n) return 1;
        if (moves == 0) return 0;
        if (memo[i][j][moves] != -1) return memo[i][j][moves];

        int count = 0;
        for (int[] dir : DIRS) {
            count = (int) ((count + dfs(i + dir[0], j + dir[1], moves - 1)) % MOD);
        }

        memo[i][j][moves] = count;
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(maxMove × m × n)
- **空间复杂度**：O(m × n)

## 关键点总结

1. **状态定义**：dp[k][i][j] 表示 k 步到达 (i,j) 的路径数
2. **边界处理**：移出边界时累加到结果
3. **取模**：每次计算都要取模
4. **滚动数组**：只需要前一步的状态
