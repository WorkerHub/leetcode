## 题目描述

给你格式为 `"YYYY-MM-DD"` 的日期字符串，将年、月、日分别转为二进制（无前导零），用 `-` 拼接返回。

## 解题思路

按 `-` 分割字符串，用 `Integer.toBinaryString()` 转换各部分，再拼接。

## Java 代码实现

```java
class Solution {
    public String convertDateToBinary(String date) {
        String[] parts = date.split("-");
        // 分别将年、月、日转为二进制字符串（无前导零）
        return Integer.toBinaryString(Integer.parseInt(parts[0])) + "-"
             + Integer.toBinaryString(Integer.parseInt(parts[1])) + "-"
             + Integer.toBinaryString(Integer.parseInt(parts[2]));
    }
}
```

## 复杂度分析

- 时间复杂度：O(log(max_val))
- 空间复杂度：O(log(max_val))

## 关键点总结

1. `Integer.toBinaryString(n)` 直接返回无前导零的二进制字符串
2. 先 `Integer.parseInt()` 去除前导零（如 "02" -> 2）再转换
3. 三部分用 `-` 连接
