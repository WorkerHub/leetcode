## 题目描述

给你一个长度为 n 的整数数组 nums，其中 nums 的所有整数都在范围 [1, n] 内，且每个整数出现一次或两次。请你找出所有出现两次的整数，并以数组形式返回。

你必须设计并实现一个时间复杂度为 O(n) 且仅使用常量额外空间的算法解决此问题。

**示例 1:**

```
输入: nums = [4,3,2,7,8,2,3,1]
输出: [2,3]
```

**示例 2:**

```
输入: nums = [1,1,2]
输出: [1]
```

**示例 3:**

```
输入: nums = [1]
输出: []
```

**提示:**

- n == nums.length
- 1 <= n <= 10^5
- 1 <= nums[i] <= n
- nums 中的每个元素出现一次或两次

## 解题思路

这道题的关键在于：**数组中的数字范围是 [1, n]，而数组的索引范围是 [0, n-1]**，这意味着可以将数字和索引建立一一对应关系。

**核心思想：原地哈希标记法**

1. 遍历数组，对于每个数字 num，将其对应的索引位置 `abs(num) - 1` 的值标记为负数
2. 如果再次遇到某个数字时，发现其对应索引位置已经是负数，说明这个数字出现了第二次
3. 将重复的数字加入结果列表

**为什么可以用负数标记？**
- 所有数字都是正数（1 到 n）
- 将某个位置的数字变为负数，不影响我们获取其绝对值
- 负数作为"已访问"的标记，不需要额外空间

## Java 代码实现

### 方法一：原地哈希标记法（推荐，符合题目要求）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        /**
         * 原地哈希标记法
         * 时间复杂度: O(n)
         * 空间复杂度: O(1) - 不计输出数组
         */
        List<Integer> result = new ArrayList<>();

        for (int num : nums) {
            // 获取绝对值，因为之前可能已经被标记为负数
            int index = Math.abs(num) - 1;

            // 如果该位置已经是负数，说明之前出现过
            if (nums[index] < 0) {
                result.add(Math.abs(num));
            } else {
                // 标记为负数，表示已访问
                nums[index] = -nums[index];
            }
        }

        return result;
    }
}
```

### 方法二：哈希集合法（不符合空间要求，但思路简单）

```java
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        /**
         * 使用集合记录出现过的数字
         * 时间复杂度: O(n)
         * 空间复杂度: O(n)
         */
        Set<Integer> seen = new HashSet<>();
        List<Integer> result = new ArrayList<>();

        for (int num : nums) {
            if (!seen.add(num)) {
                // add 返回 false 说明元素已存在，即重复
                result.add(num);
            }
        }

        return result;
    }
}
```

### 方法三：计数法

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        /**
         * 使用计数数组统计每个数字出现次数
         * 时间复杂度: O(n)
         * 空间复杂度: O(n)
         */
        int n = nums.length;
        int[] count = new int[n + 1];  // 索引 0 不使用

        for (int num : nums) {
            count[num]++;
        }

        List<Integer> result = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (count[i] == 2) {
                result.add(i);
            }
        }

        return result;
    }
}
```

### 方法四：位置交换法（原地哈希的另一种实现）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        /**
         * 将每个数字放到其应该在的位置（num 应该在索引 num-1 处）
         * 时间复杂度: O(n)
         * 空间复杂度: O(1)
         */
        List<Integer> result = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {
            // 将 nums[i] 放到索引 nums[i]-1 的位置
            while (nums[i] != nums[nums[i] - 1]) {
                int correctIndex = nums[i] - 1;
                // 交换 nums[i] 和 nums[correctIndex]
                int temp = nums[i];
                nums[i] = nums[correctIndex];
                nums[correctIndex] = temp;
            }
        }

        // 检查哪些位置的数字不等于索引+1
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != i + 1) {
                result.add(nums[i]);
            }
        }

        return result;
    }
}
```

## 复杂度分析

**方法一（原地哈希标记）：**
- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(1)，只使用常量额外空间（不计输出数组）

**方法二（哈希集合）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)，需要额外的集合存储

**方法三（计数法）：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

**方法四（位置交换）：**
- 时间复杂度：O(n)，虽然有嵌套循环，但每个元素最多交换一次
- 空间复杂度：O(1)

## 关键点总结

1. **数组索引利用**：数字范围 [1, n] 可以映射到索引 [0, n-1]
2. **负数标记技巧**：用负数标记"已访问"，不需要额外空间
3. **绝对值获取**：使用 `Math.abs(num)` 获取原始数字，避免被负号影响
4. **原地修改**：满足 O(1) 空间复杂度要求
5. **恢复原数组**：如果需要，可以再遍历一次将所有负数变回正数

## 易错点

1. **忘记取绝对值**：
   ```java
   // 错误：num 可能已经被标记为负数
   int index = num - 1;

   // 正确：使用绝对值
   int index = Math.abs(num) - 1;
   ```

2. **索引越界**：
   - 数字范围是 [1, n]，索引应该是 `num - 1`
   - 确保 `0 <= index < nums.length`

3. **修改顺序问题**：
   - 先判断是否为负，再标记
   - 不要在判断前就修改数组

4. **结果重复**：
   - 每个重复数字应该只出现一次在结果中
   - 方法一自然避免了这个问题（第二次遇到才加入）
