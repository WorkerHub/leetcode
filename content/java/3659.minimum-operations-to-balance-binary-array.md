## 题目描述

给你一个二进制数组 `nums`，每次操作可以翻转任意两个相邻元素。返回使数组中 0 的数量等于 1 的数量所需的最少操作次数。若无法实现返回 -1。

## 解题思路

每次翻转相邻元素等价于交换两元素（冒泡排序一步）。目标有两种：1 全在偶数位或全在奇数位。对每种目标，计算每个 1 移到对应目标位置的距离之和，取最小值。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        if (n % 2 == 1) return -1;

        List<Integer> ones = new ArrayList<>();
        for (int i = 0; i < n; i++) if (nums[i] == 1) ones.add(i);

        if (ones.size() != n / 2) return -1;

        int half = n / 2;
        // 目标1：1 在奇数位 (1,3,5,...)
        long ops1 = 0;
        for (int i = 0; i < half; i++) ops1 += Math.abs(ones.get(i) - (2 * i + 1));
        // 目标2：1 在偶数位 (0,2,4,...)
        long ops2 = 0;
        for (int i = 0; i < half; i++) ops2 += Math.abs(ones.get(i) - 2 * i);

        return (int) Math.min(ops1, ops2);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 翻转相邻元素等价于冒泡排序的一步，操作数等于总移动距离
2. 两种目标位置（1 在偶数位或奇数位）取最小值
3. 配对时保持顺序（第 i 个 1 对应第 i 个目标位）
