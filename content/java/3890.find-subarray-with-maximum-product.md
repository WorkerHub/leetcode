## 题目描述

给你一个整数数组 `nums`，找到乘积最大的非空连续子数组并返回该子数组，若有多个则返回最早出现的那个。

## 解题思路

动态规划同时维护以当前元素结尾的最大乘积和最小乘积（因负负得正），同时记录对应的起始位置，更新全局最优解。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int[] maxProductSubarray(int[] nums) {
        int n = nums.length;
        int maxProd = nums[0], minProd = nums[0];
        int maxStart = 0, minStart = 0;
        int bestProd = nums[0], bestStart = 0, bestEnd = 0;

        for (int i = 1; i < n; i++) {
            int v = nums[i];
            int tempMax = maxProd, tempMaxStart = maxStart;

            // 三种候选：单独成子数组、接在最大值后、接在最小值后
            if (v >= tempMax * v && v >= minProd * v) {
                maxProd = v;
                maxStart = i;
            } else if (tempMax * v >= minProd * v) {
                maxProd = tempMax * v;
                // maxStart 不变
            } else {
                maxProd = minProd * v;
                maxStart = minStart;
            }

            if (v <= tempMax * v && v <= minProd * v) {
                minProd = v;
                minStart = i;
            } else if (minProd * v <= tempMax * v) {
                minProd = minProd * v;
                // minStart 不变
            } else {
                minProd = tempMax * v;
                minStart = tempMaxStart;
            }

            // 更新全局最优（相等时保留更早的）
            if (maxProd > bestProd) {
                bestProd = maxProd;
                bestStart = maxStart;
                bestEnd = i;
            }
        }

        return Arrays.copyOfRange(nums, bestStart, bestEnd + 1);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单次遍历
- 空间复杂度：O(1)，不计输出

## 关键点总结

1. 最大乘积子数组 DP 同时维护最大值和最小值（负数情况下负负得正）。
2. 记录每个状态的起始位置，以便恢复最优子数组。
3. 多个最优子数组时取最早出现的（下标最小）。
