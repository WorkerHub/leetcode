## 题目描述

给你一个长度为 `n` 的字符串数组 `names`。你将会在文件系统中创建 `n` 个文件夹：第 `i` 分钟创建名为 `names[i]` 的文件夹。

由于两个文件夹不能同名，系统如果与现有文件夹名称同名，则会在文件名后面加上最小的正整数后缀，使其名称变为**唯一**。后缀格式为 `"(k)"`，其中 `k` 是正整数。

返回长度为 `n` 的字符串数组，其中 `ans[i]` 是创建第 `i` 个文件夹时给定的名称。

**示例 1：**

```
输入：names = ["pes","fifa","gta","pes(2019)"]
输出：["pes","fifa","gta","pes(2019)"]
解释：前三个文件夹各自唯一，第四个"pes(2019)"也唯一，直接创建。
```

**示例 2：**

```
输入：names = ["gta","gta(1)","gta","avalon"]
输出：["gta","gta(1)","gta(2)","avalon"]
解释：
- "gta" 唯一，创建。
- "gta(1)" 唯一，创建。
- "gta" 已存在，尝试 "gta(1)" 已存在，尝试 "gta(2)" 不存在，创建。
- "avalon" 唯一，创建。
```

**示例 3：**

```
输入：names = ["onepiece","onepiece(1)","onepiece(2)","onepiece(3)","onepiece"]
输出：["onepiece","onepiece(1)","onepiece(2)","onepiece(3)","onepiece(4)"]
```

**提示：**
- `1 <= names.length <= 5 * 10^4`
- `1 <= names[i].length <= 20`
- `names[i]` 由小写英文字母、数字和/或圆括号组成

---

## 解题思路

**核心思想：** 用哈希表记录每个名称下一个可用的最小 k 值，避免重复查找。

**暴力方法的问题：**
- 对每个名称从 k=1 开始逐一尝试，最坏情况下要试 O(n) 次，整体 O(n^2)，可能超时。

**优化方法：**
- 哈希表 `count[name]` 记录名称 `name` 下次应该尝试的最小 k（初始为 1）。
- 当名称不重复时直接使用，并在哈希表中记录该名称。
- 当名称重复时，从 `count[name]` 开始找到第一个不重复的 `"name(k)"`，更新 `count[name]`。

## Java 代码实现

### 方法一：哈希表记录下一个可用 k（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String[] getFolderNames(String[] names) {
        // count[name]：下次为 name 添加后缀时从哪个 k 开始尝试
        // 如果 name 在 count 中，说明它已经被使用过
        Map<String, Integer> count = new HashMap<>();
        String[] result = new String[names.length];

        for (int i = 0; i < names.length; i++) {
            String name = names[i];
            if (!count.containsKey(name)) {
                // 名称未使用
                result[i] = name;
                count.put(name, 1);  // 记录：下次遇到同名时从 k=1 开始
            } else {
                // 名称已使用，找最小的可用 k
                int k = count.get(name);
                String newName = name + "(" + k + ")";
                while (count.containsKey(newName)) {
                    k++;
                    newName = name + "(" + k + ")";
                }
                result[i] = newName;
                count.put(name, k + 1);      // 更新 name 的下一个 k（跳过已用的）
                count.put(newName, 1);        // 新名称也加入哈希表（可能被后续使用）
            }
        }

        return result;
    }
}
```

### 方法二：双哈希表（count + used 分开记录）

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public String[] getFolderNames(String[] names) {
        Map<String, Integer> count = new HashMap<>();  // name -> 下次尝试的 k
        Set<String> used = new HashSet<>();            // 已使用的文件夹名称
        String[] result = new String[names.length];

        for (int i = 0; i < names.length; i++) {
            String name = names[i];
            if (!used.contains(name)) {
                // 名称未使用，直接用
                result[i] = name;
                used.add(name);
                count.putIfAbsent(name, 1);  // 初始化 k 从 1 开始
            } else {
                // 名称已存在，找最小的 k 使得 name(k) 未使用
                int k = count.getOrDefault(name, 1);
                String newName = name + "(" + k + ")";
                while (used.contains(newName)) {
                    k++;
                    newName = name + "(" + k + ")";
                }
                // 找到可用名称
                result[i] = newName;
                used.add(newName);
                count.put(name, k + 1);          // 更新 name 的下一个 k
                count.putIfAbsent(newName, 1);   // 新名称也可能被后续使用
            }
        }

        return result;
    }
}
```

### 方法三：暴力法（简单但可能超时）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public String[] getFolderNames(String[] names) {
        Set<String> used = new HashSet<>();
        String[] result = new String[names.length];

        for (int i = 0; i < names.length; i++) {
            String name = names[i];
            if (!used.contains(name)) {
                result[i] = name;
                used.add(name);
            } else {
                // 从 k=1 开始逐一尝试（无优化）
                int k = 1;
                String newName = name + "(" + k + ")";
                while (used.contains(newName)) {
                    k++;
                    newName = name + "(" + k + ")";
                }
                result[i] = newName;
                used.add(newName);
            }
        }

        return result;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 哈希表优化 | 均摊 O(n) | O(n) |
| 暴力法 | O(n^2) 最坏 | O(n) |

- 方法一中，`count[name]` 记录了下次应该从哪个 k 开始尝试，避免了从 1 重新扫描。
- 每次查找和更新操作均摊 O(1)。

## 图解示例

以 `names = ["gta","gta(1)","gta","avalon"]` 为例：

```
处理 "gta"：
  "gta" 不在 count 中，直接使用，count={"gta":1}，result=["gta"]

处理 "gta(1)"：
  "gta(1)" 不在 count 中，直接使用，count={"gta":1, "gta(1)":1}，result=["gta","gta(1)"]

处理 "gta"：
  "gta" 在 count 中（k=1），尝试 "gta(1)"
  "gta(1)" 在 count 中（已使用），k=2，尝试 "gta(2)"
  "gta(2)" 不在 count 中，使用，count["gta"]=3，result=["gta","gta(1)","gta(2)"]

处理 "avalon"：
  直接使用，result=["gta","gta(1)","gta(2)","avalon"]
```

## 关键点总结

1. 哈希表的作用是**记录每个名称下一次应该从哪个 k 开始**，避免每次从 k=1 重新扫描。
2. 当新名称 `"name(k)"` 被使用后，也需要将其加入哈希表（因为后续可能再次碰到同名）。
3. `count[name]` 的更新：找到 k 后，将 `count[name]` 更新为 `k+1`（下次从这里开始）。
4. 哈希表本身既作为"已使用名称"的集合，也记录了下一个 k 值。

---

## 易错点

- **新名称也要加入哈希表**：`"name(k)"` 被使用后，如果之后出现 `"name(k)"` 这个名称，也需要给它加后缀，所以 `count.put("name(k)", 1)`。
- **k 的更新**：找到 k 后，`count[name]` 更新为 `k+1`（而不是 k），因为 k 已经被使用了。
- **后缀格式**：后缀是 `"(k)"`（括号包围数字），在 Java 中用 `name + "(" + k + ")"` 拼接。
