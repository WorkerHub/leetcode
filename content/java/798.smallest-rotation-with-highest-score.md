## 题目描述

给定数组 nums，将数组旋转 k 个位置后，如果 nums[i] <= i 则得 1 分。返回使得分最高的最小旋转次数 k。

**示例：**
```
输入：nums = [2,3,1,4,0]
输出：3
```

## 解题思路

差分数组：对每个元素计算哪些 k 值会让它得分，用差分数组标记区间 +1，最后前缀和找最大值。

## Java 代码实现

```java
class Solution {
    public int bestRotation(int[] nums) {
        int n = nums.length;
        int[] diff = new int[n];

        for (int i = 0; i < n; i++) {
            // 旋转 k 后，元素 nums[i] 的新下标为 (i - k + n) % n
            // 得分条件：nums[i] <= (i - k + n) % n
            // 得分的 k 范围：[lo, hi]
            int lo = (i + 1) % n;
            int hi = (i - nums[i] + n) % n;
            diff[lo]++;
            if (hi + 1 < n) {
                diff[hi + 1]--;
            } else if (hi + 1 == n) {
                // 环形处理
                diff[0]--;
            }
            // 如果区间跨越边界
            if (lo > hi) {
                diff[0]++;
                if (hi + 1 < n) diff[hi + 1]--;
                diff[lo]++;
                // 修正：重新计算
            }
        }

        // 使用更清晰的方式重新实现
        diff = new int[n];
        for (int i = 0; i < n; i++) {
            int lo = (i + 1) % n;
            int hi = (i - nums[i] + n) % n;
            if (lo <= hi) {
                diff[lo]++;
                if (hi + 1 < n) diff[hi + 1]--;
            } else {
                // 区间分成 [lo, n-1] 和 [0, hi]
                diff[lo]++;
                diff[0]++;
                if (hi + 1 < n) diff[hi + 1]--;
            }
        }

        int maxScore = 0, bestK = 0, score = 0;
        for (int k = 0; k < n; k++) {
            score += diff[k];
            if (score > maxScore) {
                maxScore = score;
                bestK = k;
            }
        }
        return bestK;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **差分数组**：标记每个元素得分的 k 值区间
2. **环形区间**：区间跨边界时拆成两段
3. **前缀和求最大**：累加差分数组找最大得分
