## 题目描述

给你两个 `HH:MM` 格式的时间段 `event1` 和 `event2`，判断两个事件是否存在时间冲突（有非空交集）。

## 解题思路

两个闭区间有交集等价于：`start1 <= end2 AND start2 <= end1`。`HH:MM` 格式字符串可直接用字典序比较（等价于时间大小比较）。

## Java 代码实现

```java
class Solution {
    public boolean haveConflict(String[] event1, String[] event2) {
        // 两区间有交集：start1 <= end2 且 start2 <= end1
        return event1[0].compareTo(event2[1]) <= 0
            && event2[0].compareTo(event1[1]) <= 0;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 区间重叠判断：`start1 <= end2 AND start2 <= end1`
2. `HH:MM` 格式字符串可直接字典序比较，等价于时间大小
3. 端点相同也算重叠（使用 `<=`）
