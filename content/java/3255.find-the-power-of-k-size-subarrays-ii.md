## 题目描述

与 3254 完全相同的问题，数据范围更大：`1 <= n <= 10^5`，`1 <= nums[i] <= 10^6`。

## 解题思路

与 3254 相同的 O(n) 滑动窗口方法，维护以当前位置结尾的最长连续递增长度，完全适用于更大数据范围。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] resultsArray(int[] nums, int k) {
        int n = nums.length;
        int[] ans = new int[n - k + 1];
        int cnt = 1; // 以当前位置结尾的最长连续递增长度

        for (int i = 0; i < n; i++) {
            // 更新连续递增长度
            if (i > 0 && nums[i] == nums[i - 1] + 1) {
                cnt++;
            } else {
                cnt = 1;
            }
            // 填充结果
            if (i >= k - 1) {
                ans[i - k + 1] = cnt >= k ? nums[i] : -1;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)（不含输出数组）

## 关键点总结

1. 与 3254 完全相同的算法，O(n) 滑动窗口
2. k=1 时所有子数组的幂都是其自身
3. 数据范围增大但算法不变
