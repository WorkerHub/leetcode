## 题目描述

给定整数数组 `arr` 和整数 `k`，将数组重复 k 次后，求最大子数组和（对 10^9+7 取模）。

**示例：**
```
输入：arr = [1,2], k = 3
输出：9（整个重复数组之和）
```

## 解题思路

分情况讨论：k=1 直接 Kadane；k≥2 计算两个数组拼接的最大子数组和，若总和>0 则中间 k-2 个完整数组都应包含。

## Java 代码实现

```java
class Solution {
    public int kConcatenationMaxSum(int[] arr, int k) {
        long MOD = 1_000_000_007;
        long totalSum = 0;
        for (int x : arr) totalSum += x;
        
        // 计算单个或双份数组的最大子数组和（允许空子数组，最小为0）
        long maxKadane = kadane(arr, Math.min(k, 2));
        
        if (k <= 2) {
            return (int) (maxKadane % MOD);
        }
        
        // k >= 3 且总和 > 0 时，中间 k-2 个完整数组应包含
        if (totalSum > 0) {
            return (int) ((maxKadane + (k - 2) * totalSum) % MOD);
        } else {
            return (int) (maxKadane % MOD);
        }
    }
    
    private long kadane(int[] arr, int times) {
        long maxSum = 0, cur = 0;
        for (int t = 0; t < times; t++) {
            for (int x : arr) {
                cur = Math.max(0, cur + x);
                maxSum = Math.max(maxSum, cur);
            }
        }
        return maxSum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，最多遍历 2n 个元素
- **空间复杂度**：O(1)

## 关键点总结

1. **分情况**：k=1 用单数组 Kadane，k≥2 用双数组 Kadane
2. **总和正负**：totalSum>0 时中间部分全部包含
3. **取模**：用 long 避免溢出，最后取模
4. **空子数组**：Kadane 最小值为 0（题目允许空子数组）
