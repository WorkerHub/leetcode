## 题目描述

给你严格递增整数数组 `nums` 和正整数 `diff`，返回满足 `nums[j]-nums[i]==diff` 且 `nums[k]-nums[j]==diff`（i<j<k）的等差三元组数目。

## 解题思路

将所有元素放入哈希集合，对每个元素 `x` 检查 `x+diff` 和 `x+2*diff` 是否也在集合中，满足则计数加一。

## Java 代码实现

```java
class Solution {
    public int arithmeticTriplets(int[] nums, int diff) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);
        int count = 0;
        for (int x : nums) {
            // 检查 x+diff 和 x+2*diff 是否都存在
            if (set.contains(x + diff) && set.contains(x + 2 * diff)) {
                count++;
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 等差三元组等价于找 x、x+diff、x+2*diff 都在数组中的元素 x。
2. HashSet O(1) 查找，一次遍历即可。
3. 数组严格递增保证不会重复计数。
