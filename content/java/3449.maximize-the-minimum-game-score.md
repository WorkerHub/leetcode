## 题目描述

给你整数数组 `points` 和整数 `m`。每次操作选下标 i，得 `points[i]` 分并将其减 1（不低于 0）。共 m 次操作，最大化所有操作中最低得分。

## 解题思路

二分答案：二分最小操作得分 T，对每个 `points[i]`，能提供 `max(0, points[i] - T + 1)` 次得分 >= T 的操作。检查总操作次数是否 >= m 即可。

## Java 代码实现

```java
class Solution {
    public long maxScore(int[] points, int m) {
        long lo = 0, hi = 0;
        for (int p : points) hi = Math.max(hi, p);

        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (canAchieve(points, m, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }

    private boolean canAchieve(int[] points, long m, long T) {
        if (T == 0) return true;
        long totalOps = 0;
        for (int p : points) {
            if (p >= T) {
                // 从 p 减到 T，共 p - T + 1 次操作得分 >= T
                totalOps += p - T + 1;
                if (totalOps >= m) return true;
            }
        }
        return totalOps >= m;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log(max_p))，二分 * 线性检查
- 空间复杂度：O(1)

## 关键点总结

1. 二分答案：最小操作得分 T 具有单调性（T 越大越难满足）
2. `points[i]` 能提供 `max(0, points[i] - T + 1)` 次 >= T 的操作
3. 使用 `long` 避免累加时溢出
