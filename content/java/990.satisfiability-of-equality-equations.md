## 题目描述

给定字符串方程数组 equations（如 "a==b" 或 "a!=b"），判断是否存在满足所有方程的变量赋值方案。

**示例：**
```
输入：equations = ["a==b","b!=a"]
输出：false
```

## 解题思路

并查集：先处理所有 == 将相等变量合并，再检查所有 != 是否有矛盾（两个变量在同一集合却要求不等）。

## Java 代码实现

```java
class Solution {
    private int[] parent = new int[26];

    public boolean equationsPossible(String[] equations) {
        for (int i = 0; i < 26; i++) parent[i] = i;

        // 第一遍：合并相等变量
        for (String eq : equations) {
            if (eq.charAt(1) == '=') {
                union(eq.charAt(0) - 'a', eq.charAt(3) - 'a');
            }
        }

        // 第二遍：检查不等关系是否矛盾
        for (String eq : equations) {
            if (eq.charAt(1) == '!') {
                if (find(eq.charAt(0) - 'a') == find(eq.charAt(3) - 'a')) {
                    return false;
                }
            }
        }

        return true;
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int x, int y) {
        parent[find(x)] = find(y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * α(26))，近似 O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两遍遍历**：先合并相等，再检查不等
2. **并查集**：处理等价关系的传递性
3. **路径压缩**：优化查找效率
