## 题目描述

给定正整数 `n`，找出最大的正整数 `x`（`x <= n`），使得 `x` 的十进制表示中没有重复的数字。

## 解题思路

贪心逐位构造。从高位到低位，尽量保持与 `n` 相同的前缀。遇到重复数字时，在当前位减 1（选第一个未使用的数字），后续位贪心填从 9 到 0 中未使用的数字。

## Java 代码实现

```java
class Solution {
    public int maxNonRepeatingDigit(int n) {
        char[] digits = String.valueOf(n).toCharArray();
        int len = digits.length;

        for (int i = 0; i < len; i++) {
            boolean[] used = new boolean[10];
            // 检查前 i 位是否有重复
            boolean valid = true;
            for (int j = 0; j < i; j++) {
                int d = digits[j] - '0';
                if (used[d]) { valid = false; break; }
                used[d] = true;
            }
            if (!valid) break;

            int cur = digits[i] - '0';
            if (used[cur]) {
                // 当前位出现重复，在该位减 1 找第一个未用数字，后续贪心填最大
                for (int nd = cur - 1; nd >= (i == 0 ? 1 : 0); nd--) {
                    if (!used[nd]) {
                        StringBuilder sb = new StringBuilder();
                        for (int j = 0; j < i; j++) sb.append(digits[j]);
                        sb.append((char)('0' + nd));
                        used[nd] = true;
                        for (int d = 9; d >= 0 && sb.length() < len; d--) {
                            if (!used[d]) { sb.append((char)('0' + d)); used[d] = true; }
                        }
                        return Integer.parseInt(sb.toString());
                    }
                }
                // 无法在当前位减，回溯到上一位
                break;
            }
            used[cur] = true;
        }

        // 最后整体贪心：若 n 本身无重复返回 n，否则逐步构造
        String s = String.valueOf(n);
        boolean[] used2 = new boolean[10];
        StringBuilder res = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            int d = s.charAt(i) - '0';
            if (used2[d]) {
                // 找该位减 1 的最大合法数字
                for (int nd = d - 1; nd >= (i == 0 ? 1 : 0); nd--) {
                    if (!used2[nd]) {
                        res.append((char)('0' + nd));
                        used2[nd] = true;
                        for (int dd = 9; dd >= 0 && res.length() < s.length(); dd--) {
                            if (!used2[dd]) { res.append((char)('0' + dd)); used2[dd] = true; }
                        }
                        return Integer.parseInt(res.toString());
                    }
                }
                // 需要截断，移除最后一位并减
                res.deleteCharAt(res.length() - 1);
                // 简化：直接返回 n-1 递归（实际上逻辑较复杂，用下面简化版）
                break;
            }
            used2[d] = true;
            res.append(s.charAt(i));
        }
        // 若 n 本身无重复
        if (res.length() == s.length()) return n;

        // 回退一位减1并填充
        while (res.length() > 0) {
            int last = res.charAt(res.length() - 1) - '0';
            res.deleteCharAt(res.length() - 1);
            boolean[] usedPfx = new boolean[10];
            for (char c : res.toString().toCharArray()) usedPfx[c - '0'] = true;
            for (int nd = last - 1; nd >= (res.length() == 0 ? 1 : 0); nd--) {
                if (!usedPfx[nd]) {
                    res.append((char)('0' + nd));
                    usedPfx[nd] = true;
                    for (int dd = 9; dd >= 0 && res.length() < s.length(); dd--) {
                        if (!usedPfx[dd]) { res.append((char)('0' + dd)); usedPfx[dd] = true; }
                    }
                    return Integer.parseInt(res.toString());
                }
            }
        }
        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(L^2)，L 为位数（最多 10）
- 空间复杂度：O(L)

## 关键点总结

1. 最多 10 位，无重复数字的最大数为 9876543210
2. 贪心：尽量保留前缀，遇到重复则在当前位减 1
3. 后续位贪心填 9,8,7... 中未使用的数字
