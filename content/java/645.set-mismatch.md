## 题目描述

数组 nums 包含从 1 到 n 的整数，其中一个数字重复，一个数字缺失。返回 [重复数, 缺失数]。

**示例：**
```
输入：nums = [1,2,2,4]
输出：[2,3]
```

## 解题思路

数学方法：实际和 - 去重和 = 重复数，期望和 - 去重和 = 缺失数。

## Java 代码实现

```java
class Solution {
    public int[] findErrorNums(int[] nums) {
        int n = nums.length;
        Set<Integer> set = new HashSet<>();
        int actualSum = 0, uniqueSum = 0;

        for (int num : nums) {
            actualSum += num;
            set.add(num);
        }
        for (int val : set) {
            uniqueSum += val;
        }

        int expectedSum = n * (n + 1) / 2;
        int duplicate = actualSum - uniqueSum;
        int missing = expectedSum - uniqueSum;

        return new int[]{duplicate, missing};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **数学公式**：利用和的差值
2. **HashSet 去重**：得到不重复的元素和
3. **期望和**：n*(n+1)/2
