## 题目描述

给你两棵无向树（分别有 n 和 m 个节点），选各一个节点用一条边连接，返回合并后树的最小可能直径。

## 解题思路

合并后直径取三者最大值：树 1 的直径 d1、树 2 的直径 d2、以及经过新边的最长路径 `ceil(d1/2) + ceil(d2/2) + 1`（选各自中心节点连接使该路径最短）。树的直径用两次 BFS 求得。

## Java 代码实现

```java
class Solution {
    public int minimumDiameterAfterMerge(int[][] edges1, int[][] edges2) {
        int d1 = getDiameter(edges1.length + 1, edges1);
        int d2 = getDiameter(edges2.length + 1, edges2);
        int merged = (d1 + 1) / 2 + (d2 + 1) / 2 + 1;
        return Math.max(Math.max(d1, d2), merged);
    }

    private int getDiameter(int n, int[][] edges) {
        if (n == 1) return 0;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        // 第一次 BFS：从节点 0 找最远节点 u
        int[] res = bfsFarthest(graph, 0, n);
        // 第二次 BFS：从 u 找最远节点，距离即直径
        return bfsFarthest(graph, res[0], n)[1];
    }

    // 返回 [最远节点, 最远距离]
    private int[] bfsFarthest(List<List<Integer>> graph, int start, int n) {
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        dist[start] = 0;
        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        int farthest = start;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : graph.get(u)) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    q.offer(v);
                    if (dist[v] > dist[farthest]) farthest = v;
                }
            }
        }
        return new int[]{farthest, dist[farthest]};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 合并后直径 = max(d1, d2, ⌈d1/2⌉ + ⌈d2/2⌉ + 1)
2. 选各自树的中心节点连接，最小化跨树路径
3. 树的直径用两次 BFS 求得（第一次找端点，第二次量距离）
