## 题目描述

给你整数数组 nums 和整数 target，返回和恰好等于 target 的最长子序列的长度，不存在则返回 -1。

## 解题思路

0-1 背包变种：`dp[j]` 表示和恰好为 j 时能选取的最多元素个数，不可达则为 `Integer.MIN_VALUE`。对每个元素从右向左更新，最终返回 `dp[target]`。

## Java 代码实现

```java
class Solution {
    public int lengthOfLongestSubsequence(List<Integer> nums, int target) {
        int[] dp = new int[target + 1];
        Arrays.fill(dp, Integer.MIN_VALUE);
        dp[0] = 0;

        for (int num : nums) {
            // 0-1 背包：从右向左，防止重复选取
            for (int j = target; j >= num; j--) {
                if (dp[j - num] != Integer.MIN_VALUE) {
                    dp[j] = Math.max(dp[j], dp[j - num] + 1);
                }
            }
        }
        return dp[target] == Integer.MIN_VALUE ? -1 : dp[target];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × target)
- **空间复杂度**：O(target)

## 关键点总结

1. dp[0]=0，其余初始化为 MIN_VALUE 区分"和为 j 且可达"与"不可达"
2. 0-1 背包须从右向左遍历，防止同一元素被重复使用
3. 只有 dp[j-num] 可达时才更新 dp[j]
