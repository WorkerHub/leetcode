## 题目描述

给你两个字符串 `s` 和 `t`，可以从 `s` 中删除最多一个字符，使 `s` 和 `t` 的最长公共前缀尽可能长。返回最长公共前缀的长度。

## 解题思路

双指针：先找不删除时的公共前缀长度 base（第一个不匹配位置）。然后在 base 处跳过 s 中的一个字符，继续比较 s[base+1..] 和 t[base..]，累加额外匹配长度。

## Java 代码实现

```java
class Solution {
    public int longestCommonPrefix(String s, String t) {
        int n = s.length(), m = t.length();

        // 找第一个不匹配位置
        int base = 0;
        while (base < n && base < m && s.charAt(base) == t.charAt(base)) {
            base++;
        }

        // 已到达某个字符串末尾，无需删除
        if (base == n || base == m) return base;

        // 尝试删除 s[base]，继续比较 s[base+1..] 和 t[base..]
        int si = base + 1, ti = base;
        while (si < n && ti < m && s.charAt(si) == t.charAt(ti)) {
            si++;
            ti++;
        }
        int extra = ti - base;

        return base + extra;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)

## 关键点总结

1. 先找不删除时的公共前缀长度 base
2. 在第一个不匹配位置删除 s 中该字符，继续比较
3. 删除后续比较起点为 (base+1, base)
