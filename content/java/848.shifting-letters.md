## 题目描述

给定字符串 s 和整数数组 shifts。对于 shifts[i]=x，将 s 的前 i+1 个字母各移位 x 次。返回最终字符串。

**示例：**
```
输入：s = "abc", shifts = [3,5,9]
输出："rpl"
```

## 解题思路

后缀和：每个位置的实际移位次数是 shifts[i] + shifts[i+1] + ... + shifts[n-1]。从后往前累加即可。

## Java 代码实现

```java
class Solution {
    public String shiftingLetters(String s, int[] shifts) {
        int n = s.length();
        char[] result = s.toCharArray();

        // 从后往前计算后缀和
        long totalShift = 0;
        for (int i = n - 1; i >= 0; i--) {
            totalShift += shifts[i];
            int shifted = (int) ((result[i] - 'a' + totalShift) % 26);
            result[i] = (char) ('a' + shifted);
        }

        return new String(result);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **后缀和**：从后往前累加得到每个位置的实际移位
2. **取模运算**：%26 处理环形字母表
3. **long 防溢出**：shifts 累加可能超过 int 范围
