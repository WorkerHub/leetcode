## 题目描述

给你整数数组 `nums`（所有元素 >= 2），将其分割成连续子数组，使每个子数组的 GCD 严格大于 1，返回最少子数组数目。

## 解题思路

贪心：维护当前子数组的 GCD，若加入新元素后 GCD 变为 1，则必须在此处分割，新子数组从当前元素开始。由于所有元素 >= 2，单个元素单独构成子数组也满足条件。

## Java 代码实现

```java
class Solution {
    public int minimumSplits(int[] nums) {
        int ans = 1;
        int curGcd = nums[0]; // 当前子数组的 GCD

        for (int i = 1; i < nums.length; i++) {
            int newGcd = gcd(curGcd, nums[i]);
            if (newGcd == 1) {
                // GCD 变为 1，必须在此处分割
                ans++;
                curGcd = nums[i]; // 新子数组从当前元素开始
            } else {
                curGcd = newGcd; // 继续延伸当前子数组
            }
        }
        return ans;
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log(maxVal))
- **空间复杂度**：O(1)

## 关键点总结

1. 贪心：当前 GCD 为 1 时必须分割，否则继续延伸
2. 所有元素 >= 2，单独一个元素 GCD = 元素本身 >= 2，保证可以分割
3. GCD 随子数组增长单调不增
