## 题目描述

给你一个矩形蛋糕，大小为 `h x w`，以及两个整数数组 `horizontalCuts` 和 `verticalCuts`，其中：
- `horizontalCuts[i]` 是从矩形蛋糕顶部到第 `i` 条水平切割线的距离
- `verticalCuts[j]` 是从矩形蛋糕的左侧到第 `j` 条竖直切割线的距离

请你返回按数组 `horizontalCuts` 和 `verticalCuts` 切割后得到的**最大蛋糕块**的面积，由于答案可能是一个很大的数字，返回它对 `10^9 + 7` 取余的结果。

**示例 1：**
```
输入：h = 5, w = 4, horizontalCuts = [1,2,4], verticalCuts = [1,3]
输出：4
解释：最大间距：水平 max(1,1,2,1)=2，竖直 max(1,2,1)=2，面积=4
```

**示例 2：**
```
输入：h = 5, w = 4, horizontalCuts = [3,1], verticalCuts = [1]
输出：6
解释：最大间距：水平 max(1,2,2)=2，竖直 max(1,3)=3，面积=6
```

**示例 3：**
```
输入：h = 5, w = 4, horizontalCuts = [3], verticalCuts = [3]
输出：9
```

**提示：**
- `2 <= h, w <= 10^9`
- `1 <= horizontalCuts.length <= min(h-1, 10^5)`
- `1 <= verticalCuts.length <= min(w-1, 10^5)`
- `1 <= horizontalCuts[i] < h`
- `1 <= verticalCuts[i] < w`
- 题目中数据保证 `horizontalCuts` 中的所有元素各不相同，`verticalCuts` 中的所有元素各不相同

## 解题思路

**贪心思路：**

最大蛋糕块面积 = 水平方向最大间距 × 竖直方向最大间距

1. 对水平切割线排序，找相邻切割线（含边界 0 和 h）之间的最大间距
2. 对竖直切割线排序，找相邻切割线（含边界 0 和 w）之间的最大间距
3. 两个最大间距相乘，对 `10^9 + 7` 取模

**注意**：h、w 可达 10^9，面积可达 10^18，需要用 `long` 防止整数溢出。

## Java 代码实现

### 方法一：排序 + 最大间距（推荐）

```java
import java.util.Arrays;

class Solution {
    public int maxArea(int h, int w, int[] horizontalCuts, int[] verticalCuts) {
        final int MOD = 1_000_000_007;

        // 计算切割线之间（含两端边界）的最大间距
        long maxH = maxGap(horizontalCuts, h);
        long maxV = maxGap(verticalCuts, w);

        return (int) ((maxH * maxV) % MOD);
    }

    private long maxGap(int[] cuts, int total) {
        Arrays.sort(cuts);
        long maxG = 0;
        int prev = 0;
        for (int c : cuts) {
            maxG = Math.max(maxG, c - prev);
            prev = c;
        }
        // 最后一个切割线到边界的距离
        maxG = Math.max(maxG, total - prev);
        return maxG;
    }
}
```

### 方法二：加入边界后排序（更简洁）

```java
import java.util.Arrays;

class Solution {
    public int maxArea(int h, int w, int[] horizontalCuts, int[] verticalCuts) {
        final int MOD = 1_000_000_007;

        long maxH = maxGap(horizontalCuts, h);
        long maxV = maxGap(verticalCuts, w);

        return (int) ((maxH * maxV) % MOD);
    }

    private long maxGap(int[] cuts, int total) {
        // 加入边界 0 和总长度，排序后计算相邻差值的最大值
        int n = cuts.length;
        int[] arr = new int[n + 2];
        arr[0] = 0;
        arr[n + 1] = total;
        for (int i = 0; i < n; i++) arr[i + 1] = cuts[i];
        Arrays.sort(arr);

        long maxG = 0;
        for (int i = 1; i < arr.length; i++) {
            maxG = Math.max(maxG, arr[i] - arr[i - 1]);
        }
        return maxG;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m + n log n)，m 和 n 分别是水平和竖直切割线的数量
- 空间复杂度：O(m + n)，排序后的数组

## 关键点总结

1. 最大面积 = 水平最大间距 × 竖直最大间距（贪心，两个维度独立）
2. 排序后，间距就是相邻元素的差，需要加入边界 0 和总长度
3. 取模操作在**最后相乘后**进行，乘积使用 `long` 防止溢出

## 易错点

- 不要忘记加入蛋糕边界（0 和 h/w），否则第一段和最后一段间距会漏算
- Java 中 h、w 最大 10^9，两者相乘可达 10^18，必须用 `long` 而非 `int`
- 取模要在乘积之后进行：`(maxH * maxV) % MOD`
