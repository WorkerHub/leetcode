## 题目描述

给你正整数数组 `nums`，选取 k（k>=3）个元素组成最大周长的合法多边形（最大边 < 其余边之和），返回最大周长或 -1。

## 解题思路

排序后用前缀和，从最大边开始枚举：若 `nums[i] < prefix[i]`（其余边之和），则可构成合法多边形，周长为 `prefix[i+1]`，取第一个满足条件的即为最大周长。

## Java 代码实现

```java
class Solution {
    public long largestPerimeter(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        for (int i = n - 1; i >= 2; i--) {
            // 最大边 nums[i]，其余边之和 prefix[i]
            if (nums[i] < prefix[i]) return prefix[i + 1];
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 包含更多元素的多边形周长更大且更容易满足合法条件
2. 从最大边往小枚举，第一个满足条件的就是答案
3. 周长为所有选取元素之和，用 long 防溢出
