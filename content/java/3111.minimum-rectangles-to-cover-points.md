## 题目描述

给你二维点数组 `points` 和整数 `w`，用宽度为 w、高度无限的矩形覆盖所有点。返回所需最少矩形数量。

## 解题思路

只关注 x 坐标，贪心排序后从最小未覆盖 x 出发放矩形，该矩形覆盖到 x+w，跳过范围内所有点，直到所有点被覆盖。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minRectanglesToCoverPoints(int[][] points, int w) {
        int[] xs = new int[points.length];
        for (int i = 0; i < points.length; i++) xs[i] = points[i][0];
        Arrays.sort(xs);
        int ans = 0;
        long right = -1;
        for (int x : xs) {
            if (x > right) {
                ans++;
                right = (long) x + w; // 新矩形覆盖到 x+w
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 矩形高度无限，只需关心 x 坐标覆盖
2. 贪心：每次从最左未覆盖点出发，覆盖范围 [x, x+w]
