## 题目描述

给你 n×n 整数矩阵 `grid`，返回大小为 (n-2)×(n-2) 的矩阵 `maxLocal`，其中 `maxLocal[i][j]` 等于 `grid` 中以 `(i+1,j+1)` 为中心的 3×3 区域的最大值。

## 解题思路

枚举每个 (i,j)（0 <= i,j < n-2），遍历以 (i,j) 为左上角的 3×3 区域（9 个格子），取最大值填入结果矩阵。

## Java 代码实现

```java
class Solution {
    public int[][] largestLocal(int[][] grid) {
        int n = grid.length;
        int[][] result = new int[n - 2][n - 2];
        for (int i = 0; i < n - 2; i++) {
            for (int j = 0; j < n - 2; j++) {
                int max = 0;
                // 枚举 3x3 区域
                for (int r = i; r < i + 3; r++)
                    for (int c = j; c < j + 3; c++)
                        max = Math.max(max, grid[r][c]);
                result[i][j] = max;
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)（每格枚举 9 次）
- **空间复杂度**：O(1)（不含输出）

## 关键点总结

1. 输出矩阵大小为 (n-2)×(n-2)，下标 (i,j) 对应 grid 中以 (i,j) 为左上角的 3×3 区域。
2. 双重循环枚举 9 个格子取最大值，n<=100 时完全可接受。
3. 索引范围：i 和 j 均从 0 到 n-3（即 `range(n-2)`）。
