## 题目描述

numPeople 人站成一圈，每人恰好和一人握手（共 numPeople/2 次握手），求没有交叉的握手方案数（mod 10^9+7）。

**示例：**
```
numPeople = 4 → 2
numPeople = 6 → 5
numPeople = 8 → 14
```

## 解题思路

这是第 n 个卡特兰数 C(numPeople/2)。固定一人与第 k 个人握手，将圈分为两半，方案数为两半的乘积，对所有 k 求和即为卡特兰递推。

## Java 代码实现

```java
class Solution {
    public int numberOfWays(int numPeople) {
        long MOD = 1_000_000_007;
        int n = numPeople / 2;
        // dp[i] = 第 i 个卡特兰数
        long[] dp = new long[n + 1];
        dp[0] = 1;
        
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                dp[i] = (dp[i] + dp[j] * dp[i - 1 - j]) % MOD;
            }
        }
        return (int) dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，n = numPeople/2
- **空间复杂度**：O(n)

## 关键点总结

1. **卡特兰数**：C(n) = Σ C(i) × C(n-1-i)，i 从 0 到 n-1
2. **固定一人分割**：握手将圈分为两个独立子问题
3. **k 必须为奇数**：保证两侧人数都是偶数
4. **经典应用**：括号匹配、BST 计数、非交叉划分
