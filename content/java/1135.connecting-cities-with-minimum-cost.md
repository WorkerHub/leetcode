## 题目描述

n 座城市编号 1~n，connections[i] = [x, y, cost] 表示连接城市 x 和 y 的成本。返回连接所有城市的最低成本，无法连接则返回 -1。

**示例：**
```
输入：n = 3, connections = [[1,2,5],[1,3,6],[2,3,1]]
输出：6
```

## 解题思路

Kruskal 最小生成树：按边权排序，用并查集贪心选边，选够 n-1 条边即完成。

## Java 代码实现

```java
class Solution {
    private int[] parent;
    private int[] rank;

    public int minimumCost(int n, int[][] connections) {
        // 初始化并查集
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int i = 1; i <= n; i++) parent[i] = i;

        // 按边权排序
        Arrays.sort(connections, (a, b) -> a[2] - b[2]);

        int totalCost = 0;
        int edges = 0;

        for (int[] conn : connections) {
            if (union(conn[0], conn[1])) {
                totalCost += conn[2];
                edges++;
                // 生成树有 n-1 条边
                if (edges == n - 1) return totalCost;
            }
        }

        return -1;
    }

    private int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }

    private boolean union(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;
        // 按秩合并
        if (rank[rx] < rank[ry]) {
            parent[rx] = ry;
        } else if (rank[rx] > rank[ry]) {
            parent[ry] = rx;
        } else {
            parent[ry] = rx;
            rank[rx]++;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(E log E)，排序为主
- **空间复杂度**：O(n)，并查集

## 关键点总结

1. **Kruskal 算法**：排序边 + 并查集选边
2. **路径压缩 + 按秩合并**：并查集近 O(1) 操作
3. **n-1 条边提前退出**：生成树恰好 n-1 条边
4. **城市编号从 1 开始**：并查集大小 n+1
5. **返回 -1**：边不够连通所有城市时
