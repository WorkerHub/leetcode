## 题目描述

给定一个已排序的正整数数组 `nums`，和一个正整数 `n`。从 `[1, n]` 区间内选取任意个数字补充到 `nums` 中，使得 `[1, n]` 区间内的任何数字都可以用 `nums` 中某几个数字的和来表示。

请返回**满足上述要求的最少的补充数字个数**。

**示例 1:**

```
输入: nums = [1,3], n = 6
输出: 1
解释:
根据 nums 里现有的组合 [1], [3], [1,3]，可以得出 1, 3, 4。
现在如果我们将 2 添加到 nums 中， 组合变为: [1], [2], [3], [1,3], [2,3], [1,2], [1,2,3]。
其和可以表示数字 1, 2, 3, 4, 5, 6，能够覆盖 [1, 6] 区间里所有的数。
所以我们最少需要添加一个数字。
```

**示例 2:**

```
输入: nums = [1,5,10], n = 20
输出: 2
解释: 我们需要添加 [2, 4]。
```

**示例 3:**

```
输入: nums = [1,2,2], n = 5
输出: 0
```

**提示:**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`
- `nums` 按**升序**排列
- `1 <= n <= 2^31 - 1`

## 解题思路

这道题是一道经典的**贪心算法**题，核心思想是维护一个**已覆盖区间** `[1, miss)`。

### 核心思想

1. **已覆盖区间**：假设当前可以覆盖 `[1, miss)`，即 `1` 到 `miss - 1` 的所有数都能用现有数字的和表示

2. **贪心策略**：
   - 如果 `nums[i] <= miss`，则可以将覆盖区间扩展到 `[1, miss + nums[i])`
   - 如果 `nums[i] > miss`，则需要补充数字 `miss`，覆盖区间扩展到 `[1, 2 * miss)`

3. **为什么补充 `miss`？**
   - 当前可以覆盖 `[1, miss)`
   - 补充 `miss` 后，可以覆盖 `[1, miss)` 和 `[miss, 2*miss)`，合并为 `[1, 2*miss)`
   - 这样覆盖范围最大，补充的数字最少（贪心）

### 算法流程

1. 初始化 `miss = 1`（当前缺失的最小数字），`i = 0`（nums 的索引），`patches = 0`（补充的数字个数）
2. 当 `miss <= n` 时循环：
   - 如果 `i < nums.length` 且 `nums[i] <= miss`：使用 `nums[i]`，`miss += nums[i]`，`i += 1`
   - 否则：补充 `miss`，`miss += miss`（即 `miss *= 2`），`patches += 1`
3. 返回 `patches`

## Java 代码实现

### 方法一：贪心算法（推荐）⭐

```java
class Solution {
    public int minPatches(int[] nums, int n) {
        // 贪心算法：维护已覆盖区间 [1, miss)
        long miss = 1;  // 当前缺失的最小数字（使用 long 防止溢出）
        int i = 0;      // nums 的索引
        int patches = 0; // 补充的数字个数

        while (miss <= n) {
            if (i < nums.length && nums[i] <= miss) {
                // 使用 nums[i]，扩展覆盖区间
                miss += nums[i];
                i++;
            } else {
                // 补充 miss，覆盖区间扩展到 [1, 2*miss)
                miss += miss;  // 等价于 miss *= 2
                patches++;
            }
        }

        return patches;
    }
}
```

### 方法二：详细注释版（便于理解）

```java
class Solution {
    public int minPatches(int[] nums, int n) {
        // 贪心算法：维护已覆盖区间
        // miss 表示当前最小的缺失数字
        // 已覆盖区间为 [1, miss)，即 1 到 miss-1 都能表示
        long miss = 1;
        int i = 0;      // nums 的当前索引
        int patches = 0; // 补充的数字个数

        // 当 miss > n 时，说明 [1, n] 已全部覆盖
        while (miss <= n) {
            // 情况 1：当前 nums[i] 可以使用
            // 条件：i 在范围内，且 nums[i] <= miss
            // 为什么 nums[i] <= miss 可以用？
            // 因为 [1, miss) 已覆盖，加上 nums[i] 后，可以表示：
            // - 原来的 [1, miss)
            // - nums[i] 加上 [1, miss) 中的任意数，得到 [nums[i], miss + nums[i])
            // 合并后覆盖 [1, miss + nums[i])
            if (i < nums.length && nums[i] <= miss) {
                miss += nums[i];
                i++;
            }

            // 情况 2：nums[i] 太大或不存在，需要补充数字
            // 补充什么数字最优？补充 miss
            // 因为补充 miss 后，覆盖区间从 [1, miss) 扩展到 [1, 2*miss)
            // 这是最大的扩展，符合贪心策略
            else {
                miss += miss;  // 覆盖区间翻倍
                patches++;
            }
        }

        return patches;
    }
}
```

### 方法三：简洁写法

```java
class Solution {
    public int minPatches(int[] nums, int n) {
        // 简洁写法：使用 long 防止 miss 溢出
        long miss = 1;
        int i = 0, patches = 0;

        while (miss <= n) {
            if (i < nums.length && nums[i] <= miss) {
                miss += nums[i++];
            } else {
                miss <<= 1;  // miss *= 2（位运算优化）
                patches++;
            }
        }

        return patches;
    }
}
```

## 复杂度分析

**所有方法**

- **时间复杂度**：O(m + log n)
  - m：nums 的长度，最多遍历一次
  - log n：补充的数字个数最多为 log n（每次覆盖区间翻倍）
  
- **空间复杂度**：O(1)
  - 只使用常数个变量

## 关键点总结

1. **已覆盖区间** `[1, miss)`：关键状态变量
2. **贪心策略**：
   - 能用 nums[i] 就用（扩展到 `miss + nums[i]`）
   - 不能用就补充 miss（扩展到 `2 * miss`）
3. **为什么补充 miss 最优？**
   - 已覆盖 `[1, miss)`，补充 miss 后可以表示 `[miss, 2*miss)`
   - 合并后覆盖 `[1, 2*miss)`，扩展最大
4. **循环条件**：`miss <= n`，当 `miss > n` 时说明 `[1, n]` 已全部覆盖
5. **nums 已排序**：可以按顺序使用，不需要回溯

## 易错点

1. **覆盖区间理解错误**：
   - `miss` 表示当前最小缺失数字，已覆盖区间是 `[1, miss)`，**不包括 miss**
   
2. **使用条件错误**：
   - 正确：`nums[i] <= miss`
   - 错误：`nums[i] < miss`（等于时也可以用）

3. **补充数字错误**：
   - 正确：补充 `miss`
   - 错误：补充其他数字（无法保证最优）

4. **循环条件错误**：
   - 正确：`while (miss <= n)`
   - 错误：`while (miss < n)`（miss 可能等于 n）

5. **整数溢出**：
   - `miss += miss` 可能导致 int 溢出（当 miss > 10^9 时）
   - Java 中必须使用 `long` 类型存储 miss

## 图解示例

示例 1：`nums = [1, 3], n = 6`

```
初始状态：
miss = 1, i = 0, patches = 0
已覆盖：[] (空)

步骤 1：nums[0] = 1 <= miss = 1
  使用 nums[0]，miss = 1 + 1 = 2
  已覆盖：[1, 2) → 可表示 {1}

步骤 2：nums[1] = 3 > miss = 2
  补充 miss = 2，miss = 2 * 2 = 4，patches = 1
  已覆盖：[1, 4) → 可表示 {1, 2, 3}

步骤 3：nums[1] = 3 <= miss = 4
  使用 nums[1]，miss = 4 + 3 = 7
  已覆盖：[1, 7) → 可表示 {1, 2, 3, 4, 5, 6}

miss = 7 > n = 6，结束
返回 patches = 1
```

示例 2：`nums = [1, 5, 10], n = 20`

```
miss = 1 → 使用 1 → miss = 2
miss = 2 → 补充 2 → miss = 4, patches = 1
miss = 4 → 补充 4 → miss = 8, patches = 2
miss = 8 → 使用 5 → miss = 13
miss = 13 → 使用 10 → miss = 23
miss = 23 > 20，结束
返回 patches = 2
```
