## 题目描述

给你整数数组 `start`、整数 `d` 和整数 `m`，从前 m 个下标中各选一个 `x[i]`（满足 `start[i] <= x[i] <= start[i]+d`），要求所有选值互不相同，返回最小值的最大可能值，不可行则返回 -1。

## 解题思路

二分答案 v（最小值），贪心检验：对每个区间有效范围 `[max(start[i], v), start[i]+d]`，按右端点排序后，用递增整数依次填充（当前值需 >= 区间左端点），若某区间无法分配则不可行。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxScore(int[] start, int d, int m) {
        // 确定二分范围
        int lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
        for (int i = 0; i < m; i++) {
            lo = Math.min(lo, start[i]);
            hi = Math.max(hi, start[i] + d);
        }

        if (!feasible(start, d, m, lo)) return -1;

        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (feasible(start, d, m, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean feasible(int[] start, int d, int m, int v) {
        // 生成 (右端点, 左端点) 对，按右端点排序
        int[][] pairs = new int[m][2];
        for (int i = 0; i < m; i++) {
            int left = Math.max(start[i], v);
            int right = start[i] + d;
            if (left > right) return false;
            pairs[i][0] = right;
            pairs[i][1] = left;
        }
        Arrays.sort(pairs, (a, b) -> a[0] - b[0]);

        long cur = v;
        for (int[] p : pairs) {
            if (cur < p[1]) cur = p[1]; // 不能低于区间左端点
            if (cur > p[0]) return false;
            cur++;
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log m * log(d))，二分 * 排序
- 空间复杂度：O(m)

## 关键点总结

1. 二分答案：枚举最小值 v，保证答案最大化
2. 贪心：按右端点排序，用递增整数依次分配（当前值需 >= 区间左端点）
3. `cur` 必须从 `max(cur, 左端点)` 开始，不能低于区间左端点约束
