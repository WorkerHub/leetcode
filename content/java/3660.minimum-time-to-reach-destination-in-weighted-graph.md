## 题目描述

给你一个 `n` 个节点的有向加权图，边集 `edges[i] = [u, v, w]`。从节点 0 出发，可以沿边移动或在当前节点等待。返回到达节点 `n-1` 的最短时间，不可达返回 -1。

## 解题思路

标准 Dijkstra 单源最短路：等待操作只会增加时间，不影响最短路结果。直接用 Dijkstra 求从节点 0 到节点 n-1 的最短路。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumTime(int n, int[][] edges) {
        List<int[]>[] graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) graph[e[0]].add(new int[]{e[1], e[2]});

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        // 最小堆：(距离, 节点)
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            if (u == n - 1) return (int) d;
            for (int[] edge : graph[u]) {
                int v = edge[0];
                long nd = d + edge[1];
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{nd, v});
                }
            }
        }
        return dist[n - 1] == Long.MAX_VALUE ? -1 : (int) dist[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O((V + E) log V)
- 空间复杂度：O(V + E)

## 关键点总结

1. 等待操作不影响 Dijkstra 正确性（等待只增加时间）
2. 用 `long` 避免边权累加溢出
3. 到达目标节点时提前返回
