## 题目描述

给你长度为 `n` 的整数数组 `nums`，返回单调对 `(arr1, arr2)` 的数量，其中 arr1 非递减、arr2 非递增，且 `arr1[i] + arr2[i] == nums[i]`，结果对 `10^9 + 7` 取模。

## 解题思路

设 `arr1[i] = y`，则约束为 `max(0, y - diff) <= arr1[i-1] <= min(y, nums[i-1])`，其中 `diff = nums[i] - nums[i-1]`。用 DP + 前缀和优化，`dp[y]` 表示 `arr1[i] = y` 时的方案数。

## Java 代码实现

```java
class Solution {
    public int countOfPairs(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        int maxVal = 0;
        for (int x : nums) maxVal = Math.max(maxVal, x);

        // dp[x] = arr1[i] = x 时的方案数
        long[] dp = new long[maxVal + 1];
        for (int x = 0; x <= nums[0]; x++) dp[x] = 1;

        for (int i = 1; i < n; i++) {
            long[] newDp = new long[maxVal + 1];
            // 构建前缀和加速区间查询
            long[] prefix = new long[maxVal + 2];
            for (int x = 0; x <= maxVal; x++) {
                prefix[x + 1] = (prefix[x] + dp[x]) % MOD;
            }
            int diff = nums[i] - nums[i - 1];
            for (int y = 0; y <= nums[i]; y++) {
                // 前一个 arr1 值 x 的合法范围
                int lo = Math.max(0, y - diff);
                int hi = Math.min(y, nums[i - 1]);
                if (lo > hi) continue;
                newDp[y] = (prefix[hi + 1] - prefix[lo] + MOD) % MOD;
            }
            dp = newDp;
        }

        long ans = 0;
        for (long v : dp) ans = (ans + v) % MOD;
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * maxVal)
- 空间复杂度：O(maxVal)

## 关键点总结

1. 将问题转化为选择 arr1[i] 的值，推导合法范围
2. 前缀和优化内层区间求和，降低时间复杂度
3. x 的上界为 `min(y, nums[i-1])`，需同时考虑两个约束
