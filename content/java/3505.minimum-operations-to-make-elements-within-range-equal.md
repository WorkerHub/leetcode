## 题目描述

给你整数数组 `nums` 和整数 `lower`、`upper`，每次操作将某元素 +1 或 -1，返回使所有不在 `[lower, upper]` 范围内的元素都变为该范围内某值的最少操作次数。

## 解题思路

贪心：小于 `lower` 的元素变为 `lower`（代价 `lower - x`），大于 `upper` 的元素变为 `upper`（代价 `x - upper`），已在范围内的元素代价为 0，累加即得答案。

## Java 代码实现

```java
class Solution {
    public long minOperations(int[] nums, int lower, int upper) {
        long total = 0;
        for (int x : nums) {
            if (x < lower) total += lower - x;
            else if (x > upper) total += x - upper;
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个元素独立贪心：最近目标为 lower 或 upper
2. 已在范围内代价为 0，直接跳过
3. 使用 `long` 防止累加溢出
