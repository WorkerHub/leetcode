## 题目描述

给你整数数组 maxHeights，建一组山形塔（先升后降），每座塔高度不超过 maxHeights[i]，返回高度之和的最大值。

## 解题思路

枚举峰顶：对每个下标 i 作为峰顶（高度取 maxHeights[i]），往左递推 `heights[j] = min(maxHeights[j], heights[j+1])`，往右递推 `heights[j] = min(maxHeights[j], heights[j-1])`，取所有峰顶方案中的最大和。

## Java 代码实现

```java
class Solution {
    public long maximumSumOfHeights(List<Integer> maxHeights) {
        int n = maxHeights.size();
        long ans = 0;

        for (int peak = 0; peak < n; peak++) {
            long[] heights = new long[n];
            heights[peak] = maxHeights.get(peak);

            // 往左：非递减约束
            for (int j = peak - 1; j >= 0; j--) {
                heights[j] = Math.min(maxHeights.get(j), heights[j + 1]);
            }

            // 往右：非递增约束
            for (int j = peak + 1; j < n; j++) {
                heights[j] = Math.min(maxHeights.get(j), heights[j - 1]);
            }

            long total = 0;
            for (long h : heights) total += h;
            ans = Math.max(ans, total);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
- **空间复杂度**：O(n)

## 关键点总结

1. 枚举每个位置为峰顶，峰顶高度取最大允许值
2. 往两侧递推：每个位置取 maxHeights 和相邻内侧高度的最小值
3. 数据量小（n ≤ 10^3），O(n^2) 足够
