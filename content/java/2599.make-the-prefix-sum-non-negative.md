## 题目描述

每次操作可将 `nums` 中任一元素移到数组末尾，返回使所有前缀和均非负所需的最少操作次数。

## 解题思路

**贪心 + 最小堆**：从左到右遍历，维护当前前缀和。当前缀和变负时，从已遇到的负数中选出最小（绝对值最大）的移走，能最大程度恢复前缀和。用最小堆维护已遇到的负数。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int makePrefSumNonNeg(int[] nums) {
        PriorityQueue<Integer> pq = new PriorityQueue<>(); // 最小堆
        long prefix = 0;
        int ops = 0;

        for (int x : nums) {
            prefix += x;
            if (x < 0) {
                pq.offer(x); // 存入负数
            }
            // 前缀和为负时，移走最小（最负）的元素
            while (prefix < 0 && !pq.isEmpty()) {
                int minNeg = pq.poll();
                prefix -= minNeg; // 减去负数 = 加绝对值
                ops++;
            }
        }
        return ops;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心：当前缀和为负时，移走当前已遇到的最小（最负）的数
2. 移走某元素等价于撤销其对前缀和的贡献
3. 只有负数才会使前缀和下降，堆中只需存负数
