## 题目描述

给你 2 个鸡蛋和 `n` 层楼，返回找到临界楼层所需的最少操作次数（最坏情况下）。

## 解题思路

数学推导：设最少操作次数为 k，则 k 次可覆盖最大楼层数为 k*(k+1)/2。最优策略每次递减步长（k, k-1, ...），因此求满足 k*(k+1)/2 >= n 的最小 k。

## Java 代码实现

```java
class Solution {
    public int twoEggDrop(int n) {
        // 求最小 k 使得 k*(k+1)/2 >= n
        int k = 1;
        while (k * (k + 1) / 2 < n) {
            k++;
        }
        return k;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(sqrt(n))
- **空间复杂度**：O(1)

## 关键点总结

1. 2 个鸡蛋时数学公式：k*(k+1)/2 >= n 的最小 k
2. 最优策略是三角数技巧：每次递减步长（k, k-1, k-2, ...）
