## 题目描述

给你整数数组 nums 和两个整数 indexDifference、valueDifference，找出满足 `abs(i-j) >= indexDifference` 且 `abs(nums[i]-nums[j]) >= valueDifference` 的两个下标 `[i, j]`，不存在则返回 `[-1, -1]`。

## 解题思路

数据范围 n <= 100，直接暴力枚举所有下标对，同时检查下标差和值差条件即可。

## Java 代码实现

```java
class Solution {
    public int[] findIndices(int[] nums, int indexDifference, int valueDifference) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                // 同时满足下标差和值差条件
                if (Math.abs(i - j) >= indexDifference &&
                    Math.abs(nums[i] - nums[j]) >= valueDifference) {
                    return new int[]{i, j};
                }
            }
        }
        return new int[]{-1, -1};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)，枚举所有下标对
- **空间复杂度**：O(1)

## 关键点总结

1. 数据范围小（n <= 100），暴力 O(n²) 完全可接受
2. `Math.abs` 处理绝对值，无需分类讨论
3. indexDifference == 0 时允许 i == j
