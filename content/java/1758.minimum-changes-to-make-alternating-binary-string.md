## 题目描述

给你二进制字符串 `s`，返回将其变为交替字符串（相邻字符不同）所需的最少操作数。

## 解题思路

只有两种目标交替字符串：`"010101..."` 和 `"101010..."`，两者不同字符数之和等于 n。只需统计与第一种的不同字符数 `cost1`，答案为 `min(cost1, n - cost1)`。

## Java 代码实现

```java
class Solution {
    public int minOperations(String s) {
        int n = s.length();
        int cost1 = 0; // 与 "010101..." 的不同字符数

        for (int i = 0; i < n; i++) {
            // 偶数位应为 '0'，奇数位应为 '1'
            char expected = (char) ('0' + i % 2);
            if (s.charAt(i) != expected) cost1++;
        }

        return Math.min(cost1, n - cost1); // 两种目标取最小
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 两种目标的不同字符数互补（和为 n）
2. 只需计算一种，取 `min(cost1, n-cost1)`
