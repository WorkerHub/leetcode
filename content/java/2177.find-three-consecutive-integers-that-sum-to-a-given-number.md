## 题目描述

找三个连续整数使其和等于num，若存在返回数组否则返回空数组。

## 解题思路

设中间数为n，则和=3n。num能被3整除时n=num/3，返回[n-1,n,n+1]；否则返回空。

## Java 代码实现

```java
class Solution {
    public long[] sumOfThree(long num) {
        if (num % 3 != 0) return new long[0];
        long n = num / 3;
        return new long[]{n - 1, n, n + 1};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **(n-1)+n+(n+1)=3n**：num必须被3整除
2. **中间数=num/3**：直接计算
3. **用long**：num可达10^15
