## 题目描述

给你压缩字符串 `compressed`（格式为字符+数字的交替组合），返回其"更好的压缩"：合并所有相同字符的次数后按字母顺序排列。

## 解题思路

解析压缩字符串，用计数数组统计每个字母的总次数，然后按字母顺序重建输出。

## Java 代码实现

```java
class Solution {
    public String betterCompression(String compressed) {
        int[] cnt = new int[26];
        int i = 0, n = compressed.length();
        while (i < n) {
            char c = compressed.charAt(i++);
            int num = 0;
            // 读取数字（可能多位）
            while (i < n && Character.isDigit(compressed.charAt(i))) {
                num = num * 10 + (compressed.charAt(i++) - '0');
            }
            cnt[c - 'a'] += num;
        }
        // 按字母顺序构建结果
        StringBuilder sb = new StringBuilder();
        for (int k = 0; k < 26; k++) {
            if (cnt[k] > 0) {
                sb.append((char) ('a' + k)).append(cnt[k]);
            }
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（字母表固定 26 个）

## 关键点总结

1. 数字部分可能是多位，需循环读取
2. 用大小为 26 的数组统计各字母总次数
3. 遍历数组按字母顺序输出，无需额外排序
