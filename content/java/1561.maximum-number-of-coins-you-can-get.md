## 题目描述

3n 堆硬币分成 n 组（每组3堆），Alice 拿最大、你拿次大、Bob 拿最小。选择分组使你获得最多硬币。

**示例：**
```
输入：piles = [2,4,1,2,7,8]
输出：9
```

## 解题思路

贪心：排序后最小 n 堆给 Bob，剩余 2n 堆从大到小每两堆你拿次大的（下标 n, n+2, ...）。

## Java 代码实现

```java
class Solution {
    public int maxCoins(int[] piles) {
        Arrays.sort(piles);
        int n = piles.length / 3;
        int ans = 0;
        // 从第 n 个开始，每隔一个取一个
        for (int i = n; i < piles.length; i += 2) {
            ans += piles[i];
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心分配**：最小 n 堆全给 Bob
2. **取法**：排序后从第 n 个开始每隔一个取
3. **证明**：大的两堆配一堆小的，你取次大
