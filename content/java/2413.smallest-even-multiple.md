## 题目描述

给你正整数 `n`，返回 2 和 `n` 的最小公倍数。

## 解题思路

若 n 为偶数，`lcm(2, n) = n`；若 n 为奇数，`lcm(2, n) = 2 * n`。

## Java 代码实现

```java
class Solution {
    public int smallestEvenMultiple(int n) {
        // 偶数：lcm = n；奇数：lcm = 2*n
        return n % 2 == 0 ? n : 2 * n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 与 2 求 LCM：偶数不变，奇数乘以 2。
2. 三元运算符一行完成。
