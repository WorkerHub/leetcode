## 题目描述

对 `nums` 中任意元素可以加减 `value` 任意次，返回操作后数组的最大 MEX（最小非负缺失整数）。

## 解题思路

**数学 + 哈希表**：每个元素通过加减 `value` 后，余数 `x % value` 不变。统计每个余数有多少个元素，从 0 开始贪心：检查余数为 `mex % value` 的元素够不够用，每次消耗一个，直到某余数耗尽。

注意 Java 中对负数取余可能为负，需加 `value` 修正。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findSmallestInteger(int[] nums, int value) {
        // 统计每个余数的元素个数（确保余数非负）
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : nums) {
            int r = ((x % value) + value) % value; // 非负余数
            cnt.merge(r, 1, Integer::sum);
        }

        int mex = 0;
        while (cnt.getOrDefault(mex % value, 0) > 0) {
            cnt.merge(mex % value, -1, Integer::sum);
            mex++;
        }
        return mex;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + MEX)
- 空间复杂度：O(value)

## 关键点总结

1. 每个元素通过加减 `value` 变换后，余数不变
2. 同一余数的 `cnt` 个元素可以覆盖 `cnt` 个等差为 `value` 的整数
3. Java 对负数取余可能为负，需 `((x % value) + value) % value` 修正
