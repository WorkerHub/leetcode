## 题目描述

十字路口两条道路，同一时间只允许一个方向通行。实现 TrafficLight 类，初始 road1 绿灯，carArrived 方法处理来车逻辑。

**规则：**
- 绿灯方向直接通过
- 红灯方向先切换信号灯再通过

## 解题思路

用互斥锁保护临界区，记录当前绿灯道路。若来车方向非绿灯，先调用 turnGreen 切换，再 crossCar。

## Java 代码实现

```java
class TrafficLight {
    private int greenRoad;
    private final Object lock = new Object();
    
    public TrafficLight() {
        greenRoad = 1; // 初始 road1 绿灯
    }
    
    public void carArrived(int carId, int roadId, int direction,
                          Runnable turnGreen, Runnable crossCar) {
        synchronized (lock) {
            if (roadId != greenRoad) {
                turnGreen.run();
                greenRoad = roadId;
            }
            crossCar.run();
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1) 每次调用
- **空间复杂度**：O(1)

## 关键点总结

1. **互斥锁**：保证同一时刻只有一辆车在路口
2. **状态记录**：greenRoad 记录当前绿灯方向
3. **条件切换**：只在需要时切换信号灯
