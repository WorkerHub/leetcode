## 题目描述

给你一个由字符 `'a'`、`'b'`、`'c'` 组成的字符串 `s` 和非负整数 `k`，每分钟可从左端或右端取一个字符，要求三种字符各取至少 `k` 个，返回最少所需分钟数，无法完成则返回 `-1`。

## 解题思路

逆向思维：从两端取字符等价于保留中间一段不取。用滑动窗口求最长合法中间段（窗口内每种字符数量不超过 `total[c] - k`），答案为 `n - 最大窗口长度`。

## Java 代码实现

```java
class Solution {
    public int takeCharacters(String s, int k) {
        int n = s.length();
        int[] total = new int[3];
        // 统计各字符总量
        for (char c : s.toCharArray()) total[c - 'a']++;

        // 总量不足直接返回 -1
        for (int cnt : total) if (cnt < k) return -1;

        int[] window = new int[3];
        int maxWindow = 0, left = 0;
        for (int right = 0; right < n; right++) {
            int idx = s.charAt(right) - 'a';
            window[idx]++;
            // 若窗口内该字符超出允许量，收缩左边界
            while (window[idx] > total[idx] - k) {
                window[s.charAt(left) - 'a']--;
                left++;
            }
            maxWindow = Math.max(maxWindow, right - left + 1);
        }
        return n - maxWindow;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 取走两端等价于保留中间，转化为求最长保留窗口
2. 窗口内允许的最多 c 字符数为 `total[c] - k`
3. 滑动窗口只需检查刚加入右端的字符是否超出限制
