## 题目描述

给你 n 个节点的有向图，每个节点恰好有一条出边，返回数组 `answer`，`answer[i]` 为从节点 i 出发能访问的不同节点数。

## 解题思路

函数图（每节点一条出边）必然存在环：拓扑排序找出所有非环节点，再扫描剩余节点标记环（答案 = 环的长度），最后从链端点反向传播（链节点答案 = 到环的链长 + 对应环节点答案）。

## Java 代码实现

```java
class Solution {
    public int[] countVisitedNodes(List<Integer> edges) {
        int n = edges.size();
        int[] inDeg = new int[n];
        for (int v : edges) inDeg[v]++;

        int[] ans = new int[n];
        boolean[] onCycle = new boolean[n];
        Arrays.fill(onCycle, true);

        // 拓扑排序，标记非环节点
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < n; i++) if (inDeg[i] == 0) q.offer(i);
        while (!q.isEmpty()) {
            int u = q.poll();
            onCycle[u] = false;
            int v = edges.get(u);
            if (--inDeg[v] == 0) q.offer(v);
        }

        // 计算环的大小
        boolean[] visited = new boolean[n];
        for (int i = 0; i < n; i++) {
            if (onCycle[i] && !visited[i]) {
                List<Integer> cycle = new ArrayList<>();
                int cur = i;
                while (!visited[cur]) {
                    visited[cur] = true;
                    cycle.add(cur);
                    cur = edges.get(cur);
                }
                for (int node : cycle) ans[node] = cycle.size();
            }
        }

        // 链节点反向传播答案（重新按拓扑逆序）
        int[] inDeg2 = new int[n];
        for (int i = 0; i < n; i++) if (!onCycle[i]) inDeg2[edges.get(i)]++;
        for (int i = 0; i < n; i++) if (!onCycle[i] && inDeg2[i] == 0) q.offer(i);
        while (!q.isEmpty()) {
            int u = q.poll();
            int v = edges.get(u);
            ans[u] = ans[v] + 1;
            if (!onCycle[v] && --inDeg2[v] == 0) q.offer(v);
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 函数图（每节点一条出边）必然有环，拓扑排序区分环节点和链节点
2. 环上节点答案 = 环的长度
3. 链节点答案 = 到环的路径长度 + 环入口节点的答案
