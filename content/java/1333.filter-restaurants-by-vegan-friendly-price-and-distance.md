## 题目描述

给你一个餐馆信息数组 `restaurants`，其中 `restaurants[i] = [id_i, rating_i, veganFriendly_i, price_i, distance_i]`。你必须使用以下三个过滤器来过滤这些餐馆信息。

其中素食者友好过滤器 `veganFriendly` 的值可以为 `true` 或者 `false`，如果该过滤器设为 `true`，则只考虑 `veganFriendly_i` 为 `true` 的餐馆，本过滤器设为 `false` 时，可以考虑所有餐馆。此外，我们还有最大价格过滤器 `maxPrice` 和最大距离过滤器 `maxDistance`，分别用来过滤价格大于 `maxPrice` 或距离大于 `maxDistance` 的餐馆。

过滤后返回餐馆的 **id**，按照 `rating` 从高到低排序。如果 `rating` 相同，则按 `id` 从高到低排序。请返回过滤后餐馆的 `id` 数组。

**示例 1：**
```
输入：restaurants = [[1,4,1,40,10],[2,8,0,50,5],[3,8,1,30,4],[4,10,0,10,3],[5,1,1,15,1]],
     veganFriendly = 1, maxPrice = 50, maxDistance = 10
输出：[3,1,5]
解释：
餐馆 1：[1,4,1,40,10] 满足所有条件，id = 1
餐馆 2：[2,8,0,50,5] 不满足条件（veganFriendly 为 0，但 veganFriendly 过滤器为 1）
餐馆 3：[3,8,1,30,4] 满足所有条件，id = 3
餐馆 4：[4,10,0,10,3] 不满足条件（veganFriendly 为 0）
餐馆 5：[5,1,1,15,1] 满足所有条件，id = 5
按 rating 降序排序：3（rating=8）, 1（rating=4）, 5（rating=1）
```

**示例 2：**
```
输入：restaurants = [[1,4,1,40,10],[2,8,0,50,5],[3,8,1,30,4],[4,10,0,10,3],[5,1,1,15,1]],
     veganFriendly = 0, maxPrice = 50, maxDistance = 10
输出：[4,3,2,1,5]
```

**提示：**
- `1 <= restaurants.length <= 10^4`
- `restaurants[i].length == 5`
- `1 <= id_i, rating_i, price_i, distance_i <= 10^5`
- `veganFriendly_i` 为 `0` 或 `1`
- `veganFriendly` 为 `0` 或 `1`

## 解题思路

**算法步骤：**
1. 遍历餐馆列表，按三个条件过滤
2. 对满足条件的餐馆按 `(rating, id)` 降序排序
3. 返回排序后的 id 列表

**过滤条件：**
- 若 `veganFriendly == 1`，则 `veganFriendly_i` 必须为 1
- `price_i <= maxPrice`
- `distance_i <= maxDistance`

## Java 代码实现

### 方法一：过滤 + 自定义排序（推荐）

```java
import java.util.*;

class Solution {
    public List<Integer> filterRestaurants(int[][] restaurants, int veganFriendly,
                                           int maxPrice, int maxDistance) {
        List<int[]> filtered = new ArrayList<>();
        
        // 过滤：素食友好 + 价格 + 距离
        for (int[] r : restaurants) {
            int vegan = r[2], price = r[3], distance = r[4];
            // 素食过滤：veganFriendly=1 时只保留 vegan=1 的餐馆
            if (veganFriendly == 1 && vegan != 1) continue;
            if (price > maxPrice) continue;
            if (distance > maxDistance) continue;
            filtered.add(r);
        }
        
        // 按 rating 降序，rating 相同按 id 降序
        filtered.sort((a, b) -> a[1] != b[1] ? b[1] - a[1] : b[0] - a[0]);
        
        // 返回 id 列表
        List<Integer> result = new ArrayList<>();
        for (int[] r : filtered) {
            result.add(r[0]);
        }
        return result;
    }
}
```

### 方法二：使用 Comparator.comparingInt（更清晰）

```java
import java.util.*;
import java.util.stream.*;

class Solution {
    public List<Integer> filterRestaurants(int[][] restaurants, int veganFriendly,
                                           int maxPrice, int maxDistance) {
        return Arrays.stream(restaurants)
            // 过滤条件
            .filter(r -> (veganFriendly == 0 || r[2] == 1) && r[3] <= maxPrice && r[4] <= maxDistance)
            // 按 rating 降序，rating 相同按 id 降序
            .sorted((a, b) -> a[1] != b[1] ? b[1] - a[1] : b[0] - a[0])
            // 提取 id
            .map(r -> r[0])
            .collect(Collectors.toList());
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/二 | O(n log n) | O(n) |

- **时间复杂度**：过滤 O(n)，排序 O(n log n)，总体 O(n log n)
- **空间复杂度**：存储过滤结果 O(n)

## 关键点总结

1. 三个过滤条件的逻辑：`veganFriendly` 为 0 时不限制素食，为 1 时只保留素食餐馆
2. 排序键是 `(rating, id)` 两级，均为降序
3. Java 的 `Comparator` 可以通过链式比较实现多级排序

## 易错点

1. 素食过滤的条件：`veganFriendly=0` 时不过滤任何餐馆，`veganFriendly=1` 时只保留 `vegan=1`
   - 错误写法：`r[2] == veganFriendly`（当 `veganFriendly=0` 时会过滤掉 `vegan=1` 的餐馆）
   - 正确写法：`veganFriendly == 0 || r[2] == 1`
2. 排序是降序，注意 `b[1] - a[1]` 而非 `a[1] - b[1]`
3. 注意返回的是 `id`，不是餐馆的完整信息
