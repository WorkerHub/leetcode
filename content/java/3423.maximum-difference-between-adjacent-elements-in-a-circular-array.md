## 题目描述

给定循环数组 `nums`（最后一个元素与第一个元素相邻），返回所有相邻元素绝对差的最大值。

## Java 代码实现

```java
class Solution {
    public int maxAdjacentDistance(int[] nums) {
        int n = nums.length;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            // 使用 (i+1)%n 处理循环边界
            ans = Math.max(ans, Math.abs(nums[i] - nums[(i + 1) % n]));
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 循环数组：`nums[n-1]` 和 `nums[0]` 也是相邻的。
2. 使用 `(i+1) % n` 处理循环边界。
3. 取所有相邻差绝对值的最大值。
