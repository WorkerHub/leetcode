## 题目描述

与 3265 相同，但允许**最多两次**数字交换（每次交换一对数字）。`2 <= nums.length <= 10^3`，`0 <= nums[i] <= 10^7`。

## 解题思路

生成每个数经过最多两次交换后的所有可能变体（含自身），用哈希表统计。每个数最多 8 位，两次交换枚举量 O(D^4)，可以接受。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPairs(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        int ans = 0;

        for (int x : nums) {
            Set<Integer> variants = getVariants(x);
            for (int v : variants) {
                ans += cnt.getOrDefault(v, 0);
            }
            cnt.merge(x, 1, Integer::sum);
        }
        return ans;
    }

    private Set<Integer> getVariants(int x) {
        char[] s0 = String.format("%08d", x).toCharArray();
        Set<Integer> variants = new HashSet<>();
        variants.add(x);

        int n = s0.length;
        // 第一次交换
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                char tmp = s0[i]; s0[i] = s0[j]; s0[j] = tmp;
                if (s0[0] != '0') {
                    int v1 = Integer.parseInt(new String(s0));
                    variants.add(v1);
                    // 第二次交换
                    char[] s1 = s0.clone();
                    for (int p = 0; p < n; p++) {
                        for (int q = p + 1; q < n; q++) {
                            char t = s1[p]; s1[p] = s1[q]; s1[q] = t;
                            if (s1[0] != '0') {
                                variants.add(Integer.parseInt(new String(s1)));
                            }
                            t = s1[p]; s1[p] = s1[q]; s1[q] = t;
                        }
                    }
                }
                // 还原
                tmp = s0[i]; s0[i] = s0[j]; s0[j] = tmp;
            }
        }
        return variants;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * D^4)，D 为数字位数（最多 8）
- 空间复杂度：O(D^4) 每个数字的变体数

## 关键点总结

1. 最多两次交换，枚举第一次和第二次的所有可能组合
2. 集合去重，避免重复计数
3. 先统计后查询，只统计 i < j 的对
