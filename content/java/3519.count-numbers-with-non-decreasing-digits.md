## 题目描述

给定两个整数 `l` 和 `r`（最大 10^18），统计区间 `[l, r]` 内各位数字非递减的整数个数。

## 解题思路

数位 DP + 组合数公式：`f(r) - f(l-1)`。对于 `f(n)`，逐位枚举，对不受上界约束的位：从当前最小可选数字 `d` 到 9，后续 `remaining` 位从 `d` 到 9 中选（可重复），方案数为 `C(9-d+remaining, remaining)`。

## Java 代码实现

```java
class Solution {
    public long countNumbers(long l, long r) {
        return countUpTo(r) - countUpTo(l - 1);
    }

    private long countUpTo(long n) {
        if (n <= 0) return 0;
        int[] digits = getDigits(n);
        int m = digits.length;
        long total = 0;
        int prevDigit = 0;
        boolean started = false;

        for (int i = 0; i < m; i++) {
            int limit = digits[i];
            int from = started ? prevDigit : 1; // 前导零不计
            // 枚举 d < limit（不含 limit，不受约束的部分）
            for (int d = from; d < limit; d++) {
                int remaining = m - i - 1;
                total += comb(9 - d + remaining, remaining);
            }
            // 检查 digits[i] 是否满足非递减
            if (started && digits[i] < prevDigit) return total;
            // 继续取 digits[i]
            if (!started && digits[i] == 0) {
                // 前导零：不更新 prevDigit，继续
            } else {
                prevDigit = digits[i];
                started = true;
            }
        }
        // n 本身满足条件
        if (started) total++;
        return total;
    }

    private int[] getDigits(long n) {
        String s = Long.toString(n);
        int[] d = new int[s.length()];
        for (int i = 0; i < s.length(); i++) d[i] = s.charAt(i) - '0';
        return d;
    }

    // C(n, r) with cap to avoid overflow
    private long comb(int n, int r) {
        if (r < 0 || n < r) return 0;
        if (r == 0) return 1;
        r = Math.min(r, n - r);
        long res = 1;
        for (int i = 0; i < r; i++) {
            res = res * (n - i) / (i + 1);
        }
        return res;
    }
}
```

## 复杂度分析

- 时间复杂度：O(D * 10)，D 为数字位数（最多 19）
- 空间复杂度：O(D)

## 关键点总结

1. 前缀计数：`f(r) - f(l-1)`
2. 不受上界约束时，选数字 d 后剩余位的方案数为 `C(9-d+remaining, remaining)`（多重集组合）
3. 遇到违反非递减的上界数字时立即截止
