## 题目描述

给你一棵以 `root` 为根的二叉树，返回其中最长锯齿形路径的长度（边数）。锯齿形路径要求方向左右交替。

## 解题思路

DFS 时传入到达当前节点的方向（左/右）和当前锯齿长度。若继续锯齿方向则长度加 1，若方向中断则重置为 1。对每个节点更新全局最大值，路径可从任意节点出发。

## Java 代码实现

```java
class Solution {
    private int ans = 0;

    public int longestZigZag(TreeNode root) {
        dfs(root, true, 0);
        dfs(root, false, 0);
        return ans;
    }

    // goLeft: 下一步应向左走（true）还是向右走（false）
    // length: 当前锯齿路径已有的边数
    private void dfs(TreeNode node, boolean goLeft, int length) {
        if (node == null) return;
        ans = Math.max(ans, length);
        if (goLeft) {
            dfs(node.left, false, length + 1);  // 向左继续锯齿，下一步向右
            dfs(node.right, true, 1);            // 向右中断，重新计数
        } else {
            dfs(node.right, true, length + 1);   // 向右继续锯齿，下一步向左
            dfs(node.left, false, 1);             // 向左中断，重新计数
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个节点访问两次（左右方向各一次，但整体仍为 O(n)）。
- 空间复杂度：O(h)，h 为树的高度，递归栈深度。

## 关键点总结

1. DFS 传递方向和当前长度，每到一个节点立即更新全局最大值。
2. 方向中断时长度重置为 1（新路径从当前这条边开始）。
3. 路径可从任意节点出发，根节点需同时尝试向左和向右两个起始方向。
