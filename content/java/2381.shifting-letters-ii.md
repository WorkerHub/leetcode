## 题目描述

给你字符串 `s` 和操作数组 `shifts`（每项为 `[start, end, direction]`），同时对 `[start, end]` 范围内的字母向前（direction=1）或向后（direction=0）移位 1 位，返回最终字符串。

## 解题思路

差分数组：direction=1 时 delta=+1，direction=0 时 delta=-1，在区间两端打标记，前缀和还原每个位置的总移位量，取模 26 后更新字符。

## Java 代码实现

```java
class Solution {
    public String shiftingLetters(String s, int[][] shifts) {
        int n = s.length();
        int[] diff = new int[n + 1]; // 差分数组
        for (int[] sh : shifts) {
            int delta = sh[2] == 1 ? 1 : -1;
            diff[sh[0]] += delta;
            diff[sh[1] + 1] -= delta;
        }
        char[] res = s.toCharArray();
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += diff[i];
            // 取模并处理负数
            int shift = ((total % 26) + 26) % 26;
            res[i] = (char) ('a' + (res[i] - 'a' + shift) % 26);
        }
        return new String(res);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + m)，m 为 shifts 长度
- **空间复杂度**：O(n)

## 关键点总结

1. 差分数组 + 前缀和实现区间加法，O(m + n) 处理所有操作。
2. Java 的 `%` 对负数可能返回负值，需要 `(total % 26 + 26) % 26` 处理。
3. direction=1 向前（+1），direction=0 向后（-1）。
