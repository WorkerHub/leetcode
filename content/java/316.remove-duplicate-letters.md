## 题目描述

给你一个字符串 `s` ，请你去除字符串中重复的字母，使得每个字母只出现一次。需保证**返回结果的字典序最小**（要求不能打乱其他字符的相对位置）。

**示例 1：**
```
输入：s = "bcabc"
输出："abc"
```

**示例 2：**
```
输入：s = "cbacdcbc"
输出："acdb"
```

**提示：**
- `1 <= s.length <= 10^4`
- `s` 由小写英文字母组成

## 解题思路

这道题需要满足三个条件：
1. **去重**：每个字符只出现一次
2. **字典序最小**：结果是最小的
3. **保持相对顺序**：不能任意排列

### 核心思想：贪心 + 单调栈

使用单调栈维护结果，关键在于决定何时弹出栈顶元素：
- 当前字符比栈顶小
- 栈顶字符后面还会出现（可以后面再加入）
- 当前字符不在栈中（避免重复）

## Java 代码实现

### 方法一：单调栈 + 贪心（推荐）⭐

```java
class Solution {
    public String removeDuplicateLetters(String s) {
        // 统计每个字符的最后出现位置
        int[] lastOccurrence = new int[26];
        for (int i = 0; i < s.length(); i++) {
            lastOccurrence[s.charAt(i) - 'a'] = i;
        }

        // 单调栈（用 Deque 模拟）
        Deque<Character> stack = new ArrayDeque<>();
        // 记录栈中已有的字符
        boolean[] inStack = new boolean[26];

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);

            // 如果字符已在栈中，跳过
            if (inStack[ch - 'a']) continue;

            // 维护单调性：当前字符比栈顶小，且栈顶后面还会出现
            while (!stack.isEmpty() && ch < stack.peek()
                    && i < lastOccurrence[stack.peek() - 'a']) {
                char removed = stack.pop();
                inStack[removed - 'a'] = false;
            }

            // 将当前字符入栈
            stack.push(ch);
            inStack[ch - 'a'] = true;
        }

        // 将栈中字符转为字符串（栈底到栈顶）
        StringBuilder sb = new StringBuilder();
        for (char c : stack) sb.append(c);
        return sb.reverse().toString();
    }
}
```

### 方法二：使用计数器

```java
class Solution {
    public String removeDuplicateLetters(String s) {
        // 统计每个字符出现次数
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        Deque<Character> stack = new ArrayDeque<>();
        boolean[] inStack = new boolean[26];

        for (char ch : s.toCharArray()) {
            // 减少计数
            count[ch - 'a']--;

            // 已在栈中，跳过
            if (inStack[ch - 'a']) continue;

            // 弹出条件：栈顶更大 且 后面还有
            while (!stack.isEmpty() && ch < stack.peek()
                    && count[stack.peek() - 'a'] > 0) {
                char removed = stack.pop();
                inStack[removed - 'a'] = false;
            }

            stack.push(ch);
            inStack[ch - 'a'] = true;
        }

        // 构建结果字符串
        StringBuilder sb = new StringBuilder();
        for (char c : stack) sb.append(c);
        return sb.reverse().toString();
    }
}
```

### 方法三：带详细注释的版本

```java
class Solution {
    /**
     * 单调栈 + 贪心
     *
     * 核心思想：
     * 1. 每个字符只保留一次
     * 2. 结果字典序最小
     * 3. 保持相对顺序
     *
     * 策略：
     * - 遍历字符串
     * - 如果当前字符比栈顶小，且栈顶后面还会出现，就弹出栈顶
     * - 直到不满足条件，将当前字符入栈
     */
    public String removeDuplicateLetters(String s) {
        // 记录每个字符最后出现的位置
        int[] lastPos = new int[26];
        for (int i = 0; i < s.length(); i++) {
            lastPos[s.charAt(i) - 'a'] = i;
        }

        Deque<Character> stack = new ArrayDeque<>(); // 结果栈
        boolean[] used = new boolean[26];            // 已使用的字符

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);

            // 1. 如果字符已在结果中，跳过
            if (used[ch - 'a']) continue;

            // 2. 维护单调性（贪心）
            // 条件：
            // - 栈不为空
            // - 当前字符 < 栈顶字符（想要更小的字典序）
            // - 栈顶字符后面还会出现（可以后面再加）
            while (!stack.isEmpty() && ch < stack.peek()
                    && i < lastPos[stack.peek() - 'a']) {
                char removed = stack.pop();
                used[removed - 'a'] = false;
            }

            // 3. 加入当前字符
            stack.push(ch);
            used[ch - 'a'] = true;
        }

        // 构建结果（栈是逆序的，需要反转）
        StringBuilder sb = new StringBuilder();
        for (char c : stack) sb.append(c);
        return sb.reverse().toString();
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，每个字符最多入栈出栈一次
- 空间复杂度：O(1)，字符集大小固定（26 个字母）

## 关键点总结

1. **单调栈**：维护字典序递增
2. **贪心策略**：能弹就弹，让后面的小字符靠前
3. **弹出条件**：
   - 当前字符 < 栈顶
   - 栈顶后面还会出现
   - 当前字符不在栈中
4. **最后出现位置**：判断能否弹出的依据
5. **inStack 数组**：快速判断字符是否已在结果中

## 易错点

1. **重复处理**：已在栈中的字符要跳过
2. **弹出条件**：三个条件都要满足
3. **计数 vs 最后位置**：
   - 计数：需要每次减 1
   - 最后位置：一次性计算
4. **数组操作**：弹出时要同步更新 inStack/used
5. **结果构建**：Java 的 Deque 栈顶是最先 push 的，输出时需要反转
