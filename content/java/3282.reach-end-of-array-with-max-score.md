## 题目描述

给你整数数组 `nums`，从下标 0 开始，每次跳到位置 `j>i` 得分 `(j-i)*nums[i]`，返回跳到末尾的最大总得分。

## 解题思路

贪心：每次移动 1 步，得分等于当前前缀最大值。总得分 = Σ(前缀最大值) for i in [0, n-2]。原因：只有遇到更大值时才值得停留，否则直接延长距离乘以当前最大值等价于每步累加最大值。

## Java 代码实现

```java
class Solution {
    public long findMaximumScore(int[] nums) {
        long ans = 0;
        long curMax = 0;
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            curMax = Math.max(curMax, nums[i]); // 维护前缀最大值
            ans += curMax;                      // 每步贡献当前最大值
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 等价转化：总得分 = Σ(位置 i 到 i+1 的前缀最大值)
2. 只在遇到更大值时停留，否则继续延伸
3. 注意返回值用 `long`，n 和 nums[i] 最大均为 10^9
