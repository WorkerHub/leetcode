## 题目描述

给你特性数组 `features` 和用户反馈数组 `responses`，统计每个 feature 被多少不同用户提及（同一用户同次反馈中重复提及只算一次），按频率降序（频率相同保持原序）返回 `features`。

## 解题思路

用哈希表统计每个 feature 的提及用户数，对每个 response 用 Set 去重后统计。再对 features 按频率降序、原始索引升序稳定排序。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public String[] sortFeatures(String[] features, String[] responses) {
        Set<String> featureSet = new HashSet<>(Arrays.asList(features));
        Map<String, Integer> count = new HashMap<>();

        for (String response : responses) {
            // 同一 response 中每个 feature 只计一次
            Set<String> words = new HashSet<>(Arrays.asList(response.split(" ")));
            for (String w : words) {
                if (featureSet.contains(w)) {
                    count.merge(w, 1, Integer::sum);
                }
            }
        }

        // 记录原始索引
        Integer[] indices = new Integer[features.length];
        for (int i = 0; i < features.length; i++) indices[i] = i;

        // 按频率降序，频率相同保持原索引升序（稳定排序）
        Arrays.sort(indices, (a, b) ->
            count.getOrDefault(features[b], 0) - count.getOrDefault(features[a], 0)
        );

        String[] ans = new String[features.length];
        for (int i = 0; i < features.length; i++) ans[i] = features[indices[i]];
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * m + n log n)，n 为特性数，m 为反馈平均词数
- **空间复杂度**：O(n)

## 关键点总结

1. 用 Set 对每个 response 的单词去重，确保同次反馈不重复计数
2. Java `Arrays.sort` 对对象数组稳定排序（等频率时保持原顺序）
