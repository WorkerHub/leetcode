## 题目描述

句子 `s` 由小写字母和数字组成，判断句子中所有数字是否严格递增。

## 解题思路

按空格分割字符串，遍历每个 token，若为纯数字则与上一个数字比较是否严格递增。

## Java 代码实现

### 方法一：split + 判断数字（推荐）

```java
class Solution {
    public boolean areNumbersAscending(String s) {
        int prev = -1;
        for (String token : s.split(" ")) {
            if (Character.isDigit(token.charAt(0))) { // token 为纯数字
                int num = Integer.parseInt(token);
                if (num <= prev) return false;
                prev = num;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)（split 产生的数组）

## 关键点总结

1. 分割后判断 token 首字符是否为数字
2. 严格递增，不能相等
