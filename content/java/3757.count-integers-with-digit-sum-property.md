## 题目描述

给定整数 `n`，统计 `[1, n]` 范围内，满足"数字之和等于某个完全平方数"的整数数量。

## 解题思路

数位 DP。数字和范围 1~81（最多 9 位，每位最大 9）。对每个完全平方数目标 `t`，用数位 DP 统计 [1, n] 中数字和等于 `t` 的整数数量，累加得答案。

## Java 代码实现

```java
class Solution {
    private char[] digits;
    private int[][] memo;

    public int countIntegers(int n) {
        digits = String.valueOf(n).toCharArray();
        int len = digits.length;
        int total = 0;
        // 完全平方数 <= 81
        for (int r = 1; r * r <= 81; r++) {
            memo = new int[len][82];
            for (int[] row : memo) java.util.Arrays.fill(row, -1);
            total += dp(0, r * r, 1, false);
        }
        return total;
    }

    private int dp(int pos, int rem, int tight, boolean started) {
        if (rem < 0) return 0;
        if (pos == digits.length) {
            return (started && rem == 0) ? 1 : 0;
        }
        if (started && memo[pos][rem] != -1 && tight == 0) {
            return memo[pos][rem];
        }
        int limit = tight == 1 ? (digits[pos] - '0') : 9;
        int count = 0;
        for (int d = 0; d <= limit; d++) {
            int newTight = (tight == 1 && d == limit) ? 1 : 0;
            if (d == 0 && !started) {
                count += dp(pos + 1, rem, newTight, false);
            } else {
                count += dp(pos + 1, rem - d, newTight, true);
            }
        }
        if (started && tight == 0) memo[pos][rem] = count;
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(L × 81 × 10)，L 为位数（最多 10）
- 空间复杂度：O(L × 81)

## 关键点总结

1. 数字和上界为 81，完全平方数只有 9 个（1,4,9,...,81）
2. 数位 DP 的标准套路：pos、剩余目标和、tight 标志
3. 对每个目标完全平方数分别统计再求和
