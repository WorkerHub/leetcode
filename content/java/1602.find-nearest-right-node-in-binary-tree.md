## 题目描述

给定二叉树和节点u，返回与u同层中最近的右侧节点。若u是该层最右节点返回null。

## 解题思路

BFS层序遍历，找到u后返回队列头部的下一个节点（同层）。若u是该层最后一个则返回null。

## Java 代码实现

```java
class Solution {
    public TreeNode findNearestRightNode(TreeNode root, TreeNode u) {
        if (root == null) return null;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node == u) {
                    // 如果是该层最后一个节点，返回null
                    return (i < size - 1) ? queue.peek() : null;
                }
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return null;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **BFS天然按层遍历**：找到u后看同层下一个
2. **判断层末**：用循环变量i判断是否是该层最后一个
3. **queue.peek()**：获取队列头但不弹出
