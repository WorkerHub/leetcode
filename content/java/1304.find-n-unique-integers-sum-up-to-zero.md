## 题目描述

返回 n 个各不相同的整数组成的数组，使得和为 0。

**示例：**
```
输入：n = 5
输出：[-2,-1,0,1,2]
```

## 解题思路

对称构造：[-1, 1, -2, 2, ...]，n 为奇数时加个 0。

## Java 代码实现

```java
class Solution {
    public int[] sumZero(int n) {
        int[] result = new int[n];
        for (int i = 0; i < n / 2; i++) {
            result[i] = i + 1;
            result[n - 1 - i] = -(i + 1);
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（不计结果）

## 关键点总结

1. **对称构造**：正负配对自然抵消
2. **奇数中间**：加 0 不影响和
3. **简洁方法**：也可用 [1, 2, ..., n-1, -(1+2+...+n-1)]
