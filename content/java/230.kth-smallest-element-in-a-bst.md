## 题目描述

给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**示例 1：**

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

```
    3
   / \
  1   4
   \
    2
```

**示例 2：**

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

```
        5
       / \
      3   6
     / \
    2   4
   /
  1
```

**提示：**

- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶：** 如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

## 解题思路

这道题的关键是利用**二叉搜索树（BST）的性质**：中序遍历 BST 得到的序列是**升序**的。

### 核心思想

**中序遍历 BST，第 k 个访问的节点就是第 k 小的元素。**

中序遍历顺序：左 -> 根 -> 右

### 三种实现方式

1. **递归中序遍历**：完整遍历后取第 k 个
2. **迭代中序遍历**：边遍历边计数，找到第 k 个立即停止
3. **优化：提前终止**：递归时记录计数，找到后立即返回

## Java 代码实现

### 方法一：递归中序遍历（推荐）

```java
class Solution {
    private int count = 0; // 当前访问的是第几个节点
    private int result = 0; // 结果

    public int kthSmallest(TreeNode root, int k) {
        count = 0;
        result = 0;
        inorder(root, k);
        return result;
    }

    private void inorder(TreeNode node, int k) {
        if (node == null) {
            return;
        }

        // 遍历左子树
        inorder(node.left, k);

        // 访问当前节点
        count++;
        if (count == k) {
            result = node.val;
            return;
        }

        // 遍历右子树
        inorder(node.right, k);
    }
}
```

### 方法二：迭代中序遍历（栈）

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode node = root;
        int count = 0;

        while (!stack.isEmpty() || node != null) {
            // 一直往左走，将左节点入栈
            while (node != null) {
                stack.push(node);
                node = node.left;
            }

            // 弹出栈顶节点（当前最小的未访问节点）
            node = stack.pop();
            count++;

            // 如果是第 k 个节点，返回
            if (count == k) {
                return node.val;
            }

            // 转向右子树
            node = node.right;
        }

        return -1; // 不会到达这里
    }
}
```

### 方法三：完整中序遍历后取第 k 个

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        List<Integer> sortedVals = new ArrayList<>();
        inorder(root, sortedVals);
        return sortedVals.get(k - 1);
    }

    /** 中序遍历，将结果收集到列表 */
    private void inorder(TreeNode node, List<Integer> list) {
        if (node == null) {
            return;
        }
        inorder(node.left, list);
        list.add(node.val);
        inorder(node.right, list);
    }
}
```

### 方法四：Morris 遍历（空间 O(1)）

```java
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        // Morris 中序遍历，不使用栈和递归
        int count = 0;
        TreeNode current = root;

        while (current != null) {
            if (current.left == null) {
                // 左子树为空，访问当前节点
                count++;
                if (count == k) {
                    return current.val;
                }
                current = current.right;
            } else {
                // 找到左子树的最右节点（前驱节点）
                TreeNode predecessor = current.left;
                while (predecessor.right != null && predecessor.right != current) {
                    predecessor = predecessor.right;
                }

                if (predecessor.right == null) {
                    // 建立线索
                    predecessor.right = current;
                    current = current.left;
                } else {
                    // 恢复树结构，访问当前节点
                    predecessor.right = null;
                    count++;
                    if (count == k) {
                        return current.val;
                    }
                    current = current.right;
                }
            }
        }

        return -1;
    }
}
```

### 方法五：详细注释版（迭代）

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        /**
         * 查找二叉搜索树中第 k 小的元素
         *
         * 核心思想：
         * 1. BST 的中序遍历是升序的
         * 2. 中序遍历的第 k 个节点就是第 k 小的元素
         * 3. 使用迭代 + 栈实现中序遍历
         */
        Deque<TreeNode> stack = new ArrayDeque<>(); // 栈：存储待访问的节点
        TreeNode node = root;   // 当前节点
        int count = 0;          // 已访问的节点数

        while (!stack.isEmpty() || node != null) {
            // 步骤1：一直往左走，将路径上的节点压栈
            while (node != null) {
                stack.push(node);
                node = node.left;
            }

            // 步骤2：弹出栈顶节点（当前最小的未访问节点）
            node = stack.pop();

            // 步骤3：访问节点（计数）
            count++;
            if (count == k) {
                // 找到第 k 小的元素
                return node.val;
            }

            // 步骤4：转向右子树
            node = node.right;
        }

        return -1;
    }
}
```

## 复杂度分析

**方法一：递归中序遍历**
- 时间复杂度：O(k)，最好情况下访问 k 个节点就可以停止
- 空间复杂度：O(h)，递归栈深度为树的高度

**方法二：迭代中序遍历**
- 时间复杂度：O(k)，访问前 k 个节点
- 空间复杂度：O(h)，栈的深度为树的高度

**方法三：完整遍历**
- 时间复杂度：O(n)，需要遍历所有节点
- 空间复杂度：O(n)，需要存储所有节点的值

**方法四：Morris 遍历**
- 时间复杂度：O(k)，虽然每条边最多访问 2 次，但只访问前 k 个节点
- 空间复杂度：O(1)，不使用额外空间

## 图解示例

以示例 2 为例：

```
        5
       / \
      3   6
     / \
    2   4
   /
  1

中序遍历顺序：1 -> 2 -> 3 -> 4 -> 5 -> 6

k = 3，第 3 小的元素是 3

迭代过程：
1. 一路向左：5 -> 3 -> 2 -> 1，栈：[5, 3, 2, 1]
2. 弹出 1，count=1，转向右子树（null）
3. 弹出 2，count=2，转向右子树（null）
4. 弹出 3，count=3，找到！返回 3
```

## 关键点总结

1. **BST 性质**：中序遍历得到升序序列
2. **提前终止**：找到第 k 个节点后立即停止，不需要遍历整棵树
3. **中序遍历模板**：掌握递归和迭代两种实现
4. **空间优化**：Morris 遍历可以做到 O(1) 空间
5. **计数技巧**：使用变量记录已访问的节点数

## 易错点

1. **索引问题**：题目是从 1 开始计数，不是从 0
2. **遍历顺序**：必须是中序遍历（左-根-右），不能是前序或后序
3. **提前返回**：找到第 k 个节点后要立即返回，不要继续遍历
4. **空节点检查**：递归和迭代都要检查空节点
5. **栈的使用**：迭代时要正确使用栈模拟递归
