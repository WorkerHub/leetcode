## 题目描述

给定一个单链表的头节点 `head`，其中的元素按升序排序，将其转换为高度平衡的二叉搜索树。

本题中，一个高度平衡二叉树是指一个二叉树每个节点的左右两个子树的高度差不超过 1。

**示例 1：**

```
输入：head = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：一个可能的答案是 [0,-3,9,-10,null,5]，它表示所示的高度平衡二叉搜索树。
```

**示例 2：**

```
输入：head = []
输出：[]
```

**提示：**

- `head` 中的节点数在 `[0, 2 * 10^4]` 范围内
- `-10^5 <= Node.val <= 10^5`

## 解题思路

这道题是第 108 题的进阶版，区别在于数据结构从数组换成了链表。链表不支持随机访问，所以不能直接使用索引，需要调整策略。

### 核心思路

**方法一：转换为数组**
- 先遍历链表，将所有值存入数组
- 然后使用第 108 题的方法构建平衡 BST
- 时间 O(n)，空间 O(n)

**方法二：快慢指针找中点**
- 使用快慢指针找到链表的中间节点作为根节点
- 递归地处理左右两半链表
- 时间 O(n log n)，空间 O(log n)

**方法三：中序遍历模拟（最优）**
- 利用 BST 的中序遍历等于有序序列的性质
- 先计算链表长度，确定树的结构
- 按中序遍历的顺序构建树，同时遍历链表
- 时间 O(n)，空间 O(log n)

## Java 代码实现

### 方法一：转换为数组（最简单）⭐

```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        // 步骤 1：将链表转换为数组
        List<Integer> values = new ArrayList<>();
        ListNode current = head;
        while (current != null) {
            values.add(current.val);
            current = current.next;
        }

        // 步骤 2：使用数组构建平衡 BST
        return buildTree(values, 0, values.size() - 1);
    }

    private TreeNode buildTree(List<Integer> values, int left, int right) {
        if (left > right) return null;

        // 选择中间元素作为根节点
        int mid = (left + right) / 2;
        TreeNode root = new TreeNode(values.get(mid));

        // 递归构建左右子树
        root.left = buildTree(values, left, mid - 1);
        root.right = buildTree(values, mid + 1, right);

        return root;
    }
}
```

### 方法二：快慢指针找中点

```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) return null;
        return build(head, null);
    }

    private TreeNode build(ListNode left, ListNode right) {
        // left 到 right（不含）之间没有节点
        if (left == right) return null;

        // 使用快慢指针找到链表中点
        ListNode slow = left, fast = left;
        while (fast != right && fast.next != right) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 创建根节点
        TreeNode root = new TreeNode(slow.val);

        // 递归构建左右子树
        root.left = build(left, slow);
        root.right = build(slow.next, right);

        return root;
    }
}
```

### 方法三：中序遍历模拟（最优）⭐⭐

```java
class Solution {
    // 当前遍历到的链表节点
    private ListNode current;

    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) return null;

        // 步骤 1：计算链表长度
        int length = 0;
        ListNode node = head;
        while (node != null) {
            length++;
            node = node.next;
        }

        this.current = head;
        return buildTree(0, length - 1);
    }

    private TreeNode buildTree(int left, int right) {
        if (left > right) return null;

        // 计算中间位置
        int mid = (left + right) / 2;

        // 按照中序遍历的顺序：先构建左子树
        TreeNode leftChild = buildTree(left, mid - 1);

        // 创建根节点，并移动链表指针
        TreeNode root = new TreeNode(current.val);
        root.left = leftChild;
        current = current.next;

        // 构建右子树
        root.right = buildTree(mid + 1, right);

        return root;
    }
}
```

### 方法四：快慢指针 + 断链

```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        if (head == null) return null;

        // 找到中间节点，同时断开左半部分
        ListNode mid = getMid(head);
        TreeNode root = new TreeNode(mid.val);

        // 如果只有一个节点
        if (head == mid) return root;

        // 递归构建左右子树
        root.left = sortedListToBST(head);
        root.right = sortedListToBST(mid.next);

        return root;
    }

    private ListNode getMid(ListNode head) {
        ListNode prev = null;
        ListNode slow = head, fast = head;

        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }

        // 断开左半部分和中间节点
        if (prev != null) prev.next = null;

        return slow;
    }
}
```

## 复杂度分析

### 方法一：转换为数组

- **时间复杂度**：O(n)，遍历链表一次 + 构建树一次
- **空间复杂度**：O(n)，需要额外数组存储所有值

### 方法二：快慢指针

- **时间复杂度**：O(n log n)
  - 每层递归需要 O(n) 时间找中点
  - 递归深度为 O(log n)
- **空间复杂度**：O(log n)，递归调用栈

### 方法三：中序遍历模拟

- **时间复杂度**：O(n)，计算长度 O(n) + 遍历链表一次 O(n)
- **空间复杂度**：O(log n)，递归调用栈

### 方法四：递归 + 断链

- **时间复杂度**：O(n log n)，同方法二
- **空间复杂度**：O(log n)，递归调用栈

## 关键点总结

1. **方法选择**：
   - 简单实现：方法一（转数组）
   - 空间优化：方法二或方法三
   - 时间最优：方法三
2. **快慢指针技巧**：快指针走两步，慢指针走一步，可以找到链表中点
3. **中序遍历妙用**：方法三巧妙利用了 BST 中序遍历的性质
4. **链表特点**：不支持随机访问，需要顺序遍历
5. **Java 成员变量**：方法三中 `current` 是成员变量，负责跟踪当前链表节点

## 易错点

1. **快慢指针初始化**：要注意快慢指针的起始位置
2. **边界条件**：空链表、单节点链表要特殊处理
3. **链表断开**：方法四要注意断开链表时不要丢失节点
4. **中序遍历顺序**：方法三要严格按照 左-根-右 的顺序
5. **链表指针移动**：方法三中要确保每个节点恰好被访问一次
