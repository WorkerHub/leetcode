## 题目描述

给你一个整数数组 `arr` 和两个整数 `k` 和 `threshold`。

请你返回长度为 `k` 且平均值大于等于 `threshold` 的**子数组数目**。

**示例 1：**
```
输入：arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4
输出：3
解释：子数组 [2,5,5], [5,5,5] 和 [5,5,8] 的平均值分别为 4, 5 和 6。其他长度为 3 的子数组的平均值都不大于 4。
     所以返回 3。
```

**示例 2：**
```
输入：arr = [11,13,17,23,29,31,7,5,2,3], k = 3, threshold = 5
输出：6
```

**提示：**
- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^4`
- `1 <= k <= arr.length`
- `0 <= threshold <= 10^4`

## 解题思路

**滑动窗口：**

固定长度为 k 的窗口从左向右滑动，维护窗口内元素的和。

- 平均值 >= threshold 等价于 窗口和 >= threshold * k（避免浮点运算）
- 每次窗口右移一位：加入右端新元素，减去左端旧元素

**时间复杂度：** O(n)，每个元素只被加入和移出窗口各一次。

## Java 代码实现

### 方法一：滑动窗口（推荐）

```java
class Solution {
    public int numOfSubarrays(int[] arr, int k, int threshold) {
        int n = arr.length;
        int target = threshold * k; // 等价转换：避免除法（浮点数精度问题）
        
        // 初始化第一个窗口
        int windowSum = 0;
        for (int i = 0; i < k; i++) windowSum += arr[i];
        int count = windowSum >= target ? 1 : 0;
        
        // 滑动窗口：从第 2 个窗口开始
        for (int i = k; i < n; i++) {
            windowSum += arr[i];       // 加入右端新元素
            windowSum -= arr[i - k];   // 移出左端旧元素
            if (windowSum >= target) count++;
        }
        
        return count;
    }
}
```

### 方法二：前缀和

```java
class Solution {
    public int numOfSubarrays(int[] arr, int k, int threshold) {
        int n = arr.length;
        // 构建前缀和数组
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + arr[i];
        
        int target = threshold * k;
        int count = 0;
        
        // 枚举所有长度为 k 的子数组 [i, i+k-1]
        for (int i = 0; i <= n - k; i++) {
            if (prefix[i + k] - prefix[i] >= target) count++;
        }
        
        return count;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（滑动窗口） | O(n) | O(1) |
| 方法二（前缀和） | O(n) | O(n) |

## 图解示例

以 `arr = [2,2,2,2,5,5,5,8], k=3, threshold=4, target=12` 为例：

```
窗口滑动过程：
[2,2,2] -> sum=6  < 12，不计
  [2,2,5] -> sum=9  < 12，不计
    [2,5,5] -> sum=12 >= 12，计数! (+1)
      [5,5,5] -> sum=15 >= 12，计数! (+2)
        [5,5,8] -> sum=18 >= 12，计数! (+3)

结果: 3
```

## 关键点总结

1. 平均值 >= threshold 等价于 窗口和 >= threshold * k，避免浮点数运算
2. 滑动窗口维护固定大小 k 的窗口，每次移动只做一次加法和一次减法
3. 窗口和从第一个窗口开始初始化，后续滑动更新

## 易错点

1. 避免用 `sum / k >= threshold`（浮点数精度问题），改用乘法
2. 初始化第一个窗口时，累加前 k 个元素
3. 循环从 `k` 开始（窗口右移一位），到 `n-1`

## 学习建议

1. 固定长度滑动窗口是最基础的滑动窗口类型，先掌握这个再学可变长度
2. 核心操作：加入右端 + 移出左端，O(1) 更新窗口和
3. 用乘法转换代替除法，是处理"平均值"问题的常用技巧
4. 与前缀和方法相比，滑动窗口空间复杂度更优（O(1) vs O(n)）
