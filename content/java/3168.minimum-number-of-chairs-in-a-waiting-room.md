## 题目描述

给你字符串 `s`（由 'E' 进入和 'L' 离开组成），返回等候室需要准备的最少椅子数（即同时在室内人数的历史最大值）。

## 解题思路

模拟人数变化：遇到 'E' 加 1，遇到 'L' 减 1，记录过程中的最大值。

## Java 代码实现

```java
class Solution {
    public int minimumChairs(String s) {
        int cur = 0, ans = 0;
        for (char c : s.toCharArray()) {
            if (c == 'E') {
                cur++;
                ans = Math.max(ans, cur); // 更新最大同时在室人数
            } else {
                cur--;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 最少椅子数 = 同时在室内人数的最大值
2. 只在进入时更新最大值（离开不会需要更多椅子）
