## 题目描述

给定rowSum和colSum，构造非负整数矩阵使每行/列之和满足要求。

**示例：**
```
输入：rowSum = [3,8], colSum = [4,7]
输出：[[3,0],[1,7]]
```

## 解题思路

贪心：每个位置填入min(rowSum[i], colSum[j])，然后更新剩余行列和。

## Java 代码实现

```java
class Solution {
    public int[][] restoreMatrix(int[] rowSum, int[] colSum) {
        int m = rowSum.length, n = colSum.length;
        int[][] matrix = new int[m][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int val = Math.min(rowSum[i], colSum[j]);
                matrix[i][j] = val;
                rowSum[i] -= val;
                colSum[j] -= val;
            }
        }
        return matrix;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N)
- **空间复杂度**：O(M × N)

## 关键点总结

1. **贪心策略**：每个位置填min(rowSum[i], colSum[j])
2. **总和相等保证有解**：贪心一定能找到合法解
3. **无需回溯**：贪心直接构造
