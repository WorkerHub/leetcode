## 题目描述

给你 `n` 节点无向图，边权为正整数或 -1（待定），将所有 -1 边改为正整数使 `source` 到 `destination` 的最短路恰好等于 `target`，返回修改后的边列表（无解返回空数组）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private static final long INF = (long) 2e18;

    public int[][] modifiedGraphEdges(int n, int[][] edges, int source, int destination, int target) {
        // 第一次 Dijkstra：只用固定边，判断可行性
        long[] dist1 = dijkstra(n, edges, source, false);
        if (dist1[destination] < target) return new int[0][]; // 固定边已小于 target

        // 第二次：逐一启用 -1 边
        for (int i = 0; i < edges.length; i++) {
            if (edges[i][2] == -1) {
                edges[i][2] = 1; // 先设为最小权重
                long[] dist2 = dijkstra(n, edges, source, true);
                if (dist2[destination] <= target) {
                    // 调整这条边使最短路恰好等于 target
                    edges[i][2] += (int)(target - dist2[destination]);
                    // 后续 -1 边设为大值
                    for (int j = i + 1; j < edges.length; j++) {
                        if (edges[j][2] == -1) edges[j][2] = (int) 2e9;
                    }
                    return edges;
                }
            }
        }
        return new int[0][];
    }

    private long[] dijkstra(int n, int[][] edges, int src, boolean includeNegative) {
        long[] dist = new long[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, src});

        List<int[]>[] adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            int w = e[2];
            if (w == -1 && !includeNegative) continue;
            if (w > 0) {
                adj[e[0]].add(new int[]{e[1], w});
                adj[e[1]].add(new int[]{e[0], w});
            }
        }

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0]; int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (int[] next : adj[u]) {
                long nd = dist[u] + next[1];
                if (nd < dist[next[0]]) {
                    dist[next[0]] = nd;
                    pq.offer(new long[]{nd, next[0]});
                }
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * (n + m) log n)，m 为边数
- 空间复杂度：O(n + m)

## 关键点总结

1. 先只用固定边做 Dijkstra，若已小于 target 则无解
2. 逐一启用 -1 边（先设为 1），若最短路 <= target，调整该边权使恰好等于 target
3. 后续未处理的 -1 边设为大值
