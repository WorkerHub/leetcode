## 题目描述

给你公交出发时间数组 `buses`、乘客到站时间数组 `passengers` 和每辆车容量 `capacity`，你的到站时间不能与任何乘客相同，返回你能搭上公交的最晚到站时间。

## 解题思路

排序后双指针模拟上客过程。末班车有余量则候选时刻为末班车出发时间，否则为末班车最后上车乘客的到站时间。从候选时刻向前找第一个不与已有乘客冲突的时刻。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int latestTimeCatchTheBus(int[] buses, int[] passengers, int capacity) {
        Arrays.sort(buses);
        Arrays.sort(passengers);
        Set<Integer> taken = new HashSet<>();
        for (int p : passengers) taken.add(p);

        int j = 0, cap = 0;
        for (int bus : buses) {
            cap = capacity;
            while (j < passengers.length && passengers[j] <= bus && cap > 0) {
                cap--;
                j++;
            }
        }

        // 末班车有余量则从末班车时间开始，否则从最后上车乘客时间开始
        int t = (cap > 0) ? buses[buses.length - 1] : passengers[j - 1];
        while (taken.contains(t)) t--; // 向前找不冲突的时刻
        return t;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) log(n + m))，n 为公交数，m 为乘客数
- **空间复杂度**：O(m)

## 关键点总结

1. 排序后用双指针模拟，末班车循环结束后 `cap` 为末班车剩余容量。
2. 候选时刻：末班车有余量取 `buses[末]`，否则取 `passengers[j-1]`。
3. 从候选时刻向前找不在 `taken` 集合中的时刻。
