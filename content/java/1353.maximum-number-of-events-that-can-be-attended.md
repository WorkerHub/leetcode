## 题目描述

给你一个数组 `events`，其中 `events[i] = [startDay_i, endDay_i]`，表示活动 i 从 `startDay_i` 开始，到 `endDay_i` 结束（均为闭区间）。

你可以在满足 `startDay_i <= d <= endDay_i` 的任意一天 d 参加活动 i，**每天只能参加一个活动**。

请你返回你可以参加的 **最多** 活动数目。

**示例 1：**
```
输入：events = [[1,2],[2,3],[3,4]]
输出：3
解释：你可以参加所有三个活动
  - 第 1 天：参加活动 [1,2]
  - 第 2 天：参加活动 [2,3]
  - 第 3 天：参加活动 [3,4]
```

**示例 2：**
```
输入：events= [[1,2],[2,3],[3,4],[1,2]]
输出：4
```

**示例 3：**
```
输入：events = [[1,4],[4,4],[2,2],[3,4],[1,1]]
输出：4
```

**提示：**
- `1 <= events.length <= 10^5`
- `events[i].length == 2`
- `1 <= startDay_i <= endDay_i <= 10^5`

## 解题思路

**贪心策略：** 每天优先参加截止日期最早的活动。

**直觉：** 截止日期越早的活动越"紧迫"，如果不尽早参加就会错过，而截止日期晚的活动以后有更多机会参加。

**算法步骤：**
1. 将所有活动按开始日期排序。
2. 用一个最小堆（优先队列）存储当前"可参加"的活动的截止日期。
3. 从第 1 天到最后一天，逐天模拟：
   - 将今天开始的所有活动的截止日期加入堆。
   - 移除堆中已过期的活动（截止日期 < 今天）。
   - 如果堆非空，选截止日期最小（最紧迫）的活动参加，计数+1。

**关键优化：** 不需要逐天遍历到最大天数，可以跳转到下一个有活动开始的天或堆中最早截止日期的天。

## Java 代码实现

### 方法一：贪心 + 最小堆（推荐）

```java
import java.util.*;

class Solution {
    public int maxEvents(int[][] events) {
        // 按开始时间排序
        Arrays.sort(events, (a, b) -> a[0] - b[0]);
        
        int n = events.length;
        int idx = 0;          // events 的指针
        PriorityQueue<Integer> heap = new PriorityQueue<>(); // 最小堆，存截止日期
        int count = 0;        // 参加活动的总数
        
        // 确定最大天数
        int maxDay = 0;
        for (int[] e : events) maxDay = Math.max(maxDay, e[1]);
        
        int day = 1;
        while (day <= maxDay) {
            // 将今天（day）开始的所有活动加入堆
            while (idx < n && events[idx][0] <= day) {
                heap.offer(events[idx][1]); // 只存截止日期
                idx++;
            }
            
            // 移除已过期的活动（截止日期 < 今天）
            while (!heap.isEmpty() && heap.peek() < day) {
                heap.poll();
            }
            
            // 参加截止日期最早的活动
            if (!heap.isEmpty()) {
                heap.poll(); // 今天参加这个活动
                count++;
                day++;
            } else if (idx < n) {
                // 堆为空但还有未开始的活动，直接跳到下一个活动的开始日
                day = events[idx][0];
            } else {
                break; // 所有活动都处理完了
            }
        }
        
        return count;
    }
}
```

### 方法二：贪心 + 最小堆（简洁版，不跳天）

```java
import java.util.*;

class Solution {
    public int maxEvents(int[][] events) {
        Arrays.sort(events, (a, b) -> a[0] - b[0]);
        PriorityQueue<Integer> heap = new PriorityQueue<>(); // 最小堆
        int count = 0;
        int idx = 0;
        int n = events.length;
        
        for (int day = 1; day <= 100000; day++) {
            // 加入今天开始的活动
            while (idx < n && events[idx][0] == day) {
                heap.offer(events[idx][1]);
                idx++;
            }
            
            // 移除过期活动
            while (!heap.isEmpty() && heap.peek() < day) {
                heap.poll();
            }
            
            // 参加截止最早的活动
            if (!heap.isEmpty()) {
                heap.poll();
                count++;
            }
        }
        
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(D * log N) 或 O(N log N)，其中 D 是天数范围（最多 10^5），N 是活动数。排序 O(N log N)，每天堆操作 O(log N)，总计 O((D + N) log N)。使用跳天优化后，实际遍历的天数不超过 N，变为 O(N log N)。
- 空间复杂度：O(N)，堆的大小最多为 N。

## 图解示例

以 `events = [[1,4],[4,4],[2,2],[3,4],[1,1]]` 为例（排序后 `[[1,1],[1,4],[2,2],[3,4],[4,4]]`）：

```
day=1: 加入 [1,1],[1,4] -> 堆=[1,4]，参加截止=1 的活动，count=1，堆=[4]
day=2: 加入 [2,2] -> 堆=[2,4]，参加截止=2 的活动，count=2，堆=[4]
day=3: 加入 [3,4] -> 堆=[4,4]，参加截止=4 的活动，count=3，堆=[4]
day=4: 加入 [4,4] -> 堆=[4,4]，参加截止=4 的活动，count=4，堆=[4]
day=5: 无新活动，堆=[4]，堆顶4<5，清除，堆空，结束

最终 count=4
```

## 关键点总结

1. **贪心选择**：每天优先参加截止日期最早的活动，是此类问题的标准贪心策略。
2. **最小堆**：用最小堆高效获取截止日期最小的活动，堆操作 O(log N)。
3. **跳天优化**：堆为空时直接跳到下一个活动的开始天，避免遍历无用的天。
4. **过期清理**：每天需要清除堆中截止日期 < 当天的活动（已过期无法参加）。
5. **只存截止日期**：堆中只需存储截止日期，不需要记录活动编号。

## 易错点

- 在加入"今天开始"的活动时，条件应为 `events[i][0] <= day`（小于等于），而不是等于，因为开始天早于今天但还没加入堆的活动也需要处理（跳天情况下可能出现）。
- 过期清理的条件是 `heap.peek() < day`（严格小于），截止日期等于今天的活动今天还可以参加。
- 跳天时直接设 `day = events[i][0]`，不是 `day + 1`。
