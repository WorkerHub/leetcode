## 题目描述

给你长度为 4 的数组 `a` 和整数数组 `b`，从 `b` 中选下标 `i0<i1<i2<i3`，返回 `a[0]*b[i0]+a[1]*b[i1]+a[2]*b[i2]+a[3]*b[i3]` 的最大值。

## 解题思路

DP：`dp[k]` 表示已从 b 中选了 k 个的最大乘积和。遍历 b 的每个元素，从后往前更新 dp，避免同一元素被选多次。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long maxScore(int[] a, int[] b) {
        long[] dp = new long[5];
        long NEG_INF = Long.MIN_VALUE / 2;
        Arrays.fill(dp, NEG_INF);
        dp[0] = 0;

        for (int bj : b) {
            // 从后往前更新，避免同一 bj 被选多次
            for (int k = 3; k >= 0; k--) {
                if (dp[k] != NEG_INF) {
                    dp[k + 1] = Math.max(dp[k + 1], dp[k] + (long) a[k] * bj);
                }
            }
        }
        return dp[4];
    }
}
```

## 复杂度分析

- 时间复杂度：O(4n) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. dp[k] 表示已选 k 个 b 中元素的最大值，初始 dp[0]=0，其余为负无穷
2. 从后往前更新（k 从 3 到 0），防止同一 b[j] 被重复选入
3. 注意用 `long` 防止溢出（a[k] 和 bj 均可达 10^5，乘积需 long）
