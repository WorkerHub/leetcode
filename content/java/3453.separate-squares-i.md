## 题目描述

给你一个二维整数数组 `squares`，其中 `squares[i] = [xi, yi, li]` 表示左下角为 `(xi, yi)`、边长为 `li` 的正方形。找一条水平线 `y = h`，使上方和下方正方形总面积相等，返回最小的 `h`。

## 解题思路

二分水平线高度 h。对给定 h，计算下方总面积（分段线性且单调），找最小 h 使下方面积 >= 总面积/2。二分 100 次精度足够。

## Java 代码实现

```java
class Solution {
    public double separateSquares(int[][] squares) {
        // 计算总面积
        long totalArea = 0;
        for (int[] sq : squares) {
            totalArea += (long) sq[2] * sq[2];
        }
        double half = totalArea / 2.0;

        // 确定二分范围
        double lo = Double.MAX_VALUE, hi = Double.MIN_VALUE;
        for (int[] sq : squares) {
            lo = Math.min(lo, sq[1]);
            hi = Math.max(hi, sq[1] + sq[2]);
        }

        // 二分 100 次，精度满足要求
        for (int iter = 0; iter < 100; iter++) {
            double mid = (lo + hi) / 2.0;
            if (belowArea(squares, mid) >= half) {
                hi = mid;
            } else {
                lo = mid;
            }
        }
        return lo;
    }

    // 计算水平线 h 下方的总面积
    private double belowArea(int[][] squares, double h) {
        double area = 0;
        for (int[] sq : squares) {
            int y = sq[1], l = sq[2];
            double top = y + l;
            if (top <= h) {
                // 整个正方形在下方
                area += (long) l * l;
            } else if (y < h) {
                // 部分在下方
                area += l * (h - y);
            }
        }
        return area;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 100)，二分迭代次数固定
- 空间复杂度：O(1)

## 关键点总结

1. `below_area(h)` 关于 h 单调不减，可以二分
2. 找最小 h 使下方面积 >= 总面积/2
3. 二分 100 次精度可达 10^-9 级别
