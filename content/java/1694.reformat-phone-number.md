## 题目描述

电话号码字符串含数字、空格和破折号。删除非数字字符后，每 3 位一组分块，最后剩余 4 位则拆成 2+2，其余 2 或 3 位直接一块。用 `-` 连接返回。

## 解题思路

**模拟：** 先过滤非数字字符，再按规则分块：每次取 3 位直到剩余不超过 4 位，最后剩 4 位拆成 2+2，剩 2 或 3 位直接一块。

## Java 代码实现

```java
class Solution {
    public String reformatNumber(String number) {
        // 过滤非数字字符
        StringBuilder digits = new StringBuilder();
        for (char c : number.toCharArray()) {
            if (Character.isDigit(c)) digits.append(c);
        }

        String d = digits.toString();
        int n = d.length();
        List<String> blocks = new ArrayList<>();
        int i = 0;

        // 每次取 3 位，直到剩余不超过 4 位
        while (n - i > 4) {
            blocks.add(d.substring(i, i + 3));
            i += 3;
        }
        // 处理剩余部分
        int remaining = n - i;
        if (remaining == 4) {
            // 4 位拆成 2+2
            blocks.add(d.substring(i, i + 2));
            blocks.add(d.substring(i + 2, i + 4));
        } else {
            // 2 或 3 位直接一块
            blocks.add(d.substring(i));
        }

        return String.join("-", blocks);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 先清除非数字字符，再分块
2. 剩余 4 位必须拆成 2+2，不能作为一整块
3. `String.join("-", list)` 连接各块
