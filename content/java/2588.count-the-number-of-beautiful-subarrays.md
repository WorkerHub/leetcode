## 题目描述

给你整数数组 `nums`，若子数组每一个二进制位上 1 的个数都是偶数，则称为漂亮子数组，返回漂亮子数组的数目。

## 解题思路

每一位 1 的个数为偶数等价于子数组 XOR 为 0；维护前缀 XOR，用哈希表统计每个前缀 XOR 出现次数，相同前缀 XOR 的下标对就对应一个漂亮子数组。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long beautifulSubarrays(int[] nums) {
        Map<Integer, Integer> cnt = new HashMap<>();
        cnt.put(0, 1); // 空前缀
        int prefix = 0;
        long ans = 0;
        for (int x : nums) {
            prefix ^= x;
            ans += cnt.getOrDefault(prefix, 0);
            cnt.merge(prefix, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 子数组 XOR = 0 等价于两端前缀 XOR 相等
2. 初始化 `cnt[0] = 1` 表示空前缀
3. 先统计再更新计数，避免重复计数
