## 题目描述

给你整数 `n`，表示将圆分成 `n` 个相等扇形所需的最少切割次数。

## 解题思路

n=1 无需切割；n 为偶数时每条直径可切两份，需 n/2 刀；n 为奇数时每刀只切一份，需 n 刀。

## Java 代码实现

```java
class Solution {
    public int numberOfCuts(int n) {
        if (n == 1) return 0;
        return n % 2 == 0 ? n / 2 : n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. n=1 特殊情况，返回 0
2. 偶数：对径直线一刀切两份，共 n/2 刀
3. 奇数：每刀只切一份，共 n 刀
