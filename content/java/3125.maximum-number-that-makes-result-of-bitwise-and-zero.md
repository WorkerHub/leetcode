## 题目描述

给定整数n，返回满足 n AND x == 0 的最大非负整数x。

## 解题思路

n AND x == 0 要求x的每一位只能在n对应位为0处为1。最大x就是n在最高位范围内的按位取反：mask = (1<<位数)-1，x = mask XOR n。

## Java 代码实现

```java
class Solution {
    public long maxNumber(int n) {
        if (n == 0) return 0;
        // 找n的最高位数
        int bits = Integer.SIZE - Integer.numberOfLeadingZeros(n);
        long mask = (1L << bits) - 1;
        return mask ^ n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **n AND x == 0**：x和n不能同时在某一位为1
2. **最大x = mask XOR n**：将n的0位全部置1
3. **mask = (1<<bit_length)-1**：与n等位数的全1掩码
