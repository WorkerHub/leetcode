## 题目描述

n×n 棋盘上骑士从 (row, column) 开始随机走 k 步（8个方向等概率），返回留在棋盘上的概率。

**示例：**
```
输入：n = 3, k = 2, row = 0, column = 0
输出：0.06250
```

## 解题思路

动态规划：dp[i][j] 表示走完当前步后在 (i,j) 的概率。每步从上一步的每个位置向8个方向转移概率/8。

## Java 代码实现

```java
class Solution {
    public double knightProbability(int n, int k, int row, int column) {
        int[][] dirs = {{-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}};

        double[][] dp = new double[n][n];
        dp[row][column] = 1.0;

        for (int step = 0; step < k; step++) {
            double[][] newDp = new double[n][n];
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (dp[i][j] > 0) {
                        for (int[] dir : dirs) {
                            int ni = i + dir[0], nj = j + dir[1];
                            if (ni >= 0 && ni < n && nj >= 0 && nj < n) {
                                newDp[ni][nj] += dp[i][j] / 8.0;
                            }
                        }
                    }
                }
            }
            dp = newDp;
        }

        double prob = 0;
        for (double[] r : dp) {
            for (double val : r) {
                prob += val;
            }
        }
        return prob;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(k × n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. **概率 DP**：每步概率均分为 8 份
2. **滚动数组**：只需保存上一步的状态
3. **累加所有位置概率**：最终求和即为留在棋盘的概率
