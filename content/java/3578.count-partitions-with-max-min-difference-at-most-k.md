## 题目描述

给定整数数组 `nums` 和整数 `k`，将数组分成若干连续子数组，每个子数组最大值和最小值之差不超过 `k`，求满足条件的分区数量，对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPartitions(int[] nums, int k) {
        int MOD = 1_000_000_007;
        int n = nums.length;
        long[] dp = new long[n + 1];
        long[] prefix = new long[n + 2];
        dp[0] = 1;
        prefix[1] = 1;

        // 单调递减队列（追踪最大值）和单调递增队列（追踪最小值）
        Deque<Integer> maxDq = new ArrayDeque<>();
        Deque<Integer> minDq = new ArrayDeque<>();
        int left = 0;

        for (int right = 0; right < n; right++) {
            while (!maxDq.isEmpty() && nums[maxDq.peekLast()] <= nums[right]) maxDq.pollLast();
            maxDq.offerLast(right);
            while (!minDq.isEmpty() && nums[minDq.peekLast()] >= nums[right]) minDq.pollLast();
            minDq.offerLast(right);

            // 维护 left：确保 [left, right] 的 max - min <= k
            while (nums[maxDq.peekFirst()] - nums[minDq.peekFirst()] > k) {
                left++;
                if (maxDq.peekFirst() < left) maxDq.pollFirst();
                if (minDq.peekFirst() < left) minDq.pollFirst();
            }

            // dp[right+1] = sum(dp[left..right]) = prefix[right+1] - prefix[left]
            dp[right + 1] = (prefix[right + 1] - prefix[left] + MOD) % MOD;
            prefix[right + 2] = (prefix[right + 1] + dp[right + 1]) % MOD;
        }
        return (int) dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，单调队列均摊 O(1)
- 空间复杂度：O(n)，DP 数组和前缀和

## 关键点总结

1. 单调队列维护滑动窗口的最大值和最小值
2. 双指针 `left` 确保窗口合法（max - min <= k）
3. 前缀和快速计算 dp 区间求和，取模时注意负数处理
