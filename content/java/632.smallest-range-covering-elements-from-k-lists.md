## 题目描述

有 `k` 个升序列表，找到最小区间使每个列表至少有一个数包含在其中。

**示例：**
```
输入：nums = [[4,10,15,24,26],[0,9,12,20],[5,18,22,30]]
输出：[20,24]
```

## 解题思路

最小堆 + 贪心：维护每个列表的当前元素指针，堆顶为最小值，变量追踪最大值，每次弹出最小值并推入其列表的下一个元素。

## Java 代码实现

```java
class Solution {
    public int[] smallestRange(List<List<Integer>> nums) {
        // 最小堆：[值, 列表索引, 元素索引]
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        int maxVal = Integer.MIN_VALUE;

        // 初始化：每个列表的第一个元素入堆
        for (int i = 0; i < nums.size(); i++) {
            int val = nums.get(i).get(0);
            minHeap.offer(new int[]{val, i, 0});
            maxVal = Math.max(maxVal, val);
        }

        int[] result = {minHeap.peek()[0], maxVal};

        while (true) {
            int[] curr = minHeap.poll();
            int minVal = curr[0], listIdx = curr[1], elemIdx = curr[2];

            // 更新最小区间
            if (maxVal - minVal < result[1] - result[0]) {
                result[0] = minVal;
                result[1] = maxVal;
            }

            // 推入下一个元素
            elemIdx++;
            if (elemIdx >= nums.get(listIdx).size()) break;

            int nextVal = nums.get(listIdx).get(elemIdx);
            minHeap.offer(new int[]{nextVal, listIdx, elemIdx});
            maxVal = Math.max(maxVal, nextVal);
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log k)，n 为总元素数，k 为列表数
- **空间复杂度**：O(k)

## 关键点总结

1. **堆维护最小值**：堆顶是窗口左端点
2. **变量维护最大值**：右端点
3. **移动最小值**：每次弹出最小值推入其下一个元素
4. **终止条件**：某列表用完
