## 题目描述

给定二叉树根节点，返回层内元素之和最大的最小层号（根节点为第 1 层）。

**示例：**
```
输入：root = [1,7,0,7,-8,null,null]
输出：2（第2层和为7，第3层和为-1）
```

## 解题思路

BFS 层序遍历，逐层计算和，记录最大和对应的最小层号。

## Java 代码实现

```java
class Solution {
    public int maxLevelSum(TreeNode root) {
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int maxSum = Integer.MIN_VALUE;
        int maxLevel = 1, level = 0;

        while (!queue.isEmpty()) {
            level++;
            int size = queue.size();
            int levelSum = 0;
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                levelSum += node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            if (levelSum > maxSum) {
                maxSum = levelSum;
                maxLevel = level;
            }
        }
        return maxLevel;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次
- **空间复杂度**：O(w)，w 为树的最大宽度

## 关键点总结

1. **BFS 层序遍历**：天然按层处理
2. **负无穷初始化**：节点值可能为负
3. **严格大于**：`>` 而非 `>=`，保证返回最小层号
4. **层号从 1 开始**
