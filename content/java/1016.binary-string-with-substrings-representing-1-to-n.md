## 题目描述

给定一个二进制字符串 `s` 和一个正整数 `n`，如果对于 `[1, n]` 范围内的每个整数，其二进制表示都是 `s` 的子串，就返回 `true`，否则返回 `false`。

子串是字符串中连续的字符序列。

**示例 1：**
```
输入：s = "0110", n = 3
输出：true
解释：
1 的二进制表示是 "1"，在 s 中
2 的二进制表示是 "10"，在 s 中
3 的二进制表示是 "11"，在 s 中
```

**示例 2：**
```
输入：s = "0110", n = 4
输出：false
解释：
4 的二进制表示是 "100"，不在 s 中
```

**提示：**
- `1 <= s.length <= 1000`
- `s[i]` 不是 `'0'` 就是 `'1'`
- `1 <= n <= 10^9`

## 解题思路

这道题的核心是判断字符串 `s` 是否包含从 1 到 n 的所有整数的二进制表示作为子串。

**关键观察：**

1. **从大到小检查更高效**：如果一个较大的数的二进制表示不在 `s` 中，那么可以立即返回 `false`。从 n 开始向下检查，能更早发现不满足条件的情况。

2. **数学剪枝**：当 n 足够大时（比如 n > 2 * len(s)），肯定无法满足条件。

3. **高位数字优先**：位数多的数字（大数）的二进制表示更难被包含，如果所有高位数都被包含了，低位数更容易被包含。

## Java 代码实现

### 方法一：暴力检查（基础解法）

```java
class Solution {
    public boolean queryString(String s, int n) {
        // 遍历 1 到 n 的所有整数
        for (int i = 1; i <= n; i++) {
            // 将整数转换为二进制字符串
            String binary = Integer.toBinaryString(i);
            // 检查是否是 s 的子串
            if (!s.contains(binary)) return false;
        }
        return true;
    }
}
```

### 方法二：从大到小检查（推荐）

```java
class Solution {
    public boolean queryString(String s, int n) {
        // 数学剪枝：如果 n 太大，直接返回 false
        if (n > 2 * s.length()) return false;

        // 从 n 开始向下检查到 1
        for (int i = n; i >= 1; i--) {
            String binary = Integer.toBinaryString(i);
            if (!s.contains(binary)) return false;
        }
        return true;
    }
}
```

### 方法三：哈希集合法

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean queryString(String s, int n) {
        // 早期剪枝
        if (n >= 2 * s.length()) return false;

        // 用集合存储所有有效的二进制子串对应的数值
        Set<Integer> binaryNums = new HashSet<>();

        // 遍历所有子串
        for (int i = 0; i < s.length(); i++) {
            // 二进制数不能以 0 开头
            if (s.charAt(i) == '0') continue;

            // 枚举以 i 开头的所有子串（限制最多 31 位）
            for (int j = i + 1; j <= Math.min(i + 31, s.length()); j++) {
                String substr = s.substring(i, j);
                int num = Integer.parseInt(substr, 2); // 将二进制字符串转换为整数

                if (num <= n) {
                    binaryNums.add(num);
                } else {
                    break; // 如果已经超过 n，更长子串也会超过
                }
            }
        }

        // 检查是否包含 1 到 n 的所有数
        return binaryNums.size() == n;
    }
}
```

## 复杂度分析

**方法一和方法二（暴力检查）：**
- 时间复杂度：O(n × len(s))，需要检查 n 个数，每次检查是 O(len(s))
- 空间复杂度：O(log n)，存储二进制字符串的空间

**方法三（哈希集合法）：**
- 时间复杂度：O(len(s)^2)，遍历所有子串
- 空间复杂度：O(len(s))，哈希集合存储子串对应的数值

当 n 较小时，方法一、二更快；当 n 很大时，方法三更优。

## 关键点总结

1. **二进制转换**：Java 中使用 `Integer.toBinaryString(n)` 将整数转换为二进制字符串
2. **子串判断**：Java 中使用 `s.contains(sub)` 判断子串
3. **优化策略**：从大到小检查，因为大数的二进制表示更难被包含
4. **数学剪枝**：当 n 超过一定范围时（如 n > 2 × len(s)），可以直接返回 false
5. **位数限制**：由于 n <= 10^9 < 2^30，二进制字符串最多 30 位

## 易错点

1. **二进制转换**：Java 中用 `Integer.toBinaryString()` 而不是 Python 的 `bin()[2:]`
2. **边界条件**：n = 1 时，只需检查字符串是否包含 "1"
3. **二进制数不以 0 开头**：在提取子串时，需要排除以 '0' 开头的子串
4. **数值范围**：n 最大可达 10^9，需要考虑性能优化
5. **Integer.parseInt 溢出**：子串过长时可能溢出，需要限制长度
