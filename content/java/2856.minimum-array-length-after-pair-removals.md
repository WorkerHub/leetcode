## 题目描述

给你一个非递减整数数组 nums，每次可删除满足 `nums[i] < nums[j]`（i < j）的一对元素，返回最多操作后数组的最短长度。

## 解题思路

双指针：数组前半和后半配对，左指针从下标 0 起，右指针从 n/2 起，当 `nums[l] < nums[r]` 时配对并各进一步，否则右指针右移，最终剩余 = `n - 2 * pairs`。

## Java 代码实现

```java
class Solution {
    public int minLengthAfterRemovals(List<Integer> nums) {
        int n = nums.size();
        int l = 0, r = n / 2, pairs = 0;

        // 前半和后半进行贪心配对
        while (l < n / 2 && r < n) {
            if (nums.get(l) < nums.get(r)) {
                pairs++;
                l++;
                r++;
            } else {
                // 需要跳过后半中与前半相同的元素
                r++;
            }
        }
        return n - 2 * pairs;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 配对条件是严格小于，相同元素不能配对
2. 前半和后半双指针贪心：后半找到比前半大的才配对
3. 结果 = `n - 2 * pairs`（每次配对删两个元素）
