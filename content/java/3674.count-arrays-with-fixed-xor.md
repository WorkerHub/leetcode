## 题目描述

给你三个整数 `n`、`k` 和 `x`，返回满足以下条件的长度为 `n` 的数组数量：每个元素在 0 到 k 之间，且所有元素的 XOR 等于 x。结果对 `10^9 + 7` 取模。

## 解题思路

按位独立处理：对第 b 位，若 k 的该位为 0，所有元素该位只能为 0；若 k 的该位为 1，每个元素该位可自由选 0 或 1，n 个元素中 XOR 为 xb 的方案数为 `2^(n-1)`（奇偶各半）。总方案数为各位方案数之积。

## Java 代码实现

```java
class Solution {
    public int countArrays(int n, int k, int x) {
        final int MOD = 1_000_000_007;
        // n个0/1中有奇数/偶数个1各有2^(n-1)种方案
        long half = pow(2, n - 1, MOD);
        long ans = 1;

        for (int bit = 0; bit < 30; bit++) {
            int kb = (k >> bit) & 1; // k在该位的值
            int xb = (x >> bit) & 1; // x在该位的值
            if (kb == 0) {
                // 所有元素该位只能为0
                if (xb != 0) return 0;
                // 方案数为1，不影响ans
            } else {
                // 每个元素该位可选0或1，XOR为xb的方案数为2^(n-1)
                ans = ans * half % MOD;
            }
        }
        return (int) ans;
    }

    private long pow(long base, long exp, long mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(30 + log n)
- 空间复杂度：O(1)

## 关键点总结

1. 每位独立处理，总方案数为各位方案数之积
2. 若 k 的第 b 位为 0，所有元素该位只能是 0
3. 奇数个 1 和偶数个 1 各有 `2^(n-1)` 种方案
