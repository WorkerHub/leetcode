## 题目描述

重新排列字符串中的空格，使每对相邻单词之间空格数相等且最大化，多余空格放末尾。

**示例：**
```
输入：text = "  this is  a sentence "
输出："this   is   a   sentence"
```

## 解题思路

统计总空格数和单词，计算间隔空格数和余数。

## Java 代码实现

```java
class Solution {
    public String reorderSpaces(String text) {
        int spaces = 0;
        for (char c : text.toCharArray()) {
            if (c == ' ') spaces++;
        }
        
        String[] words = text.trim().split("\\s+");
        int n = words.length;
        
        if (n == 1) {
            return words[0] + " ".repeat(spaces);
        }
        
        int gap = spaces / (n - 1);
        int remainder = spaces % (n - 1);
        
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.append(words[i]);
            if (i < n - 1) sb.append(" ".repeat(gap));
        }
        sb.append(" ".repeat(remainder));
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **统计空格数**：遍历原字符串
2. **只有一个单词**：所有空格放末尾
3. **间隔空格** = 总空格 / (单词数-1)，余数放末尾
