## 题目描述

给你 `n` 个城市、双向道路数组 `roads` 和苹果价格数组 `appleCost`，从城市 `i` 出发购买苹果后须返回原城市，途中每段路的费用乘以 `(k+1)`，返回每个城市出发的最小总费用。

## 解题思路

多源 Dijkstra：将边权设为 `cost * (k+1)`（含来回），以每个城市 `i` 的苹果价格 `appleCost[i]` 作为初始距离，一次 Dijkstra 即可得到所有城市的答案。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long[] minCost(int n, int[][] roads, int[] appleCost, int k) {
        // 建图，边权 = cost * (k+1)（来回费用）
        List<long[]>[] adj = new List[n + 1];
        for (int i = 1; i <= n; i++) adj[i] = new ArrayList<>();
        for (int[] road : roads) {
            long w = (long) road[2] * (k + 1);
            adj[road[0]].add(new long[]{road[1], w});
            adj[road[1]].add(new long[]{road[0], w});
        }

        // 多源 Dijkstra，初始距离为各城市苹果价格
        long[] dist = new long[n + 1];
        Arrays.fill(dist, Long.MAX_VALUE);
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        for (int i = 1; i <= n; i++) {
            dist[i] = appleCost[i - 1];
            pq.offer(new long[]{dist[i], i});
        }

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d > dist[u]) continue;
            for (long[] e : adj[u]) {
                int v = (int) e[0];
                long nd = dist[u] + e[1];
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{nd, v});
                }
            }
        }

        // 返回城市 1..n 的结果
        long[] ans = new long[n];
        for (int i = 1; i <= n; i++) ans[i - 1] = dist[i];
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) log n)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 边权设为 `cost * (k+1)` 将来回费用合并到单次建图中
2. 多源 Dijkstra 将所有城市同时作为源点，一次遍历得到所有答案
3. 使用 `long` 防止费用乘法溢出
