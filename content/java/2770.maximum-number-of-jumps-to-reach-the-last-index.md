## 题目描述

给你整数数组 `nums` 和整数 `target`，从下标 0 出发，可以从 `i` 跳到 `j`（`i < j`）且 `|nums[i] - nums[j]| <= target`，返回到达下标 `n-1` 的最大跳跃次数（不可达返回 -1）。

## Java 代码实现

```java
class Solution {
    public int maximumJumps(int[] nums, int target) {
        int n = nums.length;
        int[] dp = new int[n];
        java.util.Arrays.fill(dp, -1);
        dp[0] = 0;
        for (int j = 1; j < n; j++) {
            for (int i = 0; i < j; i++) {
                // dp[i] >= 0 表示 i 可达
                if (dp[i] >= 0 && Math.abs(nums[i] - nums[j]) <= target) {
                    dp[j] = Math.max(dp[j], dp[i] + 1);
                }
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)
- 空间复杂度：O(n)

## 关键点总结

1. dp[i] = -1 表示不可达
2. 最大跳跃次数，所以取 max 而非 min
3. 转移条件：差值 <= target
