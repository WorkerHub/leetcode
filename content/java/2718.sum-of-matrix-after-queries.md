## 题目描述

给你整数 `n` 和查询数组 `queries`，每个查询将某行或某列所有元素设置为指定值，返回所有查询执行完后矩阵的元素之和。

## Java 代码实现

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public long matrixSumQueries(int n, int[][] queries) {
        Set<Integer> seenRows = new HashSet<>();
        Set<Integer> seenCols = new HashSet<>();
        long ans = 0;
        // 逆序处理，后面的查询会覆盖前面的结果
        for (int i = queries.length - 1; i >= 0; i--) {
            int type = queries[i][0], index = queries[i][1], val = queries[i][2];
            if (type == 0) { // 行操作
                if (!seenRows.contains(index)) {
                    // 该行中未被列覆盖的格子数 = n - 已覆盖列数
                    ans += (long) val * (n - seenCols.size());
                    seenRows.add(index);
                }
            } else { // 列操作
                if (!seenCols.contains(index)) {
                    // 该列中未被行覆盖的格子数 = n - 已覆盖行数
                    ans += (long) val * (n - seenRows.size());
                    seenCols.add(index);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(q)，q 为查询数量
- 空间复杂度：O(n)，行列集合大小

## 关键点总结

1. 后续查询会覆盖前面的结果，逆序处理确保每行/列只计算一次
2. 行 `r` 的贡献：`val * (n - 已覆盖列数)`，因为列操作会覆盖行中的某些格子
3. 同理，列 `c` 的贡献：`val * (n - 已覆盖行数)`
