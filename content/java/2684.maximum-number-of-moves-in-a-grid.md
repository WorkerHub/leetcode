## 题目描述

给你矩阵 `grid`，从第 0 列任意行出发，每步可向右上、右、右下移动到值**严格更大**的格子，返回最大移动次数。

## Java 代码实现

```java
class Solution {
    public int maxMoves(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        // 初始化为 -1 表示不可达，第 0 列可达
        for (int[] row : dp) java.util.Arrays.fill(row, -1);
        for (int i = 0; i < m; i++) dp[i][0] = 0;

        int ans = 0;
        for (int j = 1; j < n; j++) {
            for (int i = 0; i < m; i++) {
                // 三个可能的来源：右上、右、右下
                for (int di = -1; di <= 1; di++) {
                    int pi = i + di;
                    if (pi >= 0 && pi < m && dp[pi][j - 1] >= 0
                            && grid[i][j] > grid[pi][j - 1]) {
                        dp[i][j] = Math.max(dp[i][j], dp[pi][j - 1] + 1);
                    }
                }
                ans = Math.max(ans, dp[i][j]);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)
- 空间复杂度：O(m * n)

## 关键点总结

1. DP 按列从左到右计算，每格从三个前驱取最大步数
2. -1 表示不可达，第 0 列全部初始化为 0
