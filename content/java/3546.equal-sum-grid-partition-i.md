## 题目描述

给定一个 `m x n` 的整数矩阵 `grid`，将其沿某条水平线或垂直线分割成两个非空部分，使得两部分的元素之和相等。判断是否存在这样的分割方式。

## 解题思路

计算前缀行和和前缀列和，枚举所有可能的水平切割和垂直切割位置。若某切割处的前缀和等于总和的一半，则合法。

## Java 代码实现

```java
class Solution {
    public boolean canPartitionGrid(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        long total = 0;
        // 计算总和
        for (int[] row : grid)
            for (int val : row)
                total += val;

        // 检查水平切割
        long rowPrefix = 0;
        for (int i = 0; i < m - 1; i++) {
            for (int val : grid[i]) rowPrefix += val;
            if (rowPrefix * 2 == total) return true;
        }

        // 检查垂直切割
        long colPrefix = 0;
        for (int j = 0; j < n - 1; j++) {
            for (int r = 0; r < m; r++) colPrefix += grid[r][j];
            if (colPrefix * 2 == total) return true;
        }

        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n)，计算前缀和
- 空间复杂度：O(1)

## 关键点总结

1. 枚举所有 `m-1` 个水平切割位置和 `n-1` 个垂直切割位置
2. 若某切割处的前缀和等于总和的一半，则合法
3. 使用乘 2 代替除以 2，避免浮点数问题
