## 题目描述

给你整数数组 `nums`，对于 `i < j`，若 `j - i != nums[j] - nums[i]`，则称 `(i, j)` 是一个**坏对**。返回所有坏对的数量。

## 解题思路

好对 `(i, j)` 等价于 `nums[i] - i == nums[j] - j`。用哈希表统计每个差值 `nums[i] - i` 的出现次数，好对数为各组组合数之和，坏对数 = 总对数 - 好对数。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countBadPairs(int[] nums) {
        int n = nums.length;
        long totalPairs = (long) n * (n - 1) / 2;

        // 统计每个 key = nums[i] - i 的出现次数
        Map<Integer, Long> freq = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int key = nums[i] - i;
            freq.merge(key, 1L, Long::sum);
        }

        // 好对数 = sum(C(cnt, 2)) for each key
        long goodPairs = 0;
        for (long cnt : freq.values()) {
            goodPairs += cnt * (cnt - 1) / 2;
        }

        return totalPairs - goodPairs;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，哈希表操作
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 好对 `(i, j)` 等价于 `nums[i] - i == nums[j] - j`，即差值相同。
2. 坏对数 = 总对数 - 好对数，转化为统计好对数。
3. 用哈希表统计每个差值的频率，好对数用组合数 C(cnt, 2) 计算。
