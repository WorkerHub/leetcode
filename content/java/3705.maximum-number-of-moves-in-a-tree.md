## 题目描述

给定 n 个节点的无向树，每个节点有值 `vals[i]`。从任意节点出发，每次只能移动到值更大的节点。求能进行的最大移动次数。

## 解题思路

换根 DP：第一次 DFS 计算每个节点向子树方向的最长严格递增路径 `down[v]`；第二次 DFS 计算从 v 向父节点方向的最长路径 `up[v]`。答案为 `max(down[v] + up[v])`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    List<Integer>[] graph;
    int[] vals, down, up;
    int ans = 0;

    public int maxMoves(int n, int[][] edges, int[] vals) {
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) { graph[e[0]].add(e[1]); graph[e[1]].add(e[0]); }
        this.vals = vals;
        down = new int[n]; up = new int[n];
        dfs1(0, -1);
        dfs2(0, -1);
        return ans;
    }

    private void dfs1(int v, int parent) {
        for (int u : graph[v]) {
            if (u == parent) continue;
            dfs1(u, v);
            if (vals[u] > vals[v]) down[v] = Math.max(down[v], down[u] + 1);
        }
        ans = Math.max(ans, down[v]);
    }

    private void dfs2(int v, int parent) {
        for (int u : graph[v]) {
            if (u == parent) continue;
            // up[u]: 从u向v走，再从v向其他方向延伸
            if (vals[v] > vals[u]) {
                // 找v除u外的最优子树
                int bestOther = 0;
                for (int w : graph[v]) {
                    if (w == parent || w == u) continue;
                    if (vals[w] > vals[v]) bestOther = Math.max(bestOther, down[w] + 1);
                }
                up[u] = 1 + Math.max(up[v], bestOther);
            }
            ans = Math.max(ans, down[u] + up[u]);
            dfs2(u, v);
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)（最坏情况下内层循环），可优化为 O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 换根 DP：两次 DFS 分别计算向下和向上的最长路径
2. 严格递增保证无环，DFS 不需要 visited
3. up[u] 的计算需排除 u 自身对 v 的贡献
