## 题目描述

给定长度为 `n` 的整数数组 `nums`（是 1 到 n 的排列）。求有多少个不同的值可以表示为 `nums[i] XOR nums[j] XOR nums[k]`（0 <= i < j < k < n）。

## 解题思路

数学规律：nums 是 1 到 n 的完整排列，三元组 XOR 可达值等于 `2^bits`，其中 `bits = n 的二进制位数`。特殊处理 n=3：只有一个三元组 `1^2^3=0`，答案为 1。

## Java 代码实现

```java
class Solution {
    public int uniqueXorTriplets(int[] nums) {
        int n = nums.length;
        if (n == 3) return 1; // 唯一三元组 1^2^3=0
        // 1~n 完整排列，三元组 XOR 可覆盖 0 到 2^bits-1 所有值
        int bits = 32 - Integer.numberOfLeadingZeros(n);
        return 1 << bits;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 利用 1 XOR 2 XOR 3 = 0 可构造任意目标 XOR 值
2. 完整排列使 XOR 可达范围为 `[0, 2^bits)`
3. n=3 是特殊情况，只有一个三元组
