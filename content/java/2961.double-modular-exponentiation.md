## 题目描述

给你二维数组 `variables`，其中 `variables[i] = [a, b, c, m]`，若 `((a^b % 10)^c) % m == target` 则为好下标，返回所有好下标。

## 解题思路

按公式直接计算：先用快速幂计算 `a^b % 10`，再以结果为底数计算 `base^c % m`，与 target 比较。

## Java 代码实现

```java
class Solution {
    public List<Integer> getGoodIndices(int[][] variables, int target) {
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < variables.length; i++) {
            int a = variables[i][0], b = variables[i][1];
            int c = variables[i][2], m = variables[i][3];
            // 第一步：a^b % 10
            long step1 = powMod(a, b, 10);
            // 第二步：step1^c % m
            long step2 = powMod(step1, c, m);
            if (step2 == target) result.add(i);
        }
        return result;
    }

    private long powMod(long base, int exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × log(max(b, c)))
- **空间复杂度**：O(1)

## 关键点总结

1. 两次快速幂：第一次对 10 取模，第二次对 m 取模
2. 第一步结果是 [0,9] 之间的值，作为第二步的底数
3. b 和 c 最大 10^5，必须用快速幂
