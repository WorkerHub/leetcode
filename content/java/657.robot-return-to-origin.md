## 题目描述

在二维平面上，有一个机器人从原点 `(0, 0)` 开始。给出它的移动顺序，判断这个机器人在完成移动后是否在 `(0, 0)` 处结束。

移动顺序由字符串 `moves` 表示。字符 `move[i]` 表示其第 `i` 次移动。机器人的有效动作有 `R`（右），`L`（左），`U`（上）和 `D`（下）。

如果机器人在完成所有动作后返回原点，则返回 `true`。否则，返回 `false`。

**注意：**机器人"面朝"的方向无关紧要。`R` 将始终使机器人向右移动一次，`L` 将始终向左移动等。此外，假设每次移动机器人的移动幅度相同。

**示例 1:**

```
输入: moves = "UD"
输出: true
解释：机器人向上移动一次，然后向下移动一次。所有动作都具有相同的幅度，因此它最终回到它开始的原点。因此，返回 true。
```

**示例 2:**

```
输入: moves = "LL"
输出: false
解释：机器人向左移动两次。它最终位于原点的左侧，距原点有两次"移动"的距离。返回 false。
```

**提示:**
- `1 <= moves.length <= 2 * 10^4`
- `moves` 只包含字符 `'U'`, `'D'`, `'L'` 和 `'R'`

## 解题思路

这是一道非常简单的模拟题。机器人能回到原点的充要条件是：

**核心观察：**

1. **水平方向**：向左移动的次数 = 向右移动的次数
2. **垂直方向**：向上移动的次数 = 向下移动的次数

### 解法思路

**方法一：计数法**
- 统计 `L` 和 `R` 的数量是否相等
- 统计 `U` 和 `D` 的数量是否相等

**方法二：坐标模拟**
- 维护 `(x, y)` 坐标
- 根据移动方向更新坐标
- 最后判断是否回到 `(0, 0)`

## Java 代码实现

### 方法一：计数法（最简洁）

```java
class Solution {
    public boolean judgeCircle(String moves) {
        // 统计四个方向的移动次数
        int left = 0, right = 0, up = 0, down = 0;
        for (char c : moves.toCharArray()) {
            if (c == 'L') left++;
            else if (c == 'R') right++;
            else if (c == 'U') up++;
            else if (c == 'D') down++;
        }
        return left == right && up == down;
    }
}
```

### 方法二：坐标模拟

```java
class Solution {
    public boolean judgeCircle(String moves) {
        // 模拟机器人移动，维护坐标
        int x = 0, y = 0;

        for (char move : moves.toCharArray()) {
            if (move == 'U') y++;
            else if (move == 'D') y--;
            else if (move == 'L') x--;
            else if (move == 'R') x++;
        }

        return x == 0 && y == 0;
    }
}
```

### 方法三：方向映射

```java
import java.util.*;

class Solution {
    public boolean judgeCircle(String moves) {
        // 使用 Map 存储方向映射
        Map<Character, int[]> directions = new HashMap<>();
        directions.put('U', new int[]{0, 1});
        directions.put('D', new int[]{0, -1});
        directions.put('L', new int[]{-1, 0});
        directions.put('R', new int[]{1, 0});

        int x = 0, y = 0;

        for (char move : moves.toCharArray()) {
            int[] dir = directions.get(move);
            x += dir[0];
            y += dir[1];
        }

        return x == 0 && y == 0;
    }
}
```

### 方法四：字符统计

```java
class Solution {
    public boolean judgeCircle(String moves) {
        // 统计各方向出现次数
        int[] count = new int[128]; // ASCII 字符计数
        for (char c : moves.toCharArray()) {
            count[c]++;
        }
        return count['L'] == count['R'] && count['U'] == count['D'];
    }
}
```

## 复杂度分析

### 方法一：计数法
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，只使用常量空间

### 方法二：坐标模拟
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，只使用两个变量

### 方法三：方向映射
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，Map 大小固定

### 方法四：字符统计
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(1)，数组大小固定

## 图解示例

示例 1：`moves = "UD"`

```
起点：(0, 0)

移动 'U'：(0, 0) -> (0, 1)
         ↑
        (0,1)
         |
        (0,0)

移动 'D'：(0, 1) -> (0, 0)
        (0,1)
         |
         ↓
        (0,0) ✓ 回到原点

结果：true
```

示例 2：`moves = "LL"`

```
起点：(0, 0)

移动 'L'：(0, 0) -> (-1, 0)
(-1,0) <- (0,0)

移动 'L'：(-1, 0) -> (-2, 0)
(-2,0) <- (-1,0) <- (0,0)

结果：false（在 (-2, 0)，未回到原点）
```

**计数法分析：**

```
moves = "UD"
L: 0, R: 0 -> L == R ✓
U: 1, D: 1 -> U == D ✓
结果：true

moves = "LL"
L: 2, R: 0 -> L != R ✗
结果：false
```

## 关键点总结

1. **问题本质**：判断水平和垂直方向的移动是否平衡
2. **等价条件**：`count(L) == count(R)` 且 `count(U) == count(D)`
3. **多种实现**：计数、坐标模拟、方向映射都可以
4. **代码简洁性**：计数法简洁高效
5. **无需考虑顺序**：移动的顺序不影响最终位置

## 易错点

1. **忘记检查垂直方向**：
   ```java
   // 错误：只检查水平
   return left == right;
   
   // 正确：同时检查水平和垂直
   return left == right && up == down;
   ```

2. **坐标更新方向错误**：
   ```java
   // 注意 y 轴方向：U 是 +1，D 是 -1
   if (move == 'U') y++;       // 向上
   else if (move == 'D') y--;  // 向下
   ```

3. **字符串遍历**：
   ```java
   // Java 中遍历字符串字符
   for (char c : moves.toCharArray()) { ... }
   // 或者
   for (int i = 0; i < moves.length(); i++) {
       char c = moves.charAt(i);
   }
   ```
