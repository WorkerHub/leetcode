## 题目描述

假设你是一个专业的狗仔，参加了一个 n 人派对。在这个派对人群当中可能存在一位明星。所谓明星是指，所有其他人都认识他/她，但他/她不认识其他任何人。

现在你想要确认这个"明星"是谁，或者确定这里没有明星。而你唯一能做的就是问诸如 "你好，A 先生，请问你认识 B 先生吗？" 的问题，以确定 A 是否认识 B。你需要在（渐近意义上）尽可能少的问题内来确定这位明星是谁（或者确定这里没有明星）。

在本题中，你可以调用 API `boolean knows(int a, int b)` 来获取 A 是否认识 B。请你来实现一个函数 `int findCelebrity(int n)`。

派对最多只会有一个明星参加。若明星存在，请返回明星的编号；若明星不存在，请返回 -1。

**示例 1：**
```
输入: graph = [
  [1,1,0],
  [0,1,0],
  [1,1,1]
]
输出: 1
解释: 有编号分别为 0、1 和 2 的三个人。graph[i][j] = 1 代表编号为 i 的人认识编号为 j 的人，
而 graph[i][j] = 0 则代表编号为 i 的人不认识编号为 j 的人。
明星是编号 1 的人，因为 0 和 2 均认识他/她，但 1 不认识任何人。
```

**示例 2：**
```
输入: graph = [
  [1,0,1],
  [1,1,0],
  [0,1,1]
]
输出: -1
解释: 没有明星。
```

**提示：**
- n == graph.length
- n == graph[i].length
- 2 <= n <= 100
- graph[i][j] 是 0 或 1
- graph[i][i] == 1

**进阶：** 如果允许调用 API 的最大次数为 3 * n，你能否设计一个不超过调用次数限制的解决方案呢？

## 解题思路

### 明星的定义

明星的两个条件：
1. 所有其他人都认识明星：`knows(i, celebrity) == true` for all i != celebrity
2. 明星不认识任何其他人：`knows(celebrity, i) == false` for all i != celebrity

### 暴力解法

对每个人 i，检查是否满足明星条件：
- 时间复杂度：O(n^2)
- API 调用次数：O(n^2)

### 优化思路：两阶段算法

**阶段一：找候选人（O(n)）**

关键观察：
- 如果 `knows(a, b) == true`，则 a 不可能是明星（明星不认识别人）
- 如果 `knows(a, b) == false`，则 b 不可能是明星（所有人都认识明星）
- 因此，每次调用 `knows(a, b)` 都能排除一个人

使用单指针遍历，每次排除一个人，最后剩下一个候选人。

**阶段二：验证候选人（O(n)）**

检查候选人是否真的是明星：
1. 候选人不认识其他任何人
2. 其他所有人都认识候选人

### 方法一：两阶段算法（推荐）

```java
public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 阶段一：找候选人
        int candidate = 0;
        for (int i = 1; i < n; i++) {
            // 如果 candidate 认识 i，则 candidate 不可能是明星
            // i 成为新的候选人
            if (knows(candidate, i)) {
                candidate = i;
            }
            // 否则，i 不可能是明星（candidate 不认识 i），candidate 保持不变
        }

        // 阶段二：验证候选人
        for (int i = 0; i < n; i++) {
            if (i == candidate) continue;

            // 候选人认识其他人，或者其他人不认识候选人
            // 都说明候选人不是明星
            if (knows(candidate, i) || !knows(i, candidate)) {
                return -1;
            }
        }

        return candidate;
    }
}
```

### 方法二：栈方法

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 将所有人入栈
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            stack.push(i);
        }

        // 阶段一：通过配对比较，每次排除一个人
        while (stack.size() > 1) {
            int a = stack.pop();
            int b = stack.pop();

            if (knows(a, b)) {
                // a 认识 b，a 不可能是明星，保留 b
                stack.push(b);
            } else {
                // a 不认识 b，b 不可能是明星，保留 a
                stack.push(a);
            }
        }

        // 栈中剩余的是候选人
        int candidate = stack.pop();

        // 阶段二：验证候选人
        for (int i = 0; i < n; i++) {
            if (i == candidate) continue;
            if (knows(candidate, i) || !knows(i, candidate)) {
                return -1;
            }
        }

        return candidate;
    }
}
```

### 方法三：优化的验证（减少 API 调用）

```java
public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 阶段一：找候选人
        int candidate = 0;
        for (int i = 1; i < n; i++) {
            if (knows(candidate, i)) {
                candidate = i;
            }
        }

        // 阶段二：验证候选人
        // 先检查候选人是否认识前面的人（0 到 candidate-1）
        for (int i = 0; i < candidate; i++) {
            if (knows(candidate, i)) return -1;
        }

        // 再检查所有人是否认识候选人，以及候选人是否认识后面的人
        for (int i = 0; i < n; i++) {
            if (i == candidate) continue;
            if (!knows(i, candidate)) return -1;
            if (i > candidate && knows(candidate, i)) return -1;
        }

        return candidate;
    }
}
```

### 方法四：详细注释版（便于理解）

```java
public class Solution extends Relation {
    public int findCelebrity(int n) {
        // 阶段一：找候选人
        // 关键思想：通过 n-1 次比较，排除 n-1 个人
        int candidate = 0;

        for (int i = 1; i < n; i++) {
            // 询问：candidate 认识 i 吗？
            if (knows(candidate, i)) {
                // 如果 candidate 认识 i
                // 那么 candidate 不可能是明星（明星不认识别人）
                // i 成为新的候选人
                candidate = i;
            }
            // 如果 candidate 不认识 i
            // 那么 i 不可能是明星（所有人都应该认识明星）
            // candidate 保持不变
        }

        // 现在 candidate 是唯一可能的明星，但还需要验证

        // 阶段二：验证候选人
        // 需要检查两个条件：
        // 1. 候选人不认识其他任何人
        // 2. 其他所有人都认识候选人
        for (int i = 0; i < n; i++) {
            if (i == candidate) continue;

            // 检查条件 1：候选人不应该认识 i
            if (knows(candidate, i)) return -1;

            // 检查条件 2：i 应该认识候选人
            if (!knows(i, candidate)) return -1;
        }

        // 通过所有检查，candidate 是明星
        return candidate;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- 阶段一：O(n) 找候选人
- 阶段二：O(n) 验证候选人

**空间复杂度：** O(1)
- 只使用常数额外空间

**API 调用次数：** 最多 3n 次
- 阶段一：最多 n-1 次
- 阶段二：最多 2n 次（每个人检查两次）
- 总计：最多 3n-1 次

## 关键点总结

1. **核心思想**：每次 `knows(a, b)` 调用都能排除一个人
   - `knows(a, b) == true` → a 不是明星
   - `knows(a, b) == false` → b 不是明星

2. **两阶段算法**：
   - 阶段一：通过排除法找到唯一候选人
   - 阶段二：验证候选人是否真的是明星

3. **时间优化**：从 O(n^2) 降到 O(n)

4. **API 调用优化**：从 O(n^2) 降到 O(n)

5. **边界情况**：可能没有明星，需要返回 -1

## 易错点

1. **忘记验证候选人**
   ```java
   // 错误：直接返回候选人，没有验证
   return candidate;
   
   // 正确：验证后再返回
   for (int i = 0; i < n; i++) {
       if (knows(candidate, i) || !knows(i, candidate)) return -1;
   }
   return candidate;
   ```

2. **验证时的条件判断**
   ```java
   // 错误：条件写反
   if (!knows(candidate, i) || knows(i, candidate)) return -1;
   
   // 正确：候选人不应该认识别人，别人应该认识候选人
   if (knows(candidate, i) || !knows(i, candidate)) return -1;
   ```

3. **遗漏自己的情况**
   ```java
   // 验证时要跳过候选人自己
   if (i == candidate) continue;
   ```

4. **Java 中继承父类**：使用 `knows` API 需要继承 `Relation` 类
   ```java
   public class Solution extends Relation {
       // knows(a, b) 已在父类中定义
   }
   ```
