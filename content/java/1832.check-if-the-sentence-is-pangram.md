## 题目描述

判断字符串是否包含所有26个小写英文字母（全字母句）。

## 解题思路

用位掩码或集合统计出现过的字母，判断是否全覆盖。

## Java 代码实现

```java
class Solution {
    public boolean checkIfPangram(String sentence) {
        int mask = 0;
        for (char c : sentence.toCharArray()) {
            mask |= 1 << (c - 'a');
        }
        return mask == (1 << 26) - 1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **位掩码**：26位对应26个字母
2. **全1判断**：mask == (1<<26)-1
3. **或运算累积**：每个字母出现即标记
