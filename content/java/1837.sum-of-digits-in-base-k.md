## 题目描述

返回整数n在k进制下各位数字之和。

## 解题思路

反复取余和整除：n%k得最低位，n/=k去掉最低位。

## Java 代码实现

```java
class Solution {
    public int sumBase(int n, int k) {
        int sum = 0;
        while (n > 0) {
            sum += n % k;
            n /= k;
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(log_k(N))
- **空间复杂度**：O(1)

## 关键点总结

1. **标准进制转换**：取余+整除
2. **只需各位之和**：不需存完整表示
