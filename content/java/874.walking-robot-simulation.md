## 题目描述

机器人从 (0,0) 出发面向北方，接收命令（-2 左转、-1 右转、1~9 前进），有障碍物会阻挡。返回经过的所有点到原点的最大欧式距离的平方。

**示例：**
```
输入：commands = [4,-1,3], obstacles = []
输出：25（到达 (3,4)）
```

## 解题思路

模拟：方向数组表示四个方向，用 HashSet 存储障碍物坐标，逐步模拟行走。

## Java 代码实现

```java
class Solution {
    public int robotSim(int[] commands, int[][] obstacles) {
        // 方向：北、东、南、西
        int[] dx = {0, 1, 0, -1};
        int[] dy = {1, 0, -1, 0};

        Set<String> obstacleSet = new HashSet<>();
        for (int[] obs : obstacles) {
            obstacleSet.add(obs[0] + "," + obs[1]);
        }

        int x = 0, y = 0, di = 0;
        int result = 0;

        for (int cmd : commands) {
            if (cmd == -2) {
                di = (di + 3) % 4; // 左转
            } else if (cmd == -1) {
                di = (di + 1) % 4; // 右转
            } else {
                for (int i = 0; i < cmd; i++) {
                    int nx = x + dx[di], ny = y + dy[di];
                    if (!obstacleSet.contains(nx + "," + ny)) {
                        x = nx;
                        y = ny;
                        result = Math.max(result, x * x + y * y);
                    }
                }
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N + K)，N 为命令数，K 为总步数
- **空间复杂度**：O(M)，M 为障碍物数量

## 关键点总结

1. **方向数组**：dx/dy 配合方向索引
2. **障碍物集合**：HashSet 快速查询
3. **逐步前进**：每步检查障碍物
