## 题目描述

给定一个由 0 和 1 组成的矩阵 `mat`，输出每个格子到最近 0 的距离。

**示例：**
```
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]
```

## 解题思路

多源 BFS：所有 0 作为起点同时扩散，首次到达即最短距离。

## Java 代码实现

### 方法一：多源 BFS（推荐）

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        Queue<int[]> queue = new LinkedList<>();

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 0) {
                    queue.offer(new int[]{i, j});
                } else {
                    dist[i][j] = Integer.MAX_VALUE;
                }
            }
        }

        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            for (int[] d : dirs) {
                int x = cell[0] + d[0], y = cell[1] + d[1];
                if (x >= 0 && x < m && y >= 0 && y < n
                        && dist[x][y] > dist[cell[0]][cell[1]] + 1) {
                    dist[x][y] = dist[cell[0]][cell[1]] + 1;
                    queue.offer(new int[]{x, y});
                }
            }
        }
        return dist;
    }
}
```

### 方法二：动态规划

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        int INF = m + n;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dist[i][j] = mat[i][j] == 0 ? 0 : INF;
            }
        }

        // 从左上到右下
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i > 0) dist[i][j] = Math.min(dist[i][j], dist[i-1][j] + 1);
                if (j > 0) dist[i][j] = Math.min(dist[i][j], dist[i][j-1] + 1);
            }
        }

        // 从右下到左上
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (i < m - 1) dist[i][j] = Math.min(dist[i][j], dist[i+1][j] + 1);
                if (j < n - 1) dist[i][j] = Math.min(dist[i][j], dist[i][j+1] + 1);
            }
        }
        return dist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：BFS O(m × n)，DP O(1)（不算结果数组）

## 关键点总结

1. **多源 BFS**：所有 0 同时入队，层层扩散
2. **DP 两次遍历**：左上到右下 + 右下到左上覆盖所有方向
