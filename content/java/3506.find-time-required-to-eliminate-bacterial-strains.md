## 题目描述

有 `n` 种细菌菌株，给定数组 `timeReq` 和整数 `splitTime`。每次操作可以消灭一种菌株（耗时 `timeReq[i]`），或等待 `splitTime` 时间后所有剩余菌株数量翻倍。求消灭所有菌株的最短时间。

## 解题思路

贪心 + 枚举分裂位置：将菌株按耗时降序排序，最多只分裂一次（分裂多次会累加 splitTime 且增加后续负担）。枚举在消灭前 `i` 个（耗时最长的）后进行一次分裂，剩余 `(n-i)` 种各变 2 份，代价为 `prefix[i] + splitTime + 2*(prefix[n]-prefix[i])`，与不分裂的代价 `prefix[n]` 取最小。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int minEliminationTime(int[] timeReq, int splitTime) {
        Arrays.sort(timeReq);
        int n = timeReq.length;
        // 降序：先消灭耗时最长的
        for (int i = 0, j = n - 1; i < j; i++, j--) {
            int tmp = timeReq[i]; timeReq[i] = timeReq[j]; timeReq[j] = tmp;
        }
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + timeReq[i];

        long ans = prefix[n]; // 不分裂
        for (int i = 0; i <= n; i++) {
            // 先消灭前 i 个，再分裂一次，剩余每种有 2 份
            long cost = prefix[i] + splitTime + 2 * (prefix[n] - prefix[i]);
            ans = Math.min(ans, cost);
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(n)，前缀和数组

## 关键点总结

1. 降序排序后优先消灭耗时大的菌株，再分裂更合算
2. 最优方案至多分裂一次（多次分裂收益递减）
3. 枚举分裂位置，O(n) 找全局最优
