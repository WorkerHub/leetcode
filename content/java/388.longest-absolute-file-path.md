## 题目描述

假设有一个同时存储文件和目录的文件系统。下图展示了文件系统的一个示例：

```
dir
    subdir1
        file1.ext
        subsubdir1
    subdir2
        subsubdir2
            file2.ext
```

在文本格式中，如下所示（用 `\t` 表示制表符）：

```
"dir\n\tsubdir1\n\t\tfile1.ext\n\t\tsubsubdir1\n\tsubdir2\n\t\tsubsubdir2\n\t\t\tfile2.ext"
```

文件系统中的每个文件和文件夹都有一个唯一的**绝对路径**，即从根目录到该文件/目录的路径，路径中的目录由 `/` 分隔。

上面的例子中，指向 `file2.ext` 的绝对路径是 `"dir/subdir2/subsubdir2/file2.ext"`。路径长度为 `32`（不包含路径分隔符）。

`subsubdir1` 是一个目录，不包含任何文件。

给定一个字符串 `input` 表示上述格式的文件系统，返回文件系统中**指向文件的最长绝对路径的长度**。如果系统中没有文件，返回 `0`。

**注意：**

- 文件名至少存在一个 `.` 和一个文件扩展名。
- 目录或者子目录的名字不能包含 `.`。

**示例 1:**

![](https://assets.leetcode.com/uploads/2020/08/28/dir1.jpg)

```
输入：input = "dir\n\tsubdir1\n\tsubdir2\n\t\tfile.ext"
输出：20
解释：只有一个文件，绝对路径为 "dir/subdir2/file.ext"，路径长度 20
```

**示例 2:**

![](https://assets.leetcode.com/uploads/2020/08/28/dir2.jpg)

```
输入：input = "dir\n\tsubdir1\n\t\tfile1.ext\n\t\tsubsubdir1\n\tsubdir2\n\t\tsubsubdir2\n\t\t\tfile2.ext"
输出：32
解释：存在两个文件：
"dir/subdir1/file1.ext"，路径长度 21
"dir/subdir2/subsubdir2/file2.ext"，路径长度 32
返回 32，因为这是最长的路径
```

**示例 3:**

```
输入：input = "a"
输出：0
解释：不存在任何文件
```

**示例 4:**

```
输入：input = "file1.txt\nfile2.txt\nlongfile.txt"
输出：12
解释：根目录下有 3 个文件。
因为根目录中任何东西的绝对路径只是名称本身，所以答案是 "longfile.txt"，路径长度为 12
```

**提示:**

- `1 <= input.length <= 10^4`
- `input` 可能包含小写或大写的英文字母，一个换行符 `'\n'`，一个制表符 `'\t'`，一个点 `'.'`，一个空格 `' '`，和数字。
- 所有文件和目录的名字都是**非空**的。

## 解题思路

本题的关键在于：

1. **层级关系**：通过 `\t` 的数量判断层级深度
2. **文件识别**：包含 `.` 的是文件，否则是目录
3. **路径长度**：需要累加当前层级及之前所有父目录的长度，加上 `/` 分隔符

### 核心思想：栈维护路径长度

**算法流程：**

1. 按 `\n` 分割字符串，得到每个文件/目录
2. 统计每个项的 `\t` 数量，确定层级
3. 使用栈维护每一层的路径长度
4. 遇到文件时，计算完整路径长度并更新最大值

**栈的作用：**
- `stack[i]` 存储第 `i` 层的路径总长度（包括所有父目录）
- 当前层级小于栈的大小时，说明回到了上层，需要弹栈

## Java 代码实现

### 方法一：栈维护路径长度（推荐）⭐

```java
import java.util.*;

class Solution {
    public int lengthLongestPath(String input) {
        int maxLen = 0;
        // 栈存储每层的累计路径长度（初始化虚拟根目录，长度为 0）
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);

        for (String line : input.split("\n")) {
            // 统计 \t 的数量，确定层级（深度）
            int depth = 0;
            while (depth < line.length() && line.charAt(depth) == '\t') {
                depth++;
            }
            // 去掉 \t 后的实际名称
            String name = line.substring(depth);

            // 弹出栈，直到栈的大小为 depth + 1（对应父层）
            while (stack.size() > depth + 1) {
                stack.pop();
            }

            // 当前长度 = 父目录长度 + 当前名称长度 + 分隔符（非根目录需要加 /）
            int length = stack.peek() + name.length() + (depth > 0 ? 1 : 0);

            if (name.contains(".")) {
                // 是文件，更新最大值
                maxLen = Math.max(maxLen, length);
            }

            // 压栈（无论是文件还是目录）
            stack.push(length);
        }

        return maxLen;
    }
}
```

### 方法二：使用数组作为栈（更高效）

```java
class Solution {
    public int lengthLongestPath(String input) {
        int maxLen = 0;
        // 使用数组模拟栈，stack[i] 表示第 i 层的路径总长度
        // 多分配一位，用于虚拟根目录（depth 0 的父层）
        int[] stack = new int[input.length() + 1];
        // stack[0] = 0 作为虚拟根目录

        for (String line : input.split("\n")) {
            // 统计 \t 数量确定深度
            int depth = 0;
            while (depth < line.length() && line.charAt(depth) == '\t') {
                depth++;
            }
            String name = line.substring(depth);

            // 当前层路径长度 = 父层长度 + 名称长度 + 分隔符
            int length = stack[depth] + name.length() + (depth > 0 ? 1 : 0);
            // 存入当前层（depth + 1 位置）
            stack[depth + 1] = length;

            if (name.contains(".")) {
                // 是文件，更新最大值
                maxLen = Math.max(maxLen, length);
            }
        }

        return maxLen;
    }
}
```

### 方法三：HashMap 维护（最清晰）

```java
import java.util.*;

class Solution {
    public int lengthLongestPath(String input) {
        int maxLen = 0;
        // HashMap 存储层级 -> 路径长度
        Map<Integer, Integer> lengths = new HashMap<>();
        lengths.put(-1, 0); // 虚拟根目录

        for (String line : input.split("\n")) {
            // 统计层级
            int level = 0;
            while (level < line.length() && line.charAt(level) == '\t') {
                level++;
            }
            String name = line.replace("\t", "");

            // 当前层的长度 = 父层长度 + 名称长度 + 分隔符
            int len = lengths.get(level - 1) + name.length() + (level > 0 ? 1 : 0);
            lengths.put(level, len);

            // 如果是文件
            if (name.contains(".")) {
                maxLen = Math.max(maxLen, len);
            }
        }

        return maxLen;
    }
}
```

## 复杂度分析

**时间复杂度：** O(n)
- n 是字符串的长度
- 需要遍历字符串一次，每个字符最多被处理常数次

**空间复杂度：** O(d)
- d 是目录的最大深度
- 栈或字典最多存储 d 个层级的信息

## 关键点总结

1. **层级识别**：`\t` 的数量表示层级深度
2. **文件判断**：包含 `.` 的是文件
3. **路径长度计算**：当前层 = 父层 + 名称长度 + 分隔符（/）
4. **栈的使用**：维护每层的累计长度，支持快速回退
5. **分隔符处理**：根目录（level 0）不需要前导 `/`

## 易错点

1. **分隔符计数**：路径长度不包括 `/`，但计算时要加上
2. **根目录处理**：第一层不需要加 `/` 分隔符
3. **目录 vs 文件**：目录也要压栈，只是不更新最大值
4. **栈的大小**：回到上层时需要弹栈
5. **边界情况**：没有文件时返回 0
6. **Java split 转义**：`split("\n")` 需要注意转义，`split("\\n")` 也可以
