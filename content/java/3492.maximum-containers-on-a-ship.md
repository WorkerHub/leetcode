## 题目描述

一艘船有 `n * n` 个货柜格，每个格最多放一个集装箱（重 1 千克），船的最大载重为 `w` 千克，返回能放置的最大集装箱数量。

## 解题思路

答案受两个约束：货柜格数 `n*n` 和最大载重 `w`，取两者最小值。

## Java 代码实现

```java
class Solution {
    public int maxContainers(int n, int w) {
        return Math.min(n * n, w);
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 答案受格数和载重双重约束，取最小值
2. n 最大 1000，`n*n` 最大 10^6，不会溢出 int
3. 每个集装箱重量相同（1 千克），直接比较
