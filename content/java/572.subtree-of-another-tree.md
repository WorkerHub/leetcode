## 题目描述

给你两棵二叉树 `root` 和 `subRoot`。检验 `root` 中是否包含和 `subRoot` 具有相同结构和节点值的子树。如果存在，返回 `true`；否则，返回 `false`。

二叉树 `tree` 的一棵子树包括 `tree` 的某个节点和这个节点的所有后代节点。`tree` 也可以看做它自身的一棵子树。

**示例 1：**
```
输入：root = [3,4,5,1,2], subRoot = [4,1,2]
输出：true
```

**示例 2：**
```
输入：root = [3,4,5,1,2,null,null,null,null,0], subRoot = [4,1,2]
输出：false
```

**提示：**
- `root` 树上的节点数量范围是 `[1, 2000]`
- `subRoot` 树上的节点数量范围是 `[1, 1000]`
- `-10^4 <= root.val <= 10^4`
- `-10^4 <= subRoot.val <= 10^4`

## 解题思路

遍历主树的每个节点，检查以该节点为根的子树是否与 subRoot 相同。

## Java 代码实现

### 方法一：递归 DFS（推荐）⭐

```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        // 递归检查每个节点
        if (root == null) return false;

        // 检查当前节点是否与 subRoot 相同
        if (isSameTree(root, subRoot)) return true;

        // 递归检查左右子树
        return isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
    }

    // 检查两棵树是否相同
    private boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        return p.val == q.val
            && isSameTree(p.left, q.left)
            && isSameTree(p.right, q.right);
    }
}
```

### 方法二：序列化匹配

```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        // 序列化后字符串匹配
        return serialize(root).contains(serialize(subRoot));
    }

    // 序列化树，加特殊符号避免误匹配
    private String serialize(TreeNode node) {
        if (node == null) return "#";
        return "^" + node.val + "," + serialize(node.left) + "," + serialize(node.right);
    }
}
```

## 复杂度分析

**方法一：**
- **时间复杂度**：O(m × n)，m 和 n 分别是两棵树的节点数
- **空间复杂度**：O(h)，递归栈深度

**方法二：**
- **时间复杂度**：O(m + n)
- **空间复杂度**：O(m + n)

## 关键点总结

1. **子树定义**：必须包含所有后代节点
2. **递归思路**：检查当前节点 + 递归左右子树
3. **相同树判断**：值和结构都要相同
4. **字符串匹配**：序列化后可以用字符串匹配

## 易错点

1. **子树 vs 子结构**：子树必须完整，不能只匹配部分
2. **空树处理**：空树不是任何树的子树
3. **序列化**：需要加特殊符号（如 `^`）避免误匹配
