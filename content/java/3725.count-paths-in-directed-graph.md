## 题目描述

给定有 `n` 个节点的有向无环图（DAG）和边集 `edges`，计算从节点 `0` 出发到达节点 `n-1` 的路径总数，结果对 `10^9 + 7` 取模。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int countPaths(int n, int[][] edges) {
        final int MOD = 1_000_000_007;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) graph.get(e[0]).add(e[1]);

        // 拓扑排序 DP
        int[] inDegree = new int[n];
        for (int[] e : edges) inDegree[e[1]]++;

        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < n; i++) if (inDegree[i] == 0) queue.offer(i);

        List<Integer> topo = new ArrayList<>();
        while (!queue.isEmpty()) {
            int u = queue.poll();
            topo.add(u);
            for (int v : graph.get(u)) if (--inDegree[v] == 0) queue.offer(v);
        }

        // 逆拓扑序 DP：dp[u] = 从 u 到 n-1 的路径数
        long[] dp = new long[n];
        dp[n - 1] = 1;
        for (int i = topo.size() - 1; i >= 0; i--) {
            int u = topo.get(i);
            for (int v : graph.get(u)) dp[u] = (dp[u] + dp[v]) % MOD;
        }

        return (int) dp[0];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n + m)，拓扑排序线性
- 空间复杂度：O(n + m)

## 关键点总结

1. DAG 上的路径计数是经典动态规划问题
2. 拓扑排序保证处理每个节点时，其所有后继节点已处理完毕
3. `dp[n-1] = 1` 作为基准，逆拓扑序累加得到 `dp[0]`
