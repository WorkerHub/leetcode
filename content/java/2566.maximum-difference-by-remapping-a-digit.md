## 题目描述

给你整数 `num`，可以将其十进制表示中某个数字（0-9）全部替换为另一个数字，求最大值减最小值的结果。

## 解题思路

最大值：将第一个不是 9 的数字全部替换为 9；最小值：将第一个数字全部替换为 0。

## Java 代码实现

```java
class Solution {
    public int minMaxDifference(int num) {
        String s = Integer.toString(num);
        // 最大值：第一个非 9 数字替换为 9
        int maxVal = num;
        for (char c : s.toCharArray()) {
            if (c != '9') {
                maxVal = Integer.parseInt(s.replace(c, '9'));
                break;
            }
        }
        // 最小值：第一个数字替换为 0
        int minVal = Integer.parseInt(s.replace(s.charAt(0), '0'));
        return maxVal - minVal;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(d)，d 为位数
- **空间复杂度**：O(d)

## 关键点总结

1. 最大化：将首个非 9 数字全部换成 9
2. 最小化：将首位数字全部换成 0（允许前导零）
3. 用 `String.replace(char, char)` 一次完成全局替换
