## 题目描述

给你数字字符串 `num`，返回其排列中平衡字符串（奇数位数字之和 = 偶数位数字之和，1 索引）的数量，对 10^9+7 取模。

## 解题思路

总和为奇数时无解。设奇数位数量为 `oddLen = (n+1)/2`，目标 = 总和/2。DP：`dp[j][s]` = 从数字中选了 j 个放奇数位且和为 s 的方案数（用组合数 C(cnt[d], k) 分配每个数字）。最终答案乘以 `oddLen! * evenLen!`（位置排列）。

## Java 代码实现

```java
class Solution {
    public int countBalancedPermutations(String num) {
        final int MOD = 1_000_000_007;
        int n = num.length();
        int[] cnt = new int[10];
        int total = 0;
        for (char c : num.toCharArray()) { cnt[c - '0']++; total += c - '0'; }
        if (total % 2 != 0) return 0;

        int target = total / 2;
        int oddLen = (n + 1) / 2, evenLen = n / 2;

        // 预处理阶乘和逆阶乘
        int maxN = n + 1;
        long[] fact = new long[maxN], invFact = new long[maxN];
        fact[0] = 1;
        for (int i = 1; i < maxN; i++) fact[i] = fact[i-1] * i % MOD;
        invFact[maxN - 1] = modPow(fact[maxN - 1], MOD - 2, MOD);
        for (int i = maxN - 2; i >= 0; i--) invFact[i] = invFact[i+1] * (i+1) % MOD;

        // dp[j][s] = 选了 j 个放奇数位，和为 s 的方案数
        long[][] dp = new long[oddLen + 1][target + 1];
        dp[0][0] = 1;

        for (int d = 0; d <= 9; d++) {
            int c = cnt[d];
            if (c == 0) continue;
            long[][] ndp = new long[oddLen + 1][target + 1];
            for (int j = 0; j <= oddLen; j++) {
                for (int s = 0; s <= target; s++) {
                    if (dp[j][s] == 0) continue;
                    // 选 k 个数字 d 放奇数位
                    for (int k = 0; k <= Math.min(c, oddLen - j); k++) {
                        int ns = s + k * d;
                        if (ns > target) break;
                        long ways = fact[c] % MOD * invFact[k] % MOD * invFact[c - k] % MOD;
                        ndp[j + k][ns] = (ndp[j + k][ns] + dp[j][s] * ways) % MOD;
                    }
                }
            }
            dp = ndp;
        }

        // 乘以 oddLen! * evenLen!（位置排列）
        return (int) (dp[oddLen][target] * fact[oddLen] % MOD * fact[evenLen] % MOD);
    }

    private long modPow(long base, long exp, long mod) {
        long result = 1; base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod; exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10 * oddLen * target)，target <= 9*80 = 720
- 空间复杂度：O(oddLen * target)

## 关键点总结

1. 总和为奇数时直接返回 0
2. 对每个数字枚举分配多少到奇数位，用 C(cnt[d], k) 计算分配方案
3. 最终乘以 `oddLen! * evenLen!` 得到位置排列数
