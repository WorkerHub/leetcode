## 题目描述

给你一个整数数组 `nums`，返回元素互不相同的子数组中元素之和的最大值。

## 解题思路

滑动窗口：维护双指针 `[left, right]` 表示无重复元素的窗口。右指针移入元素时若出现重复，则不断移动左指针直到重复消除，同时维护当前窗口和，每步更新最大和。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long maximumSubarraySum(int[] nums) {
        int left = 0;
        long currSum = 0, maxSum = 0;
        Map<Integer, Integer> freq = new HashMap<>();

        for (int right = 0; right < nums.length; right++) {
            int v = nums[right];
            freq.merge(v, 1, Integer::sum);
            currSum += v;

            // 出现重复，收缩左端直到无重复
            while (freq.get(v) > 1) {
                int lv = nums[left];
                freq.merge(lv, -1, Integer::sum);
                currSum -= lv;
                left++;
            }
            maxSum = Math.max(maxSum, currSum);
        }
        return maxSum;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，双指针各移动 n 次
- 空间复杂度：O(n)，哈希表

## 关键点总结

1. 滑动窗口维护无重复子数组，右端移入重复元素时收缩左端。
2. 维护当前窗口和 `currSum`，每次更新最大和。
3. 收缩左端时同步更新频次表和当前窗口和。
