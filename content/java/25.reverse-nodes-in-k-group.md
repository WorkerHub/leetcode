## 题目描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**
```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**
```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

**提示：**
- 链表中的节点数目为 `n`
- `1 <= k <= n <= 5000`
- `0 <= Node.val <= 1000`

**进阶：** 你可以设计一个只用 O(1) 额外内存空间的算法解决此问题吗？

## 解题思路

核心思想：
1. 分组处理：每 k 个节点一组
2. 反转每一组
3. 连接各组

关键步骤：
1. 检查剩余节点是否够 k 个
2. 反转这 k 个节点
3. 递归或迭代处理下一组

## Java 代码实现

### 方法一：迭代法（推荐）

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0, head);
        ListNode prevGroup = dummy;

        while (true) {
            // 检查剩余节点是否够 k 个
            ListNode kth = getKth(prevGroup, k);
            if (kth == null) {
                break;
            }

            // 记录下一组的开始
            ListNode nextGroup = kth.next;

            // 反转当前组
            ListNode prev = kth.next;
            ListNode curr = prevGroup.next;
            while (curr != nextGroup) {
                ListNode temp = curr.next;
                curr.next = prev;
                prev = curr;
                curr = temp;
            }

            // 连接反转后的组
            ListNode temp = prevGroup.next;
            prevGroup.next = kth;
            prevGroup = temp;
        }

        return dummy.next;
    }

    private ListNode getKth(ListNode curr, int k) {
        // 获取从 curr 开始的第 k 个节点
        while (curr != null && k > 0) {
            curr = curr.next;
            k--;
        }
        return curr;
    }
}
```

### 方法二：递归法

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 检查是否有 k 个节点
        ListNode curr = head;
        int count = 0;
        while (curr != null && count < k) {
            curr = curr.next;
            count++;
        }

        // 不足 k 个，直接返回
        if (count < k) {
            return head;
        }

        // 反转前 k 个节点
        ListNode prev = null;
        curr = head;
        for (int i = 0; i < k; i++) {
            ListNode temp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = temp;
        }

        // 递归处理剩余部分
        head.next = reverseKGroup(curr, k);

        // prev 是新的头节点
        return prev;
    }
}
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(n)
- 空间复杂度：
  - 迭代法 O(1)
  - 递归法 O(n/k)，递归调用栈

## 关键点总结

1. **分组检查**：确保有 k 个节点才反转
2. **反转链表**：基础操作，需熟练掌握
3. **连接各组**：正确连接反转后的各组
4. **边界处理**：最后不足 k 个节点保持原序

## 易错点

1. **不足 k 个**：最后一组不足 k 个不反转
2. **指针丢失**：反转过程中要保存必要的指针
3. **边界情况**：k = 1 时直接返回原链表
