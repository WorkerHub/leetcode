## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，对于每个长度为 `k` 的窗口，统计出现频率等于窗口内最大频率的元素数目。返回所有窗口的统计结果数组。

## 解题思路

滑动窗口：维护频率表 `freq`、窗口内最大频率 `maxFreq` 和达到最大频率的元素种类数 `countMax`。右端元素加入时更新，左端元素移除时若 `countMax` 降为 0 则最大频率减 1。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int[] countElements(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> freq = new HashMap<>();
        int maxFreq = 0, countMax = 0;
        int[] ans = new int[n - k + 1];

        for (int i = 0; i < n; i++) {
            // 加入右端元素
            int v = nums[i];
            freq.merge(v, 1, Integer::sum);
            int fv = freq.get(v);
            if (fv > maxFreq) {
                maxFreq = fv;
                countMax = 1;
            } else if (fv == maxFreq) {
                countMax++;
            }

            // 窗口超过 k，移除左端元素
            if (i >= k) {
                int lv = nums[i - k];
                int flv = freq.get(lv);
                if (flv == maxFreq) countMax--;
                if (flv == 1) freq.remove(lv);
                else freq.put(lv, flv - 1);
                // 若无元素达到 maxFreq，说明最大频率降低 1
                if (countMax == 0) {
                    maxFreq--;
                    for (int f : freq.values()) {
                        if (f == maxFreq) countMax++;
                    }
                }
            }

            // 记录结果
            if (i >= k - 1) {
                ans[i - k + 1] = countMax;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，摊销（重扫频率表很少发生）
- 空间复杂度：O(k)，窗口频率表

## 关键点总结

1. 维护 `maxFreq` 和 `countMax` 两个变量跟踪最大频率及其种类数。
2. 右端元素加入：若新频率 > maxFreq 则重置 countMax=1，= maxFreq 则累加。
3. 左端元素移除：若 countMax 降为 0，最大频率减 1，重新统计 countMax。
