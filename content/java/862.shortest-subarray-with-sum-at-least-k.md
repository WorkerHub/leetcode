## 题目描述

给你一个整数数组 nums 和一个整数 k ，找出 nums 中和至少为 k 的 最短非空子数组 ，并返回该子数组的长度。如果不存在这样的 子数组 ，返回 -1 。

子数组 是数组中 连续 的一部分。

**示例 1：**
```
输入：nums = [1], k = 1
输出：1
```

**示例 2：**
```
输入：nums = [1,2], k = 4
输出：-1
```

**示例 3：**
```
输入：nums = [2,-1,2], k = 3
输出：3
```

**提示：**
- 1 <= nums.length <= 10^5
- -10^5 <= nums[i] <= 10^5
- 1 <= k <= 10^9

## 解题思路

这道题的难点在于**数组包含负数**，不能使用普通的滑动窗口。

**关键观察：**
1. 使用前缀和：`preSum[i]` 表示前 i 个元素的和
2. 子数组 `[i, j]` 的和 = `preSum[j] - preSum[i-1]`
3. 要找最短的 j-i，使得 `preSum[j] - preSum[i] >= k`

**单调队列解法：**
1. 维护一个单调递增的双端队列，存储前缀和的索引
2. 对于当前位置 j：
   - 从队首移除所有满足 `preSum[j] - preSum[队首] >= k` 的元素，更新答案
   - 从队尾移除所有 `preSum[队尾] >= preSum[j]` 的元素（不会是最优解）
3. 将 j 加入队列

**为什么队尾移除？**
- 如果 `preSum[i] >= preSum[j]` 且 i < j，那么 i 永远不会是最优解
- 因为 j 位置更靠后，且前缀和更小，能产生更大的子数组和

## Java 代码实现

### 方法一：单调队列（推荐）

```java
class Solution {
    public int shortestSubarray(int[] nums, int k) {
        int n = nums.length;
        // 前缀和数组（注意用 long 防止溢出）
        long[] preSum = new long[n + 1];
        for (int i = 0; i < n; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
        }

        int result = n + 1;
        // 单调队列，存储索引
        Deque<Integer> queue = new ArrayDeque<>();

        for (int i = 0; i <= n; i++) {
            // 从队首移除满足条件的元素，更新最短长度
            while (!queue.isEmpty() && preSum[i] - preSum[queue.peekFirst()] >= k) {
                result = Math.min(result, i - queue.pollFirst());
            }

            // 从队尾移除不可能是最优解的元素（保持队列单调递增）
            while (!queue.isEmpty() && preSum[queue.peekLast()] >= preSum[i]) {
                queue.pollLast();
            }

            queue.offerLast(i);
        }

        return result <= n ? result : -1;
    }
}
```

**代码说明：**
- 单调队列维护前缀和递增
- 队首元素是最小的前缀和
- 及时移除无用元素
- 使用 long 防止整数溢出

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多入队出队一次。
- **空间复杂度**：O(n)，前缀和数组和队列。

## 关键点总结

1. **前缀和**：转化为前缀和相减问题
2. **单调队列**：维护前缀和递增（双端队列）
3. **双端操作**：队首队尾都可能需要移除
4. **负数处理**：单调队列能处理负数情况
5. **整数溢出**：使用 long 类型

## 易错点

1. **边界索引**：前缀和数组长度是 n+1，循环到 i=n
2. **单调性**：队列维护递增，不是递减
3. **溢出处理**：nums[i] 最大 10^5，长度最大 10^5，乘积可能超 int
4. **返回值**：没有找到返回 -1
