## 题目描述

从位置0出发，每次跳[minJump, maxJump]距离到值为'0'的位置，判断能否到达末尾。

## 解题思路

DP+滑动窗口：dp[i]表示能否到达i，维护窗口[i-maxJump, i-minJump]内可达点数，大于0则dp[i]=true。

## Java 代码实现

```java
class Solution {
    public boolean canReach(String s, int minJump, int maxJump) {
        int n = s.length();
        if (s.charAt(n - 1) != '0') return false;
        
        boolean[] dp = new boolean[n];
        dp[0] = true;
        int window = 0; // 窗口内可达点计数
        
        for (int i = 1; i < n; i++) {
            // 扩展窗口右边界
            if (i >= minJump && dp[i - minJump]) window++;
            // 收缩窗口左边界
            if (i > maxJump && dp[i - maxJump - 1]) window--;
            
            if (s.charAt(i) == '0' && window > 0) {
                dp[i] = true;
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **滑动窗口优化**：动态维护区间内可达点数
2. **窗口边界**：右扩展在i>=minJump时，左收缩在i>maxJump时
3. **s[i]=='0'才可达**：额外条件
