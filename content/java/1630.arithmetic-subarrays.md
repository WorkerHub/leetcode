## 题目描述

给你整数数组 `nums` 和两个整数数组 `l`、`r`，对每个查询 `[l[i], r[i]]`，判断 `nums[l[i]..r[i]]` 重新排列后是否可以构成等差数列。

**示例：**
- `nums=[4,6,5,9,3,7], l=[0,0,2], r=[2,3,5]` → `[true,false,true]`

## 解题思路

对每个查询提取子数组，**排序后检查相邻差是否相等**。

## Java 代码实现

```java
class Solution {
    public List<Boolean> checkArithmeticSubarrays(int[] nums, int[] l, int[] r) {
        List<Boolean> result = new ArrayList<>();

        for (int i = 0; i < l.length; i++) {
            result.add(isArithmetic(nums, l[i], r[i]));
        }
        return result;
    }

    private boolean isArithmetic(int[] nums, int left, int right) {
        int len = right - left + 1;
        if (len < 2) return true;

        // 提取并排序子数组
        int[] sub = Arrays.copyOfRange(nums, left, right + 1);
        Arrays.sort(sub);

        // 检查相邻差是否相等
        int d = sub[1] - sub[0];
        for (int i = 2; i < len; i++) {
            if (sub[i] - sub[i - 1] != d) return false;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q * m log m)，q 为查询数，m 为子数组平均长度
- **空间复杂度**：O(m)，临时子数组

## 关键点总结

1. 排序后检查相邻差是否相等，直观高效
2. `Arrays.copyOfRange` 提取子数组，`Arrays.sort` 排序
3. 子数组长度小于 2 时直接返回 true
