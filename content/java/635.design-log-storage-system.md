## 题目描述

设计日志存储系统，支持 `put(id, timestamp)` 和 `retrieve(start, end, granularity)` 操作，根据时间粒度检索日志。

**示例：**
```
logSystem.put(1, "2017:01:01:23:59:59");
logSystem.put(2, "2017:01:01:22:59:59");
logSystem.put(3, "2016:01:01:00:00:00");
logSystem.retrieve("2016:01:01:01:01:01", "2017:01:01:23:00:00", "Year");
// 返回 [3, 2, 1]
```

## 解题思路

根据粒度截断时间戳进行字符串比较，格式固定保证字典序等于时间序。

## Java 代码实现

```java
class LogSystem {
    private List<int[]> logs; // [id, 保留原始时间戳索引]
    private List<String> timestamps;
    private Map<String, Integer> granMap;

    public LogSystem() {
        logs = new ArrayList<>();
        timestamps = new ArrayList<>();
        granMap = new HashMap<>();
        granMap.put("Year", 4);
        granMap.put("Month", 7);
        granMap.put("Day", 10);
        granMap.put("Hour", 13);
        granMap.put("Minute", 16);
        granMap.put("Second", 19);
    }

    public void put(int id, String timestamp) {
        logs.add(new int[]{id});
        timestamps.add(timestamp);
    }

    public List<Integer> retrieve(String start, String end, String granularity) {
        int len = granMap.get(granularity);
        String s = start.substring(0, len);
        String e = end.substring(0, len);

        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < timestamps.size(); i++) {
            String t = timestamps.get(i).substring(0, len);
            if (t.compareTo(s) >= 0 && t.compareTo(e) <= 0) {
                result.add(logs.get(i)[0]);
            }
        }
        return result;
    }
}
```

## 复杂度分析

- **put**：O(1)
- **retrieve**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **字符串截断比较**：根据粒度截取固定长度
2. **格式固定**：字典序等于时间序
3. **粒度映射**：Year→4, Month→7, Day→10, Hour→13, Minute→16, Second→19
