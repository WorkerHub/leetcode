## 题目描述

网格中火在蔓延，求从(0,0)出发最多可等待多少分钟后仍能到达(m-1,n-1)。

## 解题思路

二分等待时间+BFS验证。先多源BFS预计算火到达每格的时间，然后二分等待时间t，BFS验证人能否在火之前到达终点（终点允许同时到达）。

## Java 代码实现

```java
class Solution {
    private static final int[][] DIRS = {{-1,0},{1,0},{0,-1},{0,1}};

    public int maximumMinutes(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] fireTime = new int[m][n];
        for (int[] row : fireTime) Arrays.fill(row, Integer.MAX_VALUE);

        // 多源BFS计算火的到达时间
        Deque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1) { fireTime[i][j] = 0; q.offer(new int[]{i, j}); }

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int[] d : DIRS) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 0 && fireTime[nr][nc] == Integer.MAX_VALUE) {
                    fireTime[nr][nc] = fireTime[cur[0]][cur[1]] + 1;
                    q.offer(new int[]{nr, nc});
                }
            }
        }

        // 二分等待时间
        int lo = 0, hi = m * n;
        if (!canEscape(grid, fireTime, 0, m, n)) return -1;
        if (canEscape(grid, fireTime, hi, m, n)) return 1_000_000_000;

        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (canEscape(grid, fireTime, mid, m, n)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean canEscape(int[][] grid, int[][] fireTime, int wait, int m, int n) {
        if (fireTime[0][0] <= wait) return false;
        boolean[][] vis = new boolean[m][n];
        vis[0][0] = true;
        Deque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{0, 0});
        int step = wait;

        while (!q.isEmpty()) {
            int size = q.size();
            step++;
            for (int i = 0; i < size; i++) {
                int[] cur = q.poll();
                for (int[] d : DIRS) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc] == 2 || vis[nr][nc]) continue;
                    // 终点允许同时到达
                    if (nr == m - 1 && nc == n - 1) {
                        if (step <= fireTime[nr][nc]) return true;
                        continue;
                    }
                    if (step < fireTime[nr][nc]) {
                        vis[nr][nc] = true;
                        q.offer(new int[]{nr, nc});
                    }
                }
            }
        }
        return false;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m*n*log(m*n))
- **空间复杂度**：O(m*n)

## 关键点总结

1. **多源BFS预计算火的到达时间**
2. **二分等待时间**：单调性保证正确
3. **终点特殊处理**：允许与火同时到达（<=），其他格子必须严格早于火（<）
