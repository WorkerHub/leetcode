## 题目描述

给你一个整数数组 `nums`，返回按位或（OR）等于整个数组按位或的非空子集数量。

## 解题思路

先计算整个数组的 OR 值 `target`。由于 n <= 16，枚举所有 `2^n - 1` 个非空子集，统计 OR 等于 `target` 的数量。

## Java 代码实现

```java
class Solution {
    public int countSubsets(int[] nums) {
        int n = nums.length;
        int target = 0;
        for (int x : nums) target |= x;

        int count = 0;
        // 枚举所有非空子集
        for (int mask = 1; mask < (1 << n); mask++) {
            int orVal = 0;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 1) orVal |= nums[i];
            }
            if (orVal == target) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(1)

## 关键点总结

1. 目标 OR 值一定是整个数组的 OR（OR 是单调的）
2. n <= 16 时状态压缩枚举所有子集可行
3. 只统计非空子集（mask 从 1 开始）
