## 题目描述

给你字符串 `key` 和加密消息 `message`，按 key 中字母第一次出现的顺序建立解密映射表（第 i 个新字母对应 'a'+i），对 message 解密并返回结果。

## 解题思路

遍历 `key` 按首次出现顺序收集 26 个字母，构建解密映射数组（大小为 26）。再遍历 `message` 逐字符替换。

## Java 代码实现

```java
class Solution {
    public String decodeMessage(String key, String message) {
        char[] mapping = new char[26]; // mapping[密文字母-'a'] = 明文字母
        int idx = 0;
        for (char c : key.toCharArray()) {
            if (c != ' ' && mapping[c - 'a'] == 0) {
                mapping[c - 'a'] = (char) ('a' + idx); // 建立映射
                idx++;
                if (idx == 26) break;
            }
        }
        StringBuilder sb = new StringBuilder();
        for (char c : message.toCharArray()) {
            if (c == ' ') sb.append(' ');
            else sb.append(mapping[c - 'a']); // 查映射表解密
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(|key| + |message|)
- **空间复杂度**：O(1)（映射表固定 26 个字符）

## 关键点总结

1. 按 key 中字母**第一次出现**的顺序建立映射，不是按字母表顺序。
2. 空格保持不变，不参与映射。
3. 用数组替代哈希表，常数更小。
