## 题目描述

给定一个单词集合 `words`（没有重复），请找出并返回其中所有的单词方块。

单词序列 `[word1, word2, ..., wordk]` 满足以下条件即称为单词方块：
- `k` 是一个正整数
- `k == word1.length == word2.length == ... == wordk.length`
- 第 `k` 行和第 `k` 列的字符串完全相同

例如，单词序列 `["ball","area","lead","lady"]` 构成一个单词方块，因为每个单词长度都是 4，并且：
- 第 0 行和第 0 列都是 "ball"
- 第 1 行和第 1 列都是 "area"
- 第 2 行和第 2 列都是 "lead"
- 第 3 行和第 3 列都是 "lady"

**示例 1：**
```
输入：words = ["area","lead","wall","lady","ball"]
输出：[["ball","area","lead","lady"],["wall","area","lead","lady"]]
解释：
输出包含两个单词方块。
第一个：
b a l l
a r e a
l e a d
l a d y

第二个：
w a l l
a r e a
l e a d
l a d y
```

**示例 2：**
```
输入：words = ["abat","baba","atan","atal"]
输出：[["baba","abat","baba","atal"],["baba","abat","baba","atan"]]
解释：
输出包含两个单词方块。
第一个：
b a b a
a b a t
b a b a
a t a l

第二个：
b a b a
a b a t
b a b a
a t a n
```

**提示：**
- `1 <= words.length <= 1000`
- `1 <= words[i].length <= 4`
- 所有 `words[i]` 的长度相同
- `words[i]` 仅由小写英文字母组成
- 所有 `words[i]` 互不相同

## 解题思路

这道题需要找出所有可能的单词方块。核心思想是使用回溯 + 字典树剪枝。

**关键观察：**
1. 单词方块的性质：第 i 行的前缀 = 前 i 列的字符
2. 在构建第 i 行时，需要满足的前缀已经确定
3. 使用字典树可以快速找到具有指定前缀的所有单词

**算法流程：**
1. 构建字典树，存储所有单词
2. 对于字典树的每个节点，存储以该前缀开头的所有单词
3. 使用回溯法逐行构建单词方块：
   - 确定当前行需要的前缀（由前面已选择的单词决定）
   - 从字典树中找到所有符合前缀的候选单词
   - 尝试每个候选单词，继续递归
   - 如果成功构建 n 行，加入结果

## Java 代码实现

### 方法一：回溯 + 字典树 ⭐ 推荐

```java
import java.util.*;

class Solution {
    // 字典树节点
    static class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        List<String> words = new ArrayList<>();  // 存储以当前前缀开头的所有单词
    }

    private TrieNode root = new TrieNode();
    private int n;

    public List<List<String>> wordSquares(String[] words) {
        n = words[0].length();  // 单词长度

        // 将所有单词插入字典树
        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                node.children.putIfAbsent(c, new TrieNode());
                node = node.children.get(c);
                node.words.add(word);  // 记录以该前缀开头的单词
            }
        }

        List<List<String>> result = new ArrayList<>();
        List<String> square = new ArrayList<>();

        // 尝试以每个单词作为第一行
        for (String word : words) {
            square.add(word);
            backtrack(square, result);
            square.remove(square.size() - 1);
        }

        return result;
    }

    private List<String> getWordsWithPrefix(String prefix) {
        // 查找具有指定前缀的所有单词
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            if (!node.children.containsKey(c)) {
                return new ArrayList<>();
            }
            node = node.children.get(c);
        }
        return node.words;
    }

    private void backtrack(List<String> square, List<List<String>> result) {
        // 如果已经构建了 n 行，找到一个解
        if (square.size() == n) {
            result.add(new ArrayList<>(square));
            return;
        }

        // 确定下一行需要的前缀
        // 第 i 行的前缀 = 前 i 列的字符
        int pos = square.size();  // 当前要填充的行号
        StringBuilder prefix = new StringBuilder();
        for (String row : square) {
            prefix.append(row.charAt(pos));
        }

        // 获取所有符合前缀的候选单词
        List<String> candidates = getWordsWithPrefix(prefix.toString());

        // 尝试每个候选单词
        for (String word : candidates) {
            square.add(word);
            backtrack(square, result);
            square.remove(square.size() - 1);
        }
    }
}
```

### 方法二：回溯 + HashMap 优化

```java
import java.util.*;

class Solution {
    public List<List<String>> wordSquares(String[] words) {
        int n = words[0].length();

        // 构建前缀到单词的映射
        Map<String, List<String>> prefixMap = new HashMap<>();
        for (String word : words) {
            for (int i = 1; i <= word.length(); i++) {
                String prefix = word.substring(0, i);
                prefixMap.computeIfAbsent(prefix, k -> new ArrayList<>()).add(word);
            }
        }

        List<List<String>> result = new ArrayList<>();
        List<String> square = new ArrayList<>();

        // 尝试每个单词作为起始
        for (String word : words) {
            square.add(word);
            backtrack(square, n, prefixMap, result);
            square.remove(square.size() - 1);
        }

        return result;
    }

    private void backtrack(List<String> square, int n,
                           Map<String, List<String>> prefixMap,
                           List<List<String>> result) {
        if (square.size() == n) {
            result.add(new ArrayList<>(square));
            return;
        }

        // 计算需要的前缀
        int pos = square.size();
        StringBuilder prefix = new StringBuilder();
        for (String row : square) {
            prefix.append(row.charAt(pos));
        }

        // 获取候选单词
        List<String> candidates = prefixMap.getOrDefault(prefix.toString(), new ArrayList<>());
        for (String word : candidates) {
            square.add(word);
            backtrack(square, n, prefixMap, result);
            square.remove(square.size() - 1);
        }
    }
}
```

### 方法三：优化版（提前计算所有前缀）

```java
import java.util.*;

class Solution {
    public List<List<String>> wordSquares(String[] words) {
        if (words == null || words.length == 0) {
            return new ArrayList<>();
        }

        int n = words[0].length();

        // 为每个长度的前缀建立索引（包含空前缀）
        Map<String, List<String>> prefixDict = new HashMap<>();
        for (String word : words) {
            for (int i = 0; i < n; i++) {
                String prefix = word.substring(0, i);
                prefixDict.computeIfAbsent(prefix, k -> new ArrayList<>()).add(word);
            }
        }

        List<List<String>> result = new ArrayList<>();
        List<String> square = new ArrayList<>();

        for (String word : words) {
            square.add(word);
            backtrack(1, square, n, prefixDict, result);
            square.remove(square.size() - 1);
        }

        return result;
    }

    private void backtrack(int step, List<String> square, int n,
                           Map<String, List<String>> prefixDict,
                           List<List<String>> result) {
        if (step == n) {
            result.add(new ArrayList<>(square));
            return;
        }

        // 构建需要的前缀
        StringBuilder prefix = new StringBuilder();
        for (int i = 0; i < step; i++) {
            prefix.append(square.get(i).charAt(step));
        }

        // 尝试所有候选单词
        List<String> candidates = prefixDict.getOrDefault(prefix.toString(), new ArrayList<>());
        for (String word : candidates) {
            square.add(word);
            backtrack(step + 1, square, n, prefixDict, result);
            square.remove(square.size() - 1);
        }
    }
}
```

## 复杂度分析

**方法一：回溯 + 字典树**
- 时间复杂度：O(N × L × 26^L)，其中 N 是单词数量，L 是单词长度
  - 构建字典树：O(N × L)
  - 回溯：最坏情况下需要尝试所有可能的组合
  - 实际运行中，由于剪枝，复杂度远小于理论值
- 空间复杂度：O(N × L)，字典树和递归栈的空间

**方法二：哈希表**
- 时间复杂度：O(N × L + 结果数量 × L²)
- 空间复杂度：O(N × L)

## 关键点总结

1. **字典树应用**：使用字典树快速查找具有指定前缀的单词
2. **回溯剪枝**：通过前缀限制大幅减少搜索空间
3. **前缀计算**：第 i 行的前缀由前 i-1 行的第 i 列字符组成
4. **空间换时间**：在字典树节点中存储单词列表，避免重复搜索
5. **优化策略**：可以按单词频率排序，优先尝试更常见的单词

## 易错点

1. **前缀计算错误**：第 i 行的前缀是前面所有行的第 i 个字符
2. **边界检查**：需要检查前缀是否存在对应的单词
3. **结果复制**：加入结果时要复制列表，不能直接引用
4. **字典树构建**：每个节点都要存储以该前缀开头的所有单词
5. **回溯状态恢复**：记得在递归返回时恢复状态（remove 最后一个元素）
