## 题目描述

给你整数数组 `nums`，将其分割成若干子数组，使每个子数组的首尾元素 GCD 大于 1，返回最少子数组数目，若无法分割返回 -1。

## 解题思路

DP：`dp[i]` 表示将 `nums[0..i]` 有效分割的最少子数组数。枚举每个可能的子数组起点 `j`，若 `gcd(nums[j], nums[i]) > 1`，则 `dp[i] = min(dp[i], dp[j-1] + 1)`（j=0 时 dp[j-1]=0）。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int validSubarraySplit(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, Integer.MAX_VALUE);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= i; j++) {
                // 子数组 [j..i]，首元素 nums[j]，末元素 nums[i]
                if (gcd(nums[j], nums[i]) > 1) {
                    int prev = (j == 0) ? 0 : dp[j - 1];
                    if (prev != Integer.MAX_VALUE) {
                        dp[i] = Math.min(dp[i], prev + 1);
                    }
                }
            }
        }
        return dp[n - 1] == Integer.MAX_VALUE ? -1 : dp[n - 1];
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n² × log(maxVal))
- **空间复杂度**：O(n)

## 关键点总结

1. 有效子数组的条件：首尾元素 GCD > 1
2. 单个元素 `nums[i] > 1` 时可单独成一段
3. `nums[i] = 1` 的元素必须与其他元素组合
