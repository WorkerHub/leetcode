## 题目描述

给你一个整数数组 `nums` 和两个整数 `indexDiff` 和 `valueDiff`。

找出满足下述条件的下标对 `(i, j)`：

- `i != j`
- `abs(i - j) <= indexDiff`
- `abs(nums[i] - nums[j]) <= valueDiff`

如果存在，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0
输出：true
解释：可以找出 (i, j) = (0, 3)。
满足下述 3 个条件：
i != j --> 0 != 3
abs(i - j) <= indexDiff --> abs(0 - 3) <= 3
abs(nums[i] - nums[j]) <= valueDiff --> abs(1 - 1) <= 0
```

**示例 2：**

```
输入：nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3
输出：false
解释：尝试所有可能的下标对 (i, j)，都无法满足这 3 个条件，因此返回 false。
```

**提示：**

- `2 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `1 <= indexDiff <= nums.length`
- `0 <= valueDiff <= 10^9`

## 解题思路

这是"存在重复元素"系列的最难版本，需要同时满足索引差和值差的限制。

**核心思想：**

1. **滑动窗口**：维护大小为 `indexDiff` 的窗口
2. **桶排序思想**：将值域划分为大小为 `valueDiff + 1` 的桶
3. **桶内检查**：同一桶内的任意两个数，值差 <= valueDiff
4. **相邻桶检查**：相邻桶之间也可能满足值差条件

**算法流程（桶排序法）：**

1. 将值域划分为桶，桶的大小为 `valueDiff + 1`
2. 维护滑动窗口，窗口内的元素对应的桶存入 HashMap
3. 对于当前元素：
   - 计算它所在的桶号
   - 检查同一桶是否已有元素（必然满足值差）
   - 检查相邻桶是否有满足值差的元素
4. 将当前元素加入桶
5. 窗口移动时，移除最左边元素对应的桶

**Java 特别注意：** Java 的整数除法向零截断，而 Python 的 `//` 是向下取整，处理负数时需要特殊处理桶号计算。

## Java 代码实现

### 方法一：桶排序（推荐）⭐

```java
class Solution {
    public boolean containsNearbyAlmostDuplicate(int[] nums, int indexDiff, int valueDiff) {
        if (valueDiff < 0) return false;

        // 桶的大小（用 long 防止溢出）
        long bucketSize = (long) valueDiff + 1;
        Map<Long, Long> buckets = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            long num = (long) nums[i];
            long bucketId = getBucketId(num, bucketSize);

            // 检查同一桶（同桶内值差必然 <= valueDiff）
            if (buckets.containsKey(bucketId)) {
                return true;
            }

            // 检查左邻桶
            if (buckets.containsKey(bucketId - 1) &&
                Math.abs(num - buckets.get(bucketId - 1)) <= valueDiff) {
                return true;
            }

            // 检查右邻桶
            if (buckets.containsKey(bucketId + 1) &&
                Math.abs(num - buckets.get(bucketId + 1)) <= valueDiff) {
                return true;
            }

            // 加入当前桶
            buckets.put(bucketId, num);

            // 维护滑动窗口大小
            if (i >= indexDiff) {
                long oldNum = (long) nums[i - indexDiff];
                long oldBucketId = getBucketId(oldNum, bucketSize);
                buckets.remove(oldBucketId);
            }
        }

        return false;
    }

    /**
     * 计算桶号，正确处理负数（Java 整数除法向零截断，需要手动实现向下取整）
     * 例如：valueDiff=3，bucketSize=4
     * [0,3] -> 桶0, [4,7] -> 桶1, [-4,-1] -> 桶-1
     */
    private long getBucketId(long num, long bucketSize) {
        // Java 的 / 对负数向零截断，不同于 Python 的 // 向下取整
        // 需要特殊处理负数
        if (num >= 0) {
            return num / bucketSize;
        } else {
            // 例如：-1 / 4 在 Java 中 = 0，但我们需要 -1
            // 公式：(num + 1) / bucketSize - 1
            return (num + 1) / bucketSize - 1;
        }
    }
}
```

### 方法二：滑动窗口 + TreeSet（有序集合）

```java
class Solution {
    public boolean containsNearbyAlmostDuplicate(int[] nums, int indexDiff, int valueDiff) {
        // 使用 TreeSet 维护有序滑动窗口
        TreeSet<Long> window = new TreeSet<>();

        for (int i = 0; i < nums.length; i++) {
            long num = (long) nums[i];

            // 维护窗口大小
            if (i > indexDiff) {
                window.remove((long) nums[i - indexDiff - 1]);
            }

            // 在有序窗口中查找 [num - valueDiff, num + valueDiff] 范围的数
            // floor: 最大的 <= num + valueDiff 的数
            Long ceiling = window.ceiling(num - valueDiff);
            if (ceiling != null && ceiling <= num + valueDiff) {
                return true;
            }

            window.add(num);
        }

        return false;
    }
}
```

class Solution {

### 方法四：桶排序（详细注释版）

```java
class Solution {
    public boolean containsNearbyAlmostDuplicate(int[] nums, int indexDiff, int valueDiff) {
        /**
         * 桶排序思想：
         * 将数值范围划分为大小为 valueDiff + 1 的桶
         * 同一桶内的任意两个数，值差必然 <= valueDiff
         *
         * 注意 Java 与 Python 的区别：
         * Python: -1 // 4 = -1（向下取整）
         * Java:   -1 / 4 = 0（向零截断）
         * 所以 Java 需要特殊处理负数的桶号计算
         */
        if (valueDiff < 0) return false;

        long w = (long) valueDiff + 1; // 桶的大小
        Map<Long, Long> buckets = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            long num = (long) nums[i];
            // 计算桶号（正确处理负数）
            long bucketId = getBucketId(num, w);

            // 情况1：同一桶内已有元素
            // 桶大小 = valueDiff + 1，同桶元素值差必然 <= valueDiff
            if (buckets.containsKey(bucketId)) {
                return true;
            }

            // 情况2：检查左邻桶
            // 左邻桶最大值 < 当前桶最小值，差值可能仍在 valueDiff 内
            if (buckets.containsKey(bucketId - 1) &&
                Math.abs(num - buckets.get(bucketId - 1)) <= valueDiff) {
                return true;
            }

            // 情况3：检查右邻桶
            if (buckets.containsKey(bucketId + 1) &&
                Math.abs(num - buckets.get(bucketId + 1)) <= valueDiff) {
                return true;
            }

            // 将当前元素加入桶
            buckets.put(bucketId, num);

            // 维护滑动窗口
            // 当窗口大小超过 indexDiff 时，移除最左边的元素
            if (i >= indexDiff) {
                long oldNum = (long) nums[i - indexDiff];
                buckets.remove(getBucketId(oldNum, w));
            }
        }

        return false;
    }

    private long getBucketId(long num, long bucketSize) {
        // 向下取整的除法（处理负数）
        if (num >= 0) {
            return num / bucketSize;
        }
        // 将 num 映射到非负数后计算，再减去偏移
        // (num + 1) / bucketSize - 1 等价于 floor(num / bucketSize)
        return (num + 1) / bucketSize - 1;
    }
}
```

## 复杂度分析

**方法一（桶排序）：**

- **时间复杂度：** O(N)
  - 每个元素处理一次
  - 桶的操作（查找、插入、删除）都是 O(1)
- **空间复杂度：** O(min(N, indexDiff))
  - 窗口内最多 indexDiff 个桶

**方法二（TreeSet）：**

- **时间复杂度：** O(N log K)
  - K 是窗口大小 min(N, indexDiff)
  - 二分查找：O(log K)
- **空间复杂度：** O(min(N, indexDiff))

**方法三（暴力）：**

- **时间复杂度：** O(N × indexDiff)
- **空间复杂度：** O(1)

## 关键点总结

1. **桶排序思想**：将值域划分为固定大小的桶，同桶元素值差必然满足
2. **桶的大小**：`valueDiff + 1`，确保同桶元素值差 <= valueDiff
3. **相邻桶检查**：相邻桶的元素也可能满足条件
4. **滑动窗口**：维护索引差限制，超出窗口的桶及时移除
5. **Java 负数处理**：Java 除法向零截断，需要特殊处理桶号计算
6. **防溢出**：使用 `long` 类型，`nums[i]` 范围为 `[-10^9, 10^9]`，相减可能溢出 `int`

## 易错点

1. **桶的大小计算错误**：
   ```java
   // 错误：桶大小设为 valueDiff
   long bucketSize = valueDiff;
   // 正确：桶大小应该是 valueDiff + 1
   long bucketSize = (long) valueDiff + 1;
   ```

2. **Java 负数的桶号计算**：
   ```java
   // 错误：直接用 Java 的除法（向零截断）
   long bucketId = num / bucketSize; // -1 / 4 = 0，但应该是 -1
   // 正确：使用自定义函数处理负数
   long bucketId = getBucketId(num, bucketSize);
   ```

3. **相邻桶检查遗漏**：
   ```java
   // 错误：只检查同一桶
   if (buckets.containsKey(bucketId)) return true;
   // 正确：还要检查相邻桶
   if (buckets.containsKey(bucketId - 1) && ...) return true;
   if (buckets.containsKey(bucketId + 1) && ...) return true;
   ```

4. **整数溢出**：
   ```java
   // 错误：int 相减可能溢出
   if (Math.abs(nums[i] - buckets.get(bucketId - 1)) <= valueDiff)
   // 正确：使用 long
   if (Math.abs(num - buckets.get(bucketId - 1)) <= valueDiff) // num 是 long
   ```

5. **窗口边界错误**：
   ```java
   // 正确：当 i >= indexDiff 时，移除 i - indexDiff 位置的元素
   if (i >= indexDiff) {
       long oldBucketId = getBucketId((long) nums[i - indexDiff], w);
       buckets.remove(oldBucketId);
   }
   ```
