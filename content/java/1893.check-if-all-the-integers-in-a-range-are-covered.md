## 题目描述

给你区间数组 `ranges` 和整数 `left`、`right`，判断 `[left, right]` 内的每个整数是否都被至少一个区间覆盖。

## 解题思路

差分数组：对每个区间 `[s, e]` 做 `diff[s]++, diff[e+1]--`，前缀和得到每个位置的覆盖次数，检查 `[left, right]` 内是否都 >= 1。

## Java 代码实现

```java
class Solution {
    public boolean isCovered(int[][] ranges, int left, int right) {
        int[] diff = new int[52]; // 下标范围 1~51

        // 差分标记
        for (int[] range : ranges) {
            diff[range[0]]++;
            diff[range[1] + 1]--;
        }

        // 计算前缀和，检查覆盖情况
        int cover = 0;
        for (int i = 1; i <= 50; i++) {
            cover += diff[i];
            if (i >= left && i <= right && cover <= 0) {
                return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + 50)
- **空间复杂度**：O(50)

## 关键点总结

1. 差分数组适合区间覆盖统计：`diff[l]++, diff[r+1]--`，前缀和即覆盖次数
2. 数据范围小（1-50），暴力枚举也可行
3. 前缀和从小到大累积
