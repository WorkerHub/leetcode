## 题目描述

给你三个正整数 `a`、`b`、`c`，每次操作选两个非零整数各减 1，返回最大操作次数。

## 解题思路

数学贪心：若最大值 >= 另两个之和，则答案为另两个之和；否则答案为三数之和除以 2 下取整。

## Java 代码实现

```java
class Solution {
    public int maximumScore(int a, int b, int c) {
        // 排序令 a <= b <= c
        int[] arr = {a, b, c};
        java.util.Arrays.sort(arr);
        int x = arr[0], y = arr[1], z = arr[2];

        if (z >= x + y) {
            // 最大值过多，只能与其他两个配对
            return x + y;
        } else {
            // 可以均衡消耗，答案为总和一半
            return (x + y + z) / 2;
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 若最大值 >= 其他两数之和，答案受限于小两数之和
2. 否则总能消耗掉总和的一半（向下取整）
