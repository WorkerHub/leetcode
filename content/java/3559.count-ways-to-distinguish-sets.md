## 题目描述

给定整数 `n` 和 `k`，将 `1` 到 `n` 分成大小为 `k` 和 `n-k` 的两个有序集合，计算满足条件的有序对数量，对 `10^9 + 7` 取模。

## 解题思路

从 n 个元素中选 k 个放入集合 A（有序），其余放入集合 B（有序）。方案数 = `C(n, k) * k! * (n-k)! = n!`。

## Java 代码实现

```java
class Solution {
    public int countWays(int n, int k) {
        final int MOD = 1_000_000_007;
        // 计算 n!
        long result = 1;
        for (int i = 2; i <= n; i++)
            result = result * i % MOD;
        return (int) result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，计算阶乘
- 空间复杂度：O(1)

## 关键点总结

1. `C(n, k) * k! * (n-k)! = n!`
2. 两个有序集合的分法等价于 n 个元素的全排列
3. 注意对 `10^9 + 7` 取模
