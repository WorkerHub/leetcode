## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都 **围成一圈**，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **在不触动警报装置的情况下**，今晚能够偷窃到的最高金额。

**示例 1：**

```
输入：nums = [2,3,2]
输出：3
解释：你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2），因为他们是相邻的。
```

**示例 2：**

```
输入：nums = [1,2,3,1]
输出：4
解释：你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

**示例 3：**

```
输入：nums = [1,2,3]
输出：3
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 解题思路

这道题是 [198. 打家劫舍](https://leetcode.com/problems/house-robber/) 的进阶版，增加了"环形"约束。

**核心思想：**

房屋成环后，第一间和最后一间不能同时偷。因此可以分解为两个子问题：
1. **偷第一间房**：则不能偷最后一间，范围是 `[0, n-2]`
2. **不偷第一间房**：则可以偷最后一间，范围是 `[1, n-1]`

对这两个范围分别求解 [198. 打家劫舍] 的线性问题，取最大值即可。

**特殊情况：**
- 只有 1 间房：直接返回 `nums[0]`
- 只有 2 间房：返回 `max(nums[0], nums[1])`

**算法流程：**

1. 定义辅助函数 `robLinear(start, end)`：解决线性打家劫舍问题
2. 特殊情况处理：`n == 1` 直接返回
3. 分别计算：
   - `max1 = robLinear(0, n-2)`（不偷最后一间）
   - `max2 = robLinear(1, n-1)`（不偷第一间）
4. 返回 `max(max1, max2)`

## Java 代码实现

### 方法一：动态规划（推荐）⭐

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;

        // 特殊情况
        if (n == 1) return nums[0];
        if (n == 2) return Math.max(nums[0], nums[1]);

        // 情况1：偷第一间，不偷最后一间（范围 [0, n-2]）
        int max1 = robLinear(nums, 0, n - 2);
        // 情况2：不偷第一间，可以偷最后一间（范围 [1, n-1]）
        int max2 = robLinear(nums, 1, n - 1);

        return Math.max(max1, max2);
    }

    private int robLinear(int[] nums, int start, int end) {
        // 线性打家劫舍 DP（空间优化版）
        int prev2 = 0; // dp[i-2]
        int prev1 = 0; // dp[i-1]

        for (int i = start; i <= end; i++) {
            // dp[i] = max(dp[i-1], dp[i-2] + nums[i])
            int curr = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
}
```

### 方法二：DP 数组版（更直观）

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];

        // 两种情况取最大值
        return Math.max(robLinear(nums, 0, n - 2), robLinear(nums, 1, n - 1));
    }

    private int robLinear(int[] nums, int start, int end) {
        // 使用 DP 数组
        int len = end - start + 1;
        if (len == 0) return 0;
        if (len == 1) return nums[start];

        int[] dp = new int[len];
        dp[0] = nums[start];
        dp[1] = Math.max(nums[start], nums[start + 1]);

        for (int i = 2; i < len; i++) {
            // 偷当前房 or 不偷当前房
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[start + i]);
        }

        return dp[len - 1];
    }
}
```

### 方法三：递归 + 记忆化（理解用）

```java
class Solution {
    private int[] memo;
    private int[] nums;

    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];

        this.nums = nums;

        // 情况1：[0, n-2]
        memo = new int[n];
        Arrays.fill(memo, -1);
        int max1 = dp(0, n - 2);

        // 情况2：[1, n-1]
        memo = new int[n];
        Arrays.fill(memo, -1);
        int max2 = dp(1, n - 1);

        return Math.max(max1, max2);
    }

    private int dp(int i, int end) {
        // 从第 i 间房开始，范围到 end
        if (i > end) return 0;
        if (memo[i] != -1) return memo[i];

        // 偷当前房 or 不偷当前房
        memo[i] = Math.max(dp(i + 1, end), nums[i] + dp(i + 2, end));
        return memo[i];
    }
}
```

## 复杂度分析

**方法一（空间优化 DP）：**

- **时间复杂度：** O(N)，两次遍历数组
- **空间复杂度：** O(1)，只用常数变量

**方法二（DP 数组）：**

- **时间复杂度：** O(N)
- **空间复杂度：** O(N)，需要 DP 数组

**方法三（递归 + 记忆化）：**

- **时间复杂度：** O(N)
- **空间复杂度：** O(N)，递归栈 + 缓存

## 关键点总结

1. **环形问题线性化**：通过分情况讨论，将环形问题转化为两个线性问题
2. **状态转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
3. **空间优化**：只需保存前两个状态，无需完整 DP 数组
4. **边界处理**：注意 `n == 1` 和 `n == 2` 的特殊情况
5. **问题分解**：复杂约束通过拆分成简单子问题解决

## 易错点

1. **忘记处理 n=1 的情况**：
   ```java
   // 错误：直接分两种情况会导致范围错误
   return Math.max(robLinear(nums, 0, n - 2), robLinear(nums, 1, n - 1));
   // 正确：先判断特殊情况
   if (n == 1) return nums[0];
   ```

2. **范围理解错误**：
   ```java
   // 错误：两个范围都包含所有元素
   robLinear(nums, 0, n - 1); // 错误：包含了最后一间
   // 正确：第一种情况不包含最后一间
   robLinear(nums, 0, n - 2); // 正确
   ```

3. **初始值设置错误**：
   ```java
   // 错误：prev1, prev2 初始化为 nums[start]
   int prev2 = nums[start], prev1 = nums[start];
   // 正确：初始化为 0
   int prev2 = 0, prev1 = 0;
   ```

4. **Java 整数溢出**：题目数据范围在 `[0, 1000]`，最多 100 间房，总和不超过 100000，不需要使用 `long`

5. **逻辑混淆**：不要试图在同一个 DP 中处理环形约束，分开处理更清晰
