## 题目描述

给你等长字符串 `s1` 和 `s2`，对其中一个字符串执行最多一次字符串交换（选两个下标互换字符）后能否使两者相等，返回 `true` 或 `false`。

## 解题思路

找出所有不相同的位置列表 `diff`：
- `diff` 为空：已相等，返回 `true`
- `diff` 长度为 2：检查交叉是否匹配，即 `s1[i]==s2[j]` 且 `s1[j]==s2[i]`
- 其他长度：返回 `false`

## Java 代码实现

```java
class Solution {
    public boolean areAlmostEqual(String s1, String s2) {
        int n = s1.length();
        int[] diff = new int[2];
        int cnt = 0;

        for (int i = 0; i < n; i++) {
            if (s1.charAt(i) != s2.charAt(i)) {
                if (cnt >= 2) return false; // 超过两个差异位置
                diff[cnt++] = i;
            }
        }

        if (cnt == 0) return true; // 完全相同
        if (cnt == 1) return false; // 一次交换影响两个位置，无法修复 1 个差异

        // cnt == 2：检查交叉匹配
        int i = diff[0], j = diff[1];
        return s1.charAt(i) == s2.charAt(j) && s1.charAt(j) == s2.charAt(i);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 差异位置数只能是 0 或 2，才可能通过一次交换修复
2. 差异数为 2 时还需验证交叉匹配：`s1[i]==s2[j]` 且 `s1[j]==s2[i]`
