## 题目描述

给你数字 `k`，请你返回和为 `k` 的斐波那契数字的最少数目，其中，每个斐波那契数字都可以被使用多次。

斐波那契数列定义如下：

- `F1 = 1`
- `F2 = 1`
- `Fn = Fn-1 + Fn-2`（n > 2）

数据保证对于给定的 `k`，一定能找到可行解。

**示例 1：**

```
输入：k = 7
输出：2
解释：斐波那契数列为 1, 1, 2, 3, 5, 8, 13, ...
     7 = 2 + 5
```

**示例 2：**

```
输入：k = 10
输出：2
解释：10 = 2 + 8
```

**示例 3：**

```
输入：k = 19
输出：3
解释：19 = 1 + 5 + 13
```

**提示：**

- `1 <= k <= 10^9`

## 解题思路

### 贪心策略：每次取不超过 k 的最大斐波那契数

**为什么贪心有效？**

斐波那契数列有一个重要性质（Zeckendorf 定理）：任何正整数都可以唯一表示为若干个不连续的斐波那契数之和（每个斐波那契数最多用一次）。

贪心算法：每次取不超过 k 的最大斐波那契数，然后 k 减去该数，重复直到 k = 0。

这类似于零钱兑换问题，但斐波那契数有特殊结构，使得贪心算法最优（不像普通面值的硬币需要 DP）。

### 算法步骤

1. 预先生成所有不超过 k 的斐波那契数
2. 从最大的斐波那契数开始贪心选取
3. 每次减去能用的最大斐波那契数，计数 +1
4. 重复直到 k = 0

## Java 代码实现

### 方法一：贪心（推荐）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int findMinFibonacciNumbers(int k) {
        // 生成所有不超过 k 的斐波那契数
        List<Integer> fibs = new ArrayList<>();
        int a = 1, b = 1;
        fibs.add(a);
        fibs.add(b);
        while (a + b <= k) {
            int c = a + b;
            fibs.add(c);
            a = b;
            b = c;
        }

        // 贪心：每次取不超过 k 的最大斐波那契数
        int count = 0;
        int idx = fibs.size() - 1;
        while (k > 0) {
            // 找最大的不超过 k 的斐波那契数
            while (fibs.get(idx) > k) {
                idx--;
            }
            k -= fibs.get(idx);
            count++;
        }

        return count;
    }
}
```

### 方法二：贪心（简化版，每次重新查找）

```java
class Solution {
    public int findMinFibonacciNumbers(int k) {
        int count = 0;
        while (k > 0) {
            // 找最大的不超过 k 的斐波那契数
            int fib = largestFib(k);
            k -= fib;
            count++;
        }
        return count;
    }

    // 找最大的不超过 n 的斐波那契数
    private int largestFib(int n) {
        int a = 1, b = 1;
        while (b <= n) {
            int c = a + b;
            a = b;
            b = c;
        }
        return a;  // 返回 a，因为此时 b > n
    }
}
```

## 复杂度分析

设 `k <= 10^9`，斐波那契数列在 10^9 以内约有 44 个数。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 贪心 | O(log^2 k) | O(log k) |
| 简化贪心 | O(log^2 k) | O(1) |

注：贪心步数最多约 O(log k) 次（每步至少减去约一半），每次找最大斐波那契数 O(log k)。

## 关键点总结

1. 贪心策略：每次取不超过 k 的**最大**斐波那契数
2. 贪心有效性基于 Zeckendorf 定理：每个正整数可以唯一表示为不连续斐波那契数之和
3. 10^9 以内斐波那契数最多 44 个，步数非常少
4. 不需要 DP，贪心直接得到最优解

## 易错点

1. 斐波那契数列从 F1=1, F2=1 开始，注意不要漏掉重复的 1
2. 生成斐波那契数时注意终止条件：`a + b <= k`
3. 不要误以为这是零钱兑换（需要DP），斐波那契数的特殊结构使贪心有效

## 图解示例

以 `k = 19` 为例：

```
斐波那契数列：1, 1, 2, 3, 5, 8, 13, 21, ...
不超过 19 的最大值：13
k = 19 - 13 = 6，计数 = 1

不超过 6 的最大值：5
k = 6 - 5 = 1，计数 = 2

不超过 1 的最大值：1
k = 1 - 1 = 0，计数 = 3

答案：3（13 + 5 + 1 = 19）
```
