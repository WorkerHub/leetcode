## 题目描述

给你长度 n 的整数数组 nums 和正整数 k，若子序列之和等于 k 则其幂为 `2^(n - 子序列长度)`，返回所有非空子序列幂之和对 10^9+7 取模。

## 解题思路

DP 按大小分层统计和为 k 的子序列数：`dp[j][sum]` 为大小为 j、和为 sum 的子序列数；答案为 `sum(dp[j][k] * 2^(n-j))`（n <= 15 保证可行）。

## Java 代码实现

```java
class Solution {
    public int sumOfPower(int[] nums, int k) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        // dp[j] 表示大小为 j 的子序列的和的计数（哈希表）
        Map<Integer, Long>[] dp = new HashMap[n + 1];
        for (int i = 0; i <= n; i++) dp[i] = new HashMap<>();
        dp[0].put(0, 1L);

        for (int num : nums) {
            // 倒序更新避免重复选同一元素
            for (int j = Math.min(n - 1, n); j >= 0; j--) {
                for (Map.Entry<Integer, Long> e : dp[j].entrySet()) {
                    int newSum = e.getKey() + num;
                    dp[j + 1].merge(newSum, e.getValue(), (a, b) -> (a + b) % MOD);
                }
            }
        }

        long ans = 0;
        for (int j = 1; j <= n; j++) {
            Long cnt = dp[j].get(k);
            if (cnt != null) {
                ans = (ans + cnt % MOD * pow(2, n - j, MOD)) % MOD;
            }
        }
        return (int) ans;
    }

    private long pow(long base, int exp, int mod) {
        long result = 1;
        base %= mod;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2 * k)，n <= 15
- **空间复杂度**：O(n * k)

## 关键点总结

1. 问题转化：幂之和 = 统计每种大小的和为 k 的子序列数，乘以 `2^(n-j)`
2. DP 按大小分层，倒序更新避免重复选元素
3. n <= 15 保证状态数有限
