## 题目描述

给你一个二维整数数组 `envelopes`，其中 `envelopes[i] = [wi, hi]`，表示第 `i` 个信封的宽度和高度。

当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里，如同俄罗斯套娃一样。

请计算最多能有多少个信封能组成一组"俄罗斯套娃"信封（即可以把一个信封放到另一个信封里面）。

注意：不允许旋转信封。

**示例 1：**
```
输入：envelopes = [[5,4],[6,4],[6,7],[2,3]]
输出：3
解释：最多信封的个数为 3, 组合为: [2,3] => [5,4] => [6,7]。
```

**示例 2：**
```
输入：envelopes = [[1,1],[1,1],[1,1]]
输出：1
```

**提示：**
- `1 <= envelopes.length <= 10^5`
- `envelopes[i].length == 2`
- `1 <= wi, hi <= 10^5`

## 解题思路

这道题是 [300. 最长递增子序列](https://leetcode.com/problems/longest-increasing-subsequence/) 的二维版本。

**核心思想：**
1. 按宽度升序排序，宽度相同时按高度降序排序
2. 在高度上求最长递增子序列（LIS）

**为什么宽度相同时高度降序？**
- 避免宽度相同的信封被同时选中
- 例如 `[[3,3], [3,4]]`，如果都按升序，会错误地认为可以嵌套

## Java 代码实现

### 方法一：排序 + DP（O(n²)）

```java
import java.util.Arrays;

class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        // 按宽度升序，宽度相同时高度降序
        Arrays.sort(envelopes, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);

        int n = envelopes.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                // 严格递增（不能有等号）
                if (envelopes[j][1] < envelopes[i][1]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
        }

        int max = 0;
        for (int v : dp) max = Math.max(max, v);
        return max;
    }
}
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

### 方法二：排序 + 二分（O(n log n)）⭐

```java
import java.util.Arrays;
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        // 排序：宽度升序，宽度相同时高度降序
        Arrays.sort(envelopes, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);

        // 提取高度数组
        int n = envelopes.length;
        int[] heights = new int[n];
        for (int i = 0; i < n; i++) {
            heights[i] = envelopes[i][1];
        }

        // 二分法求 LIS
        List<Integer> tails = new ArrayList<>();

        for (int h : heights) {
            // 找到第一个 >= h 的位置（lower_bound）
            int left = 0, right = tails.size();
            while (left < right) {
                int mid = (left + right) / 2;
                if (tails.get(mid) < h) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            if (left == tails.size()) {
                // 比所有元素都大，追加
                tails.add(h);
            } else {
                // 替换第一个 >= h 的元素
                tails.set(left, h);
            }
        }

        return tails.size();
    }
}
```

**时间复杂度：** O(n log n)
**空间复杂度：** O(n)

```
            宽度相同，高度降序

提取高度：[3, 4, 7, 4]

求 LIS：
tails = []
h=3: tails = [3]

```

## 关键点总结

1. **排序策略**：宽度升序，高度降序
2. **降维**：转化为一维 LIS 问题
3. **二分优化**：O(n log n) 求 LIS
4. **避免重复**：高度降序防止宽度相同的信封被选中

## 易错点

1. **排序方式**
   ```java
   // 错误：都升序
   Arrays.sort(envelopes);

   // 正确：宽度升序，高度降序
   Arrays.sort(envelopes, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);
   ```

2. **LIS 判断条件**
   ```java
   // 要严格递增
   if (envelopes[j][1] < envelopes[i][1])  // 不能有等号
   ```
