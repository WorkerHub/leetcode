## 题目描述

字母板 5×5+1 布局（a-y 在 5 行，z 单独在第 6 行第 0 列）。从 (0,0) 出发，用 U/D/L/R 移动，! 选取字符。返回拼出 target 的最短指令序列。

**示例：**
```
输入：target = "leet"
输出："DDR!UURRR!!DDD!"
```

## 解题思路

每个字符坐标：行 = (ch-'a')/5，列 = (ch-'a')%5。关键：'z' 在 (5,0) 右侧无格子。移动顺序：先左移/上移，再下移/右移，可安全处理 z。

## Java 代码实现

```java
class Solution {
    public String alphabetBoardPath(String target) {
        StringBuilder sb = new StringBuilder();
        int curRow = 0, curCol = 0;

        for (char ch : target.toCharArray()) {
            int targetRow = (ch - 'a') / 5;
            int targetCol = (ch - 'a') % 5;

            // 先左移、上移（安全离开 z 区域）
            while (curCol > targetCol) { sb.append('L'); curCol--; }
            while (curRow > targetRow) { sb.append('U'); curRow--; }
            // 再下移、右移（安全进入 z 区域）
            while (curRow < targetRow) { sb.append('D'); curRow++; }
            while (curCol < targetCol) { sb.append('R'); curCol++; }

            sb.append('!');
        }

        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)，n 为 target 长度（每字符最多移动常数步）
- **空间复杂度**：O(n)，结果字符串

## 关键点总结

1. **坐标公式**：行 = (ch-'a')/5，列 = (ch-'a')%5
2. **移动顺序**：先 L/U 再 D/R，避免进入 z 右侧无效区域
3. **z 的特殊性**：(5,0) 右侧无格子，不能先右移再下移到 z
