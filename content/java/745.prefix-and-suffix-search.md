## 题目描述

设计一个词典，支持通过前缀和后缀检索单词。返回同时满足前缀和后缀条件的单词的最大下标。

**示例：**
```
WordFilter wordFilter = new WordFilter(["apple"]);
wordFilter.f("a", "e"); // 返回 0
```

## 解题思路

哈希表存储所有可能的 `{后缀}#{前缀}` 组合及其对应的最大索引。查询时直接构造 key 查找。

## Java 代码实现

```java
class WordFilter {
    private Map<String, Integer> map;

    public WordFilter(String[] words) {
        map = new HashMap<>();
        for (int idx = 0; idx < words.length; idx++) {
            String word = words[idx];
            int len = word.length();
            // 枚举所有前缀和后缀组合
            for (int i = 0; i <= len; i++) {
                for (int j = 0; j <= len; j++) {
                    String key = word.substring(i) + "#" + word.substring(0, j);
                    map.put(key, idx);
                }
            }
        }
    }

    public int f(String pref, String suff) {
        return map.getOrDefault(suff + "#" + pref, -1);
    }
}
```

## 复杂度分析

- **初始化时间**：O(N × L³)
- **查询时间**：O(L)
- **空间复杂度**：O(N × L³)

## 关键点总结

1. **组合键**：`{后缀}#{前缀}` 作为唯一标识
2. **分隔符**：用 `#` 避免前后缀拼接歧义
3. **索引覆盖**：相同 key 自动保留最大索引
