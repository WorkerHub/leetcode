## 题目描述

给你二叉树根节点 `root` 和两个节点值 `p`、`q`，返回这两个节点之间边的数目（距离）。

## 解题思路

找到 `p` 和 `q` 的最近公共祖先（LCA），距离 = LCA 到 `p` 的深度 + LCA 到 `q` 的深度。

## Java 代码实现

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

class Solution {
    public int findDistance(TreeNode root, int p, int q) {
        TreeNode lca = findLCA(root, p, q);
        return depth(lca, p, 0) + depth(lca, q, 0);
    }

    // 找最近公共祖先
    private TreeNode findLCA(TreeNode node, int p, int q) {
        if (node == null) return null;
        if (node.val == p || node.val == q) return node;
        TreeNode left = findLCA(node.left, p, q);
        TreeNode right = findLCA(node.right, p, q);
        if (left != null && right != null) return node; // 当前节点是 LCA
        return left != null ? left : right;
    }

    // 从 node 出发找目标节点的深度
    private int depth(TreeNode node, int target, int d) {
        if (node == null) return -1;
        if (node.val == target) return d;
        int left = depth(node.left, target, d + 1);
        if (left != -1) return left;
        return depth(node.right, target, d + 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)，递归栈

## 关键点总结

1. LCA 法：距离 = LCA 到 p 的距离 + LCA 到 q 的距离
2. p 或 q 可能是另一个的祖先，此时 LCA 即为较浅的那个
