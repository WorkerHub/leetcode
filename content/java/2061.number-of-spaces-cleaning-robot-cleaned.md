## 题目描述

清洁机器人从 (0,0) 出发朝右，遇到障碍物或边界时向右转 90 度，进入循环时停止，返回清洁的空地数目。

## 解题思路

模拟机器人运动，用 `(r, c, d)` 状态集合检测循环，状态重复时停止。

## Java 代码实现

### 方法一：模拟（推荐）

```java
import java.util.*;

class Solution {
    public int numberOfCleanRooms(int[][] room) {
        int m = room.length, n = room[0].length;
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}; // 右下左上
        int r = 0, c = 0, d = 0;
        Set<Integer> cleaned = new HashSet<>();
        Set<Integer> visited = new HashSet<>(); // 状态 (r, c, d) 编码

        while (true) {
            int state = (r * n + c) * 4 + d;
            if (!visited.add(state)) break; // 已访问，进入循环
            cleaned.add(r * n + c);
            int nr = r + dirs[d][0], nc = c + dirs[d][1];
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && room[nr][nc] == 0) {
                r = nr; c = nc;
            } else {
                d = (d + 1) % 4; // 向右转
            }
        }
        return cleaned.size();
    }
}
```

## 复杂度分析

- 时间复杂度：O(m * n * 4)
- 空间复杂度：O(m * n)

## 关键点总结

1. 状态 (r, c, d) 重复则进入循环，停止
2. 遇到障碍物或边界时原地向右转，不移动
