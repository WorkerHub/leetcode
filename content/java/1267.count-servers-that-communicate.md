## 题目描述

m×n 网格，grid[i][j]=1 表示有服务器。同行或同列的服务器可通信。统计能与至少一台其他服务器通信的服务器数量。

**示例：**
```
输入：grid = [[1,0],[1,1]]
输出：3
```

## 解题思路

统计每行每列的服务器数量，若某服务器所在行或列有 >1 台服务器，则它能通信。

## Java 代码实现

```java
class Solution {
    public int countServers(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] rowCount = new int[m];
        int[] colCount = new int[n];
        
        // 统计每行每列服务器数量
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    rowCount[i]++;
                    colCount[j]++;
                }
            }
        }
        
        // 能通信的服务器：所在行或列有多于1台
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1 && (rowCount[i] > 1 || colCount[j] > 1)) {
                    count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m + n)

## 关键点总结

1. **行列计数**：先统计每行每列的服务器数
2. **通信条件**：行或列数量 > 1 即能通信
3. **两次遍历**：第一次计数，第二次判断
