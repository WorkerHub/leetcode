## 题目描述

给定二维点集（n<=10），求覆盖所有点所需的最少直线数量。

## 解题思路

位DP：预处理所有两点确定的直线及其覆盖掩码，dp[mask]表示覆盖点集mask的最少直线数。每次选覆盖最低未覆盖点的直线。

## Java 代码实现

```java
class Solution {
    public int minimumLines(int[][] points) {
        int n = points.length;
        if (n <= 2) return 1;
        
        // 预处理所有直线覆盖的点集
        List<Integer> lineMasks = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int mask = 0;
                for (int k = 0; k < n; k++) {
                    // 共线判断：叉积为0
                    int dx1 = points[j][0] - points[i][0];
                    int dy1 = points[j][1] - points[i][1];
                    int dx2 = points[k][0] - points[i][0];
                    int dy2 = points[k][1] - points[i][1];
                    if (dy1 * dx2 == dy2 * dx1) {
                        mask |= 1 << k;
                    }
                }
                lineMasks.add(mask);
            }
        }
        
        int full = (1 << n) - 1;
        int[] dp = new int[full + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        
        for (int mask = 0; mask < full; mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            // 找最低未覆盖的点
            int lowest = -1;
            for (int b = 0; b < n; b++) {
                if ((mask >> b & 1) == 0) {
                    lowest = b;
                    break;
                }
            }
            // 枚举覆盖lowest的直线
            for (int lm : lineMasks) {
                if ((lm >> lowest & 1) == 1) {
                    int newMask = mask | lm;
                    dp[newMask] = Math.min(dp[newMask], dp[mask] + 1);
                }
            }
        }
        return dp[full];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(2^N * N^2)
- **空间复杂度**：O(2^N)

## 关键点总结

1. **共线判断用叉积**：避免除法和浮点误差
2. **位DP覆盖问题**：每次选覆盖最低未覆盖点的直线，避免重复搜索
3. **n<=10**：2^10=1024，状态空间可接受
