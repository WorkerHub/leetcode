## 题目描述

n 个骰子每个有 k 面（1~k），返回投出总和为 target 的方式数，对 10^9+7 取模。

**示例：**
```
输入：n = 2, k = 6, target = 7
输出：6（1+6, 2+5, 3+4, 4+3, 5+2, 6+1）
```

## 解题思路

DP：`dp[i][j]` = 用 i 个骰子得到和 j 的方法数。转移：`dp[i][j] = sum(dp[i-1][j-face])`，face 从 1 到 k。用滚动数组优化空间。

## Java 代码实现

```java
class Solution {
    public int numRollsToTarget(int n, int k, int target) {
        int MOD = 1_000_000_007;
        if (target < n || target > n * k) return 0;

        // 滚动数组：dp[j] = 用当前骰子数得到和 j 的方法数
        int[] dp = new int[target + 1];
        dp[0] = 1;

        for (int i = 1; i <= n; i++) {
            int[] newDp = new int[target + 1];
            for (int j = i; j <= Math.min(target, i * k); j++) {
                // 枚举当前骰子点数
                for (int face = 1; face <= k && face <= j; face++) {
                    newDp[j] = (newDp[j] + dp[j - face]) % MOD;
                }
            }
            dp = newDp;
        }

        return dp[target];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * target * k)
- **空间复杂度**：O(target)

## 关键点总结

1. **状态定义**：`dp[i][j]` 用 i 个骰子凑和 j 的方法数
2. **状态转移**：枚举当前骰子点数 1~k
3. **取模**：每次加法后取模防溢出
4. **滚动数组**：只需上一层结果，用 newDp 避免覆盖
5. **边界剪枝**：target < n 或 target > n*k 时直接返回 0
