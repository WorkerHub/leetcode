## 题目描述

**斐波那契数**（通常用 `F(n)` 表示）形成的序列称为**斐波那契数列**。该数列由 `0` 和 `1` 开始，后面的每一项数字都是前面两项数字的和。也就是：

```
F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1
```

给定 `n`，计算 `F(n)`。

**示例 1：**
```
输入：n = 2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1
```

**示例 2：**
```
输入：n = 3
输出：2
解释：F(3) = F(2) + F(1) = 1 + 1 = 2
```

**示例 3：**
```
输入：n = 4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3
```

**提示：**
- `0 <= n <= 30`

## 解题思路

斐波那契数列是算法学习的经典问题，有多种解法，从简单到优化，每种都有其教学意义。

### 核心思想：
1. **递归**：直接根据定义实现，但会重复计算
2. **记忆化**：缓存已计算的结果，避免重复
3. **动态规划**：自底向上计算，空间优化
4. **数学公式**：通项公式（Binet公式）
5. **矩阵快速幂**：O(log n) 时间复杂度

### 解法对比：
| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 递归 | O(2^n) | O(n) | 简单但低效 |
| 记忆化 | O(n) | O(n) | 递归 + 缓存 |
| DP（数组） | O(n) | O(n) | 迭代实现 |
| DP（优化） | O(n) | O(1) | 只保留两个变量 |
| 矩阵快速幂 | O(log n) | O(1) | 最优但复杂 |

## Java 代码实现

### 方法一：递归（不推荐，仅供理解）

```java
class Solution {
    public int fib(int n) {
        // 朴素递归，会超时
        // 时间复杂度：O(2^n)，空间复杂度：O(n)
        if (n <= 1) return n;
        return fib(n - 1) + fib(n - 2);
    }
}
```

### 方法二：记忆化递归

```java
import java.util.*;

class Solution {
    private Map<Integer, Integer> memo = new HashMap<>();

    public int fib(int n) {
        // 递归 + 缓存，避免重复计算
        // 时间复杂度：O(n)，空间复杂度：O(n)
        if (n <= 1) return n;
        if (memo.containsKey(n)) return memo.get(n);

        int result = fib(n - 1) + fib(n - 2);
        memo.put(n, result);
        return result;
    }
}
```

### 方法三：动态规划（数组）

```java
class Solution {
    public int fib(int n) {
        // 自底向上的动态规划
        // 时间复杂度：O(n)，空间复杂度：O(n)
        if (n <= 1) return n;

        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
}
```

### 方法四：动态规划（空间优化）⭐推荐

```java
class Solution {
    public int fib(int n) {
        // 空间优化的 DP，只保留前两个值
        // 时间复杂度：O(n)，空间复杂度：O(1)
        if (n <= 1) return n;

        // prev2 = F(i-2), prev1 = F(i-1)
        int prev2 = 0, prev1 = 1;

        for (int i = 2; i <= n; i++) {
            int current = prev1 + prev2;
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
```

### 方法五：矩阵快速幂（最优解）

```java
class Solution {
    public int fib(int n) {
        // 矩阵快速幂，O(log n) 时间
        // [[F(n+1), F(n)], [F(n), F(n-1)]] = [[1,1],[1,0]]^n
        // 时间复杂度：O(log n)，空间复杂度：O(1)
        if (n <= 1) return n;

        long[][] base = {{1, 1}, {1, 0}};
        long[][] result = matrixPower(base, n);
        return (int) result[0][1];
    }

    private long[][] matrixMultiply(long[][] a, long[][] b) {
        // 2x2 矩阵乘法
        return new long[][]{
            {a[0][0] * b[0][0] + a[0][1] * b[1][0],
             a[0][0] * b[0][1] + a[0][1] * b[1][1]},
            {a[1][0] * b[0][0] + a[1][1] * b[1][0],
             a[1][0] * b[0][1] + a[1][1] * b[1][1]}
        };
    }

    private long[][] matrixPower(long[][] mat, int n) {
        // 矩阵快速幂
        if (n == 1) return mat;
        if (n % 2 == 0) {
            long[][] half = matrixPower(mat, n / 2);
            return matrixMultiply(half, half);
        } else {
            return matrixMultiply(mat, matrixPower(mat, n - 1));
        }
    }
}
```

## 复杂度分析

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 递归 | O(2^n) | O(n) | 指数级，不可接受 |
| 记忆化 | O(n) | O(n) | 实用，易理解 |
| DP 数组 | O(n) | O(n) | 标准 DP |
| DP 优化 | O(n) | O(1) | **面试推荐** |
| 矩阵快速幂 | O(log n) | O(1) | 理论最优 |

## 关键点总结

1. **递归优化**：记忆化可以将 O(2^n) 优化到 O(n)
2. **空间优化**：只需保留前两个值，不需要整个数组
3. **边界条件**：F(0) = 0, F(1) = 1
4. **变量更新顺序**：必须先计算 current，再更新 prev2 和 prev1
5. **矩阵快速幂**：适合超大 n 的情况

## 易错点

1. **边界处理**：n = 0 和 n = 1 是特殊情况
2. **变量更新顺序**：要先算 current，再同步更新两个变量
3. **索引范围**：循环从 2 开始，到 n
4. **矩阵乘法**：注意矩阵乘法的顺序和实现
5. **整数溢出**：矩阵快速幂中使用 long 防止溢出

## 图解示例

```
F(5) 的递归树（朴素递归）：

                 F(5)
              /        \
          F(4)          F(3)
         /    \        /    \
      F(3)   F(2)   F(2)   F(1)
      / \    / \    / \
   F(2) F(1) F(1) F(0) F(1) F(0)
   / \
F(1) F(0)

可以看到 F(3), F(2) 等被重复计算多次！

---

动态规划（优化版）过程：

n = 0: return 0
n = 1: return 1
n = 2: prev2=0, prev1=1 → current=1 → prev2=1, prev1=1
n = 3: prev2=1, prev1=1 → current=2 → prev2=1, prev1=2
n = 4: prev2=1, prev1=2 → current=3 → prev2=2, prev1=3
n = 5: prev2=2, prev1=3 → current=5 → prev2=3, prev1=5

每个值只计算一次！
```
