## 题目描述

给你 n 节点无根树和代价数组 `cost`，对每个节点 v，在其中放置的硬币数等于子树内选最多 3 个节点代价乘积的最大值（子树节点数 < 3 则为 0），返回所有节点的结果数组。

## 解题思路

后序 DFS 遍历，每个节点保留子树中最大 3 个和最小 2 个代价值（共 5 个）。对每个节点取两种方案的最大值：最大 3 个乘积，或最大 1 个乘以最小 2 个（负负得正）。

## Java 代码实现

```java
class Solution {
    private List<Integer>[] graph;
    private int[] cost;
    private long[] result;

    public long[] placedCoins(int[][] edges, int[] cost) {
        int n = cost.length;
        this.cost = cost;
        this.result = new long[n];
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(e[1]);
            graph[e[1]].add(e[0]);
        }
        dfs(0, -1);
        return result;
    }

    private long[] dfs(int node, int parent) {
        long[] vals = {cost[node]};
        List<Long> subtree = new ArrayList<>();
        subtree.add((long) cost[node]);

        for (int child : graph[node]) {
            if (child == parent) continue;
            long[] childVals = dfs(child, node);
            for (long v : childVals) subtree.add(v);
        }

        Collections.sort(subtree);
        int sz = subtree.size();
        if (sz >= 3) {
            // 方案1：最大的 3 个
            long opt1 = subtree.get(sz-1) * subtree.get(sz-2) * subtree.get(sz-3);
            // 方案2：最大的 1 个 + 最小的 2 个（负负得正）
            long opt2 = subtree.get(sz-1) * subtree.get(0) * subtree.get(1);
            result[node] = Math.max(opt1, opt2);
        }

        // 只保留最大 3 个和最小 2 个（共至多 5 个）
        if (sz <= 5) {
            long[] ret = new long[sz];
            for (int i = 0; i < sz; i++) ret[i] = subtree.get(i);
            return ret;
        }
        return new long[]{subtree.get(0), subtree.get(1),
                          subtree.get(sz-3), subtree.get(sz-2), subtree.get(sz-1)};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 每个节点只需保留子树最大 3 个和最小 2 个值，减少合并代价
2. 两种方案取最大：最大 3 个乘积，或最大 1 个乘以最小 2 个
3. 子树节点数 < 3 时乘积为 0
