## 题目描述

给你整数 `n` 和 `t`，返回大于等于 `n` 的最小整数，使得其各位数字之积能被 `t` 整除。

## 解题思路

数据范围极小（n <= 100），从 n 开始逐个枚举，计算各位乘积，判断是否被 t 整除。含数字 0 的整数乘积为 0，可被任意 t 整除。

## Java 代码实现

```java
class Solution {
    public int smallestNumber(int n, int t) {
        for (int x = n; ; x++) {
            int prod = 1, tmp = x;
            while (tmp > 0) { prod *= tmp % 10; tmp /= 10; }
            if (prod % t == 0) return x;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(答案 - n)，数据范围小，极快
- 空间复杂度：O(1)

## 关键点总结

1. 含 0 的数字乘积为 0，`0 % t == 0` 恒成立
2. 从 n 开始（包含 n 本身）枚举
3. 数据范围小，暴力枚举即可
