## 题目描述

找长度为k的子数组中，包含至少m个不同值的子数组的最大元素之和。

## 解题思路

固定大小k的滑动窗口+HashMap记录频次。len(map)>=m时更新答案。

## Java 代码实现

```java
class Solution {
    public long maxSum(List<Integer> nums, int m, int k) {
        Map<Integer, Integer> cnt = new HashMap<>();
        long windowSum = 0;
        long ans = 0;

        for (int i = 0; i < nums.size(); i++) {
            // 加入右端
            int val = nums.get(i);
            cnt.merge(val, 1, Integer::sum);
            windowSum += val;

            // 移出左端
            if (i >= k) {
                int leftVal = nums.get(i - k);
                cnt.merge(leftVal, -1, Integer::sum);
                if (cnt.get(leftVal) == 0) cnt.remove(leftVal);
                windowSum -= leftVal;
            }

            // 窗口大小为k时检查
            if (i >= k - 1 && cnt.size() >= m) {
                ans = Math.max(ans, windowSum);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(K)

## 关键点总结

1. **固定窗口k+HashMap记录频次**
2. **频次为0时删除key**：保持size准确
3. **窗口达到k时才检查答案**
