## 题目描述

给定整数数组 `nums`（-1 表示障碍物），从下标 0 出发每次跳 1 步或 2 步，不能跳到障碍物，返回到达末尾的最少跳跃次数，不可达返回 -1。

## Java 代码实现

```java
class Solution {
    public int minimumJumps(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        int INF = Integer.MAX_VALUE / 2;
        java.util.Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int i = 1; i < n; i++) {
            if (nums[i] == -1) continue; // 障碍位置跳过
            if (i >= 1 && dp[i - 1] != INF) dp[i] = Math.min(dp[i], dp[i - 1] + 1);
            if (i >= 2 && dp[i - 2] != INF) dp[i] = Math.min(dp[i], dp[i - 2] + 1);
        }
        return dp[n - 1] == INF ? -1 : dp[n - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 障碍位置直接跳过，不更新 dp 值
2. dp[i] = min(dp[i-1], dp[i-2]) + 1（前驱可达时）
3. 返回值不可达时返回 -1
