## 题目描述

长度为 arrLen 的数组，指针从位置 0 开始，每步可左移、右移或不动。求恰好 steps 步后回到位置 0 的方案数（mod 10^9+7）。

**示例：**
```
输入：steps = 3, arrLen = 2
输出：4
```

## 解题思路

DP：dp[i][j] = 走 i 步后在位置 j 的方案数。关键优化：位置最远只能到 min(arrLen-1, steps/2)。

## Java 代码实现

```java
class Solution {
    public int numWays(int steps, int arrLen) {
        int MOD = 1_000_000_007;
        // 位置最远只能到 steps/2
        int maxPos = Math.min(arrLen - 1, steps / 2);
        
        // dp[j] = 当前步数下在位置 j 的方案数
        long[] dp = new long[maxPos + 1];
        dp[0] = 1;
        
        for (int i = 1; i <= steps; i++) {
            long[] newDp = new long[maxPos + 1];
            for (int j = 0; j <= maxPos; j++) {
                newDp[j] = dp[j]; // 不动
                if (j > 0) newDp[j] = (newDp[j] + dp[j - 1]) % MOD; // 从左来
                if (j < maxPos) newDp[j] = (newDp[j] + dp[j + 1]) % MOD; // 从右来
            }
            dp = newDp;
        }
        return (int) dp[0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(steps × min(arrLen, steps/2))
- **空间复杂度**：O(min(arrLen, steps/2))

## 关键点总结

1. **位置上界**：最远走 steps/2 步就必须回来
2. **滚动数组**：只需两层 dp
3. **三种转移**：从左、从右、不动
4. **取模**：每步累加时取模
