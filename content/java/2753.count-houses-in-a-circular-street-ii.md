## 题目描述

给你环形街道的 API（支持开/关门），在最多 `k` 次调用内（`k >= 2n`）统计房屋数量。

## Java 代码实现

```java
/**
 * // This is the Road's API interface.
 * interface Road {
 *     public void openDoor();
 *     public void closeDoor();
 *     public boolean isDoorOpen();
 *     public void moveToNextHouse();
 * }
 */
class Solution {
    public int houseCount(Road road, int k) {
        // 先用 k/2 步关闭所有经过的门，确保覆盖整圈
        for (int i = 0; i < k / 2; i++) {
            road.closeDoor();
            road.moveToNextHouse();
        }
        // 打开起始位置的门作为标记
        road.openDoor();
        int count = 0;
        road.moveToNextHouse();
        count++;
        // 移动直到再次遇到打开的门（起点）
        while (!road.isDoorOpen()) {
            road.moveToNextHouse();
            count++;
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，最多 k 次 API 调用
- 空间复杂度：O(1)

## 关键点总结

1. 先关门可以清除之前任意状态
2. 打开起点门后，移动计数直到再次遇到开着的门
