## 题目描述

给你整数数组 `nums`，找最小下标 i 使得 `nums[0..i]` 的乘积与 `nums[i+1..n-1]` 的乘积互质，不存在返回 -1。

## 解题思路

对每个质因数记录其在 nums 中最后出现的位置；从左扫描，维护左半部分所有质因数的最大"最后位置" maxLast，当 `maxLast <= i` 时即找到合法分割点。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findValidSplit(int[] nums) {
        int n = nums.length;
        Map<Integer, Integer> last = new HashMap<>();
        // 记录每个质因数最后出现的位置
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            for (int d = 2; (long) d * d <= x; d++) {
                if (x % d == 0) {
                    last.put(d, i);
                    while (x % d == 0) x /= d;
                }
            }
            if (x > 1) last.put(x, i);
        }
        // 从左扫描，维护必须延伸到的最远位置
        int maxLast = 0;
        for (int i = 0; i < n - 1; i++) {
            int x = nums[i];
            for (int d = 2; (long) d * d <= x; d++) {
                if (x % d == 0) {
                    maxLast = Math.max(maxLast, last.get(d));
                    while (x % d == 0) x /= d;
                }
            }
            if (x > 1) maxLast = Math.max(maxLast, last.get(x));
            if (maxLast <= i) return i;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n * sqrt(M))，M 为最大元素值
- **空间复杂度**：O(P)，P 为不同质因数数量

## 关键点总结

1. 分割点合法等价于左侧所有质因数不出现在右侧
2. 维护 maxLast = 左侧遇到的质因数最后位置的最大值
3. `maxLast <= i` 时所有质因数已完全落在左半部分
