## 题目描述

给你一个数字字符串 `s`，统计有多少个子字符串满足：子字符串代表的数字能被其最后一位数字整除。

## 解题思路

对每个末尾数字 d（1-9），维护以当前位置结尾、值 mod d = r 的子串数 `remCnt[d][r]`。当新字符 c 到来时，更新转移：旧余数 r -> 新余数 (r*10+c) mod d。当末尾字符为 d 时，累加 `remCnt[d][0]`。

## Java 代码实现

```java
class Solution {
    public long countSubstrings(String s) {
        int n = s.length();
        long ans = 0;

        // remCnt[d][r]：对数字 d，以当前位置结尾且值 mod d = r 的子串数
        long[][] remCnt = new long[10][10]; // d: 1-9, r: 0..d-1

        for (int j = 0; j < n; j++) {
            int c = s.charAt(j) - '0';
            // 从高 d 到低 d 更新，避免覆盖问题（实际上各 d 独立，可任意顺序）
            for (int d = 1; d <= 9; d++) {
                long[] newRem = new long[d];
                // 旧子串末尾加上字符 c
                for (int r = 0; r < d; r++) {
                    newRem[(r * 10 + c) % d] += remCnt[d][r];
                }
                // 加上只包含单个字符 c 的子串
                newRem[c % d] += 1;
                for (int r = 0; r < d; r++) {
                    remCnt[d][r] = newRem[r];
                }
            }
            // 统计末尾为 c（且 c != 0）的合法子串
            if (c != 0) {
                ans += remCnt[c][0];
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 81) = O(n)，每个字符更新 9 个 d，每个 d 最多 9 种余数
- 空间复杂度：O(1)

## 关键点总结

1. 对每个末尾数字 d，维护独立的余数状态数组
2. 转移：新来字符 c，旧余数 r -> 新余数 (r*10+c) mod d
3. 当末尾字符为 d 时，计数 remCnt[d][0]（整除的子串数）
