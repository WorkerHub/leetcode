## 题目描述

给你查询数组 `queries`（每个查询 `[l, r]`），将 x 变为 0 的操作是将 x 替换为 `floor(x/2)`，返回每个查询将区间 [l, r] 所有数变为 0 所需的最少操作总数。

## 解题思路

将 x 变为 0 需要的操作次数 = x 的二进制长度（`Integer.numberOfBits` 或 `32 - Integer.numberOfLeadingZeros`）。预处理前缀和，O(1) 回答每个区间查询。

## Java 代码实现

```java
class Solution {
    public long[] minOperations(int[][] queries) {
        int MAX = 1_000_001;
        long[] prefix = new long[MAX];
        for (int x = 1; x < MAX; x++) {
            // x 的二进制长度 = floor(log2(x)) + 1
            prefix[x] = prefix[x - 1] + (32 - Integer.numberOfLeadingZeros(x));
        }

        long[] result = new long[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            result[i] = prefix[r] - prefix[l - 1];
        }
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(M + q)，M = 10^6 为值域，q 为查询数量
- 空间复杂度：O(M)

## 关键点总结

1. x 变为 0 的操作次数 = x 的二进制位数 = `32 - Integer.numberOfLeadingZeros(x)`
2. 前缀和预处理，O(1) 回答区间和查询
3. 区间查询 = `prefix[r] - prefix[l-1]`
