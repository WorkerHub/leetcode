## 题目描述

按顺序完成 `tasks` 数组中的任务，相同类型任务之间需间隔至少 `space` 天，返回完成所有任务所需的最少天数。

## 解题思路

贪心模拟：维护哈希表记录每种任务上次完成的天数，处理每个任务时天数至少 +1，若上次完成天数 + space + 1 > 当前天数则跳到那天。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long taskSchedulerII(int[] tasks, int space) {
        Map<Integer, Long> lastDone = new HashMap<>();
        long day = 0;
        for (int task : tasks) {
            day++; // 至少过一天
            if (lastDone.containsKey(task)) {
                long earliest = lastDone.get(task) + space + 1; // 最早可完成该任务的天数
                if (day < earliest) day = earliest; // 等待
            }
            lastDone.put(task, day);
        }
        return day;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)，k 为不同任务类型数

## 关键点总结

1. 每处理一个任务，天数至少 +1；若同类任务间隔不足则直接跳到可完成的最早天数。
2. 间隔 `space` 意味着完成同类任务间隔至少 `space+1` 天。
3. 天数使用 `long` 防止大规模输入溢出。
