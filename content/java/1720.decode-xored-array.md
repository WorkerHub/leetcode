## 题目描述

已知 `encoded[i] = arr[i] XOR arr[i+1]` 和 `arr[0] = first`，返回原数组 `arr`。

## 解题思路

利用异或可逆性：`arr[i+1] = arr[i] XOR encoded[i]`，从 `arr[0] = first` 依次推出每个元素。

## Java 代码实现

```java
class Solution {
    public int[] decode(int[] encoded, int first) {
        int n = encoded.length + 1;
        int[] arr = new int[n];
        arr[0] = first;
        for (int i = 0; i < encoded.length; i++) {
            arr[i + 1] = arr[i] ^ encoded[i];
        }
        return arr;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. 异或可逆：`a ^ b = c` 则 `a ^ c = b`
2. 输出数组长度为 `encoded.length + 1`
