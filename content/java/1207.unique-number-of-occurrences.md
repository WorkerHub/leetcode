## 题目描述

给定整数数组 arr，如果数组中每个值的出现次数都是唯一的，则返回 true，否则返回 false。

**示例：**
```
输入：arr = [1,2,2,1,1,3]
输出：true（1出现3次，2出现2次，3出现1次，次数都不同）
```

## 解题思路

先用 HashMap 统计每个数字出现的次数，再用 HashSet 检查所有次数是否唯一（Set 大小等于 Map 大小）。

## Java 代码实现

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        // 统计频率
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : arr) {
            count.merge(num, 1, Integer::sum);
        }
        // 检查频率是否唯一
        Set<Integer> freqSet = new HashSet<>(count.values());
        return freqSet.size() == count.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **两步法**：先统计频率，再验证唯一性
2. **Set 去重**：Set 大小 == Map 大小 说明无重复频率
3. **merge 方法**：`count.merge(num, 1, Integer::sum)` 简洁统计
