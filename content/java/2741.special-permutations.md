## 题目描述

给你 `n` 个互不相同的正整数数组 `nums`，如果排列中每对相邻元素互相整除，则称为特殊排列，返回特殊排列的数目（对 `10^9 + 7` 取模）。

## Java 代码实现

```java
class Solution {
    public int specialPerm(int[] nums) {
        final int MOD = 1_000_000_007;
        int n = nums.length;
        int full = (1 << n) - 1;
        // dp[mask][i] = 已选集合为 mask，最后一个元素为 nums[i] 的方案数
        int[][] dp = new int[1 << n][n];
        for (int i = 0; i < n; i++) dp[1 << i][i] = 1;

        for (int mask = 1; mask < (1 << n); mask++) {
            for (int last = 0; last < n; last++) {
                if ((mask >> last & 1) == 0 || dp[mask][last] == 0) continue;
                // 枚举下一个元素
                for (int nxt = 0; nxt < n; nxt++) {
                    if ((mask >> nxt & 1) != 0) continue;
                    if (nums[nxt] % nums[last] == 0 || nums[last] % nums[nxt] == 0) {
                        dp[mask | (1 << nxt)][nxt] = (dp[mask | (1 << nxt)][nxt] + dp[mask][last]) % MOD;
                    }
                }
            }
        }
        long ans = 0;
        for (int v : dp[full]) ans += v;
        return (int) (ans % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n^2)
- 空间复杂度：O(2^n * n)

## 关键点总结

1. n <= 14，状压 DP 总状态 2^14 * 14 = 229376
2. 转移条件是相邻元素整除关系
3. 枚举最后一个元素的位置作为起点
