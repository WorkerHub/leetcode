## 题目描述

给你 n 个节点（0 到 n-1）的有权无向图和整数 `maxDistance`，选择关闭一些节点，使所有开放节点间最短路不超过 `maxDistance`，返回满足条件的方案数。

## 解题思路

n <= 10，枚举所有 2^n 个子集（开放节点集合）。预先对全图运行 Floyd-Warshall 算出所有节点对最短路，对每个子集检查开放节点对间的距离是否都不超过 maxDistance。

## Java 代码实现

```java
class Solution {
    public int numberOfSets(int n, int maxDistance, int[][] roads) {
        final int INF = Integer.MAX_VALUE / 2;
        int[][] dist = new int[n][n];
        // 初始化距离矩阵
        for (int[] row : dist) Arrays.fill(row, INF);
        for (int i = 0; i < n; i++) dist[i][i] = 0;
        for (int[] r : roads) {
            dist[r[0]][r[1]] = Math.min(dist[r[0]][r[1]], r[2]);
            dist[r[1]][r[0]] = Math.min(dist[r[1]][r[0]], r[2]);
        }

        // Floyd-Warshall 计算全图最短路
        for (int k = 0; k < n; k++)
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    if (dist[i][k] + dist[k][j] < dist[i][j])
                        dist[i][j] = dist[i][k] + dist[k][j];

        int ans = 0;
        // 枚举所有子集（开放节点集合）
        for (int mask = 0; mask < (1 << n); mask++) {
            boolean valid = true;
            outer:
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) == 0) continue;
                for (int j = i + 1; j < n; j++) {
                    if ((mask >> j & 1) == 0) continue;
                    if (dist[i][j] > maxDistance) { valid = false; break outer; }
                }
            }
            if (valid) ans++;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n³ + 2ⁿ × n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. n <= 10，2^10 = 1024 个子集，规模可接受
2. Floyd-Warshall 预计算全图最短路（允许经过关闭节点作为中间节点）
3. 空集合（无开放节点）也是有效方案
