## 题目描述

给定整数数组 `nums`，找出和最大的子数组，但子数组中不能包含连续的两个零。返回满足条件的子数组最大和（空子数组和为 0）。

## Java 代码实现

```java
class Solution {
    public int maxSubarraySum(int[] nums) {
        int ans = 0;
        int curSum = 0;
        boolean prevZero = false;

        for (int x : nums) {
            if (x == 0) {
                if (prevZero) {
                    // 连续两个零，子数组中断，重置
                    curSum = 0;
                }
                // 单个零可以包含在子数组中
                prevZero = true;
            } else {
                curSum += x;
                prevZero = false;
            }
            curSum = Math.max(curSum, 0); // 负数则舍弃（类似 Kadane）
            ans = Math.max(ans, curSum);
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 遇到连续两个零时当前子数组中断，重置和为 0
2. 单个零可以包含在子数组中
3. 类似 Kadane 算法，当和变负时重置
