## 题目描述

给定 n×n 矩阵（n <= 6），每次可交换相邻两个元素（水平或垂直），返回将矩阵转换为单位矩阵所需的最少操作次数。

## 解题思路

n 较小（n <= 6），使用 BFS 在状态空间上搜索最短路径。将矩阵展开为一维数组作为状态，用哈希表记录已访问状态，BFS 逐层扩展直到到达目标状态。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minCost(int[][] matrix) {
        int n = matrix.length;
        // 构建目标状态（单位矩阵展平）
        int[] target = new int[n * n];
        for (int i = 0; i < n; i++) target[i * n + i] = 1;
        String targetKey = Arrays.toString(target);

        // 构建起始状态
        int[] start = new int[n * n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                start[i * n + j] = matrix[i][j];
        String startKey = Arrays.toString(start);

        if (startKey.equals(targetKey)) return 0;

        // BFS 搜索最少交换次数
        Map<String, Integer> dist = new HashMap<>();
        Queue<int[]> queue = new LinkedList<>();
        dist.put(startKey, 0);
        queue.offer(start);

        int[][] dirs = {{0, 1}, {1, 0}};

        while (!queue.isEmpty()) {
            int[] state = queue.poll();
            int ops = dist.get(Arrays.toString(state));

            for (int r = 0; r < n; r++) {
                for (int c = 0; c < n; c++) {
                    for (int[] d : dirs) {
                        int nr = r + d[0], nc = c + d[1];
                        if (nr < n && nc < n) {
                            // 交换相邻元素 (r,c) 和 (nr,nc)
                            int[] newState = state.clone();
                            int tmp = newState[r * n + c];
                            newState[r * n + c] = newState[nr * n + nc];
                            newState[nr * n + nc] = tmp;
                            String key = Arrays.toString(newState);
                            if (!dist.containsKey(key)) {
                                if (key.equals(targetKey)) return ops + 1;
                                dist.put(key, ops + 1);
                                queue.offer(newState);
                            }
                        }
                    }
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：BFS 最坏 O(n^2 * (n^2)!)，实际因剪枝较快
- 空间复杂度：O((n^2)!)，状态空间

## 关键点总结

1. n <= 6 是暗示可以使用状态搜索（BFS/DFS + 记忆化）。
2. 曼哈顿距离是操作次数的下界。
3. 实际操作中元素互相影响，曼哈顿距离不等于实际操作数。
