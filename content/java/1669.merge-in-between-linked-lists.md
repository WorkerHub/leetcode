## 题目描述

将 `list1` 中下标 a 到 b（含端点）的节点删除，将 `list2` 插入到被删除节点的位置。

## 解题思路

找到 `list1` 中第 `a-1` 个节点（前驱）和第 `b+1` 个节点（后继），将前驱连到 `list2` 头，`list2` 尾连到后继。

## Java 代码实现

```java
class Solution {
    public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
        // 找到第 a-1 个节点（list2 的前驱）
        ListNode nodeA = list1;
        for (int i = 0; i < a - 1; i++) {
            nodeA = nodeA.next;
        }

        // 从 a-1 再走 b-a+2 步到达 b+1（后继）
        ListNode nodeB = nodeA;
        for (int i = 0; i < b - a + 2; i++) {
            nodeB = nodeB.next;
        }

        // 连接 list2
        nodeA.next = list2;

        // 找到 list2 的末尾
        ListNode tail = list2;
        while (tail.next != null) {
            tail = tail.next;
        }

        tail.next = nodeB;
        return list1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m + n)，m 为 list1 长度，n 为 list2 长度
- **空间复杂度**：O(1)

## 关键点总结

1. 找两个关键节点：第 a-1 个（前驱）和第 b+1 个（后继）
2. 从 a-1 再走 b-a+2 步到达 b+1
3. list2 末尾连接到后继节点
