## 题目描述

将所有产品分配给 n 个商店（每家只能分一种），最小化最大分配量（各商店最大分配量的最小值）。

## 解题思路

二分最大分配量 x，验证每种产品需要 `ceil(q/x)` 个商店，若总数 <= n 则合法，二分找最小合法 x。

## Java 代码实现

### 方法一：二分查找（推荐）

```java
class Solution {
    public int minimizedMaximum(int n, int[] quantities) {
        int lo = 1, hi = 0;
        for (int q : quantities) hi = Math.max(hi, q);

        while (lo < hi) {
            int mid = (lo + hi) / 2;
            long stores = 0;
            for (int q : quantities) stores += (q + mid - 1) / mid;
            if (stores <= n) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(m log V)
- 空间复杂度：O(1)

## 关键点总结

1. 二分最大分配量，具有单调性
2. 每种产品需要 `ceil(q/x) = (q+x-1)/x` 个商店
3. 总商店数用 long 防溢出
