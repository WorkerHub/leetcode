## 题目描述

给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。

这里的遵循指完全匹配，例如，`pattern` 里的每个字母和字符串 `s` 中的每个非空单词之间存在着双向连接的对应规律。

**示例 1:**

```
输入: pattern = "abba", s = "dog cat cat dog"
输出: true
```

**示例 2:**

```
输入: pattern = "abba", s = "dog cat cat fish"
输出: false
```

**示例 3:**

```
输入: pattern = "aaaa", s = "dog cat cat dog"
输出: false
```

**提示:**

- `1 <= pattern.length <= 300`
- `pattern` 只包含小写英文字母
- `1 <= s.length <= 3000`
- `s` 只包含小写英文字母和 `' '`
- `s` 不包含任何前导或尾随对空格
- `s` 中每个单词都被单个空格分隔

## 解题思路

这道题是同构字符串的变种，要求判断模式字符串和单词序列是否一一对应。核心是建立双向映射。

**核心思想：**

需要满足两个条件：
1. 每个字符唯一对应一个单词（字符 -> 单词）
2. 每个单词唯一对应一个字符（单词 -> 字符）

**关键观察：**

- `pattern = "abba"`, `s = "dog cat cat dog"` ✓
  - a -> dog, b -> cat, b -> cat, a -> dog
- `pattern = "abba"`, `s = "dog cat cat fish"` ✗
  - a -> dog, b -> cat, b -> cat, a -> fish（a 对应了两个不同单词）
- `pattern = "abba"`, `s = "dog dog dog dog"` ✗
  - a -> dog, b -> dog（两个不同字符对应同一个单词）

**算法思路：**

方法一：双哈希表
- 维护两个映射：charToWord 和 wordToChar
- 遍历时检查映射的一致性

方法二：单哈希表 + 集合
- 哈希表记录字符到单词的映射
- 集合记录已使用的单词

## Java 代码实现

### 方法一：双哈希表（推荐）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        // 双哈希表建立双向映射
        // 时间复杂度 O(n+m)，空间复杂度 O(n+m)
        String[] words = s.split(" ");

        // 长度不匹配直接返回 false
        if (pattern.length() != words.length) return false;

        Map<Character, String> charToWord = new HashMap<>(); // 字符 -> 单词
        Map<String, Character> wordToChar = new HashMap<>(); // 单词 -> 字符

        for (int i = 0; i < pattern.length(); i++) {
            char c = pattern.charAt(i);
            String word = words[i];

            // 检查字符到单词的映射
            if (charToWord.containsKey(c)) {
                if (!charToWord.get(c).equals(word)) return false;
            } else {
                charToWord.put(c, word);
            }

            // 检查单词到字符的映射
            if (wordToChar.containsKey(word)) {
                if (wordToChar.get(word) != c) return false;
            } else {
                wordToChar.put(word, c);
            }
        }

        return true;
    }
}
```

### 方法二：哈希表 + 集合

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        String[] words = s.split(" ");

        if (pattern.length() != words.length) return false;

        Map<Character, String> mapping = new HashMap<>(); // 字符 -> 单词
        Set<String> usedWords = new HashSet<>();          // 已使用的单词

        for (int i = 0; i < pattern.length(); i++) {
            char c = pattern.charAt(i);
            String word = words[i];

            if (mapping.containsKey(c)) {
                // 字符已映射，检查是否一致
                if (!mapping.get(c).equals(word)) return false;
            } else {
                // 字符未映射，检查单词是否被其他字符使用
                if (usedWords.contains(word)) return false;
                mapping.put(c, word);
                usedWords.add(word);
            }
        }

        return true;
    }
}
```

### 方法三：详细注释版（新手友好）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    /**
     * 判断字符串 s 是否遵循 pattern 的规律
     *
     * 要求：双向一一对应
     * - 每个字符唯一对应一个单词
     * - 每个单词唯一对应一个字符
     *
     * 示例：
     * pattern = "abba"
     * s = "dog cat cat dog"
     *
     * 建立映射：
     * a <-> dog
     * b <-> cat
     *
     * 验证：
     * a -> dog ✓
     * b -> cat ✓
     * b -> cat ✓
     * a -> dog ✓
     *
     * 返回 true
     */
    public boolean wordPattern(String pattern, String s) {
        // 按空格分割字符串
        String[] words = s.split(" ");

        // 长度必须相同
        if (pattern.length() != words.length) return false;

        // 双向映射
        Map<Character, String> charMap = new HashMap<>(); // 字符 -> 单词的映射
        Map<String, Character> wordMap = new HashMap<>(); // 单词 -> 字符的映射

        // 遍历每一对 (字符, 单词)
        for (int i = 0; i < pattern.length(); i++) {
            char c = pattern.charAt(i);
            String word = words[i];

            // 检查字符的映射
            if (charMap.containsKey(c)) {
                // 字符已经有映射，检查是否一致
                if (!charMap.get(c).equals(word)) {
                    return false;
                }
            } else {
                // 建立新映射
                charMap.put(c, word);
            }

            // 检查单词的映射
            if (wordMap.containsKey(word)) {
                // 单词已经有映射，检查是否一致
                if (wordMap.get(word) != c) {
                    return false;
                }
            } else {
                // 建立新映射
                wordMap.put(word, c);
            }
        }

        return true;
    }
}
```

### 方法四：简化双哈希表（优雅写法）

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        String[] words = s.split(" ");

        if (pattern.length() != words.length) return false;

        Map<Character, String> p2w = new HashMap<>();
        Map<String, Character> w2p = new HashMap<>();

        for (int i = 0; i < pattern.length(); i++) {
            char p = pattern.charAt(i);
            String w = words[i];

            // 检查两个方向的映射是否一致
            if ((p2w.containsKey(p) && !p2w.get(p).equals(w))
                    || (w2p.containsKey(w) && w2p.get(w) != p)) {
                return false;
            }

            p2w.put(p, w);
            w2p.put(w, p);
        }

        return true;
    }
}
```

## 复杂度分析

**方法一、二：哈希表**
- 时间复杂度：`O(n + m)` n 是 pattern 长度，m 是 s 长度
- 空间复杂度：`O(n)` 存储映射关系

## 关键点总结

1. **双向映射**：必须同时检查字符->单词和单词->字符两个方向
2. **长度检查**：pattern 和单词数量必须相等
3. **一一对应**：不能多对一，也不能一对多
4. **字符串分割**：使用 `split(" ")` 分割单词
5. **映射冲突**：发现不一致立即返回 false

## 易错点

1. **忘记双向检查**：只检查字符到单词的映射，忘记检查反向
2. **长度不检查**：直接开始遍历，可能导致索引越界
3. **字符串比较**：Java 中字符串比较要用 `.equals()` 而不是 `==`
4. **映射覆盖**：错误地允许映射被修改
5. **边界情况**：pattern 或 s 为空的情况
