## 题目描述

给你 n×n 的 LCP 矩阵，返回字典序最小的长度为 n 的字符串使其 LCP 矩阵与给定一致，若不存在返回 `""`。

## 解题思路

贪心构造：若 `lcp[i][j] > 0`（j < i），则 `word[i] = word[j]`，否则分配最小可用字母；构造后用 DP 逆序计算实际 LCP 并与给定矩阵对比验证。

## Java 代码实现

```java
class Solution {
    public String findTheString(int[][] lcp) {
        int n = lcp.length;
        char[] word = new char[n];
        char nextChar = 'a';

        // 贪心构造
        for (int i = 0; i < n; i++) {
            if (word[i] != 0) continue;
            if (nextChar > 'z') return "";
            word[i] = nextChar++;
            // lcp[i][j] > 0 说明 word[j] = word[i]
            for (int j = i + 1; j < n; j++) {
                if (lcp[i][j] > 0) word[j] = word[i];
            }
        }

        // 验证：DP 逆序计算实际 LCP
        int[][] real = new int[n + 1][n + 1];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                if (word[i] == word[j]) {
                    real[i][j] = real[i + 1][j + 1] + 1;
                } else {
                    real[i][j] = 0;
                }
                if (real[i][j] != lcp[i][j]) return "";
            }
        }
        return new String(word);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n²)

## 关键点总结

1. 贪心：`lcp[i][j] > 0` 传播字母赋值，字母不够用时返回 ""
2. 构造后必须验证，逆序 DP 计算实际 LCP
3. `real[i][j] = real[i+1][j+1] + 1` 当 `word[i] == word[j]`
