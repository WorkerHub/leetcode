## 题目描述

给你整数数组 `nums` 和整数 `k`，每次操作可删除最小元素，返回使所有剩余元素 >= k 的最少操作次数。

## 解题思路

统计 nums 中严格小于 k 的元素个数，即为必须删除的次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int count = 0;
        // 统计小于 k 的元素个数
        for (int x : nums) {
            if (x < k) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 只需统计小于 k 的元素个数（必须全部删除）
2. 条件是严格小于 k，等于 k 的元素满足条件无需删除
3. 不需要真正执行删除操作
