## 题目描述

母鸡和谷粒在数轴上，所有母鸡同时移动，每秒一步，求吃完所有谷粒的最短时间。

## 解题思路

二分答案+贪心验证：排序后，每只母鸡贪心吃最左边未吃谷粒，向左走再向右或反之取最优。

## Java 代码实现

```java
class Solution {
    public int minimumTime(int[] hens, int[] grains) {
        Arrays.sort(hens);
        Arrays.sort(grains);
        long lo = 0, hi = 2_000_000_000L;

        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (canEat(hens, grains, mid)) hi = mid;
            else lo = mid + 1;
        }
        return (int) lo;
    }

    private boolean canEat(int[] hens, int[] grains, long t) {
        int j = 0;
        for (int h : hens) {
            if (j >= grains.length) return true;
            if (grains[j] < h - t) return false;

            long right;
            if (grains[j] >= h) {
                // 谷粒在右边，直接走
                right = h + t;
            } else {
                // 谷粒在左边，需要绕路
                long leftDist = h - grains[j];
                // 先左后右 或 先右后左 取最远
                right = h + Math.max(t - 2 * leftDist, (t - leftDist) / 2);
            }
            // 二分找right右边界
            int lo2 = j, hi2 = grains.length;
            while (lo2 < hi2) {
                int mid2 = (lo2 + hi2) / 2;
                if (grains[mid2] <= right) lo2 = mid2 + 1;
                else hi2 = mid2;
            }
            j = lo2;
        }
        return j >= grains.length;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((N+M) * log(maxVal))
- **空间复杂度**：O(1)

## 关键点总结

1. **二分时间**：经典最小化答案
2. **绕路代价**：先走一侧再折回，距离翻倍
3. **贪心匹配**：每只母鸡吃最左边未处理的谷粒
