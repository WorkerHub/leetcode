## 题目描述

n×n 网格 grid 上叠放立方体（grid[i][j] 个），返回在 xy、yz、zx 三个平面上的投影面积之和。

**示例：**
```
输入：grid = [[1,2],[3,4]]
输出：17
```

## 解题思路

分别计算三个投影：xy 为非零格子数，yz 为每行最大值之和，zx 为每列最大值之和。

## Java 代码实现

```java
class Solution {
    public int projectionArea(int[][] grid) {
        int n = grid.length;
        int xy = 0, yz = 0, zx = 0;

        for (int i = 0; i < n; i++) {
            int rowMax = 0, colMax = 0;
            for (int j = 0; j < n; j++) {
                if (grid[i][j] > 0) xy++;
                rowMax = Math.max(rowMax, grid[i][j]);
                colMax = Math.max(colMax, grid[j][i]);
            }
            yz += rowMax;
            zx += colMax;
        }

        return xy + yz + zx;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

## 关键点总结

1. **xy 投影**：俯视图，计数非零格子
2. **yz 投影**：正视图，每行最大值
3. **zx 投影**：侧视图，每列最大值
