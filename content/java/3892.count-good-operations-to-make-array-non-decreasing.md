## 题目描述

给你一个整数数组 `nums`，统计有多少个下标 `i`，使得将 `nums[i]` 替换为 `nums[i] + 1` 后数组仍然是非递减序列。

## 解题思路

对每个位置 `i`，修改后的值 `nums[i] + 1` 只影响与左右相邻元素的大小关系：需满足 `nums[i-1] <= nums[i]+1` 且 `nums[i]+1 <= nums[i+1]`，边界元素只有一侧约束。

## Java 代码实现

```java
class Solution {
    public int countGoodOperations(int[] nums) {
        int n = nums.length;
        int count = 0;

        for (int i = 0; i < n; i++) {
            int newVal = nums[i] + 1;

            // 检查左侧约束：左邻 <= 修改后的值
            boolean okLeft = (i == 0 || nums[i - 1] <= newVal);
            // 检查右侧约束：修改后的值 <= 右邻
            boolean okRight = (i == n - 1 || newVal <= nums[i + 1]);

            if (okLeft && okRight) count++;
        }

        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 每个操作只影响与相邻元素的大小关系，无需重新检查整个数组。
2. 条件 1：修改后的值 >= 左邻；条件 2：修改后的值 <= 右邻。
3. 边界处理：首元素无左邻约束，末元素无右邻约束。
