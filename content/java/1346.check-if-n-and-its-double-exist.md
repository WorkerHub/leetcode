## 题目描述

给你一个整数数组 `arr`，请你检查是否存在两个整数 `N` 和 `M`，满足 `N` 是 `M` 的两倍（即，`N = 2 * M`）。

更正式地，检查是否存在两个下标 `i` 和 `j` 满足：
- `i != j`
- `0 <= i, j < arr.length`
- `arr[i] == 2 * arr[j]`

**示例 1：**
```
输入：arr = [10,2,5,3]
输出：true
解释：N = 10，M = 5（10 = 2 * 5）
```

**示例 2：**
```
输入：arr = [7,1,14,11]
输出：true
解释：N = 14，M = 7（14 = 2 * 7）
```

**示例 3：**
```
输入：arr = [3,1,7,11]
输出：false
解释：在该数组中不存在满足条件的两个元素。
```

**提示：**
- `2 <= arr.length <= 500`
- `-10^3 <= arr[i] <= 10^3`

## 解题思路

**方法一（哈希集合）：**

遍历数组，对每个元素 `x`：
- 检查 `2 * x` 是否在已见集合中（`x` 是 M，`2x` 是 N）
- 检查 `x / 2`（`x` 是偶数时）是否在已见集合中（`x` 是 N，`x/2` 是 M）

或者，可以先将所有元素放入集合，然后对每个元素 `x` 检查 `2*x` 是否也在集合中（注意 0 的特殊情况）。

**方法二（排序 + 二分查找）：**

排序后对每个元素 `x` 二分查找 `2*x`。

## Java 代码实现

### 方法一：哈希集合一次遍历（推荐）

```java
import java.util.*;

class Solution {
    public boolean checkIfExist(int[] arr) {
        Set<Integer> seen = new HashSet<>();
        
        for (int x : arr) {
            // 检查 2*x 是否在 seen 中（x 作为 M，2x 作为 N）
            // 检查 x/2 是否在 seen 中（x 作为 N，x/2 作为 M）
            if (seen.contains(2 * x) || (x % 2 == 0 && seen.contains(x / 2))) {
                return true;
            }
            seen.add(x);
        }
        
        return false;
    }
}
```

### 方法二：哈希集合预处理（两次遍历）

```java
import java.util.*;

class Solution {
    public boolean checkIfExist(int[] arr) {
        // 先统计 0 的个数，处理特殊情况
        int zeroCount = 0;
        Set<Integer> set = new HashSet<>();
        for (int x : arr) {
            if (x == 0) zeroCount++;
            set.add(x);
        }
        
        for (int x : arr) {
            // x=0 时：2*0=0 在 set 中，但需要数组中有两个 0
            if (x == 0) {
                if (zeroCount >= 2) return true;
            } else {
                // 检查 2*x 是否在数组中
                if (set.contains(2 * x)) return true;
            }
        }
        
        return false;
    }
}
```

### 方法三：排序 + 二分查找

```java
import java.util.Arrays;

class Solution {
    public boolean checkIfExist(int[] arr) {
        Arrays.sort(arr);
        int n = arr.length;
        
        for (int i = 0; i < n; i++) {
            int target = 2 * arr[i];
            // 在整个数组中查找 target（排除自身）
            int lo = 0, hi = n - 1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (arr[mid] == target) {
                    if (mid != i) return true; // 找到且不是自身
                    break; // 找到但是自身，退出二分
                } else if (arr[mid] < target) {
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
        }
        
        return false;
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一/二（哈希集合） | O(n) | O(n) |
| 方法三（排序+二分） | O(n log n) | O(1) |

## 关键点总结

1. 方法一的哈希集合遍历最高效：一次遍历，每次检查 `2*x` 和 `x/2`
2. 特殊情况：`x = 0` 时，`2*0 = 0`，需要数组中有两个 0 才成立
3. 方法一的一次遍历天然避免了 `i == j` 的问题（`seen` 中只有之前的元素）

## 易错点

1. `x = 0` 的特殊情况：`2 * 0 = 0`，如果用集合预处理，`0` 在集合中只有一个，会错误返回 `true`
2. 方法一中使用一次遍历可以避免 `i == j` 的问题
3. Java 中整数除法 `x / 2` 会向零取整，负奇数时 `-3 / 2 = -1`，检查条件 `x % 2 == 0` 是正确的

## 图解示例

以 `arr = [10,2,5,3]` 为例（方法一）：

```
seen = {}

遍历 x=10：
  2*10=20 not in seen, 10%2==0, 10/2=5 not in seen

遍历 x=2：
  2*2=4 not in seen, 2%2==0, 2/2=1 not in seen
  seen = {10, 2}

  2*5=10 in seen! -> 返回 true
```
