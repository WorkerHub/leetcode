## 题目描述

给你字符串 `target`、字符串数组 `words` 和费用数组 `costs`，每次可以选用一个单词拼接到末尾，返回构造 `target` 的最小总费用，无法构造则返回 `-1`。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int minimumCost(String target, String[] words, int[] costs) {
        // 构建字典树，记录每个单词结尾节点的最小花费
        int[][] children = new int[target.length() * 26 + 26][26];
        int[] minCost = new int[target.length() * 26 + 26];
        int trieSize = 1;
        // 初始化字典树节点（0 表示无子节点）
        for (int[] row : children) Arrays.fill(row, -1);

        for (int i = 0; i < words.length; i++) {
            int node = 0;
            for (char c : words[i].toCharArray()) {
                int idx = c - 'a';
                if (children[node][idx] == -1) {
                    children[node][idx] = trieSize++;
                }
                node = children[node][idx];
            }
            // 保留最小花费
            if (minCost[node] == 0) minCost[node] = costs[i];
            else minCost[node] = Math.min(minCost[node], costs[i]);
        }

        int n = target.length();
        int INF = Integer.MAX_VALUE / 2;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            if (dp[i] == INF) continue;
            // 从位置 i 开始沿字典树向右匹配
            int node = 0;
            for (int j = i; j < n; j++) {
                int idx = target.charAt(j) - 'a';
                if (children[node][idx] == -1) break;
                node = children[node][idx];
                if (minCost[node] > 0) {
                    dp[j + 1] = Math.min(dp[j + 1], dp[i] + minCost[node]);
                }
            }
        }

        return dp[n] == INF ? -1 : dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2 + L)，L 为所有 words 总长度
- 空间复杂度：O(n * 26 + L)

## 关键点总结

1. 字典树从每个起点向右扩展，避免重复计算前缀
2. 同一个单词可能有多个 cost，只保留最小值
3. dp[0] = 0 为初始状态，无法构造时返回 -1
