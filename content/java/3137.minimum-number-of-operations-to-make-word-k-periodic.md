## 题目描述

将字符串切分为长度k的块，通过替换操作使所有块相同，求最少操作次数。

## 解题思路

统计每种块的出现频率，保留出现最多的块不替换，答案=总块数-最大频率。

## Java 代码实现

```java
class Solution {
    public int minimumOperationsToMakeKPeriodic(String word, int k) {
        int n = word.length();
        int blocks = n / k;
        Map<String, Integer> freq = new HashMap<>();
        int maxCount = 0;
        for (int i = 0; i < n; i += k) {
            String block = word.substring(i, i + k);
            int cnt = freq.merge(block, 1, Integer::sum);
            maxCount = Math.max(maxCount, cnt);
        }
        return blocks - maxCount;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N/K)

## 关键点总结

1. **贪心**：保留频率最高的块不变
2. **答案=总块数-最大频率**
3. **用HashMap统计块频率**
