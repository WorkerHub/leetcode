## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32 位整数。

**示例 1：**

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2：**

```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是连续子数组。
```

**提示：**

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何前缀或后缀的乘积都保证是一个 32 位整数

## 解题思路

这道题是第 53 题"最大子数组和"的变体，但乘法有特殊性：
- 负数乘以负数会变成正数
- 最小值遇到负数可能变成最大值

**关键观察：**

1. 如果当前数是正数：
   - 希望之前的乘积越大越好
2. 如果当前数是负数：
   - 希望之前的乘积越小越好（负负得正）
3. 如果当前数是 0：
   - 乘积归零，重新开始

**动态规划思路：**

维护两个状态：
- `maxProd`：以当前位置结尾的最大乘积
- `minProd`：以当前位置结尾的最小乘积（可能是负数）

状态转移：
```
maxProd = max(nums[i], maxProd * nums[i], minProd * nums[i])
minProd = min(nums[i], maxProd * nums[i], minProd * nums[i])
```

为什么需要 `minProd`？
- 当前数如果是负数，之前的最小值（负数）乘以它可能得到最大值

## Java 代码实现

### 方法一：动态规划（交换技巧，推荐）

```java
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 初始化
        int maxProd = nums[0];
        int minProd = nums[0];
        int result = nums[0];

        // 从第二个元素开始遍历
        for (int i = 1; i < nums.length; i++) {
            int num = nums[i];

            // 如果当前数是负数，交换 max 和 min
            // 因为负数会让最大变最小，最小变最大
            if (num < 0) {
                int tmp = maxProd;
                maxProd = minProd;
                minProd = tmp;
            }

            // 状态转移
            maxProd = Math.max(num, maxProd * num);
            minProd = Math.min(num, minProd * num);

            // 更新全局最大值
            result = Math.max(result, maxProd);
        }

        return result;
    }
}
```

### 方法二：不交换的写法（更清晰）

```java
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        int maxProd = nums[0];
        int minProd = nums[0];
        int result = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int num = nums[i];

            // 同时考虑三种情况：
            // 1. 当前数字单独作为子数组
            // 2. 当前数字乘以之前的最大乘积
            // 3. 当前数字乘以之前的最小乘积（负负得正）
            int newMax = Math.max(num, Math.max(maxProd * num, minProd * num));
            int newMin = Math.min(num, Math.min(maxProd * num, minProd * num));

            maxProd = newMax;
            minProd = newMin;

            result = Math.max(result, maxProd);
        }

        return result;
    }
}
```

### 方法三：使用数组记录（DP 经典形式）

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;

        // dpMax[i]: 以 nums[i] 结尾的最大乘积
        // dpMin[i]: 以 nums[i] 结尾的最小乘积
        int[] dpMax = new int[n];
        int[] dpMin = new int[n];

        dpMax[0] = dpMin[0] = nums[0];
        int result = nums[0];

        for (int i = 1; i < n; i++) {
            // 考虑三种选择
            dpMax[i] = Math.max(nums[i],
                        Math.max(dpMax[i-1] * nums[i], dpMin[i-1] * nums[i]));

            dpMin[i] = Math.min(nums[i],
                        Math.min(dpMax[i-1] * nums[i], dpMin[i-1] * nums[i]));

            result = Math.max(result, dpMax[i]);
        }

        return result;
    }
}
```

### 方法四：前缀积和后缀积（巧妙思路）

```java
class Solution {
    public int maxProduct(int[] nums) {
        /**
         * 思路：从左到右和从右到左各扫描一次
         * 遇到 0 时重置为 1
         */
        int n = nums.length;
        int result = Integer.MIN_VALUE;

        // 从左到右
        int product = 1;
        for (int num : nums) {
            product *= num;
            result = Math.max(result, product);
            if (product == 0) product = 1;
        }

        // 从右到左
        product = 1;
        for (int i = n - 1; i >= 0; i--) {
            product *= nums[i];
            result = Math.max(result, product);
            if (product == 0) product = 1;
        }

        return result;
    }
}
```

## 复杂度分析

**方法一、二、三：动态规划**

- 时间复杂度：O(n)
  - 遍历数组一次
- 空间复杂度：
  - 方法一、二：O(1) - 只用常数个变量
  - 方法三：O(n) - 使用 dp 数组

**方法四：双向遍历**

- 时间复杂度：O(n)
  - 两次遍历
- 空间复杂度：O(1)

## 图解示例

以 `nums = [2, 3, -2, 4]` 为例：

```
初始: maxProd=2, minProd=2, result=2

i=1, num=3:
  newMax = max(3, 2*3=6, 2*3=6) = 6
  newMin = min(3, 2*3=6, 2*3=6) = 3
  result = 6

i=2, num=-2:
  newMax = max(-2, 6*(-2)=-12, 3*(-2)=-6) = -2
  newMin = min(-2, 6*(-2)=-12, 3*(-2)=-6) = -12
  result = 6 (保持不变)

i=3, num=4:
  newMax = max(4, -2*4=-8, -12*4=-48) = 4
  newMin = min(4, -2*4=-8, -12*4=-48) = -48
  result = 6

最终结果: 6
```

以 `nums = [2, -5, -2, -4, 3]` 为例（有负数的情况）：

```
初始: max=2, min=2, result=2

i=1, num=-5:
  交换后: max=2, min=2
  max = max(-5, 2*(-5)) = -5
  min = min(-5, 2*(-5)) = -10
  result = 2

i=2, num=-2:
  max = max(-2, -5*(-2), -10*(-2)) = 20
  min = min(-2, -5*(-2), -10*(-2)) = -2
  result = 20

i=3, num=-4:
  max = max(-4, 20*(-4), -2*(-4)) = 8
  min = min(-4, 20*(-4), -2*(-4)) = -80
  result = 20

i=4, num=3:
  max = max(3, 8*3, -80*3) = 24
  min = min(3, 8*3, -80*3) = -240
  result = 24

最终结果: 24 (整个数组的乘积)
```

## 关键点总结

1. **维护两个状态**：
   - 最大乘积：用于更新答案
   - 最小乘积：可能在遇到负数时变成最大值

2. **负数的影响**：
   - 负数会使最大变最小，最小变最大
   - 方法一中交换 max 和 min 是一个优化技巧

3. **三种选择**：
   - 当前数字单独成为子数组（重新开始）
   - 乘以之前的最大乘积
   - 乘以之前的最小乘积

4. **0 的处理**：
   - 乘以 0 会归零
   - 自动处理，不需要特殊判断
   - max/min 都会变成 0，然后从下一个数重新开始

5. **动态规划的优化**：
   - 状态只依赖前一个位置，可以用变量代替数组
   - 空间复杂度从 O(n) 优化到 O(1)

## 易错点

1. **忘记维护最小值**：
   - 只维护最大值无法处理负数情况
   - 例如 `[2, -5, -2]`，最大乘积是 20

2. **状态转移时的选择**：
   - 必须考虑三种情况，不能只考虑两种
   - `max(num, maxProd * num)` 是不够的

3. **初始化**：
   - `result` 要初始化为 `nums[0]`，而不是 0
   - 如果数组全是负数，0 会导致错误结果

4. **交换的时机**：
   - 在更新 maxProd 和 minProd 之前交换
   - Java 中需要用临时变量交换

5. **边界情况**：
   - 空数组（题目保证不会）
   - 单个元素
   - 全是负数
   - 包含 0
