## 题目描述

给定整数 `n`，构造 `2^n x 2^n` 矩阵：1x1 时填 0；否则将矩阵分为四个子矩阵，左上+0，左下+quarter，右下+2*quarter，右上+3*quarter（quarter = 子矩阵大小^2）。

## 解题思路

递归分治：将矩阵分为四个象限，每个象限递归填充并加上对应偏移量。

## Java 代码实现

```java
class Solution {
    private int[][] grid;

    public int[][] specialGrid(int n) {
        int size = 1 << n;
        grid = new int[size][size];
        fill(0, 0, size, 0);
        return grid;
    }

    private void fill(int r, int c, int sz, int base) {
        if (sz == 1) { grid[r][c] = base; return; }
        int half = sz / 2;
        int quarter = half * half;
        fill(r,        c,        half, base);              // 左上 +0
        fill(r + half, c,        half, base + quarter);    // 左下 +1*quarter
        fill(r + half, c + half, half, base + 2 * quarter); // 右下 +2*quarter
        fill(r,        c + half, half, base + 3 * quarter); // 右上 +3*quarter
    }
}
```

## 复杂度分析

- 时间复杂度：O(4^n)
- 空间复杂度：O(4^n)

## 关键点总结

1. 四个象限偏移量：左上0，左下1，右下2，右上3（乘 quarter）
2. quarter = 子矩阵元素数 = half^2
3. 递归基准：sz=1 时直接赋值
