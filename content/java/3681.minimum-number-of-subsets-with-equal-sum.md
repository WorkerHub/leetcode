## 题目描述

给你一个整数数组 `nums`（长度 <= 16），将其分成若干非空子集，使得每个子集的元素之和相等。返回最少的子集数量，若无法完成则返回 -1。

## 解题思路

枚举子集数 k，检验总和能否被 k 整除，然后用回溯验证是否能分成 k 组、每组和为 `total/k`。降序排列元素并加剪枝可大幅提速。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    private int[] nums;
    private boolean[] used;
    private int target;

    public int minimumSubsets(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;
        // 降序排列加速剪枝
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n / 2; i++) { int t = nums[i]; nums[i] = nums[n-1-i]; nums[n-1-i] = t; }
        this.nums = nums;
        this.used = new boolean[n];

        for (int k = 1; k <= n; k++) {
            if (total % k != 0) continue;
            if (nums[0] > total / k) continue; // 最大元素超过目标
            this.target = total / k;
            Arrays.fill(used, false);
            if (backtrack(0, 0, 0, k)) return k;
        }
        return -1;
    }

    private boolean backtrack(int group, int currSum, int start, int k) {
        if (group == k) return true;
        if (currSum == target) return backtrack(group + 1, 0, 0, k);
        for (int i = start; i < nums.length; i++) {
            if (used[i] || currSum + nums[i] > target) continue;
            used[i] = true;
            if (backtrack(group, currSum + nums[i], i + 1, k)) return true;
            used[i] = false;
            // 剪枝：当前组为空时，相同值的后续元素也会失败
            if (currSum == 0) break;
        }
        return false;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k * k! / (k/n)!)，回溯带剪枝
- 空间复杂度：O(n)

## 关键点总结

1. 枚举子集数 k，target = total / k
2. 回溯：元素降序排列，`currSum == 0` 时相同值跳过
3. 最大元素超过 target 时直接跳过该 k
