## 题目描述

给定整数数组 `nums`，若元素 `nums[i]` 在数组中恰好出现 `nums[i]` 次，则称该元素为"好"元素。返回所有好元素的总和（同一值只计一次）。

## 解题思路

统计每个元素的出现次数，若出现次数等于元素值本身，则该元素是好元素，将其值加入结果（每种值只算一次）。

## Java 代码实现

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int sumOfGoodValues(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }

        int total = 0;
        for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
            int val = entry.getKey();
            int count = entry.getValue();
            if (count == val) {
                // 好元素：值等于出现次数，每种值只计一次
                total += val;
            }
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 统计频率后判断 `freq == val` 即为好元素
2. 每种值只计一次（不乘以出现次数）
3. `nums[i] <= nums.length`，所有值在合法范围内
