## 题目描述

解析化学式，返回每种原子按字母序排列的数量字符串。支持括号嵌套和数字倍数。

**示例：**
```
输入：formula = "Mg(OH)2"
输出："H2MgO2"
```

## 解题思路

栈 + 哈希表：遇到 `(` 压入新 Map，遇到 `)` 弹出并乘以倍数合并到上层，遇到元素名解析名称和数量。

## Java 代码实现

```java
class Solution {
    public String countOfAtoms(String formula) {
        Deque<Map<String, Integer>> stack = new ArrayDeque<>();
        stack.push(new HashMap<>());
        int i = 0, n = formula.length();

        while (i < n) {
            if (formula.charAt(i) == '(') {
                stack.push(new HashMap<>());
                i++;
            } else if (formula.charAt(i) == ')') {
                i++;
                int start = i;
                while (i < n && Character.isDigit(formula.charAt(i))) i++;
                int multiplier = start < i ? Integer.parseInt(formula.substring(start, i)) : 1;

                Map<String, Integer> top = stack.pop();
                for (Map.Entry<String, Integer> entry : top.entrySet()) {
                    stack.peek().merge(entry.getKey(), entry.getValue() * multiplier, Integer::sum);
                }
            } else {
                // 解析元素名
                int start = i;
                i++;
                while (i < n && Character.isLowerCase(formula.charAt(i))) i++;
                String atom = formula.substring(start, i);

                // 解析数量
                start = i;
                while (i < n && Character.isDigit(formula.charAt(i))) i++;
                int count = start < i ? Integer.parseInt(formula.substring(start, i)) : 1;

                stack.peek().merge(atom, count, Integer::sum);
            }
        }

        // 按字母序排列构建结果
        TreeMap<String, Integer> sorted = new TreeMap<>(stack.peek());
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<String, Integer> entry : sorted.entrySet()) {
            sb.append(entry.getKey());
            if (entry.getValue() > 1) sb.append(entry.getValue());
        }
        return sb.toString();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n²)
- **空间复杂度**：O(n)

## 关键点总结

1. **栈处理括号**：每层括号对应一个 Map
2. **倍数合并**：弹出时乘以括号后数字
3. **元素名解析**：大写开头 + 可选小写字母
4. **TreeMap 排序**：按字母序输出
