## 题目描述

给你只含 `'a'` 和 `'b'` 的字符串 `s`，使 `s` **平衡**（不含 "ba" 子序列，即所有 'a' 在 'b' 之前）需要删除的**最少字符数**。

## 解题思路

**贪心（栈）：** 遍历字符串，记录当前未匹配的 'b' 数量。遇到 'a' 时若前面有 'b'，选择删除一个 'b'（代价最小）。

**DP：** `dp` = 前缀平衡的最少删除数，遇到 'a' 时 `dp = min(dp+1, b_count)`。

## Java 代码实现

```java
class Solution {
    public int minimumDeletions(String s) {
        // 贪心：遇到 'a' 且前面有 'b' 时，删除一个 'b'
        int bCount = 0;   // 当前未匹配的 'b' 数量
        int deletions = 0;

        for (char c : s.toCharArray()) {
            if (c == 'b') {
                bCount++; // 'b' 入栈
            } else { // c == 'a'
                if (bCount > 0) {
                    // 有未匹配的 'b' 在前面，删除它
                    bCount--;
                    deletions++;
                }
            }
        }

        return deletions;
    }
}
```

### 方法二：DP

```java
class Solution {
    public int minimumDeletions(String s) {
        int dp = 0;      // 前缀平衡的最少删除数
        int bCount = 0;  // 已见到的 'b' 数量

        for (char c : s.toCharArray()) {
            if (c == 'b') {
                bCount++;
            } else {
                // 删 'a'：dp+1；或删前面某个 'b'：bCount
                dp = Math.min(dp + 1, bCount);
            }
        }

        return dp;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 平衡字符串 = 不含 "ba" 子序列
2. 贪心：遇到 'a' 且前面有 'b' 时，选择删除 'b'（保留 'a'）更优
3. DP：`dp = min(dp+1, bCount)` 取两种操作的最小代价
