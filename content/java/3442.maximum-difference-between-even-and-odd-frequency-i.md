## 题目描述

给定字符串 `s`，返回出现奇数次的字符的最大频率与出现偶数次的字符的最小频率之差。

## Java 代码实现

```java
class Solution {
    public int maxDifference(String s) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;

        int maxOdd = 0, minEven = Integer.MAX_VALUE;
        for (int f : freq) {
            if (f == 0) continue;
            if (f % 2 == 1) maxOdd = Math.max(maxOdd, f);
            else minEven = Math.min(minEven, f);
        }
        if (minEven == Integer.MAX_VALUE) minEven = 0;
        return maxOdd - minEven;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 统计每个字符频率，按奇偶分组
2. 找最大奇频和最小偶频，计算差值
3. 某类频率不存在时视为 0
