## 题目描述

骰子投掷 n 次，连续掷出数字 i 的次数不能超过 rollMax[i]。求合法点数序列的数量（对 10^9+7 取模）。

**示例：**
```
输入：n = 2, rollMax = [1,1,2,2,2,3]
输出：34（36 - 2，排除 (1,1) 和 (2,2)）
```

## 解题思路

三维 DP：dp[i][j][k] = 投掷 i 次、最后点数为 j、连续出现 k 次的序列数。转移时若换点数则 k 重置为 1，否则 k+1（不超过 rollMax[j]）。

## Java 代码实现

```java
class Solution {
    public int dieSimulator(int n, int[] rollMax) {
        long MOD = 1_000_000_007;
        // dp[j][k]: 最后点数为 j，连续出现 k 次的序列数
        long[][] dp = new long[6][16];
        
        // 初始化：第一次投掷
        for (int j = 0; j < 6; j++) {
            dp[j][1] = 1;
        }
        
        for (int i = 2; i <= n; i++) {
            long[][] newDp = new long[6][16];
            for (int j = 0; j < 6; j++) {
                // 计算上一轮所有以其他点数结尾的总数
                for (int prev = 0; prev < 6; prev++) {
                    if (prev == j) continue;
                    long total = 0;
                    for (int k = 1; k <= rollMax[prev]; k++) {
                        total = (total + dp[prev][k]) % MOD;
                    }
                    // 换点数，连续次数重置为 1
                    newDp[j][1] = (newDp[j][1] + total) % MOD;
                }
                // 相同点数，连续次数 +1
                for (int k = 2; k <= rollMax[j]; k++) {
                    newDp[j][k] = dp[j][k - 1];
                }
            }
            dp = newDp;
        }
        
        // 汇总所有状态
        long ans = 0;
        for (int j = 0; j < 6; j++) {
            for (int k = 1; k <= rollMax[j]; k++) {
                ans = (ans + dp[j][k]) % MOD;
            }
        }
        return (int) ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × 6 × 6 × max(rollMax))
- **空间复杂度**：O(6 × max(rollMax))（滚动数组优化）

## 关键点总结

1. **三维状态**：投掷次数 × 点数 × 连续次数
2. **转移分类**：换点数（k=1）vs 不换点数（k+1）
3. **滚动数组**：只需前一轮状态
4. **取模**：每步都取模防止溢出
