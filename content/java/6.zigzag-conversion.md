## 题目描述

将一个给定字符串 `s` 根据给定的行数 `numRows`，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 `"PAYPALISHIRING"` 行数为 `3` 时，排列如下：

```
P   A   H   N
A P L S I I G
Y   I   R
```

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如：`"PAHNAPLSIIGYIR"`。

请你实现这个将字符串进行指定行数变换的函数。

**示例 1：**
```
输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"
```

**示例 2：**
```
输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
解释：
P     I    N
A   L S  I G
Y A   H R
P     I
```

**示例 3：**
```
输入：s = "A", numRows = 1
输出："A"
```

**提示：**
- `1 <= s.length <= 1000`
- `s` 由英文字母（小写和大写）、`','` 和 `'.'` 组成
- `1 <= numRows <= 1000`

## 解题思路

核心思想：按行存储字符

关键观察：
- 第一行和最后一行：方向只有一个
- 中间行：方向会改变（向下->向上）
- 用一个标志位控制方向

## Java 代码实现

### 方法一：按行存储（推荐）

```java
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || numRows >= s.length()) {
            return s;
        }
        
        // 创建 numRows 个 StringBuilder 存储每一行
        StringBuilder[] rows = new StringBuilder[numRows];
        for (int i = 0; i < numRows; i++) {
            rows[i] = new StringBuilder();
        }
        
        int currentRow = 0;
        boolean goingDown = false;
        
        for (char c : s.toCharArray()) {
            rows[currentRow].append(c);
            
            // 到达第一行或最后一行时改变方向
            if (currentRow == 0 || currentRow == numRows - 1) {
                goingDown = !goingDown;
            }
            
            // 移动到下一行
            currentRow += goingDown ? 1 : -1;
        }
        
        StringBuilder result = new StringBuilder();
        for (StringBuilder row : rows) {
            result.append(row);
        }
        return result.toString();
    }
}
```

### 方法二：找规律（数学方法）

```java
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || numRows >= s.length()) {
            return s;
        }
        
        StringBuilder result = new StringBuilder();
        int cycleLen = 2 * numRows - 2;  // 一个周期的长度
        
        for (int i = 0; i < numRows; i++) {
            for (int j = i; j < s.length(); j += cycleLen) {
                result.append(s.charAt(j));
                
                // 中间行还有斜向的字符
                if (i != 0 && i != numRows - 1) {
                    int k = j + cycleLen - 2 * i;
                    if (k < s.length()) {
                        result.append(s.charAt(k));
                    }
                }
            }
        }
        
        return result.toString();
    }
}
```

## 复杂度分析

**两种方法：**
- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. **方向控制**：到达边界时改变方向
2. **边界情况**：numRows = 1 时直接返回
3. **周期规律**：每 `2*numRows-2` 个字符为一个周期

## 易错点

1. **边界**：numRows = 1 或 numRows >= s.length() 时
2. **方向改变**：在第一行和最后一行改变

## 学习建议

方法一更直观，方法二需要找规律。建议先掌握方法一。
