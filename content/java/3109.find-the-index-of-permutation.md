## 题目描述

给你 [1, 2, ..., n] 的一个排列 `perm`，返回其在所有排列中的字典序排名（从 1 开始），答案对 10^9+7 取模。

## 解题思路

Lehmer 码：对每个位置 i，统计比 perm[i] 小的未使用数个数，乘以 (n-i-1)!，累加后 +1。用树状数组（BIT）高效查询前缀和（即小于 x 的未使用数个数）。

## Java 代码实现

```java
class Solution {
    int[] bit;
    int n;

    public int getPermutationIndex(int[] perm) {
        final int MOD = 1_000_000_007;
        n = perm.length;
        bit = new int[n + 1];
        for (int i = 1; i <= n; i++) update(i, 1); // 初始化所有数都在

        long[] fact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;

        long ans = 0;
        for (int i = 0; i < n; i++) {
            long smaller = query(perm[i] - 1); // 比 perm[i] 小的未使用数个数
            ans = (ans + smaller % MOD * fact[n - i - 1]) % MOD;
            update(perm[i], -1); // 标记已使用
        }
        return (int) ((ans + 1) % MOD);
    }

    private void update(int i, int delta) {
        for (; i <= n; i += i & -i) bit[i] += delta;
    }

    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & -i) s += bit[i];
        return s;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)
- 空间复杂度：O(n)

## 关键点总结

1. Lehmer 码：每位乘以对应阶乘，最后 +1 得排名
2. 树状数组支持 O(log n) 的前缀和查询和单点更新
