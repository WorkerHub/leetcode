## 题目描述

银行m行n列，'1'表示安全设备。相邻非空行（中间全0行）之间的激光束数=两行设备数之积。求总激光束数。

## 解题思路

统计每行'1'的个数，过滤全0行后，相邻非空行设备数之积的总和。

## Java 代码实现

```java
class Solution {
    public int numberOfBeams(String[] bank) {
        int ans = 0;
        int prev = 0;
        for (String row : bank) {
            int curr = 0;
            for (char c : row.toCharArray()) {
                if (c == '1') curr++;
            }
            if (curr > 0) {
                ans += prev * curr;
                prev = curr;
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M * N)
- **空间复杂度**：O(1)

## 关键点总结

1. **过滤全0行**：只统计非空行
2. **相邻非空行之积**：prev*curr累加
3. **一次遍历**：无需存储所有行的计数
