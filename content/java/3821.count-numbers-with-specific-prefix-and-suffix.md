## 题目描述

给定整数范围 `[lo, hi]` 和字符串 `prefix`、`suffix`，返回范围内十进制表示同时以 prefix 开头且以 suffix 结尾的整数数目。

## Java 代码实现

```java
class Solution {
    public int countNumbers(int lo, int hi, String prefix, String suffix) {
        int count = 0;
        int maxLen = String.valueOf(hi).length();
        int pLen = prefix.length(), sLen = suffix.length();

        for (int totalLen = Math.max(pLen, sLen); totalLen <= maxLen; totalLen++) {
            int midLen = totalLen - pLen - sLen;
            if (midLen < 0) {
                // 前缀和后缀有重叠，验证重叠部分是否一致
                int overlap = pLen + sLen - totalLen;
                if (prefix.substring(pLen - overlap).equals(suffix.substring(0, overlap))) {
                    String numStr = prefix + suffix.substring(overlap);
                    if (numStr.length() == totalLen) {
                        long num = Long.parseLong(numStr);
                        if (num >= lo && num <= hi) count++;
                    }
                }
            } else if (midLen == 0) {
                String numStr = prefix + suffix;
                if (numStr.length() == totalLen) {
                    long num = Long.parseLong(numStr);
                    if (num >= lo && num <= hi) count++;
                }
            } else {
                // 枚举中间部分
                int midCount = 1;
                for (int i = 0; i < midLen; i++) midCount *= 10;
                for (int mid = 0; mid < midCount; mid++) {
                    String midStr = String.format("%0" + midLen + "d", mid);
                    long num = Long.parseLong(prefix + midStr + suffix);
                    if (num >= lo && num <= hi) count++;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(10^midLen * maxLen)，枚举中间部分
- 空间复杂度：O(1)

## 关键点总结

1. 枚举总位数，计算中间部分长度
2. 前缀和后缀可能有重叠，重叠部分需一致
3. hi <= 10^9，最多 10 位，枚举空间有限
