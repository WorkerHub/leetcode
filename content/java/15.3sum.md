## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且不重复的三元组。

**示例 1：**
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

**示例 2：**
```
输入：nums = [0,1,1]
输出：[]
```

**示例 3：**
```
输入：nums = [0,0,0]
输出：[[0,0,0]]
```

## 解题思路

### 核心思想：排序 + 双指针

1. **排序**：先对数组排序，方便去重和使用双指针
2. **固定一个数**：将三数之和转化为两数之和问题
3. **双指针**：在剩余数组中用双指针查找两数之和
4. **去重**：避免重复的三元组

## Java 代码实现

### 方法：排序 + 双指针（推荐）

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;
        
        // 固定第一个数
        for (int i = 0; i < n - 2; i++) {
            // 跳过重复的第一个数
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            // 剪枝：如果最小的数都大于0，后面不可能有解
            if (nums[i] > 0) break;
            
            // 双指针查找剩余两个数
            int left = i + 1, right = n - 1;
            int target = -nums[i];
            
            while (left < right) {
                int sum = nums[left] + nums[right];
                
                if (sum == target) {
                    // 找到一组解
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    
                    // 跳过重复的元素
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    
                    // 移动指针
                    left++;
                    right--;
                } else if (sum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n^2)
  - 排序：O(n log n)
  - 双指针遍历：O(n^2)

- **空间复杂度**：O(log n)，排序所需的栈空间

## 图解示例

以 `nums = [-1,0,1,2,-1,-4]` 为例：

```
排序后：[-4, -1, -1, 0, 1, 2]

i=0, nums[i]=-4:
  left=1, right=5: -4+(-1)+2 = -3 < 0, left++
  ...无解

i=1, nums[i]=-1:
  left=2, right=5: -1+(-1)+2 = 0  -> [-1,-1,2]
  left=3, right=4: -1+0+1 = 0  -> [-1,0,1]

i=2, nums[i]=-1: 跳过（重复）

结果：[[-1,-1,2], [-1,0,1]]
```

## 关键点总结

1. **排序是前提**：排序后才能使用双指针，且方便去重
2. **三数转两数**：固定一个数，问题变成两数之和
3. **去重三个位置**：第一个数、第二个数、第三个数都要去重
4. **剪枝优化**：如果 `nums[i] > 0`，后面不可能有解

## 易错点

1. **去重位置**：`if (i > 0 && nums[i] == nums[i-1])` 不能漏掉 `i > 0`
2. **去重时机**：找到解后要先跳过重复元素，再移动指针
3. **边界条件**：跳过重复时也要检查 `left < right`
