## 题目描述

给定整数 `n`，统计 `[1, n]` 范围内"美丽数字"的数量：该数字的每一位数字都不为 0，且该数字能被其每一位数字整除。

## 解题思路

数位 DP。由于 1~9 的 LCM = 2520，维护当前已选数字的 LCM（最大 2520）和当前数 mod 2520，最终判断整除性。

## Java 代码实现

```java
class Solution {
    private char[] digits;
    private int[][][][] memo;

    public int countBeautifulNumbers(int n) {
        digits = String.valueOf(n).toCharArray();
        int len = digits.length;
        // dp[pos][lcm][mod][tight] - lcm最大2520，mod最大2520
        memo = new int[len][2521][2521][2];
        for (int[][][] a : memo)
            for (int[][] b : a)
                for (int[] c : b)
                    java.util.Arrays.fill(c, -1);
        return dp(0, 1, 0, 1, false);
    }

    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    private int lcm(int a, int b) {
        return a / gcd(a, b) * b;
    }

    private int dp(int pos, int curLcm, int curMod, int tight, boolean started) {
        if (pos == digits.length) {
            if (!started) return 0;
            // 检查当前数能否被所有位的 LCM 整除
            return curMod % curLcm == 0 ? 1 : 0;
        }
        if (memo[pos][curLcm][curMod][tight] != -1 && started) {
            return memo[pos][curLcm][curMod][tight];
        }
        int limit = tight == 1 ? (digits[pos] - '0') : 9;
        int count = 0;
        for (int d = 0; d <= limit; d++) {
            int newTight = (tight == 1 && d == limit) ? 1 : 0;
            if (d == 0 && !started) {
                // 前导零
                count += dp(pos + 1, 1, 0, newTight, false);
            } else if (d == 0) {
                // 数中含 0，不是美丽数字，跳过
            } else {
                int newLcm = started ? lcm(curLcm, d) : d;
                int newMod = (curMod * 10 + d) % 2520;
                count += dp(pos + 1, newLcm, newMod, newTight, true);
            }
        }
        if (started) memo[pos][curLcm][curMod][tight] = count;
        return count;
    }
}
```

## 复杂度分析

- 时间复杂度：O(L × 2520 × 2520 × 10)，L 为位数（最多 10）
- 空间复杂度：O(L × 2520 × 2520)

## 关键点总结

1. 美丽数字能被其每一位的 LCM 整除，LCM 最大为 2520
2. 数位 DP 维护当前 LCM 和当前数 mod 2520，最终检查整除性
3. 含 0 的数字直接排除
