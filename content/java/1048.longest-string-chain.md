## 题目描述

给定单词数组，如果在 wordA 任何位置添加一个字母可以得到 wordB，则 wordA 是 wordB 的前身。返回最长词链长度。

**示例：**
```
输入：words = ["a","b","ba","bca","bda","bdca"]
输出：4（["a","ba","bda","bdca"]）
```

## 解题思路

按长度排序后 DP。dp[word] 表示以 word 结尾的最长词链长度。对每个单词，尝试删除每个字符得到前身，若前身存在则转移。

## Java 代码实现

```java
class Solution {
    public int longestStrChain(String[] words) {
        // 按长度排序
        Arrays.sort(words, (a, b) -> a.length() - b.length());

        // dp[word] = 以 word 结尾的最长词链长度
        Map<String, Integer> dp = new HashMap<>();
        int result = 1;

        for (String word : words) {
            dp.put(word, 1);

            // 尝试删除每个字符得到前身
            for (int i = 0; i < word.length(); i++) {
                String prev = word.substring(0, i) + word.substring(i + 1);
                if (dp.containsKey(prev)) {
                    dp.put(word, Math.max(dp.get(word), dp.get(prev) + 1));
                }
            }

            result = Math.max(result, dp.get(word));
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n × L²)，L 为单词平均长度
- **空间复杂度**：O(n)

## 关键点总结

1. **按长度排序**：保证计算 dp[word] 时前身已处理
2. **删除字符找前身**：比添加字符更高效
3. **哈希表存 DP**：快速查找前身是否存在
