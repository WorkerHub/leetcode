## 题目描述

假设你有一个特殊的键盘包含下面的按键：

- `A`：在屏幕上打印一个 'A'。
- `Ctrl-A`：选中整个屏幕。
- `Ctrl-C`：复制选中区域到缓冲区。
- `Ctrl-V`：将缓冲区内容输出到上次输入的结束位置，并显示在屏幕上。

现在，你只可以按键 N 次（使用上述四种按键），请问屏幕上最多可以显示几个 'A'？

**示例 1:**
```
输入: N = 3
输出: 3
解释: 
我们最多可以在屏幕上显示三个'A'通过如下顺序按键：
A, A, A
```

**示例 2:**
```
输入: N = 7
输出: 9
解释: 
我们最多可以在屏幕上显示九个'A'通过如下顺序按键：
A, A, A, Ctrl A, Ctrl C, Ctrl V, Ctrl V
```

**提示:**
- 1 <= N <= 50

## 解题思路

这是一个经典的动态规划问题，关键是找到最优的"复制-粘贴"策略。

**核心观察：**

1. **操作序列分析**：要复制粘贴，需要连续3个操作：Ctrl-A、Ctrl-C、Ctrl-V（先粘贴一次）
2. **最优子结构**：对于 n 次操作，最后一段操作要么是打印 A，要么是执行若干次粘贴
3. **状态转移**：
   - 如果在第 i-j 步时有 dp[i-j] 个 A
   - 使用 j-2 次粘贴（加上一次 Ctrl-A 和一次 Ctrl-C）
   - 可以得到 dp[i-j] * (j-1) 个 A

**动态规划思路：**

- `dp[i]` 表示使用 i 次操作最多能得到多少个 A
- 对于每个 i，枚举最后一次"全选-复制-粘贴序列"的长度 j
- 状态转移方程：`dp[i] = max(dp[i], dp[i-j] * (j-1))`，其中 j >= 3

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public int maxA(int n) {
        // dp[i] 表示 i 次操作能得到的最多 A 的数量
        int[] dp = new int[n + 1];
        
        // 初始化：前几步只能一直按 A
        for (int i = 1; i <= n; i++) {
            dp[i] = i;
        }
        
        // 从第4步开始可以考虑复制粘贴
        for (int i = 4; i <= n; i++) {
            // 枚举最后一次复制粘贴序列的长度 j
            // j = 3: Ctrl-A, Ctrl-C, Ctrl-V (复制1次，得到2倍)
            // j = 4: Ctrl-A, Ctrl-C, Ctrl-V, Ctrl-V (复制2次，得到3倍)
            for (int j = 3; j < i; j++) {
                // 在第 i-j 步时有 dp[i-j] 个 A
                // 使用 j 步进行全选、复制、粘贴操作
                // 其中 1 步 Ctrl-A，1 步 Ctrl-C，j-2 步 Ctrl-V
                // 总共粘贴 j-2 次，加上原来的1份，共 j-1 份
                dp[i] = Math.max(dp[i], dp[i - j] * (j - 1));
            }
        }
        
        return dp[n];
    }
}
```

### 方法二：优化的动态规划

```java
class Solution {
    public int maxA(int n) {
        // 初始化：dp[i] = i
        int[] dp = new int[n + 1];
        for (int i = 0; i <= n; i++) {
            dp[i] = i;
        }
        
        for (int i = 4; i <= n; i++) {
            // 只需要检查最近的几个位置
            // 因为复制太多次不如重新累积
            for (int j = 3; j < Math.min(i, 8); j++) {
                dp[i] = Math.max(dp[i], dp[i - j] * (j - 1));
            }
        }
        
        return dp[n];
    }
}
```

### 方法三：数学优化

```java
class Solution {
    public int maxA(int n) {
        if (n <= 6) return n;
        
        int[] dp = new int[n + 1];
        for (int i = 1; i <= 6; i++) {
            dp[i] = i;
        }
        
        for (int i = 7; i <= n; i++) {
            // 最优粘贴长度不超过5
            for (int j = 3; j < 6; j++) {
                dp[i] = Math.max(dp[i], dp[i - j] * (j - 1));
            }
        }
        
        return dp[n];
    }
}
```

## 复杂度分析

### 方法一：动态规划
- **时间复杂度**：O(n²)，两层循环，外层 n 次，内层最多 n 次
- **空间复杂度**：O(n)，使用一维 dp 数组

### 方法二：优化的动态规划
- **时间复杂度**：O(n)，外层 n 次，内层常数次（最多7次）
- **空间复杂度**：O(n)，使用一维 dp 数组

### 方法三：数学优化
- **时间复杂度**：O(n)，单层循环，内层常数次
- **空间复杂度**：O(n)，使用一维 dp 数组

## 图解示例

以 n = 7 为例：

```
步骤 1: A                    -> 1 个 A
步骤 2: A, A                 -> 2 个 A
步骤 3: A, A, A              -> 3 个 A
步骤 4: A, A, A, Ctrl-A      -> 3 个 A (全选)
步骤 5: A, A, A, Ctrl-A, Ctrl-C  -> 3 个 A (复制)
步骤 6: ..., Ctrl-V          -> 6 个 A (粘贴，3+3)
步骤 7: ..., Ctrl-V          -> 9 个 A (粘贴，6+3)

最终得到 9 个 A
```

**为什么不是一直按 A？**
- 一直按 A：7 步只能得到 7 个 A
- 复制粘贴策略：7 步可以得到 9 个 A

## 关键点总结

1. **动态规划思想**：dp[i] 依赖于之前的状态 dp[i-j]
2. **状态转移**：枚举最后一次复制粘贴序列的长度
3. **复制粘贴成本**：至少需要 3 步（Ctrl-A + Ctrl-C + Ctrl-V）
4. **倍数关系**：使用 j 步进行复制粘贴，可以得到 (j-1) 倍的 A
5. **优化观察**：最优解中粘贴长度不会太长（通常不超过5-6次）

## 易错点

1. **初始条件**：n < 3 时只能一直按 A，结果就是 n
2. **循环范围**：j 至少为 3（全选、复制、粘贴各一次）
3. **倍数计算**：j 步操作得到的是 (j-1) 倍，不是 j 倍
4. **状态初始化**：dp[i] 初始值应该是 i（表示一直按 A）
5. **边界处理**：确保数组访问不越界
