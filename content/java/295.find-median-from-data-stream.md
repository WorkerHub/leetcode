## 题目描述

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如：
- [2,3,4] 的中位数是 3
- [2,3] 的中位数是 (2 + 3) / 2 = 2.5

设计一个支持以下两种操作的数据结构：

- void addNum(int num) - 从数据流中添加一个整数到数据结构中。
- double findMedian() - 返回目前所有元素的中位数。

**示例 1：**
```
输入：
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出：
[null, null, null, 1.5, null, 2.0]

解释：
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr = [1, 2, 3]
medianFinder.findMedian(); // 返回 2.0
```

**提示：**
- -10^5 <= num <= 10^5
- 在调用 findMedian 之前，数据结构中至少有一个元素
- 最多调用 5 * 10^4 次 addNum 和 findMedian

**进阶：**
- 如果数据流中所有整数都在 0 到 100 范围内，你将如何优化你的算法？
- 如果数据流中 99% 的整数都在 0 到 100 范围内，你将如何优化你的算法？

## 解题思路

这是一道经典的数据流问题，核心是如何高效地维护中位数。

**方法对比：**

| 方法 | addNum | findMedian | 空间 | 说明 |
|------|--------|------------|------|------|
| 排序数组 | O(n) | O(1) | O(n) | 插入慢 |
| 双堆 | O(log n) | O(1) | O(n) | 最优解 |
| 平衡树 | O(log n) | O(log n) | O(n) | 需要额外操作 |

**双堆解法（推荐）：**

核心思想是维护两个堆：
- **大顶堆（maxHeap）**：存储较小的一半数字
- **小顶堆（minHeap）**：存储较大的一半数字

**关键性质：**
1. 大顶堆的最大值 <= 小顶堆的最小值
2. 两个堆的大小差不超过 1
3. 中位数就在堆顶

**添加元素流程：**
1. 先加入大顶堆，然后将大顶堆的最大值移到小顶堆
2. 如果小顶堆过大，将小顶堆的最小值移回大顶堆
3. 保持：maxHeap.size() == minHeap.size() 或 maxHeap.size() == minHeap.size() + 1

## Java 代码实现

### 方法一：双堆（推荐）

```java
import java.util.PriorityQueue;
import java.util.Collections;

class MedianFinder {
    // 大顶堆：存储较小的一半（Java PriorityQueue 默认是小顶堆，用 Collections.reverseOrder() 变为大顶堆）
    private PriorityQueue<Integer> maxHeap;
    // 小顶堆：存储较大的一半
    private PriorityQueue<Integer> minHeap;

    public MedianFinder() {
        maxHeap = new PriorityQueue<>(Collections.reverseOrder()); // 大顶堆
        minHeap = new PriorityQueue<>();                           // 小顶堆
    }

    public void addNum(int num) {
        // 先加入大顶堆
        maxHeap.offer(num);

        // 将大顶堆的最大值移到小顶堆
        // 保证大顶堆的所有元素 <= 小顶堆的所有元素
        minHeap.offer(maxHeap.poll());

        // 平衡两个堆的大小（保持大顶堆元素个数 >= 小顶堆）
        if (minHeap.size() > maxHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        // 如果两个堆大小相等，中位数是两个堆顶的平均值
        if (maxHeap.size() == minHeap.size()) {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
        // 否则，中位数是大顶堆的堆顶（大顶堆元素多一个）
        return maxHeap.peek();
    }
}
```

### 方法二：简化版双堆

```java
import java.util.PriorityQueue;
import java.util.Collections;

class MedianFinder {
    private PriorityQueue<Integer> small; // 大顶堆 - 较小一半
    private PriorityQueue<Integer> large; // 小顶堆 - 较大一半

    public MedianFinder() {
        small = new PriorityQueue<>(Collections.reverseOrder());
        large = new PriorityQueue<>();
    }

    public void addNum(int num) {
        // 添加到大顶堆
        small.offer(num);

        // 确保 small 的最大值 <= large 的最小值
        if (!small.isEmpty() && !large.isEmpty() && small.peek() > large.peek()) {
            large.offer(small.poll());
        }

        // 平衡大小（small 的元素可以多一个）
        if (small.size() > large.size() + 1) {
            large.offer(small.poll());
        }
        if (large.size() > small.size()) {
            small.offer(large.poll());
        }
    }

    public double findMedian() {
        if (small.size() > large.size()) {
            return small.peek();
        }
        return (small.peek() + large.peek()) / 2.0;
    }
}
```

### 方法三：排序数组（暴力，仅用于对比）

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class MedianFinder {
    private List<Integer> nums;

    public MedianFinder() {
        nums = new ArrayList<>();
    }

    public void addNum(int num) {
        // 二分查找插入位置（保持有序）
        int left = 0, right = nums.size();
        while (left < right) {
            int mid = (left + right) / 2;
            if (nums.get(mid) < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        nums.add(left, num);
    }

    public double findMedian() {
        int n = nums.size();
        if (n % 2 == 1) {
            return nums.get(n / 2);
        } else {
            return (nums.get(n / 2 - 1) + nums.get(n / 2)) / 2.0;
        }
    }
}
```

## 复杂度分析

### 方法一（双堆）：

**时间复杂度：**
- addNum: O(log n) - 堆的插入和删除操作
- findMedian: O(1) - 直接访问堆顶

**空间复杂度：** O(n)
- 需要存储所有 n 个元素

### 方法三（排序数组）：

**时间复杂度：**
- addNum: O(n) - 插入操作需要移动元素
- findMedian: O(1) - 直接访问中间位置

**空间复杂度：** O(n)

## 关键点总结

1. **双堆平衡**：始终保持两个堆大小相差不超过 1
2. **堆的性质**：大顶堆的最大值 <= 小顶堆的最小值
3. **Java 大顶堆**：使用 `Collections.reverseOrder()` 创建大顶堆
4. **插入顺序**：总是先插入大顶堆，再调整平衡
5. **中位数位置**：根据两个堆的大小决定中位数在哪

## 易错点

1. **忘记平衡堆的大小**
   ```java
   // 错误：只移动元素，不检查大小
   maxHeap.offer(num);
   minHeap.offer(maxHeap.poll());
   // 忘记检查 minHeap 是否过大
   
   // 正确：要平衡大小
   if (minHeap.size() > maxHeap.size()) {
       maxHeap.offer(minHeap.poll());
   }
   ```

2. **Java 大顶堆的创建**
   ```java
   // 错误：直接用 PriorityQueue 是小顶堆
   PriorityQueue<Integer> maxHeap = new PriorityQueue<>();
   
   // 正确：用 Collections.reverseOrder() 或 lambda
   PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
   // 或者
   PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
   ```

3. **中位数计算时的整除问题**
   ```java
   // 错误：整数除法（Java 中两个 int 相除结果是 int）
   return (maxHeap.peek() + minHeap.peek()) / 2;
   
   // 正确：确保返回 double
   return (maxHeap.peek() + minHeap.peek()) / 2.0;
   ```

4. **初始化时的边界检查**
   ```java
   // 错误：没有检查堆是否为空
   if (small.peek() > large.peek()) { ... }
   // 如果 large 为空会抛出 NullPointerException
   
   // 正确：先检查是否为空
   if (!small.isEmpty() && !large.isEmpty() && small.peek() > large.peek()) { ... }
   ```
