## 题目描述

给定整数数组 `nums`，每次操作翻转任意元素的任意一位（代价为 1），求使数组所有元素的每一位都完全一致（全 0 或全 1）的最少总操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        int total = 0;

        for (int b = 0; b < 30; b++) { // 10^9 < 2^30
            int ones = 0;
            for (int x : nums) ones += (x >> b) & 1;
            int zeros = n - ones;
            // 该位最少翻转：min(使全为1的代价, 使全为0的代价)
            total += Math.min(ones, zeros);
        }

        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 30)
- 空间复杂度：O(1)

## 关键点总结

1. 各位独立处理：每位要么全变 0，要么全变 1
2. 该位最少翻转 = `min(该位1的个数, 该位0的个数)`
3. 30 位足以覆盖 10^9 范围
