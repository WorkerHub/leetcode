## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**
```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**
```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**提示：**
- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 解题思路

### 方法一：纵向扫描（推荐）
从第一列开始，逐列比较所有字符串的字符。

### 方法二：横向扫描
依次遍历字符串数组，逐个更新最长公共前缀。

## Java 代码实现

### 方法一：纵向扫描（推荐）

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";
        
        // 以第一个字符串的长度为基准
        for (int i = 0; i < strs[0].length(); i++) {
            char c = strs[0].charAt(i);
            
            // 检查其他所有字符串的第i个字符
            for (int j = 1; j < strs.length; j++) {
                // 如果到达某个字符串末尾，或字符不匹配
                if (i == strs[j].length() || strs[j].charAt(i) != c) {
                    return strs[0].substring(0, i);
                }
            }
        }
        
        return strs[0];
    }
}
```

### 方法二：横向扫描

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";
        
        String prefix = strs[0];
        
        for (int i = 1; i < strs.length; i++) {
            // 不断缩短prefix，直到它是strs[i]的前缀
            while (!strs[i].startsWith(prefix)) {
                prefix = prefix.substring(0, prefix.length() - 1);
                if (prefix.isEmpty()) return "";
            }
        }
        
        return prefix;
    }
}
```

### 方法三：分治法

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";
        return divide(strs, 0, strs.length - 1);
    }
    
    private String divide(String[] strs, int start, int end) {
        if (start == end) return strs[start];
        
        int mid = (start + end) / 2;
        String left = divide(strs, start, mid);
        String right = divide(strs, mid + 1, end);
        
        return commonPrefix(left, right);
    }
    
    private String commonPrefix(String left, String right) {
        int minLen = Math.min(left.length(), right.length());
        for (int i = 0; i < minLen; i++) {
            if (left.charAt(i) != right.charAt(i)) {
                return left.substring(0, i);
            }
        }
        return left.substring(0, minLen);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n)，m 是字符串数量，n 是字符串平均长度
- **空间复杂度**：O(1)（分治法为 O(m * log m)）

## 关键点总结

1. **边界条件**：空数组、空字符串需要特殊处理
2. **提前终止**：一旦发现不匹配，可以提前返回
3. **纵向扫描**：代码简洁，推荐使用

## 易错点

1. **空数组检查**：要先判断 `strs` 是否为空
2. **字符串长度**：不同字符串长度可能不同，注意越界
