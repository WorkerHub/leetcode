## 题目描述

字符串的移位是指将字符串中每个字母按照字母表的顺序向某个方向移动固定的步数。例如，将 "abc" 移位 1 步得到 "bcd"，移位 2 步得到 "cde"。

给定一个字符串列表，将相同移位序列的所有字符串分组在一起。你可以按任意顺序返回答案。

**示例 1：**
```
输入: strings = ["abc","bcd","acef","xyz","az","ba","a","z"]
输出: [["acef"],["a","z"],["abc","bcd","xyz"],["az","ba"]]
```

**示例 2：**
```
输入: strings = ["a"]
输出: [["a"]]
```

**提示：**
- 1 <= strings.length <= 200
- 1 <= strings[i].length <= 50
- strings[i] 由小写英文字母组成

## 解题思路

这道题的核心是找到一个**规范化的表示方法**，使得同一移位序列的字符串有相同的特征。

**核心思想：**
- 两个字符串属于同一移位序列，当且仅当它们相邻字符间的"距离"序列相同
- 例如 "abc" 和 "xyz"：
  - "abc": b-a=1, c-b=1 → [1, 1]
  - "xyz": y-x=1, z-y=1 → [1, 1]
  - 它们有相同的距离序列，属于同一组

**关键观察：**
1. **距离序列**：相邻字符的距离差，如 "abc" → (1,1)，"az" → (25)
2. **循环性**：字母表是循环的，'z' 到 'a' 的距离是 1
3. **单字符特殊情况**：单个字符的字符串应该独立分组

**算法设计：**
1. 计算每个字符串的距离序列作为哈希键
2. 使用哈希表将相同距离序列的字符串分组
3. 返回哈希表的所有值

## Java 代码实现

### 方法一：距离序列哈希（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        // 使用字符串形式的距离序列作为哈希键
        Map<String, List<String>> groups = new HashMap<>();
        
        for (String s : strings) {
            String key = getKey(s);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        
        return new ArrayList<>(groups.values());
    }
    
    private String getKey(String s) {
        if (s.length() == 1) {
            return "";  // 单字符返回空字符串
        }
        
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i < s.length(); i++) {
            // 计算相邻字符的距离（处理循环）
            int distance = (s.charAt(i) - s.charAt(i - 1) + 26) % 26;
            sb.append(distance).append(',');
        }
        
        return sb.toString();
    }
}
```

### 方法二：规范化到 'a' 开头（另一种思路）

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        Map<String, List<String>> groups = new HashMap<>();
        
        for (String s : strings) {
            // 规范化：将第一个字符移位到 'a'
            String key = normalize(s);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        
        return new ArrayList<>(groups.values());
    }
    
    private String normalize(String s) {
        if (s.isEmpty()) return "";
        
        // 计算需要移动的步数（使第一个字符变成 'a'）
        int shift = s.charAt(0) - 'a';
        
        // 对每个字符执行反向移位
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            sb.append((char) ((c - shift + 26) % 26 + 'a'));
        }
        
        return sb.toString();
    }
}
```

### 方法三：使用元组列表作为键（完整版）

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        Map<String, List<String>> groups = new HashMap<>();
        
        for (String s : strings) {
            String key = getSignature(s);
            groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        
        return new ArrayList<>(groups.values());
    }
    
    // 生成字符串的特征签名（使用逗号分隔的距离序列）
    private String getSignature(String s) {
        if (s.length() <= 1) {
            return "#"; // 单字符特殊标记
        }
        
        StringBuilder signature = new StringBuilder();
        for (int i = 1; i < s.length(); i++) {
            int diff = (s.charAt(i) - s.charAt(i - 1) + 26) % 26;
            signature.append(diff);
            if (i < s.length() - 1) {
                signature.append(',');
            }
        }
        
        return signature.toString();
    }
}
```

### 方法四：简洁版本

```java
import java.util.*;

class Solution {
    public List<List<String>> groupStrings(String[] strings) {
        Map<String, List<String>> map = new HashMap<>();
        
        for (String s : strings) {
            String key = encode(s);
            if (!map.containsKey(key)) {
                map.put(key, new ArrayList<>());
            }
            map.get(key).add(s);
        }
        
        return new ArrayList<>(map.values());
    }
    
    private String encode(String s) {
        // 构建相邻字符距离的字符串表示
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < s.length() - 1; i++) {
            sb.append((char) ((s.charAt(i + 1) - s.charAt(i) + 26) % 26));
        }
        return sb.toString();
    }
}
```

## 复杂度分析

所有方法的复杂度类似：
- **时间复杂度**：O(n * k)，其中 n 是字符串数量，k 是平均字符串长度
- **空间复杂度**：O(n * k)，存储所有字符串和哈希表

## 图解示例

**示例 1：strings = ["abc","bcd","acef","xyz","az","ba","a","z"]**

```
计算每个字符串的距离序列：

"abc":  b-a=1, c-b=1        → "1,1,"
"bcd":  c-b=1, d-c=1        → "1,1,"
"xyz":  y-x=1, z-y=1        → "1,1,"

"acef": c-a=2, e-c=2, f-e=1 → "2,2,1,"

"az":   z-a=25              → "25,"
"ba":   a-b=(1-2+26)%26=25  → "25,"

"a":    单字符              → ""
"z":    单字符              → ""

分组结果：
  "1,1,":   ["abc", "bcd", "xyz"]
  "2,2,1,": ["acef"]
  "25,":    ["az", "ba"]
  "":       ["a", "z"]
```

**为什么 "az" 和 "ba" 是同一组？**
```
"az": a → z 是向前移动 25 步（或向后移动 1 步）
"ba": b → a 是向前移动 25 步（或向后移动 1 步）

它们的移位模式相同！
```

## 关键点总结

1. **距离序列**：相邻字符的距离差是判断移位序列的关键
2. **循环处理**：使用 `% 26` 处理字母表的循环性
3. **加 26 防负数**：`(diff + 26) % 26` 避免负数问题
4. **单字符处理**：单字符串应该独立分组
5. **Java HashMap**：使用 `computeIfAbsent` 简化分组代码

## 易错点

1. **负数处理**：`(s.charAt(i) - s.charAt(i-1)) % 26` 可能是负数，要加 26
2. **单字符**：忘记特殊处理单字符字符串
3. **键的唯一性**：确保不同移位序列的字符串有不同的键
4. **距离计算**：要理解 "az" 的距离是 25，不是 -1
5. **字符串拼接效率**：使用 `StringBuilder` 而不是 `+` 运算符

**常见追问：**
- Q: 为什么 "az" 和 "ba" 是同一组？
- A: 因为它们的距离序列都是 (25,)，表示向前移动 25 步

- Q: 如果字母表不循环怎么办？
- A: 去掉 % 26 和 + 26，直接计算差值

- Q: 能否用其他方法表示移位序列？
- A: 可以用规范化方法（方法二），将所有字符串规范化到以 'a' 开头
