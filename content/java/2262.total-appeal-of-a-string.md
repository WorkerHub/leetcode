## 题目描述

返回字符串所有子串的吸引力（不同字母数量）之和。

## 解题思路

贡献法：字符s[i]对子串[l,r]有贡献当且仅当它是该子串中首次出现。对每个位置i，贡献次数=(i-last[ch])*(n-i)，其中last[ch]是上次出现位置。

## Java 代码实现

```java
class Solution {
    public long appealSum(String s) {
        int n = s.length();
        int[] last = new int[26];
        Arrays.fill(last, -1);
        long total = 0;

        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            // 字符c对以i结尾的子串的贡献：左端点可从last[c]+1到i
            // 右端点固定为i，所以贡献=(i-last[c])
            // 但要累加到所有以i结尾的子串，用dp递推
            total += (long)(i - last[c]) * (n - i);
            last[c] = i;
        }
        return total;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贡献法**：每个字符对包含它且它首次出现的子串贡献1
2. **左端点范围**：last[c]+1到i，共i-last[c]个
3. **右端点范围**：i到n-1，共n-i个
