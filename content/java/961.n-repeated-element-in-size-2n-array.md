## 题目描述

长度为 2n 的数组包含 n+1 个不同元素，其中一个重复 n 次。找出这个重复元素。

**示例：**
```
输入：nums = [2,1,2,5,3,2]
输出：2
```

## 解题思路

HashSet：遍历数组，遇到重复的就是答案。

## Java 代码实现

```java
class Solution {
    public int repeatedNTimes(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (!seen.add(num)) return num;
        }
        return -1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(n)

## 关键点总结

1. **HashSet 检测重复**：add 返回 false 说明已存在
2. **数学性质**：重复元素占一半，第一个重复的一定是它
3. **简洁实现**：一行核心逻辑
