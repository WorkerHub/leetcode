## 题目描述

给你正整数 `s`，找最大的正整数 `n`，使得对所有 `1 <= i < j <= n` 均有 `i * j <= s`，返回 `n`。

## 解题思路

所有 `i < j` 对中最大乘积为 `(n-1) * n`，条件化简为 `n * (n-1) <= s`。二分查找最大满足条件的 n。

## Java 代码实现

```java
class Solution {
    public int maximumLength(long s) {
        long lo = 1, hi = (long) Math.sqrt(s) + 2;
        while (lo < hi) {
            long mid = (lo + hi + 1) / 2;
            if (mid * (mid - 1) <= s) lo = mid;
            else hi = mid - 1;
        }
        return (int) lo;
    }
}
```

## 复杂度分析

- 时间复杂度：O(log s)，二分查找
- 空间复杂度：O(1)

## 关键点总结

1. 最大约束来自最大的两个相邻整数乘积 `(n-1) * n`
2. 条件化简为 `n * (n-1) <= s`，二分求最大 n
3. 注意使用 `long` 防止乘法溢出（s 可达 10^12）
