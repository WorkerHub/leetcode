## 题目描述

给你两个长度 n 的数组 nums 和 freq，每步 i 后 ID nums[i] 的频率变化 freq[i]，返回每步后出现频率最高的 ID 的频率。

## 解题思路

最大堆 + 懒删除：维护哈希表记录每个 ID 的当前频率，最大堆存 (-freq, id)，堆顶如与实际频率不符则弹出跳过。

## Java 代码实现

```java
class Solution {
    public long[] mostFrequentIDs(int[] nums, int[] freq) {
        int n = nums.length;
        Map<Integer, Long> count = new HashMap<>();
        // 最大堆：{负频率, id}
        PriorityQueue<long[]> heap = new PriorityQueue<>((a, b) ->
            Long.compare(a[0], b[0]));
        long[] result = new long[n];

        for (int i = 0; i < n; i++) {
            int uid = nums[i];
            long newFreq = count.getOrDefault(uid, 0L) + freq[i];
            count.put(uid, newFreq);
            heap.offer(new long[]{-newFreq, uid});

            // 懒删除：弹出过时的堆顶
            while (!heap.isEmpty() && -heap.peek()[0] != count.getOrDefault((int) heap.peek()[1], 0L)) {
                heap.poll();
            }
            result[i] = heap.isEmpty() ? 0 : -heap.peek()[0];
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)，堆操作
- **空间复杂度**：O(n)

## 关键点总结

1. 懒删除：堆中保留旧值，只在查询时验证是否过期
2. 频率可能变为负数，频率 <= 0 的 ID 不计入统计
3. 用 long 防止频率溢出
