## 题目描述

给你一个整数数组 `nums`，返回将 `nums` 分割为最少非递减子数组所需的操作次数（即非递减段的数量）。

## 解题思路

统计数组中相邻元素的下降次数（`nums[i] < nums[i-1]`），答案等于下降次数 + 1（初始有 1 段，每次下降开始新段）。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums) {
        int segments = 1;
        // 每次出现下降就开始新段
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < nums[i - 1]) {
                segments++;
            }
        }
        return segments;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，一次遍历
- 空间复杂度：O(1)

## 关键点总结

1. 将数组分成若干非递减段，段数即操作次数。
2. 每次 `nums[i] < nums[i-1]` 就开始新段。
3. 初始有 1 段，每次下降 +1。
