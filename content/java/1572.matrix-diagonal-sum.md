## 题目描述

返回正方形矩阵两条对角线元素之和（交叉点只计一次）。

**示例：**
```
输入：mat = [[1,2,3],[4,5,6],[7,8,9]]
输出：25
```

## 解题思路

主对角线 mat[i][i]，副对角线 mat[i][n-1-i]，奇数矩阵减去中心重复。

## Java 代码实现

```java
class Solution {
    public int diagonalSum(int[][] mat) {
        int n = mat.length;
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += mat[i][i];           // 主对角线
            sum += mat[i][n - 1 - i];   // 副对角线
        }
        // 奇数矩阵中心被加了两次
        if (n % 2 == 1) {
            sum -= mat[n / 2][n / 2];
        }
        return sum;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **两条对角线**：(i,i) 和 (i,n-1-i)
2. **奇数去重**：中心元素被两条对角线共享
