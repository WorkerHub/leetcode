## 题目描述

给定整数数组 `nums`，对每个下标 `i` 定义贡献为子数组 `nums[max(0, i-nums[i])..i]` 的元素和，返回所有下标贡献之和。

## Java 代码实现

```java
class Solution {
    public int subarraySum(int[] nums) {
        int n = nums.length;
        // 构建前缀和
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];

        int total = 0;
        for (int i = 0; i < n; i++) {
            // 子数组左边界
            int left = Math.max(0, i - nums[i]);
            // 区间 [left, i] 的和
            total += prefix[i + 1] - prefix[left];
        }
        return total;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 前缀和使区间查询降至 O(1)
2. 左边界 `max(0, i-nums[i])` 防止下标越界
3. `prefix[i+1] - prefix[left]` 表示区间 `[left, i]` 的元素和
