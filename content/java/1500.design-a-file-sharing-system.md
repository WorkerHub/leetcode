## 题目描述

我们需要设计一个文件共享系统，用户可以上传/下载文件的某些数据块。该文件只有一个，被分成了 `m` 个**数据块**，编号从 `1` 到 `m`。

实现 `FileSharing` 类：

- `FileSharing(int m)`：用文件的 `m` 个数据块数量初始化该对象。
- `int join(int[] ownedChunks)`：一个新用户加入系统，已经拥有某些数据块 `ownedChunks`。系统分配给该用户**最小的可用**用户 ID（从 1 开始）。返回该用户 ID。
- `void leave(int userID)`：用户 `userID` 离开系统，释放其占用的用户 ID 和所有数据块。
- `int[] request(int userID, int chunkID)`：用户 `userID` 请求数据块 `chunkID`。返回拥有该数据块的**所有用户 ID**（有序），若有用户拥有该块，则用户 `userID` 也会获得该数据块（加入自己的集合）。若无人拥有，返回空数组。

**示例：**

```
fs = FileSharing(4)
fs.join([])         // 返回 1（用户1没有任何数据块）
fs.join([2])        // 返回 2（用户2拥有数据块2）
fs.join([1, 3])     // 返回 3（用户3拥有数据块1和3）
fs.request(1, 3)    // 返回 [3]（用户3有块3），用户1也获得块3
fs.request(2, 2)    // 返回 [2]（用户2有块2），用户2已有无需变化
fs.leave(1)         // 用户1离开
fs.request(2, 1)    // 返回 []（无人有块1）
fs.leave(2)
fs.join([2])        // 返回 1（用户ID 1 被复用，最小可用）
```

**提示：**

- `1 <= m <= 10^5`
- `0 <= ownedChunks.length <= min(100, m)`
- `1 <= ownedChunks[i] <= m`
- `1 <= chunkID <= m`
- `userID` 是一个有效的、当前在系统中的用户
- 每次调用 `join` 时最多有 `10^4` 个用户在系统中
- 最多调用 `10^4` 次 `join`、`leave` 和 `request`

## 解题思路

**数据结构设计：**

1. **用户 ID 管理**：
   - 需要分配"最小可用 ID"，天然适合使用**最小堆**（PriorityQueue）。
   - 当用户离开时，将其 ID 放回堆中。
   - 若堆为空，则分配一个新的递增 ID（`nextId++`）。

2. **数据块拥有者记录**：
   - `chunkToUsers[chunkID]`：有序集合（TreeSet），记录拥有该块的所有用户。
   - `userToChunks[userID]`：记录该用户拥有的所有数据块（用于 `leave` 时清理）。

3. **join 操作**：
   - 从堆中获取最小 ID（或生成新 ID）。
   - 将 `ownedChunks` 注册到 `chunkToUsers` 中。
   - 更新 `userToChunks`。

4. **leave 操作**：
   - 将用户从其所有 `chunkToUsers` 集合中移除。
   - 清空 `userToChunks[userID]`。
   - 将 `userID` 放回最小堆。

5. **request 操作**：
   - 获取 `chunkToUsers[chunkID]` 的有序用户列表。
   - 若非空，将 `userID` 加入该集合，并更新 `userToChunks[userID]`。
   - 返回排序后的用户列表。

## Java 代码实现

### 方法一：最小堆 + HashMap（推荐）

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.Set;
import java.util.TreeSet;

class FileSharing {
    private int nextId;                                 // 下一个新用户 ID
    private PriorityQueue<Integer> availableIds;        // 最小堆，存储可用 ID
    private Map<Integer, TreeSet<Integer>> chunkToUsers; // 数据块 -> 有序用户集合
    private Map<Integer, Set<Integer>> userToChunks;    // 用户 -> 数据块集合

    public FileSharing(int m) {
        nextId = 1;
        availableIds = new PriorityQueue<>();
        chunkToUsers = new HashMap<>();
        userToChunks = new HashMap<>();
    }

    public int join(int[] ownedChunks) {
        // 获取最小可用用户 ID
        int userId = availableIds.isEmpty() ? nextId++ : availableIds.poll();

        // 注册数据块
        Set<Integer> chunks = new HashSet<>();
        for (int chunk : ownedChunks) {
            chunkToUsers.computeIfAbsent(chunk, k -> new TreeSet<>()).add(userId);
            chunks.add(chunk);
        }
        userToChunks.put(userId, chunks);

        return userId;
    }

    public void leave(int userID) {
        // 从所有拥有的数据块中移除该用户
        Set<Integer> chunks = userToChunks.get(userID);
        if (chunks != null) {
            for (int chunk : chunks) {
                TreeSet<Integer> users = chunkToUsers.get(chunk);
                if (users != null) {
                    users.remove(userID);
                }
            }
        }

        // 清空该用户的数据块记录
        userToChunks.remove(userID);

        // 将用户 ID 归还到可用堆
        availableIds.offer(userID);
    }

    public int[] request(int userID, int chunkID) {
        // 获取拥有该数据块的所有用户（TreeSet 已有序）
        TreeSet<Integer> ownerSet = chunkToUsers.get(chunkID);
        if (ownerSet == null || ownerSet.isEmpty()) {
            return new int[0];
        }

        // 记录当前拥有者（不含 userID）
        int[] owners = ownerSet.stream().mapToInt(Integer::intValue).toArray();

        // 若有人拥有该块，userID 也获得该块
        chunkToUsers.computeIfAbsent(chunkID, k -> new TreeSet<>()).add(userID);
        userToChunks.computeIfAbsent(userID, k -> new HashSet<>()).add(chunkID);

        return owners;
    }
}
```

### 方法二：简化版（直接使用 ArrayList 排序，避免 TreeSet）

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.Set;

class FileSharing {
    private int nextId;
    private PriorityQueue<Integer> heap;          // 最小堆，管理可复用 ID
    private Map<Integer, Set<Integer>> chunkOwners; // chunk_id -> 用户集合
    private Map<Integer, Set<Integer>> userChunks;  // user_id -> 块集合

    public FileSharing(int m) {
        nextId = 1;
        heap = new PriorityQueue<>();
        chunkOwners = new HashMap<>();
        userChunks = new HashMap<>();
    }

    public int join(int[] ownedChunks) {
        // 取最小可用 ID
        int uid = heap.isEmpty() ? nextId++ : heap.poll();

        // 注册拥有的数据块
        Set<Integer> chunks = new HashSet<>();
        for (int c : ownedChunks) {
            chunkOwners.computeIfAbsent(c, k -> new HashSet<>()).add(uid);
            chunks.add(c);
        }
        userChunks.put(uid, chunks);

        return uid;
    }

    public void leave(int userID) {
        // 从各数据块中注销
        Set<Integer> chunks = userChunks.remove(userID);
        if (chunks != null) {
            for (int c : chunks) {
                Set<Integer> users = chunkOwners.get(c);
                if (users != null) users.remove(userID);
            }
        }
        // 归还 ID
        heap.offer(userID);
    }

    public int[] request(int userID, int chunkID) {
        Set<Integer> ownerSet = chunkOwners.get(chunkID);
        if (ownerSet == null || ownerSet.isEmpty()) {
            return new int[0];
        }

        // 排序输出
        List<Integer> ownerList = new ArrayList<>(ownerSet);
        Collections.sort(ownerList);

        // 用户 userID 也获得该块
        ownerSet.add(userID);
        userChunks.computeIfAbsent(userID, k -> new HashSet<>()).add(chunkID);

        return ownerList.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

### 方法三：TreeSet 维护有序拥有者（查询最快）

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.PriorityQueue;
import java.util.Set;
import java.util.TreeSet;

class FileSharing {
    private int nextId = 1;
    private PriorityQueue<Integer> availIds = new PriorityQueue<>();
    // 使用 TreeSet 保证每次 request 返回有序结果，O(n) 转数组
    private Map<Integer, TreeSet<Integer>> chunkOwners = new HashMap<>();
    private Map<Integer, Set<Integer>> userChunks = new HashMap<>();

    public FileSharing(int m) {}

    public int join(int[] ownedChunks) {
        int uid = availIds.isEmpty() ? nextId++ : availIds.poll();
        userChunks.put(uid, new HashSet<>());
        for (int c : ownedChunks) {
            chunkOwners.computeIfAbsent(c, k -> new TreeSet<>()).add(uid);
            userChunks.get(uid).add(c);
        }
        return uid;
    }

    public void leave(int userID) {
        for (int c : userChunks.getOrDefault(userID, new HashSet<>())) {
            if (chunkOwners.containsKey(c)) chunkOwners.get(c).remove(userID);
        }
        userChunks.remove(userID);
        availIds.offer(userID);
    }

    public int[] request(int userID, int chunkID) {
        TreeSet<Integer> owners = chunkOwners.getOrDefault(chunkID, new TreeSet<>());
        if (owners.isEmpty()) return new int[0];

        // 取当前拥有者快照（有序）
        int[] result = owners.stream().mapToInt(Integer::intValue).toArray();

        // userID 获得该块
        chunkOwners.computeIfAbsent(chunkID, k -> new TreeSet<>()).add(userID);
        userChunks.computeIfAbsent(userID, k -> new HashSet<>()).add(chunkID);

        return result;
    }
}
```

## 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `join` | O(c log u) | c = ownedChunks 长度，u = 当前用户数 |
| `leave` | O(c log u) | c = 用户拥有的块数 |
| `request` | O(u log u) | 排序 owners，u 为拥有该块的用户数 |

- 空间复杂度：O(u * c + m)，u 为用户数，c 为每用户平均块数，m 为总块数

## 关键点总结

1. **最小堆复用 ID**：保证每次 `join` 返回最小可用 ID，`leave` 时将 ID 归还堆中。
2. **双向映射**：`chunkOwners`（块→用户集合）和 `userChunks`（用户→块集合）相互补充，支持高效的增删查操作。
3. **leave 清理**：离开时必须同时从所有 `chunkOwners` 中移除该用户，以及清除 `userChunks` 中的条目。
4. **request 的幂等性**：若 `userID` 已拥有该块，加入集合不影响结果（集合自动去重）。

## 易错点

- **ID 复用顺序**：离开的用户 ID 必须能被再次分配，且始终返回最小可用 ID。
- **request 中先记录后更新**：先把当前 `owners` 列表记录下来（不含 `userID`），再更新集合（加入 `userID`），否则 `userID` 可能出现在返回列表中。
- **leave 时的清理**：忘记从 `chunkOwners` 中移除用户，会导致后续 `request` 返回已离开的用户。
- **新 ID 的生成逻辑**：需要判断堆是否为空，若为空才递增 `nextId`。
