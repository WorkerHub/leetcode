## 题目描述

对字符串重复执行"找下一个更小排列"的操作直到完全降序，求操作次数mod 10^9+7。等价于求字符串的字典序排名。

## 解题思路

组合数学：每一位的贡献 = 比当前字符小的字符数 × 后缀多重排列数。用费马小定理求模逆元。

## Java 代码实现

```java
class Solution {
    private static final int MOD = 1_000_000_007;
    
    public int makeStringSorted(String s) {
        int n = s.length();
        // 预计算阶乘和逆阶乘
        long[] fact = new long[n + 1];
        long[] invFact = new long[n + 1];
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = power(fact[n], MOD - 2);
        for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % MOD;
        
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;
        
        // 维护 invDenom = 1 / (cnt[0]! * cnt[1]! * ... * cnt[25]!)
        long invDenom = 1;
        for (int c : cnt) invDenom = invDenom * invFact[c] % MOD;
        
        long result = 0;
        for (int i = 0; i < n; i++) {
            int idx = s.charAt(i) - 'a';
            int m = n - i; // 后缀长度
            
            // 比s[i]小的字符总数
            int smaller = 0;
            for (int j = 0; j < idx; j++) smaller += cnt[j];
            
            // 贡献 = smaller * (m-1)! * invDenom
            result = (result + (long) smaller % MOD * fact[m - 1] % MOD * invDenom) % MOD;
            
            // 更新：移除s[i]，invDenom中cnt[idx]!变为(cnt[idx]-1)!
            invDenom = invDenom * cnt[idx] % MOD;
            cnt[idx]--;
        }
        return (int) result;
    }
    
    private long power(long base, long exp) {
        long result = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × 26)
- **空间复杂度**：O(N)

## 关键点总结

1. **操作次数=字典序排名**：比s小的排列数
2. **多重排列数**：(m-1)! / prod(cnt[j]!)
3. **费马小定理求逆元**：模意义下除法
4. **维护invDenom**：移除字符时乘以cnt[ch]
