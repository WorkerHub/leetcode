## 题目描述

给定一个字符串，判断该字符串中的字符是否可以通过重新排列组成一个回文串。

**示例 1：**
```
输入: s = "code"
输出: false
```

**示例 2：**
```
输入: s = "aab"
输出: true
解释: "aab" 可以排列成 "aba"
```

**示例 3：**
```
输入: s = "carerac"
输出: true
解释: "carerac" 可以排列成 "racecar"
```

**提示：**
- `1 <= s.length <= 5000`
- `s` 只包含小写英文字母

## 解题思路

判断一个字符串能否重排为回文串，关键是理解**回文串的特性**。

**回文串的字符特点：**
1. 字符串长度为偶数：所有字符出现次数都是偶数
2. 字符串长度为奇数：只有一个字符出现次数为奇数，其他都是偶数

**核心思路：**
- 统计每个字符的出现次数
- 检查出现奇数次的字符数量
- 如果出现奇数次的字符数量 ≤ 1，返回 true

**举例说明：**
- `"aab"` → a:2, b:1 → 1 个奇数次 → 可以组成 "aba" ✓
- `"code"` → c:1, o:1, d:1, e:1 → 4 个奇数次 → 不能组成回文 ✗
- `"carerac"` → c:2, a:2, r:2, e:1 → 1 个奇数次 → 可以组成 "racecar" ✓

## Java 代码实现

### 方法一：哈希表计数（推荐）⭐

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean canPermutePalindrome(String s) {
        // 统计每个字符的出现次数
        Map<Character, Integer> count = new HashMap<>();
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        // 统计出现奇数次的字符个数
        int oddCount = 0;
        for (int freq : count.values()) {
            if (freq % 2 == 1) {
                oddCount++;
            }
        }

        // 最多只能有一个字符出现奇数次
        return oddCount <= 1;
    }
}
```

### 方法二：数组计数（针对小写字母优化）

```java
class Solution {
    public boolean canPermutePalindrome(String s) {
        // 使用数组代替哈希表（仅适用于小写字母）
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }

        // 统计奇数次字符
        int oddCount = 0;
        for (int freq : count) {
            if (freq % 2 == 1) {
                oddCount++;
                if (oddCount > 1) {
                    return false; // 提前退出优化
                }
            }
        }

        return true;
    }
}
```

### 方法三：集合方法（巧妙）

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean canPermutePalindrome(String s) {
        // 利用集合的性质：
        // - 如果字符出现偶数次，加入再删除，集合不变
        // - 如果字符出现奇数次，最终会留在集合中
        Set<Character> charSet = new HashSet<>();

        for (char c : s.toCharArray()) {
            if (charSet.contains(c)) {
                charSet.remove(c);
            } else {
                charSet.add(c);
            }
        }

        // 最多只能剩下一个字符（奇数次）
        return charSet.size() <= 1;
    }
}
```

### 方法四：位运算（高级）

```java
class Solution {
    public boolean canPermutePalindrome(String s) {
        // 使用位运算优化空间，适用于 26 个小写字母
        // 使用一个整数的每一位表示某个字符出现次数的奇偶性
        int bitmap = 0;

        for (char c : s.toCharArray()) {
            // 计算字符对应的位
            int bit = 1 << (c - 'a');
            // 异或操作：出现偶数次变 0，奇数次变 1
            bitmap ^= bit;
        }

        // 检查 bitmap 是否最多只有 1 位为 1
        // bitmap & (bitmap - 1) 可以消除最右边的 1
        return bitmap == 0 || (bitmap & (bitmap - 1)) == 0;
    }
}
```

## 复杂度分析

### 方法一、二
- **时间复杂度**：O(n)，遍历字符串一次统计，再遍历计数一次检查
- **空间复杂度**：O(k)，k 是字符集大小（小写字母最多 26）

### 方法三（集合）
- **时间复杂度**：O(n)，遍历字符串一次
- **空间复杂度**：O(k)，集合最多存储 k 个字符

### 方法四（位运算）
- **时间复杂度**：O(n)
- **空间复杂度**：O(1)，只用一个整数

## 关键点总结

1. **回文串特性**：字符出现次数必须满足最多一个奇数
2. **计数方法**：
   - HashMap（通用方法）
   - 数组（针对小写字母优化）
   - 集合（巧妙）
   - 位运算（空间最优）
3. **优化技巧**：在统计过程中发现奇数次字符超过 1 个可提前返回
4. **集合方法原理**：利用配对消除的思想
5. **位运算技巧**：`bitmap & (bitmap - 1) == 0` 判断是否只有一位为 1

## 易错点

1. **边界条件**：空字符串可以组成回文（奇数次字符为 0 个）
2. **奇偶判断**：要统计出现**奇数次**的字符个数，不是偶数次
3. **判断条件**：是 `<= 1` 而不是 `== 1`（偶数长度字符串时为 0）
4. **字符集假设**：不要假设只有小写字母，除非题目明确说明
5. **Java 中字符串遍历**：使用 `s.toCharArray()` 或 `s.charAt(i)`

## 学习建议

1. **理解回文的性质**：
   - 偶数长度：所有字符偶数次
   - 奇数长度：一个字符奇数次，其他偶数次

2. **掌握多种实现**：
   - 方法一（HashMap）最常用
   - 方法三（集合）最巧妙
   - 方法四（位运算）面试亮点

3. **位运算技巧**：
   - `bitmap ^= bit`：异或实现奇偶切换
   - `bitmap & (bitmap - 1)`：消除最右边的 1
   - 这两个技巧在很多位运算题中都会用到

4. **举一反三**：
   - 本题只判断是否可以，下一题（267）要求生成所有排列
   - 理解本题是下一题的基础

5. **优化思考**：
   - 能否提前退出？（统计到第 2 个奇数次字符时）
   - 能否用更少的空间？（位运算 O(1)）
