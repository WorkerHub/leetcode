## 题目描述

有 n 个弹珠和 k 个袋子，每个袋子装连续弹珠，得分为首末弹珠重量之和，返回所有分配方案中最大总得分与最小总得分的差值。

## 解题思路

关键观察：无论怎么分，`weights[0]` 和 `weights[n-1]` 固定贡献。分成 k 袋需 k-1 个分割点，每个分割点 i 额外贡献 `weights[i] + weights[i+1]`。答案 = 相邻对之和数组中最大 k-1 个之和减最小 k-1 个之和。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public long putMarbles(int[] weights, int k) {
        if (k == 1) return 0;
        int n = weights.length;
        // 计算相邻对之和
        int[] adj = new int[n - 1];
        for (int i = 0; i < n - 1; i++) adj[i] = weights[i] + weights[i + 1];
        Arrays.sort(adj);

        long maxScore = 0, minScore = 0;
        for (int i = 0; i < k - 1; i++) {
            minScore += adj[i];                  // 最小 k-1 个
            maxScore += adj[n - 2 - i];          // 最大 k-1 个
        }
        return maxScore - minScore;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 首尾弹珠固定贡献，变化量在于 k-1 个分割点的选择
2. 分割点 i 的贡献为 `weights[i] + weights[i+1]`，即相邻对之和
3. 最大 k-1 个 adj 之和减最小 k-1 个即为答案
