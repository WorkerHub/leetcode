## 题目描述

给你一个整数数组 `nums`，每次从下标 `i` 跳到 `j`（`i < j`）得分为 `(j - i) * nums[j]`，返回从下标 `0` 跳到 `n-1` 的最大总分。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public long maxScore(int[] nums) {
        int n = nums.length;
        // 从右到左维护单调递减栈，保留所有"有价值"的跳跃点
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {
                stack.pop();
            }
            stack.push(i);
        }
        // 将栈转为从左到右的列表（单调递增）
        List<Integer> points = new ArrayList<>(stack);
        Collections.reverse(points);

        long ans = 0;
        // 按关键节点顺序累加得分
        for (int i = 1; i < points.size(); i++) {
            int p = points.get(i - 1);
            int j = points.get(i);
            ans += (long) (j - p) * nums[j];
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 贪心策略：只跳到"单调递增"的关键节点
2. 单调栈可以高效找出这些关键节点
3. 跳过的中间节点不会带来更高收益
