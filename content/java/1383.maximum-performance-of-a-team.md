## 题目描述

有 n 名工程师，每人有速度 speed[i] 和效率 efficiency[i]。选最多 k 人组成团队，团队表现值 = sum(speed) × min(efficiency)，返回最大团队表现值对 10^9+7 取余的结果。

## 解题思路

枚举每个工程师作为团队中效率最低的成员：按效率降序排序，依次处理时前面所有人效率均更高，满足最低效率条件。用最小堆维护当前选中的 k 人速度，堆大小超过 k 时弹出最小速度。每次计算速度和 × 当前效率更新答案。时间复杂度 O(n log n)。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int maxPerformance(int n, int[] speed, int[] efficiency, int k) {
        final long MOD = 1_000_000_007L;

        // 按效率降序排序
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> efficiency[b] - efficiency[a]);

        // 最小堆维护当前选中工程师的速度（最多 k 个）
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        long speedSum = 0;
        long ans = 0;

        for (int i : idx) {
            // 将当前工程师加入堆
            minHeap.offer(speed[i]);
            speedSum += speed[i];

            // 超过 k 人时移除速度最小的
            if (minHeap.size() > k) {
                speedSum -= minHeap.poll();
            }

            // 当前工程师是效率最低的，计算团队表现值
            ans = Math.max(ans, speedSum * efficiency[i]);
        }

        return (int) (ans % MOD);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序 O(n log n) + 堆操作 O(n log k)。
- 空间复杂度：O(n)，排序辅助数组和堆。

## 关键点总结

1. 枚举 min(efficiency)：将效率最小值固定后，贪心选速度最大的 k 人。
2. 效率降序处理保证在枚举到效率 e_i 时，前面所有人效率均 ≥ e_i。
3. 取模在最后执行：中间用 `long` 计算，最终返回时取模，避免影响 max 比较。
