## 题目描述

三枚石子放置在数轴上位置 a、b、c，每次只能移动两端石子到中间空位。求使石子连续的最小和最大移动次数。

**示例：**
```
输入：a = 1, b = 2, c = 5
输出：[1, 2]
```

## 解题思路

数学分析：排序后，最大移动 = 总空位数 z-x-2；最小移动分三种情况：已连续(0)、有一侧间隔≤2(1)、否则(2)。

## Java 代码实现

```java
class Solution {
    public int[] numMovesStones(int a, int b, int c) {
        // 排序三个位置
        int[] s = {a, b, c};
        Arrays.sort(s);
        int x = s[0], y = s[1], z = s[2];

        // 最大移动次数：总空位数
        int maxMoves = z - x - 2;

        // 最小移动次数
        int minMoves;
        if (z - x == 2) {
            // 已经连续
            minMoves = 0;
        } else if (y - x <= 2 || z - y <= 2) {
            // 有一侧间隔 ≤ 2，只需移动 1 次
            minMoves = 1;
        } else {
            // 两侧间隔都 > 2，需要移动 2 次
            minMoves = 2;
        }

        return new int[]{minMoves, maxMoves};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **排序后分析**：将三个位置排序为 x < y < z
2. **最大移动**：每次只移动一格，等于总空位数
3. **最小移动分类讨论**：已连续(0)、有一侧间隔≤2(1)、否则(2)
