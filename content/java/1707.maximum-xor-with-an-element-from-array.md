## 题目描述

数组 `nums` 和查询 `queries[i] = [xi, mi]`，第 `i` 个查询返回 `xi` 与 `nums` 中所有 `<= mi` 的元素异或的最大值，若无合法元素则返回 -1。

## 解题思路

**离线排序 + 字典树（Trie）：** 将查询按 `mi` 升序排序，`nums` 也升序排序。双指针推进：处理每个查询前，将 `nums` 中 `<= mi` 的数插入 Trie，然后在 Trie 中查询与 `xi` 异或最大的数。

## Java 代码实现

```java
class Solution {
    private int[][] trie;
    private int trieSize;

    private void insert(int num) {
        int node = 0;
        for (int i = 30; i >= 0; i--) {
            int bit = (num >> i) & 1;
            if (trie[node][bit] == 0) {
                trie[node][bit] = ++trieSize;
            }
            node = trie[node][bit];
        }
    }

    private int query(int num) {
        int node = 0, xorVal = 0;
        for (int i = 30; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit; // 尽量选不同的位
            if (trie[node][want] != 0) {
                xorVal |= (1 << i);
                node = trie[node][want];
            } else if (trie[node][bit] != 0) {
                node = trie[node][bit];
            } else {
                return -1; // 字典树为空
            }
        }
        return xorVal;
    }

    public int[] maximizeXor(int[] nums, int[][] queries) {
        Arrays.sort(nums);
        int q = queries.length;
        Integer[] qi = new Integer[q];
        for (int i = 0; i < q; i++) qi[i] = i;
        Arrays.sort(qi, (a, b) -> queries[a][1] - queries[b][1]);

        // 预分配 Trie：每个数 31 位，最多 nums.length * 31 个节点
        trie = new int[nums.length * 31 + 1][2];
        trieSize = 0;

        int[] ans = new int[q];
        int ei = 0;
        for (int idx : qi) {
            int xi = queries[idx][0], mi = queries[idx][1];
            // 将所有 <= mi 的数插入 Trie
            while (ei < nums.length && nums[ei] <= mi) insert(nums[ei++]);
            ans[idx] = (ei == 0) ? -1 : query(xi);
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + q) log(max_val))
- **空间复杂度**：O(n * 31)

## 关键点总结

1. 离线处理：按 mi 排序，边指针单调推进
2. Trie 查询时贪心：每位尽量选与目标不同的方向
3. 数字最大 1e9，用 31 位表示
