## 题目描述

给定年份 year 和月份 month，返回该月有多少天。

**示例：**
```
输入：year = 2000, month = 2
输出：29
```

## 解题思路

查表 + 闰年判断：非 2 月直接查表，2 月根据闰年规则（能被 400 整除，或能被 4 整除且不能被 100 整除）返回 28 或 29。

## Java 代码实现

```java
class Solution {
    public int numberOfDays(int year, int month) {
        int[] days = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

        if (month != 2) return days[month];

        // 闰年判断
        boolean leap = (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
        return leap ? 29 : 28;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. **闰年规则**：能被 400 整除 OR (能被 4 整除 AND 不能被 100 整除)
2. **查表法**：非 2 月天数固定
3. **注意 1900 年不是闰年**：能被 100 整除但不能被 400 整除
