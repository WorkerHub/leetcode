## 题目描述

给长度为 3 的整数数组表示三角形三边，返回三角形类型："equilateral"（等边）、"isosceles"（等腰）、"scalene"（不等边）或 "none"（不能构成三角形）。

## 解题思路

先排序，检查三角形不等式（最小两边之和 > 最大边），再根据不同值个数判断类型。

## Java 代码实现

```java
class Solution {
    public String triangleType(int[] nums) {
        Arrays.sort(nums);
        int a = nums[0], b = nums[1], c = nums[2];
        if (a + b <= c) return "none";
        if (a == c) return "equilateral";
        if (a == b || b == c) return "isosceles";
        return "scalene";
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 排序后只需检查 a+b > c（最严格的三角不等式）
2. a==c 等价于三边相等（排序后最小==最大）
3. 等腰：排序后 a==b 或 b==c
