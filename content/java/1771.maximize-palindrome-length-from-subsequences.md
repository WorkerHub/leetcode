## 题目描述

给你字符串 `word1` 和 `word2`，从各自选一个非空子序列拼接，返回可构造的最长回文串长度。

## 解题思路

拼接 `s = word1 + word2`，用区间 DP 求最长回文子序列 `dp[i][j]`。在 `s[i]==s[j]` 且 `i` 来自 `word1`（`i < n1`）、`j` 来自 `word2`（`j >= n1`）时更新答案，确保两个字符串各有贡献。

## Java 代码实现

```java
class Solution {
    public int longestPalindrome(String word1, String word2) {
        String s = word1 + word2;
        int n = s.length(), n1 = word1.length();
        int[][] dp = new int[n][n];
        int ans = 0;

        // 长度为 1
        for (int i = 0; i < n; i++) dp[i][i] = 1;

        // 按长度由小到大
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = (len == 2 ? 0 : dp[i + 1][j - 1]) + 2;
                    // i 来自 word1，j 来自 word2，则是有效答案
                    if (i < n1 && j >= n1) ans = Math.max(ans, dp[i][j]);
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }

        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n1+n2)^2)
- **空间复杂度**：O((n1+n2)^2)

## 关键点总结

1. 拼接字符串后求 LPS，但只在跨越分界时更新答案
2. 跨界条件：`i < n1 <= j`
