## 题目描述

给定整数数组 hand 和整数 groupSize，判断能否将牌分成若干组，每组恰好 groupSize 张连续的牌。

**示例：**
```
输入：hand = [1,2,3,6,2,3,4,7,8], groupSize = 3
输出：true（[1,2,3],[2,3,4],[6,7,8]）
```

## 解题思路

贪心：排序后从最小的牌开始组成顺子，用 HashMap 计数，每次消耗连续 groupSize 张。

## Java 代码实现

```java
class Solution {
    public boolean isNStraightHand(int[] hand, int groupSize) {
        if (hand.length % groupSize != 0) return false;

        TreeMap<Integer, Integer> count = new TreeMap<>();
        for (int card : hand) {
            count.merge(card, 1, Integer::sum);
        }

        while (!count.isEmpty()) {
            int first = count.firstKey();
            int numGroups = count.get(first);

            for (int i = 0; i < groupSize; i++) {
                int card = first + i;
                Integer cnt = count.get(card);
                if (cnt == null || cnt < numGroups) return false;
                if (cnt == numGroups) {
                    count.remove(card);
                } else {
                    count.put(card, cnt - numGroups);
                }
            }
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **贪心策略**：从最小的牌开始组顺子
2. **TreeMap**：自动排序的计数器
3. **整除检查**：总牌数必须是 groupSize 的倍数
