## 题目描述

给你整数数组 `nums` 和 `divisors`，`divisors[i]` 的可整除性分数为 `nums` 中能被其整除的元素数，返回分数最大的 `divisors[i]`，相同分数时返回最小值。

## Java 代码实现

```java
class Solution {
    public int maxDivScore(int[] nums, int[] divisors) {
        int bestScore = -1, bestDiv = Integer.MAX_VALUE;
        for (int d : divisors) {
            int score = 0;
            for (int x : nums) {
                if (x % d == 0) score++;
            }
            // 分数更大，或相同分数时取更小的除数
            if (score > bestScore || (score == bestScore && d < bestDiv)) {
                bestScore = score;
                bestDiv = d;
            }
        }
        return bestDiv;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * m)，n 为 nums 长度，m 为 divisors 长度
- 空间复杂度：O(1)

## 关键点总结

1. 更新条件：分数更大，或分数相同且除数更小
2. 遍历所有除数（含重复值）均正确
