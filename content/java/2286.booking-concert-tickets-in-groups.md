## 题目描述

设计演唱会订票系统，支持gather(同排k人)和scatter(分散k人到多排)操作。

## 解题思路

线段树维护区间最大剩余和区间总剩余。gather用线段树二分找第一个剩余>=k的排；scatter检查总剩余后逐排填充。

## Java 代码实现

```java
class BookMyShow {
    private int n, m;
    private long[] sumTree;
    private int[] maxTree;
    private long[] seats; // 每排剩余

    public BookMyShow(int n, int m) {
        this.n = n;
        this.m = m;
        sumTree = new long[4 * n];
        maxTree = new int[4 * n];
        seats = new long[n];
        Arrays.fill(seats, m);
        build(1, 0, n - 1);
    }

    private void build(int node, int l, int r) {
        if (l == r) { sumTree[node] = m; maxTree[node] = m; return; }
        int mid = (l + r) / 2;
        build(2 * node, l, mid); build(2 * node + 1, mid + 1, r);
        pushUp(node);
    }

    private void pushUp(int node) {
        sumTree[node] = sumTree[2 * node] + sumTree[2 * node + 1];
        maxTree[node] = Math.max(maxTree[2 * node], maxTree[2 * node + 1]);
    }

    private void update(int node, int l, int r, int idx, long val) {
        if (l == r) { sumTree[node] = val; maxTree[node] = (int) val; return; }
        int mid = (l + r) / 2;
        if (idx <= mid) update(2 * node, l, mid, idx, val);
        else update(2 * node + 1, mid + 1, r, idx, val);
        pushUp(node);
    }

    private int findFirst(int node, int l, int r, int ql, int qr, int k) {
        if (maxTree[node] < k || l > qr || r < ql) return -1;
        if (l == r) return l;
        int mid = (l + r) / 2;
        int left = findFirst(2 * node, l, mid, ql, qr, k);
        return left != -1 ? left : findFirst(2 * node + 1, mid + 1, r, ql, qr, k);
    }

    private long querySum(int node, int l, int r, int ql, int qr) {
        if (ql > qr || l > qr || r < ql) return 0;
        if (ql <= l && r <= qr) return sumTree[node];
        int mid = (l + r) / 2;
        return querySum(2 * node, l, mid, ql, qr) + querySum(2 * node + 1, mid + 1, r, ql, qr);
    }

    public int[] gather(int k, int maxRow) {
        int row = findFirst(1, 0, n - 1, 0, maxRow, k);
        if (row == -1) return new int[]{};
        int col = (int)(m - seats[row]);
        seats[row] -= k;
        update(1, 0, n - 1, row, seats[row]);
        return new int[]{row, col};
    }

    public boolean scatter(int k, int maxRow) {
        long total = querySum(1, 0, n - 1, 0, maxRow);
        if (total < k) return false;
        long remaining = k;
        int row = findFirst(1, 0, n - 1, 0, maxRow, 1);
        while (remaining > 0) {
            long take = Math.min(seats[row], remaining);
            seats[row] -= take;
            update(1, 0, n - 1, row, seats[row]);
            remaining -= take;
            if (remaining > 0) row = findFirst(1, 0, n - 1, row + 1, maxRow, 1);
        }
        return true;
    }
}
```

## 复杂度分析

- **gather**：O(log N)
- **scatter**：均摊O(log² N)

## 关键点总结

1. **线段树维护最大值和总和**
2. **findFirst在线段树上二分**：找最前满足条件的排
3. **scatter逐排填充**：找下一个有剩余的排
