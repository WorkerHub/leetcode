## 题目描述

给定 `n`，返回 `[1,2,...,n]` 的错排数量（没有元素在原位），结果 mod 10^9+7。

**示例：**
```
输入：n = 3
输出：2（[2,3,1] 和 [3,1,2]）
```

## 解题思路

错排递推公式：`D(n) = (n-1) × [D(n-1) + D(n-2)]`，D(1)=0, D(2)=1。

## Java 代码实现

```java
class Solution {
    public int findDerangement(int n) {
        if (n == 1) return 0;
        if (n == 2) return 1;

        int MOD = 1_000_000_007;
        long prev2 = 0; // D(1)
        long prev1 = 1; // D(2)

        for (int i = 3; i <= n; i++) {
            long curr = (i - 1) * (prev1 + prev2) % MOD;
            prev2 = prev1;
            prev1 = curr;
        }

        return (int) prev1;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **递推公式**：D(n) = (n-1) × [D(n-1) + D(n-2)]
2. **滚动变量**：只需前两个状态
3. **取模**：每步都取模防溢出
