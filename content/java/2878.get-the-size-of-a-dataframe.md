## 题目描述

给定 DataFrame players，返回其行数和列数，格式为 `[rows, columns]`。

## 解题思路

本题为 Python Pandas 专项练习，使用 `df.shape` 属性获取 `(rows, cols)` 元组。

## Java 代码实现

```java
// 本题为 Pandas 专项练习
// df.shape 等价于获取二维表格的行数和列数

class Solution {
    // Java 中使用二维数组或列表时的等价操作
    public int[] getDataframeSize(int[][] data, int cols) {
        int rows = data.length;
        return new int[]{rows, cols};
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. `df.shape` 返回 `(rows, columns)` 元组
2. `len(df)` 获取行数，`len(df.columns)` 获取列数
3. 需要返回列表格式 `[rows, cols]`
