## 题目描述

给定整数 `n` 和 `k`，每次操作可将 `n` 减去 `k` 的某个正整数次幂（可重复使用），判断能否将 `n` 变为 0。

## Java 代码实现

```java
class Solution {
    public boolean checkZero(int n, int k) {
        // 完全背包：物品为 k 的各幂次，能否凑成 n
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        long p = k;
        while (p <= n) {
            for (int i = (int) p; i <= n; i++) {
                if (dp[i - (int) p]) dp[i] = true;
            }
            p *= k;
        }
        return dp[n];
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * log_k(n))，幂次数量为 O(log_k(n))
- 空间复杂度：O(n)

## 关键点总结

1. 问题等价于完全背包：物品为 k 的各幂次，背包容量为 n
2. 幂次可重复使用（完全背包而非 0/1 背包）
3. 使用 `long` 计算幂次防止乘法溢出
