## 题目描述

给你一个由若干括号和字母组成的字符串 `s`，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按**任意顺序**返回。

**示例 1：**
```
输入：s = "()())()"
输出：["(())()","()()()"]
```

**示例 2：**
```
输入：s = "(a)())()"
输出：["(a())()","(a)()()"]
```

**示例 3：**
```
输入：s = ")("
输出：[""]
```

**提示：**
- `1 <= s.length <= 25`
- `s` 由小写英文字母以及括号 `'('` 和 `')'` 组成
- `s` 中至多含 20 个括号

## 解题思路

这道题的核心是找到需要删除的**最小数量**的括号，使得字符串有效。关键点：

1. **先确定需要删除的数量**：
   - 遍历字符串，统计需要删除的左括号和右括号数量
   - 左括号过多：出现了多余的 `(`
   - 右括号过多：出现了无法匹配的 `)`

2. **使用 BFS 或 DFS 生成所有可能的删除方案**：
   - BFS 方法：每次删除一个括号，层层扩展，第一次得到有效字符串时就是最小删除
   - DFS 方法：记录需要删除的左右括号数量，递归尝试删除

3. **去重**：使用 set 存储结果，避免重复

## Java 代码实现

### 方法一：BFS（推荐）⭐

```java
import java.util.*;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        Set<String> visited = new HashSet<>();
        visited.add(s);
        Queue<String> queue = new ArrayDeque<>();
        queue.offer(s);
        boolean found = false; // 标记是否找到有效字符串

        while (!queue.isEmpty()) {
            String current = queue.poll();

            // 检查当前字符串是否有效
            if (isValid(current)) {
                result.add(current);
                found = true;
            }

            // 如果已经找到有效字符串，就不再继续删除（保证最小删除）
            if (found) continue;

            // 尝试删除每个位置的括号
            for (int i = 0; i < current.length(); i++) {
                // 只删除括号
                if (current.charAt(i) != '(' && current.charAt(i) != ')') continue;

                // 删除第 i 个字符
                String next = current.substring(0, i) + current.substring(i + 1);

                // 去重
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }

        return result;
    }

    private boolean isValid(String s) {
        // 判断字符串是否有效
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') count++;
            else if (c == ')') {
                count--;
                if (count < 0) return false;
            }
        }
        return count == 0;
    }
}
```

### 方法二：DFS + 剪枝（更优）⭐⭐

```java
import java.util.*;

class Solution {
    private List<String> result = new ArrayList<>();
    private String s;

    public List<String> removeInvalidParentheses(String s) {
        this.s = s;
        // 先计算需要删除的左右括号数量
        int leftRemove = 0, rightRemove = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                leftRemove++;
            } else if (c == ')') {
                if (leftRemove > 0) leftRemove--;
                else rightRemove++;
            }
        }

        dfs(0, 0, 0, leftRemove, rightRemove, new StringBuilder());

        // 去重
        return new ArrayList<>(new HashSet<>(result));
    }

    private void dfs(int index, int leftCount, int rightCount,
                     int leftRem, int rightRem, StringBuilder path) {
        // 递归终止条件
        if (index == s.length()) {
            if (leftRem == 0 && rightRem == 0) {
                result.add(path.toString());
            }
            return;
        }

        char c = s.charAt(index);

        // 情况1：删除当前字符（如果是括号且还需要删除）
        if (c == '(' && leftRem > 0) {
            // 删除左括号
            dfs(index + 1, leftCount, rightCount, leftRem - 1, rightRem, path);
        }
        if (c == ')' && rightRem > 0) {
            // 删除右括号
            dfs(index + 1, leftCount, rightCount, leftRem, rightRem - 1, path);
        }

        // 情况2：保留当前字符
        path.append(c);
        if (c != '(' && c != ')') {
            // 不是括号，直接加入
            dfs(index + 1, leftCount, rightCount, leftRem, rightRem, path);
        } else if (c == '(') {
            // 保留左括号
            dfs(index + 1, leftCount + 1, rightCount, leftRem, rightRem, path);
        } else if (rightCount < leftCount) {
            // 保留右括号（但必须保证右括号不超过左括号）
            dfs(index + 1, leftCount, rightCount + 1, leftRem, rightRem, path);
        }
        path.deleteCharAt(path.length() - 1);
    }
}
```

### 方法三：DFS + 优化去重

```java
import java.util.*;

class Solution {
    private List<String> result = new ArrayList<>();
    private String s;

    public List<String> removeInvalidParentheses(String s) {
        this.s = s;
        // 计算需要删除的左右括号数量
        int leftRemove = 0, rightRemove = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') leftRemove++;
            else if (c == ')') {
                if (leftRemove > 0) leftRemove--;
                else rightRemove++;
            }
        }

        dfs(0, leftRemove, rightRemove, 0, 0, "");
        return result;
    }

    private void dfs(int start, int leftRem, int rightRem,
                     int leftCount, int rightCount, String path) {
        if (leftRem == 0 && rightRem == 0) {
            if (isValid(path)) {
                result.add(path);
            }
            return;
        }

        for (int i = start; i < s.length(); i++) {
            // 去重：跳过连续相同的括号
            if (i > start && s.charAt(i) == s.charAt(i - 1)) continue;

            // 剪枝：剩余字符不够删除
            if (leftRem + rightRem > s.length() - i) break;

            char c = s.charAt(i);

            // 尝试删除左括号
            if (leftRem > 0 && c == '(') {
                dfs(i + 1, leftRem - 1, rightRem, leftCount, rightCount, path);
            }

            // 尝试删除右括号
            if (rightRem > 0 && c == ')') {
                dfs(i + 1, leftRem, rightRem - 1, leftCount, rightCount, path);
            }

            // 保留当前字符
            path += c;
            if (c == '(') leftCount++;
            else if (c == ')') rightCount++;

            // 剪枝：右括号已经多于左括号
            if (rightCount > leftCount) break;
        }
    }

    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') count++;
            else if (c == ')') {
                count--;
                if (count < 0) return false;
            }
        }
        return count == 0;
    }
}
```

## 复杂度分析

**方法一（BFS）：**
- 时间复杂度：O(2^n)，最坏情况下需要尝试所有删除组合
- 空间复杂度：O(2^n)，队列和 visited 集合的空间

**方法二（DFS）：**
- 时间复杂度：O(2^n)，每个括号有删除和保留两种选择
- 空间复杂度：O(n)，递归栈的深度

## 关键点总结

1. **先计算最小删除数量**：遍历字符串，统计需要删除的左右括号数量
2. **BFS 保证最小删除**：第一次遇到有效字符串时，就是删除最少的方案
3. **DFS 需要预先计算**：通过预先计算删除数量来保证最小删除
4. **剪枝优化**：
   - 右括号数量不能超过左括号数量
   - 跳过连续相同的括号避免重复
5. **去重**：使用 set 或在递归中避免重复

## 易错点

1. **忘记去重**：不同的删除方案可能产生相同的结果
2. **没有保证最小删除**：必须先计算需要删除的数量
3. **剪枝不当**：过度剪枝可能漏掉正确答案
4. **边界条件**：空字符串、全是字母、全是括号等情况
