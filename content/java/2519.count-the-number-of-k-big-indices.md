## 题目描述

给你整数数组 `nums` 和正整数 `k`，若下标 `i` 左边至少有 `k` 个严格小于 `nums[i]` 的元素且右边也至少有 `k` 个，则称 `i` 为 k-big，返回 k-big 下标的数目。

## 解题思路

用树状数组（BIT）分两次扫描：从左到右计算每个位置左侧严格小于当前值的数量，再从右到左计算右侧，两者均 >= k 则统计。

## Java 代码实现

```java
class Solution {
    int[] bit;
    int maxVal;

    public int kBigIndices(int[] nums, int k) {
        int n = nums.length;
        maxVal = 0;
        for (int v : nums) maxVal = Math.max(maxVal, v);

        // 计算左侧小于 nums[i] 的数量
        int[] left = new int[n];
        bit = new int[maxVal + 1];
        for (int i = 0; i < n; i++) {
            left[i] = query(nums[i] - 1);
            update(nums[i]);
        }

        // 计算右侧小于 nums[i] 的数量
        int[] right = new int[n];
        bit = new int[maxVal + 1];
        for (int i = n - 1; i >= 0; i--) {
            right[i] = query(nums[i] - 1);
            update(nums[i]);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (left[i] >= k && right[i] >= k) ans++;
        }
        return ans;
    }

    // 树状数组单点更新
    private void update(int i) {
        for (; i <= maxVal; i += i & (-i)) bit[i]++;
    }

    // 树状数组前缀查询 [1, i]
    private int query(int i) {
        int s = 0;
        for (; i > 0; i -= i & (-i)) s += bit[i];
        return s;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log M)，M 为值域大小
- **空间复杂度**：O(n + M)

## 关键点总结

1. 问题分解为：左侧严格小于当前值的数量 + 右侧严格小于当前值的数量
2. 树状数组 `query(nums[i] - 1)` 精确统计严格小于的数量
3. 两次独立扫描（从左和从右）分别构建 BIT
