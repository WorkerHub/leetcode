## 题目描述

对每个查询字符串，在 wordsContainer 中找与其有最长公共后缀的字符串（多个最长则取最短的，再取下标最小的），返回下标数组。

## 解题思路

反转所有字符串，将后缀匹配转化为前缀匹配，构建 Trie。每个节点存储当前路径上的"最优"字符串（最短且下标最小），查询时沿 Trie 走到最深匹配节点取最优值。

## Java 代码实现

```java
class Solution {
    int[] trieChildren[];
    int[] trieNext; // 每个节点的最优字符串下标
    int trieSize = 1;
    String[] container;

    public int[] stringIndices(String[] wordsContainer, String[] wordsQuery) {
        this.container = wordsContainer;
        int maxLen = 0;
        for (String s : wordsContainer) maxLen += s.length();
        trieChildren = new int[maxLen + 1][26];
        trieNext = new int[maxLen + 1];
        Arrays.fill(trieNext, -1);

        for (int i = 0; i < wordsContainer.length; i++) {
            insert(wordsContainer[i], i);
        }

        int[] result = new int[wordsQuery.length];
        for (int i = 0; i < wordsQuery.length; i++) {
            result[i] = query(wordsQuery[i]);
        }
        return result;
    }

    private boolean isBetter(int newIdx, int oldIdx) {
        if (oldIdx == -1) return true;
        int nl = container[newIdx].length(), ol = container[oldIdx].length();
        return nl < ol || (nl == ol && newIdx < oldIdx);
    }

    private void insert(String word, int idx) {
        int node = 0;
        if (isBetter(idx, trieNext[0])) trieNext[0] = idx;
        for (int i = word.length() - 1; i >= 0; i--) {
            int c = word.charAt(i) - 'a';
            if (trieChildren[node][c] == 0) {
                trieChildren[node][c] = trieSize++;
                trieNext[trieChildren[node][c]] = -1;
            }
            node = trieChildren[node][c];
            if (isBetter(idx, trieNext[node])) trieNext[node] = idx;
        }
    }

    private int query(String word) {
        int node = 0, best = trieNext[0];
        for (int i = word.length() - 1; i >= 0; i--) {
            int c = word.charAt(i) - 'a';
            if (trieChildren[node][c] == 0) break;
            node = trieChildren[node][c];
            best = trieNext[node];
        }
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O((n + m) * L)，L 为最大字符串长度
- **空间复杂度**：O(n * L)，Trie 大小

## 关键点总结

1. 将后缀匹配转化为前缀匹配（从字符串末尾向前遍历）
2. Trie 每个节点记录"最优"字符串（最短、下标最小）
3. 查询时沿 Trie 走，最深匹配节点的最优值即为答案
