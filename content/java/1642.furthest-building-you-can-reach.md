## 题目描述

给你整数数组 `heights`、砖块数 `bricks` 和梯子数 `ladders`。从建筑 0 出发，遇到更高的建筑需要用砖块（差值数量）或梯子（无视高度差）。返回最远能到达的建筑下标。

## 解题思路

**贪心 + 最小堆：** 尽可能将梯子用在高度差最大处。

遇到上坡先假装用梯子（压入最小堆）。若梯子数超出 `ladders`，把堆中最小的高度差换成砖块。砖块不够则停止。

## Java 代码实现

```java
class Solution {
    public int furthestBuilding(int[] heights, int bricks, int ladders) {
        // 最小堆，存放已假装用梯子的高度差
        PriorityQueue<Integer> heap = new PriorityQueue<>();

        for (int i = 0; i < heights.length - 1; i++) {
            int diff = heights[i + 1] - heights[i];

            if (diff <= 0) continue; // 下坡或平路，直接走

            // 先用梯子（压入堆中）
            heap.offer(diff);

            // 若梯子用超了，把最小的高度差换成砖块
            if (heap.size() > ladders) {
                bricks -= heap.poll(); // 用砖块弥补最小差值
                if (bricks < 0) return i; // 砖块不够，停在当前建筑
            }
        }

        return heights.length - 1; // 能到达最后一栋
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log k)，k 为梯子数量
- **空间复杂度**：O(k)

## 关键点总结

1. 贪心：梯子用在最大高度差处，小差值用砖块
2. 最小堆维护已用梯子的差值，超出数量时换出最小值改用砖块
3. 砖块不够时立即返回当前位置 i（不是 i+1）
