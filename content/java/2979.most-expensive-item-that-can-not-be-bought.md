## 题目描述

给你两个互质正整数 `primeOne` 和 `primeTwo`，返回无法被表示为 `a*primeOne + b*primeTwo`（a,b>=0）的最大整数。

## 解题思路

直接套 Frobenius 硬币问题公式：两个互质整数 a、b 的最大不可表示数 = `a*b - a - b`。

## Java 代码实现

```java
class Solution {
    public long mostExpensiveItem(int primeOne, int primeTwo) {
        // Frobenius 公式：a*b - a - b
        return (long) primeOne * primeTwo - primeOne - primeTwo;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(1)
- **空间复杂度**：O(1)

## 关键点总结

1. 鸡块数问题（Frobenius coin problem）：两个互质整数的最大不可表示数 = a*b-a-b
2. 互质（gcd=1）是公式成立的前提
3. 结果可达 10^18，需用 long
