## 题目描述

股价折线图用最少线段表示，相邻点共线可合并为一条线段。

## 解题思路

按日期排序，遍历相邻三点判断是否共线。用交叉乘法(y2-y1)*(x3-x2)!=(y3-y2)*(x2-x1)判断斜率变化，避免浮点误差。

## Java 代码实现

```java
class Solution {
    public int minimumLines(int[][] stockPrices) {
        int n = stockPrices.length;
        if (n <= 1) return 0;
        Arrays.sort(stockPrices, (a, b) -> a[0] - b[0]);

        int lines = 1;
        for (int i = 2; i < n; i++) {
            long x1 = stockPrices[i - 2][0], y1 = stockPrices[i - 2][1];
            long x2 = stockPrices[i - 1][0], y2 = stockPrices[i - 1][1];
            long x3 = stockPrices[i][0], y3 = stockPrices[i][1];
            // 交叉乘法判断共线
            if ((y2 - y1) * (x3 - x2) != (y3 - y2) * (x2 - x1)) {
                lines++;
            }
        }
        return lines;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **交叉乘法判断共线**：避免浮点精度问题
2. **用long防溢出**：坐标值乘积可能超int
3. **每次斜率变化则线段数+1**
