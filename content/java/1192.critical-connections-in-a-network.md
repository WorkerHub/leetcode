## 题目描述

给定 n 台服务器和无向连接列表，找出所有关键连接（删除后会导致图不连通的边，即"桥"）。

**示例：**
```
输入：n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
输出：[[1,3]]
```

## 解题思路

Tarjan 算法求桥：DFS 遍历，维护 `dfn[u]`（访问时间戳）和 `low[u]`（能回溯到的最早时间戳）。若 `low[v] > dfn[u]`，则 (u,v) 是桥。

## Java 代码实现

```java
class Solution {
    private int timer = 0;
    
    public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
        // 建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (List<Integer> conn : connections) {
            graph.get(conn.get(0)).add(conn.get(1));
            graph.get(conn.get(1)).add(conn.get(0));
        }
        
        int[] dfn = new int[n];
        int[] low = new int[n];
        Arrays.fill(dfn, -1);
        
        List<List<Integer>> result = new ArrayList<>();
        dfs(0, -1, graph, dfn, low, result);
        return result;
    }
    
    private void dfs(int u, int parent, List<List<Integer>> graph, int[] dfn, int[] low, List<List<Integer>> result) {
        dfn[u] = low[u] = timer++;
        
        for (int v : graph.get(u)) {
            if (v == parent) continue;
            if (dfn[v] == -1) {
                dfs(v, u, graph, dfn, low, result);
                low[u] = Math.min(low[u], low[v]);
                // 桥的判断条件
                if (low[v] > dfn[u]) {
                    result.add(Arrays.asList(u, v));
                }
            } else {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
    }
}
```

## 复杂度分析

- **时间复杂度**：O(V + E)
- **空间复杂度**：O(V + E)

## 关键点总结

1. **Tarjan 算法**：DFS + 时间戳 + low 值回溯
2. **桥的条件**：`low[v] > dfn[u]` 表示 v 无法绕过 (u,v) 回到更早节点
3. **跳过父节点**：避免把树边误判为回边
4. **dfn=-1 判未访问**：区分已访问和未访问节点
