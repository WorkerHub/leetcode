## 题目描述

找数组中值等于target的元素与start的最小距离。

## 解题思路

线性扫描，遇到等于target的位置计算|i - start|，取最小值。

## Java 代码实现

```java
class Solution {
    public int getMinDistance(int[] nums, int target, int start) {
        int minDist = Integer.MAX_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == target) {
                minDist = Math.min(minDist, Math.abs(i - start));
            }
        }
        return minDist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **线性扫描**：遍历所有等于target的位置
2. **绝对值距离**：Math.abs(i - start)
