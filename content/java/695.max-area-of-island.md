## 题目描述

m×n 二进制矩阵，1 为陆地 0 为水，返回最大岛屿面积（四连通），无岛屿返回 0。

**示例：**
```
输入：grid = [[0,0,1,0,...],...]
输出：6
```

## 解题思路

DFS：遍历矩阵，遇到 1 开始 DFS，标记已访问（置0），递归四个方向，返回面积，更新最大值。

## Java 代码实现

```java
class Solution {
    private int[][] grid;
    private int m, n;

    public int maxAreaOfIsland(int[][] grid) {
        this.grid = grid;
        m = grid.length;
        n = grid[0].length;
        int maxArea = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    maxArea = Math.max(maxArea, dfs(i, j));
                }
            }
        }
        return maxArea;
    }

    private int dfs(int i, int j) {
        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == 0) {
            return 0;
        }
        grid[i][j] = 0; // 标记已访问
        return 1 + dfs(i + 1, j) + dfs(i - 1, j) + dfs(i, j + 1) + dfs(i, j - 1);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m × n)
- **空间复杂度**：O(m × n)，递归栈最坏情况

## 关键点总结

1. **DFS 模板**：边界检查 + 标记 + 递归四方向
2. **面积累加**：当前 1 + 四方向递归结果
3. **标记已访问**：置 0 防止重复访问
