## 题目描述

给你一个 `m x n` 的矩阵，值为 0（空格）、1（障碍物）或 2（目标），从 `(0, 0)` 出发，每步移动代价为 1，遇到障碍物需额外代价 1 移除，返回到达任意目标格子的最少总代价。

## 解题思路

Dijkstra 最短路：移动到空格代价 1，移动到障碍物代价 2（移动 + 移除）。用优先队列维护当前最小代价节点，到达目标格子时返回。

## Java 代码实现

```java
import java.util.PriorityQueue;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) java.util.Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        // 优先队列：{代价, 行, 列}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, 0, 0});

        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int cost = cur[0], r = cur[1], c = cur[2];

            // 剪枝：非最优路径跳过
            if (cost > dist[r][c]) continue;

            // 到达目标
            if (grid[r][c] == 2) return cost;

            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;

                // 障碍物代价 2，空格代价 1
                int moveCost = (grid[nr][nc] == 1) ? 2 : 1;
                int newCost = cost + moveCost;

                if (newCost < dist[nr][nc]) {
                    dist[nr][nc] = newCost;
                    pq.offer(new int[]{newCost, nr, nc});
                }
            }
        }

        return -1;
    }
}
```

## 复杂度分析

- 时间复杂度：O(mn log(mn))，Dijkstra 加优先队列
- 空间复杂度：O(mn)

## 关键点总结

1. 移动到障碍物代价 2（移动 + 移除），空格代价 1（仅移动）。
2. Dijkstra 适用于边权为正整数的最短路问题。
3. 到达任意目标格子（值为 2）时即可返回结果。
