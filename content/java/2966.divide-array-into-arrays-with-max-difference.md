## 题目描述

给你长度为 n（n 为 3 的倍数）的整数数组 `nums` 和正整数 `k`，将其分成 n/3 个大小为 3 的子数组，要求每个子数组最大最小差不超过 `k`，返回分法（无解返回空数组）。

## 解题思路

排序后贪心地将每三个连续元素分为一组。若任意一组首尾差 > k 则无解。

## Java 代码实现

```java
class Solution {
    public int[][] divideArray(int[] nums, int k) {
        Arrays.sort(nums);
        int n = nums.length;
        int[][] result = new int[n / 3][3];

        for (int i = 0; i < n; i += 3) {
            if (nums[i + 2] - nums[i] > k) return new int[0][]; // 不可行
            result[i / 3] = new int[]{nums[i], nums[i + 1], nums[i + 2]};
        }
        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. 贪心：排序后相邻三个分一组，是使组内差最小的最优策略
2. 每组首尾差（排序后）= 最大最小差，只需检查首尾
3. 任意一组不满足则整体无解
