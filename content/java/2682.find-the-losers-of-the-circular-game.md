## 题目描述

`n` 个人围成一圈，游戏从第 1 人出发，第 `i` 次传 `i*k` 个位置，直到某人收到第二次球，返回从未收到球的人的编号列表（升序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public List<Integer> circularGameLosers(int n, int k) {
        boolean[] received = new boolean[n + 1];
        int pos = 1, step = k;

        while (!received[pos]) {
            received[pos] = true;
            pos = (pos - 1 + step) % n + 1; // 循环位置（1-indexed）
            step += k;
        }

        List<Integer> losers = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (!received[i]) losers.add(i);
        }
        return losers;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，最多传 n 次
- 空间复杂度：O(n)

## 关键点总结

1. 模拟游戏：每次步长增加 k，循环位置公式 `(pos - 1 + step) % n + 1`
2. 记录收到球的人，最终返回未收到的
