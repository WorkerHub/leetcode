## 题目描述

2xn 矩阵中，机器人一先走（清零所过格子），机器人二后走，两者都最优策略，返回机器人二的最大得分。

## 解题思路

机器人一在某列 j 从第 0 行转入第 1 行，机器人二只能拿第一行 j+1 到 n-1 的和（`topSuffix[j+1]`）或第二行 0 到 j-1 的和（`botPrefix[j]`），取两者最大值。机器人一枚举所有转弯列，取使机器人二得分最小的列。

## Java 代码实现

### 方法一：前缀和枚举（推荐）

```java
class Solution {
    public long gridGame(int[][] grid) {
        int n = grid[0].length;
        long topSum = 0;
        for (int v : grid[0]) topSum += v;

        long botSum = 0;
        long ans = Long.MAX_VALUE;

        for (int j = 0; j < n; j++) {
            topSum -= grid[0][j]; // 机器人一在j列转弯，第一行j之后留给机器人二
            // topSum = grid[0][j+1..n-1], botSum = grid[1][0..j-1]
            long robot2 = Math.max(topSum, botSum);
            ans = Math.min(ans, robot2);
            botSum += grid[1][j];
        }

        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 机器人一必须在某列 j 从第 0 行转入第 1 行
2. 机器人二面对剩余格子：第一行 j+1 到 n-1，第二行 0 到 j-1
3. 答案是 `min(max(topSuffix, botPrefix))`，注意 min/max 层次不能颠倒
