## 题目描述

给你两个 1 到 n 的排列数组 `A` 和 `B`，前缀公共数组 `C[i]` 等于 `A[0..i]` 和 `B[0..i]` 中的公共元素数量，返回 `C`。

## Java 代码实现

```java
class Solution {
    public int[] findThePrefixCommonArray(int[] A, int[] B) {
        int n = A.length;
        int[] count = new int[n + 1]; // count[x]: x 在 A、B 前缀中各出现 1 次后累计
        int[] ans = new int[n];
        int common = 0;

        for (int i = 0; i < n; i++) {
            // 处理 A 的当前元素
            count[A[i]]++;
            if (count[A[i]] == 2) common++; // A 和 B 的前缀都包含了 A[i]
            // 处理 B 的当前元素
            count[B[i]]++;
            if (count[B[i]] == 2) common++; // A 和 B 的前缀都包含了 B[i]
            ans[i] = common;
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## 关键点总结

1. 某元素在 A 和 B 的前缀中均出现时（计数达到 2），公共数加 1
2. 计数数组比集合交集更高效
