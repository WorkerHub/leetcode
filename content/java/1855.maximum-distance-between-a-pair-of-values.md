## 题目描述

两个非递增数组，找有效数对(i,j)满足i≤j且nums1[i]≤nums2[j]，求最大距离j-i。

## 解题思路

双指针：利用两数组单调性，nums1[i]≤nums2[j]时j右移扩大距离，否则i右移。

## Java 代码实现

```java
class Solution {
    public int maxDistance(int[] nums1, int[] nums2) {
        int i = 0, j = 0;
        int maxDist = 0;
        int m = nums1.length, n = nums2.length;
        
        while (i < m && j < n) {
            if (nums1[i] <= nums2[j]) {
                maxDist = Math.max(maxDist, j - i);
                j++;
            } else {
                i++;
                if (i > j) j = i; // j不能小于i
            }
        }
        return maxDist;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M + N)
- **空间复杂度**：O(1)

## 关键点总结

1. **双指针利用单调性**：两数组非递增
2. **j不能小于i**：有效数对要求i≤j
3. **满足条件时j右移**：贪心扩大距离
