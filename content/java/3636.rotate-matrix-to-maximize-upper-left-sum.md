## 题目描述

给定 `n x n` 矩阵 `grid`，可进行 0/90/180/270 度旋转，返回旋转后左上角 `k x k` 子矩阵元素和的最大值。

## Java 代码实现

```java
class Solution {
    public int rotateGrid(int[][] grid, int k) {
        int n = grid.length;
        int ans = 0;

        // 枚举 4 种旋转，用坐标映射避免实际旋转
        for (int rot = 0; rot < 4; rot++) {
            int total = 0;
            for (int i = 0; i < k; i++) {
                for (int j = 0; j < k; j++) {
                    int val;
                    if (rot == 0)      val = grid[i][j];
                    else if (rot == 1) val = grid[n - 1 - j][i];
                    else if (rot == 2) val = grid[n - 1 - i][n - 1 - j];
                    else               val = grid[j][n - 1 - i];
                    total += val;
                }
            }
            ans = Math.max(ans, total);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(k^2)，枚举 4 次，每次 O(k^2)
- 空间复杂度：O(1)

## 关键点总结

1. 矩阵只有 4 种旋转状态，直接枚举
2. 用坐标映射公式代替实际旋转矩阵，避免 O(n^2) 额外空间
3. 旋转 r 次后，`(i,j)` 对应原矩阵的坐标有固定映射规律
