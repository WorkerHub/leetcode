## 题目描述

给定正整数数组 nums 和整数 k，返回恰好由 k 个不同整数组成的子数组个数。

**示例：**
```
输入：nums = [1,2,1,2,3], k = 2
输出：7
```

## 解题思路

转化为差值：恰好 k 个 = 至多 k 个 - 至多 k-1 个。用滑动窗口分别计算 atMost(k) 和 atMost(k-1)。

## Java 代码实现

```java
class Solution {
    public int subarraysWithKDistinct(int[] nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }

    private int atMost(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        int left = 0, result = 0;

        for (int right = 0; right < nums.length; right++) {
            count.merge(nums[right], 1, Integer::sum);

            while (count.size() > k) {
                int val = count.get(nums[left]);
                if (val == 1) {
                    count.remove(nums[left]);
                } else {
                    count.put(nums[left], val - 1);
                }
                left++;
            }

            result += right - left + 1;
        }

        return result;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(k)

## 关键点总结

1. **恰好 = 至多 - 至多少一**：经典转化技巧
2. **滑动窗口**：维护窗口内不同整数个数
3. **计数公式**：每次右指针移动贡献 right - left + 1 个子数组
