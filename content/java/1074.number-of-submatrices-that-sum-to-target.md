## 题目描述

给定 m×n 整数矩阵和目标值 target，返回元素和等于 target 的非空子矩阵数量。

**示例：**
```
输入：matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0
输出：4
```

## 解题思路

降维：枚举上下边界，将多行压缩为一维列和数组，然后用前缀和+哈希表统计和为 target 的子数组数（560 题的扩展）。

## Java 代码实现

```java
class Solution {
    public int numSubmatrixSumTarget(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        int count = 0;

        // 枚举上边界
        for (int row1 = 0; row1 < m; row1++) {
            int[] colSum = new int[n];

            // 枚举下边界
            for (int row2 = row1; row2 < m; row2++) {
                // 更新列和，同时用前缀和+哈希表统计
                Map<Integer, Integer> prefixCount = new HashMap<>();
                prefixCount.put(0, 1);
                int curSum = 0;

                for (int col = 0; col < n; col++) {
                    colSum[col] += matrix[row2][col];
                    curSum += colSum[col];
                    count += prefixCount.getOrDefault(curSum - target, 0);
                    prefixCount.merge(curSum, 1, Integer::sum);
                }
            }
        }

        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m² × n)
- **空间复杂度**：O(n)

## 关键点总结

1. **降维**：二维子矩阵问题→一维子数组问题
2. **前缀和+哈希表**：O(n) 统计和为 target 的子数组
3. **在线计算列和**：避免额外的二维前缀和数组
