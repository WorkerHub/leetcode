## 题目描述

二进制矩阵中每次选一个1并将其所在行和列全部置0，求变为全0的最少操作次数。

## 解题思路

BFS状态搜索：将矩阵每行编码为整数作为状态，枚举每个1的位置执行操作，BFS找最短路径。

## Java 代码实现

```java
class Solution {
    public int removeOnes(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        
        // 编码初始状态
        long start = encode(grid, m, n);
        if (start == 0) return 0;
        
        Map<Long, Integer> visited = new HashMap<>();
        visited.put(start, 0);
        Queue<Long> queue = new LinkedList<>();
        queue.offer(start);
        
        while (!queue.isEmpty()) {
            long state = queue.poll();
            int ops = visited.get(state);
            
            // 枚举所有1的位置
            for (int i = 0; i < m; i++) {
                int row = (int)((state >> (i * n)) & ((1L << n) - 1));
                for (int j = 0; j < n; j++) {
                    if ((row >> j & 1) == 0) continue;
                    // 清除第i行和第j列
                    long newState = state;
                    // 清除第i行
                    newState &= ~(((1L << n) - 1) << (i * n));
                    // 清除第j列
                    for (int r = 0; r < m; r++) {
                        newState &= ~(1L << (r * n + j));
                    }
                    
                    if (newState == 0) return ops + 1;
                    if (!visited.containsKey(newState)) {
                        visited.put(newState, ops + 1);
                        queue.offer(newState);
                    }
                }
            }
        }
        return -1;
    }
    
    private long encode(int[][] grid, int m, int n) {
        long state = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    state |= 1L << (i * n + j);
                }
            }
        }
        return state;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(states * M * N)
- **空间复杂度**：O(states)

## 关键点总结

1. **状态编码**：m*n位表示整个矩阵，每位对应一个格子
2. **操作效果**：清除整行和整列的所有1
3. **BFS最短路径**：保证找到最少操作次数
