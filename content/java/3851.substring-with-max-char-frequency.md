## 题目描述

给你一个字符串 `s` 和一个整数 `k`，找到长度恰好为 `k` 的子串中，出现频率最高的字符的最大频率。

## 解题思路

使用滑动窗口 + 数组：维护大小为 k 的窗口，用数组记录各字符频率。每次窗口右移时更新频率并追踪窗口内最大频率。

## Java 代码实现

```java
class Solution {
    public int maxFreq(String s, int k) {
        int[] freq = new int[26];
        int maxFreq = 0;
        int ans = 0;
        int n = s.length();

        for (int i = 0; i < n; i++) {
            // 加入右端字符
            int right = s.charAt(i) - 'a';
            freq[right]++;
            maxFreq = Math.max(maxFreq, freq[right]);

            // 窗口大小超过 k，移除左端字符
            if (i >= k) {
                int left = s.charAt(i - k) - 'a';
                freq[left]--;
                // 若移除的是最大频率字符，需重新计算最大值
                if (freq[left] < maxFreq - 1) {
                    // 无需重算，maxFreq 仍可能有效
                } else if (freq[left] + 1 == maxFreq) {
                    // 检查是否还有其他字符达到 maxFreq
                    boolean found = false;
                    for (int f : freq) {
                        if (f == maxFreq) { found = true; break; }
                    }
                    if (!found) maxFreq--;
                }
            }

            // 窗口大小恰好为 k 时记录答案
            if (i >= k - 1) {
                ans = Math.max(ans, maxFreq);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * 26) = O(n)
- 空间复杂度：O(1)，固定 26 个字母

## 关键点总结

1. 滑动窗口维护固定大小 k 的字符频率表。
2. 移除左端字符后，最大频率可能减少，需要重新检查。
3. 窗口达到大小 k 时（`i >= k - 1`）才记录答案。
