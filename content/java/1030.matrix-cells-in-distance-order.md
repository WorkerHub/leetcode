## 题目描述

给定 rows x cols 矩阵和中心点 (rCenter, cCenter)，返回所有单元格坐标按曼哈顿距离从小到大排序。

**示例：**
```
输入：rows = 2, cols = 2, rCenter = 0, cCenter = 1
输出：[[0,1],[0,0],[1,1],[1,0]]
```

## 解题思路

生成所有坐标，按曼哈顿距离排序。或用 BFS 从中心扩展。

## Java 代码实现

```java
class Solution {
    public int[][] allCellsDistOrder(int rows, int cols, int rCenter, int cCenter) {
        int[][] cells = new int[rows * cols][2];
        int idx = 0;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                cells[idx++] = new int[]{r, c};
            }
        }

        Arrays.sort(cells, (a, b) ->
            Math.abs(a[0] - rCenter) + Math.abs(a[1] - cCenter) -
            Math.abs(b[0] - rCenter) - Math.abs(b[1] - cCenter));

        return cells;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(RC * log(RC))
- **空间复杂度**：O(RC)

## 关键点总结

1. **曼哈顿距离**：|r1-r2| + |c1-c2|
2. **自定义排序**：按距离排序即可
3. **BFS 替代**：可用 BFS 从中心扩展达到 O(RC)
