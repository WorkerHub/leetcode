## 题目描述

给你一个正整数 `n`，返回所有长度为 `n` 且不含相邻零的二进制字符串（任意顺序）。

## Java 代码实现

```java
import java.util.*;

class Solution {
    private List<String> ans = new ArrayList<>();

    public List<String> validStrings(int n) {
        // 回溯生成，初始假设前一位不是 '0'，允许第一位放 '0'
        backtrack(new char[n], 0, '1');
        return ans;
    }

    private void backtrack(char[] path, int idx, char lastChar) {
        if (idx == path.length) {
            ans.add(new String(path));
            return;
        }
        // 尝试放 '1'
        path[idx] = '1';
        backtrack(path, idx + 1, '1');
        // 只有上一位不是 '0' 时才能放 '0'
        if (lastChar != '0') {
            path[idx] = '0';
            backtrack(path, idx + 1, '0');
        }
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n)，结果集大小约为 2^n
- 空间复杂度：O(n * 2^n)，存储所有结果

## 关键点总结

1. 核心约束：不允许相邻两位都是 '0'
2. 递归时，若上一位是 '0'，则当前位只能是 '1'
3. 初始时假设前一位不是 '0'，允许第一位放 '0'
