## 题目描述

给你整数数组 `nums` 和正整数 `k`，返回所有子序列和中第 k 大的值（空子序列和为 0）。

## 解题思路

最大子序列和 = 所有正数之和 `maxSum`。将所有数取绝对值排序，用最小堆枚举"减少量"：每次从堆中取最小代价，生成两个新状态（继续累加下一个或用下一个替换当前），第 k-1 次出堆时对应第 k 大的子序列和。

## Java 代码实现

```java
class Solution {
    public long kSum(int[] nums, int k) {
        long maxSum = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] >= 0) {
                maxSum += nums[i];
            } else {
                nums[i] = -nums[i]; // 取绝对值
            }
        }
        Arrays.sort(nums);

        // 最小堆：(损失量, 当前下标)
        PriorityQueue<long[]> heap = new PriorityQueue<>((a, b) -> Long.compare(a[0], b[0]));
        heap.offer(new long[]{nums[0], 0});

        long ans = maxSum;
        for (int i = 1; i < k; i++) {
            long[] top = heap.poll();
            long cost = top[0];
            int idx = (int) top[1];
            ans = maxSum - cost; // 当前第 i+1 大的值
            if (idx + 1 < nums.length) {
                // 再减去下一个（累加）
                heap.offer(new long[]{cost + nums[idx + 1], idx + 1});
                // 用下一个替换当前（替换）
                heap.offer(new long[]{cost - nums[idx] + nums[idx + 1], idx + 1});
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n + k log k)
- **空间复杂度**：O(n + k)

## 关键点总结

1. 最大子序列和 = 所有正数之和；更小的子序列和 = maxSum 减去某种"代价"。
2. 将所有数取绝对值排序，堆中维护（代价, 下标），每次扩展两个状态。
3. 第 1 大是 maxSum，循环 k-1 次后 ans 即为第 k 大。
