## 题目描述

给定整数 `n` 和 `k`，返回 `[1, n]` 中字典序第 `k` 小的数字。

**示例 1：**
```
输入: n = 13, k = 2
输出: 10
解释: 字典序排列是 [1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]，所以第二小的数字是 10。
```

**示例 2：**
```
输入: n = 1, k = 1
输出: 1
```

**提示：**
- `1 <= k <= n <= 10^9`

## 解题思路

这道题要求找到字典序第 k 小的数字。暴力排序会超时，需要使用字典树的思想。

**关键观察：**
1. 字典序可以看作十叉树的前序遍历
2. 不需要真正构建树，可以通过数学方法计算子树大小
3. 根据子树大小判断第 k 个数在哪个子树中

**十叉树结构：**
```
        根
      /  |  \
     1   2 ... 9
    /|\  /|\
  10 ... 20 ...
```

**算法流程：**
1. 从 1 开始（字典序最小）
2. 计算当前前缀下的数字个数
3. 如果个数 >= k，在当前子树中查找（深入）
4. 否则，跳到下一个前缀（右移）

## Java 代码实现

### 方法一：字典树 + 数学计算 ⭐ 推荐

```java
class Solution {
    public int findKthNumber(int n, int k) {
        long curr = 1;  // 使用 long 防止溢出
        k--;  // 因为从 1 开始，所以 k-1
        
        while (k > 0) {
            long steps = countSteps(curr, n);
            
            if (steps <= k) {
                // 第 k 个数不在当前子树中，跳到下一个前缀
                curr++;
                k -= steps;
            } else {
                // 第 k 个数在当前子树中，深入一层
                curr *= 10;
                k--;
            }
        }
        
        return (int) curr;
    }
    
    // 计算以 curr 为前缀的数字个数（在 [1, n] 范围内）
    private long countSteps(long curr, long n) {
        long steps = 0;
        long first = curr;
        long last = curr;
        
        while (first <= n) {
            // 当前层的数字个数
            steps += Math.min(last, n) - first + 1;
            
            // 移动到下一层
            first *= 10;
            last = last * 10 + 9;  // 使用 long 防止溢出
        }
        
        return steps;
    }
}
```

### 方法二：详细注释版

```java
class Solution {
    public int findKthNumber(int n, int k) {
        long current = 1;  // 从字典序最小的数字 1 开始
        k = k - 1;  // 因为已经在 1 了，所以还需要走 k-1 步
        
        while (k > 0) {
            // 计算以 current 为前缀的子树有多少个数
            long count = getCount(current, n);
            
            if (count <= k) {
                // 第 k 个数不在 current 的子树中
                // 跳到下一个兄弟节点
                current += 1;
                k -= count;
            } else {
                // 第 k 个数在 current 的子树中
                // 深入到子节点（加一位）
                current *= 10;
                k -= 1;  // 深入一层，消耗 1 步
            }
        }
        
        return (int) current;
    }
    
    /**
     * 计算以 prefix 为前缀的数字在 [1, n] 范围内有多少个
     * 例如：prefix=1, n=13
     * 第1层: 1 (1个)
     * 第2层: 10, 11, 12, 13 (4个)
     * 总共5个
     */
    private long getCount(long prefix, long n) {
        long count = 0;
        long first = prefix;      // 当前层的第一个数
        long last = prefix;       // 当前层的最后一个数
        
        while (first <= n) {
            // 当前层在 [first, last] 范围内有多少个数在 [1, n] 中
            count += Math.min(last, n) - first + 1;
            
            // 移动到下一层
            first *= 10;           // 下一层第一个数
            last = last * 10 + 9;  // 下一层最后一个数（防止溢出使用 long）
        }
        
        return count;
    }
}
```

### 方法三：简化版

```java
class Solution {
    public int findKthNumber(int n, int k) {
        long curr = 1;
        k--;
        
        while (k > 0) {
            // 内联计算当前前缀的子树大小
            long steps = 0;
            long first = curr, last = curr;
            
            while (first <= n) {
                steps += Math.min(last, n) - first + 1;
                first *= 10;
                last = last * 10 + 9;
            }
            
            // 判断往哪走
            if (steps <= k) {
                curr++;       // 向右移动（跳到下一个前缀）
                k -= steps;
            } else {
                curr *= 10;  // 向下移动（深入子树）
                k--;
            }
        }
        
        return (int) curr;
    }
}
```

## 复杂度分析

**所有方法：**
- 时间复杂度：O((log n)²)
  - 外层循环最多 log n 次（数字的位数）
  - 内层计算子树大小也是 O(log n)
- 空间复杂度：O(1)

## 图解示例

以 `n = 13, k = 2` 为例：

```
字典序：[1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]

十叉树结构：
         根
    1    2   3 ... 9

查找过程：

   计算以1为前缀的数字个数：1, 10, 11, 12, 13 = 5个

2. curr = 1 * 10 = 10, k = 0
   k = 0，找到答案：10
```

## 关键点总结

1. **字典树思想**：将问题建模为十叉树的遍历
2. **数学计算**：通过计算子树大小避免遍历所有数
3. **两种移动**：深入（×10）或右移（+1）
4. **步数统计**：每次计算当前子树有多少个数
5. **边界处理**：要考虑 n 的限制

## 易错点

1. **k 的初始化**：要先 `k--`，因为从 1 开始
2. **子树大小计算**：要用 `Math.min(last, n)` 限制范围
3. **深入步数**：深入一层要 `k--`
4. **整数溢出**：`last * 10 + 9` 当 n 接近 10^9 时会溢出 int，必须使用 long
5. **curr 类型**：curr 用 long 声明，最终转换为 int 返回
