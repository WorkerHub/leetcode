## 题目描述

返回字符串所有子串中最大的方差（最多字母次数-最少字母次数的最大值）。

## 解题思路

枚举字符对(a,b)，用Kadane变体求"a次数-b次数"的最大子数组和，约束子数组必须含b。维护含b和不含b的两个DP状态。

## Java 代码实现

```java
class Solution {
    public int largestVariance(String s) {
        int ans = 0;
        // 统计出现的字符
        boolean[] exists = new boolean[26];
        for (char c : s.toCharArray()) exists[c - 'a'] = true;

        for (int a = 0; a < 26; a++) {
            if (!exists[a]) continue;
            for (int b = 0; b < 26; b++) {
                if (a == b || !exists[b]) continue;
                // Kadane变体：a为+1，b为-1
                int dpNoB = 0;       // 不含b的最大余额
                int dpWithB = Integer.MIN_VALUE / 2; // 含b的最大余额

                for (char ch : s.toCharArray()) {
                    if (ch - 'a' == a) {
                        dpNoB++;
                        dpWithB++;
                    } else if (ch - 'a' == b) {
                        dpWithB = Math.max(dpNoB, dpWithB) - 1;
                        dpNoB = Math.max(dpNoB - 1, 0);
                    }
                    ans = Math.max(ans, dpWithB);
                }
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(26² * N) = O(N)
- **空间复杂度**：O(1)

## 关键点总结

1. **枚举字符对**：将问题分解为26²个子问题
2. **Kadane变体**：维护含b和不含b两个状态
3. **必须含b约束**：子串只有一种字母时方差为0
