## 题目描述

买第i种水果可免费获得之后i种水果，求买完所有n种水果的最少花费。

## 解题思路

dp[i]为获得前i种水果的最小花费，转移来自j in [ceil(i/2), i]。用单调队列维护滑动窗口最小值。

## Java 代码实现

```java
class Solution {
    public int minimumCoins(int[] prices) {
        int n = prices.length;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        Deque<int[]> dq = new ArrayDeque<>(); // {cost, j}
        for (int i = 1; i <= n; i++) {
            // 加入j=i: cost = dp[i-1] + prices[i-1]
            int cost = dp[i - 1] + prices[i - 1];
            while (!dq.isEmpty() && dq.peekLast()[0] >= cost) {
                dq.pollLast();
            }
            dq.offerLast(new int[]{cost, i});

            // 移除j < ceil(i/2)的元素
            int lo = (i + 1) / 2;
            while (!dq.isEmpty() && dq.peekFirst()[1] < lo) {
                dq.pollFirst();
            }
            dp[i] = dq.peekFirst()[0];
        }
        return dp[n];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **买第j种覆盖到2j**：dp[i]从j in [ceil(i/2), i]转移
2. **单调队列维护窗口最小值**
3. **窗口左边界随i增大而右移**
