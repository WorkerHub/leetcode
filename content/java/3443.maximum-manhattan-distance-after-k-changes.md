## 题目描述

给定方向字符串 `s`（含 N/S/E/W）和整数 `k`，最多改变 k 个字符，返回移动过程中任意时刻可达的最大曼哈顿距离。

## Java 代码实现

```java
class Solution {
    public int maxDistance(String s, int k) {
        int ans = 0;
        // 枚举 4 种目标象限（NE, NW, SE, SW）
        int[][] quads = {{'N','E'}, {'N','W'}, {'S','E'}, {'S','W'}};
        char[] opp = new char[128];
        opp['N'] = 'S'; opp['S'] = 'N'; opp['E'] = 'W'; opp['W'] = 'E';

        for (int[] q : quads) {
            char d1 = (char)q[0], d2 = (char)q[1];
            char op1 = opp[d1], op2 = opp[d2];
            int[] cnt = new int[128];

            for (char c : s.toCharArray()) {
                cnt[c]++;
                // 贪心：先将 op1 改为 d1，再将 op2 改为 d2
                int ch1 = Math.min(cnt[op1], k);
                int ch2 = Math.min(cnt[op2], k - ch1);
                int dist = (cnt[d1] - cnt[op1] + 2 * ch1) + (cnt[d2] - cnt[op2] + 2 * ch2);
                ans = Math.max(ans, dist);
            }
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(4 * n) = O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 曼哈顿距离 = |x| + |y|，枚举 4 种目标象限方向
2. 对每种象限，贪心地把 k 次改变优先用于第一方向
3. 改变 ch1 次 op1 后，d1 方向距离增加 2*ch1（一减一增）
