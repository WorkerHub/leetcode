## 题目描述

Alice 和 Bob 交替玩石子游戏（Alice 先手）。Alice 第一轮取 10 块，之后每轮递减 1（第二轮取 9，第三轮取 8，...）；Bob 每轮取 1 块。若某人轮到时石子不够取，该人输。返回 Alice 是否获胜。

## 解题思路

直接模拟：Alice 依次取 10、9、8、...、1，Bob 每次取 1。若 Alice 取时石子不足则 Alice 输，若 Bob 取时石子为 0 则 Bob 输。最多模拟 10 轮，O(1) 时间。

## Java 代码实现

```java
class Solution {
    public boolean canAliceWin(int n) {
        int stones = n;
        // Alice 依次取 10, 9, 8, ..., 1
        for (int take = 10; take >= 1; take--) {
            // Alice 取 take 块
            if (stones < take) {
                return false; // Alice 输
            }
            stones -= take;
            // Bob 取 1 块
            if (stones == 0) {
                return true; // Bob 输
            }
            stones -= 1;
        }
        return true; // Alice 取完所有轮次，Bob 输
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)，最多模拟 10 轮
- 空间复杂度：O(1)

## 关键点总结

1. Alice 每轮取的数量递减（10, 9, 8, ..., 1），Bob 每轮取 1。
2. Alice 轮到时石子不足则 Alice 输，Bob 轮到时石子为 0 则 Bob 输。
3. 最多模拟 10 轮，是常数时间。
