## 题目描述

给你一份航线列表 `tickets`，其中 `tickets[i] = [from_i, to_i]` 表示飞机出发和降落的机场地点。请你对该行程进行重新规划排序。

所有这些机票都属于一个从 `JFK`（肯尼迪国际机场）出发的先生，所以该行程必须从 `JFK` 开始。如果存在多种有效的行程，请你按**字典序**返回最小的行程组合。

- 例如，行程 `["JFK", "LGA"]` 与 `["JFK", "LGB"]` 相比就更小，字典序更靠前。

假定所有机票至少存在一种合理的行程。且所有的机票必须都用一次且只能用一次。

**示例 1:**

```
输入：tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]
输出：["JFK","MUC","LHR","SFO","SJC"]
```

**示例 2:**

```
输入：tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]
输出：["JFK","ATL","JFK","SFO","ATL","SFO"]
解释：另一种有效的行程是 ["JFK","SFO","ATL","JFK","ATL","SFO"]，但是它字典序更大。
```

**提示:**

- `1 <= tickets.length <= 300`
- `tickets[i].length == 2`
- `from_i.length == 3`
- `to_i.length == 3`
- `from_i` 和 `to_i` 由大写英文字母组成
- `from_i != to_i`

## 解题思路

这道题是经典的**欧拉路径**问题，使用 **Hierholzer 算法**求解。

### 核心概念

1. **欧拉路径**：图中经过每条边恰好一次的路径
2. **欧拉回路**：起点和终点相同的欧拉路径

### 算法思想

1. **构建图**：用邻接表存储图，每个机场对应一个目的地列表
2. **排序**：将每个机场的目的地按字典序排序（保证字典序最小）
3. **DFS 遍历**：
   - 从 `JFK` 开始深度优先搜索
   - 每次选择字典序最小的未访问边
   - 访问完所有边后，将节点加入结果
4. **逆序输出**：DFS 的访问顺序是逆序的，需要反转

### Hierholzer 算法原理

- **后序遍历**：先访问完所有邻居，再将当前节点加入结果
- **为什么逆序？**：因为是后序遍历，最后访问的节点（终点）先加入结果

## Java 代码实现

### 方法一：Hierholzer 算法递归版（推荐）⭐

```java
import java.util.*;

class Solution {
    // 图的邻接表
    Map<String, PriorityQueue<String>> graph = new HashMap<>();
    List<String> result = new ArrayList<>();

    public List<String> findItinerary(List<List<String>> tickets) {
        // 构建图（使用最小堆保证字典序）
        for (List<String> ticket : tickets) {
            String src = ticket.get(0);
            String dst = ticket.get(1);
            graph.computeIfAbsent(src, k -> new PriorityQueue<>()).offer(dst);
        }

        // 从 JFK 开始 DFS
        dfs("JFK");

        // 逆序返回（因为是后序遍历）
        Collections.reverse(result);
        return result;
    }

    private void dfs(String airport) {
        PriorityQueue<String> neighbors = graph.get(airport);
        // 访问所有邻居（按字典序）
        while (neighbors != null && !neighbors.isEmpty()) {
            String next = neighbors.poll();
            dfs(next);
        }
        // 后序遍历：所有邻居访问完后，将当前节点加入结果
        result.add(airport);
    }
}
```

### 方法二：迭代版 Hierholzer 算法

```java
import java.util.*;

class Solution {
    public List<String> findItinerary(List<List<String>> tickets) {
        // 构建图（使用最小堆保证字典序）
        Map<String, PriorityQueue<String>> graph = new HashMap<>();
        for (List<String> ticket : tickets) {
            graph.computeIfAbsent(ticket.get(0), k -> new PriorityQueue<>()).offer(ticket.get(1));
        }

        Deque<String> stack = new ArrayDeque<>();
        List<String> result = new LinkedList<>();

        stack.push("JFK");

        while (!stack.isEmpty()) {
            String current = stack.peek();
            PriorityQueue<String> neighbors = graph.get(current);

            // 如果当前节点有未访问的邻居
            if (neighbors != null && !neighbors.isEmpty()) {
                // 访问字典序最小的邻居
                stack.push(neighbors.poll());
            } else {
                // 所有邻居都访问完了，将当前节点加入结果
                result.add(0, stack.pop());
            }
        }

        return result;
    }
}
```

### 方法三：排序后使用列表模拟栈（逆序排序 + 末尾弹出）

```java
import java.util.*;

class Solution {
    Map<String, List<String>> graph = new HashMap<>();
    List<String> result = new ArrayList<>();

    public List<String> findItinerary(List<List<String>> tickets) {
        // 构建图（邻接表）
        for (List<String> ticket : tickets) {
            graph.computeIfAbsent(ticket.get(0), k -> new ArrayList<>()).add(ticket.get(1));
        }

        // 对每个机场的目的地按字典序逆序排序，方便后续从末尾弹出（等效于从最小值开始访问）
        for (List<String> neighbors : graph.values()) {
            Collections.sort(neighbors, Collections.reverseOrder());
        }

        dfs("JFK");

        // 逆序返回
        Collections.reverse(result);
        return result;
    }

    private void dfs(String airport) {
        List<String> neighbors = graph.get(airport);
        while (neighbors != null && !neighbors.isEmpty()) {
            // 弹出最后一个（逆序排序后，末尾为最小的字典序）
            String next = neighbors.remove(neighbors.size() - 1);
            dfs(next);
        }
        result.add(airport);
    }
}
```

## 复杂度分析

**方法一/二/三：Hierholzer 算法**

- **时间复杂度**：O(E log E)
  - E：边的数量（机票数）
  - 排序：O(E log E)
  - DFS：O(E)，每条边访问一次
  
- **空间复杂度**：O(E)
  - 图的存储：O(E)
  - 递归栈/显式栈：O(E)

## 关键点总结

1. **欧拉路径问题**：每条边恰好经过一次
2. **Hierholzer 算法**：后序遍历 + 逆序输出
3. **字典序最小**：对邻居按字典序排序
4. **逆序排序技巧**：逆序排序 + `remove(size-1)` 等价于正序 + `remove(0)`，但效率更高
5. **后序遍历**：先访问完所有邻居，再处理当前节点
6. **为什么要逆序**：DFS 后序遍历得到的是逆序的路径

## 易错点

1. **排序方向**：
   - 正序排序 + `remove(0)`：O(n)
   - 逆序排序 + `remove(size-1)`：O(1)（推荐）

2. **后序遍历理解**：
   - 错误：先将当前节点加入结果，再访问邻居
   - 正确：先访问完所有邻居，再将当前节点加入结果

3. **结果要逆序**：因为是后序遍历

4. **图的构建**：使用 `computeIfAbsent` 避免 NullPointerException

5. **起点固定**：必须从 `"JFK"` 开始

```
构建图（排序后）：
JFK -> [ATL, SFO]
ATL -> [JFK, SFO]
SFO -> [ATL]

DFS 过程（后序遍历）：
1. 从 JFK 开始
2. 访问 ATL（字典序最小）
3. 从 ATL 访问 JFK
4. 从 JFK 访问 SFO
5. 从 SFO 访问 ATL
6. 从 ATL 访问 SFO
7. SFO 无邻居，加入结果：result = [SFO]
8. 回到 ATL，加入结果：result = [SFO, ATL]
9. 回到 SFO，加入结果：result = [SFO, ATL, SFO]
10. 回到 JFK，加入结果：result = [SFO, ATL, SFO, JFK]
11. 回到 ATL，加入结果：result = [SFO, ATL, SFO, JFK, ATL]
12. 回到 JFK，加入结果：result = [SFO, ATL, SFO, JFK, ATL, JFK]

逆序：[JFK, ATL, JFK, SFO, ATL, SFO] ✓
```
