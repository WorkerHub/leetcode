## 题目描述

将 1~n 排列使得所有质数在质数索引上（索引从 1 开始），返回方案数对 10^9+7 取模。

**示例：**
```
输入：n = 5
输出：12（3个质数排列3! × 2个合数排列2! = 6×2 = 12）
```

## 解题思路

统计 1~n 中质数个数 p，合数个数 n-p。结果 = p! × (n-p)! mod 10^9+7。

## Java 代码实现

```java
class Solution {
    public int numPrimeArrangements(int n) {
        int MOD = 1_000_000_007;
        int primeCount = countPrimes(n);
        int compositeCount = n - primeCount;

        // 计算 primeCount! * compositeCount! mod MOD
        long result = 1;
        for (int i = 2; i <= primeCount; i++) {
            result = (result * i) % MOD;
        }
        for (int i = 2; i <= compositeCount; i++) {
            result = (result * i) % MOD;
        }
        return (int) result;
    }

    private int countPrimes(int n) {
        if (n < 2) return 0;
        boolean[] isComposite = new boolean[n + 1];
        int count = 0;
        for (int i = 2; i <= n; i++) {
            if (!isComposite[i]) {
                count++;
                for (int j = i * 2; j <= n; j += i) {
                    isComposite[j] = true;
                }
            }
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log log n)，埃氏筛 + O(n) 阶乘
- **空间复杂度**：O(n)，筛法数组

## 关键点总结

1. **独立排列**：质数和合数各自独立排列
2. **乘法原理**：总方案 = 质数排列数 × 合数排列数
3. **埃氏筛**：高效统计质数个数
4. **逐步取模**：阶乘计算中每步取模防溢出
5. **1 不是质数**：归入合数计算
