## 题目描述

将数组 `nums` 重新排列成 `perm`，返回满足 `perm[i] > nums[i]` 的下标数目的最大值（**最大伟大值**）。

## 解题思路

**排序 + 贪心双指针**（田忌赛马）：对 `nums` 排序，用指针 `ptr` 指向待被超越的元素，遍历排序后的数组，若当前元素能超越 `nums[ptr]`，则配对成功，`ptr` 前进。

## Java 代码实现

```java
import java.util.Arrays;

class Solution {
    public int maximizeGreatness(int[] nums) {
        Arrays.sort(nums);
        int ptr = 0; // 待被超越的元素指针
        for (int x : nums) {
            if (x > nums[ptr]) {
                ptr++;
            }
        }
        return ptr;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log n)，排序
- 空间复杂度：O(1)

## 关键点总结

1. 排序后用双指针贪心配对，类似"田忌赛马"
2. 只有严格大于才算（`>`，不含等于）
3. 指针 `ptr` 前进的次数即为最终答案
