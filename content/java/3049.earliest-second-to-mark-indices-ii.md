## 题目描述

与 3048 相同题意，但 n 和 m 扩大到 5×10^5，需要更高效的算法。

## 解题思路

二分答案 + 贪心 + 最大堆。从后往前遍历前 T 秒，每次遇到首次出现的下标，将其 `nums[i]` 加入最大堆并预扣空闲；若空闲不足，则从堆中弹出代价最大的下标（放弃标记该下标并归还资源）。

## Java 代码实现

```java
class Solution {
    private int[] nums;
    private int[] changeIndices;
    private int n;

    public int earliestSecondToMarkIndices(int[] nums, int[] changeIndices) {
        this.nums = nums;
        this.changeIndices = changeIndices;
        this.n = nums.length;
        int m = changeIndices.length;

        int lo = 1, hi = m, ans = -1;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (check(mid)) { ans = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        return ans;
    }

    private boolean check(int T) {
        // 最大堆（存 nums[i] 的代价）
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        boolean[] seen = new boolean[n];
        int free = 0, cnt = 0;

        for (int t = T - 1; t >= 0; t--) {
            int idx = changeIndices[t] - 1;
            if (!seen[idx]) {
                seen[idx] = true;
                heap.offer(nums[idx]);
                free -= nums[idx]; // 预扣减 1 操作次数
                cnt++;
                // 空闲不足时，放弃代价最大的下标
                if (free < 0) {
                    free += heap.poll() + 1; // 归还代价并释放此时刻
                    cnt--;
                }
            } else {
                free++; // 此时刻空闲，可用于减 1
            }
        }
        return cnt == n;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m log(n + m))，二分 O(log m) 次，每次验证 O(m log n)
- **空间复杂度**：O(n + m)

## 关键点总结

1. 二分答案 + 贪心是此类问题的标准做法
2. 从后往前贪心：空闲时刻用于减 1，遇到新下标考虑是否标记
3. 最大堆：若资源不足，优先放弃代价最大的标记（最优化资源利用）
