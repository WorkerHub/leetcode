## 题目描述

给你整数数组 `nums` 和正整数 `x > y`，每次操作选一个下标 `i`，将 `nums[i]` 减 `x`，其余元素减 `y`，返回使所有元素 <= 0 的最少操作次数。

## Java 代码实现

```java
class Solution {
    public int minOperations(int[] nums, int x, int y) {
        int lo = 0, hi = 0;
        for (int v : nums) hi = Math.max(hi, v);
        int diff = x - y;

        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (canFinish(nums, mid, y, diff)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    // 判断 k 次操作能否使所有元素 <= 0
    private boolean canFinish(int[] nums, int k, int y, int diff) {
        long needed = 0;
        for (int num : nums) {
            long remaining = num - (long) k * y;
            if (remaining > 0) {
                // 需要被额外选中的次数（向上取整）
                needed += (remaining + diff - 1) / diff;
                if (needed > k) return false;
            }
        }
        return true;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n log(max(nums)))
- 空间复杂度：O(1)

## 关键点总结

1. 二分操作次数 k，转化为判定问题
2. k 次操作后每个元素至少减了 `k*y`，被选中的额外再减 `diff = x-y`
3. 累加各元素需被额外选中的次数，若 <= k 则可行
4. 向上取整用 `(a + diff - 1) / diff` 避免浮点误差
