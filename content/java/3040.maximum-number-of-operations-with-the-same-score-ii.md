## 题目描述

每次可取数组前两个、后两个或首尾两个元素，分数必须相同，求最多操作次数。

## 解题思路

第一次操作有三种选择确定target，对每种target用区间DP(l,r)求最大操作数。

## Java 代码实现

```java
class Solution {
    private int[][] memo;
    private int[] nums;
    private int target;

    public int maxOperations(int[] nums) {
        this.nums = nums;
        int n = nums.length;
        int ans = 0;
        // 三种可能的target
        int[] targets = {nums[0] + nums[1], nums[n - 1] + nums[n - 2], nums[0] + nums[n - 1]};
        for (int t : targets) {
            target = t;
            memo = new int[n][n];
            for (int[] row : memo) Arrays.fill(row, -1);
            ans = Math.max(ans, dp(0, n - 1));
        }
        return ans;
    }

    private int dp(int l, int r) {
        if (r - l < 1) return 0;
        if (memo[l][r] != -1) return memo[l][r];
        int best = 0;
        if (nums[l] + nums[l + 1] == target) best = Math.max(best, 1 + dp(l + 2, r));
        if (nums[r - 1] + nums[r] == target) best = Math.max(best, 1 + dp(l, r - 2));
        if (nums[l] + nums[r] == target) best = Math.max(best, 1 + dp(l + 1, r - 1));
        memo[l][r] = best;
        return best;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(N^2)

## 关键点总结

1. **三种target选择**：前两个/后两个/首尾
2. **区间DP记忆化**：dp(l,r)表示区间内最多操作数
3. **每次三种操作选最优**
