## 题目描述

给定正整数数组 `nums`（元素 <= 10），若子数组所有元素乘积等于其 LCM，则称为"等积子数组"，返回最长等积子数组的长度。

## Java 代码实现

```java
class Solution {
    public int maxLength(int[] nums) {
        int n = nums.length;
        int ans = 1;

        for (int i = 0; i < n; i++) {
            long product = 1;
            long lcmVal = 1;
            for (int j = i; j < n; j++) {
                product *= nums[j];
                lcmVal = lcm(lcmVal, nums[j]);
                if (product == lcmVal) {
                    ans = Math.max(ans, j - i + 1);
                }
                // 若乘积超过 LCM 过多（超出 long 范围前截断）
                if (product > 1_000_000_000L) break; // 防止溢出（nums<=10, n<=100）
            }
        }
        return ans;
    }

    private long gcd(long a, long b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    private long lcm(long a, long b) {
        return a / gcd(a, b) * b;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n^2)，枚举所有子数组
- 空间复杂度：O(1)

## 关键点总结

1. 乘积 == LCM 等价于所有元素两两互质。
2. 元素 <= 10，素因子只有 2, 3, 5, 7，可以用位掩码优化。
3. 发现不互质即可提前终止内层循环。
