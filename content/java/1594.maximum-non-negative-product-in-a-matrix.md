## 题目描述

从矩阵左上角到右下角（只能右或下），求路径元素乘积的最大非负积，对10^9+7取模。若最大积为负返回-1。

## 解题思路

DP同时维护最大值和最小值：负数乘以最小值（负数）可能得最大正值。每个位置取四种候选值的最大/最小。

## Java 代码实现

```java
class Solution {
    public int maxProductPath(int[][] grid) {
        long MOD = 1_000_000_007;
        int m = grid.length, n = grid[0].length;
        long[][] dpMax = new long[m][n];
        long[][] dpMin = new long[m][n];
        
        dpMax[0][0] = dpMin[0][0] = grid[0][0];
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            dpMax[0][j] = dpMin[0][j] = dpMax[0][j - 1] * grid[0][j];
        }
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            dpMax[i][0] = dpMin[i][0] = dpMax[i - 1][0] * grid[i][0];
        }
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                long x = grid[i][j];
                long a = dpMax[i - 1][j] * x;
                long b = dpMin[i - 1][j] * x;
                long c = dpMax[i][j - 1] * x;
                long d = dpMin[i][j - 1] * x;
                dpMax[i][j] = Math.max(Math.max(a, b), Math.max(c, d));
                dpMin[i][j] = Math.min(Math.min(a, b), Math.min(c, d));
            }
        }
        
        long ans = dpMax[m - 1][n - 1];
        return ans < 0 ? -1 : (int)(ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(M × N)
- **空间复杂度**：O(M × N)

## 关键点总结

1. **同时维护最大值和最小值**：负负得正
2. **四个候选值**：来自两个方向×最大最小
3. **取模只在最终**：不能边算边取模（负数逻辑会错）
