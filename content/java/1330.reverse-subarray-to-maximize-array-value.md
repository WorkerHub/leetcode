## 题目描述

给你一个整数数组 `nums`。「数组值」定义为所有满足 `0 <= i < nums.length-1` 的 `|nums[i] - nums[i+1]|` 之和。

你可以选择任意子数组 `nums[i..j]`（`i < j`，包含两端），并将其反转。你只能执行这个操作一次（也可以不执行）。

请你返回执行该操作后的最大数组值。

**示例 1：**
```
输入：nums = [2,3,1,5,4]
输出：10
解释：通过翻转子数组 [3,1,5]，数组变成 [2,5,1,3,4]，数组值为 10。
```

**示例 2：**
```
输入：nums = [2,4,9,24,2,1,10]
输出：68
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

**关键数学分析：**

翻转子数组 `nums[l..r]` 后，只有 `l-1` 与 `l` 之间，以及 `r` 与 `r+1` 之间的绝对值差会改变，其余位置不变。

**原始数组值：**`S = sum(|nums[i] - nums[i+1]|)`

翻转 `[l, r]` 后，变化量 `delta = 新贡献 - 旧贡献`：
- 去掉：`|nums[l-1] - nums[l]|`（左边界贡献，如果 `l > 0`）
- 去掉：`|nums[r] - nums[r+1]|`（右边界贡献，如果 `r < n-1`）
- 加上：`|nums[l-1] - nums[r]|`（翻转后左边界）
- 加上：`|nums[l] - nums[r+1]|`（翻转后右边界）

因此：`delta = |nums[l-1] - nums[r]| + |nums[l] - nums[r+1]| - |nums[l-1] - nums[l]| - |nums[r] - nums[r+1]|`

**目标：** 最大化 `delta`，即最大化：
`|nums[l-1] - nums[r]| + |nums[l] - nums[r+1]|`

**用绝对值展开分析：**

设 `a = nums[l-1]`, `b = nums[l]`, `c = nums[r]`, `d = nums[r+1]`。

我们要最大化 `|a - c| + |b - d| - |a - b| - |c - d|`。

展开 `|a - c|` 时有 4 种情况（`+a-c`, `-a+c` 各两种），总共 `2^4 = 16` 种组合，但最终有效的只有：
- `max(0, (a-b) + (d-c))` 这种类型
- 需要遍历枚举所有 `(a, b)` 对和 `(c, d)` 对，用单调维护最大最小值

**算法（贪心 + 四种情形枚举）：**

将 `|a - c| + |b - d|` 展开后，最大化公式可以转化为维护四个量的最大值：
- `max(a + b)` 与 `min(c + d)` 的差
- `max(a - b)` 与 `min(c - d)` 的差
- `max(-a + b)` 与 `min(-c + d)` 的差
- `max(-a - b)` 与 `min(-c - d)` 的差

## Java 代码实现

### 方法一：贪心 + 数学分析（O(n)，推荐）

```java
class Solution {
    public int maxValueAfterReverse(int[] nums) {
        int n = nums.length;
        
        // 计算原始数组值
        int total = 0;
        for (int i = 0; i < n - 1; i++) {
            total += Math.abs(nums[i] - nums[i + 1]);
        }
        
        int bestGain = 0;
        
        // 情形 1：翻转包含第一个或最后一个元素的子数组
        for (int i = 1; i < n - 1; i++) {
            // 翻转 [0, i]：影响边 (i, i+1)，新边 (0, i+1)
            bestGain = Math.max(bestGain,
                Math.abs(nums[0] - nums[i + 1]) - Math.abs(nums[i] - nums[i + 1]));
            // 翻转 [i, n-1]：影响边 (i-1, i)，新边 (i-1, n-1)
            bestGain = Math.max(bestGain,
                Math.abs(nums[n - 1] - nums[i - 1]) - Math.abs(nums[i] - nums[i - 1]));
        }
        
        // 情形 2：翻转中间部分，枚举四种符号组合
        int[][] signs = {{1, 1}, {1, -1}, {-1, 1}, {-1, -1}};
        for (int[] sign : signs) {
            int s1 = sign[0], s2 = sign[1];
            int curMax = Integer.MIN_VALUE;
            for (int i = 0; i < n - 1; i++) {
                int a = nums[i], b = nums[i + 1];
                // 先用之前维护的 curMax 计算增益（先用后更新）
                if (curMax != Integer.MIN_VALUE) {
                    bestGain = Math.max(bestGain, curMax - s1 * a - s2 * b);
                }
                // 将当前 (a, b) 加入候选
                curMax = Math.max(curMax, s1 * a + s2 * b);
            }
        }
        
        return total + bestGain;
    }
}
```

### 方法二：暴力枚举（O(n^2)，适合理解）

```java
class Solution {
    public int maxValueAfterReverse(int[] nums) {
        int n = nums.length;
        int result = arrayValue(nums, n);
        
        // 枚举所有翻转区间 [l, r]
        for (int l = 0; l < n; l++) {
            for (int r = l + 1; r < n; r++) {
                // 翻转 [l, r]
                reverse(nums, l, r);
                result = Math.max(result, arrayValue(nums, n));
                // 复原
                reverse(nums, l, r);
            }
        }
        
        return result;
    }
    
    private int arrayValue(int[] nums, int n) {
        int sum = 0;
        for (int i = 0; i < n - 1; i++) {
            sum += Math.abs(nums[i] - nums[i + 1]);
        }
        return sum;
    }
    
    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            int tmp = nums[l];
            nums[l] = nums[r];
            nums[r] = tmp;
            l++;
            r--;
        }
    }
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 方法一（贪心） | O(n) | O(1) |
| 方法二（暴力） | O(n^2) | O(1) |

## 关键点总结

1. 翻转子数组只影响两个端点处的边，其余边不变
2. 增益公式 `|a-c| + |b-d| - |a-b| - |c-d|` 是核心
3. 端点情形（包含第一个或最后一个元素）可以直接枚举 O(n)
4. 中间情形需要用四种符号组合枚举最大值差
5. 整体思路：数学化简 + 贪心维护最大/最小值

## 易错点

1. 增益计算时注意区分"边界翻转"和"中间翻转"两种情形
2. 中间情形中维护 `curMax` 时，必须在计算 `bestGain` 之后再更新（先用后更新）
3. 答案不能小于原始值（不翻转时 gain=0）
