## 题目描述

袋中有 `numOnes` 个 1、`numZeros` 个 0、`numNegOnes` 个 -1，从中取 `k` 个，返回可得的最大数字总和。

## 解题思路

**贪心**：优先取 1，然后取 0，最后迫不得已取 -1。最终总和 = 取 1 的数量 - 取 -1 的数量。

## Java 代码实现

```java
class Solution {
    public int kItemsWithMaximumSum(int numOnes, int numZeros, int numNegOnes, int k) {
        // 优先取 1
        int takeOnes = Math.min(k, numOnes);
        k -= takeOnes;
        // 其次取 0
        int takeZeros = Math.min(k, numZeros);
        k -= takeZeros;
        // 最后取 -1
        return takeOnes - k;
    }
}
```

## 复杂度分析

- 时间复杂度：O(1)
- 空间复杂度：O(1)

## 关键点总结

1. 贪心：按 1 > 0 > -1 的优先级选取
2. 选 0 不改变总和，但必须消耗选取名额
3. 最终总和 = 选 1 的数量 - 选 -1 的数量
