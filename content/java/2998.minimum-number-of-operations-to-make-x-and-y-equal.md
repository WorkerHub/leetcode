## 题目描述

给你正整数 `x` 和 `y`，每次可对 x 执行：若整除 11 则除以 11，若整除 5 则除以 5，加 1 或减 1，返回使 x == y 的最少操作次数。

## 解题思路

BFS 从 x 出发，将每种操作视为图的边，求到达 y 的最短路径。若当前值 < y 则只能用 +1 操作，直接补差即可。

## Java 代码实现

```java
class Solution {
    public int minimumOperationsToMakeEqual(int x, int y) {
        if (x <= y) return y - x; // 只能 +1

        Map<Integer, Integer> dist = new HashMap<>();
        Queue<Integer> queue = new LinkedList<>();
        dist.put(x, 0);
        queue.offer(x);

        while (!queue.isEmpty()) {
            int curr = queue.poll();
            int d = dist.get(curr);

            int[] nexts = {curr + 1, curr - 1,
                           curr % 11 == 0 ? curr / 11 : -1,
                           curr % 5  == 0 ? curr / 5  : -1};
            for (int nxt : nexts) {
                if (nxt < 1) continue;
                if (nxt == y) return d + 1;
                if (nxt >= y && !dist.containsKey(nxt)) {
                    dist.put(nxt, d + 1);
                    queue.offer(nxt);
                }
            }
            // 若 curr-1 < y，不入队但直接返回 d+1+(y-(curr-1))
            if (curr - 1 > 0 && curr - 1 < y) {
                return d + 1 + (y - (curr - 1));
            }
        }
        return Math.abs(x - y);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(x)
- **空间复杂度**：O(x)

## 关键点总结

1. BFS 求最短路，操作为 +1, -1, /11, /5
2. 到达 < y 的状态后只能 +1，直接补差
3. 搜索范围限制在 [y, x] 附近
