## 题目描述

给定锁的强度数组 `strength` 和常数 `K`，破第 j 把锁时能量 `X = 1 + j*K`，等待时间为 `ceil(X/strength[i])*strength[i] - X`，求最优顺序使总等待时间最小。

## Java 代码实现

```java
import java.util.*;

class Solution {
    public int findMinimumTime(List<Integer> strength, int K) {
        int n = strength.size();
        // 状压 DP（适合 n <= 20）
        long[] dp = new long[1 << n];
        long INF = Long.MAX_VALUE / 2;
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == INF) continue;
            int numOpened = Integer.bitCount(mask);
            long X = 1L + (long) numOpened * K;

            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) continue;
                long s = strength.get(i);
                // 等待时间：向上取整到 s 的倍数再减 X
                long need = ((X + s - 1) / s) * s;
                long wait = need - X;
                int newMask = mask | (1 << i);
                dp[newMask] = Math.min(dp[newMask], dp[mask] + wait);
            }
        }

        return (int) dp[(1 << n) - 1];
    }
}
```

## 复杂度分析

- 时间复杂度：O(2^n * n)，状压 DP
- 空间复杂度：O(2^n)

## 关键点总结

1. 破锁顺序影响每步的 X 值，进而影响等待时间。
2. 等待时间 = `ceil(X / s) * s - X`，可用整数除法计算。
3. 状压 DP 适合 n <= 20，大规模需要匈牙利算法等高级方法。
