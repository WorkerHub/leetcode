## 题目描述

初始所有球无色，每次查询将球 `x` 染色为颜色 `y`，返回每次查询后颜色唯一（该颜色恰好只有一个球拥有）的球的数量。

## 解题思路

维护两个哈希表：`ballColor` 记录每个球的当前颜色，`colorCount` 记录每种颜色的球数。同时维护一个计数 `unique` 表示颜色数恰好为 1 的种数。每次染色时更新旧颜色和新颜色的计数，并相应调整 `unique`。

## Java 代码实现

```java
class Solution {
    public int[] queryResults(int limit, int[][] queries) {
        Map<Integer, Integer> ballColor = new HashMap<>();  // 球 -> 颜色
        Map<Integer, Integer> colorCount = new HashMap<>(); // 颜色 -> 球数
        int unique = 0; // 颜色数恰好为 1 的种数
        int[] ans = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {
            int x = queries[i][0], y = queries[i][1];

            // 处理旧颜色
            if (ballColor.containsKey(x)) {
                int oldColor = ballColor.get(x);
                int oldCnt = colorCount.get(oldColor);
                if (oldCnt == 1) unique--; // 旧颜色不再唯一
                colorCount.put(oldColor, oldCnt - 1);
                if (oldCnt - 1 == 1) unique++; // 旧颜色重新变为唯一
            }

            // 处理新颜色
            int newCnt = colorCount.getOrDefault(y, 0);
            if (newCnt == 1) unique--; // 新颜色原来唯一，即将不再
            colorCount.put(y, newCnt + 1);
            if (newCnt + 1 == 1) unique++; // 新颜色变为唯一

            ballColor.put(x, y);
            ans[i] = unique;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(q)，每次查询 O(1)
- **空间复杂度**：O(q)

## 关键点总结

1. 维护 `colorCount` 跟踪每种颜色的球数，动态更新 `unique`
2. 旧颜色计数减 1、新颜色计数加 1 时，分别检查是否穿越 1 这个阈值
3. 球数量可达 10^9，需用哈希表而非数组
