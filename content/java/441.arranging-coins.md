## 题目描述

你总共有 n 枚硬币，并计划将它们按阶梯状排列。对于一个由 k 行组成的阶梯，其第 i 行必须正好有 i 枚硬币。阶梯的最后一行可能是不完整的。

给你一个数字 n，请你计算并返回可形成完整阶梯行的总行数。

**示例 1:**

```
输入: n = 5
输出: 2
解释: 因为第三行不完整，所以返回 2。
第 1 行: ○
第 2 行: ○ ○
第 3 行: ○ ○
```

**示例 2:**

```
输入: n = 8
输出: 3
解释: 因为第四行不完整，所以返回 3。
第 1 行: ○
第 2 行: ○ ○
第 3 行: ○ ○ ○
第 4 行: ○ ○
```

**提示:**

- 1 <= n <= 2^31 - 1

## 解题思路

这道题本质上是求一个等差数列的和。如果我们能排列 k 行完整的阶梯，那么需要的硬币数量为：

1 + 2 + 3 + ... + k = k * (k + 1) / 2

我们需要找到最大的 k，使得 k * (k + 1) / 2 <= n。

**三种解法思路：**

1. **数学公式法**：通过求解不等式直接计算
2. **二分查找法**：在 [0, n] 范围内二分查找最大的 k
3. **迭代累加法**：从 1 开始逐行累加（适合小数据）

## Java 代码实现

### 方法一：数学公式法（推荐）

```java
class Solution {
    public int arrangeCoins(int n) {
        /**
         * 使用数学公式求解
         * k * (k + 1) / 2 <= n
         * k^2 + k - 2n <= 0
         * k <= (-1 + sqrt(1 + 8n)) / 2
         * 注意：8L * n 避免整数溢出
         */
        // 直接使用求根公式，转为 long 防止溢出
        return (int)((-1 + Math.sqrt(1 + 8L * n)) / 2);
    }
}
```

### 方法二：二分查找法

```java
class Solution {
    public int arrangeCoins(int n) {
        /**
         * 二分查找最大的 k，使得 k*(k+1)/2 <= n
         * 时间复杂度: O(log n)
         * 空间复杂度: O(1)
         */
        long left = 0, right = n;

        while (left <= right) {
            long mid = left + (right - left) / 2;
            // 计算前 mid 行需要的硬币数，使用 long 防止溢出
            long total = mid * (mid + 1) / 2;

            if (total == n) {
                return (int) mid;
            } else if (total < n) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        // 返回 right，因为 right 是最后一个满足条件的值
        return (int) right;
    }
}
```

### 方法三：迭代累加法

```java
class Solution {
    public int arrangeCoins(int n) {
        /**
         * 逐行累加，直到硬币不够
         * 时间复杂度: O(sqrt(n))
         * 空间复杂度: O(1)
         */
        int row = 0;
        long total = 0;

        while (total + row + 1 <= n) {
            row++;
            total += row;
        }

        return row;
    }
}
```

### 方法四：整数平方根法

```java
class Solution {
    public int arrangeCoins(int n) {
        /**
         * 利用整数平方根避免浮点数误差
         * 等价于 Python 的 math.isqrt
         */
        // 计算 (sqrt(8n+1) - 1) / 2，用 long 防止溢出
        long val = (long)(Math.sqrt(8L * n + 1));
        // 修正浮点误差
        while (val * val > 8L * n + 1) val--;
        while ((val + 1) * (val + 1) <= 8L * n + 1) val++;
        return (int)((val - 1) / 2);
    }
}
```

## 复杂度分析

**方法一（数学公式）：**
- 时间复杂度：O(1)，仅需一次计算
- 空间复杂度：O(1)

**方法二（二分查找）：**
- 时间复杂度：O(log n)，二分查找的时间复杂度
- 空间复杂度：O(1)

**方法三（迭代累加）：**
- 时间复杂度：O(√n)，需要迭代约 √n 次
- 空间复杂度：O(1)

## 关键点总结

1. **等差数列求和公式**：k 行完整阶梯需要 k*(k+1)/2 枚硬币
2. **数学转换**：将问题转化为求解不等式 k^2 + k - 2n <= 0
3. **二分查找优化**：可以避免浮点数计算，更稳定
4. **边界处理**：注意 n = 0 和 n = 1 的特殊情况
5. **整数溢出**：Java 中计算 k*(k+1)/2 时要用 long 避免溢出

## 易错点

1. **浮点数精度问题**：
   - 使用 `Math.sqrt()` 可能产生精度误差
   - 建议对结果做边界校验，或使用二分查找

2. **二分查找边界**：
   - 返回的是 `right` 而不是 `left`
   - `right` 是最后一个满足条件的值

3. **溢出问题**：
   - Java 的 int 最大值约为 2.1×10^9，n 最大为 2^31-1
   - 计算 `mid * (mid + 1)` 时必须使用 long

4. **特殊情况**：
   - n = 0 应返回 0
   - n = 1 应返回 1
