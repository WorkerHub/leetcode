## 题目描述

给定未排序整数数组，找到最长连续递增子序列的长度。

**示例：**
```
输入：nums = [1,3,5,4,7]
输出：3（[1,3,5]）
```

## 解题思路

一次遍历，维护当前连续递增长度。当前元素大于前一个则长度+1，否则重置为1。

## Java 代码实现

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        if (nums.length == 0) return 0;

        int maxLen = 1;
        int curLen = 1;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                curLen++;
                maxLen = Math.max(maxLen, curLen);
            } else {
                curLen = 1;
            }
        }

        return maxLen;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **连续性**：必须是原数组中连续的元素
2. **一次遍历**：遇到非递增元素时重置
3. **严格递增**：条件是 >，不是 >=
