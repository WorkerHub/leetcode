## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s`，则返回 `true`。

**注意：** 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**
```
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**
```
输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**
```
输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false
```

**提示：**
- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串互不相同

## 解题思路

这是一道经典的动态规划问题，也可以用带记忆化的回溯解决。

**核心思想：判断字符串能否被字典中的单词拼接**

### 方法一：动态规划（最优解）

**定义状态：**
- `dp[i]` 表示字符串 `s[0..i)`（前 i 个字符）能否被字典中的单词拼接

**状态转移方程：**
```
dp[i] = any(dp[j] && s[j..i) in wordDict) for j in [0, i)
```
- 如果存在某个位置 `j`，使得 `s[0..j)` 可以被拼接（`dp[j] = true`）
- 并且 `s[j..i)` 在字典中
- 那么 `s[0..i)` 就可以被拼接（`dp[i] = true`）

**初始状态：**
- `dp[0] = true`（空字符串可以被拼接）

**算法流程：**
1. 初始化 dp 数组，`dp[0] = true`
2. 遍历字符串的每个位置 i（从 1 到 n）
3. 对于每个 i，检查所有可能的分割点 j（从 0 到 i-1）
4. 如果 `dp[j]` 为 true 且 `s[j..i)` 在字典中，则 `dp[i] = true`

### 方法二：回溯 + 记忆化

从字符串开头开始，尝试匹配字典中的每个单词，递归处理剩余部分，使用记忆化避免重复计算。

## Java 代码实现

### 方法一：动态规划（推荐）

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        // 将字典转为集合，加快查找速度
        Set<String> wordSet = new HashSet<>(wordDict);
        
        // dp[i] 表示 s[0..i) 能否被拼接
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;  // 空字符串可以被拼接
        
        // 遍历字符串的每个位置
        for (int i = 1; i <= n; i++) {
            // 检查所有可能的分割点
            for (int j = 0; j < i; j++) {
                // 如果 s[0..j) 可以被拼接，且 s[j..i) 在字典中
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;  // 找到一种拼接方式即可
                }
            }
        }
        
        return dp[n];
    }
}
```

### 方法二：动态规划（优化版，从单词长度入手）

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        Set<String> wordSet = new HashSet<>(wordDict);
        // 获取字典中单词的最大长度，减少不必要的检查
        int maxLen = 0;
        for (String word : wordDict) {
            maxLen = Math.max(maxLen, word.length());
        }
        
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        
        for (int i = 1; i <= n; i++) {
            // 只检查长度不超过最大单词长度的子串
            for (int j = Math.max(0, i - maxLen); j < i; j++) {
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        
        return dp[n];
    }
}
```

### 方法三：回溯 + 记忆化

```java
class Solution {
    private Map<Integer, Boolean> memo = new HashMap<>();
    
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> wordSet = new HashSet<>(wordDict);
        return backtrack(s, wordSet, 0);
    }
    
    private boolean backtrack(String s, Set<String> wordSet, int start) {
        // 已经处理完整个字符串
        if (start == s.length()) {
            return true;
        }
        
        // 如果已经计算过，直接返回结果
        if (memo.containsKey(start)) {
            return memo.get(start);
        }
        
        // 尝试匹配字典中的每个单词
        for (int end = start + 1; end <= s.length(); end++) {
            String word = s.substring(start, end);
            if (wordSet.contains(word)) {
                // 如果当前单词匹配，递归处理剩余部分
                if (backtrack(s, wordSet, end)) {
                    memo.put(start, true);
                    return true;
                }
            }
        }
        
        memo.put(start, false);
        return false;
    }
}
```

### 方法四：BFS（广度优先搜索）

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> wordSet = new HashSet<>(wordDict);
        int n = s.length();
        boolean[] visited = new boolean[n + 1];  // 记录已访问的位置
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        
        while (!queue.isEmpty()) {
            int start = queue.poll();
            if (start == n) {
                return true;
            }
            
            // 尝试所有可能的下一个位置
            for (int end = start + 1; end <= n; end++) {
                if (!visited[end] && wordSet.contains(s.substring(start, end))) {
                    queue.offer(end);
                    visited[end] = true;
                }
            }
        }
        
        return false;
    }
}
```

## 复杂度分析

### 方法一、二：动态规划
- **时间复杂度**：O(n² × m)，其中 n 是字符串长度，m 是平均单词长度（字符串切片和哈希查找）
- **空间复杂度**：O(n)，dp 数组的空间

### 方法三：回溯 + 记忆化
- **时间复杂度**：O(n² × m)，最坏情况下需要检查所有子串
- **空间复杂度**：O(n)，记忆化数组和递归栈的空间

### 方法四：BFS
- **时间复杂度**：O(n² × m)
- **空间复杂度**：O(n)，队列和 visited 数组的空间

## 关键点总结

1. **动态规划的应用**：将问题分解为子问题，避免重复计算
2. **集合优化查找**：将列表转为集合，O(1) 时间查找
3. **状态定义**：`dp[i]` 表示前缀字符串能否被拼接
4. **优化技巧**：记录最大单词长度，减少不必要的检查
5. **多种解法**：DP、回溯、BFS 都可以解决，但 DP 最优

## 易错点

1. **索引问题**：`dp[i]` 对应字符串 `s[0..i)`，注意 substring 的左闭右开
   ```java
   s.substring(j, i)  // [j, i) 区间
   ```

2. **字典查找**：要将 `wordDict` 转为 `HashSet`，提高查找效率
   ```java
   Set<String> wordSet = new HashSet<>(wordDict);
   ```

3. **初始状态**：`dp[0] = true` 不能忘记，表示空字符串可以被拼接

4. **重复使用**：字典中的单词可以重复使用，不需要标记是否使用过

5. **break 优化**：找到一种拼接方式后可以立即 break，不需要继续检查

1. **理解 DP 思想**：
   - 子问题：前 i 个字符能否被拼接
   - 最优子结构：如果前 j 个字符可以，且 s[j..i) 在字典中，则前 i 个字符可以
   - 无后效性：前面的决策不影响后面
2. **画图辅助**：用表格记录 dp 数组的变化过程
3. **从简单到复杂**：
