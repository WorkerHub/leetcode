## 题目描述

假设有一个很长的花坛，一部分地块种植了花，另一部分却没有。可是，花不能种植在相邻的地块上，它们会争夺水源，两者都会死去。

给你一个整数数组 `flowerbed` 表示花坛，由若干 0 和 1 组成，其中 0 表示没种植花，1 表示种植了花。另有一个数 `n`，能否在不打破种植规则的情况下种入 `n` 朵花？能则返回 `true`，不能则返回 `false`。

**示例 1：**

```
输入：flowerbed = [1,0,0,0,1], n = 1
输出：true
```

**示例 2：**

```
输入：flowerbed = [1,0,0,0,1], n = 2
输出：false
```

**提示：**

- `1 <= flowerbed.length <= 2 * 10^4`
- `flowerbed[i]` 为 0 或 1
- `flowerbed` 中不存在相邻的两朵花
- `0 <= n <= flowerbed.length`

## 解题思路

这是一道经典的**贪心算法**题目。核心思想是：尽可能多地种植花朵，然后判断能否达到 n。

**种植规则：**
- 当前位置为 0（未种花）
- 前一个位置为 0 或不存在（边界）
- 后一个位置为 0 或不存在（边界）

**贪心策略：**
从左到右遍历，只要满足条件就立即种植，这样可以为后面留出更多空间。

**关键观察：**
- 位置 i 可以种花的条件：`flowerbed[i] == 0 && (i == 0 || flowerbed[i-1] == 0) && (i == len-1 || flowerbed[i+1] == 0)`
- 种植后需要将 `flowerbed[i]` 标记为 1，防止下一个位置违反规则

## Java 代码实现

### 方法一：贪心算法（推荐）⭐

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        // 贪心算法：从左到右尽可能多地种花
        int count = 0; // 记录能种植的花朵数量
        int length = flowerbed.length;

        for (int i = 0; i < length; i++) {
            // 检查当前位置是否可以种花
            if (flowerbed[i] == 0) {
                // 检查前一个位置（边界或为0）
                boolean prevEmpty = (i == 0) || (flowerbed[i - 1] == 0);
                // 检查后一个位置（边界或为0）
                boolean nextEmpty = (i == length - 1) || (flowerbed[i + 1] == 0);

                if (prevEmpty && nextEmpty) {
                    // 种植花朵
                    flowerbed[i] = 1;
                    count++;

                    // 提前返回优化
                    if (count >= n) {
                        return true;
                    }
                }
            }
        }

        return count >= n;
    }
}
```

### 方法二：跳跃优化

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        // 优化：种植后可以跳过下一个位置
        int count = 0;
        int i = 0;
        int length = flowerbed.length;

        while (i < length) {
            if (flowerbed[i] == 0
                    && (i == 0 || flowerbed[i - 1] == 0)
                    && (i == length - 1 || flowerbed[i + 1] == 0)) {
                flowerbed[i] = 1;
                count++;
                i += 2; // 跳过下一个位置
                if (count >= n) {
                    return true;
                }
            } else {
                i++;
            }
        }

        return count >= n;
    }
}
```

### 方法三：两端添加虚拟0

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        // 技巧：在数组两端添加虚拟的0，简化边界判断
        int len = flowerbed.length;
        int[] bed = new int[len + 2];
        // 前后各加一个0
        System.arraycopy(flowerbed, 0, bed, 1, len);

        for (int i = 1; i <= len; i++) {
            if (bed[i - 1] == 0 && bed[i] == 0 && bed[i + 1] == 0) {
                bed[i] = 1;
                n--;
            }
        }

        return n <= 0;
    }
}
```

## 复杂度分析

### 方法一、二、三
- **时间复杂度**：O(m)，m 为数组长度，需要遍历一遍数组
- **空间复杂度**：O(1)（方法一、二），O(m)（方法三复制数组）

以 `flowerbed = [1,0,0,0,1], n = 1` 为例：

        ↑

i=0: flowerbed[0]=1，跳过

i=2: flowerbed[2]=0

              ↑

     前面：flowerbed[2]=1 ❌
     
i=4: flowerbed[4]=1，跳过

```

## 关键点总结

1. **贪心思想**：从左到右尽可能多地种花，不会错过更优解
2. **边界处理**：第一个和最后一个位置只需检查一侧
3. **状态更新**：种植后立即更新数组，防止影响后续判断
4. **提前返回**：一旦 count >= n 就可以返回 true
5. **跳跃优化**：种植后下一个位置必然不能种，可以直接跳过

## 易错点

1. **边界条件处理不当**：数组边界时 i-1 或 i+1 越界
2. **忘记更新数组**：种植后必须将 flowerbed[i] 设为 1，否则相邻位置也会被判断为可种植
3. **判断顺序错误**：应该先确保 flowerbed[i] == 0
4. **返回条件错误**：应该是 count >= n 而不是 count == n

**新手学习路径：**

1. **理解贪心算法**：每一步做出当前最优选择，本题能种就种，不会错过更好的方案

2. **边界处理技巧**：
   - 方法一：使用布尔表达式 `(i == 0) || (flowerbed[i-1] == 0)`
   - 方法三：在两端添加虚拟元素，统一处理逻辑

3. **循序渐进**：
   - 第一步：写出暴力检查（不考虑优化）
   - 第二步：添加提前返回优化
   - 第三步：尝试跳跃优化

4. **测试用例**：
   ```

   [0], n=1          // 单个元素
