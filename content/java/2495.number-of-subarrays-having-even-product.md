## 题目描述

给你整数数组 `nums`，返回乘积为偶数的子数组数量（子数组乘积为偶数当且仅当含至少一个偶数）。

## 解题思路

以 `i` 结尾的偶数乘积子数组数 = `lastEven + 1`（左端点可取 `0` 到 `lastEven`），`lastEven` 为 `i` 左侧（含 `i`）最近偶数的下标；若 `i` 左侧无偶数则贡献 0。

## Java 代码实现

```java
class Solution {
    public long numberOfSubarrays(int[] nums) {
        long ans = 0;
        int lastEven = -1; // 最近偶数的下标
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] % 2 == 0) lastEven = i;
            if (lastEven >= 0) ans += lastEven + 1;
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 偶数乘积 ↔ 子数组内至少有一个偶数
2. 以 i 结尾的合法子数组，左端点可取 0 到 lastEven，共 `lastEven + 1` 个
3. 返回值用 `long` 防止 n² 级别溢出
