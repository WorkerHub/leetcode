## 题目描述

给定只含小写字母的字符串 `s`，返回出现频率最高的元音字母的频率与出现频率最高的辅音字母的频率之和。

## 解题思路

统计每个字符频率，分别在元音集合 `{a,e,i,o,u}` 和辅音中找最大频率，求和。

## Java 代码实现

```java
class Solution {
    public int maxFreqVowelConsonant(String s) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;

        String vowels = "aeiou";
        int maxV = 0, maxC = 0;
        for (int i = 0; i < 26; i++) {
            if (vowels.indexOf('a' + i) >= 0) maxV = Math.max(maxV, cnt[i]);
            else maxC = Math.max(maxC, cnt[i]);
        }
        return maxV + maxC;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 元音：a e i o u，其余为辅音
2. 分别找两类最大频率后求和
3. 字符串中可能无元音或无辅音，返回 0
