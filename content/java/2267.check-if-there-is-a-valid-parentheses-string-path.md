## 题目描述

括号矩阵中从左上到右下（只能向右或向下），判断是否存在路径使括号合法。

## 解题思路

DP：dp[i][j]记录到达(i,j)时可能的未匹配左括号数集合。遇'('余额+1，遇')'余额-1（<0丢弃）。路径长度m+n-1必须为偶数。终点余额含0即合法。

## Java 代码实现

```java
class Solution {
    public boolean hasValidPath(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        if ((m + n - 1) % 2 == 1) return false;

        // dp[j] = 到达当前行第j列可能的余额集合（用boolean数组）
        int maxBal = (m + n) / 2;
        boolean[][] dp = new boolean[n][maxBal + 1];

        for (int i = 0; i < m; i++) {
            boolean[][] ndp = new boolean[n][maxBal + 1];
            for (int j = 0; j < n; j++) {
                // 收集前一状态
                boolean[] prev = new boolean[maxBal + 1];
                if (i == 0 && j == 0) {
                    prev[0] = true;
                }
                if (i > 0) {
                    for (int b = 0; b <= maxBal; b++)
                        if (dp[j][b]) prev[b] = true;
                }
                if (j > 0) {
                    for (int b = 0; b <= maxBal; b++)
                        if (ndp[j - 1][b]) prev[b] = true;
                }

                // 根据当前字符转移
                for (int b = 0; b <= maxBal; b++) {
                    if (!prev[b]) continue;
                    if (grid[i][j] == '(') {
                        if (b + 1 <= maxBal) ndp[j][b + 1] = true;
                    } else {
                        if (b - 1 >= 0) ndp[j][b - 1] = true;
                    }
                }
            }
            dp = ndp;
        }
        return dp[n - 1][0];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(m * n * (m+n))
- **空间复杂度**：O(n * (m+n))

## 关键点总结

1. **路径长度奇数直接返回false**
2. **DP记录余额集合**：余额范围[0, (m+n)/2]
3. **终点余额为0即合法**
