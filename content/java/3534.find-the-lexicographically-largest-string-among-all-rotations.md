## 题目描述

给定字符串 `s`，返回其所有旋转（循环移位）中字典序最大的那个。

## 解题思路

最大旋转一定从最大字符开始。找所有最大字符的位置，逐一比较各旋转串，取最大值。

## Java 代码实现

```java
class Solution {
    public String largestRotation(String s) {
        int n = s.length();
        char maxChar = s.charAt(0);
        for (char c : s.toCharArray()) if (c > maxChar) maxChar = c;

        String best = null;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) != maxChar) continue;
            String rot = s.substring(i) + s.substring(0, i);
            if (best == null || rot.compareTo(best) > 0) best = rot;
        }
        return best;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n * k)，k 为最大字符出现次数，O(n^2) 最坏
- 空间复杂度：O(n)

## 关键点总结

1. 最大旋转一定从最大字符开始，无需枚举所有旋转
2. 有多个最大字符时逐一比较对应旋转
3. Java 字符串 compareTo 支持字典序比较
