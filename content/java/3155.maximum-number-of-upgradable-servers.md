## 题目描述

每个数据中心有 `count[i]` 台服务器，升级一台需 `upgrade[i]` 资金，卖出一台得 `sell[i]` 资金，初始资金 `money[i]`。可卖出若干台换取资金再升级，返回每个数据中心最多能升级的服务器数量。

## 解题思路

设升级 x 台，则卖出 `count - x` 台，所需资金 `x * upgrade <= money + (count - x) * sell`，化简得 `x <= (money + count * sell) / (upgrade + sell)`，再与 `count` 取最小。

## Java 代码实现

```java
class Solution {
    public int[] maxUpgradableServers(int[] count, int[] upgrade, int[] sell, int[] money) {
        int n = count.length;
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            long c = count[i], u = upgrade[i], s = sell[i], m = money[i];
            // x * (u + s) <= m + c * s  =>  x <= (m + c*s) / (u+s)
            ans[i] = (int) Math.min(c, (m + c * s) / (u + s));
        }
        return ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 卖出 `count - x` 台再升级 x 台，资金约束化简为 `x <= (money + count*sell) / (upgrade+sell)`
2. 结果不超过 `count[i]`，取最小值
3. 中间计算使用 `long` 防止溢出
