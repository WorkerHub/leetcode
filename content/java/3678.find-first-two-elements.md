## 题目描述

给你一个整数数组 `nums`，返回数组中最小的两个元素（按升序排列）。若数组元素少于 2 个，返回所有元素。

## 解题思路

线性扫描维护最小值 `first` 和次小值 `second`，遍历一次即可，无需排序。

## Java 代码实现

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findFirstTwo(int[] nums) {
        long first = Long.MAX_VALUE, second = Long.MAX_VALUE;
        for (int x : nums) {
            if (x <= first) {
                second = first;
                first = x;
            } else if (x < second) {
                second = x;
            }
        }
        List<Integer> result = new ArrayList<>();
        result.add((int) first);
        if (second != Long.MAX_VALUE) result.add((int) second);
        return result;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 线性扫描维护最小和次小，允许重复元素
2. 只有一个元素时返回一个元素的列表
