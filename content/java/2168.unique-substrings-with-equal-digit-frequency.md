## 题目描述

给定数字字符串s，返回所有每个出现数字频率相同的不同子串数量。

## 解题思路

枚举所有子串，维护频率数组，判断条件：maxFreq * uniqueCount == length。用滚动哈希去重。

## Java 代码实现

```java
class Solution {
    public int equalDigitFrequency(String s) {
        int n = s.length();
        long MOD = (1L << 61) - 1;
        long BASE = 131;
        Set<Long> seen = new HashSet<>();
        
        for (int i = 0; i < n; i++) {
            int[] cnt = new int[10];
            long hash = 0;
            int uniqueCnt = 0;
            int maxFreq = 0;
            
            for (int j = i; j < n; j++) {
                int d = s.charAt(j) - '0';
                if (cnt[d] == 0) uniqueCnt++;
                cnt[d]++;
                maxFreq = Math.max(maxFreq, cnt[d]);
                hash = (hash * BASE + d + 1) % MOD;
                
                int length = j - i + 1;
                // 所有出现数字频率相同的充要条件
                if (maxFreq * uniqueCnt == length) {
                    seen.add(hash);
                }
            }
        }
        return seen.size();
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N^2)
- **空间复杂度**：O(N^2)

## 关键点总结

1. **频率相等判断**：maxFreq * uniqueCount == length
2. **滚动哈希去重**：避免存储完整字符串
3. **增量维护**：扩展子串时更新cnt、maxFreq、uniqueCnt
