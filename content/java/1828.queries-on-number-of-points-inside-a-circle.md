## 题目描述

给定点集和圆形查询，每个查询计算圆内或圆上的点数。

## 解题思路

暴力枚举：数据量小（各≤500），对每个查询遍历所有点，用距离平方判断。

## Java 代码实现

```java
class Solution {
    public int[] countPoints(int[][] points, int[][] queries) {
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int xj = queries[i][0], yj = queries[i][1], rj = queries[i][2];
            int count = 0;
            for (int[] p : points) {
                int dx = p[0] - xj, dy = p[1] - yj;
                if (dx * dx + dy * dy <= rj * rj) count++;
            }
            answer[i] = count;
        }
        return answer;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N × M)
- **空间复杂度**：O(1)

## 关键点总结

1. **距离平方比较**：避免浮点误差
2. **条件是≤**：包含圆上的点
3. **数据量小**：暴力可行
