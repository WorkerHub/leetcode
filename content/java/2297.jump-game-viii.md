## 题目描述

从下标0跳到n-1，跳跃代价为目标值与当前值之差。只能跳到下一个更大等或更小等的位置，求最小总代价。

## 解题思路

两个单调栈建边：递减栈找下一个>=的位置（代价正），递增栈找下一个<=的位置（代价负变正）。建图后DP求最短路。

## Java 代码实现

```java
class Solution {
    public long minCost(int[] nums, int[] costs) {
        int n = nums.length;
        long[] dp = new long[n];
        Arrays.fill(dp, Long.MAX_VALUE);
        dp[0] = 0;

        // 单调递减栈：找下一个 >= nums[i] 的位置
        Deque<Integer> decStack = new ArrayDeque<>();
        // 单调递增栈：找下一个 <= nums[i] 的位置
        Deque<Integer> incStack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            while (!decStack.isEmpty() && nums[decStack.peek()] <= nums[i]) {
                int j = decStack.pop();
                if (dp[j] != Long.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[j] + costs[i]);
                }
            }
            while (!incStack.isEmpty() && nums[incStack.peek()] >= nums[i]) {
                int j = incStack.pop();
                if (dp[j] != Long.MAX_VALUE) {
                    dp[i] = Math.min(dp[i], dp[j] + costs[i]);
                }
            }
            decStack.push(i);
            incStack.push(i);
        }
        return dp[n - 1];
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N)
- **空间复杂度**：O(N)

## 关键点总结

1. **两个单调栈建边**：分别处理>=和<=跳跃
2. **边权为costs[i]**：跳到i的代价固定
3. **栈弹出时转移DP**：保证每条边只处理一次
