## 题目描述

给你一个二维整数数组 nums，每个元素表示数轴上的区间 `[start, end]`，返回被至少一个区间覆盖的整数点数量。

## 解题思路

差分数组：对每个区间 `[l, r]` 执行 `diff[l]++`、`diff[r+1]--`，前缀和后统计正值个数。

## Java 代码实现

```java
class Solution {
    public int numberOfPoints(List<List<Integer>> nums) {
        int[] diff = new int[102]; // 坐标范围 [1, 100]

        for (List<Integer> interval : nums) {
            int start = interval.get(0), end = interval.get(1);
            diff[start]++;
            diff[end + 1]--;
        }

        // 前缀和，统计被覆盖的点
        int count = 0, prefix = 0;
        for (int i = 1; i <= 100; i++) {
            prefix += diff[i];
            if (prefix > 0) count++;
        }
        return count;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n + max_range)
- **空间复杂度**：O(max_range)

## 关键点总结

1. 差分数组适合区间覆盖计数，前缀和还原覆盖次数
2. `diff[end+1]--` 注意数组大小需预留足够空间
3. 数据范围小（坐标 ≤ 100），直接固定大小数组即可
