## 题目描述

给你小写字母字符串 `s`，返回第一个出现两次的字母。

## 解题思路

用整数的低 26 位做位掩码，遍历时检查当前字母对应位是否已被设置；若是则为答案，否则置位。

## Java 代码实现

```java
class Solution {
    public char repeatedCharacter(String s) {
        int mask = 0;
        for (char c : s.toCharArray()) {
            int bit = 1 << (c - 'a');
            if ((mask & bit) != 0) return c; // 该位已出现过
            mask |= bit;
        }
        return ' '; // 题目保证存在，不会到达此处
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. 位掩码用整数的低 26 位表示 26 个字母的出现状态。
2. 检查 `(mask & bit) != 0` 判断是否已出现，然后 `mask |= bit` 置位。
3. 题目保证答案存在，无需处理不存在的情况。
