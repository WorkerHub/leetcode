## 题目描述

给定一个仅包含数字 `0-9` 的字符串 `num` 和一个目标值整数 `target`，在 `num` 的数字之间添加二元运算符（不是一元）`+`、`-` 或 `*`，返回所有能够得到目标值的表达式。

注意，返回表达式中的操作数不应该包含前导零。

**示例 1:**

```
输入: num = "123", target = 6
输出: ["1+2+3", "1*2*3"]
解释: "1*2*3" 和 "1+2+3" 都能得到 6。
```

**示例 2:**

```
输入: num = "232", target = 8
输出: ["2*3+2", "2+3*2"]
解释: "2*3+2" 和 "2+3*2" 都能得到 8。
```

**示例 3:**

```
输入: num = "3456237490", target = 9191
输出: []
解释: 表达式 "3456237490" 无法得到 9191。
```

**提示:**

- `1 <= num.length <= 10`
- `num` 仅含数字
- `-2^31 <= target <= 2^31 - 1`

## 解题思路

这是一道经典的回溯问题，难点在于处理乘法的优先级和前导零。

**核心思想：**

1. **回溯枚举**：在每两个数字之间尝试放置 `+`、`-`、`*` 或不放（连续数字）
2. **乘法优先级**：需要记录上一个操作数，遇到乘法时要回退上一步的加减操作
3. **前导零处理**：数字不能有前导零（除了数字 0 本身）

**关键难点：处理乘法**

假设当前表达式为 `a + b`，当前值为 `a + b`，现在要添加 `* c`：
- 应该计算 `a + b * c`，而不是 `(a + b) * c`
- 需要先减去 `b`，再加上 `b * c`
- 因此需要记录上一个操作数 `prev`

**示例：** `"123"` 目标 6
```
1 + 2 + 3 = 6  ✓
1 + 2 * 3 = 1 + 6 = 7  ✗
1 * 2 + 3 = 2 + 3 = 5  ✗
1 * 2 * 3 = 6  ✓
```

**算法流程：**

1. 从第一个数字开始，枚举所有可能的数字组合
2. 对于每个数字，尝试添加 `+`、`-`、`*` 操作符
3. 递归处理剩余字符串
4. 到达字符串末尾时，检查是否等于目标值
5. 处理乘法时，使用 `current - prev + prev * num` 的技巧

## Java 代码实现

### 方法一：回溯法（标准解法）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> addOperators(String num, int target) {
        List<String> result = new ArrayList<>();
        backtrack(num, target, 0, "", 0, 0, result);
        return result;
    }

    /**
     * 回溯递归
     * @param num    原始数字字符串
     * @param target 目标值
     * @param index  当前处理的位置
     * @param path   当前构建的表达式字符串
     * @param current 当前表达式的计算结果
     * @param prev   上一个操作数（用于处理乘法优先级）
     * @param result 结果列表
     */
    private void backtrack(String num, int target, int index,
                           String path, long current, long prev,
                           List<String> result) {
        // 递归终止：处理完所有数字
        if (index == num.length()) {
            if (current == target) {
                result.add(path);
            }
            return;
        }

        // 枚举当前位置开始的所有可能数字
        for (int i = index; i < num.length(); i++) {
            // 避免前导零（除非数字本身就是 0）
            if (i != index && num.charAt(index) == '0') {
                break;
            }

            String numStr = num.substring(index, i + 1);
            long numVal = Long.parseLong(numStr);

            // 第一个数字，不添加操作符
            if (index == 0) {
                backtrack(num, target, i + 1, numStr, numVal, numVal, result);
            } else {
                // 尝试加法
                backtrack(num, target, i + 1, path + "+" + numStr,
                        current + numVal, numVal, result);

                // 尝试减法
                backtrack(num, target, i + 1, path + "-" + numStr,
                        current - numVal, -numVal, result);

                // 尝试乘法（关键：需要回退上一次的加减操作）
                // current - prev 撤销上一次操作
                // prev * numVal 计算新的乘法结果
                backtrack(num, target, i + 1, path + "*" + numStr,
                        current - prev + prev * numVal, prev * numVal, result);
            }
        }
    }
}
```

### 方法二：使用 StringBuilder 优化字符串拼接

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    private List<String> result;
    private String num;
    private int target;

    public List<String> addOperators(String num, int target) {
        result = new ArrayList<>();
        this.num = num;
        this.target = target;
        backtrack(0, new StringBuilder(), 0L, 0L);
        return result;
    }

    private void backtrack(int index, StringBuilder sb, long current, long prev) {
        if (index == num.length()) {
            if (current == target) {
                result.add(sb.toString());
            }
            return;
        }

        int len = sb.length(); // 记录当前长度，用于回溯

        for (int i = index; i < num.length(); i++) {
            // 前导零剪枝
            if (i != index && num.charAt(index) == '0') break;

            String numStr = num.substring(index, i + 1);
            long numVal = Long.parseLong(numStr);

            if (index == 0) {
                sb.append(numStr);
                backtrack(i + 1, sb, numVal, numVal);
                sb.setLength(len); // 回溯：恢复到之前的长度
            } else {
                // 加法
                sb.append('+').append(numStr);
                backtrack(i + 1, sb, current + numVal, numVal);
                sb.setLength(len);

                // 减法
                sb.append('-').append(numStr);
                backtrack(i + 1, sb, current - numVal, -numVal);
                sb.setLength(len);

                // 乘法
                sb.append('*').append(numStr);
                backtrack(i + 1, sb, current - prev + prev * numVal, prev * numVal);
                sb.setLength(len);
            }
        }
    }
}
```

### 方法三：详细注释版（新手友好）

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> addOperators(String num, int target) {
        List<String> result = new ArrayList<>();
        dfs(num, target, 0, "", 0L, 0L, result);
        return result;
    }

    /**
     * pos:   当前处理到 num 的哪个位置
     * expr:  当前构造的表达式字符串
     * value: 当前表达式的计算值
     * last:  上一个参与计算的数（用于乘法回退）
     *
     * 示例：对于表达式 "1+2*3"
     * - 当处理到 "1+2" 时: value=3, last=2
     * - 添加 "*3" 后: value = 3 - 2 + 2*3 = 1 + 6 = 7
     */
    private void dfs(String num, int target, int pos,
                     String expr, long value, long last,
                     List<String> result) {
        // 边界条件：遍历完整个字符串
        if (pos == num.length()) {
            if (value == target) {
                result.add(expr);
            }
            return;
        }

        // 从当前位置开始，尝试不同长度的数字
        for (int i = pos; i < num.length(); i++) {
            // 跳过前导零（"05" 是非法的，但 "0" 是合法的）
            if (i != pos && num.charAt(pos) == '0') break;

            String s = num.substring(pos, i + 1);
            long n = Long.parseLong(s);

            // 第一个数字特殊处理（不需要运算符）
            if (pos == 0) {
                dfs(num, target, i + 1, s, n, n, result);
                continue;
            }

            // 尝试加法：直接加到 value 上
            dfs(num, target, i + 1, expr + "+" + s, value + n, n, result);

            // 尝试减法：直接从 value 减去
            dfs(num, target, i + 1, expr + "-" + s, value - n, -n, result);

            // 尝试乘法：需要特殊处理
            // 因为 1+2*3 应该是 1+(2*3)=7，而不是 (1+2)*3=9
            // value - last: 撤销上一个数的影响
            // last * n: 计算乘法
            dfs(num, target, i + 1, expr + "*" + s,
                    value - last + last * n, last * n, result);
        }
    }
}
```

## 复杂度分析

**时间复杂度：** `O(4^n * n)`
- 每个位置有 4 种选择：`+`、`-`、`*` 或与下一位组合
- 最坏情况下有 `4^n` 种组合
- 每次构造字符串需要 `O(n)` 时间

**空间复杂度：** `O(n)`
- 递归深度最多为 `n`
- 不计算结果列表的空间

## 关键点总结

1. **乘法处理技巧**：`current - prev + prev * num` 是解决乘法优先级的关键
2. **前导零判断**：长度大于 1 且首字符为 '0' 的数字是非法的
3. **递归参数设计**：需要维护当前值、上一个操作数两个关键信息
4. **long 类型**：Java 中需要用 long 防止整数溢出
5. **边界处理**：第一个数字不需要操作符，需要单独处理

## 易错点

1. **忘记处理乘法优先级**：直接 `current * num` 是错误的
2. **前导零判断不完整**：要用 `break` 而不是 `continue`，因为后续更长的数字也会有前导零
3. **prev 的值**：加法和减法时 `prev` 应该是 `num` 或 `-num`，乘法时是 `prev * num`
4. **整数溢出**：Java 中必须使用 `long` 类型，防止中间计算溢出
5. **第一个数字**：忘记特殊处理第一个数字（不需要运算符）
