## 题目描述

给你二维平面上的点数组 `points`，恰好移除一个点后，返回剩余点对中最大曼哈顿距离的最小可能值。

## 解题思路

令 u = x+y，v = x-y，最大曼哈顿距离 = max(u极差, v极差)。极值由 u/v 的最大最小点决定，枚举移除 4 个极值点中任意一个，取最小结果（O(n) 重新计算）。

## Java 代码实现

```java
class Solution {
    public int minimumDistance(int[][] points) {
        int n = points.length;
        // 找 u=x+y 和 v=x-y 的极值点索引
        int minUi = 0, maxUi = 0, minVi = 0, maxVi = 0;
        for (int i = 1; i < n; i++) {
            int u = points[i][0] + points[i][1];
            int v = points[i][0] - points[i][1];
            if (u < points[minUi][0] + points[minUi][1]) minUi = i;
            if (u > points[maxUi][0] + points[maxUi][1]) maxUi = i;
            if (v < points[minVi][0] - points[minVi][1]) minVi = i;
            if (v > points[maxVi][0] - points[maxVi][1]) maxVi = i;
        }
        int ans = Integer.MAX_VALUE;
        for (int skip : new int[]{minUi, maxUi, minVi, maxVi}) {
            ans = Math.min(ans, maxDistWithout(points, skip));
        }
        return ans;
    }

    private int maxDistWithout(int[][] points, int skip) {
        int minU = Integer.MAX_VALUE, maxU = Integer.MIN_VALUE;
        int minV = Integer.MAX_VALUE, maxV = Integer.MIN_VALUE;
        for (int i = 0; i < points.length; i++) {
            if (i == skip) continue;
            int u = points[i][0] + points[i][1];
            int v = points[i][0] - points[i][1];
            minU = Math.min(minU, u); maxU = Math.max(maxU, u);
            minV = Math.min(minV, v); maxV = Math.max(maxV, v);
        }
        return Math.max(maxU - minU, maxV - minV);
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，枚举 4 个候选点，每次 O(n)
- 空间复杂度：O(1)

## 关键点总结

1. 曼哈顿距离通过坐标旋转 45° 转化，最大距离 = max(u极差, v极差)
2. 只需枚举移除 4 个极值点的情况
