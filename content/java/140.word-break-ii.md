## 题目描述

给定一个字符串 `s` 和一个字符串字典 `wordDict`，在字符串 `s` 中增加空格来构建一个句子，使得句子中所有的单词都在词典中。**以任意顺序**返回所有这些可能的句子。

**注意：** 词典中的同一个单词可能在分段中被重复使用多次。

**示例 1：**
```
输入: s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
输出: ["cats and dog","cat sand dog"]
```

**示例 2：**
```
输入: s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
输出: ["pine apple pen apple","pineapple pen apple","pine applepen apple"]
解释: 注意你可以重复使用字典中的单词。
```

**示例 3：**
```
输入: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出: []
```

**提示：**
- `1 <= s.length <= 20`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 10`
- `s` 和 `wordDict[i]` 仅有小写英文字母组成
- `wordDict` 中所有字符串都不同

## 解题思路

这道题是 LeetCode 139（单词拆分）的进阶版，需要返回所有可能的拼接方案。

**核心思想：回溯 + 记忆化搜索**

### 关键步骤：

1. **先判断能否拼接**：使用 139 题的 DP 方法判断是否有解，避免无解时的无效回溯
2. **回溯生成所有方案**：从字符串开头开始，尝试匹配字典中的每个单词
3. **记忆化优化**：对于相同的子串，记录其所有可能的拆分结果

### 算法流程：

1. 使用 DP 预判断字符串能否被拆分（剪枝）
2. 从位置 0 开始回溯：
   - 尝试匹配字典中的每个单词
   - 如果匹配成功，递归处理剩余部分
   - 将当前单词与剩余部分的结果组合
3. 使用哈希表记忆化，避免重复计算相同子串的拆分

## Java 代码实现

### 方法一：回溯 + 记忆化（推荐）

```java
class Solution {
    private Map<Integer, List<String>> memo = new HashMap<>();
    private Set<String> wordSet;
    private String s;
    
    public List<String> wordBreak(String s, List<String> wordDict) {
        this.s = s;
        this.wordSet = new HashSet<>(wordDict);
        return backtrack(0);
    }
    
    private List<String> backtrack(int start) {
        // 如果已经到达字符串末尾，返回空字符串作为递归基础
        if (start == s.length()) {
            List<String> result = new ArrayList<>();
            result.add("");
            return result;
        }
        
        // 如果已经计算过，直接返回
        if (memo.containsKey(start)) {
            return memo.get(start);
        }
        
        List<String> results = new ArrayList<>();
        // 尝试从 start 开始的所有可能的单词
        for (int end = start + 1; end <= s.length(); end++) {
            String word = s.substring(start, end);
            if (wordSet.contains(word)) {
                // 递归获取剩余部分的所有拆分
                List<String> subResults = backtrack(end);
                // 将当前单词与剩余部分的结果组合
                for (String sub : subResults) {
                    if (sub.isEmpty()) {
                        results.add(word);
                    } else {
                        results.add(word + " " + sub);
                    }
                }
            }
        }
        
        memo.put(start, results);
        return results;
    }
}
```

### 方法二：回溯 + DP 预判断（优化版）

```java
class Solution {
    public List<String> wordBreak(String s, List<String> wordDict) {
        Set<String> wordSet = new HashSet<>(wordDict);
        int n = s.length();
        
        // 先用 DP 判断能否拆分（剪枝）
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && wordSet.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        
        // 如果无法拆分，直接返回空列表
        if (!dp[n]) {
            return new ArrayList<>();
        }
        
        // 回溯生成所有拆分方案
        Map<Integer, List<String>> memo = new HashMap<>();
        return dfs(s, wordSet, dp, memo, 0);
    }
    
    private List<String> dfs(String s, Set<String> wordSet, boolean[] dp,
                              Map<Integer, List<String>> memo, int start) {
        if (start == s.length()) {
            List<String> result = new ArrayList<>();
            result.add("");
            return result;
        }
        if (memo.containsKey(start)) {
            return memo.get(start);
        }
        
        List<String> results = new ArrayList<>();
        for (int end = start + 1; end <= s.length(); end++) {
            // 剪枝：只有 dp[end] 为 true 时才继续
            if (dp[end] && wordSet.contains(s.substring(start, end))) {
                List<String> subResults = dfs(s, wordSet, dp, memo, end);
                for (String sub : subResults) {
                    results.add(s.substring(start, end) + (sub.isEmpty() ? "" : " " + sub));
                }
            }
        }
        
        memo.put(start, results);
        return results;
    }
}
```

### 方法三：回溯（朴素版本，便于理解）

```java
class Solution {
    public List<String> wordBreak(String s, List<String> wordDict) {
        Set<String> wordSet = new HashSet<>(wordDict);
        List<String> results = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backtrack(s, wordSet, 0, path, results);
        return results;
    }
    
    private void backtrack(String s, Set<String> wordSet, int start,
                           List<String> path, List<String> results) {
        // 如果已经处理完整个字符串
        if (start == s.length()) {
            results.add(String.join(" ", path));
            return;
        }
        
        // 尝试所有可能的单词
        for (int end = start + 1; end <= s.length(); end++) {
            String word = s.substring(start, end);
            if (wordSet.contains(word)) {
                path.add(word);
                backtrack(s, wordSet, end, path, results);
                path.remove(path.size() - 1);  // 回溯
            }
        }
    }
}
```

### 方法四：动态规划（自底向上）

```java
class Solution {
    public List<String> wordBreak(String s, List<String> wordDict) {
        Set<String> wordSet = new HashSet<>(wordDict);
        int n = s.length();
        
        // dp[i] 存储 s[0..i) 的所有可能拆分
        List<List<String>> dp = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            dp.add(new ArrayList<>());
        }
        dp.get(0).add("");  // 空字符串
        
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                String word = s.substring(j, i);
                if (wordSet.contains(word) && !dp.get(j).isEmpty()) {
                    // 将 s[0..j) 的每种拆分与当前单词组合
                    for (String sentence : dp.get(j)) {
                        if (sentence.isEmpty()) {
                            dp.get(i).add(word);
                        } else {
                            dp.get(i).add(sentence + " " + word);
                        }
                    }
                }
            }
        }
        
        return dp.get(n);
    }
}
```

## 复杂度分析

### 方法一、二：回溯 + 记忆化
- **时间复杂度**：O(n × 2^n)，最坏情况下有指数级的拆分方案
- **空间复杂度**：O(n × 2^n)，记忆化存储所有结果

### 方法三：朴素回溯
- **时间复杂度**：O(n × 2^n)，没有记忆化会重复计算
- **空间复杂度**：O(n)，递归栈深度

### 方法四：动态规划
- **时间复杂度**：O(n² × 2^n)
- **空间复杂度**：O(n × 2^n)

最终结果：

路径2: cats -> and -> dog   →  "cats and dog"

**记忆化过程：**
```
memo[7] (子串 "dog"):
  - 匹配 "dog"，剩余 "" → ["dog"]

memo[4] (子串 "anddog"):
  - 匹配 "and"，剩余 "dog" → memo[7] = ["dog"]
  - 结果: ["and dog"]

memo[3] (子串 "sanddog"):
  - 匹配 "sand"，剩余 "dog" → memo[7] = ["dog"]
  - 结果: ["sand dog"]

memo[0] (子串 "catsanddog"):
  - 匹配 "cat"，剩余 "sanddog" → memo[3] = ["sand dog"]
  - 结果: ["cat sand dog"]
  - 匹配 "cats"，剩余 "anddog" → memo[4] = ["and dog"]
  - 结果: ["cats and dog"]
```

## 关键点总结

1. **记忆化的必要性**：相同子串会被多次访问，记忆化避免重复计算
2. **DP 预判断**：先判断能否拆分，避免无解时的大量回溯
3. **结果组合**：将当前单词与子问题的结果用空格连接
4. **递归终止条件**：到达字符串末尾时返回包含空字符串的列表
5. **剪枝策略**：利用 DP 结果进行剪枝，只探索有效路径

## 易错点

1. **忘记记忆化**：没有记忆化会导致超时
2. **字符串拼接**：注意空格的处理，空字符串不需要加空格
   ```java
   if (sub.isEmpty()) {
       results.add(word);
   } else {
       results.add(word + " " + sub);
   }
   ```
3. **递归基础情况**：`start == s.length()` 时返回包含空字符串的列表，不是空列表
   ```java
   // 错误
   return new ArrayList<>();
   
   // 正确
   List<String> result = new ArrayList<>();
   result.add("");
   return result;
   ```
4. **结果为空的情况**：有些字符串无法拆分，要先判断
5. **Java 字符串拼接**：用 `String.join(" ", path)` 而不是手动拼接
