## 题目描述

将偶数长度数组配成n/2对，使最大对和最小。

## 解题思路

排序后最小配最大（双指针从两端向中间），取所有对和的最大值。

## Java 代码实现

```java
class Solution {
    public int minPairSum(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int maxPair = 0;
        for (int i = 0; i < n / 2; i++) {
            maxPair = Math.max(maxPair, nums[i] + nums[n - 1 - i]);
        }
        return maxPair;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N log N)
- **空间复杂度**：O(1)

## 关键点总结

1. **贪心**：最小配最大，均衡各对差异
2. **双指针**：排序后从两端向中间配对
