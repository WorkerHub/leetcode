## 题目描述

字符串由 'L', 'R', 'X' 组成。XL 可变为 LX，RX 可变为 XR。判断 start 能否通过若干次操作变为 end。

**示例：**
```
输入：start = "RXXLRXRXL", end = "XRLXXRRLX"
输出：true
```

## 解题思路

双指针：去掉 X 后字符序列必须相同；L 只能左移（start 中位置 >= end 中位置），R 只能右移（start 中位置 <= end 中位置）。

## Java 代码实现

```java
class Solution {
    public boolean canTransform(String start, String end) {
        int n = start.length();
        int i = 0, j = 0;

        while (i < n || j < n) {
            // 跳过 X
            while (i < n && start.charAt(i) == 'X') i++;
            while (j < n && end.charAt(j) == 'X') j++;

            // 都到末尾
            if (i == n && j == n) return true;
            // 只有一个到末尾
            if (i == n || j == n) return false;

            // 字符必须相同
            if (start.charAt(i) != end.charAt(j)) return false;

            // L 只能左移
            if (start.charAt(i) == 'L' && i < j) return false;
            // R 只能右移
            if (start.charAt(i) == 'R' && i > j) return false;

            i++;
            j++;
        }
        return true;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 关键点总结

1. **移动方向**：L 只能左移，R 只能右移
2. **相对顺序**：去掉 X 后 L/R 顺序不变
3. **位置约束**：L 的位置只能减小，R 的位置只能增大
