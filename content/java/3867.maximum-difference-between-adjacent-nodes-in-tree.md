## 题目描述

给你一棵 n 个节点的树（以边列表形式给出）和每个节点的值，返回树中任意一条边两端节点值之差的绝对值的最大值。

## 解题思路

直接遍历所有边，对每条边计算两端节点值之差的绝对值，维护全局最大值。树有 n-1 条边，一次遍历即可。

## Java 代码实现

```java
class Solution {
    public int maxDifference(int n, int[][] edges, int[] values) {
        int ans = 0;
        // 遍历所有边，计算两端节点值差的绝对值
        for (int[] edge : edges) {
            int diff = Math.abs(values[edge[0]] - values[edge[1]]);
            ans = Math.max(ans, diff);
        }
        return ans;
    }
}
```

## 复杂度分析

- 时间复杂度：O(n)，遍历所有边（树有 n-1 条边）
- 空间复杂度：O(1)

## 关键点总结

1. 树有 n-1 条边，遍历所有边计算差值即可。
2. 边是无向的，取绝对值后只需遍历一次，无需反向。
3. 直接使用边列表，无需构建邻接表。
