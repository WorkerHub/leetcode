## 题目描述

给定n节点无向图，返回最短环的长度，不存在环返回-1。

## 解题思路

从每个节点BFS，发现已访问邻居(非父节点)时找到环，环长=dist[u]+dist[v]+1，取所有起点的最小值。

## Java 代码实现

```java
class Solution {
    public int findShortestCycle(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        int ans = Integer.MAX_VALUE;
        for (int src = 0; src < n; src++) {
            int[] dist = new int[n];
            Arrays.fill(dist, -1);
            dist[src] = 0;
            Queue<int[]> queue = new LinkedList<>();
            queue.offer(new int[]{src, -1}); // {节点, 父节点}

            while (!queue.isEmpty()) {
                int[] cur = queue.poll();
                int u = cur[0], parent = cur[1];
                for (int v : graph.get(u)) {
                    if (dist[v] == -1) {
                        dist[v] = dist[u] + 1;
                        queue.offer(new int[]{v, u});
                    } else if (v != parent) {
                        // 发现环
                        ans = Math.min(ans, dist[u] + dist[v] + 1);
                    }
                }
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

## 复杂度分析

- **时间复杂度**：O(N * (N + M))
- **空间复杂度**：O(N + M)

## 关键点总结

1. **每个节点BFS**：发现回边时计算环长
2. **环长公式**：dist[u] + dist[v] + 1
3. **排除父节点**：避免将同一条边误判为环
