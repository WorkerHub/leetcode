## 题目描述

给定平面上的一些点，返回凸包上的所有点。

**示例：**
```
输入：points = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]
输出：[[1,1],[2,0],[4,2],[3,3],[2,4]]
```

## 解题思路

Graham 扫描算法：排序后分别构建上下凸包。

## Java 代码实现

```java
class Solution {
    public int[][] outerTrees(int[][] points) {
        int n = points.length;
        if (n <= 3) return points;

        Arrays.sort(points, (a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);

        // 构建下凸包
        int[] stack = new int[n + 1];
        boolean[] used = new boolean[n];
        int top = 0;

        for (int i = 0; i < n; i++) {
            while (top >= 2 && cross(points[stack[top-2]], points[stack[top-1]], points[i]) < 0) {
                used[stack[--top]] = false;
            }
            stack[top++] = i;
            used[i] = true;
        }

        // 构建上凸包
        int lower = top;
        for (int i = n - 2; i >= 0; i--) {
            if (used[i]) continue;
            while (top > lower && cross(points[stack[top-2]], points[stack[top-1]], points[i]) < 0) {
                used[stack[--top]] = false;
            }
            stack[top++] = i;
            used[i] = true;
        }

        int[][] result = new int[top - 1][2];
        for (int i = 0; i < top - 1; i++) {
            result[i] = points[stack[i]];
        }
        return result;
    }

    private int cross(int[] o, int[] a, int[] b) {
        return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0]);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(n log n)
- **空间复杂度**：O(n)

## 关键点总结

1. **叉积**：判断点的转向
2. **Graham 扫描**：上下凸包分别构建
3. **共线处理**：`< 0` 而非 `<= 0`（保留共线点）
