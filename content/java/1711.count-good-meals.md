## 题目描述

数组 `deliciousness`，两道食物美味程度之和为 2 的幂则为**好餐**。返回好餐数量对 `10^9 + 7` 取余。

## 解题思路

**哈希表：** 顺序遍历，对每个数 `x` 枚举所有 2 的幂（`2^0` 到 `2^21`），查找补数是否已在哈希表中。先查后插，避免自身配对。

## Java 代码实现

```java
class Solution {
    public int countPairs(int[] deliciousness) {
        final int MOD = 1_000_000_007;
        Map<Integer, Integer> count = new HashMap<>();
        long ans = 0;

        for (int x : deliciousness) {
            // 枚举 2^0 到 2^21
            for (int i = 0; i <= 21; i++) {
                int power = 1 << i;
                int comp = power - x;
                ans += count.getOrDefault(comp, 0);
            }
            count.merge(x, 1, Integer::sum);
        }
        return (int) (ans % MOD);
    }
}
```

## 复杂度分析

- **时间复杂度**：O(22n)
- **空间复杂度**：O(n)

## 关键点总结

1. 两数之和最大 `2^21`，枚举 22 个 2 的幂
2. 先查哈希表再插入，自然避免重复计数
