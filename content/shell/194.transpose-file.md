## 题目描述

给定一个文件 `file.txt`，转置它的内容。

你可以假设每行列数相同，并且每个字段由空格 `' '` 分隔。

**示例：**

假设 `file.txt` 内容如下：
```
name age
alice 21
ryan 30
```

应当输出：
```
name alice ryan
age 21 30
```

## 解题思路

这道题要求将文本文件的行列进行转置，类似于矩阵转置操作。

**核心思想：**
1. 原文件的每一行变成结果的每一列
2. 原文件的每一列变成结果的每一行
3. 需要将第 i 行第 j 列的元素放到新的第 j 行第 i 列

**算法步骤：**
1. 读取文件，确定行数和列数
2. 对于每一列（列号从 1 到 n）：
   - 提取该列的所有元素
   - 将它们用空格连接成一行输出

**Shell 实现策略：**
- 使用 `awk` 的数组存储每一列的数据
- 使用 `NF`（字段数）确定列数
- 使用 `NR`（行号）遍历所有行

## Bash 代码实现

### 方法一：awk 数组存储（推荐）⭐

```bash
# Read from the file file.txt and print its transposed content to stdout.
awk '
{
    # 遍历当前行的每个字段
    for (i = 1; i <= NF; i++) {
        # 将第 i 列的值存入数组 a[i]，多行用空格连接
        if (NR == 1) {
            a[i] = $i
        } else {
            a[i] = a[i] " " $i
        }
    }
}
END {
    # 输出转置后的结果
    for (i = 1; i <= NF; i++) {
        print a[i]
    }
}
' file.txt
```

**代码说明：**
- `NF`：当前行的字段数（列数）
- `NR`：当前行号
- `$i`：第 i 个字段的值
- `a[i]`：存储第 i 列的所有值
- 第一行直接赋值，后续行用空格拼接

### 方法二：awk 简化版

```bash
# Read from the file file.txt and print its transposed content to stdout.
awk '
{
    for (i = 1; i <= NF; i++) {
        a[i] = (a[i] ? a[i] " " : "") $i
    }
}
END {
    for (i = 1; i <= NF; i++) {
        print a[i]
    }
}
' file.txt
```

**代码说明：**
- 使用三元运算符 `a[i] ? a[i] " " : ""`
- 如果 `a[i]` 存在则添加空格，否则从空字符串开始
- 更简洁，避免判断 `NR == 1`

### 方法三：使用 paste 命令

```bash
# Read from the file file.txt and print its transposed content to stdout.
# 方法：将每一列提取出来，然后用 paste 合并

# 获取列数
ncol=$(head -1 file.txt | wc -w)

# 遍历每一列
for i in $(seq 1 $ncol); do
    cut -d' ' -f$i file.txt | paste -sd' '
done
```

**代码说明：**
- `wc -w`：统计单词数，即列数
- `cut -d' ' -f$i`：提取第 i 列
- `paste -sd' '`：将多行合并成一行，用空格分隔

### 方法四：纯 awk 一行版

```bash
# Read from the file file.txt and print its transposed content to stdout.
awk '{for(i=1;i<=NF;i++)a[i]=(a[i]?a[i]" ":"")$i}END{for(i=1;i<=NF;i++)print a[i]}' file.txt
```

**代码说明：**
- 与方法二相同，只是压缩成一行
- 适合 LeetCode 提交

## 复杂度分析

**时间复杂度：** O(n × m)
- n 是行数
- m 是列数
- 需要遍历所有元素

**空间复杂度：** O(n × m)
- 需要数组存储所有元素

## 关键点总结

1. **awk 数组**：使用关联数组存储每一列的数据
2. **字段遍历**：`for (i = 1; i <= NF; i++)` 遍历当前行的所有字段
3. **字符串拼接**：在 awk 中使用空格直接拼接字符串
4. **END 块**：在处理完所有行后执行，用于输出结果
5. **三元运算符**：`condition ? true_value : false_value` 简化条件判断

## 易错点

1. **空格分隔符**：
   - `awk` 默认使用空格和制表符作为分隔符
   - 如果需要指定分隔符，使用 `-F` 选项

2. **数组索引从 1 开始**：
   - awk 中字段编号从 1 开始（`$1, $2, ...`）
   - `$0` 表示整行

3. **字符串拼接时的空格**：
   - 第一个元素前不应有空格
   - 后续元素之间用单个空格分隔

4. **列数获取**：
   - 假设所有行列数相同
   - 使用第一行或最后一行的 `NF` 都可以

5. **paste 命令的 -s 选项**：
   - `-s`：串行模式，将多行合并成一行
   - `-d' '`：指定分隔符为空格
