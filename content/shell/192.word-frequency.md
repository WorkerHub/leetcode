## 题目描述

写一个 bash 脚本以统计一个文本文件 `words.txt` 中每个单词出现的频率。

为了简单起见，你可以假设：
- `words.txt` 只包含小写字母和空格 `' '` 字符。
- 每个单词只包含小写字母。
- 单词间由一个或多个空格字符分隔。

**示例：**

假设 `words.txt` 内容如下：
```
the day is sunny the the
the sunny is is
```

你的脚本应当输出（以词频降序排列）：
```
the 4
is 3
sunny 2
day 1
```

**说明：**
- 不要担心词频相同的单词的排序问题，每个单词出现的频率都是唯一的。
- 你能想出多种解决方案吗？

## 解题思路

这道题需要使用 Shell 命令进行文本处理。核心步骤：

1. **分词**：将文本中的单词分离出来（每行一个单词）
2. **排序**：相同的单词排在一起
3. **计数**：统计每个单词出现的次数
4. **排序**：按频率降序排列

### 常用 Shell 命令

- `cat`：读取文件内容
- `tr`：转换或删除字符
- `sort`：排序
- `uniq -c`：统计重复行的次数
- `awk`：文本处理工具
- `xargs`：构建命令行

## Shell 代码实现

### 方法一：tr + sort + uniq（推荐）⭐

```bash
#!/bin/bash

# 使用 tr 将空格替换为换行，然后排序、计数、再排序
cat words.txt | tr -s ' ' '\n' | sort | uniq -c | sort -rn | awk '{print $2, $1}'
```

**命令解析：**
- `cat words.txt`：读取文件内容
- `tr -s ' ' '\n'`：将空格替换为换行符（`-s` 压缩连续的空格）
- `sort`：按字典序排序（相同单词会相邻）
- `uniq -c`：统计每个单词出现的次数（前面加上次数）
- `sort -rn`：按数字降序排序（`-r` 逆序，`-n` 数字排序）
- `awk '{print $2, $1}'`：交换列顺序（先打印单词，再打印次数）

### 方法二：awk 一行解决（最简洁）⭐

```bash
#!/bin/bash

# 使用 awk 直接统计和排序
awk '{
    for (i=1; i<=NF; i++) {
        count[$i]++
    }
}
END {
    for (word in count) {
        print word, count[word]
    }
}' words.txt | sort -k2 -rn
```

**命令解析：**
- `for (i=1; i<=NF; i++)`：遍历每一行的每个字段（`NF` 是字段数）
- `count[$i]++`：用关联数组统计每个单词的频率
- `END`：处理完所有行后执行
- `print word, count[word]`：输出单词和频率
- `sort -k2 -rn`：按第二列（频率）数字降序排序

### 方法三：xargs + sort + uniq

```bash
#!/bin/bash

# 使用 xargs 将所有单词转换为每行一个单词
cat words.txt | xargs -n 1 | sort | uniq -c | sort -rn | awk '{print $2, $1}'
```

**命令解析：**
- `xargs -n 1`：每次取一个参数，输出到新行
- 其余步骤同方法一

### 方法四：完整的 awk 解决方案（一步到位）

```bash
#!/bin/bash

# awk 完成所有处理，包括排序
awk '{
    for (i=1; i<=NF; i++) {
        count[$i]++
    }
}
END {
    # 将结果存入数组
    for (word in count) {
        words[++n] = word
        freq[n] = count[word]
    }
    
    # 冒泡排序（按频率降序）
    for (i=1; i<=n; i++) {
        for (j=i+1; j<=n; j++) {
            if (freq[i] < freq[j]) {
                # 交换频率
                temp = freq[i]
                freq[i] = freq[j]
                freq[j] = temp
                # 交换单词
                temp = words[i]
                words[i] = words[j]
                words[j] = temp
            }
        }
    }
    
    # 输出结果
    for (i=1; i<=n; i++) {
        print words[i], freq[i]
    }
}' words.txt
```

### 方法五：grep + sort + uniq

```bash
#!/bin/bash

# 使用 grep 提取单词
grep -oE '[a-z]+' words.txt | sort | uniq -c | sort -rn | awk '{print $2, $1}'
```

**命令解析：**
- `grep -oE '[a-z]+'`：提取所有小写字母单词（`-o` 只输出匹配部分，`-E` 扩展正则）
- 其余步骤同方法一

## 复杂度分析

**方法一（tr + sort + uniq）：**
- **时间复杂度**：O(n log n)，主要是排序的复杂度
- **空间复杂度**：O(n)，需要存储所有单词

**方法二（awk）：**
- **时间复杂度**：O(n + k log k)，n 是单词总数，k 是不同单词数
- **空间复杂度**：O(k)，存储不同的单词

## 关键点总结

1. **文本分词**：
   - `tr -s ' ' '\n'`：替换空格为换行
   - `xargs -n 1`：每行一个单词
   - `grep -oE '[a-z]+'`：正则提取单词

2. **统计频率**：
   - `uniq -c`：统计相邻重复行（需要先排序）
   - `awk` 关联数组：直接统计

3. **排序技巧**：
   - `sort -rn`：按数字降序（`-r` 逆序，`-n` 数字）
   - `sort -k2 -rn`：按第二列降序

4. **awk 强大功能**：
   - 关联数组：`count[$i]++`
   - 遍历数组：`for (word in count)`
   - 字段访问：`$i` 表示第 i 个字段

5. **管道组合**：Shell 的强大之处在于可以组合多个命令

## 易错点

1. **tr 的空格处理**：
   ```bash
   tr -s ' ' '\n'   # ✅ -s 压缩连续空格
   tr ' ' '\n'      # ❌ 多个空格会产生空行
   ```

2. **sort 的类型**：
   ```bash
   sort -rn         # ✅ 按数字降序
   sort -r          # ❌ 按字符串降序（10 < 2）
   ```

3. **uniq 必须先排序**：
   ```bash
   sort | uniq -c   # ✅ 正确
   uniq -c          # ❌ 只统计相邻的重复行
   ```

4. **awk 的字段顺序**：
   ```bash
   awk '{print $2, $1}'  # ✅ 先单词后频率
   awk '{print $1, $2}'  # ❌ 先频率后单词
   ```

5. **文件不存在的处理**：
   ```bash
   cat words.txt 2>/dev/null || echo "File not found"
   ```
