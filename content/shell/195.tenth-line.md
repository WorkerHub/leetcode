## 题目描述

给定一个文本文件 `file.txt`，请只打印这个文件中的第十行。

**示例：**

假设 `file.txt` 有如下内容：

```
Line 1
Line 2
Line 3
Line 4
Line 5
Line 6
Line 7
Line 8
Line 9
Line 10
```

你的脚本应当显示第十行：

```
Line 10
```

**说明：**

1. 如果文件少于十行，你应当输出什么？
2. 至少有三种不同的解法，请尝试尽可能多的方法来解决。

## 解题思路

这是一道 Shell 脚本题，需要从文件中提取特定行。主要思路包括：

1. **使用 sed 命令**：sed 可以指定行号进行操作
2. **使用 tail 和 head 组合**：先取前10行，再取最后1行
3. **使用 awk 命令**：awk 可以处理行号
4. **使用 NR 变量**：在脚本中判断行号

**关键点：**
- 处理文件少于10行的情况（避免错误输出）
- Shell 命令的行号从1开始计数
- 不同命令的效率和可读性

## Bash 代码实现

### 方法一：sed 命令（推荐）

```bash
#!/bin/bash
# 使用 sed 提取第10行
# -n: 不自动打印所有行
# 10p: 只打印第10行
sed -n '10p' file.txt
```

**优点：** 简洁高效，sed 专门用于文本处理

### 方法二：tail 和 head 组合

```bash
#!/bin/bash
# 先取前10行，再从中取最后1行
head -n 10 file.txt | tail -n 1
```

**说明：**
- `head -n 10`：取前10行
- `tail -n 1`：从管道输入中取最后1行

**缺点：** 如果文件不足10行，会输出最后一行而非空

### 方法三：awk 命令

```bash
#!/bin/bash
# 使用 awk 的行号变量 NR
# NR == 10: 当前行号等于10时执行
awk 'NR == 10' file.txt
```

**说明：**
- `NR`：awk 的内置变量，表示当前行号
- 当 NR == 10 时，默认操作是打印该行

### 方法四：awk 优化版（处理少于10行）

```bash
#!/bin/bash
# 处理文件少于10行的情况
awk 'NR == 10 {print; exit}' file.txt
```

**改进：**
- 找到第10行后立即退出，提高效率
- 文件少于10行时不输出任何内容

### 方法五：tail 命令

```bash
#!/bin/bash
# 跳过前9行，取下一行
tail -n +10 file.txt | head -n 1
```

**说明：**
- `tail -n +10`：从第10行开始显示到文件末尾
- `head -n 1`：只取第一行

### 方法六：sed 增强版（处理边界情况）

```bash
#!/bin/bash
# 检查文件行数
if [ $(wc -l < file.txt) -ge 10 ]; then
    sed -n '10p' file.txt
fi
```

**特点：** 显式检查文件行数，更严谨

## 复杂度分析

### 时间复杂度

- **方法一（sed）**：O(n)，其中 n = 10，sed 读取到第10行即可停止（内部优化）
- **方法二（head + tail）**：O(10)，head 读取前10行
- **方法三（awk）**：O(n)，awk 需要逐行读取直到第10行
- **方法五（tail + head）**：O(n)，tail 需要先定位到第10行

实际上，对于小文件，性能差异可忽略；对于大文件，sed 和 awk 更高效。

### 空间复杂度

所有方法：O(1)，只存储当前处理的行

## 命令对比

| 方法 | 命令 | 优点 | 缺点 |
|------|------|------|------|
| sed | `sed -n '10p'` | 简洁、专业 | 需要了解 sed 语法 |
| awk | `awk 'NR==10'` | 灵活、可扩展 | 稍显冗长 |
| head+tail | `head -10 \| tail -1` | 直观易懂 | 文件少于10行时有问题 |
| tail+head | `tail -n+10 \| head -1` | 可用 | 不够简洁 |

## 关键点总结

1. **sed 是首选**：`sed -n '10p'` 最简洁高效
2. **行号从1开始**：Shell 命令的行号计数从1开始，不是0
3. **边界情况**：需要考虑文件少于10行的情况
4. **管道组合**：多个命令可以通过管道 `|` 组合使用
5. **效率考虑**：对于大文件，sed 和 awk 在找到目标行后会停止读取（内部优化）

## 易错点

1. **使用 `sed '10p'` 而非 `sed -n '10p'`**
   - 错误：会输出所有行，第10行重复输出
   - 正确：使用 `-n` 禁止自动打印

2. **head + tail 顺序错误**
   - 错误：`tail -1 file.txt | head -10`（逻辑错误）
   - 正确：`head -10 file.txt | tail -1`

3. **文件不存在或为空**
   - 应该检查文件是否存在：`[ -f file.txt ]`
   - 或使用 `2>/dev/null` 重定向错误输出

4. **行号理解错误**
   - Shell 行号从1开始，不是0
   - `tail -n +10` 表示从第10行开始（包含第10行）
